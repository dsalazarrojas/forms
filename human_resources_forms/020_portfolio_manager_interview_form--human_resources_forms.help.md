# portfolio_manager_interview_form - Help Guide
## Purpose
The "portfolio_manager_interview_form" is a tool designed to gather information about an individual's work history and experiences.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the required fields with the requested information.
2. Review each field explanation below for details on what information to enter and how it will be used.

## Field-by-Field Explanation
* **Candidate Information** (`Candidate Information`, text, required/optional): Enter a brief description of the candidate or employee, such as name and job title.
* **Job Title** (`Job Title`, text, optional): Enter the job title of the current or most recent job.
* **Employment Status** (`Employment Status`, select_one, optional): Select "active", "inactive", or "retired" to indicate the current employment status.
* **Job Start Date** (`Job Start Date`, date, optional): Enter the start date of the job.
* **Job End Date** (`Job End Date`, date, optional): Enter the end date of the job.
* **Job Duration** (`Job Duration`, number, optional): Enter the length of time worked in the job.
* **Salary** (`Salary`, number, optional): Enter the current or most recent salary.
* **Contact Information** (`Contact Information`, text, optional): Enter any additional contact information such as a personal email or phone number.
* **Email** (`Email`, email, optional): Enter the email address of the candidate or employee.
* **Phone Number** (`Phone Number`, text, optional): Enter the phone number of the candidate or employee.
* **Work Address** (`Work Address`, text, optional): Enter the work address of the candidate or employee.
* **Work Address Line 1** (`Work Address Line 1`, text, optional): Enter the first line of the work address.
* **Work Address Line 2** (`Work Address Line 2`, text, optional): Enter the second line of the work address.
* **City** (`City`, text, optional): Enter the city of the work address.
* **State** (`State`, select_one, optional): Select the state of the work address from the list.
* **Zip Code** (`Zip Code`, number, optional): Enter the zip code of the work address.
* **Job Title 2** (`Job Title 2`, text, optional): Enter any additional job titles.
* **Work Experience** (`Work Experience`, text, optional): Enter any additional work experience details.
* **Skills** (`Skills`, select_multiple, optional): Select any relevant skills from the list, such as Microsoft Office or Adobe Creative Suite.
* **Work Education** (`Work Education`, text, optional): Enter any additional work education details.
* **Education Level** (`Education Level`, select_one, optional): Select the level of education (e.g., High School, Bachelor's, etc.).
* **Work Experience Years** (`Work Experience Years`, number, optional): Enter the length of time worked in years.
* **Job Function** (`Job Function`, select_multiple, optional): Select any relevant job functions from the list, such as Software Development or Marketing.
* **Job Function 2** (`Job Function 2`, optional): Enter any additional job functions. 

Note: This form is designed to be filled out by the user, so please ensure to read each field explanation carefully and fill in the relevant information accurately. If you are unsure about any field, please ask the administrator for clarification.
