# Employee Development Metrics Program Registration Form - Help Guide
## Purpose
The purpose of this form is to collect information from employees participating in development programs, enabling Human Resources teams and managers to track and monitor employee development metrics.

## How To Complete This Form
To complete this form, follow these steps:
1. Select the correct development program from the available options on Page 2.
2. Provide a brief description of the employee details on Page 3.
3. Enter the registration date on Page 4.

## Field-by-Field Explanation
### Page 1
* **First Page**: This page serves as a general overview of the form and is currently not required to be filled out, but it's recommended to review the form before proceeding.

### Page 2
* **Development Program Details**: Select the correct development program that the employee is participating in from the dropdown menu. This is a crucial field as it determines which development program the employee will be tracked under.

### Page 3
* **Employee Details**: Please provide a brief description of the employee's details, such as their name, job title, or any other relevant information.

### Page 4
* **Registration Date**: Enter the date the employee registered for the development program. This date is used to track the registration timeline and ensure accurate monitoring of progress.

**Tips**
* Make sure to review the form thoroughly before submission to avoid errors.
* Ensure that each submission is made only once to maintain data accuracy.
* If you have any questions or concerns, please don't hesitate to contact your HR team for assistance.
