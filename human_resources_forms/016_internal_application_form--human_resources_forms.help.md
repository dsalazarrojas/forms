# Internal Application Form - Help Guide
## Purpose
This form is used to submit internal job applications within the organization.

## How To Complete This Form
Before filling out this form, please ensure that you have reviewed and understood the internal job posting guidelines and that you are eligible to apply for the job. If you need help or guidance, contact your HR representative for assistance.

## Field-by-Field Explanation
- **Job Title** (`job_title`, select_one, required): Select the title of the job you are applying for.
- **Job Description** (`job_description`, text, optional): Provide a brief description of the job you are applying for. This field is optional, but it can help your application stand out.
- **Job Tags** (`job_tags`, select_multiple, optional): Choose relevant tags to describe the job you are applying for. This field is optional and can help with job categorization and searching.
- **Tags Choices** (`job_tags_choices`, text, optional): Enter any additional tags or keywords related to the job. This field is optional and can help with job filtering and searching.
- **Work Hours** (`work_hours`, time, optional): If the job requires specific work hours, enter them here. This field is optional, but it can help the hiring manager understand the job requirements.
- **Job Type** (`job_type`, select_one, optional): Check if the job is full-time or part-time.
- **Job Type Choices** (`job_type_choices`, select_multiple, optional): If you have multiple job types, select all that apply. This field is optional.
- **Work Duration** (`work_duration`, date, optional): Enter the expected duration of the job.
- **Work Duration Choices** (`work_duration_choices`, text, optional): If you have specific requirements or limitations for the job duration, enter them here. This field is optional.
- **Contact Person** (`contact_person`, text, optional): If you have a specific contact person for this job, enter their name. This field is optional.
- **Contact Email** (`contact_email`, email, optional): If you have a specific contact email for this job, enter it. This field is optional.
- **Contact Phone** (`contact_phone`, text, optional): If you have a specific contact phone number for this job, enter it. This field is optional.
- **Job Posting Date** (`job_posting_date`, date, optional): Enter the date the job was posted. This field is optional.
- **Internal Applying** (`internal_applying`, select_one, optional): Check if this is an internal application.
- **Internal Posting Choices** (`internal_posting_choices`, select_one, optional): If this is an internal posting, select the type of internal posting. This field is optional.

Note: The fields marked as "optional" are not required, but filling them out can provide additional context and information to the hiring manager.
