# Peer Evaluation Rubric Form Template - Help Guide

## Purpose

This form is used for peer evaluation, where a participant is asked to evaluate their peers based on a set of criteria. The form is designed to collect information about the participant's peer's performance and provide feedback for improvement.

## How To Complete This Form

1.  To complete this form, follow the instructions below.
2.  Start by filling in the required fields, which are marked with an asterisk (\*).
3.  For each field, provide a response based on your honest and constructive feedback.
4.  Make sure to review your answers before submitting the form to ensure you've provided accurate and complete information.

## Field-by-Field Explanation

* **Peer Evaluation Rubric** (`section_2`, text, required/optional): This field is for providing comments or feedback about the peer's performance. Enter your thoughts and observations about the peer's strengths and weaknesses.
* **Criteria 1** (`criteria_1`, select_one, required): Select "Yes" if the peer has met this criterion, "No" if they haven't. This will help identify areas where the peer needs improvement.
* **Criteria 2, 3, 4, 5** (`criteria_2`, `criteria_3`, `criteria_4`, `criteria_5`, select_multiple, required): For each criterion, select all the options that apply to the peer's performance.
* **Comments** (`comments`, text, optional) and **Comments (2)** (`comments_2`, text, optional): These fields are for any additional comments or feedback you'd like to provide. They are not required, but can be helpful for the peer to understand your perspective.
* **Submit** (`submit`, note, required/optional): Click this button to submit your evaluation.
