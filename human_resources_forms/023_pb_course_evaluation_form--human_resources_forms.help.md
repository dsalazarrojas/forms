# pb_course_evaluation_form - Help Guide
## Purpose
This form is used to collect information for employee evaluations.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the Employee Name field with the name of the employee you are evaluating.
2. Enter the Email field with the employee's email address.
3. Write your Evaluation in the Evaluation field, which should be a free-text note.
4. Choose a Date when the evaluation was conducted.
5. Select a Time when the evaluation was conducted.
6. Enter the Phone number of the employee (if applicable).
7. Select one option from the Select One field.
8. Select multiple options from the Select Multiple field.
9. Enter the Decimal Places field with a numeric value.
10. Select one or multiple options from the Integer Values field.
11. Add any additional comments in the Note field (optional).
11. If not required, fill in the Text Input Field.

## Field-by-Field Explanation
* **Employee Name**: The name of the employee being evaluated.
  * Type: Text
  * Required: Yes
* **Email**: The email address of the employee being evaluated.
  * Type: Email
  * Required: Yes
* **Evaluation**: A free-text field for evaluating the employee.
  * Type: Note
  * Required: Yes
* **Date**: The date when the evaluation was conducted.
  * Type: Date
  * Required: Yes
* **Time**: The time when the evaluation was conducted.
  * Type: Time
  * Required: Yes
* **Phone**: The phone number of the employee (if applicable).
  * Type: Text
  * Required: Yes
* **Select One**: Choose one option from the list.
  * Type: Select One
  * Required: Yes
* **Select Multiple**: Choose multiple options from the list.
  * Type: Select Multiple
  * Required: Yes
* **Decimal Places**: A numeric field for inputting a value.
  * Type: Number
  * Required: Yes
* **Integer Values**: Select one or multiple options from the list.
  * Type: Select Multiple
  * Required: Yes
* **Note**: A free-text field for adding comments (optional).
  * Type: Note
  * Required: No
* **Text Input Field**: A free-text field for inputting a value (optional).
  * Type: Text
  * Required: No
