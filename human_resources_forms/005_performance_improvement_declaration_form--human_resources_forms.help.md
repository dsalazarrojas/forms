# performance_improvement_declaration_form - Help Guide
## Purpose
The performance improvement declaration form is a tool used to document and track employee performance improvement plans, allowing for data-driven decision-making and targeted support.

## How To Complete This Form
To complete this form, follow these steps:

1. Choose the issue type that best describes the problem you're facing.
2. Provide a clear and concise description of the issue.
3. Select the specific areas for improvement (improvement goals).
4. Outline the action plans you plan to take to address the issue.
5. Indicate the start and end dates of the issue, if applicable.
6. Enter the date the issue was closed, if applicable.

## Field-by-Field Explanation
- **issue type** (`issue type`, `select_one`): Choose the type of issue you're facing. This will help management understand the context and provide targeted support.
- **issue description** (`issue description`, `text`): Provide a clear and concise description of the issue, including any relevant details.
- **improvement goals** (`improvement goals`, `select_multiple`): Select the specific areas where you'd like to see improvement.
- **action plans** (`action plans`, `text`): Outline the steps you'll take to address the issue and achieve the improvement goals.
- **issue date start** (`issue date start`, `date`): Enter the date the issue started, if applicable.
- **issue date end** (`issue date end`, `date`): Enter the date the issue ended, if applicable.
- **issue date closed** (`issue date closed`, `date`): Enter the date the issue was closed, if applicable.

## Tips
- Be as specific as possible when describing the issue and its impact.
- Clearly outline the action plans to ensure understanding and tracking of progress.
- Enter dates accurately, if applicable.
- If you're unsure about any field, please ask your manager or HR representative for guidance.
