# Employee Exit Offboarding Form - Help Guide
## Purpose
This form is used to document the reasons for an employee's departure from the company, gather contact information, and collect details about the exit process.

## How To Complete This Form
To complete this form, follow these steps:

* Fill out the employee information sections (Employee Name, Employee Email, Job Title, and Manager Name and Email) with the departing employee's details.
* Select a reason for the employee's departure from the options provided (if applicable).
* Enter the last day of work and exit interview date and time.
* Provide any comments or feedback from the exit interview in the Exit Comments and Manager Comments sections.

## Field-by-Field Explanation
* **What is the reason for the employee's departure?** (`employee_departing_reason`, text, not required)
	+ This field allows the employee to provide a brief explanation for their reason for leaving the company.
* **Employee Name** (`employee_name`, text, not required)
	+ This field is for the employee's name.
* **Employee Email** (`employee_email`, email, not required)
	+ This field is for the employee's email address.
* **Job Title** (`employee_job_title`, text, not required)
	+ This field is for the employee's job title.
* **Manager Name** (`manager_name`, text, not required)
	+ This field is for the manager's name.
* **Manager Email** (`manager_email`, email, not required)
	+ This field is for the manager's email address.
* **Last Day of Work** (`last_day_of_work`, date, not required)
	+ This field is for the employee's last day of work.
* **Exit Interview Date** (`exit_interview_date`, date, not required)
	+ This field is for the date of the exit interview.
* **Exit Interview Time** (`exit_interview_time`, time, not required)
	+ This field is for the time of the exit interview.
* **Exit Comments** (`exit_comments`, text, not required)
	+ This field is for any comments or feedback from the exit interview.
* **Manager Comments** (`manager_comments`, text, not required)
	+ This field is for any comments or feedback from the manager.

## Tips
* Ensure that you have the necessary permissions and approvals before sharing this form with anyone outside the company.
* Review the form carefully before submission to ensure accuracy and completeness.
* Use this form as a template to create a positive and respectful offboarding process.
