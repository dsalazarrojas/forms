# tco_holiday_request - Help Guide
## Purpose
The "tco_holiday_request" form is used to manage employee holiday requests. It captures essential information to process and approve or deny these requests.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the "Requester ID" field with the ID of the employee submitting the request.
2. Enter the start and end dates of the absence in the "Dates of Absence Start" and "Dates of Absence End" fields, respectively.
3. Choose the duration of the absence in the "Duration" field.
4. Select "Yes" or "No" in the "Reason for Request" field, indicating the reason for the request.
5. Select "Active", "Inactive", or "Pending" in the "Approval Status" field, indicating the current status of the request.
6. Select "Yes", "No", or multiple options for "Approval Status Options", specifying the approval status.
7. Enter any additional details in the "Description" field.
8. Indicate if the request is "Yes" or "No" for "Assigned To".
9. Select "Yes", "No" or multiple options for "Assigned To Options", specifying the assignment status.
10. Choose "Yes", "No" or multiple options for "Submitted" and "Submitted By" fields, indicating the submitted status and who submitted it.
11. Select "Yes" or "No" for "Assigned Tool" and "Assigned Tool Options", indicating if a tool is assigned.
12. Enter the date and time of submission in the "Submitted On" and "Submitted At" fields.

## Field-by-Field Explanation
- **Requester ID** (required): Enter the ID of the employee submitting the request.
- **Dates of Absence Start** (optional): Enter the start date of the absence in the format MM/DD/YY.
- **Dates of Absence End** (optional): Enter the end date of the absence in the format MM/DD/YY.
- **Duration** (required): Choose the duration of the absence in days.
- **Reason for Request** (required): Select "Yes" or "No" for the reason for the request.
- **Approval Status** (required): Select "Active", "Inactive", or "Pending" for the approval status.
- **Approval Status Options** (required): Select "Yes", "No", or multiple options for the approval status.
- **Description** (optional): Enter any additional details.
- **Assigned To** (required): Indicate if the request is assigned to "Yes" or "No".
- **Assigned To Options** (required): Select "Yes", "No" or multiple options for the assignment status.
- **Submitted** (required): Choose "Yes" or "No" for the submitted status.
- **Submitted By** (required): Select "Yes" or "No" for who submitted it.
- **Assigned Tool** (required): Indicate if a tool is assigned "Yes" or "No".
- **Assigned Tool Options** (required): Select "Yes", "No", or multiple options for the assignment status.
- **Submitted On** (required): Enter the date of submission in the format MM/DD/YY.
- **Submitted On Range** (required): Enter the range of days the request was submitted.
- **Created On** (required): Enter the date the request was created.
- **Updated On** (required): Enter the date the request was last updated.
- **Submitted At** (required): Enter the time of submission.
- **Updated At** (required): Enter the time the request was last updated.

Note: The fields marked as "required" must be filled out before submitting the form.
