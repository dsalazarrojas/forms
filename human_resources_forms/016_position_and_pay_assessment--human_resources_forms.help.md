# position_and_pay_assessment - Help Guide
## Purpose
The position and pay assessment form is designed to collect data on employee performance, compensation, and other relevant factors. This information helps in creating a comprehensive evaluation of the employee's standing and provides a structured approach to assessing their position and pay.

## How To Complete This Form
To complete this form, follow these steps:

* Fill in the employee's details in the "Employee Details" field.
* Select the employee's compensation status in the "Compensation" field.
* Evaluate the employee's performance using the options provided in the "Performance Rating" field.
* Choose the job performance rating that best describes the employee's performance in the "Job Performance Rating" field.
* Select the scale for the job performance rating in the "Job Performance Rating Scale" field.
* Indicate the employee's salary frequency in the "Salary Frequency" field.
* Select the scale for the salary frequency in the "Salary Frequency Scale" field.
* Indicate whether the employee receives a promotion in the "Pay Frequency" field.
* Select the promotion frequency scale in the "Promotion Frequency" field.
* Select the position rating that best describes the employee's standing in the "Position Rating" field.

## Field-by-Field Explanation
* **Employee Details**: This field collects the employee's details, including their name, job title, and other relevant information.
* **Compensation**: Select "Yes" if the employee is currently compensated and "No" if they are not.
* **Performance Rating**: Evaluate the employee's performance using the options "Good", "Fair", or "Needs Improvement".
* **Job Performance Rating**: Choose the job performance rating that best describes the employee's performance.
* **Job Performance Rating Scale**: Select the scale that best describes the employee's performance.
* **Salary Frequency**: Indicate whether the employee receives a salary.
* **Salary Frequency Scale**: Select the scale for the salary frequency.
* **Pay Frequency**: Indicate whether the employee receives a pay.
* **Promotion Frequency**: Indicate whether the employee receives a promotion.
* **Promotion Frequency Scale**: Select the scale for the promotion frequency.
* **Position Rating**: Select the position rating that best describes the employee's standing in the organization.
* **Position Rating Scale**: Currently not applicable as this field is not defined in the YAML.
