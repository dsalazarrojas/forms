# performance_improvement_notice - Help Guide
## Purpose
This form is used to document and track performance improvement notices sent to employees, ensuring that the follow-up process is properly managed.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the employee's ID and name.
2. Select the department and the expected outcome.
3. Provide the concern description and expected outcome.
4. Enter the employee's comments and manager's comments.
5. Select the manager's signoff and employee's signoff.
6. Enter the manager's name, email, and phone number.
7. Set the date sent and the follow-up date.
8. Select the follow-up status and comments.
9. Select the performance improvement status.

## Field-by-Field Explanation

* **Employee ID** (`employee_id`, number, required): Enter the employee's ID number.
* **Name** (`name`, text, required): Enter the employee's name.
* **Department** (`department`, select_one, required): Select the department the employee belongs to.
* **Date Last Review** (`date_last_review`, date, required): Enter the date of the last review.
* **Date Next Review** (`date_next_review`, date, required): Enter the date of the next review.
* **Concern Description** (`concern_description`, note, required): Describe the concern or issue.
* **Expected Outcome** (`expected_outcome`, select_multiple, required): Select the expected outcome of the performance improvement process.
* **Employee Comments** (`employee_comments`, text, required): Enter the employee's comments.
* **Manager Comments** (`manager_comments`, text, required): Enter the manager's comments.
* **Manager Signoff** (`manager_signoff`, select_one, required): Select the manager's signoff status.
* **Employee Signoff** (`employee_signoff`, select_multiple, required): Select the employee's signoff status.
* **Manager Name** (`manager_name`, text, required): Enter the manager's name.
* **Manager Email** (`manager_email`, email, required): Enter the manager's email address.
* **Manager Phone** (`manager_phone`, text, required): Enter the manager's phone number.
* **Date Sent** (`date_sent`, date, required): Enter the date the notice was sent.
* **Sent By** (`sent_by`, text, required): Identify who sent the notice.
* **Performance Rating** (`performance_rating`, number, required): Enter the performance rating.
* **Action Plan** (`action_plan`, text, required): Enter the action plan to improve employee performance.
* **Follow Up Date** (`follow_up_date`, date, required): Enter the follow-up date.
* **Follow Up By** (`follow_up_by`, text, required): Identify who will follow up with the employee.
* **Follow Up Comments** (`follow_up_comments`, text, required): Enter the follow-up comments.
* **Follow Up Status** (`follow_up_status`, select_one, required): Select the follow-up status.
* **Follow Up Comments** (`follow_up_comments`, text, required): Enter the follow-up comments.
* **Performance Improvement Status** (`performance_improvement_status`, select_one, required): Select the performance improvement status.
