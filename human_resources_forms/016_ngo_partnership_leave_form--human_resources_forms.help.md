# NGO Partnership Leave Form - Help Guide
## Purpose
The NGO Partnership Leave Form is a tool for NGOs to manage leave requests from employees and their partners. It helps in keeping a record of leave requests, approvals, and related notes, ensuring a smooth and efficient process.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the employee request section with your name and date.
2. Select the type of leave you are requesting (full-time, part-time, flexible, or vacation).
3. Choose the frequency of your leave (once, bi-weekly, monthly).
4. Enter the start and end dates of your leave.
5. Add any relevant comments or notes.

## Field-by-Field Explanation

* **Employee Request** (employee_request, text, required)
	+ This field is for the employee to input their name and date.
* **Start Date/Time** (leave_start_date_time, date, required)
	+ This field is for the employee to input the start date and time of their leave.
* **End Date/Time** (end_date, date, required)
	+ This field is for the employee to input the end date and time of their leave.
* **Partner Name** (partner_name, text, required)
	+ This field is for the employee's partner to input their name.
* **Partner Email** (partner_email, email, required)
	+ This field is for the employee's partner to input their email address.
* **Partner Phone** (partner_phone, text, required)
	+ This field is for the employee's partner to input their phone number.
* **Leave Start Time** (leave_start_time, time, required)
	+ This field is for the employee to input the start time of their leave.
* **Leave End Time** (leave_end_time, time, required)
	+ This field is for the employee to input the end time of their leave.
* **Leave Days Off** (leave_days_off, text, required)
	+ This field is for the employee to input the number of days they will be taking off.
* **Return To Work Date** (return_to_work_date, date, required)
	+ This field is for the employee to input the date they will return to work.
* **Reason For Leave** (reason_for_leave, text, required)
	+ This field is for the employee to input the reason for their leave.
* **Manager Approval** (manager_approval, select_one, required)
	+ This field is for the manager to select their approval status (approved, declined, pending).
* **Employee Approval** (employee_approval, select_multiple, required)
	+ This field is for the employee to select their approval status (approved, declined, pending).
* **Leave Status** (leave_status, select_one, required)
	+ This field is for the manager to select the leave status (approved, declined, pending).
* **Partner Comment** (partner_comment, text, required)
	+ This field is for the partner to input any comments regarding the leave request.
* **Manager Comment** (manager_comment, text, required)
	+ This field is for the manager to input any comments regarding the leave request.
* **HR Approval** (hr_approval, select_one, required)
	+ This field is for HR to select their approval status (approved, declined, pending).
* **Notes** (notes, text, required)
	+ This field is for the employee to input any additional notes regarding the leave request.
* **Partner Notes** (partner_notes, text, required)
	+ This field is for the partner to input any additional notes regarding the leave request.
* **Manager Notes** (manager_notes, text, required)
	+ This field is for the manager to input any additional notes regarding the leave request.
* **Leave Request Type** (leave_request_type, select_one, required)
	+ This field is for the employee to select the type of leave they are requesting (full-time, part-time, flexible, vacation).
* **Leave Request Frequency** (leave_request_frequency, select_multiple, required)
	+ This field is for the employee to select the frequency of their leave (once, bi-weekly, monthly).
* **Frequency Count** (frequency_count, number, required)
	+ This field is for the employee to input the number of times they are requesting leave in the selected frequency.
* **Leave Start Date/Time** (leave_start_date_time, date, required)
	+ This field is for the employee to input the start date and time of their leave.

## Tips
* Make sure to fill out all required fields accurately and completely.
* Double-check the leave request details before submitting the form.
* Ensure that the leave request is approved by the necessary parties before taking leave.
* Keep notes and comments concise and clear for easy reference.
