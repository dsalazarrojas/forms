# Talent Acquisition Report Form - Help Guide
## Purpose
The Talent Acquisition Report Form is designed to collect information on the talent acquisition process for a company. This includes whether a candidate was acquired, the hiring process, candidate information, and other relevant details.

## How To Complete This Form
1. Review the form sections and determine which questions are relevant to your specific situation.
2. Answer each question in the relevant section, selecting the correct option or entering relevant information.
3. Ensure that you have completed all required fields before submitting the form.

## Field-by-Field Explanation

* **Candidate Information** (`candidate_information`, select_one, not required): This field is a dropdown menu with options "Yes" or "No". Select "Yes" if a candidate was acquired, "No" otherwise.
* **Hiring Process** (`hiring_processes`, select_multiple, not required): This field is a dropdown menu with options "Yes" or "No". Select all options that apply to the hiring process.
* **Candidate Resume** (`candidate_resume`, note, not required): This field is a free-text field where you can enter any additional information about the candidate's resume.
* **Candidate Skills** (`candidate_skills`, text, not required): This field is for entering the skills of the candidate. You can enter a single skill or a list of skills separated by commas.
* **Interview Date** (`interview_date`, date, not required): This field is for entering the date of the interview with the candidate. Format the date as "YYYY-MM-DD" or according to your organization's date format.
* **Job Title** (`job_title`, select_multiple, not required): This field is a dropdown menu with options "Yes" or "No". Select all job titles that apply to the candidate.
* **Job Type** (`job_type`, select_one, not required): This field is a dropdown menu with options "Yes" or "No". Select the type of job that applies to the candidate.
* **Job Level** (`job_level`, select_multiple, not required): This field is a dropdown menu with options "High" or "Low". Select all job levels that apply to the candidate.
* **Job Category** (`job_category`, select_one, not required): This field is a dropdown menu with options "Yes" or "No". Select the job category that applies to the candidate.
* **Interviewers** (`interviewers`, select_multiple, not required): This field is a dropdown menu with options "Yes" or "No". Select all interviewers involved in the hiring process.
* **Hiring Manager** (`hiring_manager`, select_one, not required): This field is a dropdown menu with options "Yes" or "No". Select the hiring manager involved in the hiring process.

## Tips
* Ensure that you are providing accurate and relevant information for each field.
* If you are unsure about any field, please consult with your supervisor or HR representative.
* Complete the form as soon as possible after the hiring process is complete.
