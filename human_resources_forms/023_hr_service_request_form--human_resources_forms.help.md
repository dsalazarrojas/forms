# hr_service_request_form - Help Guide
## Purpose
This form is used to submit a request for HR services to the HR department. Please fill out the form below to submit your request.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the required fields marked as such.
2. Choose the services you are interested in using (if you need more than one).
3. Provide a brief description of your request.
4. Enter your contact information to ensure we can get back to you.
5. Optionally, indicate your location where the services will be used.

## Field-by-Field Explanation
- **Service Request Form** (`service_request_form`, `text`, required/optional): This is the main field where you can describe the services you are requesting.
- **Location** (`service_request_form_location`, `text`, optional): If you are requesting services for a specific location, such as a branch or office, enter it here. If not, you can leave this field blank.
- **Services Needed** (`service_request_form_services_needed`, `select_multiple`, optional): Select the services you are interested in using from the list.
  • HR
  • Payroll
  • Benefits
- **Description** (`service_request_form_description`, `text`, optional): Provide a brief description of your request.
- **Contact Info** (`service_request_form_contact_info`, `text`, optional): Enter your name and contact information so we can get back to you.
- **Email** (`service_request_form_email`, `email`, optional): Enter your email address so we can contact you.
- **Department** (`service_request_form_department`, `text`, optional): If you are requesting services for a specific department, enter it here. If not, you can leave this field blank.

## Tips
* Be as clear and concise as possible when filling out the form.
* If you need services that are not listed, please contact the HR department directly.
* If you are unsure about any field, feel free to ask for assistance.
