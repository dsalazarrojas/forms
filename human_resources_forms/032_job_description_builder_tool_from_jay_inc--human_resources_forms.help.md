# Job Description Builder Tool From Jay Inc - Help Guide

## Purpose
The Job Description Builder Tool is a form designed to help users create a basic job description for various job postings. It's a simple and intuitive tool that allows users to quickly and easily generate a job description tailored to their specific needs.

## How To Complete This Form
To complete this form, please follow these steps:

* Select the "job description" field and enter the main responsibilities and duties of the job.
* Enter the "job title" field with the exact title of the job.
* Choose the "work hours" field by selecting the number of hours you expect the employee to work per week.
* Select the "job category" field by choosing the primary category of the job (e.g., Sales, Marketing, IT, HR, Finance).
* Choose the "job type" field by entering the job type (e.g., full-time, part-time, contract).
* Enter the "job location" field with the exact location where the job is based.
* Select the "job start date" and "job end date" fields if applicable.
* Choose the "job status" field by selecting the status of the job (Active, Inactive, On Hold).
* Optionally, enter the "assigned tool" field with any additional tools or equipment assigned to the job.

## Field-by-Field Explanation
### 1. **Job Description** (text)
* This is the main description of the job. Enter a brief summary of the job's responsibilities and duties.

### 2. **Job Title** (text)
* Enter the exact title of the job. This will be used to identify the job posting.

### 3. **Work Hours** (select)
* Select the number of hours you expect the employee to work per week.

### 4. **Job Category** (select multiple)
* Choose the primary category of the job. Options include:
	+ Sales
	+ Marketing
	+ IT
	+ HR
	+ Finance

### 5. **Job Type** (text)
* Enter the job type. Examples include:
	+ Full-time
	+ Part-time
	+ Contract

### 6. **Job Location** (text)
* Enter the exact location where the job is based.

### 7. **Job Start Date** (date)
* Enter the start date of the job. If the job has no start date, leave this field blank.

### 8. **Job End Date** (date)
* Enter the end date of the job. If the job has no end date, leave this field blank.

### 9. **Job Status** (select)
* Select the status of the job:
	+ Active
	+ Inactive
	+ On Hold

### 10. **Assigned Tool** (text)
* Optionally, enter any additional tools or equipment assigned to the job.
