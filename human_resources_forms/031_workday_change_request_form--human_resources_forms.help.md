# Workday Change Request Form - Help Guide

## Purpose
This form is designed to help employees submit workday-related change requests. It captures relevant information to facilitate efficient processing of these requests.

## How To Complete This Form

1. Fill in the form with the required and optional fields as prompted.
2. Select the relevant options from the "Employee ID" field to identify the requesting employee.
3. Provide the "Start Date" and "End Date" for the request, if applicable.
4. Enter a brief explanation for the "Reason for Request" field.
5. Optionally select the "Workday" and "Status" fields if applicable.
6. You can add comments to the "Comments" field, if needed.
7. Once you've filled out the form, review your submission to ensure all fields have been completed accurately.
8. Submit the form for processing.

## Field-by-Field Explanation

* **Workday Change Request Form Fields**: This field is not a field to fill in, but it's the title of the form, which you cannot fill in.
* **Employee ID**: Select one of the provided Employee IDs to identify the requesting employee.
* **Start Date**: Enter the start date of the request, if applicable. If not provided, it will be left blank.
* **End Date**: Enter the end date of the request, if applicable. If not provided, it will be left blank.
* **Reason for Request**: Provide a brief explanation for the request, describing the purpose and context of the change.
* **Comments**: Add any additional information or comments about the request, if necessary.
* **Workday**: Select the relevant workday from the provided list (Monday, Tuesday, Wednesday, Thursday, Friday, Saturday, Sunday). This helps the team identify the specific workday for the request.
* **Status**: Select the current status of the request (Open, In Progress, Rejected, Approved, Closed). This helps the team track the progress of the request.
* **Workday**: 
  This field is not very clear. If it's meant to indicate the day of the week when the workday starts or ends, it might be better named "Weekday" for clarity. If it's meant to be something else, please clarify the intended meaning of this field to ensure it's used correctly.
* **Status**: 
  This field is meant to track the progress of the request. It's likely used to monitor whether the request is still open, in progress, rejected, approved, or closed. Please ensure you select the most accurate status to reflect the request's current state.
