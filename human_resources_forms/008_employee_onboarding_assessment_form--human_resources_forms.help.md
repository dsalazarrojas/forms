# Employee Onboarding Assessment Form - Help Guide
## Purpose

This form is used to gather information about the onboarding process for new employees. It is designed to help us understand how our onboarding process is functioning and identify areas for improvement.

## How To Complete This Form

To complete this form, please fill out the following information about the new hire:

1. **New Hire Feedback**: Provide a brief description of the new hire's feedback about their onboarding experience.
2. **Onboarding Outcome**: Enter the outcome of the onboarding process for the new hire (e.g., 1, 2, or 3).
3. **New Hire Date**: Enter the date the new hire joined the company.
4. **Training Session**: If applicable, select whether the new hire had a training session during onboarding.
5. **Training Type**: If the new hire had a training session, select the type of training (e.g., in-person, online, or other).
6. **Onboarding Process**: Select which onboarding processes were followed during the new hire's onboarding process.
7. **Feedback Comments**: If you have any additional comments or feedback about the new hire's onboarding experience, please provide them here.
8. **Manager Name**: Enter the name of the new hire's manager.
9. **Email**: Enter the new hire's email address.
10. **Phone**: Enter the new hire's phone number.
11. **New Hire Name**: Enter the full name of the new hire.
12. **Onboarding Status**: Select the current status of the new hire's onboarding progress.
13. **Follow Up Questions**: If you have any follow-up questions about the new hire's onboarding experience, please provide them here.
