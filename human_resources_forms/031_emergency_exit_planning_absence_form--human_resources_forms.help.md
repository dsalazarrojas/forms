# Emergency Exit Planning Absence Form - Help Guide
## Purpose
The Emergency Exit Planning Absence Form is designed to collect information about emergency exit drills. Please use this form to report your emergency exit absence to the company.

## How To Complete This Form
1. Fill in the details of your emergency exit drill, including the location and the time it occurred.
2. Indicate whether you have had an emergency exit drill before or not.
3. Provide details about your emergency contact, including their name, phone number, and email.
4. Add any additional notes if necessary.

## Field-by-Field Explanation

* **emergency_exit_drill (1)**: A number that represents the number of the drill.
	+ Type: number
	+ This field represents the number of the drill you are currently going through.
* **emergency_exit_drill_location (2)**: The location of the drill.
	+ Type: select_one
	+ Choose the correct location where the drill took place.
	+ Options: Emergency Exit A, Emergency Exit B, Emergency Exit C
* **emergency_absence (3)**: A yes/no question indicating if you have been through an emergency exit drill before.
	+ Type: select_multiple
	+ Select yes if you have been through an emergency exit drill before, no otherwise.
* **date_of_absence (4)**: The date of the drill.
	+ Type: date
	+ Enter the date of the drill.
* **start_time_of_drill (5)**: The start time of the drill.
	+ Type: time
	+ Enter the start time of the drill.
* **end_time_of_drill (6)**: The end time of the drill.
	+ Type: time
	+ Enter the end time of the drill.
* **number_of_emergency_exit_drills_completed (7)**: A number that represents the number of drills completed.
	+ Type: number
	+ Enter the number of drills completed.
* **emergency_contact_name (8)**: The name of the emergency contact.
	+ Type: text
	+ Enter the name of the emergency contact.
* **emergency_contact_number (9)**: The phone number of the emergency contact.
	+ Type: text
	+ Enter the phone number of the emergency contact.
* **emergency_contact_email (10)**: The email of the emergency contact.
	+ Type: email
	+ Enter the email of the emergency contact.
* **notes (11)**: Additional notes about the drill.
	+ Type: note
	+ Enter any additional notes if necessary.
* **assigned (12)**: The tool assigned for the drill.
	+ Type: text
	+ Enter the tool assigned for the drill.
* **output_file (13)**: The output file name.
	+ Type: text
	+ Enter the output file name.
