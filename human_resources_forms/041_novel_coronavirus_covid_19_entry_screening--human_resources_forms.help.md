# novel-coronavirus-covid-19-entry-screening - Help Guide

## Purpose
This form is used to screen employees for potential exposure to the novel coronavirus (COVID-19) when they enter the workplace. It helps identify employees who may be at risk of being infected or spreading the virus and to provide necessary support and resources.

## How To Complete This Form
To complete this form, simply fill in the required information as prompted. The form will guide you through each section.

## Field-by-Field Explanation
### Employee ID
* **Employee ID** (`employee_id`, number, required): Enter your employee ID number as it appears on your ID badge or as assigned to you by HR.
### Name
* **Name** (`name`, text, required): Enter your name as it appears on your ID badge or as you would like it to be listed.
### Contact Number
* **Contact Number** (`contact_number`, text, optional): If you would like to provide a contact number (e.g. phone number or email), please enter it here.
### Email Address
* **Email Address** (`email_address`, email, optional): If you have an email address, please enter it here.
### Phone Number
* **Phone Number** (`phone_number`, text, optional): If you have a phone number, please enter it here.
### Date Entered
* **Date Entered** (`date_entered`, date, required): Enter the date you are entering the workplace.
### Symptoms Present
* **Symptoms Present** (`symptoms_present`, select multiple, optional): If you have any COVID-19 symptoms, please select all that apply (e.g. Fever, Cough, etc.).
* Options: 
  + Yes
  + No
### Travel History
* **Travel History** (`travel_history`, text, optional): If you have recently traveled to any high-risk countries or regions, please enter the details here.
### Close Contact
* **Close Contact** (`close_contact`, select one, optional): If you have had close contact with someone who has COVID-19, please select Yes.
* Options: 
  + Yes
  + No
### Exposure Risk
* **Exposure Risk** (`exposure_risk`, select one, optional): If you believe you are at risk of exposure to COVID-19, please select Yes.
* Options: 
  + Yes
  + No
### Health Insurance
* **Health Insurance** (`health_insurance`, select multiple, optional): If you have health insurance that covers COVID-19 testing and treatment, please select Yes.
* Options: 
  + Yes
  + No
### Medical Supplies
* **Medical Supplies** (`medical_supplies`, select multiple, optional): If you have access to medical supplies such as masks, gloves, etc., please select Yes.
* Options: 
  + Yes
  + No
### Symptoms Present List
* **Symptoms Present List** (`symptoms_present_list`, select multiple, optional): If you have any of the following symptoms, please select all that apply: 
  + Fever
  + Cough
  + Shortness of breath or difficulty breathing
  + Chest pain or discomfort
  + Muscle or body aches
  + Headache
  + Sore throat
  + Runny nose or stuffy nose
  + Diarrhea
  + Nausea or vomiting
  + Fatigue
  + Loss of taste or smell
  + Loss of appetite
  + Confusion or difficulty concentrating
  + Sore throat
  + Muscle or joint pain
  + Skin rash
  + Conjunctivitis (pink eye)
  + Eye redness
  + New loss of speech or ability to swallow
  + New loss of ability to move
  + New loss of ability to understand
  + Severe illness
  + Other (please specify)
* Options: 
  + Yes
  + No
### Medical Condition
* **Medical Condition** (`medical_condition`, text, optional): If you have any pre-existing medical conditions, please enter the details here.
### Follow-up Plan
* **Follow-up Plan** (`follow_up_plan`, select multiple, optional): If you would like to schedule a follow-up appointment or test, please select Yes.
* Options: 
  + Yes
  + No
