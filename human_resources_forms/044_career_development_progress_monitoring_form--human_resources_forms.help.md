# Career Development Progress Monitoring Form - Help Guide
## Purpose
This form is designed to help managers monitor and track the progress of employees in their career development programs. It should be used during regular check-ins with employees to discuss their performance and set new goals for the next review period.

## How To Complete This Form
1. Enter the employee's name in the "Employee name" field.
2. Set the start and end dates of the monitoring period using the "Review period start" and "Review period end" fields, respectively.
3. List the goals set for this period in the "Goals set during period" field.
4. Provide a brief summary of the progress achieved in the "Progress summary" field.
5. If applicable, enter quantitative outcomes in the "Metrics and results" field.
6. Add any manager comments and next steps in the "Manager comments" field.
7. (Optional) Schedule the next review date in the "Next review date" field.
8. (Optional) Identify any additional support or resources needed by the employee in the "Additional support required" field.

## Field-by-Field Explanation
* **Employee name** (`employee_name`, required): Enter the name of the employee being monitored.
* **Review period start** (`review_period_start`, required): Enter the start date of the monitoring period.
* **Review period end** (`review_period_end`, required): Enter the end date of the monitoring period.
* **Goals set during period** (`goals_set`, required): List the specific goals set for this monitoring period.
* **Progress summary** (`progress_summary`, required): Provide a brief description of the progress achieved during this period.
* **Metrics and results** (`metrics_and_results`, optional): If applicable, enter quantitative outcomes or metrics that demonstrate progress.
* **Manager comments** (`manager_comments`, optional): Enter manager feedback and next steps or any other relevant comments.
* **Next review date** (`next_review_date`, optional): (If this is a recurring review) Enter the date of the next review.
* **Additional support required** (`additional_support_required`, optional): Identify any extra resources or support needed by the employee.
