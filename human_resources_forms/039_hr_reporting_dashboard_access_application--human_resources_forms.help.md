# HR Reporting Dashboard Access Application - Help Guide

## Purpose

The HR Reporting Dashboard Access Application is used to manage and track access to HR reporting dashboards for employees and managers. This application enables employees to request access to specific dashboards and their managers to approve or deny these requests.

## How To Complete This Form

To complete this form, follow these steps:

1. Fill out the required fields, marked with an asterisk (*). These fields are necessary to process your request.
2. Select the appropriate options for each field as instructed.
3. Provide any additional comments or notes that may be helpful for the manager to review your request.

## Field-by-Field Explanation

### **Manager Request** (`manager_request`, text, required)
* This field is used to enter a brief description of the request being made.

### **Employee Request** (`employee_request`, text, required)
* This field is used to enter a brief description of the request being made by the employee.

### **Employee ID** (`employee_id`, number, required)
* This field is used to enter the employee's ID number.

### **Manager Name** (`manager_name`, text, required)
* This field is used to enter the name of the manager requesting access.

### **Request Date** (`request_date`, date, required)
* This field is used to enter the date the request was made.

### **Dashboard Name** (`dashboard_name`, select_one, required)
* This field is used to select the specific dashboard being requested access to.

### **Dashboard Access** (`dashboard_access`, select_multiple, required)
* This field is used to select the specific dashboards being requested access to.

### **Comments** (`comments`, text, optional)
* This field is used to enter any additional comments or notes about the request.

### **Manager Comments** (`manager_comments`, text, optional)
* This field is used to enter any additional comments or notes from the manager.

### **Manager Approval** (`manager_approval`, select_one, optional)
* This field is used to select the manager's approval status for the request.

### **Request Status** (`request_status`, select_one, required)
* This field is used to select the current status of the request.

### **Comments Status** (`comments_status`, select_one, optional)
* This field is used to select the current status of the comments.

### **Request Type** (`request_type`, select_multiple, optional)
* This field is used to select the type of request being made.

### **Request Date Range** (`request_date_range`, date, optional)
* This field is used to enter a date range for the request.

### **Manager Request Date** (`manager_request_date`, date, optional)
* This field is used to enter the date the manager's request was made.

### **Employee Comments** (`employee_comments`, text, optional)
* This field is used to enter any additional comments or notes from the employee.

### **Manager Comments** (`manager_comments`, text, optional)
* This field is used to enter any additional comments or notes from the manager.

### **Manager Request Status** (`manager_request_status`, select_one, optional)
* This field is used to select the manager's request status.

### **Request Comments** (`request_comments`, text, optional)
* This field is used to enter any additional comments or notes for the request.

### **Manager Notes** (`manager_notes`, text, optional)
* This field is used to enter any additional notes or information from the manager.

Note: This guide is meant to be a helpful reference for users. If you are unsure about any of the fields, please reach out to the HR department for clarification.
