# Tech Employee Performance Audit Form - Help Guide
## Purpose
The purpose of this form is to help managers evaluate the technical performance of employees and identify areas for improvement.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the tech employee you are evaluating.
2. Fill out the form by answering the questions and selecting options for each field as applicable.
3. Make sure to provide concrete feedback and suggestions for improvement.

## Field-by-Field Explanation

* **Tech Employee Info**: This is where you can enter a brief description of the employee and their job title.
* **Manager Review**: Rate the employee's overall performance as Excellent, Good, Fair, or Poor.
* **Employee Rating**: Rate the employee's overall performance as a number.
* **Feedback**: Provide any feedback or comments on the employee's performance.
* **Tech Skills**: Select all the technical skills the employee has demonstrated proficiency in. (e.g., HTML, CSS, JavaScript, Python)
* **Communication Skills**: Rate the employee's communication skills as Strong, Needs Improvement, or Unsatisfactory.
* **Work Style**: Rate the employee's work style as Collaborative, Independent, or Autocratic.
* **Tech Skills Used**: Select all the technical skills the employee has used for their work. (e.g., HTML, CSS, JavaScript, Python)
* **Additional Comments**: Provide any additional comments or suggestions for improvement.
* **Tech Skills Needed**: Select all the technical skills the employee needs to improve or develop. (e.g., HTML, CSS, JavaScript, Python)
* **Action Item**: Provide a brief description of any action item that needs to be addressed.
* **Action Item Details**: Provide a detailed description of the action item that needs to be addressed.

Please note that fields 1 (Tech Employee Info), 4 (Feedback), 7 (Work Style), 8 (Tech Skills Used), 9 (Additional Comments), and 10 (Tech Skills Needed) are text fields that can be filled out freely. Fields 2, 3, 5, 6, and 12 are select fields that have specific options to choose from.
