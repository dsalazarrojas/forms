# Team Manager Leave Form - Help Guide
## Purpose
The Team Manager Leave Form is designed to allow team managers to request time off for team members in a concise and organized way, facilitating efficient processing of leave requests and reducing administrative burden. This form should be used for all types of team members, but if you are unsure if the form applies to your role or situation, please reach out to your team lead or HR representative for guidance.

## How To Complete This Form
To complete this form, follow these steps:

1. **Start Date**: Enter the start date of the leave period.
2. **End Date**: Enter the end date of the leave period.
3. **Team Member**: Select the team member for whom you are submitting the leave request.
4. **Leave Reason**: Select the reason for the leave (e.g., Vacation, Sick Leave, Medical, or Other).
5. **Start Time** (optional): If applicable, enter the start time of the leave period.
6. **End Time** (optional): If applicable, enter the end time of the leave period.
7. **Duration**: Enter the number of days or hours of the leave period.
8. **Notes**: Add any additional comments or explanations for the leave request.
9. **Manager Approval**: Select "Approve" to approve the leave request, or "Deny" to reject it.
10. **Manager Comments** (optional): Add any comments or explanations for the manager's decision.
11. **Team Lead Approval** (optional): If applicable, select "Approve" to approve the leave request, or "Deny" to reject it.
12. **Team Lead Comments** (optional): If applicable, add any comments or explanations for the team lead's decision.
13. **HR Approval** (optional): If applicable, select "Approve" to approve the leave request, or "Deny" to reject it.
14. **HR Comments** (optional): If applicable, add any comments or explanations for HR's decision.
15. **Submit**: Click the "Submit" button to finalize the leave request.

## Field-by-Field Explanation

* **Start Date**: This field asks you to enter the date when the team member will start their leave.
	+ Type: date
	+ Mandatory: yes
* **End Date**: This field asks you to enter the date when the team member will end their leave.
	+ Type: date
	+ Mandatory: yes
* **Team Member**: This field allows you to select the team member for whom you are submitting the leave request.
	+ Type: select_one
	+ Mandatory: yes
* **Leave Reason**: This field asks you to select the reason for the leave (e.g., Vacation, Sick Leave, Medical, or Other).
	+ Type: select_multiple
	+ Mandatory: yes
* **Start Time** (optional): If applicable, this field asks you to enter the start time of the leave period.
	+ Type: time
	+ Mandatory: no
* **End Time** (optional): If applicable, this field asks you to enter the end time of the leave period.
	+ Type: time
	+ Mandatory: no
* **Duration**: This field asks you to enter the number of days or hours of the leave period.
	+ Type: number
	+ Mandatory: yes
* **Notes**: This field allows you to add any additional comments or explanations for the leave request.
	+ Type: note
	+ Mandatory: no
* **Manager Approval**: This field asks you to approve or deny the leave request.
	+ Type: select_one
	+ Mandatory: yes
* **Manager Comments** (optional): If you approve the leave request, use this field to add any comments or explanations for your decision.
	+ Type: text
	+ Mandatory: no
* **Team Lead Approval** (optional): If applicable, this field asks you to approve or deny the leave request.
	+ Type: select_one
	+ Mandatory: no
* **Team Lead Comments** (optional): If you approve the leave request, use this field to add any comments or explanations for your decision.
	+ Type: text
	+ Mandatory: no
* **HR Approval** (optional): If applicable, this field asks you to approve or deny the leave request.
	+ Type: select_one
	+ Mandatory: no
* **HR Comments** (optional): If you approve the leave request, use this field to add any comments or explanations for your decision.
	+ Type: text
	+ Mandatory: no
* **Submit**: This button submits the leave request.
	+ Type: text
	+ Mandatory: yes
* **Cancel**: This button cancels the leave request.
	+ Type: text
	+ Mandatory: no

Please note that the **Submit** and **Cancel** buttons are not part of the form fields but are used to finalize or cancel the leave request, respectively.
