# HR Communication Request Form - Help Guide
## Purpose
The HR Communication Request Form is a platform for employees to submit requests for HR-related issues, concerns, or questions to their designated HR personnel.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the form with your First Name, Email, and any other relevant information.
2. Clearly describe your question, concern, or issue in the "Question or concern" field.
3. Select the department(s) related to your request.
4. Choose the urgency level of your request (High, Medium, or Low).
5. Select who you would like to receive the response from (Manager, Supervisor, or HR).
6. Set a deadline for the response if required.
7. Optionally, add any additional comments or notes.
8. Submit the form to receive a response from the designated person.

## Field-by-Field Explanation
* **First Name**: Your first name to identify yourself.
* **Email**: Your email address associated with your company account.
* **Question or concern**: Describe your question, concern, or issue in this field.
* **Urgency/Priority**: Select the level of urgency for your request (High, Medium, or Low).
* **Department**: Choose the department(s) related to your request (HR, Operations, Finance, or IT).
* **Date**: Set a date for the response if required.
* **Time**: Set a time for the response if required.
* **Submitted By**: Select who submitted the request (Self, Manager, Supervisor, or HR).
* **Response Required By**: Set a date for the response if required.
* **Response Given**: Set a time for the response if required.
* **Notes**: Add any additional comments or notes for the designated person.
* **Submitted To**: Select who received the request (Manager, Supervisor, or HR).
* **Submitted To Email**: Enter the email address of who received the request.
* **Assigned To**: Select who will be assigned to address the request (Manager, Supervisor, or HR).
* **Assigned To Email**: Enter the email address of who will be assigned to address the request.
* **Comments**: Add any additional comments or notes for the assigned person.
* **Request Form**: Select whether this is a new request or a follow-up question.
* **Submitted By Name**: Select whether you submitted the request as the original submitter or not.
* **Assigned To Name**: Select whether the assigned person will be receiving the request or not.
* **Submitter**: Select whether you are the original submitter or not.
* **Submitted**: Set the date of submission.
* **Assigned**: Set the date of assignment.
* **Response Given**: Set a time for response if required.
* **Response Required**: Set a date for response if required.
* **Status**: Select the status of the request (In Progress, Resolved, Waiting, or Completed).
