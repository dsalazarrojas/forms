# Staff Skills Survey - Help Guide

## Purpose
The "Staff Skills Survey" is designed to help employees gauge their self-assessment of their skills and abilities, specifically in areas like leadership, communication, data analysis, time management, and financial management. This survey aims to provide a comprehensive overview of the staff's strengths and weaknesses, allowing for more informed decisions and training opportunities.

## How To Complete This Form
To complete this form, follow these steps:

* Select the skills you think you possess from the list of options provided for each task.
* You can select multiple skills per task, as each question is a select_multiple type.

## Field-by-Field Explanation

* **What do you think about the following tasks?** (`survey_questions`, text, optional): This is an introductory question to help you focus on the upcoming tasks. Please provide a brief response to the following questions.
* **Leadership and management** (`task1`, select_multiple, optional): This question is about leadership and management skills. Select all that apply from the options:
	+ Leading and managing teams
	+ Project planning and execution
	+ Time and task management
* **Communication** (`task2`, select_multiple, optional): This question is about communication skills. Select all that apply from the options:
	+ Verbal communication
	+ Written communication
	+ Presentation and public speaking
* **Data analysis and interpretation** (`task3`, select_multiple, optional): This question is about data analysis and interpretation skills. Select all that apply from the options:
	+ Data analysis
	+ Data interpretation
	+ Statistical analysis
* **Time management** (`task4`, select_multiple, optional): This question is about time management skills. Select all that apply from the options:
	+ Meeting and deadline management
	+ Time estimation and estimation
	+ Time planning and prioritizing
* **Financial management** (`task5`, select_multiple, optional): This question is about financial management skills. Select all that apply from the options:
	+ Budgeting and forecasting
	+ Financial planning and budgeting
	+ Financial reporting and analysis

## Tips
* Be honest with your self-assessment, as it will help in creating a realistic picture of your skills.
* Select only the skills you are confident about, and leave blank if you are unsure or lack experience.
* Take your time, and review your answers carefully before submitting the form.
