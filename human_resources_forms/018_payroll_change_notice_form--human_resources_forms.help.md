# payroll_change_notice_form - Help Guide
## Purpose
The Payroll Change Notice Form is used to document changes in an employee's job title, salary, and other relevant details. This form appears to be used by employees, managers, or HR personnel to update payroll information.

## How To Complete This Form

1.  Ensure you have access to the correct information and are completing the form with the relevant details.
2.  If you need to document changes in a specific area (e.g., job title or pay frequency), select the correct options in the corresponding fields.
3.  Enter any additional information that may be relevant to the change, such as notes.
4.  Review the form carefully for accuracy and completeness.

## Field-by-Field Explanation

*   **Employee Info (1)** (employee_info, text, required): Enter the employee's name, employee ID, or other identifying information as required.
*   **Job Title (2)** (job_title, select_one, required): Select the new job title of the employee.
*   **Salary (3)** (salary, number, required): Enter the new salary for the employee, if applicable.
*   **Manager Name (4)** (manager_name, text, required): Enter the name of the employee's manager.
*   **Reason (5)** (reason, text, required): Enter a brief explanation of the change.
*   **Effective Date (6)** (effective_date, date, required): Enter the date the change takes effect.
*   **Pay Frequency (7)** (pay_frequency, select_multiple, required): Select how often the employee gets paid (e.g., Weekly, Bi-Weekly, Monthly).
*   **Pay Amount (8)** (pay_amount, number, required): Enter the new pay amount for the employee.
*   **Pay Frequency 2 (9)** (pay_frequency_2, select_multiple, required): Select any additional pay frequencies, if applicable.
*   **Pay Amount 2 (10)** (pay_amount_2, number, required): Enter any additional pay amounts, if applicable.
*   **Manager Email (11)** (manager_email, email, required): Enter the email address of the employee's manager.
*   **Employee Name (12)** (employee_name, text, required): Enter the employee's name.
*   **Department (13)** (department, text, required): Enter the department the employee belongs to.
*   **Manager Phone (14)** (manager_phone, text, required): Enter the phone number of the employee's manager.
*   **Notes (15)** (notes, note, required): Enter any additional notes about the change.
*   **Employee Phone (16)** (employee_phone, text, required): Enter the employee's phone number.
*   **Manager Email 2 (17)** (manager_email_2, text, required): Enter the email address of the second manager, if applicable.
*   **Department 2 (18)** (department_2, text, required): Enter the department the second manager belongs to, if applicable.
*   **Notes 2 (19)** (notes_2, note, required): Enter any additional notes about the change, if applicable.
*   **Notes 3 (20)** (notes_3, note, required): Enter any additional notes about the change, if applicable.
*   **Notes 1 (21)** (notes_1, note, required): Enter any additional notes about the change, if applicable.
*   **Notes 2 (22)** (notes_2, note, required): Enter any additional notes about the change, if applicable.
*   **Notes 3 (23)** (notes_3, note, required): Enter any additional notes about the change, if applicable.
*   **Notes 1 (24)** (notes_1, note, required): Enter any additional notes about the change, if applicable.
*   **Notes 4 (25)** (notes_4, note, required): Enter any additional notes about the change, if applicable.

## Tips

*   Double-check the form for accuracy and completeness before submitting.
*   Ensure all relevant fields are completed with the correct information.
*   If you're unsure about a field, consult the relevant personnel or refer to the form's internal documentation.
*   Enter any additional comments or notes that may be helpful for future reference.
