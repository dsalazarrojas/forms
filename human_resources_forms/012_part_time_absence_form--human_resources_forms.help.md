# Part Time Absence Form - Help Guide
## Purpose
The Part Time Absence Form is used to request part-time absences from work. This form should be completed by the employee to submit a formal request for leave or time off.

## How To Complete This Form
To fill out this form, follow these steps:

1. Select 'Yes' or 'No' for submitting the request.
2. Choose the start date and end date of the absence.
3. Select the reason for the absence from the available options.
4. Enter the start and end time of the absence if applicable.
5. Enter the number of hours and days requested.
6. Select 'Yes' or 'No' for approval status.
7. Optionally, enter a comment or note for the manager's reference.

## Field-by-Field Explanation

- **submit_request** (`submit_request`, select_multiple, required): Select 'Yes' to submit this form for approval.
  
- **start_date** (`start_date`, date, required): Enter the start date of your absence.
  
- **end_date** (`end_date`, date, required): Enter the end date of your absence.
  
- **reason** (`reason`, select_one, required): Select the reason for your absence from the available options.
  
- **leave_start_time** (`leave_start_time`, time, optional): Enter the start time of your absence if it's an irregular time.
  
- **leave_end_time** (`leave_end_time`, time, optional): Enter the end time of your absence if it's an irregular time.
  
- **hours_requested** (`hours_requested`, number, optional): Enter the number of hours you are requesting off.
  
- **days_requested** (`days_requested`, number, optional): Enter the number of days you are requesting off.
  
- **leave_type** (`leave_type`, select_one, required): Select 'Yes' or 'No' for the type of leave.
  
- **approval_status** (`approval_status`, select_one, required): Select 'Active' or 'Inactive' for the approval status.
  
- **manager_comment** (`manager_comment`, note, optional): Enter any additional comments for the manager's reference.
