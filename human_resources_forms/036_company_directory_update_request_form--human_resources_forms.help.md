# Company Directory Update Request Form - Help Guide
## Purpose
This form is used by employees to request an update to their company directory information. It helps ensure that the employee's directory information is up-to-date and accurate.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in your full name and employee ID.
2. Enter your current email address and phone number.
3. Select the types of information that need to be updated (e.g. email address, phone number, job title, etc.).
4. If any of the above information is changing, fill in the new details.
5. Describe any work schedule changes.
6. Enter the name and phone number of your emergency contact person.
7. Select the reason for the update.
8. Select the date when the change should take effect.
9. Select the level of urgency for the update.
10. Select all the systems that need to be updated (e.g. company directory, email signature, phone system, etc.).
11. Select all the people that need to be notified (e.g. your team, department, all staff, etc.).
12. Add any additional comments or instructions.
13. Sign the form electronically and indicate the request date.
14. Have your manager review and approve the request.

## Field-by-Field Explanation
* **Full Name**: First and last name of the employee.
* **Employee ID**: The employee's ID number.
* **Current Email Address**: The email address that currently appears in the directory.
* **Current Phone Number**: The phone number that currently appears in the directory.
* **Department**: The department the employee is part of.
* **Current Job Title**: The employee's current job title.
* **Manager Name**: The name of the employee's direct supervisor.
* **What information needs to be updated?**: Select all the types of information that need to be updated (e.g. email address, phone number, job title, etc.).
* **New Email Address**: If the email needs to be updated, enter the new email.
* **New Phone Number**: If the phone number needs to be updated, enter the new phone number.
* **New Job Title**: If the job title needs to be updated, enter the new job title.
* **New Department**: If the department needs to be updated, enter the new department.
* **New Manager Name**: If the manager name needs to be updated, enter the new manager's name.
* **New Office Location**: If the office location needs to be updated, enter the new office location.
* **New Mailing Address**: If the mailing address needs to be updated, enter the new mailing address.
* **Describe work schedule change**: If the work schedule needs to be updated, describe the change.
* **Emergency Contact Name**: The name of the emergency contact person.
* **Emergency Contact Phone**: The phone number of the emergency contact person.
* **Emergency Contact Relationship**: The relationship of the emergency contact person to the employee.
* **Reason for Update**: Select the reason for the update (e.g. promotion, department transfer, etc.).
* **When should this change take effect?**: Select the date when the change should take effect.
* **How urgent is this update?**: Select the level of urgency (e.g. can wait 1-2 weeks, needed within 1 week, etc.).
* **Which systems should be updated?**: Select all the systems that need to be updated (e.g. company directory, email signature, phone system, etc.).
* **Who should be notified?**: Select all the people that need to be notified (e.g. your team, department, all staff, etc.).
* **Additional comments**: Any additional comments or instructions.
* **Requester Signature**: Electronic signature of the person making the request.
* **Request Date**: The date of the request.
* **Manager Approval**: Approval or denial by the manager.
* **For HR use only**: Note for HR use only.
* **Processed By**: Name of the HR staff member who processed the request.
* **Processed Date**: The date the request was processed.

## Tips
* Make sure to fill in all required fields.
* Be specific when selecting the types of information to be updated.
* If any information is changing, provide the new details.
* If applicable, select all the systems and people that need to be updated.
* Review and approve the form before submitting.
* Have your manager review and approve the form.
* Note any additional comments or instructions.
* Sign the form electronically.
* Keep track of the request date.
