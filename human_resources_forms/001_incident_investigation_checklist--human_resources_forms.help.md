# incident_investigation_checklist - Help Guide
## Purpose
This form is designed to gather information about incidents that require investigation. The purpose of this form is to collect details about incidents, including their type, date, and status. The information collected will help to track and resolve incidents efficiently.

## How To Complete This Form
To complete this form, follow these steps:

* Review the incident details page, which requires a brief description of the incident.
* Select the type of incident from the options provided:
	+ Non-Work Related
	+ Work-Related
* Enter the date the incident occurred, using the format mm/dd/yyyy.
* Choose the investigator responsible for the case:
	+ Manager
	+ HR Representative
	+ Other
* On the witness info page, provide any relevant details about witnesses.
* On the incident status page, select the current status of the incident:
	+ Open
	+ Closed
	+ In Progress
* On the action items page, list any actions that need to be taken.
* On the notes page, enter any additional comments or notes about the incident.

## Field-by-Field Explanation
* **Incident Details** (1, text, required/optional): This field is used to briefly describe the incident. Please provide a concise and accurate summary of what happened.
* **Incident Type** (2, select_one, required/optional): This field allows you to categorize the incident as either Non-Work Related or Work-Related.
* **Incident Date** (3, date, required/optional): Enter the date the incident occurred, using the format mm/dd/yyyy.
* **Investigator** (4, select_one, required/optional): Choose the person responsible for investigating the incident:
	+ Manager
	+ HR Representative
	+ Other
* **Witness Info** (5, text, required/optional): This field is used to provide any relevant details about witnesses.
* **Incident Status** (6, select_multiple, required/optional): Select the current status of the incident:
	+ Open
	+ Closed
	+ In Progress
* **Action Items** (7, text, required/optional): List any actions that need to be taken to resolve the incident.
* **Notes** (8, note, required/optional): Enter any additional comments or notes about the incident.

## Tips
* Make sure to provide accurate and clear information about the incident.
* Double-check your selections and entries for accuracy.
* Use the form to track and resolve incidents efficiently.
