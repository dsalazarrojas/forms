# Back End Developer Interview Form - Help Guide
## Purpose
The Back End Developer Interview Form is used to collect information about potential back-end developers for the hiring process. This form is intended for actual back-end developer interviews and should only be used for this purpose.

## How To Complete This Form
To complete this form, follow these steps:
1. Enter the candidate's name in the `candidate_name` field.
2. Enter the candidate's email address in the `email` field. This is used for scheduling interviews.
3. Enter the candidate's phone number in the `phone` field, if desired.
4. Enter the candidate's years of backend experience in the `years_experience` field.
5. Select all the primary programming languages the candidate is proficient in using the `primary_languages` field.
6. Provide the candidate's database experience in the `databases_experience` field.
7. Leave any additional notes about the system design exercise in the `system_design_exercise` field.
8. Enter a numerical score or pass/fail for the coding challenge in the `coding_challenge_score` field.
9. Add any cultural fit notes about the candidate in the `cultural_fit_notes` field.
10. Select the recommended next step for the candidate in the `interview_outcome` field.

## Field-by-Field Explanation
* **Candidate name (candidate_name, text, required)**: Enter the full name of the candidate.
* **Email address (email, email, required)**: Enter the candidate's email address for scheduling interviews.
* **Phone number (phone, text, optional)**: Enter the candidate's phone number for urgent contact.
* **Years of backend experience (years_experience, number, required)**: Enter the candidate's years of backend experience.
* **Primary programming languages (primary_languages, select_multiple, required)**: Select all the primary programming languages the candidate is proficient in.
* **Database experience (databases_experience, text, optional)**: Enter the candidate's database experience.
* **System design exercise notes (system_design_exercise, note, optional)**: Leave any additional notes about the system design exercise.
* **Coding challenge score (coding_challenge_score, number, optional)**: Enter a numerical score or pass/fail for the coding challenge.
* **Cultural fit notes (cultural_fit_notes, text, optional)**: Add any cultural fit notes about the candidate.
* **Interview outcome (interview_outcome, select_one, required)**: Select the recommended next step for the candidate.
