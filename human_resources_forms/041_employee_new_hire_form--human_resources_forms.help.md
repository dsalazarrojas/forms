# Employee New Hire Form - Help Guide
## Purpose
The Employee New Hire Form is a crucial document that captures essential information about a new hire's details, including their name, job title, job status, department, location, and more. It's essential to fill out this form accurately to ensure that all necessary data is collected.

## How To Complete This Form

1. Review and fill in the new hire's details on each field, using the following sections as a guide.
2. Double-check the form for any required fields that you need to complete.

## Field-by-Field Explanation

* **New Hire Details (1)**:
	+ This is the first section where you'll provide an overview of the new hire.
* **Name (2)**:
	+ Enter the new hire's full name.
* **Job Title (3)**:
	+ Enter the new hire's job title or position.
* **Job Status (4)**:
	+ Select the new hire's job status from the options provided (Active, Inactive, Probationary).
* **Job Category (5)**:
	+ Enter a brief description of the new hire's job category.
* **Department (6)**:
	+ Select the department that the new hire belongs to from the options provided (HR, Operations, Finance).
* **Location (7)**:
	+ Select the location where the new hire will be working (Downtown, Remote, Other).
* **Date of Hire (8)**:
	+ Enter the date the new hire started working.
* **Phone (9)**:
	+ Enter the new hire's contact phone number.
* **Email (10)**:
	+ Enter the new hire's email address.
* **Notes (11)**:
	+ Enter any additional notes or comments about the new hire.
* **Time of Hire (12)**:
	+ Enter the time of day the new hire started working.
* **Job Code (13)**:
	+ Enter a unique job code assigned to the new hire.

## Tips

* Double-check all required fields to ensure accuracy.
* If you're unsure about any field, please consult the relevant department or HR representative.
* Please review the form thoroughly before submitting it to ensure it's complete and accurate.
