# Compassionate Leave Absence Form - Help Guide

## Purpose
<thinking>When an employee or their family member experiences a compassionate leave, they need to provide the necessary details for the leave request to be processed. This form is a standardized way of collecting essential information for HR to evaluate and manage the leave request efficiently. Ensure you fill out the form accurately and provide any supporting documentation as needed.</thinking>

## How To Complete This Form

To complete this form, follow these steps:

1. Fill in your employee information, including your full name, department, and direct supervisor's name.
2. Select the relationship to the person requiring the leave (e.g., Spouse / Domestic Partner, Parent / Guardian, etc.).
3. Enter the leave start and end dates (inclusive).
4. Provide the total number of working days requested for the leave.
5. Briefly describe the reason for the leave request.
6. If needed, provide emergency contact information for while you are away.
7. Confirm that this leave request aligns with the company's compassionate leave policy.
8. Finally, select today's date for the request submission.

## Field-by-Field Explanation

* **Employee Full Name** (1, Text, Required): Enter your full legal name.
* **Department / Team** (3, Text, Required): Your current working department.
* **Reporting Manager** (4, Text, Required): Name of your direct supervisor.
* **Relationship to Subject** (6, Select One, Required): Select the relationship to the person requiring the leave, e.g., Spouse / Domestic Partner, Parent / Guardian, etc.
* **Leave Start Date** (7, Date, Required): First day of absence.
* **Leave End Date** (8, Date, Required): Last day of absence.
* **Total Working Days Requested** (9, Number, Required): Number of scheduled work days missed.
* **Reason for Leave Request** (10, Text, Required): Briefly describe the emergency or circumstance.
* **Emergency Contact Information** (11, Text, Optional): How can we reach you if urgent work issues arise?
* **Policy Acknowledgment** (12, Select One, Required): Confirm that this request aligns with the company's compassionate leave policy.
* **Date of Submission** (13, Date, Required): Select today's date for the request submission.
