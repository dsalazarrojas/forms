# internship_rotation_overview - Help Guide
## Purpose
The internship rotation overview form is designed to collect information about the internship program's progress and achievements.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the rotation dates for the internship program.
2. Choose the departments involved in the internship.
3. Select the supervisors responsible for the internship.
4. Describe the learning goals of the rotation.

## Field-by-Field Explanation
### Rotation Dates
* **Rotation Dates** (`Rotation Dates`, `date`, required: false):
  This field allows you to select the dates for the internship rotation.

### Departments
* **Departments** (`departments`, `select_multiple`, required: false):
  Select the departments involved in the internship program.

### Supervisors
* **Supervisors** (`supervisors`, `select_one`, required: false):
  Choose the supervisor responsible for the internship.

### Learning Goals
* **Learning Goals** (`learning_goals`, `text`, required: false):
  Enter the learning goals for the rotation, describing what you aim to achieve.

## Tips
* Make sure to select the correct departments and supervisors involved in the internship.
* Be clear and concise when describing the learning goals.
* Use specific language when describing the learning goals, so they can be easily understood.
* If you're unsure about any field, you can ask for help or clarification.
