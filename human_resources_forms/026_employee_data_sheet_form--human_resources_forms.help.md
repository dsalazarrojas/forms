# Employee Data Sheet Form - Help Guide
## Purpose
The "Employee Data Sheet Form" is a document used to record and maintain up-to-date information about employees in an organization. This form will help ensure that all essential employee data is accurately collected and stored.

## How To Complete This Form
To complete the form, follow these steps:
1. Ensure you have access to the form and that it is filled out for the intended employee.
2. Fill out the form with the required and optional information.
3. Verify that all fields have been completed accurately and correctly.

## Field-by-Field Explanation

* **Employee Duties** (`employee_duties`, text, optional): This field is used to document an employee's job duties and responsibilities.
* **Contact Address** (`contact_address`, text, optional): This field is used to record an employee's contact address, if applicable.
* **Employee Performance Records** (`employee_performance_records`, text, optional): This field is used to collect any relevant employee performance records, if applicable.
* **Supervisor** (`supervisor_id`, select_one, optional): This field allows you to indicate whether the employee has a supervisor or not. Choose 'Yes' if the employee has a supervisor, 'No' otherwise.
* **Supervisor Name** (`supervisor_name`, text, optional): This field is used to enter the supervisor's name, if applicable.
* **Employee Name** (`employee_name`, text, optional): This field is used to record the employee's name.
* **Job Title** (`employee_job_title`, text, optional): This field is used to document the employee's job title.
* **Reporting Manager** (`reporting_manager_id`, select_one, optional): This field allows you to indicate whether the employee has a reporting manager or not. Choose 'Yes' if the employee has a reporting manager, 'No' otherwise.
* **Reporting Manager Name** (`reporting_manager_name`, text, optional): This field is used to enter the reporting manager's name, if applicable.
* **Department** (`department_id`, select_one, optional): This field allows you to indicate whether the employee is in a department or not. Choose 'Yes' if the employee is in a department, 'No' otherwise.
* **Department (2)** (`department`, text, optional): This field is used to record the department name, if applicable.
* **Job Category** (`job_category`, text, optional): This field is used to document the employee's job category.

## Tips
* Ensure all fields are completed accurately and correctly to prevent errors.
* If a field is not applicable, mark it as 'Not Applicable' or leave it blank.
* Review the form carefully before submitting it to ensure all information is correct.
