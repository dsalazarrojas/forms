# Military Spouse Leave Form - Help Guide
## Purpose
The Military Spouse Leave Form is a standardized form for military personnel to request leave for their spouses. This form is used to provide a clear and concise way to submit leave requests, allowing for efficient processing and review by relevant authorities.

## How To Complete This Form
To complete this form, follow the steps below:

1. Fill out all required fields, indicated by an asterisk (\*) on the form.
2. Provide a brief explanation of the reason for the leave request in the "Reason for Leave" field.
3. Select the relevant deployment status and leave request type from the dropdown menus.
4. Optionally, provide a contact email or phone number for follow-up, but this is not required.

## Field-by-Field Explanation
* **Military Spouse Leave Request**: This is the main section of the form where you will provide a detailed request for leave. Please make sure to include all required information.
* **Military Spouse Name**: Please enter the name of the military spouse requesting the leave.
* **Request Date Start**: Enter the date you would like the leave to start.
* **Request Date End**: Enter the date you would like the leave to end.
* **Reason for Leave**: Provide a brief explanation of the reason for the leave request. This will help the reviewing authorities understand the context of the request.
* **Deployment Status**: Select the relevant deployment status for your spouse from the dropdown menu.
* **Leave Request Type**: Select the type of leave request you are submitting (e.g. Military Leave, Family Leave, Bereavement Leave, etc.).
* **Contact Email**: If you would like to be contacted for follow-up, enter a contact email address.
* **Contact Phone**: If you would like to be contacted for follow-up, enter a contact phone number.
* **Note**: This is an optional field for any additional information or context you would like to provide.
