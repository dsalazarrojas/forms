# IT System Access Offboarding Form - Help Guide

## Purpose
This form is designed to capture essential information for IT system access revocation, ensuring a seamless process.

## How To Complete This Form

1. Please fill out the form accurately and completely.
2. Ensure you have the necessary permissions to access the requested fields.

## Field-by-Field Explanation

* **User Information**: Enter the username of the user whose access you wish to offboard.
* **Employee Id**: Enter the employee ID number associated with the user.
* **Department**: Enter the department the user belongs to, e.g., HR, Marketing, etc.
* **Manager Name**: Enter the name of the user's manager.
* **Manager Email**: Enter the email address of the manager.
* **System Access**: Select 'Active' if the user has current active system access, or 'Inactive' if access has already been revoked.
* **Access Type**: Choose whether the user has 'Admin' access, 'User' access, or 'Read-Only' access.
* **Access Level**: Determine the level of access the user has, either 'Full' or 'Limited'.
* **Access Expiration**: Enter the date on which access should expire (use YYYY-MM-DD format).
* **Manager Phone**: Enter the phone number of the manager.
* **Manager Title**: Enter the title of the manager.
* **System Access Expiration**: Enter the date on which system access should expire (use YYYY-MM-DD format).
* **Reason for Deactivation**: Enter a brief reason for revoking system access.
