# Employee Performance Report Form - Help Guide

## Purpose
The Employee Performance Report Form is a tool used to collect data on employee performance, provide feedback, and track progress over time. It's designed to help managers and employees identify areas of improvement and set goals for growth.

## How To Complete This Form

To complete this form, follow these steps:

1. **Employee Name**: Enter the name of the employee being evaluated.
2. **Job Title**: Enter the title of the employee's job.
3. **Performance Rating**: Select the employee's performance level using the provided options (Excellent, Good, Fair, Poor).
4. **Feedback Date**: Enter the date when feedback was provided to the employee.
5. **Review Start Date**: Enter the start date of the performance review.
6. **Review End Date**: Enter the end date of the performance review.
7. **Employee Rating**: Select the employee's rating (Highly Satisfactory, Unsatisfactory).
8. **Performance Comments**: Enter any comments about the employee's performance.
9. **Action Items**: Select any urgent, important, or less important action items for the employee.
10. **Performance Issues**: Select any true or false statements regarding performance issues.
11. **Evaluation Date**: Enter the date when the evaluation was done.
12. **Performance Frequency**: Select how frequently the employee's performance is evaluated (High, Medium, Low).
13. **Evaluation Period**: Enter the period when the evaluation was done.
14. **Next Evaluation Date**: Enter the date for the next evaluation.

## Tips

* Please ensure that all required fields are completed before submitting the form.
* The performance rating and employee rating are select fields, so choose the most accurate option.
* For performance comments, enter any relevant information about the employee's performance.
* Use the action items field to track any urgent, important, or less important tasks for the employee.
* Select 'True' for performance issues that exist and 'False' for those that don't.
* The evaluation date and next evaluation date fields are for tracking progress and scheduling future evaluations.
* If you're unsure about any field, consult with the employee or the relevant department head.
