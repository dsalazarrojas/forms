# R and R Form - Help Guide

## Purpose
The R and R Form is used to record and track employee achievements and recognition.

## How To Complete This Form
To complete this form, follow the instructions below:

1. Fill out the required fields:
	* R and R Form
	* Achievement Description
	* Awarding Manager Name
	* Awarding Manager Title
	* Manager Title
2. Fill out the optional fields as necessary:
	* Description (briefly describe the reason for the employee's achievement)
	* Approval Date
	* Award Value
	* Award Currency
	* Award Fund
	* Award Fund Amount
	* Award Fund Currency
	* Recognition Date
	* Status
	* Reason for Status
	* Status Date
	* Manager Name
	* Approval Notes

## Field-by-Field Explanation

* **R and R Form** (Text, Optional): A brief title for the form.
* **Description** (Text, Optional): Briefly describe the reason for the employee's achievement.
* **Employee Name** (Text, Required): Enter the name of the employee whose achievement is being recognized.
* **Employee ID** (Number, Optional): Enter the employee's ID number (if applicable).
* **Award Type** (Select One, Optional): Select the type of award or recognition (e.g., Award, Recognition, Both).
* **Reason for Achievement** (Text, Optional): Briefly describe the reason for the employee's achievement.
* **Achievement Description** (Text, Required): A detailed description of the employee's achievement.
* **Employee/Manager Comments** (Text, Optional): Additional comments from the employee or manager.
* **Manager Approvals** (Select Multiple, Optional): Select all managers who approved this R and R.
* **Approval Date** (Date, Optional): The date of approval.
* **Award Value** (Number, Optional): Enter award value in dollars.
* **Award Currency** (Select One, Optional): Choose award currency (e.g., USD).
* **Award Fund** (Select One, Optional): Choose award fund (e.g., Departmental, Company-Wide, None).
* **Award Fund Amount** (Number, Optional): Enter award fund amount.
* **Award Fund Currency** (Select One, Optional): Choose award fund currency.
* **Recognition Date** (Date, Optional): The date of recognition.
* **Awarding Manager** (Text, Required): Enter the name of the manager awarding the recognition.
* **Awarding Manager Title** (Text, Required): Enter the title of the manager awarding the recognition.
* **Manager Title** (Text, Required): Enter manager title.
* **Status** (Select One, Optional): Select status (e.g., Active).
* **Reason for Status** (Text, Optional): Briefly describe reason for status.
* **Status Date** (Date, Optional): The date of status change.
* **Manager Name** (Text, Optional): Enter manager name.
* **Approval Notes** (Text, Optional): Enter approval notes.

## Tips
* Be sure to fill out all required fields before submitting the form.
* Use clear and concise language when filling out the form.
* If you are unsure about a field, ask your HR representative for clarification.
* Review the form for accuracy before submitting it.
