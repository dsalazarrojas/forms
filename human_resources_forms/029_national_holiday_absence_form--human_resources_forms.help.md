# national_holiday_absence_form - Help Guide
## Purpose
This form is designed to request national holiday absences for employees. It is intended for use in a human resources setting to collect information from employees who need to take time off due to national holidays. Please use this form only when you need to request absence for a national holiday, and do not duplicate this request if you have already submitted one in the past.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the form completely, but only if you need to request absence for a national holiday.
2. If you are unsure about a field, refer to the field-by-field explanation below.

## Field-by-Field Explanation

* **request_details** (`request_details`, text, optional): This field is where you can provide any additional details about your absence request, such as the number of days you will be absent or any specific dates you need off.
* **national_holiday** (`national_holiday`, select_one, optional): Select the national holiday you are requesting absence for. Please choose from the list of available holidays.
* **request_date** (`request_date`, date, optional): If you are requesting absence on a specific date, fill in this field with the date you will be absent. If you are unsure, you can leave this field blank.
* **start_date** (`start_date`, date, optional): If you need to start your absence on a specific date, fill in this field with the start date of your absence. If you are unsure, you can leave this field blank.

## Tips
* Make sure to only fill in the necessary fields to ensure your absence request is complete and clear.
* If you are requesting absence for multiple national holidays, please submit a separate form for each holiday.
* If you have already submitted a national holiday absence request, do not duplicate the form. Check your previous requests to see if you need to update or modify an existing one.
