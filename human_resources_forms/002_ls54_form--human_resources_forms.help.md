# LS54 Form - Help Guide
## Purpose
The LS54 Form is used to document and manage employee termination information. It is designed to be filled out by HR personnel and administrators to record details about employee terminations.

## How To Complete This Form
1. Gather all necessary information and documentation before starting to fill out the form.
2. Read through each page and field to ensure you understand what is required.
3. Complete all required fields accurately and completely.
4. Provide as much detail as possible in optional fields.

## Field-by-Field Explanation

* **Employee Name** (`employee_name`, text, required): Please fill out the full name of the employee being terminated.
* **Employer Name** (`employer_name`, text, required): Enter the full name of the employer or company that the employee was working for.
* **Employer Address** (`employer_address`, text, required): Enter the full address of the employer or company that the employee was working for.
* **Labor Law Section** (`labor_law_section`, select_one, optional): Please select the relevant labor law section that applies to the termination. If unsure, select "Other".
* **Employee Type** (`employee_type`, select_multiple, optional): Select all applicable employee types that apply to the termination. For example, if the employee was an Exempt employee, select "Exempt".
* **Employment Status** (`employment_status`, select_one, optional): Please select the employment status of the employee at the time of termination. For example, if the employee was working full-time, select "Full-time".
* **Start Date** (`start_date`, date, optional): Enter the date the employee started working for the employer.
* **End Date** (`end_date`, date, optional): Enter the date the employee terminated or left the company.
* **Reason for Termination** (`reason_for_termination`, select_one, optional): Please select the reason for the employee's termination. For example, "Discharge" if the employee was terminated due to performance issues.
* **Termination Date** (`termination_date`, date, optional): Enter the date the employee was terminated.
* **Termination Reason** (`termination_reason`, text, optional): Provide a brief description of the reason for the termination.
* **Termination Status** (`termination_status`, select_one, optional): Please select the termination status of the employee. For example, "Active" if the termination was voluntary.
* **Termination Cause** (`termination_cause`, text, optional): Provide a brief description of the cause of the termination.
* **Termination Effective Date** (`termination_effective_date`, date, optional): Enter the date the termination took effect.
* **Termination Type** (`termination_type`, select_one, optional): Please select the type of termination. For example, "Voluntary" if the employee chose to leave.
* **Employer ID** (`employer_id`, number, optional): Enter the ID number of the employer or company that the employee was working for.
* **Employee ID** (`employee_id`, number, optional): Enter the ID number of the employee being terminated.
* **Reason for Request** (`reason_for_request`, text, optional): Please provide a brief description of the reason for filling out this form.
* **Request Date** (`request_date`, date, optional): Enter the date this form was submitted or requested.
* **Termination Type** (`termination_termination_type`, select_one, optional): Select the type of termination that occurred. For example, "Voluntary" if the employee left of their own accord.
* **Termination Cause** (`termination_cause`, text, optional): Provide a brief description of the reason for the termination.
*   **Other fields with "Other" as an option**: If a field has "Other" as an option, please select "Other" and describe the specific reason or details in the field provided. This will help in providing more accurate and detailed information about the termination.
 
Please note that some fields may have additional instructions or explanations within the form itself or in the HR manual. Refer to these resources for more information.
