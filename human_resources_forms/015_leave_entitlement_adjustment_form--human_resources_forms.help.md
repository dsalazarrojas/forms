# Leave Entitlement Adjustment Form - Help Guide
## Purpose
The Leave Entitlement Adjustment Form is used by HR personnel to update the leave balance of an employee. This form is used for making adjustments to an employee's leave entitlements, such as adding or subtracting leave balance based on individual circumstances.

## How To Complete This Form
To complete this form, follow these steps:

1. Ensure you have the necessary permissions to access this form.
2. Select the correct Employee ID of the employee whose leave entitlements you want to adjust.
3. Check if the employee is eligible for a leave adjustment by checking their leave type (Yes/No).
4. Enter the start date of the adjustment period if applicable.
5. Enter the end date of the adjustment period if applicable.
6. Enter the change in leave balance (e.g., add or subtract).
7. Provide a reason for the adjustment, if necessary.
8. Enter any comments or explanation for the adjustment.

## Field-by-Field Explanation

* **Employee ID** (`1`, `employee_id`, **Required**): Enter the employee's unique ID number.
* **Leave Type** (`2`, `leave_type`, **Optional**, Yes/No): Check if the employee is eligible for a leave adjustment (Yes) or not (No).
* **Start Date** (`3`, `start_date`, **Optional**, Date): Enter the start date of the adjustment period, if applicable.
* **End Date** (`4`, `end_date`, **Optional**, Date): Enter the end date of the adjustment period, if applicable.
* **Leave Balance** (`5`, `leave_balance`, **Required**, Number): Enter the change in leave balance (e.g., add or subtract).
* **Reason for adjustment** (`6`, `reason_for_adjustment`, **Optional**, Yes/No): Provide a reason for the adjustment, if necessary.
* **Adjustment Amount** (`7`, `adjustment_amount`, **Optional**, Number): Enter the amount of the adjustment (e.g., days).
* **Comments** (`8`, `comments`, **Optional**, Note): Enter any comments or explanation for the adjustment, if necessary.

## Tips
* Make sure to double-check the employee's information before submitting the form.
* Use this form only for valid reasons and avoid duplicating existing adjustments.
* Review the form carefully before submission to ensure accuracy and completeness.
