# work_schedule_change_request_form - Help Guide
## Purpose
The purpose of this form is to request changes to an employee's schedule. It is intended for employees or their authorized representatives to submit requests for changes to their own or someone else's schedule.

## How To Complete This Form
- Click on the "Form Section" page and fill out the requested information in the "Employee Details" field. 
- Enter the "Employee ID" number in the designated field.
- Select the "Department" from the available options.
- Enter the "Job Title" and "Reason for Change" in the designated fields.
- Select the "Start Date" and "End Date" using the provided date picker.
- Enter the "New Schedule Request" in the designated field.
- Select the "Manager Approval" option from the dropdown menu.
- Sign the "Submitter’s Signature" field with your name.

## Field-by-Field Explanation
- **Form Section**: 
  This page serves as the header for the form and contains no actual fields to be filled out.
  It is intended to provide a clear separation between form sections.
- **Employee Details**: 
  Enter the employee's details in this field. This may include their name, job title, department, or other relevant information.
- **Employee ID**: 
  Enter the employee's ID number in this field. This is typically a unique identifier for the employee in the system.
- **Department**: 
  Select the department the employee belongs to from the available options.
- **Job Title**: 
  Enter the employee's job title in this field.
- **Reason for Change**: 
  Enter the reason for the schedule change in this field. This should be a clear and concise explanation of the request.
- **Start Date**: 
  Select the start date of the new schedule using the provided date picker.
- **End Date**: 
  Select the end date of the new schedule using the provided date picker.
- **New Schedule Request**: 
  Enter the new schedule request in this field. This should include any additional details or notes about the request.
- **Manager Approval**: 
  Select the "Manager Approval" option to indicate that the manager has approved or rejected the schedule change.
- **Submitter’s Signature**: 
  Sign this field with your name as the person submitting the request. 

## Tips
- Make sure to enter accurate information to ensure that the request is processed correctly.
- If you are requesting changes for someone else, ensure that you have their authorization to do so.
- Review the company policies and procedures before submitting the request to ensure that it aligns with company guidelines. 
- Ensure that the manager has approved or rejected the request before proceeding with the schedule change.
