# Military Leave Form - Help Guide
## Purpose
The purpose of this form is to collect information from military personnel regarding their military leave. It is used to track and record the details of their leave, including the start and end dates, reason for leave, and other relevant details.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter your User ID in the "User ID" field.
2. Select the "Service Start Date" field and enter the date you are requesting military leave to begin.
3. Select the "Military Leaving Date" field and enter the date you are requesting military leave to end.
4. Answer "Type of Service" questions by selecting the correct options.
   * For Active Duty, select "Yes" if you are currently active duty. For "No" if you are not.
   * For Reserve Duty, select "Yes" if you are currently in reserve duty. For "No" if you are not.
   * For Other, select "Yes" if your type of service is other than active or reserve. For "No" if it is not.
5. Enter the "Military Leaving Reason" field with a brief description of why you are requesting military leave.
6. Select your current "Military Status" by selecting the correct options.
   * For Active, select "Yes" if you are currently active. For "No" if you are not.
   * For Inactive, select "Yes" if you are currently inactive. For "No" if you are not.
7. Select your current "Military Status 1" by selecting the correct options.
   * For Active, select "Yes" if you are currently active. For "No" if you are not.
   * For Inactive, select "Yes" if you are currently inactive. For "No" if you are not.
8. Select your current "Military Status 2" by selecting the correct options.
   * For Reserve, select "Yes" if you are currently in reserve. For "No" if you are not.
9. Select the "Military Return Date" field and enter the date you expect to return from military leave.
10. Answer "Time of Year" questions by selecting the correct options.
   * For each month of the year, select "Yes" if you are taking military leave during that month. For "No" if you are not.

## Field-by-Field Explanation

* **Military Leave Form** (`military_leave_form`, text): This is the title of the form.
* **User ID** (`user_id`, number): Enter your unique User ID.
* **Service Start Date** (`service_start_date`, date): Enter the date you are requesting military leave to begin.
* **Military Leaving Date** (`military_leaving_date`, date): Enter the date you are requesting military leave to end.
* **Type of Service** (`type_of_service`, select_one): Answer the type of service question by selecting "Yes" or "No" for Active Duty, Reserve Duty, or Other.
* **Active Duty** (`type_of_service_1`, select_one): Answer if you are currently in Active Duty. Select "Yes" or "No".
* **Reserve Duty** (`type_of_service_2`, select_one): Answer if you are currently in Reserve Duty. Select "Yes" or "No".
* **Other** (`type_of_service_3`, select_one): Answer if your type of service is other than Active Duty or Reserve Duty. Select "Yes" or "No".
* **Military Leaving Reason** (`military_leaving_reason`, text): Enter a brief description of why you are requesting military leave.
* **Military Status** (`military_status`, select_multiple): Answer the military status question by selecting "Yes" or "No" for Active, Inactive.
* **Active** (`military_status_1`, select_multiple): Answer if you are currently active. Select "Yes" or "No".
* **Reserve** (`military_status_2`, select_multiple): Answer if you are currently in Reserve. Select "Yes" or "No".
* **Inactive** (`military_status_3`, select_multiple): Answer if you are currently inactive. Select "Yes" or "No".
* **Military Return Date** (`military_return_date`, date): Enter the date you expect to return from military leave.
* **Time of Year** (`time_of_year`, select_one): Answer the time of year question by selecting "Yes" or "No" for each month.
