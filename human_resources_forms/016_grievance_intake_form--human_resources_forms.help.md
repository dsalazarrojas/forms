# Grievance Intake Form - Help Guide

## Purpose
The Grievance Intake Form is used to document and track grievances, ensuring a structured approach to managing and resolving complaints and issues.

## How To Complete This Form

To complete this form, follow these steps:

1. Enter the description of the grievance in the **description** field.
2. Provide more details about the grievance in the **details** field.
3. Choose the **category** that best fits the grievance.
4. Select the **subcategory** that is most relevant to the grievance.
5. Indicate the priority level of the grievance by selecting **High**, **Medium**, or **Low**.
6. Choose the current **status** of the grievance from **In Progress**, **Resolved**, or **Closed**.
7. Enter any additional **notes** about the grievance.
8. If applicable, provide a **resolution** for the grievance.
9. Check the **closed** box if the grievance has been resolved.

## Field-by-Field Explanation

- **grievance_intake** (`text`, required/optional): Enter a brief description of the grievance.
  - This field is used to briefly summarize the issue or problem being reported.

- **description** (`text`, required/optional): Provide a more detailed explanation of the grievance.
  - This field helps to gather more comprehensive information about the issue.

- **details** (`text`, required/optional): Enter any additional information about the grievance.
  - This field can be used to capture specific details that are not included in the description.

- **category** (`select_one`, required/optional): Choose the most relevant category for the grievance.
  - This selection helps to categorize grievances for better management and tracking.

- **subcategory** (`select_multiple`, required/optional): Select all subcategories that apply to the grievance.
  - This field allows you to select multiple subcategories that are relevant to the issue at hand.

- **priority** (`select_one`, required/optional): Indicate the priority level of the grievance.
  - This helps to prioritize the issues based on their severity or urgency.

- **status** (`select_multiple`, required/optional): Select the current status of the grievance.
  - This field reflects whether the issue is still active, resolved, or closed.

- **notes** (`text`, required/optional): Enter any additional comments or information about the grievance.
  - Use this field to store any relevant notes or comments about the issue.

- **resolution** (`text`, required/optional): If the grievance has been resolved, provide a brief summary of the resolution.
  - This field is used to document the resolution or outcome of the grievance.

- **closed** (`select_one`, required/optional): Check this box if the grievance has been resolved.
  - This field indicates whether the issue has been fully addressed or not.
