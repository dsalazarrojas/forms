# Employee Discussion Record Form - Help Guide
## Purpose
The Employee Discussion Record Form is used to document and track discussions between managers and employees. This form helps to improve employee performance, address issues, and provide a clear record of actions taken.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the employee's name in the **employee_name** field.
2. Select the date of the discussion in the **discussion_date** field.
3. Choose the time of the discussion in the **discussion_time** field.
4. Describe the discussion subject in the **discussion_subject** field.
5. Provide notes about the discussion in the **discussion_notes** field.
6. Record the conclusion of the discussion in the **discussion_conclusion** field.
7. Specify any performance improvement actions taken in the **performance_improvement_actions** field.
8. Choose the status of the discussion in the **discussion_status** field.
9. Set a follow-up date in the **follow_up_date** field.
10. Choose the follow-up time in the **follow_up_time** field.
11. Provide the follow-up status in the **follow_up_status** field.
12. Enter any follow-up notes in the **follow_up_notes** field.
13. Summarize the follow-up conclusion in the **follow_up_conclusion** field.
14. Record any follow-up actions taken in the **follow_up_actions** field.
15. Describe the follow-up outcome in the **follow_up_outcome** field.
16. Enter any follow-up comments in the **follow_up_comment** field.
17. Specify the next steps in the **follow_up_next_steps** field.
18. Select the form completion status in the **form_completion_status** field.
19. Enter the last updated by in the **follow_up_last_updated_by** field.

## Field-by-Field Explanation
- **employee_name**: Enter the employee's name who was involved in the discussion.
  * Required: No
  * Type: Text
- **discussion_date**: Enter the date of the discussion.
  * Required: No
  * Type: Date
- **discussion_time**: Choose the time of the discussion.
  * Required: No
  * Type: Time
- **discussion_subject**: Describe the subject of the discussion.
  * Required: No
  * Type: Text
- **discussion_notes**: Provide notes about the discussion.
  * Required: No
  * Type: Text
- **discussion_conclusion**: Record the conclusion of the discussion.
  * Required: No
  * Type: Text
- **performance_improvement_actions**: Specify any performance improvement actions taken.
  * Required: No
  * Type: Text
- **discussion_status**: Choose the status of the discussion.
  * Required: No
  * Type: Select One
  * Options: Open, Closed, In Progress
- **follow_up_date**: Set a follow-up date.
  * Required: No
  * Type: Date
- **follow_up_time**: Choose the follow-up time.
  * Required: No
  * Type: Time
- **follow_up_status**: Specify the status of the follow-up.
  * Required: No
  * Type: Text
- **follow_up_notes**: Enter any follow-up notes.
  * Required: No
  * Type: Text
- **follow_up_conclusion**: Summarize the follow-up conclusion.
  * Required: No
  * Type: Text
- **follow_up_actions**: Record any follow-up actions taken.
  * Required: No
  * Type: Text
- **follow_up_outcome**: Describe the outcome of the follow-up.
  * Required: No
  * Type: Text
- **follow_up_comment**: Enter any follow-up comments.
  * Required: No
  * Type: Text
- **follow_up_next_steps**: Specify the next steps.
  * Required: No
  * Type: Text
- **form_completion_status**: Select the form completion status.
  * Required: No
  * Type: Select Multiple
  * Options: Completed, Incomplete, Pending
- **follow_up_last_updated_by**: Enter the last updated by.
  * Required: No
  * Type: Text
