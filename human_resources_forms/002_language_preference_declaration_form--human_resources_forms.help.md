# language_preference_declaration_form - Help Guide
## Purpose
This form is designed to collect information about language preferences from employees or applicants. It will help us understand individual preferences for languages they can understand, communicate, and work in, and to determine if they need translation support.

## How To Complete This Form
To complete this form, follow the instructions below:

1. Please select your answer for each question by choosing one of the provided options.
2. If a question is not applicable to you, you can simply leave it blank.
3. If you have any additional comments or concerns regarding language support, please use the "assigned_tool" field to provide more information.

## Field-by-Field Explanation

* **language_preference** (`language_preference`, `select_one`, not required): This field asks whether you prefer to communicate in a specific language. Please select "Yes" if you can understand, read, and communicate in the selected language.
* **primary_language** (`primary_language`, `select_multiple`, not required): This field asks which language you are most proficient in. Please select all languages you are proficient in, as it will help us understand your language capabilities.
* **communication_preferences** (`communication_preferences`, `select_multiple`, not required): This field asks about your preferences for communication in different languages. Please select all languages you prefer for communication.
* **translation_needs** (`translation_needs`, `select_one`, not required): This field asks whether you need translation support for certain languages. Please select "Yes" if you need translation support for any language.
* **assigned_tool** (`assigned_tool`, `text`, not required): This field is for any additional comments or concerns you may have regarding language support. If you have any specific requests or requirements, please describe them here.
* **output_file** (`output_file`, `text`, not required): This field is for any additional information you'd like to provide, such as your language proficiency levels or certifications.

## Tips
- Please be as accurate and honest as possible when answering these questions, as they will help us better serve you and our diverse workforce.
- If you have any questions or concerns, please don't hesitate to reach out to us.
- If you have any additional resources or tools that would help support language diversity, please let us know.
- Thank you for taking the time to complete this form!
