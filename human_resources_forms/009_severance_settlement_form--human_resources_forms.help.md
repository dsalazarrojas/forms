# Severance Settlement Form - Help Guide
## Purpose
The Severance Settlement Form is used to document an employee's severance package details, including their name, reason for departure, dates, and payment terms. This helps ensure accurate and efficient processing of severance settlements.

## How To Complete This Form

1.  Ensure you have all necessary information before starting.
2.  Fill out the form carefully, following the guidelines below.

## Field-by-Field Explanation

*   **Severance Settlement Form** (`severance_settlement_form`, text, required): This is the form header, indicating you're filling out the Severance Settlement Form.
*   **Employee Name** (`employee_name`, text, required): Enter the name of the employee whose severance settlement details you're documenting.
*   **Reason for Departure** (`reason_for_departure`, text, required): Describe the reason for the employee's departure.
*   **Out Date** (`out_date`, date, required): Enter the date the employee's employment ended.
*   **Notice Period** (`notice_period`, number, required): Specify the number of days or weeks the employee received notice before leaving.
*   **Benefits** (`benefits`, select\_multiple, required): Select the benefits the employee is entitled to as part of their severance package from the provided options (COBRA, COBRA+1, COBRA+2).
*   **Separation Packages** (`separation_packages`, select\_one, required): Choose the specific severance package the employee is receiving from the provided options (Severance Package A, Severance Package B, Severance Package C).
*   **Termination Date** (`termination_date`, date, required): Enter the date the employee's employment ended.
*   **Reason** (`reason`, text, required): Briefly explain the reason for the employee's termination.
*   **Employee Number** (`employee_number`, number, required): Enter the employee's ID number.
*   **Out Time** (`out_time`, time, required): Specify the time of the employee's out-date.
*   **Payment Terms** (`payment_terms`, select\_one, required): Choose how the payment will be made from the provided options (Cash, Check, Wire Transfer).
*   **Address** (`address`, text, optional): If applicable, enter the address where the payment will be sent.
*   **Pay To** (`pay_to`, text, optional): If applicable, enter the name of the person or company to be paid.
*   **Bank Name** (`bank_name`, text, optional): If applicable, enter the name of the bank.
*   **Bank Branch** (`bank_branch`, text, optional): If applicable, enter the name of the bank branch.
*   **Bank Account Number** (`bank_account_number`, text, optional): If applicable, enter the bank account number.
*   **Routing Number** (`routing_number`, text, optional): If applicable, enter the routing number.
*   **Payment Method** (`payment_method`, select\_one, optional): Choose how the payment will be received from the provided options (Cash, Check, Wire Transfer).
*   **Notes** (`notes`, text, optional): If necessary, provide additional details or comments.
*   **Payment Terms 2** (`payment_terms_2`, select\_one, optional): Choose how the payment will be made from the provided options (Cash, Check, Wire Transfer).
*   **Pay To 2** (`pay_to_2`, text, optional): If applicable, enter the name of the person or company to be paid.
*   **Check Number** (`check_number`, text, optional): If applicable, enter the check number.
*   **Check Date** (`check_date`, date, optional): If applicable, enter the date the check was issued.
*   **Pay to Check** (`pay_to_check`, text, optional): If applicable, enter the name of the person or company to receive the check.

By following this guide, end-users will be able to navigate and complete the Severance Settlement Form accurately and effectively, ensuring that all necessary information is included and payment terms are correctly documented.
