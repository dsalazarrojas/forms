# Permanent Placement Form - Help Guide
## Purpose

The Permanent Placement Form is used to record and track permanent placements of candidates in the company's human resources management system.

## How To Complete This Form

1. Review the form carefully to ensure you are filling out the correct fields.
2. Select the relevant options for each field, taking care to fill out all required fields.
3. Fill out the form accurately and completely, following the provided instructions for each field.

## Field-by-Field Explanation

* **Placement Details (1)** (`placement_details`, text, required: false): Enter a brief description of the placement, including any relevant details about the candidate and the job.
* **Candidate (2)** (`candidate`, select_one, required: false): Select the candidate associated with this placement.
* **Placement Date (3)** (`placement_date`, date, required: false): Enter the date of the placement.
* **Recruiter (4)** (`recruiter`, select_multiple, required: false): Select the recruiter associated with this placement.
* **Agency (5)** (`agency`, text, required: false): Enter the agency associated with this placement.
* **Job Title (6)** (`job_title`, text, required: false): Enter the job title for this placement.
* **Job Description (7)** (`job_description`, text, required: false): Enter a brief description of the job.
* **Job Type (8)** (`job_type`, select_multiple, required: false): Select the job type for this placement.
* **Job Level (9)** (`job_level`, select_one, required: false): Select the job level for this placement.
* **Placement Status (10)** (`placement_status`, select_one, required: false): Select the placement status.
* **Notes (11)** (`notes`, text, required: false): Enter any additional notes or comments about this placement.
* **Comments (12)** (`comments`, text, required: false): Enter any comments or feedback about this placement.
* **Permanent Placement Agreement (13)** (`permanent_placement_agreement`, select_one, required: false): Select the permanent placement agreement.
* **Job Type 2 (14)** (`job_type_2`, select_one, required: false): Select the job type for this placement (if applicable).
