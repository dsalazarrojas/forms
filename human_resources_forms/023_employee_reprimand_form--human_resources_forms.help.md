# Employee Reprimand Form - Help Guide
## Purpose
This form is used to document and record incidents that require disciplinary actions against employees. It helps HR or management to track and address behavioral issues in the workplace.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the Employee Name in the first field.
2. Provide a clear and concise Reason for Reprimand in the second field.
3. Select the Date of Incident in the format YYYY-MM-DD.
4. Choose the Time of Incident in the format HH -MM AM/PM.
5. Describe the Description of Incident in the third field.
6. Indicate whether there were Safety Violations (Yes/No).
7. Select the specific Safety Violations (options) that occurred.
8. Check if there were Policies Violations (Yes/No).
9. Select the specific Policies Violations (options) that occurred.
10. Check if there were Attendance Violations (Yes/No).
11. Select the specific Attendance Violations (options) that occurred.
12. Provide an Action Plan for addressing the issue.
13. Choose the Disciplinary Actions (Yes/No) that will be taken.
14. Select the specific Disciplinary Actions (options) that will be taken.

## Field-by-Field Explanation
* **Employee Name** (`employee_reprimand_form_employee_name`, text, required): Enter the name of the employee involved in the incident.
* **Reason for Reprimand** (`employee_reprimand_form_reason_for_reprimand`, text, required): Provide a clear and concise reason for the reprimand.
* **Date of Incident** (`employee_reprimand_form_date_of_incident`, date, required): Select the date of the incident in the format YYYY-MM-DD.
* **Time of Incident** (`employee_reprimand_form_time_of_incident`, time, required): Choose the time of the incident in the format HH -MM AM/PM.
* **Description of Incident** (`employee_reprimand_form_description`, text, required): Describe the incident in detail.
* **Safety Violations** (`employee_reprimand_form_safety_violations`, select_multiple, optional): Check if there were safety violations (Yes/No).
* **Safety Violations Options** (`employee_reprimand_form_safety_violations_options`, select_one, optional): Select specific safety violations (options) that occurred.
* **Policies Violations** (`employee_reprimand_form_policies_violations`, select_multiple, optional): Check if there were policy violations (Yes/No).
* **Policies Violations Options** (`employee_reprimand_form_policies_violations_options`, select_one, optional): Select specific policy violations (options) that occurred.
* **Attendance Violations** (`employee_reprimand_form_attendance_violations`, select_multiple, optional): Check if there were attendance violations (Yes/No).
* **Attendance Violations Options** (`employee_reprimand_form_attendance_violations_options`, select_one, optional): Select specific attendance violations (options) that occurred.
* **Action Plan** (`employee_reprimand_form_action_plan`, text, optional): Provide an action plan for addressing the issue.
* **Disciplinary Actions** (`employee_reprimand_form_disciplinary_actions`, select_multiple, optional): Check if disciplinary actions will be taken (Yes/No).
* **Disciplinary Actions Options** (`employee_reprimand_form_disciplinary_actions_options`, select_one, optional): Select specific disciplinary actions (options) that will be taken.

## Tips
- Be clear and concise in your answers.
- Make sure to select specific options for each category if necessary.
- Double-check your answers for accuracy.
