# Employee Termination Process Checklist - Help Guide
## Purpose
The Employee Termination Process Checklist is a form used to guide administrators through the employee termination process, ensuring that all necessary steps are taken to finalize an employee's exit from the company.

## How To Complete This Form
To complete this form, please follow these steps:

1. Review each section and answer the questions accordingly.
2. For each question, select the relevant option that applies to the employee's situation.
3. Ensure you confirm each step by selecting "Yes" or "No" to indicate completion.

## Field-by-Field Explanation

### Introduction (1)
- **Introduction**: A brief introduction to the termination process.

### Employee Data (2)
- **Employee Data**: This section is used to collect employee data. Please select the relevant options for the employee's situation.

### Reason For Termination (3)
- **Reason For Termination**: This field is used to record the reason for termination. Please select the correct reason.

### Termination Date (4)
- **Termination Date**: This field is used to record the termination date of the employee. Please enter the date in the format MM/DD/YYYY.

### Property Return (5)
- **Property Return**: This section is used to confirm whether the company will be returning any company property. Please select the relevant options.
