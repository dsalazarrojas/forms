# Annual Review (Manager Feedback) - Help Guide
## Purpose
The purpose of this form is to gather feedback from managers on the performance of their employees on an annual basis. This feedback is essential for employees to understand their strengths and weaknesses, set goals, and work towards improvement.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the required fields, marked as "Required" in the form.
2. Answer each question truthfully and to the best of your ability.
3. Be specific with your feedback, providing concrete examples whenever possible.
4. Review and edit your responses before submitting the form.

## Field-by-Field Explanation

* **Your Name (Manager)** (`manager_name`, `text`, required): This field is for the manager's name and should be filled in accurately.
* **Your Email** (`manager_email`, `email`, required): This field is for the manager's work email address and should be filled in accurately.
* **Employee Name** (`employee_name`, `text`, required): This field is for the name of the employee being reviewed and should be filled in accurately.
* **Employee ID** (`employee_id`, `text`, optional): This field is for the employee's ID number and is not required.
* **Employee Position Title** (`employee_position`, `text`, required): This field is for the employee’s job title and should be filled in accurately.
* **Department** (`department`, `text`, required): This field is for the department the employee belongs to and should be filled in accurately.
* **How long have you managed this employee** (`time_managing_employee`, `select_one`, required): This field is for the manager to select how long they have managed the employee.
* **Overall performance rating** (`overall_performance_rating`, `select_one`, required): This field is for the manager to select the employee's overall performance rating.
* **Quality of work and attention to detail** (`quality_of_work`, `select_one`, required): This field is for the manager to select the employee's quality of work and attention to detail.
* **Productivity and efficiency** (`productivity_efficiency`, `select_one`, required): This field is for the manager to select the employee's productivity and efficiency.
* **Reliability and dependability** (`reliability_dependability`, `select_one`, required): This field is for the manager to select the employee's reliability and dependability.
* **Teamwork and collaboration** (`teamwork_collaboration`, `select_one`, required): This field is for the manager to select the employee's teamwork and collaboration.
* **Communication skills** (`communication_skills`, `select_one`, required): This field is for the manager to select the employee's communication skills.
* **Initiative and leadership potential** (`initiative_leadership`, `select_one`, required): This field is for the manager to select the employee's initiative and leadership potential.
* **Technical competency and expertise** (`technical_competency`, `select_one`, required): This field is for the manager to select the employee's technical competency and expertise.
* **Achievement of performance goals** (`goal_achievement`, `select_one`, required): This field is for the manager to select the employee's achievement of performance goals.
* **Employee's key strengths** (`employee_strengths`, `text`, required): This field is for the manager to list the employee's key strengths.
* **Areas for improvement** (`improvement_areas`, `text`, required): This field is for the manager to list areas where the employee can improve.
* **Specific examples** (`specific_examples`, `text`, optional): This field is for the manager to provide specific examples supporting their ratings.
* **Development plan for next year** (`development_plan`, `text`, optional): This field is for the manager to suggest a development plan for the employee.
* **Salary increase recommendation** (`salary_increase_recommendation`, `select_one`, optional): This field is for the manager to recommend a salary increase for the employee.
* **Promotion or advancement potential** (`promotion_potential`, `select_one`, optional): This field is for the manager to select the employee’s promotion or advancement potential.
* **Likelihood to retain this employee** (`retention_assessment`, `select_one`, required): This field is for the manager to select the likelihood of retaining the employee.
* **Additional comments** (`additional_comments`, `text`, optional): This field is for the manager to add any additional comments.

## Tips
* Be specific and concrete with your feedback, providing examples and supporting evidence where possible.
* Review and edit your responses before submitting the form.
* Ensure that your feedback is fair and unbiased.
* Consult with HR or other relevant personnel if you're unsure about any field or aspect of the form.
