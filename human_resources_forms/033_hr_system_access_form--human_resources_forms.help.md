# HR System Access Form - Help Guide
## Purpose
The HR System Access Form is used by HR personnel to request access to the company's HR system for employees. This form ensures that only authorized personnel have access to sensitive HR system data, promoting security and data integrity.

## How To Complete This Form
To complete this form, follow the steps below:

1.  On the first page, select the Onboarding Date for the employee and confirm if they have access to the system.
2.  On the second page, select the appropriate options for System Access, Role, Department, Team Members, System Access Type, and other relevant fields.
3.  On the last page, enter any additional notes about the employee's HR system access and confirm their Manager's details.

## Field-by-Field Explanation

*   **Onboarding Date** (`Onboarding Date`, `date`, required/optional): Select the date the employee was onboarded into the company.
*   **System Access** (`System Access`, `select_one`, required/optional): Select `Yes` if the employee needs access to the HR system, and `No` otherwise.
*   **Role** (`Role`, `select_multiple`, required/optional): Select one or more roles that the employee should have access to. Multiple options can be selected.
*   **Employee ID** (`Employee ID`, `text`, required/optional): Enter the employee's ID number.
*   **Employee Name** (`Employee Name`, `text`, required/optional): Enter the employee's name.
*   **Department** (`Department`, `select_one`, required/optional): Select `Yes` if the employee is part of a department or team.
*   **Manager ID** (`Manager ID`, `text`, required/optional): Enter the manager's ID number.
*   **Manager Name** (`Manager Name`, `text`, required/optional): Enter the manager's name.
*   **Manager Title** (`Manager Title`, `text`, required/optional): Enter the manager's title or position.
*   **Manager Email** (`Manager Email`, `email`, required/optional): Enter the manager's email address.
*   **Manager Phone** (`Manager Phone`, `text`, required/optional): Enter the manager's phone number.
*   **Team Members** (`Team Members`, `select_multiple`, required/optional): Select one or more team members that the employee should have access to.
*   **Other Team Members** (`Other Team Members`, `text`, required/optional): Enter any additional team members not listed in the previous field.
*   **System Access Type** (`System Access Type`, `select_one`, required/optional): Select the type of system access the employee should have.
*   **Notes** (`Notes`, `text`, required/optional): Enter any additional notes about the employee's HR system access.

## Tips

*   Please ensure all fields are accurate and complete before submitting the form.
*   If you're unsure about any field or have questions, please reach out to your HR department for clarification.
*   This form is intended for internal use only, please do not share it with external parties.
*   The HR System Access Form is subject to change, please refer to the company's HR policy for the most up-to-date information.
