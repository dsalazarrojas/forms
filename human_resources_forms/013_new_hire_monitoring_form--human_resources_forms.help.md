# New Hire Monitoring Form - Help Guide
## Purpose
The New Hire Monitoring Form is a tool used to monitor new hires within the organization. It ensures that all necessary information is accurately documented and up-to-date, helping to streamline the onboarding process and reduce administrative tasks.

## How To Complete This Form
To complete this form, follow these steps:

1.  Click on the "New Hire Monitoring Form" section.
2.  Enter the Employee ID of the new hire.
3.  Select the Hire Date of the new hire.

## Field-by-Field Explanation

*   **New Hire Monitoring Form**: This is the main section of the form where you can enter all the necessary information about the new hire. 
    *   **Employee ID**: A unique identifier assigned to the new hire. Please enter the employee ID exactly as it appears on their personnel record.
    *   **Hire Date**: The date the new hire joined the organization. Enter the date in the format `YYYY-MM-DD`. 

## Tips
- Ensure that you only complete this form for new hires, and avoid duplicating entries for the same employee.
- Double-check that you have entered the correct employee ID and hire date to ensure accurate tracking. 
- If you're unsure about any information, consult with the HR department for assistance.
