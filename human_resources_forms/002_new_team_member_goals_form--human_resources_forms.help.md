# New Team Member Goals Form - Help Guide

## Purpose

This form is used to collect and document the goals and objectives of new team members.

## How To Complete This Form

1. Review each field carefully and select the most accurate option.
2. Provide any additional comments or explanations as necessary.
3. Submit the form once you have completed it.

## Field-by-Field Explanation

* **first_page**: This is the first page of the form, which is used to introduce the form and provide additional context.
	+ This page does not require a response.
* **section 1**: This section is used to determine the focus areas for the new team member's goals.
	+ Choose one or multiple options that best fit the new team member's role and responsibilities.
* **section 1 goal 1**: This field is used to collect the new team member's primary goal.
	+ Enter a brief description of the new team member's primary goal.
* **section 1 goal 2**: This field is used to collect the new team member's secondary goal.
	+ Enter a brief description of the new team member's secondary goal.
* **section 1 goal 3**: This field is used to collect the new team member's third goal.
	+ Enter a brief description of the new team member's third goal.
* **section 1 goal 4**: This field is used to collect the new team member's fourth goal.
	+ Enter a brief description of the new team member's fourth goal.
* **section 2**: This section is used to determine if the new team member is expected to focus on specific areas.
	+ Choose one option that best fits the new team member's focus area.
* **section 2 goal 1**: This field is used to collect the new team member's goal for this section.
	+ Enter a brief description of the new team member's goal.
* **section 2 goal 2**: This field is used to collect the new team member's second goal for this section.
	+ Enter a brief description of the new team member's second goal.
* **section 2 goal 3**: This field is used to collect the new team member's third goal for this section.
	+ Enter a brief description of the new team member's third goal.
* **section 3**: This section is used to determine if the new team member is expected to take on specific tasks.
	+ Choose one option that best fits the new team member's focus area.
* **section 3 goal 1**: This field is used to collect the new team member's goal for this section.
	+ Enter a brief description of the new team member's goal.
* **section 3 goal 2**: This field is used to collect the new team member's second goal for this section.
	+ Enter a brief description of the new team member's second goal.
* **section 4**: This section is used to determine if the new team member has specific goals or responsibilities.
	+ Choose one or multiple options that best fit the new team member's goals or responsibilities.
* **section 4 goal 1**: This field is used to collect the new team member's goal for this section.
	+ Enter a brief description of the new team member's goal.
* **section 4 goal 2**: This field is used to collect the new team member's second goal for this section.
	+ Enter a brief description of the new team member's second goal.
* **comments**: This field is used to provide any additional comments or explanations.
	+ Enter any additional comments or explanations related to the new team member's goals.
* **confirm**: This field is used to confirm the completion of the form.
	+ Select "Yes" to confirm the completion of the form.
* **submit**: This field is used to submit the form once it has been completed.
	+ Select "Yes" to submit the form.
* **review**: This field is used to request a review of the form.
	+ Select "Yes" to request a review.
* **approve**: This field is used to approve the form.
	+ Select "Yes" to approve the form.
* **decline**: This field is used to decline the form.
	+ Select "Yes" to decline the form.
* **decline_reason**: This field is used to provide a reason for decline.
	+ Enter a brief description of the reason for decline.
* **save_and_submit**: This field is used to save and submit the form.
	+ Select "Yes" to save and submit the form.

Note: This help guide is intended to be concrete, concise, and practical. If any field label is unclear, the explanation is based on the best-effort interpretation of the field's purpose.
