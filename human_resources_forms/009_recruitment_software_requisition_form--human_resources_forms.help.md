# Recruitment Software Requisition Form - Help Guide

## Purpose
The Recruitment Software Requisition Form is used to request software and related expenses from the organization. This form helps to streamline the process of submitting software requisitions, ensuring that all necessary information is gathered and approved before the request is processed.

## How To Complete This Form

To fill out the form, follow these steps:

1. Start by selecting the "Software Requisition" page.
2. Enter the required details in the following fields:
   - **Software Requisition**: Enter a brief description of the software or service being requested.
   - **Job Title**: Enter the job title related to the software request.
   - **Department**: Enter the department requesting the software.
   - **Job Description**: Enter a brief description of the job that the software is intended to support.
3. Select the software type from the dropdown menu.
4. Enter the name of the software requestor.
5. If applicable, select the department head and approver.
6. Provide the software cost and funding source.
7. If necessary, enter the date and time for the submission.
8. Add any additional notes about the software request.
9. Enter the email and phone number of the person submitting the request.
10. Select the software status.
11. Finally, confirm the created by, updated by, updated date, updated time, created date, created time, assigned to, submitted by fields as they are auto-filled.

## Field-by-Field Explanation

* **Software Requisition**: This is a text field where you can enter a brief description of the software or service being requested.
* **Job Title**: This field is for entering the job title related to the software request.
* **Department**: Enter the department requesting the software.
* **Job Description**: Enter a brief description of the job that the software is intended to support.
* **Software Type**: This dropdown menu lists the available software types. Select the type that best matches your request.
* **Software Requestor**: Enter the name of the person or team requesting the software.
* **Department Head**: If applicable, enter the name of the department head who will be approving the request.
* **Approver**: If applicable, enter the name of the person approving the request.
* **Requisitioner**: Enter the name of the person submitting the request.
* **Software Cost**: Enter the cost of the software being requested.
* **Software Funding Source**: Select the source of the funding for the software request.
* **Date**: Enter the date when the software request was made.
* **Time**: Enter the time when the software request was made.
* **Notes**: Add any additional notes about the software request.
* **Email**: Enter the email address of the person submitting the request.
* **Phone**: Enter the phone number of the person submitting the request.
* **Software Status**: This dropdown menu lists the available software status options. Select the status that best matches your request.
* **Created By**: This field is automatically populated with the name of the person who created the request.
* **Updated By**: This field is automatically populated with the name of the person who last updated the request.
* **Updated Date**: This field is automatically populated with the date the request was last updated.
* **Updated Time**: This field is automatically populated with the time the request was last updated.
* **Created Date**: This field is automatically populated with the date the request was created.
* **Created Time**: This field is automatically populated with the time the request was created.
* **Assigned To**: This field is automatically populated with the name of the person assigned to the request.
* **Submitted By**: This field is automatically populated with the name of the person who submitted the request.

Note: The fields marked as required are mandatory fields that need to be filled out. The fields with options are dropdown menus that allow you to select from a list of available choices. The fields with type "text" are text fields where you can enter free-formatted text. The fields with type "number" are fields for entering numerical values. The fields with type "date" and "time" are for entering dates and times respectively. The fields with type "note" are for adding additional notes. The fields with type "select_one" and "select_multiple" are dropdown menus for selecting from a list of options.
