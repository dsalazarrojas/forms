# Performance Review Amendment Form - Help Guide
## Purpose
The Performance Review Amendment Form is used to make changes to an existing performance review. This form is necessary when there are discrepancies between the initial performance review and the employee's actual performance.

## How To Complete This Form
To complete this form, please follow these steps:

1. Ensure you have the necessary information and documents ready.
2. Fill in the employee's **Employee ID** to associate the amendment with the correct employee.
3. Enter the **Manager ID** to associate the amendment with the correct manager.
4. Rate the employee's performance using the **Rating** field.
5. Provide a brief **Comment** on the changes made.
6. Select the **Date** of the performance review amendment.
7. Optionally, enter a **Reason for Amendment** to provide context for the changes.

## Field-by-Field Explanation
### Employee ID (`employee_id`, number, required: false)
*   The **Employee ID** field is used to identify the employee whose performance review is being amended. Enter the employee's unique ID number.

### Manager ID (`manager_id`, number, required: false)
*   The **Manager ID** field is used to identify the manager who is making the performance review amendment. Enter the manager's unique ID number.

### Rating (`rating`, number, required: false)
*   The **Rating** field is used to evaluate the employee's performance. Enter a numerical value between 1 and 10.

### Comment (`comment`, text, required: false)
*   The **Comment** field is used to provide a brief description of the changes made to the performance review. Enter a short message to clarify the reasons for the amendment.

### Date (`date`, date, required: false)
*   The **Date** field is used to specify the date when the performance review amendment was made.

### Reason for Amendment (`reason`, text, required: false)
*   The **Reason for Amendment** field is an optional field where you can enter any additional context or explanation for the performance review amendment.

## Tips
*   Please ensure that all fields are filled out accurately and completely.
*   Double-check your information before submitting the form.
*   This form is for amendments to performance reviews, not for creating new reviews.
*   If you are unsure about any part of the form, please contact your supervisor or HR representative for assistance.
