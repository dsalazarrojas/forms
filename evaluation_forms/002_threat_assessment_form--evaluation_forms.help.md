# Threat Assessment Form - Help Guide
## Purpose
The Threat Assessment Form is used to assess the level of threat posed by a particular threat to the organization.

## How To Complete This Form
To complete this form, follow these steps:

* Read the form carefully and ensure you understand the purpose and instructions.
* For each field, provide the most accurate and up-to-date information about the threat.
* Select the most appropriate option from the drop-down menus.
* Enter your answer in the text fields.
* Review your answers carefully before submitting the form.

## Field-by-Field Explanation
* **Threat Assessment Form 1** (`threat_assessment_form_1`, text, required/optional): This field is used to enter a brief description of the threat.
* **Threat Level** (`threat_level_label`, select_one, optional): This field asks you to select the level of threat posed by the threat, using the options provided. The options are:
	+ Low: The threat is not considered significant.
	+ Medium: The threat is moderately significant.
	+ High: The threat is highly significant.
* **Threat Category** (`threat_category_label`, select_multiple, optional): This field asks you to select one or more categories that the threat falls into, using the options provided. The options are:
	+ Cyber: The threat is related to cyber security.
	+ Physical: The threat is related to physical security.
	+ Environmental: The threat is related to environmental security.
	+ Social: The threat is related to social security.
* **Threat Frequency** (`threat_frequency_label`, select_one, optional): This field asks you to select how often the threat occurs, using the options provided. The options are:
	+ Rare: The threat occurs very infrequently.
	+ Occasional: The threat occurs occasionally.
	+ Frequent: The threat occurs frequently.
* **Threat Impact** (`threat_impact_label`, text, optional): This field is used to enter a brief description of the potential impact of the threat.
* **Threat Probability** (`threat_probability_label`, number, optional): This field asks you to enter a numerical value representing the likelihood of the threat occurring.
* **Threat Risk Level** (`threat_risk_level_label`, text, optional): This field is used to enter a brief description of the level of risk associated with the threat.
* **Threat Assessment** (`threat_assessment_label`, select_one, optional): This field asks you to select whether the threat is Accepted, Recommended, or Not Recommended.
* **Mitigation Plan** (`mitigation_plan_label`, text, optional): This field is used to enter any mitigation plans or recommendations for addressing the threat.

Tips:

* Be as specific and detailed as possible when completing this form.
* Use the options provided to select the most accurate response.
* If a field is not applicable, select the "Not Applicable" option.
* Review this form carefully before submitting it to ensure that your answers are accurate and complete.
