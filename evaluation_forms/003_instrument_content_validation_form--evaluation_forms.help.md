# Instrument Content Validation Form - Help Guide
## Purpose
The Instrument Content Validation Form is a tool for evaluating and validating the content of a musical instrument. It helps ensure that the instrument's content is accurate, complete, and meets the required standards.

## How To Complete This Form
To complete this form, please follow these steps:

1. Enter the name of the instrument in the "instrument_name" field.
2. Enter the version of the instrument in the "instrument_version" field.
3. If relevant, enter a numerical rating for the instrument's performance using the "expert_rating_scale" field. Note that this field is optional.
4. Enter your expert rating for the instrument's performance using the "expert_rating" field. This field is also optional.
5. In the "comments" field, provide any additional comments or feedback about the instrument.
6. Enter the content of the instrument in the "instrument_content" field. This field is required.
7. Repeat steps 3-6 for any subsequent instruments that require evaluation (e.g., "instrument_content_2", "expert_rating_2", "instrument_name 2", etc.).

## Field-by-Field Explanation

* **instrument_name** (`instrument_name`, text, required): Enter the name of the instrument being evaluated.
* **instrument_version** (`instrument_version`, text, required): Enter the version or model number of the instrument.
* **expert_rating_scale** (`expert_rating_scale`, number, optional): Enter a numerical rating for the instrument's performance, if relevant. This field is intended to provide a quick snapshot of the instrument's performance.
* **expert_rating** (`expert_rating`, number, optional): Enter your expert rating for the instrument's performance. This field is intended to provide a more detailed assessment of the instrument's performance.
* **comments** (`comments`, text, optional): Enter any additional comments or feedback about the instrument. This field is for general notes and insights.
* **instrument_content** (`instrument_content`, text, required): Enter the content of the instrument, such as its description, specification, or features.
* **expert_rating_scale_2** (`expert_rating_scale_2`, number, optional): Enter a numerical rating for the performance of the second instrument, if relevant.
* **expert_rating_2** (`expert_rating_2`, number, optional): Enter your expert rating for the performance of the second instrument. This field is intended to provide a more detailed assessment of the second instrument's performance.
* **comments_2** (`comments_2`, text, optional): Enter any additional comments or feedback about the second instrument. This field is for general notes and insights.
* **instrument_content_2** (`instrument_content_2`, text, optional): Enter the content of the second instrument, if it exists. This field is optional but required for specific use cases.

## Tips
* Ensure that each field is complete and accurate.
* Use clear and concise language in the "comments" fields.
* If you are evaluating multiple instruments, make sure to fill out the fields consistently for each instrument.
