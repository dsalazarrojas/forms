# Focus Group Questionnaire - Help Guide

## Purpose
This form is designed to collect feedback and evaluation data from various stakeholders, project team members, and interviewees on a specific project or initiative.

## How To Complete This Form

*   Start by selecting the evaluation form type from the options provided in the "Evaluation Form Type" field.
*   In the "Stakeholders" field, select all the relevant stakeholders involved in the project or initiative.
*   In the "Stakeholders Roles" field, select the role of the stakeholders you selected in the previous step.
*   Answer the questions in the "Evaluation Form Question" field as accurately and honestly as possible.
*   Select the type of question from the options provided in the "Question Type" field.
*   Enter your response to the question in the "Answer" field.
*   In the "Evaluation Scale" field, select the scale to be used for evaluation.
*   Finally, enter your name, phone number, and email address in the last three fields for contact information.

## Field-by-Field Explanation

*   **Evaluation Form Type** (`evaluation_form_type`): Select the type of evaluation form to be used.
    *   This field allows you to select the type of evaluation form to be used for the project or initiative.
*   **Stakeholders** (`stakeholders`): Select all relevant stakeholders involved in the project or initiative.
    *   This field is used to select all the stakeholders involved in the project or initiative.
*   **Stakeholders Roles** (`stakeholders_roles`): Select the role of the stakeholders.
    *   This field is used to select the role of the stakeholders selected in the previous step.
*   **Evaluation Form Question** (`evaluation_form_question`): Answer the question accurately and honestly.
    *   This field is used to enter your response to the question selected in the previous step.
*   **Question Type** (`question_type`): Select the type of question.
    *   This field is used to select the type of question to be asked.
*   **Answer** (`answer`): Enter your response to the question.
    *   This field is used to enter your response to the question selected in the previous step.
*   **Evaluation Scale** (`evaluation_scale`): Select the evaluation scale to be used.
    *   This field is used to select the evaluation scale to be used for the project or initiative.
*   **Name** (`name`): Enter your name.
    *   This field is used to enter your name for contact information.
*   **Phone Number** (`phone_number`): Enter your phone number.
    *   This field is used to enter your phone number for contact information.
*   **Email** (`email`): Enter your email address.
    *   This field is used to enter your email address for contact information.
*   **Location** (`location`): Enter the location where the project or initiative is being implemented.
    *   This field is used to enter the location where the project or initiative is being implemented.
*   **Note** (`note`): Enter any additional notes about the project or initiative.
    *   This field is used to enter any additional notes about the project or initiative.
*   **Project Name** (`project_name`): Enter the name of the project or initiative.
    *   This field is used to enter the name of the project or initiative.
*   **Project Description** (`project_description`): Enter a brief description of the project or initiative.
    *   This field is used to enter a brief description of the project or initiative.
*   **Evaluation Form Question 2** (`evaluation_form_question_2`): Enter any additional questions or comments.
    *   This field is used to enter any additional questions or comments about the project or initiative.
