# Department Report Form - Help Guide
## Purpose
The Department Report Form is a general-purpose form used by department staff to report issues and their resolutions within the department.

## How To Complete This Form
To complete this form, follow these steps:

1. Provide a brief description of the issue in the "Issue Description" field.
2. Select all relevant issues that have occurred from the "Issues" dropdown list.
3. In the "Actions Taken" field, describe any steps taken to address the issue.
4. Indicate whether the issue has been resolved in the "Issue Solved" field.
5. If the issue has been resolved, provide a description of the resolution in the "Issue Solved Description" field.
6. Enter the date the issue occurred in the "Date" field.
7. Enter the time the issue occurred in the "Time" field.
8. Specify who was assigned to address the issue in the "Assigned To" field.
9. Specify the tool or system used to address the issue in the "Assigned Tool" field.
10. Enter the department affected by the issue in the "Department" field.

## Field-by-Field Explanation

### Issue Description
**Issue Description** (`issue_description`, text, optional)
Provide a brief description of the issue, including any relevant details.

### Issues
**Issues** (`issues`, select_multiple, optional)
Select all relevant issues that have occurred.

### Actions Taken
**Actions Taken** (`actions_taken`, note, optional)
Describe any steps taken to address the issue.

### Issue Solved
**Issue Solved** (`issue_solved`, select_one, optional)
Indicate whether the issue has been resolved.

### Issue Solved Description
**Issue Solved Description** (`issue_solved_description`, text, optional)
If the issue has been resolved, provide a description of the resolution.

### Date
**Date** (`date`, date, optional)
Enter the date the issue occurred.

### Time
**Time** (`time`, time, optional)
Enter the time the issue occurred.

### Assigned To
**Assigned To** (`assigned_to`, text, optional)
Specify who was assigned to address the issue.

### Assigned Tool
**Assigned Tool** (`assigned_tool`, text, optional)
Specify the tool or system used to address the issue.

### Department
**Department** (`department`, text, optional)
Enter the department affected by the issue.

## Tips

* Be as detailed as possible when describing the issue and its resolution.
* Use the "Issues" field to select all relevant issues that have occurred.
* If an issue has been resolved, make sure to provide a clear description of the resolution.
* Enter dates and times in the format MM/DD/YYYY and HH:MM AM/PM respectively.
* Be accurate when assigning individuals or tools to address issues.
