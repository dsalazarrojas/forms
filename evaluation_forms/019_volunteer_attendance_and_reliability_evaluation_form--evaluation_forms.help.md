# Volunteer Attendance And Reliability Evaluation Form - Help Guide

## Purpose
The Volunteer Attendance And Reliability Evaluation Form is used to assess volunteers' performance and participation in events or activities. This form collects information about their attendance, attendance scores, reliability, and other relevant details.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the required information, starting with the Volunteer field.
2. Select the Date of the event or activity you are evaluating.
3. Enter the Volunteer Name of the person being evaluated.
4. Assign an Attendance Score and select the corresponding Attendance Score Scale.
5. Select the Reliability Score Scale and assign a value for the Reliability Score Scale Value field.
6. Optionally, provide Comments and additional comments, if applicable.
7. Enter the Email of the volunteer and/or their Phone number, if necessary.
8. If a tool was assigned to the volunteer, enter the name of the tool and who used it.

## Field-by-Field Explanation

* **Volunteer** (`1`, `text`, required): Enter the name of the volunteer being evaluated.
* **Date** (`2`, `date`, required): Select the date of the event or activity being evaluated.
* **Volunteer Name** (`3`, `text`, required): Enter the name of the volunteer.
* **Attendance Score** (`4`, `number`, required): Assign a numerical score out of a maximum score to indicate the volunteer's attendance.
* **Attendance Score Scale** (`5`, `select_one`, required): Select the scale for the attendance score, e.g., Scale 1, Scale 2, or Scale 3.
* **Attendance Score Scale Value** (`6`, `number`, required): Enter the numerical value for the selected scale.
* **Reliability** (`7`, `number`, required): Assign a numerical score for the volunteer's reliability.
* **Reliability Score Scale** (`8`, `select_one`, required): Select the scale for the reliability score, e.g., Scale 1, Scale 2, or Scale 3.
* **Reliability Score Scale Value** (`9`, `number`, required): Enter the numerical value for the selected scale.
* **Comments** (`10`, `text`, optional): Add any comments about the volunteer's performance or attendance.
* **Email** (`11`, `email`, required): Enter the email address of the volunteer.
* **Phone** (`12`, `text`, optional): Enter the phone number of the volunteer.
* **Assigned Tool** (`13`, `text`, optional): Enter the name of the tool assigned to the volunteer.
* **Assigned Tool User** (`14`, `text`, optional): Enter the name of the user who used the tool.
* **Comments and additional comments** (`15`, `text`, optional): Add any additional comments or information about the volunteer's performance.

Note: This guide assumes that the form fields are labeled accurately and consistently. If you're unsure about a field, refer to the original YAML description.
