## Static Evaluation Form - Help Guide

## Purpose
The Static Evaluation Form is a tool used to gather feedback and insights on a project or person. It helps to evaluate and identify areas of improvement, providing a structured format for providing qualitative and quantitative feedback.

## How To Complete This Form
To complete the Static Evaluation Form, follow these steps:

1. Click on the "Static Evaluation Form" link to begin the form.
2. On each page, select the relevant options for the corresponding field.
3. Enter any additional comments or information as needed.
4. Review your entries before submitting the form.

## Field-by-Field Explanation

### Page 1 - Evaluation Form
* **Static Evaluation Form** (`static_evaluation_form_1`, text, required): Enter a brief description of the project or person being evaluated.
* **Project Name** (`project_name`, text, optional): Enter the name of the project or person being evaluated.
* **Project Type** (`project_type`, select multiple, optional):
	+ Choose the type of project from the available options (People, Projects, Processes).
* **Evaluations Criteria** (`evaluation_criteria`, select multiple, optional):
	+ Choose the evaluation criteria from the available options (People, Projects, Processes).
* **Evaluation Score** (`evaluation_score`, number, optional): Enter a numerical score for the evaluation (1-10).
* **Evaluation Comments** (`evaluation_comments`, text, optional): Enter any additional comments or feedback.
* **Recommended Actions** (`recommended_actions`, text, optional): Enter any recommended actions or next steps.

Note: All fields are optional, but it's recommended to complete as much information as possible to get the most accurate and comprehensive evaluation.
