# erp_platform_selection_evaluation_form - Help Guide
## Purpose
This form is designed to help users evaluate and compare different ERP platforms. The data collected through this form will be used to generate insights and reports that can help make informed decisions about which platforms to use.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the ERP platform you are evaluating from the first dropdown menu.
2. Fill in the form name and description in the text fields.
3. If you have experience with the platform, answer "Yes" or "No" to indicate whether you've used it.
4. Optionally, you can provide the platform's name if it's different from the one being evaluated.

## Field-by-Field Explanation

* **erp Platform Selection** (`erp_platform_selection`, select_one, required): Select the ERP platform you are evaluating from the list.
* **evaluation Form** (`evaluation_form`, text, optional): Enter a brief description of the form you are evaluating.
* **form Description** (`form_description`, text, optional): Enter a brief description of the form you are evaluating.
* **vendor Name** (`vendor_name`, select_one, optional): If the platform has a vendor name different from the one being evaluated, select "Yes" to indicate this.
