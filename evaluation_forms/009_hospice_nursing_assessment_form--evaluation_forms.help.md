# Hospice Nursing Assessment Form - Help Guide
## Purpose
The purpose of this form is to collect clinical data about a patient in a hospice setting.

## How To Complete This Form
To complete this form, please follow the steps below:

* Please fill in all required fields as accurately as possible.
* Be as detailed as possible when providing information in free text fields.
* If unsure about a field or have additional information that is not captured in the form, please provide it in the 'Additional Comments' field.
* Review and submit the form once complete.

## Field-by-Field Explanation

* **first_page**: This field is a text input field for any additional information that needs to be captured on the first page.
* **hospice_nursing_assessment**: This field is a dropdown menu that allows you to select the level of hospice nursing assessment required.
* **patient_condition**: This field is a text input field to capture the patient's current medical condition.
* **patient_status**: This field is a dropdown menu that allows you to select the patient's status (stable, declining, improving).
* **pain_level**: This field is a numerical input field to record the patient's current pain level.
* **vital_signs**: This field is a time input field to capture the patient's vital signs.
* **medication**: This field is a text input field to capture the patient's current medication.
* **hospice_id**: This field is a numerical input field to record the patient's hospice ID.
* **date_of_last_dose**: This field is a date input field to record the date of the last medication dose.
* **last_dose_administered_by**: This field is a text input field to record who administered the last medication dose.
* **next_dose_administered_by**: This field is a text input field to record who will administer the next medication dose.
* **hospice_medication**: This field is a text input field to capture the patient's current medication.
* **hospice_medication_frequencies**: This field is a text input field to capture the patient's medication frequencies.
* **hospice_medication_doses**: This field is a text input field to capture the patient's medication doses.
* **hospice_medication_strengths**: This field is a text input field to capture the patient's medication strengths.
* **hospice_medication_routes**: This field is a text input field to capture the patient's medication routes.
* **hospice_medication_comments**: This field is a text input field to capture any additional comments about the patient's medication.
* **hospice_care_level**: This field is a text input field to capture the patient's current care level.
* **hospice_care_level_frequencies**: This field is a text input field to capture the patient's care level frequencies.
* **hospice_care_level_doses**: This field is a text input field to capture the patient's care level doses.
* **hospice_care_level_strengths**: This field is a text input field to capture the patient's care level strengths.
* **hospice_care_level_routes**: This field is a text input field to capture the patient's care level routes.
* **hospice_care_level_comments**: This field is a text input field to capture any additional comments about the patient's care level.
* **hospice_other_care_level**: This field is a text input field to capture any other care level information that may be relevant.
* **hospice_other_care_level_comments**: This field is a text input field to capture any additional comments about the other care level.

## Tips
* Please ensure you have the necessary permissions and clearance to access and modify patient data.
* If unsure about any field or have additional information, please reach out to the relevant authorities for further clarification.
* Review and submit the form once complete.
* Ensure the form is accurate and complete before submitting it.
