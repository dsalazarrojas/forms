# Personalized Medicine Innovation Evaluation Form - Help Guide
## Purpose
This form is designed to collect feedback and evaluation scores from reviewers on a project submitted by a team. It guides the reviewer through a multi-step evaluation process, allowing them to select multiple evaluation criteria, provide a score, and submit comments and feedback.

## How To Complete This Form
To complete this form, follow these steps:

1. Read each question carefully and ensure you understand what is being asked.
2. Select the evaluation criteria that apply to the project.
3. Enter the project details, such as name, description, and status.
4. Provide a score for each selected evaluation criterion.
5. Enter your contact information, including name, role, and institute.
6. Submit your comments and feedback on the project.

## Field-by-Field Explanation

* **user-input** (1.1): Enter a brief description of the project.
* **Evaluation Criteria** (2.1): Select all the evaluation criteria that apply to the project. This will help the reviewer evaluate the project based on multiple criteria.
* **Medicine Name** (3.1): Enter the name of the medicine being evaluated.
* **Project Description** (4.1): Enter a short description of the project. This is an optional field, but it can provide additional context to your evaluation.
* **Evaluation Score** (5.1): Provide a score for each selected evaluation criterion.
* **Team Members** (6.1): Select the team members involved in the project.
* **Evaluation Criteria List** (7.1): Enter a list of evaluation criteria for the project.
* **Submission Date** (8.1): Enter the date you submitted the project.
* **Submission Time** (9.1): Enter the time you submitted the project.
* **Contact Info** (10.1): Enter your contact information, including name and email.
* **Email Address** (11.1): Enter your email address.
* **Phone Number** (12.1): Enter your phone number.
* **Project Status** (13.1): Select the current status of the project.
* **Project Category** (14.1): Select the category of the project.
* **Project Phase** (15.1): Select the phase of the project.
* **Project Duration** (16.1): Enter the duration of the project in days.
* **Project Start Date** (17.1): Enter the start date of the project.
* **Project End Date** (18.1): Enter the end date of the project.
* **Submission Status** (19.1): Select the submission status of the project.
* **Reviewer Comments** (20.1): Enter your comments and feedback on the project.
* **Submission Fee** (21.1): Enter the submission fee (if applicable).
* **Reviewer Name** (22.1): Enter your name as the reviewer.
* **Reviewer Role** (23.1): Enter your role as the reviewer.
* **Reviewer Institute** (24.1): Enter the name of the institute where you are from.
* **Submission Comments** (25.1): Enter any additional comments on the submission.
