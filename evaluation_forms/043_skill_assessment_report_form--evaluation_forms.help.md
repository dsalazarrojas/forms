# Skill Assessment Report Form - Help Guide
## Purpose
The purpose of this form is to collect feedback and assessments on a specific set of skills from a manager to an employee.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the Employee ID of the individual being assessed.
2. Assess the employee's skill 1 performance by selecting either "Yes" or "No".
3. Provide a brief description of the employee's skill 1 performance.
4. Assess the employee's skill 2 performance by selecting either "Yes" or "No" for each option.
5. Provide a brief description of the employee's skill 2 performance.
6. Enter the Manager ID of the person evaluating the employee.
7. Enter the Manager Name (optional).
8. Choose a specific date for the evaluation (optional).
9. Select a time for the evaluation (optional).
10. Enter any additional notes or comments about the employee's performance.

## Field-by-Field Explanation
### employee_id
* **Employee ID** (`<name>`, `number`, optional): Enter the ID number of the employee being assessed.

### skill_1_id
* **Skill 1 Label** (`<name>`, `select_one`, required): Assess the employee's skill 1 performance by selecting either "Yes" or "No".

### skill_1_description
* **Skill 1 Description** (`<name>`, `text`, optional): Provide a brief description of the employee's skill 1 performance.

### skill_2_id
* **Skill 2 Label** (`<name>`, `select_multiple`, optional): Assess the employee's skill 2 performance by selecting either "Yes" or "No" for each option.

### skill_2_description
* **Skill 2 Description** (`<name>`, `text`, optional): Provide a brief description of the employee's skill 2 performance.

### manager_id
* **Manager ID** (`<name>`, `number`, optional): Enter the ID number of the manager evaluating the employee.

### manager_name
* **Manager Name** (`<name>`, `text`, optional): Enter the name of the manager evaluating the employee.

### evaluation_date
* **Evaluation Date** (`<name>`, `date`, optional): Choose a specific date for the evaluation.

### evaluation_time
* **Evaluation Time** (`<name>`, `time`, optional): Select a specific time for the evaluation.

### note
* **Note** (`<name>`, `note`, optional): Enter any additional notes or comments about the employee's performance.

## Tips
* Please ensure that all required fields are filled out for a comprehensive assessment.
* If a field is not applicable, feel free to skip it.
* If you need help or have questions, please reach out to your supervisor or support team.
