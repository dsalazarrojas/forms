# logistics_partner_evaluation_request_form - Help Guide
## Purpose
This form is used by logistics partners to submit an evaluation request to our team. It is a simple form that captures essential information about the request, including supplier details, evaluation date, and reason for the request.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter your supplier name in the first field, "Supplier Name."
2. Select the date for the evaluation request using the date picker in the "Evaluation Date" field.
3. Provide a brief explanation for the request in the "Evaluation Request Reason" field.

## Field-by-Field Explanation
### Supplier Name (`Supplier Name`, text, optional)
Enter the name of your company or organization that is submitting the evaluation request.
### Evaluation Date (`Evaluation Date`, date, optional)
Select the date when you would like to conduct or have the evaluation completed. This will help us plan and schedule the evaluation process.
### Evaluation Request Reason (`Evaluation Request Reason`, text, optional)
Briefly explain why you are requesting an evaluation. This will help us understand the scope and objectives of the evaluation.
