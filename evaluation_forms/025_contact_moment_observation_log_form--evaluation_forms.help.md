# Contact Moment Observation Log Form - Help Guide

## Purpose

This form is used to document and evaluate customer interactions, such as phone calls, emails, or live chats. The goal is to provide constructive feedback to agents and identify areas for improvement.

## How To Complete This Form

1. Review the interaction notes and relevant documentation or recordings.
2. Assess the interaction based on your evaluation criteria, such as active listening, empathy, problem-solving, and overall performance.
3. Complete each field with specific and honest answers.
4. Use the guidelines above as a reference when filling out the form.

## Field-by-Field Explanation

* **Contact Moment Observation Log** (`log_header`): This is the title of the form and the starting point for your evaluation.
* **Observer Name** (`observer_name`): Enter the name of the person conducting the evaluation.
* **Observer Role** (`observer_role`): Select the role of the evaluator, such as Supervisor, Team Lead, Quality Analyst, Trainer, or Manager.
* **Observation Date** (`observation_date`): Enter the date of the interaction being evaluated.
* **Observation Time** (`observation_time`): Enter the start time of the interaction.
* **Agent Being Observed** (`agent_name`): Enter the name of the agent being evaluated.
* **Agent ID** (`agent_id`): Enter the identifier or employee number of the agent being evaluated.
* **Type of Interaction** (`interaction_type`): Select the type of interaction that took place, such as Inbound Phone Call, Outbound Phone Call, Email, Live Chat, Video Call, or Social Media.
* **Interaction Duration** (`interaction_duration`): Enter the duration of the interaction in minutes.
* **Customer Type** (`customer_type`): Select the type of customer being interacted with, such as New Customer, Existing Customer, VIP Customer, or Escalated Customer.
* **Reason for Contact** (`call_reason`): Enter the primary reason for the interaction, which is the main issue or purpose of the conversation.
* **Greeting and Opening** (`greeting_assessment`): Assess how well the agent greeted and opened the interaction, using the scale Excellent, Good, Average, Below Average, or Poor.
* **Active Listening Skills** (`active_listening`): Assess how well the agent listened during the interaction, using the scale Excellent, Good, Average, Below Average, or Poor.
* **Empathy Demonstrated** (`empathy_demonstrated`): Assess how well the agent demonstrated empathy during the interaction, using the scale Yes - Very Well, Yes - Adequately, Minimal, or False.
* **Problem Solving Ability** (`problem_solving`): Assess how well the agent was able to resolve the issue during the interaction, using the scale Excellent, Good, Average, Below Average, or Poor.
* **Product Knowledge** (`product_knowledge`): Assess the agent's level of product knowledge, using the scale Expert, Proficient, Adequate, Limited, or Insufficient.
* **Communication Clarity** (`communication_clarity`): Assess how clear the agent's communication was during the interaction, using the scale Very Clear, Clear, Somewhat Clear, Unclear, or Confusing.
* **System and Tool Usage** (`system_usage`): Assess how well the agent used systems and tools during the interaction, using the scale Excellent, Good, Average, Below Average, or Poor.
* **Compliance and Policy Adherence** (`compliance_adherence`): Assess how well the agent followed policies and procedures during the interaction, using the scale Fully Compliant, Mostly Compliant, Partially Compliant, or Non-Compliant.
* **Closing and Summary** (`closing_quality`): Assess how well the agent closed the interaction, using the scale Excellent, Good, Average, Below Average, or Poor.
* **Strengths Observed** (`strengths_observed`): Enter any strengths or positive observations about the agent's performance.
* **Areas for Improvement** (`areas_for_improvement`): Enter any areas where the agent can improve their performance.
* **Coaching Recommended** (`coaching_recommended`): Select whether follow-up coaching is recommended, using the scale Yes - Immediate, Yes - Within Week, Yes - Routine Coaching, or No - Performance Satisfactory.
* **Overall Performance Score** (`overall_score`): Rate the agent's overall performance on a scale of 1 to 10.
* **Was Feedback Provided to Agent** (`feedback_provided`): Select whether feedback was provided to the agent, using the scale Yes - Immediately, Yes - Scheduled, or Not Yet.
* **Follow-up Date** (`follow_up_date`): Enter the date when progress should be reviewed, if scheduled.
