# housing_manager_assessment_form - Help Guide
## Purpose
The housing_manager_assessment_form is designed to collect feedback and assessment from a housing manager. This form will help assess the manager's performance, leadership, communication, and teamwork skills.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill in your name and title (supervisor name) on the first page.
2. Select a date for the evaluation (Evaluation Date) on the second page.
3. Rate the manager's overall performance, leadership, communication, and teamwork skills using the rating scale provided.
4. Provide a brief comment for each of the rated skills.
5. Submit the form once you have completed all the fields.

## Field-by-Field Explanation

* **Supervisor Name** (Supervisor Name, Text, Optional): Enter your name and title for the housing manager being assessed.
* **Evaluation Date** (Evaluation Date, Date, Optional): Select the date you're evaluating the housing manager's performance.
* **Rating for Overall Performance** (Rating Overall Performance, Number, Optional): Rate the manager's overall performance using the scale provided.
* **Comment for Overall Performance** (Comment Overall Performance, Text, Optional): Provide a brief comment on the manager's overall performance.
* **Rating for Leadership** (Rating Leadership, Number, Optional): Rate the manager's leadership skills using the scale provided.
* **Comment for Leadership** (Comment Leadership, Text, Optional): Provide a brief comment on the manager's leadership skills.
* **Rating for Communication** (Rating Communication, Number, Optional): Rate the manager's communication skills using the scale provided.
* **Comment for Communication** (Comment Communication, Text, Optional): Provide a brief comment on the manager's communication skills.
* **Rating for Teamwork** (Rating Teamwork, Number, Optional): Rate the manager's teamwork skills using the scale provided.
* **Comment for Teamwork** (Comment Teamwork, Text, Optional): Provide a brief comment on the manager's teamwork skills.

## Tips

* Please ensure that you're evaluating the housing manager's performance fairly and accurately.
* If you're unsure about a particular skill, please provide a brief explanation in the comment field.
* Please submit the form once you have completed all the fields, as repeating the effort may lead to inconsistent data.
* If you've already filled out this form for the same manager, please do not submit another one.
