# Systems Evaluation Checklist - Help Guide
## Purpose
The Systems Evaluation Checklist form is a tool for project managers to evaluate and track the performance of their projects' systems. It helps project managers to identify areas that need improvement and make data-driven decisions.

## How To Complete This Form
To complete this form, please follow these steps:

1. Start by reviewing the project's current status, including any ongoing or past evaluations.
2. Fill out the form with the relevant information for your project.
3. Ensure that you've selected the correct evaluation method, frequency, and status for your project.
4. Enter the required information for each field, and use the notes and comments sections for any additional details.
5. Save your progress regularly, as the form is designed for ongoing evaluations.

## Field-by-Field Explanation

* **Checklist 1**: This is the first page of the evaluation form. You can start by reviewing the project manager's information and adding any notes or comments as needed.
* **Project Manager**: This field is for entering the project manager's name or contact information.
* **System Name**: Enter the name of the project's system being evaluated.
* **Evaluation Method**: Select the method used for evaluating the system (System, Team, or Manager).
* **Evaluation Date**: Enter the date of the evaluation.
* **Evaluation Frequency**: Select how often the system is evaluated (Monthly, Quarterly, or Yearly).
* **Evaluation Notes**: Enter any additional comments or notes about the evaluation.
* **Email**: Enter the project manager's email address (if applicable).
* **Phone**: Enter the project manager's phone number (if applicable).
* **Project Status**: Select the project's status (Active, Inactive, or On Hold).
* **Evaluation Status**: Select the status of the evaluation (Not Evaluated, In Progress, or Done).
* **Evaluation Comments**: Enter any additional comments about the evaluation.
* **Next Evaluation Date**: Enter the date of the next evaluation (if applicable).
* **Previous Evaluation Date**: Enter the date of the previous evaluation (if applicable).
* **Evaluation Frequency 2**: Select how often the system is evaluated (Monthly, Quarterly, or Yearly) for the next evaluation period.
* **Evaluation Frequency 3**: Select how often the system is evaluated (Monthly, Quarterly, or Yearly) for the next evaluation period.
* **Evaluation Comments 2**: Enter any additional comments about the evaluation.
* **Evaluation Status 2**: Select the status of the evaluation (Not Evaluated, In Progress, or Done) for the next evaluation period.

## Tips

* Ensure that you're using the correct evaluation method, frequency, and status for your project.
* Use the notes and comments sections to provide additional information about the project.
* Save your progress regularly, as the form is designed for ongoing evaluations.
* Review the form before submitting it to ensure that all required fields are completed.
