# Stage Progress Assessment - Help Guide
## Purpose
The Stage Progress Assessment form is used to evaluate the progress of a stage in a project or process. It helps assessors to provide a rating on the current stage's progress and provide feedback for future improvements.

## How To Complete This Form
To complete this form, please follow these steps:

1.  Navigate to the Stage Progress Assessment form.
2.  Select the Evaluation Criterion that best applies to the current stage.
3.  Choose the rating on the Rating Scale that reflects the current progress.
4.  If necessary, provide additional feedback in the Feedback Text field.

## Field-by-Field Explanation
* **Evaluation Criterion**: Choose an option from the list that best describes the current progress. This field is not required, but it will help assessors to provide a clear understanding of the stage's progress.
* **Rating Scale**: Select a rating from 1 to 10 that represents the current progress. The higher the rating, the better the progress. This field is not required, but it will help assessors to provide a numerical evaluation of the stage's progress.
* **Feedback Text**: If you have additional comments or suggestions, please provide them here. This field is not required, but it will help assessors to gain a deeper understanding of the stage's progress.

## Tips
* Please choose the Evaluation Criterion carefully, as it will help assessors to understand the stage's progress.
* The Rating Scale should reflect the overall progress, not just the current stage's progress.
* Use the Feedback Text field to provide concrete feedback that can help improve the stage's progress in the future.
