# Language Function Evaluation Survey - Help Guide

## Purpose
This form is designed to gather information about the language function of participants in a study or survey. The purpose of this form is to collect evaluations of language function from participants.

## How To Complete This Form
To complete this form, follow these steps:

1. Review the introduction page, which provides background information about the survey.
2. Select the options that best describe your language history, language abilities, and communication skills.
3. Choose the language production options that best reflect your language abilities.
4. Select the language understanding options that best reflect your comprehension of language.
5. Evaluate your language function by selecting the best option from the provided choices.
6. Add any additional comments or feedback about your experience.
