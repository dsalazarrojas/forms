# Property Evaluation Form - Help Guide
## Purpose
The Property Evaluation Form is used to collect data about properties, such as their location, type, size, use, condition, and other relevant details. This form is likely used for various purposes, including but not limited to:
* Evaluating properties for sale, lease, or ownership
* Assessing properties for condition and potential value
* Gathering information for inspection and assessment purposes

## How To Complete This Form
To complete the Property Evaluation Form, follow these steps:
1. Fill out the form from start to finish, ensuring all required fields are completed.
2. Enter accurate and relevant information for each field, and don't hesitate to add notes or comments if necessary.

## Field-by-Field Explanation

* **Property Location (1)** (`property_location`, `text`, required: false): Enter the location or address of the property being evaluated.
* **Property Type (2)** (`property_type`, `text`, required: false): Provide a description of the property type, e.g., apartment, condominium, single family, etc.
* **Property Size (3)** (`property_size`, `number`, required: false): Enter the size of the property in square feet or acres.
* **Property Use (4)** (`property_use`, `select_one`, required: false):
	+ Choose one of the following: Apartment, Condominium, Single Family, Townhouse, Vacation
* **Property Condition (5)** (`property_condition`, `select_multiple`, required: false):
	+ Choose multiple conditions from: Fair, Poor, Average, Good, Excellent
* **Inspection Date (6)** (`inspection_date`, `date`, required: false): Enter the date of the inspection, if applicable.
* **Inspector Name (7)** (`inspector_name`, `text`, required: false): Enter the name of the inspector, if applicable.
* **Property Status (8)** (`property_status`, `select_one`, required: false):
	+ Choose one of the following: For Sale, Leased, Owned, Pending, Under Contract, Other
* **Notes (9)** (`notes`, `note`, required: false): Enter any relevant notes or comments about the property.
* **Inspection Finding (10)** (`inspection_finding`, `text`, required: false): Enter any findings from the inspection, if applicable.
* **Property Value (11)** (`property_value`, `number`, required: false): Enter the value or estimated value of the property.
* **Property Value Range (12)** (`property_value_range`, `select_multiple`, required: false):
	+ Choose multiple values from: Low, Medium, High
* **Property Details (13)** (`property_details`, `text`, required: false): Enter additional details about the property.
* **Inspector License (14)** (`inspector_license`, `text`, required: false): Enter any relevant license information about the inspector.
