# Mock Interview Evaluation Form - Help Guide
## Purpose
The Mock Interview Evaluation Form is a survey used to gather feedback from candidates about their experiences during mock interviews. Your feedback will help recruiters improve the mock interview process.

## How To Complete This Form
1. Ensure you have participated in a mock interview and have thoughts about your experience.
2. Read each question carefully and answer honestly.
3. If a question does not apply, you can select "N/A" as an option.
4. Submit your feedback in the form below.

## Field-by-Field Explanation
* **Mock Interview Form**: This is the main section where you will be rating the mock interview.
	+ Type: Text input
	+ Required: Optional
	+ Explanation: Describe your experience during the mock interview. Be as detailed as possible.
* **Recruiter Rating**: Rate the recruiter who conducted the mock interview with you.
	+ Type: Select one
	+ Options: Very Good, Good, Fair, Poor
	+ Explanation: Rate how well the recruiter prepared you for the mock interview and how engaging they were.
* **Interviewers Rating**: Rate the interviewers who conducted the mock interview.
	+ Type: Select one
	+ Options: Very Good, Good, Fair, Poor
	+ Explanation: Rate how well the interviewers prepared you for the interview and how engaging they were.
* **Questions Asked**: List the questions that were asked during the mock interview.
	+ Type: Text input
	+ Required: Optional
	+ Explanation: Provide a list of the questions that were asked, even if they were not answered.
* **Comments**: Provide any additional comments about your experience.
	+ Type: Note input
	+ Required: Optional
	+ Explanation: Share any additional thoughts or comments about your experience.
* **Rating Scale**: Rate the rating scale used during the mock interview.
	+ Type: Select one
	+ Options: 1-2, 3-4, 5-6
	+ Explanation: Rate how well the rating scale was used to measure your performance.
* **Feedback**: Provide feedback to the recruiter.
	+ Type: Note input
	+ Required: Optional
	+ Explanation: Share any feedback or suggestions for improvement.
* **Interview Experience**: Rate the overall experience of the mock interview.
	+ Type: Select one
	+ Options: Very Good, Good, Fair, Poor
	+ Explanation: Rate how engaging and helpful the mock interview was.
* **Overall Experience**: Rate the overall experience of the mock interview.
	+ Type: Select one
	+ Options: Very Good, Good, Fair, Poor
	+ Explanation: Rate how satisfied you were with the overall experience.
* **Next Steps**: Indicate next steps for improvement.
	+ Type: Select one
	+ Options: Very Good, Good, Fair, Poor
	+ Explanation: Rate how likely you are to take the next steps in the process.
* **Mock Interview Format**: Rate the format of the mock interview.
	+ Type: Select multiple
	+ Options: Video Format, Audio Format, Text Format, Other
	+ Explanation: Rate how well the format of the mock interview met your needs.
* **Mock Interview Duration**: Rate the duration of the mock interview.
	+ Type: Select one
	+ Options: 15-30 Minutes, 30-60 Minutes, 1-2 Hours, More than 2 Hours
	+ Explanation: Rate how long the mock interview was and whether it was sufficient for you to prepare.
