# Banned Player Report - Help Guide
## Purpose
This form is designed to report a player who has been banned from our platform. Please fill out this form to report a player who has committed a rule violation or other misconduct.

## How To Complete This Form
To complete this form, follow these steps:
1. Fill in the reporter's username and email address on page 1.
2. Select the report date and time on page 2.
3. Provide the banned player's username and server name on page 3.
4. Choose the type of violation and its severity on page 4.
5. Describe the incident on page 5.
6. Add any witnesses or evidence on page 6.
7. Specify the type of evidence you have on page 7.
8. If applicable, select the previous violations and affected players on page 8.
9. Choose the recommended action for the player on page 9.
10. Suggest a ban duration if applicable on page 10.
11. Add any additional comments on page 11.
12. Choose how to follow up with the player on page 12.
13. Decide if you want to report anonymously on page 13.
14. Declare the truth of your report on page 14.
15. Finally, submit the form on page 15.

## Field-by-Field Explanation

* **Reporter Username** (`reporter_username`, `text`, required): This is the username of the person submitting the report.
* **Reporter Email** (`reporter_email`, `email`, required): This is the email address of the person submitting the report.
* **Report Date** (`report_date`, `date`, required): This is the date of the incident.
* **Report Time** (`report_time`, `time`, required): This is the time of the incident.
* **Banned Player Username** (`banned_player_username`, `text`, required): This is the username of the player being reported.
* **Player ID** (`player_id`, `text`, optional): If you have the player's ID, please provide it.
* **Server Name** (`server_name`, `text`, required): This is the server where the incident occurred.
* **Violation Type** (`violation_type`, `select_one`, required): This is the type of violation committed by the player (e.g., Cheating, Hacking, etc.).
* **Violation Category** (`violation_category`, `select_one`, required): This is the severity level of the violation (e.g., Minor Infraction, Serious Offense, etc.).
* **Incident Description** (`incident_description`, `text`, required): This is a detailed description of what happened.
* **Witnesses** (`witnesses`, `text`, optional): If anyone else saw the incident, list their usernames here.
* **Evidence Type** (`evidence_type`, `select_multiple`, required): Please select the type of evidence you have (e.g., Screenshot, Video Recording, etc.).
* **Evidence Links** (`evidence_links`, `text`, optional): If you have URLs to evidence, provide them here.
* **Previous Violations** (`previous_violations`, `select_one`, required): Has this player offended before? If yes, how many times?
* **Number of Affected Players** (`affected_players`, `number`, optional): If the player affected others, how many?
* **Game Mode** (`game_mode`, `text`, optional): What mode was the player playing when the incident occurred?
* **Match ID** (`match_id`, `text`, optional): If applicable, provide the match ID.
* **Recommended Action** (`recommended_action`, `select_one`, required): What should happen to the player?
* **Suggested Ban Duration** (`ban_duration`, `select_one`, optional): If the recommended action is a temporary ban, suggest a duration.
* **Reporter Statement** (`reporter_statement`, `text`, optional): Any additional comments from the reporter.
* **Contact Preference** (`contact_preference`, `select_one`, required): How do you want to follow up with the player?
* **Anonymous Report** (`anonymous_report`, `select_one`, required): Do you want to report anonymously?
* **Truth Declaration** (`truth_declaration`, `select_one`, required): Is this report accurate?
* **Submission Date** (`submission_date`, `date`, required): This is the date you're submitting the form.

## Tips
Please fill out as much information as possible to help us process your report effectively. If you're unsure about any field, please contact us for assistance.
