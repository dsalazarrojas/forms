# Coworking Space Evaluation Checklist - Help Guide
## Purpose
The Coworking Space Evaluation Checklist is a form used to evaluate the characteristics and attributes of a coworking space. It gathers information about the space's features, amenities, and suitability for use.

## How To Complete This Form
To complete this form, follow these steps:

1. Review each page of the form and ensure you have all the necessary information.
2. For each field, provide the required information in the corresponding format (e.g., select one option, enter a text response, etc.).
3. If a field is not required, you can leave it blank.
4. Ensure that all required fields are filled out before submitting the form.

## Field-by-Field Explanation
* **Coworking Space Evaluation Checklist** (`page`, `text`, required: `false`): 
	+ This is the first page of the form, which asks for a brief description of the coworking space.
* **Evaluation Form 1** (`evaluation_form_1`, `select_one`, required: `false`):
	+ Choose one option to describe the space's condition (e.g., "Excellent", "Fair", etc.).
* **Evaluation Form 2** (`evaluation_form_2`, `select_multiple`, required: `false`):
	+ Select all options that apply to describe the space's features (e.g., "High-Speed Internet", "Quiet Work Area", etc.).
* **Coworking Space Evaluation Checklist Page 2** (`page`, `note`, required: `false`):
	+ This is the second page of the form, which is for additional notes about the space.
* **Evaluation Form 3** (`evaluation_form_3`, `text`, required: `false`):
	+ Enter a brief description of the space's amenities.
* **Evaluation Form 4** (`evaluation_form_4`, `number`, required: `false`):
	+ Enter a numerical value to describe the space's size (e.g., "1000 sq. ft.").
* **Evaluation Form 5** (`evaluation_form_5`, `number`, required: `false`):
	+ Enter a numerical value to describe the space's seating capacity.
* **Evaluation Form 6** (`evaluation_form_6`, `date`, required: `false`):
	+ Enter a date for the space's availability.
* **Evaluation Form 7** (`evaluation_form_7`, `time`, required: `false`):
	+ Enter a time range for the space's usage.
* **Evaluation Form 8** (`evaluation_form_8`, `email`, required: `false`):
	+ Enter the contact email for the space's management or administrator.
* **Evaluation Form 9** (`evaluation_form_9`, `text`, required: `false`):
	+ Enter a brief description of the space's unique features.
* **Evaluation Form 10** (`evaluation_form_10`, `date`, required: `false`):
	+ Enter a date for the space's next scheduled maintenance.
* **Evaluation Form 11** (`evaluation_form_11`, `text`, required: `false`):
	+ Enter a brief description of the space's overall condition.
* **Evaluation Form 12** (`evaluation_form_12`, `date`, required: `false`):
	+ Enter a date for the space's next review or assessment.
