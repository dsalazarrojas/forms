> **# Hanaro Progress Sheet Report Template - Help Guide**
> 
> ## Purpose
> The purpose of this form is to collect information about a student's progress in reading and listening skills, and provide feedback for improvement.
> 
> ## How To Complete This Form
> To complete this form, follow these steps:
> 1. Fill in the student's name and ID as prompted.
> 2. Select the current level of reading and listening progress using the dropdown menu.
> 3. Choose the level of understanding from the dropdown menu for "Understand Teachers Discussions".
> 4. Provide any additional comments or feedback in the "Reading Progress Notes" and "Listening Progress Notes" fields, if necessary.
> 5. Enter the student's email address for "Reading Progress Email" and "Listening Progress Email" fields.
> 6. Set the date and time of the progress sheet using the "Progress Sheet Date" and "Progress Sheet Time" fields.
> 7. Select the name of the teacher who assigned the progress sheet.
> 8. Finally, select the overall level of progress using the dropdown menu for "Progress Sheet".
> 
> ## Field-by-Field Explanation
> 
> * **Student Name** (Student Name, text, required): Enter the student's name as per their official records.
> * **Student ID** (Student ID, number, required): Enter the student's ID number as per their official records.
> * **Teacher Name** (Teacher Name, text, required): Enter your name as the teacher responsible for this progress sheet.
> * **Reading Progress** (Reading Progress, select_one, required): Select the level of reading progress from the dropdown menu.
> * **Listening Progress** (Listening Progress, select_one, required): Select the level of listening progress from the dropdown menu.
> * **Understand Teachers Discussions** (Understand Teachers Discussions, select_multiple, required): Select the level of understanding from the dropdown menu.
> * **Reading Progress Notes** (Reading Progress Notes, note, optional): Provide any additional comments or feedback for the student's reading progress.
> * **Listening Progress Notes** (Listening Progress Notes, note, optional): Provide any additional comments or feedback for the student's listening progress.
> * **Reading Progress Email** (Reading Progress Email, email, required): Enter the student's email address for receiving progress reports.
> * **Listening Progress Email** (Listening Progress Email, email, required): Enter the student's email address for receiving progress reports.
> * **Progress Sheet Date** (Progress Sheet Date, date, required): Set the date of the progress sheet.
> * **Progress Sheet Time** (Progress Sheet Time, time, required): Set the time of the progress sheet.
> * **Assigned To** (Assigned To, select_one, optional): Select the name of the teacher who assigned the progress sheet.
> * **Progress Sheet** (Progress Sheet, select_one, required): Select the overall level of progress from the dropdown menu.
