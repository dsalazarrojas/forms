# Disability Assessment Form - Help Guide
## Purpose
This form is designed to assess your level of disability or impairment in various areas, including disability categories, symptoms, medical conditions, functional limitations, and educational impact. It will help healthcare professionals understand your situation and provide a comprehensive assessment.

## How To Complete This Form
- Review each field carefully and answer the questions accurately.
- If you are unsure about any question, please select the "Don't know" option.
- You can select multiple options for fields that allow it (e.g., "Disability Categories," "Symptoms," "Functional Limitations," and "Medical Professional").

## Field-by-Field Explanation
* **Disability Categories** (`disability_categories`, `select_multiple`, required: false):
  This field asks about your level of disability or impairment in various categories. Select all the categories that apply to you.
* **Symptoms** (`symptoms`, `select_multiple`, required: false):
  This field asks about the symptoms you are experiencing. Select all the symptoms that apply to you.
* **Medical Condition** (`medical_condition`, `select_one`, required: false):
  This field asks about your current medical condition. Select "Yes" if you have a medical condition, and "No" if you don't.
* **Medical Treatment** (`medical_treatment`, `select_one`, required: false):
  This field asks about your current medical treatment. Select "Yes" if you are receiving medical treatment, and "No" if you are not.
* **Functional Limitations** (`functional_limitations`, `select_multiple`, required: false):
  This field asks about your functional limitations. Select all the limitations that apply to you.
* **Educational Impact** (`educational_impact`, `select_multiple`, required: false):
  This field asks about the educational impact of your disability or impairment. Select all the areas that apply to you.
* **Disability Status** (`disability_status`, `select_one`, required: false):
  This field asks about your current disability status. Select "Active" if you are actively experiencing symptoms or limitations, and "Inactive" if you are not.
* **Medical Professional** (`medical_professional`, `select_multiple`, required: false):
  This field asks about your relationship with a medical professional. Select "Yes" if you have a medical professional, and "No" if you don't.
* **Educational Institution** (`educational_institution`, `select_one`, required: false):
  This field asks about your educational institution. Select "Yes" if you are currently enrolled, and "No" if you are not.

## Tips
- Make sure to answer each question accurately and honestly.
- If you are unsure about any question, please select the "Don't know" option.
- You can select multiple options for fields that allow it.
