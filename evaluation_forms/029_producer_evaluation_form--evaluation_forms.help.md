# producer_evaluation_form - Help Guide

## Purpose
The producer_evaluation_form is used to evaluate the quality of a crop produced by a specific producer. It gathers information on the producer's name, crop name, crop quality, and other details to assess and improve their operations.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the form page by page, providing information in each field.
2. Start with the first page, which includes fields for the producer's name and crop name.
3. Move on to the subsequent pages, which include fields for crop quality, evaluation date, evaluation time, and other details.
4. Use the options provided in the select fields (e.g., crop quality, evaluation score) or enter free-form text in the text fields (e.g., producer name, notes).

## Field-by-Field Explanation
### Producer Name (producer_name)
• **Producer Name** (`producer_name`, text, required/optional): Enter the name of the producer who produced the crop.

### Crop Name (crop_name)
• **Crop Name** (`crop_name`, text, required/optional): Enter the name of the crop being evaluated.

### Crop Quality (crop_quality)
• **Crop Quality** (`crop_quality`, select_one, required/optional): Select the quality of the crop from the options provided (High, Medium, Low).

### Evaluation Date (evaluation_date)
• **Evaluation Date** (`evaluation_date`, date, required/optional): Enter the date when the evaluation was conducted.

### Evaluation Time (evaluation_time)
• **Evaluation Time** (`evaluation_time`, time, required/optional): Enter the time when the evaluation was conducted.

### Evaluation Score (evaluation_score)
• **Evaluation Score** (`evaluation_score`, select_one, required/optional): Select the score of the evaluation from the options provided (Good, Medium, Low).

### Notes (notes)
• **Notes** (`notes`, text, required/optional): Enter any additional comments or observations about the evaluation.

### Email (email)
• **Email** (`email`, email, required/optional): Enter the email address of the producer or relevant contact information.

### Phone (phone)
• **Phone** (`phone`, text, required/optional): Enter the phone number of the producer or relevant contact information.

### Producer Comment (producer_comment)
• **Producer Comment** (`producer_comment`, text, required/optional): Enter any additional comments from the producer.

### Evaluation Comment (evaluation_comment)
• **Evaluation Comment** (`evaluation_comment`, text, required/optional): Enter any comments or observations about the evaluation process.

## Tips
* Make sure to fill out all required fields (e.g., producer name, crop name, evaluation date).
* Use the options provided in select fields (e.g., crop quality, evaluation score).
* Enter free-form text in text fields (e.g., producer comment, evaluation comment).
* Double-check your entries for accuracy and completeness before submitting the form.
