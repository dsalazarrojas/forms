# Effort Estimation Form - Help Guide
## Purpose
The effort estimation form is a tool to help project managers and team members estimate the effort required to complete a project, identify potential risks, and allocate resources. It is not intended for official project proposals or formal project plans.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the project name and brief description.
2. Provide the project start and end dates.
3. Select the project manager or team member responsible for the project.
4. Estimate the number of man-hours and man-days required to complete the project.
5. Estimate the duration of the project in hours and days.
6. Specify the budget allocated for the project.
7. Identify the type of resources required (Hardware, Software, or Personnel).
8. Select the specific resources and skills required.
9. Assess the risk type and impact.
10. Enter your risk probability and estimated hours required to mitigate the risk.
11. Add any additional notes or comments.
12. Enter the contact email and phone number of the project manager or team member.

## Field-by-Field Explanation

* **Project Name** (text): Enter the name of the project.
* **Project Description** (text): Enter a brief description of the project.
* **Project Start Date** (date): Enter the project start date.
* **Project End Date** (date): Enter the project end date.
* **Project Manager** (select_one): Select the project manager or team member responsible for the project (Project Lead, Team Lead, or Team Member).
* **Team Member** (select_multiple): Select the team members involved in the project (Member 1, Member 2, Member 3).
* **Estimated Man Hours** (number): Estimate the total man-hours required to complete the project.
* **Estimated Man Hours Per Week** (number): Estimate the average man-hours required per week.
* **Estimated Man Days** (number): Estimate the total man-days required to complete the project.
* **Estimated Duration** (time): Estimate the project duration in hours and days.
* **Budget Allocated** (number): Estimate the budget allocated for the project.
* **Resource Type** (select_one): Select the type of resources required (Hardware, Software, or Personnel).
* **Resources Allocated** (select_multiple): Select the specific resources required (Resource 1, Resource 2, Resource 3).
* **Manpower Allocated** (select_multiple): Select the specific skills required (Skill 1, Skill 2, Skill 3).
* **Risk Type** (select_one): Select the risk type (High, Medium, or Low).
* **Risk Impact** (select_one): Select the risk impact (High, Medium, or Low).
* **Risk Probability** (number): Estimate the risk probability.
* **Notes** (text): Enter any additional notes or comments.
* **Email** (email): Enter the contact email of the project manager or team member.
* **Phone** (text): Enter the contact phone number of the project manager or team member.
