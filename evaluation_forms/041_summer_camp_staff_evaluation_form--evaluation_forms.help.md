# summer_camp_staff_evaluation_form - Help Guide
## Purpose
This form is used by authorized personnel to evaluate a camper's performance during a summer camp session.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the camper's name in the "Camper Name" field.
2. Select the camper's grade in the "Grade" field. Note: This field is optional.
3. Describe the camper's performance in the "Performance" field. Note: This field is optional.
4. Record the camper's attendance date in the "Attendance" field. This field is required.
5. Select whether the camper had proper counselor supervision in the "Counselor" field. Note: This field is optional.
6. Describe the camper's conduct in the "Conduct" field. Note: This field is optional.
7. Note the camper's hygiene level in the "Hygiene" field. Note: This field is optional.
8. Check whether the camper followed the dress code in the "Dress Code" field. Note: This field is optional.
9. Describe any food-related incidents or issues in the "Food" field. Note: This field is optional.
10. Add any additional notes or comments about the camper's experience in the "Notes" field. Note: This field is optional.

## Field-by-Field Explanation

* **Camper Name** (`camper_name`, text, required): Enter the name of the camper being evaluated.
* **Grade** (`camper_grade`, text, optional): Enter the camper's grade. Note: This is an optional field.
* **Performance** (`camper_performance`, text, optional): Describe the camper's performance during the session.
* **Attendance** (`camper_attendance`, date, required): Record the date of the camper's attendance in the session.
* **Counselor** (`camper_counselor`, text, optional): Select whether the camper had proper counselor supervision.
* **Conduct** (`camper_conduct`, text, optional): Describe the camper's conduct during the session.
* **Hygiene** (`camper_hygiene`, text, optional): Note the camper's hygiene level.
* **Dress Code** (`camper_dress`, select_one, optional): Check whether the camper followed the dress code.
* **Food** (`camper_food`, text, optional): Describe any food-related incidents or issues.
* **Notes** (`camper_notes`, note, optional): Add any additional notes or comments about the camper's experience.
