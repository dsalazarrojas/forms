# School Administrator Evaluation Form - Help Guide
## Purpose

This form is designed to evaluate the performance and skills of school administrators. It assesses their ability to manage school operations, interact with students and colleagues, and make informed decisions. This form is intended to provide a comprehensive evaluation of the school administrator's strengths and weaknesses, helping to identify areas for improvement and development.

## How To Complete This Form

1. Please answer the questions in the form by selecting the appropriate options or entering text in the designated fields.
2. If a field is marked as required, you must provide an answer to complete the form.
3. Review your answers carefully before submitting the form, as this will help ensure accurate and honest feedback.

## Field-by-Field Explanation

* **Performance** (`school_administrator_performance`, select_multiple, required): This question asks about the administrator's performance in their role. Select one or multiple options that describe their level of performance:
	+ Yes: The administrator performs their duties well.
	+ No: The administrator performs their duties poorly or not at all.
* **Communication** (`communication`, text, required): Describe the administrator's communication style and how they interact with students, teachers, and parents.
* **Leadership Skills** (`leadership_skills`, select_one, required): This question assesses the administrator's leadership skills. Select an option that best describes their ability to lead:
	+ Yes: The administrator is an effective leader.
	+ No: The administrator is not an effective leader.
* **Time Management** (`time_management`, number, optional): If applicable, describe how the administrator manages their time and prioritizes tasks.
* **Problem Solving** (`problem_solving`, note, optional): If applicable, describe how the administrator approaches problems and finds solutions.
* **Decision Making** (`decision_making`, date, required): Enter the date of the last evaluation or review of the administrator's decision-making process.
* **Adaptability** (`adaptability`, time, required): This question assesses the administrator's ability to adapt to changing situations. Enter the time they took to adapt:
* **Feedback and Consequences** (`feedback_and_consequences`, select_one, optional): This question asks about the administrator's response to feedback and consequences. Select an option that best describes their approach:
	+ Yes: The administrator takes feedback and consequences well.
	+ No: The administrator does not take feedback and consequences well.
* **School Administrator Attitude** (`school_administrator_attitude`, text, required): Describe the administrator's attitude towards their role and the school.
* **School Administrator Role** (`school_administrator_role`, select_multiple, required): Select one or multiple options that describe the administrator's role:
	+ Yes: The administrator is in a leadership role.
	+ No: The administrator is not in a leadership role.
* **School Administrator Expectations** (`school_administrator_expectations`, text, optional): If applicable, describe the administrator's expectations and goals for their role.
* **School Administrator Support** (`school_administrator_support`, select_one, optional): This question assesses the administrator's support system. Select an option that best describes their support:
	+ Yes: The administrator has a strong support system.
	+ No: The administrator does not have a strong support system.
* **School Administrator Leadership Style** (`school_administrator_leadership_style`, select_one, required): This question asks about the administrator's leadership style. Select an option that best describes their approach:
	+ Yes: The administrator is an effective leader.
	+ No: The administrator is not an effective leader.
* **School Administrator Performance Goals** (`school_administrator_performance_goals`, select_multiple, required): Select one or multiple options that describe the administrator's performance goals:
	+ Yes: The administrator sets and achieves performance goals.
	+ No: The administrator does not set or achieve performance goals.
* **School Administrator Evaluation** (`school_administrator_evaluation`, select_multiple, required): Select one or multiple options that describe the evaluation methods:
	+ Yes: The administrator is evaluated frequently.
	+ No: The administrator is not evaluated frequently.
* **School Administrator Evaluation Frequency** (`school_administrator_evaluation_frequency`, select_multiple, required): Select one or multiple options that describe the frequency of evaluations:
	+ Yes: The administrator is evaluated regularly.
	+ No: The administrator is not evaluated regularly.
* **School Administrator Evaluation Form Comments** (`school_administrator_evaluation_form_comments`, text, optional): Enter any comments or feedback about the evaluation form.
* **School Administrator Additional Comments** (`school_administrator_additional_comments`, text, optional): Enter any additional comments or feedback about the administrator.
* **School Administrator Recommendation** (`school_administrator_recommendation`, select_multiple, required): Select one or multiple options that describe the recommendation:
	+ Yes: The administrator is recommended.
	+ No: The administrator is not recommended.
* **School Administrator Recommendation For** (`school_administrator_recommendation_for`, text, optional): If applicable, describe the reason for the recommendation.
* **School Administrator Recommendation Reason** (`school_administrator_recommendation_reason`, text, optional): If applicable, describe the reason for the recommendation.
* **School Administrator Recommendation Date** (`school_administrator_recommendation_date`, date, optional): Enter the date of the recommendation.
* **School Administrator Recommendation By** (`school_administrator_recommendation_by`, text, optional): Enter the person or organization making the recommendation.
* **School Administrator Recommendation Time** (`school_administrator_recommendation_time`, time, optional): Enter the time of the recommendation.

Note: This help guide is not exhaustive, please review the form carefully and seek clarification if you need further assistance.
