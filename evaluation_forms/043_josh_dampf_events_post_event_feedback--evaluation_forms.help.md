# josh_dampf_events_post_event_feedback - Help Guide
## Purpose
This form is designed to gather feedback and evaluation from event attendees to improve future events.

## How To Complete This Form
To complete this form, follow these steps:

1. Read through each page carefully and fill in the fields as instructed.
2. Make sure to answer all required fields (marked as `true`).
3. Double-check your answers for accuracy and completeness.

## Field-by-Field Explanation
### Page 1: Post Event Survey
* **Post Event Survey**: This page is an introductory section, providing a space for event attendees to write their thoughts, comments, or questions about the event. (Required: false)
* **Evaluation (Select One)**: Choose one of the options to rate the event: 1 or 2.
	+ 1: The event was excellent and met my expectations.
	+ 2: The event was okay, but had some minor issues.
* **Feedback (Text)**: Share your thoughts, comments, or suggestions about the event. This is an optional field, but your feedback is valuable to us!

## Tips
* Make sure to fill in the form carefully and accurately.
* If you're unsure about any question, ask your colleagues or the event organizer for clarification.
* If you've already filled out this form, do not fill it out again.
