# Mentee Progress Check In - Help Guide
## Purpose
The Mentee Progress Check In form is used to track and assess progress on specific goals, provide progress dates and times, and offer feedback and comments for the mentee. This form is a crucial tool for mentors or coaches to evaluate progress, identify areas for improvement, and guide the mentee towards achieving their goals.

## How To Complete This Form

To complete this form, follow these steps:

1. Enter the mentee's name and select the relevant goals they are working on.
2. Rate the mentee's progress on each goal using the corresponding value field.
3. Select the progress status for each goal (e.g., Not Started, In Progress, Completed).
4. Provide progress details for each goal, including any additional comments.
5. Choose the frequency of progress check-ins (e.g., Daily, Weekly, Bi-Weekly).
6. Leave any additional feedback or comments for the mentee.
7. Optionally, enter progress dates and times for each check-in.

## Field-by-Field Explanation

* **Mentee Name**: Enter the mentee's name, as they will be the one filling out this form.
* **Goal 1, Goal 2, Goal 3**: Select the goals the mentee is working on for each of these fields.
* **Current Progress**: Enter a brief description of the mentee's current progress.
* **Progress Date**: Enter the date of the progress check-in (optional).
* **Progress Time**: Enter the time of the progress check-in (optional).
* **Goal 1 Value, Goal 2 Value, Goal 3 Value**: Rate the mentee's progress on each goal using the corresponding value field.
* **Goal 1 Progress Status, Goal 2 Progress Status, Goal 3 Progress Status**: Select the progress status for each goal (e.g., Not Started, In Progress, Completed).
* **Goal 1 Progress Details, Goal 2 Progress Details, Goal 3 Progress Details**: Provide additional comments or details about the mentee's progress on each goal.
* **Progress Frequency**: Select the frequency of progress check-ins (e.g., Daily, Weekly, Bi-Weekly).
* **Mentee Feedback**: Leave any feedback or comments for the mentee.
* **Additional Comments**: Provide any additional comments or thoughts about the mentee's progress.
* **Progress Check In 2, Progress Check In 3**: Enter the dates of previous progress check-ins (optional).

Note: Some fields are marked as required, meaning they must be filled out before submitting the form. Please fill out all required fields to ensure accurate progress tracking and feedback.
