# Homework Record Form - Help Guide

## Purpose
This form is designed to record and track student homework records. It collects information about the student's name, assignment title, due date, and status. Administrators can use this form to monitor student progress, identify areas where students may need additional support, or review completed assignments.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the student's first name in the "First Name" field.
2. Enter the student's last name in the "Last Name" field.
3. Enter the assignment title in the "Assignment Title" field.
4. Select the due date for the assignment from the calendar.
5. Select the status of the assignment from the dropdown menu:
   * Completed: The assignment has been completed by the student.
   * Incomplete: The assignment is not yet complete.
   * Pending: The assignment is due or overdue.
6. Enter the teacher's name in the "Teacher Name" field (optional).
7. Click the "Submit" button to save the record.

## Field-by-Field Explanation
* **First Name** (`student_first_name`, text, required/optional): Enter the student's first name.
* **Last Name** (`student_last_name`, text, required/optional): Enter the student's last name.
* **Assignment Title** (`assignment_title`, text, required/optional): Enter the title of the homework assignment.
* **Assignment Due Date** (`assignment_due_date`, date, required/optional): Select the due date for the assignment using the calendar.
* **Status** (`assignment_status`, select_one, required): Choose the status of the assignment:
	+ Completed: The assignment has been completed.
	+ Incomplete: The assignment is not yet complete.
	+ Pending: The assignment is due or overdue.
* **Teacher Name** (`teacher_name`, text, required/optional): Enter the teacher's name (if applicable).

## Tips
* Make sure to accurately select the status to reflect the current state of the assignment.
* Use the calendar to select the correct due date.
* Keep the teacher's name up to date if applicable.
* Review and update the record regularly to ensure accurate tracking.
