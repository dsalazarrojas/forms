# Mental Wellness Initiative Evaluation Form - Help Guide
## Purpose
The Mental Wellness Initiative Evaluation Form is a comprehensive form designed to gather information about your mental wellness status, experiences, and preferences. This form will help us better understand your specific needs and provide more effective support.

## How To Complete This Form
1. Please fill out the form in a step-by-step manner, one page at a time.
2. Start with the first page and read each question carefully before answering.
3. Use the provided options for select fields, and select all that apply for multi-select fields.
4. Enter your contact information and date/time of completion in the last section.

## Field-by-Field Explanation

- **mentalWellnessFormPart1** (Page 1, text): This is the first section of the form where you can provide any relevant information about your mental wellness status.
- **formSection** (Page 2, select one): Please select the option that best describes your current mental wellness situation.
	+ Option 1: Feeling overwhelmed or struggling to cope
	+ Option 2: Experiencing mild symptoms of anxiety or depression
	+ Option 3: Other (please specify in mentalWellnessFormPart1)
- **programType** (Page 3, select multiple): Please select all the programs or services that you are interested in or currently participating in for mental wellness initiatives.
	+ Option 4: Mindfulness-based programs
	+ Option 5: Group therapy sessions
	+ Option 6: One-on-one counseling
- **participantName** (Page 4, text): Please enter your name to help us identify you in our records.
- **contactInformation** (Page 5, email): Please enter your email address so we can contact you for follow-up.
- **date** (Page 6, date): Enter the date you are completing this form.
- **time** (Page 7, time): Enter the time you are completing this form.
- **notes** (Page 8, text): This is an optional section for any additional comments or information you'd like to share.
- **mental_wellness_initiative_evaluation_form_part9** (Page 9, select one): Please select the option that best describes your current mental wellness situation.
	+ Option 7: Feeling stressed or overwhelmed
	+ Option 8: Experiencing burnout or exhaustion
	+ Option 9: Other (please specify in mentalWellnessFormPart9)
- **mental_wellness_initiative_evaluation_form_part10** (Page 10, select multiple): Please select all the programs or services that you are interested in or currently participating in for mental wellness initiatives.
	+ Option 10: Mindfulness-based programs
	+ Option 11: Group therapy sessions
	+ Option 12: One-on-one counseling
