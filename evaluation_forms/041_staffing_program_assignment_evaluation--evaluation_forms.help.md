# Staffing Program Assignment Evaluation - Help Guide
## Purpose
The Staffing Program Assignment Evaluation form is designed to gather information about the progress of a staffing program assignment, enabling team members and managers to track and assess performance.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the Assignment Title field with a clear and concise description of the assignment.
2. Enter the Team Member ID of the person assigned to the task.
3. Select the start date and start time of the assignment using the date and time pickers.
4. Choose the end date and end time of the assignment.
5. Enter the location where the assignment was or will be performed.
6. Choose the current status of the assignment from the options provided.
7. Select the performance metrics that apply to the assignment from the options provided.

## Field-by-Field Explanation
* **Assignment Title** (assignment_title): A brief description of the assignment, e.g., "Project X - Task A" or "Event Planning - Event Z".
* **Team Member ID** (team_member_id): The unique identifier for the team member assigned to the task, e.g., "JDOE-1234".
* **Assignment Start Date** (assignment_start_date): The date the assignment started, e.g., "2022-01-01".
* **Assignment Start Time** (assignment_start_time): The time the assignment started, e.g., "08:00".
* **Assignment End Date** (assignment_end_date): The date the assignment ended or is expected to end, e.g., "2022-01-15".
* **Assignment End Time** (assignment_end_time): The time the assignment ended or is expected to end, e.g., "17:00".
* **Assignment Location** (assignment_location): The location where the assignment was or will be performed, e.g., "New York City".
* **Assignment Status** (assignment_status): Choose one of the provided options:
	+ Active: Assignment is currently active and ongoing.
	+ Pending: Assignment is pending or awaiting further action.
	+ Cancelled: Assignment has been cancelled or abandoned.
	+ Completed: Assignment has been finished and closed.
* **Performance Metrics** (performance_metrics): Select all that apply from the provided options:
	+ On Time: Assignment was completed on the scheduled time.
	+ On Schedule: Assignment was completed within the scheduled timeframe.
	+ Overdue: Assignment was completed later than scheduled.
	+ Delayed: Assignment was delayed due to unforeseen circumstances.
	+ Cancelled: Assignment was cancelled or abandoned.
	+ Completed: Assignment was finished and closed.

## Tips
- Make sure to fill out all required fields to ensure accurate tracking and evaluation of the assignment.
- Use the correct format for dates and times (YYYY-MM-DD and HH:MM, respectively).
- If you're unsure about any field or have questions, refer to this help guide for clarification.
