# Nonprofit Advocacy Toolkit Feedback Evaluation Form - Help Guide
## Purpose
The purpose of this form is to gather feedback from users on the Nonprofit Advocacy Toolkit, its usability, and potential areas of improvement. We value your opinions and suggestions to enhance the toolkit and provide a better experience for all users.

## How To Complete This Form
1. Please answer each question as thoroughly and honestly as possible.
2. If a field is optional, you can skip it if you prefer not to provide information.
3. For multiple choice questions, select the option that best describes your experience with the toolkit.

## Field-by-Field Explanation

* **Form Intro** (`form_intro`): This section provides a brief introduction to the form and its purpose.
* **User Info** (`user_info`): Please provide your contact information so we can follow up with you if needed.
* **Evaluation Scale** (`evaluation_scale`): On a scale of 1-5, rate how helpful the toolkit was in your work.
* **Evaluation Scale Label** (`evaluation_scale_label`): Describe the evaluation scale you used.
* **Evaluation Scale Had Help** (`evaluation_scale_had_help`): If you had help while using the toolkit, describe what kind of help you received.
* **Evaluation Scale Would Help** (`evaluation_scale_would_help`): If you would have liked help while using the toolkit, describe what kind of help you would have liked.
* **Evaluation Scale Comment** (`evaluation_scale_comment`): Provide any additional comments or suggestions related to the evaluation scale.
* **Resources** (`resources`): Select the resources you found most helpful while using the toolkit.
* **Resources Label** (`resources_label`): Describe the resources you selected.
* **Resources Comment** (`resources_comment`): Provide any additional comments or suggestions related to the resources.
* **Feedback Resources** (`feedback_resources`): Provide feedback on the resources provided with the toolkit.
* **Evaluation Scale Had Improvement** (`evaluation_scale_had_improvement`): If you saw improvement in your work while using the toolkit, describe what you saw.
* **Evaluation Scale Would Improve** (`evaluation_scale_would_improve`): If you think the toolkit could be improved, describe what you would like to see changed.
* **Evaluation Scale Comments** (`evaluation_scale_comments`): Provide any additional comments or suggestions related to the evaluation scale.
* **Form Complete** (`form_complete`): Select how likely you are to complete the toolkit's form in the future.
* **Evaluation Scale Would Recommend** (`evaluation_scale_would_recommend`): If you would recommend the toolkit to a colleague, explain why.
* **Evaluation Scale Would Recommend Comments** (`evaluation_scale_would_recommend_comments`): Provide any additional comments or suggestions related to the recommendation.
* **Evaluation Scale Would Recommend Why** (`evaluation_scale_would_recommend_why`): Explain why you would recommend the toolkit.
* **Evaluation Scale Comments to Organizers** (`evaluation_scale_comments_to_organizers`): Provide any additional comments or suggestions related to the toolkit's organizers.
* **Feedback Organizers** (`feedback_organizers`): Provide feedback on the toolkit's organizers.
* **Evaluation Scale Comments to Organizers** (`evaluation_scale_comments_to_organizers`): Provide any additional comments or suggestions related to the toolkit's comments.
* **Evaluation Scale Improvement Suggestions** (`evaluation_scale_improvement_suggestions`): If you have any suggestions for improvement, provide them here.
* **Evaluation Scale Improvement Suggestions to Organizers** (`evaluation_scale_improvement_suggestions_organizers`): If you have any suggestions for improvement to the toolkit's organizers, provide them here.
* **Evaluation Scale Improvement Suggestions Implementation** (`evaluation_scale_improvement_suggestions_implementation`): If you would like to see any of your suggestions implemented, describe how and why.
