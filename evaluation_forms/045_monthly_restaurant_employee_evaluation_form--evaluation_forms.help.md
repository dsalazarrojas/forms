# Monthly Restaurant Employee Evaluation Form - Help Guide
## Purpose
The purpose of this form is to help restaurant management track and evaluate employee performance on a monthly basis.

## How To Complete This Form
To complete this form, please follow these steps:

* Fill out the form for each employee, providing feedback on their performance for the month.
* Use the scale provided to rate the employee's performance in each category.
* Be sure to provide specific examples or feedback to support your ratings.
* Complete all required fields, but feel free to leave optional fields blank.
* Save and submit the form once completed.

## Field-by-Field Explanation

* **Employee Name**: The name of the employee being evaluated.
	+ Type: text
	+ Required: false
* **Manager Name**: The name of the person completing the evaluation.
	+ Type: text
	+ Required: false
* **Department**: The department or section of the restaurant the employee works in.
	+ Type: text
	+ Required: false
* **Month Completed**: The date range for which this evaluation is being completed.
	+ Type: time
	+ Required: false
* **Evaluation Date**: The date on which this evaluation is being completed.
	+ Type: date
	+ Required: false
* **Overall Performance**: A rating of the employee's overall performance for the month.
	+ Type: number
	+ Required: false
* **Communication Skills**: A rating of the employee's communication skills.
	+ Type: number
	+ Required: false
* **Teamwork**: A rating of the employee's ability to work with others.
	+ Type: number
	+ Required: false
* **Adaptability**: A rating of the employee's ability to adapt to changing situations.
	+ Type: number
	+ Required: false
* **Initiative**: A rating of the employee's initiative and proactivity.
	+ Type: number
	+ Required: false
* **Time Management**: A rating of the employee's ability to manage their time effectively.
	+ Type: number
	+ Required: false
* **Attendance**: A rating of the employee's attendance and punctuality.
	+ Type: number
	+ Required: false
* **Punctuality**: A rating of the employee's punctuality.
	+ Type: number
	+ Required: false
* **Job Knowledge**: A rating of the employee's knowledge of their job.
	+ Type: number
	+ Required: false
* **Initiative Attitude**: A rating of the employee's attitude towards taking initiative.
	+ Type: number
	+ Required: false
* **Leadership**: A rating of the employee's leadership skills.
	+ Type: number
	+ Required: false
* **Initiative Quality**: A rating of the quality of the employee's initiative.
	+ Type: number
	+ Required: false
* **Initiative Quantity**: A rating of the quantity of the employee's initiative.
	+ Type: number
	+ Required: false
* **Initiative Effort**: A rating of the effort put into the employee's initiative.
	+ Type: number
	+ Required: false
* **Initiative Effectiveness**: A rating of the effectiveness of the employee's initiative.
	+ Type: number
	+ Required: false
* **Overall Score**: The overall score for the employee's performance.
	+ Type: number
	+ Required: false
* **Feedback**: Any feedback or comments you have for the employee.
	+ Type: text
	+ Required: false
* **Action Items**: Any specific actions you recommend the employee work on.
	+ Type: text
	+ Required: false

Note: Please refer to the scale provided for guidance on how to rate each category.
