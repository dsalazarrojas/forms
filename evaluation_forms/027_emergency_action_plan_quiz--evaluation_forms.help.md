# Emergency Action Plan Quiz - Help Guide
## Purpose

The Emergency Action Plan Quiz is a tool to help employees prepare for emergency situations by evaluating their response to fire-related hazards. This form should only be filled out by employees who have undergone proper training and are familiar with emergency protocols.

## How To Complete This Form

1. Review each section of the form carefully.
2. For each question, select the most accurate response based on your training and experience.
3. If a question does not apply to your specific situation, indicate "N/A" (Not Applicable).
4. Once you have completed the form, review your responses to ensure accuracy and completeness.

## Field-by-Field Explanation

* **First Responder**: This section is for identifying the first person to respond to the emergency situation. Please select the most appropriate response based on your role and responsibility.
	+ Type: Text
	+ Required: No
* **Fire**: This section is for selecting the most likely fire hazard. Choose the one that best describes the emergency situation.
	+ Type: Select One
	+ Required: No
	+ Options: fire alarm, fire drill, fire extinguisher, fire sprinkler system
* **Alarm**: This section is for selecting the alarm system in place in the building. Please choose the most accurate response.
	+ Type: Number
	+ Required: No
* **Alarm Sound**: This section is for selecting the alarm sound used in the building. Please choose the most accurate response.
	+ Type: Select Multiple
	+ Required: No
	+ Options: Strobe, Horn, Bell, None, Siren
* **Alarm Source**: This section is for selecting the source of the alarm system. Please choose the most accurate response.
	+ Type: Select Multiple
	+ Required: No
	+ Options: Fire alarm, Smoke detector, Horn, Strobe, None
* **Alarm Procedure**: This section is for describing the procedure to follow in case of an alarm. Please provide a brief description.
	+ Type: Text
	+ Required: No
* **Emergency Contact**: This section is for selecting the person to contact in case of an emergency. Please choose the most appropriate response.
	+ Type: Select One
	+ Required: No
	+ Options: Manager, Fire Department, '911', Other
* **Other Emergency Contact**: This section is for entering the name of the other emergency contact.
	+ Type: Text
	+ Required: No
* **Emergency Contact Phone**: This section is for entering the phone number of the emergency contact.
	+ Type: Text
	+ Required: No
* **Fire Evacuation**: This section is for selecting the evacuation route. Please choose the most accurate response.
	+ Type: Select Multiple
	+ Required: No
	+ Options: Stairwell, Elevator, Hallway, Other
* **Other Fire Evacuation**: This section is for entering the alternative evacuation route.
	+ Type: Text
	+ Required: No
* **Fire Fighting**: This section is for selecting the fire fighting equipment. Please choose the most accurate response.
	+ Type: Select Multiple
	+ Required: No
	+ Options: Fire extinguisher, Fire blanket, Fire hydrant, Other
* **Other Fire Fighting**: This section is for entering the other fire fighting equipment.
	+ Type: Text
	+ Required: No
* **Assembling**: This section is for selecting the assembly point. Please choose the most accurate response.
	+ Type: Select Multiple
	+ Required: No
	+ Options: At the assembly point, Near the assembly point, In the hallway, Other
* **Other Assembling**: This section is for entering the alternative assembly point.
	+ Type: Text
	+ Required: No
* **Accountable**: This section is for selecting the accountable person. Please choose the most accurate response.
	+ Type: Select Multiple
	+ Required: No
	+ Options: Manager, Assistant Manager, Other
* **Other Accountable**: This section is for entering the name of the other accountable person.
	+ Type: Text
	+ Required: No
* **Accountable Name**: This section is for entering the name of the accountable person.
	+ Type: Text
	+ Required: No
* **Alarm Check**: This section is for selecting whether to check the alarm system regularly. Please choose the most accurate response.
	+ Type: Select Multiple
	+ Required: No
	+ Options: 'True', 'False'
* **Other Alarm Check**: This section is for entering the other alarm check frequency.
	+ Type: Text
	+ Required: No
* **Alarm Check Frequency**: This section is for entering the frequency of alarm checks.
	+ Type: Number
	+ Required: No
* **Alarm and Exit**: This section is for selecting whether to alarm and exit the area. Please choose the most accurate response.
	+ Type: Select Multiple
	+ Required: No
