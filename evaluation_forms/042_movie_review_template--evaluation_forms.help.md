# Movie Review Template - Help Guide
## Purpose
The Movie Review Template is designed to collect evaluations of movies. It is intended for users to input title and rating information about a movie they have watched.

## How To Complete This Form
To complete this form, follow these steps:
1. Enter the title of the movie you are reviewing.
2. Type a brief review of your experience watching the movie in the text field.
3. Assign a rating between 0 and 5 to express your opinion about the movie's quality.
4. Select a recommendation option to express whether you would recommend the movie to others.

## Field-by-Field Explanation
* **Enter Movie Title**: This field is required to input the title of the movie you are reviewing. Please type it accurately.
* **Enter Movie Review**: This optional field is intended for you to type a brief review of your experience watching the movie. It's not required but is helpful for others to understand your opinion.
* **Rating**: This field is required to input a numerical rating between 0 and 5 that represents your opinion about the movie's quality.
* **Rating Scale**: This optional field is a scale to rate how you rate the movie. Please select one of the options from 0 to 5.
* **Recommend**: This optional field is a checkbox where you can select whether you would recommend the movie to others.
