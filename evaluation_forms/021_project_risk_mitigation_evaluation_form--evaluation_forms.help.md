# Project Risk Mitigation Evaluation Form - Help Guide
## Purpose
The Project Risk Mitigation Evaluation Form is designed to collect and evaluate project risk mitigation strategies. It's intended for project managers to assess the risks associated with a project and identify potential areas for improvement.

## How To Complete This Form
To complete this form, follow these steps:

1. Provide a brief description of the project and its scope
2. Identify potential risks associated with the project
3. Evaluate the level of risk for each identified risk
4. Document the risk description, frequency, and impact
5. Assign a project manager ID for each risk

## Field-by-Field Explanation
- **Project Name** (`project_name`, text, required/optional): Enter a brief description of the project and its scope.
- **Project Risk Description** (`risk_description`, text, required/optional): Provide a detailed description of each risk identified in the project.
- **Risk Level** (`risk_level`, select_one, required/optional): Select the level of risk for each identified risk:
	+ Low
	+ Medium
	+ High
- **Frequency** (`risk_frequency`, select_one, required/optional): Select the frequency of each risk:
	+ Daily
	+ Weekly
	+ Monthly
	+ Quarterly
	+ Yearly
- **Impact** (`risk_impact`, select_one, required/optional): Select the impact of each risk:
	+ Low
	+ Medium
	+ High
- **Project Manager ID** (`project_manager_id`, text, required/optional): Enter a unique ID for each project manager responsible for the risk.
- **Risk Description ID** (`risk_description_id`, text, required/optional): Enter a unique ID for each risk description.
- **Risk Level ID** (`risk_level_id`, text, required/optional): Enter a unique ID for each risk level.
- **Frequency ID** (`risk_frequency_id`, text, required/optional): Enter a unique ID for each risk frequency.
- **Impact ID** (`risk_impact_id`, text, required/optional): Enter a unique ID for each risk impact.

## Tips
* Be thorough when describing each risk and its associated frequency and impact.
* Use the project manager ID to track which team member is responsible for each risk.
* Use the risk description ID to reference the original risk description.
* Use the risk level, frequency, and impact IDs to track the risk assessment for each risk.
