# Time And Attendance Vendor Evaluation Form - Help Guide
## Purpose
This form is designed to gather feedback on the performance and effectiveness of time and attendance vendors. It helps administrators evaluate vendors and make informed decisions about their use.

## How To Complete This Form
To complete this form, follow these steps:

1.  Review the form questions and fields carefully to ensure you have all the necessary information to answer them accurately.
2.  Fill in the required fields with your honest and thoughtful feedback.
3.  Make sure to review your answers before submitting the form.

## Field-by-Field Explanation

*   **Vendor Name**: The name of the vendor being evaluated. Please enter the name of the vendor as it is known to you. 
    *   Type: text
    *   Required: false
*   **Rating**: Rate the vendor's overall performance on a scale of 1-5. This will help us understand their strengths and weaknesses.
    *   Type: select_one
    *   Options: 1, 2, 3, 4, 5
    *   Required: false
*   **Comments**: Provide any additional comments or observations about the vendor's performance. This will help us understand their strengths and weaknesses.
    *   Type: text
    *   Required: false
*   **Time Of Day**: The time of day when the vendor's system was used. Please enter in 24-hour format (e.g. 14:00).
    *   Type: date
    *   Required: false
*   **Time Of Week**: The time of week when the vendor's system was used. Please enter in the format "Monday" to "Sunday".
    *   Type: time
    *   Required: false
*   **Time Of Month**: The date when the vendor's system was last used. Please enter in the format "YYYY-MM-DD".
    *   Type: date
    *   Required: false
*   **Evaluation Period**: A brief description of the evaluation period. Please provide context about the time frame of use.
    *   Type: text
    *   Required: false
*   **Evaluation Period Start**: The start date of the evaluation period.
    *   Type: date
    *   Required: false
*   **Evaluation Period End**: The end date of the evaluation period.
    *   Type: date
    *   Required: false
*   **Vendor Relationship**: Select all that apply to describe your relationship with the vendor.
    *   Type: select_multiple
    *   Options: Primary, Secondary, Tertiary, None
    *   Required: false
*   **Primary Contact**: The primary contact person at the vendor.
    *   Type: text
    *   Required: false
*   **Vendor Email**: The email address of the vendor.
    *   Type: email
    *   Required: false
*   **Vendor Phone**: The phone number of the vendor.
    *   Type: text
    *   Required: false

Please make sure to review your answers carefully before submitting the form. If you have any questions or concerns, please contact the administrator for assistance.
