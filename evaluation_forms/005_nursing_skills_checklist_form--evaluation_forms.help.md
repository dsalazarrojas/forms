# Nursing Skills Checklist Form - Help Guide

## Purpose
The Nursing Skills Checklist Form is designed to assess the level of proficiency of a nurse's skills and knowledge in various medical areas. This form is meant to be completed by nurses or healthcare professionals to provide a comprehensive evaluation of their abilities. It is used to ensure that nurses are equipped to provide high-quality care to patients and meet the standards of medical practice.

## How To Complete This Form

To complete this form, follow these steps:

1. Begin by filling out the "Medical Assessment" section, which asks for a brief description of the nurse's work experience and qualifications.
2. Then, proceed to the "Medical Skills" section, where you will select the level of proficiency you possess in areas such as Basic First Aid, Advanced First Aid, Critical Care, and Emergency Response.
3. Next, move on to the "Skills Level" section, where you will select the level of proficiency you possess in various medical skills.
4. The "Medical Knowledge" section requires you to select the level of knowledge you possess in different areas of medical knowledge.
5. In the "Medical Certification" section, you will indicate whether you hold a medical certification or not.
6. The "Medical Equipment" section asks you to select the level of proficiency you possess in the use of medical equipment.
7. The "Medical Communication" section requires you to rate the quality of your communication skills with patients.
8. The "Medical Documentation" section asks you to select the level of accuracy and completeness of your medical documentation.
9. In the "Medical Care" section, you will rate the quality of your care provided to patients.
10. The "Medical Emergency" section requires you to select the level of proficiency you possess in handling medical emergencies.
11. The "Medical Supervision" section asks you to indicate whether you work under supervision or not.
12. The "Medical Evaluation" section requires you to report the completion status of your evaluations.
13. The "Medical Supervision Notes" section asks you to report the completion status of your supervision notes.
14. The "Medical Knowledge Notes" and "Medical Skills Notes" sections are text fields where you can provide additional information about your knowledge and skills.

## Field-by-Field Explanation

* **Medical Assessment** (`medical_assessment`, text, optional): Provide a brief description of your work experience and qualifications.
* **Medical Skills** (`medical_skills`, select_one, optional):
	+ **Basic First Aid**: Select the level of proficiency you possess in Basic First Aid.
	+ **Advanced First Aid**: Select the level of proficiency you possess in Advanced First Aid.
	+ **Critical Care**: Select the level of proficiency you possess in Critical Care.
	+ **Emergency Response**: Select the level of proficiency you possess in Emergency Response.
* **Skills Level** (`skills_level`, select_multiple, optional):
	+ **Beginner**: Select if you have basic knowledge and experience in a medical skill.
	+ **Intermediate**: Select if you have some experience and knowledge in a medical skill.
	+ **Advanced**: Select if you have extensive experience and knowledge in a medical skill.
	+ **Proficient**: Select if you have mastered a medical skill.
	+ **Expert**: Select if you are an expert in a medical skill.
* **Medical Knowledge** (`medical_knowledge`, select_one, optional):
	+ **Basic**: Select if you have basic knowledge in a medical field.
	+ **Intermediate**: Select if you have some knowledge in a medical field.
	+ **Advanced**: Select if you have extensive knowledge in a medical field.
	+ **Proficient**: Select if you have mastered a medical field.
	+ **Expert**: Select if you are an expert in a medical field.
* **Medical Certification** (`medical_certification`, select_one, optional):
	+ **Certified**: Select if you hold a medical certification.
	+ **Non-certified**: Select if you do not hold a medical certification.
	+ **In progress**: Select if you are in the process of obtaining a medical certification.
* **Medical Equipment** (`medical_equipment`, select_multiple, optional):
	+ **Basic**: Select if you have basic knowledge of medical equipment.
	+ **Intermediate**: Select if you have some knowledge of medical equipment.
	+ **Advanced**: Select if you have extensive knowledge of medical equipment.
	+ **Proficient**: Select if you have mastered the use of medical equipment.
	+ **Expert**: Select if you are an expert in the use of medical equipment.
* **Medical Communication** (`medical_communication`, select_one, optional):
	+ **Excellent**: Select if your communication skills with patients are excellent.
	+ **Good**: Select if your communication skills with patients are good.
	+ **Fair**: Select if your communication skills with patients are fair.
	+ **Poor**: Select if your communication skills with patients are poor.
* **Medical Documentation** (`medical_documentation`, select_multiple, optional):
	+ **Accurate**: Select if your medical documentation is accurate and complete.
	+ **Inaccurate**: Select if your medical documentation is inaccurate.
	+ **Incomplete**: Select if your medical documentation is incomplete.
	+ **Not applicable**: Select if medical documentation is not applicable in your work.
* **Medical Care** (`medical_care`, select_one, optional):
	+ **Excellent**: Select if the quality of your care provided to patients is excellent.
	+ **Good**: Select if the quality of your care provided to patients is good.
	+ **Fair**: Select if the quality of your care provided to patients is fair.
	+ **Poor**: Select if the quality of your care provided to patients is poor.
* **Medical Emergency** (`medical_emergency`, select_multiple, optional):
	+ **Emergency**: Select if you have experience in handling medical emergencies.
	+ **Non-emergency**: Select if you do not have experience in handling medical emergencies.
	+ **In progress**: Select if you are in the process of handling medical emergencies.
* **Medical Supervision** (`medical_supervision`, select_one, optional):
	+ **Supervised**: Select if you work under supervision.
	+ **Unsupervised**: Select if you do not work under supervision.
	+ **Not applicable**: Select if supervision is not applicable in your work.
* **Medical Evaluation** (`medical_evaluation`, select_one, optional):
	+ **Completed**: Select if you have completed evaluations.
	+ **Not Completed**: Select if you have not completed evaluations.
	+ **In progress**: Select if you are in the process of completing evaluations.
* **Medical Supervision Notes** (`medical_supervision_notes`, select_one, optional):
	+ **Completed**: Select if your supervision notes are completed.
	+ **Not Completed**: Select if your supervision notes are not completed.
	+ **In progress**: Select if you are in the process of completing supervision notes.
* **Medical Knowledge Notes** (`medical_knowledge_notes`, text, optional): 
	+ Provide additional information about your knowledge in medical fields.
* **Medical Skills Notes** (`medical_skills_notes`, text, optional): 
	+ Provide additional information about your skills in medical fields.
