# Start And Stop Evaluation Form - Help Guide

## Purpose
This form is used to record the start and stop dates of an evaluation, as well as the reasons for stopping it. It is intended for use in evaluations that can be started and stopped, such as in research or project management settings.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the **start_date** field with the date when the evaluation began.
2. Fill in the **end_date** field with the date when the evaluation ended.
3. In the **evaluation_type** field, select the category that best describes the evaluation type.
4. In the **evaluation_type_option_1**, **evaluation_type_option_2**, and **evaluation_type_option_3** fields, provide additional information about the evaluation type, if necessary.
5. In the **reasons_for_stopping** field, select the reason why the evaluation was stopped from the options provided.
6. If the reason for stopping is not listed, you can select **other** and provide a brief description of the reason in the **reasons_for_stopping_other** field.
7. In the **reasons_for_stopping_option_1**, **reasons_for_stopping_option_2**, and **reasons_for_stopping_option_3** fields, select the specific reason why the evaluation was stopped, if applicable.

## Field-by-Field Explanation

* **start_date**: Enter the date when the evaluation began.
* **end_date**: Enter the date when the evaluation ended.
* **evaluation_type**: Select the category that best describes the evaluation type.
* **evaluation_type_option_1**: If necessary, provide additional information about the evaluation type.
* **evaluation_type_option_2**: If necessary, provide additional information about the evaluation type.
* **evaluation_type_option_3**: If necessary, provide additional information about the evaluation type.
* **reasons_for_stopping**: Select the reason why the evaluation was stopped from the options provided.
* **reasons_for_stopping_other**: If the reason for stopping is not listed, select **other** and provide a brief description of the reason.
* **reasons_for_stopping_option_1**: If necessary, select the specific reason why the evaluation was stopped.
* **reasons_for_stopping_option_2**: If necessary, select the specific reason why the evaluation was stopped.
* **reasons_for_stopping_option_3**: If necessary, select the specific reason why the evaluation was stopped.
* **reasons_for_stopping_option_4**: If necessary, select the specific reason why the evaluation was stopped.

## Tips
- Make sure to fill in all required fields accurately and completely.
- If you are unsure about a field, refer to your project manager or research team leader for guidance.
- This form is intended for recording evaluations that can be started and stopped, so ensure you have the necessary permissions to fill it out.
