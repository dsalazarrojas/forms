# Healthcare Innovation Pilot Project Evaluation Form - Help Guide
## Purpose
This form is designed to collect feedback and evaluations on healthcare pilot projects. It allows healthcare professionals to assess the impact, challenges, and overall effectiveness of these projects.

## How To Complete This Form
To complete this form, please follow these steps:

1. Ensure that you have the project ID, if available.
2. Input the project's evaluation date and the date when you completed the form.
3. Provide your rating for the project, using the scale from 0 to 10.
4. Enter your comments for the project in the comments field.
5. If applicable, choose the submission status of the form, whether Not Started, In Progress, or Completed.
6. Choose the overall category for the project, which is High, Medium, or Low.
7. Enter your thoughts and opinions on the project in the overall comments field.
8. If applicable, input the overall rating for the project.
9. Choose the overall status of the form, which can be Active, InActive, Draft, or Completed.
10. Finally, ensure that you have filled out all required fields, and submit the form.

## Field-by-Field Explanation
* **Project ID (Project ID, number, Optional)**: This field is not required but recommended for project identification purposes.
* **Project Name (prophet_name, text, Optional)**: This field is for the name of the project participant.
* **Evaluation Date (evaluation_date, date, Optional)**: This field is for the date of the project's evaluation.
* **Rating (Rating, number, Optional)**: This field is for the rating of the project, using a scale from 0 to 10.
* **Comments (Comments, text, Optional)**: This field is for any comments or suggestions on the project.
* **Impact (Impact, text, Optional)**: This field is for the project's impact.
* **Recommendations (prophets_recommendations, text, Optional)**: This field is for any recommendations on the project.
* **Challenges (Challenges, text, Optional)**: This field is for any challenges faced during the project.
* **Evaluation Score (Evaluation Score, number, Optional)**: This field is for the project's evaluation score.
* **Evaluation Comments (Evaluation Comments, text, Optional)**: This field is for any evaluation comments on the project.
* **Rating Category (rating_category, select_one, Optional)**: This field is for the category of the project's rating.
* **Overall Comments (Overall Comments, text, Optional)**: This field is for any thoughts or opinions on the project.
* **Overall Rating (Overall Rating, number, Optional)**: This field is for the overall rating of the project, using a scale from 0 to 10.
* **Overall Comments 2 (Overall Comments 2, text, Optional)**: This field is for any overall comments on the project.
* **Evaluation Form Completion Date (Evaluation Form Completion Date, date, Optional)**: This field is for the date when you completed the form.
* **Submission Status (Submission Status, select_one, Optional)**: This field is for the status of the submission, which can be Not Started, In Progress, or Completed.
* **Evaluation Form Status (Evaluation Form Status, select_multiple, Optional)**: This field is for the overall status of the form, which can be Active, InActive, Draft, or Completed.
* **Overall Comments 3 (Overall Comments 3, text, Optional)**: This field is for any overall comments on the project.
* **Evaluation Score Category (Evaluation Score Category, select_one, Optional)**: This field is for the category of the project's evaluation score.
* **Overall Rating 2 (Overall Rating 2, number, Optional)**: This field is for the overall rating of the project, using a scale from 0 to 10.
* **Form ID (Form ID, number, Optional)**: This field is not required but can be used for identification purposes.
* **Evaluation Form Status (Evaluation Form Status, select_multiple, Optional)**: This field is for the overall status of the form, which can be Active, InActive, Draft, or Completed.

## Tips
* Please ensure that all required fields are filled out before submitting the form.
* For date fields, use the correct format (e.g., 2022-01-01).
* For select fields, choose one of the given options.
* For numerical fields, input a value between 0 and 10.
* For free-text fields, provide clear and concise comments.
