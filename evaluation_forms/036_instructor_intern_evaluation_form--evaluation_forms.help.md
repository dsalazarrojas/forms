# Instructor Intern Evaluation Form - Help Guide
## Purpose
This form is used to evaluate the performance of interns working with instructors.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the relevant facility and intern from the options provided.
2. Indicate whether or not the intern's work has met expectations.
3. Choose the date and time of the evaluation.
4. Add any additional comments or feedback for the intern.
5. Save or submit your evaluation.

## Field-by-Field Explanation
- **Facility** (`Facility name`, select_multiple): Select the facilities where you have worked with the intern.
  * Examples: You can select multiple facilities if the intern has worked at multiple locations.
- **Intern** (`Intern 1` `Intern 2`, select_one): Select the name of the intern being evaluated.
  * Choose one of the available options to indicate which intern you are evaluating.
- **Feedback** (`Yes` `No`, select_one): Indicate whether the intern's work has met your expectations.
  * Select 'Yes' if the intern's work has met expectations, 'No' otherwise.
- **Date** (`Date`, date): Choose the date of the evaluation.
  * Use the format MM/DD/YYYY.
- **Time** (`Time`, time): Choose the time of the evaluation.
  * Use the format HH:MM AM/PM.
- **Note** (`Note`, note): Add any additional comments or feedback for the intern.
  * This field is optional and can be used to provide more detailed feedback.
- **Submitted** (`Submitted`, date): This field is not required and is automatically populated when you submit the form.
  * It shows the date and time when you submitted the form.
