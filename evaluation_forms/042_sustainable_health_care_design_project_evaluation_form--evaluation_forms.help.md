# sustainable_health_care_design_project_evaluation_form - Help Guide
## Purpose
The "Sustainable Health Care Design Project Evaluation Form" is a tool designed to help evaluate the sustainability features and performance of a project. It gathers information on various aspects of the project, including project details, stakeholder engagement, site characteristics, and overall performance.

## How To Complete This Form

1. Review each field carefully to understand its purpose and required information.
2. Complete each field as accurately and thoroughly as possible.
3. Submit your completed form for review and evaluation.

## Field-by-Field Explanation

* **Project Details** (`project_details`, `text`, required: `false`): Enter a brief description of the project, including the project name, location, and any relevant details.
* **Sustainability Features** (`sustainability_features`, `select_multiple`, required: `false`): Select all the sustainability features that apply to your project from the list:
	+ Green Building and Energy Efficiency
	+ Water Conservation
	+ Material Selection and Waste Management
	+ Sustainable Materials and Products
	+ Commissioning and Building Performance
* **Stakeholder Engagement** (`stakeholder_engagement`, `select_one`, required: `false`): Indicate the level of stakeholder engagement in the project:
	+ High
	+ Medium
	+ Low
* **Site Characteristics** (`site_characteristics`, `select_multiple`, required: `false`): Select the site characteristics that apply to your project from the list:
	+ Building Type - Hospital
	+ Building Type - Healthcare Office
	+ Number of Floors - 1-2
	+ Number of Floors - 3-5
	+ Number of Floors - 6 or more
* **Project Team** (`project_team`, `select_one`, required: `false`): Select the primary project team member from the list:
	+ Architect/Designer
	+ Engineer
	+ Contractor
	+ Owner
	+ Facility Manager
* **Project Status** (`project_status`, `select_one`, required: `false`): Indicate the current project status:
	+ In Progress
	+ On Hold
	+ Completed
* **Overall Performance** (`overall_performance`, `select_one`, required: `false`): Assess the overall performance of the project:
	+ High
	+ Medium
	+ Low
* **Project Location** (`project_location`, `select_one`, required: `false`): Select the project location:
	+ Urban
	+ Rural
	+ Suburban
* **Project Size** (`project_size`, `number`, required: `false`): Enter the numerical value of the project size.
* **Project Budget** (`project_budget`, `number`, required: `false`): Enter the numerical value of the project budget.
* **Project Start Date** (`project_start_date`, `date`, required: `false`): Enter the start date of the project.
* **Project End Date** (`project_end_date`, `date`, required: `false`): Enter the end date of the project.

## Tips

* Please ensure that all required fields are completed before submitting the form.
* If you are unsure about any field, please seek guidance from a project representative or form administrator.
* The form is designed to be completed by project team members or stakeholders involved in the project.
* Please review and revise your responses before submitting the form to ensure accuracy and completeness.
