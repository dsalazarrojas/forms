# Due Diligence Assessment Questionnaire - Help Guide
## Purpose
This form is designed to gather information about a company's due diligence.

## How To Complete This Form
1. Fill out the company's basic contact information: Company Name, Contact Name, Contact Email, and Contact Phone.
2. Determine the entity type by selecting 'Yes' or 'No' from the dropdown menu. If 'No' is selected, enter the entity type in the text field.
3. Provide the entity type description if the entity type is 'Other'.
4. Fill out the address, city, and country of the company.
5. Determine the entity status by selecting 'Active' or 'Inactive' from the dropdown menu. If 'Inactive' is selected, enter a brief description of the status in the text field.
6. Determine the ownership type by selecting 'Yes' or 'No' from the dropdown menu. If 'No' is selected, enter the ownership type in the text field.
7. Determine the entity size by selecting 'Yes' or 'No' from the dropdown menu. If 'No' is selected, enter the entity size in the text field.

## Field-by-Field Explanation

* **Company Name** (`company_name`): Enter the name of the company.
* **Contact Name** (`contact_name`): Enter the name of the contact person.
* **Contact Email** (`contact_email`): Enter the email address of the contact person.
* **Contact Phone** (`contact_phone`): Enter the phone number of the contact person.
* **Entity Type** (`entity_type`): Select 'Yes' if the company is a legal entity (such as a corporation or partnership), 'No' otherwise.
* **Entity Type Other** (`entity_type_other`): This field is optional and should be used to describe a company that is not a traditional legal entity.
* **Entity Type Other Description** (`entity_type_other_description`): Provide a description of the company's entity type if it is not a traditional legal entity.
* **Address** (`address`): Enter the company's address.
* **City** (`city`): Enter the city of the company's address.
* **State** (`state`): Enter the state of the company's address.
* **Zip** (`zip`): Enter the zip code of the company's address.
* **Country** (`country`): Enter the country of the company's address.
* **Date of Establishment** (`date_of_establishment`): Enter the date when the company was established.
* **Entity Status** (`entity_status`): Select 'Active' if the company is operational, 'Inactive' otherwise. If 'Inactive' is selected, enter a brief description of the status in the text field.
* **Entity Status Other** (`entity_status_other`): This field is optional and should be used to describe a company status that is not 'Active' or 'Inactive'.
* **Entity Status Other Description** (`entity_status_other_description`): Provide a description of the company's status if it is not 'Active' or 'Inactive'.
* **Industry** (`industry`): Enter the industry the company operates in.
* **Ownership Type** (`ownership_type`): Select 'Yes' if the company is a private entity, 'No' otherwise. If 'No' is selected, enter the ownership type in the text field.
* **Ownership Type Other** (`ownership_type_other`): This field is optional and should be used to describe a company ownership type that is not 'Private' or 'Public'.
* **Ownership Type Other Description** (`ownership_type_other_description`): Provide a description of the company's ownership type if it is not 'Private' or 'Public'.
* **Entity Size** (`entity_size`): Select 'Yes' if the company is large, 'No' otherwise. If 'No' is selected, enter the entity size in the text field.
* **Entity Size Other** (`entity_size_other`): This field is optional and should be used to describe a company size that is not 'Large' or 'Small'.
* **Entity Size Other Description** (`entity_size_other_description`): Provide a description of the company's size if it is not 'Large' or 'Small'.
* **Notes** (`notes`): Add any additional comments or notes about the company.

Note: This help guide is intended to be a general explanation of the form. If you need more detailed information or clarification on specific fields, please refer to the form's fields' labels and hints for additional guidance.
