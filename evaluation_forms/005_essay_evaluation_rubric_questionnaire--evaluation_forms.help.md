# Essay Evaluation Rubric Questionnaire - Help Guide
## Purpose
This form is used to collect feedback and scores on an essay evaluation rubric. It is designed to provide a structured way to assess the quality and effectiveness of an essay.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill out the fields as required by entering the relevant information. The fields are:
	* Essay Evaluation Rubric: This is a text field where you can enter a brief description of the essay evaluation rubric.
	* Student Info: This is a text field where you can enter information about the student, such as their name and ID number.
	* Rubric Score 1-7: These are number fields where you can enter scores for each rubric criteria.
	* Feedback 1: This is a text field where you can enter feedback on the essay.

## Field-by-Field Explanation
* **Essay Evaluation Rubric** (`essay_evaluation_rubric`, text, optional): Enter a brief description of the essay evaluation rubric used.
* **Student Info** (`student_info`, text, optional): Enter information about the student, such as their name and ID number.
* **Rubric Score 1** (`rubric_score_1`, number, optional): Enter a score for the first rubric criteria.
* **Rubric Score 2** (`rubric_score_2`, number, optional): Enter a score for the second rubric criteria.
* **Feedback 1** (`feedback_1`, text, optional): Enter feedback on the essay.
* **Rubric Score 3** (`rubric_score_3`, number, optional): Enter a score for the third rubric criteria.
* **Rubric Score 4** (`rubric_score_4`, number, optional): Enter a score for the fourth rubric criteria.
* **Rubric Score 5** (`rubric_score_5`, number, optional): Enter a score for the fifth rubric criteria.
* **Rubric Score 6** (`rubric_score_6`, number, optional): Enter a score for the sixth rubric criteria.
* **Rubric Score 7** (`rubric_score_7`, number, optional): Enter a score for the seventh rubric criteria.

## Tips
* Make sure to enter the correct scores and feedback for each rubric criteria.
* Review each field carefully before submitting the form to ensure accurate and fair feedback.
* Enter scores and feedback based on the rubric criteria provided.
