# Evidence Based Practice Project Evaluation Plan - Help Guide
## Purpose
This form is a tool to help project managers and evaluators create a comprehensive evaluation plan for a project.

## How To Complete This Form
To complete this form, follow the steps outlined above.

## Field-by-Field Explanation

* **Project Title** (`project_title`, `text`, required/optional): Enter a brief title for the project.
* **Project Lead** (`project_lead`, `text`, required/optional): Enter the name of the project lead.
* **Project Description** (`project_description`, `text`, required/optional): Write a brief description of the project.
* **Project Start Date** (`project_start_date`, `date`, required/optional): Enter the project's start date.
* **Project End Date** (`project_end_date`, `date`, required/optional): Enter the project's end date.
* **Project Start Time** (`project_start_time`, `time`, required/optional): Enter the project's start time.
* **Project End Time** (`project_end_time`, `time`, required/optional): Enter the project's end time.
* **Project Location** (`project_location`, `text`, required/optional): Enter the project's location.
* **Project Team** (`project_team`, `text`, required/optional): List the project team members.
* **Project Status** (`project_status`, `text`, required/optional): Enter the current project status.
* **Evidence Base** (`evidence_base`, `text`, required/optional): Describe the evidence base used for the evaluation.
* **Project Goal** (`project_goal`, `text`, required/optional): Enter the project goal.
* **Expected Outcome** (`expected_outcome`, `text`, required/optional): Specify the expected outcome of the project.
* **Evaluation Frequency** (`evaluation_frequency`, `text`, required): Choose the frequency of evaluation.
* **Evaluation Method** (`evaluation_method`, `select_multiple`, required): Select the evaluation method(s) to be used.
* **Evaluation Cycle Frequency** (`evaluation_cycle_frequency`, `text`, required/optional): Enter the frequency of the evaluation cycle (if applicable).
* **Evaluation Cycle Start Date** (`evaluation_cycle_start_date`, `date`, required/optional): Enter the start date of the evaluation cycle (if applicable).
* **Evaluation Cycle End Date** (`evaluation_cycle_end_date`, `date`, required/optional): Enter the end date of the evaluation cycle (if applicable).
* **Evaluation Method Description** (`evaluation_method_description`, `text`, required/optional): Provide a description of the evaluation method.
* **Evaluation Cycle Frequency** (`evaluation_cycle_frequency`, `select_one`, required): Choose the frequency of the evaluation cycle (if applicable).
* **Evidence Base Citation** (`evidence_base_citation`, `text`, required/optional): Enter the citation for the evidence base (if applicable).
* **Evidence Base Reference** (`evidence_base_reference`, `text`, required/optional): Enter the reference for the evidence base (if applicable).
* **Evidence Base Description** (`evidence_base_description`, `text`, required/optional): Describe the evidence base.

## Tips
* Please fill out all required fields.
* Make sure to provide accurate and relevant information.
* This form is a guide, and you may need to adapt it to your specific project needs.
* If you're unsure about a field, contact the project lead or team members for clarification.
