# N95 Fit Test Form - Help Guide
## Purpose
The N95 Fit Test Form is used to record the details of an N95 fit test. It is a crucial process to ensure that respirators fit properly and safely on a person's face. This form helps to document the results of the fit test, which is essential for maintaining the integrity of the respirator and ensuring the health and safety of the testee.

## How To Complete This Form
1. Fill in the testee's name, age, height, weight, and gender.
2. Record the fit tester's name and location where the test was conducted.
3. Enter the date and time of the test.
4. Record the type and model of the respirator being tested.
5. Select the correct fit test result and seal area from the provided options.
6. If necessary, add any comments or notes for the testee.
7. Record the seal pressure value and respirator size.
8. Select the correct size of the respirator being tested.
9. Fill in any additional notes for the fit tester.

## Field-by-Field Explanation

* **Testee Name** (`testee_name`, text, required): Enter the full name of the testee, as it is written on their identification.
* **Fit Tester Name** (`fit_tester_name`, text, required): Enter the full name of the fit tester conducting the test.
* **Test Location** (`test_location`, text, required): Record the location where the fit test was conducted.
* **Test Date** (`test_date`, date, required): Enter the date when the fit test was conducted.
* **Test Time** (`test_time`, time, required): Enter the time when the fit test was conducted.
* **Respirator Mask** (`respirator_mask`, text, required): Record the model and type of respirator being tested.
* **Seal Area** (`seal_area`, text, required): Record the area used for the seal test.
* **Fit Test Result** (`fit_test_result`, select_one, required): Select from the options provided to record the result of the fit test.
* **Comments** (`comments`, text, required): Enter any additional comments or notes about the testee.
* **Seal Pressure Value** (`seal_pressure_value`, number, required): Record the pressure value used for the seal test.
* **Testee Gender** (`testee_gender`, select_one, required): Select from the options provided to record the testee's gender.
* **Respirator Size** (`respirator_size`, select_one, required): Select from the options provided to record the size of the respirator being tested.
* **Testee Age** (`testee_age`, number, required): Enter the age of the testee.
* **Testee Weight** (`testee_weight`, number, required): Enter the weight of the testee.
* **Testee Height** (`testee_height`, number, required): Enter the height of the testee.
* **Respirator Size Fit Test** (`respirator_size_fit_test`, select_one, required): Select from the options provided to record the fit test result.
* **Fit Tester Notes** (`fit_tester_notes`, text, required): Enter any additional notes for the fit tester.
* **Seal Tester Notes** (`seal_tester_notes`, text, required): Enter any additional notes for the seal tester.
* **Respirator Type** (`respirator_type`, text, required): Record the type of respirator being tested.
* **Respirator Model** (`respirator_model`, text, required): Record the model of the respirator being tested.
* **Seal Area Test** (`seal_area_test`, text, required): Record any additional information about the seal area test.
* **Fit Tester ID** (`fit_tester_id`, text, required): Enter the ID of the fit tester conducting the test.
