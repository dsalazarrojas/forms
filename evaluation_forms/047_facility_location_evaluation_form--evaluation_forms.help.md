# Facility Location Evaluation Form - Help Guide
## Purpose
This form is used to collect and evaluate information about a facility's location, including its address, phone number, email, and map-related information.

## How To Complete This Form
To complete this form, follow these steps:

1. Start by reading the introduction page, which provides background information about the form.
2. Enter the facility's address in the "Facility Address" field.
3. Provide a description of the facility in the "Facility Description" field.
4. Enter the facility's phone number in the "Facility Phone" field.
5. Enter the facility's email address in the "Facility Email" field.
6. For the "Location Map" field, select the type of map you would like to use from the dropdown menu (Satellite, Mapbox, Google, or Mapquest).
7. In the "Location Map Scale" field, select the scale of the map you would like to display (1, 500, 1000, 2000, or 3000).
8. In the "Location Map Zoom" field, select the zoom level of the map you would like to display (0, 1, 2, 3, or 4).
9. Finally, select the type of map you would like to display in the "Location Map Type" field (Road Map, Satellite Map, Hybrid Map, or Terrain Map).

## Field-by-Field Explanation

* **Introduction**:
	+ This is a note field that provides a brief description of the form's purpose.
* **Facility Address**:
	+ Enter the facility's physical address, including the street number and name.
* **Facility Description**:
	+ Provide a brief description of the facility, including its purpose, features, and services offered.
* **Facility Phone**:
	+ Enter the facility's phone number.
* **Facility Email**:
	+ Enter the facility's email address.
* **Location Map URL**:
	+ Enter the URL of the location map of the facility.
* **Location Map**:
	+ Select the type of map you would like to use to display the facility's location (Satellite, Mapbox, Google, or Mapquest).
* **Location Map Scale**:
	+ Select the scale of the map you would like to display (1, 500, 1000, 2000, or 3000).
* **Location Map Zoom**:
	+ Select the zoom level of the map you would like to display (0, 1, 2, 3, or 4).
* **Location Map Type**:
	+ Select the type of map you would like to display (Road Map, Satellite Map, Hybrid Map, or Terrain Map).

Tips:

* Make sure to enter accurate and up-to-date information to ensure that the map is displayed correctly.
* If you're not sure about the type of map or scale, feel free to ask for help or clarification.
* The form will not be submitted until you have completed all the required fields.
