# Event Feedback Form - Help Guide
## Purpose
The Event Feedback Form is designed to collect feedback from event attendees on various aspects of the event they attended. This feedback will help event organizers evaluate their performance and make necessary improvements for future events.

## How To Complete This Form
To complete the form, follow these steps:

1. Please provide the title of the event you attended in the **Event Title** field.
2. Rate your overall experience of the event in the **Rating** field on a scale from 1 to 5.
3. If you have any comments or feedback about the event, please provide them in the **Comments** field.
4. Describe the event in the **Event Description** field.
5. Rate the event presentation as **Excellent**, **Good**, or **Poor** in the **Event Presentation** field.
6. Select multiple options for the event venue in the **Event Venue** field as **Excellent**, **Good**, or **Poor**.
7. Rate the event presentation quality as **Excellent**, **Good**, or **Poor** in the **Event Presentation Quality** field.
8. Rate the event services as **Excellent**, **Good**, or **Poor** in the **Event Services** field.
9. Rate the event fulfillment as **Excellent**, **Good**, or **Poor** in the **Event Fulfillment** field.
10. Rate the overall experience as **Excellent**, **Good**, or **Poor** in the **Overall Experience** field.
11. Select multiple options for the event attendance in the **Event Attendance** field as **Excellent**, **Good**, or **Poor**.
12. If you have any suggestions for future events, please provide them in the **Event Suggestion** field.
13. If you would like to be contacted about this feedback, please provide your email address in the **Email** field.
14. If you would like to be contacted about this feedback, please provide your phone number in the **Phone** field.
15. If you would like to provide your name, please do so in the **Name** field.

## Field-by-Field Explanation

* **Event Title** (`event_title`, text, optional): Provide the title of the event you attended.
* **Rating** (`rating`, number, optional): Rate your overall experience of the event on a scale from 1 to 5.
* **Comments** (`comments`, text, optional): Provide any comments or feedback you have about the event.
* **Event Description** (`event_description`, text, optional): Describe the event you attended.
* **Event Presentation** (`event_presentation`, select_one, required): Rate the event presentation as **Excellent**, **Good**, or **Poor**.
* **Event Venue** (`event_venue`, select_multiple, optional): Select multiple options for the event venue as **Excellent**, **Good**, or **Poor**.
* **Event Presentation Quality** (`event_presentation_quality`, select_one, required): Rate the event presentation quality as **Excellent**, **Good**, or **Poor**.
* **Event Services** (`event_services`, select_one, required): Rate the event services as **Excellent**, **Good**, or **Poor**.
* **Event Fulfillment** (`event_fulfillment`, select_one, required): Rate the event fulfillment as **Excellent**, **Good**, or **Poor**.
* **Overall Experience** (`overall_experience`, select_one, required): Rate the overall experience as **Excellent**, **Good**, or **Poor**.
* **Event Attendance** (`event_attendance`, select_multiple, optional): Select multiple options for the event attendance as **Excellent**, **Good**, or **Poor**.
* **Event Suggestion** (`event_suggestion`, text, optional): Provide any suggestions for future events.
* **Email** (`email`, email, optional): Provide your email address if you would like to be contacted about this feedback.
* **Phone** (`phone`, text, optional): Provide your phone number if you would like to be contacted about this feedback.
* **Name** (`name`, text, optional): Provide your name if you would like to be contacted about this feedback.

Tips:
* Please provide as much detail as possible in the **Event Description** and **Comments** fields.
* Use the **Event Venue** field to select all options that apply to the event venue.
* Use the **Event Attendance** field to select all options that apply to the event attendance.
* If you have any suggestions for future events, please provide them in the **Event Suggestion** field.
