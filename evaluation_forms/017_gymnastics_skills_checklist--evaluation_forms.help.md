# Gymnastics Skills Checklist - Help Guide
## Purpose
This form is designed to assess and record the skills and abilities of a gymnast, specifically in the context of gymnastics training or evaluation.

## How To Complete This Form

1. Review each field and its label to ensure you understand its purpose and requirements.
2. Fill out the required fields completely.
3. For non-required fields, complete them only if you have relevant information.

## Field-by-Field Explanation

* **Skills Assessed**: This field is for noting the skills or abilities assessed during the evaluation. Enter a brief description or list of skills.
* **Skill Level**: Select the level of mastery for each skill, using the options provided:
	+ Mastery
	+ Novice
	+ Intermediate
	+ Advanced
* **Skill Comments**: Enter any additional comments or observations about the skill.
* **Skill Dangerous**: Check the boxes for any skills that pose a danger or risk to the gymnast.
* **Skill Frequency**: Enter the number of days and times the skill was practiced in the past (e.g., 2 weeks, 4 days, 6 hours).
* **Skill Dated**: Enter the date the skill was first practiced or last practiced.
* **Skill Dated Days**: Enter the number of days since the skill was last practiced.
* **Skill Dated Times**: Enter the number of times the skill was practiced in the past.
* **Skill Dated Notes**: Enter any additional notes about the date the skill was practiced.
* **Skill Practiced**: Enter the date the skill was last practiced.
* **Skill Practiced Days**: Enter the number of days since the skill was last practiced.
* **Skill Practiced Times**: Enter the number of times the skill was practiced in the past.
* **Skill Practiced Notes**: Enter any additional notes about the skill.
* **Skill Mastered**: Check the box if the skill is considered mastered or not.
* **Skill Mastered Days**: Enter the number of days since the skill was mastered.
* **Skill Mastered Times**: Enter the number of times the skill was mastered.
* **Skill Mastered Notes**: Enter any additional notes about mastering the skill.
* **Skill Mastered Dangerous**: Check the boxes for any skills that pose a danger or risk when mastered.
* **Skill Level Dangerous**: Select any dangers or risks associated with the skill level.
* **Skill Notes**: Enter any additional comments or observations about the skill.
* **Skill Comments**: Enter any additional comments or feedback about the skill.
* **Assigned Tool**: Enter any equipment or tools used to perform the skill.

Note: This form is designed to be completed by someone with knowledge of the gymnast's skills and abilities. If you are unsure about any field, please consult with the gymnast or their coach/trainer.
