# Innovation Project Impact Evaluation Form - Help Guide

## Purpose
This form is designed to evaluate the impact of an innovation project. It collects information on project attributes such as project duration, budget, team size, location, and evaluation type. This form is used to assess the effectiveness of the project in achieving its objectives and identify areas for improvement.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the required fields, marked with an *.
2. Enter the project title and description.
3. Rate the project's impact on various areas, such as sustainability, environment, socioeconomic, and economy.
4. Select the target audience for the project.
5. Specify the project duration and dates.
6. Select the project location.
7. Rate the collaboration level and project status.
8. Choose the evaluation type and frequency.
9. Select the evaluation basis.
10. Enter any evaluation comments if necessary.
11. Finally, select the evaluation date and time.

## Field-by-Field Explanation

* **Project Impact** (`project_impact_title`, text, *): Enter a brief description of the project's impact.
* **Impact Score** (`project_impact_score`, number, *): Rate the project's impact on a scale of 1-5.
* **Rationale** (`impact_rationale`, text, ): Provide a brief explanation of the project's impact.
* **Expected Impact Area** (`expected_impact_area`, text, ): Specify the expected impact area of the project.
* **Actual Impact Area** (`actual_impact_area`, select_multiple, ): Select multiple areas where the project actually had an impact, e.g., Environment, Socioeconomic, Economic.
* **Target Audience** (`target_audience`, select_one, ): Select the target audience of the project, e.g., General Public, Key Stakeholders, Project Team.
* **Impact on Sustainability** (`impact_on_sustainability`, number, ): Rate the project's impact on sustainability (e.g., 0.0).
* **Impact on Environment** (`impact_on_environment`, select_one, ): Rate the project's impact on the environment, e.g., High, Medium, Low.
* **Impact on Socioeconomic** (`impact_on_socioeconomic`, select_one, ): Rate the project's impact on socioeconomic, e.g., High, Medium, Low.
* **Impact on Economy** (`impact_on_economy`, select_one, ): Rate the project's impact on the economy, e.g., High, Medium, Low.
* **Impact on Project Sustainability** (`impact_on_project_sustainability`, select_one, ): Rate the project's impact on project sustainability, e.g., High, Medium, Low.
* **Project Duration** (`project_duration`, time, *): Enter the project duration in hours.
* **Project Start Date** (`project_start_date`, date, *): Enter the project start date.
* **Project End Date** (`project_end_date`, date, *): Enter the project end date.
* **Team Size** (`team_size`, number, *): Enter the number of team members.
* **Collaboration Level** (`collaboration_level`, select_one, ): Rate the level of collaboration, e.g., High, Medium, Low.
* **Project Budget** (`project_budget`, number, ): Enter the project budget.
* **Project Location** (`project_location`, text, *): Enter the project location.
* **Project Status** (`project_status`, select_one, ): Select the project status, e.g., Active, Completed, Cancelled.
* **Evaluation Type** (`evaluation_type`, select_one, ): Select the evaluation type, e.g., Formal, Informal, None.
* **Evaluation Frequency** (`evaluation_frequency`, select_one, ): Select the evaluation frequency, e.g., Daily, Weekly, Monthly, Quarterly.
* **Evaluation Basis** (`evaluation_basis`, select_one, ): Select the evaluation basis, e.g., Project Manager, Project Team, Project Team and Stakeholders, None.
* **Evaluation Comments** (`evaluation_comments`, text, ): Enter any additional comments for evaluation.
* **Evaluation Date** (`evaluation_date`, date, *): Enter the date of evaluation.
* **Evaluation Time** (`evaluation_time`, time, ): Enter the time of evaluation.
