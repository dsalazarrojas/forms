# Program Evaluation And Monitoring Checklist - Help Guide
## Purpose
The Program Evaluation And Monitoring Checklist is a tool used to collect data on the evaluation and monitoring process for a specific program or project. It helps program managers or evaluators assess the effectiveness and efficiency of the program in achieving its goals.

## How To Complete This Form
1. Review the form and understand the purpose and structure.
2. Answer the questions according to your knowledge and understanding of the program.
3. For each question, select the appropriate option that best describes your situation.
4. Enter any additional comments or notes in the "Evaluation Questions" field for further clarification.

## Field-by-Field Explanation

* **Introduction** (`1`, `note`, required: `false`): A brief introduction to the program or project, providing context and background information.
* **Objectives** (`2`, `select_multiple`, required: `false`): Check the objectives of the program, and select all that apply. (e.g., "Yes" for each objective that is relevant)
* **Monitoring** (`3`, `select_one`, required: `false`): Indicate whether the program has a monitoring system in place to track progress. (e.g., "Yes" if monitoring is done regularly)
* **Follow Up** (`4`, `date`, required: `false`): Enter the date for the last follow-up activity.
* **Frequency** (`5`, `select_multiple`, required: `false`): Check the frequency of monitoring and evaluation activities. (e.g., "Yes" for each frequency that applies)
* **Evaluation Cycle** (`6`, `number`, required: `false`): Enter the number of evaluation cycles conducted.
* **Target Group** (`7`, `select_multiple`, required: `false`): Identify the target group(s) for the program or project. (e.g., "Yes" for each target group that applies)
* **Stakeholders** (`8`, `select_one`, required: `false`): Indicate whether stakeholders have been engaged in the evaluation and monitoring process. (e.g., "Yes" if stakeholders are involved)
* **Evaluation Questions** (`9`, `note`, required: `false`): Enter any additional comments or questions related to the evaluation process.
* **Evaluation Frequency** (`10`, `select_multiple`, required: `false`): Check the frequency of evaluation activities. (e.g., "Yes" for each frequency that applies)
* **Monitoring Frequency** (`11`, `select_multiple`, required: `false`): Check the frequency of monitoring activities. (e.g., "Yes" for each frequency that applies)
* **Evaluation Outcome** (`12`, `select_multiple`, required: `false`): Check the outcomes of the evaluation process. (e.g., "Yes" for each outcome that applies)
* **Monitoring Outcome** (`13`, `select_multiple`, required: `false`): Check the outcomes of the monitoring process. (e.g., "Yes" for each outcome that applies)
* **Follow Up Outcome** (`14`, `select_multiple`, required: `false`): Check the outcomes of follow-up activities. (e.g., "Yes" for each outcome that applies)

Note: This form is not exhaustive and additional fields or questions may be added or modified as needed. 

Tips:
- Answer each question truthfully and to the best of your knowledge.
- Provide specific dates and details when required.
- Review the form and ensure you have answered all questions before submitting.
