# Application Localization Assessment - Help Guide
## Purpose
The purpose of this form is to help assess the quality of an application's localization. It will be used to evaluate the translation accuracy, cultural sensitivity, and overall performance of the application in different languages and regions.

## How To Complete This Form
1. Fill in the assessment date and your name.
2. Select the assessor's role.
3. Enter the application name and its version.
4. Choose the type of assessment to be done (website, mobile app, desktop application, or web service API).
5. Select the language being assessed.
6. Evaluate the overall translation accuracy, terminology consistency, cultural sensitivity, and contextual appropriateness of the translation.
7. Identify any layout and functionality issues.
8. Describe any reported issues or text overflow problems.
9. Evaluate the overall localization quality rating.

## Field-by-Field Explanation

* **Assessment Date** (2: assessment_date): Enter the date of the assessment. This is a required field and should be filled with the current date.
* **Assessor Name** (3: assessor_name): Enter your name and role as the assessor. This field is required and should be filled with your name and title.
* **Assessor Role** (4: assessor_role): Choose the role of the assessor from the dropdown list:
	+ QA Tester
	+ Localization Manager
	+ Product Manager
	+ Developer
	+ Native Speaker
	+ Other
* **Application Name** (6: application_name): Enter the name of the application being assessed. This field is required.
* **Application Version** (7: application_version): Enter the version number of the application (if applicable).
* **Assessment Type** (8: assessment_type): Choose the type of assessment to be done:
	+ Website
	+ Mobile app
	+ Desktop application
	+ Web service API
	+ Software documentation
* **Language Being Assessed** (9: language_tested): Select the language being assessed:
	+ Spanish
	+ French
	+ German
	+ Chinese
	+ Japanese
	+ Arabic
	+ Portuguese
	+ Other
* **Overall Translation Accuracy** (12: translation_accuracy): Evaluate the overall translation accuracy:
	+ Excellent
	+ Good
	+ Acceptable
	+ Poor
	+ Unacceptable
* **Terminology Consistency** (13: terminology_consistency): Evaluate the consistency of the terminologies throughout the application:
	+ Consistent
	+ Mostly consistent
	+ Somewhat consistent
	+ Inconsistent
	+ Highly inconsistent
* **Cultural Sensitivity and Appropriateness** (16: cultural_sensitivity): Evaluate the cultural sensitivity and appropriateness:
	+ Excellent
	+ Good
	+ Acceptable
	+ Poor
	+ Offensive
* **Date and Time Formats** (17: date_format_correctness): Evaluate the correctness of date and time formats:
	+ Correct
	+ Mostly correct
	+ Some issues
	+ Incorrect
	+ Not applicable
* **Currency Format Correctness** (18: currency_format): Evaluate the correctness of currency formats:
	+ Correct
	+ Mostly correct
	+ Some issues
	+ Incorrect
	+ Not applicable
* **Contextual Appropriateness** (14: contextual_appropriateness): Evaluate the contextual appropriateness:
	+ Highly appropriate
	+ Appropriate
	+ Somewhat appropriate
	+ Not appropriate
	+ Inappropriate
* **Any Text Overflow Issues** (20: text_overflow_issues): Identify any text overflow issues:
	+ No issues
	+ Minor issues
	+ Moderate issues
	+ Significant issues
* **Proper RTL Language Support** (21: rtl_language_support): Evaluate the proper right-to-left language support:
	+ Works correctly
	+ Works with minor issues
	+ Works with major issues
	+ Not implemented
	+ Not applicable
* **Reported Issues** (22: reported_issues): Describe any localization issues found. This is an optional field.
* **Overall Localization Quality Rating** (23: overall_rating): Evaluate the overall localization quality:
	+ Excellent
	+ Good
	+ Acceptable
	+ Poor
	+ Unacceptable

## Tips
* Be as specific as possible when evaluating each field.
* If you are unsure about any field, please select "Not applicable".
* If you are a native speaker of the assessed language, please be honest about any issues you found.
* Please keep the assessment fair and objective.
