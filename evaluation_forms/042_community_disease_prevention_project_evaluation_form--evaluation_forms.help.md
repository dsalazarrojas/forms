# Disease Prevention Project Evaluation - Help Guide
## Purpose

This form is designed to help project managers and evaluators assess the success of disease prevention projects. It gathers information on key aspects such as project objectives, outcomes, and cost-effectiveness. By using this form, you'll be able to provide valuable insights and feedback to project team members and stakeholders.

## How To Complete This Form

*   To complete this form, navigate through each page and fill in the required information. Each page contains several fields, which are described in the field-by-field explanation section.
*   You may skip fields that are not required.
*   Use the provided hints for guidance on filling in each field.

## Field-by-Field Explanation

*   **Project name** (`project_name`, `text`, required)
    *   A brief title of the initiative being evaluated.
*   **Evaluation period** (`evaluation_period`, `text`, required)
    *   Dates covered by this evaluation (format: mm/yyyy-mm/yyyy).
*   **Were project objectives met** (`objectives_met`, `select_one`, required)
    *   Choose whether project objectives were:
        + Fully met
        + Partially met
        + Not met
*   **Key outcomes observed** (`key_outcomes`, `text`, required)
    *   Quantitative or qualitative results achieved by the project.
*   **Challenges encountered** (`challenges_encountered`, `text`, optional)
    *   Obstacles that affected the implementation of the project.
*   **Perceived cost effectiveness** (`cost_effectiveness`, `select_one`, optional)
    *   Rate the financial efficiency of the project:
        + High
        + Moderate
        + Low
*   **Recommendations for future projects** (`recommendations`, `text`, optional)
    *   Suggested improvements or next steps for future projects.

## Tips

*   Be honest and objective when answering the questions.
*   Use specific examples or details when filling in the key outcomes and challenges encountered fields.
*   If you're unsure about any of the fields, use the provided hints for guidance.
*   This form is designed to gather valuable information. Your feedback is appreciated and will help improve the project.
