# Sustainability Index Evaluation Request - Help Guide

## Purpose
This form is used to request an evaluation of an organization's sustainability index. It provides the necessary information to conduct a thorough evaluation.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the required fields with accurate and relevant information.
2. Ensure that the focus areas and type of documentation are selected correctly.
3. Enter the evaluator's details correctly.
4. Select the evaluation date.
5. Verify that the submitted information is accurate and complete.

## Field-by-Field Explanation

* **Organization Name**: Enter the name of the organization requesting the evaluation.
* **Focus Areas**: Select all areas that the evaluation should focus on (e.g., 'Yes' or 'No' to indicate focus areas).
* **Type of Documentation**: Choose the type of documentation that should be used for the evaluation (e.g., 'Yes' or 'No').
* **Context**: Provide a brief context for the evaluation.
* **Evaluator Name**: Enter the name of the person conducting the evaluation.
* **Evaluator Email**: Enter the email address of the person conducting the evaluation.
* **Evaluator Phone**: Enter the phone number of the person conducting the evaluation.
* **Evaluation Date**: Enter the date when the evaluation should be conducted.
* **Submitted By**: Enter the name of the person submitting the request.
* **Submitted On**: Enter the date and time when the request is submitted.
* **Organization Address**: Enter the physical address of the organization requesting the evaluation.
