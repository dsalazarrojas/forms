# Project Efficiency Evaluation Request Form - Help Guide

## Purpose
This form is used to gather information from project team members to evaluate the efficiency of a project.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill out the form completely and accurately.
2. Make sure to only fill out the form once per project.

## Field-by-Field Explanation

### 1. **Project Information** (Project Information, text, optional)
Provide a brief description of the project.

### 2. **Project Status** (Project Status, select_one, optional)
Select the current status of the project (Active, Inactive, On Hold, Closed).

### 3. **Project Type** (Project Type, select_multiple, optional)
Select the type of project (Internal, External).

### 4. **Project Description** (Project Description, text, optional)
Provide a detailed description of the project.

### 5. **Project Manager** (Project Manager, text, optional)
Enter the name of the project manager.

### 6. **Evaluation Date** (Evaluation Date, date, optional)
Enter the date of the evaluation (mm/dd/yyyy).

### 7. **Evaluation Time** (Evaluation Time, time, optional)
Enter the time of the evaluation (hh:mm AM/PM).

### 8. **Notes** (Notes, note, optional)
Provide any additional comments or notes about the project.

### 9. **Email** (Email, email, optional)
Enter a valid email address.

### 10. **Phone Number** (Phone Number, text, optional)
Enter a valid phone number.
