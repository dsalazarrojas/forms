# Organist Evaluation Request Form - Help Guide

## Purpose
The Organist Evaluation Request Form is used to evaluate the performance of an organist. Fill out this form to provide feedback on an organist's ability to play the organ.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the **performance_id**, a unique identifier for the organist's performance.
2. Enter the **performer_name**, the name of the organist being evaluated.
3. Enter the **event_id**, a unique identifier for the event where the performance took place.
4. Select the **evaluation_date** and **evaluation_time** for the evaluation.
5. Enter a brief description of the evaluation in **evaluation_comments** (optional).
6. Provide a numerical score out of 10 for the **performance_score**.
7. Indicate whether the **event_type** was a concert or other type of event.
8. (Optional) If applicable, enter the **performance_id_2** for a second performance being evaluated.

## Field-by-Field Explanation

* **performance_id**: A unique identifier for the organist's performance. Enter the ID number assigned to this performance.
* **performer_name**: The name of the organist being evaluated.
* **event_id**: A unique identifier for the event where the performance took place.
* **evaluation_date**: The date on which the evaluation will be completed.
* **evaluation_time**: The time on which the evaluation will be completed.
* **evaluation_comments**: A brief description of the evaluation (optional).
* **performance_score**: A numerical score out of 10, indicating the organist's performance.
* **event_type**: Select 'Yes' if the event was a concert, 'No' otherwise.
* **performance_id_2**: (Optional) A second unique identifier for a second performance being evaluated. This field is optional and not required for most evaluations.
 
## Tips
* Ensure you have the correct performance ID and event ID before submitting the form.
* If you need to re-evaluate a performance, make sure the changes from the previous evaluation are significant enough to warrant a new evaluation.
* If you're unsure about any part of the form, consult with the organist or event organiser for clarification.
