# Kahlo Home Evaluation Form - Help Guide
## Purpose
The Kahlo Home Evaluation Form is a tool for collecting information about properties and their evaluation status. It helps us to better understand the state of properties, track progress, and make informed decisions.

## How To Complete This Form
To complete this form, follow these steps:

1. Ensure you have all the necessary information and permissions to access the property data.
2. Click on the 'Start Form' button to begin filling out the form.
3. Select the property type from the dropdown menu.
4. Choose the location of the property.
5. Select the evaluation type.
6. Provide the contact information and any additional notes if necessary.

## Field-by-Field Explanation
* **Contact Info** (`contact_info`, `email`, `optional`):
	+ A section to collect contact information, including email address.
	+ Please fill in the contact information accurately and truthfully.
* **Contact Number** (`contact_number`, `text`, `optional`):
	+ A field to collect the contact number for the property owner.
	+ Enter the contact number if available.
* **Property Type** (`property_type`, `select_one`, `optional`):
	+ A dropdown menu to select the type of property (Home, Commercial, Mixed Use, or Other).
	+ Select the correct type for the property.
* **Property Location** (`property_location`, `select_multiple`, `required`):
	+ A dropdown menu to select the location of the property (Downtown, Uptown, Suburbs, or Rural).
	+ Select all applicable locations for the property.
* **Evaluation Type** (`evaluation_type`, `select_one`, `required`):
	+ A dropdown menu to select the type of evaluation (Home, Commercial, Mixed Use, or Other).
	+ Select the correct type for the property evaluation.
* **Evaluation Date** (`evaluation_date`, `date`, `optional`):
	+ A field to record the date of the evaluation.
	+ If applicable, enter the date of the evaluation.
* **Evaluation Time** (`evaluation_time`, `time`, `optional`):
	+ A field to record the time of the evaluation.
	+ If applicable, enter the time of the evaluation.
* **Evaluation Notes** (`evaluation_notes`, `note`, `optional`):
	+ A field for any additional notes or comments about the evaluation.
	+ If necessary, add any relevant notes or comments.
* **Submitted By** (`submitted_by`, `select_one`, `optional`):
	+ A dropdown menu to select who submitted the evaluation (User1, User2, User3).
	+ If applicable, select the correct submitter.
* **Review Status** (`review_status`, `select_one`, `optional`):
	+ A dropdown menu to select the review status (Pending, Approved, Denied).
	+ Select the correct review status for the property.
* **Review Note** (`review_note`, `note`, `optional`):
	+ A field for any additional review comments or notes.
	+ If necessary, add any relevant review comments.
* **Review Date** (`review_date`, `date`, `optional`):
	+ A field to record the date of the review.
	+ If applicable, enter the review date.
* **Submitted By Name** (`submitted_by_name`, `text`, `optional`):
	+ A field to record the name of the submitter.
	+ If applicable, enter the submitter's name.
* **Submitted By Number** (`submitted_by_number`, `text`, `optional`):
	+ A field to record the submitter's number.
	+ If applicable, enter the submitter's number.
* **Reviewer Name** (`reviewer_name`, `text`, `optional`):
	+ A field to record the reviewer's name.
	+ If applicable, enter the reviewer's name.
* **Reviewer Number** (`reviewer_number`, `text`, `optional`):
	+ A field to record the reviewer's number.
	+ If applicable, enter the reviewer's number.
* **Property Owner Note** (`property_owner_note`, `note`, `optional`):
	+ A field for any additional notes or comments from the property owner.
	+ If necessary, add any relevant notes or comments from the owner.
* **Property Owner Name** (`property_owner_name`, `text`, `optional`):
	+ A field to record the name of the property owner.
	+ If applicable, enter the property owner's name.
* **Property Owner Number** (`property_owner_number`, `text`, `optional`):
	+ A field to record the property owner's number.
	+ If applicable, enter the property owner's number.
* **Follow Up Date** (`follow_up_date`, `date`, `optional`):
	+ A field to record the follow-up date.
	+ If applicable, enter the follow-up date.
* **Follow Up Time** (`follow_up_time`, `time`, `optional`):
	+ A field to record the follow-up time.
	+ If applicable, enter the follow-up time.
* **Follow Up Status** (`follow_up_status`, `select_one`, `optional`):

	+ If applicable, select the correct follow-up status.
* **Follow Up Note** (`follow_up_note`, `note`, `optional`):
