# Church Security Assessment Form - Help Guide

## Purpose
The Church Security Assessment Form is a tool designed to evaluate the security level of a church or other place of worship. This form helps assessors identify areas of improvement and provide recommendations for enhancing the church's security.

## How To Complete This Form

### Before Starting
- Make sure you have permission to conduct the assessment from the church administration or leadership.
- Ensure you have a clear understanding of the form's purpose and the church's current security measures.
- Complete the form accurately and thoroughly, providing as much detail as possible.

### Completing the Form

- **Assessor Information**: This section is for the person conducting the assessment.
    - **Assessor Full Name** (`assessor_name`): Enter your full name.
    - **Your Role** (`assessor_role`): Select your role (Church Staff, Security Team Member, External Consultant, Law Enforcement, Board Member, or Other).
    
- **Church Information**: This section is for the church being assessed.
    - **Date of Assessment** (`assessment_date`): Enter the date of the assessment.
    - **Church Name** (`church_name`): Enter the name of the church.
    - **Average Weekly Attendance** (`church_size`): Select the average weekly attendance number (Under 100, 100-250, 251-500, 501-1000, or Over 1000).
    
- **Security Measures**: This section assesses the church's security measures.
    - **Does the Church Have a Security Team** (`security_team`): Select whether the church has a security team (Yes, full-time, Yes, volunteer-based, No, but planning to, or False).
    - **How Many Security Team Members** (`security_team_size`): If applicable, enter the number of security team members.
    - **Access Control Systems** (`access_control`): Select all applicable access control systems (Locked doors during services, Key card access, Security cameras, Metal detectors, Bag checks, Ushers at entrances, or None).
    - **Surveillance Systems** (`surveillance`): Select the type of surveillance system (Comprehensive camera coverage, Partial camera coverage, Basic camera system, or No cameras).
    - **Emergency Plan** (`emergency_plan`): Select whether there is an emergency action plan (Yes, documented and practiced, Yes, documented but not practiced, Yes, verbal only, or False).
    - **Emergency Training** (`emergency_training`): Select how often emergency training is conducted (Monthly, Quarterly, Annually, Rarely, or Never).
    - **Emergency Communication System** (`communication_system`): Select the type of emergency communication system (Two-way radios, Phone tree, Text alert system, Public address system, or No system).
    - **Medical Emergency Equipment** (`medical_equipment`): Select all applicable medical emergency equipment (AED (Defibrillator), First aid kits, Emergency oxygen, Trained medical personnel, or None).
    
- **Parking and Nursery Security**: This section assesses parking and nursery security.
    - **Parking Lot Security** (`parking_security`): Select the level of parking lot security (Well-lit with cameras, Well-lit only, Some lighting, Poorly lit, or No security measures).
    - **Nursery Security Procedures** (`nursery_security`): Select the level of nursery security procedures (Check-in/check-out system, Background checks for workers, Two-adult policy, Secure access doors, or All of the above, or None of the above).
    
- **Incident History and Types**: This section assesses the church's incident history and types.
    - **Have There Been Security Incidents** (`incident_history`): Select whether there have been security incidents in the past 2 years (Yes, multiple, Yes, one or two, False, or Not sure).
    - **Types of Incidents** (`incident_types`): Select all applicable types of incidents (Theft, Vandalism, Trespassing, Disruptive behavior, Medical emergency, Threat made, Violence, or None).
    
- **Local Law Enforcement**: This section assesses the church's relationship with local law enforcement.
    - **Relationship with Local Law Enforcement** (`local_law_enforcement`): Select the level of relationship (Regular contact and cooperation, Occasional contact, Minimal contact, No contact).
    
- **Overall Security Risk Level**: This section assesses the overall security risk level.
    - **Overall Security Risk Level** (`risk_level`): Select the overall security risk level (Low risk, Moderate risk, Elevated risk, High risk, or Severe risk).
    
- **Priority Improvements Needed**: This section identifies priority improvements needed.
    - **Priority Security Improvements Needed** (`priority_improvements`): Select the top 3 priority security improvements (Access control, Surveillance cameras, Security team training, Emergency planning, Communication systems, Lighting, Medical preparedness, Background checks, or None).
    
- **Budget and Recommendations**: This section is for the assessor's recommendations and the availability of a budget.
    - **Is Budget Available for Security Improvements** (`budget_available`): Select whether a budget is available for security improvements (Yes, adequate budget, Yes, limited budget, No budget currently, or Not sure).
    - **Security Recommendations** (`recommendations`): Enter your professional recommendations.
    - **Recommended Follow-Up Assessment Date** (`follow_up_date`): Enter the recommended follow-up assessment date (if applicable).

### Additional Tips

- Be thorough and accurate when completing the form.
- If a field is not applicable, select "None" or "Not Applicable".
- If you have any questions or concerns, contact your supervisor or the church administration.
- This form is a tool to enhance the church's security, not a punitive measure.

### Review and Submission

- Review the form carefully before submission to ensure accuracy.
- Submit the form to the church administration or security team.
- Follow up with the church to ensure they have received the form and are taking necessary actions.
