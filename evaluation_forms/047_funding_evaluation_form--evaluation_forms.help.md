# Funding Evaluation Form - Help Guide
## Purpose
The Funding Evaluation Form is used to gather information about projects, including their description, funding amount, start and end dates, status, evaluation score, comments, category, and project lead. This form helps to evaluate and track project progress, identify areas for improvement, and provide feedback to project teams.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the "Project Description" field with a brief description of the project.
2. Enter the "Funding Amount" field with the total amount of funding allocated for the project.
3. Select the "Project Start Date" and "Project End Date" fields to indicate the project's start and end dates.
4. Choose the "Project Status" field to indicate the current status of the project.
5. Evaluate the project's quality and impact by entering a score in the "Evaluation Score" field.
6. Add any additional comments about the project in the "Evaluation Comment" field.
7. Select a category for the project from the "Project Category" field.
8. Enter the name of the project lead in the "Project Lead" field.

## Field-by-Field Explanation
* **Project Description**: A brief description of the project.
* **Funding Amount**: The total amount of funding allocated for the project.
* **Project Start Date**: Select the start date for the project.
* **Project End Date**: Select the end date for the project.
* **Project Status**: Choose the current status of the project.
* **Evaluation Score**: Evaluate the project's quality and impact.
* **Evaluation Comment**: Add any additional comments about the project.
* **Project Category**: Select a category for the project.
* **Project Lead**: Enter the name of the project lead.

## Tips
* Please be as specific as possible when filling in the fields, especially the "Project Description" and "Project Lead" fields.
* Make sure to choose the correct project status and category to ensure accurate tracking and reporting.
* The "Evaluation Score" and "Evaluation Comment" fields are optional, but provide valuable feedback for project teams.
* If you're unsure about any field, please ask your project manager or team for clarification.
