# Seminar Evaluation Survey - Help Guide
## Purpose
The Seminar Evaluation Survey is used to gather feedback and evaluations from seminar attendees. It helps seminar organizers and facilitators assess the quality and effectiveness of the seminar.

## How To Complete This Form
To complete this form, follow these steps:
1. Answer each question to the best of your ability.
2. If you have any comments or suggestions, please include them in the text fields.
3. For the multiple-choice questions, select all applicable options.
4. Make sure to complete all required fields.

## Field-by-Field Explanation
* **seminar_evaluation_survey_page_1** (`text`, Optional): Please provide any comments or feedback about the seminar.
* **seminar_evaluation_survey_page_2** (`text`, Optional): Any additional comments or feedback.
* **seminar_evaluation_survey_page_3** (`text`, Optional): More comments or feedback about the seminar.
* **seminar_evaluation_survey_page_4** (`text`, Optional): Even more comments or feedback.
* **seminar_evaluation_survey_page_5** (`text`, Optional): Any other comments or feedback.
* **seminar_evaluation_survey_page_6** (`text`, Optional): Additional comments or feedback.
* **seminar_evaluation_survey_page_7** (`text`, Optional): Further comments or feedback.
* **seminar_evaluation_survey_page_8** (`text`, Optional): More thoughts about the seminar.
* **seminar_evaluation_survey_page_9** (`text`, Optional): Last comments or feedback.
* **seminar_evaluation_survey_page_10** (`text`, Optional): Additional comments or feedback.
* **seminar_evaluation_survey_page_11** (`select_one`, Required): What did you like most about the seminar? (Select one of the options: Option 1, Option 2, Option 3)
* **seminar_evaluation_survey_page_12** (`select_multiple`, Required): Which of the following topics were covered in the seminar? (Select multiple options: Option 1, Option 2, Option 3)

Note: If you have any other feedback or comments that are not covered by the questions, please include them in the text fields.
