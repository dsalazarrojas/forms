# rfid_performance_evaluation_form - Help Guide
## Purpose
The `rfid_performance_evaluation_form` is used to evaluate and document the performance of RFID systems, including whether RFID tests were conducted and the results of metrics and observations made during these tests.

## How To Complete This Form
To complete this form, simply navigate through the form's pages and fill in the requested fields. Each page contains multiple fields where you can provide information. You can complete the form by selecting the options from the dropdown menu or typing in the fields. Don't forget to save your changes after each page to proceed to the next one.

## Field-by-Field Explanation
* **rfid_tests** (select_multiple): Select 'Yes' or 'No' to indicate whether RFID tests were conducted during the evaluation.
* **metric_1_label** (number): Enter the value of the first metric observed during the test. 
* **metric_2_label** (number): Enter the value of the second metric observed during the test. 
* **metric_3_label** (date): Enter the date of the metric observation or the end of the test.
* **issue** (text): Describe any issues that occurred during the test.
* **recommendation** (text): Provide any recommendations or suggestions for improvement based on the test results.
* **notes** (note): Enter any additional notes or comments about the test.

## Tips
- Save your changes before proceeding to the next page to avoid losing any filled-in information.
- Ensure that you have answered all required fields (indicated by a red asterisk *) before submitting the form.
- If you need to add more information or details, use the notes field to do so. 

Note: The required fields are marked with a red asterisk * in the Field-by-Field Explanation section, but since there are no required fields in the provided YAML, I've removed it from the Tips section.
