# Verbal Language Assessment Form - Help Guide
## Purpose
The Verbal Language Assessment Form is designed to collect information about an individual's verbal language skills. It includes fields for user input, demographic details, and scoring.

## How To Complete This Form
1. Please fill in the required fields marked with an asterisk (\*). If you are unsure about any field, refer to the field-by-field explanation below.
2. For fields with multiple options, choose the most accurate response from the provided list.
3. Enter your email address and phone number for communication purposes.

## Field-by-Field Explanation
* **User Input** (`user_input`, text, required): This is the main input field for gathering additional information about the individual.
* **first name** (`first_name`, text, required): Enter the first name of the individual.
* **last name** (`last_name`, text, required): Enter the last name of the individual.
* **native language** (`native_language`, text, required): Choose the language the individual is most comfortable speaking in.
* **test language** (`test_language`, text, required): Choose the language the individual is being tested in.
* **score** (`score`, number, required): Enter the score obtained during the test.
* **time** (`time`, time, required): Enter the time taken to complete the test.
* **date** (`date`, date, required): Enter the date of the test.
* **notes** (`notes`, note, optional): Add any additional comments or notes about the individual's performance.
* **email** (`email`, email, required): Enter the individual's email address for communication purposes.
* **phone** (`phone`, text, required): Enter the individual's phone number for communication purposes.
* **selected language** (`selected_language`, select_one, required): Choose the language that best represents the individual's verbal skills.
	+ Options: Option 1, Option 2, Option 3, Option 4, Option 5
* **selected language other** (`selected_language_other`, select_multiple, optional): Choose multiple languages that best represent the individual's verbal skills. (Note: only required if "selected language other" is selected)
* **other selected language** (`selected_language_other_option`, text, optional): Enter any additional language options that are not listed.
* **other selected language option 2** (`selected_language_other_option_2`, text, optional): Enter any additional language options that are not listed.

## Tips
- Please ensure you are entering accurate and complete information about the individual's language skills.
- If you are unsure about any of the fields, refer to the field-by-field explanation above.
- If you select "selected language other" in the previous field, please ensure you enter additional options in the "other selected language" fields.
