# graham_cracker_structure_ranking - Help Guide
## Purpose
The "Graham Cracker Structure Ranking" form is used to evaluate or rank a Graham Cracker's structure. It gathers information on the cracker's features and performance in a specific challenge.

## How To Complete This Form

1. Fill out the following sections:
	* Challenge Name: Enter the name of the challenge the cracker is participating in, if applicable.
	* Challenge Image: Select one of the three options for the quality of the challenge's image.
	* Rating: Evaluate or rate the cracker's quality or performance using a number.
	* Feedback: Provide any additional comments or notes about the cracker.
	* Collect Photos: Select multiple options for the photos to be collected, if necessary.

## Field-by-Field Explanation

* **Challenge Name** (challenge_name, text, optional): Enter the name of the challenge or event the cracker is participating in.
* **Challenge Image** (challenge_image, select_one, optional): Select the quality of the challenge's image from the options: Option 1, Option 2, or Option 3.
* **Rating** (rating, number, optional): Evaluate the cracker's quality or performance using a numerical value.
* **Feedback** (feedback, text, optional): Provide any additional comments or notes about the cracker.
* **Collect Photos** (collect_photos, select_multiple, optional): Select multiple options for the photos to be collected, if applicable.
