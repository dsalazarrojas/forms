# environmental_conservation_project_impact_assessment - Help Guide
## Purpose
This form assesses the impact of a project on the environment by collecting relevant project information.

## How To Complete This Form

1.  Start by filling in the required information, which is marked as "Required" in the form fields.
2.  Enter the "project_id" field if you have it available.
3.  Enter the project's title in the "project_title" field.
4.  Briefly describe the project in the "project_description" field.
5.  Select the project's location from the options provided in the "project_location" field.
6.  Enter the project's start date in the "project_start_date" field in the correct format (e.g., YYYY-MM-DD).
7.  Enter the project's end date in the "project_end_date" field in the correct format (e.g., YYYY-MM-DD).
8.  If the project is funded, enter the budget in the "project_budget" field.
9.  For the "project_outcome" field, select one of the provided options or type "other" if it's not listed.
10.  If "other" was selected for "project_outcome", type your custom outcome in the "project_outcome_other" field.
11.  Select the impact areas of the project from the options provided in the "project_impact_area" field.
12.  List any project partners in the "project_partners" field.

## Field-by-Field Explanation
* **project_id** (`number`, Required): Enter the unique identifier of the project.
* **project_title** (`text`, Required): Enter the title of the project.
* **project_description** (`text`, Required): Briefly describe the project.
* **project_location** (`select_one`, Required): Select the project's location from the options provided.
* **project_start_date** (`date`, Optional): Enter the project's start date in the correct format (e.g., YYYY-MM-DD).
* **project_end_date** (`date`, Optional): Enter the project's end date in the correct format (e.g., YYYY-MM-DD).
* **project_budget** (`number`, Optional): Enter the budget of the project.
* **project_outcome** (`select_one`, Required): Select one of the provided options or type "other" if it's not listed.
* **project_outcome_other** (`text`, Optional): Enter a custom outcome if "other" was selected.
* **project_impact_area** (`select_multiple`, Optional): Select multiple impact areas of the project from the options provided.
* **project_partners** (`text`, Optional): List any project partners.

## Tips

- Be as specific as possible when filling in the "project_outcome_other" field.
- Be accurate when selecting the impact areas in the "project_impact_area" field.
- List all relevant project partners in the "project_partners" field.
- Format dates correctly in the "project_start_date" and "project_end_date" fields.
- If "other" was selected for "project_outcome", provide a clear and concise description of the outcome.
