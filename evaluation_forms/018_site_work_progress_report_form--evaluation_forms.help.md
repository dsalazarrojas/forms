# Site Work Progress Report Form - Help Guide
## Purpose
The Site Work Progress Report Form is designed to gather information about the progress of site work projects. This form is intended to be completed by site workers or project managers to report on the status of their projects.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the client name in the "client name" field.
2. Enter the project number in the "project number" field.
3. Enter the start date of the project in the "start date" field.
4. Review the form for completeness and accuracy before submitting it.

## Field-by-Field Explanation
* **Client Name** (`client_name`, text, optional): Enter the name of the client or organization related to the site work project.
* **Project Number** (`project_number`, text, optional): Enter the unique identifier assigned to the project.
* **Start Date** (`start_date`, date, optional): Enter the date the project began.
* **Site Work Progress Report Form** (`site_work_progress_report_form`, text, optional): Enter a brief description of the site work progress report (this field is currently labeled as "Site Work Progress Report Form", but this is a required field for the form to be complete).

## Tips
* Make sure to enter accurate and up-to-date information in each field.
* Review the form for completeness and accuracy before submitting it.
* If you have any issues or concerns, contact form@gic.mx for support.
