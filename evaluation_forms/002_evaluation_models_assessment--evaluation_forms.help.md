# Evaluation Models Assessment - Help Guide

## Purpose
This form is designed to help assess the evaluation models. It collects various types of information to understand better how the evaluation models are being used and their overall performance.

## How To Complete This Form
To complete this form, please follow these steps:

1. Start by providing general information about the assessment, such as the title and date.
2. Select the assessment strategy used (Assessment A, Assessment B, or Assessment C).
3. For each assessment item, provide a brief note describing the item and its type (Type A, Type B, or Type C).
4. Enter the name of each assessment item.
5. Choose the type details for each item (Option 1, Option 2, or Option 3).
6. Enter the assessment date and time.
7. Specify the location where the assessment took place.
8. Select the assessment results (Result A, Result B, or Result C).
9. Provide any feedback about the assessment.
10. Enter your email address.

## Field-by-Field Explanation

* **General Information** (`General Information`, `text`, required/optional): Enter a brief description of the assessment.
* **Assessment Strategy** (`Assessment Strategy`, `select_one`, required): Choose how the assessment was conducted (Assessment A, Assessment B, or Assessment C).
* **Assessment Item** (`Assessment Item`, `note`, required/optional): Enter a brief description of the item being assessed.
* **Assessment Item Type** (`Assessment Item Type`, `select_multiple`, required): Select the type of item being assessed (Type A, Type B, or Type C).
* **Assessment Item Name** (`Assessment Item Name`, `text`, required): Enter the name of the item being assessed.
* **Item Type Details** (`Item Type Details`, `select_one`, required): Choose the specific details of the item type (Option 1, Option 2, or Option 3).
* **Assessment Date** (`Assessment Date`, `date`, required): Enter the date the assessment was conducted.
* **Assessment Time** (`Assessment Time`, `time`, required): Enter the time the assessment was conducted.
* **Assessment Location** (`Assessment Location`, `text`, required): Enter the location where the assessment took place.
* **Assessment Results** (`Assessment Results`, `select_multiple`, required): Select the results of the assessment (Result A, Result B, or Result C).
* **Feedback** (`Feedback`, `note`, optional): Provide any feedback about the assessment.
* **Email** (`Email`, `email`, required): Enter your email address.
* **Goals** (`Goals`, `text`, optional): Enter any goals or objectives related to the assessment.
* **Comments** (`Comments`, `note`, optional): Provide any additional comments about the assessment.
