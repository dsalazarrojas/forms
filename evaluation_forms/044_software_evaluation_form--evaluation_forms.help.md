# Software Evaluation Form - Help Guide
## Purpose

The Software Evaluation Form is used to collect information about software products, allowing evaluators to provide feedback, reviews, or ratings for improvement. This form helps to gather specific details about each software product, aiding in the evaluation process.

## How To Complete This Form

To complete the form, follow these steps:

1. Select the correct category that best describes the software product being evaluated (Page 1, category field).
2. Write a brief description of the software product (Page 1, description field).
3. Provide the effective date or rating of the software product (Page 1, effective field).
4. Enter the evaluation date (Page 1, date field).
5. Enter the evaluation time (Page 1, time field).
6. Repeat the process for any additional software products being evaluated (Pages 2-3).

## Field-by-Field Explanation

* **category** (`category`, select_one): Choose the most relevant category for the software product you're evaluating (e.g., Option 1, Option 2, or Option 3).
* **description** (`description`, text): Enter a brief description of the software product.
* **effective** (`effective`, number): Provide a numerical rating (0-100) of the software product's effectiveness.
* **date** (`date`, date): Enter the date of the evaluation.
* **time** (`time`, time): Enter the time of the evaluation.
* **software_evaluation_form_2** (`software_evaluation_form_2`, text): This field is intended for additional comments or notes about the software product. 
* **category_2** (`category_2`, select_one): Choose the most relevant category for this software product (e.g., Option 1, Option 2, or Option 3).
* **description_2** (`description_2`, text): Enter a brief description of this software product.
* **effective_2** (`effective_2`, number): Provide a numerical rating (0-100) of this software product's effectiveness.
* **date_2** (`date_2`, date): Enter the evaluation date.
* **time_2** (`time_2`, time): Enter the evaluation time.
* **software_evaluation_form_3** (`software_evaluation_form_3`, text): This field is intended for additional comments or notes about this software product. 

## Tips

* Make sure to select the correct category for each software product.
* Keep descriptions brief and to the point.
* Use numerical values for effectiveness ratings between 0 and 100.
* Use the correct date and time format for each field.
