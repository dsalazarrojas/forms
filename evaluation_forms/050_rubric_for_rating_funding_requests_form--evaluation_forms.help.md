# rubric_for_rating_funding_requests_form - Help Guide
## Purpose
This form is used to rate funding requests. It's designed to gather information about the progress of funding requests, helping to track their status and make informed decisions.

## How To Complete This Form
To complete this form, follow these steps:

1. Ensure you have all the necessary information about the funding request at hand.
2. Read each field carefully to understand what's being asked.
3. Fill out the form with the requested information.

## Field-by-Field Explanation

* **Request Details (1)** (`request_details`, `text`, required: false): This is a text field where you can provide any additional information related to the funding request.
* **Score (2)** (`score`, `number`, required: false): Please enter a score for the funding request, using whole numbers only.
* **Comments (3)** (`comments`, `text`, required: false): Add any comments or notes about the funding request.
* **Rating (4)** (`rating`, `select_one`, required: false): Choose one of the following ratings:
	+ Funding is on track
	+ Funding is off track
	+ Funding is uncertain
* **Score 2 (5)** (`score_2`, `number`, required: false): This field is intended to gather additional score information. You can use it for tracking progress over time.
* **Comments 2 (6)** (`comments_2`, `text`, required: false): Enter any comments related to this second score.
* **Rating 2 (7)** (`rating_2`, `select_one`, required: false): Choose one of the following ratings:
	+ Funding is on track
	+ Funding is off track
	+ Funding is uncertain
* **Score 3 (8)** (`score_3`, `number`, required: false): This field is meant for tracking further progress. You can use it to compare with previous scores.
* **Comments 3 (9)** (`comments_3`, `text`, required: false): Add any comments related to this third score.
* **Rating 3 (10)** (`rating_3`, `select_one`, required: false): Choose one of the following ratings:
	+ Funding is on track
	+ Funding is off track
	+ Funding is uncertain
* **Score 4 (11)** (`score_4`, `number`, required: false): This is an additional score field. Use it to track progress.
* **Comments 4 (12)** (`comments_4`, `text`, required: false): Enter any comments related to this fourth score.
* **Score 4 (12)** (`score_4`, `text`, required: false): Similar to Score 1, use it for tracking progress over time. 
* **Rating 4 (13)** (`rating_4`, `select_one`, required: false): Choose one of the following ratings:
	+ Funding is on track
	+ Funding is off track
	+ Funding is uncertain
