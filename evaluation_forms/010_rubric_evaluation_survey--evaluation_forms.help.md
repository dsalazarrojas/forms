# rubric_evaluation_survey - Help Guide
## Purpose
The rubric_evaluation_survey form is designed to evaluate student performance against a set of criteria. It provides a comprehensive framework for assessing students' work, projects, or presentations, helping to ensure consistency and fairness in evaluations.

## How To Complete This Form
To complete this form, follow these steps:

1. Ensure you are familiar with the rubric criteria and scale being evaluated.
2. Review the student's performance in relation to the rubric criteria.
3. Select the appropriate scale options for each criteria or use the text field for more in-depth comments.
4. Provide any additional feedback or comments that you feel are relevant.
5. Review your answers for accuracy and completeness.

## Field-by-Field Explanation
* **Student Performance** (Student Performance, note, optional): Use this field to briefly summarize the student's performance in relation to the rubric criteria. This should provide context for your subsequent evaluations.
* **Rubric Scale** (Rubric Scale, select one, optional): Select the scale that best describes the student's performance. This field is used to provide a quick evaluation of the student's overall performance.
* **Evaluation Comments** (Evaluation Comments, note, optional): Use this field to provide more in-depth comments or feedback on the student's performance. Be as specific as possible to provide actionable feedback.
* **Additional Feedback** (Additional Feedback, text, optional): Provide any additional feedback or comments that you feel are relevant to the student's performance.
* **Rubric Scale Scale 1** (Rubric Scale Scale 1, select multiple, optional): Select the scales that best describe the student's performance for this specific criteria.
* **Rubric Criteria 1** (Rubric Criteria 1, select one, optional): Select the criteria that best describes the student's performance.
* **Rubric Criteria 2** (Rubric Criteria 2, select multiple, optional): Select the criteria that best describe the student's performance.

Note: All fields are optional, but providing as much information as possible will help ensure a comprehensive evaluation.
