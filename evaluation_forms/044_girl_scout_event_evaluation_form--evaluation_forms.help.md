# Girl Scout Event Evaluation Form - Help Guide
## Purpose
The Girl Scout Event Evaluation Form is used to gather feedback and opinions on Girl Scout events. This form helps event organizers understand what worked well and what needs improvement to make future events successful and enjoyable for attendees.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the title of the event you are evaluating.
2. Select the date of the event.
3. Choose the time of the day the event took place.
4. Answer the "Evaluation Scale" question by selecting 'Yes' if you found the event to be well-executed.
5. Choose your overall satisfaction with the event (Satisfied or Dissatisfied).
6. Select your level of satisfaction with the specific event (Satisfied or Dissatisfied).
7. Answer the "Event Impressions" question by selecting 'Yes' if the event impressed you.
8. Choose whether you would recommend the event to others (Yes or No).
9. Provide any suggestions for future events in the "Event Suggestions" field.
10. Rate the event using the rating scale (if applicable).
11. Indicate whether you have completed the evaluation form (Yes or No).

## Field-by-Field Explanation

* **Girl Scout Event Title** (`event_title`, text, required: false): Enter the title of the event being evaluated.
* **event_date** (`event_date`, date, required: false): Enter the date of the event.
* **Event Time** (`event_time`, time, required: false): Choose the time of day the event took place (e.g., morning, afternoon, evening).
* **Evaluation Scale** (`evaluation_scale`, select_one, required: false): Select 'Yes' if the event was well-executed.
* **Overall Satisfaction** (`overall_satisfaction`, select_multiple, required: false): Choose how satisfied you are with the event (Satisfied or Dissatisfied).
* **Event Satisfaction** (`event_satisfaction`, select_one, required: false): Select your level of satisfaction with the specific event.
* **Event Impressions** (`event_impressions`, select_multiple, required: false): Select 'Yes' if the event impressed you.
* **Event Recommendation** (`event_recommendation`, select_multiple, required: false): Choose whether you would recommend the event to others (Yes or No).
* **Event Suggestions** (`event_suggestions`, note, required: false): Provide any suggestions for future events.
* **Event Rating** (`event_rating`, number, required: false): Rate the event using the provided scale (1-5 or 1-10).
* **Evaluation Form** (`evaluation_form`, select_one, required: false): Indicate whether you have completed the evaluation form (Yes or No).
