# Executive Leadership Interview Form - Help Guide
## Purpose
This form is used to evaluate the performance of candidates during an executive leadership interview.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill in the candidate's name, position title, and email address.
2. Select a suitable date and time for the interview from the given options or select 'N/A' if not applicable.
3. Rate the candidate's performance as 'Excellent', 'Satisfactory', or 'Unsatisfactory'.
4. Provide a brief summary of your recommendation for the candidate.
5. Add any additional comments or feedback about the candidate's performance.
6. Select the panel member(s) who interviewed the candidate.
7. If applicable, select the name of the panel member who interviewed the candidate.

## Field-by-Field Explanation
- **Candidate Name** (`candidate_name`, text, required: false): Enter the name of the candidate being interviewed.
- **Position Title** (`position_title`, text, required: false): Enter the position title of the candidate.
- **Candidate Email** (`candidate_email`, email, required: false): Enter the email address of the candidate.
- **Candidate Phone** (`candidate_phone`, text, required: false): Enter the phone number of the candidate.
- **Interview Date** (`interview_date`, date, required: false): Select the date of the interview from the given options or select 'N/A' if not applicable.
- **Interview Time** (`interview_time`, time, required: false): Select the time of the interview from the given options or select 'N/A' if not applicable.
- **Evaluation** (`evaluation`, select_one, required: false): Rate the candidate's performance as 'Excellent', 'Satisfactory', or 'Unsatisfactory'.
- **Recommendation** (`recommendation`, text, required: false): Provide a brief summary of your recommendation for the candidate.
- **Feedback** (`feedback`, note, required: false): Add any additional comments or feedback about the candidate's performance.
- **Panel** (`panel`, select_one, required: false): Select a panel member from the given options.
- **Panel Member** (`panel_member`, select_multiple, required: false): If applicable, select the name of the panel member who interviewed the candidate.
- **Additional Comments** (`additional_comments`, text, required: false): Add any additional comments or feedback about the candidate's performance.

## Tips
- Please fill in the form accurately and truthfully.
- If a field is not applicable, select 'N/A' and add a brief explanation in the 'Additional Comments' section.
- If a field is not relevant, leave it blank.
- Please note that the form is for internal use only.
