# Feedback Voltage Amplifier Evaluation Form - Help Guide
## Purpose
The Feedback Voltage Amplifier Evaluation Form is used for evaluating the performance of a voltage amplifier after a test or evaluation.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in your **User Name** in the field "User Name".
2. Enter the date of the test in the field "Test Date".
3. Select the evaluation result in the field "Evaluation Result" (Pass, Failed, or Not Evaluated).
4. Add any comments about the evaluation in the field "Comments".
5. Fill in the details about the user who was assigned to perform the evaluation in the fields "Assigned User", "Assigned User Email", and "Assigned User Phone" (if applicable).
6. Enter the evaluation location in the field "Evaluation Location".
7. Enter the device used for the evaluation in the field "Evaluation Device".
8. Add any notes about the evaluation in the fields "Notes" (if applicable).

## Field-by-Field Explanation

* **User Name** (`user_name`, text, required): Enter your name as the person submitting the feedback.
* **Test Date** (`test_date`, date, required): Enter the date on which the test was performed.
* **Voltage Level** (`voltage_level`, number, required): Enter the voltage level of the amplifier during the test.
* **Evaluation Result** (`evaluation_result`, select_one, required): Select the outcome of the test (Pass, Failed, or Not Evaluated).
* **Comments** (`comments`, text, required): Add any comments about the test.
* **User Email** (`user_email`, email, required): Enter the email of the user who performed the evaluation.
* **User Phone** (`user_phone`, text, required): Enter the phone number of the user who performed the evaluation.
* **Assigned User** (`assigned_user`, text, optional): Enter the name of the user assigned to perform the evaluation (if applicable).
* **Assigned User Email** (`assigned_user_email`, email, optional): Enter the email of the user assigned to perform the evaluation (if applicable).
* **Assigned User Phone** (`assigned_user_phone`, text, optional): Enter the phone number of the user assigned to perform the evaluation (if applicable).
* **Evaluation Location** (`evaluation_location`, text, required): Enter the location where the evaluation was performed.
* **Evaluation Device** (`evaluation_device`, text, required): Enter the device used for the evaluation.
* **Notes** (`notes`, note, optional): Add any notes about the evaluation.
* **Evaluation Type** (`evaluation_type`, select_one, optional): Select the type of evaluation (Lab or Field).
* **Evaluation Type Other** (`evaluation_type_other`, text, optional): Enter any other evaluation type (if not Lab or Field).
* **Voltage Level Other** (`voltage_level_other`, text, optional): Enter any other voltage level (if not a number).
* **Evaluation Notes** (`evaluation_notes`, note, optional): Add any additional notes about the evaluation.
* **Test Notes** (`test_notes`, note, optional): Add any notes about the test.
* **Test Environment** (`test_environment`, text, optional): Enter the test environment details (if not a standard environment).
* **Test Environment Other** (`test_environment_other`, text, optional): Enter any other test environment details (if not a standard environment).
* **Comments Other** (`comments_other`, text, optional): Enter any other comments about the test.
* **Test Result Notes** (`test_result_notes`, note, optional): Add any notes about the test result.
* **Test Result Comments** (`test_result_comments`, text, optional): Enter any comments about the test result.
* **Test Result Comments Other** (`test_result_other_comments`, text, optional): Enter any other comments about the test result.
* **Test Result Evaluate** (`test_result_evaluate`, text, optional): Enter the result of the evaluation (if not Pass, Failed, or Not Evaluated).
