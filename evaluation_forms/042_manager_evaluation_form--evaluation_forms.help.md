# Manager Evaluation Form - Help Guide
## Purpose
The Manager Evaluation Form is used by managers to evaluate the performance of their direct reports. This form helps managers provide a comprehensive evaluation of their employee's strengths and areas for improvement.

## How To Complete This Form
1. Ensure you have all necessary information before starting the form.
2. Complete the form in a quiet and private setting, away from distractions.
3. Answer all questions thoroughly and honestly.
4. Use the dropdown menus to select the correct options for each field.
5. Review and edit your responses before submitting the form.

## Field-by-Field Explanation

* **Employee Name** (`employee_name`, text, required): This is the name of the employee you are evaluating. Please enter the employee's full name as it appears on their personnel records.
* **Evaluation Period** (`evaluation_period`, date, required): This is the time period during which the employee's performance was being evaluated. Enter the start and end dates of the evaluation period.
* **Evaluation Date** (`evaluation_date`, date, required): This is the date on which the evaluation was completed. Enter the date the form was submitted.
* **Manager Name** (`manager_name`, text, required): This is your name as the manager evaluating the employee. Please enter your name as it appears on your personnel records.
* **Employee Rating** (`employee_rating`, select_one, required): This is a rating of the employee's overall performance. Select one of the three options provided:
	+ Option 1: Exceeded Expectations
	+ Option 2: Met Expectations
	+ Option 3: Did Not Meet Expectations
* **Strengths** (`strengths`, select_multiple, required): This is a list of the employee's strengths during the evaluation period. Select all applicable options from the dropdown menu.
* **Areas for Improvement** (`areas_for_improvement`, text, required): This is a list of areas where the employee needs improvement. Enter specific details about the areas for improvement.
* **Comments** (`comments`, text, optional): This is an optional field for you to provide any additional comments or feedback about the employee's performance.
* **Signature** (`signature`, text, optional): This is an optional field for you to sign and date the evaluation form.

Note: All fields marked as "required" must be completed before submitting the form.
