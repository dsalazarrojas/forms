# Sunday School Evaluation Form - Help Guide
## Purpose
The Sunday School Evaluation Form is a tool used to evaluate the performance of students and staff members in a Sunday school setting.

## How To Complete This Form
1. Please complete the form completely and accurately for each student or staff member being evaluated.
2. Use the correct format for date fields (mm/dd/yyyy).
3. Use numerical values for attendance and attitude fields.

## Field-by-Field Explanation

* **Student Name** (`student_name`, text, optional): Enter the name of the student being evaluated.
* **Class ID** (`class_id`, number, optional): Enter the ID number of the class the student belongs to.
* **Date** (`date`, date, optional): Enter the date of the evaluation (mm/dd/yyyy).
* **Evaluation Date** (`evaluation_date`, date, optional): Enter the date of the evaluation (mm/dd/yyyy).
* **Student Attendance** (`student_attendance`, number, optional): Enter the number of times the student has attended Sunday school.
* **Student Attitude** (`student_attitude`, number, optional): Enter a numerical value indicating the student's attitude during the evaluation period.
* **Parent Attendance** (`parent_attendance`, number, optional): Enter the number of times the parent has attended Sunday school.
* **Parent Attitude** (`parent_attitude`, text, optional): Enter a text description of the parent's attitude during the evaluation period.
* **Teacher Attendance** (`teacher_attendance`, number, optional): Enter the number of times the teacher has attended Sunday school.
* **Teacher Attitude** (`teacher_attitude`, number, optional): Enter a numerical value indicating the teacher's attitude during the evaluation period.

## Tips
- Double-check your entries for accuracy before submitting.
- Ensure that you are filling out the form for the correct student or staff member.
- If a field is marked as required, ensure that you complete it as it is part of the evaluation process.
