# Quality Benchmark Pilot Application Form - Help Guide
## Purpose
This form is designed to gather essential information from organizations applying for a quality benchmark pilot. It's a critical step in the application process, and accurate completion will help us evaluate your organization's readiness for the pilot program.

## How To Complete This Form
1. **Form Title**: Enter the title of your organization or the program you're applying for. (required)
2. **Program Manager Name**: Enter the name of the program manager responsible for the quality benchmark pilot. (required)
3. **Program Manager Email**: Enter the email of the program manager. (required)
4. **Organization Name**: Enter the name of your organization. (required)
5. **Program Type**: Enter the type of program you're interested in piloting. (required)
6. **Program Description**: Provide a brief description of your program. (optional)
7. **Contact Name**: Enter the name of the contact person for the pilot program. (required)
8. **Contact Email**: Enter the email of the contact person. (required)
9. **Contact Phone**: Enter the phone number of the contact person. (optional)
10. **Contact Notes**: Enter any additional notes or comments about the contact person. (optional)
11. **Organization Ready for Pilot**: Check 'Yes' if your organization is ready for the pilot program, 'No' if it's not, or 'Maybe' if you're unsure. (required)
12. **Program Start Date**: Enter the expected start date of the program. (required)
13. **Program End Date**: Enter the expected end date of the program. (required)
14. **Assessment Start Date**: Enter the expected start date of the assessment. (optional)
15. **Assessment End Date**: Enter the expected end date of the assessment. (optional)
16. **Evaluation Criteria**: Enter any specific evaluation criteria for the pilot program. (optional)
17. **Participant Names**: List the names of all participants involved in the program. (optional)
18. **Participant Emails**: List the emails of all participants. (optional)
19. **Participant Titles**: List the titles or positions of all participants. (optional)
20. **Participant Organizations**: List the organizations of all participants. (optional)
21. **Participant Phones**: List the phone numbers of all participants. (optional)
22. **Participant Notes**: Enter any additional notes or comments about the participants. (optional)
23. **Evaluation Criteria Comments**: Enter any comments or feedback about the evaluation criteria. (optional)
24. **Participant Benchmarking Status**: Choose the status of the participant(s) in the pilot program: 'Not Selected', 'In Progress', or 'Completed'. (optional)
25. **Notes**: Enter any additional notes or comments about the application. (optional)

## Field-by-Field Explanation

* **Form Title (1)**: A brief title of the form that should describe the purpose of the application.
* **Program Manager Name (2)**: The name of the person responsible for managing the quality benchmark pilot within the organization.
* **Program Manager Email (3)**: The email address of the program manager.

* **Program Type (5)**: The type or category of the program being applied for.

* **Contact Name (7)**: The name of the person responsible for contact and communication about the pilot program.

* **Contact Phone (9)**: The phone number of the contact person.
* **Contact Notes (10)**: Additional notes or comments about the contact person.
* **Organization Ready for Pilot (11)**: Check 'Yes' if your organization is ready for the pilot program, 'No' if it's not, or 'Maybe' if you're unsure.
* **Program Start Date (12)**: The expected start date of the program.
* **Program End Date (13)**: The expected end date of the program.
* **Assessment Start Date (14)**: The expected start date of the assessment.
* **Assessment End Date (15)**: The expected end date of the assessment.
* **Evaluation Criteria (16)**: Specific evaluation criteria for the pilot program.
* **Participant Names (17)**: List the names of all participants involved in the program.
* **Participant Emails (18)**: List the emails of all participants.
* **Participant Titles (19)**: List the titles or positions of all participants.
* **Participant Organizations (20)**: List the organizations of all participants.
