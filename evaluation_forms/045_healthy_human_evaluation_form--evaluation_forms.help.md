# Healthy_Human_Evaluation_Form - Help Guide
## Purpose
The Healthy Human Evaluation Form is used to gather information about a person's health and wellness. It is a collection of questions that help assess physical and mental health status, habits, and lifestyle choices.

## How To Complete This Form
To complete this form, simply go through each question and answer the following:
- Select all that apply for each question
- Answer each question with the options provided
- Make sure to review your answers carefully before submitting the form

## Field-by-Field Explanation

* **Main Page (1)** (`main_page`, text, optional): This is the introduction page of the form. It is not required to answer this question.
* **How often do you visit your healthcare provider? (2)** (`evaluation_question_1`, select_multiple, optional): This question asks about the frequency of visits to a healthcare provider. Answer with one or more of the following options:
	+ Never
