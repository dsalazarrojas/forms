# Draft GCs Reporting Form - Help Guide

## Purpose
The Draft GCs Reporting Form is designed to collect information related to draft General Correspondence reports. This form is used to track and document draft GCs for further review and processing. Please use this form to report all new or updated draft GCs.

## How To Complete This Form
To complete this form, follow these steps:

1. Ensure that you have reviewed and understood the purpose and instructions outlined above.
2. Fill out the form accurately and completely.
3. Select the correct options for each field as applicable.
4. Review and verify your submission before submitting.

## Field-by-Field Explanation

### 1. User Input
* **User Input** (`user_input`, text, optional): This field is a text input where you can provide any additional comments or information related to the draft GCs being reported.

### 2. Report Date
* **Report Date** (`report_date`, date, required): Enter the date when the draft GC was reported. This is a mandatory field.

### 3. Comments
* **Comments** (`draft_gcs_reporting_form_comments`, note, optional): This field is for any additional comments or information you would like to provide about the draft GCs being reported.

### 4. Assigned Technician
* **Assigned Technician** (`assigned_technician`, select_one, required): Indicate if the draft GC has been assigned to a technician. Select 'Yes' if it has.

### 5. Phone
* **Phone** (`phone`, text, optional): Enter the phone number of the technician assigned to the draft GC.

### 6. Email
* **Email** (`email`, email, required): Enter the email address of the technician assigned to the draft GC.

### 7. Second Assigned Technician
* **Second Assigned Technician** (`assigned_technician_2`, select_one, optional): Indicate if the draft GC has been assigned to a second technician. Select 'Yes' if it has.

### 8. Second Phone
* **Second Phone** (`phone_2`, text, optional): Enter the phone number of the second technician assigned to the draft GC.

### 9. Second Email
* **Second Email** (`email_2`, email, optional): Enter the email address of the second technician assigned to the draft GC.

### 10. Second Report Date
* **Second Report Date** (`report_date_2`, date, optional): Enter the date when the second report was submitted.

### 11. Second Comments
* **Second Comments** (`draft_gcs_reporting_form_comments_2`, note, optional): This field is for any additional comments or information related to the second report.

### 12. Third Assigned Technician
* **Third Assigned Technician** (`assigned_technician_3`, select_one, optional): Indicate if the draft GC has been assigned to a third technician. Select 'Yes' if it has.

### 13. Third Phone
* **Third Phone** (`phone_3`, text, optional): Enter the phone number of the third technician assigned to the draft GC.

### 14. Third Email
* **Third Email** (`email_3`, email, optional): Enter the email address of the third technician assigned to the draft GC.

### 15. Third Report Date
* **Third Report Date** (`report_date_3`, date, optional): Enter the date when the third report was submitted.

### 16. Third Comments
* **Third Comments** (`draft_gcs_reporting_form_comments_3`, note, optional): This field is for any additional comments or information related to the third report.

### 17. Fourth Assigned Technician
* **Fourth Assigned Technician** (`assigned_technician_4`, select_one, optional): Indicate if the draft GC has been assigned to a fourth technician. Select 'Yes' if it has.

### 18. Fourth Phone
* **Fourth Phone** (`phone_4`, text, optional): Enter the phone number of the fourth technician assigned to the draft GC.

### 19. Fourth Email
