# Master Program Evaluation Form - Help Guide
## Purpose
The Master Program Evaluation Form is used to collect feedback and comments from users on various aspects of the master program, including policies, faculty issues, and information and support availability.

## How To Complete This Form
To complete this form, follow these steps:

1. Review the form fields and labels carefully.
2. Provide your honest feedback and comments in the designated fields.
3. Select the most applicable options for "information access," "policies clarity," "faculty issues," and other relevant fields.
4. Write as much or as little as you see fit in the comment fields.

## Field-by-Field Explanation

* **comments**: This field is for any additional comments or feedback you have on the program.
* **comments2**: Another field for additional comments or feedback.
* **comments3**, **comments4**, ..., **comments20**: Multiple fields for users to provide further comments and feedback.
* **information access**: Select "Yes" if you have access to the necessary information for the program. Select "No" otherwise.
* **policies clarity**: Indicate the clarity of the program's policies by selecting "Yes" if they are clear or "No" if they are not.
* **faculty issues**: Identify any faculty issues that you have encountered while participating in the program by selecting "Yes" if there are issues or "No" if there are no issues.
* **academic support**: Select "Yes" if you have received adequate academic support from the program or "No" if not.
* **comments** (note field with id 2) is another field for further comments or feedback.
