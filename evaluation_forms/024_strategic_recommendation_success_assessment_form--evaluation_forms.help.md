# Strategic Recommendation Success Assessment Form - Help Guide
## Purpose
This form is designed to assess the success of a project by gathering information on expected and actual outcomes, project manager's comments, and recommendations for improvement.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the name of the project that was completed.
2. Enter the name of the project manager who oversaw the project.
3. Enter the name of the strategic initiative that the project was part of.
4. Describe the expected outcome of the project.
5. Describe the actual outcome of the project.
6. Rate the project outcome success, on a scale of 1-10.
7. Provide any recommendations for improvement, if necessary.
8. Repeat step 7 for any additional recommendations.
9. Provide any comments about the project.
10. Enter a final rating of the project's overall success, on a scale of 1-10.

## Field-by-Field Explanation

* **project_name (Text, Optional)**: Enter the name of the project that was completed.
* **project_manager_name (Text, Optional)**: Enter the name of the project manager who oversaw the project.
* **strategic_initiative_name (Text, Optional)**: Enter the name of the strategic initiative that the project was part of.
* **expected_outcome (Text, Optional)**: Describe the expected outcome of the project.
* **actual_outcome (Text, Optional)**: Describe the actual outcome of the project.
* **project_outcome_success_rating (Text, Optional)**: Rate the project outcome success, on a scale of 1-10.
* **recommendation_for_improvement (Text, Optional)**: Provide any recommendations for improvement, if necessary.
* **recommendation_for_improvement_2 (Text, Optional)**: Repeat step 6 for any additional recommendations.
* **recommendation_for_improvement_3 (Text, Optional)**: Repeat step 6 for any additional recommendations.
* **overall_project_success_rating (Text, Optional)**: Enter a final rating of the project's overall success, on a scale of 1-10.
* **project_manager_comments (Text, Optional)**: Provide any comments about the project.

## Tips

* Make sure to be as specific as possible when describing the expected and actual outcomes.
* Use numbers to rate the project outcome success and overall project success.
* Provide as many recommendations for improvement as necessary.
* Make sure to include any comments about the project.
* This form is designed to be as flexible as possible, so don't hesitate to add or remove fields as needed.
