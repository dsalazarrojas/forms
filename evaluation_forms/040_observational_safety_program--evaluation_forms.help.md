# Observational Safety Program - Help Guide
## Purpose
The Observational Safety Program form is designed to help site inspectors document and report on the safety conditions of a construction site. This form is used to gather information on various aspects of site safety, including site address, inspector name, and date of inspection.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the **Site Address** of the construction site being inspected.
2. Enter the name of the **Inspector Name** who conducted the inspection.
3. Select the **Date Of Inspection** using the calendar picker.
4. Select the **Time Of Inspection Start** and **Time Of Inspection End** using the time picker.
5. Enter the current **Weather Conditions** at the site.
6. Enter any **Inspector Comments** regarding the site conditions or concerns.
7. Select or describe the **Safety Equipment Provided** at the site, such as safety glasses, harnesses, or vests.
8. If any safety equipment not listed is provided, enter **Safety Equipment Provided Other**.
9. Check if hazardous materials such as **Paint**, **Chemicals**, or **Power Tools** are used on site. You can also select **Other** if the material used is not listed.
10. If other hazardous materials are used on site, enter **Hazardous Materials Used Other**.
11. Select **Confined Space Entry** status as **True** or **False**, and if **True**, enter the reason for the confined space entry.
12. Enter the **Scaffolding Height** if applicable.
13. Select the type of **Scaffolding** used, such as **Scaffold Tower**, **Swing Staging**, or **Scaffolding**.
14. If other scaffolding types are used, enter **Scaffolding Type Other**.
15. Enter the **Scaffolding Condition** and check if **Scaffolding Stability Checked**.
16. If other scaffolding stability checked status is selected, enter **Scaffolding Stability Checked Other**.
17. Finally, enter any **Site Inspection Notes** regarding the site conditions or concerns.

## Field-by-Field Explanation

* **Site Address**: Enter the address of the construction site being inspected.
* **Inspector Name**: Enter the name of the inspector who conducted the inspection.
* **Date Of Inspection**: Select the date of the inspection using the calendar picker.
* **Time Of Inspection Start**: Select the start time of the inspection using the time picker.
* **Time Of Inspection End**: Select the end time of the inspection using the time picker.
* **Weather Conditions**: Enter the current weather conditions at the site.
* **Inspector Comments**: Enter any comments or concerns regarding the site conditions or concerns.
* **Safety Equipment Provided**: Select the safety equipment provided on site, such as safety glasses, harnesses, or vests.
* **Safety Equipment Provided Other**: If other safety equipment is provided on site, enter the name and description of the equipment.
* **Hazardous Materials Used**: Check if hazardous materials such as paint, chemicals, or power tools are used on site. You can also select **Other** if the material used is not listed.
* **Hazardous Materials Used Other**: If other hazardous materials are used on site, enter the name and description of the material.
* **Confined Space Entry**: Select **True** if confined space entry is possible, and enter the reason for the entry.
* **Scaffolding Height**: Enter the height of the scaffolding if applicable.
* **Scaffolding Type**: Select the type of scaffolding used, such as **Scaffold Tower**, **Swing Staging**, or **Scaffolding**.
* **Scaffolding Type Other**: If other scaffolding types are used, enter the name and description of the type.
* **Scaffolding Condition**: Enter the condition of the scaffolding, such as **Good**, **Fair**, or **Poor**.
* **Scaffolding Stability Checked**: Check if scaffolding stability is checked, and if **False**, enter the reason for not checking.
* **Scaffolding Stability Checked Other**: If other scaffolding stability checked status is selected, enter the reason.
* **Site Inspection Notes**: Enter any notes or concerns regarding the site conditions or concerns.

**Tips**

* Make sure to complete all fields as accurately and thoroughly as possible.
* If you are unsure about any field, ask the project manager or site supervisor for guidance.
* This form is only for authorized site inspectors, and data collected should be used solely for the purpose of improving site safety.
* If you have any questions or concerns about this form, contact the project manager or site supervisor.
