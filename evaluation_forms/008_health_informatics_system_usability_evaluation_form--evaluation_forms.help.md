# Health Informatics System Usability Evaluation Form - Help Guide
## Purpose
This form is designed to assess the usability and effectiveness of a Health Informatics System. It aims to gather information on how well the system meets the user's needs and expectations.

## How To Complete This Form
To complete this form, follow these steps:

1. Start by reading the form carefully and understanding what each question is asking.
2. Answer each question truthfully based on your real-world experience with the Health Informatics System.
3. Use the dropdown menu options to choose the most accurate response for each question.
4. Make sure to submit the form when you have finished.

## Field-by-Field Explanation

* **Health Informatics System Usability Evaluation Form** (<page 1>): Enter a short description of the form, describing its purpose and scope.
* **patient_name** (<page 2>): Please enter the name of the patient you used the Health Informatics System for.
* **health_informatics_system** (<page 3>): Describe the Health Informatics System you used.
* **user_experience** (<page 4>): Answer in number, where 1-10, how easy was it for you to use the system? (e.g., 8)
* **user_frustration** (<page 5>): If you experienced any frustration while using the system, describe it briefly.
* **Health IT System Usability Evaluation Form** (<page 6>): Choose the level of usability for the system you used. Please select one or more options:
	+ System Usability
	+ System Usability and Functionality
	+ System Usability and Functionality and Responsiveness
* **Evaluation Form 3** (<page 7>): If you have any feedback or comments about the system, please enter them here.
* **system_usability** (<page 8>): Rate the usability of the system you used. Please select one option:
	+ Good
	+ Very Good
	+ Fair
	+ Poor
* **goals_achieved** (<page 9>): If you have any goals or expectations that you wanted to achieve while using the system, please describe them briefly.

## Tips
* Answer each question carefully and honestly.
* If you're unsure of how to answer a question, ask for help or contact the system administrators.
* If you have any additional feedback or comments, please enter them in the **Evaluation Form 3** field.
