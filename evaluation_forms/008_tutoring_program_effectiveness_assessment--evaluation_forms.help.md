# Tutoring Program Effectiveness Assessment - Help Guide
## Purpose
This form is designed to help evaluate the effectiveness of a tutoring program. It asks for feedback on the overall experience, satisfaction with progress, and areas of improvement.

## How To Complete This Form
To complete this form, follow these steps:

* Read through each page carefully and answer all the questions honestly.
* For each page, you will be asked about your experience with the tutoring program.
* You can answer each question using the options provided or by typing your own response in the text fields.

## Field-by-Field Explanation

* **Overall Satisfaction (page_2)**: This question asks about your overall satisfaction with the tutoring program. Please select a number from 1 to 5, where 1 is "Not Satisfied" and 5 is "Very Satisfied".
* **Instruction Quality (page_3)**: This question asks about the quality of instruction provided by the tutors. Please select a number from 1 to 5, where 1 is "Poor" and 5 is "Excellent".
* **Areas of Improvement (page_4)**: This question asks you to identify areas where the tutoring program could improve. Please type your response in the text field.
* **Program Outcomes (page_5)**: This question asks about the outcomes you have seen as a result of the tutoring program. Please select all that apply from the options provided.
* **Benefits Received (page_6)**: This question asks about the benefits you have received from the tutoring program. Please select all that apply from the options provided.
* **Program Goals (page_7)**: This question asks about how the tutoring program has met or exceeded your expectations. Please select all that apply from the options provided.
* **Feedback on Sessions (page_8)**: This question asks for your feedback about the tutoring sessions. Please type your response in the text field.
* **Satisfaction with Progress (page_9)**: This question asks about your satisfaction with your progress while in the tutoring program. Please select a number from 1 to 5, where 1 is "Not Satisfied" and 5 is "Very Satisfied".
* **Areas of Improvement (continued) (page_10)**: This question asks for additional areas where the tutoring program could improve. Please type your response in the text field.
* **Additional Feedback (page_11)**: This question asks for any additional feedback about the tutoring program. Please type your response in the text field.
* **More Feedback (page_12)**: This question asks for any more feedback about the tutoring program. Please type your response in the text field.
