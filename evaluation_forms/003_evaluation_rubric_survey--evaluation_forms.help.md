# Evaluation Rubric Survey - Help Guide
## Purpose
The Evaluation Rubric Survey is a form used to collect feedback and evaluation information from users. It is meant to be completed by evaluators who will score and provide comments on the submitted work to ensure consistency and fairness in the evaluation process.

## How To Complete This Form
This form is divided into several sections, each with its own set of questions or fields. Please read each section carefully and complete all required fields. Here's an overview of what to expect:

1. **Introduction**: This is a text field where you can provide any relevant background or context information about the submission.
2. **Criteria 1-Criteria 5**: These sections ask you to select an option that best matches the submission's quality in relation to each of the 5 criteria. Please select one option for Criteria 1 and multiple options for Criteria 2-5 as applicable.
3. **Score 1-Score 3**: These fields ask you to enter a numerical score for each of the 3 criteria. Please enter a number between 1 and 10 for each score.
4. **Submission Date** and **Evaluation Date**: These fields ask for the dates of submission and evaluation respectively.
5. **Comments**: This is a text field where you can provide any additional comments or feedback on the submission.

## Field-by-Field Explanation

### Introduction
* **Introduction** (`introduction`, `text`, optional): This is a text field where you can provide any relevant background or context information about the submission.

### Criteria 1
* **Criteria 1** (`criteria_1`, `select_one`, optional): Select the option that best matches the submission's quality in relation to this criteria.

### Criteria 2
* **Criteria 2** (`criteria_2`, `select_multiple`, optional): Select multiple options that best match the submission's quality in relation to this criteria.

### Criteria 3
* **Criteria 3** (`criteria_3`, `date`, optional): Enter the date of submission.

### Criteria 4
* **Criteria 4** (`criteria_4`, `time`, optional): Enter the time of submission.

### Criteria 5
* **Criteria 5** (`criteria_5`, `note`, optional): Please enter any additional comments or feedback on the submission.

### Score 1
* **Score 1** (`score_1`, `number`, optional): Enter a numerical score between 1 and 10 for this criteria.

### Score 2
* **Score 2** (`score_2`, `number`, optional): Enter a numerical score between 1 and 10 for this criteria.

### Score 3
* **Score 3** (`score_3`, `number`, optional): Enter a numerical score between 1 and 10 for this criteria.

### Submission Date
* **Submission Date** (`submission_date`, `date`, optional): Enter the date the submission was made.

### Evaluation Date
* **Evaluation Date** (`evaluation_date`, `date`, optional): Enter the date this evaluation was made.

### Comments
* **Comments** (`comments`, `text`, optional): Please provide any additional comments or feedback on the submission. 

## Tips

* Please fill in all required fields to ensure a complete evaluation.
* If a field is not required, you can leave it blank.
* Be as specific as possible when providing feedback and comments.
* If you have any doubts or questions, please consult the submission guidelines.
* This form is designed to be easy to use, but if you need help, please reach out to the support team.
