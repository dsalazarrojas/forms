# International Exchange Program Impact Evaluation - Help Guide

## Purpose

The International Exchange Program Impact Evaluation form is designed to collect feedback and data on the impact of the International Exchange Program. This form helps to assess the effectiveness of the program in achieving its objectives and identifying areas for improvement.

## How To Complete This Form

### Page 1: Participant Information

* This page is used to collect information about the participant. Please enter your name, email, and phone number in the corresponding fields.

### Page 2: Exchange Details

* This page collects information about the exchange details, including the start and end dates of the program, and the duration of the program.

### Page 3: Outcomes Measured

* Select all the outcomes that were measured during the program. These include Language skills, Interpersonal skills, Cultural awareness, and Professional skills.

### Page 4: Evaluation Method

* Please describe the method used for evaluation.

### Page 5: Evaluation Location

* Select the location where the evaluation took place.

### Page 6: Participant Feedback

* Please provide your feedback about the program.

### Page 7: Evaluator Feedback

* Please provide your feedback about the participant.

### Page 8: Program Outcomes

* Select all the outcomes that were achieved by the participant as a result of the program.

### Page 9: Evaluator Recommendations

* Please provide recommendations for the participant or the program.

### Page 10: Evaluation Completion

* Enter the date when the evaluation was completed.

### Page 11: Participant Signature

* Please sign your name as the participant.

### Page 12: Evaluator Signature

* Please sign your name as the evaluator.

### Page 13: Participant Email

* Please enter your email address as the participant.

### Page 14: Evaluator Email

* Please enter your email address as the evaluator.

### Page 15: Participant Phone

* Please enter your phone number as the participant.

### Page 16: Evaluator Phone

* Please enter your phone number as the evaluator.

### Page 17: Evaluation Comments

* Please provide any additional comments about the evaluation.

### Page 18: Evaluator Comments

* Please provide any additional comments about the evaluation.

### Page 19: Participant Language

* Select your language.

### Page 20: Evaluator Language

* Select your language.

### Page 21: Program Start Date

* Enter the start date of the program.

### Page 22: Program End Date

* Enter the end date of the program.

### Page 23: Program Duration

* Enter the duration of the program.

### Page 24: Program Location

* Enter the location of the program.

### Page 25: Participant Status

* Select the participant status.
