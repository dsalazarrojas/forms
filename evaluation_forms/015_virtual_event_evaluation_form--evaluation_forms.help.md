# Virtual Event Evaluation Form - Help Guide
## Purpose
This Virtual Event Evaluation Form is designed to help evaluate the success of a virtual event. The form collects information on event details, speaker ratings, and overall satisfaction. The data collected will be used to improve future virtual events.

## How To Complete This Form
To complete this form, follow the instructions below:

1. Click on the "Virtual Event Evaluation Form" link to access the form.
2. Fill out the form by selecting or typing the required information.
3. Make sure to review the form before submitting it to ensure all required fields are filled out.

## Field-by-Field Explanation
### Virtual Event Details
* **Virtual Event Details** (`1`, `note`, required: `false`): This is a brief description of the virtual event. Please provide a concise summary of the event.

### Event Name
* **Event Name** (`2`, `text`, required: `false`): Enter the name of the event.

### Event Date
* **Event Date** (`3`, `date`, required: `false`): Select the date of the event.

### Time Zone
* **Time Zone** (`4`, `select_one`, required: `false`): Choose whether the event took place in a time zone that affected your experience.

### Session Topics
* **Session Topics** (`5`, `select_multiple`, required: `false`): Select the topics covered during the session.

### Select Topics
* **Select Topics** (`6`, `select_multiple`, required: `false`): Select the topics you want to rate as part of the session.

### Speaker Name
* **Speaker Name** (`7`, `select_one`, required: `false`): Choose whether the speaker was effective in their role.

### Speaker E-mail
* **Speaker E-mail** (`8`, `email`, required: `false`): Enter the email of the speaker.

### Speaker Phone
* **Speaker Phone** (`9`, `text`, required: `false`): Enter the phone number of the speaker.

### Speaker Rating
* **Speaker Rating** (`10`, `number`, required: `false`): Rate the performance of the speaker.

### Session Rating
* **Session Rating** (`11`, `number`, required: `false`): Rate the session itself.

### Overall Satisfaction
* **Overall Satisfaction** (`12`, `number`, required: `false`): Rate your overall satisfaction with the virtual event.

### Comments
* **Comments** (`13`, `note`, required: `false`): Provide any additional comments about the virtual event.

## Tips
* Please fill out all required fields to ensure accurate evaluation.
* If you have any additional comments or feedback, please use the "Comments" field.
* If you have any issues or questions, contact your event organizer.
