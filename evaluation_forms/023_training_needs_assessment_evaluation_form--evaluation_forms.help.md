# training_needs_assessment_evaluation_form - Help Guide
## Purpose
The "Training Needs Assessment Evaluation Form" is used to assess the training needs of employees in a organization.

## How To Complete This Form

1. Select one of the options for "first_page" to indicate which page you are on.
2. If "training_needs" is a required field, enter a brief description of the employee's training needs.
3. For "training_level", select all levels that apply to the employee's training needs (High, Low).
4. Enter the evaluation date and time in the "evaluation_date" and "evaluation_time" fields, respectively.
5. Enter any additional evaluation notes in the "evaluation_notes" field.
6. Enter the employee's email address in the "email" field.
7. Enter the employee's phone number in the "phone_number" field.
8. Enter a brief justification for the employee's training needs in the "training_needs_justification" field.
9. Select "Yes" or "No" for "evaluation_form_submitted" to indicate if this form has been submitted before.
10. Select "Active" or "Inactive" for "evaluation_status" to indicate the status of the training needs.
11. Select "Active" or "Inactive" for "submission_status" to indicate the status of the submission.
12. Enter a text description for "submission_id" to identify the submission.
13. Select "Active" or "Inactive" for "submission_status" to indicate the status of the submission.

## Field-by-Field Explanation

* **first_page**: Select one of the options to indicate which page you are on.
* **training_needs**: Enter a brief description of the employee's training needs.
* **training_level**: Select all levels that apply to the employee's training needs (High, Low).
* **evaluation_date**: Enter the evaluation date in the format MM/DD/YY.
* **evaluation_time**: Enter the evaluation time in 24-hour format (HH:MM).
* **evaluation_notes**: Enter any additional evaluation notes.
* **email**: Enter the employee's email address.
* **phone_number**: Enter the employee's phone number.
* **training_needs_justification**: Enter a brief justification for the employee's training needs.
* **evaluation_form_submitted**: Select "Yes" or "No" to indicate if this form has been submitted before.
* **evaluation_status**: Select "Active" or "Inactive" to indicate the status of the training needs.
* **submission_id**: Enter a text description for the submission ID.
* **submission_status**: Select "Active" or "Inactive" to indicate the status of the submission.
