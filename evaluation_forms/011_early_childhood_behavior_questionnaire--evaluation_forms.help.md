# Early Childhood Behavior Questionnaire - Help Guide
## Purpose
The Early Childhood Behavior Questionnaire is a tool for caregivers or parents to report on a child's behavior, habits, and characteristics in early childhood.

## How To Complete This Form
1. Select the correct page and fill out the required fields.
2. For questions that have multiple options (e.g., select_multiple), choose the correct answer from the provided list.
3. Ensure all required fields are completed before submitting the form.
