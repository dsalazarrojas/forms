# Data Analytics In Medicine Research Evaluation - Help Guide
## Purpose
This form is designed to help assess the effectiveness and application of data analytics in medicine research. It collects feedback on various aspects of data analytics, including its outcomes, challenges, and improvements.

## How To Complete This Form
To complete this form, please follow these steps:

1. Begin by filling out the **introduction** field, which is a text field where you can provide a brief introduction to your evaluation.
2. Select all applicable **outcomes** from the list provided, as this field is required.
3. In the **challenges** field, enter any challenges or obstacles you have faced while applying data analytics in medicine research.
4. If you have any improvements or suggestions, enter them in the **improvements** field.
5. List your data sources in the **data sources** field, if applicable.
6. In the **outcomes_2** field, enter any additional outcomes or results you have achieved using data analytics.
7. Select all applicable **tools** from the list provided, as this field is optional.
8. In the **outcomes_3** field, enter any additional outcomes or results you have achieved using data analytics.
9. Finally, enter any additional suggestions or comments you have about data analytics in medicine research in the **suggestions** field.
10. Summarize your experience and feedback in the **comments** field.

## Field-by-Field Explanation
* **introduction** (`introduction`, text, optional): Enter a brief introduction to your evaluation.
* **outcomes** (`outcomes`, select_multiple, true): Select all applicable outcomes from the list provided. This field is required.
* **challenges** (`challenges`, text, optional): Enter any challenges or obstacles you have faced while applying data analytics in medicine research.
* **improvements** (`improvements`, text, optional): Enter any improvements or suggestions you have.
* **data sources** (`data sources`, text, optional): List your data sources, if applicable.
* **outcomes_2** (`outcomes_2`, text, optional): Enter any additional outcomes or results you have achieved using data analytics.
* **tools** (`tools`, select_multiple, false): Select all applicable tools from the list provided, if applicable. This field is optional.
* **outcomes_3** (`outcomes_3`, text, optional): Enter any additional outcomes or results you have achieved using data analytics.
* **suggestions** (`suggestions`, text, optional): Enter any additional suggestions or comments you have about data analytics in medicine research.
* **comments** (`comments`, text, optional): Summarize your experience and feedback in this field.
