# Softball Tryout Evaluation Form - Help Guide
## Purpose
The Softball Tryout Evaluation Form is designed to collect information about each player's skills and performance during the tryout session.

## How To Complete This Form
To complete this form, follow these steps:

1. Please fill in the player's information on the Player Info page.
2. Indicate which skills you have assessed on the Skills Assessed page.
3. Add any additional comments or notes on the Evaluation Comments page.
4. Date and time of the evaluation on the Evaluation Date page.

## Field-by-Field Explanation
* **Player Info** (`Player Info`, `text`, required/optional): Enter the player's name and any other relevant information you think would be helpful for the team.
* **Skills Assessed** (`Skills Assessed`, `select_multiple`, required/optional): Select all the skills you have assessed during the tryout, such as hitting, pitching, and fielding.
* **Evaluation Comments** (`Evaluation Comments`, `note`, required/optional): Add any comments or notes about the player's performance, such as strengths and weaknesses.
* **Evaluation Date** (`Evaluation Date`, `date`, required/optional): Enter the date and time of the evaluation, which will help track when the evaluation was conducted.

## Tips
- Make sure to provide honest and constructive feedback for the player.
- Keep the evaluation comments concise and specific.
- Use the date field to keep track of the evaluation timeline.
