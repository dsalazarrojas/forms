# feedback_form_bampm_2020 - Help Guide
## Purpose
This form is designed to collect feedback from users about the B&amp;M 2020 project.

## How To Complete This Form
To complete this form, follow these steps:

1. Review the form carefully before starting to ensure you are providing feedback for the correct project.
2. Answer each question carefully and accurately, providing as much detail as possible.
3. Make sure to fill out all required fields (* indicates a required field).
4. If you're unsure about any question, please ask for clarification.

## Field-by-Field Explanation
* **Feedback Form B&amp;M 2020** (`feedback_form_bampm_2020_page_6`, select_one, required): This field is used to select the type of feedback form you are providing.
* **Theatre Project Name** (`feedback_form_bampm_2020_page_2`, text, required): Please enter the name of the theatre project you are providing feedback on.
* **Rating** (`feedback_form_bampm_2020_page_3`, number, required): Please enter a number between 1 and 5 to rate your experience with the project.
* **Comments** (`feedback_form_bampm_2020_page_4`, text, false): This is a text field where you can provide more details about your experience with the project.
* **Contact** (`feedback_form_bampm_2020_page_5`, email, false): Please enter your contact information so we can follow up with you about your feedback.
* **Feedback Form Date** (`feedback_form_bampm_2020_page_7`, date, required): Please enter the date you are providing feedback on.
* **Feedback Form Time** (`feedback_form_bampm_2020_page_8`, time, required): Please enter the time you are providing feedback on.
* **Date** (`feedback_form_bampm_2020_page_7`, date, required) and **Time** (`feedback_form_bampm_2020_page_8`, time, required): Unfortunately, the "Date" and "Time" fields are very confusing and it seems they are not actually meant to be used as dates and times but rather something else. Please provide feedback on this and we'll clarify their purpose.
* **Feedback Form B&amp;M 2020** (`feedback_form_bampm_2020_page_6`, select_one, required): This field is meant to be a select_one type where the user has to pick one of the provided options: Feedback Form B&amp;M 2020, Evaluation Form, Other. However, it seems like this field is actually redundant with the "Feedback Form B&amp;M 2020" option provided in the select_one field above it. This field will be removed in the next iteration of the form.
 
## Tips
* Please be honest and accurate when providing feedback.
* If you have any questions or concerns, please do not hesitate to contact us.
* We appreciate your feedback and will use it to improve the project.
* Please make sure to proofread your feedback carefully before submitting it.
