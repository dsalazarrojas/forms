# Population Health Analytics Project Evaluation Form - Help Guide
## Purpose
This form is designed to evaluate the performance of population health analytics projects, providing a structured and comprehensive assessment of project objectives, outcomes, challenges, and future improvements.

## How To Complete This Form

To complete this form, please follow these steps:

1. Review the project's goals, objectives, and timelines.
2. Answer each question concisely, providing relevant and accurate information.
3. Be as detailed as possible in your responses, but keep in mind that this form is designed for a quick and easy assessment.

## Field-by-Field Explanation

* **Project Objectives**: Provide a brief description of the project's main objectives.
	+ Type: `text`
	+ Optional
* **Project Outcomes**: Select all applicable outcomes that match your project's performance.
	+ Type: `select_multiple`
	+ Options: Successful, Partially Successful, Not Successful
* **Project Challenges**: Describe any challenges or obstacles that hindered the project's progress.
	+ Type: `text`
	+ Optional
* **Future Improvements**: Suggest potential areas for improvement for future projects.
	+ Type: `text`
	+ Optional
* **Team Name**: Enter the name of your project team.
	+ Type: `text`
	+ Optional
* **Hospital Name**: Enter the name of the hospital or organization responsible for the project.
	+ Type: `text`
	+ Optional
* **Researcher Name**: Enter the name of the researcher or principal investigator.
	+ Type: `text`
	+ Optional
* **Project Start Date**: Enter the start date of the project.
	+ Type: `date`
	+ Optional
* **Project End Date**: Enter the end date of the project.
	+ Type: `date`
	+ Optional
* **Project Lead**: Select the project lead or manager responsible for the project.
	+ Type: `select_one`
	+ Options: John, Jane, Jim
* **Team Lead**: Enter the name of the team lead or coordinator.
	+ Type: `text`
	+ Optional
* **Feedback**: Provide any additional comments or feedback about the project.
	+ Type: `text`
	+ Optional
* **Evaluation Form**: A free-text field for comments or notes.
	+ Type: `note`
	+ Optional
* **Evaluation Form Date**: Enter the date of the form completion.
	+ Type: `date`
	+ Optional
* **Comments**: Additional comments or feedback about the project.
	+ Type: `text`
	+ Optional

## Tips

* Please answer each question truthfully and accurately.
* If you're unsure about any question, feel free to ask for clarification.
* This form is designed for a quick and easy assessment, so keep your answers concise but detailed.
* If you have any comments or feedback, use the `Feedback` or `Comments` fields.
