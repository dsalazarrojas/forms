# reading_recording_submission_form_template - Help Guide
## Purpose
The "reading_recording_submission_form_template" is a form designed to support the evaluation and recording of student submissions. It collects data on student submissions, including details about the recording, comments, feedback, and status updates.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the student's ID in the "Student Id" field.
2. Enter the submission date in the "Submission Date" field.
3. Provide the recording link in the "Recording Link" field.
4. Enter any comments in the "Comments" field.
5. Rate the recording quality using the "Recording Quality" dropdown menu.
6. Update the submission status using the "Submission Status" dropdown menu.
7. Enter any review notes in the "Review Notes" field.

## Field-by-Field Explanation
- **Student Id** (`student_id`, number, optional): Enter the student's ID, which is a unique identifier for the student.
- **Submission Date** (`submission_date`, date, optional): Enter the date the submission was made.
- **Recording Link** (`recording_link`, text, optional): Provide a link to the recording that was submitted.
- **Comments** (`comments`, text, optional): Enter any comments or feedback you have on the submission.
- **Rating** (`rating`, number, optional): Rate the recording quality using a scale.
- **Feedback** (`feedback`, text, optional): Enter any feedback you have on the submission.
- **Recording Quality** (`recording_quality`, select_one, optional): Rate the recording quality using the dropdown menu: Excellent, Good, Fair, or Poor.
- **Submission Status** (`submission_status`, select_one, optional): Update the submission status using the dropdown menu: Pending Review, Approved, Rejected, or Completed.
- **Review Notes** (`review_notes`, text, optional): Enter any review notes or comments on the submission.
