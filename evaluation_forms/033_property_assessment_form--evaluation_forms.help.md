# Property Assessment Form - Help Guide
## Purpose
The Property Assessment Form is a tool used to collect and document information about a property's characteristics, features, and condition. This form is essential for ensuring that properties are assessed accurately and consistently.

## How To Complete This Form
To complete this form, follow these steps:

1. Start by filling out the **Property Address** field with the property's address.
2. Next, answer the **Property Type** question by selecting 'Yes' or 'No' to indicate whether the property has the specified feature.
3. Enter the **Property Age** as a numerical value.
4. Describe the **Property Condition** by selecting all applicable features from the list.
5. In the **Property Features** field, provide a detailed description of the property's features.
6. Enter the **Property Value** as a numerical value.
7. Select the **Property Status** by choosing 'Active' or 'Inactive'.
8. Finally, enter the **Property Price** as a numerical value.

## Field-by-Field Explanation

* **Property Address** (Property Address, Text, Required): Enter the address of the property, including the house number, street name, and any additional details.
* **Property Type** (Property Type, Select One, Optional): Select 'Yes' if the property has the specified feature, otherwise select 'No'.
* **Property Age** (Property Age, Number, Required): Enter the age of the property as a numerical value.
* **Property Condition** (Property Condition, Select Multiple, Optional): Select all features that apply to the property's condition.
* **Property Features** (Property Features, Note, Optional): Provide a detailed description of the property's features.
* **Property Value** (Property Value, Number, Required): Enter the value of the property as a numerical value.
* **Property Status** (Property Status, Select One, Optional): Select 'Active' if the property is currently active, otherwise select 'Inactive'.
* **Property Price** (Property Price, Number, Required): Enter the price of the property as a numerical value.
* **Property Photos** (Property Photos, Text, Optional): Provide up to 500 characters for any additional photos or observations about the property.
* **Property Notes** (Property Notes, Note, Optional): Enter any additional notes or comments about the property.
