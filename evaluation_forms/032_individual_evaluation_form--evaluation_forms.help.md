# Individual Evaluation Form - Help Guide
## Purpose
The individual evaluation form is a tool used by managers to evaluate employees' performance, identify areas for improvement, and document feedback. This form ensures consistency and accuracy in the evaluation process.

## How To Complete This Form

To complete this form, follow these steps:

1. Enter the employee's name in the **Employee Name** field.
2. Select the employee's current position from the **Employee Position** field.
3. Enter the date of the evaluation in the **Evaluation Date** field.
4. For the **Evaluation Period**, select 'Yes' if the evaluation is for the current period, and 'No' otherwise.
5. Rate the employee's performance on a scale of 0-100 in the **Performance Rating** field.
6. Type any areas where the employee needs improvement in the **Areas for Improvement** field.
7. Write a comment for the employee in the **Employee Comments** field.
8. Add any comments from the manager in the **Manager Comments** field.
9. Set the evaluation status as **Pending**, **Complete**, or **Incomplete** in the **Evaluation Status** field.
10. If applicable, set the evaluation due date and completion date in the **Evaluation Due Date** and **Evaluation Completed Date** fields.
11. Enter the name of the person submitting the evaluation in the **Submitted By** field.
12. Enter the name of the person the evaluation is submitted to in the **Submitted To** field.

## Field-by-Field Explanation
* **Employee Name (text, required)**: Enter the name of the employee being evaluated.
* **Employee Position (text, required)**: Select the current position of the employee being evaluated.
* **Evaluation Date (date, optional)**: Enter the date of the evaluation.
* **Evaluation Period (select_one, required)**: Select 'Yes' if the evaluation is for the current period, and 'No' otherwise.
* **Performance Rating (number, required)**: Rate the employee's performance on a scale of 0-100.
* **Areas for Improvement (text, required)**: Identify any areas where the employee needs improvement.
* **Employee Comments (text, required)**: Write a comment for the employee.
* **Manager Comments (text, required)**: Add any comments from the manager.
* **Evaluation Status (select_one, required)**: Set the evaluation status as **Pending**, **Complete**, or **Incomplete**.
* **Evaluation Due Date (date, optional)**: Set the evaluation due date, if applicable.
* **Evaluation Completed Date (date, optional)**: Set the evaluation completion date, if applicable.
* **Submitted By (text, required)**: Enter the name of the person submitting the evaluation.
* **Submitted To (text, required)**: Enter the name of the person the evaluation is submitted to.
