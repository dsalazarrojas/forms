# Mentee Evaluation Form - Help Guide
## Purpose
The Mentee Evaluation Form is used to assess the progress and satisfaction of a mentee during a mentorship program or project.

## How To Complete This Form
To complete this form, follow these steps:

1. Ensure you have all the necessary information and context before starting to fill out the form.
2. Review the form and understand the questions and fields that need to be answered.
3. Fill out the form in the following fields:

### Field-by-Field Explanation

* **Mentee Progress** (`mentee_progress`): A text field where you can provide an update on the mentee's progress.
* **Feedback** (`feedback`): A text field where you can provide any additional feedback or comments about the mentee.
* **Program Progress** (`program_progress`): A text field where you can update the progress of the mentee in the program.
* **Mentee Satisfaction** (`mentee_satisfaction`): A multiple-choice field where you can rate the mentee's satisfaction with the program.
	+ Select one of the options: Satisfied or Dissatisfied.
* **Program Satisfaction** (`program_satisfaction`): A multiple-choice field where you can rate the mentee's satisfaction with the program.
	+ Select one of the options: Satisfied or Dissatisfied.
* **Evaluation Status** (`evaluation_status`): A single-choice field where you can select the current evaluation status.
	+ Select one of the options: Not yet started, Started, or Finished.
* **Evaluation Date** (`evaluation_date`): A date field where you can select the date of the evaluation.
* **Evaluation Time** (`evaluation_time`): A time field where you can select the time of the evaluation.
* **Mentee Comments** (`mentee_comments`): A text field where you can provide any comments from the mentee.
* **Mentor Comments** (`mentor_comments`): A text field where you can provide any comments or feedback from the mentor.
## Tips
* Ensure that you are providing honest and accurate feedback.
* Use clear and concise language when filling out the form.
* Make sure to save the form before submitting it.
