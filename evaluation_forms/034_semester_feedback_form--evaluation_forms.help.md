# semester_feedback_form - Help Guide
## Purpose
The semester_feedback_form is used to collect feedback from students about their experiences and satisfaction with the current semester.

## How To Complete This Form

1. The form has two sections, each representing a semester. Please fill out the fields for both sections.
2. Select the start and end dates for each semester in the corresponding date fields (semester_start_date and semester_end_date).
3. Select the start and end month for each semester in the corresponding select_one fields (start_month and end_month).
4. Rate your overall satisfaction with the current semester using the select_one field (overall_satisfaction).
5. Provide any additional feedback or comments about the current semester in the text field (feedback).
6. Enter the email of the user assigned to your feedback in the email field (assigned_user).
7. Enter your phone number to be contacted by the assigned user in the text field (phone_number).
8. Enter any additional notes about the current semester in the note field (notes).
9. Enter your name in the text field (participant_name).
10. Repeat steps 2-8 for the second section.

## Field-by-Field Explanation

* **semester_start_date**: The date when the current semester started.
* **start_month**: The month when the current semester started.
* **end_date**: The date when the current semester ended.
* **end_month**: The month when the current semester ended.
* **overall_satisfaction**: Rate your overall satisfaction with the current semester.
* **feedback**: Provide any additional feedback or comments about the current semester.
* **assigned_user**: The email of the user assigned to your feedback.
* **phone_number**: Enter your phone number to be contacted by the assigned user.
* **notes**: Enter any additional notes about the current semester.
* **participant_name**: Enter your name.
* **semester_end_date**: The date when the second semester ended.
* **start_month_2**: The month when the second semester started.
* **end_month_2**: The month when the second semester ended.
* **feedback_2**: Provide any additional feedback or comments about the second semester.
* **notes_2**: Enter any additional notes about the second semester.
* **assigned_user_2**: The email of the user assigned to your feedback for the second semester.
* **participant_name_2**: Enter your name for the second semester.
* **phone_number_2**: Enter your phone number to be contacted by the assigned user for the second semester.
* **phone_number_3**: Enter your phone number to be contacted by the assigned user for the third semester.
* **participant_name_3**: Enter your name for the third semester.
* **assigned_user_3**: The email of the user assigned to your feedback for the third semester.
