# Hospital Performance Evaluation Form - Help Guide

## Purpose
The Hospital Performance Evaluation Form is designed to provide an assessment of a hospital's performance in various key areas, including employee performance, patient care, time management, communication, teamwork, leadership, and patient satisfaction. This form helps evaluate the hospital's ability to provide quality care and services to its patients, staff, and the community. 

## How To Complete This Form
To complete this form, follow these steps:

1. Review the form pages, which include Hospital Overview, employee performance, patient care, time management, communication, teamwork, leadership, and patient satisfaction.
2. Fill out the form by selecting the relevant options for each page, or type in any additional comments or notes if necessary.
3. Make sure to submit your evaluation at the end of the form.

## Field-by-Field Explanation

### Hospital Overview (Page 1)
* **Hospital Overview**: This is a note field where you can provide a brief overview of the hospital's performance, including any notable achievements or areas for improvement.

### Employee Performance (Page 2)
* **Employee performance**: This is a select multiple field where you can choose up to 3 options that best describe the hospital's employee performance:
	+ Option 1: High
	+ Option 2: Medium
	+ Option 3: Low

### Patient Care (Page 3)
* **Patient care**: This is a select one field where you can choose one option that best describes the hospital's patient care:
	+ Option 1: Excellent
	+ Option 2: Good
	+ Option 3: Needs Improvement

### Time Management (Page 4)
* **Time management**: This is a number field where you can input a numerical value that best describes the hospital's time management. Please use a scale from 1 to 10.

### Communication (Page 5)
* **Communication**: This is a select multiple field where you can choose up to 3 options that best describe the hospital's communication:
	+ Option 1: Effective
	+ Option 2: Medium
	+ Option 3: Poor

### Teamwork (Page 6)
* **Teamwork**: This is a select one field where you can choose one option that best describes the hospital's teamwork:
	+ Option 1: High
	+ Option 2: Medium
	+ Option 3: Low

### Leadership (Page 7)
* **Leadership**: This is a note field where you can provide a brief note about the hospital's leadership, including any notable achievements or areas for improvement.

### Patient Satisfaction (Page 8)
* **Patient satisfaction**: This is a select multiple field where you can choose up to 3 options that best describe the patient's satisfaction with the hospital:
	+ Option 1: High
	+ Option 2: Medium
	+ Option 3: Low

## Tips
* Please be thorough and honest when completing this form.
* If you have any additional comments or suggestions, please type them in the note fields.
* Make sure to submit your evaluation at the end of the form.
