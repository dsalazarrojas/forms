# Medical Equipment Loan Request Form - Help Guide
## Purpose
This form is designed to request medical equipment loans. It collects information about the loan request, equipment details, and other relevant data to facilitate a smooth lending process.

## How To Complete This Form
1.  Review each field carefully and fill in the required information accurately.
2.  Provide details about the equipment you are requesting to be loaned out, including its status and any additional notes.
3.  Specify the loan period and loaner fee (if applicable).
4.  Confirm the loaner's contact information and any additional details.
5.  Review your submission before submitting the form.

## Field-by-Field Explanation
- **Loan Request**: A brief description of the loan request, including the reason for the request.
  - Type: text
  - Required: false
  - This field provides an opportunity to briefly describe the purpose of the loan request.
- **Equipment Details**: A description of the equipment being requested.
  - Type: text
  - Required: false
  - Provide specific details about the equipment, such as its make and model, condition, and any other relevant information.
- **Loan Date**: The date when you would like to take possession of the loaned equipment.
  - Type: date
  - Required: false
  - Enter the date when you will need the equipment.
- **Return Date**: The date when you will return the loaned equipment.
  - Type: date
  - Required: false
  - Enter the date by which you will return the equipment.
- **Reason**: A brief explanation of why you need the equipment.
  - Type: text
  - Required: false
  - Describe the reason for requesting the loan in a concise manner.
- **Borrower Details**: Additional information about the borrower.
  - Type: text
  - Required: false
  - Provide any relevant details about the borrower, such as their department or contact information.
- **Equipment List**: A list of the equipment being loaned out.
  - Type: select multiple
  - Required: false
  - Select from the options provided, indicating which equipment is being loaned out.
- **Loan Period**: The duration of the loan period.
  - Type: number
  - Required: false
  - Specify the number of days or weeks you will need the equipment for.
- **Loaner Fee**: The fee associated with loaning out the equipment.
  - Type: number
  - Required: false
  - Enter the fee, if applicable.
- **Equipment Status**: The status of the loaned equipment.
  - Type: select one
  - Required: false
  - Choose from the available options: Available, Unavailable, In Use.
- **Status Update**: An optional note about the loan request's progress.
  - Type: text
  - Required: false
  - Provide any updates about the loan request.
- **Borrower Info**: Additional borrower information (e.g., department, contact info).
  - Type: text
  - Required: false
  - Enter any relevant borrower information.
- **Equipment ID**: The equipment ID number.
  - Type: number
  - Required: false
  - Enter the equipment ID number.
- **Loaner Contact**: The contact information of the loaner.
  - Type: text
  - Required: false
  - Enter the loaner's contact information.
- **Loaner Email**: The loaner's email address.
  - Type: email
  - Required: false
  - Enter the loaner's email address.
- **Notes**: Any additional information about the loan request.
  - Type: note
  - Required: false
  - Enter any additional notes about the loan request.
