# support_leadership_continuity_form - Help Guide
## Purpose
The support leadership continuity form is a tool used to identify and document potential successors for key roles within the organization. This form helps ensure that the organization is prepared for a smooth transition of responsibilities in case of vacancies.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the succession status of the role:
	* If a successor has been identified, select "successor Identified".
	* If no successor has been identified, select "No Successor Identified".
	* If the role is not applicable for succession, select "Not Applicable".
2. List potential successors for the role. Select all applicable options from the list of:
	* Successors 1
	* Successors 2
	* Successors 3
3. (Optional) Provide additional comments about the role or potential successors.
4. Describe the next steps for each identified successor.

## Field-by-Field Explanation

* **Succession Status** (`succession_status`, Select One, required: false): Select the current succession status of the role. This will help determine the next steps for completing the form.
* **Potential Successors** (`potential_successors`, Select Multiple, required: false): List all potential successors for the role. Select all applicable options from the list of Successors 1, Successors 2, and Successors 3. This will help identify potential candidates for the role in case of a vacancy.
* **Resource Needs** (`resource_needs`, Number, required: false): This field is intended for additional information or notes about the resource needs or requirements for the potential successors. Please note that this field is not currently being used.
* **Additional Comments** (`additional_comments`, Note, required: false): Provide any additional comments or information about the role or potential successors.
* **Next Steps** (`next_steps`, Text, required: false): Describe the next steps for each identified successor. This will help ensure that the organization is prepared for a smooth transition of responsibilities.
