# project_management_roadmap_form - Help Guide
## Purpose
The project_management_roadmap_form is used to capture high-level project management details.

## How To Complete This Form
To complete this form, simply fill out the fields as follows:

1. **Project Objectives** (`project_objectives`, text, optional): Enter a brief description of the project's objectives.
2. **Project Timelines** (`project_timelines`, number, optional): Enter the project's timelines.
3. **Project Milestones** (`project_milestones`, select_multiple, optional): Select one or more of the following options:
	* Yes
	* No
4. **Project Owners** (`project_owners`, select_one, optional): Select one of the following options:
	* Yes
	* No
5. **Project Risks** (`project_risks`, select_multiple, optional): Select one or more of the following options:
	* Yes
	* No
6. **Project Risks Notes** (`project_risks_notes`, note, optional): Enter additional information about project risks.
7. **Project Start Date** (`project_start_date`, date, optional): Enter the project start date.
8. **Project End Date** (`project_end_date`, date, optional): Enter the project end date.

## Field-by-Field Explanation

* **Project Objectives**: Enter a brief description of the project's objectives.
* **Project Timelines**: Enter the project's timelines.
* **Project Milestones**: Select one or more of the following:
	+ Yes: Indicate that the project has milestones.
	+ No: Indicate that the project does not have milestones.
* **Project Owners**: Select one of the following:
	+ Yes: Indicate that the project has a single owner.
	+ No: Indicate that the project does not have an owner.
* **Project Risks**: Select one or more of the following:
	+ Yes: Indicate that the project has risks.
	+ No: Indicate that the project does not have risks.
* **Project Risks Notes**: Enter additional information about project risks.
* **Project Start Date**: Enter the project start date.
* **Project End Date**: Enter the project end date.

## Tips
- Make sure to fill out all the required fields (none of the fields in this form are required, so you can fill out as many or as few fields as you like).
- Double-check your entries for accuracy and completeness.
- You can select multiple options for project milestones and risks by holding down the Ctrl key (or Command key on a Mac) while clicking on multiple options.
