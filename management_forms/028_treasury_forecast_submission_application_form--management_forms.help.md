# Treasury Forecast Submission Application Form - Help Guide
## Purpose
This form is designed to help users submit and track financial forecast and actual data for a specific period. It gathers information on department, period, cash inflow, and other relevant details to facilitate planning and analysis.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the relevant department and period for the forecast and actual data.
2. Indicate whether cash inflow is present or not for each department.
3. Enter the start and end dates for both forecast and actual periods.
4. Enter the forecast and actual values for each department.
5. Select the period for which the data applies.
6. Confirm your identity as the user submitting the data.
7. Verify the entity for which the data is being submitted.

## Field-by-Field Explanation

* **Department Id (department_id)**: Select the department for which you are submitting the data.
* **Period Id (period_id)**: Choose the period for which the data is being submitted.
* **Cash Inflow Id (cash_inflow_id)**: Indicate whether cash inflow is present or not for the selected department.
* **Forecast Start Date (forecast_start_date)**: Enter the start date of the forecast period.
* **Forecast End Date (forecast_end_date)**: Enter the end date of the forecast period.
* **Actual Start Date (actual_start_date)**: Enter the start date of the actual period.
* **Actual End Date (actual_end_date)**: Enter the end date of the actual period.
* **Forecast (forecast)**: Enter the forecasted value for the selected department.
* **Actual (actual)**: Enter the actual value for the selected department.
* **Period (period)**: Select the period for which the data applies.
* **User Id (user_id)**: Confirm your identity as the user submitting the data.
* **Entity Id (entity_id)**: Verify the entity for which the data is being submitted.
