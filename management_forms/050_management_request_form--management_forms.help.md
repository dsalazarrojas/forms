# Management Request Form - Help Guide
## Purpose
The Management Request Form is used by team members to submit requests for management's consideration. These requests are typically for tasks that need to be assigned to specific team members, such as tasks that require special attention or resources.

## How To Complete This Form
To complete this form, please follow these steps:

1. Ensure that you have not already created a duplicate request for the same task.
2. Fill out all required fields, indicated by an asterisk (\*) in the label.
3. Provide accurate information in each field, as incomplete or inaccurate information can lead to requests being declined or delayed.
4. Submit the form once you have completed all required fields.

## Field-by-Field Explanation
* **Form Name** (`form_name`, text, **required**): Enter a brief description of the request or task.
* **Departmental Request** (`departmental_request`, number, **required**): Select the department that the request is related to.
* **Request Date** (`request_date`, date, **required**): Enter the date of the request.
* **Request Time** (`request_time`, time, **required**): Enter the time of the request.
* **Requestor** (`requestor`, select_one, **required**): Select the person making the request.
* **Department** (`department`, select_multiple, **required**): Select the department(s) that the request is related to.
* **Priority** (`priority`, select_one, **required**): Select the priority level of the request.
* **Request Details** (`request_details`, note, **required**): Enter a detailed description of the request.
* **Follow Up Date** (`follow_up_date`, date, **required**): Enter the date to follow up on the request.
* **Follow Up Time** (`follow_up_time`, time, **required**): Enter the time to follow up on the request.
* **Follow Up Details** (`follow_up_details`, note, **required**): Enter the details to follow up on the request.
* **Assigned User** (`assigned_user`, select_one, **required**): Select the team member to assign the request to.
* **Assigned Date** (`assigned_date`, date, **required**): Enter the date to assign the request to the team member.
* **Assigned Time** (`assigned_time`, time, **required**): Enter the time to assign the request to the team member.
* **Completed Date** (`completed_date`, date, optional): Enter the date the request was completed, if applicable.
* **Completed Time** (`completed_time`, time, optional): Enter the time the request was completed, if applicable.
* **Comments** (`comments`, note, optional): Add any additional comments about the request.
* **Prophets and Ideas** (`prophets_and_ideas`, text, optional): Enter any additional ideas or insights related to the request.
* **Requestor 2** (`requestor_2`, select_one, optional): Select the second person making the request, if applicable.
* **Department 2** (`department_2`, select_multiple, optional): Select the department(s) that the request is related to, if applicable.
* **Priority 2** (`priority_2`, select_one, optional): Select the priority level of the request, if applicable.
* **Follow Up Date 2** (`follow_up_date_2`, date, optional): Enter the date to follow up on the request, if applicable.
* **Follow Up Time 2** (`follow_up_time_2`, time, optional): Enter the time to follow up on the request, if applicable.
* **Follow Up Details 2** (`follow_up_details_2`, note, optional): Enter the details to follow up on the request, if applicable.
* **Assigned User 2** (`assigned_user_2`, select_one, **required**): Select the team member to assign the request to, if applicable.
* **Follow Up Date 2** (`follow_up_date_2`, date, optional): Enter the date to follow up on the request, if applicable.
* **Follow Up Time 2** (`follow_up_time_2`, time, optional): Enter the time to follow up on the request, if applicable.

## Tips

* Be sure to review the form carefully before submitting to ensure that all required fields are complete.
* Use accurate and concise language to ensure that the request is clear and easy to understand.
* If you are unsure about any field, please contact the relevant team member or management for guidance.
* If you need to make multiple requests, you can create a new form for each request.
* If you have any questions or concerns about the form, please reach out to the relevant team member or management.
