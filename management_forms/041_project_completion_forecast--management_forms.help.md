# project_completion_forecast - Help Guide
## Purpose
The project_completion_forecast form is designed to gather essential project information from project managers to provide a clear understanding of project progress and expectations.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill in the relevant fields with accurate and up-to-date information.
2. Review each field carefully to ensure accuracy and completeness.
3. If a field is optional, you can leave it blank if not applicable.
4. For select_one fields, choose the most suitable option from the available choices.

## Field-by-Field Explanation
* **Project Forecast** (`project_forecast`, text, optional): A brief summary of the project's expected outcome and key deliverables.
* **Project Scope** (`project_scope`, text, optional): A detailed description of the project's objectives and key deliverables.
* **Project Timeline** (`project_timeline`, date, optional): The expected start and end dates of the project.
* **Project Delivery Confidence** (`project_delivery_confidence`, text, optional): A subjective estimate of the project's expected delivery date and confidence in achieving it.
* **Project Status** (`project_status`, select_one, optional): The current status of the project, which can be In Progress, Delayed, Completed, or On Hold.
* **Project Manager Name** (`project_manager_name`, text, optional): The name of the project manager responsible for the project.
* **Project Manager Email** (`project_manager_email`, email, optional): The contact email of the project manager.
* **Project Manager Phone** (`project_manager_phone`, text, optional): The contact phone number of the project manager.
* **Project Start Date** (`project_start_date`, date, optional): The actual start date of the project.

## Tips
* Please be as accurate and concise as possible when filling in the form.
* If a field is not applicable, you can leave it blank.
* Review each field carefully before submitting the form to ensure completeness and accuracy.
