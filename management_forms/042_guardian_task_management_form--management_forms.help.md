# Guardian Task Management Form - Help Guide

## Purpose
The Guardian Task Management Form is a tool used to manage tasks and their associated data. It is designed to be simple and user-friendly, making it easy for users to input and update task-related data.

## How To Complete This Form

1.  Navigate to the Guardian Task Management Form.
2.  Select the task status (Active, Completed, Inactive, or On Hold) and enter the task due date.
3.  Choose the task priority (Low, Medium, High, or Urgent) and select the person assigned to the task (John Doe or Jane Doe).
4.  Input any additional comments about the task in the "Task Comments" field.
5.  Input any additional notes about the task in the "Task Notes" field.
6.  Select the person who assigned the task (John Doe or Jane Doe).
7.  Input any additional comments about the task in the "Task Comments 2" field (if applicable).
8.  Input any additional notes about the task in the "Task Notes 2" field (if applicable).

## Field-by-Field Explanation

*   **Task Due Date**: This field is used to input the due date of the task.
    *   Enter the date in the format mm/dd/yyyy.
*   **Task Status**: This field is used to select the status of the task.
    *   Select the status of the task from the available options (Active, Completed, Inactive, or On Hold).
*   **Task Priority**: This field is used to select the priority of the task.
    *   Select the priority of the task from the available options (Low, Medium, High, or Urgent).
*   **Task Assigned To**: This field is used to select the person assigned to the task.
    *   Select the person assigned to the task from the available options (John Doe or Jane Doe).
*   **Task Comments**: This field is used to input additional comments about the task.
    *   Enter any additional comments about the task.
*   **Task Notes**: This field is used to input additional notes about the task.
    *   Enter any additional notes about the task.
*   **Task Assigned By**: This field is used to select the person who assigned the task.
    *   Select the person who assigned the task from the available options (John Doe or Jane Doe).
*   **Task Comments 2**: This field is used to input additional comments about the task (optional).
    *   Enter any additional comments about the task (if applicable).
*   **Task Notes 2**: This field is used to input additional notes about the task (optional).
    *   Enter any additional notes about the task (if applicable).
*   **Task Priority 2**: This field is used to select the priority of the task (optional).
    *   Select the priority of the task from the available options (Low, Medium, High, or Urgent) (if applicable).
*   **Task Status 2**: This field is used to select the status of the task (optional).
    *   Select the status of the task from the available options (Active, Completed, Inactive, or On Hold) (if applicable).

## Tips

*   Always ensure that the task due date is accurate and up-to-date.
*   Make sure to select the correct status and priority for each task.
*   Enter all necessary comments and notes for each task.
*   If you encounter any issues with the form, contact [form@gic.mx](mailto:form@gic.mx).
