# Project Transition Plan Form - Help Guide
## Purpose
The Project Transition Plan Form is used to document the transition plan for a project, including key deliverables, risks, and approvals from stakeholders.

## How To Complete This Form
1. Fill in the Project ID and select the current Project Status.
2. Select the Owner ID from the list of available options.
3. Enter the Key Deliverables, Risks, and Transition Date.
4. Enter the Owner Approval, Manager Approval, and Team Approval.
5. Provide Comments from the project owner, manager, and team.
6. Enter any Additional Notes and Transition Time.

## Field-by-Field Explanation
* **Project Id** (1, text, required): Enter the project ID number.
* **Project Status** (2, select_one, required): Select the current project status (Active or Inactive).
* **Owner Id** (3, select_multiple, required): Select the owner ID from the list of available options.
* **Key Deliverables** (4, text, required): Enter the key deliverables for the project.
* **Risks** (5, text, optional): Enter any risks associated with the project.
* **Approvals** (6, select_multiple, required): Select whether the project owner, manager, and team have approved the transition plan.
* **Date** (7, date, required): Enter the transition date.
* **Time** (8, time, optional): Enter the transition time.
* **Owner Notes** (9, text, optional): Enter any notes from the owner.
* **Email** (10, email, required): Enter the email address of the project owner.
* **Phone** (11, text, optional): Enter the phone number of the project owner.
* **Project Notes** (12, text, optional): Enter any additional project notes.
* **Owner Comments** (13, text, optional): Enter any comments from the project owner.
* **Manager Comments** (14, text, optional): Enter any comments from the manager.
* **Team Comments** (15, text, optional): Enter any comments from the team.
* **Transition Date** (16, date, required): Enter the date of the transition.
* **Transition Time** (17, time, optional): Enter the time of the transition.
* **Transition Notes** (18, note, optional): Enter any notes for the transition.
* **Owner Approval** (19, select_multiple, required): Select whether the project owner has approved the transition plan.
* **Manager Approval** (20, select_multiple, required): Select whether the manager has approved the transition plan.
* **Team Approval** (21, select_multiple, required): Select whether the team has approved the transition plan.
* **Comments** (22, text, optional): Enter any additional comments.
* **Project Status Comments** (23, text, optional): Enter any comments on the project status.
* **Transition Comments** (24, text, optional): Enter any comments on the transition.
* **Owner Comments** (25, text, optional): Enter any comments from the project owner.
