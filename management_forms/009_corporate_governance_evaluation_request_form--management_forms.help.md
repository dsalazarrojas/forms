# corporate_governance_evaluation_request_form - Help Guide
## Purpose
This form is for submitting a review request for corporate governance evaluation. This form is intended to gather information from employees or teams within the organization to assess whether a review is necessary.

## How To Complete This Form
To fill out this form, follow these steps:

1. Select the Review Request page.
2. Enter a brief description of the review request in the Review Request field.
3. Choose your preferred timeline for the review in the Preferred Timeline field.
4. Add any supporting documents required for the review in the Supporting Documents field.
5. Select the Board Compliance Teams involved in the review in the Board Compliance Teams field.
6. Choose any advisors who will be assisting in the review in the Advisors field.
7. Optionally, enter the Review Request Form field for any additional information.
8. Enter the Review Request Date if it is known.
9. Select the Review Request Status to indicate the current status of the request.
10. Select the Review Request Form Status to indicate the current status of the form.

## Field-by-Field Explanation

* **Review Request**: 
  * Type: Text
  * Description: Enter a brief description of the review request.
* **Preferred Timeline**: 
  * Type: Date
  * Description: Select the preferred date for the review to be completed.
* **Supporting Documents**: 
  * Type: Select Multiple
  * Description: Attach any additional documents that support the review request, such as meeting minutes or financial reports.
* **Board Compliance Teams**: 
  * Type: Select One
  * Description: Choose the team responsible for overseeing the review process.
* **Advisors**:
  * Type: Select Multiple
  * Description: Select any advisors who will be assisting in the review process.
* **Review Request Form**: 
  * Type: Text
  * Description: Enter any additional information that may be required for the review.
* **Review Request Date**: 
  * Type: Time
  * Description: Enter the date of the review request if known.
* **Review Request Status**: 
  * Type: Select One
  * Description: Select the current status of the review request.
* **Review Request Form Status**: 
  * Type: Select One
  * Description: Select the status of the review form itself.
* **Review Request Form**: 
  * Type: Text
  * Description: This field appears to be a duplicate of "Review Request" (id: 1), which is likely an error. It is best to disregard this field.
