# fleet_maintenance_declaration_form - Help Guide
## Purpose
This form is used to declare new or updated maintenance activities on a vehicle. It should only be used when there are new maintenance activities that need to be recorded.

## How To Complete This Form
1. Please fill out all required fields, marked with an asterisk (\*).
2. For each field, enter the information as requested.
3. If you are unsure about any field, you can ask for help from the fleet manager or owner.

## Field-by-Field Explanation

* **Vehicle Identification** (\*): Enter the vehicle's identification number to link this declaration to the correct vehicle.
* **Vehicle Maintenance Schedule** (\*): If the vehicle requires regular maintenance, select 'Yes' from the options. This will help to schedule the maintenance activities.
* **Date** (\*): Enter the date you are submitting this declaration.
* **Time** (\*): Enter the time you are submitting this declaration.
* **Email** (\*): Enter your email address for contact purposes.
* **Phone** (\*): Enter your phone number for contact purposes.
* **Note**: Add any additional information you want to include in this declaration. 
* **Other fields**: These fields can be used to add any other information you feel is relevant to the vehicle's maintenance activities. They are not required but can help to provide more context. 

Note: All required fields are marked with an asterisk (\*).
