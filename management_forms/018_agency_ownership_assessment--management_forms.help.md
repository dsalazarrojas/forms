# Agency Ownership Assessment - Help Guide
## Purpose
The Agency Ownership Assessment form is used to evaluate the ownership structure of agencies and collect information about their ownership breakdown, recent changes, and supporting documents.

## How To Complete This Form
1. **Enter the full name of the agency** in the "Agency Name" field (Field 1) and select the **Assessment Date** (Field 2) for the date of this ownership assessment.
2. **Enter the name** of the person preparing the assessment in the "Prepared By" field (Field 3) and **enter the period covered by this assessment** in the "Assessment Period" field (Field 4).
3. To describe the **ownership structure** of the agency, select the type of entity for the agency in the "Entity Type" field (Field 5).
4. **Enter the total percentage of ownership** in the "Total Ownership Percentage" field (Field 7).
5. The "Ownership Breakdown" section (Fields 8-11) is used to list the owners of the agency, their percentages, and types. Repeat the following steps for each owner:
   * Enter the **name** of the owner in the "Owner Name" field (Field 9, 12, 15).
   * Enter the **percentage of ownership** for the owner in the "Ownership Percentage" field (Field 10, 13, 16).
   * Select the **type of owner** in the "Owner Type" field (Field 11, 14, 17).
6. **Indicate if there have been any ownership changes in the past year** in the "Recent Ownership Changes" field (Field 18).
7. If yes, provide details about recent ownership changes in the "Ownership Change Details" field (Field 19).
8. **List any supporting documents attached to this assessment** in the "Supporting Documents Attached" field (Field 20).
9. Finally, enter your **digital signature** in the "Authorized Signature" field (Field 21).

## Field-by-Field Explanation
* **Agency Name (Field 1)**: Enter the full name of the agency.
* **Assessment Date (Field 2)**: Select the date of this ownership assessment.
* **Prepared By (Field 3)**: Enter the name of the person preparing this assessment.
* **Assessment Period (Field 4)**: Enter the period covered by this assessment.
* **Entity Type (Field 5)**: Select the type of entity for the agency.
* **Total Ownership Percentage (Field 7)**: Enter the total percentage of ownership (should equal 100%).
* **Owner Name 1 (Field 9)**: Enter the name of the first owner.
* **Ownership Percentage 1 (Field 10)**: Enter the percentage of ownership for the first owner.
* **Owner Type 1 (Field 11)**: Select the type of the first owner.
* **Owner Name 2 (Field 12)**: Enter the name of the second owner (if applicable).
* **Ownership Percentage 2 (Field 13)**: Enter the percentage of ownership for the second owner (if applicable).
* **Owner Type 2 (Field 14)**: Select the type of the second owner (if applicable).
* **Owner Name 3 (Field 15)**: Enter the name of the third owner (if applicable).
* **Ownership Percentage 3 (Field 16)**: Enter the percentage of ownership for the third owner (if applicable).
* **Owner Type 3 (Field 17)**: Select the type of the third owner (if applicable).
* **Recent Ownership Changes (Field 18)**: Indicate if there have been any ownership changes in the past year.
* **Ownership Change Details (Field 19)**: If yes, provide details about recent ownership changes.
* **Supporting Documents Attached (Field 20)**: List any supporting documents attached to this assessment.
* **Authorized Signature (Field 21)**: Enter your digital signature.
