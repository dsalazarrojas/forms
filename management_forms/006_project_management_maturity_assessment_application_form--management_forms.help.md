# Project Management Maturity Assessment Application Form - Help Guide
## Purpose
The Project Management Maturity Assessment Application Form is used to evaluate the management maturity of a project and its team.

## How To Complete This Form
To complete this form, please follow these steps:

1. Select the project team members who will be working on the project.
2. Enter the project name, status, type, start and end dates, duration, location, and other relevant details.
3. Provide information about the project lead, project manager, sponsor, and their respective roles and contact details.

## Field-by-Field Explanation

* **Project Team**: Select all team members who will be working on the project. This includes all individuals with significant roles and responsibilities in the project.
* **Project Name**: Enter the name of the project.
* **Project Lead**: Enter the name of the project lead.
* **Team Size**: Enter the size of the team.
* **Team Distribution**: Select the type of team distribution, such as Agile, Waterfall, or Hybrid.
* **Project Status**: Select the current status of the project, such as In Progress, Active, Completed, or On Hold.
* **Project Type**: Select the type of project, such as IT Project or Non-IT Project.
* **Start Date**: Enter the start date of the project.
* **End Date**: Enter the end date of the project.
* **Duration**: Enter the duration of the project.
* **Location**: Enter the location of the project.
* **Description**: Enter a brief description of the project.
* **Project Manager**: Enter the name of the project manager.
* **PM Organisation**: Enter the organisation of the project manager.
* **PM Name**: Enter the name of the project manager.
* **PM Position**: Enter the position of the project manager.
* **PM Email**: Enter the email of the project manager.
* **PM Phone**: Enter the phone number of the project manager.
* **Sponsor**: Enter the name of the sponsor.
* **Sponsor Organisation**: Enter the organisation of the sponsor.
* **Sponsor Name**: Enter the name of the sponsor.
* **Sponsor Position**: Enter the position of the sponsor.
* **Sponsor Email**: Enter the email of the sponsor.
* **Sponsor Phone**: Enter the phone number of the sponsor.

## Tips
Please make sure to complete this form carefully and accurately, as the results will be used to assess the project management maturity. If you have any questions or concerns, please contact the project management office.
