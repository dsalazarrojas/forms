# Recurring Task Management Form - Help Guide

## Purpose
The Recurring Task Management Form is used to create, edit, and manage recurring tasks that need to be performed on a regular basis. This form helps you to set up and track these tasks, ensuring that you don't miss any important deadlines.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the "Recurring Task Properties" page to input the main properties of the recurring task, including the title and due date.
2. Choose the "Assignee Properties" page to select which users are assigned to this task and whether they will receive notifications.
3. On the "Start Time" and "End Time" pages, input the time frame for the recurring task.
4. On the "Due Date" page, input the date by which the task should be completed.
5. On the "Reminder" page, choose whether you want to receive reminders for this task.
6. On the "Assignee List" page, select which users are assigned to this task.
7. On the "Priority" page, choose the priority level of the task.
8. On the "Status" page, choose the status of the task (Active or Inactive).
9. On the "Recurrence Properties" page, choose whether this task is a recurring task.
10. On the "Recurrence Pattern" page, choose the recurrence pattern of the task (e.g., daily, weekly, etc.).
11. On the "Recurrence Frequency" page, choose the frequency of the recurrence (e.g., every 1 day, week, etc.).
12. On the "Recurrence Start Date" page, input the start date of the recurrence.
13. On the "Recurrence End Date" page, input the end date of the recurrence.
14. On the "Recurrence End Time" page, input the end time of the recurrence.
15. On the "Recurrence End Time Repeats" page, choose whether the recurrence end time should repeat.
16. On the "Recurrence End Time Repeats Options" page, choose which options to repeat (e.g., daily, weekly, etc.).
17. On the "Recurrence End Time Until" page, input the end time until which the recurrence should repeat.
