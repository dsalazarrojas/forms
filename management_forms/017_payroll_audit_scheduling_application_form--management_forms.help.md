# Payroll Audit Scheduling Application Form - Help Guide
## Purpose
The Payroll Audit Scheduling Application Form is designed to help users schedule and track payroll audits efficiently. This form allows users to submit or view audit requests and their corresponding details, update or change the status of audit requests, and record additional notes or comments for each audit request.

## How To Complete This Form
To complete this form, follow these steps:

1. Ensure you have all necessary information before starting the form. This includes the audit request details, preferred date and time, and any additional notes or comments.
2. Select the relevant options for each field, paying attention to the required and optional fields.
3. Submit or update the form as needed.

## Field-by-Field Explanation

* **Request Information (ID 1)**: This field is a note that provides a space to enter any additional information about the audit request. Enter any relevant details that are not included in other fields.
* **Preferred Date (ID 2)**: Select a date for the audit to take place. This field is optional.
* **Key Details (ID 3)**: This is a note field for entering any additional information that is relevant to the audit request. Enter any details that are not included in other fields.
* **Auditor Details (ID 4)**: Select whether an auditor is available to perform the audit. Options include "Yes" or "No".
* **Status (ID 5)**: Select the current status of the audit request. Options include "Active", "Inactive", and "Not Started".
* **Status Notes (ID 6)**: This is an optional note field for entering any additional comments or updates about the audit request status.
* **Request Type (ID 7)**: Select the type of audit request. Options include "Request for Review", "Request for Adjustment", and "Request for Verification".
* **Preferred Time (ID 8)**: Select a preferred time for the audit to take place. This field is optional.
* **Auditor Name (ID 9)**: Select the name of the auditor assigned to the audit request. Options include "John Doe", "Jane Doe", and "Mary Smith".
* **Audit Date (ID 10)**: Select the date for the audit to take place. This field is optional.
* **Audit Start Date (ID 11)**: Select the start date for the audit. This field is optional.
* **Audit Finish Date (ID 12)**: Select the finish date for the audit. This field is optional.
* **Audit Duration (ID 13)**: Enter the duration of the audit in hours or minutes. This field is optional.
* **Audit Status (ID 14)**: Select the current status of the audit. Options include "Not Started", "In Progress", and "Finished".
* **Audit Notes (ID 15)**: This is an optional note field for entering any additional comments or updates about the audit request.
* **Review Request (ID 16)**: Select whether a review is requested. Options include "Yes" or "No".
* **Adjustment Request (ID 17)**: Select whether an adjustment is requested. Options include "Yes" or "No".
* **Verification Request (ID 18)**: Select whether a verification is requested. Options include "Yes" or "No".
* **Location (ID 19)**: Select the location where the audit will take place. Options include "Location A", "Location B", and "Location C".
* **Location Details (ID 20)**: This is an optional note field for entering any additional information about the location.
* **Preferred Time (ID 21)**: Select a preferred time for the audit to take place. This field is optional.
* **Location Details (ID 22)**: This is an optional note field for entering any additional information about the location.
* **Additional Notes (ID 23)**: This is an optional note field for entering any additional comments or updates about the audit request.
* **Audit Date Range (ID 24)**: Enter a date range for the audit to take place.
* **Finish Audit Request (ID 25)**: Select whether to finish the audit request. Options include "Yes" or "No".
