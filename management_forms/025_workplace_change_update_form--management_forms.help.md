# Workplace Change Update Form - Help Guide
## Purpose
This form is used to report changes in the workplace management structure, such as changes in a manager or department. Please fill out this form only if there has been a change in your current or new manager, location, or department.

## How To Complete This Form
1. Fill out the form completely.
2. Enter your Employee Name to identify yourself in the system.
3. Indicate if you currently have a manager by selecting "Yes" or "No".
4. If you currently have a manager, select "Yes" for the New Manager field, and enter the name of your new manager.
5. Enter the Employee ID.
6. Provide a reason for the change, including details about the change.
7. Enter the Date of the change.
8. Enter the new Location, if applicable.
9. Enter the new Department, if applicable.
10. Select the approval level: High or Low.
11. Enter the date for the approval.
12. Optionally, add any additional comments about the change.

## Field-by-Field Explanation
* **Employee Name (Employee Name)**: Enter your employee name to identify yourself in the system.
* **Current Manager (Current Manager)**: Indicate if you currently have a manager by selecting "Yes" or "No".
* **New Manager (New Manager)**: If you have a manager, select "Yes" and enter the name of your new manager.
* **Employee Id (Employee Id)**: Enter your employee ID number.
* **Reason for Change (Reason for change)**: Provide a clear reason for the change, including details about the change.
* **Date of Change (Date of Change)**: Enter the date of the change.
* **New Location (New Location)**: Enter the new location, if applicable.
* **New Department (New Department)**: Enter the new department, if applicable.
* **Approval Level (Approval Level)**: Select the approval level: High or Low.
* **Approval Date (Approval Date)**: Enter the date for the approval.
* **Comments (Comments)**: Optionally, add any additional comments about the change.

## Tips
* Please fill out the form only if there has been a change in your current or new manager, location, or department.
* Ensure you fill out all required fields.
