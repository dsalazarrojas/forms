# Roofing Inspection Form - Help Guide

## Purpose
The Roofing Inspection Form is designed to collect information about a roofing inspection. 

## How To Complete This Form

### Note: Before starting the form, please make sure you are familiar with the purpose and fields explained below.

## Field-by-Field Explanation

### 1. Roof Inspection (inspect_roofing)
- This field is a note field that allows you to document any general notes about the roof inspection.

### 2. Roof Type (roof-type)
- This field is a dropdown menu to select the type of roof.
- Please choose from the options: 'Yes' or 'No' to indicate whether the roof type is present or not.

### 3. Roof Condition (roof-condition)
- This field is a dropdown menu to select the condition of the roof.
- Please choose from the options: 'Yes' or 'No' to indicate whether the roof condition is present or not.

### 4. Material Type (material-type)
- This field is a dropdown menu to select the type of roofing material.
- Please choose from the options: 'Yes' or 'No' to indicate whether the material type is present or not.

### 5. Material Condition (material-condition)
- This field is a dropdown menu to select the condition of the material.
- Please choose from the options: 'Yes' or 'No' to indicate whether the material condition is present or not.

### 6. Damage Type (damage-type)
- This field is a dropdown menu to select the type of damage found during the inspection.
- Please choose from the options: 'Yes' or 'No' to indicate whether the damage type is present or not.

### 7. Damage Condition (damage-condition)
- This field is a dropdown menu to select the condition of the damage.
- Please choose from the options: 'Yes' or 'No' to indicate whether the damage condition is present or not.

### 8. Inspection Date (inspection-date)
- This field is a date field to document the date of the inspection.

### 9. Inspection Time (inspection-time)
- This field is a time field to document the time of the inspection.

### 10. Inspector Name (inspector-name)
- This field is a text field to document the name of the inspector.

### 11. Inspector Email (inspector-email)
- This field is an email field to document the email of the inspector.

### 12. Inspector Phone (inspector-phone)
- This field is a text field to document the phone number of the inspector.

## Tips
- Please fill out the form with as much information as possible to provide a comprehensive picture of the roof's condition.
- If you are unsure about any field, please review the field explanations above.
- If you have any further questions, please contact the property management team.
