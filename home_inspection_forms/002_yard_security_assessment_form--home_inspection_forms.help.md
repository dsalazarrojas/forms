# Yard Security Assessment Form - Help Guide
## Purpose
This form is designed to assess the security risks and control measures in place at a yard or property. 

## How To Complete This Form
To complete this form, please follow these steps:
1. Review the list of security risks (page 2) and select all applicable risks that are present at your yard or property.
2. For each selected risk, choose the corresponding risk level (page 3) that best describes the level of concern.
3. List all security systems you have in place to mitigate each selected risk (page 4).
4. Identify all access control measures in place to prevent or deter each selected risk (page 5).
5. Describe the current security risks and threats and any plans you have to mitigate them (page 6).
6. Summarize your action plan to address the selected risks (page 7).
7. Indicate the status of your action plan (page 8).

## Field-by-Field Explanation
### Page 1: Main Page
- **No label** (id: 1, type: text, required: false): This is the main page of the form.
### Page 2: Security Risks
- **Security Risks** (id: 2, type: select_multiple, required: false): 
  List all applicable security risks that are present at your yard or property. The available options are:
  * Dogs
  * Burglars
  * Vandals
  * Trespassers
  * Wildlife
  * Weather
### Page 3: Risk Level
- **Risk Level** (id: 3, type: select_one, required: false): Choose the level of concern for each selected risk from:
  * low
  * medium
  * high
### Page 4: Security Systems
- **Security Systems** (id: 4, type: select_multiple, required: false): List all security systems you have in place to mitigate each selected risk. The available options are:
  * Motion detectors
  * Security cameras
  * Alarm system
  * Security lights
  * Fences
  * Gates
### Page 5: Access Control
- **Access Control** (id: 5, type: select_multiple, required: false): Identify all access control measures in place to prevent or deter each selected risk. The available options are:
  * Gates
  * Fences
  * Doors
  * Windows
  * Perimeter
### Page 6: Risk Description
- **Risk Description** (id: 6, type: text, required: false): Describe the current security risks and threats at your yard or property.
### Page 7: Action Plan
- **Action Plan** (id: 7, type: text, required: false): Summarize your action plan to address the selected risks.
### Page 8: Action Plan Status
- **Action Plan Status** (id: 8, type: select_one, required: false): Indicate the status of your action plan from:
  * In progress
  * Completed
  * Not started
