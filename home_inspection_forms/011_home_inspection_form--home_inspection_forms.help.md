# Home Inspection Form - Help Guide
## Purpose
The "Home Inspection Form" is a crucial tool for evaluating the condition and value of a property. It helps inspectors collect detailed information about the property, including its address, location, and various aspects of its structure.

## How To Complete This Form
To complete the form, follow these steps:

1. Fill out the "address" field with the property's exact address.
2. Enter the date of the inspection in the "date" field.
3. Provide your name and contact information in the "inspector" and "contact" fields, respectively.
4. In the "comments" field, enter any relevant notes or observations about the property.
5. Select the relevant options for "category" and "property_type" to indicate the type of property and its condition.
6. Enter any additional details in the "category_options" and "property_type_options" fields if needed.
7. Select the "building_type" option that best describes the property's type.
8. Enter the location details, including the city, state, and zip code, in the "location," "location_city," "location_state," and "location_zip" fields.
9. Provide any additional information or notes in the "location_address," "location_zip_options," and "location_zip_code" fields if needed.

## Field-by-Field Explanation
* **Address**: Enter the exact address of the property.
* **Date**: Enter the date of the inspection.
* **Inspector**: Enter your name and title or position.
* **Comments**: Enter any notes or observations about the property.
* **Category**: Select 'Yes' if the property falls under a specific category (e.g., rental, sold, or pending).
* **Category Options**: Enter any additional details about the category.
* **Property Type**: Select 'Yes' if the property is of a specific type (e.g., single-family, condominium, or commercial).
* **Property Type Options**: Enter any additional details about the property type.
* **Building Type**: Select 'Yes' if the building is a specific type (e.g., single-story, multi-story, or condo).
* **Building Type Options**: Enter any additional details about the building type.
* **Location**: Enter the general area or location of the property.
* **Location Address**: Enter any additional details about the property's address.
* **Location City**: Enter the city where the property is located.
* **Location State**: Enter the state where the property is located.
* **Location State Options**: Enter any additional details about the state.
* **Location Zip**: Enter the zip code of the property.
* **Location Zip Options**: Enter any additional details about the zip code.
* **Location Zip Code**: Enter the zip code of the property.
