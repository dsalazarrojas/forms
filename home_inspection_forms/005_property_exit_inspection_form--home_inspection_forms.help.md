# Property Exit Inspection Form - Help Guide
## Purpose
This form is used to collect information about the condition of a property's systems during an exit inspection. The information provided will help the inspector assess the overall state of the property and its systems.

## How To Complete This Form
To complete this form, follow these steps:

1. Select each category from the provided sections.
2. In each category section, write down any observed issues, defects, or notes about the condition of the systems.

## Field-by-Field Explanation

* **General Conditions** (`General Conditions`, `text`, optional): This field is used to describe any general conditions that may affect the property or its systems. Please provide a brief description of any notable issues or concerns you have about the property's overall condition.
* **Electrical Systems** (`Electrical Systems`, `number`, optional): This field is used to report any issues or defects with the electrical systems, such as flickering lights or malfunctioning outlets. Please provide a numerical value to indicate the severity of the issue (e.g., 1-5, where 1 is minor and 5 is critical).
* **Plumbing Systems** (`Plumbing Systems`, `text`, optional): This field is used to describe any issues or defects with the plumbing systems, such as leaks or clogged drains. Please provide a brief description of the issue.
* **Heating and Cooling Systems** (`Heating and Cooling Systems`, `text`, optional): This field is used to report any issues or defects with the heating and cooling systems, such as malfunctioning thermostats or faulty air conditioning units. Please provide a brief description of the issue.
* **Safety Systems** (`Safety Systems`, `text`, optional): This field is used to describe any safety concerns or issues with the property's systems, such as malfunctioning smoke detectors or inadequate emergency exit lighting. Please provide a brief description of the issue.
* **Environmental Systems** (`Environmental Systems`, `text`, optional): This field is used to report any issues or defects with the property's environmental systems, such as pest infestations or poor air quality. Please provide a brief description of the issue.
* **Other Systems** (`Other Systems`, `text`, optional): This field is used to describe any other systems not listed above that require attention. Please provide a brief description of the issue.
* **Electrical Systems 2** (`Electrical Systems 2`, `text`, optional): This field is similar to the "Electrical Systems" field and is used to report any additional issues or defects with the electrical systems. Please provide a brief description of the issue.
* **Plumbing Systems 2** (`Plumbing Systems 2`, `text`, optional): This field is similar to the "Plumbing Systems" field and is used to describe any additional issues or defects with the plumbing systems. Please provide a brief description of the issue.
* **Heating and Cooling Systems 2** (`Heating and Cooling Systems 2`, `text`, optional): This field is similar to the "Heating and Cooling Systems" field and is used to report any additional issues or defects with the heating and cooling systems. Please provide a brief description of the issue.

## Tips
* Please provide as much detail as possible for each field.
* If you're unsure about a particular system or issue, please ask for clarification before submitting the form.
* Remember to review and complete all fields thoroughly to ensure accurate and comprehensive information about the property's systems.
