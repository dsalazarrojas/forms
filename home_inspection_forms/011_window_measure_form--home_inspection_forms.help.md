# Window Measure Form - Help Guide

## Purpose
The Window Measure Form is designed to collect measurements and other relevant information about windows. This form is intended for use by home inspectors, contractors, or other professionals who need to accurately record and track window measurements for various purposes such as repairs, replacements, or assessments.

## How To Complete This Form

1.  To complete this form, start by selecting the page number from the dropdown menu. Each page has specific fields that correspond to the selected page number.
2.  Fill in the required fields with the requested information. The required fields are highlighted in red.
3.  For fields that allow multiple selections (e.g., select_multiple), choose as many relevant options as necessary.
4.  For fields of type date and time, use the formats YYYY-MM-DD and HH:MM:SS, respectively.
