# Smoke Alarm Authorization Form - Help Guide
## Purpose
This form is used to authorize and document the details of a smoke alarm system in a property.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the type of property (Residential, Commercial, or Other).
2. Choose who the property owner is (Owner or Tenant).
3. Enter the property owner's name.
4. Enter the property owner's phone number.
5. Enter the property owner's email address.
6. Enter the property address.
7. Enter the installation date of the smoke alarm system.
8. Add any additional notes about the property or smoke alarm system.
9. (Optional) Select who the system is assigned to (e.g., chatjimmy or Other).

## Field-by-Field Explanation
* **Property Type** (`property_type`, Select One, required: false): Select the type of property (Residential, Commercial, or Other).
* **Property Owner** (`property_owner`, Select Multiple, required: false): Choose who the property owner is (Owner or Tenant).
* **Owner Name** (`owner_name`, Text, required: false): Enter the property owner's name.
* **Owner Phone** (`owner_phone`, Text, required: false): Enter the property owner's phone number.
* **Owner Email** (`owner_email`, Email, required: false): Enter the property owner's email address.
* **Property Address** (`property_address`, Text, required: false): Enter the property address.
* **Installation Date** (`installation_date`, Date, required: false): Enter the installation date of the smoke alarm system.
* **Notes** (`notes`, Note, required: false): Add any additional notes about the property or smoke alarm system.
* **Assigned To** (`assigned_to`, Select One, required: false): (Optional) Select who the system is assigned to (e.g., chatjimmy or Other).
* **Additional Notes** (`additional_notes`, Note, required: false): Add any additional notes about the property or smoke alarm system.
