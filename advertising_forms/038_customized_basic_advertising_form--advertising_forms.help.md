# Customized Basic Advertising Form - Help Guide

## Purpose
The Customized Basic Advertising Form is designed to collect information for customized advertising campaigns. This form helps clients create tailored advertising campaigns with specific settings to suit their needs.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the required fields with accurate and relevant information.
2. Select the preferred channel for the advertising campaign.
3. Choose the ad schedule and start and end dates for the campaign.
4. Select the ad preference(s) that suits your needs.
5. Provide your email address and phone number.
6. Add any additional notes about the ad location and description.
7. Choose whether to include an image and provide the URL for the ad.
8. Select the ad status and campaign status.
9. Set the ad budget and duration.
10. Select the frequency of the ad.
11. Add any additional customer notes.
12. Select additional preferences as required.

## Field-by-Field Explanation

* **Customer Name** (`customer_name`, text, optional): Enter your name as the customer.
* **Preferred Channel** (`preferred_channel`, select_one, optional): Choose your preferred channel for the advertising campaign.
* **Ad Schedule** (`ad_schedule`, time, optional): Select the schedule for the advertisement.
* **Ad Start Date** (`ad_start_date`, date, optional): Enter the start date for the advertisement.
* **Ad End Date** (`ad_end_date`, date, optional): Enter the end date for the advertisement.
* **Ad Preference** (`ad_preference`, select_multiple, optional): Choose the preferences for the advertisement.
* **Customer Email** (`customer_email`, email, optional): Enter your email address.
* **Customer Phone** (`customer_phone`, text, optional): Enter your phone number.
* **Ad Location** (`ad_location`, note, optional): Add any additional notes about the ad location.
* **Ad Description** (`ad_description`, text, optional): Add a description of the advertisement.
* **Ad Image** (`ad_image`, select_one, optional): Choose whether to include an image with the ad.
* **Ad URL** (`ad_url`, text, optional): Enter the URL for the ad.
* **Ad Status** (`ad_status`, select_multiple, optional): Select the status of the advertisement.
* **Ad Budget** (`ad_budget`, number, optional): Set the budget for the advertisement.
* **Ad Campaign** (`ad_campaign`, select_one, optional): Choose whether to include the ad in the campaign.
* **Ad Duration** (`ad_duration`, number, optional): Set the duration for the advertisement.
* **Ad Frequency** (`ad_frequency`, select_multiple, optional): Choose the frequency of the ad.
* **Customer Note** (`customer_note`, note, optional): Add any additional customer notes.
* **Preference 1** (`customer_preference_1`, select_multiple, optional): Select preferences 1.
* **Preference 2** (`customer_preference_2`, select_multiple, optional): Select preferences 2.
* **Preference 3** (`customer_preference_3`, select_multiple, optional): Select preferences 3.
* **Preference 4** (`customer_preference_4`, select_multiple, optional): Select preferences 4.
* **Preference 5** (`customer_preference_5`, select_multiple, optional): Select preferences 5.
* **Preference 6** (`customer_preference_6`, select_multiple, optional): Select preferences 6.
* **Preference 7** (`customer_preference_7`, select_multiple, optional): Select preferences 7.
