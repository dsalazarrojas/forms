# Social Media Content Request Form - Help Guide
## Purpose
The Social Media Content Request Form is a simple, internal tool used to request social media content creation or promotion within your organization. It helps gather necessary information for content planning, approval, and publishing.

## How To Complete This Form
To fill out this form, follow these steps:

1.  Choose the social media platform where you would like the content to be published.
2.  Select the type of content you would like to create (e.g., video, image, text, or link).
3.  Provide a valid URL (if required) for the content to be linked from or to be displayed on the selected platform.
4.  Enter a brief description of the content, describing what it will be about.
5.  Set a start date and end date for when the content will be published.
6.  Choose the start and end times for the content, if applicable.
7.  Submit the form after providing all necessary details.

## Field-by-Field Explanation

* **Social Media Platform**: Choose the social media platform where you would like the content to be published (e.g., Facebook, Instagram, Twitter, TikTok, or YouTube).
* **Content Type**: Select the type of content you would like to create (e.g., Video, Image, Text, or Link).
* **Platform Link**: Enter a valid URL for the content to be linked from or displayed on the selected social media platform. (Optional)
* **Content Description**: Write a brief description of the content, describing what it will be about.
* **Start Date**: Choose a valid date when you would like the content to start publishing.
* **End Date**: Select a valid date when you would like the content to end publishing.
* **Start Time**: Select a time when you would like the content to start publishing.
* **End Time**: Select a time when you would like the content to end publishing.

## Tips

* Please ensure you have the necessary permissions and approvals to publish content on the selected social media platforms.
* This form is for internal use only, and the information gathered will be used for planning and publishing purposes within your organization.
* If you are unsure about any field, feel free to reach out to the form administrators for guidance.
