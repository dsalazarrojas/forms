## Web Banner Creation Request Form - Help Guide

## Purpose
This form is designed for creating web banner requests. It allows users to submit their requests for web banners, including details such as description, image URL, size, and priority. The form is used to manage web banner requests for various teams and stakeholders.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the required fields, indicated by an asterisk (\*).
2. Select the correct options for each field as instructed.
3. Ensure that you have the necessary permissions to access the assigned tool users and assigned tool.
4. Review your submission before submitting the form.

## Field-by-Field Explanation
* **Web Banner Creation Request** (`web_banner_creation_request`, text, required): Enter a brief description of the web banner request.
* **Web Banner Description** (`webBannerDescription`, text, required): Provide a detailed description of the web banner request.
* **Image URL** (`image_url`, text, required): Enter the URL of the image to be used for the web banner.
* **Size** (`size`, number, optional): Select the size of the web banner (e.g., 200x200).
* **Color** (`color`, text, optional): Enter the color of the web banner (e.g., #ffffff).
* **Background Color** (`background_color`, text, optional): Enter the background color of the web banner (e.g., #000000).
* **Text Color** (`text_color`, text, optional): Enter the text color of the web banner (e.g., #000000).
* **Font Size** (`font_size`, text, optional): Enter the font size of the web banner (e.g., 14).
* **Font Family** (`font_family`, text, optional): Select the font family of the web banner (e.g., Arial).
* **Font Style** (`font_style`, text, optional): Select the font style of the web banner (e.g., bold).
* **Content** (`content`, text, optional): Enter the content of the web banner (e.g., "Limited time offer!").
* **Due Date** (`due_date`, date, optional): Select the due date for the web banner request.
* **Priority** (`priority`, number, optional): Select the priority level of the web banner request (e.g., High, Low).
* **Assigned Tool User** (`assigned_tool_user`, select_one, optional): Select the user who will be assigned to work on the web banner request.
* **Assigned Tool** (`assigned_tool`, select_multiple, optional): Select the tools that will be used to create the web banner.
* **Created By** (`created_by`, select_one, optional): Select the user who created the web banner request.
* **Status** (`status`, select_one, optional): Select the status of the web banner request (e.g., Draft, Approved).
* **Updated By** (`updated_by`, select_one, optional): Select the user who last updated the web banner request.
* **Updated At** (`updated_at`, date, optional): Select the date and time the web banner request was last updated.
* **Comments** (`comments`, text, optional): Enter any comments regarding the web banner request.
* **Comment** (`comment`, text, optional): Enter a comment regarding the web banner request.
* **Created At** (`created_at`, date, optional): Select the date and time the web banner request was created.
* **Updated By Comment** (`updated_by_comment`, select_one, optional): Select the user who last updated the comment.
* **Assigned To** (`assigned_to`, select_multiple, optional): Select whether the web banner request is assigned to someone.
* **Assigned To Email** (`assigned_to_email`, email, optional): Enter the email address of the person assigned to the web banner request.

## Tips
* Make sure to fill in all required fields.
* Select the correct options for each field as instructed.
* Review your submission before submitting the form.
* Use the correct format for date fields (e.g., YYYY-MM-DD).
* Use the correct format for email addresses (e.g., [username@example.com](mailto:username@example.com)).
