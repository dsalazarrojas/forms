# educational_expo_sponsorship_form - Help Guide
## Purpose
This form is used to collect sponsorship applications for the educational expo. It is a tool for the event organizers to gather necessary information from potential sponsors.

## How To Complete This Form
1. Fill out the form completely and honestly.
2. Make sure to provide all required information.
3. Review your submission before submitting it.

## Field-by-Field Explanation
* **Sponsor Name** (`sponsor_name`, `text`, required: false): Enter the name of your institution or organization.
* **Institution Type** (`institution_type`, `select_one`, required: false): Select the type of your institution from the options:
	+ Educational Institution
	+ Non-Profit Organization
	+ For-Profit Organization
* **Contact Email** (`contact_email`, `email`, required: false): Enter a valid email address that the event organizers can use to contact you.
* **Contact Phone** (`contact_phone`, `text`, required: false): Enter a valid phone number that the event organizers can use to contact you.
* **Event Name** (`event_name`, `text`, required: false): Enter the name of the event you are sponsoring.
* **Event Date** (`event_date`, `date`, required: false): Select the date of the event you are sponsoring.
* **Event Time** (`event_time`, `time`, required: false): Select the time of the event you are sponsoring.
* **Event Venue** (`event_venue`, `text`, required: false): Enter the location of the event you are sponsoring.
* **Event Details** (`event_details`, `text`, required: false): Enter a brief description of the event you are sponsoring.
* **Support Request Amount** (`support_request_amount`, `number`, required: false): Enter the amount of support you are requesting.
* **Support Request Frequency** (`support_request_frequency`, `select_multiple`, required: false): Select the frequency of support you are requesting:
	+ Daily
	+ Weekly
	+ Monthly
* **Sponsorship Status** (`sponsorship_status`, `select_multiple`, required: false): Select the status of your sponsorship request:
	+ Pending
	+ Approved
	+ Rejected
* **Assigned Rep** (`assigned_rep`, `select_multiple`, required: true): Select whether a representative from your organization has been assigned to this sponsorship:
	+ Yes
	+ No

## Tips
* Make sure to review your submission before submitting it to ensure accuracy and completeness.
* If you are unsure about any field, please contact the event organizers for clarification.
