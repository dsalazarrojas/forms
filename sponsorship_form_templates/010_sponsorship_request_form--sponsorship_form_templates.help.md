# Sponsorship Request Form - Help Guide
## Purpose
The Sponsorship Request Form is a tool used to collect information from users about their sponsorship requests. It helps us keep track of requests made to our organization, including details such as name, email, organization, and sponsorship level. This form is used to ensure that all requests are properly recorded and assigned to the correct person or team.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter your name in the "Name" field.
2. Enter your email address in the "Email" field.
3. Select the name of your organization in the "Organization" field.
4. Choose your desired sponsorship level from the "Sponsorship Level" field.
5. Enter a message to provide more details about your request in the "Message" field.
6. Select the due date for your request using the calendar icon in the "Due Date" field.
7. Add any additional notes about your request in the "Notes" field.
8. If you have a preferred user assigned to handle your request, select their name in the "Assigned User" field.
9. If you're submitting the form on behalf of someone else, select "user" in the "Submitted By" field.
10. Review and confirm that the form information is accurate before submitting.

## Field-by-Field Explanation
### 1. Name (`Name`, text, optional)
Enter your name as you would like it to be displayed in the request record.

### 2. Email (`Email`, email, optional)
Enter your email address for correspondence and updates.

### 3. Organization (`Organization`, text, optional)
Select the name of your organization to associate with the request.

### 4. Sponsorship Level (`Sponsorship Level`, select_one, optional)
Choose the level of sponsorship you are requesting from "Low", "Medium", or "High".

### 5. Message (`Message`, text, optional)
Provide any additional information or details about your request.

### 6. Date (`Date`, date, optional)
Select the date when you expect the request to be completed or submitted.

### 7. Time (`Time`, time, optional)
Select the time when you expect the request to be completed or submitted.

### 8. Notes (`Notes`, note, optional)
Add any additional notes or comments about your request.

### 9. Assigned User (`Assigned User`, select_one, optional)
Select the user who you would like to be assigned to handle your request.

### 10. Submitted By (`Submitted By`, select_one, optional)
Select "user" if you are submitting the form on behalf of someone else.

### 11. Created By (`Created By`, select_one, optional)
This field is automatically populated with the user who created the request.

### 12. Updated By (`Updated By`, select_one, optional)
This field is automatically populated with the user who last updated the request.

### 13. Created At (`Date Created`, date, optional)
Automatically populated with the date when the request was created.

### 14. Updated At (`Date Updated`, date, optional)
Automatically populated with the date when the request was last updated.

### 15. Date Submitted (`Date Submitted`, date, optional)
Automatically populated with the date when the request was submitted.

### 16. Date Assigned (`Date Assigned`, date, optional)
Automatically populated with the date when the request was assigned.

### 17. Status (`Status`, select_one, optional)
Select the status of your request from "New", "In Progress", "Approved", or "Rejected".

### 18. Due Date (`Due Date`, date, optional)
Select the due date for your request.

### 19. Notes Count (`Notes Count`, number, optional)
Automatically calculated and displayed for reference.

### 20. Submission Count (`Submission Count`, number, optional)
Automatically calculated and displayed for reference.

### 21. Submitted Count (`Submitted Count`, number, optional)
Automatically calculated and displayed for reference.

### 22. Assigned Count (`Assigned Count`, number, optional)
Automatically calculated and displayed for reference.

### 23. Status Count (`Status Count`, number, optional)
Automatically calculated and displayed for reference.

### 24. Submitted User (`Submitted User`, select_one, optional)
Select "user" if you are submitting the form on behalf of someone else.

### 25. Created User (`Created User`, select_one, optional)
This field is automatically populated with the user who created the request.

### 26. Updated User (`Updated User`, select_one, optional)
This field is automatically populated with the user who last updated the request.

### 27. Submitted At (`Submitted At`, date, optional)
Automatically populated with the date when the request was submitted.
