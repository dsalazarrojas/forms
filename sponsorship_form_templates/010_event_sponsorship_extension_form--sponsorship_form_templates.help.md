# Event Sponsorship Extension Form - Help Guide
## Purpose
The Event Sponsorship Extension Form is designed to simplify the process of collecting information from potential sponsors, making it easier for event organizers to secure sponsorships and funding. This form is used to collect details about the event, such as its title, category, and description, which will be used to tailor sponsorships to the event's specific needs.

## How To Complete This Form
To complete this form, follow these steps:

1. **Enter the Title**: This is the name of the event you are seeking sponsorship for. Enter a brief and descriptive title that accurately represents the event.
2. **Select Category**: Choose the category for the event from the drop-down menu. This helps the sponsor understand the nature of the event.
3. **Describe the Event**: Provide a detailed description of the event, including its purpose, goals, and expected outcomes. This helps the sponsor understand the event's context and relevance.
4. **Upload Output File**: You can upload any supporting file for the event, such as a document or image, that can help the sponsor understand the event's requirements.
5. **Enter Assigned Tool**: If you have assigned a specific tool or resource for the event, enter its name or identifier.
6. **Re-enter Category**: This is a duplicate field for the category, please enter the same category as selected in step 2.

## Field-by-Field Explanation

* **Event Sponsorship Extension Form**:
	+ **Event Sponsorship Extension Form** (1, text, required): Enter the title of the event.
* **category** (2, select_multiple, optional): Choose a category for the event to help the sponsor understand its nature.
* **description** (3, text, optional): Describe the event in detail, including its purpose, goals, and expected outcomes.
* **output_file** (4, text, optional): Upload a supporting file for the event, such as a document or image.
* **form_ids** (5, number, optional): Enter any unique identifier for the form, if applicable.
* **assigned_tool** (6, text, optional): Enter the name or identifier of any tool or resource assigned to the event.
* **category** (7, text, optional): This is another field for the category, please enter the same category as selected in step 2.
* **category** (8, text, optional): Another duplicate field for the category, please enter the same category as selected in step 2.

## Tips

* Make sure to provide accurate and detailed information about the event to increase the chances of securing sponsorships.
* Review the form carefully before submitting it to ensure all required fields are completed.
* If you have any questions or concerns, feel free to contact the event organizers for assistance.
