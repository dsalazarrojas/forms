# Gender Violence Prevention Awareness Survey - Help Guide

## Purpose
This survey is designed to help raise awareness and prevent gender-based violence. It collects data on individuals' experiences with gender violence and their perceptions of support systems.

## How To Complete This Form
To complete this form, follow these steps:

1. Select one of the options for "Gender" on the first page.
2. Enter your age on the second page.
3. Select all applicable options for "Experience of Violence" on the third page.
4. Select all applicable options for "Relationship Status" on the fourth page.
5. Select all applicable options for "Frequency of Violence" on the fifth page.
6. Answer "Yes" or "No" to "Have You Sought Help" on the sixth page.
7. Answer "Yes" or "No" to "Reported" on the seventh page.
8. Select all applicable options for "Support System" on the eighth page.
9. Select all applicable options from whom you have sought help from on the ninth page.
10. Answer "Yes, some help" or "Yes, a lot of help" to "Have Received Help" on the tenth page.
11. Answer "Yes, sometimes" or "Never" to "Experience Self" on the eleventh page.
12. Answer "Yes" or "No" to "Self-Reported" on the twelfth page.

## Field-by-Field Explanation

* **Gender** (`gender_violence_survey`, select_one): Select your gender, which is the category to which you identify as.
* **Age** (`age`, number): Enter your age.
* **Experience of Violence** (`experience_of_violence`, select_multiple): Select all the types of violence you have experienced, such as Physical Violence, Emotional or Verbal Abuse, Financial Abuse, or Sexual Abuse.
*   If you select "Other (please specify)", you will be able to provide further details in the next field.
* **Relationship Status** (`relationship_status`, select_multiple): Select all the relationships in which you have experienced violence, such as Partner/Spouse, Family Member, Friend, or Other (please specify).
*   If you select "Other (please specify)", you will be able to provide further details in the next field.
* **Frequency of Violence** (`frequency_of_violence`, select_multiple): Select how often you have experienced violence, such as Never, Occasionally, Frequently, or Daily.
* **Have You Sought Help?** (`help_seek`, select_one): Answer if you have sought help for the violence you have experienced.
*   Answer "Yes" if you have sought help, or "No" if you have not.
* **Reported** (`reported`, select_one): Answer if you have reported the violence to anyone.
*   Answer "Yes" if you have reported, "No" if you have not, or "To someone else" if you reported to someone else.
*   If you select "Other (please specify)", you will be able to provide further details in the next field.
* **Support System** (`support_system`, select_multiple): Select all the support systems you have accessed, such as Police/Family/Friends, Hotline/Website/Online Support Groups, or Other (please specify).
*   If you select "Other (please specify)", you will be able to provide further details in the next field.
* **Support System From** (`help_seek_from`, select_multiple): Select all the individuals or organizations from whom you have sought help.
*   If you select "Other (please specify)", you will be able to provide further details in the next field.
*   Answer "Yes, some help" if you have received some help, or "Yes, a lot of help" if you have received a lot of help.
*   Answer "No" if you have not received help.
* **Experience Self** (`experience_self`, select_one): Answer if you have experienced self-harm or self-violence.
*   Answer "Yes, sometimes" if you have sometimes experienced self-harm or self-violence, or "Never" if you have never experienced self-harm or self-violence.
* **Self-Reported** (`self_reported`, select_one): Answer if you have self-reported the violence.
*   Answer "Yes" if you have self-reported, or "No" if you have not.

## Tips
Please answer honestly and accurately to the best of your abilities. If you need help or support, please reach out to organizations or individuals in your area.
