# Singles Experience Survey - Help Guide

## Purpose
The Singles Experience Survey is designed to collect information about a singular event. This form is meant for internal use, so please fill it out as accurately and thoroughly as possible.

## How To Complete This Form
To complete this form, follow these steps:

1. Provide event details in the Event Details section (page 1).
2. Choose the type of event you are filling out the form for in the Event Type section (page 2).
3. Enter the event location in the Event Location section (page 3).
4. Select the date of the event in the Event Date section (page 4).
5. Choose the time of the event in the Event Time section (page 5).
6. Provide a description of the event in the Event Description section (page 6).

## Field-by-Field Explanation
* **Event Details** (`event_details`, `text`, optional): Enter a brief description of the event.
* **Event Type** (`event_type`, select_one, optional):
	+ Select 'Yes' if the event you are filling out this form for is a special type of event.
	+ Select 'No' if the event is not a special type of event.
* **Event Location** (`event_location`, `text`, optional): Enter the location where the event took place.
* **Event Date** (`event_date`, `date`, optional): Select the date of the event in YYYY-MM-DD format.
* **Event Time** (`event_time`, `time`, optional): Select the time of the event in 24-hour format.
* **Event Description** (`event_description`, `text`, optional): Provide a detailed description of the event.
