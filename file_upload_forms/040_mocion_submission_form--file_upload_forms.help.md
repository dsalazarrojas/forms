# Mocion Submission Form - Help Guide

## Purpose
This form is designed to collect meeting information for submission. It is used to gather details about a meeting, including its location, date, time, and any attached files.

## How To Complete This Form
To complete this form, follow these steps:
1. Review the meeting details and ensure you have all the necessary information and attachments.
2. Fill out the relevant fields with the requested information.
3. Upload any required files.

## Field-by-Field Explanation

* **Meeting Submission Form** (text, optional): Enter a brief description of the meeting.
* **Meeting Details** (text, optional): Enter a detailed description of the meeting, including its purpose and any notable points.
* **Meeting Date** (date, optional): Enter the date of the meeting in the format DD/MM/YY.
* **Meeting Time** (time, optional): Enter the start and end times of the meeting in 24-hour format (HH:MM).
* **Meeting Location** (text, optional): Enter the location of the meeting.
* **Meeting Start Time** (time, optional): Enter the start time of the meeting in 24-hour format (HH:MM).
* **Meeting Start Date** (date, optional): Enter the start date of the meeting in the format DD/MM/YY.
* **Meeting End Time** (time, optional): Enter the end time of the meeting in 24-hour format (HH:MM).
* **Meeting End Date** (date, optional): Enter the end date of the meeting in the format DD/MM/YY.
* **Meeting Agenda** (note, optional): Enter a list of the meeting's agenda items, including any action items or next steps.
* **Meeting Notes** (text, optional): Enter any additional notes or comments about the meeting.
* **Meeting Files** (text, optional): Enter a list of attached files, such as documents or presentation materials.
* **File Upload 1** (text, optional): Upload the first file associated with the meeting.
* **File Upload 2** (text, optional): Upload the second file associated with the meeting.
* **File Upload 3** (text, optional): Upload the third file associated with the meeting.

## Tips
- Ensure all fields are filled out accurately and thoroughly.
- Attach all required files to ensure completeness of the meeting report.
- Review the form for completeness before submission.
- Use the meeting report for reference and follow-up actions.
