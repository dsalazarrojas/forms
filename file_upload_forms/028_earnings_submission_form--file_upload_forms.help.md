# Earnings Submission Form - Help Guide
## Purpose
The Earnings Submission Form is used to submit earnings information for processing and review. Please ensure you have all necessary documents and data before completing this form to avoid delays or errors.

## How To Complete This Form
1. Fill in the **Earnings Details** section with the relevant information.
2. Enter the dates for which you are submitting earnings (**Date 1** and **Date 2**).
3. Specify the amount earned for each date (**Amount 1** and **Amount 2**).
4. Optionally add any additional **Notes**.
5. Select the submission method used (**Submission Method**: Invoicing, Payroll, or Other).
6. If applicable, upload a file related to your earnings submission (**Uploaded File**).
7. Choose the type of file uploaded (**Uploaded File Type**: PDF, DOCX, CSV, Excel, PNG, GIF, BMP, JPG, TIF, TIFF).
8. Provide the name of the uploaded file (**Uploaded File Name**).
9. Specify the size of the uploaded file (**Uploaded File Size**).
10. Optionally describe the uploaded file (**Uploaded File Description**).
11. Indicate the status of the uploaded file (**Uploaded File Status**: Uploaded or Not Uploaded).

## Field-by-Field Explanation
* **Earnings Details**: Enter a brief description of your earnings, such as job title, hours worked, or other relevant information.
* **Date 1**: Enter the date for which you are submitting earnings.
* **Amount 1**: Enter the amount earned for **Date 1**.
* **Date 2**: Enter the date for which you are submitting earnings.
* **Amount 2**: Enter the amount earned for **Date 2**.
* **Notes**: Add any additional comments or information related to your earnings submission.
* **Submission Method**: Select the method used to submit earnings (Invoicing, Payroll, or Other).
* **Uploaded File**: If required, upload a relevant file related to your earnings submission.
* **Uploaded File Type**: Choose the type of file uploaded.
* **Uploaded File Name**: Enter the name of the uploaded file.
* **Uploaded File Size**: Specify the size of the uploaded file.
* **Uploaded File Description**: Provide a brief description of the uploaded file.
* **Uploaded File Status**: Indicate whether the file has been uploaded or not.
