# Tax Report Submission Request Form - Help Guide
## Purpose
This form is designed to collect information for tax report submission requests. It's used to gather essential details about the submitted tax report, including the submission date, submitted person's details, and submission status.

## How To Complete This Form
1. Fill in the Submission Date field with the exact date of the submission.
2. Select the correct Submission Type (Online Submission or In-House Submission).
3. Choose the correct Tax Year for the submission.
4. Select the Submission Status (Approved, Rejected, or In Progress).
5. Fill in the Company field with the name and address of the company.
6. Enter the Tax Report details.
7. Provide any supporting documents, if necessary.
8. Fill in the Manager field with the name of the person submitting the report.
9. Enter the Phone and Fax fields with the contact information.
10. Add any additional remarks or comments about the submission, if needed.

## Field-by-Field Explanation

* **Submission Date** (`submission_date`, date, required): Enter the exact date when the tax report was submitted.
* **Submitted By** (`submitted_by`, select_one, optional): Select the person who submitted the report (Accountant, Finance Team, or Other).
* **Company** (`company`, text, required): Enter the name and address of the company submitting the report.
* **Tax Report** (`tax_report`, text, required): Provide a detailed description of the tax report.
* **Supporting Documents** (`supporting_documents`, text, optional): Attach any documents related to the submission.
* **Remarks** (`remarks`, text, optional): Add any additional comments or remarks about the submission.
* **Title** (`submitted_by_title`, text, required): Enter the title of the person submitting the report.
* **Position** (`submitted_by_position`, text, optional): Enter the position of the person submitting the report.
* **Department** (`submitted_by_department`, text, optional): Enter the department of the person submitting the report.
* **Email** (`submitted_by_email`, email, required): Enter the email address of the person submitting the report.
* **Phone** (`submitted_by_phone`, text, required): Enter the phone number of the person submitting the report.
* **Fax** (`submitted_by_fax`, text, optional): Enter the fax number of the person submitting the report.
* **Notes** (`submitted_by_notes`, note, optional): Add any additional notes or comments about the submission.
* **Other** (`submitted_by_other`, text, optional): Enter any other details about the submission.
* **Address** (`submitted_by_address`, text, optional): Enter the address of the person submitting the report.
* **State** (`submitted_by_state`, text, optional): Enter the state of the person submitting the report.
* **City** (`submitted_by_city`, text, optional): Enter the city of the person submitting the report.
* **Zip** (`submitted_by_zip`, text, required): Enter the zip code of the person submitting the report.
* **Submission Type** (`submission_type`, select_one, required): Select the type of submission (Online Submission or In-House Submission).
* **Submission Location** (`submission_location`, text, optional): Enter the location of the submission.
* **Tax Year** (`tax_year`, select_multiple, required): Select the tax year for the submission.
* **Submission Status** (`submission_status`, select_one, required): Select the status of the submission (Approved, Rejected, or In Progress).
* **Submission Comment** (`submission_comment`, text, optional): Add any additional comments about the submission.
* **Submission Comment 2** (`submission_comment_2`, text, optional): Add any additional comments about the submission.
* **Manager** (`submitted_by_manager`, select_one, optional): Select the manager who approved the submission.
* **Submission Location 2** (`submission_location_2`, text, optional): Enter any additional location information.
* **Submission Type 2** (`submission_type_2`, select_one, optional): Select the submission type.
* **Submission Comment 3** (`submission_comment_3`, text, optional): Add any additional comments about the submission.
* **Submission Status 2** (`submission_status_2`, select_one, optional): Select the status of the submission.
* **Submission Comment 4** (`submission_comment_4`, text, optional): Add any additional comments about the submission.
