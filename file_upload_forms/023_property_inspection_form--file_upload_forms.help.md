# property_inspection_form - Help Guide
## Purpose
The Property Inspection Form is used to collect information about a property inspection, including details about the property, the inspector, and the client. It is intended to provide a comprehensive record of the inspection findings and to facilitate communication between the inspector and the client.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter your User Input in the text field provided. This is the main section where you can enter any relevant information about the property inspection.
2. Upload a file if required by the client or your organization.
3. Select the Property Type from the drop-down menu to indicate the type of property being inspected.
4. Choose the Property Condition using the multi-select menu to indicate the current condition of the property.
5. Enter the Inspector Name and Title in the respective text fields.
6. Enter the Date and Time Inspected using the date and time fields.
7. Enter the Property Address if required.
8. Enter any additional Inspector Notes in the text field.
9. Enter the Client Name, Email, and Phone Number if required.
10. Sign and date the Inspector Signature and Client Signature fields.

## Field-by-Field Explanation
- **User Input** (`User Input`, `text`, required/optional): A text field for entering any relevant information about the property inspection.
- **File Upload** (`File Upload`, `text`, required/optional): Upload a file as required by the client or your organization.
- **Property Type** (`Property Type`, `select_one`, required/optional): Select the type of property being inspected from the drop-down menu.
- **Property Condition** (`Property Condition`, `select_multiple`, required/optional): Choose the current condition of the property using the multi-select menu.
- **Inspector Name** (`Inspector Name`, `text`, required/optional): Enter the name of the inspector conducting the inspection.
- **Date Inspected** (`Date Inspected`, `date`, required/optional): Enter the date of the inspection in the date field.
- **Time Inspected** (`Time Inspected`, `time`, required/optional): Enter the time of the inspection in the time field.
- **Notes** (`Notes`, `note`, required/optional): Enter any additional comments or notes about the inspection.
- **Email** (`Email`, `email`, required/optional): Enter the email address of the client if required.
- **Phone** (`Phone`, `text`, required/optional): Enter the phone number of the client if required.
- **Inspector Signature** (`Inspector Signature`, `text`, required/optional): Sign and date the inspection report.
- **Client Name** (`Client Name`, `text`, required/optional): Enter the name of the client if required.
- **Client Email** (`Client Email`, `email`, required/optional): Enter the email address of the client if required.
- **Client Phone** (`Client Phone`, `text`, required/optional): Enter the phone number of the client if required.
- **Inspector Title** (`Inspector Title`, `text`, required/optional): Enter the title of the inspector if required.
- **Date of Visit** (`Date of Visit`, `date`, required/optional): Enter the date of the visit in the date field.
- **Time of Visit** (`Time of Visit`, `time`, required/optional): Enter the time of the visit in the time field.
- **Property Address** (`Property Address`, `text`, required/optional): Enter the address of the property if required.
- **Inspector Notes** (`Inspector Notes`, `note`, required/optional): Enter any additional comments or notes about the inspection.
- **Client Signature** (`Client Signature`, `text`, required/optional): Sign and date the inspection report.
- **Client Title** (`Client Title`, `text`, required/optional): Enter the title of the client if required.
- **Property Status** (`Property Status`, `select_one`, required/optional): Select the current status of the property from the drop-down menu.
- **Property Subtype** (`Property Subtype`, `select_multiple`, required/optional): Choose the subtype of the property using the multi-select menu.
- **Additional Info** (`Additional Info`, `text`, required/optional): Enter any additional information about the property.
- **Inspector Comments** (`Inspector Comments`, `text`, required/optional): Enter any comments or notes from the inspector.
