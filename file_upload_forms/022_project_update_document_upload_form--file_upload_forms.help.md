Project Update Document Upload Form - Help Guide
=====================================

## Purpose
This form is designed to allow project managers and team members to upload project update documents and categorize them for easy access and reference.

## How To Complete This Form
To complete this form, follow these steps:

1. Navigate to the form and review the project progress update page.
2. If necessary, provide a detailed project progress update in the text field on page 1.
3. On page 2, select the number of files you are attaching to support your project progress update.
4. On page 3, choose whether or not to upload a file. If you choose "Yes", you will be able to upload a file.
5. On page 4, select a category for your uploaded file from the provided options.

## Field-by-Field Explanation
### Project Progress Update (`project_update_document_upload_form_page_1`)
* **Project Progress Update** (Text, Optional): Enter a brief description of your project's current progress and status.

### Document Upload (`project_update_document_upload_form_page_2`)
* **Document Upload** (Number, Optional): Indicate the number of files you are attaching to support your project progress update.

### File Upload (`project_update_document_upload_form_page_3`)
* **File Upload** (Select Multiple, Optional): Choose "Yes" to upload a file, or "No" if you are not attaching a file.

### Category (`project_update_document_upload_form_page_4`)
* **Category** (Select One, Optional): Select a category for your uploaded file from the options "File Upload Forms" or "Business Report Forms".
