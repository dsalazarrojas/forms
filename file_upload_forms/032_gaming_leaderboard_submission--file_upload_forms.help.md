# Gaming Leaderboard Submission - Help Guide
## Purpose
The Gaming Leaderboard Submission form is used to collect scores from players for a specific game on a designated leaderboard.

## How To Complete This Form

1. Fill out the form with your gaming information.
2. Enter your name and score in the respective fields.
3. Provide the name of the game you're playing.
4. If applicable, enter the name of your team.
5. Enter the name of the leaderboard you're submitting to.
6. Set the date and time of your submission.

## Field-by-Field Explanation
* **Player Name (Player Name)**: A field to identify the player submitting the score.
* **Score (Score)**: The player's actual score.
* **Game Name (Game Name)**: The name of the game being played.
* **Team Name (Team Name)**: The name of the team the player is playing with (if applicable).
* **Leaderboard Name (Leaderboard Name)**: The name of the leaderboard the score is being submitted to.
* **Submission Date (Submission Date)**: The date and time of when the score was submitted.
* **Score Value (Score Value)**: The actual value of the score (if different from the score field).

## Tips
- Make sure to fill out all required fields to ensure your submission is successful.
- Double-check the game and leaderboard names to ensure accuracy.
- If you're unsure about any field, contact the leaderboard administrator for clarification.
