# Quiz Badge Submission Form - Help Guide

## Purpose
This form is designed to collect demographic information and badges earned by users in a quiz-based system.

## How To Complete This Form
1. Fill in your first name in the first field.
2. Enter your email address in the second field.
3. If necessary, upload a file (e.g., proof of badge earnement) in the third field.
4. Select the badges you have earned from the options in the fourth field.
5. Submit the form to complete your badge submission.

## Field-by-Field Explanation

* **First Name** (`first_name`, text, optional): Enter your first name for identification purposes.
* **Email** (`email`, email, optional): Enter your email address for contact and verification purposes.
* **File** (`file`, text, optional): If you have proof of badge earnement, upload a file to support your claim. This can be a screenshot, a photo, or any other relevant document.
* **Badges** (`badge_claim`, select multiple, optional): Select all the badges you have earned from the provided options.

## Tips
* Make sure to fill in your first name and email address accurately.
* Be mindful of the file size and format when uploading a supporting document.
* Select only the badges you have earned to avoid incorrect claims.
* If you are unsure about the badge claim process, contact form support at form@gic.mx.
