# Creation Archiving Form - Help Guide

## Purpose
The Creation Archiving Form is a tool for capturing and tracking metadata about creative works, such as art, literature, or designs. Its purpose is to provide a standardized way to collect relevant details about each creation, making it easier to manage and maintain records.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the required fields, such as creation date and category.
2. Provide a brief description of the creation.
3. Upload any relevant files, such as images or videos.
4. Select the correct status for the creation, such as "archived", "pending", or "draft".
5. Review and update any additional fields as necessary.

## Field-by-Field Explanation

* **Creation ID** (`form_id`, number, required: false): Enter a unique identifier for the creation, if available.
* **Creation Date** (`creation_date`, date, required: false): Enter the date the creation was made.
* **Creation Time** (`creation_time`, time, required: false): Enter the time the creation was made.
* **Creation Description** (`creation_description`, text, required: false): Provide a brief description of the creation.
* **Creation Image** (`creation_image`, text, required: false): Upload an image related to the creation.
* **Creation Audio** (`creation_audio`, text, required: false): Upload an audio file related to the creation.
* **Creation Video** (`creation_video`, text, required: false): Upload a video file related to the creation.
* **Creation Text** (`creation_text`, text, required: false): Enter any additional text about the creation.
* **Category ID** (`category_id`, number, required: false): Select the category or genre of the creation.
* **User ID** (`user_id`, number, required: false): Identify the user who created the creation.
* **Archivations Status** (`archivations_status`, select_one, required: false): Select the status of the creation, such as "archived", "pending", or "draft".
* **File Upload URL** (`file_upload_url`, text, required: false): Enter a link to an external file upload.
* **File Upload** (`file_upload`, text, required: false): Upload a file related to the creation.
* **Creation Location** (`creation_location`, text, required: false): Enter the location where the creation was made.
* **Creation Material** (`creation_material`, text, required: false): Enter the material used to create the creation.
* **Creation Technique** (`creation_technique`, text, required: false): Enter the technique used to create the creation.
* **Creation Mimetype** (`creation_mimetype`, text, required: false): Enter the mimetype of the creation.
* **Creation Size** (`creation_size`, number, required: false): Enter the size of the creation.
* **Creation Height** (`creation_height`, number, required: false): Enter the height of the creation.
* **Creation Width** (`creation_width`, number, required: false): Enter the width of the creation.
* **Archivations Notes** (`archivations_notes`, text, required: false): Enter any additional notes about the archivations process.
* **Creation Tags** (`creation_tags`, text, required: false): Enter tags or keywords related to the creation.
