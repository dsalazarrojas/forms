# Event Layout Upload Form - Help Guide
## Purpose
The Event Layout Upload Form is designed to collect information about events, specifically the layout of the event. This form is meant to be used by event organizers, planners, and administrators to gather details about events in a structured and organized way.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the "Event Layout File" field by uploading the layout of your event.
2. Enter the "Planning Details" field with any additional information about the event.
3. Input the "Event Date" and "Event Time" fields with the date and time of the event.
4. Provide the "Event Venue" field with the location of the event.
5. If applicable, add additional files to the "Additional Files" field.
6. Enter any further details about the event in the "Planning Details 2" field.
7. If the event has a date and time, input the "Event Date 2" and "Event Time 2" fields with the date and time of the event.
8. Enter the "Event Venue 2" field with the location of the event.
9. Finally, fill out the "Event Layout File 2" field with any additional layouts for the event.

## Field-by-Field Explanation
* **Event Layout File**: Upload the layout of your event. This is an important field as it helps event organizers and planners get a clear visual representation of the event layout.
* **Planning Details**: Enter any additional information about the event that is not included in the event layout.
* **Event Date**: Input the date of the event in the format "yyyy-MM-dd". This is crucial for scheduling and planning purposes.
* **Event Time**: Input the time of the event in the format "HH:MM". This helps event organizers and planners coordinate and schedule the event properly.
* **Event Venue**: Enter the location of the event.
* **Additional Files**: If you have additional files related to the event, upload them here.
* **Planning Details 2**: Enter any further information about the event.
* **Event Date 2**: If the event has a date, input it in the format "yyyy-MM-dd".
* **Event Time 2**: If the event has a time, input it in the format "HH:MM".
* **Event Venue 2**: Enter the location of the event, this field is similar to the Event Venue field, but for a second event.
* **Event Layout File 2**: Upload any additional layouts for the event.
