# Cybersecurity Data Recovery Referral Form - Help Guide
## Purpose
This form is designed for organizations to report and track security incidents related to malware, phishing, ransomware, data breaches, or other types of security incidents. It helps the incident response team to quickly gather essential information and start taking corrective actions to mitigate the incident.

## How To Complete This Form

### Before You Begin

* Ensure you have the necessary authorization to fill out this form.
* Verify that the form has not been completed by another representative from your organization.

### Completing the Form

1. **Form Data**: Enter a brief description of the incident.
2. **Incident Type**: Select the type of incident from the provided options (Malware, Phishing, Ransomware, Data Breach, or Other). This will help the incident response team to categorize and prioritize responses.
3. **Incident Date**: Enter the date of the incident.
4. **Incident Time**: Enter the time of the incident.
5. **Affected Assets**: Describe the assets that were affected by the incident.
6. **Incident Details**: Provide a detailed description of the incident.
7. **Recovery Actions**: Describe any recovery actions already taken or planned.
8. **Form Submitter**: Enter your name and title (e.g., "John Doe, IT Manager").
9. **Contact Person**: Enter the name and title of the person to contact for more information.
10. **Contact Email**: Enter the email address of the contact person.
11. **Form Submitter Email**: Enter the email address of the person submitting the form.
12. **Organization**: Enter your organization's name.
13. **Organization Address**: Enter your organization's address.
14. **Organization Phone**: Enter your organization's phone number.
15. **Upload File**: Upload any relevant files related to the incident.
16. **File Metadata**: Describe the file uploaded.
17. **File Type**: Select the type of file uploaded (CSV, Excel, PDF, Word).
18. **Upload File 2**: If additional files are relevant, you can upload another file here.
19. **File Metadata 2**: Describe the file uploaded.

## Field-by-Field Explanation

* **Form Data**: A brief description of the incident. Please provide as much detail as possible.
* **Incident Type**: Select the type of incident from the options provided.
* **Incident Date**: The date of the incident.
* **Incident Time**: The time of the incident.
* **Affected Assets**: A list or description of the assets affected by the incident.
* **Incident Details**: A detailed description of the incident.
* **Recovery Actions**: Describe any recovery actions already taken or planned.
* **Form Submitter**: Your name and title.
* **Contact Person**: The name and title of the person to contact for more information.
* **Contact Email**: The email address of the contact person.
* **Form Submitter Email**: The email address of the person submitting the form.
* **Organization**: Your organization's name.
* **Organization Address**: Your organization's address.
* **Organization Phone**: Your organization's phone number.
* **Upload File**: Upload any relevant files related to the incident.
* **File Metadata**: A description of the file uploaded.
* **File Type**: The type of file uploaded (CSV, Excel, PDF, Word).
* **Upload File 2**: If additional files are relevant, you can upload another file here.
* **File Metadata 2**: A description of the file uploaded.
