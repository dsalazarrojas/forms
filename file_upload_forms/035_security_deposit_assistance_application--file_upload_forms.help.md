# Security Deposit Assistance Application - Help Guide
## Purpose
The Security Deposit Assistance Application form is used to collect information and documents from tenants to facilitate the review and processing of their security deposit applications. This guide will walk you through each field in the form to help you complete it accurately and efficiently.

## How To Complete This Form
To complete the form, follow these steps:

1. Fill out all required fields, denoted by an asterisk (\*) in the label.
2. Enter the tenant's name in the **Tenant Name** field.
3. Select the date of the application in the **Application Date** field. This should be the date the application is made.
4. Enter the tenant's ID number in the **Tenant ID** field.
5. Enter the deposit amount in the **Deposit Amount** field.
6. If required, upload any supporting deposit documents in the **Upload Deposit** field.
7. Upload proof of identity in the **Upload Proof** field.
8. Upload any relevant documents in the **Upload Documents** field.
9. Upload a digital signature in the **Upload Signature** field.
10. Select the status of the application in the **Status** field. You can choose from Approved, Not Approved, or Pending.

## Field-by-Field Explanation
* **Tenant Name** (`tenant_name`, text, optional): Enter the name of the tenant making the application.
* **Application Date** (`application_date`, date, optional): Enter the date the application is made.
* **Tenant ID** (`tenant_id`, text, optional): Enter the tenant's ID number.
* **Deposit Amount** (`deposit_amount`, number, optional): Enter the amount of the security deposit.
* **Upload Deposit** (`upload_deposit`, text, optional): Upload any supporting documents related to the deposit, if required.
* **Upload Proof** (`upload_proof`, text, optional): Upload proof of identity.
* **Upload Documents** (`upload_documents`, text, optional): Upload any relevant documents.
* **Upload Signature** (`upload_signature`, text, optional): Upload a digital signature.
* **Review Date** (`review_date`, date, optional): Enter the date the application will be reviewed.
* **Reviewed By** (`review_by`, text, optional): Enter the name of the person reviewing the application.
* **Status** (`status`, select_one, optional): Select the status of the application, from Approved, Not Approved, or Pending.

## Tips
* Make sure to fill out all required fields accurately and completely.
* Upload any supporting documents or proof of identity, if required.
* Select a status that accurately reflects the current state of the application.
* If you are unsure about any field or have questions, please contact housing management for assistance.
