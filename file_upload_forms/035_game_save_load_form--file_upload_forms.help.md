# Game Save Load Form - Help Guide

## Purpose
This form is used to save and load games for various platforms, with the goal of tracking game progress and metadata.

## How To Complete This Form
To complete this form, follow these steps:

1.  Enter the game details in the required fields (Save Request, Load Request, Game Name, Game ID, and File Upload).
2.  If applicable, enter any additional information in the optional fields (Platform, Description, Status, Priority, Due Date, Due Time, Assigned To, Notes, Game Platform, Game Type, Save Game ID, Load File ID, Load Game ID, Save Game ID, Game Version ID, Platform ID, Save Game Time, Save Game Date).
3.  Ensure that all required fields are filled out accurately to avoid any issues with saving or loading the game.

## Field-by-Field Explanation

*   **Save Request**: Enter the title of the game you want to save. This is a required field.
*   **Load Request**: Enter the title of the game you want to load. This is a required field.
*   **Game Name**: Enter the name of the game you're saving or loading. This is a required field.
*   **Platform**: Select the platform on which the game is saved or loaded. If you're unsure, you can leave this blank.
*   **Description**: Enter a short description of the game, if desired.
*   **Game ID**: Select the ID of the game you're saving or loading. This is a required field.
*   **File Upload**: Select the type of file you're uploading. Choose from '1', '2', or '3' to select the correct file type. This is a required field.
*   **Load Time**: Enter the time you want to load the game. This is an optional field.
*   **Status**: Select the current status of the game, if applicable. Choose from 'New', 'In Progress', or 'Done'. This is an optional field.
*   **Priority**: Select the priority level of the game, if applicable. Choose from 'Low', 'Medium', or 'High'. This is an optional field.
*   **Due Date**: Enter the due date for the game, if applicable. This is an optional field.
*   **Due Time**: Enter the due time for the game, if applicable. This is an optional field.
*   **Assigned To**: Select the team responsible for the game, if applicable. Choose from 'QA Team', 'Support Team', or 'Game Team'. This is an optional field.
*   **Notes**: Enter any additional notes or comments about the game. This is an optional field.
*   **Game Platform**: Select the type of platform for the game, if applicable. Choose from 'Console', 'Mobile', or 'PC'. This is an optional field.
*   **Game Type**: Select the type of game, if applicable. Choose from 'Action', 'Adventure', or 'Casual'. This is an optional field.
*   **Save File ID**: Select the ID of the file you're saving. This is an optional field.
*   **Load File ID**: Select the ID of the file you're loading. This is an optional field.
*   **Load Game ID**: Select the ID of the game you're loading. This is an optional field.
*   **Save Game ID**: Select the ID of the saved game. This is an optional field.
*   **Game Version ID**: Select the version ID of the game, if applicable. This is an optional field.
*   **Platform ID**: Select the ID of the platform, if applicable. This is an optional field.
*   **Save Game Time**: Enter the time you want to save the game. This is an optional field.
*   **Save Game Date**: Enter the date to save the game. This is an optional field.
