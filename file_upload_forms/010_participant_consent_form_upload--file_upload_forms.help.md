# Participant Consent Form Upload - Help Guide
## Purpose

This form is designed to collect participant consent forms that acknowledge a participant's agreement to participate in a study, survey, or other data collection activity.

## How To Complete This Form

1.  Fill out the form completely and accurately.
2.  Ensure that you have the required permissions to upload the participant consent form.
3.  Upload the participant consent form in the specified format (e.g., PDF, Word, etc.).

## Field-by-Field Explanation

*   **Participant Consent Form Upload (participant_consent_form_upload)**:
    This field is for uploading the participant consent form. It is not required, but it is essential to provide the form for participants to sign and return.
*   **File (file)**:
    This field is for specifying the file name of the uploaded participant consent form.
*   **Description (description)**:
    This field is for providing a brief description of the uploaded participant consent form. This can help identify the form and its purpose.
*   **Uploaded File (uploaded_file)**:
    This field is for displaying the uploaded participant consent form. If a file has been uploaded, this field will be populated with the file details.
    Note: This field is not editable; it displays the uploaded file.

## Tips

*   Make sure to use the correct format for the uploaded file (e.g., PDF, Word, etc.).
*   Verify that the uploaded file is a valid participant consent form.
*   Double-check that the participant consent form includes all required information, such as the study's purpose, risks, and benefits, as well as the participant's rights and responsibilities.
