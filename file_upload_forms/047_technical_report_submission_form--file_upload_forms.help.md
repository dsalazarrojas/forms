# Technical Report Submission Form - Help Guide
## Purpose
This form is used to collect technical reports and supporting documents from users. 

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the "Technical Report" field with a brief description of your report.
2. If necessary, upload supporting documents by selecting "Supporting Documents".
3. Choose the author of the report from the dropdown menu.
4. Enter the date and time of the report.
5. Add any additional comments about the report.
6. Select the author's contact email and phone number.
7. Upload additional attachments for the report, if required.
8. Upload supporting attachments, if necessary.

## Field-by-Field Explanation
### Technical Report (<name>: Technical Report, <type>: text)
This is a text field where you can enter a brief description of your report.

### Supporting Documents (<name>: Supporting Documents, <type>: text)
This field allows you to upload supporting documents if necessary.

### Author Details (<name>: Author Details, <type>: select_one)
Select the author of the report from the dropdown menu.

### Date (<name>: Date, <type>: date)
Enter the date of the report in the format MM/DD/YYYY.

### Time (<name>: Time, <type>: time)
Enter the time of the report in the format HH:MM AM/PM.

### Comments (<name>: Comments, <type>: text)
This field is for any additional comments about the report.

### Author (<name>: Author, <type>: select_one)
Select the author's name from the dropdown menu.

### Email (<name>: Email, <type>: email)
Enter the author's email address.

### Phone (<name>: Phone, <type>: text)
Enter the author's phone number.

### Attachment (<name>: Attachment, <type>: text)
Upload supporting attachments for the report.

### Additional Attachment (<name>: Additional Attachment, <type>: text)
Upload more supporting attachments if necessary.

## Tips
- Make sure to review the form carefully before submitting.
- Only submit the report once you're sure it's complete and accurate.
- If you're unsure about any field, contact us for assistance.
