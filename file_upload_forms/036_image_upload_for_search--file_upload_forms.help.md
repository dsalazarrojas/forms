# image_upload_for_search - Help Guide
## Purpose
The form is used to collect information for search image uploads, which can be used to search for specific images or upload images to be searched by others.

## How To Complete This Form
To complete this form, please follow these steps:

1.  Please review the form carefully to ensure you are providing all required information.
2.  Fill out the form with all necessary fields.
3.  Upload the image you wish to upload.
4.  Enter the consent and consent date.
5.  Select the upload type.

## Field-by-Field Explanation
- **Consent** (consent, text, required): Please provide your consent for the image upload.
- **Consent Date** (consent_date, date, required): Enter the date you gave your consent.
- **Image** (image_upload, text, required): Upload the image you wish to upload.
- **Images** (image_upload_multiple, text, optional): If you have multiple images to upload, please list them here.
- **File Name** (file_name, text, optional): Enter a name for the uploaded file.
- **File Name Label** (file_name_label, text, optional): Enter a label for the uploaded file.
- **File Size** (file_size, text, optional): Enter the size of the uploaded file.
- **Upload Type** (upload_type, select_one, required): Select the type of upload you are performing.

## Tips
- Make sure to provide all required fields to ensure successful form submission.
