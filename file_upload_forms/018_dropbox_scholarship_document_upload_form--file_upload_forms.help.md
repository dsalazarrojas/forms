# Dropbox Scholarship Document Upload Form - Help Guide
## Purpose
This form is designed to collect documents from applicants for a scholarship application. Please fill out this form to upload relevant documents required for the application process.

## How To Complete This Form
1. Click on the "Upload Documents" button to initiate the upload process.
2. Select the type of document you want to upload from the provided options.
3. Upload the chosen document by either selecting a file from your computer or mobile device, or enter the URL of the document.
4. If prompted, enter the required additional information for the uploaded document.
