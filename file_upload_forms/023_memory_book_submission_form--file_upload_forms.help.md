# Memory Book Submission Form - Help Guide

## Purpose
The Memory Book Submission Form is designed to collect user-submitted memory book entries with associated details. Only one submission per user is allowed.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter your User Name in the User Name field.
2. Share your Story in the Story field.
3. If applicable, upload a Photo in the Photo field.
4. Enter your Email in the Email field.
5. Enter your Phone number in the Phone field.
6. Select the Submission Date and Submission Time fields to indicate when your memory was submitted.
7. Select a Story Photo from the options (if applicable).
8. Choose the Time Zone where your memory was submitted.
9. Enter any Additional Notes in the Additional Notes field (if applicable).
10. Select the Submission Location where your memory was submitted.
11. Select the tool that submitted your memory (e.g. chatjimmy, other).
12. Choose the Form Version from the options.
13. Enter a Form ID (if applicable).
14. Select the Category of the memory book entry.
15. Enter a Description of your memory (if applicable).
16. Enter the Output File path (if applicable).
17. Select the tool that submitted your memory (e.g. chatjimmy, other).
18. Select the Category of the memory book entry.
19. Enter the Output File path (if applicable).

## Field-by-Field Explanation

* **User Name**: Enter your name as it should appear in the memory book entry.
* **Story**: Share your memory in the story field. Be as detailed and descriptive as possible.
* **Photo**: Upload a relevant photo that enhances your memory (if applicable).
* **Email**: Enter your email address for contact purposes.
* **Phone**: Enter your phone number for contact purposes.
* **Submission Date**: Select the date on which your memory was submitted.
* **Submission Time**: Select the time on which your memory was submitted.
* **Story Photo**: Select a photo that relates to your story (if applicable).
* **Time Zone**: Choose the time zone in which your memory was submitted.
* **Additional Notes**: Enter any additional information about your memory (if applicable).
* **Submission Location**: Choose the location where your memory was submitted.
* **Tool**: Select the tool that submitted your memory (e.g. chatjimmy, other).
* **Form Version**: Choose the version of the form that you are using.
* **Form ID**: Enter a unique identifier for your memory book entry (if applicable).
* **Category**: Select the category of the memory book entry.
* **Description**: Enter a description of your memory (if applicable).
* **Output File**: Enter the path to the output file (if applicable).
* **Assigned Tool**: Select the tool that submitted your memory (e.g. chatjimmy, other).
* **Submission Form**: Enter the submission form used (if applicable).
* **Category**: Select the category of the memory book entry.
* **Output File**: Enter the path to the output file (if applicable).
