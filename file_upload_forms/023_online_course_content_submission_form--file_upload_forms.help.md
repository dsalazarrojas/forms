# Online Course Content Submission Form - Help Guide
## Purpose
This form is for submitting course content, including course titles, authors, dates, descriptions, files, and other relevant information. Please fill out the form accurately and completely to ensure that your course is properly documented and available for review.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the course title in the "Course Title" field.
2. Enter the course author's name in the "Course Author" field.
3. Select the date of last update for the course in the "Date of Last Update" field.
4. Optionally, provide a description of the course in the "Description of the Course" field.
5. For each file upload field, select the corresponding file type from the dropdown menu and upload the relevant file.
6. Add any additional course notes in the "Course Notes" field.
7. Select relevant tags for the course in the "Course Tags" field.
8. Enter the course email address in the "Course Email" field (if applicable).
9. Enter the course phone number in the "Course Phone" field (if applicable).

## Field-by-Field Explanation

* **Course Title (required)**: Enter the title of the course.
* **Course Author (required)**: Enter the author's name of the course.
* **Date of Last Update (required)**: Select the date of last update for the course.
* **Description of the Course (optional)**: Provide a brief description of the course.
* **Course File Upload 1 (required)**: Upload a file related to the course (e.g., a syllabus or presentation). Select the corresponding file type from the dropdown menu.
* **File Type 1 (required)**: Select the type of file you uploaded (e.g., PDF, PowerPoint, etc.).
* **Course File Upload 2 (optional)**: Upload another file related to the course (e.g., a video or audio file). Select the corresponding file type from the dropdown menu.
* **File Type 2 (optional)**: Select the type of file you uploaded (e.g., MP4, WAV, etc.).
* **Course Notes (optional)**: Add any additional notes about the course.
* **Course Tags (optional)**: Select relevant tags for the course (e.g., category, level, etc.).
* **Course Email (optional)**: Enter the email address of the course author or owner (if applicable).
* **Course Phone (optional)**: Enter the phone number of the course author or owner (if applicable).
