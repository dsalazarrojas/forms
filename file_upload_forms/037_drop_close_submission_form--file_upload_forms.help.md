# drop_close_submission_form - Help Guide
## Purpose
The "drop_close_submission_form" is used to collect information for closing a submission, providing an overview of the relevant details.

## How To Complete This Form
To complete this form, follow these steps:

1. Upload any relevant evidence related to the submission.
2. Provide a brief description of the uploaded evidence.
3. Select facilities related to the submission (optional).
4. Select additional facility information (optional).
5. Select operations related to the submission (optional).
6. Select additional operation information (optional).
7. Select logistics information (optional).
8. Select additional logistics information (optional).
9. Select the team leader (optional).
10. Select additional team leader information (optional).
11. Provide any additional comments.
12. Select the closure date for the submission.
13. Select the closure time for the submission (optional).
14. Upload a relevant file (optional).
14. Select additional facilities (optional).
15. Provide any additional comments (optional).
16. Click the "Submit" button to complete the form.
