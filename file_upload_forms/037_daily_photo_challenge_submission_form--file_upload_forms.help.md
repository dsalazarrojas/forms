# Daily Photo Challenge Submission Form - Help Guide
## Purpose
The "Daily Photo Challenge Submission Form" is used to submit photos for a daily photo challenge. Users need to provide a photo, a description of the photo, the date of submission, and the type of challenge it belongs to.

## How To Complete This Form
To complete this form, follow these steps:

1. Select a file to upload as the photo entry.
2. Enter a brief description of the photo.
3. Choose the challenge type from the options provided.
4. Select the date of submission.
5. Click the submit button to send the form.

## Field-by-Field Explanation

* **Select a File (photo_upload)** 
  This field allows you to upload a photo from your computer or device. Make sure the file is in a format that is compatible with our system (e.g., JPEG, PNG, etc.).
* **Enter Description (description)** 
  Write a brief description of the photo to help us understand the context and significance of the entry.
* **Submission Date (date)** 
  Select the date you are submitting the photo for the challenge. This date should match the date the challenge was active.
* **Challenge Type (entry_type)** 
  Choose the correct type of challenge the photo belongs to from the provided options. This will help us categorize and display the photo correctly.
