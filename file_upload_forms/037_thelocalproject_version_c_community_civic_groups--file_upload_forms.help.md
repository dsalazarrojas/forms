# Thelocalproject Version C Community Civic Groups - Help Guide

## Purpose
This form is designed to gather information from community members about their civic groups and provide contact details for verification purposes.

## How To Complete This Form
To complete this form, follow these steps:

1. Select all the civic groups that apply to you.
2. Enter your contact information (date) if you wish to share it.
3. Enter the version details (name) if you wish to share it.
4. Upload a file if you wish to share it (e.g., images, documents).
5. Indicate whether you are willing to share your file (yes/no).

## Field-by-Field Explanation
* **community_civic_groups** (Select all that apply): This field allows you to select all the civic groups that you are a part of. Please choose all the groups that are relevant to you.
* **contact_info** (Date): This field is for sharing your contact information. If you wish to share it, enter your date in the format MM/DD/YYYY.
* **version** (Text): This field is for entering the name of the version details you wish to share.
* **file_upload** (Text): This field is for uploading a file. You can upload any type of file (e.g., image, document).
* **file_type** (Select one): Indicate whether you are willing to share your file (yes/no). If you choose yes, you will be able to upload a file in the next field.
