# home_renovation_design_upload_form - Help Guide

## Purpose
This form is used to upload and collect information about home renovation project designs.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the file type from the options provided.
2. Enter the file size in the text field.
3. Upload the file in the designated text field.
4. Provide the file name as the name of the uploaded file.
5. Enter project details in the text area.
6. Enter the designer's name.
7. Enter the designer's phone number.
8. Enter the designer's email address.
9. Enter the contractor's name.
10. Enter the contractor's phone number.
11. Enter the contractor's email address.
12. Select the project status (Active or Inactive) from the options.

## Field-by-Field Explanation

* **File Type** (`file_type`, select_one, required: false): Select the type of file being uploaded (e.g., "Yes" or "No").
* **File Size** (`file_size`, number, required: false): Enter the size of the file in the text field.
* **Upload File** (`upload_file`, text, required: false): Upload the file by providing the file path or URL.
* **File Name** (`file_name`, text, required: false): Enter the name of the uploaded file.
* **Project Details** (`project_details`, note, required: false): Enter any relevant project details.
* **Designer Name** (`designer_name`, text, required: false): Enter the designer's name.
* **Designer Phone** (`designer_phone`, text, required: false): Enter the designer's phone number.
* **Designer Email** (`designer_email`, email, required: false): Enter the designer's email address.
* **Contractor Name** (`contractor_name`, text, required: false): Enter the contractor's name.
* **Contractor Phone** (`contractor_phone`, text, required: false): Enter the contractor's phone number.
* **Contractor Email** (`contractor_email`, email, required: false): Enter the contractor's email address.
* **Project Status** (`project_status`, select_multiple, required: false): Select the project status (Active or Inactive) from the options.
