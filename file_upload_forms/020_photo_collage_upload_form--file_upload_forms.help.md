# Photo Collage Upload Form - Help Guide
## Purpose
This form is used to upload a photo collage for contest submission.

## How To Complete This Form
To complete this form, follow these steps:

1. Make sure you have a valid photo collage to upload.
2. Fill out all the fields accurately and truthfully.
3. Ensure that you have not previously submitted a photo collage with the same title and school name.

## Field-by-Field Explanation
### Upload Photo Collage
* **Upload Photo Collage** (photo_collage_upload_form, text, optional): Upload a valid photo collage for the contest submission.

### School Name
* **School Name** (school_name, text, optional): Enter the name of the school that created the photo collage.

### School Type
* **School Type** (school_type, select_one, optional): Indicate if the school is a public or private institution.

### Contest Category
* **Contest Category** (contest_category, select_multiple, optional): Select all the contest categories that the photo collage fits into.

### School Location
* **School Location** (school_location, text, optional): Enter the location of the school that created the photo collage.

### School Contact
* **School Contact** (school_contact, text, optional): Enter the contact information for the school that created the photo collage.

### Upload Date
* **Upload Date** (upload_date, date, optional): Indicate the date of the upload.

### Submitter
* **Submitter** (submitter, select_one, optional): Indicate if you are the submitter of the photo collage.

## Tips
* Make sure to fill out all fields accurately and truthfully.
* Ensure that you have not previously submitted a photo collage with the same title and school name.
* Only upload valid photo collages for the contest submission.
