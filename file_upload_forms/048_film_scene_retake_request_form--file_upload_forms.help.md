<# Film Scene Retake Request Form - Help Guide

## Purpose
The Film Scene Retake Request Form is used to request a retake for a specific film scene. It is intended to provide detailed information about the scene that needs to be retaken, including the reason for the retake, the preferred date and time for the retake, and other relevant details.

## How To Complete This Form
To complete this form, please follow these steps:

1. Enter a detailed description of the scene that needs to be retaken in the "Scene Request" field.
2. Enter a brief reason for why the scene needs to be retaken in the "Reason" field.
3. If you have a preferred date for the retake, enter it in the "Preferred Date" field. If you do not have a preferred date, you can leave this field blank.
4. If you have a preferred time for the retake, enter it in the "Preferred Time" field. If you do not have a preferred time, you can leave this field blank.
5. If you have a specific urgency level for the retake, enter a number from 1-5 in the "Urgency Level" field. This field is optional, but it can help the production team understand the level of priority for the scene retake.
6. If you have any supporting files or documentation that can help with the retake, upload them in the "Supporting Files" field.

## Field-by-Field Explanation
* **Scene Request**: Enter a detailed description of the specific scene that needs to be retaken.
* **Reason**: Enter a brief reason for why the scene needs to be retaken.
* **Preferred Date**: Enter the preferred date for the retake, if available. If no date is entered, the production team will use their discretion.
* **Preferred Time**: Enter the preferred time for the retake, if available. If no time is entered, the production team will use their discretion.
* **Urgency Level**: Enter a number from 1-5 to indicate the level of priority for the scene retake. This field is optional.
* **Supporting Files**: Upload any supporting files or documentation that can help with the retake.
