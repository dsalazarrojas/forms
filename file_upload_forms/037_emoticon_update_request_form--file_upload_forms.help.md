# Emoticon Update Request Form - Help Guide

## Purpose
This form is used to submit requests for updates to emoticons.

## How To Complete This Form
1. Please select the relevant section you would like to update:
	* Community Suggestion: Provide feedback or suggestions for community-related emoticon changes.
	* Design Change Request: Report design-related issues or changes needed for emoticons.
	* Supporting Files: Attach files that support your request.
2. Fill in the fields as required, using the available space to provide as much detail as possible.
3. In the Emoticon Update Request Form Comments field, provide any additional information about your request.
4. If applicable, select the assigned designer who will be working on the request.
5. Review your submission carefully before submitting the form.

## Field-by-Field Explanation

* **Community Suggestion** (`community_suggestions`, text, optional): Please provide your feedback or suggestions for community-related changes to the emoticon. Be as detailed as possible.
* **Design Change Request** (`design_change_requests`, text, optional): Report any design-related issues or changes needed for the emoticon. Be specific about what you want to see changed.
* **Supporting Files 1 - 8** (`supporting_files_1`-`supporting_files_8`, text, optional): Attach any files that support your request. This could be images, design files, or other relevant files.
* **Emoticon Update Request Form Comments** (`emoticon_update_request_form_comments`, text, optional): Provide any additional information about your request.
* **Assigned Designer** (`assigned_designer`, select_one, optional): Select the designer who will be working on the request.

## Tips
* Make sure to provide clear and concise explanations for your request.
* Attach any supporting files that will help the designer understand your request.
* If you are unsure about what to fill in, please ask a designer for guidance.
* If you are a designer, please ensure you are responding to your assigned requests and keeping track of your workload.
