# Medical Examiner Certification Verification Form - Help Guide
## Purpose
This form is used to verify details of a medical examiner's certification.

## How To Complete This Form
1. Fill in the "Request Date" field with the date the verification request was made.
2. Enter the "Examiner Name" in the text field.
3. Provide the "Certificate Number" for the certification.
4. Select the "Certificate Type" from the available options.
5. Choose the current "Certificate Status" from the available options.
6. Enter any additional "Notes" if necessary.
7. (Optional) Upload an "Attachment" or "Certificate" if required or recommended.

## Field-by-Field Explanation
* **Request Date**: 
    * Type: Date
    * Purpose: Track when the verification request was made.
* **Examiner Name**: 
    * Type: Text
    * Purpose: Enter the name of the medical examiner.
* **Certificate Number**: 
    * Type: Text
    * Purpose: Enter the unique identifier for the certification.
* **Certificate Type**:
    * Type: Select One
    * Purpose: Choose the type of certification.
* **Certificate Status**:
    * Type: Select Multiple
    * Purpose: Choose the current status of the certification.
* **Notes**: 
    * Type: Note
    * Purpose: Enter any additional comments or explanations.
* **Upload Attachment**: 
    * Type: Text
    * Purpose: Upload supporting documents or files related to the certification.
* **Upload Certificate**: 
    * Type: Text
    * Purpose: Upload the certification document itself (if required or recommended).

## Tips
* Please ensure that you're filling out the form for the correct certification.
* Double-check the "Certificate Status" to ensure accuracy.
* Use the "Notes" field to add any additional context.
* Upload attachments or certificates when required or recommended.
* Review and verify the submitted data for accuracy before proceeding.
