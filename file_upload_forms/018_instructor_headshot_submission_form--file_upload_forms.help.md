# Instructor Headshot Submission Form - Help Guide
## Purpose
The Instructor Headshot Submission Form is used to collect a headshot image and associated information from instructors for display on our platform.

## How To Complete This Form
1. Fill out the form with your first and last name.
2. Select your department affiliation (if applicable).
3. Upload a file with your headshot image.
4. Confirm that you have completed the form correctly and submitted it only once.

## Field-by-Field Explanation

### First Name
• **First Name** (`first_name`, text, required/optional): Enter your first name in this field.

### Last Name
• **Last Name** (`last_name`, text, required/optional): Enter your last name in this field.

### Department
• **Department** (`department`, select_one, required/optional): Select your department from the provided options (Yes or No).

### File
• **File** (`file`, text, required/optional): This field is not currently used. Please do not fill it out.

### Upload File
• **Upload File** (`upload_file`, text, required/optional): Upload a file with your headshot image. Please ensure it is a valid image file.
