# Marketing Client Campaign Information Collection - Help Guide
## Purpose
This form is designed to collect and store information about marketing clients' campaigns for efficient management and analysis.

## How To Complete This Form
1. **Campaign Briefs**: Provide a brief description of the campaign, including its objectives, goals, and key highlights.
2. **Marketing Client ID**: Enter the unique ID of the marketing client.
3. **Budget**: Enter the budget allocated for the campaign.
4. **Timeline**: Enter the campaign's start and end dates.
5. **Agency**: Select 'Yes' if the agency is associated with the campaign.
6. **Status**: Select the status of the campaign, such as 'Active' or 'Inactive'.
7. **Priority**: Select 'Yes' if the campaign is a priority.
8. **Notes**: Enter any additional notes about the campaign.
9. **File Upload**: Upload any relevant files or attachments related to the campaign.
10. **Email**: Enter the email address of the marketing client.
11. **Phone**: Enter the phone number of the marketing client.
12. **Additional Notes**: Enter any additional notes or comments about the marketing client.
13. **Agency Address**: Enter the address of the agency handling the campaign.
14. **Agency Contact**: Enter the contact information of the agency representative.
15. **Agency Phone**: Enter the phone number of the agency.
16. **Agency Email**: Enter the email address of the agency.
17. **Agency Website**: Enter the website URL of the agency.
18. **Agency Social Media**: Select the social media platforms used by the agency (e.g., Facebook, Twitter, Instagram, etc.).
19. **Agency Facebook**: Select 'Yes' if the agency has a Facebook presence.
20. **Agency Twitter**: Select 'Yes' if the agency has a Twitter presence.
21. **Agency Instagram**: Select 'Yes' if the agency has an Instagram presence.
22. **Agency YouTube**: Select 'Yes' if the agency has a YouTube presence.
23. **Agency LinkedIn**: Select 'Yes' if the agency has a LinkedIn presence.
24. **Agency Additional Social Media**: Select 'Yes' if the agency has any additional social media presence.
