# Chest X Ray Workflow Documentation - Help Guide
## Purpose
The purpose of this form is to capture and document the workflow and examination details for each chest X-ray examination. This form is used to ensure that all necessary information is captured and documented in a consistent and accurate manner.

## How To Complete This Form

### Step 1: Patient Information

*   **Patient Name**: Enter the full name of the patient.
*   **Patient ID**: Enter the patient's identification number.
*   **Date of Birth**: Enter the patient's date of birth in the format `YYYY-MM-DD`.
*   **Gender**: Select the patient's gender from the provided options.
*   **Pregnancy Status**: Select the pregnancy status of the patient, if applicable.
*   **Was Contrast Used**: Select whether contrast was used during the examination.

### Step 2: Examination Details

*   **Exam Date**: Enter the date of the X-ray examination.
*   **Exam Time**: Enter the time of the X-ray examination.
*   **Exam Type**: Select the type of X-ray examination performed.
*   **Patient Positioning**: Select the positioning of the patient during the examination.
*   **Positioning Aids Used**: Select any aids used for patient positioning.
*   **Protective Equipment Used**: Select the radiation protection used during the examination.
*   **Image Quality**: Select the quality of the acquired images.
*   **Was Repeat Required**: Select whether a repeat of the examination was necessary.
*   **Repeat Reason**: Enter the reason for repeating the examination, if necessary.
*   **Number of Images**: Enter the total number of images acquired.
*   **Were Images Uploaded**: Select whether all images were uploaded to the PACS.
*   **PACS Number**: Enter the PACS accession number, if applicable.
*   **Radiologist Assigned**: Enter the name of the radiologist assigned to review the examination.
*   **Priority Level**: Select the urgency of the examination.
*   **Preliminary Read Available**: Select whether a preliminary read was provided.
*   **Critical Findings**: Select whether critical findings were noted during the examination.
*   **Critical Findings Details**: Enter any critical findings, if necessary.
*   **Was Physician Notified**: Select whether the ordering physician was notified.
*   **Notification Time**: Enter the time when the physician was notified, if necessary.
*   **Patient Instructions Given**: Select whether post-exam instructions were given to the patient.
*   **Adverse Events**: Select any adverse events that occurred during the examination.
*   **Adverse Events Details**: Enter any adverse events, if necessary.
*   **Workflow Status**: Select the current status of the workflow.
*   **Is All Documentation Complete**: Select whether all documentation is complete.
*   **Technologist Signature**: Confirm that this documentation is accurate.
*   **Documentation Date**: Enter the date of documentation.
