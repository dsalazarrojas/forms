# Document Conversion Request Form - Help Guide
## Purpose
This form is designed to help users request document conversions for specific files. Please use this form to submit requests for converting files to the required format.

## How To Complete This Form
1. Fill in the required information: 
   - **Title**: Enter a brief description of the document conversion request.
2. **Input File**: Upload the file that needs to be converted.
3. **Output Format**: Select the desired format of the converted document.
4. **Conversion Method**: Choose the conversion method you prefer.
5. **File Name**: Enter the desired name for the converted file.
6. **File Size**: Optionally input the expected size of the converted file.
7. **Upload Date**: Select the upload date of the original file.
8. **Upload Time**: Select the upload time of the original file.

## Field-by-Field Explanation
- **Document Conversion Request** (`title`, `text`, required): Enter a brief description of the document conversion request.
- **Input File** (`input_file`, `text`, required): Upload the file that needs to be converted.
  - Please ensure the file is in a compatible format for the requested conversion.
- **Output Format** (`output_format`, `select_one`, optional): Select the desired format of the converted document. Please note that not all formats may be supported.
  - If you're unsure, please refer to our supported file formats list.
- **Conversion Method** (`document_conversion_method`, `select_multiple`, optional): Choose the conversion method you prefer. Please note that not all methods may be supported.
  - If you're unsure, please refer to our supported conversion methods list.
- **File Name** (`file_name`, `text`, optional): Enter the desired name for the converted file.
  - Please use a descriptive name that helps identify the converted file.
- **File Size** (`file_size`, `number`, optional): Optionally input the expected size of the converted file.
  - This will help us ensure the converted file meets your requirements.
- **Upload Date** (`upload_date`, `date`, optional): Select the date of the original file upload.
  - This will help us verify the file's age.
- **Upload Time** (`upload_time`, `time`, optional): Select the time of the original file upload.
  - This will help us verify the file's timestamp.

## Tips
- Please ensure the uploaded file is in a compatible format for the requested conversion.
- If you're unsure about any field or conversion method, please refer to our supported file formats and conversion methods lists.
