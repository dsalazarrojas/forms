# FASTA File Analysis Submission - Help Guide

## Purpose
This form is used for submitting FASTA files for analysis. The form collects information about the user who submitted the file, the lab that will perform the analysis, and additional details about the file and analysis.

## How To Complete This Form
To complete this form, follow these steps:

1. Upload your FASTA file in the "Fasta File" field.
2. Enter your email address in the "Email" field.
3. Select the type of analysis you require from the "Analysis Type" dropdown menu.
4. If selecting "Other (Specify below)", enter the type of analysis you require in the "Other Analysis Type" field.
5. Indicate if the file format is not FASTA in the "File Format" field.
6. Enter any additional information about the sequence, such as its length, in the "Fasta Sequence" fields.
7. Enter the name of the lab that will perform the analysis in the "Lab Name" field.
8. Enter the address of the lab in the "Lab Address" field.
9. Enter the phone number of the lab in the "Lab Phone" field.
10. Enter the name of the contact person at the lab in the "Lab Contact Name" field.
11. Enter the email of the contact person at the lab in the "Lab Contact Email" field.
12. Enter the phone number of the contact person at the lab in the "Lab Contact Phone" field.
13. Enter any additional notes about the lab in the "Lab Note" fields.
14. Finally, click the "Submit" button to complete the form.

## Field-by-Field Explanation

* **Fasta File**: Upload the FASTA file for analysis.
* **Email** (`submitter_email`, required, email): Enter your email address for contact purposes.
* **Analysis Type** (`analysis_type`, select_one, optional): Select the type of analysis you require.
	+ Protein Structure Homology Analysis
	+ RNA Structure Homology Analysis
	+ Protein Sequence Homology Analysis
	+ RNA Sequence Homology Analysis
	+ Sequence Alignment Analysis
	+ Other (Specify below)
* **Other Analysis Type** (`other_analysis_type`, text, optional): Enter the type of analysis if you selected "Other (Specify below)" in the Analysis Type field.
* **Other Analysis Type Description** (`other_analysis_type_description`, text, optional): Enter any additional information about the analysis type.
* **File Format** (`file_format`, select_multiple, optional): Indicate the file format of the uploaded file.
	+ FASTA
	+ Other
* **Fasta Sequence** (`fasta_sequence`, text, optional): Enter any additional information about the sequence.
* **Fasta Sequence Length** (`fasta_sequence_length`, number, optional): Enter the length of the sequence if required.
* **Fasta Sequence ID** (`fasta_sequence_id`, text, optional): Enter the ID of the sequence if required.
* **Analysis Requests** (`analysis_requests`, text, optional): Enter any additional requests for the analysis.
* **Submitter Email** (`submitter_email`, required, email): Enter your email address for contact purposes.
* **Submitter Name** (`submitter_name`, required, text): Enter your name.
* **Lab Name** (`lab_name`, required, text): Enter the name of the lab that will perform the analysis.
* **Lab Address** (`lab_address`, required, text): Enter the address of the lab.
* **Lab Phone** (`lab_phone`, required, text): Enter the phone number of the lab.
* **Lab Contact Name** (`lab_contact_name`, required, text): Enter the name of the contact person at the lab.
* **Lab Contact Email** (`lab_contact_email`, required, email): Enter the email of the contact person at the lab.
* **Lab Contact Phone** (`lab_contact_phone`, required, text): Enter the phone number of the contact person at the lab.
* **Lab Note** (`lab_note`, optional, text): Enter any additional notes about the lab.
* **Lab Note 2** (`lab_note_2`, optional, text): Enter any additional notes about the lab.
* **Lab Note 3** (`lab_note_3`, optional, text): Enter any additional notes about the lab.
* **Lab Note 4** (`lab_note_4`, optional, text): Enter any additional notes about the lab.
* **Lab Note 5** (`lab_note_5`, optional, text): Enter any additional notes about the lab.
* **Lab Note 6** (`lab_note_6`, optional, text): Enter any additional notes about the lab.
