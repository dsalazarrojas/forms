# Backup Request Form - Help Guide
## Purpose
The Backup Request Form is used to submit requests for data backup and restore. This form ensures that all backup requests are properly documented and reviewed by IT before being processed.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in your contact information:
	* Full Name
	* Department
	* Email Address
	* Phone Number
2. Specify the backup details:
	* Type of Backup Requested (e.g., Full system backup, File and folder backup, etc.)
	* Priority Level (e.g., Critical, High, Medium, Low, Scheduled)
3. Provide information about the data:
	* Description of Data to Backup
	* Data Location
	* Estimated Data Size
4. Choose your backup options:
	* Preferred Backup Destination (e.g., Primary backup server, Secondary backup server, Cloud storage, etc.)
	* Retention Requirement (e.g., 30 days, 90 days, 1 year, etc.)
	* Encryption Required (e.g., Yes, high security, Yes, standard encryption, No, standard backup, Not sure)
	* Sensitive Data (e.g., Yes, highly sensitive, Yes, moderately sensitive, No, not sensitive, Not sure)
5. Set up notification and approval:
	* Notification Preference (e.g., Email when started, Email when completed, SMS notification, Phone call, No notification needed)
	* Manager Approval Status (e.g., Yes, approved, Pending approval, Not yet requested)
6. Provide additional comments or information:
	* Any Other Information

## Field-by-Field Explanation
### 1. **Full Name** (requester_name, text, required)
Your full name as it appears on your official records.
### 2. **Department** (department, text, required)
Your department or team name.
### 3. **Email Address** (email, email, required)
Your contact email.
### 4. **Phone Number** (phone, text, required)
Your contact phone number.
### 5. **Request Date** (request_date, date, required)
The date of this backup request.
### 6. **Type of Backup Requested** (backup_type, select_one, required)
Select the type of backup you need (e.g., Full system backup, File and folder backup, etc.).
### 7. **Priority Level** (priority_level, select_one, required)
Choose your backup priority level (e.g., Critical, High, Medium, Low, Scheduled).
### 8. **Description of Data to Backup** (data_description, text, required)
Describe the data you want to backup in detail.
### 9. **Data Location** (data_location, text, required)
Specify where the data is stored.
### 10. **Estimated Data Size** (data_size, select_one, required)
Estimate the data size in GB or TB.
### 11. **Upload File List** (file_upload, text, optional)
If you have a document with file details, upload it here.
### 12. **Preferred Backup Destination** (backup_destination, select_one, required)
Choose where you want the backup to be stored (e.g., Primary backup server, Secondary backup server, Cloud storage, etc.).
### 13. **Retention Requirement** (retention_requirement, select_one, required)
Select how long the backup should be kept (e.g., 30 days, 90 days, 1 year, etc.).
### 14. **Encryption Required** (encryption_required, select_one, required)
Choose if this data needs special encryption (e.g., Yes, high security, Yes, standard encryption, No, standard backup, Not sure).
### 15. **Sensitive Data** (sensitive_data, select_one, required)
Determine if this data contains sensitive information (e.g., Yes, highly sensitive, Yes, moderately sensitive, No, not sensitive, Not sure).
### 16. **Compliance Requirements** (compliance_requirements, select_multiple, optional)
List any regulatory requirements (e.g., HIPAA, GDPR, PCI DSS, SOX, None, Other).
### 17. **Backup Schedule Preference** (backup_schedule, select_one, required)
Choose when you want the backup to be performed (e.g., Immediately, During business hours, After business hours, Weekend).
### 18. **Preferred Backup Date** (preferred_backup_date, date, optional)
If you have a scheduled backup, select a date for the backup.
### 19. **Restore Testing Required** (restore_testing, select_one, required)
Choose if you want to test the restore after the backup (e.g., Yes, required, Yes, recommended, No, not needed).
### 20. **Notification Preference** (notification_preference, select_multiple, required)
Select how you want to be notified (e.g., Email when started, Email when completed, SMS notification, Phone call, No notification needed).
### 21. **Special Instructions** (special_instructions, text, optional)
Add any additional requirements or notes.
### 22. **Manager Approval Status** (approval_status, select_one, required)
Determine if your manager has approved this request (e.g., Yes, approved, Pending approval, Not yet requested).
### 23. **Manager Name** (manager_name, text, optional)
Enter the name of your approving manager.
### 24. **Additional Comments** (additional_comments, text, optional)
Add any other information about this backup request.

Please fill out this form carefully and completely to ensure a smooth and efficient backup request process. If you have any questions or concerns, contact your IT department for assistance.
