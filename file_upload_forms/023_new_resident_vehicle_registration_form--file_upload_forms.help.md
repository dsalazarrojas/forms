# New Resident Vehicle Registration Form - Help Guide
## Purpose
This form is designed to collect information about a new resident's vehicle for registration purposes. Please fill it out carefully to avoid any errors or duplicates.

## How To Complete This Form
1. **Enter your resident vehicle details**: In this section, please provide a brief description of your vehicle, including the make, model, and any other relevant details.
2. **Enter resident information**: Please fill out this field with your contact information, such as your name and address.
3. **Upload vehicle image**: If available, please attach a clear image of your vehicle for our records.
4. **Complete the vehicle registration form**: Please fill out this section with any additional details required for vehicle registration.
5. **Apply for parking**: Check the "Yes" box if you would like to apply for parking privileges.
6. **Enter parking application fee**: If you have checked "Yes" for parking application, please provide the fee amount.
7. **Select parking application fee currency**: Choose the currency for the parking application fee.
8. **Discount for parking application fee**: If you have checked "Yes" for parking application, you can apply for a discount on the parking application fee.

## Field-by-Field Explanation
* **Resident Vehicle Details** (`resident_vehicle_details`, text, required/optional): Please provide a brief description of your vehicle.
* **Resident Information** (`resident_info`, text, required/optional): Enter your contact information, such as name and address.
* **Upload Vehicle Image** (`vehicle_image`, text, required/optional): If available, please attach a clear image of your vehicle.
* **Vehicle Registration Form** (`vehicle_registration_form`, text, required/optional): Please fill out any additional details required for vehicle registration.
* **Parking Application** (`parking_application`, select_one, required/optional): Check "Yes" if you would like to apply for parking privileges.
* **Parking Application Fee** (`parking_application_fee`, number, required/optional): Enter the parking application fee amount, if applicable.
* **Parking Application Fee Amount** (`parking_application_fee_amount`, number, required/optional): Enter the parking application fee amount.
* **Parking Application Fee Currency** (`parking_application_fee_currency`, select_one, required/optional): Choose the currency for the parking application fee.
* **Discount for Parking Application Fee** (`parking_application_fee_discount`, number, required/optional): If you have checked "Yes" for parking application, you can apply for a discount on the parking application fee.
