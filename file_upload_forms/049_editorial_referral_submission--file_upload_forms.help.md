# editorial_referral_submission - Help Guide

## Purpose
This form is designed to collect information and files for editorial referrals.

## How To Complete This Form
Before filling out the form, make sure you have a clear idea of your submission and the file you're uploading. This will help you provide accurate and relevant information.

## Field-by-Field Explanation

* **Submission Information**: This field is where you can provide details about the submission, such as its title, date, and any relevant context.
* **Contributor Information**: Here, you can enter information about yourself or the person contributing to the submission, including their name, contact details, and any other relevant credentials.
* **File Info**: This field is for adding a brief description of the file you're uploading, including its purpose and any relevant details.
* **Upload File**: This is where you'll upload the actual file related to the submission. Ensure it's the correct file and in the correct format.
* **Pitch**: In this field, you can provide a brief pitch or summary of the submission, highlighting its key points and relevance.

## Tips
* Double-check the "Submission Information" field for any existing submissions related to your work to prevent duplication.
* Make sure the file you're uploading is in the correct format and size.
* If you're unsure about any of the fields, contact the relevant authorities for guidance.
* This form is designed to be completed in a few minutes, so take your time and be accurate.
