# Illustrator Portfolio Upload Form - Help Guide
## Purpose
The Illustrator Portfolio Upload Form is a platform for creatives to upload their portfolios, showcasing their work to potential clients, employers, or collaborators. This form helps you to provide necessary information about yourself and your portfolio, as well as upload the actual files.

## How To Complete This Form
To complete this form, follow these steps:

1.  Fill in the User Information section with your name and contact details.
2.  Enter your User Name, which will be used to identify you on the platform.
3.  Provide your Email and Phone number for contact purposes.
4.  Add information about your style, including Style Information, Style Name, and Style Description.
5.  Select the relevant Style Tags for your portfolio.
6.  Upload a file for your portfolio, using the "Portfolio File" field.
7.  Once you have uploaded your file, click "Submit" to complete the form.

## Field-by-Field Explanation
* **User Information**: This section is where you provide basic contact information about yourself.
* **User Name**: Please enter a unique name that will identify you on the platform.
* **Email**: Enter your email address for contact purposes.
* **Phone**: Enter your phone number for easy contact.
* **Style Information**: Describe your style or area of expertise.
* **Style Name**: Give a name to your style to make it easily identifiable.
* **Style Description**: A brief description of your style and what it entails.
* **Style Tags**: Choose relevant tags for your style to help others find you.
* **Portfolio File**: Upload the file for your portfolio.
* **Uploaded File**: This field will display the file you have uploaded, once it's submitted.
* **Portfolio Info**: A field for entering any additional portfolio information.
* **Uploaded File**: Displays the status of your uploaded file.
* **Portfolio Uploader**: This field is used to display information about who uploaded the file.
* **Portfolio Uploader Info**: Displays information about the uploader.
* **Style File Uploaded**: Displays that a style file has been uploaded.
* **Style File Uploader**: Displays information about who uploaded the style file.
* **User Portfolio Uploaded**: Displays that a user's portfolio has been uploaded.
* **User Portfolio Uploader**: Displays information about who uploaded the user's portfolio.
* **Uploaded File**: Displays the file that was uploaded.
* **Portfolio Uploader**: Displays information about the uploader of the portfolio.
* **Portfolio Uploader Info**: Displays information about the uploader's portfolio.
* **Portfolio Info**: Displays the uploaded portfolio information.
* **Uploaded File Info**: Displays information about the uploaded file.
* **Portfolio Files Uploader**: Displays information about who uploaded the files.
* **Style File Uploader**: Displays information about who uploaded the style file.
* **Uploaded File Status**: Displays the status of the uploaded file.
* **Portfolio Uploader Info**: Displays information about the uploader.
* **Uploaded File**: Displays the uploaded file.
* **Portfolio Files Uploaded**: Displays the number of files uploaded.
* **Uploaded File Uploader**: Displays information about who uploaded the file.
