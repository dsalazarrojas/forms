# script_scene_submission_form - Help Guide
## Purpose
The "script_scene_submission_form" is used for script scene submissions. It is essential to fill out this form accurately and thoroughly to ensure that your submission is processed correctly.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill out the form completely, paying attention to all required fields (marked as required).
2. Ensure that you enter your contact information (submitter_email and submitter_phone) correctly.
3. Select the correct response for "script_type" and "submitter_category".
4. Upload any necessary files in the fields "script_scene_file1" and "script_scene_file2".
5. Confirm your agreement and acknowledgement by selecting "Yes" for both.

## Field-by-Field Explanation
* **Submitter (<type=text, required=True>)**: Enter your name as the submitter of this script scene.
* **Script Scene Name (<type=text, required=False>)**: Enter the name of the script scene being submitted.
* **Script Type (<type=select_one, required=True>)**: Select whether this script scene is a "Yes" or "No" submission.
* **Script Scene Files (<type=text, required=True>)**: Upload any necessary files related to this script scene.
* **Scene Description (<type=note, required=False>)**: Provide a description of the script scene (optional).
* **Submitter Email (<type=email, required=True>)**: Enter your email address as the submitter of this script scene.
* **Submitter Phone (<type=text, required=False>)**: Enter your phone number as the submitter of this script scene (optional).
* **Submitter Notes (<type=note, required=False>)**: Provide any additional notes about your submission (optional).
* **Submitter Category (<type=select_multiple, required=False>)**: Select any categories that apply to this submission.
* **Submitter Tags (<type=select_multiple, required=False>)**: Select any tags that apply to this submission.
* **Submitter Comments (<type=note, required=False>)**: Provide any additional comments about your submission (optional).
* **Submitter Agreement (<type=select_one, required=True>)**: Confirm that you have read and agreed to the terms of submission.
* **Submitter Acknowledgement (<type=select_one, required=True>)**: Confirm that you have read and acknowledged the submission process.
* **Submitter Date (<type=date, required=False>)**: Enter the date of submission (optional).
* **Submitter Time (<type=time, required=False>)**: Enter the time of submission (optional).

Note: This form is subject to change, and you should always review the most up-to-date version of this help guide for any updates or changes.
