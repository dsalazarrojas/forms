# Study Material Upload Form - Help Guide
## Purpose
The Study Material Upload Form is a tool used by users to report their uploaded study materials to the system. This form is used to gather information about the materials, including their descriptions, uploaders' identities, and contact information.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the relevant options for the uploaded study materials (yes or no).
2. Enter the name and description of each uploaded file (File 1, File 2, File 3).
3. Provide a brief description of the uploaded study materials.
4. Indicate whether you are the one who uploaded the material (yes or no).
5. Enter your contact email address.

## Field-by-Field Explanation

* **Upload Study Material** (`study_material_upload_form_page`): This field is a selection of "yes" or "no" indicating whether or not you have uploaded the relevant study materials.
* **File 1** (`file_1`): Enter the name of the first file you have uploaded.
* **File 2** (`file_2`): Enter the name of the second file you have uploaded, if any.
* **File 3** (`file_3`): Enter the name of the third file you have uploaded, if any.
* **Description** (`description`): Provide a brief description of the uploaded study materials.
* **Uploaded By** (`uploaded_by`): Indicate "yes" if you are the one who uploaded the study material, or "no" otherwise.
* **Email** (`email`): Enter your email address for contact purposes.

## Tips
- Make sure you are the one who uploaded the study material you're reporting.
- Be as concise as possible while providing a clear description of the material.
- If you have any issues or concerns, don't hesitate to reach out to the system administrators.
