# Rendition Download Request Form - Help Guide
## Purpose

This form is used to request a rendition of a file from the system. A rendition is a scaled version of a file, often used for printing or viewing.

## How To Complete This Form

1. Fill out the form with the required information to request a rendition of your file.
2. Provide the title of the file you would like to receive a rendition for.
3. Select the desired rendition of the file from the options provided.
4. Choose the formats in which you would like to receive the rendition (e.g. PDF, JPEG, PNG, or TIFF).
5. Set the delivery timeline for when you would like to receive the rendition.
6. Specify a due date for the rendition, if applicable.
7. Decide if you would like to receive an email notification when the rendition is ready.
8. Enter your contact person's name and contact number for any additional contact information.

## Field-by-Field Explanation

- **File Rendition Request** (Page 1):
    - A note field to provide a brief description of your file rendition request.
- **Rendition File** (Page 1):
    - Enter the title of the file for which you are requesting a rendition.
- **File Rendition** (Page 1):
    - Select the desired rendition of the file (e.g. 1x, 2x, 4x, or 8x).
    - Note: This field is not required, but selecting "None" will cancel the request.
- **Rendition Formats** (Page 2):
    - Select the formats in which you would like to receive the rendition (e.g. PDF, JPEG, PNG, or TIFF).
    - Note: You can select multiple formats.
- **Delivery Timeline** (Page 2):
    - Enter the date by which you would like to receive the rendition.
- **Rendition Due Date** (Page 2):
    - Enter the date by which you would like to receive the rendition, if different from the delivery timeline.
    - Note: This field is optional.
- **Email Notification** (Page 2):
    - Decide if you would like to receive an email notification when the rendition is ready.
- **Contact Person** (Page 3):
    - Enter the name of the contact person responsible for this request.
- **Contact Number** (Page 3):
    - Enter the contact number of the contact person.

## Tips

- Make sure to fill out all required fields to ensure your request is processed correctly.
- If you have any issues or concerns with your rendition request, please contact the system administrators.
- If you would like to cancel your rendition request, please select "None" in the File Rendition field.
