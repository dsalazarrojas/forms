Civil Drawings Submission Form - Help Guide
=====================================

## Purpose
The Civil Drawings Submission Form is designed for engineers and contractors to submit design drawings for civil projects. This form requires information about the project submission details, including the submitter's name, firm name, and license number. Additionally, it asks for project information such as the project name, official project ID, and permit number. The form also includes fields for categorizing the drawings, providing revision information, and uploading files to a secure FTP server. A certification of compliance with local codes and standards is required.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter your name as the submitter in the "Submitter Full Name" field.
2. Enter your firm's name in the "Engineering/Contracting Firm" field.
3. Provide your professional license number in the "Professional License Number (P.E.)" field.
4. Enter the project name in the "Project Name" field.
5. Enter the official project ID or permit number in the "Official Project ID/Permit Number" field.
6. Select the category of drawings from the "Category of Drawings" dropdown menu.
7. Enter the drawing revision number in the "Drawing Revision Number" field.
8. Choose the date of the drawings from the calendar in the "Date of Drawings" field.
9. Upload all PDF and CAD files to the secure FTP server provided in your project portal, including the Project ID and Revision Number in the filename.
10. Enter the total number of sheets in the "Total Number of Sheets in Set" field.
11. Provide any additional comments or revision notes in the "Additional Comments or Revision Notes" field.
12. Confirm that the drawings comply with all local codes and standards by selecting "I Certify" in the "Compliance Certification" dropdown menu.
13. Finally, select the date you are submitting the drawings in the "Date Submitted" field.

## Field-by-Field Explanation

* **Submitter Full Name** (`submitter_name`, text, required): This field is for your full name as the submitter.
* **Engineering/Contracting Firm** (`company_firm_name`, text, required): This field is for your firm's name.
* **Professional License Number (P.E.)** (`license_number`, text, required): This field is for your professional license number.
* **Project Name** (`project_name`, text, required): This field is for the name of the project.
* **Official Project ID/Permit Number** (`project_id_number`, text, required): This field is for the official project ID or permit number.
* **Category of Drawings** (`drawing_category`, select_one, required): This dropdown menu allows you to categorize the drawings into one of the following options: Site Plan/Grading, Structural Designs, Utility/Drainage Plans, Traffic/Transportation, or Landscape and Irrigation.
* **Drawing Revision Number** (`revision_number`, text, required): This field is for the revision number of the drawings.
* **Date of Drawings** (`drawing_date`, date, required): This field is for the date of the drawings.
* **Note - Please upload all PDF and CAD files to the secure FTP server provided in your project portal** (`file_upload_instructions`, note, required): This field is for a note about uploading files to the secure FTP server.
* **Total Number of Sheets in Set** (`sheet_count`, number, required): This field is for the total number of sheets in the drawing set.
* **Additional Comments or Revision Notes** (`special_submission_notes`, text, optional): This field is for any additional comments or revision notes.
* **Compliance Certification** (`compliance_certification`, select_one, required): This dropdown menu allows you to confirm that the drawings comply with all local codes and standards.
* **Date Submitted** (`submission_timestamp`, date, required): This field is for the date you are submitting the drawings.

Note: Ensure that all fields marked as "required" are completed accurately and thoroughly to avoid any issues with submission.
