# Construction Bid Document Upload Form - Help Guide
## Purpose
This form is used to upload construction bid documents for a specific project, including project details, bid amount, and other relevant information.

## How To Complete This Form
1. Ensure you have read the project guidelines and requirements before filling out this form.
2. Fill in the required fields with accurate and up-to-date information.
3. Upload the corresponding bid documents and proposals.
4. Review and submit the form to complete the bid submission process.

## Field-by-Field Explanation
- **Project Name** (`project_name`, text, required): Enter the name of the construction project.
- **Project Number** (`project_number`, text, optional): Provide the project reference or bid number, if applicable.
- **Contractor Company Name** (`contractor_name`, text, required): Enter the legal name of the bidding company.
- **Contractor License Number** (`contractor_license`, text, required): Input the state or local license number of the bidding company.
- **Contact Person** (`contact_person`, text, required): Enter the primary contact person for the bid submission.
- **Contact Email** (`contact_email`, email, required): Enter the email address for communication and correspondence.
- **Contact Phone** (`contact_phone`, text, required): Provide the phone number for questions and inquiries.
- **Bid Submission Date** (`bid_submission_date`, date, required): Enter the date of this bid submission.
- **Bid Deadline** (`bid_deadline`, date, required): Enter the project bid deadline date.
- **Document Type Being Submitted** (`document_type`, select_one, required): Select the type of document being submitted, such as "Complete Bid Package" or "Preliminary Bid".
- **Total Bid Amount** (`bid_amount`, number, required): Enter the total dollar amount of the bid.
- **Proposed Project Timeline** (`project_timeline`, text, required): Estimated completion time in days or weeks.
- **Bid Documents Upload** (`bid_documents`, text, required): Upload the bid documents and proposals.
- **Drawings Included** (`drawings_included`, select_one, required): Check if the submitted documents include drawings.
- **Specifications Included** (`specifications_included`, select_one, required): Check if the submitted documents include specifications.
- **Bonding Capacity** (`bonding_capacity`, text, optional): Enter the maximum bond amount available.
- **Insurance Coverage Amount** (`insurance_coverage`, text, optional): Enter the total liability coverage amount.
- **Relevant Previous Experience** (`previous_experience`, text, optional): Describe similar projects completed.
- **References Provided** (`references_provided`, select_one, optional): Check if project references are provided.
- **Special Conditions or Exceptions** (`special_conditions`, text, optional): Note any exceptions to bid requirements.
- **Bid Validity Period** (`bid_validity_period`, select_one, required): Select the period for which this bid is valid.
- **Authorized Signature** (`authorized_signature`, text, required): Type full name as signature.
- **Signature Date** (`signature_date`, date, required): Enter the date of the signature.

**Tips**:

* Ensure that all required fields are filled in accurately and completely.
* Double-check the selected bid type and bid deadline to avoid errors.
* Attach relevant documents and proposals to support the bid submission.
* Review the bid submission form carefully before submitting it.
