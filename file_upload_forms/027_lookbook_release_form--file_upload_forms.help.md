# lookbook_release_form - Help Guide
## Purpose
This form is used to track the release of Lookbooks, ensuring that all stakeholders are aware of their publication and accessibility.

## How To Complete This Form
To complete this form, follow these steps:

1. Review the fields below and ensure you have all the necessary information.
2. Enter the required and optional information as prompted.

## Field-by-Field Explanation
### contributor_permissions
* **contributor_permissions** (`contributor_permissions`, `note`, optional): This field is used to record the permissions granted to contributors. You can select 'Yes' or 'No' to indicate whether the contributor has been granted permission.

### creative_assets
* **creative_assets** (`creative_assets`, `text`, optional): This field is used to collect information about the creative assets related to the Lookbook release. Enter a brief description of the assets.

### publication_date
* **publication_date** (`publication_date`, `date`, optional): This field is used to record the date of publication. Enter the date in the format 'MM/DD/YYYY'.

### publication_type
* **publication_type** (`publication_type`, `select_one`, optional): This field is used to specify the type of publication. Select 'Yes' or 'No' to indicate whether it's a publication or not.

### published_by
* **published_by** (`published_by`, `select_multiple`, optional): This field is used to specify who published the Lookbook. Select 'Yes' or 'No' to indicate whether it was published by the contributor or someone else.

### client_permissions
* **client_permissions** (`client_permissions`, `select_multiple`, optional): This field is used to record the permissions granted to the client. Select 'Yes' or 'No' to indicate whether the client has been granted permission.

### client_assets
* **client_assets** (`client_assets`, `select_multiple`, optional): This field is used to collect information about the client's assets. Select 'Yes' or 'No' to indicate whether the client has assets related to the Lookbook release.

### release_date
* **release_date** (`release_date`, `date`, optional): This field is used to record the release date of the Lookbook. Enter the date in the format 'MM/DD/YYYY'.

### publication_status
* **publication_status** (`publication_status`, `select_one`, optional): This field is used to record the publication status of the Lookbook. Select 'Active' or 'Inactive' to indicate its status.

## Tips
* Ensure that you have all necessary information before completing this form.
* Review your entries carefully to avoid errors.
* Please note that some fields are optional, but ensure you complete all required fields.
