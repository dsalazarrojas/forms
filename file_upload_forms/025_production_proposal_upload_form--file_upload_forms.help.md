# Production Proposal Upload Form - Help Guide
## Purpose
The Production Proposal Upload Form is used to upload a production proposal for evaluation and review. This form ensures that all relevant details, including project information, budget, and contact details, are captured in a structured manner.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill out each page in sequence, starting from "Upload Production Proposal" to "Contact Note".
2. Ensure that all required fields are completed, as marked with an asterisk (\*).
3. Enter valid data in each field, following the format specified in the field label.
4. Once you have completed all fields, click the submit button to upload the proposal.

## Field-by-Field Explanation

* **Upload Production Proposal** (1/10):
    * This is the main proposal document that you will upload. Please select the "Choose File" button to browse and upload your proposal.
* **Project Details** (2/10):
    * Please enter a brief description of the project, including project name, location, and any relevant background information.
* **Production Type** (3/10):
    * Select one or more production types that apply to your proposal, such as "Film", "Television", "Theatre", etc.
* **Production Budget** (4/10):
    * Enter the total budget for the project, including all expenses.
* **Production Deadline** (5/10):
    * Enter the deadline for completing the project, including start and end dates.
* **Production File** (6/10):
    * If there is an accompanying file related to the proposal, such as a contract or a script, please upload it here.
* **Contact Person** (7/10):
    * Enter the name and title of the contact person responsible for the project.
* **Contact Email** (8/10):
    * Enter the email address of the contact person.
* **Contact Phone** (9/10):
    * Enter the phone number of the contact person.
* **Contact Note** (10/10):
    * Enter any additional notes or comments for the contact person, if necessary.
