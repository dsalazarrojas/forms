# Send A File With Captcha Form - Help Guide
## Purpose
This form is used to upload a file while validating that the submitter is a human. It requires users to select a file and complete a CAPTCHA challenge to confirm their identity.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the file you wish to upload.
2. Select the correct option for the CAPTCHA challenge.
3. Click the "Send" button to submit your file and CAPTCHA.

## Field-by-Field Explanation
* **File to Upload** (text, required): Enter the path and name of the file you wish to upload.
* **Captcha** (select_one, optional): Choose one of the CAPTCHA options to complete the challenge.
* **Send** (text, required): Confirm that you have completed the CAPTCHA challenge and are ready to submit your file.

## Tips
* Make sure to select the correct option for the CAPTCHA challenge to avoid being flagged as a bot.
* Ensure that the file you select is valid and ready for upload.
* If you are having trouble completing the CAPTCHA challenge, try refreshing the page or contacting support for assistance.
