# Wallpaper Request For Browser Extension - Help Guide
## Purpose
This form is designed to collect information for wallpaper requests for browser extensions. It includes fields for user details, wallpaper description, tags, priority, due date, notes, status, and other relevant metadata.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in your first name in the "FirstName" field.
2. Enter your email address in the "Email" field.
3. Provide a description of the design in the "DesignDescription" field.
4. Upload the wallpaper by clicking on the "WallpaperUpload" field.
5. Select the category from the list in the "Category" field.
6. Add any relevant tags in the "Tags" field.
7. Set the priority of the request in the "Priority" field.
8. Enter the due date in the "DueDate" field.
9. Add any additional notes in the "Notes" field.
10. Select the person assigned to in the "AssignedTo" field.
11. Enter the date submitted in the "SubmittedAt" field.
12. Set the status of the request in the "Status" field.
13. Add any additional notes about the status in the "StatusNote" field.
14. Select the person who created the request in the "CreatedBy" field.
15. Select the person who submitted the request in the "SubmittedBy" field.
16. Enter the category tag in the "CategoryTag" field.
17. Enter the due time in the "DueTime" field.
18. Add any additional tags in the "TagsList" field.
19. Add any additional notes in the "AdditionalNotes" field.
20. Enter the date submitted in the "SubmittedDate" field.
21. Add any additional notes about the person assigned to in the "AssignedToNote" field.
22. Add any additional notes about the status in the "StatusNote" field.
23. Add any additional notes about the category in the "CategoryNote" field.
24. Enter the due time in the "DueTime" field.
25. Enter the submitted time in the "SubmittedTime" field.
