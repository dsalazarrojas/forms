# Music Festival Demo Upload Form - Help Guide
## Purpose
This form is designed for uploading and managing music festival demo files within the organization. It helps track and process various aspects of music festival demos, including artist and music information.

## How To Complete This Form
To use this form, follow these steps:

1. Enter the artist's name in the "artist" field.
2. Provide the music details in the "music" field.
3. Select the band name in the "band" field.
4. Upload the demo file using the "upload_file" field.
5. Add a description of the demo in the "description" field.
6. Select the category for the demo in the "category" field.
7. Enter the form ID in the "form_id" field.
8. Enter the form version in the "form_version" field.
9. Assign a tool to the demo in the "assigned_tool" field.
10. Enter the form name in the "form_name" field.
11. Enter the form label in the "form_label" field.
12. Add a description for the form in the "form_description" field.
13. Enter the form URL in the "form_url" field.
14. Upload a form image in the "form_image" field.
15. Enter custom CSS in the "form_css" field.
16. Enter custom JavaScript in the "form_js" field.
17. Upload custom CSS for the form in the "form_css_file" field.
18. Upload custom JavaScript for the form in the "form_js_file" field.
19. Enter HTML for the form in the "form_html" field.
20. Upload HTML for the form in the "form_html_file" field.
21. Enter custom JavaScript for the form in the "form_js_script" field.
22. Upload custom JavaScript for the form in the "form_js_script_file" field.
23. Enter custom CSS class for the form in the "form_css_class" field.

## Field-by-Field Explanation
* **Artist** (`artist`, text, required): Enter the name of the artist performing at the music festival demo.
* **Music** (`music`, text, required): Provide details about the music played at the music festival demo.
* **Band** (`band`, text, required): Select the name of the band performing at the music festival demo.
* **Upload File** (`upload_file`, text, required): Upload the music festival demo file.
* **Description** (`description`, text, required): Add a description for the music festival demo.
* **Category** (`category`, text, required): Select the category for the music festival demo.
* **Form ID** (`form_id`, number, required): Enter the form ID for the music festival demo.
* **Form Version** (`form_version`, text, required): Enter the form version for the music festival demo.
* **Assigned Tool** (`assigned_tool`, text, required): Assign a tool to the music festival demo.
* **Form Name** (`form_name`, text, required): Enter the name for the music festival demo form.
* **Form Label** (`form_label`, text, required): Enter the label for the music festival demo form.
* **Form Description** (`form_description`, text, required): Add a description for the music festival demo form.
* **Form URL** (`form_url`, text, required): Enter the URL for the music festival demo form.
* **Form Image** (`form_image`, text, required): Upload an image for the music festival demo form.
* **Custom CSS** (`form_css`, text, required): Enter custom CSS for the music festival demo form.
* **Custom JavaScript** (`form_js`, text, required): Enter custom JavaScript for the music festival demo form.
* **Custom CSS File** (`form_css_file`, text, required): Upload custom CSS for the music festival demo form.
* **Custom JavaScript File** (`form_js_file`, text, required): Upload custom JavaScript for the music festival demo form.
* **Form HTML** (`form_html`, text, required): Enter HTML for the music festival demo form.
