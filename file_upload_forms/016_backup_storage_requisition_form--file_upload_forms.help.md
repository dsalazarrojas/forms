# Backup Storage Requisition Form - Help Guide
## Purpose
The Backup Storage Requisition Form is used to collect information about storage needs from the requester, helping IT teams or administrators plan and manage storage infrastructure.

## How To Complete This Form
To complete this form, please follow these steps:

* Fill out all the required fields (indicated by an asterisks (*)).
* If you need to store data with a custom capacity, please select "Custom" for storage capacity and provide the exact capacity in TB or GB.
* For select_multiple fields, please select all that apply.
* For select_one fields, please select one option.

## Field-by-Field Explanation
* **Requester Name** (`requester_name`, Text, required): Enter your name or the name of the person submitting the request.
* **Email Address** (`requester_email`, Text, required): Enter your email address.
* **Phone Number** (`requester_phone`, Phone, optional): Enter your phone number if you want to be contacted regarding this request.
* **Department** (`department`, Text, required): Enter your department name.
* **Manager/Supervisor Name** (`manager_name`, Text, required): Enter your manager's name.
* **Type of Storage Needed** (`storage_type`, Select One, required): Select the type of storage you need, such as External Hard Drive, Network Attached Storage (NAS), Cloud Storage Subscription, etc.
* **Required Storage Capacity** (`storage_capacity`, Select One, required): Select the storage capacity you need, such as 1 TB, 2 TB, 4 TB, etc.
* **Custom Capacity** (`custom_capacity`, Text, optional): If you selected "Custom" for storage capacity, enter the exact capacity in TB or GB.
* **Primary Purpose for Storage** (`storage_purpose`, Select One, required): Select the primary purpose of the storage, such as Daily Backups, Archive Storage, etc.
* **Type of Data to Store** (`data_type`, Select Multiple, required): Select all types of data you will be storing, such as Documents, Databases, Application Files, etc.
* **Current Estimated Data Size** (`estimated_data_size`, Text, required): Enter the current estimated data size.
* **Expected Data Growth Per Year** (`growth_projection`, Text, optional): Enter the expected data growth per year.
* **Access Type Required** (`access_type`, Select One, required): Select the access type required, such as Local Network Access, Remote Access, etc.
* **Backup Frequency** (`backup_frequency`, Select One, required): Select the backup frequency, such as Continuous, Hourly, Daily, etc.
* **Encryption Required?** (`encryption_needed`, Select One, required): Select if encryption is required.
* **Redundancy/RAID Configuration Needed?** (`redundancy_required`, Select One, optional): Select if redundancy or RAID configuration is needed.
* **Required Compliance Standards** (`compliance_standards`, Select Multiple, optional): Select all required compliance standards, such as GDPR, HIPAA, etc.
* **Data Classification Level** (`data_classification`, Select One, required): Select the data classification level, such as Public, Internal, etc.
* **Date Needed By** (`needed_by_date`, Date, required): Enter the date the storage is needed by.
* **Cost Center or Budget Code** (`budget_code`, Text, optional): Enter the cost center or budget code.

## Tips
* Please double-check all fields before submitting the form.
* If you have any questions, please contact your IT department or the form creator.
* Please note that this form is intended to collect information and may not cover all possible scenarios or technical requirements. If you have special requirements, please discuss with your IT department or the form creator.
