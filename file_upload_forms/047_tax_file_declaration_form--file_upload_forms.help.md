# Tax File Declaration Form - Help Guide
## Purpose
The Tax File Declaration Form is used to collect information about a tax file declaration form. This includes its title, description, category, and file details.

## How To Complete This Form
To complete this form, please follow these steps:

1. Enter a title for the tax file declaration form in the **Tax File Declaration Form** field.
2. Provide a brief description of the form in the **Description** field.
3. Select a category for the form from the **Category** options (e.g., "Yes" or "No").
4. Enter the file details in the **Tax File** field.
5. Select the file type from the **File Type** options (e.g., "Yes" or "No").
6. Finally, select the **Submit** option to complete and submit the form, or **Cancel** to discard any changes.

## Field-by-Field Explanation
* **Tax File Declaration Form** (1): Enter a brief title for the tax file declaration form.
* **Description** (2): Provide a brief description of the form, explaining its purpose and any relevant details.
* **Category** (3): Select "Yes" if the tax file declaration form is applicable, or "No" if it is not.
* **Tax File** (6): Enter the details of the tax file, including the file name and description.
* **File Type** (7): Select "Yes" if the file is of the tax file type, or "No" if it is not.
* **Tax File** (8): This field is not used in the current form version. Please do not enter any information.
* **Submit** (9): Select "Submit" to complete and submit the form, or "Cancel" to discard any changes.

## Tips
* Please ensure that you have a valid tax file declaration form before completing this form.
* Double-check your entries before submitting the form to ensure accuracy.
* If you have any questions or need assistance, contact your administrator or support team.
