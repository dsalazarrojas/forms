# Voice Over Sample Upload Form - Help Guide
## Purpose
The Voice Over Sample Upload Form is a tool for users to upload multiple samples of voice over work at once. This form is designed to collect metadata about each file, including its title, size, upload method, and description.

## How To Complete This Form
To complete this form, follow the steps below:

1. Enter the title of the first file in the "File 1 Name" field.
2. Enter the size of the first file in the "File 1 Size" field.
3. Select the upload method for the first file from the options provided in the "Upload Method" field.
4. Enter a description of the first file in the "Description" field.
5. Repeat steps 1-4 for each additional file you wish to upload.

## Field-by-Field Explanation

* **File 1 Name** (`file_name`): Enter the title of the first file you are uploading.
* **File 1 Size** (`file_size`): Enter the size of the first file in bytes.
* **Upload Method** (`upload_method`): Select the method by which the first file was uploaded (e.g. "Manual Upload", "API Upload", etc.).
* **Description** (`description`): Enter a brief description of the first file.
* **Talent** (`talent`): Enter the talent who performed the voice over work for the first file.
* **Category** (`category`): Select the category of the voice over work for the first file (e.g. "Action", "Commercials", "Narration", "Voice Over", "Voice-over").
* **File 2 Name** (`file_name_2`): Enter the title of the second file you are uploading.
* **File 2 Size** (`file_size_2`): Enter the size of the second file in bytes.
* **Upload Method 2** (`upload_method_2`): Select the method by which the second file was uploaded.
* **Description 2** (`description_2`): Enter a brief description of the second file.
* **Talent 2** (`talent_2`): Enter the talent who performed the voice over work for the second file.
* **Category 2** (`category_2`): Select the category of the voice over work for the second file.
* **Submit 2** (`submit_2`): This field is not used in the form's functionality.
* This pattern continues for File 3 and beyond, using the same field labels with an incremented index.

**Tips**: Make sure to fill out each field accurately and thoroughly, as this information will be used for data processing and organization purposes. If you have any questions or concerns, please contact your administrator for assistance.
