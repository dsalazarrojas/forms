# New Particle Submission Form - Help Guide
## Purpose
The New Particle Submission Form is a comprehensive form used to submit new particles for research and review purposes.

## How To Complete This Form
To complete this form, follow these steps:

1. Ensure you have all necessary information and files before starting the form.
2. Enter the particle information in the **Particle Info** field.
3. Provide research details in the **Research Details** field.
4. Upload the relevant file using the **Upload Particle File** field.
5. Choose the file type from the **File Type** field.
6. Enter a description of the particle in the **Particle Description** field.
7. Enter the research institution and topic in the **Research Institution** and **Research Topic** fields.
8. Upload the file using the **Upload File** field.
9. Enter the file name and submitter information in the **File Name**, **Submitter Name**, **Submitter Email**, and **Submitter Phone** fields.
10. Select the date and time for submission and review in the **Date** and **Time** fields.
11. Enter the location of the research in the **Location** field.
12. Enter any additional notes in the **Note** field.
13. Enter the file size in the **File Size** field.
14. Choose the particle status from the **Particle Status** field.
15. Enter the file URL in the **File URL** field.
16. Select the research type in the **Research Type** field.
17. Select the research category in the **Research Category** field.
18. Enter the review date in the **Review Date** field.
19. Select the review time in the **Review Time** field.
20. Enter any review comments in the **Review Comment** field.

## Field-by-Field Explanation
* **Particle Info**: Enter a brief description of the particle.
* **Research Details**: Provide detailed information about the research.
* **Upload Particle File**: Upload a file related to the particle.
* **File Type**: Choose the type of file uploaded (e.g., PDF, DOCX, XLS).
* **Particle Description**: Enter a detailed description of the particle.
* **Research Institution**: Enter the institution conducting the research.
* **Research Topic**: Enter the topic of the research.
* **Upload File**: Upload a file related to the research.
* **File Name**: Enter a name for the uploaded file.
* **Submitter Name**: Enter your name as the submitter.
* **Submitter Email**: Enter your email as the submitter.
* **Submitter Phone**: Enter your phone number as the submitter.
* **Date**: Select the date of submission.
* **Time**: Select the time of submission.
* **Location**: Enter the location of the research.
* **Note**: Enter any additional notes about the particle.
* **File Size**: Enter the size of the uploaded file.
* **Particle Status**: Choose the status of the particle (e.g., submitted, reviewed, rejected, accepted).
* **File URL**: Enter the URL of the uploaded file.
* **Research Type**: Enter the type of research conducted (e.g., experimental, theoretical).
* **Research Category**: Enter the category of the research (e.g., physics, biology).
* **Review Date**: Select the date of review.
* **Review Time**: Select the time of review.
* **Review Comment**: Enter any comments about the review.

## Tips
* Ensure that the particle has not been previously submitted.
* Review the form carefully before submission to avoid errors.
* Upload a file related to the particle.
* Enter accurate information to avoid duplication and ensure successful submission.
