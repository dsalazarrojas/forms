# evidence_portfolio_submission_form - Help Guide
## Purpose
This form is designed for submitting evidence portfolios, which are collections of documents and other digital artifacts that demonstrate student learning and achievement.

## How To Complete This Form
1. Select the corresponding page from the top navigation bar.
2. Fill in the required fields with the relevant information.

## Field-by-Field Explanation

* **Submit File** (Page 1)
	+ Label: Submit File
	+ Purpose: Upload your student's portfolio file.
	+ Type: text
	+ Required: false

* **File** (Page 2)
	+ Label: File
	+ Purpose: Select the file to be uploaded for review.
	+ Type: text
	+ Required: true

* **Student Name** (Page 3)
	+ Label: Student Name
	+ Purpose: Enter the student's name.
	+ Type: text
	+ Required: true

* **Teacher Name** (Page 4)
	+ Label: Teacher Name
	+ Purpose: Enter the teacher's name.
	+ Type: text
	+ Required: true

* **Assessment Comments** (Page 5)
	+ Label: Assessment Comments
	+ Purpose: Enter comments or feedback on the student's work (optional).
	+ Type: text
	+ Required: false

* **Assessment Date and Time** (Page 6)
	+ Label: Assessment Date and Time
	+ Purpose: Enter the date and time of the assessment.
	+ Type: date and time
	+ Required: true

* **Upload File** (Page 7)
	+ Label: Upload File
	+ Purpose: Upload your student's portfolio file.
	+ Type: text
	+ Required: true

* **Assessment Comments** (Page 8)
	+ Label: Assessment Comments
	+ Purpose: Enter comments or feedback on the student's work.
	+ Type: text
	+ Required: false

* **Assessment Grade** (Page 9)
	+ Label: Assessment Grade
	+ Purpose: Enter the grade of the assessment.
	+ Type: number
	+ Required: true

* **Submission Status** (Page 10)
	+ Label: Submission Status
	+ Purpose: Select the submission status.
	+ Type: select_one
	+ Options: Completed, Pending, Cancelled
	+ Required: true

* **Submitted By** (Page 11)
	+ Label: Submitted By
	+ Purpose: Select the submitter type.
	+ Type: select_multiple
	+ Options: Student, Teacher, Parent
	+ Required: true

* **Submission Date and Time** (Page 12)
	+ Label: Submission Date and Time
	+ Purpose: Enter the submission date and time.
	+ Type: date and time
	+ Required: true

* **Submitter Information** (Page 13)
	+ Label: Submitter Information
	+ Purpose: Enter the submitter's information.
	+ Type: text
	+ Required: true

* **Email and Phone** (Page 14)
	+ Label: Email and Phone
	+ Purpose: Enter the submitter's email and phone number.
	+ Type: text
	+ Required: true

* **Address and Comments** (Page 15)
	+ Label: Address and Comments
	+ Purpose: Enter the submitter's address and comments.
	+ Type: text
	+ Required: true

Please note that some fields are optional, but are intended to provide additional information. Ensure that you complete all required fields accurately and thoroughly.
