# Planning Condition Change Application - Help Guide
## Purpose
The Planning Condition Change Application form is used to document changes to project conditions that have a significant impact on the project's overall condition. This form helps project team members to request and track changes to project scope, timeline, or budget in a structured way.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the correct "Change Requester" and "Submitter" options to indicate who is requesting and submitting the change.
2. Enter the "Project ID" to identify the project affected by the change.
3. Provide a brief description of the change in the "Condition Change Details" field.
4. Specify the "Change Request Status" to indicate the status of the change request.
5. If the change involves a file upload, provide the file in the "File" field.
6. Select the relevant "Project Team Members" and "Project Team Leads" options to indicate their involvement in the change.

## Field-by-Field Explanation

* **Change Requester** (`change_requester`, `Yes/No`, optional): Indicates who is requesting the change. Choose "Yes" if you are the person requesting the change.
* **Project ID** (`project_id`, `number`, optional): Enter the unique project ID to identify the project affected by the change.
* **Date Change Happened** (`date_change_happened`, `date`, optional): Enter the date when the change happened or is expected to happen.
* **Time Change Happened** (`time_change_happened`, `time`, optional): Enter the time when the change happened or is expected to happen.
* **Condition Change Details** (`condition_change_details`, `text`, optional): Provide a brief description of the change.
* **Change Request Status** (`change_request_status`, `Active/Inactive`, optional): Choose the status of the change request.
* **Submitter** (`submitter`, `Yes/No`, optional): Indicates who is submitting the change request.
* **Submitter Email** (`submitter_email`, `email`, optional): Enter the email of the submitter.
* **Submitter Phone** (`submitter_phone`, `text`, optional): Enter the phone number of the submitter.
* **Submitter Department** (`submitter_department`, `Yes/No`, optional): Indicate the department of the submitter.
* **Submitter Designation** (`submitter_designation`, `Yes/No`, optional): Indicate the designation of the submitter.
* **Submitter Location** (`submitter_location`, `Yes/No`, optional): Indicate the location of the submitter.
* **Project Team Members** (`project_team_members`, `Yes/No`, optional): Select the project team members involved in the change.
* **Project Team Leads** (`project_team_leads`, `Yes/No`, optional): Select the project team leads involved in the change.
* **Change Request Comments** (`change_request_comments`, `text`, optional): Enter any additional comments about the change request.
* **File** (`form_file`, `text`, optional): Upload any relevant files related to the change.
* **Project File** (`form_file2`, `text`, optional): Upload any other relevant files related to the change.

Note: The fields with "optional" or "Yes/No" are not required fields but are included for additional information or options. The date and time fields are optional but can be useful for tracking changes over time.
