# Joint Application Evidence Form - Help Guide

## Purpose
The Joint Application Evidence Form is used for sharing joint application information between two parties. It's a critical component of the application process, and ensuring accurate and consistent completion is key.

## How To Complete This Form
1. Carefully fill out each field with the required information for both parties.
2. Upload any relevant files as requested.
3. Select the consent options as necessary.

## Field-by-Field Explanation

* **Shared Application Form Data** (`Shared Application Form Data`, `text`, required/optional): This field allows you to input shared application data.
* **Applicant 1 Form Data** (`Applicant 1 Form Data`, `text`, optional): This field is for inputting Applicant 1's form data.
* **Applicant 2 Form Data** (`Applicant 2 Form Data`, `text`, optional): This field is for inputting Applicant 2's form data.
* **Upload Shared Applicant Docs** (`Upload Shared Applicant Docs`, `text`, optional): Upload any relevant documents for both parties.
* **Upload Evidences** (`Upload Evidences`, `text`, optional): Upload any evidence required for the joint application.
* **Upload Evidences 1** (`Upload Evidences 1`, `text`, optional): Upload any additional evidence required for the joint application.
* **Review Evidences** (`Review Evidences`, `text`, optional): Review and confirm the uploaded evidence.
* **Review Evidences 1** (`Review Evidences 1`, `text`, optional): Review and confirm the uploaded evidence for Applicant 1.
* **Review Evidences 2** (`Review Evidences 2`, `text`, optional): Review and confirm the uploaded evidence for Applicant 2.
* **File Upload 1** (`File Upload 1`, `text`, optional): Upload any file as requested.
* **File Upload 2** (`File Upload 2`, `text`, optional): Upload any additional file as requested.
* **File Upload 3** (`File Upload 3`, `text`, optional): Upload any further file as requested.
* **File Upload 4** (`File Upload 4`, `text`, optional): Upload any more file as requested.
* **File Upload 5** (`File Upload 5`, `text`, optional): Upload any further file as requested.
* **File Upload 6** (`File Upload 6`, `text`, optional): Upload any additional file as requested.
* **File Upload 7** (`File Upload 7`, `text`, optional): Upload any file as requested.
* **File Upload 8** (`File Upload 8`, `text`, optional): Upload any further file as requested.
* **Consent Form** (`Consent Form`, `select_multiple`, optional): Select the consent options as necessary.
* **Consent Form 1** (`Consent Form 1`, `select_multiple`, optional): Select the consent options as necessary for Applicant 1.
* **Consent Form 2** (`Consent Form 2`, `select_multiple`, optional): Select the consent options as necessary for Applicant 2.

Note: All fields are optional, but filling them out carefully and consistently is crucial for the joint application process.
