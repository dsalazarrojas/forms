# Planning Permission Search Request Form - Help Guide
## Purpose
The Planning Permission Search Request Form is used to search for planning permissions related to properties. It is designed to gather relevant information from users to facilitate the search process.

## How To Complete This Form
1. Fill in the required fields:
	* Address Line 1
	* City
	* Country
	* Postal Code
	* Contact Number
	* Submitter
	* Submitter Note (optional)
2. Fill in any optional fields:
	* Address Line 2
	* State
	* Date of Birth
	* Search Type
	* Property Type
	* Search Term
	* Address Search Type
	* Property Owner
	* Email
	* Address Note
	* Address Additional Info
	* Property Additional Info
	* Search Result
	* Upload File
	* Uploaded File
	* Prophets
3. Select the correct options:
	* Search Type
	* Property Type

## Field-by-Field Explanation
* **Address Line 1** (`address_line_1`, text, required): Enter the first line of the address.
* **Address Line 2** (`address_line_2`, text, optional): Enter the second line of the address.
* **City** (`city`, text, required): Enter the city name.
* **State** (`state`, text, optional): Enter the state name.
* **Country** (`country`, text, required): Enter the country name.
* **Postal Code** (`postal_code`, text, required): Enter the postal code (zip code).
* **Date of Birth** (`date_of_birth`, date, optional): Enter the date of birth (in YYYY-MM-DD format).
* **Search Type** (`search_type`, select_one, optional): Select "Yes" if searching for a specific type of property, otherwise "No".
* **Property Type** (`property_type`, select_multiple, optional): Select one or more property types if applicable.
* **Search Term** (`search_term`, text, required): Enter the search term (description of the property).
* **Address Search Type** (`address_search_type`, select_one, optional): Select "Yes" if searching for a specific type of address, otherwise "No".
* **Property Owner** (`property_owner`, text, optional): Enter the property owner name.
* **Contact Number** (`contact_number`, text, required): Enter the contact number.
* **Email** (`email`, email, optional): Enter the email address.
* **Address Note** (`address_note`, note, optional): Enter any additional notes about the address.
* **Address Additional Info** (`address_additional_info`, text, optional): Enter any additional information about the address.
* **Property Additional Info** (`property_additional_info`, text, optional): Enter any additional information about the property.
* **Search Result** (`search_result`, text, optional): Enter any additional notes about the search result.
* **Upload File** (`upload_file`, text, optional): Upload any supporting documents or files.
* **Uploaded File** (`uploaded_file`, text, optional): Enter the filename of the uploaded file.
* **Submitter** (`submitter`, text, required): Enter your name and title.
* **Submitter Note** (`submitter_note`, note, optional): Enter any additional notes about the submitter.
* **Prophets** (`prophets`, text, optional): Enter any additional information about the prophets.
