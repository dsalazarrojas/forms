# playwright_script_upload_form - Help Guide
## Purpose
The `playwright_script_upload_form` is used to upload and manage scripts for the Playwright testing framework. This form is essential for QA and engineering teams to create, update, and store scripts.

## How To Complete This Form
To complete this form, follow these steps:

1.  Enter the **Script Name**: Provide a unique and descriptive name for the script.
2.  Enter the **Context**: Describe the context in which the script is used.
3.  Upload your **Script**: Select the script file from your device or enter the link to the script.
4.  Choose the **File Type**: Select the type of file being uploaded (Playwright, HTML, or Other).
5.  Choose the **Upload Type**: Select whether the script is being uploaded (upload) or linked (link).
6.  Add a **Description**: Briefly describe the script.
7.  Select the **Category**: Choose between QA and Engineering categories.
8.  Choose the **Status**: Set the script's status as Active, Inactive, or Pending.
9.  Optionally, add **Comments**: Add any comments or notes about the script.
10. Optionally, select the **Uploaded By** and **Review By**: Select users responsible for uploading and reviewing the script.
11. Optionally, set the **Created At**, **Updated At**, and **Deleted At** dates.
12. Finally, select whether the script was **Created By** someone or not.

## Field-by-Field Explanation

* **Script Name**: The name of the script being uploaded.
	+ Type: text input
	+ Required: Yes
* **Context**: A brief description of the context in which the script is used.
	+ Type: text input
	+ Required: Yes
* **Upload Script**: Upload your script file or enter the link to the script.
	+ Type: text input
	+ Required: Yes
* **File Type**: The type of file being uploaded (Playwright, HTML, or Other).
	+ Type: select_one
	+ Required: Yes
* **Upload Type**: Whether the script is being uploaded (upload) or linked (link).
	+ Type: select_one
	+ Required: Yes
* **Description**: A brief description of the script.
	+ Type: text input
	+ Required: Yes
* **Category**: The category of the script (QA or Engineering).
	+ Type: select_multiple
	+ Required: Yes
* **Status**: The status of the script (Active, Inactive, or Pending).
	+ Type: select_one
	+ Required: Yes
* **Comments**: Any additional comments or notes about the script.
	+ Type: text input
	+ Required: No
* **Uploaded By**: The user responsible for uploading the script.
	+ Type: select_multiple
	+ Required: No
* **Review By**: The user responsible for reviewing the script.
	+ Type: select_multiple
	+ Required: No
* **Created At**: The date the script was created.
	+ Type: date
	+ Required: No
* **Updated At**: The date the script was updated.
	+ Type: date
	+ Required: No
* **Deleted At**: The date the script was deleted.
	+ Type: date
	+ Required: No
* **Created By**: Whether the script was created by someone or not.
	+ Type: select_multiple
	+ Required: No

## Tips

* Ensure you're uploading the correct file type for your script.
* Choose the correct category for your script.
* Set the correct status for your script.
* Fill out all required fields to avoid errors.
* Use clear and concise language when describing your script and comments.
