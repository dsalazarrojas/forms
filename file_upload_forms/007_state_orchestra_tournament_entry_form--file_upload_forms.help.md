# State Orchestra Tournament Entry Form - Help Guide
## Purpose
This form is used to collect information from users for the State Orchestra Tournament entry.

## How To Complete This Form
1. Please fill out the form completely and honestly.
2. Review each field carefully to ensure you're providing accurate information.
3. If a field is marked as required, please ensure it's filled out before proceeding.
4. You can upload files in the "Upload Files" section if required.

## Field-by-Field Explanation
* **User Info** (`user_info`, `text`, required): This field is used to collect your basic information such as name and other identifying details.
* **Contact** (`contact`, `text`, required): This field is used to collect your contact information such as email and phone number.
* **Orchestra Info** (`orchestra_info`, `text`, required): This field is used to collect information about the orchestra you're entering, such as name and details about the event.
* **Upload Files** (`upload_files`, `text`, optional): This field is used to upload any relevant files or documents that may be required for the entry.
