# erp_declaration_form - Help Guide
## Purpose
The ERP Declaration Form is used to collect information related to Enterprise Resource Planning declarations. It is a critical part of our company's internal processes and helps ensure that all ERP-related activities are properly documented and accounted for.

## How To Complete This Form
To complete this form, follow these steps:

1. Review each field carefully to ensure you understand what is being asked.
2. Fill out the required fields with the requested information.
3. If you are unsure about any field, refer to the Field-by-Field Explanation section for clarification.

## Field-by-Field Explanation

* **Upload ERP declarations** (erp_declaration_form_1):
	+ Label: erp_declarations
	+ Type: Select Multiple
	+ Purpose: Select all ERP declarations that apply to your work/project.
	+ Example: If your project involves multiple ERP declarations, select all relevant options.
* **Upload file (1)** (file_upload_1):
	+ Label: upload_erp_declarations
	+ Type: Text
	+ Purpose: Upload a file related to your ERP declaration.
	+ Example: Attach a relevant document or file that supports your declaration.
* **Upload attachment (1)** (file_upload_2):
	+ Label: attachment_1
	+ Type: Text
	+ Purpose: Upload an attachment related to your ERP declaration.
	+ Example: Attach a supporting document or file that explains your declaration.
* **Upload attachment (2)** (file_upload_3):
	+ Label: attachment_2
	+ Type: Text
	+ Purpose: Upload an additional attachment related to your ERP declaration.
	+ Example: Attach another supporting document or file that explains your declaration.
* **Employee ID** (employee_id):
	+ Label: employee
	+ Type: Select One
	+ Purpose: Select your Employee ID related to the ERP declaration.
	+ Example: Enter your unique Employee ID number.
* **Date** (erp_declaration_date):
	+ Label: date
	+ Type: Date
	+ Purpose: Enter the date of the ERP declaration.
	+ Example: Enter the date when you completed the ERP declaration.
* **Time** (erp_declaration_time):
	+ Label: time
	+ Type: Time
	+ Purpose: Enter the time of the ERP declaration.
	+ Example: Enter the time when you completed the ERP declaration.
* **Notes** (notes):
	+ Label: notes
	+ Type: Note
	+ Purpose: Add any additional notes related to your ERP declaration.
	+ Example: Enter any extra information that is not covered in other fields.

## Tips
* Make sure to upload relevant files and attachments that support your ERP declaration.
* Double-check your selections and entries for accuracy.
* If you are unsure about any field, refer to the Field-by-Field Explanation section for clarification.
* Review each field carefully before submitting the form.
* If you have any issues or questions, please contact our support team for assistance.
