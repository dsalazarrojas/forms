# Digital Content Metadata Form - Help Guide
## Purpose
The Digital Content Metadata Form is a tool used to collect and manage metadata about digital content. It helps provide important information about the content, such as its category, content type, date published, and license, among other details. This form is essential for ensuring that content is accurately and consistently described, making it easier to find, categorize, and manage.

## How To Complete This Form
To fill out the Digital Content Metadata Form, follow these steps:

1. **Project Name**: Enter the title of the digital content, which can be a document, image, video, or any other type of digital content.
2. **Category**: Select the category that best describes the content. Choose from the available options to ensure you are accurately categorizing the content.
3. **Content Type**: Select the type of content you are submitting. This helps determine how the content will be processed and stored.
4. **Tags**: Enter any relevant keywords that describe the content.
5. **Date Published**: If applicable, enter the date the content was published.
6. **Date Uploaded**: Enter the date the content was uploaded to the system.
7. **Author**: Enter the author's name.
8. **Author URL**: If the author has a website or social media profile, enter their URL.
9. **Publisher**: Enter the publisher's name.
10. **Publisher URL**: If the publisher has a website or social media profile, enter their URL.
11. **Image URL**: If the content includes an image, enter the URL of the image.
12. **File Size**: Enter the size of the file in bytes.
13. **Language**: Enter the language of the content.
14. **Copyright**: Select the copyright license for the content.
15. **License**: Select the license under which the content is made available.
16. **Description**: Enter a brief description of the content.
17. **Keywords 2**: Enter any additional keywords that describe the content.
18. **Tags 2**: Enter additional tags that describe the content.
19. **Categories**: Select any additional categories that describe the content. You can choose multiple categories.
20. **Content URL**: Enter the URL of the content, if applicable.
21. **Author URL 2**: If the author has a second URL, enter it here.
22. **Publisher URL 2**: If the publisher has a second URL, enter it here.
23. **Image URL 2**: If the content includes a second image, enter the URL of the image.
24. **File Size 2**: Enter the size of the second file in bytes.
25. **Submit**: Once you have filled out all the required fields, click the "Submit" button to save your changes.
