# supplementary_information_collection_form - Help Guide
## Purpose
The supplementary_information_collection_form is used for collecting supplementary information from end-users.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the supplementary information page, which includes the case information and document uploads.
2. Select the appropriate case information from the dropdown menu.
3. Upload relevant documents from the options provided.
4. Move on to the follow-up details page.
5. Fill out the follow-up details as required.
