# obstetric_fellowship_application - Help Guide
## Purpose
The Obstetric Fellowship Application form is designed to collect information about obstetric fellowships. This form helps to gather data on various aspects of the fellowship, including its location, duration, status, and description. Fill out this form accurately to ensure that the application process is efficient and effective.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the form in the following sections:
	* Obstetric Fellowship Application
	* Obstetric Fellowship Programs
	* Obstetric Fellowship Location
	* Obstetric Fellowship Program Duration
	* Obstetric Fellowship Program Status
	* Obstetric Fellowship Start Date
	* Obstetric Fellowship End Date
	* Obstetric Fellowship Program Description
	* Obstetric Fellowship Program URL

## Field-by-Field Explanation

* **Obstetric Fellowship Application** (`1`, `text`, required: false): This field is the title of the obstetric fellowship application.
* **Obstetric Fellowship Programs** (`2`, `select_multiple`, required: false): Check the box if your obstetric fellowship program is active or not.
* **Obstetric Fellowship Location** (`3`, `text`, required: false): Enter the location where your obstetric fellowship is situated.
* **Obstetric Fellowship Program Duration** (`4`, `number`, required: false): Enter the duration of your obstetric fellowship program in months.
* **Obstetric Fellowship Program Status** (`5`, `select_one`, required: false): Select the status of your obstetric fellowship program as active or inactive.
* **Obstetric Fellowship Start Date** (`6`, `date`, required: false): Enter the start date of your obstetric fellowship.
* **Obstetric Fellowship End Date** (`7`, `date`, required: false): Enter the end date of your obstetric fellowship.
* **Obstetric Fellowship Program Description** (`8`, `text`, required: false): Enter a brief description of your obstetric fellowship program.
* **Obstetric Fellowship Program URL** (`9`, `text`, required: false): Enter the URL of your obstetric fellowship program.
