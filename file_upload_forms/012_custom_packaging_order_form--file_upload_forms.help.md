# Custom Packaging Order Form - Help Guide
## Purpose
The Custom Packaging Order Form is used to capture information for custom packaging orders.

## How To Complete This Form
- Fill out all the required fields.
- Double check that you are using the correct assigned tool.
- Review the order details for accuracy before submitting.

## Field-by-Field Explanation

* **Business Name** (`business_name`, Text, Optional): Enter your company name.
* **Contact Person** (`contact_person`, Text, Optional): Enter the name of the contact person handling this order.
* **Order Date** (`order_date`, Date, Optional): Enter the date of the order. Format should be MM/DD/YY.
* **Order Time** (`order_time`, Time, Optional): Enter the time of the order. Format should be 24-hour clock (HH:MM).
* **Business Email** (`business_email`, Email, Optional): Enter your company email address.
* **Business Phone** (`business_phone`, Text, Optional): Enter your company phone number.
* **Business Address** (`business_address`, Text, Optional): Enter your company address.
* **Shipping Address** (`shipping_address`, Text, Optional): Enter the shipping address if different from your business address.
* **Package Specs** (`package_specs`, Text, Optional): Enter any specific details about the packaging requirements.
* **Order Details** (`order_details`, Text, Optional): Enter any other details about the order.
* **Order Notes** (`order_notes`, Text, Optional): Enter any notes about the order.
* **Assigned Tool** (`assigned_tool`, Select, Optional): Select the tool assigned to process this order.
* **Form IDs** (`form_ids`, Number, Optional): Not used, please ignore.
