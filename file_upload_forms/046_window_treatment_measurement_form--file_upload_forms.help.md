# window_treatment_measurement_form - Help Guide

## Purpose
This form is designed to collect measurements and specifications for window and door treatments. It's used for both internal and external window and door measurements.

## How To Complete This Form

* Please fill out the form with the required information for each field.
* Make sure to provide accurate measurements for window and door width, height, and type.
* Choose the correct window and door type from the options provided.
* If you have any additional notes or comments, use the 'notes' field.
* If you need to attach any supporting documents, use the 'file_upload' fields.

## Field-by-Field Explanation

* **window_treatment_measurement_form_1**: Enter the title of the window treatment measurement (text, required: false)
	+ A brief name for the window treatment measurement, e.g. "Living Room Window Treatment".
* **measurement_section**: Enter the measurement section (text, required: false)
	+ A description of the measurement section, e.g. "Measure the width and height of the window".
* **window_treatment_measurement_form_2**: Enter your window measurement here (text, required: false)
	+ A detailed description of the window measurement, e.g. "Measure the window width and height including the frame".
* **window_width**: Enter the window width (number, required: false)
	+ The width of the window in inches or millimeters.
* **window_height**: Enter the window height (number, required: false)
	+ The height of the window in inches or millimeters.
* **window_type**: Select the type of window (select_one, required: false)
	+ Choose from the following options:
		- Casement window
		- Double hung window
		- Hopper window
		- Pivot window
		- Picture window
		- Single hung window
		- Slider window
* **door_height**: Enter the door height (number, required: false)
	+ The height of the door in inches or millimeters.
* **door_width**: Enter the door width (number, required: false)
	+ The width of the door in inches or millimeters.
* **door_type**: Select the type of door (select_one, required: false)
	+ Choose from the following options:
		- Pivot door
		- Sliding door
		- Swing door
		- Hinged door
* **window_treatment_type**: Select the type of window treatment (select_multiple, required: false)
	+ Choose from the following options:
		- Blinds
		- Curtains
		- Shutters
* **notes**: Enter any additional notes or comments (note, required: false)
	+ Any additional information about the measurement or treatment.
* **email**: Enter your contact email (email, required: false)
	+ Your email address for follow-up.
* **phone**: Enter your contact phone number (text, required: false)
	+ Your phone number for follow-up.
* **file_upload**: Attach any supporting documents (text, required: false)
	+ Any additional documents that may be required for the measurement or treatment.
* **file_upload_2**: Attach any additional supporting documents (text, required: false)
	+ Any additional documents that may be required for the measurement or treatment.
* **file_upload_3**: Attach any additional supporting documents (text, required: false)
	+ Any additional documents that may be required for the measurement or treatment.

## Tips
* Make sure to double-check your measurements and selections before submitting the form.
* If you're unsure about any of the fields, contact the relevant authorities for guidance.
* This form is for both internal and external window and door measurements.
