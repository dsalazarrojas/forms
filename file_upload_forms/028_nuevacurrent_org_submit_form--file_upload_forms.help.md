# nuevacurrent_org_submit_form - Help Guide
## Purpose
The "nuevacurrent_org_submit_form" is a form designed to collect information about a file submission from the NuevoCurrent organization. It is intended to capture details such as messages, file information, and categorization.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter any relevant message in the "message" field.
2. If applicable, select a file to upload and enter its details in the "file" field.
3. Choose a "category" for the submission.
4. Select "Yes" or "No" for "file_type" to indicate the type of file.
5. Provide the "author" who submitted the file.
6. Optionally, select a tool to be assigned to the submission.
7. Enter a category ID, tool ID, form ID, file type ID, and assigned user ID as numbers.
8. Once all fields are filled out, click the "submit" button to submit the form.

## Field-by-Field Explanation

* **Message** (Text, optional): Enter any relevant message or description for the submission.
* **File** (Text, optional): Select and upload a file for the submission.
* **Category** (Select multiple, optional): Choose a category for the submission.
* **File Type** (Select one, optional): Select "Yes" or "No" to indicate the type of file.
* **Author** (Text, optional): Enter the author of the submission.
* **Assigned Tool** (Text, optional): Select a tool to be assigned to the submission.
* **Category ID** (Number, optional): Enter a unique category ID for the submission.
* **Tool ID** (Number, optional): Enter a unique tool ID for the submission.
* **Form ID** (Number, optional): Enter a unique form ID for the submission.
* **File Type ID** (Number, optional): Enter a unique file type ID for the submission.
* **Assigned User** (Text, optional): Enter the user assigned to the submission.
* **Submit** (Text, optional): Click this button to submit the form after filling out all fields.
