# Image Upload For Visual Effects - Help Guide
## Purpose
This form is used to collect information and files related to a project, specifically for visual effects. It's essential to provide accurate and relevant details to ensure the project's success.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter a brief description of the project in the "Project Description" field.
2. Provide the URL or upload a reference image in the "Reference Image" field.
3. Enter the deadline date and time for the project in the "Deadline Date" and "Deadline Time" fields, respectively.
4. Select whether you need to upload multiple image files in the "Image Files" field.
5. Provide your contact information, including email, phone number, and website, in the "Contact Information" fields.
6. Add any additional notes or information in the "Additional Notes" field.
7. Upload project brief files 1 and 2 in the "Project Brief File" and "Project Brief File 2" fields, respectively.
8. Enter brief descriptions of the project 1 and 2 in the "Project Brief" and "Project Brief 2" fields, respectively.

## Field-by-Field Explanation

* **Project Description** (`Project Description`, text, required):
  Enter a brief description of the project.

* **Deadline Time** (`Deadline Time`, time, optional):
  Enter the deadline time for the project.

  Select whether you need to upload multiple image files.
* **Contact Information** (`Contact Information`, text, optional):
  Provide your contact information.
* **Contact Email** (`Contact Email`, email, optional):
  Enter your email address.
* **Contact Phone** (`Contact Phone`, text, optional):
  Enter your phone number.
* **Contact Website** (`Contact Website`, text, optional):
  Enter your website URL.
* **Contact Address** (`Contact Address`, text, optional):
  Enter your street address.
* **Additional Notes** (`Additional Notes`, note, optional):
  Add any additional notes or information.
* **Project Brief File** (`Project Brief File`, text, optional):
  Upload project brief file 1.
* **Project Brief** (`Project Brief`, text, optional):
  Enter brief description of the project 1.
* **Image Files 2** (`Image Files 2`, select multiple, optional):
  Select whether you need to upload multiple image files 2.
* **Project Brief File 2** (`Project Brief File 2`, text, optional):
  Upload project brief file 2.
* **Project Brief 2** (`Project Brief 2`, text, optional):
  Enter brief description of the project 2.
* **Image Files 3** (`Image Files 3`, select multiple, optional):
  Select whether you need to upload multiple image files 3.
* **Image Files 4** (`Image Files 4`, select multiple, optional):
