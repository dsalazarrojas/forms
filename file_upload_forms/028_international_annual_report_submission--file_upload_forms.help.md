# international_annual_report_submission - Help Guide
## Purpose
This form is used to collect information for the International Annual Report Submission.

## How To Complete This Form

- Please enter the name of the organization submitting the report.
- Select the reporting period from the options provided.
- Choose the reporting cycle from the options provided.
- Upload any relevant file attachments.
- Select any supporting documents.
- Enter the name of the person submitting the report.
- Finally, select the date of submission.

## Field-by-Field Explanation

* **organization_name (Text)**: Enter the name of the organization submitting the report.
* **reporting_period (Number)**: Select the reporting period from the options provided. This field is used to determine the time frame for which the report is being submitted.
* **reporting_date (Date)**: Enter the date on which the report is being submitted.
* **reporting_cycle (Select One)**: Choose the reporting cycle from the options provided. This field is used to determine which reporting cycle is associated with the submission.
* **file_attachments (Text)**: Upload any relevant files that support the report. This can include images, videos, or other document types.
* **supporting_documents (Text)**: Select any additional documents that support the report.
* **submitted_by (Text)**: Enter the name of the person submitting the report.
* **submitted_on (Date)**: Enter the date on which the report was submitted.

## Tips
* Make sure to upload all necessary files and supporting documents to ensure a complete submission.
* Verify the accuracy of the information entered in all fields before submission.
* If you are unsure about any field, please contact your supervisor or the IT department for assistance.
