# Digital Asset Release Form - Help Guide
## Purpose
The Digital Asset Release Form is used to release digital assets for sharing and collaboration. It gathers essential information about the asset, including its details, permissions, and status, to ensure accurate tracking and management of digital assets within the organization.

## How To Complete This Form
To complete this form, follow these steps:

1. **Upload Asset**: Enter the digital asset's name or ID.
2. **Asset Details**: Provide a brief description of the asset.
3. **Permissions**: Select the desired permissions for the asset (1, 2, or 3).
4. **Submit**: Confirm that the asset is ready for release.
5. **File Name**: Enter the name of the file containing the asset.
6. **Asset Type**: Choose the type of asset (1, 2, or 3).
7. **Asset Version**: Enter the version of the asset.
8. **Upload Date**: Select the date the asset was uploaded.
9. **Created Date**: Select the date the asset was created.
10. **Updated Date**: Select the date the asset was last updated.
11. **Asset Tags**: Select relevant tags for the asset (1, 2, or 3).
12. **Asset License**: Choose the license type for the asset (1 or 2).
13. **Asset URL**: Enter the URL of the asset.
14. **Asset Description**: Provide a brief description of the asset.
15. **File Size**: Enter the size of the file in bytes.
16. **Asset Status**: Select the status of the asset (1 or 2).
17. **Asset Notes**: Provide any additional notes about the asset.
18. **Asset Tags 2**: Select relevant tags for the asset (Yes or No).
19. **Asset License 2**: Choose the license type for the asset (Yes or No).
20. **Upload User**: Enter the user who uploaded the asset.
21. **Upload Date/Time**: Select the date and time the asset was uploaded.
22. **Created User**: Enter the user who created the asset.
23. **Updated User**: Enter the user who last updated the asset.
24. **Asset ID**: Enter the unique identifier for the asset.
25. **Asset Version 2**: Enter the version of the asset.
