# Wrestling Event Banner Selection - Help Guide
## Purpose
This form is used to gather information for wrestling event planning, focusing on banner and sponsorship details.

## How To Complete This Form
To complete this form, follow these steps:

1. Review each page carefully, ensuring that you have all the necessary information.
2. Select the relevant options for each field according to your event's specifics.
3. Provide accurate and detailed information for each field, if applicable.
4. Double-check your answers before submitting the form.

## Field-by-Field Explanation

* **banner_preferences** (`banner_preferences`, select_multiple, required: false): Select "Yes" if the event banner is needed, "No" otherwise.
* **artwork** (`artwork`, select_multiple, required: false): Select "Yes" if the event banner artwork is needed, "No" otherwise.
* **placement_details** (`placement_details`, select_multiple, required: false): Select "Yes" if the event banner placement is specific, "No" otherwise.
* **event_details** (`event_details`, select_multiple, required: false): Select "Yes" if the event has specific details, "No" otherwise.
* **signage_details** (`signage_details`, select_multiple, required: false): Select "Yes" if event signage is needed, "No" otherwise.
* **approvals** (`approvals`, select_multiple, required: false): Select "Yes" if event approvals are needed, "No" otherwise.
* **event_date** (`event_date`, date, required: false): Enter the date of the event (optional).
* **event_time** (`event_time`, time, required: false): Enter the time of the event (optional).
* **event_location** (`event_location`, select_one, required: false): Select the event location from the options provided.
* **event_type** (`event_type`, select_one, required: false): Select the type of event from the options provided.
* **file** (`file`, text, required: false): Enter any relevant file information (optional).
* **sponsor_name** (`sponsor_name`, text, required: false): Enter the sponsor's name (optional).
* **sponsor_email** (`sponsor_email`, email, required: false): Enter the sponsor's email (optional).
* **sponsor_phone** (`sponsor_phone`, text, required: false): Enter the sponsor's phone number (optional).
* **sponsor_banner** (`sponsor_banner`, text, required: false): Enter the sponsor's banner information (optional).
* **sponsor_preferences** (`sponsor_preferences`, select_multiple, required: false): Select the sponsor's preferences (optional).
* **organizer** (`organizer`, text, required: false): Enter the event organizer's name (optional).
* **notes** (`notes`, note, required: false): Add any additional event notes (optional).
* **event_notes** (`event_notes`, note, required: false): Add any event notes (optional).
* **approval_status** (`approval_status`, select_multiple, required: false): Select the approval status (optional).
* **sponsor_notes** (`sponsor_notes`, note, required: false): Add any sponsor-specific notes (optional).
* **banner_preferences_notes** (`banner_preferences_notes`, note, required: false): Add any banner preference notes (optional).
* **event_details_notes** (`event_details_notes`, note, required: false): Add any event detail-specific notes (optional).
* **signage_details_notes** (`signage_details_notes`, note, required: false): Add any signage detail-specific notes (optional).
* **approvals_notes** (`approvals_notes`, note, required: false): Add any approvals-specific notes (optional).

## Tips
- Double-check all fields for accuracy before submitting the form.
- Review and update the form regularly to ensure that it reflects the current event specifics.
- Use clear and concise language when filling out the form to avoid confusion.
