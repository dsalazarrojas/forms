# ecommerce_size_chart_extension_request_form - Help Guide
## Purpose
The ecommerce size chart extension request form is a tool for submitting size chart extension requests. It helps in gathering necessary information from users to efficiently manage and prioritize size chart updates.

## How To Complete This Form
- To complete this form, follow these steps:
  1. Fill in the required fields marked with an asterisk (*), which are:
     - Company Name
     - Size Chart Status
     - Size Chart URL (for the existing chart)
  2. Optional fields can be filled in as needed, providing more context or details about the request.
  3. Ensure the Size Chart Status is accurately selected to reflect the current state of the size chart.

## Field-by-Field Explanation

* **Company Name** (Company Name, text, required): Enter the name of your company or organization submitting the request.
* **Product URL** (Product URL, text, optional): If applicable, provide the URL of the product in question for easier reference.
* **Size Chart URL** (Size Chart URL, text, required): Enter the URL of the existing size chart for the product.
* **Size Chart File** (Size Chart File, text, optional): If a size chart file is available, you can provide it for further reference.
* **Review Comments** (Review Comments, text, optional): Add any relevant comments or feedback about the size chart in need of an update.
* **Size Chart Status** (Size Chart Status, select_one, required): Select one of the following status options:
  - Waiting: The size chart is in the waiting state.
  - In Progress: The size chart is currently under review or being updated.
  - Complete: The size chart is fully updated.
* **Review Date** (Review Date, date, optional): If known, provide the date when the size chart was last reviewed.
* **Review Time** (Review Time, time, optional): If applicable, mention the time when the size chart was last reviewed.

## Tips
- Be as specific as possible when filling in the form to ensure efficient processing of your size chart extension request.
- Use the Size Chart Status field to keep your requestor and internal teams updated on the current status.
- If you have any further questions or need assistance, please contact form@gic.mx.
