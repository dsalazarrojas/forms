# Document Editing Submission Form - Help Guide

## Purpose
The Document Editing Submission Form is used to edit and update documents submitted for review. It is essential to ensure that you understand the form's purpose and complete it accurately to avoid delays or issues in the review process.

## How To Complete This Form
To complete this form, follow these steps:

1.  Click on the "Submit Document" button to initiate the submission process.
2.  Select whether to **Submit Document** or **No** to indicate your choice.
3.  Choose the **Document Type** from the available options.
4.  Enter the **Document Title** in the provided text field.
5.  Enter a brief **Document Description** if needed.
6.  Upload files relevant to the document submission.
7.  Enter the name(s) and email address(es) of the person(s) who will review the document in the **Document Reviewer(s)** field.
8.  Select the **Document Status** from the available options.
9.  Enter the **Submission Date** and **Submission Time** using the provided date and time input fields.
10.  Optionally, add a **Submission Note** if necessary.
11.  Optionally, add a **Reviewer Note** for the reviewer's reference.

## Field-by-Field Explanation

*   **Submit Document** (`submit_document_form`, select_one, required/optional): Choose to submit or not submit the document.
    *   Select "Yes" to proceed with submission.
    *   Select "No" to cancel the submission.
*   **Document Type** (`document_type`, select_multiple, required): Choose from the available document types.
    *   Select one or more document types as applicable.
*   **Document Title** (`document_title`, text, required): Enter a short title of the document.
    *   Provide a clear and concise title for easy identification.
*   **Document Description** (`document_description`, text, optional): Enter a brief description of the document.
    *   Provide an optional description for further context.
*   **Upload Files** (`uploaded_files`, text, required): Upload relevant files for the document submission.
    *   Select and upload files related to the document.
*   **Reviewer Notes** (`reviewer_notes`, text, optional): Enter notes for the reviewer.
    *   Provide notes for the reviewer's reference, if necessary.
*   **Document Status** (`document_status`, select_one, required): Select the document status.
    *   Choose from the available options (Active, Inactive).
*   **Document Reviewers** (`document_reviewers`, email, required): Enter the name and email of the reviewer.
    *   Provide the name and email address of the reviewer(s).
*   **Submission Date** (`submission_date`, date, required): Enter the date of submission.
    *   Select the date of submission using the provided input field.
*   **Submission Time** (`submission_time`, time, required): Enter the time of submission.
    *   Select the time of submission using the provided input field.
*   **Submission Note** (`submission_note`, text, optional): Enter a note for the submission.
    *   Provide a note for the submission, if necessary.
*   **Reviewer Note** (`reviewer_note`, text, optional): Enter a note for the reviewer.
    *   Provide a note for the reviewer, if necessary.
