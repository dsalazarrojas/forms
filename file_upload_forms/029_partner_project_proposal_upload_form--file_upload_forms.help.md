# partner_project_proposal_upload_form - Help Guide
## Purpose
This form is used to collect information for a partner project proposal from a submitter.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill in the project name in the "project_name" field.
2. Select the correct project category from the dropdown menu.
3. Enter a brief description of the project in the "project_description" field.
4. If you need to upload any additional files for the project, enter the file path in the "project_file" field.
5. Select the person responsible for submitting the proposal from the "submitter_details" field.
6. Enter a valid email address for the submitter in the "submitter_email" field.
7. Enter the date by which you would like the project to be completed in the "project_deadline" field.
8. If necessary, enter the time the project should be completed in the "project_time" field.

## Field-by-Field Explanation
* **project_name** (`project_name`, text, required): Enter the name of the project.
* **project_category** (`project_category`, select_one, required): Select the correct category for the project.
* **project_description** (`project_description`, text, required): Briefly describe the project.
* **document_upload** (`document_upload`, text, optional): If you need to upload any additional files for the project, enter the file path here.
* **submitter_details** (`submitter_details`, select_multiple, optional): Select the person responsible for submitting the proposal.
* **submitter_email** (`submitter_email`, email, required): Enter a valid email address for the submitter.
* **submitter_phone** (`submitter_phone`, text, optional): Enter the submitter's phone number (if applicable).
* **project_tags** (`project_tags`, text, optional): Enter any relevant tags for the project.
* **project_deadline** (`project_deadline`, date, required): Enter the date by which you would like the project to be completed.
* **project_time** (`project_time`, time, optional): Enter the time the project should be completed (if applicable).
* **submitter_address** (`submitter_address`, text, optional): Enter the submitter's address (if applicable).
* **project_file** (`project_file`, text, optional): If you need to upload any additional files for the project, enter the file path here.
* **project_notes** (`project_notes`, text, optional): Enter any additional notes for the project.
* **submitter_notes** (`submitter_notes`, text, optional): Enter any additional notes for the submitter.
