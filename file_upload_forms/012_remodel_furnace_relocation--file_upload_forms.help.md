# Remodel Furnace Relocation - Help Guide
## Purpose
This form is used to collect information from clients for a home renovation project, specifically a "Remodel Furnace Relocation" project.

## How To Complete This Form
To complete this form, please follow these steps:

1. Upload any relevant files, such as floor plans or sketches, to help us understand your project better.
2. Schedule the renovations with us by selecting a date for the project start and end.
3. Provide your contact information so we can get in touch with you.
4. Select the area of your home that needs renovation (e.g. furnace, kitchen, bathroom, etc.).
5. Enter any additional notes or comments you may have about the project.
6. Enter your email address so we can get in touch with you.
7. Enter your phone number in case we need to contact you quickly.
8. If the client is working with a different tool (e.g. not "Chatjimmy"), select "Other" and enter the name of the tool.

## Field-by-Field Explanation

* **Upload File**: This field allows you to attach any relevant files to your project, such as floor plans or sketches.
* **Schedule Renovations**: Please select a date for when you'd like the project to start and end.
* **Upload Plans**: Similar to the "Upload File" field, this allows you to attach plans for the project.
* **Home Address**: Please enter the address of your home so we can accurately locate it.
* **Contact Info**: Please enter your contact information, including email and phone number, so we can get in touch with you.
* **Renovation Area**: Select the area of your home that needs renovation. You can choose from the following options: furnace, kitchen, bathroom, living room, basement, attic, garage, and backyard.
* **Renovation Schedule**: Please select a date for when the project start and end.
* **Notes**: Please enter any additional notes or comments you may have about the project.
* **Email**: Please enter your email address so we can get in touch with you.
* **Phone**: Enter your phone number in case we need to contact you quickly.
* **Assigned Tool**: Please select the tool that will be used for the project. If it's not "Chatjimmy", select "Other" and enter the name of the tool.
* **Other Tool**: If you selected "Other" in the "Assigned Tool" field, please enter the name of the tool that will be used for the project.
