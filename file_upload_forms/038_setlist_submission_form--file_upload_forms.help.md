# Setlist Submission Form - Help Guide
## Purpose
The Setlist Submission Form is designed to collect information about live events or setlists submitted by users. This form aims to gather essential details about the event, including event details, uploaded files, artist and venue notes, and promotional information. The form is used to collect accurate and organized data for event promotion, archiving, or other related purposes.

## How To Complete This Form
To complete the form, follow these steps:

1. Enter the event details in the `event_details` field. This field is required and should include any relevant information about the event.
2. Upload the required files by selecting them from the `files` field. You can choose up to three audio files.
3. Add any additional notes for the artist, venue, and event promoter in the `artist_submission_notes`, `venue_submission_notes`, and `event_promoter_notes` fields, respectively. These fields are not required but can be useful for additional context.
4. Select the uploaded files for the setlist submission in the `setlist_submission_form_files` field. This field is not required but can be used to include additional files.
5. Enter the date and time of the event in the `setlist_submission_date` and `setlist_submission_time` fields, respectively. These fields are required and should be entered in the correct format.

## Field-by-Field Explanation
* **event_details**: This field is required and should be used to enter the details of the event, such as the date, time, location, and other relevant information.
* **files**: This field is required and allows you to upload up to three audio files for the event.
* **artist_submission_notes**: This field is not required and can be used to add any additional notes or information about the artist performing at the event.
* **venue_submission_notes**: This field is not required and can be used to add any additional notes or information about the venue hosting the event.
* **event_promoter_notes**: This field is not required and can be used to add any additional notes or information about the event promoter.
* **setlist_submission_notes**: This field is not required and can be used to add any additional notes or information about the setlist submission.
* **setlist_submission_form_files**: This field is not required and allows you to select up to three additional audio files for the setlist submission.
* **setlist_submission_date**: This field is required and should be entered in the format `YYYY-MM-DD`.
* **setlist_submission_time**: This field is required and should be entered in the format `HH:MM:SS`.
* **setlist_submission_time**: This field is required and is a 24-hour time field.
