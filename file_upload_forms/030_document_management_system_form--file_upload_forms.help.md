# Document Management System Form - Help Guide
## Purpose
The Document Management System Form is a tool for document owners to upload and manage their documents in a systematic and organized way. This form ensures that documents are properly labeled, stored, and tracked.

## How To Complete This Form

To complete this form, follow these steps:

1. Enter the title of the document in the `Form Title` field.
2. Select the file type from the `File Type` dropdown menu.
3. Enter the file name in the `File Name` field.
4. Enter the file size in the `File Size` field.
5. Select the current status of the document from the `File Status` dropdown menu.
6. Enter the email address of the document owner in the `File Owner` field.
7. Enter the location where the file is stored in the `File Location` field.
8. Select the category of the document from the `File Category` field.
9. Enter any additional notes about the document in the `File Notes` field.
10. Enter the ID of the form in the `Form ID` field.
11. Enter the version of the form in the `Form Version` field.
12. Enter the tool assigned to the document in the `Assigned Tool` field.
13. Enter the user assigned to the document in the `Assigned User` field.
14. Enter the group assigned to the document in the `Assigned Group` field.
15. Enter the date and time the document was submitted in the `Submitted Date` and `Submitted Time` fields.
16. Enter the user who submitted the document in the `Submitted By` field.

## Field-by-Field Explanation

* **Form Title**: Enter the title of the document, which will be displayed as the title of the document.
* **File Type**: Select the type of file from the dropdown menu. Options are: Document, Image, Audio.
* **File Name**: Enter the name of the file.
* **File Size**: Enter the size of the file.
* **File Status**: Select the current status of the document from the dropdown menu. Options are: Pending, Approved, Rejected.
* **File Owner**: Enter the email address of the document owner.
* **File Location**: Enter the location where the file is stored.
* **File Category**: Select the category of the document from the dropdown menu. Options are: Marketing, Sales, Finance.
* **File Notes**: Enter any additional notes about the document.
* **Form ID**: Enter the ID of the form.
* **Form Version**: Enter the version of the form.
* **Assigned Tool**: Enter the tool assigned to the document.
* **Assigned User**: Enter the user assigned to the document.
* **Assigned Group**: Enter the group assigned to the document.
* **Submitted Date**: Enter the date the document was submitted.
* **Submitted Time**: Enter the time the document was submitted.
* **Submitted By**: Enter the user who submitted the document.

Note: The `Form Title` field is not required, but it's recommended to be filled in for better organization.
