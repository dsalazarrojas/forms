# Synthesis Document Submission Form - Help Guide
## Purpose
The Synthesis Document Submission Form is intended for users to submit their documents for synthesis, such as uploading and processing their own documents. This form allows users to upload a single synthesis document and associate it with a project ID.

## How To Complete This Form
To complete the form, follow these general steps:

1. **Fill out the required field**: The only required field is the `project_id`, which is a unique identifier for the project this document is associated with. This field is a number and must be filled out accurately.
2. **Upload your document**: Enter a title for your document in the `synthesis_document` field, and then upload the actual document file using the file upload functionality.
3. **Verify your submission**: Review your completed form to ensure all required fields are filled out accurately and the document uploaded correctly.

## Field-by-Field Explanation
* **Submitter Name**: This is the name of the person or entity submitting the document. It is an optional field, but providing this information helps the processing team identify who submitted the document.
* **Synthesis Document**: This is where you enter the title of the document you are uploading. This field is also optional, but providing a title helps the processing team understand the content of the document.
* **Project ID**: This is a unique identifier for the project this document is associated with. It is required and must be a valid number.

## Tips
* Make sure to fill out the `project_id` field accurately to ensure the document is associated with the correct project.
* Ensure the uploaded document is in a supported format (e.g. PDF, DOCX, etc.) to avoid processing delays.
* If you have any issues with the submission process, contact the processing team for assistance.
