# Marketing Campaign Asset Upload Form - Help Guide
## Purpose
The Marketing Campaign Asset Upload Form is designed to collect marketing campaign assets from users. It helps to categorize and prioritize uploaded files based on their type and campaign name.

## How To Complete This Form
To complete this form, follow these steps:

1. Ensure you have the correct type of file to upload (image, video, audio, or document).
2. Provide the campaign name associated with the uploaded file.
3. Select the type of file being uploaded (image, video, audio, or document).
4. Upload the file(s) as prompted.

## Field-by-Field Explanation

* **Campaign Name (Required)**: This field is mandatory, and it should match the name of the campaign that the uploaded file is associated with.
* **File Type (Required)**: This field allows you to select the type of file you are uploading. Choose from image, video, audio, or document.
* **File 1 (Required)**: This field is for uploading a file. Please make sure you have the correct type of file to match the selected file type above.
* **File 2 (Optional)**: This field is for uploading an additional file, if necessary. If you're not uploading a second file, you can leave this field blank.
* **File 3 (Optional)**: This field is for uploading another file, if needed. If you're not uploading a third file, you can leave this field blank.
* **Campaign Tag (Optional)**: This field allows you to add context or tags to the campaign, such as a brief description or keywords.
