# video-upload-with-subtitles - Help Guide
## Purpose
This form is designed to collect information about videos with subtitles that meet the required standards and guidelines.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the **File Upload** field with the video file you want to upload.
2. Enter the **Title** of the video in the corresponding field.
3. Select one or more **Subtitle** options that match the language of the video.
4. If applicable, fill out the **Description** field to provide more information about the video.
5. Select the **Video File** field with the video file you want to upload.
6. Select the **Subtitles File** field with the subtitles file for the video.
7. (Optional) Enter the **Start Time**, **End Time**, and **Start Date** and **End Date** fields if the video has specific time and date requirements.

## Field-by-Field Explanation
* **File Upload**: Upload the video file you want to share with others or use for educational purposes. Make sure to upload the correct file type and size.
* **Enter Title**: Enter a brief and descriptive title for the video that includes its name and a short description.
* **Select Subtitle**: Select one or more subtitles that match the language of the video. This will help others understand the video better.
* **Description**: Provide a short description of the video if you want to add more context. This is optional, but it helps to give others a better understanding of the video content.
* **Select Video File**: Select the video file you want to upload. Make sure it is in the correct format and size.
* **Select Subtitles File**: Select the subtitles file for the video. This file should match the selected subtitle language.
* **Start Time**, **End Time**, and **Start Date**, **End Date**: If the video has specific time and date requirements, fill out these fields accordingly. Otherwise, leave them empty.

## Tips
* Make sure to upload the correct file type and size for the video and subtitles.
* Select the correct subtitle language to ensure others understand the video content.
* Fill out the **Description** field if you want to provide more information about the video.
* If the video has specific time and date requirements, fill out the **Start Time**, **End Time**, **Start Date**, and **End Date** fields accurately.
