# Media Upload For Review - Help Guide
## Purpose

This form is used to upload and review media files. It is meant to be a straightforward process for users to share files and receive feedback or approval from reviewers.

## How To Complete This Form

1. Fill out the form by providing necessary information in the fields below.
2. Upload the required file in the designated file upload field.
3. Provide the project name and media information in the respective fields.
4. Once you have filled out all the required fields, click the submit button to send the form for review.

## Field-by-Field Explanation
* **File Upload** (file_upload, file, required): This field is where you will upload the media file to be reviewed. Make sure to select the correct file format and size limitations are met.
* **Project** (project, text, required): Enter a brief description of the project or context for the uploaded media file.
* **Media** (media, text, required): Provide a description of the media file, including its type, location, or any other relevant details.
* **Submit** (submit, text, required): Click this button to send the form for review. Once submitted, the form will be reviewed and feedback will be provided.

## Tips

* Make sure to upload the correct file format and size limitations before submitting the form.
* Double-check the project and media fields for accuracy and completeness.
* If you are unsure about any field or process, feel free to contact us for assistance.
