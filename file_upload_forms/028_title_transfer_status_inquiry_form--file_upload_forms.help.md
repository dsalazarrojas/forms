# Title Transfer Status Inquiry Form - Help Guide
## Purpose
The Title Transfer Status Inquiry Form is used to gather information about the current status of title transfers within an organization. This form is designed to help users track and manage title transfers efficiently.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the correct category for the title transfer from the "Category" field.
2. Enter a brief description of the title transfer in the "Description" field.
3. Assign the title transfer to a specific tool by selecting it from the "Assigned Tool" field.
4. Enter the form ID number in the "Form ID" field.
5. Enter the title of the transfer in the "Title" field.
6. Enter a description of the status of the transfer in the "Description 2" field.
7. Upload an output file related to the transfer, if applicable, in the "Output File" field.
8. Enter a category for the output file in the "Category 2" field.
9. Enter a description of the output file in the "Description 3" field.

## Field-by-Field Explanation
* **Category**: The category of the title transfer (e.g., File Upload Forms, Other).
* **Description**: Enter a brief description of the title transfer.
* **Assigned Tool**: Select the tool assigned to handle this title transfer.
* **Form ID**: Enter the form ID number for this title transfer.
* **Title**: Enter the title of the transfer.
* **Description 2**: Enter a description of the status of the transfer.
* **Output File**: Upload an output file related to the transfer, if applicable.
* **Category 2**: Enter a category for the output file.
* **Description 3**: Enter a description of the output file.
* **Form IDs**: Enter any additional form IDs related to this title transfer.
* **Description 3**: This field appears to be a duplicate of the "Description 2" field and seems to be a placeholder for further description of the status of the transfer.
