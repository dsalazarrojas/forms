# Application Amendment Form - Help Guide
## Purpose
This form is used to update or modify existing application data. It's intended to be a clear and structured way to collect the necessary information for processing the amendment request.

## How To Complete This Form

1.  Start by reviewing the original application information section, which includes the applicant's name, email address used on the application, and application ID or reference number.
2.  If necessary, select the relevant category for the amendment (e.g., Personal Contact Information, Educational History, etc.).
3.  Provide a clear reason for the amendment request, describing the changes required.
4.  Include a detailed description of the changes, ensuring accuracy and clarity.
5.  If applicable, attach new or updated supporting documentation and provide its title and description.
6.  Specify the urgency of the amendment request (Standard Processing or High Priority - Deadline Approaching).
7.  Confirm that the provided information is accurate and replaces the previous data.
8.  Provide an electronic signature (Full Name) and, if desired, a phone number for follow-up.

## Field-by-Field Explanation

*   **Applicant Full Name** (`applicant_name`, text, **Required**): Enter the applicant's full name as it appears on their application.
*   **Email Address Used on Application** (`email_on_application`, email, **Required**): Enter the email address used on the original application.
*   **Application ID or Reference Number** (`application_id`, text, **Required**): Enter the application ID or reference number.
*   **What part of your application requires an update?** (`amendment_category`, select_one, **Required**): Select the relevant category for the amendment request (e.g., Personal Contact Information, Educational History).
*   **Reason for the Amendment Request** (`reason_for_amendment`, text, **Required**): Provide a clear explanation for the amendment request, specifying the changes required.
*   **Description of Changes** (`amendment_description`, text, **Required**): Describe the changes to be made, ensuring accuracy and clarity.
*   **Title of the New Document (If Applicable)** (`new_document_title`, text, **Optional**): If attaching new or updated documentation, provide its title.
*   **Name of the Original Document to be Replaced** (`previous_document_to_replace`, text, **Optional**): If replacing an existing document, enter its name.
*   **Urgency of this Amendment Request** (`urgency_of_amendment`, select_one, **Required**): Specify the urgency of the amendment request (Standard Processing or High Priority - Deadline Approaching).
*   **I confirm that the information provided in this amendment is accurate and replaces the previous data** (`accuracy_statement`, select_one, **Required**): Confirm that the information provided is accurate and replaces the previous data.
*   **Date of Request** (`signature_date`, date, **Required**): Enter the date of the amendment request.
*   **Electronic Signature (Full Name)** (`applicant_signature_name`, text, **Required**): Provide your full name as an electronic signature.
*   **Phone Number for Follow-up (Optional)** (`contact_phone_for_followup`, text, **Optional**): If you want to be contacted for further information, provide a phone number.

## Tips

*   Make sure to review the original application information for accuracy and completeness.
*   Clearly describe the changes required for the amendment request.
*   Ensure that the attached documentation is accurate and complete.
*   Double-check your information before confirming the amendment request.
*   If you have any questions or concerns, contact the relevant authorities for assistance.
