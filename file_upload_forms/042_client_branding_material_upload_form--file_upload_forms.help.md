# Client Branding Material Upload Form - Help Guide

## Purpose
This form is used to upload client-provided branding materials for use in project development.

## How To Complete This Form

1. Ensure you have all necessary branding materials (logos, guides, etc.) ready for upload.
2. Fill out the required fields with accurate information.
3. Upload your materials to the agency's secure drive, or link to them if you're using an external link.
4. Confirm that your upload is complete and accurate.
5. Provide additional notes for the creative team if necessary.

## Field-by-Field Explanation

* **Client Name** (`client_name`, text, required): Enter your client's name as it should be displayed in our records.
* **Project Name** (`project_title`, text, required): Enter the name of the project you're uploading materials for.
* **Asset Category** (`asset_category`, select_one, required): Select the category of materials you're uploading (e.g. Final Logo Package, Style Guide, etc.).
* **Are logos provided in vector format (AI/EPS/SVG)?** (`file_format_check`, select_one, required): Choose if your logos are in vector format, raster only, or not applicable.
* **Are color codes (HEX/RGB/CMYK) included?** (`color_profile`, select_one, required): Indicate if color codes are included with the uploaded materials.
* **I authorize the agency to use these assets for the current project** (`usage_authorization`, select_one, required): Confirm that you've given the agency permission to use these assets.
* **Are any assets subject to 3rd party licensing?** (`third_party_licensing`, select_one, required): Check if any assets are subject to 3rd party licensing (e.g. stock photos).
* **Date of Submission** (`submission_date`, date, required): Enter the date of your submission.
* **Email for verification** (`contact_email`, email, required): Provide a contact email for verification purposes.
* **Additional Notes for the Creative Team** (`additional_notes`, text, optional): Leave any additional information or notes for the creative team.
* **Confirmation of Upload** (`upload_confirmation`, select_one, required): Confirm that you've uploaded the materials successfully.
* **Link to Assets (if not using direct upload)** (`drive_link`, text, optional): Provide a link to the uploaded materials if not using direct upload.

Please review your submissions carefully to ensure accuracy and completeness. If you have any doubts, don't hesitate to reach out to your project manager for further clarification.
