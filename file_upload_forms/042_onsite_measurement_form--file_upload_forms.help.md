# onsite_measurement_form - Help Guide
## Purpose
The onsite measurement form is used to upload files and pictures associated with measurements.

## How To Complete This Form
1. Click on the "Upload files and pictures" tab to access the first page of the form.
2. On this page, select "Yes" if you have files to upload or "No" if you do not.
3. If you have selected "Yes," proceed to the second page.
4. Add any relevant notes or explanations in the "Onsite Measurement Form 2" page.

## Field-by-Field Explanation

* **File Uploads** (`File Uploads`, `select_multiple`, required: false): 
  Select "Yes" if you have files to upload related to the measurement, and "No" otherwise. This field helps us understand whether you need to upload additional files for this measurement.
* **measurement_pictures** (`measurement_pictures`, `text`, required: false): 
  This field is currently not used. If you need to add pictures related to the measurement, please use the "File Uploads" field.
* **Onsite Measurement Form 2** (`Onsite Measurement Form 2`, `note`, required: false): 
  Please add any relevant notes or explanations related to the measurement. This field can be used to provide further details about the measurement.
* **upload_file** (`upload_file`, `text`, required: false): 
  This field is currently not used. You can disregard this field for now.
* **Yes/No** (`Yes/No`, `select_multiple`, required: false): 
  Select "Yes" if you have files to upload or "No" if you do not have any files.
