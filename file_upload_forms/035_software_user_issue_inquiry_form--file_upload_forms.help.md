# software_user_issue_inquiry_form - Help Guide
## Purpose
The software_user_issue_inquiry_form is a tool used to collect detailed information from software users regarding issues they are experiencing with the software. This form is intended for users to provide a clear and concise description of the problem they are facing, allowing the support team to better understand and assist with the issue.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter your name and surname in the "First Name" and "Last Name" fields.
2. Select the type of issue you are experiencing by choosing from the options provided in the "Issue Type" field.
3. In the "Issue Description" field, briefly describe the issue you are experiencing. This should include as much detail as possible so that the support team can understand the problem clearly.
4. If applicable, provide a screenshot of the issue by uploading a file in the "Screenshot of Issue" field.
5. If applicable, provide any attachments related to the issue by uploading a file in the "Attachment" field.
6. Enter the date you first reported the issue in the "Issue Reported At" field.
7. If you have already been assisted by the support team, enter the date and time you were last updated by them in the "Issue Triage" field.
8. Select the priority of the issue by choosing from the options provided in the "Issue Priority" field.
9. Finally, select the current status of the issue by choosing from the options provided in the "Issue Status" field.

## Field-by-Field Explanation

* **First Name** (text): Enter your first name for reference purposes.
* **Last Name** (text): Enter your last name for reference purposes.
* **Issue Type** (select one): Choose the type of issue you are experiencing. Options include:
	+ Software Bug: A problem with the software's functionality or performance.
	+ Software Issue: A general problem with the software, but not necessarily a bug.
	+ Other: If the issue does not fit into one of the above categories.
* **Issue Description** (text): Describe the issue you are experiencing in as much detail as possible.
* **Screenshot of Issue** (text): If applicable, upload a screenshot of the issue.
* **Attachment** (text): If applicable, upload any attachments related to the issue.
* **Issue Reported At** (date): Enter the date you first reported the issue.
* **Issue Triage** (time): If you have already been assisted by the support team, enter the date and time you were last updated by them.
* **Issue Priority** (select one): Choose the priority of the issue:
	+ High: Critical issues that require immediate attention.
	+ Medium: Issues that require attention, but are not critical.
	+ Low: Non-essential issues that can be addressed later.
* **Issue Status** (select one): Choose the current status of the issue:
	+ Open: The issue is still open and not resolved.
	+ Resolved: The issue has been resolved.
	+ Closed: The issue is no longer active and will not be addressed further.
