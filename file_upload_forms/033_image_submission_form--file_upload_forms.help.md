## image_submission_form - Help Guide

## Purpose
The image_submission_form is a tool for uploading and submitting images. This form is designed to collect basic information about an image, such as its title, upload description, and the actual image file. It is intended for various use cases where images need to be uploaded and recorded.

## How To Complete This Form

To complete the image_submission_form, follow these steps:

1. Fill in the `base_form_data` field with a brief description of the image. This field is not required, but it will help us understand the context of the image.
2. In the `upload` field, provide the title of the image, as it will be displayed alongside the image.
3. In the `file` field, upload the actual image file. Please ensure the file is in a supported format, such as JPEG, PNG, GIF, or others.

## Field-by-Field Explanation

* **base_form_data**: (text, optional) Brief description of the image. This field is not mandatory, but it helps us understand the context of the image.
* **upload**: (text, optional) Title of the image, which will be displayed alongside the image.
* **file**: (file, required) Upload the actual image file. Ensure it is in a supported format (e.g., JPEG, PNG, GIF, etc.).

## Tips

* Make sure to upload a high-quality image that meets the supported formats.
* Use a brief and concise description in the `base_form_data` field to help us understand the image context.
* Ensure the `title` in the `upload` field is clear and descriptive.
* If you need help or have further questions, contact form@gic.mx.
