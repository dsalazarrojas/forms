# dropbox_incident_report_upload_form - Help Guide
## Purpose
The purpose of this form is to gather detailed information about an incident that occurred on the premises of a Dropbox employee or in a Dropbox-managed environment. This information will be used to improve incident response processes and ensure that we can learn from any future incidents.

## How To Complete This Form
- Please fill out the form completely and accurately, including all required fields (marked with `*`).
- Make sure to provide as much detail as possible about the incident, its cause, resolution, and outcome.
- If you are reporting an incident that has not yet been resolved, complete the form up to the point of the incident.
- If you are unsure about any field, refer to the Field-by-Field Explanation section below.

## Field-by-Field Explanation
- **Form Header** (`form_header`, `text`, optional): This is the header of the form where you can enter any relevant text, such as the incident ID number or any other identifier.
- **Form Title** (`form_title`, `text`, optional): Enter a brief title for the incident report.
- **Form Description** (`form_description`, `text`, optional): Provide a short description of the incident.
- **Incident Date** (`incident_date`, `date`, required): Enter the date the incident occurred.
- **Incident Time** (`incident_time`, `time`, required): Enter the time the incident occurred.
- **Incident Location** (`incident_location`, `text`, required): Enter the location of the incident, including the floor or department affected.
- **Incident Description** (`incident_description`, `text`, optional): Provide a detailed description of what happened.
- **Incident Cause** (`incident_cause`, `text`, optional): Try to identify the root cause of the incident, if known.
- **Incident Resolution** (`incident_resolution`, `text`, optional): Describe how the incident was resolved, if applicable.
- **Incident Outcome** (`incident_outcome`, `text`, optional): Report any changes or updates resulting from the incident.
- **Incident Actions** (`incident_actions`, `text`, optional): List any actions taken as a result of the incident.
- **Form Footer** (`form_footer`, `text`, optional): Enter any final comments or notes about the incident.

## Tips
- Make sure to proofread your submission for accuracy before submitting it.
- If you have any questions or concerns, contact your local Dropbox representative.
- For ongoing or current incidents, please report them to your local Dropbox incident response team.
