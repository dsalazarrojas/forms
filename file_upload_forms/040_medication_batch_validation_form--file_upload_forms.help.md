# medication_batch_validation_form - Help Guide
## Purpose
This form is used for validating medication batches.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the batch number in the "Batch number" field.
2. Enter the medication batch ID in the "Medication batch ID" field.
3. Enter the batch size in the "Batch size" field.
4. Enter the start date in the "Start date" field.
5. Enter the finish date in the "Finish date" field.
6. Select the batch status from the dropdown menu in the "Batch status" field.
7. Select the contact person from the dropdown menu in the "Contact person" field.
8. Enter any additional notes in the "Additional notes" field.

## Field-by-Field Explanation

* **Batch number** (`batch_number`, number, required): Enter the batch number of the medication batch.
* **Medication batch ID** (`medication_batch_id`, number, required): Enter the ID of the medication batch.
* **Batch size** (`batch_size`, number, required): Enter the number of units or quantity of the medication batch.
* **Start date** (`start_date`, date, required): Enter the start date of the medication batch.
* **Finish date** (`finish_date`, date, required): Enter the finish date of the medication batch.
* **Batch status** (`batch_status`, select_one, required): Select the status of the batch from the dropdown menu.
* **Contact person** (`contact_person`, select_multiple, required): Select one or more contact persons responsible for the batch.
* **Additional notes** (`form_info_11`, note, required): Enter any additional notes about the medication batch.

## Tips
* Make sure to enter accurate and relevant information to ensure the medication batch is correctly validated.
* Double-check the form for any missing or required fields before submission.
* If you need assistance, contact the help desk.
