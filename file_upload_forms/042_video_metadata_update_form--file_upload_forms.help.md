# Video Metadata Update Form - Help Guide
## Purpose
The Video Metadata Update Form is used to update information associated with a video, such as its title, description, tags, and upload details.

## How To Complete This Form
1. Enter the video ID in the "video-id" field. This is the unique identifier for the video you want to update.
2. Fill in any of the fields you want to update:
	* "video-title": Enter the new title for the video.
	* "video-description": Enter the new description for the video.
	* "video-tags": Select the tags you want to associate with the video.
	* "video-date-uploaded", "video-date-modified": Enter the dates the video was uploaded and modified.
	* "new-video-title", "new-video-description", "new-video-tags", "new-video-date-uploaded", "new-video-date-modified": Enter new information for the video.
3. Enter the "video-upload-url", "video-thumbnail-url", "video-upload-username", and "video-upload-password" fields if you are uploading a new video or updating existing upload information.
4. Click the "Submit" button to save your changes.

## Field-by-Field Explanation

* **video-id** (`video-id`, number, required): Enter the unique identifier for the video you want to update.
* **video-title** (`video-title`, text, optional): Enter the new title for the video.
* **video-description** (`video-description`, text, optional): Enter the new description for the video.
* **video-tags** (`video-tags`, select multiple, optional): Select the tags you want to associate with the video.
* **video-date-uploaded** (`video-date-uploaded`, date, optional): Enter the date the video was uploaded.
* **video-date-modified** (`video-date-modified`, date, optional): Enter the date the video was modified.
* **new-video-title** (`new-video-title`, text, optional): Enter the new title for the video.
* **new-video-description** (`new-video-description`, text, optional): Enter the new description for the video.
* **new-video-tags** (`new-video-tags`, select multiple, optional): Select the new tags for the video.
* **new-video-date-uploaded** (`new-video-date-uploaded`, date, optional): Enter the new upload date for the video.
* **new-video-date-modified** (`new-video-date-modified`, date, optional): Enter the new modified date for the video.
* **video-upload-url** (`video-upload-url`, text, optional): Enter the URL for the video upload.
* **video-thumbnail-url** (`video-thumbnail-url`, text, optional): Enter the URL for the video thumbnail.
* **video-upload-username** (`video-upload-username`, text, optional): Enter the username for the video upload.
* **video-upload-password** (`video-upload-password`, text, optional): Enter the password for the video upload.
* **video-thumbnail-caption** (`video-thumbnail-caption`, text, optional): Enter a caption for the video thumbnail.
* **video-thumbnail-username** (`video-thumbnail-username`, text, optional): Enter the username for the video thumbnail.
* **video-upload-username** (`video-upload-username`, text, optional): Enter the username for the video upload.
* **video-upload-password** (`video-upload-password`, text, optional): Enter the password for the video upload.
