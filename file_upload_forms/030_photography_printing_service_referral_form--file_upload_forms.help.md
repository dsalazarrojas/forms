# Photography Printing Service Referral Form - Help Guide
## Purpose
This form is designed to capture referrals for the photography printing service. Referrals can be from customers, colleagues, or friends who have recommended our services.

## How To Complete This Form
To complete this form, follow these steps:

* Please ensure that you have a valid reason for referral.
* Fill in the required fields as much as possible.
* If you're unsure about any field, feel free to contact our support team for assistance.

## Field-by-Field Explanation

* **Photography Printing Service**: This field is not required. You can enter a brief description of the photography printing service you're referring.
* **Contact**: Please enter the contact information of the person making the referral. This can include name, phone number, and email.
* **Referral Source**: This field is not required, but if you are referring from a known source (e.g., a friend or colleague), select "Yes" to indicate this.
* **Phone**: Enter the phone number of the person making the referral.
* **Email**: Enter the email address of the person making the referral.
* **Message**: Enter any additional message or information you would like to provide about the referral.
* **Photo**: Please enter the name or description of the photo to be printed.
* **File**: This field is not required, but if you would like to attach a file (e.g., photo), upload it here.
* **Date**: Enter the date you would like the printing service to be performed.
* **Time**: Enter the time you would like the printing service to be performed. 

Note: Please ensure that all fields that have a "required" property set to true in the form schema are filled in as much as possible.
