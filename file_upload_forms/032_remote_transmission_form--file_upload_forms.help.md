# Remote Transmission Form - Help Guide
## Purpose
The Remote Transmission Form is designed to collect information related to remote transmission. This form helps us gather data that will help us improve our services.

## How To Complete This Form
- To submit this form, simply fill out the required fields as instructed below.

## Field-by-Field Explanation
- **Title** (`remote_transmission_form`, Text, Required: False): Enter a title for your transmission. This will help us identify your submission.
- **Input** (`remote_transmission_form_input`, Text, Required: False): Enter any additional information that is relevant to your transmission. This field is free-text and can be used for any additional comments.
- **File Input** (`remote_transmission_form_file_input`, Text, Required: False): Upload any files associated with your transmission. This field accepts text-based file uploads.
- **Transmission Status** (`remote_transmission_form_checkbox`, Select Multiple, Required: False): Check if this transmission is a test or production transmission.
- **Email** (`remote_transmission_form_email`, Email, Required: False): Enter your email address for any communication purposes.
- **Phone** (`remote_transmission_form_phone`, Text, Required: False): Enter your phone number for any follow-up communication.
- **Select One** (`remote_transmission_form_select_one`, Select One, Required: False): Select either Yes or No for any specific criteria related to the transmission.
- **Select Multiple** (`remote_transmission_form_select_multiple`, Select Multiple, Required: False): Select all applicable options that apply to your transmission.
- **Date** (`remote_transmission_form_date`, Date, Required: False): Select a date for the transmission.
- **Time** (`remote_transmission_form_time`, Time, Required: False): Select a time for the transmission.
- **Note** (`remote_transmission_form_note`, Text, Required: False): Enter any additional notes about the transmission.
- **Capture** (`remote_transmission_form_capture`, Text, Required: False): Enter any relevant details about the transmission.

# Tips
- Fill out all required fields carefully and accurately.
- Upload any relevant files for further reference.
- Double check your submission for errors before submitting.
