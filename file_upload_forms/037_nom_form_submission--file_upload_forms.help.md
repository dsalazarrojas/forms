# NOM Form Submission - Help Guide
## Purpose
The "NOM Form Submission" is a comprehensive form designed to capture details about file uploads, including metadata about the files and information about the submitters. This form is intended to gather information for administrative or regulatory purposes.

## How To Complete This Form
To complete this form, follow these steps:

1. Review the form sections carefully to understand what information is required for each field.
2. For each file, enter the file name and size.
3. Select the type of file from the provided options.
4. Enter your contact information, including email, phone number, name, address, and message.
5. Select your role and designation, as applicable.
6. Enter any additional information as required.
7. Submit the form once you have completed all the necessary fields.

## Field-by-Field Explanation
### File 1
* **File 1** (`file_upload_1`, `text`, required: false): Enter the name of the first file being uploaded.
* **File 1 Name** (`file_name_1`, `text`, required: false): Enter a description or label for the first file.
* **File 1 Size** (`file_size_1`, `number`, required: false): Enter the size of the first file in the required unit (e.g., bytes, KB, MB).
* **File 1 Type** (`file_type_1`, `select_one`, required: false): Select the type of file from the provided options.
### File 2
* **File 2** (`file_upload_2`, `text`, required: false): Enter the name of the second file being uploaded.
* **File 2 Name** (`file_name_2`, `text`, required: false): Enter a description or label for the second file.
* **File 2 Size** (`file_size_2`, `number`, required: false): Enter the size of the second file in the required unit (e.g., bytes, KB, MB).
* **File 2 Type** (`file_type_2`, `select_one`, required: false): Select the type of file from the provided options.
### Additional Information
* **Description** (`description`, `text`, required: false): Enter any additional information about the files being uploaded.
* **Upload Date** (`upload_date`, `date`, required: false): Enter the date you uploaded the files.
* **Upload Time** (`upload_time`, `time`, required: false): Enter the time you uploaded the files.
* **Submitter Email** (`submitter_email`, `email`, required: false): Enter your email address.
* **Submitter Phone** (`submitter_phone`, `text`, required: false): Enter your phone number.
* **Submitter Name** (`submitter_name`, `text`, required: false): Enter your name.
* **Submitter Address** (`submitter_address`, `text`, required: false): Enter your address.
* **Submitter Message** (`submitter_message`, `text`, required: false): Enter any additional message or information about the submission.
* **Organization** (`organization`, `text`, required: false): Enter the name of the organization you represent.
* **Department** (`department`, `text`, required: false): Enter the department you belong to.
* **Role** (`role`, `text`, required: false): Enter your role or position.
* **Submitter ID** (`submitter_id`, `text`, required: false): Enter your ID number or employee number.
* **Submitter Type** (`submitter_type`, `select_one`, required: false): Select your type from the provided options.
* **Designation** (`submitter_designation`, `select_one`, required: false): Select your designation from the provided options.
* **Position** (`submitter_position`, `text`, required: false): Enter your position or title.
* **Submitter Department** (`submitter_department`, `text`, required: false): Enter the department you belong to.
* **Submitter Designation 2** (`submitter_designation_2`, `select_one`, required: false): Select your second designation from the provided options.
