# Social Security Fraud Report Form - Help Guide
## Purpose
The Social Security Fraud Report Form is a tool used to report suspected or known Social Security number misuse. This form is designed to gather information from users who suspect or know that someone is misusing a Social Security number.

## How To Complete This Form

To complete this form, follow these steps:

1. Fill in the required fields with accurate and detailed information.
2. If you are reporting for someone else, ensure you have their permission or authority to report on their behalf.
3. If you have multiple instances of Social Security number misuse, submit a separate report for each instance.

## Field-by-Field Explanation

* **user_info** (Text, required): Enter your name and contact information.
* **report_type** (Select One, required): Choose the type of report you are submitting. Please select "Report a suspected Social Security number misuse" or "Report a known Social Security number misuse."
* **ssn** (Text, required): Enter the Social Security number you are reporting.
* **report_details** (Text, required): Provide a detailed description of what you are reporting. Please include as much information as possible, including dates, times, and any other relevant details.
* **file_uploads** (Text, optional): If you have supporting documents or files that can aid in the investigation, please upload them here.
* **email** (Email, required): Enter your email address so we can follow up with you.
* **phone** (Text, optional): Enter your phone number so we can contact you if needed.
* **date** (Date, required): Enter the date of the suspected or known Social Security number misuse.
* **follow_up_email** (Email, optional): Enter the email address of the person who is misusing the Social Security number (if different from your own).
* **follow_up_phone** (Text, optional): Enter the phone number of the person who is misusing the Social Security number (if different from your own).

## Tips
* Please be as detailed as possible when providing information in the **report_details** field.
* If you are unsure about any of the fields, please contact us for assistance.
* We will follow up with you to ensure we have all necessary information before taking action.
* If you are reporting multiple instances of Social Security number misuse, please submit a separate report for each instance.
