# Seal Intake Inspection Form - Help Guide
## Purpose
The Seal Intake Inspection Form is used to assess the condition of a seal and determine its status for further processing or action.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter your response in the first field, "Seal Intake Form".
2. Select the condition of the seal from the options provided in the "Seal Condition" field.
3. If applicable, provide a description of your findings in the "Condition Check 1" field.
4. Add any additional notes or comments in the "Notes" field.

## Field-by-Field Explanation
* **Seal Intake Form** (`seal_intake_form`, text, required: false): Enter a brief description of the seal in question.
* **Seal Condition** (`seal_condition`, select_one, required: false): Select the condition of the seal from the options provided:
	+ Excellent
	+ Good
	+ Fair
	+ Poor
* **Condition Check 1** (`condition_check_1`, text, required: false): Provide a description of any condition checks performed on the seal.
* **Notes** (`notes`, text, required: false): Add any additional notes or comments about the seal's condition.
