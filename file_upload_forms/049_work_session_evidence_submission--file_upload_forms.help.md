# Work Session Evidence Submission - Help Guide

## Purpose
The Work Session Evidence Submission form is used to record and document the details of work sessions, including the date, time, location, and outcome of the session. This form helps to maintain a clear and accurate record of all work sessions.

## How To Complete This Form
To complete this form, follow these steps:

1. Ensure you are submitting new evidence for a work session that has not been previously submitted.
2. Fill in the required fields (Session Date, Session Time, Session Location, Session Outcome, and File Evidence) as accurately as possible.
3. If you have any additional information or notes about the session, add them to the Session Outcome Notes field.
4. Attach any relevant file evidence to support your submission.

## Field-by-Field Explanation

* **Session Date** (session_date, date, required): Enter the date of the work session in the format dd/mm/yyyy.
* **Session Time** (session_time, time, required): Enter the time of the work session in the format 24-hour time (HH:MM).
* **Session Location** (session_location, text, required): Enter a clear and concise description of the location where the work session took place.
* **Session Outcome** (session_outcome, select_one, required): Choose the outcome of the work session from the options:
	+ Positive: Session was successful and met the objectives.
	+ Negative: Session was unsuccessful and did not meet the objectives.
	+ Cancelled: Session was cancelled or not completed.
* **File Evidence** (file_evidence, text, required): Attach a file that provides supporting evidence for the session, such as a photo, video, or document.
* **Session Outcome Notes** (session_outcome_notes, text, optional): Enter any additional notes or details about the session outcome.
* **Notes** (notes, text, optional): Enter any additional information or comments about the session that may be helpful for reference.
