# yacht_docking_reservation_form - Help Guide
## Purpose
This form is used to make a yacht docking reservation. It gathers information about the user, their boat, and the docking details.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter your name, email, and phone number in the respective fields.
2. Select your preferred marina from the dropdown menu.
3. Select your boat type from the dropdown menu.
4. Choose a docking date and time.
5. Choose a departure date and time.
6. Select whether you need a slip size.
7. If necessary, enter your reservation ID.
8. Provide additional comments about your reservation.
9. Upload a file if required.
10. Select the type of file you are uploading.

## Field-by-Field Explanation

* **User Name** (text, required): Enter your name.
* **Email** (email, required): Enter your email address.
* **Phone** (text, required): Enter your phone number.
* **Marina** (select_one, required): Select the marina where you want to dock your boat. You can choose from the options provided.
* **Boat Type** (select_one, required): Select the type of boat you have. You can choose from the options provided.
* **Docking Date** (date, required): Select the date you want to dock your boat.
* **Docking Time** (time, required): Select the time you want to dock your boat.
* **Departure Date** (date, required): Select the date you want to depart from the marina.
* **Departure Time** (time, required): Select the time you want to depart from the marina.
* **Slip Size** (select_one, optional): Select whether you need a slip size or not. This is only necessary if you have a specific requirement.
* **Reservation ID** (text, optional): Enter your reservation ID if you have one.
* **Comments** (note, optional): Provide any additional comments about your reservation.
* **File** (text, required): Upload any file required for your reservation.
* **Uploaded Files** (text, optional): You can upload multiple files if necessary.
* **Uploaded File Type** (select_one, required): Select the type of file you are uploading (Image or Document).
