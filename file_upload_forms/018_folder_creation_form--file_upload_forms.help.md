# Folder Creation Form - Help Guide
## Purpose
The Folder Creation Form is used to create new folders, allowing users to organize and categorize their files and data. This form gathers essential information about the folder, including its name, description, type, status, and other relevant details.

## How To Complete This Form
To complete this form, follow these steps:

1.  Enter the **Folder Name** in the text field. This is a required field, and the folder name is used to identify the folder. It should be a unique and descriptive name.
2.  Provide a brief **Folder Description** in the text field below. This field is optional, and it's meant to describe the folder's purpose or content.
3.  Select the **Folder Type** from the drop-down menu. This determines the category or classification of the folder.
4.  Choose the **Folder Status** by selecting one or more options from the list. This indicates the current status of the folder.
5.  Enter the **Created Date** and **Created Time** using the date and time pickers. These fields are optional and are used to record the date and time the folder was created.
6.  Select the **Folder Parent** from the drop-down menu, if applicable. This is the parent folder of the new folder.
7.  Choose the **Folder Children** by selecting multiple options from the list. This indicates the folders that belong to the new folder.
8.  Enter the **Folder Location** using a numeric value. This is an optional field and can be used to store the location of the folder.
9.  Add any **Folder Notes** in the text area. This field is optional and provides additional information about the folder.

## Field-by-Field Explanation
*   **Folder Name**: This is the title of the folder. It should be unique and descriptive.
*   **Folder Description**: This is a brief description of the folder's purpose or content.
*   **Folder Type**: This determines the category or classification of the folder.
*   **Folder Status**: This indicates the current status of the folder.
*   **Created Date**: This records the date the folder was created.
*   **Created Time**: This records the time the folder was created.
*   **Folder Parent**: This is the parent folder of the new folder.
*   **Folder Children**: These are the folders that belong to the new folder.
*   **Folder Location**: This stores the location of the folder.
*   **Folder Notes**: This provides additional information about the folder.
