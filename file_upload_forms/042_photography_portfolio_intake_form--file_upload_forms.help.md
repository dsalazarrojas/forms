# Photography Portfolio Intake Form - Help Guide
## Purpose
The Photography Portfolio Intake Form is used to collect information about a photography portfolio project. This includes project details, contact information, and file attachments.

## How To Complete This Form

To complete this form, follow these steps:

1. Enter the **Project Name** of the project you want to add to the portfolio.
2. Provide a **Project Description** that summarizes the project.
3. Select the desired **Style Preferences** for the project (Landscape, Portrait, or Still Life).
4. Enter the **Project URL** if there is a website associated with the project.
5. Enter your **Contact Info**, including your **Name**, **Email**, and **Phone**.
6. Upload **Project Files** that are relevant to the project (up to 3 files).
7. Select the **File Type** for each attached file (JPEG, PNG, or SVG).
8. Enter a **File Description** for each attached file.
9. Enter the **Project Date** and **Project Time** for the project.
10. Select the **Project Type** for the project (Wedding, Commercial, or Editorial).
11. Enter the **Project Address**, **Project City**, and **Project Zip**, and **Project Country** for the project location.
12. Enter the **Note** and **Style Note** for the project.

## Field-by-Field Explanation

* **Project Name**: Enter a brief name for the project.
* **Project Description**: Enter a brief description of the project.
* **Style Preferences**: Select one or more styles that are relevant to the project (Landscape, Portrait, or Still Life).
* **Project URL**: Enter the URL of a website associated with the project.
* **Contact Info**:
	+ **Name**: Enter your name as the contact person for the project.
	+ **Email**: Enter your email address.
	+ **Phone**: Enter your phone number.
* **Project Files**: Attach up to 3 relevant files related to the project.
* **File Type**: Select the type of file (JPEG, PNG, or SVG) for each attached file.
* **File Description**: Enter a brief description of each attached file.
* **Project Date**: Enter the date of the project.
* **Project Time**: Enter the time of the project.
* **Project Type**: Select the type of project (Wedding, Commercial, or Editorial).
* **Project Address**: Enter the address of the project location.
* **Project City**: Enter the city of the project location.
* **Project Zip**: Enter the zip code of the project location.
* **Project Country**: Enter the country of the project location.
* **Note**: Enter any additional notes about the project.
* **Style Note**: Enter any additional notes about the project style.
* **Project Address**: Enter the address of the project location.
* **Contact Name**: Enter your name as the contact person.
* **Contact Phone**: Enter your phone number.
* **Contact Email**: Enter your email address.

Please note that some fields are required and some are optional. Please fill out the required fields completely and accurately to ensure that your project is properly documented in the portfolio.
