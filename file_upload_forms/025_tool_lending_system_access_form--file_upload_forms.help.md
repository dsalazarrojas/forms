# Tool Lending System Access Form - Help Guide
## Purpose
This form is used to request access to the Tool Lending System.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter your User Name in the "User Name" field.
2. Provide your Organization's name in the "Organization" field.
3. Enter your Email address in the "Email" field.
4. Enter your contact phone number in the "Contact Phone" field.
5. Specify the Tool that you are requesting access to in the "Assigned Tool" field.
6. Select the Tool Type (Hand Tool, Machine Tool, or Equipment) in the "Tool Type" field.
7. Specify the location of the Tool in the "Tool Location" field.
8. Select the User Agreement checkboxes that apply to your situation.
9. Enter the date you plan to start using the Tool in the "Tool Lending Start Date" field.
10. Enter the date you plan to return the Tool in the "Tool Lending End Date" field.
11. Enter the date you plan to return the Tool in the "Tool Return Date" field.
12. Select the Tool Status (Available, In Use, Lended, or Returned) in the "Tool Status" field.
13. If desired, add any additional information about the Tool in the "Tool Notes" field.
14. If desired, update the Tool Status in the "Tool Status Update" field.
15. If desired, add any additional information about the Tool's condition in the "Tool Condition" field.
16. If desired, add any additional information about the Tool's serial number in the "Tool Serial Number" field.
17. If desired, add any additional information about the Tool's model number in the "Tool Model Number" field.
18. If desired, add any additional information about the Tool's manufacturer in the "Tool Manufacturer" field.
19. If desired, enter the date the Tool was purchased in the "Tool Purchase Date" field.
20. If desired, enter the date the Tool's warranty started in the "Tool Warranty Start Date" field.
21. If desired, enter the date the Tool's warranty will end in the "Tool Warranty End Date" field.

## Field-by-Field Explanation

* **User Name** (1, text, required): Enter your User Name to identify yourself.
* **Organization** (2, text, required): Enter your Organization's name to associate with your request.
* **Email** (3, email, required): Enter your Email address for communication purposes.
* **Contact Phone** (4, text, required): Enter your contact phone number for contactability.
* **Assigned Tool** (5, text, required): Specify the Tool you are requesting access to.
* **Tool Type** (6, select_one, required): Select the Tool Type (Hand Tool, Machine Tool, or Equipment) to categorize the Tool.
* **Tool Location** (7, text, required): Specify the location of the Tool.
* **User Agreement** (8, select_multiple, required): Select the User Agreement checkboxes that apply to your situation.
* **Tool Lending Start Date** (9, date, required): Enter the date you plan to start using the Tool.
* **Tool Lending End Date** (10, date, required): Enter the date you plan to return the Tool.
* **Tool Return Date** (11, date, required): Enter the date you plan to return the Tool.
* **Tool Status** (12, select_one, required): Select the Tool Status (Available, In Use, Lended, or Returned) to categorize the Tool.
* **Tool Note** (13, note, optional): Add any additional information about the Tool if desired.
* **Organization ID** (14, text, optional): If desired, add any additional information about your Organization.
* **Assigned User** (15, text, optional): If desired, add any additional information about the assigned user.
* **Tool Status Update** (16, text, optional): If desired, update the Tool Status.
* **Tool Condition** (17, text, optional): If desired, add any additional information about the Tool's condition.
* **Tool Serial Number** (18, text, optional): If desired, add any additional information about the Tool's serial number.
* **Tool Model Number** (19, text, optional): If desired, add any additional information about the Tool's model number.
* **Tool Manufacturer** (20, text, optional): If desired, add any additional information about the Tool's manufacturer.
* **Tool Purchase Date** (21, date, optional): If desired, enter the date the Tool was purchased.
* **Tool Warranty Start Date** (22, date, optional): If desired, enter the date the Tool's warranty started.
* **Tool Warranty End Date** (23, date, optional): If desired, enter the date the Tool's warranty will end.
* **Tool Notes** (24, note, optional): If desired, add any additional information about the Tool.
* **Assigned Tool Status Update** (25, text, optional): If desired, update the Tool Status.

## Tips

* Ensure that you provide accurate and complete information to ensure efficient handling of your request.
* Review the form carefully before submitting to avoid errors.
* If you have any questions or concerns, please contact us for assistance.
