# Educator Course Material Upload Form - Help Guide

## Purpose

## How To Complete This Form

1. Review the form fields and ensure you have all the required information ready.
2. Fill out the form fields according to the explanations below.

## Field-by-Field Explanation

* **Course Material** (1): Enter a brief description of the course material you are uploading.
* **Material Type** (2): Select the type of material you are uploading (Audio, Video, Document).
* **Material Category** (3): Choose the category for the material (Category 1, Category 2, Category 3).
* **Uploaded By** (4): Enter the name of the person who uploaded the material.
* **Uploaded At** (5): Select the date the material was uploaded.
* **Uploaded File Name** (6): Enter a name for the uploaded file.
* **Uploaded File Size** (7): Enter the size of the uploaded file.
* **Uploaded File** (8): Select the uploaded file.
* **Description** (9): Enter a brief description of the material.
* **Tags** (10): Enter relevant tags for the material.
* **Material URL** (11): Enter a URL for the material.
* **Tags URL** (12): Enter a URL for the tags.
* **Course Name** (13): Enter the name of the course associated with the material.
* **Course Code** (14): Enter the course code associated with the material.
* **Course Version** (15): Enter the version of the course associated with the material.
* **Course Year** (16): Enter the year of the course associated with the material.
* **Course Semester** (17): Enter the semester of the course associated with the material.
* **Course Level** (18): Select the level of the course (Level 1, Level 2).
* **Course Subject** (19): Enter the subject of the course.
* **Course Topic** (20): Enter a topic associated with the course.
* **Course Credits** (21): Enter the credits associated with the course.
* **Course Duration** (22): Enter the duration of the course.
* **Material Language** (23): Select the language of the material (English, Spanish, French, Other).
* **Material Difficulty** (24): Select the difficulty level of the material (Easy, Medium, Hard).
* **Course Status** (25): Select the status of the course (Published, Unpublished, Pending).

## Tips

* Ensure that all required fields are filled out before submitting the form.
* Double-check your entries for accuracy and completeness.
* If you are unsure about any field, contact your administrator for assistance.
