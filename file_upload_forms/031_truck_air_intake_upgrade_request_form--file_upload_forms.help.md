# Truck Air Intake Upgrade Request Form - Help Guide
## Purpose
The Truck Air Intake Upgrade Request Form is used to gather information from shop staff regarding truck air intake upgrades. This form should only be used to submit new requests, not to update or re-submit existing ones.

## How To Complete This Form
1. Ensure you have all the necessary information and documentation required for the intake upgrade.
2. Fill out the form with the following details:
	* Shop: Enter the shop ID where the vehicle will be serviced.
	* Service Team: Enter the name of the service team member responsible for the upgrade.
	* Fleet Operator: Enter the name of the fleet operator who will be performing the upgrade.
	* Upload File: Upload the relevant file associated with the upgrade request.
	* File Name: Enter a name for the uploaded file.
	* Intake Type: Select whether the upgrade is for an air intake or air filter.
	* Intake Status: Select the status of the intake (e.g., Active, Inactive).
	* Intake Priority: Enter the priority level of the upgrade (e.g., 1, 2, 3).
	* Due Date: Enter the due date for the upgrade.
	* Comments: Add any additional comments regarding the upgrade.
	* Email: Enter the customer's email address.
	* Phone: Enter the customer's phone number.
	* Notes: Add any additional notes regarding the upgrade.
	* Intake Date: Enter the date the upgrade will be performed.
	* Intake Time: Enter the time the upgrade will be performed.
	* Intake Location: Enter the location where the upgrade will be performed.
	* Intake Notes: Add any additional notes regarding the upgrade.
	* Customer Name: Enter the customer's name.
	* Customer Email: Enter the customer's email address.
	* Customer Phone: Enter the customer's phone number.
	* Service Type: Select the type of service required for the upgrade.
	* Air Leak Type: Select whether the upgrade is for an air leak or air filter.
	* Air Filter Status: Select the status of the air filter (e.g., Active, Inactive).
	* Air Filter Priority: Enter the priority level of the upgrade.
	* Air Filter Due Date: Enter the due date for the upgrade.
3. Ensure all required fields are completed before submitting the form.
