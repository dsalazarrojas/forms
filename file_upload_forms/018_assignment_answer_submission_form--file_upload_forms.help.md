# Assignment Answer Submission Form - Help Guide

## Purpose
The purpose of this form is to collect student's assignment submissions and verify their original work. It helps in organizing and managing assignments efficiently.

## How To Complete This Form
1. Please fill out the form thoroughly and accurately.
2. Attach the relevant file to the 'Upload Assignment File' field.
3. Confirm that the work is your own original work by selecting 'Yes' for the plagiarism declaration.
4. Provide any additional comments or explanations as needed.

## Field-by-Field Explanation
* **First Name** (`student_first_name`, text, required): Your first name.
* **Last Name** (`student_last_name`, text, required): Your last name.
* **Student ID Number** (`student_id`, text, required): Your institutional student ID number.
* **Email Address** (`student_email`, email, required): Your email address.
* **Course Name** (`course_name`, text, required): Name of the course.
* **Course Number** (`course_number`, text, required): Course identification number.
* **Instructor Name** (`instructor_name`, text, required): Name of your course instructor.
* **Assignment Title** (`assignment_title`, text, required): Title or name of the assignment.
* **Assignment Number** (`assignment_number`, text, required): Which assignment number?
* **Submission Date** (`submission_date`, date, required): Date you are submitting the assignment.
* **Submission Time** (`submission_time`, time, required): Time you are submitting the assignment.
* **Assignment Due Date** (`due_date`, date, required): Original due date.
* **Is This a Late Submission?** (`is_late_submission`, select_one, required): Was it submitted after due date?
* **Days Late (if applicable)** (`days_late`, number, required): Number of days past due date.
* **Submission File Format** (`submission_format`, select_one, required): What format is the assignment (e.g., PDF, Word Document, Text File, etc.)?
* **Upload Assignment File** (`file_submission`, text, required): Attach your completed assignment file.
* **Brief Description of Submission** (`assignment_description`, text, required): Summary of what you are submitting.
* **I confirm this work is my own original work** (`plagiarism_declaration`, select_one, required): Plagiarism statement.
* **Sources or References Used** (`sources_cited`, text, optional): Any sources you consulted.
* **Any Help Received Acknowledged** (`help_acknowledged`, text, optional): Tutoring, peer review, etc.
* **Any Technical Issues Experienced?** (`technical_issues`, text, optional): Problems uploading or formatting?
* **Additional Comments or Notes** (`additional_notes`, text, optional): Anything else for the instructor?
* **Student Signature** (`student_signature`, text, required): Type your name as signature.
