# Open Access Repository Upload Request Form - Help Guide

## Purpose
This form is designed to collect information from authors to upload their manuscripts to a repository.

## How To Complete This Form
1. Fill in the required fields as prompted.
2. Select the relevant repository options (Open Access, Closed Access, Hybrid, or Author's Choice).
3. Choose the access rights for your manuscript (Public, Private).
4. Upload your manuscripts.

## Field-by-Field Explanation

* **Author First Name**: This field is used to collect the first name of the author.
* **Author Last Name**: This field is used to collect the last name of the author.
* **Author Email**: This field is used to collect the email address of the author.
* **Upload Manuscript 1**: This field is for uploading the first manuscript file.
* **Upload Manuscript 2**: This field is for uploading the second manuscript file.
* **Repository Selection**: This field allows you to select the type of repository where you want to upload your manuscript. Choose from:
	+ Open Access: This option is for manuscripts that are openly available to the public.
	+ Closed Access: This option is for manuscripts that are not publicly available.
	+ Hybrid: This option is for manuscripts that have a mix of open and closed access.
	+ Author's Choice: This option allows you to choose a custom repository type.
* **Access Rights**: This field allows you to choose the access rights for your manuscript. Choose from:
	+ Public: This option makes your manuscript publicly available.
	+ Private: This option keeps your manuscript private.

## Tips
- Make sure to fill in all required fields.
- Select the correct repository and access rights for your manuscript.
- Upload your manuscripts in a compatible format (e.g., PDF, DOCX).
- If you have any issues with the form, contact [form@gic.mx](mailto:form@gic.mx).
