# CNC Project Registration Form - Help Guide

## Purpose
This form is for registering a new CNC project, allowing you to provide detailed information about your project's specifications, requirements, and deadlines. Fill out this form to ensure that we have all necessary details to accurately quote and deliver your project.

## How To Complete This Form
To complete this form, simply fill out each field accurately and thoroughly. Required fields are marked with an asterisk (\*). Please make sure to review and submit the form only when you have finished filling out all required fields.

## Field-by-Field Explanation

* **Project Name** (`project_name`, text, \*) This is the descriptive name of your CNC project.
* **Requester Name** (`requester_name`, text, \*) This is your full name that will be associated with the project.
* **Email Address** (`requester_email`, email, \*) This is your email address where we will be able to contact you for project updates.
* **Phone Number** (`requester_phone`, text, ) This is your phone number where we can contact you for project updates.
* **Organization or Company** (`organization_name`, text, \*) This is your organization's or company's name that will be associated with the project.
* **Project Description** (`project_description`, text, \*) A brief overview of what you need machined.
* **Material Type** (`material_type`, select_one, \*) Choose the material that will be used for the project.
* **Material Dimensions** (`material_dimensions`, text, ) Specify the length, width, and height or detailed specs of the material.
* **Quantity Needed** (`desired_quantities`, number, \*) Enter how many parts you need.
* **Design File Upload** (`design_file`, text, \*) Upload your CAD file (CAD, DWG, STL, STEP, IGES, etc.) or provide a brief description of your design.
* **Tolerance Requirements** (`tolerances`, text, ) Specify any tight tolerances or precision needs.
* **Surface Finish Required** (`surface_finish`, select_one, ) Choose the required surface finish.
* **Preferred Machine Type** (`machine_type`, select_one, ) Choose the type of CNC machine preferred.
* **Project Deadline** (`deadline`, date, \*) Choose the deadline for project completion.
* **Timeline Flexibility** (`timeline_flexibility`, select_one, ) Choose how flexible your deadline is (very flexible, flexible, tight, or very tight).
* **Special Requirements or Notes** (`special_requirements`, text, ) Enter any special handling, markings, testing, etc. requirements.
* **Budget Range** (`budget_range`, select_one, ) Choose the budget range for the project.
* **Reference Project or Similar Work** (`reference_project`, text, ) Enter any previous projects we can reference.
* **Preferred Delivery Method** (`delivery_method`, select_one, ) Choose the preferred delivery method.
* **Registration Date** (`registration_date`, date, \*) This is the date this form was submitted.

Please note that some of the fields are optional (marked with a `*`), and you should only fill them out if they are necessary for your project.
