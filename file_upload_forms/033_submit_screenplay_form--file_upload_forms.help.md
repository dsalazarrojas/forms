# Submit Screenplay Form - Help Guide
## Purpose

The Submit Screenplay Form is used for submitting original screenplays for review and consideration. Screenplays are typically 90-120 pages of written work that outline the story, characters, and plot of a film or television show.

## How To Complete This Form

1. Review the form carefully before starting.
2. Ensure you have the required information and materials ready, including the screenplay and any supporting documents.
3. Select the correct category (File Upload Forms or Other) that best describes the type of work you are submitting.
4. Fill in the required fields accurately, including form id, category, and description.
5. If additional fields are required or relevant to your submission, provide details accordingly.
6. Upload any supporting documents or attachments as needed.

## Field-by-Field Explanation
* **Form ID** (form_id): This is the unique identifier of your screenplay. Enter a number that matches the internal ID of your work. 
* **Category** (category): Select "File Upload Forms" if your screenplay is a file upload form, or select "Other" if it's a different type of form. 
* **Description** (description): Briefly describe the nature of your work. 
* **Assigned Tool** (assigned_tool): List any tools, software, or systems used to create this screenplay. 
* **Form ID 1-6** (form_id_1-6): Enter the form ID of a corresponding form in the database. 
* **Category 1-6** (category_1-6): Select the category of each form. 
* **Description 1-6** (description_1-6): Briefly describe each form. 
* **Assigned Tool 1-6** (assigned_tool_1-6): List any tools, software, or systems used to create each form. 

## Tips

* Ensure all fields are filled in accurately and completely.
* Use the correct category and form ID to help with organization and tracking.
* Attach any supporting documents or attachments as needed.
* If you're unsure about any field, consult the help guide or contact the support team for assistance.
