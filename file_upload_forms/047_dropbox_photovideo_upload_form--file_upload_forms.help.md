# Dropbox Photovideo Upload Form - Help Guide
## Purpose
The Dropbox Photovideo Upload Form is a tool used to upload images and videos to your Dropbox account. This form guides you through the process of uploading files to your account.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter a title for the file in the "Title" field.
2. Provide a brief description of the file in the "Description" field.
3. Select the type of file you are uploading (Image or Video) from the "File Upload" field.
4. Confirm that you want to upload the file by selecting "Yes" from the "Confirm Upload" field.
5. If the file upload is successful, the "File Uploaded" field will display a confirmation message.
6. If the file upload fails, the "File Failed" field will display an error message.
7. To attempt to upload the file again, select "Yes" from the "Upload Again" field.
8. If you are satisfied with the upload process, you can confirm that you want to delete the file by selecting "Yes" from the "Confirm Delete" field.

## Field-by-Field Explanation
* **Title** (`title`, `text`, required: false): Enter a title for the file you are uploading.
* **Description** (`description`, `text`, required: false): Provide a brief description of the file you are uploading.
* **File Upload** (`file_upload`, `select_one`, required: false): Select the type of file you are uploading (Image or Video).
* **Upload File** (`upload_file`, `text`, required: false): This field is not necessary for the file upload process, but it is used to display the upload status.
* **Confirm Upload** (`confirm_upload`, `select_one`, required: false): Confirm that you want to upload the file by selecting "Yes".
* **File Uploaded** (`file_uploaded`, `note`, required: false): This field displays a confirmation message if the file upload is successful.
* **File Failed** (`file_failed`, `note`, required: false): This field displays an error message if the file upload fails.
* **Error Message** (`error_message`, `text`, required: false): This field is used to display the reason for the file upload failure.
* **Upload Again** (`upload_again`, `select_multiple`, required: false): Select "Yes" to attempt to upload the file again.
* **Confirm Delete** (`confirm_delete`, `select_one`, required: false): Confirm that you want to delete the file by selecting "Yes".
