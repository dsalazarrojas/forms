# study_guide_conversion_request_form - Help Guide
## Purpose
This form is used to request the conversion of a study guide from an internal system. Fill out this form with the requested information to submit your request.

## How To Complete This Form
To complete this form:

1. Enter your name and email address so the conversion request can be directed to the correct person.
2. Enter the ID of the study guide you'd like to be converted.
3. Select the format you'd like the converted file to be in (PDF, EPUB, or Other).
4. Choose the department that the study guide belongs to (Math, Science, or Other).
5. Enter a file name (optional).
6. Provide a brief description of the conversion request (optional).
7. Add any additional notes you'd like to include with the request.

## Field-by-Field Explanation
- **Submitting User** (`id: 1`): Enter your name and title to identify yourself as the person requesting the conversion.
  - **Email** (`id: 2`): Enter your email address so the conversion request can be directed to the correct person.
  - **Study Guide Id** (`id: 3`): Enter the ID of the study guide you'd like to be converted.
  - **Requested Format** (`id: 4`): Choose the format you'd like the converted file to be in (PDF, EPUB, or Other).
  - **Department** (`id: 5`): Choose the department that the study guide belongs to (Math, Science, or Other).
  - **File Name** (`id: 6`): Enter a file name for the converted file (optional).
  - **Description** (`id: 7`): Provide a brief description of the conversion request (optional).
  - **Submitter Note** (`id: 8`): Add any additional notes you'd like to include with the request (optional).

## Tips
- Make sure to enter the correct Study Guide ID to ensure the conversion request is directed to the correct resource.
- If you're unsure about the format you'd like the converted file to be in, choose "Other" and include a note with your request.
- If you're requesting a conversion for someone else, make sure to include their name and email address in the "Submitting User" and "Email" fields.
- If you have any additional questions or concerns, please contact the support team for assistance.
