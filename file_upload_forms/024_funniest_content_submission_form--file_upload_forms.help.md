# Funniest Content Submission Form - Help Guide
## Purpose
This form is designed to collect user-generated content, such as jokes, stories, or other humorous media, for the website or platform. The form is meant to be simple and easy to use, allowing users to submit their content in a variety of formats.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the required fields:
	* **User Name**: Enter your name as you want it to be displayed on the website.
	* **User E-mail**: Enter your email address to receive feedback or notifications about your submission.
2. Choose your content type:
	* Select the category that best describes your submission:
		+ Funny
		+ Story
		+ Joke
3. Choose a subcategory (optional):
	* Select one or more subcategories that best describe your submission:
		+ Funny
		+ Story
4. Choose a content type (optional):
	* Select the type of content you are submitting:
		+ Text
		+ Image
		+ Video
5. Add tags (optional):
	* Select one or more tags that describe your submission:
		+ funny
		+ story
6. Enter your submission:
	* Type your joke or story in the **User Joke** field.
	* If you selected **image** or **video**, you can upload your file in the **User Media** field.
7. Review your submission:
	* Make sure you have filled out all required fields and selected all relevant categories and tags.

## Field-by-Field Explanation
### **User Joke (1)**
User Joke is a text field where you can enter your joke or funny story.
### **User Story (2)**
User Story is another text field where you can enter another type of story or anecdote.
### **User Media (3)**
User Media is a text field where you can enter a URL or upload a file (e.g. an image or video).
### **Category (4)**
Category helps the site administrators categorize your content. Select one of the following options:
	* Funny
	* Story
	* Joke
### **Subcategory (5)**
Subcategory helps to further describe your content. Select one or more of the following options:
	* Funny
	* Story
### **Content Type (6)**
Content Type describes the type of media you are submitting. Select one of the following options:
	* text
	* image
	* video
### **Tags (7)**
Tags are keywords that help site administrators filter your content. Select one or more of the following options:
	* funny
	* story
### **User Name (8)**
User Name is a field where you can enter your name as you want it to be displayed on the website.
### **User E-mail (9)**
User E-mail is a field where you can enter your email address to receive feedback or notifications.
### **User Phone (10)**
User Phone is a field where you can enter your phone number (optional).
### **User Location (11)**
User Location is a field where you can select your online or offline location.
### **User Website (12)**
User Website is a field where you can enter your personal website or social media profile.

## Tips

* Make sure to fill out all required fields, including User Name and User E-mail.
* You can submit multiple media types (e.g. text, image, and video) in the **User Media** field.
* Use the **Tags** field to help site administrators filter your content.
* If you are having trouble uploading a file, try reducing the file size or format.
