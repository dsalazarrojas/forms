# User Data Upload Form - Help Guide
## Purpose
The purpose of this form is to collect file-related information, including upload details and attributes of the file.

## How To Complete This Form
To complete this form, follow the steps below:

1. Enter your name and surname in the "First Name" and "Last Name" fields.
2. Provide your email address in the "Email Address" field.
3. Enter your contact phone number in the "Contact Phone" field.
4. Upload a file by entering its description, size, and type.
5. Set the "Upload Date" and "Upload Time" fields accordingly.
6. Provide any additional comments about the file.
7. Select the "Assigned To" field to specify who the file was assigned to.
8. Choose how the file was uploaded, either "Uploaded by user" or "Automated System".
9. Enter the "Uploaded By Name" and "Uploaded By Department" fields if applicable.
10. Select the "Form ID" and "Upload Number" fields if required.
11. Specify the "Upload User" field as "uploaded user" or "Other".
12. Select the "Upload Status" field to indicate the status of the upload.
13. Choose the "Upload User Group" field to specify the group the file was uploaded to.
14. Enter the "File Name" field with the name of the uploaded file.

## Field-by-Field Explanation

* **First Name** (`first_name`, text, optional): Enter your first name.
* **Last Name** (`last_name`, text, optional): Enter your last name.
* **Email Address** (`email_address`, email, optional): Enter your email address.
* **Contact Phone** (`contact_phone`, text, optional): Enter your contact phone number.
* **Upload File** (`upload_file`, text, optional): This field is for uploading a file, please enter its name.
* **File Description** (`file_description`, text, optional): A brief description of the file.
* **File Size** (`file_size`, number, optional): Enter the file size.
* **File Type** (`file_type`, select_one, optional): Choose the type of file (Image, Document, Video).
* **Upload Date** (`upload_date`, date, optional): Set the upload date.
* **Upload Time** (`upload_time`, time, optional): Set the upload time.
* **Additional Comments** (`additional_comments`, text, optional): Enter any additional comments about the file.
* **Assigned To** (`assigned_tool`, select_one, optional): Specify who the file was assigned to (chatjimmy, Someone Else).
* **Uploaded By** (`uploaded_by`, select_one, optional): Choose how the file was uploaded (uploaded by user, Automated System).
* **Uploaded On** (`uploaded_date`, date, optional): Set the date the file was uploaded.
* **Uploaded Time** (`uploaded_time`, time, optional): Set the time the file was uploaded.
* **Uploaded By Name** (`uploaded_by_name`, text, optional): Enter the name of the person who uploaded the file.
* **Uploaded By Department** (`uploaded_by_department`, text, optional): Enter the department of the person who uploaded the file.
* **Form ID** (`form_id`, number, optional): Enter the form ID.
* **Upload** (`upload_number`, number, optional): Enter the upload number.
* **Upload User** (`upload_user`, select_one, optional): Choose how the file was uploaded (uploaded user, Other).
* **Uploaded Group** (`uploaded_group`, text, optional): Enter the group the file was uploaded to.
* **Upload Status** (`upload_status`, select_one, optional): Choose the upload status (Completed, Pending, Failed).
* **Upload User Group** (`upload_user_group`, select_multiple, optional): Choose the group the file was uploaded to (Group A, Group B).
* **File Name** (`file_name`, text, optional): Enter the name of the file.
* **Comments** (`comments`, text, optional): Enter any comments about the file.
