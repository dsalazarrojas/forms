# Home Inspection Report Release Form - Help Guide
## Purpose
The Home Inspection Report Release Form is a tool for home inspectors to collect information about the inspection report they are releasing. The form helps determine the category of the report and provides a description of the report, as well as who the report is being released to and why.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the category of the inspection report from the "Category" field.
2. Provide a brief description of the report in the "Description" field.
3. Select who the report is being released to from the "Release To" field. You can choose to release to the "Homeowner", "Realtor", or "Both".
4. Select the reason for the release from the "Release Reason" field. You can choose from "For Inspection Report", "For Marketing Material", "For Appraisal Report", or "Other".
5. Enter the name of the file being released in the "File Name" field.
6. Select the type of file being released (e.g., Image, Document, Audio, Video, or Other) from the "File Type" field.
7. Click on the "Upload" field to attach the file being released.
8. Click on the "Submit" button to submit the form.

## Field-by-Field Explanation

* **Category** (`Category`): Select the category of the inspection report. Options: File Upload Forms, Other.
* **Description** (`Description`): Provide a brief description of the report.
* **Release To** (`Release To`): Select who the report is being released to. Options: Homeowner, Realtor, Both.
* **Release Reason** (`Release Reason`): Select the reason for the release. Options: For Inspection Report, For Marketing Material, For Appraisal Report, Other.
* **File Name** (`File Name`): Enter the name of the file being released.
* **File Type** (`File Type`): Select the type of file being released. Options: Image, Document, Audio, Video, Other.
* **Upload** (`Upload`): Attach the file being released.
* **Submit** (`Submit`): Submit the form.
* **Back** (`Back`): Go back to the previous page.
* **Cancel** (`Cancel`): Cancel the form submission.

## Tips
- Make sure to select the correct category and release reason for the report.
- Enter a clear and concise description of the report.
- Attach the correct file for the report.
- Review the information before submitting the form to ensure accuracy.
- If you need to cancel the form, click on the "Cancel" button.
