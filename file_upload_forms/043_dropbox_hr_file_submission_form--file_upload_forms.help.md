# Dropbox HR File Submission Form - Help Guide
## Purpose
The Dropbox HR File Submission Form is designed to enable users to upload and categorize files related to HR activities such as performance reviews, medical records, or personnel records.

## How to Complete This Form
1. Fill in the "File Submission" field with the title of the file you are submitting.
2. Select the appropriate category for your file from the "Document Type" options.
3. If you have a corresponding document to upload, click on the "Document Upload" field to attach it.
4. Finally, choose a date for the file upload by entering or selecting the date it was uploaded.

## Field-by-Field Explanation
* **File Submission (text)**: Enter the title or description of the file you are submitting. This will help us track the file's identity in our system.
* **Document Type (select_one)**: Choose the category that best describes the type of file you are uploading. This field is crucial for us to accurately categorize and store the file.
* **Document Upload (text)**: If you have a corresponding document to upload, click on this field to attach it. Please note that only files of reasonable size will be accepted.
* **Date Uploaded (date)**: Enter the date the file was uploaded. This field helps us track when the file was submitted and ensures we have an accurate record of its upload.
