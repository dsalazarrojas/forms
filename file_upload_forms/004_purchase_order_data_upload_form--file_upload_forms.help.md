# Purchase Order Data Upload Form - Help Guide

## Purpose
This form is designed to collect and upload purchase order data for management and tracking purposes.

## How To Complete This Form

To complete this form, follow these steps:

1. Fill out the Order Details section with the relevant information about the purchase order.
2. Upload the purchase order data file using the Upload button.
3. Select the Vendor Name from the drop-down list.
4. Enter the Delivery Date and Delivery Time.
5. Enter the Order Amount.
6. Choose the Payment Method.
7. Add any additional notes about the purchase order.
8. Enter the Email and Phone contact information of the person uploading the data.
9. Select the Order Status.
10. Confirm that the data has been uploaded by clicking the Confirm button.

## Field-by-Field Explanation

* **Order Details**: Enter a brief description of the purchase order.
* **Upload File**: Upload the purchase order data file in CSV or similar format.
* **Purchase Order Data**: Enter any additional notes or comments about the purchase order.
* **Vendor Name**: Select the name of the vendor from the drop-down list.
* **Delivery Date**: Enter the date the purchase order is expected to be delivered.
* **Delivery Time**: Enter the time the purchase order is expected to be delivered.
* **Order Amount**: Enter the total amount of the purchase order.
* **Payment Method**: Select whether the payment method is 'Yes' or 'No'.
* **Notes**: Enter any additional comments or notes about the purchase order.
* **Email**: Enter the email address of the person uploading the data.
* **Phone**: Enter the phone number of the person uploading the data.
* **Order Status**: Select the status of the purchase order from the drop-down list.
* **Upload**: Click the Upload button to upload the file.
* **Confirm Upload**: Confirm that the data has been uploaded.
* **Confirm**: Confirm that the data has been uploaded and submitted.
* **Cancel**: Cancel the upload process.
* **Vendor Orders**: Select whether the vendor orders are 'Yes' or 'No'.

Note: This form is designed to be used with purchase order data that is already in an organized format (CSV or similar). If you're unsure about the format or need help with data preparation, please consult with your internal teams or stakeholders.
