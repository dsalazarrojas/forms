# Expansion Pack Release Form - Help Guide

## Purpose
This form is used to collect information about the expansion pack release, including whether it is released, the game version, release date, promotional assets, internal approvals, and game team members.

## How To Complete This Form
To complete this form, follow these steps:

1.  Select all the options that apply to the expansion pack release.
2.  Enter the game version in the format specified.
3.  Enter the release date in the format specified.
4.  Select all the promotional assets that are applicable.
5.  Select whether the expansion pack has internal approvals.
6.  Select all the game team members who are part of the expansion pack release.

## Field-by-Field Explanation
- **prophets** (`expansion_pack_release_form`, select_multiple, required: false)
  This field is used to indicate whether the expansion pack is released or not. Select all the options that apply.
- **game version** (`game_version`, text, required: false)
  Enter the version of the game that the expansion pack is associated with.
- **release date** (`release_date`, text, required: false)
  Enter the date the expansion pack was released in the format specified.
- **promotional assets** (`promotional_assets`, select_multiple, required: false)
  Select all the promotional assets that are part of the expansion pack release.
- **internal approvals** (`internal_approvals`, select_one, required: false)
  Indicate whether the expansion pack has internal approvals or not.
- **game team members** (`game_team_members`, select_multiple, required: false)
  Select all the game team members who are part of the expansion pack release.

## Tips
- Make sure to select all the applicable options for each field.
- Enter the information in the format specified for the release date and game version fields.
- If the expansion pack does not have internal approvals, select "No".
- Review all the fields before submitting the form to ensure all the required information is provided.
