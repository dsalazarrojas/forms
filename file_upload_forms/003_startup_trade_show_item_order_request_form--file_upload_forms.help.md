# Startup Trade Show Item Order Request Form - Help Guide
## Purpose
This form is used by startups to request an order of items for the trade show. It is essential to fill out this form accurately to ensure that your request is processed correctly.

## How To Complete This Form
To complete this form, please follow these steps:

1.  Select the event team that you are working with from the list provided.
2.  Enter a name for the item you are requesting.
3.  Choose the date you would like to report on the trade show.
4.  Select the time you would like to report on the trade show.
5.  Enter the number of items you would like to order.
6.  Add any additional notes or comments about your request.
7.  Choose the size of the item you would like to order (Large, Medium, or Small).

## Field-by-Field Explanation
* **Event Team**: Select the event team that you are working with. This will help us understand which team is responsible for your request. You can choose from "Event Team" or "Other".
* **Item Name**: Enter a name for the item you are requesting. This should be a brief description of the item, such as a product name or a description of the item.
* **Report Date**: Enter the date you would like to report on the trade show. This should be in the format dd/mm/yyyy.
* **Report Time**: Select the time you would like to report on the trade show. This is where you can choose the time that works best for you.
* **Item Count**: Enter the number of items you would like to order. This can be a whole number, such as 1 or 2.
* **Notes**: Add any additional comments or notes about your request. This is an optional field, but it can be helpful to provide more information about your request.
* **Item Type**: Choose the size of the item you would like to order. You can choose from "Large", "Medium", or "Small".
