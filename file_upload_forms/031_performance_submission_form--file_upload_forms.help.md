# Performance Submission Form - Help Guide
## Purpose
The Performance Submission Form is designed to collect details about a performance from users, which will be used to track and analyze performance metrics.

## How To Complete This Form
To complete this form, follow these steps:

* Fill out all the required fields, including "Venue" and "Date".
* Select all the necessary files to upload for the performance.
* Add any relevant notes about the performance in the "Note" field.
* Review and submit the form once you have completed all the necessary fields.

## Field-by-Field Explanation

* **Enter performance details** (`performance_submission_form`, text, required): Enter a brief description of the performance, including any relevant details about the event or activity.
* **Upload files** (`file_uploads`, select_multiple, required): Select all the files that are relevant to the performance, such as images, videos, or documents. The options for this field are:
	+ 1
	+ 2
	+ 3
* **Venue** (`venue`, select_one, required): Select the venue where the performance took place. The options for this field are:
	+ Option 1
	+ Option 2
	+ Option 3
* **Date** (`date`, date, required): Enter the date of the performance. This field should be in the format mm/dd/yyyy.
* **Time** (`time`, time, required): Enter the time of the performance. This field should be in the format 12:00 PM.
* **Note** (`note`, note, optional): Add any additional notes about the performance, such as any notable events or outcomes.
