# Moment Challenge Submission Form - Help Guide
## Purpose
The purpose of this form is to collect submissions for a moment challenge. It is designed to gather information from participants, including user inputs, photos, and other relevant details.

## How To Complete This Form
1. Review the provided instructions carefully.
2. Ensure you have all necessary documents or materials prepared for submission.
3. Fill out the form with accurate and complete information.
4. Select the relevant options for each field as instructed.

## Field-by-Field Explanation
### User Inputs (Page 1)
* **User Inputs** (`user_inputs`, `text`, required: false): This section is for the user to input any information they wish to share about their experience or moment challenge submission.

### Photos (Page 1)
* **Photos** (`photo_inputs`, `text`, required: false): This section is for the user to provide photos related to their moment challenge submission.

### Consent Form (Page 2)
* **Consent Form** (`consent_form`, `select_multiple`, required: false): You must select whether or not you agree to participate in this challenge.

### Photo (Page 2)
* **Photo** (`photo`, `text`, required: false): This section is for the user to provide a link to their photo or other image related to their challenge submission.

### Video (Page 2)
* **Video** (`video`, `text`, required: false): This section is for the user to provide a link to their video or other media related to their challenge submission.

### Participant Details (Page 3)
* **Participant Details** (`participant_details`, `text`, required: false): This section is for the user to input any other details they wish to share about themselves or their participation.

### Name (Page 4)
* **Name** (`name`, `text`, required: false): This section is for the user to input their name.

## Tips
* Please ensure all information is accurate and complete.
* If you need help or have questions, contact form@gic.mx.
