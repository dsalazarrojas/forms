# Executive Program Project Submission - Help Guide
## Purpose
This form is designed for project teams to submit Executive Program project proposals, allowing for a structured and organized submission process.

## How To Complete This Form
- Start by providing project details, including any relevant project information.
- Upload any necessary project files, if applicable.
- Evaluate your project using the provided evaluation section.
- If additional files are required, upload them in the additional files section.

## Field-by-Field Explanation
### Project Details
* **Project Details** (`project_details`, text, optional): This section is for providing any relevant project information, such as project title, description, or goals.

### Project Files
* **Project Files** (`project_files`, text, optional): This section is for uploading any necessary project files, such as documents or presentations.

### Project Evaluations
* **Project Evaluations** (`project_evaluations`, note, optional): This section is for evaluating your project, including any feedback or comments.

### Additional Files
* **Additional Files** (`project_files_2`, text, optional): This section is for uploading any additional project files, such as attachments or supporting documents.

## Tips
- Ensure that all sections are completed before submitting the form.
- Search for existing projects before submitting a new project proposal to prevent duplication.
- Only submit one project proposal per form.
