# Engineering Photo Submission Form - Help Guide
## Purpose
The Engineering Photo Submission Form is used for submitting photos related to engineering projects. The form is designed to collect relevant information about the project, including project details and photo metadata.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the project name and description in the Project Name and Project Description fields.
2. Enter the URL of the photo you wish to submit in the Photo URL field.
3. Upload the photo file by entering its URL in the File field or uploading it directly using the file upload option.
4. Provide the project manager's contact information in the Project Manager field.
5. Enter the date and time the photo was taken in the Photo Date and Photo Time fields.
6. Add any additional comments or notes about the photo in the Photo Note field.
7. Enter your contact information, including your phone number, in the Engineer Phone field.

## Field-by-Field Explanation

* **Project Name** (`project_name`, text, required: false): Enter the name of the project you are submitting the photo for.
* **Project Description** (`project_description`, text, required: false): Enter a brief description of the project.
* **Photo URL** (`photo_url`, text, required: false): Enter the URL of the photo you wish to submit.
* **File** (`file`, text, required: false): Upload or enter the URL of the photo file.
* **Project Manager** (`project_manager`, text, required: false): Enter the name and contact information for the project manager.
* **Photo Date** (`photo_date`, date, required: false): Enter the date the photo was taken.
* **Photo Time** (`photo_time`, time, required: false): Enter the time the photo was taken.
* **Photo Note** (`photo_note`, text, required: false): Enter any additional comments or notes about the photo.
* **Engineer Phone** (`engineer_phone`, text, required: false): Enter your contact phone number.
