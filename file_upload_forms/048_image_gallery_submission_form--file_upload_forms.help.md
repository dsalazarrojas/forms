# Image Gallery Submission Form - Help Guide
## Purpose
The Image Gallery Submission Form is a tool for users to submit images with associated metadata (caption, description, category, tags, and file information) for display in an image gallery.

## How To Complete This Form
To complete this form, follow these steps:

1. Upload an image by providing the required file information on page 1.
2. Add a caption for the image on page 2.
3. Enter a description for the image on page 3.
4. Specify the category for the image on page 4, selecting one or multiple options from the dropdown menu.
5. Choose any tags or labels for the image on page 5.
6. Click the "Submit" button on the last page to complete the form.

## Field-by-Field Explanation
### **Upload Image**
 Upload a file to be displayed as an image in the gallery. This field is required.
### **Caption**
 Enter a brief description of the image, to be displayed below it. (Optional)
### **Description**
 Enter a more detailed description of the image, if desired. (Optional)
### **Category**
 Select one or multiple categories for the image to be displayed under. (Optional)
### **Tags**
 Choose one or multiple tags or labels for the image to be easily searchable. (Optional)
### **File**
 Enter any additional file information for the image, such as a file name or size. (Optional)

Note: The "Tags" field is a select-one field with two options, but for clarity, it's meant to allow users to assign one or multiple tags to the image, but for the sake of the form, it's treated as a select-one field.
