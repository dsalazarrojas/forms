# stand_up_comedy_night_submission_form - Help Guide

## Purpose
This form is designed to gather necessary information for stand-up comedy night submissions. It is a critical tool for event organizers to collect and manage data for events.

## How To Complete This Form
To complete this form, follow these steps:
1. Select the relevant options for each field.
2. Fill out the required text fields.
3. Upload any necessary files.
4. Select the submission status.
5. Click the submit button to send the form.

## Field-by-Field Explanation
* **Performer Info** (`performer_info`, select_one, required): Choose 'Yes' or 'No' to indicate if the performer has a submission for this event.
* **Act Info** (`act_info`, select_multiple, required): Choose 'Yes' or 'No' for each act participating in this event.
* **Event Info** (`event_info`, select_one, required): Choose 'Yes' or 'No' to indicate if this event is a submission.
* **Review Info** (`review_info`, select_multiple, required): Choose 'Yes' or 'No' for each review submitted for this event.
* **File Upload** (`file_upload`, text, required): Upload any necessary files for this submission.
* **File Info** (`file_info`, select_one, required): Choose 'Yes' or 'No' to indicate if a file is attached.
* **Review Submission** (`review_submission`, select_one, required): Choose 'Yes' or 'No' to indicate if this event has a review submission.
* **String** (`string`, text, required): Fill out the relevant string field.
* **Act Submission** (`act_submission`, text, required): Fill out the act submission information.
* **Event Submission** (`event_submission`, text, required): Fill out the event submission details.
* **Review Submission 2** (`review_submission_2`, text, required): Fill out the review submission 2 details.
* **File Submission** (`file_submission`, text, required): Upload any additional files for this submission.
* **Submission Status** (`submission_status`, select_one, required): Choose 'Active' or 'Inactive' to indicate the submission status.
* **Performer Submission** (`performer_submission`, text, required): Fill out the performer submission information.
* **Event Submission 2** (`event_submission_2`, text, required): Fill out the event submission 2 details.
* **Submission Type** (`submission_type`, text, required): Fill out the submission type.
* **Submit Button** (`submit_button`, text, required): Click this button to send the form.
