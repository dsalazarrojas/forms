# Retail Rebae Receipt Upload Form - Help Guide
## Purpose
This form is designed for users to upload receipts related to retail rebates. Users can upload receipts, add review notes, and select a claim date to facilitate the rebate process.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the "Receipt File" field and choose the receipt you want to upload.
2. Add any relevant "Review Notes" in the text area provided.
3. Select the "Claim Date" for the receipt.
4. Click the "Upload" button to submit the form.

## Field-by-Field Explanation

* **User Input** (`User Input`, `text`, optional): This field is a general text input where you can add any relevant information about the receipt.
* **Receipt File** (`Receipt File`, `text`, optional): This is where you upload your receipt file. You can either select the file from your device or enter the receipt details manually.
* **Upload** (`Upload`, `text`, optional): Click this button to upload the receipt file and complete the form.
* **Review Notes** (`Review Notes`, `note`, optional): Add any review notes about the receipt or the rebate process in this text area.
* **Claim Date** (`Claim Date`, `date`, optional): Select the date for which you are claiming the rebate.
