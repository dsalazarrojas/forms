# Receipt Submission For Projects - Help Guide
## Purpose
This form is for project managers and team members to submit receipts related to specific projects. Each receipt should be associated with a project, and the form aims to collect relevant information to help manage project resources effectively.

## How To Complete This Form
1. Ensure you have the required information about the project and the receipt you want to submit.
2. Select the "Upload File" page to attach the receipt file.
3. Enter the "Project Name" and "Project Manager" fields to identify the project and the person responsible for the project.
4. Choose the "Upload Date" field to select the date when the receipt was received or is expected to be received.
5. Click "Submit" to save your submission.

## Field-by-Field Explanation

* **Upload File** (`<name>`, `<type>`, **required**/optional): Attach the receipt file related to the project. The file can be any type of document (e.g., PDF, image, or audio file). 
* **Project Name** (`<name>`, **text**, optional): Enter the name of the project this receipt is associated with. If you're unsure, you can ask your project manager for guidance.
* **Project Manager** (`<name>`, **text**, optional): Enter the name of the project manager or team member responsible for this project. This will help us keep track of who's working on what.
* **Upload Date** (`<name>`, **date**, optional): Choose the date when you received or expect to receive the receipt. If you're not sure, use today's date or the expected date.
