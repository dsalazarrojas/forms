# Song Licensing Submission Application - Help Guide
## Purpose
This form is intended for artists and their managers to submit songs for consideration for licensing. It collects necessary information about the song, artist, and contact details to facilitate the submission process.

## How To Complete This Form
Please fill out the form with the following information:

*   Artist Information: Enter your name, alias, and email address.
*   Song Upload: Provide a title for the song, if you wish.
*   Song Details: Describe the song in 100 characters or less.
*   License Terms: Read and agree to the license terms and conditions.
*   File Upload: Upload any additional files related to the song.
*   Contact Information: Provide your contact information so we can get in touch.
*   Artist Statement: Write a brief statement about the song.
*   Manager Statement: Write a brief statement about the song.
*   Contact Details: Enter any additional contact details we need to contact you.
*   Song Files: Upload any other files related to the song.
*   Manager Information: Enter your manager's name, email address, phone number, and address.
*   Other Owners: If applicable, enter the name and contact information of other owners.
*   Release Date: Enter the release date of the song.
*   Release Year: Enter the release year of the song.
*   Song Duration: Enter the duration of the song.
*   Publisher Details: Enter any details about the publisher.
*   Record Label: Enter the name of the record label.
*   Record Label Owner: Enter the name of the record label owner.
*   Record Label Address: Enter the address of the record label.
*   Record Label Phone: Enter the phone number of the record label.
*   Record Label Email: Enter the email address of the record label.
*   Manager Email: Enter the email address of the manager.
*   Manager Phone: Enter the phone number of the manager.
*   Manager Address: Enter the address of the manager.
