# Document Review Meeting Form - Help Guide

## Purpose
The purpose of this form is to gather information and feedback during a document review meeting. It is designed to help participants provide detailed information about the document being reviewed.

## How To Complete This Form
To complete the form, follow these steps:

1.  Begin by selecting the correct "Document Type" and enter the "Document Name".
2.  Enter the "Schedule Session" date and time for the meeting.
3.  Click on "Upload File" to upload the document to be reviewed.
4.  Add any "Additional Info" relevant to the document or meeting.
5.  Select the "File Type" and "File Name" as they relate to the uploaded file.
6.  Provide feedback and comments in the "Collect Feedback" section.
7.  Record any "Decisions" made during the meeting.
8.  Select the "Follow-up Tasks" required for the document or meeting.
9.  Enter the "Review Session" time and date.
10.  Add any "Additional Comments" about the document or meeting.

## Field-by-Field Explanation

* **Document Type** (`document_type`, `select_one`, required: false): Select the type of document being reviewed, such as "Contract", "Policy", or "Agreement".
* **Document Name** (`document_name`, `text`, required: false): Enter the name of the document being reviewed.
* **Schedule Sessions** (`schedule_session`, `date`, required: false): Schedule the date and time for the meeting.
* **Upload Document** (`file_upload_page`, `note`, required: false): Upload the document to be reviewed.
* **Collect Feedback** (`collect_feedback`, `select_multiple`, required: false): Provide feedback on the document, selecting one or more of the options provided.
* **Record Decisions** (`record_decisions`, `number`, required: false): Record any decisions made during the meeting.
* **Follow-up Tasks** (`follow_up_tasks`, `select_one`, required: false): Select the follow-up tasks required for the document or meeting.
* **Review Session** (`review_session`, `time`, required: false): Enter the time and date for the review session.
* **Additional Info** (`collect_additional_info`, `text`, required: false): Provide any additional information about the document or meeting.
* **File Type** (`file_type`, `text`, required: false): Select the type of file uploaded, such as "PDF", "Excel", or "Word".
* **File Name** (`file_name`, `text`, required: false): Enter the name of the file uploaded.
* **File Size** (`file_size`, `number`, required: false): Enter the size of the file uploaded.
* **File Description** (`file_description`, `text`, required: false): Add a description of the file uploaded.
* **Tags** (`file_tags`, `text`, required: false): Add any tags or keywords associated with the file.
* **Comments** (`file_comments`, `text`, required: false): Add any comments about the file or meeting.
* **Status** (`file_status`, `select_one`, required: false): Select the status of the file, such as "In Progress", "Approved", or "Rejected".
* **Version** (`file_version`, `number`, required: false): Enter the version of the file.
* **Date** (`file_date`, `date`, required: false): Enter the date of the file.
* **Time** (`file_time`, `time`, required: false): Enter the time of the file.
* **URL** (`file_url`, `text`, required: false): Enter the URL of the file.
* **Note** (`file_note`, `note`, required: false): Add any additional notes about the file or meeting.

Note: This form is designed to be flexible and accommodate different types of document review meetings. Please fill in the relevant fields as required for your specific meeting needs.
