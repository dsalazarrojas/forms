# Lost Property Search Request Form - Help Guide
## Purpose
This form is used to report a lost property and gather information to aid in its recovery.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the "Lost Property Search Request" option.
2. Enter a brief description of the lost item.
3. Enter the date you last saw the item.
4. Enter the last known location of the lost item.
5. Select the type of item that was lost (if applicable).
6. Enter a description of the item (if applicable).
7. Select the status of the item (Active or Inactive).
8. Enter your name as the customer who reported the lost property.
9. Enter your phone number.
10. Enter your email address.
11. Enter any additional message or comments you have about the lost property.
12. Upload an image of the lost property (if available).

## Field-by-Field Explanation
* **Lost Property Search Request** (Select One): Choose 'Yes' if you are sure the property was lost.
* **Lost Item Description**: Enter a brief description of the lost item, e.g., "black wallet" or "iPhone".
* **Date Found**: Enter the date you last saw the item.
* **Last Seen Location**: Enter the last known location where you last saw the item.
* **Found Location**: Enter the location where you believe the item was found (if different from last seen location).
* **Item Type**: Select the type of item that was lost (e.g., "wallet", "phone", etc.).
* **Item Description**: Enter a detailed description of the item, including any unique features or characteristics.
* **Item Status**: Select the status of the item, either "Active" or "Inactive".
* **Customer Name**: Enter your name as the customer who reported the lost property.
* **Customer Phone**: Enter your phone number.
* **Customer Email**: Enter your email address.
* **Customer Message**: Enter any additional comments or information you have about the lost property.
* **Upload Image**: Upload an image of the lost property (if available).
