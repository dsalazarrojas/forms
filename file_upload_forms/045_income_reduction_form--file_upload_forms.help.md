# Income Reduction Form - Help Guide
## Purpose
The Income Reduction Form is a tool used to capture information about income reductions, specifically for mortgage modifications or other types of income reductions. This form helps customers provide accurate and complete information to their lender to adjust their mortgage payments.

## How To Complete This Form
To complete this form, follow these steps:

1. Choose the type of income reduction you are experiencing (Mortgage Modification or Other).
2. Provide a brief description of the modification or reduction.
3. If applicable, upload any supporting documentation.

## Field-by-Field Explanation
* **Income Reduction Form** (`income_reduction_form`, text, required/optional): This field is the main description of the income reduction. Provide a brief and accurate description of the reduction, including the date and amount affected.
* **Mortgage Modification** (`mortgage_modification`, text, required/optional): This field is used to provide details about the mortgage modification. If you are experiencing a mortgage modification, please provide a brief description here.
* **Credit Reduction Services** (`credit_reduction_services`, text, required/optional): This field is used to provide any additional information about credit reduction services used to achieve the income reduction.
* **Form Type** (`form_type`, select_one, required/optional): Select the type of income reduction you are experiencing (Mortgage Modification or Other).
* **File Upload** (`file_upload`, text, required/optional): If you have any supporting documentation for the income reduction, upload it here.
