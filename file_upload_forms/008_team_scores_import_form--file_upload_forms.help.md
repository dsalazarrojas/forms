# Team Scores Import Form - Help Guide
## Purpose
The Team Scores Import Form is a tool to import scores data from a file into the system for a specific match round. This form helps users upload their team's scores for the match round in question.

## How To Complete This Form
To complete this form, follow these steps:
1. Enter the team name in the 'Team Name' field.
2. Upload the file containing the scores data using the 'File' field.
3. Select the match round for which you want to import the scores in the 'Match Round' field.
4. Review and submit the form to import the scores into the system.

## Field-by-Field Explanation
- **Team Name** (`team_name`, text, required): Enter the name of your team that you want to upload scores for. This field helps the system identify your team and match the scores against the existing team in the system.
  - **File** (`file`, text, required): Upload a file containing your team's scores data. The file should be in a format compatible with the system's import process. This field is necessary for the system to import the scores correctly.
  - **Match Round** (`match_round`, text, required): Select the match round for which you want to import the scores. This field ensures that scores are matched against the correct round in the system.

## Tips
- Make sure to enter the correct team name to avoid duplicate team names.
- Ensure that the uploaded file is in the correct format for the import process to succeed.
- Select the correct match round to ensure scores are imported for the right round.
