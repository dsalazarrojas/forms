# Dcrit Submission Form - Help Guide

## Purpose
The Dcrit Submission Form is a tool used to collect information from users who wish to submit their projects for review. It is a straightforward form designed to gather necessary details about the projects being submitted.

## How To Complete This Form
To complete this form, please follow these steps:

1. Provide the project name and link in the respective fields.
2. Upload a file or provide any relevant online resources for further review.
3. Complete the submission form fields as accurately as possible.
4. Ensure that all required fields are filled out before submitting the form.

## Field-by-Field Explanation
### Project Name (`project_name`)
**Required:** `true`
* This field is required to identify the project being submitted. Please enter the name of the project in a clear and concise manner.

### Project Link (`project_link`)
**Optional:** `false`
* If applicable, provide a link to the project's online presence, allowing reviewers to access additional information.

### Upload Project (`file_upload`)
**Required:** `true`
* This field is for uploading a relevant file related to the project. Ensure the file is in a suitable format and size for review.

### Online Resources (`online_resources`)
**Optional:** `false`
* If additional information is available online, provide the links or URLs to access them.

### Submitter (`submitted_by`)
**Required:** `true`
* This field is required to provide information about the submitter. Please fill it out accurately to ensure your submission is properly credited.

### Submission Date (`submitted_on`)
**Required:** `true`
* This field is for recording the date and time of submission. Please select the correct date from the calendar provided.

## Tips
* Double-check all fields before submitting to ensure accuracy and completeness.
* Ensure that all required fields are filled out to avoid any issues with submission.
* If you have any issues or concerns, please contact `form@gic.mx` for assistance.
