# Cover Design Submission Form - Help Guide
## Purpose
The Cover Design Submission Form is used to collect submission information for a cover design submission. This form is designed to gather all the necessary details required for the submission process.

## How To Complete This Form
To complete this form, follow these steps:

1. Click on the "Start Submission" button to begin the submission process.
2. Fill out all required fields with the relevant information.
3. Ensure you have attached the relevant file(s) and uploaded them correctly.
4. Review and edit your submission before clicking the "Submit" button.

## Field-by-Field Explanation
* **Form Header** (`form_header`, `text`, required: false): This field is used to input a brief description of the submission. It is not required but can provide additional context.
* **File Input** (`file_input`, `text`, required: true): This field is used to upload a file related to the submission. The file should be in a format supported by the system.
* **File URL** (`file_url`, `text`, required: true): This field is used to input the URL of the file if it is not attached directly.
* **File Attachment** (`file_attachment`, `text`, required: false): This field is used to input additional attachments or notes related to the file.
* **Cover Design** (`cover_design`, `text`, required: true): This field is used to input the cover design description.
* **Submission Title** (`submission_title`, `text`, required: true): This field is used to input a title for the submission.
* **Submission Description** (`submission_description`, `text`, required: false): This field is used to input a description for the submission.
* **Submission Category** (`submission_category`, `select_one`, required: true): This field is used to select a category for the submission.
* **Submission Tags** (`submission_tags`, `select_multiple`, required: false): This field is used to select multiple tags for the submission.
* **Submission Status** (`submission_status`, `select_one`, required: true): This field is used to select the status of the submission.
* **File Size Limit** (`file_size_limit`, `number`, required: true): This field is used to input the file size limit for the submission.
* **Submission Date** (`submission_date`, `date`, required: true): This field is used to input the date of submission.
* **Submission Time** (`submission_time`, `time`, required: true): This field is used to input the time of submission.
* **Submission Email** (`submission_email`, `email`, required: false): This field is used to input the email for the submission.
* **Submission Phone** (`submission_phone`, `text`, required: false): This field is used to input the phone number for the submission.
* **Submission Notes** (`submission_notes`, `note`, required: true): This field is used to input notes for the submission.
* **Submission Comments** (`submission_comments`, `select_one`, required: false): This field is used to select comments for the submission.
* **Submission File Type** (`submission_file_type`, `select_one`, required: true): This field is used to select the file type for the submission.
* **Submission Attachment** (`submission_attachment`, `text`, required: false): This field is used to input additional attachments or notes related to the submission.
* **Submission Attachment URL** (`submission_attachment_url`, `text`, required: false): This field is used to input the URL of the attachment if it is not attached directly.
* **Submission Uploaded by** (`submission_uploaded_by`, `select_one`, required: true): This field is used to select whether the submission was uploaded by the user.
* **Submission Uploaded at** (`submission_uploaded_at`, `select_one`, required: true): This field is used to select whether the submission was uploaded at the specified time.
* **Submission Reviewed by** (`submission_reviewed_by`, `select_one`, required: false): This field is used to select whether the submission was reviewed by someone.
* **Submission Reviewed at** (`submission_reviewed_at`, `select_one`, required: false): This field is used to select whether the submission was reviewed at the specified time.

## Tips
* Ensure you have attached the relevant file(s) and uploaded them correctly.
* Review and edit your submission before clicking the "Submit" button.
* Double-check all required fields before submitting the form.
