# participant_intake_and_media_submission - Help Guide
## Purpose
The participant intake and media submission form is used to collect essential information from participants in various contexts, such as research, events, or community engagement. This form is used to obtain consent and gather media submissions from participants.

## How To Complete This Form
To complete this form, follow these steps:

1.  Fill in the participant details section, providing your name, email, and any other relevant information.
2.  Indicate your consent to participate by selecting the correct option in the "Consent" field.
3.  If you have given consent, provide a reason for your consent in the "Consent Reason" field.
4.  Select the type of intake form you are submitting for (e.g., Contest, Campaign, Class, or Community Project).
5.  If you have selected a form type that has a subtype option, select the subtype that best describes your intake form (e.g., "Yes" or "No").
6.  If you have selected a form subtype that requires further explanation, provide a brief description in the "Intake Form Subtype Other" field.
7.  Select the type of media you are uploading (e.g., Video, Image, Audio, or File).
8.  If you have selected a media type, you will need to upload the media file in the "Intake Media Upload" field.

## Field-by-Field Explanation

* **Participant Details**: Enter your name and other relevant information in this field.
* **Consent**: Indicate whether you have given consent to participate.
* **Consent Reason**: If you have given consent, provide a reason for your consent.
* **Intake Form Type**: Select the type of intake form you are submitting (e.g., Contest, Campaign, Class, or Community Project).
* **Intake Form Subtype**: If applicable, select the subtype of your intake form.
* **Intake Form Subtype Other**: If you have selected a form subtype that requires further explanation, provide a brief description.
* **Intake Media Type**: Select the type of media you are uploading (e.g., Video, Image, Audio, or File).
* **Intake Media**: Enter a description of the media you are uploading.
* **Intake Media Upload**: Upload the media file.

## Tips
* Make sure to select the correct media type and upload the corresponding file.
* Ensure that you have provided your consent before completing this form.
* If you are unsure about any of the fields, do not hesitate to contact us for assistance.
* Please note that some fields may be required or optional, depending on your selection in other fields.
