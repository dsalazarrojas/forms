# investment_fund_document_upload_form - Help Guide
## Purpose

The investment_fund_document_upload_form is a tool for uploading documents related to investment funds.

## How To Complete This Form

1. Fill in all the required fields and select the corresponding options.
2. Choose the document type from the "Document type" field.
3. Upload the document in the "Upload file" field.
4. Enter the investor's name and other relevant information.
5. Select the correct option from the "Select one" field.
6. Choose multiple options from the "Select multiple" field.
7. Enter other relevant details as required.
