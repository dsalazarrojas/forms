# Horticulture Entry Card - Help Guide
## Purpose
This form, Horticulture Entry Card, is designed to collect data related to horticulture entries. It helps gather and store information about various activities, events, or data points related to gardening, agriculture, or plant-based projects. 

## How To Complete This Form

To fill out this form, follow these steps:
1. Enter your **First Name** in the First Name field.
2. Enter your **Last Name** in the Last Name field.
3. Enter your **Phone** number in the Phone field.
4. Enter your **Email** address in the Email field. Please make sure it follows the standard email format (e.g., "john.doe@example.com").
5. Attach or upload a file related to the horticulture entry in the File field.
6. Select a date from the Date field.
7. Select a time for the horticulture entry in the Time field.
8. Enter a Note about the horticulture entry in the Note field.
9. Once all fields are filled out, click the **Submit** button to save the data.

## Field-by-Field Explanation
### First Name (`first_name`, text, not required)
Enter your first name as it appears on your identification or in common usage.

### Last Name (`last_name`, text, not required)
Enter your last name as it appears on your identification or in common usage.

### Phone (`phone`, text, not required)
Enter your phone number without any special characters.

### Email (`email`, email, not required)
Enter your email address in the standard format (e.g., "john.doe@example.com").

### File (`file`, text, not required)
Attach or upload a file related to the horticulture entry. This can be an image, document, or any other type of file.

### Date (`date`, date, not required)
Select a date for the horticulture entry.

### Time (`time`, time, not required)
Select a time for the horticulture entry.

### Note (`note`, note, not required)
Enter a brief note about the horticulture entry.

### Submit (`submit`, text, not required)
Click this button to save the horticulture entry once all fields are filled out.

## Tips
- Please make sure to fill out all required fields or the form will not save your data.
- Make sure the file you attach is relevant to the horticulture entry.
- Select a date and time relevant to the horticulture entry.
