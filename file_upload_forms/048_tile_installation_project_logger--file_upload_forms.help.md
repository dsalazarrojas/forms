## Tile Installation Project Logger - Help Guide

## Purpose
This form is used to log tile installation projects, capturing essential information about the project's status, details, and progress.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the title of the tile installation project in the "Tile Installation Project" field.
2. Select the job date from the calendar.
3. Enter the installation address in the "Installation Address" field.
4. Choose the installation status from the dropdown menu:
	* Installed: The project is completed.
	* Not Installed: The project is not completed.
	* On Hold: The project is put on hold.
5. Enter the installation date.
6. Select the job site inspector's name from the dropdown menu.
7. Enter the job site inspector's license number.
8. Enter the job site inspector's phone number.
9. Enter the job site inspector's email.
10. Enter the installation location (e.g., building, floor, room).
11. Choose who installed the tile from the dropdown menu:
	* Owner: The owner of the project installed the tile.
	* Contractor: A contractor installed the tile.
	* Other: Someone else installed the tile.
12. Enter the job site inspector's address.
13. Add any additional notes about the project in the "Notes" field.
14. Confirm if you have uploaded any files related to the project:
	* Yes: Yes, you have uploaded files.
	* No: No, you have not uploaded files.
15. (Optional) Upload up to 8 files associated with the project.
16. Confirm if you have uploaded any additional files:
	* Yes: Yes, you have uploaded additional files.
	* No: No, you have not uploaded additional files.
