# Daily Location Media Submission - Help Guide
## Purpose
The "Daily Location Media Submission" form is designed to collect information and media from users about their daily locations. This form is intended to gather data on the type of media submitted (audio, image, or video), the location where the media was captured, and additional details such as date and time of capture, location description, coordinates, notes, and any associated file.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the title of the media submission in the "form_title" field.
2. Select the type of media you are submitting by choosing an option in the "MediaType" field.
3. Enter the location where the media was captured in the "Location" field.
4. Enter the date and time the media was captured in the "Date Stamped" and "Time" fields.
5. Provide a brief description of the location in the "Location Description" field.
6. Enter the coordinates of the location in the "Location Coordinates" field.
7. Add any additional notes about the location in the "Location Notes" field.
8. If desired, upload a file associated with the media in the "File" field.
9. Finally, upload the media file in the "Upload File" field.

## Field-by-Field Explanation

* **Daily Location Media Submission Title** (`form_title`, text, optional): Enter a brief title for the media submission.
* **MediaType** (`media_type`, select_one, optional): Select the type of media you are submitting, such as audio, image, or video.
* **Location** (`location`, text, optional): Enter the location where the media was captured.
* **Date Stamped** (`date_stamped`, date, optional): Enter the date the media was captured.
* **Time** (`time`, time, optional): Enter the time the media was captured.
* **Location Description** (`location_description`, text, optional): Provide a brief description of the location.
* **Location Coordinates** (`location_coordinates`, text, optional): Enter the coordinates of the location.
* **Location Notes** (`location_notes`, note, optional): Add any additional notes about the location.
* **File** (`file`, text, optional): If desired, upload a file associated with the media.
* **Upload File** (`upload_file`, text, optional): Upload the media file.

## Tips

* Please ensure that the media you upload is relevant to the location submitted.
* Please do not submit duplicate entries for the same location.
* If you have any issues with the form, please contact us at form@gic.mx.
