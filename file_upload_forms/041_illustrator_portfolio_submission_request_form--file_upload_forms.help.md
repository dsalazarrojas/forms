# Illustrator Portfolio Submission Request Form - Help Guide
## Purpose
This form is designed to help Illustrators and designers submit their portfolios for evaluation and review.

## How To Complete This Form
To complete this form, follow these steps:

1. **Portfolio Request Form**: This is the main entry field for your portfolio request. Please enter a brief description of your work or a short statement outlining your portfolio's focus.
2. **Portfolio Details**: Provide more details about your portfolio, such as any relevant experience or accomplishments.
3. **Contact Information**: Enter your name, email, and any other relevant contact information.
4. **Upload File**: Upload a file that showcases your portfolio, such as a PDF or a link to a online portfolio.
5. **Upload File 2**: This is an optional second file upload field. You can use it to upload additional files or supporting materials for your portfolio.

## Tips
* Make sure to provide clear and concise information about your portfolio and contact details.
* Use a brief and descriptive title for your portfolio request.
* If you have multiple files to upload, use the second file upload field.
* If you have any questions or concerns, please contact us at form@gic.mx.
