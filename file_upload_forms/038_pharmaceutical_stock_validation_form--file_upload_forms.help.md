# pharmaceutical_stock_validation_form - Help Guide
## Purpose
This form is used to validate and track the current status of pharmaceutical stock.

## How To Complete This Form

To complete this form, follow these steps:

1. Enter a brief title for the stock being validated in the **form_title** field.
2. In the **form_category** field, select 'Yes' if the stock is a pharmaceutical product, and 'No' otherwise.
3. In the **category** field, select 'Yes' if the stock is assigned to a department or location, and 'No' otherwise.
4. Provide a brief description of the stock in the **form_description** field.
5. Optionally, provide additional description in the **form_description_2** field.
6. Optionally, upload a related file in the **output_file** field.
7. If applicable, enter the assigned tool in the **form_assigned_tool** field.

## Field-by-Field Explanation

* **form_title** (1, text, optional): Enter a brief title for the stock being validated.
* **form_category** (2, select_one, required): Select 'Yes' if the stock is a pharmaceutical product.
* **form_description** (3, text, optional): Provide a brief description of the stock.
* **description** (4, text, optional): Additional description of the stock, if necessary.
* **category** (5, select_one, required): Select 'Yes' if the stock is assigned to a department or location, and 'No' otherwise.
* **output_file** (6, text, optional): Upload a related file, if applicable.
* **assigned_tool** (7, text, optional): Enter the assigned tool, if applicable.
