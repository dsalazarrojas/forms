The form purpose is to collect information from event attendees to generate a digital badge prototype for the event. This badge will serve as a proof of attendance or participation in the event. # digital_event_badge_prototype_application - Help Guide
## Purpose
This form is designed to collect information for generating a digital badge prototype for event attendees.

## How To Complete This Form
To complete this form, follow these steps:

* Please ensure you have all the necessary information required to fill out the form.
* Select the "Event Title", "Organizer Name", "Event Start Date", and "Event End Date" fields with accurate and correct information about the event.
* For "Badge Type", please select one or multiple options that apply to your role in the event (e.g., "Yes" for those who have participated or "No" for those who did not participate).
* Enter your "Attendee Email" if you want to receive the digital badge.
* Add a brief description for the "Badge Image" field, if you'd like to have a custom image on your badge.
* If you're the primary attendee, fill out the "Attendee Name" field with your details.

## Field-by-Field Explanation
### * Event Title (text): 
Enter the title of the event you participated in.

### * Organizer Name (text): 
Enter the name of the person or organization that organized the event.

### * Event Start Date (date):
Enter the date the event started.

### * Event End Date (date):
Enter the date the event ended.

### * Attendee Email (email):
Enter your email address to receive the digital badge.

### * Badge Type (select multiple): 
Select "Yes" if you participated in the event and "No" if you did not participate.

### * Badge Image (text): 
Enter a brief description for your badge image, if you'd like to have a custom image.

### * Attendee Name (text): 
If you're the primary attendee, fill out this field with your details.
