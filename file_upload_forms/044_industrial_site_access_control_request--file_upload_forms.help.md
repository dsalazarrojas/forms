## industrial_site_access_control_request - Help Guide

## Purpose
This form is used to request access to an industrial site. It is intended for visitors to provide necessary information for site access approvals and upload required documents.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the **Visitor Entry Request** field with the name and any other relevant information about the visitor.
2. Specify the **Site Location** where the visitor will be accessing.
3. Provide detailed **Visitor Details** for the site access team to review.
4. Select one of the **Site Access Approvals** options that best matches the visitor's reason for access.
5. In the **Comments** field, provide any additional context or information about the visit.
6. Upload any **Documents** required for site access approval in the **Upload Documents** field.
7. Finally, select the relevant **Submit Request** options to specify the type of access requested.

## Field-by-Field Explanation

* **Visitor Entry Request**: Enter the name of the person requesting site access.
* **Site Location**: Enter the specific location on the site where the visitor will be accessing.
* **Visitor Details**: Provide as much detail as possible about the visitor, including their purpose and duration of visit.
* **Site Access Approvals**: Choose the option that best describes the reason for the visitor's access:
	+ Option 1: Maintenance/Repair
	+ Option 2: Inspection/Testing
	+ Option 3: Research/Training
* **Comments**: Add any additional context or information about the visit, such as the visitor's schedule or expected arrival time.
* **Upload Documents**: Upload any documents required for site access approval, such as ID or proof of insurance.
* **Submit Request**: Select the type of access requested:
	+ Option 1: General Access
	+ Option 2: Specialized Access (e.g. for a specific project)
	+ Option 3: Emergency Access (e.g. for an urgent situation)
