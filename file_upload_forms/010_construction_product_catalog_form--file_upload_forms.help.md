# Construction Product Catalog Form - Help Guide
## Purpose
The purpose of this form is to provide a centralized repository of construction product information for easy access and reference.

## How To Complete This Form
To complete this form, follow these steps:

1. Review the form carefully to ensure you have all the required information ready.
2. Enter the product name in the "Product name" field, which will be displayed in catalog listings.
3. Provide the product's SKU or model number in the "SKU or model number" field.
4. Select the product category from the available options (e.g., Fasteners, Concrete, Tools).
5. Enter the unit price for the product.
6. Indicate the stock quantity available.
7. Add a short description for the product for catalog use.
8. Provide any key technical specifications or dimensions for the product.
9. If images will be supplied separately, mark the "Product image note" field accordingly.

## Field-by-Field Explanation

* **Product name** (required): Enter the name used in catalog listings. This field is required to ensure consistency and accuracy in catalog display.
* **SKU or model number** (optional): Enter the manufacturer's model or SKU number for the product.
* **Product category** (required): Select the product category (e.g., Fasteners, Concrete, Tools).
* **Unit price** (required): Enter the price per unit in local currency.
* **Stock quantity** (optional): Indicate the number of units available for sale.
* **Product description** (optional): Add a short description for the product for catalog use.
* **Technical specifications** (optional): Provide any key technical details or dimensions for the product.
* **Product image note** (optional): Select whether images will be supplied separately for the product.
  + **Will upload images**: Indicate that images will be uploaded for the product.
  + **No images available**: Indicate that no images will be supplied for the product.
