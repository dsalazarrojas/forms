# cultural_festival_media_upload_form - Help Guide
## Purpose
This form is designed to collect information and media from participants in a cultural festival.

## How To Complete This Form
To complete this form, please follow these steps:

1. Please fill out the Participant Information page with your name, email, and any other relevant details.
2. Upload your participant photo, video, or audio to share with the festival audience.
3. Consent to participate in the festival by selecting "I consent to participate in this festival" from the dropdown menu.
4. Select which type of media you'd like to submit (Photo, Video, Audio, or Other).
5. If you'd like to submit other media not listed in the previous options, please use the "Other Media" field.
6. Fill out the Festival Information page with the festival's name, description, start and end dates, and location.

## Field-by-Field Explanation
### Participant Information
* **Participant Information**: This is the first page where you'll be asked to provide your name, email, and any other relevant details. Please fill out this page completely and accurately.
* **Participant Photo**: This is the field where you can upload your participant photo. Please make sure the photo is clear and in a format that can be easily uploaded (e.g., JPEG, PNG, GIF).
* **Participant Video**: This is the field where you can upload your participant video. Please make sure the video is clear and in a format that can be easily uploaded (e.g., MP4, MOV, AVI).
* **Participant Audio**: This is the field where you can upload your participant audio. Please make sure the audio is clear and in a format that can be easily uploaded (e.g., MP3, WAV).
* **Consent**: This is a dropdown menu where you can select whether you consent to participate in the festival. Please choose the option that best represents your intention.
* **Participant Media**: This is a dropdown menu where you can select the type of media you'd like to submit (Photo, Video, Audio, or Other).
* **Other Media**: This is a field where you can describe any other media you'd like to submit that is not listed in the previous options.
* **Festival Information**: This is the page where you'll be asked to provide information about the festival you're participating in. Please fill out this page completely and accurately.
* **Festival Name**: This is the field where you can enter the name of the festival.
* **Festival Description**: This is the field where you can enter a brief description of the festival.
* **Festival Start Date**: This is the field where you can enter the start date of the festival.
* **Festival End Date**: This is the field where you can enter the end date of the festival.
* **Festival Location**: This is the field where you can enter the location of the festival.

## Tips
* Please make sure to fill out each page completely and accurately before proceeding to the next one.
* If you're unsure about any of the fields, please ask us for clarification.
* We'll take care of the rest, including checking for duplication and non-relevant submissions.
