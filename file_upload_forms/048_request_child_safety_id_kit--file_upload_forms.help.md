# Request Child Safety ID Kit - Help Guide
## Purpose
This form is used to request a safety ID kit for a child, which can be used in various contexts such as schools, nonprofits, and community programs.

## How To Complete This Form
Follow the steps outlined above to complete this form.

## Field-by-Field Explanation

* **Category** (Select One): 
	+ Choose the category that best describes the organization or context in which you are requesting the safety ID kit.
* **Description** (Text): 
	+ Enter a brief description of the request for the safety ID kit.
* **Upload Child Safety ID Kit** (Text): 
	+ Upload the relevant safety ID kit document or file.
* **Capture Consent** (Text): 
	+ Enter your consent to capture the requested safety ID kit data.
* **Submit Form** (Text): 
	+ Review and submit the form to finalize your request.
* **Email** (Email): 
	+ Enter your email address for contact and communication purposes.
* **Phone** (Text): 
	+ Enter your phone number for contact and communication purposes.
* **Address** (Text): 
	+ Enter your address for contact and communication purposes.
* **Manage Data Collection** (Note): 
	+ This field is for internal use and not applicable for general users.
