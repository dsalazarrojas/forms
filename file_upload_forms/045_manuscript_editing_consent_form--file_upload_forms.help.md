# Manuscript Editing Consent Form - Help Guide
## Purpose

The Manuscript Editing Consent Form is used to collect data on manuscript editing and submission history to facilitate the review and editing process.

## How To Complete This Form

1. Please fill out the form completely and accurately.
2. Ensure that all required fields are filled out before submitting the form.
3. Please select the correct options for manuscript upload, submission date, manuscript type, submission status, manuscript revision status, manuscript status, manuscript reviewer, editor, project manager, and project manager.

## Field-by-Field Explanation

* **project_name** (1, text, required): The project name is a mandatory field that should be entered accurately.
* **author_name** (2, text, required): Enter the author's name in this field.
* **email** (3, email, required): Enter the author's contact email address.
* **contact_number** (4, text, required): Enter the author's contact number.
* **project_details** (5, text, required): Enter any additional project details in this field.
* **manuscript_upload** (6, select_one, required): Select the correct manuscript upload option.
	+ Manuscript Upload 1
	+ Manuscript Upload 2
	+ Manuscript Upload 3
* **submission_date** (7, date, required): Enter the manuscript submission date.
* **manuscript_type** (8, select_one, required): Select the manuscript type.
	+ Type 1
	+ Type 2
	+ Type 3
* **manuscript_pages** (9, number, required): Enter the number of manuscript pages.
* **manuscript_length** (10, number, required): Enter the length of the manuscript.
* **submission_status** (11, select_multiple, required): Select the submission status of the manuscript.
	+ Status 1
	+ Status 2
	+ Status 3
* **manuscript_revision_status** (12, select_multiple, required): Select the manuscript's revision status.
	+ Revision Status 1
	+ Revision Status 2
	+ Revision Status 3
* **manuscript_status** (13, select_multiple, required): Select the manuscript status.
	+ Active
	+ Inactive
* **manuscript_reviewer** (14, select_one, required): Select the manuscript reviewer.
	+ Reviewer 1
	+ Reviewer 2
	+ Reviewer 3
* **manuscript_editor** (15, select_one, required): Select the editor for the manuscript.
	+ Editor 1
	+ Editor 2
	+ Editor 3
* **project_manager** (16, select_one, required): Select the project manager.
	+ Manager 1
	+ Manager 2
	+ Manager 3
* **author_signature** (17, text, required): Sign here to confirm that you have reviewed and agreed on the manuscript details.
* **editor_signature** (18, text, required): Sign here to confirm that you have reviewed and agreed on the manuscript details.
* **project_manager_signature** (19, text, required): Sign here to confirm that you have reviewed and agreed on the manuscript details.
* **manuscript_editor_note** (20, note, optional): Enter any notes from the editor.
* **manuscript_review_note** (21, note, optional): Enter any notes from the reviewer.
* **submission_date_2** (22, date, required): Enter another submission date.
* **submission_date_3** (23, date, required): Enter another submission date.
* **submission_date_4** (24, date, required): Enter another submission date.

## Tips

- Please double-check all fields before submitting the form.
- Ensure that all required fields are filled out accurately.
- Review the form carefully to ensure that all information is correct and up-to-date.

Please note that the dates fields are marked as required, but there is only one submission date field (id: 7) that is actually used in the form fields list. The other date fields (id: 22-24) are likely duplicates and can be removed to avoid confusion.
