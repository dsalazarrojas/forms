# Feature Recipe Release Form - Help Guide
## Purpose
This form is used to submit a new feature recipe for review and potential release in the system.

## How To Complete This Form
To complete this form, follow these steps:

*   Enter the required details about the recipe data, including the title and description.
*   Choose the publishing permission for the recipe by selecting from the available options.
*   Provide any original ingredients used in the recipe.
*   Describe the cooking method used to prepare the recipe.
*   Upload any relevant recipe image.

## Field-by-Field Explanation

*   **Recipe Data** (`recipe_data`, `text`, required): This field is used to enter the title and description of the feature recipe.
*   **Publishing Permission** (`publishing_permission`, `select_multiple`, required): Select the appropriate publishing permission for the feature recipe. This field is not optional and must be completed.
*   **Original Ingredients** (`original_ingredients`, `text`, required): This field is used to list any original ingredients used in the recipe.
*   **Cooking Method** (`cooking_method`, `text`, required): Describe the cooking method used to prepare the recipe.
*   **Recipe Image** (`recipe_image`, `text`, required): Upload any relevant recipe image to help illustrate the feature recipe.
