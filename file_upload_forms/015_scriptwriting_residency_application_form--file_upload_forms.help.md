# Scriptwriting Residency Application Form - Help Guide
## Purpose
The Scriptwriting Residency Application Form is designed to collect necessary information from applicants for the scriptwriting residency program. Please fill out this form to apply for the residency program.

## How To Complete This Form
1.  Start by filling out the required fields: **First Name**, **Last Name**, **Script ID**, **Script Status**, **Script Type**, **Script Length**, **Script Start Date**, **Script End Date**, **Script Genre**, and **Script Format**.
2.  Select the relevant **Script Type** from the options provided.
3.  Enter the actual **Script Start Date** and **Script End Date**.
4.  Upload any relevant files in the **File Uploads** section, if applicable.
5.  Set the **Submission Date** and **Residency Start Date** (if applicable).

## Field-by-Field Explanation
- **First Name**: Enter your first name as it appears on official documents.
- **Last Name**: Enter your last name as it appears on official documents.
- **Script ID**: Enter a unique ID for your script (e.g., "MyScript123").
- **Script Status**: Briefly describe the status of your script (e.g., completed, ongoing, or in development).
- **Script Type**: Select the type of script you've applied with (e.g., feature film, short film, or play).
- **Script Length**: Enter the length of your script in terms of pages or words.
- **Script Start Date**: Enter the date you began working on your script.
- **Script End Date**: Enter the date you completed your script (or when you expect it to be completed).
- **Script Genre**: Enter the genre of your script (e.g., comedy, drama, or sci-fi).
- **Script Format**: Enter the format of your script (e.g., PDF, Word, or Google Doc).
- **File Uploads**: If applicable, upload any supporting documents or materials related to your script.
- **Submission Date**: Enter the date you submitted your script.
- **Residency Start Date**: If you've been accepted, enter the date you expect to start the residency program (if applicable).
