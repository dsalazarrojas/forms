# Dropbox Insurance Upload Form - Help Guide

## Purpose
The Dropbox Insurance Upload Form is intended to collect information about an insurance policy from customers to facilitate easier and more efficient insurance claim handling.

## How To Complete This Form
To complete this form, follow these steps:

1. Click on the "Upload Document" field and select the insurance policy document you wish to upload.
2. Choose the type of insurance you are uploading (e.g., Health, Life, or Auto Insurance) in the "Insurance Type" field.
3. If you are uploading a file, click on the "Upload File" field to select the file you wish to upload.

## Field-by-Field Explanation

* **Upload Document** (upload_document, text, not required): This is where you can enter the details of your insurance policy. Please type in the policy number, carrier name, and any other relevant information about your policy. 
* **Insurance Type** (insurance_type, select_one, not required): Select the type of insurance you are uploading (Health, Life, or Auto Insurance).
* **Upload File** (upload_file, text, not required): If you need to upload a file related to your insurance policy, please select the file using this field.
