# image_upload_for_recognition - Help Guide
## Purpose
The form is designed to collect image files for recognition purposes. This includes uploading images for Identification, Analysis, or Both recognition types.

## How To Complete This Form
1. Click on the "Image File" field to upload your image file.
2. Enter a brief description of the image in the "description" field.
3. Select the type of recognition required from the "Type of Recognition" dropdown menu.
4. Select the purpose of recognition from the "Purpose of Recognition" dropdown menu.
5. Click on the "Submit" button to complete the form.

## Field-by-Field Explanation
* **Image File** (`image_file`, text, optional): Upload your image file from your computer or select a previously uploaded file.
* **description** (`image_description`, text, optional): Enter a brief description of the image, which will help in efficient processing and categorization.
* **Type of Recognition** (`recognition_type`, select_one, optional): Choose the type of recognition required for the image:
	+ Identification
	+ Analysis
* **Purpose of Recognition** (`recognition_purpose`, select_multiple, optional): Select the purpose of recognition for the image:
	+ Identification
	+ Analysis
	+ Both

## Tips
* Make sure to upload only image files.
* If unsure about the type or purpose of recognition, please check with your supervisor or contact the relevant department for clarification.
* Ensure that the image file is clear and of good quality for accurate recognition.
