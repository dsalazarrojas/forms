# Flotilla Derby Awards Submission - Help Guide
## Purpose
This form is designed to collect supporting documentation for the Flotilla Derby Awards Submission. Please fill out this form with the required and optional information to submit your application.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the required fields, marked with an asterisk (\*) in their labels.
2. Select the supporting documentation files as required or optional from your computer or other sources.
3. Upload each file and make sure they are correctly uploaded.
4. Once you've filled out all the required fields and uploaded the required files, click the "Submit" button to finalize your submission.
