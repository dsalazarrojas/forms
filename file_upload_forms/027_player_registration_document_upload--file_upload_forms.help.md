# Player Registration & Document Upload - Help Guide
## Purpose
This form is designed to collect player information and upload documents related to the player. It is used to register players and upload relevant documents such as player registration forms, player documents, and player profiles.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the player's details in the **Player Details** section.
2. Select the type of document to be uploaded in the **Documents** section.
3. Upload the selected document in the **File** section.
4. Confirm the player's email address in the **Confirm Email** section.
5. Enter the player's phone number in the **Phone** section.
6. Select the document type and upload another document if necessary.
7. Enter any additional notes about the player in the **Player Notes** section.
8. Select the player's team and position.
9. Enter any additional document details.

## Field-by-Field Explanation

* **Player Details**: Enter the player's name, date of birth, and address.
* **Documents**: Select the type of document to be uploaded (e.g., Player Registration Form, Player Document, Player Profile).
* **Upload**: Choose the type of document to be uploaded (e.g., Player Registration Form, Player Document, Player Registration and Document Upload).
* **File**: Upload the selected document.
* **Confirm Email**: Confirm the player's email address.
* **Phone**: Enter the player's phone number.
* **Document Type**: Select the type of document uploaded (e.g., Player Registration Form, Player Document, Player Profile).
* **Player Name**: Enter the player's name.
* **Player DOB**: Enter the player's date of birth.
* **Player Phone**: Enter the player's phone number.
* **Player Address**: Enter the player's address.
* **Document Uploaded**: This is a note field to indicate if a document has been uploaded.
* **Document Type 2**: Select the type of document uploaded (e.g., Player Registration Form, Player Document, Player Profile).
* **Player Document**: Enter any additional details about the document.
* **Player Notes**: Enter any additional notes about the player.
* **Team**: Select if the player is part of a team.
* **Position**: Select the player's position.
* **Document Name**: Enter the name of the uploaded document.
* **Document Type 3**: Select the type of document uploaded (e.g., Player Registration Form, Player Document, Player Profile).
* **Document ID**: Enter the ID of the uploaded document.
* **Document Size**: Select the size of the uploaded document (e.g., Large, Small, Medium).
* **Document Type 4**: Select the type of document uploaded (e.g., Player Registration Form, Player Document, Player Profile).
* **Document Uploaded 2**: This is a note field to indicate if a document has been uploaded.
* **Document ID 2**: Enter the ID of the uploaded document.
* **Document Size 2**: This field is not used.
* **Document Type 4**: This field is not used.

Note: The form requires the user to select the type of document to be uploaded, but it does not enforce the selection of a specific document type. Therefore, users can choose any document type for upload, including "Player Registration and Document Upload".
