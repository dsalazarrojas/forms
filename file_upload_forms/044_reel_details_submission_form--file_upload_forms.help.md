# Reel Details Submission Form - Help Guide
## Purpose
This form is used to collect and store detailed information about a reel, including title, image, video, audio, description, tags, and file attachments. The information gathered from this form will be used for internal purposes and may be used in conjunction with other forms and tools.

## How To Complete This Form
To complete this form, follow these steps:

1. **Reel Details**: Enter a brief title for your reel in this text field.
2. **Reel Image**: Upload or enter the URL of the image that represents your reel.
3. **Reel Video**: Enter a link or upload the video file for your reel.
4. **Reel Audio**: Enter a link or upload the audio file for your reel.
5. **Reel Description**: Add a detailed description of your reel in this text field.
6. **Reel Tags**: Select all applicable tags for your reel from the multiple-select list.
7. **Reel Tags 2**: Select a single tag for your reel from the single-select list.
8. **Reel File**: Attach a file to your reel, if required.

## Field-by-Field Explanation

* **Reel Details (reel_details)**: This is the main title of your reel. Enter a short and descriptive title that summarizes the content of your reel.
* **Reel Image (reel_image)**: This is the image that represents your reel. You can either upload a new image or enter a URL of an existing image.
* **Reel Video (reel_video)**: This is the video that is part of your reel. You can either enter a link to a video or upload a video file.
* **Reel Audio (reel_audio)**: This is the audio file that is part of your reel. You can either enter a link to an audio file or upload an audio file.
* **Reel Description (reel_description)**: This is a detailed description of your reel. Add as much information as you need to help others understand your content.
* **Reel Tags (reel_tags)**: Select all applicable tags for your reel from the multiple-select list. These tags will help categorize and filter your reel for easier searching.
* **Reel Tags 2 (reel_tags_2)**: Select a single tag for your reel from the single-select list. This tag will help further categorize and filter your reel.
* **Reel File (reel_file)**: Attach a file to your reel, if required. This can be any type of file that is relevant to your content.

## Tips

* Make sure to fill out all required fields for accurate and complete information.
* Use clear and concise language when filling out the Reel Description field.
* Use relevant tags to help others find your reel.
* Ensure that all attached files are relevant to your reel content.
