# Training Assignment Submission Form - Help Guide
## Purpose
This form is designed to collect information about submitted training assignments, including the type of file submitted, description, submission status, submitter's identity, and submission timestamp.

## How To Complete This Form
1. Select one of the options for "What type of file is this?" to indicate the type of file submitted. This field is required.
2. Enter a description of the submitted file in the "Description" field. This field is also required.
3. Indicate if the submission is "Yes" or "No" for "Submit Training Assignment". This field is not required.
4. Choose one or multiple submitter's identity from the "Who submitted this?" field. This field is required.
5. Enter the date and time of submission in the "Date Submitted" and "Time Submitted" fields, respectively.
6. Select one of the options for "Training Assignment Submission Form 7", "Training Assignment Submission Form 8", "Training Assignment Submission Form 9", or "Training Assignment Submission Form 10" if applicable, to provide additional information about the submission. These fields are not required.
7. Finally, click submit to complete the form.

## Field-by-Field Explanation
* **What type of file is this?** (`training_assignment_submission_form_1`, select_multiple, required): Choose the correct type of file submitted, such as "True", "False", or other options.
* **Description** (description, text, required): Provide a brief description of the submitted file.
* **Submit Training Assignment** (training_assignment_submission_form_3, select_one, not required): Indicate if the submission is valid or not.
* **Who submitted this?** (submitted_by, select_multiple, required): Choose one or multiple submitter's identity.
* **Date Submitted** (date_submitted, date, required): Enter the date of submission.
* **Time Submitted** (time_submitted, time, required): Enter the time of submission.
* **Training Assignment Submission Form 7** (training_assignment_submission_form_7, select_one, not required): Select one of the options for additional information.
* **Training Assignment Submission Form 8** (training_assignment_submission_form_8, select_multiple, required): Choose one or multiple options for additional information.
* **Training Assignment Submission Form 9** (training_assignment_submission_form_9, text, required): Enter additional information about the submission.
* **Training Assignment Submission Form** (training_assignment_submission_form_10, select_one, not required): Select one of the options for additional information.
* **Training Assignment Submission Form 7** is used for other types of submissions that do not fit into the main categories.
* **Training Assignment Submission Form 8** is used to confirm that the submission is valid.
* **Training Assignment Submission Form 9** is used to provide more details about the submission.
* **Training Assignment Submission Form 10** is used for other types of submissions.
* Note: The fields with the same name (e.g., "Training Assignment Submission Form 8" and "Training Assignment Submission Form 9") have different labels and are not directly related.
 
## Tips
* Make sure to select the correct type of file submitted.
* Fill out all required fields to ensure accurate submission information.
* Be mindful of the time and date submitted, as this is a crucial part of the submission information. 
* If unsure about the type of file or submission, ask a supervisor or colleague for guidance.
