# PDF Submit Form - Help Guide
## Purpose
The PDF Submit Form is used to submit files for processing. This form collects information about the submitter and their uploaded file.

## How To Complete This Form
To complete the PDF Submit Form, follow these steps:

1. **Click on the "Upload PDF" field to select and upload a PDF file from your computer or provide the URL of a publicly accessible PDF file if you do not have a file to upload.**

## Field-by-Field Explanation
* **Upload PDF**: 
	+ Upload a PDF file by clicking on this field and selecting the file from your computer. You can also enter the URL of a publicly accessible PDF file if you do not have a file to upload.
* **Submission Date**: 
	+ Enter the date of the submission in the format of YYYY-MM-DD (e.g., 2022-01-01).
* **Email**: 
	+ Enter a valid email address to receive updates and notifications.
* **Phone**: 
	+ Enter a phone number to be contacted in case we need more information.
* **Description**: 
	+ Enter a brief description of the file you are submitting (e.g., "Report on Project X").
* **Uploaded By**: 
	+ Enter your name as it appears on your ID or business card.
* **Upload Date**: 
	+ This field is not used, but is included for potential future use.
* **File URL**: 
	+ Enter the URL of a publicly accessible PDF file if you do not have a file to upload.
* **File Name**: 
	+ Enter a name for the file as it will be stored and referenced.
* **Notes**: 
	+ Enter any additional comments or notes related to the submission.
* **Submission File**: 
	+ Confirm that the file you uploaded is correct before submitting.
