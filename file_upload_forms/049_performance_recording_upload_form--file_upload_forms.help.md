# Performance Recording Upload Form - Help Guide
## Purpose
The Performance Recording Upload Form is used to upload performance recordings and provide metadata for easy access and reference.

## How To Complete This Form
To complete this form, follow these steps:

* Ensure you are uploading a relevant performance recording and that you have not already uploaded this recording.
* Fill out the form with the required information:
	+ Performer Name: Enter the name of the performer who is featured in the recording.
	+ Recording File: Upload the performance recording file.
	+ Performance Type: Select the type of performance (e.g. music, dance, etc.).
	+ Event Name: Enter the name of the event where the performance took place.
	+ Event Date: (Optional) Enter the date of the event.
	+ Event Time: (Optional) Enter the time of the event.

## Field-by-Field Explanation
* **Performer Name** (`performer_name`, `text`, required): Enter the name of the performer who is featured in the recording.
* **Recording File** (`recording_file`, `text`, required): Upload the performance recording file.
* **Performance Type** (`performance_type`, `select_one`, required): Select the type of performance (e.g. music, dance, etc.).
* **Event Name** (`event_name`, `text`, required): Enter the name of the event where the performance took place.
* **Event Date** (`event_date`, `date`, optional): (Optional) Enter the date of the event. Please use the standard date format (e.g., YYYY-MM-DD).
* **Event Time** (`event_time`, `time`, optional): (Optional) Enter the time of the event. Please use the standard time format (e.g., HH:MM:SS).

## Tips
* Please ensure that the recording file is in a compatible format (e.g. WAV, MP3, etc.) before uploading.
* If you are unsure about the performance type or event details, please contact your administrator for clarification.
