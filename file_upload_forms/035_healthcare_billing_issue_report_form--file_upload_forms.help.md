# Healthcare Billing Issue Report Form - Help Guide
## Purpose
This form is used to report issues or concerns with healthcare billing to the healthcare provider's billing department. This may include errors, discrepancies, or problems with billing statements.

## How To Complete This Form
1. Enter the title of the form in the "Healthcare Billing Issue Report Form" field.
2. Upload a document or reference number related to the issue (if applicable).
3. Provide the patient's name as it appears on the billing records.
4. Select the reason for the issue using the provided options or select "Other (specify)" and provide a brief description.
5. Choose your preferred method of contact for follow-up (phone, email, text message, or mail).
6. Provide your preferred contact information (phone number, email, or physical address).
7. Add any additional comments or details about the issue in the "Form Comments" field.

## Field-by-Field Explanation

* **Healthcare Billing Issue Report Form** (`form_title`, text, optional): Enter a brief title to identify the form and the issue being reported.
* **Upload Document** (`upload_document`, text, optional): If you have a document related to the issue, you can upload it here. This could be a PDF, image, or other file type.
* **Patient Name** (`patient_name`, text, optional): Please enter the patient's name as it appears on the billing records.
* **Billing Concern** (`billing_concern`, select_one, optional): Select one of the provided options or select "Other (specify)" to describe the specific issue. Options include:
	+ Overcharge
	+ Undercharge
	+ Missing Charges
	+ Incorrect Bill
	+ Unpaid Bill
	+ Other (specify)
* **Issue Description** (`issue_description`, text, optional): Provide a brief description of the issue, if selected as "Other (specify)" or if the issue is not listed in the provided options.
* **Contact Preferred** (`contact_preferred`, select_one, optional): Choose your preferred method of contact for follow-up.
	+ Phone
	+ Email
	+ Text Message
	+ Mail
* **Contact Details** (`contact_details`, text, optional): Enter your preferred contact information for follow-up, if selected as "Phone" or "Mail".
* **Contact Phone** (`contact_phone`, text, optional): Enter your phone number if "Phone" is selected as the preferred method of contact.
* **Contact Email** (`contact_email`, email, optional): Enter your email address if "Email" is selected as the preferred method of contact.
* **Form Comments** (`form_comments`, text, optional): Add any additional comments or details about the issue.

## Tips

* Please ensure that the issue has not been previously reported before filling out this form.
* If you are unsure about any part of the form, please contact the healthcare provider's billing department for guidance.
* If you need to report an urgent matter, please contact the billing department directly.
