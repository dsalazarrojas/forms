# dropbox_submission_form - Help Guide
## Purpose
The "dropbox_submission_form" is designed to collect specific types of information from users for a submission, such as submitting files, notes, and contact information.

## How To Complete This Form
To complete this form, follow these steps:

1. Determine if you have files to submit. If you do, select "Yes" in the "submit_files" field.
2. If you have files to submit, click on the "files_uploads_1" field and select the number of files you want to upload.
3. Enter any additional notes in the "notes" field.
4. If you have contact information to share, enter your email address in the "email" field and/or your phone number in the "phone" field.
5. Set the date of your submission in the "date" field.
6. Set the time of your submission in the "time" field.
7. Finally, confirm whether you have completed all required sections by reviewing the form. If everything looks correct, click the submit button.

## Field-by-Field Explanation
* **submit_files** (select_multiple, required: false): This field asks whether you have files to submit or not. Select "Yes" if you have files, and "No" otherwise.
* **files_uploads_1** (number, required: false): This field allows you to select the number of files you have to upload. Enter the number of files you want to upload, up to the maximum allowed amount.
* **files_uploads_2**, **files_uploads_3**, **files_uploads_4** (text, required: false): These fields are for entering file upload metadata. Enter file names, file types, or other relevant details about the files you are uploading.
* **notes** (note, required: false): Enter any additional notes or comments related to your submission.
* **email** (email, required: false): Enter your email address for contact purposes.
* **phone** (text, required: false): Enter your phone number for contact purposes.
* **date** (date, required: false): Set the date of your submission.
* **time** (time, required: false): Set the time of your submission.
