# Principal Resume Submission Form - Help Guide
## Purpose
This form is used to collect detailed information from principals, including their contact details, educational background, and professional experience. It helps the administration or HR personnel to evaluate the eligibility and qualifications of applicants.

## How To Complete This Form
1. Fill in the required fields as accurately and comprehensively as possible.
2. Upload a resume that represents your current and relevant experience, skills, and achievements.
3. Review each field carefully before submitting the form.

## Field-by-Field Explanation
* **Principal Name**: A field to input your name as a principal.
	+ Type: Text
	+ Required: True
* **School Address**: A field to input your school's address.
	+ Type: Text
	+ Required: True
* **Email**: A field to input your email address.
	+ Type: Email
	+ Required: True
* **Phone**: A field to input your contact phone number.
	+ Type: Text
	+ Required: True
* **Resume Attachment**: A field to upload a resume or document that represents your professional history.
	+ Type: Text
	+ Required: True
* **Resume**: A field to input a brief description of your resume.
	+ Type: Text
	+ Required: True
* **Resume Type**: A field to select the type of resume uploaded (e.g., teaching, administrative, etc.).
	+ Type: Select One
	+ Required: False
* **Principal Experience**: A field to input the number of years of principal's experience.
	+ Type: Number
	+ Required: True
* **Years of Experience**: A field to input the total number of years of experience.
	+ Type: Number
	+ Required: False
* **School District**: A field to input the school district you work in.
	+ Type: Text
	+ Required: True
* **School Boards Achieved**: A field to select the school boards you have achieved.
	+ Type: Select Multiple
	+ Required: True
* **Resume Upload Instructions**: A field to provide any additional information about your uploaded resume.
	+ Type: Text
	+ Required: False
* **Additional Information**: A field to provide any additional details about your qualifications.
	+ Type: Text
	+ Required: False
* **Principal References**: A field to input any relevant references.
	+ Type: Text
	+ Required: False
* **School Board Certifications**: A field to select the school board certifications you have achieved.
	+ Type: Select Multiple
	+ Required: False

## Tips
- Please ensure that all required fields are filled accurately and comprehensively.
- Upload a resume that represents your current and relevant experience, skills, and achievements.
- Review each field carefully before submitting the form.
- If you have any doubts or concerns, please contact the relevant department or authority for further clarification.
