# Digital Art Print Order Form - Help Guide
## Purpose
This form is used to order a digital art print. Please fill out the form with the required information to ensure a smooth ordering process.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill out the print order details on Page 1.
2. Upload your digital file on Page 2.
3. Provide payment information on Page 3.
4. Confirm your order details and submit the form.

## Field-by-Field Explanation

### Page 1: Print Order

* **Print Order**: Enter the print details for your digital art print. (Required)
* **File Upload**: Upload your digital file. (Optional)
* **File Size**: Select the file size in MB or GB. (Required)
* **File Type**: Select the type of file you are uploading (e.g., image, document, video, or audio). (Required)
* **Price**: Enter the price of your digital art print. (Required)
* **Payment Amount**: Enter the amount you are paying for your order. (Required)
* **Currency**: Select the currency for your payment (e.g., USD, EUR, or GBP). (Required)
* **Payment Method**: Select the payment method you want to use (e.g., credit card or PayPal). (Required)
* **Email**: Enter your email address for communication. (Required)
* **Phone**: Enter your phone number for contact. (Optional)

### Page 2: File Details

* **File Name**: Enter the name of your digital file. (Required)
* **File Type**: Select the type of file (e.g., JPG, PNG, GIF, or BMP). (Required)
* **File URL**: Enter the URL of your file if you don't want to upload it here. (Optional)
* **File Size (MB)**: Select the file size in MB. (Required)
* **File Resolution**: Enter the file resolution (e.g., 1000, 2000, etc.). (Optional)
* **File Color Mode**: Select the color mode of your file (e.g., RGB, CMYK, or LAB). (Optional)
* **File Compression**: Select the compression method (e.g., none or lossless). (Optional)
* **File Print Size**: Select the print size (e.g., A4, A5, or A6). (Optional)
* **File Print Orientation**: Select the print orientation (e.g., portrait or landscape). (Optional)
* **File Print Finish**: Select the print finish (e.g., glossy, matte, or pearlescent). (Optional)

### Page 3: Confirmation

* **Date**: Enter the date for your order. (Required)
* **Time**: Enter the time for your order. (Required)

Note: The fields marked as (Required) are mandatory and need to be filled out.
