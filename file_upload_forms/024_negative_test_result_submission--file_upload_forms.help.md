# Negative Test Result Submission - Help Guide
## Purpose
This form is used to submit negative test results for quality control and verification.

## How To Complete This Form

1. Enter the test date in the "Test Date" field. This should be the date the test was performed.
2. Select the "Test Result" from the dropdown list, indicating that the test result is negative.
3. Upload the relevant file by clicking on the "Upload File 1" button.
4. Enter the contact name and email of the person who performed the test. This will allow us to get in touch with them for further questions or information.
5. Enter the name of the event or project associated with this test result, if applicable.
6. Optionally, enter the name of the organization and department responsible for this test result, if applicable.
7. Enter the tracking ID, which is a unique identifier for this submission.

## Field-by-Field Explanation

* **Test Result Submission** (`test_result_submission`, text, optional): A field to enter a brief description or notes about the test result submission.
* **Test Date** (`test_date`, date, required): Enter the date of the test in the correct format.
* **Upload File 1** (`file_upload_0`, text, required): Upload the relevant file, such as a photograph or document, associated with the test result.
* **Contact Name** (`contact_name`, text, optional): Enter the name of the person who performed the test.
* **Contact Email** (`contact_email`, email, required): Enter the email address of the person who performed the test.
* **Contact Phone** (`contact_phone`, text, optional): Enter the phone number of the person who performed the test.
* **Event Name** (`event_name`, text, optional): Enter the name of the event or project associated with this test result.
* **Organization** (`organization`, text, optional): Enter the name of the organization responsible for this test result.
* **Department** (`department`, text, optional): Enter the department responsible for this test result.
* **Tracking Id** (`tracking_id`, number, required): Enter a unique tracking ID for this submission.
