# operating-statement-submission - Help Guide
## Purpose
This form is for submitting an operating statement, which is a document that provides information about the operating activities, financial performance, and other relevant data of an organization or entity. The operating statement is used for internal review and decision-making purposes, and it's essential for ensuring accurate and transparent financial reporting.

## How To Complete This Form
To complete this form, please follow these steps:

1. Provide a brief description of your operating statement.
2. Specify the reporting period for which you're submitting the operating statement.
3. Select the reporting date for the submitted operating statement.
4. Choose the time of day when the reporting date is valid (AM/PM).
5. Upload any relevant supporting documents, such as financial reports or data sheets.

## Field-by-Field Explanation
* **operating_statement (text)**: A brief description of the operating statement, which should include essential details about the organization's or entity's activities, financial performance, and other relevant data.
* **reporting_period (number)**: The time period for which you're submitting the operating statement. Please enter the number of months or quarters for which you're reporting.
* **reporting_date (date)**: The date when the reporting period starts. Please follow the standard date format (YYYY-MM-DD).
* **reporting_time (time)**: The AM/PM indicator for the reporting date. Select either AM or PM to indicate the correct time of day.
* **supporting_documents (text)**: Upload any relevant documents that support your operating statement, such as financial reports or data sheets.
