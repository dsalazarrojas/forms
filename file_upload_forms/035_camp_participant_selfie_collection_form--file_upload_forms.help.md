# Camp Participant Selfie Collection Form - Help Guide
## Purpose
This form collects participant selfies from campers for various purposes such as ID badges, activity participation, group yearbooks, social media features, and staff recognition. The collected selfies are stored in the camp's secure database and used for specific purposes as granted by the participant.
## How To Complete This Form
To complete this form, follow the instructions below:

1. Click on the "Begin" button to start the form.
2. Fill out the form by providing your personal details and uploading your selfie.
3. In the "Photo Purpose" field, select the primary reason for submitting this photo.
4. Ensure the selfie meets the provided upload instructions before uploading it.
5. Enter the "File Name or Reference ID" provided by the upload tool.
6. Select the "Who is uploading this photo?" option to identify who is uploading the photo.
7. Read and acknowledge the "Privacy and Security Acknowledgment" option.
8. Enter the "Date of Photo" when you took the selfie.
9. Add any additional notes or context for the photo (optional).
10. Enter a verification code if required.
## Field-by-Field Explanation
* **Participant Full Name** (`participant_full_name_selfie`, `text`, required): Enter your full name as it should be displayed on the ID badge or yearbook.
* **Camper ID Number (Optional)** (`camper_id_number_selfie`, `text`, required): Enter your camper ID number if applicable.
* **Cabin or Group Name** (`cabin_group_assignment_selfie`, `text`, required): Enter the name of your cabin or group, e.g., "Oak Cabin" or "Trailblazers".
* **Primary Purpose of this Photo** (`photo_purpose_selfie`, `select_one`, required): Select the primary purpose of this photo from the provided options:
	+ ID Badge / Profile Photo
	+ Activity Participation Evidence
	+ Group Yearbook - Memory Book
	+ Social Media Feature
	+ Staff Recognition
* **File Name or Reference ID** (`uploaded_file_reference_selfie`, `text`, required): Enter the file name or reference ID provided by the upload tool.
* **Consent to Use this Photo** (`photo_use_consent_selfie`, `select_one`, required): Select "I Consent" to grant permission to use the photo for the specified purpose.
* **Privacy and Security Acknowledgment** (`privacy_acknowledgment_selfie`, `select_one`, required): Select "I Acknowledge" to understand that the photo will be stored in the camp's secure database.
* **Date of Photo** (`selfie_submission_date`, `date`, required): Enter the date when you took the selfie.
* **Who is uploading this photo?** (`uploader_role_selfie`, `select_one`, required): Select who is uploading this photo:
	+ The Participant
	+ Parent - Guardian
	+ Camp Counselor - Staff
* **Additional Notes or Context** (`additional_photo_notes`, `text`, optional): Enter any additional information or context related to the photo.
* **Verification Code (If Applicable)** (`submission_verification_code`, `text`, optional): Enter a verification code if required.
* **Selfie Upload Instructions** (`photo_upload_placeholder`, `note`, required): Ensure the selfie meets the provided upload instructions before uploading it.
* **Selfie Upload Instructions (Example)** (`photo_upload_placeholder`, `note`, required): Please ensure the photo is clear, shows only your face, and has a neutral background.
