# tedx_talk_submission_form - Help Guide
## Purpose
The tedx_talk_submission_form is used to collect information about speakers and their proposed talks for the TEDx conference.

## How To Complete This Form
To fill out this form, follow these steps:

1. Scroll through the form pages to find the relevant sections.
2. Fill in the required and optional fields as needed.

## Field-by-Field Explanation
* **Speaker Information** (`speaker_info`, text, required: false): This field is used to input the speaker's information.
* **Talk Title** (`talk_title`, text, required: false): This field is used to input the title of the talk.
* **Abstract** (`abstract`, text, required: false): This field is used to input a brief description of the talk.
* **Bio** (`bio`, text, required: false): This field is used to input a brief biography of the speaker.
* **Video URL** (`video_url`, text, required: false): This field is used to input a URL of a video related to the talk.
* **Supporting Materials** (`supporting_materials`, text, required: false): This field is used to input any additional materials related to the talk.
* **Image URL** (`image_url`, text, required: false): This field is used to input a URL of an image related to the talk.
* **Submitter Information** (`submitter_info`, text, required: false): This field is used to input information about the person submitting the talk.

## Tips
* Please ensure that you're submitting a valid talk proposal.
* Review your submission carefully before submitting it.
* Make sure you fill in all required fields.
