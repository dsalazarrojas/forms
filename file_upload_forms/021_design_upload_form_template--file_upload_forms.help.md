### Design Upload Form Template - Help Guide

### Purpose
This form is designed to collect information about a design project, including project details, status, and file uploads. It is intended for use in a project management or design submission context.

### How To Complete This Form
To complete this form, follow these steps:

1. Select the project status and type from the provided options.
2. Provide a brief project description.
3. Upload design files by selecting the "Upload Design File" fields (e.g., "Upload Design File", "Upload Design File 2", etc.).
4. Enter project details such as project start date, deadline, and URL(s) as required.
5. Select "Submit" to submit the project.
