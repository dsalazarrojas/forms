# Stock Image Requisition Form - Help Guide

## Purpose
The Stock Image Requisition Form is used to request images for a project. It collects information about the project, the type of image needed, and other relevant details to facilitate the image requisition process.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the **Project Description** field with a brief description of the project that requires the image.
2. Select the type of image needed from the **Image Type** dropdown menu.
3. Enter the number of images required for the project in the **Project Image Count** field.
4. Enter your email and phone number to contact you.
5. Click the **Submit** button to submit your request.

## Field-by-Field Explanation

* **Project Description** (`project_description`, text, required): Briefly describe the project that requires the image.
* **Image Type** (`image_type`, select_one, required): Select the type of image you need, such as "photo", "graphic", or "illustration".
* **Project Image Count** (`project_image_count`, number, required): Enter the total number of images you need for your project.
* **Email** (`email`, email, required): Enter your email address so we can contact you regarding your image requisition.
* **Phone** (`phone`, text, required): Enter your phone number so we can contact you regarding your image requisition.

Note: The **Submit** button is not a field, but a button that you click to submit your requisition request.
