# Investment Proposal Submission Form - Help Guide
## Purpose
The purpose of this form is to collect and store information about investment proposals submitted to the organization for review and consideration.

## How To Complete This Form
To complete this form, please follow these steps:

1. Choose a funding request from the list provided.
2. Enter a brief description of the project being proposed.
3. Select the location(s) of the project.
4. Enter the estimated investment amount.
5. Choose the submission date for the proposal.
6. Select the review status of the proposal (Not Reviewed, Approved, or Rejected).
7. Set the review date (if applicable).

## Field-by-Field Explanation

* **Funding Request**: Select the type of funding you are requesting. (Funding Request 1, Funding Request 2, Funding Request 3)
* **Project Description**: Enter a brief description of the project, including its objectives and goals.
* **Project Location**: Select all locations where the project will be implemented or conducted.
* **Investment Amount**: Enter the estimated investment amount required for the project.
* **Submission Date**: Enter the date the proposal is submitted for review.
* **Review Status**: Select the current status of the review process (Not Reviewed, Approved, or Rejected).
* **Review Date**: Enter the date the review was completed (if applicable).

## Tips

* Ensure that all fields are completed accurately and thoroughly.
* Check that the proposal is aligned with the organization's funding priorities before submitting.
* If you are unsure about any aspect of the form, please contact the relevant department for assistance.
