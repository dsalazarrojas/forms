# Vendor Booth Image Upload Form - Help Guide
## Purpose
This form is designed to collect information and files related to vendor booths, including exhibitor photos, vendor details, event name, booth number, photo URL, uploaded files, and event date. The form is used to support event management and organization.

## How To Complete This Form
To complete the form, please follow these steps:

1. Select the exhibitor booth photos by choosing one or more options from the dropdown menu.
2. Enter the vendor details in the text field.
3. Enter the event name in the text field.
4. Enter the booth number in the text field.
5. Enter the photo URL in the text field.
6. Upload a file by clicking the "Browse" button and selecting the file from your computer.
7. Enter the event date in the date field.

## Field-by-Field Explanation

* **Exhibitor Booth Photos** (`exhibitor_booth_photos`, select_multiple, optional): Choose one or more photos from the list to upload for your exhibitor booth.
* **Vendor Details** (`vendor_details`, text, optional): Enter any additional information about your vendor, such as a brief description or contact information.
* **Event Name** (`event_name`, text, optional): Enter the name of the event where you will be exhibiting.
* **Booth Number** (`booth_number`, text, optional): Enter the number of your booth at the event.
* **Photo URL** (`photo_url`, text, optional): Enter a URL of an image of your booth photo, if you don't want to upload a file.
* **File** (`file`, text, optional): Upload a file by clicking the "Browse" button and selecting the file from your computer.
* **Event Date** (`event_date`, date, optional): Enter the date of the event where you will be exhibiting.

## Tips

* Make sure to fill out all required fields (none are required in this form).
* If you have multiple photos, you can choose more than one option from the dropdown menu.
* If you upload a file, please make sure it is in a compatible format (e.g. JPEG, PNG, PDF).
* If you have any doubts or issues with the form, please contact us at [form@gic.mx](mailto:form@gic.mx).
