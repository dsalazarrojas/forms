# Roof Skylight Planning Permission Application - Help Guide

## Purpose
The Roof Skylight Planning Permission Application form is used to gather necessary information from users who are planning to install skylights on their roofs.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in your User Name and Project Address fields.
2. Select the correct Property Type (House, Apartment, or Condo) that corresponds to your project.
3. Provide a brief description of the project in the Project Details field.
4. Choose the correct Roof Type (Flat, Pitched, or Curved) for your project.
5. Enter the size of your project in square units (e.g., 100 square meters) in the Building Size field.
6. Enter the number of stories (if applicable) in the Number of Stories field.
7. Enter the floor area (in square meters) in the Floor Area field.
8. Enter the height of your project in meters in the Height field.
9. Enter the latitude and longitude coordinates of your project location in the Latitude and Longitude fields.
10. Upload any supporting files relevant to your project in the File 1, 2, 3, and 4 fields, if applicable.

## Field-by-Field Explanation

* **User Name**: Enter your full name as it appears on official documents.
* **Project Address**: Enter the address of the project location.
* **Property Type**: Select the type of property you own or are responsible for (House, Apartment, Condo).
* **Project Details**: Provide a brief description of the project, including any relevant details or notes.
* **Roof Type**: Select the type of roof you are planning to install skylights on (Flat, Pitched, or Curved).
* **Building Size**: Enter the size of the building in square units (e.g., 100 square meters).
* **Number of Stories**: Enter the number of stories (levels) in the building, if applicable.
* **Floor Area**: Enter the floor area of the building in square meters.
* **Height**: Enter the height of the building in meters.
* **Latitude**: Enter the latitude coordinates of your project location.
* **Longitude**: Enter the longitude coordinates of your project location.
* **File 1, 2, 3, 4**: Upload any supporting files relevant to your project (e.g., blueprints, plans, photos).

Note: The file upload fields allow you to attach relevant documents or images to support your application. You can upload up to four files per field.
