# Disk Information Submission Form - Help Guide
## Purpose
The Disk Information Submission Form is used to submit information about disk devices, allowing users to accurately record and track disk details for further analysis and management.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the storage device name in the `Storage Device` field.
2. Type in the serial number of the disk in the `Serial Number` field.
3. If applicable, enter the disk capacity in the `Disk Capacity` field in GB.
4. Select the interface type (SATA, PCIe, or NVMe) from the options provided in the `Interface Type` field.
5. Specify the storage location in the `Storage Location` field.
6. Choose the storage status (Active, Offline, or Decommissioned) from the options provided in the `Storage Status` field.
7. Enter any additional remarks in the `Remarks` field. This is an optional field for any further comments about the disk.
8. If applicable, upload the file related to the disk in the `Upload File` field.
9. Select the team or team member responsible for the disk from the options provided in the `Assigned To` field.

## Field-by-Field Explanation
- **Storage Device**: <small>This field is required for identifying the disk you are submitting information about. It should match the name of the storage device.</small>
- **Serial Number**: <small>Enter the serial number of the disk. This is a unique identifier for the disk.</small>
- **Disk Capacity**: <small>If known, enter the capacity of the disk in GB.</small>
- **Interface Type**: <small>Choose the interface type of the disk from the provided options.</small>
- **Storage Location**: <small>Specify the location where the disk is currently stored.</small>
- **Storage Status**: <small>Choose the status of the disk from the provided options.</small>
- **Remarks**: <small>This field is for any additional comments or observations you may have about the disk.</small>
- **Upload File**: <small>This is an optional field for uploading a file related to the disk. Ensure that you have permission to upload files.</small>
- **Assigned To**: <small>Choose the team or team member responsible for the disk from the provided options.</small>
