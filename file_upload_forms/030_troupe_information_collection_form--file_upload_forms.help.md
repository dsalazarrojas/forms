# Troupe Information Collection Form - Help Guide
## Purpose
This form collects information about a troupe (a group of performers or actors) for internal purposes.

## How To Complete This Form
- To complete this form, simply follow the instructions for each field.
- Enter the required information accurately and thoroughly.
- If you're unsure about a specific field, refer to the field-by-field explanation below.

## Field-by-Field Explanation
- **Troupe Information** (`troupe_info`, text, optional): Enter a brief description or name of the troupe.
  This field should contain the name or description of the troupe. If you're unsure about the name, you can also enter a brief description.
- **Files Upload** (`files_upload`, text, optional): Please upload any relevant files or documents related to the troupe.
  This field allows you to attach files that are relevant to the troupe, such as images, videos, or documents. This can be useful for future reference.
- **Performer Details** (`performer_details`, select_multiple, optional): Select one or more of the following options to describe the performer(s) in the troupe:
  - **Name**: Enter the performer's name.
  - **Age**: Enter the performer's age.
  - **Contact Info**: Enter the performer's contact information.
  Please select one or more of the above options to provide details about the performers in the troupe.
- **Promotional Materials** (`promotional_materials`, text, optional): Enter any promotional materials (e.g., images, videos, or text) related to the troupe.
  This field is intended for promotional purposes, such as attaching images or videos of the troupe's performances.
- **Permissions** (`permissions`, select_one, optional): Select the correct option to describe the troupe's permissions:
  - **True**: Indicate that the troupe has given permission for the project/initiative.
  - **False**: Indicate that the troupe has not given permission for the project/initiative.
  This field helps to track the troupe's permission status for the project or initiative.
- **Other (if not above)** (`permissions_other`, text, optional): Enter any additional information regarding the troupe's permissions if not listed above.
  This field is meant for any other permission-related information that doesn't fit in the above options.
- **Other** (`permissions_other_text`, text, optional): Enter any text to describe the "Other" permission status.
  This field allows you to provide a brief description of the "Other" permission status.
- **Troupe Additional Info** (`troupe_info_additional`, text, optional): Enter any additional information about the troupe.
  This field is intended for any extra details that don't fit in the other fields.

## Tips
- Be thorough and accurate when filling out the form.
- If you're unsure about a field, refer back to the field-by-field explanation above.
- This form should only be filled out once per troupe to avoid duplication.
