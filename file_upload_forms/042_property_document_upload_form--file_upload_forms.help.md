# Property Document Upload Form - Help Guide
## Purpose
The Property Document Upload Form is used to collect and manage property-related documents. This form allows users to upload and store documents associated with properties, ensuring that the required information is accurately and efficiently submitted.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the Property Document Upload Form title to provide a brief description of the document being uploaded.
2. Enter the property details, if necessary, to provide additional context about the property associated with the document.
3. Select the document type from the available options (Building, Condo, or Land).
4. Upload the document by selecting the file from your computer or device.
5. Specify the authorization level for the uploaded document (Owner, Manager, or Employee).
6. Enter the date and time the document was submitted.
7. Add any additional note about the document, if needed.
8. Enter the email address of the person submitting the document.
9. Enter the phone number of the person submitting the document.
10. Specify the file size in bytes or kilobytes.
11. Enter the file type.
12. Enter the file name.
13. Enter the file extension.
14. Specify the file size unit (e.g., bytes, kilobytes, megabytes).
15. Enter the uploaded file URL.
16. Enter the date and time the document was created.
17. Enter the date and time the document was updated.
18. Enter the date and time the document was deleted.

## Field-by-Field Explanation

* **Property Document Upload Form** (`form_title`): Enter a brief description of the document being uploaded.
* **Property Details** (`property_details`): Provide additional context about the property associated with the document.
* **Document Type** (`document_type`): Select the type of document being uploaded (Building, Condo, or Land).
* **Document Upload** (`document_upload`): Upload the document by selecting the file from your computer or device.
* **Authorization** (`authorization`): Specify the level of authorization for the uploaded document (Owner, Manager, or Employee).
* **Date Submitted** (`date_submitted`): Enter the date and time the document was submitted.
* **Note** (`note`): Add any additional note about the document, if needed.
* **Email** (`email`): Enter the email address of the person submitting the document.
* **Phone** (`phone`): Enter the phone number of the person submitting the document.
* **File Size** (`file_size`): Specify the file size in bytes or kilobytes.
* **File Type** (`file_type`): Enter the file type.
* **File Name** (`file_name`): Enter the name of the uploaded file.
* **File Extension** (`file_extension`): Enter the file extension.
* **File Size Unit** (`file_size_unit`): Specify the file size unit (e.g., bytes, kilobytes, megabytes).
* **Uploaded File** (`uploaded_file`): This field is not applicable as it is not a field in the form.
* **Submitted By** (`submitted_by`): Enter the name of the person submitting the document.
* **Form Title** (`form_title`): This field is not applicable as it is not a field in the form.
* **Property Status** (`property_status`): Enter the status of the property associated with the document.
* **Property ID** (`property_id`): Enter the ID of the property associated with the document.
* **Document Status** (`document_status`): Enter the status of the uploaded document.
* **File URL** (`file_url`): Enter the URL of the uploaded file.
* **Created At** (`created_at`): Enter the date and time the document was created.
* **Updated At** (`updated_at`): Enter the date and time the document was updated.
* **Deleted At** (`deleted_at`): Enter the date and time the document was deleted.
