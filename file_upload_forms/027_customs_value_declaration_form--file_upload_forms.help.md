# Customs Value Declaration Form - Help Guide
## Purpose
This form is used to collect and declare the customs value of a shipment for customs clearance purposes.

## How To Complete This Form
To complete this form, please follow these steps:

* Review the questions carefully and answer them accurately.
* Fill out each section of the form in the format and manner required.
* Ensure that all required fields are completed before submitting the form.

## Field-by-Field Explanation

* **Shipment Details**: Enter the details of the shipment, including the shipment number, date, and time. This information will help identify the shipment and ensure that it is processed correctly.
* **Shipment Type**: Select the type of shipment (Type or Type 2). This helps determine the customs declaration type and any additional requirements that apply.
* **Country of Origin**: Enter the country where the shipment originated from.
* **Country of Destination**: Enter the country where the shipment is going to.
* **Customs Declaration Number**: Enter the customs declaration number associated with the shipment.
* **Shipment Value**: Enter the total value of the shipment.
* **Shipment Weight**: Enter the weight of the shipment.
* **Shipment Description**: Enter a brief description of the shipment.
* **Customs Officer Name**: Enter the name of the customs officer responsible for the declaration.
* **Customs Officer Title**: Enter the title of the customs officer.
* **Customs Officer Department**: Enter the department of the customs officer.
* **Shipment Date**: Enter the date of the shipment.
* **Shipment Time**: Enter the time of the shipment.
* **Shipment Port Of Loading**: Enter the port of loading for the shipment.
* **Shipment Vessel Type**: Enter the type of vessel used for the shipment.
* **Shipment Vessel Name**: Enter the name of the vessel used for the shipment.
* **Shipment Vessel Number**: Enter the number of the vessel used for the shipment.
* **Shipment Vessel Type ID**: Enter the ID of the vessel type.
* **Shipment Hazardous Goods**: Select all applicable hazardous goods in the shipment.
* **Shipment Vessel Type Description**: Enter a description of the vessel type.
* **Shipment Customs Value Declaration**: Select the type of customs value declaration (Select One or Select Two).
* **Shipment Customs Declaration Status**: Enter the status of the customs declaration.
* **Shipment Customs Declaration Type**: Enter the type of customs declaration.
* **Shipment Exporter Name**: Enter the name of the exporter.
* **Shipment Exporter Address**: Enter the address of the exporter.

Note: The fields with a type of "select_one" or "select_multiple" require selecting one or multiple options from the list provided. Ensure to select only the applicable options.
