# Custom Greeting Card Design Request - Help Guide

## Purpose
This form is used to request a custom greeting card design for a special occasion or event. Please use this form to provide details about the card's style, size, message type, delivery information, and any additional preferences or requirements you may have.

## How To Complete This Form
To complete this form, please follow these steps:

1. Determine if you want a custom card style (Yes/No).
2. Choose the size of the card (Yes/No).
3. Select the type of message you want to display on the card (Yes/No).
4. Indicate if you have any special delivery information (Yes/No).
5. Provide the file attachment for the card (if applicable).
6. Enter the message you want to display on the card.
7. Add any additional style preferences.
8. Enter the expected delivery time.
9. Provide the name of the card recipient.
10. Enter the contact email of the person responsible for the delivery.
11. Enter the contact phone number of the person responsible for the delivery.
12. Enter the contact address of the person responsible for the delivery.

## Field-by-Field Explanation
* **Card Style**: Choose "Yes" if you want a custom card style, "No" if you want a standard card style.
* **Card Size**: Choose "Yes" if you want a custom card size, "No" if you want a standard card size.
* **Message Type**: Choose "Yes" if you want a custom message on the card, "No" if you want a standard message.
* **Delivery Info**: Choose "Yes" if you have special delivery information, "No" if no special delivery information is required.
* **File**: Upload any relevant files, such as images or documents, to help us understand your design requirements.
* **Message**: Enter the message you want to display on the card.
* **Style Preferences**: Enter any additional style preferences or requirements for your custom card design.
* **Delivery Time**: Enter the expected delivery time for the card.
* **Card Name**: Enter the name of the card recipient.
* **Contact Email**: Enter the email address of the person responsible for the delivery.
* **Contact Phone**: Enter the phone number of the person responsible for the delivery.
* **Contact Address**: Enter the address of the person responsible for the delivery.

## Tips
Please ensure that the information provided is accurate and clear, as it will be used to create a custom card design that meets your specific needs. If you have any questions or concerns, please do not hesitate to contact us.
