# entry_upload_form - Help Guide
## Purpose
The "entry_upload_form" is a form designed to collect and store information about entries, allowing users to input relevant details and categorize them accurately.

## How To Complete This Form
1. Fill out all required fields (marked as required in the form).
2. Enter your User Input in the **User Input** field (id: 1).
3. Upload your **Entry File** (id: 2), which is a mandatory field.
4. Select the appropriate **Category** (id: 3) from the dropdown menu.
5. (Optional) Select relevant **Tags** (id: 4) from the dropdown menu.
6. Click the **Submit** button (id: 5) to complete and create the new entry.

## Field-by-Field Explanation
* **User Input** (id: 1, text, required): Enter the relevant information for the entry, such as a description or details.
* **Entry File** (id: 2, text, required): Upload a file associated with the entry, such as a document or image.
* **Category** (id: 3, select_one, required): Choose the category for the entry from the available options.
* **Tags** (id: 4, select_multiple, optional): Select additional tags for the entry from the available options (if applicable).
* **Submit** (id: 5, text, required): Confirm the entry information and create a new entry.
