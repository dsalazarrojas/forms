# Video Submit Form - Help Guide
## Purpose
The Video Submit Form is a web-based form designed to help users upload new video content to the system. By filling out this form, you can submit a video for review and potential inclusion in the system.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out all required fields with accurate and relevant information.
2. Make sure to upload a valid video file using the "Upload Video" field.
3. Add a description of the video to help our team understand its context.
4. Choose relevant tags to categorize the video.
5. Select a category for the video.
6. Optionally, add a title for the video.

## Field-by-Field Explanation
* **Upload Video (<font size=".8">Upload a video file for review</font>):** Upload a video file that you would like to submit for review.
* **Video Link (<font size=".8">Enter a URL of the video</font>):** If you don't want to upload a file, you can enter a URL of the video that you would like to share.
* **Description (<font size=".8">Explain the context of the video</font>):** Add a brief description of the video to help our team understand its relevance and context.
* **Tags (<font size=".8">Add relevant keywords to the video</font>):** Choose relevant tags to categorize the video. You can select multiple tags by holding the Ctrl key while selecting.
* **Category (<font size=".8">Select a category for the video</font>):** Choose a category for the video to help our team understand its context.
* **Title (<font size=".8">Add a title for the video (optional)</font>):** Optionally, add a title for the video if you like.
* **Submit (<font size=".8">Confirm the video submission</font>):** Once you have filled out all necessary information, click on this button to submit your video for review.
* **Cancel (<font size=".8">Cancel the form submission</font>):** If you don't want to submit the video, click on this button to cancel the form submission.
