# Consultant Report Submission - Help Guide
## Purpose
This form is designed for consultants to submit their reports, including project status updates, findings, and recommendations, as well as any accompanying files and visual assets. It serves as a centralized platform for internal stakeholders to review and manage submissions.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the required fields with accurate and relevant information.
2. Select the most appropriate report category from the dropdown list.
3. Upload the full PDF report document and any additional supporting visual assets (if applicable).
4. Confirm compliance with data privacy and GDPR regulations.
5. Provide the authorized representative's name and the date of report submission.

## Field-by-Field Explanation

* **Report Title/Description** (`report_title_ident`): A brief title and description of the report.
	+ Enter a clear and concise title that summarizes the report's content.
* **Consultant Full Name or Legal Entity** (`consultant_full_name_ident`): The name of the consultant or the legal entity submitting the report.
	+ Enter the full name of the consultant or the name of the legal entity.
* **Consultant Contact Email** (`consultant_email_ident`): The email address of the consultant or authorized representative.
	+ Enter a valid email address for contact purposes.
* **Project Reference/Contract ID** (`project_reference_ident`): A unique identifier for the project or contract.
	+ Enter the project's or contract's reference number.
* **Internal Sponsor/Project Manager (Name)** (`internal_sponsor_ident`): The name of the internal sponsor or project manager.
	+ Enter the name of the internal sponsor or project manager.
* **Primary Report Category** (`report_type_ident`): Select the most appropriate category for the report from the dropdown list.
	+ Choose the category that best describes the report's content.
* **Executive Summary of Key Findings** (`executive_summary_desc`): A brief summary of the report's key findings.
	+ Limit to 1000 characters.
* **Primary Professional Recommendation** (`primary_recommendation_ident`): A clear and actionable advice.
	+ Provide one recommendation that addresses the report's purpose.
* **Full PDF Report Document Uploaded** (`report_pdf_uploaded_verified`): Confirm that the full PDF report document has been uploaded.
	+ Select "Yes - Uploaded to Portal" if uploaded.
* **Raw Data or Technical Appendix Uploaded (If Applicable)** (`raw_data_appendix_uploaded`): Confirm if raw data or technical appendix has been uploaded.
	+ Select "True" if uploaded, "False" otherwise, or "N/A" if not applicable.
* **Supporting Visual Assets Ready for Portal (PPT/Images)** (`visual_assets_uploaded_checklist`): Check all applicable visual assets.
	+ Select all relevant visual assets that support the report.
* **Acknowledgment of Data Privacy and GDPR Compliance** (`data_privacy_compliance_ack`): Acknowledge compliance with data privacy and GDPR regulations.
	+ Select "I Acknowledge and Confirm" to confirm compliance.
* **Authorized Representative Name** (`authorized_representative_name_label`): The name of the authorized representative.
	+ Enter the authorized representative's name.
* **Date of Report Submission** (`submission_date`): The date of report submission.
	+ Enter the date of submission.
* **Additional Submission Instructions or Notes** (`additional_submission_notes`): Any additional notes or instructions.
	+ Provide any additional information relevant to submission.
* **Internal Review Status (For Sponsor)** (`internal_review_status_auto_label`): The internal review status.
	+ This field is for internal use only.

Note to users: This form serves as a submission platform, and all fields are subject to review and validation to ensure accuracy and completeness of the submitted information. If you have any questions or concerns, please reach out to your internal sponsor or project manager.
