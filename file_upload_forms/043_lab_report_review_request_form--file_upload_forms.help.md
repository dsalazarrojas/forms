# Lab Report Review Request Form - Help Guide

## Purpose
This form is used to request a review of a lab report. It allows you to select the type of lab review required and provide relevant comments.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the lab type from the dropdown menu.
2. Enter the lab number in the text field.
3. Provide a brief description of the lab report in the text field.
4. Add any comments or notes regarding the review request in the text field.
5. Provide the reviewer's information in the text field.

## Field-by-Field Explanation
### **Select Lab Type** (id: 1, type: select_one)
Select the type of lab review required, such as Lab Type or Another Lab Type.

### **Lab Number** (id: 2, type: text)
Enter the lab number associated with the lab report you are requesting a review for.

### **Lab Report** (id: 3, type: text)
Briefly describe the lab report you are reviewing, including any relevant details or context.

### **Lab Report Review Comments** (id: 4, type: note)
Enter any comments or notes you have regarding the review request, such as additional information or instructions for the reviewer.

### **Reviewer Information** (id: 5, type: text)
Enter the reviewer's information, including their name, email, and any other relevant details.

## Tips
- Please ensure that you have a clear understanding of the lab report and the review request before submitting the form.
- Be concise and accurate when filling out the form.
- If you are unsure about any of the fields, please ask your supervisor or team lead for clarification.
