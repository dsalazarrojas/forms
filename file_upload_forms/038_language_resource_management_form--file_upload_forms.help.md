# Language Resource Management Form - Help Guide

## Purpose
The Language Resource Management Form is a tool used to manage language resources, including material details, usage rules, and file uploads. This form is designed to collect information about language materials, such as their status, version, and ownership, to ensure accurate and efficient management of language resources.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the "Material Details" field and choose "Yes" or "No" to indicate whether the material is available or not.
2. In the "Material Ownership" field, select "Yes" or "No" to specify who owns the material.
3. If the material is available, you can upload a file by providing a file name and description in the "File Upload" field.
4. In the "File Type" field, select one or more file types (e.g., "Yes" for one type, "No" for another).
5. Select the "Material Status" field and choose between "Active" and "Inactive" to indicate the material's status.
6. Enter the material's version in the "Material Version" field.
7. Provide the material's description in the "Material Description" field.
8. In the "Material Category" field, enter the category of the material.
9. Select the "Material Language" field and choose "Yes" or "No" to indicate the language of the material.
10. In the "Material Status 2" field, select between "Active" and "Inactive" to indicate the material's status.
11. Enter the material's version 2 in the "Material Version 2" field.
12. Provide the date of the material's version in the "Material Version Date" field.
13. In the "Created By" field, enter the name of the user who created the material.
14. In the "Date Uploaded" field, select the date the material was uploaded.
15. In the "Uploaded By" field, enter the name of the user who uploaded the material.
16. In the "Material Last Updated" field, select the date the material was last updated.
17. In the "Material Last Updated By" field, enter the name of the user who last updated the material.
18. Select the "Material Language 2" field and choose "Yes" or "No" to indicate the language of the material.
19. In the "Material Category 2" field, enter the category of the material.
20. In the "Material Description 2" field, enter a description of the material.
21. In the "Material Version 2" field, enter the version of the material.
22. In the "Material Version Date" field, select the date of the material's version.
23. In the "Material Version Author" field, enter the author of the material's version.
24. In the "Created By 2" field, enter the name of the user who created the material.
