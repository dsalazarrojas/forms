# Moot Court Brief Upload Form - Help Guide

## Purpose
The Moot Court Brief Upload Form is a tool for uploading files related to a particular case. It helps to categorize and organize files in a centralized location.

## How To Complete This Form
To complete this form, follow these steps:

1. Choose a category for the file from the dropdown menu. This will help the system to associate the file with the correct case and prevent duplication.
2. Provide a brief description of the file in the "Description" field. This will help users to easily identify the file when searching for it.
3. Upload the file by clicking on the "Upload File" field. Ensure that the file is relevant to the selected category and not a duplicate of an already uploaded file.
4. Enter your email address in the "Email" field. This will allow us to contact you with any updates or notifications.
5. Enter your phone number in the "Phone" field (optional). This will allow us to contact you directly if needed.

## Field-by-Field Explanation

* **Moot Court Brief Upload Form** (`form_title`, text, optional): Enter a title for the uploaded file. This will be displayed when searching for the file.
* **Category** (`category`, select_one, required): Choose a category for the file to associate it with the correct case and prevent duplication.
* **Description** (`description`, text, required): Briefly describe the uploaded file to help with organization and searchability.
* **Upload File** (`upload_file`, text, required): Upload the file relevant to the selected category.
* **Email** (`email`, email, required): Enter your email address to receive updates or notifications.
* **Phone** (`phone`, text, optional): Enter your phone number for direct contact.
