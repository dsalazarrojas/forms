# Dropbox Creative Brief Upload Form - Help Guide
## Purpose
The Dropbox Creative Brief Upload Form is a user-friendly interface for uploading files related to a creative brief in a structured and controlled manner.

## How To Complete This Form
To complete this form, simply fill out the required fields and upload the relevant files. Please make sure to select the correct category and choose the correct files to be uploaded.

## Field-by-Field Explanation
* **Form title** (`form_title`, text, optional): Provide a title for the form, which will be displayed as a header for the uploaded content.
* **Form description** (`form_description`, text, optional): Enter a brief description of the form, which will be displayed below the form title.
* **Form category** (`form_category`, select_one, required): Select the category for the form from the provided options, which will help to filter and categorize the uploaded content.
* **Form files** (`form_files`, select_multiple, required): Choose the files to be uploaded from the provided options, which will be attached to the form as supporting content.
* **File upload** (`file_upload`, text, optional): This field is not currently used. Please ignore.
* **Date** (`form_date`, date, optional): Enter the date for the form, which will be displayed as a timestamp for the uploaded content.
* **Time** (`form_time`, time, optional): Enter the time for the form, which will be displayed as a timestamp for the uploaded content.
* **Email** (`form_email`, email, optional): Enter a contact email for the form, which will be displayed as a point of contact for the uploaded content.
* **Phone** (`form_phone`, text, optional): Enter a contact phone number for the form, which will be displayed as a point of contact for the uploaded content.
* **Note** (`form_note`, note, optional): Enter a note or comment for the form, which will be displayed as additional information for the uploaded content.
* **Submit** (`form_submit`, text, optional): Enter a submit message for the form, which will be displayed as a confirmation message after submission.
* **Captcha** (`form_captcha`, text, optional): This field is not currently used. Please ignore.
