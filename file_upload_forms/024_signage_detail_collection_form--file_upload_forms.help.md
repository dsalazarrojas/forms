# Signage Detail Collection Form - Help Guide
## Purpose

The Signage Detail Collection Form is a comprehensive form designed to collect detailed information about project signage. This form helps to ensure that all necessary data is gathered accurately and consistently, making it easier for project team members and stakeholders to track and manage projects.

## How To Complete This Form

1. Fill out the form fields as prompted, providing accurate and detailed information for each field.
2. Ensure that all required fields are completed, indicated by the "required" label in the field descriptions below.

## Field-by-Field Explanation

* **Project Details** (project_details): Enter a brief description of the project.
* **Design Assets** (design_assets): List any design assets related to the project.
* **Approvals** (approvals): Select the approvals received for the project.
* **Project Status** (project_status): Choose the current project status from the list of options.
* **Project Status Label** (project_status_label): Enter a label for the project status.
* **Sign Type** (sign_type): Select the type of sign related to the project from the list of options.
* **Project Description** (project_description): Enter a detailed description of the project.
* **Sign Color** (sign_color): Select the color of the sign from the list of options.
* **Sign Size** (sign_size): Enter the size of the sign in numeric format (e.g., 12 inches).
* **Project Budget** (project_budget): Enter the project budget in numeric format (e.g., 1000).
* **Project Start Date** (project_start_date): Enter the project start date in the format MM/DD/YYYY.
* **Project End Date** (project_end_date): Enter the project end date in the format MM/DD/YYYY.
* **File Uploader 1** (file_uploader_1): Upload relevant files for the project.
* **File Uploader 2** (file_uploader_2): Upload additional relevant files for the project.
* **Project Approver** (project_approver): Select the project approver(s) from the list of options.
* **Project Approver Label** (project_approver_label): Enter a label for the project approver(s).
* **Project Notes** (project_notes): Enter any additional project notes.

## Tips

* Make sure to double-check the accuracy of all uploaded files before submitting the form.
* Ensure that the project status is up-to-date and reflects the current project progress.
* If you're unsure about any field or have questions, please reach out to your project team for guidance.
