# Game Character Design Upload Form - Help Guide
## Purpose
This form is designed to collect data for game character designs. It guides users through a series of fields to ensure that all necessary information is provided.

## How To Complete This Form
1. Start by filling in the form title.
2. Enter a brief description of the character concept.
3. Fill in the character name, age, and image.
4. Choose the character's gender and file type.
5. Select relevant tags and reviewers for the character.
6. Upload the character's design file.
7. Finally, review and submit the form.

## Field-by-Field Explanation
* **Form Title** (1): A brief title for the form.
* **Character Concept** (2): A brief description of the character's concept.
* **Character Name** (3): The name of the character.
* **Character Age** (4): The character's age.
* **Character Gender** (5): The character's gender.
* **Character Image** (6): The character's image file.
* **Description** (7): A detailed description of the character.
* **Tags** (8): A list of relevant tags for the character.
* **Reviewers** (9): A list of reviewers for the character.
* **Upload File** (10): Upload the character's design file.
* **File Size** (11): The size of the uploaded file.
* **File Type** (12): The type of the uploaded file.
* **Character Tags** (13): A list of yes or no tags for the character.
* **Character Type** (14): A list of yes or no tags for the character.
* **Character Status** (15): A list of active or inactive status for the character.
* **Character Tags 2** (16): A list of yes or no tags for the character.
* **Character Name 2** (17): The name of the character.
* **Character Age 2** (18): The character's age.
* **Character Gender 2** (19): The character's gender.
* **Character Image 2** (20): The character's image file.
* **Description 2** (21): A detailed description of the character.
* **Submit** (22): Submit the form after filling in all necessary information.

Note: This form is designed to prevent users from duplicating character information by limiting the number of character fields. If you need to add more character information, please create a new form or ask for assistance.
