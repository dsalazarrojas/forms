# Engineer In Training (EIT) Certification Application - Help Guide
## Purpose
The Engineer In Training (EIT) Certification Application form is designed to collect information from candidates who wish to obtain their Engineer In Training (EIT) certification. The form gathers details about the applicant, their EIT details, references, certification documents, and other relevant information.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the required fields:
	* EIT Certification Agreement: This is a mandatory field where you need to agree to the certification terms.
	* Upload Document: You can upload any relevant document required for your certification.
2. Fill in the optional fields:
	* Application Form: You can provide any additional information about yourself.
	* EIT Details: You can provide your EIT details if required.
	* References: You can provide any relevant references.
	* Review Comments: You can provide any review comments.
	* Additional Comments: You can provide any additional comments.

## Field-by-Field Explanation
* **EIT Certification Agreement**: (`eit_certification_agreement`, text, required)
	+ This is the agreement form for your EIT certification. Please review and agree to the terms before proceeding.
* **Application Form** (`application_form`, text, optional)
	+ This is an optional field for providing additional information about yourself.
* **EIT Details** (`eit_details`, text, optional)
	+ This field is optional for providing your EIT details.
* **References** (`references`, text, optional)
	+ This is an optional field for providing any relevant references.
* **Upload Document** (`upload_document`, text, optional)
	+ This is an optional field for uploading any relevant documents.
* **Review Comments** (`review_comments`, text, optional)
	+ This is an optional field for providing any review comments.
* **Additional Comments** (`additional_comments`, text, optional)
	+ This is an optional field for providing any additional comments.
* **EIT Certificate** (`eit_certificate`, number, optional)
	+ This field is optional for providing the EIT certificate number.
* **Review Status** (`review_status`, text, optional)
	+ This field is optional for tracking the review status.
