# Corporate Minutes Form - Help Guide

## Purpose
The Corporate Minutes Form is a tool for secretaries to record and document meetings, ensuring accuracy and consistency in reporting. It is used to record meeting dates, attendees, outcomes, and approval status.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the meeting date from the date input field.
2. Enter the meeting minutes in the text area provided.
3. List all meeting attendees in the select multiple field.
4. Choose the main outcomes and decisions from the meeting from the text area.
5. Check the meeting approval status by selecting the correct option from the select one field.

## Field-by-Field Explanation

* **Meeting Date** (`meeting_date`, date, required: false): Enter the date of the meeting.
* **Meeting Minutes** (`meeting_minutes`, text, required: false): Enter a detailed description of what happened during the meeting.
* **Meeting Location** (`meeting_location`, text, required: false): Enter the location of the meeting.
* **Meeting Attendees** (`meeting_attendees`, select multiple, required: false): List all attendees, separated by commas.
* **Meeting Notes** (`meeting_notes`, text, required: false): Enter any additional notes from the meeting.
* **Meeting Attendance** (`meeting_attendance`, select one, required: false): Select the attendance status of the meeting (e.g., true or false).
* **Meeting Outcomes** (`meeting_outcomes`, text, required: false): Enter the main actions and decisions from the meeting.
* **Meeting Approval** (`meeting_approval`, select one, required: false): Check the approval status of the meeting.

## Tips

* Use this form to document every meeting, including regular meetings and special events.
* Ensure that all relevant information is accurate and up-to-date.
* Use the select multiple field for meeting attendees to avoid errors in documenting multiple attendees.
