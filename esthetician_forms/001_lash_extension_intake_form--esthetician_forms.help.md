# lash_extension_intake_form - Help Guide
## Purpose
This form is designed to collect information from clients for lash extension services, repair, and other related treatments. It helps the technician understand the client's needs and preferences, ensuring a more personalized experience during the treatment process.

## How To Complete This Form
1. Select the "Client Details" page and fill in the necessary information, including client name, contact information, and other relevant details.
2. On the "Lash Extension Services" page, select the options that apply to the client's needs, such as "Yes" for services they require.
3. For each subsequent page, follow the same process, selecting the options that apply to the client's needs.
4. Review and submit the form once complete.

## Field-by-Field Explanation

* **Client Details** (`client_details`, `text`, `false`): Enter the client's name and any other relevant details, such as contact information.
* **Lash Extension Services** (`lash_extension_services`, `select_one`, `false`): Select "Yes" if the client requires lash extension services.
* **Lash Type** (`lash_type`, `select_multiple`, `false`): Select the types of lash extension services the client requires, such as "Yes" for lash extension.
* **Eye Type** (`eye_type`, `select_multiple`, `false`): Select the types of eye treatments the client requires, such as "Yes" for eye type.
* **Lashes to Repair** (`lashes_to_repair`, `select_multiple`, `false`): Select the types of lashes that require repair, such as "Yes" for lash extension.
* **Lash Repair Services** (`lash_repair_services`, `select_multiple`, `false`): Select the types of lash repair services the client requires, such as "Yes" for repair.
* **Lash Lift** (`lash_lift`, `select_multiple`, `false`): Select the types of lash lift services the client requires, such as "Yes" for lift.
* **Lash Extension** (`lash_extension`, `select_multiple`, `false`): Select the types of lash extension services the client requires, such as "Yes" for extension.
* **Lash Repair** (`lash_repair`, `select_multiple`, `false`): Select the types of lash repair services the client requires, such as "Yes" for repair.
* **Lash Bonding** (`lash_bonding`, `select_multiple`, `false`): Select the types of lash bonding services the client requires, such as "Yes" for bonding.
* **Eyebrow** (`eyebrow`, `select_multiple`, `false`): Select the types of eyebrow services the client requires, such as "Yes" for eyebrow.
* **Eye Brows** (`eye_brows`, `select_multiple`, `false`): Select the types of eye brows services the client requires, such as "Yes" for eye brows.
* **Full Brows** (`full_brows`, `select_one`, `false`): Select "Yes" if the client requires full brow services.
* **Lash Application** (`lash_application`, `select_one`, `false`): Select "Yes" if the client requires lash application services.

## Tips
- Make sure to review the form carefully before submitting to ensure accurate and complete information.
- If you're unsure about any field, please ask your technician for guidance.
- This form is designed to be a helpful resource for both clients and technicians.
