# Sugaring Waiver Form - Help Guide
## Purpose
This form is used to collect information for a specific type of service. Please fill in the required fields accurately to ensure proper service handling and billing.

## How To Complete This Form
1. Fill out the form carefully, following the instructions for each field.
2. Ensure you answer all required fields accurately.
3. Review the form before submission to ensure all fields are filled in correctly.

## Field-by-Field Explanation

* **Client Name**: A text field for the client's name. Please type in the client's full name.
* **Contact Email**: A text field for the client's email address. Please type in a valid email address.
* **Contact Phone**: A text field for the client's phone number. Please type in a valid phone number.
* **Services**: A multiple-select field for the services provided. Please select all applicable services.
* **Risk Factors**: A text field for any risk factors to be considered. Please fill this in if applicable.
* **Waiver Agreed**: A single-select field to indicate if the client has agreed to the waiver. Please select 'Agreed'.
* **Signature**: A date field for the client's signature. Please fill in the date of signature.
* **Eesthetician Name**: A text field for the esthetician's name. Please type in the esthetician's name.
* **Eesthetician Title**: A text field for the esthetician's title. Please type in the esthetician's title.
* **Location**: A time field for the location of service. Please fill in the time of service.
* **Date**: A date field for the date of service. Please fill in the date of service.
* **Time**: A time field for the time of service. Please fill in the time of service.

## Tips
- Ensure accuracy and completeness in all fields.
- Review the form before submission.
- If you have any issues or queries, please contact the service provider.
