# Aesthetic Note - Help Guide
## Purpose

The Aesthetic Note form is designed to capture essential information about the client's aesthetic treatment session, including their personal details, treatment specifics, and post-treatment instructions. This form helps estheticians gather and document relevant information for future reference, improving the quality of care and ensuring continuity of services.

## How To Complete This Form

To complete this form, follow these steps:

1. **Fill out each section carefully**: Complete all required fields, and provide as much detail as possible for optional fields.
2. **Use the correct input type**: Ensure you enter information in the correct field type (date, text, email, etc.)
3. **Select relevant options**: Choose the most accurate option that corresponds to the client's condition or treatment.

## Field-by-Field Explanation

* **Client Full Name**: Enter the client's complete legal name. This is a required field.
* **Date of Birth**: Enter the client's date of birth. This is a required field.
* **Client Phone Number**: Enter the client's primary phone number for contact purposes. This is an optional field.
* **Client Email Address**: Enter the client's email address for appointment confirmations and follow-ups. This is an optional field.
* **Medical Conditions**: List any medical conditions relevant to the aesthetic treatments. This is an optional field.
* **Treatment Information**: A note section for any additional information about the treatment session. This is an optional field.
* **Treatment Date**: Enter the date when the treatment was performed. This is a required field.
* **Treatment Time**: Enter the time when the treatment was performed. This is a required field.
* **Performing Esthetician**: Enter the name of the esthetician who performed the treatment. This is a required field.
* **Type of Treatment**: Select the type of aesthetic treatment performed (e.g., Facial Treatment, Chemical Peel, etc.). This is a required field.
* **Treatment Area**: Choose the area of the body that was treated. This is a required field.
* **Products Used**: List the products used during the treatment. This is a required field.
* **Treatment Details**: A note section for any additional information about the treatment session. This is an optional field.
* **Skin Condition Assessment**: Assess the client's skin condition before the treatment. This is a required field.
* **Treatment Procedure Notes**: Enter detailed notes about the treatment procedure performed. This is a required field.
* **Client Reaction Response**: Describe how the client reacted to the treatment. This is an optional field.
* **Adverse Reactions**: Indicate if there were any adverse reactions during the treatment. Select the most accurate option (e.g., None, Mild Redness, etc.). This is a required field.
* **Treatment Outcome**: Assess the outcome of the treatment. This is a required field.
* **Recommendations and Follow-up**: A note section for any recommendations or follow-up instructions. This is an optional field.
* **Home Care Instructions**: Provide instructions for the client to follow at home. This is a required field.
* **Products Recommended to Take Home**: List any products recommended for the client to purchase. This is an optional field.
* **Follow-up Treatment Scheduled**: Indicate if a follow-up treatment is scheduled. Select the most accurate option (e.g., True, False, To be scheduled). This is a required field.
* **Next Appointment Date**: Enter the date of the next scheduled appointment. This is an optional field.
* **Treatment Frequency Recommendation**: Provide a recommendation for the frequency of future treatments. This is an optional field.
* **Contraindications**: A note section for any contraindications that may affect future treatments. This is an optional field.
* **Contraindications Present**: Indicate if there are any contraindications. Select the most accurate option (e.g., True, False, Uncertain). This is a required field.
* **Contraindication Details**: If yes, please specify the contraindications. This is an optional field.
* **Electronic Signature of the Performing Esthetician**: Enter the electronic signature of the performing esthetician. This is a required field.

Note: This guide is a general explanation of the form and its fields. If you have specific questions or concerns, please refer to your institution's guidelines or consult with an esthetician.
