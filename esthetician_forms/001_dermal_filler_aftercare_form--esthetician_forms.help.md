# Dermal Filler Aftercare Form - Help Guide
## Purpose

This form is used to track and record aftercare information for dermal filler treatments. It collects data on the skin type, product used, and follow-up schedule, as well as any aftercare notes and follow-up instructions.

## How To Complete This Form

This form consists of 8 fields, each with specific information to collect. Please refer to the Field-by-Field Explanation for detailed explanations of each field.

## Field-by-Field Explanation

* **Filler Aftercare Instructions** (`filler_aftercare_instructions`, `text`, required): 
	+ This field is a text input where you can enter any specific aftercare instructions provided to the patient. 
* **Skin Type** (`skin_type`, `select_multiple`, required): 
	+ Select one or more of the options provided (normal, sensitive, dry, oily) to indicate the type of skin the dermal filler was applied to. 
* **Product Used** (`product_used`, `select_one`, required): 
	+ Choose the product used for the treatment (dermal filler, retinol, or other - please specify). 
* **Follow-up Schedule** (`follow_up_schedule`, `date`, optional): 
	+ If applicable, enter a date for the follow-up appointment. 
* **Follow-up Contact** (`follow_up_contact`, `text`, optional): 
	+ Enter any additional contact information for follow-up (e.g., phone number or email). 
* **Aftercare Notes** (`aftercare_notes`, `note`, optional): 
	+ Add any aftercare notes or comments about the treatment. 
* **Follow-up Instructions** (`follow_up_instructions`, `text`, required): 
	+ Enter any specific follow-up instructions provided to the patient. 
* **Photos** (`photos`, `text`, optional): 
	+ Add any photos related to the treatment, such as before-and-after images. 

## Tips

* Please make sure to enter all required fields.
* If you have any questions or concerns about this form, contact your healthcare professional. 
* If you need to make any changes to this form, please refer to your healthcare professional for guidance.
