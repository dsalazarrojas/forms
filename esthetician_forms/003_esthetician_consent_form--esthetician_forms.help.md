# esthetician_consent_form - Help Guide
## Purpose
The esthetician_consent_form is used to collect client information and consent for esthetician services.

## How To Complete This Form
1. Select the relevant options for each page from the dropdown menus.
2. Enter any additional details in the text fields.

## Field-by-Field Explanation
* **Client Information** (`client_information`, `select_multiple`, required: false):
	+ This field allows you to select multiple options from the provided list.
* **Eesthetician Services** (`esthetician_services`, `select_one`, required: false):
	+ Select one option from the provided list.
* **Medical History** (`medical_history`, `text`, required: false):
	+ Enter any relevant medical information here.
* **Eesthetician Services Details** (`esthetician_services_details`, `select_multiple`, required: false):
	+ Select multiple options from the provided list.
* **Eesthetician Agreement** (`esthetician_agreement`, `text`, required: false):
	+ Enter any additional agreement details here.

## Tips
* Make sure to fill out all relevant fields to ensure accurate and complete information.
