# Anchor Class Registration Form - Help Guide
## Purpose
The Anchor Class Registration Form is used to collect information from parents or guardians about their child's registration for the Anchor Class program. The form is designed to gather necessary details about the student's registration status, academic information, medical needs, contact details, and other relevant information.

## How To Complete This Form
To complete this form, please follow the steps below:

1.  Please ensure that the information you provide is accurate and up-to-date.
2.  Fill out all required fields, marked with an asterisk (\*).
3.  For fields with dropdown menus, select the relevant option that best suits your situation.
4.  If you're unsure about any field, leave it blank and contact us for clarification.
5.  Once you've completed the form, review it carefully before submitting.

## Field-by-Field Explanation

*   **Registration Date** (\*): This is the date the student will begin attending the Anchor Class program.
*   **Academic Term/Year** (\*): Select the term and year the student is registering for.
*   **Student First Name** (\*): Enter the student's first name.
*   **Student Last Name** (\*): Enter the student's last name.
*   **Date of Birth** (\*): Enter the student's date of birth in MM/DD/YYYY format.
*   **Age** (\*): Enter the student's age.
*   **Gender**: Select the student's gender.
*   **Student ID Number**: This is the student's ID number, if applicable.
*   **Grade Level** (\*): Select the student's current grade level.
*   **Anchor Class Type**: Select the desired class type for the student.
*   **Subject Area** (\*): Select the subject area the student is registering for.
*   **Specific Class Name**: Enter the specific class name, if known.
*   **Class Level**: Select the class level for the student.
*   **Preferred Schedule**: Select the preferred schedule for the student.
*   **Relationship to Student**: Select the relationship between the parent/guardian and the student.
*   **Parent/Guardian First Name** (\*): Enter the parent/guardian's first name.
*   **Parent/Guardian Last Name** (\*): Enter the parent/guardian's last name.
*   **Email Address** (\*): Enter the parent/guardian's email address for communications.
*   **Primary Phone Number** (\*): Enter the primary phone number for the parent/guardian.
*   **Secondary Phone Number**: Enter the secondary phone number for the parent/guardian, if applicable.
*   **Street Address** (\*): Enter the street address of the parent/guardian's residence.
*   **City** (\*): Enter the city of the parent/guardian's residence.
*   **State** (\*): Enter the state of the parent/guardian's residence.
*   **ZIP Code** (\*): Enter the ZIP code of the parent/guardian's residence.
*   **Emergency Contact Name**: Enter the name of the emergency contact.
*   **Emergency Contact Phone**: Enter the phone number of the emergency contact.
*   **Relationship to Student**: Select the relationship between the emergency contact and the student.
*   **Known Medical Conditions**: Enter any known medical conditions the student has, if applicable.
*   **Allergies**: Enter any known allergies the student has, if applicable.
*   **Current Medications**: Enter any current medications the student is taking, if applicable.
*   **Physician Name**: Enter the student's physician's name, if applicable.
*   **Physician Phone**: Enter the student's physician's phone number, if applicable.
*   **Insurance Provider**: Enter the student's insurance provider's name, if applicable.
*   **Previous School**: Enter the student's previous school's name, if applicable.
*   **GPA**: Enter the student's current GPA, if applicable.
*   **Academic Goals**: Enter the student's academic goals, if applicable.
*   **Learning Style**: Select the student's learning style.
*   **Special Needs**: Enter any special needs the student has, if applicable.
*   **Transportation Needed**: Select if transportation is needed for the student.
*   **Authorized for Pickup**: Enter the authorized person or organization to pick up the student.
*   **Photo Permission**: Select if photo permission is granted.
*   **Field Trip Permission**: Select if field trip permission is granted.
*   **Technology Use Permission**: Select if technology use permission is granted.
*   **Payment Method**: Select the payment method for class fees.
*   **Financial Assistance**: Select if financial assistance is applying for.
*   **Extracurricular Interests**: Enter the student's extracurricular interests, if applicable.
*   **Additional Comments**: Enter any additional comments or information, if applicable.
*   **How Did You Hear About This Program**: Select how the student heard about the program.
*   **Terms and Conditions**: Select the terms and conditions of the form.
*   **Code of Conduct Acknowledgment**: Select the code of conduct acknowledgment.
*   **Parent/Guardian Signature** (\*): Enter the parent/guardian's signature.
*   **Date of Signature** (\*): Enter the date of signature.
*   **Registration Status**: Select the registration status of the student.
*   **Assigned Teacher**: Enter the assigned teacher's name, if applicable.
*   **Class Section**: Enter the class section the student is assigned to, if applicable.

Note: Please refer to the school's website or contact the school's administration for more information or clarification on any of the fields.
