# Class And Teacher Filter Form - Help Guide
## Purpose
This form is designed to gather information from students' parents, guardians, or authorized representatives to help filter and sort students in a class and pair them with suitable teachers based on their preferences and needs.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill in the student's name, ID number, and current grade level in the "Student Information" section.
2. Select the student's enrollment type (new, returning, or transfer student) in the "Enrollment Type" section.
3. In the "Class Preferences" section, choose the preferred class size and section.
4. If applicable, select the preferred teacher or specific teacher qualities in the "Teacher Preferences" section.
5. Indicate if the student has special needs or an IEP plan in the "Special Needs and Accommodations" section.
6. Add any additional information or requests in the "Additional Information or Requests" section.

## Field-by-Field Explanation
* **Student Name**: Enter the student's full name as it appears on their official records.
* **Student ID Number**: Provide the student's ID number for identification purposes.
* **Current Grade Level**: Choose the student's current grade level from the drop-down menu.
* **Enrollment Type**: Select the type of enrollment (new, returning, or transfer student).
* **Preferred Class Size**: Choose the preferred class size from the options (Small class - under 20 students, Medium class - 20-30 students, Standard class - 30-40 students, No preference).
* **Preferred Class Section**: Enter the preferred class section, if available (e.g., A, B, C, etc.).
* **Preferred Classroom Environment**: Select the preferred classroom environment (Traditional lecture style, Interactive group work, Project-based learning, Technology-enhanced, Mixed approach, No preference).
* **Preferred Learning Style Preference**: Choose the preferred learning style preference (Visual learner, Auditory learner, Kinesthetic learner, Mixed learning style, Not sure).
* **Teacher Preference**: Indicate if you have a preference for a specific teacher or specific teacher qualities.
* **Preferred Teacher Name**: If applicable, enter the name of the preferred teacher.
* **Preferred Teacher Qualities**: Select all the qualities that you prefer in a teacher (strict and disciplined, Encouraging and supportive, Innovative and creative, Patient with individual learners, Strong subject knowledge, Good communicator, Experienced with special needs).
* **Does the student have special educational needs?**: Select 'True' if the student has special needs.
* **Details of special needs or required accommodations**: Provide any additional information about the student's special needs or required accommodations.
* **Does the student have an IEP plan?**: Select 'True' if the student has an IEP plan.
* **Any scheduling preferences or constraints**: Enter any scheduling preferences or constraints.
* **Peer grouping requests or concerns**: Provide any peer grouping requests or concerns.
* **Additional information or requests**: Enter any additional information or requests.

Note: The fields marked as "required" are mandatory and must be completed. Please make sure to fill out all required fields to ensure accurate and effective filtering and sorting of students.
