# Server Maintenance Extension Form - Help Guide
## Purpose
This form is used to submit server maintenance requests to the relevant team for processing. It is essential to fill in all required fields accurately to ensure efficient maintenance processing.
## How To Complete This Form
- Click on a blank page to start filling in a new form instance.
- Fill in all required fields, marked as "required."
- If a field is not required, you can leave it blank, but ensure you fill in all other required fields.
- Once all fields are filled, click the 'Submit' button to send the form to the maintenance team.
## Field-by-Field Explanation
- **Server Maintenance Request**: Enter a brief description of the maintenance task. 
  * This field is required.
- **Date**: Select the date when the maintenance task is scheduled to start.
  * This field is not required, but recommended for planning purposes.
- **Duration**: Enter the expected duration of the maintenance task in hours.
  * This field is required.
- **Start Time**: Enter the start time of the maintenance task in 24-hour format.
  * This field is required.
- **End Time**: Enter the end time of the maintenance task in 24-hour format.
  * This field is required.
- **Reason**: Enter a brief explanation of the maintenance request, if necessary.
  * This field is not required.
- **Email**: Enter your email address for contact purposes.
  * This field is required.
- **Server Maintenance Status**: Select the current status of the maintenance request.
  * Options: Active, Scheduled, In Progress, Completed. This field is required.
## Tips
- Be as detailed as possible when filling in the 'Server Maintenance Request' field.
- Ensure that all required fields are completed before submitting the form.
- The 'Server Maintenance Status' field should reflect the actual status of the maintenance request accurately.
- If you need to make changes to an existing request, please submit a new request with the updated information, rather than editing the original request.
