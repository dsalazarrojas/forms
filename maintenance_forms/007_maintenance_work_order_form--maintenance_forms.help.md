# Maintenance Work Order Form - Help Guide
## Purpose
This form is used to record and report maintenance activities for equipment in a warehouse or factory setting.

## How To Complete This Form

To complete this form, follow these steps:

1. Select the correct "Maintenance Type" that describes the work order.
2. Enter the "Equipment ID" of the equipment being maintained.
3. Provide a brief description of the equipment, such as its location or purpose.
4. Select the start and end dates for the maintenance work order.
5. Choose the start and end times for the work order.
6. Select the "Maintenance Status" of the work order.
7. Optionally, provide a note or additional details in the "Maintenance Work Order Form 1" field.

## Field-by-Field Explanation

* **Maintenance Work Order Form 1 (Note)**: This field is for providing a brief summary or note about the maintenance work order. It's not required but can be useful for additional context.
* **Equipment ID**: Enter the ID of the equipment being maintained. This helps track which specific piece of equipment is being worked on.
* **Maintenance Type**: Choose the type of maintenance being performed. This will help in categorizing and prioritizing maintenance tasks.
* **Maintenance Type Options**: Select any additional types of maintenance that apply to the equipment. This field allows for multiple selections.
* **Equipment Description**: Briefly describe the equipment being maintained, including its location or purpose. This helps in identifying and accessing the equipment.
* **Work Order Date**: Enter the date for the maintenance work order.
* **Work Order Start**: Select the start time for the maintenance work order.
* **Work Order End**: Select the end time for the maintenance work order.
* **Assigned To**: Enter the name or team responsible for completing the maintenance work order.
* **Maintenance Status**: Select the current status of the maintenance work order.
