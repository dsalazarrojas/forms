# IT Third Party Maintenance Service Request - Help Guide
## Purpose

This form is used to submit a third-party maintenance service request for IT support. Please fill out the form carefully and accurately to ensure that your request is handled efficiently.

## How To Complete This Form

1. Click on the "submit" button to start filling out the form.
2. Select a category for the request (if required).
3. Enter a detailed description of the maintenance service required.
4. Choose the priority of the request.
5. Enter the start and end dates for the scheduled maintenance.
6. Select the assigned tool for the request.
7. Add any additional notes or comments.
8. Enter the email and phone number of the person responsible for the maintenance.
9. Enter the name and email of the customer.
10. Enter the notes for the customer.
11. Click the "submit" button to complete the form.

## Field-by-Field Explanation

* **form_title** (`it_third_party_maintenance_service_request_form`, text, required): Enter a title for the maintenance request.
* **category** (`category`, select one, false): Choose a category for the request. This field is not required but helps the support team understand the nature of the request.
* **description** (`description`, text, required): Enter a detailed description of the maintenance service required.
* **priority** (`priority`, select one, false): Select the priority of the request (low, medium, or high).
* **scheduling_start_date** (`scheduling_start_date`, date, false): Enter the start date of the scheduled maintenance.
* **scheduling_end_date** (`scheduling_end_date`, date, false): Enter the end date of the scheduled maintenance.
* **assigned_tool** (`assigned_tool`, select one, false): Select the tool to be used for the request.
* **notes** (`notes`, note, false): Add any additional comments or notes about the request.
* **email** (`email`, email, false): Enter the email of the person responsible for the maintenance.
* **phone** (`phone`, text, false): Enter the phone number of the person responsible for the maintenance.
* **submit** (`submit`, text, false): Click to submit the form.
* **cancel** (`cancel`, text, false): This button cancels the form submission.
* **category_options** (`category_options`, select multiple, false): Choose multiple categories for the request.
* **vendor_name** (`vendor_name`, text, false): Enter the name of the vendor providing the maintenance service.
* **vendor_description** (`vendor_description`, text, false): Enter a description of the vendor's service.
* **vendor_address** (`vendor_address`, text, false): Enter the address of the vendor.
* **vendor_phone** (`vendor_phone`, text, false): Enter the phone number of the vendor.
* **vendor_email** (`vendor_email`, email, false): Enter the email of the vendor.
* **vendor_website** (`vendor_website`, text, false): Enter the website of the vendor.
* **vendor_notes** (`vendor_notes`, note, false): Add any additional notes about the vendor.
* **customer_name** (`customer_name`, text, false): Enter the name of the customer.
* **customer_email** (`customer_email`, email, false): Enter the email of the customer.
* **customer_phone** (`customer_phone`, text, false): Enter the phone number of the customer.
* **customer_notes** (`customer_notes`, note, false): Add any additional notes about the customer.
