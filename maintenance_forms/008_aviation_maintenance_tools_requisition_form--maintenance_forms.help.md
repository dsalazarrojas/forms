# Aviation Maintenance Tools Requisition Form - Help Guide
## Purpose
The Aviation Maintenance Tools Requisition Form is used to request maintenance tools, equipment, or services related to aviation. It ensures that the requester provides all necessary information for the maintenance team to process the request efficiently.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the type of request you are submitting (e.g., new tool request, replacement tool, calibration service, etc.).
2. Enter the date of your request.
3. Provide your full name and employee ID.
4. Select your maintenance department.
5. Enter your work email and phone extension (if applicable).
6. Specify the type of aircraft this request is related to.
7. Enter the tail number or registration of the aircraft.
8. If applicable, enter the work order number associated with the request.
9. Enter the name, part number, and quantity of each tool required.
10. Explain the justification for your request.
11. Select the urgency level (e.g., Routine, Soon, Urgent, Immediate).
12. Specify the expected duration of use for the tool(s).
13. If necessary, enter any special requirements (e.g., calibration, certification, or handling needs).
14. If necessary, specify the date you expect to return the tool(s).
15. Enter the name of your supervisor.
16. Select the status of your supervisor's approval.
17. Enter any additional notes or information.

## Field-by-Field Explanation

* **Requisition Type (id: 1)**: What type of request is this (e.g., New tool request, Replacement tool, Calibration service, etc.).
* **Request Date (id: 2)**: The date you are submitting this request.
* **Requester Full Name (id: 3)**: Your full name as an employee.
* **Employee ID (id: 4)**: Your employee identification number.
* **Department (id: 5)**: Your maintenance department.
* **Email Address (id: 6)**: Your work email address.
* **Phone Extension (id: 7)**: Your work phone extension (if applicable).
* **Aircraft Type (id: 8)**: The type of aircraft this request is related to.
* **Aircraft Tail Number (id: 9)**: The tail number or registration of the aircraft.
* **Work Order Number (id: 10)**: The associated work order number (if applicable).
* **Tool 1 Name (id: 11)**: The name of the first tool required.
* **Tool 1 Part Number (id: 12)**: The manufacturer part number of the first tool.
* **Tool 1 Quantity (id: 13)**: The quantity of the first tool needed.
* **Tool 2 Name (id: 14)**: The name of the second tool (if needed).
* **Tool 2 Part Number (id: 15)**: The manufacturer part number of the second tool (if needed).
* **Tool 2 Quantity (id: 16)**: The quantity of the second tool needed (if needed).
* **Tool 3 Name (id: 17)**: The name of the third tool (if needed).
* **Tool 3 Part Number (id: 18)**: The manufacturer part number of the third tool (if needed).
* **Tool 3 Quantity (id: 19)**: The quantity of the third tool needed (if needed).
* **Justification (id: 20)**: Explain why you need these tools.
* **Urgency Level (id: 21)**: The level of urgency for the request (e.g., Routine, Soon, Urgent, Immediate).
* **Expected Duration of Use (id: 22)**: The expected duration of use for the tool(s).
* **Special Requirements (id: 23)**: Any special requirements (e.g., calibration, certification, handling needs).
* **Expected Return Date (id: 24)**: The date you expect to return the tool(s).
* **Supervisor Name (id: 25)**: The name of your supervisor.
* **Supervisor Approval Status (id: 26)**: The status of your supervisor's approval.
* **Additional Notes (id: 27)**: Any additional information about your request.
