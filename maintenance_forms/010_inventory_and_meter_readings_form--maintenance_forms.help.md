# inventory_and_meter_readings_form - Help Guide
## Purpose
The "inventory_and_meter_readings_form" is a form used to collect data on meter readings and inventory values for a location.

## How To Complete This Form
To complete this form, please follow these steps:

1. Select the location for which you want to report meter readings and inventory values.
2. Enter the current meter value for the selected location.
3. Choose the type of issue (if any) that you have encountered at the location.
4. Add any additional notes about the location or issues.
5. Enter contact information (phone, email) if the issue requires further communication.
6. Select the tools that have been assigned to address the issue.
7. Enter the name of the location (if not already selected).
8. Enter the inventory value for the location.

## Field-by-Field Explanation
- **Location**: Enter the name or identifier of the location where you are reporting meter readings and inventory values.
- **Meter Value**: Enter the current meter reading for the selected location.
- **Issue**: Select the type of issue you have encountered at the location (if any).
  - None: No issue has been reported.
  - Maintenance: Routine maintenance is required.
  - Repair: Repair is required.
  - Other: Select this option if the issue is not Maintenance or Repair.
- **Notes**: Add any additional notes about the location or issues.
- **Contact**: Enter your contact information (phone, email) if the issue requires further communication.
- **Phone**: Enter your phone number.
- **Email**: Enter your email address.
- **Assigned Tool**: Select the tools that have been assigned to address the issue (if any).
- **Location Name**: Enter the name of the location (if not already selected).
- **Inventory Value**: Enter the current inventory level for the selected location.
