# Fire Alarm Reinstallation Request Form - Help Guide
## Purpose
The Fire Alarm Reinstallation Request Form is used to collect information about the reinstallation of a fire alarm system in a property. This form is used to gather details about the reinstallation process, including the property owner's and manager's information, the reinstallation request and description, visit request and schedule, work details, and other relevant information.

## How To Complete This Form
To complete this form, follow these steps:

1.  Fill in the **Requestor Info** section with your details, including your name and contact information.
2.  Enter the **Property Id** and **Property Name** of the property where the fire alarm system is installed.
3.  In the **Reinstallation Request Info** field, provide a brief description of the reinstallation request.
4.  Enter the **Reinstallation Reason** for the reinstallation in this field.
5.  Describe the **Reinstallation Description** in detail, including any relevant information or specifications about the reinstallation.
6.  Choose a **Visit Request** time from the available options.
7.  Select the **Visit Request Time** for the reinstallation visit.
8.  Provide any additional **Work Details** related to the reinstallation.
9.  Choose the **Work Status** of the reinstallation (In Progress, Complete, Canceled, or Not Scheduled).
10. Enter the **Contact Info** of the person responsible for the reinstallation.
11. Select the **Assigned To** personnel responsible for the reinstallation.
12. Choose if you need a **Follow Up** (True/False).
13. If you need a **Follow Up**, select a date for the follow-up.
14. Provide any additional **Comments** or notes about the reinstallation request.
15. Enter any additional **Notes** about the reinstallation request.

## Field-by-Field Explanation

* **Requestor Info** (`requestor_info`, `text`, required/optional): This field is used to collect the name and contact information of the person submitting the reinstallation request. Please enter your name and contact details accurately.
* **Property Id** (`property_id`, `number`, required/optional): This field is used to enter the ID of the property where the fire alarm system is installed. If you're unsure about the property ID, you can find it on the property's records or contact the property manager for assistance.
* **Property Name** (`property_name`, `text`, required/optional): This field is used to enter the name of the property where the fire alarm system is installed. If you're unsure about the property name, you can find it on the property's records or contact the property manager for assistance.
* **Reinstallation Request Info** (`reinstallation_request_info`, `text`, required/optional): This field is used to provide a brief description of the reinstallation request.
* **Reinstallation Reason** (`reinstallation_reason`, `text`, required/optional): This field is used to enter the reason for the reinstallation of the fire alarm system.
* **Reinstallation Description** (`reinstallation_description`, `text`, required/optional): This field is used to describe the reinstallation process in detail, including any relevant information or specifications.
* **Reinstallation Date** (`reinstallation_date`, `date`, required/optional): This field is used to enter the date of the reinstallation. 
* **Visit Request** (`visit_request`, `select_multiple`, required/optional): This field is used to select the time for the reinstallation visit from the available options.
* **Visit Request Time** (`visit_request_time`, `time`, required/optional): This field is used to select the time for the reinstallation visit.
* **Work Details** (`work_details`, `text`, required/optional): This field is used to provide any additional details about the reinstallation work.
* **Work Status** (`work_status`, `select_one`, required/optional): This field is used to select the status of the reinstallation (In Progress, Complete, Canceled, or Not Scheduled).
* **Contact Info** (`contact_info`, `text`, required/optional): This field is used to enter the contact information of the person responsible for the reinstallation.
* **Assigned To** (`assigned_to`, `select_one`, required/optional): This field is used to select the personnel responsible for the reinstallation.
* **Follow Up** (`follow_up`, `select_one`, required/optional): This field is used to select if you need a follow-up (True/False).
* **Follow Up Date** (`follow_up_date`, `date`, required/optional): This field is used to enter the date for the follow-up.
* **Comments** (`comments`, `text`, required/optional): This field is used to enter any additional comments or notes about the reinstallation request.
* **Notes** (`notes`, `text`, required/optional): This field is used to enter any additional notes about the reinstallation request.

Tips: 
* Please ensure that all the required fields are filled out correctly before submitting the form.
* Review each field carefully before submitting to avoid errors.
* If you're unsure about any part of the process, do not hesitate to reach out to the relevant authorities for guidance. 
* Be accurate and concise when filling out the form.
