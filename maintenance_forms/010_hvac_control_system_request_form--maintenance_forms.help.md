# HVAC Control System Request Form - Help Guide

## Purpose
This form is used to submit requests for HVAC control system maintenance, adjustments, or issues. It helps the maintenance team track and prioritize these requests effectively.

## How To Complete This Form
To complete this form, follow these steps:

1. Provide a brief description of the HVAC control system issue or adjustment request in the **HVAC Control Issue** field.
2. Specify the type of adjustment or issue, such as **Heating**, **Cooling**, **Electrical**, or **Plumbing**.
3. Select the **Location** where the issue or adjustment is required.
4. Provide a detailed **Description** of the issue or adjustment request.
5. Set the **Priority** of the request, choosing from **High** or **Low**.
6. Enter the date and time when the issue or adjustment was first noticed in the **Date** and **Time** fields.
7. Enter your name and contact information in the **Submitter**, **Email**, and **Phone** fields.
8. Select the person or team member you would like to be assigned to handle the request in the **Assigned To** field.
9. Add any additional comments or notes in the **Comments** field.
10. Select the category of the form from the list of options.
11. Fill out the form completely and submit it to the maintenance team.
