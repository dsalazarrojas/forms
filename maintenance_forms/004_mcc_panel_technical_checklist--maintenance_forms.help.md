# MCC Panel Technical Checklist - Help Guide
## Purpose
This form is designed to collect information about the technical specifications of a MCC panel, which is a critical component in electrical and control systems.

## How To Complete This Form
To complete this form, please select the options for each field as accurately as possible based on your observations and knowledge of the MCC panel. Make sure to save the form after completing it.

## Field-by-Field Explanation
* **electrical_systems** (`electrical_systems`, select_one, required): Check if the electrical systems are present and functional.
* **electrical_systems_2** (electrical_systems_2, text, not required): Additional information about electrical systems.
* **electrical_systems_3** (electrical_systems_3, text, not required): More information about electrical systems.
* **mechanical_systems** (mechanical_systems, select_multiple, required): Check if the mechanical systems are present and functional.
* **mechanical_systems_2** (mechanical_systems_2, text, not required): Additional information about mechanical systems.
* **mechanical_systems_3** (mechanical_systems_3, text, not required): More information about mechanical systems.
* **hydraulic_systems** (hydraulic_systems, select_multiple, required): Check if the hydraulic systems are present and functional.
* **hydraulic_systems_2** (hydraulic_systems_2, text, not required): Additional information about hydraulic systems.
* **hydraulic_systems_3** (hydraulic_systems_3, text, not required): More information about hydraulic systems.
* **plumbing_systems** (plumbing_systems, select_multiple, required): Check if the plumbing systems are present and functional.
* **plumbing_systems_2** (plumbing_systems_2, text, not required): Additional information about plumbing systems.
* **plumbing_systems_3** (plumbing_systems_3, text, not required): More information about plumbing systems.
* **panel_mounting** (panel_mounting, select_multiple, required): Check if the panel mounting is present and secure.
* **panel_mounting_2** (panel_mounting_2, text, not required): Additional information about panel mounting.
* **panel_mounting_3** (panel_mounting_3, text, not required): More information about panel mounting.
* **electrical_connectors** (electrical_connectors, select_multiple, required): Check if the electrical connectors are present and secure.
* **electrical_connectors_2** (electrical_connectors_2, text, not required): Additional information about electrical connectors.
* **electrical_connectors_3** (electrical_connectors_3, text, not required): More information about electrical connectors.
* **control_panel** (control_panel, select_one, required): Check if the control panel is present and functional.
* **control_panel_2** (control_panel_2, text, not required): Additional information about control panel.
* **control_panel_3** (control_panel_3, text, not required): More information about control panel.
