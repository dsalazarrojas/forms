# Facility Maintenance Check Out Form - Help Guide

## Purpose
This form is intended for maintenance personnel to check out a facility or equipment for a specific period, ensuring accurate tracking of maintenance activities. It captures relevant information for both the maintenance crew and facility management.

## How To Complete This Form

To complete this form, follow these steps:

1. Determine if equipment or facility is borrowed or assigned. If borrowed, select "Yes" for "Equipment Borrowed". If assigned, select "Yes" for "Assigned Tool".
2. Enter the "Start Date" and "End Date" if the facility or equipment is checked out for a specific period.
3. Choose the "Check Out Duration" in number format.
4. Select "Yes" or "No" for "Facility Manager Name" to indicate if a manager is responsible for the maintenance activity.
5. Enter the "Contact Number" and "Email" to ensure proper communication with maintenance crew members.
6. Add any relevant "Notes" about the maintenance activity.
7. Select "Yes" or "No" for "Notes" if any additional information is needed.
8. Finally, select the "Facility Name" to identify the location of the maintenance activity.

## Field-by-Field Explanation

* **Equipment Borrowed**: 
  • Equipment Borrowed (Yes, No): Indicate if equipment is borrowed or not.
* **Assigned Tool**: 
  • Assigned Tool (Yes, No): Choose "Yes" if tool is assigned to a maintenance crew member.
* **Start Date**: 
  • Start Date: Enter the date when the maintenance activity starts.
* **End Date**: 
  • End Date: Enter the date when the maintenance activity ends.
* **Check Out Duration**: 
  • Check Out Duration: Enter the duration of the maintenance activity in numbers.
* **Facility Manager Name**: 
  • Facility Manager Name (Yes, No): Select "Yes" if facility manager is responsible for the maintenance activity.
* **Check Out Status**: 
  • Check Out Status (Active, Inactive): Choose "Active" or "Inactive" to indicate the status of the maintenance activity.
* **Comments**: 
  • Comments: Add any additional comments about the maintenance activity.
* **Assigned To**: 
  • Assigned To (Yes, No): Choose "Yes" if the maintenance activity is assigned to a crew member.
* **Contact Number**: 
  • Contact Number: Enter the contact number of the maintenance crew member.
* **Email**: 
  • Email: Enter the email of the maintenance crew member.
* **Notes**: 
  • Notes (Yes, No): Add or remove any additional notes for the maintenance activity.
* **Facility Name**: 
  • Facility Name: Select the name of the facility undergoing maintenance.
