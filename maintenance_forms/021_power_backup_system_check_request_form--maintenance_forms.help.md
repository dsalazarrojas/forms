# Power Backup System Check Request Form - Help Guide

## Purpose
This form is used to request a power backup system check for a specific location. It is intended for maintenance or repair purposes.

## How To Complete This Form

1. Please select the type of generator used in the building from the options provided.
2. Enter the unique identifier for the building where the power backup system is located.
3. Provide the physical address where the power backup system is located.
4. If applicable, enter the date and time of the last visit or check of the power backup system.
5. If applicable, enter the start and end times for the check.
6. Enter any additional information or comments about the power backup system or the request.

## Field-by-Field Explanation

* **Generator Type**: Select "Yes" if the building uses a generator as a power backup system. This will help the technicians to identify the type of equipment to check.
	+ Select "No" if the building does not use a generator.
* **Building ID**: Enter a unique identifier for the building where the power backup system is located. This helps to identify the location where the system is installed.
* **Address**: Enter the physical address where the power backup system is located. This is useful for navigation or further investigation.
* **Date of Visit**: If you are reporting a previous check or maintenance visit, enter the date of the visit. If not applicable, leave this field blank.
* **Start Time**: If you are scheduling a new check, enter the start time of the check. If not applicable, leave this field blank.
* **End Time**: If you are scheduling a new check, enter the end time of the check. If not applicable, leave this field blank.
* **Notes**: Enter any additional comments or information about the power backup system or the request. This is an optional field for extra details.

## Tips

* Make sure to fill out the form completely and accurately to ensure that the power backup system is checked correctly.
* If you are unsure about any of the fields, please reach out to the maintenance team for assistance.
* Please be specific about the date and time of the check, if applicable.
