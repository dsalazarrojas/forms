# Faucet Inspection Checklist - Help Guide
## Purpose
The Faucet Inspection Checklist is a form used to inspect faucets in residential or commercial buildings to evaluate their condition and functionality.

## How To Complete This Form
To complete the form, please follow these steps:
1. Determine the building type where the faucet inspection is being conducted. Select the correct building type from the "Building" field.
2. Identify the type of faucet being inspected. Select all applicable types from the "Faucet Type" field.
3. Evaluate the condition of the faucet and select the correct option from the "Condition" field.
4. Determine the location of the faucet. Select all applicable locations from the "Location" field.
5. If necessary, provide additional notes about the faucet's condition. This field is optional.
6. Upload up to 10 photos of the faucet from the "Photo 1" to "Photo 10" fields. These fields are optional.

## Field-by-Field Explanation
* **Building**: (Required)
Select the type of building where the faucet is located (e.g., residential, commercial, etc.).
* **Faucet Type**: (Required)
Select all applicable types of faucets (e.g., water-saving, standard, etc.).
* **Condition**: (Required)
Evaluate the faucet's condition based on the options provided (e.g., Option 1, Option 2, Option 3).
* **Location**: (Required)
Select all locations where the faucet is found (e.g., Kitchen, Bathroom, Basement, etc.).
* **Notes**: (Optional)
Provide any additional comments or notes about the faucet's condition.
* **Photo 1** to **Photo 10**: (Optional)
Upload up to 10 photos of the faucet for further reference.

## Tips
* Ensure all required fields are completed before submitting the form.
* Use clear and descriptive labels for the photos uploaded.
* If you're unsure about any field, refer to the form's purpose and instructions above.
