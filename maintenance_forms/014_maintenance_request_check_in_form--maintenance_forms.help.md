# maintenance_request_check_in_form - Help Guide
## Purpose
The maintenance request check-in form is used to report issues with equipment, track maintenance activities, and schedule repairs. It is essential to fill out this form accurately and completely to ensure that maintenance teams can efficiently address the problem.

## How To Complete This Form
To complete this form, follow these steps:

1.  Enter a brief description of the issue you are reporting in the "report_issue" field.
2.  Provide a detailed description of the problem in the "description" field.
3.  Enter the date you first noticed the issue in the "report_date" field.
4.  Enter the time you first noticed the issue in the "report_time" field.

## Field-by-Field Explanation
* **prophets** (`report_issue`, text, required/optional): A brief description of the issue you are reporting.
* **description** (`description`, text, required/optional): A detailed description of the problem, including any error messages or symptoms you have encountered.
* **report_date** (`report_date`, date, required/optional): The date you first noticed the issue.
* **report_time** (`report_time`, time, required/optional): The time you first noticed the issue.
