# Server Maintenance Checklist - Help Guide
## Purpose
The Server Maintenance Checklist is a form used to record and report server maintenance activities, including any issues or problems encountered during the process. This form helps server administrators or IT professionals stay organized, prioritize tasks, and provide a clear record of their activities.

## How To Complete This Form
To complete this form, follow these steps:

1.  Click on the "Server Maintenance" page.
2.  Complete the required fields:
    *  Select the "Date" of the maintenance activity.
    *  Enter the "Time" of the maintenance activity.
    *  Provide a brief "Description" of the maintenance activity.
3.  Indicate if "Assistance Needed" is required for the activity.
4.  Select the "Assistance Type" if assistance is needed.
5.  Report the "Server Status" after maintenance.

## Field-by-Field Explanation
* **Server Maintenance** (`checklist`, `note`, required: false): This field is a note field where you can enter any notes or comments about the maintenance activity.
* **Date** (`date`, `optional`: false): Enter the date of the maintenance activity.
* **Time** (`time`, `optional`: false): Enter the time of the maintenance activity.
* **Description** (`text`, `optional`: false): Provide a brief description of the maintenance activity.
* **Assistance Needed** (`select_multiple`, `optional`: false): Check if any assistance is needed for this activity.
* **Assistance Type** (`select_one`, `optional`: false): Select the type of assistance needed if checked.
* **Server Status** (`select_one`, `optional`: false): Report the status of the server after maintenance (Up, Down, or Unknown).

## Tips
* Make sure to fill out all required fields.
* Be as detailed as possible when providing the "Description" of the maintenance activity.
* If assistance is needed, select the correct "Assistance Type" to help the support team prioritize tasks efficiently.
