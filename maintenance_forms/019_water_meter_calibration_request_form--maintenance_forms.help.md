# Water Meter Calibration Request Form - Help Guide
## Purpose
The Water Meter Calibration Request Form is used by facilities management to request calibration of water meters in the building's utilities department.

## How To Complete This Form
Fill out the form completely and accurately. Make sure that the meter serial number is correct and that all fields marked as required are filled out.

## Field-by-Field Explanation
* **Meter Serial Number (`meter_serial_number`, text, required)**: The meter's serial number is required to identify the correct meter to be calibrated.
* **Meter Reading Date (`meter_reading_date`, date, optional)**: Optional field to input the date of the meter reading. If left blank, the form will default to the current date.
* **Meter Reading Value (`meter_reading_value`, text, optional)**: Optional field to input the meter reading value. If left blank, the form will default to the current reading.
* **Calibration Interval (`calibration_interval`, select, optional)**: Select from the available options to specify the calibration interval for the meter.
* **Comments (`comments`, note, optional)**: A notes field for any additional comments or information.
* **Email Address (`email_address`, email, optional)**: A field to input the meter's email address.
* **Phone Number (`phone_number`, text, optional)**: A field to input the meter's phone number.

**Tips**: Please make sure that the meter serial number is correct and that all required fields are filled out to ensure that your request is processed correctly.
