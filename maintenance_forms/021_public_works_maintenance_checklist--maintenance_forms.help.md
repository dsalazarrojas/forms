# public_works_maintenance_checklist - Help Guide
## Purpose
The public works maintenance checklist form is used to track and maintain public works projects.

## How To Complete This Form
To complete this form, follow the steps below:
- Select the maintenance tasks that apply to the project.
- Provide a description of the selected tasks.
- Set the start and end dates for the project.
- Specify who is assigned to complete the tasks.
- Set the status of the project.
- Add any additional notes or comments.
- Enter the email and phone contact information for the project.
- Select the category and subcategory of the project.
- Set the priority level for the project.
- Set a deadline for the project.
- Specify the type of task.

## Field-by-Field Explanation
- **Select Maintenance Tasks**: This field is used to select the maintenance tasks that apply to the project.
  • Select one or more options from the provided list.
- **Description**: This field is used to provide a brief description of the selected tasks.
  • Type in a short description of the tasks.
- **Start Date**: This field is used to set the start date of the project.
  • Select a date using the calendar picker.
- **End Date**: This field is used to set the end date of the project.
  • Select a date using the calendar picker.
- **Assigned To**: This field is used to specify who is assigned to complete the tasks.
  • Type in the name or title of the person assigned.
- **Assigned Tool**: This field is used to specify the tool or equipment used to complete the tasks.
  • Type in the name or title of the tool or equipment.
- **Status**: This field is used to set the status of the project.
  • Select one of the provided options: Active or Inactive.
- **Notes**: This field is used to add any additional notes or comments.
  • Type in any additional comments or notes.
- **Email**: This field is used to enter the email contact information for the project.
  • Type in the email address.
- **Phone**: This field is used to enter the phone contact information for the project.
  • Type in the phone number.
- **Category**: This field is used to select the category of the project.
  • Select one of the provided options.
- **Subcategory**: This field is used to select the subcategory of the project.
  • Select one of the provided options.
- **Priority**: This field is used to set the priority level of the project.
  • Select one of the provided options.
- **Deadline**: This field is used to set a deadline for the project.
  • Select a date using the calendar picker.
- **Task Type**: This field is used to specify the type of task.
  • Select one of the provided options.
