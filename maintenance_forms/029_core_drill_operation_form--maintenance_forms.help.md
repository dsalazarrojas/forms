# Core Drill Operation Form - Help Guide
## Purpose
The Core Drill Operation Form is used to record and document the details of a core drilling operation. This form is intended to collect information about the core drilling process, including the drilling date, time, location, and results. The form is divided into several sections, each of which is dedicated to a specific aspect of the core drilling operation.

## How To Complete This Form
To complete this form, follow these steps:

* Click on the "New Entry" button to create a new entry for the core drilling operation.
* Enter the date and time of the core drilling operation on pages 2 and 3.
* Select the drill number and drilling fluid used on page 4.
* Choose the drilling method and tools used on page 9.
* Select the drilling status on page 12.
* Enter the drilling start and finish times on pages 13 and 14.
* Enter the drilling depth on page 15.
* Provide a description of the drilling area on page 16.
* Optional: Enter any comments about the drilling area on page 17.

## Field-by-Field Explanation
* **Core Drill Operation Form 1** (`core_drill_operation_form_page_1`, text, optional): A brief description of the core drilling operation.
* **Drill Number** (`core_drill_operation_form_page_4`, number, required): A unique identifier for the drill.
* **Drill Bit** (`core_drill_operation_form_page_6`, text, optional): The type of drill bit used.
* **Drilling Fluid** (`core_drill_operation_form_page_7`, text, optional): The type of drilling fluid used.
* **Drilling Method** (`core_drill_operation_form_page_8`, text, optional): The method used for drilling.
* **Drilling Tool** (`core_drill_operation_form_page_9`, select_multiple, required): Select the tools used during the drilling operation.
* **Drilling Area** (`core_drill_operation_form_page_10`, text, optional): A description of the area drilled.
* **Drilling Operation** (`core_drill_operation_form_page_11`, text, optional): A description of the drilling operation.
* **Drilling Status** (`core_drill_operation_form_page_12`, select_one, required): Select the current status of the drilling operation (Running or Complete).
* **Drilling Start Time** (`core_drill_operation_form_page_13`, date, required): The start time of the drilling operation.
* **Drilling Finish Time** (`core_drill_operation_form_page_14`, time, required): The finish time of the drilling operation.
* **Drill Depth** (`core_drill_operation_form_page_15`, number, required): The depth of the drilled core.
* **Drilling Area Description** (`core_drill_operation_form_page_16`, text, optional): A description of the drilling area.
* **Drilling Area Comments** (`core_drill_operation_form_page_17`, text, optional): Optional comments about the drilling area.
* **Drilling Area Location** (`core_drill_operation_form_page_18`, text, optional): A description of the location of the drilling area.
* **Drilling Area Location Latitude** (`core_drill_operation_form_page_19`, text, optional): The latitude of the drilling location.
* **Drilling Area Location Longitude** (`core_drill_operation_form_page_20`, text, optional): The longitude of the drilling location.
* **Drilling Area Location Elevation** (`core_drill_operation_form_page_21`, text, optional): The elevation of the drilling location.
* **Drilling Start Location** (`core_drill_operation_form_page_22`, text, optional): A description of the start location of the drilling operation.
* **Drilling Finish Location** (`core_drill_operation_form_page_23`, text, optional): A description of the finish location of the drilling operation.
* **Drilling Start Location Latitude** (`core_drill_operation_form_page_24`, text, optional): The latitude of the start location of the drilling operation.
* **Drilling Finish Location Longitude** (`core_drill_operation_form_page_25`, text, optional): The longitude of the finish location of the drilling operation.

## Tips
* Please ensure that all required fields are filled before submitting the form.
* If a field is left blank, it may affect the accuracy and completeness of the recorded data.
* Review the form carefully to ensure that all information is accurate and up-to-date.
* If you are unsure about any field, please consult with your supervisor or the form administrator.
* The form is designed to be user-friendly and easy to navigate. If you encounter any issues or need assistance, please don't hesitate to contact us.
