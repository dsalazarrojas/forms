# Website Maintenance Renewal Agreement - Help Guide

## Purpose
The Website Maintenance Renewal Agreement form is used to capture and manage the details of website maintenance agreements. This includes the website URL, contract start and end dates, renewal frequency, and payment information. The form helps in ensuring that website maintenance is performed on time and according to the agreed-upon terms.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the website URL in the "Website URL" field.
2. Select the start and end dates of the maintenance contract in the respective fields.
3. Choose the renewal frequency (if applicable).
4. Enter the start date of the renewal period.
5. Select the payment frequency (if applicable).
6. Enter the payment details (amount and method).
7. Mark the agreement as signed or not signed.

## Field-by-field Explanation
* **Website URL** (`website_url`, text, required): Enter the URL of the website that requires maintenance.
* **Maintenance Contract Start Date** (`maintenance_contract_start_date`, date, required): Select the start date of the maintenance contract.
* **Maintenance Contract End Date** (`maintenance_contract_end_date`, date, required): Select the end date of the maintenance contract.
* **Renewal Frequency** (`renewal_frequency`, select_one, optional): Select the frequency at which the maintenance contract should be renewed (if applicable).
* **Renewal Start Date** (`renewal_start_date`, date, required): Select the start date of the renewal period.
* **Payment Frequency** (`payment_frequency`, select_one, optional): Select the payment frequency (one-time or ongoing payments).
* **Payment Amount** (`payment_amount`, number, required): Enter the payment amount.
* **Payment Method** (`payment_method`, select_one, optional): Select the payment method (credit card, cheque, or bank transfer).
* **Payment Status** (`payment_status`, select_one, optional): Mark the payment status as paid or unpaid.
* **Maintenance Agreement Signed** (`maintenance_agreement_signed`, select_one, optional): Mark the agreement as signed or not signed.
