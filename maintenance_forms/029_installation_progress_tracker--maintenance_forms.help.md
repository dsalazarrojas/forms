# Installation Progress Tracker - Help Guide
## Purpose
The Installation Progress Tracker form is a tool designed to track the progress of installations. It helps users to record and review information related to the installation stages, start and end dates, and status.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the stage of the installation progress from the options provided.
2. Enter the start date of the installation.
3. Enter the end date of the installation.
4. Enter the update date of the last action taken on the installation.
5. Provide a description of the installation stage.
6. Choose the status of the installation (Complete, In Progress, or Not Started).
7. Enter the user who last updated the installation information.
8. Enter the time of the last update.
9. Enter the time of creation of the installation.

## Field-by-Field Explanation

* **Stage** (`stage`,  text): Enter a brief description of the current installation stage.
* **Stage ID** (`stage_id`, number): Enter a unique identifier for the installation stage (optional).
* **Start Date** (`start_date`, date): Enter the date when the installation started.
* **End Date** (`end_date`, date): Enter the date when the installation ended (if applicable).
* **Update Date** (`update_date`, date): Enter the date of the last update made on the installation.
* **Stage Name** (`stage_name`, text): Enter a brief description of the installation stage.
* **Stage Description** (`stage_description`, text): Enter a detailed description of the installation stage.
* **Stage Status** (`stage_status`, select_one): Select the status of the installation (Complete, In Progress, or Not Started).
* **Updated By** (`updated_by`, text): Enter the user who last updated the installation information.
* **Updated At** (`updated_at`, text): Enter the time of the last update.
* **Created At** (`created_at`, text): Enter the time of creation of the installation.

## Tips
* Make sure to fill out all required fields accurately and completely.
* Use the correct status option (Complete, In Progress, or Not Started) for the current stage of the installation.
* Enter dates in the correct format (YYYY-MM-DD).
* Use the "Updated By" field to record the user who made the last update.
* Use the "Updated At" field to record the time of the last update.
* Use the "Created At" field to record the time of creation of the installation.
