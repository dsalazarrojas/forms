# Fire Safety Equipment Test Request Form - Help Guide
## Purpose
The Fire Safety Equipment Test Request Form is used for requesting fire safety equipment tests. This form is designed to gather information about the test request, including the test date and time, test frequency, and any additional comments or notes.

## How To Complete This Form
To complete this form, follow these steps:

1.  Review the form carefully and make sure you have all the necessary information before starting.
2.  Fill out the **Request Details** field with a brief description of the test request.
3.  Enter the **Test Frequency** (1, 2, or 3 times a year) that best describes how often you would like the equipment tested.
4.  Choose the date and time you would like the test to take place on. The date and time should be a valid date and time in the future.
5.  Add any **Additional Notes** you would like to include with the request, such as any specific issues or concerns you have.

## Field-by-Field Explanation

* **Request Details** (`request_details`, text, required): Please enter a brief description of the test request, including the type of test or maintenance required.
* **Test Frequency** (`test_frequency`, number, optional): Choose how often you would like the equipment to be tested (1, 2, or 3 times a year).
* **Test Date** (`test_date`, date, optional): Choose a valid date and time for the test to take place.
* **Test Time** (`test_time`, time, optional): Choose a valid time for the test to take place.
* **Additional Notes** (`notes`, note, optional): Add any additional comments or notes about the request.
* **Assigned To** (`assigned_to`, text, optional): Enter the name of the person or team responsible for completing the test.

## Tips
* Make sure to double-check all fields before submitting the form to ensure that it is complete and accurate.
* If you are unsure about any of the fields, please reach out to the designated contact person for assistance.
* This form should be submitted once per test request. If multiple tests are required, please submit multiple forms.
