# Facility Maintenance Status Report Form - Help Guide
## Purpose
The purpose of this form is to report on the status of maintenance requests for facilities. Please use this form to update the status of maintenance requests as needed.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the maintenance request you wish to update (if applicable).
2. Choose the status of the maintenance request from the dropdown options.
3. Fill out any applicable fields, such as the description or asset ID.
4. Select the type of maintenance (mechanical, electrical, etc.) and asset type (building, equipment, etc.).
5. Enter the date the maintenance was completed (if applicable).

## Field-by-Field Explanation
* **Maintenance Request** (`maintenance_request`, text, not required): Briefly describe the maintenance request, such as a problem or issue you are reporting.
* **Facility ID** (`facility_id`, number, not required): Enter the ID of the facility where the maintenance request is located.
* **Maintenance Status** (`maintenance_status`, select_one, required): Select the current status of the maintenance request from the dropdown options (Approved, Not Started, In Progress, Completed).
* **Repair Type** (`repair_type`, select_one, not required): Select the type of maintenance (Mechanical, Electrical, Plumbing, HVAC, Other).
* **Description** (`description`, text, not required): Enter a detailed description of the maintenance request, such as the specific issue or problem being addressed.
* **Asset ID** (`asset_id`, number, not required): Enter the ID of the asset being maintained.
* **Asset Type** (`asset_type`, select_one, required): Select the type of asset being maintained (Building, Equipment, Vehicle, Other).
* **Date Completed** (`date_completed`, date, not required): Enter the date the maintenance was completed (if applicable).

## Tips
* Please ensure that all fields are completed before submitting the form.
* If the maintenance request is no longer applicable, please delete it from the system.
* If you are unsure about any field or have questions, please reach out to the facility management team for assistance.
