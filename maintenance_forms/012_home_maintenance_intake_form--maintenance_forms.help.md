# Home Maintenance Intake Form - Help Guide
## Purpose
This form is used to collect information for home maintenance requests from residents or property managers.

## How To Complete This Form
To complete this form, please follow the steps below:

1. Fill in the **Maintenance Request Form** section with a brief description of the maintenance request.
2. Enter the **Property Details** section with any relevant information about the property (e.g. address, unit number, etc.).
3. Provide your **Contact Details** in the **Contact Details** section, including your name, email, and phone number.
4. Choose a **Priority** level for your request (Urgent, High, or Low).
5. Enter your **Property Address** in the **Property Address** section.
6. Enter the **Contact Name**, **Contact Email**, and **Contact Phone** for the person submitting the request.
7. Add any additional **Notes** or **Comments** if necessary.
8. Select the **Assigned Tool** responsible for the maintenance request.
9. Enter the **Submission Date** and **Submission Time** of the request.
10. Choose the current **Status** of the request (Pending, In Progress, or Completed).
11. Enter the **Property Manager Name**, **Property Manager Email**, and **Property Manager Phone** if applicable.
12. Enter the **Landlord Name**, **Landlord Email**, and **Landlord Phone** if applicable.
13. Add any additional **Property Manager Notes** or **Landlord Notes** if necessary.

## Field-by-Field Explanation

* **Maintenance Request Form** (maintenance_request_form, text, required): A brief description of the maintenance request.
* **Property Details** (property_details, text, required): Any relevant information about the property (e.g. address, unit number, etc.).
* **Contact Details** (contact_details, text, required): Your name, email, and phone number.
* **Date** (maintenance_request_date, date, required): The date the request was submitted.
* **Start Time** (start_time, time, required): The time the request was submitted.
* **End Time** (end_time, time, required): The time the request was completed.
* **Priority** (maintenance_request_priority, select_one, required): The level of priority for the request (Urgent, High, or Low).
* **Property Address** (property_address, text, required): The address of the property.
* **Contact Name** (contact_name, text, required): The name of the person submitting the request.
* **Contact Email** (contact_email, email, required): The email of the person submitting the request.
* **Contact Phone** (contact_phone, text, required): The phone number of the person submitting the request.
* **Notes** (notes, note, required): Any additional comments or notes about the request.
* **Comments** (comments, text, required): Any additional comments or notes about the request.
* **Assigned Tool** (assigned_tool, select_one, required): The tool or person responsible for the maintenance request.
* **Submission Date** (submission_date, date, required): The date the request was submitted.
* **Submission Time** (submission_time, time, required): The time the request was submitted.
* **Status** (maintenance_request_status, select_one, required): The current status of the request (Pending, In Progress, or Completed).
* **Property Manager Name** (property_manager_name, text, required): The name of the property manager.
* **Property Manager Email** (property_manager_email, email, required): The email of the property manager.
* **Property Manager Phone** (property_manager_phone, text, required): The phone number of the property manager.
* **Property Manager Notes** (property_manager_notes, note, required): Any additional notes from the property manager.
* **Landlord Name** (landlord_name, text, required): The name of the landlord.
* **Landlord Email** (landlord_email, email, required): The email of the landlord.
* **Landlord Phone** (landlord_phone, text, required): The phone number of the landlord.
* **Landlord Notes** (landlord_notes, note, required): Any additional notes from the landlord.
