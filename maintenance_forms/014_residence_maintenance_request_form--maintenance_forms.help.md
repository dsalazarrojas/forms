# Residence Maintenance Request Form - Help Guide
## Purpose
The Residence Maintenance Request Form is a tool for users to submit requests for maintenance work on a residence. This form is used to collect information about the request, including the category, description, priority, and contact information.

## How To Complete This Form
To submit a residence maintenance request, follow these steps:
- Select the category of the maintenance request (e.g., Maintenance Forms).
- Provide a brief description of the maintenance request.
- Choose the priority of the request (High, Medium, or Low).
- Enter the specific maintenance request details.
- Provide contact information for follow-up.

## Field-by-Field Explanation

* **Category** (optional): Select the category that best describes the maintenance request (e.g., Maintenance Forms).
* **Description** (optional): Enter a brief description of the maintenance request.
* **Priority** (optional): Choose the level of priority for the request (High, Medium, or Low).
* **Maintenance Request** (required): Enter a detailed description of the maintenance request.
* **Contact Info** (optional): Provide contact information for follow-up, including name, phone number, and email.
* **Email** (required): Enter a valid email address for follow-up communication.

## Tips
- Please ensure that the information provided is accurate and complete.
- Duplicate requests will not be accepted.
- If the request is urgent or requires immediate attention, please indicate this in the maintenance request field.
- If you have any questions or need further assistance, please contact us at [insert contact information].
