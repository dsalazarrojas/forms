# Service Request Work Order - Help Guide

## Purpose

This form is used to collect and manage service requests.

## How To Complete This Form

### Step 1: Select the Type of Request

*   **Request Type** (`Request Type`, select_one): Choose the type of service request you are submitting. Options include Service Call, Preventative Maintenance, Emergency, and Planned Maintenance.

### Step 2: Specify the Priority Level

*   **Priority Level** (`Priority Level`, select_one): Choose the priority level of the service request. Options include High, Medium, and Low.

### Step 3: Enter Request Details

*   **Request Date** (`Request Date`, date): Enter the date the service request was made.
*   **Request Time** (`Request Time`, time): Enter the time the service request was made.
*   **Location** (`Location`, text): Enter the location where the service request was made.
*   **Description** (`Description`, text): Enter a brief description of the service request.
*   **Scheduled Visit Date** (`Scheduled Visit Date`, date): Enter the date for the scheduled visit.
*   **Scheduled Visit Time** (`Scheduled Visit Time`, time): Enter the time for the scheduled visit.
*   **Service Provider** (`Service Provider`, select_one): Choose the service provider assigned to handle the request. Options include ABC, DEF, and GHI.
*   **Service Request ID** (`Service Request ID`, number): Enter the unique identifier for the service request.
*   **Service Request Comments** (`Service Request Comments`, text): Enter any additional comments or notes for the service request.

## Field-by-Field Explanation

*   **Service Request Status** (`Service Request Status`, select_one): Choose the current status of the service request. Options include Pending, In Progress, Completed, and Cancelled.
*   **Service Request Notes** (`Service Request Notes`, text): Enter any additional information or notes for the service request.
*   **Service Request Attachments** (`Service Request Attachments`, text): Attach any relevant files or documents to provide more context.
*   **Assigned To** (`Assigned To`, select_one): Choose the person or team assigned to handle the service request. Options include Maintenance Team, Property Manager, and Service Provider.

## Tips

*   Make sure to select the correct type of request and priority level to ensure timely processing.
*   Enter clear and concise descriptions to facilitate quick understanding of the service request.
*   Attach any relevant files or documents to provide more context.
*   Use the comments field for any additional information that may be needed.

Please note that this guide assumes that the form has been filled out correctly. If you have any questions or concerns, please reach out to the relevant personnel for assistance.
