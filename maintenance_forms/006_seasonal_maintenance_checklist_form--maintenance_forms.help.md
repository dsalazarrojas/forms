# Seasonal Maintenance Checklist Form - Help Guide
## Purpose
This form is designed to aid property owners and managers in tracking and documenting seasonal maintenance tasks for their properties.

## How To Complete This Form
1. Select the relevant seasonal tasks for each season by choosing the corresponding options under "Seasonal tasks" and "Select season tasks" fields.
2. Note down the specific tasks to be performed by the "Seasonal tasks selected" field.
3. Provide property details such as address, owner's name, phone number, and email.
4. Add any additional comments or notes in the "Property notes" field.
5. Set the status of the maintenance checklist to "Not started", "Started", or "Completed".
6. Optionally set the due date and due time for the maintenance checklist.
7. Add any comments or notes for future reference.

## Field-by-Field Explanation

* **Seasonal maintenance checklist form**: This is the form header.
* **Select seasonal tasks**: Select all relevant seasonal tasks for each season using the dropdown options.
* **Select seasonal tasks selected**: Select all relevant seasonal tasks for each season from the options listed below.
* **Spring tasks**: Select all relevant spring tasks from the options listed below.
* **Select spring tasks**: Select all relevant spring tasks.
* **Fall tasks**: Select all relevant fall tasks from the options listed below.
* **Select fall tasks**: Select all relevant fall tasks.
* **Summer tasks**: Select all relevant summer tasks from the options listed below.
* **Select summer tasks**: Select all relevant summer tasks.
* **Winter tasks**: Select all relevant winter tasks from the options listed below.
* **Select winter tasks**: Select all relevant winter tasks.
* **Others**: Select all other tasks that don't fit into a specific season.
* **Property address**: Enter the property address.
* **Property owner**: Enter the property owner's name.
* **Property owner phone**: Enter the property owner's phone number.
* **Property owner email**: Enter the property owner's email address.
* **Property notes**: Add any additional comments or notes about the property.
* **Property Notes 2**: Add any additional comments or notes about the property (if needed).
* **Maintenance checklist notes**: Add any additional comments or notes about the maintenance checklist.
* **Maintenance Checklist Notes 2**: Add any additional comments or notes about the maintenance checklist (if needed).
* **Seasonal maintenance checklist status**: Select the status of the maintenance checklist as "Not started", "Started", or "Completed".
* **Due date**: Optionally select the due date for the maintenance checklist.
* **Due time**: Optionally select the due time for the maintenance checklist.
* **Comments**: Add any comments or notes for future reference.
* **Completed**: Optionally enter the date when the maintenance checklist was completed.
* **Seasonal maintenance checklist form**: This is the form footer.
