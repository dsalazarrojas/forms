# Gym Maintenance Request Form - Help Guide
## Purpose
The Gym Maintenance Request Form is used to report maintenance issues or request services for the gym's facilities and equipment. This form helps gym staff to efficiently manage maintenance requests and ensure that issues are addressed promptly.

## How To Complete This Form
To complete this form, follow these steps:

1. Describe the problem or maintenance request in the **Problem Description** field.
2. Indicate whether the maintenance request is for a **Maintenance Type** (e.g., equipment repair, facility cleaning) and select the corresponding option.
3. Specify the **Priority** of the request (e.g., high, low).
4. Select the staff member or team to be **Assigned To** (e.g., facilities team, equipment maintenance team).
5. Enter the **Date** and **Time** of the maintenance request.
6. Provide more details about the **Maintenance Request** in the **Maintenance Request Details** field.
7. Indicate if **Equipment Damaged** is involved.
8. Enter any additional information about the **Maintenance Type Details**.
9. Select the **Maintenance Status** (e.g., active, inactive).
10. Enter the **Resolved Date** and **Resolved Time** if the issue has been resolved.
11. Add any **Comments** about the issue or request.
12. Select the staff member or team to be **Assigned To** for the maintenance request.

## Field-by-Field Explanation

* **Maintenance Request**: Enter a brief description of the maintenance request.
* **Problem Description**: Describe the problem or issue that requires maintenance.
* **Maintenance Type**: Select the type of maintenance required (e.g., equipment repair, facility cleaning).
* **Priority**: Indicate the priority of the maintenance request (e.g., high, low).
* **Assigned To**: Select the staff member or team to be assigned to the maintenance request.
* **Date**: Enter the date of the maintenance request.
* **Time**: Enter the time of the maintenance request.
* **Maintenance Request Details**: Provide more details about the maintenance request.
* **Equipment Damaged**: Indicate if equipment is damaged.
* **Maintenance Type Details**: Enter any additional information about the maintenance type.
* **Location**: Enter the location of the maintenance request (e.g., equipment room, gym floor).
* **Maintenance Status**: Select the status of the maintenance request (e.g., active, inactive).
* **Resolved Date**: Enter the date the issue was resolved.
* **Resolved Time**: Enter the time the issue was resolved.
* **Comments**: Add any comments about the issue or request.
* **Assigned To**: Select the staff member or team to be assigned to the maintenance request.
