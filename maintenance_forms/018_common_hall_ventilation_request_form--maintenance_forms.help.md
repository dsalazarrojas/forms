# Common Hall Ventilation Request Form - Help Guide

## Purpose
This form is used to report issues with common halls' ventilation systems. Please fill out this form to report any problems you're experiencing, such as poor air circulation, unpleasant odors, or excessive heat or cold. Your detailed report will help our facilities team assess the situation and take necessary steps to resolve the issue.

## How To Complete This Form

1.  Fill out each field carefully and thoroughly, providing as much information as possible.
2.  Review your responses before submitting the form to ensure you've included all necessary details.
3.  If you're unsure about any field, refer to the field-by-field explanations below for guidance.

## Field-by-Field Explanation

* **Request Information** (`request_information`, note, optional): A text box for any additional details you'd like to provide about your request.
* **Request Date** (`request_date`, date, required): The date you're submitting this request.
* **Request ID** (`request_id`, text, required): A unique reference number for this request.
* **Requester Information** (`requester_information`, note, optional): A text box for any additional information about the person making this request.
* **Requester Name** (`requester_name`, text, required): The full name of the person making this request.
* **Requester Email** (`requester_email`, email, required): The contact email address of the person making this request.
* **Requester Phone** (`requester_phone`, text, optional): The contact phone number of the person making this request.
* **Department** (`department`, text, optional): Your department or division name.
* **Property Information** (`property_information`, note, optional): A text box for any details about the building location.
* **Building Name** (`building_name`, text, required): The name of the building where the issue is occurring.
* **Building Address** (`building_address`, text, required): The full address of the building where the issue is occurring.
* **Location Details** (`location_details`, note, optional): A text box for any additional information about the location.
* **Hall Location** (`hall_location`, text, required): The specific hall where the ventilation issue is occurring.
* **Floor Level** (`floor_level`, text, required): The floor affected by the issue.
* **Zone Area** (`zone_area`, text, optional): The specific zone or area within the hall affected.
* **Issue Details** (`issue_details`, note, optional): A text box for any additional information about the issue.
* **Issue Type** (`issue_type`, select_one, required): The type of ventilation issue you're experiencing (e.g., Poor Air Circulation, Unpleasant Odors, etc.).
* **Issue Severity** (`issue_severity`, select_one, required): The severity level of the issue (e.g., Minor, Moderate, Severe, Critical).
* **Issue Duration** (`issue_duration`, select_one, required): The length of time the issue has been occurring (e.g., Less than 1 day, 1-3 days, etc.).
* **Affected Population** (`affected_population`, select_one, required): An estimate of the number of people affected by the issue (e.g., 1-5 people, 6-20 people, etc.).
* **Health Concerns** (`health_concerns`, select_one, required): Whether there are any health concerns related to this issue (e.g., Yes - Urgent, Yes - Moderate, etc.).
* **Health Concern Details** (`health_concern_details`, text, optional): A text box for any additional information about health concerns.
* **Previous Reports** (`previous_reports`, select_one, required): Whether this issue has been reported before (e.g., Yes, No).
* **Priority Request** (`priority_request`, select_one, required): The requested priority level (e.g., Low, Medium, High, Emergency).
* **Additional Comments** (`additional_comments`, text, optional): A text box for any additional information or comments.
* **Preferred Contact Time** (`preferred_contact_time`, select_one, optional): The best time to contact you regarding this issue (e.g., Morning, Afternoon, etc.).
