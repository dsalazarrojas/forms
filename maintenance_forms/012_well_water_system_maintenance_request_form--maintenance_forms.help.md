# Well Water System Maintenance Request Form - Help Guide

## Purpose
This form is designed to collect information for maintenance requests related to the well water system. It will guide you in reporting any issues, scheduling service visits, and providing essential details for the maintenance teams to address the problem efficiently.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the **Maintenance Request Form** section with a clear and concise description of the issue or problem you are experiencing with the well water system.
2. Select the **Urgency Level** that best describes the priority of the issue. Choose from the available options: **Urgent**, **Not Urgent**, or **Low Priority**.
3. Provide the scheduled date for the **Service Visit** in the **Service Visit Scheduled Date** field. If no date is selected, it will be considered as 'No date scheduled'.
4. Enter the planned time for the **Service Visit** in the **Service Visit Scheduled Time** field. If no time is selected, it will be considered as 'No time scheduled'.
5. Enter any additional relevant information about the **Well System Data**.
6. If you have a preferred team for the maintenance visit, please select it in the **Maintenance Teams** field.
7. Describe the current status of the well system in the **Well System Status** field.
8. Add any **Comments** about the issue or problem you are experiencing.
9. If you have a **Phone Number**, please enter it so we can contact you for further clarification.

## Field-by-Field Explanation

* **Maintenance Request Form (1)**: Enter a clear and concise description of the issue or problem you are experiencing with the well water system.
* **System Service Request (2)**: Provide a brief description of the issue or problem you are experiencing with the system.
* **Urgency Level (3)**: Select all that apply to indicate the priority of the issue. Urgent issues require immediate attention. Not Urgent and Low Priority issues can be scheduled at a later time.
* **Service Visit Scheduled Date (4)**: Enter the date for the scheduled service visit. If no date is selected, it will be considered as 'No date scheduled'.
* **Service Visit Scheduled Time (5)**: Enter the time for the scheduled service visit. If no time is selected, it will be considered as 'No time scheduled'.
* **Well System Data (6)**: Enter any relevant information about the well system, such as meter reading or water quality issues.
* **Maintenance Teams (7)**: Select the preferred maintenance team to handle the issue. If no team is selected, the default team will be assigned.
* **Well System Status (8)**: Describe the current status of the well system, including any issues or problems.
* **Comments (9)**: Add any additional comments or details about the issue.
* **Phone Number (10)**: Enter a phone number where we can contact you for further clarification or scheduling updates.
