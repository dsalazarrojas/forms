# Maintenance Inspection Request Form - Help Guide

## Purpose
The Maintenance Inspection Request Form is designed to capture information for maintenance inspections on tanks and pumps. This form helps to ensure that all necessary details are recorded and communicated effectively, facilitating a thorough inspection process.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill out the "maintenance_inspection_request_form" section, which is a text field where you can provide a brief description of the maintenance inspection request.
2. In the "tank_photos_section", you can add any relevant photos of the tank(s) that require inspection.
3. Similarly, in the "pump_photos_section", you can add any relevant photos of the pump(s) that need to be inspected.

## Field-by-Field Explanation

* **maintenance_inspection_request_form** (<type> text): This field is a text input where you can type a brief description of the maintenance inspection request. Please provide a clear and concise statement of the issue or problem you'd like the maintenance team to investigate.
* **tank_photos_section** (<type> note): This field allows you to attach photos of the tank(s) that need to be inspected. You can add one or more photos to provide visual documentation of the issue. Make sure to include clear and well-lit photos with good resolution.
* **pump_photos_section** (<type> note): Similar to the tank_photos_section, this field is used to attach photos of the pump(s) that require inspection. Include clear and well-lit photos with good resolution to facilitate a thorough inspection.
