# Facility Features Assessment - Help Guide
## Purpose
This form is designed to assess the features of a facility, providing a systematic and comprehensive evaluation of the different aspects of a facility.

## How To Complete This Form

To complete this form, follow these steps:

1. Select the facility name from the list of available options. This is the facility you are assessing.
2. For each feature, select the options that apply to the facility.
3. Fill out the inspection date, which is the date of the assessment.
4. Make sure to complete all fields, as some are required for the assessment to be complete.

## Field-by-Field Explanation

* **Facility Name** (`facility_name`, `select_one`, required): Select the correct facility name from the list.
* **Inspection Date** (`inspection_date`, `date`, required): Enter the date of the assessment.
* **Feature 1** (`feature_1`, `select_multiple`, required): Select all applicable options for this feature.
* **Feature 2** (`feature_2`, `select_one`, required): Select the most accurate option for this feature.
* **Feature 3** (`feature_3`, `select_one`, required): Select the most accurate option for this feature.
* **Feature 4** (`feature_4`, `select_multiple`, required): Select all applicable options for this feature.
* **Feature 5** (`feature_5`, `select_multiple`, optional): Select all applicable options for this feature (if applicable).

## Tips

* Make sure to select the correct options for each feature to ensure an accurate assessment.
* For features with multiple options, select all that apply.
* If a feature does not apply, select "None" or do not fill in the field.
* Double-check the form before submitting to ensure all required fields are complete.
