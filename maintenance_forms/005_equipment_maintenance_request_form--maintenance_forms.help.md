# Equipment Maintenance Request Form - Help Guide
## Purpose
The Equipment Maintenance Request Form is used to report requests for equipment maintenance. This form is designed to guide users through the necessary information required for efficient maintenance request processing.

## How To Complete This Form

To complete this form, follow these steps:

1. Select the Equipment Type from the list provided.
2. Provide a brief description of the equipment that requires maintenance.
3. Set the priority of the maintenance request (High, Medium, or Low).
4. Choose the current Status of the equipment (New, In Progress, Completed).
5. If the equipment is not available, select its current status.
6. If applicable, enter the Maintenance Due Date.
7. If applicable, enter the Maintenance Cost.
8. Add any additional Notes if necessary.
9. Choose who submitted the request (Staff, Contractor, or External).
10. Enter the date the request was submitted.
11. If applicable, select Yes if the equipment is assigned to a user.
12. Enter the Due Date for the maintenance.

## Field-by-Field Explanation
* **Equipment Type**: Select the type of equipment that requires maintenance. This will help the maintenance team identify the correct equipment and prioritize the request accordingly.
* **Description**: Provide a brief description of the equipment that requires maintenance.
* **Priority**: Set the priority of the maintenance request. High, Medium, or Low indicate the urgency and importance of the maintenance.
* **Status**: Choose the current status of the equipment that requires maintenance.
* **Equipment Status**: If the equipment is not available, choose its current status (Available, Under Maintenance, Offline).
* **Maintenance Due Date**: Enter the date the maintenance is due, if applicable.
* **Maintenance Cost**: Enter the cost of the maintenance, if applicable.
* **Notes**: Add any additional notes about the maintenance request.
* **Submitted By**: Choose who submitted the request (Staff, Contractor, or External).
* **Submitted Date**: Enter the date the request was submitted.
* **Assigned User**: Select Yes if the equipment is assigned to a user for maintenance.
* **Assigned User Name**: Enter the name of the user who is assigned for maintenance, if applicable.
* **Due Date**: Enter the date the maintenance is due, if applicable.
