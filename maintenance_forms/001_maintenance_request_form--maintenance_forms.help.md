# Maintenance Request Form - Help Guide
## Purpose
The Maintenance Request Form is used to submit maintenance requests for any issues that need to be fixed or improved at your location, building, or equipment.

## How To Complete This Form
To complete this form, follow these steps:

1. Select a category for your maintenance request (e.g., "Maintenance Forms" or "Other").
2. Briefly describe the issue that requires maintenance.
3. Add any additional comments or details about the problem.
4. Indicate if the maintenance task is easy to understand (yes/no).
5. Check if coding knowledge is required to complete the task (yes/no).

## Field-by-Field Explanation

* **Category** (`category`, select_one, required/optional): Choose a category that best describes the maintenance request you're submitting. This will help us understand the scope of the issue.
* **Description** (`description`, text, required/optional): Briefly describe the problem you're experiencing. Be as specific as possible, so we can understand the issue better.
* **Additional Comments** (`maintenance_request_form_description`, text, required/optional): If you have any additional comments or information about the problem, please add it here.
* **Easy To Use?** (`easy_to_use`, select_one, required/optional): Indicate if the maintenance task is easy to understand or if you need guidance.
* **No Coding Required?** (`no_coding`, select_one, required/optional): Check if the maintenance task requires any coding knowledge or not.

## Tips

* Be as concise as possible when describing the issue.
* Try to provide as much detail as you can about the problem.
* If you're unsure about a field, just ask, and we'll be happy to help!
