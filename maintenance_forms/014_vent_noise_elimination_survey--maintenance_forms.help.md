# Vent Noise Elimination Survey - Help Guide

## Purpose
This form is used to report and track vent noise issues in ventilation systems. Please fill out the form to help identify and resolve these problems.

## How To Complete This Form

1. **Vent Noise Report**: This field is required and should be a brief description of the reported issue.
2. **Has Fix Attempted**: Select 'True' if any attempts have been made to fix the issue, otherwise select 'False'.
3. **Fix Status**: Select one or more of the following:
	* In Progress: The fix is currently in progress.
	* Complete: The fix is completed.
	* Incomplete: The fix is incomplete or not fully addressed.
4. **Date Reported**: Enter the date the issue was reported in the format MM/DD/YYYY.
5. **Reported By**: This field is optional and can be filled out if desired.
6. **Reported To**: This field is optional and can be filled out if desired.
7. **Description**: This field is for a more detailed description of the issue. Please provide as much detail as possible.
8. **Vent Type**: Select the type of vent that is experiencing the issue:
	* Squeaking
	* Hissing
	* Rattling
9. **Location**: This field is optional and can be filled out if desired.
10. **Comments**: This field is optional and can be used to provide any additional information about the issue.
11. **Follow-up Status**: Select 'True' if further follow-up is required, otherwise select 'False'.
12. **Next Follow-up**: This field is optional and can be used to schedule a follow-up.
13. **Follow-up Date**: If the follow-up date is scheduled, enter it in the format MM/DD/YYYY.
14. **Follow-up By**: This field is optional and can be used to specify who will be following up on the issue.

## Field-by-Field Explanation

* **Vent Noise Report** (required): Enter a brief description of the reported issue, including the vent type, location, and any other relevant details.
* **Has Fix Attempted** (required): Select 'True' if any attempts have been made to fix the issue, otherwise select 'False'.
* **Fix Status** (required): Select one or more of the following:
	+ In Progress: The fix is currently in progress.
	+ Complete: The fix is completed.
	+ Incomplete: The fix is incomplete or not fully addressed.
* **Date Reported** (required): Enter the date the issue was reported in the format MM/DD/YYYY.
* **Reported By** (optional): Enter the name or ID of the person who reported the issue.
* **Reported To** (optional): Enter the name or ID of the person or team that received the report.
* **Description** (required): Enter a more detailed description of the issue, including any relevant details or context.
* **Vent Type** (required): Select the type of vent that is experiencing the issue:
	+ Squeaking
	+ Hissing
	+ Rattling
* **Location** (optional): Enter the location of the vent, if relevant.
* **Comments** (optional): Enter any additional information or comments about the issue.
* **Follow-up Status** (required): Select 'True' if further follow-up is required, otherwise select 'False'.
* **Next Follow-up** (optional): Enter the date and time of the next follow-up.
* **Follow-up Date** (optional): Enter the date of the next follow-up in the format MM/DD/YYYY.
* **Follow-up By** (optional): Enter the name or ID of the person or team that will follow up on the issue.
