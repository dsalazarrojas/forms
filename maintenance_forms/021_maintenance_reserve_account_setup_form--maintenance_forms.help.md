# Maintenance Reserve Account Setup Form - Help Guide
## Purpose
This form is used to set up a maintenance reserve account for a property.

## How To Complete This Form
To complete this form, please follow these steps:

1.  **Maintenance**: Select 'Yes' or 'No' to indicate if maintenance is required.
2.  **Properties**: Select 'Yes' or 'No' to indicate if the property is being maintained.
3.  **Organizations**: Select 'Yes' or 'No' to indicate if the organizations that will be impacted by the maintenance are being listed.
4.  **Request Date**: Enter the date you would like the maintenance to take place on a specific date.
5.  **Request Time**: Enter the time you would like the maintenance to take place.
6.  **Requester Type**: Select 'Yes' or 'No' to indicate if a specific type of requester is being used.
7.  **Requester Contact**: Enter the email address of the person or organization making the maintenance request.
8.  **Property Name**: Enter the name of the property being maintained.
9.  **Property Address**: Enter the address of the property being maintained.
10. **Property Phone**: Enter the phone number of the property or organization being maintained.
11.  **Request Details**: Enter a brief description of the maintenance request.
12.  **Request Approvals**: Select 'Yes' or 'No' to indicate if the request requires approvals.

## Field-by-Field Explanation
* **Maintenance**: 
  * Select 'Yes' if maintenance is required for the property.
  * Select 'No' if no maintenance is required.
*  **Properties**: 
  * Select 'Yes' if the property being maintained is being listed.
  * Select 'No' if no specific property is being listed.
*  **Organizations**: 
  * Select 'Yes' if the organizations that will be impacted by the maintenance are listed.
  * Select 'No' if no organizations are being listed.
*  **Request Date**:
  * Enter the date you would like the maintenance to take place on.
*  **Request Time**:
  * Enter the time you would like the maintenance to take place.
*  **Requester Type**:
  * Select 'Yes' if a specific type of requester is being used.
  * Select 'No' if no specific type of requester is used.
*  **Requester Contact**:
  * Enter the email address of the person or organization making the maintenance request.
*  **Property Name**:
  * Enter the name of the property being maintained.
*  **Property Address**:
  * Enter the address of the property being maintained.
*  **Property Phone**:
  * Enter the phone number of the property or organization being maintained.
*  **Request Details**:
  * Enter a brief description of the maintenance request.
*  **Request Approvals**:
  * Select 'Yes' if the request requires approvals.
  * Select 'No' if no approvals are required.

## Tips
* Ensure that the information provided is accurate and complete to ensure proper processing.
* This form should only be filled out once for each maintenance request.
* If unsure about any field, please ask for clarification before submitting the form.
