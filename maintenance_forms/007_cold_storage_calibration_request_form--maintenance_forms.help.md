# Cold Storage Calibration Request Form - Help Guide
## Purpose
This form is for requesting calibration services for cold storage equipment, such as refrigerators, freezers, and other temperature-controlled units.

## How To Complete This Form
1. Fill in your name, email, phone number, and department.
2. Select the type of cold storage unit and its manufacturer.
3. Enter the equipment's model number and serial number (if available).
4. Provide the current temperature range of the equipment.
5. Select the type of calibration requested (e.g., routine, preventive, corrective, etc.).
6. Enter the last calibration date (if applicable).
7. Select a preferred service date and time.
8. Choose the urgency level of the request.
9. Select the reason for the calibration request.
10. Provide additional notes or comments if necessary.

## Field-by-Field Explanation

* **Requester Full Name** (`requester_name`): Enter your full name, first and last name.
* **Email Address** (`requester_email`): Enter your work email address.
* **Phone Number** (`requester_phone`): Enter your direct contact number.
* **Department** (`department`): Enter your department or division.
* **Organization** (`organization`): Enter the name of your company or institution.
* **Facility Location** (`facility_location`): Enter the building and room number where the equipment is located.
* **Type of Cold Storage Unit** (`cold_storage_type`): Select the type of cold storage unit you are requesting calibration for (e.g., walk-in refrigerator, walk-in freezer, etc.).
* **Equipment Manufacturer** (`equipment_manufacturer`): Enter the brand name of the equipment.
* **Equipment Model Number** (`equipment_model`): Enter the model number of the equipment.
* **Equipment Serial Number** (`equipment_serial`): Enter the serial number of the equipment, if available.
* **Current Temperature Range** (`current_temperature_range`): Enter the current operating temperature range of the equipment.
* **Type of Calibration Requested** (`calibration_type`): Select the type of calibration requested (e.g., routine, preventive, corrective, etc.).
* **Last Calibration Date** (`last_calibration_date`): Enter the date of the last calibration, if applicable.
* **Calibration Due Date** (`calibration_due_date`): Select the date when the calibration is due.
* **Preferred Service Date** (`preferred_service_date`): Select the preferred date for service.
* **Preferred Time of Day** (`preferred_time`): Select the best time for service (e.g., morning, afternoon, evening, etc.).
* **Urgency Level** (`urgency_level`): Select the urgency level of the request (e.g., routine, standard, priority, etc.).
* **Reason for Calibration Request** (`reason_for_calibration`): Select the reason why the calibration is needed (e.g., scheduled maintenance, temperature drift detected, etc.).
* **Additional Notes or Comments** (`reason_details`): Provide any additional information or comments about the request.
* **Special Access Instructions** (`access_instructions`): Enter any special instructions for accessing the equipment, such as keys or entry procedures.
* **Safety Requirements** (`safety_requirements`): Enter any safety protocols or PPE required for the service.
* **Will Contents Be Removed** (`contents_status`): Select whether the contents will be removed from the unit for service.
* **Is Downtime Acceptable** (`downtime_acceptable`): Select whether downtime is acceptable for the unit.
* **Backup Storage Available** (`backup_storage_available`): Select whether backup storage is available.
* **Certification Documentation Required** (`certification_required`): Select the type of certification documentation required.
* **Purchase Order Number** (`purchase_order_number`): Enter the purchase order number, if applicable.
* **Budget or Cost Center Code** (`budget_code`): Enter the budget or cost center code, for billing purposes.
* **Additional Notes or Comments** (`additional_notes`): Enter any additional information or comments.
