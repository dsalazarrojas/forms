# Common Area Lighting Repair Request - Help Guide
## Purpose
The Common Area Lighting Repair Request form is used to submit a report of a lighting issue in a common area of a property.

## How To Complete This Form
To complete this form, follow these steps:

1. Provide your name and contact information (Requester Name, Requester Email, Requester Phone)
2. Choose your relationship to the property (Requester Type)
3. Enter the property details (Property Name, Property Address)
4. Describe the issue (Location Details, Specific Location)
5. Select the common area affected (Common Area Type)
6. Specify the issue type (Issue Type)
7. Enter the number of light fixtures affected (Number of Fixtures)
8. Provide the duration of the issue (Issue Duration)
9. Indicate if the issue creates a safety concern (Safety Concern)
10. Choose the priority level of the request (Priority Level)
11. Provide any additional comments or details (Additional Description)
12. If desired, include photos of the issue (Photos Available)

## Field-by-Field Explanation

* **Requester Name** (Required): The full name of the requester.
* **Requester Email** (Required): The email address of the requester.
* **Requester Phone** (Optional): The phone number of the requester.
* **Requester Type** (Required): The type of person submitting the request (Resident, Employee, Visitor, etc.)
* **Property Name** (Required): The name of the property or building.
* **Property Address** (Required): The full address of the property.
* **Location Details** (Optional): Any additional details about the location of the issue.
* **Specific Location** (Required): A more specific location within the property (e.g., room number).
* **Common Area Type** (Required): The type of common area affected (Lobby, Hallway, etc.).
* **Issue Type** (Required): The type of lighting issue (Light Completely Out, Flickering, etc.).
* **Number of Fixtures** (Required): The number of light fixtures affected.
* **Issue Duration** (Required): The duration of the issue (Less than 1 day, 1-3 days, etc.).
* **Safety Concern** (Required): Indicate if the issue creates a safety concern.
* **Priority Level** (Required): The level of priority requested for the issue (Low, Medium, High, etc.).
* **Additional Description** (Optional): Any additional details about the issue.
* **Photos Available** (Optional): Indicate if photos are available to support the request.
* **Preferred Repair Time** (Optional): The preferred time for the repair.
* **Access Instructions** (Optional): Any special access instructions for the repair crew.
