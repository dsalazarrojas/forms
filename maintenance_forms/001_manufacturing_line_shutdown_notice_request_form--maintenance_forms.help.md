# Manufacturing Line Shutdown Notice Request Form - Help Guide
## Purpose
This form is used to request a manufacturing line shutdown notice, which is required for various purposes such as planned maintenance, repairs, or other critical events that affect production.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the production line that will be shut down.
2. Choose the timing of the shutdown (date).
3. Provide a reason for the shutdown.
4. Confirm if the production manager has approved the shutdown.
5. Enter the production manager's name and ID.
6. Add any comments if necessary.
7. Get the production manager's notes and approval.
