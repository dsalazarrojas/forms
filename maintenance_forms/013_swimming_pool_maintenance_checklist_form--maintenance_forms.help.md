# swimming_pool_maintenance_checklist_form - Help Guide
## Purpose
The purpose of this form is to collect and document the status of various swimming pool maintenance tasks.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the maintenance tasks that need to be completed.
2. Enter the results of water testing, if applicable.
3. Report on skimmer cleaning status.
4. Check and report on pool pump maintenance.
5. Report on tile cleaning status.
6. Record chemical levels.
7. Check and report on pool water temperature.
8. Record pool depth.
9. Report on pool surface area.
10. Record the pool's location.
11. Select the user assigned to the pool maintenance task.
12. Enter the date of the maintenance activity.

## Field-by-Field Explanation
- **Maintenance Tasks** (`maintenance_tasks`, select_multiple, required): This field allows you to select the maintenance tasks that need to be completed for the pool. Select each task that applies from the list provided.
- **Water Testing** (`water_testing`, text, required): Enter the results of any water testing that was conducted.
- **Skimmer Cleaning** (`skimmer_cleaning`, text, required): Report on the status of skimmer cleaning, including any debris found.
- **Pump Maintenance** (`pump_maintenance`, text, required): Check and report on pump maintenance, including any issues found.
- **Tile Cleaning** (`tile_cleaning`, text, required): Report on tile cleaning status, including any staining or issues found.
- **Chemical Levels** (`chemical_levels`, select_one, required): Select the current chemical level in the pool, from Low, Medium, or High.
- **Pool Water Temp** (`pool_water_temp`, number, required): Check and record the current pool water temperature.
- **Pool Depth** (`pool_depth`, text, required): Record the current pool depth.
- **Pool Surface Area** (`pool_surface_area`, text, required): Report on the pool's surface area, including any changes or issues.
- **Pool Location** (`pool_location`, text, required): Record the location of the pool.
- **Assigned User** (`assigned_user`, select_one, required): Select the user assigned to perform the maintenance task.
- **Maintenance Date** (`maintenance_date`, date, required): Enter the date of the maintenance activity.
