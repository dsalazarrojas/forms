This form is designed to collect data for the maintenance of roofs in a property. It is used to assess the condition, type, and other relevant details of a roof, and to plan and record maintenance activities.

The form is intended for use by property managers and inspectors to collect data that will help them make informed decisions about roof maintenance. It is not intended for use by the general public.

The form has the following sections:

- Roof Condition: This section collects information about the overall condition of the roof.
- Type: This section asks for the type of roof, for example, tile, metal, or shingle.
- Age: This section asks for the age of the roof.
- Damage: This section allows the inspector to report any damage they observe on the roof.
- Leaks: This section asks if there are any leaks on the roof, with options to select multiple types of leaks.
- Repair History: This section allows the inspector to report on any repairs done on the roof.
- Maintenance Frequency: This section asks how often the roof should be inspected.
- Last Inspection Date: This section asks for the date of the last inspection.
- Next Inspection Date: This section asks for the date of the next scheduled inspection.
- Materials: This section asks if the roof uses materials that are prone to damage.
- Inspection Result: This section allows the inspector to report the result of the inspection.
- Action Plan: This section allows the inspector to suggest any action to be taken.
- Comments: This section allows the inspector to add any additional comments.
- Assigned Inspector: This section asks if an inspector was assigned to the property.
- Assigned Inspector Notes: This section allows the assigned inspector to add any notes.
- Property Manager Notes: This section allows property managers to add any notes.
- Inspection Status: This section asks for the status of the inspection, active or inactive.
