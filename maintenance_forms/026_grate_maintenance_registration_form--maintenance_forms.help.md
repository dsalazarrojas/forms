# Grate Maintenance Registration Form - Help Guide
## Purpose
The Grate Maintenance Registration Form is used to document and register maintenance requests for the Grate system. This form collects essential information about the maintenance work, including date, time, description, and priority level.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the date and time for the maintenance task in the "Date" and "Time" fields, respectively.
2. Provide a brief description of the maintenance work in the "Description" field.
3. If necessary, enter your contact details (phone number and email) in the "Contact Number" and "Email" fields.
4. Indicate the priority level of the maintenance task in the "Priority" field.
5. If desired, specify who the task should be assigned to in the "Assign To" field.

## Field-by-Field Explanation
* **Grate Maintenance Form**: 
    * Type: Text
    * Required: No
    * Description: Enter a brief description of the maintenance work to be performed.
* **Date**: 
    * Type: Date
    * Required: No
    * Description: Enter the date for the maintenance task.
* **Time**: 
    * Type: Time
    * Required: No
    * Description: Enter the time for the maintenance task.
* **Description**: 
    * Type: Text
    * Required: No
    * Description: Provide a brief description of the maintenance work.
* **Requester**: 
    * Type: Text
    * Required: No
    * Description: Enter your name or title for reference.
* **Contact Number**: 
    * Type: Text
    * Required: No
    * Description: Enter your phone number for contact purposes.
* **Email**: 
    * Type: Email
    * Required: No
    * Description: Enter your email address for contact purposes.
* **Comments**: 
    * Type: Text
    * Required: No
    * Description: Provide any additional comments or information about the maintenance task.
* **Priority**: 
    * Type: Select One
    * Required: No
    * Description: Indicate the priority level of the maintenance task, with options for Low, Medium, and High.
* **Assign To**: 
    * Type: Select Multiple
    * Required: No
    * Description: Specify who the maintenance task should be assigned to, with options for chatjimmy and Other.
