# Residential Grounds Maintenance Checklist - Help Guide
## Purpose
This form is used to record and track the status of residential grounds maintenance tasks, property manager information, and other essential details for property management.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the relevant options for Property Photos from the list of available choices.
2. Choose one of the options for Exterior Components to indicate the state of the property's exterior components.
3. Select the Grounds Maintenance option to indicate if this maintenance is required.
4. Add any Additional Notes if needed.
5. Select one of the options for Follow-Ups to indicate if follow-up actions are necessary.
6. Indicate if the Property Manager Info is available or not.
7. Select the Maintenance Schedule option to indicate if a scheduled maintenance is planned.
8. Indicate if Completed Maintenance tasks are finished.
9. Choose one of the options for Property Inspections to indicate if an inspection is needed.
10. Select the Maintenance Plan option to indicate if a maintenance plan is in place.
11. Select one of the options for Maintenance Budget to indicate the maintenance status.
12. Choose one of the options for Property Owners to indicate if the property owners are aware of the maintenance.
13. Select one of the options for Property Management to indicate if property management activities are performed.
14. Indicate if Maintenance Schedule Follow-Ups are needed.
15. Select one of the options for Maintenance Plan Follow-Ups to indicate if follow-up actions are necessary.
16. Choose one of the options for Property Maintenance to indicate if the property maintenance is completed.
17. Select one of the options for Property Management Follow-Ups to indicate if property management follow-ups are necessary.
18. Indicate if Property Owner Follow-Ups are needed.
19. Add any Property Owner Notes if required.
20. Add any Maintenance Plan Notes if required.
21. Add any Property Management Notes if required.
22. Add any Maintenance Follow-Ups notes if required.
23. Add any Property Follow-Ups notes if required.
24. Set a time for the Follow-Up Schedule if necessary.

## Field-by-Field Explanation
* **Property Photos** (Property Photos, select_multiple, required): Choose the relevant photos from the list to provide a visual representation of the property.
* **Exterior Components** (Exterior Components, select_one, required): Select the state of the exterior components of the property (e.g., doors, windows, roof, etc.).
* **Grounds Maintenance** (Grounds Maintenance, select_one, required): Indicate if the grounds maintenance is required or not.
* **Additional Notes** (Additional Notes, text, optional): Add any additional comments or notes about the property or maintenance activities.
* **Follow-Ups** (Follow-Ups, select_multiple, optional): Indicate if follow-up actions are necessary for any of the selected maintenance activities.
* **Property Manager Info** (Property Manager Info, select_multiple, required): Indicate if property manager information is available or not.
* **Maintenance Schedule** (Maintenance Schedule, select_one, optional): Indicate if a scheduled maintenance plan is in place.
* **Completed Maintenance** (Completed Maintenance, select_multiple, optional): Indicate if maintenance tasks are completed.
* **Property Inspections** (Property Inspections, select_multiple, required): Select the options to indicate if property inspections are required.
* **Maintenance Plan** (Maintenance Plan, select_multiple, optional): Indicate if a maintenance plan is in place.
* **Maintenance Budget** (Maintenance Budget, select_multiple, optional): Indicate if a maintenance budget is in place.
* **Property Owners** (Property Owners, select_multiple, optional): Indicate if the property owners are aware of maintenance activities.
* **Property Management** (Property Management, select_multiple, optional): Indicate if property management activities are performed.
* **Maintenance Schedule Follow-Ups** (Maintenance Schedule Follow-Ups, select_multiple, optional): Indicate if follow-up actions are necessary for maintenance schedule activities.
* **Maintenance Plan Follow-Ups** (Maintenance Plan Follow-Ups, select_multiple, optional): Indicate if follow-up actions are necessary for maintenance plan activities.
* **Property Maintenance** (Property Maintenance, select_multiple, optional): Indicate if property maintenance activities are completed.
* **Property Management Follow-Ups** (Property Management Follow-Ups, select_multiple, optional): Indicate if property management follow-ups are necessary.
* **Property Owner Follow-Ups** (Property Owner Follow-Ups, select_multiple, optional): Indicate if follow-ups with property owners are necessary.
* **Property Owner Notes** (Property Owner Notes, text, optional): Add any notes regarding the property owners.
* **Maintenance Plan Notes** (Maintenance Plan Notes, text, optional): Add any notes regarding the maintenance plan.
* **Property Management Notes** (Property Management Notes, text, optional): Add any notes regarding property management activities.
* **Maintenance Follow-Ups** (Maintenance Follow-Ups, text, optional): Add any notes regarding maintenance follow-ups.
* **Property Follow-Ups** (Property Follow-Ups, text, optional): Add any notes regarding property follow-ups.
* **Follow-Up Schedule** (Follow-Up Schedule, time, optional): Set a specific time for the follow-up schedule if necessary.

## Tips
- Make sure to select all relevant options that apply to the property's maintenance status.
- Double-check the property manager information and property owner details.
- Add notes for any necessary follow-ups or maintenance activities.
- Be thorough in maintaining the property's records.
- Update the form regularly to reflect changes in the property's maintenance status.
