# School Virtual Learning Parent Survey - Help Guide

## Purpose
This form is designed to gather feedback from parents on their experience with the school's virtual learning program.

## How To Complete This Form
To complete this form, please follow these steps:

1. Please provide a title for your feedback, if desired.
2. Select what you dislike about the program by choosing one or more options from the list.
3. Select what you like about the program by choosing one or more options from the list.
4. Select what the school does right or wrong by choosing one or more options from the list.
5. If you would like to request a change, please provide a brief description.
6. Select your preferred method of communication for parent support.
7. Select if you would like to request help.
8. If you have any suggestions for improvement, provide them in the text field.
9. If you would like to provide additional comments, please do so in the text field.

## Field-by-Field Explanation

* **Parent Survey Title** (`parent_survey_title`, text, optional): This is where you can provide a title for your feedback, if desired.
* **What don't you like** (`parent_say_what_you_dont_like`, select_multiple, required): Choose one or more options from the list to indicate what you don't like about the program.
* **What do you like** (`parent_say_what_you_do_like`, select_multiple, optional): Choose one or more options from the list to indicate what you like about the program.
* **What do we do right** (`parent_say_what_we_do_right`, select_multiple, optional): Choose one or more options from the list to indicate what the school does well.
* **What do we do wrong** (`parent_say_what_we_do_wrong`, select_multiple, optional): Choose one or more options from the list to indicate what the school does poorly.
* **Request a change** (`parent_request_change`, text, optional): If you have a suggestion for improvement, please provide a brief description.
* **Parent Support** (`parent_survey_title_2`, select_one, required): Choose your preferred method of communication for parent support.
* **How can we help you** (`parent_request_help`, select_multiple, optional): Choose one or more options to indicate how you would like to be helped.
* **Suggest an improvement** (`parent_suggest_improve`, text, optional): If you have any suggestions for improvement, please provide them in the text field.
* **Why** (`parent_say_why`, text, optional): This is a text field where you can provide additional comments or explanation.
* **Comments** (`parent_comments`, text, optional): This is a text field where you can provide additional comments or feedback.
