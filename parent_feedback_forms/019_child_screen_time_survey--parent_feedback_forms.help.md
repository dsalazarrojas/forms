# Child Screen Time Survey - Help Guide

## Purpose

The Child Screen Time Survey is designed to collect data on a child's screen time habits and behaviors, helping parents and caregivers understand the impact of screen time on their child's life. This information will be used to develop resources and strategies for effective screen time management.

## How To Complete This Form

1. Select the survey date from the date input field.
2. Fill out the required personal details:
   * First name and last name of the parent or guardian.
   * Email address of the parent or guardian.
   * First name and last name of the child.
   * Age of the child.
3. Provide details on the devices the child regularly uses.
4. Report the average screen time on weekdays and weekends.
5. Choose the primary screen activities the child engages in.
6. Indicate the presence and strictness of screen time rules in the home.
7. Identify areas where screens are not allowed.
8. Answer questions on screen time before bed.
9. Select the observed behavioral changes related to screen time.
10. Rate the child's sleep quality.
11. Indicate the child's physical activity level.
12. Choose the impact of screen time on social interactions.
13. Report the impact of screen time on academic performance.
14. Indicate the use of parental controls or monitoring software.
15. Describe how you monitor content viewed by your child.
16. List any main concerns about the child's screen time.
17. If needed, specify the support or resources required to manage screen time effectively.

## Field-by-Field Explanation

* **Survey Date (1)** (`survey_date`, date, required): The date on which the survey was completed.
* **Parent or Guardian First Name (2)** (`parent_guardian_first_name`, text, required): The first name of the parent or guardian.
* **Parent or Guardian Last Name (3)** (`parent_guardian_last_name`, text, required): The last name of the parent or guardian.
* **Parent or Guardian Email (4)** (`parent_guardian_email`, email, required): The primary email address for contact.
* **Child First Name (5)** (`child_first_name`, text, required): The first name of the child.
* **Child Last Name (6)** (`child_last_name`, text, required): The last name of the child.
* **Child Age (7)** (`child_age`, number, required): The current age of the child in years.
* **Child Grade Level (8)** (`child_grade_level`, select_one, required): The current grade level of the child.
* **Devices Child Uses (9)** (`devices_owned`, select_multiple, required): Select the devices the child regularly uses.
* **Average Weekday Screen Time (10)** (`weekday_screen_time`, select_one, required): The average amount of screen time on weekdays.
* **Average Weekend Screen Time (11)** (`weekend_screen_time`, select_one, required): The average amount of screen time on weekends.
* **Primary Screen Activities (12)** (`primary_screen_activities`, select_multiple, required): Choose the primary screen activities the child engages in.
* **Screen Time Rules (13)** (`screen_time_rules`, select_one, required): Indicate the presence and strictness of screen time rules in the home.
* **Screen-Free Zones (14)** (`screen_free_zones`, select_multiple, required): Identify areas where screens are not allowed.
* **Screen Time Before Bed (15)** (`screen_time_before_bed`, select_one, required): Answer questions on screen time before bed.
* **Behavioral Changes Observed (16)** (`behavioral_changes_observed`, select_multiple, required): Select observed behavioral changes related to screen time.
* **Child Sleep Quality (17)** (`sleep_quality`, select_one, required): Rate the child's sleep quality.
* **Physical Activity Level (18)** (`physical_activity_level`, select_one, required): Indicate the child's physical activity level.
* **Impact on Social Interactions (19)** (`social_interaction_impact`, select_one, required): Choose the impact of screen time on social interactions.
* **Impact on Academic Performance (20)** (`academic_performance_impact`, select_one, required): Report the impact of screen time on academic performance.
* **Parental Controls Used (21)** (`parental_controls_used`, select_one, required): Indicate the use of parental controls or monitoring software.
* **Content Monitoring (22)** (`content_monitoring`, select_one, required): Describe how you monitor content viewed by your child.
* **Screen Time Concerns (23)** (`screen_time_concerns`, text, optional): List any main concerns about the child's screen time.
* **Support Needed (24)** (`support_needed`, text, optional): Specify the support or resources required to manage screen time effectively.

## Tips

* Be accurate and honest when filling out the form.
* Select only the options that accurately reflect your child's screen time habits.
* If unsure, refer to the provided options for guidance.
* Take your time, and do not hesitate to ask if you need help.
