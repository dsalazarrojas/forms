# Non Commercial Use Agreement - Help Guide
## Purpose
The Non Commercial Use Agreement form is used to collect information about non-commercial use agreements, which are contracts that outline the terms and conditions under which a user or group of users will use certain resources, tools, or services without expecting to sell or trade them for profit.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the correct category for the non-commercial use agreement.
2. Write a clear and concise description of the agreement.
3. Select the tool or service related to the agreement, if applicable.
4. Fill in the rest of the form as needed.

## Field-by-Field Explanation
### non_commercial_use_agreement (Page 1)
* **non_commercial_use_agreement**: This is a title field where you can enter a name for the non-commercial use agreement.

### category (Page 2)
* **category**: This field is used to select the category for the non-commercial use agreement. Please select "Consent Forms" to ensure that the agreement is properly classified.

### description (Page 3)
* **description**: This is a field where you can enter a clear and concise description of the non-commercial use agreement.

### output (Page 4)
* **output**: This is a field where you can enter the output or the result of the non-commercial use agreement.

### assigned_tool (Page 5)
* **assigned_tool**: If the non-commercial use agreement is related to a specific tool or service, select the corresponding tool from the dropdown menu. If not, select "Other" to indicate that this field is not applicable.

### output_file (Page 6)
* **output_file**: This is a field where you can enter the output or the result of the non-commercial use agreement.

### form_ids (Page 7)
* **form_ids**: This is a field where you can enter any additional information or IDs related to the non-commercial use agreement.

## Tips
* Make sure to fill out all required fields to ensure that the non-commercial use agreement is properly generated.
* Review the form carefully before submitting to ensure that all information is accurate and complete.
* If you need help or have questions, please contact your supervisor or the form administrator.
