# Intellectual Property Use Authorization Form - Help Guide
## Purpose
This form is used to capture user authorization for the use of intellectual property (IP) owned by our company. The purpose of this form is to obtain user consent for the specified usage of IP and to ensure that users understand how their IP will be used.

## How To Complete This Form
To complete this form, please follow these steps:

1. Provide your user information, including your name and contact details.
2. Select the permission level you wish to have access to the IP, such as Full Access, Read-Only, or Restricted Access.
3. Choose the usage terms under which you agree to use the IP.
4. Specify the duration of the authorization, including the start and end dates.
5. Provide any relevant IP information that may be required.
6. Finally, agree to the usage terms you selected by selecting the corresponding option in the "I agree to use IP as described above" field.

## Field-by-Field Explanation
* **User Information** (`user_info`, text, optional): This field is used to collect user information, including name and contact details. Please provide your name and any other relevant contact information.
* **Permission Level** (`permission_level`, select_one, required): Choose the access level you wish to have to the IP. Please select from the options: Full Access, Read-Only, or Restricted Access.
* **Usage Terms** (`usage_terms`, select_multiple, optional): Select the usage terms under which you agree to use the IP. Please choose from the options: Usage by our company, Usage by third-party service providers, or Usage by partners.
* **Duration of Authorization** (`duration`, date, optional): Specify the duration of the authorization, including the start and end dates. This field is optional but recommended for clarity.
* **IP Information** (`ip_info`, note, optional): This field is used to provide any relevant IP information that may be required. Please provide any relevant details.
* **I agree to use IP as described above** (`ip_agreed`, select_multiple, required): Agree to the usage terms you selected by selecting the corresponding option. Please select either "Yes" or "No".
