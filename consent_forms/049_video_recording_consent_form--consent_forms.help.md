# video_recording_consent_form - Help Guide
## Purpose
This form is used to collect consent for video recordings from users. It is essential to complete this form before any video recording can take place.

## How To Complete This Form
1. Click on "Submit" to start filling out the form.
2. Answer each question carefully and accurately.
3. Make sure to read and agree to the terms and conditions at the end of the form.

## Field-by-Field Explanation

* **Video Recording Consent** (`1`, `text`, required):
	+ This is the primary section where you can enter your consent to be recorded.
	+ Please type "Yes" if you agree to be recorded.
* **Purpose of Recording** (`2`, `text`, required):
	+ This field is used to describe the purpose of the recording.
	+ Please enter the reason for the recording in this field.
* **Recorded By** (`3`, `text`, required):
	+ This field is used to identify who is recording you.
	+ Please enter the name or initials of the person recording.
* **Location of Recording** (`4`, `text`, required):
	+ This field is used to identify the location where the recording will take place.
	+ Please enter the address or location name.
* **Release of Recordings** (`5`, `text`, required):
	+ This field is used to describe how the recordings will be released.
	+ Please select one of the options or describe your preference.
* **Consent to Record** (`6`, `select_multiple`, required):
	+ Select all the options that apply to you:
		- Yes
		- No
* **Consent to Reuse** (`7`, `select_multiple`, required):
	+ Select all the options that apply to you:
		- Yes
		- No
* **Consent to Share** (`8`, `select_multiple`, required):
	+ Select all the options that apply to you:
		- Yes
		- No
* **Consent to Upload** (`9`, `select_multiple`, required):
	+ Select all the options that apply to you:
		- Yes
		- No
* **Contact Preferences** (`10`, `select_multiple`, required):
	+ Select how you would like to be contacted:
		- Email
		- Phone
		- Text
		- None
* **Email** (`11`, `email`, optional):
	+ If you want to be contacted via email, enter your email address here.
* **Phone** (`12`, `text`, optional):
	+ If you want to be contacted via phone, enter your phone number here.
* **Date** (`13`, `date`, required):
	+ Enter the date of the recording.
* **Time** (`14`, `time`, required):
	+ Enter the time of the recording.
* **Duration** (`15`, `number`, optional):
	+ If you know the duration of the recording, enter it here.
* **Timezone** (`16`, `select_one`, required):
	+ Select your time zone:
		- PST
		- EDT
		- CST
		- CDT
		- UTC
* **Timezone Offset** (`17`, `text`, required):
	+ If your time zone is not listed, enter your timezone offset here.
* **Video File Format** (`18`, `select_one`, required):
	+ Select the format of the video file:
		- mp4
		- avi
		- mpg
* **Video Quality** (`19`, `select_one`, required):
	+ Select the video quality:
		- High
		- Low
		- Medium
* **Recording Location** (`20`, `select_one`, required):
	+ Select where the recording will take place:
		- On-site
		- Remote
		- Hybrid
* **Recording Equipment** (`21`, `select_one`, required):
	+ Select the equipment used for recording:
		- Camera
		- Phone
		- Other
* **Backup Method** (`22`, `select_one`, required):
	+ Select the backup method:
		- Cloud
		- On-site
		- Other
* **Video Password** (`23`, `text`, required):
	+ Enter a password for the video.
* **Video Password Hint** (`24`, `text`, optional):
	+ Enter a hint for the password.
* **Terms and Conditions** (`25`, `note`, required):
	+ Please read and agree to the terms and conditions before submitting the form.
