# hoa_proxy_form - Help Guide

## Purpose
The hoa_proxy_form is a form designed for users to input information for generating a proxy form for a specific purpose. 

## How To Complete This Form
To complete this form, please fill in the following information and submit.

## Field-by-Field Explanation
- **Hoa Proxy Form** (`title`, text, required/optional: false): Enter the title of the form you want to create.
  - This field should be filled with a brief and descriptive title for the form.
- **Category** (`category`, text, required/optional: false): Select a category for the form.
  - Choose a category that best fits the form's purpose.
- **Description** (`description`, text, required/optional: false): Enter a description of the form.
  - Write a short description of the form's purpose and intended use.
- **Assigned Tool** (`assigned_tool`, text, required/optional: false): Indicate which tool is associated with the form.
  - If applicable, select the tool this form will be used with.

## Tips
When filling out the form, be as accurate and concise as possible to ensure the generated proxy form meets your needs.
