# Smart Plug Monitoring Consent Form - Help Guide
## Purpose
The Smart Plug Monitoring Consent Form is used to collect consent from end-users to monitor their smart plugs. It's a necessary step to ensure that users are aware of what data will be collected and how it will be used.

## How To Complete This Form
1. Select the option that best describes your preference for monitoring.
2. Provide your contact details, including your name, email, and phone number.
3. If desired, leave a note with any additional information.
4. If you're confirming a signature, select the option that best describes the situation.
5. If you're leaving a note for the confirmed signature, provide a brief explanation.

## Field-by-Field Explanation
### Smart Plug Monitoring
* **Smart Plug Monitoring** (`Smart Plug Monitoring`, `text`, required/optional): This field is where you'll select your preference for monitoring. Please choose one of the options provided.

### Consent and Signature
* **Consent and Signature** (`select_one`, required): Please select the option that best describes your consent and signature. You can choose between `Option 1`, `Option 2`, or `Option 3`.

### Contact Details
* **Contact Details** (`select_multiple`, required): Please select all the contact details you'd like to share with us, including your name, email, and phone number.

### Note
* **Note** (`note`, optional): If you'd like to leave any additional information, please do so in this field.

### Date
* **Date** (`date`, optional): If you'd like to select a specific date, please do so. Note that this field is not required.

### Time
* **Time** (`time`, optional): If you'd like to select a specific time, please do so. Note that this field is not required.

### Phone
* **Phone** (`text`, optional): If you'd like to provide your phone number, please do so in this field. Note that this field is not required.

### Email
* **Email** (`email`, optional): If you'd like to provide your email address, please do so in this field. Note that this field is not required.

### Confirm Signature
* **Confirm Signature** (`select_one`, optional): If you're confirming a signature, please select the option that best describes the situation. You can choose between `Option 1` or `Option 2`.

### Confirm Signature Note
* **Confirm Signature Note** (`note`, optional): If you'd like to leave a note for the confirmed signature, please do so. Note that this field is not required.
