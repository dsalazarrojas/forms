# Financial Compliance Reporting Consent Form - Help Guide
## Purpose
This form is used to obtain user consent for financial compliance reporting. It is a required form that must be completed and signed by the user to indicate their consent for reporting activities.

## How To Complete This Form
To complete this form, follow these steps:
1. Fill in the required fields with the requested information, including:
	* Reporting Frequency: Select the frequency of the reporting activity (e.g., Daily, Weekly, Monthly).
	* Reporting Manager: Select one or more managers who will be responsible for the reporting activity.
2. Fill in any additional information as required or desired.

## Field-by-Field Explanation
* **User Consent** (User Consent, text, Optional)
	+ This field is for the user to provide their consent for financial compliance reporting.
* **Reporting Period** (Reporting Period, date, Optional)
	+ Select the period for which the user consents to the reporting activity.
* **Reporting Frequency** (Reporting Frequency, select_one, **Required**)
	+ Select the frequency of the reporting activity (e.g., Daily, Weekly, Monthly).
* **Contact Name** (Contact Name, text, Optional)
	+ Enter the name of the contact person responsible for the reporting activity.
* **Contact Email** (Contact Email, email, Optional)
	+ Enter the email address of the contact person responsible for the reporting activity.
* **Contact Phone** (Contact Phone, text, Optional)
	+ Enter the phone number of the contact person responsible for the reporting activity.
* **Contact Department** (Contact Department, text, Optional)
	+ Enter the department or division responsible for the reporting activity.
* **Reporting Manager** (Reporting Manager, select_multiple, **Required**)
	+ Select one or more managers who will be responsible for the reporting activity.
* **Reporting Officer** (Reporting Officer, text, Optional)
	+ Enter the name of the reporting officer responsible for the reporting activity.
* **Date Signed** (Date Signed, date, Optional)
	+ Select the date the user signed the form.
* **Signature** (Signature, note, Optional)
	+ Sign your name to indicate your consent.
* **Comments** (Comments, text, Optional)
	+ Enter any additional comments or notes about the reporting activity.
* **Form Version** (Form Version, text, Optional)
	+ Enter the version of the form being used.
