# Guardian Consent Form - Help Guide
## Purpose
This form is used to obtain consent from a guardian for a specific activity or event. The guardian's name, contact information, and consent will be stored for reference.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter a brief title for the form in the "Guardian Consent Form" field.
2. Select a category for the form from the options provided (e.g., "Consent Forms" or "Other").
3. Enter a description of the activity or event for which you are seeking consent.
4. Fill in the guardian's details in the "Guardian Details" field.
5. Provide a detailed description of the activity in the "Activity Details" field.

## Field-by-Field Explanation

* **Guardian Consent Form** (`form_title`, `text`, not required): Enter a brief title for the form to identify it.
* **Category** (`category`, `select_one`, not required): Select a category for the form from the options provided.
* **Description** (`description`, `text`, not required): Enter a description of the activity or event for which you are seeking consent.
* **Guardian Details** (`guardian_details`, `text`, not required): Fill in the guardian's details, such as their name and contact information.
* **Activity Details** (`activity_details`, `text`, not required): Provide a detailed description of the activity for which you are seeking consent.

## Tips

* Make sure to fill in all the required fields to ensure accurate and complete consent.
* Be specific when providing activity details to ensure the guardian has a clear understanding of the activity.
* If you're unsure about any field, please ask a colleague for assistance.
