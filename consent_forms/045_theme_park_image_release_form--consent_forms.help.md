# Theme Park Image Release Form - Help Guide
## Purpose
This form is used to obtain consent from guests for the use of their theme park images.

## How To Complete This Form
To complete this form, simply follow these steps:

1. Provide your name and email address in the corresponding fields.
2. Select the type of theme park image(s) you wish to release.
3. Choose the intended release location(s) for the image(s).

## Field-by-Field Explanation

* **Theme Park Image Release** (`theme_park_image_release_form_1`, text, optional): Provide a brief description of the type of image you wish to release.
* **Guest Name** (`theme_park_image_release_form_2`, text, optional): Enter your name as it should be displayed in connection with your image.
* **Theme Park** (`theme_park`, text, optional): Enter the name of the theme park you visited.
* **Guest Email** (`guest_email`, email, optional): Enter your email address.
* **Theme Park Image** (`theme_park_image_release_form_5`, text, optional): Describe the theme park image you wish to release.
* **Release What** (`release_what`, select_multiple, optional): Select all that apply:
	+ Park
	+ Rides
	+ Attractions
	+ Shows
	+ Entertainment
* **Release Where** (`release_where`, select_multiple, optional): Select all that apply:
	+ Theme Park
	+ Social Media
	+ Online
	+ Printed Materials
	+ Other
* **Signature** (`signature`, text, optional): Sign your name to confirm your consent.
* **Date** (`date`, date, optional): Date of visit to the theme park.
* **Time** (`time`, time, optional): Time of visit to the theme park.
* **Additional Comments** (`theme_park_image_release_form_11`, text, optional): If there's anything else you'd like to add, please do so here.

## Tips
* Please ensure that you have the permission of any minors accompanying you to complete this form.
* If you have any questions or concerns, please contact us at form@gic.mx.
