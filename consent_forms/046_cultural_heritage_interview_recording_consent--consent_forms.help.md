# Cultural Heritage Interview Recording Consent - Help Guide
## Purpose
This form is designed to gather information about an individual's consent to record their cultural heritage interview.

## How To Complete This Form

To complete this form, follow these steps:

1. Answer the "recording-consent" question by selecting "Yes" or "No" to indicate your consent for the recording.
2. If you select "Yes", you will be asked to choose the format of the recording (mp3, wav, or flac).
3. Select the device used for the recording (phone, computer, or digital camera).
4. Choose the location of the recording (in-person, over-the-phone, or video-call).
5. Provide any additional comments or notes from the researcher.

## Field-by-Field Explanation
### 1. **Cultural Heritage Interview Recording Consent** (`cultural_heriage_interview_recording_consent`)
	* Type: Text
	* Required: False
	* Purpose: This is the title of the form.
### 2. **Researcher Name** (`researcher-name`)
	* Type: Text
	* Required: False
	* Purpose: This is the name of the researcher who will be conducting the interview.
### 3. **Recording Consent**
	* Type: Select One
	* Required: True
	* Purpose: This question determines whether you agree to be recorded during the interview. Select "Yes" to consent to the recording.
### 4. **Date of Recording**
	* Type: Date
	* Required: False
	* Purpose: This field is not required but will record the date of the interview.
### 5. **Time of Recording**
	* Type: Time
	* Required: False
	* Purpose: This field is not required but will record the time of the interview.
### 6. **Recording Format**
	* Type: Select One
	* Required: True
	* Purpose: Choose the format of the recording (mp3, wav, or flac).
### 7. **Recording Device**
	* Type: Select One
	* Required: False
	* Purpose: Select the device used for the recording (phone, computer, or digital camera).
### 8. **Location of Recording**
	* Type: Select One
	* Required: True
	* Purpose: Choose where the recording will take place (in-person, over-the-phone, or video-call).
### 9. **Additional Comments**
	* Type: Text
	* Required: False
	* Purpose: This field is for any additional comments or notes from the researcher.
### 10. **Researcher Notes**
	* Type: Text
	* Required: False
	* Purpose: This field is for the researcher to add any notes about the interview or the individual.
