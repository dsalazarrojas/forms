# Photo Print Release Form Template - Help Guide
## Purpose
The Photo Print Release Form Template is used to obtain consent from a client for printing and sharing their photos.

## How To Complete This Form
To complete this form, please follow these steps:

1. Enter the client's name in the "Client Name" field.
2. Select the date the photo was captured in the "Photo Capture Date" field.
3. Choose whether or not you grant permission for printing in the "Print Permission Granted" field.
4. Select which print permits you would like to grant in the "Print Permit" field.
5. Enter the number of prints you would like to make in the "Print Quantity" field (this field is only required if you choose to print).
6. If you would like to share the photos, select the "Photo Location" field.
7. Choose the studio where the photo was captured in the "Photo Capture Location" field.
8. Select which location you would like to share the photos at in the "Print Location" field.
9. Select which contact method you would like to use to reach you in the event of any questions or concerns in the "Contact Info" field.

## Field-by-Field Explanation

* **Client Name** (`client_name`, required): Please enter the name of the client.
* **Photo Capture Date** (`photo_capture_date`, required): Enter the date the photo was captured.
* **Print Permission Granted** (`print_permission_granted`, required): Choose "Yes" to grant permission for printing, and "No" to deny.
* **Print Permit** (`print_permit`, required): Select the type of print permit you would like to grant (e.g. Print permit, Print permit 1, Print permit 2).
* **Print Quantity** (`print_quantity`, required): Enter the number of prints you would like to make. This field is only required if you choose to print.
* **Photo Location** (`photo_location`, optional): If you would like to share the photos, enter the location where you would like to share them.
* **Photo Capture Location** (`photo_capture_location`, required): Select the studio where the photo was captured.
* **Print Location** (`print_location`, required): Select the location where you would like to share the photos (e.g. Online, Offline).
* **Contact Info** (`contact_info`, required): Select the contact method you would like to use (e.g. Email, Phone, Text).
