# Leak Repair Service Agreement - Help Guide
## Purpose
This form is used to capture essential details about a service repair job involving a leak from a customer or client. The collected data will be used to facilitate communication and record-keeping between the service provider and the customer.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter your **service-agreement** on the first page. This is an optional field for any additional information you'd like to share about the service agreement.
2. Schedule the **visit-schedule** by selecting a date for the visit.
3. Provide **key-details** about the issue with the leak, such as its location and severity.
4. Describe the **data_collection** requirements for the job, including any specific data that needs to be collected or measured.
5. Enter your **form_submission** comments or any other relevant information about the job.
6. Provide **contractor_info** about the service provider, including their name and contact details.
7. Enter **customer_info** about the customer, including their name and contact details.
8. Describe the **job_details** of the service job, including the work to be done and any specific requirements.
9. Sign the **signature** page to confirm that you've read and understood the agreement.
10. Select the **contract-status** of the agreement, which can be Active, Inactive, or Pending.

## Field-by-Field Explanation

* **service-agreement**: Enter any additional information you'd like to share about the service agreement.
	+ Type: text
	+ Required: No
* **visit-schedule**: Select a date for the visit.
	+ Type: date
	+ Required: No
* **key-details**: Describe the issue with the leak, including its location and severity.
	+ Type: text
	+ Required: No
* **data-collection**: Describe the data collection requirements for the job, including any specific data that needs to be collected or measured.
	+ Type: text
	+ Required: No
* **form-submission**: Enter any additional comments or information about the job.
	+ Type: text
	+ Required: No
* **contractor-info**: Enter your name and contact details as the service provider.
	+ Type: text
	+ Required: No
* **customer-info**: Enter the customer's name and contact details.
	+ Type: text
	+ Required: No
* **job-details**: Describe the job details, including the work to be done and any specific requirements.
	+ Type: text
	+ Required: No
* **signature**: Sign to confirm that you've read and understood the agreement.
	+ Type: note
	+ Required: No
* **contract-status**: Select the status of the agreement, which can be Active, Inactive, or Pending.
	+ Type: select_one
	+ Required: No
