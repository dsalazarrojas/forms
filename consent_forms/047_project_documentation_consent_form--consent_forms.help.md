# project_documentation_consent_form - Help Guide
## Purpose
This form is designed to gather participant information and obtain their consent for various aspects of a project, including photography, recording, and sharing of project materials.

## How To Complete This Form
To complete this form, follow these steps:

1. Provide your participant information on the "Participant Information" page.
2. Choose the type of consent you are willing to give.
3. Indicate whether you are willing to be photographed or recorded.
4. Decide whether you are willing to grant permission for your project materials to be shared.
5. If you have chosen to grant permission for sharing, specify the purpose for which the materials will be used (educational, research, or promotional).

## Field-by-Field Explanation

* **Participant Information** (1): Provide your participant information, which will help us identify and contact you if needed.
* **What type of consent will be obtained?** (2): Select one of the following options:
	+ Educational: For educational purposes, such as using images or videos for teaching or presentations.
	+ Research: For research purposes, such as studying or analyzing data.
	+ Promotional: For promotional purposes, such as using images or videos for marketing or advertising.
* **Will you be photographed?** (3): Select all that apply:
	+ True: You are willing to be photographed.
	+ False: You do not want to be photographed.
* **Will you be recorded?** (4): Select all that apply:
	+ True: You are willing to be recorded.
	+ False: You do not want to be recorded.
* **Will you grant permission for your project materials to be shared?** (5): Select all that apply:
	+ True: You grant permission for your project materials to be shared.
	+ False: You do not grant permission for your project materials to be shared.
* **For educational purposes, what will the materials be used for?** (6): Select all that apply:
	+ Teaching: For teaching purposes, such as using images or videos for educational instruction.
	+ Research: For research purposes, such as studying or analyzing data.
	+ Project presentation: For presenting projects or results.
* **For research purposes, what will the materials be used for?** (7): Select all that apply:
	+ Study: For conducting studies or experiments.
	+ Analysis: For data analysis.
	+ Presentation: For presenting research findings.
* **For promotional purposes, what will the materials be used for?** (8): Select all that apply:
	+ Social media: For promoting on social media platforms.
	+ Website: For publishing on a website.
	+ Print materials: For printing promotional materials, such as posters or flyers.

## Tips
* Make sure to fill out all required fields and select all applicable options for each field.
* Double-check your selections before submitting the form.
* If you have any questions or concerns, please contact us at [contact email].
