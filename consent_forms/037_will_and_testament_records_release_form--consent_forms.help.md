# Will And Testament Records Release Form - Help Guide
## Purpose
The Will And Testament Records Release Form is used to record information about will and testament documents. 

## How To Complete This Form

To complete this form, follow these steps:

* Select the type of document (e.g., will, testament, letter testament, codicil) from the drop-down menu.
* Choose whether you want to record this document as active or inactive.
* Enter the date and time the document was created.
* Enter the location where the document was created.
* Enter a document number and version.
* Provide contact information for authorized individuals (executor, attorney, beneficiary).
* Enter a contact email and phone number.

## Field-by-Field Explanation

* **release_form** (Select Multiple): This field asks you to confirm whether you want to release the will and testament records.
	+ Select "Yes" to release the records.
	+ Select "No" to keep the records private.
* **authorized_individual** (Select One): This field asks you to choose from the following options:
	+ Authorized Executor: This is the person appointed by the testator to manage their estate.
	+ Authorized Attorney: This is the person appointed by the testator to handle their estate's legal matters.
	+ Authorized Beneficiary: This is the person who benefits from the will and testament.
* **relationship** (Text): This field is for describing the relationship between the authorized individual and the testator.
* **estate_settlement_process** (Text): This field is for describing the estate settlement process.
* **will_and_testament_document** (Select One): This field asks you to select the type of document (e.g., will, testament, letter testament, codicil).
* **document_date** (Date): This field asks for the date the document was created.
* **document_time** (Time): This field asks for the time the document was created.
* **document_location** (Text): This field is for describing the location where the document was created.
* **document_number** (Number): This field asks for a document number.
* **document_version** (Number): This field asks for a document version.
* **estate_administrator** (Text): This field is for describing the estate administrator.
* **document_status** (Select One): This field asks you to select the document status:
	+ Active: This means the document is active and being managed.
	+ Inactive: This means the document is not active and not being managed.
	+ Archived: This means the document is archived and not being managed.
* **notes** (Note): This field is for adding any additional comments or notes about the document.
* **email** (Email): This field asks for a contact email address.
* **phone** (Text): This field asks for a contact phone number.
* **confirm_email** (Email): This field is for confirming the contact email address.
* **confirm_phone** (Text): This field is for confirming the contact phone number.
* **confirm_address** (Text): This field is for confirming the address of the authorized individual.
* **confirm_city** (Text): This field is for confirming the city of the authorized individual.
* **confirm_state** (Text): This field is for confirming the state of the authorized individual.
* **confirm_zip** (Text): This field is for confirming the zip code of the authorized individual.
* **confirm_postal_code** (Text): This field is for confirming the postal code of the authorized individual.
* **confirm_country** (Text): This field is for confirming the country of the authorized individual.
* **confirm_document_version** (Number): This field is for confirming the document version number.

**Tips**

* Please fill out the form accurately and completely.
* Do not leave any fields blank unless it's clearly specified that it's optional.
* Please ensure that you have the necessary permissions and authority to access or manage will and testament documents.
* Please review the document carefully before filling out this form.
* If you have any questions or concerns, please contact the relevant authorities.
