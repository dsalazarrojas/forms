# Public Event Participation Waiver Form - Help Guide
## Purpose
This guide is to help participants complete the Public Event Participation Waiver Form correctly and understand the purpose of each field.

## How To Complete This Form
1. The form has multiple pages with fields that need to be filled in. Please complete each page in order.
2. Fill in the required fields first, which are marked as "required" in the form.
3. If a field is not required, but you want to provide additional information, you can fill it in as well.

## Field-by-Field Explanation
### Participants Name (1)
* **Participants Name**: <Participants Name>, a text field to input your name.
* Explanation: Please provide your name as it appears on your government-issued ID or passport.
### Event ID (2)
* **Event ID**: <Event ID>, a number field to input the ID of the event you are participating in.
* Explanation: Please provide the ID number of the event you are participating in. This can usually be found on the event's advertisement or registration page.
### Event Name (3)
* **Event Name**: <Event Name>, a text field to input the name of the event you are participating in.
* Explanation: This is the name of the event you are participating in. If you are unsure, please check the event's advertisement or registration page.
### Waiver Type (4)
* **Waiver Type**: Please select one of the options (Choice 1, Choice 2, Choice 3).
* Explanation: Select the type of waiver you are signing. Please note that this field is required.
### Waiver Signed (5)
* **Waiver Signed**: Please select "True" if you have signed the waiver or "False" if you have not.
* Explanation: Please select "True" if you have signed the waiver or "False" if you have not.
### Participant Date of Birth (6)
* **Participant Date of Birth**: <Participant Date of Birth>, a date field to input your date of birth.
* Explanation: Please provide your date of birth in the format "YYYY-MM-DD".
### Participant Phone (7)
* **Participant Phone**: <Participant Phone>, a text field to input your phone number.
* Explanation: Please provide your phone number if you want to be reached in case of an emergency or other communication.
### Waiver Date Signed (8)
* **Waiver Date Signed**: <Waiver Date Signed>, a date field to input the date you signed the waiver.
* Explanation: Please provide the date you signed the waiver.
### Participant Address (9)
* **Participant Address**: <Participant Address>, a text field to input your address.
* Explanation: Please provide your address for contact and communication purposes.
### Waiver Version (10)
* **Waiver Version**: <Waiver Version>, a text field to input the version of the waiver you are signing.
* Explanation: This field is not required but can be useful if you need to provide additional information about the waiver you are signing.

## Tips
* Please ensure that you are filling in the correct information for the event you are participating in.
* If you are unsure about any field, please ask the event organizer for clarification.
* Please review the waiver carefully before signing it.
* If you have any questions or issues with the form, please contact the event organizer or support team.
