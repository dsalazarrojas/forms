# Fishing Competition Form - Help Guide
## Purpose
The Fishing Competition Form is designed to collect information about fishing competitions. It is used to gather user input on various aspects of fishing competitions.

## How To Complete This Form
To complete this form, follow these steps:

* Start by filling out the flight field, which is used to indicate the type of flight associated with the competition.
* In the contestant field, select all applicable answers. This field is used to track the types of contestants participating in the competition.
* In the event field, select all applicable answers. This field is used to track the types of events associated with the competition.
* In the fish type field, select the type of fish being targeted in the competition.

## Field-by-Field Explanation
* **Flight**: Enter the type of flight associated with the competition (e.g., morning, afternoon, etc.).
* **Contestant**: Select all types of contestants participating in the competition, if applicable. This may include professional, amateur, or both.
* **Event**: Select all types of events associated with the competition, if applicable. This may include local, national, or international.
* **Fish Type**: Select the type of fish being targeted in the competition (e.g., salmon, trout, bass, etc.).
