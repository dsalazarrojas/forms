# faith_based_video_sermon_appearance_consent_form - Help Guide
## Purpose
The purpose of this form is to collect contact information and recording type preferences for faith-based video sermons. This form is used to ensure that the speaker, host, or content creator has given their consent for the recording and sharing of their video sermons.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the correct contact type for the speaker, host, or content creator.
	* Choose "Video" if you are a video producer or creator.
	* Choose "Live" if you are a live presenter or performer.
	* Choose "Both" if you are both a video and live presenter.
2. Enter the email address of the speaker, host, or content creator.
3. Enter the phone number of the speaker, host, or content creator.
4. Enter the address of the speaker, host, or content creator.
5. Select the recording type for the video sermon.
	* Choose "Video" if you want to record a video of the sermon.
	* Choose "Live" if you want to record a live presentation.
	* Choose "Both" if you want to record both a video and live presentation.
6. Select the additional recording types for the video sermon.
	* Choose "Video" if you want to record a video of the sermon.
	* Choose "Live" if you want to record a live presentation.
	* Choose "Both" if you want to record both a video and live presentation.

* **Contact Details (`contact_details`)**: Select the correct contact type for the speaker, host, or content creator.
	+ Required
	+ Type: select_one
	+ Options: Video, Live, Both

	+ Required
	+ Type: email
* **Phone (`contact_details3`)**: Enter the phone number of the speaker, host, or content creator.
	+ Required
	+ Type: text
* **Address (`contact_details4`)**: Enter the address of the speaker, host, or content creator.
	+ Required
	+ Type: text
* **Recording Type (`contact_details5`)**: Select the recording type for the video sermon.
	+ Required
	+ Type: select_one
	+ Options: Video, Live, Both
* **Recording Type 2 (`contact_details6`)**: Select the additional recording type for the video sermon.
	+ Optional
	+ Type: select_multiple
	+ Options: Video, Live, Both
