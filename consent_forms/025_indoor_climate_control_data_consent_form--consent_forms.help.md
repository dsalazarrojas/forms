## Form Logic
This form is used to collect indoor climate control data consent from property owners. The primary goal is to obtain consent for monitoring and data collection purposes. The form is divided into several sections that ask for various types of consent, including property owner consent, monitoring purpose, and data sharing. Completing this form will help property owners understand how their indoor climate control data will be used and what will be shared with third parties. 

This form will be filled out by property managers or owners to gather consent from occupants, ensuring they understand the scope and intent of the data collection. 

The form is part of a larger system for managing indoor climate control data.

## Indoor Climate Control Data Consent Form - Help Guide
## Purpose
This form is used to collect indoor climate control data from property owners, seeking their consent for monitoring and data collection purposes.

## How To Complete This Form
To complete this form, please follow these steps:

1. Review the form carefully to understand the purpose and scope of the consent.
2. Select the relevant options for each field, based on your understanding of the indoor climate control data to be collected.
3. Sign and date the form to indicate your consent.

## Field-by-Field Explanation
### Indoor Climate Control Data (<id: 1>)
* **Indoor Climate Control Data** (`select_multiple`, required): Please select all the types of data you are consenting to collect: "Yes" for each type of data you wish to collect.

### Property Owner Consent (<id: 2>)
* **Property Owner Consent** (`select_one`, required): Please select "Yes" to indicate that you are consenting to the collection and use of your indoor climate control data.

### Monitoring Purpose (<id: 3>)
* **Monitoring Purpose** (`select_one`, required): Please select "Yes" to indicate the purpose of the data collection. This could be for monitoring, optimization, or research projects.

### Research Projects (<id: 4>)
* **Research Projects** (`select_multiple`, optional): If the data collection is for research projects, please select all the relevant options.

### Monitoring Duration (<id: 5>)
* **Monitoring Duration** (`select_one`, optional): If the data collection is for monitoring, please select the duration for which the monitoring will take place.

### Optimization Projects (<id: 6>)
* **Optimization Projects** (`select_multiple`, optional): If the data collection is for optimization projects, please select all the relevant options.

### Monitoring Frequency (<id: 7>)
* **Monitoring Frequency** (`select_one`, optional): If the data collection is for monitoring, please select the frequency at which the monitoring will occur.

### Data Sharing (<id: 8>)
* **Data Sharing** (`select_one`, optional): If the data collection is to be shared with third parties, please select "Yes".

### Consent Date (<id: 9>)
* **Consent Date** (`date`, required): Please enter the date on which you are providing consent.

### Form Version (<id: 10>)
* **Form Version** (`text`, required): Please enter the version of this form being used.

### Assigned Tool (<id: 11>)
* **Assigned Tool** (`text`, required): Please enter the tool assigned for this form (e.g., system, software, etc.).

**Tips**

* Please review this form carefully before filling it out.
* If you are unsure about any of the options, please ask a member of your organization for guidance.
* This form must be signed and dated to be considered valid. 

This form is used to gather consent for indoor climate control data collection and monitoring purposes. Completing this form is mandatory for property owners to understand how their data will be used and shared.
