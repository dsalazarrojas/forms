# Rehabilitation App Usability Recording Consent Form - Help Guide

## Purpose
This form is used to record the consent and demographic information of participants in a usability testing session for a rehabilitation app. It is essential to collect this information to ensure a smooth and productive testing experience for both the participant and the test administrators.

## How To Complete This Form
To complete this form, follow the instructions below:

1. Please enter your participant information in the fields provided.
2. Answer the consent question by selecting "True" if you agree to be recorded or "False" if you do not.
3. If you have a phone number, please enter it in the "Participant Phone" field.
4. If you have an email address, please enter it in the "Participant Email" field.
5. If you have an address, please enter it in the "Participant Address" field.
6. If you are being recorded, you can select the recording duration that best describes the test session.

## Field-by-Field Explanation
- **Participant Information** (participant_information): This field is where you can enter your name and other relevant participant information.
  * **Consent to Record** (consent_to_record): Please select "True" if you are willing to be recorded during the test session, or "False" if you are not.
  * **Participant Phone** (participant_phone): This field is optional, and you can enter your phone number if you have one.
  * **Participant Email** (participant_email): This field is optional, and you can enter your email address if you have one.
  * **Participant Address** (participant_address): This field is optional, and you can enter your address if you have one.
  * **Recording Location** (recording_location): This field is optional, and you can enter the location where the recording will take place.
  * **Recording Duration** (recording_duration): If you are being recorded, please select the recording duration that best describes the test session.
  * **Participant Notes** (participant_note): This field is optional, and you can enter any additional comments or notes you may have.

## Tips
- Please ensure that all fields are completed accurately to avoid any issues during the test session.
- If you are unsure about any field, do not hesitate to ask the test administrators for clarification.
- It is essential to have all required fields filled out to ensure a smooth testing experience.
