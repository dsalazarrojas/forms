# Creative Writing Reading Recording Consent Form - Help Guide
## Purpose
The "Creative Writing Reading Recording Consent Form" is designed to capture consent and information from individuals involved in creative writing projects. This form ensures that all parties involved are aware of and agree to the terms of recording and usage of the creative work.

## How To Complete This Form

1. **First Name** (`first_name`, text, required): Enter your first name.
2. **Last Name** (`last_name`, text, required): Enter your last name.
3. **Phone Number** (`phone`, text, required): Enter a valid phone number where you can be reached.
4. **School Name** (`school_name`, text, required): Enter the name of the school or institution associated with the project.
5. **Event ID** (`event_id`, text, required): Enter the ID number for the project or event.
6. **Usage** (`usage`, select_one, optional): Select 'Yes' if the recording is for usage purposes, 'No' if not.
7. **Other (usage)** (`usage_other`, text, optional): If 'Yes' is selected for 'Usage', provide a brief description of the usage.
8. **Recording Permission** (`recording_permission`, select_multiple, optional): Select 'Yes' for recording permission, 'No' if not.
9. **Storage Permission** (`storage_permission`, select_multiple, optional): Select 'Yes' for storage permission, 'No' if not.
10. **Storage Description** (`storage_description`, text, optional): If 'Yes' is selected for 'Storage Permission', provide a brief description of storage details.
11. **Recording Method** (`recording_method`, select_one, optional): Select 'Yes' if recording method is required, 'No' if not.
12. **Consent Date** (`consent_date`, date, optional): Date when the consent was given.
13. **Recording Location** (`recording_location`, text, optional): Enter the location where the recording will take place.
14. **Recording Time** (`recording_time`, time, optional): Time when the recording will be made.
15. **Recording Agency** (`recording_agency`, select_one, optional): Select 'Yes' if recording agency is involved, 'No' if not.
16. **Other (Recording Agency)** (`recording_agency_other`, text, optional): If 'Yes' is selected for 'Recording Agency', provide a brief description of the agency.
17. **Recording Agency Agreement** (`recording_agency_agreement`, text, optional): Enter the agreement or contract between the agency and the school.
18. **Recording Agency Agreement Info** (`recording_agency_agreement_info`, text, optional): Enter any additional information related to the recording agency agreement.
19. **Other Info (Recording Agency)** (`recording_agency_other_info`, text, optional): Enter any other information related to the recording agency.
