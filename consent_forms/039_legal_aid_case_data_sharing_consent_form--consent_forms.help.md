# Legal Aid Case Data Sharing Consent Form - Help Guide
## Purpose
This form is designed to collect informed consent from individuals before sharing their legal aid case data with other parties. It's essential to review the form carefully to ensure that it aligns with the organization's or entity's specific requirements.

## How To Complete This Form
To complete this form, please follow the steps below:

1. Review the form carefully to understand the purpose and the fields required.
2. Select the relevant category for the legal aid case data sharing.
3. Provide a description of the case in the designated field.
4. Check if you want to share the data with any selected parties.
5. Specify the method of sharing the data.
6. Enter the names and titles of the parties you want to share the data with.
7. Indicate if you want to share the data with multiple parties at once.
8. Enter the date sharing began and the date sharing ends.
9. Confirm that you understand the risks involved in sharing the data.
10. Sign the form to provide explicit consent.

## Field-by-Field Explanation
- **Category**: Select the category for the legal aid case data sharing. This field helps identify the type of data being shared.
  * Type: select multiple
  * Required: false
- **Description**: Enter a brief description of the legal aid case data being shared. This field helps explain the context of the data.
  * Type: note
  * Required: true
- **Selected Parties**: Check if you want to share the data with any selected parties.
  * Type: select one
  * Required: false
- **Sharing Method**: Specify the method for sharing the data. This field helps determine how the data will be shared.
  * Type: select one
  * Required: false
- **Share With**: Enter the names and titles of the parties you want to share the data with.
  * Type: text
  * Required: true
- **Share With Multiple**: Check if you want to share the data with multiple parties at once.
  * Type: select multiple
  * Required: false
- **Date Sharing Began**: Enter the date when sharing began.
  * Type: date
  * Required: true
- **Date Sharing Ends**: Enter the date when sharing will end.
  * Type: date
  * Required: true
- **Consent**: Confirm that you understand the risks involved in sharing the data.
  * Type: select one
  * Required: true
- **Signature**: Provide your signature to explicit consent.
  * Type: text
  * Required: true
- **Date Signed**: Enter the date the form was signed.
  * Type: date
  * Required: false
  * Note: This field is not required but recommended for record-keeping purposes.
- **Time Signed**: Enter the time the form was signed.
  * Type: time
  * Required: false
  * Note: This field is not required but recommended for record-keeping purposes.

## Tips
- Please review the form carefully before submission to ensure accuracy and completeness.
- If you are unsure about any field, please seek clarification from the responsible party.
- Ensure that you have informed consent from all parties involved before sharing the data.
- Store this form securely to maintain confidentiality and protect sensitive data.
