# Prototype Evaluation Permission Form - Help Guide
## Purpose
This form is used to obtain permission to evaluate a prototype. It captures information needed for the evaluation process, including contact details, date and time, and the status of the evaluation. Please ensure you have a valid reason for evaluating the prototype before submitting this form.

## How To Complete This Form
To complete this form, follow the instructions below.

1. Enter your name and email address in the "Name" and "Email" fields, respectively. These fields are required to contact you for further communication.
2. If you have a phone number, enter it in the "Phone" field. This is an optional field but can be helpful for communication.
3. Select the start and end dates for the evaluation in the "Start Date" and "End Date" fields, respectively. These fields are optional but help track the evaluation period.
4. Enter the version of the prototype being evaluated in the "Prototype Version" field. This field is optional but helps track changes.
5. If applicable, specify the location where the evaluation took place in the "Evaluation Location" field.
6. Select the current status of the evaluation from the options provided in the "Evaluation Status" field. This field is optional.
7. Enter any comments or feedback about the prototype in the "Evaluation Comments" field. This field is optional.
8. If you have submitted the form before, select the corresponding option in the "Form Submitted" field. This field is optional.
9. Indicate if you plan to evaluate the prototype in the "Evaluate Prototype" field. This field is optional.
10. Finally, select the completion status of the evaluation from the options provided in the "Complete" field. This field is optional.

## Field-by-Field Explanation
* **Form Title** (`prototype_evaluation_permission_form`, text, optional): Enter a suitable title for the evaluation.
* **Name** (`name`, text, required): Enter your name as the person submitting the form.
* **Email** (`email`, email, required): Enter your email address for further communication.
* **Phone** (`phone`, text, optional): Enter your phone number for further communication (optional).
* **Start Date** (`evaluation_start_date`, date, optional): Select the start date of the evaluation period.
* **End Date** (`evaluation_end_date`, date, optional): Select the end date of the evaluation period.
* **Evaluation Period** (`evaluation_period`, number, optional): Enter the duration of the evaluation period.
* **Prototype Version** (`prototype_version`, text, optional): Enter the version of the prototype being evaluated.
* **Evaluation Location** (`evaluation_location`, text, optional): Enter the location where the evaluation took place.
* **Evaluation Status** (`evaluation_status`, select_one, optional): Select the status of the evaluation from the options provided.
* **Evaluation Comments** (`evaluation_comments`, note, optional): Enter any comments or feedback about the prototype.
* **Form Submitted** (`evaluation_form_submitted`, select_multiple, optional): If you have submitted the form before, select the corresponding option.
* **Evaluate Prototype** (`prototype_evaluate`, select_one, optional): Indicate if you plan to evaluate the prototype.
* **Complete** (`evaluation_complete`, select_one, optional): Select the completion status of the evaluation.
