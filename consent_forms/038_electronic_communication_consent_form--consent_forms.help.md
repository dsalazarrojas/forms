# electronic_communication_consent_form - Help Guide
## Purpose
This form is designed to collect electronic communication consent from patients. It is used to gather information about how patients would like to receive communication from medical providers, such as emails, phone calls, or text messages.

## How To Complete This Form
To complete this form, follow these steps:

1. Ensure that you have a clear understanding of your communication preferences as a patient.
2. Fill in the patient name in the text field below.
3. Choose how you would like to receive communication from us through the "Consent Method" dropdown menu.
4. If you would like to be contacted by email, enter your email address in the "Email" field.
5. If you would like to be contacted by phone, enter your phone number in the "Phone" field.
6. If you have a portal ID that you would like to use for communication, enter it in the "Portal" field.
7. Check the "HIPAA Compliance" box if you are compliant with HIPAA regulations.
8. Select a date for your consent in the "Consent Date" field.

## Field-by-Field Explanation
- **Patient Name** (`patient_name`, text, required): Enter your name as it should be used for communication.
- **Consent Method** (`consent_method`, select_one, optional): Choose how you would like to receive communication from us:
  * email: Receive communication via email.
  * text: Receive communication via text message.
  * patient portal: Receive communication through the patient portal.
  * phone: Receive communication via phone call.
  * mail: Receive communication via mail.
- **Email** (`email`, email, optional): Enter your email address if you have chosen to receive communication via email.
- **Phone** (`phone`, text, optional): Enter your phone number if you have chosen to receive communication via phone call.
- **Portal** (`portal`, text, optional): Enter your patient portal ID if you have chosen to receive communication through the patient portal.
- **HIPAA Compliance** (`hipaa_compliance`, select_one, optional): Check this box if you are compliant with HIPAA regulations.
- **Consent Date** (`consent_date`, date, optional): Select a date for your consent.
