# survey_area_access_permission_form - Help Guide
## Purpose
The survey_area_access_permission_form is used to request access to a survey area. Only users with legitimate work-related access needs should fill out this form.

## How To Complete This Form
To complete this form, follow these steps:

1. Select "Yes" or "No" from the permission field to indicate if you have already been granted permission to access the survey area.
2. Select "Yes" or "No" from the permission field to indicate if you have already been granted permission to access the survey area.
3. Select the desired access level from the access level field to specify how much access you require.
4. Select the user(s) you would like to grant access to from the user field.

## Field-by-Field Explanation
* **Permission**: Select "Yes" to indicate you have not been granted access to the survey area before, or "No" to indicate you already have access.
* **Access Level**: Choose the level of access you require: "read", "write", or "admin".
* **User(s)**: Select the user(s) you would like to grant access to. You can select one or multiple users.
* **Note**: The "survey area access" field is not a field to fill out, but rather a description of the form purpose.
