# Content Sharing Consent Form - Help Guide

## Purpose
The Content Sharing Consent Form is a document used to obtain the content owner's consent for sharing their content on various platforms. This form ensures that the content owner grants permission for the sharing of their content, specifying the sharing purposes, platforms, and duration.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill in your content owner's information:
	* **Content Owner Name**: Enter the name of the content owner.
	* **Content Owner Email**: Enter the email address of the content owner.
	* **Content Owner Phone**: Enter the contact number of the content owner (optional).
2. Provide information about the content:
	* **Content Title**: Enter the title of the content to be shared.
	* **Content Description**: Describe the content in brief.
	* **Content Type**: Select the type of content (e.g., article, blog post, photograph, video, etc.).
	* **Content URL**: Enter the location of the content (optional).
3. Specify sharing details:
	* **Sharing Purpose**: Select the reason for sharing the content (e.g., educational use, research, marketing, etc.).
	* **Sharing Platforms**: Select the platforms where the content will be shared (e.g., website, blog, social media, etc.).
	* **Audience Type**: Select who will see the shared content (e.g., general public, students, employees, etc.).
	* **Geographic Scope**: Select the geographic area where the content will be shared (e.g., local, regional, national, international, etc.).
	* **Sharing Duration**: Select how long the content will be shared (e.g., one-time share, 1 month, 3 months, etc.).
4. Specify sharing conditions:
	* **Modification Allowed**: Select if the content can be modified (e.g., no modifications, minor edits, etc.).
	* **Attribution Required**: Select how the content owner should be credited (e.g., full attribution, partial attribution, etc.).
	* **Attribution Format**: Enter the format of the attribution (optional).
	* **Commercial Use**: Select if the content will be used for commercial purposes.
	* **Compensation**: Select if there is payment for sharing.
	* **Compensation Amount**: Enter the amount of compensation (optional).
	* **Exclusivity**: Select if the sharing is exclusive.
	* **Additional Terms**: Enter any other terms or conditions.
5. Confirm consent:
	* **Consent Granted**: Select yes or no to confirm that you grant consent to share the content.
