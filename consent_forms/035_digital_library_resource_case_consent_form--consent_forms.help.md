# digital_library_resource_case_consent_form - Help Guide
## Purpose
This form is used to collect permissions for using digital resources and case materials. It ensures that users provide clear consent for their actions and helps maintain transparency and accountability.

## How To Complete This Form
To complete this form, follow these steps:

* Fill out the "form_title" field with a clear and concise title for the form.
* Select the correct category for the form, either "Consent Forms" or "Other", in the "category" field.
* Provide a brief description of the form in the "description" field.
* Select "Consent Forms" as the correct category for the form in the "form_category" field.
* Specify the name of the output file in the "form_output_file" field, if applicable.
* Fill out the "assigned_tool" field with relevant information, if applicable.

## Field-by-Field Explanation
* **Digital Library Resource Case Consent Form (form_title)**: Enter a clear and concise title for the form.
* **Category (category)**: Select the correct category for the form, either "Consent Forms" or "Other".
* **Description (description)**: Provide a brief description of the form.
* **Form Category (form_category)**: Select "Consent Forms" as the correct category for the form.
* **Output File (form_output_file)**: Specify the name of the output file, if applicable.
* **Assigned Tool (assigned_tool)**: Enter relevant information about the assigned tool, if applicable.
