# Immigration Waiver Cover Letter Questionnaire - Help Guide
## Purpose
This form is used to create a cover letter for immigration waiver, which is a document that allows a non-citizen to request that immigration or border control waive certain legal requirements or restrictions in order to enter, stay or travel in the country.

## How To Complete This Form
Before filling out this form, please make sure you have all the necessary information required for the client. The form has multiple sections that need to be filled out in order to create a complete and accurate cover letter.

## Field-by-Field Explanation
* **Introduction (1, text)**: This section is an overview of the cover letter. Please provide a brief introduction that explains the purpose of the waiver request.
* **Client Name (2, text, required)**: Please enter the client's full name.
* **Client Contact (3, text, required)**: Please enter the client's contact information, including their address and phone number.
* **Attorney Name (4, text, required)**: Please enter your name and title as the attorney representing the client.
* **Attorney Email (5, email, required)**: Please enter your email address.
* **Document Type (6, select_one, required)**: Please select the type of document being applied for (Application for Waiver, Application for Waiver and Consent, or Other).
* **Document ID (7, text, optional)**: If applicable, please enter the ID number of the document being applied for.
* **Supporting Documents (8, select_multiple, optional)**: Please select the type of supporting documents attached to the application (Proof of Identity, Proof of Income, or Proof of Residency).
* **Submitter Name (9, text, required)**: Please enter your name as the submitter.
* **Submitter Email (10, email, required)**: Please enter your email address.
* **Submitter Phone (11, text, optional)**: If applicable, please enter your phone number.
* **Submitter Contact (12, text, required)**: Please enter your contact information.
* **Submitter Address (13, text, optional)**: If applicable, please enter your address.
* **Submitter City (14, text, optional)**: If applicable, please enter your city.
* **Submitter Province (15, text, optional)**: If applicable, please enter your province.
* **Submitter Postal Code (16, text, optional)**: If applicable, please enter your postal code.
* **Submitter Date of Birth (17, date, optional)**: If applicable, please enter your date of birth.
* **Document Date (18, date, optional)**: If applicable, please enter the date of the document.
* **Submitter Signature (19, text, optional)**: If applicable, please sign this section to indicate that you have reviewed and approved this application.
* **Submitter Note (20, text, optional)**: If applicable, please add any additional comments or notes about the application.
* **Document Note (21, text, optional)**: If applicable, please add any additional comments or notes about the document.
* **Waiver (22, select_one, required)**: Please indicate if the waiver is granted or not.
* **Submitted By (23, select_one, required)**: Please indicate if the waiver was submitted by the client or not.
* **Submitted Date (24, date, required)**: Please enter the date when the waiver was submitted.
* **Submitter IP (25, text, optional)**: If applicable, please enter your IP address.
