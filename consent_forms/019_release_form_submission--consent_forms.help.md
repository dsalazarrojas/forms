# Release Form Submission - Help Guide
## Purpose
The purpose of this form is to collect information related to a release form submission. It is designed to gather details such as participant names, dates, and signatures for an activity or event.

## How To Complete This Form
To complete this form, follow these steps:

1. Review the form carefully to ensure it is being filled out for the correct purpose and that you are not duplicating an existing submission.
2. Fill out the form accurately and completely.
3. If you are a participant, provide your name and signature in the corresponding fields.
4. If you are an organization, provide your logo and signature in the corresponding fields.

## Field-by-Field Explanation

* **Release Form** (`release_form_submission`, note, optional): This field is a placeholder for any additional notes or comments related to the release form submission. It is not a mandatory field, but it can be useful for providing further context or details.
* **Participant Name** (`participant_name`, text, optional): This field is for the name of the participant who is submitting the release form. Please enter the participant's name accurately and completely.
* **Activity Date** (`activity_date`, date, optional): This field is for the date of the activity or event related to the release form submission. Please enter the date in the correct format (mm/dd/yyyy).
* **Organization Logo** (`organization_logo`, text, optional): This field is for the logo of the organization involved in the activity or event. Please enter the logo's name or a brief description.
* **Consent Date** (`consent_date`, date, optional): This field is for the date when consent was given or received. Please enter the date in the correct format (mm/dd/yyyy).
* **Participant Signature** (`participant_signature`, note, optional): This field is for the participant's signature, confirming they have submitted the release form. It is not a mandatory field, but it can be useful for authentication purposes.
* **Organization Signature** (`organization_signature`, note, optional): This field is for the organization's signature, confirming they have accepted or received the release form. It is not a mandatory field, but it can be useful for authentication purposes.
* **Participant Name 2** (`participant_name_2`, text, optional): This field is for the name of a second participant involved in the activity or event. Please enter the participant's name accurately and completely.
* **Participant Name 3** (`participant_name_3`, text, optional): This field is for the name of a third participant involved in the activity or event. Please enter the participant's name accurately and completely.
* **Participant Name 4** (`participant_name_4`, text, optional): This field is for the name of a fourth participant involved in the activity or event. Please enter the participant's name accurately and completely.
* **Participant Name 5** (`participant_name_5`, text, optional): This field is for the name of a fifth participant involved in the activity or event. Please enter the participant's name accurately and completely.
* **Participant Name 6** (`participant_name_6`, text, optional): This field is for the name of a sixth participant involved in the activity or event. Please enter the participant's name accurately and completely.

## Tips
* Ensure that you are filling out the form for the correct purpose and that you are not duplicating an existing submission.
* Double-check your entries for accuracy and completeness.
* If you are unsure about any field or have questions, please contact the form administrators at form@gic.mx.
