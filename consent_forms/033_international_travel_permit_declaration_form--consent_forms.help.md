# International Travel Permit Declaration Form - Help Guide
## Purpose

This form is used to declare international travel information for administrative or regulatory purposes, such as obtaining an international travel permit.

## How To Complete This Form

1. Fill in the required fields with accurate and complete information.
2. Provide as much detail as possible for each field.
3. Review your responses for accuracy and completeness before submitting the form.

## Field-by-Field Explanation

* **Travel information** (id: 1, type: text, required: false)
  This field is used to enter information about the travel, such as travel dates, destination, and any other relevant details.
* **Travel reason** (id: 2, type: text, required: false)
  This field is used to explain the reason for the travel.
* **Travel dates** (id: 3, type: date, required: false)
  This field is used to enter the travel dates.
* **Travel destination** (id: 4, type: text, required: false)
  This field is used to enter the destination of the travel.
* **Travel document** (id: 5, type: text, required: false)
  This field is used to enter any travel documents required for the trip.
* **Travel details** (id: 6, type: text, required: false)
  This field is used to enter additional travel details, such as flight numbers and departure and arrival times.
* **Contact person** (id: 7, type: text, required: false)
  This field is used to enter contact information for the person traveling.
* **Contact phone** (id: 8, type: text, required: false)
  This field is used to enter a contact phone number for the person traveling.
* **Contact email** (id: 9, type: email, required: false)
  This field is used to enter a contact email address for the person traveling.
* **Flight number** (id: 10, type: text, required: false)
  This field is used to enter any flight number(s) associated with the travel.
* **Flight time** (id: 11, type: time, required: false)
  This field is used to enter the flight time.
* **Flight arrival** (id: 12, type: time, required: false)
  This field is used to enter the flight arrival time.
* **Arrival date** (id: 13, type: date, required: false)
  This field is used to enter the arrival date.
* **Travel group** (id: 14, type: text, required: false)
  This field is used to enter any travel group information.
* **Travel document ID** (id: 15, type: number, required: false)
  This field is used to enter any travel document ID.
* **Visa information** (id: 16, type: text, required: false)
  This field is used to enter visa information for the travel.
* **Flight departure** (id: 17, type: time, required: false)
  This field is used to enter the flight departure time.
* **Travel type** (id: 18, type: select_one, required: false)
  This field is used to select the type of travel (Private, Business, Personal).
* **Travel purpose** (id: 19, type: select_multiple, required: false)
  This field is used to select the purpose of the travel (Business, Pleasure, Family, Health, Other).
* **Travel duration** (id: 20, type: number, required: false)
  This field is used to enter the duration of the travel.
* **Country of origin** (id: 21, type: text, required: false)
  This field is used to enter the country of origin.
* **Country of destination** (id: 22, type: text, required: false)
  This field is used to enter the country of destination.
* **Travel agency** (id: 23, type: text, required: false)
  This field is used to enter any travel agency information.
* **Travel agency contact** (id: 24, type: text, required: false)
  This field is used to enter any travel agency contact information.
* **Assigned tool** (id: 25, type: text, required: false)
  This field is used to enter any assigned tool information.

## Tips

* Please make sure to fill in all required fields accurately and completely.
* Review your responses for accuracy and completeness before submitting the form.
* If you are unsure about any field, please contact the relevant authorities for clarification.
