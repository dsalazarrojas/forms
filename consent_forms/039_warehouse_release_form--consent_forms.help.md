# Warehouse Release Form - Help Guide
## Purpose
The Warehouse Release Form is used to record the release of items or assets from a warehouse. This form is used to gather information about the item being released, including its quantity, price, and date of release. It is also used to record any additional notes or remarks about the release.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the status of the item being released using the "user_input" field. You can choose "Yes" or "No" depending on whether the item is being released.
2. Enter the item number in the "item_number" field.
3. Provide a brief description of the item in the "item_description" field.
4. Enter the quantity of the item being released in the "quantity" field.
5. Enter the unit price of the item in the "unit_price" field.
6. Select the date of release from the calendar picker or enter it manually in the "date_of_release" field.
7. Select the time of release from the time picker or enter it manually in the "time_of_release" field.
8. Enter any additional notes or remarks about the release in the "remarks" field.
9. Select the status of the release using the "release_by" field. You can choose "Yes" or "No" depending on whether the release is authorized.
10. Enter the date of release in the "release_date" field.

## Field-by-Field Explanation
* **user_input**: Choose "Yes" if the item is being released or "No" if it is not.
* **item_number**: Enter the number of the item being released.
* **item_description**: Provide a brief description of the item being released.
* **quantity**: Enter the number of units of the item being released.
* **unit_price**: Enter the price per unit of the item.
* **date_of_release**: Select the date of release from the calendar picker or enter it manually.
* **time_of_release**: Select the time of release from the time picker or enter it manually.
* **remarks**: Enter any additional notes or remarks about the release.
* **release_by**: Choose "Yes" if the release is authorized or "No" if it is not.
* **release_date**: Enter the date of release.

## Tips
* Make sure to enter accurate information for each field to ensure that the release is recorded correctly.
* If you are unsure about any of the fields, refer to your warehouse management manual or contact your supervisor for guidance.
* This form is intended for internal use, so please keep the information confidential.
