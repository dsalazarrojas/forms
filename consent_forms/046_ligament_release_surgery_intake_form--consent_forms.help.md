# Ligament Release Surgery Intake Form - Help Guide
## Purpose
This form is designed to collect essential information from patients undergoing ligament release surgery. It includes personal contact details, medical history, and consent for the procedure.

## How To Complete This Form
To complete this form, follow these steps:

1. Please fill in your First Name, Last Name, Email, Phone number, and Date of Surgery in the corresponding fields.
2. Select the Type of Surgery you are having.
3. If you have any Pre-Surgical Test Results, please provide them in the Pre-Surgical Test Results field.
4. If necessary, fill in your Anesthesia, Surgeon, Medical History, Medications, Allergies, and Emergency Contacts information.
5. Please provide your insurance information if applicable.
6. Sign and date your Signature field.
7. Sign and date the Doctor's Signature field (if applicable).
8. Ensure you have read and understood the Consent Statement and Terms and Conditions.
9. Select the corresponding options for Consent Statement and Terms and Conditions.

## Field-by-Field Explanation
* **First Name** (First Name, text, required): Please fill in your first name.
* **Last Name** (Last Name, text, required): Please fill in your last name.
* **Email** (Email, email, required): Please fill in your email address.
* **Phone** (Phone, text, required): Please fill in your phone number.
* **Date of Surgery** (Date of Surgery, date, required): Please fill in the date of your surgery.
* **Type of Surgery** (Type of Surgery, select_one, required): Please select the type of surgery you are having.
* **Pre-Surgical Test Results** (Pre-Surgical Test Results, text, optional): If you have any pre-surgical test results, please provide them here.
* **Anesthesia** (Anesthesia, text, optional): If you have any anesthesia information, please fill it in here.
* **Surgeon** (Surgeon, text, optional): If your surgeon has any specific instructions, please fill them in here.
* **Medical History** (Medical History, note, optional): If you have any medical history, please provide it here.
* **Medications** (Medications, text, optional): If you are taking any medications, please list them here.
* **Allergies** (Allergies, text, optional): If you have any allergies, please list them here.
* **Emergency Contacts** (Emergency Contacts, text, optional): If you have any emergency contacts, please provide their information here.
* **Insurance** (Insurance, text, optional): If you have any insurance information, please provide it here.
* **Signature** (Signature, text, required): Please sign your name to confirm you have read and understood the form.
* **Signature Date** (Signature Date, date, required): Please date your signature.
* **Doctor Signature** (Doctor Signature, text, optional): If your doctor has any comments or instructions, please fill them in here.
* **Doctor Signature Date** (Doctor Signature Date, date, optional): If your doctor signs this form, please date their signature.
* **Doctor Name** (Doctor Name, text, optional): If your doctor's name is not already known to us, please provide it here.
* **Hospital** (Hospital, text, optional): If you have any hospital information, please fill it in here.
* **Room Number** (Room Number, text, optional): If you have any room number, please provide it here.
* **Surgical Team** (Surgical Team, text, optional): If you have any information about the surgical team, please provide it here.
* **Consent Statement** (Consent Statement, select_multiple, required): Please select the corresponding option for the consent statement.
* **Terms and Conditions** (Terms and Conditions, select_one, required): Please select the corresponding option for the terms and conditions.
