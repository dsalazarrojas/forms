# Field Trip Permission Form - Help Guide
## Purpose
This form is used to request permission for a field trip, which can include activities such as visiting museums, zoos, historical sites, or any other off-site educational activity. 

## How To Complete This Form
To fill out the form, please follow these steps:
- Enter the name of the field trip in the field trip name field.
- Choose the type of trip (e.g., school or field trip) using the trip type dropdown menu.
- Input the estimated number of students going on the trip in the student count field.
- Check the parent permission checkbox if you have the approval from all parents for this trip.
- Check the teacher permission checkbox if you, as a teacher, have permission to conduct this trip.
- Select a date for the trip in the date field (mm/dd/yyyy format).
- Choose the time of the trip in the time field (hh:mm AM/PM format).
- Check the school permission checkbox if you have approval from the school administration for this trip.
- Optionally, provide any additional contact information for the trip in the contact field.
- If needed, add any additional notes about the trip in the notes field.

## Field-by-Field Explanation
* **Field Trip Name** (`field_trip_name`, text, optional): Enter the name of the field trip, such as "Visit to the Local Museum".
* **Trip Type** (`trip_type`, select_one, optional): Choose the type of trip from the dropdown menu, e.g., "School Trip" or "Field Trip".
* **Student Count** (`student_count`, number, optional): Enter the estimated number of students going on the trip.
* **Parent Permission** (`parent_permission`, select_one, optional): Check this box if you have approval from all parents for this trip.
* **Teacher Permission** (`teacher_permission`, select_one, optional): Check this box if you have permission to conduct this trip.
* **Date** (`date`, date, optional): Select a date for the trip in the mm/dd/yyyy format.
* **Time** (`time`, time, optional): Choose the time of the trip in the hh:mm AM/PM format.
* **School Permission** (`school_permission`, select_one, optional): Check this box if you have approval from the school administration for this trip.
* **Contact** (`contact`, text, optional): Provide any additional contact information for the trip.
* **Notes** (`notes`, note, optional): Add any additional notes about the trip if needed.
