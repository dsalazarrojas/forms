# Sensor Installation Consent Form - Help Guide
## Purpose
The Sensor Installation Consent Form is used to obtain consent from a contact person before installing a sensor at their location.

## How To Complete This Form
To complete this form, follow these steps:

1.  Select the type of sensor being installed from the options provided.
2.  Enter the contact person's name.
3.  Provide details about the sensor, if necessary.
4.  Enter the address where the sensor will be installed.
5.  Enter the date and time of the installation.
6.  Enter the contact number of the contact person.
7.  Enter the email of the contact person.
8.  Provide a statement indicating you have received the consent of the contact person.

## Field-by-Field Explanation

* **Sensor Type:** Select the type of sensor being installed (e.g., Temperature, Humidity, Pressure, Motion). This is an optional field but is required for the sensor installation process.
* **Contact Person's Name:** Enter the name of the contact person who will be the point of contact for the sensor installation.
* **Sensor Details:** If necessary, provide additional details about the sensor, such as its model number or serial number.
* **Installation Address:** Enter the exact address where the sensor will be installed.
*   <i>Note:</i> Make sure to enter the address correctly to ensure proper installation.
*   <i>Tip:</i> If you're unsure about the address, please contact the contact person for clarification.
* **Installation Date and Time:** Enter the date and time of the installation in the format MM/DD/YYYY HH:MM (e.g., 02/22/2021 14:30).
*   <i>Note:</i> The installation date and time should match the actual date and time of the installation.
* **Contact Number:** Enter the contact number of the contact person for any further communication or questions.
*   <i>Tip:</i> Make sure to enter a valid contact number to ensure proper communication.
* **Email:** Enter the email of the contact person.
*   <i>Note:</i> The contact person's email should be valid and active.
* **Consent:** This field is a statement indicating that you have received the consent of the contact person for the sensor installation. Please check this box and include your name in the text area below to complete this form.
  <i>Note:</i> This is an important step to confirm that the contact person has given their consent.
