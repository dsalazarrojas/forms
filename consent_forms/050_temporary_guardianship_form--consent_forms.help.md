# Temporary Guardianship Form - Help Guide

## Purpose
The purpose of this form is to collect information about a temporary guardianship arrangement, including the temporary guardian's details and the relationship between them and the minor or vulnerable adult.

## How To Complete This Form
1. Select the type of temporary guardian from the options provided.
2. Choose the relationship between the temporary guardian and the minor or vulnerable adult.
3. Enter the start and end dates of the temporary guardianship, if applicable.
4. Enter the address and contact details of the temporary guardian.
5. Complete any other relevant sections as required.

## Field-by-Field Explanation
* **Temporary Guardian** (`form_2`, select_one, required: false):
	+ This field allows you to select the type of temporary guardian, e.g., Mother, Father, or Other.
* **Temporary Guardian 2** (`form_3`, select_multiple, required: false):
	+ This field allows you to select multiple types of temporary guardians, e.g., Mother and Father.
* **Temporary Guardian Type** (`form_4`, select_one, required: false):
	+ This field allows you to select the type of temporary guardianship, e.g., Emergency, Temporary, or Permanent.
* **Temporary Guardian Name** (`form_5`, text, required: false):
	+ This field is for the name of the temporary guardian.
* **Guardian Relationship** (`form_6`, text, required: false):
	+ This field is for the relationship between the temporary guardian and the minor or vulnerable adult.
* **Relationship Start Date** (`form_7`, date, required: false):
	+ This field is for the start date of the temporary guardianship, if applicable.
* **Relationship End Date** (`form_8`, date, required: false):
	+ This field is for the end date of the temporary guardianship, if applicable.
* **Address** (`form_9`, text, required: false):
	+ This field is for the address of the temporary guardian.
* **City** (`form_10`, text, required: false):
	+ This field is for the city of the temporary guardian's address.
* **State** (`form_11`, text, required: false):
	+ This field is for the state of the temporary guardian's address.
* **Zip** (`form_12`, text, required: false):
	+ This field is for the zip code of the temporary guardian's address.
* **Phone** (`form_13`, text, required: false):
	+ This field is for the contact phone number of the temporary guardian.
