# Editable Chemical Peel Consent - Help Guide
## Purpose
This form is used to obtain consent for a chemical peel treatment.

## How To Complete This Form
To complete this form, please follow these steps:
1. Enter your user information, including any relevant contact details.
2. Select the type of chemical peel treatment you are seeking.
3. Choose the type and concentration of the chemical peel solution.
4. Specify the number of passes for the treatment and the duration of each pass.
5. Determine the interval between passes.
6. Select the treatment area to be treated.
7. Choose the chemical peel product to be used.
8. Sign and date the form to confirm your consent.

## Field-by-Field Explanation
- **User Information** (user_information, text, required/optional): Enter your name, contact details, and any other relevant information.
- **Chemical Peel** (chemical_peel, text, required/optional): Briefly describe the chemical peel treatment you are seeking.
- **Type of Treatment** (consent_type, select_one, required): Select the type of chemical peel treatment you are seeking (Chemical Peel or Microdermabrasion).
- **Type of Chemical Peel** (chemical_peel_type, select_one, required): Select the type of chemical peel (Light Peel, Medium Peel, or Deep Peel).
- **Chemical Peel Concentration** (chemical_peel_concentration, select_one, required): Select the concentration of the chemical peel solution (5%, 10%, 15%, or 20%).
- **Number of Passes** (num_passes, select_multiple, required): Select the number of passes for the treatment (1, 2, or 3).
- **Duration of Each Pass** (num_passes_duration, select_multiple, required): Select the duration of each pass (5, 10, or 15).
- **Interval Between Passes** (num_passes_interval, select_multiple, required): Select the interval between passes (7, 14, or 21).
- **Chemical Peel Solution** (chemical_peel_solution, select_one, required): Select the chemical peel solution to be used (Glycolic Acid, Salicylic Acid, or Lactic Acid).
- **Interval Between Passes (minutes)** (num_passes_interval_unit, select_one, required): Select the unit for the interval between passes (minutes, hours, or days).
- **Chemical Peel Product** (chemical_peel_product, select_one, required): Select the chemical peel product to be used (Product A, Product B, or Product C).
- **Treatment Area** (treatment_area, select_one, required): Select the area to be treated (Face, Neck, Back, Chest, Hands, Fingers, Toes, Feet, Ears, or Eyelids).
- **Signature** (signature, note, required/optional): Sign and date the form to confirm your consent.

## Tips
Please ensure that you have read and understood each field carefully before proceeding. If you have any questions or concerns, please reach out to the treatment administrator for assistance.
