# Cross Campus Collaboration Data Consent Form - Help Guide

## Purpose
This form is intended for individuals and teams to provide information and obtain consent for cross-campus collaborations involving data sharing. It is used to capture general information, project details, and participant data.

## How To Complete This Form

To complete this form, follow these steps:

* Enter your general information (page 1) to identify yourself and your contact details.
* Provide project information (page 2) including project title, status, start and end dates, and start and end times.
* Specify sharing consent for the project data (page 3).
* Add any additional information about the project.
* Indicate the number of project participants.
* Choose the project status and select one from the options.
* Enter project lead details: name, email, phone number.
* Identify project collaborators.
* Specify project organisation.
* Add a description of the project.
* Enter project location.
* Provide the project URL.
* Add relevant tags.

## Field-by-Field Explanation

### General Information (Page 1)
* **Name**: Enter your name as it should appear on the form.
* **Email**: Enter your email address.
* **Phone**: Enter your phone number.
* **Contact Details**: Enter any other relevant contact information.

### Project Info (Page 2)
* **Project Title**: Enter the title of the project.
* **Project Status**: Choose one from the options provided.
* **Project Start Date**: Enter the project start date.
* **Project End Date**: Enter the project end date.
* **Project Start Time**: Enter the project start time.
* **Project End Time**: Enter the project end time.

### Sharing Consent (Page 3)
* **Sharing Consent**: Specify whether or not you agree to share project data.

### Contact Details (Page 4)
* **Project Lead Name**: Enter the project lead's name.
* **Project Lead Email**: Enter the project lead's email address.
* **Project Lead Phone**: Enter the project lead's phone number.
* **Project Location**: Enter the location of the project.

### Project Participants (Page 5)
* **Number of Project Participants**: Enter the total number of people involved in the project.

### Additional Information (Page 6)
* **Additional Information**: Add any further details about the project.

### Project Tags (Page 7)
* **Project Tags**: Add relevant tags related to the project.

### Project Lead (Page 8)
* **Project Lead Name**: Enter the name of the project lead.
* **Project Lead Email**: Enter the project lead's email address.
* **Project Lead Phone**: Enter the project lead's phone number.

### Project Collaborators (Page 9)
* **Project Collaborators**: Enter the number of collaborators for the project.

### Project Organisation (Page 10)
* **Project Organisation**: Enter the name of the project organisation.

### Project Description (Page 11)
* **Project Description**: Enter a detailed description of the project.

### Project Location (Page 12)
* **Project Location**: Enter the location of the project.

### Project URL (Page 13)
* **Project URL**: Enter the URL of the project.

### Project Lead (Page 14)
* **Project Lead Name**: Enter the name of the project lead.
* **Project Lead Email**: Enter the project lead's email address.
* **Project Lead Phone**: Enter the project lead's phone number.

### Tips
* Please ensure that all required fields are filled in before submitting the form.
* Review your entries carefully before submitting to avoid errors.
* If you are unsure about any of the fields, please contact your project lead or contact person for clarification.
