# insurance-policy-release-form - Help Guide
## Purpose
This form is used for releasing an insurance policy. Please fill it out thoroughly and accurately to ensure a smooth process.

## How To Complete This Form

1. Fill out each field carefully and accurately, as indicated below.
2. Make sure to sign and date the form once completed.
3. Review and submit the form for processing.

## Field-by-Field Explanation

* **Policyholder Name** (`policyholder_name`, `text`, required)
	+ This field is for the policyholder's name.
* **Policy Number** (`policy_number`, `number`, required)
	+ This field is for the policy number.
* **Policy Start Date** (`policy_start_date`, `date`, required)
	+ This field is for the policy start date.
* **Policy End Date** (`policy_end_date`, `date`, required)
	+ This field is for the policy end date.
* **Release Date** (`release_date`, `date`, required)
	+ This field is for the release date of the policy.
* **Release Time** (`release_time`, `time`, required)
	+ This field is for the release time of the policy.
* **Reason for Release** (`reason_for_release`, `text`, required)
	+ This field is for the reason the policy is being released.
* **Signature** (`signature`, `note`, required)
	+ This field is for the policyholder's or agent's signature.
* **Phone** (`phone`, `text`, required)
	+ This field is for the policyholder's or agent's contact phone number.
* **Email** (`email`, `email`, required)
	+ This field is for the policyholder's or agent's email address.
* **Policy Proofs** (`policy_proofs`, `select_multiple`, required)
	+ Select any applicable policy proofs from the available options.
* **Release By** (`release_by`, `select_one`, required)
	+ Select the individual or entity releasing the policy from the available options.
* **Policy Terms Read** (`policy_terms_read`, `select_one`, required)
	+ Confirm that the policy terms were read.
* **Policy Terms Agreed** (`policy_terms_agreed`, `select_one`, required)
	+ Confirm that the policy terms were agreed upon.
* **Insurance Provider Info** (`insurance_provider_info`, `select_multiple`, required)
	+ Select any applicable insurance provider information from the available options.
* **Policy Type** (`policy_type`, `select_one`, required)
	+ Select the type of policy being released.
* **Policy Status** (`policy_status`, `select_one`, required)
	+ Select the current status of the policy.
* **Policy Comments** (`policy_comments`, `text`, optional)
	+ This field is for any additional comments regarding the policy.
* **Reason for Cancel** (`reason_for_cancel`, `text`, required)
	+ This field is for the reason the policy is being cancelled.
* **Reason for Cancel Other** (`reason_for_cancel_other`, `text`, optional)
	+ This field is for any other reason for cancellation.
* **Issuer Name** (`policy_issuer_name`, `text`, required)
	+ This field is for the issuer's name.
* **Issuer Signature** (`policy_issuer_signature`, `note`, required)
	+ This field is for the issuer's signature.
* **Cancel Date** (`policy_cancel_date`, `date`, optional)
	+ This field is for the cancellation date.
* **Cancel Reason** (`policy_cancel_reason`, `text`, optional)
	+ This field is for the reason of cancellation.
* **Cancel Status** (`policy_cancel_status`, `select_one`, required)
	+ Select the current status of the policy after cancellation.

Note: Ensure all fields are filled out accurately and thoroughly to avoid delays in the policy release process.
