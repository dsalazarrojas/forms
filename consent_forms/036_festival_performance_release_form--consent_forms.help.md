# festival_performance_release_form - Help Guide
## Purpose
This form is used to obtain necessary consents and information from performers for the release of festival performances. Please fill out this form carefully to ensure your consents are recorded correctly.

## How To Complete This Form
1. Click on the "Submit" button to start filling out the form.
2. Enter your name as the performer in the "Performer Name" field.
3. Enter your email address in the "Contact Email" field.
4. Select your response to each consent question:
	* "Recording Consent": Select "Yes" if you allow recordings of your performance. Select "No" if you do not.
	* "Video Consent": Select "Yes" if you allow video recording of your performance. Select "No" if you do not.
	* "Photography Consent": Select "Yes" if you allow photography of your performance. Select "No" if you do not.
	* "Audio Consent": Select "Yes" if you allow audio recording of your performance. Select "No" if you do not.
5. Select your event information:
	* "Event Date" and "Event Start Time" should be in the format "YYYY-MM-DD" and "HH:MM" respectively.
	* "Event Location" is a free-text field where you can enter any relevant location information.
	* "Performance Duration" is the length of your performance in minutes.
6. Select "Media Usage" to indicate whether you allow media usage of your performance. Select "Yes" or "No".
7. Once you have filled out all fields, click the "Submit" button to submit your form.

## Field-by-Field Explanation

* **Performer Name (Performer Name)** (`text`, required): Enter your name as the performer.
* **Contact Email (Contact Email)** (`email`, required): Enter your email address.
* **Recording Consent (Recording Consent)** (`select_multiple`, required): Select "Yes" if you allow recordings of your performance, "No" if you do not.
* **Video Consent (Video Consent)** (`select_multiple`, required): Select "Yes" if you allow video recording of your performance, "No" if you do not.
* **Photography Consent (Photography Consent)** (`select_multiple`, required): Select "Yes" if you allow photography of your performance, "No" if you do not.
* **Audio Consent (Audio Consent)** (`select_multiple`, required): Select "Yes" if you allow audio recording of your performance, "No" if you do not.
* **Media Type (Media Type)** (`select_one`, required): Select "Yes" if you allow media usage of your performance, "No" if you do not.
* **Event Date (Event Date)** (`date`, required): Enter the date of your event in the format "YYYY-MM-DD".
* **Event Start Time (Event Start Time)** (`time`, required): Enter the start time of your event in the format "HH:MM".
* **Event Location (Event Location)** (`text`, required): Enter any relevant location information for your event.
* **Performance Duration (Performance Duration)** (`number`, required): Enter the length of your performance in minutes.
* **Recording Release (Recording Release)** (`text`, required): Enter any additional recording release information.
* **Video Consent (Video Consent)** (`select_multiple`, optional): Select "Yes" if you allow video recording of your performance, "No" if you do not.
* **Photo Consent (Photo Consent)** (`select_multiple`, optional): Select "Yes" if you allow photo recording of your performance, "No" if you do not.

Please note that all fields marked as "required" must be filled out before submitting the form. If you have any questions or concerns, please contact [support email] for assistance.
