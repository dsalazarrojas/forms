# Veterinary Technology Exhibition Media Consent Form - Help Guide
## Purpose
This form is used to collect consent from participants to use their media (photos, videos, audio recordings) for the veterinary technology exhibition. It ensures that participants understand how their media will be used and are comfortable with it.

## How To Complete This Form
1. Please fill out the form carefully and thoroughly.
2. Ensure that you are aware of what each field means and that you have provided the correct information.
3. Review your answers carefully before submitting the form.
4. If you are unsure about any field or have any questions, please contact the exhibition organizers.

## Field-by-Field Explanation
### First Name (required)
* **First Name** (`first_name`, text, required): Please enter your first name as it should be displayed in the exhibition media.

### Email (optional)
* **Email** (`email`, email, optional): Enter your email address so that we can contact you if we need more information or if you have any questions about your media usage.

### Contact Number (required)
* **Contact Number** (`contact_number`, text, required): Enter your contact number so that we can contact you if we need more information or have any questions.

### Media Consent (select multiple)
* **Media Consent** (`consent_media`, select multiple, required): Choose the media you are consenting to use:
	+ Yes: We can use your media for the exhibition.
	+ No: We cannot use your media for the exhibition.

### Photo Consent (select one)
* **Photo Consent** (`photo_consent`, select one, required): Choose if you consent to use your photos in the exhibition:
	+ Yes: We can use your photos.
	+ No: We cannot use your photos.

### Video Consent (select one)
* **Video Consent** (`video_consent`, select one, required): Choose if you consent to use your videos in the exhibition:
	+ Yes: We can use your videos.
	+ No: We cannot use your videos.

### Audio Consent (select one)
* **Audio Consent** (`audio_consent`, select one, required): Choose if you consent to use your audio recordings in the exhibition:
	+ Yes: We can use your audio recordings.
	+ No: We cannot use your audio recordings.

### Other Media (select one)
* **Other Media** (`other_media`, select one, required): Choose if you consent to use any other media not mentioned above (e.g., 3D scans, X-ray images):
	+ Yes: We can use your other media.
	+ No: We cannot use your other media.

### Usage Purpose (select multiple)
* **Usage Purpose** (`usage_purpose`, select multiple, required): Choose the purpose for which you would like your media to be used:
	+ Yes: Education and research.
	+ No: Other (Please specify in the 'Other' field)
