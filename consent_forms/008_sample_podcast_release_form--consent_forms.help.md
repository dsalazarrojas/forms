# Sample Podcast Release Form - Help Guide
## Purpose
This form is a consent form for podcast creators to obtain permission from their guests to release the recording of their episode. It is an original form created using AI and is not affiliated with any form platforms.

## How To Complete This Form
To fill out this form, follow these steps:

1. **Enter your name**: Fill in your name as the guest on the podcast.
2. **Choose a date**: Select the date of the recording or the date you are granting release permission for.
3. **Select a time**: Choose the time of the recording or the time you are granting release permission for.
4. **Upload audio**: You can upload an audio file related to the recording, but this is optional.
5. **Choose an image**: Select the type of image or audio file you are associated with the recording (e.g., Audio file, Video file).
6. **Grant release permission**: Select 'Yes' to grant release permission to the podcast creators to release the recording.

## Field-by-Field Explanation
* **Guest Name**: Your name as the guest on the podcast.
* **Date**: The date of the recording or the date you are granting release permission for. Use the format 'YYYY-MM-DD'.
* **Time**: The time of the recording or the time you are granting release permission for.
* **Audio**: A field to upload an audio file related to the recording, if applicable.
* **Image**: A field to select the type of image or audio file you are associated with the recording (e.g., Audio file, Video file).
* **Release Permission**: A field to select whether you grant release permission to the podcast creators to release the recording.
