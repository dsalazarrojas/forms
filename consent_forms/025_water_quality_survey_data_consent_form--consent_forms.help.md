# Water Quality Survey Data Consent Form - Help Guide
## Purpose
This form is used to collect consents from end users for their data to be collected and stored for the water quality survey.

## How To Complete This Form
- Carefully read through each page of the form, understanding the purpose of each field.
- Answer each field accordingly, making sure to fill in accurate and relevant information.

## Field-by-Field Explanation
- **Water Quality Survey Data Consent Form** (<form_title>):
	* This is the title of the form, which should be filled in with the current date and time.
- **Category** (<category>):
	* Select the correct category for the form, either "Consent Forms" or "Other".
- **Description** (<description>):
	* Provide a brief description of the form and its purpose.
- **Form ID** (<form_id>):
	* Enter the unique identifier for the form, typically a number.
- **Category Label** (<category_label>):
	* Enter a label for the category selected in the "Category" field.
- **Form Description** (<form_description>):
	* Enter a brief description of the form.
- **Assigned Tool** (<assigned_tool>):
	* Select the tool that will be used to collect and store the data.
- **Output File** (<output_file>):
	* Enter the name of the output file that will be generated.
- **Output File Extension** (<output_file_extension>):
	* Enter the file extension for the output file.
- **Form Title** (<form_title>):
	* Enter the title of the form, which will be used as a header for the output file.
