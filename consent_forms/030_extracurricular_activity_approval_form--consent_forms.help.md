# extracurricular_activity_approval_form - Help Guide
## Purpose

The **extracurricular_activity_approval_form** is a form used to collect and track student information and approvals for extracurricular activities. 

## How To Complete This Form

To complete this form, follow these steps:

1. Enter the student's **Student ID** (number) in the corresponding field.
2. Provide the student's name in the **Student Name** field.
3. Enter any relevant **Teacher Info** (text) about the activity, if applicable.
4. Provide details about the **Activity Info** (text) in which the student is participating.
5. Enter any additional **Approval Info** (text) that the teacher or school administration may need to know.
6. Optionally, add any **Parent Comments** (text) from the student's parent or guardian.
7. Include any comments from the **School Admin Comments** (text) field, if necessary.
8. Add any **School Officer Comments** (text), if required.

## Field-by-Field Explanation
* **Student ID** (Student ID, number, optional): Enter the student's unique identifier number.
* **Student Name** (Student Name, text, optional): Enter the student's name.
* **Teacher Info** (Teacher Info, text, optional): Enter any relevant information about the teacher's involvement or approval.
* **Activity Info** (Activity Info, text, optional): Enter details about the activity in which the student is participating.
* **Approval Info** (Approval Info, text, optional): Enter any additional approval information.
* **Parent Comments** (Parent Comments, text, optional): Add any comments from the student's parent or guardian.
* **School Admin Comments** (School Admin Comments, text, optional): Enter any additional comments from the school administration.
* **School Officer Comments** (School Officer Comments, text, optional): Add any comments from the school officer. 

## Tips

* Please make sure to fill out each field accurately and completely.
* Review all fields for completeness before submitting the form.
* Ensure all required fields are filled out.
