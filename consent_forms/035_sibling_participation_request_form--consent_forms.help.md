# Sibling Participation Request Form - Help Guide
## Purpose
The Sibling Participation Request Form is used to gather information about the participant's sibling, which is necessary for making informed decisions about their program or event participation.

## How To Complete This Form
To complete this form, follow these steps:
1. Enter the sibling's first name in the **Sibling First Name** field.
2. Enter the sibling's last name in the **Sibling Last Name** field.
3. Provide the sibling's email address in the **Sibling Email** field.
4. Select the sibling's relationship to the participant from the options provided in the **How does the sibling's relationship to the participant fit this program/event?** field.
5. Indicate if the sibling has attended the same school as the participant in the current year in the **Has the sibling attended the same school as the participant this year?** field.
6. If the sibling has not attended the same school as the participant, provide the school information in the **Other school information** field (optional).
7. Indicate if the sibling has participated in any programs or events with the participant in the **Has the sibling participated in any programs or events with the participant?** field.
8. If the sibling has participated in programs or events, select the number of programs/events they have participated in from the options provided in the **How many programs/events has the sibling participated in with the participant?** field.
9. Provide any additional comments or information about the sibling's participation in the **Additional Comments** field (optional).

## Field-by-Field Explanation

* **Sibling First Name (Sibling First Name, text, required)**: Enter the sibling's first name.
* **Sibling Last Name (Sibling Last Name, text, required)**: Enter the sibling's last name.
* **Sibling Email (Sibling Email, email, required)**: Enter the sibling's email address.
* **How does the sibling's relationship to the participant fit this program/event? (Select One, required)**: Select the sibling's relationship to the participant from the options provided:
	+ Parent/Guardian
	+ Sibling
* **Has the sibling attended the same school as the participant this year? (Select One, required)**: Indicate if the sibling has attended the same school as the participant in the current year.
* **Other school information (Text, optional)**: If the sibling has not attended the same school as the participant, provide the school information.
* **Has the sibling participated in any programs or events with the participant? (Select One, required)**: Indicate if the sibling has participated in any programs or events with the participant.
* **How many programs/events has the sibling participated in with the participant? (Number, required)**: If the sibling has participated in programs or events, select the number of programs/events they have participated in.
* **Additional Comments (Text, optional)**: Provide any additional comments or information about the sibling's participation.
