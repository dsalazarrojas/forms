# Videography Project Submission Permission Form - Help Guide
## Purpose
This form is used to collect information from clients regarding a videography project submission. It's essential to fill out this form accurately to ensure that the project is completed correctly and that all necessary permissions and agreements are in place.

## How To Complete This Form
To complete this form, please follow the steps below:

1. Fill out the required fields with accurate and complete information.
2. Review each field carefully before submitting the form.
3. Make sure to check the box next to "Client Consent" to confirm that you have read and understood the project details and agreements.

## Field-by-Field Explanation

* **Client Name**: Enter the name of the client or company you are working with.
* **Project Title**: Enter a brief title for the project that describes the work to be done.
* **Project Start Date**: Enter the date when the project is expected to start.
* **Project End Date**: Enter the date when the project is expected to end.
* **Location**: Enter the location where the project will take place.
* **Contact Email**: Enter the email address of the client or contact person.
* **Contact Phone**: Enter the phone number of the client or contact person.
* **Client Consent**: Select "Yes" to confirm that you have read and understood the project details and agreements.
* **Project Concerns**: Enter any concerns or issues you have with the project.
* **Videographer Notes**: Enter any additional notes about the project from the videographer.
* **Project Status**: Select the status of the project (Active, Inactive, or Pending).
* **Client Signature Date**: Enter the date of the client's signature.
* **Client Signature**: Sign your name as the client or representative.
* **Videographer Signature**: Sign your name as the videographer.
* **Client Name 2**: Confirm if you are a client or a representative.
* **Project Type**: Select "Yes" if the project is a new project, "No" if it's a repeat project.
* **Videographer Name**: Enter the name of the videographer.
* **Project Start Time**: Enter the start time of the project.
* **Project End Time**: Enter the end time of the project.
* **Client Address**: Enter the address of the client or contact person.
* **Client City**: Enter the city of the client or contact person.
* **Client State**: Enter the state of the client or contact person.
* **Client Zip**: Enter the zip code of the client or contact person.
* **Videographer License**: Enter any relevant license information of the videographer.
* **Videographer Company**: Enter the name of the videographer's company.
* **Tips**: Make sure to review each field carefully before submitting the form to ensure that all necessary permissions and agreements are in place.
