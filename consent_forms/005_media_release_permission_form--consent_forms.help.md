# media_release_permission_form - Help Guide
## Purpose
The Media Release Permission Form is a crucial document that helps establish a legal basis for media-related activities involving participants. It outlines the terms under which participants grant permission for the use of their image, voice, or likeness in media content. By completing this form, participants acknowledge and agree to the conditions set forth, which includes the purpose of the activity, the media to be used, and the rights granted to the media owner.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the **Form Details** section with a brief description of the media release permission form, including the event name, date, and location.
2. Choose the **Participant Details** section to select the type of participant you are obtaining media release permission for (Participant Name, Participant Email, or Participant Phone).
3. In the **Media Details** section, select the type of media that will be used or recorded during the activity (Image, Video, or both).
4. Provide the **Purpose** of the activity or event where the media will be used.
5. Select the **Location** where the activity will take place (On Location or Off Location).
6. Enter the **Signature Date**, which is the date on which the participant signs the form.
7. Enter the **Signature Time**, which is the time on which the participant signs the form.
8. In the **Media Release** section, enter a brief statement explaining the terms of the media release, which will be used as is or slightly modified.
9. If you need to add additional information, you may also provide a **Contact Name**, **Contact Number**, and **Contact Email** for follow-up or communication purposes.

## Field-by-Field Explanation

* **Form Details** (`form_details`): Enter a brief description of the event or activity where the media release permission is being obtained.
* **Participant Details** (`participant_details`): Select the type of participant you are obtaining media release permission for:
	+ Participant Name: Select the name of the participant.
	+ Participant Email: Enter the email address of the participant.
	+ Participant Phone: Enter the phone number of the participant.
* **Media Details** (`media_details`): Select the type of media that will be used or recorded during the activity:
	+ Image: Select this option if images will be taken during the activity.
	+ Video: Select this option if video recording will be made during the activity.
* **Purpose** (`purpose`): Enter the purpose or reason for obtaining media release permission.
* **Location** (`location`): Select the location where the activity will take place:
	+ On Location: The activity will take place at the same location.
	+ Off Location: The activity will not take place at the same location as the participant's name and contact information.
* **Signature Date** (`signature_date`): Enter the date on which the participant signs the form.
* **Signature Time** (`signature_time`): Enter the time on which the participant signs the form.
* **Media Release** (`media_release`): Enter a brief statement explaining the terms of the media release.
* **Contact Name** (`contact_name`): If you want to include a contact person for follow-up or communication purposes, enter their name.
* **Contact Number** (`contact_number`): Enter the phone number of the contact person.
* **Contact Email** (`contact_email`): Enter the email address of the contact person.
* **Media Owner** (`media_owner`): Enter the name of the media owner or the organization responsible for the media content.

## Tips

* Ensure that the participant understands the terms of the media release before obtaining their consent.
* Review the form carefully to ensure that all required fields are filled out correctly.
* Store the signed form for future reference and record keeping purposes.
* Keep the form up to date with any changes to the media release terms.
