# entertainment_sponsorship_mention_consent_form - Help Guide
## Purpose
This form is designed to collect information from event organizers regarding the sponsorship mention consent for entertainment events. It gathers details about the sponsor, the preferred format of mention, and other relevant information.

## How To Complete This Form
To complete this form, follow these steps:

1. Provide sponsor details in the **Sponsor Details** field. This is an optional field.
2. Choose the **Preferred Mention Format** for the sponsorship from the dropdown options.
3. If applicable, provide **Formal Consent** in the **Formal Consent** field. This is also an optional field.
4. Select the type of **Event** from the dropdown options.
5. Enter the **Event Date** if required.
6. Provide additional **Show Details** in the optional text field.

## Field-by-Field Explanation
* **Sponsor Details** (`sponsor_details`, text, optional): Enter the name and contact information of the sponsor.
* **Preferred Mention Format** (`mention_format`, select_multiple, optional): Choose how you want the sponsorship to be mentioned, such as Format 1, Format 2, or Format 3.
* **Formal Consent** (`consent`, note, optional): Provide a formal consent or agreement from the sponsor.
* **Event Type** (`event_type`, select_one, optional): Select the type of event, such as Event A, Event B, Event C, or Event D.
* **Event Date** (`event_date`, date, optional): Enter the date of the event if required.
* **Show Details** (`show_details`, text, optional): Enter any additional details about the event.
