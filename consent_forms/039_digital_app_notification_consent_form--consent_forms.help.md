# digital_app_notification_consent_form - Help Guide
## Purpose
The digital app notification consent form is designed to collect user's consent to receive notifications and updates from the digital app. This form is used to understand the user's preferences for communication and ensure that they are informed about any updates or notifications.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in your **full name** in the field labeled "full_name". This is a required field and must be completed.
2. Enter your **email** address in the field labeled "email". This is a required field and must be completed.
3. Provide your **phone number** in the field labeled "phone_number". This is a required field and must be completed.
4. Select the notification channels you would like to receive updates from in the field labeled "notification_channels". You can select multiple channels such as Email, SMS, Phone, and WhatsApp.
5. If you want to receive updates, select **yes** in the field labeled "explicit_consent". If you do not want to receive updates, select **no**.
6. If you have a preferred contact number, enter it in the field labeled "contact_number". This is an optional field.
7. If you have a preferred contact frequency, enter it in the field labeled "contact_frequency". This is an optional field.
8. Select the contact channels you would like to use for contact in the field labeled "contact_channels". You can select multiple channels such as Email, SMS, Phone, and WhatsApp.

## Field-by-Field Explanation

* **full_name** (`full_name`, `text`, required):
	+ This is the field to fill in your full name.
* **email** (`email`, `email`, required):
	+ Enter your email address to receive notifications and updates from the digital app.
* **phone_number** (`phone_number`, `text`, required):
	+ Enter your phone number to receive phone notifications.
* **notification_channels** (`notification_channels`, `select_multiple`, required):
	+ Select the notification channels you would like to receive updates from. You can select multiple channels.
* **how_often** (`notification_frequency`, `number`, optional):
	+ This field is not required, but if you want to specify how often you would like to receive updates, fill it in. Note that this field is optional.
* **explicit_consent** (`explicit_consent`, `select_one`, required):
	+ Select **yes** to give explicit consent to receive notifications and updates, or **no** to decline.
* **preferred_contact_number** (`contact_number`, `text`, optional):
	+ If you have a preferred contact number, enter it here. This is an optional field.
* **preferred_contact_frequency** (`contact_frequency`, `text`, optional):
	+ If you have a preferred contact frequency, enter it here. This is an optional field.
* **contact_channels** (`contact_channels`, `select_multiple`, required):
	+ Select the contact channels you would like to use for contact. You can select multiple channels.
