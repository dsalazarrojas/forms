# Treasury Analysis Publication Consent Form - Help Guide
## Purpose
The Treasury Analysis Publication Consent Form is used to obtain consent from individuals before publishing their treasury analysis data. This form is a legal document that ensures the individuals understand their rights and responsibilities related to the data they are providing.
## How To Complete This Form
To complete the form, follow these steps:
1. Fill out the required fields with accurate information.
2. Review the form carefully before submitting it.
3. If you are unsure about any field, seek guidance from an authorized person.
## Field-by-Field Explanation
- **User Name**: This is a required field where you should enter your full name. Please enter your name as it appears on your identification documents.
  * Type: `text`
  * Required: `true`
  * Hint: `User Name`
- **User Email**: This is a required field where you should enter your official email address. Please ensure it is accurate and up-to-date.
  * Type: `email`
  * Required: `true`
  * Hint: `null`
- **Project Title**: This is an optional field where you can enter the title of the project related to the data. Please enter a brief description of the project.
  * Type: `text`
  * Required: `false`
  * Hint: `Project Title`
- **Department**: In this field, please select all departments that the data relates to. If no department is applicable, select 'No'.
  * Type: `select_multiple`
  * Required: `true`
  * Hint: `null`
- **Role**: Please select your role in the project or department.
  * Type: `select_one`
  * Required: `true`
  * Hint: `Role`
- **Date of Consent**: This is a required field where you should enter the date you are providing consent for publication.
  * Type: `date`
  * Required: `true`
  * Hint: `null`
- **Consent**: Please indicate whether you give consent for publication of your data. Please select 'True' if you agree to publication.
  * Type: `select_one`
  * Required: `true`
  * Hint: `null`
- **Notes**: This is an optional field where you can enter any additional information or comments related to your consent.
  * Type: `note`
  * Required: `false`
  * Hint: `null`
- **Signature**: This is an optional field where you should enter your signature. Please sign with your name.
  * Type: `text`
  * Required: `false`
  * Hint: `null`
- **Date Signed**: This is an optional field where you should enter the date you signed the form.
  * Type: `date`
  * Required: `false`
  * Hint: `null`
- **Signature Image**: This is an optional field where you can upload a scanned copy of your signature.
  * Type: `text`
  * Required: `false`
  * Hint: `null`
- **File Attachment**: This is an optional field where you can attach a file related to the data.
  * Type: `text`
  * Required: `false`
  * Hint: `null`
- **File Type**: This is an optional field where you should select the type of file you attached.
  * Type: `select_one`
  * Required: `false`
  * Hint: `null`
- **Department Agreed**: Please select whether your department has agreed to publish your data.
  * Type: `select_one`
  * Required: `false`
  * Hint: `null`
