# Secure Information Submission Form - Help Guide
## Purpose
The Secure Information Submission Form is designed to collect sensitive and confidential information from users in a secure and controlled environment. This form ensures that all submitted data is handled with the utmost care and in accordance with relevant regulations.

## How To Complete This Form

To complete this form, please follow these steps:

1. **Form Submission Details**: This section is for general information about the submission.
2. **Form Title**: Enter a brief title for the form, if desired.
3. **Form Description**: Provide a short description of the form.
4. **Form Category**: Select the category that best suits your form.
5. **Document Uploads**: You can upload multiple documents related to your submission.
6. **Document 1**: Select the first document you'd like to upload.
7. **Document 2**: Select the second document you'd like to upload.
8. **Form Notes**: Add any additional information you'd like to include with your submission.
9. **Comments**: Provide any comments or feedback about your submission.

## Field-by-Field Explanation

### Form Submission Details
* **Form Submission Details (text)**: Enter a brief description of the form submission. This field is not required.

### Form Title
* **Form Title (text)**: Enter a brief title for the form, if desired. This field is not required.

### Form Description
* **Form Description (text)**: Provide a short description of the form. This field is not required.

### Form Category
* **Form Category (text)**: Select the category that best suits your form. This field is not required.

### Document Uploads
* **Document Uploads (text)**: Upload multiple documents related to your submission. You can add multiple documents, but each document should be a different type. This field is not required.

### Document 1
* **Document 1 (text)**: Select the first document you'd like to upload. This field is not required.

### Document 2
* **Document 2 (text)**: Select the second document you'd like to upload. This field is not required.

### Form Notes
* **Form Notes (note)**: Add any additional information you'd like to include with your submission. This field is not required.

### Comments
* **Comments (text)**: Provide any comments or feedback about your submission. This field is not required.

## Tips

* Make sure to fill out all required fields before submitting the form.
* Use clear and concise language when filling out the form.
* If you're unsure about any field, please contact our support team for guidance.
* You can upload multiple documents, but each document should be a different type.
