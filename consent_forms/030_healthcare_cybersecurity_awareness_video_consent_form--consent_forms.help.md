# Healthcare Cybersecurity Awareness Video Consent Form - Help Guide
## Purpose
This form is used to collect user consent for viewing healthcare cybersecurity awareness videos. It is essential to document and record user consent for training videos related to healthcare cybersecurity.

## How To Complete This Form
1. Select "Yes" or "No" for "Video Consent" to indicate whether you have watched or wish to watch the video.
2. If necessary, enter your "User Name" and "Contact Email" to provide additional information.
3. Choose "Yes" or "No" for "Consent Status" to indicate your current consent status.
4. Fill out any other required or optional fields as necessary.

## Field-by-Field Explanation
* **Video Consent**: Select "Yes" or "No" to indicate whether you have watched or wish to watch the video.
* **User Name**: Enter your name if you wish to provide additional information.
* **Contact Email**: Enter your email address if you wish to provide additional information.
* **Date of Consent**: The date when you provided consent.
* **Consent Status**: Choose "Yes" or "No" to indicate your current consent status.
* **Project Name**: Enter project name if it is relevant.
* **Training Video Prophets**: Select which video(s) you have viewed.
* **Video File**, **Video Length Minutes**, **Video Title**, **Video URL**, **Video Description**, **Video Provider**, **Video Length**: Fill out any of these fields if you wish to provide additional video information.
* **Video Provider 2**, **Video URL 2**, **Video Length Minutes 2**: Fill out these fields if you wish to provide additional video information for second video.
* **Consent Status Date** and **Consent Status Time**: Enter dates and times for when you last updated your consent status.
* **Video Url 2**, **Video Provider 2**: Fill out these fields if you wish to provide additional video information for second video.
* **Video Length Minutes 2**: Enter length of the second video.
* **Video File 2**: Enter video file for second video.
* **Video Description 2**: Enter description of second video.
* **Video Length**: Enter length of the video.
* **Video Format**: Enter video format.
* **Consent Status Date**: The date when you last updated your consent status.
* **Consent Status Time**: The time when you last updated your consent status.
* **Video Url 2**: Enter URL of second video.
* **Video Provider 2**: Enter provider of second video.
* **Video Length Minutes 2**: Enter length of second video.
* **Video File 2**: Enter file of second video.
* **Video Description 2**: Enter description of second video.

## Tips
* Please make sure to select "Yes" for "Video Consent" to indicate that you have watched or wish to watch the video.
* Make sure to fill out any required fields.
* If you are unsure about any field, please contact the project team for assistance.
* Please review all fields carefully before submitting the form to ensure accuracy.
* If you have any issues or concerns, please reach out to the project team.
