# Pet Care Service Agreement - Help Guide
## Purpose
This form is used to capture information from pet owners regarding pet care services, including services provided, service details, start and end dates, and signatures from both the client and the veterinarian.

## How To Complete This Form
1. Please select the services you would like to have provided for your pet (Bathing, Feeding, Medication Administration).
2. Provide details about the services you would like to have performed (e.g., frequency, duration).
3. Choose a start date for the services (format: yyyy-mm-dd).
4. Choose an end date for the services (format: yyyy-mm-dd).
5. Print your signature below to acknowledge that you have read, understood, and agreed to the services provided.

## Field-by-Field Explanation
* **Services Provided** (`services_provided`, `select_multiple`, required): Select all the services you would like to have provided for your pet (e.g., bathing, feeding, medication administration).
* **Service Details** (`service_details`, `text`, optional): Provide more information about the services you would like to have performed (e.g., frequency, duration).
* **Service Start Date** (`service_start_date`, `date`, required): Choose a start date for the services (format: yyyy-mm-dd).
* **Service End Date** (`service_end_date`, `date`, required): Choose an end date for the services (format: yyyy-mm-dd).
* **Client Signature** (`client_signature`, `note`, required): Print your signature below to acknowledge that you have read, understood, and agreed to the services provided.
* **Veterinarian Signature** (`veterinarian_signature`, `note`, required): Print the veterinarian's signature below to acknowledge that they have read, understood, and agreed to the services provided.
* **Business Terms** (`business_terms`, `text`, optional): If you have any questions or concerns about our business terms, please write them here.
* **Contact Details** (`contact_details`, `text`, optional): Please provide any additional contact information if you need to be reached for further questions or concerns.

## Tips
* Please ensure that you have read and understood all the services provided before signing below.
* Make sure to provide accurate start and end dates for the services.
* Both the client and the veterinarian must sign below to confirm agreement.
