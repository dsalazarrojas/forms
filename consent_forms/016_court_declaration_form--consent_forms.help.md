# court-declaration-form - Help Guide
## Purpose
This form is used to collect information for a court declaration.

## How To Complete This Form
To complete this form, follow these steps:

1.  Review the form purpose and ensure you have all the required information.
2.  Fill in the **Form ID** field with the ID of the form being used for the declaration.
3.  Select the tool that was assigned to the form from the **Assigned Tool** dropdown menu.
4.  Enter your **User Name** and **User Email** accurately.
5.  Add a **Description** of the declaration if necessary.
6.  Select the **Category** of the declaration from the dropdown menu.
7.  If required, select a **Subcategory** and add any additional **Notes**.

## Field-by-Field Explanation

*   **Form ID** (`form_id`, number, required: false): A unique identifier for the form being used for the declaration. Enter a number to identify the form accurately.
*   **Assigned Tool** (`assigned_tool`, select_multiple, required: false): Select the tool assigned to the form from the provided options.
*   **User Name** (`user_name`, text, required: false): Enter your name accurately as it will be used for the declaration.
*   **User Email** (`user_email`, email, required: false): Enter your email accurately as it will be used for the declaration.
*   **Description** (`description`, text, required: false): Add a brief description of the declaration if necessary.
*   **Category** (`category`, select_one, required: true): Select the category of the declaration from the provided options. This helps in organizing and managing declarations accurately.
*   **Subcategory** (`subcategory`, text, required: false): If required by the category, select a subcategory for the declaration.
*   **Notes** (`notes`, note, required: false): Add any additional notes for the declaration.

**Tips:** Ensure that all fields are filled accurately to avoid any delays or issues in the declaration process. If unsure about any field, please reach out to the relevant authorities for assistance.
