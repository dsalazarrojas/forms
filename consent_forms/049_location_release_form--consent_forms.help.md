# Location Release Form - Help Guide
## Purpose
The Location Release Form is used to collect information from individuals who want to release their locations for use by others. This form helps us understand the details of the release, such as the location's name, contact information, and release specifics.

## How To Complete This Form
To complete this form, follow these steps:
1. Fill out the Location Name field with the official name of the location.
2. Enter the contact person's name in the Contact Name field.
3. Provide the contact person's email address in the Contact Email field.
4. Enter the contact person's phone number in the Contact Phone field.
5. Enter the address of the location in the Location Address field.
6. Select the Type of Release from the available options (Location Usage Rights, Equipment Usage Rights, or Talent Usage Rights).
7. Choose the Release Date for the location.
8. Enter the start and end times for the duration of the release in the Duration Start and Duration End fields.
9. Add any Release Notes that are relevant to the location.

## Field-by-Field Explanation
- **Location Name** (`location_name`, text, required): Enter the official name of the location.
- **Contact Name** (`contact_name`, text, required): Enter the name of the contact person.
- **Contact Email** (`contact_email`, email, required): Enter the email address of the contact person.
- **Contact Phone** (`contact_phone`, text, required): Enter the phone number of the contact person.
- **Location Address** (`location_address`, text, optional): Enter the address of the location.
- **Type of Release** (`release_type`, select_multiple, required): Select the type of release (Location Usage Rights, Equipment Usage Rights, or Talent Usage Rights).
- **Release Date** (`release_date`, date, required): Choose the date for the release of the location.
- **Duration Start** (`duration_start`, time, optional): Enter the start time for the duration of the release.
- **Duration End** (`duration_end`, time, optional): Enter the end time for the duration of the release.
- **Release Notes** (`notes`, note, optional): Add any additional notes relevant to the location release.

## Tips
* Ensure that all required fields are filled out accurately.
* Double-check the Release Date to ensure it aligns with the project timeline.
* If you have any questions or concerns, reach out to the contact person provided.
