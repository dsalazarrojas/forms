# Menu Planning Consent Form - Help Guide
## Purpose
This form is designed to obtain consent from participants for specific menu items, such as dietary restrictions and food allergies, to ensure their well-being and safety during menu planning.

## How To Complete This Form
To complete this form, follow these steps:

1. **Participant Name**: Please enter your name as the participant.
2. **Email**: Enter your email address for contact purposes.
3. **Phone Number**: Provide your phone number if you'd like to be contacted for any additional information.
4. **Dietary Restrictions**: Select all the dietary restrictions that apply to you (Yes/No).
	* This field is for selecting dietary restrictions, such as vegetarian, gluten-free, dairy-free, nut-free, etc.
5. **Food Allergies**: Select all the food allergies that apply to you (Yes/No).
	* This field is for selecting food allergies, such as shellfish, soy, etc.
6. **Vegetarian**: Please select if you follow a vegetarian diet (Yes/No).
7. **Gluten Free**: Please select if you require gluten-free options (Yes/No).
8. **Dairy Free**: Please select if you require dairy-free options (Yes/No).
9. **Nut Free**: Please select if you require nut-free options (Yes/No).
10. **Soy Free**: Please select if you require soy-free options (Yes/No).
11. **Shellfish Free**: Please select if you require shellfish-free options (Yes/No).
12. **Shellfish**: Please select if you are shellfish (Yes/No).
13. **Participant Diet**: Please select your participant diet type (Yes/No).
14. **Participant Note**: Please enter any additional notes about your dietary requirements.
15. **Planner Name**: This field is for the planner to fill out, not participants.
