# Building Inspection Entry Consent Form - Help Guide
## Purpose
This form is used to gather consent from the property owner or authorized representative for a building inspection.

## How To Complete This Form

1. Ensure that you have the authority to complete this form and that the inspection is scheduled.
2. Complete the form fields according to the instructions provided below.

## Field-by-Field Explanation

* **Property Owner Name** (`property_owner`): Enter the full name of the property owner or authorized representative.
	+ Type: Text
	+ Required: Yes
* **Owner Email** (`owner_email`): Enter the email address of the property owner or authorized representative.
	+ Type: Email
	+ Required: Yes
* **Owner Phone** (`owner_phone`): Enter the phone number of the property owner or authorized representative.
	+ Type: Text
	+ Required: Yes
* **Consent Date** (`consent_date`): Enter the date on which you are giving consent for the inspection.
	+ Type: Date
	+ Required: Yes
* **Property Address** (`property_address`): Enter the full address of the property.
	+ Type: Text
	+ Required: Yes
* **Unit Number** (`unit_number`): If the property is a multi-unit building, enter the unit number if applicable.
	+ Type: Text
	+ Required: No
* **Property Type** (`property_type`): Select the classification of the property (e.g., Single Family Home, Apartment, etc.).
	+ Type: Select One
	+ Required: Yes
* **Tenant Name** (`tenant_name`): If the property is occupied by a tenant, enter their name.
	+ Type: Text
	+ Required: No
* **Tenant Contact** (`tenant_contact`): If the property is occupied by a tenant, enter their phone or email.
	+ Type: Text
	+ Required: No
* **Inspector Name** (`inspector_name`): Enter the name of the inspector performing the inspection.
	+ Type: Text
	+ Required: Yes
* **Inspector Company** (`inspector_company`): Enter the name of the inspection company or agency.
	+ Type: Text
	+ Required: Yes
* **Inspector License Number** (`inspector_license`): Enter the license or certification number of the inspector.
	+ Type: Text
	+ Required: Yes
* **Inspection Type** (`inspection_type`): Select the purpose of the inspection (e.g., Routine, Pre-Purchase, etc.).
	+ Type: Select One
	+ Required: Yes
* **Inspection Description** (`inspection_description`): Describe the purpose and scope of the inspection.
	+ Type: Text
	+ Required: Yes
* **Scheduled Inspection Date** (`scheduled_date`): Enter the date on which the inspection is scheduled to occur.
	+ Type: Date
	+ Required: Yes
* **Scheduled Time** (`scheduled_time`): Enter the expected time of the inspection.
	+ Type: Time
	+ Required: Yes
* **Estimated Duration** (`estimated_duration`): Select the estimated duration of the inspection (e.g., Less than 1 hour, 1-2 hours, etc.).
	+ Type: Select One
	+ Required: Yes
* **Areas to Inspect** (`areas_to_inspect`): Select all areas of the property that will be inspected (e.g., Exterior, Interior, etc.).
	+ Type: Select Multiple
	+ Required: Yes
* **Special Access Needed** (`special_access_needed`): If any special access is required (e.g., locked areas), enter details.
	+ Type: Text
	+ Required: No
* **Pets on Property** (`pets_on_property`): Indicate if there are pets on the property.
	+ Type: Select One
	+ Required: Yes
* **Occupancy During Inspection** (`occupancy_during_inspection`): Indicate if anyone will be home during the inspection.
	+ Type: Select One
	+ Required: Yes
* **Entry Method** (`entry_method`): Select how the inspector will enter the property (e.g., Owner Will Be Present, Lockbox, etc.).
	+ Type: Select One
	+ Required: Yes
* **Photo Consent** (`photo_consent`): Indicate if photos will be taken during the inspection.
	+ Type: Select One
	+ Required: Yes
* **Damage Liability Acknowledgment** (`damage_liability`): Confirm that the inspector is not liable for pre-existing damage.
	+ Type: Select One
	+ Required: Yes
* **Privacy Agreement** (`privacy_agreement`): Confirm that the inspector will respect the property's privacy.
	+ Type: Select One
	+ Required: Yes
* **Consent Valid Until** (`consent_valid_until`): Enter the expiration date of the consent (if applicable).
	+ Type: Date
	+ Required: No
* **Consent Acknowledgment** (`consent_signature`): Confirm that you consent to the inspection.
	+ Type: Select One
	+ Required: Yes

## Tips

* Ensure that all fields are completed accurately and truthfully.
* Review the form carefully before submitting it.
* If you have any questions or concerns, contact the inspection company or authority.
* The inspection will be conducted according to the information provided in this form.
* The inspector will respect the property's privacy and will not disclose any information without consent.
* The inspection report will be provided after the inspection has been completed.
