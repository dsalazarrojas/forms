# Anesthesia Procedure Checklist - Help Guide
## Purpose
The Anesthesia Procedure Checklist is a form used to record and verify the necessary steps for patient safety before an anesthetic procedure can take place. It ensures that critical details and assessments are accurately documented.

## How To Complete This Form
1. Fill out the form with accurate information.
2. Ensure all required fields are filled out.
3. Complete the select options with the correct choices.

## Field-by-Field Explanation

* **Patient Full Name** (`patient_name`, text, required): Enter the full name of the patient.
* **Medical Record Number (MRN)** (`medical_record_number`, text, required): Enter the patient's Medical Record Number.
* **Attending Anesthesiologist** (`attending_anesthesiologist`, text, required): Enter the name of the attending anesthesiologist.
* **Pre-Op Confirmation** (`section_preop_confirmation`, note, required): This section provides a space for the anesthesiologist to confirm they have reviewed the patient's pre-anesthetic procedure checklist.
* **Anesthesia Consent Form Signed?** (`consent_form_signed`, select_one, required): Select 'True' if the patient's anesthesia consent form has been signed, 'False' otherwise.
* **NPO Status Verified?** (`npo_status_verified`, select_one, required): Select 'True' if the patient's NPO (Nothing by Mouth) status has been verified, 'False' otherwise.
* **Airway Assessment Result (Mallampati Score)** (`airway_assessment_completed`, select_one, required): Select the Mallampati Score for the patient's airway assessment.
* **Patient Safety --** (`section_patient_safety`, note, required): This section provides a space for the anesthesiologist to review patient safety concerns.
* **Identity Verification Steps Completed** (`identity_verification_steps`, select_multiple, required): Select all that apply:
	+ Name Acknowledged
	+ DOB Confirmed
	+ Wristband Checked
	+ Procedure Site Marked
* **Dental Status Checked** (`dental_status_checked`, select_one, required): Select Loose Teeth, Caps / Crowns, or No Issues.
* **IV Access Successfully Established?** (`iv_access_established`, select_one, required): Select 'True' if IV access has been successfully established, 'False' otherwise.
* **Special Anesthetic Concerns or Alerts** (`special_anesthetic_concerns`, text, required): Record any special anesthetic concerns or alerts.
* **Checklist Completion Date and Time** (`checklist_completion_date`, text, required): Enter the date and time the checklist was completed.
* **Verified By (Initials)** (`verified_by_initials`, text, required): Enter the initials of the person verifying the information.

**Tips:**

* Always complete this form accurately and thoroughly.
* Ensure that all required fields are filled out.
* If you're unsure about any information, please review with the patient or consult with the attending anesthesiologist.
