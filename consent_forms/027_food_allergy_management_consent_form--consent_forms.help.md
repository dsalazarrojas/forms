# Food Allergy Management Consent Form - Help Guide
## Purpose
The Food Allergy Management Consent Form is designed to gather essential information about a student's food allergies, medical conditions, and emergency contact details. This guide will walk you through each section of the form to help you complete it accurately and efficiently.

## How To Complete This Form

### General Instructions
To complete this form, please answer each section carefully and thoroughly. If you're unsure about any question or section, please consult with the student's parents or healthcare professionals.

## Field-by-Field Explanation
### Page 1: Patient Info
* **Patient Info** (`patient_info`, text, optional): Enter the student's name, DOB (Date of Birth), and any other relevant medical history.
* **Emergency Contact** (`emergency_contact`, text, optional): Provide the contact information for the student's emergency contact person.
### Page 2: Allergy Status
* **Allergy Status** (`allergy_status`, text, optional): Describe the student's allergy status, including any medical conditions that may affect their allergy treatment.
### Page 3: Consent Type
* **Consent Type** (`consent_type`, select one, optional): Select one of the following options:
	+ Emergency: This is an emergency situation where immediate medical attention is required.
	+ Non-Emergency: This is a non-emergency situation where the student's allergy is not severe.
	+ Both: This is both an emergency and non-emergency situation.
### Page 4: Emergency Medication
* **Emergency Medication** (`emergency_medication`, text, optional): List any emergency medication that the student may require in case of an allergic reaction.
### Page 5: Allergy Info
* **Allergy Info** (`allergy_info`, text, optional): Provide any additional information about the student's allergies.
### Page 6: Medication List
* **Medication List** (`medication_list`, text, optional): List any medications the student is currently taking that may affect their allergy treatment.
### Page 7: Treatment Status
* **Treatment Status** (`treatment_status`, select one, optional): Select one of the following options:
	+ Allergist: The student has an allergist.
	+ ER: The student requires emergency medical attention.
	+ Both: The student has both an allergist and requires emergency medical attention.
### Page 8: School or Camp Info
* **School or Camp Name** (`school_camp_name`, text, optional): Enter the name of the school or camp the student attends.
* **School or Camp Phone** (`school_camp_phone`, text, optional): Enter the phone number of the school or camp.
* **School or Camp Email** (`school_camp_email`, email, optional): Enter the email address of the school or camp.
### Page 9: Student Allergist
* **Student Allergist** (`student_allergist`, text, optional): Provide the name of the student's allergist.
### Page 10: Student Info
* **Student Name** (`student_name`, text, optional): Enter the student's name.
* **Student DOB** (`student_dob`, date, optional): Enter the student's date of birth.
### Page 11: Emergency Contact Info
* **Emergency Contact** (`emergency_contact`, text, optional): Provide the contact information for the student's emergency contact person.
* **Contact Phone** (`contact_phone`, text, optional): Enter the phone number of the student's emergency contact person.
* **Relationship** (`contact_relationship`, select one, optional): Select one of the following options:
	+ Parent
	+ Guardian
	+ Other
* **Contact Info** (`contact_info`, text, optional): Enter any additional information about the student's emergency contact person.
### Page 12: Student Medical Notes
* **Student Medical Notes** (`student_medical_notes`, text, optional): Provide any medical notes or information about the student.
### Page 13: Medical Notes
* **Medical Notes** (`medical_notes`, text, optional): Provide any medical notes or information about the student.
### Page 14: Food Allergies
* **Food Allergies** (`food_allergies`, select multiple, optional): Select all the food allergens that apply to the student:
	+ Milk
	+ Eggs
	+ Peanuts
	+ Wheat
	+ Fish
	+ Soy
	+ Tree Nuts
	+ Shellfish
	+ Sesame
### Page 15: Food Intolerances
* **Food Intolerances** (`food_intolerances`, text, optional): List any food intolerances the student may have.
### Page 16: Emergency Medication Administration
* **Emergency Medication Administration** (`emergency_medication_administration`, select one, optional): Select one of the following options:
	+ By a healthcare professional
	+ By a non-healthcare professional
	+ Not at all
### Page 17: Medical Conditions
* **Medical Conditions** (`medical_conditions`, text, optional): List any medical conditions the student may have.
### Page 18: Medical Procedures
* **Medical Procedures** (`medical_procedures`, text, optional): List any medical procedures the student may have undergone.
### Page 19: Consent Signed
* **Consent Signed** (`consent_signed`, select multiple, optional): Select one of the following options:
	+ True
	+ False
	+ Partially Signed

### Tips
* Please review each section carefully before submitting the form.
* Ensure that you've answered all questions accurately and completely.
* If you're unsure about any question or section, please consult with the student's parents or healthcare professionals.
* Please keep the form confidential and do not share it with anyone without the student's consent.
