# Daycare Transportation Form - Help Guide
## Purpose
This form is used to provide information for daycare transportation, including pick up and drop off locations, transportation method, and pick up time. This helps our daycare staff to organize and manage transportation requests efficiently.

## How To Complete This Form
1. Fill in the pick-up location where you want to be picked up from.
2. Enter the drop-off location where you need to be dropped off at.
3. Choose one or more transportation methods from the list (Taxi, Bus, Train, or Other).
4. Select the pick-up time for the transportation request.
5. Enter the name of the parent responsible for picking up the child at the pick-up location.
6. Provide the phone number of the parent or contact person for further communication.

## Field-by-Field Explanation

* **Pick up location** (`pick_up_location`, text, required: false): Enter the address or specific location where you want to be picked up from.
* **Drop off location** (`drop_off_location`, text, required: false): Enter the address or specific location where you need to be dropped off at.
* **Transportation method** (`transportation_method`, select multiple, required: false): Choose one or more of the following transportation methods: Taxi, Bus, Train, or Other.
* **Pick up time** (`transportation_time`, time, required: false): Select the time when you would like to be picked up.
* **Pick up parent** (`pick_up_parent`, text, required: false): Enter the name of the parent or guardian who will be picking up the child at the pick-up location.
* **Contact number** (`contact_number`, text, required: false): Enter the phone number of the parent or contact person for further communication.
