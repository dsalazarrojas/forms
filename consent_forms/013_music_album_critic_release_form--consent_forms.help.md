# Music Album Critic Release Form - Help Guide
## Purpose
This form is used to collect feedback on released music albums, ensuring that all necessary information is collected for publication.

## How To Complete This Form
To complete this form, follow these steps:

1. Provide the album name in the `album_name` field.
2. Rate the album using the `rating` field. You can choose from 1 to 5 stars.
3. Write a review in the `review` field.
4. Select the publication status of the album using the `publication_status` field. You can choose from Published, Unpublished, or Awaiting.
5. Choose the critical ratings using the `critic_rating` field. You can select multiple ratings from 5 stars, 4 stars, 3 stars, 2 stars, or 1 star.
6. Select the publication date and time using the `publication_date` and `publication_time` fields, respectively.
7. If necessary, add any additional publication notes in the `publication_notes` field.

## Field-by-Field Explanation
* **Music Album Critic Release Form**: This is the title of the form.
* **album_name**: Provide the name of the album you are reviewing.
* **rating**: Rate the album from 1 to 5 stars.
* **review**: Write a critical review of the album.
* **publication_ready**: Note: This field is likely intended to indicate whether the album is ready for publication, but it's not currently used in the form. (Please ignore)
* **publication_date**: Select the date of publication.
* **publication_time**: Select the time of publication.
* **publication_status**: Select the status of the album, which can be Published, Unpublished, or Awaiting.
* **critic_rating**: Select the critic's rating of the album from 1 to 5 stars.
* **review_date**: This field is currently not used, so please ignore.
* **email**: This field is intended for contact information, but it's not currently used in the form. (Please ignore)
* **phone**: This field is also intended for contact information, but it's not currently used in the form. (Please ignore)
* **publication_notes**: Add any additional notes about the publication of the album.
* **critic_name**: This field is not currently used, so please ignore.
* **publication_notes**: Add any additional notes about the publication of the album.
