# playwright_script_reproduction_release_form - Help Guide
## Purpose

This form is used to gather information and obtain permissions for the reproduction and release of a script. It's essential to fill out this form accurately and completely to ensure the reproduction and release process is done correctly.

## How To Complete This Form

1. Fill out the form in the following order:
   - Start with the script details (Script Name, Script Type, Production Company, and Production Organization).
   - Move on to the production information (Production Date, Script Reproduction Permission, Performance Permission, and Script Reproduction Purpose).
   - Provide contact details (Contact Name, Contact Email, Contact Phone, and Contact Notes).
   - Add any Additional Information and sign the form.

## Field-by-Field Explanation

### 1. Script Name
* **Script Name**: `script_name` (`text`, required: false)
  Enter the name of the script being reproduced.

### 2. Script Type
* **Script Type**: `script_type` (`text`, required: false)
  Specify the type of script (e.g., movie, TV show, etc.).

### 3. Production Company
* **Production Company**: `production_company` (`text`, required: false)
  Enter the name of the production company that produced the script.

### 4. Production Organization
* **Production Organization**: `production_organization` (`text`, required: false)
  Specify the name of the production organization that handled the script production.

### 5. Production Date
* **Production Date**: `production_date` (`date`, required: false)
  Enter the date of production (YYYY-MM-DD format).

### 6. Script Reproduction Permission
* **Script Reproduction Permission**: `script_reproduction_permission` (`select_multiple`, required: false)
  Confirm if you have reproduction permission for the script (True or False).

### 7. Performance Permission
* **Performance Permission**: `performance_permission` (`select_multiple`, required: false)
  Confirm if you have performance permission for the script (True or False).

### 8. Script Reproduction Purpose
* **Script Reproduction Purpose**: `script_reproduction_purpose` (`text`, required: false)
  Explain the purpose of reproducing the script (e.g., for educational use).

### 9. Production Notes
* **Production Notes**: `production_notes` (`note`, required: false)
  Add any notes about the production process or script requirements.

### 10. Contact Name
* **Contact Name**: `contact_name` (`text`, required: false)
  Enter the name of the contact person responsible for the script reproduction.

### 11. Contact Email
* **Contact Email**: `contact_email` (`email`, required: false)
  Provide the email address of the contact person.

### 12. Contact Phone
* **Contact Phone**: `contact_phone` (`text`, required: false)
  Enter the phone number of the contact person.

### 13. Contact Notes
* **Contact Notes**: `contact_notes` (`text`, required: false)
  Add any additional notes about the contact person or production team.

### 14. Additional Information
* **Additional Information**: `additional_information` (`text`, required: false)
  Provide any extra details about the production or script reproduction.

### 15. Signed Date
* **Signed Date**: `signed_date` (`date`, required: false)
  Enter the date when this form was signed (YYYY-MM-DD format).

### 16. Signed By
* **Signed By**: `signed_by` (`text`, required: false)
  Enter the name of the person who signed this form.

### 17. Signed At
* **Signed At**: `signed_at` (`time`, required: false)
  Enter the time when this form was signed (HH:MM format).

### 18. Production Status
* **Production Status**: `production_status` (`select_one`, required: false)
  Specify the current production status (Active, Inactive, or Unknown).

## Tips

- Ensure all fields are filled out accurately and completely.
- If you're unsure about any field, please contact the form owner or production team for guidance.
- Save this form for future reference or reproduction efforts.
