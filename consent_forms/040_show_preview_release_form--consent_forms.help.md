# Show Preview Release Form - Help Guide

## Purpose
This form is used to collect participant information and preferences before displaying a preview of a release.

## How To Complete This Form
1. Fill in the participant's name and email address in the "Participant Information" section.
2. Select the type of email address you want to use (Personal, Work, or Other).
3. Select the type of phone number you want to use (Home, Work, or Cell).
4. Indicate whether the participant is a minor (Yes or No).
5. Enter the participant's date of birth, if applicable.
6. Choose whether to display the participant's title (Yes or No).
7. Choose the start and end dates for the preview release, if applicable.
8. Sign the participant signature section, if required.
9. Select whether to display the preview release (Yes or No).
10. Select whether to use the participant's information for promotional recordings (Yes or No).
11. Enter any additional notes from the participant, if necessary.

## Field-by-Field Explanation

* **Participant Information** (`show_preview_release_form`, text, required/optional): Enter the participant's name and any additional information that will help us display a preview of the release.
* **Participant Name** (`participant_name`, text, optional): Enter the participant's name.
* **Participant Email** (`participant_email`, email, optional): Enter the participant's email address.
* **Participant Phone** (`participant_phone`, text, optional): Enter the participant's phone number.
* **Participant Email Type** (`participant_email_type`, select_one, required): Select the type of email address you want to use (Personal, Work, or Other).
* **Participant Phone Type** (`participant_phone_type`, select_one, required): Select the type of phone number you want to use (Home, Work, or Cell).
* **Is Minor** (`is_minor`, select_one, required): Indicate whether the participant is a minor (Yes or No).
* **Date of Birth** (`date_of_birth`, date, optional): Enter the participant's date of birth, if applicable.
* **Show Title** (`show_title`, text, optional): Choose whether to display the participant's title.
* **Start Date** (`show_start_date`, date, optional): Choose the start date for the preview release, if applicable.
* **End Date** (`show_end_date`, date, optional): Choose the end date for the preview release, if applicable.
* **Participant Signature** (`participant_signature`, note, optional): Sign the participant signature section, if required.
* **Show Preview Release** (`show_preview_release`, select_one, required): Select whether to display the participant's information in the preview release (Yes or No).
* **Promotional Recording** (`promotional_recording`, select_one, required): Select whether to use the participant's information for promotional recordings (Yes or No).
* **Participant Note** (`participant_note`, note, optional): Enter any additional notes from the participant, if necessary.
