# student-teacher-co-design-study-consent-form - Help Guide
## Purpose
This form is intended to gather consent from students for a co-design study. It is designed to collect information necessary for the study, including parental consent, research consent, student consent, emergency contact information, and contact method.

## How To Complete This Form
To complete this form, follow the steps below:

1. Provide general information about yourself.
2. Select one of the options for parental consent.
3. Select one of the options for research consent.
4. Select multiple options for student consent.
5. Provide emergency contact information.
6. Select one of the options for contact method.
7. If necessary, add any additional comments.

## Field-by-Field Explanation

* **General Information (Page 1)**: This is the first page of the form where you will provide general information about yourself.
* **Parental Consent (Page 2)**: Please select one of the options below for parental consent.
	+ Option 1: Parent/guardian has given consent for this study.
	+ Option 2: Parent/guardian has not given consent for this study.
* **Research Consent (Page 3)**: Please select one of the options below for research consent.
	+ Option 1: I am willing to participate in the research study.
	+ Option 2: I am not willing to participate in the research study.
* **Student Consent (Page 4)**: Select multiple options below for student consent.
	+ Option 1: Option 1
	+ Option 2: Option 2
* **Emergency Contact (Page 5)**: Please provide the emergency contact information.
* **Contact Method (Page 6)**: Please select one of the options below for contact method.
	+ Option 1: Option 1
	+ Option 2: Option 2
* **Additional Comments (Page 7)**: If you have any additional comments, please add them here.

Note: Please complete the form carefully and honestly. If you have any questions or concerns, please don't hesitate to contact us.
