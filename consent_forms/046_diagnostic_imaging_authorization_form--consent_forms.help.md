## Field-by-Field Explanation
## Tips

### Patient Information (patient_id, text, optional)
* This field is used to enter the patient's ID number, if available.

### Authorization Request (authorization_request, select_multiple, optional)
* This field is used to select "Yes" if you are requesting authorization for diagnostic imaging procedures.

### Consent for Procedure (consent_procedure, select_one, optional)
* This field is used to select "Yes" if you are seeking consent for a specific procedure.

### Medical Condition (medical_condition, text, optional)
* This field is used to enter the medical condition being treated or assessed during the imaging procedure.

### Medical Imaging Authorization (medical_imaging_authorization, number, optional)
* This field is used to enter the number of imaging procedures authorized.

### Authorization Date (authorization_date, date, optional)
* This field is used to enter the date the authorization was given.

### Expiration Date (expiration_date, date, optional)
* This field is used to enter the date the authorization expires.

### Signature (signature, note, optional)
* This field is used for the patient to sign and date the form to confirm authorization.

### Medical Provider Name (medical_provider_name, text, optional)
* This field is used to enter the name of the medical provider requesting authorization.

### Patient Name (patient_name, text, optional)
* This field is used to enter the patient's name.

### Medical Organization (medical_organization, text, optional)
* This field is used to enter the name of the medical organization requesting authorization.

### Medical Specialty (medical_specialty, text, optional)
* This field is used to enter the medical specialty of the procedure.

### Procedure Code (procedure_code, select_one, optional)
* This field is used to select "Yes" if the procedure is being performed.

### Authorization Status (authorization_status, select_one, optional)
* This field is used to select "Active" to indicate the authorization is active.
