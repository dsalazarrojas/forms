# Parent Code Of Conduct Agreement - Help Guide
## Purpose
The "Parent Code Of Conduct Agreement" form is a crucial document that seeks to obtain consent from parents or guardians regarding the rules and expectations for their child's conduct within our institution. It is a legal requirement for the child's participation in our programs, and it ensures that parents or guardians are aware of and agree to a set of conduct guidelines that promote the child's safety, well-being, and success.

## How To Complete This Form
To complete this form, follow these steps:

1. Review each page carefully to ensure you understand the questions and answers.
2. Select the correct option for each question, based on your understanding.
3. Provide accurate information when required.
4. Sign and date the form to indicate your consent.

## Field-by-Field Explanation
### 1. **Parent Consenting to Code of Conduct Agreement** (`parent_consent`, `select_one`, required)
The parent or guardian must select 'Yes' or 'No' to indicate their consent to the Code of Conduct Agreement.

* If 'Yes', you are granting consent to the Code of Conduct Agreement.
* If 'No', you are indicating that you do not grant consent and will need to discuss this further with the school.

### 2. **Guardian Consenting to Code of Conduct Agreement** (`guardian_consent`, `select_multiple`, required)
The parent or guardian must select 'Yes' or 'No' to indicate their consent to the Code of Conduct Agreement for each of the provided options.

* You can select 'Yes' or 'No' for each option, based on your understanding of the Code of Conduct Agreement.

### 3. **School Program** (`school_program`, `text`, required)
Please provide the name of the school program your child is participating in.

* This information helps us understand which program your child is involved with.

### 4. **Youth Program** (`youth_program`, `text`, required)
Please provide the name of the youth program your child is participating in.

* This information helps us understand which program your child is involved with.

### 5. **Conduct Agreement** (`conduct_agreement`, `select_one`, required)
The parent or guardian must select 'Yes' or 'No' to indicate their understanding and acceptance of the Code of Conduct Agreement.

* If 'Yes', you are indicating that you understand and accept the Code of Conduct Agreement.
* If 'No', you are indicating that you do not understand or accept the Code of Conduct Agreement, and we will need to discuss this further.

### 6. **Parent Signature** (`parent_signature`, `note`, required)
Please sign and date this form to indicate your consent.

* This is a legally binding agreement, so it is essential to sign this form to confirm your consent.

### 7. **Guardian Signature** (`guardian_signature`, `note`, required)
Please sign and date this form to indicate your consent.

* This is a legally binding agreement, so it is essential to sign this form to confirm your consent.

### 8. **Agreement Date** (`agreement_date`, `date`, required)

### 9. **Agreement Time** (`agreement_time`, `time`, required)
Please provide the time you are signing this form.

### 10. **School Contact Information** (`school_contact_info`, `text`, required)
Please provide the contact information for your child's school.

* This information helps us stay in touch with your child's school.

### 11. **Parent Name** (`parent_name`, `text`, required)
Please provide your name as the parent or guardian.

* This information helps us identify you as the parent or guardian.

### 12. **Guardian Name** (`guardian_name`, `text`, required)
Please provide your name as the guardian, if applicable.
