# App Location Tracking Consent Form - Help Guide

## Purpose
This form is used to obtain consent for location tracking from the end user. It is essential to ensure that the user understands how their location data will be used, stored, and shared. This form is a critical part of ensuring that we handle user data responsibly and in accordance with privacy policies.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the date you are providing consent for location tracking (`consent_date`).
2. Enter your full name as it appears on your identification documents (`user_name`).
3. Enter your email address or user ID/Account number (if applicable) (`user_email`/`user_id`).
4. Enter your date of birth for age verification purposes (`date_of_birth`).
5. Specify the name of the application requesting location access (`app_name`).
6. Explain how your location will be used (`tracking_explanation`).
7. Choose how often your location will be accessed (`tracking_frequency`).
8. Choose the level of location accuracy required (`accuracy_level`).
9. Explain how your location data will be stored (`data_storage`).
10. Choose how long your location data will be kept (`data_retention`).
11. Choose whether your location data will be shared with third parties (`data_sharing`).
12. If applicable, describe how location data will be shared with third parties (`sharing_details`).
13. Choose whether you can control your location tracking at any time (`user_control`).
14. Enter a link to our full privacy policy document (`privacy_policy_link`).
15. Indicate your understanding of how your location will be used (`consent_understanding`).
16. Confirm that you consent to location tracking as described (`consent_acceptance`).
17. If you are a minor, indicate that parental consent is provided (`parental_consent`).
18. Confirm that you understand you can revoke this consent anytime (`consent_revocation`).
19. Enter the date of your consent (`signature_date`).

## Field-by-Field Explanation
- **Consent date** (`consent_date`): The date you are providing consent for location tracking.
  * Type: Date
  * Required: Yes
  * Hint: null
- **User full name** (`user_name`): Your full name as it appears on your identification documents.
  * Type: Text
  * Required: Yes
  * Hint: null
- **Email address/ User ID/Account number** (`user_email`/`user_id`): Your email address or user ID/Account number (if applicable).
  * Type: Text/Email
  * Required: Yes
  * Hint: null
- **Date of birth** (`date_of_birth`): For age verification purposes.
  * Type: Date
  * Required: Yes
  * Hint: For age verification
- **App name** (`app_name`): The name of the application requesting location access.
  * Type: Text
  * Required: Yes
  * Hint: Which app is requesting permission
- **How will location be used?** (`tracking_explanation`): Explanation of location tracking purpose.
  * Type: Text
  * Required: Yes
  * Hint: Explanation of location tracking purpose
- **Frequency of location tracking** (`tracking_frequency`): How often your location will be accessed.
  * Type: Select One
  * Required: Yes
  * Hint: How often location will be accessed
- **Level of location accuracy needed** (`accuracy_level`): Precise location vs general area.
  * Type: Select One
  * Required: Yes
  * Hint: Precise location vs general area
- **How will location data be stored?** (`data_storage`): Explanation of data storage.
  * Type: Text
  * Required: Yes
  * Hint: Explanation of data storage
- **Location data retention period** (`data_retention`): Retention period.
  * Type: Select One
  * Required: Yes
  * Hint: Retention period
- **Will location data be shared with third parties?** (`data_sharing`): Whether location data will be shared with third parties.
  * Type: Select One
  * Required: Yes
  * Hint: null
- **If shared, describe how location data is used** (`sharing_details`): How location data will be shared with third parties.
  * Type: Text
  * Required: False
  * Hint: null
- **Can user control location tracking?** (`user_control`): Ability to turn off or adjust tracking.
  * Type: Select One
  * Required: Yes
  * Hint: Ability to turn off or adjust
- **Link to full privacy policy** (`privacy_policy_link`): Link to our full privacy policy document.
  * Type: Text
  * Required: Yes
  * Hint: null
- **I understand how my location will be used** (`consent_understanding`): Indicate your understanding of how your location will be used.
  * Type: Select One
  * Required: Yes
  * Hint: null
- **I consent to location tracking as described** (`consent_acceptance`): Confirm that you consent to location tracking as described.
  * Type: Select One
  * Required: Yes
  * Hint: null
- **Is parental consent provided?** (`parental_consent`): If you are a minor, indicate that parental consent is provided.
  * Type: Select One
  * Required: Yes
  * Hint: If user is a minor
- **I understand I can revoke this consent anytime** (`consent_revocation`): Confirm that you understand you can revoke this consent anytime.
  * Type: Select One
  * Required: Yes
  * Hint: null
- **Consent signature date** (`signature_date`): The date of your consent.
  * Type: Date
  * Required: Yes
  * Hint: null

## Tips
* Please make sure to answer each field truthfully and with clear understanding of the questions.
* If you are unsure about any of the fields, please ask your administrator for clarification.
* Remember that you can revoke your consent anytime.
* Review our full privacy policy document for more information on how we handle user data.
