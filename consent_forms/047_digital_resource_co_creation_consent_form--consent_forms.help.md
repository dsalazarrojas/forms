# Digital Resource Co Creation Consent Form - Help Guide
## Purpose
The purpose of this form is to gather information from contributors about their role, permissions, and other details related to the digital co-creation project. This form ensures that all contributors have a clear understanding of their involvement and responsibilities in the project.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the required fields with accurate information about yourself and your involvement in the project.
2. Review each field carefully to ensure that you understand the information being requested.
3. Submit the form once you have completed it.

## Field-by-Field Explanation

* **Contributor Details**:
	+ This field is used to collect information about the contributor, such as their name and contact details.
	+ Please enter your name and any other relevant information as required.
* **Project Information**:
	+ This field is used to gather details about the project, such as its title and description.
	+ Please enter a brief description of the project and its title.
* **Permissions**:
	+ This field is used to determine what level of access the contributor has to the project resource.
	+ Please select the correct level of permission for your role in the project.
* **Project Leader Information**:
	+ This field is used to collect information about the project leader or lead contributor.
	+ Please enter the name and contact details of the project leader.
* **Co-Creation Info**:
	+ This field is used to collect information about the co-creation process and any relevant details.
	+ Please enter any relevant details about the co-creation process.
* **Project Status**:
	+ This field is used to indicate the current status of the project.
	+ Please select the current status of the project (Active or Inactive).
* **Project Start Date**:
	+ This field is used to collect the start date of the project.
	+ Please enter the date the project started.
* **Project End Date**:
	+ This field is used to collect the end date of the project.
	+ Please enter the date the project will end.
* **Resource Type**:
	+ This field is used to determine what type of resource is being created.
	+ Please select the correct type of resource (Yes or No).
* **Resource Name**:
	+ This field is used to collect the name of the resource being created.
	+ Please enter the name of the resource.
* **Resource Version**:
	+ This field is used to collect any versioning information about the resource.
	+ Please enter any versioning information as required.
* **Contributor Agreement**:
	+ This field is used to record the contributor's agreement to the terms of the project.
	+ Please read and agree to the terms of the project.
* **Contributor Consent**:
	+ This field is used to record the contributor's consent to the terms of the project.
	+ Please read and provide consent to the terms of the project.
* **Resource Owner**:
	+ This field is used to determine who owns the resource.
	+ Please select whether you own the resource (Yes or No).
* **Co-Creation License**:
	+ This field is used to determine what license will be used for the co-creation.
	+ Please select whether you want to use the co-creation license (Yes or No).
* **Resource License**:
	+ This field is used to determine what license will be used for the resource.
	+ Please select whether you want to use the resource license (Yes or No).

## Tips
* Please ensure that you are authorized to access this form and that you are not duplicating your effort by filling out a form that already exists.
* Review each field carefully to ensure that you understand the information being requested.
* Submit the form once you have completed it accurately and truthfully.
