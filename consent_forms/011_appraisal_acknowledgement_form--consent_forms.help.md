# Appraisal Acknowledgement Form - Help Guide
## Purpose
The Appraisal Acknowledgement Form is used to collect acknowledgement and information from a property seller after an appraisal report has been generated.

## How To Complete This Form
To complete this form, follow these steps:
- Ensure you have received the appraisal report before filling out this form.
- Fill out all required fields, indicated by an asterisk (\*).
- For each field, type or select the information as described below.

## Field-by-Field Explanation

- **Property Address** (`property_address`, text, \*): Type the exact address of the property that was appraised.
- **Property Type** (`property_type`, select_one, \*): Select the type of property from the options provided.
- **Appraiser Name** (`appraiser_name`, text, \*): Type the name of the appraiser who generated the report.
- **License Number** (`appraiser_license`, text, optional): If applicable, type the appraiser's license number.
- **Seller Name** (`seller_name`, text, \*): Type your name as the seller.
- **Do you acknowledge receipt of the appraisal report** (`seller_signature_required`, select_one, \*): Select 'Yes' to acknowledge receipt of the report.
- **Date of Acknowledgement** (`acknowledgement_date`, date, \*): Type the date you are acknowledging receipt of the report.
- **Any Discrepancies or Concerns** (`discrepancies`, text, optional): If there are any discrepancies or concerns with the report, type them here.
- **Additional Notes** (`additional_notes`, text, optional): If you have any additional comments or questions, type them here.
- **Townhouse**: This field is not present in the YAML, but it is a possible property type that should be included in the form as per the options list.
