# recycling_facility_audit_consent_form - Help Guide
## Purpose
This form is used to gather consent from facilities regarding an audit of their recycling processes.

## How To Complete This Form
To complete this form, follow these steps:

1. Review the form carefully to understand the purpose and objectives of the audit.
2. Answer each question honestly and accurately, taking into account your facility's current recycling processes and procedures.
3. Select the preferred audit dates for the facility.
4. Indicate whether you have a facility contact person for the audit.
5. Provide any additional information or notes that may be relevant to the audit.

## Field-by-Field Explanation
* **Facility Details**: This field is used to collect information about the facility being audited.
	+ Type: text
	+ Required: No
	+ Description: Please provide a brief description of the facility, including its name, address, and location.
* **Preferred Audit Dates**: This field is used to select preferred dates for the audit.
	+ Type: select_multiple
	+ Required: No
	+ Description: Select all the dates you prefer for the audit, in order of priority.
* **Facility Contacts**: This field is used to indicate whether you have a facility contact person for the audit.
	+ Type: select_one
	+ Required: No
	+ Description: Indicate if you have a facility contact person available for the audit.
* **Facility Contacts 2**: This field is used to collect additional contact information for the facility.
	+ Type: text
	+ Required: No
	+ Description: Provide any additional contact information for the facility, such as email addresses or phone numbers.
* **Consent**: This field is used to indicate consent for the audit.
	+ Type: note
	+ Required: No
	+ Description: Please acknowledge that you have reviewed and understood the audit's objectives, scope, and potential consequences.
* **Preferred Audit Date**: This field is used to select a preferred date for the audit.
	+ Type: date
	+ Required: No
	+ Description: Select a specific date for the audit, if possible.
* **Facility Contact**: This field is used to provide the name and contact information of the facility contact person.
	+ Type: text
	+ Required: No
	+ Description: Enter the name and contact information of the facility contact person, including their email address and phone number.
* **Facility Contact 2**: This field is used to provide additional contact information for the facility.
	+ Type: text
	+ Required: No
	+ Description: Enter any additional contact information for the facility, such as alternate contact persons or emergency contact numbers.
* **Assigned Tool**: This field is used to indicate which tool is assigned to the facility for the audit.
	+ Type: text
	+ Required: No
	+ Description: Enter the tool assigned to the facility for the audit, if any.
* **Notes**: This field is used to provide any additional information or comments about the audit.
	+ Type: note
	+ Required: No
	+ Description: Enter any additional information or comments you would like to provide about the audit.

## Tips
* Please answer all questions honestly and accurately.
* If you are unsure about any question, please consult with your facility management team.
* This form is part of the audit process, so please review it carefully before submitting.
