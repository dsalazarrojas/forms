# Relaxation Package Release Form - Help Guide
## Purpose

The "Relaxation Package Release Form" is a critical document that confirms the details of the relaxation package and ensures that the client understands the terms and conditions of the package. This form is used to:

* Confirm client details
* Schedule session information
* Obtain client consent
* Verify client signature and payment terms

## How To Complete This Form

1. **Client Details**: Enter the client's name and contact information in this field.
2. **Schedule Session**: Select whether the client has scheduled a session or not.
3. **Consent Form**: This field is for the client to review and sign the relaxation package terms and conditions.
4. **Session Details**: Enter any additional session-specific information that may be relevant.
5. **Submit Session**: Enter your submission details for the session.
6. **Session Capture**: This field is for any additional information to be captured during the session.
7. **Session Capture (Capture)**: This field is for any additional information to be captured during the session.
8. **Client Signature**: This field is for the client to sign and verify their identity.
9. **Signature Verification**: Select whether the client's signature has been verified or not.
10. **Payment Terms**: Select whether the client has agreed to the payment terms or not.
11. **Payment Terms Other**: If the client has agreed to other payment terms, specify them here.
12. **Payment Terms Other Text**: Enter any additional details about the payment terms.
13. **Signature**: This field is for any additional information about the client's signature.
14. **Signature (Capture)**: This field is for any additional information about the client's signature.
15. **Session Capture Other**: If any additional information needs to be captured during the session, specify it here.
16. **Session Capture Other Text**: Enter any additional details about the session capture.
17. **Payment Terms Capture**: Select whether the client has agreed to the payment terms or not.
18. **Client Signature Capture**: Enter any additional details about the client's signature.
19. **Signature Terms**: Select whether the client has agreed to the signature terms or not.
