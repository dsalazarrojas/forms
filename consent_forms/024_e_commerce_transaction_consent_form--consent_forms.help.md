# E Commerce Transaction Consent Form - Help Guide
## Purpose
The E Commerce Transaction Consent Form is used to record user consent for e-commerce transactions. This form captures essential details about the transaction, including user input, transaction information, and consent status.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the required and optional fields as applicable. The required fields are marked with an asterisk (\*).
2. For the "User Input" field, enter a brief description of the transaction.
3. Select the relevant transaction type from the dropdown menu in the "Transaction Type" field.
4. Enter the date and time of consent in the "Consent Date" and "Consent Time" fields.
5. Enter the customer's email address in the "Email" field.
6. Enter the customer's phone number in the "Phone" field.
7. Enter the transaction amount in the "Transaction Amount" field.
8. Enter the customer's name and address in the "Customer Name" and "Customer Address" fields.
9. Enter the customer's IP address in the "Customer IP" field.
10. Enter any relevant merchant details in the "Merchant Details" field.
11. Select the current status of the transaction from the dropdown menu in the "Transaction Status" field.
12. Indicate whether the user has given consent to the transaction by selecting either "True" or "False" in the "User Consent" field.

## Field-by-Field Explanation
* **User Input (User Input, text, required)**: Enter a brief description of the transaction.
* **Transaction Info (Transaction Info, text, required)**: This field is not currently used. Please contact the system administrator for further information.
* **Transaction Type (Transaction Type, select_one, required)**: Select the type of transaction (online or offline).
* **Consent Date (Consent Date, date, required)**: Enter the date on which the user gave consent.
* **Consent Time (Consent Time, time, required)**: Enter the time at which the user gave consent.
* **Email (Email, email, required)**: Enter the customer's email address.
* **Phone (Phone, text, required)**: Enter the customer's phone number.
* **Transaction Amount (Transaction Amount, number, required)**: Enter the amount of the transaction.
* **Customer Name (Customer Name, text, required)**: Enter the customer's name.
* **Customer Address (Customer Address, text, required)**: Enter the customer's address.
* **Customer IP (Customer IP, text, required)**: Enter the customer's IP address.
* **Merchant Details (Merchant Details, text, required)**: Enter any relevant merchant details.
* **Transaction Status (Transaction Status, select_one, required)**: Select the current status of the transaction (approved, pending, or declined).
* **User Consent (User Consent, select_multiple, required)**: Select whether the user has given consent to the transaction (True or False).
