# Stage Technician Media Release Consent Form - Help Guide
## Purpose
The Stage Technician Media Release Consent Form is a document that captures stage technicians' preferences for media release during events. This form helps to ensure that we respect their wishes and handle their media release in accordance with their consent.

## How To Complete This Form
1. Read the instructions and questions carefully before starting to fill out the form.
2. Answer each question honestly and to the best of your ability.
3. For "Backstage Crew Media Usage", select all the media types you are comfortable being photographed or recorded for.
4. In "Media Usage Description", provide a brief description of the media usage you've selected.
5. For "Media Usage Purpose", select the purpose(s) for which you are comfortable with media usage.
6. If you are a member of the backstage crew, provide the names of all crew members in "Backstage Crew Member Names".
7. In "Backstage Crew Contact Info", provide contact information for the backstage crew, if applicable.
8. Answer "Release What" with the type of media (e.g., photos, videos, audio recordings) you are comfortable being released.
9. Answer "Release When" with the dates (or date ranges) when you are comfortable with media release.
10. Answer "Release Where" with the location where you are comfortable with media release.
11. In "Release For", specify who (or who is responsible) should handle the released media.
12. Finally, "Additional Comments" can be used to provide any extra information that may be relevant to your media release.

## Field-by-Field Explanation
* **Stage Technician Media Release** (`stage_technician_media_release_consent_form`): This is the primary field that captures your media release preferences.
* **Backstage Crew Media Usage** (`backstage_crew_media_usage`): Select all the media types you are comfortable being photographed or recorded for.
  * Example: "Yes" for photos, videos, or audio recordings.
* **Media Usage Description** (`media_usage_description`): Provide a brief description of the media usage you've selected.
  * Example: "I'm comfortable being photographed during events, but not during rehearsals."
* **Media Usage Purpose** (`media_usage_purpose`): Select the purpose(s) for which you are comfortable with media usage.
  * Example: Select "Marketing" and "Promotional".
* **Backstage Crew Member Names** (`backstage_crew_member_names`): If you are a member of the backstage crew, provide the names of all crew members.
* **Backstage Crew Contact Info** (`backstage_crew_contact_info`): Provide contact information for the backstage crew, if applicable.
* **Release What** (`release_what`): Answer with the type of media you are comfortable being released (e.g., photos, videos, audio recordings).
* **Release When** (`release_when`): Answer with the dates (or date ranges) when you are comfortable with media release.
* **Release Where** (`release_where`): Answer with the location where you are comfortable with media release.
* **Release For** (`release_for`): Specify who (or who is responsible) should handle the released media.
* **Additional Comments** (`additional_comments`): Provide any extra information that may be relevant to your media release.

## Tips
* Please answer each question truthfully and to the best of your ability.
* If you are unsure about any of the questions or have concerns, don't hesitate to ask your production manager or stage manager for clarification.
* This form is intended for general-purpose media release; please don't use it for emergency situations where a quick response is required.
