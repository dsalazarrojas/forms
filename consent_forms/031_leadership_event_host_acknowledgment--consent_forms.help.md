# Leadership Event Host Acknowledgment - Help Guide
## Purpose
The Leadership Event Host Acknowledgment form is used to gather information from event hosts about their roles and responsibilities in hosting a leadership event. This form ensures that event hosts understand their duties and commit to fulfilling them.

## How To Complete This Form
1. Fill out the **Event details** field with information about the event, such as its title, date, and location.
2. In the **Host information** field, provide details about the host, including their name, contact information, and any other relevant details.
3. In the **Event host responsibilities** field, select all the responsibilities that apply to the host, such as event setup and execution, promotion, and coordination.
4. Confirm whether the host has read and understands their responsibilities by checking the **Event host confirmation** field.
5. Provide any additional information about the co-host in the **Co-host information** field, if applicable.
6. In the **Event host acknowledgment** field, write a brief acknowledgment of the host's commitment to fulfilling their responsibilities.
7. If you would like to keep track of submissions, you can add a **Submission tracking** field with any additional comments you may have.

## Field-by-Field Explanation

* **Event details** (`event_details`, `text`, optional): Enter a brief description of the event, including its title, date, and location. This field is optional but helps event organizers understand the event's context.
* **Host information** (`host_info`, `text`, optional): Enter the host's name, contact information, and any other relevant details. This field is optional but helps event organizers contact the host if needed.
* **Event host responsibilities** (`event_host_responsibilities`, `select_multiple`, required): Select all the responsibilities that apply to the host, such as event setup and execution, promotion, and coordination. This field is required as it ensures the host understands their duties.
* **Event host confirmation** (`event_host_confirmation`, `select_one`, required): Confirm whether the host has read and understands their responsibilities by selecting 'True' or 'False'. This field is required as it checks the host's commitment.
* **Co-host information** (`event_co_host`, `text`, optional): Enter any additional information about the co-host, if applicable. This field is optional.
* **Event host acknowledgment** (`event_host_acknowledgment`, `note`, required): Write a brief acknowledgment of the host's commitment to fulfilling their responsibilities. This field is required as it ensures the host understands their duties.
* **Submission tracking** (`submission_tracking`, `text`, optional): Provide any additional comments or tracking information about submissions, if needed. This field is optional.
* **Submission comments** (`submission_comments`, `text`, optional): Enter any additional comments about submissions, if needed. This field is optional.
