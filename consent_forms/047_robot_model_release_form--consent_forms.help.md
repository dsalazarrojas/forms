# Robot Model Release Form - Help Guide
## Purpose
The Robot Model Release Form is a form designed to gather information for the release of a robot model. This form is intended for internal use within an organization and is used to capture project, model, and approval/release information.

## How To Complete This Form
1. Read the form carefully and fill out the required fields.
2. Ensure you have all necessary information before submitting the form.
3. If you are unsure about any of the fields, please contact form@gic.mx for clarification.

## Field-by-Field Explanation
### **Project Information** (`project_info`, `text`, required: false)
* This field is where you can enter project-related information, such as project titles, codes, or descriptions.
### **Robot Model Information** (`model_info`, `text`, required: false)
* This field is where you can enter information about the robot model, such as its name, description, or features.
### **Approval Information** (`approval_info`, `text`, required: true)
* This field is where you need to enter the approval information for the release of the robot model.
### **Release Information** (`release_info`, `text`, required: false)
* This field is where you can enter release-related information, such as the release date, version, or notes.

## Tips
* Be thorough and accurate when filling out the form.
* Ensure you have all necessary approvals before submitting the form.
* If you have any questions or need clarification, contact form@gic.mx.
