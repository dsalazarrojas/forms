# Model Release Consent Form - Help Guide
## Purpose
This form is a consent form for models to sign off on photographs. It's used to obtain the necessary consent from models to use their photographs in various contexts.

## How To Complete This Form
To complete this form, please answer the questions as accurately and thoroughly as possible. If you have any doubts or concerns, please reach out to the form administrators. The form can be filled out on one page.

## Field-by-Field Explanation
* **Going public?** (`going_public`, `text`, required: false): Please indicate if the model is going public or not. This will help the model understand when their images will be used and shared.
* **You need you to use consent in order to have your models sign off on it to use their photographs?** (`you_need_you`, `text`, required: false): This is a confirmation that the model needs to sign the consent form before their photographs can be used.
* **Use our hassle-free template.** (`use_our_template`, `text`, required: false): This is an optional statement to inform the model about the available template for the consent form.

## Tips
* Please answer the questions accurately and thoroughly.
* If you have any doubts or concerns, please reach out to the form administrators.
* Make sure to review the form carefully before submitting it.
* This form is a template, and you can modify it as needed to suit your specific requirements.
