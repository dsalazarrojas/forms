# Maintenance Communication Logging Consent Form - Help Guide
## Purpose

This form collects information about your maintenance and communication preferences to ensure that all parties involved in maintenance activities are on the same page. Please answer the questions honestly to help us improve communication and logging.

## How To Complete This Form

1. Review each field carefully and answer the questions according to your preferences.
2. If you have any questions or need clarification, please refer to the field-by-field explanations below.
3. Complete the form once to avoid any duplication of effort.

## Field-by-Field Explanation

* **Maintenance Communication Logging Consent Form** (`maintenance_communication_logging_consent_form`, text, optional):
	+ This is the title of the form. Please leave this field blank.
* **Contact Person** (`contact_person`, select multiple, optional):
	+ Select one or more individuals or teams that you would like to communicate with regarding maintenance activities. Please choose from:
		- John
		- Jane
		- Joe
* **Communication Preferences** (`communication_preferences`, select one, optional):
	+ Choose how you would like to be contacted:
		- email
		- phone
		- text
* **Log What** (`log_what`, select multiple, optional):
	+ Select the maintenance activities that you would like to log:
		- maintenance
		- repair
		- other (please specify)
* **Consent Type** (`consent_type`, select one, optional):
	+ Choose the type of consent you would like to give:
		- written
		- verbal
		- electronic
* **Communication Frequency** (`communication_frequency`, select one, optional):
	+ Choose how often you would like to be contacted:
		- daily
		- weekly
		- monthly
* **Record Keeping** (`record_keeping`, select one, optional):
	+ Do you want to keep a record of our communication:
		- True
		- False
* **Notes** (`notes`, note, optional):
	+ Add any additional notes or comments about your preferences.
* **Consent Date** (`consent_date`, date, optional):
	+ Date on which you gave your consent
* **Consent Signature** (`consent_signature`, note, optional):
	+ Your signed signature
* **Consent Signed Date** (`consent_signed_date`, date, optional):
	+ Date on which you signed the consent

Note that all fields are optional, and you can skip sections if you don't have a particular preference or if the question does not apply to you.
