# Weighted Dip Exercise Form - Help Guide

## Purpose
This form is used to record information about a single dip exercise. Please fill out this form for each exercise you want to track.

## How To Complete This Form
- Click on "Submit" to start filling out the form.
- Select the date the exercise was performed.
- Enter the weight used during the exercise.
- Enter the number of reps completed during the exercise.
- Select the number of sets completed during the exercise.
- Select whether the exercise was performed with equipment or not.
- Enter any additional notes about the exercise.

## Field-by-Field Explanation
* **Workout** (`workout`, text, optional): Enter the name or description of the exercise.
* **Date** (`date`, date, optional): Enter the date the exercise was performed.
* **Notes** (`notes`, note, optional): Enter any additional information or comments about the exercise.
* **Weight** (`weight`, number, optional): Enter the weight used during the exercise.
* **Reps** (`reps`, number, optional): Enter the number of reps completed during the exercise.
* **Sets** (`sets`, number, optional): Enter the number of sets completed during the exercise.
* **Exercises** (`exercises`, select_multiple, optional): Select all exercises performed during the workout.
* **Exercise Type** (`exercise_type`, select_one, optional): Select the type of exercise (yes/no).
* **Equipment** (`equipment`, select_one, optional): Select whether exercise was performed with equipment or not.

## Tips
- Make sure to enter the correct date and weight for each exercise.
- Select all exercises performed during the workout.
- Select the correct type of exercise and whether it was performed with equipment.
- Use the "notes" field to enter any additional comments or information about the exercise.
