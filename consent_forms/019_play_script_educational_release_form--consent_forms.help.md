# Play Script Educational Release Form - Help Guide

## Purpose
This guide is designed to help users complete the "Play Script Educational Release Form" correctly. The form is used to gather information and provide a release agreement for students to acknowledge their understanding of educational materials. Please take a few minutes to review this guide to ensure a smooth and efficient completion process.

## How To Complete This Form

1.  To begin, select the correct category for your educational script: "Consent Forms" or "Other".
2.  Provide a clear and concise description of the educational script.
3.  If applicable, upload any relevant output files.
4.  Choose the tool(s) assigned to your script, if any.
5.  Specify the form IDs related to your script, if any.
6.  Confirm if your script has a Jotform.
7.  Choose your category for the script from the dropdown list (if applicable).
8.  List any additional categories for your script (if applicable).
9.  Confirm if your script has output files (if applicable).
10. List any additional output files for your script (if applicable).
11. Select the tool(s) assigned to your script, if any (if applicable).
12. List form IDs for your script, if any (if applicable).
13. Confirm if your script has a Jotform (if applicable).
14. Select your category for the script from the dropdown list (if applicable).
15. List any additional categories for your script (if applicable).
16. Confirm the status of your script's output files (if applicable).
17. List any additional output files for your script (if applicable).

## Field-by-Field Explanation

* **Category** (Category, Select One, Required): Select the correct category for your educational script. This will help us understand the type of content you are sharing.
* **Description** (Description, Text, Optional): Provide a clear and concise description of the educational script. This will help us understand the content of your script.
* **Output File** (Output File, Text, Optional): If you have any output files related to your script, upload them here.
* **Assigned Tool** (Assigned Tool, Text, Optional): If your script has been assigned to any tools, list them here.
* **Form IDs** (Form IDs, Number, Required): If your script has any related form IDs, list them here.
* **Jotform** (Jotform, Text, Optional): Confirm if your script has a Jotform.
* **Category List** (Category List, Select Multiple, Optional): If applicable, choose your category for the script from the dropdown list.
* **Description List** (Description List, Text, Optional): If applicable, list any additional descriptions for your script.
* **Output File List** (Output File List, Select Multiple, Optional): If applicable, confirm the status of your script's output files.
* **Assigned Tool List** (Assigned Tool List, Select Multiple, Optional): If applicable, list any tools assigned to your script.
* **Form IDs List** (Form IDs List, Select Multiple, Optional): If applicable, list any form IDs for your script.
* **Created By** (Created By, Text, Optional): Confirm who created your script.
* **Created At** (Created At, Date, Optional): Confirm when your script was created.
* **Deleted At** (Deleted At, Date, Optional): Confirm when your script was deleted (if applicable).
* **Category List 2** (Category List 2, Select Multiple, Optional): If applicable, choose your category for the script from the dropdown list.
* **Created By List** (Created By List, Select Multiple, Optional): If applicable, confirm who created your script.
* **Description List 2** (Description List 2, Text, Optional): If applicable, list any additional descriptions for your script.
* **Output File 2** (Output File 2, Text, Optional): If applicable, list any additional output files for your script.
* **Form IDs 2** (Form IDs 2, Text, Optional): If applicable, list any form IDs for your script.
* **Jotform 2** (Jotform 2, Text, Optional): If applicable, confirm if your script has a Jotform.
* **Category List 2 2** (Category List 2 2, Select Multiple, Optional): If applicable, choose your category for the script from the dropdown list.
* **Description List 2 2** (Description List 2 2, Text, Optional): If applicable, list any additional descriptions for your script.
* **Output File 2 2** (Output File 2 2, Text, Optional): If applicable, list any additional output files for your script.

Note: Please ensure all fields are accurate and complete before submitting the form. If you are unsure about any field, please contact your administrator for assistance.
