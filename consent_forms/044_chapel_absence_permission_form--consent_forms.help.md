# Chapel Absence Permission Form - Help Guide
## Purpose
The purpose of this form is to request permission for a student to be absent from chapel services. This form must be filled out and submitted by the parent or guardian of the student requesting the absence.

## How To Complete This Form
To complete this form, please follow these steps:
1. Enter the date the form is being submitted.
2. Fill out the student information section:
	* Enter the student's name in the correct format (e.g., "John Doe").
	* Enter the student's ID number.
	* Select the student's current grade level.
3. Enter the school or institution name where the student attends.
4. If the student is a minor, enter the parent or guardian's name.
5. If applicable, provide the parent or guardian's email address and phone number for contact purposes.
6. Specify the student's religious affiliation.
7. Enter the date of the requested absence and select the frequency of the absence.
8. Select the reason for the absence.
9. Provide further explanation for the reason of absence.
10. If necessary, indicate if the student requires any religious accommodations and provide details.
11. If the student will be attending an alternative activity or service, specify the name of it.
12. Confirm that the student understands the request and is aware of the chaplain's decision.
13. If you are the parent or guardian, confirm that you consent to the student's absence.
14. If the chaplain is aware of the request, select 'Yes'. If not, select 'No'. This will alert the chaplain.
15. Finally, select the current status of the request (e.g., pending, approved, or denied).

## Field-by-Field Explanation
- **Form Date** (`form_date`, date): The date the form is being submitted.
- **Student Name** (`student_name`, text, required): Enter the student's full legal name.
- **Student ID Number** (`student_id`, text, required): Enter the student's school ID number.
- **Grade Level or Year** (`grade_level`, select_one, required): Select the student's current grade level or year.
- **School or Institution Name** (`school_name`, text, required): Enter the name of the school or institution the student attends.
- **Parent or Guardian Name** (`parent_guardian_name`, text, optional): If the student is a minor, enter the parent or guardian's name.
- **Parent Email** (`parent_email`, email, optional): Enter the parent or guardian's email address for contact purposes.
- **Parent Phone Number** (`parent_phone`, text, optional): Enter the parent or guardian's phone number for contact purposes.
- **Religious Affiliation** (`religious_affiliation`, text, optional): Specify the student's faith tradition.
- **Date of Chapel Absence** (`absence_date`, date, required): Enter the date of the requested absence.
- **Frequency of Absence** (`absence_frequency`, select_one, required): Select the frequency of the absence (e.g., one-time, weekly, monthly, ongoing).
- **Reason for Absence** (`absence_reason`, select_one, required): Select the reason for the student's absence.
- **Detailed Explanation** (`absence_reason_details`, text, required): Provide a further explanation for the reason of absence.
- **Religious Accommodations Needed** (`religious_accommodation_needed`, select_one, optional): If necessary, select if the student requires any religious accommodations.
- **Accommodation Details** (`accommodation_details`, text, optional): If necessary, provide details about the accommodations needed.
- **Alternative Activity or Service** (`alternative_activity`, text, optional): If the student will be attending an alternative activity or service, specify the name of it.
- **Student Understanding of Absence Request** (`student_acknowledgment`, select_one, required): Confirm that the student understands the request.
- **Parent or Guardian Consent** (`parent_consent`, select_one, optional): If you are the parent or guardian, confirm that you consent to the student's absence.
- **Chaplain Awareness** (`chaplain_awareness`, select_one, optional): Select if the chaplain has been informed of the request.
- **Approval Status** (`approval_status`, select_one, required): Select the current status of the request (e.g., pending, approved, conditional, denied).
