# Software Application Admin Consent Request Form - Help Guide
## Purpose
This form is designed for software applications administrators to request approval for access to user information.

## How To Complete This Form
To fill out this form, you will need to provide the following information:

1.  Software Title: The name of the software application for which approval is being requested.
2.  Software Version: The version of the software application for which approval is being requested.
3.  Admin User: The user's name and title of the admin requesting access.
4.  User Email: The email address of the user to whom access is being requested.
5.  Approval Date: The date on which the approval is requested.
6.  Approval Time: The time of day at which the approval is requested.
7.  Admin Notes: Optional comments for the requested access.
8.  Approval Status: The status of the approval request (Approved, Rejected, or Pending).
9.  Admin Consent: The level of access to grant to the user (Read, Write, or Delete), if applicable.

## Field-by-Field Explanation

* **Software Title** (`Software Title`, text, optional): This is the name of the software application for which approval is being requested.
* **Software Version** (`Software Version`, text, optional): This is the version of the software application for which approval is being requested.
* **Admin User** (`Admin User`, text, optional): This is the user's name and title of the admin requesting access.
* **User Email** (`User Email`, email, optional): This is the email address of the user to whom access is being requested.
* **Approval Date** (`Approval Date`, date, optional): This is the date on which the approval is requested.
* **Approval Time** (`Approval Time`, time, optional): This is the time of day at which the approval is requested.
* **Admin Notes** (`Admin Notes`, note, optional): This is an optional field for the admin to provide additional comments or reasons for the requested access.
* **Approval Status** (`Approval Status`, select_one, optional): This field displays the status of the approval request (Approved, Rejected, or Pending).
* **Admin Consent** (`Admin Consent`, select_multiple, optional): This is an optional field where admin can choose which level of access to grant to the user (Read, Write, or Delete).
