# Trademark Licensing Consent Form - Help Guide
## Purpose
This form is used to provide consent for trademark licensing, allowing another party to use a trademark that already exists.

## How To Complete This Form
1. Select the type of trademark licensing consent you are providing: 
   - Choose from "trademark owner", "trademark agent", or "trademark owner and agent".
2. Select the trademark owner or agent:
   - Choose from a list of options provided.
3. Select the date the consent was issued:
   - Choose a date using the provided date picker.
4. Select the date the consent is effective until:
   - Choose a date using the provided date picker.
5. Provide a description of the trademark:
   - Enter a brief description of the trademark in the text box.
6. Select any images associated with the trademark:
   - Choose from a list of provided options.
7. Sign and date the form:
   - Enter your signature and date.

## Field-by-Field Explanation
* **Select Type of Trademark Licensing Consent** (`trademark_licensing_consent_form_label`, select_one, required: false): 
  Selecting this field will determine the type of consent you are giving. Choose from "trademark owner", "trademark agent", or "trademark owner and agent".
* **Trademark Owner/Agent** (`trademark_owner`, select_multiple, required: false): 
  Selecting this field will allow you to choose which trademark owner or agent is granting consent.
* **Date Issued** (`date_issued`, date, required: false): 
  Select a date when the consent was issued.
* **Date Effective Until** (`date_effective`, date, required: false): 
  Select a date when the consent is effective until.
* **Trademark Description** (`trademark_description`, note, required: false): 
  Provide a brief description of the trademark in this text box.
* **Trademark Image** (`trademark_image`, select_multiple, required: false): 
  Select any images associated with the trademark from the list provided.
* **User Signature** (`user_signature`, text, required: false): 
  Enter your signature and date in this text box.

## Tips
* Make sure to select the correct type of trademark licensing consent and choose the correct trademark owner or agent.
* Provide accurate dates for when the consent was issued and when it is effective until.
* Enter a clear and concise description of the trademark.
* Select any images associated with the trademark that are relevant to the consent.
* Make sure to sign and date the form once completed.
