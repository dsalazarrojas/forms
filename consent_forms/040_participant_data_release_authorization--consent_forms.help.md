# Participant Data Release Authorization - Help Guide
## Purpose
This form is designed to collect participant data release authorization information, which is essential for researchers, program teams, or service teams to share participant data with specific recipients for various purposes.

## How To Complete This Form
1. Choose the participant data release authorization status: Select "Yes" if you are authorized to release participant data, and "No" otherwise.
2. Provide the recipient's name in the `recipient_name` field. This is where you can enter the name of the person or organization receiving the participant data.
3. Enter the recipient organization's name in the `recipient_organization` field. This will help clarify the affiliation of the recipient organization.
4. Select the data purpose from the options provided in the `data_purpose` field. This will help ensure that data sharing is aligned with your intended use.
5. Provide the date for data release in the `release_date` field. This is the date when you plan to share participant data with the recipient.
6. Select the time of data release from the options provided in the `release_time` field. This will help schedule the data sharing according to your needs.

## Field-by-Field Explanation
* **Participant Data Release Authorized** (`participant_data_release_authorized`, `select_one`, required/optional): This field determines whether you are authorized to release participant data. Select "Yes" to affirm your authorization.
* **Recipient Name** (`recipient_name`, `text`, required/optional): Enter the name of the person or organization receiving participant data.
* **Recipient Organization** (`recipient_organization`, `text`, required/optional): Provide the name of the recipient organization.
* **Data Purpose** (`data_purpose`, `select_one`, required/optional): Select the purpose for which you plan to share participant data.
* **Data Release Date** (`release_date`, `date`, required/optional): Enter the date when you plan to share participant data with the recipient.
* **Data Release Time** (`release_time`, `time`, required/optional): Select the time of day when you plan to share participant data with the recipient.

## Tips
* Ensure that you align the data purpose with your project's requirements to avoid any confusion or misuse of participant data.
* Double-check the recipient name and organization to guarantee accurate data sharing.
