# In Person Class Participation Waiver - Help Guide
## Purpose

The In Person Class Participation Waiver form is a mandatory requirement for all participants in an in-person class setting. The form helps us ensure that we have accurate and up-to-date information about each participant, which is essential for their safety and well-being during the class.

## How To Complete This Form

1. Click on the "Start Form" button to begin the form.
2. Fill out each field with accurate and complete information.
3. Review your information carefully before submitting the form.

## Field-by-Field Explanation

* **Participant Name** (`participant_name`, text, required)
	+ Please enter your name as it appears on your official identification.
* **Contact Number** (`contact_number`, text, required)
	+ Enter your contact number where you can be reached during the class.
* **Emergency Contact** (`emergency_contact`, text, optional)
	+ If you have an emergency contact, please enter their name.
* **Email** (`email`, email, optional)
	+ If you have an email address, please enter it.
* **Date of Birth** (`date_of_birth`, date, required)
	+ Please enter your date of birth in the format MM/DD/YYYY.
* **Age** (`participant_age`, number, required)
	+ Enter your age as of today.
* **Relationship** (`emergency_contact_relation`, select_one, required)
	+ Indicate how you are related to your emergency contact.
* **Medical Condition** (`medical_condition`, text, optional)
	+ If you have any known medical conditions, please describe them.
* **Allergy List** (`allergy_list`, text, optional)
	+ If you have any allergies, please list them.
* **Medical Device** (`medical_device`, text, optional)
	+ If you have any medical devices, please describe them.
* **Medical Procedure** (`medical_procedure`, text, optional)
	+ If you have undergone any medical procedures, please describe them.
* **Medical History** (`medical_history`, text, optional)
	+ If you have any medical history, please describe them.
* **Physical Disability** (`physical_disability`, text, optional)
	+ If you have any physical disabilities, please describe them.
* **Medical Condition Description** (`medical_condition_description`, text, optional)
	+ If you have any medical conditions that require a description, please provide it.
* **Medical Device Description** (`medical_device_description`, text, optional)
	+ If you have any medical devices that require a description, please provide it.
* **Medical Procedure Description** (`medical_procedure_description`, text, optional)
	+ If you have any medical procedures that require a description, please provide it.
* **Physical Disability Description** (`physical_disability_description`, text, optional)
	+ If you have any physical disabilities that require a description, please provide it.
* **Emergency Contact Name** (`emergency_contact_name`, text, optional)
	+ If you have an emergency contact, please enter their name.
* **Emergency Contact Phone** (`emergency_contact_phone`, text, optional)
	+ If you have an emergency contact, please enter their phone number.
* **Emergency Contact Email** (`emergency_contact_email`, email, optional)
	+ If you have an emergency contact, please enter their email address.
* **Relationship 2** (`emergency_contact_relation_2`, select_one, optional)
	+ If you have a second emergency contact, please select their relationship.
* **Emergency Contact Number** (`emergency_contact_number`, text, optional)
	+ If you have an emergency contact's phone number, please enter it.
* **Emergency Contact Number Alt** (`emergency_contact_number_alt`, text, optional)
	+ If you have an alternative emergency contact's phone number, please enter it.
* **Relationship Goals** (`emergency_contact_relationship_goals`, select_one, optional)
	+ If you have a relationship goal with your emergency contact, please select it.

## Tips

* Please ensure that you enter accurate and up-to-date information.
* If you have any questions or concerns, please don't hesitate to reach out to us.
* Thank you for your cooperation and understanding.
