# Holiday Release Form - Help Guide
## Purpose
The "Holiday Release Form" is used by parents or school administrators to request a student's holiday release from school. The form is used to ensure that students are not penalized for missing school on approved holidays.

## How To Complete This Form

To complete this form, follow these steps:

1. Enter the parent's name in the "Parent Name" field.
2. Enter the student's name in the "Student Name" field.
3. Enter the student's grade level in the "Student Grade" field.
4. Select the start date of the holiday in the "Start Date" field.
5. Select the end date of the holiday in the "End Date" field.
6. Enter a brief reason for the holiday request in the "Reason" field.
7. Sign and date the "Parent Signature" field, if applicable.
8. Sign and date the "School Admin Signature" field, if applicable.
9. Select the type of holiday in the "Holiday" field, from the available options.
10. Select the holiday date in the "Holiday Date" field.

## Field-by-Field Explanation

* **Parent Name** (`parent_name`, text, required/optional): Enter the name of the parent or guardian submitting the request.
* **Student Name** (`student_name`, text, required/optional): Enter the name of the student requesting the holiday release.
* **Student Grade** (`student_grade`, number, required/optional): Enter the student's grade level (e.g., 9th, 10th, etc.).
* **Start Date** (`start_date`, date, required/optional): Select the date the holiday starts.
* **End Date** (`end_date`, date, required/optional): Select the date the holiday ends.
* **Reason** (`reason`, text, required/optional): Enter a brief reason for the holiday request. Please be specific and clear in your explanation.
* **Parent Signature** (`parent_signature`, text, required/optional): Sign and date the form, if applicable.
* **School Admin Signature** (`school_admin_signature`, text, required/optional): Sign and date the form, if applicable.
* **Holiday** (`holiday`, select_one, required/optional): Select the type of holiday from the available options (e.g., Christmas, Thanksgiving, etc.).
* **Holiday Date** (`holiday_date`, date, required/optional): Select the date of the holiday.
* **Student Signature** (`student_signature`, text, required/optional): Sign the form, if applicable.

## Tips

* Make sure to submit one request per holiday.
* Ensure that you have a valid reason for the holiday request.
* Only select a holiday type that is approved by the school.
* Sign and date the form, if applicable, to verify your request.
