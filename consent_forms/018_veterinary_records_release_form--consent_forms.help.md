# veterinary records release form - Help Guide
## Purpose
This form is used to collect information about the veterinary records release process. It is intended to be completed by the pet owner or authorized representative to provide consent for the release of veterinary records.

## How To Complete This Form
To complete this form, please follow these steps:

1. Review the form carefully to understand the purpose and questions asked.
2. Answer the questions honestly and accurately based on your knowledge.
3. Select the relevant options for each field.
4. Submit the form once you have completed all the required fields.

## Field-by-Field Explanation
* **Consent Form** (`consent_form`, select_multiple, required: false): This field asks if you give consent for the release of veterinary records. Select all that apply:
	+ Yes: You give consent for the release of veterinary records.
	+ No: You do not give consent for the release of veterinary records.
* **Pet Details** (`pet_details`, text, required: false): This field is used to provide additional information about the pet being treated. Please enter the pet's name, species, breed, and any relevant medical history.
* **Medical Records Transfer** (`medical_records_transfer`, select_one, required: false): This field asks if you want to transfer the pet's medical records to a different veterinarian. Select:
	+ Yes: You want to transfer the medical records to a different veterinarian.
	+ No: You do not want to transfer the medical records to a different veterinarian.
* **Veterinary Clinics** (`veterinary_clinics`, select_one, required: false): This field asks if you are authorizing the release of veterinary records to a different veterinary clinic. Select:
	+ Yes: You are authorizing the release of veterinary records to a different veterinary clinic.
	+ No: You are not authorizing the release of veterinary records to a different veterinary clinic.

## Tips
* Please make sure to answer all questions honestly and accurately.
* If you are unsure about any question, please contact the veterinarian for clarification.
* Once you have completed the form, please submit it to complete the veterinary records release process.
