# Smart Lighting Usage Data Consent Form - Help Guide
## Purpose
The Smart Lighting Usage Data Consent Form is used to collect user consent for the usage data of smart lighting systems. This data will be used to improve the performance and functionality of the smart lighting systems. The form is designed to be filled out by users to provide their contact information and consent for the data collection.

## How To Complete This Form
To complete this form, please follow the instructions below:

* Please fill out all required fields, denoted by an asterisk (\*).
* For each field, please provide accurate and up-to-date information.
* If you are unsure about any field, please refer to the field explanation below.

## Field-by-Field Explanation

* **First Name** (First Name, text, not required):
	+ This field is used to record your first name.
	+ Please enter your first name in the format "John" or "Jane".
	+ If you prefer not to provide your first name, you can leave this field blank.
* **Last Name** (Last Name, text, not required):
	+ This field is used to record your last name.
	+ Please enter your last name in the format "Doe".
	+ If you prefer not to provide your last name, you can leave this field blank.
* **Contact First Name** (Contact First Name, text, not required):
	+ This field is used to record the first name of the contact person.
	+ Please enter the first name of the person to contact in case of any queries.
	+ If you are unsure about who to contact, you can leave this field blank.
* **Contact Last Name** (Contact Last Name, text, not required):
	+ This field is used to record the last name of the contact person.
	+ Please enter the last name of the person to contact in case of any queries.
	+ If you are unsure about who to contact, you can leave this field blank.
* **Company Name** (Company Name, text, not required):
	+ This field is used to record the name of the company you represent.
	+ If you are not representing a company, you can leave this field blank.
* **Phone** (Phone, text, not required):
	+ This field is used to record your phone number.
	+ Please enter your phone number in the format "(123) 456-7890".
	+ If you do not have a phone number, you can leave this field blank.
* **Email** (Email, email, not required):
	+ This field is used to record your email address.
	+ Please enter a valid email address in the format "john.doe@example.com".
	+ If you do not have an email address, you can leave this field blank.
* **Street** (Street, text, not required):
	+ This field is used to record your street address.
	+ Please enter your street address in the format "123 Main Street".
	+ If you do not have a street address, you can leave this field blank.
* **City** (City, text, not required):
	+ This field is used to record the city where you reside or work.
	+ Please enter the city name in the format "Anytown".
	+ If you are unsure about the city, you can leave this field blank.
* **Country** (Country, select_one, not required):
	+ This field is used to record the country where you reside or work.
	+ Please select one of the following countries: United States, Canada, or Mexico.
* **ZIP** (ZIP, text, not required):
	+ This field is used to record your zip code or postal code.
	+ Please enter your zip code in the format "12345".
	+ If you do not have a zip code, you can leave this field blank.
* **State** (State, text, not required):
	+ This field is used to record the state where you reside or work.
	+ Please enter the state name in the format "California".
	+ If you are unsure about the state, you can leave this field blank.

## Tips
* Please fill out the form carefully and thoroughly to avoid any mistakes.
* If you have any questions or concerns about this form, please contact our support team.
* The data collected from this form will be used to improve the performance and functionality of the smart lighting systems.
