# Capsule Endoscopy Consent Form - Help Guide
## Purpose

This form is used to obtain informed consent from patients for a capsule endoscopy procedure. It's crucial to read and review each section carefully before signing.

## How To Complete This Form

1. Review each section carefully to understand the procedure, its risks, and benefits.
2. Fill in the required fields with accurate and up-to-date information.
3. Answer each question honestly, and select the correct options that apply to you.
4. Sign the consent statement at the end of the form.

## Field-by-Field Explanation

* **Patient Name**: Please enter your full name.
* **Date of Birth**: Enter your date of birth in the format MM/DD/YYYY.
* **Patient ID or Medical Record Number**: Enter your hospital/clinic ID number.
* **Email Address**: Enter your email address for communication purposes.
* **Phone Number**: Enter your contact phone number.
* **Procedure Date**: Enter the scheduled date for the procedure.
* **Physician Name**: Enter the name of your doctor or attending physician.
* **Reason for Procedure**: Explain the clinical indication for the procedure.
* **I understand the procedure**: Select "Yes, fully explained" if you have a thorough understanding of the procedure. If not, select "No, not explained."
* **Have you had capsule endoscopy before?**: Answer "Yes" if you have had the procedure before, "No" if you haven't, or "Unsure" if you're not sure.
* **Do you have a pacemaker or implanted device?**: Answer "Yes" if you have a pacemaker or implanted device, "No" if you don't, or "Unsure" if you're unsure.
* **History of bowel obstruction or stricture?**: Answer "Yes" if you have a history of bowel obstruction or stricture, "No" if you don't, or "Unsure" if you're unsure.
* **History of Crohn's disease?**: Answer "Yes" if you have a history of Crohn's disease, "No" if you don't, or "Unsure" if you're unsure.
* **Current Medications**: List all current medications you're taking.
* **Drug Allergies**: List any drug allergies you have.
* **Potential risks were explained to me**: Select "Yes, thoroughly" if you understand the risks well, "Yes, briefly" if you have some understanding, "Somewhat" if you have partial understanding, or "False" if not explained.
* **I understand common risks include**: Select all common risks that apply to you, such as capsule retention, bowel obstruction, aspiration, incomplete examination, minor discomfort, or failure to diagnose.
* **I acknowledge rare complications may occur**: Select "Yes, I understand" if you're aware of the risks, "No" if not.
* **Benefits of the procedure were explained**: Select "Yes, clear" if you understand the benefits, "Yes, somewhat" if you have some understanding, "Need clarification" if more explanation is needed, or "False" if not explained.
* **Alternative procedures were discussed**: Select "Yes" if alternative procedures were discussed with you, "No" if not, or "Partially" if partially discussed.
* **Alternatives discussed (if any)**: If alternative procedures were discussed, describe them here.
* **All my questions were answered**: Select "Yes" if all your questions were answered, "No" if not, or "Mostly" if mostly answered.
* **Additional questions or concerns**: If you have any additional questions or concerns, list them here.
* **I voluntarily consent to the capsule endoscopy procedure**: Select "Yes, I consent" to confirm your understanding and consent.
