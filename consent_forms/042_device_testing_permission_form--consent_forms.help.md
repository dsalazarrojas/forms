# Device Testing Permission Form - Help Guide
## Purpose
This form is used to collect information from participants for device testing purposes.

## How To Complete This Form
To complete this form, follow these steps:
1. Enter the participant's details, including name, email, and phone number.
2. Specify the date when the testing will start and end.
3. Provide a brief description of the testing device.
4. Fill out the consent date and confirm that you have obtained the participant's consent.

## Field-by-Field Explanation
* **Device Testing Permission** (`device_testing_permission`, text, required): This field is used to confirm that you have obtained the participant's consent for device testing.
* **Participant Details** (`participant_details`, text, required): Enter the participant's details, including name, email, and phone number.
* **Consent Date** (`consent_date`, date, required): Enter the date you obtained the participant's consent for device testing.
* **Testing Device Details** (`testing_device_details`, text, required): Provide a brief description of the testing device being used.
* **Testing Start Date** (`testing_start_date`, date, required): Enter the start date of the testing period.
* **Testing End Date** (`testing_end_date`, date, required): Enter the end date of the testing period.
* **Participant Name** (`participant_name`, text, required): Enter the participant's name.
* **Participant Email** (`participant_email`, email, required): Enter the participant's email address.
* **Participant Phone** (`participant_phone`, text, required): Enter the participant's phone number.
* **Participant Address** (`participant_address`, text, required): Enter the participant's address.
