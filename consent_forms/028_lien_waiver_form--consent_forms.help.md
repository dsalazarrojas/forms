# Lien Waiver Form - Help Guide

## Purpose
This form is used to record liens or releases on contracts between contractors and owners. 

## How To Complete This Form

To complete this form, please follow these steps:

1. **Fill out the form sections**:
	* Each section has a specific purpose and should be filled out accordingly. Make sure to provide accurate information for each field.
	* Some fields are marked as required, indicating that they must be completed to submit the form.

## Field-by-Field Explanation

### 1. **Contractor Name**
	* **Contractor Name (contractor_name)**: Enter the name of the contractor performing the work.
	* Required: false
	* Type: text

### 2. **Owner Name**
	* **Owner Name (owner_name)**: Enter the name of the owner of the property or entity receiving the work.
	* Required: true
	* Type: text

### 3. **Contact Number**
	* **Contact Number (contact_number)**: Enter the contact number of the owner or entity receiving the work.
	* Required: true
	* Type: text

### 4. **Contract Value**
	* **Contract Value (contract_value)**: Enter the value of the contract between the contractor and the owner.
	* Required: true
	* Type: number

### 5. **Lien Amount**
	* **Lien Amount (lien_amount)**: Enter the amount of the lien to be recorded.
	* Required: true
	* Type: number

### 6. **Lien Date**
	* **Lien Date (lien_date)**: Enter the date the lien was recorded or will be recorded.
	* Required: true
	* Type: date

### 7. **Waiver Text**
	* **Waiver Text (waiver_text)**: Enter any additional text or notes related to the lien or release.
	* Required: false
	* Type: note

### 8. **Owner Signature**
	* **Owner Signature (owner_signature)**: The owner must sign and date this form to acknowledge the lien or release.
	* Required: true
	* Type: text

### 9. **Contractor Signature**
	* **Contractor Signature (contractor_signature)**: The contractor must sign and date this form to acknowledge the lien or release.
	* Required: true
	* Type: text

### 10. **Lien Status**
	* **Lien Status (lien_status)**: Choose the status of the lien or release, either "Active" or "Inactive".
	* Required: true
	* Type: select_one

### 11. **Lien Status (lien_status_options)**
	* **Lien Status Options:**
		+ Active
		+ Inactive

### 12. **Owner Address 1**
	* **Owner Address 1 (owner_address_1)**: Enter the owner's street address, including house number.
	* Required: true
	* Type: text

### 13. **Owner Address 2**
	* **Owner Address 2 (owner_address_2)**: Enter any additional address information, such as apartment number or suite number.
	* Required: true
	* Type: text

### 14. **Owner City**
	* **Owner City (owner_city)**: Enter the city where the owner's address is located.
	* Required: true
	* Type: text

### 15. **Owner State**
	* **Owner State (owner_state)**: Enter the state where the owner's address is located.
	* Required: true
	* Type: text

### 16. **Owner Zip**
	* **Owner Zip (owner_zip)**: Enter the zip code for the owner's address.
	* Required: true
	* Type: text

### 17. **Contractor Address 1**
	* **Contractor Address 1 (contractor_address_1)**: Enter the contractor's street address.
	* Required: true
	* Type: text

### 18. **Contractor Address 2**
	* **Contractor Address 2 (contractor_address_2)**: Enter any additional address information, such as apartment number or suite number.
	* Required: true
	* Type: text

### 19. **Contractor City**
	* **Contractor City (contractor_city)**: Enter the city where the contractor's address is located.
	* Required: true
	* Type: text

### 20. **Contractor State**
	* **Contractor State (contractor_state)**: Enter the state where the contractor's address is located.
	* Required: true
	* Type: text

### 21. **Contractor Zip**
	* **Contractor Zip (contractor_zip)**: Enter the zip code for the contractor's address.
	* Required: true
	* Type: text

### 22. **Date Submitted**
	* **Date Submitted (date_submitted)**: Enter the date the form was submitted.
	* Required: false
	* Type: date

### 23. **Time Submitted**
	* **Time Submitted (time_submitted)**: Enter the time the form was submitted.
	* Required: false
	* Type: time

### 24. **Lien Submitted**
	* **Lien Submitted (lien_submitted)**: Choose whether the lien was submitted or not.
	* Required: false
	* Type: select_one

### 25. **Lien Submitted (lien_submitted_options)**
	* **Lien Submitted Options:**
		+ Yes
		+ No

## Tips
* Make sure to fill out the form accurately and completely.
* Double-check the form before submitting to ensure all required fields are completed.
* If you have any questions or need assistance, contact us.
* Save a copy of the completed form for your records.
