# needle_aspirate_treatment_plan--consent_forms - Help Guide

## Purpose
The needle aspirate treatment plan consent form is designed to collect relevant information for patients who have undergone or will undergo a needle aspirate procedure. It is essential to understand that this form should only be filled out by a medical professional.

## How To Complete This Form

To complete this form, follow these steps:

1.  Review the form carefully and understand the purpose and requirements.
2.  Ensure you are a qualified medical professional before filling out the form.
3.  Enter the relevant information in each field as it applies to the patient's case.
4.  Make sure to sign and date the form when it's complete.

## Field-by-Field Explanation
* **Practice** (`practice`, `text`, required: false): This field should be used for the patient's practice information.
* **Patient** (`patient_info`, `text`, required: false): Enter the patient's information such as name, date of birth, and contact number.
* **Prophets** (`prophets`, `select_multiple`, required: false): This field allows you to select multiple prophets relevant to the patient's case.
*   - Option 1, Option 2, and Option 3 are available choices for this field.
* **Follow-up Plans** (`follow_up_plans`, `note`, required: false): Use this field to note any follow-up plans for the patient.
* **Procedure Date** (`procedure_date`, `date`, required: false): Enter the date of the procedure.
* **Follow-up Procedure Date** (`follow_up_procedure_date`, `date`, required: false): Enter the date of the follow-up procedure.
* **Follow-up Plan** (`follow_up_plan`, `note`, required: false): This field is for any additional follow-up plans.
* **Procedure Time** (`procedure_time`, `time`, required: false): Enter the time of the procedure.
* **Follow-up Time** (`follow_up_time`, `time`, required: false): Enter the time of the follow-up procedure.
* **Doctor** (`procedure_doctor`, `text`, required: false): Enter the name of the doctor involved in the procedure.
* **Follow-up Doctor** (`follow_up_doctor`, `text`, required: false): This field is for the follow-up doctor's information.
* **Follow-up Status** (`follow_up_status`, `select_one`, required: false): Select the status of the follow-up procedure.
*   - Option 1, Option 2, and Option 3 are available choices for this field.
* **Follow-up Notes** (`follow_up_notes`, `note`, required: false): Use this field for any additional follow-up notes.
* **Follow-up Procedure Notes** (`follow_up_procedure_notes`, `note`, required: false): Enter any notes about the follow-up procedure.
* **Follow-up Doctor Notes** (`follow_up_doctor_notes`, `note`, required: false): This field is for the follow-up doctor's notes.
* **Follow-up Contact** (`follow_up_contact`, `text`, required: false): Enter the contact information for the follow-up appointment.
* **Follow-up Contact Method** (`follow_up_contact_method`, `select_one`, required: false): Select the method of contact for the follow-up.
*   - Option 1, Option 2, and Option 3 are available choices for this field.
* **Follow-up Procedure Method** (`follow_up_procedure_method`, `select_one`, required: false): Select the method of the follow-up procedure.
*   - Option 1, Option 2, and Option 3 are available choices for this field.
* **Follow-up Procedure Location** (`follow_up_procedure_location`, `select_one`, required: false): Select the location of the follow-up procedure.
*   - Option 1, Option 2, and Option 3 are available choices for this field.
* **Follow-up Status** (`follow_up_status`, `select_one`, required: false): Select the status of the follow-up procedure.
*   - Option 1, Option 2, and Option 3 are available choices for this field.
* **Follow-up Procedure** (`follow_up_procedure`, `select_multiple`, required: false): Select whether a follow-up procedure is needed.
*   - Option 1 and Option 2 are available choices for this field.
* **Follow-up Procedure Type** (`follow_up_procedure_type`, `select_multiple`, required: false): Select the type of follow-up procedure.
*   - Option 1 and Option 2 are available choices for this field.
* **Follow-up Procedure Status** (`follow_up_procedure_status`, `select_multiple`, required: false): Select the status of the follow-up procedure.
*   - Option 1 and Option 2 are available choices for this field.
* **Follow-up Last Prophets** (`follow_up_last_prophets`, `text`, required: false): Enter any last prothets information.
* **Follow-up Last Procedure Date** (`follow_up_last_procedure_date`, `date`, required: false): Enter the last procedure date.
