# Toothbrushing Program Registration - Help Guide
## Purpose
The Toothbrushing Program Registration form is used to enroll students in the Toothbrushing Program, a likely educational or health initiative.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the School Name in the first field.
2. Enter the Student Name in the second field.
3. Enter the Parent Name in the third field.
4. Enter the student's Email in the fourth field.
5. (Optional) Enter the student's Phone Number in the fifth field.
6. Enter the Enrollment Date in the sixth field.
7. Enter the Program Start Date in the seventh field.
8. (Optional) Enter the Program End Date in the eighth field.

## Field-by-Field Explanation
* **School Name** (School Name, text, required): Enter the name of the school the student attends.
* **Student Name** (Student Name, text, required): Enter the student's name.
* **Parent Name** (Parent Name, text, required): Enter the parent or guardian's name.
* **Email** (Email, email, required): Enter the student's email address.
* **Phone Number** (Phone Number, text, optional): Enter the student's phone number (if available).
* **Enrollment Date** (Enrollment Date, date, required): Enter the date the student enrolled in the Toothbrushing Program.
* **Program Start Date** (Program Start Date, date, required): Enter the date the program started.
* **Program End Date** (Program End Date, date, optional): Enter the date the program ended (if applicable).

## Tips
* Make sure to enter accurate and up-to-date information for each field.
* Double-check for any errors before submitting the form.
