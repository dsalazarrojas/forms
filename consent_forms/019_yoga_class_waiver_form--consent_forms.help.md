# Yoga Class Waiver Form - Help Guide

## Purpose
This form is designed to gather essential information from participants before attending a yoga class. The purpose of this form is to ensure that the participant has provided their necessary medical history, consent to participate, and emergency contact information. This form is a requirement for all participants to fill out before attending the yoga class.

## How To Complete This Form
1. Please fill out the form completely and accurately. Ensure that you have provided all the required information.
2. For medical history, select all the conditions that apply to you. If you have no medical conditions, select "No Medical Conditions" in the Medical Conditions field.
3. For consent, select "Yes" to confirm that you have read and understand the risks associated with participating in the yoga class.
4. Enter your emergency contact information, including name and phone number.
5. Enter your date of birth and preferred class start time.

## Field-by-Field Explanation

* **Participant Information** (`participant_info`, text, optional): Please enter your name and any other information you would like to share with the instructor.
* **Medical History** (`medical_history`, text, required): This field is where you will list any medical conditions that you have, such as Arthritis, Back Pain, etc. If you have no medical conditions, select "No Medical Conditions".
* **Medical Conditions** (`medical_condition`, select_multiple, required): Please select all the medical conditions that apply to you from the provided list.
* **Consent** (`consent`, select_one, required): Please select "Yes" to confirm that you have read and understand the risks associated with participating in the yoga class.
* **Notes** (`notes`, note, optional): If you have any additional information you would like to share with the instructor, please enter it here.
* **Email** (`email`, email, optional): Please enter your email address if you would like to receive communication from us.
* **Phone Number** (`phone_number`, text, optional): Please enter your phone number if you would like to be contacted.
* **Emergency Contact** (`emergency_contact`, text, optional): Please enter the name of your emergency contact person.
* **Emergency Contact Name** (`emergency_name`, text, optional): Please enter the name of your emergency contact person.
* **Emergency Phone Number** (`emergency_phone`, text, optional): Please enter the phone number of your emergency contact person.
* **Date of Birth** (`date_of_birth`, date, required): Please enter your date of birth in the format MM/DD/YYYY.
* **Time** (`time`, time, optional): Please select your preferred class start time from the provided options.
* **Instructor** (`instructor`, select_one, optional): Please select the instructor you would like to attend the class with.
* **Class Start Time** (`class_start_time`, time, required): Please select your preferred class start time.
* **Class End Time** (`class_end_time`, time, optional): Please select the end time of your class.

Please note that all fields marked as "required" are necessary to complete this form. If you are unsure about any field, please consult the instructor or contact us for assistance.
