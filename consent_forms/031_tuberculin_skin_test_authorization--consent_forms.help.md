# Tuberculin Skin Test Authorization - Help Guide
## Purpose
The Tuberculin Skin Test Authorization form is used to gather patient information for tuberculin skin testing. This form is essential for verifying patient consent, identifying the test site, and tracking test results.

## How To Complete This Form
1. Please ensure you are using the correct patient information.
2. Complete the form carefully, as it will be reviewed by healthcare staff.
3. Select the correct contact preference and healthcare provider name.
4. Choose the correct test site and test type.
5. Enter the date of birth and date of test.
6. Check the test results and enter any relevant comments.
7. Confirm that you have received consent from the patient.

## Field-by-Field Explanation
* **Patient Consent** (`patient_consent`, `note`, not required): Please provide the patient's consent, indicating that they are willing to undergo the tuberculin skin test.
* **Name** (`name`, `text`, not required): Enter the patient's name.
* **Date of Birth** (`date_of_birth`, `date`, not required): Enter the patient's date of birth.
* **Contact Preference** (`contact_preference`, `select_multiple`, not required): Select the patient's preferred method of contact.
*   *Option 1: Phone*
*   *Option 2: Email*
*   *Option 3: Mail*
* **Healthcare Provider Name** (`healthcare_provider_name`, `text`, not required): Enter the name of the healthcare provider.
* **Healthcare Provider Address** (`healthcare_provider_address`, `text`, not required): Enter the address of the healthcare provider.
* **Clinic Name** (`clinic_name`, `text`, not required): Enter the name of the clinic.
* **Date of Test** (`date_of_test`, `date`, not required): Enter the date of the tuberculin skin test.
* **Test Site** (`test_site`, `select_one`, not required): Select the site where the test was conducted.
*   *Option 1: Site 1*
*   *Option 2: Site 2*
*   *Option 3: Site 3*
* **Test Type** (`test_type`, `select_one`, not required): Select the type of test conducted.
*   *Option 1: Type 1*
*   *Option 2: Type 2*
*   *Option 3: Type 3*
* **Test Results** (`test_results`, `select_multiple`, not required): Select the test results.
*   *Option 1: Result 1*
*   *Option 2: Result 2*
*   *Option 3: Result 3*
* **Consent Given** (`consent_given`, `select_one`, not required): Select the patient's consent status.
*   *Option 1: Given*
*   *Option 2: Not Given*
* **Test Site Comments** (`test_site_comments`, `text`, not required): Enter any comments about the test site.

## Tips
* Double-check all fields before submitting the form.
* Ensure that the patient's contact preference and healthcare provider information are accurate.
* Select the correct test site and test type.
* Enter the correct date of test and test results.
