# Fencing Permit Form - Help Guide
## Purpose
The Fencing Permit Form is used to collect information for a new fencing permit application. It is intended for the property owner or their representative to fill out the form accurately and completely.

## How To Complete This Form
To complete this form, please follow these steps:

1.  Start by filling out the first page, "Applicant Details", with your or your representative's information.
2.  Move on to the "Contact Information" page, where you can provide your contact details.
3.  On the "Property Details" page, enter the relevant details about the property.
4.  In the "Property Owner" field, type the name of the property owner or yourself if you are the owner.
5.  Choose the property use type from the options provided (e.g. Single Family: Residential, Single Family: Commercial, etc.).
6.  Select all the relevant permit types (e.g. Fence Permit, Accessory Building Permit, etc.).
7.  If you are applying for a "Other: Specify" permit type, enter a brief description in the "Permit Location" field.
8.  Enter the size of the permit in the "Permit Size" field.
9.  Finally, provide any additional details or comments about the application in the "Submitter Details" field.

## Field-by-Field Explanation

* **Applicant Details**: 
  This page is for your information and contact details.
  Please fill it out accurately and completely.
  If you are representing the property owner, please make sure to include their name and contact information.
* **Contact Information**: 
  Enter your name, address, phone number, and email address.
  This information will be used for communication purposes.
* **Property Details**: 
  Provide details about the property, including its address and any other relevant information.
  This will help the local government process the permit application.
* **Property Owner**: 
  If you are not the property owner, type the name of the property owner.
  This is a required field for property information.
* **Property Use**: 
  Choose the property use type from the provided options.
  This information will help the local government determine the type of permit needed.
* **Permit Type**: 
  Select all the relevant permit types (e.g. Fence Permit, Accessory Building Permit, etc.).
  If you are applying for a "Other: Specify" permit type, enter a brief description in the "Permit Location" field.
* **Permit Location**: 
  Provide a brief description of the location where the permit is to be used.
  This is only required if you selected "Other: Specify" as the permit type.
* **Permit Size**: 
  Enter the size of the permit in the provided format.
  This information will help the local government process the permit application.
* **Submitter Details**: 
  Provide any additional details or comments about the application.
  This information will help the local government process your application.
