# Property Entry Keycard Activation Consent Form - Help Guide

## Purpose
The Property Entry Keycard Activation Consent Form is used to obtain consent from property owners for the activation of the keycard system. This form is required to ensure that the property owner is aware and agrees to the activation of the keycard system, which is used for secure entry and exit control.

## How To Complete This Form
To complete this form, please follow these steps:

1. Answer the questions on each page as accurately as possible.
2. If you are the property owner, please select "True" for the questions on pages 2 and 4.
3. If you are not the property owner, please select "False" for the questions on pages 2 and 4.
4. Enter the property address on page 1.
5. Enter the access card number on page 3, if applicable.
6. Select the activation date and time on page 5, if applicable.

## Field-by-Field Explanation

* **What is your property address** (`property_entry_keycard_activation_consent_form_1`, text, required):
    This field is used to collect the property's address. Please enter the complete address of the property.
* **Are you the property owner** (`property_entry_keycard_activation_consent_form_2`, select_one, required):
    This field is used to determine if you are the property owner. Please select "True" if you are the owner, and "False" otherwise.
* **What is the access card number** (`property_entry_keycard_activation_consent_form_3`, text, required):
    This field is used to collect the access card number, if applicable. Please enter the access card number if you have one.
* **Are you authorized to activate** (`property_entry_keycard_activation_consent_form_4`, select_one, required):
    This field is used to confirm that you are authorized to activate the keycard system. Please select "True" if you are authorized, and "False" otherwise.
* **What is the activation date and time** (`property_entry_keycard_activation_consent_form_5`, date, required):
    This field is used to collect the date and time of activation. Please select the activation date and time from the calendar.

## Tips
* Please ensure that you are filling out the form accurately and truthfully.
* If you are not sure about any of the questions, please contact the relevant authorities or seek clarification.
* Please review the form carefully before submitting it.
