# Smart Surveillance Feed Access Consent Form - Help Guide
## Purpose
The Smart Surveillance Feed Access Consent Form is used to obtain consent from users for accessing various surveillance feeds. This form is typically used in situations where users need to access surveillance feeds for security, monitoring, or other purposes. 

## How To Complete This Form
To complete this form, please follow these steps:
1. Fill in your information as prompted.
2. Select the type of surveillance feed you want to access from the "What type of surveillance feeds do you want to access?" dropdown list.
3. For "What video feed do you want to access?", select all relevant video feeds that you need to access.
4. If you wish to access the feed for a specific duration, choose the "How long would you like to access the surveillance feed for?" option and select a time period.
5. If necessary, select the start and end times for your access period.
6. Provide a date for your access to the surveillance feed.
7. Enter your email address and/or phone number for contact information.

## Field-by-Field Explanation

* **Consent Form** (<label> `Consent Form`, <type> `text`, optional): This is a text field where you can enter any additional comments or information regarding your consent.
* **What type of surveillance feeds do you want to access?** (<label> `Surveillance feed 1`, <type> `select_one`, required): Choose one of the available options from the dropdown list to select the type of surveillance feed you want to access.
* **What video feed do you want to access?** (<label> `What video feed do you want to access?`, <type> `select_multiple`, optional): Select all relevant video feeds that you need to access.
* **How long would you like to access the surveillance feed for?** (<label> `How long would you like to access the surveillance feed for?`, <type> `time`, optional): If you wish to access the feed for a specific duration, choose one of the available time periods.
* **Start Time** (<label> `Start Time`, <type> `time`, optional): If you need to access the feed from a specific start time, select the time you wish to start.
* **End Time** (<label> `End Time`, <type> `time`, optional): If you need to access the feed until a specific end time, select the time you wish to end.
* **Date of Access** (<label> `Date of Access`, <type> `date`, optional): Enter the date you wish to access the surveillance feed.
* **Email Address** (<label> `Email Address`, <type> `email`, optional): Enter your email address for contact information.
* **Phone Number** (<label> `Phone Number`, <type> `text`, optional): Enter your phone number for contact information.
