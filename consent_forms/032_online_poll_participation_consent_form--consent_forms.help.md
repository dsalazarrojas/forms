# Online Poll Participation Consent Form - Help Guide
## Purpose
The Online Poll Participation Consent Form is used to collect participant consent for online polls. The form is designed to gather information about the participant's personal details, which will be used to verify their identity and ensure a unique and accurate representation of the poll results.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the required information:
	* First name
	* Email
	* Phone number
2. Check the boxes to indicate:
	* If you have a participant ID
	* If you have a first name
	* If you have an email
	* If you have a phone number
3. If you have a participant ID, select the type of participant ID you have:
	* Yes (for a valid participant ID)
	* No (if you don't have a participant ID)
4. If you have a first name, select the type of first name you have:
	* Yes (for a valid first name)
	* No (if you don't have a first name)
5. If you have an email, select the type of email you have:
	* Yes (for a valid email)
	* No (if you don't have an email)
6. If you have a phone number, select the type of phone number you have:
	* Yes (for a valid phone number)
	* No (if you don't have a phone number)

## Field-by-Field Explanation

* **First Name** (`first_name`, text, required): Enter your first name as it appears on your identification documents.
* **Email** (`email`, email, required): Enter your email address as it appears on your identification documents.
* **Phone Number** (`phone_number`, text, required): Enter your phone number as it appears on your identification documents.
* **Participant ID** (`participant_id`, number, optional): Enter your participant ID if you have one.
* **Do You Consent** (`consent`, select_one, required): Check yes if you agree to participate in the poll and provide your information.
* **Additional Comments** (`additional_comments`, text, optional): If you have any additional comments or information, enter them here.
* **Has Additional Info** (`has_additional_info`, select_one, optional): Check yes if you have additional information.
* **Additional Info** (`additional_info`, text, optional): Enter your additional information.
* **Has Participant ID** (`has_participant_id`, select_one, optional): Check yes if you have a participant ID.
* **Participant ID Type** (`participant_id_type`, select_one, optional): Select the type of participant ID you have.
* **Has First Name** (`has_first_name`, select_one, optional): Check yes if you have a first name.
* **First Name Type** (`first_name_type`, select_one, optional): Select the type of first name you have.
* **Has Email** (`has_email`, select_one, optional): Check yes if you have an email.
* **Email Type** (`email_type`, select_one, optional): Select the type of email you have.
* **Has Phone Number** (`has_phone_number`, select_one, optional): Check yes if you have a phone number.
* **Phone Number Type** (`phone_number_type`, select_one, optional): Select the type of phone number you have.
* **Has Participant ID 2** (`has_participant_id_2`, select_one, optional): Check yes if you have another participant ID.
* **Participant ID Type 2** (`participant_id_type_2`, select_one, optional): Select the type of participant ID you have.
* **Has First Name 2** (`has_first_name_2`, select_one, optional): Check yes if you have another first name.
* **First Name Type 2** (`first_name_type_2`, select_one, optional): Select the type of first name you have.
* **Has Email 2** (`has_email_2`, select_one, optional): Check yes if you have another email.
* **Email Type 2** (`email_type_2`, select_one, optional): Select the type of email you have.
* **Has Phone Number 2** (`has_phone_number_2`, select_one, optional): Check yes if you have another phone number.
* **Participant ID Type 3** (`participant_id_type_3`, select_one, optional): Select the type of participant ID you have.

## Tips

* Make sure to enter accurate and up-to-date information.
* Check the boxes carefully to ensure you're providing the correct information.
* If you're unsure about any of the fields, ask your administrator for assistance.
