# cruise_parental_consent_form - Help Guide

## Purpose
This form is for obtaining parental consent for children's travel. It is designed to collect information about a child's travel plans and ensure that parents or guardians are aware of and approve of the arrangements.

## How To Complete This Form
To complete this form, follow these steps:

1. Review each field carefully and fill in the required information.
2. Make sure to select the correct options for "Consent to Travel" as per the travel arrangements.

## Field-by-Field Explanation
* **cruise_parental_consent_form_1** (Text Field)
	+ This is the label for the first page of the form, which is a text field that allows you to add any additional information about the form.
* **consent_to_travel** (Select One Field)
	+ Select the correct option for consent to travel:
		- '1' = Yes, with an adult
		- '2' = Yes, without an adult
		- '3' = No
* **parent_name** (Text Field)
	+ Enter the name of the parent or guardian providing consent.
* **travel_date** (Date Field)
	+ Enter the date of the travel.
* **travel_time** (Time Field)
	+ Enter the time of the travel.

## Tips
- Make sure to review the information carefully before submitting the form.
- If you are unsure about any of the fields, please contact the relevant authorities for clarification.
- This form is for informational purposes only and is not a substitute for actual parental consent.
