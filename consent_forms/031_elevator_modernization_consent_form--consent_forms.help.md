# Elevator Modernization Consent Form - Help Guide
## Purpose

The purpose of this form is to collect information and consent for elevator modernization projects.

## How To Complete This Form

1.  Fill out this form to document and track the progress, details, and outcomes of elevator modernization projects.
2.  Ensure that all fields are completed accurately and thoroughly.
3.  If a field is not applicable, please mark it as "No" or "N/A" accordingly.

## Field-by-Field Explanation

*   **Form Title** (`form_title`, text, not required): This field is used to title the form and identify the project.
*   **Page 1** (`page_1`, select_one, not required): This field asks whether the project involves the modernization of an elevator. Please select "Yes" if the project includes elevator modernization, and "No" otherwise.
*   **Page 1 Label** (`page_1_label`, text, not required): This field is used to describe the elevator that is being modernized. Please provide a brief but detailed explanation.
*   **Form Description** (`form_description`, note, not required): This field is used to provide a brief description of the form and its purpose.
*   **Category** (`category`, select_multiple, not required): This field is used to select relevant categories for the project. Please choose all applicable categories.
*   **Page 2** (`page_2`, select_one, not required): This field asks whether the project involves the modernization of multiple elevators. Please select "Yes" if the project includes multiple elevators, and "No" otherwise.
*   **Page 2 Label** (`page_2_label`, text, not required): This field is used to describe the elevators that are being modernized. Please provide a brief but detailed explanation.
*   **Form Category** (`form_category`, text, not required): This field is used to select the category of the form. Please type in the relevant category.
*   **Description** (`description`, text, not required): This field is used to provide a detailed description of the project.
*   **Output File** (`output_file`, text, not required): This field is used to specify the output file for the project.
*   **Assigned Tool** (`assigned_tool`, text, not required): This field is used to specify the tool assigned to the project.
*   **Form Version** (`form_version`, number, not required): This field is used to track the version of the form.

## Tips

*   Please ensure that all fields are completed accurately and thoroughly.
*   If you're unsure about any aspect of the form, please consult with your supervisor or relevant authorities within the organization.
*   Please fill out this form with the necessary permissions and access.
