# Property Management System API Consent Form - Help Guide

## Purpose
This form is used to obtain consent from clients for the Property Management System API. It is a crucial step in the client onboarding process, ensuring that clients are aware and agree to the terms of using the API.

## How To Complete This Form

1. To complete this form, please provide the required information for your Property Management System API access.
2. Fill in the form fields as instructed below.

## Field-by-Field Explanation

* **Property Management System API Consent Form** (`form_title`, text, required): Enter the title of the form. This will be the heading of the form. (Please enter "Property Management System API Consent Form")
* **Client Name** (`client_name`, text, required): Enter your company name or the name of the property management system you represent.
* **Client Email** (`client_email`, email, required): Enter your company email or the email of the property management system administrator.
* **Grant Consent** (`consent_grantor`, select_one, required): Select one of the options below to grant consent.
	+ Option 1: I understand and agree to the terms of using the API.
	+ Option 2: I do not understand the terms of using the API, please provide more information.
	+ Option 3: I do not agree to the terms of using the API.
* **Connection Details** (`connection_details`, text, optional): Provide any additional connection details for our team to assist with API integration.
* **API Key** (`api_key`, text, optional): If you already have an API key, please provide it. Otherwise, our team will create one for you.

## Tips

* Please make sure to fill out all required fields before submitting the form.
* If you have any questions or concerns, contact our support team for assistance.
* Our team will review and follow up with you after submitting the form to finalize API access.
