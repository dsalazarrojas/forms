# Inheritance Release Form - Help Guide

## Purpose
The Inheritance Release Form is a document used to declare the inheritance of assets, claims, disputes, and other relevant information. It serves as a formal release of any potential claims or disputes related to the assets being inherited.

## How To Complete This Form

To complete this form, please follow these steps:

1. Read each field carefully to understand its purpose and relevance.
2. Provide accurate and truthful information for each field.
3. Ensure all required fields are completed before submitting the form.

## Field-by-Field Explanation

* **Asset Accepted** (`asset_accepted`, text, optional):
	+ A field to list any assets that have been accepted as part of the inheritance.
* **Claims Waived** (`claims_waived`, text, optional):
	+ A field to declare any claims that have been waived or relinquished as part of the inheritance.
* **Disputes Settled** (`disputes_settled`, text, optional):
	+ A field to record any disputes that have been settled or resolved as part of the inheritance.
* **Heir Agreement** (`heir_agreement`, text, optional):
	+ A field to describe any agreements or understanding reached by the heir regarding the inheritance.
* **Waiver** (`waiver`, text, optional):
	+ A field to acknowledge any waiver or release of liability related to the inheritance.
* **Asset Description** (`asset_description`, text, optional):
	+ A field to provide a detailed description of the assets being inherited.
* **Asset Value** (`asset_value`, text, optional):
	+ A field to list the value of the assets being inherited.
