# Gender Equity Panel Recording Consent Form - Help Guide
## Purpose
This form is a consent form for recording a Gender Equity Panel event. It collects information related to the event, such as the title, description, location, and dates, as well as the consent for recording (video, audio, and photo shoot) and contact details for the event organizers.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the title of the event in the `gender equity panel recording consent form title` field.
2. Select the category of the form from the `category` dropdown menu.
3. If necessary, provide a brief description of the event in the `description` field.
4. Choose the type of form from the `form type` dropdown menu.
5. Fill in the title of the event in the `event title` field.
6. Enter the start and end dates of the event using the `event start date` and `event end date` fields, respectively.
7. Enter the start and end times of the event using the `event start time` and `event end time` fields, respectively.
8. List the names of the speakers in the `speaker names` field.
9. List the titles of the speakers in the `speaker titles` field.
10. Fill in the location of the event in the `location` field.
11. Indicate whether video, audio, and photo shoot recording will be done during the event by selecting the corresponding options in the `video recording`, `audio recording`, and `photo shoot` fields.
12. Fill in the description of the event in the `event description` field.
13. Fill in the contact person's name, email, phone number, and organization in the `contact person`, `contact email`, `contact phone`, and `contact organization` fields, respectively.
14. Fill in the contact person's title in the `contact title` field.
15. Fill in the status and date of the event in the `event status` and `event status date` fields, respectively.

## Field-by-Field Explanation
* **gender equity panel recording consent form title** (`title`, text, required/optional): This field is the title of the form, which should be filled in with the title of the event.
* **category** (`category`, select_one, optional): This field allows you to select the category of the form, which should be set to "Consent Forms" or "Recording Consent Forms".
* **description** (`description`, text, optional): This field is for providing a brief description of the event, if necessary.
* **form type** (`form type`, select_multiple, optional): This field allows you to choose the type of form, which should be set to "Consent Forms" and "Recording Consent Forms".
* **event title** (`event title`, text, optional): This field is for filling in the title of the event.
* **event start date** (`event start date`, date, optional): This field is for filling in the start date of the event.
* **event start time** (`event start time`, time, optional): This field is for filling in the start time of the event.
* **event end date** (`event end date`, date, optional): This field is for filling in the end date of the event.
* **event end time** (`event end time`, time, optional): This field is for filling in the end time of the event.
* **speaker names** (`speaker names`, text, optional): This field is for listing the names of the speakers.
* **speaker titles** (`speaker titles`, text, optional): This field is for listing the titles of the speakers.
* **location** (`location`, text, optional): This field is for filling in the location of the event.
* **video recording** (`video recording`, select_one, optional): This field allows you to indicate whether video recording will be done during the event.
* **audio recording** (`audio recording`, select_one, optional): This field allows you to indicate whether audio recording will be done during the event.
* **photo shoot** (`photo shoot`, select_one, optional): This field allows you to indicate whether photo shoot will be done during the event.
* **live streaming** (`live streaming`, select_one, optional): This field allows you to indicate whether live streaming will be done during the event.
* **event description** (`event description`, text, optional): This field is for filling in the description of the event.
* **contact person** (`contact person`, text, optional): This field is for filling in the contact person's name.
* **contact email** (`contact email`, text, optional): This field is for filling in the contact person's email.
* **contact phone** (`contact phone`, text, optional): This field is for filling in the contact person's phone number.
* **contact organization** (`contact organization`, text, optional): This field is for filling in the contact person's organization.
* **contact title** (`contact title`, text, optional): This field is for filling in the contact person's title.
* **event status** (`event status`, text, optional): This field is for filling in the status of the event.
* **event status date** (`event status date`, date, optional): This field is for filling in the date of the event status.
