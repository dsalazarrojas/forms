# Game Character Demo Consent Form - Help Guide
## Purpose
The Game Character Demo Consent Form is designed to obtain consent from creators to use, display, and distribute their game character demos. This form is a crucial step in the game development process, ensuring that creators' rights are respected, and their work is used appropriately.

## How To Complete This Form
To complete this form, follow these steps:

1. Ensure you have all the necessary information about the game character demo, project, and event ready.
2. Fill in the form fields as accurately and thoroughly as possible.
3. Review each field carefully to ensure you understand its purpose and requirements.
4. Submit the form once you have completed and reviewed all the fields.

## Field-by-Field Explanation

* **Form ID** (`form_id`, number, optional): This is a unique identifier for the form. If you have multiple forms, use a different number for each one.
* **Creator Name** (`creator_name`, text, optional): Enter the name of the creator of the game character demo.
* **Creator Email** (`creator_email`, email, optional): Enter the email address of the creator.
* **Creator Phone** (`creator_phone`, text, optional): Enter the phone number of the creator.
* **Permission to Use** (`permission_to_use`, select_multiple, optional): Select all the permissions you grant for the use of your game character demo. Choose from the options: Permission to Use, Permission to Display, or Permission to Distribute.
* **Permission to Display** (`permission_to_display`, select_one, optional): Select the permission to display your game character demo. Choose from the options: Permission to Display, No Permission to Display.
* **Permission to Distribute** (`permission_to_distribute`, select_one, optional): Select the permission to distribute your game character demo. Choose from the options: Permission to Distribute, No Permission to Distribute.
* **Project Name** (`project_name`, text, optional): Enter the name of the project related to the game character demo.
* **Event Name** (`event_name`, text, optional): Enter the name of the event related to the game character demo.
* **Event Date** (`event_date`, date, optional): Enter the date of the event related to the game character demo.
* **Event Time** (`event_time`, time, optional): Enter the time of the event related to the game character demo.
* **Event Type** (`event_type`, text, optional): Enter the type of event related to the game character demo.
* **Event Description** (`event_description`, text, optional): Enter a description of the event related to the game character demo.
* **Showcase Name** (`showcase_name`, text, optional): Enter the name of the showcase related to the game character demo.
* **Showcase Date** (`showcase_date`, date, optional): Enter the date of the showcase related to the game character demo.
* **Showcase Time** (`showcase_time`, time, optional): Enter the time of the showcase related to the game character demo.
* **Showcase Type** (`showcase_type`, text, optional): Enter the type of showcase related to the game character demo.
* **Development Project Name** (`development_project_name`, text, optional): Enter the name of the development project related to the game character demo.
* **Development Project Status** (`development_project_status`, text, optional): Enter the status of the development project related to the game character demo.
* **Development Project Description** (`development_project_description`, text, optional): Enter a description of the development project related to the game character demo.
* **Creator Notes** (`creator_notes`, note, optional): Add any additional notes from the creator.
* **Project Distributor** (`project_distributor`, text, optional): Enter the project distributor's name.
* **Creator Agreement** (`creator_agreement`, text, optional): Enter the creator's agreement.
* **Submitter Agreement** (`submitter_agreement`, text, optional): Enter the submitter's agreement.
* **Submitter Signature** (`submitter_signature`, text, optional): Enter the submitter's signature.

Please note that some fields are optional, but it's essential to fill in all the required fields accurately and thoroughly to ensure the form is complete and submitted correctly.
