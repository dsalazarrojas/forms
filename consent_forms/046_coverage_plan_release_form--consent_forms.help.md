# Coverage Plan Release Form - Help Guide
## Purpose
This form is used to collect information for the release of a coverage plan. It is used to gather necessary details for the coverage plan release process.

## How To Complete This Form
1. Select all that apply from "Coverage Plan Release Form 1" to identify relevant coverage plan sections.
2. If "Other" is selected, provide the specific reason for releasing the coverage plan in the "reason_for_release" field.
3. Enter the release date and time of the coverage plan in the respective fields.
4. Enter the insurance number without dashes, if available.
5. Enter the coverage plan name as per company records in the "coverage_plan_name" field.
6. Enter the coverage plan ID as per company records in the "coverage_plan_id" field.
7. Enter the reason for releasing the coverage plan in the "reason_for_release" field.
8. Provide any additional comments about the release in the "comments" field.

## Field-by-Field Explanation

* **coverage_plan_release_form** (Select all that apply, Optional): Select the coverage plan sections that need to be released.
* **release_reason** (Select one, Optional): Select the reason for releasing the coverage plan. If "Other" is selected, provide the specific reason in the "reason_for_release" field.
* **release_date** (Date, Optional): Enter the date of releasing the coverage plan.
* **release_time** (Time, Optional): Enter the time of releasing the coverage plan.
* **insurance_number** (Text, Optional): Enter insurance number without dashes.
* **coverage_plan_name** (Text, Optional): Enter Coverage Plan name as per company records.
* **coverage_plan_id** (Text, Optional): Enter Coverage Plan ID as per company records.
* **reason_for_release** (Text, Optional): Enter the reason for releasing the coverage plan.
* **comments** (Text, Optional): Enter any additional comments about the release.
* **release_date2** (Date, Optional): Enter the release date.
* **release_time2** (Time, Optional): Enter the release time.
* **coverage_plan_release_form2** (Select multiple, Optional): Select all that apply from "Coverage Plan Release Form 2" to identify relevant coverage plan sections.
* **release_reason2** (Select one, Optional): Select the reason for releasing the coverage plan. If "Other" is selected, provide the specific reason in the "reason_for_release2" field.
* **release_date3** (Date, Optional): Enter the release date.
* **release_time3** (Time, Optional): Enter the release time.
* **coverage_plan_name2** (Text, Optional): Enter Coverage Plan name as per company records.
* **coverage_plan_id2** (Text, Optional): Enter Coverage Plan ID as per company records.
* **reason_for_release2** (Text, Optional): Enter the reason for releasing the coverage plan.
* **comments2** (Text, Optional): Enter any additional comments about the release.
