# visual_art_creation_footage_consent_form - Help Guide
## Purpose
The purpose of this form is to collect the necessary information to obtain consent from artists to use their visual art creation footage.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill in your Artist Name and Email (if applicable)
2. Provide your Contact Number (if applicable)
3. Enter the Project Details
4. Describe the Footage you are submitting
5. Specify the Footage Capture Method
6. Select the type of consent you are giving
7. If necessary, specify a Release Date and Expiration Date
8. Add any Notes or comments (if necessary)

## Field-by-Field Explanation
* **Artist Name (1)** (`text`, required): Enter your name as the artist submitting the visual art creation footage.
* **Email (2)** (`email`, optional): If you have an email address associated with your artist name, enter it here. This will help us contact you if we need to discuss any further details.
* **Contact Number (3)** (`text`, optional): If you have a contact number associated with your artist name, enter it here. This will help us contact you if we need to discuss any further details.
* **Project Details (4)** (`text`, required): Enter a brief description of the project you are submitting the footage for.
* **Footage Description (5)** (`text`, optional): Enter a description of the footage you are submitting. This can be as short or as long as you like.
* **Footage Capture Method (6)** (`select_one`, optional): Select the method used to capture the footage, such as Photo, Video, Drawings/Sketches, or 3D Model.
* **Consent (7)** (`select_multiple`, optional): Select the types of media you are giving consent to use, such as Photo, Video, Drawings/Sketches, or 3D Model.
* **Release Date (8)** (`date`, optional): If you have a specific date in mind for when you would like to release the consent, enter it here.
* **Expiration Date (9)** (`date`, optional): If you have an expiration date in mind for the consent, enter it here.
* **Notes (10)** (`note`, optional): Add any additional comments or notes about the submission.

## Tips
* Ensure that you are providing accurate information about yourself and the project details.
* Make sure to clearly describe the footage you are submitting.
* Be specific about the types of media you are giving consent to use.
