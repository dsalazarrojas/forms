# Push Notification Consent Form - Help Guide
## Purpose
The "Push Notification Consent Form" is used to collect users' consent for receiving push notifications from a website or application. The form provides information about push notifications, including what they are, when they will be sent, and how they can be configured.

## How To Complete This Form
1. Click on the "Submit" button to save your consent preferences.
2. Select "Push notifications" to indicate your consent for receiving push notifications.
3. Choose how you want to be notified (in-app, email, SMS, or no notifications).
4. Select the frequency of push notifications (immediately, daily, weekly, or monthly).
5. Answer "Do you allow push notifications?" and "Consent to data collection" questions.
6. If you want to change your consent, select "True" and provide a reason in the "Why do you want to change your consent?" text field.

## Field-by-Field Explanation

* **Consent for Push Notifications** (2, select_one, required: false):
	+ This field allows you to select "Push notifications" to indicate your consent for receiving push notifications.
* **Consent Type** (3, select_multiple, required: false):
	+ This field allows you to choose how you want to be notified (in-app, website push notifications, email, or SMS and email notifications).
* **Push Notification Description** (4, text, required: false):
	+ This field is for a brief description of push notifications.
* **How do you want to be notied?** (5, select_one, required: false):
	+ This field allows you to choose how you want to be notified (in-app messages, email, SMS, or no notifications).
* **Push Notification Frequency** (6, select_one, required: false):
	+ This field allows you to select the frequency of push notifications (immediately, daily, weekly, or monthly).
* **Do you allow push notifications?** (7, select_one, required: false):
	+ This field is a yes or no question that asks if you allow push notifications.
* **Consent to data collection** (8, select_one, required: false):
	+ This field is a yes or no question that asks if you consent to data collection.
* **Do you want to change your consent?** (9, select_one, required: false):
	+ This field is a yes or no question that asks if you want to change your consent.
* **Why do you want to change your consent?** (10, text, required: false):
	+ This field is for providing a reason for changing your consent.
