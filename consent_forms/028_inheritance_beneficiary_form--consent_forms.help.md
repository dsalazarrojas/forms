# Inheritance Beneficiary Form - Help Guide

## Purpose
This form is used to collect information about an inheritance beneficiary, including details about the person inheriting the asset, the asset itself, and the contact information for the deceased or their representative.

## How To Complete This Form

1. Select the person inheriting the asset from the list of options under "Inheritance Beneficiary Person".
2. Enter the value of the asset in the "Asset Value" field. Please note that this field is not required if you have chosen "Other" under "Asset Type".
3. Provide a description of the asset in the "Asset Description" field, if applicable.
4. Choose the type of asset from the list of options under "Asset Type".
5. Select the relationship between the deceased and the inheritor from the list of options under "Relationship".
6. Enter the deceased's contact information in the "Deceased Contact" field, if applicable.
7. Enter the date of inheritance in the "Inheritance Date" field, if required.
8. Enter any additional information about the inheritance in the "Inheritance Info" field, if applicable.
9. Enter the contact person's name and contact information in the "Contact Person" and "Contact Info" fields, if applicable.
10. If the asset is of an "Other" type, enter its value and currency in the "Other Asset Value" and "Asset Value Currency" fields.

## Field-by-Field Explanation

* **Inheritance Beneficiary Person**: Select the person inheriting the asset from the list of options.
* **Asset Value**: Enter the value of the asset (e.g., $100,000).
* **Asset Description**: Provide a description of the asset (e.g., "House on Main St.").
* **Asset Type**: Choose the type of asset from the list of options (e.g., "Real Estate", "Cash", etc.).
* **Relationship**: Select the relationship between the deceased and the inheritor (e.g., "Child", "Spouse", etc.).
* **Deceased Info**: Provide any additional information about the deceased (e.g., date of death, cause of death, etc.).
* **Deceased Contact**: Enter the deceased's contact information (e.g., name, address, phone number, etc.).
* **Inheritance Date**: Enter the date of inheritance (if required).
* **Asset Location**: Enter the location of the asset (e.g., city, country, etc.).
* **Inheritance Info**: Provide any additional information about the inheritance (e.g., conditions of inheritance, etc.).
* **Contact Person**: Enter the name of the contact person for the deceased or their representative.
* **Contact Info**: Enter the contact person's contact information (e.g., name, address, phone number, etc.).
* **Asset Type Description**: Provide a description of the asset type (e.g., "Real Estate: House").
* **Other Asset Value**: Enter the value of the asset if it is of a non-standard type.
* **Asset Value Currency**: Select the currency of the asset value (e.g., USD, EUR, etc.).
* **Asset Value Amount**: Enter the value of the asset if it is of a non-standard type.
* **Inheritance Type**: Select the type of inheritance (e.g., "Will", "Trust", etc.).
* **Other Inheritance Info**: Provide any additional information about the inheritance (e.g., conditions of inheritance, etc.).
