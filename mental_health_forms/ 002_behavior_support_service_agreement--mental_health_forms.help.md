# Behavior Support Service Agreement - Help Guide

## Purpose
This guide is intended to help you complete the Behavior Support Service Agreement form accurately and efficiently. Please follow these steps to ensure you provide the required information.

## How To Complete This Form
1. **Personal Information**:
   - Enter your legal full name.
   - Provide a valid email address for contact purposes.
   - If you wish to be contacted, enter your phone number with an international dialing code if necessary.
   - Skip this field if it's not required.
2. **Date and Selection**:
   - Select the relevant date according to your needs.
   - Choose the primary selection from the options provided (Excellent, Good, Fair, Poor).
3. **Additional Information**:
   - If needed, provide any additional details relevant to your situation.
4. **Agreement**:
   - Select all that apply from the options provided.
5. **Estimated Value and Time**:
   - Enter an estimated value, using decimal format if applicable.
   - Enter a preferred time for scheduling, if required.
6. **Final Comments**:
   - Provide any final comments or notes if you have any.

## Field-by-Field Explanation
- **Full name**: Enter your legal full name accurately.
- **Email address**: Enter a valid email address for contact purposes.
- **Phone number**: Include the country code if you're outside the local region.
- **Date**: Select the date relevant to your situation.
- **Primary selection**: Choose the option (Excellent, Good, Fair, Poor) that best applies.
- **Quantity or rating**: Enter a whole number for quantity or rating.
- **Additional details**: Provide any additional relevant information about your behavior support service agreement.
- **Agreement**: Select any option that applies from the provided list.
- **Estimated value**: Enter the estimated value in decimal format when applicable.
- **Preferred time**: Enter a time for scheduling if necessary.
- **Final comments**: Provide any final comments or remarks if needed.
