# Intensive Therapy Interest Survey - Help Guide
## Purpose
The Intensive Therapy Interest Survey is a form designed to collect information from clients interested in intensive therapy sessions. This form helps us understand the client's goals, concerns, and availability for therapy sessions.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter your name and email address in the designated fields.
2. Select your top three goals for therapy in the "Goal 1" and "Goal 2" fields.
3. In the "Goal 3" field, you can select any additional goals that are not listed.
4. Choose any concerns that you are experiencing in the "Concern 1" and "Concern 2" fields.
5. In the "Concern 3" field, you can select any additional concerns that are not listed.
6. Indicate your availability for therapy sessions in the "Mon" to "Sun" fields.
7. Select your preferred start time for therapy sessions from the "Start Time" options.
8. Select your preferred end time for therapy sessions from the "End Time" options.
9. Click the "Submit" button to submit your responses.

## Field-by-Field Explanation

* **Client Name** (`client_name`, text, required): Enter your name.
* **Client Email** (`client_email`, email, required): Enter your email address.
* **Client Phone** (`client_phone`, text, optional): Enter your phone number (if applicable).
* **Goal 1** (`goal_1`, select_one, optional): Select the most important goal you have for therapy.
*   - Goal 1: Select this option if you are struggling with stress management.
*   - Goal 2: Select this option if you are dealing with anxiety or depression.
*   - Goal 3: Select this option if you are experiencing relationship issues.
* **Goal 2** (`goal_2`, select_multiple, optional): Select up to two additional goals you have for therapy.
* **Other Goal** (`other_goal`, text, optional): Enter any other goals you have for therapy (if not listed).
* **Concern 1** (`concern_1`, select_one, optional): Select the most pressing concern you are experiencing.
*   - Concern 1: Select this option if you are struggling with self-esteem issues.
*   - Concern 2: Select this option if you are dealing with relationship issues.
*   - Concern 3: Select this option if you are experiencing trauma or PTSD.
* **Concern 2** (`concern_2`, select_multiple, optional): Select up to two additional concerns you are experiencing.
* **Other Concern** (`other_concern`, text, optional): Enter any other concerns you are experiencing (if not listed).
* **Monday** (`weekday`, select_one, optional): Select the day you are available for therapy sessions.
*   - Monday: Select this option if you are available on Mondays.
*   - Tuesday: Select this option if you are available on Tuesdays.
*   - Wednesday: Select this option if you are available on Wednesdays.
*   - Thursday: Select this option if you are available on Thursdays.
*   - Friday: Select this option if you are available on Fridays.
*   - Saturday: Select this option if you are available on Saturdays.
*   - Sunday: Select this option if you are available on Sundays.
* **Start Time** (`start_time`, select_multiple, optional): Select your preferred start time for therapy sessions.
*   - 8:00 am: Select this option if you would like to start at 8:00 am.
*   - 9:00 am: Select this option if you would like to start at 9:00 am.
*   - 10:00 am: Select this option if you would like to start at 10:00 am.
*   - 11:00 am: Select this option if you would like to start at 11:00 am.
*   - 12:00 pm: Select this option if you would like to start at 12:00 pm.
*   - 1:00 pm: Select this option if you would like to start at 1:00 pm.
* **End Time** (`end_time`, select_multiple, optional): Select your preferred end time for therapy sessions.
*   - 8:00 am: Select this option if you would like to end at 8:00 am.
*   - 9:00 am: Select this option if you would like to end at 9:00 am.
*   - 10:00 am: Select this option if you would like to end at 10:00 am.
*   - 11:00 am: Select this option if you would like to end at 11:00 am.
*   - 12:00 pm: Select this option if you would like to end at 12:00 pm.
*   - 1:00 pm: Select this option if you would like to end at 1:00 pm.
* **Submit** (`submit`, text, required): Click this button to submit your responses.

## Tips

* Please answer the questions honestly and provide as much detail as possible.
* If you are completing this form for someone else, please ensure you have their consent to do so.
* If you have any questions or concerns, please contact us directly.
* We will review your responses and contact you to discuss further details about your therapy sessions.
