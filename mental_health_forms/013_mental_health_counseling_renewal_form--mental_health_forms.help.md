# mental_health_counseling_renewal_form - Help Guide
## Purpose
This form is a tool used to document and communicate client information for mental health service renewal purposes. It gathers essential details about the client and service provided. Please note that this form is meant for internal use only and should not be considered a contract for services.

## How To Complete This Form
To complete this form, follow these steps:
1. Enter your name and any other identifying information about the client (in the "Client Information" page).
2. Provide personal details about the client in the "Personal Info" page.
3. Enter the date the service started for the client in the "Service Start Date" page.
4. Enter the date the service ended for the client in the "Service End Date" page.
5. Confirm if the client has a mental health provider in the "Mental Health Provider" page.
6. Select the type of client relationship you have with the client in the "Client Relationship" page.
7. Choose the type of service provided in the "Service Type" page.
8. Optionally, add any additional notes about the client's status in the "Notes" page.

## Field-by-Field Explanation
* **Client Information** (`client_info`, text, required: false): Enter the client's name and any other identifying information.
* **Personal Info** (`personal_info`, text, required: false): Enter any relevant personal details about the client.
* **Service Info** (`service_info`, text, required: false): Enter any relevant details about the service provided.
* **Service Start Date** (`service_start_date`, date, required: false): Enter the date the service started for the client.
* **Service End Date** (`service_end_date`, date, required: false): Enter the date the service ended for the client.
* **Mental Health Provider** (`mental_health_provider`, select_multiple, required: false): Confirm if the client has a mental health provider.
* **Client Relationship** (`client_relationship`, select_one, required: false): Select the type of client relationship you have with the client.
* **Service Type** (`service_type`, select_one, required: false): Choose the type of service provided.
* **Notes** (`notes`, note, required: false): Optionally, add any additional notes about the client's status.
