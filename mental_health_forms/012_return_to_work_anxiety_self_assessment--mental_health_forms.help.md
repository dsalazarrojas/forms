# Return To Work Anxiety Self Assessment - Help Guide
## Purpose

This form is designed to assess your return to work anxiety after a period of absence from work. It will help you identify your anxiety levels, support needs, and work environment factors that may influence your return to work anxiety.

## How To Complete This Form

1. Answer the questions to the best of your ability and without any influence of external factors.
2. Select all that apply for each field.
3. Be honest and accurate in your answers.

## Field-by-Field Explanation

### Page 1: return_to_work_anxiety_self_assessment_form

*   **return_to_work_anxiety_self_assessment_form** (`return_to_work_anxiety_self_assessment_form`, text, required/optional): This is the starting point for your return to work anxiety assessment. Please enter your thoughts and feelings related to returning to work after a period of absence.
### Page 2: anxiety_level

*   **anxiety_level** (`anxiety_level`, number, required/optional): This question assesses your anxiety level on a scale of 0-10. Please select the number that best describes your current anxiety level.
### Page 3: anxiety_level_score

*   **anxiety_level_score** (`anxiety_level_score`, number, required/optional): This question calculates your anxiety level score based on your anxiety level selection. Please do not modify this field.
### Page 4: anxiety_score

*   **anxiety_score** (`anxiety_score`, number, required/optional): This question calculates your anxiety score based on your anxiety level score. Please do not modify this field.
### Page 5: return_to_work_anxiety

*   **return_to_work_anxiety** (`return_to_work_anxiety`, text, required/optional): This field is for any additional thoughts or feelings related to return to work anxiety that you would like to share.
### Page 6: concerns

*   **concerns** (`concerns`, select_multiple, required/true): Select all that apply from the following options: Anxiety, Fear, Stress, Fatigue, Insomnia, Concentration, Memory, Sleep, Irritability, Mood, Focus, Motivation, Self-esteem, Self-confidence.
### Page 7: return_to_work_support_needs

*   **return_to_work_support_needs** (`return_to_work_support_needs`, select_multiple, required/true): Select all that apply from the following options: Work-life balance, Communication, Social support, Relaxation, Mindfulness, Physical activity, Sleep hygiene, Healthy eating, Goal setting, Time management, Boundary setting, Self-esteem, Confidence, Mindfulness and self-compassion.
### Page 8: work_environment

*   **work_environment** (`work_environment`, select_one, required/true): Select one option from: Office, Home office, Flexible work hours, Work from home, On-site, Off-site.
### Page 9: work_type

*   **work_type** (`work_type`, select_one, required/true): Select one option from: Full-time, Part-time, Freelance, Remote, On-site.
### Page 10: work_scheduling

*   **work_scheduling** (`work_scheduling`, select_one, required/true): Select one option from: Fixed hours, Variable hours, Flexible hours, Flexible days, Flexible weeks.
### Page 11: work_location

*   **work_location** (`work_location`, select_one, required/true): Select one option from: Office building, Home office, On-site, Off-site.
### Page 12: work_supervision

*   **work_supervision** (`work_supervision`, select_one, required/true): Select one option from: Supervisor, Colleague, Manager, None.
### Page 13: support_team

*   **support_team** (`support_team`, select_multiple, required/true): Select all that apply from: HR, Manager, Colleague, Mental Health Team, Other.
### Page 14: return_to_work_anxiety_support_needed

*   **return_to_work_anxiety_support_needed** (`return_to_work_anxiety_support_needed`, select_one, required/true): Select one option from: True, False.
### Page 15: mental_health_referral

*   **mental_health_referral** (`mental_health_referral`, select_multiple, required/true): Select all that apply from: True, False, Undecided.
### Page 16: return_to_work_concerns

*   **return_to_work_concerns** (`return_to_work_concerns`, select_multiple, required/true): Select all that apply from: Work schedule, Workload, Office noise, Colleague relationships, Office layout, Office equipment, Office climate, Other.
### Page 17: return_to_work_support_plan

*   **return_to_work_support_plan** (`return_to_work_support_plan`, select_one, required/true): Select one option from: True, False.

## Tips

*   Please answer the questions to the best of your ability and without any influence of external factors.
*   Be honest and accurate in your answers.
*   This form is for information purposes only and does not constitute professional advice.
*   If you need additional support or consultation, please seek a healthcare professional.
