# reality-therapy-evaluation-form - Help Guide
## Purpose
This form is designed to document and evaluate reality therapy sessions, ensuring that all relevant information is recorded consistently.

## How To Complete This Form
To complete this form, simply follow the steps below:

1. Fill out each field as accurately and thoroughly as possible.
2. Use the provided labels as guidance for what information to include in each field.
3. Answer each question truthfully and to the best of your ability.

## Field-by-Field Explanation
### Session Date (`session_date`, date, required: false)
• **Session Date**: Record the date of the reality therapy session.
• This is where you will document the date on which the session took place.

### Therapist Name (`therapist_name`, text, required: false)
• **Therapist Name**: Enter the name of the therapist who conducted the session.
• This is where you will enter the name of the therapist who conducted the session.

### Session Duration (`session_duration`, number, required: false)
• **Session Duration**: Record the duration of the session.
• This is where you will document how long the session lasted.

### Session Notes (`session_notes`, text, required: false)
• **Session Notes**: Briefly describe the session.
• This is where you will record any relevant details about the session.

### Session Goals (`session_goals`, text, required: false)
• **Session Goals**: Describe the goals set for the session.
• This is where you will document the objectives of the session.

### Session Outcomes (`session_outcomes`, text, required: false)
• **Session Outcomes**: Describe the outcomes of the session.
• This is where you will document the results of the session.

### Follow-up Plan (`follow_up_plan`, select_one, required: false)
• **Follow-up Plan**: Choose the follow-up plan that best suits your needs.
• This is where you will select the follow-up plan that aligns with your needs, such as short-term follow-up in 1-2 weeks, long-term follow-up in 6-8 months, etc.

### Next Session Date (`next_session_date`, date, required: false)
• **Next Session Date**: Record the date of the next session.
• This is where you will document the date of the next session.

### Next Session Goals (`next_session_goals`, text, required: false)
• **Next Session Goals**: Describe the goals to be achieved in the next session.
• This is where you will document the objectives of the next session.

### Next Session Notes (`next_session_notes`, text, required: false)
• **Next Session Notes**: Briefly describe the next session.
• This is where you will record any relevant details about the next session.

### Next Session Outcomes (`next_session_outcomes`, text, required: false)
• **Next Session Outcomes**: Describe the outcomes of the next session.
• This is where you will document the results of the next session.

### Overall Outcomes (`overall_outcomes`, text, required: false)
• **Overall Outcomes**: Describe overall progress and any significant events.
• This is where you will document the overall progress of the reality therapy.
