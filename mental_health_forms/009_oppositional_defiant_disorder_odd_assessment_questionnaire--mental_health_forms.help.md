# oppositional_defiant_disorder_odd_assessment_questionnaire - Help Guide
## Purpose

The oppositional_defiant_disorder_odd_assessment_questionnaire is a comprehensive assessment tool used to evaluate the severity of Oppositional Defiant Disorder (ODD) symptoms. It helps identify patterns of angry, aggressive, or defiant behavior that may be present in an individual.

## How To Complete This Form

1. Read through each question carefully and select the relevant answers based on your observations and experiences.
2. For questions with options, select one option that best reflects your answer.
3. Fill out all the required questions to ensure accurate assessment results.

## Field-by-Field Explanation

* **Introduction** (`intro_page`, `text`, required: false): A brief introduction explaining the purpose of the form and its relevance to oppositional defiant disorder.
* **Has Parent Conducted** (`parent_conduct`, `select_one`, required: false): Check if the individual's parent has conducted any oppositional defiant behavior.
	+ "Yes" if the parent has exhibited oppositional defiant behavior.
	+ "No" if the parent has not exhibited oppositional defiant behavior.
* **Exhibits Rule-Breaking Behavior** (`rule_breaking_behavior`, `select_multiple`, required: true): Check if the individual exhibits rule-breaking behavior such as arguing with authority or deliberately annoying peers.
	+ Select all that apply:
		- "Yes" for rule-breaking behavior.
		- "No" for no rule-breaking behavior.
* **Exhibits Anger** (`angry_outbursts`, `select_multiple`, required: true): Check if the individual exhibits angry outbursts or irritability.
	+ Select all that apply:
		- "Yes" for anger outbursts.
		- "No" for no anger outbursts.
* **Negative Impacts** (`negative_impacts`, `select_multiple`, required: true): Check the negative impacts or consequences of the oppositional defiant disorder on the individual.
	+ Select all that apply:
		- "Yes" for negative impacts.
		- "No" for no negative impacts.
* **Reacts Emotionally** (`emotional_reactions`, `select_one`, required: true): Check if the individual reacts emotionally to situations or events.
	+ "Yes" for emotional reactions.
	+ "No" for no emotional reactions.
* **Defiance** (`defiance`, `select_multiple`, required: true): Check if the individual exhibits defiance or oppositional behavior.
	+ Select all that apply:
		- "Yes" for defiance.
		- "No" for no defiance.
* **Comments** (`negative_comments`, `text`, required: false): If any other comments or observations are relevant to the assessment.
* **Additional Comments** (`additional_comments`, `text`, required: false): If you have any additional information or comments that might be useful for the assessment.
* **Follow-up Plan** (`follow_up_plan`, `select_one`, required: true): Check if a follow-up plan is required to address the oppositional defiant disorder.
	+ "Yes" for follow-up plan.
	+ "No" for no follow-up plan.
* **Completed** (`completed`, `number`, required: true): Enter the number of completed questions.
* **Score** (`score`, `number`, required: true): Enter the assessment score.

Note: Make sure to review each question carefully and answer honestly based on your observations and experiences. The assessment results will help identify patterns of oppositional defiant disorder and guide future interventions or support. If you have any doubts or concerns, please don't hesitate to ask for help.
