# mental_health_program_approval_form - Help Guide
## Purpose
This form is used to gather information about mental health programs to be approved by the relevant authorities.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill in the program's name and description in the respective fields.
2. Enter the program's start and end dates, if applicable.
3. Provide the program's contact information, including name, email, and phone number.
4. Select the program's status from the options provided.
5. Add any additional notes about the program.
6. Enter any other details that are specific to your program, such as organisation, initiative, budget, target audience, objectives, duration, outcomes, and evaluation status.

## Field-by-Field Explanation
* **Program Name** (Program Name, text, required): Enter the name of the mental health program.
* **Program Description** (Program Description, text, required): Describe the mental health program in a brief and concise manner.
* **Program Start Date** (Program Start Date, date, optional): Enter the start date of the program, if applicable.
* **Program End Date** (Program End Date, date, optional): Enter the end date of the program, if applicable.
* **Program Location** (Program Location, text, optional): Enter the location of the program.
* **Program Contact Name** (Program Contact Name, text, optional): Enter the name of the program contact person.
* **Program Contact Email** (Program Contact Email, email, optional): Enter the email of the program contact person.
* **Program Contact Phone** (Program Contact Phone, text, optional): Enter the phone number of the program contact person.
* **Program Status** (Program Status, select one, optional): Select the status of the program from the options provided.
* **Program Notes** (Program Notes, note, optional): Add any additional notes about the program.
* **Program Organisation** (Program Organisation, text, optional): Enter the name of the program's organisation.
* **Program Initiative** (Program Initiative, text, optional): Enter any initiative related to the program.
* **Program Budget** (Program Budget, text, optional): Enter the budget of the program.
* **Program Target Audience** (Program Target Audience, text, optional): Enter the target audience of the program.
* **Program Objectives** (Program Objectives, text, optional): Enter the objectives of the program.
* **Program Duration** (Program Duration, text, optional): Enter the duration of the program.
* **Program Outcomes** (Program Outcomes, text, optional): Enter the outcomes of the program.
* **Program Review** (Program Review, date, optional): Enter the date of the program review.
* **Program Evaluation** (Program Evaluation, date, optional): Enter the date of the program evaluation.
* **Program Evaluation Notes** (Program Evaluation Notes, text, optional): Enter any evaluation notes.
* **Program Evaluation Status** (Program Evaluation Status, select one, optional): Select the status of the program evaluation from the options provided.
* **Assigned Tool** (Assigned Tool, text, optional): Enter the tool assigned to the program.
* **Submitted** (Submitted, date, optional): Enter the date when the program was submitted.
* **Approved** (Approved, date, optional): Enter the date when the program was approved.
* **Comments** (Comments, text, optional): Enter any comments related to the program.

Note: Please make sure to double-check all entered information before submitting the form to ensure accuracy and completeness.
