# Vehicle Allocation And Exchange Form - Help Guide
## Purpose
The purpose of this form is to gather information about vehicles in order to facilitate their allocation or exchange. 

## How To Complete This Form
To complete this form, follow these steps:
1. Ensure all fields are filled out completely.
2. For field **Select One**, select one option from the provided options.
3. For field **Select Multiple**, select multiple options from the provided options.
4. For field **Vehicle Number**, enter a numerical value representing the vehicle's ID or registration number.
5. For field **Vehicle Location**, enter the vehicle's current location.
6. For field **Vehicle Type**, select one option from the provided options.
7. For field **Vehicle Status**, select multiple options from the provided options.
8. For field **Vehicle Owner**, select one option from the provided options.
9. For field **Date Of Issue**, enter the date of the issue.
10. For field **Time Of Issue**, enter the time of the issue.
11. For field **Notes**, enter any additional information or comments about the vehicle.
12. For field **Email**, enter the contact information of the person responsible for the vehicle.
13. For field **Phone Number**, enter the contact phone number of the person responsible for the vehicle.
14. For field **Vehicle Allocation**, enter a numerical value representing the vehicle's allocation status.

## Field-by-Field Explanation
- **Select One** (`vehicle_details_2`): Select one option to allocate or exchange the vehicle.
- **Select Multiple** (`vehicle_details_3`): Select multiple options to allocate or exchange the vehicle.
- **Vehicle Number** (`vehicle_details_4`): Enter the vehicle's unique ID or registration number.
- **Vehicle Location** (`vehicle_details_5`): Enter the current location of the vehicle.
- **Vehicle Type** (`vehicle_details_6`): Select one option to indicate the vehicle type.
- **Vehicle Status** (`vehicle_details_7`): Select multiple options to indicate the vehicle's status.
- **Vehicle Owner** (`vehicle_details_8`): Select one option to indicate the vehicle owner.
- **Date Of Issue** (`vehicle_details_9`): Enter the date when the issue occurred.
- **Time Of Issue** (`vehicle_details_10`): Enter the time when the issue occurred.
- **Notes** (`vehicle_details_11`): Enter any additional information or comments about the vehicle.
- **Email** (`vehicle_details_12`): Enter the contact email of the person responsible for the vehicle.
- **Phone Number** (`vehicle_details_13`): Enter the contact phone number of the person responsible for the vehicle.
- **Vehicle Allocation** (`vehicle_details_14`): Enter a numerical value to indicate the vehicle's allocation status.

## Tips
- Be sure to fill out all required fields.
- Review all fields before submitting the form.
- If unsure about any field, contact support for assistance.
