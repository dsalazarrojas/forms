# HV Motor Inspection Checklist - Help Guide
## Purpose
This form is designed to guide inspectors through a comprehensive motor inspection, ensuring that all necessary checks are performed and documented.

## How To Complete This Form
1. Review the form carefully to understand the sections and fields that need to be completed.
2. Answer each field accurately and thoroughly, using the provided options or text fields as necessary.
3. Ensure that you are familiar with the fields and their relevance to the motor inspection process.
4. If you are unsure about any field or section, refer to the relevant section below for guidance.

## Field-by-Field Explanation
### 1. General Inspection
* **General Inspection** (`general_inspection`, text, optional): Briefly describe the overall condition of the motor.

### 2. Motor Connections
* **Motor Connections** (`motor_connections`, select multiple, optional): Check if all motor connections are secure and functioning properly.
	+ Select "Yes" if all connections are present and functioning correctly.
	+ Select "No" if any connections are loose, damaged, or missing.

### 3. Motor Mounting
* **Motor Mounting** (`motor_mounting`, text, optional): Check the motor's mounting points and verify that they are secure and properly aligned.

### 4. Motor Alignment
* **Motor Alignment** (`motor_alignment`, text, optional): Verify that the motor's mounting points and shafts are aligned correctly.

### 5. Motor Condition
* **Motor Condition** (`motor_condition`, text, optional): Describe the motor's overall condition, including any signs of wear or damage.

### 6. Wiring and Grounding
* **Wiring and Grounding** (`wiring_and_grounding`, text, optional): Check the wiring and grounding of the motor to ensure they are secure and properly connected.

### 7. Safety Precautions
* **Safety Precautions** (`safety_precautions`, text, optional): Describe any safety precautions taken during the inspection, such as wearing personal protective equipment (PPE).

### 8. Test and Test Equipment
* **Test and Test Equipment** (`test_and_test_equipment`, text, optional): Describe the test equipment used and any results obtained during testing.

### 9. Motor Test Results
* **Motor Test Results** (`motor_test_results`, text, optional): Describe the test results obtained, including any anomalies or issues encountered.

### 10. Electrical Test Results
* **Electrical Test Results** (`electrical_test_results`, text, optional): Describe the electrical test results obtained, including any issues or anomalies.

### 11. Mechanical Test Results
* **Mechanical Test Results** (`mechanical_test_results`, text, optional): Describe the mechanical test results obtained, including any issues or anomalies.

### 12. Safety Precautions Summary
* **Safety Precautions Summary** (`safety_precautions_summary`, text, optional): Summarize any safety precautions taken during the inspection.

### 13. Test Equipment
* **Test Equipment** (`test_equipment`, select multiple, optional): Check if the necessary test equipment is available and in good working condition.
	+ Select "Yes" if all test equipment is present and functioning correctly.
	+ Select "No" if any test equipment is missing, damaged, or not available.

### 14. Electrical Test Equipment
* **Electrical Test Equipment** (`electrical_test_equipment`, select multiple, optional): Check if the necessary electrical test equipment is available and in good working condition.
	+ Select "Yes" if all electrical test equipment is present and functioning correctly.
	+ Select "No" if any electrical test equipment is missing, damaged, or not available.

### 15. Mechanical Test Equipment
* **Mechanical Test Equipment** (`mechanical_test_equipment`, select multiple, optional): Check if the necessary mechanical test equipment is available and in good working condition.
	+ Select "Yes" if all mechanical test equipment is present and functioning correctly.
	+ Select "No" if any mechanical test equipment is missing, damaged, or not available.

### 16. Safety Precautions Checklist
* **Safety Precautions Checklist** (`safety_precautions_checklist`, select multiple, optional): Check if all safety precautions are taken during the inspection.
	+ Select "Yes" if all necessary safety precautions are taken.
	+ Select "No" if any safety precautions are missing or not taken.

### 17. Inspection Comments
* **Inspection Comments** (`inspection_comments`, text, optional): Provide any additional comments or notes about the inspection, including any issues or concerns.

### 18. Inspector Signature
* **Inspector Signature** (`inspector_signature`, text, optional): Sign the form to confirm that the inspection was conducted and completed accurately.

### 19. Date Inspected
* **Date Inspected** (`date_inspected`, date, optional): Enter the date the motor was inspected.

### 20. Time Inspected
* **Time Inspected** (`time_inspected`, time, optional): Enter the time the motor was inspected.

### 21. Inspector Name
* **Inspector Name** (`inspector_name`, text, optional): Enter the name of the inspector.

### 22. Inspector Title
* **Inspector Title** (`inspector_title`, text, optional): Enter the title of the inspector.

### 23. Company Name
* **Company Name** (`company_name`, text, optional): Enter the name of the company conducting the inspection.

### 24. Job Number
* **Job Number** (`job_number`, text, optional): Enter the job number or ID.

### 25. Remarks
* **Remarks** (`remarks`, text, optional): Provide any final comments or notes about the inspection.
