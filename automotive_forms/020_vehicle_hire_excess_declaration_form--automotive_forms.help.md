# Vehicle Hire Excess Declaration Form - Help Guide
## Purpose
The Vehicle Hire Excess Declaration Form is used to declare excesses (overcharges) on vehicle hire transactions. It helps identify and document any discrepancies between the actual vehicle hire costs and the agreed-upon rates.

## How To Complete This Form
To complete this form, follow these steps:

* Review the provided options for each field and select the correct responses.
* Fill in the form fields with the necessary information.
* Ensure all required fields are completed before submitting the form.

## Field-by-Field Explanation

### Vehicle Hire Excess Declaration Form (Vehicle Hire Excess Declaration Form)
This field is a text area for you to enter any information about the Vehicle Hire Excess Declaration Form.

* **Vehicle Type** (`vehicle_type`, select_one, required: false):
	+ Select "Yes" if you wish to declare an excess for the vehicle type.
* **Vehicle Make** (`vehicle_make`, select_multiple, required: false):
	+ Select "Yes" if you wish to declare an excess for the vehicle make.
* **Excess Amount** (`excess_amount`, number, required: false):
	+ Enter the actual amount of the excess charge.
* **Vehicle Hire Start Date** (`vehicle_hire_start_date`, date, required: false):
	+ Enter the start date of the vehicle hire.
* **Vehicle Hire End Date** (`vehicle_hire_end_date`, date, required: false):
	+ Enter the end date of the vehicle hire.
* **Vehicle Hire Location** (`vehicle_hire_location`, text, required: false):
	+ Enter the location where the vehicle was hired from.
* **Excess Declaration** (`excess_declaration`, text, required: false):
	+ Enter any additional information about the excess declaration.
* **Submit** (`submit`, submit, required: true):
	+ Click submit to complete and submit the form.
