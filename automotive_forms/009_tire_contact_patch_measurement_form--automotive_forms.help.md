# Tire Contact Patch Measurement Form - Help Guide
## Purpose
The Tire Contact Patch Measurement Form is used to collect accurate measurements related to tire contact patch for automotive purposes, such as in a workshop or repair setting. This form helps ensure proper measurement for safe and accurate tire mounting.

## How To Complete This Form
1. Click on the first page to start filling out the form.
2. On the second page, select the relevant information for each field:
 * **Tire Type**: Select the type of tire being measured. (Standard, P-Metric, P-Metric P1, P-Metric P2, P-Metric P3)
 * **Tire Size**: Select the size of the tire being measured. (Small, Standard, Large, Extra Large)
 * **Tire Speed**: Select the speed rating of the tire being measured. (Low Speed, High Speed)
3. Move to the next page and enter the measurement values:
 * **Measurement 1**: Enter the value for the first measurement.
 * **Measurement 2**: Enter the value for the second measurement.
4. Review and submit the form once completed.

## Field-by-Field Explanation
* **Tire Type** (`page_2_tire_type`, `select_multiple`, required: false): This field is used to select the type of tire being measured. Select the correct type from the options provided.
* **Tire Size** (`page_2_tire_size`, `select_one`, required: false): This field is used to select the size of the tire being measured. Select the correct size from the options provided.
* **Tire Speed** (`page_2_tire_speed`, `select_one`, required: false): This field is used to select the speed rating of the tire being measured. Select the correct speed from the options provided.
* **Measurement 1** (`page_3_measurement_1`, `number`, required: false): Enter the value for the first measurement. Ensure the value is accurate and relevant to the tire being measured.
* **Measurement 2** (`page_3_measurement_2`, `number`, required: false): Enter the value for the second measurement. Ensure the value is accurate and relevant to the tire being measured.
* **Measurement 1** (`page_4_measurement_1`, `date`, required: false): This field is used to enter a date for the measurement. Ensure the date is in a correct format (MM/DD/YY).

## Tips
* Double-check the accuracy of the measurements before submitting the form.
* Ensure the correct tire type, size, and speed are selected.
* Enter accurate values for the measurements.
