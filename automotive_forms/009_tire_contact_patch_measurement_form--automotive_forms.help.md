2. On the second page, select the relevant information for each field:
 * **Tire Type**: Select the type of tire being measured. (Standard, P-Metric, P-Metric P1, P-Metric P2, P-Metric P3)

 * **Tire Speed**: Select the speed rating of the tire being measured. (Low Speed, High Speed)
3. Move to the next page and enter the measurement values:
 * **Measurement 1**: Enter the value for the first measurement.
 * **Measurement 2**: Enter the value for the second measurement.
