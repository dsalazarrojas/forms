# Trailer Breakdown Process Checklist - Help Guide
## Purpose
The trailer breakdown process is a critical step in maintaining the reliability and safety of trailers. This form is designed to guide users through a systematic evaluation of a trailer's condition and status.

## How To Complete This Form
To complete this form, follow these steps:
1. Select the trailer type from the options provided.
2. Indicate whether the trailer's axles are present.
3. Record the date the trailer was last inspected or serviced.
4. Fill in the number of axles present or any specific details about the axles.
5. Report the status of the trailer's cleanliness.
6. Check if the trailer is secure or unsecure.
7. Indicate if the tractor is secure or unsecure.
8. Record the number of hours since last service.
9. Record any additional notes or comments about the trailer's condition.
10. Report if the trailer is ready for use or not.

## Field-by-Field Explanation
* **Trailer Type**: Select the type of trailer you are evaluating (Dry Freight, Reefer, Tanker).
* **Axle: Yes/No/Not Applicable**: Indicate whether the trailer's axles are present.
* **Last Inspection Date**: Record the date the trailer was last inspected or serviced.
* **Number of Axles**: Fill in the number of axles present or any specific details about the axles.
* **Cleanliness Status**: Report the status of the trailer's cleanliness (Clean, Dirty).
* **Security Status**: Check if the trailer is secure or unsecure.
* **Tractor Security Status**: Indicate if the tractor is secure or unsecure.
* **Hours Since Last Service**: Record the number of hours since the trailer was last serviced.
* **Additional Notes**: Record any additional comments or notes about the trailer's condition.
* **Ready for Use**: Report if the trailer is ready for use or not.
