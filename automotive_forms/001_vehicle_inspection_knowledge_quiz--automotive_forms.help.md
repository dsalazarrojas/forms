# vehicle_inspection_knowledge_quiz - Help Guide
## Purpose
The vehicle_inspection_knowledge_quiz form is designed to assess the user's knowledge on various aspects of vehicle inspection, including engine type, brake fluid level checks, suspension system function, coolant temperature checks, steering system purpose, tire inspection frequency, and final submission.

## How To Complete This Form
To complete this form, follow these steps:
1. Review each field carefully and choose the correct answer based on your knowledge of vehicle inspection.
2. Select the most accurate option for each field from the given choices.
3. Make sure to provide a valid date for the final submission.
4. Complete the form carefully, as the information is used to evaluate your knowledge on vehicle inspection.

## Field-by-Field Explanation
### 1. **Engine Type** (`engine_type`, `select_one`, required)
What is the engine type of a typical vehicle?

*   V8: This is a common type of engine used in many vehicles.
*   V6: This is another common type of engine used in many vehicles.
*   V4: This is a less common type of engine used in some vehicles.
*   Inline 4: This is a smaller engine type used in smaller vehicles.

### 2. **Brake Fluid Level Check** (`brake_fluid_level_check`, `select_one`, required)

*   Improves steering response: This is a secondary function of the suspension system.
*   Reduces vibration: This is a benefit of a well-functioning suspension system.
*   Increases vehicle height: This is not a primary function of the suspension system.

*   Not Applicable: This option is not relevant to the coolant level check.

### 5. **Steering System Purpose** (`steering_purpose`, `select_one`, required)
What is the purpose of the steering system?

*   To turn the vehicle: This is a primary function of the steering system.
*   To steer the vehicle: This is the main function of the steering system.
*   To improve vehicle stability: This is a secondary function of the steering system.
*   To reduce fuel consumption: This is not a primary function of the steering system.
