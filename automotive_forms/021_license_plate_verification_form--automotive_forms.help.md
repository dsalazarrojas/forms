# License Plate Verification Form - Help Guide
## Purpose
The License Plate Verification Form is used to verify the authenticity of a vehicle's license plate. This form is designed to collect relevant information about the vehicle, including its state, city, zip code, country, verification date and time, verification method, vehicle type, and verification result. The form is used to ensure accurate and efficient verification of license plates.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill in the relevant information about the vehicle, including:
	* **License Plate (2)**: Enter the license plate number of the vehicle.
	* **State**: Select the state where the vehicle is registered.
2. Optional, but recommended:
	* **City**: Enter the city where the vehicle is registered.
	* **Zip Code**: Enter the zip code of the vehicle's registration address.
	* **Country**: Select the country where the vehicle is registered (default: USA).
3. Verify the license plate:
	* **Verification Date**: Enter the date of the verification.
	* **Verification Time**: Select the time of the verification (AM or PM).
	* **Verification Method**: Select the method used for verification (In Person or Online).
	* **Verification Result**: Select the result of the verification (Valid or Invalid).
4. Add additional information:
	* **Notes**: Enter any additional notes about the verification.
	* **Verified By**: Enter the name of the person or entity that verified the license plate.
	* **Submitted At**: Enter the date and time the form was submitted.
	* **Verified By User**: Enter your name or username.
	* **Submitted At Server**: Enter the date and time the form was processed on the server.
	* **User IP**: Enter the IP address of the user who submitted the form.
	* **User Agent**: Enter the user agent of the user who submitted the form.
	* **User Browser**: Enter the browser used by the user to submit the form.
	* **User Operating System**: Enter the operating system of the user's device.
	* **License Verification IP**: Enter the IP address of the verification server.
	* **User-Agent Header**: Enter the User-Agent header from the user's request.
	* **User Ip Address**: Enter the user's IP address.
	* **License Plate Verification Form Verification Method**: Enter the method used for verification.
