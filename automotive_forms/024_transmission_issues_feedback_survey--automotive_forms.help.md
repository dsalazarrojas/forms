# Transmission Issues Feedback Survey - Help Guide
## Purpose
The purpose of this form is to collect feedback on transmission issues encountered by customers during service. It's essential to provide this information accurately to help resolve any problems and improve customer service.

## How To Complete This Form
To complete this form, please follow these steps:

1. Ensure that you are authorized to complete this form.
2. Review each field carefully and provide accurate information.
3. Answer all questions truthfully and completely.
4. Use the provided options for select fields, or type your own answer if it's a text field.

## Field-by-Field Explanation
* **Feedback** (`feedback`, text, required: false): This field is for providing a brief description of the transmission issue encountered.
* **transmission_problem** (`transmission_problem`, select_one, required: false): Select the type of transmission problem encountered (e.g., Transmission Problem, No Problem, Unknown).
* **issue_type** (`issue_type`, select_multiple, required: false): Choose the type of issue encountered (e.g., Gearbox Problems, Clutch Problems, Gearbox Leak).
* **Vehicle Milage** (`vehicle_milage`, number, required: false): Enter the vehicle's mileage at the time of the issue.
* **Vehicle Year** (`vehicle_year`, text, required: false): Enter the year of the vehicle.
* **Contact Method** (`contact_method`, select_multiple, required: false): Select how the customer contacted you (e.g., Email, Phone, Chat).
* **Contact Email** (`contact_email`, email, required: false): Enter the customer's email address (if applicable).
* **Contact Phone** (`contact_phone`, text, required: false): Enter the customer's phone number (if applicable).
* **Transmission Problem Description** (`transmission_problem_description`, text, required: false): Provide a detailed description of the transmission problem.
* **Vehicle Make** (`vehicle_make`, select_one, required: false): Check if the vehicle is a 'Yes' or 'No' (if applicable).
* **Vehicle Model** (`vehicle_model`, text, required: false): Enter the vehicle model.
* **Vehicle Year** (`vehicle_year`, text, required: false): Enter the vehicle year.
* **Vehicle License** (`vehicle_license`, text, required: false): Enter the vehicle license plate number.
* **Service Advisor** (`service_advisor`, text, required: false): Enter your name.
* **Mechanic** (`mechanic`, text, required: false): Enter the mechanic's name.
* **Service Date** (`service_date`, date, required: false): Enter the service date.
* **Service Time** (`service_time`, time, required: false): Enter the service time.
* **Customer Comments** (`customer_comments`, text, required: false): Allow the customer to leave any additional comments.
* **Employee Notes** (`employee_notes`, note, required: false): Add any additional notes or comments from the employee.

## Tips

* Always ensure that you're providing accurate and complete information.
* If you're unsure about any field, please don't hesitate to ask for guidance.
* This form is meant to improve customer service, so please complete it in a way that helps resolve the issue efficiently.
