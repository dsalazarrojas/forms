# Offroad Recovery Assessment - Help Guide

## Purpose
The Offroad Recovery Assessment form is designed to gather information for off-road recovery assistance. This form will help the recovery team understand the context and details of the incident, including location, vehicle type, and any hazards present. Please answer these questions to facilitate the recovery process.

## How To Complete This Form

- Please fill out the form in order, starting from the top of the page.
- For each field, provide as much detail as possible, especially if it's a required field.
- If a field is not applicable, please select "No" or indicate that it's not applicable.

## Field-by-Field Explanation

* **Incident Location** (<type:text>): Enter a brief description of the location where the incident occurred, including any nearby landmarks or reference points.
* **Vehicle Details** (<type:note>): Provide a detailed description of the vehicle involved, including its make, model, and any distinguishing features.
* **Hazards Present** (<type:select_multiple>):
	+ Select "Yes" if there are any hazards present, such as steep slopes, rocky terrain, or other obstacles.
	+ If "Yes", please provide a brief description of the hazards.
* **Photos** (<type:text>): Attach photos of the incident location, including any relevant landmarks or obstacles.
* **Recovery Services** (<type:select_one>):
	+ Choose the most relevant recovery service that assisted with the off-road incident:
		- 4x4 Clubs: A local 4x4 club or organization that provides recovery services.
		- Event Organizers: The event or festival organizers that assisted with recovery.
		- Recovery Services: Other types of recovery services, such as private companies or teams.
* **Vehicle Type** (<type:select_one>):
	+ Select "Yes" if the vehicle involved is an off-road vehicle.
	+ If "No", please indicate that the vehicle is not an off-road vehicle.
* **Recovery Location** (<type:text>): Enter a brief description of the recovery location, including any nearby landmarks or reference points.
* **Incident Date** (<type:date>): Enter the date of the incident, in the format MM/DD/YY.

Note: Please be as detailed as possible when filling out this form to ensure accurate and efficient recovery assistance. If you have any questions or concerns, please don't hesitate to contact us.
