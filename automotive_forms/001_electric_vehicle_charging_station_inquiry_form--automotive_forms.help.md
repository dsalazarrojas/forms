# Electric Vehicle Charging Station Inquiry Form - Help Guide

## Purpose
This form is designed to collect information related to electric vehicle charging station inquiries. It helps in identifying the type of inquiry, the purpose of the inquiry, and other relevant details required to address the query efficiently.

## How To Complete This Form
To complete this form, follow these steps:

*   Select the type of inquiry you are making from the "Inquiry Type" dropdown menu.
*   Choose the purpose of your inquiry from the "Inquiry For" dropdown menu.
*   If your inquiry is related to the capacity of a charging station, select "Charging Station Capacity" in the "Inquiry About" dropdown menu. If it's for installation details or maintenance scheduling, choose the relevant options accordingly.
*   If you own an electric or hybrid vehicle, select the type from the "Vehicle Type" dropdown menu.
*   Enter your vehicle's make in the "Vehicle Make" field.
*   Enter your vehicle's model in the "Vehicle Model" field.
*   Provide the name and contact information (email and phone number) of the contact person.
*   Enter the address where you would like to receive the inquiry output (if applicable).
*   Add any additional notes or information you would like to provide in the "Additional Notes" field.
*   If applicable, select the assigned tool and its ID from the "Assigned Tool" and "Assigned Tool ID" fields.
*   Choose the output format for your inquiry from the "Output Format" dropdown menu. You can select to receive the output in CSV or PDF format.
*   Provide a name for your output file.
*   Add a brief description of what you would like to see in the output (if applicable).
*   Enter the name of the person who created this inquiry.
*   If you have any specific format requirements for the output, enter the date when it was created and updated (if applicable).
*   If the inquiry is deleted, enter the date when it was deleted (if applicable).
*   Enter the form ID if required.
*   If you want to categorize this inquiry under a specific category, enter the category name.
*   Finally, provide a brief description of your inquiry in the "Description" field.
*   If applicable, assign "Jimmy" to handle this inquiry.

## Field-by-Field Explanation

*   **Inquiry Type**: Choose the type of inquiry you are making (Electric, Hybrid, None).
*   **Inquiry For**: Select the purpose of your inquiry (Electric Vehicle Charging Installation, Electric Vehicle Charging Station Maintenance, Electric Vehicle Charging Station Repair).
*   **Inquiry About**: Choose the specific inquiry topic (Charging Station Capacity, Station Installation Details, Station Maintenance Scheduling).
*   **Vehicle Type**: If your inquiry is related to electric or hybrid vehicles, select this field (Electric, Hybrid, Gasoline).
*   **Vehicle Make**: Enter your vehicle's make.
*   **Vehicle Model**: Enter your vehicle's model.
*   **Contact Person**: Provide the name and contact information (email and phone number) of the contact person.
*   **Address**: Enter the address where you would like to receive the inquiry output (if applicable).
*   **Additional Notes**: Add any additional notes or information you would like to provide.
*   **Assigned Tool**: If applicable, select the assigned tool.
*   **Assigned Tool ID**: If applicable, enter the assigned tool ID.
*   **Output File**: Choose the output format for your inquiry (CSV, Excel, PDF).
*   **Output Name**: Provide a name for your output file.
*   **Output Description**: Add a brief description of what you would like to see in the output (if applicable).
*   **Created By**: Enter the name of the person who created this inquiry.
*   **Created At**: If you have specific format requirements for the output, enter the date when it was created and updated (if applicable).
*   **Updated At**: If applicable, enter the date when it was updated.
*   **Deleted At**: If the inquiry is deleted, enter the date when it was deleted.
*   **Form ID**: Enter the form ID if required.
*   **Category**: If you want to categorize this inquiry under a specific category, enter the category name.
*   **Description**: Provide a brief description of your inquiry.
*   **Assigned Jimmy**: If applicable, assign "Jimmy" to handle this inquiry.
