# Haulout Service Agreement - Help Guide
## Purpose
The Haulout Service Agreement form is used to gather information about a vessel that is going to be hauled out for service. This form ensures that all necessary details about the vessel are captured accurately and consistently.

## How To Complete This Form
To complete this form, follow these steps:

1. Review the vessel's information to ensure you have accurate details.
2. Select the correct vessel type from the options provided.
3. Choose the correct vessel size from the options provided.
4. Select the vessel condition from the options provided.
5. Read and agree to the haulout terms.
6. Enter the haulout details, if necessary.
7. Date and time of signature.
8. Sign the agreement.

## Field-by-Field Explanation
* **Vessel Details** (`vessel_details`, `text`, required: false): Enter the vessel's details, including its name, IMO number, etc.
* **Vessel Type** (`vessel_type`, `select_one`, required: false): Select the correct vessel type from the options provided: Vessels 1-Ton, Vessels 2-Ton, Vessels 3-Ton, Vessels 4-Ton, or Other.
* **Vessel Size** (`vessel_size`, `select_one`, required: false): Select the correct vessel size from the options provided: Small, Medium, Large, or Extra Large.
* **Vessel Type Size** (`vessel_type_size`, `select_one`, required: false): Select the correct vessel type size from the options provided: Small, Medium, Large, or Extra Large.
* **Vessel Condition** (`vessel_condition`, `select_one`, required: false): Select the correct vessel condition from the options provided: Good, Fair, or Poor.
* **Haulout Terms** (`haulout_terms`, `text`, required: false): Enter any additional haulout terms or conditions.
* **Haulout Details** (`haulout_details`, `text`, required: false): Enter any additional details about the haulout, if necessary.
* **Haulout Terms Agreed** (`haulout_terms_agreed`, `select_one`, required: false): Select whether the haulout terms have been agreed upon: True or False.
* **Signature Date** (`signature_date`, `date`, required: false): Enter the date of signature.
* **Signature Time** (`signature_time`, `time`, required: false): Enter the time of signature.
