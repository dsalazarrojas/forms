# Two Wheeler User Experience Survey - Help Guide
## Purpose
The Two Wheeler User Experience Survey is designed to collect feedback and data from users related to their experiences with motorcycles or two-wheelers. This form is used to gather opinions and behaviors on various aspects of two-wheelers.
## How To Complete This Form
To complete this form, follow these steps:

1. Select the type of two-wheeler you have experience with.
2. Select the brand of the two-wheeler.
3. Select the model of the two-wheeler.
4. Select your usage type.
5. Select your average distance traveled with the two-wheeler.
6. Rate your satisfaction with the two-wheeler.
7. Enter your average speed.
8. Enter your average time used for the two-wheeler.
9. Enter the average date you use the two-wheeler.
10. Enter your average time of day you use the two-wheeler.
11. Enter any additional notes about your usage.
12. Enter the name of the average rider.
13. Enter the email of the average rider.
14. Enter the phone number of the average rider.
15. Enter any additional notes about the average rider.
16. Enter the name of the average engineer.
17. Enter the email of the average engineer.
18. Enter the phone number of the average engineer.
19. Enter any additional notes about the average engineer.
20. Enter the name of the average manager.
21. Enter the email of the average manager.
22. Enter the phone number of the average manager.
23. Enter any additional notes about the average manager.
24. Enter the total number of pages used.
25. Enter the average number of page turns.

## Field-by-Field Explanation

* **Select Two Wheeler Type (2)**: Select the type of two-wheeler you have experience with. Options: Yes, No.
* **Select Brand (4)**: Select the brand of the two-wheeler. Options: Yamaha, Honda, Kawasaki, Other.
* **Select Model (3)**: Select the model of the two-wheeler. Options: Yes, No.
* **Select Usage Type (4)**: Select the type of usage you have with the two-wheeler. Options: Yes, No.
* **Select Average Distance (5)**: Select the average distance you travel with the two-wheeler. Options: Yes, No.
* **Satisfaction (6)**: Rate your satisfaction with the two-wheeler. Options: Satisfied, Dissatisfied.
* **Average Speed (7)**: Enter your average speed. This field is a numerical input.
* **Average Time (8)**: Enter your average time used for the two-wheeler. This field is a time input.
* **Average Date (9)**: Enter the average date you use the two-wheeler. This field is a date input.
* **Average Time of Day (10)**: Enter your average time of day you use the two-wheeler. This field is a time input.
* **Average Weather (11)**: Enter any additional notes about your usage. This field is a free-form text input.
* **Average Rider Name (12)**: Enter the name of the average rider. This field is a text input.
* **Average Rider Email (13)**: Enter the email of the average rider. This field is an email input.
* **Average Rider Phone (14)**: Enter the phone number of the average rider. This field is a text input.
* **Average Rider Notes (15)**: Enter any additional notes about the average rider. This field is a free-form text input.
* **Average Engineer Name (16)**: Enter the name of the average engineer. This field is a text input.
* **Average Engineer Email (17)**: Enter the email of the average engineer. This field is an email input.
* **Average Engineer Phone (18)**: Enter the phone number of the average engineer. This field is a text input.
* **Average Engineer Notes (19)**: Enter any additional notes about the average engineer. This field is a free-form text input.
* **Average Manager Name (20)**: Enter the name of the average manager. This field is a text input.
* **Average Manager Email (21)**: Enter the email of the average manager. This field is an email input.
* **Average Manager Phone (22)**: Enter the phone number of the average manager. This field is a text input.
* **Average Manager Notes (23)**: Enter any additional notes about the average manager. This field is a free-form text input.
* **Total Pages (24)**: Enter the total number of pages used. This field is a numerical input.
* **Average Page Turns (25)**: Enter the average number of page turns. This field is a numerical input.
