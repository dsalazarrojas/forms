# vehicle_requisition_form - Help Guide
## Purpose
This form is designed to collect information about vehicles for requisition purposes in the automotive industry.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the Vehicle Id (ID number of the vehicle).
2. Enter the User Id (ID number of the user who requisitions the vehicle).
3. Enter the Vehicle Name (name of the vehicle).
4. Select the Vehicle Category (Sedan, SUV, or Truck).
5. Select the Vehicle Type (Petrol, Diesel, or Electric).
6. Enter the Vehicle Color (color of the vehicle).
7. Select the Vehicle Status (Available, Not Available, or Reserved).
8. If applicable, enter the Assigned Tool (tool associated with the vehicle).

## Field-by-Field Explanation
* **Vehicle Id** (`Vehicle Id`, text, optional): Enter the ID number of the vehicle.
* **User Id** (`User Id`, text, optional): Enter the ID number of the user who requisitions the vehicle.
* **Vehicle Name** (`Vehicle Name`, text, optional): Enter the name of the vehicle.
* **Vehicle Category** (`Vehicle Category`, select_one, optional): Select the category of the vehicle (Sedan, SUV, or Truck).
* **Vehicle Type** (`Vehicle Type`, select_multiple, optional): Select the type of the vehicle (Petrol, Diesel, or Electric).
* **Vehicle Color** (`Vehicle Color`, text, optional): Enter the color of the vehicle.
* **Vehicle Status** (`Vehicle Status`, select_one, optional): Select the status of the vehicle (Available, Not Available, or Reserved).
* **Assigned Tool** (`Assigned Tool`, text, optional): If applicable, enter the tool associated with the vehicle.

## Tips
* Please make sure to enter accurate and complete information to facilitate efficient vehicle requisitioning.
