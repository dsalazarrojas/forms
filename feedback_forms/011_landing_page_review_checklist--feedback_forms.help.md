# Landing Page Review Checklist - Help Guide
## Purpose
The Landing Page Review Checklist is a form designed to help users assess and improve the visual and design aspects of a landing page. This form collects feedback on the headline section and hero section, including font size, alignment, color, and style.

## How To Complete This Form

1.  Open the form in a web browser or application.
2.  Select the landing page you wish to review.
3.  Complete each field according to the guidelines below.

## Field-by-Field Explanation

* **Landing Page Name** (text, optional): Enter the name of the landing page.
* **Title** (text, optional): Enter the title of the landing page.
* **Headline** (text, optional): Enter the headline text for the page.
* **Subheading** (text, optional): Enter the subheading text for the page.
* **Hero Section** (text, optional): Enter the hero section description.
* **Headline Tagline** (text, optional): Enter the headline tagline text.
* **Background Image** (select_one, optional): Select the background image type for the hero section.
* **Headline Font Size** (number, optional): Enter the font size of the headline.
* **Headline Alignment** (select_one, optional): Select the alignment of the headline.
* **Headline Font Color** (select_one, optional): Select the font color of the headline.
* **Headline Background Color** (select_one, optional): Select the background color of the headline.
* **Headline Font Weight** (select_one, optional): Select the font weight of the headline.
* **Headline Font Style** (select_multiple, optional): Select the font styles of the headline.
* **Headline Font Family** (select_multiple, optional): Select the font family of the headline.
* **Hero Section Background Image** (select_one, optional): Select the background image type for the hero section.
* **Hero Section Background Color** (select_one, optional): Select the background color of the hero section.
* **Hero Section Height** (number, optional): Enter the height of the hero section.
* **Headline Tagline Font Size** (number, optional): Enter the font size of the headline tagline.
* **Headline Tagline Font Weight** (select_one, optional): Select the font weight of the headline tagline.
* **Headline Tagline Font Family** (select_multiple, optional): Select the font family of the headline tagline.
* **Headline Tagline Font Style** (select_multiple, optional): Select the font styles of the headline tagline.
* **Hero Section Background Video** (select_one, optional): Select the background video type for the hero section.
