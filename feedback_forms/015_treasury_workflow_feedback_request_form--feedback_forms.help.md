# Treasury Workflow Feedback Request Form - Help Guide
## Purpose
This form is used to gather feedback on the treasury workflow. Please submit your feedback on the workflow's efficiency, clarity, and any issues you encountered.

## How To Complete This Form
To complete this form, simply follow these steps:

1. Choose whether you think the workflow was efficient or not.
2. Select whether the workflow was clear or not.
3. List any issues you encountered during the workflow.
4. Add any additional comments or notes about your experience with the workflow.
5. If you think the finance department was involved in the workflow, please select this option.
6. If you think the treasury department was involved in the workflow, please select this option.
7. Enter the date you received the workflow.
8. If you want to be contacted, enter your email address.
9. Leave a comment if you prefer to be contacted by phone.
10. Select if you submitted this workflow.

## Field-by-Field Explanation

* **Workflow Efficiency** (Required: No): Select 'Yes' if you think the workflow was efficient. 
* **Clarity** (Required: Yes): Select 'Yes' if you think the workflow was clear.
* **Issues** (Required: Yes): List any issues you encountered during the workflow.
* **Comments** (Required: No): Add any additional comments or notes about your experience with the workflow.
* **Finance Department** (Required: No): If you think the finance department was involved in the workflow, select this option.
* **Treasury Department** (Required: No): If you think the treasury department was involved in the workflow, select this option.
* **Date Received** (Required: Yes): Enter the date you received the workflow.
* **Date Sent** (Required: No): If you want to provide the date the workflow was sent, enter it here.
* **Email** (Required: No): If you want to be contacted by email, enter your email address.
* **Phone** (Required: No): If you want to be contacted by phone, enter a comment with your phone number.
* **Submitted By** (Required: Yes): Select 'Yes' if you submitted this workflow.

Note: The form is divided into two pages, but the explanation is provided for each field on this single page for simplicity and clarity. The field-by-field explanation provides a clear understanding of what each field means and how to complete it.
