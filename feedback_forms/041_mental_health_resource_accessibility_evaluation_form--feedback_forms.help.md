# mental_health_resource_accessibility_evaluation_form - Help Guide
## Purpose
This form is used to evaluate the accessibility of mental health resources for users with specific needs.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the **Evaluation Period** by entering a numerical value.
2. Choose the **resource_type** from the provided options (Mental Health Professional, Support Group, Self-Care Resource).
3. Enter the **organization** name, which is the name of the organization providing the resource.
4. Enter the **resource_name**, which is the name of the resource being evaluated.
5. Enter the **resource_location** where the resource is available (e.g., in-person, online, phone number).
6. Provide a brief **resource_description** of the resource, including its features and any relevant details.
7. Answer the question about **resource_availability**, indicating if the resource is available 24/7 or specify the hours it is available.

## Field-by-Field Explanation
* **Evaluation Period** (1): Enter a numerical value to specify the period of the evaluation (e.g., 1 year, 2 months).
* **resource_type** (2): Select the type of mental health resource from the provided options (Mental Health Professional, Support Group, Self-Care Resource).
* **organization** (3): Enter the name of the organization providing the mental health resource.
* **resource_name** (4): Enter the name of the mental health resource being evaluated.
* **resource_location** (5): Enter the location where the resource is available (e.g., in-person, online, phone number).
* **resource_description** (6): Provide a brief description of the resource, including its features and any relevant details.
* **resource_availability** (7): Answer the question about the resource's availability, indicating if it is available 24/7 or specify the hours it is available.

## Tips
* Be as specific as possible when filling out the form.
* Ensure that you have the necessary permissions to access and evaluate the resource.
* If you are unsure about any field, please reach out to the relevant authorities for clarification.
