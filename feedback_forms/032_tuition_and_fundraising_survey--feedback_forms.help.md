# Tuition And Fundraising Survey - Help Guide

## Purpose
The Tuition And Fundraising Survey form is designed to gather information from users about their tuition and fundraising efforts.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the title and category of the survey.
2. Provide a description of the survey, if necessary.
3. Select a category (nonprofit or education) that best fits the purpose of the survey.
4. Enter the tuition rate (optional).
5. Specify the fundraising effort (optional).
6. Enter the tuition rate range (optional).
7. Enter the fundraising effort range (optional).
8. Provide a date (optional).
9. Enter a time (optional).
10. Add any additional notes or comments (optional).
11. Enter an email address (optional).
12. Enter a phone number (optional).
13. Enter a fundraising amount (optional).
14. Enter a second tuition rate (optional).
15. Select a fundraising effort for the second option (optional).
16. Add any additional comments or comments about the survey submission (optional).
17. Enter a URL for the survey (optional).
18. Enter a title for the survey (optional).

## Field-by-Field Explanation
* **Tuition And Fundraising Survey** (`form_title`): Enter a brief title for the survey.
* **Category** (`form_category`): Choose the category that best fits the purpose of the survey. Options are Nonprofit and Education.
* **Description** (`form_description`): Provide a brief description of the survey, if necessary.
* **Form Category Label** (`form_category_label`): Enter a label for the category.
* **Form Description Label** (`form_description_label`): Enter a label for the description.
* **Tuition rate** (`input_tuition_rate`): Enter the tuition rate. This field is not required.
* **Fundraising effort** (`input_fundraising_effort`): Specify how much effort is being put into fundraising. This can be High, Medium, or Low.
* **Tuition rate range** (`input_tuition_rate_range`): Enter the tuition rate range. This field is not required.
* **Fundraising effort range** (`input_fundraising_effort_range`): Enter how much effort is being put into fundraising. This can be High, Medium, or Low.
* **Tuition rate range start** (`input_tuition_rate_range_start`): Enter the start of the tuition rate range. This field is not required.
* **Fundraising effort range start** (`input_fundraising_effort_range_start`): Enter the start of the fundraising effort range. This field is not required.
* **Tuition rate range end** (`input_tuition_rate_range_end`): Enter the end of the tuition rate range. This field is not required.
* **Fundraising effort range end** (`input_fundraising_effort_range_end`): Enter the end of the fundraising effort range. This field is not required.
* **Date** (`input_date`): Enter a date, if necessary. This field is not required.
* **Time** (`input_time`): Enter a time, if necessary. This field is not required.
* **Note** (`input_note`): Add any additional comments or notes about the survey submission. This field is not required.
* **Email** (`input_email`): Enter an email address, if necessary. This field is not required.
* **Phone** (`input_phone`): Enter a phone number, if necessary. This field is not required.
* **Fundraising amount** (`input_fundraising_amount`): Enter a fundraising amount, if necessary. This field is not required.
* **Input Tuition Rate 2** (`input_tuition_rate_2`): Enter a second tuition rate, if necessary. This field is not required.
* **Input Fundraising Effort 2** (`input_fundraising_effort_2`): Select a fundraising effort for the second option, if necessary. This field is not required.
* **Comments** (`form_comment`): Add any additional comments or comments about the survey submission. This field is not required.
* **Submission type** (`form_submission_type`): Enter a submission type, if necessary. This field is not required.
* **Survey URL** (`form_survey_url`): Enter a URL for the survey, if necessary. This field is not required.
* **Survey Title** (`form_survey_title`): Enter a title for the survey, if necessary. This field is not required.
