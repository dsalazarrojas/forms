# Random Test Survey - Help Guide
## Purpose
The purpose of this form is to collect random data for testing and validation purposes. It is not intended for production use and is designed to be used in a controlled environment.

## How To Complete This Form
To complete this form, follow these steps:

1. Navigate to the form page and start filling out the fields.
2. Begin with the "main page" section.
3. Fill out the "feedback form" section with any relevant information or comments.
4. Provide your date and time of birth in the "date" and "time" fields.
5. Enter your email address in the "email" field.
6. Enter your phone number in the "phone" field.
7. Enter your name in the name field.
8. Select one of the options from the "select one" field.
9. Select multiple options from the "select multiple" field.
10. Fill out the text field with any additional information.
11. Enter a whole number in the "integer" field.
12. Enter a decimal number in the "decimal" field.
13. Select one of the options from the "select one 2" field.
14. Select multiple options from the "select multiple 2" field.

## Field-by-Field Explanation
* **main page** (`main page`, text, required/optional): This is the starting page of the form.
* **feedback form** (`feedback form`, note, required/optional): This field is for providing any additional comments or feedback.
* **date** (`date`, date, required/optional): This field is for selecting a date.
* **time** (`time`, time, required/optional): This field is for selecting a time.
* **email** (`email`, email, required/optional): This field is for entering an email address.
* **phone** (`phone`, text, required/optional): This field is for entering a phone number.
* **name** (`name`, text, required/optional): This field is for entering a name.
* **select one** (`select one`, select_one, required/optional): Select one of the available options. Options are: Option 1, Option 2, and Option 3.
* **select multiple** (`select multiple`, select_multiple, required/optional): Select multiple options. Options are: Option 1, Option 2, and so on.
* **text-field** (`text-field`, text, required/optional): This field is for entering any additional text information.
* **integer** (`integer`, number, required/optional): This field is for entering a whole number.
* **decimal** (`decimal`, number, required/optional): This field is for entering a decimal number.
* **select one 2** (`select one 2`, select_one, required/optional): Select one of the available options. Options are: Option 4, Option 5, and Option 6.
* **select multiple 2** (`select multiple 2`, select_multiple, required/optional): Select multiple options. Options are: Option 7, Option 8.
