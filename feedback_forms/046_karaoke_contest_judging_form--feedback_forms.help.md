# Karaoke Contest Judging Form - Help Guide
## Purpose
The Karaoke Contest Judging Form is used to collect scores and feedback from judges for each song in a karaoke contest. This information will help determine the winner of the contest and provide valuable feedback to participants.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the name of the contest in the **Contest Name** field.
2. Enter your name and title in the **Judge Name** and **Song Title** fields respectively.
3. Enter the date of the performance in the **Performance Date** field.
4. For each song, enter a score between 1 and 10 for each category (e.g., **Score 1**, **Score 2**, etc.).
5. Enter the **Total Score** for each song.
6. Enter any **Feedback** you have for each song.
7. Enter the name of the **Category** and **Sub Category** for each song.
8. Enter the name of the prize and its **Prize Value** for each winner.
9. Enter any additional **Comments** you have for each song.
10. Enter the date the award was made in the **Award Date** field.

## Field-by-Field Explanation
* **Contest Name**: The name of the contest being judged.
	+ Type: text
	+ Required: False
* **Judge Name**: The name of the person filling out the form.
	+ Type: text
	+ Required: False
* **Song Title**: The title of the song being judged.
	+ Type: text
	+ Required: False
* **Performance Date**: The date the song was performed.
	+ Type: date
	+ Required: False
* **Score 1**, **Score 2**, **Score 3**, **Score 4**, **Score 5**, **Score 6**, **Score 7**, **Score 8**, **Score 9**, **Score 10**: Enter a score between 1 and 10 for each category.
	+ Type: number
	+ Required: False
* **Total Score**: The total score for the song.
	+ Type: number
	+ Required: False
* **Feedback**: Any feedback you have for the song.
	+ Type: text
	+ Required: False
* **Category**: The category the song belongs to.
	+ Type: text
	+ Required: False
* **Sub Category**: The subcategory the song belongs to.
	+ Type: text
	+ Required: False
* **Prize Name**: The name of the prize for the winner.
	+ Type: text
	+ Required: False
* **Prize Value**: The value of the prize.
	+ Type: text
	+ Required: False
* **Comments**: Any additional comments you have for the song.
	+ Type: text
	+ Required: False
* **Award Date**: The date the award was made.
	+ Type: date
	+ Required: False
