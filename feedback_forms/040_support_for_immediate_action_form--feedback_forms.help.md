# Support For Immediate Action Form - Help Guide

## Purpose

The Support For Immediate Action Form is a channel for requesting support for urgent matters that need attention from the team or stakeholders. Use this form to get help when you need it the most, but make sure you haven't already reported the issue or request.

## How To Complete This Form

1.  Fill in your name to help us identify who's requesting support.
2.  Choose the type of request you're making (e.g., "Yes" or "No").
3.  Briefly describe the issue or request.
4.  Provide any relevant contact information so we can get back to you.
5.  Enter your email address if you'd like to be contacted directly.
6.  Indicate the level of urgency you're facing (High, Medium, or Low).
7.  Specify what action is requested.

## Field-by-Field Explanation

### 1. Enter your name

*   `requester_name` (`text`, required: false): Please fill in your name so we can address your request correctly.

### 2. Request type

*   `request_type` (`select_one`, required: false): Choose the type of request you're making (e.g., "Yes" or "No").

### 3. Description of the request

*   `request_description` (`text`, required: false): Briefly describe the issue or request you need help with.

### 4. Contact information

*   `contact_information` (`text`, required: false): Provide any relevant contact details so we can get back to you.

### 5. Email

*   `email` (`email`, required: false): Enter your email address if you'd like to be contacted directly.

### 6. Level of urgency

*   `urgent_level` (`select_one`, required: false): Indicate the level of urgency you're facing (High, Medium, or Low).

### 7. Action requested

*   `requested_action` (`text`, required: false): Specify what action is needed.
