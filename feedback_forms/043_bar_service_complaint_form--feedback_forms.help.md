# Bar Service Complaint Form - Help Guide
## Purpose
The Bar Service Complaint Form is used to report any issues or concerns you experienced while visiting one of our bars. This form is meant to be used for reporting problems with service, food and beverage quality, and other issues affecting your experience. Please note that this form is intended for internal use only and will not be shared with anyone outside of our organization. If you have already submitted a complaint, please do not resubmit it. Duplicate complaints will be reviewed only once.

## How To Complete This Form
To complete this form, please follow these steps:

1. Click on the "Submit" button to begin.
2. Fill out each field according to the provided hints and labels.
3. Make sure to complete all required fields.
4. Select the correct options for each field when applicable.
5. Click the "Submit" button to send your complaint.

## Field-by-Field Explanation
### Date of Complaint (Page 1)
* **Date of Complaint** (`complaint_date`, `date`, required): Enter the date of your visit using the date picker or manually enter the date in the format MM/DD/YYYY.
### Your Name (Page 1)
* **Your Name** (`complainant_name`, `text`, required): Enter your full name as it appears on your identification.
### Email Address (Page 1)
* **Email Address** (`complainant_email`, `email`, required): Enter your contact email address.
### Phone Number (Page 1)
* **Phone Number** (`complainant_phone`, `text`, required): Enter your contact phone number.
### Date of Visit (Page 2)
* **Date of Visit** (`visit_date`, `date`, required): Enter the date when the issue occurred using the date picker or manually enter the date in the format MM/DD/YYYY.
### Time of Visit (Page 2)
* **Time of Visit** (`visit_time`, `time`, optional): Select the approximate time of your visit.
### Bar Name (Page 2)
* **Bar Name** (`bar_name`, `text`, required): Enter the name of the bar establishment.
### Bar Location/Address (Page 2)
* **Bar Location/Address** (`bar_location`, `text`, required): Enter the address of the bar establishment.
### Staff Member Involved (Page 3)
* **Staff Member Involved** (`staff_member_involved`, `text`, optional): If you know the name of the staff member involved, please enter it.
### Complaint Category (Page 3)
* **Complaint Category** (`complaint_category`, `select_one`, required): Select the category of your complaint from the options:
	+ Slow Service
	+ Rude Staff
	+ Poor Drink Quality
	+ Incorrect Order
	+ Unsanitary Conditions
	+ Overcharging
	+ Other
### Service Speed Issue (Page 3)
* **Service Speed Issue** (`service_speed`, `select_one`, optional): Select the level of service speed from the options:
	+ Extremely Slow
	+ Very Slow
	+ Somewhat Slow
	+ Not About Speed
### Staff Behavior Issue (Page 4)
* **Staff Behavior Issue** (`staff_behavior`, `text`, optional): If you experienced any staff behavior issue, please describe it.
### Drink Quality Issue (Page 4)
* **Drink Quality Issue** (`drink_quality_issue`, `select_one`, optional): Select the type of drink quality issue from the options:
	+ Wrong Drink Served
	+ Drink Was Cold
	+ Drink Was Too Strong
	+ Drink Was Too Weak
	+ Incorrect Ingredients
	+ Bad Taste
	+ Other
### Order Accuracy Issue (Page 4)
* **Order Accuracy Issue** (`order_accuracy`, `text`, optional): If the order was incorrect, please describe the issue.
### Cleanliness Issue (Page 5)
* **Cleanliness Issue** (`cleanliness_issue`, `select_one`, optional): Select the type of cleanliness issue from the options:
	+ Dirty Glass
	+ Dirty Glassware or Bar Top
	+ Dirty Restroom
	+ Dirty Floor
	+ Pest Sighting
	+ Other
### Billing Issue (Page 5)
* **Billing Issue** (`billing_issue`, `text`, optional): If you experienced a billing issue, please describe it.
### Detailed Description of Issue (Page 5)
* **Detailed Description of Issue** (`detailed_complaint`, `text`, required): Provide a detailed description of the issue you experienced.
### Witnesses (Page 6)
* **Were There Witnesses?** (`witnesses`, `select_one`, optional): Select if there were witnesses:
	+ Yes
	+ No
### Witness Names or Contact Info (Page 6)
* **Witness Names or Contact Info** (`witness_names`, `text`, optional): If available, provide witness names or contact information.
### Desired Resolution (Page 6)
* **Desired Resolution** (`resolution_desired`, `text`, optional): Select the type of resolution desired:
	+ null
### Refund Requested (Page 6)
* **Refund Requested** (`refund_requested`, `select_one`, optional): Select if a refund is requested:
	+ Yes
	+ No
	+ Partial Refund
### Preferred Follow-Up Method (Page 6)
* **Preferred Follow-Up Method** (`follow_up_preference`, `select_one`, required): Select the preferred method of contact:
	+ Email
	+ Phone
	+ In Person
	+ Text Message
	+ Mail

## Tips

* Make sure to complete all required fields.
* Select the correct options for each field when applicable.
* Provide as much detail as possible in the "Detailed Description of Issue" field.
* If you have any supporting documentation or evidence, please attach it to the form or provide it separately.
* If you have any further questions or concerns, please contact us directly.
