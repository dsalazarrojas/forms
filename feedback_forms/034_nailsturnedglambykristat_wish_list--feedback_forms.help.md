# NailsTurnedGlambyKristaT Wish List - Help Guide

## Purpose
This form is designed to collect information from users about their nail preferences. It is used to gather data on what type of nails they would like and how many they would like, among other things. Please take a few minutes to complete this form accurately.

## How To Complete This Form
1. Select the options that apply to you for each of the "wish_list" fields. This field has multiple select options.
2. Enter your answer to the "nails_typed" field.
3. Enter your answer to the "color" field.
4. Choose one of the options for the "nail_type" field.
5. Enter a number for the "nail_size" field.
6. Select the options that apply to you for the "nails_wanted" fields. This field has multiple select options.
7. Enter a number for the "nail_length" field.
8. Enter a number for the "nail_width" field.
9. Enter your answer to the "nail_shape" field.

## Field-by-Field Explanation
* **wish_list** (Select Multiple, Optional): This field is asking if you want to turn any nails. Please select all the options that apply to you.
* **nails_typed** (Text, Optional): Enter the type of nails you are looking for, or would like to know more about.
* **color** (Text, Optional): Enter the color of the nails you are looking for or would like to know more about.
* **nail_type** (Select One, Optional): Choose the type of nail shape you are looking for.
* **nail_size** (Number, Optional): Enter the number of nails you are looking for.
* **nails_wanted** (Select Multiple, Optional): This field is asking if you would like to have more nails. Please select all the options that apply to you.
* **nail_length** (Number, Optional): Enter the length of the nails you are looking for.
* **nail_width** (Number, Optional): Enter the width of the nails you are looking for.
* **nail_shape** (Text, Optional): Enter the shape of the nail you are looking for or would like to know more about.
