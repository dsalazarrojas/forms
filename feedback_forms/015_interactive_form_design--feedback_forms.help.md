# Interactive Form Design - Help Guide
## Purpose

This form is designed to collect feedback on the Interactive Form Design template. It's meant for users who have experience with the template and want to provide their thoughts on how to improve it.

## How To Complete This Form

1. Please fill out the form title field to describe what you want to feedback on.
2. Choose the category of feedback you are providing (e.g., Feedback Forms).
3. In the description field, provide a brief explanation of your feedback.
4. If you have any specific suggestions for improving the template, please mention them in the description field.
5. If you have a preferred tool for creating interactive forms, select it from the options provided (e.g., Chatjimmy).
6. Finally, provide your name or any other relevant information in the output file field.

## Field-by-Field Explanation

* **Form Title** (`form_title`, text, required): Enter the title of the form you want to provide feedback on.
* **Category** (`category`, select_one, optional): Choose the type of feedback you are providing (e.g., Feedback Forms).
* **Description** (`description`, text, optional): Provide a brief explanation of your feedback.
* **Description** (`form_description`, text, optional): Describe how you currently use the template or what you would like to improve.
* **Tool** (`assigned_tool`, select_one, optional): If you have a preferred tool for creating interactive forms, select it from the options provided.
* **Output File** (`output_file`, text, optional): If you want to add any additional information about yourself, you can do so here.
