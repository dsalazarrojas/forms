# QCM Developer Feedback Form - Help Guide
## Purpose
This form is designed to collect feedback from QCM (Quality Control Metrics) developers. The purpose of this form is to gather information about the satisfaction of the developers with the QCM system and identify areas for improvement.

## How To Complete This Form
1. Please fill out the form completely and accurately to provide us with your feedback.
2. The form is divided into several sections, each with its own fields that need to be filled out.
3. Make sure to choose the correct ratings and comments that best represent your opinions.

## Field-by-Field Explanation
* **Title** (`feedback_form`, note, required: false): This is the title of the form, and it's not required to be filled out as it's a placeholder.
* **Feedback** (`feedback`, text, required: false): Please provide us with your overall feedback about the QCM system in this text field.
* **Satisfaction Score** (`satisfaction_score`, select_one, required: true): Rate your satisfaction with the QCM system using the 1-5 scale. The options are:
	+ 1: Very dissatisfied
	+ 2: Somewhat dissatisfied
	+ 3: Neutral
	+ 4: Somewhat satisfied
	+ 5: Very satisfied
* **Developer ID** (`developer_id`, select_one, required: true): Please choose the developer ID that corresponds to you.
* **QCM System Rating** (`qcm_system_rating`, select_multiple, required: true): Rate the QCM system as:
	+ Good
	+ Excellent
	+ Poor
	+ Bad
* **Improve Areas** (`improvement_areas`, select_multiple, required: true): Identify the areas where you think the QCM system can be improved. You can choose multiple areas.
* **Comments** (`comments`, text, required: false): If you have any additional comments or suggestions, please provide them in this text field.
* **Submit** (`submit`, text, required: false): Please submit your feedback by clicking on the "Submit" button.

## Tips
* Please be as specific as possible when filling out the form.
* If you have any suggestions or comments, please use the "Comments" field.
* If you have any questions or need assistance, please contact us at form@gic.mx.
