# Late Delivery Complaint Form - Help Guide
## Purpose
The Late Delivery Complaint Form is used to gather information from customers about issues with the delivery time of a specific order.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter your **Customer Name**: This is the name of the customer who is reporting the issue.
2. Enter your **Order Number**: This is the number of the order that is related to the issue.
3. Select the **Delivery Date**: This is the date that the order was supposed to be delivered.
4. Add any **Delivery Note**: If there's any relevant information about the delivery that you'd like to add, please include it here.
5. Enter your **Contact Email**: This is the email address where you can be reached to discuss the issue.
6. Enter your **Contact Phone Number**: This is the phone number where you can be reached to discuss the issue.
7. Select who the issue should be **Assigned To**: This is the person who will be handling the resolution of the issue.
8. Select the current **Status**: This is the current status of the issue, which can be New, In Progress, Resolved, or Closed.
9. Add any additional **Resolution Note**: If there's any further information that you'd like to add about the resolution, please include it here.

## Field-by-Field Explanation

* **Customer Name**: This is the name of the person reporting the issue.
* **Order Number**: This is the number of the order that is related to the issue.
* **Delivery Date**: This is the date that the order was supposed to be delivered.
* **Delivery Note**: This is any additional information about the delivery that you'd like to add.
* **Customer Note**: This is any additional information that the customer would like to add.
* **Contact Email**: This is the email address where you can be reached to discuss the issue.
* **Contact Phone**: This is the phone number where you can be reached to discuss the issue.
* **Assigned To**: This is the person who will be handling the resolution of the issue.
* **Status**: This is the current status of the issue, which can be New, In Progress, Resolved, or Closed.
* **Resolution Note**: This is any additional information that you'd like to add about the resolution.

## Tips

* Please ensure that the information is accurate and complete.
* If the customer has already reported this issue, please do not create another entry as it will be treated as a duplicate.
* Please fill out each field carefully, as it will be used for investigation and resolution.
