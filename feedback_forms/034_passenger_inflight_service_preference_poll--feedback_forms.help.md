# Passenger Inflight Service Preference Poll - Help Guide
## Purpose
This form is designed to collect feedback from passengers on the inflight service, allowing the airline to understand their opinions and make improvements.

## How To Complete This Form
To complete this form, follow these steps:

1. Select your preferences for the inflight service by choosing your answers from the options provided.
2. Rate your satisfaction with the inflight service.
3. If you have any suggestions or recommendations for the service, type them in the text field.
4. Choose your preferences for routes and cabin priority.

## Field-by-Field Explanation

* **Inflight Service Preference** (`inflight_service_preference`, select_multiple, required: false): This field allows you to select multiple options for the inflight service preferences. Select 'Yes' if you have a preference for the service, 'No' otherwise.
* **How would you rate the inflight service?** (`service_satisfaction`, select_one, required: false): This field allows you to rate the inflight service as either 'Good' or 'Fair'.
* **Do you have a recommendation for the service?** (`recommendation_for_service`, text, required: false): This field is for any suggestions or recommendations you may have for improving the inflight service. Type your feedback in this text field.
* **Which route would you like us to prioritize?** (`route_preference`, select_multiple, required: false): This field allows you to select multiple routes you would like to be prioritized.
* **Which cabin would you like us to prioritize?** (`cabin_preference`, select_multiple, required: false): This field allows you to select multiple cabins you would like to be prioritized.

## Tips
- Please provide clear and specific feedback where possible.
- If you have a suggestion, try to be as concrete as possible.
- If you have multiple preferences, select all relevant options for that field.
