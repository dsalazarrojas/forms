# Productivity Tool Usage Report Form - Help Guide
## Purpose
The Productivity Tool Usage Report Form is a tool for collecting information about the usage of productivity tools across the organization. This form is designed to gather data about which tools are being used, by whom, and to what extent.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the type of tool you used from the dropdown menu.
2. Enter the name of the tool you used, if it is not already listed in the dropdown menu.
3. Report on your usage of the tool by entering the number of hours you used it.
4. Enter your name as the user who completed the form.
5. Select the role(s) that you played when using the tool.

## Field-by-Field Explanation

* **Tool Type (1)** (`select_one`, required): Choose from Microsoft Office, Google Workspace, or Other.
* **Tool Name (2)** (`text`, optional): Enter a brief description or the actual name of the tool you used.
* **Tool Usage (3)** (`number`, optional): Report on the amount of time you spent using the tool.
* **User Name (4)** (`text`, optional): Enter your name as the user who completed the form.
* **User Role (5)** (`select_multiple`, optional): Choose from Admin, Team Lead, or Member.

## Tips

* If you are unsure of the tool type, select "Other" and enter a brief description of the tool.
* If you are reporting on a custom or internal tool, please enter the name of the tool instead of "Other".
* You can report on multiple tools in multiple submissions of this form.
* The data collected from this form will be used to identify trends and patterns in tool usage across the organization.
