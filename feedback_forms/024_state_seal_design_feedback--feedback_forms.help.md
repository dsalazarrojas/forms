# State Seal Design Feedback - Help Guide
## Purpose
This form is designed to gather feedback from users regarding the design of a state seal, which will be used to inform and improve the design.

## How To Complete This Form
1. Select the design concept that best represents the state or region. 
2. Rate the color and shape of the design using numerical ratings.
3. Provide additional comments or feedback.
4. Rate the overall design.
5. Enter any comments or questions about the design.

## Field-by-Field Explanation
### State Seal Design Feedback Page
This page is the main feedback section where you can rate the design of the state seal.

### Select Design Concept
* **Select Design Concept** (`state_seal_design_feedback_input`, `select_one`, *required*):
	+ Choose the design concept that best represents the state or region.

### Seal Color Rating
* **Seal Color Rating** (`state_seal_color_rating`, `number`, *optional*):
	+ Rate the color of the design on a scale of 1-10.

### Seal Shape Rating
* **Seal Shape Rating** (`state_seal_shape_rating`, `number`, *optional*):
	+ Rate the shape of the design on a scale of 1-10.

### Seal Font Rating
* **Seal Font Rating** (`state_seal_font_rating`, `number`, *optional*):
	+ Rate the font of the design on a scale of 1-10.

### Overall Design Rating
* **Overall Design Rating** (`state_seal_design_rating`, `number`, *optional*):
	+ Rate the overall design on a scale of 1-10.

### Comments
* **Comments** (`state_seal_comments`, `note`, *optional*):
	+ Enter any comments or feedback about the design.

### Email
* **Email** (`state_seal_email`, `email`, *optional*):
	+ Enter your email address so we can follow up with you.

### Phone
* **Phone** (`state_seal_phone`, `text`, *optional*):
	+ Enter your phone number so we can follow up with you.

### Additional Comments
* **Additional Comments** (`state_seal_additional_comments`, `note`, *optional*):
	+ Enter any additional comments or feedback about the design.
