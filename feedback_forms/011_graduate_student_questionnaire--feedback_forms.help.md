# graduate_student_questionnaire - Help Guide
## Purpose
This form is designed to collect feedback from students about their experience in the graduate program at [University Name].

## How To Complete This Form
1. Make sure you have the necessary permissions to access and complete this form.
2. Ensure that this form is relevant to your role and the feedback you want to provide.
3. Carefully review each field to ensure you have provided accurate and complete information.
4. Submit the form once you have completed all required fields.

## Field-by-Field Explanation
* **Student ID** (`student_id`, `text`, required): This field is used to identify the student who is providing feedback. Please enter your student ID number.
* **Graduation Program** (`graduation_program`, `select_one`, required): Answer this question by selecting one of the following options: Yes or No. If you answer Yes, you will be asked to provide additional comments about your graduation program experience.
* **Graduation Program Other** (`graduation_program_other`, `text`, optional): If you answered Yes to the previous question, please provide additional comments about your graduation program experience.
* **Service Quality** (`service_quality`, `select_multiple`, required): Answer this question by selecting one or more of the following options: Good, Poor. If you are not satisfied with the service, please explain why.
* **Satisfaction** (`satisfaction`, `number`, required): Rate your satisfaction with the service by selecting a number (e.g., 1, 2, 3, etc.).
* **Graduation Program Rating** (`graduation_program_rating`, `select_one`, required): Answer this question by selecting one of the following options: Good, Fair. If you answered Fair, please provide additional comments explaining why.
* **Graduation Program Comment** (`graduate_program_comment`, `text`, optional): Provide any additional comments about your graduation program experience.
* **Other Comments** (`other_comments`, `text`, optional): If you have any other comments or suggestions, please provide them here.
* **Graduation Program Suggestions** (`graduate_program_suggestions`, `text`, optional): If you have any suggestions for improving the graduation program, please provide them here.
* **Graduation Program Comments** (`graduation_program_comments`, `text`, optional): Provide any additional comments about the graduation program experience.
* **Overall Satisfaction** (`overall_satisfaction`, `time`, required): Rate your overall satisfaction with the service by entering the time (e.g., 1 minute, 10 minutes, etc.).
