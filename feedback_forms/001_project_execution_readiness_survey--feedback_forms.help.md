# Project Execution Readiness Survey - Help Guide

## Purpose
The Project Execution Readiness Survey is designed to assess the readiness of a project for launch. It gathers information on the project's status, lead and team structure, and other critical factors that can impact its success.

## How To Complete This Form
To complete this form, please fill out the following fields:

## Field-by-Field Explanation

* **Project Launch Readiness** (`project_launch_readiness`, text, not required): This field is for providing a general description of the project's launch readiness.
* **Project Details** (`project_details`, text, not required): This field is for providing additional details about the project.
* **Project Lead** (`project_lead`, select_multiple, not required): Please select whether the project lead is 'Yes' or 'No'.
* **Team Lead** (`team_lead`, select_multiple, not required): Please select whether the team lead is 'Yes' or 'No'.
* **Project Lead** (`project_lead`, text, not required): This field is for providing a name of the project lead.
* **Team Lead** (`team_lead`, text, not required): This field is for providing a name of the team lead.
* **Start Date** (`date_start`, date, not required): This field is for selecting the project's start date.
* **Start Time** (`start_time`, time, not required): This field is for selecting the project's start time.
* **Estimated Duration** (`estimated_duration`, number, not required): This field is for providing the estimated duration of the project.
* **Project Manager** (`project_manager`, text, not required): This field is for providing a name of the project manager.
* **Project Coordinator** (`project_coordinator`, text, not required): This field is for providing a name of the project coordinator.
* **Project Executive** (`project_executive`, text, not required): This field is for providing a name of the project executive.
* **Project Sponsor** (`project_sponsor`, text, not required): This field is for providing a name of the project sponsor.
* **Project Sponsor Title** (`project_sponsor_title`, text, not required): This field is for providing a title of the project sponsor.
* **Project Sponsor Department** (`project_sponsor_department`, text, not required): This field is for providing the department of the project sponsor.
* **Contact Person** (`contact_person`, text, not required): This field is for providing a contact person's name.
* **Contact Phone** (`contact_phone`, text, not required): This field is for providing a contact person's phone number.
* **Contact Email** (`contact_email`, email, not required): This field is for providing a contact person's email address.
* **Project Status** (`project_status`, select_multiple, not required): Please select whether the project status is 'Active' or 'Inactive'.
* **Project Status Comments** (`project_status_comments`, text, not required): This field is for providing comments on the project status.
* **Comments** (`comments`, note, not required): This field is for providing additional comments.
* **Notes** (`notes`, note, not required): This field is for providing additional notes.
* **Submitter** (`submitter`, text, not required): This field is for providing a submitter's name.
* **Submit Date** (`submit_date`, date, not required): This field is for selecting the submit date.
* **Submit Time** (`submit_time`, time, not required): This field is for selecting the submit time.

## Tips
* Please fill out the form thoroughly and accurately.
* If you need help or have questions, don't hesitate to ask.
* Review your answers carefully before submitting the form.
