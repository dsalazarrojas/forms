# global_health_equity_awareness_survey - Help Guide
## Purpose
The global health equity awareness survey is designed to collect information from users on their overall awareness on various health equity topics. This form aims to provide a general understanding of the user's perspective on the current state of health equity in the community.

## How To Complete This Form
To complete this form, please follow the instructions below:

* Please provide your general information, including your contact details.
* Select the relevant option that best describes your current awareness on the health equity topics.
* Provide any additional information you would like to share about your experience or concerns.

## Field-by-Field Explanation

* **General Information** (Page 1): This is the first page of the form. Please fill in your general information, including any necessary contact details.
* **Contact Information** (Page 2): Please enter your email address and/or phone number. This will allow us to contact you if needed.
* **Email** (Page 3): Please enter your email address. This will allow us to contact you if needed.
* **Phone** (Page 4): Please enter your phone number. This will allow us to contact you if needed.
* **Select Option** (Page 5): This page will allow you to choose the option that best describes your current awareness on the health equity topics. Please select one of the options provided.
* **Select Multiple** (Page 6): This page will allow you to select multiple options that best describe your current awareness on the health equity topics. Please select all the options that apply.
* **Date** (Page 7): This field is used to select a date. Please select a date from the calendar.
* **Time** (Page 8): This field is used to select a time. Please select a time from the options provided.
* **Additional Information** (Page 9): This is an open field for you to provide any additional information about your experience or concerns.
* **Integer Field** (Page 10): This field is used to select an integer value. Please select a whole number.
* **Decimal Field 1-10** (Pages 11-21): These fields are used to select decimal values. Please select decimal values between 0 and 10.
* **Date 2** (Page 22): This field is used to select a date. Please select a date from the calendar.
* **Time 2** (Page 23): This field is used to select a time. Please select a time from the options provided.
* **Integer Field 2-4** (Pages 24-26): These fields are used to select integer values. Please select whole numbers. 

Note: Some fields are optional and not required for submission.
