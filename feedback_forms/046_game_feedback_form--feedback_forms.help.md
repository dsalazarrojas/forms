# Game Feedback Form - Help Guide
## Purpose
The Game Feedback Form is a tool for providing constructive feedback on games and gaming experiences. It allows users to submit ratings and comments on games they have played, which can be used to improve game development and provide a platform for community engagement.

## How To Complete This Form
To complete this form, please follow these steps:

1. Enter the name of the game you are providing feedback on in the "Game Name" field.
2. Rate the game using the "Game Rating" field, which accepts numerical ratings from 1 to 5.
3. Provide any additional feedback or comments in the "Feedback" field.
4. Select the rating value for the game by choosing one of the available options in the "Rating Value" field.
5. Select the rating scale you wish to use by choosing one of the available options in the "Rating Scale" field.
6. Provide the date and time of when you played the game in the "Feedback Date" and "Feedback Time" fields.
7. Specify the type of game you played by selecting one or multiple options in the "Game Type" field (Tabletop or Video Game).
8. If desired, provide your email address in the "Email" field.
9. If desired, provide your phone number in the "Phone" field.
10. Add any additional notes or comments in the "Note" field.

## Field-by-Field Explanation

* **Game Name** (text): Enter the name of the game you are providing feedback on.
* **Game Rating** (number): Rate the game using a numerical rating from 1 to 5.
* **Feedback** (text): Provide any additional feedback or comments on the game.
* **Rating Value** (number): Select the rating value for the game using one of the available options.
* **Rating Scale** (select_one): Select the rating scale to use for the game feedback.
* **Feedback Date** (date): Enter the date you played the game.
* **Feedback Time** (time): Enter the time you played the game.
* **Game Type** (select_multiple): Select the type of game you played, either Tabletop or Video Game.
* **Email** (email): Enter your email address if you wish to receive updates or communications.
* **Phone** (text): Enter your phone number if you wish to be contacted for further questions or feedback.
* **Note** (note): Add any additional notes or comments on the game.
