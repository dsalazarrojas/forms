# Form Copy Paste Feedback - Help Guide
## Purpose
This form is designed to collect feedback from users about their experience with the copy paste feature in our product. Your feedback will help us identify areas for improvement and enhance the overall performance of this feature.

## How To Complete This Form
To complete this form, simply follow these steps:

1.  Read through each section carefully and provide your feedback.
2.  Answer all required fields (indicated by the \* symbol).
3.  For questions that don't require a written answer, select the most suitable option from the list.
4.  Make sure to provide a detailed description of any issues you encountered.

## Field-by-Field Explanation

### Introduction
*   **Introduction** (`text`, required): Please provide a brief introduction to your feedback. This section is where you can mention any context or background information about your feedback.

### Copy Paste Feature
*   **Copy Paste Feature** (`text`, required): Share your experience with the copy paste feature. Describe how it performed and what worked or didn't work as expected.

### Satisfaction
*   **Satisfaction** (`number`, required): Please rate your level of satisfaction with the copy paste feature on a scale of 1-10, where 1 is "very dissatisfied" and 10 is "very satisfied".

### Issues Found
*   **Issues Found** (`select_one`, required): Check the boxes for any issues you encountered while using the copy paste feature. You can select one or more from the following options:
    +   Device
    +   Browser
    +   Feature
    +   None

### Description of Issues
*   **Description** (`note`, required): For any issues you selected, please provide a detailed description to help us understand what happened.
