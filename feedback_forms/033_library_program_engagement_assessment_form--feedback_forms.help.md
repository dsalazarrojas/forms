# Library Program Engagement Assessment Form - Help Guide
## Purpose
This form is designed to collect information from library program users about their engagement and experiences with the library's programs.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter your feedback in the text box provided.
2. Select your event type (Event, Program, Service) from the dropdown menu.
3. Enter the number of programs you have attended in the "How Many Programs Did You Attend?" field.
4. Enter the specific numbers of programs you have attended in the "Program Attendance" fields (1, 2, and 3). 
5. Rate your overall experience with the program in the "Overall Rating" field.
6. Select how often you attend library programs in the "How Often Do You Attend" field.
7. Choose how you would like to be contacted (Phone, Email, Other) in the "Would You Like To Be Contacted" field.
8. Enter your contact information in the respective fields (Phone, Email, Other).
9. Add any additional comments about your experience in the "Additional Comments" field.

## Field-by-Field Explanation

* **Program Title**: Enter the title of the program you are providing feedback on.
* **Event Type**: Select the type of event you attended (Event, Program, Service).
* **How Many Programs Did You Attend**: Enter the number of programs you have attended.
* **Program Attendance 1**: Enter the number of times you attended program 1.
* **Program Attendance 2**: Enter the number of times you attended program 2.
* **Program Attendance 3**: Enter the number of times you attended program 3.
* **Overall Rating**: Rate your experience with the program on a scale of 1-5.
* **How Often Do You Attend**: Select how often you attend library programs (Daily, Weekly, Rarely).
* **Would You Like To Be Contacted**: Choose how you would like to be contacted (Phone, Email, Other).
* **Phone**: Enter your phone number if you would like to be contacted by phone.
* **Email**: Enter your email address if you would like to be contacted by email.
* **Other**: Enter any other contact information if you have selected "Other" in the "Would You Like To Be Contacted" field.
* **Additional Comments**: Enter any additional comments about your experience with the program.

## Tips
- Please fill out the form honestly and thoroughly.
- Ensure that you have selected the correct event type and provided accurate contact information.
- If you have any questions or concerns, feel free to reach out to the library staff.
