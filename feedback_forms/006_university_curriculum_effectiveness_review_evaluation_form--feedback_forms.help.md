# University Curriculum Effectiveness Review Evaluation Form - Help Guide
## Purpose
This form is designed to collect feedback from users about the effectiveness of university programs.

## How To Complete This Form
To complete this form, please follow these steps:

1. Ensure that you have a clear understanding of the program you are providing feedback on.
2. If you have already provided feedback on this program, please do not complete this form again.
3. Please select the appropriate program type (Bachelors, Masters, Doctoral) that corresponds to your experience with the program.
4. Enter your feedback score, with 1 being the lowest and 5 being the highest.
5. Provide a brief comment about your experience with the program.
6. If you have any additional comments or suggestions, you can provide them in the "additional comments" field.
7. Enter your email address and phone number (optional) so that we can contact you if needed.

## Field-by-Field Explanation
### Program ID
* (Program ID, number, required) : This field is used to identify the program you are providing feedback on. Please enter the correct program ID number from your university records.

### Program name
* (Program name, text, optional) : Enter the name of the program you are providing feedback on. This will help us to understand the context of your feedback.

### Department name
* (Department name, text, optional) : Enter the name of the department where the program is located. This will help us to understand the context of your feedback.

### Program type
* (Program type, select_one, required) : Select the type of program you are providing feedback on, which is one of Bachelors, Masters, or Doctoral.

### Academic year
* (Academic year, number, optional) : Enter the academic year you attended the program. If you are providing feedback on a specific year, please enter that year.

### Feedback score
* (Feedback score, number, required) : Provide a score from 1 to 5, where 1 is the lowest and 5 is the highest, to indicate your overall satisfaction with the program.

### Feedback comment
* (Feedback comment, text, required) : Please provide a brief comment about your experience with the program.

### Email
* (Email, email, optional) : Enter your email address so that we can contact you if needed.

### Phone
* (Phone, text, optional) : Enter your phone number so that we can contact you if needed.

### Additional comments
* (Additional comments, text, optional) : If you have any additional comments or suggestions, please provide them here.
