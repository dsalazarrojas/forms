# Art For Social Change Impact Survey - Help Guide
## Purpose
The purpose of this form is to collect data on art projects that aim to bring about social change. The data will be used to evaluate and improve the project, identify effective approaches, and inform future project development.

## How To Complete This Form

1. Fill in your name, email, and organization name (if applicable) in the 'Respondent Information' section.
2. Select the correct 'Organization Type' that best describes your organization.
3. Fill in the 'Project Name' and 'Project Start Date' in the 'Project Information' section.
4. Select the correct 'Project Category' and 'Target Audience' in the 'Project Information' section.
5. Fill in the approximate number of participants reached and the art forms used in the project in the 'Project Information' section.
6. Report on the project's goals, challenges faced, and lessons learned in the 'Impact and Evaluation' section.
7. Describe the impact of your project in the 'Impact and Evaluation' section.
8. Answer the questions on the 'Sustainability Plan' and 'Would Repeat' sections in the 'Impact and Evaluation' section.
9. Finally, provide any additional feedback or insights you may have in the 'Additional Feedback' section.

## Field-by-Field Explanation

* **Survey Date**: This field is used to record the date when you completed the survey.
* **Respondent Name**: This field is used to record your name. If you are filling the form on behalf of an organization, this field can be left blank.
* **Respondent Email**: This field is used to record your email address. If you are filling the form on behalf of an organization, this field can be left blank.
* **Organization Name**: This field is used to record the name of your organization.
* **Organization Type**: This field is used to select the type of organization you belong to.
* **Project Name**: This field is used to record the name of the art project.
* **Project Start Date**: This field is used to record the start date of the project.
* **Project Status**: This field is used to select the current status of the project.
* **Project Category**: This field is used to select the category of the project.
* **Target Audience**: This field is used to select the target audience of the project.
* **Participants Reached**: This field is used to record the approximate number of participants reached by the project.
* **Art Forms Used**: This field is used to select all art forms used in the project.
* **Community Involvement**: This field is used to select the level of community involvement in the project.
* **Project Goals**: This field is used to record the main goals of the project.
* **Goals Achieved**: This field is used to select the extent to which the project's goals were achieved.
* **Impact Areas**: This field is used to select areas where the project's impact was observed.
* **Impact Description**: This field is used to describe the impact of the project.
* **Success Stories**: This field is used to share any success stories or testimonials.
* **Challenges Faced**: This field is used to report on the challenges faced during the project.
* **Lessons Learned**: This field is used to record any lessons learned from the project.
* **Funding Sources**: This field is used to select all funding sources for the project.
* **Budget Range**: This field is used to select the approximate project budget.
* **Partnerships**: This field is used to select whether the project had any partners.
* **Partnership Details**: This field is used to describe any project partnerships.
* **Sustainability Plan**: This field is used to describe how the project will continue or have lasting impact.
* **Would Repeat**: This field is used to select whether you would do the project again.
* **Recommend to Others**: This field is used to select whether you would recommend this approach to others.
* **Additional Feedback**: This field is used to provide any additional feedback or insights.

## Tips

* Please ensure that you complete all required fields.
* If you are not sure about any field, you can leave it blank if it's marked as optional.
* If you are filling the form on behalf of an organization, you can use the organization's name, email, and other details.
* The data collected will help to improve the project and inform future project development.
* If you have any further questions or need help, please contact Art for Social Change.
* This form is for the purpose of evaluation and improvement of the project, not for commercial use.
* Please keep the responses honest and accurate.
* If you are unable to provide information on any field, please provide an explanation.
* If you have any questions or concerns, please contact Art for Social Change.
