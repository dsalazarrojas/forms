# Amazon Order Return Form - Help Guide
## Purpose
The Amazon Order Return Form is used to provide information about an order return, including order details, return reason, return resolution, and return shipping information.

## How To Complete This Form
1. Start by filling out the order information section. This includes:
	* Order Number: Enter the order number for the order you are returning. This can be found in your confirmation email.
	* Order Date: Enter the date you received the order.
2. Next, fill out the customer information section. This includes:
	* First Name: Enter your first name.
	* Last Name: Enter your last name.
	* Email Address: Enter your email address.
	* Phone Number: Enter your phone number.
3. The item details section should be filled out with:
	* Item Name: Enter the product title.
	* Item SKU/ASIN: Enter the item SKU/ASIN if available.
	* Quantity to Return: Enter the number of items you are returning.
4. The return reason section is used to select the reason for return:
	* Reason for Return: Select the primary reason for return from the list.
	* Please Provide More Details: Enter any additional information about the return reason.
5. The return resolution section is used to select the preferred resolution:
	* What Resolution Would You Prefer: Select the preferred resolution from the list.
6. The return shipping section should be filled out with:
	* Return Shipping Method: Select the method for returning the item.
	* Do You Need a Return Shipping Label: Select if you need the label to be emailed to you.
7. If applicable, fill out the return shipping address:
	* Pickup Address: Enter the address for pickup if scheduling pickup.
8. The product feedback section is used to provide feedback about the product:
	* Product Rating: Rate the product's quality.
	* How Would You Rate Product Quality: Rate the product's quality.
	* Did the Product Match Its Description: Select if the product matched its description.
	* Would You Recommend This Product: Select if you would recommend the product.
9. The seller feedback section is used to provide feedback about the seller:
	* Seller Rating: Rate the seller's rating.
	* Seller Communication Rating: Rate the seller's communication.
10. Finally, provide any additional comments:
	* Additional Comments: Enter any additional comments about the return.
11. Lastly, grant permission for Amazon to contact you about the return:
	* May We Contact You About This Return: Select yes to grant permission.
