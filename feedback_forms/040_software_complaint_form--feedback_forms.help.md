# software_complaint_form - Help Guide
## Purpose
The software_complaint_form is used for internal use to gather complaints or issues related to software usage. This form helps track and resolve issues efficiently by capturing essential information about the user, issue type, and other relevant details.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the required fields with accurate and detailed information.
2. Ensure that all fields are filled out correctly before submitting the form.
3. Review the form carefully to ensure that it is complete and accurate before submitting.

## Field-by-Field Explanation

* **User ID** (`user_id`, Number, required): Enter your unique user ID to identify yourself for the issue.
* **Description** (`description`, Text, required): Describe the issue you are experiencing with the software.
* **Issue Type** (`issue_type`, Select One, required): Choose the type of issue you are experiencing (bug, crash, or other).
* **Report Date** (`report_date`, Date, required): Enter the date you experienced the issue.
* **Report Time** (`report_time`, Time, required): Enter the time you experienced the issue.
* **Report Location** (`report_location`, Text, required): Enter the location where you experienced the issue.
* **Report Comments** (`report_comments`, Note, required): Enter any additional comments or details about the issue.
* **Software Version** (`software_version`, Text, optional): If relevant, enter the version of the software you were using when the issue occurred.
* **User Compatibility** (`user_compatibility`, Select Multiple, required): Check if you were using the software with another compatible software or system.
* **Assigned To** (`assigned_to`, Select One, required): Choose who you think is responsible for resolving the issue (Yes or No).
* **Feedback Status** (`feedback_status`, Select One, required): Choose the status of your feedback (open, resolved, or closed).
* **Created At** (`created_at`, Date, required): Automatically populated by the system, do not fill out.
* **Updated At** (`updated_at`, Date, required): Automatically populated by the system, do not fill out.
* **Deleted At** (`deleted_at`, Date, optional): Automatically populated by the system, do not fill out.
* **Comments** (`comments`, Text, optional): If you have any additional comments or feedback, enter them here.
* **Status** (`status`, Select One, optional): If you have any status updates, choose them here.
* **Form ID** (`form_id`, Number, optional): Automatically generated by the system, do not fill out.
* **Assigned To Name** (`assigned_to_name`, Text, optional): If you know the name of the person assigned to resolve the issue, enter it here.
* **Assigned To Email** (`assigned_to_email`, Email, optional): If you know the email of the person assigned to resolve the issue, enter it here.
* **Assigned To Phone** (`assigned_to_phone`, Text, optional): If you know the phone number of the person assigned to resolve the issue, enter it here.
* **Category** (`category`, Text, required): Enter a category for the issue, e.g., bug, feature request, etc.
* **Category Label** (`category_label`, Text, optional): Enter a label for the category, e.g., Bug Tracking, Feature Request, etc.
* **Description Label** (`description_label`, Text, optional): Enter a label for the description of the issue, e.g., Brief description, detailed description, etc.
* **Assigned To Name Label** (`assigned_to_name_label`, Text, optional): Enter a label for the name of the person assigned to resolve the issue, e.g., Developer, QA, etc.

## Tips
* Make sure to review the form carefully before submitting it to ensure that all fields are filled out correctly.
* If you are unsure about any field, contact the support team for guidance.
* This form is for internal use only, do not share it with anyone outside the organization.
