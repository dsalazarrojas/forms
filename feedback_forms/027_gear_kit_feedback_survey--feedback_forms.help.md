# Gear Kit Feedback Survey - Help Guide

## Purpose

This form is designed to collect feedback on equipment and submission performance to help improve the overall gear kit experience.

## How To Complete This Form

To complete this form, please follow these steps:

1. Read the introduction page for a brief overview of the form's purpose.
2. Enter the Equipment ID, a numerical identifier for the equipment being assessed.
3. Enter the Equipment Name, a descriptive name for the equipment.
4. Rate the Equipment Condition using one of the provided options (Excellent, Good, Fair, Poor).
5. Provide comments on the equipment's condition in the Condition Comments field.
6. Rate the Performance of the equipment submission using one of the provided options (Excellent, Good, Fair, Poor).
7. Provide comments on the performance submission in the Performance Comments field.
8. Rate the overall submission performance using one of the provided options (Excellent, Good, Fair, Poor).
9. Provide comments on the overall submission performance in the Submission Comments field.

## Field-by-Field Explanation

* **Equipment Id (Equipment Id, number, required)**: Enter the numerical identifier for the equipment being assessed.
* **Equipment Name (Equipment Name, text, required)**: Enter a descriptive name for the equipment.
* **Equipment Condition (Equipment Condition, select_one, required)**: Rate the equipment's condition using one of the provided options (Excellent, Good, Fair, Poor).
* **Condition Comments (Condition Comments, text, optional)**: Provide additional comments on the equipment's condition if necessary.
* **Performance Rating (Performance Rating, number, required)**: Rate the performance of the equipment submission using one of the provided options (Excellent, Good, Fair, Poor).
* **Performance Comments (Performance Comments, text, optional)**: Provide comments on the equipment's performance submission if necessary.
* **Submission Rating (Submission Rating, select_one, required)**: Rate the overall submission performance using one of the provided options (Excellent, Good, Fair, Poor).
* **Submission Comments (Submission Comments, text, optional)**: Provide additional comments on the submission performance if necessary.
