# Masselgfx Order - Help Guide

## Purpose
This form is used to collect and document information about Masselgfx orders. It allows users to input relevant details such as customer contact information, order specifics, and assigned tasks.

## How To Complete This Form
1. Start by filling out your First Name, Last Name, and Email fields.
2. Enter your Phone number, which should be in the format of your standard phone number.
3. Enter your Order ID, if applicable.
4. Provide information about the Order.
5. Choose the Graphics Type by selecting at least one option from the drop-down list.
6. Select the Graphics Color you would like to have.
7. Enter the Graphics Size, if necessary.
8. Enter the Order Date and Order Time in the correct format (MM/dd/yy and HH:MM AM/PM respectively).
9. Add any additional Order Note if needed.
10. Select the Assigned Tool and Assigned User, if applicable.

## Field-by-Field Explanation

### First Name
* **First Name** (`first_name`, `text`, required): Enter your first name here. This field is required.

### Last Name
* **Last Name** (`last_name`, `text`, required): Enter your last name here. This field is required.

### Email
* **Email** (`email`, `email`, required): Enter your email address here. This field is required.

### Phone
* **Phone** (`phone`, `text`, required): Enter your phone number here. This field is required.

### Order ID
* **Order ID** (`order_id`, `number`, required): Enter your order ID here, if applicable. This field is optional.

### Order Info
* **Order Info** (`order_info`, `text`, required): Provide information about your order here. This field is required.

### Graphics Type
* **Graphics Type** (`graphics_type`, `select_multiple`, required): Choose the type of graphics you need by selecting at least one option from the list. This field is required.

### Graphics Color
* **Graphics Color** (`graphics_color`, `select_one`, required): Select the color of the graphics you need. This field is required.

### Graphics Size
* **Graphics Size** (`graphics_size`, `number`, required): Enter the size of the graphics you need, if necessary. This field is optional.

### Order Date
* **Order Date** (`order_date`, `date`, required): Enter the date of the order in the format of MM/dd/yy. This field is required.

### Order Time
* **Order Time** (`order_time`, `time`, required): Enter the time of the order in the format of HH:MM AM/PM. This field is required.

### Order Note
* **Order Note** (`order_note`, `note`, required): Add any additional order notes here, if needed. This field is optional.

### Assigned Tool
* **Assigned Tool** (`assigned_tool`, `text`, required): Select the tool assigned to this order, if applicable. This field is optional.

### Assigned User
* **Assigned User** (`assigned_user`, `text`, required): Select the user assigned to this order, if applicable. This field is optional.

## Tips

* Please ensure to fill out all required fields.
* Use the correct format for date and time fields.
* Select at least one option for Graphics Type and one option for Graphics Color.
* Enter phone number in the format of your standard phone number.
* Use the provided options for Assigned Tool and Assigned User, if applicable.
