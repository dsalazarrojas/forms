# Gaming New Features Feedback Report Form - Help Guide
## Purpose
The purpose of this form is to collect feedback from players regarding new features added to the game. Your input helps the development team understand what players think about the features and how to improve them.

## How To Complete This Form
- To complete this form, please navigate to the designated page and select the "How satisfied are you with the new feature?" option that best describes your feelings. Please select one of the provided options: New Features, Not Impressed, Somewhat Satisfied, or Not Satisfied.
- In the "Feature Name" field, enter the name of the new feature you are providing feedback on. This helps the development team understand which feature you are commenting on.
- If you feel it would be helpful, you can provide a description of the feature in the "Description" field. This can be a short paragraph explaining what the feature does and your understanding of its purpose.
- Please enter the category this feature falls under in the "Category" field. This helps the development team organize and filter feedback.
- If you have a rating for this feature, please enter it in the "Rating" field. A rating of 0-5 will help the development team understand your overall satisfaction with the feature.
- You can add any additional comments or observations about the feature in the "Comments" field.
- If you have a screenshot of the feature in action, please provide the URL in the "Screenshot URL" field. This can be a link to a screenshot you took or a publicly available image.
- Finally, click the "Submit" button to send your feedback to the development team.

## Field-by-Field Explanation
### How satisfied are you with the new feature?
* **New Features**: You are very satisfied with the new feature.
* **Not Impressed**: You are not satisfied with the new feature.
* **Somewhat Satisfied**: You have mixed feelings about the new feature.
* **Not Satisfied**: You are very dissatisfied with the new feature.

### Feature Name
* This is the name of the new feature you are providing feedback on.

### Description
* Please enter a description of the feature, if it would be helpful to the development team.

### Category
* Please enter the category this feature falls under (e.g. gameplay, graphics, etc.).

### Rating
* This is a rating from 0-5 where 0 is very dissatisfied and 5 is very satisfied.

### Comments
* Add any additional comments or observations about the feature here.

### Screenshot URL
* If you have a screenshot of the feature in action, please provide the URL here.

### Submit
* Click this button to send your feedback to the development team.
