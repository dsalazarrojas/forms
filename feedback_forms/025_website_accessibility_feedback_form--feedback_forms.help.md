# website_accessibility_feedback_form - Help Guide
## Purpose
This form is for reporting issues with the website's accessibility. Please fill it out to help us improve the user experience.
## How To Complete This Form
To complete this form, follow these steps:
1. Select the type of issue you're experiencing on the website:
	* Choose what went wrong from the dropdown menu.
2. Describe the issue in detail:
	* Write a brief description of what happened.
3. Provide your contact information:
	* Enter your email address so we can get back to you.
4. Provide more information about the issue:
	* If you want us to improve something specific, let us know.
5. Add any comments or additional information:
	* If you have any additional details about the issue or your experience, include it here.
6. Enter your name:
	* We'll use this to confirm who submitted the feedback.

## Field-by-Field Explanation
- **What was wrong** (what_was_wrong, select_one, required): Please select one of the options to describe the issue you're reporting.
* **Description** (what_do_you_want_us_to_improve, text, required): Describe the issue in as much detail as possible, including where you were on the website and what actions you were taking when it happened.
* **Email** (email, email, optional): Enter your email address so we can get back to you about your feedback. This will help us to contact you if we need more information or need to follow up on your issue.
* **Website** (website, text, optional): If relevant, please provide the URL of the page where you encountered the issue. This will help us to locate the problem quickly.
* **Comment** (comment, text, optional): If you have any additional information or context about the issue, please include it here. This can be a good place to describe any error messages you saw or anything else that might be helpful to us.
* **Your name** (your_name, text, optional): Enter your name so we can acknowledge who submitted the feedback.
