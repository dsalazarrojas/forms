# Employee Knowledge Sharing Evaluation Form - Help Guide

## Purpose
The form collects feedback from employees on their experience with knowledge sharing initiatives, helping to identify areas of improvement and excellence.

## How To Complete This Form

1. To begin, please select the page that best reflects the most recent knowledge sharing initiative you've participated in (if you've participated in multiple initiatives, you may need to fill this form out multiple times).
2. Review each field carefully and fill it in according to the instructions provided below.

## Field-by-Field Explanation

* **Employee Knowledge Sharing Initiatives** (`employee_knowledge_sharing_initiatives`, Text, required): This field is meant to be the title or name of the knowledge-sharing initiative you're evaluating. Please enter the name of the initiative, such as "Team Meeting on Monday" or "Knowledge Sharing Session with Marketing Department".
* **Overall Satisfaction** (`overall_satisfaction`, Select One, optional): This question asks you to rate your overall satisfaction with the initiative. Select "High" if you're very satisfied, "Medium" if it was average, and "Low" if you're not satisfied.
* **Collaboration Productivity** (`collaboration_productivity`, Number, optional): If you're asked to rate the initiative's productivity in terms of collaboration, enter a number between 1 (low) and 5 (high).
* **Communication Effectiveness** (`communication_effectiveness`, Select Multiple, optional): Check one or more of the options that best describe the effectiveness of the initiative's communication. Select "Good" if the communication was clear, fair if it was somewhat clear but could be improved, and "Poor" if it was not clear.
* **Employee Suggestions** (`employee_suggestion`, Note, optional): If you have any suggestions on how to improve the initiative, type them in here.
* **Manager Suggestions** (`manager_suggestion`, Note, optional): If you have any suggestions on how to improve the initiative, type them in here.
* **Department Satisfaction** (`department_satisfaction`, Number, optional): If you're asked to rate the initiative's effectiveness in your department, enter a number between 1 (low) and 5 (high).
* **Employee Satisfaction** (`employee_satisfaction`, Select One, optional): If you're asked to rate your overall satisfaction with this form, select "High" if you're very satisfied, "Medium" if it was average, and "Low" if you're not satisfied.
