# Issue Type Selection Form - Help Guide
## Purpose
This form is designed to collect information about the issue type. Please take a few minutes to complete it accurately.

## How To Complete This Form
1. Select the issue type that best describes the problem or concern you are reporting.
2. Provide any additional details or information related to the issue.
3. Enter the date the issue was reported.

## Field-by-Field Explanation
* **Select Issue Type**: Choose one of the available options to describe the type of issue you are experiencing. This will help us understand the nature of the issue.
* **Provide Additional Details**: Enter any additional information or context about the issue, such as what happened or why it occurred. This will help us better understand the situation.
* **Date Reported**: Enter the date the issue was reported. This is an optional field, but it will help us track the history of the issue. 

## Tips
* Please answer the questions accurately and honestly.
* If you are unsure about any of the fields, feel free to ask for clarification.
* If you have any supporting documents or evidence, please attach them to the form.
