# Post-Proposal-Feedback-Survey - Help Guide
## Purpose
This form is designed to gather feedback from reviewers on project proposals, allowing project owners to gain insight into the strengths and weaknesses of their proposals.

## How To Complete This Form
To complete this form, simply select the relevant options for each field and fill out the text fields as needed. Make sure to only fill out each section once per project.

## Field-by-Field Explanation

* **Project Status**: Select the current status of the project from the options provided.
* **Project Type**: Select all relevant project types from the options provided.
* **Review Date**: If you have reviewed the project, select the date you completed the review.
* **Review Time**: If you have reviewed the project, select the time you completed the review.
* **Review Comment**: Provide a brief comment about the project.
* **Action Plan**: Describe the actions you plan to take based on this feedback.
* **Additional Comments**: Provide any additional comments about the project.
* **Suggested Improvements**: Provide any suggested improvements for the project.
* **Reviewer Feedback**: Provide feedback to the reviewer.
* **Project Owner Name**: Enter the name of the project owner.
* **Project Owner Email**: Enter the email address of the project owner.
* **Project Owner Phone**: Enter the phone number of the project owner.
* **Reviewer Name**: Enter the name of the reviewer.
* **Reviewer Email**: Enter the email address of the reviewer.
* **Reviewer Phone**: Enter the phone number of the reviewer.
* **Review Status**: Enter the review status.
* **Review Result**: Enter the review result.
* **Project Manager**: Enter the name of the project manager.
* **Project Manager Phone**: Enter the phone number of the project manager.
* **Project Manager Email**: Enter the email address of the project manager.
* **Department**: Enter the department name.
* **Submit**: Select the "Submit" option to complete the form.

Tips:
* Make sure to fill out each section thoroughly and accurately.
* Only fill out each section once per project.
* If you need help with any of the fields, please contact your project manager or reviewer for guidance.
