# Animal Product Quality Review Request Form - Help Guide
## Purpose
This form is used to request a quality review on an animal product for evaluation and assessment. Fill out this form to inform the quality team of a product issue or concern.

## How To Complete This Form
To complete this form, follow the instructions below:

1. Enter your name and email address to identify you as the requester.
2. Select the department responsible for the product.
3. Provide the date the issue or concern was discovered.
4. Enter the name of the product and its unique code or SKU.
5. Select the type of review requested (e.g., quality audit, safety assessment, etc.).
6. Choose the priority level of the review (critical, high, medium, or low).
7. Describe the issue or concern in detail.
8. Select all applicable issue categories (e.g., product defect, packaging issue, etc.).
9. Estimate the number of units or batches affected, if applicable.
10. Indicate if the issue has affected customers.
11. Confirm if you have supporting evidence (e.g., photos, documents, or samples).
12. Indicate if this is a new issue or a repeat occurrence.
13. List the stakeholders notified about the issue.
14. Specify the expected outcome from the review.
15. Enter the completion date, if applicable.
16. Add any additional information, if necessary.

## Field-by-Field Explanation

* **Requester Name** (1, text, required): Enter your full name to identify yourself as the requester.
* **Requester Email** (2, email, required): Enter your email address to contact you.
* **Requester Phone** (3, text, required): Enter your contact number for communication.
* **Department** (4, select_one, required): Select the department responsible for the product (e.g., Quality Assurance, Production, Research and Development, etc.).
* **Request Date** (5, date, required): Enter the date the issue or concern was discovered.
* **Product Name** (6, text, required): Enter the name of the product for review.
* **Product Code or SKU** (7, text, optional): Enter the unique code or SKU of the product (if applicable).
* **Batch or Lot Number** (8, text, optional): If applicable, enter the batch or lot number of the product.
* **Type of Review Requested** (9, select_one, required): Select the primary review type (e.g., quality audit, safety assessment, etc.).
* **Priority Level** (10, select_one, required): Choose the priority level of the review (critical, high, medium, or low).
* **Description of Issue or Concern** (11, text, required): Provide detailed information about the issue or concern.
* **Issue Category** (12, select_multiple, required): Select all applicable issue categories (e.g., product defect, packaging issue, etc.).
* **Estimated Quantity Affected** (13, number, optional): Enter the estimated number of units or batches affected, if applicable.
* **Has This Affected Customers** (14, select_one, required): Indicate if the issue has affected customers.
* **Do You Have Supporting Evidence** (15, select_one, required): Confirm if you have supporting evidence (e.g., photos, documents, or samples).
* **Has This Issue Occurred Before** (16, select_one, required): Indicate if this is a new issue or a repeat occurrence.
* **Stakeholders Notified** (17, select_multiple, required): Select all stakeholders notified about the issue.
* **Expected Outcome from Review** (18, text, optional): Specify the expected outcome from the review.
* **Requested Completion Date** (19, date, optional): Enter the date when you want the review to be completed.
* **Additional Information** (20, text, optional): Add any other relevant details about the issue.
