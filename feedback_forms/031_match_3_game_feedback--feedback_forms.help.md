# Match 3 Game Feedback - Help Guide

## Purpose
This form is designed to gather feedback from players about their experience with the Match 3 game. Your input will help the development team improve the game and make it more enjoyable for you and other players.

## How To Complete This Form

To provide feedback, follow these steps:

1. Select the relevant feedback category (Gameplay Feedback, Technical Issues, etc.)
2. Choose the relevant options or enter your text in the provided fields
3. Make sure to submit your feedback by clicking the submit button

## Field-by-Field Explanation

* **Gameplay Feedback** (text): Describe your experience with the gameplay mechanics of the game. This can include what you enjoyed or disliked about the gameplay.
* **Technical Issues** (select_multiple): Check the technical issues you encountered while playing the game. Select all that apply:
	+ Option 1: Crashes or freezes
	+ Option 2: Lag or slow performance
	+ Option 3: Other (please specify in the comments field)
* **Feature Preferences** (select_one): Indicate which features you would like to see improved or added to the game. Select one of the options:
	+ Option 1: More levels
	+ Option 2: More features for multiplayer
	+ Option 3: Other (please specify in the comments field)
* **Comments** (text): Enter any additional comments or suggestions about the game.
* **Email** (email): Enter your email address to receive a follow-up on our response to your feedback.
* **Phone** (text): Enter your phone number so we can reach out to you for further information (if necessary).
* **Player Feedback** (select_one): Do you find the game engaging and fun? Select one of the options:
	+ Yes
	+ No
* **Suggestions** (text): Enter any suggestions you have for new features or improvements for the game.
* **Other Comments** (text): Enter any other comments or feedback you have about the game.
* **Game Version** (text): Enter the version of the game you are playing (if known).
* **Playtime** (time): Indicate how long you have played the game (in hours).
* **Rating** (number): Rate your overall experience with the game (1-5).
* **Will Play Again** (select_one): Indicate if you would play the game again. Select one of the options:
	+ Option 1
	+ Option 2
	+ Option 3
