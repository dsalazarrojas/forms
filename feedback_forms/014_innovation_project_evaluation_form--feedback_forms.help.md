# Innovation Project Evaluation Form - Help Guide
## Purpose
This form is designed to gather information about an innovation project's progress and outcomes. It helps the innovation team to evaluate the project's performance and identify areas for improvement.

## How To Complete This Form
To complete this form, please follow these steps:
1. Review the project details and ensure that you have firsthand knowledge of the project.
2. Enter the project name and description in the "Project Name" and "Project Description" fields, respectively.
3. Choose the evaluation date and time from the "Evaluation Date" and "Evaluation Time" fields.
4. Select the project status (Completed, Ongoing, or Cancelled) from the "Project Status" field.
5. Choose the project type from the "Project Type" field (Research and Development, Product Launch, Innovation Lab, or Other).
6. Provide a brief evaluation score out of 100 for the project's performance.
7. Enter any additional comments or feedback in the "Evaluation Comment" field.
8. Enter any other relevant information in the "Other" field.
9. List the project leads and other team members involved in the project.
10. If applicable, provide additional evaluation scores out of 10 for specific aspects of the project.

## Field-by-Field Explanation

* **Introduction**: A brief summary of the project and its purpose.
* **Project Name**: Enter the name of the project.
	+ Type: text
	+ Required: No
* **Project Description**: A brief description of the project.
	+ Type: text
	+ Required: No
* **Evaluation Date**: The date when the evaluation was performed.
	+ Type: date
	+ Required: No
* **Evaluation Time**: The time when the evaluation was performed.
	+ Type: time
	+ Required: No
* **Project Status**: The current status of the project.
	+ Type: select_one
	+ Options: Completed, Ongoing, Cancelled
* **Project Type**: The type of the project (Research and Development, Product Launch, Innovation Lab, or Other).
	+ Type: select_multiple
	+ Options: Research and Development, Product Launch, Innovation Lab, Other
* **Evaluation Score**: A brief evaluation score out of 100 for the project's performance.
	+ Type: number
	+ Required: No
* **Evaluation Comment**: Any additional comments or feedback on the project.
	+ Type: text
	+ Required: No
* **Evaluation Score out of 10**: A more detailed evaluation score out of 10 for specific aspects of the project (optional).
	+ Type: number
	+ Required: No

	+ Type: number
	+ Required: No
