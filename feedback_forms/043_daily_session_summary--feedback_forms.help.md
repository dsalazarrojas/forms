# Daily Session Summary - Help Guide
## Purpose
The Daily Session Summary form is designed to gather information from trainers about their daily sessions, providing a record of each session's details.

## How To Complete This Form
To complete this form, follow these steps:

1. Ensure you are filling out this form once per session, to avoid duplication.
2. Start by filling out the fields as needed, using the available options and hints.
3. Provide accurate and complete information for each field, taking into account the available options and hints.

## Field-by-Field Explanation
* **Trainers Name** (`trainer_name`, text, optional): Please enter your name as the trainer who led the session.
* **Session Date** (`session_date`, date, optional): Enter the date of the session. Use the format YYYY-MM-DD.
* **Start Time** (`start_time`, time, optional): Enter the start time of the session.
* **End Time** (`end_time`, time, optional): Enter the end time of the session.
* **Session Notes** (`session_notes`, text, optional): Provide a brief description of the session, including any relevant details.
* **Activities** (`activities`, text, optional): List any activities conducted during the session.
* **Trainers Name** (`trainers_name`, text, optional): This field is not recommended to be filled out unless there are multiple trainers for this session.
* **Trainers Comments** (`trainers_comments`, text, optional): Enter any comments or feedback from the trainer(s) about the session.
* **Session Goals** (`session_goals`, text, optional): Describe the goals or objectives of the session.
