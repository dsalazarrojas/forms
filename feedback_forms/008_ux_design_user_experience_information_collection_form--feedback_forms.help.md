# UX Design User Experience Information Collection Form - Help Guide
## Purpose
This form is designed to collect user experience information to help designers and product teams better understand the user's needs, preferences, and pain points. The feedback collected through this form will be used to inform design decisions and product development.

## How To Complete This Form

1. To complete this form, simply choose the options that best describe your user experience.
2. Select "Other" as an option when necessary to provide additional information not listed in the provided choices.
3. Be honest and accurate in your responses to ensure that the feedback is valuable and actionable.
4. If you have trouble completing a field, please don't hesitate to ask for help.

## Field-by-Field Explanation

### User Input
* **User Input**: This field allows you to select multiple options that best describe your user experience.
* Type: Select multiple options
* Required: No
* Hint: This will help us understand what you like about our product/service.

### Satisfaction Rating
* **Satisfaction Rating**: This field asks you to rate your overall satisfaction with our product/service.
* Type: Number
* Required: No

### Usability Rating
* **Usability Rating**: This field also asks you to rate how easy it is to use our product/service.
* Type: Number
* Required: No

### User Habits
* **User Habits**: Please describe any habits or behaviors related to your use of our product/service.
* Type: Note
* Required: No

### Product Team Priority
* **Product Team Priority**: Select the level of priority that the product team should have for this feedback.
* Type: Select one option
* Required: No
* Options: High, Medium, Low

### User Feedback
* **User Feedback**: Provide any additional thoughts or feedback about your user experience.
* Type: Text
* Required: No

### Product Improvements
* **Product Improvements**: Select multiple options that represent areas where you think we can improve our product/service.
* Type: Select multiple options
* Required: No
* Hint: Please select all the options that apply.

### User Satisfaction
* **User Satisfaction**: Select your level of satisfaction with our product/service.
* Type: Select one option
* Required: No
* Options: Very Satisfied, Somewhat Satisfied, Somewhat Dissatisfied, Very Dissatisfied

## Tips
* Be honest and accurate in your responses.
* Please select the most relevant options that apply to your user experience.
* If you have any additional feedback or suggestions, please don't hesitate to provide them in the "User Feedback" field.
* Thank you for taking the time to provide us with your feedback! Your input is invaluable to us.
