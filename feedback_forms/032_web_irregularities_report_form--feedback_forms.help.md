# web_irregularities_report_form - Help Guide
## Purpose
This form is designed to collect feedback and irregularities reports from users about a given website.

## How To Complete This Form
To complete this form, follow the steps below:
1. Enter your input in the "User Input" field.
2. Provide a detailed description of the issue you encountered in the "Issue Description" field.
3. Enter the website URL where the issue was experienced.
4. Select the category of the issue from the "Issue Category" dropdown menu.
5. If you have attached any files related to the issue, you can provide them in the "Attachment" field.
6. Enter the date and time when the issue occurred in the "Issue Date" and "Issue Time" fields respectively.
7. Summarize the issue in the "Issue Summary" field.
8. If you have any additional feedback, please provide it in the "Feedback" field.
9. Finally, submit the form by clicking the "Submit" button.

## Field-by-Field Explanation
- **User Input** (text, required/optional): This field is where you can provide any additional information relevant to the issue.
- **Issue Description** (text, required): This is a detailed description of the issue you encountered.
- **Website URL** (text, required): Enter the URL of the website where the issue was experienced.
- **Issue Category** (select_one, required): Select the category of the issue from the dropdown menu:
  • Bug
  • Feature Request
  • Security Vulnerability
- **Attachment** (note, required/optional): If you have attached any files related to the issue, you can provide them here.
- **Issue Date** (date, required/optional): Enter the date when the issue occurred.
- **Issue Time** (time, required/optional): Enter the time when the issue occurred.
- **Issue Summary** (text, required): Summarize the issue in a few sentences.
- **Feedback** (select_multiple, required/optional): Provide any additional feedback about the issue:
  • Bug
  • Feature Request
  • Security Vulnerability
- **Submit** (text, required): This is the final step to submit the form.
