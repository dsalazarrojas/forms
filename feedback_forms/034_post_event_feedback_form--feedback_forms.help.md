# Post Event Feedback Form - Help Guide
## Purpose
This form is designed to collect feedback from users after an event, helping us evaluate and improve future events.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the date of the event you are providing feedback on.
2. Choose the attendees who attended the event (select all that apply).
3. Rate the overall quality of the event (e.g., Not Satisfied, Somewhat Satisfied, Satisfied).
4. Rate the event organization (e.g., Excellent, Good, Fair).
5. Select the event location (if applicable).
6. Provide any additional comments about the event.
7. If you'd like, add a rating comment to elaborate on your rating.
8. Choose the topic of the event (e.g., Topic 1, Topic 2).
9. If desired, rate the event's overall score out of a scale (e.g., 1-5).
10. Finally, rate the event's outlook for future events (e.g., Good, Fair, Not Very Good).

## Field-by-Field Explanation
* **Event Date** (required/optional): Enter the date of the event you are providing feedback on.
* **Attendees** (required): Select all attendees who attended the event.
* **Overall Rating** (required): Rate the overall quality of the event.
* **Event Organization** (required): Rate the event organization, considering factors such as communication, logistics, and quality of resources.
* **Event Location** (optional): Enter the location of the event, if it was held in a specific venue.
* **Comment** (optional): Provide any additional comments or suggestions about the event.
* **Rating Comment** (optional): Add a comment to elaborate on your overall rating.
* **Event Topic** (required): Select the topic of the event (e.g., Topic 1, Topic 2).
* **Rating Score** (optional): Rate the event's overall quality on a scale (e.g., 1-5).
* **Rating Outlook** (optional): Rate the event's outlook for future events (e.g., Good, Fair, Not Very Good).
