# Workplace Culture Feedback Form - Help Guide
## Purpose
This form is designed to gather feedback from employees on their satisfaction with the workplace culture and their suggestions for improvement. The data collected will help us create a more positive and productive work environment.

## How To Complete This Form
1. Please select the rating that best represents your level of satisfaction with the workplace culture.
2. If you have any suggestions for improvement, type them in the text field below.
3. If you'd like to provide additional comments, type them here.

## Field-by-Field Explanation
### Page 1 - Employee Satisfaction
* **Very High** (`Very High`, Select Multiple, required: false): Select this option if you are extremely satisfied with the workplace culture.
* **High** (`High`, Select Multiple, required: false): Select this option if you are somewhat satisfied with the workplace culture.
* **Average** (`Average`, Select Multiple, required: false): Select this option if you are neutral about the workplace culture.
* **Low** (`Low`, Select Multiple, required: false): Select this option if you are somewhat dissatisfied with the workplace culture.
* **Very Low** (`Very Low`, Select Multiple, required: false): Select this option if you are extremely dissatisfied with the workplace culture.

### Page 2 - Team Collaboration
* **team_collaboration** (`team_collaboration`, Text, required: false): Rate your collaboration with your team.

### Page 3 - Suggestions
* **suggestions** (`suggestions`, Note, required: false): Type any suggestions for improvement here.

### Page 4 - Comments
* **comments** (`comments`, Text, required: false): Provide any additional comments you'd like to share.
