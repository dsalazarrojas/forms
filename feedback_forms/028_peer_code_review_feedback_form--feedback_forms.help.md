# Peer Code Review Feedback Form - Help Guide
## Purpose
The Peer Code Review Feedback Form is designed to collect feedback from reviewers on a code submission. It's a crucial part of the peer code review process, allowing reviewers to provide comments, review the status of the code, and track action items assigned to the submitter.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the **Reviewer Comment** field with your constructive feedback on the code submission.
2. Select the **Review Status** to indicate whether the submission meets the required standards or not. You can choose from three options: Approved, Rejected, or Deferred.
3. If there are any issues with the submission, add them to the **Action Item** field. This is where you can list any tasks or changes that need to be made before the submission can be approved.
4. For each action item, choose its **Action Item Status** from the dropdown menu. You can select Open, In Progress, or Closed to indicate the status of the action item.
5. Set a **Due Date** for the action item, if applicable.

## Field-by-Field Explanation
* **Reviewer Comment**: This field is where you can write your feedback on the code submission. Provide specific, constructive comments that will help the submitter improve their code.
* **Review Status**: Choose from three options: Approved, Rejected, or Deferred, to indicate the status of the code submission.
* **Action Item**: List any issues or tasks that need to be addressed before the submission can be approved.
* **Action Item Status**: Select the status of each action item from the dropdown menu: Open, In Progress, or Closed.
* **Action Item Due Date**: Set a due date for each action item, if applicable.

## Tips
* Be specific and concrete in your feedback to help the submitter understand what they need to improve.
* Use the **Action Item** field to provide clear instructions on what needs to be done.
* Make sure to set a due date for action items that require a specific timeline to be completed.
* Review the form carefully before submitting to ensure you have provided all necessary feedback and information.
