# Remote Work Experience Feedback Questionnaire - Help Guide
## Purpose
This form is designed to gather feedback about your remote work experience. It will help us understand the challenges and opportunities related to remote work.

## How To Complete This Form
* Fill out the form in its entirety, answering each question to the best of your ability.
* Select the options that accurately reflect your remote work experience.
* Make sure to review your answers carefully before submitting the form.

## Field-by-Field Explanation
* **Remote work experience**: A text field where you can provide a brief description of your remote work experience.
* **Work location**: A select multiple field where you can choose all the locations where you have worked remotely (e.g., New York, Chicago, London, Paris, Sydney).
* **Work hours**: A number field where you can input the number of hours you typically work from home or remotely.
* **Work type**: A select one field where you can choose the type of work you have done remotely (remote, hybrid, on site).
* **Work frequency**: A number field where you can input the frequency of your remote work (e.g., daily, weekly, monthly).
* **Job title**: A text field where you can input your job title while working remotely.
* **Team size**: A number field where you can input the size of your team while working remotely.
* **Job type**: A select one field where you can choose the type of role you held while working remotely (manager, individual contributor, team lead).
* **Work status**: A select one field where you can choose your current work status (active, inactive, on bench).
* **Work arrangement**: A select multiple field where you can choose the work arrangement you had while working remotely (full-time, part-time, remote, on site).
* **Company**: A text field where you can input your company name while working remotely.
* **Supervisor**: A text field where you can input your supervisor's name while working remotely.
* **Manager**: A text field where you can input your manager's name while working remotely.
* **Team member**: A text field where you can input the name of your team member while working remotely.
* **Team lead**: A text field where you can input your team lead's name while working remotely.
* **On-site location**: A select multiple field where you can choose the on-site location where you worked remotely (New York, Chicago, London, Paris, Sydney).

## Tips
* Be honest and accurate when filling out this form.
* If you are unsure about any of the fields, feel free to ask for clarification.
* This form is for aggregate analysis, not individual evaluation, so don't worry about being judged.
* Make sure to review your answers carefully before submitting the form.
