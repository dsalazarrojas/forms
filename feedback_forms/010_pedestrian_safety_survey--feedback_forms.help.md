# Pedestrian Safety Survey - Help Guide
## Purpose
This form is designed to collect feedback on pedestrian safety. Your input will help us understand how to improve pedestrian safety in your area. Please answer the questions below to provide your feedback.

## How To Complete This Form
To complete this form, simply select the relevant answers from the options provided for each field. You do not need to provide any additional explanation or justification for your answers.

## Field-by-Field Explanation

* **First Page** (`first_page`, Select Multiple, required: false): Please select all that apply to you.
	+ 'Yes' - This indicates that you have encountered pedestrian safety issues at this location.
	+ 'No' - This indicates that you have not encountered pedestrian safety issues at this location.
* **Pedestrian Concerns** (`pedestrian_concerns`, Select One, required: false): Please select your primary concern.
	+ 'Yes' - This indicates that you are concerned about pedestrian safety at this location.
	+ 'No' - This indicates that you are not concerned about pedestrian safety at this location.
* **Safety Measures** (`safety_measures`, Select One, required: false): Please select the measure you think is most effective.
	+ 'Yes' - This indicates that you think this measure is effective.
	+ 'No' - This indicates that you do not think this measure is effective.
* **Pedestrian Safety** (`pedestrian_safety`, Note, required: false): Please provide a brief note about your experience with pedestrian safety.
* **Pedestrian Traffic** (`pedestrian_traffic`, Date, required: false): Please provide the date of your most recent pedestrian safety experience.
* **Pedestrian Safety Risks** (`pedestrian_safety_risks`, Select One, required: false): Please select your primary risk.
	+ 'Yes' - This indicates that you are aware of this risk.
	+ 'No' - This indicates that you are not aware of this risk.
* **Pedestrian Safety Solutions** (`pedestrian_safety_solutions`, Select Multiple, required: false): Please select all that apply to you.
	+ 'Yes' - This indicates that you think this solution is effective.
	+ 'No' - This indicates that you do not think this solution is effective.
* **Pedestrian Survey** (`pedestrian_survey`, Select One, required: false): Please select the survey you think is most relevant.
	+ 'Yes' - This indicates that you think this survey is relevant.
	+ 'No' - This indicates that you do not think this survey is relevant.
* **Pedestrian Safety Improvements** (`pedestrian_safety_improvements`, Date, required: false): Please provide the date of your most recent pedestrian safety improvement suggestion.
* **Pedestrian Safety Surveyed** (`pedestrian_safety_surveyed`, Email, required: false): Please provide an email address where you can be reached to discuss this survey further.
* **Pedestrian Safety Comments** (`pedestrian_safety_comments`, Note, required: false): Please provide any additional comments about pedestrian safety.

Note: The fields marked as 'Select Multiple' and 'Select One' allow you to select one or more options that apply to you. The fields marked as 'Note' and 'Date' are free text fields where you can provide any additional information you think is relevant.
