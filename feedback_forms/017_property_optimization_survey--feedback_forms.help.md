# property_optimization_survey - Help Guide
## Purpose
The "property_optimization_survey" form is a tool to gather information from property managers about the properties they manage. This form is designed to collect data on property performance, tenant information, and lease agreements, with the goal of optimizing property performance.

## How To Complete This Form
To complete this form, follow these steps:

1. Start by filling out the first field, "property_optimization_survey_start". This is a text field where you can enter any additional comments or information you'd like to provide.
2. In the second field, "property_optimization_survey_property_manager", enter the name of the property manager responsible for the property.
3. In the third field, "property_optimization_survey_tenants", select all tenants that are currently occupying the property. You can select multiple tenants from the dropdown menu.
4. In the fourth field, "property_optimization_survey_property_performance", select how you rate the current property performance. Choose from "Good", "Fair", or "Poor".
5. In the fifth field, "property_optimization_survey_improvement_plan", describe any plans for improving the property performance.
6. In the sixth field, "property_optimization_survey_additional_information", enter any additional comments or information you'd like to provide.
7. In the seventh field, "property_optimization_survey_lease_agreement", select the current lease agreement in place. Choose from "Lease Agreement 1", "Lease Agreement 2", or "Lease Agreement 3".
8. In the eighth field, "property_optimization_survey_property_status", select the current status of the property. Choose from "Active" or "Inactive".
9. In the ninth field, "property_optimization_survey_additional_comments", enter any additional comments or information you'd like to provide.

## Field-by-Field Explanation
* **property_optimization_survey_start** (Text): Enter any additional comments or information about the property.
* **property_optimization_survey_property_manager** (Text): Enter the name of the property manager responsible for the property.
* **property_optimization_survey_tenants** (Select Multiple): Select all tenants that are currently occupying the property from the dropdown menu.
* **property_optimization_survey_property_performance** (Select One): Rate the current property performance as "Good", "Fair", or "Poor".
* **property_optimization_survey_improvement_plan** (Text): Describe any plans for improving the property performance.
* **property_optimization_survey_additional_information** (Text): Enter any additional comments or information about the property.
* **property_optimization_survey_lease_agreement** (Select One): Select the current lease agreement in place from the dropdown menu.
* **property_optimization_survey_property_status** (Select One): Select the current status of the property as "Active" or "Inactive".
* **property_optimization_survey_additional_comments** (Text): Enter any additional comments or information about the property.

## Tips
* Make sure to provide accurate and relevant information for each field.
* If you are unsure about any field, please ask for clarification or assistance.
* This form is designed to help property managers optimize property performance, so please provide as much detail as possible.
