# Public Safety Written Exam Survey - Help Guide
## Purpose
This guide will walk you through the fields in the Public Safety Written Exam Survey form. Please read through each section carefully and answer the questions honestly.

## How To Complete This Form
To complete this form, simply follow the steps below:

1. Answer the questions honestly and to the best of your ability.
2. Select the correct options for each question.
3. Be sure to fill out all required fields, denoted by \* (asterisk).

## Field-by-Field Explanation

* **Exam Sessions** (`exam_sessions`, select_one, required: false):
	+ This field asks if you have taken any exam sessions.
	+ Select "Yes" if you have taken one or more exam sessions.
	+ Select "No" if you have not taken any exam sessions.
* **Instructions** (`instructions`, select_multiple, required: true):
	+ This field asks if you received any instructions for the exam.
	+ Select "Yes" if you received instructions.
	+ Select "No" if you did not receive instructions.
* **Difficulty Level** (`difficulty_level`, select_one, required: false):
	+ This field asks about the difficulty level of the exam.
	+ Select "High" if you found the exam challenging.
	+ Select "Low" if you found the exam easy.
* **Exam Session Difficulty** (`exam_session_difficulty`, select_multiple, required: false):
	+ This field asks about the difficulty level of each exam session.
	+ Select "Yes" if you found each session challenging.
	+ Select "No" if you did not find each session challenging.
* **Exam Session Instructions** (`exam_session_instructio`, select_one, required: false):
	+ This field asks if you received instructions for each exam session.
	+ Select "Yes" if you received instructions.
	+ Select "No" if you did not receive instructions.
* **Exam Session Time** (`exam_session_time`, time, required: true):
	+ This field asks for the total time you spent on the exam.
	+ Enter the total time in the format: HH:MM (e.g., 02:30).
* **Exam Session Duration** (`exam_session_duration`, select_multiple, required: true):
	+ This field asks about the duration of each exam session.
	+ Select "Yes" if each session lasted longer than expected.
	+ Select "No" if each session lasted as expected or less.
* **Exam Session Notes** (`exam_session_notes`, note, required: true):
	+ This field is for any additional notes you would like to share about your exam experience.
* **Exam Session Date** (`exam_session_date`, date, required: true):
	+ This field asks for the date you took the exam.
	+ Enter the date in the format: YYYY-MM-DD (e.g., 2022-02-15).
* **Exam Session Score** (`exam_session_score`, number, required: true):
	+ This field asks for your score on the exam.
	+ Enter your score as a number (e.g., 80).
* **Exam Session Outcome** (`exam_session_outcome`, select_one, required: false):
	+ This field asks about your outcome after taking the exam.
	+ Select "Yes" if you passed the exam.
	+ Select "No" if you did not pass the exam.
* **Exam Session Outcome Justification** (`exam_session_outcome_justification`, note, required: false):
	+ This field is for any additional justification or explanation about your outcome.
* **Exam Session Justification** (`exam_session_justification`, select_one, required: false):
	+ This field asks if you felt justified in your outcome.
	+ Select "Yes" if you felt justified.
	+ Select "No" if you did not feel justified.
* **Exam Session Comments** (`exam_session_comments`, select_multiple, required: false):
	+ This field is for any additional comments about your exam experience.
* **Exam Session Difficulty Justification** (`exam_session_difficulty_justification`, note, required: false):
	+ This field is for any additional justification or explanation about the difficulty of the exam.
* **Exam Session Difficulty Score** (`exam_session_difficulty_score`, number, required: false):
	+ This field asks for a score about the difficulty of the exam.
* **Exam Instructions** (`exam_instructio`, select_one, required: false):
	+ This field asks if you received instructions before the exam.
	+ Select "Yes" if you received instructions.
	+ Select "No" if you did not receive instructions.
* **Exam Session Score Justification** (`exam_session_score_justification`, note, required: false):
	+ This field is for any additional justification or explanation about your score.
* **Exam Session Difficulty Level** (`exam_session_difficulty_level`, select_multiple, required: false):
	+ This field asks about the difficulty level of each exam session.
	+ Select "High" if you found each session challenging.
	+ Select "Low" if you did not find each session challenging.
* **Exam Session Comments Justification** (`exam_session_comments_justification`, note, required: false):
	+ This field is for any additional justification or explanation about your comments.
* **Exam Session Instructions** (`exam_session_instructio`, select_one, required: false):

* **Exam Session Outcome Justification** (`exam_session_outcome_justification`, note, required: false):
	+ This field is for any additional justification or explanation about your outcome.
* **Exam Session Outcome** (`exam_session_outcome`, select_one, required: false):
	+ This field asks about your outcome after taking the exam.

	+ Select "No" if you did not pass the exam.

## Tips

* Please be honest and thorough in your responses.
* If you are unsure about any field, please ask for clarification.
* If you have any additional comments or questions, please include them in the appropriate fields.
