## menu_options_feedback_survey - Help Guide
## Purpose
This form is designed to gather feedback on the menu options provided by our establishment. By providing your input, you will help us improve our menu and provide a better dining experience for you and other customers.

## How To Complete This Form
To complete this form, simply follow the instructions below:
- Read each question carefully and answer all the questions to the best of your ability.
- Select the relevant options for each question, taking care to select only one option for questions that require a single answer (e.g., "What type of menu items would you like to see offered more?").
- Do not worry if you do not see a specific option; simply select "other" if you have something else in mind.

## Field-by-Field Explanation
- **How can we improve our menu?** (`survey_purpose`, `text`, Optional):
    This question allows you to provide your thoughts on how we can improve our menu. Please be as specific as possible to help us understand your concerns or suggestions.
- **Which menu items would you like to see offered more often?** (`menu_preferred_items`, `select_multiple`, Optional):
    Select all the menu items that you would like to see offered more often. You can select more than one option if applicable.
- **What type of menu items would you like to see offered more?** (`menu_preferred_items_type`, `select_one`, Optional):
    Choose the type of menu item you would like to see offered more often. You can select only one option from the list provided.
- **What price range would you prefer?** (`price_range`, `select_one`, Optional):
    Select the price range that you would prefer when dining with us.
- **What time of day would you prefer to dine?** (`time_of_day`, `select_one`, Optional):
    Choose the time of day when you would prefer to dine with us.
- **Which days of the week do you usually dine with us?** (`days_open`, `select_multiple`, Optional):
    Select the days of the week when you usually dine with us.
