# Physiotherapy Session Feedback Form - Help Guide
## Purpose
This form is a qualitative feedback tool for physiotherapists to provide feedback on their own or peer sessions, helping to improve performance, identify areas of improvement, and optimize resource allocation.

## How To Complete This Form

To complete this form, simply follow these steps:

1.  Choose a Physiotherapist: Select the physiotherapist who led the session you're providing feedback on. If unsure, select "Unknown".
2.  Choose a Patient: Select the patient who attended the session you're providing feedback on. If unsure, select "Unknown".
3.  Session Details: Enter the duration and date of the session. If unsure, select "Unknown" for either or both.
4.  Session Notes: Provide a brief description of the session.
5.  Additional Comments: Enter any other relevant comments about the session.

## Field-by-Field Explanation

*   **Physiotherapist**: Select the physiotherapist who conducted the session. This helps identify specific areas for improvement. Choose from the dropdown menu or select "Unknown" if unsure.
*   **Patient**: Select the patient who attended the session. This ensures feedback is linked to the correct patient. Choose from the dropdown menu or select "Unknown" if unsure.
*   **Session duration**: Enter the length of the session in hours and minutes, e.g., "30 minutes" or "1 hour". If unsure, select "Unknown".
*   **Session date**: Enter the date of the session in standard date format, e.g., "2022-02-15". If unsure, select "Unknown".
*   **Session time**: Enter the time of the session, e.g., "14:00" or "15:00". If unsure, select "Unknown".
*   **Session notes**: Provide a brief description of what happened during the session. This helps others understand the context.
*   **Physiotherapist**: This field is not applicable. Please disregard.

*   **Additional comments**: Enter any other information that might be useful for improvement or reference.

Please fill in the form accurately, providing feedback on actual sessions you've participated in or led. This helps maintain the integrity of the feedback system and ensures data reliability.
