# Feedback On Future Initiatives - Help Guide
## Purpose
The "Feedback On Future Initiatives" form is used to gather feedback from team members on proposed programs and initiatives. This feedback will help inform and improve the development of new programs and initiatives that align with the organization's goals and priorities.

## How To Complete This Form
To complete this form, follow these steps:

1. Review the proposed programs and select all the programs that you are interested in providing feedback on.
2. Choose the priority level of each program.
3. Provide any additional suggestions or comments in the "Suggestions" field.
4. Decide if you would like to compare these programs with each other (if applicable).
5. Select the timeframe for when you would like to see the programs implemented.
6. If the timeframe does not fit within the provided options, select "Other" and provide a brief explanation in the "Roadmap 3" field.
7. Confirm your selection and submit the form.

## Field-by-Field Explanation

* **Proposed Programs** (`proposed_programs`, `select_multiple`, required): Select all the proposed programs that you are interested in providing feedback on. You can select multiple programs.
* **Proposed Programs 2** (`proposed_programs_2`, `select_multiple`, required): Please select multiple programs. This field is similar to the first "Proposed Programs" field and is used to gather feedback on a separate group of programs.
* **Program Priority** (`program_priority`, `select_one`, required): Choose the priority level of each program from High, Medium, or Low.
* **Suggestions** (`suggestions`, `note`, required): Provide any additional suggestions or comments on the proposed programs.
* **Compare** (`comparison`, `select_multiple`, required): Decide if you would like to compare these programs with each other (if applicable). This field is used to gather feedback on how to compare the programs.
* **Comparison 2** (`comparison_2`, `select_multiple`, required): Please compare these programs with each other. This field is similar to the "Compare" field but is used to gather feedback on a separate group of programs.
* **Roadmap** (`roadmap`, `time`, required): Select the timeframe for when you would like to see the programs implemented.
* **Roadmap 2** (`roadmap_2`, `time`, required): This field is similar to the "Roadmap" field but is used to gather feedback on a separate group of programs.
* **Time Frame** (`roadmap_3`, `select_one`, required): If the selected timeframe does not fit within the provided options, select "Other" and provide a brief explanation.
* **Time Frame** (`timeframe`, `select_one`, required): Similar to the "Time Frame" field, but is used to gather feedback on a separate group of programs.

Note: Fields with the `select_multiple` type allow you to select multiple options from the list, while fields with the `select_one` type require you to select only one option from the list. Fields with the `time` type are used to gather feedback on time-related aspects.
