# pmi_feedback_survey - Help Guide
## Purpose
This form is designed to gather feedback from users of the project management information system to improve the system's usability, functionality, and overall user experience.

## How To Complete This Form
To complete this form, follow these steps:

1. Please review the form contents carefully and ensure that all required fields are filled correctly.
2. If a field is not required, you can skip it.
3. Do not fill in duplicate entries.
4. Answer all questions honestly and accurately.
5. Submit the form when you are finished.

## Field-by-Field Explanation
* **Project Management Practices** (`project_management_practices`, select_one, required):
	+ This field asks about the project management approach you use or have used in the past. Please select one of the options: Agile, Waterfall, or Hybrid.
* **Project Team** (`project_team`, select_multiple, required):
	+ This field allows you to select the team members involved in your project. Please choose all team members that apply: Team Members, Stakeholders, or Project Manager.
* **Communication Effectiveness** (`communication_effectiveness`, number, required):
	+ This field is not applicable in the current version of the form. Please skip it.
* **Communication Frequency** (`communication_frequency`, number, required):
	+ This field is not applicable in the current version of the form. Please skip it.
* **Team Size** (`team_size`, number, not required):
	+ This field is used to collect information about the size of your project team. Please enter a number if you have a team size that you'd like to share.
* **Project Duration** (`project_duration`, date, not required):
	+ This field is used to collect information about the duration of your project. Please enter a date if you have a project duration that you'd like to share.
* **Survey Page** (`survey_page`, note, not required):
	+ This field is a free-text field for you to write any additional comments about your experience with the project management information system. Please feel free to share any thoughts or suggestions.
