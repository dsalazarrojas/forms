# Introductory Questionnaire Sheet For Graphics - Help Guide
## Purpose
This form is used to gather introductory information about a graphics-related project or request.

## How To Complete This Form
To complete this form, follow these steps:

1.  Enter a brief title for the project or request in the "Title" field.
2.  Select the category of the project or request from the "Category" dropdown list. Currently, the options are "Feedback Forms" and "Other".
3.  Add a brief description of the project or request in the "Description" field.
4.  If applicable, select the tool that will be used to complete the project or request from the "Assigned Tool" dropdown list. Currently, the options are "chatjimmy" and "Other".
5.  Enter the ID of the form, which is a numeric value that will help identify the form.
6.  Enter the version of the form, which is also a numeric value.
7.  Add the output file name, which is the name of the file that will be generated after completing the project or request.

## Field-by-Field Explanation

*   **Category (select_one)**: Select the category of the project or request from the dropdown list. This field is optional.
*   **Description (text)**: Enter a brief description of the project or request in this field. This field is optional.
*   **Assigned Tool (select_one)**: If applicable, select the tool that will be used to complete the project or request from the dropdown list. Currently, the options are "chatjimmy" and "Other".
*   **Form ID (number)**: Enter the ID of the form, which is a numeric value that will help identify the form. This field is optional.
*   **Form Version (number)**: Enter the version of the form, which is also a numeric value. This field is optional.
*   **Output File (text)**: Add the name of the output file that will be generated after completing the project or request. This field is optional.
