# Property Feedback Form - Help Guide
## Purpose
This form is designed to collect feedback about properties from users. It's an essential tool for property managers, realtors, or administrators to gather information and insights about properties they handle.

## How To Complete This Form
To complete this form, follow these steps:

1. Provide the property name in the "Property Name" field.
2. Enter the property address in the "Property Address" field.
3. In the "Feedback" field, describe your experience or concern about the property.
4. Choose the realtor associated with the property from the "Realtor" field.
5. If applicable, provide an email address and/or phone number for communication.
6. Select the relevant date and time for the visit or interaction with the property.
7. Rate your satisfaction with the property by selecting an option from the "Rating" field.
8. Add any additional comments about the property in the "Comments" field.
9. Select the category that best describes the type of feedback you're providing in the "Category" field.
10. Finally, provide your name and select the date the feedback was submitted.

## Field-by-Field Explanation
* **Property Name** (`property_name`, text, required): Enter the name of the property you're providing feedback about.
* **Property Address** (`property_address`, text, required): Enter the address of the property.
* **Feedback** (`feedback`, text, required): Describe your experience or concern about the property.
* **Realtor** (`realtor`, select_one, optional): Select the realtor associated with the property.
* **Email** (`email`, email, optional): Provide an email address for communication (if applicable).
* **Phone** (`phone`, text, optional): Enter a phone number for communication (if applicable).
* **Date** (`date`, date, optional): Select the date of the visit or interaction with the property.
* **Time** (`time`, time, optional): Select the time of the visit or interaction with the property.
* **Rating** (`rating`, select_one, optional): Rate your satisfaction with the property by selecting an option.
* **Comments** (`comments`, text, optional): Add any additional comments about the property.
* **Category** (`category`, select_multiple, optional): Select the category that best describes the type of feedback you're providing.
* **Submitted By** (`submitted_by`, text, required): Provide your name for record-keeping purposes.
* **Submitted On** (`submitted_on`, date, required): Select the date the feedback was submitted.
