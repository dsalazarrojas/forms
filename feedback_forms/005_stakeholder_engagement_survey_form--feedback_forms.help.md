## Stakeholder Engagement Survey Form - Help Guide

## Purpose
The Stakeholder Engagement Survey Form is designed to capture information about the purpose and scope of a feedback form, as well as its output details. This form is used to create new feedback forms, and the information collected here will help us understand the context and requirements of the form that will be created.

## How To Complete This Form
To complete this form, follow these steps:

1. **Enter a title for your form**, which will be used to identify and label the form.
2. **Select the organization** that the form is associated with.
3. **Choose a category** for your form (e.g., Feedback Forms).
4. **Provide a brief description** of your form's purpose and scope.
5. **Select the tool** assigned to this form, if applicable.
6. **Enter a unique form ID** for your form.
7. **Specify the file name** for your output file.
8. **Choose the file extension** for your output file (e.g., CSV, PDF).
9. **Select the file format** for your output file (e.g., Comma Separated Values, Plain Text).
10. **Enter the path** where your output file will be located.

## Field-by-Field Explanation

* **Form Title** (`form_title`, `text`, required): Enter a brief and descriptive title for your form.
* **Organization** (`organization`, `text`, required): Select the organization associated with this form.
* **Category** (`category`, `select_one`, required): Choose a category for your form (e.g., Feedback Forms).
* **Description** (`description`, `text`, required): Provide a brief description of your form's purpose and scope.
* **Assigned Tool** (`assigned_tool`, `text`, optional): Enter the tool assigned to this form, if applicable.
* **Form ID** (`form_id`, `number`, required): Enter a unique ID for your form.
* **Output File Name** (`output_file_name`, `text`, required): Specify the name of your output file.
* **Output File Extension** (`output_file_extension`, `text`, required): Choose the file extension for your output file (e.g., CSV, PDF).
* **Output File Format** (`output_file_format`, `text`, required): Select the file format for your output file (e.g., Comma Separated Values, Plain Text).
* **Output File Path** (`output_file_path`, `text`, required): Enter the path where your output file will be located.

## Tips

* Make sure to enter a unique and descriptive title for your form.
* Choose a category that accurately reflects the form's purpose.
* Be concise in your description, as it will help us understand the form's context.
* If you're unsure about the assigned tool, you can leave this field blank.
* Ensure that your form ID is unique and easy to identify.
* Double-check the file name, extension, format, and path to ensure they match your requirements.
* Enter the correct path to ensure your output file is stored correctly.
