# Product Defect Report Form - Help Guide
## Purpose
This form is used to report defects on a product. Please fill in the required fields with as much detail as possible to help our team understand the issue and address it efficiently.

## How To Complete This Form
To complete this form, follow these steps:
1.  Select the "Product Defect" field to enter the product ID or a description of the product affected by the defect.
2.  Upload a photo of the product if possible, using the "Product Photo" field.
3.  Add any additional comments or messages in the "Additional Message" field, if needed.
4.  Provide a detailed description of the defect in the "Comment" field.

## Field-by-Field Explanation
* **Product Defect** (1, number, required):
	+ Enter the product ID or a description of the product affected by the defect.
* **Product Photo** (2, text, optional):
	+ Please upload a photo of the product if possible. This can help our team understand the issue better.
* **Additional Message** (3, text, optional):
	+ If you have any additional comments or messages that might be helpful for our team to know, enter them here.
* **Comment** (4, text, optional):
	+ Provide a detailed description of the defect, including any steps to reproduce the issue or any error messages you've seen.

## Tips
* Be as detailed as possible when describing the defect.
* Avoid submitting duplicate reports for the same issue.
* If you're unsure about any part of the form, feel free to ask our team for assistance.
