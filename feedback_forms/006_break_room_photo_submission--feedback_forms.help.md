# Break Room Photo Submission - Help Guide
## Purpose
The purpose of this form is to collect feedback from employees on the condition of the break rooms in the office. This information will help management identify areas for improvement and make necessary changes to maintain a clean and comfortable environment for all employees.

## How To Complete This Form
1. Fill in your personal details:
	* Enter your full name in the "Employee Name" field.
	* If you have an employee ID, enter it in the "Employee ID" field. If not, you can skip this field.
2. Choose the correct department or team that you belong to.
3. Select the current date for the submission.
4. Indicate the location of the break room in question (e.g. first floor, main break room, etc.).
5. Describe the building and floor level where the break room is located.
6. Choose what the photo shows (e.g. Overall break room condition, cleanliness issue, etc.).
7. Rate the break room condition and cleanliness on the submission date.
8. Describe any issues or concerns observed in the photo.
9. Select any facility issues observed (e.g. broken furniture, spills, etc.).
10. If needed, select missing or needed amenities (e.g. coffee maker, vending machine, etc.).
11. Indicate the priority level of maintenance needed (e.g. immediate attention, high priority, etc.).
12. Choose how often you have observed this issue (e.g. first time, occasionally, etc.).
13. Provide any suggestions for improvement (optional).
14. If desired, indicate if you would like to be contacted for follow-up.

## Field-by-Field Explanation
* **Employee Name**: Your full name as an employee.
* **Employee ID**: If you have an ID, enter it to help identify you for follow-up purposes.
* **Department**: Select your department or team to help us understand where the issue is located.
* **Submission Date**: Select the current date for the submission.
* **Break Room Location**: Indicate the location of the break room you are submitting a photo for (e.g. first floor, main break room, etc.).
* **Building and Floor**: Describe the building number and floor level where the break room is located.
* **What does this photo show**: Choose the type of issue or condition observed in the photo.
* **Overall Break Room Condition**: Rate the break room condition on the submission date.
* **Cleanliness Rating**: Rate the cleanliness of the break room on the submission date.
* **Describe Any Issues or Concerns**: Provide a detailed description of the observed issues or concerns.
* **Facility Issues Observed**: Select all applicable facility issues (e.g. broken furniture, spills, etc.).
* **Missing or Needed Amenities**: If needed, select the missing or needed amenities (e.g. coffee maker, vending machine, etc.).
* **Maintenance Priority Level**: Indicate the priority level of the maintenance needed (e.g. immediate attention, high priority, etc.).
* **How Often Have You Observed This Issue**: Choose how often you have observed this issue (e.g. first time, occasionally, etc.).
* **Suggestions for Improvement**: Provide any suggestions or recommendations for improvement (optional).
* **May We Contact You for Follow-up**: If desired, indicate if you would like to be contacted for follow-up.
* **Contact Email**: If desired, enter your email for follow-up purposes.
