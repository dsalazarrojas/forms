# Hair Donation Program Awareness Survey - Help Guide
## Purpose

This form is intended to gather information about your knowledge and awareness of our Hair Donation Program. It is designed to help us better understand how well our program's message is being conveyed to our audience.

## How To Complete This Form

1. Please fill out the form with your honest and accurate information.
2. Enter your name and contact email address to help us contact you in case of any questions or follow-up.
3. If you are aware of our hair donation program, please select "True" in the corresponding field.
4. If you are not aware of our hair donation program, please select "False" in the corresponding field.
5. If you have any feedback or comments, please use the "Feedback" and "Comments" fields at the end of the form.

## Field-by-Field Explanation

* **Survey Title** (`survey_title`, text, required): The title of our Hair Donation Program, which is used to identify our program.
* **Name** (`name`, text, required): Your name, which we need to know who is providing the feedback.
* **Contact Email** (`contact_email`, email, required): Your email address, which we can use to contact you if needed.
* **Phone** (`phone`, text, optional): Your phone number, which we can use to contact you if needed.
* **Awareness Program** (`awareness_program`, select_one, optional): If you are aware of our Hair Donation Program, please select "True". If not, please select "False".
* **Awareness Program Name** (`awareness_program_name`, text, required): If you are aware of our program, please provide the name of the program.
* **Awareness Program Length** (`awareness_program_length`, text, optional): The length of time you were aware of our program.
* **Awareness Program Description** (`awareness_program_description`, text, optional): A brief description of our program.
* **Awareness Program Benefits** (`awareness_program_benefit`, text, optional): The benefits of our program.
* **Awareness Program Benefit Description** (`awareness_program_benefit_description`, text, optional): A brief description of the benefits of our program.
* **Awareness Program Location** (`awareness_program_location`, text, optional): The location where you learned about our program.
* **Awareness Program Website** (`awareness_program_website`, text, optional): The website of our program.
* **Awareness Program Facebook** (`awareness_program_facebook`, select_one, optional): If our program has a Facebook presence, please select "True".
* **Awareness Program Twitter** (`awareness_program_twitter`, select_one, optional): If our program has a Twitter presence, please select "True".
* **Awareness Program Instagram** (`awareness_program_instagram`, select_one, optional): If our program has an Instagram presence, please select "True".
* **Awareness Program YouTube** (`awareness_program_youtube`, select_one, optional): If our program has a YouTube presence, please select "True".
* **Awareness Program Pinterest** (`awareness_program_pinterest`, select_one, optional): If our program has a Pinterest presence, please select "True".
* **Awareness Program Other Social Media** (`awareness_program_other_social_media`, select_one, optional): If our program has other social media presence, please select "True".
* **Awareness Program Awareness Source** (`awareness_program_awareness_source`, text, optional): Where you learned about our program (e.g. friend, website, social media, etc.).
* **Awareness Program Source Other** (`awareness_program_source_other`, text, optional): If you selected "Other" as the source, please provide the details.
* **Awareness Program Source Description** (`awareness_program_source_description`, text, optional): A brief description of where you learned about our program.
* **Awareness Program Other Description** (`awareness_program_other_description`, text, optional): Any other information about our program that you would like to share.
* **Feedback** (`feedback`, note, optional): If you have any feedback or comments, please use this field.
* **Comments** (`comments`, note, optional): If you have any additional comments, please use this field.
* **Submit** (`submit`, text, required): Please submit your completed form to send us your feedback.
