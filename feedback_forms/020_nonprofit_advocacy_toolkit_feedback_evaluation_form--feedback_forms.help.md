# Nonprofit Advocacy Toolkit Feedback Evaluation Form - Help Guide
## Purpose
The <span class="label">Nonprofit Advocacy Toolkit Feedback Evaluation Form</span> is a tool for gathering feedback on the effectiveness and usefulness of the Nonprofit Advocacy Toolkit, a resource designed to support non-profit organizations in their advocacy efforts. The form aims to gather information on organizations, partnerships, resources, and tools surveyed, as well as their level of awareness, effectiveness, and tools used.

## How To Complete This Form

To complete this form, follow these steps:

*   Click on the form title to open the form in a new tab or window.
*   Fill out the form fields as per the instructions below.

## Field-by-Field Explanation

*   <span class="label">Feedback Form</span>: Please provide a brief description of your experience with the Nonprofit Advocacy Toolkit. This can include any feedback, suggestions, or comments you have on its usefulness and effectiveness.
*   <span class="label">Organizations Surveyed</span>: Please list the names of organizations you surveyed while using the toolkit. If no organizations were surveyed, type "None".
*   <span class="label">Organizations Surveyed Number</span>: Enter the number of organizations you surveyed.
*   <span class="label">Organizations Surveyed Type</span>: Select all types of organizations that were surveyed (Government, Non-government, Both).
*   <span class="label">Partnerships Surveyed</span>: Please list the names of partnerships you surveyed while using the toolkit. If no partnerships were surveyed, type "None".
*   <span class="label">Partnerships Surveyed Number</span>: Enter the number of partnerships you surveyed.
*   <span class="label">Partnerships Surveyed Type</span>: Select all types of partnerships that were surveyed (Government, Non-government, Both).
*   <span class="label">Resources Surveyed</span>: Please list the names of resources you surveyed while using the toolkit. If no resources were surveyed, type "None".
*   <span class="label">Resources Surveyed Number</span>: Enter the number of resources you surveyed.
*   <span class="label">Resources Surveyed Type</span>: Select all types of resources that were surveyed (Online, Printed, Both).
*   <span class="label">Tools Used</span>: Please list the tools you used while using the toolkit. If no tools were used, type "None".
*   <span class="label">Tools Used Number</span>: Enter the number of tools you used.
*   <span class="label">Tools Used Type</span>: Select all types of tools used (Advocacy, Education, Both).
*   <span class="label">Tools Utility</span>: Please select the time spent using the tools.
*   <span class="label">Tools Surveyed Effectiveness Level</span>: Please select the level of effectiveness of the tools surveyed (Not Effective, Somewhat Effective, Very Effective).
*   <span class="label">Organizations Surveyed Awareness</span>: Please describe the awareness of the organizations surveyed about the toolkit.
*   <span class="label">Organizations Surveyed Awareness Level</span>: Select the level of awareness of the organizations surveyed (Low, High, Not Aware).
*   <span class="label">Partnerships Surveyed Awareness</span>: Please describe the awareness of the partnerships surveyed about the toolkit.
*   <span class="label">Partnerships Surveyed Awareness Level</span>: Select the level of awareness of the partnerships surveyed (Low, High, Not Aware).
*   <span class="label">Partnerships Surveyed Effectiveness</span>: Please describe the effectiveness of the partnerships surveyed.
*   <span class="label">Partnerships Surveyed Effectiveness Level</span>: Select the level of effectiveness of the partnerships surveyed (Not Effective, Somewhat Effective, Very Effective).
*   <span class="label">Resources Surveyed Effectiveness</span>: Please describe the effectiveness of the resources surveyed.
*   <span class="label">Resources Surveyed Effectiveness Level</span>: Select the level of effectiveness of the resources surveyed (Not Effective, Somewhat Effective, Very Effective).
*   <span class="label">Tools Surveyed Effectiveness</span>: Please describe the effectiveness of the tools surveyed.
*   <span class="label">Tools Surveyed Effectiveness Level</span>: Select the level of effectiveness of the tools surveyed (Not Effective, Somewhat Effective, Very Effective).

## Tips

*   Please answer each question as truthfully as possible.
*   If you are unsure about any of the questions, you can describe your experience or feelings about the toolkit in the Feedback Form field.
*   You can submit the form once you have completed all the fields.

This help guide will assist non-profit organizations in using the Nonprofit Advocacy Toolkit Feedback Evaluation Form effectively.
