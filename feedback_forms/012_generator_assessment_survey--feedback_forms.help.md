# Generator Assessment Survey - Help Guide

## Purpose
This form is designed to collect feedback and assessment information about generators, providing a comprehensive evaluation of their performance.

## How To Complete This Form
1.  Complete each page of the form carefully, ensuring all questions are answered thoroughly and accurately.
2.  For select_one and select_multiple questions, choose the most suitable options from the dropdown menus.
3.  For text boxes, enter your responses accurately and clearly.
4.  If you are unsure about any of the questions, please contact the assigned personnel for guidance.

## Field-by-Field Explanation

*   **Generator Type (Generator 1/2)**: Select the type of generator you are assessing.
    *   **Generator 1**: Select this option if the generator is type 1.
    *   **Generator 2**: Select this option if the generator is type 2.
*   **Efficiency Level (Low/Medium/High)**: Select the efficiency level of the generator. You can choose one or both of the options, Low and Medium or High, depending on the generator's efficiency.
    *   **Low**: Select this option if the generator has low efficiency.
    *   **Medium**: Select this option if the generator has medium efficiency.
    *   **High**: Select this option if the generator has high efficiency.
*   **Performance Metric 1-20**: Enter the numerical values for the corresponding performance metrics.
    *   **Performance Metric 1-20**: Enter the numerical values for each performance metric.
*   **Overall Score**: Enter the overall score for the generator.
    *   Enter a numerical value for the overall score.
*   **Comments**: Enter any additional comments or remarks about the generator.
    *   Enter your comments or remarks about the generator.
*   **Assigned to**: Enter the name of the person or team responsible for the generator.
    *   Enter the name of the person or team assigned to the generator.
