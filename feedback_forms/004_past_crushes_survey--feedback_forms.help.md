# Past Crushes Survey - Help Guide
## Purpose
The purpose of this survey is to collect information about your past crushes, including the characteristics of your first crush, your feelings about it, and your experiences with subsequent crushes.

## How To Complete This Form
To complete this form, follow these steps:
1. Please answer all the questions honestly and accurately.
2. Make sure to fill out all the required fields (indicated by an asterisk (*)).
3. Select the correct options for each field from the list provided.

## Field-by-Field Explanation

- **First Crush** (`first_crush`, text, required): This is the name of your first crush. Please type in the name of the person who was your first crush.
- **Age Of First Crush** (`age_of_first_crush`, number, optional): If you remember the age of your first crush, please type it in. If not, you can leave it blank.
- **Relationship Type** (`relationship_type`, select_one, optional): Check if your first crush ever turned into a relationship. Please select 'Yes' if you were in a relationship, 'No' otherwise.
- **How Did You Feel** (`how_did_you_feel`, text, optional): Describe how you felt about your first crush. Be as honest as possible.
- **First Crush Duration** (`first_crush_duration`, number, optional): If you remember the duration of your first crush, please type it in. If not, you can leave it blank.
- **Last Crush** (`last_crush`, text, optional): Type in the name of your last crush, if applicable.
- **Last Crush Duration** (`last_crush_duration`, number, optional): If you remember the duration of your last crush, please type it in. If not, you can leave it blank.
- **Relationship Status** (`relationship_status`, select_multiple, optional): Check the relationship status of your last crush. Please select 'Active' if the relationship is ongoing, 'Inactive' if it has ended.
- **Communication Type** (`communication_type`, select_one, optional): Describe how often you communicated with your last crush. Please select 'Yes' if you communicated frequently, 'No' if you rarely communicated.
