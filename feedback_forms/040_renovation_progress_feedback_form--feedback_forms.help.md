# renovation_progress_feedback_form - Help Guide
## Purpose
This form is designed to collect feedback on the progress of renovation projects. It is intended for use by project managers, clients, or other stakeholders to provide their input on the project's current status, issues, and concerns.

## How To Complete This Form

1. Fill in the required fields with as much detail as possible.
2. For optional fields, provide information if it's relevant to the project.
3. Make sure to check the box next to each field to indicate that you've filled it in or not.

## Field-by-Field Explanation

* **Project Name (1)**: Enter the name of the project.
	+ Type: text
	+ Required: No
* **Project ID (2)**: Enter the unique ID of the project.
	+ Type: number
	+ Required: No
* **Contact Name (3)**: Enter the name of the person providing feedback.
	+ Type: text
	+ Required: No
* **Project Address (4)**: Enter the address of the project location.
	+ Type: text
	+ Required: No
* **Contact Email (5)**: Enter the email address of the person providing feedback.
	+ Type: email
	+ Required: No
* **Contact Phone (6)**: Enter the phone number of the person providing feedback.
	+ Type: text
	+ Required: No
* **Project Start Date (7)**: Enter the date when the project started.
	+ Type: date
	+ Required: No
* **Project Completion Date (8)**: Enter the date when the project is expected to be completed.
	+ Type: date
	+ Required: No
* **Project Status (9)**: Select the current status of the project (Active, Inactive, Cancelled).
	+ Type: select_one
	+ Required: No
* **Other (10)**: If the project status is not listed above, select "Other" and provide a brief explanation.
	+ Type: text
	+ Required: No
* **Feedback (11)**: Provide any feedback or comments on the project's progress.
	+ Type: text
	+ Required: No
* **Project Type (12)**: Select the type of project (Residential, Commercial, Industrial).
	+ Type: select_one
	+ Required: No
* **Project Manager Name (13)**: Enter the name of the project manager.
	+ Type: text
	+ Required: No
* **Project Manager Email (14)**: Enter the email address of the project manager.
	+ Type: email
	+ Required: No
* **Project Manager Phone (15)**: Enter the phone number of the project manager.
	+ Type: text
	+ Required: No
* **Project Manager Address (16)**: Enter the address of the project manager.
	+ Type: text
	+ Required: No
* **Project Manager Status (17)**: Select the status of the project manager (Active, Inactive, Left).
	+ Type: select_one
	+ Required: No
* **Other (18)**: If the project manager's status is not listed above, select "Other" and provide a brief explanation.
	+ Type: text
	+ Required: No
* **Project Manager Experience (19)**: Enter the project manager's level of experience.
	+ Type: text
	+ Required: No
* **Project Manager Image (20)**: Enter the project manager's image.
	+ Type: text
	+ Required: No
* **Project Description (21)**: Enter a brief description of the project.
	+ Type: text
	+ Required: No
* **Other (22)**: If the project description is not provided, select "Other" and provide a brief explanation.
	+ Type: text
	+ Required: No
* **Project Image (23)**: Enter the project's image.
	+ Type: text
	+ Required: No
* **Project Video Link (24)**: Enter the link to the project's video.
	+ Type: text
	+ Required: No
* **Project Document Link (25)**: Enter the link to any relevant project documents.
	+ Type: text
	+ Required: No

**Tips**

* Please make sure to provide clear and concise answers to each field.
* Avoid including confidential or sensitive information.
* If unsure about any field, please provide an explanation for your selection.
* If you need help with anything, please contact [insert contact information].
