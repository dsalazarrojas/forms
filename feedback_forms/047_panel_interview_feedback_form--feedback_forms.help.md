# Panel Interview Feedback Form - Help Guide
## Purpose
The purpose of this form is to collect feedback from panelists about candidates after a panel interview.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the appropriate feedback options for each field based on your experience with the candidate.
2. Fill in the candidate's name, position, and interviewer name if applicable.
3. Select the date and start and end times of the interview.
4. Choose the rating and recommendation for the candidate.
5. Add any additional comments if necessary.

## Field-by-Field Explanation
- **Feedback** (`panel_interview_feedback_form`, select_multiple, required/optional): This field allows you to select multiple feedback options about the candidate's performance.
  - Select "Yes" if the candidate performed well in the interview, or "No" if they did not.
- **Interviewer Name** (`interviewer_name`, text, required/optional): This field is optional and only applicable if you are the interviewer. Please fill in your name so we can track your feedback.
- **Candidate Name** (`candidate_name`, text, required/optional): This field is used to track which candidate you are providing feedback for. Please fill it in so we can identify the candidate correctly.
- **Candidate Position** (`candidate_position`, text, required/optional): This field is used to track the candidate's position or role for which they interviewed.
- **Panelist Name** (`panelist_name`, text, required/optional): This field is optional and only applicable if you are a panelist. Please fill it in so we can track your feedback.
- **Date of Interview** (`date_of_interview`, date, required/optional): This field is used to track the date of the interview.
- **Interview Start Time** (`interview_start_time`, time, required/optional): This field is used to track the start time of the interview.
- **Interview End Time** (`interview_end_time`, time, required/optional): This field is used to track the end time of the interview.
- **Feedback Questions** (`feedback_questions`, select_one, required/optional): This field allows you to select one of the options provided to give more specific feedback about the candidate's performance.
  - Please select one of the options based on your feedback.
- **Feedback Score** (`feedback_score`, select_multiple, required/optional): This field allows you to select multiple feedback scores about the candidate's performance.
  - Select "Yes" if the candidate performed well in the selected feedback question.
- **Additional Comments** (`additional_comments`, note, required/optional): This field is used to add any additional comments about the candidate's performance.
- **Rating** (`rating`, select_one, required/optional): This field allows you to rate the candidate's overall performance.
  - Select one of the options to provide a rating of the candidate's interview performance.
- **Recommendation** (`recommendation`, select_one, required/optional): This field allows you to recommend the candidate for further evaluation.
  - Select "True" if you recommend the candidate, and "False" otherwise. 

## Tips
* Please provide honest and accurate feedback to help us improve our processes.
* Make sure to fill in all required fields to ensure accurate tracking.
* If you have already filled out this form for the same interview, do not fill it out again to avoid duplicate entries.
