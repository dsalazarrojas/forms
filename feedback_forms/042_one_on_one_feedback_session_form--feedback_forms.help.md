# One On One Feedback Session Form - Help Guide
## Purpose
The One On One Feedback Session Form is designed to collect feedback from individuals who have participated in one-on-one feedback sessions. This form helps to gather essential information on the session's title, details, goals, and outcomes.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the "One On One Feedback Session Form" title as a brief description of the session.
2. Provide details about the session in the "Session Details" field.
3. Select the session goals from the list in the "Session Goals" field. This will help us understand what you expected to achieve from the session.
4. Enter your notes about the session in the "Session Notes" field.
5. If you have any follow-up plans for the next session, enter them in the "Follow-Up Next Session" field.
6. Indicate the session outcome from the list in the "Session Outcome" field. This will help us understand how the session went.
7. If you have any follow-up next steps, enter them in the "Follow-Up Next Steps" field.
8. Select the participants involved in the session from the list in the "Session Participants" field.

## Field-by-Field Explanation
* **One On One Feedback Session Form** (`on_one_feedback_session_form_title`, text, required): Enter a brief title of the session.
* **Session Details** (`session_details`, text, optional): Provide a detailed description of the session.
* **Session Goals** (`feedback_session_goals`, select_multiple, optional): Select the goals you aimed to achieve from the list.
	+ Provide feedback on session goals
	+ Session went well
	+ Session did not go well
	+ Other
* **Session Notes** (`feedback_session_notes`, note, optional): Enter your notes about the session.
* **Follow-Up Next Session** (`follow_up_next_session`, date, optional): If you have any follow-up plans, enter the date for the next session.
* **Session Outcome** (`feedback_session_outcome`, select_one, optional): Indicate the session outcome from the list.
	+ Session went well
	+ Session did not go well
	+ No feedback session
	+ Other
* **Follow-Up Next Steps** (`follow_up_next_steps`, text, optional): Enter any follow-up plans you have.
* **Session Participants** (`session_participants`, select_multiple, optional): Select the participants involved in the session.
	+ Manager
	+ HR
	+ Mentor
	+ Employee
	+ Other
