# Group Project Feedback Form - Help Guide

## Purpose
This form is designed to collect feedback from users about a group project, helping project stakeholders understand the users' thoughts and opinions. Your input will contribute to the improvement of the project.

## How To Complete This Form
1. Read the form carefully and answer each question honestly and thoroughly.
2. Ensure you have a valid session ID for questions that ask for it.
3. Rate your satisfaction with the project on a scale of 1-5.
4. Provide specific examples and details when answering open-ended questions.
5. Fill out the form only once for each project.

## Field-by-Field Explanation

* **Overall Satisfaction** (`overall_satisfaction`, number, required): Rate your overall satisfaction with the project on a scale of 1-5.
* **What do you think about the project title?** (`project_title`, text, required): Provide your thoughts about the project title. This will help us understand your expectations and preferences.
* **What is your session ID?** (`session_id`, number, required): Please provide your session ID for reference, as this will help us identify your input.
* **What did you like most about the project?** (`feedback_question_1`, text, required): Briefly describe what you liked most about the project.
* **What did you like least about the project?** (`feedback_question_2`, text, required): Briefly describe what you liked least about the project.
* **How would you rate this project?** (`rating_scale`, select_one, required): Rate this project on a scale of 1-5.
* **Do you have any suggestions for improvement?** (`feedback_question_3`, text, required): Provide any suggestions you have for improving the project.
* **What did you find most helpful about the project?** (`feedback_question_4`, text, optional): Briefly describe what you found most helpful about the project (if any).
* **What did you find least helpful about the project?** (`feedback_question_5`, text, optional): Briefly describe what you found least helpful about the project (if any).
* **Do you have any other feedback about the project?** (`feedback_question_6`, text, optional): Provide any additional feedback about the project (if any).

## Tips
* Be honest and thorough in your answers.
* Use specific examples to support your feedback.
* Do not repeat your answers in multiple fields.
* If you have any questions or concerns, contact us for assistance.
