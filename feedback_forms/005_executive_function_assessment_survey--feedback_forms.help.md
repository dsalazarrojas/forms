# executive_function_assessment_survey - Help Guide
## Purpose
This form assesses a child's executive functions.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the executive functions you are rating from the options on the first page.
2. Enter the date of the assessment on the second page.
3. Enter the child's name on the third page.
4. Set the time of the assessment on the fourth page.
5. For each executive function, rate the child's performance on a scale from 1 to 10.
6. Choose whether to submit or save and come back later.
