# Harassment Reporting Feedback Form - Help Guide
## Purpose
The Harassment Reporting Feedback Form is a tool for reporting and documenting harassment incidents. Please use this form to provide detailed information about the incident.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the required fields:
	* Incident Date (Field 2)
	* Harasser Information (Field 4)
	* Incident Type (Field 10)
2. Provide as much detail as possible in the text fields:
	* Incident Details (Field 3)
	* Incident Location (Field 7)
	* Incident Location Details (Field 9)
3. Select the relevant reporting channel from Field 6 (Reporting Channel)
4. Optionally, report the reporter's information (Field 5)
5. Choose whether to submit the form or not (Field 13)

## Field-by-Field Explanation

### Field 2: Incident Date
* Label: Incident Date
* Type: Date
* Description: Please enter the date of the incident.

### Field 3: Incident Details
* Label: Incident Details
* Type: Text
* Description: Provide a detailed description of the incident, including as much information as possible.

### Field 4: Harasser Information
* Label: Harasser Information
* Type: Note
* Description: Enter the name, position, email, or any other relevant information about the harasser.

### Field 5: Reporter Information
* Label: Reporter Information
* Type: Text
* Description: Enter your name and contact information for follow-up, if needed.

### Field 6: Reporting Channel
* Label: Reporting Channel
* Type: Select One
* Description: Select the channel you used to report the incident (Phone, Email, Chat, In-person).

### Field 7: Incident Location
* Label: Incident Location
* Type: Text
* Description: Enter the location where the incident occurred.

### Field 8: If other, please specify
* Label: If other, please specify
* Type: Text
* Description: If the location is not listed, provide a specific location.

### Field 9: Incident Location Details
* Label: Incident Location Details
* Type: Text
* Description: Provide any additional details about the location of the incident.

### Field 10: Incident Type
* Label: Incident Type
* Type: Select One
* Description: Select the type of incident (Physical Harassment, Verbal Harassment, Sexual Harassment, Other).

### Field 11: Reported to Official
* Label: Reported to Official
* Type: Text
* Description: If applicable, enter the name of the official to whom you reported the incident.

### Field 12: Report ID
* Label: Report ID
* Type: Number
* Description: This is a unique identifier for your report.

### Field 13: Submit
* Label: Submit
* Type: Select Multiple
* Description: Choose 'Yes' to submit the form, and 'No' to discard it.

### Tips
* Please provide as much detail as possible to help us take action on the incident.
* If you have any further questions or concerns, do not hesitate to reach out to us.
