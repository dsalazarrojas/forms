# Employee Complaint Form - Help Guide
## Purpose
This form is designed to collect information about employee complaints to help management address and resolve issues efficiently.

## How To Complete This Form
To complete this form, simply follow these steps:
- Fill in the main field with your complaint.
- If necessary, provide more details about the employee who made the complaint.
- Describe the incident or issue at hand.
- If there are witnesses, enter their details.
- Select the current status of the resolution.
- If the issue has been resolved, enter the resolution date and time.
- Add any additional notes about the resolution.
- Repeat the same steps for the second resolution status, date, and time if necessary.

## Field-by-Field Explanation
* **Employee Complaint Form** (required: false)
	+ This is the main field where you can type your complaint.
* **Complaintee Details** (required: false)
	+ This field is optional and can be used to provide additional details about the employee who made the complaint.
* **Incident Details** (required: false)
	+ Provide as much detail as possible about the incident or issue at hand.
* **Witness Details** (required: false)
	+ This field can be used to provide information about any witnesses involved in the incident.
* **Resolution Status** (required: false)
	+ Choose from one of the options: Open, Closed, or Pending to indicate the current status of the resolution.
* **Resolution Date** (required: false)
	+ If the issue has been resolved, enter the date it was resolved.
* **Resolution Time** (required: false)
	+ If the issue has been resolved, enter the time it was resolved.
* **Resolution Date Time** (required: false)
	+ If the issue has been resolved, enter the date and time it was resolved.
* **Resolution Note** (required: false)
	+ Add any additional notes about the resolution.
* **Resolution Status 2** (required: false)
	+ Choose from one of the options: Open, Closed, or Pending to indicate the current status of the second resolution.
* **Resolution Date 2** (required: false)
	+ If the issue has been resolved, enter the date it was resolved.
* **Resolution Time 2** (required: false)
	+ If the issue has been resolved, enter the time it was resolved.
* **Resolution Date Time 2** (required: false)
	+ If the issue has been resolved, enter the date and time it was resolved.
* **Resolution Note 2** (required: false)
	+ Add any additional notes about the second resolution.
* **Submit** (required: false)
	+ Click this button to submit the completed form.
