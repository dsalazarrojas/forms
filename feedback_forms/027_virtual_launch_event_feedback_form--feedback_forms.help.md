# Virtual Launch Event Feedback Form - Help Guide
## Purpose

The Virtual Launch Event Feedback Form is designed to collect feedback from attendees of virtual launch events. The form helps us understand how well the event was received, what worked well, and areas where we can improve for future events.

## How To Complete This Form

1. Please fill out the form carefully, providing your honest feedback.
2. If a field is marked as required, please make sure to complete it.
3. You can add multiple suggestions in the "Suggestions" field.
4. For the "Event Success" field, please select one of the options that best describes your experience.
5. For the "Attendees Experience" field, please select one of the three options provided.
6. You can select multiple "Areas For Improvement" options if applicable.

## Field-by-Field Explanation

* **Event Name** (`event_name`, Text, Required): Please enter the name of the virtual launch event you attended.
* **Name** (`name`, Text, Optional): Enter your name, so we can address you in our response.
* **Email** (`email`, Email, Required): Enter your email address, so we can respond to your feedback and keep you updated on any changes.
* **Feedback** (`feedback`, Text, Optional): Share any thoughts or comments you have about the event.
* **Suggestions** (`suggestions`, Text, Optional): Provide any suggestions you have for improving future virtual launch events.
* **Comments** (`comments`, Text, Optional): Add any additional comments about the event.
* **Event Success** (`event_success`, Number, Optional): Select how successful you found the event to be.
	+ 1-3: Not very successful
	+ 4-5: Neutral
	+ 6-7: Very successful
* **Attendees Experience** (`attendees_experience`, Select One, Required): Select how well you felt about your experience.
	+ Very Good
	+ Average
	+ Poor
* **Areas For Improvement** (`areas_for_improvement`, Select Multiple, Optional): Select any areas that you feel could be improved.
	+ Time Management
	+ Content Quality
	+ Registration Flow
* **Overall Satisfaction** (`overall_satisfaction`, Select One, Required): Select how satisfied you are with the event.
	+ Very High
	+ High
	+ Neutral
	+ Low
	+ Very Low
