# new_design_feedback_form - Help Guide
## Purpose
The new_design_feedback_form is a tool for collecting feedback on new designs. It allows users to provide their opinions on different aspects of the design, such as quality, completeness, and assigned personnel.

## How To Complete This Form
To complete this form, simply follow these steps:

1. Provide your feedback on the new design using the fields below.
2. Select the design ID(s) that you would like to provide feedback on.
3. Enter a brief description of your feedback.
4. Select the level of feedback (Very good, Average, or Poor).
5. Enter your email address.
6. Enter your phone number (if applicable).
7. Select the date and time you would like to provide feedback for.
8. Add any additional comments or notes about the design.
9. Choose the person you would like to assign the feedback to.

## Field-by-Field Explanation

* **New Design Feedback Form**: This is the main title of the form.
* **design_id**: Select the design ID(s) you would like to provide feedback on. You can select multiple design IDs if necessary.
	+ Type: Select multiple
	+ Required: No
* **description**: Provide a brief description of your feedback. You can enter up to 255 characters.
	+ Type: Text
	+ Required: No
* **feedback**: Select the level of feedback you would like to provide (Very good, Average, or Poor).
	+ Type: Select one
	+ Required: No
* **Email**: Enter your email address so that we can contact you about your feedback.
	+ Type: Email
	+ Required: No
* **Phone Number**: Enter your phone number (if applicable). This is not required.
	+ Type: Text
	+ Required: No
* **Date**: Select the date you would like to provide feedback for.
	+ Type: Date
	+ Required: No
* **Time**: Select the time you would like to provide feedback for.
	+ Type: Time
	+ Required: No
* **comments**: Add any additional comments or notes about the design.
	+ Type: Note
	+ Required: No
* **Assigned To**: Choose the person you would like to assign the feedback to. You can select either ChatJimmy or John Doe.
	+ Type: Select one
	+ Required: No
