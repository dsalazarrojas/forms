# Event Video Feedback Form - Help Guide

## Purpose
This form is designed to gather feedback from users about event videos. The collected feedback will help us understand what you think about our event videos and improve them for the future.

## How To Complete This Form
To complete this form, follow these steps:

*   Read each question carefully and provide your honest feedback.
*   Fill in all the fields that apply to you, as some are optional.
*   If you have any additional comments or suggestions, please use the "Is there anything else you would like to add?" field.

## Field-by-Field Explanation

### 1. Event Video Feedback

*   **Event Video Feedback** (`event_video_feedback_form_1`, text, optional): This is the first question of the form where you can provide your overall thoughts about the event video.

### 2. What did you like about this video?

*   **What did you like about this video?** (`event_video_feedback_form_2`, text, optional): This question allows you to mention anything you enjoyed about the video, such as the speaker, content, or production quality.

### 3. What do you dislike about this video?

*   **What do you dislike about this video?** (`event_video_feedback_form_3`, text, optional): Here, you can mention anything that you didn't like or didn't find enjoyable about the video.

### 4. Would you watch this again?

*   **Would you watch this again?** (`event_video_feedback_form_4`, select_one, optional): This question checks how likely you are to watch the video again. Select 'Yes' if you would, and 'No' if you wouldn't.

### 5. Would you recommend it to others?

*   **Would you recommend it to others?** (`event_video_feedback_form_5`, select_one, optional): This question asks if you would suggest the video to others. Select 'Yes' if you would, and 'No' if you wouldn't.

### 6. Would you watch the speaker again?

*   **Would you watch the speaker again?** (`event_video_feedback_form_6`, select_one, optional): Here, you can choose whether you would watch the speaker again based on their performance.

### 7. What could be improved about this video?

*   **What could be improved about this video?** (`event_video_feedback_form_7`, text, optional): This question is for any suggestions you might have to improve the video in the future.

### 8. How likely are you to watch this video again?

*   **How likely are you to watch this video again?** (`event_video_feedback_form_8`, number, optional): You can rate your likelihood of watching the video again on a scale.

### 9. What do you think about this event?

*   **What do you think about this event?** (`event_video_feedback_form_9`, select_multiple, optional): This question allows you to select multiple aspects that you have thoughts about the event.

### 10. Would you give this video more views?

*   **Would you give this video more views?** (`event_video_feedback_form_10`, select_one, optional): If you think the video deserves more views, select 'Yes'. If not, select 'No'.

### 11. Would you attend the event again?

*   **Would you attend the event again?** (`event_video_feedback_form_11`, select_one, optional): This question checks if you would attend the event again, given the opportunity.

### 12. How likely would you be to attend a similar event in the future?

*   **How likely would you be to attend a similar event in the future?** (`event_video_feedback_form_12`, select_one, optional): You can rate your likelihood of attending similar events in the future.

### 13. Would you like to be informed about similar events?

*   **Would you like to be informed about similar events?** (`event_video_feedback_form_13`, select_one, optional): This question asks if you would like to receive updates about similar events.

### 14. What would you like to see more of in future events?

*   **What would you like to see more of in future events?** (`event_video_feedback_form_14`, text, optional): Here, you can suggest anything you would like to see improved or added in future events.

### 15. Is there anything else you would like to add?

*   **Is there anything else you would like to add?** (`event_video_feedback_form_15`, text, optional): This is an open-ended question for any additional comments or suggestions you might have.

### 16. How likely would you be to recommend this event to others?

### 17. What did you like most about the event?

### 18. What did you like least about the event?

### 19. Did you find this content useful?
