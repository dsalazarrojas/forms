# Soundscape Experience Feedback - Help Guide
## Purpose
This form is designed to collect feedback on participants' experience in soundscape sessions. Please fill out this form to provide your honest opinion on how we can improve the sessions for future participants.

## How To Complete This Form
To complete this form, follow these steps:

1.  Select one of the available options for each field.
2.  Enter your comments or suggestions in the text area where specified.
3.  Ensure that you complete all required fields (indicated by \*).

## Field-by-Field Explanation
* **Session Rating (\*)**: Rate your overall experience in this session from 1 to 5.
* **How did you feel during the session? (\*)**: Select all that apply:
	+ Yes
	+ No
* **What would you suggest to improve the session?**: Please provide specific suggestions for improvement.
* **What did you think about the artist? (\*)**: Select all that apply:
	+ Yes
	+ No
* **Enjoyment of the Session**: Select the time you spent in the session.
* **Session Time**: Select the time you spent in the session.
* **Contact Information**: Please enter your email or phone number so we can get in touch with you.
* **Participant Information**: This is a note field for any additional information about yourself.
* **Session Impression**: Select all that apply:
	+ Yes
	+ No
* **Additional Session Ideas**: This is a note field for any additional ideas you might have.
* **Comments**: Leave any additional comments or suggestions here.

## Tips

* Please fill out the form as honestly as possible.
* Ensure that you provide specific suggestions for improvement.
* If you have any additional comments or ideas, please use the corresponding note fields.
