# stand_up_feedback_form - Help Guide
## Purpose
This form is designed to collect feedback from participants in a stand-up comedy club event. It helps us understand how well the show was received by the audience and gather valuable insights to improve future events.

## How To Complete This Form
1.  Please provide your honest feedback on the following aspects of the show:
	* Audience size and demographics
	* Performer's ability to make the audience laugh
	* Overall engagement with the audience
	* Creativity and originality of the performance
	* Performance quality and skill
	* How likely you are to recommend the show
	* Any additional comments or suggestions
2.  Select the category that best describes the type of feedback form you are completing:
	* Feedback Forms
	* Event Feedback Forms

## Field-by-Field Explanation
* **Audience** (1): Please select the number that best describes the size of the audience at the show.
* **prophetspeaker** (2): Please type the name of the performer who was on stage.
* **Show Length** (3): Please select the number that best describes the length of the show.
* **Humor** (4): Please select the number that best describes the level of humor used in the show.
* **Engagement** (5): Please select the number that best describes your level of engagement with the audience.
* **Creativity** (6): Please select the number that best describes the level of creativity used in the show.
* **Performance** (7): Please select the number that best describes the quality of the performance.
* **Recommend** (8): Please select the number that best describes how likely you are to recommend the show to others.
* **Comments** (9): Please provide any additional comments or suggestions you have about the show.
* **Assigned Tool** (10): Please type any tools or resources that were assigned or provided during the show.
* **Category** (11): Please select the category that best describes the type of feedback form you are completing.
* **Form ID** (12): Please ignore this field as it's for internal use only.
