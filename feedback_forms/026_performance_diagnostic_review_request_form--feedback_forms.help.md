# Performance Diagnostic Review Request Form - Help Guide

## Purpose
The Performance Diagnostic Review Request Form is a tool for users to request and submit performance feedback from a reviewer to a reviewee. This form ensures that feedback is collected in a structured and non-duplicative manner.

## How To Complete This Form

1.  To complete this form, please follow these steps:
    1.  Select "Request Form" page.
    2.  Fill in the "Request Form" page with relevant details.
    3.  Select "Submit" to submit your request.
    4.  Fill in the "Reviewer Info", "Reviewee Info" fields with relevant details.
    5.  Select "Feedback Type" and choose the type of feedback you want to provide (Reviewer, Reviewee, Management, Team, Leadership, Other).
    6.  Type your feedback description in the "Feedback Description" field.
    7.  Add any comments from the "Reviewee Comments" field.
    8.  Rate the "Reviewee Performance" in the "Reviewee Performance Rating" field (number rating).
    9.  Provide any suggestions for improvement in the "Reviewee Suggestions" field.

## Field-by-Field Explanation

*   **Request Form** (`request_form`, text, not required): This is the primary page where you will input the details of your feedback request.
    *   Please fill this in with the details you would like to be known about your request.
*   **Reviewer Info** (`reviewer_info`, text, not required): This field is for the reviewer's details.
    *   Please fill this in with the reviewer's name, role, or any other relevant contact information.
*   **Reviewee Info** (`reviewee_info`, text, not required): This field is for the reviewee's details.
    *   Please fill this in with the reviewee's name, role, or any other relevant contact information.
*   **Feedback Type** (`feedback_type`, select_one, not required): This is the type of feedback you want to provide.
    *   Choose from: Reviewer, Reviewee, Management, Team, Leadership, Other
*   **Feedback Description** (`feedback_description`, text, not required): This is where you will describe the feedback you want to provide.
    *   Type in your feedback description here.
*   **Reviewee Comments** (`reviewee_comments`, text, not required): This field is for any additional comments from the reviewee.
    *   Add any comments from the reviewee here.
*   **Reviewee Performance Rating** (`reviewee_performance_rating`, number, not required): This is a number rating of the reviewee's performance.
    *   Rate the reviewee's performance on a scale (number input).
*   **Reviewee Suggestions** (`reviewee_suggestions`, text, not required): This field is for any suggestions for improvement from the reviewee.
    *   Provide any suggestions for improvement here. 

**Tips**

*   Please ensure that you fill in the required fields.
*   Be specific and detailed in your feedback description and comments.
*   Keep your feedback constructive and respectful.
*   Use the "Reviewee Performance Rating" field for a number rating of the reviewee's performance.
