# Volunteer Skill Building Outcome Evaluation Form - Help Guide
## Purpose
The Volunteer Skill Building Outcome Evaluation Form is a tool for tracking and monitoring progress in volunteer skill-building activities. It helps to identify the outcomes of these activities, provide feedback, and document skills acquired.

## How To Complete This Form
To complete this form, please follow these steps:

1. Enter the participant's name in the "Participant Name" field.
2. Describe the skill-building activity in the "Skill Building Activity" field.
3. Select the evaluation date and time in the "Evaluation Date" and "Evaluation Time" fields, respectively.
4. Provide feedback on the activity's effectiveness in the "Feedback" field.
5. List any new skills acquired during the activity in the "Skills Acquired" field.
6. Add any additional comments about the activity in the "Evaluation Comments" field.

## Field-by-Field Explanation

* **Participant Name** (Text): Enter the name of the participant who completed the skill-building activity.
* **Skill Building Activity** (Text): Describe the skill-building activity that was completed, including its name and details.
* **Evaluation Date** (Date): Select the date when the activity was evaluated.
* **Evaluation Time** (Time): Select the time when the activity was evaluated, using 24-hour format.
* **Feedback** (Text): Provide feedback on why the activity was helpful or not. Describe any issues or concerns.
* **Skills Acquired** (Text): List any new skills learned or acquired during the activity.
* **Evaluation Comments** (Text): Provide any additional comments about the activity.

## Tips

* Make sure to select the correct date and time for the evaluation.
* Use specific feedback and comments to help the volunteer understand their progress.
* Keep the "Skills Acquired" field concise and focused on new skills learned.
* Use the "Evaluation Comments" field for any additional information that doesn't fit in other fields.
