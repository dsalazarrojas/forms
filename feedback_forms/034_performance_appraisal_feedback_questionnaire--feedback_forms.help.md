# performance-appraisal-feedback-questionnaire - Help Guide
## Purpose
This form is designed to help managers and supervisors provide constructive feedback to employees. It helps in evaluating performance, goals, and job description, and provides opportunities for employees to receive feedback on areas for improvement. It also includes questions to determine if a recommended salary increase or a developer salary is needed.

## How To Complete This Form
To complete this form, follow these steps:

1. Select all the categories that you would like to provide feedback on. You can choose one or more from:
	* Feedback on performance
	* Feedback on goals
	* Feedback on job description
2. Choose how you rate the employee's performance in relation to these categories:
	* Exceeds expectations
	* Meets expectations
	* Needs improvement
3. If you want to provide feedback on specific performance criteria, enter it in the "Performance criteria" field.
4. If you have any specific feedback comments, type them in the "Feedback comments" field.
5. If you think the employee's salary is too high or too low, select an option for a "Recommended Developer Salary" and/or "Recommended salary increase".

## Field-by-Field Explanation
### Feedback Form
* **Feedback Form** (`Feedback Form`, `select_multiple`, required): Select one or more of the categories that you would like to provide feedback on. This could be:
	* Feedback on performance
	* Feedback on goals
	* Feedback on job description
### Performance and Goals
* **Performance and Goals** (`Performance and Goals`, `select_one`, required): Choose how you rate the employee's performance in relation to these categories. Options are:
	* Exceeds expectations
	* Meets expectations
	* Needs improvement
### Job Description
* **Job Description** (`Job Description`, `select_one`, required): This field is for feedback on how well the employee understands and performs their job description. Options are:
	* Too vague
	* Too specific
	* Just right
### Performance Criteria
* **Performance criteria** (`Performance criteria`, `text`, required): If you want to provide feedback on specific performance criteria, type it in this field. For example, you could enter "Meeting deadlines" or "Communication skills".
### Feedback comments
* **Feedback comments** (`Feedback comments`, `text`, required): Provide any other feedback or comments you have for the employee.
### Recommended Developer Salary
* **Recommended Developer Salary** (`Recommended Developer Salary`, `select_one`, optional): Select "True" if you think the developer's salary should be increased, "False" otherwise. If unsure, choose "Maybe".
### Recommended salary increase
* **Recommended salary increase** (`Recommended salary increase`, `select_multiple`, optional): Select "True" if you think the employee should have a salary increase, "False" otherwise. If unsure, choose "Maybe".

## Tips
* Make sure to provide specific and concrete feedback.
* Choose the most relevant options that apply to the employee's performance.
* Remember that the employee's salary will be increased only if you select the "Recommended Developer Salary" option.
* Be as objective and fair as possible when providing feedback.
