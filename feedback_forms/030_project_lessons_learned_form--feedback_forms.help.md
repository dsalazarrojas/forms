# Project Lessons Learned Form - Help Guide
## Purpose
The Project Lessons Learned Form is designed to gather feedback and insights from project leads and team members to improve project management processes and outcomes. Please complete this form to provide valuable information on your project experience.

## How To Complete This Form
To complete this form, follow these steps:

1.  Review the form sections and fields below.
2.  Fill out each field accurately and thoroughly.
3.  If you are unsure about any field, please ask your team or project lead for clarification.

## Field-by-Field Explanation
### 1. Project Leads (project_leads)
• **Project Leads** (`project_leads`, `text`, required/optional): Please enter the names and job titles of the project leads involved in the project.
### 2. Project Rating (project_rating)
• **Project Rating** (`project_rating`, `select_one`, required/optional): This field allows you to rate the project's overall success. Please select one of the following options: High, Low, or Neutral.
### 3. Lessons Learned (lessons_learned)
• **Lessons Learned** (`lessons_learned`, `text`, required/optional): Please provide a brief description of the lessons you learned from the project.
### 4. Team Feedback (team_feedback)
• **Team Feedback** (`team_feedback`, `select_multiple`, required/optional): This field allows you to provide feedback on the team's performance. Please select all that apply:
	+ Yes
	+ No
### 5. Recommendations (recommendations)
• **Recommendations** (`recommendations`, `text`, required/optional): Please provide any recommendations you have for future projects based on your experience with this project.
### 6. Contact Info for Project Leads (project_leads_contact)
• **Contact Info for Project Leads** (`project_leads_contact`, `text`, required/optional): Please provide the contact information for project leads, including phone number, email, or any other relevant contact details.
### 7. Contact Info for PMOS (pmos_contact)
• **Contact Info for PMOS** (`pmos_contact`, `text`, required/optional): Please provide the contact information for PMOS, including phone number, email, or any other relevant contact details.
### 8. Project Leads Email (project_leads_email)
• **Project Leads Email** (`project_leads_email`, `email`, required/optional): Please provide the email address of the project leads.
### 9. PMOS Email (pmos_email)
• **PMOS Email** (`pmos_email`, `email`, required/optional): Please provide the email address of PMOS.
### 10. Job Title (project_leads_job_title)
• **Job Title** (`project_leads_job_title`, `text`, required/optional): Please enter the job title of the project leads.
### 11. PMOS Job Title (pmos_job_title)
• **PMOS Job Title** (`pmos_job_title`, `text`, required/optional): Please enter the job title of PMOS.
### 12. Department (project_leads_department)
• **Department** (`project_leads_department`, `select_one`, required/optional): Please select the department of the project leads:
	+ Finance
	+ Marketing
	+ Sales
### 13. PMOS Department (pmos_department)
• **PMOS Department** (`pmos_department`, `select_one`, required/optional): Please select the department of PMOS:
	+ Finance
	+ Marketing
	+ Sales
### 14. Job Function (project_leads_job_function)
• **Job Function** (`project_leads_job_function`, `select_one`, required/optional): Please select the job function of the project leads:
	+ Project Manager
	+ Team Lead
	+ Team Member
### 15. PMOS Job Function (pmos_job_function)
• **PMOS Job Function** (`pmos_job_function`, `select_one`, required/optional): Please select the job function of PMOS:
	+ Project Manager
	+ Team Lead
	+ Team Member
### 16. Manager (project_leads_manager)
• **Manager** (`project_leads_manager`, `select_one`, required/optional): Please select whether the project leads have a manager:
	+ True
	+ False
### 17. PMOS Manager (pmos_manager)
• **PMOS Manager** (`pmos_manager`, `select_one`, required/optional): Please select whether PMOS has a manager:
	+ True
	+ False
### 18. Organisation (project_leads_organisation)
• **Organisation** (`project_leads_organisation`, `text`, required/optional): Please provide the organisation of the project leads.
### 19. PMOS Organisation (pmos_organisation)
• **PMOS Organisation** (`pmos_organisation`, `text`, required/optional): Please provide the organisation of PMOS.
### 20. Additional Comments (project_leads_additional_comments)
• **Additional Comments** (`project_leads_additional_comments`, `text`, required/optional): Please provide any additional comments or insights about the project.
### 21. PMOS Additional Comments (pmos_additional_comments)
• **PMOS Additional Comments** (`pmos_additional_comments`, `text`, required/optional): Please provide any additional comments or insights about PMOS.

## Tips
- Please be accurate and honest in your feedback.
- If you are unsure about any field, please ask your team or project lead for clarification.
- This form should only be filled out once per project. If you have already submitted feedback on this project, please do not repeat the process.
