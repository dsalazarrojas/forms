# Sewing Pattern Feedback Survey - Help Guide
## Purpose
This form is designed to collect feedback from users about our sewing patterns. We value your opinion and want to hear about your thoughts on our patterns.

## How To Complete This Form
To complete this form, simply follow these steps:

* Answer all the questions as honestly as possible.
* Choose one or more options for each question, unless otherwise indicated.
* Make sure to provide your email address if you would like to be contacted for feedback.

## Field-by-Field Explanation

* **User Input** (`user_input`, text, not required): This is a text field where you can provide any additional comments or thoughts about our sewing patterns.
* **What do you think of our patterns?** (`question_1`, select_one, not required): This question asks you to rate your overall impression of our patterns. Select one of the options: Very Good, Good, Fair, or Bad.
* **Would you like to see more patterns like this?** (`question_2`, select_multiple, not required): This question asks you if you would like to see more patterns similar to the one you are currently viewing. Choose one or more of the options: True, False, or Maybe.
* **What do you think could be improved?** (`question_3`, text, not required): This question asks you to provide specific suggestions for improvement.
* **What do you like about this pattern?** (`question_4`, select_one, not required): This question asks you to choose something you liked about the pattern. Select one of the options: The design was great, The instructions were clear, The materials were adequate, or Other (please specify).
* **What do you dislike about this pattern?** (`question_5`, select_multiple, not required): This question asks you to choose one or more things you disliked about the pattern. Select one or more of the options: The design was poor, The instructions were unclear, The materials were inadequate, or Other (please specify).
* **Do you have any comments about this pattern?** (`question_6`, note, not required): This is a free-text field where you can provide any additional comments or thoughts.
* **Email** (`email`, email, not required): If you would like to be contacted for feedback, please provide your email address.
* **Phone** (`phone`, text, not required): This is a text field where you can provide your phone number if you would like to be contacted by phone.
* **Would you like to be contacted for feedback?** (`question_7`, select_one, not required): This question asks you if you would like to be contacted for feedback.
* **How would you like to be contacted?** (`question_8`, select_one, not required): This question asks you how you would like to be contacted if you are contacted for feedback. Select one of the options: Phone, Email, or None.
