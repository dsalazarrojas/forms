# event_information_unsubscription_form - Help Guide
## Purpose
This form is used to collect information for event unsubscription.

## How To Complete This Form
- Fill out this form completely and accurately with the necessary details for the event unsubscription.
- Review all fields carefully before submitting.

## Field-by-Field Explanation
- **Unsubscribe Event** (`1`, text, optional): Enter a short note or description to briefly explain why you want to unsubscribe from the event.
- **Email** (`2`, email, optional): Enter your email address associated with the event.
  - This field is used to verify your identity.
- **Confirm Email** (`3`, select_one, required): Confirm that you want to unsubscribe from the event by selecting the corresponding option.
  - Select "confirm event email" to confirm your email address is associated with the event.
  - Select "confirm event" to confirm you want to unsubscribe from the event.
- **Confirm Email Confirmation** (`4`, select_multiple, required): Confirm that you've received a successful unsubscription confirmation.
  - Select "confirm event email confirmation" to confirm the unsubscription was successful.
  - Select "confirm event" to confirm the unsubscription was successful for the event.
- **Event ID** (`5`, number, optional): Enter a unique identifier for the event associated with your subscription.
  - Enter the event ID if you have it.
- **Event Title** (`6`, text, optional): Enter the title of the event associated with your subscription.
  - Enter the event title if you have it.
- **Event Description** (`7`, text, optional): Enter a description of the event associated with your subscription.
  - Enter a brief description of the event.
- **Event Date** (`8`, date, optional): Enter the date of the event associated with your subscription.
  - Enter the event date if you have it.
- **Event Time** (`9`, time, optional): Enter the time of the event associated with your subscription.
  - Enter the event time if you have it.
- **Submit** (`10`, select_one, required): Confirm your intent to unsubscribe from the event.
  - Select "submit" to submit your unsubscription request.
  - Select "cancel" to cancel your unsubscription request.

## Tips
- Please make sure you are using the correct event details to avoid unsubscriptions from incorrect events.
- Ensure you have filled out all required fields before submitting.
- If you have any issues or concerns, please contact [support contact information].
