# Task Prioritization Survey - Help Guide
## Purpose
The purpose of this survey is to gather information about tasks to be prioritized for a specific period. This form helps users to provide input on tasks they are responsible for and their corresponding priorities, descriptions, and other relevant details.

## How To Complete This Form
1. Select all the tasks you are responsible for.
2. Choose the priority level of each selected task (High, Medium, or Low).
3. Enter a brief description of each task.
4. Identify any tags or keywords associated with each task.
5. Indicate whether you have comments or feedback for each task.
6. Enter any additional tags or keywords for this survey.

## Field-by-Field Explanation
* **Task List** (`task_list`, `select_multiple`, optional): This field allows you to select all the tasks you are responsible for. Simply choose all the relevant tasks from the list.

* **Task Priority** (`task_priority`, `select_one`, optional): This field is used to set the priority level of each selected task. Choose High, Medium, or Low based on your assessment of the task's urgency.

* **Task Description** (`task_description`, `text`, optional): In this field, enter a brief description of each selected task. This will help us understand what each task entails.

* **Task Tags** (`task_tags`, `select_multiple`, optional): Identify any relevant tags or keywords for each task in this field. This will help us categorize the tasks more accurately.

* **Task Comments** (`task_comments`, `select_multiple`, optional): Indicate whether you have any comments or feedback for each task. If you have any notes or observations, please enter them here.

* **Tags** (`tags`, `text`, optional): Enter any additional tags or keywords that apply to this survey. This will help us further refine our understanding of the tasks and the survey's scope.
