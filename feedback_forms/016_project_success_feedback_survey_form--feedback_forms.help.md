# Project Success Feedback Survey Form - Help Guide

## Purpose
This form is designed to gather feedback from project stakeholders on the success of a project. The feedback will help the project team identify areas of improvement and make informed decisions for future projects.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the "Project Feedback" page and fill in a brief description of the project.
2. On the "Overall Project Rating" page, choose a number rating from 1 to 4, where 1 is "Not Successful" and 4 is "Very Successful".
3. On the "What do you think was the success of this project?" page, select all options that apply from the list of options provided.
4. On the "What areas of improvement do you suggest?" page, select all options that apply from the list of options provided.
5. In the "Do you have any recommendations for future projects?" field, type in any suggestions or ideas you have for future projects.
6. If you want to provide your contact information, fill in your email address and/or phone number.
7. Finally, if you have any additional comments, type them in the "Additional Comments" field.

## Field-by-Field Explanation
* **Project Feedback**:
	+ This field is a text field where you can write a brief description of the project.
	+ This field is not required, but it helps the project team understand the project context.
* **Overall Project Rating**:
	+ This field is a number field where you can rate the project from 1 to 4.
	+ 1 means "Not Successful", 2 means "Somewhat Successful", 3 means "Very Successful", and 4 means "Very Very Successful".
* **What do you think was the success of this project?**:
	+ This field is a multi-select field where you can choose all options that apply.
	+ Options are:
		- Option 1
		- Option 2
		- Option 3
		- Option 4
* **What areas of improvement do you suggest?**:
	+ This field is a multi-select field where you can choose all options that apply.
	+ Options are:
		- Option 1
		- Option 2
		- Option 3
		- Option 4
* **Do you have any recommendations for future projects?**:
	+ This field is a text field where you can write any suggestions or ideas you have for future projects.
* **Your Email**:
	+ This field is an email field where you can type your email address.
* **Your Phone**:
	+ This field is a text field where you can type your phone number.
* **Additional Comments**:
	+ This field is a note field where you can write any additional comments you have.
