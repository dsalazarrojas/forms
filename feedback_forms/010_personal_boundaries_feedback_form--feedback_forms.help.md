# Personal Boundaries Feedback Form - Help Guide
## Purpose
This form is designed to gather feedback on employee personal boundaries, specifically in the context of user behavior and interaction. The form is intended to help managers and HR personnel understand the boundaries that need to be respected in a workplace setting.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the category for which you are providing feedback.
2. Provide a brief description of the issue or concern.
3. Indicate if you feel the user's behavior is a threat to your user safety.
4. Choose how you feel about the user's boundary respect.
5. If you have any suggestions for improvement, provide them in the text box.
6. If you have any additional comments, provide them in the text box.
7. Click "Submit" to submit your feedback.

## Field-by-Field Explanation
* **Form ID**: <code> (required: false) - This is a unique identifier for the form, which will be automatically generated and cannot be edited.
* **Category**: <select> (Feedback Forms) (required: false) - Select the category for which you are providing feedback.
* **Description**: <text> (required: false) - Provide a brief description of the issue or concern.
* **User Safety**: <select multiple> (User Safety, User Respect, Workplace Safety) (required: false) - Indicate if you feel the user's behavior is a threat to your user safety.
* **Boundary Respect**: <select> (Strongly Disagree, Somewhat Disagree, Neutral, Somewhat Agree, Strongly Agree) (required: false) - Choose how you feel about the user’s boundary respect.
* **Suggestions**: <text> (required: false) - If you have any suggestions for improvement, provide them in this text box.
* **Comments**: <text> (required: false) - If you have any additional comments, provide them in this text box.

## Tips
* Please keep your feedback concise and clear.
* Please be specific about the issue or concern.
* Please be respectful in your feedback, even if it's constructive criticism.
* If you have any additional suggestions or comments, please provide them in the text boxes.
* If you have any further questions or concerns, please reach out to the HR department.
