# Daily Returns Tracking Survey - Help Guide
## Purpose
This form is designed to collect data on customer returns, including return dates, reasons, product details, and staff feedback. The collected data will be used to track and analyze customer return trends.

## How To Complete This Form

1. Fill in the Return Date field with the date the customer returned the product.
2. Enter the Customer Email of the customer who returned the product.
3. Select the Return Reason from the list of options provided.
4. Enter the Customer Name and Product Name of the product returned.
5. Enter the Product Type and Customer Order ID of the returned product.
6. Select the Order Status and Return Status from the list of options provided.
7. Enter any Comments regarding the return.
8. Enter the Customer Rating if applicable.
9. Enter any Staff Feedback regarding the return.
10. Select the Store Name and Store ID for the returned product.
11. Select the Return Method used.
12. Enter the Resolution Time and Resolution Status for the return.
13. Enter the Store ID 2 and Staff ID 2 for the returned product.

## Field-by-Field Explanation

* **Return Date** (`return_date`, date, required): Enter the date the customer returned the product.
* **Customer Email** (`customer_email`, email, required): Enter the email of the customer who returned the product.
* **Return Reason** (`return_reason`, text, required): Select the reason for the return from the list of options provided.
* **Return Type** (`return_type`, select_one, required): Select the type of return from the list of options provided.
* **Customer Name** (`customer_name`, text, required): Enter the name of the customer who returned the product.
* **Product Type** (`product_type`, text, required): Enter the type of the product returned.
* **Product Name** (`product_name`, text, required): Enter the name of the product returned.
* **Customer Order ID** (`customer_order_id`, text, required): Enter the customer order ID for the returned product.
* **Order Status** (`order_status`, select_one, required): Select the status of the order from the list of options provided.
* **Return Status** (`return_status`, select_one, required): Select the status of the return from the list of options provided.
* **Comments** (`comments`, text, required): Enter any comments regarding the return.
* **Customer Rating** (`customer_rating`, number, required): Enter a rating from 1 to 5 if applicable.
* **Staff Feedback** (`staff_feedback`, text, required): Enter any feedback from the staff regarding the return.
* **Store Name** (`store_name`, select_multiple, required): Select the name of the store where the return was processed.
* **Staff Name** (`staff_name`, text, required): Enter the name of the staff member who processed the return.
* **Return Method** (`return_method`, select_one, required): Select the method used for the return from the list of options provided.
* **Resolution Time** (`resolution_time`, time, required): Enter the time it took to resolve the return.
* **Resolution Status** (`resolution_status`, select_one, required): Select the status of the resolution from the list of options provided.
* **Store ID** (`store_id`, text, required): Enter the ID of the store where the return was processed.
* **Staff ID** (`staff_id`, text, required): Enter the ID of the staff member who processed the return.
* **Resolution Date** (`resolution_date`, date, required): Enter the date the return was resolved.
* **Resolution Time** (`resolution_time`, time, required): Enter the time it took to resolve the return.
* **Store ID 2** (`store_id_2`, text, required): Enter the ID of the store where the return was processed.
* **Staff ID 2** (`staff_id_2`, text, required): Enter the ID of the staff member who processed the return.
* **Store Name 2** (`store_name_2`, text, required): Enter the name of the store where the return was processed.
