# Post Event Networking Feedback Questionnaire - Help Guide
## Purpose

This form is a feedback mechanism designed to assess the quality of networking opportunities at events. It aims to collect valuable insights from attendees to help us improve future events.

## How To Complete This Form

- Read through each question carefully before responding.
- Provide honest and accurate feedback.
- Fill out all required fields (indicated by an asterisk (*)).
- Select only one option for single-selection questions (e.g., Quality of Networking).
- Select all applicable options for multi-selection questions (e.g., Networking Opportunities).
- You can add comments or suggestions in the "Feedback" and "Suggestions for Improvement" fields.

## Field-by-Field Explanation
### 1. Event Name
  * (`event_name`, text, not required) 
   This field is where you will enter the name of the event you attended.

### 2. Number of Attendees
  * (`attendee_count`, number, not required) 
  This field is where you will enter the estimated number of attendees at the event.

### 3. Networking Opportunities
  * (`networking_opportunities`, select_multiple, not required) 
   Select all applicable options to describe the networking opportunities you experienced at the event:
   - Attendees
   - Speakers
   - Sponsors

### 4. Quality of Networking
  * (`quality_of_networking`, select_one, not required) 
   Select one option to rate the quality of networking you experienced at the event:
   - Excellent
   - Good
   - Satisfactory

### 5. Suggestions for Improvement
  * (`suggestions_for_improvement`, text, not required) 
   Add any suggestions you may have for improving the networking experience at future events.

### 6. Feedback
  * (`feedback`, text, not required) 
   Share any additional comments or feedback you may have about the event.
