# Supermarket Survey - Help Guide
## Purpose
This form is a survey designed to gather feedback from customers about their experiences with the supermarket. It will help store management to understand customer needs and improve store operations.

## How To Complete This Form
To complete this form, simply follow these steps:

1. Read each question carefully and answer all the questions that apply to you.
2. Use the options provided for each question to select your answer.
3. If you have any additional comments or suggestions, you can include them in the text field at the top of the form.

## Field-by-Field Explanation

* **This is a supermarket survey** (`introduction`, `text`, required: false): This is a brief introduction to the survey. Please read it carefully before proceeding.
* **Customer Type** (`customer_type`, `select_multiple`, required: false): Select all the types of customer you are from the list provided. For example, if you select both "Yes" and "No", you can also select other options.
* **Age Group** (`age_group`, `text`, required: false): Please type your age group in the provided text field. For example, "20-30", "31-40", etc.
* **Customer Service** (`customer_service`, `select_multiple`, required: false): Select all the types of customer service you received from the store staff. For example, if you select both "Yes" and "No", you can also select other options.
* **Product Quality** (`product_quality`, `number`, required: false): Please rate the quality of the products you purchased. For example, on a scale of 1-5, where 1 is the lowest and 5 is the highest.
* **Store Location** (`store_location`, `select_one`, required: false): Select if you visited the store at this location.
* **Store Hours** (`store_hours`, `time`, required: false): Please type the store hours you visited. For example, "9:00 AM - 7:00 PM".
* **Store Atmosphere** (`store_atmosphere`, `select_multiple`, required: false): Select all the aspects of the store atmosphere that you found pleasant. For example, if you select both "Yes" and "No", you can also select other options.
* **Product Selection** (`product_selection`, `select_multiple`, required: false): Select all the types of products you purchased. For example, if you select both "Yes" and "No", you can also select other options.
* **Employee Friendly** (`employee_friendly`, `select_multiple`, required: false): Select all the characteristics of store employees you found pleasant. For example, if you select both "Yes" and "No", you can also select other options.
