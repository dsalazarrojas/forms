# Event Follow Up Survey - Help Guide

## Purpose
The Event Follow Up Survey is used by staff to gather information from customers after an event. It helps to ensure that the customer's experience was satisfactory and that any additional information needed to improve future events is collected.

## How To Complete This Form
To complete this form, follow these steps:

1. Make sure that the survey is not already completed for the customer's date of event.
2. Answer each question thoroughly and accurately.
3. If the customer's event type is "Yes", select all applicable options.
4. Enter any relevant contact information to help us get in touch with the customer.
5. Enter the customer's email address (if available) to help us follow up with them.
6. If you have completed the survey, you will be directed to a confirmation page. Please do not leave this page until you have been directed to do so.

## Field-by-Field Explanation
* **event_follow_up_survey** (text, required/optional): This is the main section of the survey where you can write a brief message or description about the event.
* **event_type** (select_multiple, required/optional): Check all options that apply to the event that has just occurred.
* **event_location** (text, required/optional): Enter the location of the event.
* **follow_up_question** (text, required/optional): This is a question or comment that you can use to ask the customer if they have any other questions or concerns.
* **customer_name** (text, required/optional): Enter the customer's name.
* **contact_information** (text, required/optional): Enter any contact information (e.g. phone number, address) that we can use to get in touch with the customer.
* **email** (email, required/optional): Enter the customer's email address.
* **phone** (text, required/optional): Enter the customer's phone number.
* **event_date** (date, required/optional): Enter the date of the event.
* **event_time** (time, required/optional): Enter the time of the event.

## Tips
* Please answer each question thoroughly and accurately.
* If the customer's event type is "Yes", make sure to select all applicable options.
* If you have any doubts or concerns, please contact the relevant team or supervisor.
* Make sure to save your progress regularly to avoid losing any information.
