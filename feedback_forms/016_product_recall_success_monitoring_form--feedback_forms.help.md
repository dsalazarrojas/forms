# product_recall_success_monitoring_form - Help Guide

## Purpose
This form is used to collect feedback from customers on product recall success monitoring. It helps in tracking the success of product recall activities, customer satisfaction, and other relevant metrics.

## How To Complete This Form
1. Fill in the required fields with accurate information to ensure that your feedback is considered.
2. If you have any additional comments, please use the "Customer Message" field.
3. Select the correct options for "Response Type", "Product Returned In Last 3 Years", "Product Quality", "Product Safety", "Product Satisfaction", and "Customer Service Rating" fields based on your experience.
4. Provide detailed comments for the "Customer Message Response", "Customer Service Response", and "Customer Satisfaction Response" fields if needed.
5. Submit the form once you have completed all the required fields.

## Field-by-Field Explanation

* **Form Data** (`Form Data`, text, required): Please enter a brief description of the product recall experience.
* **Recall Date** (`Recall Date`, date, required): The date of the product recall.
* **Product Name** (`Product Name`, text, required): The name of the product returned.
* **Product Code** (`Product Code`, text, required): The product code of the recalled product.
* **Customer Email** (`Customer Email`, email, required): Enter your email address so we can contact you if needed.
* **Customer Phone** (`Customer Phone`, text, required): Your phone number for follow-up.
* **Feedback** (`Feedback`, text, required): A brief description of your feedback.
* **Response Type** (`Response Type`, select_one, required): Select the type of response you are giving (e.g., refund, replacement, etc.).
* **Response Code** (`Response Code`, text, required): Enter the response code for the response type you selected.
* **Customer Message** (`Customer Message`, text, required): Enter any additional comments you have about your experience.
* **Customer Message Response Prophets** (`Customer Message Response Prophets`, text, required): Enter any response for the customer message.
* **Product Returned Quantity** (`Product Returned Quantity`, number, optional): The quantity of products returned.
* **Products Returned In Last 3 Years** (`Products Returned In Last 3 Years`, select_multiple, optional): Select the products returned in the last 3 years.
* **Reasons For Returned Products** (`Reasons For Returned Products`, text, optional): Enter the reasons for the returned products.
* **Customer Service** (`Customer Service`, time, optional): The time spent with the customer service team.
* **Product Quality** (`Product Quality`, select_one, optional): Select the quality of the product.
* **Product Safety** (`Product Safety`, text, optional): Enter any comments about product safety.
* **Product Satisfaction** (`Product Satisfaction`, select_multiple, optional): Select the product satisfaction level.
* **Customer Satisfaction** (`Customer Satisfaction`, select_one, optional): Select the customer satisfaction level.
* **Customer Satisfaction Response** (`Customer Satisfaction Response`, text, optional): Enter any response for the customer satisfaction.
* **Customer Service Response** (`Customer Service Response`, text, optional): Enter any response for the customer service.
* **Customer Message Response** (`Customer Message Response`, text, optional): Enter any response for the customer message.
* **Customer Service Rating** (`Customer Service Rating`, select_one, optional): Select the customer service rating.
* **Customer Service Rating Response** (`Customer Service Rating Response`, text, optional): Enter any response for the customer service rating.
* **Customer Returned Products Reason** (`Customer Returned Products Reason`, text, optional): Enter the reason for the returned products.
