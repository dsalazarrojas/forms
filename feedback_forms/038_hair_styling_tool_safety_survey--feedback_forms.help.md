# Hair Styling Tool Safety Survey - Help Guide

## Purpose
This form is used to gather feedback from users about the safety of hair styling tools. If you're using a hair styling tool, we'd like to know about any concerns or issues you've encountered regarding its safety.

## How To Complete This Form

To fill out this form, simply follow these steps:

1. Select the type of hair styling tool you're concerned about from the dropdown menu.
2. Choose the safety features you think are missing or inadequate in the tool.
3. If you have any specific safety concerns, type them in the text field.
4. Add any additional comments or feedback you'd like to share about the tool.
5. Provide your email address so we can follow up with you.
6. Finally, type in your phone number (if you'd like to be contacted).
7. Click the "Submit" button to submit your feedback.

## Field-by-Field Explanation

* **Hair Styling Tool Type** (`hair_styling_tool_type`, select_one, required: false): Please select the type of hair styling tool you're concerned about, such as a blow dryer, straightening tool, or hair straightener.
* **Safety Feature** (`safety_feature`, select_multiple, required: false): Choose any safety features you think are missing or inadequate in the tool, such as a heating element safety switch or overheating protection.
* **Safety Question** (`safety_question`, text, required: false): If you have a specific concern regarding the safety of the tool, type it in this field.
* **Comment** (`comment`, text, required: false): Add any additional comments or feedback you'd like to share about the tool.
* **Email** (`email`, email, required: false): Provide your email address so we can follow up with you.
* **Phone** (`phone`, text, required: false): If you'd like to be contacted, type in your phone number.
* **Submit** (`submit`, text, required: false): Click this button to submit your feedback.
