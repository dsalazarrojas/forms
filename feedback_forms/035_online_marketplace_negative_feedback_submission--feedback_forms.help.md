# online_marketplace_negative_feedback_submission - Help Guide
## Purpose
The online marketplace negative feedback submission form is designed to collect feedback from users on their negative experiences with the marketplace. This feedback will help us identify and fix issues, improve the user experience, and provide better services.

## How To Complete This Form
To complete this form, follow these steps:

1. Please fill out the form thoroughly, providing as much detail as possible about your submission.
2. Make sure to provide your contact information, so we can get in touch with you if we need more information.
3. If you want us to follow up on your issue, please mark the "Follow-up" field accordingly.
4. Please indicate if the issue is a priority for you to be resolved.

## Field-by-Field Explanation

* **Submission Details** (`submission_details`, text, required: false): Please provide a brief description of your negative experience with the marketplace. This can include details about the issue, date, time, and any other relevant information.
* **Contact Information** (`contact_information`, text, required: false): Please provide your email address or phone number so we can get in touch with you if we need more information.
* **Marketplace Details** (`marketplace_details`, text, required: false): Please provide any additional information about the marketplace that you think is relevant to the issue you're reporting.
* **Submission Comments** (`submission_comments`, text, required: true): Please provide a detailed description of your issue, including any steps you took to resolve it and any error messages you encountered.
* **Issue Priority** (`issue_priority`, select_one, required: true): Please select "Yes" if the issue is a priority for you to be resolved, and "No" otherwise. This will help us prioritize the issues we receive.
* **Follow-up** (`follow_up`, select_multiple, required: false): If you want us to follow up on your issue, please select one or both of the options "Yes" and "No" depending on your preference.

## Tips

* Please be honest and accurate in your feedback, as it will help us improve the marketplace.
* Do not report issues that are not genuine or are duplicates of previously reported issues.
* Make sure to fill out all required fields, marked as "required: true" in the form.
* If you have any questions or need help, please do not hesitate to contact us.
