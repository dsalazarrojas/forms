# Library Reading Program Evaluation Form - Help Guide
## Purpose
This form is designed to evaluate the effectiveness of the Library Reading Program, allowing you to provide feedback on your experience with the program. Your feedback will help us improve and refine the program to better serve the needs of our community.

## How To Complete This Form
To complete this form, simply fill out each section according to your experience with the Library Reading Program. For each field, you can enter text or select from the provided options. If you have additional comments or suggestions, please use the "comments" and "additional comments" fields. If you would like to contact us with questions or concerns, please provide your contact information in the "contact" section.

## Field-by-Field Explanation
- **Program Name** (`program_name`, text): This is the name of the program you participated in.
  * Please enter the name of the program as it was presented to you (e.g., "Summer Reading Program", "Children's Reading Program", etc.).
- **Program Location** (`program_location`, text): This is the location where the program took place.
  * Please enter the name of the library or location where the program was held.
- **Program Date** (`program_date`, date): This is the date the program occurred.
  * Please enter the start date of the program (MM/DD/YYYY).
- **Program Start Time** (`program_start_time`, time): This is the start time of the program.
  * Please enter the start time of the program (HH:MM AM/PM).
- **Program End Time** (`program_end_time`, time): This is the end time of the program.
  * Please enter the end time of the program (HH:MM AM/PM).
- **Program Length** (`program_length`, text): This is the duration of the program.
  * Please enter the approximate length of the program in hours or minutes.
- **Number of Participants** (`number_of_participants`, text): This is the number of participants in the program.
  * Please enter the number of people who participated in the program.
- **Participant Age Range** (`participant_age_range`, text): This is the age range of the participants.
  * Please enter the age range of the participants (e.g., "5-12", "13-18", etc.).
- **Participant Gender** (`participants_gender`, select_one): This is the gender of the participants.
  * Please select from the following options:
    + Male
    + Female
    + Other
  * If "Other", please describe the participant's gender.
- **Participant Ethnicity** (`participant_ethnicity`, text): This is the ethnicity of the participants.
  * Please enter the ethnicity of the participants.
- **Participant Language** (`participant_language`, select_multiple): This is the language(s) spoken by the participants.
  * Please select from the following options:
    + English
    + Spanish
    + Other
  * If "Other", please describe the participant's language.
- **Program Rating** (`program_rating`, number): This is your rating of the program.
  * Please rate the program on a scale of 1-5, with 1 being the lowest and 5 being the highest.
- **Program Rating Comment** (`program_rating_comment`, text): This is an explanation of your rating.
  * Please enter a brief comment about why you gave the program this rating.
- **Would Recommend** (`would_recommend`, select_one): This is whether you would recommend the program.
  * Please select from the following options:
    + 'True'
    + 'False'
    + Undecided
  * If "Undecided", please explain why.
- **Why Didn't Recommend** (`why_didnt_recommend`, text): This is why you didn't recommend the program.
  * Please enter a brief explanation of why you didn't recommend the program.
- **Comments** (`comments`, note): This is any additional comments or feedback you have about the program.
  * Please enter any additional thoughts or suggestions you have about the program.
- **Contact Email** (`contact_email`, email): This is your contact email address.
  * Please enter your email address so we can get in touch with you.
- **Contact Phone** (`contact_phone`, text): This is your phone number.
  * Please enter your phone number if you would like to be contacted.
- **Contact Message** (`contact_message`, text): This is any message you would like to leave.
  * Please enter a brief message or question.
- **Additional Comments** (`additional_comments`, text): This is any additional comments or feedback you have about the program.
  * Please enter any thoughts or suggestions you have about the program.
- **Library Rating** (`library_rating`, number): This is your rating of the library's service.
  * Please rate the library's service on a scale of 1-5, with 1 being the lowest and 5 being the highest.
- **Library Rating Comment** (`library_rating_comment`, text): This is an explanation of your library rating.
  * Please enter a brief comment about why you gave the library this rating.
