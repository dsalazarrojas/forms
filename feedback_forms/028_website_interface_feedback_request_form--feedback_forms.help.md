# Website Interface Feedback Request Form - Help Guide
## Purpose
This form is a tool for users to report issues with the website's interface and provide feedback on how it can be improved.

## How To Complete This Form
To complete this form, follow these steps:

1. **User Input**: Enter a brief description of the issue you are experiencing with the website's interface.
2. Choose the **Browser** you are using to access the website. This will help us understand which browser may be causing the issue.
3. Choose the **Device** you are using to access the website. This can help us understand how the issue is affecting your user experience.
4. Select all that apply for **Issue Type**. Choose the type of issue you are experiencing, such as Bug, Feature, or Feedback.
5. **Description**: Provide a detailed description of the issue you are experiencing.
6. You can optionally add a **Screenshot** of the issue if it is a visual bug.
7. **Email**: Enter your email address so we can contact you if we need more information.
8. Click **Submit** to send your feedback, or **Reset** to start over.

	+ **Label:** Device

* **Issue Type**: This field allows you to select the type of issue you are experiencing.
	+ **Label:** Issue Type
	+ **Type:** Select multiple options
	+ **Purpose:** Choose all that apply for Bug, Feature, or Feedback.
* **Description**: This field is where you can provide a detailed description of the issue you are experiencing.
	+ **Label:** Description
	+ **Type:** Text input field
	+ **Purpose:** Provide a detailed description of the issue.
* **Screenshot**: This field allows you to add a screenshot of the issue if it is a visual bug.
	+ **Label:** Screenshot
	+ **Type:** Select multiple options
	+ **Purpose:** You can optionally add a screenshot of the issue if it is a visual bug.
* **Email**: This field is where you can enter your email address so we can contact you if we need more information.
	+ **Label:** Email
	+ **Type:** Email input field
	+ **Purpose:** Enter your email address so we can contact you if we need more information.
* **Submit**: This button allows you to submit your feedback.
	+ **Label:** Submit
	+ **Type:** Select one option
	+ **Purpose:** Click to send your feedback.
* **Reset**: This button allows you to reset the form and start over.
	+ **Label:** Reset
	+ **Type:** Select one option

## Tips

* Please be as detailed as possible when describing the issue.
* If you are experiencing a visual bug, please add a screenshot to help us understand the issue.
* Make sure to enter a valid email address so we can contact you if we need more information.
* If you are unsure about any of the fields, you can always ask for clarification.
