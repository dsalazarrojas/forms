# Client Consultation Satisfaction Poll - Help Guide
## Purpose
This form is designed to collect feedback on our client consultation services, allowing us to gauge our performance and identify areas for improvement.

## How To Complete This Form
1. Please fill out the form with as much detail as possible.
2. Make sure to answer all required questions.
3. Use the options provided for each question to select the most accurate response.
4. If you have any additional comments or feedback, please use the "Additional Comments" field.

## Field-by-Field Explanation

* **First Name** (`client_first_name`, text, Optional - for follow-up): Enter your first name for future reference.
* **Last Name** (`client_last_name`, text, Optional - for follow-up): Enter your last name for future reference.
* **Email Address** (`client_email`, email, For survey results): Enter your email address so we can contact you with survey results.
* **Date of Consultation** (`consultation_date`, date, Required): Enter the date of your consultation appointment.
* **Consultant Name** (`consultant_name`, text, Optional - for follow-up): Enter the name of the consultant you met with.
* **Service Type** (`service_type`, select_one, Required): Select the type of consultation you received (e.g., Initial Consultation, Follow-Up Consultation, etc.).
* **Overall Satisfaction with Consultation** (`overall_satisfaction`, select_one, Required): Select your overall satisfaction with the consultation (e.g., Very Satisfied, Satisfied, Neutral, Dissatisfied, Very Dissatisfied).
* **Consultant Knowledge and Expertise** (`consultant_knowledge`, select_one, Required): Select how knowledgeable the consultant was (e.g., Excellent, Very Good, Good, Fair, Poor).
* **Consultant Professionalism** (`consultant_professionalism`, select_one, Required): Select the consultant's professionalism (e.g., Excellent, Very Good, Good, Fair, Poor).
* **Clarity of Communication** (`communication_clarity`, select_one, Required): Select how clear the consultant's explanation was (e.g., Excellent, Very Good, Good, Fair, Poor).
* **Time Spent During Consultation** (`time_spent`, select_one, Required): Select if the consultation time was adequate (e.g., More Than Enough, Adequate, Too Rushed, Too Long).
* **Were All Your Questions Addressed?** (`questions_addressed`, select_one, Required): Select if all your questions were answered (e.g., Yes, All Questions Answered, Most Questions Answered, Some Questions Answered, No Questions Answered).
* **Quality of Information Provided** (`information_provided`, select_one, Required): Select the usefulness of the information provided (e.g., Very Helpful, Helpful, Neutral, Not Very Helpful, Not Helpful at All).
* **Wait Time Before Consultation** (`wait_time`, select_one, Required): Select the time you waited before the consultation (e.g., No Wait, Under 10 Minutes, 10-20 Minutes, 20-30 Minutes, Over 30 Minutes).
* **Satisfaction with Wait Time** (`wait_time_satisfaction`, select_one, Required): Select if the wait time was acceptable (e.g., Very Satisfied, Satisfied, Neutral, Dissatisfied, Very Dissatisfied).
* **Comfort of Facility** (`facility_comfort`, select_one, Required): Select the comfort of our facility (e.g., Excellent, Very Good, Good, Fair, Poor).
* **Ease of Scheduling Appointment** (`scheduling_ease`, select_one, Required): Select how easy it was to schedule your appointment (e.g., Very Easy, Easy, Neutral, Difficult, Very Difficult).
* **Value for Time Invested** (`value_for_time`, select_one, Required): Select the value of your time invested (e.g., Excellent Value, Good Value, Fair Value, Poor Value, Very Poor Value).
* **How Likely Are You to Return?** (`likely_to_return`, select_one, Required): Select how likely you are to return to us (e.g., Very Likely, Likely, Neutral, Unlikely, Very Unlikely).
* **How Likely Are You to Recommend Us?** (`recommend_to_others`, select_one, Required): Select how likely you are to recommend us to others (e.g., Very Likely, Likely, Neutral, Unlikely, Very Unlikely).
* **What Could We Improve?** (`improvement_areas`, select_multiple, Required): Select all areas where we can improve (e.g., Wait Times, Communication, Consultant Knowledge, Facility Comfort, Scheduling Process, Follow-Up, Pricing Information, Nothing - All Good, Other).
* **Additional Comments** (`additional_comments`, text, Optional): Provide any additional feedback or comments.
* **May We Contact You for Follow-Up?** (`follow_up_permission`, select_one, Required): Select if we can contact you for follow-up (e.g., True, False).
* **Poll Completion Date** (`poll_completion_date`, date, Required): Enter the date of completing this poll.
