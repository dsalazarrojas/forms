# Animal Welfare Reporting Tool Usability Survey - Help Guide

## Purpose
This form is designed to gather feedback from users on the usability and performance of the Animal Welfare Reporting Tool. It will help us understand how users interact with the tool, identify areas of improvement, and implement changes to enhance their overall experience.

## How To Complete This Form
To complete this form, follow these steps:

1. Answer each question honestly, providing as much detail as possible.
2. Choose the correct answer for each multiple-choice question.
3. Enter your text responses in the designated fields.

## Field-by-Field Explanation

* **Reporting Tool Name or Version** (`reporting_tool_name_version`, text, required):
    * Enter the name of the Animal Welfare Reporting Tool you are using or the version you are currently using.
* **Frequency of Tool Use** (`usage_frequency_rating`, select_one, required):
    + Choose how often you use the Animal Welfare Reporting Tool:
        - **Daily**: You use the tool every day.
        - **Weekly**: You use the tool once a week.
        - **Monthly**: You use the tool less than once a week.
        - **Once or occasionally**: You use the tool very rarely.
* **Ease of Navigation** (`navigation_ease_rating`, select_one, required):
    + Choose how easy or difficult it is to find what you need in the tool:
        - **Very Easy**: The tool is very easy to navigate.
        - **Easy**: The tool is easy to navigate.
        - **Neutral**: The tool is neither easy nor difficult to navigate.
        - **Difficult**: The tool is difficult to navigate.
        - **Very Difficult**: The tool is very difficult to navigate.
* **Clarity of Field Labels and Instructions** (`label_clarity_rating`, select_one, required):
    + Choose how clear or unclear the field labels and instructions are:
        - **Very Clear**: The field labels and instructions are very clear.
        - **Clear**: The field labels and instructions are clear.
        - **Somewhat Clear**: The field labels and instructions are somewhat clear.
        - **Unclear**: The field labels and instructions are unclear.
* **Average Time to Complete a Single Report** (`completion_time_est`, text, required):
    + Enter the average time it takes you to complete a single report in the tool.
* **Experience with Technical Glitches or Bugs** (`technical_glitch_freq`, select_one, required):
    + Choose how often you experience technical glitches or bugs in the tool:
        - **Never**: You have never experienced technical glitches or bugs.
        - **Rarely**: You rarely experience technical glitches or bugs.
        - **Sometimes**: You sometimes experience technical glitches or bugs.
        - **Often**: You frequently experience technical glitches or bugs.
* **Usefulness of Search and Filter Features** (`search_feature_utility`, select_one, required):
    + Choose how useful the search and filter features are:
        - **Very Useful**: The search and filter features are very useful.
        - **Useful**: The search and filter features are useful.
        - **Neutral**: The search and filter features are neither useful nor not useful.
        - **Not Useful**: The search and filter features are not useful.
        - **Feature not found**: You have not found the search and filter feature.
* **Mobile Accessibility Performance** (`mobile_access_rating`, select_one, required):
    + Choose how well the tool performs on mobile devices:
        - **Excellent - Works great on phones**: The tool performs very well on mobile devices.
        - **Good - Functional but slow**: The tool performs well on mobile devices but is slow.
        - **Poor - Difficult to use**: The tool performs poorly on mobile devices.
        - **Not used on mobile devices**: You do not use the tool on mobile devices.
* **Feature You Use Most Frequently** (`primary_feature_used`, text, required):
    + Enter the feature in the tool that you use most frequently.
* **One Change to Improve Usability** (`improvement_usability_suggestion`, text, optional):
    + If you have any suggestions to improve the usability of the tool, enter them here.
