# Research Symposium Theme Poll - Help Guide
## Purpose
This form is designed to help the organizers of the research symposium gather feedback and information on the theme of the event.

## How To Complete This Form
To complete this form, simply follow these steps:

1. Read through the form carefully and make sure you understand what each field is asking for.
2. Fill in the relevant information for each field, making sure to provide as much detail as you can.
3. Submit your answers when you're finished.

## Field-by-Field Explanation

* **Introduction**: This is a brief introduction to the theme of the event. Please provide a short paragraph describing the theme.
* **Describe the theme**: This is a text field where you can elaborate on the theme in as much detail as you'd like.
* **Theme name**: This is where you can enter a name for the theme.
* **Theme keywords**: Enter any relevant keywords that you think best describe the theme.
* **Theme description**: This is another text field where you can further elaborate on the theme.
* **Theme image**: If you have an image that you'd like to associate with the theme, enter the URL or upload the image file.
* **Theme color**: Enter the color you think best represents the theme.
* **Theme background**: Enter a brief description of the background of the theme.
* **Theme font**: Enter a name of a font that you think is suitable for the theme.
* **Theme size**: Select "Yes" if the theme is a large-scale event or "No" if it's a small-scale event.
* **Theme location**: Choose the location(s) where the event will take place from the list provided.
* **Theme date**: Enter the date of the event.
* **Theme time**: Enter the time of the event.
* **Theme email**: Enter the email address associated with the theme.
* **Theme phone**: Enter the phone number associated with the theme.
* **Theme website**: Enter the website URL associated with the theme.
* **Theme facebook**: Enter the Facebook URL associated with the theme.
* **Theme instagram**: Enter the Instagram URL associated with the theme.
* **Theme twitter**: Enter the Twitter URL associated with the theme.
* **Theme youtube**: Enter the YouTube URL associated with the theme.
* **Theme linkedin**: Enter the LinkedIn URL associated with the theme.
* **Theme other**: Enter any other relevant information about the theme that doesn't fit into the other categories.

Note: Fields marked as required (e.g. "Theme location") are mandatory, while those not marked as required are optional.
