# menu_sequence_survey - Help Guide
## Purpose
The menu sequence survey form is used to gather feedback on the sequence of menu items in a specific menu. This feedback is used to improve the menu's layout and content.

## How To Complete This Form
1. Read each page carefully and respond to the questions accordingly.
2. Select the menu items you would like to see in your preferred sequence.
3. Answer the sequence comments questions to provide more detailed feedback.

## Field-by-Field Explanation
* **menu_items**: Choose the menu items you would like to see in your preferred sequence.
  * This field allows you to select multiple menu items that you would like to have in your preferred sequence.
  * Please select 'Yes' for each item you want to see in your sequence.
* **preferred_sequence**: Choose the sequence of menu items you prefer.
  * This field allows you to select one menu item that is most important to you in the current sequence.
  * Please select 'Yes' for the item that you prefer the most.
* **sequence_comments**: Provide any additional comments about the sequence of menu items.
  * This field allows you to provide more detailed feedback about the menu item sequence.
  * Please provide any additional comments you have about the menu items.
* **menu_item_1** to **menu_item_10**, **menu_item_11**, and **menu_item_12**: Choose the menu items you would like to see in your preferred sequence.
  * These fields allow you to select multiple menu items that you would like to have in your preferred sequence.
  * Please select 'Yes' for each item you want to see in your sequence.
* **sequence_comments_1** to **sequence_comments_4**: Provide any additional comments about the sequence of menu items.
  * These fields allow you to provide more detailed feedback about the menu item sequence.
  * Please provide any additional comments you have about the menu items.
* **preferred_sequence_1** to **preferred_sequence_6**: Choose the sequence of menu items you prefer.
  * These fields allow you to select one menu item that is most important to you in the current sequence.
  * Please select 'Yes' for the item that you prefer the most.

## Tips
* Please answer each question carefully and honestly.
* If you have any additional comments or suggestions, please provide them in the sequence comments fields.
