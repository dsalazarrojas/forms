# Reminder Setup Survey - Help Guide
## Purpose
This form collects information about your reminder setup preferences.

## How To Complete This Form
To complete this form, please follow these steps:

1. Select the preferred method of notification (email, phone, or text) under "Notification Method".
2. Choose how often you would like to receive reminders under "Frequency".
3. If you have a specific start date when you would like to start receiving reminders, select that date under "Start Date".
4. If you have a specific end date when you would like to stop receiving reminders, select that date under "End Date".
5. If you have a message you would like to display on each reminder, you can type it in under "Reminder Message".
6. If you have any additional notes about your reminders, you can type them in under "Reminder Note".

## Field-by-Field Explanation
* **Client Preferences** (client_preferences, text, required: false):
	+ This field is not currently used for any specific functionality in this version of the form, so please ignore it.
* **Notification Method** (notification_method, select_one, required: false):
	+ Select how you would like to receive reminders (email, phone, or text).
* **Reminder Time** (reminder_time, time, required: false):
	+ This field is currently not used in this version of the form.
* **Start Date** (start_date, date, required: false):
	+ If you want to start receiving reminders on a specific date, select that date.
* **End Date** (end_date, date, required: false):
	+ If you want to stop receiving reminders on a specific date, select that date.
* **Frequency** (frequency, select_multiple, required: false):
	+ Choose how often you would like to receive reminders (daily, weekly, or monthly).
* **Notification Frequency** (notification_frequency, select_one, required: false):
	+ Select how often you would like to receive notifications (never, every day, every week, or every month).
* **Reminder Message** (reminder_message, text, required: false):
	+ If you have a specific message you want to display on each reminder, type it in here.
* **Reminder Note** (reminder_note, note, required: false):
	+ If you have any additional notes about your reminders, type them in here.

Note: The fields marked as required: false are not required to be filled out, but providing information in them will help tailor the reminder system to your preferences.
