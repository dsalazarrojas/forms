# venue_rental_experience_questionnaire - Help Guide
## Purpose
The purpose of this form is to gather feedback on the rental experience of a venue.

## How To Complete This Form
To complete this form, please follow the instructions below:

1. Select the type of event that you attended (e.g., Wedding, Corporate event, Birthday party, or Other).
2. Enter the date of the event.
3. Select the start and end times of the event (optional).
4. Enter the number of guests who attended the event.
5. Provide any additional event details if needed.
6. Rate your overall experience (e.g., Very poor, Poor, Neutral, Good, or Excellent).
7. If you have any suggestions for improvement, please provide them.
8. If you would like to share any additional comments or information about your experience, please enter them in the "Comments" field.

## Field-by-Field Explanation

* **Event Type**: This field asks you to select the type of event that you attended (e.g., Wedding, Corporate event, Birthday party, or Other). Please choose the option that best describes your event.
* **Date**: This field is where you enter the date of the event. Please use the date format dd/mm/yyyy (e.g., 01/01/2022).
* **Event Start Time**: This field is where you enter the start time of the event (optional). If the start time is not required, you can leave this field blank.
* **Event End Time**: This field is where you enter the end time of the event (optional). If the end time is not required, you can leave this field blank.
* **Number of Guests**: This field asks you to enter the number of guests who attended the event. Please enter a whole number (e.g., 5, 10, 20).
* **Event Details**: This field is where you can provide any additional information about the event (e.g., event description, number of attendees, etc.).
* **Overall Experience**: This field asks you to rate your overall experience (e.g., Very poor, Poor, Neutral, Good, or Excellent). Please choose the option that best describes your experience.
* **Suggestions**: This field is where you can provide any suggestions for improvement for the venue.
* **Comments**: This field is where you can enter any additional comments or information about your experience.
