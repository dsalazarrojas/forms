# Conference Experience Feedback Form - Help Guide
## Purpose
This form is designed to gather feedback from attendees of a conference, allowing them to rate their experience in various aspects such as overall satisfaction, session quality, logistics, and networking opportunities. The feedback will help the conference organizers to improve future events.

## How To Complete This Form
To complete this form, please read each field carefully and provide your honest feedback. If you have any issues or questions, do not hesitate to contact us at form@gic.mx.

## Field-by-Field Explanation

* **Attendee name** (`attendee_name`, text, Optional): Enter your name as you would like it to be displayed in the feedback report.
* **Email address** (`email`, email, For follow up if requested): If you would like to receive follow-up about your feedback, please enter a valid email address here.
* **Overall satisfaction rating** (`overall_satisfaction`, select_one, Rate your overall conference experience): Rate your overall conference experience using the following options:
	+ Excellent
	+ Good
	+ Fair
	+ Poor
* **Session quality rating** (`session_quality`, select_one, Quality of sessions and speakers): Rate the quality of sessions and speakers using the following options:
	+ Excellent
	+ Good
	+ Fair
	+ Poor
* **Logistics and organization rating** (`logistics`, select_one, Venue, signage, and registration): Rate the venue, signage, and registration using the following options:
	+ Excellent
	+ Good
	+ Fair
	+ Poor
* **Networking opportunities rating** (`networking_opportunities`, select_one, Value of networking available): Rate the value of networking opportunities using the following options:
	+ Excellent
	+ Good
	+ Fair
	+ Poor
* **Accessibility and inclusion** (`accessibility`, select_one, How accessible was the conference): Rate how accessible the conference was using the following options:
	+ Excellent
	+ Good
	+ Fair
	+ Poor
* **Highlights or favorite moments** (`highlights`, text, What stood out for you): Share any moments or sessions that stood out for you.
* **Areas for improvement** (`improvement_areas`, text, Suggestions to improve future events): Suggest any areas that you think need improvement for future events.
* **Likelihood to attend again** (`likelihood_to_return`, select_one, Would you attend this conference again): Rate your likelihood to attend this conference again using the following options:
	+ Very likely
	+ Likely
	+ Unlikely
	+ Very unlikely
