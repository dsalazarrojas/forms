# Games Attendance Feedback Survey - Help Guide
## Purpose
This form is designed to collect feedback from game attendees about their experience at a game event. Your input will help us improve future events.

## How To Complete This Form
1. Select the relevant information for each field.
2. Fill out the form completely, as it will take less time to complete it now than to do so later.
3. Click the "Submit" button to send your feedback.

## Field-by-Field Explanation
* **Event Date** (`event_date`, required: false): Enter the date you attended the game event. This helps us track attendance over time.
* **Game Title** (`game_title`, required: false): Enter the title of the game you attended.
* **Game Attendee Rating** (`game_attendee_rating`, required: false): Select your rating of the game (1/5, 2/5, 3/5, 4/5, 5/5).
* **What did you think about the event?** (`feedback_question_1`, required: false): Select how you felt about the event (Great, Good, Okay, Bad, Did not attend).
* **Were there any issues that prevented you from fully enjoying the event?** (`feedback_question_2`, required: false): Select the issues that prevented you from fully enjoying the event (Yes, No).
* **Event Organizer** (`event_organizer`, required: false): Select whether the event was organized by a professional (Yes, No).
* **Event Location** (`event_location`, required: false): Select the location of the event (On-site, Off-site).
* **Event Organizer's Name** (`event_organizer's_name`, required: false): Select whether the event's organizer had a name (Yes, No).
* **Contact Name** (`contact_name`, required: false): Enter the name of the person to contact for further questions.
* **Contact Email** (`contact_email`, required: false): Enter the email address of the person to contact for further questions.
* **Event Date 2** (`event_date2`, required: false): Enter the date of the next event, if known.
* **Event Time** (`event_time`, required: false): Enter the time of the next event, if known.
* **Event Duration** (`event_duration`, required: false): Enter the duration of the event in minutes.
* **Event Organizer 2** (`event_organizer2`, required: false): Select whether the event was organized by a professional (Yes, No).
* **Event Organizer 3** (`event_organizer3`, required: false): Select multiple event organizers (Yes, No).
* **Game Type** (`game_type`, required: false): Select the type of game (Yes, No).
* **What did you think about the game?** (`feedback_question_1`, required: false): Select your thoughts about the game (Yes, No).
* **Were there any rules or regulations that prevented you from fully enjoying the game?** (`feedback_question_2`, required: false): Select the rules or regulations that prevented enjoyment (Yes, No).
* **Number of Games Attended** (`game_attendee_number`, required: false): Enter the number of games attended.
* **Game Organizer** (`game_organizer`, required: false): Select the game organizer (Yes, No).
* **Game Organizer 3** (`game_organizer3`, required: false): Select multiple game organizers (Yes, No).
* **Game Organizer 4** (`game_organizer4`, required: false): Select the game organizer (Yes, No).
* **Event Organizer 5** (`event_organizer5`, required: false): Select the event organizer (Yes, No).
* **Event Organizer 6** (`event_organizer6`, required: false): Select multiple event organizers (Yes, No).
* **Game Organizer** (`game_organizer`, required: false): Select the game organizer (Yes, No).

## Tips
* Please answer all questions truthfully to provide valuable feedback.
* If you're unsure about any of the questions, please select "No" or the most appropriate answer.
* If you have any additional comments or suggestions, please enter them in the "Contact Name" and "Contact Email" fields.
* Submit your feedback to help us improve future events!
