# multi-stakeholder-feedback-survey - Help Guide
## Purpose
This form is designed to collect feedback on project management and communication from project team members, managers, and other stakeholders. Your input will help us identify areas of improvement and make our projects better.
## How To Complete This Form
1. Review each field carefully and answer all questions truthfully.
2. Select the correct options for each field.
3. Enter your email address and phone number (if applicable).
4. Add any additional comments or feedback.

## Field-by-Field Explanation
* **Project Team** (`project_team`, `select_one`, optional): Select one of the following options: Team members, Team leader, or Other.
* **Project Manager** (`project_manager`, `text`, optional): Enter the name of the project manager.
* **Project Coordinator** (`project_coordinator`, `text`, optional): Enter the name of the project coordinator.
* **Project Stakeholder Group 1** (`project_stakeholder_group_1`, `select_one`, optional): Select Yes or No.
* **Project Stakeholder Group 2** (`project_stakeholder_group_2`, `select_multiple`, optional): Select all that apply: Yes or No.
* **Project Stakeholder Group 3** (`project_stakeholder_group_3`, `select_multiple`, optional): Select all that apply: Yes or No.
* **Feedback on project management** (`feedback_on_project_management`, `text`, optional): Enter any comments or feedback on project management.
* **Feedback on project management communication** (`feedback_on_project_management_communication`, `select_one`, optional): Select Yes or No.
* **Feedback On Project Management Communication 2** (`feedback_on_project_management_communication_2`, `text`, optional): Enter any additional comments on project management communication.
* **Feedback on project progress** (`feedback_on_project_progress`, `text`, optional): Enter any comments or feedback on project progress.
* **Overall satisfaction** (`overall_satisfaction`, `select_one`, optional): Select Satisfied or Dissatisfied.
* **Overall Satisfaction Communication** (`overall_satisfaction_communication`, `text`, optional): Enter any comments on overall satisfaction communication.
* **Overall Satisfaction Communication 2** (`overall_satisfaction_communication_2`, `text`, optional): Enter any additional comments on overall satisfaction communication.
* **Additional comments** (`comments`, `note`, optional): Enter any additional comments or feedback.
* **E-mail** (`email`, `email`, optional): Enter your email address.
* **Phone** (`phone`, `text`, optional): Enter your phone number.
* **Name** (`name`, `text`, optional): Enter your name.
* **Project issues** (`project_issues`, `text`, optional): Enter any project issues you're experiencing.
* **Date** (`date`, `date`, optional): Select the date.
* **Time** (`time`, `time`, optional): Select the time.
* **Feedback on Project** (`feedback_on_project`, `note`, optional): Enter any additional comments or feedback on the project.
* **Project Issues 2** (`project_issues_2`, `text`, optional): Enter any project issues you're experiencing.
* **Additional comments (2)** (`additional_comments`, `note`, optional): Enter any additional comments or feedback.
* **Stakeholder Prophets** (`stakeholder_group_1`, `text`, optional): Enter the name of the stakeholder.
* **Stakeholder** (`stakeholder`, `text`, optional): Enter the name of the stakeholder.

Note: This form has multiple fields that ask for the same type of information, such as additional comments or feedback. Please ensure that you're providing new and relevant information for each field.
