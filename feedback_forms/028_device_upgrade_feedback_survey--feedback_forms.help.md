# Device Upgrade Feedback Survey - Help Guide

## Purpose
This form is designed to collect feedback from users about their device upgrade experience. It helps us understand what users think about our device upgrades and how we can improve.

## How To Complete This Form
To complete this form, follow these steps:

1. Go to the "User Input Page" and fill out the "E-Mail" field if you'd like to be contacted about your feedback. This is optional.
2. Go to the "Rating and Comment Page" and select a rating that best describes your satisfaction with the device upgrade.
   - Select "1 - Not Satisfied" if you were not satisfied with the upgrade.
   - Select "2 - Satisfied" if you were satisfied with the upgrade.
   - Select "3 - Very Satisfied" if you were very satisfied with the upgrade.
3. If you'd like to add more detail to your feedback, type it in the "Comment" field.

## Field-by-Field Explanation
### **E-Mail** (optional)
The E-Mail field allows you to provide a valid email address so that we can contact you about your feedback.

### **Rating**
Choose a rating that best describes your satisfaction with the device upgrade:
  - **1 - Not Satisfied**: You were not satisfied with the device upgrade.
  - **2 - Satisfied**: You were satisfied with the device upgrade.
  - **3 - Very Satisfied**: You were very satisfied with the device upgrade.

### **Comment** (optional)
Provide more detail about your experience with the device upgrade if you'd like to share. This is an optional field and you can leave it blank if you're done with the survey.
