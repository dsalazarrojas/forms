# Livestock Vaccination Program Feedback Survey - Help Guide
## Purpose
The Livestock Vaccination Program Feedback Survey is designed to gather feedback from participants on their experience with the program. This survey aims to understand how participants found out about the program, how they received the services, what topics were covered, and what they found helpful or not.

## How To Complete This Form
To complete this form, please follow these steps:

1. Read each question carefully and answer them as accurately as possible.
2. Use the available options for select fields, such as select_one and select_multiple.
3. Provide as much detail as possible in text fields, such as how_did_you_get_vaccination_services and how_did_we_do.
4. Do not repeat information that is already provided in previous questions.
5. Make sure to fill in all required fields.

## Field-by-Field Explanation

* **Introduction**:
	+ This is a note field where you can enter any introduction or background information about your experience with the Livestock Vaccination Program.
* **How did you find out about vaccination?**:
	+ Please select one of the options or describe in detail how you found out about the program.
* **How did you get vaccination services?**:
	+ Please describe in detail how you received the vaccination services.
* **What did vaccination cover?**:
	+ Select multiple options that apply to your experience.
* **How did vaccination cover work?**:
	+ Please describe in detail how the vaccination services worked.
* **What did you find helpful?**:
	+ Please select one option that best describes what you found most helpful.
* **What did you not find helpful?**:
	+ Please select multiple options that apply to your experience.
* **Additional comments**:
	+ Please enter any additional comments or thoughts about your experience with the program.
* **How did we do?**:
	+ Please describe in detail how the program was delivered.
* **What did we cover?**:
	+ Select one option that best describes what you think was covered in the program.
* **What is the current level?**:
	+ Please enter a numerical value for the level of coverage.
* **What is the goal?**:
	+ Please enter a text description of the goal of the program.
* **How much time?**:
	+ Please enter a numerical value for the amount of time spent on the program.
* **Time of Day**:
	+ Please select the time of day you were vaccinated.
* **Day of Week**:
	+ Please select the day of the week you were vaccinated.
* **Date**:
	+ Please select the date you were vaccinated.
* **What was the weather?**:
	+ Please select the weather conditions on the day of vaccination.
* **Contact Name**:
	+ Please enter your name for contact purposes.
* **Contact Phone**:
	+ Please enter your phone number for contact purposes.
* **Contact Email**:
	+ Please enter your email address for contact purposes.
* **Contact Other**:
	+ Please enter any additional contact information.
* **What did you mean?**:
	+ Please enter any final thoughts or comments about your experience.
* **Additional Comments 2**:
	+ Please enter any additional comments or thoughts about your experience.
* **Contact Phone 2**:
