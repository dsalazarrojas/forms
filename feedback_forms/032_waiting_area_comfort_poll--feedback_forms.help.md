# Waiting Area Comfort Poll - Help Guide
## Purpose
This form is designed to gather feedback from visitors about their experience in the waiting area. It helps us understand what we're doing well and what we can improve to make your visit more pleasant.

## How To Complete This Form
1. Select the options that best describe your experience in the waiting area.
2. Provide any additional comments about your visit.
3. Enter your name and email address so we can follow up with you, if needed.
4. Enter your phone number, if you'd like to be contacted by phone.

## Field-by-Field Explanation
* **Waiting Area Comfort** (`waiting_area_comfort_poll_form`, select_multiple, required: false):
	+ Select all that apply to describe your experience in the waiting area. You can choose from "Yes" or "No" for each option.
* **Satisfaction** (`waiting_area_satisfaction`, select_one, required: false):
	+ Select how satisfied you are with your experience.
* **Improvement** (`waiting_area_improvement`, select_multiple, required: false):
	+ Select all that apply to describe areas for improvement in the waiting area. You can choose from "Yes" or "No" for each option.
* **Comments** (`waiting_area_comments`, text, required: false):
	+ Add any additional comments or thoughts about your visit.
* **Visitor Name** (`visitor_name`, text, required: false):
	+ Enter your name so we can follow up with you, if needed.
* **Email** (`visitor_email`, email, required: false):
	+ Enter your email address so we can follow up with you, if needed.
* **Phone** (`visitor_phone`, text, required: false):
	+ Enter your phone number, if you'd like to be contacted by phone.
