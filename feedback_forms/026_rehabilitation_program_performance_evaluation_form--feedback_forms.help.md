# Rehabilitation Program Performance Evaluation Form - Help Guide
## Purpose
The Rehabilitation Program Performance Evaluation Form is used to collect feedback on the progress and outcome of a rehabilitation program. This form helps in understanding the effectiveness of the program and identifying areas for improvement.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill out each field accurately and thoroughly.
2. Make sure to save your progress as you move to the next page, in case you need to refer back to a particular field.
3. Review each field carefully before moving to the next page.

## Field-by-Field Explanation
### User ID (1)
* **User ID** (`user_id`, number, required)
  This field is the unique identifier of the user who participated in the program.

### Program Start Date (2)
* **Program Start Date** (`program_start_date`, date, required)
  This is the date when the program started.

### Satisfaction Rating (4)
* **Satisfaction Rating** (`satisfaction_rating`, select_one, required)
  Please select one of the following options:
  + Very Satisfied
  + Somewhat Satisfied
  + Not Satisfied

### Program Name (8)
* **Program Name** (`program_name`, text, required)
  Enter the name of the program.

### Program Type (9)
* **Program Type** (`program_type`, select_one, required)
  Select one of the following options:
  + Inpatient
  + Outpatient
  + Both

### Staff ID (10)
* **Staff ID** (`staff_id`, number, required)
  This is the unique identifier of the staff member who led the program.

### Program End Date (11)
* **Program End Date** (`program_end_date`, date, required)
  This is the date when the program ended.

### Feedback Date (12)
* **Feedback Date** (`feedback_date`, date, required)
  Enter the date when you're giving feedback on the program.

### Patient ID (13)
* **Patient ID** (`patient_id`, number, optional)
  This is the unique identifier of the patient who participated in the program.

### Program Status (14)
* **Program Status** (`program_status`, select_multiple, optional)
  Select one or more of the following options:
  + Active
  + Inactive
  + Completed

### Comments (15)
* **Comments** (`comments`, text, optional)
  Enter any additional comments or feedback about the program.

### Phone (6)
* **Phone** (`phone`, text, optional)
  Enter the phone number.

### Email (7)
* **Email** (`email`, email, optional)
  Enter the email address.

### Feedback (3)
* **Feedback** (`feedback`, text, optional)
  Enter your feedback about the program.

## Tips
* Please make sure to double-check your information before submitting the form.
* If you have any questions or concerns, please contact your supervisor or the program administrator.
