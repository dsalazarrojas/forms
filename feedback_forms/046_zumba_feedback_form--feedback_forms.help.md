# Zumba Feedback Form - Help Guide
## Purpose
This form is used to capture student feedback on a Zumba class, which can help instructors and administrators evaluate and improve the quality of the classes.

## How To Complete This Form
To complete the form, follow these steps:
1. Please provide the class name in the `ClassName` field.
2. Enter the date the class was offered in the `DateOffered` field.
3. Indicate if the class is a type of Zumba class by selecting "Yes" or "No" in the `ClassType` field.
4. Write your feedback on the class in the `StudentFeedback` field.
5. Enter the name of the instructor who taught the class in the `InstructorName` field.
6. Enter the instructor's ID in the `InstructorID` field.

## Field-by-Field Explanation
* **ClassName**: Enter the name of the class that you attended.
* **DateOffered**: Enter the date the class was offered.
* **ClassType**: Indicate if the class was a type of Zumba class by selecting "Yes" or "No".
* **StudentFeedback**: Write your feedback on the class, including any comments or suggestions you have.
* **InstructorName**: Enter the name of the instructor who taught the class.
* **InstructorID**: Enter the instructor's ID number.
* **Feedback**: Provide any additional feedback on the class.
