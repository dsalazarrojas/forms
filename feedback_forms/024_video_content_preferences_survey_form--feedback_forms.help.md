# video_content_preferences_survey_form - Help Guide

## Purpose
The video_content_preferences_survey_form is a tool to collect user preferences for video content. It helps content providers understand user needs and provide better content services.

## How To Complete This Form
To complete this form, follow these steps:
1. Go through each page and input your preferences for the respective questions.
2. Make sure to input your preferences accurately, as it will help us understand your needs better.
3. You can move on to the next page once you have completed the current page.
4. Once you have completed all the pages, click on the "Submit" button to save your preferences.

## Field-by-Field Explanation

### Page 1: survey_title
* **Survey Title** (`survey_title`, text, optional): This is the title of the survey. Please input a descriptive title for this survey.
* **Survey Title 2** (`content_type_2`, select_one, optional): This field is similar to the first "Survey Title" field, and is meant to provide additional information about the content type.
* **Video ID** (`video_id`, number, optional): This field is to input the ID of the video, if applicable.
* **Survey Comments** (`survey_comments`, text, optional): This field is for any additional comments about the survey.

### Page 2: content_type
* **Content Type** (`content_type`, select_one, optional): This field is to select the type of content you prefer (Video, Audio, or Image).
* **Content Type 2** (`content_type_2`, select_one, optional): This field is similar to the first "Content Type" field, and is meant to provide additional information about the content type.

### Page 3: preferred_format
* **Preferred Format** (`preferred_format`, select_multiple, optional): This field is to select the preferred format of the content (mp4, mpg, m4v).
* **Has Video File** (`has_video_file`, select_multiple, optional): This field is to select if you have a video file.
* **Preferred Format 2** (`preferred_format_2`, select_multiple, optional): This field is similar to the first "Preferred Format" field, and is meant to provide additional information about the preferred format.

### Page 4: video_length
* **Video Length** (`video_length`, number, optional): This field is to input the length of the video.
* **Audio Length** (`audio_length`, number, optional): This field is to input the length of the audio content.
* **Video Length 2** (`video_length_2`, number, optional): This field is similar to the first "Video Length" field, and is meant to provide additional information about the video length.

### Page 5: additional_preferences
* **Has Subtitles** (`has_subtitles`, text, optional): This field is to select if the content has subtitles.
* **Is Muted** (`is_muted`, text, optional): This field is to select if the content is muted.
* **Is Looping** (`is_looping`, text, optional): This field is to select if the content is looping.
* **Is Auto Play** (`is_auto_play`, text, optional): This field is to select if the content is auto-playing.
* **Has Audio** (`has_audio`, text, optional): This field is to select if the content has audio.
* **Has Description** (`has_description`, text, optional): This field is to select if the content has a description.
* **Is Translated** (`is_translated`, text, optional): This field is to select if the content is translated.
* **Preferred Language** (`preferred_language`, select_one, optional): This field is to select the preferred language.
* **Preferred Language 2** (`preferred_language_2`, select_one, optional): This field is similar to the first "Preferred Language" field, and is meant to provide additional information about the preferred language.

### Page 6: additional_preferences_2
* **Has Video File 2** (`has_video_file_2`, select_multiple, optional): This field is similar to the first "Has Video File" field, and is meant to provide additional information about having a video file.
* **Is Translated 2** (`is_translated_2`, text, optional): This field is similar to the first "Is Translated" field, and is meant to provide additional information about being translated.
* **Has Description 2** (`has_description_2`, text, optional): This field is similar to the first "Has Description" field, and is meant to provide additional information about having a description.
* **Has Audio 2** (`has_audio_2`, text, optional): This field is similar to the first "Has Audio" field, and is meant to provide additional information about having audio.
* **Is Auto Play 2** (`is_auto_play_2`, text, optional): This field is similar to the first "Is Auto Play" field, and is meant to provide additional information about auto-playing.
* **Is Muted 2** (`is_muted_2`, text, optional): This field is similar to the first "Is Muted" field, and is meant to provide additional information about being muted.
* **Is Looping 2** (`is_looping_2`, text, optional): This field is similar to the first "Is Looping" field, and is meant to provide additional information about looping.
