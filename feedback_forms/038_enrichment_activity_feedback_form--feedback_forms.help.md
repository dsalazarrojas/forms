# Enrichment Activity Feedback Form - Help Guide
## Purpose
The Enrichment Activity Feedback Form is used to collect feedback from participants on enrichment activities. This feedback is used to improve and evaluate the effectiveness of these activities.

## How To Complete This Form
To complete this form, follow the steps above and fill out all fields accordingly. Make sure to answer all required fields (participant_feedback, rating_of_event, date_of_event, and start_time) and provide any additional information in the optional fields.

## Field-by-Field Explanation
### participant_feedback
• Label: participant_feedback
• Type: text
• Required: true
• Explain: This field is for you to provide any general feedback on the enrichment activity you participated in.

### rating_of_event
• Label: rating_of_event
• Type: number
• Required: true
• Explain: Rate your experience with the enrichment activity on a scale of 1-5, where 1 is poor and 5 is excellent.

### suggestions_for_improvement
• Label: suggestions_for_improvement
• Type: text
• Required: false
• Explain: If you have any suggestions for improving the enrichment activity, please provide them here.

### educator_feedback
• Label: educator_feedback
• Type: text
• Required: false
• Explain: Provide any feedback you have for the educator or activity leader.

### participant_feedback
• Label: participant_feedback
• Type: text
• Required: false
• Explain: If you have any further feedback for other participants, please share it here.

### date_of_event
• Label: date_of_event
• Type: date
• Required: true
• Explain: Enter the date of the enrichment activity you participated in.

### start_time
• Label: start_time
• Type: time
• Required: true
• Explain: Enter the start time of the enrichment activity.

### assigned
• Label: assigned_to
• Type: select_one
• Required: true
• Explain: Choose whether the enrichment activity was assigned to you or not.

### email
• Label: email
• Type: email
• Required: false
• Explain: Enter your email for any additional contact information.

### phone
• Label: phone
• Type: text
• Required: false
• Explain: Enter your phone number for any additional contact information.

## Tips
- Be honest and accurate in your feedback.
- Please fill out all required fields.
- If you have any questions or concerns, contact us.
