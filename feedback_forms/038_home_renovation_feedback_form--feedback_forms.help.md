# Home Renovation Feedback Form - Help Guide

## Purpose
This form is designed to collect feedback from customers about their home renovation projects. Please take a few minutes to fill out this form and provide as much detail as possible to help us improve our services.

## How To Complete This Form
To complete this form, simply fill out the required fields, which are marked with an asterisk (\*) in the label. Here's a brief explanation of each field:

## Field-by-Field Explanation

* **Renovation Project** (`renovation_project`, text, *): Please provide a brief description of your home renovation project, including the type of project (e.g., kitchen renovation, bathroom renovation, etc.)
* **Project Budget** (`project_budget`, number, *): Please enter the total budget for your project, including any relevant details.
* **Project Location** (`project_location`, text, *): Please enter the location where the project is taking place (e.g., city, state, country).
* **Contact Method** (`contact_method`, select_one, *): Please select one of the following contact methods:
	+ **Minimalist**: This method is best for brief, non-urgent messages.
	+ **Traditional**: This method is best for more detailed and personalized feedback.
	+ **Modern**: This method is best for feedback that requires a more immediate response.
* **Contact Person** (`contact_person`, text, *): Please enter your name and a way for us to contact you (e.g., phone number, email address).
* **Project Manager** (`project_manager`, select_multiple, *): Please select all applicable project managers involved in your project.
* **Contact Phone** (`contact_phone`, text, *): Please enter your phone number so we can reach you for any further communication.
* **Email Address** (`email_address`, email, *): Please enter your email address so we can contact you for any further communication.
* **Goals** (`goals`, note, *): Please provide any specific goals or objectives you have for your project.
* **Comments** (`comments`, text, optional): If you have any additional comments or feedback, please include them here.
* **Feedback** (`feedback`, text, *): If you have any feedback about our services, please provide it here.

Tips: Please be as specific as possible when answering the questions, and provide as much detail as you can to help us improve our services. If you have any questions or concerns, feel free to ask.
