# respect_message_submission_form - Help Guide
## Purpose
The `respect_message_submission_form` is designed to collect feedback and messages from users, providing valuable input on various topics.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the required fields, marked with an asterisk (\*). These fields are:
	* Message
	* Name (if you want to be contacted)
	* Email (if you want to be contacted)
	* Type of Message
	* Message For (Team, Department, or Individual)
	* Submit
2. For the remaining fields, provide any additional information you'd like to share. These fields are:
	* Recognition (if applicable)
	* Feedback (if applicable)
	* Message Details (optional)
	* Message Details 2, 3, 4, 5, and 6 (optional)
	* Contact Details (if you want to be contacted)
	* Follow Up (if applicable)
3. Select the appropriate type of message you're providing:
	* Message
	* Recognition
	* Feedback
4. Submit your completed form by clicking the "Submit" button.

## Field-by-Field Explanation
* **Message**: A text field where you can provide your message or feedback. This is a required field.
* **Name**: A text field where you can provide your name if you want to be contacted. This field is optional.
* **Email**: A text field where you can provide your email if you want to be contacted. This field is optional.
* **Recognition**: A text field where you can provide recognition or feedback, if applicable. This field is optional.
* **Feedback**: A text field where you can provide feedback. This field is required.
* **Type of Message**: A dropdown menu where you can select the type of message you're providing. Options are:
	+ Message
	+ Recognition
	+ Feedback
* **Message For**: A multi-select field where you can choose who the message is for. Options are:
	+ Team
	+ Department
	+ Individual
* **Submit**: A button to submit your completed form. This field is required.
* **Message Details**: A text field where you can provide additional message details. This field is optional.
* **Message Details 2, 3, 4, 5, and 6**: Additional text fields where you can provide more message details. These fields are optional.
* **Contact Details**: A text field where you can provide your contact details if you want to be contacted. This field is optional.
* **Follow Up**: A multi-select field where you can choose whether to follow up on your message. Options are:
	+ True
	+ False
* **Type of Message 2, 3, 4, 5, 6, 7, 8, 9, 10**: Additional dropdown menus where you can select the type of message you're providing. Options are the same as the "Type of Message" field.
* **Message Details 2, 3, 4, 5**: Additional text fields where you can provide more message details. These fields are optional.
