# Saddle Bench Feedback Survey - Help Guide
## Purpose
This form is designed to collect feedback on the Saddle Bench experience. It aims to understand how users feel about the Saddle Bench, whether they are satisfied with it, how comfortable they are using it, and if they have any suggestions for improvement. The data collected will be used to refine and improve the Saddle Bench.

## How To Complete This Form
1. Please select one of the options for each question to indicate your level of satisfaction, comfort, or preference.
2. If you have any feedback or improvement ideas, type them in the text box provided.
3. If you have contact details you'd like to share, select 'True' for "Do you have contact details to share?" and input your email or phone number in the corresponding fields.
4. Please answer the last question, "Do you have any other feedback?" and type your comments in the text box provided.

## Field-by-Field Explanation

* **How Satisfied Are You with Saddle Bench?** (`how_satisfied_with_saddle_bench`, `select_one`, not required): This question asks about your overall satisfaction with the Saddle Bench. Select one of the options: very satisfied, satisfied, neutral, dissatisfied, or very dissatisfied.
* **How Comfortable Is Saddle Bench?** (`comfort_rating`, `select_one`, not required): This question assesses your comfort level while using the Saddle Bench. Choose from: very comfortable, somewhat comfortable, neutral, somewhat uncomfortable, or very uncomfortable.
* **Any Improvement Ideas?** (`improvement_ideas`, `text`, not required): If you have any ideas on how to improve the Saddle Bench, please type them in here.
* **Do You Have Contact Details to Share?** (`contact_details`, `select_one`, not required): If you have contact information you'd like to share with us, select 'True' and we'll get in touch with you.
* **Other Feedback?** (`feedback`, `text`, not required): If you have any other comments or feedback about the Saddle Bench, please type them in here.
* **Email** (`contact_email`, `email`, not required): If you'd like to share your email address, input it here.
* **Phone** (`contact_phone`, `text`, not required): If you'd like to share your phone number, input it here.
* **Additional Contact Info** (`contact_additional`, `text`, not required): If you have any other contact information, please type it in here.
