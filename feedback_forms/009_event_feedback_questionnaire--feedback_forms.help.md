# Event Feedback Questionnaire - Help Guide
## Purpose
The Event Feedback Questionnaire is a tool for collecting feedback from event attendees. Its main goal is to gather information about the event experience.

## How To Complete This Form
To complete this form, follow these steps:
1. Provide the name of the event you attended.
2. Enter your name as the attendee.
3. Write down your feedback about the event.
4. Enter the date the event took place.
5. Enter the start time of the event.
6. Enter the end time of the event.
7. Enter the location of the event.

## Field-by-Field Explanation
* **Event Name** (`event_name`, `text`, optional): Enter the name of the event you attended.
* **Attendee Name** (`attendee_name`, `text`, optional): Enter your name, the person who attended the event.
* **Feedback** (`feedback`, `text`, optional): Share your thoughts and opinions about the event.
* **Event Date** (`event_date`, `date`, optional): Enter the date the event took place.
* **Event Time** (`event_time`, `time`, optional): Enter the time the event occurred.
* **Event Start Time** (`event_start_time`, `time`, optional): Enter the start time of the event.
* **Event End Time** (`event_end_time`, `time`, optional): Enter the end time of the event.
* **Event Location** (`event_location`, `text`, optional): Enter the location where the event took place.

## Tips
- Please answer all questions accurately and honestly.
- Use the format for date and time as specified in your device's regional settings.
- If any field is not applicable to your experience, feel free to skip it.
- If you need help or have questions, contact form administrators.
