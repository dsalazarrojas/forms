# rankings_submission_form - Help Guide
## Purpose
This form is designed to collect rankings and feedback from end-users, helping the organization to better understand user needs and preferences.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the relevant options in the "User Ratings" field to indicate your preferences or opinions.
2. Enter your scores in the "Scores" field, using numbers only.
3. Provide a list of items in the "Ordered List" field, separated by commas.
4. For each item in the "Ordered List", provide additional information in the "Ordered List Item" field.

## Field-by-Field Explanation
* **User Ratings** (`User Ratings`, select_multiple, required/optional): Select one or more options to indicate your preferences or opinions. This field is optional, but it will help the organization better understand your views.
* **Scores** (`Scores`, number, required/optional): Enter a numerical value to represent your scores or ratings. Please use numbers only.
* **Ordered List** (`Ordered List`, text, required/optional): Provide a list of items, separated by commas. For example: "Option 1, Option 2, Option 3"
* **Ordered List Item** (`Ordered List Item`, text, required/optional): Provide additional information for each item in the ordered list. For example: "Option 1: Description 1", "Option 2: Description 2", "Option 3: Description 3"

## Tips
* Please make sure to provide accurate and honest feedback.
* You can only submit the form once, so double-check your entries before submitting.
* If you're unsure about any field, please ask for clarification before submitting.
