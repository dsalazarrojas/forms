# Early Warning System Monitoring Form - Help Guide
## Purpose
The Early Warning System Monitoring Form is designed to gather essential details about the EWS monitoring process, allowing for efficient data collection and analysis.

## How To Complete This Form
1. Fill in the required fields with the relevant information.
2. Select the correct options for the Warning System Type, Monitoring Frequency, and Assigned Tool fields.
3. Enter a brief Description of the issue being monitored.
4. Provide a Contact Email address and Contact Phone number for follow-up communication.
5. Add any additional notes in the Note field, if necessary.

## Field-by-Field Explanation

* **Early Warning System** (<id: 1, <name: early_warning_system_monitoring_form, type: text>): This field is the title of the EWS monitoring process. Enter a brief, descriptive name for the monitoring process.
* **Organization** (<id: 2, <name: organization, type: text>): Enter the name of the organization being monitored.
* **Contact Person** (<id: 3, <name: contact_person, type: text>): Enter the name of the person responsible for this issue.
* **Warning System Type** (<id: 4, <name: warning_system_type, type: select_one>): Select the type of warning system being monitored from the available options (Option 1, Option 2, Option 3).
* **Description** (<id: 5, <name: description, type: text>): Enter a short description of the issue being monitored.
* **Monitoring Frequency** (<id: 6, <name: monitoring_frequency, type: select_multiple>): Select all relevant monitoring frequencies (Option 1, Option 2, Option 3) for this monitoring process.
* **Location** (<id: 7, <name: location, type: text>): Enter the location of the monitored area.
* **Date** (<id: 8, <name: date, type: date>): Enter the date of the monitoring process.
* **Time** (<id: 9, <name: time, type: time>): Enter the time of the monitoring process.
* **Contact Email** (<id: 10, <name: contact_email, type: email>): Enter the email address of the contact person.
* **Contact Phone** (<id: 11, <name: contact_phone, type: text>): Enter the phone number of the contact person.
* **Note** (<id: 12, <name: note, type: note>): Add any additional comments or notes regarding this monitoring process.
* **Assigned Tool** (<id: 13, <name: assigned_tool, type: select_one>): Select the tool assigned to this monitoring process from the available options (Option 1, Option 2, Option 3).
* **Form ID** (<id: 14, <name: form_id, type: text>): Enter any unique identifier for this form submission.
* **Output File** (<id: 15, <name: output_file, type: text>): This field is not currently used; however, if you want to provide a file for the output, please use this field to enter the path to the file. 
Note: This field might be removed or re-enabled in the future, so it is best not to enter any data here unless absolutely necessary.
