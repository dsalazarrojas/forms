# Structural Design Software Feedback - Help Guide
## Purpose
The purpose of this form is to collect feedback from users on the structural design software. Please provide honest and specific feedback on what you think could be improved in the current design, as well as any new features you think would be beneficial to include.

## How To Complete This Form
1. Please fill out the form completely and honestly. 
2. Select the category that best describes the feedback or feature request you have.
3. Be as specific as possible when describing your feedback or feature request.

## Field-by-Field Explanation
* **Structural Design Software Feedback** (`form_title`, `text`, required): This field is for the title of the feedback or feature request. Please provide a brief description of your feedback or feature request.
* **Category** (`form_category`, `select_one`, required): Select the category that best describes the feedback or feature request. This will help us to sort and prioritize your feedback.
* **Description** (`form_description`, `text`, required): This field is for a detailed description of your feedback or feature request. Please be as specific as possible.
* **User Satisfaction** (`form_user_satisfaction`, `select_multiple`, optional): If you want to express your overall satisfaction with the software, select one of the options: Very good, Good, Average, Bad, or Very bad.
* **Improvement Ideas** (`form_improvement_ideas`, `text`, optional): If you have any additional improvement ideas, please describe them here.
* **Feature Requests** (`form_feature_requests`, `text`, optional): If you have any feature requests, describe them here.
* **File Upload** (`form_file_upload`, `text`, optional): If you have any supporting files or documents for your feedback or feature request, please upload them here.
* **Submit** (`form_submit`, `select_one`, required): Click the "Submit" button to send your feedback or feature request.
* **Email** (`form_email`, `text`, optional): If you want to provide your email address for follow-up, please enter it here. This will help us to contact you for further questions or to let you know about any updates.
* **Phone** (`form_phone`, `text`, optional): If you have any phone number, please enter it here. This will help us to contact you if we need to follow-up on your feedback or feature request.
* **Name** (`form_name`, `text`, optional): If you want to provide your name, please enter it here.
* **Comment** (`form_comment`, `text`, optional): If you have any additional comments, please describe them here.
* **Date** (`form_date`, `text`, optional): If you want to provide the date and time of your feedback or feature request, please use the date picker to select the date and time.
* **Time** (`form_time`, `text`, optional): If you want to provide the time of your feedback or feature request, please use the time picker to select the time.
* **Location** (`form_location`, `text`, optional): If you want to provide your location, please enter it here.
* **Ideas** (`form_ideas`, `note`, optional): This field is for additional improvement ideas or feature requests.
* **File** (`form_file`, `text`, optional): If you have any supporting files or documents for your feedback or feature request, please upload them here.
* **User ID** (`form_user_id`, `text`, optional): If you want to provide your user ID, please enter it here.
* **User Group** (`form_user_group`, `text`, optional): If you want to provide your user group, please enter it here.
* **Department** (`form_department`, `text`, optional): If you want to provide your department, please enter it here.
* **Manager** (`form_manager`, `text`, optional): If you want to provide your manager's name, please enter it here.
* **Designer** (`form_designer`, `text`, optional): If you want to provide your designer's name, please enter it here.
* **Project Manager** (`form_project_manager`, `text`, optional): If you want to provide your project manager's name, please enter it here.
* **Project Manager Email** (`form_project_manager_email`, `text`, optional): If you want to provide your project manager's email address, please enter it here.
* **Additional Info** (`form_additional_info`, `text`, optional): If you have any additional information, please describe it here.
