# Function Performance Feedback - Help Guide
## Purpose
This form is used to collect feedback from users about a function's performance. Please provide your honest feedback to help us improve our functions.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the type of function you attended (Training, Meeting, or Company Function).
2. Enter the name of the function you attended.
3. Rate the performance of the function using the scale provided.
4. Rate your satisfaction with the function's performance.
5. If you have any suggestions for improvement, please provide them in the text field.
6. Enter the date and time of the function.
7. Select the venue where the function was held (Online or Offline).
8. List the attendees of the function.
9. Provide any additional feedback you have about the function.

## Field-by-Field Explanation
* **Function Performance** (`function_performance_feedback`, text, required): This field is where you can describe the performance of the function you attended.
* **Event Type** (`event_type`, select_one, required): This field is where you can select the type of function you attended (Training, Meeting, or Company Function).
* **Event Name** (`event_name`, text, required): This field is where you can enter the name of the function you attended.
* **Performance Rating** (`performance_rating`, number, required): This field is where you can rate the performance of the function using the scale provided.
* **Satisfaction** (`satisfaction_rating`, number, required): This field is where you can rate your satisfaction with the function's performance.
* **Suggestion for Improvement** (`suggestion_improvement`, text, required): This field is where you can provide any suggestions you have for improving the function.
* **Date** (`event_date`, date, required): This field is where you can enter the date of the function.
* **Time** (`event_time`, time, required): This field is where you can enter the time of the function.
* **Venue** (`venue`, select_one, required): This field is where you can select the venue where the function was held (Online or Offline).
* **Attendees** (`attendees`, text, required): This field is where you can list the attendees of the function.
* **Feedback** (`feedback`, text, required): This field is where you can provide any additional feedback you have about the function.
