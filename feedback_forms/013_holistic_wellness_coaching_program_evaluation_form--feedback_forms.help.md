# holistic_wellness_coaching_program_evaluation_form - Help Guide
## Purpose
The holistic wellness coaching program evaluation form is designed to gather feedback from program participants, helping providers understand their effectiveness and areas for improvement.

## How To Complete This Form
To complete this form, follow these steps:
1. Enter the coaching program title, which should be a brief description of the program.
2. Describe the program in a few sentences, including its purpose and any relevant details.
3. If applicable, select the program length, which is the duration of the program.
4. Indicate whether the program has a specific format (e.g., online, in-person).
5. If the program has specific focus areas, select the areas that apply.
6. If the program has a secondary set of focus areas, select multiple areas that apply.
7. Describe the program's goals, which are the desired outcomes.
8. Describe the program's outcomes, which are the actual results achieved by participants.
9. Provide any feedback from participants, including suggestions for improvement.

## Field-by-Field Explanation
* **Coaching Program Title** (`coaching_program_title`, text, required: false): Enter the title of the coaching program, a brief description of the program.
* **Coaching Program Description** (`coaching_program_description`, text, required: false): Describe the program in a few sentences, including its purpose and any relevant details.
* **Program Length** (`program_length`, number, required: false): Select the duration of the program.
* **Program Format** (`program_format`, select_multiple, required: false): Indicate whether the program has a specific format (e.g., online, in-person).
* **Coaching Focus Areas** (`coaching_focus_areas`, select_one, required: false): Select the primary focus area of the program.
* **Coaching Focus Areas 2** (`coaching_focus_areas_2`, select_multiple, required: false): Select multiple secondary focus areas of the program.
* **Program Goals** (`program_goals`, text, required: false): Describe the program's goals, which are the desired outcomes.
* **Program Outcomes** (`program_outcomes`, text, required: false): Describe the program's outcomes, which are the actual results achieved by participants.
* **Participant Feedback** (`participant_feedback`, text, required: false): Provide any feedback from participants, including suggestions for improvement.

## Tips
* Ensure that you are using the correct form for your specific needs.
* Be as detailed as possible when describing the program and its goals and outcomes.
* Select the focus areas that accurately reflect the program's content.
* Use this form to provide feedback and suggestions for improvement.
* If you have already submitted an evaluation for this program, please do not submit another evaluation to avoid duplication.
