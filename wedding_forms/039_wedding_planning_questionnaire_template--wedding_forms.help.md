# Wedding Planning Questionnaire Template - Help Guide
## Purpose
This form is designed to gather essential details about a couple's wedding planning, including ceremony and reception information, timelines, and contact details. It will help wedding planners or coordinators understand the couple's needs and preferences for a successful and enjoyable wedding experience.

## How To Complete This Form
To complete this form, follow these steps:

1. Answer all the required questions to the best of your ability.
2. Be as detailed as possible when providing information about the ceremony and reception.
3. Ensure you provide accurate contact information so the wedding planner or coordinator can reach you.
4. If you have any special requests or requirements, mention them in the "Special Requests" field.

## Field-by-Field Explanation
### Wedding Planning Questions
Please answer the following questions to help us plan your special day:
* **Wedding Planning Questions** (`Wedding Planning Questions`, text, not required): Provide a brief description of your wedding plans and any specific details you'd like to include.

### Couple Details
Please select all that apply to describe the couple:
* **Couple Details** (`Yes/No`, select multiple, required): Yes/No, Husband/ Wife/Both/Other.

### Ceremony Details
Please provide the following information:
* **Ceremony Details** (`Ceremony Details`, text, not required): Describe the ceremony details, including the location, time, and any specific requests.

### Reception Details
Please provide the following information:
* **Reception Details** (`Reception Details`, text, not required): Describe the reception details, including the location, time, and any specific requests.

### Photo Gallery
Please provide a brief description of your photo gallery:
* **Photo Gallery** (`Photo Gallery`, text, not required): Describe the photo gallery, including the number of guests, photographer, and any specific requests.

### Wedding Party
Please select all that apply:
* **Wedding Party** (`Yes/No`, select one, required): Yes/No.

### Venue
Please provide the venue information:
* **Venue** (`Venue`, text, not required): Describe the venue, including the location, capacity, and any specific requests.

### Dress Code
Please provide a description of the dress code:
* **Dress Code** (`Dress Code`, text, not required): Describe the dress code for the wedding party.

### Special Requests
Please provide any special requests or requirements:
* **Special Requests** (`Special Requests`, text, not required): Describe any special requests or requirements you may have.

### Timeline
Please provide the start and end dates for the wedding:
* **Timeline** (`Timeline`, date, required): Select the start and end dates for the wedding.

### Time
Please select the start and end times for the wedding:
* **Time** (`Time`, time, required): Select the start and end times for the wedding.

### Budget
Please provide the budget information:
* **Budget** (`Budget`, number, not required): Provide the estimated budget for the wedding.

### Contact Info
Please provide the contact information:
* **Contact Info** (`Contact Info`, text, required): Provide the couple's contact information, including name and phone number.

### Email
Please provide the email address:
* **Email** (`Email`, email, required): Provide the couple's email address.

### Phone
Please provide the phone number:
* **Phone** (`Phone`, text, required): Provide the couple's phone number.

### Notes
Please provide any additional notes:
* **Notes** (`Notes`, note, not required): Provide any additional notes or comments.

## Tips
* Please answer all required questions to ensure accurate planning.
* Be as detailed as possible when providing information.
* If you have any questions or concerns, contact us directly.
