# Wedding Event Planning Form - Help Guide
## Purpose
The Wedding Event Planning Form is a tool used to gather information about a couple's wedding event. This form helps event planners and organizers to gather essential details about the couple, their wedding event, and their guests.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the couple's details, including their name, date of birth, email, and phone number.
2. Provide the wedding location and details of the event.
3. Specify the number of guests attending the event.
4. Choose the event package and provide a brief description.
5. Add any additional event details, such as event date and time.
6. Add any notes about the couple or event.

## Field-by-Field Explanation

* **Wedding Event Planning Form**: This is the form title and a placeholder.
* **Couple Details**: Enter the names of the couple getting married.
* **Couple DOB**: Enter the couple's date of birth in MM/DD/YYYY format.
* **Couple Email**: Enter the couple's email address.
* **Couple Phone**: Enter the couple's phone number.
* **Wedding Details**: Provide a brief description of the wedding event.
* **Wedding Location**: Enter the location where the wedding will take place.
* **Guest Details**: Enter the names of the guests attending the event.
* **Guest Name**: Enter the name of each guest.
* **Guest Email**: Enter each guest's email address.
* **Guest Phone**: Enter each guest's phone number.
* **Number of Guests**: Specify the number of guests attending the event.
* **Event Package**: Choose the event package that best suits the couple's needs (Basic, Deluxe, or Premium).
* **Event Package Description**: Provide a brief description of the chosen event package.
* **Event Details**: Add any additional event details, such as event date and time.
* **Event Date**: Enter the date of the event in MM/DD/YYYY format.
* **Event Time**: Enter the time of the event in 24-hour format (HH:MM).
* **Event Note**: Add any notes about the event.
* **Couple Note**: Add any notes about the couple.

Note: The form fields are optional, and the user can skip any field if it's not applicable.
