# Wedding Memory Collection Form - Help Guide
## Purpose

The Wedding Memory Collection Form is designed to collect memories from wedding guests, allowing them to share their favorite moments from the special day.

## How To Complete This Form

1. **Wedding Memory Collection Form 1** (`wedding_memory_collection_form_1`, Text): 
Please share your favorite memory from the wedding day. This is a text box where you can write down your thoughts, stories, or feelings about the wedding.
2. **Wedding Memory Collection Form 2** (`wedding_memory_collection_form_2`, Text): 
Please share another favorite memory from the wedding day. Similar to the first memory, you can write down your thoughts, stories, or feelings about the wedding.
3. **Wedding Memory Collection Form 3** (`wedding_memory_collection_form_3`, Number): 
If you have a favorite number associated with the wedding, please enter it here (e.g., the number of guests, the number of hours it took for the cake to be made, etc.).
4. **Wedding Memory Collection Form 4** (`wedding_memory_collection_form_4`, Number): 
If you have a favorite number associated with the wedding, please enter it here.
5. **Wedding Memory Collection Form 5** (`wedding_memory_collection_form_5`, Select One): 
Please select one of the options to share whether or not you enjoyed the music played at the wedding.
6. **Wedding Memory Collection Form 6** (`wedding_memory_collection_form_6`, Select Multiple): 
Please select all that apply from the options to share whether or not you enjoyed the food, decorations, or other aspects of the wedding.
7. **Wedding Memory Collection Form 7** (`wedding_memory_collection_form_7`, Date): 
If you have a specific date associated with the wedding, please enter it here (e.g., the date of the wedding proposal, the date the wedding party started, etc.).
8. **Wedding Memory Collection Form 8** (`wedding_memory_collection_form_8`, Time): 
If you have a favorite time associated with the wedding, please enter it here (e.g., the time the sun rose on the wedding day, the time the first dance started, etc.).
9. **Wedding Memory Collection Form 9** (`wedding_memory_collection_form_9`, Email): 
This field is not used in the form.
10. **Wedding Memory Collection Form 10** (`wedding_memory_collection_form_10`, Text): 
Please share another favorite memory from the wedding day.
11. **Wedding Memory Collection Form 11** (`wedding_memory_collection_form_11`, Select One): 
Please select one of the options to share whether or not you enjoyed the wedding party games or activities.
12. **Wedding Memory Collection Form 12** (`wedding_memory_collection_form_12`, Select Multiple): 
Please select all that apply from the options to share whether or not you enjoyed the wedding party games or activities, decorations, or other aspects of the wedding.
13. **Wedding Memory Collection Form 13** (`wedding_memory_collection_form_13`, Text): 
Please share another favorite memory from the wedding day.
14. **Wedding Memory Collection Form 14** (`wedding_memory_collection_form_14`, Date): 
If you have a specific date associated with the wedding, please enter it here.
15. **Wedding Memory Collection Form 15** (`wedding_memory_collection_form_15`, Number): 
If you have a favorite number associated with the wedding, please enter it here.
16. **Wedding Memory Collection Form 16** (`wedding_memory_collection_form_16`, Time): 
If you have a favorite time associated with the wedding, please enter it here.
17. **Wedding Memory Collection Form 17** (`wedding_memory_collection_form_17`, Select One): 
Please select one of the options to share whether or not you enjoyed the wedding ceremony.
18. **Wedding Memory Collection Form 18** (`wedding_memory_collection_form_18`, Select Multiple): 
Please select all that apply from the options to share whether or not you enjoyed the wedding ceremony, decorations, or other aspects of the wedding.
19. **Wedding Memory Collection Form 19** (`wedding_memory_collection_form_19`, Text): 
Please share another favorite memory from the wedding day.
20. **Wedding Memory Collection Form 20** (`wedding_memory_collection_form_20`, Select One): 
Please select one of the options to share whether or not you enjoyed the photo booth or other wedding activities.
21. **Wedding Memory Collection Form 21** (`wedding_memory_collection_form_21`, Text): 
Please share another favorite memory from the wedding day.
22. **Wedding Memory Collection Form 22** (`wedding_memory_collection_form_22`, Number):

23. **Wedding Memory Collection Form 23** (`wedding_memory_collection_form_23`, Time):

## Tips

- Be as descriptive as possible when sharing your memories to make them more valuable to the couple.
- If you have trouble finding the right memory, you can always come back and edit your submission.
- You can share as many or as few memories as you like. There is no limit to the number of submissions.
- If you have questions or need help, contact the wedding planner or coordinator.
