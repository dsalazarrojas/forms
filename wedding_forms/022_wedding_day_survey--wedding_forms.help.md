# Wedding Day Survey - Help Guide
## Purpose
The Wedding Day Survey form is designed to collect essential details about a wedding event. It is meant to be filled out by the wedding party or the event planner to ensure that all relevant information is gathered in one place.

## How To Complete This Form
To complete this form, please follow these steps:

1. Select the relevant answers to the questions posed in each field.
2. Fill in any required fields (marked as "required" in the form).
3. If a field is optional, you can leave it blank.
4. Review the form carefully to ensure that all information is accurate and up-to-date.

## Field-by-Field Explanation

* **Wedding Day Survey** (id: 1, label: Wedding Day Survey, type: select_multiple, required: false)
	+ This field allows you to indicate whether this is a wedding event (Yes/No).
* **Guests Attending** (id: 2, label: Guests Attending, type: select_multiple, required: false)
	+ This field is used to estimate the number of guests attending the wedding event.
* **Wedding Date** (id: 3, label: Wedding Date, type: date, required: false)
	+ This field is used to enter the date of the wedding event.
* **Wedding Time** (id: 4, label: Wedding Time, type: time, required: false)
	+ This field is used to enter the time of the wedding event.
* **Venue Address** (id: 5, label: Venue Address, type: text, required: false)
	+ This field is used to enter the address of the wedding venue.
* **Dress Code** (id: 6, label: Dress Code, type: text, required: false)
	+ This field is used to indicate the dress code for the wedding event.
* **Dress Code Instructions** (id: 7, label: Dress Code Instructions, type: text, required: false)
	+ This field is used to provide additional instructions regarding the dress code.
* **Wedding Favors** (id: 8, label: Wedding Favors, type: text, required: false)
	+ This field is used to describe the wedding favors that will be given to guests.
* **Number of Guests** (id: 9, label: Number of Guests, type: number, required: false)
	+ This field is used to estimate the number of guests that will attend the wedding event.
* **Special Needs** (id: 10, label: Special Needs, type: text, required: false)
	+ This field is used to document any special needs that guests or the wedding party may have.
* **Wedding Theme** (id: 11, label: Wedding Theme, type: select_one, required: false)
	+ This field is used to select the theme of the wedding event (Rustic, Formal, Beach).
* **Wedding Color Scheme** (id: 12, label: Wedding Color Scheme, type: text, required: false)
	+ This field is used to enter the color scheme of the wedding event.
* **Wedding Music** (id: 13, label: Wedding Music, type: text, required: false)
	+ This field is used to describe the music that will be played at the wedding event.
* **Wedding Favors Description** (id: 14, label: Wedding Favors Description, type: text, required: false)
	+ This field is used to provide a detailed description of the wedding favors.
* **Special Instructions** (id: 15, label: Special Instructions, type: text, required: false)
	+ This field is used to enter any special instructions or notes regarding the wedding event.
* **Number of Favors** (id: 16, label: Number of Favors, type: number, required: false)
	+ This field is used to estimate the number of favors that will be given to each guest.
* **Vendor** (id: 17, label: Vendor, type: select_one, required: false)
	+ This field is used to select the vendor providing services for the wedding event (vendor1, vendor2, vendor3).
* **Vendor Info** (id: 18, label: Vendor Info, type: text, required: false)
	+ This field is used to enter any contact information for the selected vendor.
* **Wedding Ideas** (id: 19, label: Wedding Ideas, type: text, required: false)
	+ This field is used to enter any wedding ideas or inspiration.
* **Parking Information** (id: 20, label: Parking Information, type: text, required: false)
	+ This field is used to provide information about parking arrangements.
* **Accommodations** (id: 21, label: Accommodations, type: text, required: false)
	+ This field is used to enter information about accommodations for guests.
* **Vendor Email** (id: 22, label: Vendor Email, type: text, required: false)
	+ This field is used to enter the email address of the selected vendor.
* **Vendor Phone** (id: 23, label: Vendor Phone, type: text, required: false)
	+ This field is used to enter the phone number of the selected vendor.
* **Vendor Address** (id: 24, label: Vendor Address, type: text, required: false)
	+ This field is used to enter the address of the selected vendor.
* **Vendor Notes** (id: 25, label: Vendor Notes, type: text, required: false)
	+ This field is used to enter any additional notes or comments about the vendor.
