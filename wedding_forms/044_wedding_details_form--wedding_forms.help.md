# Wedding Details Form - Help Guide
## Purpose
This form is designed to collect essential details about a wedding, including the bride and groom's names, wedding date and time, location, attire, and other important aspects. The form is intended to provide a comprehensive overview of the wedding event.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the required fields with the necessary information about the wedding.
2. Choose the relevant options for each field, such as the ceremony and reception attire, theme, and invitations.
3. Enter any additional information that is not already provided in the other fields.

## Field-by-Field Explanation

* **Wedding Details**: (required) A brief description of the wedding event.
* **Bride Name**: (required) The full name of the bride.
* **Groom Name**: (required) The full name of the groom.
* **Wedding Date**: (required) The date of the wedding in the format YYYY-MM-DD.
* **Wedding Time**: (optional) The time of the wedding in 12-hour format (e.g., 14:30 for 2:30 PM).
* **Wedding Location**: (optional) The location of the wedding.
* **Wedding Dress Code**: (optional) Whether a dress code is required or not.
	+ Choose 'Yes' if a dress code is required.
	+ Choose 'No' if a dress code is not required.
* **Officiant Name**: (optional) The name of the person officiating the wedding.
* **Ceremony Start Time**: (optional) The start time of the ceremony.
* **Reception Start Time**: (optional) The start time of the reception.
* **Reception End Time**: (optional) The end time of the reception.
* **Wedding Dress Color**: (optional) The color of the wedding dress.
	+ Choose Black, White, Beige, or Other if applicable.
* **Flower Girl Bouquet Color**: (optional) The color of the flower girl's bouquet.
	+ Choose Blue, Pink, Yellow, White, or Green if applicable.
* **Ring Bearer Name**: (optional) The name of the person carrying the rings.
* **Best Man Name**: (optional) The name of the best man.
* **Best Woman Name**: (optional) The name of the best woman.
* **Wedding Party**: (optional) The list of people attending the wedding.
* **Ceremony Type**: (optional) The type of ceremony (e.g., traditional, civil, symbolic, non-religious).
	+ Choose one of the provided options.
* **Ceremony Attire**: (optional) Whether ceremony attire is required or not.
	+ Choose 'Yes' if attire is required.
	+ Choose 'No' if attire is not required.
* **Reception Attire**: (optional) Whether reception attire is required or not.
	+ Choose 'Yes' if attire is required.
	+ Choose 'No' if attire is not required.
* **Wedding Theme**: (optional) Whether a specific wedding theme is applicable.
	+ Choose 'Yes' if a theme is applicable.
	+ Choose 'No' if no theme is applicable.
* **Wedding Invitations**: (optional) Whether wedding invitations are required or not.
	+ Choose 'Yes' if invitations are required.
	+ Choose 'No' if invitations are not required.
* **Wedding Invitations Message**: (optional) A message to include on the invitations.
* **Ceremony Location**: (optional) The location of the ceremony.
* **Reception Location**: (optional) The location of the reception.

## Tips
- Make sure to double-check the fields for accuracy before submission.
- If unsure about any field, refer to the provided instructions.
- If additional information is required for any field, use the "Wedding Details" field for clarification.
