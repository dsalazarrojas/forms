# Wedding Floral Arrangement Survey - Help Guide
## Purpose
This form is designed to collect information about wedding floral arrangements from experienced wedding planners and florists. The data collected will help us understand and improve the wedding services offered by the company.

## How To Complete This Form
To complete this form, please follow these steps:

* Review the form carefully and ensure you have all necessary information about the wedding floral arrangement.
* Select the appropriate options for each field based on your experience and knowledge.
* Be as accurate and detailed as possible, especially when providing information about the flowers and foliage used.
* If you have any additional comments or information that you think would be helpful, please include them in the "Contact Info" field.

## Field-by-Field Explanation

* **Wedding Florals**: Please select 'Yes' if you have experience with creating wedding florals, and 'No' otherwise.
	+ Options: 'Yes', 'No'
* **Couples' Color Palettes**:
	+ Select all color palettes that you have experience working with.
	+ Options: 'Yes', 'No'
* **Arrangement Needs**: Please provide a detailed description of the specific needs or requirements of the wedding floral arrangement. For example, you can mention the occasion, number of guests, or any special requests from the couple.
* **Flowers And Foliage**:
	+ Select all flowers and foliage that you have used or plan to use for the wedding floral arrangement.
* **Budget**: Please provide an estimate of the budget for the wedding floral arrangement.
* **Contact Info**: If you have any additional comments or information that you think would be helpful, please provide them here.
* **Send Info**: Please enter your email address so we can contact you if we need more information or to follow up on your submission.
