# Wedding Caterer Referral Form - Help Guide
## Purpose
This form is used to collect referral information from potential clients, including wedding planners and venue managers, to connect them with suitable wedding caterers.

## How To Complete This Form
To complete this form, follow the steps below:

1. Select the type of referral you are making (e.g. wedding reception, wedding ceremony, etc.).
2. Choose the size of the event (e.g. small, medium, large, extra large).
3. Fill in the contact information for the referral source (wedding planner or venue manager).
4. Enter any referral notes or messages for the wedding planner or venue manager.
5. Select the caterers you are referring to (multiple select allowed).
6. Enter any additional information for the referral source (if applicable).

## Field-by-Field Explanation
### Page 1: Referral Information
* **Referral Information**: Enter a brief description of the referral.
* **Caterer Name**: Enter the name of the caterer being referred.
* **Venue Name**: Enter the name of the venue where the event will take place.
* **Event Date**: Enter the date of the event.
* **Contact Email**: Enter the email of the contact person for the referral source.
* **Contact Phone**: Enter the phone number of the contact person for the referral source.
* **Referral Message**: Enter a brief message for the referral source.

### Page 2: Referral Source Contact Information
* **Planner Name**: Enter the name of the wedding planner or venue manager making the referral.
* **Planner Email**: Enter the email of the wedding planner or venue manager.
* **Planner Phone**: Enter the phone number of the wedding planner or venue manager.
* **Venue Manager Name**: Enter the name of the venue manager (if applicable).
* **Venue Manager Email**: Enter the email of the venue manager (if applicable).
* **Venue Manager Phone**: Enter the phone number of the venue manager (if applicable).

### Page 3: Event Details
* **Event Type**: Select the type of event (e.g. wedding reception, wedding ceremony, etc.).
* **Event Size**: Select the size of the event (e.g. small, medium, large, extra large).
* **Event Location**: Enter the location of the event.
* **Wedding Caterer Referral**: Select multiple caterers to refer to (if applicable).
* **Other**: Enter any other information for the event (if applicable).

### Page 4: Referral Notes
* **Planner Referral Notes**: Enter any referral notes or messages for the wedding planner.
* **Venue Manager Referral Notes**: Enter any referral notes or messages for the venue manager.

### Page 5: Additional Information
* **Wedding Planner Referral Notes**: Enter any additional information for the referral source.
* **Venue Manager Referral Notes**: Enter any additional information for the venue manager.

# Tips
* Make sure to fill in all required fields to ensure accurate referral information.
* Select multiple caterers to refer to if applicable.
* Enter any additional notes or messages for the referral source as necessary.
* Review all fields before submitting the form to ensure accuracy.
