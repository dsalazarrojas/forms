# habeshabrides_feature_form - Help Guide
## Purpose
The habeshabrides_feature_form is used to submit a wedding event feature request for event planners. This form helps in providing event details such as wedding date, time, location, and services required for the event.

## How To Complete This Form

1. To start, please ensure you are filling out the form for a specific wedding event feature request.
2. Select the wedding date on the "Wedding Date" field. This is where the wedding will take place.
3. Choose the wedding time on the "Wedding Time" field. This will help the planners schedule the event accordingly.
4. Fill in the "Brides Name" field with the name of the bride.
5. Fill in the "Grooms Name" field with the name of the groom.
6. Provide the location where the wedding will take place on the "Wedding Place" field.
7. If you have any specific requirements or details about the wedding location, use the "Wedding Place Note" field.
8. Fill in the "Contact Person" field with the name of the person responsible for the event.
9. Provide the contact phone number of the person responsible in the "Contact Phone" field.
10. Fill in the "Contact Email" field with the email address of the person responsible.
11. Select the services required for the wedding event from the list of options provided in the "Wedding Services" field.
12. If you have any specific requirements or details about the services, use the "Wedding Services Note" field.

## Field-by-Field Explanation

* **Wedding Date**: This is where you select the date of the wedding event.
* **Wedding Time**: This is where you select the time of the wedding event.
* **Brides Name**: This is the name of the bride.
* **Grooms Name**: This is the name of the groom.
* **Wedding Place**: This is the location where the wedding will take place.
* **Wedding Place Note**: This is a field for any additional notes or details about the wedding location.
* **Contact Person**: This is the name of the person responsible for the event.
* **Contact Phone**: This is the contact phone number of the person responsible for the event.
* **Contact Email**: This is the email address of the person responsible for the event.
* **Wedding Services**: This is a select multiple field that allows you to choose the services required for the event. The options are:
	+ Church
	+ Event
	+ Hotel
	+ Park
	+ Restaurant
	+ Venue
* **Wedding Services Note**: This is a field for any additional notes or details about the services required.

## Tips

* Please ensure that you fill in all required fields to provide accurate and complete information.
* Use the "Wedding Services Note" field to provide any additional details or requirements for the services you have selected.
* If you have any specific requirements or details about the location, use the "Wedding Place Note" field.
* If you have any questions or concerns, you can reach out to the contact person or email address provided.
