## wedding_vendor_post_event_satisfaction_check_in - Help Guide

## Purpose
This form is for gathering feedback from vendors after an event to ensure that the event planning process and experience were satisfactory.

## How To Complete This Form
To complete this form, follow the instructions below:

1. Review each field carefully and answer accordingly.
2. Ensure you are selecting the correct options for your experience.
3. Provide honest and detailed feedback in the free-text field.

## Field-by-Field Explanation
- **Vendors Satisfaction** (`vendor_satisfaction`, select_multiple, required: false): Select all applicable options from Satisfied or Dissatisfied to express your satisfaction with various aspects of the event planning process.
  * This field allows you to express your overall satisfaction with the event planning process.
- **Event Details** (`event_details`, text, required: false): Briefly describe the event and any specific details that you think are relevant to your feedback.
  * This field is for providing context to your feedback.
- **Communication with Planner** (`communication_with_planner`, select_one, required: false): Select Yes or No to indicate how well you were communicated with by the event planner.
  * This field assesses the communication effectiveness between the vendor and the event planner.
- **Communication with Vendor** (`communication_with_vendor`, select_one, required: false): Select Yes or No to indicate how well you were communicated with by the event vendor.
  * This field assesses the communication between the vendor and the planner.
- **Overall Satisfaction** (`overall_satisfaction`, select_one, required: false): Select Satisfied or Dissatisfied to express your overall satisfaction with the event planning process.
  * This field captures your general satisfaction with the event planning process.
- **Will Use Again** (`will_use_again`, select_multiple, required: false): Select all applicable options from Yes or No to indicate if you would use the event planning service again.
  * This field indicates your willingness to use the event planning service in the future.
- **Vendor Feedback** (`vendor_feedback`, text, required: false): Provide any additional comments or suggestions you have for future improvements.
  * This field is for offering detailed feedback on the event planning service.

## Tips
* Be honest and thorough in your feedback to help improve the event planning process.
* If you have any concerns or issues, use the free-text field to provide more information.
* Submit this form only once for each event to ensure accurate feedback results.
