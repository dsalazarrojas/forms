# Change Of Tenant Form - Help Guide
## Purpose

This form is used to report a change of tenant for a rental property. It captures essential information about the current tenant's details, the reason for the change, and the new tenant's contact information.

## How To Complete This Form

1. Fill out the form date and time of submission.
2. Enter the address of the rental property.
3. Provide the unit or apartment number if applicable.
4. Enter the name of the current tenant being replaced.
5. Enter the current tenant's contact information.
6. Specify the date the current tenant is moving out.
7. Choose the reason why the current tenant is leaving.
8. Enter the name of the new tenant moving in.
9. Provide the new tenant's contact information.
10. Enter the date the new tenant is moving in.
11. Select the start and end dates of the new lease.
12. Enter the monthly rent amount for the new tenant.
13. Indicate whether a security deposit has been received from the new tenant.
14. Confirm if a property condition inspection has been completed.
15. Specify if utilities have been transferred to the new tenant.
16. Add any additional notes or conditions.

## Field-by-Field Explanation
* **Form Date** (`form_date`, date, required): The date and time this form is being submitted.
* **Property Address** (`property_address`, text, required): The address of the rental property.
* **Unit or Apartment Number** (`property_unit`, text, required): The unit or apartment number if applicable.
* **Landlord or Property Owner Name** (`landlord_name`, text, required): The name of the property owner or landlord.
* **Landlord Contact Information** (`landlord_contact`, text, required): Phone and email of the property owner or landlord.
* **Property Manager Name** (`property_manager_name`, text, optional): The name of the property manager if applicable.
* **Current Tenant Name** (`current_tenant_name`, text, required): The name of the tenant being replaced.
* **Current Tenant Contact Information** (`current_tenant_contact`, text, optional): Phone and email of the current tenant.
* **Current Tenant Move-Out Date** (`move_out_date`, date, required): The date the current tenant is moving out.
* **Reason for Tenant Change** (`reason_for_termination`, select_one, optional): The reason why the current tenant is leaving (e.g., lease expiration, mutual agreement, etc.).
* **New Tenant Name** (`new_tenant_name`, text, required): The name of the new tenant moving in.
* **New Tenant Contact Information** (`new_tenant_contact`, text, required): Phone and email of the new tenant.
* **New Tenant Move-In Date** (`new_tenant_move_in_date`, date, required): The date the new tenant is moving in.
* **New Lease Start Date** (`new_lease_start_date`, date, required): The start date of the new lease.
* **New Lease End Date** (`new_lease_end_date`, date, required): The end date of the new lease.
* **New Monthly Rent Amount** (`new_monthly_rent`, number, required): The rent amount for the new tenant.
* **Security Deposit from New Tenant** (`security_deposit_status`, select_one, optional): Whether the new tenant has provided a security deposit.
* **Property Condition Inspection Completed** (`property_condition_inspection`, select_one, optional): Whether a property condition inspection has been completed.
* **Utilities Transferred to New Tenant** (`utilities_transition`, select_one, optional): Whether utilities have been transferred to the new tenant.
* **Additional Notes or Conditions** (`additional_notes`, text, optional): Any special arrangements or notes about the change of tenant.
