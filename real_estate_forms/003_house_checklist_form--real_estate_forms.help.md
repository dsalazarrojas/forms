# House Checklist Form - Help Guide
## Purpose
This form is designed to be a comprehensive checklist for evaluating the status and characteristics of a house. It is intended to be used by real estate agents, appraisers, or other professionals who need to assess the condition of a property.

## How To Complete This Form
To complete this form, follow these steps:

1. Review the form carefully to ensure you understand each field's purpose and options.
2. Answer each field based on your observations and knowledge of the property's status.
3. Select the most accurate option for each field.
4. Make sure to review the form carefully before submitting it.

## Field-by-Field Explanation
* **house status**: This field is used to indicate the overall status of the property. Select "True" if the house is for sale or "False" if it is not.
* **basic systems status**: This field is used to evaluate the status of the basic systems in the house, such as plumbing, electrical, and HVAC. Select "Working" if all systems are functioning properly, "Not Working" if any system is not functioning, or "Unknown" if you're unsure.
* **engines status**: This field is used to assess the status of any engines or motors in the house, such as furnaces or generators. Select "Working" if all engines are functioning properly, "Not Working" if any engine is not functioning, or "Unknown" if you're unsure.
* **service requirements**: This field is used to document any service requirements or notes about the property. Provide any relevant information, such as maintenance records or outstanding issues.
* **exteriors information**: This field is used to document any information about the property's exterior, such as the condition of the roof, walls, or landscaping.
* **security information**: This field is used to document any security features or concerns about the property, such as alarm systems or potential safety hazards.
* **additional information**: This field is used to document any additional information about the property that doesn't fit in other fields.
* **house location**: This field is used to indicate the location of the property, such as urban, rural, or unknown.
* **has pool**: This field is used to indicate whether the property has a pool or not.
* **has garage**: This field is used to indicate whether the property has a garage or not.
