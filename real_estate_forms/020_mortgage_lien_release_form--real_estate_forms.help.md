# Mortgage Lien Release Form - Help Guide
## Purpose
The Mortgage Lien Release Form is used to confirm that a lien on a property has been released due to payment of the loan or to provide instructions for release of the lien.

## How To Complete This Form

1. Fill in the Loan Amount field with the total amount of the loan.
2. Select the Lender Information option to provide information about the lender.
3. Enter the Property Address where the lien is located.
4. For the Loan and Release Dates field, select the option that corresponds to the date of the loan and the date of release.
5. For the Lien and Release Amounts field, select the option that corresponds to the amount of the lien and the release amount.
6. Select 'Yes' to confirm that payment has been made in the Payment Confirmation field.
7. Provide detailed Release Instructions for release of the lien in the Release Instructions field.
8. Add any additional comments in the Additional Comments field.
9. Optionally, enter any release fees and lender fees in the respective fields.
10. Provide any final comments about the transaction.

## Field-by-Field Explanation
### Loan Amount (`loan_amount`, number, required): 
Enter the total amount of the loan.

*   Example: 10,000

### Lender Information (`lender_info`, select_one, optional): 
Provide information about the lender.

*   Select one of the following options:
    *   Lender Name
    *   Lender Phone
    *   Lender Email

### Property Address (`property_address`, text, required): 
Enter the property address where the lien is located.

*   Example: 123 Main St.

### Loan and Release Dates (`loan_release_dates`, select_one, optional): 
Select the option that corresponds to the date of the loan and the date of release.

*   Select one of the following options:
    *   Loan Date
    *   Release Date

### Lien and Release Amounts (`lien_and_release_amounts`, select_one, optional): 
Select the option that corresponds to the amount of the lien and the release amount.

*   Select one of the following options:
    *   Lien Amount
    *   Release Amount

### Payment Confirmation (`payment_confirmation`, select_one, required): 
Confirm that payment has been made.

*   Select 'Yes'.

### Release Instructions (`release_instructions`, note, required): 
Provide detailed instructions for release of the lien.

*   Enter clear and concise instructions for the release of the lien.

### Additional Comments (`additional_comments`, note, optional): 
Enter any additional comments about the transaction.

*   Enter any relevant comments or details about the transaction.

### Release Fees (`release_fees`, number, optional): 
Enter any release fees.

*   Enter a numeric value for any release fees.

### Lender Fees (`lender_fees`, number, optional): 
Enter any lender fees.

*   Enter a numeric value for any lender fees.

### Comments (`comments`, note, optional): 
Enter any final comments about the transaction.

*   Enter any final comments or details about the transaction.
