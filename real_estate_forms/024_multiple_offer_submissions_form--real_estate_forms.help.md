# Multiple Offer Submissions Form - Help Guide
## Purpose
The Multiple Offer Subscriptions Form is designed to record and track multiple offer submissions from various buyers for a specific property. This form helps real estate professionals to make informed decisions about which offer to accept, reject, or negotiate further.

## How To Complete This Form
To complete this form, follow these steps:

* Ensure you have all the necessary information required for this form.
* Start by filling out the "Home owner address" field with the correct address of the property.
* Move on to the "How many offers did you receive?" field and type in the number of offers you received.
* In the "Highest offer" field, type the amount of the highest offer, including the cents, if applicable.
* Enter the offer amount in the "Offer amount" field, which should match the amount of the highest offer.
* If you want to, you can add the contact information of the buyer (name, phone, email) and a message from the buyer in the corresponding fields.
* Review and submit the form once you've completed it.

## Field-by-Field Explanation

* **Home owner address**: Enter the address of the property for which you are tracking multiple offers. This field is required for the system to associate the offers with the correct property.
* **How many offers did you receive?**: Type the number of offers you received from different buyers for the property. This will help track the number of competing offers.
* **Highest offer**: Enter the amount of the highest offer, including cents, if applicable. This will help you evaluate the highest bid and compare it with other offers.
* **Offer amount**: Enter the amount of the highest offer, which should match the amount you entered in the "Highest offer" field. This ensures data accuracy and consistency.
* **Name of buyer**: If you want to add the name of the buyer who made the highest offer, you can do so in this field. This provides additional context for the offer.
* **Buyer phone**: If you want to add the phone number of the buyer, enter it here. This helps you contact the buyer directly for further negotiations or questions.
* **Buyer email**: If you want to add the email address of the buyer, enter it here. This provides another channel for communication with the buyer.
* **Message from buyer**: If you have a message from the buyer, enter it here. This can be useful for further discussions or negotiations.

## Tips

* Always ensure that the form is completed accurately and consistently to prevent errors and ensure data quality.
* If you're unsure about any field, refer to the property's listing details or consult with the property owner.
* Use this form to track multiple offers for one property only. If you need to track offers for multiple properties, use the form for each property separately.
