# Move In Inspection Form Holiday Homes - Help Guide
## Purpose
The Move In Inspection Form Holiday Homes is a document used to inspect and document the condition of a rental property before a tenant moves in. This form helps to ensure that the property is in a satisfactory condition for the tenant and helps to prevent any potential disputes or issues that may arise during or after the tenancy.

## How To Complete This Form

1. To complete this form, please select the "move_in_inspection_form_holiday_homes" page.
2. Fill in the "tenant_name" field with the name of the tenant who will be moving into the property.
3. Enter the "move_in_date" field with the date of the tenant's move-in date.
4. Answer the "condition_of_property" field by selecting the condition of the property from the provided options.
5. Select all applicable issues found during the inspection in the "cleanliness" field.
6. In the "damages_found" field, select all applicable damages found during the inspection.
7. In the "issues_found" field, select all applicable issues found during the inspection.
8. Use the "property_condition" field to note any specific comments or observations about the property condition.
9. Enter any additional comments or observations in the "comments" field.
10. If applicable, enter the name of the tool used for the inspection in the "assigned_tool" field.

## Field-by-Field Explanation

* **move_in_inspection_form_holiday_homes** (`move_in_inspection_form_holiday_homes`, Number, required: false): This is the page number of the form.
* **tenant_name** (`tenant_name`, Text, required: false): Enter the name of the tenant who will be moving into the property.
* **move_in_date** (`move_in_date`, Date, required: false): Enter the date of the tenant's move-in date.
* **condition_of_property** (`condition_of_property`, Select One, required: false): Select the condition of the property from the provided options:
	+ 1
	+ 2
	+ 3
* **cleanliness** (`cleanliness`, Select Multiple, required: false): Select all applicable issues with the cleanliness of the property:
	+ Clean
	+ Fair
	+ Poor
* **damages_found** (`damages_found`, Select Multiple, required: false): Select all applicable damages found during the inspection:
	+ None
	+ Small
	+ Moderate
	+ Extensive
* **issues_found** (`issues_found`, Select Multiple, required: false): Select all applicable issues found during the inspection:
	+ None
	+ Small
	+ Moderate
	+ Extensive
* **property_condition** (`property_condition`, Note, required: false): Use this field to note any specific comments or observations about the property condition.
* **comments** (`comments`, Note, required: false): Enter any additional comments or observations.
* **assigned_tool** (`assigned_tool`, Text, required: false): If applicable, enter the name of the tool used for the inspection.
