# Rental History Verification Form - Help Guide
## Purpose
This form is used to verify the rental history of a property, ensuring that the property manager provides accurate information about the tenants who have rented the property in the past.

## How To Complete This Form
1. Fill in the Tenant Details section with the relevant information about the tenant, including their name, address, and any other identifying details.
2. Select the rental history of the tenant from the options provided in the Rental History section.
3. Enter the Property Manager's Name and contact information in the Property Manager section.
4. Fill in the Tenant Reference number in the Tenant Reference section.

## Field-by-Field Explanation
* **Tenant Details** (`tenant_details`, text, optional)
	+ This field is where you provide information about the tenant, including their name, address, and any other identifying details.
* **Rental History** (`rental_history`, select_multiple, optional)
	+ Select from the options: 'never rented', 'currently rented', 'former rents', or 'other' to describe the rental history of the tenant.
* **Property Manager Name** (`property_manager_name`, text, optional)
	+ Enter the name of the property manager who is providing this information.
* **Property Manager Phone** (`property_manager_phone`, text, optional)
	+ Enter the phone number of the property manager who is providing this information.
* **Property Manager Email** (`property_manager_email`, email, optional)
	+ Enter the email address of the property manager who is providing this information.
* **Tenant Reference** (`tenant_reference`, number, optional)
	+ Enter a unique reference number provided by the property manager to identify the tenant.

## Tips
* Please ensure that the information provided is accurate and up-to-date.
* If the tenant has a complex rental history, please select 'other' and provide a brief explanation in the additional comments section.
