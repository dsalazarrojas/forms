# natural_person_fica_declaration_soukop - Help Guide

## Purpose
This form is used to create a Natural Person FICA Declaration, a document required for tax-related purposes. Fill out this form to generate a personalized declaration for your natural person FICA declaration needs.

## How To Complete This Form
- Fill out the form title and description in sections 6 and 5 respectively.
- Select the correct category in section 2, but note that this field is not required.
- Choose the correct assigned tool in section 3, or leave it to default to the provided options.
- Select the correct form ID in section 4, or leave it to default to the provided options.
- Fill out the title and description for section 7, as they are the only remaining fields required for this form.
- For sections 8, 9, 10 and 11, fill out the required fields as per the field type and options provided.

## Field-by-Field Explanation
* **Natural Person FICA Declaration** (`form_title`, text, required): Enter a brief title for your document.
* **Select Category** (`category`, select_one, required: false): Choose a category for your declaration, such as 'Real Estate Forms'.
* **Assigned Tool** (`assigned_tool`, select_one, required: false): Select the tool used for this declaration, or leave it to default to 'chatjimmy'.
* **Select Form Id** (`form_ids`, select_one, required: false): Choose a form ID, such as 'Yes', or leave it to default to the provided options.
* **Description** (`description`, text, required): Enter a brief description of your document.
* **Enter Title** (`title`, text, required): Enter a title for your document.
* **Category 2** (`category_2`, text, required): Enter a category for your document.
* **Output File** (`output_file`, text, required): Enter the path to the output file for your document.
* **Assigned Tool 2** (`assigned_tool_2`, select_one, required: false): Select the tool used for this document, or leave it to default to 'chatjimmy'.
* **Form Ids** (`form_ids_2`, select_one, required: false): Select the form ID for this document, or leave it to default to the provided options.
* **Output File 2** (`output_file_2`, text, required): Enter the path to the output file for this document.

## Tips

- Double-check the required fields for any errors before submission.
- If you are unsure of any field's requirements, refer back to this help guide for further clarification.
