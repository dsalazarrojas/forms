# Rental Reference Request - Help Guide
## Purpose

This form is designed to gather information about a rental property from the tenant or landlord. The purpose of this form is to facilitate the rental process by collecting necessary details about the rental agreement, including the tenant's contact information, property specifics, and rental terms.

## How To Complete This Form

To complete this form, please follow the steps outlined above.

## Field-by-Field Explanation

* **Tenant Name** (1, text, required/optional): Enter the name of the tenant.
* **Contact Email** (2, email, required/optional): Enter the tenant's contact email address.
* **Contact Phone** (3, text, required/optional): Enter the tenant's phone number.
* **Property Name** (4, text, required/optional): Enter the name of the rental property.
* **Landlord Name** (5, text, required/optional): Enter the name of the landlord.
* **Rental Start Date** (6, date, required/optional): Enter the start date of the rental agreement.
* **Rental End Date** (7, date, required/optional): Enter the end date of the rental agreement.
* **Rent** (8, number, required/optional): Enter the rent amount.
* **Property Type** (9, text, required/optional): Select the type of property (e.g. apartment, house, etc.).
* **Lease Status** (10, select_one, required/optional): Select the current status of the lease (Active, Inactive, Expired).
* **Reason For Lease End** (11, select_multiple, required/optional): Select the reason for the lease end (No longer renting, Lease renewal, Lease cancellation, Lease expiration).
* **Rental Agency** (12, select_one, required/optional): Select the type of rental agency (Property manager, Real estate agent, Property management company, Other).
* **Rental Agency Contact** (13, text, required/optional): Enter the contact information for the rental agency.
* **Tenant Signature** (14, note, required/optional): Provide a brief explanation for your signature as a tenant.
* **Landlord Signature** (15, note, required/optional): Provide a brief explanation for your signature as a landlord.
* **Rental Agency Authorized** (16, select_one, required/optional): Confirm whether the rental agency is authorized.
* **Landlord Notes** (17, note, required/optional): Add any additional notes from the landlord.
