# property_exit_inspection_form - Help Guide
## Purpose
This form is used to gather information about a property's details, condition, and potential damages or repairs.

## How To Complete This Form
To complete this form, follow these steps:

1. Start by entering the Property Details.
2. Select the Property Status from the available options.
3. Enter any details about the property's Condition.
4. Provide a Damage Report if there are any damages found.
5. Report the Repair Status if any work is being done or has been done.
6. If there are any property damages, enter a description and any relevant Property Damage Photos.
7. If applicable, report the Repair Cost.
8. If applicable, enter a Property Damage Description and any other supporting Property Damage Photos.

## Field-by-Field Explanation
* **Property Details (1)**: Enter a brief description of the property.
* **Property Status (2)**: Select one or multiple status options (Sold, Rented, Leased, Vacant).
* **Condition (3)**: Enter a detailed description of the property's current condition.
* **Damage Report (4)**: Enter a report of any property damages or issues.
* **Repair Status (5)**: Enter any repair or work being done on the property.
* **Property Damage (6)**: Enter a description of any property damages or issues.
* **Repair Cost (7)**: Enter the cost of any repairs.
* **Property Damage Photos (8)**: Attach any photos of property damages or issues.
* **Property Damage Description (9)**: Enter a detailed description of any property damages or issues.
