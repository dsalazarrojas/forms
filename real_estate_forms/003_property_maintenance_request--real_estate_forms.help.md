# Property Maintenance Request - Help Guide
## Purpose
The Property Maintenance Request form is designed to collect information about property maintenance issues or requests. It's used to gather details about the problem, the property's address, and the desired outcome.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the property name field with a brief description of the property.
2. Enter the address of the property where the maintenance request is for.
3. Provide a detailed description of the issue or request.
4. Choose the priority level of the request (Low, Medium, or High).
5. Select the current status of the request (In Progress, Completed, or Pending).

## Field-by-Field Explanation
* **Maintenance Request** (`maintenance_request`, note, optional): A brief summary of the maintenance issue or request.
* **Property Name** (`property_name`, text, optional): Enter a brief description of the property (e.g., house, building, etc.).
* **Address** (`address`, text, optional): The physical address of the property where the maintenance request is for.
* **Description** (`description`, text, optional): Provide a detailed description of the issue or request.
* **Priority** (`priority`, select_one, optional): Select the level of urgency for the request (Low, Medium, or High).
* **Status** (`status`, select_multiple, optional): Indicate the current status of the request (In Progress, Completed, or Pending).

## Tips
* Make sure to fill out the form accurately and thoroughly to ensure that the request is processed efficiently.
* Only submit one request per issue or problem.
* If you have any questions or concerns, contact the property maintenance team for assistance.
