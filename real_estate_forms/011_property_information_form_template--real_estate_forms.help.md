# Property Information Form Template - Help Guide
## Purpose
The Property Information Form Template is a comprehensive form for inputting property details. It is designed for real estate agents or brokers to gather and store property information for their clients.

## How To Complete This Form
To complete this form, follow these steps:

1. Start by filling in the property address in the `property_address` field.
2. Select the property type from the `property_type` dropdown menu.
3. Choose the property status from the `property_status` dropdown menu.
4. Enter the year the property was built in the `property_year_built` field.
5. Enter the square feet of the property in the `property_sqft` field.
6. Enter the number of bedrooms and bathrooms in the `property_bedrooms` and `property_bathrooms` fields respectively.
7. Select the year built range from the `property_year_built_range` dropdown menu.
8. Select the property status range from the `property_status_range` dropdown menu.
9. Choose the price range from the `property_price_range` dropdown menu.
10. Select the square feet range from the `property_sqft_range` dropdown menu.
11. Select the number of bedrooms and bathrooms range from the `property_bedrooms_range` and `property_bathrooms_range` dropdown menus respectively.
12. Add any additional notes about the property in the `property_notes` field.
13. Enter the property agent's name in the `property_agent` field.
14. Enter the property office's name in the `property_office` field.
15. Enter the property office's email in the `property_office_email` field.
16. Enter the property office's phone number in the `property_office_phone` field.
17. Select the property listings from the `property_listings` dropdown menu.
18. Select the property features from the `property_features` dropdown menu.

## Field-by-Field Explanation
* **property_address**: The property's street address. Please enter the full address, including street number and name.
* **property_type**: The type of property, such as single-family home, condominium, or apartment.
* **property_status**: The current status of the property, such as active, sold, or pending.
* **property_year_built**: The year the property was built.
* **property_sqft**: The square feet of the property.
* **property_bedrooms**: The number of bedrooms in the property.
* **property_bathrooms**: The number of bathrooms in the property.
* **property_year_built_range**: The range of years the property was built. Please select from the provided options.
* **property_status_range**: The range of property statuses. Please select from the provided options.
* **property_price_range**: The range of prices for the property. Please select from the provided options.
* **property_sqft_range**: The range of square feet for the property. Please select from the provided options.
* **property_bedrooms_range**: The range of bedrooms for the property. Please select from the provided options.
* **property_bathrooms_range**: The range of bathrooms for the property. Please select from the provided options.
* **property_notes**: Any additional notes or comments about the property.
* **property_agent**: The name of the property agent.
* **property_office**: The name of the property office.
* **property_office_email**: The email of the property office.
* **property_office_phone**: The phone number of the property office.
* **property_listings**: The property listings for the property.
* **property_features**: The features of the property.

Note: The fields marked as "select_one" or "select_multiple" require you to select one or multiple options from the provided dropdown menu. The fields marked as "text", "number", and "email" require you to enter a value directly.
