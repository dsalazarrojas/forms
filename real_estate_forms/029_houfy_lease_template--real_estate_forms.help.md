# Houfy Lease Template - Help Guide
## Purpose
This template is designed to help users create a lease agreement for properties, including information on confirmation codes, contact details, property details, and other essential data.

## How To Complete This Form
1. Please make sure to have all the required information handy.
2. Fill in the relevant fields according to your needs.
3. Review the form carefully before submission.

## Field-by-Field Explanation

* **Confirmation Code**: A unique code for each lease.
* **Name**: The name of the person or organization creating the lease.
* **Email**: The contact email address of the person or organization creating the lease.
* **Phone Number**: The phone number of the person or organization creating the lease.
* **Platform**: A description of the platform where the lease is being created (e.g., Airbnb, VRBO, etc.).
* **Property**: A description of the property being leased.
* **Nightly Rate**: The nightly rate or rent for the property.
* **Discount**: Any discount information for the property.
* **Pet Fee**: A fee for pets staying in the property.
* **Extra Guest Fee**: A fee for extra guests.
* **Tax**: Any additional tax information for the property.
* **Check-in Date**: The date the guest is expected to check-in.
* **Check-out Date**: The date the guest is expected to check-out.

## Tips
- Double-check all fields for accuracy before submitting the form.
- Ensure all fields that require a value are filled in correctly.
- Review the form regularly to update and refine it according to your needs.
