# Pre Funding Mortgage Audit Checklist - Help Guide
## Purpose
The Pre Funding Mortgage Audit Checklist is a tool to help you review and identify any potential issues or risks associated with a mortgage file. The form is used to ensure that all necessary information and documents are in order before proceeding with the funding process.

## How To Complete This Form
To complete this form, follow these steps:

1. Read through the Mortgage File Review section and flag any errors or irregularities you identify.
2. Answer the question about risks identified by selecting 'Yes' or 'No' from the Risks Identified dropdown menu.
3. If you identified any risks, provide details about them in the Risk Details text box.
4. List any issues that were flagged during the audit by selecting 'Yes' or 'No' from the Flagged Issues dropdown menu.
5. Provide any additional comments or notes about the mortgage file in the Additional Comments text box.

## Field-by-Field Explanation
* **Mortgage File Review** (Text)
	+ This is a text box where you can type any notes or comments about the mortgage file review. Please flag any errors or irregularities you identify while reviewing the file.
* **Risks Identified** (Select Multiple)
	+ Choose 'Yes' if you have identified any risks or issues with the mortgage file. This will help us track any potential problems that need to be addressed.
* **Risk Details** (Text)
	+ If you selected 'Yes' for Risks Identified, please provide details about the risks or issues you identified in this text box. This will help us understand the nature of the problem and take appropriate action.
* **Flagged Issues** (Select Multiple)
	+ Choose 'Yes' if you flagged any issues during the audit. This will help us track any potential problems that need to be addressed.
* **Additional Comments** (Text)
	+ Provide any additional comments or notes about the mortgage file that you feel are relevant to the audit process.

## Tips
* Make sure to review the mortgage file carefully to ensure all necessary information and documents are in order before proceeding with the funding process.
* If you select 'Yes' for Risks Identified or Flagged Issues, please provide clear and concise details about the problem so we can take appropriate action.
* If you have any questions or concerns about the form or the audit process, please don't hesitate to contact us.
* This form is intended to be a guide and may need to be updated as the business process evolves. If you notice any discrepancies or have suggestions for improvement, please let us know!
