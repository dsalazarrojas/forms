# fair_market_valuation_form - Help Guide
## Purpose
This form is used to collect information about a property's characteristics for real estate related purposes.

## How To Complete This Form
To fill out this form, please follow the steps outlined in the "To Complete This Form" section above.

## Field-by-Field Explanation
* **Property Address** (1, text, required): Enter the address of the property.
* **Property Type** (2, select_one, required): Select the type of property (Apartment, House, etc.).
* **Square Footage** (3, number, required): Enter the square footage of the property.
* **Year Built** (4, number, required): Enter the year the property was built.
* **Lot Size** (5, number, required): Enter the size of the lot.
* **Land Value** (6, number, required): Enter the land value.
* **Property Condition** (7, select_one, required): Select the property condition (Excellent, Fair, Poor).
* **Number of Bedrooms** (8, number, required): Enter the number of bedrooms.
* **Number of Bathrooms** (9, number, required): Enter the number of bathrooms.
* (Note: This field is a duplicate of 8)
* **Fair Market Valuation** (12, number, required): Enter the fair market valuation of the property.
* **Property Use** (13, select_one, required): Select the property use (Residential, Commercial, etc.).
* **Sale Status** (14, select_one, required): Select the sale status (Active, Inactive, etc.).
* **Property Status** (15, select_one, required): Select the property status (Active, Inactive, etc.).
* **Property Notes** (16, note, required): Enter any additional notes about the property.
* **Appraised Value** (17, number, required): Enter the appraised value of the property.
* **Sale Price** (18, number, required): Enter the sale price of the property.
* **Sale Date** (19, date, required): Enter the date of sale (or leave blank if not applicable).
* **Sale Agent** (21, select_one, required): Select whether the property was sold through an agent.
* **Property Agent** (22, select_one, required): Select whether the property was purchased through an agent.
* **Purchase Date** (24, date, required): Enter the date the property was purchased.
* **Other Notes** (25, note, required): Enter any other notes about the property.

## Tips
* Please be accurate when filling out this form, as the information will be used for real estate related purposes.
* If a field is marked as "Duplicate", enter the same value as the corresponding field with the lower ID.
* If a field is marked as "Same as [Field]", enter the same value as the field with the label specified.
