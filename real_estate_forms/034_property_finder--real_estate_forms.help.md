# Property Finder - Help Guide
## Purpose
This form is designed to collect information about properties for real estate-related applications or data collection.

## How To Complete This Form

1. Review the form carefully to understand what information is being collected.
2. Fill in the required fields (indicated by an asterisk *).
3. Select the relevant options for each field as required.
4. Submit the form once all fields are completed.

## Field-by-Field Explanation

* **Property Type** (`property_type`, text, optional): Enter the type of property (e.g., house, apartment, etc.).
* **Location** (`location`, text, optional): Enter the location or area of the property.
* **Price Range** (`price_range`, select_one, optional): Select 'Yes' or 'No' to indicate if the property is priced within a specific range.
* **Property Size** (`property_size`, text, optional): Enter the size of the property (e.g., square feet, acres, etc.).
* **Number of Bedrooms** (`num_bedrooms`, text, optional): Enter the number of bedrooms in the property.
* **Number of Bathrooms** (`num_bathrooms`, text, optional): Enter the number of bathrooms in the property.
* **Number of Floors** (`num_floors`, text, optional): Enter the number of floors in the property.
* **Property Status** (`property_status`, select_one, optional): Select 'Active' or 'Inactive' to indicate the current status of the property.
* **Property Type** (`property_type`, select_multiple, optional): Select 'Yes' or 'No' to indicate if the property is of a specific type (e.g., single-family home, condominium, etc.).
* **Property Use** (`property_use`, select_multiple, optional): Select 'Yes' or 'No' to indicate the intended use of the property (e.g., residential, commercial, etc.).
* **Property Purpose** (`property_purpose`, select_multiple, optional): Select 'Yes' or 'No' to indicate the intended purpose of the property (e.g., living, business, etc.).
* **Square Footage** (`square_footage`, text, optional): Enter the square footage of the property.
* **Lot Size** (`lot_size`, text, optional): Enter the size of the property lot or land.
* **Year Built** (`year_built`, text, optional): Enter the year the property was built.
* **Year Renovated** (`year_renovated`, text, optional): Enter the year the property was renovated.
* **Property Address** (`property_address`, text, optional): Enter the address of the property.
* **Street** (`street`, text, optional): Enter the name of the street the property is located on.

## Tips

* Be as accurate as possible when filling in the form.
* Use the select options provided to ensure the correct information is collected.
* Review the form carefully before submitting to avoid missing or incorrect information.
