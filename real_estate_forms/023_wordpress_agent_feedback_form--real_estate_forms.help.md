# wordpress_agent_feedback_form - Help Guide
## Purpose
The wordpress_agent_feedback_form is designed to capture feedback and ratings from agents or customers in a real estate context. It collects information on customer satisfaction and agent performance.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter your **Feedback** in the text field provided.
2. Rate your experience using the **Rating** field, which should be a number between 1 and 5.
3. Enter your **Agent Name** in the text field.
4. Provide the **Agency** name (if applicable).
5. Enter your **Email** address for contact purposes.
6. Enter your **Phone** number (if applicable).
7. Add any additional comments in the **Comments** field.
8. Select whether the submission is **Yes** or **No** for **Submitted**.
9. Select whether the submission was made by **Yes** or **No** for **Submitted By**.
10. Enter the **Date And Time** of submission.
11. Select the **Time** of submission (if applicable).
12. Enter your **Agent ID**.
13. Enter the **Form ID** (if applicable).
14. Select the **Submitted On** date.
15. Select the **Submitted At** date.
16. Rate the **Agent Rating** using the number field.
17. Select whether the **Agent** is **Yes** or **No**.
18. Select a score for **Agent Rating Score** using the multiple-select options.
19. Select the **Submission Status** as **Active** or **Inactive**.
20. Select whether the submission was made to **Yes** or **No** for **Submitted To**.
21. Select the status of the submission **Submitted By Status** as **Active** or **Inactive**.
22. Select the status of the submission **Submission Date Status** as **Active** or **Inactive**.
23. Select the status of the submission **Submission Time Status** as **Active** or **Inactive**.
24. Select the type of **Submitted By Status** as **Yes** or **No**.
