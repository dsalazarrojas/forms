# Property Rental Agreement Intake Form - Help Guide
## Purpose
This form is used to collect information about a rental property agreement, including tenant details, property characteristics, and lease terms.

## How To Complete This Form
1. Fill in the required information for each field, paying attention to the "Required" fields marked with an asterisk (\*) in the explanations below.
2. Review each field carefully and enter accurate information.
3. If you are unsure about any field, please contact the property manager or landlord for clarification.

## Field-by-Field Explanation
* **Tenant Name** (`tenant_name`, Text, Not Required): Enter the name of the tenant or renter.
* **Property Address** (`property_address`, Text, Not Required): Enter the address of the rental property.
* **Move In Date** (`move_in_date`, Date, Not Required): Enter the date the tenant moved in.
* **Rental Duration** (`rental_duration`, Number, Not Required): Enter the duration of the rental agreement in months or years.
* **Rental Type** (`rental_type`, Select One, Not Required): Choose the type of rental (e.g., month-to-month, lease, etc.).
* **Rent Amount** (`rent_amount`, Number, Not Required): Enter the monthly or annual rent amount.
* **Security Deposit** (`security_deposit`, Number, Not Required): Enter the security deposit amount.
* **Tenant Lease** (`tenant_lease`, Note, Not Required): Enter any lease terms or conditions that apply to the rental agreement.
* **Landlord Agreement** (`landlord_agreement`, Select Multiple, Not Required): Choose any agreements made with the landlord regarding the rental property.
* **Tenant Info** (`tenant_info`, Select Multiple, Required): Choose the tenant's information (e.g., age, income, employment status, etc.).
* **Property Type** (`property_type`, Select One, Required): Choose the type of property (e.g., house, apartment, condo, etc.).
* **Move In Status** (`move_in_status`, Select One, Required): Choose the move-in status (e.g., available for move-in, occupied, etc.).
* **Rental Status** (`rental_status`, Select One, Not Required): Choose the current status of the rental agreement.
* **Lease Status** (`lease_status`, Select Multiple, Not Required): Choose the lease status (e.g., active, inactive, expired, etc.).
* **Property Features** (`property_features`, Select Multiple, Not Required): Choose the features of the rental property.
* **Tenant Info 2** (`tenant_info_2`, Select Multiple, Not Required): Choose additional tenant information (e.g., renter's insurance, pet policy, etc.).
* **Tenant Info 3** (`tenant_info_3`, Select Multiple, Not Required): Choose more tenant information (e.g., smoking policy, viewings, etc.).
* **Property Status** (`property_status`, Select Multiple, Not Required): Choose the current status of the rental property.
* **Rental Notes** (`rental_notes`, Text, Not Required): Enter any additional notes or comments about the rental agreement.
* **Rent Frequency** (`rent_frequency`, Select One, Required): Choose the rent payment frequency (e.g., monthly, biweekly, etc.).
* **Rent Amount Frequency** (`rent_amount_frequency`, Select One, Not Required): Choose the rent payment frequency (e.g., monthly, annual, etc.).
* **Move Out Date** (`move_out_date`, Date, Not Required): Enter the date the tenant moved out.
* **Lease Terms** (`lease_terms`, Text, Not Required): Enter any lease terms or conditions that apply to the rental agreement.
* **Property Details** (`property_details`, Text, Not Required): Enter any additional information about the rental property.
