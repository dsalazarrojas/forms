# roofing_inspection_form - Help Guide
## Purpose
The Roofing Inspection Form is designed to collect information about the condition, structure, and venting system of a roof's chimney. This form helps roofing professionals or property owners record observations and notes during a roof inspection.

## How To Complete This Form
1. Review the roof area to be inspected.
2. Fill in the roof area number (1-100) to indicate the size of the roof.
3. Assess the condition of the chimney:
	* If there are no issues, select "Good".
	* If there are minor issues, select "Fair".
	* If there are significant issues, select "Poor".
4. Check the chimney's structure and select all applicable options (e.g., Brick, Wood, Clay).
5. Note the color of the roof:
	* Select all applicable colors (e.g., Black, Brown, Gray).
6. Record the roof's slope (if applicable).
7. Measure and record the height of the chimney (if applicable).
8. Check the venting type:
	* If the venting is positive, select "Positive".
	* If the venting is zero, select "Zero".
	* If the venting is negative, select "Negative".
9. Note the venting location:
	* If the venting is on the top, select "Top".
	* If the venting is on the side, select "Side".
	* If the venting is at the bottom, select "Bottom".

## Field-by-Field Explanation
* **Roof Area** (1): Enter the number of the roof being inspected.
* **Chimney Condition** (3): Record the condition of the chimney, considering the following options:
	+ Good: No issues.
	+ Fair: Minor issues.
	+ Poor: Significant issues.
* **Chimney Structure** (4): Select all applicable structures:
	+ Brick: Brick chimney.
	+ Wood: Wooden chimney.
	+ Clay: Clay chimney.
* **Roof Color** (5): Select all applicable colors:
	+ Black: Black roofing material.
	+ Brown: Brown roofing material.
	+ Gray: Gray roofing material.
* **Roof Slope** (6): Record the roof's slope (if applicable).
* **Chimney Height** (7): Measure and record the height of the chimney (if applicable).
* **Venting Type** (8): Check the venting type:
	+ Positive: Positive venting.
	+ Zero: Zero venting.
	+ Negative: Negative venting.
* **Venting Location** (9): Record the venting location:
	+ Top: Venting is on the top.
	+ Side: Venting is on the side.
	+ Bottom: Venting is at the bottom.
