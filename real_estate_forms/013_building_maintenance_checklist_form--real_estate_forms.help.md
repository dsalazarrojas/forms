# Building Maintenance Checklist Form - Help Guide
## Purpose
This form is used to record the completion status of regular and annual maintenance checks for a building, ensuring the building's safety and functionality.

## How To Complete This Form

1. Please fill out this form for each building's maintenance checks.
2. Start by entering the **Inspection Date**, which is the date of the last maintenance check.
3. Enter the **Property Address** in the full address format (e.g., 123 Main St, Anytown, USA).
4. Enter the **Inspector Name**, who conducted the inspection.
5. Check the status for each maintenance item, using the options provided for each field.
6. If any issues or repairs are needed, list them in the **Issues or Repairs Needed** field.
7. Finally, check the **Next Inspection Date**, if scheduled, or leave blank if not.

## Field-by-Field Explanation

* **Inspection Date (1)**: Date of maintenance check
  - Enter the date of the last maintenance check using the date picker or text format (MM/DD/YY).
* **Property Address (2)**: Full address of building
  - Enter the full address of the building, including street number and city, state, and zip code.
* **Inspector Name (3)**: Person conducting inspection
  - Enter the name of the person who conducted the inspection.
* **Property Manager (4)**: (Optional) Manager responsible for property
  - Enter the name of the property manager, if applicable.
* **-- Monthly Maintenance Checks -- (5)**: Regular maintenance items
  - This section is for regular maintenance checks performed every month.
* **HVAC Filter Checked or Replaced (6)**: Check or replace HVAC filter
  - Check the box to indicate if the HVAC filter has been checked or replaced.
* **Pest Control Treatment (7)**: Check if pest control has been treated
  - Check the box to indicate if pest control treatment has been applied.
* **Fire Extinguishers Inspected (8)**: Check if fire extinguishers are inspected
  - Check the box to indicate if fire extinguishers have been inspected.
* **Exterior Grounds Maintained (9)**: Check if exterior grounds are maintained
  - Check the box to indicate if the exterior grounds are in good condition.
* **-- Quarterly Maintenance Checks -- (10)**: Checks performed every three months
  - This section is for maintenance checks performed every quarter.
* **Plumbing Inspection Completed (11)**: Check if plumbing has been inspected
  - Check the box to indicate if the plumbing has been inspected.
* **Electrical Safety Inspection (12)**: Check if electrical safety has been inspected
  - Check the box to indicate if electrical safety has been inspected.
* **Roof Inspection (13)**: Check if roof has been inspected
  - Check the box to indicate if the roof has been inspected.
* **Windows and Door Seals Checked (14)**: Check if windows and door seals are in good condition
  - Check the box to indicate if windows and door seals are in good condition.
* **-- Annual Maintenance Items -- (15)**: Yearly comprehensive checks
  - This section is for annual maintenance checks.
* **HVAC System Service Completed (16)**: Check if HVAC system has been serviced
  - Check the box to indicate if the HVAC system has been serviced.
* **Chimney or Vent Cleaning (17)**: Check if chimney or vent has been cleaned
  - Check the box to indicate if the chimney or vent has been cleaned.
* **Professional Full Inspection (18)**: Check if professional full inspection has been completed
  - Check the box to indicate if a professional full inspection has been completed.
* **Issues or Repairs Needed (19)**: List any identified problems
  - If any issues or repairs are needed, list them here.
* **Work Orders Issued (20)**: Check if work orders have been issued
  - Check the box to indicate if work orders have been sent to contractors.
* **Next Inspection Date (21)**: Schedule next inspection date
  - Enter the scheduled date for the next inspection, if applicable.

## Tips

* Make sure to check each field carefully to ensure accurate data collection.
* If a field is not applicable, leave it blank or select "N/A" as the option.
* Use the provided options for each field to select the correct status.
* Complete this form for each building's maintenance checks.
