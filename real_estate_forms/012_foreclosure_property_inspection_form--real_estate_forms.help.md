# Foreclosure Property Inspection Form - Help Guide
## Purpose

The Foreclosure Property Inspection Form is a tool used to collect information about a property in foreclosure. This form helps real estate professionals and inspectors evaluate and analyze the property's condition and status.

## How To Complete This Form

1. Select the "Inspection Date" field to enter the date of the inspection.
2. Enter the "Address" of the property being inspected.
3. Enter the "Lender Name" and "Lender Phone" if applicable.
4. Enter the "Borrower Name" if applicable.
5. Select the "Property Type" to indicate the type of property (e.g., single-family home, apartment building, etc.).
6. Enter a brief description of the exterior of the property, including any notable features or damages.
7. Enter a brief description of the condition of the roof.
8. Enter a brief description of the foundation of the property.
9. Enter a brief description of the walls, including any notable features or damages.
10. Enter a brief description of the flooring.
11. Enter a brief description of the electrical system, including any notable features or damages.
12. Enter a brief description of the plumbing system, including any notable features or damages.
13. Enter a brief description of the heating and ventilation system.
14. Enter a brief description of the cooling system.
15. Enter a brief description of the fire safety features and systems, including fire alarms, sprinkler systems, and fire extinguishing systems.
16. Enter a brief description of the fire hydrants, emergency exit doors, and emergency exit stairs.

## Field-by-Field Explanation

* **Inspection Date (1)**: Enter the date of the inspection.
* **Address (2)**: Enter the address of the property being inspected.
* **Lender Name (3)**: Enter the name of the lender, if applicable.
* **Lender Phone (4)**: Enter the phone number of the lender, if applicable.
* **Borrower Name (5)**: Enter the name of the borrower, if applicable.
* **Property Type (6)**: Select the type of property being inspected (e.g., single-family home, apartment building, etc.).
* **Exterior (7)**: Briefly describe the exterior of the property, including notable features or damages.
* **Roof (8)**: Briefly describe the condition of the roof.
* **Foundation (9)**: Briefly describe the condition of the foundation.
* **Walls (10)**: Briefly describe the condition of the walls, including any notable features or damages.
* **Floors (11)**: Briefly describe the type and condition of the flooring.
* **Electrical (12)**: Briefly describe the electrical system, including any notable features or damages.
* **Plumbing (13)**: Briefly describe the plumbing system, including any notable features or damages.
* **Heating Ventilation Air (14)**: Briefly describe the heating and ventilation system.
* **Cooling (15)**: Briefly describe the cooling system.
* **Fire Safety (16)**: Briefly describe the fire safety features and systems, including fire alarms, sprinkler systems, and fire extinguishing systems.
* **Fire Suppression System (17)**: Briefly describe the fire suppression system.
* **Sprinkler System (18)**: Briefly describe the sprinkler system.
* **Fire Alarm System (19)**: Briefly describe the fire alarm system.
* **Fire Extinguishing System (20)**: Briefly describe the fire extinguishing system.
* **Fire Hydrants (21)**: Briefly describe the fire hydrants.
* **Fire Safety Devices (22)**: Briefly describe the fire safety devices.
* **Emergency Exit Prophets (23)**: Briefly describe the emergency exit doors.
* **Emergency Exit Doors (24)**: Briefly describe the emergency exit doors.
* **Emergency Exit Stairs (25)**: Briefly describe the emergency exit stairs.

## Tips

* Make sure to enter the date and time of the inspection accurately.
* Be thorough when describing the condition of each system and feature.
* If a system or feature is not applicable, indicate so in the description.
* Use proper grammar and spelling when filling out the form.
* Review the form carefully before submitting it.
