# Property Listing Form - Help Guide
## Purpose
This form is designed for listing properties for sale or rent in a real estate context. It is intended to be a comprehensive guide for agents, owners, or other parties to provide detailed information about a property.

## How To Complete This Form
- Fill in the required fields as accurately and thoroughly as possible.
- Use the correct format for date fields (e.g., MM/DD/YY).
- For select_one fields, choose only one option that best describes the property.
- For select_multiple fields, choose multiple options that apply to the property.

## Field-by-Field Explanation

* **Property Address** (`property_address`, text, required): Enter the property's physical address.
* **Property Type** (`property_type`, select_one, optional): Select the type of property (e.g., Residential, Commercial, Other).
* **Listing Price** (`listing_price`, number, optional): Enter the listing price of the property.
* **Listing Date** (`listing_date`, date, optional): Enter the date the property was listed.
* **Listing Status** (`listing_status`, select_one, optional): Select the current listing status (e.g., For Sale, For Rent, Sold Out).
* **Property Size** (`property_size`, text, optional): Enter the property's size (e.g., square feet).
* **Property Bedrooms** (`property_bedrooms`, number, optional): Enter the number of bedrooms in the property.
* **Property Bathrooms** (`property_bathrooms`, number, optional): Enter the number of bathrooms in the property.
* **Property Lot Size** (`property_lot_size`, number, optional): Enter the size of the property's lot or land.
* **Property Sqft** (`property_sqft`, number, optional): Enter the property's square footage.
* **Property Lot Type** (`property_lot_type`, select_one, optional): Select the type of property lot or land (e.g., Lot, Land, Other).
* **Property Features** (`property_features`, select_multiple, optional): Select any features the property has (e.g., Pool, View, Parking, Fenced).
* **Property Description** (`property_description`, text, optional): Enter a detailed description of the property.
* **Property Image** (`property_image`, text, optional): Enter the URL of the property's image.
* **Property Documents** (`property_documents`, select_multiple, optional): Select any documents available for the property (e.g., Photos, Videos, 3D Tour).
* **Property Agent** (`property_agent`, select_one, optional): Select the agent or representative handling the property.
* **Property Agency** (`property_agency`, text, optional): Enter the name of the property's agency or brokerage.
* **Property Location** (`property_location`, select_one, optional): Select the location of the property (e.g., City, State, County).
* **Property Zip** (`property_zip`, text, optional): Enter the property's zip code.
* **Property Phone** (`property_phone`, text, optional): Enter the contact phone number for the property.
* **Property Website** (`property_website`, text, optional): Enter the property's website or URL.
* **Property Facebook** (`property_facebook`, text, optional): Enter the property's Facebook page or URL.
* **Property Twitter** (`property_twitter`, text, optional): Enter the property's Twitter page or URL.
* **Property Instagram** (`property_instagram`, text, optional): Enter the property's Instagram page or URL.
* **Property Notes** (`property_notes`, text, optional): Enter any additional notes or comments about the property.

## Tips
- Review each field carefully to ensure accuracy and completeness.
- If a field is not applicable, leave it blank or mark it as "Not Applicable" if possible.
- If you need further guidance or clarification, contact your property listing team or support.
