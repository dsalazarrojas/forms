# House Appraisal Checklist Form - Help Guide

## Purpose
This form is designed to collect comprehensive information about a residential property, including its address, type, status, use, and various physical and functional characteristics. The form helps to ensure that all necessary information is gathered for accurate and thorough real estate appraisal.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the property's address in the "Home Address" field.
2. Select the type of property from the "Property Type" field (e.g., Single Family, Condo, Townhouse, Multi-Family).
3. Indicate the property's status from the "Property Status" field (e.g., Active, Sold, Under Contract, Pending).
4. Select the property's intended use from the "Property Use" field (e.g., Primary Residence, Investment, Rental, Other).
5. For fields marked as optional, you can skip them or provide additional information if applicable.

## Field-by-Field Explanation

* **Home Address**: Enter the property's street address, including house number and apartment number if applicable.
* **Property Type**: Choose the type of property (e.g., Single Family, Condo, Townhouse, Multi-Family).
* **Property Status**: Choose the current status of the property (e.g., Active, Sold, Under Contract, Pending).
* **Property Use**: Select the intended use of the property (e.g., Primary Residence, Investment, Rental, Other).
* **Lot Size**: Enter the property's lot size in square feet or acres, if applicable.
* **Lot Type**: Choose the type of lot (e.g., Residential, Commercial, Industrial).
* **Building Size**: Enter the property's building size in square feet, if applicable.
* **Number of Units**: Enter the number of units in the building, if applicable.
* **Year Built**: Enter the year the property was built, if applicable.
* **Roof Type**: Choose the type of roof (e.g., Gable, Hip, Flat).
* **Foundation Type**: Choose the type of foundation (e.g., Full Basement, Crawl Space, Pier and Beam, Slab, Other).
* **Exterior Finish**: Choose the exterior finish of the property (e.g., Stucco, Vinyl, Brick, Metal, Other).
* **Heating Systems**: Select the heating systems present in the property (e.g., Central AC, Heat Pump, Propane, None).
* **Electrical Systems**: Select the electrical systems present in the property (e.g., 200-amp service, 400-amp service, Other).
* **Plumbing Systems**: Select the plumbing systems present in the property (e.g., City, Well, Other).
* **Fire Safety Systems**: Select the fire safety systems present in the property (e.g., Smoke Detector, Fire Alarm, Sprinkler System, None).
* **Fire Safety Equipment**: Select the fire safety equipment present in the property (e.g., Fire Extinguisher, Fire Alarm System, Fire Sprinkler System, Other).
* **Security Systems**: Choose the security system present in the property (e.g., Gate, Alarm, Fence, Other).
* **Water Supply**: Choose the property's water supply source (e.g., City, Private, Well, Other).
* **Sewage Disposal**: Choose the property's sewage disposal method (e.g., City, Private, Other).
* **Garbage Disposal**: Choose the property's garbage disposal method (e.g., City, Private, Other).
* **Utility Payments**: Choose how utility payments are handled (e.g., Included, Separate, Other).
* **Taxes Paid**: Choose how taxes are paid (e.g., Included, Separate, Other).
* **Insurance Provider**: Choose the insurance provider (e.g., Included, Separate, Other).
* **Additional Info**: Provide any additional relevant information about the property not included in the previous fields.

Please note that not all fields are required, and some may only be applicable if you have specific circumstances. If you are unsure about any field, feel free to reach out for clarification.
