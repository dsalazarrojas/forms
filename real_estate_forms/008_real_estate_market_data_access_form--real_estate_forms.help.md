# Real Estate Market Data Access Form - Help Guide
## Purpose
The Real Estate Market Data Access Form is a tool used to collect information about properties and access real estate market data. Fill out this form to provide necessary details about a property and request access to relevant data.

## How To Complete This Form
1. Select the correct page (Page 1) and begin filling out the form.
2. Choose the correct option for property details.
3. Select the property's location from the available options.
4. Select the correct data access level.
5. Add any additional contact information if necessary.
6. Select the property type from the available options.
7. Indicate the property's status.
8. Add any property-specific notes if necessary.

## Field-by-Field Explanation
* **Page 1** (`real_estate_market_data_access_form_page`, text, required: false): This is the first and only page of the form.
* **Property Details** (`property_details`, select_multiple, required: false): Choose one or multiple options to describe the property's details.
* **Property Location** (`property_location`, select_one, required: false): Select the location of the property from the available options.
* **Data Access Level** (`data_access_level`, select_one, required: false): Choose the level of data access you need for the property.
* **Contact Information** (`contact_information`, note, required: false): Add any relevant contact information, if necessary.
* **Property Type** (`property_type`, select_multiple, required: false): Select the type of property from the available options.
* **Property Status** (`property_status`, select_one, required: false): Indicate the current status of the property.
* **Property Notes** (`property_notes`, note, required: false): Add any notes specific to the property, if necessary.
