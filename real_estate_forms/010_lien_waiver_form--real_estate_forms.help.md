# Lien Waiver Form - Help Guide
## Purpose
The Lien Waiver Form is used to create a document that releases a lien on a property, typically used in construction projects. This form is necessary to ensure that all relevant parties involved in the project, including contractors and homeowners, provide accurate information and agree to the terms of the lien waiver.

## How To Complete This Form
To complete this form, follow these steps:
1. Enter the contract address where the project is taking place.
2. Provide the contractor's name and contact information.
3. Select the type of license the contractor holds.
4. Enter the contract amount and release date.
5. Select the lien amount and type.
6. Enter the lien status and payment status.
7. Provide any additional notes if needed.

## Field-by-Field Explanation
* **Contract Address**: Enter the physical address of the contract location.
* **Contractor Name**: Enter the name of the contractor performing the work.
* **Contractor License**: Select the type of license the contractor holds.
* **Contract Amount**: Enter the total amount of the contract.
* **Release Date**: Enter the date the lien is to be released.
* **Lien Amount**: Enter the amount of the lien.
* **Lien Type**: Select the type of lien (Mechanics Lien, Materialman's Lien, or Stop Notice).
* **Contractor License Type**: Select the type of contractor license (General Contractor License or Special Contractor License).
* **Payment Terms**: Enter any payment terms or conditions.
* **Payment Date**: Enter the date of payment.
* **Lien File**: Enter the file number or reference for the lien.
* **Release File**: Enter the file number or reference for the release.
* **Lien Status**: Select the current status of the lien (Active or Inactive).
* **Lien Status Note**: Enter any additional notes for the lien status.
* **Payment Status**: Select the payment status (Paid or Unpaid).
* **Payment Status Note**: Enter any additional notes for the payment status.
* **Lien Date Status**: Select the status of the lien date (Active or Inactive).
* **Lien Date Status Note**: Enter any additional notes for the lien date status.
* **Contract Status**: Select the status of the contract (Complete or Partial).
* **Contract Status Note**: Enter any additional notes for the contract status.
* **Additional Notes**: Enter any additional information about the project.
