# self_assessment_property_inspection_form - Help Guide
## Purpose
The self-assessment property inspection form is used to gather information about a property's condition, any issues found, and other relevant details during a self-assessment property inspection.

## How To Complete This Form

1.  Complete all required fields.
2.  Enter the property address in the Property Address field.
3.  Check the property_type field to indicate whether the property is Yes or No.
4.  Select the inspection date in the inspection_date field.
5.  In the inspecting_party field, select Yes or No to indicate whether you are inspecting the property.
6.  Check the Property Condition field to indicate whether the property condition is Yes or No.
7.  In the Issues Found field, enter any issues found during the inspection.
8.  In the Maintenance Required field, select Yes or No to indicate whether maintenance is required.
9.  Enter any comments in the Comments field.
10.  Sign your name in the Signature field.
11.  Enter your email address in the Email Address field.
12.  Enter your phone number in the Phone Number field.
13.  If you have an uploaded file related to the property, enter the file URL in the File URL field.
14.  Enter the date in the Date Created field.
15.  Enter the name of the person who submitted the form in the Submitted By field.
16.  Enter the name of the person or organization assigned to the property in the Assigned To field.
17.  Enter the name of the tool used for the inspection in the Assigned Tool field.
18.  Enter any property notes in the Property Notes field.
19.  Select the assigned date in the Assigned Date field.
20.  Select the submitted date in the Submitted Date field.
21.  Enter the property status in the Property Status field.
22.  Enter the name of the user assigned to the property in the Assigned User field.
23.  Enter any status comments in the Status Comments field.
24.  Enter the property ID in the Property ID field.
25.  Enter the form ID in the Form ID field.

## Field-by-Field Explanation

*   **Property Address** (text, required): This is the address of the inspected property. Enter the full address where the property is located.
*   **property_type** (select_one, required): This field is used to indicate whether the property is being inspected. Select Yes or No.
*   **inspection_date** (date, required): This is the date the property was inspected.
*   **Inspecting Party** (select_multiple, required): This field is used to indicate whether you are inspecting the property. Select Yes or No.
*   **Property Condition** (select_multiple, required): This field is used to indicate the condition of the property. Select Yes or No.
*   **Issues Found** (text, required): This field is used to record any issues found during the inspection. Enter any details about the issues found.
*   **Maintenance Required** (select_multiple, required): This field is used to indicate whether maintenance is required. Select Yes or No.
*   **Comments** (text, required): This field is used for any additional comments about the property inspection.
*   **Signature** (text, required): This field is used for the inspector's signature.
*   **Email Address** (email, required): This field is used to enter your email address.
*   **Phone Number** (text, required): This field is used to enter your phone number.
*   **File Upload** (text, required): This field is used to upload files related to the property inspection.
*   **File URL** (text, required): This field is used to enter the URL of the uploaded file.
*   **Date Created** (date, required): This field is used to automatically record the date the form was created.
*   **Submitted By** (text, required): This field is used to enter the name of the person who submitted the form.
*   **Assigned To** (text, required): This field is used to enter the name of the person or organization assigned to the property.
*   **Assigned Tool** (text, required): This field is used to enter the name of the tool used for the inspection.
*   **Property Notes** (text, required): This field is used to enter any notes about the property.
*   **Assigned Date** (date, required): This field is used to record the assigned date.
*   **Submitted Date** (date, required): This field is used to record the submitted date.
*   **Property Status** (text, required): This field is used to enter the current status of the property.
*   **Assigned User** (text, required): This field is used to enter the name of the user assigned to the property.
*   **Status Comments** (text, required): This field is used to enter any status comments.
*   **Property ID** (text, required): This field is used to enter the property ID.
*   **Form ID** (text, required): This field is used to enter the form ID.
