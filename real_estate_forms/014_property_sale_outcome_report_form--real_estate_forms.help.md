# Property Sale Outcome Report Form - Help Guide

## Purpose
This form is designed to collect information on property sales outcomes, including transaction types, dates, prices, and other relevant details. It helps real estate professionals to track and record the success or failure of property sales.

## How To Complete This Form

To complete this form, please follow these steps:

1. Select the **Transaction Type** that best describes the property sale outcome.
2. Enter the **Date Of Transaction**, if applicable.
3. Enter the **Sale Price** of the property.
4. Select the **Sold By** agent or company responsible for the sale.
5. Choose the **Sale Status**, indicating whether the sale was successful or not.
6. Provide any additional **Notes** about the transaction.
7. If the sale was unsuccessful, select the **Unsuccessful Reason** that best explains why it failed.
8. Update the **Follow Up Status**, indicating any actions taken or planned to improve sales.
9. Enter the **Listing Number**, if available.
10. Provide the name of the **Listing Agent**, if applicable.
11. Enter the name of the **Sold Agent**, if applicable.

## Field-by-Field Explanation

* **Transaction Type** (`Transaction Type`, select_one): Select the type of transaction that occurred (e.g., sale, lease, or rental).
* **Date Of Transaction** (`Date Of Transaction`, date): Enter the date the transaction took place.
* **Sale Price** (`Sale Price`, number): Enter the price at which the property was sold.
* **Sold By** (`Sold By`, select_multiple): Select the agent or company responsible for the sale.
* **Sale Status** (`Sale Status`, select_one): Choose whether the sale was successful or not.
* **Notes** (`Notes`, note): Enter any additional comments or details about the transaction.
* **Unsuccessful Reason** (`Unsuccessful Reason`, select_one): If the sale was unsuccessful, select the reason that best explains why it failed.
* **Follow Up Status** (`Follow Up Status`, select_one): Update the status of any follow-up actions taken or planned.
* **Listing Number** (`Listing Number`, number): Enter the listing number of the property, if available.
* **Listing Agent** (`Listing Agent`, text): Enter the name of the agent or company responsible for listing the property.
* **Sold Agent** (`Sold Agent`, text): Enter the name of the agent or company that sold the property.
