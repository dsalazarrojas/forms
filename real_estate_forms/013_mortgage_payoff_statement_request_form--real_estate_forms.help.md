# Mortgage Payoff Statement Request Form - Help Guide
## Purpose
The Mortgage Payoff Statement Request Form is used to gather information from customers to facilitate the request process for a mortgage payoff statement.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the required fields:
	* `customer_name`
	* `customer_email`
	* `customer_phone`
	* `account_number`
	* `mortgage_number`
	* `pay_off_statement_request_date` (note: this is the date of the pay-off statement request)
2. Choose the correct request type from the `pay_off_statement_request` field.
3. Optionally, select the desired date and time for the pay-off statement request.

## Field-by-Field Explanation
* **form_title**: This field is not required but is a good place to put the name of the form for reference.
* **customer_name**: Enter the customer's name as it appears on their account.
* **customer_email**: Enter the customer's email address.
* **customer_phone**: Enter the customer's phone number.
* **account_number**: Enter the customer's account number.
* **mortgage_number**: Enter the customer's mortgage number.
* **pay_off_statement_request_date**: Enter the date the pay-off statement request is being made (e.g. 2022-01-01). 
* **pay_off_statement_request_date_2**: This field is for the second date of the pay-off statement request and is optional.
* **loan_number**: This is the customer's loan number.
* **mortgage_pay_off_statement_request**: Select "Yes" to request a pay-off statement.
* **jotform_submission_id**: This is an automatically generated unique identifier and does not need to be filled in.
* **page_number**: Enter the page number.
* **mortgage_number**: Enter the mortgage number.
* **pay_off_statement_request**: Select the type of pay-off statement request (e.g. Payoff Statement Request 1).
* **loan_number**: Enter the loan number.
* **submit**: Click this button to submit the form.
* **date**: Enter the date of the pay-off statement request.
* **time**: Enter the time of the pay-off statement request (note: only if the date field is filled in).
* **select_one**: Select "Yes" or "No" for the pay-off statement request status.
* **submit**: Click this button to submit the form.

## Tips
* Make sure to fill in all required fields.
* If you are unsure of any information, contact the account holder.
* The date and time fields are only required if the request type is selected as such.
