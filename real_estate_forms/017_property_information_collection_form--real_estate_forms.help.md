# Property Information Collection Form - Help Guide

## Purpose
The Property Information Collection Form is designed to gather essential details about a property for real estate purposes. This form will help collect accurate and comprehensive information about the property, including its address, type, price, and more. The information collected will be used for various property-related tasks, such as listing, sales, or rental listings.

## How To Complete This Form

To complete the form, follow these steps:

1. Fill in the Property Address field with the actual address of the property.
2. Select the Property Type from the options provided (Residential, Commercial, or Mixed Use).
3. Enter the Number of Bedrooms if applicable.
4. Fill in the Square Footage field with the property's total square footage.
5. Enter the Property Price, if known.
6. Enter the Year Built, if known.
7. (Optional) Provide a record of past prices for the property (Price History).
8. Fill in the Rent Price, if applicable.
9. Enter the Lease Duration, if applicable.
10. Enter the Square Footage per Room, if applicable.
11. Enter a brief Property Description to give a summary of the property.
12. Upload relevant Property Images.
13. Upload any Property Documents related to the property.
14. Select the Property Neighborhoods that apply to the property.
15. Select the Property Features that apply to the property.
16. Select the Property Status (For Sale, Rent, Sold, or Lease).
17. Select the Property Amenities that apply to the property.
18. Fill in the Property Agent's details (Agent, Phone, Email, Contact, Company, License Number).
19. Enter any other relevant information in the Other Information field.

## Field-by-Field Explanation

* **Property Address** (`property_address`): Enter the exact address of the property.
* **Property Type** (`property_type`): Select the type of property (Residential, Commercial, or Mixed Use).
* **Number of Bedrooms** (`number_of_bedrooms`): Enter the number of bedrooms in the property.
* **Square Footage** (`square_footage`): Enter the total square footage of the property.
* **Property Price** (`property_price`): Enter the current price of the property.
* **Year Built** (`year_built`): Enter the year the property was built.
* **Price History** (`list_price_history`): A record of past prices for the property (optional).
* **Rent Price** (`rent_price_per_month`): Enter the monthly rent price (if applicable).
* **Lease Duration** (`lease_duration`): Enter the length of the lease (if applicable).
* **Square Footage per Room** (`square_footage_per_room`): Enter the square footage per room (if applicable).
* **Property Description** (`property_description`): Enter a brief summary of the property.
* **Property Images** (`property_images`): Upload images of the property.
* **Property Documents** (`property_documents`): Upload any documents related to the property.
* **Property Neighbourhoods** (`list_property_neighborhoods`): Select the neighborhoods that apply to the property.
* **Property Features** (`list_property_features`): Select the features that apply to the property.
* **Property Status** (`property_status`): Select the current status of the property (For Sale, Rent, Sold, or Lease).
* **Property Amenities** (`list_property_amenities`): Select the amenities that apply to the property.
* **Property Agent** (`property_agent`): Enter the property agent's name.
* **Property Agent Phone** (`property_agent_phone`): Enter the property agent's phone number.
* **Property Agent Email** (`property_agent_email`): Enter the property agent's email.
* **Property Agent Contact** (`property_agent_contact`): Enter the property agent's contact information.
* **Property Agent Company** (`property_agent_company`): Enter the property agent's company name.
* **Property Agent License** (`property_agent_license`): Enter the property agent's license number.
* **Property Agent License Number** (`property_agent_license_number`): Enter the property agent's license number.
* **Other Information** (`list_property_other`): Enter any other relevant information about the property.
