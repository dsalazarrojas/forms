# Homeowner Complaint Form - Help Guide
## Purpose

This form is designed to collect information about issues or complaints reported by homeowners. By completing this form, you can provide a detailed account of the problem, including the date it occurred, its location, and a description of the issue.

## How To Complete This Form

1. To complete this form, simply follow the instructions and fill in the required fields.
2. Please enter the date the issue occurred in the "Issue Date" field.
3. Describe the issue in detail in the "Description" field.
4. Select the "Issue Status" field to indicate the current status of the issue.
5. If applicable, upload a picture of the issue in the "Image" field.

## Field-by-Field Explanation

* **Homeowner Complaint** (`homeowner_complaint`, text, required): This field is where you describe the issue or complaint you are reporting.
* **Issue Date** (`issue_date`, date, required): Please enter the date the issue occurred.
* **Location** (`issue_location`, text, required): Enter the location where the issue occurred.
* **Description** (`issue_description`, text, required): Describe the issue in detail.
* **Issue Status** (`issue_status`, select_one, required): Select the current status of the issue from the options: Active, Resolved, or Pending.
* **Image** (`issue_image`, text, optional): If applicable, upload a picture of the issue.
* **Issue Category** (`issue_category`, text, optional): This field is not currently used, but may be useful for categorizing complaints in the future.
* **Resolution** (`issue_resolution`, text, optional): If applicable, describe the resolution of the issue.
* **Comment** (`issue_comment`, text, optional): If applicable, enter any additional comments about the issue.
* **Reporter** (`issue_reporter`, text, optional): This field is not currently used, but may be useful for tracking issue reporters.
* **Report** (`issue_reporter`, text, optional): This field is not currently used, but may be useful for tracking issue reports.

Note: The fields marked as "optional" can be left blank, but are provided for additional information or follow-up purposes.
