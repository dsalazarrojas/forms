# open-house-form - Help Guide
## Purpose
The open-house-form is a tool to collect event information for internal use. It gathers details such as event name, date and time, location, description, and other relevant data to help with event planning and record-keeping.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the event name in the **Event Name** field.
2. Choose the date and time of the event in the **Event Date Time** field.
3. Provide the event address in the **Event Address** field.
4. Specify the event location in the **Event Location** field.
5. Enter a brief description of the event in the **Event Description** field.
6. Fill in the event website (if available) in the **Event Website** field.
7. If the event has a start date, enter it in the **Event Start Date** field.
8. If the event has an end date, enter it in the **Event End Date** field.
9. If the event spans an entire day, mark **Is All-Day Event** as 'Yes'.
10. If the event is a recurring event, select the corresponding option in the **Event Recurring** field.

## Field-by-Field Explanation

* **Event Name** (event_name): Enter the name of the event, e.g., 'Summer Open House'.
* **Event Date Time** (event_date_time): Choose the date and time of the event using the date picker.
* **Event Address** (event_address): Enter the address of the event, e.g., '123 Main St, Anytown, USA'.
* **Event Location** (event_location): Specify the location of the event, e.g., 'The Event Hall'.
* **Event Description** (event_description): Enter a brief description of the event, e.g., 'An open house event for our organization.'
* **Event Time** (event_time): This field is currently not clearly named; it's best-effort assumed to be related to the time of the event.
* **Event Website** (event_website): Enter the website related to the event, if any.
* **Event Start Date** (event_start_date) & **Event End Date** (event_end_date): These fields are likely meant to represent the start and end dates of the event. Note: These fields are not clearly marked as "From-To" or "Range" fields.
*   **Is All-Day Event** (event_all_day_event): Mark 'Yes' if the event runs all day.
*   **Event Recurring** (event_recurring): Select if the event happens again, e.g., 'Monthly'.
* **Event Start Time** (event_start_time) and **Event End Time** (event_end_time): These fields are not clearly labeled, but they seem to be related to the start and end time of the event.
