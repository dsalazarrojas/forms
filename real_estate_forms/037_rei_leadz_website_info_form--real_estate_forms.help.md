# rei_leadz_website_info_form - Help Guide
## Purpose
This form is designed to collect information about a website's status and details. It will help us better understand the website's performance and make informed decisions.

## How To Complete This Form
To fill out this form, follow these steps:
1. Enter the website domain name in the "website_domain" field.
2. Type the name of the lead in the "rei_leadz_lead" field.
3. Enter a description of the website in the "rei_leadz_website" field.
4. Select the current status of the website from the "website_status" dropdown menu.
5. Choose the type of website from the "website_type" dropdown menu. Options include website, blog, forum, social, and other.
6. Enter a brief description of the website in the "website_description" field.
7. Enter the contact email for the website in the "contact_email" field.
8. Enter the contact phone number for the website in the "contact_phone" field.

## Field-by-Field Explanation
* **website_domain**: Enter the domain name of the website (e.g., example.com).
* **rei_leadz_lead**: Type the name of the lead associated with this website.
* **rei_leadz_website**: Enter a brief description of the website.
* **website_status**: Select the current status of the website: 
  - active
  - inactive
  - pending
* **website_type**: Choose the type of website: 
  - website
  - blog
  - forum
  - social
  - other
* **website_description**: Enter a brief description of the website.
* **contact_email**: Enter the email address associated with the website contact.
* **contact_phone**: Enter the phone number associated with the website contact.
 
## Tips
- Please fill out the form only once per website.
- Make sure to enter accurate and up-to-date information.
- If you are unsure about any field, please reach out to the relevant team for guidance.
