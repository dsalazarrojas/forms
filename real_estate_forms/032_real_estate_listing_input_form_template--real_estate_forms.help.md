# real_estate_listing_input_form_template - Help Guide
## Purpose
This form is used to collect and update information about a real estate listing, including its address, features, and status. Authorized agents or property managers can use this form to add or modify listings.

## How To Complete This Form

1. **ListingSubmission**: Enter a brief description of the listing submission, including any relevant details or comments.
2. **listing_details**: Select the option that best describes the listing.
3. **listing_address**: Choose the address type from the available options.
4. **listing_features**: Enter any features or amenities of the property, such as "swimming pool" or "park view".
5. **agent_info**: Select the information about the agent or property manager responsible for the listing.
6. **property_manager_info**: Enter any additional information about the property manager.
7. **property_description**: Enter a brief description of the property.
8. **property_images**: Choose the images or media to be attached to the listing.
9. **property_video**: Choose the video to be attached to the listing.
10. **property_price**: Enter the price of the property.
11. **listing_status**: Select the status of the listing, such as "active" or "inactive".
12. **property_type**: Select the type of property, such as "house" or "apartment".
13. **property_size**: Enter the size of the property in square feet.
14. **property_beds**: Enter the number of bedrooms in the property.
15. **property_baths**: Enter the number of bathrooms in the property.
16. **property_sqft**: Enter the total square footage of the property.
17. **property_lot_sqft**: Enter the lot size in square feet.
18. **property_year_built**: Enter the year the property was built.
19. **property_year_renovated**: Enter the year the property was renovated, if any.
20. **property_zip**: Enter the zip code of the property location.
21. **agent_name**: Enter the name of the agent or property manager responsible for the listing.
22. **agent_email**: Enter the email address of the agent or property manager.
23. **agent_phone**: Enter the phone number of the agent or property manager.
24. **property_manager_name**: Enter the name of the property manager.
25. **property_manager_email**: Enter the email address of the property manager.

## Tips
* Make sure to fill out the form accurately and completely to ensure the listing is created or updated correctly.
* Review the form fields carefully to ensure you are entering the correct information for each field.
* If you are unsure about any of the fields, refer to the property owner or your supervisor for guidance.
