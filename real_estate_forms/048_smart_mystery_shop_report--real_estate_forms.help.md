# Smart Mystery Shop Report - Help Guide
## Purpose
The Smart Mystery Shop Report form is designed to capture details of a mystery shop visit in the real estate industry.

## How To Complete This Form

To complete this form, follow these steps:

1. Enter the shopper's name in the "Shopper Name" field.
2. Enter any relevant information about the shopper in the "Shopper Info" field.
3. Enter the contact number of the shopper in the "Contact Number" field.
4. Enter the apartment name in the "Apartment Name" field.
5. Enter the apartment address in the "Apartment Address" field.
6. Enter the community name in the "Community Name" field.
7. Enter the name of the leasing person in the "Leasing Person" field.
8. Enter any comments or feedback in the "Comments" field.
9. Enter the shop date and time in the "Shop Date" and "Shop Time" fields.
10. Select the shop status as "In Progress", "Completed", or "Cancelled" in the "Shop Status" field.
11. Enter any additional comments or feedback in the "Shop Comments" field.
12. Select the assigned user from the available options in the "Assigned User" field.
13. Select the shop type as "Apartment", "Townhome", or "Condo" in the "Shop Type" field.
14. Select the shop result as "Satisfactory", "Unsatisfactory", or "No Shop" in the "Shop Result" field.
15. Choose whether attachments are required or not in the "Shop Attachment" field.
16. If attachments are required, select the attachment type in the "Shop Attachment Type" field.
17. Enter any comments about the attachments in the "Shop Attachment Comment" field.
18. If attachments are not required, enter any additional comments or feedback in the "Shop Note" field.
