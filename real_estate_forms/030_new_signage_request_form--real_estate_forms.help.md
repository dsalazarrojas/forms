# new_signage_request_form - Help Guide
## Purpose
The new_signage_request_form is designed to collect information about new signage requests for real estate properties.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the category of the signage request from the "Category" field.
2. Provide a brief description of the signage request in the "Description" field.
3. If necessary, select the tool that will be used to fulfill the request from the "Assigned Tool" field.
4. Review and submit the form.

## Field-by-Field Explanation
* **Category** (Category, select_one, optional): Select the category of the signage request. For example, "Real Estate Forms".
* **Description** (Description, text, optional): Enter a brief description of the signage request.
* **Assigned Tool** (Assigned Tool, select_multiple, optional): Select the tool that will be used to fulfill the request. For example, "chatj" or "other".
