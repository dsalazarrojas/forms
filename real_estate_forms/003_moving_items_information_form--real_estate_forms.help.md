# moving-items-information-form - Help Guide

## Purpose
This form helps users provide accurate information about the items being moved. Please fill out all required fields for a thorough record of your items.

## How To Complete This Form
1. Read through each field carefully and understand its purpose.
2. Fill out the form with the relevant information for each field.
3. Double-check your entries for accuracy before submitting.

## Field-by-Field Explanation

* **Moving Items Information**: This is a brief description of the moving process for the items. This field is not required.
* **Item Description**: Provide a detailed description of the item, including its condition, brand, or any other relevant details. This field is not required.
* **Item Type**: Select the category of the item (e.g., Small furniture, Large furniture, Electronics, etc.). This field is not required.
* **Item Weight**: Enter the weight of the item. This field is not required.
* **Item Dimensions**: Select the size of the item (e.g., Small, Medium, Large). This field is not required.
* **Item Status**: Choose the status of the item (e.g., In storage, On truck, At destination). This field is not required.
* **Item Remarks**: Indicate if there are any special remarks or comments about the item. This field is not required.
* **Item Contact Person**: Enter the name of the person handling the item. This field is not required.
* **Item Contact Phone**: Enter the phone number of the person handling the item. This field is not required.
* **Item Contact Email**: Enter the email address of the person handling the item. This field is not required.

Note: All fields marked as "not required" can be left blank if the information is not available.
