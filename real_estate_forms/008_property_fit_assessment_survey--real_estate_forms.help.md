# Property Fit Assessment Survey - Help Guide
## Purpose
The Property Fit Assessment Survey is designed to help us understand your needs and preferences when searching for a property. By completing this survey, you will be able to get a better sense of whether a property fits you.

## How To Complete This Form
To complete this form, simply follow the instructions below:

1. Review each field carefully and answer all questions honestly.
2. For select fields, choose the option that best fits your needs.
3. For text fields, provide a brief explanation or description.

## Field-by-Field Explanation
### Introduction
*   **Introduction** (`introduction`, text, not required): This field is a brief introduction to the form. Please provide any additional information you want to share about your search for a property.

### Property Details
*   **Property Details** (`property_details`, text, not required): Please provide any additional information about the property you are interested in, such as its location or features.

### Does the Property Fit You?
*   **Does the property fit you?** (`fit_for_me`, select_multiple, not required) 
	+ Select 'Yes' if the property fits you.
	+ Select 'No' if the property does not fit you.
*   This field should only be completed if you answered 'Yes' to the previous field.

### Does it Match My Needs?
*   **Does it match my needs?** (`match_my_needs`, select_multiple, not required) 
	+ Select 'Yes' if the property meets your needs.
	+ Select 'No' if the property does not meet your needs.
*   This field should only be completed if you answered 'Yes' to the previous field.

### How Does it Fit Your Budget?
*   **How does it fit your budget?** (`budget`, number, not required) 
	+ Enter a number to indicate how closely the property fits your budget.

### Location
*   **Location** (`location`, text, not required): Please provide the location of the property, such as city, state, or zip code.

### Amenities
*   **Amenities** (`amenities`, select_multiple, not required) 
	+ Select 'Yes' if the property has the amenities you need.
	+ Select 'No' if the property does not have the amenities you need.
*   This field should only be completed if you have specific needs that require these amenities.

### Concerns
*   **Concerns** (`concerns`, text, not required): If you have any concerns about the property, please list them here.

### Next Steps
*   **Next Steps** (`next_steps`, note, not required): Please provide any additional information about your next steps or follow-up questions.

### Signature
*   **Signature** (`signature`, text, not required): If you would like to provide your signature, please do so in this field.

## Tips
- Make sure to answer honestly and accurately to get a good assessment of the property's fit for you. 
- If you select 'Yes' in "Does the property fit me?" field, make sure to complete the next relevant fields accordingly. 
- If you select 'No' in "Does the property fit me?" field, it is okay to leave the next fields empty. 
- You can provide any additional information that is relevant to your search for a property in the "Introduction" field.
