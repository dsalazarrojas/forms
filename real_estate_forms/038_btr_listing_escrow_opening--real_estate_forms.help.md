# BTR Listing Escrow Opening - Help Guide
## Purpose
This form is used to document and track critical information related to the escrow process for a real estate listing. 

## How To Complete This Form

1. Review the form carefully before filling it out to ensure you have all the necessary information required.
2. Enter the required fields first. Those are:
   - Listing Agent Name
   - Original Listing Date
   - Property Address
   - City
   - State and ZIP Code
   - MLS Number
   - Buyer Name
   - Buyer Agent Name
   - Offer Price
   - Offer Acceptance Date
   - Escrow Company Name
   - Escrow Number
   - Escrow Opening Date
   - Expected Closing Date
3. Fill out any optional fields if relevant:
   - Buyer Agent Name (if different from the buyer name)
   - Loan Contingency (if applicable)
   - Home Inspection Contingency (if applicable)
   - Appraisal Contingency (if applicable)
   - Special Conditions or Terms
   - Notes for Escrow

## Field-by-Field Explanation

* **Listing Agent Name** (`listing_agent_name`, `text`, required): Enter the name of the agent handling the listing.
* **Original Listing Date** (`listing_date`, `date`, required): Enter the date the property was first listed.
* **Property Address** (`property_address`, `text`, required): Enter the full address of the property.
* **City** (`city`, `text`, required): Enter the city of the property.
* **State and ZIP Code** (`state_zip`, `text`, required): Enter the state and zip code of the property.
* **MLS Number** (`mls_number`, `text`, required): Enter the MLS number for the property.
* **Buyer Name** (`buyer_name`, `text`, required): Enter the name of the buyer.
* **Buyer Agent Name** (`buyer_agent_name`, `text`, required): Enter the name of the buyer's agent.
* **Offer Price** (`offer_price`, `number`, required): Enter the price of the offer in dollars.
* **Offer Acceptance Date** (`offer_acceptance_date`, `date`, required): Enter the date the offer was accepted.
* **Escrow Company Name** (`escrow_company`, `text`, required): Enter the name of the escrow company.
* **Escrow Number** (`escrow_number`, `text`, required): Enter the number assigned by the escrow company.
* **Escrow Opening Date** (`escrow_opening_date`, `date`, required): Enter the date the escrow opened.
* **Expected Closing Date** (`closing_date`, `date`, required): Enter the estimated date of closing.
* **Loan Contingency** (`loan_contingency`, `select_one`, optional): Check if the loan contingency is included in the offer.
* **Home Inspection Contingency** (`inspection_contingency`, `select_one`, optional): Check if the home inspection contingency is included in the offer.
* **Appraisal Contingency** (`appraisal_contingency`, `select_one`, optional): Check if the appraisal contingency is included in the offer.
* **Special Conditions or Terms** (`special_conditions`, `text`, optional): Enter any unique terms or conditions in the contract.
* **Notes for Escrow** (`notes`, `text`, optional): Enter any important information for the escrow officer.

Note: If you're unsure about a specific field, please reach out to your real estate team for clarification.
