# virtual_open_houses_xperience - Help Guide
## Purpose
The virtual open house form is used to collect information from clients and agents for virtual open house experiences. This form should only be used for virtual open houses and not for other types of listings.

## How To Complete This Form
1. Ensure that you are an authorized user and that the listing is for a virtual open house.
2. Fill out the form with the required information for the virtual open house.
3. Review the form carefully to ensure all required fields are completed.

## Field-by-Field Explanation
* **Location** (Location, text, required: false): Enter the location of the virtual open house.
* **Price** (Price, number, required: false): Enter the price of the virtual open house.
* **Contact Name** (Contact name, text, required: false): Enter the name of the person contacting you for the virtual open house.
* **Contact Email** (Contact email, email, required: false): Enter the email address of the person contacting you for the virtual open house.
* **Contact Phone** (Contact phone, text, required: false): Enter the phone number of the person contacting you for the virtual open house.
* **Date of Birth** (Date of birth, date, required: false): Enter the date of birth of the person viewing the virtual open house.
* **Home Type** (Home type, select_one, required: false): Select the type of property (Single Family, Townhouse, Condo, Duplex).
* **Property Type** (Property type, select_multiple, required: false): Select the type(s) of property (Single Family, Townhouse, Condo, Duplex).
* **Home Status** (Home status, select_multiple, required: false): Select the status of the property (Active, Coming Soon, Sold, Under Contract, Off Market).
* **Virtual Viewing Date** (Virtual viewing date, date, required: false): Enter the date of the virtual viewing.
* **Virtual Viewing Time** (Virtual viewing time, time, required: false): Enter the time of the virtual viewing.
* **Showing Instructions** (Showing instructions, text, required: false): Enter any showing instructions for the virtual open house.
* **Open Houses Link** (Open houses link, text, required: false): Enter the link to the virtual open house.
* **Virtual Agent Name** (Virtual agent name, text, required: false): Enter the name of the virtual agent.
* **Virtual Agent Phone** (Virtual agent phone, text, required: false): Enter the phone number of the virtual agent.
* **Virtual Agent Email** (Virtual agent email, email, required: false): Enter the email address of the virtual agent.
* **Virtual Agent Status** (Virtual agent status, select_multiple, required: false): Select the status of the virtual agent (Active, Coming Soon, Sold, Under Contract, Off Market).

Note: All fields are optional, but required fields should be filled out for proper virtual open house experience.
