# Property Entry Notice - Help Guide
## Purpose
This form is used to collect information about a property entry notice. It is used by property owners, managers, or administrators to provide a clear and concise notice of a property entry or access request.

## How To Complete This Form
1. Fill out each field carefully and accurately to ensure that the information collected is complete and up-to-date.
2. Review the fields for any required information and ensure that it is completed before submitting the form.

## Field-by-Field Explanation
### Request Reason
* **Request Reason** (`property_entry_reason`, text, optional): This field is used to provide a brief description of the reason for the property entry or access request. It's a good idea to keep it concise and clear, about 1-2 sentences should be enough.

### Requestor
* **Requestor** (`property_entry_requestor`, text, optional): This field is used to identify the person or entity requesting access to the property. Please provide the full name of the person or entity.

### Name
* **Name** (`property_access_requestor_name`, text, required): This field is used to capture the name of the person requesting access to the property. Please use the full name of the person.

### Phone
* **Phone** (`property_access_requestor_phone`, text, required): This is the phone number of the person requesting access. It should be in the format of 10 digits.

### Email
* **Email** (`property_access_requestor_email`, email, required): This is the email address of the person requesting access. Please use a valid email format (e.g., @example.com).

### Property Address
* **Property Address** (`property_address`, text, optional): This field is used to capture the address of the property where access is requested. Please provide the full address, including street number and postal code.

### Access Request Date
* **Access Request Date** (`property_access_request_date`, date, optional): This field is used to record the date when the access was requested. Please use the format: day-month-year.

### Tips
* Ensure that all required fields are completed before submitting the form.
* Double-check the information provided to ensure it is accurate and up-to-date.
* If you are unsure about any field, please contact the property manager or administrator for guidance.
