# Mortgage Application Intake Form - Help Guide
## Purpose
This form is used to collect information from potential clients about their mortgage application.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the "User Information" page with your name, address, and any other relevant details.
2. Provide information about the property you're interested in purchasing or refinancing, on the "Property Information" page.
3. Fill out the "Loan Details" page with the specifics of the loan you're seeking, including the loan amount and down payment.
4. Enter your contact information on the "Contact Information" page.
5. If applicable, choose the type of mortgage you're interested in on the "Mortgage Type" page.
6. Enter the value of the property on the "Property Value" page.
7. Fill out the "Down Payment" page with the percentage of the down payment.
8. Finally, provide the loan amount on the "Loan Amount" page.

## Field-by-Field Explanation

* **User Information (Page 1)** (`user_input`, text, required: false):
	+ This page is used to collect your basic contact information. Please fill out your name, address, and any other relevant details.
* **Property Information (Page 2)** (`property_info`, text, required: false):
	+ This page is used to gather information about the property you're interested in. Please provide a detailed description of the property, including its address and any other relevant features.
* **Loan Details (Page 3)** (`loan_details`, text, required: false):
	+ This page is used to collect information about the loan you're seeking. Please fill out the loan amount, down payment, and any other relevant loan details.
* **Contact Information (Page 4)** (`contact_info`, text, required: false):
	+ This page is used to collect your contact information, including your phone number and email address.
* **Mortgage Type (Page 5)** (`mortgage_type`, select_one, required: false):
	+ This page is used to choose the type of mortgage you're interested in. Please select 'Yes' if you're interested in a mortgage, and 'No' otherwise.
* **Property Value (Page 6)** (`property_value`, number, required: false):
	+ This page is used to collect the value of the property. Please enter the actual value of the property.
* **Down Payment (Page 7)** (`down_payment`, number, required: false):
	+ This page is used to collect the down payment percentage. Please enter the percentage of the down payment.
* **Loan Amount (Page 8)** (`loan_amount`, number, required: false):
	+ This page is used to collect the loan amount. Please enter the actual loan amount.

## Tips
Please make sure to fill out all the required fields accurately and completely. If you're unsure about any field, please don't hesitate to ask for clarification.
