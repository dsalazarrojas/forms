# Attic Conversion Planning Permission Application Form - Help Guide
## Purpose
The Attic Conversion Planning Permission Application Form is a document that property owners and applicants use to request planning permission for attic conversions on their properties. This form helps the authorities to review and assess the plans and ensure that they comply with local regulations.

## How To Complete This Form
1. Begin by filling in the applicant information section (1-5).
   * Enter your full name and email address (2) for contact purposes.
   * Enter your phone number (4) for the authorities to contact you.
   * Enter your current address (5) so that the authorities can identify you.
2. Provide property information (7-10).
   * Enter the property address (7) for which you are seeking permission.
   * Enter the city (8), state or province (9), and ZIP or postal code (10).
3. Specify the type of property (11) you own, such as Single Family Home, Multi-Family, Townhouse, Condo, or Other.
4. Enter the estimated square footage of the property lot (12) if applicable.
5. Check if a parcel number (13) is available and enter it if so.
6. In the project information section (15-20):
   * Enter the purpose of the attic conversion (15), such as Residential Bedroom, Home Office, Rental Unit, Storage, or Other.
   * Enter the estimated attic area to be converted (16) in square feet.
   * Provide a detailed description (17) of the planned conversion.
   * Enter the proposed start and end dates (19-20) for the project.
7. In the construction timeline section (18-20):
   * Select the "Construction Timeline" note section (18) to indicate that it's not applicable.
   * Enter the proposed start date (19) and end date (20) for the project.
8. In the contractor information section (22-23):
   * Enter the name and license number (22-23) of the licensed contractor handling the project, if required.
9. Select "Yes" or "No" for "Architect or Engineer Design Required" if you know if professional design plan is required (24).
10. Finally, enter any additional notes (25) you wish to provide for your application.

## Tips
- Ensure that you have reviewed the local building code and zoning regulations before submitting this application.
- Double-check that all required fields are completed accurately and completely.
- Submit a single application per property address.
- If you are unsure about any aspect of the form, please do not hesitate to contact the relevant authorities.
