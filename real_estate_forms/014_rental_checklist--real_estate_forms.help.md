# Rental Checklist - Help Guide
## Purpose
The Rental Checklist form is used to track and manage rental properties, gathering key information about their status, rent details, and agent interactions.

## How To Complete This Form
To complete this form, follow these steps:

1. Start by filling in the address field with the property's address.
2. Select the current status of the property from the status dropdown menu.
3. If necessary, enter the rent amount and select the rent type (e.g., month-to-month, lease, fixed).
4. If the property's status has changed, select the new status and enter a reason for the change.
5. Record the date of the last status change.
6. Enter a note about the last status change.
7. If you're an agent, select your name from the agent dropdown menu and enter your phone number and email.

## Field-by-Field Explanation
- **Address** (`rental_checklist_address`, text, optional): Enter the address of the rental property.
- **Date** (`rental_checklist_date`, date, optional): Select the current date (if necessary).
- **Status** (`rental_checklist_status`, select_one, optional): Select the current status of the property (e.g., Available, Leased, Sold).
- **Rent** (`rental_checklist_rent`, number, optional): Enter the rent amount (if applicable).
- **Rent Type** (`rental_checklist_rent_type`, select_one, optional): Select the type of rent (e.g., Month-to-Month, Lease, Fixed).
- **Status Change** (`rental_checklist_status_change`, date, optional): Select the date of the status change.
- **Status Change Reason** (`rental_checklist_status_change_reason`, text, optional): Enter a reason for the status change.
- **Status Change Note** (`rental_checklist_status_change_note`, text, optional): Enter a note about the status change.
- **Last Status Change** (`rental_checklist_last_status_change`, date, optional): Select the date of the last status change.
- **Last Status Change Reason** (`rental_checklist_last_status_change_reason`, text, optional): Enter a reason for the last status change.
- **Last Status Change Note** (`rental_checklist_last_status_change_note`, text, optional): Enter a note about the last status change.
- **Agent** (`rental_checklist_agent`, select_one, optional): Select your name as the agent (if applicable).
- **Agent Phone** (`rental_checklist_agent_phone`, text, optional): Enter your phone number (if applicable).
- **Agent Email** (`rental_checklist_agent_email`, email, optional): Enter your email address (if applicable).
