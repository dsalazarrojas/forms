# free_home_evaluation - Help Guide
## Purpose
This form is used by real estate professionals to gather details about a property in need of a free home evaluation.

## How To Complete This Form
To complete this form, follow these steps:

1. Select "Yes" or "No" for questions 2-5 to indicate the status of the corresponding property features.
2. Enter the square footage of the property in question.
3. Enter the lot size of the property in question.
4. Select "Yes" or "No" for questions 6-9 to indicate the presence or absence of specific features in the property.
5. Enter the zip code of the property in question.
6. Enter your contact email address.
7. Enter your contact phone number.

## Field-by-Field Explanation
* **Free Home Evaluation (1)** (`title`, `text`, required): This is the title of the form.
* **Home Type (2)** (`home_type`, `select_one`, required): Select "Yes" if the property is a free home, "No" otherwise.
* **Property Type (3)** (`property_type`, `select_one`, required): Select "Yes" if the property is a free property, "No" otherwise.
* **Square Footage (4)** (`square_footage`, `number`, required): Enter the total square footage of the property.
* **Lot Size (5)** (`lot_size`, `number`, required): Enter the size of the property's lot.
* **Home Features (6)** (`home_features`, `select_multiple`, required): Select "Yes" if the property has any of the following features: 1) a pool, 2) a backyard, 3) a fireplace, 4) a garage.
* **Location (7)** (`location`, `select_one`, required): Select "Yes" if the property is located in a desirable location.
* **Neighborhood (8)** (`neighborhood`, `select_one`, required): Select "Yes" if the property is located in a desirable neighborhood.
* **Zip Code (9)** (`zip_code`, `select_one`, required): Enter the zip code of the property.
* **Contact Email (10)** (`contact_email`, `email`, required): Enter your email address.
* **Contact Phone (11)** (`contact_phone`, `text`, required): Enter your phone number.

Note: The required fields are marked with a red asterisk (*) in the original form schema.
