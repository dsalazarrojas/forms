# Property Survey - Help Guide
## Purpose
The Property Survey form is designed to collect comprehensive information about a property. It's used to gather details that help in the assessment, management, and evaluation of properties in various states.

## How To Complete This Form
1. Ensure you have all the required information before starting the survey.
2. Select the property type (Residential, Commercial, or Industrial) that best describes the property.
3. Choose the property structure (Single Family, Multi Family, Townhouse, Apartment, or House) that corresponds to the property.
4. Enter the property address accurately.
5. Specify the property boundaries (if any).
6. Mark whether the property has any charges (True or False).
7. Indicate whether the property offers any guarantees (True or False).
8. List the features available at the property (True or False).
9. Enter the property value accurately.
10. Choose the currency of the property value (USD, EUR, or JPY).
11. Specify the primary and secondary use of the property (Primary or Secondary).
12. Mark the property status (Active, Sold, or Leased).

## Field-by-Field Explanation

* **Property Address** (`property_address`, Text, Optional): Enter the exact address of the property.
* **Property Type** (`property_type`, Select Multiple, Optional): Select one or more types that describe the property. 
  - Residential for private residences.
  - Commercial for business properties or offices.
  - Industrial for manufacturing or production-related properties.
* **Property Structure** (`property_structure`, Select One, Optional): Choose the structure that best describes the property.
  - Single Family: A single-family home or residence.
  - Multi Family: A building with multiple residences, such as an apartment building.
  - Townhouse: A type of multi-family home with a shared side wall.
  - Apartment: A building with separate units, often with shared amenities.
  - House: A single-family home or residence.
* **Property Boundaries** (`property_boundaries`, Text, Optional): Enter any specific boundaries or restrictions for the property.
* **Charges** (`charges`, Select Multiple, Optional): Indicate if the property has any charges (True or False).
* **Guarantees** (`guarantees`, Select Multiple, Optional): Mark if the property offers any guarantees (True or False).
* **Features** (`features`, Select Multiple, Optional): Select if the property features are available (True or False).
* **Property Value** (`property_value`, Number, Optional): Enter the accurate value of the property.
* **Property Value Currency** (`property_value_currency`, Select One, Optional): Choose the currency of the property value.
  - USD: United States Dollars.
  - EUR: Euro.
  - JPY: Japanese Yen.
* **Property Use** (`property_use`, Select Multiple, Optional): Specify the primary and secondary use of the property.
  - Primary for the main purpose of the property.
  - Secondary for additional uses.
* **Property Status** (`property_status`, Select One, Optional): Mark the current status of the property.
  - Active for properties currently active and managed.
  - Sold for properties that have been sold.
  - Leased for properties leased or rented.
