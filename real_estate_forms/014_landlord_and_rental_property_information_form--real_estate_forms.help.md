# Landlord And Rental Property Information Form - Help Guide

## Purpose
This form is designed to collect information about rental properties and their landlords. It is intended to be used for administrative and organizational purposes, such as keeping track of rental property records and communicating with landlords. Please ensure that all required fields are completed before submitting the form.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the property address in the "Property Address" field.
2. Enter the city in the "Property City" field.
3. Enter the state in the "Property State" field.
4. Enter the zip code in the "Property Zip Code" field.
5. Select the type of property from the "Property Type" dropdown menu.
6. Select the property use from the "Property Use" dropdown menu.
7. Enter the rent amount in the "Rent Amount" field.
8. Enter the lease start date and end date in the "Lease Start Date" and "Lease End Date" fields, respectively.
9. Optionally, enter any additional information about the landlord and property in the "Landlord Information" and "Property Information" fields.
10. Enter the landlord's phone number in the "Landlord Phone" field.
11. Enter the landlord's email address in the "Landlord Email" field.
12. Enter the country of the property in the "Property Country" field.

## Field-by-Field Explanation
- **Property Address** (`property_address`, `text`, required: false): Enter the physical address of the rental property.
- **Property City** (`property_city`, `text`, required: false): Enter the city where the rental property is located.
- **Property State** (`property_state`, `text`, required: false): Enter the state where the rental property is located.
- **Property Zip Code** (`property_zip_code`, `text`, required: false): Enter the zip code of the rental property.
- **Property Type** (`property_type`, `select_one`, required: false): Select the type of property (house, apartment, condo, townhouse).
- **Property Use** (`property_use`, `select_one`, required: false): Select the use of the property (residential, commercial, industrial).
- **Rent Amount** (`rent_amount`, `number`, required: true): Enter the rent amount for the property.
- **Lease Start Date** (`lease_start_date`, `date`, required: false): Enter the start date of the lease.
- **Lease End Date** (`lease_end_date`, `date`, required: false): Enter the end date of the lease.
- **Landlord Information** (`landlord_info`, `note`, required: false): Enter any additional information about the landlord.
- **Landlord Phone** (`landlord_phone`, `text`, required: false): Enter the landlord's phone number.
- **Landlord Email** (`landlord_email`, `email`, required: false): Enter the landlord's email address.
- **Property Information** (`property_info`, `note`, required: false): Enter any additional information about the property.
- **Property Country** (`property_country`, `text`, required: false): Enter the country where the rental property is located.
