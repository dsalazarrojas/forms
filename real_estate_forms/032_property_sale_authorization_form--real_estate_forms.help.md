# Property Sale Authorization Form - Help Guide
## Purpose
This form is designed to facilitate the authorization process for real estate agents, ensuring accurate and consistent documentation of sales information. It is intended for agents to input relevant details about a property sale, including the sale date, commission rate, and payment terms.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the authorized agent by choosing 'Yes' or 'No' under 'Authorized Agent'.
2. Indicate the property type by selecting one or multiple options from the drop-down menu.
3. Input the sale date using the date picker.
4. Enter the agent's name.
5. Enter the commission rate as a numerical value.
6. If applicable, specify the payment terms and method.
7. Enter the sale price of the property.
8. Provide the buyer's name and contact information (optional).
9. Enter the property owner's name and contact information (optional).
10. Input the authorization date and the agent agreement date and expiration date (if applicable).
11. Choose the payment status as 'Active' or 'Inactive'.
12. Input the payment date using the date picker.
13. Select the payment method as 'Yes' or 'No'.
14. Add any additional notes about the authorization process (optional).

## Field-by-Field Explanation
* **Property Sale Authorization Form** (`property_sale_authorization_form`, text): This is the title of the form.
* **Authorized Agent** (`authorized_agent`, select_one): Select 'Yes' if you are the authorized agent for this property sale, or 'No' if you are not.
* **Property Type** (`property_type`, select_multiple): Choose one or multiple property types that apply to this sale.
* **Sale Date** (`sale_date`, date): Enter the date of the sale.
* **Agent Name** (`agent_name`, text): Enter your name as the agent.
* **Commission Rate** (`commission_rate`, number): Enter the commission rate as a numerical value.
* **Payment Terms** (`payment_terms`, text): If applicable, specify any payment terms for the sale.
* **Sale Price** (`sale_price`, text): Enter the sale price of the property.
* **Buyer** (`buyer`, text): Provide the buyer's name and contact information (optional).
* **Property Owner** (`property_owner`, text): Enter the property owner's name and contact information (optional).
* **Authorization Date** (`authorization_date`, date): Input the date of the authorization.
* **Agent Agreement Date** (`agent_agreement_date`, date): Input the date of the agent agreement.
* **Agent Agreement Expiration Date** (`agent_agreement_expiration_date`, date): Input the date of the agent agreement expiration (if applicable).
* **Payment Status** (`payment_status`, select_multiple): Choose 'Active' or 'Inactive' for the payment status.
* **Payment Date** (`payment_date`, date): Input the date of the payment.
* **Payment Method** (`payment_method`, select_one): Select 'Yes' or 'No' for the payment method.
* **Authorization Notes** (`authorization_notes`, note): Add any additional notes about the authorization process (optional).
