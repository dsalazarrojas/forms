# Property Valuation Request Form - Help Guide
## Purpose
The Property Valuation Request Form is used to gather information for a property valuation request from a real estate expert.

## How To Complete This Form
To complete this form, please follow the steps below:

1. Select the type of property you would like to request a valuation for. This will help us understand the property's characteristics.
2. Enter your name and contact information so we can get in touch with you.
3. Provide a detailed description of the property, including its address.
4. Select the date for the valuation.
5. Choose the method of valuation (e.g., Inspection, Review, or Calculation).
6. Enter the size of the property.
7. Enter any additional notes you would like to include.

## Field-by-Field Explanation

* **What kind of property?** (`type_of_property`, `select_one`, required): Please select the type of property you are requesting a valuation for. This can be Land, Office, Commercial, or Residential.
* **Client Name** (`client_name`, `text`, required): Please enter your name as it should appear on the valuation report.
* **Property Address** (`property_address`, `text`, required): Please enter the address of the property you are requesting a valuation for.
* **Description of Property** (`property_description`, `text`, required): Provide a detailed description of the property, including any unique features.
* **Property Type** (`property_type`, `select_one`, required): Please select the type of property from the list provided.
* **Property Size** (`property_size`, `number`, required): Enter the size of the property in square feet or acres.
* **Valuation Date** (`valuation_date`, `date`, required): Please select the date for the valuation.
* **Valuation Method** (`valuation_method`, `select_one`, required): Please choose the method of valuation from the list provided.
* **Client Contact Info** (`client_contact_info`, `text`, required): Please enter your contact information so we can get in touch with you.
* **Property Price** (`property_price`, `number`, required): Enter the price of the property.
* **Valuation Result** (`valuation_result`, `select_multiple`, optional): Please select the valuation result from the list provided. If you leave this blank, we will default to the best valuation result based on our analysis.
* **Additional Notes** (`notes`, `text`, optional): Please enter any additional notes or comments you would like to include with the valuation report.
* **Client Email** (`client_email`, `email`, required): Please enter your email address so we can contact you with any updates.
* **Client Phone** (`client_phone`, `text`, optional): Please enter your phone number so we can contact you with any updates.
* **Client Address** (`client_address`, `text`, optional): Please enter your mailing address so we can send you the valuation report.
* **Client Message** (`client_message`, `text`, optional): Please enter any message you would like to include with the valuation report.
* **Property Location** (`property_location`, `text`, optional): Please enter the location of the property.
* **Property Status** (`property_status`, `select_one`, optional): Please select the status of the property from the list provided.
* **Property Status Details** (`property_status_details`, `text`, optional): Please enter any additional details about the property's status.
* **Property Status Date** (`property_status_date`, `date`, optional): Please select the date of the property's status.
* **Property Price Range** (`property_price_range`, `text`, optional): Please enter the price range of the property.
* **Property Location Area** (`property_location_area`, `text`, optional): Please enter the location area of the property.
* **Property Use** (`property_use`, `text`, optional): Please enter the use of the property.
* **Valuation Type** (`valuation_type`, `select_one`, optional): Please select the type of valuation from the list provided.
* **Additional Notes** (`notes`, `text`, optional): Please enter any additional notes or comments you would like to include with the valuation report.
