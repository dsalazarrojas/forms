# Home Loan Application - Help Guide
## Purpose

This form is designed to collect information from you for a home loan application. It's divided into several sections, each covering different aspects of the loan application process.

## How To Complete This Form

- **Read each section carefully**: Understand what information is required in each section before proceeding.
- **Enter accurate information**: Ensure you provide accurate and truthful information in each field.
- **Submit your application**: Once you've completed the form, review it carefully before submitting it for review.

## Field-by-Field Explanation

### Personal Details
**Personal Details** (`personal_details`, text, required: false): Please enter your personal details, including your name, address, and contact information.

### Borrower Info
**Borrower Info** (`borrower_info`, text, required: false): Enter details about yourself, including your employment status, income, and any other relevant information.

### Employment Details
**Employment Details** (`employment_details`, text, required: false): Please enter your employment status, including your job title, employer, and employment duration.

### Income
**Income** (`income`, select_multiple, options: [Select One, Select Two], required: false): Select one or multiple income options that apply to you.

### Employment History
**Employment History** (`employment_history`, select_one, options: [Select Three, Select Four], required: false): Select your employment history from the options provided.

### Co. Borrower Info
**Co. Borrower Info** (`co_borrower_info`, select_multiple, options: [Select Five, Select Six], required: false): If you have a co-borrower, please select their options from the dropdown menu.

### Property Type
**Property Type** (`property_type`, select_one, options: [Select Seven, Select Eight], required: false): Select the type of property you're interested in purchasing.

### Loan Amount
**Loan Amount** (`loan_amount`, number, required: false): Enter the loan amount you're requesting.

### Loan Term
**Loan Term** (`loan_term`, select_one, options: [Select Nine, Select Ten], required: false): Select the loan term that suits your needs.

### Interest Rate
**Interest Rate** (`interest_rate`, number, required: false): Enter the interest rate you're comfortable with.

### Credit Score
**Credit Score** (`credit_score`, select_one, options: [Select Eleven, Select Twelve], required: false): Select your credit score from the options provided.

### Co. Borrower Credit Score
**Co. Borrower Credit Score** (`co_borrower_credit_score`, select_one, options: [Select Thirteen, Select Fourteen], required: false): If you have a co-borrower, please select their credit score from the dropdown menu.

### Co. Employment Details
**Co. Employment Details** (`co_employment_details`, text, required: false): If you have a co-borrower, please enter their employment details.

### Co. Income
**Co. Income** (`co_income`, select_one, options: [Select Fifteen, Select Sixteen], required: false): Select your co-borrower's income from the options provided.

### Property Status
**Property Status** (`property_status`, select_one, options: [Select Seventeen, Select Eighteen], required: false): Select the property status you're interested in.

### Property Type
**Property Type** (`property_type2`, select_one, options: [Select Nineteen, Select Twenty], required: false): Select the type of property you're interested in.

### Loan Terms
**Loan Terms** (`loan_terms`, select_multiple, options: [Select Twenty One, Select Twenty Two], required: false): Select the loan terms that suit your needs.

Note: Some fields are optional and can be skipped if not applicable.
