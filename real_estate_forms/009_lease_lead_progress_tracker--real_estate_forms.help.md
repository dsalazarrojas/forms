# lease lead progress tracker - Help Guide
## Purpose
This form is used to track the progress of a lease lead, including the lead source, status, follow-up details, and property information.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the lead source from the dropdown menu.
2. Choose the current status of the lead from the dropdown menu.
3. Enter the follow-up date and time, if applicable.
4. Enter the contact name, email, and phone number for the lead.
5. Enter the property name and address for the lead.
6. Choose the follow-up type (e.g., email, phone, in-person).
7. Select the follow-up frequency (e.g., daily, weekly, bi-weekly, monthly).
8. Enter the lease start and end dates, if applicable.
9. Select the lease length and type (e.g., month-to-month, week-to-week).
10. Choose the property manager responsible for the lead.
11. Enter any follow-up notes.

## Field-by-Field Explanation

* **Lead Source**: The source of the lead, such as a referral or online ad.
	+ Type: text
	+ Required: false
* **Lead Status**: The current status of the lead, such as new or qualified.
	+ Type: select_one
	+ Required: true
* **Follow Up Date**: The date of the last follow-up, if applicable.
	+ Type: date
	+ Required: false
* **Follow Up Time**: The time of the last follow-up, if applicable.
	+ Type: time
	+ Required: false
* **Contact Name**: The name of the contact person.
	+ Type: text
	+ Required: true
* **Contact Email**: The email address of the contact person.
	+ Type: email
	+ Required: true
* **Contact Phone**: The phone number of the contact person.
	+ Type: text
	+ Required: true
* **Follow Up Notes**: Any additional notes from the last follow-up.
	+ Type: note
	+ Required: false
* **Lead ID**: The unique ID of the lead.
	+ Type: text
	+ Required: true
* **Follow Up Type**: The type of follow-up, such as email or phone call.
	+ Type: select_one
	+ Required: true
* **Follow Up Frequency**: The frequency of follow-ups, such as daily or weekly.
	+ Type: select_multiple
	+ Required: true
* **Lease Start Date**: The start date of the lease, if applicable.
	+ Type: date
	+ Required: false
* **Lease End Date**: The end date of the lease, if applicable.
	+ Type: date
	+ Required: false
* **Lease Length**: The length of the lease, if applicable.
	+ Type: number
	+ Required: false
* **Lease Type**: The type of lease, such as month-to-month.
	+ Type: select_one

## Tips

* Make sure to update the form regularly to reflect changes in the lead status and follow-up details.
* Use the follow-up notes to record any additional information about the lead.
* Use the form in conjunction with other real estate forms to manage leads throughout the lease process.
