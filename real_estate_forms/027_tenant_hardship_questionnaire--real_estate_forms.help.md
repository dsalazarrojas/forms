# Tenant Hardship Questionnaire - Help Guide

## Purpose
This form is designed to collect information from tenants who are experiencing financial hardships related to their tenancy. The goal of this form is to help understand their current financial situation and make informed decisions.

## How To Complete This Form

1. Answer each question carefully and completely.
2. Please select all options that apply for the current financial situation, income affected, and unable to pay rent fields.
3. Enter your financial status and business impact as accurately as possible.
4. Attach any supporting documentation or files as required.
5. Enter your contact information (email and phone number) so we can get in touch with you.

## Field-by-Field Explanation

* **Financial Status** (`financial_status`, `select_one`, optional):
	+ Select one of the options to describe your current financial status.
* **Current Financial Situation** (`current_financial_situation`, `select_multiple`, optional):
	+ Select all options that apply to describe your current financial situation.
* **Income Affected** (`income_affected`, `number`, optional):
	+ Enter the amount of income affected by your financial hardship.
* **Business Impact** (`business_impact`, `select_one`, optional):
	+ Select one of the options to describe the impact of your financial hardship on your business.
* **Unable to Pay Rent** (`unable_to_pay_rent`, `select_multiple`, optional):
	+ Select all options that apply to describe why you are unable to pay rent.
* **Financial Assistance Request** (`financial_assistance_request`, `select_one`, optional):
	+ Select one of the options to indicate whether you are requesting financial assistance.
* **Date of Application** (`date_of_application`, `date`, optional):
	+ Enter the date you are submitting this form.
* **Note** (`note`, `note`, optional):
	+ Enter any additional comments or information you would like to provide.
* **Email** (`email`, `email`, optional):
	+ Enter your email address so we can get in touch with you.
* **Phone** (`phone`, `text`, optional):
	+ Enter your phone number so we can get in touch with you.
* **File Request** (`file_request`, `select_one`, optional):
	+ Select one of the options to indicate what type of file you would like to request.
* **Upload File** (`upload_file`, `select_multiple`, optional):
	+ Select all options that apply to describe the type of file you would like to upload.

## Tips

* Be honest and accurate when filling out this form.
* Attach any supporting documentation or files as required.
* Please note that this form is not a substitute for a formal application or request for assistance. If you are seeking financial assistance, please contact us separately and we will guide you through the process.
