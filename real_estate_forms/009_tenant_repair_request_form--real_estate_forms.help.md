# tenant_repair_request_form - Help Guide
## Purpose
The Tenant Repair Request Form is used to create and submit repair requests from tenants in a real estate context. This form helps in efficiently tracking and managing repair requests, ensuring that the issues are addressed promptly.


## How To Complete This Form
To complete the form, follow the steps below:

1.  Enter the title of the repair request.
2.  Select the category of the repair request (e.g., Real Estate Forms, Other Forms).
3.  Provide a detailed description of the repair issue.
4.  Optionally, select a form ID for identification purposes.
5.  Select the tool assigned to handle the repair request (e.g., chatjimmy, other tool).
6.  Upload or enter the output file (e.g., report, document).
7.  If applicable, specify the page number and name where the issue occurred.
8.  Choose the categories relevant to the repair request (e.g., Real Estate Forms, Other Forms).
9.  Briefly describe the repair request.
10.  Indicate whether the request was submitted by 'Yes' or 'No'.
11.  If applicable, choose 'Yes' or 'No' to confirm if the request was submitted to the correct person.


## Field-by-Field Explanation
* **Tenant Repair Request Form** (1): Enter a descriptive title for the repair request.
* **Category** (2): Choose the category relevant to the repair request (e.g., Real Estate Forms, Other Forms).
* **Description** (3): Provide a detailed description of the repair issue to help the assigned tool understand the problem.
* **Form ID** (4): Enter a unique ID for the form, if required (optional).
* **Assigned Tool** (5): Select the tool assigned to handle the repair request (e.g., chatjimmy, other tool).
* **Output File** (6): Upload or enter the output file related to the repair request (e.g., report, document).
* **Page Number** (7): If applicable, enter the page number where the issue occurred.
* **Page Name** (8): If applicable, enter the name of the page where the issue occurred.
* **Form Category** (9): Choose the categories relevant to the repair request (e.g., Real Estate Forms, Other Forms).
* **Form Description** (10): Briefly describe the repair request.
* **Submitted By** (11): Indicate whether the request was submitted by 'Yes' or 'No'.
* **Submitted To** (12): If applicable, choose 'Yes' or 'No' to confirm if the request was submitted to the correct person.
