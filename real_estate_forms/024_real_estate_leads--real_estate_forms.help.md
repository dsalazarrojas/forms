# real_estate_leads - Help Guide
## Purpose
The "real_estate_leads" form is designed to collect information about real estate leads, including lead type, source, status, agent involvement, property type, and location details. This data can be used to track and manage real estate leads effectively.

## How To Complete This Form
To complete the form, follow these steps:
1. Select the lead type by choosing from the options provided (buyer, seller, etc.).
2. Select the source of the lead by choosing from the options provided (online, referral, etc.).
3. Choose the status of the lead by selecting from the options provided (new, follow up, converted, etc.).
4. Indicate whether the lead has an assigned agent by selecting either 'Yes' or 'No'.
5. Select the type of property by choosing from the options provided (residential, commercial, industrial, etc.).
6. Enter the address of the lead.
7. Enter the ZIP code of the lead's location.
8. Enter the city of the lead's location.
9. Enter the state of the lead's location.

## Field-by-Field Explanation
* **Lead Type**: Select the type of lead (buyer, seller, etc.).
* **Lead Source**: Select the source of the lead (online, referral, etc.).
* **Lead Status**: Choose the status of the lead (new, follow up, converted, etc.).
* **Lead Agent**: Indicate whether the lead has an assigned agent ('Yes' or 'No').
* **Lead Property Type**: Select the type of property (residential, commercial, industrial, etc.).
* **Lead Address**: Enter the address of the lead.
* **Lead ZIP Code**: Enter the ZIP code of the lead's location.
* **Lead City**: Enter the city of the lead's location.
* **Lead State**: Enter the state of the lead's location.
