# House Buyers Information Checklist - Help Guide
## Purpose
This form is designed to collect relevant information from house buyers, helping them make informed decisions when purchasing or investing in properties. The fields in this form cover key characteristics of a property, ensuring buyers have the necessary data to make informed decisions.

## How To Complete This Form
To complete this form, simply fill in the required fields. Required fields are marked as "required" in the field labels. You can select options from dropdown menus or type in text fields as needed.

## Field-by-Field Explanation
* **Street address**: Enter the street address of the property. This helps identify the property's exact location.
* **Location type**: Indicate if the property is located in a specific location, such as a rural or urban area. This is usually a yes/no option.
* **Is rental** : Check if the property is a rental or owned. This helps understand the property's legal status.
* **Is furnished**: Confirm if the property is furnished or not. This can impact the purchase decision.
* **Lot size (acres)**: Enter the lot size of the property in acres, if applicable.
* **Home size (sqft)**: Enter the total size of the home in square feet, if applicable.
* **Number of bedrooms**: Enter the number of bedrooms in the property, if known.
* **Year built**: Enter the year the property was built, if available.
* **Year renovated**: Check if the property has been renovated, if applicable.
* **Property type**: Confirm if the property is for sale or rent, if available.
