# Key Release Form - Help Guide
## Purpose
The Key Release Form is used to document the release of keys to tenants or occupants of a property. This form captures essential information about the property, the release process, and the parties involved.

## How To Complete This Form

To complete this form, follow these steps:

1. Enter the tenant's name in the **tenant name** field (1).
2. Provide the property address in the **property address** field (2).
3. Enter the date of key release in the **release date** field (3).
4. If applicable, select the reason for the key release from the dropdown menu in the **reason for visit** field (7). If the reason is not listed, select "Other (please specify)" and provide a brief explanation in the **other reason** field (8).
5. Add any additional comments or notes as the tenant's signature in the **tenant signature** field (9).
6. Add any additional comments or notes as the manager's signature in the **manager signature** field (10).
7. If you are the tenant, sign your name in the **tenant signature** field to acknowledge that you have received the keys.
8. If you are the manager, sign your name in the **manager signature** field to confirm the key release.

## Field-by-Field Explanation

* **tenant name**: Enter the full name of the tenant or occupant.
* **property address**: Enter the exact address of the property.
* **release date**: Enter the date the keys were released to the tenant.
* **reason for visit**: If applicable, select the reason for the key release from the dropdown menu. Common options include "To perform maintenance on the property" and "To inspect the property."
* **other reason**: If the reason for the key release is not listed, provide a brief explanation in this field.
* **tenant signature**: This is where you, the tenant, sign to acknowledge receipt of the keys.
* **manager signature**: This is where you, the property manager, sign to confirm the key release.
* **company**: This field is optional but can be used to identify the property management company.
* **contact number**: This field is optional but can be used to capture the contact number of the property manager.
* **contact number**: This field is optional but can be used to capture the contact number of the property manager. 

Note: The **reason for visit** field is optional but is used to track the reason for the key release, if applicable. The **other reason** field can be used to capture additional information when the reason for visit is not listed in the dropdown menu.
