# property_listing_evaluation_checklist - Help Guide
## Purpose
The property listing evaluation checklist is a form used to collect information about a property, including its type, size, and contact details of the agent or owner. This form will help gather relevant data for property evaluation or assessment purposes.

## How To Complete This Form
1. Select the type of property from the options provided (House, Land, Condo, Townhouse, Apartment, or Duplex).
2. Enter the number of bedrooms.
3. Enter the number of bathrooms.
4. Enter the square footage of the property.
5. Enter the name of the agent or owner.
6. Enter the email of the agent or owner.
7. Enter the phone number of the agent or owner.
8. Enter the fax number of the agent or owner.
9. Enter the address of the property.

## Field-by-Field Explanation
- **Property Type (Property Type)**: Select the type of property from the options provided (House, Land, Condo, Townhouse, Apartment, or Duplex). 
- **Number of Bedrooms (Number of Bedrooms)**: Enter the number of bedrooms in the property.
- **Number of Bathrooms (Number of Bathrooms)**: Enter the number of bathrooms in the property.
- **Square Feet (Square Feet)**: Enter the square footage of the property.
- **Agent Name (Agent Name)**: Enter the name of the agent or owner of the property.
- **Email (Email)**: Enter the email of the agent or owner.
- **Phone (Phone)**: Enter the phone number of the agent or owner.
- **Fax (Fax)**: Enter the fax number of the agent or owner.
- **Address (Address)**: Enter the address of the property.

## Tips
- Make sure to enter accurate information to ensure reliable data for property evaluation or assessment purposes.
- Double-check the fields for correct formatting and completeness before submitting the form.
