# Airbnb Check In Check Out Policies Agreement Form - Help Guide
## Purpose
This form is designed to be a comprehensive guide for both the guest and host to review and agree upon the terms of the rental agreement. It includes all necessary information to ensure a smooth and enjoyable experience for both parties.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill in the Host's information: 
   - Host Name: Enter the full name of the host.
   - Host Email: Enter the contact email of the host.
   - Host Signature: Type in the host's digital signature.

2. Fill in the Guest's information:
   - Guest Name: Enter the full name of the guest.
   - Guest Email: Enter the contact email of the guest.
   - Guest Signature: Type in the guest's digital signature.

3. Fill in the Agreement Details:
   - Property Address: Enter the full address of the rental property.
   - Reservation Dates: Enter the check-in and check-out dates.
   - Agreement Date: Select the date of this agreement.
   - Check-in Time: Select the official check-in time.
   - Check-out Time: Select the official check-out time.
   - Late Check-in Policy: Select the policy for late arrivals.
   - Late Check-out Policy: Select the policy for late check-out.
   - Early Check-in Fee: Select the fee for early check-in, if applicable.
   - Late Check-out Fee: Select the fee for late check-out, if applicable.

4. Review and agree to the Policies:
   - Cancellation Policy: Select the agreed-upon cancellation terms.
   - Security Deposit: Select the security deposit amount.
   - Security Deposit Return: Select when the deposit is returned.
   - Smoking Policy: Select the smoking policy for the property.
   - Smoking Violation Fee: Select the fee for smoking violations, if applicable.
   - Pet Policy: Select the pet policy for the property.
   - Pet Fee: Select the fee for pets, if applicable.
   - Noise Policy: Select the quiet hours agreement.
   - Party Policy: Select the policy for events and parties.
   - Additional Guest Policy: Select the rules for extra guests.
   - Parking Policy: Select the parking arrangements.
   - Damage Policy: Select the responsibility for damages.
   - Cleaning Fee: Select the cleaning fee amount.
   - Key Policy: Select the key handling rules.
   - Lost Key Fee: Select the fee for lost keys, if applicable.
   - House Rules Acknowledged: Confirm that you have read and agree to the house rules.
   - Agreement Status: Select the current status of the agreement.
