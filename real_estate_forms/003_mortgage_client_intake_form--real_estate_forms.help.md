# Mortgage Client Intake Form - Help Guide
## Purpose
This form is designed to collect information from individuals or entities applying for a mortgage. It is meant to be completed by those applying for a mortgage to provide the necessary details for a smooth and efficient loan process.

## How To Complete This Form
1. To complete this form, please provide the requested information in the sections provided. 
2. Fill out the form carefully, ensuring all required fields (marked as **required**) are completed before proceeding.

## Field-by-Field Explanation
* **Client Information** (Client Information, text, required: false): This section is for providing general information about the client, such as name and contact details. 
* **Loan Information** (Loan Information, text, required: false): This section is for detailing the loan specifics, including loan amount and duration.
* **Contact Information** (Contact Information, text, required: false): This section is for providing contact details for the client or representative of the client.
* **Note** (Note, note, required: false): This section is for any additional comments or notes regarding the loan application.
* **Mortgage Information** (Mortgage Information, text, required: false): This section is for providing information about the mortgage, including type and interest rate.
* **Upload Documents** (Upload Documents, select multiple, required: false): This section allows you to attach relevant documents, such as PDFs, DOCX, and JPEGs, that support the loan application.
* **Agreement** (Agreement, select one, required: false): This section is for indicating the client's agreement status.
* **Submit** (Submit, text, required: true): This is the final step, where the user submits the completed form.

## Tips
* Please ensure all required fields are completed before submitting the form.
* You can upload multiple documents in the "Upload Documents" section.
* The "Agreement" field is not required, so you can indicate "No" if the client has not yet agreed to the loan terms. 
* If you need help or have questions, please contact form@gic.mx.
