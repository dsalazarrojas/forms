# House Showing Checklist - Help Guide
## Purpose
The House Showing Checklist form is designed to gather information about the condition and features of a property being shown to potential buyers.

## How To Complete This Form
1. Fill out the form for each property showing, ensuring that all fields are completed accurately and thoroughly.
2. Review each field carefully and select the most appropriate options based on your observations.
3. Submit the completed form to the property manager or real estate agent for review and processing.

## Field-by-Field Explanation

* **Property Address** (`property_address`, text, optional): Enter the address of the property being shown.
* **Condition Status** (`condition_status`, select_one, optional): Rate the overall condition of the property as:
	+ Excellent
	+ Fair
	+ Good
	+ Poor
* **Comments** (`comments`, text, optional): Enter any additional comments or observations about the property's condition.
* **Photos** (`photos`, select_multiple, optional): Select the number of photos taken during the showing:
	+ 1
	+ 2
	+ 3
	+ 4
* **Contact Information** (`contact_info`, text, optional): Enter any contact information for the property owner or manager.
* **Repairs Status** (`repairs_status`, select_one, optional): Rate the status of any needed repairs as:
	+ No
	+ Minor
	+ Major
	+ Extensive
* **Appliances** (`appliances`, select_multiple, optional): Select the appliances found at the property:
	+ Refrigerator
	+ Stove
	+ Microwave
	+ Dishwasher
* **Utilities** (`utilities`, select_multiple, optional): Select the utilities available at the property:
	+ Heat
	+ Electricity

* **Roof Condition** (`roof_condition`, select_one, optional): Rate the condition of the roof as:
	+ Excellent
	+ Fair
	+ Good
	+ Poor
* **Basement** (`basement`, select_multiple, optional): Select if the property has a basement:
	+ True
	+ False
* **Garage** (`garage`, select_multiple, optional): Select if the property has a garage:
	+ True
	+ False
* **Pool** (`pool`, select_multiple, optional): Select if the property has a pool:
	+ True
	+ False
* **Fireplace** (`fireplace`, select_multiple, optional): Select if the property has a fireplace:

	+ False
* **Deck** (`deck`, select_multiple, optional): Select if the property has a deck:

	+ False

	+ True
	+ False

	+ Hardwood
	+ Carpet
	+ Vinyl
	+ Tile
* **Ceilings** (`ceilings`, select_multiple, optional): Select the types of ceiling found at the property:
