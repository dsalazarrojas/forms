# Property Listing Request - Help Guide
## Purpose
The Property Listing Request form is designed for real estate agents and customers to submit property listings. It is meant to be used to collect detailed information about the properties and contact details of the submitter.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the Address field with the property's address.
2. Provide the City in which the property is located.
3. Select the State of the property.
4. Enter the Zip Code of the property.
5. Choose the Property Type of the property.
6. Specify the Listing Price of the property.
7. Indicate the Listing Status of the property.
8. Select the Property Size of the property.
9. Indicate the Property Features of the property (e.g., pool, garage, etc.).
10. Enter your Contact Email for communication purposes.
11. Provide your Contact Phone number.
12. Type in any additional Contact Message for our team.

## Field-by-Field Explanation
* **Address** (Text, Optional): Enter the property's address.
* **City** (Text, Optional): Enter the city where the property is located.
* **State** (Select One, Optional): Choose the state where the property is located.
* **Zip Code** (Text, Optional): Enter the zip code of the property.
* **Property Type** (Select One, Optional): Select the type of property (e.g., single-family home, condo, etc.).
* **Listing Price** (Number, Optional): Enter the listing price of the property.
* **Listing Status** (Select One, Optional): Choose the listing status of the property (e.g., Active, Inactive, etc.).
* **Property Size** (Select Multiple, Optional): Select the property's size features (e.g., Yes, No for pool, garage, etc.).
* **Property Features** (Select Multiple, Optional): Select the property's features (e.g., Yes, No for pool, garage, etc.).
* **Contact Email** (Email, Optional): Enter your contact email.
* **Contact Phone** (Text, Optional): Enter your contact phone number.
* **Contact Message** (Text, Optional): Add any additional contact message for our team.
