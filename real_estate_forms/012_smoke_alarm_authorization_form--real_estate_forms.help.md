# Smoke Alarm Authorization Form - Help Guide
## Purpose
The Smoke Alarm Authorization Form is used to authorize and track the smoke alarm systems installed in buildings for fire safety and security purposes. This form is designed to gather essential information about the smoke alarm system, including owner information, contact method, system type, and system status. The form helps ensure that all smoke alarm systems are properly installed, maintained, and inspected in accordance with local regulations and fire safety standards.

## How To Complete This Form
To complete this form, follow these steps:
1. Fill out the Owner Information section with your personal details.
2. Select the contact method (e.g., Contact Person, Contact Number, or Contact Email) from the provided options.
3. Enter the contact person's details in the Contact Person field.
4. Enter the contact number in the Contact Number field.
5. If applicable, enter the contact email address in the Contact Email field.
6. Select the type of smoke alarm system installed (e.g., Wired, Wireless, or Hardwired) from the provided options.
7. Select the current status of the smoke alarm system (e.g., Active or Inactive) from the provided options.
8. Select the location of the smoke alarm system (e.g., Bedroom, Living Room, or Kitchen) from the provided options.
9. Enter any additional fire alarm information, if necessary.
10. Enter the smoke alarm system model number.
11. Enter the smoke alarm system serial number.
12. Enter the date of manufacture of the smoke alarm system.
13. Enter the manufacture certification number of the smoke alarm system.
14. If applicable, enter the inspection date of the smoke alarm system.
15. Enter the inspection status of the smoke alarm system.
16. If applicable, enter the inspection certification number of the smoke alarm system.
17. If applicable, enter the inspection date of the smoke alarm system.
18. Click the Submit button to send the form.

## Field-by-Field Explanation

* **Owner Information**: Enter your personal details, including your name and address.
* **Building Information**: Enter any additional information about the building, if necessary.
* **Contact Method**: Select the way you want to be contacted (e.g., Contact Person, Contact Number, or Contact Email).
* **Contact Person**: Enter the name and details of the person to be contacted.
* **Contact Number**: Enter the contact number of the person to be contacted.
* **Contact Email**: Enter the contact email address of the person to be contacted, if applicable.
* **Fire Alarm System**: Enter any additional information about the fire alarm system, if necessary.
* **System Type**: Select the type of smoke alarm system installed (e.g., Wired, Wireless, or Hardwired).
* **System Status**: Select the current status of the smoke alarm system (e.g., Active or Inactive).
* **System Location**: Select the location of the smoke alarm system (e.g., Bedroom, Living Room, or Kitchen).
* **Smoke Alarm System Model**: Enter the model number of the smoke alarm system.
* **Smoke Alarm System Serial Number**: Enter the serial number of the smoke alarm system.
* **Smoke Alarm System Mfg Date**: Enter the date of manufacture of the smoke alarm system.
* **Smoke Alarm System Mfg Cert Number**: Enter the manufacture certification number of the smoke alarm system.
* **Smoke Alarm System Inspect Date**: If applicable, enter the inspection date of the smoke alarm system.
* **Smoke Alarm System Inspect Status**: If applicable, enter the inspection status of the smoke alarm system.
* **Smoke Alarm System Inspect Cert Number**: If applicable, enter the inspection certification number of the smoke alarm system.
* **Smoke Alarm System Inspect Date 2**: If applicable, enter the second inspection date of the smoke alarm system.
* **Smoke Alarm System Inspect Status 2**: If applicable, enter the second inspection status of the smoke alarm system.
* **Smoke Alarm System Inspect Cert Number 2**: If applicable, enter the second inspection certification number of the smoke alarm system.
* **Submit**: Click the Submit button to send the form.
