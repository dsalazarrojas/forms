# Move In Move Out Inspection Form - Help Guide
## Purpose
This form is used to collect information about the property's condition during move-in and move-out events. It will help track the condition of the property at the start and end of a rental period.

## How To Complete This Form
To complete this form, simply fill in the required fields. If a field is marked as optional, you can skip it if you do not have the necessary information.

## Field-by-Field Explanation
* **Address** (`address`, `text`, required): Enter the address of the property being inspected.
* **Date of Move In** (`date_of_move_in`, `date`, required): Enter the date of move-in.
* **Move In Type** (`move_in_type`, `select_one`, optional): Check 'Yes' if this is a move-in inspection, 'No' if this is a move-out inspection.
* **Property Condition** (`property_condition`, `select_multiple`, optional): Check 'Yes' if the property is in good condition, 'No' if there are any issues.
* **Electrical Systems** (`electrical_systems`, `select_multiple`, optional): Check 'Yes' if electrical systems (e.g., lights, outlets) are in working order, 'No' if there are issues.
* **Plumbing Fixtures** (`plumbing_fixtures`, `select_multiple`, optional): Check 'Yes' if plumbing fixtures (e.g., sink, toilet, shower) are in working order, 'No' if there are issues.
* **Appliances** (`appliances`, `select_multiple`, optional): Check 'Yes' if appliances (e.g., stove, refrigerator, washing machine) are in working order, 'No' if there are issues.
* **Heating Systems** (`heating_systems`, `select_multiple`, optional): Check 'Yes' if heating systems (e.g., heater, water heater) are in working order, 'No' if there are issues.
* **Cooling Systems** (`cooling_systems`, `select_multiple`, optional): Check 'Yes' if cooling systems (e.g., AC, fan) are in working order, 'No' if there are issues.
* **Flooring** (`flooring`, `select_multiple`, optional): Check 'Yes' if flooring (e.g., carpet, tile, hardwood) is in good condition, 'No' if there are issues.
* **Paint** (`paint`, `select_multiple`, optional): Check 'Yes' if walls and ceiling are painted in good condition, 'No' if there are issues.
* **Roof** (`roof`, `select_multiple`, optional): Check 'Yes' if the roof is in good condition, 'No' if there are issues.
* **Walls** (`walls`, `select_multiple`, optional): Check 'Yes' if walls are in good condition, 'No' if there are issues.
* **Ceilings** (`ceilings`, `select_multiple`, optional): Check 'Yes' if ceilings are in good condition, 'No' if there are issues.
* **Windows** (`windows`, `select_multiple`, optional): Check 'Yes' if windows are in good condition, 'No' if there are issues.
* **Doors** (`doors`, `select_multiple`, optional): Check 'Yes' if doors are in good condition, 'No' if there are issues.
* **Garage** (`garage`, `select_multiple`, optional): Check 'Yes' if the garage is in good condition, 'No' if there are issues.
* **Basement** (`basement`, `select_multiple`, optional): Check 'Yes' if the basement is in good condition, 'No' if there are issues.
* **Other** (`other`, `text`, optional): Describe any other issues or observations that were noted.
* **Inspector** (`inspector`, `text`, optional): Enter the name of the inspector who performed the inspection.
* **Date of Move Out** (`date_of_move_out`, `date`, optional): Enter the date of move-out.
* **Move Out Type** (`move_out_type`, `select_one`, optional): Check 'Yes' if this is a move-out inspection, 'No' if this is a move-in inspection.
* **Property Condition After Move Out** (`property_condition_after_move_out`, `select_multiple`, optional): Check 'Yes' if the property is in good condition after move-out, 'No' if there are issues.
* **Comments** (`comments`, `note`, optional): Enter any comments or observations about the inspection.
* **Assigned Tool** (`assigned_tool`, `text`, optional): Enter the tool used for the inspection.
