# maintenance_approval_form - Help Guide
## Purpose
The maintenance approval form is used to request and manage maintenance approvals in real estate properties. It's used to gather information about the maintenance activity, including the property type, contact information, and the duration of the maintenance activity.

## How To Complete This Form
To complete this form, follow these steps:

1. On the first page, select the type of property that the maintenance activity is for (Leasehold, Fee Simple, or Land lease).
2. Enter the contact person's first name.
3. Enter the contact person's last name.
4. Enter the contact person's email address.
5. Enter the contact person's phone number.
6. Select the start date and time for the maintenance activity.
7. Enter the duration of the maintenance activity (in hours or days).
8. Select the end date and time for the maintenance activity.
9. Enter a brief reason for the maintenance activity.
10. Enter any assigned tools used for the maintenance activity.
11. Enter any additional notes about the maintenance activity.
12. Select the current approval status of the maintenance activity (Approved, Rejected, or Pending).

## Field-by-Field Explanation

* **Maintenance Activity Type** (`Property Type`, select_one):
	+ This field is used to select the type of property that the maintenance activity is for.
* **Contact First Name** (`Contact First Name`, text):
	+ Enter the first name of the contact person.
* **Contact Last Name** (`Contact Last Name`, text):
	+ Enter the last name of the contact person.
* **Contact Email** (`Contact Email`, email):
	+ Enter the email address of the contact person.
* **Contact Phone** (`Contact Phone`, text):
	+ Enter the phone number of the contact person.
* **Start Date** (`Start Date`, date):
	+ Enter the start date of the maintenance activity.
* **Start Time** (`Start Time`, time):
	+ Enter the start time of the maintenance activity.
* **Duration** (`Duration`, text):
	+ Enter the duration of the maintenance activity in hours or days.
* **End Date** (`End Date`, date):
	+ Enter the end date of the maintenance activity.
* **End Time** (`End Time`, time):
	+ Enter the end time of the maintenance activity.
* **Reason** (`Reason`, text):
	+ Enter a brief reason for the maintenance activity.
* **Assigned Tool** (`Assigned Tool`, text):
	+ Enter any assigned tool used for the maintenance activity.
* **Notes** (`Notes`, text):
	+ Enter any additional notes about the maintenance activity.
* **Approval Status** (`Approval Status`, select_one):
	+ Select the current approval status of the maintenance activity (Approved, Rejected, or Pending).

## Tips
* Make sure to select the correct property type for the maintenance activity.
* Enter accurate contact information for the person requesting the maintenance activity.
* Enter a valid start and end date and time for the maintenance activity.
* Select the correct approval status for the maintenance activity.
* Enter any additional notes about the maintenance activity if necessary.
