# Property Information Form - Help Guide
## Purpose
This form is used to collect property information, such as address, size, type, and status, to provide a comprehensive overview of a property's details.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the required fields (marked as "Required" in the Field-by-Field Explanation section below) to the best of your ability.
2. Select the relevant options for the non-required fields (marked as "Select One" or "Select Multiple") that apply to the property.
3. Enter dates in the "Year Built" field using the standard date format (MM/DD/YYYY).

## Field-by-Field Explanation

### Property Address (1)
* **Property Address** (`property_address`, `text`, Required/Optional): Enter the address of the property, including the street number and street name.

### Building SqFt (2)
* **Building SqFt** (`building_sqft`, `text`, Required/Optional): Enter the square footage of the building.

### Lot Size (3)
* **Lot Size** (`lot_size`, `text`, Required/Optional): Enter the size of the lot, including units such as "Acres" or "Hectares".

### Lot Type (4)
* **Lot Type** (`lot_type`, `select_one`, Required/Optional): Select the type of lot, such as "Lot", "Land", "Condo", "Townhouse", or "House".

### Lot Dimensions (5)
* **Lot Dimensions** (`lot_dimensions`, `select_multiple`, Required/Optional): Select the dimensions of the lot, such as "Acres", "Hectares", or "Square Feet".

### Property Type (6)
* **Property Type** (`property_type`, `select_multiple`, Required/Optional): Select the type of property, such as "Single Family Residence", "Multi Family Residence", "Condo", or "Townhouse".

### Year Built (7)
* **Year Built** (`year_built`, `date`, Required/Optional): Enter the year the property was built using the standard date format (MM/DD/YYYY).

### Property Status (8)
* **Property Status** (`property_status`, `select_one`, Required/Optional): Select the status of the property, such as "Active", "Sold", or "Leased".

### Bedrooms (9)
* **Bedrooms** (`bedrooms`, `number`, Required/Optional): Enter the number of bedrooms in the property.

### Bathrooms (10)
* **Bathrooms** (`bathrooms`, `number`, Required/Optional): Enter the number of bathrooms in the property.

### Lot Value (11)
* **Lot Value** (`lot_value`, `text`, Required/Optional): Enter the value of the lot, if applicable.

### Sale Status (12)
* **Sale Status** (`sale_status`, `select_one`, Required/Optional): Select the sale status of the property, such as "On the Market", "Off the Market", "Sold", or "Leased".

## Tips
* Double-check your entries for accuracy before submitting the form.
* If you're unsure about any field, please contact us for assistance.
