# Real Estate Deed Delivery Form - Help Guide

## Purpose
This form is designed to collect and store information related to the delivery of real estate deeds. It is intended to be used by real estate agents, attorneys, and other professionals involved in the real estate industry to facilitate the transfer of properties.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the type of property you are dealing with (Residential, Commercial, or Mixed-Use).
2. Fill in the Property Type Value field with any additional information about the property type.
3. Enter the name of the property owner.
4. Enter the deed number, if applicable.
5. Select the date of transfer.
6. Enter the transfer fee, if applicable.
7. Enter the name of the agency handling the transaction.
8. Enter the agency's address.
9. Enter the agency's phone number.
10. Provide any additional information about the transaction in the Additional Information field.

## Field-by-Field Explanation

* **Property Type (`property_type`, select_one, required: false)**: Select the type of property involved in the transaction. This field is used to categorize the property as Residential, Commercial, or Mixed-Use.
* **Property Type Value (`property_type_value`, text, required: false)**: Enter any additional information about the property type. This field is optional, but can be used to provide more details about the property type.
* **Property Owner (`property_owner`, text, required: false)**: Enter the name of the individual or company owning the property. This field is optional, but is useful for identifying the party involved in the transaction.
* **Deed Number (`deed_number`, text, required: false)**: Enter the deed number, if applicable. This field is optional, but can be used to reference the specific deed associated with the property.
* **Date of Transfer (`date_of_transfer`, date, required: false)**: Select the date of transfer. This field is used to record the date when the property was transferred.
* **Transfer Fee (`transfer_fee`, number, required: false)**: Enter the transfer fee, if applicable. This field is optional, but can be used to record the fee associated with the transfer.
* **Agency Name (`agency_name`, text, required: false)**: Enter the name of the agency handling the transaction. This field is optional, but can be used to identify the party involved in the transaction.
* **Agency Address (`agency_address`, text, required: false)**: Enter the address of the agency handling the transaction. This field is optional, but can be used to provide contact information.
* **Agency Phone (`agency_phone`, text, required: false)**: Enter the phone number of the agency handling the transaction. This field is optional, but can be used to facilitate communication.
* **Additional Information (`real_estate_deed_delivery_form_additional_info`, text, required: false)**: Provide any additional information about the transaction. This field is optional, but can be used to capture any relevant details.
