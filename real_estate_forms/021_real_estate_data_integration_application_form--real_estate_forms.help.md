# Real Estate Data Integration Application Form - Help Guide

## Purpose
The purpose of this form is to collect real estate data for integration purposes, allowing users to provide information about properties, including property details, contact information, and agent details.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the relevant property details, such as property type and status.
2. Enter the property's address, including the street address.
3. Provide contact information for the property's agent or representative.
4. Enter the agent's contact information, including phone number and email.
5. Enter any additional property details, such as size and year built.

## Field-by-Field Explanation
### 1. Property Type (select_one, PropertyType)
* Select the type of property, such as Single Family Home, Multi Family Home, etc.

### 2. Property Status (select_one, propertyStatus)
* Select the status of the property, such as Active or Inactive.

### 3. Property Address (text, propertyAddress)
* Enter the street address of the property.

### 4. Property Address 1 (text, property_address_1)
* Enter any additional information about the property's address.

### 5. Contact Information (text, contactInformation)
* Enter any contact information for the property's agent or representative.

### 6. Phone (text, phone)
* Enter the phone number of the property's agent or representative.

### 7. Email (email, email)
* Enter the email of the property's agent or representative.

### 8. RealEstateAgency (text, realEstateAgency)
* Enter the name of the agency representing the property.

### 9. PropertyType (select_one, property_type)
* Select the type of property, such as Single Family Home, Multi Family Home, etc.

### 10. Listing Date (date, listingDate)
* Enter the date the property was listed.

### 11. Listing Type (select_one, listingType)
* Select the type of listing, such as Active or Inactive.

### 12. Property Details (text, property_details)
* Enter any additional information about the property.

### 13. Contact Person (text, contact_person)
* Enter the name of the contact person for the property.

### 14. Agent (text, agent)
* Enter the name of the agent or representative.

### 15. AgentEmail (email, agent_email)
* Enter the email of the agent or representative.

### 16. AgentPhone (text, agent_phone)
* Enter the phone number of the agent or representative.

### 17. AgentNote (text, agent_note)
* Enter any notes about the agent or representative.

### 18. ListingAgent (text, listing_agent)
* Enter the name of the listing agent.

### 19. AgentAgency (text, agent_agency)
* Enter the name of the agent's agency.

### 20. AgentPhone1 (text, agent_phone_1)
* Enter the phone number of the agent.

### 21. AgentEmail1 (email, agent_email_1)
* Enter the email of the agent.

### 22. PropertyPrice (number, property_price)
* Enter the price of the property.

### 23. PropertySize (number, property_size)
* Enter the size of the property.

### 24. PropertyYearBuilt (number, property_year_built)
* Enter the year the property was built.

Note: This help guide is a general guide and may not cover all possible scenarios or fields. If you have any further questions or need assistance, please contact us.
