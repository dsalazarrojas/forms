# Property Inspection Report - Help Guide
## Purpose
The Property Inspection Report form is designed to document the findings of a property inspector after visiting a rental property to identify any issues or problems. The form collects information about the property, the inspector, and any reported problems or recommendations.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the correct property details from the options provided.
2. Choose the property inspector from the list of available inspectors.
3. Enter the date of the inspection using the date picker.
4. If there are any reported problems, select the relevant option from the list.
5. Enter a description of the problem, if applicable.
6. Provide a recommendation for resolving the issue, if applicable.
7. Select your signature as the property inspector.
8. Enter the date of the inspection.

## Field-by-Field Explanation

* **Property Details** (`property_inspection_report_property_details`): Select the correct property details from the options provided.
* **Property Inspector** (`property_inspection_report_inspector`): Choose the property inspector from the list of available inspectors.
* **Inspection Date** (`property_inspection_report_inspection_date`): Enter the date of the inspection using the date picker.
* **Property Inspector Signature** (`property_inspection_report_inspector_signature`): Select your signature as the property inspector.
* **Property Inspector Date** (`property_inspection_report_inspector_date`): Enter the date of the inspection.
* **Reported Problem** (`property_inspection_report_reported_problem`): If there are any reported problems, select the relevant option from the list.
* **Description of Problem** (`property_inspection_report_description_of_problem`): Enter a description of the problem, if applicable.
* **Recommendation** (`property_inspection_report_recommendation`): Provide a recommendation for resolving the issue, if applicable.
* **Landlord Comments** (`property_inspection_report_landlord_comments`): Enter any feedback or comments from the landlord, if applicable.

## Tips
* Make sure to select the correct property details and inspector to ensure accurate reporting.
* Ensure that the inspection date is accurate and complete.
* If there are reported problems, provide a clear and detailed description of the issue.
* If a recommendation is made, ensure it is feasible and relevant to the problem.
* Review and verify the information entered before submitting the form.
