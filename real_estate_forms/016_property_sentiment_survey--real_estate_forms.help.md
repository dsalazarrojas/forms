# Property Sentiment Survey - Help Guide
## Purpose
The Property Sentiment Survey form is designed to collect information about a property's characteristics, such as type, sentiment about the market, location, and other relevant details. This form helps gather both numeric and non-numeric data to provide a comprehensive understanding of the property.

## How To Complete This Form
To complete this form, simply select the relevant options for each field. The form is divided into several sections, each focusing on a specific aspect of the property. Start by selecting the type of property and your sentiment about the market. If you are providing contact information, please include your email address. You can add a note if you want to provide additional comments. For date and time fields, select the corresponding date and time.

## Field-by-Field Explanation

* **Which type of property** (`property_type`, select_one, required): This field is used to select the type of property you are referring to, such as "Yes" or "No". This will help us understand the property's characteristics.
* **How do you feel about the property market** (`sentiment`, select_multiple, required): This field asks you to express your sentiment about the property market, selecting multiple options to indicate your feelings. This helps us understand your perception of the market.
* **Location** (`location`, text, optional): Please provide the location of the property you are referring to. This can be any relevant geographical information.
* **Price range** (`price_range`, number, optional): If you have a specific price range in mind, please enter it here. This helps us understand the property's price.
* **Interest rate** (`interest_rate`, number, optional): This field is used to input the interest rate of the property. If you are unsure, you can leave this field blank.
* **Mortgage rate** (`mortgage_rate`, number, optional): Similarly, this field is used to input the mortgage rate of the property. If you are unsure, you can leave this field blank.
* **Sentiment score** (`sentiment_score`, number, optional): If you have a sentiment score for the property, please input it here. This helps us understand your opinion of the property.
* **Contact info** (`contact_info`, text, optional): Please provide any contact information you have for the property, such as a phone number or address.
* **Email** (`email`, email, optional): If you have an email address associated with the property, please enter it here.
* **Note** (`note`, note, optional): This field is for any additional comments or notes about the property.
* **Time** (`time`, time, optional): If you want to provide a specific time for the property, please select the corresponding time.
* **Date** (`date`, date, optional): Select the date of the property you are referring to.
* **Date of birth** (`date_of_birth`, date, optional): This field is used to input the date of birth of the property. Note that this is not a required field.
* **Property address** (`property_address`, text, optional): Please provide the property's address.
* **Which type of property 1** (`property_type_1`, select_one, optional): Select the type of property 1 from the options provided.

## Tips
* Please ensure that all required fields are completed before submitting the form.
* You can leave optional fields blank if you are unsure or do not have the information.
* Make sure to double-check your entries for accuracy before submitting the form.
* If you have any further questions or need assistance, please don't hesitate to contact us.
