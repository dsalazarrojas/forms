# Rental Yield Calculation Form - Help Guide
## Purpose
The Rental Yield Calculation Form is a tool used to estimate the potential return on investment for a rental property.

## How To Complete This Form
1. Select the type of property (Apartment, House, or Other).
2. Input the rent and expenses for the property.
3. Select the tax rate.
4. Select 'Yes' or 'No' for each field to indicate if the income or expenses are expected to increase or not.
5. Select the gross incomes and expenses for different scenarios.
6. Click 'Calculate' to estimate the rental yield.

* This form is intended to be used as a quick estimation tool and the results should be verified by a qualified real estate professional.
* The form has multiple fields for annual increases in income and expenses, which are used to model different scenarios for the rental property.
* Select 'Yes' or 'No' for each field to indicate if the income or expenses are expected to increase or not.
