# EmploymentIncome Verification - Help Guide
## Purpose
The purpose of this form is to verify employment income for rental purposes. It helps real estate agents or property managers to gather information about the employment status and income of potential tenants before approving their rental application.

## How To Complete This Form
To complete this form, follow these steps:

1. Review the questions carefully and answer them according to the information available.
2. Fill in the required fields with the correct information.
3. Review and submit the form once you have completed all the necessary fields.

## Field-by-Field Explanation

* **Rental Verification Process**: This is a text field where you can describe the process you went through to verify the rental application.
* **Income Verification**: This is a dropdown field where you can select 'Yes' or 'No' to indicate if the income is verified.
* **Employment Verification**: This is a dropdown field where you can select 'Yes' or 'No' to indicate if the employment is verified.
* **Employment Income Verification**: This is a dropdown field where you can select 'Yes' or 'No' to indicate if the employment income is verified.
* **Income**: This is a numeric field where you can enter the income amount.
* **Employer Name**: This is a text field where you can enter the name of the employer.
* **Employer Address**: This is a text field where you can enter the address of the employer.
* **Employer Phone**: This is a text field where you can enter the phone number of the employer.
* **Employer Email**: This is an email field where you can enter the email address of the employer.
* **Employer Employment Start Date**: This is a date field where you can enter the start date of employment.

Note: Please ensure that you enter accurate and complete information to ensure that the form is completed correctly.
