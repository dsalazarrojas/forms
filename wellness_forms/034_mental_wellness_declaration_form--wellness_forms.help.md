# mental wellness declaration form - Help Guide
## Purpose
The Mental Wellness Declaration Form is a tool designed to help individuals assess their mental wellness status, identify potential symptoms, and seek support.

## How To Complete This Form
To complete this form, please follow these steps:

1. Select one or multiple mental wellness statuses that apply to you from the first page.
2. On the second page, type in any symptoms you're currently experiencing.
3. On the third page, describe your feelings in a brief note.
4. On the fourth page, select the type of mental health professional you're currently seeking help from.
5. On the fifth page, choose the types of mental health resources you're interested in accessing.
6. On the sixth page, write a note about any suicidal thoughts or concerns.
7. On the seventh page, select who you'd like to receive mental health support from.
8. On the last page, choose one or more mental health goals you'd like to achieve.

## Field-by-Field Explanation

* **Mental Wellness Status** (`Mental Wellness Status`, `select_multiple`, required: false): This section allows you to declare your current mental wellness status. Please select all that apply to you:
	+ Depression
	+ Anxiety
	+ Bipolar
* **Symptoms** (`Symptoms`, `text`, required: false): Describe any symptoms you're currently experiencing.
* **Feelings** (`Feelings`, `text`, required: false): Describe your feelings in a brief note.
* **Mental Health Professional Help** (`Mental Health Professional Help`, `select_one`, required: false): If you're seeking help from a mental health professional, please select one of the following:
	+ Counselor
	+ Therapist
	+ Doctor
* **Mental Health Resources** (`Mental Health Resources`, `select_multiple`, required: false): If you're interested in accessing mental health resources, please select all that apply:
	+ Support Groups
	+ Online Resources
	+ Self Help Apps
* **Suicidal Thoughts** (`Suicidal Thoughts`, `note`, required: false): If you're experiencing suicidal thoughts or concerns, please write a note about them.
* **Mental Health Support** (`Mental Health Support`, `select_one`, required: false): If you're seeking mental health support, please select one of the following:
	+ Family
	+ Friends
	+ Online Communities
* **Mental Health Goals** (`Mental Health Goals`, `select_multiple`, required: false): Please select one or more mental health goals you'd like to achieve:
	+ Improve Mood
	+ Manage Stress
	+ Improve Focus

## Tips
* Be honest and thorough when filling out this form.
* Please review the form carefully before submitting it to ensure accuracy.
* If you're unsure about any section, please reach out to a mental health professional for guidance.
