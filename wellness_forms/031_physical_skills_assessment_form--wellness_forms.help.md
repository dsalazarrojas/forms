# Physical Skills Assessment Form - Help Guide
## Purpose
This form is used to assess the physical skills of participants in a program or training. It captures information about their skills, comments, and contact details.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the participant's **Physical Skills Assessment** in the first section. This is a free-text field where you can enter any information about the participant's physical skills.
2. Fill in the **Participant Details** section with the participant's contact information, including **Participant Name**, **Participant Email**, **Participant Phone**, and **Program Name**.
3. Rate the participant's **Physical Skills** using the dropdown menu in the **Physical Skills Rating** section. Select a rating from 4 to 10.
4. Optionally, enter any additional comments about the participant's skills in the **Physical Skills Comments** section.
5. If applicable, enter the date and time the assessment was completed in the **Date Completed** and **Time Completed** fields.

## Field-by-Field Explanation
- **Physical Skills Assessment**: A free-text field where you can enter any information about the participant's physical skills. 
- **Participant Details**:
  - **Participant Name**: Enter the participant's name.
  - **Participant Email**: Enter the participant's email address.
  - **Participant Phone**: Enter the participant's phone number.
  - **Program Name**: Enter the name of the program the participant is enrolled in.
- **Physical Skills Rating**: Rate the participant's physical skills using the dropdown menu. Select a rating from 4 to 10.
- **Physical Skills Comments**: Optionally, enter any additional comments about the participant's skills.
- **Date Completed**: Enter the date the assessment was completed. 
- **Time Completed**: Enter the time the assessment was completed. 
- **Coaching Name**: If applicable, enter the name of the coach who conducted the assessment.
- **Program Name**: If applicable, enter the name of the program the participant is enrolled in.
