# Mind And Body Assessment Form - Help Guide
## Purpose
This form is designed to collect information about your physical and mental health, medical history, and current health status. Please answer all questions to the best of your ability.

## How To Complete This Form
1. Carefully read each question and provide detailed answers.
2. For questions with a dropdown menu, select one of the available options.
3. For questions with a text field, provide a brief but thorough answer.
4. If you are unsure about any question, you can ask for help or clarification.

## Field-by-Field Explanation
### Page 1: Physical Condition
* **Physical Condition**: (`physical_condition`, text, not required) A brief description of your current physical health status, e.g., "I am feeling good, but experiencing some muscle aches."
* **Medical History** (`medical_history`, text, not required) Describe any medical conditions you have or have had, e.g., "I have diabetes, but it's under control."
* **Current Medications** (`current_medications`, text, not required) List any medications you are currently taking.
* **Allergies** (`allergies`, text, not required) List any allergies you have, e.g., "I am allergic to penicillin."

### Page 2: Emergency Contact
* **Emergency Contact** (`emergency_contact`, select_one, not required) Identify a person to contact in case of an emergency:
	+ First name
	+ Last name
	+ Relationship (e.g., mother, father, spouse)
* **Emergency Contact Phone** (`emergency_contact_phone`, select_one, not required) Choose how to contact the emergency person:
	+ Home
	+ Work
	+ Mobile
* **Emergency Contact Email** (`emergency_contact_email`, select_one, not required) Choose how to contact the emergency person:
	+ Home
	+ Work
	+ Other (please specify)

### Page 3: Medical Status
* **Medical Conditions** (`medical_conditions`, text, not required) List any medical conditions you have or have had.
* **Past Medications** (`medications`, text, not required) List any medications you have taken.
* **Health Care Providers** (`health_care_providers`, select_multiple, not required) Identify health care providers you see regularly:
	+ Primary Care
	+ Specialist
	+ Chiropractor
* **Family History** (`family_history`, text, not required) Describe any family medical history.
* **Medical Tests** (`medical_tests`, text, not required) List any medical tests or screenings you have had.
* **Surgeries** (`surgeries`, text, not required) List any surgeries you have had.
* **Medical Devices** (`medical_devices`, text, not required) List any medical devices you use.

### Page 4: Additional Information
* **Other Medical Conditions** (`medical_conditions_other`, text, not required) Describe any other medical conditions you have or have had.
* **Other Medications** (`medications_other`, text, not required) List any other medications you have taken.
* **Other Health Care Providers** (`health_care_provider_other`, text, not required) Identify other health care providers you see regularly.
* **Other Family History** (`family_history_other`, text, not required) Describe any other family medical history.
* **Other Medical Tests** (`medical_tests_other`, text, not required) List any other medical tests or screenings you have had.
* **Other Surgeries** (`surgeries_other`, text, not required) List any other surgeries you have had.
* **Other Medical Devices** (`medical_devices_other`, text, not required) List any other medical devices you use.
