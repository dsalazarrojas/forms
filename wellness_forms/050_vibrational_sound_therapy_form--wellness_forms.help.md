# vibrational_sound_therapy_form - Help Guide
## Purpose
The Vibrational Sound Therapy Form is used to collect information about therapy sessions, including client information, session dates, time, and other relevant details.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the client's name and other relevant information.
2. Choose the session dates and times that suit your needs.
3. Select the sound therapy session type.
4. Enter any additional notes about the session.
5. Enter the client's email and phone number (if applicable).
6. Select the assigned tool, clerk, technician, and other relevant personnel.
7. Enter any comments or feedback about the session.
8. Finally, select the form ID and category.

## Field-by-Field Explanation

* **Client Information** (`client_info`, `text`, required: false): Enter the client's name, email, and other relevant details.
* **Session Dates** (`session_dates`, `select_multiple`, required: false): Select one or multiple dates for the therapy session.
* **Session Time** (`session_time`, `select_one`, required: false): Choose a time slot for the session.
* **Sound Therapy Session** (`sound_therapy_session`, `select_one`, required: false): Select whether this is a sound therapy session or not.
* **Vibrational Sounds Used** (`vibrational_sounds_used`, `text`, required: false): Enter any vibrational sounds used during the session.
* **Notes** (`notes`, `note`, required: false): Add any additional notes about the session.
* **Email** (`email`, `email`, required: false): Enter the client's email address.
* **Phone** (`phone`, `text`, required: false): Enter the client's phone number.
* **Assigned Tool** (`assigned_tool`, `select_one`, required: false): Select the tool assigned for the session.
* **Assigned Clerk** (`assigned_clerk`, `select_one`, required: false): Select the clerk assigned for the session.
* **Assigned Technician** (`assigned_technician`, `select_one`, required: false): Select the technician assigned for the session.
* **Therapist** (`therapist`, `select_one`, required: false): Select the therapist assigned for the session.
* **Assigned Counselor** (`assigned_counselor`, `select_one`, required: false): Select the counselor assigned for the session.
* **Comments** (`comments`, `text`, required: false): Enter any comments or feedback about the session.
* **Form ID** (`form_id`, `select_one`, required: false): Select a unique form ID.
* **Category** (`category`, `select_one`, required: false): Select a category for the form.
* **Description** (`description`, `note`, required: false): Enter a brief description of the session.
* **Assigned Tool 2** (`assigned_tool2`, `select_one`, required: false): Select a tool 2 assigned for the session.
* **Assigned Clerk 2** (`assigned_clerk2`, `select_one`, required: false): Select a clerk 2 assigned for the session.
* **Assigned Technician 2** (`assigned_technician2`, `select_one`, required: false): Select a technician 2 assigned for the session.
* **Assigned Counselor 2** (`assigned_counselor2`, `select_one`, required: false): Select a counselor 2 assigned for the session.
* **Assigned Counselor 3** (`assigned_counselor3`, `select_one`, required: false): Select a counselor 3 assigned for the session.
* **Assigned Technician 3** (`assigned_technician3`, `select_one`, required: false): Select a technician 3 assigned for the session.
* **Comments 2** (`comments2`, `text`, required: false): Enter any comments or feedback about the session 2.
* **Submitted By** (`submitted_by`, `select_one`, required: false): Select who submitted the form.
