# Wellness Program Subscription Form - Help Guide
## Purpose
This guide explains how to complete the Wellness Program Subscription Form. The form is used to collect information about participants who want to subscribe to wellness programs offered by the organization.

## How To Complete This Form
To complete this form, follow these steps:

1.  Fill in your name and email address in the respective fields.
2.  Select the wellness program(s) you are interested in from the list.
3.  If you are registering multiple participants, select their names from the list.
4.  Enter the start and end dates for the program.
5.  Provide any additional notes about the program in the "Program Details" and "Program Notes" fields.

## Field-by-Field Explanation
* **Participant Name** (`participant_name`, text, optional): This field is where you enter your name. If you are registering multiple participants, enter the name of each participant here.
* **Email** (`email`, email, required): This field is your email address. Please make sure to enter a valid email address.
* **Phone** (`phone`, text, optional): This field is where you enter your phone number.
* **Select Program** (`select_program`, select_multiple, optional): Choose one or more wellness programs you are interested in.
	+ Select one or more program(s) from the options provided.
* **Select Participants** (`select_participants`, select_multiple, optional): If you are registering multiple participants, select their names from the list.
	+ Select one or more participant(s) from the options provided.
* **Start Date** (`start_date`, date, optional): Enter the start date of the program. Note: This field only accepts dates in the format MM/DD/YYY.
* **End Date** (`end_date`, date, optional): Enter the end date of the program. Note: This field only accepts dates in the format MM/DD/YYY.
* **Program Details** (`program_details`, note, optional): Provide any additional notes or details about the program.
* **Program Notes** (`program_notes`, note, optional): Provide any additional notes or comments about the program.

## Tips
* Make sure to enter a valid email address in the "Email" field.
* If you are registering multiple participants, ensure that all participants' names are entered correctly in the "Select Participants" field.
* Double-check the start and end dates of the program.
* Use the "Program Details" and "Program Notes" fields to provide any additional information about the program.
