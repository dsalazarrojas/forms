# <string> - Help Guide
## Purpose
This form is designed to collect information related to events or sessions, which can be used for wellness or health-related purposes.

## How To Complete This Form
To complete this form, follow these steps:
1. Ensure you have all the required information ready, as some fields are mandatory.
2. Fill in the report date in the format specified for the date fields.
3. Enter your email address in the format of a standard email (e.g., name@domain.com).
4. Enter your name in the format you would like to be displayed.
5. Enter your phone number.
6. Enter your full address.
7. Describe the event or session you are reporting in the field "Event Emos".
8. Enter the Event ID if applicable.
9. Enter any additional notes about the event or session.
10. Enter the Session ID if applicable.
11. Select the correct timezone for the session from the dropdown options.
12. (Optional) Select any additional timezones relevant to the session.

## Field-by-Field Explanation
* **Report Date (reporting_date)**: Enter the date you are reporting this information. This field is required.
* **Email (email)**: Enter your email address where you can be reached. This field is required.
* **Name (name)**: Enter your name as you would like it to be displayed. This field is required.
* **Phone (phone)**: Enter your phone number. This field is required.
* **Address (address)**: Enter your full address. This field is required.
* **Event Emos (event_emos)**: Describe the event or session you are reporting. This field is required.
* **Event ID (event_id)**: Enter the ID of the event or session. This field is required.
* **Notes (notes)**: Enter any additional information about the event or session. This field is required.
* **Session ID (session_id)**: Enter the ID of the session. This field is required.
* **Session Time (session_time)**: Enter the time of the session in the specified format. This field is required.
* **Timezone (timezone)**: Select the correct timezone for the session from the dropdown options. This field is required.
* **Timezone 2 (timezone_2)**: Select any additional timezones relevant to the session. This field is optional.
