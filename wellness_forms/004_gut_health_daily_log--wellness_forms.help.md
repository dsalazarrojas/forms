# Gut Health Daily Log - Help Guide
## Purpose

The Gut Health Daily Log is a tool to help track and monitor your gut health. It is designed to collect information about your symptoms, habits, and behaviors related to your gut health.

## How To Complete This Form

1. Answer each question carefully and accurately, based on your experiences and conditions.
2. Select all that apply for questions that allow multiple selections.
3. Enter dates in the format MM/DD/YYYY.

## Field-by-Field Explanation

* **Morning Slog** (`morning_slog`, text, optional): Describe your morning bowel movement experience, e.g., "normal", "hard to pass stools", "diarrhea", etc.
* **Bowel Movements** (`bowel_movements`, select multiple, optional): Check all that apply for when you experience bowel movements, e.g., Morning, Afternoon, Evening.
* **Bloating** (`bloating`, select multiple, optional): Check all that apply for when you experience bloating, e.g., Morning, Afternoon, Evening.
* **Abdominal Cramps** (`abdominal_cramps`, select multiple, optional): Check all that apply for when you experience abdominal cramps, e.g., Morning, Afternoon, Evening.
* **Diarrhea** (`diarrhea_frequency`, text, optional): Describe your diarrhea experience, e.g., "none", "occasional", "frequent".
* **Abdominal Distension** (`abdominal_distension`, select multiple, optional): Check all that apply for when you experience abdominal distension, e.g., Morning, Afternoon, Evening.
* **Gas And Pain** (`gas_pain`, select one, optional): Select the level of gas and pain you experience, e.g., Mild, Moderate, Severe.
* **Stomach Upset** (`stomach_upset`, select multiple, optional): Check all that apply for when you experience stomach upset, e.g., Morning, Afternoon, Evening.
* **Nausea** (`nausea`, select one, optional): Select the level of nausea you experience, e.g., Mild, Moderate, Severe.
* **Vomiting** (`vomiting`, select one, optional): Select whether you experience vomiting, e.g., 'True', 'False'.
* **Food Intolerances** (`food_intolerances`, text, optional): Describe any food intolerances you experience, e.g., "lactose", "gluten", etc.
* **Medications** (`medications`, text, optional): List any medications you take, e.g., "ibuprofen", "antacids", etc.
* **Water Intake** (`water_intake`, text, optional): Report your daily water intake, e.g., "1-2 cups", "3 or more cups", etc.
* **Fiber Consumed** (`fiber_consumed`, select multiple, optional): Check all that apply for the amount of fiber you consume, e.g., 1, 2, 3 or more.
* **Fiber Sensitivity** (`fiber_sensitivity`, select one, optional): Select whether you experience fiber sensitivity, e.g., 'True', 'False'.
* **Probiotics Consumed** (`probiotics_consumed`, select one, optional): Select whether you take probiotics, e.g., 'True', 'False'.
* **Probiotics Sensitivity** (`probiotics_sensitivity`, select one, optional): Select whether you experience probiotics sensitivity, e.g., 'True', 'False'.
* **Supplements Consumed** (`supplements_consumed`, select one, optional): Select whether you take supplements, e.g., 'True', 'False'.
* **Supplements Sensitivity** (`supplements_sensitivity`, select one, optional): Select whether you experience supplements sensitivity, e.g., 'True', 'False'.
* **Exercise** (`exercise`, text, optional): Describe your exercise habits, e.g., "daily walking", "3-4 times a week", etc.
* **Diet** (`diet`, text, optional): Describe your diet, e.g., "balanced", "low-carb", etc.
* **Bowel Movement Frequency** (`bowel_movement_frequency`, select one, optional): Select your bowel movement frequency, e.g., 1-2, 3 or more.
* **Last Bowel Movement** (`last_bowel_movement`, date, optional): Report the date of your last bowel movement, in the format MM/DD/YYYY.
* **Last Menstrual Cycle Start** (`last_menstrual_cycle_start`, date, optional): Report the start date of your last menstruation cycle, in the format MM/DD/YYYY.
* **Comments** (`comments`, note, optional): Add any additional comments or notes about your gut health, e.g., "I have been experiencing bloating after eating certain foods", etc.
