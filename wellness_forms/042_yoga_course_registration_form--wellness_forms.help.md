# Yoga Course Registration Form - Help Guide
## Purpose
This form is for registering for a yoga course. Please fill out this form to secure your spot in the course.

## How To Complete This Form
1. Fill out the form completely and accurately.
2. Make sure to select the correct options for each field.
3. Review your form before submitting to ensure everything is correct.

## Field-by-Field Explanation
* **User Name** (text, required): Enter your full name as you would like it to be displayed in the course materials.
* **Email** (email, required): Enter your valid email address where you can be reached for course updates and communications.
* **Phone** (text, required): Enter your phone number in the standard international format (e.g., +1 202-123-4567).
* **Date** (date, optional): If you know the specific date you can register for the course, please provide it. If not, leave this blank and it will default to the current date.
* **Time** (time, optional): If you can provide the time you would like to register for, please do. Otherwise, it will default to the earliest available time.
* **Selected Time** (select multiple, required): Select all the times you are interested in attending the course.
* **Instructor** (text, optional): If you want to specify a preferred instructor for the course, enter their name here. 
* **Note** (note, optional): Enter any additional notes or comments you have about your registration here.
* **Course** (select one, optional): If this course has multiple sessions or tracks, select the one that best suits your needs. If not specified, leave blank and it will default to the first available session.
* **Form ID** (text, not required): This is a unique identifier for your form submission. Leave this blank unless specified by the form administrator. 

Please review this guide to ensure your form is completed accurately and completely before submitting it to the course administrators.
