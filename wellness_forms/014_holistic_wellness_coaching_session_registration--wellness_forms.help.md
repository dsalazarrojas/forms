# Holistic Wellness Coaching Session Registration - Help Guide
## Purpose
The Holistic Wellness Coaching Session Registration form is used to schedule and manage sessions with coaches or wellness professionals.

## How To Complete This Form
To complete this form, follow these steps:

1. Ensure you have all the necessary information about the session before starting the form.
2. Fill out all required fields, marked with a red asterisk (*) or labeled as "required."
3. Select the coach and location for the session from the available options.
4. Enter any additional notes or comments about the session.

## Field-by-Field Explanation
* **New Session** (1/10, number, required/optional): This field is used to identify the session number. If this is a new session, enter a unique number. If you're unsure, leave this field blank to be assigned a default number.
* **Full Name** (2/10, text, required/optional): Enter the full name of the individual or organization registering for the session.
* **Email** (3/10, email, required/optional): Enter the email address associated with the registration.
* **Phone Number** (4/10, text, required/optional): Enter the phone number of the individual or organization registering for the session.
* **Session Date** (5/10, date, required/optional): Select the date for the coaching session using the date picker or enter it manually. 
* **Session Time** (6/10, time, required/optional): Select the time for the coaching session using the time picker or enter it manually.
* **Session Duration** (7/10, number, required/optional): Enter the duration of the session.
* **Coach** (8/10, select_one, required/optional): Select the coach or wellness professional for the session from the available options.
* **Notes** (9/10, note, required/optional): Add any additional comments or notes about the session, such as special instructions or requirements.
* **Session Location** (10/10, select_multiple, required/optional): Select the location for the session from the available options.

## Tips
* If you're unsure about any of the fields, you can ask the administrative staff or coach for guidance.
* Ensure that all fields are accurate and complete before submitting the form.
* Review the form carefully to avoid mistakes or errors.
* Save a copy of the completed form for your records.
