# Membership Nomination Form - Help Guide
## Purpose
The Membership Nomination Form is used by members to nominate their graduation ceremony.

## How To Complete This Form

To complete this form, follow these steps:

1. Select the graduation category from the list provided in the first page.
2. Fill out the graduation date, if applicable.
3. Enter the graduation organizer's name and contact information.
4. Identify the graduate's name and contact information.
5. Fill out any additional information required for the graduation ceremony.

## Field-by-Field Explanation

* **graduation_nomination_form** (select multiple):
  This is a list of graduation categories from which you can select one or more.
  You can select multiple graduation categories to nominate multiple members for the ceremony.
  Examples: Graduators, Gradus, Grads.
* **graduation_nominator** (select one):
  This is the name of the person who will be nominated for the graduation ceremony.
  Please select the name from the provided options, which are typically the graduate's name.
* **graduation_date** (date):
  If applicable, please enter the graduation date to help the membership team with planning.
  This field is optional but can be useful for precise planning.
* **graduation_organizer** (select one):
  This is the name of the person who will be responsible for organizing the graduation ceremony.
  Please select from the provided options.
* **graduation_organizer_email** (email):
  Enter the email address of the graduation organizer for communication purposes.
  This field is optional but recommended for smooth communication.
* **graduation_organizer_phone** (text):
  Enter the phone number of the graduation organizer for contact purposes.
  This field is optional but recommended.
* **graduation_nominator_email** (email):
  Enter the email address of the graduation nominator for communication purposes.
  This field is optional but recommended for smooth communication.
* **graduation_nominator_phone** (text):
  Enter the phone number of the graduation nominator for contact purposes.
  This field is optional but recommended.

## Tips

- Please ensure that the information provided is accurate and up-to-date.
- If you are unsure about any of the fields, contact the membership team for assistance.
- The graduation ceremony will be scheduled once all nominations have been confirmed.
- The membership team will keep you informed about any updates or changes to the ceremony.
