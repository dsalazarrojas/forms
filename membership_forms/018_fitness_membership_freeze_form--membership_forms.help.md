# Fitness Membership Freeze Form - Help Guide
## Purpose
The Fitness Membership Freeze Form is used to freeze a membership. This form helps fitness center administrators to freeze a membership for a specific date and assign it to a particular user for review. The form is used to provide a clear reason for freezing the membership and to keep track of the frozen membership details.

## How To Complete This Form

1. Select the membership to freeze using the "Membership ID" field.
2. Enter the date you want to freeze the membership by filling in the "Date" field.
3. Provide a reason for freezing the membership in the "Reason" field.
4. If necessary, add any additional comments or notes regarding the frozen membership in the "Comments" field.
5. Optionally, select the user you want to assign the freeze to in the "Assigned to" field.
6. Click the "Submit" button to complete the form.

## Field-by-Field Explanation

* **Freeze membership (Membership Freeze)**: A field to select the membership to be frozen. Use the "Membership ID" dropdown to select the membership you want to freeze. This will automatically display the membership details.
* **Date**: The date you want to freeze the membership. Enter the date using the standard date format (e.g., 2022-01-01).
* **Membership ID**: A dropdown field to select the membership to be frozen.
* **Reason**: Provide a clear and concise reason for freezing the membership.
* **Email**: This field is not currently used for this form and is not required.
* **Phone**: This field is not used in the freeze process and is not required.
* **Notes**: Any additional comments or notes regarding the frozen membership can be entered in this field.
* **Comments**: Any additional comments regarding the frozen membership can be entered in this field.
* **Assigned to**: Select the user to whom you want to assign the frozen membership for review. Multiple users can be selected.
* **Submit**: Click this button to complete the form and freeze the membership.

## Tips

* Make sure to select the correct membership and date to freeze the membership accurately.
* Provide clear and concise reasons for freezing the membership.
* Select the correct user to assign the freeze to for review.
* Ensure that all required fields are completed before submitting the form. 

Please note that the form does not require any additional information from the end-users except for some fields which are marked as not required.
