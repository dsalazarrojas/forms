# public_speakers_club_membership_form - Help Guide

## Purpose
This form is designed to collect information from prospective members of the public speakers club. The data collected will be used to create a member profile, which will be used for club communication and membership management.

## How To Complete This Form
To complete this form, simply fill in the required fields with the requested information.

## Field-by-Field Explanation
- **Prospective member**: This field is a free-form text field where you can provide any relevant information about the prospective member.
- **Name**: Please enter the name of the prospective member.
- **Email**: Enter the email address of the prospective member.
- **Phone**: Enter the phone number of the prospective member.
- **Member since**: Select the date the prospective member has been a member of the club (if applicable).
- **Role**: Select whether the prospective member is a "Member" or "Non-member".
- **Organization**: Enter the name of the organization (if applicable) affiliated with the prospective member.

## Tips
- Make sure to fill in all required fields.
- Enter accurate and up-to-date information.
- If you are unsure about any field, please contact the club administration for clarification.
