# nap_form_online_hillside_cf - Help Guide

## Purpose
The "nap_form_online_hillside_cf" form is designed to facilitate the creation and management of online hillside memberships. This guide will walk you through the process of filling out the form and explain each field in detail.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the "Form Title" field with a descriptive name for the membership form.
2. Select the membership status in the "Membership Fields" section by choosing "Yes" or "No".
3. Enter a brief description of the form in the "Form Description" field.
4. Choose the assigned tool for the membership form.
5. Select the category for the membership form.
6. Enter the form ID, which is a unique identifier for the form.
7. Provide a description of the form in the "Description" field.
8. Enter the output file name and extension (e.g., "file.txt").

## Field-by-Field Explanation

* **Form Title** (`form_title`, `text`, required: false): Enter a descriptive title for the membership form. This will be displayed in the form header.
* **Membership Fields** (`membership_fields`, `select_multiple`, required: false): Choose "Yes" if the form is associated with membership, "No" otherwise.
* **Form Description** (`form_description`, `note`, required: false): Enter a brief description of the membership form for reference.
* **Assigned Tool** (`assigned_tool`, `select_one`, required: false): Select the tool assigned to the membership form from the options provided.
* **Category** (`category`, `select_one`, required: false): Choose the category for the membership form from the options provided.
* **Form ID** (`form_id`, `number`, required: false): Enter a unique ID for the form. This is not a required field, but recommended for identification purposes.
* **Description** (`description`, `text`, required: false): Enter a description of the membership form for reference.
* **Output File** (`output_file`, `text`, required: false): Enter the output file name and extension (e.g., "file.txt").

## Tips
- Make sure to fill out the form accurately to ensure correct processing and reporting.
- If you are unsure about any field, refer to the internal guidance on membership forms.
- If you need further assistance, contact the relevant authorities.
