# Used Book Listing Form - Help Guide

## Purpose
The Used Book Listing Form is designed to collect information about used books being listed for sale. This form helps book sellers provide relevant details about their used books, making it easier for potential buyers to find and purchase the books they need.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the title of the book you are listing for sale.
2. Enter the author's name.
3. Provide the ISBN number (if available).
4. Enter the publisher's name.
5. Specify the year the book was published.
6. Set the price of the book.
7. Select the condition of the book (New, Used, Good, Fair, or Poor).
8. Enter the quantity of the book available for sale.
9. Specify the shipping cost.
10. Add a relevant image of the book.
11. Write a brief book description.
12. Select the category of the book (Bookstore, School, Library, or Community Sale).
13. Add any relevant tags.
14. Specify if the book has been used by someone else.
15. Enter the seller's email address.
16. Provide the seller's phone number.
17. Enter the seller's address.
18. Enter the seller's website.
19. Specify the contact person for the book.
20. Add any notes about the book.
21. Enter the date the book was listed for sale.
22. Enter the time the book was listed for sale.
23. Indicate if the form has been submitted.

## Field-by-Field Explanation

* **Used Book Listing Form** (used_book_listing_form): Enter the title of the book being listed for sale.
* **Book Title** (book_title): Enter the title of the book.
* **Book Author** (book_author): Enter the author's name.
* **ISBN** (isbn): Enter the ISBN number (if available).
* **Publisher** (publisher): Enter the publisher's name.
* **Year of Publication** (year_of_publication): Enter the year the book was published.
* **Price** (price): Set the price of the book.
* **Condition** (condition): Select the condition of the book (New, Used, Good, Fair, or Poor).
* **Quantity** (quantity): Enter the number of books available for sale.
* **Shipping Cost** (shipping_cost): Set the shipping cost.
* **Image** (image): Add a relevant image of the book.
* **Book Description** (book_description): Write a brief description of the book.
* **Category** (category): Select the category of the book (Bookstore, School, Library, or Community Sale).
* **Tags** (tags): Add any relevant tags.
* **Used By** (used_by): Specify if the book has been used by someone else.
* **Email** (email): Enter the seller's email address.
* **Phone** (phone): Enter the seller's phone number.
* **Address** (address): Enter the seller's address.
* **Website** (website): Enter the seller's website.
* **Contact Person** (contact_person): Specify the contact person for the book.
* **Notes** (notes): Add any notes about the book.
* **Date Listed** (date_listed): Enter the date the book was listed for sale.
* **Time Listed** (time_listed): Enter the time the book was listed for sale.
* **Form Submitted** (form_submitted): Indicate if the form has been submitted.

## Tips
* Be as accurate as possible when filling out the form fields.
* Use relevant and descriptive text in the book description field.
* Select the correct category and tags for the book.
* Make sure to provide a clear and accurate image of the book.
* Check the form submission status to ensure it has been submitted successfully.
