# sub_order_form - Help Guide
## Purpose
The sub_order_form is used to collect various details associated with a customer's order, including order details, customer information, and payment methods.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the necessary information for the order details section, such as `order_notes`, `payment_method`, `payment_amount`, and `sub_type`.
2. Enter the necessary information for the customer information section, such as `customer_name`, `customer_phone`, `customer_email`, and `customer_details`.
3. Select the relevant options for the payment method and order status sections, such as `payment_method`, `payment_status`, and `order_status`.

## Field-by-Field Explanation

* **order_details** (Text): Enter a brief description of the order.
* **customer_details** (Text): Enter a brief description of the customer.
* **order_type** (Select One): Select the type of order (Sub Sandwich, Wrap, or Salad).
* **customer_name** (Text): Enter the customer's name.
* **customer_phone** (Text): Enter the customer's phone number.
* **customer_email** (Text): Enter the customer's email address.
* **order_notes** (Text): Enter any additional notes about the order.
* **payment_method** (Select Multiple): Select the payment method (Stripe, PayPal, Apple Pay, Google Pay, Square, Authorize, Charge, or Bank transfer).
* **payment_amount** (Number): Enter the payment amount.
* **sub_type** (Select One): Select the sub type (Turkey, Ham, or Roast).
* **sub_name** (Text): Enter the sub name.
* **sub_price** (Number): Enter the sub price.
* **order_total** (Number): Enter the total order amount.
* **confirm** (Select One): Confirm that the order is valid (True or False).
* **payment_status** (Select One): Select the payment status (Paid, Unpaid, or Pending).
* **payment_gateway** (Select One): Select the payment gateway (Stripe, PayPal, Apple Pay, Google Pay, Square, Authorize, or Bank transfer).
* **order_date** (Date): Enter the order date.
* **order_time** (Time): Enter the order time.
* **order_comments** (Text): Enter any additional comments about the order.
* **order_status** (Select One): Select the order status (Open or Closed).
* **order_id** (Number): Enter the order ID.
* **order_number** (Text): Enter the order number.
* **order_referral** (Text): Enter the referral.
* **sub_type_2** (Select One): Select the second sub type (Turkey, Ham, or Roast).
* **sub_type_2** (Text): This field seems to be a duplicate of the `sub_type` field, and its label is not clear. Please use `sub_type` instead.

## Tips

* Make sure to fill in all required fields accurately and completely.
* Double-check your information before submitting the form.
* If you have any questions or issues with the form, contact your order manager for assistance.
