# custom_pop_up_banner_order_form - Help Guide

## Purpose
The purpose of this form is to create and manage custom pop-up banner orders. It is used by authorized personnel to place orders for custom banner designs, which can include various customization options such as banner type, size, text, and more. This form helps to streamline the ordering process and ensure that all necessary information is collected accurately.

## How To Complete This Form

1. **Fill out the banner type** (`banner_type`): Select the type of banner you would like to order from the provided options.
2. **Enter the banner size** (`banner_size`): Enter the size of the banner, which will be used for production and shipping purposes.
3. **Choose the order type** (`order_type`): Select the type of order you would like to place, which will affect the production and shipping process.
4. **Provide customer information** (`customer_name`, `customer_email`, `customer_phone`): Enter the customer's name, email address, and phone number to ensure that orders are accurately routed to the customer.
5. **Enter banner text and other design specifications** (`banner_text`, `background_color`, `font_family`, `font_size`, `font_color`, `border_width`): Enter the desired text and design specifications for the banner.
6. **Add order details** (`order_description`, `order_price`, `order_quantity`, `order_notes`): Enter any additional details about the order, including description, price, quantity, and any special notes.
7. **Select assignment and submission details** (`assigned_to`, `submitted_by`, `submission_date`, `status`, `status_date`, `status_time`, `status_note`): Enter the personnel assigned to the order, submitter, submission date and time, and status notes.

## Field-by-Field Explanation

* **Banner Type** (`banner_type`, `select_one`): Choose from available options to select the type of banner.
* **Banner Size** (`banner_size`, `number`): Enter the size of the banner in a numerical format.
* **Order Type** (`order_type`, `select_one`): Select the type of order.
* **Customer Name** (`customer_name`, `text`): Enter the customer's name.
* **Customer Email** (`customer_email`, `email`): Enter the customer's email address.
* **Customer Phone** (`customer_phone`, `text`): Enter the customer's phone number.
* **Banner Text** (`banner_text`, `text`): Enter the desired text for the banner.
* **Background Color** (`background_color`, `select_one`): Select from available options to choose the background color.
* **Font Family** (`font_family`, `select_one`): Select from available options to choose the font family.
* **Font Size** (`font_size`, `number`): Enter the font size in a numerical format.
* **Font Color** (`font_color`, `select_one`): Select from available options to choose the font color.
* **Border Width** (`border_width`, `number`): Enter the width of the border in a numerical format.
* **Order Description** (`order_description`, `text`): Enter any additional details about the order.
* **Order Price** (`order_price`, `number`): Enter the price of the order in a numerical format.
* **Order Quantity** (`order_quantity`, `number`): Enter the quantity of the order in a numerical format.
* **Order Notes** (`order_notes`, `text`): Enter any special notes about the order.
* **Order Date** (`order_date`, `date`): Enter the date the order was placed.
* **Assigned To** (`assigned_to`, `select_one`): Select the personnel to whom the order will be assigned.
* **Submitted By** (`submitted_by`, `select_one`): Select the person who submitted the order.
* **Submission Date** (`submission_date`, `time`): Enter the date and time the order was submitted.
* **Status** (`status`, `select_one`): Select the status of the order.
* **Status Date** (`status_date`, `date`): Enter the date the order status was updated.
* **Status Time** (`status_time`, `time`): Enter the time the order status was updated.
* **Status Note** (`status_note`, `text`): Enter any notes about the order status update.
