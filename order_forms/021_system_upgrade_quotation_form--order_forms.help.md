# System Upgrade Quotation Form - Help Guide
## Purpose
This form is designed to help you gather information about your system upgrade intentions and provide you with a quotation or offer for the upgrade.

## How To Complete This Form
To complete this form, follow these steps:

1. Select your response to each question to indicate your intention or preference.
2. For each field, choose one of the options provided or enter a relevant value if the field type is not a selection.
3. Submit the form once you have provided all necessary information.

## Field-by-Field Explanation

* **Customer Info** (`id: 1`, `select_multiple`, optional)
	+ Select "Yes" if you are interested in providing more information about your upgrade intentions.
* **Current System Info** (`id: 2`, `select_one`, optional)
	+ Indicate whether your current system is currently running or not.
* **Upgrade Details** (`id: 3`, `select_one`, optional)
	+ Choose "Yes" to request a detailed upgrade quotation or "No" to decline.
* **Upgrade Reason** (`id: 4`, `text`, optional)
	+ Enter a brief description of your reason for upgrading your system.
* **Upgrade Frequency** (`id: 5`, `select_one`, optional)
	+ Select "Yes" if you plan to upgrade your system more frequently than once a year.
* **Customer Budget** (`id: 6`, `select_multiple`, optional)
	+ Indicate your available budget for the upgrade.
* **Estimated Upgrade Cost** (`id: 7`, `number`, optional)
	+ Enter the estimated cost of the upgrade, if known.
* **System Upgrades** (`id: 8`, `select_multiple`, optional)
	+ Select "Yes" if you are interested in upgrading multiple systems.
* **Upgrade Deadlines** (`id: 9`, `date`, optional)
	+ Provide the deadline for the upgrade, if applicable.
* **Next Upgrade Schedule** (`id: 10`, `time`, optional)
	+ Enter the next scheduled upgrade time, if known.
* **Upgrade Technology** (`id: 11`, `select_one`, optional)
	+ Choose "Yes" to request an upgrade to the latest technology.
* **Customer Contact** (`id: 12`, `select_one`, optional)
	+ Indicate how you would like to be contacted (e.g., phone, email).
* **Customer Phone** (`id: 13`, `text`, optional)
	+ Enter your contact phone number.
* **Customer Email** (`id: 14`, `email`, optional)
	+ Enter your email address for communication.

Note: All fields are optional, meaning you can leave them blank if you do not wish to provide the information.
