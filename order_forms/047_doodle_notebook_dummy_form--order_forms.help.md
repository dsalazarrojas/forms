# doodle_notebook_dummy_form - Help Guide
## Purpose
The doodle_notebook_dummy_form is for ordering a doodle notebook. It is used to collect customer information and preferences for ordering a doodle notebook.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the required fields.
2. Make sure to provide accurate and complete information.
3. Double-check your submission before submitting.

## Field-by-Field Explanation
* **Order Form (id: 1)**: Enter a brief description of the order.
* **Customer Info (id: 2)**: Enter the customer's information such as name, phone number, and email.
* **Customer Name (id: 3)**: Enter the customer's name.
* **Customer Email (id: 4)**: Enter the customer's email address.
* **Customer Phone (id: 5)**: Enter the customer's phone number.
* **Customer Note (id: 6)**: Enter any additional notes or comments about the customer.
* **Doodle Notebook Type (id: 7)**: Select the type of doodle notebook you want to order. Options are Doodle 1, Doodle 2, Doodle 3, Doodle 4, Doodle 5, Doodle 6, and Doodle 8.
* **Doodle Notebook Size (id: 8)**: Select the size of the doodle notebook. Options are small, medium, and large.
* **Doodle Notebook Color (id: 9)**: Select the color of the doodle notebook. Options are red, blue, and black.
* **Doodle Notebook Cover Type (id: 10)**: Select the type of cover for the doodle notebook. Options are plain, embossed, and debossed.
* **Doodle Notebook Paper Type (id: 11)**: Select the type of paper for the doodle notebook. Options are recycled, non-recycled, and eco-friendly.
