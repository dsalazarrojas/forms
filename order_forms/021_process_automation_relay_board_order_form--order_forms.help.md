# Process Automation Relay Board Order Form - Help Guide
## Purpose
The Process Automation Relay Board Order Form is designed to collect and manage information related to orders for the Process Automation Relay Board.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the Order Details page, which includes general information about the order.
2. On the Select Product page, choose the products you want to order.
3. On the Customer Info page, enter the customer's information, including email and phone number.
4. On the Shipping Address page, enter the shipping address.
5. On the Delivery Info page, enter the delivery date and time.
6. On the Notes page, add any additional notes or comments about the order.
7. On the Customer Email page, enter the customer's email address.
8. On the Customer Phone page, enter the customer's phone number.
9. On the Customer Notes page, add any additional notes or comments about the customer.
10. On the Assigned User page, select the user assigned to handle the order.
11. On the Assigned To page, enter the name of the user assigned to the order.
12. On the Order Status page, select the status of the order.

## Field-by-Field Explanation

* **Order Details** (`order_details`, text, required): This page includes general information about the order, such as the order number, customer name, and order date.
* **Select Product** (`product_selection`, select_multiple, required): This page allows you to select multiple products for the order.
* **Customer Info** (`customer_info`, text, required): This page includes information about the customer, such as name, email, and phone number.
* **Shipping Address** (`shipping_address`, text, required): This page is used to enter the shipping address.
* **Delivery Info** (`delivery_info`, text, required): This page is used to enter the delivery date and time.
* **Notes** (`order_notes`, note, optional): This page is used to add any additional notes or comments about the order.
* **Customer Email** (`customer_email`, email, required): This page is used to enter the customer's email address.
* **Customer Phone** (`customer_phone`, text, required): This page is used to enter the customer's phone number.
* **Customer Notes** (`customer_notes`, note, optional): This page is used to add any additional notes or comments about the customer.
* **Delivery Date** (`delivery_date`, date, required): This page is used to enter the delivery date.
* **Delivery Time** (`delivery_time`, time, required): This page is used to enter the delivery time.
* **Assigned User** (`assigned_user`, select_one, required): This page is used to select the user assigned to handle the order.
* **Assigned To** (`assigned_user_hint`, text, optional): This page is used to enter the name of the user assigned to the order.
* **Order Status** (`order_status`, select_one, required): This page is used to select the status of the order.

## Tips

* Make sure to fill out all required fields, as they are crucial for the automation process.
* Use the Select Product page to select multiple products for the order.
* Use the Notes page to add any additional notes or comments about the order.
* Use the Assigned To page to enter the name of the user assigned to the order.
* Use the Order Status page to select the status of the order.
