# Ice Machine Filter Replacement Order Form - Help Guide
## Purpose
This form is used for submitting an order for replacement filters for an ice machine. Please fill out the form with the requested information to ensure that your order is processed correctly.

## How To Complete This Form
1. Fill out the form in its entirety, ensuring that all required fields are completed.
2. Review the form for accuracy before submitting it.

## Field-by-Field Explanation
* **Ice Machine Filter Replacement Order** (`ice_machine_filter_replacement_order`, text, optional): This is the main field for submitting your filter replacement order. Please enter a brief description of the reason for the replacement.
* **Customer Name** (`customer_name`, text, optional): Enter the name of the customer submitting the order.
* **Customer Email** (`customer_email`, email, optional): Enter the email address of the customer submitting the order.
* **Customer Phone** (`customer_phone`, text, optional): Enter the phone number of the customer submitting the order.
* **Machine Model** (`machine_model`, text, optional): Enter the model number of the ice machine that needs a filter replacement.
* **Filter Type** (`filter_type`, select_one, optional):
	+ Select one of the following options:
		- Option 1
		- Option 2
		- Option 3
* **Filter Size** (`filter_size`, select_multiple, optional):
	+ Select one or more of the following options:
		- Option 1
		- Option 2
		- Option 3
* **Date** (`date`, date, optional): Enter the date of the order or the date when the filter was last replaced.
* **Time** (`time`, time, optional): Enter the time of the order or the time when the filter was last replaced.
* **Notes** (`notes`, note, optional): Enter any additional information about the order, such as the reason for the replacement or any special requests.

## Tips
* Make sure to review the form for accuracy before submitting it.
