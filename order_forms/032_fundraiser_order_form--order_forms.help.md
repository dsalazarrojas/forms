# Fundraiser Order Form - Help Guide
## Purpose
The Fundraiser Order Form is used to process orders for fundraising efforts. It collects information about the order, shipping details, and payment methods.

## How To Complete This Form

To complete this form, follow these steps:

*   Go to the form page and review the form structure.
*   Fill in the required fields (indicated by the "required" label).
*   Select the payment method and payment status options from the drop-down menus.
*   Provide any additional order notes or comments in the text fields.

## Field-by-Field Explanation

*   **Order Details**: This field collects information about the order, such as its title. Please provide a brief description of the order.
    *   Type: text
    *   Required: false
*   **Shipping Details**: Enter shipping details, including any relevant information about the delivery address, shipping costs, etc.
    *   Type: text
    *   Required: false
*   **Payment Details**: Enter any additional payment information, such as payment date or payment method.
    *   Type: text
    *   Required: false
*   **Payment Method**: Select the payment method used for the order from the options provided.
    *   Type: select_one
    *   Options: Square, PayPal
    *   Required: false
*   **Order Amount**: Enter the total amount of the order.
    *   Type: number
    *   Required: false
*   **Order Total**: Enter the total cost of the order, including any additional fees or taxes.
    *   Type: number
    *   Required: false
*   **Payment Status**: Select the status of the payment from the options provided.
    *   Type: select_one
    *   Options: Pending, Processing, Successful
    *   Required: false
*   **Order Status**: Select the status of the order from the options provided.
    *   Type: select_one
    *   Options: Pending, Processing, Successful, Failed
    *   Required: false
*   **Payment Type**: Select all applicable payment types for the order.
    *   Type: select_multiple
    *   Options: Credit Card, Bank Transfer
    *   Required: false
*   **Order Notes**: Provide any additional notes or comments about the order.
    *   Type: text
    *   Required: false
*   **Order Comments**: Enter any additional comments or feedback about the order.
    *   Type: text
    *   Required: false

## Tips

*   Before starting to fill out the form, please check to see if the form is available in the system.
*   If you are unsure about any field, please review the field explanation above.
*   If you need help with the form, please contact the support team.
