# Banquet Event Order Form - Help Guide
## Purpose
The Banquet Event Order Form is used to capture detailed information about an event organized by a client, including client contact details, event specifics, and catering and venue requirements. This information is crucial for the banquet team to effectively plan and prepare for the event. Please complete this form accurately and thoroughly to ensure that your event is successfully hosted.

## How To Complete This Form

1.  Review the form fields carefully and provide accurate and complete information for each section.
2.  Complete the form in the order of the pages as displayed.
3.  Ensure that all required fields are filled out before proceeding to the next page.
4.  If you need help or have any questions, don't hesitate to contact us.

## Field-by-Field Explanation

* **Client Full Name** (`client_full_name`, text, required): Enter your name as it appears on your business card or identification.
* **Email Address** (`client_email`, email, required): Enter your email address for communication purposes.
* **Phone Number** (`client_phone`, text, required): Enter your contact phone number.
* **Organization** (`client_organization`, text, optional): If applicable, enter the name of your organization.
* **Event Name** (`event_name`, text, required): Enter a brief description of the event.
* **Event Type** (`event_type`, select_one, required): Select the type of event (e.g., Wedding Reception, Corporate Event, etc.).
* **Event Date** (`event_date`, date, required): Enter the date of the event.
* **Event Start Time** (`event_start_time`, time, required): Enter the start time of the event.
* **Event End Time** (`event_end_time`, time, required): Enter the end time of the event.
* **Expected Number of Guests** (`expected_guests`, number, required): Enter the estimated number of guests attending.
* **Venue Selection** (`venue_selection`, select_one, required): Select the venue type (e.g., Grand Ballroom, Conference Center, etc.).
* **Meal Service** (`meal_service`, select_one, required): Select the type of meal service (e.g., Plated Dinner, Buffet Style, etc.).
* **Menu Selection** (`menu_selection`, select_one, required): Select the menu type (e.g., Premium Menu, Standard Menu, etc.).
* **Appetizers** (`appetizers`, select_multiple, optional): Select the appetizer options (e.g., Bruschetta, Shrimp Cocktail, etc.).
* **Entree Options** (`entree_options`, select_multiple, optional): Select the entree options (e.g., Grilled Salmon, Prime Rib, etc.).
* **Dessert Selection** (`dessert_selection`, select_one, required): Select the dessert type (e.g., Wedding Cake, Dessert Bar, etc.).
* **Beverage Package** (`beverage_package`, select_one, required): Select the drink options (e.g., Non-Alcoholic Only, Beer and Wine, etc.).
* **Table Setup** (`table_setup`, select_one, required): Select the seating arrangement (e.g., Round Tables, Long Tables, etc.).
* **Tablecloth Color** (`linens_color`, select_one, optional): Select the tablecloth color (e.g., White, Ivory, etc.).
* **Centerpieces** (`centerpieces`, select_one, optional): Select the table decoration (e.g., Floral Arrangements, Candles, etc.).
* **Audio Visual Needs** (`audio_visual_needs`, select_multiple, optional): Select the equipment needed (e.g., Microphone, Projector, etc.).
* **Entertainment** (`entertainment`, select_one, optional): Select the type of music or entertainment (e.g., DJ, Live Band, etc.).
* **Special Requests** (`special_requests`, text, optional): Enter any special requirements or instructions.
* **Deposit Amount** (`deposit_amount`, number, required): Enter the initial payment amount.
* **Estimated Total Budget** (`total_budget`, select_one, optional): Select the estimated total budget (e.g., Under $5000, $5000-$10000, etc.).
* **Payment Schedule** (`payment_schedule`, select_one, required): Select the payment schedule (e.g., Full Payment Upfront, 50% Deposit, etc.).
* **Cancellation Policy Acknowledgment** (`cancellation_policy_acknowledgment`, select_one, required): Confirm that you understand the cancellation policy.
* **Signature Date** (`contract_signature_date`, date, required): Enter the date of this order.

Please review and complete this form accurately to ensure that your event is successfully hosted. If you need help or have any questions, don't hesitate to contact us.
