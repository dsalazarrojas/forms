# indian_ready_meals_delivery_form - Help Guide
## Purpose
This form is designed to collect information for Indian meal delivery services.

## How To Complete This Form
To complete this form, please fill out the following fields:

## Field-by-Field Explanation

* **Customer Information (customer_info)**: Enter the customer's name and any additional information as required.
* **Delivery Address (delivery_address)**: Enter the address where the meal should be delivered.
* **Order Meal Details (order_meal_details)**: Provide any additional details about the order, if required.
* **Delivery Instructions (delivery_instructions)**: Add any delivery instructions for the meal, if required.
* **Order Notes (order_notes)**: Add any additional notes about the order.
* **Email (email)**: Enter the customer's email address.
* **Phone (phone)**: Enter the customer's phone number.
* **Delivery Date (delivery_date)**: Select the date for delivery.
* **Delivery Time (delivery_time)**: Select the time for delivery.
* **Special Instructions (special_instructions)**: Add any special instructions for the delivery.
* **Order Meal (order_meal)**: Select whether the meal is ordered.
* **Delivery Instructions 2 (delivery_instructions_2)**: Add any delivery instructions 2.
* **Delivery Method (delivery_method)**: Select the delivery method.
* **Payment Method (payment_method)**: Select the payment method.
* **Order Date (order_date)**: Select the order date.
* **Order Time (order_time)**: Select the order time.
* **Order Status (order_status)**: Select the status of the order.
* **Delivery Status (delivery_status)**: Select the status of the delivery.
* **Customer Notes (customer_notes)**: Add any notes from the customer.
* **Order Notes 2 (order_notes_2)**: Add any additional order notes.
* **Order Total (order_total)**: Enter the total cost of the order.
* **Customer Information 2 (customer_info_2)**: Enter any additional customer information.
* **Customer Name (customer_name)**: Enter the customer's name.
* **Delivery Note (delivery_note)**: Add any delivery notes.
* **Special Request (special_request)**: Add any special requests.

Note: The fields marked as required must be filled out, as they are essential for the order processing.
