# Tree Removal Services Quote Request Form - Help Guide
## Purpose

This form is designed to gather information from users to facilitate the process of requesting a quote for tree removal services. It is intended for customers who need to request a quote for tree removal services, such as tree, branch, stump, or root removal. 

## How To Complete This Form

To complete this form, follow these steps:

1. Fill out the form by providing the required and optional information.
2. Review the form carefully before submission.

## Field-by-Field Explanation

* **Quote Request** (`Quote Request`, text, optional): A brief description of your request.
* **Property Address** (`Property Address`, text, optional): Enter your property address where the tree removal service will be performed.
* **Service Type** (`Service Type`, select_one, optional): Select the type of service you are requesting (Tree, Branch, Stump, or Root removal).
* **Removal Service Required** (`Removal Service Required`, select_multiple, optional): Check "True" if you need the tree removal service. 
* **Contact First Name** (`Contact First Name`, text, optional): Enter your first name.
* **Contact Last Name** (`Contact Last Name`, text, optional): Enter your last name.
* **Contact Email** (`Contact Email`, email, optional): Enter your email address.
* **Tree Height** (`Tree Height`, number, optional): Enter the height of the tree to be removed.
* **Tree Diameter** (`Tree Diameter`, number, optional): Enter the diameter of the tree to be removed.
* **Tree Location** (`Tree Location`, text, optional): Enter the location of the tree to be removed.
* **Service Date** (`Service Date`, date, optional): Enter the date when the tree removal service is required.

## Tips

* Make sure to provide accurate and complete information to ensure that the quote is generated correctly.
* If you have any questions or concerns, please contact us.
* We will review and respond to your quote request form as soon as possible.
