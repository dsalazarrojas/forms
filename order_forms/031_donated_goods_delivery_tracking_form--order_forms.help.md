The purpose of this form is to track the delivery of donated goods, allowing users to input key details about the delivery date, delivery status, and other relevant information.

Before filling out this form, ensure that you are not duplicating efforts. If you have already filled out this form for the same delivery, please do not fill it out again.

To complete this form, follow these steps:

1. Select the delivery status of the goods.
2. Input the date of delivery.
3. Enter the tracking number associated with the delivery.
4. Input the delivery address.
5. Input the name of the person or organization receiving the goods.
6. Input any additional delivery notes.
7. Input the ID of the user assigned to this delivery.
8. Input the ID of this delivery.

The following is a field-by-field explanation of the form:

* **Delivery Date** (page 1, delivery_date): Input the date on which the goods were delivered. This field is optional.
* **Delivered By** (page 1): Select 'Yes' if the goods have been delivered, 'No' otherwise.
* **Tracking Number** (page 1): Input the tracking number associated with the delivered goods.
* **Delivery Address** (page 1): Input the address where the goods were delivered.
* **Delivered To** (page 1): Input the name of the person or organization who received the goods.
* **Delivery Status** (page 2): Select the current status of the delivery, either 'Active' or 'Inactive'.
* **Delivery Note** (page 2): Add any additional notes about the delivery.
* **Assigned User ID** (page 2): Input the ID of the user assigned to this delivery.

Some additional tips:

* Ensure that you fill out the form accurately and completely.
* If you are filling out the form for a delivery that is already active, select 'Active' for the delivery status.
* If the delivery status is 'Active', please do not change it to 'Inactive' without proper authorization.

Note: This form is part of our Donated Goods Delivery Tracking system, which helps us track and monitor the delivery of goods to those in need.
