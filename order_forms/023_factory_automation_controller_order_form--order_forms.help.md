# Factory Automation Controller Order Form - Help Guide
## Purpose
The Factory Automation Controller Order Form is designed to collect information for orders related to factory automation controllers. This form ensures that all necessary details are captured correctly, making it easier to manage orders effectively.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in your **First Name** and **Last Name** in the corresponding fields.
2. Enter your **Email** address in the "Email" field.
3. Provide your **Phone Number** in the "Phone" field.
4. Enter your **Company Name** in the "Company" field.
5. Select the **Automation Controller Type** from the dropdown menu.
6. Enter the **Quantity** of the automation controller.
7. Add any additional **Notes** about the order.
8. Choose the **Assigned Tool** from the dropdown menu.
9. Select the relevant **Category** for the order.
10. Enter the **Assigned Date/Time** of the automation controller.
11. Enter the **Submitted Date/Time** of the order.
12. Provide a brief **Description** of the order.
13. Enter the **Form ID** and **Form Version** numbers.
14. Enter the **Created By** field with your username.
15. Enter the **Created At** and **Updated At** dates.
16. Enter the **Submitted At** date.

## Field-by-Field Explanation

* **First Name**: Enter your first name to be associated with the order.
	+ Type: Text
	+ Required: False
* **Last Name**: Enter your last name to be associated with the order.
	+ Type: Text
	+ Required: False
* **Email**: Enter your email address to be associated with the order.
	+ Type: Email
	+ Required: False
* **Phone**: Enter your phone number to be associated with the order.
	+ Type: Text
	+ Required: False
* **Company**: Enter your company name to be associated with the order.
	+ Type: Text
	+ Required: False
* **Automation Controller Type**: Select the type of automation controller to be ordered.
	+ Type: Select One
	+ Required: False
* **Quantity**: Enter the quantity of the automation controller to be ordered.
	+ Type: Number
	+ Required: False
* **Notes**: Add any additional notes about the order.
	+ Type: Note
	+ Required: False
* **Assigned Tool**: Choose the tool assigned to the order.
	+ Type: Select One
	+ Required: False
* **Category**: Select the category for the order.
	+ Type: Select Multiple
	+ Required: False
* **Assigned Date/Time**: Enter the assigned date and time of the automation controller.
	+ Type: Date
	+ Required: False
* **Submitted Date/Time**: Enter the submitted date and time of the order.
	+ Type: Date
	+ Required: False
* **Description**: Provide a brief description of the order.
	+ Type: Text
	+ Required: False
* **Form ID**: Enter the form ID number.
	+ Type: Number
	+ Required: False
* **Form Version**: Enter the form version number.
	+ Type: Number
	+ Required: False
* **Created By**: Enter the name of the user who created the form.
	+ Type: Text
	+ Required: False
* **Created At**: Enter the date and time the form was created.
	+ Type: Date
	+ Required: False
* **Updated At**: Enter the date and time the form was last updated.
	+ Type: Date
	+ Required: False
* **Submitted At**: Enter the date and time the form was submitted.
	+ Type: Date
	+ Required: False
