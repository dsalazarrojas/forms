# race_event_tent_graphic_printing_order_form - Help Guide
## Purpose
This form is used for submitting orders for printing services related to race events. It requires details such as event information, printing requirements, and contact information.

## How To Complete This Form
To complete this form, follow the steps below:

1. Fill in the race event details in the "race event details" field, including the title of the event, date, and location.
2. Provide the graphic details in the "graphic details" field, including any necessary descriptions or notes.
3. In the "graphic printing info" field, specify the printing requirements for the graphics used in the event.
4. If you are submitting contact information, enter it in the "contact info" field.
5. Add any additional notes in the "notes" field.
6. Enter the email address and phone number of the contact person in the "email" and "phone" fields, respectively.
7. Specify the date and start time of the event in the "event date" and "event start time" fields.
8. Select the event location from the drop-down list in the "event location" field.
9. Choose the graphic designer responsible for the event's graphics in the "graphic designer" field.
10. Select the files required for printing in the "graphic file" field.
11. Enter the size of the graphic in the "graphic size" field.
12. Select the color and orientation of the graphic in the "graphic color" and "graphic orientation" fields, respectively.
13. Choose the finish for the graphic in the "graphic finish" field.

* **race event details**: This field is for collecting the title, date, and location of the race event. Please enter the relevant details for the event. (required)
* **graphic details**: This field is for providing any necessary descriptions or notes about the graphics used in the event. (required)

* **email**: This field is for entering the email address of the contact person. (required)

* **event date**: This field is for specifying the date of the event. (required)
* **event start time**: This field is for specifying the start time of the event. (required)
* **event location**: This field is for selecting the location of the event from the drop-down list. (required)
* **graphic designer**: This field is for choosing the graphic designer responsible for the event's graphics. (required)
* **graphic file**: This field is for selecting the files required for printing. (required)
* **graphic size**: This field is for entering the size of the graphic. (required)
* **graphic color**: This field is for selecting the color of the graphic from the drop-down list. (required)
* **graphic orientation**: This field is for selecting the orientation of the graphic from the drop-down list. (required)
