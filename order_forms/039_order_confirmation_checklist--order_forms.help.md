# ประก_Order Confirmation Checklist_ - Help Guide

## Purpose
This form is designed to help you confirm the details of an order with your customer. It ensures that all necessary information is accurate and up-to-date, making it easier to manage and follow up on customer requests.

## How To Complete This Form
To complete this form, simply follow these steps:

1. Fill in the **Customer Name** field with the customer's full name.
2. Enter the **Order Details** field with a brief description of the order.
3. Provide the **Shipping Address** field with the customer's shipping address.
4. Select the payment method used for the order (Card number, Bank transfer, or Other).
5. List the **Order Items** field with the items ordered.
6. Enter the **Tracking Number** field with the tracking number for the order.
7. Select the **Order Status** field with the current status of the order (Pending, In Transit, or Delivered).
8. Select the **Review Status** field with the status of the review (Not Reviewed, Reviewed, or Completed).
9. Enter any **Customer Note** field with any additional comments from the customer (optional).
10. If applicable, select the **Fulfillment Team** field with the team assigned to handle the order (Team A, Team B, or Team C).
11. If applicable, select the **Assigned User** field with the user assigned to handle the order (User 1, User 2, or User 3).
12. Enter the **Submission Date** field with the date the order was submitted.
13. Enter the **Submission Time** field with the time the order was submitted.
14. (Optional) Enter the **Review Date** field with the date the order was reviewed.
15. (Optional) Enter the **Review Time** field with the time the order was reviewed.
