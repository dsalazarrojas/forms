# Delivery Fee Assessment - Help Guide
## Purpose
The Delivery Fee Assessment form is used to estimate the delivery charge for an order based on various factors.

## How To Complete This Form
To complete this form, follow these steps:

1.  Estimate the delivery charge for the order by inputting the estimated delivery time in hours.
2.  Indicate the fairness of the logistics fee, which is the fee charged to customers for expedited shipping options.
3.  Choose the delivery time window that best represents when the customer would like to receive their order.
4.  Provide feedback on the urgency of the customer's feedback, which can be fair, unfair, or neutral.
5.  Select the preferred scheduling for the delivery, which can be morning, afternoon, or evening.
6.  Enter any additional comments or notes about the delivery charge.

## Field-by-Field Explanation
*   **Estimate Delivery Charge** (estimate_delivery_charge, number, required: false): This field is used to estimate the delivery charge for the order based on the estimated delivery time. Input the estimated time in hours.
*   **Logistics Fee Fairness** (logistics_fee_fairness, number, required: false): This field indicates the fairness of the logistics fee charged to the customer.
*   **Delivery Time Window** (delivery_time_window, select_one, required: false): Select the delivery time window that best represents when the customer would like to receive their order. This can be Within 1-3 hours, Within 1-24 hours, Anytime, or Today.
*   **Customer Feedback Urgency** (customer_feedback_urgency, select_one, required: false): Provide feedback on the urgency of the customer's feedback, which can be Fair, Unfair, or Neutral.
*   **Scheduling Preferences** (scheduling_preferences, select_multiple, required: false): Select the preferred scheduling time for the delivery, which can be Morning, Afternoon, or Evening.
*   **Customer Feedback** (customer_feedback, text, required: false): Enter any additional comments or notes about the delivery charge. This field is optional and provides further context for the delivery charge.
