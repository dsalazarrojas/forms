# Robotics Vision Lens Order Form - Help Guide
## Purpose
The Robotics Vision Lens Order Form is used to capture essential information for a robotics vision lens order. This includes customer details, shipping information, payment methods, and order status.

## How To Complete This Form
To complete this form, follow these steps:

1. **Select Lenses**: Choose the lens you would like to order from the available options.
2. Fill in the required fields:
	* **Customer Name**: Enter the name of the customer.
	* **Customer Email**: Enter the customer's email address.
	* **Customer Phone**: Enter the customer's phone number.
	* **Shipping Address**: Enter the shipping address of the customer.
	* **Shipping City**: Enter the city of the shipping address.
	* **Shipping State**: Enter the state of the shipping address.
	* **Shipping Zip**: Enter the zip code of the shipping address.
	* **Payment Method**: Choose a payment method from the available options (Cash, Card, PayPal).
	* **Customer Note**: Add any additional notes or comments about the order.
3. Review the form and ensure all required fields are filled in correctly.
4. Click **Submit** to complete the order.

## Field-by-Field Explanation

* **Select Lenses**: Choose the lens you would like to order from the available options.
* **Shipping Details**: Enter the shipping details of the customer.
* **Terms and Conditions**: Read and agree to the terms and conditions of the order.
* **Customer Name**: Enter the name of the customer.
* **Customer Email**: Enter the email address of the customer.
* **Customer Phone**: Enter the phone number of the customer.
* **Shipping Address**: Enter the address where the order should be shipped.
* **Shipping City**: Enter the city of the shipping address.
* **Shipping State**: Enter the state of the shipping address.
* **Shipping Zip**: Enter the zip code of the shipping address.
* **Payment Method**: Choose a payment method from the available options.
* **Customer Note**: Add any additional notes or comments about the order.
* **Customer Note Required**: If required, add any additional notes or comments about the shipping order.
* **Shipping Note**: Add any additional notes or comments about the shipping.
* **Shipping Note Required**: If required, add any additional notes or comments about the shipping.
* **Payment Method Required**: Choose whether a payment method is required for the order.
* **Customer Address**: Enter the address of the customer.
* **Customer Note Required Shipping**: If required, add any additional notes or comments about the shipping order.
* **Order ID**: Enter the order ID (not required for customers).
* **Order Date**: Enter the date of the order (not required for customers).
* **Order Time**: Enter the time of the order (not required for customers).
* **Order Status**: Choose the status of the order from the available options (Pending, Processing, Completed).
* **Customer IP**: Enter the IP address of the customer (not required for customers).
* **Customer Note Required**: If required, add any additional notes or comments about the order.
* **Shipping Note Required**: If required, add any additional notes or comments about the shipping.

**Tips**

* Ensure all required fields are filled in correctly before submitting the form.
* Double-check the information you enter to avoid any errors.
* If you are unsure about any field, contact the order administrator for assistance.
