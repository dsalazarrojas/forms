# PayU Product Order Form - Help Guide
## Purpose
This form is designed to collect order information from customers, allowing them to place orders for products. It gathers necessary details such as contact information, order date and time, payment method, and products selected for the order.

## How To Complete This Form
To place an order using this form, follow these steps:
1. Enter your First Name in the "First Name" field.
2. Enter your Last Name in the "Last Name" field.
3. Enter your Email address in the "Email" field.
4. Enter your Phone number in the "Phone" field.
5. Select a date for the order in the "Date" field.
6. Choose a time for the order in the "Time" field.
7. Select the payment method you prefer (Bank Transfer, Credit Card, or PayPal) using the "PayU Method" dropdown.
8. If necessary, add any additional comments in the "Note" field.
9. Select the products you want to order using the "Products" field.
10. Confirm the total order value in the "Total" field.

## Field-by-Field Explanation
* **First Name**: Enter your first name in this field. This is a required field.
* **Last Name**: Enter your last name in this field. This is a required field.
* **Email**: Enter the email address you want to use for the order in this field. This is a required field. Please ensure it's a valid email address.
* **Phone**: Enter your phone number in this field. This is a required field.
* **Date**: Select the date you want to place the order. This is a required field.
* **Time**: Select the time you want to place the order. This is a required field.
* **PayU Method**: Select the payment method you prefer from the options provided. You can choose from Bank Transfer, Credit Card, or PayPal.
* **Note**: If you have any additional comments or instructions for the order, enter them here. This field is optional.
* **Products**: Select the products you want to order. You can choose multiple products. This is a required field.
* **Total**: This field is automatically populated based on the products you select. It is a required field, but you cannot edit it as it is calculated.
