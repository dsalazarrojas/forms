# Regalia Rental Agreement - Help Guide
## Purpose
The Regalia Rental Agreement form is designed to collect comprehensive information for renting equipment or resources from Regalia. This form helps ensure a clear understanding between the renter and Regalia regarding the rental terms, including rental dates, periods, and preferences.

## How To Complete This Form
To complete this form, follow these steps:

1.  Select all required items from the "user-inputs" page.
2.  Enter the start and end dates of the rental period.
3.  Choose your preferred pickup and return options from the provided selections.
4.  Select the items you wish to rent.
5.  Enter the name of the item(s) you selected.
6.  (Optional) Enter the name of the school, if applicable.
7.  Confirm your preferred pickup option.
8.  Write your signature and name to confirm your agreement.
9.  If not required, enter the school address and preferred pickup time.
10. If not required, enter the preferred return time.
11. Review the form to ensure all required fields are filled in.
12. Submit the form to finalize the agreement.

## Field-by-Field Explanation

*   **User-Inputs** (Select Multiple):
    This page allows you to choose multiple items from the provided options. Select all relevant items for your rental needs.
*   **Rental-Dates** (Date):
    Enter the start and end dates for the rental period. Be sure to include the start date as the beginning of the rental and the end date as the end of the rental.
*   **Rental-Period** (Number):
    Enter the duration of your rental period. This should match the dates selected on the "Rental-Dates" field for accuracy.
*   **Pickup-Preference** (Select One):
    Choose how you would like to pick up the rented items: Option 1, Option 2, etc.
*   **Return-Preference** (Select One):
    Choose how you would like to return the rented items: Option 1, Option 2, etc.
*   **Item-Selection** (Select Multiple):
    Select all the items you would like to rent.
*   **Item-Name** (Text):
    Enter the name(s) of the item(s) you selected.
*   **School-Name** (Text):
    If you are renting for a school, enter the name of the school here.
*   **Pickup-Confirmation** (Select One):
    Confirm your preferred pickup option.
*   **Signature-Block** (Note):
    Write your signature and name to confirm your agreement to the rental terms.
*   **School-Address** (Text):
    If you are renting for a school, enter the school address here. This field is not required.
*   **Return-Date** (Date):
    If required, enter the date you prefer to return the items. This field is not required.
*   **Rental-Provider** (Text):
    If provided, enter the name of the rental provider. This field is not required.
*   **Pickup-Time** (Time):
    If required, enter the preferred time for pickup. This field is not required.
*   **Return-Time** (Time):
    If required, enter the preferred return time. This field is not required.
*   **Regalia-Rental-Agreement** (Text):
    Enter any additional comments or agreements here, which will be included in the rental contract.
*   **School-Address** (Text):
    If not required, this field is for entering the school address where the items will be picked up or returned.
*   **Return-Date** (Date):
    If required or not, enter the date you expect to return the items. This is not required.
