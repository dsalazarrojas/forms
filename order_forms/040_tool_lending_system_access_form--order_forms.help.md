# Tool Lending System Access Form - Help Guide
## Purpose
This form is used to grant access to the tool lending system for users who need to borrow tools within the organization.

## How To Complete This Form
To complete this form, please follow the steps below:

1. Fill out the required fields: First Name, Last Name, Email, Phone, Tool Lending Agreement, Start Date, and End Date.
2. Select the type of tools you need access to from the Tool Type dropdown menu.
3. Choose the status of the tools you need access to from the Tool Status dropdown menu.
4. Add any comments about your tool needs or requests.

## Field-by-Field Explanation
### User Info
* **User Info** (`User Info`, text, required): This field is a page title to help you identify the form sections.
* **First Name** (`user_info`, text, required): This is your first name that will be used to identify you within the tool lending system.
* **Last Name** (`user_last_name`, text, required): This is your last name that will be used to identify you within the tool lending system.
* **Email** (`user_email`, email, required): This is your email address that will be used to communicate with you about your tool lending access.
* **Phone** (`user_phone`, text, required): This is your contact phone number that will be used to reach you about your tool lending access.
* **Tool Lending Agreement** (`tool_lending_agreement`, text, required): This is where you confirm that you have read, understand, and agree to the tool lending system rules and guidelines.
* **Tool Type** (`tool_type`, select_one, required): Select the type of tools you need access to from the dropdown menu.
* **Start Date** (`start_date`, date, required): This is the date when you plan to start borrowing tools.
* **End Date** (`end_date`, date, required): This is the date when you plan to end your tool lending access.
* **Tool Status** (`tool_status`, select_multiple, optional): Choose from the options to indicate the status of the tools you need access to.
* **Comments** (`comments`, text, optional): Add any additional comments about your tool needs or requests.

## Tips
* Make sure to fill out all required fields accurately and completely.
* Be specific when selecting the Tool Type and Tool Status.
* If you have any questions or need help filling out this form, please contact your supervisor or tool lending administrator.
