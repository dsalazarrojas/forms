# industrial_monitoring_software_package_order_form - Help Guide
## Purpose
This form is used to order a package of industrial monitoring software.
## How To Complete This Form
To complete this form, follow the steps below:
* Fill out all required fields accurately and thoroughly.
* Select the correct software type from the options provided.
* Input any additional requirements or specifications for the software package in the "Package Requirements" field.
* Use the "Notes" field to input any additional comments or notes.
* Use the "Order Notes" field to input any specific instructions or requests for the order.

## Field-by-Field Explanation
* **Company Name** (`company_name`, text, required): Input your company's name.
* **Contact Person** (`contact_person`, text, required): Input your contact person's name.
* **Email** (`email`, email, required): Input your email address.
* **Phone** (`phone`, text, required): Input your phone number.
* **Software Type** (`software_type`, select_one, required): Select the type of software you need from the options provided: "Industrial Monitoring Software" or "Monitoring System" or "Other".
* **Package Requirements** (`package_requirements`, text, optional): Input any additional requirements or specifications you have for the software package.
* **Notes** (`notes`, note, optional): Input any additional comments or notes.
* **Order Notes** (`order_notes`, note, optional): Input any specific instructions or requests for the order.
## Tips
* Make sure to fill out all required fields accurately to ensure a prompt and correct quote.
* If you have any additional questions or concerns, please contact us.
* We appreciate your patience and understanding as we process your order.
* You can contact us if you need to make any changes to your order.
* We will review and follow up with you once we receive your completed form.
