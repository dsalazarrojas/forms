# Order Cancellation Override Request Form - Help Guide
## Purpose
The Order Cancellation Override Request Form is used to request cancelling of orders that have already been placed. Fill out this form to cancel an order and provide a reason for cancellation.

## How To Complete This Form
To complete this form, follow these steps:

* Select the reason for cancellation (order_status) to specify why the order is being cancelled.
* Enter the order ID (order_id) to identify the order to be cancelled.
* Enter the customer's name (customer_name) so we can contact them if needed.
* Enter a brief reason for cancellation (cancellation_reason) to explain why the order is being cancelled.
* If applicable, select 'Yes' or 'No' to indicate whether an override request has been made (order_override_request).
* Enter any additional information (notes) about the cancellation.

## Field-by-Field Explanation
* **Order Cancellation Override Request Form** (`order_cancellation_override_request_form`): This is the title of the form.
* **Order ID** (`order_id`): This is the unique identifier for the order being cancelled.
* **Customer Name** (`customer_name`): This field is used to store the customer's name.
* **Cancellation Reason** (`cancellation_reason`): Enter a brief reason for cancelling the order.
* **Order Status** (`order_status`): Select the reason why the order is being cancelled (Active or Inactive).
* **Reason for Cancellation** (`reason_for_cancellation`): Enter a brief reason for the cancellation.
* **Override Request** (`order_override_request`): Select 'Yes' if an override request has been made, 'No' otherwise.
* **Form Submitted By** (`form_submitted_by`): This field is used to store the user who submitted the form.
* **Form Submitted Date** (`form_submitted_date`): This is the date when the form was submitted.
* **Form Updated By** (`form_updated_by`): This field is used to store the user who last updated the form.
* **Form Updated Date** (`form_updated_date`): This is the date when the form was last updated.
* **Cancellation Request Status** (`cancellation_request_status`): Select the status of the cancellation request (Active or Inactive).
* **Notes** (`notes`): Enter any additional information about the cancellation.
* **Email** (`email`): Enter the customer's email address.
* **Phone** (`phone`): Enter the customer's phone number.
* **Order Notes** (`order_notes`): Enter any additional notes about the order.
* **Order ID 1** (`order_id_1`): This field is not currently used.
* **Order ID 2** (`order_id_2`): This field is not currently used.

## Tips
* Make sure to fill out the form accurately and thoroughly to ensure that the order cancellation is processed correctly.
* If you are unsure about any field, please ask for assistance.
* This form is used for overriding and cancelling orders, not for creating new orders.
