# Gaming Membership Gift Card Purchase Form - Help Guide
## Purpose
This form is designed to collect information for a gaming membership gift card purchase. It will be used to record details about the purchased gift cards, including the recipient's name, email, phone, membership type, card value, quantity, start date, and expiration date.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the order details in the "Order Details" field.
2. Enter the recipient's name in the "Name" field.
3. Enter the recipient's email in the "Email" field. Please use the correct email format (e.g., `user@example.com`).
4. Enter the recipient's phone number in the "Phone" field.
5. Select the membership type from the "Membership Type" dropdown list.
6. Enter the card value in the "Card Value" field. This field is a number input field, so please enter a numerical value without any currency symbol.
7. Enter the quantity of gift cards in the "Card Quantity" field.
8. Select the start date of the gift card from the "Start Date" field. Please note that if you select "monthly" as the membership type, you will need to select the last day of the month for the card to expire.
9. Enter any additional notes in the "Notes" field.
10. If "monthly" is selected as the membership type, select the last day of the month for the card expiration date in the "Card Expiration" field.

## Field-by-Field Explanation
* **Order Details** (`order_details`, `text`, optional): Enter any additional information about the order in this field.
* **Name** (`name`, `text`, optional): Enter the recipient's name.
* **Email** (`email`, `email`, optional): Enter the recipient's email address. Please use the correct email format (e.g., `user@example.com`).
* **Phone** (`phone`, `text`, optional): Enter the recipient's phone number.
* **Membership Type** (`membership_type`, `select_one`, optional): Select the membership type from the dropdown list. Options are: monthly, yearly, and lifetime.
* **Card Value** (`card_value`, `number`, optional): Enter the numerical value of the gift card.
* **Card Quantity** (`card_quantity`, `number`, optional): Enter the quantity of gift cards being purchased.
* **Start Date** (`card_start_date`, `date`, optional): Select the start date of the gift card. If "monthly" is selected as the membership type, select the last day of the month for the card to expire.
* **Notes** (`notes`, `note`, optional): Enter any additional notes about the gift card purchase.
* **Card Expiration** (`card_expiration`, `date`, optional): If "monthly" is selected as the membership type, enter the last day of the month when the card expiration date is due.
