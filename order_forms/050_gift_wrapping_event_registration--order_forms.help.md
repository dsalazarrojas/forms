# Gift Wrapping Event Registration - Help Guide
## Purpose
This form is designed to help us prepare for the gift wrapping event by gathering all necessary information about the participant and the event details. Please complete this form accurately and thoroughly to ensure that we can provide the best experience possible.

## How To Complete This Form
To complete this form, simply follow the instructions below:

1. Fill in your participant's name in the "Participant Name" field.
2. Enter your participant's email address in the "Participant Email" field.
3. Enter your participant's phone number in the "Participant Phone Number" field.
4. Write a gift message to be displayed on the gift tag in the "Gift Message To" field.
5. Select a date and time for the gift wrapping event in the "Wrap Date" and "Wrap Time" fields respectively.
6. Choose a location for the gift wrapping event in the "Wrap Location" field.
7. Enter the end time for the gift wrapping event in the "Wrap Time End" field.
8. Select a date for the gift wrapping event in the "Gift Wrapping Event Date" field.
9. Sign your name in the "Participant Signature" field.
10. Enter the time for the gift wrapping event in the "Gift Wrapping Event Time" field.
11. Enter the location for the gift wrapping event in the "Gift Wrapping Event Location" field.
12. Add any additional details about the gift message in the "Gift Message Details" field.
13. If applicable, enter the name of the gift certificate in the "Gift Certificate Name" field.
14. Enter the end time for the gift wrapping event in the "Gift Wrapping Event Time End" field.
15. Add any notes about the participant in the "Participant Notes" field.
16. Enter any additional details about the gift certificate in the "Gift Certificate Details" field.
17. Select a date for the next gift wrapping event in the "Gift Wrapping Event Date 2" field.
18. Sign and date the participant's signature in the "Participant Signature Date" field.
19. If applicable, enter the name of the gift certificate 2 in the "Gift Certificate Name 2" field.
20. Enter any additional details about the gift certificate 2 in the "Gift Certificate Details 2" field.
21. Enter the participant's phone number 2 in the "Participant Phone Number 2" field.
22. Enter the location for the gift wrapping event 2 in the "Wrap Location 2" field.
23. If applicable, enter the gift certificate in the "Gift Certificate" field.

## Field-by-Field Explanation

* **Participant Name** (`participant_name`, text, required): Enter the name of the participant.
* **Participant Email** (`participant_email`, email, required): Enter the email address of the participant.
* **Participant Phone Number** (`participant_phone_number`, text, required): Enter the phone number of the participant.
* **Gift Message To** (`gift_message_to`, text, required): Write a gift message to be displayed on the gift tag.
* **Wrap Time** (`wrap_time`, time, required): Select a time for the gift wrapping event.
* **Wrap Date** (`wrap_date`, date, required): Select a date for the gift wrapping event.
* **Wrap Location** (`wrap_location`, text, required): Choose a location for the gift wrapping event.
* **Wrap Time End** (`wrap_time_end`, time, required): Select the end time for the gift wrapping event.
* **Gift Wrapping Event Date** (`gift_wrapping_event_date`, date, required): Select a date for the gift wrapping event.
* **Participant Signature** (`participant_signature`, text, required): Sign your name as the participant.
* **Gift Wrapping Event Time** (`gift_wrapping_event_time`, time, required): Enter the time for the gift wrapping event.
* **Gift Wrapping Event Location** (`gift_wrapping_event_location`, text, required): Enter the location for the gift wrapping event.
* **Gift Message Details** (`gift_message_details`, text, required): Add any additional details about the gift message.
* **Gift Certificate Name** (`gift_certificate_name`, text, optional): If applicable, enter the name of the gift certificate.
* **Gift Wrapping Event Time End** (`gift_wrapping_event_time_end`, time, required): Select the end time for the gift wrapping event.
* **Participant Notes** (`participant_notes`, text, optional): Add any notes about the participant.
* **Gift Certificate Details** (`gift_certificate_details`, text, optional): Add any details about the gift certificate.
* **Gift Wrapping Event Date 2** (`gift_wrapping_event_date_2`, date, required): Select a date for the next gift wrapping event.
* **Participant Signature Date** (`participant_signature_date`, date, required): Sign and date your signature.
* **Gift Certificate Name 2** (`gift_certificate_name_2`, text, optional): If applicable, enter the name of the gift certificate 2.
* **Gift Certificate Details 2** (`gift_certificate_details_2`, text, optional): Add any details about the gift certificate 2.
* **Participant Phone Number 2** (`participant_phone_number_2`, text, required): Enter the participant's phone number 2.
* **Wrap Location 2** (`wrap_location_2`, text, optional): Enter the location for the gift wrapping event 2.
* **Gift Certificate** (`gift_certificate`, text, optional): If applicable, enter the gift certificate.
* **Gift Certificate Name 3** (`gift_certificate_name_3`, text, optional): If applicable, enter the name of the gift certificate 3.

## Tips

* Make sure to double-check your information for accuracy.
* If you're unsure about any field, please ask for clarification.
* Ensure that all fields with a red asterisk (\*) are required, while those without are optional.
* If you need to make any changes, please contact us and we'll be happy to assist you.
