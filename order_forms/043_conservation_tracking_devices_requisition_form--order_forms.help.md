### Conservation Tracking Devices Requisition Form - Help Guide
## Purpose
This form is used to submit a request for conservation tracking devices. It is required for all researchers and scientists to provide accurate and detailed information about their project needs, ensuring that the necessary equipment is ordered and delivered on time.

### Before proceeding, make sure to review the form carefully and ensure that all fields are completed accurately. If you have any questions or concerns, please contact the relevant department or team for assistance.

## How To Complete This Form
* Click on the "Submit" button to start a new request.
* Fill in the required fields marked with \*asterisk\*.
* Use the select menus to choose the correct options for device type, attachment method, data transmission method, and budget code.
* If you select "Other" for device type or attachment method, please provide a detailed explanation in the corresponding text field.
* Use the "Estimated Cost" field to input the total estimated expense for the requested devices.
* If you have any additional equipment or requirements, please list them in the "Additional Equipment Needed" field.
* Finally, sign the form with your full name to confirm your request.

## Field-by-Field Explanation

* **Requisition Date** (\*): This field is used to record the date the request is being made.
	+ Format: YYYY-MM-DD (e.g. 2022-07-25)
* **Requisition ID Number**: This field is used to record a unique request identifier.
* **Requester Name**: This field is used to record the name of the person requesting the devices.
* **Email Address**: This field is used to record the contact email of the person requesting the devices.
* **Phone Number**: This field is used to record the contact phone number of the person requesting the devices.
* **Department**: This field is used to record the department or team of the person requesting the devices.
* **Project Name**: This field is used to record the name of the research project.
* **Project ID Number**: This field is used to record the project identifier if applicable.
* **Principal Investigator**: This field is used to record the lead researcher name.
* **Type of Tracking Device**: This field is used to select the type of tracking device needed.
* **Quantity Requested**: This field is used to record the number of devices needed.
* **Quantity Available in Inventory**: This field is used to record the number of devices available in inventory.
* **Quantity to Purchase**: This field is used to record the number of devices needing purchase.
* **Required Specifications**: This field is used to record the technical requirements for the device.
* **Required Battery Life**: This field is used to select the minimum battery duration required.
* **Weight Limit**: This field is used to record the maximum device weight.
* **Attachment Method**: This field is used to select the method of attachment for the device.
* **Deployment Location**: This field is used to record the location where the devices will be used.
* **Expected Deployment Date**: This field is used to record the date when the devices will be deployed.
* **Expected Retrieval Date**: This field is used to record the date when the devices will be recovered.
* **Data Transmission Method**: This field is used to select the method of data transmission.
* **Data Plan Required**: This field is used to select whether a data plan is required.
* **Data Plan Duration**: This field is used to record the length of service needed.
* **Budget Code**: This field is used to record the account or grant number.
* **Estimated Cost**: This field is used to record the total estimated expense for the devices.
* **Funding Source**: This field is used to record the grant or funding name.
* **Urgency Level**: This field is used to select the urgency level for the request.
* **Justification for Request**: This field is used to record a brief explanation for the request.
* **Have You Used These Devices Before**: This field is used to record whether you have used these devices before.
* **Is Training Needed**: This field is used to record whether device training is needed.
* **Additional Equipment Needed**: This field is used to record any additional equipment or requirements.
* **Special Requirements**: This field is used to record any special requirements.
* **Requester Signature**: This field is used to record the full name of the person making the request.
* **Supervisor Approval**: This field is used to record the name of the supervisor for approval.
* **Approval Status**: This field is used to record the status of the request.
* **Other Device Type**: This field is used to provide a detailed explanation for "Other" selected for device type.
* **Other Attachment Method**: This field is used to provide a detailed explanation for "Other" selected for attachment method.

## Tips
* Make sure to provide accurate and detailed information in each field.
* Use the "Other" options carefully and only if necessary.
* Review the form carefully before submission to ensure all fields are completed accurately.
* If you have any questions or concerns, please contact the relevant department or team for assistance.
