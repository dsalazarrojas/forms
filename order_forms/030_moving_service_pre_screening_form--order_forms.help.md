# Moving Service Pre Screening Form - Help Guide
## Purpose
This form is used to collect pre-screening information for moving services. It ensures that the company has all the necessary details to process a move request correctly.

## How To Complete This Form
To complete this form, please follow these steps:

- Fill in your contact information (Field 2) and select the contact method (Field 11) to ensure that the moving company can reach you.
- Choose the type of move (Field 3) that you are undertaking.
- Provide the moving dates (Field 5) and time (Field 6) for the move.
- Specify from and to locations (Field 7 and 8) where the move will take place.
- If applicable, enter the distance (Field 9) of the move.
- Provide an estimate (Field 10) for the move.
- Select the moving company (Field 25) that you want to use for the move.
- Fill in any additional details (Field 17) about the move, such as the address and building information.
- Specify the room number (Field 19) and floor (Field 20) of the move.
- If applicable, provide information about elevator access (Field 23) and stairs (Field 22).
- Add any additional notes (Field 24) about the move.

## Field-by-Field Explanation
* **Contact Information (Field 2)**: This field is where you can enter your contact information.
* **Type of Move (Field 3)**: This field asks for the type of move: in-house, out-of-state, or out-of-country.
* **Moving Dates (Field 5)**: Please enter the moving dates in the format 'YYYY-MM-DD'.
* **Moving Time (Field 6)**: Enter the moving time in 24-hour format (HH:MM).
* **Moving From (Field 7)** and **Moving To (Field 8)**: Please specify the locations for the move. Select multiple options as applicable.
* **Moving Distance (Field 9)**: If applicable, enter the distance of the move.
* **Moving Estimate (Field 10)**: Provide an estimate for the move.
* **Contact Method (Field 11)**: Choose how the moving company should contact you.
* **Contact Number (Field 12)**: If you have selected phone as the contact method, enter your contact number.
* **Contact Email (Field 13)**: If you have selected email as the contact method, enter your contact email.
* **Move Date (Field 14)** and **Move Time (Field 15)**: Enter the move date and time if they differ from the original moving dates and time.
* **Move Comments (Field 16)**: Add any notes about the move.
* **Address (Field 17)**: Specify the address of the move, including the building information if necessary.
* **Building (Field 18)**: Enter the building number of the move.
* **Room Number (Field 19)**: Specify the room number of the move.
* **Floor (Field 20)**: Enter the floor of the move.
* **Elevator (Field 21)** and **Stairs (Field 22)**: Check if elevator is available and if you need to access it.
* **Elevator Access (Field 23)**: If applicable, check if you have access to the elevator.
* **Stairs (Field 24)**: Check if the move is accessible by stairs.
* **Notes (Field 24)**: Add any additional notes about the move.
* **Moving Company (Field 25)**: Select the moving company you want to use for the move.
