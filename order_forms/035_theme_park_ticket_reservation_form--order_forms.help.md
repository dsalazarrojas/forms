# Theme Park Ticket Reservation Form - Help Guide
## Purpose
This form is designed to help users book theme park tickets in advance. It is not a required form, but users must provide accurate and valid information to complete the process successfully.

## How To Complete This Form
- To start, select the type of ticket you require from the "Theme Park Tickets" options (e.g., Single Day, Multi Day, Season, or Membership).
- Choose a visit date and time using the "Visit Date" and "Theme Park Visit Time" fields, respectively.
- If you have selected a ticket type that requires a "Yes" or "No" answer, select the correct option.
- Enter the quantity of tickets you require in the "Ticket Quantity" field.
- Provide the name, email address, and phone number of each guest in the dedicated fields.
- Add any special instructions or additional information in the "Special Instructions" and "Additional Info" fields.
- Select your preferred payment method and provide any required payment details.
- Finally, review your selections and submit the form. If you need to cancel, click the "Cancel" button.

## Field-by-Field Explanation
* **Theme Park Tickets** (`theme_park_tickets`, select_multiple, required/optional): Select the type of ticket you require from the options: Single Day, Multi Day, Season, or Membership.
* **Visit Date** (`visit_date`, date, required/optional): Enter the date you would like to visit the theme park.
* **Ticket Type** (`ticket_type`, select_one, required/optional): Select "Yes" if you have selected a ticket type that requires it, otherwise, select "No".
* **Ticket Quantity** (`ticket_quantity`, number, required/optional): Enter the number of tickets you require.
* **Guest Name** (`guest_name`, text, required/optional): Enter the name of each guest.
* **Guest Email** (`guest_email`, email, required/optional): Enter the email address of each guest.
* **Guest Phone** (`guest_phone`, text, required/optional): Enter the phone number of each guest.
* **Special Instructions** (`special_instructions`, note, required/optional): Add any special instructions or requests.
* **Payment Method** (`payment_method`, select_one, required/optional): Select "Yes" if you have a preferred payment method, otherwise, select "No".
* **Payment Details** (`payment_details`, text, required/optional): Enter any required payment details.
* **Additional Info** (`additional_info`, text, required/optional): Add any additional information.
* **Theme Park Tour** (`theme_park_tour`, select_one, required/optional): Select "Yes" if you would like to book a theme park tour, otherwise, select "No".
* **Theme Park Visit Time** (`theme_park_visit_time`, time, required/optional): Choose the visit time.
* **Submit** (`submit`, text, required/optional): Review your selections and submit the form.
* **Cancel** (`cancel`, text, required/optional): Click to cancel the form without submitting.
* **Confirm Submit** (`confirm_submit`, text, required/optional): Confirm your submission.
* **Confirm Cancel** (`confirm_cancel`, text, required/optional): Confirm cancellation.
* **Theme Park Tour** (`theme_park_tour`, select_one, required/optional): Select "Yes" if you would like to book a theme park tour, otherwise, select "No".
