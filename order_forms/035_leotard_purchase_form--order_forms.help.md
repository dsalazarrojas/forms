# Leotard Purchase Form - Help Guide
## Purpose
The Leotard Purchase Form is a tool used by our team to collect information from customers who want to order leotards. This form will help us better understand their needs and preferences when it comes to size, color, and other customizations.

## How To Complete This Form
To complete this form, follow these steps:

1. Answer the question about whether you want a leotard or not.
2. Fill out the customer name, email, phone number, and other contact information accurately.
3. Choose your desired leotard size and color.
4. Select any additional features you'd like on your leotard.
5. Provide the date and time you'd like to receive your leotard.
6. Add any additional notes or instructions for the order.
7. Enter your customer address accurately.
8. Choose the type of order you're placing.
9. Provide any additional details about your order.
10. Enter your zip, city, state, and country for shipping purposes.
11. Choose the correct country code for your location.

## Field-by-Field Explanation
- **Leotard size**: Choose the size of the leotard you want.
  * Yes: Select this option if you want a leotard.
  * No: Select this option if you don't want a leotard.
- **Customer name**: Enter your name accurately.
- **Customer email**: Enter your email address accurately.
- **Customer phone**: Enter your phone number accurately.
- **Leotard color**: Choose the color of the leotard you want.
  * Yes: Select this option if you want a leotard.
  * No: Select this option if you don't want a leotard.
- **Leotard size option**: Select any additional features you'd like on your leotard.
  * Yes: Select this option if you want a feature.
  * No: Select this option if you don't want a feature.
- **Leotard color option**: Select any additional features you'd like on your leotard.
  * Yes: Select this option if you want a feature.
  * No: Select this option if you don't want a feature.
- **Date**: Enter the date you'd like to receive your leotard.
- **Time**: Enter the time you'd like to receive your leotard.
- **Note**: Add any additional notes or instructions for the order.
- **Customer address**: Enter your customer address accurately.
- **Order type**: Choose the type of order you're placing.
  * Yes: Select this option if you want a leotard.
  * No: Select this option if you don't want a leotard.
- **Order details**: Provide any additional details about your order.
- **Customer zip**: Enter your zip code accurately.
- **Customer city**: Enter your city accurately.
- **Customer state**: Enter your state accurately.
- **Customer country**: Enter your country accurately.
- **Customer country code**: Choose the correct country code for your location.
  * Yes: Select this option if you have a country code.
  * No: Select this option if you don't have a country code.
