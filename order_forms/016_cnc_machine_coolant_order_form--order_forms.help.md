# CNC Machine Coolant Order Form - Help Guide
## Purpose
This form is used to place an order for CNC machine coolant. It collects information about the customer, the coolant required, and the delivery details.

## How To Complete This Form

1. Please fill in your orderer information (name, email, phone number, company name, and department).
2. Select the type of coolant you need (synthetic, semi-synthetic, soluble oil, straight oil, water-soluble coolant, high-performance coolant, or other).
3. Choose the brand of coolant you prefer (Master Chemical, Blaser Swisslube, Houghton, Castrol, Mobil, Cimcool, no preference, or other).
4. Select the package size you need (1 gallon, 5 gallon pail, 15 gallon drum, 30 gallon drum, 55 gallon drum, 275 gallon tote, or bulk delivery).
5. Enter the number of containers you need.
6. If you have specific concentration requirements, enter them in the concentration ratio field.
7. List the machines that this coolant is intended for use with.
8. Select the types of applications where this coolant will be used (milling, turning, grinding, drilling, tapping, threading, general machining, or other).
9. List the materials that you will be cutting (steel, stainless steel, aluminum, cast iron, titanium, brass, copper, plastics, composites, or other).
10. Select the delivery urgency (rush, urgent, standard, flexible).
11. If you would like to specify a preferred delivery date, enter it in the preferred delivery date field.
12. Select the payment method (purchase order, credit card, company account, invoice, wire transfer).
13. If you have a purchase order number, enter it.
14. Add any special instructions or delivery requirements.
15. Enter any additional comments or information.

## Field-by-Field Explanation

* **Orderer Name**: Your full name.
* **Email Address**: Your work email address.
* **Phone Number**: Your best contact number.
* **Company Name**: Your organization.
* **Department**: Your department.
* **Shipping Address**: Complete street address.
* **City**: City for delivery.
* **State**: State or province.
* **ZIP Code**: Postal code.
* **Coolant Type**: Select the type of coolant you need.
* **Coolant Brand**: Select the brand of coolant you prefer.
* **Container Size**: Select the package size you need.
* **Quantity**: Number of containers.
* **Concentration Ratio**: If you have specific concentration requirements, enter them here.
* **Machine Compatibility**: What machines will use this coolant.
* **Application Type**: Select the types of applications where this coolant will be used.
* **Materials Being Machined**: List the materials that you will be cutting.
* **Delivery Urgency**: Select the delivery urgency.
* **Preferred Delivery Date**: If you would like to specify a delivery date, enter it here.
* **Payment Method**: Select the payment method.
* **Purchase Order Number**: Enter your purchase order number if applicable.
* **Special Instructions**: Add any delivery notes or requirements.
* **Additional Comments**: Add any other information.
