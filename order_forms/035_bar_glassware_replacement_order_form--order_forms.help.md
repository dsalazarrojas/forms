**Bar Glassware Replacement Order Form - Help Guide**

**Purpose**
This form is intended for bar or restaurant staff to request replacement glassware for their establishment. Please use this form to provide all the necessary information for a prompt and efficient ordering process.

**How To Complete This Form**
Before starting, ensure you have all the required information ready. Please answer each question carefully, as the information provided will help us to process your order correctly. 

**Field-by-Field Explanation**

* **Order Date** (`order_date`, required): The date you are requesting the glassware replacement, in the format "YYYY-MM-DD".
* **Establishment Name** (`establishment_name`, required): The name of your bar or restaurant.
* **Location Address** (`location_address`, required): The address where the glassware is to be delivered.
* **Manager Name** (`manager_name`, required): The name of the person placing the order.
* **Email Address** (`manager_email`, required): The contact email for the order.
* **Phone Number** (`manager_phone`, required): The contact phone number for the order.
* **Type of Glassware Needed** (`glassware_type`, required): Select the type of glassware you are ordering (e.g. Highball Glasses, Lowball/Old Fashioned Glasses, etc.).
* **Glass Size** (`glass_size`, optional): Select the size of the glassware you need (e.g., 1-2 oz, 3-4 oz, etc.).
* **Quantity Needed** (`quantity_needed`, required): The number of glassware pieces you are ordering.
* **Glass Color Preference** (`glass_color`, optional): Select the preferred color of the glassware (e.g., Clear, Amber, etc.).
* **Brand Preference** (`brand_preference`, optional): If you have a specific brand preference for the glassware.
* **Reason for Replacement** (`replacement_reason`, required): The reason you are requesting a replacement (e.g., Broken or Damaged, Worn Out, etc.).
* **Describe Condition or Issue** (`replacement_description`, optional): If applicable, provide details about the condition or issue with the existing glassware.
* **Urgency Level** (`urgency_level`, required): The urgency level for the order (e.g., Routine Order, Standard Priority, Expedited, etc.).
* **Date Needed By** (`delivery_date_needed`, required): The date you need the glassware by.
* **Packaging Preference** (`packaging_preference`, optional): The preferred packaging method for the glassware (e.g., Standard Carton, Protective Padding, etc.).
* **Delivery Instructions** (`delivery_instructions`, optional): Any special delivery instructions or notes.
* **Service or Replacement Contract** (`service_contract`, optional): If you have a service or replacement contract, please indicate.
* **Service Contract Number** (`contract_number`, optional): If applicable, please provide the service contract number.
* **Approved Budget Amount** (`budget_approved`, optional): The maximum approved spending for the order.
* **Purchase Order Number** (`purchase_order_number`, optional): If applicable, please provide the purchase order number.
* **Special Requirements or Notes** (`special_requirements`, optional): Any other specific needs or requirements for the order.

Please fill out the form carefully, ensuring all required fields are completed. If you have any questions or concerns, please reach out to us for assistance.
