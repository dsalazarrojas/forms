# supplies order form - Help Guide
## Purpose
The "Supplies Order Form" is used to gather information to create or update an order for supplies within the organization's internal workflow.

## How To Complete This Form
- To complete this form, start by entering the Item Description in the "Item Description" field.
- Enter the correct Item Quantity in the "Item Quantity" field.
- Select the User ID of the person responsible for the order in the "User ID" field.
- Enter the date of the order in the "Order Date" field.
- Enter the time of the order in the "Order Time" field.
- Select the status of the order from the "Status" drop-down list.
- Select the user assigned to process the order from the "Assigned User" drop-down list.
- Optionally, add any notes regarding the order in the "Note" field.
- Finally, review and submit the form.

## Field-by-Field Explanation

* **Item Description** (`item_desc`, text, required): Enter a brief description of the item being ordered.
* **Item Quantity** (`item_qty`, number, required): Enter the quantity of the item being ordered.
* **User ID** (`user_id`, number, required): Select the ID of the user responsible for processing the order.
* **Order Date** (`order_date`, date, required): Enter the date of the order.
* **Order Time** (`order_time`, time, required): Enter the time of the order.
* **Status** (`status`, select_one, required): Select the current status of the order.
* **Assigned User** (`assigned_user`, select_one, required): Select the user assigned to process the order.
* **Note** (`note`, note, optional): Enter any additional notes about the order.
* **Submit** (`submit`, text, optional): Review and submit the form once all fields are complete.
 

## Tips
- Double-check the information entered to ensure accuracy.
- If you are unsure about any field, refer to the relevant documentation or seek assistance from a colleague.
