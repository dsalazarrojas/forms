# Cleaning Service Quotation Form - Help Guide
## Purpose
This form is designed to gather information from customers about their cleaning needs for a specific property. It is meant to help customers provide accurate details about their property and cleaning requirements, allowing the cleaning services company to provide a precise quote.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in your contact information (First Name, Last Name, Email Address, Phone Number)
2. Provide details about the property to be cleaned (Property Type, Property Size, Number of Rooms, etc.)
3. Specify the type and frequency of cleaning services needed
4. Choose a preferred start date and time for the service
5. Select a preferred method for receiving the quote
6. Provide any additional information or special instructions

## Field-by-Field Explanation

- **First Name** (`customer_first_name`, Text, Required): Enter your first name for contact purposes.
- **Last Name** (`customer_last_name`, Text, Required): Enter your last name for contact purposes.
- **Email Address** (`email_address`, Email, Required): Enter your email address where you can be contacted.
- **Phone Number** (`phone_number`, Text, Required): Enter your contact phone number.
- **Company Name** (`company_name`, Text, Optional): If applicable, enter the name of the company.
- **Property Type** (`property_type`, Select One, Required): Select the type of property (e.g. Residential, Commercial, etc.).
- **Property Size** (`property_size`, Select One, Required): Select the approximate square footage of the property.
- **Number of Rooms** (`number_of_rooms`, Select One, Optional): Select the total number of rooms or areas to be cleaned.
- **Number of Bathrooms** (`number_of_bathrooms`, Select One, Optional): Select the number of bathrooms, if applicable.
- **Number of Floors** (`floors_in_property`, Select One, Required): Select how many floors need cleaning.
- **Type of Cleaning Needed** (`cleaning_type`, Select One, Required): Select the type of cleaning needed (e.g. Standard, Deep, etc.).
- **Service Frequency** (`service_frequency`, Select One, Required): Select how often the service is needed (e.g. Weekly, Bi-Weekly, etc.).
- **Additional Services Required** (`additional_services`, Select Multiple, Required): Select any extra services needed (e.g. carpet cleaning, window cleaning, etc.).
- **Current Cleanliness Level** (`current_cleanliness`, Select One, Required): Select the current cleanliness level of the property.
- **When Was Last Professional Cleaning** (`last_professional_cleaning`, Select One, Required): Select when the last professional cleaning was done.
- **Special Circumstances** (`special_circumstances`, Text, Optional): If any special circumstances apply, provide details.
- **Preferred Start Date** (`preferred_start_date`, Date, Required): Choose a preferred start date for the service.
- **Preferred Time of Day** (`preferred_time`, Select One, Required): Select a preferred time of day for the service.
- **Preferred Days of Week** (`preferred_days`, Select Multiple, Required): Select the days of the week the service should take place.
- **How Should We Send Your Quote** (`quote_delivery_method`, Select One, Required): Select a preferred method for receiving the quote (e.g. Email, Phone Call, etc.).
- **Expected Budget Range** (`budget_range`, Select One, Optional): If you have an expected budget range, select it.
- **When Do You Need Service** (`timeline_for_decision`, Select One, Required): Select when you need the service (e.g. As Soon as Possible, Within 1 Week, etc.).
- **Are You Getting Other Quotes** (`competing_quotes`, Select One, Optional): If you are comparing services, select yes.
- **Do You Have Pets** (`pets_in_property`, Select One, Optional): If you have pets, select yes.
- **Allergies or Chemical Sensitivities** (`allergies_or_sensitivities`, Text, Optional): If you have allergies or chemical sensitivities, provide details.
- **Special Instructions or Requests** (`special_instructions`, Text, Optional): If you have any special requests or instructions, provide details.
- **Property Access Information** (`access_information`, Text, Optional): If any additional access information is required, provide details.
- **Parking Availability** (`parking_availability`, Text, Optional): If parking is available for the cleaners, provide details.
- **How Did You Hear About Us** (`how_did_you_hear`, Select One, Optional): If you know how you heard about the cleaning services, select an option.
- **Additional Comments or Questions** (`additional_comments`, Text, Optional): If you have any further comments or questions, provide details.
- **Quote Request Date** (`request_date`, Date, Required): Provide the date of this request.
- **Are You Getting Other Quotes** (`competing_quotes`, Select One, Optional): If you are comparing services, select yes.
- **Pets in Property** (`pets_in_property`, Select One, Optional): If you have pets, select the type of pets.
