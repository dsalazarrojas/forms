# Customer Package Usage Log Form - Help Guide
## Purpose
This form is designed to collect and record information related to the usage of a specific package. It allows customers to provide details about their package usage, enabling the organization to track and monitor package usage.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter your name in the "Customer Name" field. This will help us identify you and associate your package usage information with your account.
2. Enter the package number in the "Package Number" field. This is the unique identifier for the package you are reporting on.
3. Enter the start date you began using the package in the "Start Date" field. This is the date when you started using the package.
4. Enter the end date you finished using the package in the "End Date" field. This is the date when you finished using the package.
5. In the "Usage Details" field, provide a brief description of how you used the package. This will help us understand how you utilized the package.
6. Enter your email address in the "Customer Email" field. This is used to contact you regarding your package.
7. Select the current status of your package from the options in the "Package Status" field. This will help us track the package's current state.
8. If you have returned or lost the package, enter the reason in the "Reason for Return" field. This will help us understand why the package was not used.
9. Optionally, enter the name of the user who was assigned to handle your package in the "Assigned User" field.

## Field-by-Field Explanation
* **Customer Name (1)**: Enter your name as it appears on your account or contact information.
* **Package Number (2)**: Enter the unique identifier for the package you are reporting on.
* **Start Date (3)**: Enter the date you began using the package.
* **End Date (4)**: Enter the date you finished using the package.
* **Usage Details (5)**: Provide a brief description of how you used the package.
* **Customer Email (6)**: Enter your email address, which we will use to contact you regarding your package.
* **Package Status (7)**: Select the current status of your package from the provided options.
* **Reason for Return (8)**: If you have returned or lost the package, enter the reason here.
* **Assigned User (9)**: Optionally, enter the name of the user who was assigned to handle your package.
