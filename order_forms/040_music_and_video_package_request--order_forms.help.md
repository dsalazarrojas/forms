# Music And Video Package Request - Help Guide
## Purpose
The Music And Video Package Request form is a tool used to gather information about an event, including its name, type, date, time, and venue, as well as the client's preferences for the event.

## How To Complete This Form

To complete this form, please follow these steps:

1. Enter the name of the event.
2. Select the type of event (Music Package, Video Package, or Both).
3. Enter the date of the event.
4. Enter the time of the event.
5. Enter the type of package required.
6. Enter the client's email address.
7. Enter a description of the event.
8. Enter the client's name.
9. Select the type of form to use for the event (Drag and Drop Form, Code Form, or Default Form).
10. (Optional) Enter any additional package details or event venue information.

## Field-by-Field Explanation

* **Event Name** (`event_name`, text, required): Enter the name of the event.
* **Event Type** (`event_type`, select_one, required): Select the type of event (Music Package, Video Package, or Both).
* **Event Date** (`event_date`, date, required): Enter the date of the event in YYYY-MM-DD format.
* **Event Time** (`event_time`, time, required): Enter the time of the event in 24-hour format (HH:MM).
* **Package Type** (`package_type`, text, required): Enter the type of package required.
* **Client Email** (`client_email`, email, required): Enter the client's email address.
* **Event Description** (`event_description`, text, required): Enter a description of the event.
* **Client Name** (`client_name`, text, required): Enter the client's name.
* **Event Details** (`event_venue`, text, optional): If required, enter any additional event venue details.
* **Event Form** (`event_details_form`, select_one, required): Select the type of form to use for the event (Drag and Drop Form, Code Form, or Default Form).
* **Package 1, 2, 3, ...** (`client_preferences_0`, `client_preferences_1`, `client_preferences_2`, `client_preferences_3`, `client_preferences_4`, `client_preferences_5`, `client_preferences_6`, text, optional): Enter any additional package details or client preferences for the event.
