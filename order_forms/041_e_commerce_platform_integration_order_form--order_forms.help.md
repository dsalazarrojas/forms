# E Commerce Platform Integration Order Form - Help Guide
## Purpose
The E Commerce Platform Integration Order Form is designed to collect necessary information for setting up new e-commerce platform integrations. This form helps our team gather required data for a smooth integration process.

## How To Complete This Form
To complete this form, please follow these steps:

1. Select the platform you are integrating (Shopify, WooCommerce, or BigCommerce).
2. Enter the date and time you would like to schedule the integration.
3. Choose the method of integration (API or Other).
4. Provide your email address and phone number.
5. Enter any additional notes for our team.
6. Select the store's API version.
7. Select the order status and integration type.
8. Choose the payment method.
9. Enter the store's shipping address.
10. Choose the store's language.
11. Enter your customer's name and email.
12. Enter the store's ID.
13. Enter the API version.

## Field-by-Field Explanation

* **Platform Name (id: 2)**: Select the e-commerce platform you are integrating (Shopify, WooCommerce, or BigCommerce).
* **Order Date (id: 3)**: Enter the date you would like to schedule the integration (YYYY-MM-DD).
* **Integration Method (id: 5)**: Choose between API and Other for the integration method.
* **Email Address (id: 7)**: Enter your email address for communication purposes.
* **Contact Number (id: 8)**: Enter your phone number for communication purposes.
* **API Credentials (id: 9)**: Enter the API credentials for the integration (if applicable).
* **Store URL (id: 10)**: Enter the store's URL (if applicable).
* **Integration Type (id: 11)**: Select between Full and Partial integrations.
* **Order Status (id: 12)**: Select the order status (New, Pending, or Cancelled).
* **Payment Method (id: 13)**: Choose between Card, PayPal, and Bank as the payment method.
* **Shipping Address (id: 14)**: Enter the store's shipping address.
* **Store Language (id: 15)**: Select the store's language (English, Spanish, or French).
* **Customer Name (id: 16)**: Enter the customer's name.
* **Customer Email (id: 17)**: Enter the customer's email.
* **Store ID (id: 18)**: Enter the store's ID.
* **API Version (id: 19)**: Enter the API version.
* **Notes 2 (id: 20)**: Enter any additional notes for our team.
* **Api Credentials 2 (id: 21)**: Enter the API credentials for the integration (if applicable).
* **Store Url 2 (id: 22)**: Enter the store's URL (if applicable).
* **Order Status 2 (id: 23)**: Select the order status (New, Pending, or Cancelled).
* **Integration Type 2 (id: 24)**: Select between Full and Partial integrations.
* **Payment Method 2 (id: 25)**: Choose between Card, PayPal, and Bank as the payment method.

## Tips

* Please ensure all fields are filled out correctly to avoid delays in the integration process.
* If you are unsure about any field, feel free to reach out to our support team for guidance.
* Provide accurate information to avoid any errors or issues during the integration process.
