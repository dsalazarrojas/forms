# Order Fulfillment Communication Form - Help Guide
## Purpose
The Order Fulfillment Communication Form is used for customers and employees to exchange information and updates on order fulfillment status, customer comments, and other relevant details.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out each section one at a time, reviewing the information as you go to ensure accuracy.
2. Use clear and concise language to convey your message or update.

## Field-by-Field Explanation
### **Order ID** (`order_id`, `number`, required: false)
* Enter the customer's order ID to reference the specific order being discussed.
### **Customer Email** (`customer_email`, `email`, required: false)
* Enter the customer's email address to ensure that the customer can receive updates and messages.
### **Customer Name** (`customer_name`, `text`, required: false)
* Enter the customer's name for identification and reference purposes.
### **Customer Comment** (`customer_comment`, `note`, required: false)
* Enter any comments or messages from the customer regarding the order.
### **Customer Phone** (`customer_phone`, `text`, required: false)
* Enter the customer's phone number for communication purposes.
### **Customer Message Type** (`customer_message_type`, `select_multiple`, required: false)
* Select the type of message you want to send to the customer (text, email, in-app, or file).
### **Customer Message** (`customer_message`, `text`, required: false)
* Enter the message to be sent to the customer based on the selected message type.
### **Employee Comment** (`employee_comment`, `note`, required: false)
* Enter any comments or updates from the employee handling the order.
### **Employee Name** (`employee_name`, `text`, required: false)
* Enter the employee's name for identification and reference purposes.
### **Employee Phone** (`employee_phone`, `text`, required: false)
* Enter the employee's phone number for communication purposes.
### **Employee Message Type** (`employee_message_type`, `select_multiple`, required: false)
* Select the type of message you want to send to the customer (text, call, email, or in-app).
### **Employee Message** (`employee_message`, `text`, required: false)
* Enter the message to be sent to the customer based on the selected message type.
### **Order Fulfillment Status** (`order_fulfillment_status`, `select_one`, required: false)
* Select the current status of the order (pending, fulfilled, or cancelled).
### **Order Fulfillment Date** (`order_fulfillment_date`, `date`, required: false)
* Enter the date of order fulfillment.
### **Order Fulfillment Communication Method** (`communication_method`, `select_multiple`, required: false)
* Select the method of communication to be used (email, phone, or in-app).
### **Attachment** (`attachment`, `text`, required: false)
* If applicable, upload any attachments related to the order.
### **Upload Attachment** (`upload_attachment`, `text`, required: false)
* Upload any additional attachments related to the order.
### **Order Comment** (`order_comment`, `note`, required: false)
* Enter any comments or updates from the employee on the order.
### **Employee Message Type (again)** (`employee_message_type`, `select_multiple`, required: false)
* Select the type of message you want to send to the customer (text, call, email, or in-app).
### **Order Fulfillment Status (again)** (`order_fulfillment_status`, `select_one`, required: false)
* Select the current status of the order (pending, fulfilled, or cancelled).
### **Attachment (again)** (`attachment`, `text`, required: false)
* If applicable, upload any additional attachments related to the order.

## Tips

* Please be clear and concise in your communication to ensure that the customer and employee are on the same page.
* Review the form carefully before sending to ensure that all necessary information is included.
* Use the form to exchange information and updates only, avoiding duplication and unnecessary messages.
