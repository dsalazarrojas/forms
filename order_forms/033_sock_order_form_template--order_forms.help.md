# Sock Order Form Template - Help Guide

## Purpose
The Sock Order Form Template is a template used for creating orders for socks. The form allows you to input information about the customer's order, including their name, contact information, order details, and shipping information. This guide will walk you through how to complete each field and provide explanations for each field's purpose.

## How To Complete This Form
To complete this form, start by filling out the customer's contact information, such as their first name, last name, and email. You can then input the customer's order details, including the quantity of socks they want to purchase, the color of the socks, and any order comments. Next, input the store information, such as the store name and store contact information. Finally, input the shipping information, including the shipping city, state, and country.

## Field-by-Field Explanation

* **First Name (id: 1)** (`First Name`, `text`, required: false): Enter the customer's first name.
* **Last Name (id: 2)** (`Last Name`, `text`, required: false): Enter the customer's last name.
* **Email (id: 3)** (`Email`, `email`, required: false): Enter the customer's email address.
* **Phone (id: 4)** (`Phone`, `text`, required: false): Enter the customer's phone number.
* **Quantity (id: 5)** (`Quantity`, `number`, required: false): Enter the number of socks to purchase.
* **Color (id: 6)** (`Color`, `select_one`, required: false): Select the color of the socks from the options.
* **Sizes (id: 7)** (`Sizes`, `select_multiple`, required: false): Select the sizes of the socks from the options. Note: This field is meant to be used to input multiple sizes, so separate each size with a comma (e.g. Small, Medium, Large).
* **Date (id: 8)** (`Date`, `date`, required: false): Enter the date for the order.
* **Time (id: 9)** (`Time`, `time`, required: false): Enter the time for the order.
* **Notes (id: 10)** (`Notes`, `note`, required: false): Enter any additional notes about the order.
* **Team Name (id: 11)** (`Team Name`, `text`, required: false): Enter the team name for the order.
* **Team Email (id: 12)** (`Team Email`, `email`, required: false): Enter the team email address.
* **Team Phone (id: 13)** (`Team Phone`, `text`, required: false): Enter the team phone number.
* **Store Name (id: 14)** (`Store Name`, `text`, required: false): Enter the store name.
* **Store Info (id: 15)** (`Store Info`, `text`, required: false): Enter any additional store information.
* **Order Comments (id: 16)** (`Order Comments`, `text`, required: false): Enter any comments about the order.
* **Order Status (id: 17)** (`Order Status`, `select_one`, required: false): Select the status of the order from the options.
* **Order Type (id: 18)** (`Order Type`, `select_multiple`, required: false): Select the type of order from the options. Note: This field is meant to be used to input multiple types, so separate each type with a comma (e.g. Retail, Wholesale).
* **Shipping Info (id: 19)** (`Shipping Info`, `text`, required: false): Enter any additional shipping information.
* **Shipping Address (id: 20)** (`Shipping Address`, `text`, required: false): Enter the shipping address.
* **Shipping City (id: 21)** (`Shipping City`, `text`, required: false): Enter the city for the shipping address.
* **Shipping State (id: 22)** (`Shipping State`, `text`, required: false): Enter the state for the shipping address.
* **Shipping Zip (id: 23)** (`Shipping Zip`, `text`, required: false): Enter the zip code for the shipping address.
* **Shipping Country (id: 24)** (`Shipping Country`, `text`, required: false): Enter the country for the shipping address.
* **Order Notes (id: 25)** (`Order Notes`, `note`, required: false): Enter any additional notes about the order.

Note: All fields are optional unless otherwise noted.
