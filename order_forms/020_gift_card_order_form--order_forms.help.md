# Gift Card Order Form - Help Guide
## Purpose

The Gift Card Order Form is a tool used to create a gift card order for a specific recipient. This form helps users to gather information such as the gift card type, order details, and recipient contact information to process the order efficiently and accurately.

## How To Complete This Form

1.  To complete this form, follow these steps:
   1.  **User Input**: Enter any additional information relevant to the order in this field. 
   2.  **Order Details**: Enter a brief description of the gift order in this field. 
   3.  **Gift Card Type**: Select the type of gift card you want to order (e.g., Option 1, Other - Cash). 
   4.  **Order Date**: If you know the date of the order, you can enter it here. 
   5.  **Order Value**: Enter the value of the order. 
   6.  **Email**: Enter the email address of the recipient. 
   7.  **Recipient Name**: Enter the name of the recipient. 
   8.  **Recipient Email**: Enter the email address of the recipient.

## Field-by-Field Explanation

*   **User Input** (`user_input`, text, optional): This field is for any additional information the user wants to provide about the order.
*   **Order Details** (`order_details`, text, required): This field is for a brief description of the gift order.
*   **Gift Card Type** (`gift_card_type`, select_one, required): This field allows you to choose the type of gift card you want to order.
*   **Order Date** (`order_date`, date, optional): This field is for the date of the order if you have one.
*   **Order Value** (`order_value`, number, required): This field is for the value of the order.
*   **Email** (`email`, email, optional): This field is for the email address of the person sending the gift card.
*   **Recipient Name** (`recipient_name`, text, optional): This field is for the name of the person receiving the gift card.
*   **Recipient Email** (`recipient_email`, email, optional): This field is for the email address of the recipient.
