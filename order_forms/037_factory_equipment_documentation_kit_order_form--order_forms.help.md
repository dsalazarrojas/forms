# Factory Equipment Documentation Kit Order Form - Help Guide
## Purpose
The Factory Equipment Documentation Kit Order Form is used to collect information for a factory equipment documentation kit order. This form helps to gather details about the order, delivery preferences, and contact information.

## How To Complete This Form
To complete this form, simply fill in the required and optional fields as follows:

1. **Order Details**: Enter a brief description of the order.
2. **Delivery Details**: Enter any specific delivery instructions or requests.
3. **Delivery Type**: Select whether you want the delivery to be "Yes" or "No".
4. **Delivery Date**: Enter the date when you would like to receive the order.
5. **Contact Name**: Enter the name of the contact person.
6. **Contact Email**: Enter the email address of the contact person.
7. **Contact Phone**: Enter the phone number of the contact person.
8. **Quantity Ordered**: Enter the quantity of the equipment documentation kit ordered.
9. **Order Comments**: Enter any additional comments or notes about the order.
10. **Order Status**: Select whether the order is "Active" or "Inactive".

## Field-by-Field Explanation

* **Order Details**: A brief description of the order. Please enter a short summary of the equipment documentation kit you are ordering.
* **Delivery Details**: Any specific delivery instructions or requests. If you have any special delivery requirements, please enter them here.
* **Delivery Type**: Select whether you want the delivery to be "Yes" or "No". If you select "Yes", it means you want the delivery to be fulfilled.
* **Delivery Date**: The date when you would like to receive the order. Please enter the date in the format MM/DD/YYYY.
* **Contact Name**: The name of the contact person. Please enter the name of the person responsible for receiving the order.
* **Contact Email**: The email address of the contact person. Please enter the email address of the person responsible for receiving the order.
* **Contact Phone**: The phone number of the contact person. Please enter the phone number of the contact person.
* **Quantity Ordered**: The quantity of the equipment documentation kit ordered. Please enter the number of kits you need.
* **Order Comments**: Any additional comments or notes about the order. Please enter any additional information you want to include.
* **Order Status**: Select whether the order is "Active" or "Inactive". Please select the status of the order as per the options provided.
