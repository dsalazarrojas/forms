# Bi Fold Door Order Form - Help Guide
## Purpose
This form is designed to collect bi-fold door order information from customers, including customer and project details, door specifications, material selection, and installation and delivery details.

## How To Complete This Form

To complete this form, follow these steps:

1. **Customer Information**
	* Enter your name and email address to create a new order.
	* Enter your phone number to ensure we can contact you for any questions or concerns.
	* If you are a business or contractor, enter your company name.
2. **Project Information**
	* Enter your project name or address to help us identify the order.
	* Select the type of project (e.g., residential, commercial, etc.).
	* Choose the project timeline (e.g., immediately, 1-2 weeks, etc.).
3. **Door Specifications**
	* Enter the number of bi-fold doors you need.
	* Enter the width and height of each door in inches or centimeters.
	* Specify the depth of each door in inches.
	* Choose the panel configuration (e.g., 2 panels, 3 panels, etc.).
4. **Material Selection**
	* Choose the material for each door (e.g., wood, steel, etc.).
	* Select the frame material (e.g., wood, metal, etc.).
	* Select the finish type (e.g., natural wood stain, painted, etc.).
	* If you have a specific color in mind, enter it here.
5. **Features and Hardware**
	* Choose the glass or window option (e.g., clear glass, frosted glass, etc.).
	* Select the hardware finish (e.g., chrome, brass, etc.).
	* Choose the locking mechanism (e.g., basic push-to-close, magnetic latch, etc.).
	* Specify if you need soft close features or not.
6. **Installation and Delivery**
	* If you need installation service, select the option that best fits your needs.
	* Enter the delivery address where you want the doors to be shipped.
	* Choose the delivery method (e.g., standard ground shipping, expedited shipping, etc.).
7. **Budget and Quotes**
	* Select the budget range that fits your needs.
	* If you have any special requirements or custom options, enter them here.
	* Add any additional notes or questions you have.
