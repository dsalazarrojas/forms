# Inventory Check Out Form - Help Guide
## Purpose

The Inventory Check Out Form is used to record the check out of items from the inventory. This form is used by employees to check out items for use or other purposes.

## How To Complete This Form

1. Enter the item name in the "Item Name" field.
2. Enter the item type in the "Item Type" field.
3. Enter the item quantity in the "Item Quantity" field.
4. Enter the item location in the "Item Location" field.
5. Enter any notes about the item in the "Item Notes" field.
6. Select the item status (Checked Out, In Stock, Lost, or Broken) in the "Item Status" field.
7. Enter the item return date in the "Item Return Date" field.
8. Enter the item return time in the "Item Return Time" field.
9. Enter the employee's name in the "Employee Name" field.
10. Enter the employee's phone number in the "Employee Phone" field.
11. Enter the employee's email in the "Employee Email" field.
12. Enter the item return location in the "Item Return Location" field.
13. Have the manager sign the form in the "Manager Signature" field.
14. Enter the customer's name in the "Customer Name" field.
15. Enter the customer's company in the "Customer Company" field.
16. Enter any description of the item in the "Item Description" field.
17. Enter the asset tag of the item in the "Asset Tag" field.
18. Enter the asset number of the item in the "Asset Number" field.
19. Enter the asset location of the item in the "Asset Location" field.
20. Select the asset status (Available, Checked Out, Lost, or Broken) in the "Asset Status" field.
21. Enter the asset condition of the item in the "Asset Condition" field.
22. Enter the asset serial number of the item in the "Asset Serial Number" field.

## Field-by-Field Explanation

* **Inventory Check Out Form** (form_title, text, required): Enter the title of the form, which is "Inventory Check Out Form".
* **Item Name** (item_name, text, required): Enter the name of the item you are checking out.
* **Item Number** (item_number, number, required): Enter the number of the item you are checking out.
* **Item Type** (item_type, select_one, optional): Select the type of item you are checking out. Options: Item Type 1, Item Type 2, Item Type 3.
* **Item Quantity** (item_quantity, number, optional): Enter the quantity of the item you are checking out.
* **Item Location** (item_location, text, optional): Enter the location of the item you are checking out.
* **Item Notes** (item_notes, note, optional): Enter any notes about the item you are checking out.
* **Item Status** (item_status, select_one, optional): Select the status of the item. Options: Checked Out, In Stock, Lost, Broken.
* **Item Return Date** (item_return_date, date, optional): Enter the return date of the item.
* **Item Return Time** (item_return_time, time, optional): Enter the return time of the item.
* **Employee Name** (employee_name, text, required): Enter your name as the employee checking out the item.
* **Employee Phone** (employee_phone, text, required): Enter your phone number as the employee checking out the item.
* **Employee Email** (employee_email, email, required): Enter your email as the employee checking out the item.
* **Item Return Location** (item_return_location, text, optional): Enter the location where the item will be returned.
* **Manager Signature** (manager_signature, text, required): Have the manager sign the form.
* **Customer Name** (customer_name, text, optional): Enter the name of the customer.
* **Customer Company** (customer_company, text, optional): Enter the company of the customer.
* **Item Description** (item_description, text, optional): Enter a description of the item.
* **Asset Tag** (asset_tag, text, optional): Enter the asset tag of the item.
* **Asset Number** (asset_number, text, optional): Enter the asset number of the item.
* **Asset Location** (asset_location, text, optional): Enter the location of the asset.
* **Asset Status** (asset_status, select_one, optional): Select the status of the asset. Options: Available, Checked Out, Lost, Broken.
* **Asset Condition** (asset_condition, text, optional): Enter the condition of the asset.
* **Asset Serial Number** (asset_serial_number, text, optional): Enter the serial number of the asset.

## Tips

* Make sure to fill out all required fields.
* Review all fields carefully before submission.
* Use the correct options in the "Item Type", "Item Status", "Asset Status", and "Asset Condition" fields.
* Enter accurate information about the item and employee.
