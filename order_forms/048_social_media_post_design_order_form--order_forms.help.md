# Social Media Post Design Order Form - Help Guide
## Purpose
The Social Media Post Design Order Form is designed to collect information from clients or designers for social media post design order. The form helps in providing the necessary details for the design process.

## How To Complete This Form
To complete this form, please follow the steps below:

1. Fill out the required fields with accurate information.
2. For the preferred social media platforms, select all the platforms you want the design to be shared on.
3. Choose the design preferences based on your needs.
4. Select the design color scheme, style, and background pattern that best suits your design requirements.
5. Choose the content text color that suits your design style.
6. If required, upload the images according to the number of images you have selected in the "Upload Images" field.
7. Select the image upload type based on the number of images you have uploaded.

## Field-by-Field Explanation
* **Form Submission** (`form_submission`, text, required): This field is a text area where you can provide any additional information about your social media post design order.
* **Client Name** (`client_name`, text, required): Please fill out this field with your name or your company's name for easy identification.
* **Preferred Social Media Platforms** (`preferred_social_media_platforms`, select_multiple, not required): Select all the social media platforms where you want the design to be shared on. You can select multiple platforms by clicking on the platform and holding the Ctrl key for Windows or Command key for Mac.
* **Design Preferences** (`design_preferences`, text, required): Describe your design preferences here, including any specific requirements or themes you want the design to follow.
* **Design Color Scheme** (`design_color_scheme`, select_one, not required): Select the color scheme that suits your design style. Options include Light, Dark, Minimal, and Bright.
* **Design Style** (`design_style`, select_multiple, not required): Select all the design styles you want the design to follow. Options include Modern, Retro, Abstract, and Minimal.
* **Background Pattern** (`background_pattern`, select_one, not required): Select the background pattern that suits your design style. Options include Solid, Textured, Gradient, and Pattern.
* **Content Text Color** (`content_text_color`, select_one, not required): Select the content text color that suits your design style. Options include Default, Dark, White, and Custom.
* **Upload Images** (`upload_images`, number, required): If you have images to upload, select the number of images you want to upload. This will determine the number of image upload fields that will appear.
* **Image Upload Type** (`image_upload_type`, select_one, not required): Select the image upload type based on the number of images you have uploaded. Options include Upload 1 File, Upload 2 Files, Upload 3 Files, and Upload None.
* **Image Upload 1** (`image_upload_1`, text, not required): If you have selected to upload 1 image, fill out this field with the path or URL of the image.
* **Image Upload 2** (`image_upload_2`, text, not required): If you have selected to upload 2 images, fill out this field with the path or URL of the second image.
* **Image Upload 3** (`image_upload_3`, text, not required): If you have selected to upload 3 images, fill out this field with the path or URL of the third image.
* **Image Upload 4** (`image_upload_4`, text, not required): If you have selected to upload 4 images, fill out this field with the path or URL of the fourth image.
* **Submission Status** (`submission_status`, note, not required): This field is a note field where you can provide any additional information about the submission status of your design order.

## Tips
Please make sure to fill out all the required fields accurately and thoroughly. If you have any issues or need help with the form, please contact the designer or the support team.
