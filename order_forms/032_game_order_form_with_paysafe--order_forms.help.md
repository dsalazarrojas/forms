# Game Order Form With Paysafe - Help Guide
## Purpose
This form is for users to create game orders with optional payment methods.

## How To Complete This Form
1. Click on each field to focus on it, and select the relevant information as prompted.
2. Enter the game details:
   - **Game Name**: Enter the name of the game you are ordering.
   - **Player Name**: Enter the name of the player associated with the game order.
3. Select the payment method:
   - **Paysafe**: Check if you are using a payment method called Paysafe.
   - **Paysafe Method Type**: If you are using Paysafe, select the type of Paysafe method you are using.
4. Optionally, enter any additional fees if applicable.

## Field-by-Field Explanation

* **Game Order Number**: <game_order_number> (text, Not Required)
	+ Enter the order number of the game.
* **Paysafe** (text, Not Required)
	+ Check if you are using a payment method called Paysafe.
* **Paysafe Method Type** (text, Not Required)
	+ Select the type of Paysafe method you are using if you are using Paysafe.
* **Game Name** (text, Not Required)
	+ Enter the name of the game you are ordering.
* **Player Name** (text, Not Required)
	+ Enter the name of the player associated with the game order.
* **Game Version** (text, Not Required)
	+ Enter the version of the game you are ordering.
* **Additional Fees** (number, Not Required)
	+ Enter any additional fees if applicable.

## Tips
- Make sure to enter accurate game details and payment information to avoid errors.
- If you are unsure about any field, ask a representative for assistance.
- This form is only an example. Please review the actual form configuration and adjust this guide accordingly.
