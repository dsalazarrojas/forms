# Yearbook Order Form - Help Guide
## Purpose
This form is used to collect information from students to place an order for a yearbook. Please provide all relevant details required for successful processing of the order.

## How To Complete This Form
1. Fill out all required fields (fields with a star (*) next to them) to ensure your order is processed correctly.
2. For the payment method, select one of the options to confirm your payment method.
3. Enter your shipping details in the fields provided.
4. Confirm the yearbook type by selecting 'Yes' or 'No'.
5. Add any comments if necessary to facilitate order processing.

## Field-by-Field Explanation
- **Title** (Yearbook Order Form, text): This is the title of the form to provide a clear indication of what it is for.
- **first_page** (first_page, text, optional): Enter any information you would like to be included on the first page of the yearbook.
- **student_information** (student_information, text, optional): Enter any information about the student to be included in the yearbook.
- **student_name** (student_name, text, optional): Enter the name of the student.
- **student_school** (student_school, text, optional): Enter the name of the student's school.
- **order_details** (order_details, note): Enter any additional details required for the order to be processed.
- **order_date** (order_date, date, optional): Enter the date on which the order is required to be processed.
- **student_grade** (student_grade, number, optional): Select the student's grade level.
- **payment_method** (payment_method, select_one): Select how you wish to pay for the yearbook. This can be Cash, Check, Credit, or Online.
- **shipping_address** (shipping_address, text, optional): Enter the shipping address to be used for shipping the yearbook.
- **payment_amount** (payment_amount, number, optional): Enter the payment amount if not paying online.
- **yearbook_type** (yearbook_type, select_one): Select whether or not the student wants a yearbook.
- **shipping_details** (shipping_details, text, optional): Enter any additional shipping details.
- **student_email** (student_email, email, optional): Enter the email of the student.
- **student_phone** (student_phone, text, optional): Enter the phone number of the student.
- **order_comments** (order_comments, note): Enter any comments or notes about the order.
- **yearbook_order_comments** (yearbook_order_comments, note): Enter any comments or notes about the yearbook order.
- **student_address** (student_address, text, optional): Enter the address of the student.
- **shipping_city** (shipping_city, text, optional): Enter the city of the shipping address.
- **shipping_state** (shipping_state, text, optional): Enter the state of the shipping address.
- **shipping_zip** (shipping_zip, text, optional): Enter the zip code of the shipping address.
- **shipping_notes** (shipping_notes, text, optional): Enter any notes about the shipping.
- **order_status** (order_status, select_one): Select the status of the order. This can be Active or Inactive.
- **yearbook_status** (yearbook_status, select_one): Select the status of the yearbook. This can be Active or Inactive.
- **student_signature** (student_signature, select_multiple): Select if the student signature is needed or not. This can be 'Yes' or 'No'.
- **yearbook_comments** (yearbook_comments, note): Enter any comments or notes about the yearbook.
