# Betty’s BAM Nails Order Form - Help Guide
## Purpose
This form is designed to collect information for an order of nail products from Betty’s BAM Nails. It is used to collect customer contact and order details for processing and delivering the product.

## How To Complete This Form

1. Fill out the form with the required information, starting with the "Customer full name," "Customer email address," "Shipping address," "Product selection," and "Payment method."
2. If applicable, fill out the optional fields: "Customer phone number," "Shade code or variant," "Quantity," "Preferred delivery date," "Gift wrap requested," and "Special instructions."
3. Review the form for accuracy before submitting.

## Field-by-Field Explanation

* **Customer full name (1)**: Enter the customer's full name as it should appear on the invoice or receipt.
* **Customer email address (2)**: Enter the customer's email address for order confirmation and tracking.
* **Customer phone number (3)**: Enter the customer's phone number, including country code, for text updates or calls. (Optional)
* **Shipping address (4)**: Enter the shipping address with street, city, state, and postal code.
* **Product selection (5)**: Select the desired nail color or kit from the available options.
* **Shade code or variant (6)**: Enter the shade code if applicable or type N A for no variant.
* **Quantity (7)**: Enter the whole number of units to be ordered.
* **Preferred delivery date (8)**: Enter a preferred delivery date for scheduling. (Optional)
* **Gift wrap requested (9)**: Select yes if you need gift wrapping. (Optional)
* **Special instructions (10)**: Enter any delivery instructions or order notes.
* **Payment method (11)**: Select the preferred payment option from the available options.
* **Order confirmation notes (12)**: This is for internal use only, please do not fill out.

## Tips
* Make sure to fill out all the required fields before submitting the form.
* Use the available options for product selection to ensure the correct product is ordered.
* If you need gift wrapping, select "Yes" for gift wrap requested.
* Review the form carefully before submitting to ensure accuracy.
