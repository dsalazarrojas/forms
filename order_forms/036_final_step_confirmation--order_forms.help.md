The purpose of the "final_step_confirmation" form is to collect and confirm important information regarding an order's completion, including customer details, payment methods, and order status. This form serves as the last step in the order process, ensuring that all necessary information is recorded and verified before an order is considered finalized. This form should be used when an order is already in progress, and the user needs to confirm its completion.

## How To Complete This Form

To complete this form, follow these steps:

1. Fill out the form fields as they appear, ensuring that you have accurate and up-to-date information for each field.
2. Select the appropriate options for "Payment Method" and "Order Status" to reflect the current state of the order.
3. Choose "Customer Approval" options for each customer, indicating their approval status.

## Field-by-Field Explanation

* **Customer Information (customer_info)**: Enter the customer's name and contact information.
* **Payment Details (payment_details)**: Select the payment method used for the order (Credit Card, Bank Transfer, or Other).
* **Order Confirmation (order_confirmation)**: A text field for additional comments or notes regarding the order.
* **Order Summary (order_summary)**: A note field for a brief summary of the order.
* **Customer Notes (customer_notes)**: Additional comments or notes from the customer.
* **Payment Terms (payment_terms)**: Choose the payment terms used for the order (Net 30, Proforma, or Other).
* **Payment Method (payment_method)**: Select the payment method used for the order.
* **Payment Status (payment_status)**: Select the current payment status (Paid, Pending Payment, or Cancelled).
* **Order Status (order_status)**: Choose the current order status (Completed, Cancelled, or Pending).
* **Customer Approval (customer_approval)**: Select the approval status for each customer.

## Tips

* Make sure to select the correct payment method and order status for each order.
* Use the "Order Confirmation" field for any additional comments or notes regarding the order.
* Review the "Order Summary" field for a brief overview of the order.
* Use the "Customer Notes" field for any additional information from the customer.
* Verify the "Customer Approval" status for each customer to ensure accurate information.

Please note that this form is designed to collect and confirm information for orders already in progress, so ensure that you have accurate and up-to-date information before completing the form.
