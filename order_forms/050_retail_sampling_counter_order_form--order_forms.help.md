# Retail Sampling Counter Order Form - Help Guide
## Purpose
The Retail Sampling Counter Order Form is used to collect information about retail sampling orders from customers. This form helps the customer service team to process and manage sampling orders efficiently.

## How To Complete This Form
To complete this form, follow these steps:

1. Start by selecting the type of product from the dropdown list.
2. Enter the customer's details, address, contact number, and email.
3. Specify the order date and time.
4. Provide a note about the order if necessary.
5. Select the order status and assigned user.
6. Enter the assigned date and time.
7. Enter the store name, address, phone number, and email.
8. Enter any additional store details if required.
9. Confirm the customer's confirmation.

## Field-by-Field Explanation

* **Product Type** (`product_type`, `select_one`): Select the type of product you are ordering from the dropdown list.
* **Customer Details** (`customer_details`, `text`): Enter the customer's name, company name, or other relevant information.
* **Address** (`customer_address`, `text`): Enter the customer's address.
* **Contact Number** (`contact_number`, `text`): Enter the customer's contact number.
* **Email** (`email`, `email`): Enter the customer's email address.
* **Order Date** (`order_date`, `date`): Enter the date of the order.
* **Order Time** (`order_time`, `time`): Enter the time of the order.
* **Order Note** (`order_note`, `note`): Provide any additional note about the order if necessary.
* **Order Details** (`order_details`, `text`): Enter any additional details about the order.
* **Order Status** (`order_status`, `select_multiple`): Select the current status of the order from the dropdown list.
* **Assigned User** (`assigned_user`, `select_one`): Select the user assigned to handle the order from the dropdown list.
* **Assigned Date** (`assigned_date`, `date`): Enter the date the order was assigned to the user.
* **Assigned Time** (`assigned_time`, `time`): Enter the time the order was assigned to the user.
* **Assigned User Note** (`assigned_user_note`, `note`): Provide any additional note about the assigned user.
* **Customer Confirmation** (`customer_confirmation`, `select_multiple`): Confirm whether the customer has confirmed the order.
* **Retail Store Details** (`retail_store_details`, `text`): Enter any additional details about the retail store.
* **Store Name** (`store_name`, `select_one`): Select the name of the store from the dropdown list.
* **Store Address** (`store_address`, `text`): Enter the store's address.
* **Store Phone** (`store_phone`, `text`): Enter the store's phone number.
* **Store Email** (`store_email`, `text`): Enter the store's email address.
* **Store Website** (`store_website`, `text`): Enter the store's website.
* **Store Manager** (`store_manager`, `text`): Enter the store manager's name.
* **Store Manager Phone** (`store_manager_phone`, `text`): Enter the store manager's phone number.
* **Store Manager Email** (`store_manager_email`, `text`): Enter the store manager's email address.
