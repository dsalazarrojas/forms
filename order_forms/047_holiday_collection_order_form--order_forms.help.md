# holiday_collection_order_form - Help Guide

## Purpose
This form is designed to create a holiday collection order for customers. It collects information about the customer, collection details, and order specifics to facilitate efficient and accurate processing of the order.

## How To Complete This Form

To complete this form, follow these steps:

1. Enter the **Collection Name** in the "Collection Name" field. This field is required.
2. Enter the **Customer Name** in the "Customer Name" field. This field is required.
3. Enter the **Email** address in the "Email" field. This field is required.
4. Enter the **Phone** number in the "Phone" field. This field is required.
5. Select the **Collection Type** from the dropdown menu in the "Collection Type" field. This field is required.
6. Select the **Product Options** by checking the corresponding checkboxes in the "Product Options" field. This field is required.
7. Enter the **Product Price** in the "Product Price" field. This field is required.
8. Enter the **Quantity** of the product in the "Quantity" field. This field is required.
9. Enter the **Product Weight** (if applicable) in the "Product Weight" field. This field is not required.
10. Select the **Unit Weight** (if applicable) in the "Unit Weight" field. This field is required when Product Weight is selected.
11. Choose the **Payment Method** from the dropdown menu in the "Payment Method" field. This field is required.
12. Enter any **Payment Details** in the "Payment Details" field. This field is required.
13. Enter the **Order Total** in the "Order Total" field. This field is required.
14. Enter any **Customer Message** in the "Customer Message" field. This field is not required.
15. Select the **Collection Status** from the dropdown menu in the "Collection Status" field. This field is required.
16. Enter the **Collection Date** in the "Collection Date" field. This field is required.
17. Enter the **Collection Time** in the "Collection Time" field. This field is required.
18. Enter any **Collection Notes** in the "Collection Notes" field. This field is not required.
19. Enter the **Delivery Address** in the "Delivery Address" field. This field is required.
20. Enter the **Delivery Post Code** in the "Delivery Post Code" field. This field is required.
21. Enter the **Delivery City** in the "Delivery City" field. This field is required.

## Field-by-Field Explanation

* **Collection Name**: Enter the name of the collection you are creating. This field is required.
* **Customer Name**: Enter the name of the customer. This field is required.
* **Email**: Enter the customer's email address. This field is required.
* **Phone**: Enter the customer's phone number. This field is required.
* **Collection Type**: Select the type of collection (e.g., Christmas, Thanksgiving, etc.). This field is required.
* **Product Options**: Select the product options you want to include in the collection. This field is required.
* **Product Price**: Enter the price of the product. This field is required.
* **Quantity**: Enter the quantity of the product. This field is required.
* **Product Weight**: If the product has a weight, enter it here. This field is not required.
* **Unit Weight**: If the product weight has a unit (e.g., kg, g, etc.), select it here. This field is required when Product Weight is selected.
* **Payment Method**: Choose the payment method for the collection (e.g., PayPal, Credit Card, etc.). This field is required.
* **Payment Details**: Enter any additional payment details. This field is required.
* **Order Total**: Enter the total cost of the collection. This field is required.
* **Customer Message**: Enter any message for the customer. This field is not required.
* **Collection Status**: Select the status of the collection (e.g., Pending, Collected, etc.). This field is required.
* **Collection Date**: Enter the date of the collection. This field is required.
* **Collection Time**: Enter the time of the collection. This field is required.
* **Collection Notes**: Enter any additional notes for the collection. This field is not required.
* **Delivery Address**: Enter the delivery address for the collection. This field is required.
* **Delivery Post Code**: Enter the post code for the delivery address. This field is required.
* **Delivery City**: Enter the city for the delivery address. This field is required.

Note: The fields marked as "required" cannot be left blank, and users must fill them out before submitting the form. Fields marked as "not required" can be left blank, but users should fill them out if necessary.
