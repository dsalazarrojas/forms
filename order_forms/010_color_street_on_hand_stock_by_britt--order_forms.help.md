# Color Street On Hand Stock By Britt - Help Guide
## Purpose
The purpose of this form is to track the stock levels and customer reservations of various sets of nail polish glitters, solids, art, French, and seasonal collections.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the relevant date for the stock tracking from the "Tracker Date" field.
2. Enter the number of sets available for each category (Glitter, Solid, Art, French, and Seasonal) in the corresponding fields.
3. Enter the number of sets reserved for customers in the "Number of Sets Reserved" field.
4. Optionally, add customer names for the reserved sets in the "Customer Names for Reservations" field.
5. Add any general notes in the "General Notes" field.

## Field-by-Field Explanation
* **Tracker Date** (1, required): Enter the date for which you want to track the stock levels.
* **-- Category Counts --** (3, note): This is a separator section for the category counts.
* **Glitter Sets (Britt)** (4, required): Enter the number of glitter sets available.
* **Solid Sets (Britt)** (5, required): Enter the number of solid sets available.
* **Art Sets (Britt)** (6, required): Enter the number of art sets available.
* **French Sets (Britt)** (7, required): Enter the number of French sets available.
* **Pedicure Sets (Britt)** (8, required): Enter the number of pedicure sets available.
* **Seasonal Sets (Britt)** (9, required): Enter the number of seasonal sets available.
* **-- Reserved for Customers --** (10, note): This is a separator section for customer reservations.
* **Number of Sets Reserved** (11, optional): Enter the number of sets reserved for customers.
* **Customer Names for Reservations** (12, optional): Enter the names of customers for whom sets are reserved.
* **General Notes** (13, optional): Add any general notes about the stock or customer reservations.
