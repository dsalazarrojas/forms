# Mulch And Straw Cost Estimator - Help Guide
## Purpose
This form is used to estimate the cost of mulch and straw for a project, helping you gather essential details for accurate quotes.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the Project Details section with information about the project, such as project type and size.
2. Enter contact information, including name, email, phone number, and company (if applicable).
3. Provide any additional details or notes about the project in the Notes field.
4. Select the Job Status of the project.
5. Enter any relevant Site Notes, if applicable.
6. Complete the Contact Address and Contact Company fields if necessary.
7. Enter any Job Description or Project Details if required.
8. Add any additional Project Details if needed.
9. Finally, fill in any Contact Notes if necessary.

## Field-by-Field Explanation

* **Project Type** (`project_type`, select_one): Select the type of project, which can be Straw, Mulch, or Other.
* **Project Size** (`project_size`, text): Enter the size of the project.
* **Quantity** (`quantity`, number): Enter the quantity required for the project.
* **Unit Price** (`unit_price`, number): Enter the unit price of the material.
* **Material** (`material`, text): Enter the material required.
* **Notes** (`notes`, note): Add any additional details about the project.
* **Estimated Delivery Date** (`estimated_delivery_date`, date): Enter the estimated delivery date for the project.
* **Delivery Time** (`delivery_time`, time): Enter the estimated delivery time for the project.
* **Contact Name** (`contact_name`, text): Enter the contact person's name.
* **Contact Email** (`contact_email`, email): Enter the contact person's email address.
* **Contact Phone** (`contact_phone`, text): Enter the contact person's phone number.
* **Job Status** (`job_status`, select_one): Select the current job status, which can be In Progress, Completed, or Canceled.
* **Estimated Delivery Time** (`estimated_delivery_time`, time): Enter the estimated delivery time for the project.
* **Estimated Duration** (`estimated_duration`, text): Enter any estimated duration of the project.
* **Project Site** (`project_site`, text): Enter the location or site of the project.
* **Site Notes** (`site_notes`, note): Add any notes related to the project site.
* **Contact Address** (`contact_address`, text): Enter the contact person's business address.
* **Contact Company** (`contact_company`, text): Enter the contact person's company.
* **Job Description** (`job_description`, text): Enter a brief description of the project.
* **Project Details 1** (`project_details_1`, text): Enter any additional details about the project.
* **Project Details 2** (`project_details_2`, text): Enter any additional details about the project.
* **Project Details 3** (`project_details_3`, text): Enter any additional details about the project.
* **Contact Notes** (`contact_notes`, note): Add any additional notes about the contact person.
