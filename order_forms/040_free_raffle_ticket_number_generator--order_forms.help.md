# Free Raffle Ticket Number Generator - Help Guide

## Purpose
The Free Raffle Ticket Number Generator form is designed to generate unique raffle tickets with specific details for events or contests. The form helps you to create raffle tickets with custom settings for random draw, winner announcement, and draw results.

## How To Complete This Form
To complete this form, fill out the following fields with the required information for your raffle event.

## Field-by-Field Explanation

* **Raffle Ticket Number** (`raffle_ticket_number`, number, optional): Enter a unique number for each raffle ticket.
* **Raffle ID** (`raffle_id`, number, optional): Enter a unique ID for the raffle event.
* **Raffle Start Number** (`raffle_start_number`, number, optional): Set the starting number for the raffle draw.
* **Raffle End Number** (`raffle_end_number`, number, optional): Set the ending number for the raffle draw.
* **Raffle Total Tickets** (`raffle_total_tickets`, number, optional): Enter the total number of tickets to be generated.
* **Raffle Winner Announcement** (`raffle_winner_announcement`, select multiple, optional): Choose how the winner will be announced (In-store, Phone, Email, Text Message).
* **Raffle Random Draw** (`raffle_random_draw`, select one, optional): Choose the frequency of the random draw (Daily, Weekly, Monthly).
* **Raffle Start Date** (`raffle_start_date`, date, optional): Set the start date for the raffle event.
* **Raffle End Date** (`raffle_end_date`, date, optional): Set the end date for the raffle event.
* **Raffle Time** (`raffle_time`, time, optional): Set the time for the raffle draw.
* **Raffle Draw Type** (`raffle_draw_type`, select one, optional): Choose the type of draw (Manual, Automated).
* **Raffle Draw Date** (`raffle_draw_date`, date, optional): Set the date for the raffle draw.
* **Raffle Draw Time** (`raffle_draw_time`, time, optional): Set the time for the raffle draw.
* **Raffle Status** (`raffle_status`, select one, optional): Choose the status of the raffle (Open, Closed).
* **Raffle Winner** (`raffle_winner`, select one, optional): Choose if there is a winner (Yes, No).
* **Total Entries** (`raffle_total_entries`, number, optional): Enter the total number of entries for the raffle.
* **Raffle Winner Notification** (`raffle_winner_notification`, select one, optional): Choose if the winner will be notified (Yes, No).
* **Raffle Random Draw Type** (`raffle_random_draw_type`, select one, optional): Choose the type of random draw (Random Draw, Manual Draw).
* **Raffle Random Draw Date** (`raffle_random_draw_date`, date, optional): Set the date for the random draw.
* **Raffle Random Draw Time** (`raffle_random_draw_time`, time, optional): Set the time for the random draw.
* **Raffle Draw Method** (`raffle_draw_method`, select one, optional): Choose the method of the draw (Online Draw, Offline Draw).
* **Raffle Draw Result** (`raffle_draw_result`, select multiple, optional): Choose the draw result (Winner, Runner-Up, No Winner).
* **Raffle Draw Date/Time** (`raffle_draw_date_time`, date, optional): Set the date and time for the draw.
* **Raffle Draw Details** (`raffle_draw_details`, select multiple, optional): Choose the details of the draw (Live Draw, No Draw).
* **Raffle Entry Details** (`raffle_entry_details`, select multiple, optional): Choose the details of the entry (Unique ID, Raffle Name, Raffle Description, Raffle Status, Raffle Draw Method, Raffle Draw Date/Time, Raffle Random Draw Date, Raffle Random Draw Time).

## Tips
* Make sure to fill out all required fields for your raffle event.
* Some fields may be optional, but it is recommended to fill them out for a complete raffle experience.
* The form will check for duplicate IDs to prevent duplicate raffle entries.
