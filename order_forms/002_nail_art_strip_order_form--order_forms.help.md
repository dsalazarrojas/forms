> # Nail Art Strip Order Form - Help Guide

## Purpose

The Nail Art Strip Order Form is used by nail salon staff to record and confirm orders for nail art strips.

## How To Complete This Form

1. Fill out the form accurately and thoroughly.
2. Make sure to include all necessary fields.
3. Double-check the form before submitting.

## Field-by-Field Explanation

* **Nail Art Strip Order Form Page 1** (`nail_art_strip_order_form_page_1`, Text, Optional)
	+ This is the first page of the form.
	+ Enter any relevant information about the order.
* **Order Form** (`order_form`, Text, Optional)
	+ Enter any additional information about the order.
* **Nail Strip Designs** (`nail_strip_designs`, Text, Optional)
	+ List any specific nail strip designs you'd like to include in the order.
* **Options** (`options`, Select Multiple, Optional)
	+ Choose from a selection of nail strip options. (Nail Strip 1, Nail Strip 2, Nail Strip 3, Nail Strip 4, Nail Strip 5, Nail Strip 6, Nail Strip 7, Nail Strip 8, Nail Strip 9, Nail Strip 10)
* **Quantity** (`quantity`, Number, Optional)
	+ Enter the quantity of each nail strip to be ordered.
* **Nail Strip Size** (`nail_strip_size`, Select One, Optional)
	+ Select from the following size options: small, medium, large, extra large.
* **Nail Strip Color** (`nail_strip_color`, Select Multiple, Optional)
	+ Choose from the following color options: Red, Blue, Yellow, Green, Purple, Pink, Orange, Brown.
* **Email** (`email`, Email, Optional)
	+ Enter the email address to contact for this order.

## Tips

* Double-check all fields before submitting the form.
* Make sure to include all necessary fields.
* If you're unsure about any field, ask your supervisor or a colleague for assistance.
* If you've already filled out this form for this order, please ensure it's accurate and up-to-date.
