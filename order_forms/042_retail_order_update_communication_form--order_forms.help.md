# retail_order_update_communication_form - Help Guide
## Purpose
This form is used to update and communicate with customers about their retail orders. It allows users to input and manage information about the order number, customer details, order status, shipping method, shipping date, and other relevant order details. This form is designed to facilitate efficient and accurate communication between customers and retailers.

## How To Complete This Form
1. Ensure you have access to the order number, which is the unique identifier for the order.
2. Fill in the Customer Name and any other relevant customer details.
3. Select the current Order Status from the drop-down options.
4. Choose the Shipping Method from the provided options.
5. Enter the Shipping Date, which should match the expected delivery date.
6. Add any necessary Customer Service Contact information, including email address.
7. Enter any relevant Retailer Notes or Customer Notes.
8. Update the Order Notes as necessary.
9. Select the Shipping Carrier and provide any additional Shipping Status information.
10. Enter the Shipping Cost and Shipping Cost Currency.
11. Set the Estimated Delivery Date and Delivery Date.
12. Select the Delivery Status.

## Field-by-Field Explanation

* **Order Number (1)**: Enter the unique identifier for the order.
* **Customer Name (2)**: Enter the customer's name.
* **Order Status (3)**: Select the current status of the order from the options:
	+ pending
	+ fulfilled
	+ cancelled
* **Shipping Method (4)**: Choose the shipping method used for the order from the options:
	+ standard
	+ priority
	+ express
* **Shipping Date (5)**: Enter the date the order was shipped.
* **Customer Service Contact (6)**: Enter any necessary contact information for the customer.
* **Customer Service Email (7)**: Enter the email address of the customer service team.
* **Retailer Note (8)**: Enter any additional notes about the order or customer.
* **Customer Note (9)**: Enter any notes from the customer.
* **Order Notes (10)**: Add any additional notes about the order.
* **Shipping Carrier (11)**: Enter the shipping carrier used for the order.
* **Order Status Date (12)**: Enter the date the order status was last updated.
* **Shipping Status (13)**: Select the shipping status from the options:
	+ standard
	+ priority
	+ express
* **Shipping Cost (14)**: Enter the cost of shipping.
* **Shipping Cost Currency (15)**: Select the currency used for shipping cost.
* **Estimated Delivery Date (16)**: Enter the expected delivery date.
* **Delivery Date (17)**: Enter the actual delivery date.
* **Delivery Status (18)**: Select the delivery status from the options.
