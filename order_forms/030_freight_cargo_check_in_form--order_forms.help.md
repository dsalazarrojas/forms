# Freight Cargo Check In Form - Help Guide
## Purpose
The Freight Cargo Check In Form is designed to collect necessary information for tracking and documenting cargo shipments.

## How To Complete This Form
To complete this form, follow these steps:

1. Complete each page of the form as directed. Each page is designed to gather specific information for cargo check-in.
2. Ensure to fill out all required fields as indicated.
3. Enter information accurately and consistently.
4. Review and submit the form for review and approval.

## Field-by-Field Explanation
### Page 1
* **form_1_page_1**: Enter a brief description of the cargo shipment, if applicable.

### Page 2
* **form_1_page_2**: Select the type of cargo being transported (option 1, option 2).

### Page 3
* **form_1_page_3**: Select all applicable options for cargo handling or special requirements (option 3, Other).

### Page 4
* **form_1_page_4**: This field is not currently used and is reserved for future development.

### Page 5
* **form_1_page_5**: Enter the expected time of delivery for the cargo, if applicable.

### Page 6
* **form_1_page_6**: Enter the approximate weight of the cargo.

### Page 7
* **form_1_page_7**: Confirm the approximate weight of the cargo.

### Page 8
* **form_1_page_8**: Enter the email address associated with the cargo shipment.

### Page 9
* **form_1_page_9**: Enter any additional comments or remarks related to the cargo shipment, if applicable.
