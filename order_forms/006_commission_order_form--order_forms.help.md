# Commission Order Form - Help Guide
## Purpose
This form is designed to gather information from clients for commission orders, including client details, project specifics, and order submission details. It's essential to complete this form accurately to ensure that the project is properly commissioned and that all parties involved are aware of the agreement.

## How To Complete This Form
1. Please fill out the form in a clear and legible manner.
2. Ensure all required fields (marked as "required") are filled out before proceeding.
3. Review your answers before submitting the form to ensure accuracy.

## Field-by-Field Explanation

* **Full Name (id: 2)** (`<name>`, `text`, **required**): Enter the client's full name as it appears on their official identification or business card.
* **Email Address (id: 3)** (`<name>`, `email`, **required**): Enter the client's email address for communication purposes.
* **Phone Number (id: 4)** (`<name>`, `text`, **optional**): If the client has a preferred phone number, enter it here.
* **Type of Work to be Commissioned (id: 6)** (`<name>`, `select_one`, **required**): Select the type of work to be commissioned (e.g., Digital Art, Software Development, Graphic Design, Writing/Editing, Research).
* **Project Title or Short Name (id: 7)** (`<name>`, `text`, **required**): Enter a descriptive title or short name for the project.
* **Detailed Project Description (id: 8)** (`<name>`, `text`, **required**): Provide a detailed description of the project, including any specific requirements or specifications.
* **Requested Deadline (id: 9)** (`<name>`, `date`, **required**): Enter the date by which the project is to be completed.
* **Estimated Budget (id: 10)** (`<name>`, `number`, **optional**): If applicable, enter the estimated budget for the project.
* **Preferred Final File Format (id: 12)** (`<name>`, `text`, **required**): Specify the preferred file format for the final project deliverable (e.g., PNG, PDF, ZIP).
* **Intended Usage Rights (id: 13)** (`<name>`, `select_one`, **required**): Select the intended usage rights for the project (e.g., Personal Use Only, Commercial Use, Full Rights Ownership).
* **Additional Requirements or Constraints (id: 14)** (`<name>`, `text`, **optional**): If necessary, provide any additional requirements or constraints for the project.
* **Terms and Conditions (id: 15)** (`<name>`, `note`, **optional**): Review the terms and conditions before accepting or declining.
* **I Agree to the Commission Terms and Payment Schedule (id: 16)** (`<name>`, `select_one`, **required**): Select "I agree" to confirm acceptance of the terms and conditions.
* **Order Submission Date (id: 17)** (`<name>`, `date`, **required**): Enter the date the order was submitted.
* **Digital Signature (id: 18)** (`<name>`, `text`, **required**): Type your full name to sign the order submission.

Please fill out the form accurately and thoroughly, and submit it for review and processing.
