# Stock Image Requisition Form - Help Guide
## Purpose

This form is used to request stock images for various projects. Please fill out the form with the necessary details to ensure accurate and efficient processing of your request.

## How To Complete This Form

To complete this form, follow these steps:

1. Select the project type from the provided options.
2. Choose the source of the stock image from the list of available sources.
3. Select the type of image required.
4. Choose the size and resolution of the image as needed.
5. Select the format of the image (e.g., JPEG, PNG, etc.).
6. If required, upload any relevant files or provide a URL for the image.
7. Enter a description of the image request.

## Field-by-Field Explanation

* **Project** (`request_project`, text, optional): Enter the name of the project that requires the stock image.
* **Project Type** (`select_project_type`, select_multiple, required): Select the type of project that this image is for (e.g., marketing, advertising, etc.).
* **Source** (`select_stock_image_source`, select_multiple, required): Choose the source of the stock image (e.g., Getty Images, Shutterstock, etc.).
* **Image Type** (`select_image_type`, select_one, optional): Select the type of image required (e.g., photo, illustration, etc.).
* **Image Size** (`select_image_size`, select_multiple, optional): Choose the size of the image as needed.
* **Resolution** (`select_resolution`, select_multiple, optional): Select the resolution of the image as needed.
* **Image Format** (`select_image_format`, select_multiple, optional): Choose the format of the image (e.g., JPEG, PNG, etc.).
* **File** (`upload_file`, text, optional): If required, upload a file related to the image request.
* **Image URL** (`image_url`, text, optional): Enter a URL for the image if it's already available online.
* **Image Count** (`image_count`, number, optional): Enter the number of images required.
* **File 2** (`upload_file_2`, text, optional): If required, upload an additional file related to the image request.
* **File 2 URL** (`image_url_2`, text, optional): Enter a URL for the second file if it's already available online.
* **Image Count 2** (`image_count_2`, number, optional): Enter the number of second images required.
* **File 3** (`upload_file_3`, text, optional): If required, upload a third file related to the image request.
* **File 3 URL** (`image_url_3`, text, optional): Enter a URL for the third file if it's already available online.
* **Image Count 3** (`image_count_3`, number, optional): Enter the number of third images required.
* **File 5** (`upload_file_5`, text, optional): If required, upload a fifth file related to the image request.
* **File 6** (`upload_file_6`, text, optional): If required, upload a sixth file related to the image request.
* **File 7** (`upload_file_7`, text, optional): If required, upload a seventh file related to the image request.
* **Description** (`description`, text, optional): Enter a brief description of the image request.
