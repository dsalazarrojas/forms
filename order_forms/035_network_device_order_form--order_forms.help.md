# Network Device Order Form - Help Guide
## Purpose
The Network Device Order Form is used to collect information about network devices, including their type, quantity, and other relevant details, for the purpose of tracking and managing network devices within an organization.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the type of network device you are ordering (e.g., Routers, Switches, Other).
2. Enter the number of devices you are ordering.
3. Provide the model of the network device (e.g., Cisco 3500, Juniper SRX320).
4. Enter the requester's name or department responsible for the order.
5. Enter the department or team responsible for the device's location.
6. Enter a brief reason for ordering the device.
7. Provide a detailed description of the equipment.
8. Select the date the device was purchased (if known).
9. Enter the cost of the device (if known).
10. Select the location where the device will be deployed (e.g., Location 1, Location 2, Location 3).
11. Enter the priority level of the device (e.g., 1, 2, 3).
12. Select the status of the device (e.g., Active, Inactive, Pending).
13. Enter any additional comments or notes about the device.
14. Enter the date the order was placed (if known).
15. Select the status of the order (e.g., Pending, Rejected, Approved).
16. Enter any comments about the order.
17. Select the status of the purchase (e.g., Pending, In Progress, Completed).
18. Enter the date the purchase was completed (if known).
19. Enter the name of the vendor or supplier.
20. Enter any additional comments about the device.

## Field-by-Field Explanation
* **Network Device Type** (`network_device_type`): Select the type of network device you are ordering (e.g., Routers, Switches, Other).
* **Network Device Count** (`network_device_count`): Enter the number of devices you are ordering.
* **Network Device Model** (`network_device_model`): Provide the model of the network device (e.g., Cisco 3500, Juniper SRX320).
* **Network Device Requester** (`network_device_requester`): Enter the name or department responsible for ordering the device.
* **Network Device Department** (`network_device_department`): Enter the department or team responsible for the device's location.
* **Network Device Reason** (`network_device_reason`): Enter a brief reason for ordering the device.
* **Network Device Equipment Description** (`network_device_equipment_description`): Provide a detailed description of the equipment.
* **Network Device Purchase Date** (`network_device_purchase_date`): Enter the date the device was purchased (if known).
* **Network Device Cost** (`network_device_cost`): Enter the cost of the device (if known).
* **Network Device Location** (`network_device_location`): Select the location where the device will be deployed (e.g., Location 1, Location 2, Location 3).
* **Network Device Priority** (`network_device_priority`): Enter the priority level of the device (e.g., 1, 2, 3).
* **Network Device Status** (`network_device_status`): Select the status of the device (e.g., Active, Inactive, Pending).
* **Network Device Notes** (`network_device_notes`): Enter any additional comments or notes about the device.
* **Network Device Order Date** (`network_device_order_date`): Enter the date the order was placed (if known).
* **Network Device Order By** (`network_device_order_by`): Enter the name of the person or department placing the order.
* **Network Device Approval** (`network_device_approval`): Select the status of the order (e.g., Approved, Rejected, Approved with Conditions).
* **Network Device Comments** (`network_device_comments`): Enter any comments about the order.
* **Network Device Approval Date** (`network_device_approval_date`): Enter the date the order was approved (if known).
* **Network Device Order Status** (`network_device_order_status`): Select the status of the order (e.g., Pending, Rejected, Approved).
* **Network Device Order Comments** (`network_device_order_comments`): Enter any comments about the order.
* **Network Device Purchase Status** (`network_device_purchase_status`): Select the status of the purchase (e.g., Pending, In Progress, Completed).
* **Network Device Purchase Date** (`network_device_purchase_date`): Enter the date the purchase was completed (if known).
* **Network Device Vendor** (`network_device_vendor`): Enter the name of the vendor or supplier.
* **Network Device Comments** (`network_device_comments`): Enter any additional comments about the device.

## Tips
* Make sure to fill out each field accurately and completely.
* If you are unsure about a field, refer to your supervisor or colleague for guidance.
* Review the form carefully before submitting it to ensure all required information is included.
* If you need to make any changes to the form, please contact the form administrator.
