# print_and_design_order_form - Help Guide
## Purpose
This form is used to gather information from customers to create print and design orders.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the **Lettering** page, which covers the text and font specifications of the print and design order.
2. Move on to the **Numbering** page, where you can select whether you want to include numbering on the printed product.
3. Finally, visit the **Coloring** page, where you can choose the color scheme for the design.

## Field-by-Field Explanation

* **Lettering** (Page 1):
	+ **Lettering** (print_and_design_order_form_page_1)
		- Type: Text input field
		- Description: This field is used to enter the text that you want to be printed on the product.
* **Numbering** (Page 2):
	+ **Numbering** (print_and_design_order_form_page_2)
		- Type: Select multiple options field
		- Description: Here, you can select whether you want to include numbering on the printed product. Select all the options that apply to your order.
* **Coloring** (Page 3):
	+ **Coloring** (print_and_design_order_form_page_3)
		- Type: Select one option field
		- Description: This field allows you to choose the color scheme for the design. Please select one option that best matches your requirements.

## Tips
* Double-check your selections on each page before moving on to the next.
* Make sure to fill out all required fields (indicated by an asterisk *) to ensure that your order is processed correctly.
* If you have any issues or concerns, please contact our support team for assistance.
