# Elderly Meals Request Form - Help Guide
## Purpose
This form is designed to request meals for an elderly individual. Please use this form to submit your request for meal preparation and delivery.

## How To Complete This Form
To complete this form, follow these steps:

1.  Fill out the form with the required information.
2.  Select the meal type and payment method from the respective dropdown menus.
3.  Enter the delivery date and senior's name.
4.  Add any special instructions or notes regarding the order.
5.  Review your request before submitting.

## Field-by-Field Explanation

*   **Meal Type** (`meal_type`, select_one): Choose the type of meal you are requesting.
    *   Select 'Yes' for a meal request.
    *   Select 'No' if you are not requesting a meal.
*   **Delivery Date** (`delivery_date`, date): Enter the date when the meal is to be delivered.
*   **Senior Name** (`senior_name`, text): Enter the senior's name.
*   **Meal Address** (`meal_address`, text): Enter the senior's address.
*   **Special Instructions** (`special_instructions`, text): Add any special instructions or notes regarding the order.
*   **Meal Request Status** (`meal_request_status`, select_one): Select the status of the meal request.
    *   Select 'Waiting List' for a pending meal request.
    *   Select 'In Progress' for an active meal request.
    *   Select 'Approved' for a confirmed meal request.
    *   Select 'Completed' for a delivered meal request.
    *   Select 'Rejected' for a canceled meal request.
*   **Payment Gateway** (`payment_gateway`, select_one): Choose the payment gateway to use for the payment.
    *   Select 'Stripe' for Stripe payment processing.
    *   Select 'PayPal' for PayPal payment processing.
    *   Select 'Authorize.net' for Authorize.net payment processing.
    *   Select 'Square' for Square payment processing.
*   **Payment Amount** (`payment_amount`, number): Enter the payment amount.
*   **Payment Method** (`payment_method`, select_multiple): Select the payment method to use.
    *   Select 'Credit Card' for credit card payments.
    *   Select 'Bank Transfer' for bank transfer payments.
    *   Select 'ACH' for Automated Clearing House payments.
    *   Select 'Cash' for cash payments.
*   **Order Notes** (`order_notes`, note): Add any additional information regarding the order.

## Tips
*   Please ensure that all required fields are filled out correctly.
*   Double-check the meal type and payment method before submitting the form.
*   If you are unsure about any field, please contact us for assistance.
