# Make Up Set Order Form - Help Guide

## Purpose
This form is designed to collect order details from customers.

## How To Complete This Form
To complete this form, follow these steps:

1. Start by filling out the Order Form, providing the required details.
2. Proceed to fill out the Payment Form, specifying the payment method.
3. Provide order details in the Order Details section.
4. List the products in the Product List section.
5. Enter the shipping address and product price.
6. Finally, fill out the Customer Info section.

## Field-by-Field Explanation

* **Order Form**: Enter the order details, such as the order type and other relevant information.
* **Payment Form**: Select the payment method for the order.
* **Order Details**: Enter the order details, such as order date and other relevant information.
* **Product Form**: Enter the product details.
* **Shipping Form**: Enter the shipping address.
* **Order Total**: Enter the total cost of the order.
* **Product List**: Select the list of products to be ordered (Yes/No).
* **Payment Method**: Select the payment method (Credit Card/PPayPal).
* **Product Price**: Enter the price of the products.
* **Shipping Address**: Enter the shipping address.
