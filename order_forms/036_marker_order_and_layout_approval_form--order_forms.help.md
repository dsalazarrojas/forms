# Marker Order And Layout Approval Form - Help Guide

## Purpose

The Marker Order And Layout Approval Form is a crucial tool for administrative tasks. It gathers information on marker orders and layouts, allowing users to review and approve them before proceeding with further actions. The form helps ensure that marker orders are thoroughly reviewed and approved, which can prevent errors and miscommunications later on in the process.

## How To Complete This Form

To complete the form, start by selecting the relevant fields and providing the necessary information. Each field has been carefully designed to guide you through the process.

## Field-by-Field Explanation

* **Marker Order** (`marker_order`, number, optional): Enter the marker order number.
* **Layout Name** (`layout_name`, text, required): Enter the name of the layout for which you are approving the marker order.
* **Layout Description** (`layout_description`, text, optional): Provide a brief description of the layout.
* **Marker Layout** (`marker_layout`, select_one, required): Select the layout type from the options provided.
* **Layout Approvals** (`layout_approvals`, select_multiple, required): Select the approval type for the layout. Options include:
	+ Approve
	+ Reject
	+ Comment
* **Comments** (`comments`, note, optional): Enter any additional comments or notes related to the layout.
* **Date Ordered** (`date_ordered`, date, optional): Enter the date the order was placed.
* **Date Approved** (`date_approved`, date, optional): Enter the date the layout was approved.
* **Date Rejected** (`date_rejected`, date, optional): Enter the date the layout was rejected.
* **Date Modified** (`date_modified`, time, optional): Enter the time the layout was modified.

## Tips

* Be sure to fill out all mandatory fields, marked as required.
* Select the correct layout type for the marker order.
* Use the comments field to provide additional context or information.
* If you are unsure about any of the fields, refer back to the form title and purpose for clarification.
