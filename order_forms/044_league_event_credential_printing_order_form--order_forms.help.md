# League Event Credential Printing Order Form - Help Guide
## Purpose
This form is used to collect information from users to print league event credentials.

## How To Complete This Form
To complete this form, please follow these steps:

1. Determine whether league event credentials are needed for your event. Select "Yes" or "No" in the "League Event Credentials" field.
2. If credentials are needed, select the type of credential you want to print ("Yes" or "No") in the "Artwork" field.
3. Enter the event details, such as the event name, date, and location, in the "Event Details" field.
4. Provide delivery details, such as the shipping address and delivery method, in the "Delivery Details" field.
5. Select the quantity of credentials you need to print in the "Quantities" field.

## Field-by-Field Explanation
- **League Event Credentials** (required/optional): Select "Yes" if you need credentials for your event, "No" otherwise.
    - This field determines whether you need league event credentials.
- **Artwork** (select_one):
    - Select "Yes" if you want to include artwork on the credential, "No" otherwise.
    - This field determines whether you want to include artwork on the credential.
- **Event Details** (required):
    - Enter the name of your event, date, and location.
    - This field is used to print the event details on the credential.
- **Delivery Details** (required):
    - Enter the shipping address and delivery method.
    - This field is used to determine how the credentials will be delivered.
- **Quantities** (required/optional):
    - Select the quantity of credentials you need to print.
    - This field determines how many credentials to print.
