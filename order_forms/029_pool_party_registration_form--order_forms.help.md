# pool_party_registration_form - Help Guide
## Purpose
The pool party registration form is designed to collect information about a party, including party details, name, date, and time. This form helps the party hosts to create a guest list and send reminders and invitations.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the party details in the "Party Details" field.
2. Add the party name in the "Party Name" field.
3. Select the party date in the "Party Date" field.
4. Enter the party time in the "Party Time" field.

## Field-by-Field Explanation
* **Party Details** (Party Details, text, optional): Enter a brief description of the party, such as "Pool Party" or "Summer BBQ".
* **Party Name** (Party Name, text, optional): Enter the name of the party, such as "John's Pool Party" or "Summer BBQ".
* **Party Date** (Party Date, date, optional): Select the date of the party using the date picker calendar. Ensure the date is in the format MM/DD/YYYY.
* **Party Time** (Party Time, time, optional): Enter the time of the party using the 12-hour clock format (AM/PM). For example, 3:00 PM.
