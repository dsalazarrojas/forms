# Daycare Supplies Order Form - Help Guide

## Purpose
The Daycare Supplies Order Form is used to place orders for supplies on behalf of daycare centers. Authorized personnel or parents can use this form to collect and submit order details.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the order details for the order you wish to place.
2. Choose the delivery method (delivery or pickup).
3. Enter the item name, quantity, and any additional notes.
4. Enter the delivery date and time if applicable.
5. Enter the parent's contact information (email and phone number).
6. Enter the parent's name.
7. Select the items to be ordered.
8. Add any additional order notes.
9. Verify the delivery method and address if applicable.
10. Confirm the order details before submitting the form.

## Field-by-Field Explanation

* **Order Details** (`id: 1, name: order_form`): Select the order details for the order you wish to place.
* **Select Delivery** (`id: 2, name: delivery_choice`): Choose whether you want to deliver the order or have it picked up.
* **Item Name** (`id: 3, name: item_name`): Enter the name of the item being ordered.
* **Quantity** (`id: 4, name: quantity`): Enter the quantity of the item being ordered.
* **Note** (`id: 5, name: note`): Add any additional notes about the order.
* **Delivery Date** (`id: 6, name: delivery_date`): Enter the date the item is to be delivered.
* **Delivery Time** (`id: 7, name: delivery_time`): Enter the time the item is to be delivered.
* **Email** (`id: 8, name: email`): Enter the email address of the person placing the order.
* **Phone** (`id: 9, name: phone`): Enter the phone number of the person placing the order.
* **Parent Name** (`id: 10, name: name`): Enter the name of the parent or guardian placing the order.
* **Item** (`id: 11, name: item_id`): Select the items to be ordered.
* **Order Notes** (`id: 12, name: order_notes`): Add any additional notes about the order.
* **Select Delivery** (`id: 13, name: delivery_choice_2`): Choose whether to deliver the order or have it picked up.
* **Address** (`id: 14, name: delivery_address`): Enter the address where the item will be delivered.
* **Order ID** (`id: 15, name: order_id`): Enter a unique ID for the order.
* **Form ID** (`id: 16, name: form_id`): Enter a unique ID for the form submission.
* **Date of Birth** (`id: 17, name: date_of_birth`): Enter the date of birth of the child.
* **Date of Order** (`id: 18, name: date_of_order`): Enter the date the order was placed.
* **Time of Order** (`id: 19, name: time_of_order`): Enter the time the order was placed.

## Tips

* Make sure to fill in all required fields to ensure a successful submission.
* Double-check the delivery details to ensure accuracy.
* Enter any additional notes or information that may be helpful for processing the order.
* Review the order details before submitting the form to ensure accuracy.
