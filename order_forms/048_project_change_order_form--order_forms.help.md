# Project Change Order Form - Help Guide
## Purpose
This form is intended to collect project information and details for change orders from clients. It's essential to complete this form accurately to ensure that project teams have all the necessary information to move forward.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the project title and status as they are currently known.
2. Choose the relevant project type from the provided options.
3. Provide a brief description of the project in the "Change Details" section.
4. Upload any necessary documents related to the project.
5. Sign both electronic signatures to confirm that the changes are approved.

## Field-by-Field Explanation
* **Project Change Order Form** (`project_change_order_form`, text, required): This field is the main title of the form.
* **Project Title** (`project_title`, text, optional): Enter the project title as it is currently known.
* **Project Status** (`project_status`, select_one, optional): Select the project status as it currently stands. The options are active, inactive, and pending.
* **Project Type** (`project_type`, select_multiple, optional): Select the project type from the provided options.
* **Document Upload** (`document_upload`, text, optional): Upload any relevant documents related to the project.
* **Change Details** (`change_details`, note, optional): Provide a brief description of the changes being made to the project.
* **Digital Signature 1** (`e_signature_1`, text, optional): Enter your electronic signature to confirm approval of the changes.
* **Digital Signature 2** (`e_signature_2`, text, optional): Enter the electronic signature of the approver or other relevant personnel.
