# Security Wristband Printing Booking Form - Help Guide

## Purpose
The Security Wristband Printing Booking Form is a form designed to collect information for booking a Security Wristband printing service. This form is used to gather details from the user to fulfill their request.

## How To Complete This Form
To complete this form, please follow these steps:
1. Fill out the form accurately and thoroughly, providing all required information.
2. Review the form before submitting it to ensure everything is correct.
3. Submit the form once you have filled it out completely and accurately.

## Field-by-Field Explanation

### 1. **First Name** 
First Name is a required field. Please enter your name as it appears on your identification.

* **First Name** (user_input_1, text, required): Please enter your first name.

### 2. **Email**
Email is an optional field. However, it is recommended to enter your email address to ensure we can contact you with any updates or questions regarding your order.

* **Email** (user_email_1, email, optional): Enter your email address.

### 3. **Phone**
Phone is an optional field. You can enter your phone number to be contacted if needed.

* **Phone** (user_phone_1, text, optional): Enter your phone number.

### 4. **Event Title**
Event Title is an optional field. You can enter the title of the event or occasion where the Security Wristband will be used.

* **Event Title** (event_title_1, text, optional): Enter the event title or occasion.

### 5. **Date**
Date is an optional field. You can enter the date of the event or occasion.

* **Date** (event_date_1, date, optional): Enter the date of the event or occasion.

### 6. **Time**
Time is an optional field. You can enter the time of the event or occasion.

* **Time** (event_time_1, time, optional): Enter the time of the event or occasion.

### 7. **Location**
Location is an optional field. You can enter the location of the event or occasion.

* **Location** (event_location_1, text, optional): Enter the location of the event or occasion.

### 8. **Number of Orders**
Number of Orders is an optional field. You can enter the number of Security Wristbands you would like to order.

* **Number of Orders** (number_of_orders_1, number, optional): Enter the number of Security Wristbands you would like to order.

### 9. **Order Details**
Order Details is an optional field. You can enter any additional details about your order.

* **Order Details** (order_details_1, text, optional): Enter any additional details about your order.

### 10. **Wristband Type**
Wristband Type is an optional field but required for ordering Security Wristbands. Please select the type of Wristband you would like to order.

* **Wristband Type** (wristband_type_1, select_one, required): Select the type of Wristband you would like to order.

### 11. **Quantity**
Quantity is an optional field but required for ordering Security Wristbands. Please enter the quantity of Wristbands you would like to order.

* **Quantity** (quantity_1, number, required): Enter the quantity of Wristbands you would like to order.

### 12. **Shipping Name**
Shipping Name is an optional field. You can enter the name of the person shipping to.

* **Shipping Name** (shipping_name_1, text, optional): Enter the name of the person shipping to.

### 13. **Shipping Address**

* **Shipping Address** (shipping_address_1, text, optional): Enter the shipping address of the Security Wristband.

### 14. **Shipping City**

### 16. **Postal Code**

### 17. **Shipping Country**
