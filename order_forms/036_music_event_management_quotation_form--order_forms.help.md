# Music Event Management Quotation Form - Help Guide

## Purpose
This form is designed to collect all necessary details about a music event to create an accurate quotation for the management company. Please fill out the form completely and truthfully to ensure accurate quotations.

## How To Complete This Form
1. Fill out the form completely and accurately.
2. Refer to the event's contract or agreement if unsure about any information.
3. Double-check your entries before submitting the form.

## Field-by-Field Explanation
* **Music Event Form** (`music_event_form`, text, required/optional): Enter a brief description of the music event.
* **Event Details** (`music_event_details`, text, required/optional): Describe the event in more detail, including any specific requirements.
* **Contact** (`contact_details`, text, required/optional): Enter the contact information for the person managing the event.
* **Event Requirements** (`event_requirements`, text, required/optional): List any specific requirements for the event, including sound equipment, stage setup, etc.
* **Requirements 2** (`event_requirements_2`, text, required/optional): Additional requirements for the event.
* **Contact Email** (`contact_email`, email, required/optional): Enter the email address of the contact person.
* **Contact Phone** (`contact_phone`, text, required/optional): Enter the phone number of the contact person.
* **Contact Address** (`contact_address`, text, required/optional): Enter the address of the contact person.
* **Event Manager** (`music_event_manager`, text, required/optional): Enter the name of the event manager.
* **Event Date** (`event_date`, date, required/optional): Enter the date of the event in the format `YYYY-MM-DD`.
* **Event Time** (`event_time`, time, required/optional): Enter the time of the event in the format `HH:MM`.
* **Duration** (`event_duration`, select_one, required/optional): Select the duration of the event from the options provided.
* **Location** (`event_location`, text, required/optional): Enter the location of the event.
* **Event Details** (`event_details`, text, required/optional): Enter additional details about the event.
* **Budget** (`music_event_budget`, text, required/optional): Enter the budget for the event.
* **Services** (`music_event_services`, text, required/optional): List the services required for the event.
* **Terms** (`music_event_terms`, text, required/optional): Enter any terms and conditions specific to the event.
* **Conditions** (`music_event_conditions`, text, required/optional): Enter any specific conditions for the event.
* **Notes** (`music_event_notes`, text, required/optional): Enter any additional notes about the event.
* **Terms 2** (`music_event_terms_2`, text, required/optional): Enter any additional terms and conditions for the event.
* **Conditions 2** (`music_event_conditions_2`, text, required/optional): Enter any additional conditions for the event.
* **Notes 2** (`music_event_notes_2`, text, required/optional): Enter any additional notes about the event.
* **Event Type** (`event_type`, select_one, required/optional): Select the type of event from the options provided.
* **Type of Event** (`event_type_2`, select_one, required/optional): Select the type of event from the options provided.
* **Event Manager 2** (`music_event_manager_2`, text, required/optional): Enter the name of the event manager (if different from Event Manager).
* **Tips**: Double-check all your entries for accuracy before submitting the form.

This help guide is designed to walk you through the fields in the Music Event Management Quotation Form. Each field is explained in detail to ensure you understand its purpose and requirements. Please fill out the form accurately and truthfully to ensure accurate quotations.
