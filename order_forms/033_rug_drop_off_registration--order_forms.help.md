# rug_drop_off_registration - Help Guide
## Purpose
The Rug Drop Off Registration form is used to collect information for the transfer of rugs between customers or services. This form ensures that all necessary details are provided for a successful transfer process.

## How To Complete This Form
To complete this form, follow the instructions below:

1. Fill in the required fields with accurate information.
2. Ensure that the fields marked as "required" have a valid input.
3. Review your input for any errors before submission.

## Field-by-Field Explanation

* **Form Title** (`form_title`, text, required): Enter a brief title for the rug transfer.
* **Description** (`rug_description`, text, required): Provide a detailed description of the rug to be transferred.
* **Preferred Drop Off Date** (`preferred_drop_off_date`, date, required): Select a date for the preferred rug drop off.
* **Preferred Drop Off Time** (`preferred_drop_off_time`, time, required): Choose a time for the preferred rug drop off.
* **Customer Intake** (`customer_intake`, text, optional): Add any additional customer information if necessary.
* **Rug Status** (`rug_status`, select_one, required): Select the status of the rug being transferred (Active or Inactive).
* **Special Handling Notes** (`special_handling_notes`, text, optional): Add any special handling instructions for the rug transfer.

## Tips
- Double-check that all required fields are filled before submission.
- Be as detailed as possible when describing the rug to be transferred.
- Ensure the selected status is accurate for the rug being transferred.
- If necessary, add any special handling instructions for a smooth transfer process.
