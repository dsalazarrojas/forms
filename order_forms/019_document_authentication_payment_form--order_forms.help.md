# document-authentication-payment-form - Help Guide
## Purpose
The document-authentication-payment-form is used to collect payment information for document authentication services.

## How To Complete This Form
To complete this form, follow these steps:

*   Fill out the required fields and provide any relevant information.
    *   The payment information page of this form contains the payment details required for document authentication services.
*   Ensure that the payment method (card number, card type, etc.) is entered correctly.
    *   Select the payment method from the list provided (e.g. Visa, Mastercard, PayPal).
*   Enter the amount of the payment in a valid format.
    *   This field requires numerical input.
*   Select the currency of the payment from the list (e.g. USD, EUR).
    *   Enter the country of the payment location from the list.
    *   Enter the state of the payment location from the list.

## Field-by-Field Explanation
* **Payment Information (`payment_information`, text, optional):** Enter your payment details for document authentication services.
* **Payment Method (`payment_method`, select_one, optional):** Select the payment method used for this transaction. Options include Visa, Mastercard, and PayPal.
* **Amount (`amount`, number, optional):** Enter the amount of the payment in a valid numerical format.
* **Currency (`currency`, text, optional):** Select the currency used for the payment from the list.
* **Country (`country`, text, optional):** Enter the country where the payment is being made.
* **State (`state`, text, optional):** Enter the state where the payment is being made.

## Tips
*   Ensure all fields are filled out correctly to process your document authentication request properly.
*   If you have any questions or issues with this form, please contact our support team.
*   Payment method must match the currency of the payment amount.
*   Currency and state fields may have limitations on input (e.g., only allow certain characters or combinations).
