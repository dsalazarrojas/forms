# Pickup Time Slot Selection - Help Guide
## Purpose
This form is used to select a suitable pickup time slot for a pickup event. Users are required to select a time slot that suits their availability.
## How To Complete This Form
To complete this form, please follow these steps:
1. Select one or multiple time slots from the list provided in the time Slot field.
2. Enter your Name in the Name field if you want to provide a personalized name for the selected time slot.
3. Optionally, provide your Phone Number in the Phone Number field for contact purposes.
4. Choose the desired Pickup Date and Pickup Time for the selected time slot. Note that these fields are optional and not required.

## Field-by-Field Explanation
* **Time Slot** (`time_slot`, `select_multiple`, optional): Choose one or multiple time slots that suits your availability. The available time slots are:
	+ 9:00 AM
	+ 10:00 AM
	+ 11:00 AM
	+ 12:00 PM
	+ 1:00 PM
	+ 2:00 PM
	+ 3:00 PM
* **Name** (`name`, `text`, optional): Enter your name if you want to provide a personalized name for the selected time slot.
* **Phone Number** (`phone_number`, `text`, optional): Enter your phone number for contact purposes, if needed.
* **Pickup Date** (`pickup_date`, `date`, optional): Select the date for the pickup event, if needed.
* **Pickup Time** (`pickup_time`, `time`, optional): Select the pickup time for the event.
