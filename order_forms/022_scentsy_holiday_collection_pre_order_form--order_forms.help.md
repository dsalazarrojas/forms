# Scentsy Holiday Collection Pre Order Form - Help Guide
## Purpose
The Scentsy Holiday Collection Pre Order Form is used to pre-order holiday gifts and decorations for your loved ones. It is designed to collect essential information about your order, including gift recipient details, order quantity, and delivery date/time.

## How To Complete This Form
To complete this form, simply follow these steps:

1. Fill out the recipient's First Name, Last Name, and Address.
2. Enter the recipient's Email and Phone number (if available).
3. Select the desired quantity for each type of gift: Holiday Ornament, Gift Card, Gift Set, and Gift Wrapping Paper.
4. Choose the desired gift and holiday date/time:
	* Select the Holiday Date from the dropdown list.
	* Choose the Time of day.
5. Add a personalized Gift Message and Order Notes (if necessary).
6. Submit your order.

## Field-by-Field Explanation

* **First Name**: Enter the recipient's first name. This will be used to address the gift.
* **Last Name**: Enter the recipient's last name. This will be used to address the gift.
* **Address**: Enter the recipient's address. This is the delivery address for the gift.
* **Email**: Enter the recipient's email address. This will be used for communication purposes.
* **Phone**: Enter the recipient's phone number. This will be used for communication purposes.
* **Quantity - Holiday Ornament**: Select the quantity of holiday ornaments you would like to order.
* **Quantity - Gift Card**: Select the quantity of gift cards you would like to order.
* **Quantity - Gift Set**: Select the quantity of gift sets you would like to order.
* **Quantity - Gift Wrapping Paper**: Select the quantity of gift wrapping paper you would like to order.
* **Holiday Ornament**: Select the desired holiday ornament.
* **Gift Card**: Select the desired gift card option.
* **Gift Set**: Select the desired gift set option.
* **Gift Wrapping Paper**: Select the desired gift wrapping paper option.
* **Holiday Date**: Select the holiday date for the gift.
* **Time**: Select the time of day for the gift.
* **Date/Time**: Select the date and time for the gift.
* **Holiday Date**: Select the holiday date for the gift.
* **Select Holiday Date**: Select the desired holiday date from the dropdown list.
* **Select Time**: Select the desired time from the dropdown list.
* **Holiday Date/Time**: Select the desired holiday date and time from the dropdown list.
* **Select Holiday Ornament 2**: Select the desired holiday ornament 2 from the dropdown list.
* **Holiday Message**: Enter a personal message for the gift.
* **Holiday Notes**: Enter any additional notes for the gift.
* **Select Holiday Date/Time**: Select the desired holiday date and time for the gift.
