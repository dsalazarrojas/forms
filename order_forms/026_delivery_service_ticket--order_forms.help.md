# Delivery Service Ticket - Help Guide
## Purpose
The "Delivery Service Ticket" form is used to create a ticket for deliveries that need to be tracked and managed internally. This includes gathering information about the delivery request, pickup and drop-off details, and customer contact information.

## How To Complete This Form
1. Fill out the form fields as prompted. Ensure you have all the required information available before submitting the form.
2. Select the correct delivery type and status options as needed.
3. Add any relevant notes or comments for internal reference.
4. Submit the form to create a new delivery service ticket.

## Field-by-Field Explanation

* **Delivery Request**: Enter a brief description of the customer's delivery request.
* **Pickup Details**: Provide details about the pickup location and any relevant notes.
* **Pickup Date**: Enter the date the pickup will occur.
* **Drop-Off Details**: Provide details about the drop-off location and any relevant notes.
* **Drop-Off Time**: Enter the time the drop-off will occur.
* **Drop-Off Address**: Enter the address where the delivery will be dropped off.
* **Contact Person**: Enter the name of the person to contact for the delivery.
* **Contact Phone**: Enter the phone number of the contact person.
* **Delivery Details**: Add any additional information about the delivery.
* **Delivery Status**: Select the status of the delivery (Active or Inactive).
* **Delivery Note**: Add any relevant notes about the delivery.
* **Customer Name**: Enter the name of the customer.
* **Customer Email**: Enter the email address of the customer.
* **Delivery Type**: Select the type of delivery (Yes or No).
* **Delivery Note 2**: Add any additional notes about the delivery.
* **Customer Note**: Add any notes from the customer.
* **Special Instructions**: Enter any special instructions for the delivery.
* **Delivery Instructions**: Enter any instructions for the delivery team.
* **Customer Comment**: Add any comments from the customer.
* **Delivery Status Note**: Add any notes about the delivery status.
* **Delivery Status Note 2**: Add any additional notes about the delivery status.
* **Delivery Service Ticket ID**: Enter a unique ID for the delivery service ticket.
* **Delivery Service Ticket Number**: Enter a unique number for the delivery service ticket.
* **Delivery Service Status**: Select the status of the delivery service (Active or Inactive).
* **Delivery Service Status Note**: Add any notes about the delivery service status.
* **Delivery Service Status Note 2**: Add any additional notes about the delivery service status.
