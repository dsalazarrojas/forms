# Colorful Cupcake Order Form - Help Guide
## Purpose
This form is designed for customers to order colorful cupcakes for special occasions or events.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in your **Customer Name** in the "Customer Name" field. This is the name of the person placing the order.
2. Enter your **Email Address** in the "Email Address" field. This is used for order confirmation and any follow-up communication.
3. Enter your **Phone Number** in the "Phone Number" field. This is used for contact purposes and order inquiries.
4. Select the **Order Date** for when you would like to receive your order in the "Order Date" field.
5. Choose how you would like to receive your order in the **Pickup or Delivery** field. Options include Store Pickup, Home Delivery, Office Delivery, and Event Venue Delivery.
6. Select the number of **Vanilla Cupcakes** you would like to order in the "Vanilla Cupcakes" field. Each cupcake costs $3.50.
7. Select the number of **Chocolate Cupcakes** you would like to order in the "Chocolate Cupcakes" field. Each cupcake costs $3.50.
8. Select the number of **Red Velvet Cupcakes** you would like to order in the "Red Velvet Cupcakes" field. Each cupcake costs $4.00.
9. Select the number of **Lemon Cupcakes** you would like to order in the "Lemon Cupcakes" field. Each cupcake costs $3.75.
10. Select the number of **Carrot Cupcakes** you would like to order in the "Carrot Cupcakes" field. Each cupcake costs $4.00.
11. Select the number of **Birthday Cake Cupcakes** you would like to order in the "Birthday Cake Cupcakes" field. Each cupcake costs $4.00.
12. Select your **Frosting Preference** in the "Frosting Preference" field. Options include Buttercream, Cream Cheese, Chocolate Ganache, Whipped Cream, and Fondant.
13. Select your **Frosting Color** in the "Frosting Color" field. Options include White, Pink, Blue, Purple, Yellow, and Rainbow.
14. If desired, add a **Custom Message** in the "Custom Message" field. This will be written on the cupcakes.
15. If you have any **Special Decorations**, add them here in the "Special Decorations" field. This includes sprinkles, edible glitter, and more.
16. If you have any **Dietary Requirements**, select them in the "Dietary Requirements" field. Options include None, Gluten-Free, Dairy-Free, Egg-Free, Nut-Free, and Vegan.
17. Select the **Occasion** for which you are ordering the cupcakes in the "Occasion" field. Options include Birthday, Wedding, Baby Shower, Graduation, Anniversary, Corporate Event, Just Because, and Other.
18. Enter the **Delivery Date** in the "Delivery Date" field. This is the date you would like to receive your order.
19. If desired, select a preferred **Delivery Time** in the "Delivery Time" field.
20. Add any **Special Instructions** in the "Special Instructions" field. This is for any additional notes for your order.
21. Finally, confirm the **Total Amount** in the "Total Amount" field. This includes tax.

## Field-by-Field Explanation

* **Customer Name** (Customer Name, text, required): Enter your full name for order processing.
* **Email Address** (Email Address, email, required): Enter your email address for order confirmation and follow-up communication.
* **Phone Number** (Phone Number, text, required): Enter your contact number for order inquiries.
* **Order Date** (Order Date, date, required): Select the date of order placement.
* **Pickup or Delivery** (Pickup or Delivery, select_one, required): Choose how you would like to receive your order.
* **Vanilla Cupcakes** (Vanilla Cupcakes, select_one, required): Select the number of vanilla cupcakes you would like to order.
* **Chocolate Cupcakes** (Chocolate Cupcakes, select_one, required): Select the number of chocolate cupcakes you would like to order.
* **Red Velvet Cupcakes** (Red Velvet Cupcakes, select_one, required): Select the number of red velvet cupcakes you would like to order.
* **Lemon Cupcakes** (Lemon Cupcakes, select_one, required): Select the number of lemon cupcakes you would like to order.
* **Carrot Cupcakes** (Carrot Cupcakes, select_one, required): Select the number of carrot cupcakes you would like to order.
* **Birthday Cake Cupcakes** (Birthday Cake Cupcakes, select_one, required): Select the number of birthday cake cupcakes you would like to order.
* **Frosting Preference** (Frosting Preference, select_one, required): Select your preferred frosting type.
* **Frosting Color** (Frosting Color, select_one, required): Select your preferred frosting color.
* **Custom Message** (Custom Message, text, optional): Add a custom message to be written on the cupcakes.
* **Special Decorations** (Special Decorations, text, optional): Add any special decorations you would like to have on your cupcakes.
* **Dietary Requirements** (Dietary Requirements, select_multiple, required): Select any dietary requirements for your order.
* **Occasion** (Occasion, select_one, required): Select the occasion for which you are ordering the cupcakes.
* **Delivery Date** (Delivery Date, date, required): Select the date you would like to receive your order.
* **Delivery Time** (Delivery Time, time, optional): Select a preferred delivery time.
* **Special Instructions** (Special Instructions, text, optional): Add any additional notes for your order.
* **Total Amount** (Total Amount, number, required): Confirm the total amount of your order including tax.
