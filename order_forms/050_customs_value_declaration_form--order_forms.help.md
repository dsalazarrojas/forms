# Customs Value Declaration Form - Help Guide
## Purpose

This form is used for declaring the value of shipments entering or exiting a country. It is typically required for customs clearance, tax calculations, and other regulatory purposes.

## How To Complete This Form

Before starting, make sure you have the required information about the shipment and the contact person responsible. This form has multiple sections, each with its own purpose. Please fill out the form in the following order:

1. Contact Information: Enter your contact details so that we can reach you if we need more information.
2. Shipment Details: Provide the details of the shipment, including its value.
3. Package Information: Enter any additional details about the package, if necessary.
4. Declaration Information: Enter any relevant information about the shipment, such as commercial or personal use.
5. Shipment Value: Enter the value of the shipment.
6. Currency: Select the currency of the shipment.
7. Shipping Method: Select the method of shipping.
8. Customs Clearance Number: Enter the customs clearance number, if applicable.
9. Date of Arrival: Enter the date the shipment arrived or is expected to arrive.

## Field-by-Field Explanation

* **Contact Information**: Enter your name, email address, and phone number so that we can contact you for any further information.
	+ Type: `text` (required: false)
* **Shipment Details**: Enter a brief description of the shipment, including its type and any other relevant details.
	+ Type: `text` (required: false)
* **Package Info**: Enter any additional details about the package, if necessary.
	+ Type: `text` (required: false)
* **Declaration Info**: Enter any relevant information about the shipment, such as commercial or personal use.
	+ Type: `text` (required: false)
* **Shipment Value**: Enter the value of the shipment, including any applicable duties or taxes.
	+ Type: `number` (required: false)
* **Currency**: Select the currency of the shipment.
	+ Type: `select_one` (required: false)
* **Options**: USD, GBP, EUR
* **Shipping Method**: Select the method of shipping.
	+ Type: `select_multiple` (required: false)
* **Options**: Air, Land, Sea, Customized Shipping Method
* **Customs Clearance Number**: Enter the customs clearance number, if applicable.
	+ Type: `text` (required: false)
* **Date of Arrival**: Enter the date the shipment arrived or is expected to arrive.
	+ Type: `date` (required: false)

## Tips

* Make sure to fill out the form accurately and completely.
* If you are unsure about any information, contact us for clarification.
* This form is a standard template and is used for regulatory purposes.
* The information provided will be used for customs clearance, tax calculations, and other relevant purposes.
