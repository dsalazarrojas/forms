# Product List Import Form - Help Guide
## Purpose
The Product List Import Form is used for importing products into the system with relevant information such as product name, description, weight, price, status, tags, image, email, phone number, and other relevant fields.

## How To Complete This Form
To complete this form, please follow these steps:

1. Enter the product name in the "Product Name" field. This is the title of the product being imported.
2. Enter a brief description of the product in the "Product Description" field.
3. Enter the product weight in the "Product Weight" field. This can be in any unit of measurement such as kg, lb, oz, or g.
4. Enter the product price in the "Product Price" field.
5. Select the status of the product from the dropdown menu in the "Product Status" field. This can be "New", "Old", "Obsolete", "Discontinued", "Backorder", or "On Order" or "On Stock".
6. Enter relevant tags for the product in the "Product Tags" field. This can be any keyword or phrase that describes the product.
7. Select the import method from the dropdown menu in the "Import Method" field. This can be "Yes" or "No".
8. Enter the product image in the "Product Image" field. This can be a URL or a file upload.
9. Enter the product email in the "Product Email" field. This can be an email address.
10. Enter the product phone number in the "Product Phone" field. This can be any phone number.
11. Upload or enter the import file in the "Import File" field. This can be a file or a URL.
12. Select the import status from the dropdown menu in the "Import Status" field. This can be "Active" or "Inactive".
13. Select the import date and time in the "Import Date Time" field. This can be any date and time.
14. Select the import date and time in UTC in the "Import Date Time (UTC)" field. This can be any date and time in UTC.
15. Select the product weight unit of measurement from the dropdown menu in the "Product Weight UOM" field. This can be "kg", "lb", "oz", "g", "ml", or "l".
16. Select any additional product weight unit of measurement from the "Product Weight UOM 2" field. This can be "kg", "lb", "oz", "g", "ml", or "l".
17. Enter any additional notes about the product in the "Notes" field.

## Field-by-Field Explanation

* **Product Name (required)**: Enter the name of the product being imported.
* **Product Description (optional)**: Enter a brief description of the product.
* **Product Weight (optional)**: Enter the weight of the product in any unit of measurement such as kg, lb, oz, or g.
* **Product Price (optional)**: Enter the price of the product.
* **Product Status (optional)**: Select the status of the product from the dropdown menu.
* **Product Tags (optional)**: Enter any keyword or phrase that describes the product.
* **Import Method (optional)**: Select whether to import the product from the file or not.
* **Product Image (optional)**: Enter the product image in the form of a URL or a file upload.
* **Product Email (optional)**: Enter the product email address.
* **Product Phone (optional)**: Enter the product phone number.
* **Import File (optional)**: Upload or enter the import file.
* **Import Status (optional)**: Select the import status from the dropdown menu.
* **Import Date Time (optional)**: Select the import date and time.
* **Import Date Time (UTC) (optional)**: Select the import date and time in UTC.
* **Product Weight UOM (optional)**: Select the product weight unit of measurement from the dropdown menu.
* **Product Weight UOM 2 (optional)**: Select any additional product weight unit of measurement.
* **Notes (optional)**: Enter any additional notes about the product.

Please note that all fields are optional unless marked as required.
