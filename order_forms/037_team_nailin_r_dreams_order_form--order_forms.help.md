# Team Nailin R Dreams Order Form - Help Guide
## Purpose
The Team Nailin R Dreams Order Form is designed to collect information for orders from customers. This form helps to gather details about the order, including color choices, street names, set selection, quantities, date ordered, comments, and other relevant details.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the desired color choices from the Color Street Form page.
2. Select one or multiple color streets from the Color Streets page.
3. Choose the desired set from the Sets page.
4. Enter the quantity of the desired item in the Quantities page.
5. Enter the date the order was placed in the Date Ordered page.
6. Provide any additional comments about the order in the Comments page.
7. If applicable, select the assigned user and tool from the Assigned User and Assigned Tool pages.
8. Enter the output file details in the Output File page.
9. Enter the form ID, category, description, issuer, issuer name, version, status, last updated date, last updated by, and assigned Jimmy details.

## Field-by-Field Explanation

* **Color Street Form (`color_street_form`):** Enter the desired color choices for the order.
* **Color Streets (`color_streets`):** Select one or multiple color streets for the order.
* **Color Streets 2 (`color_streets_2`):** Select multiple color streets for the order.
* **Sets (`sets`):** Choose the desired set for the order.
* **Quantities (`quantities`):** Enter the quantity of the desired item.
* **Date Ordered (`date_ordered`):** Enter the date the order was placed.
* **Comments (`comments`):** Provide any additional comments about the order.
* **Assigned User (`assigned_user`):** If applicable, select the assigned user for the order.
* **Assigned Tool (`assigned_tool`):** If applicable, select the assigned tool for the order.
* **Output File (`output_file`):** Enter the output file details.
* **Form ID (`form_id`):** Enter the form ID.
* **Category (`category`):** Enter the category.
* **Description (`description`):** Enter the description.
* **Category (`category_name`):** Enter the category name.
* **Form Title (`form_title`):** Enter the form title.
* **Form Category (`form_category`):** Enter the form category.
* **Form Description (`form_description`):** Enter the form description.
* **Form Issuer (`form_issuer`):** Enter the form issuer.
* **Form Issuer Name (`form_issuer_name`):** Enter the form issuer name.
* **Form Version (`form_version`):** Enter the form version.
* **Form Status (`form_status`):** Enter the form status.
* **Form Last Updated (`form_last_updated`):** Enter the last updated date.
* **Form Last Updated By (`form_last_updated_by`):** Enter the last updated by.
* **Assigned Jimmy (`assigned_jimmy`):** If applicable, select the assigned Jimmy.
* **Form Output (`form_output`):** Enter the form output details.
