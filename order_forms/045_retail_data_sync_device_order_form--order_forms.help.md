# Retail Data Sync Device Order Form - Help Guide
## Purpose

The Retail Data Sync Device Order Form is designed to collect data for retail data synchronization. This form captures information about shipping and device orders, which helps to ensure accurate and up-to-date product inventory and sales data.

## How To Complete This Form

1. Fill out each field as instructed below.
2. Make sure to complete all required fields (if any).
3. Review your answers carefully before submitting the form.

## Field-by-Field Explanation

* **Retail Data Sync Device Order Form Page 1**: This is the first page of the form, where you will find the following fields:
	* **Shipping Details** (shipping_details): Enter any additional shipping information, if applicable.
	* **Shipping Address** (shipping_address): Enter the shipping address of the device.
	* **Shipping City** (shipping_city): Enter the shipping city of the device.
	* **Shipping State** (shipping_state): Enter the shipping state of the device.
	* **Shipping Zip** (shipping_zip): Enter the shipping zip code of the device.
	* **Shipping Country** (shipping_country): Select the shipping country of the device from the options provided. (USA, Canada, Mexico)
* **Shipping Phone** (shipping_phone): Enter the shipping phone number of the device.
* **Shipping Email** (shipping_email): Enter the shipping email of the device.
* **Device Order Details** (device_order_details): Enter any additional information about the device order.
* **Device Order Type** (device_order_type): Select the type of device ordered. (Hardware, Software)
* **Internal Order** (internal_order): Enter any internal order reference.
* **Internal Comments** (internal_comments): Enter any internal comments about the order.
* **Device Type** (device_type): Select the type of device ordered. (Device 1, Device 2, Device 3)
* **Retail Data Sync** (retail_data_sync): Select if the data should be synced with retail. (Yes, No)
* **Retail Data Sync Time** (retail_data_sync_1): Set the date for retail data sync. (If "Retail Data Sync" is selected as "Yes", this field will be mandatory)
* **Retail Data Sync Time** (retail_data_sync_1_time): Set the time for retail data sync. (If "Retail Data Sync" is selected as "Yes", this field will be mandatory)

**Tips**

* Make sure to complete all required fields.
* Review the form carefully before submitting it.
* If you're unsure about any field, refer to the provided options or ask your supervisor for help.
