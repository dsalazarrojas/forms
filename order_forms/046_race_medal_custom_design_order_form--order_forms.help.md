# race_medal_custom_design_order_form - Help Guide
## Purpose
This form is designed to collect information for custom medal design orders. It allows users to input details such as medal type, size, and artwork style to produce custom medals.

## How To Complete This Form

1. Enter your order form information in the first field (order_form).
2. Select the medal specifications in the medal_specs field.
3. Choose the artwork design in the artwork_designs field.
4. Input additional artwork images in the artwork_images field.
5. Select the medal type (Gold, Silver, Bronze) in the medal_type field.
6. Input the medal size (in units) in the medal_size field.
7. Input the medal width and height (in units) in the medal_width and medal_height fields.
8. Input the medal depth (in units) in the medal_depth field.
9. Select the artwork material (Engraved, Printed, Laser, 3D) in the artwork_material field.
10. Input the quantity of medals needed in the quantity field.
11. Select whether to include artwork color ('Yes', 'No') in the artwork_color field.
12. Select whether to include artwork finish ('Yes', 'No') in the artwork_finish field.
13. Select whether to include artwork finish color ('Yes', 'No') in the artwork_finish_color field.
14. Input additional artwork image in the artwork_image field.
15. Input the medal backing material in the medal_backing field.
16. Select whether to include medal backing ribbon ('Yes', 'No') in the medal_backing_ribbon_color field.
17. Input the number of medals with backing ribbons in the medal_backing_ribbons field.
18. Input any order form submissions in the order_form_submissions field.
19. Input the artwork backing material in the artwork_backing field.
20. Select whether to include medal backing material ('Yes', 'No') in the medal_backing_material field.
21. Select whether to include artwork front backing ('Yes', 'No') in the artwork_front_backing field.
22. Input any order form notes in the order_form_notes field.
