# order_delivery_concern_contact_form - Help Guide
## Purpose
This form helps customers or business users report concerns or issues related to order delivery, enabling businesses to address and resolve these issues efficiently.

## How To Complete This Form

1. Fill in the **Order Title** field with a brief description of the order, if applicable.
2. Enter your **Customer Name** as it appears on your order receipt or invoice.
3. Provide your **Contact Email** to enable the business to get back to you with updates or questions.
4. Enter the **Delivery Date** of the order, if known.
5. Describe the **Issue Description** in detail, including any details about the order or delivery.
6. If you have any **Additional Information**, use the **Customer Message** field to provide more context.
7. Enter your **Customer Phone** number for further communication.
8. Enter the **Order ID** to help the business identify the order in question.
9. Select the correct **Customer Order Status** from the list (e.g., cancelled, fulfilled, pending).
10. Choose the **Customer Order Type** from the list (e.g., online, pickup, in person).
11. Select the **Customer Order Source** from the list (e.g., web, phone, social media).
12. Choose the **Customer Delivery Type** from the list (e.g., shipping, pickup, in person).
13. Select the **Customer Delivery Source** from the list (e.g., store, courier, online).
14. (Optional) If you're a business user, select the **Business Delivery Type** from the list (e.g., shipping, pickup).
15. (Optional) If you're a business user, select the **Business Delivery Source** from the list (e.g., store, store partner).
16. Select the **Issue Type** from the list (e.g., delayed, damaged, missing).
17. (Optional) If you're a business user, provide a **Business Issue Description** if applicable.
18. (Optional) If you have any additional information, use the **Customer Issue Description** field.
19. (Optional) If you have any additional comments, use the **Customer Note** field.
20. (Optional) If you're a business user, provide a **Business Note** if applicable.
21. (Optional) If you have any additional comments, use the **Business Message** field.
22. Enter your **Customer Signature** if you're a customer.
23. (Optional) If you're a business user, enter your **Business Signature** if applicable.
24. Finally, select the **Issue Status** from the list (e.g., pending, resolved).

## Field-by-Field Explanation

* **Order Title**: Briefly describe the order in question, if applicable.
* **Customer Name**: Enter your name as it appears on your order receipt or invoice.
* **Contact Email**: Enter your email to enable the business to get back to you with updates or questions.
* **Delivery Date**: Enter the date of the order delivery.
* **Issue Description**: Describe the issue in detail, including any details about the order or delivery.
* **Additional Information**: Provide any additional context or information about the issue.
* **Customer Phone**: Enter your phone number for further communication.
* **Order ID**: Enter the ID number of the order in question.
* **Customer Order Status**: Select the correct status of the order from the list.
* **Customer Order Type**: Choose the type of order from the list.
* **Customer Order Source**: Select the source of the order from the list.
* **Customer Delivery Type**: Choose the delivery type from the list.
* **Customer Delivery Source**: Select the source of delivery from the list.
* **Business Delivery Type**: (Optional) Select the type of delivery for business users.
* **Business Delivery Source**: (Optional) Select the source of delivery for business users.
* **Issue Type**: Select the type of issue from the list.
* **Business Issue Description**: (Optional) Provide a detailed description of the issue from the business perspective.
* **Customer Issue Description**: (Optional) Provide any additional information about the issue from the customer's perspective.
* **Customer Note**: (Optional) Provide any additional comments or information about the issue.
* **Business Note**: (Optional) Provide any additional comments or information from the business perspective.
* **Business Message**: (Optional) Provide any additional comments or information about the issue.
* **Customer Signature**: Enter your signature if you're a customer.
* **Business Signature**: (Optional) Enter your signature if you're a business user.
* **Issue Status**: Select the status of the issue from the list.

Please note that all fields marked as "required" are necessary to provide for the form to be completed. Optional fields are for additional information or comments.
