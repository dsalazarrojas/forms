# Machine Temperature Monitoring Unit Order Form - Help Guide
## Purpose
This form is used to collect information for ordering machine temperature monitoring units. It is designed to ensure accurate and efficient processing of orders.

## How To Complete This Form
1. Click on the "Order Forms" category from the options at the top of the form to ensure you are using the correct form for this purpose.
2. Fill out the fields on each page, starting from the first page and moving on to the next page.
3. For each field, follow the specific instructions provided in the "Field-by-Field Explanation" section below.

## Field-by-Field Explanation

* **Machine Temperature Monitoring Unit Order Form** (page 1)
	+ **Machine Temperature Monitoring Unit Order Form** (text, required): Enter the title of the machine temperature monitoring unit order.
* **Order Forms** (page 2)
	+ **Order Forms** (select_one, required): Select "Order Forms" from the options to ensure you are filling out the correct form type.
* **Shipping Details** (page 3)
	+ **Shipping to customer** and **Shipping to facility** (select_multiple, required): Choose the shipping method for the order.
* **Shipping Address** (page 4)
	+ **Shipping Address** (text, required): Enter the shipping address for the order.
* **City** (page 4)
	+ **City** (text, required): Enter the city of the shipping address.
* **State** (page 4)
	+ **State** (text, required): Enter the state of the shipping address.
* **Zip** (page 4)
	+ **Zip** (text, required): Enter the zip code of the shipping address.
* **Payment Details** (page 5)
	+ **Payment by credit card** and **Payment by wire transfer** (select_multiple, required): Choose the payment method for the order.
* **Unit Type** (page 5)
	+ **Yes** and **No** (select_one, required): Indicate whether the unit type is applicable or not.
* **Order Quantity** (page 6)
	+ **Order Quantity** (number, optional): Enter the quantity of the order if applicable.
* **Unit Price** (page 6)
	+ **Unit Price** (number, optional): Enter the price of the unit if applicable.
* **Total Price** (page 6)
	+ **Total Price** (number, optional): This field is auto-calculated based on the unit price and order quantity.
* **Form Submit** (page 7)
	+ **Form Submit** (note, required): Enter any comments or notes for the form submission.
* **Form Comments** (page 7)
	+ **Form Comments** (text, optional): Enter any additional comments for the form submission.
* **Submission Date** (page 7)
	+ **Submission Date** (date, required): The date the form was submitted.
* **Submission Time** (page 7)
	+ **Submission Time** (time, required): The time the form was submitted.

Note: The fields marked as required will be checked for completeness before processing.
