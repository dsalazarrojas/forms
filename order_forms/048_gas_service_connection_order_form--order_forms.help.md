# Gas Service Connection Order Form - Help Guide

## Purpose
The Gas Service Connection Order Form is a tool used to collect necessary information for a gas service connection order from customers. This form helps streamline the ordering process and reduces errors.

## How To Complete This Form
To complete this form, follow the steps outlined above.

## Field-by-Field Explanation

* **Customer Information** (`customer_info`, text, required: false): Enter the customer's name, email, phone number, and account number.
* **Service Location** (`service_location`, select_multiple, required: false): Select the location where the gas service will be provided.
* **Meter Reading** (`meter_reading`, number, required: false): Enter the current meter reading.
* **Service Type** (`service_type`, select_one, required: false): Choose the type of service needed.
* **Account Type** (`account_type`, select_one, required: false): Select the type of account.
* **Customer Name** (`customer_name`, text, required: false): Enter the customer's name.
* **EMail** (`email`, email, required: false): Enter the customer's email.
* **Phone** (`phone`, text, required: false): Enter the customer's phone number.
* **Account Number** (`account_number`, number, required: false): Enter the customer's account number.
* **Account Type 2** (`account_type_2`, select_one, required: false): Select the secondary account type if necessary.
* **Customer Address** (`customer_address`, note, required: false): Enter the customer's address if necessary.
* **Billing Address** (`billing_address`, note, required: false): Enter the billing address if necessary.
* **Connection Type** (`connection_type`, select_one, required: false): Choose the type of connection.
* **Connection Date** (`connection_date`, date, required: false): Enter the date of the connection.
* **Connection Time** (`connection_time`, time, required: false): Enter the time of the connection.
* **Service Status** (`service_status`, select_one, required: false): Select the service status.
* **Gas Type** (`gas_type`, select_one, required: false): Choose the type of gas service.
* **Meter Type** (`meter_type`, select_one, required: false): Select the type of meter.
* **Service Location2** (`service_location2`, select_one, required: false): Choose the location for the service.
* **Connection Type2** (`connection_type2`, select_one, required: false): Select the type of connection.
* **Customer Notes** (`customer_notes`, note, required: false): Add any additional customer notes if necessary.
* **Internal Notes** (`internal_notes`, note, required: false): Add any internal notes or comments.
* **Account Status** (`account_status`, select_one, required: false): Select the account status.
* **Request Type** (`request_type`, select_one, required: false): Choose the type of request.
* **Customer Signature** (`customer_signature`, select_multiple, required: false): Select whether the customer has signed the order.

Note: Some fields are not required, but it's essential to fill them out if they apply to the customer's situation.
