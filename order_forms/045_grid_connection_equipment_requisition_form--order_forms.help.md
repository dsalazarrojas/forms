# Grid Connection Equipment Requisition Form - Help Guide
## Purpose
This form is used to create a request for grid connection equipment.

## How To Complete This Form
1. Make sure you have all necessary information before starting.
2. Fill out the fields with accurate information.
3. Review your answers carefully before submitting.

## Field-by-Field Explanation
### **Project Id** (1, Number, Required)
* This field is used to identify the project for which the equipment is being requested.

### **Customer Id** (2, Number, Required)
* This field is used to identify the customer for which the equipment is being requested.

### **Site Id** (3, Number, Required)
* This field is used to identify the site for which the equipment is being requested.

### **Equipment Id** (4, Number, Required)
* This field is used to identify the equipment being requested.

### **Equipment Type** (5, Select One, Required)
* This field indicates whether or not the equipment is needed.
* Choose 'Yes' if the equipment is needed, 'No' otherwise.

### **Equipment Description** (6, Text, Required)
* This field is a brief description of the equipment being requested.

### **Requested Quantity** (7, Number, Required)
* This field is used to specify the number of equipment pieces needed.

### **Due Date** (8, Date, Required)
* This field is used to specify the date by which the equipment should be delivered.

### **Assigned Date** (9, Date, Required)
* This field is used to specify the date the equipment was assigned to a tool.

### **Assigned Tool** (10, Select Multiple, Required)
* This field indicates whether or not the equipment was assigned to a tool.
* Choose 'Yes' if the equipment was assigned to a tool, 'No' otherwise.

### **Status** (11, Select One, Required)
* This field indicates the status of the equipment request.
* Choose 'Active' if the request is active, 'Inactive' otherwise.

### **Notes** (12, Note, Required)
* This field is used to add any additional comments or notes related to the equipment request.

### **Email** (13, Email, Required)
* This field is used to specify the contact email of the person requesting the equipment.

### **Phone** (14, Text, Required)
* This field is used to specify the contact phone number of the person requesting the equipment.

### **Created By** (15, Text, Required)
* This field is used to specify the person who created the equipment request.

### **Created Date** (16, Date, Required)
* This field is used to specify the date the equipment request was created.

### **Updated By** (17, Text, Required)
* This field is used to specify the person who updated the equipment request.

### **Updated Date** (18, Date, Required)
* This field is used to specify the date the equipment request was updated.

### **Assigned Tool Name** (19, Text, Required)
* This field is used to specify the name of the tool assigned to the equipment.

### **Submitted To** (20, Text, Required)
* This field is used to specify the person or department that the equipment request was submitted to.

### **Submitted Date** (21, Date, Required)
* This field is used to specify the date the equipment request was submitted.

### **Approved By** (22, Text, Required)
* This field is used to specify the person or department that approved the equipment request.

### **Approved Date** (23, Date, Required)
* This field is used to specify the date the equipment request was approved.

### **Declined By** (24, Text, Required)
* This field is used to specify the person or department that declined the equipment request.

### **Declined Date** (25, Date, Required)
* This field is used to specify the date the equipment request was declined.

## Tips
* Ensure you fill out the form accurately and completely.
* Review your answers carefully before submitting the form. 
* Double-check the required fields to ensure you have all necessary information.
