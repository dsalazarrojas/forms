# website_maintenance_package_order_form - Help Guide
## Purpose
This form is used to collect order details for website maintenance packages. It's designed for both internal and external users to place or process website maintenance orders. Please review the form carefully to ensure accurate order submission.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the desired website maintenance package from the list of options.
2. Choose a payment method (e.g., Bank Transfer, PayPal, Credit Card).
3. If applicable, enter the package price.
4. Add any additional order notes.
5. Enter your email address.
6. Enter your phone number.

## Field-by-Field Explanation
* **Website Maintenance Order** (1, text, not required): Enter a brief description of the website maintenance order.
* **Selected Package** (2, select_multiple, not required): Select one or more website maintenance packages to order (e.g., Package A, Package B, Package C).
* **Payment Method** (3, select_one, not required): Choose a payment method to complete the order (e.g., Bank Transfer, PayPal, Credit Card).
* **Package Price** (4, number, not required): Enter the price of the selected package.
* **Order Note** (5, note, not required): Add any additional comments or notes about the order.
* **Email** (6, email, not required): Enter your email address.
* **Phone** (7, text, not required): Enter your phone number.
