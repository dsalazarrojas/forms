# Party Order Form - Help Guide
## Purpose
The Party Order Form is a tool used to gather information for party orders, such as party package type, event date and time, party size, event location, party package details, order notes, and event budget. This form is essential for event planners and coordinators to ensure that all necessary information is collected accurately and efficiently.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the party package type (Single, Double, or Triple) that suits your needs.
2. Choose the event date for which you want to place the order.
3. Enter the event time, if applicable.
4. Select the party size, if you're unsure, leave it blank.
5. Choose the event location from the provided options (Location 1, Location 2, or Location 3).
6. Add any important party package details, such as special requests or unique requirements.
7. Enter any additional order notes or comments, if needed.
8. Finally, provide an estimated event budget, if you have one.

## Field-by-Field Explanation
* **Party Package Type** (`party_package_type`, select multiple): Choose the party package type that suits your needs, such as Single, Double, or Triple.
* **Event Date** (`event_date`, date): Select the date for which you want to place the order. This will help us plan and prepare for the event accurately.
* **Event Time** (`event_time`, time): Enter the event time, if applicable.
* **Party Size** (`party_size`, number): Enter the number of guests attending the party, if you know it. Leave blank if you don't know the exact number.
* **Event Location** (`event_location`, select one): Choose from the available event locations, such as Location 1, Location 2, or Location 3.
* **Party Package Details** (`party_package_details`, note): Add any special requests or unique requirements for your party package.
* **Order Notes** (`order_notes`, text): Enter any additional comments or order notes, if needed.
* **Event Budget** (`event_budget`, number): Provide an estimated event budget, if you have one. This will help us plan and prepare for the event better.
