# Champagne Order Form - Help Guide
## Purpose
The "Champagne Order Form" is a form designed to gather information for champagne orders, ensuring accurate processing and delivery.

## How To Complete This Form
1. Please complete all required fields marked as "required" in the form.
2. Ensure you have filled out the form with accurate and complete information.
3. Review your order before submitting the form.

## Field-by-Field Explanation
* **Order Date** (`order_date`, date, required): Enter the date of the order placement.
* **Customer Name** (`customer_name`, text, required): Enter the full name of the customer.
* **Email Address** (`customer_email`, email, required): Enter the customer's email address for order confirmation.
* **Phone Number** (`customer_phone`, text, required): Enter the customer's contact phone number.
* **Company Name** (`company_name`, text, optional): Enter the company name if applicable.
* **Shipping Address** (`shipping_address`, text, required): Enter the full delivery address.
* **Billing Address** (`billing_address`, text, optional): Enter a different billing address if applicable.
* **Champagne Selection** (`champagne_selection`, select_one, required): Select the type of champagne.
* **Brand Preference** (`brand_preference`, select_one, required): Choose the preferred champagne brand.
* **Bottle Size** (`bottle_size`, select_one, required): Select the size of the bottle.
* **Quantity** (`quantity`, number, required): Enter the number of bottles.
* **Occasion** (`occasion`, select_one, required): Select the occasion for the champagne.
* **Gift Wrapping** (`gift_wrapping`, select_one, required): Choose whether to include gift wrapping.
* **Gift Message** (`gift_message`, text, optional): Enter a message to include with the gift.
* **Delivery Date Needed** (`delivery_date_needed`, date, required): Enter the date needed for delivery.
* **Delivery Time Preference** (`delivery_time_preference`, select_one, optional): Select the preferred delivery time.
* **Age Verification** (`age_verification`, select_one, required): Confirm you are 21 or older.
* **Signature Required** (`signature_required`, select_one, required): Confirm if an adult signature is required.
* **Payment Method** (`payment_method`, select_one, required): Choose the payment method.
* **Special Instructions** (`special_instructions`, text, optional): Enter any special delivery instructions.
* **Customer Signature** (`customer_signature`, text, required): Type your full name as signature.
