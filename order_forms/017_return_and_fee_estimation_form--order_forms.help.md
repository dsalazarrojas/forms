# Return and Fee Estimation Form - Help Guide
## Purpose
This form is designed to collect information for return requests and estimate the associated fees. The form is used by customers to initiate a return process and by customer service representatives to manage and track return requests.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the details of your return request in the "Return Request" field.
2. Enter the Customer Order ID to associate the return request with the corresponding order.
3. Enter the name of the item you are returning.
4. Enter a description of the item being returned.
5. Select the reason for the return from the list of options (Defective, Missing Item, Item Does Not Fit, Item Does Not Match Description, or Order Cancelled).
6. Enter the date of the return (format: YYYY-MM-DD).
7. Optionally, estimate the return fee for the item.
8. Select the status of the return from the list of options (New, Open, In Progress, or Completed).

## Field-by-Field Explanation
* **Return Request** (text, optional): Enter a brief description of your return request.
* **Customer Order ID** (number, required): Enter the unique ID of the customer order associated with this return request.
* **Return Item Name** (text, optional): Enter the name of the item being returned.
* **Return Item Description** (text, optional): Enter a detailed description of the item being returned.
* **Return Reason** (select_one, required): Select the reason for the return from the list of options:
	+ Defective: The item is defective and not usable.
	+ Missing Item: The item was missing from the order.
	+ Item Does Not Fit: The item does not fit the customer's needs.
	+ Item Does Not Match Description: The item does not match the description provided.
	+ Order Cancelled: The order was cancelled by the customer.
* **Return Date** (date, optional): Enter the date of the return in YYYY-MM-DD format.
* **Return Fee** (number, optional): Estimate the fee associated with the return.
* **Return Status** (select_multiple, required): Select the status of the return from the list of options:
	+ New: The return request has just been submitted.
	+ Open: The return request is currently being processed.
	+ In Progress: The return request is being processed.
	+ Completed: The return request has been resolved.
* **Estimated Fee Amount** (number, optional): Enter an estimated fee amount for the return.
