# simple_wine_order_form_template - Help Guide
## Purpose
The simple_wine_order_form_template is used to collect customer information and their wine preferences for an order.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the customer name.
2. Enter the customer email address.
3. Select the desired wine(s) from the list.
4. Enter the order quantity.
5. Add any order notes (optional).

## Field-by-Field Explanation

* **Customer Name** (customer_name): Enter the customer's name in a clear and accurate manner.
* **Customer Email** (customer_email): Enter the customer's email address for contact purposes.
* **Select Wine 1** (wine_selection_1): Choose one or multiple wines from the list provided.
* **Select Wine 2** (wine_selection_2): Choose another wine from the list, if desired.
* **Select Wine 3** (wine_selection_3): Choose another wine from the list, if desired.
* **Order Quantity** (order_quantity): Enter the number of bottles to order.
* **Order Notes** (order_notes): Add any additional notes or comments for the order.

## Tips
- Make sure to enter accurate and complete information for all fields.
- If no wine is selected, the order will not be complete.
- You can add as many wines to the order as needed.
- Use the order notes field to provide any special requests or instructions for the order.
