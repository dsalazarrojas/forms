# Women's Comp Order Form Template - Help Guide
## Purpose
This form is a template for recording new orders for women's clothing. It helps users to efficiently collect relevant information about the order, including the type of seller, specific item, type of item, order date, and contact details.

## How To Complete This Form

1.  Select the type of seller for the order from the provided options (Uniform seller, Jersey seller, Clothing seller).
2.  Enter the specific item being ordered, e.g., "T-shirt" or "Hat".
3.  Choose the type of item (Uniform, Jersey, Clothing) that applies to the order.
4.  Enter the date of the order using the provided date picker.
5.  (Optional) Enter the time of the order using the 24-hour clock.
6.  Enter any additional order notes, e.g., special requests or comments.
7.  Enter your phone number for contact purposes.
8.  Enter your email address for contact purposes.

## Field-by-Field Explanation

*   **order_type** (required): Select the type of seller for the order. This helps us to route the order to the correct seller.
*   **order_item** (required): Enter the specific item being ordered, e.g., "T-shirt" or "Hat".
*   **item_type** (required): Choose the type of item (Uniform, Jersey, Clothing) that applies to the order.
*   **order_date** (required): Enter the date of the order using the date picker.
*   **order_time** (optional): Enter the time of the order using the 24-hour clock. If not applicable, leave it blank.
*   **order_note** (optional): Enter any additional notes about the order, e.g., special requests or comments.
*   **order_phone** (optional): Enter your phone number for contact purposes.
*   **order_email** (optional): Enter your email address for contact purposes.
