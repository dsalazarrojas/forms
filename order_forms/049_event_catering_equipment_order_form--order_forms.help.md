# event_catering_equipment_order_form - Help Guide
## Purpose
The purpose of this form is to collect information from clients for catering equipment orders.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the event name in the "Event Catering Equipment Order" field.
2. Select the necessary catering equipment from the "Catering Equipment List" dropdown menu.
3. Enter the total number of guests for the event.
4. Provide the date of the event.
5. Enter the contact person's information (Name, Email, and Phone number).
6. Add any additional comments or notes about the event.
7. Provide the event location.
8. Add any catering equipment details.
9. Enter any special instructions for the order.
10. Indicate if you want to receive order confirmation (yes/no).
11. Choose the payment method(s) you would like to use.
12. If necessary, enter any special requests.
13. Select the signature of the event planner.
14. Add any order notes.
15. Choose the order status (processing, completed, etc.).

## Field-by-Field Explanation

* **Event Catering Equipment Order** (`event_catering_equipment_order`, text, optional): Enter the name of the event where the catering equipment is required.
* **Catering Equipment List** (`catering_equipment_list`, select_multiple, optional): Select the catering equipment needed for the event (e.g. tables, chairs, plates, etc.).
* **Total Number of Guests** (`total_number_of_guests`, number, optional): Enter the total number of guests attending the event.
* **Date of Event** (`date_of_event`, date, optional): Enter the date of the event.
* **Contact Person** (`contact_person`, text, optional): Enter the contact person's name for the event.
* **Contact Email** (`contact_email`, email, optional): Enter the contact person's email for the event.
* **Contact Phone** (`contact_phone`, text, optional): Enter the contact person's phone number for the event.
* **Additional Comments** (`additional_comments`, note, optional): Add any additional comments or notes about the event.
* **Event Location** (`event_location`, text, optional): Enter the event location.
* **Catering Equipment Details** (`catering_equipment_details`, text, optional): Enter any specific details about the catering equipment needed.
* **Special Instructions** (`special_instructions`, text, optional): Enter any special instructions for the order.
* **Order Confirmation** (`order_confirmation`, select_one, optional): Indicate if you want to receive order confirmation (yes/no).
* **Payment Method** (`payment_method`, select_multiple, optional): Select the payment method(s) you would like to use (e.g. credit card, bank transfer, etc.).
* **Special Request** (`special_request`, text, optional): Enter any special requests.
* **Signature of Event Planner** (`signature_of_event_planner`, select_one, optional): Select the signature of the event planner.
* **Order Notes** (`order_notes`, text, optional): Add any order notes.
* **Order Status** (`order_status`, select_one, optional): Choose the order status (processing, completed, etc.).
