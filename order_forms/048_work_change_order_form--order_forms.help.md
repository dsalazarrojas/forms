# Work Change Order Form - Help Guide
## Purpose
The Work Change Order Form is used to document and manage changes to a project's scope, timeline, or budget. It ensures that all parties are informed and on the same page.

## How To Complete This Form

1.  Start by filling out the **Client Signature** field. This is where the client verifies that they agree to the changes made to the project.
2.  Next, complete the **Contractor Signature** field, which confirms that the project team has acknowledged and agreed to the changes.
3.  Enter the **Date** of when the changes were made or when the agreement was reached.
4.  Write a detailed description of the change in the **Description** field.
5.  If applicable, specify the **Amount** of the change, and select the relevant currency in the **Currency** field. You can choose between USD, EUR, or JPY.
6.  If there's a tax involved, enter it in the **Tax** field.
7.  Select the payment terms for the change in the **Payment Terms** field. You can choose between Cash, Bank, or other payment methods.
8.  Choose the order terms for the change, specifying if it falls under a certain amount, or choose from a pre-defined range.
9.  If necessary, add any additional details about the change in the **Work Order Details** field.
10. Finally, fill in the **Contact Person**, **Contact Email**, and **Contact Phone** fields with the relevant information for communication and follow-up.

## Field-by-Field Explanation

*   **Client Signature** (`required: true`): This is where the client confirms they agree to the changes made.
*   **Contractor Signature** (`required: true`): This is where the project team acknowledges and agrees to the changes.
*   **Date** (`required: true`): Enter the date when the changes were made or when the agreement was reached.
*   **Description** (`required: true`): Provide a detailed description of the change.
*   **Amount** (`required: true`): If applicable, enter the amount of the change. You can select the relevant currency (USD, EUR, or JPY).
*   **Currency** (`required: true`): Select the currency for the change (USD, EUR, or JPY).
*   **Tax** (`optional`): If there's a tax involved, enter it here.
*   **Payment Terms** (`required: true`): Choose the payment terms (Cash, Bank, or other methods).
*   **Order Terms** (`required: true`): Select the order terms (1-100, 101-250, 251-500, or other pre-defined ranges).
*   **Work Order Details** (`optional`): Add any additional details about the change.
*   **Contact Person** (`optional`): Enter the contact person's name for the project.
*   **Contact Email** (`optional`): Enter the contact email for the project.
*   **Contact Phone** (`optional`): Enter the contact phone number for the project.
*   **Payment Date** (`optional`): If payment terms involve a specific date, enter it here.
*   **Payment Time** (`optional`): If payment terms involve a specific time, enter it here.
