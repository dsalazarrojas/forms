# Cinema Ticket Order Form - Help Guide
## Purpose
The Cinema Ticket Order Form is a tool used to collect information for ordering cinema tickets. The form is designed to gather all necessary details for each ticket order, ensuring that the order is processed accurately and efficiently.

## How To Complete This Form
To complete this form, please follow these steps:

* Enter your Customer Full Name, Email Address, and Phone Number.
* Select the Cinema Location of your preferred theater.
* Choose the movie you wish to watch from the list of available releases.
* Select the date and time of the show you wish to attend.
* Choose the type of ticket you require (Adult, Child, Senior, Student, or Military).
* Enter the number of tickets for each type.
* Select your preferred seating preference (Front section, Middle section, Back section, VIP, or No preference).
* If applicable, provide specific seat numbers if you have preferences.
* Add a concession package to your order (No thanks, Small combo, Medium combo, Large combo, or VIP package).
* Select the method of payment you wish to use (Credit Card, Debit Card, Gift Card, Mobile Payment, or Pay at Theater).
* If paying by card, enter your Card Number, Expiration Date, and 3-digit CVV code.
* Provide any special requests or accommodations (e.g., accessibility needs).
* Finally, select the method you would like to receive your tickets (Email, Text message, Pick up at box office, or Mail delivery).

## Field-by-Field Explanation

* **Customer Full Name**: Enter your first and last name as it appears on your government ID.
  * Type: Text
  * Required: True
* **Email Address**: Enter your email address for ticket confirmation.
  * Type: Email
  * Required: True
* **Phone Number**: Enter your phone number for contact purposes.
  * Type: Text
  * Required: True
* **Cinema Location**: Select the theater where you wish to watch the movie.
  * Type: Select One
  * Required: True
* **Select Movie**: Choose the movie you wish to watch.
  * Type: Select One
  * Required: True
* **Show Date**: Select the date of the movie show.
  * Type: Date
  * Required: True
* **Show Time**: Select the time of the movie show.
  * Type: Time
  * Required: True
* **Ticket Type**: Choose the type of ticket you require (Adult, Child, Senior, Student, or Military).
  * Type: Select Multiple
  * Required: True
* **Number of Adult Tickets**: Enter the number of adult tickets you require.
  * Type: Number
  * Required: True
* **Number of Child Tickets**: Enter the number of child tickets you require.
  * Type: Number
  * Required: False
* **Number of Senior Tickets**: Enter the number of senior tickets you require.
  * Type: Number
  * Required: False
* **Number of Student Tickets**: Enter the number of student tickets you require.
  * Type: Number
  * Required: False
* **Seating Preference**: Choose your preferred seating (Front section, Middle section, Back section, VIP, or No preference).
  * Type: Select One
  * Required: True
* **Specific Seat Numbers**: If you have preferences, enter the specific seat numbers.
  * Type: Text
  * Required: False
* **Add Concession Package**: Choose a concession package to add to your order (No thanks, Small combo, Medium combo, Large combo, or VIP package).
  * Type: Select One
  * Required: True
* **Payment Method**: Choose the method of payment you wish to use (Credit Card, Debit Card, Gift Card, Mobile Payment, or Pay at Theater).
  * Type: Select One
  * Required: True
* **Card Number**: If paying by card, enter your card number.
  * Type: Text
  * Required: False
* **Expiration Date**: If paying by card, enter your card expiration date in MM/YY format.
  * Type: Text
  * Required: False
* **CVV Code**: If paying by card, enter your 3-digit CVV code.
  * Type: Text
  * Required: False
* **Total Amount**: The total amount will be calculated automatically.
  * Type: Number
  * Required: True
* **Special Requests or Accommodations**: Provide any special requests or accommodations (e.g., accessibility needs).
  * Type: Text
  * Required: False
* **How Would You Like to Receive Tickets**: Choose how you would like to receive your tickets (Email, Text message, Pick up at box office, or Mail delivery).
  * Type: Select One
  * Required: True
* **Promotional Code**: If you have a promotional code, enter it here.
  * Type: Text
  * Required: False
