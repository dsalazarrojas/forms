# Club Event Souvenir Production Order Form - Help Guide
## Purpose
The Club Event Souvenir Production Order Form is designed to collect all necessary information for the production and delivery of souvenirs for your club event. This form helps ensure that all required details are provided to create the perfect souvenirs for your event.

## How To Complete This Form
1. Enter the event name, date, and contact person's information in the first section.
2. Describe the souvenir item and its design details in the next section.
3. Specify the quantity, sizes, and material type for the souvenir in the next section.
4. Choose a delivery method and provide the production deadline in the third section.
5. Enter the pricing and payment information in the last section.

## Field-by-Field Explanation

* **Event Name**: Enter the name of the club event.
	+ Type: text
	+ Required: true
* **Event Date**: Enter the date when the event is scheduled.
	+ Type: date
	+ Required: true
* **Contact Person**: Enter the name of the person placing the order.
	+ Type: text
	+ Required: true
* **Contact Email**: Enter the contact email address of the person placing the order.
	+ Type: email
	+ Required: true
* **Contact Phone**: Enter the contact phone number of the person placing the order.
	+ Type: text
	+ Required: true
* **-- Souvenir Specifications --**: Enter details about the souvenir items, such as design, color, etc.
	+ Type: note
	+ Required: false
* **Souvenir Item Type**: Choose the type of souvenir item.
	+ Type: select_one
	+ Required: true
	+ Options: T-shirt, Hat or cap, Mug, Water bottle, Bag, Pin or badge, Wristband, Other
* **Souvenir Description**: Enter a detailed description of the souvenir item.
	+ Type: text
	+ Required: true
* **Design or Logo Details**: Enter any design or logo details for the souvenir item.
	+ Type: text
	+ Required: true
* **-- Quantity and Sizing --**: Enter the total number of items needed and size breakdown.
	+ Type: note
	+ Required: false
* **Total Number of Items**: Enter the total number of souvenirs needed.
	+ Type: number
	+ Required: true
* **Size Breakdown**: Enter the quantity for each size.
	+ Type: text
	+ Required: false
* **Color Options**: Enter the available colors for the souvenir item.
	+ Type: text
	+ Required: true
* **-- Materials and Quality --**: Enter the material type and production quality of the souvenir item.
	+ Type: note
	+ Required: false
* **Material Type**: Enter the material type of the souvenir item (e.g., fabric, plastic, etc.).
	+ Type: text
	+ Required: true
* **Quality Level**: Choose the quality level of the souvenir item.
	+ Type: select_one
	+ Required: true
	+ Options: Basic, Standard, Premium, Luxury
* **-- Production Timeline --**: Enter the production timeline and deadline for the souvenir item.
	+ Type: note
	+ Required: false
* **Production Deadline**: Enter the deadline when the items must be finished.
	+ Type: date
	+ Required: true
* **Delivery Method**: Choose the delivery method for the souvenir item.
	+ Type: select_one
	+ Required: true
	+ Options: Bulk delivery to venue, Individual pickup, Shipped, Will arrange
* **Delivery Date**: Enter the date when to deliver or pick up the items.
	+ Type: date
	+ Required: true
* **-- Pricing and Payment --**: Enter the cost and payment information for the souvenir item.
	+ Type: note
	+ Required: false
* **Cost Per Unit**: Enter the price for each souvenir item.
	+ Type: number
	+ Required: true
* **Total Production Cost**: Enter the total cost for all items.
	+ Type: number
	+ Required: true
* **Payment Method**: Choose the payment method.
	+ Type: select_one
	+ Required: true
	+ Options: Invoice, Cash, Check, Credit card, Bank transfer, Other
* **Special Requests or Instructions**: Enter any additional notes or instructions for production.
	+ Type: text
	+ Required: false
