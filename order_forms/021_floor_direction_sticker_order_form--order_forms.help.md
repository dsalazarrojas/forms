# floor Direction Sticker Order Form - Help Guide
## Purpose
The purpose of this form is to collect information for ordering floor direction stickers from a customer.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the delivery information field with your delivery address and any other relevant details.
2. Select the contact details for how the customer would like to be contacted.
3. Fill out the contact details field with the customer's name and any other relevant information.
4. Describe the order details in the order details field.
5. Select the products that you would like to order, ensuring that all required fields are completed.

## Field-by-Field Explanation
* **delivery_information (Text, Required)**: This field is where you can input your delivery address and any other relevant delivery information.
* **contact_details (Select One, Optional)**: This is where you can select the contact method the customer would like to be contacted with (e.g. email, phone, etc.).
* **contact_details (Text, Optional)**: This field is where you can input the customer's name and any other relevant contact information.
* **order_details (Text, Optional)**: This is where you can describe the order details, such as the quantity and type of products ordered.
* **products (Select Multiple, Required)**: This field is where you can select all the products you would like to order. Ensure that you have selected all 10 available products to complete the form.

## Tips
* Make sure to fill out all required fields to ensure that your order can be processed successfully.
* If you have any special requests or instructions, make sure to include them in the order details field. 
* If you have any questions or concerns, please do not hesitate to contact us.
