# Paint Order Form - Help Guide
## Purpose
The Paint Order Form is a digital form used to capture essential information for painting orders. This form is designed to gather details from both customers and suppliers, ensuring accurate and efficient ordering processes.

## How To Complete This Form
To complete the Paint Order Form, follow these steps:

1. Enter the title of the paint order at the top of the form.
2. Provide the paint order details, including any relevant information about the order.
3. Select the paint color ID, if applicable.
4. Enter the date of the order.
5. Enter the customer's name and contact information (phone and email).
6. Enter the supplier's name and contact information (phone and email).
7. Select the type of paint to order.
8. Choose the paint colors to be delivered.
9. Enter the supplier's address.
10. Add any additional order comments.
11. Enter the paint quantity and unit price.
12. Enter the total price.
13. Select the order status.
14. Enter any supplier quote information.
15. Select the payment method.
16. Select the customer's order date.
17. Select the supplier's order date.
18. Select the payment status.
19. Complete the form by reviewing all the entered information for accuracy.

## Field-by-Field Explanation

* **Paint Order Form** (`paint_order_form`): This field is the title of the paint order.
* **Paint Order Details** (`order_details`): Enter a brief description of the paint order.
* **Paint Color ID** (`paint_color_id`): Select the ID of the paint color to be ordered, or choose "Other" if not specified.
* **Order Date** (`order_date`): Enter the date of the order in the required format.
* **Customer Name** (`customer_name`): Enter the customer's name.
* **Supplier Name** (`supplier_name`): Enter the supplier's name.
* **Paint Type** (`paint_type`): Select the type of paint to be ordered, such as "Latex" or "Oil-based".
* **Paint Color** (`paint_color`): Select multiple paint colors to be delivered, such as "Red" or "Blue".
* **Supplier Address** (`supplier_address`): Enter the supplier's address.
* **Order Notes** (`order_notes`): Add any additional comments about the order.
* **Customer Phone** (`customer_phone`): Enter the customer's phone number.
* **Customer Email** (`customer_email`): Enter the customer's email address.
* **Supplier Phone** (`supplier_phone`): Enter the supplier's phone number.
* **Supplier Email** (`supplier_email`): Enter the supplier's email address.
* **Order Comments** (`order_comments`): Add any comments about the order from the supplier.
* **Paint Quantity** (`paint_quantity`): Enter the quantity of paint to be ordered.
* **Paint Unit Price** (`paint_unit_price`): Enter the unit price of the paint.
* **Total Price** (`total_price`): This field will auto-calculate the total price of the order.
* **Paint Order Status** (`order_status`): Select the current status of the paint order.
* **Supplier Quote** (`supplier_quote`): Enter any quote information from the supplier.
* **Order Date Time** (`order_date_time`): Enter the date and time of the order.
* **Payment Method** (`payment_method`): Select the payment method, such as "Credit Card" or "Bank Transfer".
* **Customer Order Date** (`customer_order_date`): Select the customer's order date.
* **Supplier Order Date** (`supplier_order_date`): Select the supplier's order date.
* **Payment Status** (`payment_status`): Select the current payment status of the order.
