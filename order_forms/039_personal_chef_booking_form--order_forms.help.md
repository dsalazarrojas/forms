# personal_chef_booking_form - Help Guide
## Purpose
The personal chef booking form is used to book a personal chef service for events. It gathers information from the client to prepare and deliver the service.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the **Client Name**, **Event Date**, and **Number of Guests** information.
2. Select the **Chef Service** needed (e.g., Private Dinner, Event, etc.).
3. Enter the **Event Type** (Private or Public).
4. Enter the **Start Time** and **End Time** of the event.
5. Provide any **Additional Info** about the event.
6. Enter the **Client Phone** and **Email** information.
7. Select the **Form Status** (Draft, Open, Closed, Sent, or Completed).
8. Select **Submitted** (No or Yes).
9. Enter the **Submitted At** date and time.

## Field-by-Field Explanation

* **Client Name**: Enter the name of the client booking the event.
* **Event Date**: Enter the date of the event in the format `YYYY-MM-DD`.
* **Start Time**: Enter the start time of the event in the format `HH:MM`.
* **End Time**: Enter the end time of the event in the format `HH:MM`.
* **Message**: Enter any additional information about the event.
* **Chef Service**: Select the type of service needed (Private Dinner, Event, Personal Assistant, Party Planning, Private Dining).
* **Client Phone**: Enter the client's phone number.
* **Event Type**: Select the type of event (Private or Public).
* **Number of Guests**: Enter the number of guests attending the event.
* **Event Location**: Enter the location of the event.
* **Additional Info**: Enter any additional information about the event.
* **Email**: Enter the client's email address.
* **Form ID**: Enter the form ID (not required).
* **User ID**: Enter the User ID (not required).
* **Assigned Tool**: Enter the assigned tool (not required).
* **Created At**: Display the date and time the form was created.
* **Updated At**: Display the date and time the form was updated.
* **Created By**: Display the user who created the form.
* **Updated By**: Display the user who updated the form.
* **Status**: Select the form status (Open, Closed, Sent, or Completed).
* **Assigned To**: Enter the assigned user (not required).
* **Form Status**: Select the form status (Draft, Open, Closed, Sent, or Completed).
* **Notes**: Enter any notes about the form.
* **Submitted**: Select whether the form has been submitted (No or Yes).
* **Submitted At**: Display the date and time the form was submitted.
* **Status**: Select the status of the form (Open, Closed, Sent, or Completed).
