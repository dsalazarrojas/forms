# Heat Exchanger Assembly Order Form - Help Guide
## Purpose
The Heat Exchanger Assembly Order Form is a crucial tool for customers to place orders for heat exchanger assemblies with specific details about the product, customer, and order requirements.

## How To Complete This Form
To fill out this form, please go through each page and provide the requested information accurately and completely. Ensure that all required fields are filled out as they are marked with an asterisk (\*).

## Field-by-Field Explanation

* **Heat Exchanger Assembly Order Form** (`heat_exchanger_order_form_page_1`): This is the title of the form that you are currently on.
* **Product ID** (`product_id`): This is the unique ID of the product you are ordering. Please enter the exact ID as it appears on the product packaging or documentation.
* **Quantity** (`quantity`): This is the number of heat exchangers you are ordering. Please enter a whole number, without any decimals or commas.
* **Customer Name** (`customer_name`): This is the name of the customer placing the order. Please use the full name as it appears on the customer's identification.
* **Customer Email** (`customer_email`): This is the email address of the customer placing the order. Please ensure it is a valid email address.
* **Customer Phone** (`customer_phone`): This is the phone number of the customer placing the order. Please enter the exact number without any symbols or spaces.
* **Order Date** (`order_date`): This is the date on which you are placing the order. Please use the format YYYY-MM-DD.
* **Order Time** (`order_time`): This is the time at which you are placing the order. Please use the format HH:MM:SS.
* **Notes** (`notes`): This field is optional and used for any additional comments or notes about the order.
* **Delivery Note** (`delivery_note`): This field is optional and used for any notes about the delivery of the order.
* **Heat Exchanger Part Details** (`heat_exchanger_part_details`): This field is optional and used for any specific details about the heat exchanger parts required.
* **Order Status** (`order_status`): This is the current status of the order. Please select the correct status from the list: New, In Progress, Done, On Hold, Cancelled.
* **Order Type** (`order_type`): This is the type of order being placed. Please select all applicable types from the list: Repair, Return, Refund.
* **Heat Exchanger Serial Number** (`heat_exchanger_serial_number`): This is the unique serial number of the heat exchanger being ordered. Please enter the exact number as it appears on the product packaging or documentation.
* **Customer Order Reference** (`customer_order_reference`): This is the reference number for the customer's order. Please enter the exact number as it appears on the customer's order confirmation.
* **Order Notes** (`order_notes`): This field is optional and used for any additional comments or notes about the order.
* **Delivery Address** (`delivery_address`): This is the address to which the order will be delivered. Please enter the exact address as it appears on the customer's documentation.
* **Delivery Instructions** (`delivery_instructions`): This field is optional and used for any specific delivery instructions.
* **Customer Comments** (`customer_comments`): This field is optional and used for any comments from the customer.
* **Delivery Person** (`delivery_person`): This field is optional and used for the name of the person delivering the order.
* **Heat Exchanger Model** (`heat_exchanger_model`): This is the model number of the heat exchanger being ordered. Please enter the exact model number as it appears on the product packaging or documentation.
* **Delivery Date** (`delivery_date`): This is the date on which the order will be delivered. Please use the format YYYY-MM-DD.
* **Delivery Time** (`delivery_time`): This is the time at which the order will be delivered. Please use the format HH:MM:SS.

## Tips
* Please fill out all required fields accurately and completely.
* Ensure that all information is entered correctly to avoid any confusion or errors in processing the order.
* If any information is unclear or missing, please contact the relevant support team for assistance.
* Please review the form carefully before submitting it to ensure that all fields are filled out correctly.
