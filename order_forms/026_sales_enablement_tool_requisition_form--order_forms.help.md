# Sales Enablement Tool Requisition Form - Help Guide
## Purpose
This form is designed to gather feedback from sales teams on their enablement tool needs. Please use it to report any issues, suggestions, or improvements related to sales enablement tools.

## How To Complete This Form
To complete this form, follow these steps:

1. Select "Yes" if you have used an enablement tool in your sales process.
2. If you answered "Yes" in step 1, select the pages relevant to your tool usage.
3. Answer the questions on each selected page.
4. If you have used multiple enablement tools, you may answer this form multiple times, but please ensure you have answered each tool's specific questions completely.
5. Submit your feedback.

## Field-by-Field Explanation
- **sales-enablement-tool-requisition-form** (`page 1`, select_multiple, required): Select "Yes" if you have used an enablement tool in your sales process.
  This is the first page of the form and it determines if you are eligible to answer the rest of the form.
- **sales-enablement-tool-requisition-form-2** (`page 2`, text, optional): Please describe the enablement tool(s) you use in your sales process.
  This is the second page of the form and it's where you describe which enablement tool you use.
- **sales-enablement-tool-requisition-form-3** (`page 3`, text, optional): Describe your current enablement tool usage frequency.
  This is the third page of the form and it's where you describe how often you use the enablement tool.
- **assigned-tool** (`page 4`, select_one, optional): Select "Yes" if you are currently using an assigned enablement tool.
  This is the fourth page of the form and it's where you select if the enablement tool is assigned to you.
- **sales-enablement-tool-requisition-form-4** (`page 5`, select_multiple, optional): If you selected "Yes" in the previous page, select "Yes" if the assigned enablement tool is relevant to your sales process.
  This is the fifth page of the form and it's where you select if the assigned enablement tool is relevant to your sales process.
- **sales-enablement-tool-requisition-form-5** (`page 6`, text, optional): Please describe the specific features or functionalities of the enablement tool you use.
  This is the sixth page of the form and it's where you describe the features or functionalities of the enablement tool you use.
- **sales-enablement-tool-requisition-form-6** (`page 7`, text, optional): Describe the benefits you've seen from using the enablement tool.
  This is the seventh page of the form and it's where you describe the benefits you've seen from using the enablement tool.
- **sales-enablement-tool-requisition-form-7** (`page 8`, text, optional): Describe any challenges or difficulties you've faced while using the enablement tool.
  This is the eighth page of the form and it's where you describe any challenges or difficulties you've faced while using the enablement tool.
- **sales-enablement-tool-requisition-form-8** (`page 9`, text, optional): If applicable, please describe any suggestions for improvement you have for the enablement tool.
  This is the ninth page of the form and it's where you provide your suggestions for improvement.
- **sales-enablement-tool-requisition-form-9** (`page 10`, text, optional): If applicable, please provide any specific enablement tool versions or updates that would be helpful.
  This is the tenth page of the form and it's where you describe any specific enablement tool versions or updates that would be helpful.

## Tips
Please answer each question on each page accurately and completely to ensure you provide valuable feedback. If you have any questions or concerns, please contact your manager or support team.
