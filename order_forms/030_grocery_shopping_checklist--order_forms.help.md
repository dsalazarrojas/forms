# Grocery Shopping Checklist - Help Guide
## Purpose
This form is designed to help users create a shopping list for grocery items. Users can quickly select items from the given list, add any additional items, store name, and other relevant information such as date and time.

## How To Complete This Form
To complete this form, follow these steps:

1. Review the "grocery_items" select multiple field and choose all the items you need to purchase.
2. If you have any additional items not on the list, enter them in the "shopping_list" text field.
3. Enter the store's name in the "store_name" text field.
4. Select the date you created this shopping list in the "date" field.
5. Select the time you created this shopping list in the "time" field.
6. If applicable, enter the quantity and unit price for each item in the "quantity" and "unit_price" fields, respectively.

## Field-by-Field Explanation
* **grocery_items**: A select multiple field where you can choose multiple items from the given list.
* **shopping_list**: A text field where you can add any additional items not on the select multiple list.
* **store_name**: A text field for the store's name.
* **date**: A date field to record when the shopping list was created.
* **time**: A time field to record when the shopping list was created.
* **quantity**: A number field to track the quantity of each item.
* **unit_price**: A number field to track the unit price of each item.
