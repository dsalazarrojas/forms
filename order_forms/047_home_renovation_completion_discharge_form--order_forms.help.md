# home_renovation_completion_discharge_form - Help Guide
## Purpose
This form is designed to capture information about home renovation projects, specifically the completion and discharge process.

## How To Complete This Form
To complete this form, follow these steps:
1. Fill in the project address and customer name on page 1.
2. Select the project status from the list on page 2.
3. Enter any additional project notes on page 2.
4. Add any comments from the project inspector on page 2.
5. Add any comments from the project manager on page 2.
6. Date and time the project completion on page 3.
7. Enter the project status update and date on page 3.

## Field-by-Field Explanation
- **Project Address** (`Project Address`, text, required): Enter the address of the renovation project.
- **Customer Name** (`Customer Name`, text, required): Enter the name of the customer or homeowner.
- **Project Status** (`Project Status`, select_one, required): Select the current status of the project from the list, such as "Completed" or "Not Completed".
- **Project Notes** (`Project Notes`, note, optional): Enter any additional notes about the project.
- **Inspector Comments** (`Inspector Comments`, note, optional): Enter any comments from the project inspector.
- **Project Manager Comments** (`Project Manager Comments`, note, optional): Enter any comments from the project manager.
- **Customer Signature** (`Customer Signature`, text, optional): Sign and date the form to confirm completion.
- **Inspector Signature** (`Inspector Signature`, text, optional): Sign and date the form to confirm inspection.
- **Project Manager Signature** (`Project Manager Signature`, text, optional): Sign and date the form to confirm project manager approval.
- **Date Completed** (`Date Completed`, date, optional): Date and time the project completion.
- **Completion Date** (`Completion Date`, date, optional): Date of project completion.
- **Project Status Update** (`Project Status Update`, text, required): Enter the updated project status.
- **Project Status Update Date** (`Project Status Update Date`, date, optional): Date of project status update.
- **Photos** (`Photos`, note, optional): Attach any photos or images related to the project.
- **Documents** (`Documents`, note, optional): Attach any relevant documents related to the project.
- **Other Documents** (`Other Documents`, note, optional): Attach any additional documents related to the project.
