# University Educational Tool Order Form - Help Guide
## Purpose
The University Educational Tool Order Form is used to order educational tools and resources for the university community. This form is designed to gather information about the tools, contact information, and order details.

## How To Complete This Form
To complete this form, please follow these steps:

1. Select the tool you would like to order from the list of available tools.
2. Enter the quantity of the tool you would like to order.
3. Provide a brief description of your request.
4. Enter your name and email address for contact information.
5. Optionally, provide additional comments or notes about your order.

## Field-by-Field Explanation

* **order_form** (Text): A brief description of your request. (Required)
* **select_tool** (Select One): Select the tool you would like to order. (Required)
* **quantity** (Number): Enter the quantity of the tool you would like to order. (Required)
* **department** (Text): If applicable, select the department you are representing. (Optional)
* **request_description** (Text): A brief description of your request. (Optional)
* **contact_name** (Text): Enter your name. (Required)
* **contact_email** (Email): Enter your email address. (Required)
* **contact_phone** (Text): Enter your phone number. (Optional)
* **order_comments** (Note): Provide additional comments or notes about your order. (Optional)
* **submitted_by** (Select Multiple): If applicable, select who submitted the order. (Optional)
* **submitted_by_2** (Select Multiple): If applicable, select who submitted the order. (Optional)
* **submit_date** (Date): Date the order was submitted. (Not required)
* **submit_time** (Time): Time the order was submitted. (Not required)
* **tool_type** (Select One): If applicable, select the type of tool. (Optional)
* **tool_status** (Select One): If applicable, select the tool status. (Optional)
* **submitter** (Select Multiple): If applicable, select who submitted the order. (Optional)
* **order_date** (Date): Date the order was placed. (Not required)
* **order_time** (Time): Time the order was placed. (Not required)
* **review_date** (Date): Date the order was reviewed. (Not required)
* **review_time** (Time): Time the order was reviewed. (Not required)
* **tool_name** (Select One): If applicable, select the name of the tool. (Optional)
* **tool_description** (Text): If applicable, enter a brief description of the tool. (Optional)
* **tool_price** (Number): If applicable, enter the price of the tool. (Optional)
* **tool_quantity** (Number): If applicable, enter the quantity of the tool. (Optional)
* **order_notes** (Note): Provide additional comments or notes about your order. (Optional)
* **submitter_department** (Select One): If applicable, select the department of the submitter. (Optional)
* **submitter_email** (Email): If applicable, enter the email address of the submitter. (Optional)
* **submitter_phone** (Text): If applicable, enter the phone number of the submitter. (Optional)
* **submitter_jobtitle** (Text): If applicable, enter the job title of the submitter. (Optional)

## Tips

* Make sure to fill in all required fields correctly.
* Select only one option for select fields.
* Multiple selections are allowed for fields with "select_multiple" type.
* Review your form carefully before submitting.
