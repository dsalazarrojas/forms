# Machine Efficiency Tracker Order Form - Help Guide
## Purpose
The Machine Efficiency Tracker Order Form is used to record information related to machine efficiency, such as orders for maintenance or services.

## How To Complete This Form
1. Fill in the "Order form" field with any additional information you need to include about the order.
2. Provide details about the order in the "Order details" field.
3. Select an option from the "Order summary" dropdown menu to categorize the order.

## Field-by-Field Explanation
* **Order form** (`order_form`, text, not required): A free-text field where you can enter any additional information about the order.
* **Order details** (`order_details`, text, not required): A free-text field where you can provide more details about the order.
* **Order summary** (`order_summary`, select_one, not required): A dropdown menu with two options: "option 1" or "option 2". Select the option that best describes the order summary.
