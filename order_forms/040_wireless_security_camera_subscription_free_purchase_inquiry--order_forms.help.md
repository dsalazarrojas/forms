# wireless_security_camera_subscription_free_purchase_inquiry - Help Guide
## Purpose
This form is used to collect contact information and purchase inquiries from customers interested in purchasing free wireless security cameras.

## How To Complete This Form
To complete this form, simply fill in the required fields as accurately as possible. If a field is not required, you can leave it blank or fill it in if you wish.

## Field-by-Field Explanation
* **Contact Details** (`1`, `text`, required:false): Please provide your name and contact information. If you'd like to be contacted, please enter your name and contact details here.
* **Security Provider** (`2`, `text`, required:false): If you're purchasing from a specific security provider, please mention their name here.
* **Contact Person** (`3`, `text`, required:false): If you've spoken to a contact person at the security provider, please mention their name here.
* **Schedule Follow Up** (`4`, `text`, required:false): If you'd like to schedule a follow-up, please specify a date and time here.
* **Contact Method** (`5`, `select_one`, required:false): How would you like to be contacted? Please select one of the following options: Retailer, Installer, or Other.
* **Contact Number** (`6`, `text`, required:false): If you'd like to be contacted via phone, please enter your contact number here.
* **Email Address** (`7`, `email`, required:false): If you'd like to be contacted via email, please enter your email address here.
* **Wireless Camera Model** (`8`, `text`, required:false): If you're inquiring about a specific wireless camera model, please mention it here.
* **Purchase Inquiry** (`9`, `text`, required:false): Please provide any additional information about your purchase inquiry here.
