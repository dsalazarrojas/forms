## Event Registration And Preorder Form - Help Guide

## Purpose
This form is designed to collect event registration and preorder information from attendees. The form allows event organizers to create a registration page for their event, and attendees can use it to register for the event and preorder products associated with it.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the required fields, which are marked with an asterisk (*).
2. For each field, provide accurate and relevant information.
3. Review your information carefully before submitting the form.

## Field-by-Field Explanation
### Form Title (1)
* **Form Title (1)** (`title`, `text`, required/optional): This is the title of the form. It will be displayed to the user. Please enter a descriptive and catchy title for the event registration and preorder form.

### Event Organizer (2)
* **Event Organizer** (`event_organizer`, `text`, required/optional): This field is for the person or organization responsible for the event. Enter the name of the event organizer.

### Event Name (3)
* **Event Name** (`event_name`, `text`, required/optional): This field is for the name of the event. Enter a brief description of the event.

### Event Description (4)
* **Event Description** (`event_description`, `text`, required/optional): This field is for a longer description of the event. Provide a detailed description of the event.

### Start Date (5)
* **Start Date** (`start_date`, `date`, required/optional): This field is for the start date of the event. Enter the date in the format MM/DD/YYYY.

### End Date (6)
* **End Date** (`end_date`, `date`, required/optional): This field is for the end date of the event. Enter the date in the format MM/DD/YYYY.

### Event Location (7)
* **Event Location** (`event_location`, `text`, required/optional): This field is for the location of the event. Enter the name of the venue or location where the event will take place.

### Attendee Name (8)
* **Attendee Name** (`attendee_name`, `text`, required/optional): This field is for the name of the person attending the event. Enter your name.

### Attendee Email (9)
* **Attendee Email** (`attendee_email`, `email`, required/optional): This field is for the email of the person attending the event. Enter a valid email address.

### Attendee Phone (10)
* **Attendee Phone** (`attendee_phone`, `text`, required/optional): This field is for the phone number of the person attending the event. Enter a valid phone number.

### Product Name (11)
* **Product Name** (`product_name`, `text`, required/optional): This field is for the name of the product associated with the event. Enter the name of the product.

### Product Description (12)
* **Product Description** (`product_description`, `text`, required/optional): This field is for a description of the product. Enter a brief description of the product.

### Product Price (13)
* **Product Price** (`product_price`, `number`, required/optional): This field is for the price of the product. Enter the price of the product.

### Product Quantity (14)
* **Product Quantity** (`product_quantity`, `number`, required/optional): This field is for the quantity of the product you want to preorder. Enter the quantity of the product.

### Product Preorder Option (15)
* **Product Preorder Option** (`product_preorder_option`, `select_one`, required/true): This field is for selecting the preorder option for the product. Choose the option from the dropdown list.

### Event Organizer Message (16)
* **Event Organizer Message** (`event_organizer_message`, `note`, required/optional): This field is for any additional message from the event organizer. Enter any message you want to convey to the attendees.

### Attendee Message (17)
* **Attendee Message** (`attendee_message`, `note`, required/optional): This field is for any additional message from the attendee. Enter any message you want to convey to the event organizer.

### Submit (18)
* **Submit** (`event_registration_and_preorder_form_submit`, `text`, required/optional): This is the submit button to finish the form.

### Preorder Message (19)
* **Preorder Message** (`event_organizer_preorder_message`, `note`, required/optional): This field is for any additional message from the event organizer regarding the preorder. Enter any message you want to convey to the attendees.

### Preorder Status (21)
* **Preorder Status** (`product_preorder_status`, `select_one`, required/true): This field is for selecting the status of the preorder. Choose the option from the dropdown list.

### Cancel (22)
* **Cancel** (`event_registration_and_preorder_form_cancel`, `text`, required/optional): This is the cancel button to cancel the form submission.

### Product Preorder Fulfillment Message (23)
* **Product Preorder Fulfillment Message** (`product_preorder_fulfillment_message`, `note`, required/optional): This field is for any additional message from the event organizer regarding the fulfillment of the preorder. Enter any message you want to convey to the attendees.

### Product Preorder Payment Status (24)
* **Product Preorder Payment Status** (`product_preorder_payment_status`, `select_one`, required/true): This field is for selecting the payment status of the product. Choose the option from the dropdown list.

### Payment (25)
* **Payment** (`event_registration_and_preorder_form_payment`, `text`, required/optional): This field is for any additional message from the event organizer regarding the payment of the product. Enter any message you want to convey to the attendees.

## Tips
* Please make sure to review your information carefully before submitting the form.
* If you have any questions or concerns, contact the event organizer.
* The event organizer will review and confirm your registration and preorder before finalizing the event schedule and product preorder status.
