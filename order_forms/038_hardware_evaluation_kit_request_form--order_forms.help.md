# Hardware Evaluation Kit Request Form - Help Guide
## Purpose
The "Hardware Evaluation Kit Request Form" is used to request an evaluation kit from an internal system. This form collects information about the user's contact details, evaluation kit selection, and shipping information to fulfill their request.

## How To Complete This Form
To complete this form, please fill out all the required fields. This includes:
* First Name: Your first name.
* Email: Your email address.
* Phone Number: Your phone number.
* Evaluation Kit Selection: Select one of the three options for the evaluation kit.
* Delivery Address: Your delivery address.
* City: The city of your delivery address.
* State/Province: The state or province of your delivery address.
* Postal/Zip Code: The postal or zip code of your delivery address.
* Country: The country of your delivery address.
* Company: Your company name (if applicable).
* Order Date: The date the order was made.
* Shipping Date: The date the order is expected to be shipped.
* Delivery Status: The status of the delivery (in stock, on order, or on production).
* Evaluation Kit Status: The status of the evaluation kit (approved, rejected, or pending).

## Field-by-Field Explanation
* **First Name** (`1`, `text`, required): The user's first name.
* **Email** (`2`, `email`, required): The user's email address.
* **Phone Number** (`3`, `text`, required): The user's phone number.
* **Evaluation Kit Selection** (`4`, `select_one`, required): The user must select one of the three options for the evaluation kit.
* **Delivery Address** (`6`, `text`, required): The user's delivery address.
* **City** (`7`, `text`, required): The city of the user's delivery address.
* **State/Province** (`8`, `text`, required): The state or province of the user's delivery address.
* **Postal/Zip Code** (`9`, `text`, required): The postal or zip code of the user's delivery address.
* **Country** (`10`, `text`, required): The country of the user's delivery address.
* **Company** (`11`, `text`, required): The user's company name (if applicable).
* **Order Date** (`12`, `date`, required): The date the order was made.
* **Shipping Date** (`13`, `date`, required): The date the order is expected to be shipped.
* **Delivery Status** (`14`, `select_one`, required): The status of the delivery (in stock, on order, or on production).
* **Evaluation Kit Status** (`19`, `select_one`, required): The status of the evaluation kit (approved, rejected, or pending).
* **Evaluation Kit Notes** (`20`, `text`, required): Additional notes about the evaluation kit.
* **Evaluation Kit Requester** (`21`, `text`, required): The person requesting the evaluation kit.
* **Evaluation Kit Approver** (`22`, `text`, required): The person approving the evaluation kit.
* **Evaluation Kit Reviewer** (`23`, `text`, required): The person reviewing the evaluation kit.
* **Evaluation Kit Shipper** (`24`, `text`, required): The person shipping the evaluation kit.
* **Evaluation Kit Return Address** (`25`, `text`, required): The address to return the evaluation kit.

## Tips
* Make sure to fill out all the required fields to avoid incomplete or missing information.
* Double-check your evaluation kit selection and delivery address for accuracy.
* If you have any additional comments or follow-up information, feel free to add it in the "Comments" and "Follow-up" fields.
* If you need to request a follow-up, please enter the date and follow-up status in the "Follow-up Date" and "Follow-up Status" fields.
* Review your information carefully before submitting the form to ensure everything is accurate.
