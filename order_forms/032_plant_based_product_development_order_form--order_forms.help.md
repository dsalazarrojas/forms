# Plant Based Product Development Order Form - Help Guide
## Purpose
The Plant Based Product Development Order Form is used to collect information for the development of plant-based products. This form is used by production team members to ensure that all necessary information is collected before starting the production process.

## How To Complete This Form
1. Please fill out all required fields.
2. Review each page carefully and ensure that all necessary information is collected.
3. Submit the form once you have completed all required fields.

## Field-by-Field Explanation

* **Product Information (Product Information, text, required/optional)**: Please provide a detailed description of the product.
* **Production Location (Production Location, text, required/optional)**: Please enter the production location of the product.
* **Product Description (Product Description, text, required/optional)**: Please provide a detailed description of the product.
* **Ingredients (Ingredients, select_multiple, required/optional)**: Please select all ingredients used in the product.
* **Target Market (Target Market, select_one, required/optional)**: Please select the target market for the product.
* **Production Cost (Production Cost, number, required/optional)**: Please provide estimated production cost.
* **Production Time (Production Time, time, required/optional)**: Please provide estimated production time.
* **Production Method (Production Method, text, required/optional)**: Please describe the production method.
* **Packaging (Packaging, select_one, required/optional)**: Please select packaging options.
* **Sales Channels (Sales Channels, select_multiple, required/optional)**: Please select sales channels.
* **Additional Production Location (Additional Production Location, text, required/optional)**: Please enter any additional production locations.
* **Additional Sales Channels (Additional Sales Channels, text, required/optional)**: Please enter any additional sales channels.
* **Additional Target Market (Additional Target Market, select_one, required/optional)**: Please select any additional target market.
* **Additional Information (Additional Information, note, required/optional)**: Please provide any additional information.
* **Image Information (Image Information, note, required/optional)**: Please provide any image information.
* **Image Upload (Image Upload, text, required/optional)**: Please upload any images.
* **Additional Image Information (Additional Image Information, note, required/optional)**: Please provide any additional image information.
* **Additional Image Upload (Additional Image Upload, text, required/optional)**: Please upload any additional images.
* **Additional Information 2 (Additional Information 2, note, required/optional)**: Please provide any additional information.
* **Packaging Options 2 (Packaging Options 2, select_multiple, required/optional)**: Please select any additional packaging options.
* **Product Category (Product Category, select_multiple, required/optional)**: Please select the product category.
* **Image Information 2 (Image Information 2, note, required/optional)**: Please provide any additional image information.
* **Image Upload 2 (Image Upload 2, text, required/optional)**: Please upload any additional images.
* **Sales Channels 2 (Sales Channels 2, select_multiple, required/optional)**: Please select any additional sales channels.
* **Target Market 2 (Target Market 2, select_one, required/optional)**: Please select any additional target market.

Note: This guide is not intended to be comprehensive, please refer to the form itself for more detailed information. 

Please review each field carefully and fill out all required fields to ensure that the production process is properly completed.
