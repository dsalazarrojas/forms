# Component Thermal Shield Order Form - Help Guide
## Purpose
This form is designed to collect information for a thermal shield order. It is a custom-made component designed to provide thermal protection for various applications.

## How To Complete This Form
1. Fill in the order number to identify the order uniquely.
2. Enter the date of the order.
3. Provide the customer's full name.
4. Enter the customer's organization name.
5. Enter the customer's email address for contact purposes.
6. Enter the customer's phone number for contact purposes.
7. Provide the complete delivery address for the order.
8. Select the type of thermal shield required.
9. Enter the manufacturer's part number.
10. Specify the dimensions of the shield.
11. Enter the material specification required.
12. Specify the operating temperature range.
13. Enter the quantity of the shield required.
14. Enter the required thickness of the shield.
15. If applicable, select the surface finish required.
16. Check if any certification is required.
17. Select the application of the shield.
18. Enter the required delivery date.
19. Select the preferred shipping method.
20. If not required, the unit price can be left blank.
21. Select the payment terms.
22. If necessary, provide any special requirements or notes.
23. Select the current order status.

## Field-by-Field Explanation

* **Order Number** (`order_number`, `text`, required): A unique order identifier that helps track and identify the order uniquely.
* **Order Date** (`order_date`, `date`, required): The date when the order was placed.
* **Customer Name** (`customer_name`, `text`, required): The full name of the customer placing the order.
* **Organization** (`organization`, `text`, required): The name of the customer's organization or company.
* **Email Address** (`email_address`, `email`, required): The contact email of the customer.
* **Phone Number** (`phone_number`, `text`, required): The phone number of the customer for contact purposes.
* **Shipping Address** (`shipping_address`, `text`, required): The complete delivery address where the shield will be shipped.
* **Thermal Shield Type** (`thermal_shield_type`, `select_one`, required): Select the type of thermal shield required.
* **Part Number** (`part_number`, `text`, required): The manufacturer's part number of the required thermal shield.
* **Dimensions** (`dimensions`, `text`, required): Specify the dimensions of the thermal shield in millimeters.
* **Material Specification** (`material_specification`, `text`, required): Enter the material specification required for the shield.
* **Temperature Range** (`temperature_range`, `select_one`, required): Specify the operating temperature range of the shield.
* **Quantity** (`quantity`, `number`, required): Enter the number of units required.
* **Thickness** (`thickness`, `number`, required): Enter the required thickness of the shield in millimeters.
* **Surface Finish** (`surface_finish`, `select_one`, required): If applicable, select the surface finish required.
* **Certification Required** (`certification_required`, `select_one`, required): Check if any certification is required.
* **Application** (`application`, `select_one`, required): Specify the intended application of the shield.
* **Required Delivery Date** (`delivery_date`, `date`, required): Enter the required delivery date for the order.
* **Shipping Method** (`shipping_method`, `select_one`, required): Select the preferred shipping method.
* **Unit Price** (`unit_price`, `number`, required): If not required, leave blank for unit price.
* **Payment Terms** (`payment_terms`, `select_one`, required): Select the payment terms.
* **Special Requirements** (`special_requirements`, `text`, required): If any special requirements or notes are necessary.
* **Order Status** (`order_status`, `select_one`, required): Select the current order status.

## Tips
1. Make sure to fill all the required fields accurately to ensure smooth order processing.
2. If any special requirements or notes are necessary, provide them in the "Special Requirements" field.
3. Be precise when selecting the temperature range and dimensions of the shield.
4. Double-check the preferred shipping method to avoid any delays.
5. Confirm the unit price if applicable and select the correct payment terms for a smooth payment process.
