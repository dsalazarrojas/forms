## Field-by-Field Explanation
## Tips

* **Order Details** (1): 
  * Type: text
  * Required: true
  * Purpose: Enter a brief description of your order, including product details and quantities.
* **Shipping Address** (2): 
  * Type: text
  * Required: true
  * Purpose: Enter the shipping address for your order.
* **Shipping City** (3): 
  * Type: text
  * Required: true
  * Purpose: Enter the city for your shipping address.
* **Shipping State** (4): 
  * Type: text
  * Required: true
  * Purpose: Enter the state for your shipping address.
* **Shipping Zip** (5): 
  * Type: number
  * Required: true
  * Purpose: Enter the zip code for your shipping address.
* **Shipping Country** (6): 
  * Type: select_one
  * Required: true
  * Purpose: Select the country for your shipping address.
* **Order Comments** (7): 
  * Type: note
  * Required: false
  * Purpose: Enter any additional comments or notes about your order.
* **Contact Person** (8): 
  * Type: select_one
  * Required: true
  * Purpose: Select the person responsible for the order.
* **Contact E-mail** (9): 
  * Type: email
  * Required: true
  * Purpose: Enter the email address for the contact person.
* **Contact Phone** (10): 
  * Type: text
  * Required: false
  * Purpose: Enter the phone number for the contact person.
* **Order Items** (11): 
  * Type: number
  * Required: false
  * Purpose: Enter the number of items being ordered.
* **Order Total** (12): 
  * Type: number
  * Required: true
  * Purpose: Enter the total value of the order.
* **Order Date** (13): 
  * Type: date
  * Required: true
  * Purpose: Enter the date the order was placed.
* **Order Time** (14): 
  * Type: time
  * Required: true
  * Purpose: Enter the time the order was placed.
* **Order Notes** (15): 
  * Type: note
  * Required: false
  * Purpose: Enter any additional notes about the order.
* **Payment Method** (16): 
  * Type: select_one
  * Required: true
  * Purpose: Select the payment method for your order.
* **Payment Terms** (17): 
  * Type: select_multiple
  * Required: false
  * Purpose: Select the payment terms for your order (e.g., COD, Prepay, Postpay).
* **Shipping Method** (18): 
  * Type: select_one
  * Required: true
  * Purpose: Select the shipping method for your order.
* **Order Status** (19): 
  * Type: select_one
  * Required: true
  * Purpose: Select the status of your order (e.g., In Progress, Shipped, Delivered).
* **Order Notes 2** (20): 
  * Type: note
  * Required: false
  * Purpose: Enter any additional notes about the order.
* **Order Date 2** (21): 
  * Type: date
  * Required: false
  * Purpose: Enter the date the order was placed (if different from the original order date).
* **Order Notes 2** (22): 
  * Type: note
  * Required: false
  * Purpose: Enter any additional notes about the order.
* **Order Total 2** (23): 
  * Type: number
  * Required: false
  * Purpose: Enter the total value of the order (if different from the original order total).
* **Payment Terms 2** (24): 
  * Type: select_multiple
  * Required: false
  * Purpose: Select the payment terms for the order (if different from the original payment terms).
* **Shipping Method 2** (25): 
  * Type: select_one
  * Required: false
  * Purpose: Select the shipping method for your order (if different from the original shipping method).
