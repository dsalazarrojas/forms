# Propane Tank Return And Refund Request Form - Help Guide
## Purpose
The "Propane Tank Return And Refund Request Form" is used for customers to request a refund for a propane tank that has been returned. This form is part of the process for managing customer returns and refunds.

## How To Complete This Form
To complete this form, please follow these steps:

1.  In the `propane_tank_return_request_details` field, provide a detailed description of the reason for the return, including any relevant information about the tank and the issue you encountered.
2.  In the `customer_info` field, provide your contact information so that we can get in touch with you if needed.
3.  If applicable, provide the `delivery_date` and `delivery_time` of when the tank was delivered to you.
4.  Enter the `propane_tank_capacity` of the tank.
5.  Provide the `propane_return_address` where the tank was delivered.
6.  In the `return_date` field, select the date you are returning the propane tank.
7.  Select the status of your refund request in the `refund_status` field.
8.  If you'd like to provide more information about the refund, you can use the `refund_details` field.
9.  Use the `notes` field for any additional comments or notes you want to attach to the return and refund request.
10. If you have a preferred phone number, please enter it in the `customer_phone` field.
11. If you have an email address where you can be reached, please enter it in the `customer_email` field.

## Field-by-Field Explanation

*   **Propane Tank Return Request Details** (`propane_tank_return_request_details`): Please provide a detailed description of the reason for the return, including any relevant information about the tank and the issue you encountered.
*   **Customer Info** (`customer_info`): Enter your contact information so that we can get in touch with you if needed.
*   **Delivery Date** (`delivery_date`): If applicable, please enter the date when the tank was delivered to you.
*   **Delivery Time** (`delivery_time`): If applicable, please enter the time of day when the tank was delivered to you.
*   **Propane Tank Capacity** (`propane_tank_capacity`): Enter the capacity of the propane tank.
*   **Propane Return Address** (`propane_return_address`): Enter the address where the propane tank was delivered.
*   **Return Date** (`return_date`): Select the date you are returning the propane tank.
*   **Refund Status** (`refund_status`): Select the status of your refund request.
*   **Refund Details** (`refund_details`): Provide any additional information about the refund, including any documentation or supporting evidence.
*   **Notes** (`notes`): Add any additional comments or notes you want to attach to the return and refund request.
*   **Customer Phone** (`customer_phone`): Enter your preferred phone number for communication.
*   **Customer Email** (`customer_email`): Enter your email address for communication.

Please note that all fields are required except for `refund_details` and `notes`, which are optional.
