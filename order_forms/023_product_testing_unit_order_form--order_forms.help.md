# Product Testing Unit Order Form - Help Guide
## Purpose
The Product Testing Unit Order Form is used to order testing units for products. This form collects essential information from customers or testers to facilitate the testing process.

## How To Complete This Form
To complete the form, follow these steps:

1. Enter the product details in the **Product Details** field.
2. Provide a brief description of the test unit request in the **Test Unit Request** field.
3. Select the **Order Date** for the testing process.
4. Enter the customer's information in the **Customer Information** field.
5. Add any relevant details about the test unit in the **Test Unit Details** field.
6. Enter the product information in the **Product Information** field.
7. Enter the shipping information in the **Shipping Information** field.
8. Provide any additional contact information in the **Contact Information** field.
9. Add any comments about the order in the **Order Comments** field.
10. Select the status of the test unit in the **Test Unit Status** field.
11. Enter the email address of the assignee for the test unit in the **Test Unit Assignee** field.

## Field-by-Field Explanation
* **Product Details**: Enter the name and description of the product to be tested.
	+ This field is a text input for product information.
* **Test Unit Request**: Briefly describe the specific testing requirements for the product.
	+ This field is a text input for the testing purpose.
* **Order Date**: Select the date you want to start the testing process.
	+ This field is a date input for scheduling the testing process.
* **Customer Information**: Enter the customer's name, email, and any other relevant contact information.
	+ This field is a text input for customer information.
* **Test Unit Details**: Add any notes or details about the test unit.
	+ This field is a text input for test unit specifics.
* **Product Information**: Enter any product-specific information required for testing.
	+ This field is a text input for product specifics.
* **Shipping Information**: Enter the shipping address and any relevant details.
	+ This field is a text input for shipping information.
* **Contact Information**: Provide any additional contact information for the customer or tester.
	+ This field is a text input for extra contact information.
* **Order Comments**: Add any comments or notes about the order.
	+ This field is a text input for order comments.
* **Test Unit Status**: Select the current status of the test unit (Not Started, In Progress, or Completed).
	+ This field is a select input with three options: Not Started, In Progress, or Completed.
* **Test Unit Assignee**: Enter the email address of the person assigned to handle the test unit.
	+ This field is an email input for the assignee's email address.
 
# Tips
* Double-check the product details to ensure accuracy.
* Clearly describe the test unit request to help the tester understand the requirements.
* Be specific when entering the order date to avoid conflicts with other orders.
* Make sure to include all necessary customer information for smooth communication.
* Enter any relevant details about the test unit to facilitate the testing process.
* Check the test unit status regularly to ensure progress and completion.
* Verify the assignee's email address to ensure proper communication.
* Add any comments or notes about the order to help the tester understand the needs.
