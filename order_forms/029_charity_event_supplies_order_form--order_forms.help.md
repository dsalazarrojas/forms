# Charity Event Supplies Order Form - Help Guide
## Purpose
This form is used to collect information for charities or organizations that need supplies for an event or gathering.

## How To Complete This Form
To complete this form, please follow these steps:

1. Enter the Organization Name and Contact Name, Email, and Phone Number.
2. Enter the Event Name and Date.
3. Choose the Delivery Date and Address.
4. Select the number of Tables, Chairs, Tablecloths, and other supplies needed (if applicable).
5. Choose if signage is required, and select the equipment and supplies needed.
6. Enter any additional notes or special requests.
7. Choose the payment method.
8. Indicate if this is a rush order.

## Field-by-Field Explanation

* **Organization Name** (Required): Please enter the name of your organization.
* **Contact Name** (Required): Please enter the primary contact name for your organization.
* **Contact Email** (Required): Please enter the primary contact email address.
* **Contact Phone** (Required): Please enter the primary contact phone number.
* **Event Name** (Required): Please enter the name of the event.
* **Event Date** (Required): Please enter the date of the event.
* **Delivery Date** (Required): Please enter the date when you need the supplies delivered.
* **Delivery Address** (Required): Please enter the address where the supplies should be delivered.
* **Number of Tables** (Optional): Please enter the number of tables needed, if applicable.
* **Number of Chairs** (Optional): Please enter the number of chairs needed, if applicable.
* **Number of Tablecloths** (Optional): Please enter the number of tablecloths needed, if applicable.
* **Signage Required** (Optional): Select if signage is required for the event.
* **Audio Equipment** (Optional): Select the type of audio equipment needed, e.g. Microphone stand, Wireless microphone, etc.
* **Registration Supplies** (Optional): Select the type of registration supplies needed, e.g. Clipboards, Name badges, etc.
* **Decorative Items** (Optional): Please enter any decorative items needed.
* **Catering Supplies** (Optional): Select the type of catering supplies needed, e.g. Plates, Napkins, etc.
* **Cleanup Supplies** (Optional): Select the type of cleanup supplies needed, e.g. Trash bags, Recycling bins, etc.
* **Special Requests** (Optional): Please enter any other items or requests.
* **Budget Limit** (Optional): Please enter the maximum budget for this order.
* **Payment Method** (Required): Choose how you want to pay for the supplies.
* **Is this a rush order?** (Required): Indicate if this is a rush order.
* **Additional Notes** (Optional): Please enter any other details or requests.
