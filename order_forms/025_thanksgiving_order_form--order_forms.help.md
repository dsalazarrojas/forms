# thanksgiving_order_form - Help Guide
## Purpose
This form is used to collect information from customers for a thanksgiving event.

## How To Complete This Form
To complete the form, follow these steps:

*   Start by filling up the "Order Details" section with the details of the order you want to place.
*   In the "customer_info" section, select "Yes" or "No" to indicate if the customer has provided information or not.
*   In the "Date and Time" section, select a date and time for the order to be delivered or picked up.
*   In the "Order Type" section, select "Yes" or "No" to indicate if the order is for a specific type of thanksgiving meal.
*   In the "number_of_guests" section, enter the number of guests attending the thanksgiving event.
*   In the "Main Course", "Side Dish", and "Drink" sections, select "Yes" or "No" to indicate if you want to include these items in the order.
*   In the "Notes" section, provide any additional notes or comments about the order.
*   In the "Email" and "Phone" fields, enter the customer's contact information.
*   Finally, in the "Order Total" field, enter the total cost of the order.

## Field-by-Field Explanation

*   **Order Details**: This is the main section where you will provide details about the order.
    •   This section is a text field where you can enter any additional information about the order, such as special requests or comments.
*   **customer_info**: This section is used to confirm if the customer has provided the necessary information for the order.
    •   Select "Yes" if the customer has provided all the necessary information, "No" otherwise.
*   **Date and Time**: This section is used to select a date and time for the order to be delivered or picked up.
    •   Select a date and time for the order using the format dd/mm/yy hh:mm AM/PM.
*   **Order Type**: This section is used to select the type of thanksgiving order.
    •   Select "Yes" if you want a specific type of meal.
*   **number_of_guests**: This section is used to select the number of guests attending the event.
    •   Enter the number of guests attending the thanksgiving event.
*   **Main Course**, **Side Dish**, and **Drink**: These sections are used to select the main course, side dish, and drink for the order.
    •   Select "Yes" to include each item in the order, "No" otherwise.
*   **Notes**: This section is used to provide any additional comments or notes about the order.
    •   Enter any additional comments or notes about the order.
*   **Email** and **Phone**: These fields are used to enter the customer's contact information.
    •   Enter the customer's email address and phone number.
*   **Order Total**: This field is used to enter the total cost of the order.
    •   Enter the total cost of the order.

## Tips
*   Make sure to fill up all the required fields correctly to ensure that the order is processed correctly.
*   Double-check the "customer_info" section to ensure that the customer has provided all the necessary information.
