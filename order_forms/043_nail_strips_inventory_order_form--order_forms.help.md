# Nail Strips Inventory Order Form - Help Guide
## Purpose
The "Nail Strips Inventory Order Form" is used to order and track nail strips inventory. This form helps inventory management teams or administrators to categorize, describe, and set status for each order.

## How To Complete This Form
To fill out this form, follow these steps:

1. Select the category for the order.
2. Select the subcategory for the order.
3. Enter the order date in the specified format (e.g. MM/DD/YYYY).
4. Enter a brief description of the order.
5. Select the status of the order (New, Ordered, Shipped, Received, Cancelled).
6. (Optional) Select the priority level of the order.
7. Add any additional notes about the order.

## Field-by-Field Explanation
* **Category** (`form_category`, text, optional): Select the category for the order.
* **Subcategory** (`form_subcategory`, text, optional): Select the subcategory for the order.
* **Order Date** (`order_date`, date, optional): Enter the order date in the specified format (e.g. MM/DD/YYYY).
* **Description** (`form_description`, text, optional): Enter a brief description of the order.
* **Status** (`form_status`, select_one, optional): Select the status of the order (New, Ordered, Shipped, Received, Cancelled).
* **Priority** (`form_priority`, select_multiple, optional): (Optional) Select the priority level of the order.
* **Notes** (`form_notes`, note, optional): Add any additional notes about the order.
