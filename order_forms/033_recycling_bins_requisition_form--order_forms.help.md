# recycling_bins_requisition_form - Help Guide

## Purpose
This form is for requisitioning a recycling bin for a specific location.

## How To Complete This Form
1. Fill in the form location where you would like the recycling bin to be placed.
2. Select the type of material you would like the bin to be used for (e.g., Bin or Other).
3. Enter the quantity of the bin you need.
4. Enter the contact person's name and phone number.
5. Enter the contact person's email address.
6. Provide any additional details about the bin you would like (optional).
7. Add any comments about the form completion (optional).

## Field-by-Field Explanation

* **Form location**: Enter the location where you would like the recycling bin to be placed. (Text, required)
* **Material Type**: Select the type of material you would like the bin to be used for (e.g., Bin or Other). (Select one option, required)
* **Quantity**: Enter the number of bins you need. (Number, required)
* **Contact Person**: Enter the name of the person to contact regarding this requisition. (Text, required)
* **Contact Phone**: Enter the phone number of the contact person. (Text, required)
* **Contact Email**: Enter the email address of the contact person. (Email, required)
* **Bin Details**: Provide any additional details about the bin you would like (e.g., size, color). (Note, optional)
* **Form Comments**: Add any comments about the form completion (optional).
