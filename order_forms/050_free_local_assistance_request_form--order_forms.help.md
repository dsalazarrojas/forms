# free_local_assistance_request_form - Help Guide

## Purpose
The free_local_assistance_request_form is a form designed to assist in capturing information for free local assistance requests. The form is used to collect details about the requestor, the type of assistance required, and payment information for the assistance provided.

## How To Complete This Form
To complete this form, simply fill out the required fields and follow the instructions below.

## Field-by-Field Explanation
* **Form name** (1): Enter a name for the form. This will be used to identify the form and distinguish it from others.
* **User name** (2): Enter the name of the individual requesting assistance. This is a text field where you can input the user's name.
* **Email** (3): Enter the email address of the individual requesting assistance. This is where the user will receive important information and updates about their assistance.
* **Phone** (4): Enter the phone number of the individual requesting assistance. This is an optional field for contact purposes.
* **Form type** (5): Select the type of assistance required. This field allows you to classify the type of assistance, such as General, Food, Financial, or Other.
* **Description** (6): Provide a brief description of the assistance required. This is a text field where you can input a detailed description of the assistance.
* **Required fields** (7): Select which fields are required for the assistance request. This allows you to set conditions for the assistance request.
* **Date** (8): Enter the date the assistance was provided or will be provided.
* **Time** (9): Enter the time the assistance was provided or will be provided. This field is for scheduling purposes.
* **Note** (10): Leave a note or comment about the assistance request.
* **Submit** (11): Review and submit your form to complete the process.
* **Payment method** (12): Select the payment method that will be used for the assistance. Choose from the options: PayPal, Stripe, or Bank transfer.
* **Accept payments** (13): Determine if you will accept payments for the assistance. This field indicates if payment is an option.
* **Payment amount** (14): Enter the payment amount for the assistance, if applicable.
* **Payment frequency** (15): Select how often the payments will be made: One-time, Ongoing, or On-demand.
* **Payment status** (16): Select the status of the payment: Pending, Paid, or Unpaid.
* **Status** (17): Set the overall status of the request: Pending, Approved, or Declined.
* **Submit status** (18): Select the status of the submission: Submited, Draft, or Published.
* **Payment gateway** (19): Choose the payment gateway to be used for the payment.
* **Submit status label** (20): Enter a label for the submission status.
* **Payment gateway label** (21): Enter a label for the payment gateway.
* **User email** (22): Enter the email address of the user who initiated the payment.
* **Payment ID** (23): Enter the payment ID for the payment made.
* **Payment transaction ID** (24): Enter the payment transaction ID for the transaction made.
* **Payment date** (25): Enter the date the payment was made.

## Tips
* Ensure you fill out all required fields to complete the form.
* Review and submit the form carefully before finalizing the assistance request.
* Make sure to follow up on the payment status and adjust accordingly.
* Use the provided fields to track and manage the assistance requests effectively.
