# Embroidery Order Form - Help Guide
## Purpose
The Embroidery Order Form is a tool used to place an order for custom embroidery work. It is designed to collect important information from the customer to produce high-quality custom embroidered products.

## How To Complete This Form
To complete the form, follow these steps:

1. Select the desired design type: Choose whether you want a Hand-Drawn or Computer-Generated Design.
2. Select the design type: Choose the type of design you want, such as a Logo, Logo and Text, or Text only.
3. Upload a design file or enter a description of your design.
4. Select a color scheme.
5. Choose the font size: Select from 8, 10, or 12 points.
6. Choose the thread color(s): Select from Red, Blue, or Green.
7. Enter the quantity of items you need.
8. Choose the type of thread: Select from Cotton or Polyester.
9. Confirm whether this is a test order or not.
10. Enter the date and time you need the order by.
11. Select the output type: Choose between Iron on, Heat Transfer, or Sew on.
12. Enter the output size.
13. Enter any special requests.
14. Enter the customer's email address.
15. Enter the customer's phone number.
16. Enter any additional comments about the order.

## Field-by-Field Explanation

* **Customer Information (customer_info)**: Enter your name and other identifying information.
* **Choose Design (design_choice)**: Select the type of design you want for your order.
* **Design Type (design_type)**: Choose the type of design you want for your order.
* **Upload Design or Description (design_file)**: If you have a design file, upload it here. If not, enter a description of your design.
* **Color Scheme (color_scheme)**: Enter the color scheme for your design.
* **Font Size (font_size)**: Enter the font size for your design.
* **Thread Color (thread_color)**: Select the color of the thread you want to use.
* **Quantity (quantity)**: Enter the number of items you need.
* **Thread Type (thread_type)**: Choose the type of thread you want to use.
* **Confirmation (confirmation)**: Check whether this is a test order or not.
* **Date and Time (date)**: Enter the date and time you need the order by.
* **Output Type (output_type)**: Choose how you want the finished order to be delivered.
* **Output Size (output_size)**: Enter the size of the finished order.
* **Special Requests (special_requests)**: Enter any special requests or instructions for the order.
* **Customer Email (customer_email)**: Enter the customer's email address.
* **Customer Phone (customer_phone)**: Enter the customer's phone number.
* **Additional Comments (order_comments)**: Enter any additional comments or instructions for the order.
