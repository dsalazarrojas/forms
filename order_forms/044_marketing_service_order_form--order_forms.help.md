# Marketing Service Order Form - Help Guide
## Purpose
The Marketing Service Order Form is used to collect project information for marketing services. This includes details about the project name, type, service level, contact email, phone number, project status, deadline, budget, location, description, client information, and team members.

## How To Complete This Form
To complete this form, please follow these steps:

1. Enter the project name and type in the corresponding fields.
2. Select the service level and project status from the available options.
3. Enter the contact email, phone number, and project deadline.
4. Enter the project budget and location.
5. Provide a brief description of the project in the "Project Description" field.
6. Enter the client's name, company, contact name, address, and phone number.
7. Select the marketing person, project manager, and account manager.
8. Enter any additional project notes and comments.
9. Finally, review and submit the form to initiate the project.

## Field-by-Field Explanation

* **Project Name**: Enter the name of the project. This will be used to identify the project and track its progress.
* **Project Type**: Select the type of marketing service required for the project from the options provided. This will help us understand the scope of the project.
* **Service Level**: Select the level of service required for the project from the available options. This will help us determine the resources required to complete the project.
* **Contact Email**: Enter the email address of the contact person for the project. This will ensure that we can communicate with you effectively.
* **Phone Number**: Enter the phone number of the contact person for the project.
* **Project Status**: Select the current status of the project from the available options. This will help us track the project's progress.
* **Project Deadline**: Enter the deadline for completing the project. This will help us prioritize tasks and allocate resources accordingly.
* **Project Budget**: Enter the budget for the project.
* **Project Location**: Enter the location of the project.
* **Project Description**: Provide a brief description of the project. This will help us understand the project's objective.
* **Client Name**: Enter the name of the client.
* **Client Company**: Enter the name of the client's company.
* **Client Contact Name**: Enter the name of the client's contact person.
* **Client Address**: Enter the client's address.
* **Client Phone Number**: Enter the client's phone number.
* **Marketing Person**: Select the marketing person responsible for the project from the available options. This will ensure that the project is handled by the right person.
* **Project Manager**: Select the project manager for the project from the available options. This will help us track the project's progress.
* **Sales Person**: Select the sales person responsible for the project from the available options. This will help us track the project's sales progress.
* **Account Manager**: Select the account manager for the project from the available options. This will help us track the project's financial progress.
* **Project Notes**: Enter any additional notes about the project.
* **Project Comments**: Enter any additional comments about the project.
* **Project**: This field is not currently used for this form.
* **None**: This field is not currently used for this form.

Note that some fields may not be relevant to your project. Please select "None" for any field that does not apply to your project.
