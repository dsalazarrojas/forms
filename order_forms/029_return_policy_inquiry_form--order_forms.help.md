# return-policy-inquiry-form - Help Guide
## Purpose
The Return Policy Inquiry Form is used for customers to submit information when they want to inquire about their order's return or exchange policy. Please use this form to inform us about any issues with your order, so we can assist you further.

## How To Complete This Form
- To submit an inquiry, fill in the required and optional fields as instructed below.

## Field-by-Field Explanation

### 1. **Return Policy (returnPolicy)** 
  (1, text, optional): This field is for the customer to briefly describe the reason for their inquiry. Enter a short description of the issue with your order.

### 2. **Contact Number (contactNumber)**
  (2, text, optional): Enter your contact number so we can contact you to discuss your inquiry further.

### 3. **Order Reference (orderReference)**
  (3, select_one, optional): Select the order number or reference number associated with your order from the provided options.

### 4. **Reason for Return (reasonForReturn)**
  (4, select_multiple, optional): Choose the reason for your return from the provided options. You can select multiple reasons if applicable.

### 5. **Exchange Preferred (exchangePreferred)**
  (5, select_one, optional): Select the preferred exchange option from the provided choices.

### 6. **Return Date (returnDate)**
  (6, date, optional): Enter the date you would like to return the order.

### 7. **Return Time (returnTime)**
  (7, time, optional): Select the time you would like to return the order.

### 8. **Notes (notes)**
  (8, note, optional): Add any additional comments or details about your order's issue.
