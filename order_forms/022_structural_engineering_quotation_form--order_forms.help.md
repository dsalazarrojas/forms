# Structural Engineering Quotation Form - Help Guide

## Purpose
This form is designed to collect information from clients for structural engineering quotations. It gathers essential details about the client, project type, location, and other relevant information to generate a quote for the project.

## How To Complete This Form
To complete this form, follow these steps:
1. Enter the client's first and last name.
2. Provide the client's email address and company name (if applicable).
3. Select the project type (Residential, Commercial, or Industrial).
4. Enter the project location.
5. Estimate the project's cost.
6. Set a deadline for the project.
7. Add any additional comments or notes (if needed).
8. If you have more than one client contact, enter their details as per instructions.

## Field-by-Field Explanation

* **Client's First Name** (`first_name`, text, required): Enter the first name of the client.
* **Client's Last Name** (`last_name`, text, required): Enter the last name of the client.
* **Company** (`company`, text, required): Enter the client's company name (if applicable).
* **Email** (`email`, email, required): Enter the client's email address.
* **Project Type** (`project_type`, select_one, required): Select the type of project (Residential, Commercial, or Industrial).
* **Project Location** (`project_location`, text, required): Enter the location of the project.
* **Estimated Cost** (`estimated_cost`, number, required): Estimate the total cost of the project.
* **Deadline** (`deadline`, date, required): Enter the deadline for completing the project.
* **Additional Comments** (`structural_engineering_quotation_form_additional_comments`, note, required): Add any additional comments or notes for the project.
* **Client Contact 2 First Name** (`first_name_2`, text, required): Enter the first name of the second client contact.
* **Last Name** (`last_name_2`, text, required): Enter the last name of the second client contact.
* **Contact Number** (`contact_number_2`, text, required): Enter the contact number of the second client contact.
* **Project Type 2** (`project_type_2`, select_one, required): Select the type of project for the second contact (Residential, Commercial, or Industrial).
* **Project Location 2** (`project_location_2`, text, required): Enter the location of the second project.
* **Additional Comments 2** (`structural_engineering_quotation_form_additional_comments_2`, note, optional): Add any additional comments or notes for the second project.
* **Client Contact 3 First Name** (`client_contact_3_first_name`, text, optional): Enter the first name of the third client contact (if applicable).
* **Last Name** (`client_contact_3_last_name`, text, optional): Enter the last name of the third client contact (if applicable).
* **Contact Number** (`contact_number_3`, text, optional): Enter the contact number of the third client contact (if applicable).
* **Project Type 3** (`project_type_3`, select_one, optional): Select the type of project for the third contact (Residential, Commercial, or Industrial).

Note: Fields marked as "required" must be completed to generate a quotation. Fields marked as "optional" may be skipped if not needed.
