# shipping_container_issue_complaint_form - Help Guide
## Purpose
The shipping_container_issue_complaint_form is used to report issues with your shipping containers. Please use this form to report any problems that occurred during shipping, such as damage, missing items, or other issues.

## How To Complete This Form
To complete this form, please follow these steps:

1. Select the Category that best describes the issue with your shipping container.
2. Provide a detailed Description of the problem.
3. Enter the Form ID, which is a unique identifier for your shipping container.
4. Select the Assigned Tool that is associated with your shipping container.
5. Enter the Output File name or reference number.

## Field-by-Field Explanation
### Category
* **Category** (`order forms`, required): Select the category that best describes the problem with your shipping container. For example, "damage" or "missing item".

### Description
* **Description** (text, required): Enter a clear and detailed description of the issue with your shipping container.

### Form ID
* **Form ID** (text, required): Enter the unique identifier for your shipping container.

### Assigned Tool
* **Assigned Tool** (select_one, required): Select the tool that is associated with your shipping container, such as "chatjimmy" or "Other".

### Output File
* **Output File** (text, required): Enter the name or reference number of the output file associated with your shipping container.

### Shipping Container Issue Complaint Form ID
* **Shipping Container Issue Complaint Form ID** (text, required): Enter the unique identifier for this form submission.

### Shipping Container Issue Complaint Form Description
* **Shipping Container Issue Complaint Form Description** (text, required): Enter a clear and brief description of this form submission.
 

## Tips
* Please fill out the form completely and accurately to help us troubleshoot and resolve your issue efficiently.
* If you are unsure about any of the fields, please contact our support team for assistance.
* We will review and respond to your form submission as soon as possible.
