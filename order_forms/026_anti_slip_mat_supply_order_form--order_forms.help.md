# Anti Slip Mat Supply Order Form - Help Guide
## Purpose
The Anti Slip Mat Supply Order Form is used to collect information for the processing and delivery of anti-slip mats ordered by internal employees.

## How To Complete This Form
To complete this form, follow these steps:
1. Enter the requester's name in the "Requester name" field.
2. Enter the company or department's name in the "Company or department" field (if applicable).
3. Enter the product code or item model in the "Product code or item" field.
4. Enter the quantity of mats required in the "Quantity required" field.
5. Select the preferred color for the mats in the "Color preference" field (if applicable).
6. Enter the shipping address in the "Shipping address" field.
7. If required, specify the desired delivery date in the "Desired delivery date" field.
8. Optionally, enter the purchase order number for billing purposes.

## Field-by-Field Explanation
- **Requester name** (text, required): Enter the name of the person placing the order.
- **Company or department** (text, optional): Enter the name of the billing or delivery department (if applicable).
- **Product code or item** (text, required): Enter the model or SKU number for the mat.
- **Quantity required** (number, required): Enter the number of mats required.
- **Color preference** (select_one, optional): Select the preferred color for the mats (Black, Grey, Yellow, or Custom).
- **Shipping address** (text, required): Enter the full delivery address including postal code.
- **Desired delivery date** (date, optional): Specify the required delivery date if urgent.
- **Purchase order number** (text, optional): Enter the reference number for billing purposes.
