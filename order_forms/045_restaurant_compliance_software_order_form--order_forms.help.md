# restaurant_compliance_software_order_form - Help Guide
## Purpose
This form collects information from customers about their restaurant compliance software needs and preferences.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in your customer's name and email address in the "Customer Name" and "Customer Email" fields, respectively.
2. Enter your customer's phone number in the "Customer Phone" field.
3. For the "Restaurant Compliance Software Package" field, select the specific package you're interested in.
4. Enter the name of the software package you're interested in.
5. Fill in the "Software Version" field with the version of the software package you're interested in.
6. Enter the name of the vendor that provides the software package.
7. If applicable, enter the name and email address of the contact person for the vendor in the "Contact Name" and "Contact Email" fields.
8. Enter the contact person's phone number in the "Contact Phone" field.

## Field-by-Field Explanation
* **Restaurant Compliance Software Package**: Select the specific package you're interested in for the restaurant compliance software.
* **Customer Name**: Enter the name of the customer who is inquiring about the software.
* **Customer Email**: Enter a valid email address for the customer. This will help us follow up with them about their request.
* **Customer Phone**: Enter the customer's phone number so we can reach them if needed.
* **Software Package Name**: Enter the name of the specific software package you're interested in.
* **Software Version**: Enter the version of the software package you're interested in.
* **Vendor Name**: Enter the name of the vendor that provides the software package.
* **Contact Name**: Enter the name of the contact person for the vendor.
* **Contact Email**: Enter a valid email address for the contact person.
* **Contact Phone**: Enter the contact person's phone number. 

## Tips
* Be as specific as possible when filling out the form so we can best understand your customer's needs.
* If you have any additional information about the customer's requirements or preferences, feel free to include it in the comments section (if available).
* If you're not sure about any of the fields, please ask your sales representative for guidance.
