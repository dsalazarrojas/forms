# Custom Sound Drop Order Form - Help Guide

## Purpose

This form is used to gather information from customers to create a custom sound drop.

## How To Complete This Form

To complete this form, follow these steps:

1. Fill in the "Sound Drop Name" field with the name of the sound drop you are interested in ordering.
2. Select the artists involved in the "Artists" field.
3. Add any additional sound drop details in the "Sound Drop Details 2" field.
4. Provide information about the delivery process in the "Delivery Details" field.
5. Select the sound drop files in the "Sound Drop Files" field.
6. Add any additional sound drop comments in the "Sound Drop Comments" field.
7. Add any artist comments in the "Artist Comments" field.
8. Add any studio comments in the "Studio Comments" field.
9. Make sure to review your order carefully before submitting it.

## Field-by-Field Explanation

* **Sound Drop Name** (`sound_drop_name`, text, required): Enter the name of the sound drop.
* **Artists** (`sound_drop_artists`, select_one, required): Select at least one artist involved in the sound drop.
* **Sound Drop Details 2** (`sound_drop_details_2`, text, optional): Add any additional details about the sound drop.
* **Delivery Details** (`delivery_details`, text, optional): Enter any additional delivery details.
* **Delivery Date** (`delivery_date`, date, optional): Enter the delivery date in MM/DD/YYYY format.
* **Delivery Time** (`delivery_time`, time, optional): Enter the delivery time.
* **Sound Drop File** (`sound_drop_file`, text, optional): Enter any relevant file information about the sound drop.
* **Sound Drop Notes** (`sound_drop_notes`, text, optional): Enter any additional sound drop comments or notes.
* **Sound Drop Files** (`sound_drop_files`, select_multiple, required): Select the sound drop files involved in the sound drop.
* **Sound Drop Comments** (`sound_drop_comments`, text, optional): Enter any additional sound drop comments.
* **Artist Comments** (`artist_comments`, text, optional): Enter any comments from the artist.
* **Studio Comments** (`studio_comments`, text, optional): Enter any comments from the studio.
* **Sound Drop Comments** (`sound_drop_comments`, text, optional): Enter any additional sound drop comments.

## Tips

* Make sure to fill in all required fields.
* Be specific and detailed in your answers.
* Review your order carefully before submitting it.
* If you have any questions, please don't hesitate to contact us.
