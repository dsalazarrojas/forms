# sustainability_report_printing_order_form - Help Guide
## Purpose
This form is designed to collect information for printing a report related to sustainability, environmental, or conservation topics.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the report details in the "Report details" field.
2. Provide delivery details in the "Delivery details" field.
3. Enter order information in the "Order information" field.
4. Select the delivery method in the "Delivery" field.
5. Choose the delivery date and time in the "Delivery date" and "Delivery time" fields.
6. Add any delivery note in the "Delivery note" field.
7. Select the report PDFs to be printed in the "Report PDFs" field (multiple selections are possible).
8. Finally, choose the delivery method from the options provided in the "Delivery method" field.

## Field-by-Field Explanation
* **Report details** (Report details, text, required/optional): Enter the details of the report that needs to be printed.
* **Delivery details** (Delivery details, text, required/optional): Provide any relevant information about the delivery, such as special instructions or handling requirements.
* **Order information** (Order information, text, required/optional): Enter any other information related to the order.
* **Delivery** (Delivery, text, required/optional): Select the delivery method (e.g., ground, air, sea, express).
* **Delivery date** (Delivery date, date, required/optional): Choose the date for delivery.
* **Delivery time** (Delivery time, time, required/optional): Select the time for delivery.
* **Delivery note** (Delivery note, text, required/optional): Add any note about the delivery.
* **Report PDFs** (Report PDFs, select_multiple, required/optional): Select the report PDFs to be printed (multiple selections are possible).
* **Delivery method** (Delivery method, select_one, required/optional): Select the delivery method for the report.

## Tips
* Make sure to fill in all required fields to ensure accurate and successful order printing.
