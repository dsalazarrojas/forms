# Easter Brunch Order Form - Help Guide
## Purpose
The Easter Brunch Order Form is used to collect information for an Easter Brunch event. This form helps the organizers to gather details about the guests, their dietary restrictions, and any special requests for the event.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the following details for the Easter Brunch event:
	* **Easter Brunch Order**: Enter a brief description of your order in this field.
	* **Easter Brunch Guests**: Enter the number of guests attending the Easter Brunch.
	* **Easter Brunch Date**: Select the date of the event.
	* **Easter Brunch Time**: Select the time of the event.
	* **Easter Brunch Location**: Enter the location of the event.
2. Specify any dietary restrictions for the guests. Select one or more of the following options:
	* **Gluten Free**
	* **Vegetarian**
	* **Vegan**
3. If you have any special requests for the event, you can enter them in the **Special Requests** field.
4. Enter your email address and phone number so that we can contact you with updates and information about the event.

## Field-by-Field Explanation
* **Easter Brunch Order**: (`1`, `text`, required/optional) This field is a text input for you to describe your order.
* **Easter Brunch Guests**: (`2`, `number`, required/optional) Enter the number of guests attending the Easter Brunch.
* **Easter Brunch Date**: (`3`, `date`, required/optional) Select the date of the Easter Brunch event.
* **Easter Brunch Time**: (`4`, `time`, required/optional) Select the time of the Easter Brunch event.
* **Easter Brunch Location**: (`5`, `text`, required/optional) Enter the location of the Easter Brunch event.
* **Dietary Restrictions**: (`6`, `select_one`, required) Select one or more dietary restrictions for the guests. Options:
	+ **Gluten Free**
	+ **Vegetarian**
	+ **Vegan**
* **Special Requests**: (`7`, `text`, required/optional) Enter any special requests for the event.
* **Easter Brunch Email**: (`8`, `email`, required/optional) Enter your email address so that we can contact you with updates and information about the event.
* **Easter Brunch Phone**: (`9`, `text`, required/optional) Enter your phone number so that we can contact you with updates and information about the event.
* **Additional Info**: (`10`, `text`, required/optional) Enter any additional information about the event.
* **Order Notes**: (`11`, `text`, required/optional) Enter any notes or comments about the order.
* **Order Status**: (`12`, `select_multiple`, required) Select the status of the order. Options:
	+ **Confirmed**
	+ **Declined**
	+ **Pending**
