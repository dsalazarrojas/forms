# Reusable Food Wrap Order Form - Help Guide
## Purpose
The Reusable Food Wrap Order Form is used to create, manage, and review orders for reusable food wraps. This form is designed to gather information about the customer's order, including their contact details, product preferences, and any additional information they may need to provide.

## How To Complete This Form
To complete this form, follow these steps:

1. Review the form and ensure you have all the necessary information before starting.
2. Fill in the **Order Information** section with the required details about the order.
3. In the **Product Information** section, select the product(s) you wish to order.
4. If necessary, provide **Additional Information** about the order in the **Additional Information** section.
5. Choose whether the order requires a **Summary** by selecting either **Yes** or **No** in the **Order Summary** section.
6. Finally, provide any **Customer Notes** if needed.

## Field-by-Field Explanation

* **Order Information** (order_info, text, required: false):
	+ This section is where you can fill in the basic details about the order, such as the customer's name, contact information, and order date.
* **Product Information** (product_info, text, required: false):
	+ In this section, select the product(s) you wish to order from the available options.
* **Additional Information** (additional_info, note, required: false):
	+ If you need to provide any extra information about the order, such as special requests or instructions, use this section.
* **Order Summary** (order_summary, select_multiple, required: false):
	+ Choose whether the order requires a summary by selecting either **Yes** or **No**.
* **Customer Notes** (customer_notes, note, required: false):
	+ If you have any specific notes or comments about the customer, use this section.

## Tips
* Please ensure you have all the necessary information before starting the form.
* Double-check your selections and entries for accuracy.
* If you are unsure about any field, refer to the product documentation for further guidance.
* Use this form for orders for reusable food wraps only.
