# Fathers Day Cookie Order Form - Help Guide
## Purpose
This form is used to order custom cookies for Father's Day. Please provide your order details, a personal message, and any other information required to create a special gift for your father.

## How To Complete This Form
To complete this form, please follow these steps:

1. Provide your order details in the `Order Details` page.
2. Enter a personal message for the occasion in the `Order Message` page.
3. Choose the type of cookie you would like to order in the `Cookie Type` page.
4. Select the shape of the cookie in the `Cookie Shape` page.
5. Enter the quantity of cookies you would like to order in the `Quantity` page.
6. Enter the name of the gift recipient in the `Name` page.
7. Enter the father's name or a relevant detail about the gift in the `Father` page.
8. Select the date you would like to deliver the cookies in the `Date` page.

## Field-by-Field Explanation
### Order Details
• **Order Details** (`order_details`, text, required: false): Enter a brief description of your order, including any specific details you would like to include, such as the occasion, the father's interests, or any other relevant information.

### Order Message
• **Order Message** (`order_message`, text, required: false): Enter a personal message for the occasion, such as a heartfelt message or a funny joke, to make the gift extra special.

### Cookie Type
• **Cookie Type** (`cookie_type`, select_multiple, required: false): Choose the type of cookie you would like to order. You can select one or multiple options from the list.

### Cookie Shape
• **Cookie Shape** (`cookie_shape`, select_one, required: false): Choose the shape of the cookie you would like to order. You can select one option from the list.

### Quantity
• **Quantity** (`quantity`, number, required: false): Enter the quantity of cookies you would like to order. Please provide a whole number, as we can't process fractional cookies.

### Name
• **Name** (`name`, text, required: false): Enter the name of the gift recipient, such as your father's name or a relevant detail about the gift.

### Father
• **Father** (`father_day`, text, required: false): Enter the father's name or a relevant detail about the gift, such as a nickname or a special occasion.

### Date
• **Date** (`date`, date, required: false): Select the date you would like to deliver the cookies. Please use the date format YYYY-MM-DD.

## Tips
- Make sure to double-check your order details to ensure accuracy.
- If you have any questions or special requests, please contact us in advance.
- We can accommodate most special requests, but please be aware that some options may incur additional costs.
