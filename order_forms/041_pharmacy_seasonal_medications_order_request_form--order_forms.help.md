# Pharmacy Seasonal Medications Order Request Form - Help Guide
## Purpose
The "Pharmacy Seasonal Medications Order Request Form" is used to request seasonal medications for patients or healthcare providers.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter your First Name and Last Name in the respective fields.
2. Enter your Email and Phone number for contact purposes.
3. Fill in the Address if you want to provide an optional address.
4. If you're requesting medication, enter the Medication name.
5. Specify the Dosage and Quantity of the medication.
6. Select the Date and Time of administration.
7. If applicable, enter any Medical Condition related to the medication.
8. Specify the Order Date and Delivery Date.
9. Decide if you want to order or not by selecting "Yes" or "No" in the "Order By" field.
10. Choose the delivery method ("Yes" or "No").
11. If you want to specify a Pharmacy Name, you can do so in the respective field.
12. Add any additional Order Note if necessary.
13. Enter the Patient ID if applicable.
14. Select the Doctor's name.
15. If you're requesting a medication with a specific Medical Specialty, select the relevant specialty.
16. Specify the Order Status (Active or Inactive).
17. If applicable, select the Medication Type ("Yes" or "No").
18. Choose the payment method ("Yes" or "No").
19. Finally, select the Pharmacy Location if it's applicable.
20. Enter the Order Number for tracking purposes, although this is not required.

## Field-by-Field Explanation
* **First Name**: Enter your first name as requested.
* **Last Name**: Enter your last name as requested.
* **Email**: A valid email address is required for communication.
* **Phone**: Enter your phone number for contact purposes.
* **Address**: If you want to provide an address, enter it here.
* **Medication**: If requesting medication, enter the name of the medication.
* **Dosage**: Specify the dosage of the medication.
* **Quantity**: Enter the quantity of the medication needed.
* **Date Of Administration**: Select the date when the medication should be administered.
* **Time Of Administration**: Select the time of administration for the medication.
* **Medical Condition**: If relevant, enter any medical condition related to the medication.
* **Order Date**: Select the date for the order request.
* **Delivery Date**: Specify the date when the medication should be delivered.
* **Order By**: Decide if you want to order the medication ("Yes" or "No").
* **Delivery Method**: Select if you want to have the medication delivered ("Yes" or "No").
* **Pharmacy Name**: Optionally, specify the name of the pharmacy making the request.
* **Order Note**: Add any additional notes about the order.
* **Patient ID**: If applicable, enter the patient ID.
* **Doctor**: Enter the name of the doctor making the request.
* **Medical Specialty**: If applicable, select the specific medical specialty.
* **Order Status**: Select the status of the order (Active or Inactive).
* **Medication Type**: If applicable, select if the medication is a specific type.
* **Payment Method**: Select the method of payment ("Yes" or "No").
* **Pharmacy Location**: If applicable, select the location of the pharmacy.
* **Order Number**: Optionally, enter the order number for tracking purposes.

## Tips
- Please ensure all required fields are filled out for successful submission.
- If a field is not applicable to you, feel free to leave it blank or mark it as "N/A" if necessary.
- For fields with multiple options, select the correct option that applies to your situation.
