# Supplier Delivery Reliability Evaluation Form - Help Guide
## Purpose
This form is designed to gather information about a supplier's delivery performance. It's meant to be filled out for each supplier evaluation.

## How To Complete This Form
1. Enter the supplier's name in the "Supplier Name" field.
2. Enter the order number related to the delivery performance being evaluated.
3. Select the date of the delivery from the calendar.
4. Select the time of the delivery from the time picker.
5. Fill in any other fields as instructed below.

## Field-by-Field Explanation
* **Supplier Name** (`supplier_name`, text, optional): Enter the name of the supplier being evaluated.
* **Order Number** (`order_number`, text, optional): Enter the order number related to the delivery performance being evaluated.
* **Delivery Date** (`delivery_date`, date, optional): Select the date on which the delivery was made.
* **Delivery Time** (`delivery_time`, time, optional): Select the time of the delivery.
 
## Tips
- Make sure to fill out the form accurately to ensure reliable data.
- If you have trouble filling out a field, please contact [form@gic.mx](mailto:form@gic.mx).
