# Personalized Notebook Order Form - Help Guide
## Purpose
This form is used to capture information for orders that require customization, such as personalized notebooks.

## How To Complete This Form

1. Fill out the Order Form section with the necessary details about the order.
2. Provide shipping details in the Shipping Details section.
3. Enter customer information, including name, email, and phone number.
4. Add any additional order comments or notes as needed.
5. Select the notebook type and size as required.
6. Choose the notebook color and order status.
7. Complete any remaining fields as necessary.
