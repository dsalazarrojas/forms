# Vending Service Order Form - Help Guide
## Purpose

The Vending Service Order Form is a tool used to manage and track vending orders from creation to completion. This form is designed to gather necessary information about the order, including machine details, order status, and dates for restocking and ordering.

## How To Complete This Form

1.  To complete this form, simply follow the instructions for each section.
2.  Fill in the required information for each field.
3.  Double-check your answers for accuracy before submitting the form.

## Field-by-Field Explanation

* **Machine ID** (`machine_id`, number, required/optional): Please enter the unique identifier of the machine that is related to this order.
* **Machine Type** (`machine_type`, select_one, optional): Select the type of machine associated with this order. This can be a Vending Machine, Micro-Station, or Mini-Station.
* **Product ID** (`product_id`, number, optional): Enter the product ID for the product being ordered.
* **Quantity** (`quantity`, number, optional): Enter the quantity of the product being ordered.
* **Machine ID 2** (`machine_id_2`, number, optional): This field seems to be a duplicate of the Machine ID field. Please ensure you are filling in the correct machine ID.
* **Order Date** (`order_date`, date, optional): Enter the date on which this order was made.
* **Restock Date** (`restock_date`, date, optional): Enter the date on which the machine should be restocked.
* **Machine ID 3** (`machine_id_3`, number, optional): This field is a further duplicate of Machine ID, and it's best to avoid filling this in as it's not clear what its purpose is.
* **Order ID** (`order_id`, number, optional): This field appears to be a unique identifier for the order, but its purpose is not immediately clear.
* **Order Status** (`order_status`, select_one, optional): Select the current status of the order from New, In Progress, or Completed.
* **Machine ID 4** (`machine_id_4`, number, optional): This field is another duplicate of Machine ID, and it's recommended to not fill this in as it's not clear what its purpose is.
