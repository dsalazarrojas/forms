# Customer Seasonal Collection Request Form - Help Guide
## Purpose
The Customer Seasonal Collection Request Form is used by customers to provide information about their seasonal collection preferences. This form helps the business or organization understand the customer's needs and schedule the collection accordingly.

## How To Complete This Form
To complete this form, please follow the instructions below:

1. Review each page carefully to ensure you have filled out all the necessary information.
2. Fill out the form accurately and completely, as this information will be used to determine the best collection schedule for your seasonal collections.

## Field-by-Field Explanation
* **Page 1: Customer Seasonal Collection Request Form**: This is the first page of the form where you can enter any additional information that is not included in the other pages.
* **Pickup requests**: This field allows you to request a pickup or not. Please select "Yes" if you would like to have your collections collected. 
* **Pickup request description**: This field is for you to provide a brief description of your collection request.
* **Collection date**: This is where you can select a date for your collections to be collected.
* **Collection time**: This is where you can select a time for your collections to be collected.
* **Seasonal collection schedule**: This field is for you to describe your collection schedule for the season.
* **Seasonal schedule**: This field allows you to indicate whether you have a seasonal schedule.
* **Seasonal collections**: This field allows you to select whether you are interested in having seasonal collections.
* **Seasonal collections description**: This field is for you to describe your seasonal collections.
* **Collections**: This field allows you to select the type of collections you are interested in.
* **Collections**: This field allows you to select the type of collections you are interested in. (This field is the same as "Seasonal collections") 
* **Collections description**: This field is for you to describe your collections.

Note: Some fields are optional and only appear on specific pages of the form. Please fill out as much information as possible to ensure the best collection schedule is created for you.
