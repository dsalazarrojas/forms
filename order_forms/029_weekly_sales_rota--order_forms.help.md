# Weekly Sales Rota - Help Guide
## Purpose
The "Weekly Sales Rota" form is used to schedule and organize sales activities across a week. It requires sales managers and representatives to input their email addresses, phone numbers, and work schedules for each day of the week.

## How To Complete This Form
To complete this form, follow the steps below:

* Fill out the form with the required information for each sales manager and representative.
* Select the correct email address and phone number for each sales manager and representative.
* Input the work schedule for each day of the week using the date fields.

## Field-by-Field Explanation

* **Sales Manager** (`sales_manager`, `text`, optional): This field is where you input the name of the sales manager.
* **Sales Rep 1** (`sales_rep_1`, `text`, optional): This field is where you input the name of Sales Rep 1.
* **Sales Rep 2** (`sales_rep_2`, `text`, optional): This field is where you input the name of Sales Rep 2.
* **Sales Rep 3** (`sales_rep_3`, `text`, optional): This field is where you input the name of Sales Rep 3.
* **Monday** (`day1`, `date`, optional): This field is where you input the work schedule for Monday. Select the date in the format `YYYY-MM-DD`.
* **Tuesday** (`day2`, `date`, optional): This field is where you input the work schedule for Tuesday. Select the date in the format `YYYY-MM-DD`.
* **Wednesday** (`day3`, `date`, optional): This field is where you input the work schedule for Wednesday. Select the date in the format `YYYY-MM-DD`.
* **Thursday** (`day4`, `date`, optional): This field is where you input the work schedule for Thursday. Select the date in the format `YYYY-MM-DD`.
* **Friday** (`day5`, `date`, optional): This field is where you input the work schedule for Friday. Select the date in the format `YYYY-MM-DD`.
* **Saturday** (`day6`, `date`, optional): This field is where you input the work schedule for Saturday. Select the date in the format `YYYY-MM-DD`.
* **Sunday** (`day7`, `date`, optional): This field is where you input the work schedule for Sunday. Select the date in the format `YYYY-MM-DD`.
* **Sales Manager Email** (`sales_manager_email`, `email`, optional): This field is where you input the email address of the sales manager.
* **Sales Manager Phone** (`sales_manager_phone`, `text`, optional): This field is where you input the phone number of the sales manager.
* **Sales Rep 1 Email** (`sales_rep_1_email`, `email`, optional): This field is where you input the email address of Sales Rep 1.
* **Sales Rep 1 Phone** (`sales_rep_1_phone`, `text`, optional): This field is where you input the phone number of Sales Rep 1.
* **Sales Rep 2 Email** (`sales_rep_2_email`, `email`, optional): This field is where you input the email address of Sales Rep 2.
* **Sales Rep 2 Phone** (`sales_rep_2_phone`, `text`, optional): This field is where you input the phone number of Sales Rep 2.
* **Sales Rep 3 Email** (`sales_rep_3_email`, `email`, optional): This field is where you input the email address of Sales Rep 3.
* **Sales Rep 3 Phone** (`sales_rep_3_phone`, `text`, optional): This field is where you input the phone number of Sales Rep 3.

## Tips

* Make sure to input accurate and up-to-date information for each sales manager and representative.
* Double-check your email addresses and phone numbers for correctness.
* Use the correct format for the date fields (YYYY-MM-DD).
* Complete all required fields to avoid errors.
