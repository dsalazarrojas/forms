# Lubricant Delivery Request Form - Help Guide
## Purpose
This form is used to request the delivery of lubricants to the maintenance team.

## How To Complete This Form
1. Please fill in the required fields with accurate information.
2. Select the type of lubricant you need to deliver.
3. Specify the quantity of lubricant to be delivered.
4. Choose a delivery date and time, if desired.
5. Indicate if this is a recurring delivery.
6. Select the maintenance team that will receive the delivery.
7. Optionally, select a supplier for the delivery.
8. Add any additional order notes, if needed.
9. Enter your email address and phone number for contact purposes.

## Field-by-Field Explanation
* **Delivery Request**: Enter a brief description of the delivery request. This field is required.
* **Lubricant Type**: Choose the type of lubricant you need to deliver (e.g., Lubricant A, Lubricant B, Lubricant C). This field is required.
* **Quantity**: Specify the amount of lubricant to be delivered. This field is required.
* **Delivery Date**: Enter the date you would like the lubricant to be delivered. Note that this field is not required.
* **Delivery Time**: Choose a specific time for delivery, if desired. Note that this field is not required.
* **Recurring Delivery**: Check if this is a recurring delivery. If you select 'True', you will need to confirm the frequency of the delivery. This field is required.
* **Maintenance Team**: Select the maintenance team that will receive the delivery. This field is required.
* **Supplier**: Optionally, select a supplier for the delivery. This field is not required.
* **Order Notes**: Add any additional notes or comments about the order, if needed. This field is not required.
* **Email Address**: Enter your email address for contact purposes. This field is required.
* **Phone Number**: Enter your phone number for contact purposes. This field is required.
