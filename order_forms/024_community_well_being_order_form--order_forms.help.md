# Community Well Being Order Form - Help Guide

## Purpose
This form is designed to collect information from customers to place orders for "Community Well Being" products. The form is intended to be used by customers who want to order products for various purposes, such as individuals, families, or groups.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in your personal information, including your full name, email address, and phone number.
2. Select the type of products you are ordering and the target audience for these products.
3. Choose the method of distribution for the products.
4. Specify the preferred delivery date and time.
5. If applicable, enter any special delivery instructions.
6. Indicate if the order qualifies for a bulk discount.
7. Select the payment method you will use.
8. If different from the delivery address, enter the billing address.
9. Indicate if you are tax-exempt.
10. If applicable, enter your tax ID number.
11. If you would like to include a gift message, enter the message.
12. Enter any additional comments or special requests.

## Field-by-Field Explanation
### 1. Full Name (Required)
* **Full Name**: Enter your full name as it appears on your official documents.

### 2. Email Address (Required)
* **Email Address**: Enter your email address for order confirmation.

### 3. Phone Number (Required)
* **Phone Number**: Enter your contact phone number.

### 4. Delivery Address (Required)
* **Delivery Address**: Enter the address where the order should be delivered.

### 5. Organization Name (if applicable)
* **Organization Name**: If this is an order for an organization, enter the name of the organization.

### 6. What type of well-being products are you ordering? (Required)
* **What type of well-being products are you ordering?**: Select the type of products you are ordering (e.g. Wellness Kits, Mental Health Resources, etc.).

### 7. Target Audience (Required)
* **Target Audience**: Select the target audience for the products (e.g. Individuals, Families, etc.).

### 8. How will these products be distributed? (Required)
* **How will these products be distributed?**: Select the method of distribution (e.g. Direct to individuals, Through community center, etc.).

### 9. Preferred Delivery Date (Required)
* **Preferred Delivery Date**: Enter the date you would like to receive the order.

### 10. Preferred Delivery Time (Required)
* **Preferred Delivery Time**: Select the time window you would like to receive the order.

### 11. Special Delivery Instructions
* **Special Delivery Instructions**: Enter any special instructions for the delivery (e.g. gate codes, etc.).

### 12. Does this order qualify for bulk discount? (Optional)
* **Does this order qualify for bulk discount?**: Indicate if the order qualifies for a bulk discount.

### 13. Payment Method (Required)
* **Payment Method**: Select the payment method you will use (e.g. Credit Card, Debit Card, etc.).

### 14. Billing Address (if different from delivery) (Optional)
* **Billing Address**: If the billing address is different from the delivery address, enter it here.

### 15. Are you tax-exempt? (Optional)
* **Are you tax-exempt?**: Indicate if you are tax-exempt.

### 16. Tax ID Number (if applicable) (Optional)
* **Tax ID Number**: If you are tax-exempt, enter your tax ID number.

### 17. Would you like to include a gift message? (Optional)
* **Would you like to include a gift message?**: If you want to include a gift message with the order, enter it here.

### 18. Any additional comments or special requests? (Optional)
* **Any additional comments or special requests?**: Enter any additional comments or special requests you have.

## Tips
* Be sure to double-check all fields for accuracy before submitting the form.
* If you have any questions or concerns, please contact us.
* We will follow up with you to confirm the order details.
