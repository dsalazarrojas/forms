# point_of_sale_agreement_extension_form - Help Guide
## Purpose
This form is used to extend a point of sale agreement, typically for a customer who has requested an extension on their payment terms. It is intended to capture relevant information for the sales team and customer service to manage and track the agreement.

## How To Complete This Form
To complete this form, follow these steps:

1. Select whether the customer has agreed to the extension (Customer field).
2. Enter the order date (Order Date field).
3. Enter the date the sale was made (Sale Date field).
4. Enter the start date of the extended agreement (Extension Start Date field).
5. Choose the type of agreement being extended (Agreement Type field).
6. Enter any additional customer notes (Customer Notes field).
7. Select whether the sales agent is involved in the agreement (Sales Agent field).
8. Enter the sales agent's phone number (Sales Agent Phone field).
9. Enter the sales agent's email address (Sales Agent Email field).
10. Enter the sales agent's notes (Sales Agent Notes field).
11. Enter the start date of the agreement (Agreement Start Date field).
12. Enter the end date of the agreement (Agreement End Date field).

## Field-by-Field Explanation

* **Customer** (Select One): This field is used to select whether the customer has agreed to the extension. Select 'Yes' if the customer has agreed, or 'No' if not.
* **Order Date** (Date): Enter the date the order was originally made.
* **Sale Date** (Date): Enter the date the sale was actually made.
* **Extension Start Date** (Date): Enter the date the agreement is set to start.
* **Agreement Type** (Select One): Choose the type of agreement being extended.
* **Customer Notes** (Note): Enter any additional customer notes that are relevant to the agreement.
* **Sales Agent** (Select One): Select whether the sales agent is involved in the agreement. Select 'Yes' if they are, or 'No' if not.
* **Sales Agent Phone** (Text): Enter the sales agent's phone number.
* **Sales Agent Email** (Email): Enter the sales agent's email address.
* **Sales Agent Notes** (Note): Enter any notes from the sales agent that are relevant to the agreement.
* **Agreement Start Date** (Date): Enter the date the agreement is set to start.
* **Agreement End Date** (Date): Enter the date the agreement is set to end.

## Tips

* Make sure to fill out all required fields before submitting the form.
* Double-check the accuracy of the information entered.
* Ensure that all relevant fields are filled out to ensure accurate tracking and management of the agreement.
* If you are unsure about any field, please contact the sales team for guidance.
