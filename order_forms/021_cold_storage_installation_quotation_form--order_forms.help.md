# Cold Storage Installation Quotation Form - Help Guide
## Purpose
This form gathers information from clients who are requesting cold storage installation services to prepare an accurate quotation.

## How To Complete This Form
1. Fill out all the required fields marked as "true".
2. Ensure that all the provided fields have accurate and detailed information.
3. Review your submission before submitting it for quotation preparation.

## Field-by-Field Explanation
* **Client name** (`client_name`, text, required): The name of the company or individual requesting the installation service.
* **Project address** (`project_address`, text, required): The exact location where the installation will take place.
* **Installation scope** (`installation_scope`, text, required): A detailed description of the required work for the installation.
* **Preferred start date** (`preferred_start_date`, date, optional): The preferred start date for the installation work. If left blank, it will be considered as no preference.
* **Estimated storage volume** (`estimated_volume`, number, optional): The estimated cubic meters of storage volume needed.
* **Onsite requirements** (`onsite_requirements`, text, optional): Any specific requirements for the installation, such as power, access, or permits.
* **Contact phone** (`contact_phone`, text, optional): The phone number for site coordination.
* **Budget range** (`budget_range`, text, optional): A rough estimate for budgeting purposes.
* **Additional notes** (`additional_notes`, text, optional): Any other important considerations or notes that might affect the installation process.
