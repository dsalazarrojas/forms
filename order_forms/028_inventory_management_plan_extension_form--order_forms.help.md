# Inventory Management Plan Extension Form - Help Guide
## Purpose
The Inventory Management Plan Extension Form is used to request additional inventory items or modifications to existing ones. This form helps inventory managers to track and manage extension requests from users.

## How To Complete This Form
To complete this form, follow these steps:
1. Fill in the required fields: product id, product name, and extension reason.
2. Optional fields are not required but can be filled in if necessary: product name, extension request date, extension request date and time, request reason, request comment.
3. Select the Assigned tool option (Yes/No) to indicate whether the request is assigned to a specific tool.
4. Select the extension status (Extension Requested/Approved/Rejected) to indicate the current status of the request.
5. Fill in the submitted_by, submitted date, approved by, approved date, updated by, updated date, submitted for, assigned to, and extension comment fields if applicable.

## Field-by-Field Explanation

* **product_id** (Number): Enter the unique ID of the product you're requesting to extend.
* **product_name** (Text): Enter the name of the product you're requesting to extend.
* **extension_request_date** (Date): If you have a specific date for the extension request, enter it here.
* **extension_request_date_time** (Time): If you have a specific time for the extension request, enter it here.
* **request_reason** (Text): Briefly describe the reason for the extension request.
* **request_comment** (Note): Add any additional comments or notes about the request.
* **Assigned Tool** (Select Multiple): Select 'Yes' if the request is assigned to a specific tool, 'No' otherwise.
* **extension_status** (Select One): Select the current status of the request (Extension Requested, Approved, or Rejected).
* **submitted_by** (Text): Enter the name of the person who submitted the request.
* **submitted_date** (Date): Enter the date the request was submitted.
* **approved_by** (Text): Enter the name of the person who approved the request.
* **approved_date** (Date): Enter the date the request was approved.
* **updated_by** (Text): Enter the name of the person who updated the request.
* **updated_date** (Date): Enter the date the request was updated.
* **submitted_for** (Text): Enter the name of the person who submitted the request for.
* **assigned_to** (Text): Enter the name of the person assigned to the request.
* **extension_comment** (Note): Add any additional comments or notes about the extension request.
* **extension_id** (Number): Enter the unique ID of the extension request.
* **extension_name** (Text): Enter the name of the extension request.

## Tips
- Double-check your entries for accuracy before submitting the form.
- Make sure you're not duplicating an existing request.
- Keep your requests clear and concise for easier tracking and management.
