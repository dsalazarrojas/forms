# Custom Order Refund Form - Help Guide
## Purpose
The Custom Order Refund Form is a tool used to process refund requests for custom orders. This form allows authorized personnel to efficiently manage customer refunds by providing a structured way to track and resolve refund requests.

## How To Complete This Form
To complete this form, please follow these steps:

1. Enter the relevant Order ID to identify the order for which you are requesting a refund.
2. Provide a clear and concise Reason for Refund to explain the reason behind the refund request.
3. Enter the Refund Amount and Customer Refund Amount, if applicable.
4. If necessary, update the Order Total to reflect any changes made during the refund process.
5. Select the current Refund Status from the dropdown list.
6. Add any relevant Comments to the refund request.
7. Once all fields are filled out, click the "Submit" button to complete the form.

## Field-by-Field Explanation
### 1. **Order ID** (1) 
	* Label: Order ID
	* Type: Number
	* Required: No
	* Purpose: Enter the order ID to identify the order for which you are requesting a refund.
### 2. **Reason for Refund** (3) 
	* Label: Reason for Refund
	* Type: Text
	* Required: No
	* Purpose: Provide a clear and concise explanation for the reason behind the refund request.
### 3. **Refund Amount** (4) 
	* Label: Refund Amount
	* Type: Number
	* Required: No
	* Purpose: Enter the amount to be refunded to the customer.
### 4. **Customer Refund Amount** (5) 
	* Label: Customer Refund Amount
	* Type: Text
	* Required: No
	* Purpose: Enter the customer's refund amount if it differs from the original refund amount.
### 5. **Order Total** (6) 
	* Label: Order Total
	* Type: Number
	* Required: No
	* Purpose: Update the order total if necessary.
### 6. **Refund Status** (7) 
	* Label: Refund Status
	* Type: Select One
	* Required: No
	* Purpose: Select the current refund status from the list provided.
### 7. **Comments** (8) 
	* Label: Comments
	* Type: Text
	* Required: No
	* Purpose: Add any additional comments related to the refund request.

## Tips
* Make sure to fill out all relevant fields to ensure accurate and efficient processing of the refund request.
* Review the form before submitting to ensure all fields are accurate and complete.
* If you are unsure about any field or have further questions, please contact your supervisor or relevant personnel for assistance.
