# vickie_color_street_nails_in_my_stock - Help Guide
## Purpose
The form "vickie_color_street_nails_in_my_stock" is used to create and manage stock and customer order details for color street nails. This form is part of the order process and is required for accurate order processing.

## How To Complete This Form
To complete the form, follow these steps:

1. Fill out the order_form field with the relevant information.
2. List the stock items in the stock_list field.
3. Enter the stock quantity in the stock_quantity field.
4. Select the desired colors from the color_list field.
5. Enter the customer order ID in the customer_order_id field.

## Field-by-Field Explanation
* **Order Form** (`order_form`, text, required/optional): Enter the order details in this field.
* **Stock List** (`stock_list`, text, required/optional): List the stock items, separating each item with a comma.
* **Stock Quantity** (`stock_quantity`, number, required/optional): Enter the quantity of the stock item.
* **Color List** (`color_list`, select multiple, required/optional): Select the desired colors for the stock item.
* **Customer Order ID** (`customer_order_id`, text, required/optional): Enter the customer's order ID to associate it with the stock order.
