# Goods Receiving Form - Help Guide
## Purpose
This form is used to record information about goods delivered to a warehouse. It helps in maintaining accurate records and tracking received items.

## How To Complete This Form
To complete this form, follow these steps:
1. Enter the **Date** of delivery (Page 1, delivery_date).
2. Enter the **Item Name** and other relevant details (Page 1, delivery_item).
3. Select the **Received By** (Page 1, received_by).
4. Select the **Warehouse Name** (Page 1, warehouse_name).
5. Enter the **Quantity** and **Weight** of the delivered item (Page 1, item_quantity, item_weight).
6. Choose the **Status** of the item, such as **Received**, **Damaged**, or **Lost** (Page 1, item_status).
7. Optionally, enter any additional **Note** about the delivery (Page 1, item_note).
8. If there were any discrepancies during the delivery, enter the **Item** affected and the **Reason** for the discrepancy, as well as any **Note** about it (Page 1, discrepancy_item, discrepancy_reason, discrepancy_note).

## Field-by-Field Explanation
- **Date** (delivery_date): Enter the date the goods were delivered.
- **Item Name** (delivery_item): Enter the name and description of the item delivered.
- **Received By** (received_by): Select the person receiving the goods.
- **Warehouse Name** (warehouse_name): Select the warehouse receiving the goods.
- **Quantity** (item_quantity): Enter the number of items delivered.
- **Weight** (item_weight): Enter the weight of the delivered item.
- **Status** (item_status): Choose how the item was received (Received, Damaged, or Lost).
- **Note** (item_note): Add any additional comments or information about the delivery.
- **Item** (discrepancy_item): If there were any issues with the delivery, enter the item affected.
- **Reason** (discrepancy_reason): Enter a brief explanation for the discrepancy.
- **Note** (discrepancy_note): Add any additional comments about the discrepancy.
- **Status** (discrepancy_status): Mark the discrepancy as **Flagged**, **Resolved**, or **In Progress**.
