# Hotel New Property Order Request Form - Help Guide
## Purpose
This form is used for submitting new property requests to hotel management. It allows users to provide detailed information about the new property, including vendor, internal stakeholder, project needs, and other relevant details.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the vendor from the drop-down menu that best describes the company or person requesting the new property.
2. Choose the internal stakeholder who will be responsible for managing the project.
3. Indicate the project needs and requirements for the new property.
4. Choose the type of property that is being requested.
5. Provide a brief description of the new property.
6. Select the status of the property (active, inactive, or pending).
7. Enter the location of the property.
8. Indicate the status of the project.
9. Select the submission date and time.
10. Enter the name of the person assigned to manage the project.
11. Add any comments or notes about the request.
12. Enter the email and phone number of the person requesting the property.

## Field-by-Field Explanation

* **New Property Request** (`new_property_request`, text, optional): This field is where you can enter a brief description of the new property request.
* **Vendor** (`vendor`, select_multiple, optional): Choose the vendor that is requesting the new property. This can be one or multiple vendors.
* **Internal Stakeholder** (`internal_stakeholder`, select_one, optional): Select the internal stakeholder who will be responsible for managing the project.
* **Project Needs** (`project_needs`, text, optional): Enter the project needs and requirements for the new property.
* **Requested By** (`requested_by`, select_one, optional): Choose the team that is requesting the new property.
* **Property Type** (`property_type`, select_one, optional): Select the type of property that is being requested.
* **Property Description** (`property_description`, text, optional): Provide a brief description of the new property.
* **Property Status** (`property_status`, select_one, optional): Select the status of the property (active, inactive, or pending).
* **Property Location** (`property_location`, text, optional): Enter the location of the new property.
* **Project Status** (`project_status`, select_one, optional): Indicate the status of the project (active, inactive, or pending).
* **Submission Date** (`submission_date`, date, optional): Enter the date of submission for the new property request.
* **Submission Time** (`submission_time`, time, optional): Enter the time of submission for the new property request.
* **Assigned To** (`assigned_to`, text, optional): Enter the name of the person assigned to manage the project.
* **Comments** (`comments`, note, optional): Add any comments or notes about the request.
* **Email** (`email`, email, optional): Enter the email of the person requesting the new property.
* **Phone** (`phone`, text, optional): Enter the phone number of the person requesting the new property.

**Tips**

* Please ensure that all fields are filled out accurately and completely.
* If you are unsure about any field, please ask the relevant department or team for clarification.
* If you need to submit multiple properties, please submit multiple forms.
