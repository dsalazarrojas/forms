# Anti Theft Tag Supply Order Form - Help Guide

## Purpose
The Anti Theft Tag Supply Order Form is a form used to request anti-theft tags for inventory security. This form is used to collect information about the order, including the requester's name, department, tag type, quantity required, shipping address, and other relevant details. This form is designed to ensure that the correct type and quantity of tags are ordered for inventory security.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the requester's name in the "Requester name" field.
2. Select the department or store location from the "Department" field.
3. Choose the type of tag from the "Tag type" dropdown menu.
4. Enter the quantity of tags required in the "Quantity required" field.
5. Provide the full shipping address for delivery in the "Shipping address" field.
6. If applicable, enter the purchase order number for billing purposes.

## Field-by-Field Explanation
- **Requester name** (`requester`, `text`, required): Enter the name of the person placing the order.
- **Department** (`department`, `text`, optional): Enter the department or store location that the tags are for.
- **Tag type** (`tag_type`, `select_one`, required): Select the type of tag from the dropdown menu, such as Standard, High security, or RFID.
- **Quantity required** (`quantity`, `number`, required): Enter the number of tags needed.
- **Shipping address** (`shipping_address`, `text`, required): Enter the full shipping address where the tags should be delivered.
- **Purchase order number** (`purchase_order`, `text`, optional): Enter the purchase order number for billing purposes.
- **Required by date** (`required_by_date`, `date`, optional): If applicable, select the date by which the order should arrive.
