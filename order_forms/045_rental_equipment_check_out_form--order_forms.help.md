# rental_equipment_check_out_form - Help Guide
## Purpose
The rental equipment check-out form is used to collect information about the customer and equipment being rented for tracking purposes.

## How To Complete This Form

1.  Enter the customer's name in the "Customer name" field.
2.  Select the start and end dates of the rental using the "Rental start date" and "Rental end date" fields.
3.  Enter the ID of the rented equipment in the "Rental equipment ID" field.
4.  Enter the customer's contact information in the "Customer email" and "Customer phone" fields.
5.  Optionally, update the "Rental agreement status" field, even though it is not being used for its intended purpose.
6.  Enter any additional comments or information in the "Notes" field.

## Field-by-Field Explanation

*   **Customer name (Customer name, text, required: false):** 
    Enter the customer's name as they would like it to be displayed.
*   **Rental start date (Rental start date, date, required: false):** 
    Select the date the rental is to start.
*   **Rental end date (Rental end date, date, required: false):** 
    Select the date the rental is to end.
*   **Rental equipment ID (Rental equipment_id, text, required: false):** 
    Enter the ID of the equipment being rented.
*   **Customer email (Customer email, email, required: false):** 
    Enter the customer's email address.
*   **Customer phone (Customer phone, text, required: false):** 
    Enter the customer's phone number.
*   **Rental agreement status (Rental agreement_status, select_one, required: false):** 
    Select the status of the rental agreement (Active, Pending, Inactive).
*   **Notes (Notes, note, required: false):** 
    Enter any additional comments or information.
