# e_commerce_seo_change_request_form - Help Guide
## Purpose
This form is used to request changes to e-commerce SEO settings, such as titles, descriptions, keywords, and other metadata.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in your User Name, Email, and Phone number if you have any.
2. Provide a clear and concise Description of the changes you need to make to your e-commerce site's SEO settings.
3. Enter the URL of the affected page or section.
4. Select the Category of the change you need to make (e.g. "Title", "Description", "Keywords", etc.).
5. Choose the Priority level of the change (e.g. "Low", "Medium", "High").
6. Select the Date and Time you want the change to be processed.
7. Choose the Status of the change (e.g. "Open", "In Progress", "Done").
8. Enter the name of the tool assigned to process the change.
9. If applicable, attach the Output File related to the change.

## Field-by-Field Explanation
* **User Name** (`user_name`, text, optional): Your name and contact information to be used for communication purposes.
* **Email** (`email`, email, optional): Your email address to be used for further communication and updates.
* **Phone** (`phone`, text, optional): Your phone number to be used for further communication and updates.
* **Description** (`description`, text, optional): A detailed description of the changes you need to make to your e-commerce site's SEO settings.
* **URL** (`url`, text, optional): The URL of the affected page or section.
* **Category** (`category`, select_one, optional): Select the category of the change you need to make (e.g. "Title", "Description", "Keywords", etc.).
* **Priority** (`priority`, select_multiple, optional): Choose the priority level of the change (e.g. "Low", "Medium", "High").
* **Date** (`date`, date, optional): The date you want the change to be processed.
* **Time** (`time`, time, optional): The time you want the change to be processed.
* **Status** (`status`, select_one, optional): Choose the status of the change (e.g. "Open", "In Progress", "Done").
* **Assigned Tool** (`assigned_tool`, text, optional): The name of the tool assigned to process the change.
* **Output File** (`output_file`, text, optional): If applicable, attach the Output File related to the change.

## Tips
* Please make sure to fill out all required fields accurately and completely.
* Use clear and concise language when describing the changes you need to make.
* Use relevant category and priority levels to ensure that your change is processed efficiently.
* If you have any questions or need further assistance, please contact the e_commerce team directly.
