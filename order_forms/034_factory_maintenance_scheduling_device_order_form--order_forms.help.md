# Factory Maintenance Scheduling Device Order Form - Help Guide
## Purpose
The Factory Maintenance Scheduling Device Order Form is designed to help you plan and schedule maintenance activities for devices in your factory efficiently.

## How To Complete This Form

To complete this form, please follow these steps:

1.  Enter the factory name and contact name.
2.  Optionally, add your contact email and phone number for better communication.
3.  Specify the start and end dates for the maintenance schedule.
4.  Choose the equipment type and add a brief description, which are required fields.
5.  Select whether you want to schedule maintenance (Yes or No) and choose the specific days of the week if scheduling is chosen.
6.  Set the schedule time for the maintenance activity.
7.  Add any maintenance notes, if necessary.

## Field-by-Field Explanation
### Factory Name (Factory Name)
*   **Factory Name**: Enter the name of the factory where the maintenance activity will take place.
*   This field is required.
*   Please ensure that it's accurate and up to date.

### Contact Name (Contact Name)
*   **Contact Name**: Enter the name of the person or team responsible for the maintenance activity.
*   This field is required.
*   Please ensure it's accurate and up to date.

### Contact Email (Contact Email)
*   **Contact Email**: Provide your email address for better communication with the maintenance team.
*   This field is optional.
*   Please ensure it's a valid email address.

### Contact Phone (Contact Phone)
*   **Contact Phone**: Enter your phone number for better communication with the maintenance team.
*   This field is optional.
*   Please ensure it's a valid phone number.

### Start Date (Start Date)
*   **Start Date**: Enter the start date for the maintenance schedule.
*   This field is required.
*   Please ensure it's a date in the format YYYY-MM-DD.

### End Date (End Date)
*   **End Date**: Enter the end date for the maintenance schedule.
*   This field is required.
*   Please ensure it's a date in the format YYYY-MM-DD.

### Equipment Type (Equipment Type)
*   **Equipment Type**: Select the type of equipment that requires maintenance.
*   This field is required.
*   Choose from the available options or type a custom type if not listed.

### Equipment Description (Equipment Description)
*   **Equipment Description**: Briefly describe the equipment that needs maintenance.
*   This field is required.
*   Please keep it concise and clear.

### Schedule Type (Schedule Type)
*   **Schedule Type**: Choose whether you want to schedule maintenance (Yes or No).
*   This field is required.
*   If you choose 'Yes', select the specific days of the week for the schedule.

### Schedule Day (Schedule Day)
*   **Schedule Day**: Select the specific days of the week for the maintenance schedule, if choosing 'Yes' for Schedule Type.
*   This field is optional.
*   Choose from the available options.

### Schedule Time (Schedule Time)
*   **Schedule Time**: Set the schedule time for the maintenance activity.
*   This field is required.
*   Please ensure it's in the format HH:MM.

### Maintenance Notes (Maintenance Notes)
*   **Maintenance Notes**: Add any additional information or notes about the maintenance activity.
*   This field is optional.
*   Please keep it brief and clear.
