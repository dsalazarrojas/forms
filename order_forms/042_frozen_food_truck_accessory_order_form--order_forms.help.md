# frozen_food_truck_accessory_order_form - Help Guide
## Purpose
This form is used to record orders for frozen food truck accessories. It captures essential details such as order total, assigned user, order date, and order status to ensure smooth processing and tracking of orders.

## How To Complete This Form

1. Fill in the **Order Total** (`order_total`) field with the total cost of the order.
2. Select the **Assigned User** (`assigned_user`) field from the dropdown list to assign the order to a specific user (chatjimmy or jenny).
3. Enter the **Order Date** (`order_date`) field with the date the order was received.
4. Select the **Order Status** (`order_status`) field from the dropdown list to indicate whether the order is pending or completed.
5. Optionally, add any additional **Order Notes** (`order_notes`) or **Comments** (`order_comments`) for the order.
6. Submit the form to generate a new order.

## Field-by-Field Explanation
* **Order Total** (`order_total`): Enter the total cost of the order.
* **Customer Info** (`customer_info`): Enter any relevant customer information, such as name, phone number, or email.
* **Order Items** (`order_items`): Enter a list of items ordered, separated by commas or newline characters.
* **Order Notes** (`order_notes`): Enter any notes or comments for the order, such as special instructions or requests.
* **Order Date** (`order_date`): Enter the date the order was received in the format mm/dd/yyyy.
* **Assigned User** (`assigned_user`): Select the user assigned to process this order.
* **Order Status** (`order_status`): Select whether the order is pending or completed.
* **Comments** (`order_comments`): Enter any additional comments or notes for the order.

## Tips
* Please double-check the order total to ensure accuracy.
* Verify that the assigned user is selected correctly.
* Update the order status regularly to reflect the order's current status.
* Keep order notes and comments concise but informative for reference.
