# Production Information Collection Form - Help Guide
## Purpose

The Production Information Collection Form is used to gather detailed information about a production process. This form helps in collecting data about the production details such as project name, production date and time, production location, status, and other relevant information.

## How To Complete This Form

1. Fill out the form as per the provided guidelines.
2. Ensure that the required fields are filled in completely.
3. Double-check the information provided before submitting the form.

## Field-by-Field Explanation

* **Project Name** (`project_name`, text, optional): Enter the name of the production project.
* **Production Date** (`production_date`, date, optional): Enter the date of the production.
* **Production Time** (`production_time`, time, optional): Enter the time of the production.
* **Production Location** (`production_location`, text, optional): Enter the location of the production.
* **Production Status** (`production_status`, select multiple, optional): Select all the relevant statuses of the production (In Progress, Completed, Canceled).
* **Production Notes** (`production_notes`, note, optional): Add any additional notes about the production.
* **Project Manager Name** (`project_manager_name`, text, optional): Enter the name of the project manager.
* **Production Manager Name** (`production_manager_name`, text, optional): Enter the name of the production manager.
* **Production Contact** (`production_contact`, text, optional): Enter the contact name of the production team.
* **Production Email** (`production_email`, email, optional): Enter the email id of the production team.
* **Production Phone** (`production_phone`, text, optional): Enter the phone number of the production team.
* **Production Fax** (`production_fax`, text, optional): Enter the fax number of the production team.
* **Production Address** (`production_address`, text, optional): Enter the address of the production team.
* **Production City** (`production_city`, text, optional): Enter the city of the production location.
* **Production State** (`production_state`, text, optional): Enter the state of the production location.
* **Production Zip** (`production_zip`, text, optional): Enter the zip code of the production location.
* **Production Country** (`production_country`, text, optional): Enter the country of the production location.
* **Production URL** (`production_url`, text, optional): Enter the URL of the production team.
* **Production Comments** (`production_comments`, note, optional): Add any additional comments about the production.
* **Production Image** (`production_image`, text, optional): Enter any image related to the production.
* **Production Video** (`production_video`, text, optional): Enter any video related to the production.
* **Production Audio** (`production_audio`, text, optional): Enter any audio related to the production.
* **Production Document** (`production_document`, text, optional): Enter any document related to the production.
* **Production Attachment** (`production_attachment`, text, optional): Attach any documents or images to the production.
* **Comments** (`production_comments`, note, optional): Add any additional comments about the production.

## Tips

- Make sure to double-check all the fields before submitting the form to avoid any errors.
- Use clear and correct formats for dates, times, and other fields to avoid any issues.
- If any field is missing, please fill it in as per the provided guidelines.
