# Order Information Collection Form - Help Guide
## Purpose
This form is designed to collect order information from customers, such as customer details and order details. The collected data will be used for sales purposes.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the required information in the fields provided.
2. Make sure to fill out all the fields, including those marked as required (Customer Info, Customer Info 2, Customer Info 3, Order Details 3).
3. If a field is not required, you can leave it blank.

## Field-by-Field Explanation
- **Customer Info** (`customer_info`, `text`, required/optional): Enter your customer information, such as name, contact number, and address.
- **Customer Info 2** (`customer_info_2`, `text`, required/optional): Enter any additional customer information.
- **Order Details** (`order_details`, `text`, required/optional): Enter order details such as order number, date, and total amount.
- **Order Details 2** (`order_details_2`, `text`, required/optional): Enter any additional order details.
- **Customer Info 3** (`customer_info_3`, `text`, required/optional): Enter more customer information.
- **Order Details 3** (`order_details_3`, `text`, required/optional): Enter further order details.
- **Customer Info 4** (`customer_info_4`, `text`, required/optional): Enter more customer information.
- **Order Details 4** (`order_details_4`, `text`, required/optional): Enter any final order details.

## Tips
- Please make sure to fill out all required fields.
- If you have any issues or concerns, contact [form@gic.mx](mailto:form@gic.mx).
