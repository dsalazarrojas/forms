# Ice Cream Order Form - Help Guide

## Purpose
This form is used to collect information from customers for ice cream orders. It is meant to capture details about the customer, order, and payment method. Please fill out this form to submit your order.

## How To Complete This Form
To complete this form, simply follow the instructions on each page. You will be asked to provide your customer information, order details, and payment method. Please make sure to fill out all required fields and submit your order.

## Field-by-Field Explanation
* **Customer Info (1)**:
  * A text field to input customer information (e.g., name, address).
  * Required: false
* **Order Details (2)**:
  * A text field to input order details (e.g., flavor, quantity).
  * Required: false
* **Payment Method (3)**:
  * A select multiple field to choose one or more payment methods (e.g., credit card, cash, PayPal).
  * Options: credit card, cash, PayPal
  * Required: false
* **Order Date (4)**:
  * A date field to input the order date.
  * Required: false
* **Customer Notes (5)**:
  * A note field to input any additional customer notes.
  * Required: false
* **Order Status (6)**:
  * A select one field to choose the order status (e.g., Pending, Shipped, Cancelled).
  * Options: Pending, Shipped, Cancelled
  * Required: false
* **Customer Email (7)**:
  * An email field to input the customer's email address.
  * Required: false
* **Customer Phone (8)**:
  * A text field to input the customer's phone number.
  * Required: false
* **Customer Address (9)**:
  * A text field to input the customer's address.
  * Hint: Enter a valid address
  * Required: false
* **Order Id (10)**:
  * A number field to input the order ID.
  * Required: false
* **Store Id (11)**:
  * A number field to input the store ID.
  * Required: false
* **Customer Type (12)**:
  * A select one field to choose the customer type (e.g., New, Returning, Regular).
  * Options: New, Returning, Regular
  * Required: false
* **Order Comments (13)**:
  * A note field to input any additional order comments.
  * Required: false
* **Order Total (14)**:
  * A number field to input the order total.
  * Required: false

## Tips
Please make sure to fill out all required fields and submit your order correctly. If you have any questions or concerns, please contact us.
