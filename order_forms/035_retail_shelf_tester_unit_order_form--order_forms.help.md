# Retail Shelf Tester Unit Order Form - Help Guide
## Purpose
The Retail Shelf Tester Unit Order Form is a form designed to collect information about a unit of a product for testing purposes.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the product code of the unit you are testing from the available options.
2. Enter the unit quantity of the unit you are testing.
3. Enter the tester unit price of the unit you are testing.
4. Enter the tester unit name of the unit you are testing.
5. Select the price per unit of the unit you are testing.
6. Select the tester unit weight of the unit you are testing.
7. Select the length of the unit you are testing.
8. Select the width of the unit you are testing.
9. Select the height of the unit you are testing.
10. Select the type of unit you are testing.
11. Select the brand of the unit you are testing.
12. Select the size of the unit you are testing.
13. Select the color of the unit you are testing.
14. Enter the tester unit description of the unit you are testing.
15. Select the image of the unit you are testing.
16. Select the video of the unit you are testing.
17. Select the document of the unit you are testing.
18. Add any notes or comments about the unit you are testing.
19. Enter the unit email of the unit you are testing.
20. Enter the tester unit phone number of the unit you are testing.
21. Enter the unit address of the unit you are testing.
22. Enter the date and time of the order for the unit you are testing.

## Field-by-Field Explanation

* **Product Code**: Select the product code of the unit you are testing.
* **Unit Quantity**: Enter the quantity of the unit you are testing.
* **Tester Unit Price**: Enter the price of the unit you are testing.
* **Tester Unit Name**: Enter the name of the unit you are testing.
* **Price per Unit**: Select the price per unit of the unit you are testing.
* **Tester Unit Weight**: Select the weight of the unit you are testing.
* **Tester Unit Length**: Select the length of the unit you are testing.
* **Tester Unit Width**: Select the width of the unit you are testing.
* **Tester Unit Height**: Select the height of the unit you are testing.
* **Tester Unit Type**: Select the type of unit you are testing.
* **Tester Unit Brand**: Select the brand of the unit you are testing.
* **Tester Unit Size**: Select the size of the unit you are testing.
* **Tester Unit Color**: Select the color of the unit you are testing.
* **Tester Unit Description**: Enter a brief description of the unit you are testing.
* **Tester Unit Image**: Select the image of the unit you are testing.
* **Tester Unit Video**: Select a video of the unit you are testing.
* **Tester Unit Document**: Select the document of the unit you are testing.
* **Tester Unit Note**: Add any notes or comments about the unit you are testing.
* **Unit Email**: Enter the email of the unit you are testing.
* **Tester Unit Phone**: Enter the phone number of the unit you are testing.
* **Unit Address**: Enter the address of the unit you are testing.
* **Tester Unit Order Date**: Enter the date of the order for the unit you are testing.
* **Tester Unit Order Time**: Enter the time of the order for the unit you are testing.
* **Unit Comments**: Add any additional comments about the unit you are testing.
