# Signage Detail Collection Form - Help Guide
## Purpose
The purpose of this form is to collect detailed information about signage projects from project stakeholders, improving project management and collaboration among team members.

## How To Complete This Form

To complete this form, please follow these steps:

1. Fill out the project details page with the necessary information about the project.
2. Move on to the design assets page and provide any relevant design assets for the project.
3. On the approvals page, indicate whether the project has received approvals or not.
4. Finally, add any additional comments about the project on the additional comments page.

## Field-by-Field Explanation

* **Project Details** (project_details): This field is used to enter a brief description of the project.
* **Design Assets** (design_assets): This field is used to provide any relevant design assets, such as images or documents, for the project.
* **Approvals** (approvals): This field is used to indicate whether the project has received approvals or not.
	+ Choose 'Yes' if the project has received all necessary approvals.
	+ Choose 'No' if the project has not received all necessary approvals.
* **Additional Comments** (additional_comments): This field is used to add any additional comments or information about the project.
* **Sign Type** (sign_type): This field is used to select the type of signage for the project.
	+ Choose 'Yes' for signage projects that require design assets.
	+ Choose 'No' for signage projects that do not require design assets.
* **Project Status** (project_status): This field is used to select the status of the project.
	+ Choose 'Active' for projects that are currently active and ongoing.
	+ Choose 'Inactive' for projects that are completed or put on hold.
* **Production Type** (production_type): This field is used to select the type of production for the project.
	+ Choose 'Yes' for production projects that require physical assets.
	+ Choose 'No' for production projects that do not require physical assets.
* **Production Status** (production_status): This field is used to select the status of the production.
	+ Choose 'Active' for projects that are currently in production.
	+ Choose 'Inactive' for projects that are completed or put on hold.
* **Delivery Date** (delivery_date): This field is used to enter the expected delivery date of the project.
* **Production Date** (production_date): This field is used to enter the production date of the project.
