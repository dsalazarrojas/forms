## Retail Store Signage Requisition Form - Help Guide

## Purpose
This form is used to request retail signage for a store location. The form is a centralized process to ensure that signage requests are properly tracked and communicated to the production and installation teams. Before proceeding, please ensure that you have a valid reason for the request and that it's not a duplicate. If you're unsure, please check with the relevant team members or your supervisor.

## How To Complete This Form

To complete this form, follow the instructions below:

1. Fill in the required information in the form, including the store number, location, and assigned to fields.
2. Select the correct region and category for the store.
3. Indicate the urgency of the signage request (high/medium/low).
4. Provide any additional comments or notes if necessary.
5. Fill in the production and installation dates if available.

## Field-by-Field Explanation

### Store Number (<number, number, required>)
Enter the store's unique numerical identifier.

### Region (<select_one, optional>)
Select the region where the store is located.

* Example: Store 1 is located in the New York Region.

### Location (<text, required>)
Enter the store location, including city and state.

* Example: New York City, NY 10001

### Category (<select_multiple, optional>)
Select the category of signage required for the store.

* Example: Storefront Sign, Menu Board Sign, etc.

### Signage Type (<select_one, optional>)
Select the type of signage required (e.g., LED, Neon, etc.).

* Example: LED Sign

### Quantity (<number, required>)
Enter the quantity of signage required.

* Example: 1 for a single storefront sign and 2 for a double-sided menu board.

### Urgency (<select_one, optional>)
Select the level of urgency for the signage request (high, medium, low).

* Example: High for immediate installation, medium for priority, and low for standard.

### Comments (<note, optional>)
Enter any additional comments or notes for the production team.

* Example: Please ensure that the sign is installed by the end of the week.

### Assigned To (<text, required>)
Enter the name of the person assigned to oversee the signage production and installation.

* Example: John Doe, Production Manager.

### Production Date (<date, required>)
Enter the expected production date for the signage.

* Example: 2023-02-20

### Installation Date (<date, required>)
Enter the expected installation date for the signage.

* Example: 2023-02-21

### Status (<select_one, optional>)
Select the status of the signage request.

* Example: New, In Progress, Completed.

### Store Hours (<time, optional>)
Enter the store hours, if applicable.

* Example: 8am - 6pm

### Notes (<note, optional>)
Enter any additional comments or notes for the installation team.

* Example: Please ensure that the sign is installed near the entrance.

### Email (<email, optional>)
Enter the email address for the contact person.

* Example: johndoe@example.com

### Phone (<text, optional>)
Enter the phone number for the contact person.

* Example: 123-456-7890

### Production Team (<text, required>)
Enter the name of the production team member assigned to the signage project.

* Example: John Doe, Production Manager.

### Production Status (<select_one, optional>)
Select the status of the production process.

* Example: New, In Progress, Completed.

### Installation Status (<select_one, optional>)
Select the status of the installation process.

* Example: New, In Progress, Completed.

Note: The fields marked as required should be filled in for the form to be considered complete.
