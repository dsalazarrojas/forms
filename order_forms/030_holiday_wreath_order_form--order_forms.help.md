# holiday_wreath_order_form - Help Guide
## Purpose
This form is intended for customers to provide information about their holiday wreath orders. It helps the staff to process the orders accurately and efficiently.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the form details (if provided).
2. Enter your name in the "Customer Name" field.
3. Select a date for the order in the "Order Date" field.
4. If you have any special requests, type them in the "Special Requests" field.
5. Enter your email address in the "Customer Email" field.

## Field-by-Field Explanation
* **Form Details (text)** (`form_details`, required: false, id: 1): This is a text box for any additional information about your order.
* **Customer Name (text)** (`customer_name`, required: false, id: 2): Please enter your name as it should be written on the wreath.
* **Order Date (date)** (`order_date`, required: false, id: 3): Select the date you would like to have the wreath delivered or ready for pickup.
* **Special Requests (text)** (`special_requests`, required: false, id: 4): If you have any special requests for the wreath (e.g. "Please do not use red ribbon"), type them here.
* **Customer Email (email)** (`customer_email`, required: false, id: 5): Enter the email address where you would like to receive updates about your order.

## Tips
* Make sure to enter your correct email address so that we can send you updates about your order.
* If you have any special requests, please be as specific as possible so that we can fulfill your needs accurately.
