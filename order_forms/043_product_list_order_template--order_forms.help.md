# Product List Order Template - Help Guide
## Purpose
The "Product List Order Template" form is a simple, multi-page form used to create a list of products for an order. This form is typically used by sales and customer service teams to collect information about products, making it easier to process orders accurately and efficiently.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the `Order Template` field on page 1 to provide a brief description of the order.
2. Enter the `Product Price` of each product on page 2.
3. Enter the `Quantity` of each product on page 2.
4. Calculate the `Total Price` of each product by multiplying the `Product Price` and `Quantity` on page 3.
5. Enter the `Product Name` of each product on page 4.

## Field-by-Field Explanation

* **Order Template** (`order_template`, text, required): A brief description of the order. This field is used to provide context for the products listed.
* **Product Price** (`product_price`, number, optional): The price of the product. This field should be filled in if applicable.
* **Quantity** (`quantity`, number, optional): The quantity of the product being ordered. This field should be filled in if applicable.
* **Total Price** (`total_price`, number, optional): The total price of the order. This field will automatically calculate if `Product Price` and `Quantity` are filled in.
* **Product Name** (`product_name`, text, optional): The name of the product being ordered. This field is used to identify the product.

## Tips
- Make sure to fill in all required fields for accurate order processing.
- Double-check the `Total Price` field to ensure it is correct.
- If you are unsure about any field, consult relevant documentation or seek assistance from a colleague.
