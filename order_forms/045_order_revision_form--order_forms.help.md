# Order Revision Form - Help Guide
## Purpose
The Order Revision Form is a tool designed to facilitate the revision or cancellation of orders on our website. It ensures accurate and clear communication between customers and staff, promoting efficient resolution of order-related issues.

## How To Complete This Form
To complete the Order Revision Form, follow these steps:

1.  Review the form carefully and understand the fields required for your specific situation.
2.  Fill in the relevant fields with accurate and clear information.
3.  If the order has been canceled, select the correct reason from the dropdown options.
4.  If other reasons apply, type the reason in the text field "Reason for Revising (other)".
5.  Ensure all required fields are filled in, as indicated by the red asterisk \*\*.

## Field-by-Field Explanation

* **Revisions Date** (`revision_date`, Date): Date of the order revision.
* **Reason For Revising** (`reason`, Select one): Select the reason for revising the order. Options include:
	+ Cancellation
	+ Revision Request
	+ Other
* **If other, please specify** (`reason_other`, Text): If you selected "Other", please provide the specific reason for revising the order.
* **Customer Comment** (`customer_comment`, Text): Add a note about this order revision.
* **Product Info** (`product_info`, Text): Provide product information related to this order revision.
* **Is order cancelled** (`order_cancelled`, Select one): If the order has been cancelled, select "True".
* **Cancel Reason** (`cancelled_reason`, Text): If the order has been cancelled, provide the reason for cancellation.
* **Customer Info** (`customer_info`, Text): Enter customer name, phone number and email.
* **Customer Email** (`customer_email`, Email): Enter customer email.
* **Customer Name** (`customer_name`, Text): Enter customer name.
* **Customer Phone** (`customer_phone`, Text): Enter customer phone number.
* **Order Number** (`order_number`, Text): Enter order number on the website.
* **Store Name** (`store_name`, Text): Enter store name.
* **Store Email** (`store_email`, Email): Enter store email.
* **Store Phone** (`store_phone`, Text): Enter store phone number.

Note: This guide only covers the provided fields. Additional fields may be present based on the form's configuration. Always follow the provided instructions for each field's label and hint for the best results. 

**Tips:**
- Double-check your information for accuracy before submitting.
- Ensure you have filled in all required fields, as indicated by the red asterisk \*\*.
- If you are unsure about any field or process, consult with staff or review the form guidelines for clarification.
