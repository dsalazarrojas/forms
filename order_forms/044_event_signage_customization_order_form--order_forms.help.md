# Event Signage Customization Order Form - Help Guide
## Purpose
This form is designed to collect information for event signage customization orders. Fill out this form to provide details about your event and specify your preferences for the signage design.

## How To Complete This Form
1. Fill in the event name in the "Event Name" field.
2. Select the type of event (e.g. Conference, Trade Show, Wedding, Seminar) from the "Event Type" dropdown menu.
3. Enter the event location in the "Location" field.
4. Enter the event date in the "Date" field (format: MM/DD/YYYY).
5. Select the event time from the "Time" field (format: HH:MM AM/PM).
6. Provide a brief description of the event in the "Description" field.
7. On the next page, select the type of signage you would like (Standard or Custom).
8. Choose the desired signage shape (Rectangle, Oval, Rounded Rectangle).
9. Select the color scheme (Color 1, Color 2, Color 3) that you prefer.
10. Choose the font size (Size 1, Size 2, Size 3) for the signage.
11. Select the font color (Color 1, Color 2, Color 3) for the signage text.
12. Choose the font style (Font 1, Font 2, Font 3) for the signage text.
13. On the last page, confirm whether you want to include any additional custom design elements for your event.

## Field-by-Field Explanation

* **Event Name**: Enter the name of your event in this field.
* **Event Type**: Select the type of event from the dropdown menu (Conference, Trade Show, Wedding, Seminar).
* **Location**: Enter the location of your event in this field.
* **Date**: Enter the date of your event in the format MM/DD/YYYY.
* **Time**: Select the time of your event from the dropdown menu (HH:MM AM/PM).
* **Description**: Provide a brief description of your event in this field.
* **Type of Signage**: Select whether you want Standard or Custom signage.
* **Signage Shape**: Choose the shape of your event signage (Rectangle, Oval, Rounded Rectangle).
* **Color Scheme**: Select the color scheme for your event signage (Color 1, Color 2, Color 3).
* **Font Size**: Choose the font size for your event signage (Size 1, Size 2, Size 3).
* **Font Color**: Select the font color for your event signage (Color 1, Color 2, Color 3).
* **Font Style**: Choose the font style for your event signage (Font 1, Font 2, Font 3).
* **Additional Custom Design Elements**: Confirm whether you want to include any additional custom design elements for your event.

## Tips
* Make sure to enter the correct date and time for your event.
* Select the correct type of event and signage shape to match your event's unique needs.
* If you have any specific design requirements, please provide more details in the "Description" field.
* If you want to include custom design elements, please provide clear instructions on what you want to include.
* Please review all fields carefully before submitting the form to ensure accuracy.
