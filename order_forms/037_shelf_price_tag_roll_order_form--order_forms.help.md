# Shelf Price Tag Roll Order Form - Help Guide
## Purpose
This form is used to record orders for shelf price tags.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the order form at the top of the page.
2. Fill in the order details as prompted, including tag type, quantity, color, material type, size, shape, color type, font, font size, tag size, order date, and notes.
3. Enter customer information, including name, email, phone number, address, city, state, post code, and country.
4. Review the form for accuracy before submitting it.

## Field-by-Field Explanation

* **Order Form**: (`id: 1`, text, not required) This is the main section of the form where you enter the order details.
* **customer_info**: (`id: 2`, text, not required) This is where you enter the customer's name, but you can enter any relevant information about the customer.
* **Order Details**: (`id: 3`, text, not required) Enter any additional details about the order.
* **Tag Type**: (`id: 4`, select_one, not required) Select the type of tag you are ordering, e.g. "A1".
* **Quantity**: (`id: 5`, number, not required) Enter the quantity of tags you are ordering. Note that this form does not support partial quantities.
* **Color**: (`id: 6`, select_one, not required) Select the color of the tag you are ordering, e.g. "Red".
* **Material Type**: (`id: 7`, select_multiple, not required) Select the material type of the tag you are ordering, e.g. "Paper".
* **Size**: (`id: 8`, select_multiple, not required) Select the size of the tag you are ordering, e.g. "Small".
* **Shape**: (`id: 9`, select_multiple, not required) Select the shape of the tag you are ordering, e.g. "Round".
* **Color Type**: (`id: 10`, select_multiple, not required) Select the color type of the tag you are ordering, e.g. "Solid".
* **Material Color**: (`id: 11`, select_multiple, not required) Select the material color of the tag you are ordering, e.g. "Red".
* **Font**: (`id: 12`, select_multiple, not required) Select the font of the tag you are ordering, e.g. "Font 1".
* **Font Size**: (`id: 13`, number, not required) Enter the font size of the tag you are ordering.
* **Tag Size**: (`id: 14`, number, not required) Enter the size of the tag you are ordering.
* **Order Date**: (`id: 15`, date, not required) Enter the date of the order.
* **Notes**: (`id: 16`, note, not required) Enter any additional notes about the order.
* **Customer Name**: (`id: 17`, text, not required) Enter the name of the customer.
* **Customer Email**: (`id: 18`, email, not required) Enter the email address of the customer.
* **Customer Phone**: (`id: 19`, text, not required) Enter the phone number of the customer.
* **Customer Address**: (`id: 20`, text, not required) Enter the address of the customer.
* **Customer City**: (`id: 21`, text, not required) Enter the city of the customer.
* **Customer State**: (`id: 22`, text, not required) Enter the state of the customer.
* **Customer Postal Code**: (`id: 23`, text, not required) Enter the post code of the customer.
* **Customer Country**: (`id: 24`, text, not required) Enter the country of the customer.
