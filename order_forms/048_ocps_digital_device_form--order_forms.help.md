# OCPS Digital Device Form - Help Guide
## Purpose
This form is used to collect information about digital devices ordered, managed, and maintained within the institution.

## How To Complete This Form
1. Fill in the required fields with relevant information about the device.
2. Select the appropriate options for fields such as device type, status, and accessories as per the given options.
3. Provide a brief description of the reason for rejection, return, or other notes if necessary.
4. Ensure all fields are filled in correctly and accurately.

## Field-by-Field Explanation

* **Digital Device Form** (`1`, `text`, required): Enter a brief title or description of the device.
* **School** (`2`, `text`, optional): Enter the name of the school where the device is being ordered or managed.
* **Student** (`3`, `text`, optional): Enter the name of the student associated with the device.
* **Teacher** (`4`, `text`, optional): Enter the name of the teacher responsible for the device.
* **Grade Level** (`5`, `select_one`, optional): Select the grade level of the student using the device (9, 10, 11).
* **Order Date** (`6`, `date`, optional): Enter the date when the device was ordered.
* **Order Status** (`7`, `select_one`, optional): Select the current status of the order (New, Pending, Completed).
* **Reason for Rejection** (`8`, `text`, optional): Provide a brief description of the reason for rejection if applicable.
* **Remarks** (`9`, `note`, optional): Enter any additional comments or remarks about the device.
* **Device Type** (`10`, `select_one`, optional): Select the type of device (iPad, Laptop, Notebook).
* **Device Status** (`11`, `select_one`, optional): Select the status of the device (Available, Not Available, Lost, Missing, Stolen, Broken).
* **Student Signature** (`12`, `text`, optional): Enter the student's signature if applicable.
* **Teacher Signature** (`13`, `text`, optional): Enter the teacher's signature if applicable.
* **Comments** (`14`, `note`, optional): Enter any comments or remarks about the device.
* **School Signature** (`15`, `text`, optional): Enter the school's signature if applicable.
* **Device Serial Number** (`16`, `text`, optional): Enter the device's serial number if known.
* **School Code** (`17`, `text`, optional): Enter the school's code or identifier if applicable.
* **Order Number** (`18`, `text`, optional): Enter the order number for the device.
* **Student ID** (`19`, `text`, optional): Enter the student's ID if applicable.
* **Device Model** (`20`, `text`, optional): Enter the model of the device if known.
* **Reason for Return** (`21`, `select_multiple`, optional): Select all applicable reasons for return (Defective, Damaged, Stolen, Lost, Not needed).
* **Device Accessories** (`22`, `select_one`, optional): Select any accessories that come with the device (Case, Charger, Screen Protector, None).
* **Return Status** (`23`, `select_one`, optional): Select the status of the return (Not Returned, Returned, Partially Returned).
* **Device Condition** (`24`, `select_one`, optional): Select the condition of the device (Good, Fair, Poor).
* **Notes** (`25`, `note`, optional): Enter any additional notes or comments about the device.
