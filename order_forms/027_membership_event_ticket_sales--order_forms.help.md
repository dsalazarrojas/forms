# Membership Event Ticket Sales - Help Guide
## Purpose
This form is designed to capture information about membership event ticket sales, including event details, attendee information, payment method, and order status. The form is intended to be used by customers or staff members to process and confirm sales.

## How To Complete This Form
To complete this form, please follow these steps:

1. Provide event information, including any relevant details about the event.
2. Enter attendee information, as required for the sale.
3. Select the member status of the attendee.
4. Choose the payment method and select the tickets to be purchased.
5. Enter the payment information and amount in the selected currency.
6. Select the payment gateway to be used for the transaction.
7. Set the order status to Active or Inactive.

## Field-by-Field Explanation
* **Event Information (1)** (`event_information`, required/optional): Enter a brief description of the event, including any relevant details.
* **Attendee Information (2)** (`attendee_information`, required): Enter the name and contact information of the person purchasing the ticket.
* **Member Status (3)** (`member_status`, optional): Select the status of the attendee, which can be Active or Inactive.
* **Ticket Selections (4)** (`ticket_selections`, optional): Choose the type of ticket to be purchased, e.g., 'Yes' or 'No'.
* **Payment Method (5)** (`payment_method`, optional): Select the payment method to be used, e.g., 'Yes' or 'No'.
* **Payment Information (6)** (`payment_information`, required): Enter the payment method and any additional information about the payment.
* **Payment Amount (7)** (`payment_amount`, required): Enter the amount of the payment in the selected currency.
* **Payment Currency (8)** (`payment_currency`, optional): Select the currency of the payment, e.g., 'Yes' or 'No'.
* **Payment Gateway (9)** (`payment_gateway`, optional): Select the payment gateway to be used for the transaction, e.g., 'Yes' or 'No'.
* **Order Status (10)** (`order_status`, optional): Set the order status to Active or Inactive.

## Tips
* Ensure that all required fields are filled in accurately and completely.
* Review the form carefully before submitting it to avoid errors.
* If you're unsure about any field, please contact the relevant staff member for assistance.
