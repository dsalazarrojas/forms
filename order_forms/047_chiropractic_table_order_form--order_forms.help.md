# Chiropractic Table Order Form - Help Guide
## Purpose
The Chiropractic Table Order Form is designed to gather all necessary information to process and deliver chiropractic tables for clinics or individuals. Please refer to the form's internal reasoning block for a brief explanation.

## How To Complete This Form
To fill out this form accurately, follow these steps:
1. Fill in the Buyer Name field with the name of the person or clinic ordering the table(s).
2. Provide the Contact Email address that the order confirmation should be sent to.
3. Select the Table Model that suits your needs from the provided options.
4. Indicate the Number of tables you wish to order.
5. Enter the Shipping Address where the table(s) should be delivered.
6. If desired, specify a preferred Delivery Date, but note that this is optional as it's not required to complete the form.
7. Choose the Payment Method you prefer for the order (Credit Card, Invoice, or Bank Transfer).
8. Finally, indicate if professional Installation is required for the ordered table(s).

## Field-by-Field Explanation
* **Buyer Name (Required)**: The name of the person or clinic placing the order.
* **Contact Email (Required)**: The email address to receive order confirmation and updates.
* **Table Model (Required)**: Select the type of table needed, such as Standard Adjustment Table, Portable Folding Table, or Hydraulic Adjustment Table.
* **Quantity (Required)**: Enter the number of tables ordered.
* **Shipping Address (Required)**: The address where the table(s) should be delivered to.
* **Delivery Date Preference (Optional)**: If you have a specific date preference for the delivery, please enter it here. However, this field is optional and not required to complete the form.
* **Payment Method (Required)**: Choose between Credit Card, Invoice, or Bank Transfer as the preferred payment method.
* **Installation Required (Optional)**: Indicate if professional installation is necessary for the ordered table(s).
