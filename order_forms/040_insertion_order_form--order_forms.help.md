# Insertion Order Form - Help Guide
## Purpose
The Insertion Order Form is a tool used to collect information about an advertisement order, including customer details, ad placement, dates, and payment terms.

## How To Complete This Form
1. Click on the "Order Details" page to enter the title of the order.
2. On the "Customer Info" page, provide your contact information, including name, email, and phone number.
3. On the "Ad Media" page, select the ad media type.
4. On the "Ad Placement" page, select whether the ad will be placed on the "Yes" or "No" option.
5. On the "Date of Ad Delivery" page, select the date of ad delivery.
6. On the "Ad Cost" and "Ad Budget" pages, enter the ad cost and budget, respectively.
7. On the "Ad Status" page, select the status of the ad, which can be either "Active" or "Inactive".
8. On the "Ad Tags" page, select multiple tags for the ad.
9. On the "Payment Terms" page, enter any payment terms.
10. On the "Contact Person" page, enter the contact person's name.
11. On the "Contact E-mail" page, enter the contact email.
12. On the "Contact Phone" page, enter the contact phone number.
13. On the "Order Notes" page, enter any order notes.
14. On the "Ad Type" page, select whether the ad is a "Yes" or "No" option.
15. On the "Ad Size" page, select whether the ad size is a "Yes" or "No" option.
16. On the "Ad Orientation" page, select whether the ad orientation is a "Yes" or "No" option.
17. On the "Ad Color" page, select whether the ad color is a "Yes" or "No" option.
18. On the "Ad Orientation Unit" page, select whether the ad orientation unit is a "Yes" or "No" option.
19. On the "Ad Color Type" page, select whether the ad color type is a "Yes" or "No" option.
20. On the "Ad Color Scheme" page, select whether the ad color scheme is a "Yes" or "No" option.
21. On the "Ad Color Scheme Type" page, select whether the ad color scheme type is a "Yes" or "No" option.
22. On the "Ad Size Unit" page, select whether the ad size unit is a "Yes" or "No" option.
23. On the "Ad Size" page, select whether the ad size is a "Yes" or "No" option.

## Field-by-Field Explanation

* **Order Details (Page 1)** (`order_details`, text, optional): Enter the title of the order.
* **Customer Info (Page 2)** (`customer_info`, text, optional): Provide your contact information, including name, email, and phone number.
* **Ad Media (Page 3)** (`ad_media`, text, optional): Select the ad media type.
* **Ad Placement (Page 4)** (`ad_placement`, select_one, optional): Select whether the ad will be placed on the "Yes" or "No" option.
* **Date of Ad Delivery (Page 5)** (`date_of_ad_delivery`, date, optional): Select the date of ad delivery.
* **Ad Cost (Page 6)** (`ad_cost`, number, optional): Enter the ad cost.
* **Ad Budget (Page 7)** (`ad_budget`, number, optional): Enter the ad budget.
* **Ad Status (Page 8)** (`ad_status`, select_one, optional): Select the status of the ad, which can be either "Active" or "Inactive".
* **Ad Tags (Page 9)** (`ad_tags`, select_multiple, optional): Select multiple tags for the ad.
* **Payment Terms (Page 10)** (`payment_terms`, text, optional): Enter any payment terms.
* **Contact Person (Page 11)** (`contact_person`, text, optional): Enter the contact person's name.
* **Contact E-mail (Page 12)** (`contact_email`, email, optional): Enter the contact email.
* **Contact Phone (Page 13)** (`contact_phone`, text, optional): Enter the contact phone number.
* **Order Notes (Page 14)** (`order_notes`, note, optional): Enter any order notes.
* **Ad Type (Page 15)** (`ad_type`, select_one, optional): Select whether the ad is a "Yes" or "No" option.
* **Ad Size (Page 16)** (`ad_size`, select_one, optional): Select whether the ad size is a "Yes" or "No" option.
* **Ad Orientation (Page 17)** (`ad_orientation`, select_one, optional): Select whether the ad orientation is a "Yes" or "No" option.
* **Ad Color (Page 18)** (`ad_color`, select_one, optional): Select whether the ad color is a "Yes" or "No" option.
* **Ad Orientation Unit (Page 19)** (`ad_orientation_unit`, select_one, optional): Select whether the ad orientation unit is a "Yes" or "No" option.
* **Ad Color Type (Page 20)** (`ad_color_type`, select_one, optional): Select whether the ad color type is a "Yes" or "No" option.
* **Ad Color Scheme (Page 21)** (`ad_color_scheme`, select_one, optional): Select whether the ad color scheme is a "Yes" or "No" option.
* **Ad Color Scheme Type (Page 22)** (`ad_color_scheme_type`, select_one, optional): Select whether the ad color scheme type is a "Yes" or "No" option.
* **Ad Size Unit (Page 23)** (`ad_size_unit`, select_one, optional): Select whether the ad size unit is a "Yes" or "No" option.
* **Ad Size (Page 24)** (`ad_size`, select_one, optional): Select whether the ad size is a "Yes" or "No" option.
