# Main Course Selection Form - Help Guide

## Purpose

The Main Course Selection Form is a tool used to collect information related to a course or event. It helps users input their preferences and requirements for the course or event, enabling efficient planning and coordination.

## How To Complete This Form

To complete this form, follow these steps:

1. Select the main courses you are interested in for the event by choosing "Yes" or "No" for each option.
2. If you have additional courses to select, you can select "Yes" or "No" for each option.
3. Provide any additional information you would like to include about the event.
4. Enter your contact information, including your email address and phone number.
5. Specify the date and time of the event.
6. Choose the type of event you are planning.
7. Enter a brief description of the event.
8. If there are any special instructions, please include them here.
9. Finally, select the catering services you require for the event.

## Field-by-Field Explanation

* **Main Course Selection** (`main_course_selection_form`, select_one, Required/Optional): This field allows you to select "Yes" or "No" for the main courses you are interested in. Select "Yes" for courses you want to include in your event.
* **Main Course 1** (`main_course_selection_form_1`, select_one, Required/Optional): Similar to the Main Course Selection field, this is used to select "Yes" or "No" for the first main course.
* **Side Course Selection** (`side_course_selection_form`, select_multiple, Required/Optional): Here, you can select "Yes" or "No" for each side course you want to include in your event. Select "Yes" for each course you want to include.
* **Side Course 1** (`side_course_selection_form_1`, select_multiple, Required/Optional): Like Side Course Selection, this field is used to select "Yes" or "No" for the first side course.
* **Additional Info** (`additional_info`, note, Required/Optional): This field is for any extra information you would like to add about your event.
* **Email Address** (`email_address`, email, Required/Optional): Enter your email address here so that we can contact you.
* **Phone Number** (`phone_number`, text, Required/Optional): Enter your phone number so we can contact you.
* **Date Of Event** (`date_of_event`, date, Required/Optional): Select the date of your event.
* **Time Of Event** (`time_of_event`, time, Required/Optional): Choose the time of your event.
* **Event Type** (`event_type`, select_one, Required/Optional): Select "Yes" or "No" for the type of event you are planning.
* **Event Description** (`event_description`, text, Required/Optional): Enter a brief description of your event.
* **Special Instructions** (`special_instructions`, text, Required/Optional): If there are any special instructions, please include them here.
* **Catering Service** (`catering_service`, select_multiple, Required/Optional): Select "Yes" or "No" for the catering services you require.
