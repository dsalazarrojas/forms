# Single Plane Engine Intake Order Form - Help Guide
## Purpose
The Single Plane Engine Intake Order Form is used to collect information from customers for engine orders. It gathers details about the customer, order, and shipping information to ensure accurate processing of the order.

## How To Complete This Form

1.  Start by filling out the User Input page, which includes information about the customer such as their shipping details and order comments. 
    This page is used to gather essential details about the customer and their order.
2.  Next, move on to the Payment Details page, which requires information about the payment method and payment total. 
    Ensure the payment details are accurate to avoid any issues with order processing.
3.  The Shipping Details page requires information about the shipping method and shipping cost. 
    Please select the correct shipping method and ensure the shipping cost is accurate.
4.  On the Order Comments page, provide any additional comments or instructions related to the order. 
    This is an opportunity to add any special requests or notes about the order.
5.  On the Customer Info page, fill out the customer's contact information and shipping address. 
    This information will be used to contact the customer and for shipping purposes.
6.  The Order Notes page is for any notes or comments about the order that the customer wants to add. 
    This can be used to communicate with the customer about the order status.
7.  On the Engine Type page, select the type of engine ordered. 
    Please ensure the correct type is selected to avoid any errors in order processing.
8.  The Engine Model page is for selecting the model of the engine ordered. 
    Ensure the correct model is selected to avoid any issues.
9.  On the Engine Serial Number page, enter the serial number of the engine. 
    This is a required field to identify the engine.
10. The Order Status page allows you to select the status of the order. 
    Please select the correct status to ensure the order is processed accordingly.
11. The Payment Method page is for selecting the method of payment. 
    Please ensure the correct method is selected to avoid any issues with order processing.
12. On the Order Date page, enter the date of the order. 
    This is a required field to track the order date.
13. The Shipping Method page is for selecting the method of shipping. 
    Please ensure the correct method is selected to avoid any issues with shipping.
14. On the Order Weight page, enter the weight of the order. 
    This is a required field to calculate the shipping cost.
15. The Shipping Cost page is for calculating the shipping cost based on the order weight. 
    Please ensure the calculation is accurate to avoid any issues with order processing.
16. On the Order Total page, enter the total cost of the order. 
    This is a required field to process the order accurately.
17. The Order Notes 2 page is for any additional notes or comments about the order. 
    This can be used to communicate with the customer about the order status.
18. On the Customer Notes page, enter any additional notes or comments from the customer. 
    This can be used to communicate with the customer about their order.
19. The Payment Details 2 page is for any additional payment details. 
    This can be used to communicate with the customer about their payment.
20. On the Shipping Details 2 page, enter any additional shipping details. 
    This can be used to communicate with the customer about their shipping.
21. The Order Comments 2 page is for any additional comments or instructions related to the order. 
    This can be used to communicate with the customer about their order.
22. On the Shipping Address 2 page, enter any additional shipping address information. 
    This can be used to ensure accurate shipping of the order.
23. The Customer Info 2 page is for entering any additional customer information. 
    This can be used to communicate with the customer about their order.
24. On the Notes page, enter any additional notes or comments. 
    This can be used to communicate with the customer about their order.
