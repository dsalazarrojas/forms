# Promo Order Form - Help Guide
## Purpose
The Promo Order Form is designed to collect details about orders, including promotions. This form helps to gather information about the promotion name, image, price, currency, product name, order type, order date, order time, status, total, customer email, customer phone, order source, and other relevant details.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the required fields with the appropriate information.
2. Ensure that all required fields (marked with an asterisk \*) are completed before submitting the form.
3. Review the form for accuracy and completeness before submitting it.

## Field-by-Field Explanation
* **promo_name** (`promo_name`, text, *): Enter the name of the promotion.
* **price** (`price`, number, *): Enter the price of the promotion in the selected currency.
* **currency** (`currency`, select_one, *): Select the currency of the promotion (USD, EUR, JPY, CNY).
* **product_name** (`product_name`, text, *): Enter the name of the product.
* **order_type** (`order_type`, select_one): Select the type of order (Online, Offline).
* **order_date** (`order_date`, date, *): Enter the date of the order.
* **order_time** (`order_time`, time): Enter the time of the order.
* **promo_status** (`promo_status`, select_one, *): Select the status of the promotion (Active, Inactive).
* **order_amount** (`order_amount`, number): Enter the total amount of the order.
* **order_currency** (`order_currency`, select_one): Select the currency of the order (USD, EUR, JPY, CNY).
* **order_note** (`order_note`, text): Enter any additional notes about the order.
* **order_status** (`order_status`, select_one, *): Select the status of the order (Pending, Completed, Cancelled).
* **order_total** (`order_total`, number, *): Enter the total value of the order.
* **customer_email** (`customer_email`, email, *): Enter the email address of the customer.
* **customer_phone** (`customer_phone`, text, *): Enter the phone number of the customer.
* **order_source** (`order_source`, select_one, *): Select the source of the order (Online, Offline).
* **order_notes** (`order_notes`, text): Enter any additional notes about the order.
* **order_address** (`order_address`, text): Enter the address of the order.
* **customer_address** (`customer_address`, text): Enter the address of the customer.
* **order_notes_2** (`order_notes_2`, text): Enter any additional notes about the order.
* **promo_notes** (`promo_notes`, text): Enter any additional notes about the promotion.
* **customer_notes** (`customer_notes`, text): Enter any additional notes about the customer.

## Tips
