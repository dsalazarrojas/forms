# <string> - Help Guide
## Purpose
The "<string>" form is used to collect event details and order information for events such as concerts, conferences, and workshops.

## How To Complete This Form
To complete the form, follow these steps:

1. Fill in the **Event Details** section with the name and location of the event.
2. Select the **Event Type** from the dropdown menu, indicating whether the event is a concert, conference, or workshop.
3. Enter the **Event Date** and **Event Time** in the respective fields.
4. Provide a brief description of the event in the **Event Description** field.
5. If required, select the **Requested Items** from the list.
6. Enter the **Contact Email** and **Contact Phone** of the person responsible for the event.
7. Finally, select the desired **Order Form** items from the list.

## Field-by-Field Explanation

* **Event Details**: Enter the name and location of the event.
	+ **Name**: The name of the event.
	+ **Location**: The location of the event.
* **Event Type**: Select the type of event from the dropdown menu.
* **Event Date**: Enter the date of the event in the format YYYY-MM-DD.
* **Event Time**: Enter the time of the event in the format HH:MM.
* **Event Description**: Provide a brief description of the event.
* **Requested Items**: Select the items required for the event from the list.
* **Contact Email**: Enter the email of the contact person responsible for the event.
* **Contact Phone**: Enter the phone number of the contact person.
* **Order Form**: Select the desired items for the order form from the list.
* **Order Form Items 1-10**: Select or enter the items required for the event from the list. These items will be included in the order form.

Note: The **Order Form Items 1-10** fields are optional and only required if specific items are selected in the **Order Form** field.
