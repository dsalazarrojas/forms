# Store Cleaning Crew Supply Order Form - Help Guide
## Purpose
The Store Cleaning Crew Supply Order Form is a tool used to order supplies and products for the store's cleaning crew.

## How To Complete This Form
To complete this form, follow these steps:
1. Select a delivery date for the order.
2. Choose the products that you need to order.
3. Select a delivery method for the order.
4. Enter the quantity of each product being ordered.
5. Provide a delivery date and time.
6. Add any additional notes about the order.
7. Enter an email address and phone number for contact information.
8. Select the user that will be responsible for receiving the order.

## Field-by-Field Explanation

* **store_cleaning_crew_supply_order (1)**: Enter the description or name of your order.
* **delivery_date (2)**: Select the date you need the order to be delivered. This is where you can choose from three options: Delivery 1, Delivery 2, or Delivery 3.
* **requested_products (3)**: Choose the products that you need from the list of Cleaning Product 1, Cleaning Product 2, Cleaning Product 3. You can select one or more of these options.
* **delivery_method (4)**: Select the method for delivering the order. This is similar to the "delivery_date" field.
* **quantity (5)**: Enter the quantity of each product that you need to order. This field is a numeric field, so enter a whole number.
* **delivery_date_2 (6)**: This field is a duplicate of the "delivery_date" field.
* **delivery_time (7)**: Select the time you need the order to be delivered.
* **notes (8)**: Add any additional notes or comments about the order.
* **email (9)**: Enter your contact email address.
* **phone_number (10)**: Enter your contact phone number.
* **assigned_user (11)**: Select the user who will be responsible for receiving the order. This is where you can choose from three options: User 1, User 2, or User 3.

## Tips
* Make sure to choose a delivery date and method that works best for your needs.
* Double-check that you have entered the correct quantity of each product.
* Add any additional notes or comments about the order in the "notes" field.
* Enter the correct email address and phone number for contact information.
* Select the correct user that will be responsible for receiving the order.
