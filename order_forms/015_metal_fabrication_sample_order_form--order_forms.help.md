# metal_fabrication_sample_order_form - Help Guide

## Purpose
This form is designed for customers to order metal samples for fabrication purposes. It collects information about the customer's sample request, material specifications, and order details.

## How To Complete This Form
- Please select the "Sample Request" field to describe the type of sample you would like to order.
- If you need to select a material, choose one from the "Material Type" dropdown menu.
- Enter the thickness of the sample in the "Material Thickness" field.
- Enter the width of the sample in the "Material Width" field.
- Enter the size of the sample in the "Sample Size" field.
- Enter the length of the sample in the "Sample Length" field.
- Enter the width of the sample in the "Sample Width" field.
- Enter the height of the sample in the "Sample Height" field.
- Enter the weight of the sample in the "Sample Weight" field.
- Enter the quantity of samples you would like to order in the "Quantity Ordered" field.
- Enter a brief description of the material in the "Material Description" field.
- Select the production time in the "Production Time" field.
- Select the production date in the "Production Date" field.
- Enter any additional notes about your order in the "Notes" field.
- Enter your email address in the "Email" field.
- Enter your phone number in the "Phone Number" field.

## Field-by-Field Explanation
- **Sample Request (Sample Request, text, optional)**: A brief description of the sample you would like to order.
- **Material Type (Material Type, select_one, optional)**: The type of material you would like to use for the sample.
- **Material Thickness (Material Thickness, number, optional)**: The thickness of the sample.
- **Material Width (Material Width, number, optional)**: The width of the sample.
- **Sample Size (Sample Size, number, optional)**: The size of the sample.
- **Sample Length (Sample Length, number, optional)**: The length of the sample.
- **Sample Width (Sample Width, number, optional)**: The width of the sample.
- **Sample Height (Sample Height, number, optional)**: The height of the sample.
- **Sample Weight (Sample Weight, number, optional)**: The weight of the sample.
- **Quantity Ordered (Quantity Ordered, number, optional)**: The quantity of samples you would like to order.
- **Material Description (Material Description, text, optional)**: A brief description of the material you would like to use.
- **Production Time (Production Time, time, optional)**: The time it takes to produce the sample.
- **Production Date (Production Date, date, optional)**: The date on which the sample will be produced.
- **Notes (Notes, note, optional)**: Any additional notes about your order.
- **Email (Email, email, optional)**: Your email address for contact and updates.
- **Phone Number (Phone Number, text, optional)**: Your phone number for contact and updates.
