# Product packaging design order form - Help Guide

## Purpose
This form is for collecting information on product packaging design orders from clients.

## How To Complete This Form

To fill out this form, please follow these steps:

*   Fill in all required fields (indicated by a red asterisk) with the requested information.
*   For the "Client Name", "Order Details", and "Deadline" fields, enter a text description of the client's name, order details, and desired deadline, respectively.
*   For the "Packaging Size" field, select a number corresponding to the desired size of the packaging.
*   For the "Packaging Type" field, select "Yes" if the client requires a specific packaging type.
*   For the "Material Type" field, select all applicable material types required by the client.
*   For the "Color Scheme" field, select "Yes" if the client requires a specific color scheme.
*   For the "Packaging Layout" field, provide a text description of the desired packaging layout.
*   You may select multiple material types for the "Material Type" field.

## Field-by-Field Explanation

*   **Client Name** (text, client_name, required): Enter the client's name for this order.
*   **Order Details** (text, order_details, required): Enter a text description of the order details.
*   **Packaging Size** (number, packaging_size, optional): Select the desired size of the packaging (e.g., 1 for small, 2 for medium, 3 for large).
*   **Packaging Type** (select_one, packaging_type, optional): Select "Yes" if the client requires a specific packaging type.
*   **Material Type** (select_multiple, material_type, optional): Select all applicable material types required by the client.
*   **Color Scheme** (select_one, color_scheme, optional): Select "Yes" if the client requires a specific color scheme.
*   **Packaging Layout** (text, packaging_layout, optional): Provide a text description of the desired packaging layout.
*   **Deadline** (date, deadline, optional): Enter the desired deadline for the order.
*   You can only select one option from the "Packaging Type", "Color Scheme", and "Packaging Size" fields.

## Tips

*   Double-check all fields to ensure accuracy before submission.
*   If a field is optional, ensure you only fill it out if it's truly necessary for the order.
