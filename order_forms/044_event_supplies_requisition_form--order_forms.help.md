# event_supplies_requisition_form - Help Guide
## Purpose
The event_supplies_requisition_form is used by event planners and coordinators to request supplies for events. It helps in submitting supply requirements which can be anything from catering services, decorations, miscellaneous items, and other essential event supplies.

## How To Complete This Form
To fill out this form:
1. Ensure you have the necessary permissions to access this form.
2. Review the form carefully, selecting the required supplies for your event.
3. Select the supplies you need, using the provided options.
4. Confirm your supply requests.

## Field-by-Field Explanation

* **event_planner (1, text, required/optional)**: Enter the name of the event planner or coordinator responsible for this form submission.
* **event_date (2, date, required/optional)**: Enter the date of the event for which you are requesting supplies.
* **list_of_supplies (3, select_multiple, required/optional)**: Select all the supplies you need for your event. Options:
	+ Yes
	+ No
* **event_supplies_requisition (4, select_one, required/optional)**: Select the primary supply type you are requesting. Options:
	+ Catering
