# Restaurant Linen Replacement Order Form - Help Guide
## Purpose
This form is used to submit an order for linens that need to be replaced in a restaurant or event. This form helps to gather all necessary information required to ensure the correct linens are ordered and delivered to the correct location.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the category of the order (e.g. Food & Beverage Order Forms).
2. Provide a brief description of the order (e.g. what type of linens are needed, why they are needed, etc.).
3. Select the type of linens that need to be ordered (e.g. tablecloths, napkins).
4. Enter the count of each type of linen needed.
5. Choose the size of the tablecloths.
6. Choose the color of the tablecloths.
7. Choose the type of napkins needed.
8. Choose the size of the napkins.
9. Select the unit of measurement for the tablecloths (e.g. count, square feet, square meters).

## Field-by-Field Explanation

* **Restaurant Linen Replacement Order Form** (`restaurant_linen_replacement_order_form`, text, optional)
	+ This is the main form title.
* **Category** (`category`, select_one, optional)
	+ Select the category for the order (e.g. Food & Beverage Order Forms).
* **Description** (`description`, text, optional)
	+ Provide a brief description of the order.
* **Category** (`category_2`, select_multiple, optional)
	+ Select any additional categories the order falls under (e.g. Other, Order Forms).
* **Tablecloth Count** (`tablecloth_count`, number, optional)
	+ Enter the count of tablecloths needed.
* **Napkin Count** (`napkin_count`, number, optional)
	+ Enter the count of napkins needed.
* **Tablecloth Size** (`tablecloth_size`, select_one, optional)
	+ Select the size of the tablecloths (e.g. Full, Half, Quarter).
* **Tablecloth Color** (`tablecloth_color`, select_one, optional)
	+ Select the color of the tablecloths (e.g. White, Blue, Red).
* **Linen Tablecloth Count** (`linen_tablecloth_count`, number, optional)
	+ Enter the count of linen tablecloths needed.
* **Napkin Type** (`napkin_type`, select_one, optional)
	+ Select the type of napkins needed (e.g. Paper, Cloth, Tissue).
* **Napkins Size** (`napkins_size`, select_one, optional)
	+ Select the size of the napkins (e.g. Full, Half, Quarter).
* **Tablecloth Size Unit** (`tablecloth_size_unit`, select_one, optional)
	+ Select the unit of measurement for the tablecloths (e.g. Count, Square Feet, Square Meters).
* **Linen Type** (`linen_type`, select_one, optional)
	+ Select the type of linen needed (e.g. Cotton, Polyester, Linen).

## Tips
* Please ensure that all fields are filled in accurately to avoid errors in the order process.
* If you are unsure about any field, please reach out to the relevant staff member for clarification.
* This form is designed to be used by restaurant staff to submit orders for linens that need to be replaced.
