# digitalForensicsToolRequisitionForm - Help Guide

## Purpose

This form is used to requisition digital forensics tools for specific purposes. It is essential to fill out the form accurately to ensure that the requested tools are provided correctly and in a timely manner.

## How To Complete This Form

Before filling out this form, please make sure you have all the necessary information ready. Here are the steps to follow:

1. Select the type of tool you are requesting (e.g., Digital Forensics Tools, Forensic Software, or Other).
2. Enter the number of tools you are requesting.
3. Choose the date and time you would like to receive the tools.
4. Add any additional notes or comments if needed.
5. Provide your contact information, including your name, phone number, and email.
6. Choose the tool you would like to be assigned to (if applicable).
7. Specify the status of the requisition form (e.g., Pending, Approved, or Rejected).
8. Add any additional notes or comments for the assigned tool.
9. Review and submit the form once complete.

## Field-by-Field Explanation

* **Tool Type**: 
	+ Select the type of tool you are requesting (e.g., Digital Forensics Tools, Forensic Software, or Other).
* **Requested Tool Count**: 
	+ Enter the number of tools you are requesting.
* **Tool Request Date**:
	+ Enter the date you would like to receive the tools.
* **Tool Request Time**:
	+ Enter the time you would like to receive the tools.
* **Additional Notes**:
	+ Add any additional notes or comments about your tool request.
* **Contact Name**:
	+ Enter your name as the contact person.
* **Contact Phone**:
	+ Enter your phone number as the contact person.
* **Contact Email**:
	+ Enter your email address as the contact person.
* **Assigned Tool**:
	+ Choose the tool you would like to be assigned to (if applicable).
* **Assigned Tool Name**:
	+ Enter the name of the assigned tool.
* **Tool Status**:
	+ Choose the status of the requisition form (e.g., Pending, Approved, or Rejected).
* **Notes for Assigned Tool**:
	+ Add any additional notes or comments for the assigned tool.
* **Requisition Form Status**:
	+ Choose the status of the requisition form (e.g., Pending, Approved, or Rejected).
* **Notes for Requisition Form**:
	+ Add any additional notes or comments for the requisition form.
* **Comments**:
	+ Add any additional comments about the tool request.
* **Tool Serial Number**:
	+ Enter the serial number of the tool.
* **Tool Model Number**:
	+ Enter the model number of the tool.
* **Tool Software Version**:
	+ Enter the software version of the tool.
* **Comments for Tool**:
	+ Add any additional comments about the tool.
* **Requisition Reason**:
	+ Enter the reason for the tool requisition.
* **Remarks**:
	+ Add any additional remarks or comments.
* **Tool Serial Number 2**:
	+ Enter the serial number of the tool (if applicable).
* **Tool Model Number 2**:
	+ Enter the model number of the tool (if applicable).

	+ Add any additional notes or comments.

Note: Please ensure all fields are filled out accurately and completely to ensure timely and correct delivery of the tools.
