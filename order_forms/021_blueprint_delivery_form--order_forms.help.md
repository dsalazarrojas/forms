# Blueprint Delivery Form - Help Guide
## Purpose

The purpose of this form is to collect information about the delivery of blueprints, including the requester's name, project name, delivery address, number of copies, paper type, preferred delivery date, and contact phone number. This form ensures that the requested blueprints are delivered correctly and in a timely manner.

## How To Complete This Form

To complete this form, follow these steps:

1. Enter the Requester name in the "Requester name" field.
2. Enter the Project name in the "Project name" field.
3. Enter the Delivery address in the "Delivery address" field.
4. Enter the Number of copies in the "Number of copies" field.
5. Choose the Paper type from the available options in the "Paper type" field.
6. Enter the Preferred delivery date in the "Preferred delivery date" field, if required.
7. Enter the Contact phone number in the "Contact phone" field.
8. Add any additional instructions in the "Additional instructions" field, if required.

## Field-by-Field Explanation

* **Requester name (Required)**: Enter the full name of the person or organization requesting the blueprints.
* **Project name (Required)**: Enter the reference project identifier.
* **Delivery address (Required)**: Specify the address where the blueprints should be delivered.
* **Number of copies (Required)**: Enter the whole number of copies required.
* **Paper type (Required)**: Choose the paper specification from the options:
	+ Standard bond
	+ Heavy duty
	+ Waterproof
* **Preferred delivery date (Optional)**: Enter the date for delivery, if desired.
* **Contact phone (Required)**: Enter the phone number for delivery queries.
* **Additional instructions (Optional)**: Enter any special handling instructions for the blueprints.

## Tips

* Double-check the fields for accuracy before submission to ensure correct delivery of the blueprints.
* Make sure to enter the correct preferred delivery date, if required.
* If you have any special instructions, please add them in the "Additional instructions" field.
