# Custom Catering Order Form - Help Guide
## Purpose
This form is used to collect information from users for a custom catering order. It will be used to understand their preferences and requirements for their event or gathering.

## How To Complete This Form
1. Select the "Yes" or "No" options for each field as required.
2. Enter the guest count in the "Guest Count" field.
3. Choose the "Yes" or "No" options for event details such as delivery and payment.
4. Select the "Yes" or "No" options for special requests.
5. Select the "Yes" or "No" options for order summary.
6. Enter the order notes in the "Order Notes" field.
7. Select a date for the event in the "Event Date" field.
8. Select a time for the event in the "Event Time" field.
9. Enter the estimated delivery time in the "Estimated Delivery Time" field.
10. Enter the contact person and their phone number in the "Contact Person" and "Phone Number" fields respectively.
11. Enter the email address and company name in the "Email Address" and "Company Name" fields respectively.
12. Enter the street, city, state, zip, and country in the "Street", "City", "State", "Zip", and "Country" fields respectively.
13. Select a date for the order in the "Order Date" field.
14. Select a time for the order in the "Event Start Time" field.
15. Enter the total guest count in the "Total Guest Count" field.
16. Enter the total order amount in the "Order Total" field.

## Field-by-Field Explanation
* **Menu Selections** (`menu_selections`, select_multiple, required): Select the menu options you would like to include in your catering order.
* **Guest Count** (`guest_count`, number, required): Enter the number of guests attending the event.
* **Event Details** (`event_details`, select_one, required): Choose whether the event is a Yes or No event.
* **Delivery Details** (`delivery_details`, select_multiple, required): Select whether you want delivery or not.
* **Payment Info** (`payment_info`, select_multiple, required): Choose whether you want to pay online or offline.
* **Special Requests** (`special_requests`, select_one, required): Select whether you have any special requests.
* **Order Summary** (`order_summary`, select_multiple, required): Select whether you want to receive an order summary.
* **Submit** (`submit`, select_one, required): Choose whether to submit the form.
* **Order Notes** (`order_notes`, note, required): Enter any additional notes or comments for the order.
* **Order Date** (`order_date`, date, required): Select the date for the order.
* **Event Time** (`event_time`, time, required): Select the time for the event.
* **Estimated Delivery Time** (`estimated_delivery_time`, time, required): Enter the estimated delivery time.
* **Contact Person** (`contact_person`, text, required): Enter the contact person's name.
* **Phone Number** (`phone_number`, text, required): Enter the contact person's phone number.
* **Email Address** (`email_address`, email, required): Enter the contact person's email address.
* **Company Name** (`company_name`, text, required): Enter the company name.
* **Street** (`street`, text, required): Enter the street address.
* **City** (`city`, text, required): Enter the city name.
* **State** (`state`, text, required): Enter the state name.
* **Zip** (`zip`, text, required): Enter the zip code.
* **Country** (`country`, text, required): Enter the country name.
* **Event Date** (`event_date`, date, required): Select the date for the event.
* **Event Start Time** (`event_start_time`, time, required): Select the start time for the event.
* **Total Guest Count** (`total_guest_count`, number, required): Enter the total guest count.
* **Order Total** (`order_total`, number, required): Enter the total order amount.
