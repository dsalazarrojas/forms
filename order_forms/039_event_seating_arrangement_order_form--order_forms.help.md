# Event Seating Arrangement Order Form - Help Guide
## Purpose
This form is used to gather information about the seating arrangement for an event. It is used by event coordinators and staff to ensure that all necessary arrangements are made for a successful and safe event.

## How To Complete This Form

1. Fill out the form completely, paying attention to the required fields marked with an asterisk (\*).
2. Enter the event name and date and time of the event.
3. Select the seat type and seat number for each attendee.
4. Enter the guest name and email address for each attendee.
5. If necessary, enter any special requests or requirements for each attendee.
6. Select the meal option and confirm that the information is correct.
7. Enter any dietary restrictions or special needs for each attendee.
8. Enter any additional comments or accessibility information for each attendee.
9. Confirm that the information is correct and complete.
10. Sign and date the form to confirm that you have reviewed and verified the information.

## Field-by-Field Explanation

* **Event Name (1)** (`event_name`, text, required): Enter the name of the event.
* **Date and Time (2)** (`date_time`, date/time, required): Enter the date and time of the event.
* **Seat Type (3)** (`seat_type`, select_one, required): Select the type of seat required for the attendee. Options include Single, Double, and Table.
* **Seat Number (4)** (`seat_number`, number, required): Enter the seat number for the attendee.
* **Guest Name (5)** (`guest_name`, text, required): Enter the guest name.
* **Guest Email (6)** (`guest_email`, email, required): Enter the guest email address.
* **Special Request (7)** (`special_request`, note, required): Enter any special requests or requirements for the guest.
* **Phone Number (8)** (`phone_number`, text, required): Enter the phone number for the guest.
* **Event Date (9)** (`event_date`, date, required): Enter the date of the event.
* **Event Time (10)** (`event_time`, time, required): Enter the time of the event.
* **Event Duration (11)** (`event_duration`, number, required): Enter the duration of the event.
* **Seat Arrangement (12)** (`seat_arrangement`, select_multiple, required): Select the seat arrangement type for the event. Options include Window Table, Window Table with Partition, Window with Bar, and Window.
* **Seat Arrangement Details (13)** (`seat_arrangement_details`, text, required): Enter any additional details about the seat arrangement.
* **Meal Option (14)** (`meal_option`, select_one, required): Select the meal option for the guest. Options include Vegetarian, Vegan, Gluten-Free, and None.
* **Dietary Restrictions (15)** (`dietary_restrictions`, text, required): Enter any dietary restrictions or requirements for the guest.
* **Special Needs (16)** (`special_needs`, text, optional): Enter any special needs or requirements for the guest.
* **Accessibility (17)** (`accessibility`, text, required): Enter any accessibility information for the guest.
* **Comments (18)** (`comments`, text, optional): Enter any additional comments or information about the guest.
* **Confirm (19)** (`confirm`, select_one, required): Confirm that the information is correct.
* **Note (20)** (`note`, text, optional): Enter any additional notes or comments.
* **Signature (21)** (`signature`, text, optional): Enter your signature.
* **Signature Date (22)** (`signature_date`, date, optional): Enter the date of the signature.
* **Signature Date Time (23)** (`signature_time`, time, optional): Enter the time of the signature.
* **Signature Confirmation (24)** (`signature_confirmation`, text, optional): Enter a confirmation of the signature.
* **Submit (25)** (`submit`, select_one, required): Select Submit to confirm that the form is complete and accurate.

## Tips

* Ensure that all required fields are completed accurately and thoroughly.
* Review the form carefully before signing and submitting.
* If you are unsure about any field, please ask for clarification.
* This form should only be filled out once per event.
