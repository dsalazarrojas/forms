# Facility Management Tool Requisition Form - Help Guide

## Purpose
This form is designed to help you request facility management tools, such as tools, equipment, or supplies, from the facilities management team.

## How To Complete This Form
1. Select the tools you need from the options in the "Requested Tools" field.
2. Choose the category of the tool you are requesting, such as "Tool", "Equipment", or "Supplies".
3. Provide a brief description of the tool you are requesting in the "Description" field.
4. Indicate the quantity of the tool you are requesting.
5. Select the date and time you would like to receive the tool.
6. Enter the location where the tool will be used.
7. Choose the person who will be responsible for the tool, such as "Assigned", "Manager", or "Supervisor".
8. Enter the email address of the person responsible for the tool.
9. Enter the phone number of the person responsible for the tool.
10. Add any additional notes or comments about the request.

## Field-by-Field Explanation
- **Requested Tools**: Select all the tools you need from the options provided. This will help the facilities management team understand what you are requesting.
  * Type: Select Multiple
  * Required: No
- **Tool Category**: Choose the category of the tool you are requesting, such as "Tool", "Equipment", or "Supplies". This will help the facilities management team understand the type of item you are requesting.
  * Type: Select One
  * Required: No
- **Description**: Provide a brief description of the tool you are requesting. This will help the facilities management team understand what you are requesting.
  * Type: Text
  * Required: No
- **Quantity**: Indicate the quantity of the tool you are requesting.
  * Type: Number
  * Required: No
- **Request Date**: Select the date you would like to receive the tool.
  * Type: Date
  * Required: No
- **Request Time**: Select the time you would like to receive the tool.
  * Type: Time
  * Required: No
- **Location**: Enter the location where the tool will be used.
  * Type: Text
  * Required: No
- **Manager**: Choose the person who will be responsible for the tool, such as "Assigned", "Manager", or "Supervisor".
  * Type: Select One
  * Required: No
- **Email**: Enter the email address of the person responsible for the tool.
  * Type: Email
  * Required: No
- **Phone**: Enter the phone number of the person responsible for the tool.
  * Type: Text
  * Required: No
- **Notes**: Add any additional notes or comments about your request.
  * Type: Note
  * Required: No
