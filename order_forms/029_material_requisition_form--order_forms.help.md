# Material Requisition Form - Help Guide
## Purpose
The Material Requisition Form is designed to gather information about materials needed by employees or departments, and to communicate these needs to management or procurement teams.

## How To Complete This Form
To complete this form, please follow these steps:

1. Determine if you are submitting a form (`Yes`/`No`) - This field is optional but helps track the source of the request.
2. Select the type of material you are requesting (`material type`).
3. Provide a brief description of the material you are requesting (`material description`).
4. Specify the quantity of the material needed.
5. Select the date by which the material is required (`required date`).
6. Indicate if the material is assigned to a tool (`assigned tool`) - This field is optional.
7. Select the submitter of the form (`submitter`) - This field is optional.
8. Select the department that will be using the material (`department`) - This field is optional.
9. Select the person submitting the form (`submitted by`) - This field is optional.
10. Select the person/department the form is being submitted to (`submitted to`) - This field is optional.
11. Select the status of the request (`status`) - This field is optional.
12. Add any additional comments regarding the material request.
13. Enter a unique ID for the form (`form id`).
14. Enter the version of the form being filled out (`form version`).

## Field-by-Field Explanation
* **form_details**: This field allows you to indicate if this is a new form or an update to an existing one.
* **material_type**: This field is used to select the type of material you are requesting.
* **material_description**: Enter a brief description of the material you are requesting.
* **quantity**: Enter the quantity of the material needed.
* **required_date**: This field is used to select the date by which the material is required.
* **assigned_tool**: This field is used to indicate if the material is assigned to a tool.
* **submitter**: Select the person submitting the form.
* **department**: Select the department that will be using the material.
* **submitted_by**: Select the person submitting the form.
* **submitted_to**: Select the person/department the form is being submitted to.
* **status**: This field is used to track the status of the material request.
* **comments**: Add any additional comments about the material request.
* **form_id**: Enter a unique ID for the form.
* **form_version**: Enter the version of the form being filled out.

Tips:
* Make sure to fill out all required fields.
* If unsure about the material type, select `other` to allow additional description.
* If you are submitting on behalf of someone else, please make sure to fill out the `submitted_by` field.
* If the material is not assigned to a tool, it's likely not required to be filled out.
* This form will help streamline the material requisition process and ensure the right materials are ordered in a timely manner. 

Please note that the required fields are `form_details`, `material_type`, `quantity`, and `required_date`. The other fields are optional and provide additional information to support the material requisition process. 

Please ensure to fill out the form correctly to help us process your request efficiently. 

This form is designed to be completed by you, the requester, and will be reviewed by our team to process your request.
