# Family Menu Selection Form - Help Guide
## Purpose
The "Family Menu Selection Form" is used to gather information about family members and their needs for an event. This information helps event planners create an inclusive menu that caters to each family member's dietary restrictions, preferences, and other requirements.

## How To Complete This Form
To complete the form, follow these steps:
1. Review the form sections and ensure you are familiar with each field and its purpose.
2. Fill out the form section by section, providing accurate and detailed information as required.
3. Make sure to select the correct options for each field and double-check your responses.
4. Complete all required fields and ensure you have answered all relevant questions.

## Field-by-Field Explanation
* **Event Selection Form 1** (`family_menu_selection_1`, Select One, Required: false): 
  This section asks whether or not you would like to participate in the event. Select "Yes" if you plan to attend, and "No" if you do not.
* **Family Selection Form 1** (`family_selection_form_1`, Select Multiple, Required: false): 
  In this section, you can select multiple family members who will be participating in the event. Choose as many family members as apply to ensure that everyone's preferences and restrictions are included in the menu planning.
* **Date of Event 1** (`date_of_event_1`, Date, Required: false): 
  Provide the date of the event, which will help the event planners schedule the menu and other activities accordingly.
* **Time of Event 1** (`time_of_event_1`, Time, Required: false): 
  Enter the start and end times of the event to allow the menu planners to schedule meal times and other activities.
* **Dietary Restrictions 1** (`dietary_restrictions_1`, Text, Required: false): 
  Describe any dietary restrictions or allergies you or your family members have, so that the menu planners can create suitable options for you.
* **Preferred Dishes 1** (`preferred_dishes_1`, Select Multiple, Required: false): 
  Select the dishes you would like to have included in the menu. This will help the event planners tailor the menu to your preferences.
* **Event Description 1** (`event_description_1`, Note, Required: false): 
  Provide a brief description of the event, which will help the event planners understand your needs and preferences.
* **Event Description 2** (`event_description_2`, Text, Required: false): 
  Enter any additional details about the event that might be helpful for the menu planners.
* **Email 1** (`email_1`, Email, Required: false): 
  Provide your email address so that the event planners can contact you with updates and information.
* **Phone 1** (`phone_1`, Text, Required: false): 
  Enter your phone number in case the event planners need to contact you with urgent information.
* **Event Location 1** (`event_location_1`, Text, Required: false): 
  Specify the location where the event will take place.
* **Event Location 2** (`event_location_2`, Text, Required: false): 
  Enter the address or venue where the event will be held.
* **Event Start Date 1** (`event_start_date_1`, Date, Required: false): 
  Enter the start date of the event.
* **Event End Date 1** (`event_end_date_1`, Date, Required: false): 
  Enter the end date of the event.
* **Event Start Time 1** (`event_start_time_1`, Time, Required: false): 
  Enter the start time of the event.
* **Event End Time 1** (`event_end_time_1`, Time, Required: false): 
  Enter the end time of the event.
* **Event Organizers 1** (`event_organizers_1`, Text, Required: false): 
  List the names and contact information of the event organizers.
* **Event Organizers 2** (`event_organizers_2`, Text, Required: false): 
  Enter the names and contact information of the event organizers.
* **Event Notes 1** (`event_notes_1`, Note, Required: false): 
  Enter any additional comments or notes about the event.
* **Event Notes 2** (`event_notes_2`, Text, Required: false): 
  Provide any further comments or details about the event.
* **Event Status 1** (`event_status_1`, Text, Required: false): 
  Enter the status of the event, such as "Active" or "Inactive".
* **Event Status 2** (`event_status_2`, Select One, Required: false): 
  Select the status of the event from the options provided.
* **Family Member 1** (`family_member_1`, Select One, Required: false): 
  Select whether or not you are a family member. This will help the event planners include you in their menu planning and other preparations.

## Tips
* Double-check your responses to ensure accuracy and completeness.
* Review each field carefully to avoid missing essential information.
* If you have any questions or concerns, contact the event planners directly.
