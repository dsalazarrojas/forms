# Weekly Daily Order Form - Help Guide

## Purpose
The Weekly Daily Order Form is a form used to create and manage weekly orders for customers.

## How To Complete This Form
To complete this form, follow these steps:

1. Start by filling out the form as needed, entering information as required.
2. Ensure that all required fields (indicated by a red star) are filled out before submitting the form.
3. Review your entries for accuracy before submitting the form.

## Field-by-Field Explanation

* **Customer Name** (`weekly_daily_order_form_page_2`, text, required/optional): Enter the customer's name.
* **Customer Phone** (`weekly_daily_order_form_page_3`, text, required/optional): Enter the customer's phone number.
* **Customer Email** (`weekly_daily_order_form_page_4`, email, required/optional): Enter the customer's email address.
* **Order Details** (`weekly_daily_order_form_page_5`, text, required/optional): Enter a brief description of the order.
* **Order Notes** (`weekly_daily_order_form_page_6`, note, required/optional): Add any additional notes about the order.
* **Weekly Schedule** (`weekly_daily_order_form_page_7`, time, required/optional): Select the weekly schedule for the order.
* **Daily Schedule** (`weekly_daily_order_form_page_8`, time, required/optional): Select the daily schedule for the order.
* **Order Products** (`weekly_daily_order_form_page_9`, select_multiple, required/optional): Choose the products to be included in the order (e.g., Product A, Product B, Product C).
* **Order Total** (`weekly_daily_order_form_page_10`, number, required/optional): Enter the total cost of the order.
* **Assigned Tool** (`weekly_daily_order_form_page_11`, text, required/optional): Enter the assigned tool used for the order.
* **Form ID** (`weekly_daily_order_form_page_12`, text, required/optional): Enter the form ID (leave blank if not applicable).

Note: Some fields may be optional, but ensure that required fields are filled out before submitting the form.
