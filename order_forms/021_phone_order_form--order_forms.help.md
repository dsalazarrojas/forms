# Phone Order Form - Help Guide
## Purpose
The Phone Order Form is used to collect customer contact information and order details for phone orders.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter your customer's name in the "Customer Name" field.
2. If the customer's company is relevant to the order, enter it in the "Company" field.
3. Enter the customer's email address in the "Email" field.
4. Enter the customer's phone number in the "Phone" field.
5. Select the date of the order in the "Order Date" field (using the date picker).
6. Select the time of the order in the "Order Time" field (using the time picker).
7. Optionally, provide any additional order details in the "Order Details" field.
8. Select the shipping method for the order from the options provided (Cash, Pickup, or Shipping).

## Field-by-Field Explanation

* **Customer Name** (Customer Name, text, required): This is the customer's name. Please enter it as it appears on their business card or introduction.
* **Company** (Company, text, optional): If the customer's company is relevant to the order, enter it here.
* **Email** (Email, email, required): Enter the customer's email address. This will be used to contact them about their order.
* **Phone** (Phone, text, required): Enter the customer's phone number. This will be used to contact them about their order.
* **Order Date** (Order Date, date, required): Select the date of the order using the date picker.
* **Order Time** (Order Time, time, required): Select the time of the order using the time picker.
* **Order Details** (Order Details, text, optional): If there are any additional details about the order, enter them here.
* **Shipping Method** (Shipping Method, select_one, required): Select the shipping method for the order from the options provided (Cash, Pickup, or Shipping).
