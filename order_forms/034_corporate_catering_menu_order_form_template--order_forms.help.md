# Corporate Catering Menu Order Form Template - Help Guide

## Purpose
The Corporate Catering Menu Order Form Template is used to gather information from corporate clients to order catering services for their events or personal occasions.

## How To Complete This Form
To complete this form, follow these steps:

1.  Select the type of event for which you are ordering catering services.
2.  Enter your name and email address (optional but recommended for communication purposes).
3.  Enter your phone number (optional but recommended for communication purposes).
4.  Enter the date and time of the event (if applicable).
5.  Select the number of guests attending the event.
6.  Choose the menu items you would like to order (Salad, Chicken, Beef, Vegetarian, Fruit Platter, or Dessert).
7.  Enter any additional notes about the order.
8.  Select the type of corporate catering service you need (Full Menu, Partial Menu, or None).
9.  Choose the type of catering service you need (Delivery, Pick-up, or Both).
10.  Enter the total cost of the order (optional but recommended for accurate pricing).
11.  If applicable, enter the assigned tool.

## Field-by-Field Explanation

* **Event Type** (`event_type`, `select_one`, required): Select the type of event for which you are ordering catering services.
* **Name** (`name`, `text`, optional): Enter your name.
* **Email** (`email`, `email`, optional): Enter your email address for communication purposes.
* **Phone** (`phone`, `text`, optional): Enter your phone number for communication purposes.
* **Order Date** (`order_date`, `date`, optional): Enter the date of the event (if applicable).
* **Order Time** (`order_time`, `time`, optional): Enter the time of the event (if applicable).
* **Event Date** (`event_date`, `date`, optional): Enter the date of the event (if applicable).
* **Event Time** (`event_time`, `time`, optional): Enter the time of the event (if applicable).
* **Number of Guests** (`number_of_guests`, `number`, optional): Enter the number of guests attending the event.
* **Menu Items** (`menu_items`, `select_multiple`, optional): Choose the menu items you would like to order (Salad, Chicken, Beef, Vegetarian, Fruit Platter, or Dessert).
* **Notes** (`notes`, `note`, optional): Enter any additional notes about the order.
* **Corporate Catering** (`corporate_catering`, `select_multiple`, required): Select the type of corporate catering service you need (Full Menu, Partial Menu, or None).
* **Catering Service** (`catering_service`, `select_one`, optional): Choose the type of catering service you need (Delivery, Pick-up, or Both).
* **Total Cost** (`total_cost`, `number`, optional): Enter the total cost of the order (if applicable).
* **Assigned Tool** (`assigned_tool`, `text`, optional): If applicable, enter the assigned tool.

**Tips**

* Make sure to fill out all required fields to ensure accurate and complete information.
* Use the provided menu options to choose the items you would like to order.
* If you have any additional questions or concerns, please contact us for further assistance.
