# directional_signage_order_form - Help Guide
## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the required fields, marked as such in this guide.
2. Leave blank fields as necessary, as they are not required for the specific sign order.
3. Select options from dropdowns and radio buttons as needed for the sign's details.
4. Enter any additional comments or notes in the 'Notes' field.

## Field-by-Field Explanation

* **Business Name** (`business_name`, text, required): Enter the name of the business or organization associated with the event or location.
* **Event Name** (`event_name`, text, required): Enter the name of the event or location.
* **Event Date** (`event_date`, date, required): Select the date of the event or location.
* **Event Time** (`event_time`, time, required): Select the time of the event or location.
* **Event Location** (`event_location`, text, required): Enter the location of the event or location.
* **Signage Type** (`signage_type`, select_one, required): Choose the type of signage that best suits the event or location. Options include:
	+ Map: A map that shows the location.
	+ Directional Arrow: An arrow pointing to the location.
	+ Both: A combination of both options above.
	+ Other: Custom signage type not listed here.
* **Number of Signs** (`number_of_signs`, number, required): Enter the number of signs needed for the event or location.
* **Sign Color** (`sign_color`, select_multiple, required): Choose the color(s) for the sign(s). Options include:
	+ Blue
	+ Red
