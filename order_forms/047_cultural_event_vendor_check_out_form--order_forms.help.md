# cultural_event_vendor_check_out_form - Help Guide
## Purpose
The cultural_event_vendor_check_out_form is used to capture details of cultural events with vendors for administrative purposes.

## How To Complete This Form
To complete this form, follow these steps:
1. Fill out the vendor's name and email.
2. Select the payment method (Cash, Online, Credit/Debit).
3. Enter the payment amount.
4. Enter any additional notes about the event or vendor.
5. Update the payment status (Paid, Pending, Declined).
6. Specify the assigned tool for the event.
7. Enter the form ID (this is likely a unique identifier for the form).
8. Select the category of the event (Yes or No).
9. Enter a brief description of the event.
10. Specify if the form is assigned to a category (Yes or No).

## Field-by-Field Explanation
* **vendor_name** (text, required): Enter the name of the vendor.
* **email** (email, optional): Enter the email of the vendor.
* **payment_method** (select_one, optional): Select the payment method used for the transaction (Cash, Online, Credit/Debit).
* **payment_amount** (number, optional): Enter the amount paid to the vendor.
* **vendor_address** (text, optional): Enter the address of the vendor (if applicable).
* **notes** (text, optional): Enter any additional notes about the event or vendor.
* **payment_status** (select_multiple, optional): Select the current status of the payment (Paid, Pending, Declined).
* **assigned_tool** (text, optional): Enter the assigned tool for the event.
* **form_id** (text, optional): Enter the unique identifier for the form.
* **category** (select_multiple, optional): Select if the event falls under a specific category (Yes or No).
* **description** (text, optional): Enter a brief description of the event.
* **assigned_form** (select_multiple, optional): Specify if the form is assigned to a category (Yes or No).

Note: All fields marked as "optional" can be left blank if not applicable to the specific event or vendor.
