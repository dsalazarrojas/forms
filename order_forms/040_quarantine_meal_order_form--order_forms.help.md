# Quarantine Meal Order Form - Help Guide

## Purpose
The Quarantine Meal Order Form is a simple tool used to collect meal order information for patients or individuals in a quarantine setting.

## How To Complete This Form
1. To complete this form, start by selecting the "Quarantine Meal Order Form" category.
2. Choose the date for the meal order.
3. Select a form category from the options: Food Type, Diet Type, or Other.
4. Select the food item from the options: Pizza, Burgers, Salads, or Sandwiches.
5. Enter the quantity of the food item ordered.
6. Enter any special requests or comments for the meal order.
7. Select where the order is from: School Nurse, Hospital, or Self-Ordered.

## Field-by-Field Explanation
* **Quarantine Meal Order Form** (quarantinemalorder, note, not required): This is the form title and introduction.
* **Order Date** (orderdate, date, not required): Enter the date for the meal order. This is the date when the meal order is to be fulfilled.
* **Form Category** (orderformcategory, select_one, not required): Select a category for the meal order. This can be Food Type, Diet Type, or Other.
* **Food Item** (fooditem, select_one, not required): Select the type of food to be ordered. Options are Pizza, Burgers, Salads, or Sandwiches.
* **Quantity** (quantity, number, not required): Enter the quantity of the food item ordered.
* **Special Request** (specialrequest, text, not required): Enter any special requests or comments for the meal order.
* **Order From** (orderfrom, select_one, not required): Select where the meal order is from. Options are School Nurse, Hospital, or Self-Ordered.

## Tips
* Make sure to fill out each field accurately and completely.
* If unsure about any field, ask for assistance from authorized personnel.
* This form is for basic meal order information collection. Other systems or databases might be used to track detailed meal planning and nutritional information.
