# Crystal Form Submission - Help Guide
## Purpose
The Crystal Form Submission form is a tool for users to submit event information for event organizers or coordinators to track.

## How To Complete This Form

1.  The form is split into several sections, each corresponding to a different aspect of the event.
2.  Fill out the form section by section, starting with the "Form Submission" page.
3.  Begin by selecting the "Event Type" from the dropdown menu. This will determine what kind of event you are submitting.
4.  Enter the "Event Date" in the format specified (DD/MM/YYYY or MM/DD/YYYY).
5.  Select the "Event Time" from the dropdown menu.
6.  Enter the "Event Location" in the text field.
7.  If necessary, list the attendees in the "Attendees List" field.
8.  Select the correct options for "Event Details List" to provide additional information about the event.
9.  Enter the contact information in the "Contact Info" and "Contact Number" fields.
10. Finally, confirm that you have submitted the form correctly and completely.

## Field-by-Field Explanation

* **Feedback** (Feedback, text, optional): Enter any additional feedback or comments about the event.
* **Contact Info** (Contact Info, email, optional): Enter the contact email or phone number of the event organizer or coordinator.
* **Contact Number** (Contact Number, text, optional): Enter a secondary contact number for the event.
* **Contact Number 2** (Contact Number 2, text, optional): Enter a tertiary contact number for the event.
* **Event Details** (Event Details, select multiple, optional): Select the event details you wish to provide, such as Event Type, Date, Time, and Location.
* **Event Type** (Event Type, select one, optional): Select the type of event (Meeting, Conference, Seminar, or Webinar).
* **Event Date** (Event Date, date, optional): Enter the date of the event in the format DD/MM/YYYY or MM/DD/YYYY.
* **Event Time** (Event Time, time, optional): Select the time of the event.
* **Event Location** (Event Location, text, optional): Enter the location of the event.
* **Attendees** (Attendees, text, optional): List the attendees for the event.
* **Attendees List** (Attendees List, select multiple, optional): Select the attendees for the event (Yes or No).
* **Submitted By** (Submitted By, text, optional): Enter the name of the person submitting the form.
* **Submitted By 2** (Submitted By 2, text, optional): Enter the name of the secondary submitter.
* **Event Details List** (Event Details List, select multiple, optional): Select the event details you wish to provide, such as Event Type, Date, Time, and Location.
