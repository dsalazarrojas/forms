# Product Order Form Without Tax - Help Guide
## Purpose
This form is for customers or end-users to place product orders without tax. It's designed for demonstration or testing purposes.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the products you would like to order by choosing from the list of available products.
2. Enter the quantity of each product you'd like to order.
3. Enter the price for each product (if applicable).
4. Click on "Submit" to place your order.

## Field-by-Field Explanation

### 1. **Products** (`products`, select_multiple, required: false)
Select the products you'd like to order from the list of available products (Product A, Product B, Product C).

### 2. **Quantity** (`quantity`, number, required: false)
Enter the quantity of the selected products you'd like to order.

### 3. **Price** (`price`, number, required: false)
Enter the price for each product, if applicable. This field is not required but can be used to override the default price.

### 4. **Total** (`total`, number, required: false)
This field is automatically calculated based on the selected products and quantities. You can't edit this field directly, as it's generated dynamically.

## Tips
* Make sure to select the correct products and quantities to avoid errors.
* If you need to override the price for a product, enter the correct price for that product.
* This form is for demonstration or testing purposes only. If you need to place an actual order, please use the regular order form with tax applied.
