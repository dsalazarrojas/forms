# Gift Return Authorization Contact Form - Help Guide
## Purpose
This form is for customers to provide information about a gift return, which will be used to process the return and resolve any issues related to the gift.

## How To Complete This Form
1. Fill out the form completely, providing all the required information.
2. Review your answers carefully before submitting the form.

## Field-by-Field Explanation
* **Order Details**:
	+ **Order Number**: This field is required to identify the specific order related to the gift return.
	+ **Order Date**: This field should contain the date the order was placed.
	+ **Order Total**: This field is required to confirm the total amount paid for the gift.
* **Shipping Details**:
	+ **Shipping Name**: This field is required to confirm the name on the shipping label.
	+ **Shipping Address**: This field should contain the address the gift was shipped to.
* **Contact Info**:
	+ **Name**: This field should contain the name of the person authorized to return the gift.
	+ **Email**: This field is required for communication and will not be displayed to other users.
	+ **Phone**: This field should contain the phone number of the person authorized to return the gift.
* **Return Preferences**:
	+ **Reason for Return**: This field should explain the reason for the gift return, including any issues or defects with the gift.
	+ **Return Method**: This field should be selected to indicate the preferred return method (e.g., exchange, refund, or store credit).
