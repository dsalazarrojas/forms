# Recognition Order Form - Help Guide
## Purpose
This form is used to create a formal recognition order with all the necessary details. It is essential to provide accurate information to ensure a smooth process.

## How To Complete This Form
1. Fill in the employee's name as per company records.
2. Choose the department for which the award is intended.
3. Select the award type from the available options (Gold Medal, Plaque, or Crystal).
4. Choose the date on which the award is to be given.
5. Provide a brief reason for the award.
6. Select any nominees or prophets for the award, if applicable.
7. If required, select a time for the order.
8. Add any additional comments or notes about the order in the "Order Note" field.
9. Enter the employee's email address for contact purposes.
10. If necessary, enter the employee's phone number.
11. Enter the employee's email address for communication.
12. Enter the employee's phone number for contact.

## Field-by-Field Explanation
* **Employee Name**: Enter the employee's name as per company records.
* **Department**: Select the department for which the award is intended.
* **Award Type**: Choose the award type from the available options (Gold Medal, Plaque, or Crystal).
* **Date of Award**: Enter the date on which the award is to be given (mm/dd/yyyy).
* **Reason for Award**: Briefly describe the reason for the award.
* **Nominees Prophets**: Select any nominees or prophets for the award (John Smith, Jane Doe, or John Doe).
* **Prophets**: Select the employee or person to whom the award is to be given.
* **Order Date**: Enter the date on which the order is to be fulfilled (mm/dd/yyyy).
* **Order Time**: Enter the time at which the order is to be fulfilled (HH:MM).
* **Order Note**: Add any additional comments or notes about the order.
* **Email**: Enter the employee's email address for contact and communication.
* **Phone**: Enter the employee's phone number for contact purposes.
* **Employee Email**: Enter the employee's email address for communication purposes.
* **Employee Phone**: Enter the employee's phone number for contact purposes.

## Tips
* Always verify the employee's current status and recognition order progress before filling this form.
* Avoid duplicating existing orders or awards. 
* Fill in the form accurately and thoroughly to avoid any errors. 
* Use the "Order Note" field for any additional comments or information about the order.
