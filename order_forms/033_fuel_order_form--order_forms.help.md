# Fuel Order Form - Help Guide
## Purpose
The Fuel Order Form is designed to collect information for fuel orders. This form helps users place orders for fuel with various options for fuel type and vehicle information.

## How To Complete This Form
To complete the form, follow these steps:

1. Start by filling in the **Vehicle Type** field with the type of vehicle you are ordering fuel for (e.g., Car, Truck, Motorcycle, or Boat).
2. Select the desired **Fuel Type** from the options provided (e.g., Gasoline, Diesel, Hybrid, or Electric).
3. Enter the **Fuel Amount** in the designated field.
4. Choose the **Fuel Card Type** from the options provided (e.g., Standard Card, Standard Plus Card, Plus Card, or Premium Card).
5. Fill in the **Fuel Card Number** (only required if a fuel card is being used).
6. Enter the **Field 8** information (required).
7. Choose the **Order Date** for the fuel order (optional).

## Field-by-Field Explanation

* **Vehicle Type** (select_one): Select the type of vehicle you are ordering fuel for.
* **Fuel Type** (select_multiple): Select the type of fuel you need for your vehicle (e.g., Gasoline, Diesel, Hybrid, or Electric).
* **Fuel Amount** (number): Enter the amount of fuel needed.
* **Fuel Card Type** (select_one): Choose the type of fuel card you are using (e.g., Standard Card, Standard Plus Card, Plus Card, or Premium Card).
* **Fuel Card Number** (number): Enter the number of the fuel card being used (only required if a fuel card is being used).
* **Field 8** (text): Provide any additional information about the order (required).
* **Order Date** (date): Enter the date for the fuel order (optional).

## Tips

* Be sure to select the correct vehicle type and fuel type for your order.
* If using a fuel card, ensure you have the correct number and type of card.
* Double-check the field 8 information for accuracy and completeness.
* Enter the correct order date if applicable.
