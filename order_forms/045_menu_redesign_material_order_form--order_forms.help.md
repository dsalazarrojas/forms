# Menu Redesign Material Order Form - Help Guide
## Purpose
The purpose of this form is to collect information from customers to order a menu redesign for materials. Please use this form to select the materials you want to have redesigned and enter your contact information for follow-up.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the materials you want to have redesigned using the "Material Choice 1" and "Material Choice 2" fields. You can choose one or multiple options for "Material Choice 2".
2. Enter your contact information in the "Customer Name", "Email", and "Phone" fields.
3. If necessary, provide a description of the materials you are interested in having redesigned in the "Description" field.
4. Click the "Submit" button to submit your order.

## Field-by-Field Explanation
* **Customer Name** (`customer_name`, text, required: false): Enter your name as you would like to be addressed.
* **Email** (`email`, email, required: false): Enter your email address.
* **Phone** (`phone`, text, required: false): Enter your phone number.
* **Material Choice 1** (`material_choice_1`, select_one, required: false): Select the first material you want to have redesigned.
* **Material Choice 2** (`material_choice_2`, select_multiple, required: false): Select multiple materials you want to have redesigned.
* **Description** (`description`, text, required: false): Provide a brief description of the materials you are interested in having redesigned.
* **Submit** (`submit`, text, required: false): Click to submit your order.

## Tips
- Make sure to select the correct materials for the redesign.
- Enter accurate contact information so that we can follow up with you.
- If you have any further questions or requests, please contact us.
