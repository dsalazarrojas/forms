# Worker First Aid Kit Refill Order Form - Help Guide
## Purpose
The Worker First Aid Kit Refill Order Form is used to order a refill for a First Aid Kit for workers. This form is designed to ensure that you accurately report the status of your First Aid Kits, so we can provide you with the right supplies and quantity to keep your workplace safe and compliant.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the **Work Location** field with your company name or department ID.
2. Choose the type of First Aid Kit you need to refill (e.g., "Yes" for a standard First Aid Kit).
3. Select the size of the First Aid Kit you need (e.g., "Yes" for a standard size).
4. Choose the quantity of First Aids you need (e.g., "Yes" for 1-2 First Aids).
5. Select the frequency of the order (e.g., "Yes" for a monthly order).

## Field-by-Field Explanation

* **Work Location** (1): Enter your company name or department ID to associate the order with your location.
* **First Aid Kit Type** (2): Select "Yes" for a standard First Aid Kit or "No" for no First Aid Kit.
* **First Aid Kit Size** (3): Select "Yes" for the standard size or "No" for a large/extra-large size.
* **First Aids Quantity** (4): Select the number of First Aids you need, up to 5 options (e.g., 1, 2, 3, 4, or 5 First Aids).
* **Order Frequency** (5): Select "Yes" for a monthly order or "No" for a one-time order.

## Tips

* Ensure you accurately report the status of your First Aid Kits.
* Review the options for each field carefully to avoid errors.
* If you're unsure about any field, contact your supervisor or HR representative for guidance.
