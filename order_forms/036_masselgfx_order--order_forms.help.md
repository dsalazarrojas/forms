# Masselgfx Order - Help Guide
## Purpose
The Masselgfx Order form is a tool used to collect order details from clients. It is used to ensure accurate and efficient processing of orders.
## How To Complete This Form
To complete the Masselgfx Order form, follow these steps:

1. Select the type of graphic you wish to order (Image, Graphic, or Logo).
2. Enter the Client Name.
3. Enter the client's Email (if applicable).
4. Enter the client's Phone number (if applicable).
5. Enter the Date and Time ordered (if applicable).
6. Enter any additional Note (if applicable).

## Field-by-Field Explanation
* **Graphic Type** (`graphic_type`, select_one, required): Select the type of graphic you wish to order. This will be one of the following options: Image, Graphic, or Logo.
* **Client Name** (`client_name`, text, optional): Enter the client's name accurately and completely.
* **Email** (`email`, email, optional): Enter the client's email address. This field is optional but recommended for correspondence purposes.
* **Phone** (`phone`, text, optional): Enter the client's phone number. This field is optional but recommended for communication purposes.
* **Date Ordered** (`date_ordered`, date, optional): Enter the date the order was placed. This field is optional but recommended for tracking purposes.
* **Time Ordered** (`time_ordered`, time, optional): Enter the time the order was placed. This field is optional but recommended for tracking purposes.
* **Note** (`note`, note, optional): Enter any additional notes about the order. This field is optional and is used to provide further context for the order.

## Tips
- Ensure accuracy and completeness when filling out the form.
- Use the options available in the "Graphic Type" field.
- Enter the correct format for the "Date" and "Time" fields (mm/dd/yyyy and hh:mm respectively).
- This form is for order collection purposes only. Any notes entered in the "Note" field will be reviewed and considered as part of the order process.
