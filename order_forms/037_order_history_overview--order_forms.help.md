# order_history_overview - Help Guide

## Purpose
The "Order History Overview" form is designed to provide a snapshot of your past orders, allowing you to review order details, track progress, and analyze order performance.

## How To Complete This Form
To complete this form, follow these steps:

1. Click on the "Order History" tab to view the form.
2. Enter the "Order Number" if known to narrow down the search.
3. Select the "Order Status" to filter by completion status.
4. Click "Submit" to generate the overview report.

## Field-by-Field Explanation

* **Order Number** (`order_number`, `number`, false): Enter the order number to view the specific order details. This field is optional but can help in quickly locating a particular order.
* **Order Status** (`status`, `select_one`, false): Choose the order status to filter the orders by their completion status. Select from the options: active, completed, or cancelled.
* **Customer** (`customer`, `text`, false): Enter a customer's name or part of their name to search for related orders. This field is optional and can help in identifying orders related to a specific customer.
* **Order History** (`order_history`, `text`, false): Enter a brief description or keyword to narrow down the search results. This field is optional and can help in searching for orders with specific details.

## Tips
- Make sure to enter the correct order number to ensure accurate results.
- Select the correct order status to filter orders accurately.
- Use the customer field to search for orders related to a specific customer.
- Use the order history field to search for orders with specific details.
