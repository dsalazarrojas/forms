# Fashion Retail Display Mannequins Requisition Form - Help Guide
## Purpose
This form is used to create a requisition for fashion retail display mannequins. It is intended for store staff to request mannequins for various purposes, such as in-store displays, events, or exhibitions.

## How To Complete This Form
To complete this form, follow these steps:

1. **Store ID**: Enter the store ID where the mannequins are needed.
2. **Mannequin Type**: Select the type of mannequin required (Stand alone, Tabletop, or Wall Mount).
3. **Quantity Requested**: Enter the number of mannequins needed.
4. **Color Requested**: Select the color(s) of mannequins required (White, Black, Grey, Brown, or Beige). Note that this is optional.
5. **Delivery Location**: Select the delivery location for the mannequins (Store, Warehouse, or Home).
6. **Delivery Date**: Enter the date when the mannequins are needed.
7. **Email**: Enter your email address for contact purposes.
8. **Phone**: Enter your phone number for contact purposes.
9. **Assigned To**: Select the person or team responsible for handling the requisition (Operations or Visual Merchandising).
10. **Delivery Status**: Select the current status of the requisition (In Progress, Delayed, Shipped, or Received).

## Field-by-Field Explanation
* **Store ID** (store id, number, required): Enter the store ID where the mannequins are needed.
* **Mannequin Type** (mannequin type, select_one, required): Select the type of mannequin required (Stand alone, Tabletop, or Wall Mount).
* **Quantity Requested** (quantity requested, number, required): Enter the number of mannequins needed.
* **Color Requested** (color requested, select_multiple, optional): Select the color(s) of mannequins required (White, Black, Grey, Brown, or Beige).
* **Delivery Location** (delivery location, select_one, required): Select the delivery location for the mannequins (Store, Warehouse, or Home).
* **Delivery Date** (delivery date, date, required): Enter the date when the mannequins are needed.
* **Email** (email, email, required): Enter your email address for contact purposes.
* **Phone** (phone, text, optional): Enter your phone number for contact purposes.
* **Assigned To** (assigned to, select_one, required): Select the person or team responsible for handling the requisition (Operations or Visual Merchandising).
* **Delivery Status** (delivery status, select_one, required): Select the current status of the requisition (In Progress, Delayed, Shipped, or Received).
