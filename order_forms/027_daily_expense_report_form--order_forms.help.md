# Daily Expense Report Form - Help Guide
## Purpose
The Daily Expense Report Form is a simple tool for users to report their daily expenses for reimbursement. This form is meant to be filled out by users to provide all necessary information for their daily expenses.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the date of the expense from the calendar input field.
2. Enter a brief description of the expense item, such as "Lunch" or "Gas for work car".
3. Enter the amount of the expense.
4. Select the category of the expense using the dropdown menu (Yes or No).
5. Provide a more detailed description of the expense (optional).
6. Enter the location where the expense was incurred.
7. Add any additional notes about the expense.
8. Enter your email address for contact purposes.

## Field-by-Field Explanation
* **Expense Date**: Enter the date of the expense using the calendar input field. The date should be in the format of MM/DD/YY.
* **Item**: Enter a brief description of the expense item, such as "Lunch" or "Gas for work car".
* **Amount**: Enter the total amount of the expense.
* **Category**: Select the category of the expense using the dropdown menu. This field is likely meant to categorize the expense as reimbursable or not.
* **Description**: Provide a more detailed description of the expense, including any relevant details.
* **Location**: Enter the location where the expense was incurred.
* **Note**: Add any additional notes about the expense.
* **Email**: Enter your email address for contact purposes. This field is meant for someone else to use for contact, not for you to enter your own email address.
