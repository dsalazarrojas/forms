# Club Event Tent And Flag Order Form - Help Guide
## Purpose
The Club Event Tent And Flag Order Form is used to collect information about a club event, including the event name, date, location, and logistical requirements for tents and flags. This information is used to ensure that the club has the necessary supplies and resources for their event.

## How To Complete This Form
To complete this form, please follow these steps:

1. Enter the name of the event in the "Event Name" field.
2. Select the date of the event using the calendar picker.
3. Enter the start time of the event in the "Event Time" field.
4. Enter the name of the person coordinating the event in the "Event Organizer Name" field.
5. Enter their contact email address in the "Email Address" field.
6. Enter their contact phone number in the "Phone Number" field.
7. Enter the location of the event in the "Event Location" field.
8. Enter the specific area within the location where the tent will be set up in the "Location Details" field.
9. Indicate if tents are needed for the event, and if so, select the tent size and color preference.
10. Indicate if flags are needed for the event, and if so, select the type and design preference.
11. Enter the time and date for setup and teardown.
12. Provide any additional setup and teardown instructions.

## Field-by-Field Explanation

* **Event Name** (`event_name`, required): Enter the name of your club event.
* **Event Date** (`event_date`, required): Select the date of the event using the calendar picker.
* **Event Time** (`event_time`, required): Enter the start time of the event in 24-hour format (HH:MM AM/PM).
* **Event Organizer Name** (`organizer_name`, required): Enter the name of the person coordinating the event.
* **Email Address** (`organizer_email`, required): Enter their contact email address.
* **Phone Number** (`organizer_phone`, required): Enter their contact phone number.
* **Event Location** (`event_location`, required): Enter the venue name and address where the event will be held.
* **Location Details** (`location_details`, required): Enter the specific area within the location where the tent will be set up.
* **Expected Weather Conditions** (`weather_forecast`, optional): Describe the expected weather conditions for the event.
* **Tent Needed** (`tent_needed`, required): Indicate if tents are needed for the event.
* **Tent Size** (`tent_size`, optional): Select the size of the tent needed.
* **Number of Tents** (`tent_quantity`, optional): Enter the number of tents needed.
* **Tent Color Preference** (`tent_color`, optional): Select the color preference for the tent.
* **Tent Features** (`tent_features`, optional): Select any features needed for the tent.
* **Flag Needed** (`flag_needed`, required): Indicate if flags are needed for the event.
* **Flag Type** (`flag_type`, optional): Select the type of flag needed.
* **Number of Flags** (`flag_quantity`, optional): Enter the number of flags needed.
* **Flag Design or Logo** (`flag_design`, optional): Describe the design or logo to be printed on the flag.
* **Setup Time Needed** (`setup_time`, required): Enter the time to arrive for setup.
* **Setup Date** (`setup_date`, required): Enter the date for setup.
* **Teardown Instructions** (`teardown_instructions`, required): Provide instructions for dismantling and returning the tent and flags.

Note: If you are unsure about any of the fields, please contact the event coordinators for clarification.
