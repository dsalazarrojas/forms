# Trends & Colours For Resellers - Help Guide
## Purpose
This form is used to collect order details and payment information from resellers, enabling us to process orders accurately and efficiently.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter your **customer name** in the "customer name" field.
2. Select the **order date** from the calendar.
3. Enter the **product name** of the item being ordered.
4. Enter the **quantity** of the item being ordered.
5. Enter the **unit price** of the item being ordered.
6. If the order has a **payment method**, select "Yes" or "No" in the "payment method" field.
7. If you have a **contact email**, enter it in the "contact email" field.
8. If you have a **contact phone**, enter it in the "contact phone" field.
9. If you wish to add any **customer notes**, enter them in the "customer notes" field.

## Field-by-Field Explanation

* **customer name** (Customer name, text, required): Enter the name of the customer placing the order.
* **order date** (Order date, date, required): Select the date the order is being placed.
* **product name** (Product name, text, optional): Enter the name of the product being ordered.
* **quantity** (Quantity, number, required): Enter the number of items being ordered.
* **unit price** (Unit price, number, required): Enter the price of each item being ordered.
* **total price** (Total price, number, optional): This field will be automatically populated once the quantity and unit price are entered.
* **payment method** (Payment method, select_one, required): Select "Yes" if the order is paid via a payment method, "No" otherwise.
* **contact email** (Contact email, email, optional): Enter the email address of the customer.
* **contact phone** (Contact phone, text, optional): Enter the phone number of the customer.
* **customer notes** (Customer notes, note, optional): Enter any notes or comments about the order.
* **payment method** (Payment method, select_one, required): This field is actually "payment_method" but it's being used to repeat the field description for emphasis. Please disregard this entry.
* **payment_method** (Payment method, select_one, required): Select "Yes" if the order is paid via a payment method, "No" otherwise.
