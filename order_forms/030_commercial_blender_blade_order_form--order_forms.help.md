# Commercial Blender Blade Order Form - Help Guide
## Purpose

This form is designed to gather information for a commercial blender blade order. Please complete it thoroughly to ensure accurate ordering and timely delivery.

## How To Complete This Form

1. **Customer Name** (`customer_name`, text, required): Enter the full name of the customer or business name.
2. **Contact Person** (`contact_person`, text, required): Enter the primary contact name.
3. **Email Address** (`email`, email, required): Enter the email address for order confirmation.
4. **Phone Number** (`phone`, text, required): Enter the contact number for order inquiries.
5. **Company Name** (`company_name`, text, optional): Enter the business name if applicable.
6. **Blender Model** (`blender_brand`, select_one, required): Select the blender brand for which you need the blade assembly.
7. **Blender Model Number** (`blender_model_number`, text, required): Enter the specific model number.
8. **Blade Type** (`blade_type`, select_one, required): Select the type of blade assembly needed (e.g., Standard, Heavy Duty, etc.).
9. **Blade Material** (`blade_material`, select_one, required): Select the material preference (e.g., Stainless Steel, Ceramic, etc.).
10. **Number of Blade Assemblies** (`number_of_blades`, number, required): Enter the number of blade assemblies needed.
11. **Blade Diameter** (`blade_diameter`, number, optional): Enter the size in inches if applicable.
12. **Mounting Type** (`mounting_type`, select_one, required): Select the mounting type (e.g., Square Drive, Round Drive, etc.).
13. **Bearing Type** (`bearing_type`, select_one, optional): Select the bearing type if applicable.
14. **Replacement or Upgrade** (`replacement_or_upgrade`, select_one, required): Indicate if this is a replacement or upgrade order.
15. **Unit Price** (`unit_price`, number, required): Enter the price per blade assembly.
16. **Quantity Discount** (`quantity_discount`, number, optional): Enter the discount applied if applicable.
17. **Subtotal** (`subtotal`, number, required): The order subtotal will be calculated automatically.
18. **Shipping Cost** (`shipping_cost`, number, required): Enter the shipping and handling cost.
19. **Total Amount** (`total_amount`, number, required): The total order amount will be calculated automatically.
20. **Shipping Address** (`shipping_address`, text, required): Enter the complete delivery address.
21. **Shipping Method** (`shipping_method`, select_one, required): Select the shipping preference (e.g., Standard Shipping, Express Shipping, etc.).
22. **Payment Method** (`payment_method`, select_one, required): Select the payment method (e.g., Credit Card, Debit Card, etc.).
23. **Purchase Order Number** (`purchase_order_number`, text, optional): Enter the PO number if applicable.
24. **Special Instructions** (`special_instructions`, text, optional): Enter any special requests or instructions.

## Tips

- Double-check the required fields before submission.
- Ensure the correct shipping address is entered to avoid delays.
- Review the total amount carefully before confirming the order.

By following this guide, you should be able to complete the form accurately and efficiently. If you have any questions or need further assistance, please contact our sales team.
