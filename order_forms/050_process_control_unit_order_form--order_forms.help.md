# Process Control Unit Order Form - Help Guide
## Purpose
The Process Control Unit Order Form is a tool used to collect information for the process control unit order process. It is used by buyers to ensure that all the necessary details are collected accurately and efficiently when placing an order with a supplier.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the units for which you want to place an order. You can select multiple units if needed.
2. Provide the delivery details, such as the delivery address and date.
3. Confirm the payment terms. Please select 'Yes' if you agree to the payment terms.
4. Select the delivery status of the unit. Please select 'Active' if the unit is active and 'Inactive' if it is not.
5. If required, provide the supplier details, unit description, unit part number, delivery date and time, payment amount, payment method, supplier name, contact number, and notes.

## Field-by-Field Explanation

### Unit Selections (id: 1)
Unit Selections is a multiple selection field where you can select the units for which you want to place an order. This field is required.

### Delivery Details (id: 2)
Delivery Details is a text field where you can provide any additional information regarding the delivery. This field is optional.

### Delivery Date (id: 3)
Delivery Date is a date field where you can select the date of delivery. This field is optional.

### Payment Details (id: 4)
Payment Details is a text field where you can provide any additional information regarding the payment. This field is optional.

### Delivery Address (id: 5)
Delivery Address is a text field where you can provide the address where the unit will be delivered. This field is optional.

### Payment Terms (id: 6)
Payment Terms is a select field where you can confirm the payment terms. Please select 'Yes' if you agree to the payment terms. This field is required.

### Payment Date (id: 7)
Payment Date is a date field where you can select the date of payment. This field is optional.

### Delivery Status (id: 8)
Delivery Status is a select field where you can select the status of the delivery. Please select 'Active' if the unit is active and 'Inactive' if it is not. This field is required.

### Supplier Details (id: 9)
Supplier Details is a text field where you can provide any additional information regarding the supplier. This field is optional.

### Unit Description (id: 10)
Unit Description is a text field where you can provide a brief description of the unit. This field is optional.

### Unit Part Number (id: 11)
Unit Part Number is a text field where you can provide the part number of the unit. This field is optional.

### Delivery Date Time (id: 12)
Delivery Date Time is a time field where you can select the time of delivery. This field is optional.

### Payment Amount (id: 13)
Payment Amount is a number field where you can select the amount to be paid for the unit. This field is optional.

### Payment Method (id: 14)
Payment Method is a select field where you can select the payment method. Please select 'Yes' if you agree to the payment method. This field is required.

### Supplier Name (id: 15)
Supplier Name is a text field where you can provide the name of the supplier. This field is optional.

### Contact Number (id: 16)
Contact Number is a text field where you can provide the contact number of the supplier. This field is optional.

### Notes (id: 17)
Notes is a text field where you can provide any additional information or notes. This field is optional.

## Tips
Please ensure that you provide accurate and up-to-date information in each field to avoid any issues. If you are unsure about any field, please consult with the relevant department.
