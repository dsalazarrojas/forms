# Seasonal Display Installation Quote Request Form - Help Guide
## Purpose
This form is designed to gather information from customers to create accurate quotes for seasonal display installation. Please fill out this form with as much detail as possible to ensure that our team can provide you with the best possible quote.

## How To Complete This Form

To fill out this form, follow these steps:

1. Fill out your personal details (Customer Name, Contact Name, Business Name, Address, Contact Email, and Phone Number) to ensure we can get in touch with you.
2. Describe the display you would like installed (Display Description, Display Type, Display Size, Display Material, and Color).
3. Provide installation details (Installation Date, Installation Time, and Location Details).
4. Select any additional options you would like to add (Select One and Select Multiple).
5. Add any notes you would like to add to your quote (Note 1-4).

## Field-by-Field Explanation

* **Customer Name** (`customer_name`): Please fill out your name as it appears on your identification or business card.
* **Contact Name** (`contact_name`): Please fill out your contact name, this can be a person or business name.
* **Business Name** (`business_name`): Please fill out your business name if applicable.
* **Address** (`address`): Please fill out your business address where the display will be installed.
* **Contact Email** (`contact_email`): Please fill out your email address so we can get in touch with you.
* **Phone Number** (`phone_number`): Please fill out your phone number so we can get in touch with you.
* **Display Description** (`display_description`): Describe the display you would like installed, including its size and material.
* **Display Type** (`display_type`): Please select the type of display you would like installed.
* **Display Size** (`display_size`): Please select the size of the display.
* **Display Material** (`display_material`): Please select the material of the display.
* **Color** (`color`): Please select the color of the display.
* **Installation Date** (`installation_date`): Please select the date you would like the display installed.
* **Installation Time** (`installation_time`): Please select the time you would like the display installed.
* **Location Details** (`location_details`): Please provide any additional details about the installation location.
* **Number of Displays** (`number_of_displays`): Please select the number of displays you would like installed.
* **Select One** (`select_one`): Please select one of the options provided.
* **Select Multiple** (`select_multiple`): Please select multiple options from the provided options.
* **Note 1** (`note`): Please add any notes to your quote.
* **Note 2** (`note_2`): Please add any additional notes to your quote.
* **Note 3** (`note_3`): Please add any additional notes to your quote.
* **Note 4** (`note_4`): Please add any final notes to your quote.
* **Installation Cost** (`installation_cost`): Please fill out the cost of installation.
* **Labor Cost** (`labor_cost`): Please fill out the labor cost.
* **Total Cost** (`total_cost`): Please fill out the total cost.
