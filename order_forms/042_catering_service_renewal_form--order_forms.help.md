# Catering Service Renewal Form - Help Guide

## Purpose
This form is for clients to renew their catering services with the company. It's essential to fill out the form accurately and thoroughly to ensure a smooth service renewal process.

## How To Complete This Form
1. Fill out all the required fields with accurate information.
2. Review the form carefully before submitting it.

## Field-by-Field Explanation

* **Client Name** (`client_name`, text, required): Please enter your full name as it appears on your identification.
* **Email Address** (`email`, email, required): Enter your email address to ensure we can contact you.
* **Phone Number** (`phone`, text, required): Enter your contact phone number.
* **Company Name** (`company_name`, text, optional): If you're renewing on behalf of a company, enter the company name.
* **Renewal Date** (`renewal_date`, date, required): Enter the date you'd like to renew your service.
* **Original Contract Date** (`original_contract_date`, date, optional): If you have an existing contract, enter the start date.
* **Contract Number** (`contract_number`, text, optional): Enter your contract reference number.
* **Service Type** (`service_type`, select_one, required): Select the type of service you'd like to renew (e.g., Monthly Catering, Quarterly Catering, etc.).
* **Renewal Period** (`renewal_period`, select_one, required): Select the duration of the renewed service (e.g., 3 Months, 6 Months, 1 Year, etc.).
* **Continue Current Menu** (`continue_current_menu`, select_one, required): Choose whether you'd like to continue with the current menu or make changes.
* **Menu Changes Requested** (`menu_changes_requested`, text, optional): If you'd like to make changes, describe them here.
* **Guest Count Change** (`guest_count_change`, select_one, optional): If you expect changes in the guest count, select the relevant option.
* **New Guest Count** (`new_guest_count`, number, optional): If you've selected "Increase" or "Decrease" in the previous field, enter the updated count.
* **Frequency Change** (`frequency_change`, select_one, optional): If you'd like to change the service frequency, select the relevant option.
* **New Frequency** (`new_frequency`, text, optional): If you've selected "More Often" or "Less Often", describe the new frequency.
* **Budget Change** (`budget_change`, select_one, optional): If you expect changes in the budget, select the relevant option.
* **New Budget** (`new_budget`, number, optional): If you've selected "Increase Budget", enter the updated amount.
* **Additional Services Needed** (`additional_services`, select_multiple, optional): Select any additional services you'd like to include.
* **Services to Remove** (`services_to_remove`, text, optional): If you'd like to cancel any services, describe them here.
* **Satisfaction Rating** (`satisfaction_rating`, select_one, required): Rate your satisfaction with the current service.
* **Issues to Address** (`issues_to_address`, text, optional): If you have any problems to fix, describe them here.
* **Special Requests** (`special_requests`, text, optional): If you have any new requirements, describe them here.
* **Payment Method Change** (`payment_method_change`, select_one, optional): If you'd like to change the payment method, select the relevant option.
* **Terms and Conditions Accepted** (`terms_accepted`, select_one, required): Confirm you've read and agreed to the terms and conditions.
* **Signature Date** (`signature_date`, date, required): Enter the date you're signing this agreement.
* **Additional Comments** (`additional_comments`, text, optional): If you have any additional information, describe them here.
