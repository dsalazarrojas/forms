# polish_on_point_order_form_template - Help Guide
## Purpose
This form is intended for ordering or sales purposes, possibly related to a specific collection or product line.

## How To Complete This Form
To complete this form, follow these steps:

1. Review the form carefully and make sure you understand the fields and their meanings.
2. Fill out the fields according to your needs, ensuring you select the correct options for each field.
3. Submit the form when you have completed all necessary fields.

## Field-by-Field Explanation
Here's a detailed explanation of each field:

* **contact_person** (`contact_person`, `note`, not required): This field is for any additional information or notes you'd like to provide about the contact person.
* **Fall Collection** (`Fall Collection`, `text`, not required): This field is for providing a brief description or details about the Fall Collection.
* **Fall Collections -** (`Fall Collections -`, `select_multiple`, not required): Select all the Fall collections that apply to your order.
	+ Select 'Yes' for each collection that you're interested in.
* **Autumn** (`Autumn`, `select_one`, not required): Select 'Yes' for Autumn, and 'No' for other seasons.
* **Fall Collection 2** (`Fall Collection 2`, `select_one`, not required): Select 'Yes' for Fall Collection 2, and 'No' for other seasons.
* **Fall Collection 3** (`Fall Collection 3`, `select_one`, not required): Select 'Yes' for Fall Collection 3, and 'No' for other seasons.
* **Fall Collection 4** (`Fall Collection 4`, `select_one`, not required): Select 'Yes' for Fall Collection 4, and 'No' for other seasons.

## Tips

* Be sure to select the correct options for each field, and double-check your selections before submitting the form.
* If you're unsure about any field, ask your sales or support team for clarification.
* Fill out the form carefully, and review it before submitting to ensure accuracy.
