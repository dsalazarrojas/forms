# Pool House Service Contract - Help Guide
## Purpose
The Pool House Service Contract form is a tool for managing pool house services. It collects information about the service, including the home owner, service provider, address, and service status.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the "Pool House Service Contract" page from the main menu.
2. Fill in the fields as prompted:

## Field-by-Field Explanation
- **Pool House Service Contract** (`pool_house_service_contract`, note, not required): This is the title of the form.
- **Home Owner** (`home_owner`, text, not required): Enter the name of the home owner.
- **Service Provider** (`service_provider`, select one, not required): Select 'Yes' if the service provider is applicable.
- **Service Provider Name** (`service_provider_name`, text, not required): Enter the name of the service provider.
- **Address** (`address`, text, not required): Enter the address of the pool house service.
- **City** (`city`, text, not required): Enter the city of the pool house service.
- **State** (`state`, text, not required): Enter the state of the pool house service.
- **Zip Code** (`zip_code`, text, not required): Enter the zip code of the pool house service.
- **Start Date** (`start_date`, date, not required): Enter the start date of the service.
- **End Date** (`end_date`, date, not required): Enter the end date of the service.
- **Service Description** (`service_description`, text, not required): Enter a brief description of the service.
- **Pool Type** (`pool_type`, select one, not required): Select 'Yes' if the pool is applicable.
- **Pool Size** (`pool_size`, select one, not required): Select 'Yes' if the pool size is applicable.
- **Pool Location** (`pool_location`, text, not required): Enter the location of the pool.
- **Service Type** (`service_type`, select one, not required): Select 'Yes' if the service type is applicable.
- **Service Frequency** (`service_frequency`, select multiple, not required): Select multiple options for the service frequency.
- **Notes** (`notes`, text, not required): Enter any additional notes or comments about the service.
- **Assigned Tool** (`assigned_tool`, text, not required): Enter the assigned tool or equipment for the service.
- **Assigned User** (`assigned_user`, text, not required): Enter the assigned user or personnel for the service.
- **Service Status** (`service_status`, select one, not required): Select the service status (Active or Inactive).
- **Completed Date** (`completed_date`, date, not required): Enter the date the service was completed.
- **Service Contract Status** (`service_contract_status`, select one, not required): Select the service contract status (Active or Inactive).
- **Service Contract Type** (`service_contract_type`, select one, not required): Select 'Yes' if the service contract type is applicable.
- **Service Contract Terms** (`service_contract_terms`, text, not required): Enter any additional terms or conditions of the service contract.
- **Review Date** (`review_date`, date, not required): Enter the date the service was reviewed.

## Tips

* Please ensure that all fields are filled in accurately and completely.
* If you're unsure about any field, please consult with the relevant personnel.
* This form is for informational purposes only, please do not use it for transactional operations.
