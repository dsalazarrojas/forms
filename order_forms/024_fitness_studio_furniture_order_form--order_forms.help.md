# Fitness Studio Furniture Order Form - Help Guide
## Purpose
The Fitness Studio Furniture Order Form is a form designed to gather information about the furniture orders from customers.

## How To Complete This Form
To complete this form, follow the steps below:

1.  In the **Form Data** field, select the type of furniture you'd like to order.
2.  In the **Furniture Ordered** field, choose the specific items you'd like to order from the list provided.
3.  In the **Number Ordered** field, specify the quantity of each item you'd like to order.
4.  In the **Customer Name** field, enter your name as you'd like it to be displayed on the order confirmation.
5.  In the **Customer Email** field, enter your email address so we can contact you with updates on your order.
6.  In the **Customer Phone** field, enter your phone number so we can contact you with any questions or updates.
7.  In the **Customer Note** field, add any additional notes or comments about your order.
8.  In the **Staff Member** field, select the staff member responsible for handling your order.
9.  In the **Total Number Ordered** field, input the total number of items ordered.

## Field-by-Field Explanation
- **Form Data**:
    - **Form Data** (`form_1_form_data`, text, optional): Enter a brief description or note about the order.
- **Furniture Ordered**:
    - **Furniture Ordered** (`form_1_furniture_ordered`, select multiple, optional): Choose the specific type of furniture you'd like to order. This field allows you to select multiple items from the available options.
- **Number Ordered**:
    - **Number Ordered** (`form_1_number_ordered`, number, optional): Specify the quantity of each item you'd like to order.
- **Customer Name**:
    - **Customer Name** (`form_1_customer_name`, text, optional): Enter your name as you'd like it to be displayed on the order confirmation.
- **Customer Email**:
    - **Customer Email** (`form_1_customer_email`, email, optional): Enter your email address so we can contact you with updates on your order.
- **Customer Phone**:
    - **Customer Phone** (`form_1_customer_phone`, text, optional): Enter your phone number so we can contact you with any questions or updates.
- **Customer Note**:
    - **Customer Note** (`form_1_customer_note`, note, optional): Add any additional notes or comments about your order.
- **Staff Member**:
    - **Staff Member** (`form_1_staff_member`, select multiple, optional): Select the staff member responsible for handling your order.
- **Total Number Ordered**:
    - **Total Number Ordered** (`form_1_total_number_ordered`, number, optional): Input the total number of items ordered.
