# Cake Pop Order Form Template - Help Guide
## Purpose
The purpose of this form is to collect information for a custom cake pop order from customers. It's essential to fill out the form carefully to ensure that we can create the desired cake pops according to your preferences.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out your name and email address in the "Your Name" and "Email Address" fields, respectively.
2. Enter your phone number in the "Phone Number" field.
3. Select a date for the order and pickup in the "Order Date" and "Pickup Date" fields, respectively.
4. Choose the flavor and coating type for the cake pops in the "Cake Pop Flavor" and "Coating Type" fields, respectively.
5. Specify the quantity of cake pops you would like to order in the "Quantity" field.
6. Select a dozen option from the "Dozen Option" field to determine the number of cake pops in each order.
7. Choose a decorative style for the cake pops in the "Decorative Style" field.
8. If desired, select a color scheme for the cake pops in the "Color Scheme" field.
9. Select any additional toppings or sprinkles you would like to add in the "Sprinkles or Toppings" field.
10. Indicate the occasion for the order in the "Occasion" field.
11. If you have any special requests or messages, type them in the "Custom Message" field.
12. Choose a packaging option for the cake pops in the "Packaging Option" field.
13. If you have any dietary requirements, select them from the "Dietary Requirements" field.
14. Select a delivery method in the "Delivery Method" field.
15. If you selected delivery, provide your delivery address in the "Delivery Address" field.
16. Choose a payment method in the "Payment Method" field.

## Field-by-Field Explanation
- **Your Name** (Required): Enter your full name, including any title or honorifics.
- **Email Address** (Required): Enter your email address for order confirmation.
- **Phone Number** (Required): Enter your contact number for any further questions.
- **Order Date** (Required): Select today's date for the order.
- **Pickup Date** (Required): Select the date you need to pickup the cake pops.
- **Pickup Time** (Optional): Select a preferred pickup time.
- **Cake Pop Flavor** (Required): Choose one or more flavors for the cake pops.
- **Coating Type** (Required): Select a coating type for the cake pops.
- **Quantity** (Required): Enter the number of cake pops you would like to order.
- **Dozen Option** (Required): Select the desired quantity for the cake pops, with options like one dozen (12), three dozen (36), etc.
- **Decorative Style** (Required): Choose a decorative style for the cake pops, like Simple, Drizzled, etc.
- **Color Scheme** (Optional): If you have a preferred color scheme, type it in this field.
- **Sprinkles or Toppings** (Optional): Select any additional toppings or sprinkles you want to add.
- **Occasion** (Required): Indicate the purpose or occasion for the order, like Birthday, Wedding, etc.
- **Custom Message** (Optional): If you have any special requests or messages, type them in this field.
- **Packaging Option** (Optional): Choose a packaging option, like Standard box, Gift box, etc.
- **Dietary Requirements** (Required): If you have any dietary restrictions, select them from the options provided.
- **Delivery Method** (Required): Select a delivery method, like Pickup in store, Local delivery, etc.
- **Delivery Address** (Optional): If you selected delivery, provide your address in this field.
- **Payment Method** (Required): Choose a payment method, like Credit card, Debit card, etc.
- **Special Instructions** (Optional): If you have any special requests or information, type it in this field.
