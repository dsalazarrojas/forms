# Inventory Lot Assessment Form - Help Guide
## Purpose

The Inventory Lot Assessment Form is a tool used to collect and evaluate the attributes of an inventory lot, enabling efficient inventory management and tracking.

## How To Complete This Form

1. Fill out the **Lot Number** field with the unique identifier assigned to the inventory lot.
2. Select the **Inventory Type** to classify the lot as either "Lot" or "Non-inventory".
3. Choose the **Condition** of the lot from the options "New", "Used", or "Refurbished".
4. Enter the **Quantity** of the items in the lot.
5. Enter the **Value** of the items in the lot.
6. Provide any additional **Notes** about the lot.
7. Select the **Assigned To** personnel responsible for the lot (optional).
8. Select the **Created By** personnel who created the lot (optional).
9. Select the **Updated By** personnel who last updated the lot (optional).
10. Enter the **Date** and **Time** of the assessment (optional).
11. Choose the **Location** where the lot is stored from the options "Warehouse A", "Warehouse B", or "Warehouse C" (optional).

## Field-by-Field Explanation

* **Lot Number**: A unique identifier for the inventory lot.
* **Inventory Type**: Classification of the lot as either "Lot" or "Non-inventory".
* **Condition**: The current state of the lot (New, Used, or Refurbished).
* **Quantity**: The number of items in the lot.
* **Value**: The monetary value of the items in the lot.
* **Notes**: Any additional comments or details about the lot.
* **Assigned To**: Select one or multiple personnel responsible for the lot (optional).
* **Created By**: Select one or multiple personnel who created the lot (optional).
* **Updated By**: Select one or multiple personnel who last updated the lot (optional).
* **Date**: The date of the assessment (optional).
* **Time**: The time of the assessment (optional).
* **Location**: The storage location of the lot (optional).
