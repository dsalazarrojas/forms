# Order Cancellation Refund Form - Help Guide
## Purpose
The Order Cancellation Refund Form is used to collect information required for processing order cancellations and refunds.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the "Order Cancellation Refund Form" page.
2. Fill in the "Order Date" field with the date the order was placed.
3. Provide a reason for cancellation in the "reason_for_cancellation" field or select a valid option from the dropdown list.
4. Enter any additional details about the cancellation in the "reason_for_cancellation_other" field if necessary.
5. If relevant, select the reason for cancellation from the "select_reason_for_cancellation" dropdown.
6. Enter the customer's email and phone number in the "customer_email" and "customer_phone" fields respectively.
7. Enter the customer's name in the "customer_name" field.
8. Provide a detailed reason for the cancellation/refund in the "reason_for_cancellation_refund" field.
