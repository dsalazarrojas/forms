# Medal Order Form - Help Guide

## Purpose
This Medal Order Form is used for tracking and managing medal orders. It gathers information related to medals, including their quantity, type, and availability.

## How To Complete This Form
1. Fill in the relevant fields with the required information.
2. For fields with options, select the corresponding value from the list.
3. Make sure to fill in all required fields (indicated by a red asterisk next to the label).
