# Stage Design Quotation Form - Help Guide
## Purpose
This form is designed to capture information related to stage design quotations for events or projects. It helps to document and assign tasks, collect quotations, and track progress.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the Event Planner field with the details of the event.
2. Provide the Stage Designer's contact information in the Stage Designer field.
3. Enter the event details in the Event Details field.
4. Enter the event date in the Event Date field.
5. Enter the event time in the Event Time field.
6. Specify the event location in the Event Location field.
7. Choose the stage type from the Stage Type options.
8. Select whether to include quotation items in the Quotation Items field.
9. Enter the quotation price in the Quotation Price field.
10. Add any quotation notes in the Quotation Notes field.
11. Enter event notes in the Event Notes field.
12. Assign a user to the event in the Assigned User field.
13. Assign a tool to the event in the Assigned Tool field.
14. Enter the name of the user who created the form in the Created By field.
15. Enter the name of the user who updated the form in the Updated By field.
16. Enter the form ID in the Form ID field.
17. Enter the date the form was created in the Created Date field.
18. Enter the date the form was updated in the Updated Date field.
19. Select the category of the event in the Category field.
20. Enter a description of the event in the Description field.
21. Enter the title of the form in the Title field.
22. Upload or link the output file in the Output File field.
23. Enter the name of the assigned tool in the Assigned Tool Name field.
24. Enter the category name in the Category Name field.
25. Enter the description name in the Description Name field.

## Field-by-Field Explanation

* **Event Planner**: Enter the details of the event that you are planning.
* **Stage Designer**: Enter the contact information of the stage designer responsible for the event.
* **Event Details**: Enter any additional details about the event.
* **Event Date**: Enter the date of the event in the format MM/DD/YYYY.
* **Event Time**: Enter the time of the event in the format HH:MM AM/PM.
* **Event Location**: Enter the location of the event.
* **Stage Type**: Select the type of stage required for the event.
* **Quotation Items**: Select whether to include quotation items for the event.
* **Quotation Price**: Enter the price of the quotation for the event.
* **Quotation Notes**: Enter any additional notes about the quotation.
* **Event Notes**: Enter any additional notes about the event.
* **Assigned User**: Assign a user to the event.
* **Assigned Tool**: Assign a tool to the event.
* **Created By**: Enter the name of the user who created the form.
* **Updated By**: Enter the name of the user who updated the form.
* **Form ID**: Enter the unique ID of the form.
* **Created Date**: Enter the date the form was created.
* **Updated Date**: Enter the date the form was updated.
* **Category**: Select the category of the event.
* **Description**: Enter a brief description of the event.
* **Title**: Enter a title for the form.
* **Output File**: Upload or link the output file related to the event.
* **Assigned Tool Name**: Enter the name of the assigned tool.
* **Category Name**: Enter the name of the category.
* **Description Name**: Enter the name of the description.
