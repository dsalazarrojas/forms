# Wedding Package With Price Change - Help Guide
## Purpose
This form is used to collect information from clients about their wedding package preferences and details, including agreement to price changes and selected services.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the client's contact information in the **Client Details** field.
2. Provide the wedding package details in the **Package Details** field.
3. Select **Yes** or **No** for the services you want to include in the package from the **Services** field.
4. Enter the description of the services selected in the **Services Description** field.
5. Enter the new price for the package in the **Price** field.

## Field-by-Field Explanation

### Client Details

* **Client Details** (`wedding_package_with_price_change_client_details`, text, required): Enter the client's name, email, and phone number.

### Package Details

* **Package Details** (`wedding_package_with_price_change_package_details`, text, required): Enter a brief description of the wedding package.

### Agreement

* **Agreement** (`wedding_package_with_price_change_agreement`, select_one, required): Select **Yes** to agree to the price changes, **No** otherwise.

### Services

* **Services** (`wedding_package_with_price_change_services`, select_multiple, required): Select the services you want to include in the package from the available options (**Yes** or **No**).

### Services Description

* **Services Description** (`wedding_package_with_price_change_services_description`, text, optional): Enter a brief description of the selected services.

### Price

* **Price** (`wedding_package_with_price_change_price`, number, required): Enter the new price for the package.

## Tips

* Make sure to select all required fields before submitting the form.
* Double-check the services description for accuracy.
* Enter the correct price in the **Price** field.
