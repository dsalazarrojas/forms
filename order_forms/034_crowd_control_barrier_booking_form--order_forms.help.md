# Crowd Control Barrier Booking Form - Help Guide
## Purpose
This guide helps users complete the Crowd Control Barrier Booking Form successfully.

## How To Complete This Form
To complete this form, follow these steps:
1. Enter your name in the User Name field.
2. Enter your email address in the User Email field.
3. Enter the name of the event in the Event Name field.
4. Enter the date of the event in the Event Date field.
5. Enter the time of the event in the Event Time field.
6. Select the type of event by choosing an option in the Event Type field.
7. Provide event details in the Event Details field.
8. Select the required barrier type(s) in the Barrier Type field.
9. Enter the duration of the booking in the Duration field.
10. Enter the size of the barrier in the Barrier Size field.
11. Enter the cost of the barrier in the Barrier Cost field.
12. If applicable, provide special requests in the Special Request field.
13. Select the method of payment in the Payment Method field.
14. Enter the event location in the Event Location field.
15. Enter your contact phone number in the Contact Phone field.
16. Confirm the booking by selecting an option in the Confirm Booking field.

## Field-by-Field Explanation
### User Name (User Name, text, required: false)
• **User Name**: This field is for identifying you and your organization. Please enter your name accurately.

### User Email (User Email, email, required: false)
• **User Email**: Enter your email address here. This will be used for communication.

### Event Name (Event Name, text, required: false)
• **Event Name**: Enter the name of the event, such as "Concert" or "Conference".

### Event Date (Event Date, date, required: false)
• **Event Date**: Enter the date of the event.

### Event Time (Event Time, time, required: false)
• **Event Time**: Enter the time of the event.

### Event Type (Event Type, select_one, required: false)
• **Event Type**: Select the type of event. For example, "Yes" for a concert or "No" for a conference.

### Event Details (Event Details, note, required: false)
• **Event Details**: Provide any additional information about the event.

### Barrier Type (Barrier Type, select_multiple, required: false)
• **Barrier Type**: Select all the barrier types required for your event. For example, "Yes" for multiple barriers or "No" for a single barrier.

### Booking Date (Booking Date, date, required: false)
• **Booking Date**: Enter the date you would like to book the barrier.

### Duration (Duration, number, required: false)
• **Duration**: Enter the duration of the event.

### Barrier Size (Barrier Size, number, required: false)
• **Barrier Size**: Enter the size of the barrier.

### Barrier Cost (Barrier Cost, number, required: false)
• **Barrier Cost**: Enter the cost of the barrier.

### Special Request (Special Request, note, required: false)
• **Special Request**: If you have any special requests, please describe them here.

### Payment Method (Payment Method, select_multiple, required: false)
• **Payment Method**: Select the method of payment. For example, "Yes" for online payment or "No" for offline payment.

### Event Location (Event Location, text, required: false)
• **Event Location**: Enter the location of the event.

### Contact Phone (Contact Phone, text, required: false)
• **Contact Phone**: Enter your contact phone number.

### Confirm Booking (Confirm Booking, select_one, required: false)
• **Confirm Booking**: Confirm that you would like to book the barrier by selecting "Yes" or "No".

## Tips
- Please ensure that you have all the required information before submitting the form.
- If you have any special requests, please enter them clearly in the Special Request field.
- Double-check the form before submission to avoid any errors.
