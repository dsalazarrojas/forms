# themed_wedding_supply_order_form - Help Guide
## Purpose
This form is used to place orders for themed weddings. It helps the event coordinator gather all the necessary information about the event and the order, including event details, contact information, payment details, and order status.

## How To Complete This Form
To complete this form, simply follow these steps:

1. Fill in the **Event Name** field with the name of the event.
2. Fill in the **Event Date** field with the date of the event.
3. Select the **Theme** of the event from the options provided.
4. Select the **Event Type** of the event from the options provided.
5. Enter the estimated number of **Guests Attending**.
6. Fill in the **Contact First Name**, **Contact Last Name**, and **Contact Email** fields with your contact information.
7. Fill in the **Contact Phone** field with your phone number.
8. Enter any additional **Order Details** in the text area.
9. Select the **Payment Method** from the options provided.
10. Enter the **Payment Amount**.
11. Select the **Event Color Scheme** from the options provided.
12. Fill in the **Event Location**.
13. Enter any additional **Event Notes** in the text area.
14. Fill in the **Vendor** information (if applicable).
15. Enter any additional **Vendor Notes** in the text area.
16. Select the **Order Status** from the options provided.
17. Select the **Payment Status** from the options provided.
18. Enter the number of **Total Items**.
19. Enter any additional **Itemized Items** in the text area.
20. Fill in the **Order Date**.
21. Enter any additional **Order Notes** in the text area.
22. Enter your **Submitted By** name.

## Field-by-Field Explanation

* **Event Name** (`event_name`, text, optional): Enter the name of the event.
* **Event Date** (`event_date`, date, optional): Enter the date of the event.
* **Theme** (`theme`, select_one, optional): Select the theme of the event from the options provided.
* **Event Type** (`event_type`, select_multiple, optional): Select the type of the event from the options provided.
* **Guests Attending** (`guests_attending`, number, optional): Enter the estimated number of guests attending.
* **Contact First Name** (`contact_first_name`, text, optional): Enter your first name.
* **Contact Last Name** (`contact_last_name`, text, optional): Enter your last name.
* **Contact Email** (`contact_email`, email, optional): Enter your email address.
* **Contact Phone** (`contact_phone`, text, optional): Enter your phone number.
* **Order Details** (`order_details`, note, optional): Enter any additional details about the order.
* **Payment Method** (`payment_method`, select_one, optional): Select the payment method from the options provided.
* **Payment Amount** (`payment_amount`, number, optional): Enter the payment amount.
* **Event Color Scheme** (`event_color_scheme`, select_multiple, optional): Select the event color scheme from the options provided.
* **Event Location** (`event_location`, text, optional): Enter the location of the event.
* **Event Notes** (`event_notes`, note, optional): Enter any additional notes about the event.
* **Vendor** (`vendor`, text, optional): Enter the vendor information (if applicable).
* **Vendor Notes** (`vendor_notes`, note, optional): Enter any additional vendor notes.
* **Order Status** (`order_status`, select_one, optional): Select the status of the order from the options provided.
* **Payment Status** (`payment_status`, select_one, optional): Select the payment status from the options provided.
* **Total Items** (`total_items`, number, optional): Enter the total number of items.
* **Itemized Items** (`itemized_items`, note, optional): Enter any itemized items.
* **Order Date** (`order_date`, date, optional): Enter the order date.
* **Order Notes** (`order_notes`, note, optional): Enter any additional order notes.
* **Submitted By** (`submitted_by`, text, optional): Enter your name.
