# Valentine Box Order Form - Help Guide
## Purpose
This form is used to capture order information, customer details, delivery information, payment, and shipping details for Valentine's Day gift delivery orders.

## How To Complete This Form
To fill out this form correctly:

1.  Select the "Order Information" page and fill in the order details.
2.  Proceed to the "Customer Information" page to input the customer's details.
3.  Then move to the "Delivery Information" page for delivery instructions.
4.  Fill out the "Payment Information" page with payment details.
5.  On the "Shipping Options" page, select shipping options for the order.
6.  You can add any special instructions on the "Special Instructions" page.
7.  The "Customer Message" field allows the customer to leave a message for the recipient.
8.  Finally, select the shipping method and cost on the "Shipping Method" page.

## Field-by-Field Explanation

* **Order Information** (`valentine_box_order_form`, text, optional): Enter a brief description of the order.
* **Customer Information** (`customer_info`, text, optional): Enter the customer's details, including name, address, etc.
* **Delivery Information** (`delivery_info`, text, optional): Provide delivery instructions for the order.
* **Payment Information** (`payment_info`, text, optional): Enter the payment details, such as card number and expiry date.
* **Shipping Options** (`shipping_options`, select_multiple, optional): Select one or more shipping options for the order.
* **Special Instructions** (`special_instructions`, note, optional): Add any additional instructions for the order.
* **Customer Message** (`customer_message`, text, optional): A message for the recipient from the customer.
* **Shipping Cost** (`shipping_cost`, number, optional): Enter the shipping cost.
* **Shipping Method** (`shipping_method`, select_one, optional): Select the shipping method for the order.
