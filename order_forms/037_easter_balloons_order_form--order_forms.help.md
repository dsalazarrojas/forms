# Easter Balloons Order Form - Help Guide

## Purpose

This form is used to collect information for an Easter-themed balloon order. The goal is to gather details such as the type of balloons, quantity, and other relevant information required for the order.

## How To Complete This Form

1.  Fill in the details as prompted, ensuring all required fields are completed.
2.  Select the desired balloon type from the available options.
3.  Enter the quantity of balloons needed.
4.  Choose the desired color for the balloons.
5.  Specify the delivery date and time for the order.
6.  Provide customer details and address.
7.  Enter the email address and phone number of the customer.
8.  Add any additional message if required.
9.  Confirm the order details by selecting the correct option.

## Field-by-Field Explanation

* **Easter Balloons Order Form** (Text): This is the title of the form.
* **Order Details** (Text): This field allows you to describe any specific instructions or details for the order.
* **Balloon Type** (Select Multiple): Here, you can select the type of Easter balloons you want to order (e.g., Easter Balloon A, Easter Balloon B, Easter Balloon C).
* **Quantity** (Number): Enter the number of balloons you want to order.
* **Color** (Select One): Choose the desired color for the balloons (e.g., Red, Blue, Green).
* **Delivery Date** (Date): Enter the date when you would like to have the balloons delivered.
* **Delivery Time** (Time): Specify the time for the delivery.
* **Customer Details** (Text): Provide any information about the customer, if required.
* **Address** (Select Multiple): Select the address components (Street, City, State, Zip) for delivery.
* **Email** (Email): Enter the email address of the person responsible for the order.
* **Phone** (Text): Enter the phone number of the person responsible for the order.
* **Message** (Note): If required, provide any additional message for the order.
* **Confirm** (Select Multiple): Select 'True' to confirm the order details.
* **Confirm Message** (Text): If you selected 'True' in the previous field, provide a message confirming the order details.
