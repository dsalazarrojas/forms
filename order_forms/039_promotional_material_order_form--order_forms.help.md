# promotional_material_order_form - Help Guide
## Purpose
This form is used to request promotional materials for internal or external use.

## How To Complete This Form
1. Fill in your user information: Provide your name, company, and contact email.
2. Select the promotional material: Choose the material you are interested in from the available options.
3. Add details about your request: Enter any additional details or comments you have about your request.
4. Complete any other required fields: Ensure you fill in all required fields for accurate and efficient processing.

## Field-by-Field Explanation

* **User name (user_name)**: This is a field used to capture the user's name.
* **Company (company)**: This is a field to record the user's company name.
* **Contact email (contact_email)**: This is a required field to capture the user's email address.
* **Contact phone (contact_phone)**: This is a required field to capture the user's phone number for further communication.
* **Promotional material (promotional_material)**: This is a select-one field used to select the promotional material being requested.
* **Request details (request_details)**: This is a field used to capture any additional information the user wants to include with their request.
* **Additional comments (additional_comments)**: This is a field used for the user to include any further comments about their request.
* **Assigned tool (assigned_tool)**: This is a field used to record the tool assigned to the request.
* **Assigned tool name (assigned_tool_name)**: This is a field used to record the name of the tool assigned to the request.
* **Assigned tool url (assigned_tool_url)**: This is a field used to record the URL of the tool assigned to the request.
* **Created by (created_by)**: This is a field used to capture who created the request.
* **Created date (created_date)**: This is a field used to record the date the request was created.
* **Created time (created_time)**: This is a field used to record the time the request was created.
* **Updated by (updated_by)**: This is a field used to capture who updated the request.
* **Updated date (updated_date)**: This is a field used to record the date the request was updated.
* **Updated time (updated_time)**: This is a field used to record the time the request was updated.
* **Form ID (form_id)**: This is a field used to record the form id.
* **Category (category)**: This is a field used to record the category of the form.
* **Description (description)**: This is a field used to record a description about the form.
* **Form title (form_title)**: This is a field used to record the title of the form.
* **Form output file (form_output_file)**: This is a field used to record the file output of the form.
* **Form assigned tool (form_assigned_tool)**: This is a field used to record the tool assigned to the form.
* **Form assigned tool name (form_assigned_tool_name)**: This is a field used to record the name of the tool assigned to the form.
* **Form assigned tool url (form_assigned_tool_url)**: This is a field used to record the URL of the tool assigned to the form.
* **Assigned jimmy (assigned_jimmy)**: This is a field used to record the name of the jimmy assigned to the form.
