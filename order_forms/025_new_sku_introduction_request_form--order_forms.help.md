# new_sku_introduction_request_form - Help Guide
## Purpose
The "new_sku_introduction_request_form" is a form used to request new stock keeping unit (SKU) introductions. This form helps inventory management teams to gather information about new products and introduce them to the inventory system.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill out the form completely and accurately with the requested information.
2. Ensure all required fields are filled out.
3. Review your submission before submitting it for processing.

## Field-by-Field Explanation

* **product_details**: Enter a brief description of the product, its category, and any other relevant details. This field is required.
* **product_images** (Number): Upload 0-3 images of the product. You can add more images if necessary, but it's not required.
* **product_name**: Enter the name of the product. This field is optional, but it's helpful for search and categorization.

## Tips

* Make sure to upload clear and high-quality images of the product.
* If you're requesting a new SKU for a product that's already in the system, please fill out the form with the existing SKU information and note the reason for the new request.
* If you're unsure about any field, please contact the inventory management team for clarification or guidance.
