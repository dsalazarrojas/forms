# Equipment Rental Approval Form - Help Guide

## Purpose
This form is used to request approval for renting equipment for a specific project. It is essential to fill out the form with accurate and complete information to ensure that your request is processed efficiently.

## How To Complete This Form
1. Fill out the form with the necessary details for the equipment rental request.
2. Make sure to fill out all required fields marked as * (e.g., equipment details, rental date, start date, rental duration, condition, and equipment type).
3. If you are unsure about any field, consult the relevant section below for clarification.

## Field-by-Field Explanation

* **Rental Form** (page 1, <type: text>, required): 
Fill out this field with a short description of the rental request, including the project details and any relevant context.
* **Equipment Details** (page 1, <type: select_one>, required):
Indicate whether the requested equipment is for 'yes' or 'no'. This helps us determine the scope of the request.
* **Rental Date** (page 3, <type: date>, required):
Enter the date you plan to return the equipment.
* **Start Date** (page 3, <type: time>, required):
Enter the start time of the rental period.
* **Rental Duration** (page 3, <type: number>, required):
Specify the length of time you need to rent the equipment.
* **Condition** (page 4, <type: select_one>, required):
Choose the condition of the equipment you are requesting: new, used, certified, or refurbished.
* **Equipment Type** (page 4, <type: select_one>, required):
Select the type of equipment you are requesting: general or specific.
* **Customer** (page 5, <type: select_multiple>, optional):
Select the customer's name, email, or phone number for communication purposes.
* **Employee** (page 5, <type: select_multiple>, optional):
Select the employee's name, role, or phone number for internal coordination.
* **Comments** (page 6, <type: text>, optional):
Add any additional comments or information about the rental request.

## Tips
* Make sure to double-check your information for accuracy before submitting the form.
* If you have any questions or concerns, please don't hesitate to contact us.
