# Video Conversion Request Form - Help Guide
## Purpose

The Video Conversion Request Form is used to request the conversion of a video file from one format to another. This form helps us understand your video conversion needs and ensures that we can deliver the converted file according to your preferences.

## How To Complete This Form

1. Fill out the required fields, marked with an asterisk (\*). The form has two required fields:
	* **File** (`file`, `text`, \*): Enter the file you'd like to convert.
	* **Convert To** (`convert_to`, `select_multiple`, \*): Select the format you'd like to convert the file to.
2. Fill out the optional fields with any additional information you'd like to provide.
	* **Request Information** (`submit_request`, `text`): This is a free-text field for any additional comments or information about your conversion request.
	* **File to Convert** (`file_to_convert`, `select_multiple`): Select the format of the file you'd like to convert (e.g., MP4, MOV, AVI).
	* **File Size** (`file_size`, `number`): If available, select the approximate file size of the file to be converted.
	* **Priority Level** (`priority_level`, `select_one`): Choose the priority level of your conversion request (High, Medium, or Low).
	* **Expected Delivery Time** (`expected_delivery_time`, `date`): If available, select a date for the expected delivery of the converted file.
	* **Contact Information** (`contact_info`, `note`): If you need to contact us for any reason, enter your information in this field.

## Field-by-Field Explanation
### Request Information
* **Request Information**: A field for any additional comments or information about your conversion request.

### File to Convert
* **File to Convert**: Select the format of the file you'd like to convert (e.g., MP4, MOV, AVI).

### File Size
* **File Size**: If you know the approximate file size of the file to be converted, enter it here.

### Convert To
* **Convert To**: Select the format you'd like to convert the file to.

### Priority Level
* **Priority Level**: Choose the priority level of your conversion request (High, Medium, or Low).

### Expected Delivery Time
* **Expected Delivery Time**: If you need the converted file by a specific date, enter it here.

### Contact Information
* **Contact Information**: If you need to contact us for any reason, enter your information in this field.

### File
* **File**: Enter the file you'd like to convert.
