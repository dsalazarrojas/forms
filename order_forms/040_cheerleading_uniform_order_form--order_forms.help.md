## Cheerleading Uniform Order Form - Help Guide

## Purpose

This form is designed to collect information for a cheerleading uniform order. The form is used to gather details about the order, including the parent/guardian's information, athlete's information, and uniform sizing.

## How To Complete This Form

To complete this form, please follow these steps:

1. Fill in the required fields with the corresponding information.
2. Select the athlete's team assignment from the dropdown list.
3. Choose the correct uniform size for each component (skirt, top/shells, briefs/bloomers, and cheer shoes).
4. Enter the contact email for order status updates.
5. If you have any special fitting concerns, such as needing extra length in the skirt, please provide detailed notes in the "Special Fitting Notes" field.
6. Review and confirm that you authorize the order and size selections.

## Field-by-Field Explanation

* **Parent / Guardian Full Name**: Enter the full name of the parent or guardian who is placing the order.
* **Athlete Full Name**: Enter the full name of the athlete who will be wearing the uniform.
* **Contact Email**: Enter a valid email address where you can receive order status updates.
* **Team Assignment**: Select the cheer team the athlete is assigned to (Junior Squad, Varsity Squad, or Elite Competition Team).
* **Skirt Size**: Select the size of the skirt from the available options (Youth S, Youth M, Youth L, Adult XS, Adult S, Adult M, Adult L).
* **Top / Shell Size**: Select the size of the top/shells from the available options (Youth S, Youth M, Youth L, Adult XS, Adult S, Adult M, Adult L).
* **Briefs / Bloomers Size**: Select the size of the briefs/bloomers from the available options (Small, Medium, Large, XL).
* **Cheer Shoe Size**: Enter the size of the cheer shoe (e.g. Womens 7-5, Youth 3).
* **Warm-up Suit Size (Optional)**: If you would like to order a warm-up suit, select the size from the available options (None, Small, Medium, Large, XL).
* **Total Order Amount ($)**: This field is automatically calculated based on your size selections.
* **Payment Confirmation Number**: If you paid for the order through an external portal, enter the confirmation number provided.
* **Special Fitting Notes**: If you have any special fitting concerns, such as needing extra length in the skirt, enter them here.
* **I authorize this order and size selection**: Confirm that you have reviewed and authorize the order and size selections.
* **Order Entry Date**: The date and time the order was placed.
