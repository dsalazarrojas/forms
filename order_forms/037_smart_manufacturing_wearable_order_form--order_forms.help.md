# Smart Manufacturing Wearable Order Form - Help Guide
## Purpose
The Smart Manufacturing Wearable Order Form is a digital order form used by factories to submit orders for wearables. The form collects essential information for order processing and facilitates the delivery of accurate and timely orders.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the factory's name in the "factory_name" field.
2. Provide the factory's address in the "factory_address" field.
3. Enter the contact person's name or title in the "contact" field.
4. Select the delivery date in the "delivery_date" field.
5. Select the delivery time in the "delivery_time" field.
6. Choose the shipping method in the "shipping_method" field.

## Field-by-Field Explanation

* **factory_name** (text): Enter the name of the factory submitting the order. This is a required field and must be filled in.
* **factory_address** (text): Enter the address of the factory submitting the order. This is a required field and must be filled in.
* **contact** (text): Enter the name or title of the person to contact for order details. This is a required field and must be filled in.
* **delivery_date** (date): Select the date on which the order is to be delivered. This is a required field and must be filled in.
* **delivery_time** (time): Select the time on which the order is to be delivered. This is a required field and must be filled in.
* **shipping_method** (text): Choose the method of shipping for the order. This is a required field and must be filled in.

## Tips
- Ensure that all fields are filled in accurately and completely before submitting the form.
- Double-check the fields for errors or inconsistencies before submission.
- Use the form in conjunction with other order forms for efficient order processing.
- Contact the form creators for any queries or issues with the form.
