# Smart Beverage Line Cleaner Order Form - Help Guide
## Purpose
The Smart Beverage Line Cleaner Order Form is designed to collect information for orders related to the Smart Beverage Line Cleaner. This form is crucial for capturing essential details about the order, ensuring accurate processing and timely delivery.

## How To Complete This Form
To complete the form, follow these steps:

1.  Fill out the **Supplier Name** field with the name of the supplier providing the product or service.
2.  Enter the **Contact Email** of the person responsible for the order (optional).
3.  Enter the **Contact Phone** number of the person responsible for the order (required).
4.  Select the **Order Date** for the requested order (required).
5.  Choose the products or services you are requesting from the **Product Request** dropdown (required).
6.  If necessary, add any **Comments** about the order.
7.  Indicate whether the order has been assigned a **Tool** (required).
8.  Select the **User** assigned to the order (required).
9.  Choose the **Status** of the order (required).
10.  Add any **Notes** about the order (optional).
11.  If necessary, indicate if the order was **Submitted By** (optional).
12.  Fill out the **Form Submitted Date** and **Form Submitted Time** fields for the order (required).
13.  If necessary, add any **Customer Comments** (optional).
14.  If necessary, add any **Order Comments** (optional).
15.  Choose whether the delivery was **Confirmed** (optional).
16.  Add any **Delivery Notes** (optional).
17.  Select whether **Payment Terms** apply to the order (required).
18.  Choose the **Payment Method** (required).
19.  If necessary, add any **Payment Notes** (optional).
20.  Indicate whether the order includes a **Billing Address** (required).
21.  Indicate whether the order includes a **Shipping Address** (required).
22.  Choose the **Delivery Status** of the order (required).

## Field-by-Field Explanation
* **Supplier Name** (id: 2, required): Enter the name of the supplier providing the product or service.
*   **Contact Email** (id: 3, optional): Enter the email address of the person responsible for the order.
*   **Contact Phone** (id: 4, required): Enter the phone number of the person responsible for the order.
*   **Order Date** (id: 5, required): Choose the date for the order.
*   **Delivery Date** (id: 6, optional): Choose the date for the delivery.
*   **Product Request** (id: 7, required): Choose the products or services you are requesting from the dropdown.
*   **Comments** (id: 8, optional): Add any comments about the order.
*   **Assigned Tool** (id: 9, required): Indicate whether the order has been assigned a tool.
*   **Assigned User** (id: 10, required): Select the user assigned to the order.
*   **Status** (id: 11, required): Choose the status of the order.
*   **Notes** (id: 12, optional): Add any notes about the order.
*   **Form Submitted By** (id: 13, optional): Indicate if the order was submitted by.
*   **Form Submitted Date** (id: 14, required): Enter the date the form was submitted.
*   **Form Submitted Time** (id: 15, required): Enter the time the form was submitted.
*   **Customer Comments** (id: 16, optional): Add any customer comments.
*   **Order Comments** (id: 17, optional): Add any order comments.
*   **Delivery Confirmation** (id: 18, optional): Indicate whether the delivery was confirmed.
*   **Delivery Notes** (id: 19, optional): Add any delivery notes.
*   **Payment Terms** (id: 20, required): Select whether payment terms apply to the order.
*   **Payment Method** (id: 21, required): Choose the payment method.
*   **Payment Notes** (id: 22, optional): Add any payment notes.
*   **Billing Address** (id: 23, required): Indicate whether the order includes a billing address.
*   **Shipping Address** (id: 24, required): Indicate whether the order includes a shipping address.
*   **Delivery Status** (id: 25, required): Choose the status of the delivery.

## Tips
*   Always fill out all required fields accurately to avoid delays or issues with order processing.
*   Be clear and concise in your comments and notes to help the order's progress.
*   Double-check the form before submitting it to ensure all required fields are filled in correctly.
