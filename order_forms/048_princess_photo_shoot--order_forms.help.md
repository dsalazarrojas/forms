# Princess Photo Shoot - Help Guide
## Purpose
This form is designed to collect information for a photo shoot, specifically a "Princess Photo Shoot". It allows users to input various details about the shoot, including category, description, and other relevant information.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the category of the photo shoot.
2. Input a brief description of the shoot.
3. Enter the photo session details.
4. Select the booking date and time for the photo shoot.
5. Add any additional notes about the shoot.
6. Enter your email address and phone number.
7. Input the form ID and user ID.
8. Enter the user name.
9. Input the form title and description.
10. Select the form category.
11. Assign a tool to the form.
12. Select the output file for the form.
13. Input multiple form IDs.
14. Enter your phone number.
15. Input photo session details 2.
16. Select the booking date and time 2.
17. Enter your phone number 2.
18. Input photo session booking 2.
19. Select the booking time 2.
20. Input photo session booking date 2.
21. Input form ID 2.
22. Input form ID 2 2.
23. Enter your phone number 2.
24. Input photo session details 2 2.

## Field-by-Field Explanation
* **Princess Photo Shoot Form** (`princess_photo_shoot_form`, text, required): This is the main label for the form. It should be completed with the name of the photo shoot.
* **Category** (`category`, select_one, required): Select the category for the photo shoot (e.g., Order Forms, Other Forms).
* **Description** (`description`, text, required): Enter a brief description of the photo shoot.
* **Photo Session Details** (`photo_session_details`, text, required): Enter details about the photo session.
* **Booking Date** (`booking_date`, date, required): Select the date of the photo shoot.
* **Booking Time** (`booking_time`, time, required): Select the time of the photo shoot.
* **Notes** (`notes`, text, required): Add any additional notes about the shoot.
* **Email** (`email`, email, required): Enter your email address.
* **Phone** (`phone`, text, required): Enter your phone number.
* **Form ID** (`form_id`, text, required): Enter the form ID.
* **User ID** (`user_id`, text, required): Enter the user ID.
* **User Name** (`user_name`, text, required): Enter the user name.
* **Form Title** (`form_title`, text, required): Enter the form title.
* **Form Description** (`form_description`, text, required): Enter a description of the form.
* **Form Category** (`form_category`, text, required): Select the category for the form.
* **Assigned Tool** (`assigned_tool`, text, required): Assign a tool to the form.
* **Output File** (`output_file`, text, required): Select the output file for the form.
* **Form IDs** (`form_ids`, text, required): Enter multiple form IDs.
* **User Phone** (`user_phone`, text, required): Enter your phone number.
* **Photo Session Details 2** (`photo_session_details_2`, text, required): Enter details about the photo session 2.
* **Photo Session Booking Date** (`photo_session_booking_date`, date, required): Select the date of the photo session 2.
* **Photo Session Booking Time** (`photo_session_booking_time`, time, required): Select the time of the photo session 2.
* **User Phone 2** (`user_phone2`, text, required): Enter your phone number 2.

* **Photo Session Booking Date 2** (`photo_session_booking_date_2`, date, required): Select the date of the photo session booking 2.
