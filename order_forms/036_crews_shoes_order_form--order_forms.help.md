# Crews Shoes Order Form - Help Guide
## Purpose
This form is used to collect information about an employee's shoe sizes for various sizes 1 through 20.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter your employee information in the "Employee Info" field.
2. Select the correct shoe sizes for your employee from the dropdown menus for "Employee Shoes Size 1" through "Employee Shoes Size 20".
3. Click the "Submit" button to complete the form.

## Field-by-Field Explanation

* **Employee Info** (`employee_info`, text, required): Enter your employee's name, ID, or other identifying information so the form can be associated with your employee.
* **Employee Shoes** (`employee_shoes`, select_multiple, required): Select the correct shoe sizes for your employee. This field is likely a placeholder for multiple shoe size selections.
* **Submit** (`submit_button`, text, required): Click this button to complete and submit the form.

Note: The "Employee Shoes" field is a select_multiple field, which suggests that multiple shoe sizes can be selected, but the field name and description do not match the field type. A more accurate description would be "Select the correct shoe sizes for your employee."
