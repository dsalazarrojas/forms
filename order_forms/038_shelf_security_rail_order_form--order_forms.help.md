# Shelf Security Rail Order Form - Help Guide
## Purpose
The Shelf Security Rail Order Form is a form used to collect information for orders of shelf security rails. It is used to guide the customer through the process of placing an order for safety barriers for shelves.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the retail store where you would like to place the order.
2. Select the shipping details, such as address, city, and ZIP code.
3. Enter the quantity of shelf security rails you would like to order.
4. Choose the payment method, such as credit, cash, or other.
5. Select the shipping method, such as ground, air, or other.
6. If desired, add any additional notes about the order.
7. Enter your email address.
8. Enter your phone number.
9. Review and submit the form.

## Field-by-Field Explanation
### Retail Store (retail_store)
* **Label**: Retail Store
* **Type**: Text Input
* **Required**: No
* This is the store where you would like to place the order. Enter the name of the store where you need the shelf security rails.

### Shipping Details (shipping_details)
* **Label**: Shipping Details
* **Type**: Select Multiple
* **Required**: No
* This field allows you to select how you would like the shelf security rails to be shipped. Options include Shipping to Address, Shipping to City, Shipping to State, and Shipping to ZIP.

### Quantity Ordered (quantity_ordered)
* **Label**: Quantity Ordered
* **Type**: Number Input
* **Required**: No
* This field asks for the amount of shelf security rails you would like to order. Please enter a numerical value.

### Payment Details (payment_details)
* **Label**: Payment Details
* **Type**: Select One
* **Required**: No
* This field allows you to choose the payment method for the order. Options include Credit, Cash, and Other.

### Shipping Method (shipping_method)
* **Label**: Shipping Method
* **Type**: Select Multiple
* **Required**: No
* This field asks for the shipping method you would like to use for the order. Options include Ground, Air, and Other.

### Payment Method (payment_method)
* **Label**: Payment Method
* **Type**: Select One
* **Required**: No
* This field asks for the method of payment you would like to use. Options include Bank Transfer, PayPal, and Other.

### Notes (notes)
* **Label**: Notes
* **Type**: Text Input
* **Required**: No
* This field is an open text area where you can add any additional comments or notes about the order.

### Email (email)
* **Label**: Email
* **Type**: Email Input
* **Required**: No
* This field asks for your email address so that we can contact you if needed.

### Phone Number (phone_number)
* **Label**: Phone Number
* **Type**: Text Input
* **Required**: No
* This field asks for your phone number so that we can contact you if needed.

### Tips
* Make sure to double-check the accuracy of your order before submitting.
* Ensure that you are not duplicating an existing order.
* If you have any questions or concerns, please contact us.
