# Factory Calibration Toolkit Order Form - Help Guide
## Purpose
The Factory Calibration Toolkit Order Form is a tool used to collect order details for the calibration toolkit products. It is designed to gather information about the order, product, user, and delivery details.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the order details in the first section.
2. Provide product information in the second section.
3. Add user information in the third section.
4. Specify delivery details in the last section.

## Field-by-Field Explanation

* **Order Details** (`order_details`, text, required: false): Enter a brief description of the order, including any special instructions or notes.
* **Product Info** (`product_info`, text, required: false): Provide any relevant information about the product being ordered, such as product name, quantity, or configuration.
* **User Info** (`user_info`, text, required: false): Enter any relevant information about the user placing the order, such as name, contact number, or email.
* **Delivery Details** (`delivery_details`, text, required: false): Specify the delivery details, including date, time, and any special instructions.
