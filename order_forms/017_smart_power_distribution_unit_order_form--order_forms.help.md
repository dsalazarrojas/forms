# Smart Power Distribution Unit Order Form - Help Guide
## Purpose

This form is used to collect information for a Smart Power Distribution Unit (PDU) order. The form gathers necessary details for the delivery of the PDU, including contact information, delivery address, and specific delivery times.

## How To Complete This Form

- Follow the instructions below to fill out the form correctly.
- Make sure to fill out all the required fields.
- If a field is not required, feel free to leave it blank or provide optional information.

## Field-by-Field Explanation

* **First Name** (id: 1): Please enter your first name.
	+ Type: text
	+ Required: yes
* **Delivery Address** (id: 2): Enter the address where you'd like to receive your order.
	+ Type: text
	+ Required: no
* **Last Name** (id: 3): Enter your last name.
	+ Type: text
	+ Required: yes
* **Order Description** (id: 4): Briefly describe your order details (optional).
	+ Type: text
	+ Required: no
* **Delivery Time** (id: 6): Enter the exact date you'd like to receive your order.
	+ Type: date
	+ Required: yes
* **Delivery Time Slot** (id: 7): Choose a specific time slot for delivery.
	+ Type: time
	+ Required: yes
* **Delivery Options** (id: 8): Select 'Yes' or 'No' for delivery options (if applicable).
	+ Type: select_one
	+ Required: yes
* **Delivery Time Option2** (id: 9): Select multiple delivery options (if applicable).
	+ Type: select_multiple
	+ Required: yes
* **Contact Information** (id: 10): Enter any additional contact information (optional).
	+ Type: text
	+ Required: no
* **Delivery Location** (id: 11): Enter the location where delivery should occur (optional).
	+ Type: text
	+ Required: no
* **Delivery Time4** (id: 12): Enter any specific delivery time (if applicable).
	+ Type: text
	+ Required: no

Note: Please double-check the required fields to avoid any issues with your order submission.
