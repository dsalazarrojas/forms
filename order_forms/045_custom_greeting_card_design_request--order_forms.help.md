# custom_greeting_card_design_request - Help Guide
## Purpose
The purpose of this form is to collect information for custom greeting card design requests.

## How To Complete This Form
1. Select the type of card you want (Birthday, Holiday, Wedding).
2. Indicate if the occasion is special.
3. Choose the design style of the card (Apple, Banana, Cherry).
4. Add a brief description of the card image.
5. Enter delivery details such as delivery address, zip code, state, city, phone number, and email.
6. Choose the size of the card (A6, A7, A8).
7. Select the shape of the card (Rectangle, Square, Circle).
8. Choose the type of paper used for the card (Recycled, Glossy, Matte).
9. Enter a brief message to be printed on the card.
10. Add a signature to the card with a name and a message.
11. Select the delivery time and date.
12. Add any additional delivery notes.

## Field-by-Field Explanation
* **card_type** (required): Choose the type of card you want (Birthday, Holiday, Wedding).
* **special_occasion** (required): Indicate if the occasion is special.
* **design_style** (optional): Choose the design style of the card (Apple, Banana, Cherry).
* **design_image** (optional): Add a brief description of the card image.
* **delivery_details** (optional): Enter delivery details such as delivery address, zip code, state, city, phone number, and email.
* **delivery_info** (optional): Enter additional delivery information.
* **delivery_address** (optional): Enter the delivery address.
* **delivery_zip** (optional): Enter the zip code of the delivery address.
* **delivery_state** (optional): Enter the state of the delivery address.
* **delivery_city** (optional): Enter the city of the delivery address.
* **delivery_phone** (optional): Enter the phone number of the delivery address.
* **delivery_email** (optional): Enter the email of the delivery address.
* **delivery_time** (optional): Select the delivery time.
* **delivery_date** (optional): Select the delivery date.
* **delivery_notes** (optional): Add any additional delivery notes.
* **card_size** (optional): Choose the size of the card (A6, A7, A8).
* **card_shape** (optional): Select the shape of the card (Rectangle, Square, Circle).
* **paper_type** (optional): Choose the type of paper used for the card (Recycled, Glossy, Matte).
* **card_message** (optional): Enter a brief message to be printed on the card.
* **signature_name** (optional): Add a signature to the card with a name.
* **signature_message** (optional): Add a signature to the card with a message.
* **signature_image** (optional): Add a signature image to the card.
* **delivery_email** (optional): Enter the email of the delivery address.
* **delivery_notes** (optional): Add any additional delivery notes.
