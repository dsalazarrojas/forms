# Appraisal Order Form - Help Guide
## Purpose
This form is used to collect information for ordering an appraisal, which is a valuation assessment of a property's value.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill out the order information.
2. Select the type of property.
3. Select the type of appraisal.
4. Enter the property address.
5. Enter the loan amount.
6. Enter the loan officer name and contact email.
7. Enter the needed-by date.

## Field-by-Field Explanation

* **Order Date**: Enter the date you would like the appraisal to be completed by.
* **Loan Officer Name**: Enter the name of the loan officer assigned to your appraisal order.
* **Contact Email**: Enter the email of the person responsible for contacting you.
* **Property Information**: Enter any additional information about the property.
* **Property Address**: Enter the address of the property to be appraised.
* **City**: Enter the city of the property's location.
* **State**: Enter the state of the property's location.
* **Zip Code**: Enter the zip code of the property's location.
* **Type of Property**: Select the type of property (e.g. Single Family, Condo, Townhouse, etc.).
* **Type of Appraisal**: Select the type of appraisal you need (e.g. Full Appraisal, Limited Appraisal, etc.).
* **Loan Amount**: Enter the loan amount for which the appraisal is needed.
* **Purchase Price or Current Value**: Enter the purchase price or current value of the property (optional).
* **Special Instructions**: Enter any special instructions or notes for the appraiser.
* **Needed By Date**: Enter the date by which you need the appraisal to be completed.
