# Transaction Status Inquiry Form - Help Guide
## Purpose
This form is used to inquire about the status of a transaction. It helps in retrieving information about a specific transaction.

## How To Complete This Form
To complete this form, follow these steps:
1. Enter the Transaction ID of the transaction you want to inquire about.
2. Choose the Transaction Date and Time of the transaction you want to inquire about.
3. Select the status of the transaction from the options provided.
4. Enter any additional information or message about the transaction.
5. Choose whether or not to submit the form.
6. Select the category and assigned tool for the transaction, if applicable.

## Field-by-Field Explanation
- **Transaction ID** (`transaction_id`, number, required): Enter the unique ID of the transaction you want to inquire about.
- **Transaction Date** (`transaction_date`, date, required): Enter the date of the transaction.
- **Transaction Time** (`transaction_time`, time, required): Enter the time of the transaction.
- **Transaction Status** (`transaction_status`, select one, required): Choose the current status of the transaction from the options: Processing, Successful, Failed.
- **Transaction Message** (`transaction_message`, text, optional): Enter any additional information or message about the transaction.
- **Submit** (`form_submit`, select one, required): Choose whether to submit the form or not.
- **Category** (`form_category`, select one, optional): Choose the category of the form from the options: Order Forms, Other.
- **Assigned Tool** (`assigned_tool`, select one, optional): Select the assigned tool for the transaction from the options: chatjimmy, chatjimmy2.
 
## Tips
- Make sure to fill out all the required fields correctly to ensure a successful submission.
- Double-check the Transaction Status option to ensure it accurately reflects the current status of the transaction.
- If you're not sure about any field, contact the relevant department for assistance.
- This form is meant to be used by authorized users only, so please refrain from sharing it with non-authorised users.
