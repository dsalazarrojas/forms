# Factory Production Counter Device Order Form - Help Guide
## Purpose
The Factory Production Counter Device Order Form is a tool for users to record and track factory production counter data. By filling out this form, you'll be able to gather crucial information for efficient production and delivery processes.

## How To Complete This Form
To fill out this form, follow these steps:

1. **Customer Information**
	* Enter the Customer Name in the first field.
	* Enter the Contact Email of the customer in the second field.
2. **Order Details**
	* Select the Order Type from the drop-down menu.
	* Enter the Production Date.
3. **Product Specifications**
	* Enter the Serial Number of the device (if applicable).
	* Provide a brief description of the device.
	* Select the Quantity of devices to be produced.
4. **Production Information**
	* Enter the Production Location.
	* Enter any additional Production Notes.
5. **Delivery and Status**
	* Enter the Delivery Date.
	* Select the Order Status and Production Status.
6. **Additional Information**
	* Enter any relevant Customer Notes.
	* Enter the Device Model.
	* Enter the Customer PO (if applicable).
	* Add any additional Notes.

## Field-by-Field Explanation

* **Customer Name**: Enter the name of the customer who ordered the device.
* **Contact Email**: Enter the email address of the customer's contact person.
* **Order Type**: Select the type of order from the drop-down menu.
* **Production Date**: Enter the date when the device was produced.
* **Serial Number**: Enter the serial number of the device (if applicable).
* **Device Description**: Provide a brief description of the device.
* **Quantity**: Enter the number of devices to be produced.
* **Production Location**: Enter the location where the device was produced.
* **Customer Notes**: Enter any additional notes or comments from the customer.
* **Device Model**: Enter the model of the device being produced.
* **Customer PO**: Enter any purchase order information for the customer.
* **Notes**: Enter any additional notes or comments about the order.

**Tips:** Make sure to double-check all information for accuracy, as incorrect data can cause delays in production and delivery. If you're unsure about any field, please contact the relevant production team for clarification.
