# Store Inspection Checklist Order Form - Help Guide
## Purpose
This form is used to order and plan store inspections, allowing you to coordinate and track the inspection schedule and details.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the required fields with the relevant information.
2. Select the correct options for each field, such as the location and preferred date for the inspection.
3. Complete the checklist items that apply to the inspection.
4. Add any additional notes or comments about the inspection or order.

## Field-by-Field Explanation

* **Store Inspection Checklist Form**: This is the title of the form, and is required.
* **Contact Details**: Enter the contact information for the person who will be conducting the inspection, including their name, phone number, and email.
	+ Enter the contact person's name
	+ Enter their phone number
	+ Enter their email address
* **Location**: Enter the location of the store that will be inspected.
* **Start Time**: Enter the expected start time of the inspection.
* **End Time**: Enter the expected end time of the inspection.
* **Order Date**: Enter the date of the order for the inspection.
* **Preferred Date**: Select a preferred date for the inspection.
* **Store Inspections Checklist**: Select the checklist items that apply to the inspection.
* **Store Inspection Checklist Order Notes**: Add any additional notes about the inspection order.
* **Store Inspection Checklist Notes**: Add any notes about the inspection checklist.
* **Contact Person Notes**: Add any notes about the contact person.
* **Order Form Notes 2**: Add any additional notes about the order form.
* **Submit Button 3**: This is the final submit button for the form.
* **Review**: This field is not required, but can be used to add any additional notes or comments about the inspection.
