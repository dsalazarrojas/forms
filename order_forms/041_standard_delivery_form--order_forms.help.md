# Standard Delivery Form - Help Guide
## Purpose
The Standard Delivery Form is designed to capture essential details for delivering goods or services to customers. This form helps in ensuring that all necessary information is provided to facilitate a smooth and efficient delivery process.

## How To Complete This Form
To complete the form, follow these steps:

1. Start by providing the **Delivery Details** (Field 1) with the required information for the delivery.
2. Enter the **Customer Details** (Field 2) with the relevant customer information.
3. Fill in the **Delivery Address** (Field 3) with the address where the delivery will be made.
4. Enter the **Delivery Date** (Field 4) and **Delivery Time** (Field 5) if they are relevant.
5. Provide a **Customer Message** (Field 6) if you need to convey any specific information to the customer.
6. Enter the **Customer Email** (Field 7) and **Customer Phone** (Field 8) if they are provided.
7. Add any **Customer Note** (Field 9) if needed.
8. Select the **Delivery Status** (Field 10) from the options provided.
9. Add any additional **Delivery Status Note** (Field 11) if necessary.
10. Optionally, you can provide **Delivery Date Optional** (Field 12), **Delivery Time Optional** (Field 13), **Customer Message Optional** (Field 14), **Customer Email Optional** (Field 15), **Customer Phone Optional** (Field 16), **Customer Note Optional** (Field 17), and **Assigned To** (Field 18) if required or applicable.

## Field-by-Field Explanation

* **Delivery Details** (Field 1, **text**, required): Enter the necessary details for the delivery.
* **Customer Details** (Field 2, **text**, required): Provide the relevant customer information, such as name and contact details.
* **Delivery Address** (Field 3, **text, required): Enter the address where the delivery will be made.
* **Delivery Date** (Field 4, **date, required): Enter the date for the delivery if it's not already filled in.
* **Delivery Time** (Field 5, **time, required): Enter the time for the delivery if it's not already filled in.
* **Customer Message** (Field 6, **note, required): Enter any specific information for the customer.
* **Customer Email** (Field 7, **email, required): Enter the customer's email address.
* **Customer Phone** (Field 8, **text, required): Enter the customer's phone number.
* **Customer Note** (Field 9, **note, required): Add any additional customer information.
* **Delivery Status** (Field 10, **select_one, required): Select the status of the delivery from the provided options.
* **Delivery Status Note** (Field 11, **note, required): Add any additional information about the delivery status.
* **Delivery Date Optional** (Field 12, **date, required): Enter the delivery date if not already filled in.
* **Delivery Time Optional** (Field 13, **time, required): Enter the delivery time if not already filled in.
* **Customer Message Optional** (Field 14, **note, required): Enter any additional customer information.
* **Customer Email Optional** (Field 15, **email, required): Enter the customer's email address if not already provided.
* **Customer Phone Optional** (Field 16, **text, required): Enter the customer's phone number if not already provided.
* **Customer Note Optional** (Field 17, **note, required): Add any additional customer information if not already filled in.
* **Assigned To** (Field 18, **select_one, required): Select who is responsible for the delivery.
* **Delivery Status Note** (Field 11, **note, required): Add any additional information about the delivery status if not already filled in.
* **Order Form ID** (Field 19, **text, required): Enter the order form ID.
* **Delivery Form ID** (Field 20, **text, required): Enter the delivery form ID.
* **Order Form Version** (Field 21, **text, required): Enter the order form version.
* **Form Version** (Field 22, **text, required): Enter the form version.
* **Form ID** (Field 23, **text, required): Enter the form ID.
* **Output File** (Field 24, **text, required): Enter the output file name.

Note: The required fields are marked as "required" in the form and should be filled in accordingly. Optional fields can be filled in if needed but are not mandatory.
