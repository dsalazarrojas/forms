# Custom Button Badge Quotation Request - Help Guide
## Purpose
The Custom Button Badge Quotation Request form is used to collect information for creating a custom button badge quotation request. This form will guide you through the necessary steps to provide the required details for your quotation request.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the required fields marked with an asterisk (\*) to ensure that your quotation request is complete.
2. Provide accurate and detailed information in each field.
3. Review your form before submitting it to ensure that all required fields are filled out.

## Field-by-Field Explanation
* **Custom Button Badge Quotation Requester** (`custom_button_badge_quotation_requester`, text, required*): Enter your company name or department name.
* **Quote Requester** (`quote_requester`, text, required*): Enter your name or the name of the person making the request.
* **Contact Info** (`contact_info`, text, required*): Enter your contact information, such as email and phone number.
* **Delivery Date** (`delivery_date`, date, required*): Enter the date you would like to receive the delivery of the custom button badge.
* **Delivery Time** (`delivery_time`, time, required*): Enter the time you would like to receive the delivery of the custom button badge.
* **Quantity** (`quantity`, number, required*): Enter the quantity of custom button badges you would like to order.
* **Material** (`material`, text, required*): Enter the type of material you would like to use for the custom button badge.
* **Colors** (`colors`, select_multiple, optional): Select the colors you would like to use for the custom button badge (e.g., Black, White, Red, Blue).
* **Font Sizes** (`font_sizes`, select_multiple, required*): Select the font sizes you would like to use for the custom button badge text (e.g., 12pt, 14pt, 16pt, 18pt).
* **Fonts** (`fonts`, select_multiple, required*): Select the fonts you would like to use for the custom button badge text (e.g., Arial, Times New Roman, Courier).
* **Paper Types** (`paper_types`, select_multiple, required*): Select the paper types you would like to use for the custom button badge (e.g., Glossy, Matte, Semi-gloss).
* **Finishes** (`finishes`, select_multiple, required*): Select the finishes you would like to use for the custom button badge (e.g., Spot varnish, Foil stamping, Laser).
* **Custom Request Comments** (`custom_request_comments`, text, required*): Enter any additional comments or notes about your custom request.
* **Custom Requester** (`custom_requester`, text, required*): Enter your company name or department name.
* **Custom Requester Phone** (`custom_requester_phone`, text, required*): Enter your phone number.
* **Delivery Address** (`delivery_address`, text, required*): Enter the delivery address.
* **Follow Up Email** (`follow_up_email`, email, optional): Enter the email address for follow-up communications.
* **Follow Up Phone** (`follow_up_phone`, text, optional): Enter the phone number for follow-up communications.
* **Follow Up Notes** (`follow_up_notes`, text, optional): Enter any follow-up notes.
* **Notes** (`notes`, text, optional): Enter any additional notes about your custom request.

Note: The asterisk (\*) indicates a required field.
