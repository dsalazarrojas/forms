# Beverage Packaging Requisition Form - Help Guide
## Purpose

The Beverage Packaging Requisition Form is used to create new packaging orders for various types of beverages. This form gathers necessary information for packaging production, including packaging type, specification, quantity, and required delivery date. 

## How To Complete This Form

1. Enter your name and contact information at the top of the form.
2. Select your department and company information for the order.
3. Enter the delivery address details for the packaging.
4. Choose the packaging type and beverage type needed.
5. Specify the quantity and packaging specifications required.
6. Select the required delivery date and urgency level for the order.
7. If this order requires manager approval, select Yes and enter the approver's name.
8. Add any special instructions or additional comments.
9. Review and submit the form for processing.

## Field-by-Field Explanation

* **Your Name (text)** (`requester_name`, required): Enter your full name to help us contact you with order updates.
* **Email Address (email)** (`requester_email`, required): Your email address will receive order confirmation and updates.
* **Phone Number (text)** (`requester_phone`, required): Enter your phone number for coordination with our team.
* **Department (select_one)** (`department`, required): Select the department this order is for from the list provided.
* **Company Name (text)** (`company_name`, required): Enter your company or facility name.
* **Delivery Address (text)** (`delivery_address`, required): Enter the full delivery address for the packaging.
* **City (text)** (`city`, required): Enter the city for the delivery address.
* **State (text)** (`state`, required): Enter the state for the delivery address.
* **Postal Code (text)** (`postal_code`, required): Enter the postal code for the delivery address.
* **Packaging Type Needed (select_one)** (`packaging_type`, required): Select the packaging type needed for the order from the list provided.
* **Beverage Type (select_one)** (`beverage_type`, required): Select the type of beverage this packaging is for from the list provided.
* **Quantity Needed (number)** (`quantity`, required): Enter the number of units needed for the order.
* **Packaging Specifications (text)** (`specifications`, required): Describe the size, material, color, and other specifications required for the order.
* **Required Delivery Date (date)** (`required_date`, required): Select the date when the packaging is needed.
* **Urgency Level (select_one)** (`urgency_level`, required): Select the urgency level of this order from the options provided.
* **Budget Code (text)** (`budget_code`, optional): Enter your internal budget code or account code.
* **Is Approval Required (select_one)** (`approval_required`, required): If this order requires manager approval, select Yes and enter the approver's name.
* **Approver Name (text)** (`approver_name`, optional): Enter the name of the approving manager.
* **Special Instructions (text)** (`special_instructions`, optional): Add any special requirements or notes for this order.
* **Additional Comments (text)** (`additional_comments`, optional): Add any other relevant information about this requisition.

## Tips

- Make sure to review the form carefully before submitting to ensure all required fields are filled.
- Double-check the packaging type and specifications for accuracy.
- Select the correct urgency level for your order.
- If this order requires approval, make sure to enter the approver's name correctly.
