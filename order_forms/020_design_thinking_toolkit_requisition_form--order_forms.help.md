# design_thinking_toolkit_requisition_form - Help Guide
## Purpose
The design thinking toolkit requisition form is used to request tools from the design thinking toolkit. This form helps team members to keep track of the tools requested and their status.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the requester who is submitting the request.
2. Enter the name of the tool you need.
3. Provide a brief description of the tool you need.
4. If the tool is available online, provide the link to access it.
5. Select the type of tool you need (e.g., Sketch, Figma, Adobe).
6. Select the category of the tool you need (e.g., UX, UI/UX, Visual Design, Branding).
7. If you know the version of the tool, provide it.
8. Select the current status of the tool (e.g., Available, Out of stock, Not Available).
9. If you need the tool urgently, select the order date and time.
10. If you need multiple tools, enter the quantity you need.
11. If you know the price of the tool, enter it.
12. If the tool is already assigned to someone else, provide their name.
13. If you have any comments or notes about the tool, provide them.
14. Finally, select how you want to submit the request (e.g., submit, save as draft, save and submit).

## Field-by-Field Explanation
* **Requester**: Enter the name of the person or team that is requesting the tool.
* **Tool Name**: Enter the name of the tool you need (e.g., Figma, Adobe Illustrator).
* **Description**: Provide a brief description of what the tool is used for.
* **Tool Link**: If the tool is available online, provide the link to access it.
* **Tool Type**: Select the type of tool you need (e.g., Sketch, Figma, Adobe).
* **Tool Category**: Select the category of tool you need (e.g., UX, UI/UX, Visual Design, Branding).
* **Tool Version**: If you know the version of the tool, enter it.
* **Tool Status**: Select the current status of the tool (e.g., Available, Out of stock, Not Available).
* **Order Date**: If you need the tool urgently, select the date you need it by.
* **Order Time**: If you need the tool urgently, select the time you need it by.
* **Order Quantity**: Enter the quantity of tools you need.
* **Order Price**: If you know the price of the tool, enter it.
* **Assigned Tool**: If the tool is already assigned to someone else, provide their name.
* **Comments**: Provide any additional comments or notes about the tool.
* **Submit**: Select how you want to submit the request (e.g., submit, save as draft, save and submit).
* **Cancel**: Select how you want to cancel the request (e.g., cancel, save as draft).
* **Save and Submit**: Select how you want to save and submit the request (e.g., save and submit).
* **Save as Draft**: Select how you want to save the request as a draft (e.g., yes, no).
* **Save and Preview**: Select how you want to save and preview the request (e.g., yes, no).
* **Save**: Select how you want to save the request (e.g., yes, no).
* **Preview**: Select how you want to preview the request (e.g., yes, no).
