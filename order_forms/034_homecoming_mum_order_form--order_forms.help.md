# Homecoming Mum Order Form - Help Guide
## Purpose
This form is designed to collect information from customers for a homecoming mum order. Please fill out the form to provide the necessary details for the order.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the form completely and accurately.
2. Make sure to provide all required information.
3. Review your answers for any errors before submitting.

## Field-by-Field Explanation
* **customer_info** (customer_info, text, required:false):
	+ This field is used to collect basic customer information.
* **event_details** (event_details, text, required:false):
	+ Provide the event details for the mum order.
* **delivery_info** (delivery_info, text, required:false):
	+ Please provide delivery information.
* **payment_info** (payment_info, text, required:false):
	+ Please provide payment information.
