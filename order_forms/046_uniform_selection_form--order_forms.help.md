# Uniform Selection Form - Help Guide
## Purpose
The Uniform Selection Form is used to select uniform-related information for an order. This form is designed to guide the user in specifying the type of uniform, its size, style, quantity, and color.

## How To Complete This Form
To complete this form, follow the steps below:
1. Review each page carefully to ensure you have all necessary information.
2. Select the options for each field as required.
3. Click the "Submit" button to submit your selection.

## Field-by-Field Explanation
### Uniform Size
* **Uniform Size** (`Yes`, `No`, required: false): This field allows you to select the type of uniform size you need (e.g., S, M, L, XL). Choose 'Yes' if you need a uniform with a specific size.
### Style
* **Style** (`Yes`, `No`, required: false): This field allows you to select the style of the uniform (e.g., casual, formal, sports).
### Quantity
* **Quantity** (`number`, required: false): This field is for specifying the number of uniforms you need.
### Color
* **Color** (`Yes`, `No`, required: false): This field allows you to select the color of the uniform (e.g., red, blue, black).
 
## Tips
* Make sure to review each field carefully before submitting your selection.
* Ensure that you have provided all necessary information before clicking the "Submit" button.
* If you have any questions or concerns, please contact your administrator for assistance.
