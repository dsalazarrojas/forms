# Obituary Order Form - Help Guide
## Purpose
This form is designed to collect information about an individual's obituary order, ensuring that all necessary details are gathered efficiently and accurately.

## How To Complete This Form
To complete this form, simply follow these steps:
1. Enter the funeral home name in the `Funeral Home` field.
2. Select the type of obituary to be published from the `Obituary Type` field.
3. Enter a description of the deceased in the `Obituary Text` field.
4. If applicable, include the date of death and date of birth of the deceased.
5. List any additional fields for the obituary in the `Additional Fields` field.
6. Indicate whether any funeral homes are involved by selecting the relevant options in the `Funeral Homes` field.

## Field-by-Field Explanation
* **Funeral Home**: Enter the name of the funeral home involved with the deceased's service. This will help us process the order correctly.
* **Funeral Director**: Enter the name of the funeral director handling the service.
* **Obituary Type**: Choose the type of obituary you would like to publish for the deceased, whether it's a Standard Obituary, Obituary with Photo, or Obituary with Eulogy.
* **Obituary Text**: Provide a description of the deceased, including any relevant details or memories you'd like to share.
* **Date of Death**: Enter the date of death of the deceased, if known.
* **Date of Birth**: Enter the date of birth of the deceased, if known.
* **Additional Fields**: If you have any additional information or fields you'd like to include in the obituary, enter them here. This could include, for example, the name of any pallbearers or the location of the service.
* **Funeral Homes**: Indicate whether the following funeral homes are involved in the service: 
  * Yes: The funeral home is involved.
  * No: The funeral home is not involved.
