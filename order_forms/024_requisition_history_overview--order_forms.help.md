# requiision_history_overview - Help Guide
## Purpose
The "Requisition History Overview" form is used to track and view the status of requisitions. It allows users to select multiple requisitions, view their respective requisition numbers, dates, approved amounts, and status. This form is essential for administrators to have a comprehensive overview of all requisitions.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the requisitions you want to view by choosing "Yes" or "No" for each option under "Requisitions".
2. Review the selected requisition numbers, dates, and approved amounts.
3. Check the status of each selected requisition (Approved, Pending, or Rejected).

## Field-by-Field Explanation
* **Requisitions** (`requiision_history_overview`, select_multiple, not required): Select multiple requisitions you want to view.
* **Requisition Number** (`requisition_number`, number, not required): The unique identifier for each requisition.
* **Requisition Date** (`requisition_date`, date, not required): The date when the requisition was created.
* **Approved Amount** (`approved_amount`, number, not required): The amount approved for each requisition.
* **Status** (`status`, select_one, not required): The current status of each selected requisition (Approved, Pending, or Rejected).
* **Notes** (`notes`, note, not required): Additional comments or notes about each requisition.

## Tips
* Make sure to select only the requisitions you want to view for an accurate overview.
* Review each field carefully to ensure the information is accurate and up-to-date. 
* Use the "Requisitions" field to focus on specific requisitions of interest.
