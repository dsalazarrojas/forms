# Shipping Carton Size Test Order Form - Help Guide
## Purpose
The Shipping Carton Size Test Order Form is a test order form used for testing the delivery process. It should not be used for actual delivery purposes.

## How To Complete This Form
To complete this form, follow the steps below:

1. Choose whether to test the shipping carton size or not.
2. Select the delivery date and time you would like to receive the test order.
3. Enter your contact number so we can reach out to you.
4. Provide details about the test carton.
5. Answer the series of yes or no questions about the test carton sizes.
6. Enter the delivery address, city, state, zip code, and country where you would like to receive the test order.
7. Answer any additional yes or no questions about the test carton sizes.
