# Spark Plug Socket Extension Order Form - Help Guide

## Purpose

The Spark Plug Socket Extension Order Form is designed to collect essential information from customers for the purpose of ordering spark plug socket extensions. This form helps ensure that all necessary details are gathered accurately and efficiently, allowing for smooth processing and fulfillment of orders.

## How To Complete This Form

To complete this form, follow these steps:

1.  Enter your shop's name in the **Shop Name** field.
2.  Provide your shop's address in the **Address** field (optional).
3.  Select the **Date** of the order.
4.  Choose the **Time** of the order.
5.  Select the type of order from the **Type** field (Spark Plugs or Socket Extensions).
6.  Enter the **Quantity** of the item ordered.
7.  Enter your **Email** address for contact.
8.  Enter your **Phone Number** for easy contact.
9.  Provide your **Customer Name**.
10. Enter any additional **Customer Notes** regarding the order.
11. If applicable, enter any **Shop Notes** regarding the shop's status.

## Field-by-Field Explanation

- **Shop Name** (`shop_name`, text, required): This field is used to enter your shop's name.
- **Address** (`shop_address`, text, optional): This field is used to enter your shop's address, if applicable.
- **Date** (`order_date`, date, required): Enter the date of the order.
- **Time** (`order_time`, time, required): Select the time of the order.
- **Type** (`product_type`, select_one, required): Select from the options "Spark Plugs" or "Socket Extensions" to choose the type of order.
- **Quantity** (`quantity`, number, required): Enter the quantity of the item ordered.
- **Email** (`email`, email, required): Enter your email address for easy contact.
- **Phone Number** (`phone_number`, text, required): Enter your phone number for easy contact.
- **Customer Name** (`customer_name`, text, required): Enter your customer's name.
- **Customer Note** (`customer_note`, note, optional): This field is used for customers to add any additional comments regarding the order.
- **Shop Note** (`shop_note`, note, optional): This field is used for the shop to add any additional comments regarding the customer or order.
- **Assigned Tool** (`assigned_tool`, select_one, required): Select the tool assigned to the order from the options "chatjimmy" or "Other".
- **Order Form ID** (`order_form_id`, text, optional): This field is used for internal use and is not required for customer information.
- **Shop Category** (`shop_category`, text, optional): This field is used for shop categorization but is not required for order processing.
- **Shop Description** (`shop_description`, text, optional): This field is used for shop description and is not required for order processing.
- **Shop Subcategory** (`shop_subcategory`, text, optional): This field is used for shop sub-categorization but is not required for order processing.
- **Shop Status** (`shop_status`, select_one, optional): This field is used for shop status but is not required for order processing.
- **Shop Priority** (`shop_priority`, select_one, optional): This field is used for shop priority but is not required for order processing.
- **Shop URL** (`shop_url`, text, optional): This field is used for shop URL but is not required for order processing.
- **Shop Domain** (`shop_domain`, text, optional): This field is used for shop domain but is not required for order processing.
- **Spark Plug Type** (`spark_plug_type`, text, optional): This field is used for spark plug type but is not required for order processing.
- **Customer URL** (`customer_url`, text, optional): This field is used for customer URL but is not required for order processing.
- **Shop Email** (`shop_email`, email, optional): This field is used for shop email but is not required for order processing.
- **Shop Phone Number** (`shop_phone_number`, text, optional): This field is used for shop phone number but is not required for order processing.
- **Shop Notes** (`shop_notes`, note, optional): This field is used for shop notes but is not required for order processing.
