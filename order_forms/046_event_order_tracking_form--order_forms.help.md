# Event Order Tracking Form - Help Guide

## Purpose
The Event Order Tracking Form is designed to collect information related to events, including event details, attendee information, payment status, specific requests, and other relevant data. This form aims to streamline the tracking and management of event orders, providing a structured platform for users to submit their event-related requests or details.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the required fields with the necessary information for the event order.
2. Make sure to include all relevant details, such as event date, time, and event organizer.
3. Choose the correct payment status (pending, confirmed, canceled) and payment method.
4. Specify any specific requests or requirements for the event order.
5. Review and submit the form once complete.

## Field-by-Field Explanation

* **Event Order Details** (`event_order_details`, text, required/optional): Enter a brief description of the event order.
* **Attendee Info** (`attendee_info`, text, required/optional): Enter the information of the attendee(s) for the event.
* **Payment Status** (`payment_status`, text, required/optional): Select the current status of the payment (pending, confirmed, canceled).
* **Specific Requests** (`specific_requests`, text, required/optional): Enter any specific requests or requirements for the event order.
* **Event Date** (`event_date`, date, required/optional): Enter the date of the event.
* **Event Time** (`event_time`, time, required/optional): Enter the time of the event.
* **Event Organizer** (`event_organizer`, text, required/optional): Enter the name of the event organizer.
* **Email** (`email`, email, required/optional): Enter the email address of the attendee or event organizer.
* **Phone** (`phone`, text, required/optional): Enter the phone number of the attendee or event organizer.
* **Note** (`note`, note, required/optional): Enter any additional notes or comments for the event order.
* **Order Status** (`order_status`, select multiple, required/optional): Select the current status of the event order (pending, confirmed, canceled).
* **Assigned Tool** (`assigned_tool`, select one, required/optional): Choose the tool assigned to the event (chatjimmy, Other).
* **Form ID** (`form_id`, number, required/optional): Enter a unique identifier for the form.
* **Output File** (`output_file`, text, required/optional): Enter the name of the output file for the event order.
* **Category** (`category`, text, required/optional): Enter the category of the event.
* **Description** (`description`, text, required/optional): Enter a description of the event.
* **Tags** (`tags`, text, required/optional): Enter any relevant tags for the event.
* **Title** (`title`, text, required/optional): Enter a title for the event.
* **Event Order Date** (`event_order_date`, date, required/optional): Enter the date of the event order.
* **Event Order Time** (`event_order_time`, time, required/optional): Enter the time of the event order.
* **Event Order Status** (`event_order_status`, select multiple, required/optional): Select the current status of the event order (pending, confirmed, canceled).
* **Payment Method** (`payment_method`, text, required/optional): Enter the method of payment.
* **Payment Amount** (`payment_amount`, number, required/optional): Enter the amount paid for the event.
* **Order Number** (`order_number`, number, required/optional): Enter a unique order number for the event.
* **Assigned Tool 2** (`assigned_tool2`, select one, required/optional): Choose a second tool assigned to the event (chatjimmy, Other).

Note: Some fields are not strictly required, but are recommended for complete event tracking and management. Review each field carefully and fill out only what is necessary for your event order.
