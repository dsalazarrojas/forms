# resistor_array_termination_order_form - Help Guide
## Purpose
The resistor_array_termination_order_form is used to collect order and termination details for resistor arrays. It's essential to complete this form accurately to ensure proper processing and delivery of the ordered items.


## How To Complete This Form
1. Select a customer to fill out the customer information section.
2. Provide order details in the order details section.
3. Choose the array type from the available options (single or array).
4. Select the termination type (Solderable or Waveguide).
5. Enter the termination date in the date field.
6. Specify the resistor value for the order.
7. If needed, add any additional notes about the order.

## Field-by-Field Explanation
* **customer_info (customer_info, text, required)**: Enter the customer's name or organization to identify who is placing the order.
* **order_details (order_details, text, optional)**: Add any additional information about the order if required.
* **array_type (array_type, select_multiple, required)**: Choose whether the order is for a single or array resistor.
* **termination_type (termination_type, select_one, required)**: Select the termination type as Solderable or Waveguide.
* **date (date, date, required)**: Enter the date for the termination order.
* **resistor_value (resistor_value, number, required)**: Specify the value of the resistor required for the order.
* **notes (notes, note, optional)**: Add any additional comments or notes about the order, if needed.
