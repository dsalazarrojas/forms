# hvac_system_requisition_form - Help Guide
## Purpose
The hvac_system_requisition_form is a form used to submit a formal request for the installation or modification of a heating, ventilation, and air conditioning system in a building.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the form with the required information.
2. Select the correct system type (Cooling, Heating, or Both).
3. Choose the system size (Small, Medium, or Large).
4. Select the temperature range for the system.
5. Choose the installation location (Office, Home, or Restaurant).
6. Enter the date of the intended installation.
7. Enter the time of the intended installation.
8. Provide any additional system requirements.
9. Enter the contact person's name.
10. Enter the contact person's phone number.
11. Enter the contact person's email.

## Field-by-Field Explanation
* **Requisition Details** (`id: 1`, `label: Requisition Details`): This section is intended to provide a short description of the reason for the requisition.
* **System Type** (`id: 2`, `label: System Type`): Select the type of system you are requesting (Cooling, Heating, or Both).
* **System Size** (`id: 3`, `label: System Size`): Choose the size of the system you require (Small, Medium, or Large).
* **Temperature Range** (`id: 4`, `label: Temperature Range`): Select the temperature range for the system (Low Temperature, High Temperature, or Neutral).
* **Installation Location** (`id: 5`, `label: Installation Location`): Choose the location where the system will be installed (Office, Home, or Restaurant).
* **Installation Date** (`id: 6`, `label: Installation Date`): Enter the date of the intended installation.
* **Installation Time** (`id: 7`, `label: Installation Time`): Enter the time of the intended installation.
* **System Requirements** (`id: 8`, `label: System Requirements`): Provide any additional requirements for the system.
* **Contact Person** (`id: 9`, `label: Contact Person`): Enter the name of the person to contact.
* **Contact Number** (`id: 10`, `label: Contact Number`): Enter the phone number of the contact person.
* **Contact Email** (`id: 11`, `label: Contact Email`): Enter the email of the contact person.
* **Additional Comments** (`id: 12`, `label: Additional Comments`): Provide any additional comments or notes about the requisition.

## Tips
* Be sure to fill out all required fields accurately to ensure that your requisition is processed correctly.
* If you are unsure about any of the fields, please contact the facilities department for clarification.
