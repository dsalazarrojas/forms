# Delivery Check In Form - Help Guide
## Purpose
The Delivery Check In Form is a document used to record delivery information, providing a standardized way to collect and store data about delivery events.

## How To Complete This Form
To complete this form, follow these steps:

1.  Enter the delivery date and time in the appropriate fields.
2.  Input the driver's name and phone number for easy contact.
3.  Enter the delivery address, city, state, and zip code for precise location information.
4.  If necessary, add a note about the delivery for further reference.
5.  Submit the form once all required and optional fields have been completed.

## Field-by-Field Explanation
*   **Delivery Information** (`delivery_check_in_form`, text, required: false): This field is intended for any additional information about the delivery, such as special instructions or notes.
*   **Delivery Date** (`delivery_date`, date, required: false): Enter the date of the delivery.
*   **Delivery Time** (`delivery_time`, time, required: false): Enter the time of the delivery.
*   **Driver Name** (`driver_name`, text, required: false): Enter the name of the person delivering the package.
*   **Delivery Address** (`delivery_address`, text, required: false): Enter the address where the delivery is taking place.
*   **Delivery City** (`delivery_city`, text, required: false): Enter the city where the delivery is taking place.
*   **Delivery State** (`delivery_state`, text, required: false): Enter the state where the delivery is taking place.
*   **Delivery Zip** (`delivery_zip`, text, required: false): Enter the zip code where the delivery is taking place.
*   **Delivery Note** (`delivery_note`, note, required: false): If needed, enter a note about the delivery for additional reference.
*   **Driver Phone** (`driver_phone`, text, required: false): Enter the phone number of the person delivering the package.

## Tips
-   Ensure that all required fields are completed before submitting the form.
-   Enter as much detail as possible to help ensure accurate tracking and delivery of the package.
-   If additional fields are not applicable, simply leave them blank.
