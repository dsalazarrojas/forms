# Service Estimate Request Form - Help Guide
## Purpose
The Service Estimate Request Form is used to gather information about a service estimation request from the end user. This form is used to determine the scope of work and estimate the time and cost required for a project.

## How To Complete This Form
To complete this form, please follow these steps:

1. Select the first page.
2. On the first page, you will be asked to confirm that the project requires a service estimation.
3. On the second page, select "Yes" or "No" to indicate whether the project requires additional details.
4. If you selected "Yes", provide additional project details.
5. On the third page, enter your contact details.
6. On the fourth page, provide a detailed description of the project requirements.

## Field-by-Field Explanation
* **Project Details** (`project_details`, `select_one`, required): This field asks you to confirm whether the project requires additional details. Select "Yes" if the project has specific requirements or constraints that need to be considered during the estimation process. Select "No" if the project is a standard or straightforward project.
* **Contact Details** (`contact_details`, `text`, required): This field is not used as part of the form and has a blank field in the YAML. Please ignore this field and move on to the next one.
* **Project Requirements** (`project_requirements`, `text`, required): This field is where you provide a detailed description of the project requirements. Please be as specific and detailed as possible to ensure that the estimator has a clear understanding of the project scope and timeline.
