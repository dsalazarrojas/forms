# virtual_event_service_order_form - Help Guide
## Purpose
The virtual_event_service_order_form is used to create, update, or inquire about events related to virtual event services. This form collects information about the event, including its name, service selection, participants, date and time, additional services, and details.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the **Event Name** in the text field at the top of the page.
2. Select the desired **Service** from the dropdown menu.
3. Enter the number of **Participants**.
4. Choose the **Event Date and Time** using the date picker.
5. Select additional **Services** as needed from the multiple-choice list.
6. Enter any relevant **Event Details** in the text field.
7. If required, provide **Attendee Information** in the text field.

## Field-by-Field Explanation

* **Event Name**: A text field to input the name of the event. This field is required and should be filled in accordingly.
* **Service**: A dropdown menu to select one option from the list. This field is required and should be chosen carefully, as it will determine the type of event service ordered.
* **Participants**: A number field to input the number of attendees. This field is required and should be accurate, as it will impact the event's capacity and logistics.
* **Event Date and Time**: A date field to input the event's date and time. This field is required and should be in the correct format (YYYY-MM-DD).
* **Additional Services**: A multiple-choice list to select additional services. This field is required and should be chosen based on the event's needs.
* **Event Details**: A text field to provide any relevant details about the event. This field is required and should be clear and concise.
* **Attendee Information**: An optional text field to provide information about the attendees, if necessary. This field is not required and is only needed for specific event scenarios.
