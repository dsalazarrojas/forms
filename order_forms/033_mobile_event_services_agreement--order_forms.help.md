# Mobile Event Services Agreement - Help Guide

## Purpose
The Mobile Event Services Agreement form is a document that outlines the terms and conditions of the service provider's services for a mobile event. The form is used to collect information from the event planner, service provider, and other relevant parties, ensuring a clear understanding of the services provided and the terms of the agreement.

## How To Complete This Form
To complete the Mobile Event Services Agreement form, follow these steps:

1. Fill in your contact information, including Event Planner Name, Service Provider Name, and Service Provider Contact.
2. Select the Event Date and Event Location.
3. Choose the Service Type and Service Duration.
4. Enter your Service Provider Name and Service Provider Email.
5. Confirm the Terms and Conditions by selecting the appropriate options.
6. Set the Agreement Status and Event Start and End Dates.
7. Complete any other required fields as prompted.

## Field-by-Field Explanation
* **Event Planner Name (1)** (`text`, required: false): This field is used to enter the name of the event planner.
* **Service Provider Name (2)** (`text`, required: false): This field is used to enter the name of the service provider.
* **Event Date (3)** (`date`, required: false): This field is used to select the date of the event.
* **Service Type (4)** (`select_one`, required: false): This field is used to select the type of service provided.
* **Service Duration (5)** (`number`, required: false): This field is used to enter the duration of the service.
* **Event Location (6)** (`text`, required: false): This field is used to enter the location of the event.
* **Service Provider Contact (7)** (`text`, required: false): This field is used to enter the contact information of the service provider.
* **Service Provider Email (8)** (`email`, required: false): This field is used to enter the email address of the service provider.
* **Service Provider Phone (9)** (`text`, required: false): This field is used to enter the phone number of the service provider.
* **Terms Accepted (10)** (`select_multiple`, required: false): This field is used to confirm that the terms and conditions have been accepted.
* **Terms Date (11)** (`date`, required: false): This field is used to enter the date the terms and conditions were accepted.
* **Agreement Status (12)** (`select_one`, required: false): This field is used to set the status of the agreement.
* **Event Start Date (13)** (`date`, required: false): This field is used to select the start date of the event.
* **Event End Date (14)** (`date`, required: false): This field is used to select the end date of the event.
* **Service Provider Address (15)** (`text`, required: false): This field is used to enter the address of the service provider.

## Tips
* Please ensure that all required fields are completed accurately and truthfully.
* Review the terms and conditions carefully before accepting them.
* If you have any questions or concerns, please contact your service provider.
