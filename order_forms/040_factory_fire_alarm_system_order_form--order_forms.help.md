# Factory Fire Alarm System Order Form - Help Guide
## Purpose
This form is designed to collect information from customers who are interested in ordering a fire alarm system for their factory site.

## How To Complete This Form
To complete this form, follow the steps below:

1. Provide the site address where the fire alarm system will be installed.
2. Enter your site contact name and details.
3. Select the equipment type you are interested in (System 1, System 2, or System 3).
4. Choose the system type (Panel, Hardwire, or Wireless).
5. Indicate whether you would like to request installation service.
6. Provide additional site details.
7. Enter your customer name and contact email address.

## Field-by-Field Explanation
* **Site Address**: Please enter the address of the factory site where the system will be installed.
* **Site Contact Name**: Enter your name and contact details for the site.
* **Equipment Request**: Choose the type of system you are interested in (System 1, System 2, or System 3).
* **System Type**: Select the type of system you would like to install (Panel, Hardwire, or Wireless).
* **Installation Service**: Indicate whether you would like to request installation service for the system.
* **Site Details**: Provide any additional details about the site where the system will be installed.
* **Customer Name**: Enter your name and contact information for the order.
* **Customer Email**: Enter your email address so we can keep you informed about the order status.
