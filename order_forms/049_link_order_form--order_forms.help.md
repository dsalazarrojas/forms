# link_order_form - Help Guide
## Purpose
The link_order_form is used for linking customer orders with payment information, allowing the user to track and manage customer orders.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the order details, including customer information and order total.
2. Select the customer's order status.
3. Choose the payment method (Cash, Card, or Online Payment).
4. Add any notes or comments as needed.
5. Fill in the customer's email and phone number if necessary.
6. Select the customer's order status (Active or Inactive).
7. Select the customer's order status (Active or Inactive).

## Field-by-Field Explanation

* **Order Details** (1, text, required/optional): Enter the details of the order.
* **Customer Info** (2, select_one, required/optional): Select the customer's information from the options provided.
* **Order Total** (3, number, required/optional): Enter the total amount of the order.
* **Order Status** (4, select_one, required/optional): Select the current status of the order.
* **Due Date** (5, date, required/optional): Enter the due date of the order.
* **Payment Method** (7, select_one, required/true): Select the payment method (Cash, Card, or Online Payment).
* **Notes** (8, note, required/optional): Enter any notes or comments about the order.
* **Email** (9, email, required/optional): Enter the customer's email address.
* **Phone** (10, text, required/optional): Enter the customer's phone number.
* **Customer Email** (11, email, required/optional): Enter the customer's email address.
* **Customer Phone** (12, text, required/optional): Enter the customer's phone number.
* **Order ID** (13, select_one, required/optional): Select the order ID from the options provided.
* **Customer Name** (14, text, required/optional): Enter the customer's name.
* **Customer Company** (15, text, required/optional): Enter the customer's company name.
* **Order Comments** (16, text, required/optional): Enter any comments about the order.
* **Customer Comments** (17, text, required/optional): Enter any comments from the customer.
* **Order Status 2** (18, select_one, required/optional): Select the second status of the order.
* **Order Status 3** (19, select_one, required/optional): Select the third status of the order.
* **Order Notes** (20, note, required/optional): Enter any additional notes about the order.
* **Customer Notes** (21, note, required/optional): Enter any additional comments from the customer.
* **Customer Order Status** (22, select_one, required/optional): Select the customer's order status.
* **Due Time** (23, time, required/optional): Enter the due time of the order.
* **Order Total 2** (24, number, required/optional): Enter the total amount of the second order.
* **Order Notes 2** (25, note, required/optional): Enter any additional notes about the second order.

Note: Required fields are marked as required/true, while optional fields are marked as required/optional or required/false.
