# Farm Egg And Dairy Order Form - Help Guide
## Purpose
The Farm Egg And Dairy Order Form is used to place orders for egg and dairy products. This form gathers information about the order, the customer, and any additional details or notes.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the type of egg and dairy order you are placing.
2. Enter the date and time of the order in the format specified in the respective fields.
3. Provide a note about the order if necessary.
4. Enter the customer's email address for contact purposes.
5. Enter any additional customer information in the text field.

## Field-by-Field Explanation

* **Egg and Dairy Order Type**: Select the type of egg and dairy order you are placing. This field is a select-one type, meaning you can only choose one option.
* **Order Date**: Enter the date of the order in the format MM/DD/YY (e.g., 02/16/2023).
* **Order Time**: Enter the time of the order in the format HH:MM (e.g., 14:30).
* **Order Note**: Enter any additional details or notes about the order in this text field.
* **Customer Email**: Enter the customer's email address for contact purposes.
* **Customer Information**: Enter any additional information about the customer in this text field.
