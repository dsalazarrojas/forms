# currency_conversion_form - Help Guide
## Purpose
This form is a tool for users to convert currencies and input notes or comments about their conversion request.

## How To Complete This Form
To complete this form, follow these steps:
1. Select the original currency from the "Select Currency" dropdown list.
2. Input the amount you want to convert in the "Amount" field.
3. Select the target currency from the "Select Currency 2" dropdown list.
4. Choose whether you want to convert the currency immediately with "Convert To".
5. If converting, select the date and time of conversion with "Convert Now" and "Time Of Conversion" fields respectively.
6. Input any additional notes or comments about your conversion request in the "Note" field.

## Field-by-Field Explanation
* **Select Currency**: Select the original currency you want to convert from the available options. This will help us understand which currency to convert from.
* **Amount**: Input the amount you want to convert. Please make sure to input a valid numerical value. 
* **Select Currency 2**: Choose the target currency you want to convert to from the available options. 
* **Convert To**: Select whether you want to convert the currency immediately. Please note that this field will only appear if you selected "Yes" in "Select Currency 2" 
* **Convert Now**: If you selected "Yes" in "Convert To", select the date and time you want the conversion to happen. This field will only appear if "Convert To" is selected. 
* **Time Of Conversion**: Input the specific time you want the conversion to occur if "Convert Now" is selected. 
* **Note**: Add any additional comments or notes about your conversion request.
