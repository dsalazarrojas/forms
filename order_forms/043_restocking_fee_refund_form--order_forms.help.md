# Restocking Fee Refund Form - Help Guide
## Purpose
The Restocking Fee Refund Form is used to request a refund for a restocking fee charged on an order. This form is only for orders that have been cancelled or otherwise returned to us. Please ensure you have a clear reason for the refund request, as this will aid in processing your request.

## How To Complete This Form

### To complete this form, follow these steps:
* Ensure you have a valid order ID, order type, and amount refunded before proceeding.
* Select the correct order type (New, Used, or Both) to describe the type of order being refunded.
* Choose the order status that accurately reflects the current state of your order (Open, Awaiting Fulfillment, Fulfilled, Cancelled).
* If relevant, select multiple order status options to indicate the various statuses your order has gone through.
* Enter the amount refunded, which should match the amount originally charged for the restocking fee.
* If you feel it's necessary, provide a brief description of your refund request to help us understand your case.

## Field-by-Field Explanation
* **Restocking Fee Refund Form**: Enter the title of the form to confirm it is correct.
* **Order ID**: Enter the unique ID of the order for which you are requesting a refund.
*   *Order ID is a required field and should correspond to the exact order you are referring to.*
* **Order Type**: Select the type of order being refunded (New, Used, or Both).
*   *This field helps us understand the type of item being returned or cancelled.*
* **Order Status**: Choose the order status that most accurately reflects the current state of your order (Open, Awaiting Fulfillment, Fulfilled, Cancelled).
*   *Select multiple status options if your order has gone through multiple stages.*
* **Amount Refunded**: Enter the exact amount refunded for the restocking fee.
*   *This amount should match the original fee charged for the restocking fee.*
* **Description**: Provide a brief explanation for your refund request, if applicable.
*   *This helps us understand your case and process your request efficiently.*

## Tips
* Please ensure all fields are filled out before submitting the form.
* Make sure to enter accurate information for Order ID, Order Type, and Amount Refunded fields.
* Double-check the order status to ensure it reflects the current state of your order.
* If you're unsure about any field, contact our support team for assistance.
