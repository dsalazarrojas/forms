# Wedding Invitation Form - Help Guide
## Purpose
The Wedding Invitation Form is a tool used to collect information about a wedding invitation, making it easier to plan and coordinate the event.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the Wedding Invitation Form title and other details as requested.
2. Choose the wedding theme (yes or no) and provide any other details as needed.
3. Enter the wedding date and time.
4. Select the venue where the wedding will take place.
5. Provide the dress code for the occasion.
6. List any gifts you would like to receive, if applicable.
7. Enter a message if you'd like to include a gift message with your gift.
8. Choose whether to RSVP (yes or no) and provide a brief message, if desired.
9. Select the RSVP deadline.

## Field-by-Field Explanation
* **Wedding Invitation Form title** (text): Enter a brief title for the wedding invitation.
* **Wedding theme** (select multiple): Choose the theme of the wedding (yes or no).
* **Wedding date** (date): Enter the date of the wedding.
* **Wedding time** (time): Enter the time of the wedding.
* **Venue** (text): Enter the location where the wedding will take place.
* **Dress code** (text): Enter the dress code for the wedding guests.
* **Gifts** (text): List any gifts you would like to receive, if applicable.
* **Gift message** (text): Enter a message to include with your gift, if desired.
* **RSVP** (select one): Choose whether to RSVP (yes or no).
* **RSVP message** (text): Enter a brief message if you'd like to include with your RSVP.
* **RSVP deadline** (date): Select the deadline for RSVPs.

## Tips
* Make sure to provide accurate and detailed information about the wedding.
* If you're unsure about any of the fields, feel free to ask the wedding planner or coordinator for clarification.
* This form is meant to be a helpful guide, so don't hesitate to ask questions or seek help if needed.
