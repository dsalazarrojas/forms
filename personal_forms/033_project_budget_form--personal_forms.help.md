# project_budget_form - Help Guide
## Purpose
The project budget form is a tool for documenting and managing personal project budgets. It captures essential details such as project start and end dates, amounts, and additional notes, providing a clear and organized overview of project expenses.

## How To Complete This Form
To fill out this form, follow these steps:

1. Select whether the project is active or not using the "Project" field.
2. Provide a brief and concise name for the project.
3. Select the project category(ies) from the provided options.
4. Enter the project's start date in the "Start Date" field.
5. Enter the project's end date in the "End Date" field.
6. Enter the budget amount for the project in the "Amount" field.
7. Add any additional notes regarding the project in the "Notes" field.
8. Add any additional notes about the project in the "Additional Notes" field.

## Field-by-Field Explanation
- **Project** (`project_budget_form_project`, select_one, not required): Choose "Yes" if the project is active and "No" otherwise.
- **Name** (`project_budget_form_name`, text, not required): Give a brief and concise name for the project.
- **Category** (`project_budget_form_category`, select_multiple, not required): Select the category(ies) that best describes the project.
- **Start Date** (`project_budget_form_start_date`, date, not required): Enter the start date of the project.
- **End Date** (`project_budget_form_end_date`, date, not required): Enter the end date of the project.
- **Amount** (`project_budget_form_amount`, number, not required): Enter the budget amount for the project.
- **Notes** (`project_budget_form_notes`, note, not required): Add any notes or comments about the project.
- **Additional Notes** (`project_budget_form_additional_notes`, note, not required): Add any additional information about the project.
