# Swap Item Tracker - Help Guide
## Purpose
The Swap Item Tracker form is designed to help users keep track of swaps or trades between individuals. It's meant to be used by individuals or organizations swapping items, such as collectibles, books, or other items of value.

## How To Complete This Form
To use this form, follow these steps:
- Click on the "User Input" field and type in the name or identifier of the item being swapped.
- Select the current status of the item (e.g., "Waiting," "Sold," or "Available") in the "Item Status" field.
- If applicable, upload or link to an image of the item in the "Item Image" field.
- Add any additional notes about the item in the "Notes" field.
- Enter the date of the swap in the "Swap Date" field.
- Select the current swap status (e.g., "Completed," "Pending," or "Waiting") in the "Swap Status" field.
- If necessary, enter the date the swap status was updated in the "Status Date" field.

## Field-by-Field Explanation
* **User Input** (Text, Optional): Enter the name or identifier of the item being swapped.
* **Item Description** (Text, Required): Provide a brief description of the item being swapped.
* **Item Status** (Select One, Required): Choose the current status of the item (e.g., Waiting, Sold, or Available).
* **Item Image** (Text, Optional): Upload or link to an image of the item, if applicable.
* **Note** (Note, Optional): Add any additional notes or comments about the item.
* **Notes** (Note, Optional): Add any additional notes or comments about the swap process.
* **Photos** (Note, Optional): Upload photos related to the swap, if necessary.
* **Swap Date** (Date, Required): Enter the date the swap occurred or is expected to occur.
* **Swap Status** (Select Multiple, Required): Choose the current status of the swap (e.g., Completed, Pending, or Waiting).
* **Status Date** (Date, Optional): Enter the date the swap status was updated, if necessary.
* **Exchange Date** (Date, Optional): Enter the date the item was exchanged or is expected to be exchanged.

Please note that this form is a general template and may need to be adapted to specific use cases or industries.
