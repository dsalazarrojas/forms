# Romantic Note Template Form - Help Guide

## Purpose
The Romantic Note Template Form is designed to create customized and thoughtful romantic notes for special occasions. This form guides you through collecting the necessary information to craft a heartfelt message.

## How To Complete This Form

1. Enter your name to include it in the message as the sender.
2. Write a personal message expressing your feelings or thoughts.
3. Select an event that is relevant to the note (e.g., anniversary, birthday).
4. Choose the date when the event occurred or will occur.
5. Choose the time of the event (if applicable).
6. Select the recipient(s) of the note (e.g., partner, family member, friend).
7. Optionally, enter the recipient's email address for sending the message.
8. If sending a message, select whether to send it or not.
9. Optionally, add any additional notes or comments.
10. Select the type of recipient(s) for the note (e.g., partner, friend, family member).
11. Select the type of note (e.g., general, anniversary, birthday).
12. Optionally, enter a note's date and time.
13. Add a personal message for the note.
14. Select the status of the note (e.g., sent, pending).
15. Optionally, select the type of message status (e.g., sent, pending).
16. Select the type of event for the note (e.g., general, anniversary, birthday).
17. Select the type of note for the note (e.g., general, anniversary, birthday).
18. Optionally, add any additional notes or comments.
19. Select the status of the signature (e.g., signed, unsigned).
20. Optionally, select the status of the signature (e.g., signed, unsigned).

## Field-by-Field Explanation

* **Name** (1, Text, Required): Enter your name to include it in the message as the sender.
* **Message** (2, Text, Required): Write a personal message expressing your feelings or thoughts.
* **Event** (3, Select One, Not Required): Select an event that is relevant to the note (e.g., anniversary, birthday).
* **Date** (4, Date, Required): Choose the date when the event occurred or will occur.
* **Time** (5, Time, Required): Choose the time of the event (if applicable).
* **Recipient** (6, Select Multiple, Required): Select the recipient(s) of the note (e.g., partner, family member, friend).
* **Recipient Email** (8, Email, Not Required): Optionally, enter the recipient's email address for sending the message.
* **Send Message** (10, Select One, Required): If sending a message, select whether to send it or not.
* **Notes** (7, Text, Required): Optionally, add any additional notes or comments.
* **Notes Type** (16, Select Multiple, Not Required): Select the type of note (e.g., general, anniversary, birthday).
* **Notes Status** (21, Select Multiple, Not Required): Select the status of the note (e.g., sent, pending).
* **Event Type** (15, Select One, Not Required): Select the type of event for the note (e.g., general, anniversary, birthday).
* **Signature** (24, Select One, Not Required): Select the status of the signature (e.g., signed, unsigned).
* **Signature Status** (25, Select One, Not Required): Optionally, select the status of the signature (e.g., signed, unsigned).

## Tips

* Make sure to include the necessary information for the message to be sent or received correctly.
* Double-check the details to avoid mistakes.
* Use the correct format for the dates and times.
* Ensure that the event and type of note are correctly selected.
* Use the notes section to add any additional comments or details.
