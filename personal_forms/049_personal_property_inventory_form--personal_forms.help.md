# personal_property_inventory_form - Help Guide
## Purpose
This form is used to catalog and track personal properties such as vehicles, jewelry, or other valuable items. The form is designed to collect specific, categorized information about each property.

## How To Complete This Form

To complete this form, follow these steps:

1.  Select the category of the property from the options provided.
2.  Enter a brief description of the property.
3.  Enter the value of the property.
4.  Enter the date the property was acquired.
5.  Enter the date the property was sold.
6.  Enter any additional information about the property being sold.
7.  If the property has a category, select the corresponding category from the options provided.
8.  Enter any notes about the property.
9.  Enter the phone number associated with the property.
10.  Enter the email associated with the property.
11.  Select the type of insurance coverage for the property from the options provided.
12.  Select the deductible amount for the insurance coverage.
13.  Select the value of the insurance coverage.
14.  Select the type of insurance coverage from the options provided.
15.  Enter the name of the person or entity insured.
16.  Enter the date the person or entity was insured.
17.  Enter the amount insured.
18.  Enter the insured value.

## Field-by-Field Explanation

*   **category** (`category`, `select_one`, required: false): Select the category of the property from the options provided.
*   **description** (`description`, `text`, required: false): Enter a brief description of the property.
*   **value** (`value`, `number`, required: false): Enter the value of the property.
*   **date_acquired** (`date_acquired`, `date`, required: false): Enter the date the property was acquired.
*   **date_sold** (`date_sold`, `date`, required: false): Enter the date the property was sold.
*   **sold** (`sold`, `text`, required: false): Enter any additional information about the property being sold.
*   **category_id** (`category_id`, `select_one`, required: false): If the property has a category, select the corresponding category from the options provided.
*   **notes** (`notes`, `note`, required: false): Enter any notes about the property.
*   **phone** (`phone`, `text`, required: false): Enter the phone number associated with the property.
*   **email** (`email`, `email`, required: false): Enter the email associated with the property.
*   **insurance** (`insurance`, `select_one`, required: false): Select the type of insurance coverage for the property from the options provided.
*   **insurance_deductible** (`insurance_deductible`, `select_one`, required: false): Select the deductible amount for the insurance coverage.
*   **insurance_value** (`insurance_value`, `select_one`, required: false): Select the value of the insurance coverage.
*   **insurance_type** (`insurance_type`, `select_one`, required: false): Select the type of insurance coverage from the options provided.
*   **insured** (`insured`, `text`, required: false): Enter the name of the person or entity insured.
*   **insured_date** (`insured_date`, `date`, required: false): Enter the date the person or entity was insured.
*   **insured_amount** (`insured_amount`, `number`, required: false): Enter the amount insured.
*   **insured_value** (`insured_value`, `number`, required: false): Enter the insured value.

## Tips

*   Be sure to complete all required fields for accurate information.
*   Use the category selection to ensure correct categorization of the property.
*   Enter accurate and up-to-date information for each field.
*   If unsure about any field, refer to the field label for clarification.
