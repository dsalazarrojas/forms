# Physical Fitness Questionnaire - Help Guide
## Purpose
The Physical Fitness Questionnaire is a survey designed to help you assess your own physical fitness level and health status. It will ask you questions about your general information, lifestyle habits, medical history, and physical activity level. Please answer all questions honestly to get an accurate assessment of your fitness level.

## How To Complete This Form

1. Answer each question carefully and thoroughly.
2. Make sure to select the correct option for each question.
3. If you have any questions or concerns about a particular question, please don't hesitate to contact us.

## Field-by-Field Explanation

* **General Information** (`1`, `text`, required): This is the first section of the form where you will provide some general information about yourself.
* **Height (cm)** (`2`, `number`, optional): Please enter your height in centimeters.
* **Weight (kg)** (`3`, `number`, optional): Please enter your weight in kilograms.
* **Age (years)** (`4`, `number`, required): Please enter your age in years.
* **Activity level** (`5`, `select_multiple`, required): Please select all that apply to you:
	+ Inactive
	+ Moderately active
	+ Very active
	+ Extremely active
* **Smoking status** (`6`, `select_multiple`, optional): Please select all that apply to you:
	+ Never
	+ Past smoker
	+ Current smoker
* **Medication** (`7`, `select_multiple`, optional): Please select all that apply to you:
	+ No medication
	+ Diabetes medication
	+ Cholesterol medication
	+ Hypertension medication
	+ Other
* **Medical conditions** (`8`, `select_multiple`, optional): Please select all that apply to you:
	+ None
	+ Arthritis
	+ Chronic pain
	+ Heart disease
	+ Respiratory disease
	+ Other
* **Injury history** (`9`, `text`, optional): If you have any previous injuries, please describe them here.
* **Workout days per week** (`10`, `select_one`, required): Please select:
	+ 0 days
	+ 1-2 days
	+ 3-4 days
	+ 5-6 days
	+ 7 days
* **Workout duration (min)** (`11`, `number`, optional): If you have a consistent workout routine, please enter the duration in minutes per session.
* **Workout intensity** (`12`, `select_multiple`, optional): Please select all that apply to you:
	+ Gentle
	+ Moderate
	+ High
* **Diet type** (`13`, `select_multiple`, optional): Please select all that apply to you:
	+ Low fat
	+ Moderate
	+ Balanced
	+ Other

## Tips

* Please answer all questions honestly and thoroughly.
* If you have any questions or concerns, please don't hesitate to contact us.
