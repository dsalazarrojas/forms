# Secret Santa Questionnaire - Help Guide
## Purpose
The Secret Santa Questionnaire is designed to collect information about participants' preferences and limits for a fun and fair gift exchange during the holiday season.

## How To Complete This Form
To complete this form, follow these steps:

1. Read through the form carefully and make sure you understand each field.
2. Answer the questions truthfully and to the best of your ability.
3. Fill out the form completely and accurately.
4. If you need help with any of the fields, please refer to the Field-by-Field Explanation section below.

## Field-by-Field Explanation
### 1. **participant_list** (`Yes, No`, required: false)
* This field asks whether you want to participate in the Secret Santa activity. Please select "Yes" if you want to participate, and "No" if you don't.

### 2. **gift_limit** (`number`, required: false)
* This field is for setting a gift limit for the person giving gifts. Please enter a number to indicate the maximum budget for gifts.

### 3. **gift_limit_description** (`text`, required: false)
* This field is for providing a brief description of the gift limit set in the previous field.

### 4. **gift_price_limit** (`number`, required: false)
* This field is for setting a price limit for gifts. Please enter a number to indicate the maximum price for gifts.

### 5. **participant_limit** (`number`, required: false)
* This field is for setting a limit on the number of participants. Please enter a number to indicate the maximum number of participants.

### 6. **draw_date** (`date`, required: false)
* This field is for selecting a date for the draw. Please choose a date for when the draw should take place.

### 7. **draw_time** (`time`, required: false)
* This field is for selecting a time for the draw. Please choose a time for when the draw should take place.

### 8. **participant_info** (`text`, required: false)
* This field is for providing additional information about yourself as a participant. Please write a brief description of your preferences and interests.

### 9. **gift_info** (`text`, required: false)
* This field is for providing information about the types of gifts you would like or dislike. Please write a brief description of your gift preferences.

### 10. **gift_reciever_info** (`text`, required: false)
* This field is for providing information about the person you will draw to buy a gift for. Please write a brief description of their preferences and interests.

### 11. **draw_winner** (`Yes, No`, required: false)
* This field is for choosing whether or not to draw a winner. Please select "Yes" if you want to draw a winner, and "No" if you don't.

### 12. **draw_winner_message** (`text`, required: false)
* This field is for writing a message to be shown to the winner if you are drawing a participant to buy a gift. Please write a brief and festive message for the winner.
