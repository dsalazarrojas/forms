# Relationship Change Notification - Help Guide
## Purpose
The purpose of this form is to notify the system about changes to a member's relationship status. It is used by the HR team, membership organizations, and insurers to ensure that the system stays up-to-date with the latest information.

## How To Complete This Form
1. Select the correct relationship status from the "Relationship Status" field.
2. If necessary, attach relevant documents to the "Documents" field.
3. Fill out the "Reason For Change" field with a brief explanation of the change.
4. Enter the "Updated By" field with the name of the entity making the change (e.g. "HR Team Member", "Membership Organization", etc.).
5. Enter the "Updated By" fields with the updated contact information (email and/or phone number).
6. Select the correct "Relationship Type" from the "Relationship Type" field.
7. Enter the "Relationship ID" field with the ID number of the member's relationship.
8. Fill out any other required fields as necessary.

## Field-by-Field Explanation

* **Relationship Status** (`relationship_status`, required): Select the new relationship status of the member. This field is required to ensure that the system accurately tracks the member's relationship changes.
* **Effective Date** (`relationship_change_date`, optional): If applicable, enter the date when the relationship change took effect.
* **Documents** (`documents_attached`, optional): Attach any relevant documents to support the relationship change (e.g. a copy of a court order, a divorce certificate, etc.).
* **Reason For Change** (`reason_for_change`, optional): Provide a brief explanation of the reason for the relationship change.
* **Updated By** (`updated_by`, required): Enter the name of the entity making the change (e.g. "HR Team Member", "Membership Organization", etc.). This field is required to ensure that the system accurately tracks who made the change.
* **Updated By Email** (`updated_by_email`, optional): Enter the email address of the entity making the change.
* **Updated By Phone** (`updated_by_phone`, optional): Enter the phone number of the entity making the change.
* **Updated By Document** (`updated_by_document`, optional): Enter the ID number of the document used to update the change.
* **Relationship Type** (`relationship_type`, optional): Select the type of relationship change (e.g. divorce, death, etc.).
* **Relationship Type Option** (`relationship_type_option`, optional): Select the specific type of relationship change (e.g. married, single, etc.).
* **Relationship ID** (`relationship_id`, optional): Enter the ID number of the member's relationship.
* **Relationship Change Document** (`relationship_change_document`, optional): Attach any relevant documents to support the relationship change.
* **Relationship Change Effective Date** (`relationship_change_effective_date`, optional): Enter the date when the relationship change became effective.
