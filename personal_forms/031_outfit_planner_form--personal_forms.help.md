# Outfit Planner Form - Help Guide
## Purpose
The Outfit Planner Form is a tool that helps users submit information about a specific event or meeting, including the type of event, date, location, description, and other relevant details. This information will be used to create a personalized outfit for the occasion.

## How To Complete This Form
1. Select the type of event you are planning (e.g., "Yes" or "No").
2. Choose the date of the event.
3. Enter the location of the event.
4. Briefly describe the event.
5. Specify any special style requests or preferences.
6. List any clothing items you need.
7. Enter the name of the contact person.
8. Enter the email of the contact person.

## Field-by-Field Explanation
* **event_type**: (`event_type`, select_one, required: false) - Select the type of event you are planning.
* **event_date**: (`event_date`, date, required: false) - Enter the date of the event (e.g., 2024-02-15).
* **event_location**: (`event_location`, text, required: false) - Enter the location of the event (e.g., "New York City").
* **event_description**: (`event_description`, text, required: false) - Briefly describe the event.
* **style_requests**: (`style_requests`, text, required: false) - Specify any special style requests or preferences.
* **clothing_items**: (`clothing_items`, text, required: false) - List any clothing items you need.
* **contact_name**: (`contact_name`, text, required: false) - Enter the name of the contact person.
* **contact_email**: (`contact_email`, email, required: false) - Enter the email of the contact person.

## Tips
* Please ensure that you have provided accurate and complete information to help us create the best possible outfit for the occasion.
* If you have any questions or concerns, please don't hesitate to reach out to us.
* Thank you for using the Outfit Planner Form to help us create a great outfit for you!
