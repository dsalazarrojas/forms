# Hair Care Recommendation Form - Help Guide
## Purpose
The Hair Care Recommendation Form is designed to gather information about a person's hair care habits and preferences. This information will be used to provide personalized recommendations for hair care products or treatments.

## How To Complete This Form
1. Fill out the form completely and accurately.
2. Select the correct options for each field, paying attention to the required fields.
3. If you are unsure about any of the options, ask a hair care professional for guidance.

## Field-by-Field Explanation
* **Hair Type** (hair_type, select_one, required: false):
	+ Select the type of hair you have (Option 1, Option 2, or Option 3).
* **Skin Type** (skin_type, select_one, required: false):
	+ Select your skin type (Yes or No).
* **Hair Length** (hair_length, select_multiple, required: false):
	+ Select the length of your hair (Option 1, Option 2).
* **Color Type** (color_type, select_one, required: false):
	+ Select your hair color type (Yes or No).
* **Product Use** (product_use, select_multiple, required: false):
	+ Select the products you currently use for hair care (Option 1, Option 2).
* **Hair Problem** (hair_problem, select_multiple, required: false):
	+ Select any hair problems you are currently experiencing (Option 1, Option 2).
* **Hair Problem 2** (hair_problem_2, select_one, required: false):
	+ Select whether you have any additional hair problems (Yes or No).
* **Skin Problem** (skin_problem, select_multiple, required: false):
	+ Select any skin problems you are currently experiencing (Option 1, Option 2).

## Tips
* Be honest when answering the questions, as this information will be used to provide personalized recommendations.
* If you have any questions or concerns, ask a hair care professional for guidance.
* This form should only be filled out once per person.
