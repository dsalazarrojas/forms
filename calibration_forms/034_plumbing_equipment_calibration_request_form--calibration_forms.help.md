# Plumbing Equipment Calibration Request Form - Help Guide
## Purpose
This form is designed to collect information from users to request calibration for plumbing equipment. It ensures that necessary details are submitted to facilitate the calibration process.

## How To Complete This Form
To complete this form, follow these steps:

1. Provide a brief description of the equipment you want to be calibrated.
2. Select the preferred date for the calibration service.
3. Enter the equipment model if required or applicable.
4. Enter the last calibration date (if applicable).
5. Enter the next calibration due date (if applicable).
6. Add any additional notes or comments about the calibration request.
7. Select the service date for the calibration.

## Field-by-Field Explanation

* **Calibration Request Form** (`calibration_request_form`, text, required): This field is the main description of the equipment you want to be calibrated. Please provide a brief description of the equipment, including its type and location.
* **Equipment Details** (`equipment_details`, text, optional): If required or applicable, provide additional details about the equipment, such as its model number or serial number.
* **Preferred Date** (`preferred_date`, date, required): Select a date for the calibration service. Please note that the selected date must be in the future.
* **Equipment Model** (`equipment_model`, text, optional): If the equipment model is not already described in the calibration request form, provide it here.
* **Last Calibration Date** (`last_calibration_date`, date, optional): If the equipment has a previous calibration record, enter the date of the last calibration.
* **Next Calibration Due Date** (`next_calibration_due_date`, date, optional): If the equipment has a scheduled next calibration, enter the date.
* **Additional Notes** (`additional_notes`, text, required): Please add any additional information or comments about the calibration request.
* **Service Date** (`service_date`, date, optional): If applicable, select the date for the calibration service.

## Tips

* Ensure that you provide a brief and clear description of the equipment in the Calibration Request Form.
* If the calibration due date is not specified, please enter the recommended next calibration date for the equipment.
* If you have any additional notes or comments, please add them to the Additional Notes field.
* Please select a date for the calibration service in the Service Date field.
* If you are unsure about any of the fields, please contact [insert contact information] for assistance.
