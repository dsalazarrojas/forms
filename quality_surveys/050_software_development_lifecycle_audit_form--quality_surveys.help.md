# Software Development Lifecycle Audit Form - Help Guide
## Purpose
The Software Development Lifecycle Audit Form is designed to collect information about software development projects. This form helps to gather data on various aspects of a project, including its name, description, team size, sprint duration, and more. The goal is to ensure that all necessary information is collected efficiently and accurately.

## How To Complete This Form

1. Please fill out the form with the required information for each field, following the instructions below.
2. Make sure to provide the correct format for each field type (e.g., date, number, text).
3. If you are unsure about any field, please refer to the Field-by-Field Explanation section below.

## Field-by-Field Explanation

* **Project name** (`project_name`): Enter the name of the software development project.
* **Description** (`project_description`): Provide a brief description of the project.
* **Type** (`project_type`): Select the type of project (Waterfall, Agile, Hybrid).
* **Team size** (`project_team_size`): Enter the number of team members working on the project.
* **Sprint duration** (`project_sprint_duration`): Enter the duration of each sprint in hours (optional).
* **Sprint frequency** (`project_sprint_frequency`): Select the frequency of sprints (Daily, Weekly, Bi-weekly, Monthly).
* **Sprint start date** (`project_sprint_start_date`): Enter the start date of the current sprint.
* **Sprint end date** (`project_sprint_end_date`): Enter the end date of the current sprint.
* **Project status** (`project_status`): Select the current status of the project (Active, Inactive, On-hold).
* **Lead name** (`project_lead_name`): Enter the name of the project lead.
* **Lead email** (`project_lead_email`): Enter the email of the project lead.
* **Lead phone** (`project_lead_phone`): Enter the phone number of the project lead.
* **Lead role** (`project_lead_role`): Enter the role of the project lead.
* **Lead manager name** (`project_lead_manager_name`): Enter the name of the project lead manager.
* **Lead manager email** (`project_lead_manager_email`): Enter the email of the project lead manager.
* **Lead manager phone** (`project_lead_manager_phone`): Enter the phone number of the project lead manager.
* **Lead manager role** (`project_lead_manager_role`): Enter the role of the project lead manager.
* **Lead team** (`project_lead_team`): Enter the name of the project lead team.
* **Sprint start date estimated** (`project_sprint_start_date_estimated`): Enter the estimated start date of the next sprint (optional).
* **Sprint end date estimated** (`project_sprint_end_date_estimated`): Enter the estimated end date of the next sprint (optional).
* **Estimated sprint start date** (`project_lead_estimated_sprint_start_date`): Enter the estimated start date of the next sprint (optional).
* **Estimated sprint end date** (`project_lead_estimated_sprint_end_date`): Enter the estimated end date of the next sprint (optional).
* **Actual sprint duration** (`project_lead_actual_sprint_duration`): Enter the actual duration of the current sprint (optional).
* **Lead manager comment** (`project_lead_manager_comment`): Add any comments from the project lead manager (optional).
* **Project lead comment** (`project_lead_comment`): Add any comments from the project lead (optional).
