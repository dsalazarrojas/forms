# Process Control Audit Survey - Help Guide
## Purpose
The Process Control Audit Survey is a tool used by quality teams to assess the current state of process controls and identify areas for improvement.

## How To Complete This Form
To complete this form, please follow these steps:

1. Select all process controls that are currently in place from the dropdown menu on page 1.
2. Assess the risk level of each process control on page 2.
3. List all process steps on page 3.
4. Evaluate process controls using the checklist on page 4.
5. List all corrective actions taken on page 5.
6. Describe continuous improvement opportunities on page 6.
7. List all process outputs or products on page 7.
8. List all control outputs or results on page 8.

## Field-by-Field Explanation

* **Process Controls** (<type> select_multiple): Select all process controls currently in place.
* **Risk Assessment** (<label> text): Assess the risk level of each process control.
* **Risk Level** (<label> select_one): Choose the risk level of each process control.
* **Process Steps** (<label> note): List all process steps.
* **Control Evaluation** (<label> select_multiple): Evaluate process controls using the checklist.
* **Corrective Actions** (<label> text): List all corrective actions taken.
* **Continuous Improvement** (<label> text): Describe continuous improvement opportunities.
* **Process Outputs** (<label> text): List all process outputs or products.
* **Control Outputs** (<label> text): List all control outputs or results.

## Tips
- Be specific when listing process steps and corrective actions.
- Assess risk levels honestly and accurately.
- Evaluate controls using the provided checklist.
- Keep responses concise and clear.
