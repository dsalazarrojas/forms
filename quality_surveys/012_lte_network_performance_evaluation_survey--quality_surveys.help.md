# LTE Network Performance Evaluation Survey - Help Guide
## Purpose
This form is designed to collect feedback on the performance of Local Area Networks (LANs) or wireless networks. It helps us understand how well the network performed, and what issues users experienced.

## How To Complete This Form
1. Answer the question "LTE Survey" with your experience. Select 'Yes' if the network performed well, 'No' otherwise.
2. Enter the name or model of the device you used to access the network in the "Device" field.
3. If applicable, enter the location where you used the network in the "Location" field.
4. Rate the network performance in the "Network Performance Rating" field. A higher score indicates better performance.
5. Select any issues you experienced with the network in the "Network Issues" field.
6. If you encountered any issues with services offered through the network (e.g., internet, phone, etc.), select them in the "Service Issues" field.
7. If you have any additional comments about the network performance, enter them in the "Network Performance Comments" field.

## Field-by-Field Explanation
* **LTE Survey** (`lte_survey`, select_multiple, required): This question asks if the network performed well.
* **Device** (`device`, text, required): Enter the name or model of the device you used to access the network.
* **Location** (`location`, text, optional): If applicable, enter the location where you used the network.
* **Network Performance Rating** (`network_performance_rating`, number, required): Rate the network performance. A higher score indicates better performance.
* **Network Issues** (`network_issues`, select_one, required): Select any issues you experienced with the network.
* **Service Issues** (`service_issues`, select_multiple, optional): If you encountered any issues with services offered through the network (e.g., internet, phone, etc.), select them.
* **Network Performance Comments** (`network_performance_comments`, text, optional): Enter any additional comments about the network performance.
