# Renewable Energy Project Standards Audit Form - Help Guide
## Purpose
The Renewable Energy Project Standards Audit Form is designed to collect detailed information about renewable energy projects, allowing for a comprehensive audit and review. This form helps ensure that all necessary data is captured, enabling a thorough assessment and evaluation of project standards.

## How To Complete This Form
To fill out this form, follow these steps:

1. Enter the project address in the "Project Address" field.
2. Provide the project name in the "Project Name" field.
3. Specify the project location in the "Project Location" field.
4. Enter the date of your visit in the "Date of Visit" field in the format (DD/MM/YYYY).
5. Enter your name as the reviewer in the "Reviewer Name" field.
6. Enter the name of your organization in the "Reviewer Organization" field.
7. Enter the date you reviewed the project in the "Date Reviewed" field in the format (DD/MM/YYYY).
8. Enter your phone number in the "Reviewer Phone" field.
9. Enter your email address in the "Reviewer Email" field.
10. Sign your name in the "Reviewer Signature" field.
11. Enter the name of the project manager in the "Project Manager Name" field.
12. Enter the contact information for the project manager in the "Project Manager Contact" field.
13. Enter the phone number of the project manager in the "Project Manager Phone" field.
14. Enter the email address of the project manager in the "Project Manager Email" field.
15. Select the current project status from the "Project Status" dropdown menu.
16. Provide any site visit details in the "Site Visit Details" field.
17. Add any comments from the site visit in the "Site Visit Comments" field.
18. Capture any project notes in the "Project Notes" field.
19. Add any site visit photos in the "Site Visit Photos" field.
20. Add any site visit videos in the "Site Visit Videos" field.
21. Upload any site visit documents in the "Site Visit Documents" field.

## Field-by-Field Explanation

* **Project Address** (`project_address`, text, required: false): Enter the physical address of the project location.
* **Project Name** (`project_name`, text, required: false): Enter the name of the project.
* **Project Location** (`project_location`, text, required: false): Specify the location of the project.
* **Date of Visit** (`date_of_visit`, date, required: false): Enter the date you visited the project site in the format (DD/MM/YYYY).
* **Reviewer Name** (`reviewer_name`, text, required: false): Enter your name as the reviewer.
* **Reviewer Organization** (`reviewer_organization`, text, required: false): Enter the name of your organization.
* **Date Reviewed** (`date_reviewed`, date, required: false): Enter the date you reviewed the project in the format (DD/MM/YYYY).
* **Reviewer Phone** (`reviewer_phone`, text, required: false): Enter your phone number.
* **Reviewer Email** (`reviewer_email`, email, required: false): Enter your email address.
* **Reviewer Signature** (`reviewer_signature`, note, required: false): Sign your name as the reviewer.
* **Project Manager Name** (`project_manager_name`, text, required: false): Enter the name of the project manager.
* **Project Manager Contact** (`project_manager_contact`, text, required: false): Enter the contact information for the project manager.
* **Project Manager Phone** (`project_manager_phone`, text, required: false): Enter the phone number of the project manager.
* **Project Manager Email** (`project_manager_email`, email, required: false): Enter the email address of the project manager.
* **Project Status** (`project_status`, select_one, required: false): Select the current status of the project from the dropdown menu.
* **Site Visit Details** (`site_visit_details`, text, required: false): Provide any site visit details.
* **Site Visit Comments** (`site_visit_comments`, text, required: false): Add any comments from the site visit.
* **Project Notes** (`project_notes`, text, required: false): Capture any project notes.
* **Site Visit Photos** (`site_visit_photos`, text, required: false): Add any site visit photos.
* **Site Visit Videos** (`site_visit_videos`, text, required: false): Add any site visit videos.
* **Site Visit Documents** (`site_visit_documents`, text, required: false): Upload any site visit documents.

## Tips
- Ensure that all required fields are filled out accurately and completely.
- Review the form carefully before submission to ensure that all necessary information is included.
- Use the "Reviewer Signature" field for authenticity and verification purposes.
- For site visit details, comments, and notes, provide as much information as possible for a comprehensive assessment.
- For project status, select the most accurate status from the dropdown menu.
- Ensure that all project manager contact information is accurate and up-to-date.
