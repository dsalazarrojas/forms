# Assembly Line Inspection Form - Help Guide
## Purpose
The Assembly Line Inspection Form is a tool to aid inspectors in conducting thorough and accurate inspections of assembly lines. It guides you through the inspection process and helps you document your findings.

## How To Complete This Form
1.  Enter your **Inspector Name** in the first field. This field is required.
2.  Enter the **Assembly Line ID** number for the line being inspected.
3.  Select the **Current Shift** in which you are conducting the inspection from the dropdown options.
4.  Enter the **Time of Inspection** in the format of HH:MM (e.g., 14:30 for 2:30 PM).
5.  Enter the **Component Batch or Serial Number** for the inspected product or component.
6.  Check the results of the **Visual Inspection**. If the line passes, select **Pass**. If it fails, select **Fail**.
7.  Check the **Dimensional Accuracy Check**. If the inspected product or component meets specifications, select **Within Tolerance**. If it does not, select **Out of Tolerance**.
8.  Check the **Fastener and Torque Verification**. Select **Verified** if all is correct, **Correction Required** if there's a problem, or **Not Applicable** if it's not relevant to the specific inspection.
9.  Perform a **Functional Test Performance** inspection. Select **Optimal** if the line or component functions as intended, **Marginal** if it's slightly below standard, or **Critical Failure** if it's severely impaired.
10. If any of the above checks failed, provide **Details of Non-conformance** in the optional field.
11. If necessary, document the **Immediate Corrective Action Taken** in the optional field.
12. Finally, select the **Post-inspection Line Status** from the dropdown options. If the line is ready to resume production, select **Resume Production**. If it's held for maintenance, select **Hold for Maintenance**. If the inspected product or component is quarantined, select **Quarantine Batch**.

## Field-by-Field Explanation
* **Inspector Name**: Enter your name and title for identification and accountability purposes. This field is required.
* **Assembly Line ID**: Enter the unique identifier for the assembly line being inspected.
* **Current Shift**: Select the current shift during which the inspection is taking place.
* **Time of Inspection**: Enter the exact time of the inspection (HH:MM format).
* **Component Batch or Serial Number**: Enter the batch or serial number of the inspected product or component.
* **Visual Inspection Result**: Check for surface defects or contamination. Select **Pass** for no defects, **Fail** otherwise.
* **Dimensional Accuracy Check**: Verify the dimensions of the inspected product or component meet specified standards. Select **Within Tolerance** if correct, **Out of Tolerance** otherwise.
* **Fastener and Torque Verification**: Check fasteners and torque specifications. Select **Verified** if correct, **Correction Required** for issues, **Not Applicable** for inspections that don't pertain to this check.
* **Functional Test Performance**: Evaluate the line or component's functionality. Select **Optimal** for ideal performance, **Marginal** for slight issues, **Critical Failure** for severe problems.
* **Details of Non-conformance**: If a check failed, describe the reasons and specific issues in this field. (Optional)
* **Immediate Corrective Action Taken**: Document any immediate actions taken to address issues. (Optional)
* **Post-inspection Line Status**: Select the status of the assembly line after inspection. Options include **Resume Production**, **Hold for Maintenance**, and **Quarantine Batch**. This field is required.
