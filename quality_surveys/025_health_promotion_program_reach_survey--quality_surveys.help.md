# Health Promotion Program Reach Survey - Help Guide
## Purpose
This form is designed to collect information about health promotion programs that have reached various populations. It helps health promotion program administrators or coordinators track and record data about their programs, including areas of focus, types, locations, and other relevant details.

## How To Complete This Form

1. Select the program area(s) where the program was conducted.
2. Answer whether the program type is Yes or No.
3. Enter the name of the program.
4. If the program has a repeat or follow-up, select Yes or No.
5. Enter the program start date (if applicable).
6. Enter the program end date (if applicable).
7. Enter the number of program hours conducted.
8. Provide the name of the contact person.
9. Provide the contact email (if applicable).
10. Provide the contact phone number (if applicable).
11. Enter any program notes or comments.
12. Enter the program location (if applicable).
13. Enter the number of program participants (if applicable).
14. Enter the submitted by field with your name or initials.

## Field-by-Field Explanation

* **Program Area** (`program_area`, text, optional): Select the area or region where the program was conducted, e.g., urban, rural, or specific neighborhood.
* **Program Area Repeat** (`program_area_repeat`, text, optional): If the program targeted multiple areas, enter them here.
* **Program Type** (`program_type`, select_one, optional): Answer whether the program was conducted in Yes or No format, e.g., Yes for programs with a specific type.
* **Program Type Repeat** (`program_type_repeat`, select_one, optional): If the program has a specific type, select Yes or No here.
* **Program Name** (`program_name`, text, optional): Enter the name of the program, e.g., name of the program or initiative.
* **Program Name Repeat** (`program_name_repeat`, text, optional): If the program has a repeat or follow-up, enter the new program name here.
* **Program Start Date** (`program_start_date`, date, optional): Enter the start date of the program, in the format YYYY-MM-DD.
* **Program Start Date Repeat** (`program_start_date_repeat`, date, optional): If the program has a repeat or follow-up, enter the new start date here.
* **Program End Date** (`program_end_date`, date, optional): Enter the end date of the program, in the format YYYY-MM-DD.
* **Program End Date Repeat** (`program_end_date_repeat`, date, optional): If the program has a repeat or follow-up, enter the new end date here.
* **Program Hours** (`program_hours`, text, optional): Enter the total number of hours the program was conducted.
* **Program Hours Repeat** (`program_hours_repeat`, text, optional): If the program has a repeat or follow-up, enter the total number of hours here.
* **Contact Person** (`contact_person`, text, optional): Enter the name of the contact person in charge of the program.
* **Contact Email** (`contact_email`, email, optional): Enter the email address of the contact person.
* **Contact Phone** (`contact_phone`, text, optional): Enter the phone number of the contact person.
* **Contact Phone Repeat** (`contact_phone_repeat`, text, optional): If the contact person changed during the repeat or follow-up, enter their new phone number.
* **Program Notes** (`program_notes`, text, optional): Enter any additional comments or notes about the program.
* **Program Notes Repeat** (`program_notes_repeat`, text, optional): If there are notes for the repeat or follow-up, enter them here.
* **Program Location** (`program_location`, text, optional): Enter the location where the program was conducted.
* **Program Location Repeat** (`program_location_repeat`, text, optional): If the program has a repeat or follow-up, enter the new location here.
* **Program Participants** (`program_participants`, text, optional): Enter the number of program participants.
* **Program Participants Repeat** (`program_participants_repeat`, text, optional): If the repeat or follow-up program had a different number of participants, enter the new number here.
* **Submitted By** (`submitted_by`, text, optional): Enter your name or initials, e.g., for reporting and tracking purposes.
