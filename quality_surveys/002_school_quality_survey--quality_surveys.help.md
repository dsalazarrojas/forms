# School Quality Survey - Help Guide
## Purpose
The School Quality Survey is a form designed to collect feedback on the quality of a school. Your responses will help us understand your experience and identify areas for improvement.

## How To Complete This Form
1. Select the options that best describe your experience at the school.
2. Answer each question to provide as much detail as possible.
3. Click "Submit" to send your feedback.

## Field-by-Field Explanation
* **School Quality** (`school_quality`, select_multiple, required: false):
	+ This field asks you to rate the overall quality of the school. Select from the options: Good, Poor.
* **School Administration** (`school_admin`, select_one, required: false):
	+ This field asks you to rate how satisfactory you found the school administration. Select from the options: very satisfactory, fairly satisfactory, very unsatisfactory.
* **School Facilities** (`school_facilities`, select_multiple, required: false):
	+ This field asks you if you have access to necessary facilities at the school. Select from the options: Yes, No.
* **Teachers Quality** (`teachers_quality`, text, required: false):
	+ This field is a text input where you can describe the quality of the teachers you have interacted with.
* **Teacher Support** (`teacher_support`, select_multiple, required: false):
	+ This field asks you if you feel supported by the teachers. Select from the options: Yes, No.
* **Student Life** (`student_life`, select_multiple, required: false):
	+ This field asks you about your overall life at the school. Select from the options: Yes, No.
* **Student Support Services** (`student_support_services`, select_multiple, required: false):
	+ This field asks you if you have access to necessary support services for students. Select from the options: Yes, No.
* **Student Career Services** (`student_career_services`, select_multiple, required: false):
	+ This field asks you if you have access to career services for students. Select from the options: Yes, No.
* **Student Academic Services** (`student_academic_services`, select_multiple, required: false):
	+ This field asks you if you have access to academic services for students. Select from the options: Yes, No.
* **School Location** (`school_location`, select_one, required: false):
	+ This field asks you to describe the location of the school. Select from the options: urban, rural.
* **School Size** (`school_size`, select_one, required: false):
	+ This field asks you to describe the size of the school. Select from the options: small, large.
* **Student Population** (`student_population`, text, required: false):
	+ This field is a text input where you can describe the size of the student population.

## Tips
* Answer honestly and to the best of your ability.
* Please do not submit duplicate responses.
* If you have any questions or concerns, please contact us directly.
