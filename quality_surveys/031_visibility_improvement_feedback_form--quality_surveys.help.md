# Visibility Improvement Feedback Form - Help Guide
## Purpose
The Visibility Improvement Feedback Form is designed to help the operations team understand how users perceive the completion status of a facility after receiving a follow-up from the operations team. This form is meant to collect feedback from users about the improvement in visibility of a facility.

## How To Complete This Form
To complete this form, follow these steps:

1. Choose the facility that this feedback is about.
2. Answer the "Feedback" question with your thoughts about the facility's visibility improvement.
3. Select the "Before Result" option that best describes how you initially perceived the facility's completion status.
4. Select the "After Result" option that best describes how you perceive the facility's completion status after receiving the follow-up from the operations team.
5. If necessary, provide additional information in the "Result Differ" field.
6. Enter the follow-up date and time, if applicable.
7. Enter any additional comments or notes in the "Facility Notes", "Safety Notes", "Operations Notes", and "Jotform" fields, if necessary.

## Field-by-Field Explanation
* **facility_id (1)**: This is the ID of the facility that this feedback is about. Please select the facility from the list of options.
* **Feedback (2)**: Describe your thoughts about the facility's visibility improvement. What did you experience? What worked or didn't work?
* **Before Result (3)**: Select the option that best describes how you initially perceived the facility's completion status. Choose one of the following:
	+ Reported as completed
	+ Reported as partially completed
	+ Reported as incompleted
* **After Result (4)**: Select the option that best describes how you perceive the facility's completion status after receiving the follow-up from the operations team. Choose one of the following:
	+ Reported as completed
	+ Partially reported as completed
	+ Not reported as completed
* **Result Differ (5)**: If you noticed any difference in the facility's completion status after receiving the follow-up, enter the number of days or hours that the difference took place.
* **Follow-up (6)**: Enter the date and time of the follow-up you received from the operations team.
* **Follow-up Time (7)**: Enter the time of the follow-up you received from the operations team.
* **Facility Notes (8)**: Add any additional comments or notes about the facility.
* **Safety Notes (9)**: Add any safety-related comments or notes about the facility.
* **Operations Notes (10)**: Add any operations-related comments or notes about the facility.
* **Jotform (11)**: Add any additional comments or notes about the facility.
* **Facility ID 1 (12)**: This is another field for selecting a facility. Select the facility from the list of options.
* **Facility ID 2 (13)**: This is another field for selecting multiple facilities. Select the facilities from the list of options.
* **Facility ID 3 (14)**: This is another field for selecting multiple facilities. Select the facilities from the list of options.
