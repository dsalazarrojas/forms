# Lab Instrument Calibration Report Form - Help Guide
## Purpose
The Lab Instrument Calibration Report Form is used to collect information about lab instruments, including their calibration status and frequency. This form helps maintain accurate and reliable results in laboratory settings.

## How To Complete This Form
1. Start by entering the instrument ID, which is a unique identifier for the instrument.
2. Select the calibration date, which is the date when the instrument was last calibrated.
3. Choose the calibration frequency, which indicates how often the instrument should be calibrated. Options include:
	* Daily
	* Weekly
	* Monthly
	* Quarterly
	* Semi-Annually
	* Annually
4. Select the calibration status, which indicates the current state of the instrument:
	* In progress
	* Completed
	* Not completed
5. Enter the name of the technician who performed the calibration, if applicable.
6. Add any additional remarks or comments about the instrument, if necessary.

## Field-by-Field Explanation

* **Instrument ID** (instrument_id): This is a unique identifier for the instrument.
* **Calibration Date** (calibration_date): The date when the instrument was last calibrated.
* **Calibration Frequency** (calibration_frequency): Indicates how often the instrument should be calibrated.
* **Calibration Status** (calibration_status): Indicates the current state of the instrument.
* **Technician** (technician): The name of the technician who performed the calibration, if applicable.
* **Remarks** (remarks): Additional comments or notes about the instrument, if necessary.

## Tips
- Make sure to fill in the instrument ID accurately, as it is a unique identifier.
- Select the correct calibration frequency and status to ensure proper maintenance.
- Add any necessary remarks or comments to provide more information about the instrument.
- Review the form carefully before submitting to ensure all fields are filled in accurately.
