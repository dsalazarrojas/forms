# Veterinary Supplier Quality Rating Survey - Help Guide
## Purpose
This form is designed to collect feedback and ratings from users about their experience with a veterinary supplier. It helps the quality assurance team to evaluate and improve the quality of service provided by veterinary suppliers.

## How To Complete This Form

To complete this form, follow the steps below:

1. Ensure that you are filling out this form for a specific veterinary supplier and that you have not already submitted a rating for the same supplier.
2. Fill in the required fields with accurate information.
3. Provide a clear and concise rating for each rating scale.
4. Add any additional comments or notes as needed.

## Field-by-Field Explanation

* **Supplier Name (Required)** (`supplier_name`, `text`): Enter the name of the veterinary supplier you are rating.
* **Rating Scale (Required)** (`rating_scale`, `select_one`): Select one of the following options: Poor, Fair, Good, Very Good, Excellent.
* **Contact Name (Optional)** (`contact_name`, `text`): Enter the name of the contact person associated with the supplier.
* **Contact Email (Optional)** (`contact_email`, `text`): Enter the email address of the contact person associated with the supplier.
* **Rating Scale 1 (Required)** (`rating_scale_1`, `select_one`): Select one of the following options: Poor, Fair, Good, Very Good, Excellent.
* **Rating Scale 2 (Required)** (`rating_scale_2`, `select_one`): Select one of the following options: Poor, Fair, Good, Very Good, Excellent.
* **Comment (Optional)** (`comment`, `text`): Enter any additional comments or notes about the supplier.
* **Supplier Rating (Required)** (`supplier_rating`, `number`): Enter a numerical rating for the supplier (0-10).
* **Submission Date (Optional)** (`submission_date`, `date`): Enter the date and time of submission.
* **Submission Time (Optional)** (`submission_time`, `time`): Enter the time of submission.
* **Submitted By (Required)** (`submitted_by`, `text`): Enter your name and initials.
* **Rating Scale 3 (Required)** (`rating_scale_3`, `select_one`): Select one of the following options: Poor, Fair, Good, Very Good, Excellent.
* **Rating Scale 4 (Required)** (`rating_scale_4`, `select_one`): Select one of the following options: Poor, Fair, Good, Very Good, Excellent.
* **Overall Rating (Required)** (`overall_rating`, `select_one`): Select one of the following options: Poor, Fair, Good, Very Good, Excellent.
* **Comment 2 (Optional)** (`comment_2`, `text`): Enter any additional comments or notes about the supplier.
* **Submission Notes (Optional)** (`submission_notes`, `text`): Enter any additional notes about the submission process.
* **Supplier Notes (Optional)** (`supplier_notes`, `text`): Enter any notes about the supplier.
* **Follow-up Action (Required)** (`follow_up_action`, `select_one`): Select one of the following options: Schedule follow-up, Send reminder, No action.
* **Next Follow-up Date (Optional)** (`next_follow_up_date`, `date`): Enter the next follow-up date.
* **Follow-up Status (Required)** (`follow_up_status`, `select_one`): Select one of the following options: Completed, Not Completed, Not Applicable.
* **Supplier Response (Optional)** (`supplier_response`, `text`): Enter any response from the supplier.
* **Rating Scale 5 (Optional)** (`rating_scale_5`, `select_one`): Select one of the following options: Poor, Fair, Good, Very Good, Excellent.
* **Rating Scale 6 (Optional)** (`rating_scale_6`, `select_one`): Select one of the following options: Poor, Fair, Good, Very Good, Excellent.
* **Rating Scale 7 (Optional)** (`rating_scale_7`, `select_one`): Select one of the following options: Poor, Fair, Good, Very Good, Excellent.
* **Submission Date 1 (Optional)** (`submission_date_1`, `date`): Enter the submission date and time.

Note: All required fields must be filled out for the submission to be valid.
