# Pressure Injury Prevention Survey - Help Guide
## Purpose
This form is designed to collect information on the prevention practices and training needs related to pressure ulcers in healthcare settings. It helps healthcare organizations assess the effectiveness of their prevention practices and identify areas for improvement.

## How To Complete This Form
To complete this survey, please answer each question to the best of your ability. The questions are designed to be self-explanatory, but here's a brief explanation of each section:

## Field-by-Field Explanation
- **Introduction**: The introduction section provides a brief background on the purpose of the survey.
  * **Prevention Practices** (Q1): This question asks about the practices used to prevent pressure ulcers. You can select all that apply.
  * **Training Needs** (Q2): This question asks about the staff that requires training on pressure ulcer prevention. You can select one option.
  * **Barriers** (Q3): This question asks about the barriers to providing pressure ulcer prevention training. You can select one option.
  * **Comments** (Q4): This is an optional text field for any additional comments or feedback.

**Prevention Practices** questions 5, 14, 16, 18, 20:
  * **Preventing pressure ulcers** (Q5, Q14): This question asks about the frequency of preventing pressure ulcers. You can select one of the following options:
    * Always
    * Sometimes
    * Never
    * Unsure
  * **Using compression devices** (Q16, Q17): This question asks about the use of compression devices. You can select one of the following options:
    * Always
    * Sometimes
    * Never
    * Unsure
  * **Using foam** (Q18, Q19): This question asks about the use of foam. You can select one of the following options:
    * Always
    * Sometimes
    * Never
    * Unsure

**Barriers** questions 4, 11, 13:
  * **Barriers** (Q4, Q11): This question asks about the barriers to providing pressure ulcer prevention training. You can select one of the following options:
    * Lack of training
    * Limited resources
    * Lack of support
  * **Other barriers** (Q13, Q20, Q21): This question asks for any additional barriers to providing pressure ulcer prevention training.

## Tips
* Please answer each question honestly and to the best of your ability.
* You can select multiple options for the "Prevention Practices" question.
* If you have any additional comments or feedback, please use the "Comments" field.
