# Property Renovation Quality Survey - Help Guide
## Purpose
The Property Renovation Quality Survey is designed to gather user feedback on the quality of a property renovation project. This form will help us understand what aspects of the project were done well and where we can improve.

## How To Complete This Form
To complete this form, please follow these steps:

1. Start by reading the introduction page (page 1) to understand the purpose of the form.
2. On the second page, select "Yes" if you were satisfied with the performance of the contractor, or "No" if you were not.
3. On the third page, select all that apply for the quality rating of the renovation. Choose "Good" for satisfactory results and "Poor" for unsatisfactory results.
4. On the fourth page, select "Yes" if you were satisfied with the communication from the contractor, or "No" if you were not.
5. On the final page, you can add any additional comments or feedback about the project.

## Field-by-Field Explanation
### Property Renovation Quality Survey Page 1
* **Property Renovation Quality Survey Page 1** (`property_renovation_quality_survey_page_1`, `note`, optional): This is the introduction page to the form. Please read it carefully to understand the purpose and instructions of the form.

### Contractor Performance
* **Contractor Performance** (`contractor_performance`, `select_one`, optional): This page asks whether you were satisfied with the performance of the contractor. Please select "Yes" for satisfactory performance and "No" for unsatisfactory performance.

### Quality Rating
* **Quality Rating** (`quality_rating`, `select_multiple`, optional): This page asks for your rating of the quality of the renovation. Please select all that apply. If you were satisfied with the results, choose "Good" and "Good". If you were unsatisfied with the results, choose "Poor" and "Good" is not applicable.

### Communication
* **Communication** (`communication`, `select_one`, optional): This page asks whether you were satisfied with the communication from the contractor. Please select "Yes" for satisfactory communication and "No" for unsatisfactory communication.

### Property Renovation Quality Survey Page 5
* **Property Renovation Quality Survey Page 5** (`property_renovation_quality_survey_page_5`, `note`, optional): This page is for additional comments or feedback about the project. Please use this space to provide any further information about your experience with the renovation.
