# Metal Measurement Standardization Survey - Help Guide
## Purpose
The purpose of this survey is to collect information about metal measurement standardization practices, needs, and processes.

## How To Complete This Form
To complete this form, please follow the steps below:

1. Review each page and ensure you have all the necessary information and data ready before proceeding.
2. Read each field description to understand what information is being requested.
3. Fill in the form accurately and thoroughly, taking care to follow the instructions for each field.

## Field-by-Field Explanation

* **Introduction** (`page_1`, Note, not required): This field is a brief introduction to the survey. It's not required to answer this question, but reading it will help you understand the context of the form.
* **Metal Analysis (page 2)** (`metal_analysis_p1`, Text, not required): This field is for any additional information or analysis related to the metal being measured. You can enter any relevant details or comments about the metal's properties or characteristics.
* **Standardization Needs** (`page_3`, Select Multiple, not required): Please select all standardization needs that apply to your metal measurement process. These options are:
	+ Yes
	+ No
* **Lab Equipment** (`page_4`, Select One, not required): Please select if you have the necessary lab equipment for standardization.
	+ Yes
	+ No
* **Manufacturer Info** (`page_5`, Select One, not required): Please select if you have the necessary information from the manufacturer about the metal's standardization.
	+ Yes
	+ No
* **Sample Info** (`page_6`, Select One, not required): Please select if you have the necessary information from the sample about the metal's standardization.
	+ Yes
	+ No
* **Data Collection** (`page_7`, Number, not required): This field is for entering numerical data related to the metal's standardization. Please enter a number that represents the data collected.
* **Standardization Needs** (`page_8`, Select Multiple, not required): Please select all standardization needs that apply to your metal measurement process. These options are:
	+ Yes
	+ No
* **Standardization Processes** (`page_9`, Select Multiple, not required): Please select all standardization processes that you use for your metal measurement process. These options are:
	+ Yes
	+ No
* **Standardization Results** (`page_10`, Select Multiple, not required): Please select all standardization results that you have achieved for your metal measurement process. These options are:
	+ Yes
	+ No
