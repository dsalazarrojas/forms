# Spray Batch Production Log - Help Guide
## Purpose
The Spray Batch Production Log is a form used to record the production details of a specific batch of spray production. It helps track and document the production process, ensuring accurate and efficient management of production data.

## How To Complete This Form
1. Fill in the `Batch ID` field with a unique identifier for this production batch.
2. Enter the `Production Date` in the format `YYYY-MM-DD`.
3. Enter the `Production Time` in the format `HH:MM:SS`.
4. Fill in the `Batch Number` field with the specific production batch number.
5. Enter the `Equipment ID` field with the equipment used for production.
6. Enter the `Operator ID` field with the name or ID of the operator who performed the production.
7. Provide detailed `Production Details` about the production process.
8. Enter the `Batch Weight` field with the weight of the produced batch.
9. Select the `Batch Weight UOM` field with the unit of measurement used for the batch weight (e.g., kg).
10. Enter the `Production Location` field with the location where the production took place.
11. Select the `Production Status` field with the status of the production (Running, Completed, or Aborted).
12. Enter `Operator Comments` if any comments from the operator are necessary.
13. Enter `Supervisor Comments` if any comments from the supervisor are necessary.
14. Add `Additional Notes` for any other important details.

## Field-by-Field Explanation
- **Batch ID** (batch_id, number, optional): A unique identifier for this production batch.
- **Production Date** (production_date, date, optional): The date on which the production took place.
- **Production Time** (production_time, time, optional): The time of the production.
- **Batch Number** (batch_number, text, optional): The specific production batch number.
- **Equipment ID** (equipment_id, number, optional): The equipment used for production.
- **Operator ID** (operator_id, text, optional): The name or ID of the operator who performed the production.
- **Production Details** (production_details, text, optional): Detailed information about the production process.
- **Batch Weight** (batch_weight, number, optional): The weight of the produced batch.
- **Batch Weight UOM** (batch_weight_uom, text, optional): The unit of measurement for the batch weight (e.g., kg).
- **Production Location** (production_location, text, optional): The location where the production took place.
- **Production Status** (production_status, select_one, optional): Select the status of the production (Running, Completed, or Aborted).
- **Operator Comments** (operator_comments, text, optional): Comments from the operator.
- **Supervisor Comments** (supervisor_comments, text, optional): Comments from the supervisor.
- **Additional Notes** (notes, text, optional): For any other important details.
