# Study Data Quality Assessment Form - Help Guide
## Purpose
The Study Data Quality Assessment Form is a tool used to evaluate the quality of study data. It helps assessors evaluate and provide feedback on the quality of data collected during studies. The form is divided into sections that cover various aspects of data quality, including overall data quality, data errors, data formatting, and more. The form is designed to provide a comprehensive assessment of study data, helping to identify areas that require improvement.

## How To Complete This Form
To complete this form, follow these steps:

1. Review the study data carefully.
2. Answer each field according to your assessment of the data quality.
3. Select the relevant options for each field based on your evaluation.
4. Provide any additional comments or feedback in the "Additional Comments" field if needed.

## Field-by-Field Explanation

* **Overall Data Quality** (`1`, `text`, required): Evaluate the overall quality of the study data. Provide a brief description of your assessment.
* **Data Errors** (`2`, `select_multiple`, required): Check the relevant options for any data errors you have identified.
  - **Yes**: You have identified data errors in the study data.
  - **No**: There are no data errors in the study data.
* **Data Formatting** (`3`, `text`, required): Assess the formatting of the study data. For example, if the data is well-formatted and easily read, select "Good". If the data is poorly formatted, select "Poor".
* **Data Linking** (`4`, `select_one`, required): Evaluate whether the data linking is correct or incorrect.
  - **Yes**: The data linking is correct.
  - **No**: The data linking is incorrect.
* **Data Update** (`5`, `text`, required): Assess the update status of the study data. For example, if the data is up-to-date, select "Good". If the data is outdated, select "Poor".
* **Data Labeling** (`6`, `text`, required): Evaluate the labeling of the study data. For example, if the data is well-labeled and easy to understand, select "Good". If the data is poorly labeled, select "Poor".
* **Duplicate Data** (`7`, `select_multiple`, required): Check for duplicate data in the study data. Select the relevant options based on your assessment.
  - **Yes**: There is duplicate data in the study data.
  - **No**: There is no duplicate data in the study data.
* **Data Aggregation** (`8`, `text`, required): Assess the aggregation status of the study data. For example, if the data is aggregated correctly, select "Good". If the data is not aggregated correctly, select "Poor".
* **Data Averaging** (`9`, `text`, required): Evaluate the averaging status of the study data. For example, if the data is averaged correctly, select "Good". If the data is not averaged correctly, select "Poor".
* **Missing Data** (`10`, `select_multiple`, required): Check for missing data in the study data. Select the relevant options based on your assessment.
  - **Yes**: There is missing data in the study data.
  - **No**: There is no missing data in the study data.
* **Data Sourcing** (`11`, `text`, required): Assess the sourcing status of the study data. For example, if the data is sourced from credible sources, select "Good". If the data is sourced from poor sources, select "Poor".
* **Data Obsolete** (`12`, `select_multiple`, required): Check for obsolete data in the study data. Select the relevant options based on your assessment.
  - **Yes**: There is obsolete data in the study data.
  - **No**: There is no obsolete data in the study data.
* **Study Data Quality Form 13** (`13`, `text`, required): This field is intended for any additional comments or feedback on the study data quality.
* **Additional Comments** (`14`, `text`, optional): Provide any additional comments or feedback on the study data quality, if needed.
