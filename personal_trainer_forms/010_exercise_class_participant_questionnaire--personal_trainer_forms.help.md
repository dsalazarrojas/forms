# exercise_class_participant_questionnaire - Help Guide
## Purpose
The exercise_class_participant_questionnaire form is a tool for participants to provide information about themselves and their exercise class experiences. This form will help the instructor or trainer to tailor the class to the participant's needs and preferences.

## How To Complete This Form
To complete this form, follow these steps:

1. Answer all the questions to the best of your ability. If you are unsure of any information, please provide an answer that is as accurate as possible.
2. If you have a specific goal or objective that is not listed, please select "Other" for the corresponding field and provide your own answer.
3. If you have any previous exercise class experiences, please describe them in the space provided.

## Field-by-Field Explanation
### Participant Information (1)
* **Participant Information** (`participant_information`, text, optional): This field is for providing any additional information about yourself that you think would be helpful for the instructor to know.

### Exercise Class Info (2)
* **Exercise Class Info** (`exercise_class_info`, text, optional): This field is for providing any additional information about the exercise class you are interested in.

### Participant Goal (3)
* **Participant Goal** (`participant_goal`, select_one, optional): Select one of the goals listed (Goal 1, Goal 2, Goal 3) that best describes your reason for taking the exercise class. If none of the listed goals apply, select "Other" and provide your own answer.

### Other (4)
* **Other** (`participant_goal_other`, text, optional): If you selected "Other" for the Participant Goal field, provide your own answer.

### Exercise Name (5)
* **Exercise Name** (`exercise_name`, select_one, optional): Select one of the exercises listed (Squats, Lunges, Push-ups) that you are interested in. If none of the listed exercises apply, select "Other" and provide your own answer.

### Other Exercise Name (6)
* **Other Exercise Name** (`exercise_name_other`, text, optional): If you selected "Other" for the Exercise Name field, provide your own answer.

### Participant Notes (7)
* **Participant Notes** (`participant_notes`, note, optional): This is a text area for you to provide any additional information about yourself that you think would be helpful for the instructor to know.

### Participant Contact (8)
* **Participant Contact** (`participant_contact`, text, optional): This field is for providing your contact information.

### Email (9)
* **Email** (`participant_email`, email, optional): This is your email address that we may use to contact you.

### Phone (10)
* **Phone** (`participant_phone`, text, optional): This field is for providing your phone number.

### Exercise Class Start Date (11)
* **Exercise Class Start Date** (`exercise_class_start_date`, date, optional): Enter the date you would like to start the exercise class.

### Exercise Class Start Time (12)
* **Exercise Class Start Time** (`exercise_class_start_time`, time, optional): Enter the time you would like to start the exercise class.

### Exercise Class Duration (13)
* **Exercise Class Duration** (`exercise_class_duration`, number, optional): Enter the duration of the exercise class in minutes.

### Exercise Class Location (14)
* **Exercise Class Location** (`exercise_class_location`, text, optional): This field is for providing the location of the exercise class.

### Participant Previous Exercise Classes (15)
* **Participant Previous Exercise Classes** (`participant_previous_exercise_classes`, text, optional): Describe any previous exercise class experiences you have had.

### Other Previous Exercise Classes (16)
* **Other Previous Exercise Classes** (`participant_previous_classes_other`, text, optional): If you answered "Other" for the Participant Previous Exercise Classes field, provide your own answer.

### Participant Previous Classes Frequency (17)
* **Participant Previous Classes Frequency** (`participant_previous_classes_frequency`, select_one, optional): Select one of the frequencies listed (Daily, Weekly, Monthly) that best describes how often you participate in exercise classes.

### Other Previous Classes Frequency (18)
* **Other Previous Classes Frequency** (`participant_previous_classes_frequency_other`, text, optional): If you selected "Other" for the Participant Previous Classes Frequency field, provide your own answer.

### Participant Previous Classes Comments (19)
* **Participant Previous Classes Comments** (`participant_previous_classes_comments`, text, optional): This field is for providing any additional information about your previous exercise class experiences.

### Participant Previous Classes Reason for Stopping (20)
* **Participant Previous Classes Reason for Stopping** (`participant_previous_classes_reason_for_stopping`, text, optional): If you have stopped participating in exercise classes, provide a reason why.

### Other Previous Classes (21)
* **Other Previous Classes** (`participant_previous_classes_other_2`, text, optional): If you answered "Other" for the Participant Previous Classes field, provide your own answer.

### Other Details (22)
* **Other Details** (`participant_goal_other_details`, text, optional): If you selected "Other" for the Participant Goal field, provide additional details.

### Participant Previous Classes Injuries (23)
* **Participant Previous Classes Injuries** (`participant_previous_classes_injuries`, text, optional): This field is for describing any injuries you have had while participating in exercise classes.

### Participant Previous Classes Medical Conditions (24)
* **Participant Previous Classes Medical Conditions** (`participant_previous_classes_medical_conditions`, text, optional): This field is for describing any medical conditions you have that may be relevant to exercise class participation.

### Participant Previous Classes Notes (25)
* **Participant Previous Classes Notes** (`participant_previous_classes_notes`, note, optional): This is a text area for providing any additional information about your previous exercise class experiences.

### Tips
* Please answer all questions to the best of your ability.
* If you have any questions or concerns, do not hesitate to contact us.
* We appreciate your participation and look forward to working with you.
