# Weighted Dip Exercise Form - Help Guide
## Purpose
The Weighted Dip Exercise Form is used to record and track the details of a weighted dip exercise, including the date of the exercise, weight used, repetitions, exercise type, weight machine used, weight machine setting, weight used (machine), and additional notes.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the date of the exercise using the calendar picker for "Date of Exercise".
2. Enter the weight used for the exercise in the "Weight Used" field.
3. Enter the number of repetitions completed in the "Repetitions" field.
4. Select the exercise type from the dropdown menu in the "Exercise Type" field.
5. Choose the weight machine used from the dropdown menu in the "Weight Machine Used" field.
6. Select the weight machine setting from the dropdown menu in the "Weight Machine Setting" field.
7. Enter the weight used (machine) in the "Weight Used (Machine)" field.
8. Enter any additional notes about the exercise in the "Notes" field.

## Field-by-Field Explanation
* **Exercise Form** (`exercise_form`, text, required): Enter a brief description of the exercise, including the type of exercise and any relevant details.
* **Date of Exercise** (`date_of_exercise`, date, required): Enter the date of the exercise using the calendar picker.
* **Weight Used** (`weight_used`, number, required): Enter the weight used for the exercise.
* **Repetitions** (`repetitions`, number, required): Enter the number of repetitions completed.
* **Exercise Type** (`exercise_type`, select_one, required): Select the type of exercise from the dropdown menu.
* **Weight Machine Used** (`weight_machine_used`, select_multiple, required): Choose the weight machine used from the dropdown menu.
* **Weight Machine Setting** (`weight_machine_setting`, select_multiple, required): Select the weight machine setting from the dropdown menu.
* **Weight Used (Machine)** (`weight_used_weight_machine`, number, required): Enter the weight used for the machine.
* **Notes** (`notes`, text, required): Enter any additional notes about the exercise.
* **Notes (Machine)** (`notes_weight_machine`, text, optional): Enter any additional notes about the machine used.
* **Email** (`email`, email, optional): Enter your email address.
* **Phone Number** (`phone_number`, text, optional): Enter your phone number.
* **Coach Notes** (`coach_notes`, text, optional): Enter any notes from the coach.
* **Gym Location** (`gym_location`, text, optional): Enter the gym location.
* **Coach Name** (`coach_name`, text, optional): Enter the coach's name.
* **Athlete Name** (`athlete_name`, text, optional): Enter the athlete's name.
* **Athlete ID** (`athlete_id`, select_one, optional): Select the athlete's ID from the dropdown menu.
