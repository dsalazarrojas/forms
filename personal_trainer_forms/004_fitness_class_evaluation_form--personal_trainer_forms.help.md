# Fitness Class Evaluation Form - Help Guide
## Purpose
The purpose of this form is to gather feedback from clients about their experience with a fitness class.

## How To Complete This Form
To complete this form, simply follow the steps below:

1. Answer each question truthfully, selecting all options that apply.
2. Make sure to fill out each field only once.

## Field-by-Field Explanation
### 1. **Overall Rating**
(overall_rating, number, optional)
This question is asking for your overall rating of the fitness class. Please select one of the following options:

* A 1-5 scale, where:
	+ 1: Very Poor
	+ 2: Poor
	+ 3: Average
	+ 4: Good
	+ 5: Excellent

### 2. **Did You Class Experience?**
(class_experience, select_one, optional)
