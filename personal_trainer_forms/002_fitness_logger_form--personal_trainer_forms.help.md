# Fitness Logger Form - Help Guide
## Purpose
The Fitness Logger Form is a comprehensive form designed for logging and tracking client fitness information.

## How To Complete This Form

To complete the form, follow these steps:

1. Start by filling out the Client Information section, which includes fields for client's name, phone number, email, fitness goal, and selecting the type of client.
2. Proceed to the Progress Logs section, where you can record exercise and weight logs, as well as take progress photos and notes.

## Field-by-Field Explanation

* **Client Name** (1): Enter the client's name.
* **Date** (2): Enter the date of the session.
* **Exercise** (3): Select the type of exercise the client performed. Choose from the options: Option 1, Option 2, Option 3, or select Other.
* **Weight** (4): Enter the client's weight.
* **Email** (5): Enter the client's email address.
* **Phone Number** (6): Enter the client's phone number.
* **Fitness Goal** (7): Select the client's fitness goal. Choose from the options: Option 1, Option 2, or select Other.
* **Notes** (8): Enter any additional notes about the session.
* **Notes 2** (9): Enter any additional notes about the session.
* **Exercise Log** (10): Record the client's exercise log.
* **Notes 3** (11): Enter any additional notes about the session.
* **Weight Log** (12): Record the client's weight log.
* **Progress Photos** (13): Upload progress photos of the client.
* **Additional Notes** (14): Enter any additional notes about the session.
* **Workout Log** (15): Record the client's workout log.
* **Progress Notes** (16): Enter progress notes about the client's progress.
* **Client Info** (17): Select the type of client (e.g., individual, personal trainer). Choose from the options: Option 1, Option 2, Option 3, or select Other.
