# Project Execution Readiness Survey - Help Guide
## Purpose

The Project Execution Readiness Survey is a tool to assess the current status and readiness of a project to be executed.

## How To Complete This Form

1. Choose the correct option for each field based on your knowledge of the project.
2. Select "Ready" or "Not Ready" for the project execution readiness.
3. Enter the project launch date in the format mm/dd/yyyy.
4. Enter the project manager's name.
5. Enter the lead officer's name.
6. Choose the project execution status (On Track, Delayed, or At Risk).
7. Select risk factors that apply to the project (Resource constraints, Time constraints, Financial constraints, or Other).
8. Enter the project start date in the format mm/dd/yyyy.
9. Enter the project end date in the format mm/dd/yyyy.
10. Enter the team size.
11. Enter the team diversity.
12. Enter the team location.
13. Enter the project budget.
14. Enter the project scope.
15. Enter the project schedule.
16. Enter a brief description of the risk.
17. Enter an action plan to address the risk.
18. Enter the team's skills and expertise.
19. Choose the project phase (Phase 1, Phase 2, or Phase 3).
20. Enter a description of the project phase.
21. Choose the project status (Active, Inactive, or Archived).
22. Choose whether the project has a category (Yes or No).
23. Enter a brief description of the project.
24. Enter the project owner's name.
25. Enter the project manager's name.
26. Enter the project executive's name (if applicable).

## Field-by-Field Explanation

* **Project Launch Readiness** (`project_execution_readiness_survey`, `select_one`, required): Choose "Ready" if the project is ready to be executed, "Not Ready" if it's not ready, or "Undetermined" if you're unsure.
* **Project Launch Date** (`project_launch_date`, `date`, required): Enter the date when the project will be launched. Format: mm/dd/yyyy.
* **Project Manager** (`project_manager_name`, `text`, required): Enter the name of the project manager.
* **Lead Officer** (`lead_officer_name`, `text`, required): Enter the name of the lead officer.
* **Project Execution Status** (`project_execution_status`, `select_one`, required): Choose "On Track" if the project is progressing as planned, "Delayed" if it's behind schedule, or "At Risk" if the project faces significant challenges.
* **Risk Factors** (`risk_factors`, `select_multiple`, required): Select risk factors that apply to the project, such as Resource constraints, Time constraints, Financial constraints, or Other (please specify).
* **Project Start Date** (`project_start_date`, `date`, required): Enter the date when the project started. Format: mm/dd/yyyy.
* **Project End Date** (`project_end_date`, `date`, required): Enter the date when the project will end. Format: mm/dd/yyyy.
* **Team Size** (`team_size`, `text`, required): Enter the number of team members.
* **Team Diversity** (`team_diversity`, `text`, required): Enter the diversity of the team.
* **Team Location** (`team_location`, `text`, required): Enter the location where the team is based.
* **Project Budget** (`project_budget`, `number`, required): Enter the total project budget.
* **Project Scope** (`project_scope`, `text`, required): Enter a brief description of the project scope.
* **Project Schedule** (`project_schedule`, `text`, required): Enter the project schedule.
* **Risk Description** (`risk_description`, `text`, required): Enter a brief description of the risk.
* **Action Plan** (`action_plan`, `text`, required): Enter a plan to address the risk.
* **Team Skills** (`team_skills`, `text`, required): Enter the skills and expertise of the team.
* **Project Phase** (`project_phase`, `select_one`, required): Choose the current project phase (Phase 1, Phase 2, or Phase 3).
* **Project Phase Description** (`project_phase_description`, `text`, required): Enter a description of the project phase.
* **Project Status** (`project_status`, `select_one`, required): Choose the project status (Active, Inactive, or Archived).
* **Project Category** (`project_category`, `select_one`, required): Choose whether the project has a category (Yes or No).
* **Project Description** (`project_description`, `text`, required): Enter a brief description of the project.
* **Project Owner** (`project_owner`, `text`, required): Enter the name of the project owner.
* **Project Manager** (`project_manager`, `text`, required): Enter the name of the project manager.
* **Project Executive** (`project_executive`, `text`, optional): Enter the name of the project executive.
