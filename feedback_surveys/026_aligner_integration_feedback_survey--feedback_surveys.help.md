# Aligner Integration Feedback Survey - Help Guide
## Purpose
This survey is designed to gather feedback from users about their experience with Aligner Integration. The goal is to collect information about the effectiveness and usability of the system, as well as potential issues and areas for improvement.

## How To Complete This Form
To complete this form, follow these steps:

* Read each question carefully and answer accordingly.
* Provide detailed answers to the open-ended questions.
* Select one answer for each multiple-choice question.
* You can skip questions that are not applicable to your experience.

## Field-by-Field Explanation

* **Respondent Name** (`respondent_name`, `text`, required/optional): Enter your full name.
* **Email Address** (`email_address`, `email`, required/true): Enter your contact email address.
* **Practice Name** (`practice_name`, `text`, required/true): Enter the name of your dental practice.
* **Practice Type** (`practice_type`, `select_one`, required/true): Select the type of practice you work in (e.g. Private practice, Group practice, DSO/Corporate, etc.).
* **Your Role** (`role_in_practice`, `select_one`, required/true): Select your role in the practice (e.g. Dentist/Orthodontist, Dental Assistant, Treatment Coordinator, etc.).
* **Aligner System Used** (`aligner_system_used`, `select_one`, required/true): Select the Aligner system you use (e.g. Invisalign, ClearCorrect, Spark Aligners, etc.).
* **Integration Type** (`integration_type`, `select_one`, required/true): Select the type of integration you use (e.g. Practice management software, Imaging software, Scanning system, etc.).
* **Integration Duration** (`integration_duration`, `select_one`, required/true): Select how long you have been using the integration (e.g. Less than 1 month, 1-3 months, etc.).
* **Ease of Initial Setup** (`ease_of_setup`, `select_one`, required/true): Rate the ease of initial setup of the integration (e.g. Very Easy, Easy, Moderate, etc.).
* **Ease of Daily Use** (`ease_of_use`, `select_one`, required/true): Rate the ease of daily use of the integration (e.g. Very Easy, Easy, Moderate, etc.).
* **Reliability Rating** (`reliability_rating`, `select_one`, required/true): Rate the reliability of the integration (e.g. Excellent, Good, Average, Poor, etc.).
* **Data Sync Accuracy** (`data_sync_accuracy`, `select_one`, required/true): Rate the accuracy of data synchronization (e.g. Excellent, Good, Average, Poor, etc.).
* **Workflow Improvement** (`workflow_improvement`, `select_one`, required/true): Select how the integration has improved your workflow (e.g. Significantly improved, Somewhat improved, No change, etc.).
* **Time Savings** (`time_savings`, `select_one`, required/true): Select the estimated hours saved per week due to the integration (e.g. No time saved, 1-2 hours, 3-5 hours, etc.).
* **Patient Experience Impact** (`patient_experience_impact`, `select_one`, required/true): Select the impact on patient experience (e.g. Significantly improved, Somewhat improved, No change, etc.).
* **Technical Support Rating** (`technical_support_rating`, `select_one`, required/false): Rate the technical support provided by the vendor (e.g. Excellent, Good, Average, Poor, etc.).
* **Issues Encountered** (`issues_encountered`, `select_multiple`, required/true): Select all the issues you have encountered with the integration (e.g. Connection problems, Data sync errors, etc.).
* **Issue Frequency** (`issue_frequency`, `select_one`, required/true): Select how often you encounter issues with the integration (e.g. Never, Rarely, Sometimes, etc.).
* **Desired Features** (`feature_requests`, `text`, required/false): Describe any desired features you would like to see in the integration.
* **Training Adequacy** (`training_adequacy`, `select_one`, required/true): Select the level of training provided by the vendor (e.g. More than sufficient, Sufficient, Adequate, etc.).
* **Value for Cost** (`value_for_cost`, `select_one`, required/true): Rate the value for the cost of the integration (e.g. Excellent value, Good value, Fair value, etc.).
* **Recommend to Others** (`recommend_to_others`, `select_one`, required/true): Select how likely you are to recommend the integration to others (e.g. Very likely, Likely, Neutral, etc.).
* **Overall Satisfaction** (`overall_satisfaction`, `select_one`, required/true): Rate your overall satisfaction with the integration (e.g. Very satisfied, Satisfied, Neutral, etc.).
* **Additional Feedback** (`additional_feedback`, `text`, required/false): Provide any additional feedback about the integration.
