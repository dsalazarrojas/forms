# Experiential Learning Impact Survey - Help Guide

## Purpose
This form is used to gather feedback from participants in an experiential learning activity. It is designed to evaluate the impact of the learning activity, identify areas of improvement, and inform future planning.

## How To Complete This Form
To complete this form, simply follow the instructions below:

1. **Participants** (Required): Enter the number of participants in the experiential learning activity.
2. **Feedback** (Required): Provide a brief description of your feedback, thoughts, or suggestions about the learning activity.
3. **Outcome** (Required): Select all the outcomes that you experienced as a result of the learning activity:
	* Yes
	* No
4. **Skills Gained** (Required): Select the skills you gained from the learning activity:
	* Outcome 1
	* Outcome 2
	* Outcome 3
5. **Improvement Ideas** (Required): Provide any improvement ideas you have for the learning activity. You can enter as many ideas as you like.

## Field-by-Field Explanation
* **Participants**: A numeric value indicating the number of participants in the learning activity.
* **Feedback**: A text field to provide feedback, thoughts, or suggestions about the learning activity.
* **Outcome**: A multiple choice field where you can select all the outcomes that you experienced as a result of the learning activity.
* **Skills Gained**: A single choice field where you can select the skills you gained from the learning activity.
* **Improvement Ideas**: A note field where you can provide any improvement ideas you have for the learning activity.

## Tips
* Please provide honest and constructive feedback to help us improve our services.
* If you have any concerns or issues, please describe them clearly.
* You can enter as many improvement ideas as you like in the "Improvement Ideas" field.
* You should not be able to fill out this form again if you've already done so in the past.
