# Diversity Program Awareness Survey - Help Guide
## Purpose
The Diversity Program Awareness Survey aims to assess employees' knowledge and understanding of the company's diversity program, identify areas of improvement, and gather feedback for the program's continued development and growth.

## How To Complete This Form
To complete this form, follow these steps:
1. Start by reading the introduction and understanding the purpose of the survey.
2. Choose all the ways through which you currently learn about diversity in the workplace.
3. Select whether you have participated in diversity-related activities or not.
4. If applicable, choose one or more feelings about the diversity program in the workplace.
5. If you wish, provide suggestions on how the program can be improved.
6. Finally, fill in your contact information so that we can follow up with you for any additional information or to discuss your feedback.

## Field-by-Field Explanation

* **Introduction** (`diversity_program_awareness_survey_form_1`): This is a brief introduction to the survey. Please take a moment to read it carefully before proceeding.
* **How do you learn about diversity?** (`how_do_you_learn_about_diversity`): Select all the ways through which you currently learn about diversity in the workplace. This could be through workshops and trainings, diversity committee meetings, leadership discussions, newsletters, or other means.
* **Have you participated in diversity-related activities?** (`have_you_participated_in_diversity_related_activities`): Select `yes` if you have participated in diversity-related activities, and `no` otherwise.
* **How do you feel about diversity in the workplace?** (`how_do_you_feel_about_diversity_in_the_workplace`): If you have participated in diversity-related activities, select one or more feelings about the diversity program in the workplace. You can choose between `very positive`, `somewhat positive`, `neutral`, `somewhat negative`, or `very negative`.
* **What would you like to improve?** (`what_do_you_want_to_improve`): If you have suggestions or ideas for improving the diversity program, please provide them here.
* **Suggestions** (`suggestions`): If you have additional suggestions or comments about the program, please share them here.
* **Contact Information** (`contact_information`): Please provide your contact information so that we can follow up with you for any further discussion or to gather more information.
* **Repeat Contact Information** (`contact_information_repeat`): If you would like to be contacted by someone other than yourself, please provide the name and contact information of the person you would like us to contact.
