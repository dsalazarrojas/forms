# Screen Capture Feedback Form - Help Guide
## Purpose
The Screen Capture Feedback Form is used to collect feedback from end-users about issues they have encountered while using our product. Please use this form to report any bugs, suggestions, or feedback you have for our team.

## How To Complete This Form
To complete this form, simply follow these steps:

1. Select the type of issue you would like to report: Bug Report, Feedback, or Suggestion.
2. Provide a rating of how severe the issue is.
3. Attach a screen capture of the issue by uploading an image or describing it in detail.
4. If applicable, provide additional context about the issue in the "Context" field.
5. Share any additional comments or insights you have about the issue in the "Additional Comments" field.

## Field-by-Field Explanation

* **Feedback Form**: Select the type of issue you would like to report: Bug Report, Feedback, or Suggestion.
* **Rating**: Indicate how severe the issue is, on a scale of 1-5.
* **Screen Capture**: Attach a screen capture of the issue by uploading an image or describing it in detail.
* **Context**: Provide additional context about the issue, if applicable.
* **Additional Comments**: Share any additional comments or insights you have about the issue.
