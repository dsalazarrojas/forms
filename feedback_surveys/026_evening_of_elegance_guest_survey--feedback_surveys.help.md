# evening_of_elegance_guest_survey - Help Guide
## Purpose
This guide will walk you through the evening_of_elegance_guest_survey form, designed to gather feedback from guests about their experience at the event.

## How To Complete This Form
To complete this form, follow these steps:

1. Answer the questions truthfully and to the best of your ability.
2. Fill in the required fields (marked as "required" in the form).
3. If you have any additional comments or feedback, use the "Additional feedback" field.

## Field-by-Field Explanation

* **Did you attend the event** (`event_attended`): This question is to confirm whether you attended the event or not. Please answer "Yes" if you did and "No" if you did not.
* **Event Date** (`event_attended_date`): Please enter the date you attended the event.
* **Event time** (`event_attended_time`): Please enter the time you attended the event.
* **Satisfaction with entertainment** (`satisfaction_with_entertainment`): This question asks about your satisfaction with the entertainment provided at the event. Please select one of the options:
	+ Option 1: Very satisfied
	+ Option 2: Somewhat satisfied
	+ Option 3: Neutral
	+ Option 4: Somewhat dissatisfied
	+ Option 5: Very dissatisfied
* **Satisfaction with service** (`satisfaction_with_service`): This question asks about your satisfaction with the service provided during the event. Please select one of the options:
	+ Option 1: Very satisfied
	+ Option 2: Somewhat satisfied
	+ Option 3: Neutral
	+ Option 4: Somewhat dissatisfied
	+ Option 5: Very dissatisfied
* **Satisfaction with food** (`satisfaction_with_food`): This question asks about your satisfaction with the food provided at the event. Please select one of the options:
	+ Option 1: Very satisfied
	+ Option 2: Somewhat satisfied
	+ Option 3: Neutral
	+ Option 4: Somewhat dissatisfied
	+ Option 5: Very dissatisfied
* **Satisfaction with event theme** (`satisfaction_with_event_theme`): This question asks about your satisfaction with the event theme. Please select one of the options:
	+ Option 1: Very satisfied
	+ Option 2: Somewhat satisfied
	+ Option 3: Neutral
	+ Option 4: Somewhat dissatisfied
	+ Option 5: Very dissatisfied
* **Satisfaction with event ambiance** (`satisfaction_with_event_ambiance`): This question asks about your satisfaction with the event ambiance. Please select one of the options:
	+ Option 1: Very satisfied
	+ Option 2: Somewhat satisfied
	+ Option 3: Neutral
	+ Option 4: Somewhat dissatisfied
	+ Option 5: Very dissatisfied
* **Satisfaction with price** (`satisfaction_with_price`): This question asks about your satisfaction with the price of the event. Please select one of the options:
	+ Option 1: Very satisfied
	+ Option 2: Somewhat satisfied
	+ Option 3: Neutral
	+ Option 4: Somewhat dissatisfied
	+ Option 5: Very dissatisfied
* **Satisfaction with event** (`satisfaction_with_event`): This question asks about your overall satisfaction with the event. Please select one of the options:
	+ Option 1: Very satisfied
	+ Option 2: Somewhat satisfied
	+ Option 3: Neutral
	+ Option 4: Somewhat dissatisfied
	+ Option 5: Very dissatisfied
* **Would you attend again** (`would_attend_again`): This question asks if you would attend the event again. Please select one or more of the options:
	+ Option 1: Yes
	+ Option 2: Maybe
	+ Option 3: No
* **Would you recommend** (`would_recommend`): This question asks if you would recommend the event to others. Please select one or more of the options:
	+ Option 1: Yes
	+ Option 2: Maybe
	+ Option 3: No
* **Why not recommend** (`why_not_recommend`): This question is for you to provide a reason why you would not recommend the event (if you selected "No" in the previous question).
* **How did you hear about us** (`how_did_you_hear`): This question asks how you heard about the event. Please select one or more of the options:
	+ Option 1: Social media
	+ Option 2: Word of mouth
	+ Option 3: Online advertising
	+ Option 4: Print advertising
	+ Option 5: Other
* **Social media** (`social_media`): This question asks which social media platforms you have used to learn about or interact with us. Please select one or more of the options:
	+ Option 1: Facebook
	+ Option 2: Instagram
	+ Option 3: Twitter
	+ Option 4: YouTube
	+ Option 5: Other
* **Word of mouth** (`word_of_mouth`): This question asks if you have learned about the event through word of mouth. Please select "Yes" or "No".
* **Email** (`email`): This is a field for you to enter your email address (if you would like to be contacted for future events).
* **Phone** (`phone`): This is a field for you to enter your phone number (if you would like to be contacted for future events).
* **Additional feedback** (`feedback`): This is a field for you to provide any additional comments or feedback about your experience at the event.
* **Comments** (`comments`): This is a field for you to provide any additional comments or feedback about your experience at the event.
