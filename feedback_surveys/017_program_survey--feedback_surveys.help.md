# Program Survey - Help Guide
## Purpose
This form is used to collect data about a program or project. It's a part of the "Feedback Surveys" category.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the name of the program or project in the "Program Name" field.
2. Provide the start date of the program or project in the "Start Date" field.
3. Enter the end date of the program or project in the "End Date" field.
4. Select the category of the program or project from the "Category" dropdown menu.
5. Enter a brief description of the program or project in the "Description" field.
6. Choose the frequency of the program or project from the "Frequency" dropdown menu.
7. Enter the target population of the program or project in the "Target Population" field.
8. List the expected outcomes of the program or project in the "Outcomes" field.
9. Enter the services provided by the program or project in the "Services" field.
10. If any additional services are provided, enter them in the "Other Services" field.

## Field-by-Field Explanation
* **Program Name** (`program_survey_program_name`, text, required/optional): Enter the name of the program or project.
* **Start Date** (`program_survey_start_date`, date, required/optional): Enter the start date of the program or project.
* **End Date** (`program_survey_end_date`, date, required/optional): Enter the end date of the program or project.
* **Category** (`program_survey_category`, select_one, optional): Choose the category of the program or project.
* **Description** (`program_survey_description`, text, optional): Enter a brief description of the program or project.
* **Frequency** (`program_survey_frequency`, select_multiple, optional): Choose the frequency of the program or project (Daily, Weekly, Monthly, Quarterly).
* **Target Population** (`program_survey_target_population`, text, optional): Enter the target population of the program or project.
* **Outcomes** (`program_survey_outcomes`, text, optional): List the expected outcomes of the program or project.
* **Services** (`program_survey_services`, text, optional): Enter the services provided by the program or project.
* **Other Services** (`program_survey_services_other`, text, optional): Enter any additional services provided by the program or project.

## Tips
* Please provide accurate and detailed information for each field.
* If you are unsure about any field, feel free to ask for clarification.
* This form is for data collection purposes only.
