# Drywall Work Expectations Survey - Help Guide
## Purpose
This form is intended to collect information about drywall work expectations from project team members. It's used to gather project details, team composition, communication preferences, and other relevant information.

## How To Complete This Form
1. Answer all questions honestly and accurately.
2. Select the relevant options for each question.
3. Enter your contact name and contact details in the relevant fields.
4. Provide feedback and comments in the text fields.
5. Ensure that all required fields are completed.

## Field-by-Field Explanation
* **Drywall Work Expectations Survey** (Text Field, Text, Optional): A field for any additional comments or feedback.
* **Communication Preferences** (Select Multiple, Multiple Choice, Required): Select all the communication methods you would like to use for this project.
* **Project Estimates** (Number Field, Number, Required): Enter your project estimates for the drywall work.
* **Feedback and Comments** (Text Field, Text, Optional): Provide any additional feedback or comments about the project.
* **Date and Time** (Date Field, Date, Optional): Enter the date and time you would like to start the project.
* **Contact Details** (Select One, Single Choice, Required): Select the contact person for your project.
* **Work Hours** (Time Field, Time, Required): Enter the expected work hours for the project.
* **Project Status** (Select Multiple, Multiple Choice, Required): Select the current status of your project.
* **Expected Delivery Date** (Date Field, Date, Optional): Enter the expected delivery date for your project.
* **Work Expectations** (Text Field, Text, Required): Enter your work expectations for the project.
* **Communication Channels** (Select One, Single Choice, Required): Select the preferred communication channel for your project.
* **Project Manager** (Select One, Single Choice, Required): Select the project manager for your project.
* **Project Team** (Select Multiple, Multiple Choice, Required): Select the team members involved in the project.
* **Project Status** (Select Multiple, Multiple Choice, Required): Select the current status of your project.
* **Feedback Comments** (Text Field, Text, Optional): Provide any additional feedback or comments about the project.
* **Drywall Installation** (Number Field, Number, Required): Enter the drywall installation details for your project.
* **Expected Start Date** (Date Field, Date, Optional): Enter the expected start date for your project.
* **Project Scope** (Text Field, Text, Required): Enter the project scope for your project.
* **Contact Name** (Text Field, Text, Required): Enter your contact name.
* **Project Manager Contact** (Text Field, Text, Optional): Enter the contact details for your project manager.
* **Project Manager Phone** (Text Field, Text, Optional): Enter the phone number of your project manager.
* **Project Manager Email** (Email Field, Email, Optional): Enter the email of your project manager.
* **Project Manager Notes** (Text Field, Text, Optional): Enter any additional notes for your project manager.
* **Contact Method** (Select One, Single Choice, Optional): Select how you would like to be contacted.
* **Contact Notes** (Text Field, Text, Optional): Enter any additional contact notes.
