# ERP User Feedback Survey - Help Guide
## Purpose
This survey is designed to gather feedback from ERP users to improve the overall user experience and identify potential areas of improvement.

## How To Complete This Form
To complete this form, please follow these steps:

1. Answer each question truthfully and to the best of your knowledge.
2. Select all relevant options for your interests and availability.
3. Provide clear and concise text for suggested improvements and comments.
4. Enter your contact information if you'd like to be notified about any changes or updates.

## Field-by-Field Explanation

* **Introduction**: Please read this page carefully as it provides an overview of the survey and its purpose.
* **Satisfaction**: Please rate your overall satisfaction with the ERP system on a scale of 1-5, where 1 is Very Dissatisfied and 5 is Very Satisfied.
* **User Satisfaction**: Please choose how satisfied you are with the current state of the ERP system. You can choose from Very Satisfied, Somewhat Satisfied, Neutral, Somewhat Dissatisfied, or Very Dissatisfied.
* **User Satisfaction Scale**: Please choose the scale that best represents your level of satisfaction.
* **Department**: Please select all departments that interest you or for which you have availability.
* **Suggestion**: Please provide any suggestions or ideas for improving the ERP system.
* **Comment**: Please provide any additional comments or questions you have about the ERP system.
* **Email**: Please enter your email address if you'd like to be notified about any changes or updates to the ERP system.
* **Phone**: Please enter your phone number if you'd like to be contacted about any further questions or discussions.
* **Department 1-3**: Please select all departments that interest you or for which you have availability.

Note: Please be aware that some fields are optional. You can choose to skip them if you don't have information or don't see the relevance.
