# Tourist attraction feedback questionnaire - Help Guide
## Purpose
This form collects feedback from tourists about their experiences at a particular tourist attraction.

## How To Complete This Form
1. Enter the **Tourist Attraction Name** of the location you visited.
2. **Rate your experience**: Choose a rating from 1 to 5.
3. **Enter your Email** address for contact.
4. **Enter your Phone Number** if you'd like to be contacted.
5. **Enter the Tourist Attraction Address** where the location is situated.
6. **What can be improved?**: Provide any comments or suggestions you have for improvement.
7. **Rating Date**: Enter the date you visited the attraction.
8. **Rating Time**: Enter the time you visited the attraction.
9. **How likely are you to recommend this tourist attraction?**: Choose an option from the dropdown menu.
10. **Any additional comments?**: Provide any other comments you'd like to share.
11. **Attach an image** or any other document, audio, or video to help illustrate your feedback.
12. **Attach a document** or other relevant file to support your feedback.
13. **Attach a video** to illustrate your feedback.
14. **Attach an audio** file to support your feedback.
15. **Attach other** files or media to support your feedback.
16. **Attach a description** of the file you're uploading.
17. **Attach a filename** for the file you're uploading.
18. **Attach a file type** for the file you're uploading.
19. **Attach a file size** for the file you're uploading.
20. **Attach a file size unit** for the file you're uploading.
21. **Attach a filename** for the file you're uploading.
22. **Attach a description** of the file you're uploading.
23. **Attach a file type** for the file you're uploading.
24. **Attach a size unit** for the file you're uploading.
25. **Attach a filename** for the file you're uploading.

## Field-by-Field Explanation

* **Tourist Attraction Name** (`1`, `text`, required): Enter the name of the tourist attraction.
* **Rate your experience** (`2`, `number`, required): Choose a rating from 1 to 5 to express your experience.
* **Additional rating comments** (`3`, `note`, optional): Provide any comments about your rating.
* **Email** (`4`, `email`, required): Enter your email address so we can contact you.
* **Phone number** (`5`, `text`, optional): Enter your phone number if you'd like to be contacted.
* **Tourist attraction address** (`6`, `text`, required): Enter the address of the tourist attraction.
* **What do you think can be improved?** (`7`, `note`, required): Provide any comments or suggestions for improvement.
* **Rating date** (`8`, `date`, required): Enter the date you visited the attraction.
* **Rating time** (`9`, `time`, required): Enter the time you visited the attraction.
* **How likely are you to recommend this tourist attraction?** (`10`, `select_one`, optional): Choose an option from the dropdown menu.
* **Any additional comments?** (`11`, `select_multiple`, optional): Provide any other comments you'd like to share.
* **Attach an image** (`12`, `note`, optional): Attach an image or other document, audio, or video to support your feedback.
* **Attach a document** (`13`, `note`, optional): Attach a relevant document to support your feedback.
* **Attach a video** (`14`, `note`, optional): Attach a video to illustrate your feedback.
* **Attach an audio** (`15`, `note`, optional): Attach an audio file to support your feedback.
* **Attach other** (`16`, `note`, optional): Attach any other files or media to support your feedback.
* **Attach a description** (`17`, `text`, optional): Provide a description of the file you're uploading.
* **Attach a filename** (`18`, `text`, optional): Enter a filename for the file you're uploading.
* **Attach a file type** (`19`, `text`, optional): Enter the type of file you're uploading.
* **Attach a file size** (`20`, `text`, optional): Enter the size of the file you're uploading.
