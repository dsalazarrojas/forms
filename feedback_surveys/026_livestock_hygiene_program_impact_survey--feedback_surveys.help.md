# Livestock Hygiene Program Impact Survey - Help Guide
## Purpose
This form is designed to collect data on the impact of the Livestock Hygiene Program. Your responses will help us better understand how the program affects farmers like you.

## How To Complete This Form
To complete this form, please follow these steps:

1. Review each page carefully and answer all the questions truthfully.
2. If you have already completed a similar survey, please do not repeat your responses.
3. Take your time and answer each question to the best of your ability.

## Field-by-Field Explanation

* **Introduction** (1: introduction, Note, Not Required):
This is a brief overview of the form and the program. Read it carefully before proceeding.
* **Program Type** (2: program_type, Text, Not Required):
Choose the type of program you have used.
* **Program Start Date** (3: program_start_date, Date, Not Required):
Enter the date when the program started. This will help us understand when the program began.
* **Program End Date** (4: program_end_date, Date, Not Required):
Enter the date when the program ended. This will help us understand when the program ended.
* **Frequency of Use** (5: frequency_of_use, Select Multiple, Not Required):
Choose how often you use the program. Select all that apply.
* **Number of Farmers** (6: number_of_farmers, Number, Not Required):
Enter the number of farmers who have used the program.
* **Farm Location** (7: farm_location, Text, Not Required):
Enter the location of your farm. This will help us understand where the program was used.

## Tips

* Please answer all questions truthfully and accurately.
* If you have any questions or concerns, please contact us.
* Thank you for taking the time to complete this form! Your input is invaluable in helping us improve the Livestock Hygiene Program.
