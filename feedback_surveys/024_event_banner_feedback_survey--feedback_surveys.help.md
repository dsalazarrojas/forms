# Event Banner Feedback Survey - Help Guide
## Purpose
This form is designed to collect feedback from users about the event banners, specifically about their signage. The main goal is to get an understanding of how well the banners are visible, readable, and understood by the audience.

## How To Complete This Form
To complete this form, follow these steps:

1. Review the questions below and answer them as accurately as possible.
2. Select all that apply for multiple-choice questions.
3. Provide detailed comments or suggestions in the text fields.
4. Click the "Submit" button to send your feedback.

## Field-by-Field Explanation
* **Event Signage** (`event_signage_questions`, select_multiple, optional): This question asks if you found the event signage clear and effective. Choose all that apply from the options provided.
* **Rating** (`event_signage_rating`, number, optional): Rate your overall experience with the event signage on a scale of 1-10.
* **Comments** (`event_signage_comments`, text, optional): Provide any additional comments or thoughts about the event signage.
* **Opinion** (`event_signage_opinion`, select_one, optional): Choose an option to express your opinion about the event signage:
	+ Event Team: The event team did a great job with the signage.
	+ Sponsors: The event sponsors did a great job with the signage.
	+ Venue: The venue was well-labeled and easy to navigate.
* **Suggestions** (`event_signage_suggestions`, text, optional): If you have any suggestions or ideas for improvement, please share them in this text field.
* **Agreement** (`event_signage_agreement`, select_multiple, optional): Do you agree or disagree with the following statements about the event signage? Choose all that apply:
	+ Yes
	+ No
* **Don't Know** (`event_signage_dont_know`, select_one, optional): If you are unsure or didn't pay attention to the event signage, choose this option.
* **Submit** (`submit`, text, optional): Type in your name and email address to submit your feedback. This is the final step to complete the form.
