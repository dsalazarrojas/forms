# NGO Event Accessibility Experience Survey - Help Guide
## Purpose
This survey aims to gather feedback from event attendees on their accessibility experience to help improve future events.

## How To Complete This Form
* Please fill out this survey only if you have attended the event.
* If you have not experienced any of the accessibility features mentioned in this form, you can still provide feedback on how you think they could be improved or what you would like to see in the future.
* Answer each question honestly and accurately, and provide any additional comments or suggestions in the "Comments" field.

## Field-by-Field Explanation
* **Event Details (Text)** (`event_details`, Text, Optional): 
This is the space for you to provide a brief description of your experience at the event, including any notable moments or highlights.
* **Accessibility Accommodations (Select One)** (`accessibility_accommodations`, Select One, Optional): 
* Wheel Chair Accessible: Please select this option if you found the event venue to be wheelchair accessible.
* Other: If none of the above options apply, please select "Other" and provide a brief explanation in the "Comments" field.
* **Improvements Needed (Select Multiple)** (`improvements_needed`, Select Multiple, Optional): 
* Wheel Chair Accessible: Please select this option if you think wheelchair accessibility could be improved.
* Sign Language Interpreter: Please select this option if you think sign language interpreters could be provided in future events.
* Closed Captioning: Please select this option if you think closed captioning could be provided in future events.
* **Unmet Needs (Select Multiple)** (`unmet_needs`, Select Multiple, Optional): 
* Wheel Chair Accessible: Please select this option if you did not have access to wheelchair accessibility at the event.
* Sign Language Interpreter: Please select this option if you would like to see sign language interpreters provided in future events.
* Closed Captioning: Please select this option if you would like to see closed captioning provided in future events.
* **Overall Rating (Number)** (`overall_rating`, Number, Optional): 
This is a numerical rating of your overall experience at the event, with 1 being the lowest and 5 being the highest.
* **Email (Email)** (`email`, Email, Optional): 
Please enter your email address if you would like to be contacted about future events or for any follow-up questions.
