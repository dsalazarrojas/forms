# Pet Healthcare Communication Survey - Help Guide
## Purpose
The Pet Healthcare Communication Survey is designed to collect feedback and survey responses from pet owners, veterinarians, or pet healthcare providers to improve communication between them and identify areas of improvement in pet healthcare services.

## How To Complete This Form
1. Fill out the **Contact Form** (Page 1) with your basic contact information.
2. Select your answer to the **Communication Survey** question on Page 2.
3. Provide **Pet Details** (Page 3) if applicable.
4. Choose your **Communication Preferences** (Page 4) from the options provided.
5. If you have any additional comments, type them in the **Additional Comments** field (Page 5).
6. Enter your **Email** address (Page 6) and **Phone** number (Page 7) if you want to be contacted for follow-up.
7. Select a **Submission Date** (Page 8) and choose the **Submission Time** (Page 9) and **Submission Timezone** (Page 10) to indicate when you completed the survey.
8. Indicate if you are submitting the survey for a **Submission Date Range** (Page 11) or select a specific **Submission Date** (Page 12).
9. If you are submitting for a range of dates, select the **From** and **To** dates (Pages 13-14).
10. If you are submitting for a range of times, select the **From** and **To** times (Pages 15-16).
11. Enter a **Survey ID** (Page 17) if you have been assigned one.
12. Select a **Submission Status** (Page 18) and indicate if you are **Active** or **Inactive**.
13. If applicable, select an **Assigned Tool** (Page 19).
14. Enter the file name and path of the **Output File** (Page 20).
15. Finally, enter a **Form ID** (Page 21) and select the **Category** (Page 22) for this survey submission.
