# Roundabout Issues Survey - Help Guide

## Purpose
The purpose of this form is to collect feedback and survey data from users about their experiences and concerns with roundabouts. This information will be used to inform design decisions and identify areas for improvement.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the type of issue you are experiencing or concerned about (e.g. roundabout condition, construction, etc.).
2. Provide a clear and concise description of the issue.
3. If you have any safety concerns, select all that apply.
4. If you have any other safety concerns, list them in the text field.
5. If you have any other characteristics of the roundabout you'd like to mention, select all that apply.
6. If you'd like to add any additional comments or information about your submission, please do so in the text field.

## Field-by-Field Explanation

* **issue_type**: Select the type of issue you are experiencing or concerned about. You can choose from "roundabout condition", "roundabout construction", or "other".
	+ roundabout condition: This refers to any issues you've experienced while driving or navigating a roundabout.
	+ roundabout construction: This refers to any issues you've experienced during or after construction of a roundabout.
	+ other: If none of the above options apply, choose "other" and provide a brief description in the text field.
* **issue_description**: Please provide a clear and concise description of the issue you selected in the "issue_type" field.
* **safety_concern**: If you have any safety concerns, select all that apply.
	+ roundabout: This includes concerns about pedestrians, vehicles, or other safety hazards in or near the roundabout.
	+ road signs: This includes concerns about signage related to the roundabout.
	+ pedestrian: This includes concerns about pedestrian safety in or near the roundabout.
* **safety_concerns**: If you have any other safety concerns, list them in this text field.
* **roundabout_characteristics**: If you have any other characteristics of the roundabout you'd like to mention, select all that apply.
	+ roundabout shape: This includes concerns about the shape or design of the roundabout.
	+ roundabout size: This includes concerns about the size of the roundabout.
	+ roundabout orientation: This includes concerns about the orientation of the roundabout.
* **roundabout_characteristics_list**: If you have any additional characteristics of the roundabout you'd like to mention, provide a clear and concise description in this text field.
* **submission_comments**: If you have any additional comments or information about your submission, please provide them in this text field.
