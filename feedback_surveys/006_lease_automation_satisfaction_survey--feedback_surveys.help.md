# Lease Automation Satisfaction Survey - Help Guide
## Purpose
This form is designed to collect feedback on your experience with the lease automation process. Please take a few minutes to complete this form and share your thoughts on how the process is working for you.

## How To Complete This Form
To complete this form, simply follow these steps:

1. Answer each question in a way that best reflects your experience with the lease automation process.
2. For select_one and select_multiple fields, choose the options that best match your response.
3. If you have any additional comments or feedback, please use the text fields to provide more information.
4. Submit the form when you're finished.

## Field-by-Field Explanation

* **Lease Automation Survey** (`lease_automation_survey`, text, optional): This is the main question where you can provide any comments or feedback about the lease automation process.
* **Feedback On Lease Automation** (`feedback_lease_automation`, text, optional): If you have any specific feedback on the lease automation process, please type it here.
* **How Important** (`lease_automation_important`, select_one, optional): Please choose how important the lease automation process is to you. Options are:
	+ Very Unimportant
	+ Somewhat Unimportant
	+ Neutral
	+ Somewhat Important
	+ Very Important
* **Important Score** (`lease_automation_important_score`, number, optional): If you chose "Very Important" or "Somewhat Important" for the previous question, please provide a score out of 5 to rate how important it is. For example, if you chose "Very Important", you can type 5 here.
* **Lease Automation Improvement** (`lease_automation_improvement`, text, optional): If you have any ideas or suggestions on how to improve the lease automation process, please type them here.
* **Finance** (`finance_survey`, select_multiple, optional): Please indicate your level of agreement with the following statements about the finance aspect of the lease automation process. Options are:
	+ True
	+ False
	+ Maybe
* **Operations** (`operations_survey`, select_multiple, optional): Please indicate your level of agreement with the following statements about the operations aspect of the lease automation process. Options are:
	+ True
	+ False
	+ Maybe
* **Lease Automation Issues** (`lease_survey_automation_issues`, select_multiple, optional): If you've experienced any issues with the lease automation process, please select all that apply. Options are:
	+ True
	+ False
	+ Maybe
