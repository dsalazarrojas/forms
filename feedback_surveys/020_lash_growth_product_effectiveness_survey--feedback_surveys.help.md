# Lash Growth Product Effectiveness Survey - Help Guide
## Purpose
This survey is designed to help us understand how well our lash growth product works for you. Your feedback will help us make improvements to the product and its development process.

## How To Complete This Form
To complete this form, simply fill out the fields below and submit your response. Please answer each question as accurately and thoroughly as possible.

## Field-by-Field Explanation

* **Intro** (`intro`, text, required: false): Please provide a brief introduction to this survey, including any relevant background information or context about your experience with the product.
* **Results** (`results`, number, required: false): If you experienced any visible results from using the product (e.g., noticeable lash growth), please enter a number to indicate the level of improvement.
* **Satisfaction** (`satisfaction`, text, required: false): Please describe your overall satisfaction with the product, including any positive or negative feelings you experienced while using it.
* **Side Effects** (`side_effects`, text, required: false): If you experienced any side effects while using the product, please describe them here.
* **Improvement Areas** (`improvement_areas`, text, required: false): If you have suggestions for how we can improve the product, please share them here.
* **Comments** (`comments`, text, required: false): Is there anything else you would like to share about your experience with the product?
* **Assigned Tool** (`assigned_tool`, text, required: false): If you used a specific tool or device while taking the product, please describe it here.
* **Form ID** (`form_id`, text, required: false): Please do not fill out this field. This is a system-generated field.
* **Category** (`category`, text, required: false): This is an internal field for categorizing the survey data.
* **Description** (`description`, text, required: false): This is an optional field for any additional comments or context.
* **Output File** (`output_file`, text, required: false): The output of the survey will be saved in a file.
* **Assigned Survey** (`assigned_survey`, text, required: false): This is a field for internal use only.

Note: The output file will be generated in a format that can be easily imported into various tools and analysis software.
