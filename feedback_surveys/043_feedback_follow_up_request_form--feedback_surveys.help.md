# Feedback Follow Up Request Form - Help Guide

## Purpose
This form is used to record and track follow-up requests from customers or users that require attention and resolution.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter your first name in the "First Name" field.
2. Enter your valid email address in the "Email" field.
3. Provide a brief description of the feedback context, if applicable, in the "Feedback Context" field.
4. Clearly state the reason for the follow-up request in the "Follow Up Request" field.
5. Choose the best contact method from the options provided (Phone, Email, or In-Person) in the "Best Contact Method" field.
6. Select the preferred response time for the follow-up request (As Soon As Possible, Weekdays, or Weekends) in the "Preferred Response Time" field.
7. Add any additional comments or context related to the follow-up request in the "Additional Comments" field.
8. If applicable, specify the follow-up date and time in the "Follow Up Date" and "Follow Up Time" fields, respectively.
9. Identify the tool or channel that is related to the follow-up request in the "Assigned Tool" field.
10. If applicable, specify the agent assigned to handle the follow-up request in the "Assigned Agent" field.
11. Indicate the priority level of the follow-up request (Low, Medium, or High) in the "Priority Level" field.
12. Choose the follow-up method (Phone Call, Email, or In-Person) in the "Follow Up Method" field.
13. Provide any additional details related to the follow-up request in the "Follow Up Details" field.

## Field-by-Field Explanation

* **First Name** (`first_name`, text, required): Enter your first name.
* **Email** (`email`, email, required): Enter your valid email address.
* **Feedback Context** (`feedback_context`, text, optional): Provide a brief description of the feedback context, if applicable.
* **Follow Up Request** (`follow_up_request`, text, required): Clearly state the reason for the follow-up request.
* **Best Contact Method** (`best_contact_method`, select_one, required): Choose the best contact method from the options provided (Phone, Email, or In-Person).
* **Preferred Response Time** (`preferred_response_time`, select_one, required): Select the preferred response time for the follow-up request (As Soon As Possible, Weekdays, or Weekends).
* **Additional Comments** (`additional_comments`, text, optional): Add any additional comments or context related to the follow-up request.
* **Follow Up Date** (`follow_up_date`, date, optional): If applicable, specify the follow-up date.
* **Follow Up Time** (`follow_up_time`, time, optional): If applicable, specify the follow-up time.
* **Assigned Tool** (`assigned_tool`, text, optional): Identify the tool or channel related to the follow-up request.
* **Assigned Agent** (`assigned_agent`, text, optional): If applicable, specify the agent assigned to handle the follow-up request.
* **Priority Level** (`priority_level`, select_multiple, optional): Indicate the priority level of the follow-up request (Low, Medium, or High).
* **Follow Up Method** (`follow_up_method`, select_one, required): Choose the follow-up method (Phone Call, Email, or In-Person).
* **Follow Up Details** (`follow_up_details`, text, optional): Provide any additional details related to the follow-up request.
