# Event Vendor Support Feedback Survey - Help Guide

## Purpose
This form is used to gather feedback from event planners and vendors on their experiences with event support. Your input will help us to better understand our support services and identify areas for improvement.

## How To Complete This Form

1. Please select all that apply to the questions on the following pages. You will be asked to choose from the options "Yes" and "No" for the majority of the questions. For questions that ask for free text responses, you can enter your answers in the text fields.

## Field-by-Field Explanation

### Event Planners (<event_planners>, <type>: select_multiple, <required>: false)
Please select all event planners that you have received support from.

*   "Yes" to indicate that you have received support from event planners
*   "No" to indicate that you have not received support from event planners

### Event Vendors (<event_vendors>, <type>: select_multiple, <required>: false)
Please select all event vendors that you have received support from.

*   "Yes" to indicate that you have received support from event vendors
*   "No" to indicate that you have not received support from event vendors

### Event Vendor (<event_vendor>, <type>: select_one, <required>: false)
Please select the event vendor you are providing feedback about.

*   "Yes" to indicate that you are providing feedback about this event vendor
*   "No" to indicate that you are not providing feedback about this event vendor

### Suggestions (<suggestions>, <type>: text, <required>: false)
Please enter any suggestions you have for improving our support services.

### Support Issues (<support_issues>, <type>: text, <required>: false)
Please enter any issues you have experienced with our support services.

### Suggestions for Improvement (<suggestions_for_improvement>, <type>: text, <required>: false)
Please enter any suggestions you have for improving our support services.

### Satisfaction (<satisfaction>, <type>: number, <required>: false)
Please rate your satisfaction with our support services on a scale of 1-5. A score of 1 indicates the lowest satisfaction, while 5 indicates the highest satisfaction.

*   Enter a number between 1 and 5 to rate your satisfaction
*   You can also use the number keys on your keyboard to enter a number quickly.

## Tips
*   Please answer all questions that apply to your experience with our event support services.
*   If a question does not apply to you, please leave the field blank or select "N/A" in the dropdown menu if available.
*   For free text fields, you can enter multiple lines of text if needed.
*   If you have any issues with submitting the form, please contact us at [insert contact information].
