## Media Viewer Preference Report Form - Help Guide

## Purpose
This form is intended to collect feedback from users about their media viewing preferences.

## How To Complete This Form
To complete this form, follow these steps:

1.  Select the preferred viewing device from the list provided.
2.  Choose when you viewed the media content.
3.  Select the frequency with which you viewed the media content (if applicable).
