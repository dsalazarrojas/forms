# customer_negative_feedback_handling_survey - Help Guide

## Purpose
This form is used to capture customer negative feedback and guide the support team in handling it effectively.

## How To Complete This Form
1. Select the correct customer contact method from the drop-down list.
2. Provide a detailed description of the issue the customer experienced.
3. Select one or more resolution methods that were used to address the issue.
4. Update the follow-up status and date.
5. Add any follow-up notes for reference.

## Field-by-Field Explanation
• **Negative Feedback Received** (`Negative Feedback Received`, `note`, required/optional): This field is a note section where the support team member can summarize the negative feedback received from the customer.
• **Customer Contact Details** (`Customer Contact Details`, `select_one`, required): This field asks you to select the method the customer used to contact us (e.g., Email, Phone, Chat).
• **Feedback Description** (`Feedback Description`, `text`, required): Provide a detailed description of the issue the customer experienced.
• **Resolution Method** (`Resolution Method`, `select_multiple`, required): Select one or more methods used to resolve the issue (e.g., Escalate to Manager, Refund, Replace or Repair).
• **Follow Up Status** (`Follow Up Status`, `select_one`, required): Update the follow-up status for the customer feedback (e.g., Not Done, Done, On Hold, N/A).
• **Follow Up Date** (`Follow Up Date`, `date`, optional): Enter the date when the follow-up was done.
• **Follow Up Time** (`Follow Up Time`, `time`, optional): Enter the time when the follow-up was done.
• **Follow Up Notes** (`Follow Up Notes`, `note`, optional): Add any follow-up notes for reference.
• **Customer Feedback Frequency** (`Customer Feedback Frequency`, `number`, optional): Enter the frequency of customer feedback (e.g., once, multiple times).
• **Customer Feedback Source** (`Customer Feedback Source`, `select_multiple`, optional): Select the source of the customer feedback (e.g., Social Media, Email, Phone, In App, Other).
• **Customer Feedback Type** (`Customer Feedback Type`, `select_multiple`, optional): Select the type of customer feedback (e.g., Complaint, Suggestion, Other).
• **Customer Feedback Source Other** (`Customer Feedback Source Other`, `text`, optional): If the customer feedback source is not listed, provide the actual source.
• **Customer Feedback Description Other** (`Customer Feedback Description Other`, `text`, optional): If the customer feedback description is not listed, provide the actual description.
• **Customer Feedback Resolution Other** (`Customer Feedback Resolution Other`, `text`, optional): If the resolution method is not listed, provide the actual resolution method.

## Tips
- Be concise and clear in your answers to ensure the support team can efficiently address the customer issue.
- Use this form only for customer negative feedback; other forms or processes may be in place for different types of customer interactions.
- Make sure to follow up on customer feedback and update the status and date as necessary.
