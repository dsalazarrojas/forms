# Galvanizing Process Feedback - Help Guide
## Purpose
The Galvanizing Process Feedback form is designed to collect user feedback about a galvanizing process run. This feedback is used to identify areas for improvement and optimize the galvanizing process for future runs.

## How To Complete This Form
1. **Galvanizing Process Feedback Form**
2. **Galvanizing Process Run**
3. **Issues Found**
4. **Issue Description**
5. **Satisfaction Rating**
6. **Additional Comments**

## Field-by-Field Explanation

* **Feedback Form Data** (`feedback_form_data`, text, optional): Enter a brief description of your experience with the galvanizing process run.
* **Galvanizing Process Run** (`galvanizing_process_run`, number, optional): Provide the galvanizing process run number.
* **Issues Found** (`issues_found`, select_multiple, optional): Select from the options provided:
	+ None
	+ Issue with the galvanizing line
	+ Issue with the process
	+ Other
* **Issue Description** (`issue_description`, text, optional): Provide a detailed description of the issue you selected.
* **Satisfaction Rating** (`satisfaction_rating`, number, optional): Rate your satisfaction with this galvanizing process run on a scale of 1 (not satisfied) to 5 (very satisfied).
* **Additional Comments** (`additional_comments`, text, optional): Is there anything else you'd like to comment on?

## Tips
- Be as detailed as possible when describing issues, as this will help us better understand the problems you've encountered.
- If you've selected "Other" for Issues Found, please provide a detailed description of the issue.
- For the Satisfaction Rating, please rate your overall experience with the galvanizing process run.
- You can add any additional comments or feedback you'd like to provide about the galvanizing process run.
