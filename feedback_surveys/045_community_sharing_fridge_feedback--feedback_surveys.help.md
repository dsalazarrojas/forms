# Community Sharing Fridge Feedback - Help Guide
## Purpose
The Community Sharing Fridge Feedback form is used to collect feedback from fridge users, allowing the management team to understand their experiences and preferences, and to make informed decisions to improve the service.

## How To Complete This Form
1. Please answer the questions honestly and accurately, providing as much detail as possible.
2. Select all relevant options for the "How Has the Fridge Impacted You" and "Have You Experienced Any Issues" questions.
3. If you have additional comments or suggestions, please use the text fields "Additional Comments" and "What Improvements Would You Suggest" to provide more information.
4. Please select only one option for the other questions, and make sure to fill out all required fields (those marked as required: true).

## Field-by-Field Explanation
* **Respondent Information** (`respondent_info`, `note`, optional): This is a text field where you can provide your basic details if you'd like.
* **First Name** (`first_name`, `text`, optional): Enter your first name if you'd like to be contacted or recognized for your feedback.
* **Last Name** (`last_name`, `text`, optional): Enter your last name if you'd like to be contacted or recognized for your feedback.
* **Email Address** (`email`, `email`, optional): Enter your email address if you'd like to receive updates or follow-ups on your feedback.
* **ZIP Code** (`zip_code`, `text`, optional): Enter your zip code to help us understand your location.
* **How Do You Use the Fridge** (`usage_type`, `select_one`, required): Select how you use the fridge (e.g., I Take Food, I Donate Food, etc.).
* **Which Fridge Location Do You Use** (`fridge_location`, `text`, required): Choose the specific location where you use the fridge.
* **How Often Do You Use the Fridge** (`frequency`, `select_one`, required): Select how often you use the fridge (e.g., Daily, Several Times a Week, etc.).
* **Satisfaction Ratings** (`satisfaction_ratings`, `note`, optional): Rate your satisfaction with the service on a scale of 1-5.
* **Overall Satisfaction** (`overall_satisfaction`, `select_one`, required): Select your overall satisfaction with the service (e.g., Very Satisfied, Satisfied, etc.).
* **Quality of Food Available** (`food_quality`, `select_one`, required): Rate the quality of food available in the fridge (e.g., Excellent, Very Good, etc.).
* **Variety of Food Available** (`food_variety`, `select_one`, required): Rate the variety of food available in the fridge (e.g., Excellent, Very Good, etc.).
* **Cleanliness of Fridge Area** (`cleanliness`, `select_one`, required): Rate the cleanliness of the fridge area (e.g., Excellent, Very Good, etc.).
* **Accessibility of Location** (`accessibility`, `select_one`, required): Rate how accessible the location is (e.g., Excellent, Very Good, etc.).
* **Food Availability When You Visit** (`availability`, `select_one`, required): Rate the availability of food when you visit (e.g., Always Available, Usually Available, etc.).
* **Safety** (`safety`, `select_one`, required): Rate how safe you feel when using the fridge (e.g., Very Safe, Safe, etc.).
* **How Has the Fridge Impacted You** (`impact`, `select_multiple`, required): Select all the ways the fridge has impacted you (e.g., Reduced Food Costs, Improved Nutrition, etc.).
* **Have You Experienced Any Issues** (`issues`, `select_multiple`, required): Select all the issues you've experienced with the fridge (e.g., Empty Fridge, Spoiled Food, etc.).
* **Describe the Issues** (`issues_description`, `text`, optional): If you've selected any issues, please describe them in more detail.
* **What Improvements Would You Suggest** (`improvements`, `text`, optional): If you have any suggestions for improvement, please type them here.
* **Would You Like to Volunteer** (`volunteer_interest`, `select_one`, optional): Select if you'd like to volunteer to help maintain the fridge.
* **What Tasks Would You Help With** (`volunteer_tasks`, `select_multiple`, optional): Select the tasks you'd be willing to help with.
* **Would You Like to Donate** (`donation_interest`, `select_one`, optional): Select if you'd like to donate to support the fridge.
* **How Do You Prefer Updates** (`communication`, `select_one`, optional): Select how you'd like to receive updates (e.g., Email, Social Media, etc.).
* **Would You Recommend the Fridge to Others** (`recommend`, `select_one`, required): Select if you'd recommend the fridge to others.
* **Additional Comments** (`additional_comments`, `text`, optional): If you have any other comments or thoughts, please share them here.
