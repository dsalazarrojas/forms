# International Buyer Return Policy Survey - Help Guide
## Purpose
This form is designed to collect feedback from buyers on their experience with the return policy process. It aims to understand the clarity of return information on product pages, the ease or difficulty of the return process, and the quality of communication between buyer and seller.

## How To Complete This Form

1.  Answer each question honestly, based on your actual experience with the return process.
2.  Select the option that best describes your experience for each question.
3.  You can submit as many times as you like, but please do so only once per experience.

## Field-by-Field Explanation

### 1. **Is return information clearly displayed on product pages?**
   •   This question aims to gauge how easy or difficult you found it to locate return information on product pages.
   •   Please select one of the following options: Very clear, Somewhat clear, Not very clear.

### 2. **How easy or difficult was the return process for you?**
   •   This question assesses your experience with the actual return process.
   •   Choose from: Very easy, Somewhat easy, Somewhat difficult, Very difficult.

### 3. **How satisfied were you with the return process?**
   •   This question seeks to understand your overall satisfaction level with the return process.
   •   Select one of the following: Very satisfied, Somewhat satisfied, Not very satisfied, Very dissatisfied.

### 4. **What challenges did you face during the return process?**
   •   This open-ended question allows you to share any difficulties you experienced during the return process.
   •   Type your answer in the text field provided.

### 5. **Did you receive clarification about the return process from the seller?**
   •   This question evaluates how well you understood the return process.
   •   Choose from: Very clear, Somewhat clear, Not very clear.

### 6. **How responsive was the seller to your return questions?**
   •   This question measures the seller's communication quality.
   •   Select one of the following: Very responsive, Somewhat responsive, Not very responsive.

### 7. **Was communication clear and timely?**
   •   This question assesses the communication quality and promptness.
   •   Choose from: Very clear and timely, Somewhat clear and timely, Not very clear and timely.

### 8. **Why were you satisfied or dissatisfied with the return process?**
   •   This open-ended question allows you to provide a detailed explanation for your satisfaction or dissatisfaction.
   •   Type your answer in the text field provided.

## Tips

*   Be honest and accurate in your responses.
*   Only submit this form once per experience.
*   Your feedback is valuable to us, and we appreciate your time.
