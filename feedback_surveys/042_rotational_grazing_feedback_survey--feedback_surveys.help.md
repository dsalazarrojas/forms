# rotational_grazing_feedback_survey - Help Guide
## Purpose
This form is used to gather feedback about your experience with rotational grazing. Your input will help us improve and refine our rotational grazing program.

## How To Complete This Form
To complete this form, simply read each question carefully and select the most accurate answer. You can use the space provided for additional comments if needed.

## Field-by-Field Explanation
- **What benefits does rotational grazing provide?** (`program_benefits`, select_multiple, required): Please select all the benefits you have experienced with rotational grazing. The options are:
	+ Yes (tick the box if you have experienced this benefit)
	+ No (tick the box if you have not experienced this benefit)
- **Have you experienced any challenges with rotational grazing?** (`challenges`, select_one, required): Please select one of the challenges you have faced with rotational grazing. The options are:
	+ Yes (tick the box if you have experienced this challenge)
	+ No (tick the box if you have not experienced this challenge)
- **How satisfied are you with rotational grazing?** (`satisfaction`, number, required): Please rate your satisfaction with rotational grazing on a scale of 1-5, where 1 is very dissatisfied and 5 is very satisfied.
- **Additional Comments** (`additional_comments`, note, optional): If you have any additional thoughts or comments about rotational grazing, please type them here. This is a space for any extra information you would like to share with us.
