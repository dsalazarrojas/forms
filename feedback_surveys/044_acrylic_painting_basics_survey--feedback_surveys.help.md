# Acrylic Painting Basics Survey - Help Guide
## Purpose
This survey is designed to collect feedback from students who have taken an acrylic painting class or workshop. Your input will help instructors refine their teaching methods and improve the overall learning experience.

## How To Complete This Form
- Carefully read each field's label and explanation below
- Fill out the survey in its entirety, answering all required fields
- Use the options provided for select fields, and write your answer in the designated text fields

## Field-by-Field Explanation
- **Student Name (1)**: Please enter your name, if you wish to identify yourself.
  - Type: text
  - Required: false
- **Previous Painting Experience (2)**: Select the level of your previous painting experience:
  - Type: select_one
  - Options: None, Some Watercolor, Some Oil, Advanced Artist
  - Required: true
- **Instructor Clarity Rating (3)**: Rate the clarity of the instructor's explanations:
  - Type: select_one
  - Options: 1 - unclear, 5 - very clear
  - Required: true
- **Techniques Mastered (4)**: Select the techniques you feel confident with:
  - Type: select_multiple
  - Options: Color Mixing, Glazing, Impasto, Blending, Scumbling
  - Required: false
- **Pace of the Class (5)**: Choose the pace of the class that suited you best:
  - Type: select_one
  - Options: Too Slow, Just Right, Too Fast
  - Required: true
- **Quality of Materials Provided (6)**: Rate the quality of the materials provided:
  - Type: select_one
  - Options: Poor, Good, Excellent, I brought my own
  - Required: true
- **Most Challenging Aspect of Acrylics (7)**: Describe the most challenging aspect of acrylics:
  - Type: text
  - Required: false
- **What would you like to learn next? (8)**: Suggest ideas for future workshops or topics:
  - Type: text
  - Required: false
- **Would you take an advanced course? (9)**: Indicate your interest in taking an advanced course:
  - Type: select_one
  - Options: 'True', 'False', Maybe
  - Required: true
- **Practice Note (10)**: Add any additional comments or suggestions:
  - Type: note
  - Required: false

## Tips
- Please answer honestly and thoroughly to provide valuable feedback
- Your input will help improve future classes and workshops
- If you have any additional comments or suggestions, please use the practice note field.
