# Treasury Forecasting Accuracy Survey - Help Guide
## Purpose
This form is designed to gather feedback on the treasury forecasting accuracy in the company.

## How To Complete This Form
To complete this form, please follow these steps:

1. Read through each page carefully.
2. Select one option for each question.
3. Provide any additional comments or feedback in the "Comments" field.
4. Submit your response.

## Field-by-Field Explanation

* **Introduction** (`introduction`, `note`, required: false): This page serves as an introduction to the survey.
* **Forecasting Methods** (`forecasting_methods`, `select_one`, required: false): Please select how you typically perform forecasting in the company:
	+ Automated
	+ In-house
	+ Manual
* **Forecasting Accuracy Level** (`accuracy_level`, `select_one`, required: false): Please rate the accuracy of the forecasting process:
	+ High
	+ Medium
	+ Low
* **Challenges** (`challenges`, `select_multiple`, required: false): If you have encountered challenges with the forecasting process, please select all that apply:
	+ Cash flow management
	+ Inaccurate forecasting
	+ Lack of visibility
	+ Other (please specify)
* **Comments** (`comments`, `text`, required: false): If you have any additional comments or feedback, please provide them here.
* **Finance Team Feedback** (`finance_team_feedback`, `select_one`, required: false): How would you rate the finance team's feedback on the forecasting process?
	+ Strongly Agree
	+ Somewhat Agree
	+ Neutral
	+ Somewhat Disagree
	+ Strongly Disagree
* **Non-finance Team Feedback** (`non_finance_team_feedback`, `select_one`, required: false): How would you rate the non-finance team's feedback on the forecasting process?
	+ Strongly Agree
	+ Somewhat Agree
	+ Neutral
	+ Somewhat Disagree
	+ Strongly Disagree
