# Organizational Structure Feedback Survey - Help Guide
## Purpose
The "Organizational Structure Feedback Survey" is a tool used to gather information about how employees perceive and interact with their organizational structure, with the aim of identifying areas that need improvement. This survey is not publicly shared, and the feedback will be used to inform internal decisions.

## How To Complete This Form
- Answer each question carefully, providing as much detail as possible.
- Make sure to answer all questions marked with an asterisk (\*).
- Be honest and provide your genuine thoughts and experiences.

## Field-by-Field Explanation

* **Role Hierarchy** (`role_hierarchy`, text, optional): This field is asking about the current role hierarchy within the organization. If you have a clear understanding of how roles are defined and communicated, please describe it. If not, you can provide any details you have about the hierarchy.
* **Communication Effectiveness** (`communication_effectiveness`, number, optional): This question is asking about how effectively information is communicated throughout the organization. Rate your experience, where:
	+ 1 = Very Poor
	+ 2 = Fair
	+ 3 = Neutral
	+ 4 = Good
	+ 5 = Excellent
* **Reporting Lines** (`reporting_lines`, select_one, optional): This question is asking about the current reporting lines within the organization. Do you have:
	+ 'Yes' - Clear reporting lines
	+ 'No' - Unclear reporting lines
* **Role Clarity** (`role_clarity`, select_multiple, optional): This question is asking about the clarity of roles within the organization. Please select all that apply:
	+ 'Yes'
	+ 'No'
* **Decision Making** (`decision_making`, text, optional): This field is asking about your experience with decision-making processes within the organization. Please provide any details you have.
* **Hierarchy Level** (`hierarchy_level`, select_one, optional): This question is asking about the level of hierarchy within the organization. Do you have:
	+ High
	+ Low
* **Communication Channels** (`communication_channels`, text, optional): This field is asking about the current communication channels used within the organization. If you have any information about how communication happens, please provide it.
* **Manager Support** (`manager_support`, number, optional): This question is asking about how effectively your manager supports you. Rate your experience, where:
	+ 1 = Very Poor
	+ 2 = Fair
	+ 3 = Neutral
	+ 4 = Good
	+ 5 = Excellent
* **Team Size** (`team_size`, select_multiple, optional): This question is asking about the team size and composition. Please select all that apply:
	+ 'Yes'
	+ 'No'
* **Feedback Frequency** (`feedback_frequency`, date, optional): This field is asking about how often you receive feedback. Please provide the date of your last feedback session.
* **Feedback Channels** (`feedback_channels`, select_one, optional): This question is asking about the current feedback channels used within the organization. Do you have:

	+ 4 = Good
