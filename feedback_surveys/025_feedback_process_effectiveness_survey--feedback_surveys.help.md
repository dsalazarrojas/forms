# Feedback Process Effectiveness Survey - Help Guide
## Purpose
This form aims to collect feedback on the processes in place, their effectiveness, and the tools used to manage feedback.

## How To Complete This Form
1. Please select the category for this feedback (if applicable) from the options provided.
2. Enter a title for the survey to identify it.
3. You can provide a brief description of the survey.
4. Select the tool assigned for this process (e.g., chatjimmy).
5. Provide a name of a file to save the output of this form, or leave it blank for the system to generate a default name.

## Field-by-Field Explanation
* **Feedback Process Effectiveness Survey** (`feedback_process_effectiveness_survey_title`, text, optional): Enter a unique title for this survey to help identify it in the feedback collection.
* **Category** (`category`, select_one, optional): Select a category for this feedback (e.g., 'Feedback Surveys') to help with filtering.
* **Description** (`description`, text, optional): Provide a brief description of the survey, e.g., the purpose or context.
* **Form ID** (`form_id`, number, optional): Enter a unique ID for this form, or leave it blank for the system to generate one.
* **Assigned Tool** (`assigned_tool`, select_one, optional): Select the tool used for this process, e.g., chatjimmy.
* **Output File** (`output_file`, text, optional): Enter the name of a file to save the output of this form, or leave it blank for the system to generate one.
* **Description (Note)** (`description`, text, optional): This is a note with a detailed explanation of the purpose and context of the survey.
