# Job Flexibility Perception Survey - Help Guide

## Purpose
This survey aims to gather your perceptions on various aspects of job flexibility, such as work-from-home options, flexible start and end times, work hours, and days off.

## How To Complete This Form
Please follow the instructions below to complete the form:

1. Review each page carefully and fill out the required fields.
2. Select the most accurate options for each field from the provided choices.
3. Be as honest as possible when answering the questions.

## Field-by-Field Explanation

**1. Work from Home (1/1)**
*   **Work from Home**: This question is asking about your current or preferred work-from-home arrangement. Please answer with the number of days or hours you work from home.
*   **Hint:** If you work from home full-time, please answer as "Fully". If you work from home part-time, please answer as "Partially".

**2. Remote Work Options (2/1)**
*   **Remote Work Options**: This question is asking about your availability to work remotely. Please select all the options that apply to you.
*   **Options:**
    *   **Partially**: You work remotely some days or hours.
    *   **Fully**: You work remotely full-time.

**3. Start Time (3/1)**
*   **Start Time**: This question is asking about your preferred start time for work. Please select a start time that works best for you.
*   **Hint:** If you prefer to start work early, please select a start time before 08:00. If you prefer to start work later, please select a start time after 08:00.

**4. End Time (4/1)**
*   **End Time**: This question is asking about your preferred end time for work. Please select an end time that works best for you.
*   **Hint:** If you prefer to end work early, please select an end time before 17:00. If you prefer to end work later, please select an end time after 17:00.

**5. Work Week (5/1)**
*   **Work Week**: This question is asking about the number of hours you work per week. Please answer with the total number of hours you work in a week.
*   **Hint:** If you work full-time, please answer 40 hours or more. If you work part-time, please answer less than 40 hours.

**6. Work Hours (6/1)**
*   **Work Hours**: This question is asking about the number of hours you work per day. Please answer with the average number of hours you work in a day.
*   **Hint:** If you work full-time, please answer 8 hours or more. If you work part-time, please answer less than 8 hours.

**7. Work Days (7/1)**
*   **Work Days**: This question is asking about the number of days you work per week. Please answer with the total number of days you work in a week.
*   **Hint:** If you work full-time, please answer 5 or 6 days. If you work part-time, please answer less than 5 days.

**8. Hours per Day (8/1)**
*   **Hours per Day**: This question is asking about the number of hours you work per day. Please answer with the average number of hours you work in a day.
*   **Hint:** If you work full-time, please answer 8 hours or more. If you work part-time, please answer less than 8 hours.

**9. Flexible Start Time (9/1)**
*   **Flexible Start Time**: This question is asking about your flexibility with start time. Please select a start time that you feel comfortable with.
*   **Hint:** If you're flexible about your start time, please answer any time of the day.

**10. Flexible End Time (10/1)**
*   **Flexible End Time**: This question is asking about your flexibility with end time. Please select an end time that you feel comfortable with.
*   **Hint:** If you're flexible about your end time, please answer any time of day.

**11. Flexible Days Off (11/1)**
*   **Flexible Days Off**: This question is asking about your preferences for flexible days off. Please answer with the number of days you'd like to have off.
*   **Hint:** If you prefer to have more days off, please answer a higher number.

**12. Flexible Hours Off (12/1)**
*   **Flexible Hours Off**: This question is asking about your preferences for flexible hours off. Please answer with the number of hours you'd like to have off.
*   **Hint:** If you prefer to have more hours off, please answer a higher number.

## Tips
*   Be honest and accurate when answering the questions.
*   Please answer the questions based on your current or preferred work situation.
*   If you have any questions or concerns, please feel free to contact us.
