# Pet Tech App Experience Survey - Help Guide
## Purpose
This form is designed to collect feedback and survey responses from users regarding their experience with the Pet Tech App.

## How To Complete This Form

1. Review each question carefully to ensure you provide accurate and detailed responses.
2. Answer each question to the best of your ability, providing as much information as possible.
3. Make sure to complete all required fields (indicated as "required" in the form).
4. Submit your completed form to provide your feedback.

## Field-by-Field Explanation

* **Pet Tech App Experience Survey** (`pet_tech_app_experience_survey`): This is the main question of the form, which asks you to describe your overall experience with the Pet Tech App.
* **App Usage** (`app_usage`): Please report how frequently you use the Pet Tech App, on a numeric scale (e.g., 1-10 times a week).
* **Satisfaction** (`satisfaction`): Select the option that best describes your level of satisfaction with the Pet Tech App:
	+ Option 1: Very Satisfied
	+ Option 2: Somewhat Satisfied
	+ Option 3: Not Satisfied
* **Issues** (`issues`): If you have encountered any issues with the Pet Tech App, please describe them in detail.
* **Feature Requests** (`feature_requests`): If you have any feature requests for the Pet Tech App, please describe them in detail.
* **Overall Experience** (`overall_experience`): Select all that apply from the following options:
	+ Option 1: Very Good
	+ Option 2: Somewhat Good
	+ Option 3: Not Good
* **Comments** (`comments`): Please provide any additional comments or suggestions you may have about the Pet Tech App.
* **Email** (`email`): Enter your email address so we can contact you if necessary.
* **Phone** (`phone`): Enter your phone number so we can contact you if necessary.
* **Pet Breed** (`pet_breed`): Select the breed of pet you have used the Pet Tech App for:
	+ Option 1: Dog
	+ Option 2: Cat
	+ Option 3: Other (please specify)
* **Pet Age** (`pet_age`): Select the age of your pet:
	+ Option 1: 0-2 years
	+ Option 2: 2-5 years
	+ Option 3: 5+ years
* **Tech Product** (`tech_product`): Select the tech product you used with the Pet Tech App:
	+ Option 1: Product 1
	+ Option 2: Product 2
	+ Option 3: Other (please specify)
* **Issue Description** (`issue_description`): If you have encountered any issues with the Pet Tech App, please describe them in detail.
* **Feature Request Description** (`feature_request_description`): If you have any feature requests for the Pet Tech App, please describe them in detail.
* **Rating** (`rating`): Please provide a numeric rating for the Pet Tech App (e.g., 1-5).
* **Rating Scale** (`rating_scale`): Select the scale you used to rate the Pet Tech App:
	+ Option 1: 1-5 scale
	+ Option 2: 1-10 scale
* **Rating Scale Options** (`rating_scale_options`): Select all that apply from the following options:
	+ Option 1: Option 1
	+ Option 2: Option 2
