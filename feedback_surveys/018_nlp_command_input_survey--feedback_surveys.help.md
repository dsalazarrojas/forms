# NLP Command Input Survey - Help Guide
## Purpose
The NLP Command Input Survey is designed to collect feedback from users about their experience with NLP commands. This feedback will help us understand how users utilize NLP commands, what challenges they face, and how we can improve the form and overall user experience.

## How To Complete This Form
To complete this form, please follow these steps:

1. Review the form questions carefully and answer them accurately.
2. For text fields, provide a clear and concise response.
3. For select_one and select_multiple fields, choose the most suitable option from the provided list.
4. For the date field, select the date you would like to improve the form.
5. Submit the form once you have completed all the questions.

## Field-by-Field Explanation

* **Nlp Command Usage (required)**: Describe how you typically use NLP commands in your workflow.
* **Challenges (optional)**: If you have any challenges or difficulties with using NLP commands, describe them here.
* **Improvements (optional)**: If you have any suggestions or ideas for improving NLP commands, describe them here.
* **Assigned Tool (required)**: Select the tool assigned to you for using NLP commands. (Please choose one of the following options: chatjimmy, other)
* **Form Help (optional)**: Select all that apply from the provided options regarding your feedback on the form. (Please choose one or more from the following options: feedback on form design, feedback on navigation, other)
* **What to Improve (optional)**: Select all that apply from the provided options regarding what you would like to improve in the form. (Please choose one or more from the following options: overall form clarity, overall form navigation, overall form satisfaction)
* **Why to Improve (required)**: Explain why you would like to improve the form. Please provide a clear and concise description.
* **When to Improve (optional)**: Select the date you would like to see the form improved by. (This is optional, but please select a specific date if you have one in mind.)
