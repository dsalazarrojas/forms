# Volleyball Team Snack Preferences Survey - Help Guide
## Purpose
This form is designed to collect information about the preferences and needs of the volleyball team members regarding snacks. It aims to ensure that all team members' needs and constraints are considered when ordering snacks for team gatherings and events.

## How To Complete This Form
To complete this form, please follow these steps:

1. Review the form questions carefully and answer all the questions honestly.
2. For each question, select the most accurate option from the provided choices (e.g., "Yes", "No", etc.).
3. If you have any additional comments or information that are not addressed in the provided options, please use the "Additional Information" field to provide more details.

## Field-by-Field Explanation
* **Snacks** (`main_page_snacks`, select_multiple, required: false): Answer "Yes" if you would like to have snacks available for the team, or "No" if you do not have any snack preferences.
* **Dietary Preferences** (`main_page_dietary_preferences`, select_one, required: false): Select "Yes" if you have any dietary restrictions or preferences that need to be considered when ordering snacks (e.g., vegetarian, gluten-free, etc.).
* **Special Diets** (`main_page_special_diets`, select_multiple, required: false): Choose any special diets that you have (e.g., vegan, keto, etc.).
* **Food Allergies** (`main_page_food_allergies`, select_multiple, required: false): Check any food allergies you have (e.g., peanut allergy, gluten allergy, etc.).
* **Additional Information** (`main_page_additional_info`, note, required: false): If you have any other comments or concerns about snacks, please provide more details here.
* **Coach Preferences** (`main_page_coach_preferences`, select_one, required: false): Answer "Yes" if you would like to have a separate option for coach preferences (e.g., do not provide snacks for coaches, etc.).
* **Additional Information** (`main_page_additional_info_2`, note, required: false): If you have any other comments or information that are not addressed in the previous questions, please provide more details here.
* **Submission Confirmation** (`main_page_submission_confirmation`, select_one, required: false): Answer "Yes" to confirm that you have completed the form accurately and submit it.

Note: This form does not require all fields to be completed, so please answer only the questions that are relevant to your needs and preferences.
