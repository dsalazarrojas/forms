# Digital Therapy Program Feedback Survey - Help Guide
## Purpose
The Digital Therapy Program Feedback Survey is a form designed to collect feedback from participants about their experiences with the digital therapy program. Your input is crucial in helping us improve the program and provide better services to future participants.

## How To Complete This Form
To complete this form, follow the steps below:

1. Fill in your **Participant ID**, which is a unique identifier assigned to you as a participant.
2. Select your **Overall Satisfaction** rating, indicating how satisfied you are with the program overall.
3. Provide any additional **Comments** you have about your experience with the program.
4. If applicable, select the **Tool Assigned** option to indicate which tool was assigned to you.
5. Answer the **Satisfactory Level** question by selecting how satisfied you are with the level of satisfaction you experienced with the program.
6. Answer the **Dissatisfactory Level** question by selecting how dissatisfied you are with the level of dissatisfaction you experienced with the program.
7. Select the **Satisfied** option to indicate whether you were satisfied with the program.
8. Answer the **Not Satisfied** question by selecting how not satisfied you are with the program.
9. Select the **Somewhat Dissatisfied** option to indicate if you were somewhat dissatisfied with the program.
10. Answer the **Not Dissatisfied** question by selecting how not dissatisfied you are with the program.
11. Select the **Comments 2** option to provide any additional comments about your experience with the program.

## Field-by-Field Explanation
* **Participant ID** (`participant_id`, `number`, required): Enter your unique participant ID to identify you as a participant in the program.
* **Overall Satisfaction** (`participant_rating`, `select_one`, required): Select one of the following options to indicate your overall satisfaction with the program:
	+ Very Satisfied
	+ Somewhat Satisfied
	+ Neutral
	+ Somewhat Dissatisfied
	+ Very Dissatisfied
* **Comments** (`comments`, `note`, optional): Provide any additional comments about your experience with the program.
* **Tool Assigned** (`assigned_tool_id`, `select_one`, optional): Select the tool that was assigned to you during the program.
* **Category ID** (`category_id`, `number`, optional): Enter the category ID, if applicable.
* **Satisfactory Level** (`participant_rating_2`, `select_one`, optional): Select one of the following options to indicate how satisfied you are with the level of satisfaction you experienced with the program:
	+ Very Satisfied
	+ Somewhat Satisfied
	+ Neutral
	+ Somewhat Dissatisfied
	+ Very Dissatisfied
* **Dissatisfactory Level** (`participant_rating_3`, `select_one`, optional): Select one of the following options to indicate how dissatisfied you are with the level of dissatisfaction you experienced with the program:
	+ Very Satisfied
	+ Somewhat Satisfied
	+ Neutral
	+ Somewhat Dissatisfied
	+ Very Dissatisfied
* **Satisfied** (`participant_id_2`, `select_one`, optional): Select one of the following options to indicate if you were satisfied with the program:
	+ True
	+ False
* **Not Satisfied** (`participant_rating_4`, `select_one`, optional): Select one of the following options to indicate how not satisfied you are with the program:
	+ True
	+ False
* **Somewhat Dissatisfied** (`participant_id_3`, `select_one`, optional): Select one of the following options to indicate if you were somewhat dissatisfied with the program:
	+ True
	+ False
* **Not Dissatisfied** (`participant_rating_5`, `select_one`, optional): Select one of the following options to indicate how not dissatisfied you are with the program:
	+ True
	+ False
* **Comments 2** (`comments_2`, `select_one`, optional): Select one of the following options to provide additional comments:
	+ True
	+ False
