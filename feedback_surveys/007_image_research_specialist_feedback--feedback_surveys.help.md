# image_research_specialist_feedback - Help Guide
## Purpose
The purpose of this form is to gather feedback from users about the image research specialist team's performance.

## How To Complete This Form
To complete this form, follow these steps:
- Select the "Feedback for Image Research Specialist" page to begin the feedback process.
- On this page, select all that apply to indicate whether or not the specialist has performed well in certain areas.
- Move on to the next page to continue the feedback process.

## Field-by-Field Explanation
### Research Specialist
* **Feedback for Image Research Specialist** (`research_specialist`, `select_multiple`, optional):
	+ Select all that apply to indicate whether or not the specialist has performed well in certain areas.
* **Category** (`category`, `select_one`, optional):
	+ Select the category that best describes the type of service provided by the specialist.
* **Asset Type** (`asset_type`, `select_one`, optional):
	+ Select the type of asset that the specialist worked on.
* **Rating** (`rating`, `number`, optional):
	+ Rate the specialist's performance on a scale of 0-10.
* **Comment** (`comment`, `text`, optional):
	+ Provide a more detailed explanation of the specialist's performance.
* **Submitted By** (`submitted_by`, `text`, optional):
	+ Enter your name or username.
* **Date Submitted** (`submitted_on`, `date`, optional):
	+ Enter the date you are submitting this feedback.
* **User Submitted** (`submitted_by_user`, `text`, optional):
	+ Enter any additional context or notes about this submission.
