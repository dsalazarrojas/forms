# store_features_evaluation_form - Help Guide
## Purpose
The store features evaluation form is designed to collect feedback and evaluation of store features from users. This form is used to gather information about the features of a store, including the overall score and comments.

## How To Complete This Form
1. Select the category that best describes the store features you are evaluating.
2. Choose the options for each feature (feature1, feature2, and feature3) that you would like to evaluate. Please select only one option for each feature.
3. Enter your overall score for the store features.
4. Enter any additional comments about the store features.
5. Select the submission status.
6. Fill in your details (name, email, phone, and date/time of submission).
