# Global Economic Empowerment Survey - Help Guide
## Purpose

The Global Economic Empowerment Survey is a data collection tool aimed at assessing the financial stability and well-being of individuals or households. This information will help inform economic policies and programs that promote financial inclusion.

## How To Complete This Form

1. Please answer each question carefully and honestly.
2. Select the relevant answer options from the provided list.
3. Make sure to answer all required questions (marked as "required" in the form).
4. If you are unsure about any question, please ask for help or clarification.

## Field-by-Field Explanation

### Employment Status
* **Employment Status (Active/Inactive)** (`employment_status`, `select_one`, required): This question asks about your current employment status. Please select "Active" if you are employed, and "Inactive" if you are not employed.
* **Household Income** (`household_income`, `number`, required): This question asks about the total income of your household. Please enter a numerical value.
* **Income Sources (Yes/No)** (`income_sources`, `select_one`, required): This question asks whether you have any income sources. Select "Yes" if you have any income sources, and "No" if you do not.
* **Savings Institution (Yes/No)** (`savings_institution`, `select_multiple`, required): This question asks whether you have savings institutions, such as banks or credit unions. Select "Yes" if you do have savings institutions, and "No" if you do not.
* **Financial Institutions (Yes/No)** (`financial_institutions`, `select_multiple`, required): This question asks whether you have access to financial institutions, such as banks, credit unions, or other financial providers. Select "Yes" if you do have financial institutions, and "No" if you do not.
* **Savings Instructors (Yes/No)** (`savings_in`, `select_multiple`, required): This question asks whether you have savings instructors, such as financial advisors or planners. Select "Yes" if you have savings instructors, and "No" if you do not.
* **Household Income Source** (`household_income_source`, `select_one`, required): This question asks about the primary source of income for your household. Select "Yes" if the income is from a specific source, and "No" if it is not.
* **Household Income Period** (`household_income_period`, `text`, required): This question asks about the period of time your household has had consistent income. Please enter a text response.
* **Household Income Frequency** (`household_income_frequency`, `select_one`, required): This question asks about how often your household has income. Select "Yes" if your household has income, and "No" if it does not.
* **Household Income Amount** (`household_income_amount`, `number`, required): This question asks about the amount of income your household has. Please enter a numerical value.
* **Household Income Difference** (`household_incomediffers`, `select_one`, required): This question asks whether the income of your household is stable or has changed recently. Select "Yes" if it has changed, and "No" if it has not.
* **Household Income Important** (`household_income_important`, `select_multiple`, required): This question asks about the importance of income for your household. Select all applicable options.
* **Financial Access (Yes/No)** (`financial_access`, `select_multiple`, required): This question asks about your access to financial services. Select "Yes" if you have access, and "No" if you do not.
* **Savings Awareness** (`savings_awareness`, `select_one`, required): This question asks about your awareness of savings options. Select "Yes" if you are aware, and "No" if you are not.
* **Savings Goals** (`savings_goals`, `select_one`, required): This question asks about your savings goals. Select "Yes" if you have savings goals, and "No" if you do not.
* **Savings Frequency** (`savings_frequency`, `select_one`, required): This question asks about how frequently you save. Select "Yes" if you do save, and "No" if you do not.
* **Financial Institutional Instruments (Yes/No)** (`financial_institutional_instruments`, `select_multiple`, required): This question asks about your access to financial institutional instruments. Select "Yes" if you have access, and "No" if you do not.
* **Financial Institutional Products (Yes/No)** (`financial_institutional_products`, `select_multiple`, required): This question asks about your access to financial institutional products. Select "Yes" if you have access, and "No" if you do not.
* **Financial Services (Yes/No)** (`financial_services`, `select_multiple`, required): This question asks about your access to financial services. Select "Yes" if you have access, and "No" if you do not.
* **Financial Service Institutions (Yes/No)** (`financial_services_institutions`, `select_multiple`, required): This question asks about your access to financial service institutions. Select "Yes" if you have access, and "No" if you do not.
* **Savings Instrument (Yes/No)** (`savings_instrument`, `select_multiple`, required): This question asks about your use of savings instruments. Select "Yes" if you use them, and "No" if you do not.
* **Financial Aid (Yes/No)** (`financial_aid`, `select_one`, required): This question asks about your access to financial aid. Select "Yes" if you have access, and "No" if you do not.
* **Empowerment** (`empowerment`, `select_one`, required): This question asks about your level of financial empowerment. Select "Yes" if you feel empowered, and "No" if you do not.
* **Region** (`region`, `select_one`, required): This question asks about your location. Select "Yes" if you are in a specific region, and "No" if you are not.
* **Notes** (`notes`, `note`, required): This question allows you to provide additional comments or notes. Please enter a text response.

## Tips

* Be honest and accurate when answering the questions.
* If you need help or clarification about any question, please ask.
* Make sure to review your answers before submitting the form.
