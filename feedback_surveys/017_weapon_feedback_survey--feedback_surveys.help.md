# weapon_feedback_survey - Help Guide
## Purpose
This form is designed to collect feedback on weapons, including their type, model, performance, and any issues encountered. It's intended for reporting and improving weapons.

## How To Complete This Form
This form has multiple pages. Please go to each page and complete the fields as instructed.

## Field-by-Field Explanation
* **Weapon Type** (<type: select_one>, required: false>): Choose the type of weapon you're providing feedback on. This field is optional.
* **Weapon Model** (<type: select_one, required: false>): Select the model of the weapon from the options provided.
* **Performance Rating** (<type: number, required: false>): Rate the performance of the weapon on a scale. The exact scale is not specified in the form, so please rate it based on your understanding of the weapon's performance.
* **Issue Report** (<type: text, required: false>): If you've encountered any issues with the weapon, describe them in this field.
* **Improvement Suggestion** (<type: text, required: false>): If you have any suggestions for improving the weapon, describe them in this field.

## Tips
- Please be as detailed as possible when filling out the form.
- If you're unsure about any field, please ask for clarification.
- This form is intended for collecting feedback, so please be respectful and constructive in your responses.
