# Project Satisfaction Survey - Help Guide
## Purpose
This form is designed to collect feedback from end users on their experiences with the project. Your input will help us identify areas where we can improve the project to make it more valuable and user-friendly.

## How To Complete This Form
To complete this form, please answer the questions in the following order:

1. Go through the form page by page, starting with the first page.
2. For each field, provide the most accurate and honest response you can.
3. Use the provided options for select fields, or enter a free-text response if the field is a text input.

## Field-by-Field Explanation
* **project_satisfaction_survey_1** (`project_satisfaction_survey_1_label`, text, optional): Please provide your general thoughts about the project. This field is optional, but your response will help us understand your overall satisfaction with the project.
* **category_1** (`category_1_label`, select_one, optional): Choose the category that best describes your experience with the project. This field has two options: "category 1 option 1" and "category 1 option 2".
* **description_1** (`description_1_label`, text, optional): Please provide a more detailed description of your experience with the project. This field is optional, but it will help us better understand your feedback.

## Tips
* Please be honest and accurate in your responses.
* If you have any suggestions or comments that are not covered in these fields, please include them in the "project_satisfaction_survey_1" field.
* If you have any questions or concerns, please contact us.
