# Partnership Facilities Audit Survey - Help Guide

## Purpose
The Partnership Facilities Audit Survey is a tool used to gather information about facilities within partnerships. It helps auditors and partners evaluate the facilities' compliance and quality. This survey is essential for ensuring that all facilities within the partnership adhere to the required standards and guidelines.

## How To Complete This Form
To complete this form, please follow these steps:

1. Read through each page carefully and fill out the required information for each field.
2. Use the provided hints to guide you through the process.
3. If you have any questions or concerns, please don't hesitate to ask for help.

## Field-by-Field Explanation

* **Introduction**: This is a note field where you can write any additional information or context about the facility you are surveying.
* **Facility Address**: Please enter the address of the facility, including the street address, city, and state.
* **Facility Name**: Enter the name of the facility being surveyed.
* **Facility Type**: Select the type of facility from the dropdown list. You can choose between "Manufacturing" and "Other".
* **Facility Rating**: Enter a rating for the facility's overall quality or compliance. This field is a number value.
* **Rating Observation**: If you have any observations or comments about the facility's rating, enter them here.
* **Partner Name**: Enter the name of the partner associated with the facility.
* **Partner Title**: Enter the title of the partner associated with the facility.
* **Facility Compliance**: Enter a rating for the facility's compliance with the required standards. This field is a number value.
* **Facility Observations**: If you have any observations or comments about the facility, enter them here.
* **Facility Comments**: Enter any additional comments or information about the facility.
* **Facility Ratings**: Select the ratings that apply to the facility. You can choose multiple options.
* **Audit Date**: Enter the date the audit was conducted.
* **Auditor**: Enter the name of the person who conducted the audit.
* **Comments**: Enter any additional comments or observations about the audit process or facility.
* **Partner Comments**: Enter any comments or observations from the partner associated with the facility.
* **Facility Rating Averages**: This is a note field where you can calculate and enter the average rating of the facility, if necessary.

Please note that all fields are optional, and you can skip any fields that are not relevant to your specific situation. If you have any questions or concerns, please don't hesitate to ask for help.
