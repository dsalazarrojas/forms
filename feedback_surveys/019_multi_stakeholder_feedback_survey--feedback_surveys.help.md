# Multi Stakeholder Feedback Survey - Help Guide
## Purpose
This form is designed to gather feedback from various stakeholders in the project, including team members, external stakeholders, project management officers, customers, project participants, project leaders, project sponsors, and other stakeholders.

## How To Complete This Form
1. Select all stakeholders involved in your project.
	* Choose all that apply from the following options:
		+ Project team members
		+ External stakeholders
		+ Project management officers
		+ Customers
		+ Project participants
		+ Project leaders
		+ Project sponsors
		+ Other stakeholders
2. Provide contact information for each stakeholder.
	* Enter the Stakeholder name for each selected stakeholder.
	* Enter the Stakeholder email for each selected stakeholder.
	* Enter the Stakeholder phone number for each selected stakeholder.
3. Rate your satisfaction with the project.
	* Select a number from 1-5 to rate your satisfaction with the project.
4. Provide feedback.
	* Type any comments or issues you may have with the project.

## Field-by-Field Explanation
### Project team members
* **Project team members** (`project_team_members`, select_multiple, required: false): Select all the project team members who are involved in your project. Choose all that apply from the options provided.

### External stakeholders
* **External stakeholders** (`external_stakeholders`, select_multiple, required: false): Select all the external stakeholders who are involved in your project. Choose all that apply from the options provided.

### Project management officers
* **Project management officers** (`project_management_officers`, select_multiple, required: false): Select all the project management officers who are involved in your project. Choose all that apply from the options provided.

### Customers
* **Customers** (`customers`, select_multiple, required: false): Select all the customers who are involved in your project. Choose all that apply from the options provided.

### Project participants
* **Project participants** (`project_participants`, select_multiple, required: false): Select all the project participants who are involved in your project. Choose all that apply from the options provided.

### Project leaders
* **Project leaders** (`project_leaders`, select_multiple, required: false): Select all the project leaders who are involved in your project. Choose all that apply from the options provided.

### Project sponsors
* **Project sponsors** (`project_sponsors`, select_multiple, required: false): Select all the project sponsors who are involved in your project. Choose all that apply from the options provided.

### Other stakeholders
* **Other stakeholders** (`other_stakeholders`, select_multiple, required: false): Select all the other stakeholders who are involved in your project. Choose all that apply from the options provided.

### Project team leaders
* **Project team leaders** (`project_team_leaders`, select_multiple, required: false): Select all the project team leaders who are involved in your project. Choose all that apply from the options provided.

### Project Sponsor
* **Project Sponsor** (`project_sponsor`, select_one, required: false): Select whether the project sponsor is applicable or not.

### Stakeholder Group
* **Stakeholder Group** (`stakeholder_group`, text, required: false): Enter the group that the stakeholder belongs to.

### Stakeholder Name
* **Stakeholder Name** (`stakeholder_name`, text, required: false): Enter the name of the stakeholder.

### Stakeholder Email
* **Stakeholder Email** (`stakeholder_email`, email, required: false): Enter the email of the stakeholder.

### Stakeholder Phone
* **Stakeholder Phone** (`stakeholder_phone`, text, required: false): Enter the phone number of the stakeholder.

### Rating
* **Rating** (`rating`, number, required: false): Rate your satisfaction with the project from 1-5.

### Feedback
* **Feedback** (`feedback`, note, required: false): Provide any comments or issues you may have with the project.
