# Beacons Audit Survey - Help Guide
## Purpose
The Beacons Audit Survey is designed to gather your feedback on your experience with beacons. This form will help us understand how you use beacons, what you like or dislike about them, and how we can improve our product.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in your name, email address, and select your role.
2. Choose how long you've been using beacons.
3. Select the size of your beacon deployment.
4. Choose the main application of beacons.
5. Rate the overall effectiveness of beacons.
6. Select the reliability of the signal.
7. Rate your satisfaction with battery life.
8. Select how easy or difficult it was to set up beacons.
9. Choose how much maintenance is required for beacons.
10. Answer if you've achieved a return on investment (ROI) with beacons.
11. Select the impact on user engagement.
12. Choose all the challenges you faced while using beacons.
13. Let us know if you would recommend beacons to others.
14. Select your future plans for beacon technology.
15. Provide any additional feedback you'd like to share.

## Field-by-Field Explanation
* **Respondent Name** (1) (`respondent_name`, text, Optional): Please fill in your full name for our reference.
* **Email Address** (2) (`email_address`, email, For follow-up): Enter your email address for follow-up communication.
* **Organization** (3) (`organization`, text, Required): Type in your company or institution name.
* **Your Role** (4) (`role`, select_one, Required): Select your job title from the list.
* **How Long Have You Used Beacons** (5) (`beacon_usage_duration`, select_one, Required): Choose how long you've been using beacons.
* **Size of Beacon Deployment** (6) (`beacon_deployment_size`, select_one, Required): Select the number of beacons you have deployed.
* **Primary Use Case** (7) (`primary_use_case`, select_one, Required): Select the main application of beacons.
* **Overall Beacon Effectiveness** (8) (`beacon_effectiveness`, select_one, Required): Rate how effective beacons have been in your experience.
* **Signal Reliability** (9) (`signal_reliability`, select_one, Required): Select the reliability of the signal beacons provide.
* **Battery Life Satisfaction** (10) (`battery_life_satisfaction`, select_one, Required): Rate your satisfaction with battery life.
* **Ease of Deployment** (11) (`ease_of_deployment`, select_one, Required): Select how easy or difficult it was to set up beacons.
* **Maintenance Requirements** (12) (`maintenance_requirements`, select_one, Required): Choose how much maintenance beacons require.
* **Has ROI Been Achieved** (13) (`roi_achieved`, select_one, Required): Answer if you've achieved a return on investment (ROI) with beacons.
* **Impact on User Engagement** (14) (`user_engagement_impact`, select_one, Required): Select the impact beacons have had on user engagement.
* **Challenges Faced** (15) (`challenges_faced`, select_multiple, Required): Choose all the challenges you faced while using beacons.
* **Would You Recommend Beacons** (16) (`would_recommend`, select_one, Required): Let us know if you would recommend beacons to others.
* **Future Plans for Beacon Technology** (17) (`future_plans`, select_one, Required): Select your future plans for beacon technology.
* **Additional Feedback** (18) (`additional_feedback`, text, Optional): Provide any additional feedback or comments you'd like to share.
