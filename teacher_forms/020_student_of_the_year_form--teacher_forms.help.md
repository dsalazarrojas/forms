# Student Of The Year Form - Help Guide
## Purpose
This form is designed to collect and document student nomination information for academic achievements.

## How To Complete This Form
To complete this form, follow these steps:
1. Fill in the required and optional fields with the relevant information for the student nomination.
2. Make sure to complete all the required fields (indicated by *) in each page.
3. Review the form for accuracy and completeness before submitting.

## Field-by-Field Explanation

* **Nomination Page** (`nomination_page`, text, required): Enter a brief description of the student's nomination.
* **Nomination Page 1** (`nomination_page_1`, text, required): Enter more details about the student's nomination.
* **Nomination Page 2** (`nomination_page_2`, text, required): Enter even more details about the student's nomination.
* **Student Info** (`student_info`, text, required): Enter basic information about the student, such as name and grade level.
* **Name** (`name`, text, required): Enter the student's name.
* **Other Name** (`name_other`, text, required): Enter any other name associated with the student (e.g. alternate name).
* **Email** (`email`, email, required): Enter the student's email address.
* **Phone** (`phone`, text, required): Enter the student's phone number.
* **Nomination Date** (`nomination_date`, date, required): Enter the date of the nomination.
* **Nomination Time** (`nomination_time`, time, required): Enter the time of the nomination.
* **Student Grade Level** (`student_grade_level`, text, required): Enter the student's grade level (e.g. freshman, sophomore, junior, senior).
* **Student Subject Area** (`student_subject_area`, text, required): Enter the student's subject area of achievement (e.g. mathematics, science, language arts).
* **Teacher Name** (`teacher_name`, text, required): Enter the teacher's name associated with the student.
* **Teacher Email** (`teacher_email`, text, required): Enter the teacher's email address.
* **Teacher Phone** (`teacher_phone`, text, required): Enter the teacher's phone number.
* **Other Teacher Name** (`teacher_name_other`, text, required): Enter any other teacher associated with the student.
* **Other Teacher Name 1** (`teacher_name_other_1`, text, required): Enter another teacher associated with the student.
* **Other Teacher Name 2** (`teacher_name_other_2`, text, required): Enter another teacher associated with the student.
* **Other Teacher Name 3** (`teacher_name_other_3`, text, required): Enter another teacher associated with the student.
* **Other Teacher Name 4** (`teacher_name_other_4`, text, required): Enter another teacher associated with the student.
* **Other Teacher Name 5** (`teacher_name_other_5`, text, required): Enter another teacher associated with the student.
* **Nomination Comments** (`nomination_comments`, text, required): Enter any comments or additional information about the nomination.
* **Student Id** (`student_id`, number, required): Enter the student's ID number.
* **Teacher Id** (`teacher_id`, number, required): Enter the teacher's ID number.
* **Submit** (`submit`, text, required): Click to submit the form and complete the nomination.
