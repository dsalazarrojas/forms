# international_school_application_form - Help Guide
## Purpose
This form is designed to collect information from students applying to international schools.

## How To Complete This Form
To complete this form, follow the steps below:

1. Fill in the student's personal details.
2. Provide the guardian's information (if applicable).
3. Select the preferred language and country of origin.
4. Add any additional information as required.
5. Review and submit the form.

## Field-by-Field Explanation

* **Student name** (`student_name`, text, required): Enter the student's full name.
* **Student email** (`student_email`, email, required): Enter a valid email address for the student.
* **Date of birth** (`student_date_of_birth`, date, required): Enter the student's date of birth in the format `YYYY-MM-DD`.
* **Guardian name** (`guardian_name`, text, optional): Enter the guardian's full name (if applicable).
* **Guardian email** (`guardian_email`, email, optional): Enter a valid email address for the guardian (if applicable).
* **Student address** (`student_address`, text, required): Enter the student's residential address.
* **Student phone** (`student_phone`, text, optional): Enter the student's phone number (if applicable).
* **Guardian phone** (`guardian_phone`, text, optional): Enter the guardian's phone number (if applicable).
* **Student country** (`student_country`, select one, required): Select the student's country of origin.
* **Guardian country** (`guardian_country`, select one, optional): Select the guardian's country of origin (if applicable).
* **Preferred language** (`preferred_language`, select multiple, optional): Select one or more languages the student would like to learn.
* **Student notes** (`student_notes`, note, optional): Enter any additional information about the student.
* **Guardian notes** (`guardian_notes`, note, optional): Enter any additional information about the guardian.
* **Teacher recommendation** (`teacher_recommendation`, text, optional): Enter a recommendation from the student's teacher.
* **Teacher name** (`teacher_name`, text, optional): Enter the teacher's name who is providing the recommendation.
* **Teacher email** (`teacher_email`, email, optional): Enter the teacher's email address.
* **Teacher phone** (`teacher_phone`, text, optional): Enter the teacher's phone number.
* **Teacher school** (`teacher_school`, text, optional): Enter the name of the teacher's school.
* **Teacher country** (`teacher_country`, select one, optional): Select the teacher's country of origin.
* **Additional information** (`student_additional_information`, text, optional): Enter any additional information about the student.
* **Language proficiency** (`student_language_proficiency`, select multiple, optional): Select one or more languages the student is proficient in.
* **Guardian information** (`guardian_additional_information`, text, optional): Enter any additional information about the guardian.
* **Family background** (`student_family_background`, text, optional): Enter any information about the student's family background.
* **Guardian family background** (`guardian_family_background`, text, optional): Enter any information about the guardian's family background.
* **Submit** (`submission`, text, optional): Click the submit button to complete and submit the form.

Please note that the required fields are marked with a red asterisk (*) in the field label.
