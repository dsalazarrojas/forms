# Student Goal Setting Form - Help Guide

## Purpose
The Student Goal Setting Form is designed to be a tool for teachers to set and track goals for their students. This form serves as a means to document and communicate student goals, progress, and feedback.

## How To Complete This Form

To get started, simply follow the steps outlined below:

1.  Ensure you have access to the form and a clear understanding of the student's current grade level.
2.  Select one of the two options for "goal" (Yes/No) based on whether or not you want to set a goal for this particular student.
3.  If you've chosen 'Yes', provide a brief description of the student goal in the "goal_description" field.
4.  Set the "target_grade" field based on the student's expected grade level for the next grading period.
5.  Determine the student's current "progress" (Yes/No) status, and select accordingly.
6.  Choose one or more target behaviors for the student in the "target_behavior" field.
7.  Write any additional comments or notes about the student in the "teacher_notes" field.
8.  Provide student feedback in the "student_feedback" field, if applicable.
9.  Enter your signature as the teacher in the "teacher_signature" field.
10. Enter the parent/guardian's signature in the "parent_signature" field, if applicable.
11. Enter the student's name in the "student_name" field.
12. Select the school year in which the student is enrolled in the "school_year" field.

## Field-by-Field Explanation

* **student_goal_setting_form** (`student_goal_setting_form`, text, optional): This field is for the teacher to input a brief description of the form, if applicable.
* **goals** (`goals`, select multiple, optional): This field allows you to indicate if you want to set a goal for the student (Yes/No).
* **goal_description** (`goal_description`, text, optional): Provide a brief description of the student's goal if selected in the "goals" field.
* **target_grade** (`target_grade`, number, optional): Enter the student's expected grade level for the next grading period.
* **student_progress** (`student_progress`, select one, optional): This field indicates the student's current progress (Yes/No).
* **target_behavior** (`target_behavior`, select multiple, optional): Select one or more target behaviors for the student.
* **teacher_notes** (`teacher_notes`, note, optional): Enter any additional comments or notes about the student.
* **student_feedback** (`student_feedback`, text, optional): Provide feedback from the student if applicable.
* **teacher_signature** (`teacher_signature`, text, optional): Enter your signature as the teacher.
* **parent_signature** (`parent_signature`, text, optional): Enter the parent/guardian's signature if applicable.
* **student_name** (`student_name`, select one, optional): Select the student's name.
* **school_year** (`school_year`, select one, optional): Select the school year the student is enrolled in.
