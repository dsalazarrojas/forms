# Faculty Teaching Resources Questionnaire - Help Guide
## Purpose
The Faculty Teaching Resources Questionnaire is designed to gather information from faculty members about their use and satisfaction with various teaching resources. This data will help the institution better understand faculty's perception and use of teaching resources, which can inform decision-making and improve teaching practices.

## How To Complete This Form

1. Review each page of the form carefully.
2. Select all resources that you have used for teaching purposes.
3. Rate your satisfaction with the selected resources.
4. Provide any additional comments or feedback about the resources.
5. Ensure that you submit the form accurately and honestly.

## Field-by-Field Explanation

* **Teaching Resources Used**
	+ This field is where you select all resources that you have used for teaching purposes. You can choose from:
		- Books/Textbooks
		- Online Resources
		- Other (please specify)
* **Satisfaction with Teaching Resources**
	+ This field asks you to rate your satisfaction with each selected resource. You can choose from:
		- Very satisfied
		- Neutral
		- Very dissatisfied
* **Email**
	+ This is a required field where you provide your email address.
* **Additional Comments**
	+ This is an optional field where you can provide any additional comments or feedback about the resources.
* **Have You Used Any Other Resources?**
	+ This field asks if you have used any other resources for teaching purposes. You can choose from:
		- Yes
		- No
* **Have You Used Books/Textbooks?**
	+ This field asks if you have used books and textbooks as teaching resources. You can choose from:
		- Yes
		- No
* **Have You Used Online Resources?**
	+ This field asks if you have used online resources as teaching resources. You can choose from:
		- Yes
		- No
* **Date**
	+ This is a required field where you provide a date in the format MM/DD/YYYY.
* **Do You Plan to Use Any Other Resources?**
	+ This field asks if you plan to use any other resources in the future. You can choose from:
		- Yes
		- No
* **Do You Plan to Use Books/Textbooks?**
	+ This field asks if you plan to use books and textbooks as teaching resources in the future. You can choose from:
		- Yes
		- No
* **Do You Plan to Use Online Resources?**
	+ This field asks if you plan to use online resources as teaching resources in the future. You can choose from:
		- Yes
		- No
