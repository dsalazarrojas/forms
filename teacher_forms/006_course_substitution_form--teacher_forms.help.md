# Course Substitution Form - Help Guide
## Purpose
This form is used to manage course substitutions for a school, allowing users to track and update the status of course substitutions.

## How To Complete This Form
1.  Enter the Course ID of the course for which you are requesting a substitution.
2.  Select the Start Date of the course for which you are making the substitution.
3.  Select the End Date of the course for which you are making the substitution.
4.  Enter the Teacher ID of the teacher requesting the substitution.
5.  Select Yes or No to indicate whether the teacher is requesting the substitution.
6.  Enter the Reason for the substitution. (Note: This field is for free-form comments.)
7.  Select Yes or No to indicate whether the user requesting the substitution is a teacher or student.
8.  Select Yes or No to indicate whether the teacher has approved the substitution.
9.  Enter the comments made by the teacher when approving or declining the substitution. (Note: This field is for free-form comments.)
10. Enter the Student ID of the student for whom the substitution is being made.
11.  Select Yes or No to indicate whether the student is eligible for the substitution.
12.  Select Yes or No to indicate whether the user requesting the substitution is a teacher or student.
13.  Select Yes or No to indicate whether the teacher has confirmed the substitution.
14.  Enter comments made by the teacher when confirming or declining the substitution. (Note: This field is for free-form comments.)
15.  Select the status of the course substitution, which can be Active or Inactive.
16.  Enter any additional comments from the teacher about the substitution.
17.  Select Yes or No to indicate whether the teacher is the requesting user.
18.  Select Yes or No to indicate whether multiple approvals are required for the substitution.
19.  Select Yes or No to indicate whether the user requesting the substitution is the teacher.
20.  Enter any additional comments from the teacher requesting user.
21.  Select the status of the course substitution approvals, which can be Yes or No.

## Field-by-Field Explanation
* **Course Id** (1, `number`, required): Enter the ID of the course for which you are making the substitution.
* **Start Date** (2, `date`, optional): Select the start date of the course for which you are making the substitution.
* **End Date** (3, `date`, optional): Select the end date of the course for which you are making the substitution.
* **Teacher Id** (4, `number`, optional): Enter the ID of the teacher requesting the substitution.
* **Teacher Substitution** (5, `select_multiple`, optional): Select Yes or No to indicate whether the teacher is requesting the substitution.
* **Reason For Substitution** (6, `note`, optional): Enter a brief description of why the substitution is being made.
* **Course Substitution Requesting User** (7, `select_one`, optional): Select Yes or No to indicate whether the user requesting the substitution is a teacher or student.
* **Teacher Approval** (8, `select_one`, optional): Select Yes or No to indicate whether the teacher has approved the substitution.
* **Teacher Comments** (9, `note`, optional): Enter any comments made by the teacher when approving or declining the substitution.
* **Student Id** (10, `number`, optional): Enter the ID of the student for whom the substitution is being made.
* **Student Substitution** (11, `select_multiple`, optional): Select Yes or No to indicate whether the student is eligible for the substitution.
* **School Year** (12, `select_one`, optional): Select Yes or No to indicate the school year of the course.
* **Teacher Substitution Requesting User** (13, `select_one`, optional): Select Yes or No to indicate whether the user requesting the substitution is a teacher or student.
* **Teacher Confirmation** (14, `select_one`, optional): Select Yes or No to indicate whether the teacher has confirmed the substitution.
* **Teacher Confirmation Comments** (15, `note`, optional): Enter any comments made by the teacher when confirming or declining the substitution.
* **Course Substitution Status** (16, `select_one`, optional): Select the status of the course substitution, which can be Active or Inactive.
* **Teacher Comments** (17, `note`, optional): Enter any additional comments from the teacher.
* **Teacher Requesting User** (18, `select_one`, optional): Select Yes or No to indicate whether the teacher is the requesting user.
* **Teacher Substitution Approvals** (19, `select_multiple`, optional): Select Yes or No to indicate whether multiple approvals are required for the substitution.
* **Teacher Substitution Requesting User** (20, `select_one`, optional): Select Yes or No to indicate whether the user requesting the substitution is the teacher.
* **Teacher Requesting User** (21, `select_one`, optional): Select Yes or No to indicate whether the teacher is the requesting user.
* **Teacher Substitution Approvals Comments** (22, `note`, optional): Enter any additional comments from the teacher requesting user.
* **Teacher Requesting User Approvals Comments** (23, `note`, optional): Enter any additional comments from the teacher requesting user.
* **Teacher Requesting User Comments** (24, `note`, optional): Enter any additional comments from the teacher requesting user.
* **Course Substitution Approvals** (25, `select_multiple`, optional): Select Yes or No to indicate whether the course substitution approvals are valid.
