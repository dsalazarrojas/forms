# Teacher Request Form - Help Guide
## Purpose
This form is used to submit requests for assistance or support from teachers. Please fill out the form carefully to ensure your request is processed efficiently.

## How To Complete This Form

To complete this form, please follow these steps:

1. Enter your teacher's name accurately.
2. Provide your email address for communication.
3. Select the type of support you need (e.g., online tutoring, on-site tutoring, phone or Skype call).
4. Choose the days you prefer for the support session (e.g., Monday, Tuesday, Wednesday, etc.).
5. Select the start and end times for the support session.
6. Specify the duration of the support session (in minutes).
7. If applicable, enter the location where the on-site support will take place.

## Field-by-Field Explanation

* **Teacher Name (`teacher_name`, text, required):** Enter the name of the teacher requesting support. Please ensure the name is accurate and up-to-date.
* **Student Email (`email`, email, required):** Enter the teacher's email address where we can contact them for communication.
* **Request Type (`request_type`, select_one, required):** Select the type of support the teacher is requesting. Please choose from the provided options: Online Tutoring, On-Site Tutoring, Phone/Skype Call.
* **Preferred Days (`preferred_days`, select_multiple, required):** Choose the days of the week when the teacher is available for the support session. Select one or more days from the provided options: Monday, Tuesday, Wednesday, Thursday, Friday, Saturday, Sunday.
* **Start Time (`start_time`, time, required):** Enter the start time of the support session. Please use the 24-hour clock format (e.g., 14:00 for 2:00 PM).
* **End Time (`end_time`, time, required):** Enter the end time of the support session. Please use the 24-hour clock format (e.g., 16:00 for 4:00 PM).
* **Duration (`duration`, number, required):** Specify the length of time the support session will last (in minutes).
* **Location (`location`, text, required):** Enter the location where the on-site support will take place (if applicable). 

## Tips

* If you're unsure about any field, please reach out to our support team for guidance.
* Please submit one request per form. If you have multiple requests, please submit separate forms for each request.
* We appreciate your attention to detail and accuracy when filling out this form to ensure efficient processing of your request.
