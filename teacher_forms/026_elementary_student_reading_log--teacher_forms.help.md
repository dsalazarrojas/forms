# elementary_student_reading_log - Help Guide

## Purpose
The elementary_student_reading_log form is used to collect data on students' reading habits, specifically whether they have read a particular book or not. This form is designed to be completed by students or their parents/guardians.

## How To Complete This Form

To complete this form, please follow these steps:

1. Select the relevant answer for the question "reading_log" from the dropdown menu.
2. Enter the student's name in the field "student_name".
3. Enter the grade level of the student (if applicable) in the field "grade".
4. Select the date of the reading log entry in the field "date".

## Field-by-Field Explanation

* **reading_log**: 
	+ A multiple-choice question that asks if the student has read the book or not.
	+ Select "Yes" if the student has read the book, or "No" otherwise.
* **student_name**: 
	+ The name of the student who completed this reading log entry.
* **grade**: 
	+ The grade level of the student (e.g. 3rd, 4th, 5th, etc.).
* **date**: 
	+ The date on which the reading log entry was made.

## Tips

* Please ensure that you have answered the question in the "reading_log" field truthfully.
* Make sure to enter the student's name correctly in the "student_name" field.
* The "grade" field is optional and should only be filled out if the student has a specific grade level.
* The "date" field should be filled out for each reading log entry.
