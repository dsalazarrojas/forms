# Student Incident Report Form - Help Guide
## Purpose
The Student Incident Report Form is a tool for teachers to report incidents involving students, allowing administrators to track and address issues promptly.

## How To Complete This Form
To complete this form, follow these steps:

1. Answer the question about the student's involvement in the incident.
2. Choose the teacher's reaction to the incident.
3. Provide additional details about the incident, including the date and time it occurred.
4. Enter the student's name and contact information, if applicable.
5. Add any additional comments or comments about the incident.

## Field-by-Field Explanation

* **Student Involvement** (`student_involvement`, text, required/optional)
	+ Explain the student's level of involvement in the incident. This field is not always required.
* **Teacher Reaction** (`teacher_reaction`, select_one, required/optional)
	+ Choose the teacher's reaction to the incident using the options "Very Good", "Somewhat Good", or "Not So Good".
* **Student Involvement 2** (`student_involvement_2`, select_multiple, required/optional)
	+ Choose all that apply from "Yes" or "No" regarding the student's level of involvement in the incident.
* **Teacher Reaction 2** (`teacher_reaction_2`, select_one, required/optional)
	+ Choose the teacher's reaction to the incident using the options "Very Good", "Somewhat Good", or "Not So Good".
* **Student Involvement 3** (`student_involvement_2`, select_multiple, required/optional)
	+ Choose all that apply from "Yes" or "No" regarding the student's level of involvement in the incident.
* **Teacher Reaction 3** (`teacher_reaction_2`, select_one, required/optional)
	+ Choose the teacher's reaction to the incident using the options "Yes" or "No".
* **Incident Description** (`incident_description`, text, required/optional)
	+ Provide a detailed description of the incident, including what happened and any relevant details.
* **Incident Date** (`incident_date`, date, required/optional)
	+ Enter the date and time of the incident, using the date format (e.g., MM/DD/YYYY).
* **Incident Time** (`incident_time`, time, required/optional)
	+ Enter the time of the incident.
* **Student Name** (`student_name`, text, required/optional)
	+ Enter the student's name involved in the incident.
* **Student Email** (`student_email`, email, required/optional)
	+ Enter the student's email address, if applicable.
* **Student Phone** (`student_phone`, text, required/optional)
	+ Enter the student's phone number, if applicable.
* **Teacher Signature** (`teacher_signature`, note, required/optional)
	+ Please sign here to indicate that you have completed this report.
* **Student Signature** (`student_signature`, note, required/optional)
	+ Please sign here to confirm that you have reported this incident.
* **Teacher Comments** (`teacher_comments`, text, required/optional)
	+ Add any additional comments or feedback about the incident.
* **Student Comments** (`student_comments`, text, required/optional)
	+ Add any additional comments or feedback from the student involved.

Note: Some fields are optional, but are required for the form to be completed. The fields with the label "Please Sign Here" require a signature from the student or teacher, respectively.
