# Physical Education Fitness Log Form - Help Guide
## Purpose
The Physical Education Fitness Log Form is used by students to report their exercises completed, sets and reps done, and any additional comments from their teacher during a physical education class. This form is essential for tracking student progress and evaluating their performance.

## How To Complete This Form
1. Please enter your **student name** in the first field. This is required information and must be filled in for the form to be valid.
2. Fill in the **date** of the class or physical activity you are reporting on. This is also required.
3. In the **exercises completed** field, select all the exercises you completed during class. You can choose multiple options.
4. For each exercise selected, enter the number of **sets completed** and **reps completed**. For example, if you did 3 sets of 10 reps, enter 3 for sets and 10 for reps.
5. If you have any additional comments or feedback for your teacher, you can enter them in the **additional comments** field. This is optional.
6. Leave the **assigned by** field blank as it is not required.
7. Finally, fill in the **version** field with the current version number of the form. This is also optional.

## Field-by-Field Explanation

* **student_name (student_name)**: This is the student's name, and it is a required field.
	+ Type: text
	+ Required: true
* **date**: This field represents the date of the class or physical activity being reported on.
	+ Type: date
	+ Required: true
* **exercises_completed (exercise_completed)**: Select all exercises completed during the class.
	+ Type: select_multiple
	+ Required: true
* **sets_completed (sets_completed)**: Enter the number of sets completed for each exercise selected.
	+ Type: number
	+ Required: true
* **reps_completed (reps_completed)**: Enter the number of reps completed for each exercise selected.
	+ Type: number
	+ Required: true
* **notes (notes)**: This is an optional field for any additional comments or feedback.
	+ Type: text
	+ Required: false
* **teacher_comments (teacher_comments)**: This is an optional field for any comments from the teacher.
	+ Type: text
	+ Required: false
* **assigned_by (physical_education_fitness_log_form_assigned_by)**: This field is not required and should be left blank.
	+ Type: text
	+ Required: false
* **additional_comments (teacher_comments_2)**: This is an optional field for any additional comments from the teacher.
	+ Type: text
	+ Required: false
* **version (physical_education_fitness_log_form_version)**: This field is optional and should be left blank.
	+ Type: text
	+ Required: false

## Tips

* Make sure to select all exercises completed during the class.
* Enter accurate information for sets and reps completed to ensure accurate progress tracking.
* If you have any additional comments or feedback, use the **additional comments** field.
* If you have any further comments or feedback, use the **notes** field.
