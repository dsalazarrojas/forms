# Montessori School Class Enhancement Form - Help Guide
## Purpose
This form is used by teachers to provide feedback from parents, comments from teachers, and action plans for a specific class that has received feedback.

## How To Complete This Form

### Step 1: Select the teacher who completed this form
Fill in the `submitted_by` field with the name of the teacher who is submitting this form.

### Step 2: Fill in the class details
- Enter the `class_name` of the class this form is for.
- Enter the `class_id` of the class this form is for.
- Select the `category` of the class (Yes/No).
- Select the `submitted_to` field with the department this form is being submitted to.

### Step 3: Select the staff members assigned to the class
Select the staff members who will be assigned to this class from the `assigned_to` field.

### Step 4: Provide feedback from parents
- Enter the `feedback` field with the feedback from parents.
- Enter the `parent_comments` field with any comments from parents.

### Step 5: Provide comments from teachers
Enter the `teacher_comments` field with any comments from the teacher.

### Step 6: Create an action plan for the class
Enter the `action_plans` field with any action plans for the class.

### Step 7: Enter date and time submitted
- Enter the `date_submitted` field with the date this form was submitted.
- Enter the `submitted_by_department` field with the department that submitted this form.

### Step 8: Additional information
- Enter the `submitted_to_department` field with the department this form was submitted to.
- Enter the `submitted_to_division` field with the division this form was submitted to.
- Enter the `submitted_to_location` field with the location this form was submitted from.
- Enter the `submitted_to_team` field with the team this form was submitted to.
- Enter the `submitted_to_level` field with the level this form was submitted to.
- Enter the `submitted_to_status` field with the status this form was submitted as (Active/Inactive).
- Select the `submitted_to_priority` field with the priority of this form (Yes/No).
- Select the `submitted_to_type` field with the type of submission (Yes/No).
- Enter the `submitted_to_user` field with the user who received this form.

## Field-by-Field Explanation

* **submitted_by** (teacher_name, required): Enter the name of the teacher who completed this form.
* **class_name** (class_name, required): Enter the name of the class this form is for.
* **class_id** (class_id, required): Enter the ID of the class this form is for.
* **category** (category, required): Select Yes if this class received feedback, otherwise select No.
* **assigned_to** (assigned_to, optional): Select the staff members who will be assigned to this class.
* **feedback** (feedback, required): Enter the feedback from parents.
* **parent_comments** (parent_comments, required): Enter any comments from parents.
* **teacher_comments** (teacher_comments, required): Enter any comments from the teacher.
* **action_plans** (action_plans, required): Enter any action plans for the class.
* **date_submitted** (date_submitted, required): Enter the date this form was submitted.
* **submitted_by_department** (submitted_by_department, required): Enter the department that submitted this form.
* **submitted_to_department** (submitted_to_department, required): Enter the department this form was submitted to.
* **submitted_to_division** (submitted_to_division, required): Enter the division this form was submitted to.
* **submitted_to_location** (submitted_to_location, required): Enter the location this form was submitted from.
* **submitted_to_team** (submitted_to_team, required): Enter the team this form was submitted to.
* **submitted_to_level** (submitted_to_level, required): Enter the level this form was submitted to.
* **submitted_to_status** (submitted_to_status, required): Select Active if this form is active, otherwise select Inactive.
* **submitted_to_priority** (submitted_to_priority, required): Select Yes if this form has high priority, otherwise select No.
* **submitted_to_type** (submitted_to_type, required): Select Yes if this form is a new submission, otherwise select No.
* **submitted_to_user** (submitted_to_user, required): Enter the user who received this form.
* **notes** (notes, required): Enter any additional notes about this submission.

## Tips

* Make sure to fill out all required fields.
* Double-check the date and time submitted.
* Enter any additional comments or notes as needed.
* Review this guide if you have any questions or need clarification on any field.
