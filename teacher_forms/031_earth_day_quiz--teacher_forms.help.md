# Earth Day Quiz - Help Guide
## Purpose
This form is designed to collect user responses and feedback on various aspects related to Earth Day, a global event celebrating environmental awareness and conservation.

## How To Complete This Form
1. Start by filling out all the required fields. If a field is not marked as required, you can leave it blank.
2. For fields with options, choose one or multiple responses as per the instructions.

## Field-by-Field Explanation
* **What is your name?** (`earth_day_quiz_name`, text, optional): This field is for you to provide your name so that we can address you correctly.
* **Email Address** (`earth_day_quiz_email`, email, optional): Enter your email address to ensure we can contact you with any updates or further information.
* **Phone Number** (`earth_day_quiz_phone`, text, optional): Provide your phone number to enable us to reach out to you if needed.
* **Date** (`earth_day_quiz_date`, date, optional): Select the date you are taking the quiz for, if different from the current date.
* **Time** (`earth_day_quiz_time`, time, optional): Select the time you are taking the quiz for, if different from the current time.
* **Note** (`earth_day_quiz_note`, note, optional): Enter any additional comments or notes you'd like to share.
* **Select One** (`earth_day_quiz_select_one`, select_one, optional): Choose one of the provided options that best represents your preference.
* **Select Multiple** (`earth_day_quiz_select_multiple`, select_multiple, optional): Select one or multiple options from the provided list.
* **Decimal** (`earth_day_quiz_decimal`, number, optional): Enter a numerical value to complete this field.

## Tips
* Ensure that all fields are filled correctly to provide accurate responses.
* If you have any questions or concerns, please don't hesitate to contact us.
* If you are unsure about any field, please leave it blank or consult the provided instructions.
