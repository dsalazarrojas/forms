# school_media_release_form - Help Guide

## Purpose

The "school_media_release_form" form is designed to collect information from parents about their child's media usage, including their name, image, and audio use in school settings. This form is crucial for schools to obtain the necessary permissions and consent from parents before using their child's media.

## How To Complete This Form

To complete this form, follow these steps:

1. **Enter Parent Details**: Fill in the "Parent Details" field with the parent's name and any other relevant information.
2. **Enter Student Name**: Type in the student's name in the "Student Name" field.
3. **Choose Student Image Use**: Select the intended use of the student's image from the options provided in the "Student Image Use" field.
4. **Choose Student Audio Use**: Select the intended use of the student's audio from the options provided in the "Student Audio Use" field.
5. **Obtain Parent Signature**: Sign the "Parent Signature" field to confirm the parent's consent.
6. **Choose School Use**: Select the purpose for which the school will use the student's media from the options provided in the "School Use" field.

## Field-by-Field Explanation

- **Parent Details**: Enter the parent's name and any other relevant details.
  * **Type:** Text field
  * **Required:** No

- **Student Name**: Enter the student's name who is associated with the media.
  * **Type:** Text field
  * **Required:** No

- **Student Image Use**: Choose the intended use of the student's image.
  * **Type:** Select multiple option field
  * **Required:** No

  Options: 
  + option 1: For school ID cards
  + option 2: For school events
  + option 3: For other purposes ( specify below )

- **Student Audio Use**: Choose the intended use of the student's audio.
  * **Type:** Select multiple option field
  * **Required:** No

  Options: 
  + option 1: For announcements
  + option 2: For other purposes ( specify below )

- **Parent Signature**: Obtain the parent's signature as a confirmation of consent.
  * **Type:** Note field
  * **Required:** No

- **School Use**: Choose the purpose for which the school will use the student's media.
  * **Type:** Select multiple option field
  * **Required:** No

  Options: 
  + option 1: For marketing purposes
  + option 2: For educational purposes ( specify below )
  + option 3: For other purposes ( specify below )

## Tips

* Be sure to enter the parent's name and any other relevant details accurately to ensure the form is completed correctly.
* Choose the most suitable options for the intended use of the student's media.
* Obtain the parent's signature to confirm their consent before submitting the form.
