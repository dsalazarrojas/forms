# Speech Evaluation Form - Help Guide
## Purpose
The Speech Evaluation Form is a tool used by teachers to assess their students' communication skills in a speech evaluation context.

## How To Complete This Form
To complete the Speech Evaluation Form, follow these steps:

1. Start by filling out the **Teachers Information** section with your name and any other relevant details.
2. In the **Students Information** section, enter the student's name and any other relevant information about the student.
3. Answer the question **How effective is the student at communicating with others?** using the provided scale: Very good, Good, Average, or Poor.
4. Select all relevant communication skills used by the student from the list **What communication skills is this student using?**, which may include Verbal, Nonverbal, or Both.
5. Add any additional comments about the student's performance in the **Additional comments** section.
6. Finally, enter the date and time of the evaluation in the **Date** and **Time** fields, respectively.

## Field-by-Field Explanation
* **Teachers Information**: Enter your name and any other relevant details.
* **Students Information**: Enter the student's name and any other relevant information about the student.
* **How effective is the student at communicating with others?**: Use the provided scale to rate the student's communication skills: Very good, Good, Average, or Poor.
* **What communication skills is this student using?**: Select all relevant communication skills used by the student, which may include Verbal, Nonverbal, or Both.
* **Additional comments**: Add any additional comments about the student's performance.
* **Date**: Enter the date of the evaluation.
* **Time**: Enter the time of the evaluation.
* **Form submitted successfully**: This field is not editable and indicates that the form has been successfully submitted.
