# Progress Monitoring Form - Help Guide
## Purpose
The Progress Monitoring Form is designed to collect essential information about a student's project, including project title, teacher and student information, progress status, and final evaluation.

## How To Complete This Form
To complete this form, follow these steps:
1. Fill in the project title.
2. Provide teacher and student information.
3. Enter the date of the project's progress.
4. Select the current project status (New, In Progress, On Hold, or Completed).
5. Enter any progress notes.
6. Enter any teacher notes.
7. Describe the project goals.
8. Describe the project outcomes.
9. Describe any project obstacles.
10. Enter teacher comments.
11. Enter student comments.
12. Describe project goals achieved.
13. Describe project outcomes met.
14. Describe project obstacles overcome.
15. Outline the next steps.
16. Write a final project evaluation.
