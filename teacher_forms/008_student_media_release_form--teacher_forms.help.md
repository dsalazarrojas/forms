# Student Media Release Form - Help Guide
## Purpose
The Student Media Release Form is a document that collects student information and consent for media releases, including photo, video, and audio permissions. It helps schools or organizations obtain parental or guardian consent for students to participate in media activities.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill in the student's information, including their name, school name, address, and any other relevant details.
2. Select the types of media to which you consent (e.g., photo, video, audio).
3. Choose the channels where the media will be published (e.g., social media, website, print media).
4. Specify the purpose of the media release (e.g., for promotional purposes, educational purposes).
5. Indicate whether you consent to the student's photo, video, and audio use.
6. Select the schools or organizations that should have access to the student's media (e.g., parent, guardian, school administrators).
7. Provide contact information for further inquiries.
8. Set the date for the consent.

## Field-by-Field Explanation

* **Student Information** (student_name): Enter the student's name as they are registered in the school.
* **Media Types** (media_types): Select the types of media to which you consent, such as "Yes" for photo, video, or audio.
* **Permission** (permission): Enter a brief description of the media release, e.g., "for photo, video, or audio purposes."
* **Publication Channels** (publication_channels): Select the channels where the media will be published, such as social media, website, or print media.
* **Publication Purpose** (publication_purpose): Specify the reason for the media release, e.g., for promotional purposes, educational purposes.
* **Photo/Video/Audio** (photo_video_audio): Indicate whether you consent to the student's photo, video, or audio use.
* **Other Media** (other_media): Select other types of media to which you consent, if any.
* **Parent/Guardian Permission** (parent_permission): Select the parent or guardian that has provided consent.
* **School Permission** (school_permission): Select the school or organization that has permission to use the student's media.
* **Contact Information** (contact_info): Provide the parent's contact information for further inquiries.
* **Date** (date): Set the date for the consent.
* **School Information** (school_name, school_address, student_school_id): Enter the school's name, address, and student ID for the student.
* **Consent** (parent_permission, school_permission): Confirm the consent for the media release.
