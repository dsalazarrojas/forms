# multiple_intelligence_survey - Help Guide
## Purpose
This form aims to evaluate an individual's multiple intelligences, including their cognitive, social, spatial, linguistic, logical-mathematical, bodily-kinesthetic, musical, interpersonal, intra-personal, and naturalistic intelligences. 

## How To Complete This Form
To complete this form, follow these steps:
1. Read the intro page carefully.
2. For the 'Multiple Intelligence' question, select the types that best apply to you.
3. If you selected 'Other' for 'Multiple Intelligence', provide a brief description in the 'Intelligence Type Other' field.
4. Select the types of surveys you are interested in taking in the 'Survey Type' question.
5. If you selected 'Other' for 'Survey Type', provide a brief description in the 'Survey Type Other Desc' field.
6. Provide any additional descriptions or notes for 'Intelligence Type Other Desc'.

## Field-by-Field Explanation
* **Multiple Intelligence** (`multiple_intelligence`, text, required): 
	+ Select all the multiple intelligences that apply to you from the available options.
	+ These options include 'Cognitive', 'Social', 'Spatial', 'Linguistic', 'Logical-Mathematical', 'Bodily-Kinesthetic', 'Musical', 'Interpersonal', 'Intrapersonal', and 'Naturalistic'.
