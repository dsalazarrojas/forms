# Weekly Class Evaluation Form - Help Guide
## Purpose
This form is designed to help teachers understand students' progress, what they have learned, and what challenges they faced in a weekly class session.

## How To Complete This Form
1.  On page 1, enter a brief title for your class evaluation.
2.  On pages 2-4, answer the questions on Class Evaluation Question 1, 2, and 3.
3.  On page 5, answer the questions on Class Evaluation Question 2.
4.  Add any additional comments on the Additional Comments field.

## Field-by-Field Explanation

*   **Page 1 (Weekly Class Evaluation Form)**: Input a brief title for your class evaluation.
*   **Class Evaluation Question 1** (What did you learn this week?):
    *   Answer this question to share what you learned in the class this week.
*   **Class Evaluation Question 2** (What was the most interesting thing you learned this week?):
    *   Share the most interesting thing you learned in the class this week.
*   **Class Evaluation Question 3** (What was the biggest challenge you faced this week?):
    *   Share the biggest challenge you faced in the class this week.
*   **Class Evaluation Question 4** (What do you plan to work on next week?):
    *   Share what you plan to work on next week.
*   **Class Evaluation Question 5** (What did you enjoy most about this week?):
    *   Share what you enjoyed most about this week's class material.
*   **Class Evaluation Question 6** (What was the most challenging part of the lesson?):
    *   Share the most challenging part of the lesson.
*   **Class Evaluation Question 7** (Is there anything you would like to discuss or need help with?):
    *   Share anything you would like to discuss or need help with.
*   **Class Evaluation Question 8** (What did you learn this week that was new to you?):
    *   Share what you learned this week that was new to you.
*   **Class Evaluation Question 9** (Is there anything you would like to add or discuss?):
    *   Share anything you would like to add or discuss.
*   **Additional Comments**: Add any additional comments about your progress and needs.
*   **Additional Comments**: This field is for any additional comments or thoughts you have about your progress and needs.
