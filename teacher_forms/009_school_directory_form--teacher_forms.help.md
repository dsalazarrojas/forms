# School Directory Form - Help Guide

## Purpose
This form is used to collect and organize data about students in the school directory. It captures essential information such as name, contact details, student grade level, and other relevant data points. This form helps to create and manage a comprehensive directory of students, making it easier for teachers to access and use the information for various school activities and events.

## How To Complete This Form
1. Fill in the required fields:
	* First Name
	* Last Name
	* Email
	* Phone
	* Student ID
	* School
	* Student Grade
	* Teacher Name
	* Teacher Subject
	* Student Name
	* Student Grade Level (select one or multiple options)
	* Student Birthdate
	* Parent Name
	* Parent Email
2. If applicable, select a School and Student Grade options that match the student's information.
3. Enter relevant details in the text fields for Teacher Subject and Classroom Name.
4. If you want to provide additional information about the student's grade level, use the Student Grade Level Other field.

## Field-by-Field Explanation
* **First Name**: Enter the student's first name.
* **Last Name**: Enter the student's last name.
* **Email**: Enter the student's email address.
* **Phone**: Enter the student's phone number.
* **Student ID**: Enter the student's ID number.
* **School**: Select the type of school the student attends (Elementary, High School, or Both).
* **Student Grade**: Indicate whether the student is in a high or low grade level.
* **Student Grade Level Other**: Provide any additional information about the student's grade level if not listed under High or Low.
* **Student Name**: Enter the student's name (this should match with the First Name and Last Name fields).
* **Student Birthdate**: Enter the student's birthdate in the standard date format (YYYY-MM-DD).
* **Parent Name**: Enter the parent's name.
* **Parent Email**: Enter the parent's email address.
* **Teacher Name**: Enter the teacher's name who is associated with the student.
* **Teacher Subject**: Enter the subject taught by the teacher.
* **Classroom Name**: Enter the name of the classroom where the student is located (this is optional).
* **Student Grade Level**: Select all applicable grade levels for the student (High, Low).

Note: Make sure to fill in all required fields and provide accurate information to ensure accurate directory entry.
