# Preschool Teacher Performance Evaluation Form - Help Guide
## Purpose
The Preschool Teacher Performance Evaluation Form is designed to gather information from the school administration to assess a preschool teacher's performance. The form is used to evaluate the teacher's overall performance, provide feedback, and gather comments and student feedback.

## How To Complete This Form
To complete this form, follow these steps:

1. Review the form pages and make sure you understand each section.
2. Fill out the General Information page with the teacher's details such as name, email, and phone number.
3. On the Teacher Evaluation page, choose the appropriate option that best describes the teacher's performance.
4. In the Comments page, provide any additional feedback or comments you have for the teacher.
5. In the Student Feedback page, select the option that best describes the feedback from students.
6. In the Teacher Feedback page, choose the option that best describes the feedback from the teacher.
7. In the Comments page, provide any additional comments or feedback.
8. Fill out the Email, Phone, Date, and Time pages with the relevant information.
9. Finally, fill out the Submitted By page with your name and any additional comments.

## Field-by-Field Explanation
- **General Information** (General Information, text, required/optional): This page is used to gather the teacher's general information such as name, email, and phone number. Please provide the teacher's name, email, and phone number to help the evaluator assess their performance.
- **Teacher Evaluation** (Teacher Evaluation, select multiple, required/optional): This page is used to evaluate the teacher's performance. Please choose the options that best describe the teacher's performance.
- **Comments** (Comments, text, required/optional): This page is used to provide any additional feedback or comments about the teacher.
- **Student Feedback** (Student Feedback, select one, required/optional): This page is used to gather feedback from students. Please select the option that best describes the feedback from students.
- **Teacher Feedback** (Teacher Feedback, select multiple, required/optional): This page is used to gather feedback from the teacher. Please select the option that best describes the teacher's feedback.
- **Comments** (Comments, text, required/optional): This page is used to provide any additional feedback or comments about the teacher.
- **Email** (Email, email, required/optional): This page is used to provide the teacher's email address.
- **Phone** (Phone, text, required/optional): This page is used to provide the teacher's phone number.
- **Date** (Date, date, required/optional): This page is used to select the date of the evaluation.
- **Time** (Time, time, required/optional): This page is used to select the time of the evaluation.
- **Submitted by** (Submitted by, text, required/optional): This page is used to provide the name of the person submitting the evaluation.

## Tips
- Please ensure that all required fields are filled out before submitting the form.
- Please be honest and thorough in your feedback and comments.
- Please select the options that best describe the teacher's performance and feedback.
- If you have any additional comments or feedback, please provide them in the Comments page.
