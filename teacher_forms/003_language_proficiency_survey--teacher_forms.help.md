# Language Proficiency Survey - Help Guide
## Purpose

This form is designed to help you assess your language proficiency in various aspects of language usage.

## How To Complete This Form

To complete this form, please follow these steps:

1. Read each question carefully and answer honestly.
2. Select the relevant options for each question.
3. Make sure to answer all questions, even if they seem similar.
4. Review your answers before submitting the form.

* **Introduction** (`1`, `note`, required: `false`): This is a note field where you can provide any additional information about your language proficiency.
