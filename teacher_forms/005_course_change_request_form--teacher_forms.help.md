# Course Change Request Form - Help Guide
## Purpose

The Course Change Request Form is designed to be a straightforward way for instructors to request changes to their courses. This includes making changes to existing courses or creating new courses entirely. Fill out this form to notify the relevant parties of any changes you'd like to make to your course.

## How To Complete This Form

1. Fill out the form completely and accurately, including any relevant information in the fields provided.
2. Ensure that all required fields are filled out.
3. Review the form carefully before submitting it.

## Field-by-Field Explanation

* **Course Title** (`2`, `text`, required): This field is used to identify the course you are making changes to.
* **Reason For Change** (`3`, `text`, optional): Explain why you are requesting this change. Be specific about the reason for the change.
* **New Course Request** (`4`, `text`, optional): If you are requesting a new course, enter a description of the new course here.
* **New Course Title** (`5`, `text`, optional): If you are requesting a new course, enter the new course title here.
* **New Course Number** (`6`, `text`, optional): If you are requesting a new course, enter the new course number here.
* **Instructor Request** (`7`, `text`, optional): If you have specific requests for the instructor, enter them here.
* **Instructor Request Date** (`8`, `date`, optional): If you have a specific date for the requested change, enter it here.
* **Submitted To** (`9`, `text`, optional): Indicate who the changes will be submitted to (e.g. department chair, director, etc.).
* **Submitted By** (`10`, `text`, optional): Enter your name or username to confirm who is submitting this request.
* **Instructor Response** (`11`, `text`, optional): Use this field to provide any additional comments or responses to the change request.
