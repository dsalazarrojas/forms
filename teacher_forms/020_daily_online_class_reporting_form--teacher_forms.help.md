# Daily Online Class Reporting Form - Help Guide
## Purpose
The "Daily Online Class Reporting Form" is a tool used by teachers to report on their daily activities and interactions with students in online classes. This form helps to gather valuable information and insights that support data-driven decision making and improve teaching and learning outcomes.

## How To Complete This Form
### Step 1: Log in to your account and access the form
To access the form, you should log in to your account and navigate to the designated page with the form.

### Step 2: Select your Category
Select the category that best describes the type of class being reported (Teacher Forms, Other, Unknown, Unspecified)

### Step 3: Fill out all required fields
Ensure that you fill out all fields marked as "required". These fields are:

*   `teacher-id`
*   `teacher-answers`
*   `student-answers`
*   `teacher-feedback`
*   `assigned-tool`
*   `student-feedback`
*   `category`

### Step 4: Provide detailed responses
For fields marked as "text", please provide detailed and clear responses.

### Step 5: Submit the form
Once you have completed all required fields, click the "Submit" button to save your report.

## Field-by-Field Explanation
*   **Teacher ID**: (`teacher-id`, number, required) - Enter your teacher ID number.
*   **Teacher Answers**: (`teacher-answers`, text, required) - Please answer the following questions.
*   **Student Answers**: (`student-answers`, text, required) - Please enter the answers provided by the students.
*   **Teacher Feedback**: (`teacher-feedback`, text, required) - Please provide feedback on the class.
*   **Assigned Tool**: (`assigned-tool`, text, required) - Please enter the tool assigned to the class.
*   **Student Feedback**: (`student-feedback`, text, required) - Please provide feedback from students.
*   **Category**: (`category`, select_one, required) - Select the category that best describes the type of class.
