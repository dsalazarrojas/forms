# Student Program Feedback Form - Help Guide
## Purpose
The Student Program Feedback Form is designed to collect feedback from students on their experience with the program. This form helps teachers and program administrators to assess student satisfaction and identify areas for improvement.

## How To Complete This Form
1. Click on the 'Next' button to move through the pages and provide your feedback.
2. For each field, please provide as much detail as possible to help us understand your experience.
3. If a field is marked as optional, feel free to skip it if you don't have the information.

## Field-by-Field Explanation
* **Student Program**: Please describe your experience with the program. This is where you can share your thoughts and opinions about the program. (Student Program: `Student Program`)
* **Category**: Please select the category of the program you participated in. (Category: `Program 1`, `Program 2`, `Program 3`)
* **Comments**: If you have any additional comments or suggestions, please provide them here. (Comments: `text`)
* **Email**: Please provide your email address so we can contact you if we need more information. (Email: `email`)
* **Phone**: Please provide your phone number so we can contact you if we need to discuss further. (Phone: `text`)
* **Date**: If you have a preferred date for the program, please provide it here. (Date: `date`)
* **Time**: If you have a preferred time for the program, please provide it here. (Time: `time`)
* **Program ID**: Please provide the program ID number if you know it. (Program ID: `number`)

## Tips
* Please be as detailed as possible when providing feedback.
* If you are unsure about any field, feel free to ask for clarification.
* Please complete the form once, as duplicate submissions may cause confusion and skew the data.
