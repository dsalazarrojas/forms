# Curriculum Planning Form - Help Guide
## Purpose
The curriculum planning form is a tool designed to aid teachers in planning their classes and curriculum for a specific period.

## How To Complete This Form
To complete this form, follow these steps:

* Select the relevant subjects for the classes.
* Enter the total number of classes to be planned.
* Add a name for each class.
* Choose the period when each class will take place.
* Select the person assigned to each class.
* Specify the specific dates for each class period.
* Choose whether the classes will be held indoors or outdoors.
* Select the time of day or night for the classes.
* Add any additional comments or remarks about the classes.
* If necessary, mention any specific resources that will be used in the classes.

## Field-by-Field Explanation
* **What are the subjects to be taught?** (`subject_areas`, Select Multiple): Select the relevant subjects for the classes you are planning.
* **How many classes are to be planned?** (`total_classes`, Number): Enter the total number of classes you are planning.
* **What is the class name?** (`class_names`, Text): Add a name for each class.
* **What is the period for each class?** (`subject_periods`, Select One): Choose the period when each class will take place.
* **To whom will the classes be assigned?** (`assigned_user`, Select One): Select the person assigned to each class.
* **What are the specific dates of each period?** (`dates`, Date): Specify the specific dates for each class period.
* **Will the classes be held indoors or outdoors?** (`venue`, Select One): Choose whether the classes will be held indoors or outdoors.
* **Will the classes be conducted during the day or at night?** (`time`, Time): Select the time of day or night for the classes.
* **Any comments or remarks about the classes?** (`teacher_comments`, Text): Add any additional comments or remarks about the classes.
* **Any specific resources to be used in the classes?** (`resources`, Text): If necessary, mention any specific resources that will be used in the classes.
