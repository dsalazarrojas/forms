# Matching Features Practice Task Form - Help Guide
## Purpose
The Matching Features Practice Task Form is a tool used by teachers to help students match features between two teams.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the feature you want to match from the "select_feature" field.
2. Choose the task you want to match with the selected feature from the "select_task" field.
3. Select the team member you want to assign the task to from the "team_member" field.
4. If necessary, add any matches from the "match" field.
5. Input the date and start time of the task in the "date" and "start_time" fields.
6. Enter the duration of the task in the "duration" field.
7. Select the status of the task from the "status" field.
8. Optionally, enter additional information in the "notes" field.
9. Enter any comments regarding the task in the "comments" field.
10. Enter the email and phone number of the assigned user in the "email" and "phone" fields.

## Field-by-Field Explanation
- **Select Feature** (`select_feature`, select_one, required: false): Select the feature you want to match.
- **Select Task** (`select_task`, select_one, required: false): Choose the task you want to match with the selected feature.
- **Team Member** (`team_member`, text, required: false): Enter the team member you want to assign the task to.
- **Match** (`match`, select_multiple, required: false): Select any matches you have found.
- **Date** (`date`, date, required: false): Input the date of the task.
- **Start Time** (`start_time`, time, required: false): Enter the start time of the task.
- **End Time** (`end_time`, time, required: false): Enter the end time of the task.
- **Duration** (`duration`, number, required: false): Enter the duration of the task.
- **Status** (`status`, select_one, required: false): Select the status of the task.
- **Assigned User** (`assigned_user`, text, required: false): Enter the email of the assigned user.
- **Assigned Tool** (`assigned_tool`, text, required: false): Enter the assigned tool.
- **Notes** (`notes`, note, required: false): Add any additional information regarding the task.
- **Comments** (`comments`, text, required: false): Enter any comments about the task.
- **Email** (`email`, email, required: false): Enter the email of the assigned user.
- **Phone** (`phone`, text, required: false): Enter the phone number of the assigned user.
