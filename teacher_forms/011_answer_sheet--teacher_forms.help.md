# Answer Sheet - Help Guide
## Purpose
The Answer Sheet form is designed to help teachers create a document with answers to a set of questions for their students. It is a tool for assessments and evaluations.

## How To Complete This Form
1. Fill in the student's name in the "Student name" field. Enter their full name as listed on the school roster.
2. If applicable, fill in the student's ID number in the "Student id number" field.
3. Enter the class name or code in the "Class name or code" field.
4. Select the type of answer sheet (Multiple choice, Short answer, or Mixed) in the "Answer sheet type" field.
5. Enter the total number of questions in the "Total number of questions" field.
6. Choose a date for the assessment in the "Test date" field.
7. (Optional) Add any teacher comments in the "Teacher comments" field.

## Field-by-Field Explanation

* **Student name** (`student_name`, required): Enter the full name of the student as listed on the school roster.
* **Student id number** (`student_id`, optional): If applicable, enter the student's ID number for reference.
* **Class name or code** (`class_name`, optional): Enter the name or code of the class where the assessment took place.
* **Answer sheet type** (`answer_sheet_type`, required): Select the type of answer sheet (Multiple choice, Short answer, or Mixed).
* **Test date** (`test_date`, required): Choose a date for the assessment.
* **Total number of questions** (`total_questions`, required): Enter the total number of questions in the assessment.
* **Teacher comments** (`teacher_comments`, optional): Add any optional comments from the teacher.

## Tips
* Ensure that all required fields are completed.
* Double-check that the "Answer sheet type" field matches the type of questions on the assessment.
* Use the "Teacher comments" field for any additional information the teacher wants to provide to the student.
