# online_class_assignment_upload_form - Help Guide
## Purpose
This form is designed for teachers to upload and manage assignments for their classes. It allows them to input information about their forms, such as names and comments, and track the submission status of assignments.

## How To Complete This Form
1. **Upload File**: Select a file related to the assignment from your computer or cloud storage.
2. **Assignment Name**: Input the name of the assignment.
3. **Due Date**: Set the due date for the assignment.
4. **Teacher Comments**: Input comments about the assignment.
5. **Student Comments**: Input comments from students about the assignment.
6. **Submission Status**: Select the submission status of the assignment (Not Yet Started, Completed, or In Progress).
7. **Assigned Tool**: Select the tool assigned to the assignment (Google Drive, OneDrive, or Dropbox).
8. **File Type**: Select the type of file uploaded (pdf, docx, jpg, png, or zip).
9. **Class Name**: Input the name of the class.
10. **Label Fields**: For each field, input a label that describes the field.

## Field-by-Field Explanation

* **Teacher Form**: Input your name or role as a teacher.
* **Upload File**: Upload a file related to the assignment, such as a PDF or document.
* **Assignment Name**: Input the name of the assignment, such as "Math Homework" or "Science Project".
* **Due Date**: Set the due date for the assignment, such as "Monday, February 13, 2023".
* **Teacher Comments**: Input comments about the assignment, such as "This is a challenging project. Please complete it by the due date."
* **Student Comments**: Input comments from students about the assignment, such as "I completed the project. Please let me know if it is correct."
* **Submission Status**: Select the submission status of the assignment:
	+ **Not Yet Started**: The assignment has not been started.
	+ **Completed**: The assignment has been completed.
	+ **In Progress**: The assignment is still in progress.
* **Assigned Tool**: Select the tool assigned to the assignment:
	+ **Google Drive**: The assignment uses Google Drive.
	+ **OneDrive**: The assignment uses OneDrive.
	+ **Dropbox**: The assignment uses Dropbox.
* **File Type**: Select the type of file uploaded:
	+ **pdf**: The file is a PDF.
	+ **docx**: The file is a Word document.
	+ **jpg**: The file is an image.
	+ **png**: The file is an image.
	+ **zip**: The file is a compressed file.
* **Class Name**: Input the name of the class, such as "Math 101" or "Science 202".
* **Label Fields**: Input a label for each field to describe its purpose.
