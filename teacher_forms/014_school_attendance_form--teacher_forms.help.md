# School Attendance Form - Help Guide
## Purpose
The School Attendance Form is used by teachers to track student attendance in a school setting. It captures information on student name, grade level, attendance date, and other relevant details such as absent, late, missing, and excused students.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the Student Name field with the student's name.
2. Select the student's grade level from the drop-down menu.
3. If applicable, indicate the number of absent, late, missing, and excused students.
4. Enter any additional notes or comments in the Notes field.
5. Select the Category (e.g., Teacher Forms, Student Forms, Staff Forms) and Assigned Tool for the form.
6. Save your changes and output the form as a file for your records.

## Field-by-Field Explanation
* **Student Name** (Student Name, text, required): Enter the full name of the student, including first and last names.
* **Student Grade** (Student Grade, select_one, required): Select the student's grade level from the drop-down menu.
* **Attendance Date** (Attendance Date, date, required): Enter the date of the attendance record.
* **Absent Students** (Absent Students, text, required): Enter the number of students absent on the attendance date.
* **Late Students** (Late Students, text, required): Enter the number of students late on the attendance date.
* **Missing Students** (Missing Students, text, required): Enter the number of students missing on the attendance date.
* **Excused Students** (Excused Students, text, required): Enter the number of students excused on the attendance date.
* **Notes** (Notes, note, required): Enter any additional comments or notes related to the attendance record.
* **Category** (Category, select_one, required): Select the category of the form (e.g., Teacher Forms, Student Forms, Staff Forms).
* **Assigned Tool** (Assigned Tool, text, required): Enter the tool assigned for the form.
* **Output File** (Output File, text, required): Enter the file name or location for the output file.
* **Created By** (Created By, text, required): Enter the name of the person creating the form.

Note: This form is not intended to be used as a substitute for other attendance management systems or software. It is meant to be a simple tool for teachers to quickly track student attendance.
