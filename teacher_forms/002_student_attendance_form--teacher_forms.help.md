# Student Attendance Form - Help Guide
## Purpose
The Student Attendance Form is used to record the attendance of students in a class.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the student's name in the "Student Name" field.
2. Enter the teacher's name in the "Teacher Name" field.
3. Enter the name of the class in the "Class Name" field.
4. Select the date of attendance in the "Date" field using the calendar icon.
5. Enter the time of attendance in the "Time" field.
6. For each student, select their attendance status (Present, Absent, or Late) in the "Student Attendance" field.
7. If necessary, add a note about the student's attendance in the "Note" field.
8. Enter the student's email address in the "Email" field.
9. Enter the student's phone number in the "Phone" field.
10. If applicable, select the assigned tool used by the student in the "Assigned Tool" field.
11. If not using an assigned tool, enter the name of the other tool used by the student in the "Other Tool" field.

## Field-by-Field Explanation

* **Student Name**: Enter the name of the student.
* **Teacher Name**: Enter the name of the teacher responsible for the class.
* **Class Name**: Enter the name of the class the student is attending.
* **Date**: Select the date of attendance using the calendar icon.
* **Time**: Enter the time of attendance.
* **Student Attendance**: Select the attendance status of the student (Present, Absent, or Late).
* **Note**: Add a note about the student's attendance if necessary.
* **Email**: Enter the student's email address.
* **Phone**: Enter the student's phone number.
* **Assigned Tool**: Select the assigned tool used by the student (chatjimmy or other).
* **Other Tool**: If not using an assigned tool, enter the name of the other tool used by the student.
