# Student Information Request Form - Help Guide
## Purpose
This form is designed to collect information about students for administrative purposes, such as tracking student progress or for academic reporting.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the student's ID number in the "Student ID" field.
2. Fill in the student's name in the "Student name" field.
3. Select the appropriate course from the "Course name" dropdown menu.
4. Choose the student's school year from the "School year" dropdown menu.
5. Select the student's school division from the "School division" dropdown menu.
6. (Optional) Enter the teacher's name in the "Teacher name" field, if applicable.

## Field-by-Field Explanation
* **Student ID (1)** (number, required: false): Enter the student's unique identifier number.
* **Student name (2)** (text, required: false): Fill in the student's full name.
* **Course name (3)** (select_one, required: false): Select the name of the course the student is enrolled in.
	+ Options: Math, Science, English
* **School year (4)** (select_multiple, required: false): Choose the grade level of the student.
	+ Options: 9th, 10th, 11th, 12th
* **Teacher name (5)** (text, required: false): (Optional) Enter the name of the student's teacher or mentor.
* **School division (6)** (select_multiple, required: false): Select the student's school division.
	+ Options: Division A, Division B, Division C

## Tips
* Make sure to fill in the required fields accurately and completely.
* Double-check the options for the "Course name" and "School division" fields to ensure you select the correct values.
* If you're unsure about any field, ask your supervisor or the form's administrator for clarification.
