# Teacher Donation Request Form - Help Guide
## Purpose
The Teacher Donation Request Form is a tool for teachers to request donations for their classrooms. This form is meant to help gather necessary information from teachers and ensure their requests are processed efficiently.

## How To Complete This Form
- Fill out all required fields (if any)
- Provide as much detail as possible for the requested fields
- Proofread the form for accuracy before submitting

## Field-by-Field Explanation

* **Teacher Donor Information** (`teacher_donor_form`):
	+ This field is meant to provide the donor's name and contact information.
* **Teacher Information** (`teacher_info`):
	+ This field is where the teacher can provide any additional information about themselves.
* **Donor Information** (`donor_info`):
	+ This field is meant to provide the donor's name and contact information.
* **Donation Amount** (`donation_amount`):
	+ Enter the total amount of the donation.
* **Donation Method** (`donation_method`):
	+ Select one of the following options:
		+ Cash
		+ Check
		+ Credit Card
* **Donation Date** (`donation_date`):
	+ The date the donation will be received or used.
* **Donor Name** (`donor_name`):
	+ Enter the donor's name.
* **Donor Email** (`donor_email`):
	+ Enter the donor's email address.
* **Donor Phone** (`donor_phone`):
	+ Enter the donor's phone number.
* **School Name** (`school_name`):
	+ Enter the name of the school.
* **Teacher's School** (`teacher_school`):
	+ Enter the name of the teacher's school.
* **Teacher's Grade Level** (`teacher_grade_level`):
	+ Enter the teacher's grade level.
* **Student's Name** (`student_name`):
	+ Enter the student's name.
* **Student's Grade Level** (`student_grade_level`):
	+ Enter the student's grade level.
* **Reason for Request** (`reason_for_request`):
	+ Briefly explain the reason for the donation request.
* **Teacher's Lesson Plan** (`teacher_lesson_plan`):
	+ Briefly describe the teacher's lesson plan or project.
* **Teacher's Project** (`teacher_project`):
	+ Briefly describe the teacher's project.
* **Teacher's Classroom Supplies** (`teacher_classroom_supplies`):
	+ List the specific classroom supplies needed.
* **Student's Project** (`student_project`):
	+ Briefly describe the student's project.
* **Student's Classroom Supplies** (`student_classroom_supplies`):
	+ List the specific supplies needed for the student's project.
* **Total Donation** (`total_donation`):
	+ Enter the total value of the donation.
* **Donor Comment** (`donor_comment`):
	+ Provide additional comments or context for the donation.
* **Teacher's Comment** (`teacher_comment`):
	+ Provide any additional comments from the teacher.
* **School Comment** (`school_comment`):
	+ Provide any additional comments from the school.

Note: The fields marked as "required" are mandatory fields that must be filled out.
