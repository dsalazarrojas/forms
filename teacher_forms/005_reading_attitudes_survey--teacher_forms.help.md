# reading_attitudes_survey - Help Guide
## Purpose

This form is used to gather information about your reading habits and attitudes. The goal is to understand your personal experiences and perceptions related to reading.

## How To Complete This Form

To complete this form, follow these steps:

1. Select a page with one field.
2. Answer each question truthfully.
3. If a field is not required, you can leave it blank.

## Field-by-Field Explanation

* **reading_attitudes_survey** (`text`, required: false):
	+ This field asks about your general attitudes towards reading.
	+ Please provide a brief description of your feelings or thoughts about reading.
* **reading_habits** (`text`, required: false):
	+ This field asks about your reading habits, such as the frequency and duration of your reading activities.
	+ Please describe your typical reading habits, e.g., how often do you read, for how long.
* **reading_habits_frequency** (`select_one`, required: false):
	+ This field asks how often you read.
	+ Please select "Yes" if you read regularly, and "No" if you don't read regularly.
* **reading_frequency_days** (`select_multiple`, required: false):
	+ This field asks about the number of days you read in a typical week.
	+ Select all the days that you read.
* **reading_frequency_minutes** (`select_multiple`, required: false):
	+ This field asks about the amount of time you spend reading in a typical day/week.
	+ Select all the time slots that apply to you.

## Tips

* Please answer honestly and accurately.
* If you're unsure about a question, please try to make an educated guess.
* If you have any questions or need help, don't hesitate to ask.
