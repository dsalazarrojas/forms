# Digital Escape Room Template - Help Guide
## Purpose
The Digital Escape Room Template form is used to design and organize a digital escape room, collecting details about puzzle design, player experience, and scoring systems.

## How To Complete This Form
- To start, review the template structure and fields.
- Fill out the fields for the puzzle designer (e.g., Mr. and Mrs. Johnson), puzzle theme, and puzzle description.
- Select the puzzle type (e.g., Room Escape, Puzzle Game, or Puzzle Adventure) and set the puzzle difficulty level (e.g., Easy, Medium, or Hard).
- Define the game length and player goal.
- Specify the room description, room background, and room theme.
- Input the puzzle solutions and solutions count.
- Decide on the player score type and set the score values.

## Field-by-Field Explanation
* **Player Name**: Enter the player's name or alias.
* **Puzzle Designer**: Select the designer or team behind the puzzle (e.g., Mr. and Mrs. Johnson).
* **Puzzle Name**: Enter a short description of the puzzle.
* **Puzzle Description**: Describe the puzzle in more detail.
* **Puzzle Theme**: Enter a short description of the puzzle theme.
* **Puzzle Type**: Select the type of puzzle or game experience (e.g., Room Escape, Puzzle Game, or Puzzle Adventure).
* **Puzzle Difficulty**: Set the difficulty level of the puzzle (e.g., Easy, Medium, or Hard).
* **Game Length**: Enter the length of the game in minutes or rounds.
* **Player Goal**: Define the player's ultimate goal (e.g., Find the key, Escape the room, etc.).
* **Player Objective**: Enter a description of the player's objective or motivation.
* **Puzzle Goal**: Select the puzzle's ultimate goal (e.g., Find the key, Unlock the door, etc.).
* **Room Description**: Describe the room or environment where the puzzle takes place.
* **Room Background**: Enter the background or story behind the room.
* **Room Theme**: Enter a short description of the room theme.
* **Puzzle Solutions**: Enter a description of the puzzle solutions or answers.
* **Puzzle Solutions Count**: Enter the number of puzzle solutions.
* **Player Score**: Set the player's score or rating system (e.g., Time, Points, or Stars).
* **Player Score Type**: Select the type of score or rating system (e.g., Time, Points, or Stars).
