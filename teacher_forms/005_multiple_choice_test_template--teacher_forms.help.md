# Multiple Choice Test Template - Help Guide
## Purpose
The Multiple Choice Test Template is a form designed for creating multiple choice tests. It allows users to create a series of questions with multiple choice options.

## How To Complete This Form
To complete this form, follow these steps:
1. Select the number of questions you want to include in your test.
2. Fill in the answers to each question, selecting the correct option for each question.
3. Review and submit the form when you're finished.
