# First Day Of School Questionnaire - Help Guide
## Purpose
The First Day Of School Questionnaire is a form designed to collect information about the student's background, family, and educational details.

## How To Complete This Form

1. Start by filling out the "Previous years of schooling" field, which is a text field where you can provide information about the student's previous years of schooling.
2. Next, select the family background from the options provided in the "Family background" field.
3. In the "Favorite subjects" field, select all the subjects that the student enjoys learning or is interested in.
4. For "Favorite hobbies", select all the activities that the student enjoys doing in their free time.
5. In the "Interests" field, provide any other information about the student's interests.
6. Fill out the "Grade next year" field with the student's expected grade level for the upcoming year.
7. Provide the family size in the "Family size" field.
8. List the names of the student's siblings in the "Siblings names" field.
9. Select the parent's occupation from the options provided in the "Parents occupation" field.
10. Select the parent's education level from the options provided in the "Parents education" field.
11. Fill out the "Family income" field with the family's annual income.
12. Select the parent's language from the options provided in the "Parents language" field.
13. Select the student's language from the options provided in the "Student language" field.
14. In the "Favorite classmate" field, provide the name of the student's favorite classmate.
15. Fill out the "Teacher name" field with the teacher's name.
16. Select the teacher's grade level from the options provided in the "Teacher grade" field.
17. Select the teacher's subject from the options provided in the "Teacher subject" field.
18. Select the student's subject from the options provided in the "Student subject" field.
19. Select the student's education level from the options provided in the "Student education level" field.
20. Select the teacher's education level from the options provided in the "Teacher education level" field.
21. Select the student's previous schooling from the options provided in the "Previous schooling" field.
22. Fill out the "School year" field with the current school year.
23. In the "Student attendance" field, provide information about the student's attendance.
24. Select the school level from the options provided in the "School level" field.
25. Fill out the "Teacher attendance" field with the teacher's attendance.

* **Siblings names** (`siblings_names`, text, optional): List the names of the student's siblings.
* **Parents occupation** (`parents_occupation`, select_one, optional): Select the parent's occupation from the options provided.
* **Parents education** (`parents_education`, select_multiple, optional): Select the parent's education level from the options provided.
* **Family income** (`family_income`, number, optional): Fill out the family's annual income.
* **Parents language** (`parents_language`, select_multiple, optional): Select the parent's language from the options provided.
* **Student language** (`student_language`, select_multiple, optional): Select the student's language from the options provided.
* **Favorite classmate** (`favorite_classmate`, text, optional): Provide the name of the student's favorite classmate.
* **Teacher name** (`teacher_name`, text, optional): Fill out the teacher's name.
* **Teacher grade** (`teacher_grade`, select_one, optional): Select the teacher's grade level from the options provided.
* **Teacher subject** (`teacher_subject`, select_multiple, optional): Select the teacher's subject from the options provided.
* **Student subject** (`student_subject`, select_multiple, optional): Select the student's subject from the options provided.

## Tips

* Make sure to fill out all the required fields accurately and completely.
* If you're unsure about any field, ask for clarification from the teacher or school administrator.
* Double-check your answers before submitting the form.
* If you need help with any field, contact the teacher or school administrator for assistance.
