# Parent Contact Log Form - Help Guide
## Purpose
The Parent Contact Log Form is a tool for recording and managing interactions between parents and staff members. It helps ensure that all relevant information is captured and that the next steps are taken to follow up with parents and other contacts.

## How To Complete This Form
To complete the form, follow these steps:

1. Enter the First Name of the parent who contacted you.
2. Enter the Last Name of the parent.
3. Enter the parent's Email.
4. Enter the Date and Time of contact.
5. Select the Contact Method that best describes the interaction.
6. Select the Assigned Staff Member responsible for following up.
7. Choose the Contact Status that best describes the outcome of the contact.
8. Check if Follow-up is needed and, if so, select the date and time for the follow-up.
9. Enter the Follow-up Method and Status.
10. Enter any additional Notes or Parent Response.

## Field-by-Field Explanation
* **First Name** (id: 1, type: text, required): Enter the first name of the parent.
* **Last Name** (id: 2, type: text, required): Enter the last name of the parent.
* **Email** (id: 3, type: email, required): Enter the parent's email address.
* **Date Contacted** (id: 4, type: date, required): Enter the date of contact.
* **Time Contacted** (id: 5, type: time, required): Enter the time of contact.
* **Contact Method** (id: 6, type: select_multiple, required): Select the best description of the contact method used (e.g., phone, email, in-person).
* **Assigned Staff Member** (id: 8, type: select_one, required): Choose the staff member assigned to follow up on this contact.
* **Contact Status** (id: 9, type: select_one, required): Choose the status of the contact (e.g., New Contact, Re-Contact, No Contact).
* **Next Steps** (id: 10, type: text, required): Enter any next steps or actions required.
* **Contact Details** (id: 7, type: text, optional): Enter any additional details about the contact.
* **Follow-up Needed** (id: 12, type: select_one, required): Check if follow-up is needed and, if so, choose Yes.
* **Follow-up Date** (id: 13, type: date, optional): Enter the date for follow-up, if needed.
* **Follow-up Time** (id: 14, type: time, optional): Enter the time for follow-up, if needed.
* **Follow-up Method** (id: 15, type: text, optional): Enter the method for follow-up.
* **Follow-up Status** (id: 16, type: select_one, required): Choose the status of the follow-up (e.g., Follow-up Done, No Follow-up).
* **Parent Response** (id: 17, type: text, optional): Enter any response or feedback from the parent.
* **Parent Notes** (id: 18, type: text, optional): Enter any additional notes from the parent.
* **Staff Response** (id: 19, type: text, optional): Enter any response or feedback from the staff member.
* **Staff Notes** (id: 20, type: text, optional): Enter any additional notes from the staff member.
