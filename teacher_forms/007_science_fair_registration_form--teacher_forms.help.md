# science_fair_registration_form - Help Guide
## Purpose
This guide will walk you through the science fair registration form, providing an explanation of each field and tips for completing the form successfully.

## How To Complete This Form
1. Fill in the participant information on the first page, including participant name, email, phone number, and school.
2. Move to the project information page to fill in the project title, description, and category.
3. Select the science fair category and any other relevant events for participation.
4. Review and submit the form for successful registration.

## Field-by-Field Explanation
### Participant Information
* **Participant Name**: The name of the participant.
* **Participant Email**: A valid email address for the participant.
* **Participant Phone**: A phone number for the participant.
* **Participant School**: The name of the participant's school.
* **Participant Teacher**: The name of the participant's teacher.

### Project Information
* **Project Name**: The title of the participant's project.
* **Project Description**: A brief description of the project.
* **Select Category**: Choose a category for the project from the provided options.
* **Submission Date**: The date of project submission (if applicable).

### Event Selection
* **Science Fair**: Select any relevant events for the participant to participate in.
* **Select Category**: This field is actually a duplicate of the project category field, please ignore this field to avoid confusion.
* **Submission Date**: This date field is not required, but if filled in, it will be used for submission purposes.

### Tips
* Make sure to fill in all required fields.
* Use a valid email address and phone number.
* Double-check the project category and science fair events selections.
* Review the form carefully before submission to avoid errors.
