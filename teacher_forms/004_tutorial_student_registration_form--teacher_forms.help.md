# Tutorial Student Registration Form - Help Guide
## Purpose
The Tutorial Student Registration Form is used to collect and manage student information for registration purposes. It is essential to provide accurate and complete data to ensure efficient processing and accurate records.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the student's name in the "Student Name" field.
2. Enter the student's email address in the "Student Email" field.
3. Provide the student's phone number in the "Student Phone" field.
4. Enter the student's address in the "Student Address" field.
5. Select the student's program of study from the options provided in the "Student Program of Study" field.
6. Enter the student's course ID in the "Student Course ID" field.
7. Enter the student's class ID in the "Student Class ID" field.
8. Select the start and end dates of the student's attendance period in the "Student Start Date" and "Student End Date" fields.
9. Choose the student's status from the options provided in the "Student Status" field.
10. Enter any additional information about the student in the "Student Additional Info" field.
11. Record any relevant notes for the student in the "Student Teacher Notes" field.
12. If applicable, enter the student's school name in the "Student School Name" field.

## Field-by-Field Explanation
* **Student Name**: Enter the student's full name, as it appears on their official documents.
* **Student Email**: Enter the student's email address for communication purposes. Ensure it is a valid email address.
* **Student Phone**: Enter the student's phone number where they can be reached.
* **Student Address**: Enter the student's current address for record-keeping purposes.
* **Student Date of Birth**: Select the student's date of birth in the format of MM/DD/YY or YYYY-MM-DD.
* **Student Program of Study**: Select the student's program of study from the provided options.
* **Student Course ID**: Enter the student's course ID, if applicable.
* **Student Class ID**: Enter the student's class ID, if applicable.
* **Student Start Date**: Select the start date of the student's attendance period.
* **Student End Date**: Select the end date of the student's attendance period.
* **Student Status**: Choose the student's status from the provided options.
* **Student Program Status**: Enter any additional status information about the student's program.
* **Student Additional Info**: Provide any extra information about the student, if needed.
* **Student Teacher Notes**: Record any notes or comments from the teacher.
* **Student School Name**: Enter the student's school name, if applicable.

## Tips
* Ensure all fields are filled in correctly and accurately before submitting the form.
* If unsure about any field, please refer to the student's official documents or contact the student directly.
* This form is intended for teacher or staff use only. Do not share or duplicate this form without authorization.
* Review the form carefully before submission to avoid errors.
