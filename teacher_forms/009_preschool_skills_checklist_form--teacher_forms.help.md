# Preschool Skills Checklist Form - Help Guide
## Purpose
The Preschool Skills Checklist Form is designed to assess a child's skills in various areas such as math, reading, science, physical, social, and emotional development.

## How To Complete This Form
To complete this form, please follow these steps:

1. Select the relevant option for each skill area to indicate whether the child demonstrates the skill or not.
2. Enter the child's name, date of birth, and any other relevant information in the corresponding fields.
3. If you have any additional comments or notes about the child's progress, you can include them in the "Comments" field.
4. Finally, sign and date the form to indicate that it has been completed.

## Field-by-Field Explanation
* **Skills Checklist**: Select the relevant option for each skill area to indicate whether the child demonstrates the skill or not.
  * Math Skill (`Math Skill`): Select 'Yes' if the child demonstrates math skills such as counting, basic addition and subtraction, etc.
  * Reading Skill (`Reading Skill`): Select 'Yes' if the child demonstrates reading skills such as recognizing letters, spelling words, etc.
  * Science Skill (`Science Skill`): Select 'Yes' if the child demonstrates science skills such as understanding basic concepts, etc.
  * Physical Skill (`Physical Skill`): Select 'Yes' if the child demonstrates physical skills such as running, jumping, etc.
  * Social Skill (`Social Skill`): Select 'Yes' if the child demonstrates social skills such as sharing, etc.
  * Emotional Maturity (`Emotional Maturity`): Select the relevant option for emotional maturity such as being able to express emotions, etc.
* **Student Name**: Enter the child's name as it is spelled.
* **Date of Birth**: Enter the child's date of birth in the format MM/DD/YYYY.
* **Gender**: Select the relevant option for the child's gender.
* **Comments**: Enter any additional comments or notes about the child's progress.
* **Completed By**: Select the relevant option for who completed the form.
* **Date Completed**: Enter the date the form was completed.
* **Time Spent**: Enter the amount of time spent with the child, if applicable.
* **Time Spent Hint**: Enter any additional information about the time spent with the child, if applicable.
* **Completed On**: Enter the time of day the form was completed, if applicable.
* **Teacher Signature**: Sign your name as the teacher who completed the form.
* **Teacher Name**: Enter your name as the teacher who completed the form.
* **Teacher Title**: Enter your title as the teacher who completed the form.
* **School Name**: Enter the name of the school where the form was completed.
* **School Address**: Enter the address of the school where the form was completed.
* **Student Count**: Enter the number of students you have assessed, if applicable.
* **Student Count Hint**: Enter any additional information about the student count, if applicable.
* **Teacher Count**: Enter the number of teachers who completed the form, if applicable.
* **Comments**: Enter any additional comments or notes about the child's progress.
