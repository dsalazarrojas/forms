# Home Language Survey - Help Guide
## Purpose
The Home Language Survey is a form designed to collect information about your language proficiency and language learning habits. This information will help us understand your language abilities better.

## How To Complete This Form

1. The form consists of several sections, each with its own set of questions. Please answer each question carefully, and make sure to complete all the required sections.
2. You can select multiple answers for some questions, so choose all the options that apply to you.
3. If you have any additional comments or information about your language learning habits, please use the "Comments" field to provide more details.
4. Finally, make sure to submit the form with your name and a valid student ID number.

## Field-by-Field Explanation
* **Home Language** (`home_language_survey`, select_multiple, optional): This question is asking about your native language or the language you most often use in your daily life. Select all languages that apply to you.
* **First Language** (`first_language`, select_one, optional): This question is asking about the first language you learned or spoke as a child. Please select 'Yes' if it's the language you learned first.
* **Second Language** (`second_language`, select_one, optional): This question is asking about the second language you learned or spoke. Please select 'Yes' if it has become a significant part of your language use.
* **Language Proficiency** (`language_proficiency`, text, optional): This question is asking about your language proficiency level. Please provide a short description of your language skills.
* **Comments** (`comments`, note, optional): This field is for any additional comments or information you'd like to share about your language learning habits.
* **Student ID** (`student_id`, number, optional): This is your student ID number. Please enter your student ID number for identification purposes.
* **Teacher Name** (`teacher_name`, text, optional): This field is for your teacher's name. Please enter the name of your teacher who will be submitting this form.
* **Date Submitted** (`date_submitted`, date, optional): This field will be automatically populated with the date and time of submission.

## Tips
* Please answer honestly about your language abilities.
* Make sure to complete all the required sections.
* If you have any questions or need help, don't hesitate to ask.
