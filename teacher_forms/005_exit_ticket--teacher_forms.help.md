# Exit Ticket - Help Guide
## Purpose
This form is used by teachers to provide feedback and assessment on a student's work or project.

## How To Complete This Form
1. Make sure you are a teacher and have a specific student's work or project in mind.
2. Ensure that you have reviewed the student's work or project before completing the form.
3. Answer each field as accurately and completely as possible.
4. Do not hesitate to use any available information or resources to provide the most comprehensive feedback.

## Field-by-Field Explanation

* **Teacher Form Data** (`teacher_form_data`, note, required: false): Please provide any relevant information about the student's work or project, such as the class or assignment it pertains to.
* **Student Data** (`student_data`, note, required: false): Enter any relevant student information, such as their name or ID number.
* **Submission Notes** (`submission_notes`, note, required: false): Provide any notes or comments about the student's submission, such as the date received or any issues with the submission.
* **Teacher Assessment** (`teacher_assessment`, select_one, required: false): Choose one of the following options to provide a concise assessment of the student's work or project:
	+ Option 1
	+ Option 2
	+ Option 3
* **Teacher Comments** (`teacher_comments`, note, required: false): Enter any additional comments or feedback you have about the student's work or project.
* **Student Comments** (`student_comments`, select_multiple, required: false): Choose one or multiple options to provide feedback on the student's work or project:
	+ Option 1
	+ Option 2
	+ Option 3
	+ Option 4
* **Teacher Signature** (`teacher_signature`, select_one, required: false): Indicate whether you have reviewed and agreed with the assessment and comments provided:
	+ 'Yes'
	+ 'No'
* **Student Signature** (`student_signature`, select_one, required: false): Check with the student to see if they have reviewed and agreed with the assessment and comments provided:
	+ 'Yes'
	+ 'No'
