# Student Innovation Project Evaluation Form - Help Guide
## Purpose
The Student Innovation Project Evaluation Form is used by teachers to assess and provide feedback on student innovation projects. This form helps to identify areas of excellence and potential areas for improvement in each project.

## How To Complete This Form
- Fill out the form completely and accurately, using information from the student project.
- Ensure that you select the correct evaluation options for each field.

## Field-by-Field Explanation

* **Student Name (1)** (`student_name`, text, optional): Enter the student's name as submitted with the project.
* **Project Name (2)** (`project_name`, text, optional): Enter the name of the project submitted by the student.
* **Project Description (3)** (`project_description`, text, optional): Enter a brief description of the project.
* **Innovation Type (4)** (`innovation_type`, select_one, optional): Select the type of innovation project (e.g., Research Project, Product Design, Service Based).
* **Problem Statement (5)** (`problem_statement`, text, optional): Describe the problem the student project aims to solve.
* **Goal Statement (6)** (`goal_statement`, text, optional): Describe the goal of the student project.
* **Solution Statement (7)** (`solution_statement`, text, optional): Describe how the student project addresses the problem.
* **Project Outcomes (8)** (`project_outcomes`, text, optional): Describe the project outcomes or results.
* **Teacher Evaluation (9)** (`teacher_evaluation`, select_one, required): Select the overall teacher evaluation of the project (e.g., Excellent, Good, Fair).
* **Student Innovation Skills (10)** (`student_innovation_skills`, select_multiple, required): Select the skills demonstrated by the student through this project (e.g., Critical Thinking, Communication, Problem Solving).
* **Project Impact (11)** (`project_impact`, select_one, required): Select the impact of the project (e.g., High, Medium, Low).
* **Recommendation (12)** (`recommendation`, select_multiple, required): Select the level of recommendation for further development or implementation (e.g., Highly Recommended, Recommended, Not Recommended).
* **Comments (13)** (`comments`, text, optional): Add any comments or feedback on the project.
* **Date Submitted (14)** (`date_submitted`, date, optional): Enter the date the project was submitted.
* **Date Completed (15)** (`date_completed`, date, optional): Enter the date the project was completed.
* **Teacher Comments (16)** (`teacher_comments`, text, optional): Add any comments or feedback from the teacher.
* **Student Comments (17)** (`student_comments`, text, optional): Add any comments or feedback from the student.
* **Evaluation Date (18)** (`evaluation_date`, date, optional): Enter the date the project was evaluated.
* **Project Status (19)** (`project_status`, select_one, optional): Select the current status of the project (e.g., Active, Completed, In Progress).
* **Project Category (20)** (`project_category`, select_multiple, optional): Select the category of the project (e.g., Science, Technology, Math, Other).
* **Student Name 2 (21)** (`student_name_2`, text, optional): Enter the name of another student involved in the project (if applicable).
* **Teacher Comments 2 (22)** (`teacher_comments_2`, text, optional): Add comments or feedback from another teacher (if applicable).
* **Student Comments 2 (23)** (`student_comments_2`, text, optional): Add comments or feedback from another student (if applicable).
* **Teacher Evaluation 2 (24)** (`teacher_evaluation_2`, select_one, required): Select the overall evaluation of another student's contribution (e.g., Excellent, Good, Fair).
* **Project Type (25)** (`project_type`, select_one, optional): Select the type of project (e.g., Research Project, Product Design, Service Based).
