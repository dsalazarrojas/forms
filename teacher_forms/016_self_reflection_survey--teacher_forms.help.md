# Self Reflection Survey - Help Guide
## Purpose
This form is designed to collect self-reflection data from teachers, providing valuable insights into your teaching practices and areas for improvement.

## How To Complete This Form

1. Answer the questions accurately and honestly, providing as much detail as possible for each field.
2. Review each field's required status, as some fields are marked as required (indicated by the word "Yes" in the required column).

## Field-by-Field Explanation
* **Self Reflection Survey** (`self_reflection_survey`, text, not required): A text field where you can write your self-reflection thoughts and ideas.
* **Category** (`category`, select_one, not required): Select one category that best describes your self-reflection (e.g., Option 1, Option 2, or Option 3).
* **Description** (`description`, note, not required): A free-text field where you can provide a brief description of your self-reflection, if needed.
* **Strengths** (`strengths`, select_multiple, not required): Select all strengths that apply from the provided options (e.g., Option 1, Option 2, Option 3, Option 4, or Option 5).
* **Weaknesses** (`weaknesses`, select_multiple, not required): Select all weaknesses that apply from the provided options (e.g., Option 1, Option 2, Option 3, Option 4, or Option 5).
* **Goals** (`goals`, text, not required): A text field where you can set goals for yourself related to your self-reflection (e.g., what you want to improve on).
* **Next Steps** (`next_steps`, text, not required): A text field where you can outline next steps or actions you plan to take as a result of your self-reflection.
* **Submitted Date** (`submitted_date`, date, not required): The date on which you submitted this form (will be filled in automatically).
* **Submitted Time** (`submitted_time`, time, not required): The time at which you submitted this form (will be filled in automatically).
* **Email** (`email`, email, not required): Your email address, which will be used for communication purposes.
* **Phone** (`phone`, text, not required): Your phone number, which will be used for communication purposes.
* **Self-Assessment** (`self_assessment`, select_one, not required): Select one self-assessment option (e.g., Option 1, Option 2, or Option 3).
* **Self Reflection Survey Date** (`self_reflection_survey_date`, date, not required): The date on which this self-reflection survey was completed (will be filled in automatically).

## Tips
* Be honest and accurate when filling out the form.
* Use clear and concise language in the text fields.
* If you're unsure about any field, ask your administrator or mentor for guidance.
* Review each field carefully before submitting the form to ensure accuracy.
