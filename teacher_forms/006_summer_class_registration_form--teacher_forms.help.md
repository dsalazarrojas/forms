# Summer Class Registration Form - Help Guide
## Purpose
The Summer Class Registration Form is designed to register students in a summer class. This form collects the student's basic information, class details, and additional settings to ensure a smooth registration process.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the First Name field with the student's first name.
2. Fill out the Last Name field with the student's last name.
3. Enter the student's Email address in the Email field.
4. Enter the Phone number in the Phone field.
5. Fill out the Class ID field with the class's ID number.
6. Select the Start Date for the class from the calendar.
7. Select the End Date for the class from the calendar.
8. Choose the Class Time from the available options.
9. Enter the Teacher ID number, if required.
10. Enter the Student ID number, if required.
11. Select the Class Type from the options provided (Full Time, Part Time, or Online).
12. Choose whether the student will be attending the class (Yes or No).
13. Enter the Student Name in the Student Name field.

## Field-by-Field Explanation
* **First Name** (`first_name`, text, not required): Enter the student's first name.
* **Last Name** (`last_name`, text, not required): Enter the student's last name.
* **Email** (`email`, email, not required): Enter the student's email address.
* **Phone** (`phone`, text, not required): Enter the student's phone number.
* **Class ID** (`class_id`, number, not required): Enter the class's ID number.
* **Start Date** (`start_date`, date, not required): Select the start date for the class from the calendar.
* **End Date** (`end_date`, date, not required): Select the end date for the class from the calendar.
* **Class Time** (`class_time`, time, not required): Choose the class time from the available options.
* **Teacher ID** (`teacher_id`, text, not required): Enter the Teacher ID number, if required.
* **Student ID** (`student_id`, text, not required): Enter the Student ID number, if required.
* **Teacher ID** (`teacher_id`, text, not required): Enter the teacher's ID number.
* **Student ID** (`student_id`, text, not required): Enter the student's ID number.
* **Class Type** (`class_type`, select_multiple, not required): Select the class type (Full Time, Part Time, or Online).
* **Class Name** (`class_name`, select_one, not required): Choose whether the student will be attending the class (Yes or No).
* **Student Name** (`student_name`, text, not required): Enter the student's name.

## Tips
- Make sure to fill out all required fields.
- Enter accurate and valid information for each field.
- Double-check the form before submission to avoid errors.
- If you need help or have questions, contact the relevant authorities.
