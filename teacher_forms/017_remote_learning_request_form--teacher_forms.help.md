# Remote Learning Request Form - Help Guide

## Purpose
The purpose of this form is to facilitate remote learning requests for students. The form captures information about the student and teacher involved, as well as the remote date and time of the learning request.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the relevant fields as needed:
	* `student name`: Enter the name of the student who is requesting remote learning.
	* `student id`: Enter the student ID number, if applicable.
	* `student grade`: Choose the grade level of the student (1-6).
	* `remote date`: Select the date on which the remote learning will take place.
	* `remote time`: Select the time of day when the remote learning will occur.
	* `teacher name`: Enter the name of the teacher who will be providing the remote learning.
	* `teacher email`: Enter the email of the teacher, if desired.
	* `teacher phone`: Enter the phone number of the teacher, if desired.
	* `school name`: Enter the name of the school, if desired.
	* `reason`: Enter a brief explanation for the remote learning request.
2. Fill out any additional fields as needed.
3. Submit the form when you have completed all the required and optional fields.
