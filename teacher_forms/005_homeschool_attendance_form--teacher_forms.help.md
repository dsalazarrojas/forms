# homeschool-attendance-form - Help Guide
## Purpose
The Homeschool Attendance Form is used to track the attendance of students in a homeschooling environment. It helps teachers or administrators record the attendance of students on a given date, providing valuable information for monitoring student progress and adjusting instruction accordingly.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the relevant date for which you want to track attendance.
2. Enter the student's name in the `Student Name` field.
3. Choose the attendance status for each student from the `Select Attendance Status` field. You can choose multiple options if applicable.
4. If a student is absent or late, provide a brief reason in the `Reason Absent` or `Reason Late` field.
5. Ensure that the `Select Attendance Status` field is completed for each student, as this is a required field.

## Field-by-Field Explanation
- **Homeschool Attendance** (`id: 1`): This field is not applicable and can be ignored.
- **Student Name** (`id: 2`): Enter the name of the student for whom you are tracking attendance.
- **Attendance Date** (`id: 3`): Select the date for which you are tracking attendance. This should match the date on which the student's attendance is being recorded.
- **Attendance Status** (`id: 4`): This field is not used and can be ignored.
- **Select Attendance Status** (`id: 5`): Choose the attendance status for each student from the options `Present`, `Absent`, or `Late`. Select multiple options if applicable.
- **Reason Absent** (`id: 6`): If a student is marked as `Absent` or `Late`, provide a brief reason for their absence or tardiness.
- **Reason Late** (`id: 7`): If a student is marked as `Late`, provide a brief reason for their late arrival.
