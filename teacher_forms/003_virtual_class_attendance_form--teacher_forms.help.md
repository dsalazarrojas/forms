# Virtual Class Attendance Form - Help Guide

## Purpose
The Virtual Class Attendance Form is a tool for teachers to record attendance data for virtual classes. This form helps teachers track student attendance and any remarks or reasons for absence.

## How To Complete This Form
To complete this form, please follow these steps:

1. Enter the virtual class information in the "Virtual Class" field.
2. Enter the student's name in the "Student Name" field.
3. Select the date of attendance in the "Date" field.
4. Enter the time of attendance in the "Time" field.
5. Indicate the student's attendance status by selecting "Yes" or "No" in the "Student Attendance" field.
6. Enter the teacher's name in the "Teacher Name" field.
7. Add any additional remarks in the "Remarks" field.
8. Enter the student's ID in the "Student ID" field.
9. If applicable, select the student's status as "Active" or "Inactive" in the "Student Status" field.
10. If a student is absent, enter the reason for absence in the "Student Absent Reason" field.

## Field-by-Field Explanation
- **Virtual Class** (`virtual_class_attendance_form`, text, not required): Enter the name of the virtual class you are tracking attendance for.
- **Student Name** (`student_name`, text, not required): Enter the name of the student whose attendance you are tracking.
- **Date** (`date`, date, not required): Select the date of attendance.
- **Time** (`time`, time, not required): Select the time of attendance.
- **Student Attendance** (`student_attendance`, select_multiple, not required): Indicate the student's attendance status by selecting "Yes" or "No".
- **Teacher Name** (`teacher_name`, text, not required): Enter your name as the teacher tracking attendance.
- **Remarks** (`remarks`, note, not required): Add any additional remarks or notes about the student's attendance.
- **Student ID** (`student_id`, text, not required): Enter the student's ID number.
- **Student Status** (`student_status`, select_one, not required): If applicable, select the student's status as "Active" or "Inactive".
- **Student Absent Reason** (`student_absent_reason`, text, not required): If the student is absent, enter the reason for absence.
