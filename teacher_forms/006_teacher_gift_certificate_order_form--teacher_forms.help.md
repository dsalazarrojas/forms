# Teacher Gift Certificate Order Form - Help Guide
## Purpose
The Teacher Gift Certificate Order Form is used to order and manage gift certificates for teachers. This form helps users to provide details about the teacher, gift preference, and other relevant information.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the "First name" and "Last name" fields with the teacher's personal details.
2. Enter the teacher's email address in the "Email" field.
3. Provide the teacher's phone number in the "Phone" field.
4. Enter the teacher's name as seen on their certificate in the "Teacher name" field.
5. Select the gift item from the dropdown menu in the "Gift item" field.
6. Enter the quantity of the gift item in the "Quantity" field.
7. Set the price point for the gift in the "Price point" field.
8. Choose the order date in the "Order date" field.
9. Provide any additional delivery instructions in the "Delivery note" field (optional).
10. Select the category(ies) of the gift in the "Category" field.
11. Enter the Form ID and Assigned Tool fields for administrative purposes.
12. Specify where to output the gift certificate in the "Output file" field.

## Field-by-Field Explanation
* **First name (1)**: Enter the first name of the teacher.
* **Last name (2)**: Enter the last name of the teacher.
* **Email (3)**: Enter the email address of the teacher.
* **Phone (4)**: Enter the phone number of the teacher.
* **Teacher name (5)**: Enter the name as seen on the teacher's certificate.
* **Gift item (6)**: Select the type of gift item you would like to order.
* **Quantity (7)**: Enter the quantity of the gift item.
* **Price point (8)**: Set the price point for the gift.
* **Order date (9)**: Choose the date of the order.
* **Delivery note (10)**: Provide any additional delivery instructions (optional).
* **Category (11)**: Select the category of the gift.
* **Form ID (12)**: Enter the Form ID for administrative purposes.
* **Assigned Tool (13)**: Enter the tool assigned to the teacher.
* **Output file (14)**: Specify where to output the gift certificate.
* **User notes (15)**: Enter any notes for the user (optional).
* **Admin notes (16)**: Enter any administrative notes (optional).
* **Category (17)**: Select the category of the gift (repeated for user convenience).
* **Form IDs (18)**: Enter the Form ID for administrative purposes.

Note: Please ensure all required fields are filled in accurately to ensure proper processing.
