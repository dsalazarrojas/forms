# Homework Help Order Form - Help Guide
## Purpose
The Homework Help Order Form is used by students to submit requests for assistance with homework problems or questions. The form collects personal details, problem descriptions, and submission information to enable teachers or administrators to provide help with homework.

## How To Complete This Form
To fill out the form, follow these steps:

1. Enter your first name in the "First Name" field.
2. Enter your last name in the "Last Name" field.
3. Enter your email address in the "Email" field.
4. Enter your phone number in the "Phone" field.
5. Describe the problem or question you need help with in the "Question" field.
6. Select the relevant subject(s) (e.g., math, science, history) in the "Subject" field.
7. Select the class you are in (e.g., 2A, 3B, 4C) in the "Class" field.
8. Upload any attachments related to the problem in the "Attachment" fields.
9. Select who submitted the request (e.g., student, teacher) in the "Submitted By" field.
10. Enter the date and time the request was submitted in the "Submitted Date" and "Submitted Time" fields.

## Field-by-Field Explanation

* **First Name (Text, Required)**: Enter your first name here.
* **Last Name (Text, Optional)**: Enter your last name here.
* **Email (Email, Optional)**: Enter your email address here.
* **Phone (Text, Optional)**: Enter your phone number here.
* **Question (Text, Optional)**: Describe the problem or question you need help with.
* **Subject (Select Multiple, Optional)**: Select the relevant subject(s) for your request.
* **Class (Select One, Optional)**: Select the class you are in.
* **Attachment (Text, Optional)**: Upload any attachments related to the problem.
* **Teacher's Name (Text, Optional)**: Enter your teacher's name (if applicable).
* **Teacher's Email (Email, Optional)**: Enter your teacher's email (if applicable).
* **Assigned to (Select One, Optional)**: Select the person or tool assigned to assist with the request (e.g., "chatjimmy", "other").
* **Submitter (Text, Optional)**: Enter a name for the person or group submitting the request (e.g., "student", "teacher").
* **Submitter Email (Email, Optional)**: Enter the email address of the person or group submitting the request.
* **Due Date (Date, Optional)**: Enter the date by which the request should be completed.
* **Due Time (Time, Optional)**: Enter the time by which the request should be completed.
* **Notes (Note, Optional)**: Enter any additional notes or comments about the request.
* **Submitted By (Select One, Optional)**: Select who submitted the request (e.g., "student", "teacher").
* **Submitted Date (Date, Optional)**: Enter the date the request was submitted.
* **Submitted Time (Time, Optional)**: Enter the time the request was submitted.
