# Grade Request Form - Help Guide
## Purpose
The Grade Request Form is a tool used by teachers to request grades for students in a standardized and efficient manner.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in your name and title as the person requesting the grade (Form Title, Student Name, and Student Number fields).
2. Enter the student's grade for the relevant subject or course (Grade field).
3. Provide a brief reason for the grade request (Reason field).
4. Select the date and time of the grade request (Date and Time fields).

## Field-by-Field Explanation
* **Form Title**: Enter a brief title to identify the grade request. This is a text field and is not required.
* **Student Name**: Enter the name of the student whose grade you are requesting. This is a text field and is not required.
* **Student Number**: Enter the student's identification number. This is a number field and is not required.
* **Grade**: Enter the grade you are requesting for the student. This is a number field and is not required.
* **Reason**: Enter a brief reason for the grade request. This is a text field and is not required.
* **Date**: Select the date of the grade request. This is a date field and is not required.
* **Time**: Select the time of the grade request. This is a time field and is not required.

## Tips
* Make sure to fill in all required fields to ensure the grade request is processed accurately.
* Double-check the grade and reason entered to ensure accuracy.
* If you are unsure about any field, please contact your supervisor or the relevant school administrator for assistance.
