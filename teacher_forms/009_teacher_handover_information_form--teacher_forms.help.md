# teacher_handover_information_form - Help Guide
## Purpose
The "teacher_handover_information_form" is used to collect information from teachers during handovers of classes, resources, or other items. This form helps to ensure that all relevant information is captured and documented, making the handover process more efficient and accurate.

## How To Complete This Form
To complete this form, please follow these steps:

1. Review the form carefully and ensure you have all the necessary information before starting.
2. For each page, complete the fields as required or as needed.
3. Use the provided hints and options to guide you in filling out the form.

## Field-by-Field Explanation
### Page 1: Notes
* **notes** (text, optional): Add any relevant notes about the handover, such as details about the class or resources being handover. 

### Page 2: Outstanding Tasks
* **outstanding_tasks** (select multiple, optional): Indicate if there are any outstanding tasks related to the handover. Select 'Yes' to indicate tasks that need attention or completion.

### Page 3: Resources
* **resources** (select one, optional): Indicate if there are any resources being handover, such as equipment or documentation. Select 'Yes' to indicate resources are being handover.

### Page 4: Class Notes
* **class_notes** (select one, optional): Indicate if the handover includes class notes, such as lesson plans or handouts. Select 'Yes' to indicate class notes are being handover.

### Page 5: Class Outstanding Tasks
* **class_outstanding_tasks** (select multiple, optional): Indicate if there are any outstanding tasks related to the class, such as tasks for students or the teacher. Select 'Yes' to indicate tasks that need attention or completion.

### Page 6: Key Documents
* **key_documents** (select one, optional): Indicate if there are any key documents being handover, such as policies or procedures. Select 'Yes' to indicate key documents are being handover.

### Page 7: Next Actions
* **next_actions** (select multiple, optional): Indicate any next actions or steps that need to be taken after the handover. Select 'Yes' to indicate actions that need to be taken.

### Page 8: Handover Form Status
* **handover_form_status** (text, optional): Enter any relevant status information about the handover form, such as notes or comments. 

### Page 9: Class Handovers
* **class_handovers** (text, optional): Enter any information about previous class handovers or notes. 

Note: All fields are optional, and you should only complete them as necessary. If you are unsure about any field, please contact your supervisor or support team for guidance.
