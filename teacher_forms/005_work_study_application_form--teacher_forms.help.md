# Work Study Application Form - Help Guide
## Purpose
The Work Study Application Form is designed for teachers or educators to apply for work study programs. This form collects essential information about the program, enabling the relevant authorities to review and process the application efficiently.

## How To Complete This Form
To complete the form, follow these steps:

1.  Fill in the program's title and a short description in the respective fields.
2.  Indicate whether the program is active or inactive.
3.  Choose the relevant options for the program's status.
4.  Enter the student's name and ID, which are necessary for processing the application.

## Field-by-Field Explanation
* **work_study_program_title** (`text`, required/optional): Enter the title of the work study program. This will help the reviewers identify the program quickly and easily.
* **program_type** (`select_one`, required/optional): Choose 'Yes' or 'No' to indicate whether the program is active or inactive.
* **select_multiple** (`select_multiple`, required/optional): Select multiple options for the program's status. Note that no specific options are specified in the YAML, so best-effort explanation suggests selecting relevant choices as per the program's characteristics.
* **work_study_program_start_date** (`date`, required/optional): Enter the start date of the program.
* **work_study_program_end_date** (`date`, required/optional): Enter the end date of the program.
* **work_study_application_form_program_status** (`select_one`, required/optional): Select 'Active' or 'Inactive' to indicate the program's status.
* **student_name** (`text`, required/optional): Enter the student's name associated with the program.
* **student_id** (`number`, required/optional): Enter the student's ID number.
* **work_study_application_form_program_description** (`text`, required/optional): Write a brief description of the program.

## Tips
- Ensure that all fields are correctly filled in with accurate information to avoid any processing errors.
- If you're unsure about any field, refer to the relevant authorities or seek clarification before submitting the form.
- Double-check the program status and student information for accuracy.
- This form is designed to be completed by teachers or educators, so it's essential to be honest and accurate when filling it out.
