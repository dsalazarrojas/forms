# Preschool Initial Application Form - Help Guide
## Purpose
The Preschool Initial Application Form is a form for prospective parents to provide basic contact information and demographic data to help the preschool identify the child's eligibility and prepare for the application process.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill out all the required fields (marked as "Required" in the field-by-field explanation section below).
2. Provide accurate and truthful information to the best of your ability.
3. Submit the form once you have completed all the required fields.

## Field-by-Field Explanation
* **First Name** (1, text, Required): This is the child's first name.
* **Last Name** (2, text, Required): This is the child's last name.
* **Email** (3, email, Required): Please provide a valid email address where you can be reached for communication purposes.
* **Home Phone** (4, text, Optional): This is the phone number of the child's home.
* **Work Phone** (5, text, Optional): This is the work phone number of the person filling out the form (usually a parent or guardian).
* **Address** (6, text, Required): Please provide the child's current address.
* **City** (7, text, Required): Please provide the city where the child currently lives.
* **State** (8, select_one, Required): Please select the state where the child currently lives.
* **Zip** (9, text, Optional): This is the child's zip code.
* **Date of Birth** (10, date, Required): This is the child's date of birth.
* **Birth Certificate ID** (11, select_one, Required): Please select "Yes" if you have a birth certificate for the child; "No" otherwise.

## Tips
- Make sure to provide accurate and up-to-date information.
- If you are unsure about any field, please contact the preschool administration for clarification.
- If you are filling out this form on behalf of someone else, please ensure they are aware of the information provided.
