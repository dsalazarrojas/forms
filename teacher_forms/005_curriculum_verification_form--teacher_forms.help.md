# Curriculum Verification Form - Help Guide

## Purpose
This form is designed to collect and verify student enrollment information in a curriculum or course.

## How To Complete This Form
To complete this form, simply fill out the fields as follows:

- **Student Enrollment**: Enter the student's enrollment information in this text field.
- **Discipline Name**: Enter the name of the discipline or course the student is enrolled in.
- **Teacher Name**: Enter the name of the teacher responsible for the student's enrollment.
- **Enrollment Verification**: Enter any additional information about the student's enrollment, if applicable.
- **School Name**: Enter the name of the school the student is enrolled in.
- **Date Enrolled**: Select the date the student was enrolled in the curriculum or course. Use the calendar icon to select the date.
- **Teacher Email**: Enter the email address of the teacher who is responsible for the student's enrollment.

## Field-by-Field Explanation
- **Student Enrollment**: Enter the student's name or ID, or any other relevant enrollment information.
	* Example: Student ID, student name, etc.
- **Discipline Name**: Enter the name of the discipline or course the student is enrolled in.
	* Example: Mathematics, Science, etc.
- **Teacher Name**: Enter the name of the teacher responsible for the student's enrollment.
	* Example: Mr. Smith, Ms. Johnson, etc.
- **Enrollment Verification**: Enter any additional information about the student's enrollment, if applicable.
	* Example: Any comments or notes about the student's progress, etc.
- **School Name**: Enter the name of the school the student is enrolled in.
	* Example: ABC High School, DEF Elementary School, etc.
- **Date Enrolled**: Select the date the student was enrolled in the curriculum or course.
	* Use the calendar icon to select the date.
- **Teacher Email**: Enter the email address of the teacher who is responsible for the student's enrollment.
	* Example: teacher@example.com, etc.
