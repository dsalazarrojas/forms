# e_learning_session_feedback_form - Help Guide
## Purpose

The e_learning_session_feedback_form is designed to collect feedback and ratings from learners after an e-learning session. This information will help instructors refine their teaching methods and materials.

## How To Complete This Form

1. Select the e-learning session for which you are providing feedback by typing in the "course" field.
2. Provide a brief description of your feedback in the "feedback" field.
3. Rate the session in the "ratings" field on a scale from 1 to 5.
4. If you have any additional comments, provide them in the "comments" field.
5. If you have any suggestions for improvement, provide them in the "suggestions" field.
6. Optionally, select multiple ratings in the "ratings_2" field.
7. Optionally, provide the date of submission in the "submission" field.

## Field-by-Field Explanation

* **course (text, required: false)**: Type in the title of the course or session for which you are providing feedback.
* **session (text, required: false)**: Type in the title of the session for which you are providing feedback.
* **feedback (text, required: false)**: Type a brief description of your feedback. Be as concise as possible.
* **ratings (select_one, required: false)**: Rate the session on a scale from 1 to 5.
* **comments (text, required: false)**: If you have any additional comments, provide them here.
* **suggestions (text, required: false)**: If you have any suggestions for improvement, provide them here.
* **ratings_2 (select_multiple, required: false)**: Select multiple ratings for the session. This will override the single rating provided in the "ratings" field.
* **submission (date, required: false)**: Provide the date of submission, if applicable.
* **submission (submit, not applicable)**: Note that this field is not applicable to this form.

## Tips

* Please be as concise as possible when providing feedback.
* You can choose multiple ratings in the "ratings_2" field, but this will override the single rating provided in the "ratings" field.
* The "submission" field is optional and only requires the date of submission if you are submitting feedback on a specific date.
* If you have any issues with the form, please contact your administrator.
