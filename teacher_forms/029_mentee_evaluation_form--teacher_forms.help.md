# mentee_evaluation_form - Help Guide
## Purpose
The mentee evaluation form is used to record and track the progress and performance of mentees in various programs such as mentoring and project-based programs. This form helps mentors and administrators assess the mentees' progress, identify areas of improvement, and provide constructive feedback.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the `title` field with a brief description of the mentee's program.
2. Select the category of the program from the `category` dropdown menu.
3. Provide a detailed description of the program in the `description` field.
4. Write any additional comments you would like to make about the mentee's progress in the `comments` field.
5. Select the current progress status of the mentee from the `progress_status` dropdown menu.
6. Add any additional comments about the mentee's progress in the `progress_comments` field.
7. Rate the mentee's performance on a scale of Excellent, Good, Fair, or Poor in the `rating` field.
8. Enter the mentee's email address in the `email` field.
9. Enter the mentee's phone number in the `phone` field (optional).
10. Select who submitted the form (Mentor, Mentee, or Administrator) in the `submitted_by` dropdown menu.
11. Select the date the form was submitted in the `submitted_date` field.
12. Select the date the form was last updated in the `last_updated` field.
13. Select who last updated the form (System, Mentor, or Administrator) in the `last_updated_by` dropdown menu.

## Field-by-Field Explanation

* **title** (text, required): Enter a brief description of the mentee's program.
* **category** (select_one, required): Select the category of the program (e.g., mentoring, project, other).
* **description** (text, required): Provide a detailed description of the program.
* **comments** (text, required): Write any additional comments about the mentee's progress.
* **progress_status** (select_one, required): Select the current progress status of the mentee (e.g., In Progress, On Track, Behind).
* **progress_comments** (text, required): Add any additional comments about the mentee's progress.
* **rating** (select_one, required): Rate the mentee's performance on a scale of Excellent, Good, Fair, or Poor.
* **email** (email, required): Enter the mentee's email address.
* **phone** (text, optional): Enter the mentee's phone number (optional).
* **submitted_by** (select_one, required): Select who submitted the form (Mentor, Mentee, or Administrator).
* **submitted_date** (date, required): Select the date the form was submitted.
* **last_updated** (date, required): Select the date the form was last updated.
* **last_updated_by** (select_one, required): Select who last updated the form (System, Mentor, or Administrator).
