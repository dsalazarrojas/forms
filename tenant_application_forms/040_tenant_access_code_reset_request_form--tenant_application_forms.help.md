# Tenant Access Code Reset Request Form - Help Guide
## Purpose
This form is used to request the reset of a tenant's access code, which is a unique code used for authentication and verification. The purpose of this form is to allow tenants to request a new access code when they have forgotten or lost their existing code.

## How To Complete This Form
To complete this form, follow these steps:

1. Ensure you are submitting a genuine request for a code reset. Double-check that you have not already submitted a request or that your code has not been reset recently.
2. Provide your email address associated with your tenant account.
3. Enter the date you are requesting the code reset.
4. If necessary, add any additional notes or comments regarding your request.
5. Enter any relevant phone number (if applicable).
6. Finally, provide a brief description of the reset code you are requesting.

## Field-by-Field Explanation
* **Email** (`tenant_access_code_reset_request_email`, email, required): Enter the email address associated with your tenant account.
* **Date** (`tenant_access_code_reset_request_form_date`, date, required): Enter the date you are requesting the code reset.
* **Note** (`tenant_access_code_reset_request_form_note`, note, optional): Add any additional comments or notes regarding your request.
* **Phone Number** (`tenant_access_code_reset_request_form_phone`, text, optional): If you have a preferred or emergency contact number, enter it here (if applicable).
* **Code Description** (`tenant_access_code_reset_request_code`, text, optional): Provide a brief description of the reset code you are requesting.

Please note that this form should be completed only if you are a legitimate user requesting a reset of your access code.
