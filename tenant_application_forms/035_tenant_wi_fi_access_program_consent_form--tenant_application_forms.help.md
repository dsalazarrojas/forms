# Tenant Wi-Fi Access Program Consent Form - Help Guide

## Purpose
The Tenant Wi-Fi Access Program Consent Form is used to capture consent from tenants to access the building's Wi-Fi access program. This form is a necessary step for tenants to provide their agreement to the terms of the program and share some basic contact information.

## How To Complete This Form
To complete this form, please follow these steps:

* Please fill out the form in its entirety, or as much as you can, given the optional fields.
* If you have any issues or questions, please contact the building management.

## Field-by-Field Explanation

* **Tenant Wi-Fi Access Program Consent** (`tenant_wifi_access_program_consent_form`, text, required: false): This is the form title and introduction.
	+ It's a brief introduction to the form and its purpose.
* **Email Address** (`email_address`, email, required: false): This is where you should enter your email address. Please enter your correct email address so we can contact you with any updates or important information.
* **Phone Number** (`phone_number`, text, required: false): This is where you should enter your phone number. This information will help us contact you in case of emergencies or important updates.
* **Date of Birth** (`date_of_birth`, date, required: false): This is where you should enter your date of birth. Please note that this field is optional but might be required for some administrative purposes.
* **Agreement** (`agreement`, select_one, required: false): Please select 'Yes' if you agree to the terms of the Tenant Wi-Fi Access Program. If you don't select 'Yes', you won't be able to access the program.
* **Comments** (`comments`, text, required: false): This is an optional field where you can provide any additional comments or questions you might have.

## Tips
* Please make sure to fill out all the required fields (if any).
* If you're unsure about any field, please contact the building management for clarification.
* Once you've filled out the form, please submit it for review and approval.
