# tenant_background_check_consent_form - Help Guide
## Purpose
This form is used to collect background check consent and relevant information from landlords/tenants during the background check process.

## How To Complete This Form
To complete this form, please follow these steps:
1. Read the instructions provided and understand the purpose of this form.
2. Answer all required fields, indicated by *required* in the field explanation.
3. Select the correct option for the "Background Check" field, which is a critical component of the background check process.

## Field-by-Field Explanation
* **Background Check** (`background_check`, select_one, *required*): This field determines which type of background check to perform. Please select the option that best describes the type of check required.
* **Screening Process** (`screening_process`, text, optional): This field allows you to describe the specific screening process used to obtain the background check information.
* **Tenant Information** (`tenant_information`, text, optional): This field is used to collect additional information about the tenant.
* **Landlord Information** (`landlord_information`, text, optional): This field is used to collect additional information about the landlord.
* **Background Check Consent** (`background_check_consent`, note, not required): This field is a note for the background check consent, please fill in the information and then sign it.
## Tips
* Please ensure that you provide accurate and truthful information in all fields.
* Review your answers before submitting the form to ensure that you have completed all required fields and provided accurate information.
* If you need help or clarification, please contact our support team.
* Please do not duplicate the information provided in this form elsewhere in your application or other forms.
