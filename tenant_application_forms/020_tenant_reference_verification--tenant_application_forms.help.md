# Tenant Reference Verification - Help Guide
## Purpose
The Tenant Reference Verification form is used to gather information about a tenant's employment status and history for evaluating their creditworthiness or verifying their employment details for a rental application.

## How To Complete This Form
To complete this form, please follow these steps:

1. Enter your name, and provide a brief description of your relationship with the tenant.
2. Answer the questions about the tenant's employment status, including their employment type and duration.
3. If the tenant is no longer employed, provide the reason for their employment ended and the date it ended.

## Field-by-Field Explanation
- **Tenant Reference** (tenant_reference_verification_1_name, text, required): Enter your name as a reference for the tenant.
- **Experience** (tenant_reference_verification_2_experience, text, optional): Briefly describe your experience with the tenant.
- **Employment Status** (tenant_reference_verification_3_employment_status, select_one, optional): Select the tenant's current or past employment status (Employed, Self-Employed, or Retired).
- **Employment Type** (tenant_reference_verification_4_employment_type, select_multiple, optional): Select the type of employment the tenant has (Part-time, Full-time, or Seasonal).
- **How Long Employed** (tenant_reference_verification_5_employment_duration, select_one, optional): Answer if the tenant is currently employed (Yes or No).
- **Employment Ended** (tenant_reference_verification_6_employment_ended, date, optional): If the tenant is no longer employed, enter the date they stopped working.
- **Reason for Employment Ended** (tenant_reference_verification_7_employment_ended_reason, select_multiple, optional): If the tenant is no longer employed, select the reason for termination (Voluntarily, Unemployed, or Retired).
- **Employment Ended Date** (tenant_reference_verification_8_employment_ended_date, date, optional): If the tenant is no longer employed, enter the date they stopped working.
