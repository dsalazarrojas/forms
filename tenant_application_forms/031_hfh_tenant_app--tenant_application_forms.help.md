# hfh_tenant_app - Help Guide
## Purpose
The hfh_tenant_app form is designed to gather information from potential tenants for housing applications. It helps the housing authority to understand the applicants' needs and preferences.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill in your contact information on the first page.
2. Select the type of application you're submitting.
3. Enter your address, email, and phone number.
4. Choose the date and time you would like to move in.
5. Add any additional notes.
6. Answer the select multiple and select one questions (Yes/No).
7. Enter integer and decimal field values.
8. Repeat steps 5-7 for the second page.

## Field-by-Field Explanation
* **Contact Information** (page 1): Enter your name, address, phone number, and email.
* **Application Type** (page 1): Select the type of application you're submitting.
* **Address** (page 1): Enter your home or office address.
* **Email** (page 1): Enter your email address.
* **Phone** (page 1): Enter your phone number.
* **Date** (page 1): Choose a date you'd like to move in.
* **Time** (page 1): Select a time you'd like to move in.
* **Note** (page 1): Add any additional comments or notes.
* **Select Multiple** (page 1): Select multiple options from the given list.
* **Select One** (page 1): Select one option from the given list.
* **Integer Field** (page 1): Enter an integer value.
* **Decimal Field** (page 1): Enter a decimal value.
* **Decimal Field 2** (page 2): Enter another decimal value.
* **Address 2** (page 2): Enter another address.
* **Email 2** (page 2): Enter another email address.
* **Phone 2** (page 2): Enter another phone number.
* **Select Multiple 2** (page 2): Select multiple options from the given list.
* **Select One 2** (page 2): Select one option from the given list.
* **Integer Field 2** (page 2): Enter another integer value.
* **Decimal Field 3** (page 2): Enter another decimal value.
* **Decimal Field 4** (page 2): Enter another decimal value.
* **Integer Field 3** (page 2): Enter another integer value.
* **Select Multiple 3** (page 2): Select multiple options from the given list.
* **Select One 3** (page 2): Select one option from the given list.
* **Integer Field 4** (page 2): Enter another integer value.

Note: The required fields are not marked. Please review each field carefully to ensure you're providing the necessary information.
