# rsvp_for_event_giveaway_entry - Help Guide
## Purpose
This form is used to collect RSVP and giveaway information for a one-time event. It will not be used for any other purpose.

## How To Complete This Form
1. Fill out your name and email address in the required fields.
2. Choose the event date and time of the giveaway.
3. Select 'Yes' or 'No' to indicate if you would like to receive a giveaway item.
4. If you choose 'Yes', please provide a brief description of the item(s) you would like to receive.
5. Once you have completed the form, click the 'Submit' button to submit your RSVP and giveaway information.

## Field-by-Field Explanation
* **RSVP Form** (`rsvp_form`, text, required): Enter the name of the event you are RSVPing for. This is a required field.
* **Event Information** (`event_info`, text, required): Enter a brief description of the event you are attending. This is a required field.
* **Name** (`name`, text, required): Enter your full name as it should be listed on the event schedule. This is a required field.
* **Email** (`email`, email, required): Enter your email address where you can be reached about event details. This is a required field.
* **Phone** (`phone`, text, optional): Enter your phone number where you can be reached about event details. This is an optional field.
* **Event Date** (`event_date`, date, required): Select the date of the event you are attending. This is a required field.
* **Event Time** (`event_time`, time, required): Select the time of the event you are attending. This is a required field.
* **Event Place** (`event_place`, text, required): Enter the location of the event you are attending. This is a required field.
* **Give Away Prize** (`give_away_prize`, select_one, required): Select 'Yes' or 'No' to indicate if you would like to receive a giveaway item. This is a required field.
* **Give Away Description** (`giveaway_description`, text, optional): Enter a brief description of the item(s) you would like to receive. This is an optional field.
