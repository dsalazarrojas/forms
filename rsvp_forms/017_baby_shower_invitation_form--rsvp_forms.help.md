# Baby Shower Invitation Form - Help Guide
## Purpose
This form is designed to collect information from guests for a baby shower event. It will help the host plan and organize the event.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the **Host name** (Person organizing the shower)
2. Select a date for the **Event date**
3. Select a time for the **Event time** (optional)
4. Enter the **Venue address** (Location and directions)
5. Select a date for the **RSVP by date** (Deadline for responses)
6. Enter your **Guest name** (Full name for RSVP)
7. Select your **Attending status**:
	* Attending
	* Not attending
	* Maybe
8. If bringing a guest, select **Will you bring a plus one?**:
	* True
	* False
9. If you have any **Dietary needs** (Allergies or restrictions), enter them
10. If you have a **Message for the host**, enter it (optional)

## Field-by-Field Explanation
* **Host name**: The person organizing the baby shower.
* **Event date**: The date of the baby shower.
* **Event time**: The start time of the baby shower (optional).
* **Venue address**: The location and directions of the baby shower.
* **RSVP by date**: The deadline for responses.
* **Guest name**: The full name of the guest.
* **Attending status**: Select one of the following:
	+ Attending
	+ Not attending
	+ Maybe
* **Will you bring a plus one?**: Select True if you are bringing a guest, False otherwise.
* **Dietary needs**: Enter any allergies or restrictions.
* **Message for the host**: Enter any notes or messages for the host.

## Tips
* Make sure to fill out all required fields.
* If you are unsure about any field, ask the host or refer to the invitation for clarification.
* The host will use this information to plan and organize the baby shower, so please provide accurate and complete information.
