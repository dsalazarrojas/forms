## Purpose
This form is used to collect RSVPs for a corporate event.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the required fields, marked as such in the form.
2. Answer all questions truthfully and thoroughly.
3. Use the provided options for select_multiple and select_one fields.
4. Make sure to submit the form once you've completed all the necessary fields.

## Field-by-Field Explanation
* **RSVP Details** (`rsvp_details`): A text field where you can provide any additional details about your RSVP.
* **Guest Name** (`guest_name`): Enter your name as it appears on your invitation.
* **Guest Email** (`guest_email`): Enter your email address. This will help the event organizers contact you.
* **Guest Phone** (`guest_phone`): Enter your phone number. This is optional.
* **Preferences** (`preferences`): Select all the options that apply to you.
* **Special Requests** (`special_requests`): If you have any special requests or needs, describe them here.
* **Comments** (`comments`): Provide any additional comments or questions.
* **Event Details** (`event_details`): Enter any details about the event you'd like to share.
* **RSVP Time** (`rsvp_time`): Select the time you plan to RSVP.
* **Guest Count** (`guest_count`): If you're bringing guests, enter their count.
* **Is Attending** (`is_attending`): Select 'True' if you'll be attending, and 'False' if you won't.
* **Will Bring** (`will_brings`): Select all the items you'll bring.
* **Will Share** (`will_share`): Select all the items you'll share.
* **Will Dance** (`will_dance`): Select all the activities you'll participate in.
* **Will Eat** (`will_eat`): Select all the food options you'll choose.
* **Will Drink** (`will_drink`): Select all the drink options you'll choose.
* **Will Park** (`will_park`): Select all the parking options you'll use.
* **Other** (`other`): Provide any other information not covered in the previous fields.
* **Will Help** (`will_help`): Select all the tasks you'll help with.
* **RSVP Date** (`rsvp_date`): Select the date you're RSVPing.
* **Event Date** (`event_date`): Enter the date of the event.
* **Event Time** (`event_time`): Enter the time of the event.
* **Event Location** (`event_location`): Enter the location of the event.
* **Host Name** (`host_name`): Enter the name of the host.
* **Host Email** (`host_email`): Enter the email of the host.
