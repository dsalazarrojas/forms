# Milestone Celebration Registration - Help Guide

## Purpose
This form is used to register guests for a milestone celebration event. It gathers essential information from guests to track their attendance and preferences. The form is designed to be completed by guests who are interested in attending the milestone celebration.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill in the RSVP Form field with your name and other relevant details if required.
2. Select your RSVP preference by choosing 'Yes' or 'No' from the dropdown menu.
3. If you are attending, provide the number of guests you will be bringing.
4. Write any messages or comments you would like to share with the hosts in the Message field.
5. Provide details of the host(s) and their availability to be assigned a tool if needed.
6. Choose the planning details for the event (e.g., event date, time, assigned tool).
7. Fill in the form title and description if required.
8. Optionally, choose a category and description for the form.

## Field-by-Field Explanation
- **RSVP Form** (`RSVP Form`, `text`, required/optional): This field is used to enter your name and other relevant details if required.
  - **Name** (`Name`, `text`, required/optional): Please enter your name as it appears on your invitation or ID card.
  - **Email** (`Email`, `email`, required/optional): Enter your email address so we can contact you with updates about the milestone celebration.
  - **RSVP** (`RSVP`, `select_multiple`, required/optional): Select 'Yes' if you will be attending the milestone celebration and 'No' if not.
  - **Number of Guests** (`Number of Guests`, `number`, required/optional): If you are attending, provide the total number of guests you will be bringing.
  - **Message** (`Message`, `note`, required/optional): Write any messages or comments you would like to share with the hosts.
  - **Host Details** (`Host Details`, `select_multiple`, required/optional): Please choose if you are a host or not. If yes, provide details of your availability.
  - **Planning Details** (`Planning Details`, `text`, required/optional): Enter any planning details for the event (e.g., event date, time).
  - **Event Date** (`Event Date`, `date`, required/optional): Select the date of the event.
  - **Event Time** (`Event Time`, `time`, required/optional): Select the time of the event.
  - **Assigned Tool** (`Assigned Tool`, `text`, required/optional): Enter the tool assigned to you by the host if required.
  - **Form ID** (`Form ID`, `text`, required/optional): A unique identifier for the form.
  - **Category** (`Category`, `text`, required/optional): Choose a category for the form if required.
  - **Description** (`Description`, `text`, required/optional): Enter a description for the form if required.
  - **Output File** (`Output File`, `text`, required/optional): A file to be outputted for the form.
  - **Assigned Tool User** (`Assigned Tool User`, `text`, required/optional): Enter the user assigned to the tool.
  - **RSVP Status** (`RSVP Status`, `select_one`, required/optional): Choose the RSVP status of the event (Active or Inactive).
  - **Status Message** (`Status Message`, `text`, required/optional): Enter any status message.
  - **Created At** (`Created At`, `date`, required/optional): The date the form was created.
  - **Updated At** (`Updated At`, `date`, required/optional): The date the form was last updated.
  - **Created By** (`Created By`, `text`, required/optional): Enter the user who created the form.
  - **Updated By** (`Updated By`, `text`, required/optional): Enter the user who last updated the form.
  - **Form Title** (`Form Title`, `text`, required/optional): Enter the title of the form.
  - **Form Description** (`Form Description`, `text`, required/optional): Enter a description for the form.
  - **Form Category** (`Form Category`, `text`, required/optional): Choose a category for the form.

## Tips
Please make sure to fill out all the required fields accurately and truthfully.
