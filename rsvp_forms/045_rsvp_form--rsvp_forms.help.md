# RSVP Form - Help Guide
## Purpose
The RSVP Form is a tool used to collect essential event-related information from users. It's designed to be used for event planning and organization purposes.

## How To Complete This Form
To complete the RSVP Form, please follow these steps:

1. **Enter the Event Name**: Type in the name of the event you're interested in or will be hosting.
2. **Enter the Host Name**: Type in the name of the person hosting or organizing the event.
3. **Select the Event Date**: Choose the date of the event from the calendar options.
4. **Select the Event Time**: Choose the start time of the event.
5. **Indicate Your Attendance**: Select whether you will attend the event by choosing "Yes" or "No".
6. **Enter Guest Count**: If you're attending, indicate how many guests you will bring along.
7. **Add a Comment (Optional)**: If you'd like to share any additional information, you can type it in the comment field.
8. **Enter Your Email Address**: Type in your email address so that we can get in touch with you about the event.
9. **Enter Your Phone Number (Optional)**: If you'd like to be contacted via phone, type in your phone number.

## Field-by-Field Explanation
- **Event Name**: This is the title of the event, and it's required to be filled.
  - Type: text
  - Purpose: To identify the event
  - Required: Yes
  - Hint: Type in the name of the event
- **Host Name**: This is the name of the person hosting or organizing the event.
  - Type: text
  - Purpose: To identify the host
  - Required: Yes
  - Hint: Type in the host name
- **Event Date**: This is the date of the event.
  - Type: date
  - Purpose: To determine the event date
  - Required: Yes
  - Hint: Choose the date of the event
- **Event Time**: This is the start time of the event.
  - Type: time
  - Purpose: To determine the event time
  - Required: Yes
  - Hint: Choose the start time of the event
- **Will Attend**: This is an optional field to indicate whether you will attend the event or not.
  - Type: select_one
  - Purpose: To indicate attendance status
  - Required: Yes
  - Hint: Select "Yes" if attending, "No" otherwise
- **Guest Count**: This is an optional field to indicate how many guests you will bring along if you attend.
  - Type: number
  - Purpose: To estimate the number of guests attending
  - Required: No
  - Hint: Type in the number of guests attending
- **Comment**: This is an optional field to add any additional comments or notes about the event.
  - Type: note
  - Purpose: To add any additional comments
  - Required: No
  - Hint: Type in any additional comments
- **Email**: This is the field where you type in your email address.
  - Type: email
  - Purpose: To get in touch with you about the event
  - Required: Yes
  - Hint: Type in your email address
- **Phone**: This is the field where you type in your phone number.
  - Type: text
  - Purpose: To get in touch with you via phone
  - Required: No
  - Hint: Type in your phone number
