# Reunion Location Preference Survey - Help Guide
## Purpose
This form is used to gather information about the attendee's preference for the upcoming reunion location.

## How To Complete This Form
1. Please select your preferred location for the reunion from the options provided.
2. Choose whether you are likely to attend the reunion or not.
3. Add any additional notes or comments about your preference.
4. If you would like to be contacted, provide your email address.
5. If you would like to be contacted, provide your phone number.
6. Enter your preferred location for the reunion.

## Field-by-Field Explanation

* **Location Preference** (`Location Preference`, `select_multiple`, required/optional): Select one or more locations that you would prefer for the reunion. You can choose multiple locations.
* **Attendance Likelihood** (`Attendance Likelihood`, `select_one`, required/optional): Indicate whether you are likely to attend the reunion.
* **Notes** (`Notes`, `note`, optional): Enter any additional comments or notes about your preference.
* **E-mail** (`E-mail`, `email`, optional): If you would like to be contacted about the reunion, provide your email address.
* **Phone** (`Phone`, `text`, optional): If you would like to be contacted about the reunion, provide your phone number.
* **Location** (`Location`, `text`, optional): Enter the location that you would prefer for the reunion.

## Tips
* Please select only one or more locations that you are interested in.
* Make sure to provide a valid email address if you would like to be contacted.
* Provide a valid phone number if you would like to be contacted by phone.
* Enter a clear and concise location for the reunion.
* If you have any comments or concerns about the reunion, feel free to add them in the notes field.
