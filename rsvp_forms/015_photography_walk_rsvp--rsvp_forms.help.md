# photography_walk_rsvp - Help Guide
## Purpose
This form is designed to collect information for a photography walk event.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in your participant details in the "participant_details" field.
2. Enter the event details in the "event_details" field.
3. Check the box to indicate if you will be taking photographs during the event ("photography_event").
4. Choose the date of the event from the calendar in the "photo_walk_date" field.
5. Select the time of the event from the time options in the "photo_walk_time" field.
6. Enter the event location in the "photo_walk_location" field.
7. Add any additional notes or comments about the event in the "photography_walk_notes" field.

## Field-by-Field Explanation

* **participant_details**: This field is used to collect your participant information. Please fill in your name and any other relevant details.
* **event_details**: This field is used to collect event information such as event description or details about the event.
* **photography_event**: This field is used to indicate if you will be taking photographs during the event. Please select "Yes" if you plan on taking photographs.
* **photo_walk_date**: This field is used to select the date of the event from the provided calendar.
* **photo_walk_time**: This field is used to select the time of the event from the provided options.
* **photo_walk_location**: This field is used to enter the location of the event.
* **photography_walk_notes**: This field is used for any additional comments or notes about the event. Please use this field for any information that does not fit in other fields.
