# Online Party RSVP Form - Help Guide
## Purpose
The Online Party RSVP Form is designed to be used for guests to RSVP to a party. It is a simple and easy-to-use form that collects the necessary details from guests to ensure the host has an accurate headcount and can plan accordingly.

## How To Complete This Form
To complete this form, simply follow these steps:

1. Click on the "Submit" button to start filling out the form.
2. Select your RSVP response from the dropdown menu.
3. Enter your guest count if you are bringing more than one person.
4. Enter any additional message for the host (optional).
5. Enter your phone number for the host to contact you (optional).
6. Click on the "Submit" button to submit your response.

## Field-by-Field Explanation
- **Party Details**: This field is used to enter any additional details about the party you are attending. Please keep this field brief, as it will be used by the host to note any important information.
- **RSVP Details**: Please select your response to the question "Are you able to attend the party?" from the dropdown menu. Select "Yes" if you are able to attend, and "No" if you are not able to attend.
- **Guest Count**: If you are bringing more than one person, please enter the total number of guests you will be bringing. This will help the host plan accordingly.
- **Message**: This is an optional field for you to enter any additional information you would like to share with the host. Please keep it brief and to the point.
- **Phone Number**: If you would like to be contacted by the host with any updates or information about the party, please enter your phone number in the format (123) 456-7890. This is an optional field and not required if you do not want to be contacted.
