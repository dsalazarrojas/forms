# sweet_16_celebration_survey - Help Guide
## Purpose
The sweet_16_celebration_survey form is used to collect information from guests attending a sweet 16 celebration event.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out each field carefully, providing accurate and relevant information.
2. Start with the Main Page, which serves as a general introduction to the form.
3. Proceed to the Guest Information page to provide details about the guest(s) attending.
4. On the Attending Status page, select the attending status of the guest(s).
5. On the RSVP Date page, enter the date by which the guest will RSVP.
6. On the Contact Info page, provide the contact information of the guest(s).
7. If necessary, enter any special requests or dietary restrictions.
8. On the Special Requests page, provide any additional requests or comments.
9. On the Party Info page, select the type of party the guest is attending (e.g., Main Course, Appetizer, etc.).
10. Select the Main Course, Appetizer, and Dessert preferences.
11. Select the beverages to be consumed during the event.
12. On the Guest Message page, provide any additional message or comment.
13. On the RSVP Time page, select the time by which the guest will RSVP.
14. On the Guests Attending page, select the type(s) of guests attending (e.g., Spouse, Child, etc.).
15. On the RSVP By page, select the method by which the guest will RSVP (e.g., Online, By Phone, etc.).

## Field-by-Field Explanation

* **Main Page** (`Main Page`, `note`, optional): This page serves as a general introduction to the form.
* **Guest Information** (`Guest Information`, `text`, optional): Provide details about the guest(s) attending, such as name, age, etc.
* **Attending Status** (`Attending Status`, `select_one`, optional): Select whether the guest is attending or not.
* **RSVP Date** (`RSVP Date`, `date`, optional): Enter the date by which the guest will RSVP.
* **Contact Info** (`Contact Info`, `text`, optional): Provide the contact information of the guest(s).
* **Special Requests** (`Special Requests`, `text`, optional): Enter any special requests or comments.
* **Special Dietary Restrictions** (`Special Dietary Restrictions`, `text`, optional): Enter any special dietary restrictions.
* **Guest Message** (`Guest Message`, `text`, optional): Provide any additional message or comment.
* **RSVP Time** (`RSVP Time`, `time`, optional): Select the time by which the guest will RSVP.
* **Party Info** (`Party Info`, `select_multiple`, optional): Select the type of party the guest is attending (e.g., Main Course, Appetizer, etc.).
* **Main Course Choice** (`Main Course Choice`, `select_one`, optional): Select the main course preference.
* **Appetizer Choice** (`Appetizer Choice`, `select_one`, optional): Select the appetizer preference.
* **Dessert Choice** (`Dessert Choice`, `select_one`, optional): Select the dessert preference.
* **Drink Choice** (`Drink Choice`, `select_one`, optional): Select the beverage preference.
* **Guests Attending** (`Guests Attending`, `select_multiple`, optional): Select the type(s) of guests attending (e.g., Spouse, Child, etc.).
* **RSVP By** (`RSVP By`, `select_one`, optional): Select the method by which the guest will RSVP (e.g., Online, By Phone, etc.).
