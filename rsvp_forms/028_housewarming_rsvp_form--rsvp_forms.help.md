# Housewarming RSVP Form - Help Guide
## Purpose
This form is designed to collect RSVP information from guests and hosts for a housewarming party.

## How To Complete This Form
1. **Attendee Information** (Page 1)
	* are_you_attending: Select 'Yes' if you are attending the party, 'No' otherwise.
2. **RSVP Details** (Page 2)
	* RSVP Date: Select the date you plan to attend the party.
	* RSVP Time: Select the time you plan to attend the party.
3. **Party Information** (Page 3)
	* Party Location: Enter the location of the party.
	* Guest Name: Enter the name of the guest you are attending with (if applicable).
	* Message to Guest: Leave a message for the guest (if applicable).
4. **Additional Guest Information** (Page 4)
	* Contact Number: Enter the contact number of the guest you are attending with (if applicable).
	* Email: Enter the email of the guest you are attending with (if applicable).
	* Additional Guests: Enter the number of additional guests you are bringing (if applicable).
5. **Host Information** (Page 5)
	* Host Name: Enter the name of the host.
	* Host Number: Enter the contact number of the host.
	* Host Email: Enter the email of the host.
6. **RSVP Confirmation** (Page 6)
	* Host RSVP Confirmation: Select 'Yes' if the host has confirmed their RSVP, 'No' otherwise.
7. **Message to Host** (Page 7)
	* Message to Host: Leave a message for the host.
8. **Host Details** (Page 8)
	* Host RSVP Time: Select the time the host plans to attend the party.
	* Host Date: Select the date the host plans to attend the party.
	* Additional Guests Host: Enter the number of additional guests the host is bringing (if applicable).
9. **RSVP Confirmation** (Page 9)
	* Host RSVP Confirmation: Select 'Yes' if the host has confirmed their RSVP, 'No' otherwise.
10. **Final Message** (Page 10)
	* Message to Host: Leave a message for the host.
11. **Finalize** (Page 11)
	* Form Submitted: A confirmation of the form submission status.
