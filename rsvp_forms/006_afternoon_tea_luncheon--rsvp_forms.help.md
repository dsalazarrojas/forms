# Afternoon Tea Luncheon - Help Guide

## Purpose
This form is designed to help the host plan and prepare for the Afternoon Tea Luncheon event. Please fill out the form to let us know if you'll be attending and to share your preferences for the event.

## How To Complete This Form
To complete this form, simply navigate through the pages, and fill out each field. You can select multiple options for some fields by checking the corresponding boxes.

## Field-by-Field Explanation

* **Full Name** (`full_name`, `text`, required): Enter your full name as you would like it to be listed for the event.
* **Number of Guests** (`guest_count`, `number`, required): Include yourself in the count, as this field asks for the total number of guests you plan to attend with.
* **Attending?** (`attendance_status`, `select_one`, required): Select either "Joyfully Accept" if you plan to attend, or "Regretfully Decline" if you cannot attend.
* **Dietary Restrictions** (`dietary_restrictions`, `select_multiple`, optional): If you have any dietary restrictions, such as vegetarian, vegan, gluten-free, dairy-free, or nut allergy, select all that apply.
* **Other Dietary Notes** (`dietary_notes`, `text`, optional): If you have any other dietary needs or allergies, please specify them here.
* **Preferred Tea Blend** (`tea_preference`, `select_one`, optional): Choose your favorite type of tea from the options provided.
* **Afternoon Tea Selection - Scones, Sandwiches, etc.** (`food_selection`, `select_multiple`, optional): Select your top choices for the buffet, including Cucumber Sandwiches, Smoked Salmon Blinis, Plain Scones with Clotted Cream, Fruit Tartlets, and Macarons.
* **-- Vintage Experience --** (`vintage_header`, `note`, optional): This is a note field for you to provide any information that will help set the mood for the event.
* **Song Request for the Event** (`song_request`, `text`, optional): If there's a specific song or type of music you'd like to hear during the event, let us know here.
* **Message to the Host** (`host_message`, `text`, optional): Leave a note or message for the host here if you'd like.

Tips:

* Please fill out this form as completely and accurately as possible to help us plan the event.
* If you have any questions or concerns, don't hesitate to contact the host directly.
