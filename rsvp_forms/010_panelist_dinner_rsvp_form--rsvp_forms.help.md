# Panelist Dinner RSVP Form - Help Guide
## Purpose
This form is used to gather information from panelists regarding their attendance and preferences for the dinner event.

## How To Complete This Form
1. Select your attendance status from the options provided.
2. Choose your dietary needs from the available options.
3. Select your meal choice from the options provided.
4. Enter the number of guests you plan to bring.
5. Enter the name of each guest, if applicable.
6. Enter the email address of each guest, if applicable.
7. Add any notes or comments, if desired.
8. Select the RSVP status you intend to submit.
9. Enter the date you intend to RSVP.
10. Select the time you intend to RSVP.
11. Choose which guest will be attending from the options provided.

## Field-by-Field Explanation
* **Attendance** (`id: 2`, `type: select_one`):
	+ Select whether you will be attending the dinner event.
* **Guest Count** (`id: 3`, `type: number`):
	+ Enter the number of guests you plan to bring.
* **Dietary Needs** (`id: 4`, `type: select_multiple`):
	+ Choose which dietary options you require.
* **Meal Choice** (`id: 5`, `type: select_one`):
	+ Select your preferred meal option.
* **Guest** (`id: 6`, `type: text`):
	+ Enter the name of each guest, if applicable.
* **Guest Name** (`id: 7`, `type: text`):
	+ Enter the name of each guest.
* **Guest Phone** (`id: 8`, `type: text`):
	+ Enter the phone number of each guest.
* **Guest Email** (`id: 9`, `type: email`):
	+ Enter the email address of each guest.
* **Note** (`id: 10`, `type: note`):
	+ Add any additional notes or comments, if desired.
* **RSVP Status** (`id: 11`, `type: select_one`):
	+ Select your intended RSVP status.
* **RSVP Date** (`id: 12`, `type: date`):
	+ Enter the date you intend to RSVP.
* **RSVP Time** (`id: 13`, `type: time`):
	+ Select the time you intend to RSVP.
* **Guest Attendee** (`id: 14`, `type: select_one`):
	+ Choose which guest will be attending from the options provided.

## Tips
* Please ensure that you fill out all required fields to ensure that your RSVP is complete.
* If you have any dietary needs or preferences, please select the relevant options.
* If you have any guests attending with you, please enter their information in the corresponding fields.
* Please select the correct RSVP status to ensure that we can plan for your attendance.
* If you have any additional notes or comments, please add them in the note field.
