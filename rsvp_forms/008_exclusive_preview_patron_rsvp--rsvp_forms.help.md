# Exclusive Preview Patron RSVP - Help Guide
## Purpose
This form is used to collect RSVPs (Respondents) for a preview event. To ensure accurate planning, it's crucial that users submit their attendance and any relevant information.

## How to Complete This Form
To fill out this form, follow these steps:

1. Confirm your attendance by selecting the event date and time that you plan to attend.
2. Enter the number of guests you will be bringing.
3. Choose any special needs that apply to you (e.g., wheelchair accessibility, service animal).
4. Select the event location where the event will take place.
5. If you need to provide additional information or have a special message for the host, enter it in the designated field.
6. Enter your email address so the host can contact you with event updates.
7. Enter your phone number, if available, for further contact.
8. Submit the form to confirm your RSVP.

## Field-by-Field Explanation
* **event_details**: This field is for you to enter any specific details about the event you're attending.
* **event_date**: Enter the date you plan to attend the event (e.g., 2024-03-14).
* **event_time**: Select the time of the event you plan to attend (e.g., 14:00).
* **rsvp**: Confirm your attendance by entering "Yes, I'm attending".
* **guests**: Enter the number of guests you plan to bring (e.g., 2).
* **special_needs**: Select any special needs you require, such as wheelchair accessibility or service animal.
* **rsvp_message**: Enter any additional information or message for the host (e.g., "I have a special request for the event").
* **email**: Enter your email address so the host can contact you with event updates (e.g., user@example.com).
* **phone**: Enter your phone number, if available, for further contact (e.g., 123-456-7890).
* **event_location**: Choose the location of the event (e.g., Location 1).

## Tips
* Please ensure that your information is accurate, as it will help the event host make necessary arrangements.
* If you need to make changes to your RSVP, contact the event host directly.
* If you're experiencing any issues while filling out this form, contact our support team.
