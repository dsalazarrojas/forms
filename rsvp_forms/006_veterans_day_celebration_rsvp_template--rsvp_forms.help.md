# Veterans Day Celebration RSVP Template - Help Guide
## Purpose
The Veterans Day Celebration RSVP Template is a form designed to collect information from attendees about their attendance status and any special requests or additional comments for the Veterans Day celebration event.

## How To Complete This Form
1. Please fill out the form below with the requested information.
2. Ensure you fill in all required fields (indicated by an asterisk \*).
3. You can select multiple options for the "Event Attendance Status" field if applicable.
4. If you have any special requests or additional comments, please enter them in the "Additional Comments" field.
5. If you are bringing any guests, please fill in their names in the corresponding fields (e.g. "Name of Guest", "Name of Guest 2", etc.).

## Field-by-Field Explanation
* **Guest Name**: Please enter your own name as you would like it to be listed on the event program.
* **Attending Date**: Select the date you plan to attend the event (Veterans Day).
* **Event Attendance Status**: Select all applicable options to indicate your event attendance status. Please be honest and accurate about your intentions.
* **RSVP By**: Enter the date you plan to RSVP by, which is the last date you can make changes to your response.
* **Contact Number**: Enter a contact number where the event organizer can reach you for any updates or changes.
* **Email**: Enter your email address for the event organizer to use for communication.
* **Additional Comments**: If you have any special requests or additional comments, please enter them here.
* **Special Requests**: If you have any special requests (e.g., dietary restrictions, accessibility needs), please enter them here.
* **Name of Guest 1**, **Name of Guest 2**, **Name of Guest 3**, **Name of Guest 4**: If you are bringing any guests, please enter their names here.
* These fields are optional, but please fill them in if you are bringing any guests.
