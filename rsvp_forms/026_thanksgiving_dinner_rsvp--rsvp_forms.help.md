# Thanksgiving Dinner RSVP - Help Guide

## Purpose
This form is for guests to RSVP to a Thanksgiving dinner event. Please complete this form to let us know if you can attend, and provide any necessary information for the host to prepare.

## How To Complete This Form
To complete this form, simply follow these steps:
1. Enter your guest name in the **Guest Name** field. This is a required field.
2. Indicate your **attending** status in the **attending** field. Select one of the following:
	* True (I will attend)
	* False (I will not attend)
	* Maybe (I'm unsure)
3. (Optional) If you have a date to RSVP, please enter it in the **RSVP Date** field in the format YYYY-MM-DD.
4. If you're bringing guests, enter the number of guests in the **Number of Guests** field.
5. (Optional) If you have any special requests, enter them in the **Special Requests** field.
6. (Optional) If you'd like to indicate when you plan to arrive for the dinner, select a time in the **RSVP Time** field.
7. If you have an email address, enter it in the **Email** field to enable us to contact you.
8. If you'd like to leave your phone number, enter it in the **Phone** field.
9. If you'd like to leave any comments, enter them in the **Comments** field.
10. If you'd like to include a message for the host, enter it in the **Message** field.
11. If you're bringing a guest, select the number of guests in the **Bring a guest** field. You can select multiple options.

## Field-by-Field Explanation
* **Guest Name** (text, required): Enter your name as a guest.
* **attending** (select_one, required): Indicate your attending status.
* **RSVP Date** (date, optional): If you have a specific date to RSVP, enter it in the format YYYY-MM-DD.
* **Number of Guests** (number, optional): If you're bringing guests, enter the number of guests.
* **Special Requests** (text, optional): If you have any special requests, enter them here.
* **RSVP Time** (time, optional): If you'd like to indicate when you plan to arrive, select a time.
* **Email** (email, optional): If you'd like to enter your email address, do so here.
* **Phone** (text, optional): If you'd like to enter your phone number, do so here.
* **Comments** (text, optional): If you'd like to leave any comments, enter them here.
* **Message** (note, optional): If you'd like to leave a message for the host, enter it here.
* **Bring a guest** (select_multiple, optional): If you're bringing a guest, select the number of guests.
