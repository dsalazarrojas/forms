# Sensory Event Registration - Help Guide
## Purpose
This guide will walk you through the Sensory Event Registration form to help you complete it accurately and efficiently. The form is designed to gather information about your attendance and preferences for a sensory event.

## How To Complete This Form
To complete this form, follow these steps:
1. Fill in your **First Name** (ID: 1) and **Last Name** (ID: 2) accurately.
2. Enter your **Email** (ID: 3) and **Phone** (ID: 4) to ensure we can contact you about the event.
3. Provide the **Event Date** (ID: 5) and **Event Time** (ID: 6) of the event you're registering for.
4. If the event has a duration, enter the **Session Duration** (ID: 7) in minutes.
5. For **Accessibility Request** (ID: 8) and **Accessibility Request Description** (ID: 9), please let us know about any necessary arrangements you need for a comfortable and inclusive event experience. Be as detailed as possible.
6. Choose one of the options in **RSVP** (ID: 10) to indicate your attendance status:
	* **Yes, I will be attending**
	* **No, I will not be attending**
	* **Maybe, I'm still checking**
7. If you're attending, provide a brief description of your intentions in **RSVP Description** (ID: 11).
8. You can add any additional comments in **RSVP Comments** (ID: 12) if needed.
9. Choose your preferred **Session Preferences** (ID: 13) from the options:
	* **Indoor**
	* **Outdoor**
	* **Online**
10. In case of **Session Preferences Description** (ID: 14), feel free to provide more details about your preference.
11. Finally, select the **Event Type** (ID: 15) from the available options:
	* **Workshop**
	* **Conference**
	* **Meeting**
	* **Lecture**

## Field-by-Field Explanation
### First Name (ID: 1)
Your **First Name** is the first name you are known by.
* Type: Text
* Required: False
* Hint: This will help us identify you in event communication and materials.

### Last Name (ID: 2)
Your **Last Name** is the last name you are known by.
* Type: Text
* Required: False
* Hint: This will help us identify you in event communication and materials.

### Email (ID: 3)
Your **Email** is the address where you can be reached.
* Type: Email
* Required: False
* Hint: Use the same email address you use for event notifications and updates.

### Phone (ID: 4)
Your **Phone** is the number we can use to call you about the event.
* Type: Text
* Required: False
* Hint: Use your primary phone number for event organizers to contact you.

### Event Date (ID: 5)
Provide the date of the event.
* Type: Date
* Required: False

### Event Time (ID: 6)
Provide the time of the event.
* Type: Time
* Required: False

### Session Duration (ID: 7)
If the event has a duration, enter the time in minutes.
* Type: Number
* Required: False

### Accessibility Request (ID: 8)
If you have any special requirements, describe them here.
* Type: Text
* Required: False

### Accessibility Request Description (ID: 9)
Provide details about your accessibility request.
* Type: Text
* Required: False

### RSVP (ID: 10)
Choose your attendance status:
	* **Yes, I will be attending**
	* **No, I will not be attending**
	* **Maybe, I'm still checking**
* Type: Select Multiple
* Required: False

### RSVP Description (ID: 11)
If you're attending, provide a brief description of your intentions.
* Type: Text
* Required: False

### RSVP Comments (ID: 12)
Add any additional comments about your RSVP.
* Type: Text
* Required: False

### Session Preferences (ID: 13)
Choose your preference for the event location:
	* **Indoor**
	* **Outdoor**
	* **Online**
* Type: Select One
* Required: False

### Session Preferences Description (ID: 14)
Provide details about your session preferences.
* Type: Text
* Required: False

### Event Type (ID: 15)
Select the type of event:
	* **Workshop**
	* **Conference**
	* **Meeting**
	* **Lecture**
* Type: Select One
* Required: False

## Tips
* Be accurate when filling in your information to avoid any confusion.
* Double-check your responses for correct formatting.
* If you have any difficulties or questions, contact event organizers or support for assistance.
