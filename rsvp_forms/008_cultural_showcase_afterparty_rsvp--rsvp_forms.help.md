# Cultural Showcase Afterparty RSVP - Help Guide
## Purpose
This form is designed to collect RSVP information from guests attending a cultural showcase afterparty. You will provide your name, contact information, and other relevant details to help us plan for your presence.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the number of guests attending with you.
2. Choose the name of each guest.
3. Select the dietary needs of each guest.
4. Enter the name and contact information of each guest.
5. Provide any additional notes or comments about each guest.
6. Choose the date and time you plan to attend.
7. Confirm your start and end times.

## Field-by-Field Explanation
- **Guest Count** (`guest_count`, number, required): Please select the number of guests attending with you.
- **RSVP** (`rsvp`, select_one, required): Choose how many guests you are RSVPing for.
  - Guest 1
  - Guest 2
  - Guest 3
- **Guest Name** (`guest_name`, text, required): Enter the name of each guest.
- **Guest Email** (`guest_email`, email, required): Enter a valid email address for each guest.
- **Guest Phone** (`guest_phone`, text, optional): Enter a contact phone number for each guest.
- **Note** (`note`, note, optional): Add any additional notes or comments about each guest.
- **Guests Dietary Needs** (`dietary_needs`, select_multiple, optional): Choose the dietary needs for each guest.
  - Veggie
  - Non Veggie
  - Other
- **RSVP Date** (`rsvp_date`, date, required): Select the date you plan to attend.
- **Start Time** (`start_time`, time, required): Choose the start time of the event.
- **End Time** (`end_time`, time, required): Choose the end time of the event.

## Tips
Remember to complete the form for each guest attending with you. If you have any specific dietary needs or requirements, please let us know so we can ensure we can cater to them.
