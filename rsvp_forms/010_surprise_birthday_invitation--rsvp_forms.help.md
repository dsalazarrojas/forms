# Surprise Birthday Invitation - Help Guide
## Purpose
This form is designed to collect RSVP information and optional messages from guests for a surprise birthday event.

## How To Complete This Form
1. Select your attendance by choosing 'Yes' or 'No' from the "Guests" dropdown.
2. If you are attending, enter a message for the birthday recipient in the "Guest's message" field.
3. Select your availability by choosing 'Yes' or 'No' for "RSVP starts at", "RSVP ends at", and "RSVP closes at".
4. Enter a valid time for "RSVP open at" if you are choosing 'Yes' for the "RSVP starts at" field.
5. Optionally, you can send a message to the birthday recipient with your RSVP.

## Field-by-Field Explanation
* **Guests**: Choose whether you are attending the surprise birthday event by selecting 'Yes' or 'No' from the dropdown.
* **Guest's message**: Enter a message for the birthday recipient if you are attending.
* **RSVP starts at**: Select 'Yes' if you are attending the event and it starts at a specific time. This may require you to enter a valid time in the "RSVP open at" field.
* **RSVP ends at**: Select 'Yes' if you are attending the event and it ends at a specific time.
* **RSVP closes at**: Select 'Yes' if you want to know when the RSVPs will close.
* **RSVP open at**: Enter a valid time if you selected 'Yes' for the "RSVP starts at" field.
* **Birthday recipient**: Enter the name of the birthday recipient.
* **Guest's message**: This is an optional field where you can send a personal message to the birthday recipient.
