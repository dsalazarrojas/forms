# Holiday Gathering Schedule - Help Guide

## Purpose
The "Holiday Gathering Schedule" form is used to collect and organize information about holiday gatherings. It helps in tracking and planning for team-building, social events, or corporate gatherings.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the **Host Name** of the holiday gathering.
2. Indicate if there is a **Guest List** by selecting "Yes" or "No" from the dropdown menu.
3. Select the **Date** of the event using the date picker.
4. Select the **Time** of the event using the time picker.
5. Enter the **Address** where the event is taking place.
6. Enter the **Phone Number** of the host or contact person.
7. Enter the **Email** of the host or contact person.

## Field-by-Field Explanation
- **Host Name (host_name)**: Enter the name of the person or organization hosting the holiday gathering. 
- **Guest List (guest_list)**: Indicate if there is a guest list present at the event. Select "Yes" if there is a list, "No" otherwise. 
- **Date (date)**: Select the date of the holiday gathering. 
- **Time (time)**: Select the time of the holiday gathering. 
- **Address (address)**: Enter the address where the event is taking place. 
- **Phone Number (phone_number)**: Enter the phone number of the host or contact person. 
- **Email (email)**: Enter the email of the host or contact person. 

## Tips
- Double-check the accuracy of the form details before submission.
- Ensure that the form is completed only once a year.
- If you are unsure about any field, please contact the event organizer or your supervisor.
