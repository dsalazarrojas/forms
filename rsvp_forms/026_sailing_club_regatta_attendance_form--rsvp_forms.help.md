# sailing_club_regatta_attendance_form - Help Guide
## Purpose
The sailing_club_regatta_attendance_form is a tool for sailing club members to RSVP to regatta events and provide additional information about their attendance.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the event title in the "Sailing Club Regatta Attendance Form" field.
2. Select the category of the event from the drop-down menu.
3. If desired, enter a brief description of the event.
4. Choose the category and description for the event from the "Form Category" and "Form Description" fields.
5. Enter the name of the output file (if desired).
6. Select the tool(s) used during the event.
7. Enter the tool(s) assigned to the event.
8. Enter the unique form ID (if desired).
9. Enter the title, category, and description of the event for a second time (this is likely an error in the schema and will be ignored for now).
10. Submit the form to complete your RSVP and provide additional information.

## Field-by-Field Explanation
* **Sailing Club Regatta Attendance Form** (text, required): Enter the name of the event.
* **Category** (select_one, optional): Choose the type of event (Sailing, Racing, Training, or Casual).
* **Description** (note, optional): Provide a brief description of the event.
* **Form Category** (select_multiple, optional): Select the category for the form, which includes combinations of sailing and other activities.
* **Form Description** (date, optional): Enter the date of the form, which is likely a date of creation or submission.
* **Output File** (text, optional): Enter the name of the output file (if desired).
* **Tool** (select_one, optional): Choose the tool(s) used during the event.
* **Assigned Tool** (select_multiple, optional): Choose the tool(s) assigned to the event.
* **Form ID** (text, optional): Enter the unique ID for the form (if desired).
* **Title** (text, optional): Enter the title of the event (this is a duplicate field and will be ignored).
* **Form Category 2** (text, optional): Enter the category of the event (this is a duplicate field and will be ignored).
* **Form Description 2** (text, optional): Enter a description of the event (this is a duplicate field and will be ignored).

## Tips
* Make sure to complete all required fields to ensure your RSVP is processed correctly.
* If you select a tool, make sure it is also assigned to the event.
* If you select multiple tools, make sure they are all assigned to the event.
