# Corporate Rebranding Event RSVP - Help Guide

## Purpose
This form is designed to collect RSVPs for a corporate rebranding event. Please fill out this form to let us know if you will be attending the event.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out all required fields.
2. Choose your RSVP method and date/time.
3. Select the event type (e.g., Meeting, Conference, Lunch, Cocktail Party).
4. If you are bringing guests, select the relevant options from the drop-down list.
5. Enter any special requests you may have.
6. Enter your event details (date, time, location, etc.) and your company name (if applicable).

## Field-by-Field Explanation

* **Event Details** (id: 1): This section contains information about the event itself. Fill in the date, time, and other event details as they are requested.
* **name** (id: 2): Please enter your name here.
* **Date** (id: 3): Enter the date of the event you are planning to attend.
* **Time** (id: 4): Enter the time of the event you are planning to attend.
* **Company** (id: 5): If you are attending the event as a representative of a company, enter the name of the company here.
* **Contact** (id: 6): Enter your email address or other contact information so we can reach you with any updates or questions.
* **RSVP Method** (id: 7): Choose how you plan to RSVP for the event (e.g., email, phone, etc.).
* **Comments** (id: 8): If you have any additional comments or notes about the event, enter them here.
* **Attending Guests** (id: 9): If you are bringing guests, select them from the provided options.
* **Special Requests** (id: 10): If you have any special requests (e.g., dietary restrictions), enter them here.
* **RSVP Date** (id: 11): This section is not used (please don't fill it in).
* **RSVP Time** (id: 12): This section is not used (please don't fill it in).
* **RSVP Method** (id: 13): This section is not used (please don't fill it in).
* **Comments** (id: 14): If you have any additional comments or notes about the event, enter them here.
* **Event Type** (id: 15): Choose the type of event you are attending (e.g., Meeting, Conference, Lunch, Cocktail Party).
* **Company Name** (id: 16): If you are attending as a representative of a company, enter the name of the company here.
* **Event Location** (id: 17): Enter the location of the event.
* **Guest Count** (id: 18): If you are bringing guests, please enter the number of guests you are planning to bring.

**Tips**

* Make sure to complete all required fields.
* Double-check your RSVP details before submitting the form.
* If you have any special requests, please enter them in the "Special Requests" field.
* If you are bringing guests, make sure to select them from the provided options.
* If you have any additional comments or notes, please enter them in the "Comments" field.
