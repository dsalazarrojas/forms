# Nonprofit Appreciation Brunch RSVP Form - Help Guide
## Purpose
The purpose of this form is to collect RSVP information for a Nonprofit Appreciation Brunch event. This information will be used to plan and prepare for the event.

## How To Complete This Form
1. Fill out all the required fields, indicated by *required* in the field label.
2. Use the provided hints as guidance for entering your information.
3. If a field has options, select the most relevant option that applies to you.

## Field-by-Field Explanation

* **Guest Name (id: 1)** (`Guest Name`, text, required: false): Please enter the name of the guest(s) attending the event.
* **RSVP Date (id: 2)** (`RSVP Date`, date, required: false): Select the date you will be attending the brunch.
* **Number of Guests (id: 3)** (`Number of Guests`, number, required: false): Enter the number of guests attending with you.
* **Contact Method (id: 4)** (`Contact Method`, select_one, required: false): Choose how you would like to be contacted (Phone, Email, or Other).
* **RSVP Status (id: 5)** (`RSVP Status`, select_multiple, required: false): Indicate your RSVP status (Attending, Declined, or Maybe).
* **Additional Guests (id: 6)** (`Additional Guests`, number, required: false): Enter the number of additional guests attending with you.
* **Comments (id: 7)** (`Comments`, note, required: false): Share any comments or special requests with the event organizers.
* **Email (id: 8)** (`Email`, email, required: false): Enter your email address if you would like to be contacted.
* **Phone (id: 9)** (`Phone`, text, required: false): Enter your phone number if you would like to be contacted.
* **Address (id: 10)** (`Address`, text, required: false): Enter your address if you would like to be contacted or if you need to provide a physical address for the event.

## Tips
* Please fill out the form accurately and completely.
* If you have any special requests or comments, use the Comments field.
* If you need to be contacted, use the Email or Phone fields to provide your contact information.
