# Event RSVP Form - Help Guide

## Purpose
This form is used to RSVP (response to an invitation) for an event or meeting. It helps collect essential details such as attendance status, contact information, and any additional notes.

## How To Complete This Form
To complete this form, please follow the steps below:

1.  Fill in your attendance status for the event. Please choose "True" if you can attend, and "False" if you cannot.
2.  Fill in your email address so we can contact you about the event.
3.  Fill in your phone number so we can contact you about the event.
4.  Optionally, you can add a personal message or note about your attendance if you'd like.

## Field-by-Field Explanation

* **Event Name (Event Name)** (`event_name`, text, **Required**): Please fill in the name of the event you are RSVPing for.
* **Event Date (Event Date)** (`event_date`, date, **Required**): Please fill in the date of the event you are RSVPing for.
* **Contact Email (Contact Email)** (`contact_email`, email, **Required**): Please fill in your email address so we can contact you about the event. This should be a valid email address.
* **Contact Phone (Contact Phone)** (`contact_phone`, text, **Required**): Please fill in your phone number so we can contact you about the event. This should be a valid phone number.
* **Attending (Attending)** (`attending`, select_one, **Required**): Please choose "True" if you can attend the event, and "False" if you cannot.
* **Note (Note)** (`note`, note, **Optional**): This field is optional, but if you'd like to add any additional notes about your attendance, please use this field.
* **RSVP Message (RSVP Message)** (`rsvp_message`, text, **Optional**): This field is optional, but if you'd like to add a personal message about your attendance, please use this field.
