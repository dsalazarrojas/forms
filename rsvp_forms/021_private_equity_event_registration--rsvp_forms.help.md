# Private Equity Event Registration - Help Guide
## Purpose
This form is designed to collect information about private equity events. It helps to gather accurate and standardized data points about each event, ensuring consistency and reducing the risk of duplication.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the type of event from the "Event Type" dropdown menu.
2. Enter the name of the investor associated with the event.
3. Select the date of the event using the date picker.
4. Enter the start time of the event.
5. Enter the session time of the event.
6. Enter the name of the venue where the event will take place.
7. Enter the address of the venue (optional).
8. Select the status of the event (Pending, Live, or Ended).
9. Enter the number of attendees expected to attend the event.
10. Provide any additional session planning information (optional).
11. If applicable, enter the attendee communications details (optional).

## Field-by-Field Explanation
* **Event Type** (Event Type, required): Select the type of event (Investor Event or Private Equity Event) to accurately categorize the event.
* **Investor Name** (Investor Name, required): Enter the name of the investor associated with the event.
* **Event Date** (Event Date, required): Select the date of the event using the date picker. This is the date when the event will take place.
* **Event Time** (Event Time, required): Enter the start time of the event. This is the time when the event will start.
* **Session Time** (Session Time, required): Enter the session time of the event. This is the time allocated for the event session.
* **Venue Name** (Venue Name, required): Enter the name of the venue where the event will take place.
* **Venue Address** (Venue Address, optional): Enter the address of the venue (if applicable).
* **Event Status** (Event Status, required): Select the status of the event (Pending, Live, or Ended) to reflect its current state.
* **Attendees** (Attendees, required): Enter the expected number of attendees for the event.
* **Session Planning** (Session Planning, optional): Provide any additional information related to the session planning.
* **Attendee Communications** (Attendee Communications, optional): If applicable, enter the details of attendee communications.

**Tips**

* Make sure to select the correct event type to ensure accurate categorization.
* Double-check the date and time to ensure consistency with other records.
* Enter the correct venue name and address for accurate location identification.
* Be accurate in counting the number of expected attendees.
* Use clear and concise language in the "Session Planning" and "Attendee Communications" fields if applicable.
* Review the form carefully before submitting to ensure all required fields are completed correctly.
