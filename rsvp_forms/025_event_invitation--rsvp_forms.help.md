# Event Invitation - Help Guide
## Purpose
This form is designed to collect information about an event invitation, including the title, guest name, date, and time.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the title of the event in the "Event Title" field.
2. Enter the name of the guest you are inviting in the "Guest Name" field.
3. Select the date of the event from the calendar in the "Event Date" field.
4. Choose the time of the event from the dropdown menu in the "Event Time" field.

## Field-by-Field Explanation

* **Event Title** (`event_invitation`, text, required): Enter the title of the event, e.g., "Summer BBQ" or "Company Holiday Party".
* **Guest Name** (`guest_name`, text, optional): Enter the name of the guest you are inviting.
* **Event Date** (`event_date`, date, optional): Select the date of the event from the calendar.
* **Event Time** (`event_time`, time, optional): Choose the time of the event from the dropdown menu.

## Tips

* Make sure to double-check the event details before submitting the form.
* If you are unsure about any of the fields, ask the event organizer for clarification.
* You can fill out this form multiple times if you need to send out multiple invitations.
