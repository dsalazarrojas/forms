# Monthly Bookkeeping Confirmation Form - Help Guide
## Purpose
The Monthly Bookkeeping Confirmation Form is used to confirm the completion of monthly bookkeeping tasks.

## How To Complete This Form
To complete this form, follow these steps:

1. Review the current status of monthly bookkeeping tasks.
2. Select the correct status for each task from the options provided.
3. If a task is not completed, add a follow-up note in the "Follow-ups" text field.
4. Confirm the date and time of the confirmation.

## Field-by-Field Explanation
- **Confirm Monthly Bookkeeping** (`confirm_monthly_bookkeeping`, select_one, required/optional): Choose whether monthly bookkeeping tasks have been completed.
	* This field is used to indicate whether all tasks have been finished.
	* Select "Yes" if tasks have been completed, or "No" if they are not.
- **Month End Tasks Confirmed** (`month_end_tasks_confirmed`, select_multiple, required/optional): Confirm the completion of specific month-end tasks.
	* This field is used to confirm which tasks have been completed for the current month.
	* Select all tasks that have been finished.
- **Follow-ups** (`follow_ups`, text, optional): Add any follow-up notes.
	* This field is used to record any additional comments or notes about tasks that need to be followed up on.
	* Add any relevant information about tasks that were not completed.
- **Recurring Data Collection** (`recurring_data_collection`, select_one, required/optional): Confirm the collection of recurring data.
	* This field is used to confirm whether recurring data has been collected.
	* Select "Yes" if data has been collected, or "No" if it has not.
- **Data Confirmed** (`data_confirmed`, select_multiple, required/optional): Confirm the confirmation of data.
	* This field is used to confirm which data has been verified.
	* Select all data that has been verified.
- **Confirm Date** (`confirm_date`, date, required/optional): Confirm the date of confirmation.
	* This field is used to confirm the date of completion.
	* Enter a date in the format MM/DD/YY or YYYY-MM-DD.
- **Confirm Time** (`confirm_time`, time, required/optional): Confirm the time of confirmation.
	* This field is used to confirm the time of completion.
	* Enter a time in the format HH:MM or HH:MM AM/PM.
