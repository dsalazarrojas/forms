# Budget Conference Entry Confirmation Form - Help Guide
## Purpose
The Budget Conference Entry Confirmation Form is a tool used to collect and confirm attendee information for a conference event.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the attendee's **full name** in the "Attendee name" field.
2. Provide the **registration ID** or confirmation number in the "Registration ID" field.
3. Select the **conference sessions** the attendee has chosen to attend (optional).
4. Check the **payment status** of the attendee (required).
5. Enter the attendee's **contact email** for conference updates (required).
6. Optionally, provide any **special requirements** the attendee may have (e.g., dietary needs or mobility requirements).
7. Finally, enter the **badge name** to display on the attendee's badge (optional) and add any **confirmation notes** (optional).

## Field-by-Field Explanation
- **Attendee name** (`attendee_name`, text, required): Enter the full name of the conference attendee.
  - This field is required to ensure we have accurate information about the attendee.
  - Please use the full name (first and last name) as it appears on the registration form.
- **Registration ID** (`registration_id`, text, required): Enter the confirmation or registration number provided to the attendee.
  - This field is necessary to confirm the attendee's registration status.
  - Enter the exact number or code given to the attendee during registration.
- **Session choices** (`session_choices`, select_multiple, optional): Select the conference sessions the attendee has chosen to attend.
  - This field is optional, but if filled, it helps us confirm the attendee's session choices.
  - Choose one or more from the options provided (e.g., Keynote, Workshop A, Workshop B, Panel discussion).
- **Special requirements** (`special_requirements`, text, optional): Enter any special requirements the attendee may have (e.g., dietary needs or mobility requirements).
  - This field is optional, but if the attendee has specific needs, please fill this out so we can accommodate them properly.
  - Please use clear and specific language when describing the requirements.
- **Payment status** (`payment_status`, select_one, required): Confirm the attendee's payment status.
  - This field is required to ensure accurate payment tracking.
  - Choose from the options: Paid, Pending, or Waived.
- **Contact email** (`contact_email`, email, required): Enter the attendee's email address for conference updates.
  - This field is necessary for us to send important updates and information to the attendee.
  - Enter the attendee's email in a format like "john.doe@example.com".
- **Badge name** (`badge_name`, text, optional): Enter the name to display on the attendee's badge.
  - This field is optional, but if filled, it helps us create a personalized badge for the attendee.
  - Please use a name that is easy to read and fits the space provided.
- **Confirmation notes** (`confirmation_notes`, text, optional): Enter any additional confirmation details or notes.
  - This field is optional, but if you have any extra information to share, please add it here.
  - Keep it brief and clear, as it will be used for our reference.

## Tips
* Please fill out the form accurately and completely to ensure we have the correct information about the attendee.
* If you're unsure about any field, please contact us for clarification.
* For security reasons, we recommend using a secure connection when filling out this form.
* If you have any questions or concerns, please don't hesitate to reach out to us.
* Make sure to save the confirmation details and keep them on file for future reference.
* The form fields may be subject to change or updates; please follow any updates and modifications accordingly.
