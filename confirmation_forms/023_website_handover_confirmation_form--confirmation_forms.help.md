# website_handover_confirmation_form - Help Guide
## Purpose
The website handover confirmation form is used to confirm the transfer of ownership of a website between two parties. This form helps to track the progress and status of the handover process.

## How To Complete This Form
1. Select the correct Project Details from the dropdown menu.
2. Enter the Transfer Date and Transfer Time if applicable.
3. Enter the Website URL of the website being transferred.
4. Choose the correct Transfer Method (e.g., FTP, SFTP, WebDAV, or Other).
5. Select the Transfer Status (e.g., Pending, In Progress, Complete, or Cancelled).
6. If required, enter a Confirmation Code.
7. Enter your Email address if you wish to be notified about the handover status updates.

## Field-by-Field Explanation
* **Project Details** (Required): Select the correct project from the dropdown menu that the handover is related to.
* **Transfer Date** (Optional): Date the handover is scheduled to take place.
* **Transfer Time** (Optional): Time the handover is scheduled to take place.
* **Website URL** (Optional): URL of the website being transferred.
* **Transfer Method** (Required): Select how the handover will be performed (e.g., FTP, SFTP, WebDAV, or Other).
* **Transfer Status** (Required): Select the current status of the handover (e.g., Pending, In Progress, Complete, or Cancelled).
* **Confirmation Code** (Optional): Enter a confirmation code if required.
* **Email** (Optional): Enter your email address to receive notifications about handover status updates.
