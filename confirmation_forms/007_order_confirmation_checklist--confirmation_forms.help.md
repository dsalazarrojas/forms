# Order Confirmation Checklist - Help Guide
## Purpose
This form is used to confirm and document all necessary information related to customer orders, including customer details, order details, shipping information, payment data, tracking numbers, and order status updates. It ensures that all required information is collected and recorded accurately.

## How To Complete This Form
To complete this form, please follow the steps below:

1. Review each page carefully and ensure you have all the necessary information for the corresponding section.
2. Enter the customer details in the "Customer Details" page (Page 1).
3. Enter the order details in the "Order Details" page (Page 2).
4. Enter the shipping information in the "Shipping Info" page (Page 3).
5. If applicable, enter the payment information in the "Payment Info" page (Page 4). Note that this field is not required.
6. Enter the tracking information in the "Tracking Info" page (Page 5).
7. Enter the review information in the "Review Info" page (Page 6).
8. Update the order status in the "Order Status" page (Page 7).
9. Add any additional notes in the "Notes" page (Page 8).

## Field-by-Field Explanation

* **Customer Details (Customer Details, Text, Required)**: This field is used to collect the customer's name and contact information.
* **Order Details (Order Details, Text, Required)**: This field is used to enter the order's description, date, or any other relevant details.
* **Shipping Info (Shipping Info, Text, Required)**: This field is used to collect the shipping address and other relevant information.
* **Payment Info (Payment Info, Text, Optional)**: This field is used to store payment method and amount information. Note that this field is not required.
* **Tracking Info (Tracking Info, Text, Required)**: This field is used to input the tracking number for the order.
* **Review Info (Review Info, Text, Required)**: This field is used to collect any review comments or feedback from the customer.
* **Order Status (Order Status, Text, Required)**: This field is used to update the order status, such as "Delivered" or "Shipped".
* **Notes (Notes, Note, Optional)**: This field is used to add any additional comments or notes about the order.

## Tips
* Please ensure that all required fields are completed accurately.
