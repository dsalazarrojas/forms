# event_confirmation_form - Help Guide
## Purpose
The event_confirmation_form is designed to gather information about an event, including its details, date, time, location, and status.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the event_details field with the relevant information about the event.
2. Enter the event date in the format YYYY-MM-DD.
3. Enter the start and end times of the event.
4. Provide a description of the event in the event_description field.
5. Enter the event location in the event_location field.
6. Select the time zone of the event from the options provided.
7. Select the current status of the event from the options provided.
8. Enter the number of attendees you are confirming to attend the event in the confirm_attendance_count fields.

## Field-by-Field Explanation
* **Event Details** (`event_details`, `text`, required/optional): Enter a brief description of the event.
* **Event Date** (`event_date`, `date`, required/optional): Enter the date of the event in the format YYYY-MM-DD.
* **Event Start Time** (`event_start_time`, `time`, required/optional): Enter the start time of the event.
* **Event End Time** (`event_end_time`, `time`, required/optional): Enter the end time of the event.
* **Event Description** (`event_description`, `text`, required/optional): Enter a brief description of the event.
* **Event Location** (`event_location`, `text`, required/optional): Enter the location of the event.
* **Event Time Zone** (`event_time_zone`, `select_one`, required/optional): Select the time zone of the event.
* **Event Status** (`event_status`, `select_multiple`, required/optional): Select the current status of the event.
* **Confirm Attendance** (`confirm_attendance`, `number`, required/optional): Enter the number of attendees you are confirming to attend the event.
* **Confirm Attendance Count** (`confirm_attendance_count`, `number`, required/optional): Enter the number of attendees you are confirming to attend the event.
* **Confirm Attendance Count 2** (`confirm_attendance_count_2`, `number`, required/optional): Enter the number of attendees you are confirming to attend the event.
* **Confirm Attendance Count 3** (`confirm_attendance_count_3`, `number`, required/optional): Enter the number of attendees you are confirming to attend the event.
