# Photo Release Consent Form - Help Guide

## Purpose
This form is used to obtain the owner's consent to use their photos. It's essential to get their consent before sharing their photos.

## How To Complete This Form

1. To complete this form, select the answer options for the fields as instructed below.
2. Make sure to provide the correct answers according to the photo owner's preferences.

## Field-by-Field Explanation

* **Photo Release** (`photo_release_consent_form`, select_multiple, required/optional): Select either "Yes" or "No" to indicate if you want to use the photo owner's photo.
* **Photo Owner** (`photo_owner`, text, required/optional): Enter the name of the photo owner.
* **Acquiring Party** (`photo_acquiring_party`, text, required/optional): Enter the name of the party acquiring the photo.
* **Purpose Allowed** (`purpose_allowed`, select_one, required/optional): Select "Yes" if the photo use is allowed for any of the purposes specified below.
* **Purpose Disallowed** (`purpose_disallowed`, select_one, required/optional): Select "Yes" if the photo use is disallowed for any of the specified purposes.
* **Other (please specify)** (`purpose_other`, text, required/optional): If the photo use is not for any of the specified purposes, please specify the purpose here.
* **Date of Capture** (`date_of_capture`, date, required/optional): Enter the date the photo was captured.
* **Signature** (`signature_photo`, text, required/optional): Enter your signature to confirm your acceptance of the photo release form.
* **Date Signed** (`signature_date`, date, required/optional): Enter the date you signed this form.

## Tips

* Please make sure to get the photo owner's consent before sharing their photos.
* Be honest and truthful when answering the questions.
* If you're unsure about any field, please ask for help or clarification.
