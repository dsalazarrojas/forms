# kings_and_queens_photography_order_form - Help Guide
## Purpose
This form is designed for internal use to collect information for photography orders.

## How To Complete This Form
To complete this form, follow these steps:
1. Fill in the required fields, which are marked as "required".
2. Select the package type and photography packages from the available options.
3. Enter the date and time of the order.
4. Provide a note about the order, if necessary.
5. Enter your email address and phone number.

## Field-by-Field Explanation
* **Order Form** (`order_form`, text, optional): Enter a brief description of the order.
* **Package Type** (`package_type`, select_multiple, required): Select one or more package types that best fit your order.
* **Photography Packages** (`photography_packages`, select_multiple, required): Select one or more photography packages that you need.
* **Date** (`date`, date, optional): Enter the date of the order.
* **Time** (`time`, time, optional): Enter the time of the order.
* **Note** (`note`, note, required): Provide any additional information about the order.
* **Email** (`email`, email, optional): Enter your email address.
* **Phone** (`phone`, text, required): Enter your phone number.

## Tips
* Make sure to fill in all required fields to ensure that the form can be properly processed.
* Select the correct package type and photography packages to ensure that you receive the right services.
* If you have any special requests or additional information, use the note field.
