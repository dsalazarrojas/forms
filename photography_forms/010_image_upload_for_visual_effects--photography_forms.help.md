# Image Upload For Visual Effects - Help Guide
## Purpose
This form is used to collect information about a project's visual effects requirements. It helps us understand the project's details and ensure that we can provide accurate and timely visual effects services.

## How To Complete This Form
1. Enter a brief description of the project in the "Project Brief" field.
2. If necessary, upload a reference image for the project.
3. Specify the deadline for the project in the "Deadline" field.
4. Select all applicable VFX requests for the project in the "VFX Request" field.
5. Enter the contact person's name in the "Contact Person" field.
6. Enter the contact email address in the "Contact Email" field.
7. Enter the contact phone number in the "Contact Phone" field.

## Field-by-Field Explanation
* **Project Brief (1)**:
 	+ This is a text field where you can enter a brief description of the project.
 	+ Enter a short and concise summary of the project's requirements and goals.
* **Reference Image (2)**:
 	+ This is a text field where you can enter the URL or upload a reference image for the project.
 	+ If you have a reference image, please upload it here. If not, provide the URL.
* **Deadline (3)**:
 	+ This is a date field where you can enter the project's deadline.
 	+ Enter the date by which the project should be completed.
* **VFX Request (4)**:
 	+ This is a select multiple field with three options: VFX 1, VFX 2, and VFX 3.
 	+ Select all applicable VFX requests for the project.
* **Contact Person (5)**:
 	+ This is a text field where you can enter the contact person's name.
 	+ Enter the name of the person who will be handling the project.
* **Contact Email (6)**:
 	+ This is an email field where you can enter the contact email address.
 	+ Enter the email address of the contact person.
* **Contact Phone (7)**:
 	+ This is a text field where you can enter the contact phone number.
 	+ Enter the phone number of the contact person.
