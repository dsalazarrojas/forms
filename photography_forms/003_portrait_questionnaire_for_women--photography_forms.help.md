# Portrait Questionnaire For Women - Help Guide
## Purpose
The Portrait Questionnaire For Women is a form designed to collect essential information about the subject, ensuring a smooth and successful photo shoot experience.

## How To Complete This Form
1. Please fill out the form completely and accurately, providing the required information for each field.
2. Make sure to include any relevant details about the subject's style, hair, skin tone, and preferences.
3. Select the correct options for the subject's photo location, wardrobe, and services.
4. Double-check the form for any errors or missing information before finalizing the shoot details.

## Field-by-Field Explanation
* **Photographer Name** (`photographer_name`, text, optional): This field is for you, the photographer, to input your name for communication purposes.
* **Contact Number** (`contact_number`, text, optional): Enter your phone number so the subject can contact you for shoot updates or inquiries.
* **E-mail** (`email`, email, optional): Enter your email address for communication and sharing photos.
* **Date Of Birth** (`date_of_birth`, date, optional): The subject's date of birth (if applicable).
* **Height** (`height`, number, optional): The subject's height (in cm or inches).
* **Measurements** (`measurements`, note, optional): Take note of the subject's body measurements for wardrobe planning.
* **Hair Color** (`hair_color`, select_one, optional): Select the subject's hair color from the options provided.
* **Hair Style** (`hair_style`, select_one, optional): Select the subject's hair style from the options provided.
* **Skin Tone** (`skin_tone`, select_multiple, optional): Select the subject's skin tone from the options provided.
* **Style** (`style`, select_one, optional): Select the subject's preferred style from the options provided.
* **Shoot Details** (`shoot_details`, select_one, optional): Select the photo location from the options provided.
* **Clothing** (`clothing`, select_multiple, optional): Select the subject's preferred clothing type from the options provided.
* **Wardrobe** (`wardrobe`, select_multiple, optional): Select the subject's preferred wardrobe type from the options provided.
* **Accessories** (`accessories`, select_multiple, optional): Select the subject's preferred accessories from the options provided.
* **Makeup** (`makeup`, select_multiple, optional): Select the subject's preferred makeup style from the options provided.
* **Hair Accessories** (`hair_accessories`, select_multiple, optional): Select the subject's preferred hair accessories from the options provided.
* **Wardrobe Details** (`wardrobe_details`, note, optional): Take note of any special wardrobe requirements or requests.
* **Photo Location** (`photo_location`, select_one, optional): Select the photo location from the options provided.
* **Photographer Notes** (`photographer_notes`, note, optional): Add any additional notes or reminders for yourself as the photographer.
* **Your Name** (`photographer_name`, text, optional): The subject's name (if different from the photographer's name).
* **Your Phone** (`photographer_phone`, text, optional): The subject's phone number.
* **Your E-mail** (`photographer_email`, email, optional): The subject's email address.
* **Your Website** (`photographer_website`, text, optional): The subject's website (if applicable).
* **Services** (`photographer_services`, select_multiple, optional): Select the services you will provide during the shoot from the options provided.
* **Shoot Date** (`shoot_date`, date, optional): The date of the photo shoot.
* **Shoot Time** (`shoot_time`, time, optional): The time of the photo shoot.
* **Shoot Duration** (`shoot_duration`, text, optional): The duration of the photo shoot.
* **Photo Delivery** (`photo_delivery`, select_one, optional): Select the method for delivering the photos to the subject.
* **Photographer License** (`photographer_license`, select_one, optional): Select the type of license for the photographer.
* **Payment Terms** (`payment_terms`, note, optional): Add any payment terms or conditions.
* **Photo Location** (`photo_location`, select_one, optional): Select the photo location from the options provided.
