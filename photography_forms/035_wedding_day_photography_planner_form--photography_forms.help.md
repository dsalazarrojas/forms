# Wedding Day Photography Planner Form - Help Guide
## Purpose
The Wedding Day Photography Planner Form is designed to collect essential information about a wedding day event, allowing event organizers and photographers to plan and prepare for the event.

## How To Complete This Form
To complete this form, follow these steps:
- Fill in the form's text fields with a brief description of the event and its details.
- Select the relevant options for the questions that apply to your event.
- Enter the event's date and time in the specified formats.
- Provide the required information for each field to ensure accurate data collection.

## Field-by-Field Explanation
### 1. **Wedding Day Photography** (`wedding_day_photography`, text, optional): 
This field is meant to provide a general description of the wedding day photography session. Enter a brief explanation of what will be captured during the photography session.

### 2. **Time** (`time`, time, optional): 
In this field, select a time in the format "HH:MM" for the event.

### 3. **Venue** (`venue`, text, optional): 
Enter the venue where the event will be held. This could be a specific location or a description of the venue's layout.

### 4. **Parents** (`parents`, select_multiple, optional): 
Select all that apply to indicate if there will be parents or not at the event.

### 5. **Kids** (`kids`, select_multiple, optional): 
Select all that apply to indicate if there will be kids at the event.

### 6. **Photography** (`photography`, text, optional): 
This field is meant to provide additional information about the photography session. Enter any specific details that are not covered by the other fields.

### 7. **Reception** (`reception`, select_one, optional): 
Select 'Yes' if there will be a reception as part of the event.

### 8. **Event Description** (`event_description`, text, optional): 
Enter a short description of the event that will help the photographer understand the occasion.

### 9. **Event Date** (`event_date`, date, optional): 
Select the date of the event in the format "YYYY-MM-DD".

### 10. **Event Time** (`event_time`, time, optional): 
Select the time of the event in the format "HH:MM".

### 11. **Reported Time** (`event_reported_time`, time, optional): 
Select the time when the event will be "reported" or when it will actually take place. This is likely meant to capture the start time of the event.

### 12. **Event Venue** (`event_venue`, text, optional): 
Enter the venue where the event will be held.

### 13. **Event Location** (`event_location`, text, optional): 
Enter the location where the event will be held. 

### 14. **Event Details** (`event_details`, text, optional): 
Enter any additional details about the event that were not covered by the previous fields.

## Tips
- Make sure to enter accurate information for each field to ensure that the event is planned and prepared correctly.
- If unsure about any of the fields, feel free to reach out to the event organizers or the photographer for clarification. 
- Review the form carefully before submitting to ensure that all required information is provided.
