# Lookbook Release Form - Help Guide
## Purpose
The "Lookbook Release Form" is used to release information about a publication to the public. This form helps ensure that the required details are provided accurately and in a consistent format.

## How To Complete This Form

*   Fill out each field carefully, ensuring that the required fields are completed.
*   Make sure that the publication details match the publication you are releasing.
*   Double-check your entries for accuracy and completeness.

## Field-by-Field Explanation

*   **Contributor Permissions** (`contributor_permissions`, text, required): This field is used to specify the permissions granted to contributors.
*   **Contributor Names** (`contributor_names`, text, required): This field is used to list the names of contributors.
*   **Release Agreement** (`release_agreement`, text, required): This field is used to provide a release agreement for the contributors.
*   **Name** (`contributor_name`, text, optional): This field is used to add a name for the publication.
*   **Phone** (`contributor_phone`, text, optional): This field is used to add a phone number for the contributor.
*   **Email** (`contributor_email`, text, optional): This field is used to add an email address for the contributor.
*   **Address** (`contributor_address`, text, optional): This field is used to add an address for the contributor.
*   **City** (`contributor_city`, text, optional): This field is used to add a city for the contributor.
*   **State** (`contributor_state`, text, optional): This field is used to add a state for the contributor.
*   **Zip** (`contributor_zip`, text, optional): This field is used to add a zip code for the contributor.
*   **Asset Type** (`asset_type`, select_one, required): This field is used to specify the type of asset being released.
*   **Asset Description** (`asset_description`, text, required): This field is used to describe the asset being released.
*   **Asset URL** (`asset_url`, text, required): This field is used to provide a URL for the asset being released.
*   **Additional Assets** (`additional_assets`, select_multiple, optional): This field is used to specify if the publication includes additional assets.
*   **Contributor Assets** (`contributor_assets`, select_multiple, optional): This field is used to specify if the contributor has assets.
*   **Publication Date** (`publication_date`, date, required): This field is used to specify the date of publication.
*   **Publication Time** (`publication_time`, time, required): This field is used to specify the time of publication.
*   **Publication Period** (`publication_period`, select_one, required): This field is used to specify the period of publication.
*   **Publication Type** (`publication_type`, select_one, required): This field is used to specify the type of publication.
*   **Publication Platform** (`publication_platform`, select_one, required): This field is used to specify the platform of publication.
*   **Publication URL** (`publication_url`, text, required): This field is used to specify the URL of the publication.
*   **Notes** (`notes`, note, optional): This field is used to provide additional notes about the publication.
