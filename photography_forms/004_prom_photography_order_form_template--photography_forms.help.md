# Prom Photography Order Form Template - Help Guide
## Purpose
The Prom Photography Order Form Template is used to collect information from students and photographers regarding photography orders for school events or proms. It helps ensure that all necessary details are captured to fulfill the order correctly.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the student's name.
2. Enter the student's email address.
3. Enter the photographer's name.
4. Enter the photographer's email address.
5. Specify the number of photo sessions.
6. Choose the type of photo session (e.g., standard, premium, etc.).
7. Select the photoshoot date.
8. Choose the photoshoot time.
9. Select a prom theme.
10. Choose a photo editing service (e.g., standard, basic retouching, etc.).
11. Select a photo printing option (e.g., standard, matte, metallic, etc.).
12. Choose the photo mounting type (e.g., standard, wooden, etc.).
13. Select a photo finish (e.g., standard, glossy, matte, etc.).
14. Choose a photo retouching option (e.g., basic, standard, advanced, etc.).
15. Select a photo delivery option (e.g., email, download, pickup, etc.).
16. (Optional) Enter any special requests or notes.

## Field-by-Field Explanation
* **Order Form** (`prom_photography_order_form`, text, required): This is the main section where the student and photographer can enter their information.
* **Student name** (`student_name`, text, required): Enter the student's name.
* **Student email** (`student_email`, email, required): Enter the student's email address.
* **Photographer name** (`photographer_name`, text, required): Enter the photographer's name.
* **Photographer email** (`photographer_email`, email, required): Enter the photographer's email address.
* **Number of photo sessions** (`photo_sessions`, number, optional): Specify the number of photo sessions required.
* **Photo session type** (`photo_session_type`, text, optional): Choose the type of photo session (e.g., standard, premium, etc.).
* **Photoshoot date** (`photoshoot_date`, date, required): Select the photoshoot date.
* **Photoshoot time** (`photoshoot_time`, time, required): Choose the photoshoot time.
* **Prom theme** (`prom_theme`, text, optional): Select a prom theme.
* **Prom color scheme** (`prom_color_scheme`, text, optional): Choose a prom color scheme.
* **Photo editing services** (`photo_editing_services`, text, optional): Choose photo editing services (e.g., standard, basic, etc.).
* **Photo printing** (`photo_printing`, select_one, required): Choose a photo printing option (e.g., standard, matte, metallic, etc.).
* **Photo mounting** (`photo_mounting`, select_multiple, required): Choose photo mounting types (e.g., standard, wooden, etc.).
* **Photo finish** (`photo_finish`, select_multiple, required): Choose a photo finish (e.g., standard, glossy, matte, etc.).
* **Photo retouching** (`photo_retouching`, select_multiple, required): Choose photo retouching options (e.g., basic, standard, advanced, etc.).
* **Photo delivery** (`photo_delivery`, select_one, required): Choose a photo delivery option (e.g., email, download, pickup, etc.).
* **Photo resolution** (`photo_resolution`, text, optional): Enter the photo resolution.
* **Photo orientation** (`photo_orientation`, text, optional): Enter the photo orientation.
* **Photo size** (`photo_size`, text, optional): Enter the photo size.
* **Photo quantity** (`photo_quantity`, number, optional): Enter the number of photos required.
* **Student attendance** (`student_attendance`, text, optional): Enter the student's attendance details.
* **Photoshoot location** (`photoshoot_location`, text, optional): Enter the photoshoot location.
* **Special requests** (`special_requests`, text, optional): Enter any special requests.
* **Notes** (`notes`, note, optional): Enter any additional notes or comments.
