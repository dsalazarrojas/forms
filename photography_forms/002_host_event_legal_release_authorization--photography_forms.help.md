# Host Event Legal Release Authorization - Help Guide
## Purpose
The Host Event Legal Release Authorization form is a legal document that provides release information for event hosts, participants, and photographers. It's essential to complete this form to ensure that all parties involved in the event have given their legal release consent.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out all required fields with accurate and up-to-date information.
2. Enter the event host's name and contact information.
3. Enter the participant's name, contact information, and signature.
4. Enter the photographer's name, contact information, and statement.
5. Review and sign the form to confirm that all parties have given their legal release consent.

## Field-by-Field Explanation

* **Event Host Name** (`event_host_name`): Enter the name of the event host.
* **Event Host Address** (`event_host_address`): Enter the address of the event host.
* **Host Event Name** (`host_event_name`): Enter the name of the host event.
* **Host Event Date** (`host_event_date`): Enter the date of the host event.
* **Participant Name** (`participant_name`): Enter the name of the participant.
* **Participant Address** (`participant_address`): Enter the address of the participant.
* **Participant Phone** (`participant_phone`): Enter the phone number of the participant.
* **Participant Email** (`participant_email`): Enter the email address of the participant.
* **Participant Signature Date** (`participant_signature_date`): Enter the date of the participant's signature.
* **Participant Signature** (`participant_signature`): Enter the participant's signature.
* **Release Date** (`release_date`): Enter the release date.
* **Event Host (2)** (`event_host`): Enter the event host's name.
* **Event Host Phone** (`event_host_phone`): Enter the phone number of the event host.
* **Event Host Email** (`event_host_email`): Enter the email address of the event host.
* **Event Host Address 2** (`event_host_address_2`): Enter the address of the event host.
* **Grant Photographer** (`photographer_release`): Enter a statement granting permission to the photographer.
* **Grant Event** (`event_release`): Enter a statement granting permission to the event.
* **Signature** (`signature`): Enter the signature of the person signing the form.
* **Photographer Name** (`photographer_name`): Enter the name of the photographer.
* **Photographer Phone** (`photographer_phone`): Enter the phone number of the photographer.
* **Photographer Email** (`photographer_email`): Enter the email address of the photographer.
* **Photographer Address** (`photographer_address`): Enter the address of the photographer.
* **Statement** (`photographer_statement`): Enter a statement from the photographer.

Note: Ensure that all fields are filled out accurately and completely to avoid any issues with the release authorization.
