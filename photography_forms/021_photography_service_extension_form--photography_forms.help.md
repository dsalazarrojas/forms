# Photography Service Extension Form - Help Guide
## Purpose
This form is used to collect information from clients about their photography service extension needs. The goal is to determine what additional services they require for their event or project.

## How To Complete This Form
To complete this form, follow these steps:
1. Review the form carefully and ensure that you have understood the purpose of each question.
2. Select the relevant options that apply to your needs.
3. Fill out the form accurately and completely.

## Field-by-Field Explanation
* **Photography Service Extension Form**: Enter a brief title or description of your photography service extension request.
* **Client Requests**: Please select all the services that you are interested in for your project or event:
	+ Select "Yes" if you are interested in this service.
* **Additional Services**: If you would like to add additional services beyond the standard package, select "Yes" and describe your needs in the text field provided.
* **Service Requests**: Please select all the additional services that you would like to include in your project:
	+ Select "Yes" for each additional service you are interested in.
* **Service Offerings**: Select all the services that you would like to have included in your project:
	+ Select "Yes" for each service that you are interested in.
* **Expanded Services**: If you have any specific requirements or requests that are not listed, select "Yes" and describe your needs in the text field provided.
* **Photography Service Requests**: Enter any specific photography service requests or requirements.
* **Requested Services**: If there are any additional services that you would like to add beyond the standard package, please select "Yes" and specify the services in the text field provided.

## Tips
* Please ensure that you have filled out the form accurately and completely.
* If you have any questions or concerns, please contact the photography team for assistance.
* If you would like to add any additional services or make any changes to your request, please let us know and we will do our best to accommodate your needs.
