# Baby Photography Booking Form - Help Guide

## Purpose
This form is used to book a photography session for babies. It collects essential information from clients, including contact details, session preferences, and consent for photo usage. Please follow the instructions below to complete the form accurately.

## How To Complete This Form
To book a photography session for your baby, please complete the following fields:

1. **Client name**: Enter the name of the parent or guardian.
2. **Contact email**: Enter the email address you can be reached at for booking confirmation.
3. **Contact phone**: If you prefer to be contacted via phone, enter your mobile number here (optional).
4. **Preferred session date**: Choose one date from the three options provided.
5. **Session type**: Select one of the four available session types: In studio, On location, Newborn, or Milestone.
6. **Number of outfits**: Indicate how many outfits you think you will need for the photo session (for planning purposes).
7. **Special requests**: If you have any specific theme or location preferences, describe them here.
8. **Model release consent**: Check 'True' if you grant permission for your baby's photos to be used in a portfolio.
9. **Deposit required**: This field is not applicable, as it seems to be a note type field. If you are unsure, please contact us.
10. **Booking date**: Select the date you wish to book the session.

## Field-by-Field Explanation
* **Client name** (`Client name`, text, required): Enter the name of the parent or guardian.
* **Contact email** (`Contact email`, email, required): Enter the email address you can be reached at for booking confirmation.
* **Contact phone** (`Contact phone`, text, optional): If you prefer to be contacted via phone, enter your mobile number here.
* **Preferred session date** (`Preferred session date`, date, required): Choose one date from the three options provided.
* **Session type** (`Session type`, select_one, required): Select one of the four available session types: In studio, On location, Newborn, or Milestone.
* **Number of outfits** (`Number of outfits`, number, optional): Indicate how many outfits you think you will need for the photo session.
* **Special requests** (`Special requests`, text, optional): If you have any specific theme or location preferences, describe them here.
* **Model release consent** (`Model release consent`, select_one, required): Check 'True' if you grant permission for your baby's photos to be used in a portfolio.
* **Deposit required** (`Deposit required`, note, optional): This field is not applicable, as it seems to be a note type field. If you are unsure, please contact us.
* **Booking date** (`Booking date`, date, required): Select the date you wish to book the session.

## Tips
* Please ensure to choose a preferred session date that suits your schedule and preferences.
* Make sure to read and understand the model release consent before checking 'True'. 
* If you have any questions or concerns, feel free to contact us at the provided contact email.
