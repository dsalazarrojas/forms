# Print Release Form - Help Guide
## Purpose
The Print Release Form is a document that confirms an image has been released for print and is suitable for public consumption. It's used to track and record the distribution of printed materials, ensuring they are not used in unauthorized or unapproved ways.

## How To Complete This Form
To complete this form, follow these steps:

1. Determine whether you are releasing the print for public consumption by selecting 'Yes' under 'Release'.
2. If applicable, enter the client's contact information under 'Client' and 'Phone'.
3. If you're releasing multiple prints, select all applicable 'Release Prints'.
4. Specify whether you will distribute the print in any way by selecting 'Yes' or 'No' under 'Distribute'.
5. Enter any additional comments or details under 'Notes'.
6. Provide your email address under 'Email' so the client can contact you.

## Field-by-Field Explanation
* **Release** (Select one):
	+ Select 'Yes' to confirm that the print is released for public consumption.
* **Client** (Text):
	+ Enter the client's name or contact information if applicable.
* **Release Prints** (Select multiple):
	+ Choose all applicable prints to be released for public consumption.
* **Distribute** (Select one):
	+ Select 'Yes' if you will distribute the print, 'No' otherwise.
* **Notes** (Note):
	+ Enter any additional comments or details about the release.
* **Email** (Email):
	+ Enter your email address for the client to contact you.
* **Phone** (Text):
	+ Enter your phone number so the client can contact you.

## Tips
* Make sure to fill out all required fields (though not all are required).
* Review the 'Release Prints' options carefully, as this is an all-or-nothing selection.
