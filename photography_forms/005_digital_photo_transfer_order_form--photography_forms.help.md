# Digital Photo Transfer Order Form - Help Guide
## Purpose
This form is designed to collect information from customers for transferring digital photos. You will need to provide your customer's name, email, phone number, photo description, preferred file format, and any design details or customer notes.

## How To Complete This Form
1. Fill in the customer's name, email, and phone number in the respective fields.
2. Provide a brief description of the photo(s) you would like to transfer.
3. Select the desired file format for the transfer (jpg, png, or tiff).
4. Add any design details or customer notes in the text area.
5. You may also upload a file or attach a link to a cloud storage service (though this option is not required).

## Field-by-Field Explanation
- **Customer Name**: Enter the customer's name.
  - This is the customer's name.
- **Email**: Enter the customer's email address.
  - This is the customer's email address.
- **Phone**: Enter the customer's phone number.
  - This is the customer's phone number.
- **Photo Description**: Briefly describe the photo(s) you would like to transfer.
  - Please provide a brief description of the photo(s) including any relevant details.
- **Transfer Format**: Choose the desired file format for the transfer.
  - Select jpg, png, or tiff.
- **Design Details**: Add any design details or notes about the photo transfer.
  - You may want to provide information on any specific edits, filters, or treatments you would like to apply.
- **Customer Notes**: Add any additional notes or comments about the photo transfer.
  - This is the space for any additional information you would like to provide to the customer.
- **File Uploader**: You may attach a file or link to a cloud storage service containing the photo(s) you would like to transfer.
  - You may use this to upload the photo(s) directly or provide a link to a location where they can be accessed.
- **File Uploader Label**: Enter a label for the file or link you are uploading.
  - This is the label to be displayed for the uploaded file or link. 

## Tips
- Please ensure that the photo description is concise and accurate.
- If you have any specific design requirements or edits, please provide them in the design details field.
- If you are uploading a file, please ensure it is in one of the supported formats (jpg, png, tiff).
- If you are providing a link to a cloud storage service, please ensure it is accessible and secure.
