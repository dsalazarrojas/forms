# event_photography_authorization_form - Help Guide
## Purpose
The "event_photography_authorization_form" is a crucial document used to authorize event photography and outline guidelines for its use, storage, and access control. It's essential to complete this form accurately to prevent potential issues with image usage, storage, and access controls.

## How To Complete This Form
To complete the form correctly, follow these steps:

1.  Choose your event photography authorization option (Option A or Option B) on page 1.
2.  Select your preferred image type (Event Details, Candid Moments, or General Moments) on page 1.
3.  Specify your sharing preference (Social Media, Email, or Other) on page 1.
4.  Provide details on storage requirements (if applicable) on page 1.
5.  Choose your desired access control level (Public, Private, or Restricted) on page 2.
6.  Enter any additional access control notes on page 2.
7.  Specify your release policy (True or False) on page 2.
8.  Enter storage period details (if applicable) on page 2.
9.  Enter any access control notes on page 3.
10.  Enter the name of the photographer on page 4.
11.  Enter photo credit details (if applicable) on page 4.
12.  Enter storage notes on page 4.
13.  Enter destruction notes (if applicable) on page 4.
14.  Specify the access type (Public, Private, or Restricted) on page 5.
15.  Enter release notes on page 5.
16.  Enter event photographer notes on page 5.
17.  Enter storage and destruction details on page 5.

## Field-by-Field Explanation

*   **Event Photography Authorization** (`event_photography_authorization`): This is a checkbox field to authorize event photography. Choose between Option A or Option B, depending on your event requirements.
*   **Image Type** (`capture_image_type`): Select the type of images you require (Event Details, Candid Moments, or General Moments) for the event photography.
*   **Sharing Option** (`sharing_option`): Specify how you want to share the event images (Social Media, Email, or Other).
*   **Storage Option** (`storage_option`): If necessary, enter storage details for the event images.
*   **Access Control** (`access_control`): Choose the desired access control level (Public, Private, or Restricted) for the event images.
*   **Access Note** (`access_note`): Enter any additional access control notes.
*   **Release Policy** (`release_policy`): Specify whether the event images are released (True or False).
*   **Storage Period** (`storage_period`): If necessary, enter the storage period for the event images.
*   **Access Control Note** (`access_control_note`): Enter any additional access control notes.
*   **Photographer** (`photographer`): Enter the name of the photographer.
*   **Photo Credit** (`photo_credit`): Enter photo credit details (if applicable).
*   **Storage Note** (`storage_note`): Enter storage notes for the event images.
*   **Destruction Note** (`destruction_note`): Enter destruction notes for the event images (if applicable).
*   **Access** (`access`): Specify the access type (Public, Private, or Restricted) for the event images.
*   **Release Note** (`release_note`): Enter release notes for the event images.
*   **Event Photographer Note** (`event_photographer_note`): Enter notes for the event photographer.
*   **Storage & Destruction** (`storage_destruction`): Enter storage and destruction details for the event images.
*   **Event Photography Authorization Form Note** (`event_photography_authorization_form_note`): Enter any additional notes for the event photography authorization form.
