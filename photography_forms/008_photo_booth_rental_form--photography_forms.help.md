# Photo Booth Rental Form - Help Guide

## Purpose
This form is designed for customers to inquire about renting a photo booth for events or photo shoots. The form helps us understand their preferences and requirements for the rental process.

## How To Complete This Form

1. Select the type of photo booth rental you are interested in from the "Photo Booth" dropdown menu on page 1.
2. Provide more information about your event or photo shoot on page 2.
3. Choose the contact person(s) you would like to be the main point of contact on page 3.
4. Select the type of photo booth information you would like to rent on page 4.
5. Provide the necessary rental information, including the duration of the rental, on page 5.
6. Enter the date and time you would like to rent the photo booth on page 6.
7. Indicate the duration of the rental on page 7.
8. Add any additional information about your event or photo shoot on page 9.
9. Finally, select the option for the rental fee and submit your request on page 11.

## Field-by-Field Explanation

* **Photo Booth** (Select One, Required): Select the type of photo booth rental you are interested in (Option 1, Option 2, Option 3).
* **More Information** (Text, Optional): Provide a brief description of your event or photo shoot.
* **Contact Information** (Select Multiple, Optional): Choose the contact person(s) you would like to be the main point of contact (John Doe, Jane Doe, Bob Smith).
* **Photo Booth Information** (Select One, Optional): Select the type of photo booth information you would like to rent (Option 1, Option 2, Option 3).
* **Rental Information** (Text, Required): Enter the number of hours you would like to rent the photo booth.
* **Date** (Date, Required): Enter the date you would like to rent the photo booth.
* **Time** (Time, Required): Enter the time you would like to start renting the photo booth.
* **Duration** (Number, Required): Indicate the duration of the rental in hours.
* **Additional Information** (Text, Optional): Add any additional details about your event or photo shoot.
* **Rental Fee** (Number, Required): Select the option for the rental fee.
* **Submit Request** (Select One, Optional): Select the option to submit your request (Option 1, Option 2, Option 3).

## Tips

* Please make sure to fill out all required fields to ensure we can process your request efficiently.
* If you have any special requests or requirements, please include them in the "Additional Information" field.
