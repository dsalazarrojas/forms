# Media Release Time Request Form - Help Guide
## Purpose
The Media Release Time Request Form is used to collect information about the timing and logistics of media releases for events or activities.

## How To Complete This Form
To complete this form, follow these steps:

1. Select whether there are media fields present (Yes/No)
2. Enter your name
3. Enter your email address
4. Enter your phone number
5. Select whether you are at a specific address (Yes/No)
6. Select whether there is a specific location (Yes/No)
7. Enter the date of the media release
8. Enter the time of the media release
9. Select the type of media (e.g. photo, video, etc.)
10. Describe any equipment used during the media release
11. Select whether there is a crew present (Yes/No)
12. Enter the release time

## Field-by-Field Explanation

* **Media Fields (form_fields)** (`form_fields`, select_multiple, required): Selecting "Yes" indicates that there are media fields present. This can include photographers, videographers, or other types of media personnel.
* **Name (name)** (`name`, text, required): Enter your name, which will be used to identify you as the person filling out the form.
* **Email (email)** (`email`, email, required): Enter your email address, which will be used to contact you if needed.
* **Phone (phone)** (`phone`, text, required): Enter your phone number, which will be used to contact you if needed.
* **Address (address)** (`address`, select_multiple, required): Selecting "Yes" indicates that you are at a specific address. This can be used to coordinate with you or send you materials.
* **Location (location)** (`location`, select_multiple, required): Selecting "Yes" indicates that there is a specific location for the media release.
* **Date (date)** (`date`, required): Enter the date of the media release.
* **Time (time)** (`time`, required): Enter the time of the media release.
* **Media Type (media_type)** (`media_type`, text, required): Describe the type of media, such as photo, video, or live stream.
* **Equipment (equipment)** (`equipment`, text, required): Describe the equipment used during the media release, such as cameras or microphones.
* **Crew (crew)** (`crew`, select_multiple, required): Selecting "Yes" indicates that there is a crew present, such as photographers or videographers.
* **Release Time (release_time)** (`release_time`, required): Enter the release time for the media.

## Tips

* Be sure to fill out all required fields.
* Double-check your information for accuracy before submitting the form.
* If you have any questions or need clarification, contact the event coordinator or organizer.
* This form is for coordinating media releases, if you are unsure which form to fill out, please contact the event coordinator or organizer.
