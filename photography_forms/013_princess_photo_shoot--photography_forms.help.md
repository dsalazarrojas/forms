# princess_photo_shoot - Help Guide
## Purpose
The "princess_photo_shoot" form is designed to collect information for a photo shoot event, such as a princess-themed party or event.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the **Form Title** field with a brief title of the event.
2. Select the **Category** of the event from the dropdown menu.
3. Enter a brief **Description** of the event in the text box.
4. Enter your **Email** and **Phone** numbers to contact you for further information.
5. Choose the **Date** and **Time** of the event from the calendars.
6. Select the **Location** of the event from the dropdown menu.
7. Add any additional **Comments** you have for the event.
8. Click the **Submit** button to complete the form.

## Field-by-Field Explanation
- **Form Title**: A brief title of the event.
  * Label: Form Title
  * Type: Text
  * Required: False
- **Category**: Select the category of the event (e.g. Photography Forms).
  * Label: Category
  * Type: Select One
  * Required: True
- **Description**: A brief description of what to expect at the event.
  * Label: Description
  * Type: Text
  * Required: False
- **Email**: The contact email of the event organizer.
  * Label: Email
  * Type: Email
  * Required: False
- **Phone**: The contact phone number of the event organizer.
  * Label: Phone
  * Type: Text
  * Required: False
- **Date**: The date of the event.
  * Label: Date
  * Type: Date
  * Required: True
- **Time**: The time of the event.
  * Label: Time
  * Type: Time
  * Required: True
- **Location**: The location of the event.
  * Label: Location
  * Type: Select One
  * Required: True
- **Comments**: Any additional comments about the event.
  * Label: Comments
  * Type: Note
  * Required: False
- **Submit**: Click to submit the form.
  * Label: Submit
  * Type: Text
  * Required: True
