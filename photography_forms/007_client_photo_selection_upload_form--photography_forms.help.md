# Client Photo Selection Upload Form - Help Guide
## Purpose
This form is used by clients to provide information about their photo selection and preferences for editing. It helps the editor understand the client's needs and expectations, ensuring that the edited photos meet their requirements.

## How To Complete This Form

To complete this form, follow these steps:

1. Select the type of session that this photoshoot was for (e.g., Portrait, Family, Wedding, etc.).
2. Enter the first name and last name of the person in the photos.
3. Enter the email address where you want to receive the edited photos.
4. If you have a phone number where the editor can reach you for any questions, enter it.
5. Choose the number of photos you want to select for editing.
6. List the specific photo numbers or filenames you want edited.
7. Select your editing style preference (e.g., Natural and Light, Warm and Golden, etc.).
8. If you have specific editing requests, enter them in the text box.
9. Choose the level of skin retouching you want (e.g., Minimal, Moderate, Heavy, etc.).
10. If you need background adjustments, select all that apply.
11. Upload example reference images that show your desired style.
12. If you have inspiration photos, upload them.
13. Choose the preferred deliverable format (e.g., High-resolution JPEG, Web-optimized JPEG, etc.).
14. Select the preferred delivery method (e.g., Online Gallery Download, Email, etc.).
15. Choose the expected turnaround time for the edited photos.
16. If you need a print package, select 'True'.
17. If you need specific print sizes, enter them.
18. If you're interested in album or canvas prints, select 'Yes'.
19. Select the intended use of the photos (e.g., Personal Use Only, Social Media, etc.).
20. Enter any additional comments or special requests.

## Field-by-Field Explanation

* **Photo Selection and Upload Form**:
This is the header of the form, which introduces the purpose of the form.
* **First Name** (`client_first_name`, text, required):
	+ Enter your first name as it appears on the photo ID or proof sheet.
* **Last Name** (`client_last_name`, text, required):
	+ Enter your last name as it appears on the photo ID or proof sheet.
* **Email Address** (`email`, email, required):
	+ Enter the email address where you want to receive the edited photos.
* **Phone Number** (`phone`, text, optional):
	+ If you have a phone number where the editor can reach you for any questions, enter it.
* **Session Type** (`session_type`, select_one, required):
	+ Select the type of session this photoshoot was for (e.g., Portrait, Family, Wedding, etc.).
* **Session Date** (`session_date`, date, required):
	+ Enter the date of the photoshoot.
* **Photographer Name** (`photographer_name`, text, optional):
	+ If you have a photographer's name, enter it.
* **Gallery Link** (`gallery_link`, text, optional):
	+ If you have a link to your proof gallery, enter it.
* **Number of Photos to Select** (`number_of_photos_to_select`, select_one, required):
	+ Select the number of photos you want to select for editing.
* **Selected Photo Numbers** (`selected_photo_numbers`, text, required):
	+ List the specific photo numbers or filenames you want edited.
* **Editing Style Preference** (`editing_style_preference`, select_one, required):
	+ Select your preferred editing style (e.g., Natural and Light, Warm and Golden, etc.).
* **Specific Editing Requests** (`specific_editing_requests`, text, optional):
	+ If you have specific editing requests, enter them.
* **Skin Retouching Level** (`skin_retouching_level`, select_one, optional):
	+ Choose the level of skin retouching you want (e.g., Minimal, Moderate, Heavy, etc.).
* **Background Adjustments Needed** (`background_adjustments`, select_multiple, optional):
	+ Select all background adjustments you need (e.g., Brighten, Darken, etc.).
* **Upload Reference Images** (`upload_reference_images`, text, optional):
	+ Upload example reference images that show your desired style.
* **Upload Inspiration Photos** (`upload_inspiration_photos`, text, optional):
	+ Upload inspiration photos you want to emulate.
* **Preferred Deliverable Format** (`deliverable_format`, select_one, required):
	+ Choose the preferred deliverable format (e.g., High-resolution JPEG, Web-optimized JPEG, etc.).
* **Preferred Delivery Method** (`delivery_method`, select_one, required):
	+ Select the preferred delivery method (e.g., Online Gallery Download, Email, etc.).
* **Expected Turnaround Time** (`turnaround_time`, select_one, required):
	+ Choose the expected turnaround time for the edited photos.
* **Print Package Needed** (`print_package_needed`, select_one, optional):
	+ If you need a print package, select 'True'.
* **Desired Print Sizes** (`print_sizes`, text, optional):
	+ If you need specific print sizes, enter them.
* **Album or Canvas Prints** (`album_or_canvas`, select_one, optional):
	+ If you're interested in album or canvas prints, select 'Yes'.
* **Intended Use of Photos** (`usage_rights`, select_multiple, required):
	+ Select all intended use of photos (e.g., Personal Use Only, Social Media, etc.).
* **Additional Comments or Special Requests** (`additional_comments`, text, optional):
	+ Enter any additional comments or special requests.

## Tips

* Ensure you fill out all required fields.
* Use specific photo numbers or filenames for selected photos.
* Upload reference images that are relevant to your desired style.
* Be clear and concise in your editing style preference and specific requests.
* Double-check your intended use of photos to avoid any misuse of the edited photos.
