> # Threat Intelligence Feed Request Form - Help Guide
## Purpose
The Threat Intelligence Feed Request Form is used to submit requests for threat intelligence feeds to our internal team. Please ensure you have the correct permissions to use this form.

## How To Complete This Form

To complete this form, simply fill out the fields with the requested information and click submit. The form will guide you through the necessary steps to provide a clear and concise request for the threat intelligence feed.

## Field-by-Field Explanation

* **threat_intelligence_type** (Select Multiple): Select the type of threat intelligence you are requesting (e.g., "Network", "Web Application", "System").
    * Select all applicable options that apply to your request.
* **threat_intelligence_feed_name** (Text): Enter a descriptive name for the feed you are requesting.
* **threat_intelligence_feed_description** (Text): Provide a brief description of the feed you are requesting.
* **threat_intelligence_feed_url** (Text): Enter the URL of the feed you are requesting.
* **threat_intelligence_feed_type** (Text): Select the type of feed you are requesting (this is different from "threat_intelligence_type" above). 
    * Note that this field is not a select multiple option but rather a select one option. 
* **threat_intelligence_feed_format** (Text): Select the format of the feed you are requesting (e.g., "CSV", "JSON", "XML").
* **threat_intelligence_feed_frequency** (Select One): Select the frequency of the feed you are requesting (e.g., "Daily", "Weekly", "Monthly").
* **threat_intelligence_feed_status** (Select One): Select the status of the feed you are requesting (e.g., "Active", "Inactive", "Under Evaluation").
* **threat_intelligence_feed_requester** (Text): Enter the name of the person requesting the feed.
* **threat_intelligence_feed_requester_email** (Email): Enter the email address of the person requesting the feed.
* **threat_intelligence_feed_requester_phone** (Text): Enter the phone number of the person requesting the feed.
* **threat_intelligence_feed_requester_chat** (Text): Enter the chat platform or channel of the person requesting the feed.
* **threat_intelligence_feed_requester_company** (Text): Enter the company name of the person requesting the feed.
* **threat_intelligence_feed_requester_address** (Text): Enter the address of the person requesting the feed.
* **threat_intelligence_feed_requester_notes** (Note): Enter any additional notes or comments about the request.
* **threat_intelligence_feed_requester_additional_info** (Text): Enter any additional information about the request.
* **threat_intelligence_feed_requester_comments** (Text): Enter any comments about the request.
* **threat_intelligence_feed_requester_attachment** (Text): Attach any relevant files or documents to the request.
* **threat_intelligence_feed_requester_additional_notes** (Text): Enter any additional notes about the request.

## Tips

* Be sure to fill out all required fields to ensure your request is processed correctly.
* If you are unsure about any field, please consult with your internal team member for clarification.
* Duplicate requests will not be processed, so please ensure you are not submitting a duplicate request.
* Submissions with false information will be met with strict consequences.
