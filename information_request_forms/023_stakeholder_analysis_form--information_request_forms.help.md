# stakeholder_analysis_form - Help Guide
## Purpose
This form is designed to collect information about stakeholders in the organization. The purpose of this form is to gather data on their needs, interests, and expectations, which will be used to identify potential collaborators, develop strategies to engage with them, and analyze their potential impact.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the type of stakeholder from the dropdown list.
2. Enter the name of the stakeholder.
3. Provide their email address.
4. Indicate the frequency of interaction with the stakeholder.
5. Select the organizations the stakeholder is associated with.
6. Describe the impact of the stakeholder on the organization.
7. If applicable, provide additional notes.

## Field-by-Field Explanation
* **StakeholderType** (SelectOne): Choose the type of stakeholder from the options provided (Business, Government, NonProfitOrganization).
* **Name** (Text): Enter the name of the stakeholder.
* **Email** (Email): Enter the email address of the stakeholder.
* **Phone** (Text): This is an optional field for providing the stakeholder's phone number.
* **Description** (Text): This field is optional and can be used for any additional comments or notes.
* **Relationship** (Text): This field is optional and can be used to describe the relationship between the stakeholder and the organization.
* **Frequency** (Text): Indicate how often you interact with the stakeholder (e.g., daily, weekly, monthly).
* **StakeholderOrganisation** (SelectMultiple): Select the organizations the stakeholder is associated with.
* **Impact** (Text): Describe the impact the stakeholder has on the organization.
* **Priority** (Text): This field is optional and can be used to indicate the priority of the stakeholder (e.g., high, medium, low).
* **Notes** (Note): This field is optional and can be used for any additional comments.
* **Comments** (Text): This field is optional and can be used for any additional comments.
* **Attachment** (Note): This field is optional and can be used to attach any relevant files or documents.
* **Follow up** (Text): This field is optional and can be used to outline any follow-up actions or next steps.
* **Next Steps** (Text): This field is optional and can be used to outline any next steps or actions to take.
* **StakeholderContact** (Text): This field is optional and can be used to provide any contact information for the stakeholder.
* **StakeholderLocation** (Text): This field is optional and can be used to indicate the location of the stakeholder.
* **StakeholderLevel** (Text): This field is optional and can be used to indicate the level of the stakeholder (e.g., manager, executive, etc.).
* **StakeholderCategory** (Text): This field is optional and can be used to categorize the stakeholder (e.g., client, partner, etc.).
* **StakeholderDepartment** (Text): This field is optional and can be used to indicate the department associated with the stakeholder.
* **StakeholderRole** (Text): This field is optional and can be used to indicate the role of the stakeholder within the organization.
* **StakeholderGroup** (Text): This field is optional and can be used to categorize the stakeholder as part of a group.
* **StakeholderNotes** (Text): This field is optional and can be used for any additional notes about the stakeholder.
* **StakeholderOther** (Text): This field is optional and can be used for any other information about the stakeholder.
