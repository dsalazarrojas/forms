# Gift Progress Record Form - Help Guide
## Purpose
The Gift Progress Record Form is used to record and track the progress of gifts made to an organization or individual.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the Gift Progress Record section with a brief description of the gift made.
2. Select the status of the Donor Information section, answering "Yes" if you are tracking the donor, "No" if not.
3. Enter any additional information about the donor in the Donor Information section.
4. Enter the Gift Information section with a brief description of the gift made.
5. Enter the Gift Progress section with any additional details of the gift progress.
6. Select the date the gift was made in the Donation Date section.
7. Enter the amount donated in the Amount Donated section.
8. Select the frequency of donations from the Frequency of Donations section, answering "Yes" if the donor donates regularly, "No" if not.
9. Select the Gift Recipient section, answering "Yes" if the gift was made for a specific recipient, "No" if not.
10. Enter any additional notes or comments about the gift in the Notes section.
11. Enter the email of the donor in the Email section.

## Field-by-Field Explanation
* **Gift Progress Record** (`gift_progress_record`, text, optional): A brief description of the gift made.
* **Donor Information** (`donor_info`, select_one, optional): Select "Yes" if you are tracking the donor, "No" if not.
* **Donor Information** (`donor_info`, text, optional): Additional information about the donor.
* **Gift Information** (`gift_info`, text, optional): A brief description of the gift made.
* **Gift Progress** (`gift_progress_info`, text, optional): Additional details of the gift progress.
* **Donation Date** (`donation_date`, date, optional): The date the gift was made.
* **Amount Donated** (`amount_donated`, number, optional): The amount donated.
* **Frequency of Donations** (`frequency_donations`, select_multiple, optional): Select "Yes" if the donor donates regularly, "No" if not.
* **Gift Recipient** (`gift_recipient`, select_one, optional): Select "Yes" if the gift was made for a specific recipient, "No" if not.
* **Notes** (`notes`, note, optional): Additional comments or notes about the gift.
* **Email** (`email`, email, optional): The email of the donor.
