# Construction Submittal Form - Help Guide
## Purpose
This form is used to collect information and documents from subcontractors for construction projects. It ensures that all necessary submittals are properly received, reviewed, and processed.

## How To Complete This Form

To complete this form, follow these steps:

1. Fill in the required fields with accurate and complete information.
2. Upload any required attachments or certifications.
3. Review and confirm the submitted information before submitting.
4. Ensure that all fields and attachments are complete and accurate.

## Field-by-Field Explanation

* **Submittal Date** (`submittal_date`, date, required): The date the submittal is submitted.
* **Submittal Number** (`submittal_number`, text, required): A sequential submittal reference number.
* **Project Name** (`project_name`, text, required): The name of the construction project.
* **Project Number** (`project_number`, text, not required): The project reference number (if applicable).
* **Subcontractor Name** (`subcontractor_name`, text, required): The company or individual submitting the submittal.
* **Subcontractor Contact** (`subcontractor_contact`, text, required): The contact person's name.
* **Subcontractor Email** (`subcontractor_email`, email, required): The email address of the subcontractor.
* **Subcontractor Phone** (`subcontractor_phone`, text, required): The phone number of the subcontractor.
* **Submittal Type** (`submittal_type`, select_one, required): The category of submittal (e.g., Product Data, Shop Drawings, etc.).
* **Specification Section** (`specification_section`, text, required): The relevant specification section number.
* **Specification Title** (`specification_title`, text, required): The title of the specification section.
* **Drawing Reference** (`drawing_reference`, text, not required): The relevant drawing numbers (if applicable).
* **Item Description** (`item_description`, text, required): A detailed description of the item.
* **Manufacturer Name** (`manufacturer_name`, text, required): The name of the product manufacturer.
* **Manufacturer Location** (`manufacturer_location`, text, not required): The city and state of the manufacturer (if applicable).
* **Product Model Number** (`product_model`, text, not required): The model or catalog number of the product.
* **Proposed Use** (`proposed_use`, text, required): Where the item will be used (e.g., in the building, outdoors, etc.).
* **Deviations from Specifications** (`deviations_from_specs`, select_one, required): Note any variations from the specifications.
* **Deviation Details** (`deviation_details`, text, not required): Describe any deviations.
* **Samples Included** (`samples_included`, select_one, required): Whether physical samples are provided.
* **Certifications Attached** (`certifications_attached`, select_one, required): Whether compliance documentation is attached.
* **Test Reports Attached** (`test_reports_attached`, select_one, required): Whether performance test results are attached.
* **Warranty Information** (`warranty_information`, select_one, required): Whether warranty details are included.
* **Lead Time** (`lead_time`, text, required): The delivery time after approval.
* **Special Requirements** (`special_requirements`, text, not required): Special storage, handling, or other requirements.
* **Attachments List** (`attachments_list`, text, required): A list of documents included.
* **Subcontractor Signature** (`subcontractor_signature`, text, required): The full name of the subcontractor.
* **General Contractor Review** (`general_contractor_review`, select_one, not required): The GC's determination.
* **GC Comments** (`gc_comments`, text, not required): The GC's notes.
* **Architect Review** (`architect_review`, select_one, not required): The architect's determination.
* **Architect Comments** (`architect_comments`, text, not required): The architect's notes.
