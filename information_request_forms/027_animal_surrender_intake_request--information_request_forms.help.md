# Animal Surrender/Intake Request - Help Guide
## Purpose
This form is used to gather information about an animal being surrendered or admitted to the shelter. It helps us understand the animal's species, breed, age, weight, socialization status, and medical conditions, which aids in finding the best possible placement and care for the animal.

## How To Complete This Form
1. Fill out the form with accurate and honest information.
2. Make sure to answer every question thoroughly.
3. If unsure or not certain about a question, answer with the available options or describe the situation as accurately as possible.

## Field-by-Field Explanation

* **Current Owner Full Name**: Provide the name of the current owner or caregiver of the animal.
* **Contact Phone Number**: Enter the phone number of the current owner or caregiver.
* **Animal Name**: Enter the name of the animal being surrendered or admitted.
* **Animal Species and Breed**: Identify the species and breed of the animal (e.g., domestic shorthair, labrador retriever).
* **Animal Weight - lbs**: Enter the animal's weight in pounds (e.g., 20 lbs, 50 lbs).
* **Animal Age**: Provide the animal's age, including any relevant descriptors (e.g., 3 years, 6 months, 5 years old).
* **Reason for Surrender**: Briefly explain the reason for surrendering or admitting the animal.
* **Socialization with Dogs**: Select one of the provided options to describe the animal's socialization status with dogs (Friendly, Selective, Aggressive, or Unknown).
* **Socialization with Cats**: Select one of the provided options to describe the animal's socialization status with cats (Friendly, Selective, Aggressive, or Unknown).
* **Socialization with Children**: Select one of the provided options to describe the animal's socialization status with children (Friendly, Selective, Aggressive, or Unknown).
* **House Trained**: Indicate whether the animal is fully trained to use a litter box (Yes or No), or if it's still learning (In Progress), or if it's only an outdoor animal (Outdoor only).
* **Current Medications or Health Issues**: List any known medical conditions or health issues the animal may have.

## Tips

* Be honest and accurate when filling out this form.
* If you are unsure about any information, contact the shelter staff for guidance.
* Completing this form will help us find the best possible placement and care for the animal.
