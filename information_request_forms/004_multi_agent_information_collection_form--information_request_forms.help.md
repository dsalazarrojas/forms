# Multi Agent Information Collection Form - Help Guide
## Purpose
The Multi Agent Information Collection Form is designed to collect information from multiple agents working on a project or partnership.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out your project details in the "Project Name" field.
2. Enter your name and contact information in the "Name", "Email", and "Phone" fields.
3. Select your role in the "Role" field.
4. Choose the project type from the "Project Type" dropdown menu.
5. Provide the start and end dates of the project.
6. Optionally, add any additional notes in the "Note" field.
7. Select the assigned tool from the "Assigned Tool" dropdown menu.
8. Choose the category of the project from the "Category" dropdown menu.
9. Add a short description of the project in the "Description" field.
10. Provide a name for the output file in the "Output File Name" field.

## Field-by-Field Explanation

* **Project Name** (`project_name`, text, required): Enter the name of the project you are working on.
* **Name** (`name`, text, required): Enter your name and title.
* **Email** (`email`, email, required): Enter your email address.
* **Phone** (`phone`, text, required): Enter your phone number.
* **Role** (`role`, text, required): Select your role in the project (e.g., team lead, member, etc.).
* **Project Type** (`project_type`, select_one, required): Choose the type of project (Project, Partnership, or Staffing).
* **Start Date** (`start_date`, date, required): Enter the start date of the project.
* **End Date** (`end_date`, date, required): Enter the end date of the project.
* **Note** (`note`, note, optional): Add any additional notes about the project.
* **Assigned Tool** (`assigned_tool`, select_one, required): Select the tool assigned to the project (Chatjimmy or other).
* **Category** (`category`, select_multiple, required): Choose the category of the project (Information Request Forms or other).
* **Description** (`description`, text, optional): Provide a short description of the project.
* **Output File Name** (`output_file_name`, text, required): Enter a name for the output file.
