# Medicaid Waiver Rate Sheet Request Form - Help Guide
## Purpose
The Medicaid Waiver Rate Sheet Request Form is designed to collect information from providers to process their waiver requests efficiently.

## How To Complete This Form
To complete this form, please follow these steps:

1. Start by entering the provider's information, including their name, address, and contact details.
2. Select the type of waiver request you are submitting.
3. Indicate whether you are a facility that has been approved and active or not.
4. Choose the type and size of your facility.
5. Provide any additional comments or explanations related to your waiver request.
6. Submit your request.

## Field-by-Field Explanation

* **Provider** (`Provider`, `text`, required): Enter the name of the provider submitting the waiver request.
* **Provider Address** (`Provider Address`, `text`, optional): Enter the address of the provider.
* **Request Date** (`Request Date`, `date`, optional): Enter the date of the request submission.
* **Contact Number** (`Contact Number`, `text`, optional): Enter the contact number of the provider.
* **Request Type** (`Request Type`, `select_one`, optional):
	+ Select `Yes` if you are submitting a waiver request.
	+ Select `No` otherwise.
* **Facility** (`Facility`, `select_multiple`, required): Check the boxes for the types of facilities that you represent.
* **Comments** (`Comments`, `note`, optional): Provide any additional comments or explanations related to your waiver request.
* **Waiver Type** (`Waiver Type`, `select_one`, optional):
	+ Select `Yes` if you are requesting a waiver.
	+ Select `No` otherwise.
* **Waiver Request** (`Waiver Request`, `text`, optional): Describe the nature of your waiver request.
* **Email** (`Email`, `email`, optional): Enter the email address of the provider.
* **Phone Number** (`Phone Number`, `text`, optional): Enter the phone number of the provider.
* **Facility Name** (`Facility Name`, `text`, optional): Enter the name of the facility.
* **Facility Address** (`Facility Address`, `text`, optional): Enter the address of the facility.
* **Facility Phone** (`Facility Phone`, `text`, optional): Enter the phone number of the facility.
* **Facility Email** (`Facility Email`, `email`, optional): Enter the email address of the facility.
* **Facility Fax** (`Facility Fax`, `text`, optional): Enter the fax number of the facility.
* **Provider Manager** (`Provider Manager`, `text`, optional): Enter the name of the provider manager.
* **Provider Manager Title** (`Provider Manager Title`, `text`, optional): Enter the title of the provider manager.
* **Facility Type** (`Facility Type`, `select_one`, optional):
	+ Select `Yes` if you are a facility with a specific type.
	+ Select `No` otherwise.
* **Facility Rating** (`Facility Rating`, `select_one`, optional):
	+ Select `Good` if you rate your facility as good.
	+ Select `Fair` otherwise.
* **Facility Status** (`Facility Status`, `select_one`, optional):
	+ Select `Active` if your facility is active.
	+ Select `Inactive` otherwise.
* **Facility Size** (`Facility Size`, `select_multiple`, optional):
	+ Select `Yes` if you have a certain size of facility.
	+ Select `No` otherwise.
* **Facility Hours** (`Facility Hours`, `select_multiple`, optional):
	+ Select `Yes` if you are open at certain hours.
	+ Select `No` otherwise.

## Tips
- Please ensure that all required fields are completed accurately and thoroughly.
- Double-check the information you enter before submitting the form.
- If you have any questions or concerns, do not hesitate to contact us for assistance.
