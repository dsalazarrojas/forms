# Low Code Development Consultation Request - Help Guide
## Purpose
This form helps you gather essential project information to discuss with our low-code development experts. Please fill it out carefully and honestly to get the most relevant advice.

## How To Complete This Form
To complete this form:

1. Fill out all required fields.
2. Choose the correct options for each field where applicable.
3. Use the provided explanations for each field as a guide.
4. Submit the form when you're finished.

## Field-by-Field Explanation
- **Project Details** (`project_details`, text, required): Enter a brief description of your project.
- **Qualify Lead** (`lead_qualification`, select_one, required): Choose "New Project" if you're starting a new project, or "Existing Project" if you're looking to continue or close an existing one.
- **Schedule Consultation** (`schedule_consultation`, select_multiple, required): Select all the ways you'd like to be contacted for the consultation (e.g., Phone Call, Meeting).
- **Project Type** (`project_type`, select_one, required): Choose whether this is a new application, existing application, new service, or existing service.
- **Expected Outcome** (`expected_outcome`, select_multiple, required): Select all the potential outcomes you expect from your project (e.g., Project Completion, Project Continuation, Project Closure, Project Delay).
- **Project Status** (`project_status`, select_one, required): Choose the current status of your project (e.g., Active, In Progress, Completed, Closed).
- **Project Deadline** (`project_deadline`, date, optional): Enter the project deadline date if applicable.
- **Project Lead Status** (`project_lead_status`, select_one, required): Choose whether this project has a new or existing lead.
- **Project Manager** (`project_manager`, text, required): Enter the project manager's name.
- **Project Manager Email** (`project_manager_email`, email, required): Enter the project manager's email address.
- **Project Manager Phone** (`project_manager_phone`, text, required): Enter the project manager's phone number.
- **Project Notes** (`project_notes`, note, optional): Add any additional notes about your project.
- **Company** (`company`, text, required): Enter your company name or name.
- **Project Contact** (`project_contact`, text, required): Enter the project contact's name or name.
- **Project Manager Location** (`project_manager_location`, text, required): Enter the project manager's location.
- **Project Description** (`project_description`, text, required): Enter a brief description of your project.
- **Technical Stack** (`technical_stack`, select_one, required): Choose the technical stack of your project (e.g., Front-end, Back-end, Full-stack, Other).
- **Project Size** (`project_size`, select_one, required): Choose the project size (e.g., Small, Medium, Large, Extra Large).
- **Project Team** (`project_team`, text, required): Enter the names of your project team.
- **Project Priority** (`project_priority`, select_one, required): Choose the project priority (e.g., High, Medium, Low).
- **Project Deadline Date** (`project_deadline_date`, date, required): Enter the project deadline date.
- **Project Deadline Time** (`project_deadline_time`, time, optional): Enter the project deadline time if applicable.
- **Project Deadline Time Zone** (`project_deadline_time_zone`, select_one, required): Choose the project deadline time zone.
- **Submission** (`submission`, text, optional): Add any additional comments or submission details.

Please note that some fields are not required to be filled out, but it's recommended to provide as much information as possible to get the most accurate advice.
