# Freedom Of Information Request Authorization Form - Help Guide
## Purpose
The Freedom Of Information Request Authorization Form is used to request and authorize access to information or records that are otherwise unavailable or inaccessible to the public. This form ensures that all required information is properly documented and signed off by authorized personnel.

## How To Complete This Form

1.  Fill out the form completely and accurately, using the following fields:
    * First name: This is the first name of the individual making the request.
    * Last name: This is the last name of the individual making the request.
    * Email: This is the email address of the individual making the request. This field is required.
    * Phone: This is the phone number of the individual making the request.
    * Date of Birth: This is the date of birth of the individual making the request.
    * Requestor ID: This is an optional field for identifying the individual making the request.
    * Purpose of Request: This is the reason or purpose of the request. This field is required.
    * Date of Request: This is the date the request was made. This field is required.
    * Contact Person Name: This is the name of the person making the request. This field is required.
    * Contact Person Email: This is the email address of the person making the request. This field is required.
    * Contact Person Phone: This is the phone number of the person making the request. This field is required.
    * Department: This is an optional field for identifying the department making the request.
    * Agency: This is an optional field for identifying the agency making the request.
    * Location: This is an optional field for identifying the location making the request.
    * Request Fee: This is an optional field for specifying the request fee.
    * Fee Paid Date: This is an optional field for specifying the date the request fee was paid.
    * Comments: This is an optional field for providing additional comments or details about the request.
    * Signature Date: This is the date the form was signed and approved. This field is required.
    * Signature Person Name: This is the name of the person signing the form. This field is required.
    * Signature Title: This is the title of the person signing the form. This field is required.
    * Signature Person Email: This is the email address of the person signing the form. This field is required.
    * Signature Person Phone: This is the phone number of the person signing the form. This field is required.
    * Authorized by: This is an optional field for specifying who authorized the request.
    * Authorization Date: This is an optional field for specifying the date the request was authorized.
    * Authorization Person Name: This is an optional field for specifying who authorized the request.
