# Request Customized Analysis - Help Guide

## Purpose
This form is used to request customized analysis support from the project management team. It gathers project-specific information to ensure that the correct resources are allocated for the analysis process.

## How To Complete This Form
To complete this form, follow the steps below:
1. Review the form pages to ensure you are filling out the correct information.
2. Select the relevant options for each field, if applicable.
3. Enter any necessary text information (e.g., project name, customer contact details).
4. Ensure that all required fields are filled out before submitting the form.

## Field-by-Field Explanation
* **Project requirements**: Select the project requirements that apply to your project. This will help the analysis team understand your project's specific needs.
* **Team Lead**: Identify if you are the team lead for this project. This information is used to ensure that the correct person is contacted for further clarification or discussion.
* **Customer name**: Enter the name of the customer associated with this project. This helps the analysis team to understand who the customer is and ensure that they are informed of any progress.
* **Project name**: Enter the name of your project. This helps the analysis team to differentiate between projects and ensure that the correct resources are allocated.
* **Expected start date**: Enter the expected start date of your project. This helps the analysis team to plan and schedule their resources accordingly.
* **Expected end date**: Enter the expected end date of your project. This helps the analysis team to plan and schedule their resources accordingly.
* **Project budget**: Enter the budget allocated for this project. This information is used to understand the project's financial constraints.
* **Priority level**: Select the priority level of your project. This helps the analysis team to allocate resources based on project urgency.
* **Analysis type**: Select the types of analysis required for this project. This helps the analysis team to understand the scope of work.
* **Project manager**: Identify if this project has a project manager. This information is used to ensure that the correct person is contacted for further clarification or discussion.
* **Customer email**: Enter the email address of the customer associated with this project. This helps the analysis team to contact the customer for any updates or questions.
* **Customer phone**: Enter the phone number of the customer associated with this project. This helps the analysis team to contact the customer for any updates or questions.

## Tips
* Ensure that all required fields are filled out before submitting the form.
* Use separate instances of this form for each project if you are submitting multiple projects.
* If you are unsure about any field, please contact the project management team for clarification.
