# COVID-19 Weekly Test Form - Help Guide
## Purpose
This form is used to collect information about a patient's COVID-19 test results, including test type, date, location, and result.
## How To Complete This Form
To complete this form, follow these steps:

*   Enter the patient's information, including their name, ID number, and date of birth.
*   Select the week during which the patient underwent the test.
*   Enter the date of the test and the type of test taken.
*   Provide information about the testing location.
*   Enter the test result.
*   Enter the date the result was received.
*   Indicate if the patient was experiencing symptoms during the test week.
*   Provide a list of symptoms the patient experienced.
*   Confirm whether the patient had close contact with a COVID-19 case.
*   Indicate the patient's vaccination status.
*   Confirm whether isolation was recommended.
*   Indicate if a follow-up test is scheduled.
*   Enter the date of the follow-up test, if scheduled.
*   Enter the name of the supervising healthcare provider.
*   Add any additional notes or information relevant to the patient's case.

## Field-by-Field Explanation
*   **Patient Name (required)**: Enter the patient's name as it appears on their medical record.
*   **Patient ID or Medical Record Number (required)**: Enter the patient's ID number or medical record number.
*   **Date of Birth (required)**: Enter the patient's date of birth.
*   **Email Address (required)**: Enter the patient's email address.
*   **Phone Number (required)**: Enter the patient's phone number.
*   **Week of Testing (required)**: Select the week during which the patient underwent the test.
*   **Date of COVID-19 Test (required)**: Enter the date the test was taken.
*   **Type of Test (required)**: Select the type of test performed.
*   **Testing Location (required)**: Enter the location where the test was performed.
*   **Test Result (required)**: Enter the result of the test (positive, negative, or inconclusive).
*   **Date Result Received (required)**: Enter the date the result was received.
*   **Symptoms Present During Test Week (required)**: Indicate if the patient was experiencing symptoms during the test week.
*   **Symptoms Experienced**: Check all the symptoms the patient experienced during the test week.
*   **Close Contact with COVID-19 Case (required)**: Confirm whether the patient had close contact with a COVID-19 case.
*   **Vaccination Status (required)**: Select the patient's vaccination status.
*   **Isolation Recommended (required)**: Confirm whether isolation was recommended.
*   **Follow-up Test Scheduled (optional)**: Indicate if a follow-up test is scheduled.
*   **Follow-up Test Date (optional)**: Enter the date of the follow-up test, if scheduled.
*   **Physician Name (optional)**: Enter the name of the supervising healthcare provider.
*   **Additional Notes (optional)**: Add any relevant information about the patient's case.
