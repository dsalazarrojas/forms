# The Idea Filter Form - Help Guide

## Purpose
The "The Idea Filter Form" is a tool designed to narrow down ideas and requests based on specific parameters. Its primary purpose is to provide a structured way to filter ideas based on priority, status, category, and other relevant criteria.

## How To Complete This Form

To complete this form, follow these steps:

1. Review each field carefully to understand its meaning and options.
2. Select the options that best match your filtering criteria.
3. Fill in all required fields, if any.
4. Submit the form to see the filtered results.

## Field-by-Field Explanation

* **Idea Filter Form Page**: This field is the first step in the form and is not a field where you can input any data. It's the initial page to navigate through.
* **Filter by Priority**: Select the priority level of the ideas you want to filter by:
	+ High: Ideas with high priority.
	+ Medium: Ideas with medium priority.
	+ Low: Ideas with low priority.
* **Filter by Status**: Select the status of the ideas you want to filter by:
	+ In Development: Ideas currently under development.
	+ Completed: Ideas that have been completed.
	+ Cancelled: Ideas that have been cancelled.
* **Filter by Category**: Select the category of ideas you want to filter by:
	+ Information Requests: Ideas related to information requests.
	+ Feedback: Ideas related to feedback.
	+ Support: Ideas related to support.
	+ Sales: Ideas related to sales.
* **Filter by Subcategory**: Select a specific subcategory under each main category:
	+ Information Requests: Information requests subcategory.
	+ Feedback: Feedback subcategory.
	+ Support: Support subcategory.
	+ Sales: Sales subcategory.
* **Filter by Date**: Select a specific date for the ideas you want to filter by. This field is for date-based filtering.
* **Filter by Time**: Select a specific time for the ideas you want to filter by. This field is for time-based filtering.
* **Filter by Description**: This field is for filtering ideas based on their descriptions. Type in the description to narrow down ideas.
* **Filter by Idea Status**: Select the status of the ideas you want to filter by:
	+ In Progress: Ideas currently in progress.
	+ Not Started: Ideas not started yet.
	+ Done: Ideas that are completed.
* **Filter by Priority Status**: Select the priority status of the ideas you want to filter by:
	+ High: Ideas with high priority status.
	+ Low: Ideas with low priority status.
	+ None: No priority status assigned.

Note: Some fields may have multiple selections allowed (e.g., select_multiple).
