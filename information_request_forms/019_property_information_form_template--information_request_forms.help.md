# property_information_form_template - Help Guide
## Purpose
This form is used to collect and store property information for internal purposes, such as property management or tracking.

## How To Complete This Form

To complete this form, follow these steps:

1. Enter the relevant details about the property in the "Property Details" field.
2. Provide the name of the property's owner in the "Property Owner" field.
3. Enter the property's address in the "Property Address" field.
4. Select the type of property from the available options in the "Property Type" field.
5. Select the subtype of property from the available options in the "Property Subtype" field. (Note: This field is optional but may be required for specific properties.)
6. Enter the current value of the property in the "Property Value" field.
7. Select the status of the property from the available options in the "Property Status" field. (Note: This field is optional but may be required for specific properties.)
8. Provide a brief description of the property in the "Property Description" field.

## Field-by-Field Explanation

*   **Property Details**: Enter a brief description of the property, including any relevant details.
*   **Property Owner**: Enter the name of the person or organization responsible for the property.
*   **Property Address**: Enter the address of the property.
*   **Property Type**: Select the type of property (e.g., residential, commercial, etc.).
*   **Property Subtype**: Select the subtype of property (e.g., office building, house, etc.). (This field is optional but may be required for specific properties.)
*   **Property Value**: Enter the current value of the property.
*   **Property Status**: Select the status of the property (Active or Inactive). (This field is optional but may be required for specific properties.)
*   **Property Description**: Enter a brief description of the property, providing any relevant details.
