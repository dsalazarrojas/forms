# Medical Record Request Form - Help Guide
## Purpose
This form is used by medical facilities to request medical records from healthcare providers. It allows you to provide your first and last name, select a medical facility, and specify a request date and time.

## How To Complete This Form
1. Fill in your first and last name in the "First Name" and "Last Name" text fields.
2. Select a medical facility from the dropdown list.
3. Choose a date for the request using the calendar picker for "Request Date."
4. Choose a time for the request using the time picker for "Request Time."

## Field-by-Field Explanation
* **First Name (Text)** (`patient_identifier`, not required): Please enter your first name as it appears on your medical records.
* **Last Name (Text)** (`last_name`, not required): Please enter your last name as it appears on your medical records.
* **Medical Facility (Select One)** (`medical_facility`, not required): Choose the medical facility where you received treatment. Please select the correct facility from the list.
* **Request Date (Date)** (`date_request`, not required): Select a date for the request using the calendar picker. This is the date you would like the records to be sent to you.
* **Request Time (Time)** (`time_request`, not required): Choose a time for the request using the time picker. This is the time you would like to receive the medical records.

## Tips
* Please make sure to fill in all required fields correctly to ensure the form is processed correctly.
* If you are unsure about any field, feel free to contact us at form@gic.mx.
