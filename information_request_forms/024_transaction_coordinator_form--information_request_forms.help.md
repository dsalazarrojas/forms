# Transaction Coordinator Form - Help Guide
## Purpose
The Transaction Coordinator Form is used to collect information from the end user to provide a comprehensive overview of a transaction. This form gathers details on various aspects of the transaction, including property details, dates, times, and other relevant information.

## How To Complete This Form
1. Start by selecting the correct options for each field. For select fields, choose one or multiple options that apply to your situation.
2. Enter text or numeric values in the text or number fields, as needed.
3. Fill out all the required fields. Although some fields are optional, filling out as much information as possible will provide a more accurate and complete picture of the transaction.
4. Review your selections and values before submitting the form to ensure accuracy and completeness.
