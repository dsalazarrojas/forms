# Non Custodial Parent Form - Help Guide
## Purpose
This form is designed to collect information about a child's non-custodial parent arrangement, including the requesting parent's relationship with the child and the custodial arrangement.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the "Non Custodial Parent Form Info" field with a brief description of the child's situation.
2. In the "Requesting Parent" field, enter the name of the parent or guardian requesting the non-custodial parent arrangement.
3. Select the custodial arrangement from the list in the "Custodial Arrangement" field.
4. If the custodial arrangement is not listed, you can enter a custom arrangement in the "Other Custodial Arrangement" field.
5. Add any additional comments or notes in the "Non Custodial Parent Form Note" field.

## Field-by-Field Explanation
### Non Custodial Parent Form Info
* **Non Custodial Parent Form Info** (`non_custodial_parent_form_info`, text, optional): A brief description of the child's situation.

### Requesting Parent
* **Requesting Parent** (`requesting_parent`, text, optional): The name of the parent or guardian requesting the non-custodial parent arrangement.

### Custodial Arrangement
* **Custodial Arrangement** (`custodial_arrangement`, select_multiple, optional): Select one or more of the following:
	+ Parent 1
	+ Parent 2
	+ Both Parents
* **Other Custodial Arrangement** (`custodial_arrangement_other`, text, optional): If the custodial arrangement is not listed, enter a custom arrangement.

### Non Custodial Parent Form Note
* **Non Custodial Parent Form Note** (`non_custodial_parent_form_note`, note, optional): Any additional comments or notes about the non-custodial parent arrangement.

## Tips
- Make sure to fill out the form accurately and honestly.
- If you are unsure about any of the fields, please consult with the relevant authorities or experts.
- This form is a generic template and may need to be adapted or modified according to your organization's specific needs and policies.
