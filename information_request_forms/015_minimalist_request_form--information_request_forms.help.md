# Minimalist Request Form - Help Guide
## Purpose
The Minimalist Request Form is designed to collect concise and essential information from users to help in processing and tracking requests efficiently.

## How To Complete This Form
To complete this form, follow these steps:

* Fill out the **General Info** section with a brief description of your request.
* Provide details about the **Requestors Info**, including any relevant information about the person or team requesting the task.
* Choose the **Priority** of your request (Normal, High, or Low) to help in determining the urgency.
* Write a detailed **Description** of the request in the space provided.
* Specify the person you would like the task to be assigned to in the **Assigned To** field.
* If applicable, provide a specific **Due Date** for the completion of the task.
* Add any additional comments or updates in the **Notes** field.

## Field-by-Field Explanation

* **General Info (1)**: A brief description of your request.
* **Requestors Info (2)**: Details about the person or team requesting the task.
* **Priority (3)**: Choose from Normal, High, or Low to determine the request's urgency.
* **Description (4)**: A detailed description of the request.
* **Assigned To (5)**: The person you would like to be assigned to this task.
* **Due Date (6)**: The date by which the task should be completed.
* **Status (7)**: Leave blank for automatic tracking.
* **Notes (8)**: Additional comments or updates about the request.

# Tips

* Make sure to fill out all required fields, marked with \*.
* Use the **Description** field for a detailed explanation of the request.
* For recurring requests, consider adding a specific **Due Date** to help in planning.
* Keep the **Notes** field for updates and comments, not for main request content.
