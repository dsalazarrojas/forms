# refer_a_friend_form - Help Guide
## Purpose
The "refer_a_friend_form" is a form designed to collect information from users who wish to refer a friend or potential client to our organization. This form is typically used by sales or business development teams to gather essential details about the referred friend or client.

## How To Complete This Form
1. Fill in all required fields with accurate and valid information.
2. Select a category for the referral from the dropdown list.
3. Enter a brief description of the referral.
4. Choose a file to output, if desired.
5. Select a tool for the assigned task, if applicable.
6. Click the "Submit" button to complete the form.

## Field-by-Field Explanation

* **Friend's name** (id: 1, required): Enter the name of the friend or client you are referring.
* **Friend's Email** (id: 2, required): Enter a valid email address of the friend or client.
* **Friend's Phone Number** (id: 3, required): Enter the phone number of the friend or client.
* **Referrer's Information** (id: 4, required): Enter your name, as you are the referrer.
* **Referrer's Email** (id: 5, required): Enter your email address.
* **Referrer's Message** (id: 6, required): Enter a brief message explaining the referral.
* **Form Category** (id: 7, required): Select a category for the referral from the list.
* **Form Description** (id: 8, required): Enter a brief description of the referral.
* **Form Title** (id: 9, required): Enter a title for the referral.
* **Form Output File** (id: 10, optional): Select a file to output, if applicable.
* **Assigned Tool** (id: 11, optional): Select a tool for the assigned task, if applicable.
* **Submit** (id: 12, required): Click this button to complete and submit the form.
* **Back** (id: 13, optional): Click this button to go back and modify the form.
* **Title 1** (id: 14, optional): This field is likely a duplicate or alternate title field.
* **Category 1** (id: 15, optional): This field is likely a duplicate or alternate category field.
* **Description 1** (id: 16, optional): This field is likely a duplicate or alternate description field.
* **Submit 1** (id: 17, optional): This button is likely a duplicate or alternate submit button.

Note: The fields marked as optional (id: 10, 11, 14, 15, 16, 17) can be ignored as they are likely duplicates or have no functionality. The user should only fill in the required fields (id: 1-9).
