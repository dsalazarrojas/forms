# Rendition Download Request Form - Help Guide
## Purpose
The Rendition Download Request Form is used to request a download of a rendition. Renditions can include various formats such as HTML, JSON, etc.

## How To Complete This Form

1. To complete this form, fill out the required information in the following fields:

## Field-by-Field Explanation

* **Rendition Format** (<type>: `select_one`): Select the desired rendition format for the download, such as "Option 1", "Option 2", or "Option 3".
* **Delivery Timeline** (<type>: `time`): Enter the delivery timeline for the download.
* **File Rendition** (<type>: `select_multiple`): Select multiple rendition options, such as "Option 1", "Option 2", or "Option 3".
* **File Name** (<type>: `text`): Enter a name for the file that you want to download.
* **File Type** (<type>: `select_multiple`): Select multiple file type options, such as "Option 1", "Option 2", or "Option 3".
* **Email** (<type>: `email`): Enter your email address where you want to receive the downloaded file.
* **Phone** (<type>: `text`): Enter your phone number where you can be reached in case of any issues with the download.
* **File Version** (<type>: `number`): Enter the version of the file you want to download.

## Tips

* Make sure to provide accurate information in the form to ensure a smooth download process.
* If you are unsure about any of the options, feel free to ask for help.
* Please note that this form is only for requesting a download of a rendition. If you need help with something else, please use the corresponding form.
