# sopw_officer_and_committee_member_agreement - Help Guide
## Purpose
This form is used to collect the agreement from Standard Operating Procedure Workflow (SOPW) officers or committee members on a specific procedure.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the category of the procedure in the "Category" field. Select the correct category from the provided options.
2. Provide a brief description of the procedure in the "Description" field.
3. Enter the name of the tool assigned to the procedure in the "Assigned Tool" field.

## Field-by-Field Explanation
### **Form Title** (`form_title`, text, optional)
* A short title for the form that will be used to identify it in the system.

### **Category** (`form_category`, select_one, optional)
* Select the category of the procedure from the provided options (e.g., Information Request Forms, Other).

### **Description** (`form_description`, text, optional)
* A brief description of the procedure being agreed upon.

### **Assigned Tool** (`form_assigned_tool`, text, optional)
* The name of the tool assigned to the procedure.
