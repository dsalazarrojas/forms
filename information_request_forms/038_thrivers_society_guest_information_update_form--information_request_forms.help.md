# thrivers_society_guest_information_update_form - Help Guide
## Purpose
The form is used to collect information from guests for the Thrivers Society. It is intended for new guests only, and you should not repeat the effort if you have already provided information.

## How To Complete This Form
To complete the form, simply follow the instructions below. Each page of the form contains its own set of fields, so please read the field-by-field explanations carefully.

## Field-by-Field Explanation

* **First Name** (`first_name`, `text`, required: false): Please enter your first name.
* **Last Name** (`last_name`, `text`, required: false): Please enter your last name.
* **Email Address** (`email_address`, `email`, required: false): Enter your email address.
* **Phone Number** (`phone_number`, `text`, required: false): Enter your phone number.
* **Date and Time** (`date_time`, `date`, required: false): Choose a date and time.
* **Select One** (`select_one`, `select_one`, required: false): Select one option from the list.
* **Select Multiple** (`select_multiple`, `select_multiple`, required: false): Select multiple options from the list.
* **Note** (`note`, `note`, required: false): Enter any additional notes or comments.
* **Time** (`time`, `time`, required: false): Select a time.
* **Integer** (`integer`, `number`, required: false): Enter an integer number.
* **Decimal** (`decimal`, `number`, required: false): Enter a decimal number.
* **Integer Array** (`integer_array`, `number`, required: false): Enter an array of integer numbers.
* **Decimal Array** (`decimal_array`, `number`, required: false): Enter an array of decimal numbers.
* **Select Array** (`select_array`, `select_multiple`, required: false): Select multiple options from the list.
* **Integer Array Again** (`integer_array_2`, `number`, required: false): Enter an array of integer numbers.
* **Decimal Array Again** (`decimal_array_2`, `number`, required: false): Enter an array of decimal numbers.
* **Select Array Again** (`select_array_2`, `select_multiple`, required: false): Select multiple options from the list.
* **Date Time 2** (`date_time_2`, `time`, required: false): Choose a date and time.
* **Select Array 3** (`select_array_3`, `select_multiple`, required: false): Select multiple options from the list.
* **Integer 2** (`integer_2`, `number`, required: false): Enter an integer number.
* **Decimal 2** (`decimal_2`, `number`, required: false): Enter a decimal number.
* **Integer Array 3** (`integer_array_3`, `number`, required: false): Enter an array of integer numbers.
* **Decimal Array 3** (`decimal_array_3`, `number`, required: false): Enter an array of decimal numbers.
* **Select Array 4** (`select_array_4`, `select_multiple`, required: false): Select multiple options from the list.
* **Integer 3** (`integer_3`, `number`, required: false): Enter an integer number.
