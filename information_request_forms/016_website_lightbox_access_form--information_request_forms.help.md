# Website Lightbox Access Form - Help Guide
## Purpose
This form is used to request access to a website's lightbox. Please fill out the form completely and accurately to ensure that your request is processed efficiently.

## How To Complete This Form
To complete this form, follow these steps:
1. Enter your return user email address in the "Return User Email" field.
2. Select the "Access Request" option to indicate your request type.
3. Provide any additional information in the "Support Inquiries" field if needed.
4. Enter "Yes" or "No" in the "Return User" field, depending on whether you want to return to the user after processing their request.
5. Enter the login links list, if applicable.
6. Enter the support inquiry type, if applicable.
7. Enter the return user phone number, email address, language, and any other relevant information.
8. Finally, submit the form to send your request to the website administrators.

## Field-by-Field Explanation
* **Access Request** (`Access Request`, text, required/optional): Select this option to indicate that you are requesting access to the lightbox.
* **Return User Email** (`user_email`, email, required): Enter the email address of the user requesting access.
* **Return User Phone** (`user_phone`, text, required/optional): Enter the phone number of the user requesting access.
* **Support Inquiries** (`support_inquiries`, note, required/optional): Enter any additional information or comments that may be relevant to your request.
* **Login Links** (`login_links`, select_one, required): Select "Yes" if you are requesting access to a list of login links.
* **Return User** (`return_user`, select_multiple, required): Indicate whether you want to return to the user after processing their request. 
* **Support Inquiry** (`support_inquiry`, select_one, required/optional): Select "Yes" if you are requesting support for your inquiry.
* **Return User Phone 2** (`return_user_phone_2`, text, required/optional): Enter any additional phone number for return user.
* **Return User Email 2** (`return_user_email_2`, email, required/optional): Enter any additional email address for return user.
* **Support Inquiry Type** (`support_inquiry_type`, select_one, required/optional): Select the type of support inquiry you are requesting.
* **Return User Country** (`return_user_country`, select_multiple, required/optional): Select the country of the return user.
* **Support Inquiry Comments** (`support_inquiry_comments`, note, required/optional): Enter any comments or additional information about the support inquiry.
* **Support Inquiry Priority** (`support_inquiry_priority`, select_one, required/optional): Select the priority of the support inquiry.
* **Return User Language** (`return_user_language`, select_multiple, required/optional): Select the language of the return user.
* **Login Links ID** (`login_links_id`, number, required): Enter the ID of the login links list.
* **Return User ID** (`return_user_id`, number, required): Enter the ID of the return user.
* **Support Inquiry ID** (`support_inquiry_id`, number, required): Enter the ID of the support inquiry.
* **Return User Date** (`return_user_date`, date, required): Enter the date of the return user.
* **Return User Time** (`return_user_time`, time, required): Enter the time of the return user.

**Tips**: Please make sure to fill out all required fields accurately and completely to ensure that your request is processed efficiently. If you have any questions or concerns, feel free to reach out to the website administrators for assistance.
