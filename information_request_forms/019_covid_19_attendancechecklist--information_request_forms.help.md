# COVID 19 AttendanceChecklist - Help Guide
## Purpose
This form is designed to collect information about a student's attendance and health status for COVID-19 related purposes.

## How To Complete This Form

1. Fill out the form with the student's information.
2. Select the correct date of the class or activity.
3. Enter the student's full name.
4. If available, enter the student's unique identifier.
5. Select the student's current belt rank.
6. Select the student's age group.
7. Choose the type of class the student attended.
8. Select the attendance status for the student.
9. Indicate if the health screening was completed and passed or not.
10. Confirm if the student has a fever.
11. Check if the student has any COVID-19 symptoms.
12. Answer if the student was exposed to someone with COVID in the past 14 days.
13. Indicate if the student wore a mask during class.
14. Check if social distancing was maintained during class.
15. Confirm the student's vaccination status.
16. Answer if the student has a recent COVID-19 test result.
17. Indicate if the equipment was sanitized before use.
18. Check if the student practiced hand hygiene.
19. If the student is a minor, enter the parent/guardian's name and phone number.
20. Sign the form with your name.

## Field-by-Field Explanation

* **Class Date (id: 1, label: Class Date, type: date, required: true):** Enter the date of the class or activity the student attended.
* **Student Name (id: 2, label: Student Name, type: text, required: true):** Enter the full name of the student.
* **Student ID (id: 3, label: Student ID, type: text, required: false):** If available, enter the student's unique identifier.
* **Belt Level (id: 4, label: Belt Level, type: select_one, required: false):** Select the student's current belt rank.
* **Age Group (id: 5, label: Age Group, type: select_one, required: true):** Select the student's age group.
* **Class Type (id: 6, label: Class Type Attended, type: select_one, required: true):** Choose the type of class the student attended.
* **Attendance Status (id: 7, label: Attendance Status, type: select_one, required: true):** Select the attendance status for the student.
* **Health Screening (id: 8, label: Health Screening Completed and Passed, type: select_one, required: true):** Indicate if the health screening was completed and passed or not.
* **Temperature Check (id: 9, label: Fever Present, type: select_one, required: false):** Confirm if the student has a fever.
* **Symptoms (id: 10, label: COVID-19 Symptoms Present, type: select_one, required: true):** Check if the student has any COVID-19 symptoms.
* **Recent Exposure (id: 11, label: Recent COVID-19 Exposure, type: select_one, required: false):** Answer if the student was exposed to someone with COVID in the past 14 days.
* **Mask Worn (id: 12, label: Mask Worn During Class, type: select_one, required: false):** Indicate if the student wore a mask during class.
* **Social Distancing (id: 13, label: Social Distancing Maintained, type: select_one, required: false):** Check if social distancing was maintained during class.
* **Vaccination (id: 14, label: Vaccination Status, type: select_one, required: false):** Confirm the student's vaccination status.
* **Recent Test Result (id: 15, label: Recent COVID-19 Test Result, type: select_one, required: false):** Answer if the student has a recent COVID-19 test result.
* **Equipment Sanitized (id: 16, label: Equipment Sanitized Before Use, type: select_one, required: false):** Indicate if the equipment was sanitized before use.
* **Hand Hygiene (id: 17, label: Student Practiced Hand Hygiene, type: select_one, required: false):** Check if the student practiced hand hygiene.
* **Parent/Guardian Info (id: 18-20, label: Parent/Guardian Name/Phone, type: text/text, required: false):** If the student is a minor, enter the parent/guardian's name and phone number.
* **Signed By (id: 21, label: Signed By, type: text, required: true):** Sign the form with your name.

## Tips

* Make sure to fill out the form accurately and completely.
* If unsure about any question, answer "Not assessed" or "Not applicable" when possible.
* If the student is a minor, provide the parent/guardian's contact information.
* Sign the form with your name.
