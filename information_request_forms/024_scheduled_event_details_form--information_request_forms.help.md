# Scheduled Event Details Form - Help Guide
## Purpose
This form is designed to collect information about scheduled events, helping our organization manage and plan events effectively.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the **Guest List** field with a list of names and numbers of guests attending the event.
2. Select the **Event Schedule** date for the event.
3. Enter the **Budget** allocated for the event.
4. Provide a brief description of the **Event Details** in the text field.

## Field-by-Field Explanation
* **Guest List**: Enter a list of names and contact information for all guests attending the event.
* **Event Schedule**: Select the date for the event from the calendar.
* **Budget**: Enter the total budget allocated for the event, including all expenses and costs.
* **Event Details**: Briefly describe the event, including its purpose, location, and any other relevant details.

## Tips
* Ensure that all fields are filled in accurately and completely to avoid missing important information.
* If you have any issues or questions while filling this form, please reach out to the relevant team directly.
* If you need to update an existing event, contact the relevant team for assistance.
