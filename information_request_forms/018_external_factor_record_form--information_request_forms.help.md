# External Factor Record Form - Help Guide
## Purpose
This form is used to record and document external factors that may impact the organization. This includes political, economic, social, technological, and environmental factors that need to be assessed and managed.

## How To Complete This Form
1. Select all applicable factors by answering "Yes" or "No" to the first 5 questions.
2. Enter a brief description of the external factor in the "Description" field.
3. Answer the questions regarding the risk level, impact, and likelihood of the external factor.
4. Provide potential mitigation strategies in the "Mitigation Strategies" field.

## Field-by-Field Explanation

* **Is the external factor political in nature?**
	+ Label: political_factor_1
	+ Type: Select One
	+ Purpose: To determine if the external factor is political in nature.
* **What is the economic value of the external factor?**
	+ Label: economic_value
	+ Type: Number
	+ Purpose: To assess the economic value of the external factor.
* **What is the social impact of the external factor?**
	+ Label: social_impact
	+ Type: Text
	+ Purpose: To describe the social impact of the external factor.
* **Is the external factor technological in nature?**
	+ Label: technological_factor_1
	+ Type: Select One
	+ Purpose: To determine if the external factor is technological in nature.
* **Is the external factor environmental in nature?**
	+ Label: environmental_factor_1
	+ Type: Select One
	+ Purpose: To determine if the external factor is environmental in nature.
* **What is the risk level of the external factor?**
	+ Label: threat_level
	+ Type: Select One
	+ Purpose: To assess the risk level of the external factor.
* **Please provide a brief description of the external factor.**
	+ Label: description
	+ Type: Text
	+ Purpose: To describe the external factor in brief.
* **Does the external factor have an impact on our organization?**
	+ Label: impact
	+ Type: Select One
	+ Purpose: To determine if the external factor has an impact on the organization.
* **How likely is the external factor to occur?**
	+ Label: likelihood
	+ Type: Number
	+ Purpose: To assess the likelihood of the external factor.
* **What are the potential mitigation strategies for the external factor?**
	+ Label: mitigation_1
	+ Type: Text
	+ Purpose: To describe potential strategies to mitigate the external factor.
* **Likelihood (1-6)**
	+ Label: likelihood_2
	+ Type: Number
	+ Purpose: To rate the likelihood of the external factor on a scale of 1-6.
* **Potential Mitigation Strategies**
	+ Label: mitigation_2
	+ Type: Text
	+ Purpose: To describe potential mitigation strategies to manage the external factor.

## Tips
* Please be as specific as possible when answering the questions.
* If you are unsure about any of the questions, please contact the relevant department for clarification.
* Make sure to save your submission and return to the form to update or modify your entry if needed.
