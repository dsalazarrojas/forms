# Dropbox File Request Form - Help Guide
## Purpose
The Dropbox File Request Form is a tool used to collect information from users about files they need to request from a Dropbox repository. This form ensures that file requests are properly documented and tracked, reducing duplication and making it easier for the team to locate and retrieve requested files.

## How To Complete This Form
To complete this form, follow these steps:

* Enter a brief description of the file you are requesting, including its location within the Dropbox repository, in the "Description" field.
* Select the type of file you are requesting (if applicable) from the "File Type" dropdown menu.
* Indicate the size of the file you are requesting in the "File Size" field.
* You can also attach a file directly from the "Upload File" field, if necessary.
* Once you have filled out all the necessary fields, click "Submit" to send your file request to the team.

## Field-by-Field Explanation

* **Description (Description, text, required)**: Provide a brief description of the file you are requesting, including its location within the Dropbox repository.
* **File Type (File Type, select_multiple, not required)**: Choose the type of file you are requesting. If you're unsure of the file type, you can select "Other" and provide additional details.
* **File Size (File Size, number, not required)**: Enter the expected size of the file you are requesting. This will help the team locate the file more efficiently.
* **Upload File (Upload File, text, not required)**: If you have the file and need to attach it to the request, select "Attach File" and upload the file from your computer.
* **Attach File (Upload File, text, not required)**: If you have selected "Attach File", you can browse to the location of the file on your computer and select it to upload to the form.
* **File Type Options (File Type, select_multiple, not required)**: This field is only visible when "File Type" is selected as "Other". It allows you to specify the file type if it doesn't match one of the pre-defined options.
