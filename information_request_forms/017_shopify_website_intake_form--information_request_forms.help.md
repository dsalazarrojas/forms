# shopify_website_intake_form - Help Guide
## Purpose
This form is intended to collect information about a client's Shopify website for internal use. This form is not meant for public submission.

## How To Complete This Form
To complete this form, follow these steps:

1. Review the form carefully and ensure you are submitting accurate information.
2. Fill out the required fields, marked as "true" in the form.
3. Select the most accurate options from the dropdown lists.
4. Provide any additional information that is not captured by the form fields.

## Field-by-Field Explanation

* **shopify_website_info**: This field is for general information about the Shopify website. Please provide a brief description of the website, including its purpose and any other relevant details.
* **shopify_client_name**: This field is for the name of the client associated with the website.
* **shopify_website_name**: This field is for the name of the Shopify website.
* **shopify_client_email**: This field is for the email address of the client.
* **shopify_client_phone**: This field is for the phone number of the client.
* **shopify_website_type**: This field is for the type of website (e.g. E-commerce, Blog, Other). Please select the most accurate option.
* **shopify_client_website_description**: This field is for a brief description of the website.
* **shopify_client_notes**: This field is for any additional notes about the website.
* **shopify_website_tags**: This field is for selecting multiple tags that describe the website.
* **shopify_client_tags**: This field is for selecting multiple tags that describe the client.
* **shopify_client_tag**: This field is for selecting multiple tags that describe the client.
* **shopify_client_tag_1**: This field is for selecting multiple tags that describe the client. (Duplicate field, please review if necessary)
* **shopify_client_tag_2**: This field is for selecting multiple tags that describe the client. (Duplicate field, please review if necessary)
* **shopify_client_tag_3**: This field is for selecting multiple tags that describe the client. (Duplicate field, please review if necessary)
* **shopify_client_tag_4**: This field is for selecting multiple tags that describe the client. (Duplicate field, please review if necessary)
* **shopify_website_intents**: This field is for selecting multiple intents that describe the website.
* **shopify_client_website_image**: This field is for the URL of the website's image.
* **shopify_client_website_link**: This field is for the URL of the website.
* **shopify_client_website_color**: This field is for the color of the website.
* **shopify_client_website_size**: This field is for the size of the website.
* **shopify_client_website_background**: This field is for the background image of the website.
* **shopify_client_website_background_color**: This field is for the background color of the website.
* **shopify_client_website_favicon**: This field is for the favicon of the website.
* **shopify_client_website_css**: This field is for the CSS code of the website.
* **shopify_client_website_js**: This field is for the JS code of the website.
