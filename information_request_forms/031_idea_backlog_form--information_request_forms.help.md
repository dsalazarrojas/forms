# Idea Backlog Form - Help Guide
## Purpose
The Idea Backlog Form is used for collecting and documenting ideas, bugs, features, and enhancements that need to be implemented or tracked. 

## How To Complete This Form
1. Click on the "New Idea" button to start filling out the form.
2. Fill out the form with the required and optional fields as described below.
3. Submit the form when finished.

## Field-by-Field Explanation
* **Enter Idea Title** (`idea_title`, text, Optional): Enter a brief and descriptive title for the idea you are submitting.
* **Idea Description** (`description`, text, Optional): Provide a detailed description of the idea you are submitting.
* **Type** (`type`, select_one, Optional): Select the type of idea you are submitting (bug, feature, or enhancement).
* **Priority** (`priority`, select_one, Optional): Set the priority of the idea (High, Low, Medium).
* **Due Date** (`due_date`, date, Optional): Enter the date by which the idea needs to be implemented or resolved.
* **Due Time** (`due_time`, time, Optional): Enter the time by which the idea needs to be implemented or resolved.
* **Assigned To** (`assigned_to`, select_multiple, Optional): Select one or more team members who are responsible for the idea.
* **Comments** (`comments`, note, Optional): Add any additional comments or details about the idea.
* **Tags** (`tags`, text, Optional): Enter any relevant tags or keywords for the idea.
* **Email** (`email`, email, Optional): Enter the email address of the person submitting the idea.
* **Phone** (`phone`, text, Optional): Enter the phone number of the person submitting the idea.

## Tips
- Please ensure that you are submitting unique and non-duplicate ideas.
- If you need to submit multiple ideas, please do so with new forms.
- If you have any questions or concerns, please contact the form administrators.
