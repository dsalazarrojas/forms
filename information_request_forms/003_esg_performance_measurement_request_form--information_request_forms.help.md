# ESG Performance Measurement Request Form - Help Guide
## Purpose
This form is designed to collect information on various aspects of ESG (Environmental, Social, and Governance) performance measurements.
## How To Complete This Form
- Read the form instructions carefully before filling out the form.
- Select the correct category, subcategory, request type, status, and other relevant options that apply to your request.
- Fill out the "Description" field with a clear and concise description of your request.
- If applicable, select the correct "Request Date" and fill out the "Comments" and "Additional Comments" fields with any relevant details.
- If necessary, attach any supporting documentation or files.

## Field-by-Field Explanation
- **ESG Performance Request**:
  - This field asks whether the requested ESG performance measurement is a new or existing record.
  - Please select "Yes" for a new measurement, and "No" if the measurement is not new.
- **Category**:
  - Select the primary category related to the ESG performance measurement.
  - Please choose the option that best describes the type of measurement being requested.
- **Subcategory**:
  - This field is related to the selected category.
  - Choose the corresponding subcategory that aligns with the selected category.
- **Request Type**:
  - Indicate the type of request being made for the ESG performance measurement.
  - Select the option that accurately represents the nature of the request.
- **Description**:
  - Provide a clear and concise description of the ESG performance measurement request.
  - Make sure to include any relevant details that will help the relevant teams and departments evaluate the request.
- **Status**:
  - Indicate the current status of the ESG performance measurement request.
  - Select the option that accurately represents the status of the request.
- **Priority**:
  - If the request is urgent or has a high level of importance, select "Yes" for a high priority.
  - Otherwise, select "No".
- **Request Date**:
  - This field is for the date the request was made or when the measurement is expected to be completed.
  - Please enter the date in the correct format.
- **Requester**:
  - Identify the person or department making the ESG performance measurement request.
  - Select the option that corresponds with the correct requester.
- **Department**:
  - Select the department that is responsible for the ESG performance measurement request.
  - This will help ensure that the request is properly routed and addressed.
- **Comments**:
  - Include any comments or feedback related to the ESG performance measurement request.
  - This will help the relevant teams and departments understand the request better.
- **Attachment**:
  - If you need to attach any supporting documentation or files, select "Yes".
  - Make sure to attach the necessary files or documentation.
- **Additional Comments**:
  - Provide any other relevant information or details that may be helpful for evaluating the ESG performance measurement request.
  - Make sure to include any additional comments or notes that will aid in the evaluation process.
