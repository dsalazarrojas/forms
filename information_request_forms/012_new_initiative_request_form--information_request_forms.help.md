# New Initiative Request Form - Help Guide
## Purpose
The New Initiative Request Form is used to gather information and request a new initiative. This form helps to ensure that all necessary details are collected before a new project or activity is initiated.

## How To Complete This Form

1. Fill out the form completely and accurately. This will help the review process and reduce potential mistakes.
2. Provide a clear and concise description of the new initiative.
3. Specify whether the initiative is categorized as "Yes" or "No".
4. Select relevant subcategories (if applicable).
5. Provide any additional details that will help in understanding the initiative.
6. Select a location where the initiative will take place.
7. Identify the team responsible for the initiative.
8. Set both a start and end date for the initiative.
9. Specify the status of the initiative (Active or Inactive).
10. Add any relevant notes.

## Field-by-Field Explanation

* **New Initiative Form** (`new_initiative_form_1`): Enter a brief title for the new initiative.
* **Description** (`description`): Provide a clear and concise description of the new initiative.
* **Category** (`category`): Choose "Yes" if the initiative fits into the main category, "No" otherwise.
* **Subcategory** (`subcategory`): Select all relevant subcategories for the initiative.
* **New Initiative Details** (`new_initiative_details`): Add any additional details that are not covered in the description.
* **Location** (`location`): Enter the location where the initiative will take place.
* **Team** (`team`): Identify the team responsible for the initiative.
* **Start Date** (`start_date`): Set the date when the initiative will start.
* **End Date** (`end_date`): Set the date when the initiative will end.
* **Status** (`status`): Choose "Active" if the initiative is live, "Inactive" otherwise.
* **Notes** (`notes`): Add any additional information or comments about the initiative.
