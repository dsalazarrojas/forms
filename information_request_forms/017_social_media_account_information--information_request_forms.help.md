# Social Media Account Information - Help Guide

## Purpose
This form is used to collect information about a person's social media account. Please provide accurate and up-to-date information.

## How To Complete This Form
To complete this form, simply follow the steps below:

1. Review the form to ensure you have all the necessary information before starting.
2. Fill in the required fields with accurate and up-to-date information.

## Field-by-Field Explanation

### First Name
• **First Name**: Enter the person's first name.

### Last Name
• **Last Name**: Enter the person's last name.

### Email
• **Email**: Enter the person's email address. Make sure to use a valid email format (e.g., user@example.com).

### Phone Number
• **Phone Number**: Enter the person's phone number. Use digits only, without any special characters.

### Date of Birth
• **Date of Birth**: Enter the person's date of birth in the format MM/DD/YYYY.

### Tips
• Please ensure that all fields are filled in accurately and consistently with the person's actual information.
• If you're unsure about any field, ask the person for clarification.
• This form is not intended for duplicate submissions. If you've already submitted this form for this person, please do not resubmit.
