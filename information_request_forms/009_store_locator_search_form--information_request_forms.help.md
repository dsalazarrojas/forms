# Store Locator Search Form - Help Guide
## Purpose
The Store Locator Search Form is a tool to help users find stores by various criteria such as category, location, and other attributes. Fill out the form below to search for stores that fit your needs.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the category of the store you are looking for (e.g. Retail Stores, Service Centers, etc.)
2. Choose the location of the store (e.g. Downtown, Uptown, Mall, etc.)
3. If you know the store name, enter it in the "Store Name" field
4. Optionally, select how you would like to sort the search results (e.g. Alphabetically, by Distance)
5. Optionally, select the distance range from the store location to the search location (e.g. 1-5 Miles, 6-10 Miles, etc.)
6. Optionally, select the unit of measurement for the distance (e.g. Kilometers, Miles)
7. If you want to get more detailed store information, enter the store's phone number, email, website, hours of operation, and description

## Field-by-Field Explanation

* **Store Locator Search** (`1`, `text`, required): Enter your search query.
* **Select Category** (`2`, `select_one`, required): Choose the category of the store you are looking for (e.g. Retail Stores, Service Centers, etc.).
* **Select Location** (`3`, `select_one`, required): Choose the location of the store you are looking for (e.g. Downtown, Uptown, Mall, etc.).
* **Store Name** (`4`, `text`, optional): If you know the store name, enter it here.
* **Select Sort By** (`5`, `select_one`, optional): Choose how you would like to sort the search results (e.g. Alphabetically, by Distance).
* **Select Distance** (`6`, `select_one`, optional): Choose the distance range from the store location to the search location (e.g. 1-5 Miles, 6-10 Miles, etc.).
* **Select Distance Unit** (`7`, `select_one`, optional): Choose the unit of measurement for the distance (e.g. Kilometers, Miles).
* **Store Hours** (`8`, `time`, optional): Enter the store hours of operation.
* **Store Phone** (`9`, `text`, optional): Enter the store's phone number.
* **Store Email** (`10`, `email`, optional): Enter the store's email address.
* **Store Website** (`11`, `text`, optional): Enter the store's website.
* **Select Distance Value** (`12`, `number`, optional): Enter the distance value.
* **Store Rating** (`13`, `number`, optional): Enter the store rating.
* **Store Description** (`14`, `note`, optional): Enter a brief description of the store.
* **Submit** (`15`, `text`, required): Click the "Submit" button to execute the search.

Note: All fields with asterisk (*) before the label are required fields.
