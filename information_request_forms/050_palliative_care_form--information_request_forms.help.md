# Palliative Care Form - Help Guide
## Purpose
The Palliative Care Form is used to gather essential information about a patient's condition to inform palliative care decisions.

## How To Complete This Form
1. Review the form and ensure all required fields are completed before submitting.
2. Complete each field according to the instructions below.

## Field-by-Field Explanation

* **Patient Information**: This field collects general information about the patient, such as demographic data.
* **Symptoms**: Select all symptoms that apply to the patient's condition. Please use the provided options or select "Other" and describe the symptom in the text field.
* **Medical History**: Select the most relevant medical history option that best describes the patient's condition.
* **Medical Prognosis**: Enter the patient's expected medical prognosis (e.g., "Good", "Fair", "Poor").
* **Treatment Plans**: Select all relevant treatment plans for the patient's condition. If "Other" is selected, describe the treatment plan in the text field.
* **Palliative Care**: Select the most appropriate palliative care option for the patient's condition.
* **Medications**: Indicate whether the patient is currently taking any medications.
* **Patient Goals**: Enter any specific goals or objectives the patient has for their care.

Note: This guide is for information purposes only and should not be used to make medical decisions. Consult with a healthcare professional for proper assessment and care.
