# Stock Forecasting Data Request Form - Help Guide
## Purpose
The purpose of this form is to collect data for stock forecasting. This form is used to gather information from users to help with investment analysis, trading, and research. The form is designed to be completed by users with relevant information about the stocks they are interested in.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the stock symbol in the `stock_symbol` field.
2. Select the desired forecast period in the `forecast_period` field (1 day, 1 month, 3 months, 6 months, or 1 year).
3. Specify the urgency of the request (low, medium, or high) if applicable.
4. Indicate the intended use of the forecast (investment analysis, trading, or research).
5. Select the type of stock forecast (Fundamental Data, Technical Analysis, or Sentiment Analysis).
6. Select the frequency of the forecast (daily, weekly, or monthly).
7. Enter the start and end dates for the forecast period.
8. Specify the unit of time for the forecast period (days, weeks, or months).
9. Indicate the team that will be using the forecast (Investment Team, Financial Team, or Research Team).
10. Select the status of the request (Pending, Completed, or In Progress).

## Field-by-Field Explanation

* **Stock Symbol** (`stock_symbol`, text, optional): Enter the stock symbol (e.g., XYZ123).
* **Forecast Period** (`forecast_period`, select_one, required): Select the forecast period (1 day, 1 month, 3 months, 6 months, or 1 year).
* **Urgency** (`urgency`, select_one, optional): Specify the urgency of the request (low, medium, or high).
* **Intended Use** (`intended_use`, text, optional): Indicate the intended use of the forecast (investment analysis, trading, or research).
* **Stock Forecast Type** (`stock_forecast_type`, select_multiple, optional): Select the type of stock forecast (Fundamental Data, Technical Analysis, or Sentiment Analysis).
* **Stock Forecast Frequency** (`stock_forecast_frequency`, select_one, optional): Select the frequency of the forecast (daily, weekly, or monthly).
* **Stock Forecast Start Date** (`stock_forecast_start_date`, date, optional): Enter the start date for the forecast period.
* **Stock Forecast End Date** (`stock_forecast_end_date`, date, optional): Enter the end date for the forecast period.
* **Stock Forecast Frequency Unit** (`stock_forecast_frequency_unit`, select_one, optional): Specify the unit of time for the forecast period (days, weeks, or months).
* **Stock Forecast Use** (`stock_forecast_use`, select_one, optional): Indicate the team that will be using the forecast (Investment Team, Financial Team, or Research Team).
* **Stock Forecast Status** (`stock_forecast_status`, select_one, required): Select the status of the request (Pending, Completed, or In Progress).
* **Stock Symbol 2** (`stock_symbol2`, text, optional): Enter an additional stock symbol (e.g., ABC123).
* **Stock Forecast Type 2** (`stock_forecast_type2`, select_multiple, optional): Select the type of stock forecast for the additional stock (Fundamental Data, Technical Analysis, or Sentiment Analysis).
* **Stock Forecast Frequency 2** (`stock_forecast_frequency2`, select_one, optional): Select the frequency of the forecast for the additional stock (daily, weekly, or monthly).
* **Stock Forecast Start Date 2** (`stock_forecast_start_date2`, date, optional): Enter the start date for the additional forecast period.
* **Stock Forecast End Date 2** (`stock_forecast_end_date2`, date, optional): Enter the end date for the additional forecast period.
* **Stock Forecast Frequency Unit 2** (`stock_forecast_frequency_unit2`, select_one, optional): Specify the unit of time for the additional forecast period (days, weeks, or months).
* **Stock Forecast Use 2** (`stock_forecast_use2`, select_one, optional): Indicate the team that will be using the additional forecast (Investment Team, Financial Team, or Research Team).
* **Stock Forecast Status 2** (`stock_forecast_status2`, select_one, optional): Select the status of the additional request (Pending, Completed, or In Progress).
* **Stock Forecast Type 3** (`stock_forecast_type3`, select_multiple, optional): Select the type of stock forecast for the additional stock (Yes or No).
* **Stock Forecast Frequency 3** (`stock_forecast_frequency3`, select_one, optional): Select the frequency of the additional stock (Yes or No).
* **Stock Forecast Start Date 3** (`stock_forecast_start_date3`, date, optional): Enter the start date for the additional forecast period.
* **Stock Forecast End Date 3** (`stock_forecast_end_date3`, date, optional): Enter the end date for the additional forecast period.
