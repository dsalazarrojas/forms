# Student Records Request Form - Help Guide
## Purpose
The Student Records Request Form is used to collect information about a student's records, including exam results, homework results, and other relevant details. This form should only be filled out for valid reasons, such as academic verification or official certification.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the student's name in the "Name" field.
2. Enter the student's ID number in the "Student ID" field.
3. Enter any relevant exam results in the "Exam Results" field.
4. Enter any relevant homework results in the "Homework Results" field.
5. Add any additional comments or information about the request in the "Comments" field.
6. If applicable, select the "Assigned Tool" field to specify the tool assigned to the student.
7. Choose the category of the request from the "Category" field.
8. Enter a brief description of the request in the "Description" field.
9. Upload any relevant output file in the "Output File" field.

## Field-by-Field Explanation
* **Name (Name)**: Enter the student's full name as it appears on their records.
* **Student ID (Student ID)**: Enter the student's ID number, if available.
* **Exam Results (Exam Results)**: Enter any relevant exam results or scores.
* **Homework Results (Homework Results)**: Enter any relevant homework results or scores.
* **Comments (Comments)**: Add any additional comments or information about the request.
* **Assigned Tool (Assigned Tool)**: If applicable, select the tool assigned to the student to help with the request.
* **Category (Category)**: Choose the category of the request from the options provided.
* **Description (Description)**: Enter a brief description of the request.
* **Output File (Output File)**: Upload any relevant output file that supports the request.

## Tips
* Make sure to fill out all required fields accurately and completely.
* If you are unsure about any field, please contact the relevant authority for assistance.
* This form is for official use only, please do not fill it out for personal or speculative purposes.
* Ensure that the request is valid and necessary before submitting it.
