# Directory Information Opt Out Form - Help Guide
## Purpose
This form is used to collect directory information opt out information from students and their guardians. This information will be used for the purpose of keeping student records up to date, as per the relevant laws and regulations.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill in the student name.
2. Fill in the guardian name.
3. Enter the email address.
4. Enter the address.

## Field-by-Field Explanation
### Student Name
* **student_name** (`text`, optional): Enter the student's name.

### Guardian Name
* **guardian_name** (`text`, optional): Enter the name of the guardian or person responsible for the student.

### Email
* **email** (`email`, optional): Enter the email address of the guardian or person responsible for the student. Please make sure to enter a valid email address in the correct format (e.g. `user@example.com`).

### Address
* **Address** (`text`, optional): Enter the address of the guardian or person responsible for the student.

## Tips
- Please make sure to fill in all fields accurately and completely.
- If you need to fill in this form for multiple students, repeat the process for each student.
- If you have any questions or concerns, contact us at `form@gic.mx`.
