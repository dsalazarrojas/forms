# seo_content_details_form - Help Guide
## Purpose
The purpose of this form is to collect SEO details and target audience information about a content piece.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the website URL in the "Website URL" field.
2. Select keywords that best describe the content's topic in the "Keywords" field.
3. Enter a brief description of the content in the "Meta Description" field.
4. Choose the content type from the "Content Type" field.
5. Enter the content's length in the "Content Length" field.
6. Choose the unit of measurement for content length from the "Content Length Unit" field.
7. Select the target audience's age group in the "Content Target Audience Age" field.
8. Select the content's language in the "Content Language" field.
9. Choose the target audience's location (city, region, country) in the "Content Target Audience Location" field.
10. Select the content's target audience's education level in the "Content Target Audience Education" field.
11. Select the content's target audience's interests in the "Content Target Audience Interest" field.
12. Select the content's target audience's occupation in the "Content Target Audience Occupation" field.
13. Select the content's target audience's income level in the "Content Target Audience Income" field.
14. Select the content's target audience's location (country) in the "Content Target Audience Location Country" field.
15. Select the content's target audience's location (region) in the "Content Target Audience Location Region" field.

## Field-by-Field Explanation
* **Website URL** (1): Enter the website's URL to help us understand where the content will be hosted.
* **Keywords** (2): Select keywords that best describe the content's topic, such as "tech news", "gaming review", etc.
* **Meta Description** (3): Enter a brief description of the content, approximately 155 characters. This will be used as a summary for search engines.
* **Content Type** (4): Choose from the options to indicate the content type, e.g., article, blog post, product review, etc.
* **Content Length** (5): Enter the length of the content in numbers, e.g., 500 words.
* **Content Length Unit** (6): Choose the unit of measurement for content length, e.g., words, characters, etc.
* **Content Target Audience Age** (11): Select the age group that the content is intended for.
* **Content Language** (16): Choose the language in which the content is written, e.g., English, Spanish, French, etc.
* **Content Target Audience Location** (12): Choose the city, region, or country where the content's target audience is located.
* **Content Target Audience Education** (15): Select the education level of the content's target audience.
* **Content Target Audience Interest** (14): Select the interests of the content's target audience.
* **Content Target Audience Occupation** (13): Select the occupation of the content's target audience.
* **Content Target Audience Income** (18): Select the income level of the content's target audience.
* **Content Target Audience Location Country** (19): Choose the country where the content's target audience is located.
* **Content Target Audience Location Region** (22): Select the region where the content's target audience is located.
* **Content Target Audience Location City** (21): Enter the city of the content's target audience location.
* **Content Target Audience Postal Code** (23): Enter the post code or zip code of the content's target audience location.
* **Content Target Audience Latitude** (24): Enter the latitude of the content's target audience location.
* **Content Target Audience Longitude** (25): Enter the longitude of the content's target audience location.
* **Content Publish Date** (8): Enter the date the content will be published, if applicable.
* **Content Publish Date Time** (9): Enter the time the content will be published, if applicable.
* **Content Target Audience Gender** (10): Select the gender of the content's target audience, if applicable.
* **Content Target Audience Location Region** (20): Select the region of the content's target audience location.
* **Content Target Audience Region** (22): Select the region where the content's target audience is located.
