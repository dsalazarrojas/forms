# HR Research Data Access Request Form - Help Guide
## Purpose
The HR Research Data Access Request Form is a document that allows authorized personnel to request access to HR data for legitimate business purposes. This form is designed to ensure that only approved employees can access sensitive employee information.

## How To Complete This Form
- To complete this form, please provide the required information in the corresponding fields.
- Review each field carefully to ensure accuracy and completeness.

## Field-by-Field Explanation
* **Form ID 1 (<name>, <type>, required/optional: <name>):** This field is for identification purposes only. Please enter your unique employee ID as per the company's standard policy.
  * Example: 12345
* **Form ID 2 (form-id-2, <type>, required/optional: <name>):** Enter your name in the format "Last name, First name" to ensure accurate identification.
  * Example: Doe, John
* **Form ID 3 (form-id-3, <type>, required/optional: <name>):** Select the reason for your data access request. This will help the HR department understand your needs and ensure you receive the correct data.
  * Examples: Research project, Compliance reporting, Employee development
* **Form ID 4 (form-id-4, <type>, required/optional: <name>):** Specify the specific data you need to access. Be as detailed as possible to ensure you receive the correct data.
  * Example: Employee demographics, Attendance history, Salary data
* **Form ID 5 (form-id-5, <type>, required/optional: <name>):** Choose the duration of data you need. Select a start date and end date for the data period you require.
  * Examples: Last quarter, Last year, Specific dates (YYYY-MM-DD)
* **Form ID 6 (form-id-6, <type>, required/optional: <name>):** Select the data format you prefer. This will help the data provider understand your needs.
  * Examples: Excel, CSV, PDF
* **Form ID 7 (form-id-7, <type>, required/optional: <name>):** Attach any supporting documents or files that support your request. These may include project proposals, meeting minutes, or approval letters.
  * Example: Project proposal, Meeting minutes, Approval letter

## Tips
* Please ensure you have the necessary authority to access HR data before submitting this form.
* Double-check the submission history to prevent duplicate requests.
* Be specific about the data you need, as this will ensure you receive the correct information.
* If you have any questions or concerns, contact HR support.
* Please note that this form is an internal HR tool and is not intended for external use.
