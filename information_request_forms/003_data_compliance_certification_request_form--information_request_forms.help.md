# Data Compliance Certification Request Form - Help Guide
## Purpose
The Data Compliance Certification Request Form is used to request certification for data compliance. This form helps users initiate the certification process by providing necessary information about the data in question.

## How To Complete This Form
To complete this form, please follow these steps:

1. Review each field carefully to ensure you provide accurate and complete information.
2. Select "Yes" or "No" for fields that require a binary response.
3. Select a date for fields that require a date.
4. Enter your email and phone number for contact information.
5. Provide a description of the data in question.

## Field-by-Field Explanation

* **Submit Request** (`submit_request`, select_one): This field asks if you have submitted a request for data compliance certification. Select "Yes" if you have submitted a request previously, and "No" if this is a new request.
* **Supporting Documents** (`supporting_documents`, select_multiple): Check the boxes for any supporting documents you have or will provide.
* **Consent** (`consent`, select_one): Select "Yes" if you have obtained consent from the data owner, and "No" if you have not.
* **Review Status** (`review_status`, select_one): This field displays the review status of your certification request. However, as a user, you should not interact with this field as it is not editable.
* **Due Date** (`due_date`, date): This field is used to track the due date for submitting certification requests. However, please note that this date is not required, and you can select a date that is convenient for you.
* **Submitted By** (`submitted_by`, select_one): Select "Yes" if you are submitting the certification request, and "No" if someone else is submitting on your behalf.
* **Submitted On** (`submitted_on`, date): This field is used to track when the certification request was submitted. However, please note that this date is not required, and you can select a date that is convenient for you.
* **Reviewed By** (`reviewed_by`, select_one): Select "Yes" if the request has been reviewed, and "No" if it has not.
* **Reviewed On** (`reviewed_on`, date): This field is used to track when the certification request was reviewed. However, please note that this date is not required, and you can select a date that is convenient for you.
* **Comments** (`comments`, text): Enter any comments or notes related to the certification request.
* **Email** (`email`, email): Enter your email address so that we can contact you about your certification request.
* **Phone** (`phone`, text): Enter your phone number so that we can contact you about your certification request.
* **Description** (`description`, text): Provide a brief description of the data in question, including its purpose and any relevant context.
