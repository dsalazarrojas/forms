# Quick Quote Form - Help Guide
## Purpose
The purpose of this form is to allow customers to quickly and easily request a quote for an order. It captures essential information about the customer and their order.

## How To Complete This Form
To complete this form, please follow these steps:
1. Fill out your first and last name in the "Customer First Name" and "Customer Last Name" fields.
2. Enter your email address and phone number in the "Customer Email" and "Customer Phone" fields, respectively.
3. Provide your company name (if applicable) in the "Company Name" field.
4. Select the type of order you're requesting a quote for in the "Order Type" dropdown menu.
5. If necessary, provide more details about your order in the "Order Details" field.

## Field-by-Field Explanation
* **Customer First Name (customer_first_name, text, required):** Enter the first name of the customer.
* **Customer Last Name (customer_last_name, text, required):** Enter the last name of the customer.
* **Customer Email (customer_email, email, required):** Enter the customer's email address.
* **Customer Phone (customer_phone, text, optional):** Enter the customer's phone number (if you'd like to be contacted).
* **Company Name (company_name, text, optional):** Enter the customer's company name (if applicable).
* **Order Type (order_type, select_one, optional):** Select the type of order you're requesting a quote for (e.g. "Yes" or "No").
* **Order Details (order_details, text, optional):** Provide more details about your order, if necessary.
