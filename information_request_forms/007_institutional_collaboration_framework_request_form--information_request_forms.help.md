# Institutional Collaboration Framework Request Form - Help Guide
## Purpose
This form is designed to collect information from users interested in proposing a collaboration framework with our institution.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the required fields, marked with an asterisk (\*). 
2. For select_multiple fields (e.g., Partner Institution, Partner Contacts), select multiple options using commas to separate them.
3. For time fields (e.g., Timeline), use the date and time format (YYYY-MM-DD HH:MM:SS).
4. Ensure you've reviewed the terms of service and user agreement before submitting the form.
5. Double-check your submission for accuracy before clicking the "Submit" button.
