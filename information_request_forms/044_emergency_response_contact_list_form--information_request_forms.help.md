# emergency_response_contact_list_form - Help Guide
## Purpose

This form collects information about emergency contacts that can be contacted in case of emergency situations.

## How To Complete This Form

To complete this form, follow these steps:

1. Select the relevant options for "Contact List" to indicate whether emergency contacts are required or not.
2. Choose the relevant options for "Emergency Contacts" to indicate whether emergency contacts exist or not.
3. In the "Client Information" field, enter any relevant information about the client, such as their name, phone number, or address.

## Field-by-Field Explanation

* **Contact List**: Select "Yes" if you are required to have a list of contacts in case of emergency situations. Select "No" if emergency contacts are not applicable.
* **Emergency Contacts**: Select "Yes" if emergency contacts exist for this client. Select "No" if no emergency contacts exist.
* **Client Information**: Enter any relevant information about the client that would be helpful in case of an emergency.

## Tips

* Make sure to only select "Yes" for "Contact List" if you are actually required to have a list of contacts.
* If you select "Yes" for "Emergency Contacts", make sure to enter the relevant contact information in the "Client Information" field.
* Be as detailed as possible when entering client information in "Client Information" to ensure that the emergency responders can quickly and effectively contact the client.
