# Retail App Error Notification Contact Form - Help Guide
## Purpose
This form is designed to help you report errors or issues with our retail app. Please use this form to provide detailed information about the problem you are experiencing and any relevant attachments that can aid in debugging.
## How To Complete This Form
To complete this form, follow these steps:

1. Select the type of device you are experiencing the issue on.
2. Choose the version of the app you are currently using.
3. Describe the steps you took to reproduce the issue.
4. If applicable, attach any files that may help us understand the issue.
5. Fill out any additional fields as needed to provide more context about the problem.

## Field-by-Field Explanation
* **What is your device type?** (`device_type`, select_one, required: false): Select the type of device you are experiencing the issue on. This could be an Android, iOS, or Windows device. If your device is not listed, please select "Other" and describe the type of device in the text field below.
* **Which app version are you using?** (`app_version`, select_one, required: false): Choose the version of the app you are currently using. If you are unsure of the version, please select "Unknown" and we will help you determine the version.
* **Steps to reproduce the issue** (`steps_to_reproduce`, text, required: false): Describe the steps you took to reproduce the issue. This will help us understand the issue more clearly and provide more accurate solutions.
* **Attach any files that help to reproduce the issue** (`file_upload`, text, required: false): If you have any files that can help us understand the issue, such as screenshots, log files, or error messages, please attach them here. Please make sure to only attach files that are relevant to the issue.
* **Additional comments** (optional): If you have any additional comments or information about the issue, please provide them here.
