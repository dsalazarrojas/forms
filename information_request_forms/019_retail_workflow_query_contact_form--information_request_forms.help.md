# retail_workflow_query_contact_form - Help Guide
## Purpose
This form is for customers to submit a query related to their retail experience. It can be used to report issues, ask questions, or seek assistance from the retail team.

## How To Complete This Form
To complete this form, follow these steps:
1. Select your query type from the list provided. This will help the retail team understand the nature of your query.
2. If you are a customer, please provide your name so that we can address your query accordingly.
3. Choose how you would like to be contacted, either by phone or email.
4. Provide more details about your query so that the retail team can better understand your concern.
5. If you have any contact information, please provide it so that we can get in touch with you.
6. If you have a preferred sales person, you can select them from the list provided.
7. If you have an email address, please provide it so that we can contact you.
8. If you have a phone number, please provide it so that we can contact you.
9. Finally, please fill in the name of your retail location.

## Field-by-Field Explanation

* **Query Type** (select_one):
	+ Select one of the following options: Sales, Service, Product, or Other.
* **Customer Name** (text):
	+ If you are a customer, please provide your name so that we can address your query accordingly.
* **Contact Method** (select_one):
	+ Choose how you would like to be contacted: Phone or Email.
* **Query Details** (text):
	+ Please provide more details about your query so that the retail team can better understand your concern.
* **Contact Information** (text):
	+ If you have any contact information, please provide it so that we can get in touch with you.
* **Retail Location** (text):
	+ If you have a retail location, please provide it so that the retail team can address your query accordingly.
* **Sales Person** (select_multiple):
	+ Select one or more of the following sales people: John, Jane, Jim.
* **Email** (email):
	+ If you have an email address, please provide it so that we can contact you.
* **Phone** (text):
	+ If you have a phone number, please provide it so that we can contact you.
