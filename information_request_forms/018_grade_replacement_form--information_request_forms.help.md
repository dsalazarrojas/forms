# Grade Replacement Form - Help Guide
## Purpose
This form is used to replace a grade for a course.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the required fields: **form_id** and **course_name**.
2. Enter the desired grade replacement information in the **Grade Replacement Form** field.
3. Review your submission carefully before submitting the form.

## Field-by-Field Explanation
- **Grade Replacement Form**: This is the main field where you can enter the grade replacement information. Please enter the new grade for the course.
- **form_id**: Enter the ID of the form that you are submitting. This is a unique number that identifies the form.
- **course_name**: Enter the name of the course that you want to replace the grade for.

## Tips
- Make sure to enter the correct form ID and course name to avoid duplicate submissions.
- Double-check your grade replacement information before submitting the form.
- If you need to replace multiple grades, submit this form multiple times with the correct form ID and course name for each grade.
