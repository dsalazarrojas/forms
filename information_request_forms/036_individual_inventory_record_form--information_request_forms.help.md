# Individual Inventory Record Form - Help Guide
## Purpose
The Individual Inventory Record Form is used to collect and maintain accurate information about individual inventory items. This form is intended for authorized personnel to record items received, track their status, and note any relevant details.

## How To Complete This Form
To complete this form, simply follow the instructions below:

1. Enter the item name in the "Item Name" field to identify the item.
2. Add a brief description of the item in the "Item Description" field.
3. Enter the item's price in the "Item Price" field.
4. Record the quantity of the item in the "Item Quantity" field.
5. Select one or multiple tags that apply to the item from the "Item Tags" field.
6. Choose the status of the item from the "Item Status" field.
7. Enter the date the item was received in the "Item Date Received" field.
8. Update the date the item was last updated in the "Item Date Last Updated" field.
9. Record the date the item was last checked in the "Item Date Last Checked" field.
10. Enter the date and time the item was last checked by in the "Item Date Last Checked By" field.
11. Add any additional notes about the item in the "Item Notes" field.

## Field-by-Field Explanation
* **Form Title** (`form_title`, text, optional): Enter a brief title for the form to help identify the purpose of the form.
* **Item Name** (`item_name`, text, optional): Enter a short and descriptive name for the item to help identify it.
* **Item Description** (`item_description`, text, optional): Provide a brief description of the item.
* **Item Price** (`item_price`, number, optional): Enter the price of the item.
* **Item Quantity** (`item_quantity`, number, optional): Record the number of items available.
* **Item Tags** (`item_tags`, select multiple, optional): Select one or multiple tags that apply to the item.
* **Item Status** (`item_status`, select one, optional): Choose the status of the item (active, inactive, or pending).
* **Item Date Received** (`item_date_received`, date, optional): Enter the date the item was received.
* **Item Date Last Updated** (`item_date_last_updated`, date, optional): Update the date the item was last updated.
* **Item Date Last Checked** (`item_date_last_checked`, time, optional): Record the date the item was last checked.
* **Item Date Last Checked By** (`item_date_last_checked_by`, time, optional): Enter the date and time the item was last checked by.
* **Item Notes** (`item_notes`, note, optional): Add any additional notes or comments about the item.

## Tips
* Make sure to enter accurate and up-to-date information to ensure the integrity of the inventory records.
* If you are unsure about any of the fields, refer to your supervisor or relevant documentation.
* If you need to make changes to an existing item, update the relevant fields and save the form to reflect the changes.
