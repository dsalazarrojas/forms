# Book Estimate Request Form - Help Guide
## Purpose
This form is used to request an estimate for a book project. It will guide the project team in understanding your project's needs and provide a detailed estimate for the project's scope, timeline, and budget.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill out all required fields (marked as *Required*) to the best of your ability.
2. Make sure to provide accurate and detailed information for each field.
3. Review your answers carefully before submitting the form.
4. Attach any relevant reference materials if applicable.
5. Submit the form once you have filled out all required fields.

## Field-by-Field Explanation

* **Full Name** (`client_full_name`, text, *Required*): Please enter your complete name as you would like it to be displayed on the project.
* **Email Address** (`client_email`, email, *Required*): Enter your email address where we will send the estimate and any further communication related to the project.
* **Phone Number** (`client_phone`, text, *Required*): Enter your contact phone number where we can reach you.
* **Company Name** (`company_name`, text, *Optional*): If applicable, enter the name of your company.
* **Describe the Work Needed** (`project_description`, text, *Required*): Please provide detailed information about the services or work you need for the project.
* **Project Scope** (`project_scope`, select_one, *Required*): Choose the size and complexity of your project:
	+ Small: A simple project with limited scope and no complex technical requirements.
	+ Medium: A medium-sized project with standard technical requirements.
	+ Large: A large project with multiple technical requirements.
	+ Complex: A complex project with many technical requirements and potential dependencies.
* **Desired Timeline** (`desired_timeline`, select_one, *Required*): Choose the desired timeline for the project:
	+ Urgent (1-2 weeks): A short timeline, usually for a critical project or with a tight deadline.
	+ Standard (1-2 months): A standard timeline, suitable for most projects.
	+ Flexible: A flexible timeline, where we can discuss and adjust as needed.
	+ No specific deadline: You do not have a specific deadline for this project.
* **Budget Range** (`budget_range`, select_one, *Optional*): Enter your approximate budget for the project:
	+ Under $1,000: A low budget project.
	+ $1,000 - $5,000: A standard budget project.
	+ $5,000 - $10,000: A medium-high budget project.
	+ $10,000+: A high budget project.
	+ Not determined: You are not sure about the budget yet.
* **Attach Reference Materials** (`attachment_files`, text, *Optional*): Attach any relevant files or documents related to the project that will help us better understand your needs.
* **Preferred Contact Method** (`preferred_contact_method`, select_one, *Required*): Choose how you would prefer to be contacted:
	+ Email: We will contact you via email.
	+ Phone: We will contact you via phone.
	+ SMS: We will contact you via SMS.
