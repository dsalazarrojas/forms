# Report Request Form - Help Guide
## Purpose
The Report Request Form is a tool used to gather information from users to create reports. It is designed for non-technical users to submit requests for reports.

## How To Complete This Form
To complete this form, simply follow these steps:

* Click on the "Request Report" button to open the form.
* Fill out the form with the required information, such as report details, report type, due date, and due time.
* Optionally, you can provide additional information about the report in the text fields.
* Click "Submit" to send the request.
