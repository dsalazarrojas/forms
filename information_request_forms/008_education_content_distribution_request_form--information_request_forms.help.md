# Education Content Distribution Request Form - Help Guide
## Purpose
The Education Content Distribution Request Form is designed to facilitate the distribution of educational content to schools or other educational institutions. This form gathers information about the content to be distributed, including its type, the needs of the educational institution, and the contact information of the person or entity requesting the content.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the "School Name" field with the name of the school or educational institution that is requesting the content.
2. Select the type of content being requested (Video, Audio, or Document).
3. Choose the type of training needs assessment required (Needs Assessment, Needs Analysis, or Needs Analysis and Assessment).
4. Select the specific content requests (Request 1, Request 2, or Request 3).
5. Provide a clear and concise description of the content distribution request in the "Content Distribution Request" field.
6. Choose how you would like to be contacted (Email, Phone, or both).
7. Enter the submission date in the format of month/day/year.
8. If you have completed the form on behalf of someone else, select "Form Completed By" as appropriate.
9. If applicable, enter the submission time in 24-hour format (HH:MM).
10. If you have any additional comments or notes, please enter them in the "Comments" field.

## Field-by-Field Explanation
* **School Name (Text)**: Enter the name of the school or educational institution requesting the content.
* **Content Type (Select One)**: Choose the type of content being requested (Video, Audio, or Document).
* **Training Needs Assessment (Select Multiple)**: Select one or more of the following options: Needs Assessment, Needs Analysis, or Needs Analysis and Assessment.
* **Content Requests (Select Multiple)**: Choose one or more of the following options: Request 1, Request 2, or Request 3.
* **Content Distribution Request (Text)**: Provide a clear and concise description of the content distribution request.
* **Contact Information (Select Multiple)**: Choose how you would like to be contacted (Email, Phone, or both).
* **Submission Date (Date)**: Enter the date in the format of month/day/year.
* **Form Completed By (Select One)**: If you have completed the form on behalf of someone else, select "Form Completed By".
* **Submission Time (Time)**: If you have the submission time recorded, enter it in 24-hour format (HH:MM).
* **Form Submitted At (Date)**: If the submission date is recorded, enter it in the format of month/day/year.
* **Comments (Note)**: Enter any additional comments or notes about the form submission. 

## Tips
* Please make sure to enter accurate and clear information to ensure efficient processing of your request.
* If you are unsure about any field, please consult with the relevant authority.
* If you have any additional requirements or special requests, please mention them in the "Comments" field.
