# Personal Data Accuracy Inquiry Form - Help Guide
## Purpose
The Personal Data Accuracy Inquiry Form is used to check the accuracy of personal data stored in the system. This form allows users to submit a detailed description of the request for data correction, enabling the data accuracy team to verify and update the data accordingly.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill in your **First Name**, **Last Name**, **Company Name (if applicable)**, and **Email**.
2. Provide your **Phone Number** for communication purposes.
3. Select the **Personal Data Inquiry Type** from the drop-down menu (e.g., Type of personal data, Category of personal data, Purpose of personal data, or Reason for request).
4. Enter your **Date of Birth**, if applicable.
5. Enter your **Address** (if applicable).
6. Provide a clear and detailed description of the request in the **Request Details** field.

## Field-by-Field Explanation
### First Name
* **First Name** (`first_name`, text, optional): Please enter your first name as it is displayed in our system.

### Last Name
* **Last Name** (`last_name`, text, optional): Please enter your last name as it is displayed in our system.

### Company Name
* **Company Name** (`company_name`, text, optional): If you are inquiring on behalf of a company, please enter the name of the company.

### Email
* **Email** (`email`, email, optional): Please enter your email address for communication purposes.

### Phone Number
* **Phone Number** (`phone_number`, text, optional): Please enter your phone number for communication purposes.

### Personal Data Inquiry Type
* **Personal Data Inquiry Type** (`personal_data_inquiry_type`, select_one, optional): Choose the type of data you are inquiring about:
	+ Type of personal data
	+ Category of personal data
	+ Purpose of personal data
	+ Reason for request

### Date of Birth
* **Date of Birth** (`date_of_birth`, date, optional): If applicable, please enter your date of birth in the format MM/DD/YY (e.g., 02/01/2000).

### Address
* **Address** (`address`, text, optional): If applicable, please enter your address for reference.

### Request Details
* **Request Details** (`request_details`, text, optional): Please provide a clear and detailed description of the request for data correction.
