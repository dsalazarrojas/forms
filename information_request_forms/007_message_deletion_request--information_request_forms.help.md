# Message Deletion Request - Help Guide
## Purpose
The Message Deletion Request form is used to request the deletion of a message. This form is for end-users to provide the necessary information for this request.

## How To Complete This Form
To complete this form, please follow these steps:

* Click on the "Message Deletion Request" page.
* The form will be displayed with several fields. Please read the field explanations below to ensure you complete the form correctly.
* Fill out the form with the required information and click the "Submit" button.

## Field-by-Field Explanation
* **Message Deletion Request** (`message_deletion_request`, note, not required): This is a note field to briefly describe the purpose of the form. Please do not fill out this field.
* **message_id** (`message_id`, text, not required): Please enter the ID of the message you wish to delete.
* **Message Type** (`message_type`, select one, not required): Choose the type of message you are requesting to delete, i.e., spam or non-spam.
* **Reason for Removal** (`reason_for_removal`, note, not required): This field is for providing additional information on why you are requesting the deletion of the message.
* **Submit** (`submit`, text, not required): This field should not be filled out by the end-user, it is a placeholder for the submit button.
* **Message Subject** (`message_subject`, text, not required): Please enter the subject of the message you wish to delete.
* **Message Body** (`message_body`, text, not required): Please enter the body of the message you wish to delete.

## Tips
* Please ensure you have not already submitted a deletion request for the same message.
* If you are unsure about any field, please contact your support team for assistance.
