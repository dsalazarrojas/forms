# Smart Meter Reading Request Form - Help Guide
## Purpose
The Smart Meter Reading Request Form is used for customers or utilities to request a meter reading from the utility company. This form is used for requesting a reading at a customer's specific meter, typically for planning and scheduling purposes.

## How To Complete This Form
To complete this form, simply fill out the required and optional fields as needed.

## Field-by-Field Explanation
### 1. Customer Details
* **Customer Name** (`Customer Name`, text, optional): Enter the customer's name associated with the meter being read.
### 2. Meter Id
* **Meter Id** (`Meter Id`, text, optional): Enter the unique identifier for the meter at which the reading is requested.
### 3. Preferred Date
* **Preferred Date** (`Preferred Date`, date, optional): Enter the date on which the meter reading is preferred. If left blank, the reading will be scheduled as soon as possible.
### 4. Instructions
* **Instructions** (`Instructions`, text, optional): Enter any specific instructions for the meter reading, such as "Please read the meter at the customer's residence".
### 5. Start Date
* **Start Date** (`Start Date`, date, optional): Enter the date on which the meter reading is to start. If left blank, the reading will be scheduled as soon as possible.
### 6. End Date
* **End Date** (`End Date`, date, optional): Enter the date on which the meter reading is to end. If left blank, the reading will be scheduled as soon as possible.
### 7. Schedule Date
* **Schedule Date** (`Schedule Date`, date, optional): Enter the date on which the meter reading is to be scheduled. If left blank, the reading will be scheduled as soon as possible.
### 8. Customer Phone
* **Customer Phone** (`Customer Phone`, text, optional): Enter the customer's phone number.
### 9. Customer Email
* **Customer Email** (`Customer Email`, email, optional): Enter the customer's email address.
### 10. Notes
* **Notes** (`Notes`, text, optional): Enter any additional notes about the meter reading request.
### 11. Meter Type
* **Meter Type** (`Meter Type`, select_one, optional): Select the type of meter (Electric, Gas, or Water).
### 12. Meter Reading Frequency
* **Meter Reading Frequency** (`Meter Reading Frequency`, select_one, optional): Select how often the meter reading is to be taken (Once A Week, Twice A Week, Daily, Monthly, Quarterly, Semi-Annually, or Annually).
### 13. Meter Status
* **Meter Status** (`Meter Status`, select_one, optional): Select the status of the meter (Active, Inactive, or Offline).
### 14. Meter Reading Type
* **Meter Reading Type** (`Meter Reading Type`, select_one, optional): Select the type of meter reading (Manual, Automatic, or Automatic With Validation).
### 15. Meter Reading Method
* **Meter Reading Method** (`Meter Reading Method`, select_one, optional): Select the method of meter reading (Manual or Automatic).
### 16. Customer Address
* **Customer Address** (`Customer Address`, text, optional): Enter the customer's address.
### 17. Customer Postal Code
* **Customer Postal Code** (`Customer Postal Code`, text, optional): Enter the customer's postal code.
### 18. Customer Province
* **Customer Province** (`Customer Province`, text, optional): Enter the customer's province.
### 19. Meter Reading Request ID
* **Meter Reading Request ID** (`Meter Reading Request ID`, text, optional): Enter the ID associated with this meter reading request.
### 20. Meter Reading Status
* **Meter Reading Status** (`Meter Reading Status`, select_one, optional): Select the status of the meter reading request (Pending, Accepted, or Rejected).
### 21. Meter Reading Request Date
* **Meter Reading Request Date** (`Meter Reading Request Date`, date, optional): Enter the date on which the meter reading request was made.
### 22. Meter Reading Request Instructions
* **Meter Reading Request Instructions** (`Meter Reading Request Instructions`, text, optional): Enter any specific instructions for the meter reading request.
### 23. Meter Reading Requester
* **Meter Reading Requester** (`Meter Reading Requester`, select_one, optional): Select who is requesting the meter reading (Customer, Utility, or Other).
### 24. Meter Reading Requester Notes
* **Meter Reading Requester Notes** (`Meter Reading Requester Notes`, text, optional): Enter any additional notes about the meter reading request.
