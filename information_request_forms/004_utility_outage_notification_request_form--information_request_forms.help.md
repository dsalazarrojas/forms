# Utility Outage Notification Request Form - Help Guide

## Purpose
The purpose of this form is to provide a structured and efficient way to report utility outages. Please fill out the form accurately to help our teams respond promptly and effectively.

## How To Complete This Form
- Ensure you have not already reported the outage and are not reporting it for someone else.
- Fill in the form with the required information.
- Review and confirm the provided details before submitting.

## Field-by-Field Explanation
- **User Details** (<text>): Please provide your name and contact information, if you want to be notified about the status of the issue.
  - Enter your name and a contact method for follow-up communication (e.g., email or phone number).
- **Location** (<text>): Please specify the exact location of the outage (e.g., building, street, or nearest landmark).
  - Type in the address, city, or other identifying features of the location where the outage is happening.
- **Outage Type** (<select multiple>): Select all the types that apply to describe the outage:
  - Option 1: Power outage
  - Option 2: Water outage
  - Option 3: Gas outage
- **Description** (<text>): Briefly describe the issue, including any relevant details (e.g., duration, frequency, or severity).
  - Give a concise explanation of the outage, including any additional context that may be helpful for the response team.
