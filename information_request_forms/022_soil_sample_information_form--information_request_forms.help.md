# Soil Sample Information Form - Help Guide
## Purpose
The Soil Sample Information Form is a tool used to gather and record information about soil samples. This form helps to ensure that all necessary details are captured and accurately recorded, reducing errors and facilitating efficient processing and analysis of the samples.

## How To Complete This Form
To complete this form, please follow these steps:

*   Enter your information carefully and accurately in each field. If a field is not required, you can leave it blank.
*   For fields with dropdown options, select the correct option that best describes the information you want to record.
*   For fields like "sample_description", "collector_name", "project_name", "client_name", and "collector_notes", enter a brief description or comment. There is no character limit, so enter as much information as you need.
*   For fields like "sample_date_received" and "sample_date_requested", enter the date in the format "YYYY-MM-DD".

## Field-by-Field Explanation

*   **sample_id** (`sample_id`, number, required: false): This field is not required, but it's an optional identifier for the sample. You can enter a unique ID if you have one.
*   **soil_type** (`soil_type`, select_one, required: false): Select the type of soil from the available options: Topsoil, Subsoil, Sandy, Clay, or Silty.
*   **sample_date_received** (`sample_date_received`, date, required: false): Enter the date the sample was received at the laboratory.
*   **sample_date_requested** (`sample_date_requested`, date, required: false): Enter the date the sample was requested for analysis.
*   **lab_id** (`lab_id`, number, required: false): This is the unique ID of the laboratory where the sample will be processed. If you don't have a lab ID, you can leave this field blank.
*   **sample_description** (`sample_description`, text, required: false): Enter a brief description of the sample, such as its origin, location, and any other relevant details.
*   **collector_name** (`collector_name`, text, required: false): Enter the name of the person who collected the sample.
*   **project_id** (`project_id`, number, required: false): This is the unique ID of the project the sample is associated with. If you don't have a project ID, you can leave this field blank.
*   **project_name** (`project_name`, text, required: false): Enter the name of the project the sample is associated with.
*   **client_name** (`client_name`, text, required: false): Enter the name of the client or organization the sample is associated with.
*   **client_email** (`client_email`, email, required: false): Enter the email address of the client or organization the sample is associated with.
*   **lab_notes** (`lab_notes`, text, required: false): Enter any additional notes from the laboratory about the sample.
*   **collector_notes** (`collector_notes`, text, required: false): Enter any additional notes from the collector about the sample.
*   **sample_weight** (`sample_weight`, number, required: false): If the sample has a weight, enter its weight in grams or other suitable units.

## Tips

*   Be careful when entering dates in the "sample_date_received" and "sample_date_requested" fields. Use the "YYYY-MM-DD" format to avoid errors.
*   If you're unsure about any field, you can leave it blank or contact the relevant personnel for guidance.
*   Remember to enter accurate and relevant information to ensure efficient processing and analysis of the sample.
