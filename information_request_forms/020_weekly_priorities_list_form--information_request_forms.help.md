# Weekly Priorities List Form - Help Guide
## Purpose
The Weekly Priorities List Form is designed to help users prioritize tasks and allocate them among team members. The form allows users to create a list of tasks, each with its own priority level, due date, and assigned individual.

## How To Complete This Form
1. **Enter a brief title** (form_title): This is the name of the task list.
2. **Select the task list ID** (task_list_id): Choose 'Yes' or 'No' to indicate whether the task list is relevant.
3. **Assign the task list** (assigned_to): Select the individual responsible for the task list.
4. **Set the priority level** (priority): Choose the priority level of the task list as High, Medium, or Low.
5. Repeat steps 2-4 for additional task lists, using the corresponding field names (e.g., task_list_id_2, assigned_to_2, priority_2).

## Field-by-Field Explanation

* **Weekly Priorities List Form** (form_title, text, optional): A brief description of the task list.
* **Task List ID** (task_list_id, select_multiple, optional): Indicate whether this task list is relevant ('Yes' or 'No').
* **Assigned To** (assigned_to, select_one, optional): Select the individual responsible for this task list.
* **Priority** (priority, select_one, optional): Set the priority level of the task list as High, Medium, or Low.
* **Due Date** (due_date, date, optional): Set the due date for the task list.
* **Due Time** (due_time, time, optional): Set the due time for the task list.
* **Description** (description, text, optional): Provide a brief description of the task list.
* **Additional Task Lists** (task_list_id_2, select_multiple, optional): Repeat the task list ID field for additional task lists.
* **Assigned To** (assigned_to_2, select_one, optional): Repeat the assigned to field for additional task lists.
* **Priority** (priority_2, select_one, optional): Repeat the priority field for additional task lists.
* **Due Date** (due_date_2, date, optional): Repeat the due date field for additional task lists.
* **Due Time** (due_time_2, time, optional): Repeat the due time field for additional task lists.
* **Description** (description_2, text, optional): Repeat the description field for additional task lists.

## Tips
* Make sure to complete the form for each task list accurately and consistently.
* If you're unsure about a field, try to match it with the corresponding field name in the form header.
* If you have any questions or issues, contact your team lead or support team.
