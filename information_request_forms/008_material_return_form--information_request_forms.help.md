# Material Return Form - Help Guide
## Purpose
This form is used to collect information from customers or users who are requesting to return materials or items purchased or leased from the organization.

## How To Complete This Form
To complete this form, please provide the following information:

*   First and last names of the person making the request (page 1).
*   Full address where the customer or user can be contacted (page 1).
*   Email address of the customer or user (page 1).
*   Phone number of the customer or user (optional, page 1).
*   Date of the return request (page 1).
*   Reason for the return request (page 1).
*   Any additional comments about the return request (page 2).

## Field-by-Field Explanation
*   **First Name** (Required, Text): Your first name.
*   **Last Name** (Required, Text): Your last name.
*   **Address** (Required, Text): Enter your full address where you can be contacted.
*   **Email** (Required, Email): Enter your email address where you can be contacted.
*   **Phone** (Optional, Text): Enter your phone number where you can be contacted.
*   **Date** (Required, Date): Enter the date of the return request.
*   **Reason** (Required, Text): Provide a brief reason for your return request.
*   **Comments** (Optional, Text): Add any additional comments about your return request.
