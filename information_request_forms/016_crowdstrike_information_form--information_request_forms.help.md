# CrowdStrike Information Form - Help Guide
## Purpose
The CrowdStrike Information Form is designed to collect general information, product inquiries, and service inquiries from users.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the category that best describes your inquiry from the options provided.
2. Provide the required information in the corresponding field.
3. If you have any additional comments or details, you can include them in the "Additional Comments" field.

## Field-by-Field Explanation
### General Inquiries
* **General Inquiries** (`General Inquiries`, `text`, required/optional): Enter a brief description of your inquiry. This field is used to gather general information from users.

### Product Inquiries
* **Product Inquiries** (`Product Inquiries`, `select_one`, required/optional): Select one of the following options:
	+ CrowdStrike Falcon
	+ CrowdStrike Security

### Service Inquiries
* **Service Inquiries** (`Service Inquiries`, `select_multiple`, required/optional): Select all the services that apply:
	+ CrowdStrike Service
	+ CrowdStrike Security Service

## Tips
* Please make sure to select only the options that apply to your inquiry.
* If you have any additional comments or details, please include them in the "Additional Comments" field.
* For general inquiries, please keep your description concise and to the point.
* If you are unsure about any of the options, feel free to ask our support team for assistance.
