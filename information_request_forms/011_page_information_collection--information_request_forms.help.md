# Page Information Collection - Help Guide

## Purpose

The purpose of this form is to collect information from users about a web page, so that page maintainers can understand what content needs to be added, updated, or removed.

## How To Complete This Form

1. To complete this form, please enter the following information:
	* **Page Title** (`page_title`): The title of the page that you are providing information about.
	* **Page URL** (`page_url`): The URL of the page.
	* **Page Description** (`page_description`): A brief description of the page content.
	* **Category** (`page_category`): Select the category that best describes the type of content on the page.
	* **Tags** (`page_tags`): Select all relevant tags for the page content.
	* **Date** (`page_date`): The date the page was last updated.
	* **Time** (`page_time`): The time the page was last updated (optional).
	* **Status** (`page_status`): Select the status of the page (e.g. "a" for available, "b" for under construction).
	* **Priority** (`page_priority`): Enter the priority level of the page (e.g. urgent, low, medium).

## Field-by-Field Explanation

* **Page Title** (Text, Required): The title of the page that you are providing information about. Please enter the exact title as it appears on the page.
* **Page URL** (Text, Required): The URL of the page. Please enter the exact URL of the page.
* **Page Description** (Text, Optional): A brief description of the page content. This will help page maintainers understand what content is on the page.
* **Category** (Select One, Required): Select the category that best describes the type of content on the page. Please select one from the provided options.
* **Tags** (Select Multiple, Optional): Select all relevant tags for the page content. This will help in searching and filtering the page list.
* **Date** (Date, Required): The date the page was last updated.
* **Time** (Time, Optional): The time the page was last updated. If this field is left blank, it will be set to the current time.
* **Status** (Select One, Required): Select the status of the page. Please select from the options provided.
* **Priority** (Text, Required): Enter the priority level of the page. Please enter the exact priority as per your team's conventions.
* **Page Image URL** (Text, Optional): The URL of the image associated with the page.
* **Page Image URL2** (Text, Optional): The URL of the second image associated with the page (if any).
