# Student Grant Application Form - Help Guide

## Purpose
The purpose of this form is to collect and document student information for grant applications. The form will help the Financial Aid Officer gather and verify the student's details accurately.

## How To Complete This Form
To fill out this form, simply follow these steps:

1. Fill out each section accurately and completely.
2. Ensure all fields are filled out, even if they are optional.

## Field-by-Field Explanation

* **StudentInformation**: Enter the student's name, student ID (if applicable), and any other relevant student-specific information.
	+ Type: text
	+ Required: No
* **StudentContactInformation**: Enter the student's contact information, including their email address, phone number, and physical address.
	+ Type: text
	+ Required: No
* **ContactPerson**: Enter the name and contact information of the person handling the student's grant application.
	+ Type: text
	+ Required: No
* **ParentContactInformation**: Enter the parent's contact information, including their email address, phone number, and physical address.
	+ Type: text
	+ Required: No
* **StudentAidRequest**: Enter a detailed description of the student's aid request.
	+ Type: text
	+ Required: No
* **FinancialAidOfficer**: Enter the Financial Aid Officer's name, title, and signature.
	+ Type: text
	+ Required: No
* **StudentStatus**: Enter the current status of the student's aid application.
	+ Type: text
	+ Required: No
* **StudentAidAmount**: Enter the amount of aid requested by the student.
	+ Type: text
	+ Required: No
* **StudentAidStartDate**: Enter the date when the student's aid will start.
	+ Type: text
	+ Required: No
* **StudentAidEndDate**: Enter the date when the student's aid will end.
	+ Type: text
	+ Required: No
* **FinancialAidOfficerSignature**: Enter the Financial Aid Officer's signature.
	+ Type: text
	+ Required: No
* **FinancialAidOfficerDate**: Enter the date of the Financial Aid Officer's signature.
	+ Type: text
	+ Required: No
* **FinancialAidOfficerTitle**: Enter the Financial Aid Officer's title.
	+ Type: text
	+ Required: No
* **StudentSignature**: Enter the student's signature.
	+ Type: text
	+ Required: No
* **StudentDate**: Enter the date of the student's signature.
	+ Type: text
	+ Required: No
* **StudentTitle**: Enter the student's title.
	+ Type: text
	+ Required: No
* **StudentGradeLevel**: Enter the student's grade level.
	+ Type: text
	+ Required: No
* **StudentSchoolName**: Enter the name of the student's school.
	+ Type: text
	+ Required: No
* **StudentSchoolYear**: Enter the student's school year.
	+ Type: text
	+ Required: No
* **StudentProgramEnrolled**: Enter the student's program of enrollment.
	+ Type: text
	+ Required: No
* **StudentProgramStartDate**: Enter the start date of the student's program.
	+ Type: text
	+ Required: No
* **StudentProgramEndDate**: Enter the end date of the student's program.
	+ Type: text
	+ Required: No
* **StudentProgramLevel**: Enter the level of the student's program.
	+ Type: text
	+ Required: No
* **AdditionalComments**: Enter any additional comments or information about the student's aid application.
	+ Type: note
	+ Required: No

**Tips**

* Please fill out this form accurately and completely.
* Ensure that all fields are filled out, even if they are optional.
* Review the form carefully before submitting it to the Financial Aid Officer.
