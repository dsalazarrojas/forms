# Cemetery Mapping Form - Help Guide

## Purpose
The Cemetery Mapping Form is used to gather information about a specific individual who has passed away, in order to facilitate the creation of a burial map or plot location map for the cemetery where they are buried.

## How To Complete This Form

1.  Ensure you have the necessary information and permissions to complete this form.
2.  Read each field carefully and provide accurate and complete answers.
3.  Submit the form once you have completed all required fields.

## Field-by-Field Explanation

*   **Request Date (1)** (`request_date`, date, required): This is the date on which you are submitting this request. Please enter the date in the format `YYYY-MM-DD`.
*   **Requester Name (2)** (`requester_name`, text, required): Provide your full name as the person requesting this information.
*   **Relationship to Deceased (3)** (`relationship_to_deceased`, select_one, required): Select one of the options provided to describe your relationship to the deceased individual (e.g., Spouse, Child, Parent, etc.).
*   **Requester Email (4)** (`requester_email`, email, required): Enter your email address for correspondence and to receive any requested information.
*   **Requester Phone (5)** (`requester_phone`, text, required): Enter your contact phone number.
*   **Mailing Address (6)** (`requester_address`, text, required): Enter your full mailing address for document delivery.
*   **Deceased Full Name (7)** (`deceased_full_name`, text, required): Provide the complete legal name of the deceased individual.
*   **Deceased Date of Birth (8)** (`deceased_date_of_birth`, date, optional): If you know the date of birth, please enter it. If not, please leave this field blank.
*   **Deceased Date of Death (9)** (`deceased_date_of_death`, date, optional): If you know the date of death, please enter it. If not, please leave this field blank.
*   **Is Burial Location Known (10)** (`burial_location_known`, select_one, required): Answer whether you know the approximate burial area, and select one of the options provided.
*   **Cemetery Section (11)** (`cemetery_section`, text, optional): If you know the section name or number, please enter it.
*   **Plot Number (12)** (`plot_number`, text, optional): If you know the plot or grave number, please enter it.
*   **Information Requested (13)** (`information_requested`, select_multiple, required): Select all the options that apply for the information you are requesting (e.g., Burial plot location map, Interment records, etc.).
*   **Purpose of Request (14)** (`purpose_of_request`, select_one, required): Select one of the options provided to describe why you are requesting this information (e.g., Personal family records, Genealogy research, etc.).
*   **Preferred Delivery Method (15)** (`delivery_method`, select_one, required): Choose how you would like to receive the requested information (e.g., Email (digital copies), Postal mail (printed copies), etc.).
*   **Additional Details (16)** (`additional_details`, text, optional): If there is any other information that may help locate the burial site, please provide it.

Note: This guide is intended to be a general reference for users completing the form. If you are unsure about any specific field or requirement, please contact the relevant authority for clarification or support.
