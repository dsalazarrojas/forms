# Video Storyboard Template - Help Guide
## Purpose
This form is used to collect information about a video storyboard template. It includes details about the project, such as project name, description, status, start and end dates, client and manager, budget, and notes. The form is designed to be completed by project managers or clients to provide a clear and concise summary of the project's storyboard template.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the required fields: **Project Name**, **Project Description**, and **Project Status**.
2. Select the relevant tags for the project from the list of options.
3. Enter the start and end dates of the project.
4. Enter the client's name and any relevant notes about the project.
5. Upload the storyboard image and video URLs.

## Field-by-Field Explanation

* **Project Name** (Text, Optional): Enter the name of the project.
* **Project Description** (Text, Optional): Enter a brief description of the project.
* **Project Tags** (Select Multiple, Optional): Choose the tags that best describe the project.
* **Project Status** (Select One, Optional): Select the current status of the project.
* **Project Start Date** (Date, Optional): Enter the start date of the project.
* **Project End Date** (Date, Optional): Enter the end date of the project.
* **Project Client** (Text, Optional): Enter the name of the project's client.
* **Project Manager** (Text, Optional): Enter the name of the project manager.
* **Storyboard Image URL** (Text, Optional): Upload the URL of the storyboard image.
* **Storyboard Video URL** (Text, Optional): Upload the URL of the storyboard video.
* **Project Budget** (Number, Optional): Enter the budget for the project.
* **Project Notes** (Note, Optional): Enter any additional notes about the project.

## Tips
* Make sure to provide accurate information about the project to ensure that the storyboard template is correctly configured.
* If you are unsure about any of the fields, please consult with the project manager or client before completing this form.
* Please note that the form is only for projects with a storyboard template associated with them.
