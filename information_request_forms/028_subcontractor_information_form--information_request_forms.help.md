# Subcontractor Information Form - Help Guide
## Purpose
The Subcontractor Information Form is used to collect information about new subcontractors who have been assigned a tool. This form is essential for adding a new subcontractor to our system and ensuring we have accurate records.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill in the First Name and Last Name fields with the subcontractor's personal details.
2. Enter the subcontractor's email address in the Email field.
3. Select the subcontractor's type from the Subcontractor Type dropdown menu (Independent, Employee, or Company).
4. Choose the subcontractor's current work status from the Work Status dropdown menu (Active or Retired).
5. Enter the subcontractor's address in the Address field. This can be a physical or virtual address.
6. Enter the subcontractor's phone number in the Phone field.
7. Write a brief description of the subcontractor's role or responsibilities in the Description field.
8. Select the tool assigned to the subcontractor from the Assigned Tool field.
9. Select the category or department the subcontractor belongs to from the Category field.
10. Add any additional notes or comments about the subcontractor in the Notes field.
11. Select the subcontractor's status from the Subcontractor Status dropdown menu (Pending or Verified).
12. Choose the subcontractor's work type from the Work Type dropdown menu (Freelance or Full-time).
13. Select the subcontractor's category from the Subcontractor Category dropdown menu (Freelance or Employee).

## Field-by-Field Explanation
* **First Name** (`first_name`, text, optional): Enter the subcontractor's first name.
* **Last Name** (`last_name`, text, optional): Enter the subcontractor's last name.
* **Email** (`email`, email, optional): Enter the subcontractor's email address.
* **Subcontractor Type** (`subcontractor_type`, select_one, optional): Select whether the subcontractor is Independent, Employee, or Company.
* **Work Status** (`work_status`, select_multiple, optional): Choose the subcontractor's current work status (Active or Retired).
* **Address** (`address`, note, optional): Enter the subcontractor's physical or virtual address.
* **Phone** (`phone`, text, optional): Enter the subcontractor's phone number.
* **Description** (`description`, text, optional): Write a brief description of the subcontractor's role or responsibilities.
* **Assigned Tool** (`assigned_tool`, text, required): Select the tool assigned to the subcontractor.
* **Category** (`category`, text, optional): Select the category or department the subcontractor belongs to.
* **Notes** (`notes`, note, optional): Add any additional notes or comments about the subcontractor.
* **Subcontractor Status** (`subcontractor_status`, select_one, optional): Select the subcontractor's status (Pending or Verified).
* **Work Type** (`work_type`, select_multiple, optional): Choose the subcontractor's work type (Freelance or Full-time).
* **Subcontractor Category** (`subcontractor_category`, select_multiple, optional): Select the subcontractor's category (Freelance or Employee).
