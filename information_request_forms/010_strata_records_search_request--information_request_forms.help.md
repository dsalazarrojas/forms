# Strata Records Search Request - Help Guide
## Purpose
The Strata Records Search Request form is designed to collect information from users for a strata search request. The form helps strata management or administrative staff gather necessary details to facilitate the search process.

## How To Complete This Form
To complete this form, please follow these steps:

1. Enter a brief description of your search request in the "Strata Search Request Form" field.
2. Provide more details about your search request in the "Strata Search Request Details" field.
3. Specify the desired date range for the search in the "Strata Search Request Date" field. This field accepts date format (mm/dd/yyyy).
4. Select the time period for the search in the "Strata Search Request Time" field.
5. Indicate if you would like to request documents related to the search in the "Strata Search Request Documents" field.
6. Provide your email address in the "Strata Search Request Email" field.
7. Enter your phone number in the "Strata Search Request Phone" field.

## Field-by-Field Explanation
* **Strata Search Request Form** (`strata_search_request_form`, text, optional): Enter a brief description of your search request.
* **Strata Search Request Details** (`strata_search_request_details`, text, optional): Provide more details about your search request.
* **Strata Search Request Date** (`strata_search_request_date_range`, date, optional): Specify the desired date range for the search. Use date format (mm/dd/yyyy).
* **Strata Search Request Time** (`strata_search_request_time_period`, time, optional): Select the time period for the search.
* **Strata Documents Requested** (`strata_documents_requested`, select_one, optional): Indicate if you would like to request documents related to the search. Options: Yes/No.
* **Strata Search Request Comments** (`strata_search_request_comments`, text, optional): Provide any additional comments about your search request.
* **Strata Search Request Documents** (`strata_search_request_documents`, select_multiple, optional): Select the types of documents you would like to request. Options: Yes/No.
* **Strata Search Request Email** (`strata_search_request_email`, email, optional): Enter your email address to be contacted about the search results.
* **Strata Search Request Phone** (`strata_search_request_phone`, text, optional): Enter your phone number to be contacted about the search results.

## Tips
* Please ensure that the information provided is accurate and complete.
* If you have any additional comments or requests, please use the "Strata Search Request Comments" field.
* If you are requesting documents related to the search, please select the relevant options in the "Strata Search Request Documents" field.
* The form is optional, but providing all required information will help the search process.
