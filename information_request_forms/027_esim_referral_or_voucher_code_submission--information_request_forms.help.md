# esim_referral_or_voucher_code_submission - Help Guide
## Purpose
This form is used to collect and store information from customers who are using eSIM referrals or voucher codes. It is used for the processing and management of these codes.

## How To Complete This Form

To complete this form, follow the instructions below:

1. Enter a title that summarizes the purpose of the submission.
2. Provide the customer's name.
3. Enter the customer's email address.
4. Enter the eSIM referral code.
5. Enter the eSIM voucher code.
6. Enter the customer's phone number.
7. Provide any additional notes about the customer, if necessary.
8. Enter the expiration date for the eSIM referral code.
9. Enter the expiration date for the eSIM voucher code.
10. Click "Submit" to complete the form.

## Field-by-Field Explanation

* **Form Title** (`form_title`, text, required): Enter a title that summarizes the purpose of the submission.
* **Customer Name** (`customer_name`, text, required): Enter the customer's name.
* **Customer Email** (`customer_email`, email, required): Enter the customer's email address.
* **eSIM Referral Code** (`esim_referral_code`, text, required): Enter the eSIM referral code provided by the customer.
* **eSIM Voucher Code** (`esim_voucher_code`, text, required): Enter the eSIM voucher code provided by the customer.
* **Customer Phone** (`customer_phone`, text, required): Enter the customer's phone number.
* **Customer Note** (`customer_note`, note, optional): Provide any additional notes about the customer, if necessary.
* **eSIM Referral Code Expires** (`esim_referral_code_expires`, date, required): Enter the expiration date for the eSIM referral code.
* **eSIM Voucher Code Expires** (`esim_voucher_code_expires`, date, required): Enter the expiration date for the eSIM voucher code.
* **Submit Form** (`submit_form`, text, required): Click "Submit" to complete the form.

## Tips
- Make sure to fill in all required fields before submitting the form.
- Ensure that the eSIM referral code and voucher code expiration dates are accurate.
- If you need to add any additional notes about the customer, use the "Customer Note" field.
