# Personalized Search Request - Help Guide

## Purpose
The Personalized Search Request form is used to gather information from users to create a search request tailored to their specific needs. It helps our team to better understand what you're looking for and provide more accurate results.

## How To Complete This Form
To complete this form, please follow these steps:

1. Enter a title for the search request in the "Form Title" field. This title will help us identify the search request clearly.
2. Select the type of search you require from the "Search Type" dropdown menu.
3. Choose the categories relevant to your search from the "Search Category" multi-select field.
4. Enter the location where you'd like to search (if applicable).
5. If desired, add priority level for the search in the "Priority" field.
6. Add any optional notes for the search in the "Search Notes" field.
7. Enter your contact email address and phone number in case we need to reach out to you.
8. Set a follow-up date and time if you'd like us to follow up with you on the search results.
9. Add any follow-up notes for the search request in the "Follow-up Notes" field.
10. Select the user to whom you'd like to assign the search request from the "Assigned To" dropdown menu.
11. Choose the user who will be responsible for handling the search request from the "Assigned By" dropdown menu.
12. Finally, set the date and time you submit the search request.

## Field-by-Field Explanation
* **Form Title** (`form_title`, text, required): Enter a brief title for the search request.
* **Search Type** (`search_type`, select_one, required): Choose the type of search you require (e.g., general, advanced, or specific).
* **Search Category** (`search_category`, select_multiple, required): Select the categories relevant to your search.
* **Search Location** (`search_location`, text, optional): Enter the location where you'd like to search (if applicable).
* **Priority** (`priority`, number, optional): Set a priority level for the search request (if desired).
* **Search Notes** (`search_notes`, note, optional): Add any optional notes for the search request.
* **Contact Email** (`contact_email`, email, required): Enter your contact email address in case we need to reach out to you.
* **Contact Phone** (`contact_phone`, text, optional): Enter your contact phone number (if applicable).
* **Follow-up** (`follow_up`, date, optional): Set a follow-up date for the search request (if desired).
* **Follow-up Time** (`follow_up_time`, time, optional): Set a follow-up time for the search request (if desired).
* **Follow-up Notes** (`follow_up_notes`, note, optional): Add any follow-up notes for the search request.
* **Assigned To** (`assigned_to`, select_one, optional): Select the user to whom you'd like to assign the search request.
* **Assigned By** (`assigned_by`, select_one, optional): Choose the user who will be responsible for handling the search request.
* **Submit Date** (`submit_date`, date, optional): Set the date you submit the search request.
* **Submit Time** (`submit_time`, time, optional): Set the time you submit the search request.

Note: Some fields are optional, but filling them out will help us better understand your search request and provide more personalized results.
