# Company Code Lookup Request - Help Guide
## Purpose
The Company Code Lookup Request form is designed to facilitate internal employees' needs for company codes used to identify and manage company resources, projects, and vendors. This form helps to gather essential information for the correct allocation and assignment of company codes.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in your full name as the requester.
2. Enter your contact email for response and clarification purposes.
3. Provide the company or vendor name to search for the code.
4. Optional: Add a reason for the lookup, if required.
5. If necessary, specify a required by date for the code.
6. Add any additional details to assist the lookup process.

## Field-by-Field Explanation

* **Requester full name** (`requester_name`, `text`, required): Please enter your full name as the person submitting this request.
* **Contact email** (`contact_email`, `email`, required): Enter your email address where you would like to receive the code and any further clarifications.
* **Company or vendor name** (`company_name_or_vendor`, `text`, required): Type the name of the company or vendor you are looking up.
* **Reason for lookup** (`reason_for_lookup`, `text`, optional): If you need to specify a reason for the lookup, please provide it here. (Optional)
* **Required by date** (`required_by_date`, `date`, optional): If you need the code by a specific date, please enter it in the format `yyyy-mm-dd`.
* **Additional details** (`additional_details`, `text`, optional): Any extra information that may assist the lookup process can be added here.

## Tips
- Please ensure that you have checked for any existing company code requests that may be pending or processed.
- Make sure to provide accurate and clear information to expedite the lookup process.
- If you have any further questions or need clarification, please don't hesitate to contact us at `form@gic.mx`.
