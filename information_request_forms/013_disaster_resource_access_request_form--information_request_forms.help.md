# Disaster Resource Access Request Form - Help Guide
## Purpose
This form is used to request access to disaster resources during emergency situations. Please provide as much detail as possible to help us expedite the request process. This form is not a replacement for other emergency services, and if you need immediate assistance, please call or text emergency services directly.

## How To Complete This Form
To complete this form, follow these steps:
1.  Please provide a clear and concise description of the emergency situation you are experiencing.
2.  Select the type of disaster you are experiencing (e.g., Hurricane, Tornado, etc.).
3.  Specify the date of the emergency or when you need assistance.
4.  Choose the resources you need (e.g., Food, Water, Shelter, etc.).
5.  Provide any additional information that will help us understand your request better.
6.  Please fill in your contact information so we can get back to you.

## Field-by-Field Explanation

* **Request Details (1)**: Please provide a brief description of your emergency situation. This will help us understand your request better.
* **Emergency Contact Details (2)**: If you have an emergency contact, please provide their name and phone number so we can reach you or your contact if needed.
* **What type of disaster? (3)**: Select the type of disaster you are experiencing from the options provided. If you are unsure, please choose 'Other' and describe in the request details field above.
* **Date of Request (4)**: Please provide the date of the emergency or when you need assistance. If you are unsure, we will use the date you complete this form.
* **Resources Needed (5)**: Please select the resources you need (e.g., Food, Water, Shelter, etc.). You can choose multiple resources.
* **Additional Info (6)**: If you have any other information that will help us understand your request better, please provide it here.
* **Requestor Information (7)**: Please provide any information about yourself or your organization so we can get back to you.
* **Requestor's Name (8)**: Please provide your name.
* **Requestor's Email (9)**: Please provide your email address so we can get back to you.
* **Requestor's Phone (10)**: Please provide your phone number so we can call or text you back.
* **Requestor's Address (11)**: Please provide your mailing address.
* **City (12)**: Please provide your city.
* **State (13)**: Please provide your state or province.
* **Zip (14)**: Please provide your zip code or postal code.
* **Country (15)**: Please provide your country.
