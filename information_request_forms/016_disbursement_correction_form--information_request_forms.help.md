# disbursement_correction_form - Help Guide
## Purpose
The disbursement correction form is used to submit corrections for discrepancies in disbursements. This form helps the internal team to review and verify the corrected information to maintain accuracy and consistency in financial records.

## How To Complete This Form
To complete this form, follow these steps:

1.  Review the disbursement records for any discrepancies.
2.  Select the disbursement ID from the drop-down menu where the discrepancy occurred.
3.  Enter the corrected amount in the corrected_amount field.

## Field-by-Field Explanation

*   **disbursement_id**: Enter the ID of the original disbursement that needs to be corrected.
*   **corrected_amount**: Enter the corrected amount of the disbursement.

## Tips

*   This form should only be filled if there is a genuine need for correction.
*   Make sure to fill in the correct disbursement ID to allow for accurate tracking and processing.
*   Double-check the corrected amount to ensure it's accurate.
*   If you're unsure about anything, contact the internal team for assistance.
