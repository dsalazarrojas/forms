# Sustainability Education Materials Request Form - Help Guide
## Purpose
This form is designed to collect information from users about their requests for sustainability education materials.

## How To Complete This Form
To complete this form, follow these steps:
1. Choose your category (School, Nonprofit, or Other)
2. Select the resources you are interested in (e.g., Textbooks, Webinars, Workshops, Training, or Other)
3. Choose the audience for whom you are requesting resources for (e.g., Students, Educators, Community Leaders, or Other)
4. Specify your resource availability date and time (if applicable)
5. Select your preferred delivery method (e.g., Email, Mail, Phone, or In-person)
6. Add any additional comments or requests

## Field-by-Field Explanation

* **School or Nonprofit (1)**: Please select the category for your organization. This will help us understand which group you belong to.
* **Resource Type (2)**: Choose the type of resources you are interested in. For example, if you are looking for educational materials, select Textbooks, Webinars, or Workshops.
* **Audience (3)**: Specify the audience for whom you would like to request these resources. For example, if you are requesting resources for students, select Students.
* **Resource Availability (4)**: If you know when you would like to receive the resources, enter the date and time. This will help us plan and schedule the delivery of the resources.
* **Resource Availability Time (5)**: If you specified resource availability date, select the corresponding time.
* **Delivery Method (6)**: Choose how you would like to receive the resources. For example, Email, Mail, Phone, or In-person.
* **Comments (7)**: If you have any additional comments or requests, type them here. This is an opportunity to provide more information about your needs.

## Tips
* Please be as specific as possible when selecting your resource types and audience to help us provide targeted support.
* If you have any questions or concerns, contact us at form@gic.mx.
