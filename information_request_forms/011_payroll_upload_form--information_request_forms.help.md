# payroll_upload_form - Help Guide
## Purpose
This form is designed to collect information from employees about the files they will upload, ensuring that the correct file type and usage information is captured.

## How To Complete This Form
To complete this form, please follow these steps:
1. Enter your name and other required information.
2. Upload the file and select the correct file type (CSV, PDF, Excel, or Other).
3. Describe the file size and format.
4. Specify the usage of the file within your organization (Finance, HR, Management, or Other).
5. Add any additional comments or information about the file.

## Field-by-Field Explanation
* **What is your name** (Text, Required): Enter your name as it appears on your identification documents.
* **File Name** (Text, Required): Give a descriptive name to the file you will upload.
* **What date will you be uploading the file on?** (Date, Optional): If you are unsure of the exact date, please provide an estimate.
* **How many files will you be uploading?** (Number, Required): Specify the number of files you are uploading.
* **What is the name of the payroll system your employer uses?** (Text, Required): Provide the exact name of the payroll system used by your employer.
* **What type of file will you be uploading?** (Select One, Required): Select one of the following options: CSV, PDF, Excel, or Other (please specify).
* **Please describe the file size and format** (Text, Required): Provide details about the file size and format (e.g., MB, KB, Excel 2007).
* **How will the file be used within your organization?** (Select Multiple, Required): Choose one or more of the following options: Finance, HR, Management, or Other (please specify).
* **Please provide any additional comments or information about the file** (Text, Optional): Add any additional details or context about the file you are uploading.

## Tips
* Ensure that you are not uploading duplicate files.
* Verify that the file type and usage information is accurate.
* If you are unsure about any of the fields, please contact us for assistance.
