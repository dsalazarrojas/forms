# Smart Water Usage Report Request Form - Help Guide
## Purpose
The Smart Water Usage Report Request Form is designed to collect information for a Smart Water Usage Report. This form helps gather details about the report period, property type, and other relevant information to ensure accurate water usage analysis or billing.

## How To Complete This Form
To complete this form, please follow these steps:

1.  Select the report period for which you want to request the report.
2.  Choose the type of property for which you are requesting the report.
3.  Enter the start and end dates for the report period.
4.  Select the frequency at which you want to receive the report.
5.  Add any additional notes about the report.
6.  Enter the property address for which you are requesting the report.
7.  Enter the name of the property manager responsible for the report.

## Field-by-Field Explanation
* **Report Request (1)**: Enter a brief description of the report you are requesting.
* **Report Period (2)**: Select the month and year for which you want to receive the report. You can choose from January to December.
* **Property Type (3)**: Choose the type of property for which you are requesting the report. This helps us identify the correct water usage metrics.
* **Reporting Period (4)**: Enter the start date and end date for the report period.
* **Report Start Date (5)**: Enter the start date of the report period.
* **Report End Date (6)**: Enter the end date of the report period.
* **Report Frequency (7)**: Select how often you want to receive the report. You can choose from daily, weekly, monthly, quarterly, semi-annually, or annually.
* **Report Notes (8)**: Add any additional information about the report you are requesting.
* **Property Address (9)**: Enter the address of the property for which you are requesting the report.
* **Property Manager Name (10)**: Enter the name of the property manager responsible for the report.

## Tips
* Please ensure that you submit accurate and complete information to avoid any delays or errors in processing your report.
* If you have any questions or concerns, please contact us.
* You can modify this form to suit your specific needs. Feel free to reach out to us if you need any assistance.
