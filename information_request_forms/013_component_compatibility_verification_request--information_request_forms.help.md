# Component Compatibility Verification Request - Help Guide
## Purpose
This form is used to collect information about a component compatibility verification request. Users will fill out this form to provide details about the component they are requesting verification for, including its name, version, and compatibility type. The form also asks for information about the system environment and any known issues that may affect compatibility.

## How To Complete This Form

1. **Request ID**: Enter a unique identifier for this request, which will be used to track and reference this specific request.
2. **Requester Name**: Enter your full name as the person making this request.
3. **Requester Email**: Enter your work email address as the person making this request.
4. **Department**: Select the department that this request is related to.
5. **Request Date**: Enter the date of this request.
6. **Primary Component**: Enter the name or ID of the primary component you are requesting verification for.
7. **Primary Component Version**: Enter the version number of the primary component.
8. **Secondary Component**: Enter the name or ID of the component you are requesting compatibility verification with.
9. **Secondary Component Version**: Enter the version number of the secondary component.
10. **Compatibility Type**: Select the type of compatibility you are verifying (e.g., hardware, software, firmware, API, etc.).
11. **System Environment**: Describe the system environment in which this component is being used.
12. **Operating System**: Select the operating system being used with the component.
13. **Known Issues**: Select the level of known issues that may affect compatibility.
14. **Issue Description**: Describe any known issues in detail.
15. **Testing Required**: Select the level of testing needed for verification.
16. **Priority Level**: Select the priority level of this request.
17. **Required Completion Date**: Enter the date by which you need the verification completed.
18. **Supporting Documents**: Select whether you will be providing supporting documents for this request.
19. **Additional Requirements**: Enter any special requirements or considerations for this request.
20. **Stakeholders to Notify**: List people who should be informed of the results of this verification.

* **Request ID**: This field is a unique identifier for this request, which will be used to track and reference this specific request. It is a required field.
