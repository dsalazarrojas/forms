# wildlife_research_logistics_support_request - Help Guide
## Purpose
This form is designed to collect information related to wildlife research logistics support requests. It helps in gathering details about the project, team, and study logistics.
## How To Complete This Form
To complete this form, follow these steps:

1. Enter the project name and description in the corresponding fields.
2. Provide the project start and end dates.
3. Enter the project location.
4. Provide the team leader's name and email.
5. Indicate if team members are part of the project (Yes/No).
6. Select the transportation type (Yes/No).
7. Enter the transportation details.
8. Enter the logistics contact's name and email.
9. Enter the logistics contact's phone number.
10. Enter the study start and end dates.
11. Enter the study location.
12. Indicate if the study is active (Yes/No).
13. Enter the review date.
14. Select the review status (Active/Inactive).

## Field-by-Field Explanation

* **Project Name** (`project_name`, text, required): Enter the name of the project.
* **Project Description** (`project_description`, text, required): Enter a brief description of the project.
* **Project Start Date** (`project_start_date`, date, required): Enter the start date of the project.
* **Project End Date** (`project_end_date`, date, required): Enter the end date of the project.
* **Project Location** (`project_location`, text, required): Enter the location of the project.
* **Team Leader Name** (`team_leader_name`, text, required): Enter the name of the team leader.
* **Team Leader Email** (`team_leader_email`, text, required): Enter the email of the team leader.
* **Team Members** (`team_member_names`, select_multiple, required): Indicate if team members are part of the project (Yes/No).
* **Team Member Email** (`team_member_email`, select_multiple, required): Indicate if team members have email addresses (Yes/No).
* **Transportation Type** (`transportation_type`, select_one, required): Select if transportation is required (Yes/No).
* **Transportation Details** (`transportation_details`, text, required): Enter the transportation details.
* **Logistics Contact Name** (`logistics_contact_name`, text, required): Enter the name of the logistics contact.
* **Logistics Contact Email** (`logistics_contact_email`, text, required): Enter the email of the logistics contact.
* **Logistics Contact Phone** (`logistics_contact_phone`, text, required): Enter the phone number of the logistics contact.
* **Study Start Date** (`study_start_date`, date, required): Enter the start date of the study.
* **Study End Date** (`study_end_date`, date, required): Enter the end date of the study.
* **Study Location** (`study_location`, text, required): Enter the location of the study.
* **Study Type** (`study_type`, select_one, required): Select if the study is active (Yes/No).
* **Notes** (`notes`, text, required): Enter any notes related to the study.
* **Attachment** (`attachment`, text, required): Enter any attachment information.
* **Attachment Description** (`attachment_description`, text, required): Enter a description of the attachment.
* **Confirm** (`confirm`, select_one, required): Confirm that the information is accurate (Yes/No).
* **Review Date** (`review_date`, date, required): Enter the review date.
* **Review Status** (`review_status`, select_one, required): Select the review status (Active/Inactive).
