# new_buyer_compliance_form - Help Guide
## Purpose
The new_buyer_compliance_form is designed to capture essential information about a new buyer for compliance purposes.

## How To Complete This Form
To complete this form, please follow these steps:
1. Fill out all required fields. While this form is not entirely mandatory, providing accurate and complete information will help ensure that the new buyer's account is set up correctly.
2. Review each field carefully before submitting the form.

## Field-by-Field Explanation
* **real_estate_compliance_file** (1, text, required/optional): Attach the real estate compliance file required for onboarding, if necessary.
* **buyer_name** (2, text, required/optional): Enter the buyer's name as it appears on their government-issued ID or passport.
* **address** (3, text, required/optional): Enter the buyer's address as it appears on their government-issued ID or passport.
* **phone** (4, text, required/optional): Enter the buyer's phone number, if applicable.
* **email** (5, email, required/optional): Enter the buyer's email address, if applicable.
* **buyer_info** (6, note, required/optional): Add any additional information about the buyer that is relevant for compliance purposes.
* **submit** (7, text, required/optional): Enter your confirmation that the form has been filled out correctly.
* **confirm** (8, select_one, required/optional): Select one of the options provided to confirm the form has been filled out correctly. 

## Tips
* Double-check all fields before submitting the form.
* If a field is not required, it's optional; you can skip it if not necessary.
* If you have any issues or concerns, contact your administrator for assistance.
