# production-data-analytics-contact-form - Help Guide
## Purpose
This form is designed to collect contact information from customers or users who are interested in learning more about data analytics related to production data.

## How To Complete This Form

1. Fill in your name in the **Name** field. This is a required field.
2. Enter your email address in the **Email** field. This is also a required field.
3. If you would like to be contacted, you can provide your phone number in the **Phone** field.
4. Select the type of analytics you are looking for in the **What kind of analytics are you looking for?** dropdown menu. This field is required.
5. Choose the data source you are interested in from the **What data source would you like to inquire about?** dropdown menu. This field is required.
6. If you have any additional information you would like to provide, enter it in the **Additional Information** field.

## Field-by-Field Explanation
* **Name** (text, required): Please enter your name.
* **Email** (email, required): Please enter a valid email address.
* **Phone** (text, optional): If you have a phone number, you can enter it here to be contacted directly.
* **What kind of analytics are you looking for?** (select multiple, required): Select one or more of the options provided: Analytics, Reporting, Insights.
* **What data source would you like to inquire about?** (select multiple, required): Select one or more of the provided options: Production Data, Sales Data, Financial Data.
* **Additional Information** (text, optional): If you have any additional comments or details that might be helpful for us to provide the best service, enter them here.
