# CMMC Level 2 Resource Request Form - Help Guide
## Purpose
The CMMC Level 2 Resource Request Form is used to gather information from organizations seeking resources and support related to the CMMC framework.

## How To Complete This Form
- Review the form carefully to ensure you understand each question and select the most accurate options.
- Answer all questions, as each one is required unless otherwise specified.
- Be detailed and specific in your responses to help us better understand your needs.

## Field-by-Field Explanation

* **Requester Name** (`requester_name`, `text`, required): Please enter your full name.
* **Email Address** (`email_address`, `email`, required): Enter your work email address.
* **Phone Number** (`phone_number`, `text`, required): Enter your best contact number.
* **Organization** (`organization`, `text`, required): Enter your company name.
* **Department** (`department`, `text`, required): Enter your department name.
* **Your Role** (`role`, `text`, required): Enter your job title.
* **Request Type** (`request_type`, `select_one`, required): Select one of the following:
  + CMMC Assessment Preparation
  + Gap Analysis
  + Policy Development
  + Technical Implementation
  + Training and Awareness
  + Documentation Review
  + Ongoing Compliance Support
  + Other
* **Current CMMC Status** (`current_cmmc_level`, `select_one`, required): Select one of the following:
  + Not Started
  + Level 1 Self-Assessment
  + Level 2 Partial Implementation
  + Level 2 Fully Implemented
  + Level 3 Certified
  + Unsure
* **Target Certification Date** (`target_certification_date`, `date`, required): Enter the date by which you need certification.
* **Contract Requirements** (`contract_requirements`, `select_one`, required): Select one of the following:
  + Yes active DoD contracts
  + Yes pending contracts
  + Planning to bid
  + No contracts currently
* **Do You Handle FCI** (`fci_handled`, `select_one`, required): Select one of the following:
  + Yes regularly
  + Yes occasionally
  + False
  + Unsure
* **Do You Handle CDI** (`cdi_handled`, `select_one`, required): Select one of the following:
  + Yes regularly
  + Yes occasionally
  + False
  + Unsure
* **Current Security Controls** (`current_controls`, `select_multiple`, required): Select all implemented controls:
  + Access Control
  + Awareness Training
  + Audit and Accountability
  + Configuration Management
  + Identification and Authentication
  + Incident Response
  + Maintenance
  + Media Protection
  + Physical Protection
  + Risk Assessment
  + Security Assessment
  + System Communications Protection
  + System and Information Integrity
  + None Implemented
* **Budget Range** (`budget_range`, `select_one`, optional): Select one of the following:
  + Under $25000
  + $25000 to $50000
  + $50000 to $100000
  + $100000 to $250000
  + Over $250000
  + Not Determined
* **Timeline Urgency** (`timeline_urgency`, `select_one`, required): Select one of the following:
  + Critical - Immediate Need
  + High - Within 30 Days
  + Medium - Within 90 Days
  + Low - Planning Phase
* **Specific Needs Description** (`specific_needs`, `text`, required): Describe your specific requirements.
* **Previous Assessments** (`previous_assessments`, `select_one`, required): Select one of the following:
  + Yes formal CMMC assessment
  + Yes internal self-assessment
  + Yes third-party assessment
  + No assessments yet
* **Team Size** (`team_size`, `number`, optional): Enter the number of employees.
* **IT Infrastructure** (`it_infrastructure`, `text`, optional): Describe your IT environment.
* **Preferred Engagement Type** (`preferred_engagement`, `select_one`, required): Select one of the following:
  + Full Consulting Engagement
  + Advisory Only
  + Training and Support
  + Assessment Only
  + Undecided
* **Additional Comments** (`additional_comments`, `text`, optional): Enter any other relevant information.

## Tips
- Be accurate and detailed in your responses.
- If you have any questions or concerns, please do not hesitate to contact us.
- We will contact you to discuss your request further.
- Please note that this form is for resource requests only; do not use it for other purposes.
