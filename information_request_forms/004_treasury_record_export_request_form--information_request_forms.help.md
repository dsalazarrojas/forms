# Treasury Record Export Request Form - Help Guide
## Purpose
The Treasury Record Export Request Form is used to request a treasury record export, which is used to retrieve a financial record from the system.

## How To Complete This Form
To complete this form, follow these steps:
* Click on the "Submit" button to submit your request.
* Fill in the required fields with accurate information.

## Field-by-Field Explanation
* **What is the purpose of this request?**: This field is required to explain the reason for your export request.
* **What type of record do you need to export?**: Select the type of record you need to export (e.g. General Ledger, Account Balance, Transaction History).
* **Start date**: Enter the start date for the record export (e.g. YYYY-MM-DD).
* **End date**: Enter the end date for the record export (e.g. YYYY-MM-DD).
* **Date range**: Select the date range for the record export (e.g. Last 7 days, Last 30 days, Last 90 days).
* **Output format**: Select the output format for the record export (e.g. Excel, CSV, PDF).
* **Has review status been assigned?**: Check if a review status has been assigned to your export request.
* **Has review status been assigned? (again)**: This field is a duplicate and can be ignored.
* **Email address**: Enter your email address where the exported file will be sent to.
* **Phone number**: Enter your phone number for any follow-up communication.
* **Review comment**: Enter any additional comments for the reviewer.
* **Review status**: Select the review status of the export request (e.g. Approved, Rejected, In Progress).
* **Review type**: Select the type of review (e.g. Internal, External, Both).
* **Export date**: Enter the date you want the record to be exported.
* **Export time**: Enter the time you want the record to be exported.
* **Export file**: Enter the name of the exported file.
* **Assigned to**: Select the person or team that will be assigned to review the export request.
* **Reviewed by**: Select the person or team that will review the export request (e.g. Finance, Audit, Operations).
* **Review comments**: Enter any additional comments for the reviewer.
* **Review comment (again)**: This field is a duplicate and can be ignored.
* **Export status**: Select the status of the export request (e.g. Exported, Not Exported, Pending).
* **Export file name**: Enter the name of the exported file.
* **Export path**: Enter the path where the exported file will be located.

Please note that some fields are not required and can be ignored if not applicable.
