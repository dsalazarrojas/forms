**Warehouse Release Form - Help Guide**

## Purpose
The Warehouse Release Form is used to indicate whether goods should be released or not. It is essential to fill out this form accurately to ensure that goods are properly managed within the warehouse.

## How To Complete This Form

1. Select one of the options to answer the question: "Is the warehouse ready to be released?"
2. Enter the name of the goods to be released, if applicable.
3. Choose the date for the release, following the date format.
4. Enter the quantity of goods to be released.
5. Provide a brief reason for releasing the goods.
6. Select one of the options for "Was released by?" to indicate whether someone or a system approved the release.
7. Select one of the options for "Release authorization" to confirm whether the release is authorized or not.

## Field-by-Field Explanation

* **release_warehouse** (Warehouse Release Form 1, `select_one`):
  This field requires you to select whether the warehouse is ready to be released or not. Choose 'Yes' if the warehouse is ready, 'No' otherwise.
* **goods_to_release** (Warehouse Release Form 2, `text`):
  Enter the name of the goods to be released, if applicable.
* **release_date** (Warehouse Release Form 3, `date`):
  Enter the date for the release in the date format (e.g., `MM/DD/YYYY`).
* **quantity** (Warehouse Release Form 4, `number`):
  Enter the quantity of goods to be released.
* **reason_for_release** (Warehouse Release Form 5, `text`):
  Provide a brief reason for releasing the goods.
* **released_by** (Warehouse Release Form 6, `select_one`):
  Indicate whether someone or a system approved the release by selecting 'Yes' if so or 'No' otherwise.
* **release_authorization** (Warehouse Release Form 7, `select_one`):
  Confirm whether the release is authorized by selecting 'Yes' if authorized or 'No' otherwise.

## Tips

- Make sure to fill out all the fields accurately for proper warehouse management.
- If you are unsure of any field, please contact your supervisor for guidance.
