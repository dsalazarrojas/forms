# Store Manager Assessment Form - Help Guide
## Purpose
The Store Manager Assessment Form is designed to evaluate the skills and performance of store managers. This form is used to collect information about a store's description, assessment, and the person responsible for its management (the "store keeper").

## How To Complete This Form
To complete this form, follow these steps:

1. Review each field carefully and enter relevant information.
2. Ensure that you provide accurate answers to each question.
3. Enter your answers according to the field-by-field explanation below.

## Field-by-Field Explanation
### **Store Manager Assessment Form** (`store_manager_assessment_form`)
A brief description of the store manager's assessment.
(required: false)

*   This field is a short answer field where you can provide a brief description of the store manager's assessment.

### **Store Assessment** (`store_assessment_form`)
A brief description of the store's performance.
(required: false)

*   This field is a short answer field where you can provide a brief description of the store's performance.

### **Store Keeper** (`store_keeper_form`)
The name of the person responsible for the store's management.
(required: false)

*   This field is a short answer field where you can enter the name of the person responsible for the store's management.

### **Store Description** (`store_assessment_form_description`)
A brief description of the store's characteristics.
(required: false)

*   This field is a short answer field where you can provide a brief description of the store's characteristics.

## Tips
*   Make sure to answer each field clearly and concisely.
*   Use correct and accurate information for each field.
*   If you have any doubts or need further clarification, please contact form@gic.mx.
