# Return Shipment Form - Help Guide
## Purpose
This form is used to document the details of a return shipment, including the date of return shipment, recipient, and reason for return. It helps the storekeeper keep track of return shipments and ensures accurate and efficient handling of returns.

## How To Complete This Form
To complete this form, simply fill in the required fields with the relevant information about the return shipment. You will be taken to the next page after completing each page of the form.

## Field-by-Field Explanation
* **Return Shipment Details** (`return_shipment_form_page_1`, text, optional): Enter a brief description of the return shipment.
* **Return Shipment Details Date** (`return_shipment_details_date`, date, optional): Enter the date of the return shipment.
* **Shipper** (`shipper`, text, optional): Enter the name or ID of the shipper who sent the shipment.
* **Recipient** (`recipient`, text, optional): Enter the name or ID of the recipient who received the shipment.
* **Reason for Return** (`reason_for_return`, text, optional): Enter a brief description of the reason for the return.
* **Notes** (`return_shipment_details_note`, note, optional): Enter any additional notes or comments about the return shipment.
* **Return Shipment Form Page 2** (`return_shipment_form_page_2`, text, optional): This field is currently not used and can be ignored.
* **Recipient Email** (`recipient_email`, email, optional): Enter the email address of the recipient who received the shipment.
* **Recipient Phone** (`recipient_phone`, text, optional): Enter the phone number of the recipient who received the shipment.
* **Return Shipment Details Date** (`return_shipment_details_date`, date, optional): This field is duplicate and currently not used. Please ignore.

## Tips
- Please ensure all fields are filled in as accurately and thoroughly as possible.
- If you are unsure about any field, please contact the storekeeper for clarification.
- This form is designed to be completed by the storekeeper or designated personnel only.
