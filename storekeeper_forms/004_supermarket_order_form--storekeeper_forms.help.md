# Supermarket Order Form - Help Guide

## Purpose
The Supermarket Order Form is designed to collect information from customers about their shopping experience in a supermarket. This helps the supermarket to gather essential details about customers and improve their services.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter your name and contact information in the **Customer Details** section.
2. In the **Store Details** section, enter the name or code of the store you visited.
3. In the **Order Items** section, list the items you'd like to purchase or have purchased.

## Field-by-Field Explanation

* **Order Form** (1):
	+ Label: Order Form
	+ Type: text
	+ Required: false
	Enter any additional information about your order, such as special requests or comments.
* **Customer Details** (2):
	+ Label: Customer Details
	+ Type: text
	+ Required: false
	Enter your name and contact information, such as phone number or email.
* **Store Details** (3):
	+ Label: Store Details
	+ Type: text
	+ Required: false
	Enter the name or code of the store you visited.
* **Order Items** (4):
	+ Label: Order Items
	+ Type: text
	+ Required: false
	Enter a list of items you'd like to purchase or have purchased.
