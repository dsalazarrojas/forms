# Return Material Authorization Form - Help Guide
## Purpose
The Return Material Authorization Form is used to initiate the return process of store items. Fill out this form to provide the necessary information required for the return process.

## How To Complete This Form
1. Fill in the Customer Name field with the customer's name.
2. Provide a brief description of the material being returned in the Material Description field.
3. Select the cost center responsible for the material in the Cost Center field.
4. Enter the quantity of material being returned in the Material Quantity field.
5. If required, enter the authorization date for the return in the Authorization Date field.
6. Add any additional remarks about the return in the Remarks field.
7. Enter the customer's phone number in the Customer Phone field.
8. Enter the customer's email address in the Customer Email field.
9. Select the person authorized to approve the return from the Authorized By field.
10. Select whether the return has been approved or denied in the Storekeeper Approval field.
11. Select whether the return has been approved or denied by the manager in the Manager Approval field.
12. Select whether the return has been approved or denied by the director in the Director Approval field.
13. Add any final remarks about the return in the Final Remarks field.

## Field-by-Field Explanation

* **Customer Name (`customer_name`, text, optional): Enter the name of the customer.
* **Material Description (`material_description`, text, optional): A brief description of the material being returned.
* **Cost Center (`cost_center`, select multiple, required): Select all cost centers responsible for the material.
* **Material Quantity (`material_quantity`, number, optional): Enter the quantity of material being returned.
* **Authorization Date (`authorization_date`, date, optional): Date of the authorization for the return.
* **Remarks (`remarks`, note, optional): Add any additional remarks about the return.
* **Customer Phone (`customer_phone`, text, optional): Enter the customer's phone number.
* **Customer Email (`customer_email`, email, optional): Enter the customer's email address.
* **Authorized By (`authorized_by`, select one, required): Select the person authorized to approve the return.
* **Storekeeper Approval (`storekeeper_approval`, select one, required): Select whether the return has been approved or denied by the storekeeper.
* **Manager Approval (`manager_approval`, select one, required): Select whether the return has been approved or denied by the manager.
* **Director Approval (`director_approval`, select one, required): Select whether the return has been approved or denied by the director.
* **Final Remarks (`remarks`, note, optional): Add any final remarks about the return.
