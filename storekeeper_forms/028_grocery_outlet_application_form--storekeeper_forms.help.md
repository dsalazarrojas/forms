# Grocery Outlet Application Form - Help Guide
## Purpose
The Grocery Outlet Application Form is used to collect employment history and emergency contact information about an individual. 

## How To Complete This Form
1. Select or fill out the required and optional fields as requested. Most of the fields on this form are not required, so you can leave them blank if they do not apply to you.
2. Fill in all the fields you have information for, even if it's not required.

## Field-by-Field Explanation
* **First Name** (`first_name`, text, optional): Enter your first name. 
* **Last Name** (`last_name`, text, optional): Enter your last name. 
* **Email** (`email`, email, optional): Enter a valid email address. 
* **Phone** (`phone`, text, optional): Enter your phone number. 
* **Date of Birth** (`date_of_birth`, date, optional): Enter your date of birth in YYYY-MM-DD format. 
* **Job Title** (`job_title`, text, optional): Enter your job title, if applicable. 
* **Years of Experience** (`years_of_experience`, number, optional): Enter the number of years you have been employed. 
* **Work History** (`work_history`, text, optional): Enter a brief description of your work history. 
* **Job References** (`job_references`, select multiple, optional): Select "Yes" if you have job references, "No" if you do not. 
* **Emergency Contacts** (`emergency_contacts`, select multiple, optional): Select "Yes" if you have emergency contacts, "No" if you do not. 
* **Emergency Contact Relationship** (`emergency_contact_relationship`, select multiple, optional): Select "Yes" if you have an emergency contact, "No" if you do not. 
* **Emergency Contact Number** (`emergency_contact_number`, text, optional): Enter the contact number if you have emergency contact. 
* **Emergency Contact Number Type** (`emergency_contact_number_type`, text, optional): Select the contact number type, if applicable. 
* **Emergency Contact Relationship Type** (`emergency_contact_relation_type`, text, optional): Select the contact type, if applicable. 
* **Employment Start Date** (`employment_start_date`, date, optional): Enter your employment start date. 
* **Last Worked At** (`last_worked_at`, date, optional): Enter your last worked date. 
* **Emergency Contact Address** (`emergency_contact_address`, text, optional): Enter the contact address if you have emergency contact. 
* **Job Reference Description** (`job_references_description`, text, optional): Enter a brief description of your job reference. 
* **Emergency Contact Relation Type** (`emergency_contact_relation_type`, text, optional): Select the contact relation type, if applicable. 
* **Employment End Date** (`employment_end_date`, date, optional): Enter your employment end date. 
* **Years Worked** (`years_worked`, number, optional): Enter the number of years you have worked. 
* **Hours Worked** (`hours_worked`, number, optional): Enter the number of hours you have worked. 
* **Employment Type** (`employment_type`, text, optional): Select the employment type, if applicable. 
* **Emergency Contact Relation Type 2** (`emergency_contact_relation_type2`, text, optional): Select the contact relation type 2, if applicable. 
* **Emergency Contacts Type** (`emergency_contacts_type`, text, optional): Select the contact type, if applicable.
