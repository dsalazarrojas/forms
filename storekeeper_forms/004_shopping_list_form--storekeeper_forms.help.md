# Shopping List Form - Help Guide

## Purpose

The shopping list form is designed to collect and manage shopping activities for storekeepers or store management teams. This includes recording store information, item purchases, and other relevant details to support inventory management and business insights.

## How To Complete This Form

1. Start by filling out the "General Info" section:
	* Enter the store name as it appears on records or official documents.
	* Input the store address, phone number, and email for contact information.
	* Select the store's hours of operation using the "Store Hours" field.
	* Add any additional notes about the store if necessary.
2. Move on to the "Item List" section:
	* Select "Yes" or "No" for whether each item will be repeated for future purchases.
	* For each item, enter the item name, quantity, price, purchase date, and whether it will be repeated.
3. Verify all fields are complete and accurate before proceeding.

## Field-by-Field Explanation

* **General Info**
	+ **Store Name** (`store_name`, required): Enter the name of the store as it appears on records or official documents.
	+ **Store Address** (`store_address`, optional): Enter the store's address for contact information.
	+ **Store Phone** (`store_phone`, required): Input the store's phone number for contact.
	+ **Store Email** (`store_email`, required): Enter the store's email address for contact.
	+ **Store Hours** (`store_hours`, required): Select the store's hours of operation using the time field.
	+ **Notes** (`notes`, optional): Add any additional notes or comments about the store.
* **Item List**
	+ **Item Name** (`item_name`, required): Enter the name of the item purchased.
	+ **Item List** (`item_list`, required): Select whether each item will be repeated for future purchases.
	+ **Quantity** (`quantity`, required): Enter the quantity of the item purchased.
	+ **Price** (`price`, required): Enter the price paid for the item.
	+ **Purchase Date** (`purchase_date`, required): Select the date the item was purchased.
	+ **Store Category** (`store_category`, optional): Select whether the store is a category that sells the item.
	+ **Repeat** (`repeat`, optional): Select whether the item will be repeated for future purchases.
	+ **Store Notes** (`store_notes`, optional): Add any additional notes or comments about the store.

## Tips

- Double-check all fields for accuracy before submitting the form.
- Use the "Store Category" field to categorize stores by their type.
- The "Repeat" field allows for tracking items that will be purchased again.
- Use the "Store Notes" field to add context or details about the store.
