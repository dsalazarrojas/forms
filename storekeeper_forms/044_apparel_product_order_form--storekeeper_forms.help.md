# Apparel Product Order Form - Help Guide
## Purpose
This form is used to provide information for apparel products ordered by stores, helping to streamline the order process and ensure accurate fulfillment.

## How To Complete This Form
To complete this form, please follow these steps:

1. Enter your store's name and ID in the respective fields.
2. Select the product's category from the provided options.
3. Enter the product's brand name.
4. Choose the size of the product ordered.
5. Specify the quantity ordered.
6. Select the priority level of the order (Low, Normal, High, or Urgent).
7. Enter the date the order was requested.
8. Optional: Enter the expected delivery date for the order.
9. Provide any additional notes or instructions for the warehouse staff.

## Field-by-Field Explanation
- **Store Name** (Store Name, Text, Required): Enter your store's name.
- **Store ID / Branch Code** (Store ID / Branch Code, Text, Required): Enter your store's ID or branch code.
- **Item SKU or Product Code** (Item SKU or Product Code, Text, Required): Enter the product's SKU or product code.
- **Product Category** (Product Category, Select One, Required): Select the category of the product (e.g., Tops, Bottoms, Outerwear, etc.).
- **Brand Name** (Brand Name, Text, Optional): Enter the brand name of the product.
- **Size** (Size, Select One, Required): Choose the size of the product ordered.
- **Quantity** (Quantity, Number, Required): Enter the quantity of the product ordered.
- **Priority** (Priority, Select One, Required): Select the priority level of the order (e.g., Low, Normal, High, or Urgent).
- **Date of Request** (Date of Request, Date, Required): Enter the date the order was requested.
- **Expected Delivery Date** (Expected Delivery Date, Date, Optional): Enter the expected delivery date for the order.
- **Additional Notes for Warehouse** (Additional Notes for Warehouse, Text, Optional): Provide any additional notes or instructions for the warehouse staff to process the order efficiently.
