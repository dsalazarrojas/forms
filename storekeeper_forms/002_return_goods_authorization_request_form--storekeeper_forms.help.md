# Return Goods Authorization Request Form - Help Guide

## Purpose

The Return Goods Authorization Request Form is used to facilitate the return of goods that were not as described, damaged, or received in error. This form helps the store understand the reason for the return and process it efficiently.

## How To Complete This Form

1. Fill out the form completely and accurately with the required information.
2. Select the correct reason for the return from the options provided.
3. Enter your return date and time.
4. Provide any additional remarks or comments.
5. Enter the contact person's information, including their email and phone number.

## Field-by-Field Explanation

* **Return Reason (<return_reason>**, Select One, Required):*   Select the reason why you are returning the goods. This could be either "Faulty", "Incorrect Order", "Damaged", or other.
*   **Product Details (<product_details>**, Text, Not Required):*   Enter a brief description of the product that is being returned, including the product name and any identifying features that can help the store process the return.
*   **Return Date (<return_date>**, Date, Not Required):*   Enter the date you wish to return the goods.
*   **Return Time (<return_time>**, Time, Not Required):*   Enter the time you wish to return the goods.
*   **Remarks (<remarks>**, Note, Not Required):*   If you have any additional comments or remarks about the return, enter them here.
*   **Contact Person (<contact_person>**, Text, Not Required):*   Enter the name of the person to contact for further information.
*   **Contact Email (<contact_email>**, Email, Not Required):*   Enter the email of the person to contact for further information.
*   **Contact Phone (<contact_phone>**, Text, Not Required):*   Enter the phone number of the person to contact for further information.
*   **Contact Address (<contact_address>**, Text, Not Required):*   Enter the address of the person to contact for further information.
