# Medical Knowledge Assessment - Help Guide
## Purpose
The Medical Knowledge Assessment form is designed to evaluate the clinical knowledge of students or healthcare staff in various medical categories.

## How To Complete This Form

To complete this form, follow these steps:

1.  On page 1, choose whether the form is being used for students or healthcare staff.
2.  On page 2, select the category of the form (e.g., anatomy, pharmacology, etc.).
3.  On page 3, enter your description for the assessment.
4.  On page 4, select the evaluation questions (e.g., yes or no answers).
5.  On the final page, enter your submission details.

## Field-by-Field Explanation

* **Medical Knowledge Assessment** (`medical_knowledge_assessment`, text, optional):
    Enter a brief title for the assessment.
* **Category** (`category`, select_one, optional):
    Select the category that the form is being used for (e.g., anatomy, pharmacology, etc.).
* **Description** (`description`, text, optional):
    Enter a description for the assessment.
* **Evaluation Questions** (`evaluation_questions`, select_multiple, optional):
    Select the evaluation questions for the assessment (e.g., yes or no answers).
* **Submit** (`submit`, text, optional):
    Enter your submission details in this field.

## Tips

*   Be concise and clear in your answers.
*   Use the category and description fields to provide additional context for the assessment.
*   Select all applicable questions for the evaluation questions field.
*   Enter the submission details accurately and completely.
