# prosocial_behavior_quiz - Help Guide
## Purpose
This form is designed to collect information about the social behavior of different groups, including educators, students, parents, teachers, trainers, admins, and others. It helps gather data for research or survey purposes.

## How To Complete This Form
To complete this form, follow these steps:

1. Select all applicable categories that you interact with or work with.
2. Enter the names and titles for each selected category.
3. Repeat this process for each section of the form.

## Field-by-Field Explanation

* **Prosocial Behavior Quiz Form** (`intro_question`, `note`, required: false): This is an introductory text that explains the purpose of the form.
* **Educators** (`section_1`, `select_multiple`, required: false): Select all the educators you interact with. If none, select 'No'.
*   **Educator's Name** (`educators_name`, `text`, required: false): Enter the name of the educator you selected in the previous field.
*   **Educator's Title** (`educators_title`, `text`, required: false): Enter the title of the educator you selected in the previous field.
*   **Students** (`section_2`, `select_multiple`, required: false): Select all the students you interact with. If none, select 'No'.
*   **Student Name** (`student_name`, `text`, required: false): Enter the name of the student you selected in the previous field.
*   **Number of Students** (`students_count`, `number`, required: false): Enter the number of students you interact with.
*   **Parents** (`section_3`, `select_multiple`, required: false): Select all the parents you interact with. If none, select 'No'.
*   **Parent's Name** (`parent_1_name`, `text`, required: false): Enter the name of the parent you selected in the previous field.
*   **Parent's Relation** (`parent_1_relation`, `text`, required: false): Enter the relation of the parent you selected in the previous field.
*   **Parent 2's Name** (`parent_2_name`, `text`, required: false): Enter the name of the second parent you interact with.
*   **Parent 2's Relation** (`parent_2_relation`, `text`, required: false): Enter the relation of the second parent you interact with.
*   **Teachers** (`section_4`, `select_multiple`, required: false): Select all the teachers you interact with. If none, select 'No'.
*   **Teacher's Name** (`teacher_name`, `text`, required: false): Enter the name of the teacher you selected in the previous field.
*   **Teacher's Title** (`teacher_title`, `text`, required: false): Enter the title of the teacher you selected in the previous field.
*   **Trainers** (`section_5`, `select_multiple`, required: false): Select all the trainers you interact with. If none, select 'No'.
*   **Trainer's Name** (`trainer_name`, `text`, required: false): Enter the name of the trainer you selected in the previous field.
*   **Trainer's Title** (`trainer_title`, `text`, required: false): Enter the title of the trainer you selected in the previous field.
*   **Admins** (`section_6`, `select_multiple`, required: false): Select all the admins you interact with. If none, select 'No'.
*   **Admin's Name** (`admin_name`, `text`, required: false): Enter the name of the admin you selected in the previous field.
*   **Admin's Title** (`admin_title`, `text`, required: false): Enter the title of the admin you selected in the previous field.
*   **Others** (`section_7`, `select_multiple`, required: false): Select all the others you interact with. If none, select 'No'.
*   **Others' Name** (`others_name`, `text`, required: false): Enter the name of the other person you selected in the previous field.
*   **Others' Title** (`others_title`, `text`, required: false): Enter the title of the other person you selected in the previous field.
*   **Others' Relation** (`others_relation`, `text`, required: false): Enter the relation of the other person you selected in the previous field.

## Tips
* Select all applicable categories to avoid unnecessary fields.
* Use accurate and correct information for each field.
* Double-check your selections and responses before submitting the form.
