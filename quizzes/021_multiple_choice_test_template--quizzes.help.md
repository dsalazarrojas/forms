# multiple_choice_test_template - Help Guide
## Purpose
The "multiple_choice_test_template" form is designed for testing multiple choice questions. It allows users to create a template to evaluate their own questions with multiple options and answers to be selected. 

## How To Complete This Form
To complete this form, follow these steps:
1. Fill out each question with your answer by selecting the relevant option for each question from the available options.
2. Optionally, you can also enter a score for each question.
3. Once you have answered all questions, click on the "Submit" field.

## Field-by-Field Explanation
* **multiple_choice_question** (`question_1`, select_one, required/optional): Answer the question "multiple_choice_question" with either "Yes" or "No".
* **answer_1** (`answer_1`, select_multiple, required/optional): Select all answers that apply to "answer_1".
* **score** (`score`, number, required/optional): Enter the score for the current question.
* **submit** (`submit`, note, required/optional): Click on this field to submit your answers.
* **multiple_choice_question_2** (`question_2`, select_one, required/optional): Answer the question "multiple_choice_question_2" with either "Yes" or "No".
* **multiple_choice_question_3** (`question_3`, select_one, required/optional): Answer the question "multiple_choice_question_3" with either "Yes" or "No".
* **multiple_choice_question_4** (`question_4`, select_one, required/optional): Answer the question "multiple_choice_question_4" with either "Yes" or "No".

## Tips
- Make sure to answer all questions before submitting your results.
- Use the available options to select the best possible answer for each question.
