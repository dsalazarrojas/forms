# Linking Words Assessment - Help Guide
## Purpose
The Linking Words Assessment form is designed to collect user-submitted data for the purpose of evaluating their understanding of linking words.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in your **First Name**, which is a required field.
2. Enter your **Email**, which is optional but recommended for future correspondence.
3. Select the **Quiz Number** you are completing the assessment for.
4. Provide the **Start Time** and **End Time** for the assessment, as these are required fields.
5. Answer each of the six **Question** fields, selecting one or multiple options from the provided choices.

## Field-by-Field Explanation
- **First Name** (First Name, text, required): Enter your personal name as you would like it to be displayed.
- **Email** (Email, email, optional): Enter a valid email address for future correspondence.
- **Quiz Number** (Quiz Number, number, required): Select the number of the quiz you are completing.
- **Start Time** (Start Time, time, required): Enter the start time of the assessment.
- **End Time** (End Time, time, required): Enter the end time of the assessment.
- **Question 1** (Question 1, select_one, required): Select one option from the list to answer the question.
- **Question 2** (Question 2, select_one, required): Select one option from the list to answer the question.
- **Question 3** (Question 3, select_one, required): Select one option from the list to answer the question.
- **Question 4** (Question 4, select_one, required): Select one option from the list to answer the question.
- **Question 5** (Question 5, select_multiple, required): Select multiple options from the list to answer the question.
- **Question 6** (Question 6, select_multiple, required): Select multiple options from the list to answer the question.
