# us_states_quiz - Help Guide
## Purpose
The "us_states_quiz" form is an optional testing tool used to collect user input on their state(s) of origin and destination.

## How To Complete This Form
1. Click on the "Submit" button to start filling out the form.
2. Go through each page and fill out the fields as instructed.

## Field-by-Field Explanation
- **which_state_is_it** (select_multiple, required: false): Select all the states that apply to your origin.
  - This field is where you'll select all the states from which you're coming from.
  - You can choose multiple states.
- **another_state** (select_one, required: false): Select the state that is next on your list.
  - This field is where you'll select the next state after your origin.
  - You can only choose one state.
- **which_state_is_next** (date, required: false): Please enter the date when you plan to arrive in the selected state. 
  - Please use a standard date format like MM/DD/YYYY.
- **additional_comments** (note, required: false): If you have any additional comments or information to provide, enter them here.
  - This is an optional field where you can add any relevant information.
- **email_address** (email, required: false): Enter your email address.
  - This field is optional and not used in this testing form.
- **phone_number** (text, required: false): Enter your phone number.
  - This field is optional and not used in this testing form.
- **final_state** (select_one, required: false): Select the last state on your list.
  - This field is where you'll select the last state on your destination list.
  - You can only choose one state.

## Tips
- Make sure to fill out each field accurately and completely.
- If you're unsure about any field, feel free to ask for help.
- You can only fill out this form once.
