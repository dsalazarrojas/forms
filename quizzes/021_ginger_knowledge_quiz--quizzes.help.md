# Ginger Knowledge Quiz - Help Guide
## Purpose
This form is designed to help test your knowledge on a set of questions. It allows you to create a quiz with up to 8 questions, each with 2 possible answers and a feedback field for users to provide comments. The quiz title, category, and description can also be customized.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the title of your quiz in the "Quiz Title" field.
2. Select the category of your quiz from the "Quiz Category" dropdown menu.
3. Enter a brief description of your quiz in the "Quiz Description" field.
4. For each question, enter the question text in the corresponding "Quiz Question" field.
5. Select the correct answer from the "Quiz Answer" dropdown menu.
6. Leave feedback for the user in the "Quiz Feedback" field.
