# Word Search Activity - Help Guide
## Purpose
The Word Search Activity form is designed to help you create a word search puzzle based on your specifications. Fill out this form to generate a unique word search puzzle that can be used for entertainment, education, or other purposes.

## How To Complete This Form
To complete this form, follow these steps:

* Fill out the **Title** field with the name of the word search activity you want to create.
* Choose the **Puzzle Size**, **Puzzle Grid Color**, **Puzzle Grid Shape**, and **Grid Orientation** from the provided options.
* Enter the **Word List**, **Word List 2**, and **Word List 3** fields with the words you want to appear in the puzzle.

## Field-by-Field Explanation
* **Word Search Activity Title (required: false)**: Enter the title of the word search activity that will be displayed on the puzzle.
* **Description (required: false)**: Enter a brief description of the word search activity if you want to add more information about it.
* **Puzzle Size (select_one)**:
	+ 5x5: Choose this option for a smaller puzzle with a grid of 5x5.
	+ 7x7: Choose this option for a medium-sized puzzle with a grid of 7x7.
	+ 9x9: Choose this option for a larger puzzle with a grid of 9x9.
	+ 11x11: Choose this option for an extra-large puzzle with a grid of 11x11.
	+ 13x13: Choose this option for an extra-extra-large puzzle with a grid of 13x13.
* **Puzzle Grid Color (select_one)**:
	+ Blue: Choose this option to have a blue grid for your puzzle.
	+ Red: Choose this option to have a red grid for your puzzle.
	+ Green: Choose this option to have a green grid for your puzzle.
	+ Yellow: Choose this option to have a yellow grid for your puzzle.
	+ Purple: Choose this option to have a purple grid for your puzzle.
* **Puzzle Grid Shape (select_one)**:
	+ Square: Choose this option for a square puzzle grid.
	+ Rectangle: Choose this option for a rectangular puzzle grid.
	+ Circle: Choose this option for a circular puzzle grid.
	+ Triangle: Choose this option for a triangular puzzle grid.
	+ Diamond: Choose this option for a diamond-shaped puzzle grid.
* **Grid Orientation (select_one)**:
	+ Horizontal: Choose this option for a horizontal grid.
	+ Vertical: Choose this option for a vertical grid.
	+ Diagonal: Choose this option for a diagonal grid.
* **Word List (required: false)**: Enter a list of words to appear in the puzzle. Use commas to separate each word.
* **Word List 2 (required: false)**: Enter another list of words to appear in the puzzle. Use commas to separate each word.
* **Word List 3 (required: false)**: Enter another list of words to appear in the puzzle. Use commas to separate each word.

## Tips
- Make sure to enter the correct number of words in each word list, as the puzzle will reflect the number of words entered.
- You can add or remove words from each word list as needed.
- Experiment with different puzzle parameters to create unique and fun word search activities.
