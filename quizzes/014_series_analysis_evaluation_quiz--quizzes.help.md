# Series Analysis Evaluation Quiz - Help Guide
## Purpose
The Series Analysis Evaluation Quiz is a form designed to help evaluate the analysis series provided by users. It is intended to assess the quality and relevance of the series, ensuring it meets the required standards.

## How To Complete This Form
To complete this form, follow these steps:

1. Review the series title, which is the name of the series being evaluated.
2. Provide a brief description of the series in the series description field.
3. Indicate whether the series features notable characters or not.
4. If it does, list their names in the series characters field. If not, simply select "No".
5. If there are additional characters not listed in the series characters field, describe them in the series characters other field.
6. Choose a theme that best represents the series, selecting one from the theme analysis 1 field. You can select one from the options provided.
7. Choose another theme that represents the series in the theme analysis 2 field. Again, select one from the options provided.
8. Select a theme that best suits the series in the theme analysis 3 field.
9. Provide a brief summary of the plot in the plot summary field.

## Field-by-Field Explanation

* **Series Title** (`series_title`, text, required: false): This is the name of the series being evaluated. Enter the exact title to ensure accurate identification.
* **Series Description** (`series_description`, text, required: false): Briefly describe the series in a few sentences.
* **Series Characters** (`series_characters`, select_multiple, required: false): Select "Yes" if the series features notable characters, and list their names in the series characters other field if necessary.
* **Other Characters (optional)** (`series_characters_other`, text, required: false): Provide the names of any characters not listed in the series characters field.
* **Theme Analysis 1** (`theme_analysis_1`, select_one, required: false): Choose a theme that best represents the series from the options provided.
* **Theme Analysis 2** (`theme_analysis_2`, select_one, required: false): Choose another theme that represents the series from the options provided.
* **Theme Analysis 3** (`theme_analysis_3`, select_one, required: false): Select a theme that best suits the series from the options provided.
* **Plot Summary** (`plot_summary`, text, required: false): Provide a brief summary of the plot.

## Tips

* Make sure to fill in all fields accurately and thoroughly.
* Be as detailed as possible when describing the series.
* If you need help or have questions, reach out to the designated support team.
