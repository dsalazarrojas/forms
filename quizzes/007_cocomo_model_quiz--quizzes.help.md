# COCOMO Model Quiz - Help Guide
## Purpose
The COCOMO Model Quiz is designed to test your knowledge about the COCOMO (Constructive Cost Model) model, which is a method used to estimate the effort required for software development projects. This quiz assesses your understanding of the model's core principles, definitions, and applications.

## How To Complete This Form
To complete this quiz, follow these steps:

1. Enter your **Student Name** in the text field at the top.
2. Provide your **Student ID** in the text field next to it.
3. Enter the **Course Name** where you are taking this quiz in the text field below.
4. Fill in the **Quiz Date** in the date format (mm/dd/yy) in the date field.
5. For questions 1-7, select the correct answer from the dropdown list.
6. For questions 8 and 9, select all that apply from the dropdown list.
7. For question 10, select the correct answer from the dropdown list.
8. Finally, rate your confidence in each answer by selecting one of the five options at the bottom.
