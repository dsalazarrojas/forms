# MCQ Practice Submission Form - Help Guide
## Purpose
The MCQ Practice Submission Form is designed to collect practice submissions for multiple-choice quizzes. This form is used to record student practice submissions for quizzes, allowing for the tracking of progress and performance.

## How To Complete This Form
1. Select the relevant information for each field as required.
2. Ensure that you provide a unique submission for each course, student, and section.
3. Double-check your entries before submitting.

## Field-by-Field Explanation
* **Course ID (`course_id`, number, required: false)**: Enter the course ID to associate this submission with the correct course.
* **Student ID (`student_id`, number, required: false)**: Enter the student ID to track individual student submissions.
* **Section (`section_id`, text, required: false)**: Enter the section number or name to categorize the submission.
* **Section (`section_id_1`, text, required: false)**: This field is a duplicate of the Section field. Please note that this field should not be filled in, as it's not necessary for the submission.

## Tips
* Always ensure that you fill in the correct course, student, and section numbers.
* If you're unsure about any field, refer to your course materials or consult with your instructor.
* Submit a unique entry for each submission.
