# Executive Functioning Quiz - Help Guide
## Purpose
This quiz is designed to assess an individual's executive functioning skills. Executive functioning is a set of high-level cognitive processes such as planning, organization, time management, and self-regulation that are essential for everyday life tasks and activities.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the form by entering your parent's name in the "Parent Name" field.
2. Enter a date in the "Date" field if you have one. If not, you can leave it blank.
3. Enter a time if you have one in the "Time" field. If not, you can leave it blank.
4. Select your executive functioning domain(s) of interest from the list in the "Executive Functioning Domain" field.
5. Answer each of the "Quiz Question" fields with either "Yes" or "No" in the "Quiz Answer" field corresponding to the question.
6. Repeat this process for all questions.

## Field-by-Field Explanation

* **Parent Name** (Parent Name, text, required): Enter your parent's name.
* **Date** (Date, date, optional): Enter the date if you have one. If not, you can leave it blank.
* **Time** (Time, time, optional): Enter the time if you have one. If not, you can leave it blank.
* **Executive Functioning Domain** (Executive Functioning Domain, select_one, optional): Select the executive functioning domain(s) you are interested in.
* **Quiz Question 1** (Quiz Question 1, note, optional): Answer this question with either "Yes" or "No".
* **Quiz Answer 1** (Quiz Answer 1, select_multiple, optional): Select "Yes" or "No" for this question.
* **Quiz Question 2** (Quiz Question 2, note, optional): Answer this question with either "Yes" or "No".
* **Quiz Answer 2** (Quiz Answer 2, select_multiple, optional): Select "Yes" or "No" for this question.
* ... (repeat for all questions and answers)

## Tips
* Make sure to select "Yes" or "No" for each question.
* You can select multiple options for each question.
* If a question does not apply to you, select "No".
* Be honest with your answers, as this quiz is designed to assess your actual abilities.
