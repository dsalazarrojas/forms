# ent_knowledge_quiz - Help Guide
## Purpose
The "ent_knowledge_quiz" form is designed to assess users' knowledge or understanding of specific concepts or topics. It is composed of five sections, each with a distinct type of question or prompt.

## How To Complete This Form
To complete this form, follow these steps:

1. Click on the "ENT Knowledge Quiz" page to begin.
2. Enter your response in the text input field.
3. Select one of the options provided for "ENT concepts".
4. Enter your numerical answer to "Scale questions".
5. Choose all relevant options for "Multiple choice questions".
6. Select multiple checkboxes for "Checkboxes".
7. Review and submit your form.

## Field-by-Field Explanation

* **ENT Knowledge Quiz (Page 1)** (`text`, optional):
	+ This field is a text input where you can provide your response to the prompt "ENT Knowledge Quiz".
* **ENT concepts (Page 2)** (`select_one`, optional):
	+ This field is a multiple-choice question where you can select one option from the list "concept 1", "concept 2", or "concept 3".
* **Scale questions (Page 3)** (`number`, optional):
	+ This field is a numerical question where you can provide a numerical answer.
* **Multiple choice questions (Page 4)** (`select_multiple`, optional):
	+ This field is a multiple-choice question where you can select multiple options from the list "option 1", "option 2", or "option 3".
* **Checkboxes (Page 5)** (`select_multiple`, optional):
	+ This field is a multi-select question where you can select multiple checkboxes from the list "checkbox 1", "checkbox 2", or "checkbox 3".

## Tips
- Please provide clear and concise answers to each question.
- Make sure to review your form before submitting to ensure you have answered all questions accurately.
- If you're unsure about any question, ask for help or clarification.
