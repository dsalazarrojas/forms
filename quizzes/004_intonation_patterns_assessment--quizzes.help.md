# Intonation Patterns Assessment - Help Guide
## Purpose
The Intonation Patterns Assessment form is designed to gather information from users on their intonation patterns, which is crucial for assessing and identifying patterns in musical performances. This form is not a comprehensive music-related form and focuses specifically on assessing intonation patterns of users.

## How To Complete This Form
1. Select one option for each of the two quiz questions (Quiz 1 and Quiz 2).
2. Enter text responses for each of the two question fields (Question 1, Question 2, Question 3, and Question 4).
3. Enter numerical values for each of the two pitch fields (Pitch 1 and Pitch 2).
4. Select multiple options for each of the two note fields (Note 1 and Note 2).
5. Enter a valid email address in the Email field.
6. Enter a phone number in the Phone field.

## Field-by-Field Explanation
* **Quiz 1** (`quiz_1`, `select_one`, optional): Select one of the three options to answer the first quiz question.
* **Quiz 2** (`quiz_2`, `select_one`, optional): Select one of the three options to answer the second quiz question.
* **Question 1** (`question_1`, `text`, optional): Enter a text response for the first question.
* **Question 2** (`question_2`, `text`, optional): Enter a text response for the second question.
* **Question 3** (`question_3`, `text`, optional): Enter a text response for the third question.
* **Question 4** (`question_4`, `text`, optional): Enter a text response for the fourth question.
* **Pitch 1** (`pitch_1`, `number`, optional): Enter a numerical value for the first pitch.
* **Pitch 2** (`pitch_2`, `number`, optional): Enter a numerical value for the second pitch.
* **Note 1** (`note_1`, `select_multiple`, optional): Select multiple options for the first note field.
* **Note 2** (`note_2`, `select_multiple`, optional): Select multiple options for the second note field.
* **Email** (`email`, `email`, optional): Enter a valid email address.
* **Phone** (`phone`, `text`, optional): Enter a phone number.

**Tips**: Ensure that the email address is in the correct format (e.g., `example@example.com`).
