# fun_seasonal_quiz - Help Guide
## Purpose
The "fun_seasonal_quiz" form is designed to help users create and manage seasonal quizzes, allowing them to input information about a specific season and question type, and then create a new set of questions for that season.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the season for which you want to create the quiz.
2. Choose the month of the season (if applicable).
3. Select the type of question you want to ask.
4. Enter the question text.
5. Enter the correct answer.
6. Optionally, select a second season and repeat steps 2-5 for a secondary season.
7. Enter your email and phone number (for verification purposes).

## Field-by-Field Explanation

* **What season is this?** (`season`, select_one): Select the season for which you want to create the quiz (e.g., Autumn, Winter, Spring, Summer).
* **Which month is this?** (`month`, select_multiple): If applicable, select the month for which you want to create the quiz (e.g., January, February, March, etc.).
* **What type of question are you looking for?** (`question_type`, select_one): Choose the type of question you want to ask (e.g., Text, Multiple Choice, True/False, Essay).
* **What's the question?** (`question`, text): Enter the text of the question.
* **What's the correct answer?** (`answer`, text): Enter the correct answer to the question.
* **Email** (`email`, email): Enter your email address (this will be used for verification purposes).
* **Phone** (`phone`, text): Enter your phone number (this will be used for verification purposes).

Note: The optional fields are only required if the corresponding season is selected. The secondary season fields can be filled out if you want to create a second set of questions for a different season.
