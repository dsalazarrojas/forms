# Vehicle Suspension Knowledge Quiz - Help Guide
## Purpose
The purpose of this form is to test your knowledge of vehicle suspension systems by asking multiple-choice questions about front and rear suspension systems, steering systems, and other suspension-related components.

## How To Complete This Form
To complete this form, follow these steps:
1. Answer the questions about front and rear suspension systems (fields 2, 4, and 5).
2. Choose the correct answer(s) for each question.
3. For field 3, select the correct components of a vehicle suspension system.
4. If necessary, enter the correct answer for field 7, the correct_answer field.
5. For field 8, select the incorrect answers.
6. Finally, choose the correct vehicle suspension system for field 10.
7. Select the "Submit" option for field 11, the submit_button field.

## Field-by-Field Explanation
- **vehicle_suspension_knowledge_quiz_form** (Field 1): This is the title of the form, and it is not a field to be completed.
- **Vehicle Suspension Knowledge Questions** (Field 2, Type: select_multiple): Choose one or multiple answers from the provided options 1, 2, 3, 4, 5.
- **Vehicle Suspension System Components** (Field 3, Type: select_one): Choose the correct components of a vehicle suspension system from the options: Front Suspension, Rear Suspension, Steering.
- **Front Suspension Systems** (Field 4, Type: select_multiple): Choose one or multiple correct front suspension systems from the options: MacPherson Strut Assembly, Multi-link, Double Wishbone, Leaf Springs, Coil Springs.
- **Rear Suspension Systems** (Field 5, Type: select_multiple): Choose one or multiple correct rear suspension systems from the options: Live Axles, Independent Rear Suspension, Rear Axle, Leaf Springs, Coil Springs.
- **Steering Systems** (Field 6, Type: select_multiple): Choose one or multiple correct steering systems from the options: Power Steering, Recirculating Ball Type, Recirculating Ball Type Steering, Hydraulic Power Steering, Recirculating Ball.
- **Correct Answer** (Field 7, Type: number): Enter the correct answer to the previous question (if necessary).
- **Incorrect Answers** (Field 8, Type: select_multiple): Choose the incorrect answers.
- **Submit Answers** (Field 9, Type: date): This field is intended for future development purposes and is not currently used.
- **Vehicle Suspension System** (Field 10, Type: select_one): Choose the correct vehicle suspension system from the options: Front Suspension, Rear Suspension, Steering, Other.
- **Submit** (Field 11, Type: select_one): Select the "Submit" option to submit your answers.
