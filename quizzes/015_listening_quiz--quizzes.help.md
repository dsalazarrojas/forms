# Listening Quiz - Help Guide
## Purpose
The Listening Quiz form is designed to help users create and manage listening quizzes. A listening quiz is a type of quiz that tests users' listening skills by asking them to answer questions based on audio recordings.

## How To Complete This Form
To complete the Listening Quiz form, follow these steps:

1. Fill in the **Quiz Settings** field with any relevant information about the quiz.
2. Select the **Questions** field to add or edit questions for the quiz.
3. Use the **Add Question** field to add new questions to the quiz.
4. Use the **Add Question** field to delete questions from the quiz.
5. If you want to add an audio file for the quiz, use the **Audio File** field.
6. If you want to add an audio file for a specific question, use the **Question Audio** field.
7. Fill in the **Question Text** field with the text of the question.
8. Select the **Question Type** field to choose the type of question (multiple choice, short answer, or true/false).
9. If applicable, fill in the **Question Audio Duration** field with the duration of the audio file.
10. If you want to add an audio file for the question, use the **Question Audio File** field.
11. Use the **Submit** field to submit the quiz for review.
12. Use the **Save for Later** field to save the quiz for later.
13. Use the **Save** field to save the quiz.
14. Use the **Discard** field to discard the quiz.

## Field-by-Field Explanation
* **Quiz Settings** (Text Field): Enter any relevant information about the quiz.
* **Questions** (Select Multiple): Select the questions you want to add or edit for the quiz.
	+ Options: Option 1, Option 2, Option 3
* **Add Question** (Select One): 
	+ Options: add, delete, save
* **Audio File** (Text Field): Add an audio file to the quiz.
* **Question Audio** (Text Field): Add an audio file to a specific question.
* **Question Text** (Text Field): Enter the text of the question.
* **Question Type** (Select One): Choose the type of question (multiple choice, short answer, or true/false).
	+ Options: multiple choice, short answer, true/false
* **Question Audio Duration** (Number Field): Enter the duration of the audio file.
* **Question Audio File** (Text Field): Add an audio file to a specific question.
* **Submit** (Select One): 
	+ Options: submit, save for later
* **Save for Later** (Select One): 
	+ Options: save, discard
* **Save** (Select One): 
	+ Options: save, cancel
* **Quiz ID** (Text Field): Enter a unique ID for the quiz.
* **Quiz Title** (Text Field): Enter a title for the quiz.
