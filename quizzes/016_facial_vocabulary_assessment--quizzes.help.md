# Facial Vocabulary Assessment - Help Guide
## Purpose
The Facial Vocabulary Assessment form is designed to collect information about students' preferences, habits, and characteristics. It is intended to be used by educators or administrators to gauge students' knowledge and understanding of facial expressions, emotions, and personal details. The form is usually completed by students as part of a class assignment, project, or assessment.

## How To Complete This Form
To complete the Facial Vocabulary Assessment form, please follow these steps:

1. **Start from the first page**: Begin by providing the student's name.
2. **Progress through the pages**: Each page will ask you for different information, so please answer each question carefully and accurately.
3. **Select options carefully**: When selecting options, choose the one that best fits the student's characteristics or preferences.
4. **Be accurate with dates and times**: When entering dates and times, use the correct format (e.g., MM/DD/YYYY for dates, HH:MM AM/PM for times).
5. **Complete all required fields**: Make sure to answer all required fields, marked as "true" in the form.

## Field-by-Field Explanation

### First Page: Name
* **Name** (required, text): Enter the student's full name as it appears on their official identification.

### Facial Expressions (Select Multiple)
* **Smile**, **Frown**, **Laugh**, **Cry** (required, select multiple): Choose all applicable options that describe the student's facial expressions.

### Facial Expressions Subcategory
* **Sad** (required, select one): Choose the subcategory that best fits the student's facial expressions.

### Second Page: Age
* **Age** (required, number): Enter the student's age.

### Student's Age
* **Age** (required, text): Re-enter the student's age for verification.

### Third Page: Gender
* **Male**, **Female**, **Other** (required, select one): Select the student's gender.

### Student's Gender

### Fifth Page: Favorite Color

### Favorite Color
