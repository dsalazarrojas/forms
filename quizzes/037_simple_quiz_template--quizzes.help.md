# simple_quiz_template - Help Guide
## Purpose
This form is designed to create a simple quiz template. It allows users to input a title, introduction, and questions, as well as specify correct answers and scoring settings. The form can be used to create a basic quiz with multiple-choice questions and scoring options.

## How To Complete This Form

To complete this form, follow these steps:

1. **Introduction**: This is a text field where you can enter a brief description of the quiz.
2. **Quiz Questions**: Select the options for the questions in your quiz. You can choose multiple options for each question.
3. **Correct Answer**: Enter the correct answer for each question.
4. **Score**: Set the scoring settings for the quiz.
5. **Quiz Title**: Enter the title of your quiz.
6. **Question Type**: Choose whether the question is "Yes" or "No".
7. **Question Text**: Enter the text of the question.
8. **Correct Answer Choice**: Select the correct answer for each question.
9. **Correct Answer Choice 2**: Select the correct answer for each question (this field is identical to Correct Answer Choice, but with a different label).

## Field-by-Field Explanation

* **Introduction** (id: 1, label: introduction, type: note, required: false): This is the description of the quiz.
* **Quiz Questions** (id: 2, label: quiz_questions, type: select_multiple, required: false): Select the options for the questions in your quiz.
* **Correct Answer** (id: 3, label: correct_answer, type: text, required: false): Enter the correct answer for each question.
* **Score** (id: 4, label: score, type: number, required: false): Set the scoring settings for the quiz.
* **Quiz Title** (id: 5, label: quiz_title, type: text, required: false): Enter the title of your quiz.
* **Question Type** (id: 6, label: question_type, type: select_one, required: false): Choose whether the question is "Yes" or "No".
* **Question Text** (id: 7, label: question_text, type: text, required: false): Enter the text of the question.
* **Correct Answer Choice** (id: 8, label: correct_answer_choice, type: select_multiple, required: false): Select the correct answer for each question.
* **Correct Answer Choice 2** (id: 9, label: correct_answer_choice_2, type: select_multiple, required: false): This field is identical to Correct Answer Choice, but with a different label.

## Tips

* Make sure to fill out all required fields to ensure that the quiz can be created successfully.
* Use the options provided for the questions and correct answers carefully to avoid mistakes.
* You can adjust the scoring settings to suit your needs.
