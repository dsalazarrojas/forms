# Economics Unit Test Quiz - Help Guide
## Purpose
The Economics Unit Test Quiz is a form designed to assess students' knowledge of economics units by asking a series of questions on various topics within the field of economics.

## How To Complete This Form
To complete this form, follow these steps:

1. Start by reading the introduction page, which provides an overview of the quiz.
2. Select the correct answer for each question in the subsequent sections.
3. Make sure to select all applicable options for multiple-select questions.
4. Review your answers carefully before submitting the form.
5. Click the "Submit" button to submit your quiz.
