# Word Puzzle Quiz - Help Guide
## Purpose
The Word Puzzle Quiz form is designed to track and record information about word puzzle quizzes. It helps you collect data on participants' answers, points earned, and other relevant details. 

## How To Complete This Form
To complete the Word Puzzle Quiz form, follow these steps:

1. Start by filling out the first two fields: **First word** and **Second word**. Enter the words you are presenting to the participants.
2. Next, choose the correct **Correct order** by selecting one of the available options.
3. In the **Category** field, select the category to which the puzzle belongs.
4. For the scoring section, fill out the **Points possible**, **Points awarded**, and **Points possible max** fields to set the point values for the correct answers and maximum points possible.
5. Enter the **Date** and **Time** fields for each of the five available slots.
6. Finally, fill out the **Email** field to store the participant's email address (if required).

## Field-by-Field Explanation
* **First word** (`first_word`, `text`, required: false): Enter the first word of the puzzle.
* **Second word** (`second_word`, `text`, required: false): Enter the second word of the puzzle.
* **Correct order** (`correct_order`, `select_one`, required: false): Choose the correct order from the available options.
* **Category** (`category`, `select_one`, required: false): Select the category for the puzzle.
* **Points possible** (`points_possible`, `number`, required: false): Set the maximum points possible for the correct answer.
* **Points awarded** (`points_awarded`, `number`, required: false): Set the points awarded for the correct answer.
* **Points possible max** (`points_possible_max`, `number`, required: false): Set the maximum points possible for the puzzle.
* **Points awarded max** (`points_awarded_max`, `number`, required: false): Set the maximum points awarded for the puzzle.
* **Points given** (`points_given`, `number`, required: false): Set the points given to the participant.
* **Points earned** (`points_earned`, `number`, required: false): Set the points earned by the participant.
* **Points possible earned** (`points_possible_earned`, `number`, required: false): Set the points possible earned by the participant.
* **Total points** (`total_points`, `number`, required: false): Calculate the total points earned by the participant.
* **Points earned max** (`points_earned_max`, `number`, required: false): Set the maximum points earned by the participant.
* **Points earned max** (`points_earned_max`, `number`, required: false): Set the maximum points earned by the participant.
* **Date 1** (`date_1`, `date`, required: false): Enter the date for the first time slot.
* **Date 2** (`date_2`, `date`, required: false): Enter the date for the second time slot.
* **Date 3** (`date_3`, `date`, required: false): Enter the date for the third time slot.
* **Date 4** (`date_4`, `date`, required: false): Enter the date for the fourth time slot.
* **Date 5** (`date_5`, `date`, required: false): Enter the date for the fifth time slot.
* **Time 1** (`time_1`, `time`, required: false): Enter the time for the first time slot.
* **Time 2** (`time_2`, `time`, required: false): Enter the time for the second time slot.
* **Time 3** (`time_3`, `time`, required: false): Enter the time for the third time slot.
* **Time 4** (`time_4`, `time`, required: false): Enter the time for the fourth time slot.
* **Time 5** (`time_5`, `time`, required: false): Enter the time for the fifth time slot.
* **Email** (`email`, `email`, required: false): Enter the participant's email address.

Note: The required status of each field is indicated in the parentheses after the field label. Required fields must be filled out, while non-required fields can be left blank or filled out as needed.
