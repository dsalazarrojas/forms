# Punctuation Knowledge Quiz - Help Guide
## Purpose
This form is designed to assess the user's understanding of punctuation marks. It will cover various types of punctuation and their correct uses in sentences.

## How To Complete This Form
To complete this form, follow these steps:

1. Review each question carefully to ensure you understand what is being asked.
2. Select the correct punctuation mark for each question.
3. Make sure to choose all required answers to proceed to the next page.
4. Once you have answered all questions, submit the form to review your results.

## Field-by-Field Explanation
* **Commas** (`commas`, `select_multiple`, `true`): Choose the correct type of comma for the given sentence.
* **Periods** (`periods`, `select_one`, `true`): Select the correct punctuation mark used at the end of a sentence.
* **Parentheses** (`parentheses`, `select_multiple`, `false`): Select all correct types of parentheses.
* **Semicolons** (`semicolons`, `select_one`, `false`): Choose the correct semicolon usage.
* **Apostrophes** (`apostrophes`, `select_multiple`, `false`): Select the correct type of apostrophe.
* **Dashes** (`dashes`, `select_multiple`, `false`): Select the correct type of dash.
* **Quotes** (`quotes`, `select_multiple`, `false`): Choose the correct type of quotation mark.
* **Question marks** (`question_marks`, `select_one`, `true`): Select the correct punctuation mark used at the end of a question.
* **Exclamation marks** (`exclamation_marks`, `select_multiple`, `true`): Choose all correct types of exclamation marks.
* **Ellipsis** (`ellips`, `select_multiple`, `false`): Select the correct type of ellipsis.
* **Brackets** (`brackets`, `select_multiple`, `false`): Select the correct type of bracket.
* **Colons** (`colons`, `select_one`, `true`): Choose the correct semicolon usage.
* **Slashs** (`slashs`, `select_multiple`, `false`): Select the correct type of slash.
