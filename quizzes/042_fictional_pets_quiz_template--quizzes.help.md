# Fictional Pets Quiz Template - Help Guide
## Purpose
The "Fictional Pets Quiz Template" is a tool used to create quizzes about fictional pets. This template is designed to be a starting point for users to create their own quizzes with multiple questions and corresponding images.

## How To Complete This Form
To complete this form, follow these steps:
1. Fill out the Quiz Title field with the title of your quiz.
2. Select a category for your quiz from the dropdown menu.
3. Add questions to your quiz by filling out the Question 1, Question 2, Question 3, and Question 4 fields. Each question will have an associated image and can have multiple correct answers.
4. Fill out the answer fields for each question.

## Field-by-Field Explanation
### Quiz Title (1)
* **Quiz Title**: A text field where you can enter the title of your quiz.
  This is the title that will be displayed at the top of your quiz.

### Category (2)
* **Category**: A dropdown menu where you can select a category for your quiz.
  This will help organize your quiz into different categories.

### Question 1 (3)
* **Question 1**: A select multiple field where you can select multiple options for the question.
  This question will be part of your quiz, and users will have to select multiple correct answers.
* **Option 1** and **Option 2**: These are the possible answers for Question 1.
  You can select one or both of these options.

### Question 1 Image (4)
* **Question 1 Image**: A text field where you can enter an image associated with Question 1.
  This image will be displayed next to Question 1.

### Question 1 Answer (5)
