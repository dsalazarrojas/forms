# site_inspection_photography_quiz - Help Guide
## Purpose
The site inspection photography quiz helps assess whether a site inspection meets the necessary guidelines.

## How To Complete This Form
To complete the quiz, start by reading the form carefully. Begin by answering the introduction and team questions, then proceed to the photography, best practices, and submission fields.

## Field-by-Field Explanation
* **Introduction** (text, optional): A brief explanation about the form and its purpose.
* **Team** (select one, required): Please select whether a team is present during site inspection.
	+ Select 'Yes' if a team is present.
	+ Select 'No' if a team is not present.
* **Photography** (text, optional): Describe the site inspection photography.
* **Best Practices** (select multiple, required): Select the best practices that are followed during site inspection.
	+ Select 'Yes' for each best practice that is followed.
	+ Select 'No' for each best practice that is not followed.
* **Submission** (date, required): Enter the date and time of submission.
* **Email** (email, optional): Enter your email address for contact purposes.
* **Phone Number** (text, optional): Enter your phone number for contact purposes.
* **Location** (text, optional): Enter the location of the site inspection.
