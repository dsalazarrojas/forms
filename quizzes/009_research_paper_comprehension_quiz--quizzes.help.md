# Research Paper Comprehension Quiz - Help Guide
## Purpose
The Research Paper Comprehension Quiz is designed to evaluate individual or group understanding of a research paper. It can be used by students, instructors, or program coordinators to gauge comprehension, track progress, or facilitate peer review in academic settings.

## How To Complete This Form
To complete this form, follow these steps:

1. Read each question carefully and answer accordingly.
2. Select the correct response from the options provided.
3. Indicate whether you have read each chapter (research reading) or not.
4. Indicate which questions you can answer for each reading chapter (research reading).

## Field-by-Field Explanation
* **instructor_name** (Text, required): Enter the name of the instructor or educator responsible for the research paper.
* **program_coordinator** (Text, required): Enter the name of the program coordinator or administrator responsible for the research paper.
* **what_was_read1** (Select One, optional): Indicate if you have read Chapter 1 of the research paper.
* **reading1_question_1** (Select Multiple, optional): Select which questions you can answer based on Chapter 1.
* **what_was_read2** (Select One, optional): Indicate if you have read Chapter 2 of the research paper.
* **reading2_question_1** (Select Multiple, optional): Select which questions you can answer based on Chapter 2.
* **what_was_read3** (Select One, optional): Indicate if you have read Chapter 3 of the research paper.
* **reading3_question_1** (Select Multiple, optional): Select which questions you can answer based on Chapter 3.
* **what_was_read4** (Select One, optional): Indicate if you have read Chapter 4 of the research paper.
* **reading4_question_1** (Select Multiple, optional): Select which questions you can answer based on Chapter 4.

## Tips
* Make sure to answer each question based on your actual reading of the research paper.
* Select only the options that you can truthfully confirm.
* If you are unsure or have not read a chapter, select "No" for the respective question.
