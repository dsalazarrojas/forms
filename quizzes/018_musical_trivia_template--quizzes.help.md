# Musical Trivia Template - Help Guide
## Purpose
The Musical Trivia Template is a form designed to collect information about a musical trivia game or quiz. This form is used to create a customized musical trivia experience for players, allowing you to tailor the questions, answers, and scoring system to your specific needs.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the musical trivia question and answer fields (fields 2 and 3) to create the trivia content.
2. Enter the score for each question in the score field (field 4).
3. Choose how to connect to SoundCloud (fields 5-10) to enable features such as sound file upload and API integration. For field 6, type in the SoundCloud connection details if applicable.
4. If you want to customize the form for your specific use case, use field 11, "Musical Trivia Customization".

## Field-by-Field Explanation

* **Musical Trivia Form** (`musical_trivia_form`, text, optional): This is the main title of the form.
* **Musical Trivia Question** (`musical_trivia_question`, text, optional): Enter the question you want to ask players.
* **Musical Trivia Answer** (`musical_trivia_answer`, text, optional): Enter the correct answer to the question.
* **Musical Trivia Score** (`musical_trivia_score`, number, optional): Enter the score for this question.
* **Musical Trivia SoundCloud** (`musical_trivia_soundcloud`, select_one, optional): Choose whether to enable sound file upload from SoundCloud.
* **Connect to SoundCloud** (`musical_trivia_connect_to_soundcloud`, text, optional): If you choose to connect to SoundCloud, type in your SoundCloud credentials.
* **Musical Trivia Customizable** (`musical_trivia_customizable`, text, optional): Enter any additional customization details for the form.
* **Connect to SoundCloud API** (`musical_trivia_connect_to_soundcloud_api`, text, optional): If you want to enable API integration with SoundCloud, type in your API credentials.
* **Musical Trivia Customization** (`musical_trivia_customization`, text, optional): Enter any additional customization details for the form.
* **No Coding** (`musical_trivia_no_coding`, text, optional): This field is not intended for end-users to interact with; it seems to be a field for internal use. Please disregard this field.
