# Cross Country Running Quiz - Help Guide

## Purpose

The Cross Country Running Quiz is a tool to gather information about cross-country running events. It is used to collect data on various aspects of running, such as course details, team information, and participant experiences.

## How To Complete This Form

1. Fill out each field accurately and thoroughly.
2. Ensure that you have answered all required fields.
3. Review your answers before submitting the form.

## Field-by-Field Explanation

* **Quiz Questions**: This field is for the actual quiz questions that will be asked.
* **race_distance** (`race_distance`, number, required: false): Enter the distance of the race.
* **finish_time** (`finish_time`, select_one, required: false): Select the finish time from the options provided.
* **water_stations** (`water_stations`, select_multiple, required: false): Select all applicable water stations.
* **course_map** (`course_map`, text, required: false): Enter the course map details.
* **race_type** (`race_type`, text, required: false): Enter the type of race (e.g., trail, road, etc.).
* **team_size** (`team_size`, text, required: false): Enter the size of the team.
* **course_length** (`course_length`, text, required: false): Enter the length of the course.
* **course_type** (`course_type`, select_one, required: false): Select the type of course (Trail, Track, Road, Mountain).
* **race_weather** (`race_weather`, select_multiple, required: false): Select all applicable weather conditions.
* **finish_line** (`finish_line`, select_one, required: false): Select the finish line from the options provided.
* **water_stop_location** (`water_stop_location`, select_multiple, required: false): Select all applicable water stop locations.
* **race_surface** (`race_surface`, select_one, required: false): Select the surface of the race (Trail, Track, Road, Mountain).
* **water_stop_frequency** (`water_stop_frequency`, select_one, required: false): Select the frequency of water stops.
* **team_member** (`team_member`, text, required: false): Enter team member information.
* **course_slope** (`course_slope`, text, required: false): Enter course slope details.
* **team_size_range** (`team_size_range`, text, required: false): Enter team size range.
* **team_age** (`team_age`, text, required: false): Enter team age.
* **team_gender** (`team_gender`, text, required: false): Enter team gender.
* **team_level** (`team_level`, select_one, required: false): Select the level of the team (High School, College, University).
* **course_elevation_gain** (`course_elevation_gain`, number, required: false): Enter the elevation gain of the course.
* **race_elevation_loss** (`race_elevation_loss`, number, required: false): Enter the elevation loss of the race.
* **team_name** (`team_name`, text, required: false): Enter the name of the team.
* **course_climate** (`course_climate`, text, required: false): Enter course climate details.
* **course_surface** (`course_surface`, text, required: false): Enter course surface details.

Note: All fields are optional, unless otherwise specified as required fields. Please ensure you fill out all required fields before submitting the form.
