# MakeCodeArcadeQuiz - Help Guide
## Purpose
This form is designed to help you create a MakeCodeArcadeQuiz, which is a quiz that consists of several questions and answers. The form is divided into pages, each with two questions and two answer fields.

## How To Complete This Form
To complete this form, follow these steps:

1. Start by filling out the introduction page, which explains the purpose and scope of the quiz.
2. Proceed to the questions pages, where you will be asked two questions at a time. Each question has 2 options: "Yes" and "No".
3. Answer each question by selecting one of the options.
4. After answering all questions, proceed to the answer pages, where you will be asked to provide a brief answer to each question.
5. Fill out each answer field with your answer.
6. Finally, click the "Submit" button to create your MakeCodeArcadeQuiz.

## Field-by-Field Explanation

* **Introduction**: This is the first page of the form, where you will be introduced to the purpose and scope of the quiz.
* **Questions 1-10**: Each question page has 2 questions with 2 options: "Yes" and "No". Select one of the options for each question.
* **Answer 1-12**: Each answer page has 2 answer fields for the answers to the previous questions. Fill out each answer field with a brief answer.
* **Submit**: This is the final step to create your MakeCodeArcadeQuiz.
* **Answer 11**: This answer field is not required and can be left blank.
* **Answer 12**: This answer field is not required and can be left blank.
