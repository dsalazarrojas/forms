# External Links Access Quiz - Help Guide
## Purpose
The External Links Access Quiz is a form used to evaluate the safety and relevance of external links. This form helps users quickly determine if a link is safe to access and what type of link it is.

## How To Complete This Form
To complete this form, follow these steps:

1. Read each question carefully and answer accordingly.
2. Select the correct answer for each question from the provided options.
3. Fill in any required information, such as link URL and description.
4. Submit the form once you have completed all the questions.

## Field-by-Field Explanation

* **links_type** (`links_type`, select_one, required): This field determines the type of link you are accessing. Select "safe link" if the link is safe to access.
* **link_url** (`link_url`, text, required): Enter the URL of the link you want to access.
* **link_description** (`link_description`, text, required): Provide a brief description of the link you want to access.
* **link_tags** (`link_tags`, select_multiple, required): Select the categories that best describe the link.
* **link_source** (`link_source`, select_one, required): Indicate whether the link is from an internal or external source.
* **link_target** (`link_target`, text, required): Enter the target ID of the link.
* **link_destination** (`link_destination`, text, required): Enter the destination ID of the link.
* **link_type** (`link_type`, select_one, required): Determine the type of link you are accessing (e.g., direct or embedded).
* **link_target_id** (`link_target_id`, text, required): Enter the target ID of the link.
* **link_destination_id** (`link_destination_id`, text, required): Enter the destination ID of the link.
* **correct_answer** (`correct_answer`, select_one, optional): Select the correct answer from the provided options. If unsure, you can submit without selecting an answer.
* **correct_answer_hint** (`correct_answer_hint`, note, optional): Provide any additional hints or comments about the correct answer, if needed.

## Tips
- Be honest and accurate when answering each question.
- If you are unsure about a link, it's better to err on the side of caution and choose "unsafe link" or do not access the link.
- Remember to submit the form once you have completed all the questions.
