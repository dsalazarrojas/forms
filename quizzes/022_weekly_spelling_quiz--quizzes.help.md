# weekly_spelling_quiz - Help Guide
## Purpose
The weekly_spelling_quiz form is a tool for teachers to create and collect data on students' weekly spelling progress. This data is used to track students' scores, grades, and other relevant details.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the required fields: Last Name, Email, School Name, Class, Quiz Type, and Score.
2. Leave the optional fields: First Name, Grade, Date, and Time blank if they are not applicable.
3. Select the relevant Class options for the student.
4. Choose the correct Quiz Type from the options.
5. Enter the student's score.
6. Add any comments or notes about the student.

## Field-by-Field Explanation
* **First Name** (`first_name`, `text`, optional): Enter the student's first name.
* **Last Name** (`last_name`, `text`, required): Enter the student's last name.
* **Email** (`email`, `email`, required): Enter the student's email address.
* **School Name** (`school_name`, `text`, required): Enter the school's name.
* **Class** (`class_name`, `select_multiple`, required): Select all applicable classes for the student.
* **Grade** (`grade`, `number`, optional): Enter the student's current grade level.
* **Quiz Type** (`quiz_type`, `select_one`, required): Choose the type of quiz (e.g. 1, 2, 3, 4, 5, or 6).
* **Date** (`date`, `date`, optional): Enter the date of the quiz.
* **Time** (`time`, `time`, optional): Enter the time of the quiz.
* **Score** (`score`, `number`, required): Enter the student's score.
* **Comments** (`comments`, `note`, optional): Add any notes or comments about the student.

## Tips
* Make sure to fill in all required fields.
* Use the class options to select all relevant classes for the student.
* If you are not sure about the Quiz Type, refer to the school's grading system for guidance.
* Use the score field to enter the student's score out of the maximum possible points.
* Use the comments field to add any additional notes or comments about the student.
