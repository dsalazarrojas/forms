# Spelling Quiz - Help Guide
## Purpose
This form is a quiz designed to test your spelling skills, where you are asked to spell a series of randomly generated words.

## How To Complete This Form
1. Select the grade level that applies to you (if you want to specify it).
2. Input the correct spelling for each of the 20 words listed below.
3. Click on the "Submit" button once you have completed all the words.

## Field-by-Field Explanation

* **Grade Level** (`Grade Level`, select_one): This field allows you to specify your grade level for the sake of tracking the quiz results. You can select from the options 1, 2, 3.
* **List of Words** (`List of Words`, text): This is not a field you need to interact with, it's just a label for the following list of words.
* **Word 1** (`Word 1`, text): Input the correct spelling of the first word.
* **Word 2** (`Word 2`, text): Input the correct spelling of the second word.
* **Word 3** (`Word 3`, text): Input the correct spelling of the third word.
* ...
* **Word 20** (`Word 20`, text): Input the correct spelling of the twentieth word.
* **Submit** (`Submit`, text): Click this button once you have completed all the words to submit your answers.
