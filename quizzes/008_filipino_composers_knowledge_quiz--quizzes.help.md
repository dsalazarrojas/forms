# filipino_composers_knowledge_quiz - Help Guide
## Purpose
This form is designed to collect information about Filipino composers and their work.

## How To Complete This Form
To complete this form, please follow the steps above.

## Field-by-Field Explanation
* **composer**: Enter the name of a Filipino composer you are familiar with.
* **era**: Select the century in which the composer lived (19th, 20th, or 21st).
* **instrument**: Choose the instruments associated with the composer (guitar, keyboard, violin).
* **genre**: Select the genres of music associated with the composer (classical, folk, pop).
* **score**: Indicate the score of the composer's work (high, low, medium, not sure).
* **year**: Enter the year of the composer's birth and death, if applicable.
* **composer bio**: Enter a brief description of the composer's bio.
* **music piece**: Enter a brief description of a notable music piece composed by the composer.
* **quiz type**: Select the type of quiz (e.g. multiple choice, fill-in-the-blank, etc.).

## Tips
* Please answer the questions truthfully and accurately.
* Make sure to select the correct century for the composer's era.
* If unsure of any information, please answer with "not sure".
