# Agent Multiple Choice Quiz - Help Guide
## Purpose
This form is designed to help evaluate an agent's knowledge and understanding of standard agency practices and procedures.

## How To Complete This Form
To complete this form, follow these steps:
1. Enter your Participant name: This is the name of the person taking the quiz.
2. Enter your Email: This is the email address where you'll receive your quiz results.
3. Answer the questions: Choose the best response for each question from the available options.
4. Confirm your passing score: Select the correct option to indicate you understand the passing criteria.
5. Provide feedback: If you'd like to suggest any improvements or changes to the quiz, please include them in the text field.
6. Save the form: Click the submit button to save your answers and completion date.

## Field-by-Field Explanation
- **Participant name** (`participant_name`, Text, Required): Enter your name as it appears on your ID badge.
- **Email** (`email`, Email, Optional): Enter a valid email address where you'll receive your quiz results.
- **What is the standard agency disclosure practice?** (`question_1`, Select One, Required): Choose the option that best describes the standard agency disclosure practice.
	+ Select "Disclose to all parties" to indicate that information is shared with all involved parties.
	+ Select "Disclose only when asked" if information is shared only when explicitly asked.
	+ Select "Never disclose" to indicate that information is shared only under exceptional circumstances.
	+ Select "Disclose only orally" to indicate that information is shared through personal communication.
- **Which action demonstrates active listening?** (`question_2`, Select One, Required): Choose the option that best describes an action demonstrating active listening.
	+ Select "Repeating concerns" to indicate repeating back what you've heard.
	+ Select "Interrupting" to indicate interrupting the speaker.
	+ Select "Ignoring nonverbal cues" to indicate ignoring nonverbal communication.
	+ Select "Changing the subject" to move away from the topic.
- **Best practice for handling confidential data?** (`question_3`, Select One, Required): Choose the option that best describes the best practice for handling confidential data.
	+ Select "Encrypt and limit access" to indicate encrypted and restricted access.
	+ Select "Share widely" to indicate sharing widely without restrictions.
	+ Select "Store on public drive" to indicate storing on an unsecured drive.
	+ Select "No special handling" to indicate no special precautions taken.
- **When should you escalate an issue?** (`question_4`, Select One, Required): Choose the option that best describes when you should escalate an issue.
	+ Select "Immediate danger" to indicate immediate action is required.
	+ Select "Minor preference" to indicate a minor issue that doesn't require escalation.
	+ Select "Personal disagreement" to indicate a disagreement that requires escalation.
	+ Select "After a year" to indicate no escalation is required.
- **I understand the passing score requirement** (`passing_score_acknowledgment`, Select One, Required): Select "Acknowledged" to confirm you understand the passing criteria.
- **Feedback on the quiz** (`feedback`, Text, Optional): Provide any suggestions or comments about the quiz.
- **Submit date** (`submit_date`, Date, Required): Enter the date you completed the quiz.
