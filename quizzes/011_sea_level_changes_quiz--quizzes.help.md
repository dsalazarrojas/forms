# Sea Level Changes Quiz - Help Guide
## Purpose
This guide provides step-by-step instructions on how to complete the Sea Level Changes Quiz form.

## How To Complete This Form
To complete this form, follow these steps:

1. Review each question carefully and answer them to the best of your ability.
2. For questions 2-4, select all that apply from the available options.
3. Enter your email address and phone number in the required fields.
4. Enter your name in the provided text field.
5. Add any additional comments or notes if you have further information to share.
