# Planned Giving Quiz - Help Guide
## Purpose
This guide will walk you through the Planned Giving Quiz form to help you understand the purpose and questions asked in each field.

## How To Complete This Form
To complete the form, simply follow the instructions below.

1. Review the questions carefully and answer each question to the best of your ability.
2. Use the options provided to select your responses.
3. If you need more space to provide information, feel free to use the "other" field provided at the end of each question.

## Field-by-Field Explanation

* **planned_giving_interest (1)**: This question asks if you have an interest in planned giving. Please select either "Yes" or "No".
* **planned_giving_gift_amount (2)**: This question asks about the amount you are interested in gifting. Please enter a numerical value.
* **planned_giving_gift_type (3)**: This question asks about the type of gift you are interested in making. Please select from the options: Cash, Stock, Real Estate, Charitable Remainder Trust, Pooled Income Unit (PIU).
* **planned_giving_gift_ownership (4)**: This question asks who the gift will benefit. Please select all that apply from the options: Benefiting Family Member, Benefiting Organization or Institution, Benefiting Other.
* **planned_giving_why (5)**: This is a text field for you to provide more information about your planned giving reasons. Please use this space to provide additional details.
* **planned_giving_future_planned_giving (6)**: This question asks if you are interested in making future planned gifts. Please select either "Yes" or "No".
* **planned_giving_future_planned_giving_reason (7)**: This question asks about your reasons for interested in future planned giving. Please enter your response.
* **planned_giving_preferred_method (8)**: This question asks about your preferred method of giving. Please select from the options: Online, In Person, Mail.
* **planned_giving_current_planned_giving_plan (9)**: This question asks if you already have a planned giving plan in place. Please select either "Yes" or "No".
* **planned_giving_why_current_planned_giving_plan (10)**: This question asks about your reasons for having a planned giving plan in place. Please enter your response.
* **planned_giving_awareness (11)**: This question asks about your awareness of different planned giving options. Please select all that apply from the options: Donor-Advised Fund, Trusts and Foundations, Will or Trust, Life Insurance, Other.
* **planned_giving_charitable_remainder_interest (12)**: This is a text field for you to provide more information about charitable remainder interest. Please use this space to provide additional details.
* **planned_giving_charitable_remainder_interest_type (13)**: This question asks if you are interested in charitable remainder interest. Please select "Yes" or "No".
* **planned_giving_other (14)**: This is a text field for you to provide more information about your planned giving preferences. Please use this space to provide additional details.
* **planned_giving_other_details (15)**: This question asks if there is any other information you would like to share with us. Please specify in this field.
* **planned_giving_acknowledge (16)**: This question asks if you are aware of our policies regarding acknowledgments. Please select either "Yes" or "No".
* **planned_giving_acknowledge_other (17)**: This question asks if there is any other acknowledgment to provide. Please enter your response.
* **planned_giving_acknowledge_details (18)**: This question asks about any other details regarding acknowledgments. Please provide your response.
* **planned_giving_other_comments (19)**: This question asks for any additional comments you would like to provide. Please use this space to provide additional comments.
* **planned_giving_other_comments_other (20)**: This question asks for any other comments you would like to provide. Please enter your response.
* **planned_giving_other_comments_other_details (21)**: This question asks for any other details regarding comments. Please provide your response.
* **planned_giving_acknowledge_comments (22)**: This question asks for any additional comments regarding acknowledgments. Please provide your response.
* **planned_giving_acknowledge_comments_other (23)**: This question asks for any other comments regarding acknowledgments. Please enter your response.
* **planned_giving_acknowledge_comments_other_details (24)**: This question asks for any other details regarding comments. Please provide your response.
* **planned_giving_other_comments_details (25)**: This question asks for any additional comments regarding other information. Please provide your response.

I hope this guide helps you complete the Planned Giving Quiz form with confidence. If you have any questions or concerns, please don't hesitate to contact us.
