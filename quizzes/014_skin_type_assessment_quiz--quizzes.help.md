# Skin Type Assessment Quiz - Help Guide
## Purpose
The Skin Type Assessment Quiz is a form designed to help users determine their skin type and potentially identify products that may be suitable for their skin. This quiz is intended to be a helpful resource for users interested in improving their skin health.

## How To Complete This Form
To complete this form, follow these steps:

1. Review each field carefully and ensure you have the most accurate information to provide.
2. Select all applicable options for each field, or choose "Rarely" or "Maybe" if applicable.
3. If you select "Maybe" for any question, please provide further explanation or details in the "skin_concerns" field.
4. When finished, submit the form to receive your results.

## Field-by-Field Explanation
- **Skin Type** (`id: 2`):
	* Select all types that apply to your skin:
		+ Acne-prone
		+ Oily
		+ Dry
		+ Combination
		+ Normal
- **Concerns** (`id: 3`):
	* If you selected "Maybe" for any skin type above, describe your specific skin concerns here.
- **Age** (`id: 4`):
	* Enter your age to help us better understand your skin's maturity level.
- **Skincare Product Use** (`id: 5`):
	* Indicate how often you use skincare products:
		+ Rarely
		+ True (often)
- **Follow-up Appointments** (`id: 6`):
	* Select if you plan to schedule follow-up appointments for your skin:
		+ True
		+ False
		+ Maybe
- **Skin Type Awareness** (`id: 7`):
	* Assess your level of skin type awareness:
		+ High
		+ Medium
		+ Low
- **Skin Concerns** (`id: 8`):
	* If you have specific skin concerns, describe them here.
- **Recommended Products** (`id: 9`):
	* If you're interested in product recommendations, describe your skin type and concerns here.

## Tips
- Be as accurate as possible when filling out the form.
- If you have any specific skin concerns or questions, feel free to provide them in the "skin_concerns" field.
- This form is not a substitute for professional skin consultation or diagnosis. If you have serious skin concerns, please consult a dermatologist or skincare professional.
