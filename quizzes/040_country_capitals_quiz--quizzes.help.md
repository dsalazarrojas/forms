# Country Capitals Quiz - Help Guide
## Purpose
The Country Capitals Quiz form is designed to collect user input for a country capitals quiz. This form will display a series of questions and allow users to input their answers.

## How To Complete This Form
1. Review the form questions and answers carefully to ensure you have the correct information.
2. Select the correct answer option for each question.
3. If a question provides an option for additional information, use this field to provide the answer.
4. Review your input before submitting the form.

## Field-by-Field Explanation
* **first_question** (text, optional): This is the first question of the quiz. Please answer this question to the best of your ability.
* **answer** (text, optional): This field is used to input your answer to the first question. Please provide a clear and concise answer.
* **hint** (note, optional): This field is used to provide additional information about the first question. If you need more context, use this field to provide any relevant details.
* **first_question_hint** (text, optional): This field is used to provide additional information about the first question. If you need more context, use this field to provide any relevant details.
* **quiz_type** (select_one, optional): This field allows you to select the type of quiz you are attempting. Please choose the correct option from the provided options.
* **options** (select_multiple, optional): This field allows you to select the options for the first question. Please choose the correct options from the provided list.

## Tips
* Make sure to complete each field carefully and thoroughly.
* If you are unsure about a field, refer to the field-by-field explanation above.
* Review your input before submitting the form to ensure accuracy.
