# Poetic Devices Knowledge Quiz - Help Guide
## Purpose
This form is designed to test your knowledge of poetic devices, which are literary elements used by poets to convey meaning and create a specific effect.

## How To Complete This Form
To complete this form, simply follow the instructions below:

1. Answer each question in the space provided.
2. Select all that apply for multiple-choice questions.
3. If you have any additional information to provide, type it in the corresponding field.
4. Submit the form once you have completed all the questions.

## Field-by-Field Explanation

* **Poetic Devices 1** (`poetic_devices_1`, select_one, required): This question asks you to confirm your knowledge of poetic devices. Select "Yes" if you are familiar with the concept, or "No" if you are not.
* **Poetic Devices 2** (`poetic_devices_2`, select_multiple, required): Choose all the poetic devices you are familiar with.
* **Poetic Devices 3** (`poetic_devices_3`, select_multiple, required): Select all the poetic devices you are familiar with.
* **Poetic Devices 4** (`poetic_devices_4`, select_one, required): Choose the poetic device you are most familiar with.
* **Poetic Devices 5** (`poetic_devices_5`, select_one, required): This question asks you to select the poetic device you are most familiar with.
* **Additional Information** (`poetic_devices_5`, note, required): Provide a sentence describing the poetic devices you are using (if any).
* **Form End** (`form_end`, note, required): This is the final section of the form. Please do not forget to submit the form once you have completed all the previous questions.

## Tips

* Please answer each question honestly.
* If you need help or clarification on any question, do not hesitate to ask.
* If you are unsure about any question, it's okay to ask for clarification.
* This form is intended for internal use only, so please do not submit it if you are not familiar with the basics of poetry.
