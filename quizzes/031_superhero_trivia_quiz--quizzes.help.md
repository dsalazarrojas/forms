# Superhero Trivia Quiz - Help Guide
## Purpose
This form is designed to collect information about a Superhero Trivia Quiz event. You can use this form to create a new quiz event, specify its details, and save them for future reference.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the Superhero Trivia Quiz title.
2. Choose the Superhero Category.
3. Enter a description of the quiz event.
4. Select the participants.
5. Choose the start and end time of the quiz event using the date format (YYYY-MM-DD).
6. Enter the location of the quiz event.
7. Specify if the quiz event has an organizer.
8. Enter any additional notes about the quiz event.
9. Enter the venue of the quiz event.
10. Enter the phone number of the quiz event.
11. Enter the email of the quiz event.

## Field-by-Field Explanation

* **Superhero Trivia Quiz title** (text, required: false): Enter a title for the Superhero Trivia Quiz event. This will be displayed on the event's title bar.
* **Superhero Category** (select_one, required: false): Choose the category of the Superhero Trivia Quiz event from the options provided.
* **Superhero Trivia Quiz description** (text, required: false): Enter a brief description of the quiz event. This can include details such as what to expect during the event.
* **Participants** (select_multiple, required: false): Select who will be participating in the quiz event.
* **Superhero Trivia Quiz start time** (date, required: false): Choose the start date of the quiz event using the date format (YYYY-MM-DD).
* **Superhero Trivia Quiz end time** (date, required: false): Choose the end date of the quiz event using the date format (YYYY-MM-DD).
* **Superhero Trivia Quiz location** (text, required: false): Enter the location of the quiz event.
* **Superhero Trivia Quiz organizer** (select_one, required: false): Specify if the quiz event has an organizer.
* **Superhero Trivia Quiz notes** (note, required: false): Enter any additional notes about the quiz event.
* **Superhero Trivia Quiz venue** (text, required: false): Enter the venue of the quiz event.
* **Superhero Trivia Quiz phone** (text, required: false): Enter the phone number of the quiz event.
* **Superhero Trivia Quiz email** (email, required: false): Enter the email of the quiz event.
