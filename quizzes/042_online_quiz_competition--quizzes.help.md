# Online Quiz Competition - Help Guide

## Purpose
This form is used to collect data on an online quiz competition, gathering information on participants, their scores, and other relevant details.

## How To Complete This Form

To complete the form, follow these steps:

1. Review the form fields below and ensure you have all the required information.
2. Fill in each field with the requested information.
3. Submit the form once you have completed all the required fields.

## Field-by-Field Explanation

* **Questions** (`id: 1`): Select all the questions that apply to the participant. This field is a multiple-choice select field.
* **Participant Name** (`id: 2`): Enter the name of the participant.
* **Participant Score** (`id: 3`): Enter the participant's score.
* **Time** (`id: 4`): Select the time period relevant to the participant.
* **Note** (`id: 5`): Enter any additional notes or comments about the participant.
* **Email** (`id: 6`): Enter the participant's email address.
* **Participant ID** (`id: 7`): Enter the participant's ID number.
* **Category** (`id: 8`): Select one category that the participant belongs to. This field is a single select field.
* **Sub Category** (`id: 9`): Select all the subcategories that apply to the participant. This field is a multiple-select field.
* **Prize Money** (`id: 10`): Enter the prize money won by the participant.
* **Participant Count** (`id: 11`): Enter the total number of participants.
* **Questions Count** (`id: 12`): Enter the total number of questions.
* **Winner** (`id: 13`): Select if the participant is the winner of the competition. This field is a single-select field.
* **Winner Image** (`id: 14`): Select if a winner image is associated with the participant.
* **Prize Image** (`id: 15`): Select if a prize image is associated with the participant.
* **Winner Message** (`id: 16`): Enter a message for the winner.
* **Questions 2** (`id: 17`): Enter any additional questions or comments.
* **Winner Name** (`id: 18`): Enter the name of the winner.
* **Participant Name 2** (`id: 19`): Enter the name of the participant (if different from the first participant name).
* **Winner Score** (`id: 20`): Enter the winner's score.

## Tips
