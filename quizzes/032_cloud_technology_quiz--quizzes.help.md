# Cloud Technology Quiz - Help Guide
## Purpose
This form is designed to test the knowledge of cloud computing concepts among users.

## How To Complete This Form
1. Please fill out the form completely and honestly, answering each question to the best of your ability.
2. For each question, select the option that you believe is the correct answer.
3. Make sure to read each question carefully, as some options may have subtle differences.
4. Once you have completed the form, click the "Submit" button to review your answers.

## Field-by-Field Explanation

* **-- Cloud Technology Knowledge Quiz --** (`section_intro`, note, required: false): This is the introduction to the quiz. It is not a question that requires an answer.
* **Your Name** (`student_name`, text, required: true): Please enter your name as it appears on your official identification.
* **Quiz Date** (`quiz_date`, date, required: true): Please enter the date you are taking the quiz.
* **-- Questions --** (`section_questions`, note, required: false): This is the section header for the questions that follow.
* **What does cloud computing primarily provide?** (`q1`, select_one, required: true): Cloud computing primarily provides on-demand computing resources over the internet.
* **Which of the following is an advantage of cloud computing?** (`q2`, select_one, required: true): An advantage of cloud computing is its scalability and flexibility.
* **Cloud computing reduces the need for** (`q3`, select_one, required: true): Cloud computing reduces the need for on-premises infrastructure and IT staff.
* **A hybrid cloud environment combines** (`q4`, select_one, required: true): A hybrid cloud environment combines public and private cloud resources.
* **What is a key difference between cloud and traditional IT?** (`q5`, select_one, required: true): A key difference between cloud and traditional IT is pay-per-use vs. capital expenditure.
* **Serverless computing means** (`q6`, select_one, required: true): Serverless computing means there are no servers.
* **Cloud storage differs from traditional storage because** (`q7`, select_one, required: true): Cloud storage differs from traditional storage because it is accessed via the internet.
* **Bandwidth in cloud computing refers to** (`q8`, select_one, required: true): Bandwidth in cloud computing refers to data transfer speed over the network.
* **What is a CDN - Content Delivery Network?** (`q9`, select_one, required: true): A CDN is a network for distributing content to users closer geographically.
* **Cloud availability refers to** (`q10`, select_one, required: true): Cloud availability refers to how long systems are operational and accessible.
* **Load balancing in cloud systems helps** (`q11`, select_one, required: true): Load balancing in cloud systems helps to distribute traffic and prevent server overload.
* **Latency in cloud computing is** (`q12`, select_one, required: true): Latency in cloud computing is the time delay in data transmission.
* **-- Quiz Complete --** (`section_results`, note, required: false): This is the end of the quiz.
* **How confident do you feel about your cloud knowledge?** (`confidence_level`, select_one, required: false): This question is optional and is intended to gauge your confidence level in your knowledge.
* **Additional comments or questions** (`additional_comments`, text, required: false): This is a field for any additional comments or questions you may have.
