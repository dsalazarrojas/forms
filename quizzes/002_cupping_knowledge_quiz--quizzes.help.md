# Cupping Knowledge Quiz - Help Guide
## Purpose
This guide will walk you through the steps to complete the "Cupping Knowledge Quiz" form.

## How To Complete This Form
1. Review each question carefully, as they are designed to assess your understanding of cupping treatments.
2. Answer the "what_is_cupping_treatment" question in the text area provided.
3. Select the correct frequency of cupping treatments from the options provided in "cupping_treatment_frequency".
4. For "cupping_knowledge_1" to "cupping_knowledge_20", type your answers to the questions in the text area provided.

## Field-by-Field Explanation
* **What is cupping treatment?** (`what_is_cupping_treatment`, `text`, required): This question is asking for a brief description of what cupping treatment is.
* **Cupping treatment goals** (`cupping_treatment_goals`, `select_one`, required/optional): Choose one of the provided options for what cupping treatment aims to achieve.
* **How often can treatments be given?** (`cupping_treatment_frequency`, `select_multiple`, required/optional): Select one or more of the provided options for the frequency of cupping treatments.
* **How long do treatments last?** (`cupping_treatment_frequency_2`, `time`, required/optional): This field is likely used to input duration of cupping treatments, but no specific instructions on format are provided. Please input in a format you are comfortable with (e.g., hours, minutes, etc.).
* **Cupping knowledge questions 1-20** (`cupping_knowledge_1` to `cupping_knowledge_21`, `text`, required/optional): These fields are for answering questions related to cupping knowledge. Please type your answers in the provided text area.
