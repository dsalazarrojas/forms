# video_quiz - Help Guide
## Purpose
The video_quiz form is used to create or manage video quiz content.

## How To Complete This Form
1. Fill out the form title field with a descriptive title for the video quiz.
2. Provide a description for the video quiz.
3. Select the category of the video quiz (e.g., "Quizzes" or "Personal Trainer Forms").
4. Enter the URL of the video to be used for the quiz.
5. Choose how the video will be embedded (e.g., None, Embedded, Embedded with controls).
6. Set the start and end times for the video quiz.
7. Decide if the video quiz will repeat (Never, Once, Multiple).
8. Enter any additional information for sharing the video quiz.

## Field-by-Field Explanation
### 1. video_quiz_title (text, required: false)
* The form title field is where you can enter a descriptive title for the video quiz.

### 2. video_quiz_description (text, required: false)
* The form description field is where you can enter a description for the video quiz.

### 3. video_quiz_category (select_one, options: Quizzes, Personal Trainer Forms, required: false)
* The category field is used to select the type of video quiz (e.g., "Quizzes" or "Personal Trainer Forms").

### 4. video_quiz_url (text, required: false)
* The video URL field is where you can enter the URL of the video to be used for the quiz.

### 5. video_quiz_embed (select_multiple, required: true, options: None, Embedded, Embedded with controls)
* The video embed field is used to choose how the video will be embedded (e.g., None, Embedded, Embedded with controls).

### 6. video_quiz_start_time (date, required: false)
* The start time field is where you can enter the start time of the video quiz.

### 7. video_quiz_end_time (date, required: false)
* The end time field is where you can enter the end time of the video quiz.

### 8. video_quiz_repeat (select_one, options: Never, Once, Multiple, required: false)
* The repeat field is used to decide if the video quiz will repeat (e.g., Never, Once, Multiple).

### 9. video_quiz_share (text, required: false)
* The share field is where you can enter any additional information for sharing the video quiz.
