# European Monetary System Quiz - Help Guide
## Purpose
This form is designed to help users create a quiz related to the European Monetary System (EMS). The quiz will cover the EMS framework and its applications.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the required information:
	* **participant_info**: Enter a brief description of the participant or the organization creating the quiz.
	* **participant_details**: Provide more details about the participant or organization, if necessary.
	* **email**: Enter a valid email address for communication.
	* **phone**: Enter a valid phone number for communication.
2. Define the quiz:
	* **question_type**: Choose the type of question you want to ask (A, B, C, or D).

3. Add options and answer:
	* **option_a**, **option_b**, **option_c**: Enter the options for the question.
	* **question_answer**: Enter the correct answer to the question.
4. Review and submit the form.
