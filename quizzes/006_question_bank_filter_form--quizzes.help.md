# Question Bank Filter Form - Help Guide
## Purpose
The Question Bank Filter Form is designed to allow users to filter question banks based on various criteria such as subject, grade level, instructional needs, and more.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the subject area that you would like to focus on.
2. Choose the grade level of the students you are creating the quiz for.
3. Decide if the questions should be for students with specific instructional needs (e.g., English language learners, math problems, etc.).
4. Select the subject areas you would like the questions to cover.
5. Choose any additional tags that you would like to include or exclude.
6. Enter the ID of the question bank you would like to filter.
7. Enter the ID of the quiz you would like to filter by.
8. Select how you would like to sort the results (by subject, grade level, or instructional needs).

## Field-by-Field Explanation
* **Subject**: 
  * Select the subject area that you would like to focus on. This can include options like "English", "Math", "Science", etc.
  * Options: "Yes" and "No"
* **Grade Level**: 
  * Choose the grade level of the students you are creating the quiz for. This can range from "High" to "Low".
  * Options: "High", "Low"
* **Instructional Needs**: 
  * Decide if the questions should be for students with specific instructional needs. This can include "Yes" or "No" for students with needs like "English language learners" or "math problems".
  * Options: "Yes", "No"
* **Subject Areas**: 
  * Select the subject areas you would like the questions to cover. This can include multiple options such as "English", "Math", "Science" etc.
  * Options: "Yes", "No"
* **Tags**: 
  * Choose any additional tags that you would like to include or exclude.
  * Options: "Yes", "No"
