# Dinosaurs Quiz - Help Guide
## Purpose
This form is designed to be a quiz that tests your knowledge about different types of dinosaurs.

## How To Complete This Form
To complete this form, follow these steps:

1. Answer the questions in the form fields.
2. Make sure to fill out all required fields.

## Field-by-Field Explanation
* **What is a T-Rex?** (text, required): Answer this question with a brief description or answer in a few words.
* **T-Rex Size** (number, optional): If you know the size of the T-Rex, please enter it here. Please note that this field is optional.
* **When did the T-Rex exist?** (date, optional): If you know when the T-Rex existed, please enter the date in the format YYYY-MM-DD. Please note that this field is optional.
* **Favorite Dinosaur** (select, optional): Choose your favorite dinosaur from the list.
* **Email Input** (email, optional): If you want to share your email with us, please enter it here. Please note that this field is optional.
* **Phone Number** (text, optional): If you want to share your phone number with us, please enter it here. Please note that this field is optional.
* **Note** (note, optional): Write any additional information you want to share with us.
* **Time** (time, optional): If you want to share your time with us, please enter it in the format 24-hour time format (HH:MM).
* **Select Multiple** (select multiple, optional): Choose multiple dinosaurs from the list.
* **Select One** (select one, optional): Choose one dinosaur from the list.
* **Select One** (select one, optional): Choose one dinosaur from the list.
* **Select Multiple** (select multiple, optional): Choose multiple dinosaurs from the list.

Note: Please review each field carefully and make sure to fill out all required fields.
