# Money Conversion Quiz - Help Guide
## Purpose
The Money Conversion Quiz is a form designed to help users practice converting money between different currencies.

## How To Complete This Form
To complete the form, follow these steps:

1. **Conversion Type**: Select the type of currency you want to convert from the dropdown options (e.g., Euro, USD, AUD, JPY, CNY).
2. **Base Currency**: Choose the base currency you want to convert from the dropdown options (e.g., USD, EUR, JPY, CNY).
3. **Conversion Rate**: Enter the conversion rate as a numerical value.
4. **Submit**: Select the correct answer for the conversion rate you entered.
5. **Result**: If you think the conversion rate is correct, select "correct". Otherwise, select "incorrect".
6. **Submit**: Click the "submit" button to submit your answer.
7. **User Comments (Optional)**: If you want to add any comments or explanations, you can do so in this field.
8. **Form ID (Internal)**: This field is not required for users; it's for internal tracking purposes only.

## Field-by-Field Explanation
- **Conversion Type (`conversion_type`, select_one):** Selects the type of currency to convert from. For example, converting Euro to Dollars.
- **Base Currency (`base_currency`, select_one):** Chooses the original currency to start with, e.g., USD, EUR, etc.
- **Conversion Rate (`conversion_rate`, number):** Enters the conversion rate as a number.
- **Result (`result`, select_multiple):** If the conversion rate is correct, select "correct". If not, select "incorrect".
- **Submit (`submit`, text):** Submits your answer to the quiz.
- **User Comments (`user_comments`, text):** Allows users to add comments or explanations for their answer.
- **Form ID (`form_id`, text):** An internal field for tracking purposes; not required for users.

## Tips
- Make sure to select the correct conversion type and base currency for accurate conversion.
- Double-check the conversion rate to ensure it's correct.
- The quiz is designed to be fun and educational; don't worry about making mistakes, they're all part of the learning process!
