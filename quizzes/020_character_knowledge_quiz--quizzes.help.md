# Character Knowledge Quiz - Help Guide
## Purpose
This form is designed to test the knowledge of users about a character or story, collecting their responses to a series of questions in a quiz format.

## How To Complete This Form
To complete this form, follow these steps:

1. Read each question carefully and respond accordingly.
2. For questions with options, select the most appropriate answer from the provided choices.
3. Enter your participant name if you wish to be identified for the quiz results.
4. Optionally, provide feedback about the quiz if you'd like to offer suggestions for improvement.
5. If you wish to submit your score, you can do so by entering a number in the corresponding field.

## Field-by-Field Explanation
- **-- Character Knowledge Quiz --**: This is the title of the form, indicating that it's a character knowledge quiz.
- **Participant name**: This is an optional field for you to enter your name if you wish to be identified as the participant who completed the quiz.
  \* Please note that this field is optional and can be left blank if you prefer to remain anonymous.
- **question 1**: This question asks to identify the protagonist of the story.
  \* Please enter the name of the protagonist in the text field provided.
- **question 2**: This question asks to select the primary trait of the protagonist.
  \* Choose one of the four options: Brave, Cautious, Curious, or Selfish.
- **question 3**: This question asks to identify the location where the story takes place.
  \* Please enter the name of the location in the text field provided.
- **question 4**: This question asks to identify a key supporting character.
  \* Please enter the name of the character in the text field provided.
- **question 5**: This question asks to describe the main conflict of the story.
  \* Please enter a brief description of the conflict in the text field provided.
- **Score submission**: This is an optional field to submit your quiz score for internal use.
  \* If you wish to submit your score, please enter a number in this field.
- **Feedback**: This is an optional field to provide feedback about the quiz.
  \* Please enter any suggestions or comments you have about the quiz in this text field.
- **Completion date**: This is an optional field to record the date the quiz was finished.
  \* If you wish to record the completion date, please enter the date in the format MM/DD/YYYY.
