# shipping_pallet_rental_order_form - Help Guide

## Purpose
The shipping pallet rental order form is used to collect information for the rental order process. This includes details on rental order type, shipping provider, payment information, and delivery details.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the type of rental order you need (Rental Order).
2. Enter the name of the shipping provider (Shipping Provider Name).
3. Enter the delivery details (Delivery Date) you require.
4. Choose the payment method and amount (Payment Method and Payment Amount).
5. Provide the Order ID (Order ID) if available.

## Field-by-Field Explanation

* **Rental Order** (Rental Order, select_multiple, required/optional): Select the type of rental order you need. You can choose either "Yes" or "No" to indicate whether the order is a rental order.
* **Shipping Provider** (Shipping Provider, text, required/optional): Enter the name of the shipping provider you are using for this order.
* **Delivery Details** (Delivery Details, time, required/optional): Enter the date you require for delivery.
* **Payment Information** (Payment Information, select_one, required/optional): Choose how you would like to pay for this order.
* **Dates** (Dates, date, required/optional): Enter the date of the order.
* **Delivery Date** (Delivery Date, date, required/optional): Enter the date you require for delivery.
* **Shipping Provider Name** (Shipping Provider Name, text, required/optional): Enter the name of the shipping provider you are using for this order.
* **Payment Amount** (Payment Amount, number, required/optional): Enter the payment amount for this order.
* **Payment Method** (Payment Method, select_one, required/optional): Choose how you would like to pay for this order.
* **Order ID** (Order ID, text, required/optional): Enter the ID of the order if you have it.

## Tips
- Be accurate when entering the delivery details to ensure smooth order fulfillment.
- Choose the correct payment method and amount to avoid delays.
- Provide the Order ID if available to save time and ensure accurate order tracking.
