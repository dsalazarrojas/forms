# Scentsy Monthly Pre Order - Help Guide
## Purpose
This form is designed to capture sales order information, including customer details, payment method, and order status.

## How To Complete This Form
1. Fill in the customer name in the "Customer Name" field.
2. Enter the customer's address in the "address" field.
3. Select the customer's city and state in the corresponding fields.
4. Enter the customer's zip code in the "zip" field.
5. Select the customer's country in the corresponding field.
6. Enter the customer's phone number and email in the "Phone" and "Email" fields respectively.
7. Select the order date in the "Order Date" field.
8. Enter the order total in the "Order Total" field.
9. Select the payment method from the options provided.
10. Select the customer representative in the "Customer Rep" field.
11. Select the order status from the options provided.
12. Add any additional notes in the "Notes" field.
13. Add any customer notes in the "Customer Notes" field.
14. Add any sales representative notes in the "Sales Rep Notes" field.
15. Select the order source from the options provided.
16. If "Order Source" is selected as "Other", enter the details in the "Order Source Other" field.
17. Select the customer source from the options provided.
18. If "Customer Source" is selected as "Other", enter the details in the "Customer Source Other" field.
19. Enter the order ID in the "Order ID" field.
20. Enter the date of sale in the "Date of Sale" field.
21. Enter the sales representative's name in the "Sales Rep" field.
22. Enter the sales representative's ID in the "Sales Rep ID" field.
23. Enter the assigned tool in the "Assigned Tool" field.

## Field-by-Field Explanation

* **Customer Name**: Enter the customer's name.
* **Address**: Enter the customer's address.
* **City**: Enter the customer's city.
* **State**: Enter the customer's state.
* **Zip**: Enter the customer's zip code.
* **Country**: Select the customer's country.
* **Phone**: Enter the customer's phone number.
* **Email**: Enter the customer's email.
* **Order Date**: Select the date for the order.
* **Order Total**: Enter the total amount of the order.
* **Payment Method**: Select the payment method (Visa, American Express, Discover, Mastercard, or PayPal).
* **Customer Rep**: Select the customer representative (Jim, John, Jane, or Joe).
* **Order Status**: Select the status of the order (Pending, Approved, or Denied).
* **Notes**: Add any additional notes.
* **Customer Notes**: Add any notes from the customer.
* **Sales Rep Notes**: Add any notes from the sales representative.
* **Order Source**: Select the source of the order (Online, Offline, Event, In-Store, or Mailer).
* **Order Source Other**: If "Order Source" is selected as "Other", enter the details.
* **Customer Source**: Select the source of the customer (Online, Offline, Event, In-Store, or Mailer).
* **Customer Source Other**: If "Customer Source" is selected as "Other", enter the details.
* **Order ID**: Enter the unique identifier for the order.
* **Date of Sale**: Select the date of sale.
* **Sales Rep**: Enter the sales representative's name.
* **Sales Rep ID**: Enter the sales representative's ID.
* **Assigned Tool**: Enter the assigned tool.
