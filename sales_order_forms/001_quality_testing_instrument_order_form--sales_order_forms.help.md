# Quality Testing Instrument Order Form - Help Guide
## Purpose
The Quality Testing Instrument Order Form is used to place an order for quality testing instruments. It captures details such as shipping and payment information. This form is used by users to ensure that orders are correctly placed and efficiently fulfilled.

## How To Complete This Form
1. Fill out each section completely and accurately, ensuring that all required fields have input.
2. Select the correct instrument type (instrument, service, or other) from the available options.
3. Provide details about the instrument price, quantity, and discount.
4. Select a payment method (credit card, bank transfer, or other) and provide bank account details if necessary.
5. Review and submit the form once all fields have been filled out.

**Instrument Order (1)**: 
The Instrument Order field is the first field in the form. It is used to select the type of instrument being ordered (instrument, service, or other). Select the correct option from the available choices to ensure that the form is correctly filled out.

**Shipping Details (2)**: 
The Shipping Details field is used to select the shipping option (instrument, service, or other). This is the same as the instrument order field, as both are used for different aspects of shipping. Select the correct option to ensure that the form is correctly filled out.
