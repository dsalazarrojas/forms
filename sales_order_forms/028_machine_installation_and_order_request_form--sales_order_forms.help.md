# Machine Installation And Order Request Form - Help Guide

## Purpose
This form is designed to collect necessary information for the installation of new machines. It gathers details about the customer, the machine, and the installation requirements, which will be used by the sales team to process the order and arrange for the installation.

## How To Complete This Form
1. Please provide your name and contact information in the "customer_details" field.
2. Enter the type of machine model you are interested in purchasing in the "machine_model" field.
3. Specify the quantity of machines you would like to order in the "quantity_ordered" field.
4. Provide the desired installation date and time in the "installation_date" and "installation_time" fields.
5. Describe the installation requirements in the detail fields provided: "installation_details", "contact_details", and "machine_details".

## Field-by-Field Explanation
* **Machine Installation And Order Request Form** (`machine_installation_and_order_request_form`, text, required: false): This is the title of the form and is not a field that needs to be filled out.
* **Customer Details** (`customer_details`, text, required: false): Enter your name, phone number, and any other relevant contact information here.
* **Machine Details** (`machine_details`, text, required: false): Describe the type of machine you are interested in, including any specific features or models.
* **Installation Details** (`installation_details`, text, required: false): Provide any specific installation requirements, such as location or space constraints.
* **Contact Details** (`contact_details`, text, required: false): Leave your contact information and any additional notes for the installation team.
* **Machine Model** (`machine_model`, number, required: false): Enter the specific model number of the machine you would like to purchase.
* **Quantity Ordered** (`quantity_ordered`, number, required: false): Specify how many machines you would like to order.
* **Installation Date** (`installation_date`, date, required: false): Select the date on which you would like the machine installed.
* **Installation Time** (`installation_time`, time, required: false): Choose the time slot on the selected installation date.
* **Installation Details (Optional)** (`installation_details`, text, required: false): Provide any additional details about the installation, such as location or space constraints.
* **Contact Details (Optional)** (`contact_details`, text, required: false): Leave your contact information and any additional notes for the installation team.
* **Installation Details (Optional)** (`machine_details`, text, required: false): Describe the machine you are interested in, including any specific features or models.

## Tips
* Double-check all fields to ensure that all required details are filled out correctly.
* If you have any additional requirements or notes, please provide them in the "installation_details" and "contact_details" fields.
* If you have any questions or concerns, please contact the sales team for assistance.
