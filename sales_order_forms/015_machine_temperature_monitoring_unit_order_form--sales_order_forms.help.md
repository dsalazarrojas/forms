# Machine Temperature Monitoring Unit Order Form - Help Guide
## Purpose
The Machine Temperature Monitoring Unit Order Form is designed to gather necessary information for the successful delivery of a machine temperature monitoring unit. This includes shipping details, contact information, payment details, and machine specifications.

## How To Complete This Form
1. Select the "Machine Type" and "Machine Model" from the provided options.
2. Enter the "Quantity" of units required.
3. Enter the "Unit Price" of the selected units.
4. Review and fill out "Shipping Details" and "Contact Information" as necessary.
5. Complete any other required fields.

## Field-by-Field Explanation
* **Shipping Details (Page 1)** (`machine_temperature_monitoring_unit_order_form_1`, text, optional): Enter the shipping address details if different from the billing address.
* **Contact Info (Page 2)** (`machine_temperature_monitoring_unit_order_form_2`, text, optional): Provide your contact information, including name and phone number, to ensure efficient communication.
* **Shipping Details (Page 3)** (`machine_temperature_monitoring_unit_order_form_3`, text, optional): Enter the shipping address details if different from the billing address.
* **Payment Details (Page 4)** (`machine_temperature_monitoring_unit_order_form_4`, text, optional): Enter your payment method and any necessary payment details.
* **Machine Type (Page 5)** (`machine_temperature_monitoring_unit_order_form_5`, select_multiple, optional): Select the type of machine you are ordering for monitoring:
	+ Machine Monitor
	+ Unit Monitor
* **Machine Model (Page 6)** (`machine_temperature_monitoring_unit_order_form_6`, select_one, optional): Select the model of the machine from the provided options:
	+ model1
	+ model2
	+ model3
* **Quantity (Page 7)** (`machine_temperature_monitoring_unit_order_form_7`, number, optional): Enter the number of units required.
* **Unit Price (Page 8)** (`machine_temperature_monitoring_unit_order_form_8`, number, optional): Enter the price per unit for the selected quantity.
