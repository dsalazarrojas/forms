# Salesforce Account Form - Help Guide
## Purpose
This form is for capturing information about sales accounts. It is intended to be used for data collection and perhaps for updating existing account records.

## How To Complete This Form
To complete this form, please follow these steps:

1. Enter the "Account Number" in the first field. This number is unique to each account and is required.
2. Enter the "Account Name" in the second field. This is the name of the account.
3. Enter the "Account Email" in the third field. This is the email address associated with the account.
4. Enter the "Account Phone" in the fourth field. This is the phone number associated with the account.
5. Select the "Account Category" from the dropdown menu in the fifth field. This field helps categorize the account type.
6. Enter any additional information about the account in the "Account Description" field.
7. Enter the dates for "Account Created", "Account Updated", and "Account Status Updated" in their respective fields. These fields are for tracking when the account was created or updated.
8. Select the "Account Type" from the dropdown menu in the "Account Type" field.
9. Enter the "Account Owner" in the next field. This is the person responsible for the account.
10. Enter any additional information about the account in the "Account Notes" field.
11. Select the "Account Status" from the dropdown menu in the "Account Status" field.
12. Select the "Account Type Updated" in the "Account Type Updated" field.
13. Enter the "Account Created By" in the next field. This is the person who created the account.
14. Enter the "Account Updated By" in the next field. This is the person who updated the account.
15. Select the "Account Status Updated By" in the next field. This is the person who updated the account status.
16. Finally, you can add any additional comments in the last two fields, if necessary.

## Field-by-Field Explanation
- **Salesforce Account**: Enter the name of the account. This is the main title of the account.
  • Type: `text`
  • Required: Optional
- **Account Number**: Enter a unique number for each account. This number is required for identification purposes.
  • Type: `number`
  • Required: Required
- **Account Name**: Enter the name of the account. This is the main title of the account.
  • Type: `text`
  • Required: Optional
- **Account Email**: Enter the email address associated with the account.
  • Type: `email`
  • Required: Optional
- **Account Phone**: Enter the phone number associated with the account.
  • Type: `text`
  • Required: Optional
- **Account Category**: Select the category for the account from the dropdown menu.
  • Type: `select_one`
  • Required: Optional
- **Account Address**: Enter any additional information about the account location.
  • Type: `text`
  • Required: Optional
- **Account Description**: Enter any additional information about the account.
  • Type: `text`
  • Required: Optional
- **Account Date**: Enter the date when the account was created.
  • Type: `date`
  • Required: Optional
- **Account Time**: Enter the time when the account was created.
  • Type: `time`
  • Required: Optional
- **Account Notes**: Enter any additional information or comments about the account.
  • Type: `note`
  • Required: Optional
- **Account Status**: Select the status for the account from the dropdown menu.
  • Type: `select_one`
  • Required: Optional
- **Account Type**: Select the type for the account from the dropdown menu.
  • Type: `select_multiple`
  • Required: Optional
- **Account Owner**: Enter the person responsible for the account.
  • Type: `text`
  • Required: Optional
- **Account Created**: Enter the date when the account was created.
  • Type: `date`
  • Required: Optional
- **Account Updated**: Enter the date when the account was last updated.
  • Type: `date`
  • Required: Optional
- **Account Status Updated**: Enter the date when the account status was last updated.
  • Type: `date`
  • Required: Optional
- **Account Created By**: Enter the person who created the account.
  • Type: `text`
  • Required: Optional
- **Account Updated By**: Enter the person who last updated the account.
  • Type: `text`
  • Required: Optional
- **Account Status Updated By**: Enter the person who last updated the account status.
  • Type: `text`
  • Required: Optional
- **Account Updated Reason**: Enter any reason for the last update.
  • Type: `text`
  • Required: Optional
