# Store Window Display Order Form - Help Guide

## Purpose
The purpose of this form is to collect information from customers who are interested in purchasing or learning more about store window displays. This form ensures that store managers and staff have a clear understanding of the customer's requirements, preferences, and contact details.

## How To Complete This Form
1. Fill out the form fields as requested, ensuring that you provide accurate and relevant information for each section.
2. Select the correct options for the "Backlit", "Frame Material", "Frame Color", "Hardware Type", and "Backlight Color" fields from the respective dropdown menus.
3. Enter numerical values for the "Window Size (sqft)" and "Storefront Size (sqft)" fields.
4. Enter text information for the "Window Graphics", "Product Image", "Special Instructions", "Store Manager Contact", "Store Manager Phone", "Store Manager Email", "Store Manager Notes", "Customer Information", "Customer Name", "Customer Phone", "Customer Email", "Customer Contact" fields.
5. Ensure that all required fields are filled out before submitting the form.

## Field-by-Field Explanation
* **Retail Window Information**: Enter a brief description of the retail window display you are interested in purchasing or inquiring about.
* **Storefront Information**: Provide details about the storefront's location, contact information, and other relevant information.
* **Product Information**: Enter the product details, such as product name and description.
* **Window Details**: Enter the specifications of the window display, including size, color, and materials used.
* **Window Size (sqft)**: Enter the size of the window display in square feet.
* **Storefront Size (sqft)**: Enter the size of the store's storefront in square feet.
* **Window Color**: Select the color of the window display from the dropdown menu.
* **Window Graphics**: Enter any custom graphics or designs that you would like to see on the window display.
* **Product Image**: Upload or enter a URL for the product image you would like to see on the window display.
* **Backlit**: Select whether the window display will have a backlight feature.
* **Frame Material**: Select the material used to make the window display frame from the dropdown menu.
* **Frame Color**: Select the color of the frame from the dropdown menu.
* **Hardware Type**: Select the type of hardware used for the window display from the dropdown menu.
* **Backlight Color**: Select the color of the backlight feature from the dropdown menu.
* **Product Price**: Enter the price of the window display you are interested in purchasing.
* **Special Instructions**: Enter any special instructions or requests you have for the window display.
* **Store Manager Contact**: Enter the contact information of the store manager, including name, phone number, and email.
* **Store Manager Phone**: Enter the phone number of the store manager.
* **Store Manager Email**: Enter the email of the store manager.
* **Store Manager Notes**: Enter any notes or comments for the store manager.
* **Customer Information**: Enter any relevant customer information, such as name, phone number, and email.
* **Customer Name**: Enter the customer's name.
* **Customer Phone**: Enter the customer's phone number.
* **Customer Email**: Enter the customer's email.
* **Customer Contact**: Enter any additional contact information for the customer.
