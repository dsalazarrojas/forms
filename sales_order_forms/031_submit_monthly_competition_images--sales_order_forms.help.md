# submit_monthly_competition_images - Help Guide
## Purpose
This form is designed to collect and submit monthly competition images for sales orders. It allows sales teams to input and track competition images for sales orders, including sales order date, sales channel, sales region, sales country, image type, image description, and sales order status.

## How To Complete This Form
To complete this form, follow these steps:

1. Review each field carefully to ensure you have the required information ready.
2. Fill in the **Sales Order Form** field with the relevant sales order details.
3. Enter the **Sales Order Date** in the format MM/DD/YYYY.
4. Select the **Competition Image** from the relevant dropdown menu.
5. Enter the **Sales Channel** where the sales order was generated.
6. Enter the **Sales Region** where the sales order was processed.
7. Enter the **Sales Country** where the sales order was shipped or sold.
8. Select the **Image Type** from the dropdown menu.
9. Enter a brief **Image Description** of the competition image.
10. Enter the **Competition Image URL** if available.
11. Select the **Sales Order Status** from the dropdown menu.
12. Enter any additional **Sales Order Status Notes**.

## Field-by-Field Explanation
* **Sales Order Form**: This field allows you to enter the relevant sales order details. Please ensure this field is accurate and up-to-date.
* **Sales Order Date**: Enter the date of the sales order in MM/DD/YYYY format.
* **Competition Image**: Select the competition image associated with the sales order from the dropdown menu.
* **Sales Channel**: Enter the sales channel where the sales order was generated (e.g. online, offline, etc.).
* **Sales Region**: Enter the sales region where the sales order was processed (e.g. North America, Europe, etc.).
* **Sales Country**: Enter the country where the sales order was shipped or sold.
* **Image Type**: Select the type of image associated with the competition (e.g. logo, banner, etc.).
* **Image Description**: Enter a brief description of the competition image.
* **Competition Image URL**: Enter the URL of the competition image if available.
* **Sales Order Status**: Select the status of the sales order from the dropdown menu (e.g. Active, Pending, Cancelled).
* **Sales Order Status Notes**: Enter any additional notes related to the sales order status.
