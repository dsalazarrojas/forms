# Recognition Order Form - Help Guide
## Purpose
The Recognition Order Form is used to collect information about a customer and their recognition order, including order details, customer information, award type, and order status.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the Order Details section with any relevant information about the recognition order.
2. In the Customer Info section, enter the customer's details, including their name and email.
3. In the Award Type section, select the type of award the customer is receiving.
4. In the Order Status section, select the current status of the order.
5. Leave any other fields blank if they are not required, as they are not necessary for the form submission.

## Field-by-Field Explanation
* **Order Details** (`order_details`, text, required: false): Enter any relevant details about the recognition order.
* **Customer Info** (`customer_info`, text, required: false): Enter the customer's name and any other relevant details.
* **Award Type** (`award_type`, select_one, required: false): Select the type of award the customer is receiving.
* **Customer Name** (`customer_name`, text, required: false): Enter the customer's name.
* **Customer Email** (`customer_email`, email, required: false): Enter the customer's email address.
* **Customer Phone** (`customer_phone`, text, required: false): Enter the customer's phone number (if applicable).
* **Award Type** (`award_type`, select_one, required: false): Select the type of award the customer is receiving.
* **Award Details** (`award_details`, text, required: false): Enter any additional details about the award.
* **Award Price** (`award_price`, number, required: false): Enter the price of the award (if applicable).
* **Order Total** (`order_total`, number, required: false): Enter the total cost of the order (if applicable).
* **Order Status** (`order_status`, select_one, required: false): Select the current status of the order (e.g., In Progress, Completed, Canceled).
* **Customer Address** (`customer_address`, note, required: false): Enter the customer's address (if applicable).
