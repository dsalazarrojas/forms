# promotional_counter_stand_order_form - Help Guide
## Purpose
The Promotional Counter Stand Order Form is used to collect information for promotional counter stand orders from customers. This form helps sales teams track and fulfill orders efficiently.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out each field with the required information.

## Field-by-Field Explanation
* **Artwork** (`artwork`, text, optional):
	+ Enter the artwork name or description.
* **Delivery Details** (`delivery_details`, text, optional):
	+ Enter any specific delivery details or instructions.
* **Payments** (`payments`, select_one, optional):
	+ Select the payment option for the order (Option 1, Option 2, or Option 3).
* **Shipping Address** (`shipping_address`, text, optional):
	+ Enter the shipping address for the order.
* **Email** (`email`, email, optional):
	+ Enter the customer's email address.
* **Phone** (`phone`, text, optional):
	+ Enter the customer's phone number.
* **Delivery Date** (`delivery_date`, date, optional):
	+ Enter the specific date for delivery.
* **Delivery Time** (`delivery_time`, time, optional):
	+ Enter the specific time for delivery.
* **Artwork Description** (`artwork_description`, text, optional):
	+ Enter a detailed description of the artwork.
* **Quantity** (`quantity`, number, optional):
	+ Enter the quantity of items ordered.
* **Price** (`price`, number, optional):
	+ Enter the price of the order.
* **Shipping Notes** (`shipping_notes`, text, optional):
	+ Enter any special shipping instructions or notes.
* **Payment Type** (`payment_type`, select_multiple, optional):
	+ Select multiple payment options for the order (Option 1, Option 2, or Option 3).
* **Customer** (`customer`, text, optional):
	+ Enter the customer's name or contact information.
* **Notes** (`notes`, note, optional):
	+ Add any additional notes or comments for the order.

## Tips
* Double-check your input for accuracy before submitting the form.
* Make sure to enter all required information for the order to be processed correctly.
