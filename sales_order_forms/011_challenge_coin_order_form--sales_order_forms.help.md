# Challenge Coin Order Form - Help Guide
## Purpose
This form is designed to collect information for a challenge coin order, allowing customers to specify their preferences for size, metal type, finish, and shipping details.

## How To Complete This Form
1.  Fill in the order date when the order was placed.
2.  Enter your full name as the customer placing the order.
3.  Enter your business or organization name if applicable.
4.  Enter your contact email address.
5.  Enter your contact phone number.
6.  Select the type of order you would like to place: custom design, stock design, or a combination of both.
7.  Enter the number of coins you would like to order.
8.  Select the diameter size of the coin from the options provided.
9.  Choose the metal type for the coin.
10.  Select the finish type for the coin.
11.  Enter any specific colors or enamel colors you would like to use.
12.  Describe the design or upload a design file if applicable.
13.  Indicate if you have a design file attached for the order.
14.  Enter any additional text or inscription you would like to have on the coin.
15.  Select the type of edge for the coin, if desired.
16.  Choose how you would like the coins to be packaged.
17.  Enter your shipping address.
18.  Select the shipping method for your order.
19.  You can also enter an approximate total cost estimate, if known.
20.  Enter any special instructions or notes for the order.
21.  Select the payment terms for your order.

## Field-by-Field Explanation

* **Order Date** (`order_date`, Date, Required): This field is used to record the date when the order was placed.
* **Customer Name** (`customer_name`, Text, Required): Enter your full name as the customer placing the order.
* **Company/Organization Name** (`company_name`, Text, Not Required): If you are placing the order on behalf of a business or organization, enter their name here.
* **Email Address** (`email_address`, Email, Required): Enter your contact email address.
* **Phone Number** (`phone_number`, Text, Required): Enter your contact phone number.
* **Order Type** (`order_type`, Select One, Required): Choose the type of order you would like to place: custom design, stock design, or a combination of both.
* **Quantity of Coins Ordered** (`coin_quantity`, Number, Required): Enter the number of coins you would like to order.
* **Coin Size** (`coin_size`, Select One, Required): Choose the diameter size of the coin from the options provided.
* **Metal Type** (`metal_type`, Select One, Required): Select the metal type for the coin from the options provided.
* **Finish Type** (`finish_type`, Select One, Required): Choose the finish type for the coin from the options provided.
* **Color or Enamel Colors** (`color_options`, Text, Not Required): Enter any specific colors or colors that you would like to use.
* **Design Description** (`design_description`, Text, Required): Describe the design or upload a design file if applicable.
* **Design File Attached** (`design_file_attached`, Select One, Required): Indicate if you have a design file attached for the order.
* **Text or Inscription** (`text_on_coin`, Text, Not Required): Enter any additional text or inscription you would like to have on the coin.
* **Edge Type** (`edge_type`, Select One, Not Required): Select the type of edge for the coin, if desired.
* **Packaging Preference** (`packaging_preference`, Select One, Not Required): Choose how you would like the coins to be packaged.
* **Shipping Address** (`shipping_address`, Text, Required): Enter your shipping address.
* **Shipping Method** (`shipping_method`, Select One, Required): Select the shipping method for your order.
* **Total Cost Estimate** (`total_cost_estimate`, Number, Not Required): Enter an approximate total cost estimate, if known.
* **Special Instructions or Notes** (`special_instructions`, Text, Not Required): Enter any additional details or special instructions for the order.
* **Payment Terms** (`payment_terms`, Select One, Not Required): Select the payment terms for your order.
