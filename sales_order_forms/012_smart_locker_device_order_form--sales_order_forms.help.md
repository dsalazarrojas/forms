# Smart Locker Device Order Form - Help Guide
## Purpose
The Smart Locker Device Order Form is used to collect information from customers for ordering a new smart locker device. It is essential to fill out this form accurately to ensure that your order is processed correctly and efficiently.

## How To Complete This Form

To complete this form, follow these steps:

*   Fill out the form completely and accurately.
*   Ensure that all required fields are filled out.
*   Review your submission carefully before submitting.

## Field-by-Field Explanation

*   **Customer Information** (`customer_info`, `text`, required: false): This field is used to collect the customer's name and contact details. Please enter your name as it appears on your identification.
*   **Device Order** (`device_order`, `select_multiple`, required: false): This field allows you to select the type of device you want to order (None, Other). If you select "Other", please provide a description in the "Device Order" field below.
*   **Device Order** (`device_order`, `select_multiple`, required: false): This field is not applicable if you select "Other" in the above field. If you need to order a different type of device, please provide a brief description in this field.
*   **Delivery Information** (`delivery_info`, `text`, required: false): This field is used to provide any additional information about your delivery preferences.
*   **Payment** (`payment_info`, `select_multiple`, required: false): This field is used to select the payment method (None, 1). Please select "None" if you don't want to pay at this time.
*   **Contact Information** (`contact_info`, `text`, required: false): This field is used to collect any additional contact information that you would like to provide.
