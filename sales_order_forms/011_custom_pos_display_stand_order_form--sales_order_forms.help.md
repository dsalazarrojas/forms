# Custom POS Display Stand Order Form - Help Guide
## Purpose
This form is used to collect information about a custom POS display stand order from the customer.

## How To Complete This Form
To complete this form, please follow these steps:

1.  Navigate through the form pages.
2.  Fill in each field according to your needs and information availability.
3.  Ensure that all required fields are completed before proceeding to the next page.
4.  Review the information provided before submission.

## Field-by-Field Explanation

* **Customer Info (customer-info)**:
	+ This field is used to capture the customer's name and other relevant contact information.
	+ Please enter the customer's name as it should be displayed on the order.
* **Display Specs (display-specs)**:
	+ This field is used to specify the display's features and requirements.
	+ Please provide a detailed description of the display's specifications.
* **Artwork (artwork)**:
	+ This field is used to determine if the display requires custom artwork.
	+ Select 'Yes' if the display requires custom artwork; otherwise, select 'No'.
* **Quantity**:
	+ This field is used to specify the number of displays ordered.
	+ Please enter the quantity of displays required.
* **Payment Method (payment-method)**:
	+ This field is used to determine the payment method for the order.
	+ Select 'Yes' if the order is paid in full; otherwise, select 'No'.
* **Order Date (order-date)**:
	+ This field is used to record the date of the order.
	+ Enter the date the order is being placed.
* **Order Time (order-time)**:
	+ This field is used to record the time of the order.
	+ Enter the time the order is being placed.
* **Notes**:
	+ This field is used to capture any additional comments or instructions.
	+ Please provide any relevant information that might aid in the order fulfillment process.
* **Customer Email (customer-email)**:
	+ This field is used to capture the customer's email address.
	+ Please ensure that the email address is accurate and up-to-date.
* **Customer Phone (customer-phone)**:
	+ This field is used to capture the customer's phone number.
	+ Please ensure that the phone number is accurate and up-to-date.

## Tips

* Please ensure that all required fields are completed before proceeding to the next page.
* Review the information provided before submission to ensure accuracy.
* If you have any questions or concerns, please do not hesitate to contact our support team.
