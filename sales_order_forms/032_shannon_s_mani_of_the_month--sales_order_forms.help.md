# shannonsmani_of_the_month_ - Help Guide
## Purpose
The "shannonsmani_of_the_month_" form is a sales order management tool that helps in capturing and organizing essential information about each order. It is used to update or create new sales orders.

## How To Complete This Form
To use this form, follow these steps:

1. Start by filling in the "Order Details" section, which includes basic information about the order.
2. Proceed to the "Customer Information" section to provide details about the customer placing the order.
3. In the "Order Status" section, select the current status of the order from the options provided.
4. The "Additional Information" field can be used to add any extra comments or notes related to the order.
5. In the "Product Information" section, enter any relevant details about the products ordered.
6. If there are repeated questions or concerns about the order, use the "Repeated Questions" field to note them.
7. Use the "Order Comments" field for any comments or observations about the order.
8. In the "Sales Rep" section, select the sales representative responsible for the order from the options provided.
9. Check if the customer placing the order is "New" or "Existing".
10. In the "Order Status 2" section, select an additional status option for the order from the provided choices.
11. Finally, select the sales representative responsible for the order from the second set of options in the "Sales Rep 2" field.
12. Confirm if the customer is "New" or "Existing" in the "Existing Customer 2" field.

## Field-by-Field Explanation
* **Order Details** (order_details, text, required/optional): Enter a brief description of the order to help in identifying and tracking it.
* **Customer Information** (customer_info, text, required/optional): Provide details about the customer, including their name, contact information, and any other relevant details.
* **Order Status** (order_status, select_one, required): Select the current status of the order from the options provided (Pending, Shipped, Cancelled).
* **Additional Information** (additional_info, text, required/optional): Add any extra comments or notes related to the order.
* **Product Information** (product_info, text, required/optional): Enter any relevant details about the products ordered.
* **Repeated Questions** (repeated_questions, text, required/optional): Use this field if you have repeated questions or concerns about the order.
* **Order Comments** (order_comments, note, required/optional): Enter any comments or observations about the order.
* **Sales Rep** (sales_rep, select_multiple, required/optional): Select the sales representative responsible for the order from the options provided.
* **Existing Customer** (existing_customer, select_one, required/optional): Check if the customer is "New" or "Existing".
* **Order Status 2** (order_status_2, select_one, required/optional): Select an additional status option for the order from the provided choices.
* **Sales Rep 2** (sales_rep_2, select_multiple, required/optional): Select the sales representative responsible for the order from the second set of options.
* **Existing Customer 2** (existing_customer_2, select_one, required/optional): Confirm if the customer is "New" or "Existing".
