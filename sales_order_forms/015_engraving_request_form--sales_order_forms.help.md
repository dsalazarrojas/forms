# Engraving Request Form - Help Guide
## Purpose
This form is designed to collect customer information and specific details for custom engraving requests.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the customer's basic information in the "Customer Info" section.
2. Provide clear and concise instructions for the engraving in the "Engraving Instructions" section.
3. Upload an image of the artwork for reference in the "Artwork Image Upload" section.
4. Add a brief description of the artwork in the "Artwork Description" section.
5. Enter the requester's name and contact details in the "Engraving Requester Name", "Email", and "Phone" sections.
6. Share any additional notes or comments about the engraving in the "Engraving Notes" section.

## Field-by-Field Explanation
* **Customer Info (customer_info)**: Enter the customer's basic information, including name and contact details.
* **Engraving Instructions (engraving_instructions)**: Provide clear and concise instructions for the engraving.
* **Artwork Image Upload (artwork_image_upload)**: Upload an image of the artwork for reference.
* **Artwork Description (artwork_description)**: Add a brief description of the artwork.
* **Engraving Requester Name (engraving_requester_name)**: Enter the name of the person requesting the engraving.
* **Email (email)**: Enter the customer's email address for contact purposes.
* **Phone (phone)**: Enter the customer's phone number for contact purposes.
* **Address (address)**: Enter the customer's address for delivery purposes.
* **Engraving Notes (engraving_notes)**: Add any additional notes or comments about the engraving.

## Tips
* Please ensure all fields are filled in accurately to avoid delays or miscommunication.
* Use clear and concise language for the "Engraving Instructions" section.
* For the "Artwork Image Upload" section, use a clear and high-quality image of the artwork.
* Be mindful of the character limits for each field to ensure all information is captured correctly.
