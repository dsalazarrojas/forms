# Call Reviews Milestones - Help Guide

## Purpose

This form is used to capture the key milestones and outcomes of a call review between the account management team and the client. The purpose of this form is to provide a clear and concise summary of the discussions had during the call, ensuring that all necessary agreements, action items, and decisions are documented and communicated effectively.

## How To Complete This Form

To complete this form, follow these steps:

1. Fill in the basic information: Enter the client's name, project name, and account manager's name in the corresponding fields.
2. Select the current milestone reached: Choose the primary milestone discussed during the call from the options provided.
3. Update the milestone status: Select the current status of the project, indicating if it's on track, ahead of schedule, experiencing minor or significant delays, or blocked.
4. Document key decisions and agreements: Provide a brief summary of the main outcomes of the call.
5. Capture client feedback: Record any comments or concerns raised by the client.
6. Assign internal and client action items: List tasks that need to be performed by the internal team and tasks assigned to the client team.
7. Set the next scheduled call date: Optionally, enter the date of the next scheduled call if applicable.
8. Identify potential project risks: Select any new or ongoing risks to the project timeline.
9. Get manager approval: Select the manager's approval status for the call summary.

## Field-by-Field Explanation

* **Client Name** (`text`, required): Enter the name of the account or company.
* **Project Name - ID** (`text`, required): Enter the reference to the specific project being reviewed.
* **Account Manager** (`text`, required): Enter the internal lead for this project.
* **Date of Call Review** (`date`, required): Enter the date of the call review.
* **Current Milestone Reached** (`select_one`, required): Select the primary milestone discussed during the call. Options: Discovery Completed, Proposal Accepted, Contract Signed, Implementation Phase 1, Implementation Phase 2, Final Delivery, Post-Launch Review.
* **Milestone Status** (`select_one`, required): Select the current status of the project. Options: On Track, Ahead of Schedule, Minor Delay, Significant Delay, Blocked.
* **Key Decisions and Agreements** (`text`, required): Provide a brief summary of the main outcomes of the call.
* **Client Feedback Received** (`text`, optional): Record any comments or concerns raised by the client.
* **Internal Action Items** (`text`, optional): List tasks that need to be performed by the internal team.
* **Client Action Items** (`text`, optional): List tasks assigned to the client team.
* **Next Scheduled Call Date** (`date`, optional): Enter the date of the next scheduled call, if applicable.
* **Potential Project Risks** (`select_multiple`, optional): Select any new or ongoing risks to the project timeline. Options: Budget overruns, Scope creep, Resource availability, Technical challenges, Communication gaps.
* **Manager Approval of Review** (`select_one`, required): Select the manager's approval status for the call summary. Options: Approved, Needs Revision, Pending further info.
