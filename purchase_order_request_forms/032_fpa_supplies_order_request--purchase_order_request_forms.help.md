# Fpa supplies order request - Help Guide
## Purpose
This form is used to request FPA supplies. It's designed to gather essential information about the order, ensuring that the request is processed correctly and efficiently.

## How To Complete This Form
1. Enter the required information for the form to be processed.
2. Ensure that all relevant fields are filled out accurately and truthfully.
3. Review your submission before submitting to ensure that everything is correct.

## Field-by-Field Explanation
- **Purchase Order Request Forms**: Enter a brief description of the purchase order request, if necessary.
- **FPA supplies**: Enter the number of FPA supplies required.
- **Quantity**: Enter the quantity of FPA supplies requested.
- **Supplier ID**: Choose 'Yes' if you have a supplier ID.
  - If 'Yes', enter the ID in the next field.
  - If 'No', skip to the next field.
- **Supplier**: Choose 'Yes' if you have a supplier in mind.
  - If 'Yes', select the supplier from the list.
  - If 'No', enter a brief description of the supplier and the team will assist you in finding a suitable one.
- **Request Date**: Enter the date when you need the supplies by.
- **Request Time**: Enter the specific time when you need the supplies by.
- **Order Note**: Enter any relevant notes or comments about the order.
- **Email**: Enter your email address.
- **Phone**: Enter your phone number.
- **Assigned Tool**: Choose 'Yes' if you have an assigned tool.
  - If 'Yes', choose the tool from the list.
  - If 'No', enter a brief description of the tool and the team will assist you in assigning it.
- **Assigned User**: Choose 'Yes' if you have an assigned user.
  - If 'Yes', choose the user from the list.
  - If 'No', enter a brief description of the user and the team will assist you in assigning one.

## Tips
- Be accurate and truthful with the information provided.
- If you're unsure about any field, contact the team for assistance.
- Review your submission before submitting to ensure that everything is correct.
