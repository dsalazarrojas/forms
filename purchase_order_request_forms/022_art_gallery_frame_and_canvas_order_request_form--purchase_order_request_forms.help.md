# Art Gallery Frame And Canvas Order Request Form - Help Guide

## Purpose

This form is used to request an art gallery frame and canvas order. It collects information about the order details and requirements for framing and canvas preparation.

## How To Complete This Form

1. Fill out the form completely, making sure to provide accurate and detailed information for each field.
2. Review the form carefully before submitting it.

## Field-by-Field Explanation

* **Request Date**: Enter the date of the order request in the format mm/dd/yyyy.
* **Requester Name**: Enter the full name of the person requesting the order.
* **Requester Email**: Enter the email address of the person requesting the order.
* **Requester Phone**: Enter the contact phone number of the person requesting the order.
* **Gallery Department**: Enter the department or division associated with this order (optional).
* **Artist Name**: Enter the name of the artist for this order.
* **Artwork Title**: Enter the title of the artwork to be framed.
* **Order Type**: Select the type of order (Frame Only, Canvas Only, Frame and Canvas, Custom Order).
* **Frame Style**: Select the preferred frame style (Traditional Wood, Modern Metal, Ornate Gold, Minimalist Black, Natural Wood, Custom).
* **Frame Color**: Enter the preferred frame color or finish.
* **Frame Width**: Enter the width of the frame in inches (optional).
* **Matting Needed**: Select whether matting is required (True or False).
* **Matting Color**: Enter the preferred matting color (optional).
* **Matting Layers**: Select the number of matting layers (Single Mat, Double Mat, Triple Mat, Not Applicable).
* **Canvas Type**: Select the type of canvas needed (Stretched Canvas, Canvas Panel, Canvas Roll, Gallery Wrap, Museum Wrap, Not Applicable).
* **Canvas Size Width**: Enter the width of the canvas in inches (optional).
* **Canvas Size Height**: Enter the height of the canvas in inches (optional).
* **Canvas Depth**: Enter the depth of the canvas in inches (optional).
* **Glass Type**: Select the type of glass or glazing (Standard Glass, UV Protection Glass, Museum Glass, Acrylic Plexiglass, Non-Glare Glass, No Glass Needed).
* **Back Board**: Select the type of back board (Standard Foam Core, Acid-Free Foam Core, Mat Board, Aluminum Composite, Not Applicable).
* **Hanging Hardware**: Select the hanging hardware needed (Wire and Hooks, D-Rings, Sawtooth Hanger, French Cleat, Standoff Mounts, None Needed).
* **Quantity**: Enter the number of items to order.
* **Estimated Cost**: Enter the estimated cost per item (optional).
* **Total Cost**: Calculated automatically based on other fields (optional).
* **Rush Order**: Select whether this is a rush order (Yes - Rush, No - Standard).
* **Needed By Date**: Enter the date when this order is needed.
* **Delivery Instructions**: Enter any special delivery instructions (optional).
* **Approval Status**: Select the current approval status (Pending Approval, Approved, Rejected).
* **Approving Manager**: Enter the name of the approving manager (optional).
* **Additional Notes**: Enter any other information about the order.

Note: This help guide is based on the provided YAML fields. Please review each field carefully and provide accurate information to ensure accurate framing and canvas preparation.
