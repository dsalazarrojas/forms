# Software Order Request Form - Help Guide
## Purpose
The software order request form is a tool for requesting the purchase of new software for the company. It ensures that all necessary information is gathered for the procurement team to process and verify the purchase request.

## How To Complete This Form
To complete this form, please follow these steps:
1. Fill in your name and email address in the "Purchase Requester" field.
2. Enter your phone number in the "Requester Phone" field.
3. Provide a brief description of the software you are requesting in the "Purchase Description" field.
4. Enter the software name in the "Software Name" field.
5. If applicable, specify the version of the software in the "Software Version" field.
6. Enter the cost of the software in the "Software Cost" field.
7. Select the date of the purchase request in the "Purchase Request Date" field.

## Field-by-Field Explanation
* **Purchase Requester** (`purchase_requester`, `text`, required: false): This field is used to input the name of the person requesting the software.
* **Requester Email** (`requester_email`, `email`, required: false): Enter the email address of the person requesting the software.
* **Requester Phone** (`software_requester_phone`, `text`, required: false): This field is used to input the requester's phone number.
* **Purchase Description** (`purchase_request_description`, `text`, required: false): This field is used to provide a brief description of the software being requested.
* **Software Name** (`software_name`, `text`, required: false): Enter the name of the software being requested.
* **Software Version** (`software_version`, `text`, required: false): If this is a version of software, please specify the version number.
* **Software Cost** (`software_cost`, `number`, required: false): Enter the cost of the software.
* **Purchase Request Date** (`purchase_request_date`, `date`, required: false): Select the date of the purchase request.

## Tips
* Please ensure that all fields are filled in accurately to ensure efficient processing of the purchase request.
* If you are unsure about any field, please contact the procurement team for assistance.
* Please note that the procurement team will review and follow up on all purchase requests.
