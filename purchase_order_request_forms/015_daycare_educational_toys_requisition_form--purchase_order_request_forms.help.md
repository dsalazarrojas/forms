# daycare_educational_toys_requisition_form - Help Guide
## Purpose
This form is designed to collect information from daycare center staff for educational toys requests. It helps in coordinating the delivery of toys to the requested locations on time.

## How To Complete This Form
To complete this form, please follow these steps:
1.  Fill in the **Request Details** section with the necessary information about the request.
2.  Select the relevant **Classroom Toys** options that apply to your request.
3.  Provide the **Toy Request Date** for the delivery.
4.  Choose the current **Delivery Status** of the request.
5.  In the **Staff Comments** section, add any additional comments about the request.
6.  Fill in your **Submitter Name** and **Submitter Email** so that we can contact you for more information.
7.  Add your **Submitter Phone Number** for any follow-up calls.
8.  Add any additional comments or information in the **Administrator Comments** section.
9.  If applicable, select a specific **Delivery Date** for the toys.
10.  In the **Delivery Details** section, include any additional information about the delivery.
11.  Finally, fill in your **Submitter Department** and **Submitter Job Title** so that we can identify your role in the organization.

## Field-by-Field Explanation
*   **Request Details**: This is the main section where you fill in the details of your request. Enter a clear and concise description of the toys you want.
*   **Purchase Order Request**: In this section, you can add any additional information or comments about the request.
*   **Classroom Toys**: This field allows you to select multiple classroom-related options for the toys you're requesting. You can choose one or more options depending on your requirements.
*   **Toy Request Date**: Enter the date when you want the toys to be delivered.
*   **Delivery Status**: Choose the current status of your request from the given options.
*   **Staff Comments**: Add any additional comments or information about the request that you think is relevant.
*   **Submitter Name**: Enter your name as the person making the request.
*   **Submitter Email**: Add your email address so that we can contact you for more information.
*   **Submitter Phone**: Provide your phone number for any follow-up calls.
*   **Administrator Comments**: This is an optional section where you can add any comments or information that is meant for our administrators.
*   **Delivery Date**: If you want to select a specific date for the delivery, you can do so here.
*   **Delivery Details**: Add any additional information about the delivery in this section.
*   **Submitter Department**: Enter the department you belong to.
*   **Submitter Job Title**: Enter your job title.
*   **Submitter Job Title 2**: Enter any additional job title if you have multiple titles.
*   **Submitter Job Title 3**: Enter any additional job title if you have multiple titles.
*   **Submitter Job Title 4**: Enter any additional job title if you have multiple titles.
*   **Submitter Location**: Enter your work location.
*   **Submitter Job Title 2**: This field is not actually used as it is a duplicate of **Submitter Job Title**.
