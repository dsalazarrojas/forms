# Campaign Material Request Form - Help Guide
## Purpose
The Campaign Material Request Form is used to request materials for a specific campaign. It is a crucial document for the procurement process, and it helps the team to gather all the necessary information for material ordering and delivery.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill in the Requester Name field with your name as the person requesting the materials.
2. Enter the Campaign Name, which is the title of the campaign for which you are requesting materials.
3. Provide a clear description of the materials you are requesting in the Item Description field.
4. Enter the number of units required for the materials.
5. If applicable, select the Delivery Deadline by which the materials are needed.
6. Enter the Internal budget or account code for the materials (optional).
7. Check the Approval Needed field if this request requires manager approval.
8. If you have a preferred supplier, enter their name in the Vendor Preference field (optional).
9. Enter the shipping address where the materials should be delivered.
10. If you have any additional instructions for ordering or delivery, enter them in the Special Instructions field (optional).

## Field-by-Field Explanation
* **Requester Name**: Enter your name as the person requesting the materials.
* **Campaign Name**: Enter the title of the campaign for which you are requesting materials.
* **Item Description**: Provide a clear description of the materials you are requesting.
* **Quantity**: Enter the number of units required for the materials.
* **Delivery Deadline**: Select the date by which the materials are needed (optional).
* **Budget Code**: Enter the internal budget or account code for the materials (optional).
* **Approval Needed**: Check this box if this request requires manager approval.
* **Vendor Preference**: If you have a preferred supplier, enter their name here (optional).
* **Shipping Address**: Enter the address where the materials should be delivered.
* **Special Instructions**: Enter any additional instructions for ordering or delivery (optional).
