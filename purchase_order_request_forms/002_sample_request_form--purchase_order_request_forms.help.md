# sample_request_form - Help Guide
## Purpose
The "sample_request_form" is a form designed to collect information about a purchase order request, enabling the efficient processing of orders. Fill out this form to submit a new sample request.

## How To Complete This Form
1. Ensure you have all the necessary information before completing this form.
2. Fill out the form in its entirety, or only the required fields if not filling out all fields.
3. Review your entries before submitting to ensure accuracy.

## Field-by-Field Explanation
* **Purchase Order Request Fields** (`purchase_order_request_fields`, text, not required):
	+ This field is a text input where you can enter any additional information about your purchase order request.
* **Sample Request Details** (`sample_request_details`, text, not required):
	+ Enter a brief description of the sample request, including any relevant details or comments.
* **Sample Request Fields 1** (`sample_request_fields_1`, select_one, not required):
	+ Select one of the available products (Product 1, Product 2, or Product 3) to request.
* **Sample Request Fields 2** (`sample_request_fields_2`, select_multiple, not required):
	+ Choose multiple products (Product 1, Product 2, or Product 3) that you are interested in.
