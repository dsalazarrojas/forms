# Pharmaceutical Lab Equipment Requisition Form - Help Guide
## Purpose
This form is used to request new pharmaceutical lab equipment for lab operations and maintenance.
## How To Complete This Form
To complete the form, follow these steps:
1. Fill out the form in multiple pages (First Page, Second Page, Third Page).
2. Answer each question carefully and thoroughly.
## Field-by-Field Explanation

* **First Page**
	+ **Equipment Type (required)** (`title`, `text`, required): Please enter the name of the equipment being requested.
	+ This field is the first page of the form and requires the most basic information about the requested equipment.
* **Second Page**
	+ **Request Status** (`page_2`, `select_one`, required): Choose 'Yes' if you want to request the new equipment, or 'No' if you do not.
	+ This field is used to determine if the user wants to request the equipment or not.
* **Date of Request** (`page_3`, `date`, required): Enter the date you would like to start using the new equipment.
	+ This field is used to determine when you would like to start using the new equipment.

## Tips
Please make sure to fill out the form carefully and accurately. If you have any questions or concerns, contact your supervisor or the lab administrator.
