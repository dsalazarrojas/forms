# hotel_new_property_order_request_form - Help Guide
## Purpose
This form is used to request information about a new property order. It gathers details about the property, vendor, project, and contact information.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the requested information in the provided fields.
2. Ensure the required fields are completed before submitting the form.

## Field-by-Field Explanation
* **Form Information** (`form_info`, text, optional): 
Enter a brief description of the property order request.
* **Vendor Information** (`vendor_info`, text, optional): 
Enter the vendor's name or contact information related to the property order.
* **Project Information** (`project_info`, text, optional): 
Enter the project's name or identifier related to the property order.
* **Property Information** (`property_info`, text, optional): 
Enter a brief description of the property being ordered.
* **Contact Information** (`contact_info`, text, optional): 
Enter your contact information for communication purposes.
* **Vendors Contacts** (`vendor_contacts`, select multiple, optional): 
Select any vendors you would like to contact for this property order.
* **Project Contacts** (`project_contacts`, select multiple, optional): 
Select any project contacts you would like to contact for this property order.
* **Order Details** (`order_details`, text, optional): 
Enter any additional details or comments about the property order.
* **Property Status** (`property_status`, select one, optional): 
Select the current status of the property (e.g., Option 1, Option 2, Option 3, Option 4, Option 5).
* **Property Type** (`property_type`, select one, optional): 
Select the type of property being ordered (e.g., Option 1, Option 2, Option 3, Option 4).
* **Property Address** (`property_address`, text, optional): 
Enter the physical address of the property.
* **Project Start Date** (`project_start_date`, date, optional): 
Enter the start date of the project related to the property order.
* **Project End Date** (`project_end_date`, date, optional): 
Enter the end date of the project related to the property order.
