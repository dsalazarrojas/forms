# Toy Production Molds Requisition Form - Help Guide
## Purpose
This form is used for customers to request toy production molds from the production team. It's essential to provide accurate information to ensure that the production process runs smoothly and that the requested molds meet the customer's needs.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the customer's name and customer PO number.
2. Enter the production date of the requested molds.
3. If required, select the production time.
4. Provide details about the production molds required.
5. Optionally, provide any additional information or comments about the production molds.

## Field-by-Field Explanation
* **item_number** (`item_number`, text, not required): Enter the item number associated with the customer's request, if applicable.
* **customer** (`customer`, text, required): Enter the name of the customer who is requesting the toy production molds.
* **customer_po_number** (`customer_po_number`, text, required): Enter the customer's purchase order (PO) number.
* **production_molds_details** (`production_molds_details`, text, not required): Describe the production molds required, including the type of materials and any specific features or requirements.
* **production_date** (`production_date`, date, required): Enter the date of production for the requested molds.
* **production_time** (`production_time`, time, not required): Select the time of production, if applicable.
* **Material** (`toy_production_molds_requisition_form_3`, text, not required): Optionally, provide additional details about the material required for the production molds.
