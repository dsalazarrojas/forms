# pharmacy_seasonal_medications_order_request_form - Help Guide
## Purpose
The pharmacy_seasonal_medications_order_request_form is used to order seasonal medications for customers. This form ensures that the customer's needs are accurately documented and communicated to relevant teams within the pharmacy.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the "Pharmacy Seasonal Medications Order Request Form" title to describe the purpose of the form.
2. Provide a brief description of the customer's needs in the "Description" field.
3. Select the relevant category for the order in the "Category" field.
4. Enter the customer's name in the "Customer Name" field.
5. Enter the customer's phone number in the "Phone" field.
6. Enter the customer's email address in the "E-mail" field.
7. Indicate if the customer needs any seasonal medications in the "Medications" field.
8. Select the priority of the order in the "Priority" field.

## Field-by-Field Explanation

* **Pharmacy Seasonal Medications Order Request Form** (`form_title`, text, required/optional): Enter a brief title to describe the purpose of the form.
* **Description** (`form_description`, text, required/optional): Provide a brief description of the customer's needs.
* **Category** (`form_category`, text, required/optional): Select the relevant category for the order.
* **Customer Name** (`form_customer_name`, text, required/optional): Enter the customer's name.
* **Phone** (`form_phone`, text, required/optional): Enter the customer's phone number.
* **E-mail** (`form_email`, email, required/optional): Enter the customer's email address.
* **Medications** (`form_medications`, select_multiple, required/optional): Indicate if the customer needs any seasonal medications.
* **Priority** (`form_priority`, select_one, required/optional): Select the priority of the order.

## Tips
- Make sure to accurately document the customer's needs in the "Description" field.
- Select the relevant category in the "Category" field.
- Ensure that the "Customer Name" field is accurate.
- Double-check the "Phone" and "E-mail" fields for correct contact information.
- Clearly indicate if the customer needs any seasonal medications in the "Medications" field.
- Choose the correct priority for the order in the "Priority" field.
