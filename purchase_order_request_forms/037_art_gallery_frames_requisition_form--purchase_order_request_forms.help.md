# Art Gallery Frames Requisition Form - Help Guide

## Purpose
This form is for staff members to request art gallery frames for exhibitions and installations. It helps the requisitioning staff provide the necessary information for the frame team to prepare the frames according to the project requirements.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter your name and the name of the exhibition or project you are working on.
2. Select your department (Curatorial, Preparation - Installation, Operations, or Special Events).
3. Specify the total number of frames required.
4. Choose the standard sizes of frames needed (if applicable).
5. If custom sizes are required, provide the details of those sizes.
6. Select the standard gallery frame style and glazing requirement.
7. Provide the delivery and hard deadline for the project.
8. Enter your budget account code and estimated cost allocation (if applicable).
9. Approve the form by entering your supervisor's name and the date of the request.

## Field-by-Field Explanation
* **Staff Member Name**: Enter your name so that we can ensure that the project is assigned to the correct person.
* **Exhibition or Project Name**: Enter the name of the exhibition or project you are requesting the frames for.
* **Department**: Select your department to ensure that the frames are prepared by the correct team.
* **Total Number of Frames Required**: Enter the total number of frames needed for the project.
* **Select Standard Sizes (If Applicable)**: If you have standard sizes in mind, select them from the drop-down list. If not, leave this field empty.
* **Custom Size Details**: If you require custom sizes, enter the details of those sizes in this field.
* **Standard Gallery Frame Style**: Select the standard frame style you want the frames to be made of.
* **Glazing Requirement**: Select the glazing type you need for the frames.
* **Delivery - Pickup Location**: Enter the location where you want the frames to be delivered to.
* **Hard Deadline for Completion**: Enter the date by which the project needs to be completed.
* **Budget - Account Code for Allocation**: Enter your budget account code to ensure correct allocation of funds.
* **Estimated Cost Allocation**: If you have estimated costs, enter them here.
* **Supervisor - Curator Approval Name**: Approve the form by entering your supervisor's name.
* **Date of Request**: Enter the date of the request.
* **Additional Project Specific Notes**: Add any additional notes or details about the project that may be helpful for the frame team.
* **Internal Reference ID (Office Use)**: Enter any internal reference ID for office use.

## Tips
* Make sure to fill out all required fields to ensure that your request is processed correctly.
* If you are unsure about any field, please contact the frame team for assistance.
* This form is for internal use only, please do not share it with external parties.
