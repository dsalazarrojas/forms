# Forestry Survey Tools Requisition Form - Help Guide
## Purpose
The purpose of this form is to help teams in forestry departments request and identify their needed tools and equipment.

## How To Complete This Form
To complete this form, follow these steps:

1.  Select the type of tool(s) you need for your team.
2.  Choose the department where you belong.
3.  Indicate when you need the tool (if applicable).
4.  Select the team leader or person who will be using the tool.
5.  Add any additional comments about the tool request.
6.  Confirm the tool assignment.

## Field-by-Field Explanation
* **Forestry Survey Tools Requisition Form** (`text`, required/optional): Enter a brief description of the tool or equipment you are requesting.
* **Tool Type** (`select_multiple`, required/optional): Select the type of tool you need, e.g., "Tool A", "Tool B", or "Tool C".
* **Team Leader** (`select_one`, required/optional): Choose the team leader or person who will be using the tool, e.g., "Team A", "Team B", or "Team C".
* **Department** (`select_one`, required/optional): Select the department you belong to, e.g., "Department A", "Department B", or "Department C".
* **Date Requested** (`date`, required/optional): Enter the date you need the tool (if applicable).
* **Time** (`time`, required/optional): Enter the time you need the tool (if applicable).
* **Tool Requester** (`select_one`, required/optional): Select the person requesting the tool, e.g., "Jimmy", "Jane", or "John".
* **Comments** (`note`, required/optional): Add any additional comments about the tool request.
* **Assigned Tool** (`select_one`, required/optional): Confirm the assigned tool after selection.

## Tips
* Make sure to fill out all necessary fields to ensure prompt processing of your request.
* If you're requesting a tool for an event, please specify the event name or description.
* For multiple tool requests, fill out separate forms or add comments to the comments field.
