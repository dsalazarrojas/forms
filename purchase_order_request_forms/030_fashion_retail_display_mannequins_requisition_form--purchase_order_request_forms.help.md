# Fashion Retail Display Mannequins Requisition Form - Help Guide
## Purpose
The Fashion Retail Display Mannequins Requisition Form is used to request new mannequins for display purposes in the retail setting. This form helps in tracking and managing mannequin requests, ensuring that the right person receives the request and the necessary information is provided.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the required fields as accurately as possible.
2. Ensure that you select the correct category for the form.
3. Enter the form title and description.
4. Choose the requested date for the form.
5. Choose the date the form should be delivered.
6. Check the form status (if applicable).
7. Fill in any additional comments or information.
8. Finally, select the person assigned to handle the form.

## Field-by-Field Explanation

* **Form ID (1)**: Enter a unique identifier for the form to keep track of requests.
* **Form Title (2)**: Briefly describe the purpose of the form.
* **Form Category (3)**: Select "Purchase Order Request Forms" to categorize the form as a request for mannequins.
* **Form Description (4)**: Provide a short description of the mannequins being requested.
* **Form Requested By (5)**: Enter the name of the person or department requesting the form.
* **Form Requested Date (6)**: Enter the date when the mannequins were requested.
* **Form Delivery Date (7)**: Enter the expected date for the delivery of the mannequins.
* **Form Status (8)**: If the form is in progress or completed, select the correct status.
* **Form Comments (9)**: Enter any additional comments or information about the mannequins.
* **Form Location (10)**: Enter the location where the mannequins are needed.
* **Form Additional Comments (11)**: Enter any extra comments or information about the mannequins.
* **Form Additional Info (12)**: Enter any additional information about the mannequins.
* **Form Additional Notes (13)**: Enter any additional notes about the mannequins.
* **Form Assigned To (14)**: Select the person or department that will handle the form and ensure the mannequins are delivered correctly.
