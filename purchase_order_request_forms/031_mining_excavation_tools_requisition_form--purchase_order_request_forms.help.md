# Mining Excavation Tools Requisition Form - Help Guide
## Purpose
The Mining Excavation Tools Requisition Form is a tool request submission form for site managers or other personnel responsible for managing site resources. Use this form to request excavation tools for mining activities. Ensure that each request is legitimate and not for testing or duplicate purposes.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the required fields with accurate information.
2. Ensure that you have permission to submit requests on behalf of the site.
3. Double-check your submission for accuracy before submitting.

## Field-by-Field Explanation
### **Tool Id** (`tool_id`, Number, Optional)
Enter the unique identifier for the requested tool, if applicable.

### **Tool Name** (`tool_name`, Text, Optional)
Enter the name of the tool being requested.

### **Category** (`category`, Text, Optional)
Specify the category of the tool being requested.

### **Quantity** (`quantity`, Number, Optional)
Enter the quantity of the tool required.

### **Unit Price** (`unit_price`, Number, Optional)
Enter the unit price of the tool.

### **Unit of Measurement** (`unit_of_measurement`, Text, Optional)
Specify the unit of measurement for the tool.

### **Total Cost** (`total_cost`, Number, Optional)
Enter the total cost of the tool request.

### **Requisition Date** (`requisition_date`, Text, Optional)
Enter the date the tool is required.

### **Delivery Date** (`delivery_date`, Text, Optional)
Enter the date the tool is expected to be delivered.

### **Remarks** (`remarks`, Text, Optional)
Add any additional comments or notes regarding the tool request.

### **Email** (`email`, Text, Optional)
Enter your contact email.

### **Phone** (`phone`, Text, Optional)
Enter your contact phone number.

### **Site Name** (`site_name`, Text, Optional)
Enter the site name where the tool will be used.

### **Site Location** (`site_location`, Text, Optional)
Enter the location of the site where the tool will be used.

### **Site Manager Name** (`site_manager_name`, Text, Optional)
Enter the name of the site manager.

### **Site Manager Phone** (`site_manager_phone`, Text, Optional)
Enter the phone number of the site manager.

### **Site Manager Email** (`site_manager_email`, Text, Optional)
Enter the email of the site manager.

### **Site Manager Remarks** (`site_manager_note`, Text, Optional)
Add any additional comments from the site manager.

### **Submitting Person** (`submitting_person`, Text, Optional)
Enter your name.

### **Submitter Phone** (`submitter_phone`, Text, Optional)
Enter your phone number.

### **Submitter Email** (`submitter_email`, Text, Optional)
Enter your email.

Note: Ensure all fields are completed accurately and according to your needs.
