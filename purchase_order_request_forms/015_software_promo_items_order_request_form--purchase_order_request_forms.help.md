# software_promo_items_order_request_form - Help Guide
## Purpose
The software_promo_items_order_request_form is a form used to request software and promotional items for events, meetings, or other activities. It helps collect necessary information in one place to streamline the request process.

## How To Complete This Form
To complete this form, please fill out all the required fields. You can find the fields explained below.

## Field-by-Field Explanation

* **Shipping Details** (`shipping_details`): Enter the shipping details for the items, such as a name, address, city, state, zip code, and phone number.
* **Item Info** (`item_info`): Describe the item you are requesting.
* **Needed By** (`needed_by`): Enter the date when you need the item (YYYY-MM-DD).
* **Report** (`report`): Select the team that will be receiving the report (Marketing Team, HR Team, Event Team, or Other).
* **Item Quantity** (`item_quantity`): Enter the quantity of the item you need.
* **Item Name** (`item_name`): Enter a name for the item.
* **Item Description** (`item_description`): Describe the item.
* **Shipping Method** (`shipping_method`): Select the shipping method (FedEx, USPS, UPS).
* **Shipping Address** (`shipping_address`): Enter the shipping address.
* **Shipping City** (`shipping_city`): Enter the city for the shipping address.
* **Shipping State** (`shipping_state`): Enter the state for the shipping address.
* **Shipping Zip** (`shipping_zip`): Enter the zip code for the shipping address.
* **Shipping Phone** (`shipping_phone`): Enter the phone number for the shipping address.
* **Shipping Email** (`shipping_email`): Enter the email for the shipping address.
* **Event Name** (`event_name`): Enter the name of the event or meeting.
* **Event Date** (`event_date`): Enter the date of the event (YYYY-MM-DD).
* **Event Time** (`event_time`): Enter the time of the event.
* **Event Location** (`event_location`): Enter the location of the event.
* **Event Notes** (`event_notes`): Enter any notes about the event.
* **Event Team** (`event_team`): Select the team that will be receiving the report (Marketing Team, HR Team, Other).
* **Item Type** (`item_type`): Select the type of item (Software, Gift, Other).
* **Item Category** (`item_category`): Enter the category of the item.
* **Item Status** (`item_status`): Enter the status of the item.
* **Item Priority** (`item_priority`): Enter the priority of the item.
* **Item Notes** (`item_notes`): Enter any notes about the item.

Note: Fields marked as `required: false` are optional and can be left blank if not applicable. Ensure you have filled out all required fields to submit the form correctly.
