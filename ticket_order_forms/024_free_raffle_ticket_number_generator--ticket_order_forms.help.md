# Free Raffle Ticket Number Generator - Help Guide

## Purpose
This form is designed to generate free raffle ticket numbers for events or promotions. It's intended for organizers to quickly and easily create random ticket numbers for their raffle drawings.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the required and optional fields as needed:
	* Raffle Ticket Generator: Enter a brief description of the raffle (e.g., "Christmas Promotion Raffle" or "Grand Opening Sale").
	* Ticket Number: Enter the number of tickets to be generated (optional, default value will be used if left blank).
	* Raffle ID: Enter a unique identifier for the raffle (optional, default value will be used if left blank).
	* Draw Date: Enter the date of the raffle drawing (optional, default value will be used if left blank).

## Field-by-Field Explanation
### Raffle Ticket Generator
* **Raffle Ticket Generator** (`raffle_ticket_generator`, text, required): Enter a brief description of the raffle.
### Ticket Number
* **Ticket Number** (`ticket_number`, number, optional): Enter the number of tickets to be generated. If left blank, the default value of 10 will be used.
### Raffle ID
* **Raffle ID** (`raffle_id`, number, optional): Enter a unique identifier for the raffle. If left blank, the default value of 1 will be used.
### Draw Date
* **Draw Date** (`draw_date`, date, optional): Enter the date of the raffle drawing. If left blank, the default value of today's date will be used.

## Tips
* Make sure to fill in all required fields to ensure accurate raffle ticket generation.
* Use the Raffle ID and Draw Date to keep track of different raffle drawings and ensure they are not confused with one another.
