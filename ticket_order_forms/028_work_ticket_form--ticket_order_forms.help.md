# Work Ticket Form - Help Guide
## Purpose
The Work Ticket Form is used to create new work tickets for various tasks and issues.
## How To Complete This Form
To complete this form, follow these steps:
1. Select the type of ticket you want to create.
2. Provide a brief description of the task or issue.
3. Enter the date when the task or issue is due.
4. Choose the time when you want to start working on the task.
5. Assign the ticket to a team member or team.
6. Set the due date for the task.
7. Select the status of the ticket.
8. Choose the priority level of the task.
9. Add any relevant comments.
10. Enter the email address and phone number of the person responsible for the task.

## Field-by-Field Explanation
* **Ticket Type**: Select the type of ticket you want to create (e.g., bug, feature, enhancement).
* **Description**: Provide a brief description of the task or issue.
* **Date**: Enter the date when the task or issue is due.
* **Time**: Choose the time when you want to start working on the task.
* **Assigned To**: Choose the team member or team that will handle the task.
* **Due Date**: Set the due date for the task.
* **Status**: Select the status of the ticket (e.g., new, in progress, completed).
* **Priority**: Choose the priority level of the task (e.g., high, medium, low).
* **Comment**: Add any relevant comments about the task or issue.
* **Email**: Enter the email address of the person responsible for the task.
* **Phone**: Enter the phone number of the person responsible for the task.
