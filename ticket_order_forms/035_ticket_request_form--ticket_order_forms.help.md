# Ticket Request Form - Help Guide

## Purpose
The Ticket Request Form is designed to be a straightforward, user-friendly way to submit tickets for events, meetings, or any other purposes where a ticket is required. This form will guide you through the necessary information for a successful submission.

## How To Complete This Form
1. Ensure you have all required information before starting the form. 
2. Select the relevant ticket type for your request.
3. Complete the form by providing all requested details.
4. Enter a valid event date in the specified format (DD/MM/YYYY).
5. Enter your event venue details, if applicable.
6. Input the ticket price, if applicable.
7. Provide the number of tickets you are requesting.
8. Enter your contact number.
9. Enter your email address.
10. Enter the event time.
11. Add a brief note about your ticket request (optional).
12. Add any additional notes about the ticket requester (optional).
13. Review your information before submitting.
14. Click the "Submit" button to submit your ticket request.

## Field-by-Field Explanation
- **Ticket Type (id: 2)**: This field is to select if you are requesting a single ticket or multiple tickets.
  - **Ticket Type** (`Single`, `Group`, `Both`): Select the type of ticket you need.
- **Event Date (id: 3)**: This field is for the date of your event. Please use the format DD/MM/YYYY.
- **Event Venue (id: 4)**: This field is for the event location, if applicable.
- **Ticket Price (id: 5)**: This field is for the price of each ticket, if applicable.
- **Number of Tickets (id: 6)**: This field is for how many tickets you need.
- **Contact Number (id: 7)**: This is your contact number for follow-up.
- **Email Address (id: 8)**: This field is for your email address, which will be the primary method of communication.
- **Event Time (id: 9)**: This field is for the time of your event.
- **Ticket Requester Form (id: 1)**: A note field where you can add any additional information about your ticket request.
- **Ticket Requester Phone (id: 12)**: This field is for adding your contact phone number.
- **Ticket Requester Email (id: 13)**: This field is for adding any other email address for communication.
- **Ticket Requester Address (id: 14)**: This field is for your contact address.
- **Ticket Requester Note (id: 15)**: A note field where you can add any additional information about yourself.

## Tips
- Ensure you have all necessary information before submitting the form.
- Be as accurate as possible when filling out the form.
- Use the format specified for date and event time fields.
- If you're unsure, consult with your event organizer or the ticketing system's administrators.
- Review your information carefully before submitting.
