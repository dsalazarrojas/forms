# Raffle Ticket Form - Help Guide
## Purpose
The Raffle Ticket Form is designed to collect and manage data for raffle tickets, including ticket details, payment information, and drawing dates and times. This form is intended for users to input ticket information, select payment methods, and track ticket status and payment status.

## How To Complete This Form

1. **Enter Raffle Ticket ID**: Enter the unique ID for the raffle ticket. This field is not required.
2. **Enter Name**: Input the name of the ticket holder or participant. This field is not required.
3. **Enter Email**: Enter the email address of the ticket holder or participant. This field is not required.
4. **Enter Phone**: Input the phone number of the ticket holder or participant. This field is not required.
5. **Enter Order Notes**: Add any additional notes or comments about the ticket order. This field is not required.
6. **Select Ticket Quantity**: Choose the number of tickets to purchase. This field is not required.
7. **Select Ticket Price**: Choose the price of the ticket. This field is not required.
8. **Select Payment Method**: Choose the payment method from the dropdown list. Options include:
	* Stripe
	* PayPal
	* Bank Transfer
9. **Other (payment method)**: If selecting "Other (payment method)", input the alternative payment method. This field is not required.
10. **Raffle Draw Date**: Select the date of the raffle draw. This field is not required.
11. **Raffle Draw Time**: Select the time of the raffle draw. This field is not required.
12. **Select Ticket Status**: Choose the status of the ticket from the dropdown list. Options include:
	* Unclaimed
	* Claimed
	* Voided
13. **Select Payment Status**: Choose the payment status from the dropdown list. Options include:
	* Pending
	* Paid
	* Refunded
14. **Ticket Number**: Enter the unique number of the raffle ticket. This field is not required.
15. **Order ID**: Input the ID of the order. This field is not required.
16. **Order URL**: Input the URL of the order. This field is not required.
17. **Select Order Status**: Choose the status of the order from the dropdown list. Options include:
	* Paid
	* Pending
	* Refunded
