# ticket_order_form - Help Guide
## Purpose
The ticket_order_form is a form used to collect event ticket order information from users.

## How To Complete This Form
To complete this form, follow these steps:

1. Ensure you have all the necessary information about the event you wish to order tickets for.
2. Select the event package you wish to order from the options provided.
3. Enter the quantity of tickets you wish to order.
4. Add any notes about the event or order if necessary.
5. Enter the email address associated with the order.
6. Enter the phone number associated with the event (if applicable).
7. Enter the date and time of the event (if applicable).
8. Click the "Submit" button to complete the order.

## Field-by-Field Explanation

* **Event Details (Event Details)**: A text input field where you can enter the event details, such as the event name, location, or description.
* **Event Package (Event Package)**: A dropdown menu where you can select the package you wish to order. Choose from:
	+ standard: The standard package.
	+ premium: The premium package.
	+ basic: The basic package.
* **Quantity (Quantity)**: A number input field where you can enter the quantity of tickets you wish to order.
* **Notes (Notes)**: A text input field where you can add any additional notes or comments about the order.
* **Email (Email)**: An email input field where you can enter the email address associated with the order.
* **Phone (Phone)**: A text input field where you can enter the phone number associated with the event (if applicable).
* **Date (Date)**: A date input field where you can enter the date of the event (if applicable).
* **Time (Time)**: A time input field where you can enter the time of the event (if applicable).
* **Submit (Submit)**: A button to complete and submit the order.

Note: The email and phone fields are optional and should only be filled if applicable to the event. The date and time fields are also optional and should only be filled if the event has a specific date and time.
