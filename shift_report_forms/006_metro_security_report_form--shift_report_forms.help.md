# Metro Security Report Form - Help Guide
## Purpose
The Metro Security Report Form is designed for reporting security incidents, collecting various information about the incident, and its location, and the reporting officer's details.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the "Shift Report Form Data" section with a brief description of the incident.
2. Select the type of incident (e.g., "Yes" or "No").
3. Enter a brief description of the incident and its location.
4. Provide as much information as possible about the incident.
5. Select the threat level (e.g., "High" or "Low") and provide a brief description.
6. Choose the security threat category.
7. Select the status of the incident (e.g., "Active" or "Inactive").
8. Enter the incident's date, time, last updated date, and time.
9. Attach any relevant files (image, audio, video, document, or attachment).
10. Fill in the reporting officer's name, contact information, and organization.
11. Finally, confirm that the incident is reported (i.e., select "Yes" or "No").

## Field-by-Field Explanation
* **Shift Report Form Data**: Enter a brief description of the incident.
* **Incident Type**: Select the type of incident (e.g., "Yes" or "No").
* **Incident Description**: Enter a brief description of the incident and its location.
* **Incident Date**: Enter the date of the incident.
* **Incident Time**: Enter the time of the incident.
* **Reporting Officer Name**: Enter your name.
* **Reporting Officer Contact Info**: Enter your contact information.
* **Reporting Officer Organization**: Enter your organization's name.
* **Reporting Officer Email**: Enter your email.
* **Incident Location**: Enter the location of the incident.
* **Incident Details**: Provide as much information as possible about the incident.
* **Reporting Reason**: Select why you are reporting this incident (e.g., "Yes" or "No").
* **Incident Image**: Attach a file of the incident image.
* **Incident Audio**: Attach a file of the incident audio.
* **Incident Video**: Attach a file of the incident video.
* **Incident Document**: Attach a file of the incident document.
* **Incident Attachment**: Attach a file of the incident attachment.
* **Security Threat Level**: Select the threat level (e.g., "High" or "Low").
* **Threat Level Description**: Enter a brief description of the threat level.
* **Security Threat Category**: Enter the security threat category.
* **Security Category Description**: Enter a brief description of the security category.
* **Incident Reporting Status**: Select the status of the incident (e.g., "Active" or "Inactive").
* **Incident Reporting Date**: Enter the date when the incident was reported.
* **Incident Last Updated Date**: Enter the date when the incident was last updated.
* **Incident Last Updated Time**: Enter the time when the incident was last updated.

## Tips
* Make sure to fill in all required fields.
* Attach any relevant files to support your report.
* Double-check your information before submitting the form.
