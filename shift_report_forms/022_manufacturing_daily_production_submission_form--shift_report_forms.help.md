## Field-by-Field Explanation
*   **Daily Production**: Enter the name of the daily production report.
*   **Defects**: List any defects or issues encountered during the shift.
*   **Downtime**: Enter any downtime events.
*   **Lines**: Select the production lines involved using the dropdown menu.
*   **Shift**: Indicate if the shift involved manufacturing operations using the dropdown menu. 
    Options: Yes, No
*   **Shift Start Time**: Enter the start time of the shift in 24-hour format (e.g., 08:00).
*   **Shift End Time**: Enter the end time of the shift in 24-hour format (e.g., 17:00).
*   **Output**: Enter the total output for the shift.
*   **Defect Description**: Provide a brief description of any defects.
