# Staff Coverage Request Form - Help Guide
## Purpose
This form is used to request coverage for shifts that a staff member is unable to work.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the date of the shift for which you are requesting coverage.
2. Choose the start time of the shift.
3. Indicate whether a staff member is available to cover the shift (`Yes` or `No`).
4. Choose the type of coverage being requested (`Regular`, `Emergency`, `Vacation`, or `Sick`).
5. Enter the length of the shift.
6. Add any additional notes about the request.
7. Select whether the request has been approved or declined (`Approve`, `Decline`, `Request More Info`).
8. Confirm whether the manager has approved the request (`Yes` or `No`).
9. Add any comment from the manager.
10. Add any comment about the request.

## Field-by-Field Explanation

* **shift_date** (Date, **Yes/No**): Enter the date of the shift for which you are requesting coverage. Selecting a date will trigger the start and end times of the shift to be calculated.
* **start_time** (Time, **Yes/No**): Choose the start time of the shift.
* **staff_member** (Select One, **Yes/No**): Indicate whether a staff member is available to cover the shift.
* **coverage_type** (Select One, **Yes/No**): Choose the type of coverage being requested.
* **shift_length** (Number, **Yes/No**): Enter the length of the shift.
* **shift_note** (Note, **Yes/No**): Add any additional notes about the request.
* **approval_status** (Select One, **Yes/No**): Select whether the request has been approved or declined.
* **manager_approval** (Select One, **Yes/No**): Confirm whether the manager has approved the request.
* **manager_comment** (Text, **Yes/No**): Add any comment from the manager.
* **requester_comment** (Text, **Yes/No**): Add any comment about the request.
* **shift_requester** (Select One, **Yes/No**): Indicate whether the request is made by the staff member who normally works the shift.
