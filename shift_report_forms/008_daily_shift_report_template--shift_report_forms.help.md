# Daily Shift Report Template - Help Guide
## Purpose
This template is used to document daily shifts, track assigned tools, and update their status. It is designed for companies that assign tools to employees for their shifts.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the required information such as employee name, shift start and end time, location, and shift type.
2. Select the assigned tool and update its status.
3. Add any comments or notes related to the shift.
4. Update the shift status and assigned tool status.

## Field-by-Field Explanation

- **Employee Name**: Enter the name of the employee who worked the shift.
- **Shift Start Time**: Enter the start time of the shift in 24-hour format (e.g., 08:00).
- **Shift End Time**: Enter the end time of the shift in 24-hour format (e.g., 16:00).
- **Shift Date**: Enter the date of the shift.
- **Location**: Enter the location where the shift was performed.
- **Shift Type**: Select the type of shift (Morning, Afternoon, Evening, or Night).
- **Notes**: Add any comments or notes related to the shift.
- **Assigned To**: Select the employee(s) assigned to this shift.
- **Employee ID**: Enter the ID of the employee who worked the shift.
- **Shift Status**: Select the status of the shift (Approved, Pending, or Rejected).
- **Shift Hours**: Enter the number of hours worked for the shift.
- **Comments**: Add any comments related to the shift.
- **Shift Report Date**: Enter the date of the shift report.
- **Assigned Tool**: Enter the name of the tool assigned to the employee.
- **Assigned Tool ID**: Enter the ID of the tool assigned to the employee.
- **Tool Type**: Select the type of tool assigned (Tool 1, Tool 2, or Tool 3).
- **Tool Status**: Select the status of the tool (Active, Inactive, or Available).
- **Comments Text**: Add any comments related to the tool.
- **Assigned Tool Status**: Select the status of the tool assignment (Approved, Rejected, or Pending).
- **Assigned Shift**: Select the type of shift for which the tool was assigned (Morning, Afternoon, Evening, or Night).
- **Shift Report Status**: Select the status of the shift report (Approved, Rejected, or Pending).
