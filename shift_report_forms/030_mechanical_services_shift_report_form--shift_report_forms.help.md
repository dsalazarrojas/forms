# Mechanical Services Shift Report Form - Help Guide
## Purpose
The Mechanical Services Shift Report Form is used to record and report on mechanical services, including work orders, technician information, and customer interactions.

## How To Complete This Form

1. Ensure that all required fields are filled in accurately and completely.
2. Enter the Work Order Number to associate this report with the relevant work order.
3. Select the Service Date of the shift.
4. Enter the Technician Name who worked on the shift.
5. Enter the Shift Start Time and Shift End Time.
6. Choose the Work Order Status to reflect the current status of the work order.
7. Select all applicable Service Types for the work order.
8. Enter any Task Comments about the work order.
9. Add any Additional Comments about the shift or work order.
10. Enter the Customer Name.
11. Enter the Customer Phone Number.
12. Enter the Customer Email.
13. Select who the work order was assigned to.
14. Update the Task Complete Status.

## Field-by-Field Explanation

* **Work Order Number (1)**: Enter the unique identifier for the work order.
* **Service Date (2)**: Enter the date on which the services were provided.
* **Technician Name (3)**: Enter the name of the technician who worked on the shift.
* **Shift Start Time (4)**: Enter the start time of the shift.
* **Shift End Time (5)**: Enter the end time of the shift.
* **Work Order Status (6)**: Choose the status of the work order from the options available.
* **Service Type (7)**: Select all applicable services performed.
* **Task Comments (8)**: Add any comments about the task or work order.
* **Additional Comments (9)**: Add any other comments or information about the shift or work order.
* **Customer Name (10)**: Enter the customer's name.
* **Customer Phone (11)**: Enter the customer's phone number.
* **Customer Email (12)**: Enter the customer's email address.
* **Assigned To (13)**: Select who the work order was assigned to.
* **Task Complete Status (14)**: Update the status of the task completion.

## Tips

* Double-check all fields for accuracy and completeness before submitting the form.
* Use the options provided for fields with select options to ensure correct selections.
* If a field is not applicable, leave it blank or select the appropriate option.
* If you're unsure about any field, contact your supervisor or team lead for guidance.
