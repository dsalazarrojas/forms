# Weekly Clinic Activity Report - Help Guide
## Purpose
The Weekly Clinic Activity Report form is used to document and report on the activity of a clinic during a specific week. This includes the start and end dates of the week, the number of staff present, and any notable events or activities that took place during that time.

## How To Complete This Form
To complete this form, simply follow these steps:
- Select the Clinic Name to report on from the provided list.
- Enter the start date of the reporting week.
- Enter the end date of the reporting week.
- Enter the number of staff members present during the week.
- Provide any notable Staffing Notes about the week's activity.
- Enter a brief description of any Service Activity that took place.

## Field-by-Field Explanation
- **Clinic Name** (`clinic_name`, text, required): The name of the clinic being reported on.
- **Week Start Date** (`week_start_date`, date, required): The date the reporting week started.
- **Week End Date** (`week_end_date`, date, required): The date the reporting week ended.
- **Staff Count** (`staff_count`, number, optional): The number of staff members present during the week.
- **Staffing Notes** (`staffing_notes`, text, optional): Any notable events or activities that took place during the week.
- **Service Activity** (`service_activity`, text, optional): A brief description of any service activity that took place during the week.

## Tips
- Make sure to complete all required fields (Clinic Name, Week Start Date, Week End Date).
- Enter as much detail as possible in the Staffing Notes and Service Activity fields.
- If no staff were present during the week, enter 0 in the Staff Count field.
