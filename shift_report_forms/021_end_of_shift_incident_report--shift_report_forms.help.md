# End of Shift Incident Report - Help Guide

## Purpose
The End of Shift Incident Report is used to document incidents that occurred during a shift, ensuring that all relevant information is captured and recorded correctly. This report is essential for incident tracking, analysis, and investigation purposes.

## How To Complete This Form
To complete this form, follow these steps:

1. Determine if an incident occurred during your shift. If yes, proceed to fill out the form.
2. Select the incident type (e.g., injury, property damage, etc.) from the incident type field.
3. Enter the location where the incident occurred.
4. Provide a brief summary of the incident.
5. Offer a detailed description of the incident.
6. If available, provide a witness statement if someone or something witnessed the incident.
7. Determine if the reporting officer and reporting manager were involved in the incident or not.
8. Select the incident category (e.g., safety, environmental, etc.).
9. Indicate if the incident was severe or not.
10. Report if any injuries were sustained during the incident.
11. Report if any damages were sustained during the incident.
12. Select the type of damage (e.g., property, equipment, etc.).
13. Determine the status of the incident (e.g., active, inactive).
14. Add any additional notes about the incident if needed.
15. Enter the date and time of the report.
16. Sign and date the report as the reporting officer.
17. Sign and date the report as the reporting manager, if applicable.
18. Enter the reporting manager's name, ID, and title, if applicable.

## Field-by-Field Explanation

* **Incident Type** (`1`, `incident_type`, **required**): This field is used to categorize the type of incident that occurred during your shift.
  \- Options: 'Yes', 'No'
* **Incident Location** (`2`, `incident_location`, **required**): Enter the location where the incident occurred.
* **Incident Summary** (`3`, `incident_summary`, **required**): Provide a brief summary of the incident.
* **Incident Description** (`4`, `incident_description`, **required**): Offer a detailed description of the incident.
* **Witness Statement** (`5`, `incident_witness_statement`, **optional**): If available, provide a witness statement if someone or something witnessed the incident.
* **Reporting Officer** (`6`, `reporting_officer`, **required**): Determine if you, as the reporting officer, were involved in the incident or not.
  \- Options: 'Yes', 'No'
* **Incident Category** (`7`, `incident_category`, **required**): Select the category of the incident (e.g., safety, environmental, etc.).
  \- Options: 'Yes', 'No'
* **Incident Severity** (`8`, `incident_severity`, **required**): Indicate if the incident was severe or not.
  \- Options: 'Yes', 'No'
* **Incident Injuries** (`9`, `incident_injuries`, **required**): Report if any injuries were sustained during the incident.
  \- Options: 'Yes', 'No'
* **Incident Damages** (`10`, `incident_damages`, **required**): Report if any damages were sustained during the incident.
  \- Options: 'Yes', 'No'
* **Incident Damage Type** (`11`, `incident_damage_type`, **required**): Select the type of damage (e.g., property, equipment, etc.).
  \- Options: 'Yes', 'No'
* **Incident Status** (`12`, `incident_status`, **required**): Determine the status of the incident (e.g., active, inactive).
  \- Options: 'Yes', 'No'
* **Incident Notes** (`13`, `incident_notes`, **optional**): Add any additional notes about the incident if needed.
* **Reporting Date** (`14`, `reporting_date`, **required**): Enter the date of the report.
* **Reporting Time** (`15`, `reporting_time`, **required**): Enter the time of the report.
* **Reporting Officer Signature** (`16`, `reporting_officer_signature`, **required**): Sign and date the report as the reporting officer.
* **Reporting Manager Signature** (`17`, `reporting_manager_signature`, **required**): Sign and date the report as the reporting manager, if applicable.
* **Reporting Manager Name** (`18`, `reporting_manager_name`, **optional**): Enter the reporting manager's name, if applicable.
* **Reporting Manager ID** (`19`, `reporting_manager_id`, **optional**): Enter the reporting manager's ID, if applicable.
* **Reporting Manager Title** (`20`, `reporting_manager_title`, **optional**): Enter the reporting manager's title, if applicable.
