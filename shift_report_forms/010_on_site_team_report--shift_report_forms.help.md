# On Site Team Report - Help Guide
## Purpose
The On Site Team Report form is used to collect information about on-site team progress, issues, and other relevant details.

## How To Complete This Form
To complete this form, please follow these steps:

1. Enter the **Site Name** of the location where the team is working.
2. List the **Team Members** who are part of the team.
3. Enter the **Start Time** and **End Time** of the shift, using the correct time format (e.g., 08:00 for 8:00 am).
4. Enter the **Site Address**, including the street address, city, state, and zip code.
5. Add any **Site Notes** about the site, such as issues or concerns.
6. Choose the **Task Progress** from the drop-down menu, using one of the following options:
	* 1
	* 2
	* 3
7. Select the **Shift Activity** from the drop-down menu, using one or more of the following options:
	* 1
	* 2
	* 3
8. Enter the **Site Updates** date, in the format MM/DD/YYYY.
9. Add any additional **Task Updates**.
10. Enter the name of the person the task is **Assigned To**.
11. Enter the **Supervisor Name**, **Supervisor Phone**, and **Supervisor Email** of the person responsible for overseeing the task.

## Field-by-Field Explanation

* **Site Name**: Enter the name of the location where the team is working.
* **Team Members**: List the names of all team members who are part of the team.
* **Start Time**: Enter the start time of the shift, using the correct time format (e.g., 08:00 for 8:00 am).
* **End Time**: Enter the end time of the shift, using the correct time format (e.g., 17:00 for 5:00 pm).
* **Site Address**: Enter the street address, city, state, and zip code of the site.
* **Site Notes**: Add any additional notes about the site, such as issues or concerns.
* **Task Progress**: Choose the progress of the task from the drop-down menu:
	* 1
	* 2
	* 3
* **Shift Activity**: Select the activity from the drop-down menu:
	* 1
	* 2
	* 3
* **Site Updates**: Enter the date of the site update, in the format MM/DD/YYYY.
* **Task Updates**: Add any additional task updates.
* **Assigned To**: Enter the name of the person assigned to the task.
* **Supervisor Name**: Enter the name of the supervisor responsible for overseeing the task.
* **Supervisor Phone**: Enter the phone number of the supervisor.
* **Supervisor Email**: Enter the email of the supervisor.
