# Temporary Work Contract Extension Form - Help Guide
## Purpose
The Temporary Work Contract Extension Form is used by employees to submit a request for an extension of their temporary work contract. The form collects information about the employee's personal details, contract terms, and employment status.

## How To Complete This Form
1. Review the form sections and fields carefully to ensure you understand the information required.
2. Fill out the form accurately and thoroughly, providing all necessary information.
3. Ensure you sign and date the form to confirm your agreement.

## Field-by-Field Explanation

* **Employee Data** (`employee_data`, text, not required):
	+ This section is used to provide personal information about the employee.
* **Contract Details** (`contract_details`, text, not required):
	+ This section is used to describe the temporary work contract, including its terms and conditions.
* **Contract Terms** (`contract_terms`, text, not required):
	+ This section is used to list any specific terms or conditions of the temporary work contract.
* **Employee Consent** (`employee_consent`, text, not required):
	+ This section is used to obtain the employee's consent for the contract extension.
* **Employer Details** (`employer_details`, text, not required):
	+ This section is used to provide information about the employer's requirements or agreements.
* **Employee Signature** (`employee_signature`, text, not required):
	+ This section is used to sign and date the form to confirm your agreement.
* **Employer Signature** (`employer_signature`, text, not required):
	+ This section is used to sign and date the form to confirm your agreement.
* **Contract Start Date** (`contract_start_date`, date, not required):
	+ This section is used to indicate the start date of the temporary work contract.
* **Contract End Date** (`contract_end_date`, date, not required):
	+ This section is used to indicate the end date of the temporary work contract.
* **Contract Reason** (`contract_reason`, text, not required):
	+ This section is used to describe the reason for the contract extension.
* **Contract Status** (`contract_status`, select_multiple, not required):
	+ This section is used to select the current employment status (Active, Inactive, Terminated).
* **Assigned User** (`assigned_user`, text, not required):
	+ This section is used to provide information about the user assigned to the contract.
* **Submitted By** (`submitted_by`, text, not required):
	+ This section is used to identify the person submitting the form.
* **Created By** (`created_by`, text, not required):
	+ This section is used to identify the person creating the form.
* **Updated By** (`updated_by`, text, not required):
	+ This section is used to identify the person updating the form.
* **Created At** (`created_at`, date, not required):
	+ This section is used to record the date and time the form was created.
* **Updated At** (`updated_at`, date, not required):
	+ This section is used to record the last update date and time.
* **Submitted At** (`submitted_at`, date, not required):
	+ This section is used to record the date and time the form was submitted.
* **Form Id** (`form_id`, text, not required):
	+ This section is used to provide a unique ID for the form.
* **Form Title** (`form_title`, text, not required):
	+ This section is used to provide a title for the form.
* **Form Category** (`form_category`, text, not required):
	+ This section is used to categorize the form.
* **Form Description** (`form_description`, text, not required):
	+ This section is used to provide a description of the form.
* **Assigned Tool** (`assigned_tool`, text, not required):
	+ This section is used to provide information about the tool assigned to the form.
* **Form Output File** (`form_output_file`, text, not required):
	+ This section is used to provide a link to the form output file.
* **Notes** (`notes`, note, not required):
	+ This section is used to provide additional comments or notes about the form.

Please note that some fields are not required, so ensure you fill out only the necessary information. If you have any questions or concerns, please contact [support email] (form@gic.mx).
