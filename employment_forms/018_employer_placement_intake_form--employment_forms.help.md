# employer_placement_intake_form - Help Guide
## Purpose
The purpose of this form is to collect information from employers about their job placement requests. This information will be used to manage and track job placements in the system.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out each page of the form, providing the requested information for each section.
2. Make sure to provide accurate and up-to-date information.
3. Review your answers carefully before submitting the form.

## Field-by-Field Explanation

* **Placement Request (id: 6)**:
	+ This is the main section for the job placement request. 
	+ Enter a brief description of the job or placement request.
* **Employer Name (id: 7)**:
	+ Enter the name of the employer requesting the job placement.
* **First Name (id: 8)**:
	+ Enter the first name of the contact person.
* **Last Name (id: 9)**:
	+ Enter the last name of the contact person.
* **Job Title (id: 10)**:
	+ Enter a detailed description of the job title.
* **Job Description (id: 11)**:
	+ Enter a detailed description of the job description.
* **Company (id: 12)**:
	+ Enter the name of the company requesting the job placement.
* **Job Location (id: 13)**:
	+ Enter the location of the job.
* **Job Type (id: 14)**:
	+ Select the type of job (e.g., Full-time, Part-time, etc.).
* **Job Shift (id: 15)**:
	+ Enter the job shift or schedule.
* **Employment Type (id: 16)**:
	+ Select the type of employment (e.g., Full-time, Part-time, etc.).
* **Job Status (id: 17)**:
	+ Select the current status of the job (e.g., Active, Passive, etc.).
* **Job Status Note (id: 18)**:
	+ Enter any additional information about the job status.
* **Job Posting Type (id: 19)**:
	+ Select the type of job posting (e.g., Agency, Client, etc.).
* **Job Category (id: 20)**:
	+ Enter the category of the job.
* **Job Posting Source (id: 21)**:
	+ Enter the source of the job posting.
* **Job Posting Date (id: 22)**:
	+ Enter the date of the job posting.
* **Job Application Deadline (id: 23)**:
	+ Enter the deadline for job applications.
* **Street (id: 24)**:

* **City (id: 25)**:

* **State (id: 26)**:
	+ Enter the state of the contact person.
* **Zip (id: 27)**:

	+ Enter the country of the contact person.
* **Email (id: 29)**:

* **Phone (id: 30)**:
	+ Enter the phone number of the contact person.
