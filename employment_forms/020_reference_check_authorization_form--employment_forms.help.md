# Reference Check Authorization Form - Help Guide
## Purpose
The Reference Check Authorization Form is used to collect information about an employee's work history, including their reference checks. It's essential to complete this form accurately and thoroughly to provide a complete picture of the employee's work history.

## How To Complete This Form
1. Select the employee's name from the options list.
2. Enter the reference's name and job title.
3. Select the reference start and end dates.
4. Choose the reference status.
5. Enter the reference's contact phone number and email.
6. Add any additional comments or notes about the reference check.
7. If applicable, select the person who submitted the form.
8. Enter the date and time the reference check was completed.
9. Select additional comments or notes about the reference check.
10. If applicable, select additional comments or notes.

## Field-by-Field Explanation
* **Employee Name**: Select the employee's name from the options list to associate this reference check with the correct employee.
* **Reference Name**: Enter the name of the person who provided the reference.
* **Reference Title**: Enter the job title of the reference.
* **Reference Start Date**: Enter the date the reference period started.
* **Reference End Date**: Enter the date the reference period ended.
* **Reference Status**: Select the status of the reference (e.g., active, inactive, unknown).
* **Reference Check**: Enter any comments or notes about the reference check.
* **Contact Phone**: Enter the reference's phone number.
* **Contact Email**: Enter the reference's email address.
* **Reference Check Note 1**: Add any additional comments or notes about the reference check.
* **Reference Check Date**: Enter the date the reference check was completed.
* **Reference Check Time**: Enter the time the reference check was completed.
* **Reference Check Note 2**: Select additional comments or notes about the reference check.
* **Reference Check Note 3**: Select additional comments or notes about the reference check.
* **Reference Check Note 4**: Select additional comments or notes about the reference check.

## Tips
* Please ensure that you have the necessary authorization to complete this form.
* Make sure to complete the form accurately and thoroughly.
* Check with the HR department if you're unsure about any information.
* Do not duplicate any existing records.
* Complete the form for each reference check separately.
