# simple_time_sheet_form - Help Guide

## Purpose
This form is used to record and report work hours, worked hours, dates, time, and other relevant details for work-related activities. It is intended for use by employees to track and track their work schedule, hours, and activities.

## How To Complete This Form

* To complete this form, start by selecting the correct "Work Date" (field 3) by clicking on the calendar icon.
* Fill in the "Work Hours" (field 1), which indicates the number of hours worked during the selected period.
* Next, enter the "Worked Hours" (field 2), which shows the actual hours worked on that specific day.
* Select the "Work Time" (field 4) by clicking on the clock icon to enter the start and end times for the work period.
* Write a brief description of the work activity in the "Work Description" (field 5) field.
* If needed, add any additional comments or details in the "Notes" (field 6) field.

## Field-by-Field Explanation

* **Work Hours** (Field 1, Number, Optional):
  This field indicates the number of hours worked during the selected period.
* **Worked Hours** (Field 2, Number, Optional):
  This field shows the actual hours worked on the specific day.
* **Work Date** (Field 3, Date, Required):
  Select the date on which the work was performed.
* **Work Time** (Field 4, Time, Required):
  Enter the start and end times for the work period using the clock icon.
* **Work Description** (Field 5, Text, Required):
  Describe the work activity performed on that day.
* **Notes** (Field 6, Note, Optional):
  Add any additional comments or details about the work activity.
