# employment_history_release_form - Help Guide
## Purpose

This form is used to gather detailed information about an employee's past employment periods and roles.

## How To Complete This Form

To complete this form, follow these steps:

1. Fill out the employee details section with the relevant information.
2. Select the employment periods for which you want to report.
3. Choose the job titles and locations for each selected employment period.
4. Select the employment status, type, and benefits for each period.
5. Provide a brief job description for each period.
6. Enter the start and end dates for each employment period.
7. Enter the start and ending salaries for each employment period.
8. Provide a reason for termination (if applicable).
9. Enter the notice period for each employment period.
10. Finally, submit the form.

## Field-by-Field Explanation

* **Employee Details**: Enter the employee's name and any other relevant details.
* **Employment Periods**: Select all the employment periods for which you want to report.
* **Job Titles**: Choose the job titles for each employment period.
* **Job Locations**: Choose the job location for each employment period.
* **Employment Status**: Select the employment status for each period (e.g., Employed, Unemployed, etc.).
* **Employment Type**: Select the employment type for each period (e.g., Full-time, Part-time, etc.).
* **Job Description**: Enter a brief description of each job.
* **Reason for Leaving**: Enter a reason for leaving if applicable.
* **Job Length**: Enter the number of months for each employment period.
* **Start Salary**: Enter the starting salary for each employment period.
* **Ending Salary**: Enter the ending salary for each employment period.
* **Reason for Termination**: Enter a reason for termination if applicable.
* **Notice Period**: Enter the number of days for each employment period.
* **Benefits**: Select whether benefits were received or not for each period.
* **Final Salary**: Enter the final salary for each employment period.

Note: This form should only be used to gather employment history information and may not be suitable for other purposes. Please ensure you only submit the form once for each employee.
