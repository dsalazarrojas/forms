# Creative Talent Recruitment Application - Help Guide
## Purpose
The Creative Talent Recruitment Application is a form designed to gather information from creative individuals who are looking to be recruited for a job or project. It is intended for internal use within the organization and helps to streamline the recruitment process by providing a structured way to collect relevant details about the applicant's qualifications, experience, and availability.

## How To Complete This Form

To complete this form, please follow these steps:

1. Fill out the required fields, marked with an asterisk (\*).
2. Ensure that you have provided accurate and up-to-date information about your qualifications, experience, and availability.
3. Use clear and concise language when filling out the form.

## Field-by-Field Explanation

### 1. Job Title
* **Job Title**: Enter a brief description of the job or project you are applying for.
	+ Type: Text field
	+ Required: False

### 2. Contact Number
* **Contact Number**: Enter your contact number where you can be reached for further information.
	+ Type: Number field
	+ Required: False

### 3. Email
* **Email**: Enter your email address where you can be reached for further information.
	+ Type: Email field
	+ Required: False

### 4. Resume
* **Resume**: Attach your resume or CV to provide more detailed information about your qualifications and experience.
	+ Type: Text field
	+ Required: False

### 5. Portfolio Link
* **Portfolio Link**: If you have a professional portfolio, provide the link to it.
	+ Type: Text field
	+ Required: False

### 6. Work Experience
* **Work Experience**: Select your current work status from the options provided:
	+ Options: Intern, Full Time, Freelance
	+ Type: Select-one field
	+ Required: True

### 7. Education
* **Education**: This field is not currently implemented, but you can use it to provide any relevant information about your educational background.
	+ Type: Note field
	+ Required: False

### 8. Skill Tags
* **Skill Tags**: Select all the skills that you possess from the options provided:
	+ Options: Design, Development, Marketing, Writing, Photography
	+ Type: Select-multiple field
	+ Required: True

### 9. Available Date
* **Available Date**: Enter the date when you are available to start work.
	+ Type: Date field
	+ Required: False

### 10. Work Status
* **Work Status**: Select your current work status from the options provided:
	+ Options: Available, Not Available
	+ Type: Select-one field
	+ Required: True

### 11. Job Type
* **Job Type**: Select the type of job you are looking for:
	+ Options: Full Time, Part Time, Freelance
	+ Type: Select-one field
	+ Required: True

### 12. Salary Range
* **Salary Range**: Select the salary range you are expecting:
	+ Options: 20,000-30,000, 30,000-40,000, 40,000-50,000, 50,000-60,000, 60,000-70,000
	+ Type: Select-multiple field
	+ Required: True

### 13. Location
* **Location**: Select the location where you are available to work:
	+ Options: Remote, On-site, Hybrid
	+ Type: Select-one field
	+ Required: True

### 14. Job Posting Date
* **Job Posting Date**: Enter the date when the job was posted.
	+ Type: Date field
	+ Required: False

### 15. Job Description
* **Job Description**: This field is not currently implemented, but you can use it to provide any additional information about the job or project.
	+ Type: Note field
	+ Required: False

## Tips

* Please ensure that you have provided accurate and up-to-date information about your qualifications, experience, and availability.
* If you have any doubts or questions, please contact the recruitment team for further assistance.
* If you have previously applied for a job or project through this form, please do not resubmit your application.
