# Worker Skills Upgrade Request Form - Help Guide
## Purpose
The Worker Skills Upgrade Request Form is used to request an upgrade of an employee's skills.

## How To Complete This Form
To complete this form, follow these steps:

1. Determine whether you need to submit a skills upgrade request. If you are an employee, select "Yes" on the "Worker Skills Upgrade Request" page. If you are a manager, select "No".
2. Enter your employee ID and manager ID on the respective pages.
3. Fill out the "Upgrade request" field with a brief description of the skills you wish to upgrade.
4. Choose the training format you prefer.
5. Select the date and time you would like the training to take place.
6. Select the manager's approval status and enter their ID.
7. If necessary, enter any additional comments.
8. Choose the training status and whether the training has been completed.
9. If applicable, enter the training completion date and time.
10. Select the manager's approval status and the status of the form.
11. Enter any comments on the form status.

## Field-by-Field Explanation

* **Worker Skills Upgrade Request** (Select): Determine whether you need to submit a skills upgrade request, "Yes" or "No".
* **Employee Id** (Number): Enter your employee ID.
* **Manager Id** (Number): Enter your manager's ID.
* **Upgrade request** (Text): Enter a brief description of the skills you wish to upgrade.
* **Training format** (Select): Choose the format you prefer for training.
* **Date Requested** (Date): Select the date you would like the training to take place.
* **Time Requested** (Time): Select the time you would like the training to take place.
* **Manager Approval** (Number): Select the manager's approval status.
* **Additional Comments** (Note): Enter any additional comments about the upgrade request.
* **Training Status** (Select): Choose the status of the training, "Active" or "Inactive".
* **Training completed** (Select): Select whether the training has been completed, "Yes" or "No".
* **Training completed on** (Date): Enter the date the training was completed.
* **Training completed at** (Time): Select the time the training was completed.
* **Manager Approval Status** (Select): Select the manager's approval status.
* **Form Submitted** (Date): Select the date the form was submitted.
* **Form Submitted by** (Select): Select whether the form was submitted, "Yes" or "No".
* **Form Submitted Time** (Time): Select the time the form was submitted.
* **Approved by** (Select): Select whether the form was approved, "Yes" or "No".
* **Approved Time** (Time): Select the time the form was approved.
* **Comments** (Note): Enter any comments on the form status.
* **Form status** (Select): Select the status of the form, "Active" or "Inactive".
* **Form Status Comments** (Text): Enter any comments on the form status.
* **Employee Id 2** (Number): Enter employee ID 2.
* **Manager Id 2** (Number): Enter manager ID 2.
* **Employee Id 3** (Number): Enter employee ID 3.
* **Manager Id 3** (Number): Enter manager ID 3.
