# Bookkeeper Candidate Evaluation - Help Guide
## Purpose
The Bookkeeper Candidate Evaluation form is designed to help assess and evaluate bookkeeping candidates. It covers various aspects of a candidate's skills, experience, and background to make an informed decision for hiring or candidate selection purposes.

## How To Complete This Form

To complete this form, please follow the steps below:

1. Enter the full name of the applicant in the **Candidate Name** field.
2. Fill in the **Application Date**, which is the date the candidate applied for the bookkeeping position.
3. Specify the **Position Applied For** that the candidate is applying for.
4. Enter the **Years of Bookkeeping Experience** the candidate has.
5. Choose the **Accounting Software** they have experience with from the list provided. Select all applicable software.
6. Select the highest **Education Level** obtained by the candidate (e.g., High school diploma, Associate degree, Bachelor degree, etc.).
7. Rate the candidate's **Technical Skills Rating** based on their proficiency (Excellent, Very Good, Good, Average, Poor).
8. Evaluate their **Attention to Detail** (Excellent, Very Good, Good, Average, Poor).
9. Rate their **Communication Skills** (Excellent, Very Good, Good, Average, Poor).
10. Rate their **Problem Solving Ability** (Excellent, Very Good, Good, Average, Poor).
11. Rate their **Time Management Skills** (Excellent, Very Good, Good, Average, Poor).
12. If applicable, select the level of **Tax Knowledge** they have (Advanced, Intermediate, Basic, Minimal).
13. If provided, select whether they have **Professional References** (Yes, excellent references; Yes, good references; Yes, adequate references; No references provided).
14. Add any additional **Interview Notes** if necessary.
15. Finally, make a selection in the **Overall Recommendation** field based on your evaluation (Highly recommend; Recommend; Consider; Do not recommend).

## Field-by-Field Explanation

* **Candidate Name**: Enter the full name of the applicant.
	+ Type: Text
	+ Required: True
* **Application Date**: The date the candidate applied for the bookkeeping position.
	+ Type: Date
	+ Required: True
* **Position Applied For**: The title of the bookkeeping position the candidate is applying for.
	+ Type: Text
	+ Required: True
* **Years of Bookkeeping Experience**: The total years of experience the candidate has in bookkeeping.
	+ Type: Number
	+ Required: True
* **Accounting Software Experience**: Select all the accounting software the candidate has experience with.
	+ Type: Select Multiple
	+ Required: True
* **Education Level**: The highest level of education obtained by the candidate.
	+ Type: Select One
	+ Required: True
* **Technical Skills Rating**: Rate the candidate's technical skills based on their proficiency.
	+ Type: Select One
	+ Required: True
* **Attention to Detail**: Evaluate their attention to detail based on their performance.
	+ Type: Select One
	+ Required: True
* **Communication Skills**: Rate their communication skills based on their performance.
	+ Type: Select One
	+ Required: True
* **Problem Solving Ability**: Rate their problem-solving skills based on their performance.
	+ Type: Select One
	+ Required: True
* **Time Management Skills**: Rate their time management skills based on their performance.
	+ Type: Select One
	+ Required: True
* **Tax Knowledge**: Select the level of tax knowledge they have, if applicable.
	+ Type: Select One
	+ Required: False
* **Professional References Provided**: Select whether they provided professional references.
	+ Type: Select One
	+ Required: True
* **Interview Notes**: Add any additional interview notes, if necessary.
	+ Type: Text
	+ Required: False
* **Overall Recommendation**: Make a selection based on your overall evaluation of the candidate.
	+ Type: Select One
	+ Required: True
