# equipment_checkout_form - Help Guide
## Purpose
The equipment_checkout_form is used to record equipment checkout information for employees. This form ensures that all equipment checked out is accurately tracked and recorded.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in your **User Name** in the User Name field. This field is required.
2. Enter your **User Email** in the User Email field. This field is required.
3. Enter the **Equipment ID** in the Equipment ID field. This field is optional.
4. Provide a brief description of the equipment being checked out in the **Equipment Description** field. This field is required.
5. Select the start and end dates for the checkout period in the **Start Date** and **End Date** fields, respectively. These fields are both required.
6. Choose the tools you will be using from the **Assigned Tool** dropdown menu. You can select one tool from the list.
7. Choose another tool you will be using from the **Another Tool** dropdown menu. You can select one tool from the list.
8. If you need to add any additional notes, you can do so in the **Note** field. This field is optional.
9. Finally, enter your **User Phone** number. This field is optional.

## Field-by-Field Explanation
* **User Name**: Enter your name as it appears on your employee ID.
* **User Email**: Enter your company email address.
* **Equipment ID**: Enter the ID of the equipment being checked out. If you are unsure, you can refer to the equipment catalog.
* **Equipment Description**: Provide a brief description of the equipment being checked out.
* **Start Date**: Enter the date the equipment was checked out.
* **End Date**: Enter the date the equipment is due to be returned.
* **Assigned Tool**: Select the tool(s) you will be using from the list provided.
* **Another Tool**: Select the tool you will be using from the list provided.
* **Note**: Add any additional notes or comments about the equipment checkout.
* **User Phone**: Enter your contact phone number.
