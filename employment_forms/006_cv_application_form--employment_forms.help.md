# CV Application Form - Help Guide
## Purpose
The CV Application Form is a tool for applicants to provide essential information about themselves for the purpose of applying for a job or position within the company. This information will be reviewed and considered as part of the application process.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill in your Full Name, Email Address, Phone Number, and Current Address.
2. Specify the Position Applying For and provide your Available Start Date.
3. If applicable, provide your Current Employer and Current Job Title.
4. Select your Education Level and years of experience.
5. List your Key Skills.
6. Provide your Languages Spoken.
7. If applicable, upload your CV and cover letter.
8. Indicate whether you have professional references available and if you're authorized to work in this country.
9. Lastly, provide any additional information you would like to include.

## Field-by-Field Explanation

* **Full Name**: This is the name as you want to be known. Please enter your full name as it should appear on official documents.
	+ Type: text
	+ Required: true
* **Email Address**: This is your primary contact email for communication.
	+ Type: email
	+ Required: true
* **Phone Number**: This is your best contact number for any further communication or interview.
	+ Type: text
	+ Required: true
* **Current Address**: This is your complete mailing address for receiving any correspondence from us.
	+ Type: text
	+ Required: true
* **Position Applying For**: Enter the job title you are interested in, as listed on our job listings.
	+ Type: text
	+ Required: true
* **Available Start Date**: Specify the date you can start work if selected.
	+ Type: date
	+ Required: true
* **Education Level**: Select your highest completed education level.
	+ Type: select_one
	+ Required: true
	+ Options: High School Diploma, Associate Degree, Bachelor's Degree, Master's Degree, Doctorate, Other
* **Years of Experience**: Select your total years of experience in the relevant field.
	+ Type: select_one
	+ Required: true
	+ Options: Entry level (0-1 years), Junior (1-3 years), Mid-level (3-5 years), Senior (5-10 years), Expert (10+ years)
* **Current Employer**: If employed, please specify your current company name or 'N/A' if unemployed.
	+ Type: text
	+ Required: false
* **Current Job Title**: If employed, please specify your current job title or 'N/A' if unemployed.
	+ Type: text
	+ Required: false
* **Key Skills**: List your main professional skills, separated by commas.
	+ Type: text
	+ Required: true
* **Languages Spoken**: List the languages you are proficient in, along with your proficiency level.
	+ Type: text
	+ Required: false
* **CV Upload**: If you have a CV or resume, please attach it as a PDF or Word document.
	+ Type: note
	+ Required: false
* **Cover Letter Upload**: If you have a cover letter, please attach it if available.
	+ Type: note
	+ Required: false
* **References Available**: Indicate whether you have professional references available and if you would like to provide them.
	+ Type: select_one
	+ Required: true
	+ Options: Yes, upon request, Yes, included with CV, Not at this time
* **Work Authorization Status**: Specify your work authorization status.
	+ Type: select_one
	+ Required: true
	+ Options: Citizen, Permanent Resident, Work Visa Holder, Require sponsorship
* **How Did You Hear About This Position**: Source of the job listing (e.g., company website, job board, social media, employee referral, recruiter, other).
	+ Type: select_one
	+ Required: false
* **Additional Information**: If you would like to include anything else about yourself, please provide it here.
	+ Type: text
	+ Required: false
