# Personnel Request Form - Help Guide
## Purpose
The Personnel Request Form is used to request new employment within an organization. It collects information from the requestor and the employee to facilitate the hiring process. This form helps ensure that all necessary details are collected and processed efficiently.

## How To Complete This Form

1. Review the form carefully to ensure you have all the necessary information required.
2. Enter your department and select the appropriate option from the dropdown list.
3. Enter the job title, which should describe the specific role or position you are requesting.
4. Select the reporting manager and department manager from the dropdown lists.
5. Enter the job start date and end date, if applicable.
6. Select the reason for your request from the available options.
7. Choose the job type (full-time, part-time, or freelance).
8. Select the job status (approved, rejected, or pending).
9. Enter the employee's name and ID, if applicable.
10. Enter the department and employee IDs, if applicable.
11. Enter the manager's ID and title, if applicable.
12. Enter your ID and title, if you are the requestor.
13. Select the requestor from the dropdown list.
14. Enter the request date, which should be the date you are submitting the request.
15. Enter your title, if you are the requestor.
16. Enter the manager's request date and department request date, if applicable.
17. Select the job request status and type.
18. Enter the employee's job title and department.

## Field-by-Field Explanation

* **New Employment Request**: This field is a free-text field for you to describe the specific employment request.
* **Department**: Select the department where you work or the department you are requesting to be part of.
* **Job Title**: Enter the title or position you are requesting, e.g., "Software Engineer" or "Marketing Manager".
* **Reporting Manager**: Select the manager who will be your direct supervisor.
* **Department Manager**: Select the manager who oversees your department.
* **Job Start Date**: Enter the date when you would like to start work, if applicable.
* **Job End Date**: Enter the date when you would like to end your employment, if applicable.
* **Reason for Request**: Select the reason for your employment request, such as "Business Need" or "Cost Savings".
* **Job Type**: Choose the type of employment you are requesting (full-time, part-time, or freelance).
* **Job Status**: Select the status of your employment request (approved, rejected, or pending).
* **Employee Name**: Enter the name of the employee, if applicable.
* **Employee ID**: Enter the ID number of the employee, if applicable.
* **Department ID**: Enter the ID number of the department, if applicable.
* **Manager ID**: Enter the ID number of the manager, if applicable.
* **Requestor ID**: Enter your ID number, if you are the requestor.
* **Request Date**: Enter the date you are submitting the request.
* **Requestor**: Select the person submitting the request from the dropdown list.
* **Requestor Title**: Enter your title, if you are the requestor.
* **Manager Request Date**: Enter the date when the manager submitted the request, if applicable.
* **Department Request Date**: Enter the date when the department submitted the request, if applicable.
* **Job Request Status**: Select the status of your employment request (approved, rejected, or pending).
* **Job Request Type**: Choose the type of employment you are requesting (full-time, part-time, or freelance).
* **Employee Job Title**: Enter the job title of the employee, if applicable.
* **Employee Department**: Select the department where the employee works, if applicable.

## Tips

* Make sure to review the form carefully before submitting it to ensure all necessary information is included.
* Use clear and concise language when filling out the form.
* If you are unsure about any field, consult with your HR or personnel department for clarification.
* If you need to make changes to the form, contact the form administrators at form@gic.mx.
