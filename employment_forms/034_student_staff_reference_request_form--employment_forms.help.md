# Student Staff Reference Request Form - Help Guide
## Purpose
The Student Staff Reference Request Form is a tool used to collect information from staff members who have been asked by students for a reference.

## How To Complete This Form
To fill out this form, follow these steps:
1. Enter the student's name in the **Student** field.
2. Enter the name of the staff member providing the reference in the **Staff Member** field.
3. Enter the department of the staff member providing the reference in the **Department** field.
4. Select the date when the reference was requested using the **Reference Request Date** field.
5. If necessary, enter the date range for the reference using the **Reference Request Date Range** field.
6. Enter the name of the staff member making the reference request in the **Reference Requester Name** field.
7. Enter the email address of the staff member making the reference request in the **Reference Requester Email** field.
8. Enter the phone number of the staff member making the reference request in the **Reference Requester Phone** field.
9. Select the status of the reference request from the dropdown menu in the **Reference Request Status** field.
10. Optionally, provide additional comments about the reference request in the **Reference Request Status Comment** field.

## Field-by-Field Explanation

* **Student**: Enter the name of the student who made the reference request.
* **Staff Member**: Enter your name as the staff member providing the reference.
* **Department**: Enter your department or work area.
* **Reference Request Date**: Select the date when the reference was requested.
* **Reference Request Date Range**: Select the date range for the reference if necessary.
* **Reference Requester Name**: Enter the name of the staff member making the reference request.
* **Reference Requester Email**: Enter the email address of the staff member making the reference request.
* **Reference Requester Phone**: Enter the phone number of the staff member making the reference request.
* **Reference Request Status**: Select the status of the reference request from the dropdown menu.
* **Reference Request Status Comment**: Provide any additional comments about the reference request.
