# crews_shoes_order_form - Help Guide
## Purpose
This form is used to process employee shoe orders, capturing essential information about the employee, order type, status, and other relevant details.

## How To Complete This Form
To complete this form, follow the instructions below:

1. Fill out the employee information on Page 1.
2. Select the order type, status, and other details on Page 2.
3. Add any additional notes or comments on Page 3.

## Field-by-Field Explanation

* **Employee Name** (`employee_name`, text, required): Enter the employee's full name.
* **Email** (`email`, email, required): Enter the employee's email address.
* **Phone** (`phone`, text, required): Enter the employee's phone number.
* **Order Date** (`order_date`, date, required): Select the date for the order.
* **Order Note** (`order_note`, note, required): Add any additional notes or comments for the order.
* **Employee Size** (`employee_size`, number, required): Select the employee's size (e.g., 5, 6, 7, etc.).
* **Order Type** (`order_type`, select_one, required): Select the purpose of the order (New, Replacement, Repair, or Other).
* **Order Status** (`order_status`, select_multiple, required): Select the status of the order (New, Open, In Progress, Done).
* **Manager Note** (`manager_note`, note, required): Add any notes or comments for the manager.
* **Employee Notes** (`employee_notes`, note, required): Add any additional notes or comments for the employee.
* **Order Comments** (`order_comments`, note, required): Add any additional comments or notes for the order.
* **Shoe Type** (`shoe_type`, select_one, required): Select the type of shoe (Dress, Athletic, Boots, Sandals, Sneakers).
* **Shoe Color** (`shoe_color`, select_one, required): Select the color of the shoe (Black, White, Brown, Red, Blue, Green, Yellow, Other).
* **Shoe Brand** (`shoe_brand`, select_one, required): Select the brand of the shoe (Converse, Vans, Adidas, Nike, Others).
* **Quantity Ordered** (`quantity_ordered`, number, required): Enter the quantity of shoes ordered.
* **Employee ID** (`employee_id`, number, required): Enter the employee's ID number.
* **Shoe Size** (`shoe_size`, number, required): Enter the size of the shoe.
* **Additional Tips**:
    - Please ensure you fill out all required fields.
    - Use clear and concise language when adding notes or comments.
    - Double-check the order details before submitting.
