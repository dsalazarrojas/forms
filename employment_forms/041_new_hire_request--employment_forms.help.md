## New Hire Request - Help Guide

## Purpose
The New Hire Request form is used to request the addition of a new employee to the company's payroll and benefits systems. This form is typically used by HR personnel or supervisors to process new hire requests.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the employee's name in the Employee Name field.
2. Select the start date from the calendar picker.
3. Select the department from the options provided.
4. Specify the employment period in the text field.
5. Answer "Yes" or "No" to the Software Requests question regarding software access.
6. If applicable, add any additional requests or comments in the Additional Requests field.
7. Specify any IT equipment requests in the IT Equipment Requests field.

## Field-by-Field Explanation
### Employee Name (Required)
* **Employee Name**: Enter the full name of the new hire, including their first and last name.

### Start Date (Required)
* **Start Date**: Select the start date of the new hire's employment with the company from the calendar picker.

### Department (Required)
* **Department**: Select the department that the new hire will be working in from the options provided.

### Employment Period (Required)
* **Employment Period**: Enter the duration of the new hire's employment, including any relevant details or restrictions.

### Software Requests (Required)
* **Software Requests**: Answer "Yes" or "No" to request access to specific software systems, which will be used to assess system access and provisioning.

### Additional Requests (Optional)
* **Additional Requests**: If the new hire has any additional requests or comments, add them here to ensure they are documented and actioned by the necessary teams.

### IT Equipment Requests (Optional)
* **IT Equipment Requests**: If the new hire requires any specific IT equipment, such as a laptop or phone, list them here to ensure provisioning and configuration are completed correctly.
