# Grievance Form - Help Guide
## Purpose
The grievance form is designed to collect information about incidents or issues that need to be reported and addressed. This form is used to gather details about the issue, the category of the issue, and the priority level of the incident. The information collected will help us to track and manage grievances efficiently.

## How To Complete This Form
1. To complete the form, fill out each field as instructed.
2. Enter your **User Name** in the "User Name" field.
3. Provide a brief description of the incident in the "Description" field.
4. Enter the date the incident occurred in the "Date" field. If the date is not known, leave it empty.
5. Enter any additional details about the incident in the "Details" field.
6. Provide an email address for contact in the "Email" field.
7. Enter your phone number for contact in the "Phone" field.
8. Attach any relevant file related to the incident in the "File" field, if applicable.
9. Select the category of the incident from the list provided in the "Category" field.
10. If the category is not listed, enter the category in the "Other Category" field.
11. Select the priority level of the incident from the list provided in the "Priority" field.
12. Check the "Escalate" field to indicate if the incident needs escalation. If "Escalate Other" is selected, provide additional details in the "Escalate Comment" field.
13. Select the status of the incident from the list provided in the "Status" field.
14. Check the "Resolution" field to indicate if the incident has been resolved. If "Resolution Other" is selected, provide additional details in the "Resolution Comment" field.
15. Enter any relevant comments about the incident in the "Comment" field.
16. Finally, click submit to complete and submit the form.

## Field-by-Field Explanation

* **User Name** (`user_name`, text, required): Enter your name as it appears on your identification.
* **Description** (`grievance_description`, text, optional): Provide a brief description of the incident.
* **Date** (`grievance_date`, date, optional): Enter the date the incident occurred. If the date is not known, leave it empty.
* **Details** (`grievance_details`, text, optional): Enter any additional details about the incident.
* **Email** (`contact_email`, email, optional): Enter your email address for contact.
* **Phone** (`contact_phone`, text, optional): Enter your phone number for contact.
* **File** (`grievance_file`, text, optional): Attach any relevant file related to the incident.
* **Category** (`grievance_category`, select_one, optional): Select the category of the incident from the list provided.
* **Other Category** (`grievance_category_other`, text, optional): If the category is not listed, enter the category in this field.
* **Priority** (`grievance_priority`, select_one, optional): Select the priority level of the incident from the list provided.
* **Escalate** (`grievance_escalate`, select_multiple, required): Check to indicate if the incident needs escalation.
* **Escalate Comment** (`grievance_comment_escalate`, text, optional): If "Escalate Other" is selected, provide additional details in this field.
* **Status** (`grievance_status`, select_one, required): Select the status of the incident from the list provided.
* **Resolution** (`grievance_resolution`, select_multiple, optional): Check to indicate if the incident has been resolved.
* **Resolution Comment** (`grievance_comment_resolution`, text, optional): If "Resolution Other" is selected, provide additional details in this field.
* **Comment** (`grievance_comment`, text, optional): Enter any relevant comments about the incident.
* **Escalate Other** (`grievance_escalate_other`, text, optional): If "Escalate" is selected, provide additional details in this field.
* **Resolution Other** (`grievance_resolution_other`, text, optional): If "Resolution" is selected, provide additional details in this field.
* **Resolution Status** (`grievance_resolution_status`, select_one, required): Select the resolution status of the incident from the list provided.
* **Comment** (`grievance_comment`, text, optional): Enter any relevant comments about the incident.
* **Escalate Comment** (`grievance_comment_escalate`, text, optional): If "Escalate" is selected, provide additional details in this field.
* **Resolution Comment** (`grievance_comment_resolution`, text, optional): If "Resolution" is selected, provide additional details in this field.
* **Note** (`grievance_note`, text, optional): Enter any additional notes about the incident.
* **Form** (`grievance_form`, text, optional): Enter any additional information about the form.
* **Other Form** (`grievance_other_form`, text, optional): If "Form" is selected, enter the form in this field.
* **Other Form** (`grievance_other_form_other`, text, optional): If "Other Form" is selected, enter the form in this field.
