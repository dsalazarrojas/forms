# Job Application Declaration Form - Help Guide
## Purpose
The Job Application Declaration Form is a standardized template for job seekers to declare their applications, providing essential information about themselves and their job requirements.

## How To Complete This Form

* Fill out the form accurately and completely with your information and job details.
* Ensure all required fields are filled out.
* Attach any necessary documents or attachments.
* Review your application carefully before submitting.

## Field-by-Field Explanation

* **Job Title**: A brief description of the job you're applying for.
	+ Type: Text
	+ Required: Yes
* **Job Applicant**: Your name and contact information.
	+ Type: Text
	+ Required: Yes
* **Contact E-mail**: Your email address for contact.
	+ Type: Email
	+ Required: Yes
* **Contact Phone**: Your phone number for contact.
	+ Type: Text
	+ Required: Yes
* **Job Category**: The category of the job you're applying for (e.g., Management, Engineering, Sales).
	+ Type: Select One
	+ Required: Yes
* **Job Level**: The level of the job (e.g., Intern, Full-time, Part-time).
	+ Type: Select Multiple
	+ Required: Yes
* **Location**: The location where you'd like to work (e.g., Local, Remote).
	+ Type: Select One
	+ Required: Yes
* **Job Type**: The type of job you're applying for (e.g., Contract, Permanent).
	+ Type: Select One
	+ Required: Yes
* **Job Status**: The current status of your application (e.g., Applied, In Progress, Accepted, Rejected).
	+ Type: Date
	+ Required: Yes
* **Job Start Date**: The date you'd like to start working.
	+ Type: Date
	+ Required: Yes
* **Job End Date**: The expected end date of your employment.
	+ Type: Date
	+ Required: Yes
* **Resume**: Attach a copy of your resume or CV.
	+ Type: Note
	+ Required: Yes
* **References**: Attach any relevant references or certificates.
	+ Type: Note
	+ Required: Yes
* **Job Application Comments**: A brief message for the hiring team.
	+ Type: Text
	+ Required: Yes
* **Job Application Attachment**: Attach any supporting documents or files.
	+ Type: Text
	+ Required: Yes
* **Job Application Status**: The status of your application (e.g., Applied, In Progress, Accepted, Rejected).
	+ Type: Select One
	+ Required: Yes
* **Job Rejection Reason**: If your application was rejected, please provide the reason.
	+ Type: Text
	+ Required: Yes
* **Job Acceptance Reason**: If your application was accepted, please provide the reason.
	+ Type: Text
	+ Required: Yes
* **Job Application Declaration Form Comments**: Additional comments about your application.
	+ Type: Text
	+ Required: Yes
* **Job Application Declaration Form Attachment**: Attach any supporting documents or files.
	+ Type: Text
	+ Required: Yes
* **Job Application Declaration Form Status**: The status of your application (e.g., Applied, Accepted, Rejected).
	+ Type: Select One
	+ Required: Yes
* **Job Application Declaration Form Comments**: Additional comments about your application.
	+ Type: Text
	+ Required: Yes
* **Job Application Declaration Form Attachment**: Attach any supporting documents or files.
	+ Type: Text
	+ Required: Yes

## Tips

* Be accurate and honest when filling out the form.
* Double-check your details before submitting.
* Attach all necessary documents or files.
* Keep the form up-to-date with the current status of your application.
