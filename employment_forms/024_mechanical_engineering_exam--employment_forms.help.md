# Mechanical Engineering Exam - Help Guide
## Purpose
The Mechanical Engineering Exam form is designed to gather information related to mechanical engineering exams. It is intended for individual users who need to complete it for personal purposes.

## How To Complete This Form
To complete this form, follow these steps:

* Select the category of the exam from the dropdown list.
* Provide a brief description of the exam.
* Choose the output file type (this field is currently disabled and not required).
* If applicable, select an assigned tool for the exam.

## Field-by-Field Explanation
* **Category** (`employment_forms`, optional): This field allows you to select a category for the exam, which helps in organizing and sorting the exams. You can choose from "employment forms" or "Other" if the exam category does not fit into any of the provided options.
* **Description** (`description`, optional): This field is for providing a brief description of the exam. This field is meant to give a concise summary of the exam's nature and content.
* **Output File** (`output_file`, optional): This field is currently disabled and not required. It's intended for users to specify a file type for the output. For now, it is not functional and can be ignored.
* **Assigned Tool** (`assigned_tool`, optional): If an assigned tool is required for the exam, select it from this field. This ensures that the tool is linked with the exam correctly.
