# Employment Eligibility Verification Form - Help Guide
## Purpose
This form is used to verify employment eligibility for an individual.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the required fields with the employee's information.
2. For each field, make sure to fill in accurate and correct information.
3. If an employee is no longer employed, select 'Yes' for the reason for termination or separation fields.

## Field-by-Field Explanation
- **Employer Name** (`1`, `employer_name`, text, **required**: false): Enter the name of the employer where the employee was last employed.
  - **Employee Name** (`2`, `employee_name`, text, **required**: false): Enter the name of the employee whose employment eligibility is being verified.
  - **Employee ID Number** (`3`, `employee_id_number`, text, **required**: false): Enter the ID number assigned to the employee by their employer.
  - **Start Date** (`4`, `start_date`, date, **required**: false): Enter the start date of the employee's employment.
  - **End Date** (`5`, `end_date`, date, **required**: false): Enter the end date of the employee's employment.
  - **Reason for Termination** (`6`, `reason_for_termination`, select_one, **required**: false): If the employee is no longer employed, select 'Yes' if they were terminated.
  - **Last Date Worked** (`7`, `last_date_worked`, date, **required**: false): Enter the last date the employee worked.
  - **Employee Status** (`8`, `employee_status`, select_one, **required**: false): Select 'Active' if the employee is currently employed or 'Inactive' if they are no longer employed.
  - **Job Title** (`9`, `job_title`, text, **required**: false): Enter the job title of the employee.
  - **Department** (`10`, `department`, text, **required**: false): Enter the department the employee was working in.
  - **Supervisor Name** (`11`, `supervisor_name`, text, **required**: false): Enter the name of the employee's supervisor.
  - **Manager Name** (`12`, `manager_name`, text, **required**: false): Enter the name of the employee's manager.
  - **Address** (`13`, `address`, text, **required**: false): Enter the address where the employee was last employed.
  - **City** (`14`, `city`, text, **required**: false): Enter the city where the employee was last employed.
  - **State** (`15`, `state`, select_one, **required**: false): If the employee was last employed in a state, select 'Yes'.
  - **Zip** (`16`, `zip`, text, **required**: false): Enter the zip code of the location where the employee was last employed.
  - **Phone Number** (`17`, `phone_number`, text, **required**: false): Enter the phone number of the location where the employee was last employed.
  - **Email** (`18`, `email`, email, **required**: false): Enter the email of the location where the employee was last employed.
  - **Reason for Separation** (`19`, `reason_for_separation`, select_one, **required**: false): If the employee is no longer employed, select 'Yes' if they were separated.
  - **Termination Date** (`20`, `termination_date`, date, **required**: false): If the employee was terminated, enter the date of termination.
  - **Manager Title** (`21`, `manager_title`, text, **required**: false): Enter the title of the manager of the employee.
  - **Supervisor Title** (`22`, `supervisor_title`, text, **required**: false): Enter the title of the supervisor of the employee.
  - **Employee Address** (`23`, `employee_address`, text, **required**: false): Enter the address of the employee.
  - **Employee City** (`24`, `employee_city`, text, **required**: false): Enter the city of the employee.
  - **Employee State** (`25`, `employee_state`, select_one, **required**: false): If the employee is currently in a state, select 'Yes'.
