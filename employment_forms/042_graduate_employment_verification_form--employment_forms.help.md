# Graduate Employment Verification Form - Help Guide

## Purpose
The "Graduate Employment Verification Form" is a tool to collect information from recent graduates to track their employment status and provide an opportunity to keep the institution informed about their career progress.

## How To Complete This Form
To fill out this form, follow these steps:

1. Fill out the contact information of the graduate on the first page.
2. Answer the employment details and select the correct status for the graduate.
3. Optionally, select "Other" for employment details and provide a brief description in the "Other" field.
4. Choose whether the graduate wants to be tracked for alumni follow-up or other custom options.
5. If "Other" is selected for alumni tracking, provide a description of the "Other" option.

## Field-by-Field Explanation

### Graduate Contact Information (ID 2)
* **Graduate Contact Information**: Fill in the contact information of the graduate, which includes any relevant details to reach out to them.

### Employment Details (ID 3)
* **Employment Details**: Select the correct option to indicate the graduate's current employment status.
  - **Employed**: Select this option if the graduate is currently employed.
  - **Unemployed**: Select this option if the graduate is unemployed.
  - **Other**: If the graduate is neither employed nor unemployed, select this option.

### Other Employment Details (ID 4)
* **Other**: This field is for describing the graduate's employment status in case it's different from the above options. Provide a brief description.

### Alumni Tracking (ID 5)
* **Alumni Tracking**: Select the options to track the graduate for alumni follow-up.
  - **Track**: Select this option to be tracked.
  - **Do Not Track**: Select this option if you do not want to be tracked.
  - **Other**: If you have a different tracking preference, select this option.

### Other Alumni Tracking (ID 6)
* **Other**: This field is for describing the graduate's alumni tracking preference in case it's different from the above options. Provide a brief description.

### Other Alumni Tracking Comment (ID 7)
* **Other (if other)**: This field is for providing any additional information regarding the graduate's alumni tracking preference.

### School Name (ID 8)
* **School Name**: Fill in the name of the graduate's school or institution.

### School URL (ID 9)
* **School URL**: Enter the URL of the graduate's school or institution if applicable.

### School Name 2 (ID 10)
