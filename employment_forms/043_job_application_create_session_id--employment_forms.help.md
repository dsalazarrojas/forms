# Job Application Create Session ID - Help Guide
## Purpose
The Job Application Create Session ID form is used to create a unique session ID for a job application, allowing for tracking and linking related documents.

## How To Complete This Form

1. Fill in the required fields to create the session ID for the job application.
2. Review the generated session ID to ensure it meets your needs.

## Field-by-Field Explanation

* **Job Application Create Session ID** (1): This is the unique session ID for the job application.
	+ Type: Number
	+ Required: No
* **Email Link** (2): A link to share the job application with others via email.
	+ Type: Email
	+ Required: No
* **Description** (3): A brief description of the job application.
	+ Type: Text
	+ Required: No
* **Category** (4): Select the category for the job application.
	+ Type: Select One
	+ Options: Employment Forms, Other Forms
	+ Required: No
* **Subscribed Date** (5): The date the job application was submitted.
	+ Type: Date
	+ Required: No
* **Subscribed Time** (6): The time the job application was submitted.
	+ Type: Time
	+ Required: No
* **Status** (7): Select the status of the job application.
	+ Type: Select Multiple
	+ Options: Draft, Active, Inactive, Deleted
	+ Required: No
* **Form ID** (8): The ID of the form used to create the job application.
	+ Type: Number
	+ Required: No

## Tips
* Make sure to fill out the required fields and review the form carefully before generating the session ID.
* Use the session ID carefully as it will be used for various purposes such as tracking and analytics.
* If you're unsure about any field, feel free to contact the support team for assistance.
