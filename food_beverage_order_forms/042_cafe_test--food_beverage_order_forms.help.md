# Cafe Test - Help Guide
## Purpose
This form is an internal testing tool for the Cafe Test. It is designed to collect test data for review.

## How To Complete This Form
1. Review the form carefully to understand the required data types and formats.
2. Fill out each field accurately according to the provided explanations.

## Field-by-Field Explanation
* **Test field one** (test_field_1, text, required: false): Fill out this field with any text input. It's an optional field, so feel free to leave it blank if not necessary.
* **Test field two** (test_field_2, text, required: false): Like the first field, this is also a text field and is optional.
* **Test date** (test_date, date, required: false): Enter a date in the format mm/dd/yyyy or dd/mm/yyyy. Be careful to use the correct date format.
* **Test numeric** (test_numeric, number, required: false): Fill out this field with a numeric value, such as a whole number.
* **Test select** (test_select, select_one, required: false): Choose one of the provided options: A, B, or C.
* **Test time** (test_time, time, required: false): Enter a time in the format 12:HH or 12:00:00 AM/PM.
* **Test email** (test_email, email, required: false): Enter a valid email address in the format [username]@domain.com.
* **Test notes** (test_notes, text, required: false): Enter any additional notes or comments about your test case.
