# Plant Based Product Development Order Form - Help Guide
## Purpose
The Plant Based Product Development Order Form is a structured template to collect all necessary information for a new plant-based product. This form ensures that product managers and developers have all the required details for a product before starting its development.

## How To Complete This Form

1. Fill out the form completely and accurately.
2. Ensure that all required fields (marked as "required" in the form) are filled out.
3. If you have any questions or need help, don't hesitate to reach out to our support team.

## Field-by-Field Explanation

* **Product Details** (`product_details`, text, required/optional): This field is used to enter the product's name, description, and any other relevant details.
* **Product Image** (`product_image`, text, required/optional): This field is used to enter the product's image URL or upload the image directly.
* **Description** (`product_description`, text, required/optional): This field is used to enter a brief description of the product.
* **Tag** (`product_tag`, text, required/optional): This field is used to enter relevant tags for the product (e.g., vegan, gluten-free, etc.).
* **Category** (`product_category`, select_one, required/optional): This field is used to select the product's category (e.g., Beverage, Snack, Dairy).
* **Target Audience** (`target_audience`, text, required/optional): This field is used to specify the product's target audience (e.g., children, adults, etc.).
* **Price** (`product_price`, number, required/optional): This field is used to enter the product's price.
* **Price Scale** (`product_price_scale`, select_one, required): This field is used to select the product's price scale (e.g., $0-1000, $1000-5000, $5000+).
* **Launch Date** (`product_launch_date`, date, required/optional): This field is used to enter the product's launch date.
* **Status** (`product_status`, select_one, required): This field is used to select the product's status (e.g., Not Started, In Development, Released).
