# thanksgiving_feast_template - Help Guide

## Purpose
This form is designed to help users create a comprehensive plan for a Thanksgiving feast. It collects information about the main course, side dishes, drinks, number of guests, guest diets, special diets, host dishes, host contact information, potluck time, event details, event date, appetizers, main course, desserts, coordination contact, coordination time, and notes. This form is essential for organizing a successful and enjoyable Thanksgiving celebration.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the main course for the Thanksgiving feast.
2. Choose the side dishes to be served.
3. Enter a drink choice (required).
4. Specify the number of guests attending (required).
5. Indicate the guest's diet preferences (required).
6. Select any special diets that need to be accommodated.
7. Enter the host's dish contribution.
8. Provide the host's contact information (required).
9. Set the potluck time (required).
10. Add any event details or notes.
11. Select the event date (required).
12. Choose the appetizers to be served.
13. Enter the main course details.
14. Select the dessert options.
15. Provide the coordination contact information (required).
16. Set the coordination time (required).
17. Add any additional notes.

## Field-by-Field Explanation

* **Main Course** (Main Course, select_multiple, required): Select one or more of the following main course options: turkey, lamb, vegetarian, or other.
* **Side Dish** (Side Dish, text, optional): Enter any additional side dishes to be served.
* **Drink** (Drink, text, required): Specify a drink choice, such as juice, soda, or wine.
* **Number of Guests** (Number of Guests, number, required): Enter the total number of guests attending the feast.
* **Guest Diet** (Guest Diet, select_one, required): Select one of the following diet options: vegetarian, non-vegetarian, or other.
* **Special Diet** (Special Diet, select_one, optional): Select if there are any special diets that need to be accommodated (e.g., gluten-free, dairy-free).
* **Host Dish** (Host Dish, text, required): Enter the host's dish contribution.
* **Host Contact** (Host Contact, text, required): Enter the host's name, phone number, and email address.
* **Potluck Time** (Potluck Time, time, required): Set the time for the potluck.
* **Event Details** (Event Details, text, optional): Add any additional event details or notes.
* **Event Date** (Event Date, date, required): Select the date of the event.
* **Appetizer** (Appetizer, select_multiple, required): Select one or more of the following appetizer options: green bean, yam, carrot, or other.
* **Main Course** (Main Course, text, required): Enter the main course details.
* **Dessert** (Dessert, select_multiple, required): Select one or more of the following dessert options: apple, mashed potatoes, pumpkin, or other.
* **Coordination Contact** (Coordination Contact, text, required): Enter the coordination contact information.
* **Coordination Time** (Coordination Time, time, required): Set the coordination time.
* **Notes** (Notes, text, optional): Add any additional notes or comments.
