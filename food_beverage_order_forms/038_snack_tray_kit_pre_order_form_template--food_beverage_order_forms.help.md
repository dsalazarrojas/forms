# Snack Tray Kit Pre Order Form Template - Help Guide
## Purpose
This form is used to collect information from customers for a customized snack tray kit order. Customers will need to provide their details, order preferences, and any additional instructions or notes.

## How To Complete This Form

1. Please fill out the form with all the required fields (marked as "required" in the form).
2. If you have any additional comments or instructions for the order, use the "Order Notes" field.
3. Select the desired products for the snack tray kit from the list provided.
4. Enter the number of each selected product in the "Order Quantity" field.

## Field-by-Field Explanation

* **Customer Info** (`customer_info`, text, required/optional): This field is for customers to provide a brief description of their business or organization, if applicable.
* **Customer Name** (`customer_name`, text, required/optional): Enter the name of the person placing the order or the name of the company.
* **Customer Email** (`customer_email`, email, required/optional): Enter the email address of the person placing the order or the contact email of the company.
* **Customer Phone** (`customer_phone`, text, required/optional): Enter the phone number of the person placing the order or the company phone number.
* **Order Date** (`order_date`, date, required/optional): Select the date for the order.
* **Order Time** (`order_time`, time, required/optional): Select the time for the order.
* **Product List** (`product_list`, select_multiple, required): Select the desired products for the snack tray kit from the provided list.
* **Order Quantity** (`order_quantity`, number, required/optional): Enter the quantity of each selected product.
* **Order Notes** (`order_notes`, text, required/optional): Provide any additional comments or instructions for the order.
* **Customer Address** (`customer_address`, text, required/optional): Enter the address of the company or event location where the snack tray kit will be delivered.
* **Product Info** (`product_info`, text, required/optional): Enter any additional information or comments about the selected products.
