# tournament_catering_service_order_form - Help Guide
## Purpose
This form is used to order catering services for a tournament.

## How To Complete This Form
To complete this form, simply fill out the required fields, and optionally provide additional information. You can complete the form in multiple steps, but we recommend completing it in the order of the fields as they appear.

## Field-by-Field Explanation
* **Tournament Name** (`tournament_name`, text, required): Enter the name of the tournament.
* **Catering Service** (`catering_service`, select multiple, required): Choose the type of catering service you require. You can select one or more options from the list.
* **Date** (`date`, date, required): Enter the date of the tournament.
* **Time** (`time`, time, required): Enter the time of the tournament.
* **Order Details** (`order_details`, text, required): Provide a brief description of the order you are placing.
* **Special Instructions** (`special_instructions`, note, optional): If you have any special requests or requirements, enter them here.
* **Contact Phone** (`phone`, text, optional): Enter your contact phone number.
* **Contact Email** (`email`, email, optional): Enter your contact email.
* **Assigned Tool** (`assigned_tool`, select one, optional): Choose the tool that will be used to handle the order. This will help us determine which system will process the order.
* **Form Submission Type** (`form_submission_type`, select one, optional): Choose how you would like to submit the form. You can submit it online or offline.
* **Form Submission URL** (`form_submission_url`, text, optional): If you are submitting the form offline, enter the URL where the form can be submitted.

Please note that all fields marked as "required" are necessary to complete the form. The others are optional and can be filled out for additional information if desired.
