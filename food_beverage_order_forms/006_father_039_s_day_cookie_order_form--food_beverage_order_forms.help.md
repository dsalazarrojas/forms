# Fathers Day Cookie Order Form - Help Guide
## Purpose
This form is used to create a cookie order for fathers day celebrations.

## How To Complete This Form

To complete this form, follow these steps:

1. Provide your name
2. Enter your contact information (phone number and email address)
3. Select the cookie shape and size
4. Add any special message on the cookie
5. Specify the order date and time
6. Enter the number of cookies you are ordering
7. Choose the order type (if applicable)
8. Confirm the order status (if applicable)

## Field-by-Field Explanation

### Order Details
* **Order Details** (`Order Details`, text, required): Please provide a brief description of your order, including any special requests or instructions.

### Cookie Shape
* **Cookie Shape** (`cookie_shape`, select_one, optional): Select the shape of the cookie you desire. Options include:
	+ Yes
	+ No

### Cookie Size
* **Cookie Size** (`cookie_size`, select_multiple, optional): Select the size of the cookie you desire. Options include:
	+ Yes
	+ No

### Cookie Message
* **Cookie Message** (`cookie_message`, note, optional): Please add any special message to be written on the cookie.

### Name of Baker
* **Name of Baker** (`name_of_baker`, text, optional): If you would like to specify a different baker, please enter their name here.

### Contact Number
* **Contact Number** (`contact_number`, text, optional): Please enter your phone number so we can contact you with order updates.

### Email Address
* **Email Address** (`email_address`, email, optional): Please enter your email address so we can send you order updates and confirmations.

### Order Date
* **Order Date** (`order_date`, date, optional): Please select the date of the order.

### Order Time
* **Order Time** (`order_time`, time, optional): Please select the time of the order.

### Order Notes
* **Order Notes** (`order_notes`, note, optional): Please add any other notes or requests for your order.

### Total Cookies
* **Total Cookies** (`total_cookies`, number, optional): Please enter the number of cookies you are ordering.

### Order Type
* **Order Type** (`order_type`, select_one, optional): Choose the type of order. Options include:
	+ Yes
	+ No

### Order Status
* **Order Status** (`order_status`, select_one, optional): Choose the status of the order. Options include:
	+ Active
	+ Inactive

### Confirm Order
* **Confirm Order** (`confirm_order`, optional): Please confirm your order by entering the following information:
	Please enter the following fields:
		+ Name of Baker
		+ Contact Number
		+ Email Address

Note: This form will not process until all required fields are filled and confirmed. Please ensure all details are accurate before submitting the form.
