# Farm To Table Meat Order Form - Help Guide
## Purpose
This form is designed to collect information about a customer's order for farm-to-table meat products. It helps the farm to gather necessary details to process and fulfill the order efficiently while maintaining accurate records.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in your **Customer Info** (Page 1): Enter your name and any other relevant contact information.
2. Enter your **Address** (Page 2): Provide your address to help us deliver your order accurately.
3. Enter your **Contact Info** (Page 3): Provide any additional contact information you'd like to share with us.
4. Enter your **Order Details** (Page 4): Describe the order you'd like to place, including the type and quantity of meat products you'd like to purchase.
5. Select the **Order Items** (Page 5): Choose the specific items you'd like to order from our farm-to-table meat products.
6. Choose your **Payment Method** (Page 6): Select how you'd like to pay for your order (e.g., credit card, PayPal).
7. Enter the **Order Total** (Page 7): This is an optional field to record the total value of your order.
8. Enter the **Order Date** (Page 8): This is the date you'd like to place your order.
9. Enter any **Notes** you'd like to add to your order (Pages 9-20): You can add up to 20 notes to provide more details about your order.

## Field-by-Field Explanation

* **Customer Info** (Page 1, `customer_info`):
	+ This field is used to collect your name and contact information.
	+ Please enter your name and any other relevant contact details.
* **Address** (Page 2, `address`):
	+ This field is used to collect your address to ensure accurate delivery of your order.
	+ Please enter your address in the format: Street Address, City, State, ZIP Code.
* **Contact Info** (Page 3, `contact_info`):
	+ This field is used to collect any additional contact information you'd like to share with us.
	+ You can enter any relevant contact details, such as phone number or email.
* **Order Details** (Page 4, `order_details`):
	+ This field is used to describe the order you'd like to place.
	+ Please provide details about the type and quantity of meat products you'd like to purchase.
* **Order Items** (Page 5, `order_items`):
	+ This field is used to select the specific items you'd like to order from our farm-to-table meat products.
	+ Choose from the options provided to select the items you'd like to order.
* **Payment Method** (Page 6, `payment_method`):
	+ This field is used to select how you'd like to pay for your order (e.g., credit card, PayPal).
	+ Choose from the options provided to select your preferred payment method.
* **Order Total** (Page 7, `order_total`):
	+ This field is used to record the total value of your order.
	+ This is an optional field; you can ignore it if you're not sure about the total value.
* **Order Date** (Page 8, `order_date`):
	+ This field is used to select the date you'd like to place your order.
	+ Choose the date from the options provided.
* **Order Comments** (Pages 9-20, `order_comments`):
	+ This field is used to add any additional comments or details about your order.
	+ You can enter up to 20 notes to provide more information about your order.
* **Delivery Time** (Page 9, `delivery_time`):
	+ This field is used to select the delivery time for your order.
	+ Choose from the options provided to select the delivery time.
* **Order Status** (Page 10, `order_status`):
	+ This field is used to select the status of your order.
	+ Choose from the options provided to select the order status (e.g., new, shipped, delivered, cancelled, paid).
* **Customer Status** (Page 11, `customer_status`):
	+ This field is used to select the status of the customer.
	+ Choose from the options provided to select the customer status (e.g., active, inactive, pending).
* **Farm Status** (Page 12, `farm_status`):
	+ This field is used to select the status of the farm.
	+ Choose from the options provided to select the farm status (e.g., active, inactive, pending).
* **Customer Type** (Page 13, `customer_type`):
	+ This field is used to select the type of customer.
	+ Choose from the options provided to select the customer type (e.g., residential, commercial, other).
* **Farm Location** (Page 14, `farm_location`):
	+ This field is used to select the location of the farm.
	+ Choose from the options provided to select the farm location (e.g., city, town, village).
* **Order Source** (Page 15, `order_source`):
	+ This field is used to select the source of the order.
	+ Choose from the options provided to select the order source (e.g., website, phone, email, in-app).
* **Order Source Details** (Page 16, `order_source_details`):
	+ This field is used to provide more details about the order source.
	+ Enter any relevant details about the order source.
* **Farm Name** (Page 17, `farm_name`):
	+ This field is used to enter the name of the farm.
	+ Please enter the name of the farm that produced the meat products.
* **Notes** (Pages 18-20, `notes`):
	+ This field is used to add any additional comments or details about your order.
	+ You can enter up to 15 notes to provide more information about your order.

Note: This help guide will help you understand how to use the form correctly and efficiently. If you have any questions or need clarification, please don't hesitate to contact us.
