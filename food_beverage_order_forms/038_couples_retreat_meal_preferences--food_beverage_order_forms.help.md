# couples_retreat_meal_preferences - Help Guide
## Purpose
This form gathers meal preferences and dietary information from couples attending a retreat to ensure that all guests' needs are met and to provide accurate headcounts for meal planning.

## How To Complete This Form
To complete this form, follow these steps:

1. Review each page and ensure you have all the information required.
2. Fill out each section with your preferred options.
3. Enter any additional comments or details where required.

## Field-by-Field Explanation

* **Meal Preferences**: Choose the type of meals you'd like to have on the retreat. You can select multiple options.
  * Select from the options listed.
  * Optional
* **Food Allergies**: If you have any food allergies, please select the ones that apply to you.
  * Choose from the available options.
  * Optional
* **Drink Preferences**: Select your preferred drink options.
  * Choose from the available options.
  * Optional
* **Meal Choice**: Indicate whether you'd like to choose your own meal or have it selected for you.
  * Select 'Yes' or 'No'.
  * Optional
* **Entree**: Select your preferred entree option.
  * Choose from the available options.
  * Optional
* **Entree Dish Details**: Enter any additional details about your entree choice, if needed.
  * Enter text.
  * Optional
* **Meal Choice Dish**: If you've selected to choose your own meal, please enter the details here.
  * Enter text.
  * Optional
* **Meal Choice Note**: If you have any specific requests or comments about your meal choice, please enter them here.
  * Enter text.
  * Optional
* **Entree Special Request**: If you have any special requests for your entree, please enter them here.
  * Enter text.
  * Optional
* **Entree Special Request Note**: If you have any additional comments or requests for your entree, please enter them here.
  * Enter text.
  * Optional
* **Dessert**: Select your preferred dessert option.
  * Choose from the available options.
  * Optional

## Tips
* If you have any questions or concerns about this form, please reach out to the retreat organizers.
* Please ensure that all fields are filled out accurately to guarantee a successful and enjoyable retreat experience.
* If you're unsure about any of the options, please select the most suitable one that applies to you.
