# Restaurant Grease Trap Cleaning Order Form - Help Guide

## Purpose
This form is designed to collect information about restaurant grease trap maintenance. It is intended for internal use within the restaurant management team to track and coordinate grease trap cleaning orders.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the name of the restaurant for which you are placing the order.
2. If applicable, provide the contact email and phone number for the restaurant staff to facilitate communication and scheduling.
3. Enter the city and state of the restaurant location, which is necessary for logistical planning.
4. Specify the type of grease trap to be cleaned (e.g., 2" P Trap, 4" P Trap, 6" P Trap).
5. Choose the size of the grease trap to be cleaned (e.g., Small, Medium, Large).
6. Select the cleaning frequency (e.g., Daily, Weekly, Monthly).
7. If desired, indicate a preferred date and time for the cleaning.
8. Enter any special instructions for the cleaning crew to follow.
9. Select the staff member assigned for the cleaning task.
10. Provide any comments regarding the order.
11. If necessary, enter an internal restaurant ID and notes for the order.
12. Enter the tool assigned for the cleaning task.

## Field-by-Field Explanation
* **Restaurant Name** (`restaurant_name`): Enter the name of the restaurant for which the cleaning order is for.
* **Contact Email** (`contact_email`): Enter the email address of the restaurant contact, if applicable.
* **Contact Phone** (`contact_phone`): Enter the phone number of the restaurant contact, if applicable.
* **Location City** (`location_city`): Enter the city of the restaurant location.
* **Location State** (`location_state`): Enter the state of the restaurant location.
* **Location Zip** (`location_zip`): Enter the zip code of the restaurant location.
* **Grease Trap Type** (`grease_trap_type`): Select the type of grease trap to be cleaned from the options provided.
* **Grease Trap Size** (`grease_trap_size`): Select the size of the grease trap to be cleaned.
* **Cleaning Frequency** (`cleaning_frequency`): Select the frequency of the cleaning from the options provided.
* **Preferred Date** (`preferred_date`): If desired, enter a preferred date for the cleaning.
* **Preferred Time** (`preferred_time`): If desired, enter a preferred time for the cleaning.
* **Special Instructions** (`special_instructions`): Enter any special instructions for the cleaning crew.
* **Assigned To** (`assigned_to`): Select the staff member assigned for the cleaning task.
* **Comments** (`comments`): Enter any comments about the order.
* **Restaurant ID** (`restaurant_id`): Enter an internal restaurant ID for the order, if necessary.
* **Assigned Tool** (`assigned_tool`): Enter the tool assigned for the cleaning task.
* **Notes** (`notes`): Enter any additional notes about the order.
* **Form Submit** (`form_submit`): Enter your name and title for the form submission, if applicable.
* **Restaurant Name 2** (`restaurant_name_2`): Enter the name of the restaurant for which the cleaning order is for.
* **Contact Email 2** (`contact_email_2`): Enter the email address of the restaurant contact, if applicable.
* **Contact Phone 2** (`contact_phone_2`): Enter the phone number of the restaurant contact, if applicable.
* **Location City 2** (`location_city_2`): Enter the city of the restaurant location.
* **Location State 2** (`location_state_2`): Enter the state of the restaurant location.
* **Location Zip 2** (`location_zip_2`): Enter the zip code of the restaurant location.
* **Form Submit 2** (`form_submit_2`): Enter your name and title for the form submission, if applicable.
