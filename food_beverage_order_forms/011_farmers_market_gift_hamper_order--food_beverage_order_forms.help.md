# Farmers Market Gift Hamper Order - Help Guide
## Purpose
This form is used to order a gift hamper for a recipient. Please fill out the form with the recipient's details and any message you'd like to include with the order. This will help us prepare a customized gift hamper for your loved one.

## How To Complete This Form
1. Select a hamper type from the options provided.
2. Enter the recipient's name.
3. Enter the recipient's email address.
4. Enter the recipient's phone number (optional).
5. Choose a delivery date and time.
6. Write a personal message for the recipient (optional).
7. Specify the quantity of gift hampers you'd like to order.

## Field-by-Field Explanation
* **Select A Hamper**: Choose the type of hamper you'd like to order (Hamper 1, Hamper 2, or Hamper 3).
* **Recipient Name**: Enter the name of the person receiving the gift hamper.
* **Recipient Email**: Enter the recipient's email address so we can send them any updates or messages.
* **Recipient Phone**: Enter the recipient's phone number (if available) so we can contact them directly.
* **Delivery Date**: Choose a date for the delivery of the gift hamper. You can choose any date that suits you.
* **Delivery Time**: Select a time for the delivery of the gift hamper. Please note that delivery times may vary depending on your location.
* **Order Message**: Write a personal message for the recipient, if you'd like.
* **Quantity Of**: Specify the number of gift hampers you'd like to order.
