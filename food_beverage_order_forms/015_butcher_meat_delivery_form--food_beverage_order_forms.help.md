# Butcher Meat Delivery Form - Help Guide
## Purpose
This form is used to place an order for meat delivery with a butcher. Please fill in all required fields to ensure your order is processed accurately.

## How To Complete This Form
1. Enter your **Customer Name** in the field provided. This is a required field.
2. Provide your **Email Address** and **Phone Number** to ensure we can contact you for any updates or confirmations.
3. Fill in your **Delivery Address** to ensure the order is delivered to the right location.
4. Select the **City** and **State or Province** where you'd like the order delivered.
5. Enter your **ZIP or Postal Code** to confirm the delivery location.
6. Choose a **Desired Delivery Date** when you would like to receive your order.
7. Select a **Preferred Delivery Time** from the options provided.
8. Select the **Beef Products Ordered** from the available options (if any).
9. Select the **Pork Products Ordered** from the available options (if any).
10. Select the **Chicken Products Ordered** from the available options (if any).
11. Add any **Specialty or Custom Items** if you have specific requests.
12. Enter the **Order Quantity** in pounds.
13. Provide any **Special Cutting Instructions** if needed.
14. Choose the **Packaging Preference** for your order.
15. Enter the **Estimated Order Cost** for your order.
16. Select the **Payment Method** for your order (Credit Card, Debit Card, Cash on Delivery, or Check).
17. Add any **Special Notes or Requests** you may have.

## Field-by-Field Explanation

* **Customer Name**: Enter your full name as it appears on your identification.
	+ Type: text
	+ Required: True
* **Email Address**: Provide a valid email that we can use to contact you.
	+ Type: email
	+ Required: True
* **Phone Number**: Enter your contact phone number for any updates or confirmations.
	+ Type: text
	+ Required: True
* **Delivery Address**: Enter the full address where you would like the order delivered.
	+ Type: text
	+ Required: True
* **City**: Enter the city where you would like the order delivered.
	+ Type: text
	+ Required: True
* **State or Province**: Select the state or province where you would like the order delivered.
	+ Type: text
	+ Required: True
* **ZIP or Postal Code**: Enter the zip or postal code for delivery.
	+ Type: text
	+ Required: True
* **Desired Delivery Date**: Choose the date when you would like to receive your order.
	+ Type: date
	+ Required: True
* **Preferred Delivery Time**: Select the time window for delivery from the options provided.
	+ Type: select_one
	+ Required: True
* **Beef Products Ordered**: Select the beef products you would like to order (if any).
	+ Type: select_multiple
	+ Required: False
* **Pork Products Ordered**: Select the pork products you would like to order (if any).
	+ Type: select_multiple
	+ Required: False
* **Chicken Products Ordered**: Select the chicken products you would like to order (if any).
	+ Type: select_multiple
	+ Required: False
* **Specialty or Custom Items**: Add any special or custom items you would like to order (if any).
	+ Type: text
	+ Required: False
* **Order Quantity**: Enter the approximate total weight in pounds.
	+ Type: number
	+ Required: True
* **Special Cutting Instructions**: Add any special cutting instructions if needed.
	+ Type: text
	+ Required: False
* **Packaging Preference**: Choose the packaging preference for your order.
	+ Type: select_one
	+ Required: True
* **Estimated Order Cost**: Enter the expected total price.
	+ Type: number
	+ Required: True
* **Payment Method**: Select the payment method for your order (Credit Card, Debit Card, Cash on Delivery, or Check).
	+ Type: select_one
	+ Required: True
* **Special Notes or Requests**: Add any special notes or requests you have.
	+ Type: text
	+ Required: False

Note: This help guide assumes that the form is filled out on a single page with the fields listed in the order they appear. The guide is designed to be concise and easy to follow. If the form is split into multiple pages, please adjust the guide accordingly.
