# Menu Nutritional Audit Form - Help Guide
## Purpose
The Menu Nutritional Audit Form is used to gather data on menu items, including their ingredients, serving amounts, and nutritional profiles. This information is essential for ensuring menu items are safe for consumption and compliant with regulatory requirements.

## How To Complete This Form
1. Navigate through the form pages to access each section.
2. Enter the required information for each section, using the provided text fields.
3. Double-check your entries for accuracy and completeness.

## Field-by-Field Explanation

* **Menu** (`menu_ingredients`, text, optional): List the ingredients used in the menu item.
	+ Enter a list of all food allergens used in the menu item.
* **Serving Amounts** (`serving_amounts`, text, optional): Provide serving amounts for each menu item.
	+ Enter the serving amount for each menu item.
* **Food Allergens** (`food_allergens`, text, optional): List all food allergens used in your menu items.
	+ Enter a list of all food allergens used in the menu items.
* **Nutrient Profiles** (`nutrient_profiles`, text, optional): Describe the nutritional profiles of each menu item.
	+ Enter a description of the nutritional profile for each menu item.
* **Menu Nutrition Facts** (`menu_nutrition_facts`, text, optional): Provide detailed nutrition facts for each menu item.
	+ Enter the detailed nutrition facts for each menu item.
* **Review Comments** (`review_comments`, text, optional): Comments from menu item reviews.
	+ Enter comments from menu item reviews.

## Tips

* Be as accurate and detailed as possible when filling out the form.
* If you are unsure about any section or require additional guidance, please consult with your supervisor or relevant authorities.
* Review the form carefully before submitting it to ensure all required information is included.
