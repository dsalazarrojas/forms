# Custom Dessert Order Form - Help Guide
## Purpose
The Custom Dessert Order Form is used to collect information for custom dessert orders, including customer details, dessert preferences, and order notes.

## How To Complete This Form

To complete this form, follow these steps:

* Fill in the required fields: 
  * Customer (id: 1)
  * Address (id: 4)
  * City (id: 5)
  * State (id: 6)
  * Zip (id: 7)
  * Date (id: 9)
  * Time (id: 10)
* For the optional fields: 
  * Choose one or more from the dessert list (id: 2)
  * Add any order notes (id: 3 and 8)
  * If required, select the correct time unit (id: 11)

## Field-by-Field Explanation
* **Customer** (id: 1): Enter the customer's name.
* **Dessert** (id: 2): Select one or more of the available dessert options. 
* **Order Notes** (id: 3): Add any special order instructions or requests.
* **Address** (id: 4): Enter the customer's address.
* **City** (id: 5): Enter the city.
* **State** (id: 6): Enter the state or region where the order is to be delivered.
* **Zip** (id: 7): Enter the zip or postal code for the delivery location.
* **Order Notes** (id: 8): Add any additional order notes or requests.
* **Date** (id: 9): Select the date for the order.
* **Time** (id: 10): Select the time for the order.
* **Time Unit** (id: 11): If you have selected a time, choose the unit of time (e.g., AM, PM).
* **Custom** (id: 12): This field is not required and is intended for any additional information you may want to add.
