# Local Farmer Product Order Form - Help Guide
## Purpose
The "Local Farmer Product Order Form" is a tool used to collect order information from customers for local farmer products. This form should only be used for orders that are intended for the local farmer market.

## How To Complete This Form
To complete this form, follow these steps:

1. Click on the "Order Form" page.
2. Enter the required information in each field.
3. Review the form carefully before submitting.

## Field-by-Field Explanation
* **Order Form**: Enter the order details in this field.
* **Customer Details**: Enter the customer's name, address, and contact information.
* **Order Details**: Enter any additional order details or comments.
* **Order Confirmation**: Enter the confirmation code provided by the farmer or a unique code for this order.
* **Additional Notes**: Enter any additional information or notes about the order.

## Tips
* Make sure to review the form carefully before submitting.
* Double-check the order details to ensure accuracy.
* Enter the correct confirmation code or code provided by the farmer.
* Use this form only for orders intended for the local farmer market.
