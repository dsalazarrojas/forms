# customer_menu_preference_request_form - Help Guide
## Purpose
The "customer_menu_preference_request_form" is a form used to collect menu preferences from customers for an event or occasion.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the main information section with your contact details.
2. Select your menu picks from the provided options.
3. If you have any special requests or allergies, list them in the "Special Requests" field.
4. Choose a date for the event.
5. Choose a time for the event.
6. Enter the name of the contact person.
7. Enter your phone number.

## Field-by-Field Explanation
* **Main Information** (`main_information`, text, not required): This field is used to collect any main information about the customer.
* **Menu Picks** (`menu_picks`, select multiple, required): Select one or more menu options that you would like to have for the event.
* **Special Requests** (`special_requests`, text, not required): If you have any special requests or allergies, such as vegetarian, vegan, or gluten-free, list them here.
* **Contact Details** (`contact_details`, text, not required): Enter any additional contact details for the event, if necessary.
* **Date** (`date`, date, required): Select a date for the event.
* **Time** (`time`, time, required): Select a time for the event.
* **Contact Person** (`contact_person`, text, required): Enter the name of the contact person for the event.
* **Phone** (`phone`, text, required): Enter your phone number.

## Tips
* Please make sure to select all required fields.
* If you have any special requests, be as specific as possible.
* Make sure to choose a date and time that works for both you and the event host.
* If you have any questions or need to make changes, contact the event host directly.
* Please note that incomplete forms may cause delays or issues with your order.
