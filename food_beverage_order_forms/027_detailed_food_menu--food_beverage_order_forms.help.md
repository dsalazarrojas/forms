# Detailed Food Menu - Help Guide
## Purpose
The "Detailed Food Menu" form is designed to help restaurant staff create and manage menu items with precision. It helps ensure that menu content is up-to-date and accurate, which in turn enhances customer satisfaction and experience.

## How To Complete This Form
To complete this form, follow these steps:

1. Select menu sections that you want to display on the menu, e.g., "Yes" or "No".
2. Choose "Yes" or "No" to indicate whether or not to display specific menu items.
3. Describe the menu item in detail using the text field.
4. Enter the price of the item.
5. List the ingredients used in the menu item.
6. Add an image to represent the menu item.
7. Choose a category for the menu item.
8. Set the status of the menu item as "Active" or "Inactive".

## Field-by-Field Explanation
### Menu
* **Menu** (select_multiple, required: false): Select "Yes" to display this menu section on the main menu. You can select multiple options.
### Food Items
* **Food Items** (select_one, required: false): Select "Yes" to include food items in the menu section.
### Menu Sections
* **Menu Sections** (select_one, required: false): Select "Yes" to create a new menu section. This field is used in conjunction with the "Menu" field.
### Description
* **Description** (text, required: false): Enter a detailed description of the menu item.
### Price
* **Price** (number, required: false): Enter the price of the menu item. This field is only required if you're adding a new menu item.
### Ingredients
* **Ingredients** (text, required: false): List the ingredients used in the menu item.
### Image
* **Image** (text, required: false): Upload or enter the URL of an image representing the menu item.
### Category
* **Category** (select_one, required: false): Choose a category for the menu item.
### Status
* **Status** (select_one, required: false): Set the status of the menu item as "Active" or "Inactive".

## Tips
* Make sure to select "Menu" fields correctly to avoid duplicate menu sections.
* Use clear and concise descriptions for menu items.
* Use the "Price" field only when adding new menu items.
* Use the "Status" field to keep menu items up-to-date.
* You can select multiple menu sections using the "Menu" field.
