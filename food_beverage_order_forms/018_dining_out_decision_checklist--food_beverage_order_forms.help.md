# Dining Out Decision Checklist - Help Guide

## Purpose
The form is a checklist for diners to communicate their preferences when eating out. This information helps the restaurant staff tailor their service to meet the group's needs.

## How To Complete This Form

To complete this form, follow these steps:

1.  Review each section and answer the questions according to your preferences.
2.  Fill in the required and optional questions according to your needs.
3.  Make sure to answer all the questions to help the restaurant staff better understand your preferences.

## Field-by-Field Explanation

* **Group Preferences** (`Group Preferences`, `note`, required: false): This is where you can add any additional notes or comments about the group you are dining with.
* **Group Size** (`Group Size`, `number`, required: false): Please select the number of people in your group.
* **Time Arrival** (`Time Arrival`, `time`, required: false): Indicate the estimated time of your arrival.
* **Special Requests** (`Special Requests`, `select_multiple`, required: false):
	+ Select the options that apply to your group:
		- **Yes**: Select this if the group has any special requests.
		- **No**: Select this if the group doesn't have any special requests.
* **Food Restrictions** (`Food Restrictions`, `select_multiple`, required: false):
	+ Select the options that apply to your group:
		- **Beef**: Select this if the group has a beef restriction.
		- **Fish**: Select this if the group has a fish restriction.
		- **Vegan**: Select this if the group has a vegan restriction.
		- **Vegetarian**: Select this if the group has a vegetarian restriction.
		- **Gluten**: Select this if the group has a gluten restriction.
		- **Dairy**: Select this if the group has a dairy restriction.
		- **Other**: Select this if the group has other restrictions not listed.
* **Drinks** (`Drinks`, `select_one`, required: false):
	+ Select the drink you want from the options:
		- **Water**
		- **Juice**
		- **Soda**
		- **Beer**
		- **Wine**
		- **Other**
* **Contact Preferences** (`Contact Preferences`, `select_multiple`, required: false):
	+ Select the options that apply to your group:
		- **Yes**: Select this if the group has any contact preferences.
		- **No**: Select this if the group doesn't have any contact preferences.
* **Restaurant Preferences** (`Restaurant Preferences`, `select_multiple`, required: false):
	+ Select the options that apply to your group:
		- **Yes**: Select this if the group has any restaurant preferences.
		- **No**: Select this if the group doesn't have any restaurant preferences.

## Tips
- Please ensure that you answer all the questions to help the restaurant staff better understand your preferences.
- If there are any additional notes or comments that are not included in the form, you can add them in the **Group Preferences** field.
- If you have any questions or concerns, don't hesitate to reach out to the restaurant staff.
