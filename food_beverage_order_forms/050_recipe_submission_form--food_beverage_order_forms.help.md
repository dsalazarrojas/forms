# Recipe Submission Form - Help Guide
## Purpose
The Recipe Submission Form is designed for users to share new recipes with the community. Please use this form to submit a recipe you'd like to share, and follow the instructions below to ensure a smooth submission process.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the "Submit a Recipe" option to indicate that you'd like to submit a new recipe.
2. In the "Ingredient" field, type the name of the ingredient(s) used in the recipe.
3. In the "Ingredient Quantity" field, enter the quantity of each ingredient used.
4. In the "Cooking Method" field, describe the cooking method used to prepare the recipe.
5. In the "Cooking Time" field, enter the cooking time required for the recipe.
6. In the "Notes" field, add any additional comments or observations about the recipe.

## Field-by-Field Explanation
* **Submit a Recipe** (Yes/No, required): Confirm that you're certain about the submission and that it's not a duplicate. Please select "Yes" if you're sure about the submission.
* **Ingredient** (text, optional): Type the name of the ingredient(s) used in the recipe.
* **Ingredient Quantity** (number, optional): Enter the quantity of each ingredient used.
* **Cooking Method** (text, optional): Describe the cooking method used to prepare the recipe.
* **Cooking Time** (time, optional): Enter the cooking time required for the recipe.
* **Notes** (note, optional): Add any additional comments or observations about the recipe.
