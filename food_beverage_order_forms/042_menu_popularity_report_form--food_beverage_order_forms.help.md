# Menu Popularity Report Form - Help Guide
## Purpose
The Menu Popularity Report Form is used to collect data on menu item sales for each month of the year. This data is used to identify trends and patterns in menu item popularity and to inform business decisions.

## How To Complete This Form
To complete this form, please follow these steps:

1. Select the month for which you want to report sales data. This form includes options for all 12 months of the year.
2. Enter the year for which you are reporting sales data. This field is required.
3. Enter the name of the dish or menu item being reported on.
4. Select the category of the dish or menu item (e.g. appetizer, entree, dessert).
5. Enter the sales quantity for the menu item for the selected month.
6. Enter the sales value for the menu item for the selected month.
7. Enter the average price of the menu item for the selected month.
8. Enter the total revenue generated by the menu item for the selected month.
9. Enter any additional notes or comments about the report.
10. Enter your email address (optional).
11. Enter your phone number (optional).
12. Select whether menu items were reported on for each month (yes or no).
13. Select whether dish popularity was reported on for each month (yes or no).
14. Select whether staff insights were reported on for each month (yes or no).
15. Select whether centralized data collection was used for each month (yes or no).

## Field-by-Field Explanation

* **Menu Popularity Report Form** (Required): This is the title of the form.
* **month** (Select): This field allows you to select the month for which you are reporting sales data.
* **year** (Number): This field is required and should be entered as a four-digit number (e.g. 2022).
* **dish_name** (Text): This field should be entered with the name of the dish or menu item being reported on.
* **category** (Text): This field should be entered with the category of the dish or menu item (e.g. appetizer, entree, dessert).
* **sales_quantity** (Number): This field should be entered with the sales quantity for the menu item for the selected month.
* **sales_value** (Number): This field should be entered with the sales value for the menu item for the selected month.
* **average_price** (Number): This field should be entered with the average price of the menu item for the selected month.
* **total_revenue** (Number): This field should be entered with the total revenue generated by the menu item for the selected month.
* **notes** (Text): This field should be entered with any additional notes or comments about the report.
* **email** (Email): This field is optional and should be entered with your email address.
* **phone_number** (Text): This field is optional and should be entered with your phone number.
* **menu_items** (Select Multiple): This field allows you to select whether menu items were reported on for each month (yes or no).
* **dish_popularity** (Select Multiple): This field allows you to select whether dish popularity was reported on for each month (yes or no).
* **staff_insights** (Select Multiple): This field allows you to select whether staff insights were reported on for each month (yes or no).
* **centralized_data_collection** (Select Multiple): This field allows you to select whether centralized data collection was used for each month (yes or no).
