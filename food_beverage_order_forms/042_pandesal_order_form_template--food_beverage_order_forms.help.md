# Pandesal Order Form Template - Help Guide
## Purpose
The Pandesal Order Form Template is a user-friendly tool for customers to place orders for pandesal with a bakery or business. The form is designed to collect necessary information to process the order efficiently.

## How To Complete This Form

To complete this form, please follow these steps:

1.  **Select the type of bread** that you would like to order by choosing from the "Bread Type" dropdown menu.
2.  **Enter the quantity** of pandesal you would like to order in the "Quantity" field.
3.  **Optional: Date** of delivery or pickup. This field is not required but helps the bakery plan for orders.
4.  **Enter your bakery's name** where you would like to order from.
5.  **Add any order notes** if you have specific instructions or requests for your order.
6.  **Enter a valid email address** if you would like to receive order confirmations and updates.
7.  **Enter your phone number** for any additional information or updates.
8.  **Click the "Submit" button** to send your order.

## Field-by-Field Explanation

*  **Bread Type:** 
	+ Label: Bread Type
	+ Select the type of bread you would like to order.
	+ Options: Whole wheat, Rye, White bread
*  **Quantity:**
	+ Label: Quantity
	+ Enter the quantity of pandesal you would like to order.
	+ Example: 1, 2, 3, etc.
*  **Date:**
	+ Label: Date
	+ Optional field to enter the date for delivery or pickup.
	+ Format: mm/dd/yyyy or dd/mm/yyyy
*  **Bakery Name:**
	+ Label: Bakery Name
	+ Enter the name of the bakery where you would like to order from.
*  **Order Notes:**
	+ Label: Order Notes
	+ Enter any specific instructions or requests for your order.
*  **Email:**
	+ Label: Email
	+ Enter a valid email address to receive order confirmations and updates.
*  **Phone:**
	+ Label: Phone
	+ Enter your phone number for any additional information or updates.
*  **Submit:**
	+ Label: Submit
	+ Click this button to send your order.
