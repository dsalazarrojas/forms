# Reusable Lunch Box Order Form - Help Guide
## Purpose
This form is used to capture information for the school's lunch box program. It is designed to be reusable, allowing you to add or remove students as needed.

## How To Complete This Form
To complete this form, please follow these steps:

1. Enter the title of the order in the "Reusable Lunch Box Order" field.
2. Enter the student's name in the "Student Name" field.
3. Enter any contact information for the student in the "Contact Information" section.
4. Select "Yes" or "No" for each of the lunch options in the "Lunch Choice" section.
5. Enter any additional notes or comments in the "Notes" fields.
6. Select any special diets that the student may have in the "Special Diets" section.
7. Enter any additional information in the "Other" field if necessary.
8. Enter any notes from the parent/guardian in the "Parent Notes" section.
9. Enter the date and time for the order in the "Date" and "Time" fields.
10. Enter the total number of students in the "Total Students" field.
11. Enter the school's name and address in the "School Name" and "School Address" fields.
12. Enter the school's email address in the "School Email" field.

## Field-by-Field Explanation

* **Reusable Lunch Box Order** (`Reusable Lunch Box Order Form`, text, required): This is the title of the order.
* **Student Name** (`Student Name`, text, required): This is the name of the student.
* **Contact Information** (`Contact Information`, text, required): This is where you can enter any contact information for the student.
* **Name** (`Name`, text, required): This is the parent/guardian's name.
* **Phone** (`Phone`, text, required): This is the parent/guardian's phone number.
* **Email** (`Email`, email, required): This is the parent/guardian's email address.
* **Grade** (`Grade`, text, required): This is the student's grade level.
* **Lunch Choice** (`Lunch Choice`, select multiple, optional): Select "Yes" or "No" for each of the lunch options.
* **Option 1** (`Option 1`, select one, optional): Select "Yes" or "No" for this option.
* **Option 2** (`Option 2`, select one, optional): Select "Yes" or "No" for this option.
* **Option 3** (`Option 3`, select one, optional): Select "Yes" or "No" for this option.
* **Notes** (`Notes`, note, optional): This is a field for you to enter any additional notes or comments.
* **Parent Notes** (`Parent Notes`, select multiple, optional): Select "Yes" or "No" for each of the notes.
* **Note 1** (`Note 1`, select one, optional): Select "Yes" or "No" for this note.
* **Note 2** (`Note 2`, select one, optional): Select "Yes" or "No" for this note.
* **Note 3** (`Note 3`, select one, optional): Select "Yes" or "No" for this note.
* **Special Diets** (`Special Diets`, select one, optional): Select "Yes" or "No" if the student has any special diets.
* **Other** (`Other`, text, optional): Enter any additional information if necessary.
* **Date** (`Date`, date, optional): Enter the date of the order.
* **Time** (`Time`, time, optional): Enter the time of the order.
* **Total Students** (`Total Students`, number, optional): Enter the total number of students in the order.
* **School Name** (`School Name`, text, optional): Enter the school's name.
* **School Address** (`School Address`, text, optional): Enter the school's address.
* **School Email** (`School Email`, email, optional): Enter the school's email address.

Note: The fields marked as "required" are mandatory and must be filled out in order to complete the form. The fields marked as "optional" can be filled out if necessary.
