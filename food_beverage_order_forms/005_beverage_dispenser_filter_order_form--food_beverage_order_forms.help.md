# Beverage Dispenser Filter Order Form - Help Guide
## Purpose
This form is used to collect information from businesses and facilities that need to order filters for their beverage dispensers.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill out all required fields (marked as "required") for each section.
2. Ensure that all fields are accurate and complete.
3. Review each section carefully to ensure that all required fields are filled out.
4. Submit the form once you have completed all required fields.

## Field-by-Field Explanation

* **Business Name** (2, text, required): Your restaurant, cafe, or facility name.
* **Type of Business** (3, select_one, required): What industry are you in? Select from the options below:
	+ Restaurant
	+ Cafe or coffee shop
	+ Hotel
	+ Office facility
	+ Retail location
	+ Event venue
	+ Other
* **Contact Person Name** (4, text, required): Name of the person placing this order.
* **Email Address** (5, email, required): For order confirmation and tracking.
* **Phone Number** (6, text, required): For order updates and delivery coordination.
* **Dispenser Model Number** (8, text, required): Check your dispenser for the model number.
* **Number of Dispensers to Service** (10, number, required): How many dispensers need filters?
* **Filter Type** (12, select_one, required): What type of filter do you need? Select from:
	+ Sediment filter
	+ Carbon filter
	+ Reverse osmosis membrane
	+ Mineral filter
	+ UV filter
	+ Multi-stage filter cartridge
	+ Unsure - need recommendation
* **Filter Size or Micron Rating** (13, select_one, required): What size filter do you need? Select from:
	+ Standard replacement
	+ 1 micron
	+ 5 micron
	+ 20 micron
	+ 100 micron
	+ Other
* **Quantity to Order** (14, number, required): How many filter units do you need?
* **Typical Filter Replacement Frequency** (15, select_one): How often do you replace filters? Select from:
	+ Monthly
	+ Quarterly
	+ Every 6 months
	+ Annually
	+ As needed
* **Delivery Address** (17, text, required): Where should filters be shipped?
* **Preferred Delivery Method** (18, select_one, required): How would you like to receive the order? Select from:
	+ Standard shipping
	+ Express shipping
	+ Next business day
	+ Local pickup
	+ Will arrange pickup
* **Preferred Delivery Date** (19, date, optional): When do you need the filters? (Leave blank if not specified)
* **Customer Account Number** (21, text, optional): Leave blank if new customer.
* **Do you have a Service Contract** (22, select_one, optional): Select from:
	+ Yes, monthly service
	+ Yes, quarterly service
	+ No, order as needed
	+ Not sure
* **Do You Need Installation Assistance** (23, select_one, optional): Select from:
	+ Yes, professional installation
	+ No, we will install
	+ Not sure
* **Special Requests or Additional Notes** (24, text, optional): Any other information about your order?
