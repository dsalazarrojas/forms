# Lunch Menu Pre Order Form - Help Guide
## Purpose
The Lunch Menu Pre Order Form is used to collect information for a pre-order from customers for a lunch menu. This form is not intended for actual order placement but rather for providing information for the order.

## How To Complete This Form
To complete this form, please follow the steps below:

1. Select the relevant options for "Payment Info" (if applicable).
2. Enter the customer's name and contact information in "Customer Info".
3. Enter any special requests or instructions in "Special Requests".
4. Confirm the order by selecting "Confirm" in "Confirm Order".

## Field-by-Field Explanation
* **Order Details** (id: 1, type: text, required: false)
	+ This field is used to enter the order details. Please provide a brief description of the order, including any specific requests or questions.
* **Menu Items** (id: 2, type: text, required: false)
	+ Select the menu items you would like to order. Please be sure to select all applicable items.
* **Payment Info** (id: 3, type: select_multiple, required: false)
	+ This field is used to select the payment method(s) and any additional payment details. Please select all applicable options.
* **Customer Info** (id: 4, type: text, required: false)
	+ Enter the customer's name and contact information.
* **Contact Info** (id: 5, type: text, required: false)
	+ Enter the customer's contact information, including phone number and address.
* **Special Requests** (id: 6, type: text, required: false)
	+ Enter any special requests or instructions for the order.
* **Confirm Order** (id: 7, type: select_one, required: false)
	+ Select "Confirm" to confirm the order or "Cancel" to cancel.
* **Order Total** (id: 8, type: number, required: false)
	+ This field is not currently applicable.
* **Customer Email** (id: 9, type: email, required: false)
	+ Enter the customer's email address.
