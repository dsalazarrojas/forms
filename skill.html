Use GIC Forms from your own AI

Install the skill and tell Claude or Codex: "Create and publish a patient intake form, then add an accessible embed to my README." Your assistant can create, validate, publish, pause, resume, and manage hosted forms and responses — no dashboard needed.

Install (Claude Code)

mkdir -p .claude/commands cli
curl -o .claude/commands/gic-forms.md https://forms.gic.mx/downloads/gic-forms-skill.md
curl -o cli/gic-forms.js https://forms.gic.mx/downloads/gic-forms.js
export GIC_API_KEY=gic_live_...   # from Settings → API Keys (Pro), or a gift key

Downloads: skill file · CLI (zero-dependency Node)

What it can do

  • Create a form from a prompt (createForm) and edit it in plain language (editForm).
  • Validate YAML before anything ships (validateForm).
  • Publish and manage hosted forms with publish, forms-list, update, pause, resume, and delete.
  • Generate accessible link, button, or iframe embeds, and list, delete, or export responses to CSV.
  • Inspect, idempotently install, verify, or remove a managed form block in one Markdown or HTML file; use --dry-run to preview.
  • Import local GIC YAML/JSON or safely authorized public HTML form URLs.
  • Deploy to Tally, Formbricks, ONA, or KoboToolbox with your platform token.
  • Import SurveyMonkey surveys as GIC YAML (Pro/Business).

Hosted lifecycle and embeds

node cli/gic-forms.js publish form.yaml --slug intake
node cli/gic-forms.js embed FORM_ID --mode iframe --label "Patient intake"
node cli/gic-forms.js responses-export FORM_ID --out responses.csv
node cli/gic-forms.js site-install --file README.md --mode button --url https://f.gic.mx/f/FORM_ID
node cli/gic-forms.js site-verify --file README.md

The CLI uses https://f.gic.mx by default. Set GIC_BRIDGE_URL only for an intentional override. Site commands edit only the explicitly targeted file and never run git push.

How GIC apps handle access

No accounts, no passwords. Three lightweight keys cover everything: a GIC_API_KEY for programmatic access to a product's bridge, your own Cloudflare credentials (CF_ACCOUNT_ID / CF_API_TOKEN) when you deploy to or transform with your own Cloudflare account, and — on the web — short-lived tokens issued after Stripe checkout. Credentials you bring stay on your machine or in your browser; GIC never stores them server-side.
