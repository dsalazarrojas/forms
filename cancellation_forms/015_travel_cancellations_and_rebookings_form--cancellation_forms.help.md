# Travel Cancellations And Rebookings Form - Help Guide
## Purpose
This form is used to collect information about travel cancellations and rebookings, allowing you to manage and process these changes efficiently.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the Customer Name, Travel Agent, and Travel Agent Phone information, if applicable.
2. Select the Reason for Cancellation and Reason for Rebooking from the corresponding dropdown menus.
3. If the travel has been rebooked, enter the Rebooked Date and Rebooked Time.

## Field-by-Field Explanation
* **Customer Name** (`Customer Name`, `text`, optional): Enter the name of the customer whose travel has been cancelled or rebooked.
* **Travel Agent** (`Travel Agent`, `text`, optional): Enter the name of the travel agent handling the cancellation or rebooking.
* **Travel Agent Phone** (`Travel Agent Phone`, `text`, optional): Enter the phone number of the travel agent handling the cancellation or rebooking.
* **Travel Agent Email** (`Travel Agent Email`, `email`, optional): Enter the email address of the travel agent handling the cancellation or rebooking.
* **Reason for Cancellation** (`Reason for Cancellation`, `select_multiple`, optional): Select the reason for the travel cancellation from the options:
	+ Cancellation
	+ Rescheduling
	+ Refunding
	+ Other
	+ Unknown
* **Reason for Rebooking** (`Reason for Rebooking`, `select_one`, optional): Select the reason for the travel rebooking from the options:
	+ Cancellation
	+ Rescheduling
	+ Refunding
	+ Other
	+ Unknown
* **Rebooked Date** (`Rebooked Date`, `date`, optional): Enter the date of the rebooked travel (if applicable).
* **Rebooked Time** (`Rebooked Time`, `time`, optional): Enter the time of the rebooked travel (if applicable).
* **Rebooked Details** (`Rebooked Details`, `text`, optional): Provide any additional details about the rebooked travel.
