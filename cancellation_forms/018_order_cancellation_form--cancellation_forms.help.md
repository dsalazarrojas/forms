# cancellation_forms - Help Guide
## Purpose
The cancellation forms are used to collect information about orders that need to be cancelled. This form is designed to gather specific details about the order, such as the order number, reason for cancellation, and order status.

## How To Complete This Form
1. Enter the order number for the order you wish to cancel.
2. Provide a reason for cancellation.
3. Select the cancellation date.
4. Enter the order total.
5. Choose the order status.
6. Enter any additional order details if necessary.
7. Enter a customer message (if applicable).
8. Sign your customer signature (if applicable).
9. Confirm the order ID.

## Field-by-Field Explanation
* **Order Number** (`order_number`, text, optional): Enter the order number of the order you wish to cancel.
* **Reason for Cancellation** (`reason_for_cancellation`, text, optional): Provide a clear and concise reason for cancelling the order.
* **Cancellation Date** (`cancellation_date`, date, optional): Select the date of cancellation.
* **Order Total** (`order_total`, number, optional): Enter the total amount of the order.
* **Order Status** (`order_status`, select_one, optional): Choose the status of the order (cancelled, pending, or completed).
* **Cancellation Reason** (`cancellation_reason`, text, optional): Enter a brief description of the reason for cancellation.
* **Order Details** (`order_details`, text, optional): Enter any additional details about the order if needed.
* **Customer Message** (`customer_message`, text, optional): Enter a message to the customer related to the cancellation.
* **Customer Signature** (`customer_signature`, text, optional): Enter your customer's signature (if required).
* **Order ID** (`order_id`, number, optional): Confirm the order ID of the order being cancelled.

**Tips:**
- Make sure to enter accurate information in all fields.
- Double-check the order number to ensure you're cancelling the correct order.
- Enter a clear reason for cancellation to help with any future reference.
- If you're unsure about any information, please contact your supervisor or customer service.
