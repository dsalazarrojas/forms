# Apprenticeship Cancellation Form - Help Guide
## Purpose
The Apprenticeship Cancellation Form is used to provide necessary information to cancel an apprenticeship program.

## How To Complete This Form
To complete this form, follow the steps below:

1. Enter the apprentice's information, including name and ID.
2. Provide the apprentice's email address and phone number.
3. Enter the name of the program they were enrolled in and its start date.
4. Select the reason for cancellation and provide additional details.

## Field-by-Field Explanation

* **Apprentice Name** (`<name>`, text, required): Enter the name of the apprentice to be cancelled.
* **Apprentice ID** (`<id>`, text, required): Enter the ID number of the apprentice to be cancelled.
* **Email Address** (`<email>`, email, required): Enter the email address of the apprentice.
* **Phone Number** (`<phone>`, text, required): Enter the phone number of the apprentice.
* **Apprenticeship Program Name** (`<program_name>`, text, required): Enter the name of the program to be cancelled.
* **Program Start Date** (`<program_start_date>`, date, required): Enter the start date of the program to be cancelled.
* **Reason for Cancellation** (`<cancellation_reason>`, select_one, required): Select one of the following reasons:
	+ Personal Circumstances
	+ Career Change
	+ Financial Reasons
	+ Health Issues
	+ Relocation
	+ Not a Good Fit
	+ Other
* **Reason Details** (`<reason_details>`, text, required): Provide a brief description of the reason for cancellation.
* **Do you have any outstanding financial obligations?** (`<outstanding_obligations>`, select_one, required): Select 'Yes' if the apprentice has outstanding financial obligations, 'No' otherwise.
* **Additional Comments** (`<final_thoughts>`, text, optional): Enter any additional comments or notes about the cancellation.
