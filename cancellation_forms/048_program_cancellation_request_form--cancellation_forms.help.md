# Program Cancellation Request Form - Help Guide
## Purpose
The Program Cancellation Request Form is used by program administrators or managers to request the cancellation of a program. This form helps to gather necessary information to process the cancellation request efficiently.

## How To Complete This Form
To complete this form, follow these steps:
1. Enter the name of the program that you want to cancel.
2. Select the reason for the cancellation.
3. Enter your name as the participant or person requesting the cancellation.
4. Enter the date when the program was scheduled to take place.
5. Enter the date when you are requesting the cancellation.
6. Provide a brief reason for the cancellation.
7. Choose whether you want the manager to approve or decline the cancellation request.
8. Optionally, enter a message to be sent to the manager.
9. Optionally, enter a message to be sent to the participant.

## Field-by-Field Explanation

* **Program name**: The name of the program you want to cancel.
	+ This field is required.
* **Cancellation reason**: The reason why you are requesting the cancellation.
	+ This field is optional, but please select one of the provided options.
* **Participant name**: The name of the person requesting the cancellation.
	+ This field is optional.
* **Program date**: The date when the program was scheduled to take place.
	+ This field is optional.
* **Request date**: The date when you are requesting the cancellation.
	+ This field is optional.
* **Reason for cancellation**: A brief description of why the program should be cancelled.
	+ This field is optional.
* **Manager approval**: Choose whether you want the manager to approve or decline the cancellation request.
	+ This field is optional.
* **Message to manager**: An optional message to be sent to the manager.
	+ This field is optional.
* **Participant message**: An optional message to be sent to the participant.
	+ This field is optional.

## Tips
- Please ensure that you have the necessary permissions to request the cancellation of a program.
- Double-check the information you enter to ensure it is accurate and complete.
- If you have any questions or concerns, please contact the program administrator or manager.
