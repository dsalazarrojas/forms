# Class Cancellation Form - Help Guide
## Purpose
The Class Cancellation Form is designed to help teachers report and document class cancellations, providing a structured approach to gather relevant information for administrative and logistical purposes.

## How To Complete This Form
To complete the Class Cancellation Form, follow these steps:

1. Enter the teacher's name and ID number (if applicable).
2. Enter the teacher's email address.
3. Enter the teacher's phone number.
4. Select the class name or section.
5. Enter the originally scheduled class date.
6. Enter the originally scheduled class time.
7. Enter the number of students affected.
8. Choose the reason for the cancellation from the provided options.
9. Provide detailed explanation for the cancellation.
10. Enter the date the cancellation is being submitted.
11. Indicate whether this is a one-time cancellation or if the class will be rescheduled.
12. If rescheduling, enter the new scheduled class date and time.
13. Select the method(s) of student notification (e.g., email, SMS, phone call, etc.).
14. Add any additional information or comments about the cancellation.

## Field-by-Field Explanation

* **Teacher Name** (`teacher_name`, text, required): Enter the name of the teacher responsible for the class.
* **Teacher ID Number** (`teacher_id`, text, optional): Enter the teacher's ID number if applicable.
* **Teacher Email** (`teacher_email`, email, required): Enter the teacher's email address.
* **Teacher Phone Number** (`teacher_phone`, text, optional): Enter the teacher's phone number.
* **Class Name or Section** (`class_name`, text, required): Enter the name of the class or section.
* **Originally Scheduled Class Date** (`class_date`, date, required): Enter the date the class was originally scheduled.
* **Originally Scheduled Class Time** (`class_time`, time, required): Enter the time the class was originally scheduled.
* **Number of Students Affected** (`number_of_students`, number, required): Enter an approximate count of students affected by the cancellation.
* **Reason for Cancellation** (`cancellation_reason`, select_one, required): Choose from a list of provided options (e.g., teacher illness, family emergency, etc.).
* **Detailed Explanation** (`reason_details`, text, required): Provide a detailed explanation for the cancellation.
* **Date Cancellation is Being Submitted** (`cancellation_date_submitted`, date, required): Enter the date the cancellation is being submitted (today's date).
* **Notice Given to Students** (`notice_provided`, select_one, required): Indicate the amount of advance notice provided to students.
* **Will this Class be Rescheduled** (`reschedule_status`, select_one, required): Choose whether this is a one-time cancellation, a rescheduled class, or permanent cancellation.
* **New Scheduled Date - if Rescheduling** (`new_class_date`, date, optional): Enter the new scheduled class date if the class is being rescheduled.
* **New Scheduled Time - if Rescheduling** (`new_class_time`, time, optional): Enter the new scheduled class time if the class is being rescheduled.
* **How will students be notified** (`student_notification`, select_multiple, required): Select all applicable methods of student notification (e.g., email, SMS, phone call, etc.).
* **Additional Information or Comments** (`additional_information`, text, optional): Add any additional comments or information about the cancellation.
