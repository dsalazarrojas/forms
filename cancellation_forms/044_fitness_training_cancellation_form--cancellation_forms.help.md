# Fitness Training Cancellation Form - Help Guide
## Purpose
This form is used to provide information for cancellation of fitness training sessions. Please use it to enter the cancellation details.

## How To Complete This Form
1. Fill in the form with the relevant information as prompted.
2. If you have any additional information or feedback, please enter it in the fields provided.

## Field-by-Field Explanation
* **Cancellation ID** (`1`, number, required: false): Enter the Cancellation ID if you have it.
* **Date of Cancellation** (`2`, date, required: false): Enter the date of the cancellation.
* **Reason for Cancellation** (`3`, text, required: false): Select one of the provided reasons or enter a custom reason.
	+ Illness/Injury
	+ No interest
	+ Work/School commitment
	+ Personal reasons
	+ Other
* **Member Feedback** (`4`, text, required: false): If you have any feedback for the member, please enter it here.
* **Staff Feedback** (`5`, text, required: false): If you have any feedback for the staff, please enter it here.
* **Additional Information** (`6`, text, required: false): If you have any further information, please enter it here.
* **Suggestion** (`7`, text, required: false): If you have any suggestions, please enter them here.
* **Email** (`8`, email, required: false): Enter your email address.
* **Phone** (`9`, text, required: false): Enter your phone number.
* **Select Reason for Cancellation** (`10`, select_one, required: false): Select one of the provided reasons.
	+ Illness/Injury
	+ No interest
	+ Work/School commitment
	+ Personal reasons
	+ Other
* **Select Additional Services** (`11`, select_multiple, required: false): Select any additional services that were included in the training session.
	+ Personalized coaching
	+ Nutrition
	+ Mindfulness
	+ Yoga
	+ Pilates
* **Date of Training** (`12`, date, required: false): Enter the date of the training session.
Please note that the form is for internal use only, and only one Cancellation ID should be provided per session cancellation. If you have any further questions or concerns, please reach out to the staff.
