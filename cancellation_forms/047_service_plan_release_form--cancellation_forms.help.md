# Service Plan Release Form - Help Guide

## Purpose
The Service Plan Release Form is used to document the release of a service plan for a customer. This form provides a standardized way to capture the necessary information for the release process, ensuring consistency and accuracy in the documentation.

## How To Complete This Form

1. **Service Plan Release Form**: Enter a brief description of the service plan being released.
2. **Customer Request Reason**: Describe the reason for releasing the service plan.
3. **Service Provider Decision**: Select the reason for releasing the service plan from the options provided.
4. **Release Date**: Enter the date on which the service plan will be released.
5. **Release Time**: Enter the time at which the service plan will be released.
6. **Reason for Release**: Provide a detailed explanation for releasing the service plan.
7. **Customer Name**: Enter the name of the customer.
8. **Customer Email**: Enter the email address of the customer.
9. **Customer Phone**: Enter the phone number of the customer.
10. **Submitted By**: Select the person submitting the release.
11. **Submitted To**: Select the department or team submitting the release to.
12. **Submitted On**: Enter the date the form was submitted.
13. **Submitter Name**: Enter the name of the person submitting the form.
14. **Submitter Email**: Enter the email address of the person submitting the form.
15. **Submitter Phone**: Enter the phone number of the person submitting the form.
16. **Form Submitted**: Select the status of the form submission.
17. **Document Number**: Enter the document number associated with the service plan.
18. **Document Status**: Select the status of the document.
19. **Document Type**: Select the type of document associated with the service plan.
20. **Document Due Date**: Enter the due date for the document.
21. **Document Date**: Enter the date the document is due.
22. **Service Plan ID**: Enter the ID number of the service plan being released.
23. **Customer Request Number**: Enter the customer request number associated with the service plan.
24. **Reason for Denial**: If the service plan is being denied, provide a detailed explanation for the denial.
25. **Reason for Denial Details**: If the service plan is being denied, provide additional details for the denial.
