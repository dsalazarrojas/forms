# Tennis Program Cancellation Form - Help Guide

## Purpose
The Tennis Program Cancellation Form is used to record the status of tennis programs in your organization. This form allows staff to indicate whether a program is active or inactive, and to enter relevant details such as the reason for cancellation, cancellation date, and cancellation time.

## How To Complete This Form
To complete this form, follow these steps:

1. Select whether the program is cancelled (Program Cancellation Info).
2. Select whether the program ID is cancelled (Tennis Program ID).
3. Enter the reason for cancellation (Reason For Cancellation).
4. Enter the cancellation date and time (Cancellation Date and Cancellation Time).
5. Enter any additional information or messages (Cancellation Message, User Message, and Staff Message).
6. Select whether the program was submitted by staff (Submitted By).
7. Set the submission and creation timestamps (Submitted At, Created At, and Updated At).
8. Select whether the program was deleted and by whom (Deleted At and Deleted By).
9. Add any attachments or notes (Attachments, File Attachments, Staff Attachments, Attachment Files, and Staff Notes).
10. Enter the staff response (Staff Response).
11. Select the cancellation status (Cancellation Status).
12. Select the submission status (Submission Status).

## Field-by-Field Explanation
* **Program Cancellation Info** (`program_cancellation_info`, select_multiple, required): Select whether the program is cancelled or not.
* **Tennis Program ID** (`tennis_program_id`, select_one, required): Select whether the program ID is cancelled or not.
* **Reason For Cancellation** (`reason_for_cancellation`, text, required): Enter the reason why the program was cancelled.
* **Cancellation Date** (`cancellation_date`, date, required): Enter the date on which the program was cancelled.
* **Cancellation Time** (`cancellation_time`, time, required): Enter the time at which the program was cancelled.
* **Cancellation Message** (`cancellation_message`, text, required): Enter any additional information about the cancellation.
* **User Message** (`user_message`, text, required): Enter any message from the user.
* **Staff Message** (`staff_message`, text, required): Enter any message from staff.
* **Staff Response** (`staff_response`, text, required): Enter the response from staff.
* **Submitted By** (`submitted_by`, select_one, required): Select whether the program was submitted by staff or not.
* **Submitted At** (`submitted_at`, date, required): Enter the timestamp when the program was submitted.
* **Created At** (`created_at`, date, required): Enter the timestamp when the program was created.
* **Updated At** (`updated_at`, date, required): Enter the timestamp when the program was last updated.
* **Deleted At** (`deleted_at`, date, required): Enter the timestamp when the program was deleted.
* **Deleted By** (`deleted_by`, select_one, required): Select whether the program was deleted by staff or not.
* **Attachments** (`attachments`, select_multiple, required): Select whether any attachments are included.
* **File Attachments** (`file_attachments`, select_multiple, required): Select whether file attachments are included.
* **Staff Attachments** (`staff_attachments`, select_multiple, required): Select whether staff attachments are included.
* **Attachment Files** (`attachment_files`, select_multiple, required): Select whether attachment files are included.
* **Staff Notes** (`staff_notes`, text, required): Enter any notes from staff.
* **Staff Response** (`staff_response`, text, required): Enter the response from staff.
* **Cancellation Status** (`cancellation_status`, select_one, required): Select whether the program is active or inactive.
* **Submission Status** (`submission_status`, select_one, required): Select whether the submission is active or inactive.
* **Deleted** (`deleted`, text, optional): Enter any details about the deletion of the program.
* **Notes** (`notes`, text, optional): Enter any additional notes.
* **File Attachments** (`file_attachments`, select_multiple, optional): Select whether file attachments are included.
* **Staff Attachments** (`staff_attachments`, select_multiple, optional): Select whether staff attachments are included.
* **Staff Attachments** (`staff_attachments`, select_multiple, optional): Select whether staff attachments are included.
* **Attachment Files** (`attachment_files`, select_multiple, optional): Select whether attachment files are included.
* **Staff Notes** (`staff_notes`, text, optional): Enter any notes from staff.
