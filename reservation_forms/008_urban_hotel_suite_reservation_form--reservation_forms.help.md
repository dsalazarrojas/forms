# Urban Hotel Suite Reservation Form - Help Guide

## Purpose
The Urban Hotel Suite Reservation Form is a digital tool used by guests to reserve a suite at the hotel. The form collects information about the guest's booking preferences, including their name, contact details, room type, and payment information. This guide will walk you through the steps to complete the form and provide an explanation of each field.

## How To Complete This Form
To complete the form, follow these steps:

1. Select the booking date from the calendar.
2. Enter the guest's name in the format "First and Last Name".
3. Enter the guest's email address.
4. Enter the guest's phone number.
5. Select the room type (Single, Double, or Suite).
6. Enter the number of rooms booked.
7. Select the arrival date from the calendar.
8. Select the departure date from the calendar.
9. Enter any additional information or message for the guest.
10. Select the payment method (Cash, Card, or Bank Transfer).
11. Select the currency for the payment (USD, EUR, or JPY).
12. Enter the payment amount.
13. Enter the payment date.
14. Enter the payment time.
15. Enter the room number.
16. Enter the suite number.
17. Select the suite type (Standard, Luxurious, or Deluxe).
18. Select the features of the suite (Balcony, Gym, or Pool).
19. Select the source of the booking (Website, Social Media, or Referral).
20. Select the guest's country.
21. Enter the guest's city.
22. Enter the guest's postal code.
23. Enter the reservation status (Pending, Confirmed, or Cancelled).
24. (Optional) Enter the guest's additional information.

## Field-by-Field Explanation

* **Booking Date (`booking_date`)**: Select the date for which you are reserving the suite.
* **Guest Name (`guest_name`)**: Enter the guest's name in the format "First and Last Name" (e.g., John Doe).
* **Guest Email (`guest_email`)**: Enter the guest's email address.
* **Guest Phone (`guest_phone`)**: Enter the guest's phone number.
* **Room Type (`room_type`)**: Select the type of room you are reserving (Single, Double, or Suite).
* **Room Count (`room_count`)**: Enter the number of rooms you are reserving.
* **Arrival Date (`arrival_date`)**: Select the date you will arrive at the hotel.
* **Departure Date (`departure_date`)**: Select the date you will depart from the hotel.
* **Guest Message (`guest_message`)**: Enter any additional information or message for the guest.
* **Payment Method (`payment_method`)**: Select the method of payment (Cash, Card, or Bank Transfer).
* **Payment Currency (`payment_currency`)**: Select the currency for the payment (USD, EUR, or JPY).
* **Payment Amount (`payment_amount`)**: Enter the total payment amount.
* **Payment Date (`payment_date`)**: Select the date of payment.
* **Payment Time (`payment_time`)**: Select the time of payment.
* **Room Number (`room_number`)**: Enter the room number.
* **Suite Number (`suite_number`)**: Enter the suite number.
* **Suite Type (`suite_type`)**: Select the type of suite (Standard, Luxurious, or Deluxe).
* **Suite Features (`suite_features`)**: Select the features of the suite (Balcony, Gym, or Pool).
* **Booking Source (`booking_source`)**: Select the source of the booking (Website, Social Media, or Referral).
* **Guest Country (`guest_country`)**: Select the guest's country.
* **Guest City (`guest_city`)**: Enter the guest's city.
* **Guest Postal Code (`guest_postal_code`)**: Enter the guest's postal code.
* **Reservation Status (`reservation_status`)**: Select the status of the reservation (Pending, Confirmed, or Cancelled).
* **Guest Additional Info (`guest_additional_info`)**: Enter any additional information about the guest (optional).
