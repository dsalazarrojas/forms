# Garden Event Space Reservation Form - Help Guide
## Purpose
The Garden Event Space Reservation Form is used to reserve a space for a garden event. Event organizers can use this form to provide details about the event, including date, time, number of guests, and type of event.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the required fields, which are marked as "required" in the form.
2. Choose the correct option for "Event Type" from the list of available options.
3. Select the number of guests attending from the list of available options.
4. Enter your "Name" and "Email" in the format they should be.
5. Enter the "Date" and "Time" for the event.
6. Provide any additional "Event Details" in the text field.
7. Review and submit the form once completed.

## Field-by-Field Explanation
* **Garden Event** (`garden_event`): Enter a brief title for the event.
* **Name** (`name`): Enter your name as the event organizer.
* **Email** (`email`): Enter your email address for contact purposes.
* **Phone** (`phone`): Enter your phone number for contact purposes.
* **Date** (`date`): Select the date of the event.
* **Time** (`time`): Select the time of the event.
* **Event Details** (`event_details`): Enter any additional details about the event.
* **Event Type** (`event_type`): Choose the type of event (e.g., meeting, workshop, party).
* **Guests** (`guests`): Select the number of guests attending the event.
* **Submit** (`submit`): Review and submit the form once completed.
