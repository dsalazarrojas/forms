## Purpose
The "Thanksgiving Song Request" form is used to collect information about songs users would like to see played during our company's Thanksgiving celebrations.

## How To Complete This Form
To complete this form, follow these steps:

1.  Select "Yes" if you would like to submit a song request or "No" if not.
2.  If you selected "Yes", provide more details about the song by filling out the text fields for "Song Details", "Artist", "Album", and "Year".
3.  You can also provide the genre of the song.

## Field-by-Field Explanation

*   **Song Request** (`Song Request`, Select Multiple, optional): Select "Yes" if you would like to submit a song request or "No" if not.
*   **Song Details** (`song_details`, text, optional): If you selected "Yes" for the song request, enter a brief description of the song.
*   **Artist** (`artist`, text, optional): If you selected "Yes" for the song request, enter the name of the artist who performs the song.
*   **Album** (`album`, text, optional): If you selected "Yes" for the song request, enter the name of the album the song is part of.
*   **Year** (`year`, number, optional): If you selected "Yes" for the song request, enter the year the song was released.
*   **Genre** (`genre`, text, optional): Enter the genre of the song.

## Tips

*   Make sure to fill out all the fields accurately for your song request.
*   Double-check your information before submitting the form.
*   If you have any questions or need help with the form, feel free to contact us.
