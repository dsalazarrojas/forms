# Historic Tour Visitor Information Form - Help Guide
## Purpose
This form is used to capture the visitor information for a historic tour, allowing the tour guide to prepare for the tour and ensure a smooth experience for all visitors.

## How To Complete This Form
1. Fill in the visitor's First Name and Last Name fields.
2. Enter the visitor's Email and Phone fields, ensuring the format is correct.
3. Provide the visitor's Birth Date and Tour Date.
4. Specify the number of visitors attending the tour.
5. If applicable, provide any Special Requirements or Emergency Contact Information.
6. Choose the Payment Method for the tour (optional).
7. Add any Notes about the visitor (optional).
8. Select the Language Preference and Tour Language for the visitor.
9. Specify any Disabilities or Accessibility Features the visitor requires.
10. Enter the tour start and end times, as well as the start and end duration.
11. Specify the number of Adults, Children, and Infants attending the tour.

## Field-by-Field Explanation
* **First Name** (1, text, required): Enter the first name of the visitor.
* **Last Name** (2, text, required): Enter the last name of the visitor.
* **Email** (3, email, required): Enter the visitor's email address in the correct format (e.g., `john.doe@example.com`).
* **Phone** (4, text, required): Enter the visitor's phone number in the correct format (e.g., `123-456-7890`).
* **Birth Date** (5, date, required): Enter the visitor's birth date in the format `mm/dd/yyyy`.
* **Tour Date** (6, date, required): Enter the tour date in the format `mm/dd/yyyy`.
* **Number of Visitors** (7, number, required): Specify the total number of visitors attending the tour.
* **Special Requirements** (8, text, optional): If the visitor has any special requirements or needs, enter them here.
* **Emergency Contact Name** (9, text, required): Enter the name of the visitor's emergency contact.
* **Emergency Contact Relationship** (10, text, required): Specify the relationship between the visitor and their emergency contact (e.g., parent, guardian, etc.).
* **Emergency Contact Phone** (11, text, required): Enter the visitor's emergency contact phone number.
* **Emergency Contact Email** (12, email, optional): Enter the visitor's emergency contact email address.
* **Payment Method** (13, select_one, optional): Choose the payment method for the tour (e.g., Credit Card, PayPal, Bank Transfer).
* **Notes** (14, note, optional): Add any additional notes about the visitor.
* **Language Preference** (15, select_multiple, optional): Select the languages the visitor is comfortable with.
* **Tour Language** (16, select_one, required): Select the language of the tour.
* **Disability** (17, select_multiple, optional): Specify any disabilities the visitor has.
* **Accessibility Features** (18, select_multiple, optional): Choose any accessibility features the visitor requires.
* **Tour Start Time** (19, time, required): Enter the tour start time in the format `HH:MM`.
* **Tour Start Duration** (20, time, required): Enter the tour start duration in the format `HH:MM`.
* **Tour End Time** (21, time, required): Enter the tour end time in the format `HH:MM`.
* **Tour End Duration** (22, time, required): Enter the tour end duration in the format `HH:MM`.
* **Number of Adults** (23, number, required): Specify the number of adult visitors.
* **Number of Children** (24, number, required): Specify the number of child visitors.
* **Number of Infants** (25, number, required): Specify the number of infant visitors.
