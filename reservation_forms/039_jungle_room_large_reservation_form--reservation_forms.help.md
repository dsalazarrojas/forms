# Jungle Room Large Reservation Form - Help Guide
## Purpose
This form is designed for users to reserve a large Jungle Room for events or meetings. It gathers necessary information for event planning and management.

## How To Complete This Form
To complete this form, follow these steps:
1. Fill in the required fields: Event Type and Attendees.
2. Provide a name for the event in the Event Name field.
3. Choose a date for the event in the Date field.
4. Select a start and end time for the event in the Start Time and End Time fields.
5. Enter the expected number of attendees in the Group Size field.
6. Enter your contact email address in the Contact Email field.
7. Enter your contact phone number in the Contact Phone field (optional).
8. Add any additional event description in the Event Description field (optional).
9. Select the type of event from the Event Type options (or use the custom "Other" option if needed).
10. If you have specific attendees in mind, add them to the Attendees field.
11. If you have any special requests, add them to the Special Requests field (optional).

## Field-by-Field Explanation
* **Event Name**: Enter the name of the event that will be held in the Jungle Room.
* **Date**: Choose a date for the event.
* **Start Time**: Select the start time of the event.
* **End Time**: Select the end time of the event.
* **Group Size**: Enter the expected number of attendees for the event.
* **Contact Email**: Enter your contact email address.
* **Contact Phone**: Enter your contact phone number (this is an optional field).
* **Event Description**: Add a brief description of the event (this is an optional field).
* **Event Type**: Select the type of event that will be held (e.g. Meeting, Seminar, Conference, or Other).
* **Attendees**: Select the number of attendees from the options provided.
* **Special Requests**: Add any special requests or requirements for the event (this is an optional field).

## Tips
* Make sure to fill in all required fields (Event Type and Attendees).
* Be specific and clear in your event name and description.
* Double-check the date and time for your event.
* If you select "Other" for the Event Type, please specify the type of event in the Event Type Other field.
