# Pre Plan Funeral Form - Help Guide

## Purpose
The Pre Plan Funeral Form is a tool to help plan and organize funeral arrangements in advance. This form collects information about the deceased person's wishes and preferences for their funeral, including their name, family members, burial site, death date, and other relevant details.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill in the required fields, marked with an asterisk (\*). These fields are essential for planning the funeral.
2. Answer the questions truthfully and accurately, using the provided options for select fields.
3. Make sure to select all relevant options for each field, as some questions have multiple options.
4. Double-check your answers before submitting the form.

## Field-by-Field Explanation

* **Funeral Planner Name** (Funeral Planner Name, text, required): Enter the name of the person planning the funeral.
* **Family Members** (Family Members, select_multiple, required): Indicate if you have family members who will be part of the funeral planning process. Select 'Yes' to include them.
* **Funeral Type** (Funeral Type, select_one, required): Choose the type of funeral you wish to have (e.g., traditional, cremation, etc.).
* **Burial Site** (Burial Site, select_one, required): Select the site where you want to be buried (e.g., cemetery, cremation grounds, etc.).
* **Death Date** (Death Date, date, required): Enter the date of the deceased person's passing.
* **Burial Date** (Burial Date, date, required): Enter the date of the burial.
* **Burial Time** (Burial Time, time, required): Enter the time of the burial.
* **Burial Location** (Burial Location, text, required): Enter the specific location of the burial (e.g., cemetery name, address, etc.).
* **Funeral Service** (Funeral Service, select_multiple, required): Indicate if you want a funeral service (e.g., eulogy, music, etc.). Select 'Yes' for each service you desire.
* **Casket Type** (Casket Type, select_one, required): Choose the type of casket you prefer (e.g., wooden, metal, etc.).
* **Flowers** (Flowers, select_multiple, optional): Indicate if you want flowers at your funeral, selecting 'Yes' for each type you desire (e.g., roses, lilies, etc.).
* **Obituary** (Obituary, text, optional): Write a brief obituary or a description of the deceased person's life.
* **Visitation** (Visitation, select_multiple, optional): Indicate if you want visitation or viewing hours, selecting 'Yes' for each hour you desire (e.g., morning, afternoon, etc.).
* **Service Attire** (Service Attire, select_multiple, optional): Indicate if you have specific attire requests for the service, selecting 'Yes' for each item you desire (e.g., suit, dress, etc.).
* **Casket Color** (Casket Color, select_one, optional): Choose the color of the casket you prefer.
* **Headstone Material** (Headstone Material, select_one, optional): Choose the material of the headstone (e.g., granite, marble, etc.).
* **Headstone Size** (Headstone Size, select_one, optional): Choose the size of the headstone you prefer.
* **Headstone Design** (Headstone Design, select_one, optional): Choose the design of the headstone (e.g., simple, intricate, etc.).
* **Headstone Engravings** (Headstone Engravings, select_multiple, optional): Indicate if you want engravings on the headstone, selecting 'Yes' for each type you desire (e.g., names, dates, etc.).
* **Headstone Shape** (Headstone Shape, select_one, optional): Choose the shape of the headstone (e.g., rectangular, circular, etc.).
* **Headstone Color** (Headstone Color, select_one, optional): Choose the color of the headstone.
* **Flowers Type** (Flowers Type, select_multiple, optional): Indicate if you want specific types of flowers, selecting 'Yes' for each type you desire (e.g., roses, lilies, etc.).
* **Flowers Color** (Flowers Color, select_multiple, optional): Indicate if you have specific color preferences for flowers, selecting 'Yes' for each color you desire (e.g., red, white, etc.).
* **Visitation Attire** (Visitation Attire, select_multiple, optional): Indicate if you have specific attire requests for visitation, selecting 'Yes' for each item you desire (e.g., suit, dress, etc.).
* **Service Location** (Service Location, text, required): Enter the location of the funeral service (e.g., church, hall, etc.).
