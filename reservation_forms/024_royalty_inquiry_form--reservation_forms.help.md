# royalty_inquiry_form - Help Guide
## Purpose
The purpose of this form is to allow customers to inquire about making a reservation at a venue. Please fill out the form below to provide all necessary information for the venue to process your reservation request.

## How To Complete This Form
To complete this form, simply fill out the fields as requested and submit the form. Each field is marked with a required/optional indicator.

## Field-by-Field Explanation
* **Reservation Request** (`reservation_request`, text, optional): A brief description of the reservation request. Please provide a clear and concise description of the event you are inquiring about.
* **Event Name** (`event_name`, text, optional): The name of the event. This will help the venue identify the event and prepare for it.
* **Event Date** (`event_date`, date, optional): The date of the event. Please provide the date in the format `MM/DD/YY`.
* **Event Time** (`event_time`, time, optional): The time of the event. Please provide the time in the format `HH:MM AM/PM`.
* **Number of Guests** (`number_of_guests`, number, optional): The number of guests attending the event.
* **Email** (`email`, email, optional): The contact email address for the customer.
* **Phone** (`phone`, text, optional): The contact phone number for the customer.
* **Services** (`services`, select_one, optional): Select the services required for the event, such as Bartender or Cocktail Mixologist.
* **Special Requests** (`special_requests`, text, optional): Any special requests or additional information about the event.
* **Reservation Request 2** (`reservation_request_2`, text, optional): Another field for any additional reservation request.
* **Event Address** (`event_address`, text, optional): The address of the event location.
* **Event Location** (`event_location`, text, optional): The location of the event.
* **Event Description** (`event_description`, text, optional): A brief description of the event.
* **Contact Number** (`contact_number`, text, optional): The contact phone number for the customer.
* **Event Date 2** (`event_date_2`, date, optional): The date of the event (if different from the first event date).
* **Event Time 2** (`event_time_2`, time, optional): The time of the event (if different from the first event time).

## Tips
* Please provide accurate and complete information to ensure that the venue can process your reservation request correctly.
* If you have any questions or concerns, please don't hesitate to contact the venue directly.
* The venue will follow up with you after receiving your form submission to confirm the details and proceed with the reservation process.
