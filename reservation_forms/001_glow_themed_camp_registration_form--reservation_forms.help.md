# Glow Themed Camp Registration Form - Help Guide

## Purpose
The purpose of this form is to collect information for a glow-themed camp event.

## How To Complete This Form

1. Please fill out each page carefully, following the instructions for each field.
2. Ensure that you provide accurate and complete information for each field.
3. If you're unsure about any field, please ask for help or clarification.

## Field-by-Field Explanation

* **Camp Details**: Enter a brief description of the camp or event.
* **Participant Name**: Enter the name of the participant registering for the event.
* **Email**: Enter the participant's email address.
* **Phone Number**: Enter the participant's phone number.
* **Participant Preferences**: Enter any additional information about the participant.
* **Activity**: Select one of the available activities: Glow-in-the-Dark Paint Night, Laser Tag, or Glow-in-the-Dark Hike.
* **Dietary Restrictions**: Select any dietary restrictions, such as Cheese, Vegetarian, or Vegan.
* **Special Requirements**: Enter any special requirements or needs for the participant.
* **Emergency Contact**: Enter the name and phone number of the participant's emergency contact.
* **Payment Details**: Enter any payment information or details.
* **Participant Price**: Enter the participant's price or payment amount.
* **T-Shirt Size**: Select the participant's t-shirt size (XS, S, M, L, XL).
* **T-Shirt Color**: Select one or more t-shirt colors (Blue, Red, Green, Yellow, Orange).
* **Participant Dated**: Enter the date the participant will attend the event.
* **Participant Time**: Enter the time the participant will attend the event.
* **Participant Date**: Enter the date the participant will attend the event. (Note: This field seems to be a duplicate of Participant Dated. Please use one of these fields.)
* **Participant Time**: Enter the time the participant will attend the event. (Note: This field seems to be a duplicate of Participant Time. Please use one of these fields.)
* **Participant Notes**: Enter any additional comments or information about the participant.
* **Organizer Notes**: Enter any additional comments or information about the event.

Please note that some fields may be optional, and you can skip them if not applicable. Ensure that you fill out all required fields to complete the form accurately.
