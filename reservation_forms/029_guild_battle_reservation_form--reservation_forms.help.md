# Guild Battle Reservation Form - Help Guide
## Purpose
This form is designed to be completed by a guild member to reserve a battle with specific details such as date, time, arena, and player count.

## How To Complete This Form
To complete this form, follow these steps:
1. Select the correct arena for the battle from the list of options.
2. Choose the correct date and time for the battle.
3. Select the number of players that will be participating in the battle.
4. Confirm the start and end times for the battle.

## Field-by-Field Explanation
* **guild-battle-reservation-form** (Label, Text, Optional): This is the title of the form, which is not actually used in the form and can be ignored.
* **guild-battle-reservation-date** (Label, Date, Required): Enter the date of the guild battle in the format of MM/DD/YYYY.
* **guild-battle-start-time** (Label, Time, Optional): Enter the start time of the guild battle in the format of HH:MM AM/PM.
* **guild-battle-end-time** (Label, Time, Optional): Enter the end time of the guild battle in the format of HH:MM AM/PM.
* **number-of-players** (Label, Select Multiple, Required): Select whether there will be yes or no players participating in the battle.
* **arena** (Label, Select One, Required): Select the arena where the guild battle will take place.
* **reservation-date** (Label, Date, Required): Enter the date of the guild battle in the format of MM/DD/YYYY.
* **start-time-2** (Label, Time, Optional): Enter the start time of the second part of the guild battle in the format of HH:MM AM/PM.
* **end-time-2** (Label, Time, Optional): Enter the end time of the second part of the guild battle in the format of HH:MM AM/PM.
* **players-count-2** (Label, Select Multiple, Optional): Select whether there will be yes or no players participating in the second part of the battle.
* **arena-2** (Label, Select One, Optional): Select the arena for the second part of the guild battle, if applicable.
* **players-count** (Label, Select Multiple, Required): Select whether there will be yes or no players participating in the battle.
* **players-count-2** (Label, Select Multiple, Optional): Select whether there will be yes or no players participating in the second part of the battle.

## Tips
* Make sure to fill out all required fields to ensure the form can be submitted successfully.
* If there are multiple parts to the battle, fill out the corresponding fields for each part.
* Review the form for accuracy before submitting it.
