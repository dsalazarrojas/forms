# Event Seat Selection Form - Help Guide
## Purpose
The purpose of this form is to collect information from attendees for seat selection or reservation purposes. This form is designed to gather data for a specific event or gathering.

## How To Complete This Form
To complete this form, follow these steps:
1. Review the form carefully to ensure you are providing the correct information.
2. On page 1, select the seat you prefer for the event by choosing from the options provided. If you do not see your preferred seat, you can contact the event organizers for assistance.
3. On page 2, select the date you plan to attend the event. You can choose from the available dates provided in the dropdown menu.
4. Select the start time of the event you plan to attend. You can select from the available start times provided in the dropdown menu.
5. If you have any accessibility requirements or notes, please provide them in the text field. This information will help us accommodate your needs.

## Field-by-Field Explanation

* **Seat Selection** (`Seat Selection`, `select_one`, required: false): Select your preferred seat for the event. If you don't see your preferred seat, please contact the event organizers for assistance.
* **Date** (`Date`, `date`, required: false): Select the date you plan to attend the event. You can choose from the available dates provided.
* **Start Time** (`Start Time`, `time`, required: false): Select the start time of the event you plan to attend. You can choose from the available start times provided.
* **Accessibility Notes** (`Accessibility Notes`, `text`, required: false): Provide any accessibility requirements or notes you may have. This information will help us accommodate your needs.
