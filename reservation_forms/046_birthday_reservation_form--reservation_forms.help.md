# Birthday Reservation Form - Help Guide
## Purpose
The Birthday Reservation Form is a tool to help us better understand your birthday celebration needs and preferences. It's a one-time form to book and customize your special day with us.

## How To Complete This Form
1.  Click on each field to fill out the required information for your birthday celebration.
2.  Ensure that all fields are filled accurately to avoid miscommunication and potential cancellations.
3.  If a field is unclear, please don't hesitate to reach out for assistance.

## Field-by-Field Explanation
* **Contact Person Name**: Enter the full name of the person booking the celebration.
	+ Type: Text
	+ Required: Yes
* **Email Address**: Enter the email address where you can be contacted about this reservation.
	+ Type: Email
	+ Required: Yes
* **Phone Number**: Enter the contact phone number for this reservation.
	+ Type: Text
	+ Required: Yes
* **Birthday Person's Name**: Enter the name of the person celebrating their birthday.
	+ Type: Text
	+ Required: Yes
* **Age Turning**: Enter the age of the person celebrating their birthday.
	+ Type: Number
	+ Required: Yes
* **Actual Birth Date**: Enter the actual birthday date of the person celebrating.
	+ Type: Date
	+ Required: No
* **Celebration Date**: Select the date for the celebration.
	+ Type: Date
	+ Required: Yes
* **Start Time**: Select the time when you'd like the celebration to start.
	+ Type: Time
	+ Required: Yes
* **End Time**: Select the time when you'd like the celebration to end.
	+ Type: Time
	+ Required: Yes
* **Number of Guests**: Enter the number of guests expected.
	+ Type: Number
	+ Required: Yes
* **Number of Children**: Enter the number of children attending.
	+ Type: Number
	+ Required: No
* **Number of Adults**: Enter the number of adults attending.
	+ Type: Number
	+ Required: No
* **Type of Celebration**: Select the type of celebration you're planning (e.g., Casual Family Party, Themed Party, etc.).
	+ Type: Select One
	+ Required: Yes
* **Party Theme**: If applicable, enter any specific party theme.
	+ Type: Text
	+ Required: No
* **Dining Preference**: Select the type of food service you'd like (e.g., Full Meal Service, Appetizers and Drinks, etc.).
	+ Type: Select One
	+ Required: Yes
* **Cake Preference**: Select how you'd like to handle cake.
	+ Type: Select One
	+ Required: No
* **Interest in Entertainment**: If you'd like to have entertainment or activities, select Yes.
	+ Type: Select One
	+ Required: No
* **Special Requests or Preferences**: If you have any specific requests or requirements, enter them here.
	+ Type: Text
	+ Required: No
* **Dietary Restrictions**: Select any dietary needs or restrictions for your guests.
	+ Type: Select Multiple
	+ Required: No
* **Accessibility Requirements**: If you or your guests have any accessibility needs, enter them here.
	+ Type: Text
	+ Required: No
* **Noise Sensitivities**: If you'd like to accommodate any sound-sensitive guests, select Yes.
	+ Type: Select One
	+ Required: No
* **Estimated Total Cost**: Enter the expected expense for the celebration.
	+ Type: Number
	+ Required: No
* **Deposit Amount**: If applicable, enter the deposit amount needed to hold the reservation.
	+ Type: Number
	+ Required: No
* **Preferred Payment Method**: Select your preferred payment method.
	+ Type: Select One
	+ Required: Yes
* **Payment Schedule**: Select when payment is due.
	+ Type: Select One
	+ Required: Yes
* **I understand the Cancellation Policy**: Confirm that you've read and understand our cancellation policy.
	+ Type: Select One
	+ Required: Yes
* **I understand the Refund Policy**: Confirm that you've read and understand our refund policy.
	+ Type: Select One
	+ Required: Yes
* **I confirm this reservation request**: This is your final confirmation of the reservation.
	+ Type: Select One
	+ Required: Yes
* **May we contact you about this reservation**: Select whether we can contact you about this reservation.
	+ Type: Select One
	+ Required: No

## Tips
* Please ensure that all fields are filled accurately to avoid miscommunication and potential cancellations.
* If you have any questions or concerns, don't hesitate to reach out to us.
* We appreciate your attention to the provided fields and any additional comments or requests you may have.
* We'll follow up with you with a confirmation of your reservation once this form is submitted.
