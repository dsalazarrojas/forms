# Facility Request Form - Help Guide
## Purpose
The Facility Request Form is designed to collect information about a facility request for a specific purpose or project. Fill out this form to provide detailed information about your facility request.

## How To Complete This Form
To complete this form, follow these steps:
1. Read the instructions carefully.
2. Answer each question thoroughly.
3. Fill in all required fields.
4. Provide clear and concise information.

## Field-by-Field Explanation
* **Facility Request Form 1** (`facility_request_form_1`, text, required): This field is for the facility type (e.g. conference room, office, laboratory).
* **Facility Request Form 2** (`facility_request_form_2`, text, required): This field is for the specific location of the facility within the building or campus.
* **Facility Request Form 3** (`facility_request_form_3`, text, required): This field is for the expected start date of the facility usage.
* **Facility Request Form 4** (`facility_request_form_4`, text, required): This field is for the expected end date of the facility usage.
* **Facility Request Form 5** (`facility_request_form_5`, text, required): This field is for the facility request purpose or project name.
* **Facility Request Form 6** (`facility_request_form_6`, text, required): This field is for any additional information or details about the facility request.
* **Facility Request Form 7** (`facility_request_form_7`, text, required): This field is for the expected number of users or attendees.
* **Facility Request Form 8** (`facility_request_form_8`, text, required): This field is for any special equipment or setup requirements.
* **Facility Request Form 9** (`facility_request_form_9`, text, required): This field is for any other information or requests.
* **Facility Request Form 10** (`facility_request_form_10`, text, required): This field is for the name of the requestor or representative.
* **Facility Request Form 11** (`facility_request_form_11`, text, required): This field is for contact information (e.g., phone number, email).
* **Facility Request Form 12** (`facility_request_form_12`, text, required): This field is for any additional comments or attachments.

## Tips
* Be clear and concise in your responses.
* Use real names and contact information.
* Attach any relevant documents or images.
* Review your form carefully before submitting.
