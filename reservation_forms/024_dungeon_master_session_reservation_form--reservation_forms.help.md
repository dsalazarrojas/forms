# Dungeon Master Session Reservation Form - Help Guide

## Purpose
This form is for reserving a Dungeon Master (DM) session. It collects details about the players who will participate in the session and the game settings that will be used. The goal is to ensure that the DM knows who is attending and what type of game they will be playing.

## How To Complete This Form

To complete this form, follow these steps:

1. Enter a brief title for the session in the text field at the top of the form.
2. Select the players who will be participating in the session from the dropdown list.
3. Enter the email and phone number of each player.
4. Choose the game duration in hours.
5. Select the type of game system that will be used (e.g., D&D 5th, Pathfinder, etc.).
6. Choose the game level (e.g., Beginner, Intermediate, Advanced).
7. Select how often the game will be played (e.g., Weekly, Bi-Weekly, Monthly).
8. Select the game day of the week.
9. Enter the game start and end times.
10. Enter any game notes (e.g., game settings, plot, etc.).
11. Enter any player notes (e.g., player character name, abilities, etc.).
12. Enter the DM's name, phone number, and email.
13. Enter the game store where the session will be held, along with its location and contact information.
14. Finally, click "Submit" to complete the form.

## Field-by-Field Explanation

* **reservation_form** (text, optional): Enter a brief title for the session.
* **player_details** (select multiple, optional): Select the players who will be participating in the session.
* **player_name** (text, optional): Enter the name of each player.
* **player_email** (email, optional): Enter the email address of each player.
* **player_phone** (text, optional): Enter the phone number of each player.
* **session_date** (date, optional): Enter the date of the session (not currently supported).
* **session_time** (time, optional): Enter the time of the session (not currently supported).
* **game_duration** (number, optional): Enter the duration of the game in hours.
* **game_system** (select one, optional): Select the game system that will be used (e.g., D&D 5th, Pathfinder, etc.).
* **game_level** (select one, optional): Select the level of the game (e.g., Beginner, Intermediate, Advanced).
* **game_frequency** (select one, optional): Select how often the game will be played (e.g., Weekly, Bi-Weekly, Monthly).
* **game_day** (select one, optional): Select the day of the week the game will be played.
* **game_start_time** (time, optional): Enter the start time of the game.
* **game_end_time** (time, optional): Enter the end time of the game.
* **game_notes** (note, optional): Enter any notes about the game (e.g., game settings, plot, etc.).
* **player_notes** (note, optional): Enter any notes about the player (e.g., player character name, abilities, etc.).
* **dms_notes** (note, optional): Enter any notes about the DM (e.g., experience, etc.).
* **game_store** (text, optional): Enter the name of the game store where the session will be held.
* **game_store_location** (text, optional): Enter the location of the game store.
* **game_store_phone** (text, optional): Enter the phone number of the game store.
* **game_store_email** (email, optional): Enter the email address of the game store.
* **dms_name** (text, optional): Enter the name of the DM.
* **dms_phone** (text, optional): Enter the phone number of the DM.
* **dms_email** (email, optional): Enter the email address of the DM.

**Tips:** If you are unsure about any of the fields, please ask the DM or game store staff for clarification. They will be happy to help you complete the form correctly.
