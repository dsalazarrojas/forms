# Detailed Service Request - Help Guide
## Purpose
The "Detailed Service Request" form is designed to collect information about a specific service request from a customer or end-user. This form helps us gather all the necessary details to provide an efficient and effective service.

## How To Complete This Form
1. **Service Request**: Provide a brief description of the service you require, such as "Haircut" or "Oil change".
2. **Description**: Add a more detailed explanation of the service you need. This is a text area where you can provide any additional information to help us better understand your request.
3. **Service Type**: Select the type of service you need from the provided options (Haircut, Oil change, Tire rotation).
4. **Date**: Choose the date on which you would like to have your service done. Please format the date as mm/dd/yyyy.
5. **Time**: Select the time slot you prefer for your service. Please format the time as 12-hour clock format (e.g., 10:00 AM).
6. **Contact Information**: Enter any relevant contact information, such as a phone number or email address.
7. **Email**: Enter a valid email address so we can communicate with you.
8. **Phone**: Add a phone number where you can be reached.

* **Service Request**: This field is where you provide the main service you need (e.g., Haircut).
