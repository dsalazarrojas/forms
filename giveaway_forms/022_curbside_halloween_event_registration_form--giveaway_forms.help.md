# Curbside Halloween Event Registration Form - Help Guide
## Purpose
The Curbside Halloween Event Registration Form is intended to collect information from participants about their attendance and interests for the Curbside Halloween event. Please fill out the form carefully to provide accurate information.

## How To Complete This Form
1.  Click on the "Submit" button at the end of the form.
2.  Fill out each field accurately and completely.
3.  Review your entries before submitting the form.

## Field-by-Field Explanation

*   **User Information** (`user_info`, text, optional): Fill in your first and last name.
    Please enter your first and last name for event organizers to address you properly.

*   **How do you want to be contacted?** (`contact_method`, select multiple, optional): Select one or more ways you would like to be contacted, such as First Name, Last Name, Phone Number, or Email Address.
    Select all the ways you would like to be contacted. For example, if you want both phone and email, make sure to select both.

*   **Are you attending the Curbside Halloween event?** (`event_participation`, select one, optional): Indicate if you're attending the event. Select 'True' if you are attending and 'False' if not.
    Choose 'True' if you are attending the event.

*   **Additional Comments** (`additional_comments`, text, optional): Add any additional comments about your attendance or preferences.
    This is an optional field for any additional comments or preferences. Please keep it brief and clear.

*   **Do not forget to pick up your goodies at the assigned pickup time** (`form_completion`, note, optional): This is a note to remind you to pick up your goodies at the assigned pickup time.
    This is a reminder for you to pick up your goodies at the assigned time.

*   **Date and Time of the Curbside Halloween event** (`event_date_time`, date, optional): Select the date and time of the Curbside Halloween event.
    This field is not relevant for participants. It's for organizers to keep track of event time.

*   **Participant Name** (`participant_name`, text, optional): Fill in your name as the participant.
    Please enter your name as the participant so that organizers can address you properly.

*   **Participant Phone** (`participant_phone`, text, optional): Fill in your phone number as the participant.
    Please enter your phone number so that organizers can contact you.

*   **Participant Email** (`participant_email`, email, optional): Fill in your email address as the participant.
    Please enter your email address so that organizers can contact you.

*   **Participant Address** (`participant_address`, text, optional): Fill in your address as the participant.
    Please enter your address so that organizers can send you any necessary information or goodies.

*   **Participant Age** (`participant_age`, number, optional): Select your age as the participant.
    Please enter your age so that organizers can know your age group.

*   **Participant Gender** (`participant_gender`, select one, optional): Select your gender as the participant.
    Please select your gender.

*   **What interests the participant?** (`participant_interests`, select multiple, optional): Select the interests of the participant.
    Select all the interests that apply.

*   **What allergies does the participant have?** (`participant_allergies`, select multiple, optional): Select the allergies of the participant.
    Select all the allergies that apply.

*   **What diet does the participant follow?** (`participant_diet`, select multiple, optional): Select the diet of the participant.
    Select all the diets that apply.

*   **What medical conditions does the participant have?** (`participant_medical_conditions`, select multiple, optional): Select the medical conditions of the participant.
    Select all the medical conditions that apply.

*   **Are there any special requests?** (`participant_special_requests`, note, optional): Add any special requests of the participant.
    This is an optional field for any special requests. Please keep it brief and clear.

*   **What special skills does the participant have?** (`participant_special_skills`, select multiple, optional): Select the special skills of the participant.
    Select all the special skills that apply.

*   **What education does the participant have?** (`participant_education`, select multiple, optional): Select the education of the participant.
    Select all the education that apply.

*   **What is the participant's employment status?** (`participant_employed`, select one, optional): Select the employment status of the participant.
    Please select your employment status.

*   **What is the participant's income range?** (`participant_income`, select multiple, optional): Select the income range of the participant.
    Select all the income ranges that apply.

*   **What are the participant's hobbies?** (`participant_hobbies`, select multiple, optional): Select the hobbies of the participant.
    Select all the hobbies that apply.

*   **What languages does the participant speak?** (`participant_languages`, select multiple, optional): Select the languages that the participant speaks.
    Select all the languages that apply.

*   **What is the participant's social media presence?** (`participant_social_media`, select multiple, optional): Select the social media presence of the participant.
    Select all the social media presence that apply.

## Tips
1.  Be accurate when filling out the form.
2.  Review your entries before submitting the form.
3.  If you have any doubts, contact the event organizers.
