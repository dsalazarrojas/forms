# Sweepstakes Entry Form - Help Guide
## Purpose
The Sweepstakes Entry Form is designed to collect essential information about a sweepstakes entry for tracking and management purposes.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the required fields, marked with an asterisk (*).
   - Enter your user name in the "Enter User Name" field.
   - Enter your email address in the "Enter Email" field.
   - Enter your phone number in the "Enter Phone Number" field.
   - Enter the sweepstakes ID in the "Sweepstakes ID" field.
   - Select the entry date in the "Entry Date" field in the format `YYYY-MM-DD` (e.g., `2022-02-15`).
   - Select the submission date in the "Submission Date" field in the format `YYYY-MM-DD` (e.g., `2022-02-15`).
   - Select the entry time in the "Entry Time" field in the format `HH:MM AM/PM` (e.g., `10:00 AM`).

2. If required, fill in the optional fields for further details about the sweepstakes and entry.

## Field-by-Field Explanation

- **Enter User Name* (required):** The name you want to be associated with this sweepstakes entry.
- **Enter Email* (required):** A valid email address you can be reached at.
- **Enter Phone Number* (required):** Your phone number for contact purposes.
- **Sweepstakes ID* (required):** The ID of the sweepstakes you are entering.
- **Entry Date* (required):** The date you entered the sweepstakes in the format `YYYY-MM-DD`.
- **Submission Date* (required):** The date you submitted your entry in the format `YYYY-MM-DD`.
- **Entry Time* (required):** The time you entered the sweepstakes in the format `HH:MM AM/PM`.
- **Entry Details (optional):** Any additional information you want to include about your entry.
- **Prize (optional):** The prize you are entering for, if applicable.
- **Winner (optional):** The winner status of your entry, if known.
- **Sweepstakes Image (optional):** An image related to the sweepstakes, if available.
- **Prize Image (optional):** An image related to the prize, if available.
- **Entry Instructions (optional):** Any instructions or guidelines related to the entry, if provided.
- **Rules (optional):** Any rules or terms and conditions related to the sweepstakes, if provided.
- **Sweepstakes Link (optional):** A link to the sweepstakes page, if available.
- **Entry Link (optional):** A link to your entry, if available.
- **Sweepstakes Image (optional):** Another sweepstakes-related image, if available.
- **Entry Type (optional):** The type of entry you are submitting, if applicable.
- **Entry Status (optional):** The status of your entry, if known.
- **Created At (optional):** The date and time the entry was created, if available.
- **Updated At (optional):** The last time the entry was updated, if available.
- **Deleted At (optional):** The date and time the entry was deleted, if applicable.
- **Winner Status (optional):** The winner status of your entry, if known.
- **Winner Type (optional):** The type of winner you are, if applicable.
- **Prize Amount (optional):** The amount of the prize, if applicable.
