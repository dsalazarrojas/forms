# School Supply Giveaway Registration Form - Help Guide
## Purpose
This form is used to register schools and students for a school supply giveaway program. It collects information about the school's interest in participating and the student's contact method.

## How To Complete This Form

To complete this form, follow these steps:

1. Select "Yes" for each page that applies to you:
   * contact_info: This is about your contact information (school or student).
   * school_info: This is about your school information (school or student).
   * student_info: This is about the student(s) you are registering for the giveaway.
   * school_info_2: This is about additional school information (school or student).
   * contact_method: This is about how you would like to be contacted.
   * contact_method_2: This is about how you would like to be contacted as a school.

## Field-by-Field Explanation
* **Contact Information** (`contact_info`, `select_one`, required: false): Select "Yes" to share your contact information.
* **School Information** (`school_info`, `select_one`, required: false): Select "Yes" to share your school information.
* **Student Information** (`student_info`, `select_multiple`, required: false): Select "Yes" for each student you are registering for the giveaway.
* **Student Information 2** (`student_info_2`, `select_multiple`, required: false): Select "Yes" for each student you are registering for the giveaway.
* **School Information 2** (`school_info_2`, `select_one`, required: false): Select "Yes" to share additional school information.
* **Contact Method** (`contact_method`, `select_one`, required: false): Select how you would like to be contacted for the giveaway.
* **Contact Method 2** (`contact_method_2`, `select_one`, required: false): Select how you would like to be contacted as a school.

## Tips

* Make sure to select "Yes" for all applicable pages to ensure you are registered for the giveaway.
* If you are unsure about any of the fields, feel free to contact the giveaway organizers for clarification.
