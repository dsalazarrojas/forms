# Employee Payroll Change Form - Help Guide
## Purpose
The Employee Payroll Change Form is used to update an employee's payroll information, including job categories, dates, and contact details.

## How To Complete This Form
1. Fill in the **Form Title** field with a brief description of the reason for the change.
2. Provide a detailed description of the change in the **Form Description** field.
3. Select the **Form Category** from the provided options.
4. If the change is not listed in the **Form Category** options, select **Category (other)** and enter the new category in the **Category (other)** field.
5. Enter the new **Title 2** and **Description 2** if applicable.
6. Select the new **Category 3** and **Category 4** from the provided options.
7. Enter the new **Date** of the change.
8. If applicable, enter the new **Phone** and **Email** details.
9. Enter any additional **Note** or **Note 2** if necessary.
10. Select the desired options for **Checkbox** and **Select One** fields.
11. Select multiple options for **Select Multiple** field if necessary.
12. Enter the new **Decimal** and **Integer** values if applicable.

## Field-by-Field Explanation

* **Form Title** (`form_title`, `text`, required: false): Enter a brief description of the reason for the change.
* **Form Description** (`form_description`, `text`, required: false): Provide a detailed description of the change.
* **Form Category** (`form_category`, `text`, required: true): Select the category of the change.
* **Category (other)** (`form_category_other`, `select_one`, required: false): Select "Category (other)" if the change is not listed in the **Form Category** options, and enter the new category in this field.
* **Title 2** (`form_title_2`, `text`, required: false): Enter the new title.
* **Description 2** (`form_description_2`, `text`, required: false): Provide a detailed description of the change.
* **Category 3** (`form_category_2`, `text`, required: true): Select the new category.
* **Category 4** (`form_category_2`, `text`, required: true): Select the new category.
* **Date** (`form_date`, `date`, required: true): Enter the new date of the change.
* **Date 2** (`form_date`, `date`, required: false): Enter the new date 2 if applicable.
* **Time** (`form_time`, `time`, required: false): Enter the new time if applicable.
* **Phone** (`form_phone`, `text`, required: false): Enter the new phone number.
* **Email** (`form_email`, `text`, required: false): Enter the new email address.
* **Note** (`form_note`, `note`, required: false): Enter any additional notes.
* **Note 2** (`form_note_2`, `note`, required: false): Enter any additional notes 2 if necessary.
* **Checkbox** (`form_checkbox`, `select_multiple`, required: false): Select multiple options if necessary.
* **Select One** (`form_select_one`, `select_one`, required: true): Select the new option.
* **Select Multiple** (`form_select_multiple`, `select_multiple`, required: false): Select multiple options if necessary.
* **Decimal** (`form_decimal`, `number`, required: false): Enter the new decimal value.
* **Integer** (`form_integer`, `number`, required: false): Enter the new integer value.
* **Integer 2** (`form_integer_2`, `number`, required: false): Enter the new integer 2 if necessary.
