# Employee Complaint Form - Help Guide
## Purpose
The Employee Complaint Form is a tool to help employees report and document incidents or issues they have experienced within the organization. This form should be used to report complaints that are not resolved through internal channels.

## How To Complete This Form
To complete this form, follow these steps:

1. Make sure you have the required information and permissions to complete the form.
2. Fill in the Employee ID field with your own employee ID number.
3. Enter the Date Of Complaint field with the date the incident or issue occurred.
4. Provide a detailed Description Of Complaint in the text field.
5. Answer the question "Reported By" with "Yes" if you are reporting the complaint, and "No" if someone else is reporting it for you.
6. Enter the ID of the employee you are reporting against in the Employee Against ID field. If you're not sure of the ID, you can search for it in the employee database.
7. Enter the name of the employee you are reporting against in the Employee Against Name field.
8. If applicable, enter the ID of the senior manager against in the Senior Manager Against ID field, and their name in the Senior Manager Against Name field.
9. Enter the ID of the supervisor against in the Supervisor Against ID field, and their name in the Supervisor Against Name field.
10. Enter the Department ID of where the incident or issue occurred in the Department ID field.
11. Enter the Department Name in the Department Name field.
12. Select all the types of employees who are involved in the complaint (e.g. regular employee, manager, contractor) in the Employee Type field.

## Field-by-Field Explanation

* **Employee ID**: Enter your own employee ID number.
* **Date Of Complaint**: Enter the date the incident or issue occurred.
* **Description Of Complaint**: Provide a detailed description of the incident or issue you're reporting.
* **Reported By**: Answer "Yes" if you are reporting the complaint, and "No" if someone else is reporting it for you.
* **Employee Against ID**: Enter the ID of the employee you are reporting against. If you're not sure of the ID, you can search for it in the employee database.
* **Employee Against Name**: Enter the name of the employee you are reporting against.
* **Senior Manager Against ID**: If applicable, enter the ID of the senior manager against, and their name will be populated automatically. If you're not sure of the ID, you can search for it in the employee database.
* **Senior Manager Against Name**: If applicable, enter the name of the senior manager against.
* **Supervisor Against ID**: If applicable, enter the ID of the supervisor against, and their name will be populated automatically. If you're not sure of the ID, you can search for it in the employee database.
* **Supervisor Against Name**: If applicable, enter the name of the supervisor against.
* **Department ID**: Enter the Department ID of where the incident or issue occurred.
* **Department Name**: Enter the Department Name.
* **Employee Type**: Select all the types of employees who are involved in the complaint (e.g. regular employee, manager, contractor).

## Tips

* Make sure to provide as much detail as possible in the Description Of Complaint field.
* If the employee you are reporting against is not in the system, please contact HR for assistance.
* If you're unsure about any of the fields, please ask HR for guidance.
* Please note that this form should only be used for reporting complaints that are not resolved through internal channels.
* If you have any questions or concerns, please contact HR for support.
