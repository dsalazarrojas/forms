# Employee Performance Evaluation Form - Help Guide
## Purpose
The Employee Performance Evaluation Form is designed to help managers and supervisors assess an employee's progress, provide feedback and guidance for improvement, and evaluate overall performance. This form will help track employee performance over time, allowing for regular evaluations and adjustments.

## How To Complete This Form
To complete this form, follow these steps:

1. **Employee Performance Form**: This is the main section where you will enter a brief description of the employee's performance.
2. **Employee Name**: Enter the employee's name as it appears in the company records or directory.
3. **Department**: Select the department the employee belongs to from the provided options (Marketing, Sales, Support).
4. **Job Title**: Choose the job title that best describes the employee's role from the options (Team Lead, Senior Team Lead, Manager).
5. **Performance Metrics**: Enter any relevant performance metrics or data related to the employee's work.
6. **Evaluation Date**: Enter the date of the evaluation in the format mm/dd/yyyy.
7. **Evaluation Frequency**: Select the frequency of the evaluation from the provided options (Annual, Semi-Annual, Quarterly).
8. **Evaluation Comments**: Enter any comments or feedback you have about the employee's performance.
9. **Feedback Given**: Enter any feedback or suggestions you have for the employee.
10. **Rating**: Choose the rating that best describes the employee's performance from the provided options (Excellent, Fair, Needs Improvement).
11. **Recommended Action Items**: Enter any recommended action items or tasks for the employee to improve their performance.
12. **Overall Performance**: Select the overall performance of the employee from the provided options (Excellent, Fair, Needs Improvement).

- **Employee Performance Form**: Enter a brief description of the employee's performance, including any notable achievements or areas that need improvement.

- **Recommended Action Items**: Enter any recommended action items or tasks for the employee to improve their performance, which can be tailored to their specific needs.
