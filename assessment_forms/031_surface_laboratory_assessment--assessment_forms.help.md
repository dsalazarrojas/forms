# Surface Laboratory Assessment - Help Guide
## Purpose
The "Surface Laboratory Assessment" form is used to collect and document information about a surface test, its results, and other relevant details.

## How To Complete This Form
To complete this form, follow these steps:

*   Start by filling in the "Surface test form" page with any additional details about the test, if needed.
*   On the next page, fill in the "Surface Test" field with a description of the test that was conducted.
*   Enter the test result in the "Test Result" field. This field is expected to be a numerical value.
*   In the "Sample ID" field, enter the identifier for the surface being tested.
*   Select the type of test conducted from the "Test Type" dropdown menu.
*   If applicable, enter the date and time of the test in the "Test Date" and "Test Time" fields, respectively.
*   Finally, select the status of the test result from the "Result Status" dropdown menu.

## Field-by-Field Explanation
*   **Surface test form (text)**: This field is where you can enter any additional details about the test.
*   **Surface Test (text)**: Enter a description of the test that was conducted.
*   **Test Result (number)**: Enter the result of the test as a numerical value.
*   **Sample ID (text)**: Enter the identifier for the surface being tested.
*   **Test Type (select_one)**: Select the type of test conducted from the available options: Blood test, Urine test, or Other.
*   **Test Date (date)**: If the test was performed on a specific date, enter it in this field.
*   **Test Time (time)**: If the test was performed on a specific time of day, enter it in this field.
*   **Result Status (select_one)**: Select the current status of the test result from the available options: Pending, Complete, or Cancelled.

## Tips
*   Make sure to fill in all required fields for the form.
*   If a field is marked as optional, it's up to you to decide whether to fill it in or not.
*   Be accurate when filling in numerical values for the test result.
*   Be precise when selecting the test type and result status.
*   Double-check your entries before submitting the form.
*   If you're unsure about any field, feel free to ask for clarification or support.
