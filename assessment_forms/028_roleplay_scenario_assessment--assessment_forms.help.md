# Roleplay Scenario Assessment - Help Guide
## Purpose
This form is designed to gather information from evaluators about roleplay scenarios. It includes various fields to collect ratings, feedback, and other relevant details.

## How To Complete This Form
- Start by reviewing the provided roleplay scenario.
- Go through each field and fill out the required and optional sections accordingly.
- Ensure that you have provided accurate and complete information for each field.

## Field-by-Field Explanation

* **What was the overall scenario rating?** (`scenario_rating`, number, required): Rate the overall quality of the scenario, using a numerical value. This rating will help in determining the scenario's quality and effectiveness.
* **Describe the scenario** (`scenario_description`, text, optional): Provide a detailed description of the scenario, including any notable aspects or areas for improvement.
* **Evaluator feedback** (`evaluator_feedback`, text, optional): Share any relevant feedback or comments you have about the scenario. This helps in identifying areas of improvement and providing constructive feedback.
* **Evaluator rating** (`evaluator_rating`, number, optional): Rate the scenario based on its overall quality. This rating is used to measure the scenario's performance.
* **What type of scenario was this?** (`scenario_type`, select_multiple, optional): Select the type of scenario from the provided options, which include Acting scenario, Role-play scenario, Role-playing scenario, Scenario, and Role-Playing scenario.
* **Evaluation date** (`evaluation_date`, date, optional): Record the date of the evaluation, which helps track the progress and timeline of the scenario.
* **Evaluation time** (`evaluation_time`, time, optional): Record the time of the evaluation, which can be useful for tracking the duration of the scenario.
* **Evaluator name** (`evaluator_name`, text, optional): Provide your name as the evaluator, which helps identify who evaluated the scenario.
* **Evaluator title** (`evaluator_title`, text, optional): Enter your title or position, which can provide additional context and credibility to the evaluation.
* **Evaluator department** (`evaluator_department`, text, optional): Enter your department or team, which can help in identifying any potential biases or affiliations.
* **Describe the details of the scenario** (`scenario_description_details`, text, optional): Provide any additional details about the scenario, which can be helpful for future reference.
* **Scenario objectives** (`scenario_objectives`, text, optional): Outline the objectives of the scenario, which can help in understanding its purpose and goals.
* **Scenario context** (`scenario_context`, text, optional): Provide the context in which the scenario was evaluated, which can be useful for future planning and development.
* **Roleplay scenario type** (`roleplay_scenario_type`, text, optional): Select the type of roleplay scenario from the provided options.
* **Evaluation form id** (`evaluation_form_id`, text, optional): Enter the unique identifier for the evaluation form, which can help in tracking and reference.
* **Scenario number** (`scenario_number`, number, optional): Enter the number of the scenario, which can be helpful for organization and tracking.
* **Roleplay scenario name** (`roleplay_scenario_name`, text, optional): Enter the name of the roleplay scenario, which can help in identification and reference.
* **Roleplay scenario description** (`roleplay_scenario_description`, text, optional): Provide a detailed description of the roleplay scenario, which can be helpful for future reference.
* **Roleplay scenario status** (`roleplay_scenario_status`, select_multiple, optional): Select the status of the roleplay scenario from the provided options, which include Draft, Approved, Rejected, Completed, Archived, and Pending.
* **Roleplay scenario priority** (`roleplay_scenario_priority`, number, optional): Enter the priority of the scenario, which can help in scheduling and prioritizing.
* **Roleplay scenario duration** (`roleplay_scenario_duration`, number, optional): Record the duration of the scenario, which can help in planning and scheduling.
* **Roleplay scenario start date** (`roleplay_scenario_start_date`, date, optional): Enter the start date of the scenario, which can help in tracking progress.
* **Roleplay scenario end date** (`roleplay_scenario_end_date`, date, optional): Enter the end date of the scenario, which can help in tracking completion.
* **Roleplay scenario status updated** (`roleplay_scenario_status_updated`, time, optional): Record the time when the scenario status was updated, which can help in tracking changes.
* **Roleplay scenario status completed** (`roleplay_scenario_status_completed`, time, optional): Record the time when the scenario was completed, which can help in tracking completion.

## Tips
- Be accurate and thorough when filling out the form.
- Ensure that you have all necessary information before completing the form.
- Review and submit the form once you have finished filling it out.
- If you're unsure about any field, refer to the provided guidance or seek clarification from the relevant authorities.
