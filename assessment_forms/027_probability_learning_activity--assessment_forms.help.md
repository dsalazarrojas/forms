# Probability Learning Activity - Help Guide

## Purpose
This form is designed to assess your understanding of probability concepts. It consists of multiple sections with various types of questions to help you demonstrate your knowledge. Please answer each section accurately and thoroughly.

## How To Complete This Form
To complete this form, follow these steps:

1. For each section, carefully read the question or prompt provided.
2. Answer each question in the space provided, using the format and type suggested for each field.
3. Ensure that you fill out all required fields, indicated by the "Required" label.
4. Double-check your answers to ensure they are accurate and complete.

## Field-by-Field Explanation

- **Student Response** (`student_response`, text, Optional): This field is for you to provide any relevant thoughts, comments, or insights about the activity.
  - Please type your response in the provided text box.
  - You can provide as much or as little information as you need.

- **Form 3** (`form_3`, Select One, Optional): This field asks you to select one option that best fits your answer.
  - Choose the option that most accurately reflects your response.
  - Select only one option from the list provided.

- **Form 4** (`form_4`, Select Multiple, Optional): This field requires you to select multiple options that best fit your answer.
  - Choose the options that most accurately reflect your response.
  - Select as many or as few options as you need.

- **Form 5** (`form_5`, Date, Optional): This field is for you to provide a specific date related to the activity.
  - Enter the date in the format suggested (e.g., MM/DD/YYYY).
  - You can leave this field blank if not applicable.

- **Form 6** (`form_6`, Time, Optional): This field is for you to provide a specific time related to the activity.
  - Enter the time in the format suggested (e.g., 12:00 PM).
  - You can leave this field blank if not applicable.

- **Form 7** (`form_7`, Number, Optional): This field is for you to provide a numerical value related to the activity.
  - Enter the number in the format suggested (e.g., 12).
  - You can leave this field blank if not applicable.

- **Form 8** (`form_8`, Email, Optional): This field is for you to provide your email address.
  - Enter your valid email address.
  - You can leave this field blank if not applicable.
 
- **Form 1** (`form_1`, Note, Not Applicable): This field is not applicable, so please ignore it.

Please note that all fields with a "Required" label are mandatory. If you have any questions or need further clarification, please reach out to the evaluator or educator for assistance.
