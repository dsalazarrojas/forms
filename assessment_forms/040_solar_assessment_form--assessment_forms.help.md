# Solar Assessment Form - Help Guide
## Purpose
The Solar Assessment Form is a tool used to collect information on a user's potential suitability for solar energy assessment.

## How To Complete This Form
1. Start by filling out the form completely, providing accurate information in each field.
2. For fields with options, select the most relevant answer to the question being asked.
3. If a field does not apply, mark it as not applicable or enter N/A, as per your discretion.

## Field-by-Field Explanation
### User Details
* **User Details** (`user_details`, text, optional): This field is for providing general information about the user. Enter any relevant details about the user that might impact the solar assessment.

### Assessment Date
* **Assessment Date** (`assessment_date`, date, optional): Select the date of the assessment.

### Assessment Time
* **Assessment Time** (`assessment_time`, time, optional): Select the time of the assessment.

### Address
* **Address** (`address`, text, optional): Enter the address of the user.

### Contact Number
* **Contact Number** (`contact_number`, number, optional): If applicable, provide a contact number for the user.

### Email
* **Email** (`email`, email, optional): Enter the email of the user, if applicable.

### Solar Suitability
* **Solar Suitability** (`solar_suitability`, select_one, optional): Select 'Suitable' if the user is suitable for solar assessment, 'Not Suitable' otherwise.

### Assessment Notes
* **Assessment Notes** (`assessment_notes`, note, optional): Enter any notes about the assessment, if necessary.

### Additional Comments
* **Additional Comments** (`additional_comments`, text, optional): Enter any additional comments or feedback.

### Assessment Form Submitter
* **Assessment Form Submitter** (`assessment_form_submitted_by`, select_multiple, optional): Select one or more individuals who submitted the form, such as 'John' or 'Jane'.
