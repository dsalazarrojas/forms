# Store Manager Assessment Form - Help Guide
## Purpose
The Store Manager Assessment Form is designed to gather information about store managers, including their personal details and store information. This form is used to evaluate and record store manager data.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the required fields:
	* Last name
	* Store name
	* Store name 2
	* Manager name
	* Manager title
	* Manager comments
2. Provide optional information:
	* First name
	* Email
	* Phone number
	* Store address
	* Manager experience
	* Store type
	* Manager salary
	* Manager rating
	* Store manager assessment
	* Selected manager assessment
	* Store name assessment
	* Selected store name assessment
	* Manager loyalty
	* Selected manager loyalty
	* Store loyalty
	* Selected store loyalty
	* Store Manager Loyalty
	* Selected Manager Loyalty
3. Select the relevant assessments:
	* Store manager assessment
	* Selected manager assessment
	* Store name assessment
	* Selected store name assessment
	* Manager loyalty
	* Selected manager loyalty
	* Store loyalty
	* Selected store loyalty
4. Add any comments or notes in the Comments field.

## Field-by-Field Explanation

* **First name** (`first_name`, text, optional): Enter the store manager's first name.
* **Last name** (`last_name`, text, required): Enter the store manager's last name.
* **Email** (`email`, email, optional): Enter the store manager's email address.
* **Phone number** (`phone`, text, optional): Enter the store manager's phone number.
* **Store name** (`store_name`, text, required): Enter the store name.
* **Store name 2** (`store_name`, text, required): Enter the store name.
* **Manager name** (`manager_name`, text, required): Enter the store manager's name.
* **Manager title** (`manager_title`, text, optional): Enter the store manager's title.
* **Manager comments** (`manager_comments`, note, optional): Add any comments or notes about the store manager.
* **Store address** (`store_address`, text, optional): Enter the store address.
* **Manager experience** (`manager_experience`, number, optional): Enter the store manager's experience.
* **Store type** (`store_type`, text, optional): Enter the store type.
* **Manager salary** (`manager_salary`, number, optional): Enter the store manager's salary.
* **Manager rating** (`manager_rating`, number, optional): Enter the store manager's rating.
* **Store manager assessment** (`store_manager_assessment`, select_multiple, optional): Select whether the store manager is 'Yes' or 'No'.
* **Selected manager assessment** (`selected_manager_assessment`, select_multiple, optional): Select whether the store manager is 'Yes' or 'No'.
* **Store name assessment** (`store_name_assessment`, select_one, optional): Select whether the store name is 'Yes' or 'No'.
* **Selected store name assessment** (`selected_store_name_assessment`, select_one, optional): Select whether the store name is 'Yes' or 'No'.
* **Manager loyalty** (`manager_loyalty`, select_multiple, optional): Select whether the store manager has 'Yes' or 'No' loyalty.
* **Selected manager loyalty** (`selected_manager_loyalty`, select_multiple, optional): Select whether the store manager has 'Yes' or 'No' loyalty.
* **Store loyalty** (`store_loyalty`, select_multiple, optional): Select whether the store has 'Yes' or 'No' loyalty.
* **Selected store loyalty** (`selected_store_loyalty`, select_multiple, optional): Select whether the store has 'Yes' or 'No' loyalty.
* **Store Manager Loyalty** (`store_manager_loyalty`, select_multiple, optional): Select whether the store manager has 'Yes' or 'No' loyalty.
* **Selected Manager Loyalty** (`selected_manager_loyalty`, select_multiple, optional): Select whether the store manager has 'Yes' or 'No' loyalty.
* **Comments** (`comments`, note, optional): Add any additional comments or notes about the store manager.

## Tips

* Make sure to fill in all required fields (Last name, Store name, Store name 2, Manager name, Manager title).
* Use the 'Select Multiple' options for Store manager assessment, Selected manager assessment, Manager loyalty, Selected manager loyalty, Store loyalty, and Selected store loyalty.
* Select only one option for Store name assessment, Selected store name assessment.
* Use the 'Notes' fields for any additional comments or notes.
