# Sewing Machine Parts Quiz - Help Guide
## Purpose
The Sewing Machine Parts Quiz is a 10-question form designed to assess your knowledge and understanding of various aspects of sewing machines.

## How To Complete This Form
To complete this form, please follow these steps:

1. Review each question carefully and answer them in the sequence presented.
2. For select_one and select_multiple questions, choose one or multiple answers from the provided options.
3. For number questions, enter a numerical value in the corresponding field.
4. For date and time questions, select a date or time from the calendar or clock picker that appears when you click on the field.
5. Answer each question to the best of your ability, and proceed to the next page when you are finished.

## Field-by-Field Explanation

* **first_question** (`first_page`, select_one, required: false): This question asks whether you have experience with sewing machines. Please select 'Yes' if you have experience, and 'No' otherwise.
* **second_question** (`second_page`, number, required: false): This question asks you to rate your level of knowledge about sewing machine parts on a scale of 0 to 10. Please enter a number between 0 and 10 to indicate your level of understanding.
* **third_question** (`third_page`, number, required: false): This question asks you to rate how many hours you have spent learning about sewing machine parts in the past year. Please enter a number that reflects your actual time spent learning about sewing machine parts.
* **fourth_question** (`fourth_page`, select_multiple, required: false): This question asks about your familiarity with various sewing machine parts. Please select all the parts you are familiar with from the list.
* **fifth_question** (`fifth_page`, select_one, required: false): This question asks whether you have ever used a sewing machine with a specific part. Please select 'Yes' if you have, and 'No' otherwise.
* **sixth_question** (`sixth_page`, select_multiple, required: false): This question asks about your experience with different types of sewing machine parts. Please select all the parts you have experience with from the list.
* **seventh_question** (`seventh_page`, date, required: false): This question asks for the date when you last used a sewing machine. Please select a date from the calendar picker or enter it manually.
* **eighth_question** (`eighth_page`, time, required: false): This question asks for the time of day when you last used a sewing machine. Please select a time from the clock picker or enter it manually.
* **ninth_question** (`ninth_page`, select_one, required: false): This question asks whether you have ever maintained or repaired a sewing machine. Please select 'Yes' if you have, and 'No' otherwise.
* **tenth_question** (`tenth_page`, select_multiple, required: false): This question asks about your experience with different types of sewing machine maintenance. Please select all the types of maintenance you have experience with from the list.

Note: The form is designed to be completed in a specific order, so please answer each question in the sequence presented.
