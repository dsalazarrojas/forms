# Water Evacuation Assessment - Help Guide
## Purpose
This form is used to collect information about water evacuation assessments. It is intended for use in emergency situations where there has been an incident or issue with the water system.

## How To Complete This Form
1. Select the correct option for the Facility Manager field, as this will determine the relevant section of the form that will be completed.
2. Enter a brief description of the issue in the Issue Description field.
3. If applicable, select the date and time of the issue in the Issue Date and Issue Time fields.
4. Select all relevant methods of evacuation in the Evacuation Method field.
5. If applicable, attach photos of the issue in the Photo Attachment field.
6. Select all relevant sources of water in the Photos field.
7. Select the relevant source of the water issue in the Water Source field.
8. Enter any details about pipe damage in the Pipe Damage field.
9. Select all relevant types of leakages in the Pipe Leakege field.
10. Enter any information about pump failure in the Pump Failure field.
11. Enter any information about well failure in the Well Failure field.
12. Enter any information about overflow in the Overflow field.
13. Select the current water quality in the Water Quality field.
14. Select the location of the water source in the Water Source Location field.
15. Select the type of water source in the Water Source Type field.
16. Select the current water level in the Water Level field.
17. Select the current water flow rate in the Flow Rate field.
18. Enter the current water flow rate value in the Flow Rate Value field.
19. Select the size of the pipe in the Pipe Size field.
20. Select the material of the pipe in the Pipe Material field.
21. Enter any additional notes or comments about the issue in the Notes field.

## Field-by-Field Explanation

* **Facility Manager** (Select One): This field is used to determine the relevant section of the form that will be completed based on your role as a facility manager.
* **Issue Description** (Text): This field is used to describe the issue with the water system.
* **Issue Date** (Date): This field is used to enter the date of the issue.
* **Issue Time** (Time): This field is used to enter the time of the issue.
* **Evacuation Method** (Select Multiple): This field is used to select all relevant methods of evacuation.
* **Photo Attachment** (Note): This field is used to attach photos of the issue.
* **Photos** (Select Multiple): This field is used to select all relevant sources of water.
* **Water Source** (Select One): This field is used to select the relevant source of the water issue.
* **Pipe Damage** (Text): This field is used to enter any details about pipe damage.
* **Pipe Leakege** (Select Multiple): This field is used to select all relevant types of leakages.
* **Pump Failure** (Text): This field is used to enter any information about pump failure.
* **Well Failure** (Text): This field is used to enter any information about well failure.
* **Overflow** (Text): This field is used to enter any information about overflow.
* **Water Quality** (Select One): This field is used to select the current water quality.
* **Water Source Location** (Select One): This field is used to select the location of the water source.
* **Water Source Type** (Select Multiple): This field is used to select the type of water source.
* **Water Level** (Select Multiple): This field is used to select the current water level.
* **Flow Rate** (Number): This field is used to enter the current water flow rate.
* **Flow Rate Value** (Select One): This field is used to select the current water flow rate value.
* **Pipe Size** (Select One): This field is used to select the size of the pipe.
* **Pipe Material** (Select Multiple): This field is used to select the material of the pipe.
* **Notes** (Note): This field is used to enter any additional notes or comments about the issue.
