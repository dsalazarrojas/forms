# Input Output Evaluation Form - Help Guide
## Purpose
The Input Output Evaluation Form is used to collect input and output data for evaluation purposes.

## How To Complete This Form
1. Fill out the form with your input and output data for the relevant project.
2. Make sure to fill out all required fields, if any.
3. If a field is not required, you can leave it blank.
4. Use the drop-down menus to select the assessment method and operation for your project.
5. Finally, click the submit button to complete the form.

## Field-by-Field Explanation

* **Process Input** (`process_input`, text, optional): Fill out this field with a brief description of the process used to generate the project input.
* **Process Output** (`process_output`, text, optional): Fill out this field with a brief description of the process used to generate the project output.
* **Project Output** (`project_output`, text, optional): Fill out this field with a brief description of the project output.
* **Assessment Method** (`assessment_method`, select multiple, optional): Select all methods that apply to your project assessment, using the following options: Value 1, Value 2, Value 3.
* **Assessment Basis** (`assessment_basis`, select one, optional): Select the basis for your project assessment, using the following options: Value 1, Value 2, Value 3.
* **Output Quality** (`output_quality`, number, optional): Enter a numeric value to represent the quality of your project output.
* **Project Review** (`project_review`, date, optional): Enter the date of your project review.
* **Quality Measures** (`quality_measures`, text, optional): Fill out this field with a brief description of the quality measures used in your project.
* **Follow up** (`follow_up`, note, optional): Enter any follow-up information for your project.
* **Email** (`email`, email, optional): Enter your email address.
* **Phone** (`phone`, text, optional): Enter your phone number.
* **Operation** (`operation`, select one, optional): Select the operation for your project, using the following options: Value 1, Value 2, Value 3.
