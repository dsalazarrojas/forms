# Ethanol Effects Assessment - Help Guide
## Purpose
This form is designed to gather information about an individual's ethanol consumption habits, including frequency, amount, and context of consumption.
## How To Complete This Form
To complete this form, follow these steps:
1. Review each page carefully and answer the questions accordingly.
2. For numerical questions, enter a whole number as prompted.
3. Select the correct option for multiple-choice questions.
4. Make sure to answer all questions, as indicated by the "required" label.
## Field-by-Field Explanation

* **Introduction** (`intro`, Note, optional): This is a brief introduction page to provide background information about the form.
* **What is your typical daily consumption of ethanol?** (`ethanol_consumption`, Number, optional): Please enter a whole number to indicate your typical daily consumption of ethanol.
* **What type of alcohol do you drink most often?** (`alcohol_type`, Select One, optional): Please select the type of alcohol you drink most often:
	+ Beer
	+ Wine
	+ Spirits
	+ Other
* **How often do you consume alcohol?** (`frequency`, Select Multiple, optional): Please select all that apply to indicate how often you consume alcohol:
	+ Daily
	+ Weekly
	+ Monthly
* **In what social situations do you usually consume alcohol?** (`social_situations`, Text, optional): Please describe the social situations where you typically consume alcohol.
* **How much alcohol do you usually consume during these social situations?** (`quantity_consumed`, Number, optional): Please enter a whole number to indicate the amount of alcohol you typically consume.
* **What is your usual unit size or serving size?** (`units_consumed`, Select One, optional): Please select the unit size or serving size you usually consume:
	+ Standard drink
	+ Shot
	+ Can
	+ Bottle
* **Do you usually drink to binge?** (`binge_drinking`, Select One, optional): Please select "True" or "False" to indicate whether you usually drink to binge.
* **Do you usually drink to get drunk?** (`drink_drinking`, Select One, optional): Please select "True" or "False" to indicate whether you usually drink to get drunk.
* **Do people pressure you to drink?** (`social_pressures`, Select One, optional): Please select "True" or "False" to indicate whether people pressure you to drink.
* **How often do you consume alcohol? (Duplicate)** (`drinking_frequency`, Select Multiple, optional): Please select all that apply to indicate how often you consume alcohol:
	+ Daily
	+ Weekly
	+ Monthly
* **Where do you usually drink?** (`drinking_location`, Select Multiple, optional): Please select all that apply to indicate where you usually drink:
	+ Home
	+ Bar or Club
	+ Restaurant
	+ Other
* **Do you usually drink alone?** (`drink_alone`, Select One, optional): Please select "True" or "False" to indicate whether you usually drink alone.
* **How many friends do you usually drink with?** (`drinking_friends`, Select Multiple, optional): Please select one or more of the following options to indicate how many friends you usually drink with:
	+ 1
	+ 2-3
	+ 4-5
	+ 6 or more
* **How old were you when you started drinking?** (`age_of_initiation`, Number, optional): Please enter a whole number to indicate how old you were when you started drinking.
* **How many years have you been drinking?** (`years_drinking`, Number, optional): Please enter a whole number to indicate how many years you have been drinking.
# Tips
* Please answer all questions truthfully and accurately.
* If you're unsure about a question, please make an educated guess based on your best judgment.
* If you need assistance or have further questions, please contact the form administrators.
