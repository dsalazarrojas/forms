# Anti Static Curtain Wall Assessment - Help Guide
## Purpose
The Anti Static Curtain Wall Assessment form is designed to document and track the performance of curtain walls in various settings, focusing on their electrostatic shielding capabilities. This form helps assessors evaluate and report on the condition of curtain walls, guiding corrective actions when necessary.

## How To Complete This Form
1. Start by filling in the Site name or location field (2) with the relevant building or room identifier.
2. Enter your name as the Assessor (3) conducting the assessment.
3. Record the date the assessment was performed (4) for accurate tracking.
4. Evaluate the curtain wall condition (5) based on the provided options (Compliant, Minor issues, Major issues, or Requires replacement).
5. If applicable, report the result of any ESD resistance test (6) or indicate if it's not applicable.
6. If necessary, suggest recommended corrective actions (7) for any issues found.
7. Finally, indicate if follow-up inspections are required (8).

## Field-by-Field Explanation
* **Site name or location (2)**: Enter the building or room identifier to ensure accurate tracking and reference.
* **Assessor name (3)**: Provide your name as the person conducting the assessment for accountability and accuracy.
* **Assessment date (4)**: Record the date of the assessment for future reference and tracking purposes.
* **Curtain wall condition (5)**: Choose from the options provided, considering your findings:
	+ Compliant: No issues were found.
	+ Minor issues: Some minor problems were identified.
	+ Major issues: Significant and potentially critical problems were found.
	+ Requires replacement: The curtain wall is no longer suitable for use.
* **ESD resistance test result (6)**: If applicable, report the test result or note that it's not applicable.
* **Recommended corrective actions (7)**: Suggest steps to address any issues found, if necessary.
* **Follow up required (8)**: Check if further inspections are necessary, and if so, schedule follow-ups accordingly.
