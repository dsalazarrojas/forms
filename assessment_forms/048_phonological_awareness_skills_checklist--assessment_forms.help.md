# Phonological Awareness Skills Checklist - Help Guide

## Purpose
This form is designed to evaluate an individual's phonological awareness skills, which are crucial for reading and language development. These skills include identifying and manipulating sounds, syllables, and other phonological units.

## How To Complete This Form
To complete this form, follow the instructions below:

1. Select the options that apply to the individual being assessed. Choose 'Yes' for skills that the individual demonstrates and 'No' for skills that they do not demonstrate.
2. Review each field carefully to ensure you are selecting the correct options.
3. Save the completed form for future reference.

## Field-by-Field Explanation

* **Prospective Listeners** (`prospective_listeners`, Select Multiple, Optional): Select 'Yes' if the individual can identify and recognize words or phrases that are similar or have the same sound pattern as a given word or phrase. Select 'No' if they are unable to do so.
* **Rhythmic Awareness** (`phonological_rhythmic_awareness`, Select One, Optional): Select 'Yes' if the individual can recognize and imitate rhythmic patterns, such as clapping or tapping. Select 'No' if they do not demonstrate this ability.
* **Syllable Awareness** (`phonological_syllable_awareness`, Select Multiple, Optional): Select 'Yes' if the individual can identify and manipulate syllable structures, such as counting or segmenting words by syllables. Select 'No' if they do not demonstrate this ability.
* **Sounds Awareness** (`phonological_sounds_awareness`, Select Multiple, Optional): Select 'Yes' if the individual can identify and manipulate phonemes (individual sounds), such as /p/ or /b/. Select 'No' if they do not demonstrate this ability.
* **Word Awareness** (`phonological_word_awareness`, Select Multiple, Optional): Select 'Yes' if the individual can identify and manipulate words by their sound structure, such as identifying the beginning or ending sound of a word. Select 'No' if they do not demonstrate this ability.
* **Sound Awareness** (`phonological_sound_awareness`, Select Multiple, Optional): This field is actually a duplicate of **Sounds Awareness**. Please use the **Sounds Awareness** field instead.
* **Segment Awareness** (`phonological_segmentation_awareness`, Select Multiple, Optional): Select 'Yes' if the individual can identify and manipulate syllable or word units, such as 'cat' vs. 'caT'. Select 'No' if they do not demonstrate this ability.
* **Aware** (`phonological_awareness`, Select Multiple, Optional): Select 'Yes' if the individual demonstrates an understanding of phonological concepts, such as sound, syllable, or word awareness. Select 'No' if they do not demonstrate this ability.
* **Rhythm Awareness** (`phonological_rhythm_awareness`, Select Multiple, Optional): Select 'Yes' if the individual can recognize and imitate rhythmic patterns, such as clapping or tapping. Select 'No' if they do not demonstrate this ability.
* **Tune Awareness** (`phonological_tune_awareness`, Select Multiple, Optional): Select 'Yes' if the individual can identify and imitate musical tunes or melodies. Select 'No' if they do not demonstrate this ability.
* **Rhyme Awareness** (`phonological_rhyme_awareness`, Select Multiple, Optional): Select 'Yes' if the individual can identify and manipulate words with the same ending sound, such as 'cat' and 'hat'. Select 'No' if they do not demonstrate this ability.
* **Segment** (`phonological_segmentation`, Select Multiple, Optional): Select 'Yes' if the individual can identify and manipulate syllable or word units, such as 'cat' vs. 'caT'. Select 'No' if they do not demonstrate this ability.

## Tips
* Ensure you are selecting the correct options based on the individual's actual abilities, not assumptions.
* If an individual is unable to perform a particular task, do not select 'Yes' for that field.
* Review each field carefully to ensure accuracy.
