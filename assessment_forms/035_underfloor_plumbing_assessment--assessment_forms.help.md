# Underfloor Plumbing Assessment - Help Guide
## Purpose
The Underfloor Plumbing Assessment form is used to collect information about the condition of underfloor plumbing in a building. The data collected will help in making informed decisions about repairs and maintenance.

## How To Complete This Form
1. Fill out the form as you inspect the underfloor plumbing in the building.
2. Answer all the fields in the form, providing as much detail as possible.
3. Ensure that you answer all the required fields.

## Field-by-Field Explanation
### Underfloor Plumbing Conditions (1)
* **underfloor_plumbing_conditions** (`text`, `optional`): This field is used to describe any conditions that affect the underfloor plumbing system. You can provide as much detail as possible about any issues you have observed.

### Inspection Date (2)
* **inspection_date** (`date`, `optional`): This field is used to record the date of the inspection. Please enter the date in a standard date format (MM/DD/YYYY).

### Inspector Name (3)
* **inspector_name** (`text`, `optional`): This field is used to record the name of the inspector who performed the assessment.

### Photo Evidence (4)
* **photo_evidence** (`note`, `optional`): If possible, take a photograph of any conditions or issues that affect the underfloor plumbing system. You can upload the photo here.

### Issues List (5)
* **issues_list** (`select_multiple`, `optional`): Please select all conditions that apply to the underfloor plumbing system from the list below: 
  * Yes (indicating that the issue is present)
  * No (indicating that the issue is not present)

### Issue Description (6)
* **issue_description** (`text`, `optional`): This field is used to describe any issues that affect the underfloor plumbing system.

### Issue Severity (7)
* **issue_severity** (`select_one`, `optional`): Please select the severity of the issue from the following options: 
  * minor
  * moderate
  * major

### Inspector Comments (8)
* **inspector_comments** (`text`, `optional`): This field is used to record any additional comments or observations from the inspector.

### Report Sent (9)
* **report_sent** (`select_one`, `optional`): Please select whether a report has been sent to the relevant authorities from the following options: 
  * sent
  * not sent

### Notes (10)
* **notes** (`note`, `optional`): This field is used to record any additional notes or observations from the inspector.
