# software_development_assessment - Help Guide
## Purpose
The software_development_assessment form is used to collect information about the software development process of a project. This form is used to assess and evaluate the project's software development details.

## How To Complete This Form
To complete this form, follow these steps:
1. Select the relevant project details (e.g., project name, date)
2. Choose the software tools used in the project
3. Select the assessment status and type of the project
4. Select the project lead and assigned person for the project
5. Enter any additional comments if needed
