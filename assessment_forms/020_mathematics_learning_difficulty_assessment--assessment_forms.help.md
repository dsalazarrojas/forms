# Mathematics Learning Difficulty Assessment - Help Guide

## Purpose

This form is designed to help teachers and parents assess a student's mathematics skills and identify areas of difficulty. By using this form, you can gather information about the student's math concept understanding, performance, and needs, and use this information to create personalized lesson plans and provide targeted support.

## How To Complete This Form

1. **Student Information**: Please enter the student's name, grade level, and any other relevant information about the student.
2. **Math Concept**: Select one or more areas where the student is having difficulty. You can choose from the following options: Math Fact Fluency, Place Value, Fractions, Geometry, Basic Operations, Word Problems, Patterns and Relations, Measurement, Data Analysis, Graphing, Probability and Statistics, Functions, Basic Math Facts, Basic Algebra, Ratios and Proportions, Basic Geometry, Basic Statistics, Basic Counting.
3. **Student Performance**: Choose one or more options to describe the student's performance in these areas. You can select from the following options: Struggling, Average, Above Average, Exceeding.
4. **Lesson Plans**: Write any relevant lesson plans or suggestions for supporting the student.
5. **Teacher Intervention**: Enter any comments or suggestions from the teacher about how they can support the student.
6. **Teacher Support**: Check if the teacher will provide additional support to the student.
7. **Other Support**: Check if the student will receive any other type of support, such as tutoring or extra help sessions.
8. **Student Response**: Enter any comments or suggestions from the student.
9. **Teacher Comment**: Enter any comments or suggestions from the teacher.
10. **Student Conceptual Understanding**: Check if the student has a good understanding of the math concepts.
11. **Teacher Intervention Plan**: Enter any plans for supporting the student.
12. **Assessment Frequency**: Choose how often the student will be assessed. You can select from the following options: Daily, Weekly, Biweekly, Monthly.
13. **Assessment Type**: Choose the type of assessment. You can select from the following options: Standardized, Non-Standardized, Informal.
14. **Assessment Location**: Choose the location where the assessment will take place. You can select from the following options: Classroom, Online, Other.
15. **Assessment Tool**: Choose the tool or resource used for the assessment. You can select from the following options: Chatjim, Online Platform, Other.
16. **Assessment Frequency Details**: Enter any additional information about the assessment frequency.
17. **Teacher Notes**: Enter any relevant comments or suggestions from the teacher.
18. **Next Steps**: Enter any next steps or suggestions for supporting the student.
19. **Assessment Type Details**: Enter any additional information about the assessment type.
20. **Assessment Location Details**: Enter any additional information about the assessment location.
21. **Assessment Tool Details**: Enter any additional information about the assessment tool.
22. **Additional Comments**: Enter any additional comments or suggestions.

## Tips

* Please enter as much information as possible to help the teacher and student identify areas of difficulty and create a plan for supporting the student.
* If you are unsure about any question, please enter "Unsure" and provide as much information as you can about the reason for the uncertainty.
* This form is designed to be used in conjunction with other assessment tools and should not be the sole means of evaluating a student's math skills.
* If you need to modify the form for your specific use case, please do so and give credit to the original creators.
