# workforce_skills_benchmark_request_form - Help Guide
## Purpose
The workforce skills benchmark request form is designed to collect information about the workforce skills benchmark request from end-users. 

## How To Complete This Form

1. Click on the "Submit" button once you have entered all the required information.
2. Ensure that all the required fields are filled out before submission.
3. If a field is marked as required, do not leave it blank.
4. Double-check the information entered before submitting the form.

## Field-by-Field Explanation

* **Scope** (1, Text, Required: False): Please enter a brief description of the workforce skills benchmark request.
* **Competencies** (2, Select One, Required: False): Please select one of the available options, 'Yes' or 'No', to indicate the competencies that need to be assessed.
* **Assessment Needs** (3, Text, Required: False): Please enter any additional information about the assessment needs of the workforce skills benchmark request.
