### dental_health_assessment_form - Help Guide

### Purpose

This form is used to gather information about a patient's dental history, medical conditions, and oral health. It helps healthcare professionals assess a patient's overall health and provide personalized recommendations for treatment.

### How To Complete This Form

1. Select a page to start filling out the form. The pages are: Patient Information, Dental History, Medical History, Medication List, Allergies, Medical Conditions, Patient Oral Health, Dental Procedures, Dental Prophylaxis, Prophylaxis Frequencies, Patient Infection Control, Treatment Options, Patient Oral Health Risks, Patient Dental History, Patient Oral Health Risks Factors, Prophylaxis Frequency.
2. Fill out each field on the selected page, following the instructions below.

### Field-by-Field Explanation

* **Patient Information (Patient Information)** (`name`, `text`, required: false): Enter the patient's name.
* **Dental History (Dental History)** (`name`, `text`, required: false): Provide a brief description of the patient's dental history.
* **Medical History (Medical History)** (`name`, `text`, required: false): Enter the patient's medical history.
* **Medication List (Medication List)** (`name`, `select_one`, required: false):
	+ Select 'Yes' if the patient has a medication list.
	+ Select 'No' otherwise.
* **Allergies (Allergies)** (`name`, `select_multiple`, required: false):
	+ Select 'Yes' for each allergy the patient has.
	+ Select 'No' otherwise.
* **Medical Conditions (Medical Conditions)** (`name`, `select_multiple`, required: false):
	+ Select 'Yes' for each medical condition the patient has.
	+ Select 'No' otherwise.
* **Patient Oral Health (Patient Oral Health)** (`name`, `select_one`, required: false):
	+ Select 'Yes' if the patient has oral health issues.
	+ Select 'No' otherwise.
* **Dental Procedures (Dental Procedures)** (`name`, `select_multiple`, required: false):
	+ Select 'Yes' for each dental procedure the patient has undergone.
	+ Select 'No' otherwise.
* **Dental Prophylaxis (Dental Prophylaxis)** (`name`, `select_multiple`, required: false):
	+ Select 'Yes' for each dental prophylaxis the patient has undergone.
	+ Select 'No' otherwise.
* **Prophylaxis Frequencies (Prophylaxis Frequencies)** (`name`, `number`, required: false):
	+ Enter the frequency of prophylaxis.
* **Patient Infection Control (Patient Infection Control)** (`name`, `select_multiple`, required: false):
	+ Select 'Yes' for each infection control measure the patient has taken.
	+ Select 'No' otherwise.
* **Treatment Options (Treatment Options)** (`name`, `select_multiple`, required: false):
	+ Select 'Yes' for each treatment option the patient has chosen.
	+ Select 'No' otherwise.
* **Patient Oral Health Risks (Patient Oral Health Risks)** (`name`, `select_multiple`, required: false):
	+ Select 'Yes' for each oral health risk factor the patient has.
	+ Select 'No' otherwise.
* **Patient Dental History (Patient Dental History)** (`name`, `select_one`, required: false):
	+ Select 'Yes' if the patient has a dental history.
	+ Select 'No' otherwise.
* **Patient Oral Health Risks Factors (Patient Oral Health Risks Factors)** (`name`, `select_one`, required: false):
	+ Select 'Yes' if the patient has oral health risks factors.
	+ Select 'No' otherwise.
* **Prophylaxis Frequency (Prophylaxis Frequency)** (`name`, `number`, required: false):
	+ Enter the frequency of prophylaxis.

### Tips

* Make sure to provide accurate information about the patient's dental and medical history.
* Select the relevant options for each field carefully.
* Review each field to ensure you have filled out all required fields.
* If you have any questions or concerns, ask a healthcare professional for guidance.
