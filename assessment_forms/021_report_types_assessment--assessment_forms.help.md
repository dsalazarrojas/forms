## Report Types Assessment - Help Guide

## Purpose
The Report Types Assessment form is used to categorize reports based on the report type and other relevant details. This form helps ensure that reports are properly assigned to the right team members and that the assessment process is accurate and efficient.

## How To Complete This Form

To complete this form, follow these steps:

1. On the "Report" page, select the appropriate report type from the dropdown menu. Choose the correct report type from the options provided (Report 1, Report 2, or Report 3).
2. On the "Type" page, select the specific report type (Report Type 1 or Report Type 2) that you believe best fits the report. This is a required field.
3. On the "Date" page, enter the date of the report in the desired format. This is a required field.
4. On the "Time" page, enter the time of the report if applicable. This field is not required.
5. On the "Note" page, provide any additional comments or observations about the report.
6. On the "Email" page, enter the contact email for the report submitter. This field is not required.
7. On the "Phone" page, enter the contact phone number for the report submitter. This field is not required.

## Field-by-Field Explanation

* **Report** (`report_types_assessment_form_1`, `select_one`, required/optional): This field allows you to select the type of report (Report 1, Report 2, or Report 3) that you are categorizing. Select the correct report type to accurately categorize the report.
* **Type** (`report_types_assessment_form_2`, `select_one`, required/optional): This field allows you to select the specific report type (Report Type 1 or Report Type 2) that you believe best fits the report. This field is required.
* **Date** (`report_types_assessment_form_3`, `date`, required/optional): Enter the date of the report in the desired format (YYYY-MM-DD or MM/DD/YY). This field is required.
* **Time** (`report_types_assessment_form_4`, `time`, required/optional): If applicable, enter the time of the report. Note that this field is not required.
* **Note** (`report_types_assessment_form_5`, `note`, required/optional): Enter any additional comments or observations about the report.
* **Email** (`report_types_assessment_form_6`, `email`, required/optional): Enter the contact email for the report submitter. Note that this field is not required.
* **Phone** (`report_types_assessment_form_7`, `text`, required/optional): Enter the contact phone number for the report submitter. Note that this field is not required.
