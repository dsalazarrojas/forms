# Student Grading Evaluation Form - Help Guide

## Purpose
This form is designed to help teachers evaluate student performance in an assessment process. It is used to track student progress and provide feedback for improvement.

## How To Complete This Form
1. Fill in the required fields (indicated by *) with the relevant information.
2. Select the relevant options for each select field.
3. Write clear and concise comments in the text fields.

## Field-by-Field Explanation

* **Student ID** (student_id, number, *): This is a unique identifier for the student being assessed.
* **Grade Assignment** (grade_assignment, number, *): Enter the grade assigned to the student for this assessment.
* **Comments** (comments, text, ): This field allows teachers to leave notes on the student's performance.
* **Student Participation** (student_participation, number, ): This field indicates the level of student participation during the assessment.
* **Teacher ID** (teacher_id, select_one, *): Check the box to indicate whether the teacher has identified the student.
* **Assessment Date** (assessment_date, date, *): Enter the date on which the assessment took place.
* **Assessment Time** (assessment_time, time, *): Enter the time on which the assessment took place.
* **Grading Criteria** (grading_criteria, text, ): This field allows teachers to describe the grading criteria used for this assessment.
* **Grade Scale** (grade_scale, select_multiple, *): Select one or more grades from the scale to record the student's performance.
* **Grade Scale Comments** (grade_scale_comments, text, ): Write any additional comments related to the student's grade.
* **Teacher Rating** (teacher_rating, number, *): Enter a rating for the teacher's overall assessment of the student.
* **Teacher Comments** (teacher_comments, text, ): This field allows teachers to leave comments on the student's performance.
* **Grade Scale** and **Grading Criteria** fields are related to recording the student's performance and can be used in conjunction with each other to provide a comprehensive assessment.
* The **Teacher ID** field is used to track whether the teacher has identified the student, and this field should be checked only when the teacher has actually assessed the student.
