# Sports Game Strategy Assessment Form - Help Guide
## Purpose
The Sports Game Strategy Assessment Form is designed to evaluate an individual's or a team's sports game strategy, considering various key elements such as pre-game preparation, in-game adjustments, and overall strategy. It will help users to assess their game plan and make informed decisions to improve their performance.

## How To Complete This Form

1. Please answer all questions thoroughly, providing detailed information whenever possible.
2. Review each question carefully before proceeding to the next one.
3. Select all applicable options for multiple-choice questions.
4. Enter text responses in the provided text boxes.
5. Double-check your answers before submitting the form.

## Field-by-Field Explanation

* **Pre Game Preparation** (`pre_game_preparation`, text, optional): This field asks about the steps taken before the game to prepare the team or individual. Please provide a detailed description of the preparation process.
* **In Game Adjustments** (`in_game_adjustments`, select multiple, required): In this field, select all adjustments that were made during the game. These may include changes to the game plan, player positioning, or other tactics.
	+ Option 1: Time-outs to regroup or reassess the game
	+ Option 2: Shift players to different positions or formations
	+ Option 3: Make strategic substitutions
* **Team Communication** (`team_communication`, text, optional): Describe how the team communicated with each other during the game.
* **Overall Strategy** (`overall_strategy`, select one, required): Choose the primary strategy employed during the game. Please select one of the following options:
	+ Option 1: Aggressive approach, focusing on scoring quickly
	+ Option 2: Defensive stance, focusing on preventing points
	+ Option 3: Adaptive strategy, adjusting to the opposing team's strengths and weaknesses
* **Game Outcome** (`game_outcome`, select one, required): Choose the game's outcome. Please select one of the following options:
	+ Option 1: Win
	+ Option 2: Loss
	+ Option 3: Draw
* **Player Performance** (`player_performance`, select multiple, required): Select all players who made significant contributions to the game. Please choose from the following options:
	+ Option 1: Player 1
	+ Option 2: Player 2
	+ Option 3: Player 3
* **Coach Feedback** (`coach_feedback`, text, optional): Describe any valuable feedback received from the coach or opponents during the game.
* **Team Performance** (`team_performance`, text, optional): Describe the overall performance of the team during the game.
* **Game Strategy** (`game_strategy`, text, optional): Outline any notable strategies employed during the game.
* **Game Plan** (`game_plan`, text, optional): Describe the game plan devised and executed during the game.

## Tips
* Make sure to answer truthfully and thoroughly to get the most accurate assessment of your game strategy.
* If unsure about any question, use your best judgment and provide a clear explanation.
* Review your answers carefully before submitting the form to ensure accuracy and completeness.
