# Remote Access Security Assessment Form - Help Guide

## Purpose
The Remote Access Security Assessment Form is designed to evaluate the security risks associated with remote access to sensitive areas or systems. It's intended for security teams to assess and manage remote access risks by collecting information on remote access practices, risk level, duration, frequency, location, and review status.

## How To Complete This Form

1. Fill in the form fields according to the information provided.
2. For fields that are not applicable or not relevant, please leave them blank.
3. Review each field's description for further guidance on what is expected.

## Field-by-Field Explanation

* **Remote Access Practices**
	+ This field is a free-text field where you can describe the remote access practices in place.
	+ Please provide a brief description of the remote access practices being used.
* **Risk Level**
	+ This field is a selection field with three options: Low, Medium, and High.
	+ Choose the risk level that best describes the security risk associated with remote access.
* **Remote Access Duration**
	+ This field is a numerical field where you can enter the duration of remote access in hours.
	+ Please provide the duration of remote access.
* **Remote Access Frequency**
	+ This field is a numerical field where you can enter the frequency of remote access in the number of times per week or month.
	+ Please provide the frequency of remote access.
* **Access Location**
	+ This field is a selection field with three options: Home, Office, and Public.
	+ Choose the location where remote access is taking place.
* **Review Status**
	+ This field is a selection field with two options: In Progress and Completed.
	+ Choose the status of the review of remote access.
* **Reviewer Comments**
	+ This field is a free-text field where the reviewer can provide comments on the assessment.
	+ Please provide any additional comments or feedback on the assessment.
