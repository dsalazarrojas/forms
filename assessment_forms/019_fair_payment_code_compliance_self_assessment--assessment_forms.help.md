# fair_payment_code_compliance_self_assessment - Help Guide
## Purpose
The Fair Payment Code Compliance Self-Assessment Form is a tool for organizations to evaluate their own compliance with fair payment codes. The form helps ensure that organizations are following the guidelines set by the fair payment code and making progress towards code compliance.

## How To Complete This Form
1. Select the assessment title that describes the reason for the self-assessment.
2. Enter your organization's name and other contact information in the Organization Name, Contact Name, Contact Email, and Contact Phone fields.
3. Enter the start and end dates of the assessment in the Assessment Start Date and Assessment End Date fields, respectively.
4. Describe the assessment frequency and methodology in the Assessment Frequency and Assessment Methodology fields.
5. Select the compliance status from the options provided in the Compliance Status field.
6. Provide any additional notes or comments in the Notes field.
7. Sign off by entering your name in the Signed By field.

## Field-by-Field Explanation
* **Assessment Title** (assessment_title, text, required/optional): Enter a brief description of the assessment.
* **Organization Name** (organization_name, text, required/optional): Enter your organization's name.
* **Contact Name** (contact_name, text, required/optional): Enter the name of the contact person.
* **Contact Email** (contact_email, email, required/optional): Enter the email address of the contact person.
* **Contact Phone** (contact_phone, text, required/optional): Enter the phone number of the contact person.
* **Assessment Start Date** (assessment_start_date, date, required/optional): Enter the start date of the assessment.
* **Assessment End Date** (assessment_end_date, date, required/optional): Enter the end date of the assessment.
* **Assessment Frequency** (assessment_frequency, text, required/optional): Describe the frequency of the assessment.
* **Assessment Methodology** (assessment_methodology, text, required/optional): Describe the methodology used for the assessment.
* **Assessment Frequency Method** (assessment_frequency_method, text, required/optional): Describe the method of the assessment frequency.
* **Payment Schedule** (payment_schedule, text, required/optional): Describe the payment schedule.
* **Payment Schedule Method** (payment_schedule_method, text, required/optional): Describe the method of the payment schedule.
* **Compliance Status** (compliance_status, select_one, required/optional): Select the compliance status from the options provided.
* **Notes** (notes, note, required/optional): Enter any additional notes or comments about the assessment.
* **Signed By** (signed_by, text, required/optional): Enter your name for signature.
