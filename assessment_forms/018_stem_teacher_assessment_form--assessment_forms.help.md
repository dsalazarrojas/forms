# STEM Teacher Assessment Form - Help Guide

## Purpose
The STEM Teacher Assessment Form is used to collect data about a teacher's assessment of a student's performance in a STEM subject area.

## How To Complete This Form

To complete this form, simply follow these steps:

1. Review each field below and determine whether you have relevant information to report.
2. For each field, provide as much detail as you have about the student's performance.
3. Save your changes and click "Submit" to complete the form.

## Field-by-Field Explanation

* **teacher_name**: Enter your name as the teacher who has assessed the student's performance in a STEM subject area.
* **teacher_rating**: Provide a rating of the student's overall performance in the subject area, on a scale from 0 to 3.
* **math_awareness**:
	+ Select all levels of math awareness where applicable:
		- 0: No math awareness.
		- 1: Basic math awareness (e.g., arithmetic operations, basic algebra).
		- 2: Intermediate math awareness (e.g., algebra, geometry, trigonometry).
		- 3: Advanced math awareness (e.g., calculus, complex algebra).
* **science_awareness**:
	+ Select all levels of science awareness where applicable:
		- 0: No science awareness.
		- 1: Basic science awareness (e.g., biology, chemistry, physics).
		- 2: Intermediate science awareness (e.g., earth science, space science).
		- 3: Advanced science awareness (e.g., advanced physics, advanced chemistry).
* **tech_awareness**:
	+ Select all levels of tech awareness where applicable:
		- 0: No tech awareness.
		- 1: Basic tech awareness (e.g., coding, robotics).
		- 2: Intermediate tech awareness (e.g., computer science, engineering).
		- 3: Advanced tech awareness (e.g., advanced programming, advanced engineering).
* **engineering_awareness**:
	+ Select all levels of engineering awareness where applicable:
		- 0: No engineering awareness.
		- 1: Basic engineering awareness (e.g., basic design, basic problem-solving).
		- 2: Intermediate engineering awareness (e.g., intermediate design, intermediate problem-solving).
		- 3: Advanced engineering awareness (e.g., advanced design, advanced problem-solving).
* **time_awareness**:
	+ Select all levels of time awareness where applicable:
		- 0: No time awareness.
		- 1: Basic time awareness (e.g., timing, scheduling).
		- 2: Intermediate time awareness (e.g., time management, time estimation).
		- 3: Advanced time awareness (e.g., time optimization, time-dependent problem-solving).
* **date_of_birth**: If you are familiar with the student's birthdate, please enter it in the correct format (MM/DD/YYYY).
* **assigned_tool**: Describe the tool or resource you have assigned to the student in a STEM subject area.
* **teacher_assessment**:
	+ Write a brief note about your overall assessment of the student's performance in a STEM subject area. 

## Tips

- Please report all relevant information you have about the student's performance in each field.
- If you are unsure about a particular field, you may choose "0" or leave it blank.
- This form is not meant to be completed in one sitting; feel free to save your progress and return to it later.
