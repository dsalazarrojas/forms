# Office Ergonomics Assessment Form - Help Guide
## Purpose
The Office Ergonomics Assessment Form is used to collect information about the office workspace, workstation, and equipment to ensure a comfortable and efficient working environment.

## How To Complete This Form
1. Please fill out each field accurately and thoroughly.
2. If you are unsure about any field, refer to the Field-by-Field Explanation section for guidance.

## Field-by-Field Explanation

* **Workspace Info (Page 1)** (`workspace_info`, text, optional)
	+ This field is where you can provide any additional information about the workspace that is not covered in other fields.
* **Workstation Info (Page 1)** (`workstation_info`, text, optional)
	+ This field is for describing the type of workstation or equipment used.
* **Chair Info (Page 1)** (`chair_info`, text, optional)
	+ This field is for describing the type of chair used.
* **Floor Info (Page 1)** (`floor_info`, text, optional)
	+ This field is for describing the type of floor material or surface.
* **Monitor Info (Page 1)** (`monitor_info`, text, optional)
	+ This field is for describing the type of monitor used.
* **Keyboard Info (Page 1)** (`keyboard_info`, text, optional)
	+ This field is for describing the type of keyboard used.
* **Mouse Info (Page 1)** (`mouse_info`, text, optional)
	+ This field is for describing the type of mouse used.
* **Other Info (Page 1)** (`other_info`, text, optional)
	+ This field is for describing any additional information about the workspace or workstation.
* **Employee Input (Page 1)** (`employee_input`, select_one, optional)
	+ Please select an option that best describes your input or feedback about your workspace.
* **Supervisor Input (Page 1)** (`supervisor_input`, select_multiple, optional)
	+ Please select all options that best describe your supervisor's input or feedback about your workspace.
* **Date (Page 2)** (`date`, date, optional)
	+ This field is for entering the date when the assessment was completed.
* **Time (Page 2)** (`time`, time, optional)
	+ This field is for entering the time when the assessment was completed.
* **Email (Page 2)** (`email`, email, optional)
	+ This field is for entering your email address.
* **Phone (Page 2)** (`phone`, text, optional)
	+ This field is for entering your phone number.
* **Note (Page 2)** (`note`, note, optional)
	+ This field is for any additional comments or notes about your workspace.
* **Workstation Height (Page 2)** (`workstation_height`, number, optional)
	+ This field is for entering the height of your workstation.
* **Workstation Width (Page 2)** (`workstation_width`, number, optional)
	+ This field is for entering the width of your workstation.
* **Monitor Height (Page 2)** (`monitor_height`, number, optional)
	+ This field is for entering the height of your monitor.
* **Monitor Width (Page 2)** (`monitor_width`, number, optional)
	+ This field is for entering the width of your monitor.
* **Distance Between Monitors (Page 2)** (`distance_between_monitors`, number, optional)
	+ This field is for entering the distance between your monitors.
* **Distance Between Workstation and Monitor (Page 2)** (`distance_between_workstation_and_monitor`, number, optional)
	+ This field is for entering the distance between your workstation and monitor.
* **Distance Between Keyboard and Mouse (Page 2)** (`distance_between_keyboard_and_mouse`, number, optional)
	+ This field is for entering the distance between your keyboard and mouse.
* **Distance Between Chair and Workstation (Page 2)** (`distance_between_chair_and_workstation`, number, optional)
	+ This field is for entering the distance between your chair and workstation.
* **Workspace Height (Page 2)** (`workspace_height`, number, optional)
	+ This field is for entering the height of your workspace.
* **Workstation Type (Page 2)** (`workstation_type`, select_one, optional)
	+ Please select an option that best describes the type of workstation used.

## Tips
* Be thorough and accurate when filling out this form.
* If you are unsure about any field, refer to this help guide for guidance.
* Please fill out this form as quickly and efficiently as possible to save time and effort.
