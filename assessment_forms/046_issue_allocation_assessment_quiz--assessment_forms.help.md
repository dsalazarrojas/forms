# Issue Allocation Assessment Quiz - Help Guide
## Purpose
The Issue Allocation Assessment Quiz form is designed to help team members allocate issues effectively.

## How To Complete This Form
To complete this form, follow these steps:
1. Read each question carefully and provide a clear and concise answer.
2. Ensure that you have the necessary information to answer each question accurately.
3. Complete each page of the form, starting with the introduction page.
4. Review each field's explanation below for guidance on how to complete it.

## Field-by-Field Explanation
* **Introduction** (Page 1, <required> false): This page provides a brief overview of the form and its purpose.
* **Issue Description** (Page 2, <required> false): Describe the issue you are allocating.
* **Allocation Method** (Page 3, <required> true): Choose how you would allocate the issue to a team. Options include:
	+ Direct: The team will handle the issue directly.
	+ Indirect: Another team will be involved in the issue's resolution.
	+ Not sure: You are unsure about how to allocate the issue.
	+ Other: Select "Other" if none of the above options apply.
* **Allocation Reason** (Page 4, <required> false): Provide the reason behind your choice of allocation method.
* **Confidence Level** (Page 5, <required> false): Enter a confidence level for your allocation decision. This will help inform team formation and resource allocation decisions.
* **Confidence Level** (Page 6, <required> false): Enter a confidence level for your allocation decision. Note: This is a duplicate field and should be used to confirm or adjust your initial confidence level.
* **Team Size** (Page 7, <required> false): If applicable, enter the expected team size for the allocated issue.
* **Team Diversity** (Page 8, <required> false): If applicable, describe any factors that would help create a diverse team for the allocated issue.
* **Scenario** (Page 9, <required> false): This page is a note-taking page for any other relevant information about the issue. Use this space to record any additional details that might aid in team formation and resource allocation decisions.
