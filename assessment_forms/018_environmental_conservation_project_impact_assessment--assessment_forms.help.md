# environmental_conservation_project_impact_assessment - Help Guide

## Purpose
This form is designed to assess the impact of a conservation project. It gathers information on the project's title, location, dates, budget, outcome, and overall rating. The form is used for tracking and evaluating conservation projects' progress, outcomes, and impacts.

## How To Complete This Form

To complete this form, follow these steps:

1. Enter the conservation project title in the **Conservation Project Title** field.
2. Provide the location of the project in the **Project Location** field.
3. Enter the start and end dates of the project in the **Conservation Project Start Date** and **Conservation Project End Date** fields respectively.
4. Describe the project location in the **Project Location Description** field.
5. Select the project type from the list of options in the **Conservation Project Type** field.
6. Enter the funding source in the **Funding Source** field.
7. List the project participants in the **Project Participants** field.
8. Describe the project objectives in the **Project Objectives** field.
9. Enter the project impact assessment in the **Project Impact Assessment** field.
10. Select the evaluation method in the **Evaluation Method** field.
11. Enter the project evaluation status in the **Project Evaluation Status** field.
12. Enter the project completion date in the **Project Completion Date** field.
13. Describe any follow-up actions in the **Follow-up Actions** field.
14. Enter the conservation project budget in the **Conservation Project Budget** field.
15. Select the conservation project outcome from the list of options in the **Conservation Project Outcome** field.
16. Describe the conservation project outcome in the **Conservation Project Outcome Description** field.
17. Enter the conservation project outcome rating in the **Conservation Project Outcome Rating** field.
18. Enter the overall rating in the **Overall Rating** field.
19. Enter the conservation project outcome impact rating in the **Conservation Project Outcome Impact Rating** field.
20. Describe the conservation project outcome impact in the **Conservation Project Outcome Impact Description** field.
21. Enter the project evaluation frequency in the **Project Evaluation Frequency** field.
22. Enter the evaluation frequency in the **Evaluation Frequency** field.
23. Enter the conservation project outcome impact in the **Conservation Project Outcome Impact** field.
24. Enter the conservation project outcome impact unit in the **Conservation Project Outcome Impact Unit** field.

## Field-by-Field Explanation

* **Conservation Project Title** (`conservation_project_title`, text, optional): Enter the title of the conservation project.
* **Project Location** (`project_location`, text, optional): Provide the location of the project.
* **Conservation Project Start Date** (`conservation_project_start_date`, date, optional): Enter the start date of the project.
* **Conservation Project End Date** (`conservation_project_end_date`, date, optional): Enter the end date of the project.
* **Project Location Description** (`project_location_description`, text, optional): Describe the project location.
* **Conservation Project Type** (`conservation_project_type`, select_multiple, optional): Select the type of conservation project.
* **Funding Source** (`funding_source`, text, optional): Enter the funding source.
* **Project Participants** (`project_participants`, text, optional): List the project participants.
* **Project Objectives** (`project_objectives`, text, optional): Describe the project objectives.
* **Project Impact Assessment** (`project_impact_assessment`, text, optional): Enter the project impact assessment.
* **Evaluation Method** (`evaluation_method`, text, optional): Select the evaluation method.
* **Project Evaluation Status** (`project_evaluation_status`, text, optional): Enter the project evaluation status.
* **Project Completion Date** (`project_completion_date`, date, optional): Enter the project completion date.
* **Follow-up Actions** (`follow_up_actions`, text, optional): Describe any follow-up actions.
* **Conservation Project Budget** (`conservation_project_budget`, number, optional): Enter the conservation project budget.
* **Conservation Project Outcome** (`conservation_project_outcome`, select_one, optional): Select the conservation project outcome.
* **Conservation Project Outcome Description** (`conservation_project_outcome_description`, text, optional): Describe the conservation project outcome.
* **Conservation Project Outcome Rating** (`conservation_project_outcome_rating`, number, optional): Enter the conservation project outcome rating.
* **Overall Rating** (`overall_rating`, number, optional): Enter the overall rating.
* **Conservation Project Outcome Impact Rating** (`conservation_project_outcome_impact_rating`, number, optional): Enter the conservation project outcome impact rating.
* **Conservation Project Outcome Impact Description** (`conservation_project_outcome_impact_description`, text, optional): Describe the conservation project outcome impact.
* **Project Evaluation Frequency** (`project_evaluation_frequency`, text, optional): Enter the project evaluation frequency.
* **Evaluation Frequency** (`evaluation_frequency`, time, optional): Enter the evaluation frequency.
* **Conservation Project Outcome Impact** (`conservation_project_outcome_impact`, time, optional): Enter the conservation project outcome impact.
* **Conservation Project Outcome Impact Unit** (`conservation_project_outcome_impact_unit`, text, optional): Enter the conservation project outcome impact unit.
