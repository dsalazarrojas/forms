# Yard Security Assessment Form - Help Guide
## Purpose
The Yard Security Assessment Form is designed to identify and document security risks and hazards present in a yard or property.

## How To Complete This Form

1. Fill in the form title at the top of the page to indicate the purpose of this security assessment.
2. Select the category of the security assessment (e.g., "Assessment Forms" or "Other").
3. Provide a brief description of the security hazard or risk you've identified.
4. Indicate the level of security risk (e.g., High, Medium, Low) that you've assessed.
5. Specify the location where the hazard or risk is present (e.g., inside or outside the property).
6. Describe the frequency of the hazard or risk (e.g., Daily, Weekly, Monthly).
7. Indicate the probability of the hazard or risk (e.g., High, Medium, Low, None).
8. Check if any action has been taken to mitigate or address the hazard or risk.
9. Provide a brief description of the action taken, if applicable.
10. Assess the level of risk present (e.g., Critical, Moderate, Low).
11. Specify the next steps to be taken to mitigate or address the hazard or risk.
12. Indicate if a follow-up is required to monitor or review the situation.
13. Provide any additional details about the follow-up, if applicable.
