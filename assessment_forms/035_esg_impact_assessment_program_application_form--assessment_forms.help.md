# ESG Impact Assessment Program Application Form - Help Guide
## Purpose
This form is designed to gather information from users about their application for the ESG Impact Assessment Program.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill in the required and optional fields as prompted on each page.
2. Review your answers carefully before submitting.

## Field-by-Field Explanation
* **User Information** (User Information, text, optional):
	+ This field is for providing your name and contact information.
* **Application Details** (Application Details, text, optional):
	+ This field is for describing your application and any relevant information.
* **Submission Confirmation** (Submission Confirmation, text, optional):
	+ This field is for confirming that you have submitted your application and understand the terms and conditions.

## Tips
* Please answer all fields truthfully and accurately.
* If you have any questions or concerns, contact form@gic.mx.
