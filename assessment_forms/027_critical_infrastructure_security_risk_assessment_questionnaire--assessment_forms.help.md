# Critical Infrastructure Security Risk Assessment Questionnaire - Help Guide
## Purpose

The Critical Infrastructure Security Risk Assessment Questionnaire is designed to evaluate the security profile of a critical infrastructure site, ensuring that the site meets the necessary standards for security.

## How To Complete This Form

To complete this form, please follow these steps:

*   Review the form carefully and ensure that you understand the purpose and relevance of each question.
*   Answer each question honestly and accurately, providing as much detail as possible.
*   Please note that some questions are required fields, indicated by a red star (\*) in the top-right corner of the field.

## Field-by-Field Explanation

*   **Introduction (1)**: This is a note field where you can enter a brief introduction to the site, including any relevant information that may be helpful in understanding the site's security profile.
*   **Site Information (2)**: This is a required field where you must enter information about the site, including the name of the site, location, and any other relevant details.
*   **Facility Security Profile (3)**: Please select whether the facility has a security profile in place. This includes questions like "Does the facility have a security profile?" and "Is the security profile up-to-date?"
*   **Security Controls (4)**: Please select which of the following security controls are in place at the facility: "Physical barriers", "Perimeter fencing", "Access control systems", "Monitoring systems", "Security guards", "Locks and bolts", and "Surveillance systems".
*   **Risk Assessment (5)**: Please enter a number between 1 and 10 to indicate the level of risk associated with the facility. For example, a risk level of 1 indicates a low level of risk, while a level of 10 indicates a high level of risk.
*   **Security Risks (6)**: Please select which of the following security risks are present at the facility: "Physical security threats", "Cyber threats", "Human error", "Natural disasters", and "Environmental threats".
*   **Site Security Controls (7)**: Please select which of the following security controls are in place at the site: "Access control systems", "Perimeter fencing", "Surveillance systems", "Monitoring systems", and "Security guards".
*   **Security Training and Awareness (8)**: Please select which of the following security training and awareness programs are in place at the facility: "Regular training sessions", "Security awareness programs", "Emergency response planning", and "Regular drills".
*   **Incident Response Plan (9)**: Please select which of the following incident response plans are in place at the facility: "Incident response team", "Emergency response planning", "Incident response procedures", and "Regular testing".
*   **Review and Validation (10)**: Please select which of the following review and validation processes are in place at the facility: "Regular reviews", "Validation of security protocols", "Risk assessment", and "Compliance checking".
*   **Conclusion (11)**: This is a note field where you can enter any final comments or observations regarding the site's security profile.

Note that some fields may have specific instructions or guidelines that will be provided inline with each field. If you have any questions or concerns, please don't hesitate to reach out to your site's administrators or technical support team.
