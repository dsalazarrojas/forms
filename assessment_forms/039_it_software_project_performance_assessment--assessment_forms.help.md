# it-software-project-performance-assessment - Help Guide
## Purpose
This form is designed to collect project assessment data for internal use within your organization.
## How To Complete This Form
To complete this form, follow these steps:
1. Fill out the project name in the "Project name" field.
2. Select the project team members from the "Project team" field.
3. Enter the project duration in the "Project duration" field.
4. Enter the project budget in the "Project budget" field.
5. Select the project status from the "Project status" field.
6. Select the project impact from the "Project impact" field.
7. Enter your project goals in the "Project goals" field.
8. Describe the project benefits in the "Project benefits" field.
9. Describe the project challenges in the "Project challenges" field.
10. Describe the project lessons learned in the "Project lessons learned" field.
11. Enter the project outcomes in the "Project outcomes" field.
12. Select the date created, time created, date started, time started, date ended, time ended, and created by fields as per your project details.
13. Enter the updated by, created at, updated at, created on, updated on, and created by timestamp fields as per your project details.

## Field-by-Field Explanation
* **Project name** (`project_name`, text, required): Enter the name of the software project.
* **Project team** (`project_team`, select_multiple, required): Select the team members involved in the project.
* **Project duration** (`project_duration`, number, required): Enter the duration of the project in days or hours.
* **Project budget** (`project_budget`, number, required): Enter the budget allocated for the project.
* **Project status** (`project_status`, select_one, required): Select the current status of the project (e.g., active, completed, pending).
* **Project impact** (`project_impact`, select_multiple, required): Select the type of impact the project had (e.g., high, medium, low).
* **Project goals** (`project_goals`, note, optional): Enter the project goals and objectives.
* **Project benefits** (`project_benefits`, text, optional): Describe the benefits of the project.
* **Project challenges** (`project_challenges`, text, optional): Describe the challenges faced during the project.
* **Project lessons learned** (`project_lessons_learned`, text, optional): Describe the lessons learned from the project.
* **Project outcomes** (`project_outcomes`, text, optional): Describe the outcomes of the project.
* **Date created** (`date_created`, date, required): Select the date the project was created.
* **Time created** (`time_created`, time, required): Enter the time the project was created.
* **Date started** (`date_started`, date, required): Select the date the project started.
* **Time started** (`time_started`, time, required): Enter the time the project started.
* **Date ended** (`date_ended`, date, required): Select the date the project ended.
* **Time ended** (`time_ended`, time, required): Enter the time the project ended.
* **Created by** (`created_by`, email, required): Enter the name of the person who created the project.
* **Updated by** (`updated_by`, email, required): Enter the name of the person who updated the project.
* **Created at** (`created_at`, date, required): Select the date the project was created.
* **Updated at** (`updated_at`, date, required): Select the date the project was updated.
* **Created on** (`created_on`, date, required): Select the day of the week the project was created.
* **Updated on** (`updated_on`, date, required): Select the day of the week the project was updated.
* **Created by timestamp** (`created_by_timestamp`, time, optional): Enter the timestamp when the project was created.
* **Updated by timestamp** (`updated_by_timestamp`, time, optional): Enter the timestamp when the project was updated.
