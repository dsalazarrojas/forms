# Skin Type Assessment Quiz - Help Guide
## Purpose
The Skin Type Assessment Quiz is a tool used by healthcare professionals to assess a patient's skin type and identify potential skin concerns that require follow-up actions. This quiz helps in gathering information about a patient's skin type and in determining the appropriate follow-up actions to be taken.

## How To Complete This Form
To complete this form, simply select the options that best describe your patient's skin type and concerns. For each question, choose one or multiple options, depending on the field type. Make sure to carefully read each question and select the most accurate option.

## Field-by-Field Explanation
### 1. Skin Type Quiz
* **Skin Type Quiz** (`skin_type_assessment_quiz`, `select_multiple`, required): This field assesses the skin type of the patient. Select all the skin types that apply to the patient's skin.

### 2. Skin Concerns
* **Skin Concerns** (`skin_concerns`, `select_one`, required): Select one option that best describes the patient's skin concerns.

### 3. Skin Concerns 2
* **Skin Concerns 2** (`skin_concerns_2`, `select_multiple`, optional): This field is an optional follow-up question about additional skin concerns. If applicable, select all concerns that apply to the patient's skin.

### 4-15. Skin Concerns 3-13
* **Skin Concerns 3-13** (`skin_concerns_3`-`skin_concerns_13`, `select_multiple/one`, optional): These fields are also optional follow-up questions about additional skin concerns. Select all or one option that best describes the patient's skin concerns, depending on the field type.

### 16. Follow Up
* **Follow Up** (`follow_up`, `select_one`, required): Select one option to indicate if a follow-up action is required.

### 17. Follow Up Method
* **Follow Up Method** (`follow_up_method`, `select_one`, required): Select one option to describe the follow-up method to be used.

### 18. Follow Up Time
* **Follow Up Time** (`follow_up_time`, `select_one`, required): Select one option to describe the follow-up time frame.

### 19. Follow Up Frequency
* **Follow Up Frequency** (`follow_up_frequency`, `select_one`, required): Select one option to describe the follow-up frequency.

### 20-23. Follow Up Notes
* **Follow Up Note 1-5** (`follow_up_note_1`-`follow_up_note_5`, `text`, required): Enter a brief note about the follow-up action to be taken.
