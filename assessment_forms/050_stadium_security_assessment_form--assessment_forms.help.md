# Stadium Security Assessment Form - Help Guide
## Purpose
This form is designed to assess the security readiness of a stadium, ensuring that its features and systems are up to date and functioning correctly. It evaluates critical elements such as event operator response times and the three levels of security readiness.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the answers to the assessment questions (1, 3-5).
2. Choose the correct response for "Event Operators" (2).
3. Provide a brief description of the assessment, if desired (6).
4. Click the "Submit" button to complete and save your answers.

## Field-by-Field Explanation
### Assessment 1
* **Assessment 1** (`stadium_security_assessment_form_1`, text, required): This is the first question in the assessment, where you are expected to provide a brief answer.

### Event Operators
* **Event Operators** (`stadium_event_operators`, select multiple, required): Choose 'Yes' if the stadium has event operators on site who can respond to emergencies, or 'No' if it does not.

### Readiness 1
* **Readiness 1** (`security_readiness_1`, number, required): This is the first level of security readiness. Please enter a numerical value to indicate the level of readiness.

### Readiness 2
* **Readiness 2** (`security_readiness_2`, number, required): This is the second level of security readiness. Please enter a numerical value to indicate the level of readiness.

### Readiness 3
* **Readiness 3** (`security_readiness_3`, number, required): This is the third level of security readiness. Please enter a numerical value to indicate the level of readiness.

### Description
* **Description** (`stadium_security_assessment_form_description`, text, optional): Provide a brief description of the assessment if desired. This field is not required but can be used to add additional context.

### Submit
* **Submit** (`submit`, note, not required): Click this button to complete and save your answers.
