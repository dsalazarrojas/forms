# Skill Assessment Tool Requisition Form - Help Guide

## Purpose
This form is used to create a request for a specific skill assessment tool to be assigned to an employee. It collects information about the employee's skills, the skills that are required, and other relevant details for the assessment. This information will be used to facilitate the assessment and ensure that the right tool is assigned to the correct person.

## How To Complete This Form

To complete this form, follow these steps:

*   Fill in your personal details, such as your first name, last name, email, and phone number.
*   Select the skills you possess that you wish to be assessed.
*   Choose the date and time you would like to have the assessment conducted.
*   Provide any additional information about the skills you are requesting to be assessed.
*   Select the team you are a part of.
*   If applicable, select the tool you wish to be assigned and its version.

## Field-by-Field Explanation

*   **First Name** (`first_name`, `text`, required: false): This field is used to collect the employee's first name.
    *   Please enter your first name to help us better understand who you are.
*   **Last Name** (`last_name`, `text`, required: false): This field is used to collect the employee's last name.
    *   Please enter your last name to help us better understand who you are.
*   **Email** (`email`, `email`, required: false): This field is used to collect the employee's email address.
    *   Please enter your email address to ensure we can contact you about your assessment.
*   **Phone** (`phone`, `text`, required: false): This field is used to collect the employee's phone number.
    *   Please enter your phone number so we can contact you to discuss your assessment.
*   **Skill** (`skill_id`, `select_multiple`, required: false): This field is used to select the skills you wish to be assessed for.
    *   Select the skills that you feel need to be assessed for this evaluation.
*   **Assessment Date** (`assessment_date`, `date`, required: false): This field is used to choose the date you would like the assessment to take place.
    *   Select the date you are available to be assessed.
*   **Assessment Time** (`assessment_time`, `time`, required: false): This field is used to select the time you would like the assessment to take place.
    *   Select the time that suits you best for the assessment.
*   **Required Skills** (`required_skills`, `text`, required: false): This field is used to provide any additional information about the skills you are requesting to be assessed.
    *   If there are any specific skills that you think should be included in the assessment, please mention them here.
*   **Notes** (`notes`, `note`, required: false): This field is used to provide additional comments or information about your request.
    *   If there is anything specific you would like to note about your assessment, please enter it here.
*   **Manager Name** (`manager_name`, `text`, required: false): This field is used to collect the name of your manager.
    *   Please enter the name of your manager so we can keep them informed about your assessment.
*   **Manager Phone** (`manager_phone`, `text`, required: false): This field is used to collect the phone number of your manager.
    *   Please enter your manager's phone number so we can contact them about your assessment.
*   **Manager Email** (`manager_email`, `email`, required: false): This field is used to collect the email address of your manager.
    *   Please enter your manager's email address so we can contact them about your assessment.
*   **Team** (`team_id`, `select_one`, required: false): This field is used to select the team you are a part of.
    *   Select the team that you are a part of so we can ensure you are assessed correctly.
*   **Tool Assigned** (`assigned_tool`, `text`, required: false): This field is used to select the tool that you wish to be assigned.
    *   Please select the tool that you would like to be assigned to you.
*   **Tool Version** (`tool_version`, `text`, required: false): This field is used to select the version of the tool that you would like to be assigned.
    *   Please select the version of the tool that you would like to use.

## Tips

*   Please make sure that you have filled out all required fields before submitting your form.
*   If you are unsure about any of the fields or the process, please don't hesitate to reach out to us for assistance.
*   We will review and process your form as soon as possible after you submit it.
