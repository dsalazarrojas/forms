# Power Factor Basics Quiz - Help Guide
## Purpose
The Power Factor Basics Quiz is a self-assessment tool for electrical engineering professionals to evaluate their understanding of power factor concepts.

## How To Complete This Form
To complete the Power Factor Basics Quiz, follow these steps:

1. Review the questions on each page and select your answer from the options provided.
2. Make sure to answer all questions, as this will ensure you receive a comprehensive assessment.
3. Use the provided options to select your answer for the question on Page 2.
4. Review the results on Page 4 to see your power factor basics assessment.

## Field-by-Field Explanation

* **Power Factor Basics** (`power_factor_basics_quiz_page_1`, text, required/optional): This is the introductory page with the quiz instructions and a brief explanation of the subject matter.
* **Electrical Power Factor** (`electrical_power_factor`, select_multiple, required/optional): Select all that apply from the list of options provided. This question is about understanding the different types of power factors (Unity, 0.5, 0.75, 0.8, 0.9, 0.95, 0.99, 1, 1.05, 1.1).
* **Question** (`question`, select_one, required/optional): This question is about selecting the power factor of a specific type of load. Select the correct answer from the options provided.
* **Answer** (`answer`, select_one, required/optional): Select the correct power factor from the options provided. This question is about selecting the correct power factor for the given type of load.
