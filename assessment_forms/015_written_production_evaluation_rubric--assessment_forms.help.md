# Written Production Evaluation Rubric - Help Guide
## Purpose
The Written Production Evaluation Rubric is a form used to assess the production quality of written work in an academic or educational setting. It collects information on the written production, including its evaluation and grading, and is meant to be completed by an administrator or evaluator.

## How To Complete This Form

1. Start by ensuring that you have all necessary information and materials ready for completion.
2. The form is divided into the following sections:
   - First page: This is the main section where you will enter the evaluation of the written production.
   - Section title: This field is optional, but if filled, it will help identify the written production being evaluated.
   - Rubric selection: Choose the rubric option(s) that apply to the written production, based on the evaluation criteria.
   - Comment: Provide any additional comments or feedback on the written production.
   - Score: Enter a numerical score for the written production, if applicable.
   - Teacher notes: Add any additional notes or comments from the evaluator.
   - Date and time: Record the date and time the written production was evaluated.

## Field-by-Field Explanation

* **Written Production Evaluation Rubric** (`written_production_evaluation_rubric`, select_multiple, required): Choose the rubric option(s) that apply to the written production, based on the evaluation criteria.
* **Written Production Comment** (`written_production_comment`, text, optional): Provide any additional comments or feedback on the written production.
* **Score** (`written_production_score`, number, optional): Enter a numerical score for the written production, if applicable.
* **Teacher Notes** (`teacher_notes`, text, optional): Add any additional notes or comments from the evaluator.
* **Date** (`date`, date, optional): Record the date the written production was evaluated.
* **Time** (`time`, time, optional): Record the time the written production was evaluated.
* **Form Submission Notes** (`form_submission_notes`, text, optional): Add any additional information or context for the form submission.
