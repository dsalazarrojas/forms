# Feature Assessment Form - Help Guide
## Purpose
This form is used to assess and prioritize features based on their priority, description, benefit, cost, and status. It is a tool to help you evaluate and compare features in a structured and organized way.

## How To Complete This Form
1. Select the feature you want to assess.
2. Input the feature's priority (if applicable).
3. Enter a brief description of the feature.
4. Describe the benefit of the feature.
5. Enter the cost of the feature (if applicable).
6. Select the status of the feature (Active or Inactive).
7. Click "Submit" to save your assessment.

## Field-by-Field Explanation
* **Feature 1** (`feature_assessment_form_1`, text, optional): Enter the name of the feature you want to assess.
* **Priority** (`feature_1_priority`, number, optional): Enter the priority of the feature (if applicable). Higher values indicate higher priority.
* **Description** (`feature_1_description`, text, optional): Enter a brief description of the feature.
* **Benefit** (`feature_1_benefit`, text, optional): Describe the benefit of the feature.
* **Cost** (`feature_1_cost`, number, optional): Enter the cost of the feature (if applicable).
* **Status** (`feature_1_status`, select_one, optional): Select the status of the feature (Active or Inactive).
* **Feature 2 1** (`feature_2_1`, text, optional): Enter the name of the first sub-feature.
* **Feature 2 1 Priority** (`feature_2_1_priority`, number, optional): Enter the priority of the sub-feature (if applicable).
* **Feature 2 1 Description** (`feature_2_1_description`, text, optional): Enter a brief description of the sub-feature.
* **Feature 2 1 Benefit** (`feature_2_1_benefit`, text, optional): Describe the benefit of the sub-feature.
* **Feature 2 1 Cost** (`feature_2_1_cost`, number, optional): Enter the cost of the sub-feature (if applicable).
* **Feature 2 1 Status** (`feature_2_1_status`, select_one, optional): Select the status of the sub-feature (Active or Inactive).
* **Feature 2 2** (`feature_2_2`, text, optional): Enter the name of the second sub-feature.
* **Feature 2 2 Priority** (`feature_2_2_priority`, number, optional): Enter the priority of the sub-feature (if applicable).
* **Feature 2 2 Description** (`feature_2_2_description`, text, optional): Enter a brief description of the sub-feature.
* **Feature 2 2 Benefit** (`feature_2_2_benefit`, text, optional): Describe the benefit of the sub-feature.
* **Feature 2 2 Cost** (`feature_2_2_cost`, number, optional): Enter the cost of the sub-feature (if applicable).
* **Feature 2 2 Status** (`feature_2_2_status`, select_one, optional): Select the status of the sub-feature (Active or Inactive).
* **Feature 3 1** (`feature_3_1`, text, optional): Enter the name of the third sub-feature.
* **Feature 3 1 Priority** (`feature_3_1_priority`, number, optional): Enter the priority of the sub-feature (if applicable).
* **Feature 3 1 Description** (`feature_3_1_description`, text, optional): Enter a brief description of the sub-feature.
* **Feature 3 1 Benefit** (`feature_3_1_benefit`, text, optional): Describe the benefit of the sub-feature.
* **Feature 3 1 Cost** (`feature_3_1_cost`, number, optional): Enter the cost of the sub-feature (if applicable).
* **Feature 3 1 Status** (`feature_3_1_status`, select_one, optional): Select the status of the sub-feature (Active or Inactive).
* **Feedback** (`feature_3_1_feedback`, text, optional): Enter any additional feedback about the sub-feature.

## Tips
* Make sure to fill in all required fields (if applicable).
* Be as detailed as possible in your descriptions and benefit inputs.
* Use the provided options for status and priority to help you make informed decisions.
* Review and revise your assessment before submitting it.
