# Data Warehouse Assessment Questionnaire - Help Guide
## Purpose
The Data Warehouse Assessment Questionnaire is designed to gather information about the current state of the data warehouse, including its governance, refresh cadence, and improvement priorities.

## How To Complete This Form
To complete this form, please follow these steps:

1. Review each page and answer the questions accordingly.
2. Make sure to fill out all required fields.
3. Provide clear and concise answers to the questions.
4. If you are unsure about any question, please ask for clarification or provide a clear explanation of your answer.

## Field-by-Field Explanation

* **Introduction** (`1`, `text`, required: `false`): This is a brief introduction to the data warehouse assessment. Please provide a short description of the data warehouse and its purpose.
* **Platform** (`2`, `text`, required: `false`): This field is for you to describe the platform or technology used for the data warehouse.
* **Governance** (`3`, `select_multiple`, required: `false`): This field allows you to select multiple governance models that apply to the data warehouse. Please choose from the following options:
	+ Stakeholder Feedback
	+ Governance Model
	+ Data Warehouse Team
	+ Refresh Frequency
	+ Data Lineage
	+ Data Quality
	+ Improvement Priorities
* **Refresh Cadence** (`4`, `date`, required: `false`): This field is for you to specify the refresh cadence of the data warehouse. Please enter a date in the correct format (e.g., "Once a week" or "Once a month").
* **Improvement Priorities** (`5`, `select_multiple`, required: `false`): This field allows you to select multiple improvement priorities for the data warehouse. Please choose from the following options:
	+ Data Quality
	+ Data Lineage
	+ Refresh Frequency
	+ Governance Model
	+ Stakeholder Feedback
	+ Improvement Priorities
	+ Data Warehouse Team
* **Stakeholder Feedback** (`6`, `note`, required: `false`): This field is for you to provide any additional feedback or comments from stakeholders.
* **Data Warehouse Team** (`7`, `text`, required: `false`): This field is for you to describe the data warehouse team, including their roles and responsibilities.
* **Governance Model** (`8`, `select_one`, required: `true`): This field is for you to select the governance model used for the data warehouse. Please choose from the following options:
	+ Centralized
	+ Decentralized
	+ Hybrid
* **Refresh Frequency** (`9`, `select_one`, required: `true`): This field is for you to select the refresh frequency of the data warehouse. Please choose from the following options:
	+ Once a week
	+ Once a month
	+ Once a quarter
	+ Once a year
* **Data Lineage** (`10`, `select_multiple`, required: `false`): This field allows you to select multiple data lineage options. Please choose from the following:
	+ Data Source
	+ Data Warehouse
	+ Data Model
	+ Data Quality
	+ Data Lineage
	+ Data Governance
* **Data Quality** (`11`, `select_multiple`, required: `true`): This field allows you to select multiple data quality options. Please choose from the following:
	+ Data Accuracy
	+ Data Completeness
	+ Data Timeliness
	+ Data Relevancy
	+ Data Integrity
* **Notes** (`12`, `note`, required: `false`): This field is for you to add any additional notes or comments.
* **Submit** (`13`, `text`, required: `false`): This field is not applicable for this form.
* **JotForm** (`14`, `text`, required: `false`): This field is not applicable for this form.
* **Assigned Tool** (`15`, `text`, required: `false`): This field is not applicable for this form.
