# Water Cadmium Contamination Assessment Form - Help Guide
## Purpose
This form is used to record data on the presence and levels of cadmium in water samples. It is meant to be completed by trained personnel to gather information on the location, type of sample, and other relevant details regarding cadmium contamination.

## How To Complete This Form
1. Select the type of sample from the options provided.
2. Enter the location where the sample was collected.
3. Record the date and time the sample was collected.
4. Enter the cadmium concentration in the specified units.
5. Select the cadmium status (Not Assessed, Low Risk, High Risk, Unknown/Unassessed, Other).
6. If applicable, select the follow-up action and date for follow-up.
7. Enter any follow-up remarks.
8. Select the units for follow-up.
9. Enter the follow-up location, personnel, and comments.
10. Finally, enter the IDs for the water source and sample.

## Field-by-Field Explanation
* **water_source** (1, text, required): Enter the source of the water sample (e.g., river, lake, etc.).
* **sample_type** (2, select_one, optional): Select the type of sample collected (e.g., Cadmium).
* **date_collected** (3, date, optional): Record the date the sample was collected.
* **time_collected** (4, time, optional): Record the time the sample was collected.
* **location** (5, text, optional): Enter the location where the sample was collected.
* **cadmium_concentration** (6, number, optional): Enter the cadmium concentration in the specified units.
* **cadmium_units** (7, select_one, optional): Select the units for cadmium concentration (e.g., micrograms per liter).
* **cadmium_status** (8, select_one, optional): Select the cadmium status (e.g., Not Assessed, Low Risk, etc.).
* **follow_up_action** (9, select_multiple, optional): Select the follow-up action (e.g., Follow up, No Action, Other Action, etc.).
* **follow_up_date** (10, date, optional): Enter the date for follow-up.
* **follow_up_time** (11, time, optional): Record the time for follow-up.
* **follow_up_location** (12, text, optional): Enter the location for follow-up.
* **follow_up_status** (13, select_one, optional): Select the follow-up status (e.g., Not Assessed, Low Risk, etc.).
* **follow_up_remarks** (14, text, optional): Enter any follow-up remarks.
* **follow_up_units** (15, select_one, optional): Select the units for follow-up (e.g., Milligrams/L).
* **follow_up_organisation** (16, text, optional): Enter the follow-up organisation.
* **follow_up_personnel** (17, text, optional): Enter the follow-up personnel.
* **follow_up_comments** (18, text, optional): Enter any follow-up comments.
* **water_source_id** (19, text, optional): Enter the ID for the water source.
* **sample_id** (20, text, optional): Enter the ID for the sample.
* **follow_up_last_update** (21, date, optional): Enter the last update date for follow-up.
