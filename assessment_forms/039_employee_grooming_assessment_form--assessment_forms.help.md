# Employee Grooming Assessment Form - Help Guide

## Purpose
The purpose of this form is to evaluate the employee's overall grooming standard and appearance.

## How To Complete This Form
1. Ensure that you have reviewed and evaluated the employee's appearance thoroughly.
2. Select the relevant attributes that best describe the employee's condition.
3. Provide any other feedback in the "feedback" field.
4. Sign and date the assessment.

## Field-by-Field Explanation

* **Employee ID** (employee_id, number, required: false): Enter the employee's ID number.
* **Job Title** (job_title, text, required: false): Enter the employee's job title.
* **Date of Joining** (date_of_joining, date, required: false): Enter the employee's date of joining.
* **Email** (email, email, required: false): Enter the employee's email address.
* **Phone** (phone, text, required: false): Enter the employee's phone number.
* **Overall Grooming Standard** (overall_grooming_standard, select_one, required: false): Select the overall grooming standard of the employee:
	+ Well groomed
	+ Below average
	+ Fair
	+ Poor
* **Hair Length** (hair_length, select_multiple, required: false): Select the hair length of the employee:
	+ Short
	+ Medium
	+ Long
* **Hair Color** (hair_color, select_one, required: false): Select the hair color of the employee:
	+ Brown
	+ Blonde
	+ Grey
	+ Red
* **Facial Hair** (facial_hair, select_one, required: false): Select the facial hair of the employee:
	+ Shaved
	+ Light
	+ Medium
	+ Dark
* **Mustache** (mustache, select_one, required: false): Select the mustache of the employee:
	+ No
	+ Trimmed
	+ Full
* **Eye Brows** (eye_brows, select_one, required: false): Select the eye brows of the employee:
	+ No
	+ Trimmed
	+ Full
* **Beard** (beard, select_one, required: false): Select the beard of the employee:
	+ No
	+ Trimmed
	+ Full
* **Ear Lobes** (ear_lobes, select_one, required: false): Select the ear lobes of the employee:
	+ No
	+ Small
	+ Medium
	+ Large
* **Nose Shape** (nose_shape, select_one, required: false): Select the nose shape of the employee:
	+ Straight
	+ Slightly curved
	+ Hooked
* **Overall Impression** (overall_impression, select_multiple, required: false): Select the overall impression of the employee:
	+ Professional
	+ Unprofessional
* **Feedback** (feedback, text, required: false): Provide any other feedback about the employee.
* **Signature** (signature, note, required: false): This is a placeholder for the assessor's signature.
* **Employee Signature** (employee_signature, select_one, required: false): Select whether the employee has signed the assessment:
	+ No
	+ Yes
* **Date of Assessment** (date_of_assessment, date, required: false): Enter the date of the assessment.
* **Assessed By** (assessed_by, text, required: false): Enter the name of the assessor.
* **Assessment Type** (assessment_type, select_one, required: false): Select the type of assessment:
	+ Grooming
	+ Dress
	+ Overall appearance

## Tips
* Ensure that you have reviewed and evaluated the employee's appearance thoroughly before completing this form.
* Be specific when selecting the attributes that best describe the employee's condition.
* Provide any other feedback that may be relevant to the assessment.
* Sign and date the assessment.
