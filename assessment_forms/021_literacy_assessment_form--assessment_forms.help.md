# Literacy Assessment Form - Help Guide
## Purpose
The Literacy Assessment Form is used to evaluate an individual's reading, writing, speaking, and listening comprehension skills.

## How To Complete This Form
To complete this form, follow these steps:

* Start by filling in the required fields as accurately as possible.
* Ensure that you have completed all the fields before submitting the form.
* Review the form carefully to ensure that you have answered all the necessary questions.

## Field-by-Field Explanation
### Page 1
* **First Page** (`first_page`, note, required: false): This page is a note field where you can take any notes or comments about the assessment. It is not required to fill this field.
* **Reading Comprehension** (`reading_comprehension`, text, required: false): This field is for assessing the individual's reading comprehension skills. Please provide a detailed description of their reading ability.
* **Writing Comprehension** (`writing_comprehension`, text, required: false): This field is for assessing the individual's writing comprehension skills. Please provide a detailed description of their writing ability.
* **Speaking Comprehension** (`speaking_comprehension`, text, required: false): This field is for assessing the individual's speaking comprehension skills. Please provide a detailed description of their speaking ability.
* **Listening Comprehension** (`listening_comprehension`, text, required: false): This field is for assessing the individual's listening comprehension skills. Please provide a detailed description of their listening ability.

### Page 2
* **Overall Assessment** (`overall_assessment`, select_one, required: false): Please select one of the options to provide a general assessment of the individual's overall literacy level. The options are 'Yes' or 'No'.
* **Total Score** (`total_score`, number, required: false): This field is for recording the total score of the assessment. Please enter the total score as a number.
* **First Page 2** (`first_page_2`, note, required: false): This is another note field for any additional comments or notes about the assessment. It is not required to fill this field.

## Tips
* Be as accurate as possible when completing the form.
* Ensure that you have all the necessary information before completing the form.
* Review the form carefully before submitting it.
* If you are unsure about any of the fields, please reach out to the relevant personnel for guidance.
