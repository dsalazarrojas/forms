# Grief Impact Assessment For Children - Help Guide
## Purpose
The "Grief Impact Assessment For Children" form is designed to help parents and caregivers assess the emotional and behavioral impact of grief on children. It is used to identify potential issues that may require professional support and to provide a comprehensive picture of the child's well-being.

## How To Complete This Form
To complete this form, please follow these steps:

1. Answer each question honestly and thoroughly, based on your knowledge of the child's situation.
2. For questions with multiple options, select all that apply.
3. If a question does not apply to the child's situation, mark the "Other (please specify)" option and provide a brief explanation.
4. Fill out the form in its entirety, and be as detailed as possible in your responses.

## Field-by-Field Explanation

* **Introduction**: This is a brief introduction to the form and its purpose.
* **Child Identification**: Please enter the child's name, age, and any other relevant identification information.
* **Relationship**: Please select the relationship between the child and the deceased (e.g. parent, grandparent, sibling).
* **Grief Type**: Please select all types of grief that you believe the child is experiencing (e.g. acute, chronic, complicated).
* **Emotional Reactions**: Please select all emotional reactions that you have observed in the child (e.g. sadness, frustration, anger).
* **Coping Mechanisms**: Please select all coping mechanisms that you have observed in the child (e.g. denial, bargaining, avoidance).
* **Behavioral Changes**: Please select all behavioral changes you have observed in the child (e.g. sleep disturbances, loss of interest, changes in behavior).
* **Emotional Changes**: Please select all emotional changes you have observed in the child (e.g. sadness, fear, shame).
* **Cognitive Changes**: Please select all cognitive changes you have observed in the child (e.g. lack of concentration, memory disturbances, disorganized thinking).
* **Functional Changes**: Please select all functional changes you have observed in the child (e.g. changes in school work, changes in social interactions).
* **Social Support**: Please select all sources of social support available to the child (e.g. true, false).
* **Support System**: Please select all sources of formal and informal support available to the child (e.g. formal support, informal support).
* **Caregiver Support**: Please select all sources of caregiver support available to the child (e.g. true, false).
* **Professional Support**: Please select all sources of professional support available to the child (e.g. true, false).
* **Self Support**: Please select all sources of self-support available to the child (e.g. true, false).
* **Support Network**: Please select all sources of support network available to the child (e.g. true, false).
* **Family Support**: Please select all sources of family support available to the child (e.g. true, false).
* **Other Support**: Please select all other sources of support available to the child (e.g. true, false).
* **Total Support**: Please enter a numerical value representing the total level of support available to the child.
* **Score**: Please enter a numerical value representing the level of grief impact on the child.
* **Completed**: Please enter the date and time the form was completed.
* **Notes**: Please enter any additional information or comments about the child's situation.
* **Additional Notes**: Please enter any additional information or comments about the child's situation.
