# Functional Group Knowledge Quiz - Help Guide
## Purpose
This form is designed to evaluate a user's knowledge of various functional groups in chemistry, specifically in the context of organic chemistry. It consists of a single question that asks for the molecular formula for a given functional group. The user is expected to provide the correct molecular formula as their answer.

## How To Complete This Form
To complete this form, follow these steps:

1. Read the prompt carefully and try to remember the molecular formula for the given functional group.
2. Type your answer in the designated answer field.
3. Click the "Submit" button to submit your answer.

## Field-by-Field Explanation

* **first-page**: This is the first page of the form where the prompt is displayed.
	+ Type: text
	+ Purpose: Displays the first page of the form.
* **quiz-question**: This field is not a question in the classical sense, but rather a text prompt asking for a specific molecular formula.
	+ Type: text
	+ Purpose: Displays the question that asks for the molecular formula.
* **answer-input**: This is the field where you can type your answer.
	+ Type: text
	+ Purpose: Enter your answer to the question.
* **submit-button**: Click this button to submit your answer.
	+ Type: text
	+ Purpose: Submit your answer to the system.
* **result-label**: This field will display a label indicating the result of your submission.
	+ Type: note
	+ Purpose: Displays the result of your submission (if any).
* **result-value**: This field will display the value of your submission result (if any).
	+ Type: note
	+ Purpose: Displays the value of your submission result (if any).

## Tips
- Please make sure to answer the question carefully and accurately.
- If you are unsure of the molecular formula, you can research it or check your notes.
