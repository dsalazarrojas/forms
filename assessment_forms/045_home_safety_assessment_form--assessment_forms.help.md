# Home Safety Assessment Form - Help Guide
## Purpose
The Home Safety Assessment Form is a comprehensive evaluation tool for home safety features and systems. It helps homeowners, buyers, or sellers assess a home's safety and accessibility.

## How To Complete This Form
To complete this form, follow these steps:

1. Review each page carefully to ensure you answer every question accurately.
2. Fill in the required fields (indicated by *).
3. For select and multiple-choice questions, select all relevant options that apply.
4. If a question is not applicable, leave it blank or select "Not Applicable" (if available).
5. Review and submit your form when complete.

## Field-by-Field Explanation

* **Home Safety Assessment Form** (`main_page`, text, not required)
    This is the introduction page for the form.
* **Electrical** (`electrical_page`, select_multiple, not required)
    * **Option 1**: Check if there is a dedicated circuit breaker for each electrical panel.
    * **Option 2**: Check if the electrical panels are installed and secured.
    * **Option 3**: Check if there are ground fault circuit interrupters (GFCIs) installed.
* **Safety Precautions** (`safety_precautions_page`, select_one, required)
    * **Option 1**: Check if there are safety precautions for emergency exits.
    * **Option 2**: Check if there are safety precautions for emergency contact information.
* **Fire Safety** (`fire_safety_page`, number, not required)
    This field is for evaluating a home's fire safety features. Enter the number that best represents the safety features.
* **Water Safety** (`water_safety_page`, select_multiple, required)
    * **Option 1**: Check if there is a water shut-off valve.
    * **Option 2**: Check if there is a sump pump and backup power source.
* **Miscellaneous** (`miscellaneous_page`, text, not required)
    Use this field for any other safety features or concerns not listed above.
