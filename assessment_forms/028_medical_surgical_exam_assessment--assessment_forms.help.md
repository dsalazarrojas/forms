# Medical Surgical Exam Assessment - Help Guide
## Purpose
This form is used to assess a patient's condition after a surgical procedure. It helps clinicians make informed decisions about the patient's care and ensures that all necessary information is collected for further evaluation and treatment.

## How To Complete This Form
1. Go through each section carefully, and make sure you have all the necessary information before starting.
2. For select_multiple and select_one fields, choose the most accurate option from the provided list.
3. For text fields, enter the relevant information, such as the patient's name, date of birth, and other identifying details.
4. Date fields are in the format MM/DD/YYYY.
5. Time fields are in the format HH:MM (24-hour clock).

## Field-by-Field Explanation
* **Patient Status** (`patient_status`, Select Multiple, **Required**): Choose one or more of the following options:
	+ Active
	+ Stable
	+ Unstable
* **Vital Signs** (`vital_signs`, Number, **Required**): Enter the patient's vital signs, such as blood pressure, temperature, and pulse.
* **Surgical Details** (`surgical_details`, Text, **Required**): Provide information about the surgical evaluation, including any complications or concerns.
* **Patient Information** (`patient_info`, Text, **Required**): Enter the patient's name, date of birth, and other relevant identifying details.
* **Surgical Findings** (`surgical_findings`, Select One, **Required**): Choose one of the following options:
	+ Positive
	+ Negative
	+ Unknown
* **Surgical Recommendations** (`surgical_recommendations`, Select Multiple, **Required**): Choose one or more of the following options:
	+ Option 1
	+ Option 2
	+ Option 3
* **Medical History** (`medical_history`, Text, **Required**): Enter the patient's medical history, including any relevant allergies or medical conditions.
* **Surgical Outcome** (`surgical_outcome`, Date, **Required**): Enter the date of the surgical outcome.
* **Postoperative Care** (`postoperative_care`, Select Multiple, **Optional**): Choose one or more of the following options:
	+ Option 1
	+ Option 2
	+ Option 3
* **Postoperative Follow-up** (`postoperative_follow_up`, Time, **Optional**): Enter the time for postoperative follow-up.
* **Additional Notes** (`additional_notes`, Note, **Optional**): Enter any additional notes or comments about the patient's condition.
* **Patient Signature** (`patient_signature`, Text, **Optional**): Enter the patient's signature, if applicable.
* **Clinician Signature** (`clinician_signature`, Text, **Optional**): Enter the clinician's signature, if applicable.
* **Facility Name** (`facility_name`, Text, **Required**): Enter the facility's name where the surgery was performed.
* **Facility Address** (`facility_address`, Text, **Required**): Enter the facility's address where the surgery was performed.
* **Facility Phone** (`facility_phone`, Text, **Required**): Enter the facility's phone number.
* **Contact Name** (`contact_name`, Text, **Required**): Enter the contact name and title (e.g., "Surgical Nurse").
* **Contact Phone** (`contact_phone`, Text, **Required**): Enter the contact phone number.
* **Medical Provider** (`medical_provider`, Text, **Required**): Enter the medical provider's name and title (e.g., "Surgeon, MD").
* **Medical License** (`medical_license`, Text, **Required**): Enter the medical provider's license number.
* **Medical Insurance** (`medical_insurance`, Text, **Required**): Enter the patient's medical insurance information.
* **Facility License** (`facility_license`, Text, **Required**): Enter the facility's license number.
* **Submit** (`submit`, Select One, **Required**): Choose one of the following options:
	+ Submit
	+ Other
