# structural_development_assessment_form - Help Guide
## Purpose
This form is designed to collect information about the structural development of a project. It assesses various aspects of the project, including site evaluation, structural development status, construction type, and more.

## How To Complete This Form
1. Review the project's current status and any relevant documentation before filling out this form.
2. Select the relevant options for each field based on your knowledge and observations.
3. Provide accurate and thorough information for each field.

## Field-by-Field Explanation

* **Site Evaluation** (`1`, `text`, required: false):
	+ Enter a brief description of the site evaluation, including any relevant comments or observations.
* **Structural Development Status** (`2`, `select_one`, required: false):
	+ Select one of the following:
		- Active
		- Inactive
* **Construction Type** (`3`, `select_multiple`, required: false):
	+ Select all that apply:
		- Yes
		- No
* **Project Location** (`4`, `text`, required: false):
	+ Enter the location of the project.
* **Date of Structural Evaluation** (`5`, `date`, required: false):
	+ Enter the date of the structural evaluation.
* **Site Visit Time** (`6`, `time`, required: false):
	+ Enter the time spent on the site visit.
* **Site Visit Date** (`7`, `date`, required: false):
	+ Enter the date of the site visit.
* **Structural Development Team Members** (`8`, `select_multiple`, required: false):
	+ Select all that apply:
		- Yes

* **Structural Development Issues** (`9`, `select_multiple`, required: false):
	+ Select all that apply:
		- Yes

* **Site Evaluations** (`10`, `select_multiple`, required: false):
	+ Select all that apply:
		- Yes
		- No
* **Findings** (`11`, `text`, required: false):
	+ Enter any findings or observations from the site evaluation.
* **Site Visit Frequency** (`12`, `select_one`, required: false):
	+ Select one of the following:
		- Yes

* **Construction Status** (`13`, `text`, required: false):

* **Project Start Date** (`14`, `date`, required: false):
