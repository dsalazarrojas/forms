# Foundation Skills Assessment - Help Guide
## Purpose
This form is used to capture information about an individual's progress in foundation skills assessment.

## How To Complete This Form
To complete this form, follow these steps:

1. **User Input**: Enter the user's input in this field. This could be their response to a question or an answer to an assessment question.
2. **Assessment Date**: Enter the date of the assessment.
3. **User ID**: Enter the user's ID number.
4. **Email**: Enter the user's email address.
5. **Phone**: Enter the user's phone number.
6. **Assessment Result**: Select the assessment result from the drop-down menu: Pass, Fail, or In Progress.
7. **Notes**: Add any additional notes about the assessment.

## Field-by-Field Explanation
* **User Input** (`user_input`, text, optional): Enter any relevant input or response from the user.
* **Assessment Date** (`assessment_date`, date, optional): Enter the date of the assessment.
* **User ID** (`user_id`, number, optional): Enter the user's ID number.
* **Email** (`email`, email, optional): Enter the user's email address.
* **Phone** (`phone`, text, optional): Enter the user's phone number.
* **Assessment Result** (`assessment_result`, select_one, optional): Select the assessment result: Pass, Fail, or In Progress.
* **Notes** (`notes`, note, optional): Add any additional notes about the assessment.
