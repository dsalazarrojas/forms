# Rider Performance Evaluation - Help Guide
## Purpose
The Rider Performance Evaluation form is used to assess the performance of a rider, tracking their progress, and providing feedback to improve their skills.

## How To Complete This Form
To complete this form, navigate through the pages and fields, providing information as needed. Each section is designed to gather specific information about the rider.

## Field-by-Field Explanation
*   **Introduction**: A text field for a brief introduction or context about the rider. (Not required)
*   **Rider Info**: A text field for entering information about the rider, such as their name, ID number, or other relevant details. (Not required)
*   **Rider Skills**: Select one or more of the options (Basic, Intermediate, Advanced) to describe the rider's skills. (Not required)
*   **Riding Ability**: Select the rating (1, 2, or 3) to describe the rider's riding ability. (Not required)
*   **Rider Level**: Select the level (Beginner, Intermediate, or Advanced) to describe the rider's level. (Not required)
*   **Rider Comments**: Enter comments or feedback about the rider. (Not required)
*   **Instructor Comments**: Enter additional comments or feedback about the rider. (Not required)
*   **Assessment Date**: Enter the date of the assessment. (Not required)
*   **Assessment Time**: Enter the time of the assessment. (Not required)
*   **Evaluation Form Completed By**: Select who completed the evaluation form (Trainer 1, 2, or 3). (Not required)

## Tips
*   Be sure to fill out each field as accurately and thoroughly as possible.
*   If a field is not required, you can leave it blank.
*   Use this form for internal purposes only.
