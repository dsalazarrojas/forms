# Critical Reading Assessment - Help Guide
## Purpose
The Critical Reading Assessment is a form used to evaluate a student's reading performance and identify areas where they may need additional support or guidance.

## How To Complete This Form
To complete this form, please follow these steps:

1.  Read the introduction and familiarize yourself with the assessment criteria.
2.  Determine whether the student has demonstrated 'Yes' or 'No' for each of the comprehension and analytical skills sections.
3.  Select the appropriate grade for the student based on their overall performance.

## Field-by-Field Explanation

* **Introduction** (`1`, `text`, required: false): This section is an optional introduction to the assessment. It is not a required field, but it provides context for the assessment.
* **Student Information** (`2`, `select_one`, required: false): Please select 'Yes' or 'No' to indicate whether the student has provided relevant student information.
* **Reading Passage** (`3`, `select_one`, required: false): Please select 'Yes' or 'No' to indicate whether the student has demonstrated understanding of the reading passage.
* **Comprehension Questions** (`4`, `select_multiple`, required: false): Please select all the comprehension questions that the student answered correctly.
* **Analytical Questions** (`5`, `select_multiple`, required: false): Please select all the analytical questions that the student answered correctly.
* **Reading Comprehension** (`6`, `text`, required: false): This is an optional text field for any additional comments about the student's reading comprehension.
* **Analytical Skills** (`7`, `text`, required: false): This is an optional text field for any additional comments about the student's analytical skills.
* **Additional Comments** (`8`, `text`, required: false): This is an optional text field for any additional comments about the student's performance.
* **Student Grade** (`9`, `select_one`, required: false): Please select a grade for the student based on their overall performance.
