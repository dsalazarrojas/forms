# Stove Installation Assessment - Help Guide
## Purpose
This form is designed to gather information about the installation of a stove in a property. It is used to record and assess details about the property, stove type, and other relevant information.

## How To Complete This Form
To complete this form, follow these steps:

1. Start by providing the **Property Details** in the first field.
2. Select the type of **Stove Type** being installed from the dropdown menu.
3. Provide information about **Ventilation Info**, if applicable.
4. Add any relevant **Photos** of the installed stove.
5. List any **Requirements** for the stove installation, if applicable.
6. Enter the name of the **Property Owner**.
7. Enter the **Property Address**.

## Field-by-Field Explanation
* **Property Details**: This field is the first step in completing the form. Enter a brief description of the property where the stove is being installed. This should include any relevant details about the property's size, location, or other features that may impact the installation.
* **Stove Type**: This field is a dropdown menu with three options: **Gas Stove**, **Electric Stove**, or **Other**. Select the type of stove that is being installed.
* **Ventilation Info**: This field is for any additional information about the ventilation requirements for the stove. If you are unsure, leave this field blank.
* **Photos**: This field is for adding any relevant photos of the installed stove. You can add multiple photos if necessary.
* **Requirements**: This field is for listing any special requirements for the stove installation. If you are unsure, leave this field blank.
* **Property Owner**: Enter the name of the property owner.
* **Property Address**: Enter the address of the property where the stove is being installed.

## Tips
* Make sure to accurately complete each field to ensure the form is completed correctly.
* If you are unsure about any of the fields, please ask your supervisor for guidance.
* Remember to review and edit your responses before submitting the form.
