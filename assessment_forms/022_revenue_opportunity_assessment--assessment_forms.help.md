# Revenue Opportunity Assessment - Help Guide
## Purpose
The Revenue Opportunity Assessment form is used to capture information about a specific revenue opportunity.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the company name in the Company Name field.
2. Provide the sales manager's name and contact information, if applicable, in the Sales Manager field.
3. Enter the account owner's name and contact information, if applicable, in the Account Owner field.
4. Enter the revenue value of the opportunity in the Revenue Value field. Use numerical figures for this field.
5. Enter the close probability of the opportunity in the Close Probability field. Use a numerical value between 0 and 100.
6. Select the pipeline stage of the opportunity from the options provided in the Pipeline Stage field.
7. Provide a brief description of the opportunity in the Deal Description field.
8. Select the type of opportunity from the options provided in the Opportunity Type field.
9. Enter the customer's name in the Customer Name field.
10. Select the company size of the customer from the options provided in the Company Size field.

## Field-by-Field Explanation

* **Company Name** (`company_name`, **text**, required): Enter the name of the company related to the revenue opportunity.
* **Sales Manager** (`sales_manager`, **text**, optional): Provide the name and contact information of the sales manager responsible for this opportunity. This field is not required but can be helpful in case the sales team needs to follow up with the sales manager.
* **Account Owner** (`account_owner`, **text**, optional): Enter the name and contact information of the account owner responsible for this opportunity. This field is not required but can be helpful for future reference.
* **Revenue Value** (`revenue_value`, **number**, optional): Enter the estimated revenue value of the opportunity. Use numerical figures for this field.
* **Close Probability** (`close_probability`, **number**, optional): Enter the close probability of the opportunity, represented as a percentage value between 0 and 100.
* **Pipeline Stage** (`pipeline_stage`, **select_one**, optional): Select the pipeline stage of the opportunity from the provided options.
	+ Pipeline Stage 1
	+ Pipeline Stage 2
	+ Pipeline Stage 3
* **Deal Description** (`deal_description`, **text**, optional): Provide a brief description of the opportunity.
* **Opportunity Type** (`opportunity_type`, **select_one**, optional): Select the type of opportunity from the options provided:
	+ New Opportunity
	+ Existing Opportunity
* **Customer Name** (`customer_name`, **text**, optional): Enter the customer's name.
* **Company Size** (`company_size`, **select_one**, optional): Select the company size from the options provided:
	+ Less than 10 employees
	+ 10-100 employees
	+ More than 100 employees

## Tips
* Ensure that you are not duplicating an existing opportunity before filling out this form.
* Use numerical values for the Revenue Value and Close Probability fields.
* Select the correct pipeline stage and opportunity type to accurately represent the opportunity.
