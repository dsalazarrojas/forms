# Accounting Information Systems Quiz - Help Guide
## Purpose
This form is designed to assess the student's understanding of accounting information systems (AIS) concepts. It contains questions that aim to evaluate the student's knowledge on various aspects of AIS, including its purpose, components, and importance in the context of accounting.

## How To Complete This Form
1. To complete this form, please select the correct answers for each question.
2. Start by filling in the student information section, which includes fields for student name, ID, and course section.
3. Then, select the correct answers to the multiple-choice questions regarding the purpose, components, and importance of AIS.
4. For the free-text questions, provide a short explanation or list relevant information.
5. Finally, submit the form to complete the assessment.

## Field-by-Field Explanation
* **Student name**: Enter your full name for grading purposes.
* **Student ID**: Enter your university or course ID.
* **Course section**: Enter the course code or semester.
* **Understanding of AIS purpose**: Select the best answer that describes the purpose of AIS.
	+ Data processing and reporting
	+ Human resources only
	+ Marketing analytics only
* **Components of an AIS**: Choose all that apply:
	+ People
	+ Procedures
	+ Data
	+ Software
	+ Hardware
* **Control objectives**: Select the best answer that describes the purpose of control objectives.
	+ Ensure data integrity
	+ Increase sales
	+ Reduce marketing spend
* **Evidence of transactions**: Select the best answer that describes which document provides primary transaction evidence.
	+ Invoice
	+ Memo
	+ Marketing plan
* **Importance of audit trail**: This question is optional and requires a short explanation.
* **Common security measures**: This question is optional and allows you to list up to three measures.
* **System integration benefits**: Select the best answer that describes the benefit of system integration.
	+ Streamlined reporting
	+ More manual entry
	+ Increased errors
* **Instructor notes**: Enter any grading comments from the instructor.
* **Submission date**: Select the date of submission in the format YYYY-MM-DD.
