# evaluation_models_assessment - Help Guide
## Purpose
The evaluation models assessment form is used to evaluate the performance of different models and provide feedback on their performance.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the evaluation models form section with a brief title summarizing the evaluation.
2. In the evaluation criteria section, describe the criteria you used to evaluate the models.
3. Provide your comments on the models in the evaluation comments section.
4. Select the date and time of the evaluation from the respective fields.
5. Choose the strategies that were used during the evaluation from the evaluation strategies field.
6. Select the models that were used during the evaluation from the evaluation models used field.
7. Add any additional notes in the evaluation notes section.

## Field-by-Field Explanation
- **Evaluation Models Form** (`evaluation_models_form`, text, optional): A brief title summarizing the evaluation.
- **Evaluation Criteria 1** (`evaluation_criteria_1`, text, optional): Describe the criteria used to evaluate the models.
- **Evaluation Criteria 2** (`evaluation_criteria_2`, text, optional): Describe the second set of criteria used to evaluate the models.
- **Evaluation Comments** (`evaluation_comments`, text, optional): Provide comments on the models.
- **Evaluation Date** (`evaluation_date`, date, optional): Select the date of the evaluation.
- **Evaluation Time** (`evaluation_time`, time, optional): Select the time of the evaluation.
- **Evaluation Strategies** (`evaluation_strategies`, select multiple, optional): Choose the strategies used during the evaluation.
  • Select one or more strategies from the list.
- **Evaluation Models Used** (`evaluation_models_used`, select one, optional): Choose the models used during the evaluation.
  • Select one model from the list.
- **Evaluation Notes** (`evaluation_notes`, note, optional): Add any additional notes on the evaluation.
  • This field is a free text field where you can add any additional information.

## Tips
- Make sure to complete all the required fields.
- Use the evaluation strategies and models used fields to provide specific information on the evaluation.
- Use the evaluation date and time fields to ensure that the evaluation is properly dated and timed.
- Use the evaluation comments field to provide detailed comments on the models.
- Use the evaluation notes field to add any additional information that is not included in the other fields.
