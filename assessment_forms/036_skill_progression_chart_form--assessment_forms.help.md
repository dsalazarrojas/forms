# Skill Progression Chart Form - Help Guide

## Purpose
This form is designed to track the skills and progress of employees in an organization. It provides a structured way to record and analyze employee skill development over time.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the Employee ID, which is a unique identifier for the employee.
2. Select the date for which you want to record the skills and progress of the employee.
3. Answer each skill question with "Yes" or "No" to indicate whether the employee has developed that skill or not.
4. For skills 3, 5, 6, and 7, select multiple skills that apply.
5. Select "Yes" or "No" for Coaching Check-in, which indicates if there was a coaching check-in for the employee.
6. Select "Yes" or "No" for Development Plan, which indicates if a development plan was created for the employee.
7. Enter any additional notes about the employee's progress in the Notes field.

## Field-by-Field Explanation

* **Employee Id** (1, number, required): Enter the unique identifier for the employee.
* **Date** (2, date, required): Select the date for which you want to record the skills and progress of the employee.
* **Skill 1** (3, select_one, required): Answer "Yes" if the employee has developed this skill, "No" otherwise.
* **Skill 2** (4, select_one, optional): Answer "Yes" if the employee has developed this skill, "No" otherwise.
* **Skill 3** (5, select_multiple, optional): Select all skills that apply.
	+ Options: "Yes", "No"
* **Skill 4** (6, select_multiple, optional): Select all skills that apply.
	+ Options: "Yes", "No"
* **Skill 5** (7, select_multiple, optional): Select all skills that apply.
	+ Options: "Yes", "No"
* **Skill 6** (8, select_multiple, optional): Select all skills that apply.
	+ Options: "Yes", "No"
* **Skill 7** (9, select_multiple, optional): Select all skills that apply.
	+ Options: "Yes", "No"
* **Skill 8** (10, select_multiple, optional): Select all skills that apply.
	+ Options: "Yes", "No"
* **Skill 9** (11, select_multiple, optional): Select all skills that apply.
	+ Options: "Yes", "No"
* **Skill 10** (12, select_multiple, optional): Select all skills that apply.
	+ Options: "Yes", "No"
* **Coaching Check-in** (13, select_multiple, optional): Answer "Yes" if there was a coaching check-in for the employee, "No" otherwise.
* **Development Plan** (14, select_one, optional): Answer "Yes" if a development plan was created for the employee, "No" otherwise.
* **Notes** (15, note, required): Enter any additional notes about the employee's progress.
