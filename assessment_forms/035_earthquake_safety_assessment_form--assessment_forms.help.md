# Earthquake Safety Assessment Form - Help Guide
## Purpose
The Earthquake Safety Assessment Form is designed to collect information about a building's safety measures and features in the context of earthquake hazards. This form will help identify potential risks and vulnerabilities in the building and provide a basis for the assessment and evaluation of the building's earthquake safety.

## How To Complete This Form
To complete this form, please follow these steps:

1. Ensure you are familiar with the building's layout, features, and emergency procedures.
2. Review the provided options and select the relevant information for each field.
3. Answer all mandatory fields (indicated by the "required" attribute in the form).
4. Enter accurate and up-to-date information.
5. Submit the form to complete the assessment and evaluation process.

## Field-by-Field Explanation

* **Building Type** (`2`): This field asks you to select the type of building, which can be either High Rise, Low Rise, or Special Building.
* **Building Structure** (`3`): This field requests you to select the type of building structure, which can be either Steel, Masonry, Wood, or Concrete.
* **Earthquake Safety Features** (`4`): This field asks you to select all the earthquake safety features that are present in the building, such as Earthquake-Resistant Design, Seismic Design Category, and Base Isolation System.
* **Building Age** (`5`): This field asks you to enter the age of the building in years.
* **Building Height** (`6`): This field asks you to enter the height of the building in meters or feet.
* **Building Location** (`7`): This field asks you to enter the address or location of the building.
* **Emergency Contact** (`8`): This field asks you to enter the name and contact information of the emergency contact person.
* **Emergency Contact Phone** (`9`): This field asks you to enter the phone number of the emergency contact person.
* **Emergency Contact E-mail** (`10`): This field asks you to enter the email address of the emergency contact person.
* **Earthquake Safety Measures** (`11`): This field is a text box for additional notes or comments about the building's earthquake safety measures.
* **Building Occupancy** (`12`): This field asks you to select the level of building occupancy, which can be Low, Medium, or High.
* **Building Hazards** (`13`): This field asks you to select all the potential hazards present in the building, such as Structural, Electrical, Fire, and Gas.
* **Fire Alarm System** (`14`): This field asks you to select whether the building has a fire alarm system, which is a mandatory field.
* **Fire Suppression System** (`15`): This field asks you to select whether the building has a fire suppression system, which is a mandatory field.
* **Sprinklers** (`16`): This field asks you to select whether the building has sprinklers.
* **Fire Extinguishers** (`17`): This field asks you to select whether the building has fire extinguishers.
* **Fire Safety Features** (`18`): This field asks you to select all the fire safety features present in the building.
* **Electrical Systems** (`19`): This field asks you to select all the electrical systems present in the building.
* **Electrical Hazards** (`20`): This field asks you to select all the electrical hazards present in the building.
* **Gas Leaks** (`21`): This field asks you to select whether the building has a gas leak.
* **Gas Shut-Off** (`22`): This field asks you to select whether the building has a gas shut-off system.
* **Water Leaks** (`23`): This field asks you to select whether the building has a water leak.
* **Earthwork** (`24`): This field asks you to select whether the building has an earthwork system.
* **Other Earthwork** (`25`): This field asks you to enter any other earthwork systems not mentioned in the options.

Note: All fields are required unless otherwise indicated.
