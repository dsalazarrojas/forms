# Lawn Mower Safety Assessment - Help Guide
## Purpose
The Lawn Mower Safety Assessment form is designed to evaluate the readiness of lawn mower operators to perform their job safely.

## How To Complete This Form
To complete this form, please follow these steps:

1. Select all that apply for Operator Readiness:
	* Operator is alert and attentive
	* Operator has knowledge of mowing equipment safety procedures
	* Operator has knowledge of mowing practices and techniques
	* Operator is familiar with safe work practices for mowing and maintenance
	* Operator has access to personal protective equipment (PPE)
	* Operator has received training on mowing and maintenance
	* Operator has knowledge of emergency procedures
	* Operator has knowledge of safe work practices for the environment
2. Select all that apply for Equipment Condition:
	* Good working order
	* Minor issues
	* Needs repair
	* Needs replacement
3. Provide a detailed description of Safe Mowing Practices in the text field.
4. Select all that apply for Safe Mowing Practices Checklist:
	* Check for any obstacles in the path
	* Check equipment and controls for damage
	* Check for uneven terrain
	* Check the weather forecast
	* Check for obstacles under the mower
	* Check for uneven mower deck
	* Check for overgrown vegetation
	* Check for loose items in the path
	* Check for uneven ground
5. Select one option for Emergency Procedures:
	* Emergency procedures in place for fire
	* Emergency procedures in place for accidents
	* Emergency procedures in place for other incidents
	* No emergency procedures in place
6. Select one option for Mowing Equipment:
	* Gas mower
	* Electric mower
	* Other - please describe
7. Provide a detailed description of Operator Instructions in the text field.
8. Provide any Additional Comments in the text field.
9. Enter the name and contact information of the emergency contact person.
10. Enter your Operator Name.
11. Select the Date and Time Submitted.
12. Enter your Operator E-mail.
13. Enter your Operator Phone number.

## Field-by-Field Explanation

* **Operator Readiness (Operator is alert and attentive)**: Select this option if the operator is alert and attentive while performing their job.
* **Equipment Condition (Good working order)**: Select this option if the equipment is in good working order.
* **Safe Mowing Practices**: Describe in detail the safe practices the operator follows while mowing.
* **Safe Mowing Practices Checklist**: Select all that apply to ensure the operator is following safe mowing practices.
* **Emergency Procedures (Emergency procedures in place for fire)**: Select this option if emergency procedures are in place in case of a fire.
* **Mowing Equipment (Gas mower)**: Select this option if the operator is using a gas-powered mower.
* **Operator Instructions**: Describe in detail the instructions provided to the operator for safe mowing practices.
* **Additional Comments**: Enter any additional comments or notes about the mowing activity.
* **Emergency Contact (Name of contact person)**: Enter the name of the emergency contact person.
* **Contact Name**: Enter the name of the contact person.
* **Operator Name (Name of operator)**: Enter your name as the operator.
* **Date Submitted (Date of submission)**: Enter the date and time of submission.
* **Operator E-mail (Email address of operator)**: Enter your email address.
* **Operator Phone (Phone number of operator)**: Enter your phone number.

## Tips

* Be honest and accurate when filling out this form.
* Make sure to select all options that apply to ensure a thorough assessment.
* Provide detailed descriptions for text fields.
* Check the form for any errors before submission.
