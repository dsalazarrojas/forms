# Palliative Care Program Assessment Form - Help Guide
## Purpose
This form is designed to assess the patient's needs and preferences for palliative care, providing a comprehensive evaluation of their symptoms, medical conditions, and support requirements.

## How To Complete This Form
1. Enter your first name
2. Enter your last name
3. Select your date of birth
4. Enter your contact number
5. Enter your email address
6. Select your preferred language
7. Select your medical team
8. Select your patient's needs (e.g. pain, fatigue, etc.)
9. If "Other" is selected, please specify the patient's needs in the text field below
10. Select if the patient has family support
11. Select if the patient has spiritual support
12. Select if the patient has advance care planning
13. Select if the patient has pain control
14. Select if the patient has fatigue control
15. Select if the patient has breath control
16. Select if the patient has symptom control
17. Select if the patient has medication management
18. Select if the patient has emotional support
19. Select if the patient has spiritual support
20. Select if the patient has social support
21. Select if the patient has a care plan in place
22. Select if the patient's pain has been assessed
23. Select if the patient's fatigue has been assessed
24. Select if the patient's breath has been assessed
25. Select if the patient's symptoms have been assessed

## Field-by-Field Explanation

- **First Name** (`first_name`, text, optional): Enter your first name.
- **Last Name** (`last_name`, text, optional): Enter your last name.
- **Date of Birth** (`date_of_birth`, date, required): Enter your date of birth in the correct format (MM/DD/YYYY).
- **Contact Number** (`contact_number`, text, required): Enter your contact number for communication and follow-up.
- **Email** (`email`, email, required): Enter your email address for communication and follow-up.
- **Preferred Language** (`preferred_language`, select_one, required): Select your preferred language for communication.
- **Medical Team** (`medical_team`, select_multiple, optional): Select the medical team(s) involved in the patient's care.
- **Patient Need** (`patient_need`, select_one, required): Select the patient's primary needs (e.g. pain, fatigue, etc.).
- **Other (Please Specify)** (`patient_need_other`, text, optional): If "Other" is selected, please provide more information about the patient's needs.
- **Family Support** (`family_support`, select_multiple, optional): Select if the patient has family support.
- **Spiritual Needs** (`spiritual_needs`, select_multiple, optional): Select if the patient has spiritual needs.
- **Advance Care Planning** (`advance_care_planning`, select_multiple, required): Select if the patient has advance care planning.
- **Pain Control** (`pain_control`, select_multiple, optional): Select if the patient has pain control.
- **Fatigue Control** (`fatigue_control`, select_multiple, optional): Select if the patient has fatigue control.
- **Breath Control** (`breath_control`, select_multiple, optional): Select if the patient has breath control.
- **Symptom Control** (`symptom_control`, select_multiple, optional): Select if the patient has symptom control.
- **Medication Management** (`medication_management`, select_multiple, optional): Select if the patient has medication management.
- **Emotional Support** (`emotional_support`, select_multiple, optional): Select if the patient has emotional support.
- **Spiritual Support** (`spiritual_support`, select_multiple, optional): Select if the patient has spiritual support.
- **Social Support** (`social_support`, select_multiple, optional): Select if the patient has social support.
- **Patient Care Plan** (`patient_care_plan`, select_multiple, required): Select if the patient has a care plan in place.
- **Pain Assessment** (`pain_assessment`, select_multiple, required): Select if the patient's pain has been assessed.
- **Fatigue Assessment** (`fatigue_assessment`, select_multiple, required): Select if the patient's fatigue has been assessed.
- **Breath Assessment** (`breath_assessment`, select_multiple, required): Select if the patient's breath has been assessed.
- **Symptom Assessment** (`symptom_assessment`, select_multiple, required): Select if the patient's symptoms have been assessed.

## Tips
* Please complete this form carefully and accurately, as the information gathered will be used to inform the patient's care plan.
* Ensure you have the necessary clearance and permissions to access the patient's information.
* If you are unsure about any of the questions, please consult with the patient's healthcare team or seek guidance from a medical professional.
