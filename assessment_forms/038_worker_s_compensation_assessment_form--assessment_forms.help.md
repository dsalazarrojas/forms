# Workers Compensation Assessment Form - Help Guide
## Purpose
This form is used to collect information about a workplace injury, including details of the incident, employee and claimant information, and medical information. It will be used by HR or insurance companies to assess the severity and impact of the injury.

## How To Complete This Form
To complete this form, follow these steps:

* Review the form carefully to ensure you have filled it out completely and accurately.
* Fill out each field in the form, providing as much detail as possible.
* If you are unsure about any field, refer to the field-by-field explanation below.

## Field-by-Field Explanation
### 1. **Injury Details**
* **Injury Details** (`injury_details`, `text`, required: false): This field is used to describe the details of the injury, including the type of injury, its severity, and any other relevant information.

### 2. **Employee Info**
* **Employee Info** (`employee_info`, `number`, required: false): This field should include the employee's ID number or other relevant information to identify them.

### 3. **Claimant Info**
* **Claimant Info** (`claimant_info`, `select_one`, required: false): This field should be selected to specify the claimant (e.g. "Claimant 1").

### 4. **Claim Details**
* **Claim Details** (`claim_details`, `date`, required: false): This field should be filled out with the date the claim was filed.

### 5. **Incident Date**
* **Incident Date** (`incident_date`, `date`, required: false): This field should be filled out with the date of the incident.

### 6. **Workplace Info**
* **Workplace Info** (`workplace_info`, `select_multiple`, required: false): This field should be selected to specify the workplace where the incident occurred (e.g. "Workplace 1").

### 7. **Injury Type**
* **Injury Type** (`injury_type`, `select_one`, required: false): This field should be selected to specify the type of injury (e.g. "Injury 1").

### 8. **Claim Status**
* **Claim Status** (`claim_status`, `select_one`, required: false): This field should be selected to specify the status of the claim (e.g. "Status 1").

### 9. **Employee Contact**
* **Employee Contact** (`employee_contact`, `text`, required: false): This field should be filled out with the employee's contact information.

### 10. **Claimant Contact**
* **Claimant Contact** (`claimant_contact`, `text`, required: false): This field should be filled out with the claimant's contact information.

### 11. **Witness Info**
* **Witness Info** (`witness_info`, `select_multiple`, required: false): This field should be selected to specify any witnesses to the incident (e.g. "Witness 1").

### 12. **Incident Location**
* **Incident Location** (`incident_location`, `select_multiple`, required: false): This field should be selected to specify the location of the incident (e.g. "Location 1").

### 13. **Incident Description**
* **Incident Description** (`incident_description`, `note`, required: false): This field should be filled out with a detailed description of the incident.

### 14. **Medical Info**
* **Medical Info** (`medical_info`, `select_multiple`, required: false): This field should be selected to specify any medical information related to the claim.

### 15. **Work Status**
* **Work Status** (`work_status`, `select_one`, required: false): This field should be selected to specify the employee's work status (e.g. "Status 1").

### 16. **Claimant Work Status**
* **Claimant Work Status** (`claimant_work_status`, `select_one`, required: false): This field should be selected to specify the claimant's work status (e.g. "Status 1").

### 17. **Medical Report**
* **Medical Report** (`medical_report`, `select_multiple`, required: false): This field should be selected to specify any medical reports related to the claim.

### 18. **Claimant Medical Status**
* **Claimant Medical Status** (`claimant_medical_status`, `select_multiple`, required: false): This field should be selected to specify the claimant's medical status (e.g. "Status 1").

### 19. **Claimant Injury Info**
* **Claimant Injury Info** (`claimant_injury_info`, `select_multiple`, required: false): This field should be selected to specify any information about the claimant's injury.

### 20. **Claimant Return to Work**
* **Claimant Return to Work** (`claimant_return_to_work`, `select_one`, required: false): This field should be selected to specify the claimant's return to work status (e.g. "Status 1").

### 21. **Claimant Medical Info**
* **Claimant Medical Info** (`claimant_medical_info`, `select_multiple`, required: false): This field should be selected to specify any medical information about the claimant.

### 22. **Supervisor Info**
* **Supervisor Info** (`supervisor_info`, `select_multiple`, required: false): This field should be selected to specify the supervisor's information (e.g. "Info 1").

### 23. **Claimant Supervisor Info**
* **Claimant Supervisor Info** (`claimant_supervisor_info`, `select_multiple`, required: false): This field should be selected to specify the claimant's supervisor information (e.g. "Info 1").

### 24. **Claimant Work Hours**
* **Claimant Work Hours** (`claimant_work_hours`, `number`, required: false): This field should be filled out with the number of hours worked.

### 25. **Claimant Work Location**
* **Claimant Work Location** (`claimant_work_location`, `select_multiple`, required: false): This field should be selected to specify the claimant's work location (e.g. "Location 1").

## Tips
* Be sure to review the form carefully before submitting it to ensure you have filled out all required fields.
* If you are unsure about any field, refer to the field-by-field explanation above.
