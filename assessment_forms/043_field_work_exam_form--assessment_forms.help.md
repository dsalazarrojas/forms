# Field Work Exam Form - Help Guide
## Purpose
The Field Work Exam Form is designed to collect relevant data for a field work exam assessment, ensuring students and examiners have a seamless and efficient experience.

## How To Complete This Form
To complete this form, follow these steps:

1. Review the form carefully and make sure you have all the necessary information before starting.
2. Select the appropriate page by choosing from the options on the first page (currently "field_work_exam_form_page_1").
3. Complete the fields on each page, starting with "Field Work Exam Form Page 1" and "Field Work Exam Form Page 2".
4. Enter your information in the designated fields.

## Field-by-Field Explanation

* **Field Work Exam Form Page 1** (`field_work_exam_form_page_1`, text, optional): This is the first page of the form, and it appears to be used as a title page for the form.
* **student_name** (`student_name_label`, text, optional): This field is for the student's name. Please enter the student's full name, first name and last name, in the format you would expect in your records.
* **student_id** (`student_id_label`, number, optional): This field is for the student's ID number. Enter the student's ID as a numeric value.
* **Field Work Exam Form Page 2** (`field_work_exam_form_page_2`, text, optional): This is the second page of the form, and it appears to be used as a continuation page for the form.

## Tips
* Please ensure all required fields are filled before submitting the form.
* If you need any help or have questions, refer to the provided instructions or contact your administrator.
