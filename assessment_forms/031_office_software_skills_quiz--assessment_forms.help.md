# Office Software Skills Quiz - Help Guide

## Purpose
This form is used to assess the suitability of office software for different purposes, such as skills assessment, hiring, and training.

## How To Complete This Form
To complete this form, please follow these steps:

1. Select the category of the office software you are evaluating. This will help determine the purpose of the form.
2. Enter a brief description of the office software.
3. Answer the questions regarding the software's capabilities:
	* Supports consistent skills assessment
	* Collects quiz responses online
	* Easy review and comparison across candidates or employees
4. Indicate whether the software supports hiring and training.

## Field-by-Field Explanation

### Category
* **Category** (`Assessment Forms`, `Quizzes`, required):
	* This field determines the type of form you are creating. Please select the option that best describes your form's purpose.

### Description
* **Description** (`Description`, `text`, required):
	* Please enter a brief description of the office software you are evaluating. This will help us understand the software's purpose and functionality.

### Description Form (Note)
* **Description Form** (`Description Form`, `note`, optional):
	* This field is for additional information or notes about the office software. It is not required, but can be used to provide context or clarification.

### Supports consistent skills assessment
* **Supports consistent skills assessment** (`True`, `False`, required):
	* Please answer "True" if the office software supports consistent skills assessment, or "False" otherwise.

### Collects quiz responses online
* **Collects quiz responses online** (`True`, `False`, required):
	* Please answer "True" if the office software can collect quiz responses online, or "False" otherwise.

### Easy review and comparison
* **Easy review and comparison** (`across candidates`, `across employees`, `both`, required):
	* Select the option that best describes how the office software handles review and comparison:
		+ `across candidates`: The software can review and compare responses across different candidates.
		+ `across employees`: The software can review and compare responses across different employees.
		+ `both`: The software can review and compare responses across both candidates and employees.

### Supports hiring and training
* **Supports hiring and training** (`hiring`, `training`, required):
	* Please select whether the office software supports hiring or training, or both.
