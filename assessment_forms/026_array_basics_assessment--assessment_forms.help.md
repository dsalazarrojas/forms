# Array Basics Assessment - Help Guide
## Purpose

This form is a self-assessment tool designed to evaluate your understanding of basic array concepts. It covers topics such as array definition, indexing, operations, and advanced concepts. Completing this form will help you identify areas where you need improvement and provide a foundation for further learning.

## How To Complete This Form

1. Read each question carefully and select the answer that best represents your understanding.
2. For open-ended questions, provide a clear and concise answer.
3. For multiple-choice questions, select all that apply.
4. For select-one questions, choose the best answer.
5. For questions that require code, provide a valid code snippet.

## Field-by-Field Explanation

* **Full Name** (`student_name`, `text`, required): Enter your full name.
* **Student ID** (`student_id`, `text`, optional): Enter your student ID (if applicable).
* **Class or Course Name** (`class_name`, `text`, required): Enter the name of the class or course you are taking.
* **Assessment Date** (`assessment_date`, `date`, required): Enter the date of the assessment (mm/dd/yyyy).
* **What is an array in programming** (`question_1`, `select_one`, required): An array is a collection of elements stored in contiguous memory.
* **What is the index of the first element in most programming languages** (`question_2`, `select_one`, required): The index is usually '0' (zero).
* **How do you access the third element of an array named myArray** (`question_3`, `select_one`, required): myArray[3] or myArray.third().
* **Which of the following are common array operations** (`question_4`, `select_multiple`, required): Inserting elements, removing elements, sorting elements, searching for elements.
* **What does the push() method do in JavaScript arrays** (`question_5`, `select_one`, required): Adds an element to the end of the array.
* **Explain how to find the length of an array** (`question_6`, `text`, required): Use the built-in length or size method.
* **What is a multidimensional array** (`question_7`, `select_one`, required): An array that contains other arrays.
* **What is the time complexity of accessing an array element by index** (`question_8`, `select_one`, required): O(1) constant time.
* **Write a simple code snippet to create an array and add three elements** (`question_10`, `text`, required): Example: myArray = [1, 2, 3]; myArray.push(4);
* **How confident are you in your understanding of array basics** (`question_11`, `select_one`, required): Very confident, confident, somewhat confident, not confident, very unsure.
* **What are your strengths in understanding arrays** (`question_23`, `text`, optional): Enter your strengths.
* **Areas you would like to improve** (`question_24`, `text`, optional): Enter areas you would like to improve.

**Tips**

* Take your time to carefully read each question before answering.
* If you're unsure of an answer, try to recall relevant information from your studies or research.
* Be honest about your level of confidence in each question.
* Use clear and concise answers for open-ended questions.
* Select all applicable answers for multiple-choice questions.
* Code snippets should be valid and executable.
