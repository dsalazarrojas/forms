# Entrepreneurship Exam Answer Sheet - Help Guide
## Purpose

This form is designed to collect information from students taking an entrepreneurship exam. The purpose of this form is to gather data on student performance, preferences, and experiences related to entrepreneurship.

## How To Complete This Form

1. Fill in the student's name in the "Student Name" field.
2. Enter the student's ID number in the "Student ID" field.
3. Answer each question according to the options provided.
4. For questions with "select_multiple" type, select all relevant options that apply.
5. For questions with "select_one" type, select only one option that best answers the question.
6. For questions with "date" type, enter the date in YYYY-MM-DD format.
7. For questions with "time" type, enter the time in 24-hour format (HH:MM).
8. Leave optional fields (student email and question 7) blank if not applicable.
