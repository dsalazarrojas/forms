# Inversion Skills Assessment - Help Guide
## Purpose
The Inversion Skills Assessment form is designed to evaluate an athlete's skills in various areas. It allows coaches and assessors to document their observations and feedback on an athlete's performance, progress, and overall assessment outcome. This form is typically used to assess an athlete's skills in a specific sport or activity.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the athlete's name in the field labeled "Athlete Name".
2. Enter the coach's name in the field labeled "Coach Name".
3. Select the date of the assessment by clicking on the calendar icon next to "Assessment Date".
4. For each skill being evaluated, select "Yes" or "No" in the "Skill to Evaluate" field. This field is not required.
5. For "Athlete Progress", "Skill Level", "Assessment Outcome", and "Assessment Status", select one of the available options (e.g. "Yes", "No", "High", etc.).
6. Enter any additional comments about the athlete's performance in the "Comments" field.
7. Enter any recommendations for the athlete in the "Recommendations" field.
8. Enter the coach's recommendations for the athlete in the "Coach Recommendations" field.
9. Enter any notes or observations about the assessment in the "Assessment Notes" field.
10. Select "Yes" or "No" for "Image Captures", indicating whether or not photos or images were taken during the assessment.
11. Finally, review and confirm the assessment outcome in the "Assessment Status" field.

## Field-by-Field Explanation

* **Athlete Name** (`athlete_name`, text, required): Enter the name of the athlete being assessed.
* **Coach Name** (`coach_name`, text, required): Enter the name of the coach conducting the assessment.
* **Assessment Date** (`assessment_date`, date, required): Select the date of the assessment.
* **Skill to Evaluate** (`skill_to_evaluate`, select_multiple, optional): Select "Yes" or "No" for each skill being evaluated. For example, if evaluating swimming, you might select "Yes" for "Swimming" and "No" for "Tennis".
* **Comments** (`comments`, text, optional): Enter any comments or observations about the athlete's performance.
* **Athlete Progress** (`athlete_progress`, select_one, optional): Select the progress of the athlete, e.g. "Yes", "No".
* **Skill Level** (`skill_level`, select_one, optional): Select the level of the athlete's skill, e.g. "High", "Low".
* **Assessment Outcome** (`assessment_outcome`, select_one, optional): Select the outcome of the assessment, e.g. "Yes", "No".
* **Recommendations** (`recommendations`, text, optional): Enter any recommendations for the athlete's improvement.
* **Coach Recommendations** (`coach_recommendations`, text, optional): Enter the coach's recommendations for the athlete's improvement.
* **Assessment Notes** (`assessment_notes`, text, optional): Enter any notes or observations about the assessment.
* **Video Recording** (`video_recording`, note, optional): This field is for recording video observations. Please enter a note describing the video.
* **Image Captures** (`image_captures`, select_multiple, optional): Select "Yes" or "No" for whether photos or images were taken during the assessment.
* **Assessment Status** (`assessment_status`, select_one, optional): Select the status of the assessment, e.g. "Active", "Inactive".
