# Transformation Readiness Assessment Request Form - Help Guide

## Purpose
This form is designed to assess the transformation readiness of an organization.

## How To Complete This Form
1. Fill out the form with your organization's information.
2. Select the assessor's role and objective.
3. Choose the current initiative and project status.
4. Provide the assessment start and end dates.
5. Select the duration of the assessment.
6. Specify the organization type.

## Field-by-Field Explanation
* **Organization** (`organization_name`, text, optional): Enter your organization's name.
* **Assessor** (`assessor`, text, optional): Enter your name or the name of the person responsible for the assessment.
* **Assessor Role** (`assessor_role`, select_one, optional): Select the role of the assessor, e.g., Transformation Consultant, Business Analyst, Project Manager, or IT Specialist.
* **Objective** (`objective`, text, optional): State your objective for the assessment.
* **Initiative Status** (`initiative_status`, select_one, optional): Select the status of the initiative, e.g., Active, Planned, Delayed, or Suspended.
* **Project Status** (`project_status`, select_one, optional): Select the status of the project, e.g., In Progress, Completed, Delayed, or Suspended.
* **Assessment Start Date** (`assess_start_date`, date, optional): Enter the start date of the assessment.
* **Assessment End Date** (`assess_end_date`, date, optional): Enter the end date of the assessment.
* **Assessment Duration** (`assess_duration`, text, optional): Describe the duration of the assessment.
* **Organization Type** (`organization_type`, select_one, optional): Select the type of your organization, e.g., Private or Public.

## Tips
* Make sure to fill out all required fields, if any.
* If you are unsure about a field, you can always ask the assessor or the relevant department for guidance.
* This form is for internal use only, and the information you provide will be used for assessment purposes only.
