# Furniture Production Assessment - Help Guide
## Purpose
This form is designed to collect information on furniture production projects.

## How To Complete This Form
To complete this form, simply follow these steps:
1. Go to the "Project Details" page (Page 1) and fill in the project name, brief description, and any other relevant details.
2. Move on to the "Project Manager" page (Page 2) and enter the project manager's name and contact information.
3. On the final page, "Production Date" (Page 3), select the production start and end dates for the project.

## Field-by-Field Explanation
### Project Details (Page 1)
* **Project Name** (`project_details`, text, required): Enter the name of the furniture production project.
* **Project Description** (`project_details`, text, optional): Provide a brief description of the project.

### Project Manager (Page 2)
* **Project Manager** (`project_manager`, text, required): Enter the name of the project manager responsible for the project.
* **Contact Information** (`project_manager`, text, optional): Add any contact information for the project manager.

### Production Date (Page 3)
* **Production Start Date** (`production_date`, date, required): Select the start date of the production project.
* **Production End Date** (`production_date`, date, required): Select the end date of the production project.

* Ensure all fields are filled out accurately to ensure correct project tracking.
