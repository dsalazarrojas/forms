# Document Compatibility Assessment - Help Guide
## Purpose
This form, called the "Document Compatibility Assessment," is a tool designed to help teams collect structured data on document issues across platforms using a no-code form builder, drag-and-drop interface, and organized form submission tracking.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the title of the document you are assessing (Field 1: form_title).
2. Check if the document is compatible (Field 2: category).
3. Provide a brief description of the document (Field 3: description).
4. Check if each of the issues listed (Fields 4-10: issue 1-5, issue 2-6) apply to your document.

## Field-by-Field Explanation

* **Field 1: form_title** (`text`, required): Enter the title of the document you are assessing.
* **Field 2: category** (`select_one`, optional): Check if the document is compatible.
* **Field 3: description** (`text`, optional): Enter a brief description of the document.
* **Field 4: issue 1** (`select_one`, optional): Check if issue 1 applies to your document.
* **Field 5: issue 2** (`select_one`, optional): Check if issue 2 applies to your document.
* **Field 6: issue 3** (`select_one`, optional): Check if issue 3 applies to your document.
* **Field 7: issue 4** (`select_one`, optional): Check if issue 4 applies to your document.
* **Field 8: issue 5** (`select_one`, optional): Check if issue 5 applies to your document.
* **Field 9: issue 6** (`select_one`, optional): Check if issue 6 applies to your document.

## Tips

* Be as specific as possible when completing the "form_title" field.
* Use a brief but clear description in the "description" field.
* Review each issue carefully and select the one that best applies to your document.
