# matching_skills_assessment - Help Guide
## Purpose
The matching skills assessment form is designed to help users match their skills with roles. This form is intended to be completed by users who want to identify their skills and match them with relevant roles.

## How To Complete This Form
To complete this form, follow these steps:

1. Read the introduction section, which provides background information about the form and its purpose.
2. In the Skills Assessment section, select all the skills that apply to you. This section is not required, so you can choose not to fill it out if you don't have any skills to match.
3. In the Match Roles section, select the roles that you are matched with based on your skills. Again, this section is not required.
4. If you have any additional information that you want to provide, you can do so in the Additional Information section. This section is also not required.

## Field-by-Field Explanation
* **Introduction** (Introduction, note, required: false): This is a brief background section that explains the purpose and instructions for the form. Please read it before proceeding.
* **Skills Assessment** (Skills Assessment, select_multiple, required: false): Select all the skills that apply to you. This will help match your skills with relevant roles.
* **Match Roles** (Match Roles, select_multiple, required: false): Select the roles that you are matched with based on your skills. Choose as many or as few roles as you think are relevant.
* **Additional Information** (Additional Information, note, required: false): If you have any additional information that you want to provide, you can enter it here.
