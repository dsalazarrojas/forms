# Functional Ability Assessment Questionnaire - Help Guide

## Purpose
The Functional Ability Assessment Questionnaire is designed to assess the functional abilities of a patient. This form is used by healthcare professionals to gather information about a patient's functional status, care plans, and other relevant details. 

## How To Complete This Form
To complete this form, please follow these steps:

1.  Review the form carefully to ensure you have all the necessary information.
2.  Fill in the fields as instructed, and make sure to select the correct options for each field.
3.  Provide clear and concise notes for each field where required.
4.  Submit the form once you have completed all the necessary fields.

## Field-by-Field Explanation

* **Patient Info (1)**: This is the section for entering the patient's basic information, including their name, date of birth, and address.
* **Prophets (2)**: Please select 'Yes' if the patient has prophets, 'No' otherwise.
* **Prophets Note (3)**: Provide a brief note about the patient's prophets, if any.
* **Patient Status (4)**: Choose 'Active' if the patient is currently active, 'Inactive' otherwise.
* **Daily Living (5)**: Select 'Yes' if the patient has daily living skills, 'No' otherwise.
* **Daily Living Note (6)**: Provide a brief note about the patient's daily living skills, if any.
* **Patient Name (7)**: This is the section for entering the patient's name.
* **Patient DOB (8)**: Enter the patient's date of birth.
* **Patient Phone (9)**: Enter the patient's phone number.
* **Patient Address (10)**: Enter the patient's address.
* **Patient Email (11)**: Enter the patient's email address.
* **Assessment Date (12)**: Enter the date of the assessment.
* **Assessment Time (13)**: Enter the time of the assessment.
* **Patient Status Note (14)**: Provide a brief note about the patient's status.
* **Care Team Members (15)**: Select 'Yes' if the patient has a care team, 'No' otherwise.
* **Team Members Note (16)**: Provide a brief note about the care team, if any.
* **Patient Care Plans (17)**: Describe the current care plan for the patient.
* **Patient Care Plans Note (18)**: Provide a brief note about the care plans.
* **Patient Outcome (19)**: Choose 'Yes' if the patient's outcome is favorable, 'No' otherwise.
* **Patient Outcome Note (20)**: Provide a brief note about the patient's outcome.
* **Submit (21)**: Once you have completed the form, press this button to submit the assessment.

Note: Ensure to review and submit the form carefully to avoid missing any important information.
