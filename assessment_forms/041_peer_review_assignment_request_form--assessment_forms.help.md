# Peer Review Assignment Request Form - Help Guide
## Purpose
This form is used by peers to request a review of a specific request. It's meant for submitting new review requests, and not for submitting repeated or duplicate requests.

## How To Complete This Form
- Fill out the form completely and accurately with the information required.
- Select the correct "Request" from the dropdown menu on the "Submit Request" page.
- Fill in the "Evaluation Criteria" text field with specific and relevant criteria that will be used for the review.
- Select all applicable "Evaluation Scale" options from the list on the "Evaluation Scale" page.
- Enter the "Review Deadline" and "Submit Deadline" dates, if applicable.
- Enter your "Email" and "Phone" contact information.
- Add any relevant "Note" to the "Note" field.
- Finally, select the "Submit" or "Cancel" option on the "Submit" page.

## Field-by-Field Explanation
* **Submit Request**: Select the specific request you would like to be reviewed.
	+ This field is a dropdown menu with three options (Request 1, Request 2, Request 3).
* **Evaluation Criteria**: Enter specific and relevant criteria that will be used for the review.
	+ This field is a text field for entering free-formatted text.
* **Evaluation Scale**: Select all applicable scales that will be used for the review.
	+ This field is a select multiple dropdown menu with three options (Scale 1, Scale 2, Scale 3).
* **Review Deadline**: Enter the deadline for the review, if applicable.
	+ This field is a date field where you can enter a specific date in YYYY-MM-DD format.
* **Submit Deadline**: Enter the deadline for submitting the review, if applicable.
	+ This field is a date field where you can enter a specific date in YYYY-MM-DD format.
* **Email**: Enter your email contact information.
	+ This field is an email field for entering your email address.
* **Phone**: Enter your phone contact information.
	+ This field is a text field for entering your phone number.
* **Note**: Add any additional note or comment related to the review.
	+ This field is a free-form text field for entering any additional information.
* **Submit**: Select this option to submit the form and complete the review request.
	+ This field is a select one dropdown menu with two options (Submit, Cancel).
