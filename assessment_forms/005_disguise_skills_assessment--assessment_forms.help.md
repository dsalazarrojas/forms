# Disguise Skills Assessment - Help Guide
## Purpose
The Disguise Skills Assessment form is designed to collect information about participants' skills and performance in an event or training setting.

## How To Complete This Form
1. Fill out the **Participant Name** field with the name of the participant being assessed.
2. Enter the name of the **Event Name** field with the name of the event or training session.
3. Provide the location of the event in the **Event Location** field.
4. Select multiple skills from the **Skills List** that the participant has demonstrated or is proficient in.
5. Provide a **Self Evaluation** of the participant's performance or skills level (e.g., "1" for low, "2" for medium, "3" for high, "4" for very high, "5" for excellent).
6. Choose a **Self Evaluation Scale** rating from the provided options (e.g., "1" for low, "2" for medium, "3" for high, "4" for very high, "5" for excellent).
7. Enter any additional **Notes** about the participant's performance or skills.
8. If applicable, provide the participant's **Email** and **Phone Number** for follow-up contact.
9. Enter the **Trainer Name**, if applicable.
10. Provide a **Participant Rating** (e.g., number value).
11. Write a brief **Participant Comment** about the participant's performance or skills.
12. Upload a **Participant Photo**, if applicable.

## Field-by-Field Explanation

* **Participant Name** (required: false): Enter the name of the participant being assessed.
* **Event Name** (required: false): Enter the name of the event or training session.
* **Event Location** (required: false): Provide the location of the event.
* **Skills List** (required: false): Select multiple skills from the list that the participant has demonstrated or is proficient in.
* **Self Evaluation** (required: false): Provide a self-assessment of the participant's performance or skills level.
* **Self Evaluation Scale** (required: false): Choose a self-evaluation scale rating from the provided options.
* **Notes** (required: false): Enter any additional comments or notes about the participant's performance or skills.
* **Participant Email** (required: false): If applicable, provide the participant's email address for follow-up contact.
* **Participant Phone** (required: false): If applicable, enter the participant's phone number for follow-up contact.
* **Trainer Name** (required: false): Enter the name of the trainer or facilitator, if applicable.
* **Participant Rating** (required: false): Provide a numerical value to assess the participant's performance or skills.
* **Participant Comment** (required: false): Write a brief comment about the participant's performance or skills.
* **Participant Photo** (required: false): If applicable, upload a photo of the participant.
