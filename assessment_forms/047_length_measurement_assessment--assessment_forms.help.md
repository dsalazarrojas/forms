# Length Measurement Assessment - Help Guide
## Purpose
The Length Measurement Assessment form is used to collect information about the length measurement process, including the method used, location, and any errors or observations that occurred during the measurement. This form helps ensure that length measurements are accurate and consistent.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the method used to take the measurement (e.g., Calipers, Micrometer, Vernier Calipers).
2. Choose the location where the measurement was taken (e.g., Top, Bottom, Left, Right, Left edge, Right edge).
3. Enter the unit of measurement used (e.g., mm, cm, m, inches, feet, yards).
4. Select the system of measurement used (e.g., SI, Imperial).
5. Enter any additional observations or comments about the measurement process.

## Field-by-Field Explanation

* **Measurement Method** (measurement_method, text, not required): Enter the method used to take the measurement (e.g., Calipers, Micrometer, Vernier Calipers).
* **Measurement Location** (measurement_location, text, not required): Enter the location where the measurement was taken (e.g., Top, Bottom, Left, Right, Left edge, Right edge).
* **Unit Used** (unit_used, select_one, not required): Select the unit of measurement used (e.g., mm, cm, m, inches, feet, yards).
* **Measurement Result** (measurement_result, number, not required): Enter the measurement result (e.g., 10.5 cm).
* **Observation** (observation, text, not required): Enter any additional observations or comments about the measurement process.
* **Method Justification** (method_justification, text, not required): Enter any justification or explanation for the measurement method used.
* **Measurement Device Used** (measurement_device_used, select_one, not required): Select the device used to take the measurement (e.g., Calipers, Micrometer, Vernier Calipers).
* **Measurement Error Type** (measurement_error_type, select_one, not required): Select the type of error that occurred during the measurement (e.g., None, Error).
* **Measurement Error Value** (measurement_error_value, number, not required): Enter the value of the error that occurred during the measurement.
* **Measurement Rounding Value** (measurement_rounded_value, number, not required): Enter the rounded measurement result.
* **Measurement Rounding Error** (measurement_rounded_error, number, not required): Enter the error that occurred during the rounding process.
* **Observation Justification** (observation_justification, text, not required): Enter any additional justifications or explanations for the observations made.
* **Additional Observation** (additional_observation, text, not required): Enter any additional observations or comments about the measurement process.
* **Measurement System** (measurement_system, select_one, not required): Select the system of measurement used (e.g., SI, Imperial).
* **Reference Point** (reference_point, select_one, not required): Select the reference point used for the measurement (e.g., Top, Bottom, Left, Right, Left edge, Right edge).
* **Measurement Location 1-5** (measurement_location_1-5, select_one, not required): Select the location(s) where the measurement was taken (e.g., Top, Bottom, Left, Right, Left edge, Right edge).

Note: Fields marked "not required" are optional and can be completed if needed.
