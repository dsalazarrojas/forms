# it_infrastructure_evaluation_form - Help Guide
## Purpose
The "it_infrastructure_evaluation_form" is designed to collect information about the current state of the organization's infrastructure.

## How To Complete This Form
To complete this form, follow these steps:

1. Review the form carefully and fill in the required fields as accurately as possible.
2. Answer each field based on your knowledge of the current infrastructure.
3. Submit the form once you have completed all the required fields.

## Field-by-Field Explanation

* **Introduction** (1, Note, Optional):
	+ This field is a note field where you can provide a brief introduction to your assessment.
* **Team Size** (2, Number, Optional):
	+ Enter the number of members in your team.
* **Team Distribution** (3, Select One, Optional):
	+ Check 'Yes' if your team is distributed across multiple locations.
* **Team Location** (4, Select Multiple, Optional):
	+ Select all locations where your team is based.
* **Infrastructure Type** (5, Select One, Optional):
	+ Choose the type of infrastructure you are assessing.
* **Infrastructure Status** (6, Select Multiple, Optional):
	+ Select all relevant statuses of your infrastructure.
* **Technology Stack** (7, Text, Optional):
	+ Enter your current technology stack.
* **Security Standards** (8, Select Multiple, Optional):
	+ Select all relevant security standards applied to your infrastructure.
* **Backup Strategy** (9, Select One, Optional):
	+ Choose your current backup strategy.
* **Disaster Recovery** (10, Select Multiple, Optional):
	+ Select all relevant disaster recovery measures.
* **Infrastructure Change** (11, Select One, Optional):
	+ Check if there have been any infrastructure changes recently.
* **Infrastructure Cost** (12, Number, Optional):
	+ Enter the current infrastructure cost.
* **Comments** (13, Note, Optional):
	+ Provide any additional comments about your infrastructure.
* **Submission** (14, Date, Optional):
	+ Enter the date of submission.
* **Evaluation Date** (15, Date, Optional):
	+ Enter the date of evaluation.
* **Assigned To** (16, Select One, Optional):
	+ Check if this form is assigned to someone else.
* **Assigned By** (17, Select One, Optional):
	+ Check if this form is assigned by someone else.
* **Submitted By** (18, Select One, Optional):
	+ Check if this form is submitted by someone else.
* **Evaluation Status** (19, Select One, Optional):
	+ Choose the current evaluation status.
* **Evaluation Comments** (20, Note, Optional):
	+ Provide any comments about your evaluation.
* **Evaluation Date** (21, Date, Optional):
	+ Enter the date of the last evaluation.
* **Next Evaluation** (22, Date, Optional):
	+ Enter the date of the next evaluation.
* **Last Evaluation** (23, Date, Optional):
	+ Enter the date of the last evaluation.
* **Evaluation Frequency** (24, Select One, Optional):
	+ Choose the evaluation frequency.
