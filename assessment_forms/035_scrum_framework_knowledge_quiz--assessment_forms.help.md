# Scrum Framework Knowledge Quiz - Help Guide
## Purpose

This help guide is designed to guide you through the Scrum Framework Knowledge Quiz, which assesses your knowledge of the Scrum framework, its principles, and its roles. The quiz aims to evaluate your understanding of key concepts, principles, and values in the Scrum framework.

## How To Complete This Form

1. Please complete each page of the form, and proceed to the next page after submitting the previous one.
2. For questions and select one/multiple fields, select the correct options from the provided list. For text fields, enter your response in the field.
3. Make sure to submit your response at the end of the quiz.
4. Review the submission page to ensure your responses are accurate before finalizing the submission.

* **Introduction (Page 1)**: This page is an overview of the Scrum Framework Knowledge Quiz.
* **Questions (Page 2)**: This page asks you to select the correct options for the following roles: Agile Team, Scrum Master, and Product Owner. Please choose the correct role(s) that you are familiar with.
	+ Agile Team: Select this option if you have experience working in an Agile team.
	+ Scrum Master: Select this option if you have experience or knowledge as a Scrum Master.
	+ Product Owner: Select this option if you have experience or knowledge as a Product Owner.
* **Scrum Values (Page 3)**: This page presents a list of Scrum values. Please select one value that you are familiar with.
	+ C: Select this option if you are familiar with the value of the letter C.
	+ D: Select this option if you are familiar with the value of the letter D.
	+ E: Select this option if you are familiar with the value of the letter E.
* **Scrum Principles (Page 4)**: This page requires a text response. Please enter the correct principle or principles of the Scrum framework.
* **Team Roles (Page 5)**: This page asks you to select multiple roles that you are familiar with from the following options: Team Member, Scrum Master, and Product Owner. Please choose all roles that you are familiar with.
	+ Team Member: Select this option if you are part of a team that practices Scrum.
	+ Scrum Master: Select this option if you have experience or knowledge as a Scrum Master.
	+ Product Owner: Select this option if you have experience or knowledge as a Product Owner.
* **Scrum Roles (Page 6)**: This page asks you to select one role that you are familiar with from the following options: Development Team, Scrum Master, and Product Owner.
* **Scrum Certifications (Page 7)**: This page requires a text response. Please enter the correct Scrum certification(s) you have or are familiar with.
* **Submission (Page 8)**: This page is the final submission page, where you can review your responses before submitting the quiz.
