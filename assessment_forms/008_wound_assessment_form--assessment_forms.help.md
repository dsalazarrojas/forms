# Wound Assessment Form - Help Guide
## Purpose
The purpose of this form is to collect information about a patient's wound assessment.

## How To Complete This Form
1. Select the patient's name from the dropdown menu or enter their name manually.
2. Enter the patient's medical record number.
3. Enter the patient's date of birth.
4. Enter the assessment date.
5. Select the location where the wound is located.
6. Choose the wound size.
7. For optional fields:
   - Base Defect: describe any base defect present.
   - Wound Color: select one or more of the available colors.
   - Bleeding or Serous: select one of the three options.
   - Edema: select one of the three options.
   - Redness: enter a numerical value.
   - Swelling: enter a numerical value.
   - Discharge: describe any discharge present.
   - Odor: select one of the three options.
   - Pain: select one of the three options.
   - Bleeding: select one of the three options.
   - Serous: select one of the three options.
   - Necrotic: select one of the three options.
   - Sinus Tissue Loss: select one of the three options.
   - Granulation: select one of the three options.
   - Wound Area Diameter: enter a numerical value.
   - Wound Length: enter a numerical value.
   - Note: enter any additional information about the wound.

## Field-by-Field Explanation

* **Patient Name** (text, required): The patient's name.
* **Medical Record Number** (text, required): The patient's medical record number.
* **Date of Birth** (date, required): The patient's date of birth.
* **Assessment Date** (date, required): The date the wound was assessed.
* **Location** (text, required): The location where the wound is located.
* **Wound Size** (select_one, optional): The size of the wound. Choose from 0-1 cm, 1-2 cm, 2-3 cm, 3-4 cm, 4-5 cm, or 5+ cm.
* **Base Defect** (text, optional): If there is a base defect present, describe it in this field.
* **Wound Color** (select_multiple, optional): Select one or more of the available colors (Red, Purple, Pink, Black, Blue).
* **Bleeding or Serous** (select_one, optional): Select one of the three options (Bleeding, Serous, None).
* **Edema** (select_one, optional): Select one of the three options (Present, Absent, Questionable).
* **Redness** (number, optional): Enter a numerical value to describe the redness of the wound.
* **Swelling** (number, optional): Enter a numerical value to describe the swelling of the wound.
* **Discharge** (text, optional): If there is discharge present, describe it in this field.
* **Odor** (select_one, optional): Select one of the three options (Present, Absent, Questionable).
* **Pain** (select_one, optional): Select one of the three options (Present, Absent, Questionable).
* **Bleeding** (select_one, optional): Select one of the three options (Present, Absent, Questionable).
* **Serous** (select_one, optional): Select one of the three options (Present, Absent, Questionable).
* **Necrotic** (select_one, optional): Select one of the three options (Present, Absent, Questionable).
* **Sinus Tissue Loss** (select_one, optional): Select one of the three options (Present, Absent, Questionable).
* **Granulation** (select_one, optional): Select one of the three options (Present, Absent, Questionable).
* **Wound Area Diameter** (number, optional): Enter a numerical value to describe the wound's area diameter.
* **Wound Length** (number, optional): Enter a numerical value to describe the wound's length.
* **Note** (note, optional): Enter any additional information about the wound.
