# Manual Control Assessment Form - Help Guide
## Purpose
The purpose of this form is to collect information about the status and frequency of manual controls within an organization, enabling a thorough assessment of their effectiveness and risks.

## How To Complete This Form
1. Review the control in question and gather the necessary information before proceeding.
2. For each field, ensure you enter the most accurate and up-to-date information.
3. Mark each field as "Not Applicable" if it is not relevant to the control in question.

## Field-by-Field Explanation

* **Department Name** (`department_name`, text, optional): Enter the name of the department owning the control.
* **Control Description** (`control_description`, text, optional): Briefly describe the control.
* **Control Frequency** (`control_frequency`, select_one, optional): Select how frequently the control is performed or reviewed. (Daily, Weekly, Monthly, Quarterly, Annually)
* **Control Status** (`control_status`, select_multiple, optional): Select the current status of the control. (Active, Inactive, Pending)
* **Control Owner** (`control_owner`, text, optional): Enter the name of the person responsible for the control.
* **Control Responsible Officer** (`control_responsible_officer`, text, optional): Enter the name of the officer responsible for the control.
* **Control Effectiveness** (`control_effectiveness`, select_one, optional): Select the effectiveness of the control. (Effective, Ineffective, Pending)
* **Control Risk Level** (`control_risk_level`, select_one, optional): Select the risk level associated with the control. (High, Medium, Low)
* **Control Comments** (`control_comments`, text, optional): Enter any additional comments about the control.
* **Form Completion** (`form_completion`, select_one, optional): Select the completion status of the form. (Completed, Partially Completed, Not Completed)
* **Assessment Frequency** (`assessment_frequency`, select_one, optional): Select how frequently the assessment is performed or reviewed. (Daily, Weekly, Monthly, Quarterly, Annually)
* **Assessment Status** (`assessment_status`, select_one, optional): Select the current status of the assessment. (Completed, Partially Completed, Not Completed)
* **Next Assessment Due Date** (`next_assessment_due_date`, date, optional): Enter the next due date for the assessment.
* **Next Assessment Frequency** (`next_assessment_frequency`, select_one, optional): Select how frequently the next assessment is scheduled. (Daily, Weekly, Monthly, Quarterly, Annually)
* **Follow-up Issues** (`follow_up_issues`, text, optional): Enter any follow-up issues identified during the assessment.
* **Follow-up Actions** (`follow_up_actions`, text, optional): Enter any follow-up actions taken during the assessment.
* **Follow-up Status** (`follow_up_status`, select_one, optional): Select the current status of follow-up actions. (Completed, In Progress, Not Completed)
* **Next Follow-up Frequency** (`next_follow_up_frequency`, select_one, optional): Select how frequently the next follow-up is scheduled. (Daily, Weekly, Monthly, Quarterly, Annually)
* **Next Follow-up Date** (`next_follow_up_date`, date, optional): Enter the next follow-up date.
* **Next Follow-up Time** (`next_follow_up_time`, time, optional): Enter the next follow-up time.
* **Last Follow-up** (`last_follow_up`, time, optional): Enter the last follow-up time.
* **Next Follow-up Location** (`next_follow_up_location`, text, optional): Enter the location of the next follow-up.
* **Follow-up Comments** (`follow_up_comments`, text, optional): Enter any follow-up comments.
* **Next Follow-up Status** (`next_follow_up_status`, select_one, optional): Select the current status of follow-up actions. (Completed, In Progress, Not Completed)
* **Review Frequency** (`review_frequency`, select_one, optional): Select how frequently reviews are performed. (Daily, Weekly, Monthly, Quarterly, Annually)

## Tips

* If you are unsure about any field, please reach out to your team or supervisor for guidance.
* Please ensure the form is completed accurately and thoroughly.
* This form is intended to be used as a guide, not a substitute for regular reviews and assessments conducted by authorized personnel.
* Please save the form after completion to facilitate future reference and tracking.
