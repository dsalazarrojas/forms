# estimation_techniques_quiz - Help Guide
## Purpose
This form is designed to collect information about a project's estimation techniques and methods used by a team.

## How To Complete This Form

To complete this form, follow these steps:

1. Select the estimation method and technique used for your project.
2. Enter the project's details, such as first and last name, project manager, name, difficulty level, and project description.
3. Provide actual and estimated hours spent on the project.
4. Enter the project's status, submission date and time, start and end dates, and times.
5. Confirm the project manager's involvement in the submission process.
6. Select the team's size and experience level.
7. Enter any submission notes or comments.

## Field-by-Field Explanation

* **Estimation Method** (`estimation_techniques_quiz`, select_multiple, required): Select one or more of the following estimation methods: The Three-Point Estimation, Top-Down Estimation, Three-Point Estimation, Bottom-Up Estimation, Expert Judgment.
* **First Name** (`first_name`, text, required): Enter your first name.
* **Last Name** (`last_name`, text, required): Enter your last name.
* **Project Manager** (`project_manager`, text, required): Enter the project manager's name.
* **Project Name** (`project_name`, text, required): Enter the project's name.
* **Difficulty Level** (`difficulty_level`, select_one, required): Select the project's difficulty level: Beginner, Intermediate, Advanced.
* **Estimation Hours** (`estimation_hours`, number, required): Enter the actual hours spent on the project.
* **Actual Hours** (`actual_hours`, number, required): Enter the actual hours spent on the project.
* **Estimated Hours** (`estimated_hours`, number, required): Enter the estimated hours spent on the project.
* **Project Description** (`project_description`, text, optional): Enter a brief description of the project.
* **Manager Comment** (`project_manager_comment`, text, optional): Enter any comment from the project manager.
* **Project Status** (`project_status`, select_one, required): Select the project's status: Completed, In Progress.
* **Submission Date** (`submission_date`, date, required): Enter the date of submission.
* **Submission Time** (`submission_time`, time, required): Enter the time of submission.
* **Project Start Date** (`project_start_date`, date, required): Enter the project's start date.
* **Project End Date** (`project_end_date`, date, required): Enter the project's end date.
* **Project Start Time** (`project_start_time`, time, required): Enter the project's start time.
* **Project End Time** (`project_end_time`, time, required): Enter the project's end time.
* **Estimation Technique Used** (`estimation_technique`, select_one, required): Select the estimation technique used: The Three-Point Estimation, Top-Down Estimation, Three-Point Estimation, Bottom-Up Estimation.
* **Estimation Method** (`estimation_method`, select_multiple, required): Select one or more of the following estimation methods: Expert Judgment, The Three-Point Estimation, Bottom-Up Estimation, Top-Down Estimation.
* **Team Size** (`team_size`, select_one, required): Select the team size: Small, Medium, Large.
* **Team Experience** (`team_experience`, select_one, required): Select the team's experience level: Beginner, Intermediate, Advanced.
* **Manager Confirmation** (`manager_confirmation`, select_one, required): Confirm if the project manager is involved in the submission process: Yes, No.
* **Submission Notes** (`submission_notes`, text, optional): Enter any submission notes or comments.
* **Submission User** (`submission_user`, text, optional): Enter your name as the submission user.
