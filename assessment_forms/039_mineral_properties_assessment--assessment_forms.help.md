# Mineral Properties Assessment - Help Guide
## Purpose
This form is designed to collect information about a sample's properties, including its composition, physical characteristics, and collection details. The purpose of this form is to gather data for the assessment of mineral properties.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the required fields, marked with an asterisk (*). These fields are:
	* sample_id
	* sampling_technique
2. Fill in any additional information that is not marked with an asterisk but is relevant to the sample. These fields are:
	* sample_description (optional)
	* sample_image (optional)
	* sample_characteristics (optional)
	* sample_weight (optional)
	* date_collected (optional)
	* date_reported (optional)
3. Select from the options provided for the following fields:
	* mineral_type
	* sample_location
	* sample_color
	* sample_shape
	* sample_texture

## Field-by-Field Explanation
### sample_id
* **sample_id** (text, *): Enter the unique identifier for the sample.

### sampling_technique
* **sampling_technique** (text, *): Describe the sampling method used to collect the sample.

### sample_description (optional)
* **sample_description** (text, optional): Provide a brief description of the sample.

### sample_image (optional)
* **sample_image** (text, optional): Attach an image of the sample.

### sample_characteristics (optional)
* **sample_characteristics** (text, optional): Describe any notable characteristics of the sample.

### sample_weight (optional)
* **sample_weight** (number, optional): Enter the weight of the sample in grams.

### mineral_type
* **mineral_type** (select_one, *): Select the type of mineral from the options provided:
	+ halite
	+ gypsum
	+ halloysite
	+ illite
	+ saponite
	+ kaolinite
	+ montmorillonite
	+ gillespite
	+ larderite
	+ muscovite
	+ annite
	+ tugtupite
	+ aluminite
	+ nchilite
	+ staurolite
	+ garnet

### sample_location (optional)
* **sample_location** (select_multiple, *): Select all relevant locations from the options provided:
	+ location 1
	+ location 2
	+ location 3

### sample_description2 (optional)
* **sample_description2** (text, optional): Provide additional information about the sample.

### sample_color (optional)
* **sample_color** (select_multiple, *): Select all relevant colors from the options provided:
	+ color 1
	+ color 2

### sample_shape (optional)
* **sample_shape** (select_multiple, *): Select all relevant shapes from the options provided:
	+ shape 1
	+ shape 2
	+ shape 3

### sample_texture (optional)
* **sample_texture** (select_multiple, *): Select all relevant textures from the options provided:
	+ texture 1
	+ texture 2
	+ texture 3
	+ texture 4

### sample_hardness (optional)
* **sample_hardness** (number, optional): Enter the hardness of the sample on the Mohs scale.

### sample_streak (optional)
* **sample_streak** (text, optional): Describe the sample's streak.

### date_collected (optional)
* **date_collected** (date, optional): Enter the date the sample was collected.

### date_reported (optional)
* **date_reported** (date, optional): Enter the date the sample was reported.

### sample_characteristics (optional)
* **sample_characteristics** (text, optional): Describe any additional characteristics of the sample.

# Tips
* Make sure to provide accurate and detailed information about the sample.
* Use clear and concise language when describing the sample's properties.
* If you're unsure about any of the fields, please consult with a mineral expert.
* Double-check your input before submitting the form to ensure accuracy.
