## Symbolic Sequence Analysis Quiz - Help Guide

### Purpose
The Symbolic Sequence Analysis Quiz is a form designed to collect information about a participant's sequence of symbols in a specific pattern. This quiz aims to assess a participant's ability to recognize and identify symbolic sequences.

### How To Complete This Form
To complete this form, follow these steps:

1. Start by selecting the **Sequence Length** field, where you will be asked to input the number of symbols that make up the sequence.
2. Then, select the **Participant Details** field, where you will be asked to confirm or deny the participant's involvement in the sequence.
3. Next, input the **Quiz Question**, which is a free-text field where you can describe the sequence.
4. Choose the **Quiz Question Type** from the drop-down menu, which defines the type of question asked.
5. Select the **Participant Sequence** field, where you will be asked to input the actual sequence of symbols.
6. Choose the **Participant Response** field, where you will be asked to confirm or deny the participant's response to the question.
7. Optionally, you can add **Notes**, which is a free-text field for additional comments or explanations.
8. If you have an **Email** and **Phone** number, you can input them for contact purposes.
9. Finally, select the **Submitted On** and **Submitted By** fields, which are automatically generated and displayed for reference.

### Field-by-Field Explanation

* **Sequence Length**: The number of symbols that make up the sequence.
* **Participant Details**: Confirm or deny the participant's involvement in the sequence.
	+ Options: Yes/No
* **Quiz Question**: A free-text field to describe the sequence.
* **Quiz Question Type**: The type of question being asked.
	+ Options: Yes/No
* **Participant Sequence**: The actual sequence of symbols.
* **Participant Response**: Confirm or deny the participant's response to the question.
	+ Options: Yes/No
* **Notes**: A free-text field for additional comments or explanations.
* **Email**: The participant's email address.
* **Phone**: The participant's phone number.
* **Submitted On**: The date and time the form was submitted.
* **Submitted By**: The user who submitted the form.
* **Quiz ID**: A unique identifier for the quiz.
* **Participant ID**: A unique identifier for the participant.
* **Pattern Type**: The type of pattern used in the sequence.
	+ Options: Yes/No
* **Pattern Name**: The name of the pattern.
* **Pattern ID**: A unique identifier for the pattern.
* **Pattern Sequence**: The actual sequence of the pattern.
* **Pattern Answer**: The answer to the pattern.
* **Pattern Sequence Type**: The type of pattern sequence.
	+ Options: Yes/No
* **Sequence ID**: A unique identifier for the sequence.
* **Participant Sequence ID**: A unique identifier for the participant's sequence.
* **Pattern Answer Type**: The type of answer given to the pattern.
* **Participant Response ID**: A unique identifier for the participant's response.
* **Quiz Type**: The type of quiz.
	+ Options: Yes/No

Note: The fields marked as required/optional are denoted by "true/false" respectively.
