# Wheelchair Usage Assessment Checklist - Help Guide
## Purpose
The Wheelchair Usage Assessment Checklist is a form designed to gather information about a patient's wheelchair usage, including their mobility level, user capacities, equipment needs, and safety concerns. This form helps healthcare providers understand the patient's needs and develop an effective follow-up plan.
## How To Complete This Form
To complete this form, follow these steps:

1. Select the patient's mobility level from the provided options.
2. List the patient's user capacities and equipment needs.
3. Indicate the patient's safety concerns and other relevant details.
4. Provide any additional comments or recommendations from the healthcare provider.

## Field-by-Field Explanation

* **1. Patient Details** (`patient_details`, text, optional)
	+ This field is for entering any additional information about the patient.
* **2. Mobility Level** (`mobility_level`, select_one, optional)
	+ Select the patient's mobility level from the options provided (Wheelchair User, Non-Wheelchair User).
* **3. Wheelchair Usage** (`wheelchair_usage`, text, optional)
	+ Describe the patient's wheelchair usage habits.
* **4. User Capacities** (`user_capacities`, select_multiple, optional)
	+ Select the patient's user capacities (Wheelchair User, Independent, Needs Assistance, Has Difficulty, Has Limitations, Has a Medical Condition).
* **5. Support Needs** (`support_needs`, select_multiple, optional)
	+ Indicate the patient's support needs (Needs Assistance, Has Difficulty, No Support Needed).
* **6. Equipment Needs** (`equipment_needs`, select_multiple, optional)
	+ Select the equipment the patient needs (Manual Wheelchair, Power Wheelchair, Tilt Wheelchair, Other).
* **7. Safety Concerns** (`safety_concerns`, select_multiple, optional)
	+ Indicate the patient's safety concerns (True, False).
* **8. Other Notes** (`other_notes`, note, optional)
	+ Provide any additional comments or notes about the patient.
* **9. Patient Goals** (`patient_goals`, text, optional)
	+ Describe the patient's goals.
* **10. Patient Comments** (`patient_comments`, text, optional)
	+ Record any comments from the patient.
* **11. Health Care Provider Comments** (`healthcare_provider_comments`, text, optional)
	+ Record any comments from the healthcare provider.
* **12. Health Care Provider Recommendations** (`healthcare_provider_recommendations`, text, optional)
	+ Record any recommendations from the healthcare provider.
* **13. Follow-Up Plan** (`follow_up_plan`, text, optional)
	+ Describe the follow-up plan for the patient.
* **14. Follow-Up Date** (`follow_up_date`, date, optional)
	+ Enter the follow-up date.
* **15. Follow-Up Time** (`follow_up_time`, time, optional)
	+ Enter the follow-up time.
* **16. Follow-Up Duration** (`follow_up_duration`, number, optional)
	+ Enter the follow-up duration.
* **17. Follow-Up Frequency** (`follow_up_frequency`, select_multiple, optional)
	+ Select the follow-up frequency (Daily, Weekly, Monthly, As Needed).
* **18. Follow-Up Notes** (`follow_up_notes`, note, optional)
	+ Provide any follow-up notes.
* **19. Follow-Up Contact** (`follow_up_contact`, text, optional)
	+ Record the follow-up contact information.
* **20. Patient Informed** (`patient_informed`, text, optional)
	+ Confirm the patient's understanding of the follow-up plan.
* **21. Informed By** (`informed_by`, select_one, optional)
	+ Indicate who informed the patient about the follow-up plan (Nurse, Doctor, Physical Therapist, Occupational Therapist).
* **22. Follow-Up Method** (`follow_up_method`, select_multiple, optional)
	+ Select the follow-up method (Phone Call, Email, In-Person, Video Call, Message).
* **23. Follow-Up Location** (`follow_up_location`, select_multiple, optional)
	+ Select the follow-up location (Clinic/Office, Home, In-Person, Other).
* **24. Patient Status** (`patient_status`, select_one, optional)
	+ Indicate the patient's status (Active/Engaged, Lost to Follow-Up, Unable to Follow-Up, Discharged/No Longer Needing Service).
* **25. Assigned Provider** (`assigned_provider`, select_one, optional)
	+ Select the assigned provider (Primary Care Provider, Specialist, Therapist, Other).

## Tips
- Make sure to fill out all required fields.
- Use the options provided in the select_one and select_multiple fields.
- Enter the follow-up date and time in the format specified.
- Double-check the patient's status to ensure it reflects their current situation.
