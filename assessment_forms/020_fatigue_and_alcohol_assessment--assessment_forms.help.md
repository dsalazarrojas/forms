# Fatigue And Alcohol Assessment - Help Guide
## Purpose
The Fatigue And Alcohol Assessment form is used to gather information on an employee's fatigue and potential exposure to alcohol, ensuring a safe and healthy work environment.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill in the required fields with accurate information, if any field is not relevant, feel free to skip it.
2. Review each field carefully to ensure you have provided accurate and detailed information.
3. If you need help with any field, refer to the Field-by-Field Explanation below.

## Field-by-Field Explanation

* **Employee Name** (`name`, text, optional): Enter the name of the employee being assessed.
* **Department** (`department`, select_one, optional): Select 'Yes' if the employee's department is relevant to this assessment.
* **Job Title** (`job_title`, text, optional): Enter the employee's job title.
* **Shift Start Time** (`shift_start`, date, optional): Enter the start time of the employee's shift, if applicable.
* **Shift End Time** (`shift_end`, date, optional): Enter the end time of the employee's shift, if applicable.
* **Alcohol Consumed** (`alcohol_consumed`, select_one, optional): Select 'Yes' if the employee consumed alcohol before or after the shift.
* **Fatigue Level** (`fatigue_level`, select_multiple, optional): Select all that apply from the following options: High, Low.
* **Medication Taken** (`medication`, select_multiple, optional): Select all that apply from the following options: Yes, No.
* **Symptoms Reported** (`symptoms`, select_multiple, optional): Select all that apply from the following options: Yes, No.
* **Action Plan** (`action_plan`, note, optional): Enter any action plan or recommendations made as a result of this assessment.
* **Reviewer** (`reviewer`, text, optional): Enter the name of the reviewer.
* **Reviewer Notes** (`reviewer_notes`, note, optional): Enter any notes made by the reviewer.
* **Review Date** (`review_date`, date, optional): Enter the date of the review.
* **Review Time** (`review_time`, time, optional): Enter the time of the review.
* **Submitted On** (`submitted_on`, date, optional): Enter the date this form was submitted.

## Tips

* Please be accurate and thorough in filling out this form, as it is used to identify potential issues and develop solutions.
* If you have any questions or concerns, please reach out to your supervisor or HR representative.
