# Virtual Assessment Guide Request Form - Help Guide
## Purpose
The Virtual Assessment Guide Request Form is used to request a virtual assessment, which is a guided process to help users complete a virtual assessment.

## How To Complete This Form
To complete this form, please follow these steps:

1.  Enter the requested information in the fields provided.
2.  Ensure you have filled out all required fields.
3.  If you are unsure about any field, refer to the field-by-field explanation below.

## Field-by-Field Explanation
* **Virtual Assessment Guide Request** (`virtual_assessment_guide_request_form`): Enter a brief description of the virtual assessment you need help with.
* **Virtual Assessment Requestor** (`virtual_assessment_requestor`): Enter the name and contact information of the person requesting the virtual assessment.
* **Virtual Assessment Request Type** (`virtual_assessment_request_type`): Select the type of virtual assessment you need help with (Virtual or Non-Virtual).
* **Consultant Virtual Assessment** (`consultant_virtual_assessment`): Enter the name of the consultant conducting the virtual assessment.
* **Educational Institution** (`educational_institution`): If the virtual assessment is for an educational institution, enter its name.
* **Internal Virtual Assessment** (`internal_virtual_assess`): This is for internal assessments; this form is not to be used. Please use the internal assessment form instead.
* **Virtual Assessment Resource** (`virtual_assessment_resource`): Select the type of resource required (Online Resource or Offline Resource).
* **Resource Location** (`resource_location`): Enter the location of the resource (e.g., online, offline, etc.).
* **Resource Type** (`resource_type`): Enter the type of resource required.
* **Resource Description** (`resource_description`): Enter a brief description of the resource.
* **Resource URL** (`resource_url`): Enter the URL of the resource.
* **Email** (`email`): Enter the email of the person requesting the virtual assessment.
* **Phone** (`phone`): Enter the phone number of the person requesting the virtual assessment.
* **Notes** (`notes`): Enter any additional notes or comments about the virtual assessment.
* **Date** (`date`): Enter the date of the virtual assessment.
* **Time** (`time`): Enter the time of the virtual assessment.
* **Qualification** (`qualification`): Select whether the virtual assessment is required for qualification (True or False).
* **Internal** (`internal`): Select whether the virtual assessment is internal (True or False).
* **Consultant Name** (`consultant_name`): Enter the name of the consultant conducting the virtual assessment.
* **Team** (`team`): Enter the name of the team requesting the virtual assessment.
* **Team Size** (`team_size`): Enter the size of the team requesting the virtual assessment.
* **Resource Availability** (`resource_availability`): Enter the availability of the resource.
* **Follow-up** (`follow_up`): Select whether a follow-up is required (True or False).
* **Next Step** (`next_step`): Enter the next step in the process.
* **Additional Info** (`additional_info`): Enter any additional information about the virtual assessment.
