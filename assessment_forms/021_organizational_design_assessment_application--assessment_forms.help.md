# Organizational Design Assessment Application - Help Guide
## Purpose
The Organizational Design Assessment Application is designed to gather essential information about an organization's design, helping to identify strengths, weaknesses, opportunities, and challenges. This form is meant to provide a comprehensive understanding of the organization's context, goals, and challenges.

## How To Complete This Form
1. Review the form pages carefully and ensure you have all the necessary information.
2. For each field, provide the requested information, taking care to fill in the fields that are marked as required.
3. Use the field labels as your guide for what information is needed for each field.
4. If a field has a specific format or options, ensure you follow that format.

## Field-by-Field Explanation
* **Main Information**: Provide a brief overview of the main information related to the organization.
* **Main Challenges**: Identify and list the main challenges the organization faces.
* **Main Goals**: Indicate if the main goal is 'Yes' or 'No' for the main challenges identified.
* **Main Context**: Enter the main context of the organization, describing its nature and environment.
* **Context Description**: Add a detailed description of the context, including its characteristics.
* **Context Status**: Select if the context is currently 'Active' or 'Inactive'.
* **Context Status Reason**: Provide a reason for the context status, if applicable.
* **Context Status History**: List the history of the context status, including any significant changes.
* **Context Status Last Update**: Enter the date of the last update to the context status.
* **Consultant Name**: Enter the name of the consultant or person responsible for the assessment.
* **Consultant Email**: Enter the email of the consultant or person responsible for the assessment.
* **Consultant Phone**: Enter the phone number of the consultant or person responsible for the assessment.
* **Main Organization**: Enter the name of the main organization.
* **Main Organization Description**: Provide a detailed description of the main organization, including its nature and activities.
* **Main Organization Type**: Check 'Yes' or 'No' for the main organization type.
* **Main Organizational Chart**: Add any relevant information about the main organizational chart, if applicable.

Note: Ensure you have completed all required fields accurately, as they are marked in the form.
