This form is used to assess a schema, which is a set of rules and definitions that determine the structure and format of data. The purpose of this form is to collect information about a schema, including its name, type, description, version, data source, and other relevant details. This information is crucial for schema owners to track and manage their schemas effectively.

The form consists of multiple pages with various fields to input different types of information.

### schema_assessment_questionnaire - Help Guide

#### Purpose

The form is used to gather information about a schema, which will be used for assessment and management purposes.

#### How To Complete This Form

1.  To start, select a schema name from the first page.
2.  On the second page, select the schema type.
3.  On the following pages, input the schema description, version, data source, and other relevant information.
4.  For fields like data frequency, quality, and status, select the appropriate options from the dropdown menu.
5.  If you want to add any comments or recommendations, you can do so on the designated fields.
6.  On the last pages, input the last reviewed and next reviewed dates and times, and select the last and next reviewed by names.

#### Field-by-Field Explanation

* **Schema Name** (1, text, required): Enter a unique and descriptive name for the schema.
* **Schema Type** (2, select_one, required): Select whether the schema is 'Yes' or 'No'.
* **Schema Description** (3, text, required): Provide a detailed description of the schema.
* **Schema Version** (4, text, required): Enter the version number of the schema.
* **Data Source** (5, text, required): Specify the source of the data.
* **Data Frequency** (6, select_one, required): Select whether data is 'Yes' or 'No'.
* **Data Quality** (7, select_multiple, required): Choose one or multiple options for data quality: 'Good', 'Poor'.
* **Schema Owner** (8, select_multiple, required): Select one or multiple options for schema owner: 'Yes', 'No'.
* **Schema Status** (9, select_multiple, required): Choose one or multiple options for schema status: 'Active', 'Inactive'.
* **Schema Category** (10, select_multiple, required): Select one or multiple options for schema category: 'Yes', 'No'.
* **Schema Priority** (11, select_one, required): Select whether the schema is 'Yes' or 'No'.
* **Schema Comments** (12, text, optional): Enter any comments or feedback about the schema.
* **Schema Recommendations** (13, text, optional): Provide any recommendations for the schema.
* **Schema Reviewers** (14, text, optional): List the names of reviewers for the schema.
* **Schema Review Comments** (15, text, optional): Enter any review comments about the schema.
* **Schema Last Reviewed** (16, date, optional): Input the date of the last review.
* **Schema Last Reviewed By** (17, text, optional): Select the name of the last reviewer.
* **Schema Last Reviewed At** (18, time, optional): Input the time of the last review.
* **Schema Last Reviewed Time** (19, time, optional): Input the time of the last review.
* **Schema Last Reviewed Date** (20, date, optional): Input the date of the last review.
* **Schema Last Reviewed By Name** (21, text, optional): Select the name of the last reviewer.
* **Schema Next Reviewed Date** (22, date, optional): Input the date of the next review.
* **Schema Next Reviewed By** (23, text, optional): Select the name of the next reviewer.
* **Schema Next Reviewed At** (24, time, optional): Input the time of the next review.
* **Schema Next Reviewed Time** (25, time, optional): Input the time of the next review.

This form is designed to help schema owners to assess and manage their schemas effectively. Please fill in the form accurately and provide as much detail as possible. If you have any questions or need help, feel free to ask.
