# Retail Compliance Assessment Form - Help Guide

## Purpose
This form is used to collect information about store managers for compliance and audit purposes. The form will guide you through the required and optional fields to ensure accurate and complete data submission.

## How To Complete This Form
1. Review each field carefully before proceeding.
2. Enter all required information in the corresponding fields.
3. Select only relevant options for select_multiple fields.
4. Submit the form once you have completed all fields.

## Field-by-Field Explanation

* **Store Location** (`store_location`, `text`, required: false): Enter the name of the store location.
* **Date of Visit** (`date_of_visit`, `date`, required: false): Enter the date of your visit to the store.
* **Store Manager Name** (`store_manager_name`, `text`, required: false): Enter the store manager's name.
* **Store Manager Title** (`store_manager_title`, `text`, required: false): Enter the store manager's title.
* **Store Manager Photo** (`store_manager_photo`, `text`, required: false): Enter the store manager's photo (if applicable).
* **Store Location Address** (`store_location_address`, `text`, required: false): Enter the store location's address.
* **Date of Audit** (`date_of_audit`, `date`, required: false): Enter the date of the audit.
* **Store Hours** (`store_hours`, `text`, required: false): Enter the store's operating hours.
* **Store Manager Contact Number** (`store_manager_contact_number`, `text`, required: false): Enter the store manager's contact number.
* **Store Manager Email** (`store_manager_email`, `email`, required: false): Enter the store manager's email address.
* **Photos** (`photos`, `text`, required: false): Enter any relevant photos (if applicable).
* **Comments** (`comments`, `note`, required: false): Enter any additional comments or notes.
* **Store Manager Vehicles** (`store_manager_vehicles`, `select_multiple`, required: false): Select all applicable vehicles used by the store manager (e.g., Van, Car, Truck, Motorcycle, Other, etc.).
* **Store Manager License Plate** (`store_manager_license_plate`, `text`, required: false): Enter the store manager's license plate number (if applicable).
* **Store Manager Work Phone** (`store_manager_work_phone`, `text`, required: false): Enter the store manager's work phone number.
* **Store Manager Cell Phone** (`store_manager_cell_phone`, `text`, required: false): Enter the store manager's cell phone number.
* **Store Manager Alternate Phone** (`store_manager_alternate_phone`, `text`, required: false): Enter the store manager's alternate phone number.
* **Store Manager Work Email** (`store_manager_work_email`, `email`, required: false): Enter the store manager's work email address.
* **Store Manager Work Address** (`store_manager_work_address`, `text`, required: false): Enter the store manager's work address.
* **Store Manager Work City** (`store_manager_work_city`, `text`, required: false): Enter the store manager's work city.
* **Store Manager Work State** (`store_manager_work_state`, `text`, required: false): Enter the store manager's work state.
* **Store Manager Work Zip** (`store_manager_work_zip`, `text`, required: false): Enter the store manager's work zip code.
* **Store Manager Work Country** (`store_manager_work_country`, `text`, required: false): Enter the store manager's work country.
* **Store Manager Work Phone Number** (`store_manager_work_phone_number`, `text`, required: false): Enter the store manager's work phone number.
* **Store Manager Vehicles** (`store_manager_vehicles`, `select_multiple`, required: false): Select all applicable vehicles used by the store manager (e.g., Van, Car, Truck, Motorcycle, Other, etc.).
