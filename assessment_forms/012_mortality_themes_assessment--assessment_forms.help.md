# Mortality Themes Assessment - Help Guide
## Purpose
The Mortality Themes Assessment Form is designed to collect participant perspectives on mortality topics. It is used to gather information about the most relevant mortality themes in a specific context or industry. The form helps to identify the key themes related to mortality and provides a structured way to collect and analyze participant responses.

## How To Complete This Form

1.  To start, select the correct response for each field. Make sure to read the explanations for each field carefully before providing your answer.
2.  For the `mortality_topics` field, select all the mortality themes that are relevant to your context or industry.
3.  Indicate whether data collection is organized or not.
4.  If you would like to receive summaries of the collected data by email, select the corresponding option.
5.  Finally, complete the form by providing your answers and submit it.
