# Depositary Obligations Assessment - Help Guide
## Purpose
The "Depositary Obligations Assessment" form is used to gather information about depositary obligations, which are financial assessments or evaluations. This form helps financial institutions or regulators monitor or assess the financial stability of a depositary.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill out the required fields, marked with an asterisk (\*).
2. For each field, refer to the explanations below for guidance.

## Field-by-Field Explanation

* **Depositary Obligations Assessment (1)**: This is the main title of the form. It's a required field and should be filled out as is.
* **Depositary Obligations Description (2)**: This field is not required but is a good place to provide any additional information about the depositary obligations. You can enter a brief description of the assessment or evaluation.
* **Date of Last Assessment (3)**: This field is used to record the date of the last assessment or evaluation. Enter the date in the format MM/DD/YYYY.
* **Frequency of Assessments (4)**: This field is not required but allows you to specify how often assessments or evaluations are performed. Enter the number of times assessments are performed per year or other frequency.
* **Type of Assessment (5)**:
	+ **Financial Institution**: Select this option if the depositary obligations pertain to a financial institution.
	+ **Central Bank**: Select this option if the depositary obligations pertain to a central bank.
	+ **Other**: Select this option if the depositary obligations don't fit into the above categories.
* **Frequency of Assessments (Frequency) (6)**:
	+ **Monthly**: Select this option if assessments or evaluations are performed every month.
	+ **Quarterly**: Select this option if assessments or evaluations are performed every quarter.
	+ **Annually**: Select this option if assessments or evaluations are performed once a year.
* **Notes (7)**: This field is not required but is a good place to provide any additional information or comments about the depositary obligations. You can enter any notes or comments you'd like.
* **Phone (8)**: This field is not required but is a good place to provide a contact phone number.
* **Email (9)**: This field is not required but is a good place to provide a contact email address.
* **Other Contact Info (10)**: This field is not required but is a good place to provide any other contact information.
