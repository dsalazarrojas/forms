# Engine Performance Assessment - Help Guide
## Purpose
This form is used to assess the performance of an engine in a vehicle. It is designed to gather information about the engine's condition, maintenance requirements, and other related factors.

## How To Complete This Form
1.  Start by filling out the check date, which is the date on which the engine check was performed.
2.  Answer the question about the engine type, selecting 'Yes' if the engine is functioning properly and 'No' otherwise.
3.  Answer the question about engine performance, selecting all the characteristics that apply.
4.  Answer the question about maintenance type, selecting 'Yes' if maintenance is required and 'No' otherwise.
5.  Answer the question about maintenance frequency, selecting all the frequencies that apply.
6.  Check the current fuel level and enter the value in the corresponding field.
7.  Check the current oil level and enter the value in the corresponding field.
8.  Check the current coolant level and enter the value in the corresponding field.
9.  Answer the question about transmission type, selecting 'Yes' if the transmission is functioning properly and 'No' otherwise.
10. Answer the question about transmission condition, selecting all the conditions that apply.
11. Answer the question about engine condition, selecting all the conditions that apply.
12. Answer the question about vehicle condition, selecting all the conditions that apply.
13. Check the fuel efficiency and enter the value in the corresponding field.
14. Answer the question about engine failure, selecting 'Yes' if the engine has failed and 'No' otherwise.
15. Answer the question about fuel type, selecting 'Yes' if the fuel type is correct and 'No' otherwise.
16. Answer the question about vehicle type, selecting 'Yes' if the vehicle type is correct and 'No' otherwise.
17. Enter the vehicle's mileage and year in the corresponding fields.
18. Repeat steps 1-17 for the second check.
