# Employee Language Assessment Form - Help Guide
## Purpose
The Employee Language Assessment Form is used to assess the language proficiency, abilities, and communication skills of employees.

## How To Complete This Form
- Carefully review the form and ensure that you have all the necessary information to complete it accurately.
- Answer the questions based on your personal knowledge of the employee's language skills.
- If you are unsure about any of the questions, please consult with the employee or their manager before submitting the form.

## Field-by-Field Explanation
* **Language Proficiency (1)**: This field is used to rate the employee's language proficiency. Please select a number to indicate their level of proficiency.
* **Language Abilities (2)**: This field is used to select the languages spoken by the employee. Please choose 'Yes' or 'No' for each language.
* **Communication Skills (3)**: This field is used to rate the employee's communication skills. Please select 'Yes' or 'No' for each skill.
* **Dialects Spoken (4)**: This field is used to select the dialects spoken by the employee. Please choose 'Yes' or 'No' for each dialect.
* **Native Language (5)**: This field is used to select the employee's native language. Please choose 'Yes' or 'No'.
* **Language Level (6)**: This field is used to rate the employee's language level. Please select 'High' or 'Low'.
* **Comments (7)**: This field is used to provide any additional comments about the employee's language skills.
* **Native Language Spoken (8)**: This field is used to select whether the employee speaks their native language. Please choose 'Yes' or 'No'.

## Tips
- If you are unsure about any of the questions, please consult with the employee or their manager before submitting the form.
- Please ensure that you are completing the form for the correct employee and that the answers are based on your personal knowledge of the employee's language skills.
