# IT System Performance Assessment Form - Help Guide

## Purpose

The IT System Performance Assessment Form is used to collect information about the performance of IT systems.

## How To Complete This Form

1. Ensure this form is not a duplicate before submitting it.
2. Fill out all required fields accurately.
3. Enter the name and type of the IT system being assessed.
4. Fill out fields for various performance metrics, such as availability, uptime, response time, reliability, and scalability.
5. Enter any additional comments or notes about the IT system.
6. Enter the email and phone number of the person submitting this form.
7. Enter any relevant system ID or identifiers.
8. Fill out the performance score and overall satisfaction with the IT system.

## Field-by-Field Explanation

* **System Name** (`it_system_name`, text, required): Enter the name of the IT system being assessed.
* **System Type** (`system_type`, select_one, required): Select the type of IT system, such as server, cloud, or network.
* **Availability** (`availability`, number, required): Enter the availability percentage of the IT system, on a scale of 1-100.
* **Uptime** (`uptime`, time, required): Enter the time the IT system was up and running.
* **Response Time** (`response_time`, number, required): Enter the time it takes for the IT system to respond.
* **Reliability** (`reliability`, select_multiple, required): Rate the reliability of the IT system, such as high, medium, or low.
* **Scalability** (`scalability`, text, optional): Enter any comments about the scalability of the IT system.
* **Maintainability** (`maintainability`, text, optional): Enter any comments about the maintainability of the IT system.
* **Cost** (`cost`, number, optional): Enter any cost-related information about the IT system.
* **Support** (`support`, text, optional): Enter any support-related information about the IT system.
* **Location** (`location`, text, optional): Enter the location of the IT system.
* **Description** (`description`, text, optional): Enter a brief description of the IT system.
* **Notes** (`notes`, note, optional): Enter any additional comments or notes about the IT system.
* **Email** (`email`, email, optional): Enter the email address of the person submitting this form.
* **Phone** (`phone`, text, optional): Enter the phone number of the person submitting this form.
* **System ID** (`system_id`, text, optional): Enter the system ID or identifier.
* **System Type ID** (`system_type_id`, text, optional): Enter any system type ID or identifier.
* **Performance Score** (`performance_score`, number, optional): Enter the performance score of the IT system.
* **Overall Satisfaction** (`overall_satisfaction`, select_one, optional): Rate the overall satisfaction with the IT system, such as high, medium, or low.
* **System Category** (`system_category`, select_one, optional): Select the category of the IT system, such as server, cloud, or network.
* **System Tags** (`system_tags`, text, optional): Enter any tags or keywords associated with the IT system.
* **System Comments** (`system_comments`, note, optional): Enter any additional comments about the IT system.
* **Submitted By** (`submitted_by`, text, optional): Enter your name or username.
