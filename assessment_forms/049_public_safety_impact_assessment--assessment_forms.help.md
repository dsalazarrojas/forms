# Public Safety Impact Assessment - Help Guide
## Purpose
The Public Safety Impact Assessment form is used to evaluate the potential risks and impacts of a project on public safety.

## How To Complete This Form

1. Enter project details such as project description, start and end dates, and assigned tools.
2. Select the project location and department.
3. Identify risk factors and mitigation measures.
4. Assess the risk level of the project.
5. Provide contact information for the project team.
6. Specify the project status and output file information.

## Field-by-Field Explanation

* **Project Details** (`project_details`): Enter a brief description of the project.
* **Project Location** (`project_location`): Enter the location of the project.
* **Mitigation Measures** (`mitigation_measures`): Describe the measures taken to mitigate potential risks.
* **Risk Factors** (`risk_factors`): Select one or more risk factors that may impact public safety.
* **Risk Assessment** (`risk_assessment`): Assess the level of risk (Low, Medium, or High).
* **Project Start Date** (`project_start_date`): Enter the start date of the project.
* **Project End Date** (`project_end_date`): Enter the end date of the project.
* **Project Description** (`project_description`): Enter a detailed description of the project.
* **Risk Level** (`risk_level`): Enter the level of risk.
* **Project Status** (`project_status`): Enter the current status of the project.
* **Contact Person** (`contact_person`): Enter the contact person's name.
* **Contact Email** (`contact_email`): Enter the contact person's email address.
* **Contact Phone** (`contact_phone`): Enter the contact person's phone number.
* **Assigned Tool** (`assigned_tool`): Enter the tool assigned to the project.
* **Output File** (`output_file`): Specify the output file for the project.
* **Notes** (`notes`): Add any additional notes about the project.
* **Project Lead** (`project_lead`): Enter the project lead's name.
* **Project Manager** (`project_manager`): Enter the project manager's name.
* **Department** (`department`): Enter the department responsible for the project.
* **Section** (`section`): Enter the section responsible for the project.
* **Team** (`team`): Enter the team members involved in the project.
* **Location** (`location`): Enter the location of the project.
* **Risk Category** (`risk_category`): Select the risk category (Category 1, Category 2, Category 3).
* **Risk Frequency** (`risk_frequency`): Select the risk frequency (Option 1, Option 2, Option 3, Option 4, Option 5).

## Tips

* Make sure to fill out all required fields.
* Use specific language when describing risk factors and mitigation measures.
* Use the correct risk assessment level (Low, Medium, or High).
* Enter accurate contact information.
* Review and update the form regularly to reflect changes in project status and risk levels.
