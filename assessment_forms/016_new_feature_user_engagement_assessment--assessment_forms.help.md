# New Feature User Engagement Assessment - Help Guide
## Purpose
This form is designed to collect feedback and assessment on a new feature from users who have interacted with it. It helps gauge the success of the new feature and identify areas for improvement.

## How To Complete This Form
To complete this form, follow these steps:

1. Ensure you have interacted with the new feature.
2. Answer the questions honestly, based on your experience with the feature.
3. Provide any improvement suggestions or comments in the "Improvement Suggestions" field.
4. If you'd like to be contacted for further discussions, fill in your email and/or phone number.

## Field-by-Field Explanation
### New Feature User Engagement Assessment
* **New Feature User Engagement Assessment** (`text`, required: false): This is the main question of the form, where you should briefly describe your experience with the new feature.

### Adoption
* **Adoption** (`select_one`, required: false): Choose one of the options that best describes how much you've adopted the new feature:
	+ Adoption is low
	+ Adoption is medium
	+ Adoption is high

### Satisfaction
* **Satisfaction** (`select_one`, required: false): Choose one of the options that best describes your level of satisfaction with the new feature:
	+ Very Dissatisfied
	+ Neutral
	+ Satisfied
	+ Very Satisfied

### Improvement Suggestions
* **Improvement Suggestions** (`note`, required: false): If you have any suggestions on how to improve the new feature, add them here.

### Contact Information
* **Email** (`email`, required: false): If you'd like to be contacted for further discussions, fill in your email address.
* **Phone** (`text`, required: false): If you'd like to be contacted via phone, fill in your phone number.

## Tips
* Be honest and thorough in your feedback.
* Only complete this form if you've genuinely interacted with the new feature.
* If you're unsure about anything, feel free to ask for clarification.
