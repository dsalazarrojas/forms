## Purpose
This form is designed to test your knowledge of PL/SQL cursor concepts. It consists of a series of questions that cover various aspects of cursors in PL/SQL, including their primary function, data fetch, and usage.

## Field-by-Field Explanation
* **What is the primary function of a cursor?** (`question_1`, text, required): A cursor in PL/SQL is a data structure that allows for the retrieval and manipulation of data from a database table.
* **How does a cursor fetch rows from the database?** (`question_2`, text, required): A cursor fetches rows from the database by navigating through them one at a time.
* **What is the purpose of a cursor forset?** (`question_3`, text, required): A cursor forset is used to fetch all rows from a single database table.
* **How is a cursor used in PL/SQL?** (`question_4`, text, required): A cursor is used in PL/SQL for data retrieval and manipulation.
* **What are the different types of cursor types in PL/SQL?** (`question_5`, text, required): There are various types of cursors in PL/SQL, including IMMUTABLE and SCROLL.
