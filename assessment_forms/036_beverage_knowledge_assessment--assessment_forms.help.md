# Beverage Knowledge Assessment - Help Guide
## Purpose
This form is designed to evaluate your beverage knowledge and skills as an employee in the industry. It will cover a range of topics, from spirits and wine to beer and coffee, and will help identify areas where you need improvement.

## How To Complete This Form
1. Please answer each question carefully, selecting the correct answer from the options provided.
2. For multiple-choice questions, select all that apply if the correct answer includes multiple options.
3. For questions 3 and 9, select all that apply from the options.
4. For question 6, select the correct coffee drink that contains steamed milk and espresso.
5. For question 7, select the standard pour size for a single shot of spirits.
6. For question 8, select the correct grape variety used to make Champagne.
7. For questions 3 and 9, be careful to select all that apply.
8. For question 10, select the key difference between an IPA and a Lager.
9. For question 15, select the coloring ingredient that gives a Pink Lady cocktail its color.
10. For question 17, rate your hands-on beverage preparation skills as honestly as possible.
11. For question 18, select all that apply from the options.
12. For question 19, select your confidence level as honestly as possible.
13. For question 20, provide any additional comments or topics you would like to be covered in training.
