# Psychological Assessment Form - Help Guide

## Purpose
The Psychological Assessment Form is a tool used to collect information about a client's psychological health status and assessment results from mental health professionals. This guide will walk you through each field in the form to help you complete it accurately and efficiently.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out each field accurately and completely.
2. Make sure to select the correct options for each field, if applicable.
3. Review your answers carefully before submitting the form.

## Field-by-Field Explanation

* **Psychological Assessment Form** (1, text, optional): Enter a brief description of the psychological assessment form, if applicable.
* **Psychological Assessment Questions** (2, text, optional): Enter the specific questions or prompts asked during the assessment.
* **Psychological Assessment Results** (3, text, optional): Enter the results of the assessment, if available.
* **Psychological Health Status** (4, select_one, optional): Select the client's current psychological health status from the options:
	+ Active
	+ Inactive
* **Mental Health Professional** (5, text, optional): Enter the name and contact information of the mental health professional who performed the assessment.
* **Client Name** (6, text, optional): Enter the name of the client being assessed.
* **Date Completed** (7, date, optional): Enter the date the assessment was completed.
* **Time Completed** (8, time, optional): Enter the time the assessment was completed.
* **Notes** (9, note, optional): Enter any additional comments or notes about the assessment.
* **Email** (10, email, optional): Enter the client's email address, if available.
* **Phone Number** (11, text, optional): Enter the client's phone number, if available.

## Tips
* Make sure to keep the information up to date and accurate.
* If you are unsure about any field, please consult with the responsible party (e.g., the client's file manager or healthcare manager).
* This form is for internal use only, so please do not share it with unauthorized parties.
