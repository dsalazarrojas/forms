# Fashion New Collection Popularity Assessment - Help Guide

## Purpose
This form is used to collect data on a new fashion collection's popularity and purchase intent. By filling out this form, you'll be able to gauge the likelihood of customers purchasing a collection based on its attributes.

## How To Complete This Form
1. Fill out the form with the following fields:
	* Fashion New Collection Name
	* Fashion New Collection Description
	* Fashion New Collection Image URL
	* Fashion New Collection Video URL
	* Fashion New Collection Price Range
	* Fashion New Collection Purchasability
	* Fashion New Collection Purchasability Rating
	* Fashion New Collection Quality
	* Fashion New Collection Quality Rating
	* Fashion New Collection Intent to Buy
	* Fashion New Collection Purchase Intent
	* Fashion New Collection Recommendation
	* Fashion New Collection Recommendation Rating
	* Fashion New Collection Purchase Probability
	* Fashion New Collection Purchase Probability Score
	* Fashion New Collection Recommendation Score Range
	* Fashion New Collection Collection Size
	* Fashion New Collection Collection Weight
	* Fashion New Collection Collection Height
	* Fashion New Collection Collection Width
	* Fashion New Collection Collection Depth
	* Fashion New Collection Collection Length
	* Fashion New Collection Color
2. Select the relevant options for each field as accurately as possible.
3. If a field is not applicable or does not apply, mark it as "Other" or leave it blank.

## Field-by-Field Explanation

* **Fashion New Collection Name** (`fashion_new_collection_name`, text, optional): Enter the name of the fashion collection.
* **Fashion New Collection Description** (`fashion_new_collection_description`, text, optional): Enter a brief description of the fashion collection.
* **Fashion New Collection Image URL** (`fashion_new_collection_image_url`, text, optional): Enter the URL of the image of the fashion collection.
* **Fashion New Collection Video URL** (`fashion_new_collection_video_url`, text, optional): Enter the URL of the video of the fashion collection.
* **Fashion New Collection Price Range** (`fashion_new_collection_price_range`, select_one, optional): Select the price range of the fashion collection (Low, Medium, High).
* **Fashion New Collection Purchasability** (`fashion_new_collection_purchasability`, text, optional): Enter the purchasability of the fashion collection.
* **Fashion New Collection Purchasability Rating** (`fashion_new_collection_purchasability_rating`, select_one, optional): Select the rating for purchasability (Very satisfied, Neutral, Dissatisfied).
* **Fashion New Collection Quality** (`fashion_new_collection_quality`, select_multiple, optional): Select the quality of the fashion collection ('Yes', 'No', Other).
* **Fashion New Collection Quality Rating** (`fashion_new_collection_quality_rating`, select_one, optional): Select the rating for quality (Very satisfied, Neutral, Dissatisfied).
* **Fashion New Collection Intent to Buy** (`fashion_new_collection_intent_to_buy`, select_multiple, optional): Select the intent to buy the fashion collection ('True', 'False', Maybe).
* **Fashion New Collection Purchase Intent** (`fashion_new_collection_purchase_intent`, select_multiple, optional): Select the purchase intent of the fashion collection ('Yes', 'No', Other).
* **Fashion New Collection Recommendation** (`fashion_new_collection_recommendation`, select_multiple, optional): Select the recommendation of the fashion collection ('Yes', 'No', Other).
* **Fashion New Collection Recommendation Rating** (`fashion_new_collection_recommendation_rating`, select_multiple, optional): Select the rating for recommendation (Very satisfied, Neutral, Dissatisfied).
* **Fashion New Collection Purchase Probability** (`fashion_new_collection_purchase_probability`, number, optional): Enter a numerical value for purchase probability.
* **Fashion New Collection Purchase Probability Score** (`fashion_new_collection_purchase_probability_score`, select_one, optional): Select the score for purchase probability ('Yes', 'No', Other).
* **Fashion New Collection Recommendation Score Range** (`fashion_new_collection_recommendation_score_range`, select_multiple, optional): Select the score range for recommendation (Low, Medium, High).
* **Fashion New Collection Collection Size** (`fashion_new_collection_collection_size`, number, optional): Enter the size of the fashion collection.
* **Fashion New Collection Collection Weight** (`fashion_new_collection_collection_weight`, number, optional): Enter the weight of the fashion collection.
* **Fashion New Collection Collection Height** (`fashion_new_collection_collection_height`, number, optional): Enter the height of the fashion collection.
* **Fashion New Collection Collection Width** (`fashion_new_collection_collection_width`, number, optional): Enter the width of the fashion collection.
* **Fashion New Collection Collection Depth** (`fashion_new_collection_collection_depth`, number, optional): Enter the depth of the fashion collection.
* **Fashion New Collection Collection Length** (`fashion_new_collection_collection_length`, number, optional): Enter the length of the fashion collection.
* **Fashion New Collection Color** (`fashion_new_collection_color`, select_one, optional): Select the color of the fashion collection (Black, White, Red, Blue, Green, Yellow, Grey, Purple, Orange, Pink, Brown, Turquoise, Silver, Gold, Bronze, Pinkish, Lavender, Beige, Navy Blue, Khaki, Beig).

## Tips
* Make sure to fill out all the fields that apply to the fashion collection.
* If a field is not applicable or does not apply, mark it as "Other" or leave it blank.
* Be as accurate as possible when selecting options for each field.
