# Tutoring Program Effectiveness Assessment - Help Guide
## Purpose
The "Tutoring Program Effectiveness Assessment" form is designed to evaluate the effectiveness of a tutoring program. This form will help assess the quality and impact of the program on students, providing a comprehensive overview of its strengths and areas for improvement.

## How To Complete This Form
To complete this form, follow these steps:

1. Review the form carefully and answer all questions as accurately as possible.
2. Select the most suitable option for each question, using the options provided or entering your own text if necessary.
3. Complete all required fields, even if some questions have multiple options.

## Field-by-Field Explanation

* **Tutoring Program Effectiveness** (`tutoring_program_effectiveness`, text, optional): Provide a brief description of the effectiveness of the tutoring program in this section. This is a free-text field, so you can write as much or as little as you need to describe the program's effectiveness.
* **Program Goals** (`program_goals`, select_one, optional): Select one or more of the goals that the tutoring program aims to achieve. Choose the goal that best represents the program's primary objective. Options:
	+ Goal 1
	+ Goal 2
	+ Goal 3
* **Student Satisfaction** (`student_satisfaction`, select_multiple, optional): Indicate the level of satisfaction of the students who have benefited from the tutoring program. Select one or more options that best describe their experience. Options:
	+ Very Satisfied
	+ Somewhat Satisfied
	+ Not Satisfied
* **Program Outcomes** (`program_outcomes`, number, optional): Report the number of program outcomes that have been achieved, such as increased grades, improved test scores, or enhanced employability. This field is for numerical data only.
* **Program Improvements** (`program_improvements`, text, optional): Suggest areas for improvement or provide recommendations for future enhancements to the tutoring program. This is a free-text field, so you can write as much or as little as you need.
