# Student Technological Readiness Assessment - Help Guide
## Purpose
The Student Technological Readiness Assessment is a self-evaluation tool designed to gauge the technological readiness of students, teachers, and schools in adopting and utilizing technology in their daily lives. This form helps administrators understand the availability and reliability of devices, internet access, and support structures within each setting.

## How To Complete This Form
1. Select all relevant answers for each question, taking your best effort to provide honest responses.
2. Ensure that you answer every question, as the form will not proceed without completing all fields.
3. If you have no access to a particular device or internet connection, select the most accurate option (e.g., "None" or "No" for device age).

## Field-by-Field Explanation

* **Student Device Access**: This question assesses whether students have access to devices at home.
	+ Select 'True' if students have access to devices at home.
	+ Select 'False' if students do not have access to devices at home.
* **Internet Reliability**: This question gauges the reliability of the internet connection.
	+ Select 'Always' if the internet connection is always reliable.
	+ Select 'Sometimes' if the internet connection is sometimes reliable.
	+ Select 'Never' if the internet connection is never reliable.
* **Digital Confidence**: This question measures the confidence level of students in using digital tools.
	+ Select 'Highly Confident' if students have high confidence in using digital tools.
	+ Select 'Somewhat Confident' if students have moderate confidence in using digital tools.
	+ Select 'Not Very Confident' if students have low confidence in using digital tools.
* **What type of device do you have?**: This question inquires about the type of device used by students.
	+ Select 'Desktop or Laptop' if students use a desktop or laptop.
	+ Select 'Tablet' if students use a tablet.
	+ Select 'Smartphone' if students use a smartphone.
	+ Select 'None' if students do not use a device.
* **How do you typically access the internet?**: This question asks about the common method of internet access.
	+ Select 'Home' if students access the internet at home.
	+ Select 'School' if students access the internet at school.
	+ Select 'Public Wi-Fi' if students access the internet through public Wi-Fi.
	+ Select 'Mobile Network (cellphone data)' if students use mobile network data.
	+ Select 'Other (please specify)' if students use an alternative method for internet access.
* **How fast is your internet?**: This question assesses the speed of internet access.
	+ Select '25mb or faster' if internet speed is 25mb or faster.
	+ Select '10-24mb' if internet speed is between 10-24mb.
	+ Select '1-9mb' if internet speed is between 1-9mb.
	+ Select 'None' if there is no internet access.
* **How old is your device?**: This question gauges the age of the device used by students.
