# Post Project Assessment Survey - Help Guide
## Purpose
The Post Project Assessment Survey is a form designed to collect project assessment data after a project has been completed. This data will help the project team and stakeholders to evaluate the project's performance, identify areas for improvement, and make informed decisions for future projects.

## How To Complete This Form
To complete this form, please follow these steps:

1. Answer all required fields, indicated by **Required** in the field-by-field explanation below.
2. Be as accurate and thorough as possible when filling out the form.
3. If you're unsure about any field, please contact the project team or manager for guidance.

## Field-by-Field Explanation

* **Project Survey** (`project_survey`, text, Optional): Please describe the project in a few sentences, highlighting its key goals and objectives.
* **Project Manager Name** (`project_manager_name`, text, Optional): Please enter the name of the project manager who managed the project.
* **Project Status** (`project_status`, select_one, Optional): Please select the status of the project from the available options.
	+ Label 1: Project successfully completed
	+ Label 2: Project partially completed
	+ Label 3: Project cancelled
	+ Label 4: Project on hold
	+ Label 5: Project not completed
* **Start Date** (`start_date`, date, Optional): Please enter the start date of the project.
* **End Date** (`end_date`, date, Optional): Please enter the end date of the project.
* **Hours Spent** (`hours_spent`, number, Optional): Please enter the total hours spent on the project.
* **Team Members** (`team_members`, select_multiple, Optional): Please select all team members who worked on the project.
	+ Team Member 1
	+ Team Member 2
	+ Team Member 3
	+ Team Member 4
	+ Team Member 5
* **Notes** (`notes`, note, Optional): Please add any additional comments or notes about the project.
* **Email** (`email`, email, Optional): Please enter the email address of the project contact person.
* **Phone** (`phone`, text, Optional): Please enter the phone number of the project contact person.

## Tips
* Please be sure to answer all required fields to ensure accurate data collection.
* If you're unsure about any field, please contact the project team or manager for guidance.
* You can submit the form once you've completed all fields.
