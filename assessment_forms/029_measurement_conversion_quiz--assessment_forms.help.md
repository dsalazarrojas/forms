# Measurement Conversion Quiz - Help Guide
## Purpose
The Measurement Conversion Quiz form is designed to help users practice converting between different units of measurement. This form is used to convert a given value from one unit to another in various measurement systems.

## How To Complete This Form
1. **Start by entering your name** (user_input_1): This is the first step in the quiz. Please enter your name as it will be used to display the results of your quiz.
2. **Select the unit to convert from** (unit_to_convert): Choose the unit you want to convert from the available options (inches, feet, yards, centimeters, meters, millimeters, kilograms, or grams).
3. **Enter the value to convert** (value_to_convert): Type the value you want to convert from the selected unit.
4. **Select the units to choose from** (units_to_choose): This is where you choose the units to convert the value to. Select all the units you want to convert the value to.
5. **Submit the form** (result): Finally, click the submit button to get the result of your conversion.

## Field-by-Field Explanation
- **What is your name (user_input_1)**: This is the first field in the form where you enter your name. It is not required.
- **Unit to convert (unit_to_convert)**: This field allows you to select the unit you want to convert from. Choose the unit that matches the value you are converting from.
- **Value to convert (value_to_convert)**: This is where you enter the value you want to convert. For example, if you want to convert 5 inches to centimeters, you would enter 5 in this field.
- **Converted value (converted_value)**: This is the calculated result of the conversion.
- **Units to choose (units_to_choose)**: This is where you select the units to convert the value to. Select all the units you want to convert to.
- **Result (result)**: This is where your converted values will be displayed.

## Tips
- Make sure to select the correct unit in the "Unit to convert" field to ensure accurate conversion results.
- Double-check the "Value to convert" field to ensure it is correct before submitting the form.
- The form will automatically generate the converted values for the selected units.
