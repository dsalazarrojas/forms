> # Core Building Assessment Form - Help Guide
## Purpose
The Core Building Assessment Form is a vital tool for evaluating a building's core structure, safety features, and environmental systems. It helps assessors identify potential issues and areas of concern, ensuring the building's integrity and safety.

## How To Complete This Form
To complete this form, follow these steps:

1. Review each page carefully and ensure you answer all required fields.
2. Answer all questions accurately and truthfully to the best of your knowledge.
3. If you're unsure about any question, ask for clarification or consult with the building owner or assessor.
4. Use the options provided to select the most accurate answer for each question.

## Field-by-Field Explanation

* **building_info**: This field is used to determine if the building is a core structure. Select 'Yes' if the building has a core structure.
* **fire_safety**: This field assesses the building's fire safety features. Select 'Yes' if the building has fire safety features such as sprinklers or fire alarms.
* **accessibility**: This field is used to describe the building's accessibility features. Please provide a detailed description of the building's accessibility features, such as ramps, elevators, or wheelchair-accessible entrances.
* **building_conditions**: This field is used to describe the building's condition. Please provide a detailed description of the building's condition, including any visible signs of wear and tear or damage.
* **safety_features**: This field assesses the building's safety features. Select 'Yes' if the building has safety features such as emergency exits, exit signs, or safety equipment.
* **regulatory_compliance**: This field is used to determine if the building complies with regulatory standards. Select 'Yes' if the building meets regulatory standards.
* **building_characteristics**: This field is used to describe the building's characteristics, such as its size, shape, or location.
* **building_age**: This field is used to determine the building's age. Please provide the exact age of the building.
* **building_status**: This field is used to determine the building's status. Select 'Active' if the building is currently occupied or in use.
* **building_condition_rating**: This field is used to rate the building's condition. Please provide a numerical value between 1 and 10, where 1 represents an excellent condition and 10 represents a poor condition.
* **building_purpose**: This field is used to determine the building's purpose. Select 'Yes' if the building has a specific purpose such as office space or residential units.
* **site_description**: This field is used to describe the site where the building is located. (Optional)
* **site_characteristics**: This field is used to describe the site's characteristics, such as its terrain or climate. (Optional)
* **structural_systems**: This field is used to describe the building's structural systems, such as the foundation or roof. (Optional)
* **structural_systems_description**: This field is used to provide a detailed description of the building's structural systems. (Optional)
* **structural_systems_rating**: This field is used to rate the building's structural systems. (Optional)
* **environmental_systems**: This field is used to describe the building's environmental systems, such as plumbing or HVAC. (Optional)
* **environmental_systems_description**: This field is used to provide a detailed description of the building's environmental systems. (Optional)
* **environmental_systems_rating**: This field is used to rate the building's environmental systems. (Optional)
* **electrical_systems**: This field is used to describe the building's electrical systems, such as generators or electrical panels. (Optional)
* **electrical_systems_description**: This field is used to provide a detailed description of the building's electrical systems. (Optional)
* **electrical_systems_rating**: This field is used to rate the building's electrical systems. (Optional)
* **mechanical_systems**: This field is used to describe the building's mechanical systems, such as HVAC or plumbing. (Optional)
* **mechanical_systems_description**: This field is used to provide a detailed description of the building's mechanical systems. (Optional)
