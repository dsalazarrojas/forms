The LED Retrofit Risk Assessment form is used to identify and document risks associated with a LED retrofit project. This form helps to collect and organize information about the project's details, electrical contractor's information, and potential risks and mitigation strategies. This form is typically used by facility managers, project managers, or electrical engineers to ensure that all relevant information is captured and documented for the project.

To complete this form, follow these steps:

### How To Complete This Form

1. **Enter Project Details**: Enter a brief description of the project, including the project location and any relevant project notes.
2. **Identify Risks**: Select the types of risks associated with the project, including Low, Moderate, and High.
3. **Add Additional Information**: Enter any additional notes about the project or electrical contractor.
4. **Capture Electrical Contractor Information**: Enter the electrical contractor's name, company name, contact information, and address.
5. **Review and Update**: Review the form to ensure that all required fields are complete and accurate.

### Field-by-Field Explanation

* **Project Details** (`project_details`, text, required: false): Enter a brief description of the project, including the project location and any relevant project notes.
* **Risks** (`risks`, select_multiple, required: true): Select the types of risks associated with the project, including Low, Moderate, and High.
* **Mitigation Strategies** (`mitigation_strategies`, text, required: false): Enter any additional notes about the project or electrical contractor. This field is intended to capture any strategies or actions to be taken to mitigate identified risks.
* **Project Notes** (`project_notes`, note, required: false): Enter any additional notes or comments about the project.
* **Electrical Contractor Information** (`electrical_contractor_info`, text, required: false): Enter any additional information about the electrical contractor.
* **Electrical Contractor Name** (`electrical_contractor_info_name`, text, required: false): Enter the name of the electrical contractor.
* **Electrical Contractor Company** (`electrical_contractor_info_company`, text, required: false): Enter the name of the electrical contractor's company.
* **Electrical Contractor Contact** (`electrical_contractor_info_contact`, text, required: false): Enter the contact information for the electrical contractor.
* **Electrical Contractor Address** (`electrical_contractor_info_address`, text, required: false): Enter the address of the electrical contractor.
* **Electrical Contractor Notes** (`electrical_contractor_notes`, note, required: false): Enter any additional notes or comments about the electrical contractor.
* **Project Location** (`project_location`, text, required: false): Enter the location of the project.
* **Client Notes** (`client_notes`, note, required: false): Enter any additional notes or comments about the client.
* **Additional Notes** (`additional_notes`, text, required: false): Enter any additional notes or comments about the project.

### Tips

* Ensure that all required fields are complete and accurate.
* Review the form carefully to ensure that all information is captured and documented.
* Use this form as a template to create a comprehensive risk assessment document for the project.
* Update the form as needed to reflect changes in the project scope or risks.
