# Nursing Home Communication Board Request Form - Help Guide
## Purpose
The Nursing Home Communication Board Request Form is used to create and manage requests for communication with residents in a nursing home. This form is essential for ensuring that staff can effectively communicate with residents and their families.

## How To Complete This Form
1. Enter the resident's name in the "Resident Name" field.
2. Enter the resident's date of birth in the "Resident DOB" field.
3. Select the facility where the resident is staying in the "Facility Name" field.
4. Choose the type of communication needed using the "Communication Type" dropdown menu.
5. Provide a detailed description of the communication in the "Communication Details" field.
6. Enter the name of the facility contact person in the "Facility Contact Name" field.
7. Enter the phone number of the facility contact person in the "Facility Contact Phone" field.
8. Enter the email of the facility contact person in the "Facility Contact Email" field.
9. Set the date for the communication request in the "Request Date" field.
10. Enter any follow-up details for the communication in the "Follow Up Details" field.
11. Set the date for the follow-up in the "Follow Up Date" field.
12. Select the staff members assigned to the communication in the "Assigned Staff" multi-select field.
13. Set the status of the communication request using the "Status" dropdown menu.
14. Enter any additional notes about the communication request in the "Notes" field.
15. Enter your email address for follow-up purposes in the "Email" field.

## Field-by-Field Explanation
* **Resident Name** (`resident_name`, Text, Optional): Enter the name of the resident who needs to be contacted.
* **Resident DOB** (`resident_dob`, Date, Optional): Enter the date of birth of the resident.
* **Facility Name** (`facility_name`, Text, Optional): Select the facility where the resident is staying.
* **Communication Type** (`communication_type`, Select One, Required): Choose the type of communication needed.
* **Communication Details** (`communication_details`, Text, Optional): Provide a detailed description of the communication.
* **Facility Contact Name** (`facility_contact_name`, Text, Optional): Enter the name of the facility contact person.
* **Facility Contact Phone** (`facility_contact_phone`, Text, Optional): Enter the phone number of the facility contact person.
* **Facility Contact Email** (`facility_contact_email`, Text, Optional): Enter the email of the facility contact person.
* **Request Date** (`request_date`, Date, Optional): Set the date for the communication request.
* **Follow Up Details** (`follow_up_details`, Text, Optional): Enter any follow-up details for the communication.
* **Follow Up Date** (`follow_up_date`, Date, Optional): Set the date for the follow-up.
* **Assigned Staff** (`assigned_staff`, Select Multiple, Required): Select the staff members assigned to the communication.
* **Status** (`status`, Select One, Required): Set the status of the communication request.
* **Notes** (`notes`, Text, Optional): Enter any additional notes about the communication request.
* **Email** (`email`, Email, Optional): Enter your email address for follow-up purposes.
