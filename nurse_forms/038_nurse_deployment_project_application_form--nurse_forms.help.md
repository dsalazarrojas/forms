# Nurse Deployment Project Application Form - Help Guide
## Purpose

This form is used to collect information from nurses who are interested in participating in a nurse deployment project. The purpose of this form is to gather details about the nurse's personal and professional experiences, project requirements, and other relevant information that will help in assigning the nurse to a suitable project.

## How To Complete This Form

1. Fill out the form completely and accurately.
2. Ensure that you have read and understood the guidelines and the form requirements.
3. Enter your personal details in the "application_details" section.
4. Enter your project details in the "project_details" section.
5. Specify your skills in the "skills" field.
6. Enter the project's location in the "project_location" field.
7. Enter a brief description of the project in the "project_description" field.
8. Enter the project's duration in days in the "project_duration" field.
9. Enter the project's budget in the "project_budget" field.
10. Specify the project's start and end dates in the "project_start_date" and "project_end_date" fields, respectively.
11. Indicate if you are willing to be assigned to a project in the "assigned_nurse" field.
12. List all nurses you are interested in working with in the "selected_nurses" field.
13. Indicate if the project requires a project manager in the "project_manager" field.
14. List all project coordinators you are interested in working with in the "project_coordinator" field.
15. Specify the project's location in the "project_location" field.
16. Choose the type of project you are applying for in the "project_type" field.
17. Choose the category of the project in the "project_category" field.
18. Indicate if the project requires a specific tool in the "assigned_tool" field.
19. Choose the status of the project in the "project_status" field.
20. Enter a detailed description of the project in the "project_description" field.

## Field-by-Field Explanation

* **application_details**: Enter your personal details, including name, contact information, etc.
* **personal_details**: Enter any relevant personal details that may be helpful for the project.
* **project_details**: Enter details about the project you are interested in participating in.
* **skills**: List your skills, separated by commas.
* **project_location**: Enter the location of the project.
* **project_description**: Enter a brief description of the project.
* **project_duration**: Enter the duration of the project in days.
* **project_budget**: Enter the budget of the project.
* **project_start_date** and **project_end_date**: Enter the start and end dates of the project, respectively.
* **assigned_nurse**: Indicate if you are willing to be assigned to a project.
* **selected_nurses**: List all nurses you are interested in working with.
* **project_manager**: Indicate if the project requires a project manager.
* **project_coordinator**: List all project coordinators you are interested in working with.
* **project_location**: Specify the project's location.
* **project_type**: Choose the type of project you are applying for.
* **project_category**: Choose the category of the project.
* **assigned_tool**: Indicate if the project requires a specific tool.
* **project_status**: Choose the status of the project.
* **project_description**: Enter a detailed description of the project.

## Tips

* Ensure that all fields are completed accurately and truthfully.
* Do not duplicate information or enter any irrelevant details.
* If you are unsure about any field, please ask for clarification or contact the project team.
