# COVID 19 Vaccine Interest Form - Help Guide
## Purpose
This form is designed to collect information from individuals interested in receiving the COVID-19 vaccine. It will help us understand your preferences and concerns regarding vaccination.

## How To Complete This Form

1.  Please complete all the required fields to ensure we have all the necessary information.
2.  For each section, please answer the questions honestly and accurately.
3.  If you have any concerns or questions, please describe them in the designated fields.

## Field-by-Field Explanation

*   **First Name** (`interest_first_name`, `text`, required): Please provide your first name.
*   **Last Name** (`interest_last_name`, `text`, required): Please provide your last name.
*   **Date of Birth** (`interest_dob`, `date`, required): Please enter your date of birth in MM-DD-YYYY format.
*   **Email Address** (`interest_email`, `email`, required): Please enter your email address.
*   **Phone Number** (`interest_phone`, `phone`, required): Please enter your contact phone number.
*   **Street Address** (`interest_address`, `text`, optional): Please provide your current street address (optional).
*   **Are You Interested in Getting the COVID-19 Vaccine** (`vaccine_interest_header`, `select_one`, required): Please select one of the interest levels: Yes, very interested / Somewhat interested / Undecided / Not very interested / Definitely not interested.
*   **If Interested, When Would You Like to Get Vaccinated** (`preferred_vaccine_timing`, `select_one`, optional): If interested, please select when you would like to get vaccinated: As soon as possible / Within 2 weeks / Within 1 month / 1-3 months from now / Later, when more information available / Not planning to get vaccinated.
*   **Do You Have a Vaccine Type Preference** (`vaccine_type_interest`, `select_one`, optional): If you have any preference among available vaccines, please select one:  Pfizer-BioNTech / Moderna / Johnson & Johnson / No specific preference.
*   **Do You Have Any Chronic Health Conditions** (`chronic_conditions_interest`, `select_one`, optional): If you have any chronic health conditions, please select: True / False / Prefer Not to Say.
*   **Allergies to Vaccine Components** (`allergies_interest`, `select_one`, required): If you have any allergies to vaccine components, please select one of the available options.
*   **Preferred Contact Method** (`preferred_contact_method`, `select_one`, required): If you have any preferred contact method, please select:  Email / Phone Call / Text Message / Mail.
*   **Preferred Vaccination Location** (`preferred_location`, `select_one`, optional): If you have any preferred location for vaccination, please select:  Local pharmacy / Clinic / Hospital / Community center / Mobile clinic / No preference.
*   **Concerns or Questions** (`vaccine_concerns`, `select_one`, required): If you have any concerns or questions, please select one of the options.
*   **Describe Your Concerns** (`vaccine_concerns`, `text`, optional): If you have any specific concerns, please describe them.
*   **What Information Would Help You Decide** (`information_needed_interest`, `text`, optional): If you need any additional information, please describe what would be helpful to you.
*   **Current Health Status** (`current_health_status`, `select_one`, required): If you have any concerns, please select your current health status: Excellent health / Good health / Fair health / Poor health.
*   **Do You Have Any Concerns About the COVID-19 Vaccine** (`vaccine_concerns`, `select_one`, required): If you have any concerns, please select one of the options: No concerns / Minor concerns / Moderate concerns / Significant concerns.
*   **May We Contact You About Vaccination Availability** (`follow_up_consent`, `select_one`, required): If you would like us to contact you about vaccination availability, please select: Yes, contact me / No, do not contact me.

## Tips

*   Please answer all required questions to ensure we have the necessary information.
*   If you are unsure about any field, please contact us for clarification.
*   This form will help us provide you with accurate and timely information about vaccination availability.
