# Nursing Quiz - Help Guide
## Purpose
This form is used to gather information about a patient's condition, medical history, and response to treatment. It helps healthcare professionals quickly and efficiently collect necessary data.

## How To Complete This Form
1. Start by filling out the Patient Name field with the patient's name as it appears on their medical record.
2. Select the appropriate question type from the question type dropdown menu.
3. Enter the question text in the provided text field.
4. Choose the answer type from the multiple-choice options.
5. Enter your response for the answer text field.
6. Enter the date and time of the patient's visit.
7. Enter the start and end date of the patient's visit.

## Field-by-Field Explanation

* **Patient Name** (`patient_name`, `text`, required): This field asks for the patient's name, which should match their medical record.
* **question type** (`question_type`, `select_one`, required/optional): This field determines the type of question you will be answering about the patient. Please select a type that best describes the question you are asking about the patient's condition.
* **question text** (`question_text`, `text`, optional): This field is where you enter the actual question text that you are asking about the patient.
* **answer type** (`answer_type`, `select_multiple`, optional): This field allows you to select the type of answer you are giving for the question.
* **answer text** (`answer_text`, `text`, optional): This field is where you enter your response to the question.
* **date/time** (`date_time`, `date`, optional): This field is where you enter the date and time of the patient's visit.
* **start date** (`start_date`, `date`, optional): This field is where you enter the start date of the patient's visit.
* **end date** (`end_date`, `date`, optional): This field is where you enter the end date of the patient's visit.

## Tips
* Please double-check the patient's name matches their medical record before submitting the form.
* Choose the correct question type and answer type to accurately reflect the patient's condition.
* Be as specific as possible when entering the question text and answer text.
* Ensure the date and time of the patient's visit is accurate.
