# Nursing Certification Audit Checklist - Help Guide
## Purpose
The purpose of this form is to collect information about a patient's nursing certification status for auditing purposes.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the patient's information, including their name and any other relevant details.
2. Select the type of certification the patient holds (e.g. RN, LPN, NP, etc.).
3. Enter the name of the certification.
4. Enter the date the certification was earned.
5. Enter the expiration date of the certification.
6. Select the current status of the certification (e.g. Active, Inactive).
7. Enter any additional details about the certification status.
8. Select the follow-up status (e.g. No follow-up needed, Follow-up needed).
9. Enter any additional details about the follow-up status.
10. Enter the next action that needs to be taken for follow-up.

## Field-by-Field Explanation

* **Patient info**
	+ This field is for entering the patient's information. Please provide a brief description of the patient.
* **Certification type**
	+ This field is to select the type of nursing certification the patient holds. Please choose from the list provided: RN, LPN, NP, or Other.
* **Certification name**
	+ This field is for entering the name of the certification.
* **Date earned**
	+ This field is for entering the date the certification was earned.
* **Expiration date**
	+ This field is for entering the expiration date of the certification.
* **Certification status**
	+ This field is to select the current status of the certification. Please choose from the list provided: Active, Inactive.
* **Certification status details**
	+ This field is for entering any additional details about the certification status.
* **Follow-up status**
	+ This field is to select the follow-up status. Please choose from the list provided: No follow-up needed, Follow-up needed.
* **Follow-up status details**
	+ This field is for entering any additional details about the follow-up status.
* **Follow-up next action**
	+ This field is for entering the next action that needs to be taken for follow-up.

Note: All fields are optional, but please provide as much information as possible to ensure accurate auditing of the patient's certification status.
