# First Aid Quiz - Help Guide

## Purpose
The First Aid Quiz is a form designed to collect information about an individual's first aid skills and knowledge. This quiz is used to assess their ability to provide basic first aid in emergency situations.

## How To Complete This Form
To complete the First Aid Quiz, follow these steps:

1. Answer each question carefully, as they are used to evaluate your first aid knowledge and skills.
2. Choose the correct start date for the quiz from the dropdown menu.
3. Select the correct answer for each multiple-choice question.
4. Enter your phone number and email address, if applicable.
5. Enter any comments or feedback about the quiz.

## Field-by-Field Explanation

* **First Aid Quiz Questions**: Enter your answer to the first aid quiz questions.
* **Multiple Choice Start Date**: Choose the start date for the quiz from the dropdown menu. This field is used to determine when the quiz began.
* **Multiple Choice Answer**: Select one or more correct answers from the dropdown menu.
* **Date**: Enter the date in the format of MM/DD/YY or MM/DD.
* **Time**: Enter the time in the format of HH:MM (24 hour format).
* **Phone Number**: Enter your phone number if you have one.
* **Email**: Enter your email address, if applicable.
* **Multiple Choice Comment**: Enter any comments about the multiple-choice question.
* **First Aid Quiz Comments**: Enter any general comments about the quiz.
* **First Aid Quiz Start Date**: Enter the start date of the quiz.
* **First Aid Quiz Start Time**: Enter the start time of the quiz.
* **First Aid Quiz End Date**: Enter the end date of the quiz.
* **First Aid Quiz End Time**: Enter the end time of the quiz.
* **First Aid Quiz Completed**: Enter the number of questions you completed.
* **First Aid Quiz Score**: Enter your score out of the total number of questions.
* **First Aid Quiz Score Percentage**: Enter your percentage score.
* **First Aid Quiz Score Out Of**: Enter the total number of questions.
* **First Aid Quiz Start Time In Seconds**: Enter the start time of the quiz in seconds.
* **First Aid Quiz End Time In Seconds**: Enter the end time of the quiz in seconds.
* **First Aid Quiz Time Spent**: Enter the time you spent on the quiz.
* **First Aid Quiz Questions Answered**: Enter the number of questions you answered.
* **Everything**: Select 'Yes' if you answered all questions, 'No' if you didn't.
* **First Aid Score**: Enter your score out of the total number.
* **Everything Else**: Enter any other information or comments.

## Tips
- Make sure to answer each question carefully, as they are used to assess your first aid knowledge and skills.
- If you have any difficulty in answering a question, select 'No' for 'Everything'.
