# Design Firm Project Release Form - Help Guide
## Purpose
The Design Firm Project Release Form is designed to capture essential project release details and confirm client involvement. It ensures a smooth handover process by collecting relevant information from the client and project team.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the project ID to associate with the project being released.
2. Provide the Client Name and Client Email for contact purposes.
3. Input the Release Date for the project.
4. Choose the Client Approval status (Approve or Reject).
5. Select the current Project Status (Active, Completed, or Closed).
6. Enter Client Phone number for further contact.
7. Add any Project Notes or Release Notes for reference.
8. Capture the Client Signature and Release Signature for official confirmation.

## Field-by-Field Explanation

* **Project Id** (`project_id`, number, required): Enter the unique ID associated with the project being released.
* **Client Name** (`client_name`, text, required): Type in the name of the client associated with the project.
* **Release Date** (`release_date`, date, required): Enter the date when the project will be released.
* **Client Approval** (`client_approval`, select_one, required): Choose 'Approve' to confirm client release approval or 'Reject' for any issues.
* **Project Status** (`project_status`, select_multiple, required): Select the status of the project (Active, Completed, or Closed).
* **Client Email** (`client_email`, email, required): Enter the email of the contact person for the client.
* **Client Phone** (`client_phone`, text, required): Enter the phone number of the client contact person.
* **Project Notes** (`project_notes`, text, optional): Add any additional notes about the project.
* **Release Notes** (`release_notes`, text, optional): Add any notes about the release process.
* **Client Signature** (`client_signature`, note, optional): Capture the client's signature for approval.
* **Release Signature** (`release_signature`, note, optional): Capture the release signature for official confirmation.
 
## Tips
- Please ensure to enter all required fields for accurate project release documentation.
- Make sure to proofread your entries before submitting the form.
- Use the Project Notes and Release Notes for any additional information that might be useful for the client or project team.
