# HTML Code Submission Form - Help Guide
## Purpose
This form is designed to collect HTML code submissions from users, which will be used to create an HTML code snippet library.

## How To Complete This Form
To complete this form, follow these steps:

1. Click on the form to begin.
2. Fill out the form sections as instructed below.

## Field-by-Field Explanation

* **Submitter Info**:
  * **Submitter Info**: Enter your name and contact information as a way to identify who is submitting the code.
* **Code Submission**:
  * **Code Submission**: Enter the HTML code you would like to submit, either for review or inclusion in the library.
* **Code Snippet**:
  * **Code Snippet**: Provide any relevant code snippets related to the submitted code.
* **Code Version**:
  * **Code Version**: Specify the version of the code you are submitting, if applicable.

## Tips
* Make sure to enter accurate and relevant information in each field.
* If you are submitting code with multiple versions, please specify each version separately in the **Code Version** field.
* If you have any questions or concerns, feel free to contact us at form@gic.mx.
