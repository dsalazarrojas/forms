# Website Launch Checklist Form - Help Guide
## Purpose
This form is a checklist for website project teams to ensure that all necessary steps are taken before launching a website. It helps track the progress of a project, from content creation to review and testing stages.

## How To Complete This Form

To complete this form, follow these steps:

1. Fill in the project name and website URL if applicable.
2. Select the content creation team.
3. Select the project status (in progress or launched).
4. Choose the launch date and launch time if applicable.
5. Select the testing status (completed or not).
6. Choose whether the website has been launched or not.
7. Add any additional notes.
8. Enter the project team members' contact information (email and phone number).

## Field-by-Field Explanation

* **Project Name** (`project_name`, text, required: false): Enter the name of the project.
* **Website URL** (`website_url`, text, required: false): Enter the URL of the website.
* **Content Creation Team** (`content_creation_team`, select multiple, required: false): Select the team members responsible for content creation.
* **Project Status** (`project_status`, select one, required: false): Choose the current status of the project (in progress or launched).
* **Launch Date** (`launch_date`, date, required: false): Enter the date of the launch if it has already been launched.
* **Testing Status** (`testing_status`, select multiple, required: false): Select the status of the testing stage (completed or not).
* **Launch Time** (`launch_time`, time, required: false): Enter the launch time if it has already been launched.
* **Launched** (`website_launched`, select one, required: false): Choose whether the website has been launched or not.
* **Notes** (`notes`, note, required: false): Add any additional notes about the project.
* **Email** (`email`, email, required: false): Enter the email address of the project manager.
* **Phone** (`phone`, text, required: false): Enter the phone number of the project manager.
* **Project Manager** (`project_manager`, text, required: false): Enter the name of the project manager.
* **Project Leader** (`project_leader`, text, required: false): Enter the name of the project leader.
* **Project Developer** (`project_developer`, text, required: false): Enter the name of the project developer.
* **Review Status** (`review_status`, select multiple, required: false): Select the status of the review stage (approved or awaiting approval or declined).
* **Testing Status** (`testing_status`, select multiple, required: false): Select the status of the testing stage (completed or not).
* **Launch Status** (`launch_status`, select one, required: false): Choose whether the website has been launched or not.

Note: The fields marked as required: false are optional, and you can fill them in only if necessary.
