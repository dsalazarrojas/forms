# Mobile Web & Marketing Form - Help Guide
## Purpose
This form is designed to collect information about mobile web and marketing forms. It is intended to be used for research, data collection, or as a template for creating custom forms.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the title of your form.
2. Select the category that best describes your form (e.g., Web Design Forms, Forms for Marketing, Web Forms).
3. Enter a description of your form, if desired.
4. Select the tool assigned to your form (e.g., chatjimmy, Other).
5. Input the output file details: file name, extension (e.g., .yaml, .json, .xml), and format (e.g., YAML, JSON, XML).
6. Select the time created and updated for your form.

## Field-by-Field Explanation
* **Title** (`title`, text, required): Enter a brief title for your form.
* **Form ID** (`form_id`, text, optional): Enter a unique ID for your form, if desired.
* **Category** (`category`, select_multiple, optional): Select one or more categories that describe your form (e.g., Web Design Forms, Forms for Marketing, Web Forms).
* **Description** (`description`, text, optional): Enter a description of your form, if desired.
* **Assigned tool** (`assigned_tool`, select_one, optional): Select the tool assigned to your form (e.g., chatjimmy, Other).
* **Output file** (`output_file`, text, optional): Enter the name of your output file.
* **Output file name** (`output_file_name`, text, optional): Enter the name of your output file.
* **Output file extension** (`output_file_extension`, select_one, optional): Select the extension of your output file (e.g., .yaml, .json, .xml).
* **Output file path** (`output_file_path`, text, optional): Enter the path where your output file will be saved.
* **Output file format** (`output_file_format`, select_one, optional): Select the format of your output file (e.g., YAML, JSON, XML).
* **Created time** (`created_time`, time, optional): Enter the time when your form was created.
* **Updated time** (`updated_time`, time, optional): Enter the time when your form was last updated.

## Tips
* Make sure to enter accurate and descriptive information for each field.
* Use the correct file extension and format for your output file.
* Select the correct tool assigned to your form.
* Take advantage of this form to collect and analyze data on mobile web and marketing forms.
