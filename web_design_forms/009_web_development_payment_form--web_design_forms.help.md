# Web Development Payment Form - Help Guide
## Purpose
This form is designed to collect information about web development projects, including project titles, client details, payment methods, and project statuses. It helps in organizing and managing web development projects efficiently.

## How To Complete This Form
- Fill in the project title in the "Project Title" field.
- If applicable, provide client information in the "Client Info" field (numeric value).
- Write a brief description of the project in the "Project Description" field.
- Specify the project requirements in the "Project Requirements" field.
- Select the payment method (e.g., Bank Transfer, PayPal, Stripe) in the "Payment Method" field.
- Enter the payment amount in the "Payment Amount" field.
- Set the project deadline (optional) in the "Project Deadline" field.
- Select the payment status (Pending, Paid, Declined) in the "Payment Status" field.
- Add any client notes if necessary in the "Client Notes" field.
- Enter the client's email address in the "Client Email" field.
- Enter the client's phone number in the "Client Phone" field (optional).
- Select the assigned user (e.g., chatjimmy, Other) in the "Assigned User" field.
- If applicable, select the created by user (e.g., chatjimmy, Other) in the "Created By" field.
- Add any comments about the form in the "Form Comments" field (optional).
- Enter form tags in the "Form Tags" field (optional).
- Set the project status (Active, In Progress, Completed) in the "Project Status" field.
- Select the updated by user (e.g., chatjimmy, Other) in the "Updated By" field (optional).
- Set the last update date in the "Updated At" field (optional).
- Set the creation date in the "Created At" field (optional).
- Enter the form ID in the "Form Id" field.
- Enter the form version in the "Form Version" field (optional).
- Enter the form version history in the "Form Version History" field (optional).
- Add any user comments in the "User Comments" field (optional).

## Field-by-Field Explanation
- **Project Title (1)** (`text`, required): This is the title of the project.
- **Client Info (2)** (`number`, optional): This field is for client information (numeric value).
- **Project Description (3)** (`text`, required): A brief description of the project.
- **Project Requirements (4)** (`text`, required): A list of requirements for the project.
- **Payment Method (5)** (`select_multiple`, required): Select the payment method (Bank Transfer, PayPal, Stripe).
- **Payment Amount (6)** (`number`, required): The payment amount for the project.
- **Project Deadline (7)** (`date`, optional): The deadline for the project completion.
- **Payment Status (8)** (`select_one`, required): The current payment status (Pending, Paid, Declined).
- **Client Notes (9)** (`text`, optional): Any additional notes for the client.
- **Client Email (10)** (`email`, required): The client's email address.
- **Client Phone (11)** (`text`, optional): The client's phone number.
- **Assigned User (12)** (`select_one`, required): The user assigned to the project.
- **Created By (13)** (`select_one`, optional): The user who created the project.
- **Form Comments (14)** (`text`, optional): Any comments about the form.
- **Form Tags (15)** (`text`, optional): Tags for the form (e.g., project type, category).
- **Project Status (18)** (`select_one`, required): The current status of the project (Active, In Progress, Completed).
- **Updated By (19)** (`select_one`, optional): The user who last updated the project.
- **Updated At (20)** (`date`, optional): The date of the last update.
- **Created At (21)** (`date`, optional): The date the project was created.
- **Form Id (22)** (`text`, required): The form's ID.
- **Form Version (23)** (`text`, optional): The current form version.
- **Form Version History (24)** (`text`, optional): A list of form version history.
- **User Comments (25)** (`text`, optional): Any comments from the user.
