# Design Brief 2 - Help Guide
## Purpose
This form is designed to collect information about a design project, specifically a design brief 2. The purpose of this form is to gather details about the project's scope, timeline, and other relevant information to ensure that the project is properly executed and meets the client's expectations.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the client's name in the "Client Name" field.
2. Provide the website URL associated with the project in the "Website URL" field.
3. Enter the contact email address of the person responsible for the project in the "Contact Email" field.
4. Enter the project's description in the "Project Description" field.
5. Select the project deadline in the "Project Deadline" field.
6. Choose whether the project scope includes "True" or "False" options in the "Project Scope" field.
7. Enter the project budget, if applicable, in the "Project Budget" field.
8. Enter the project's goals in the "Project Goals" field.
9. Enter the client's goals in the "Client Goals" field.
10. Select the project's status as "Active" or "Inactive" in the "Project Status" field.
11. Enter any additional project notes in the "Project Notes" field.
12. Enter any additional project scope options in the "Project Scope Options" field.
13. Enter any additional status options in the "Status Options" field.
14. Enter any additional project location options in the "Project Location Options" field.
15. Enter any additional project deadline 2 in the "Project Deadline 2" field.
16. Enter any additional project notes 2 in the "Project Notes 2" field.

## Field-by-Field Explanation
- **Client Name** (`client_name`, text, required): Please enter the name of the client for whom the project is being designed.
- **Website URL** (`website_url`, text, optional): Enter the URL of the client's website associated with the project.
- **Contact Email** (`contact_email`, email, required): Enter the email address of the person responsible for the project.
- **Contact Phone** (`contact_phone`, text, optional): Enter the phone number of the person responsible for the project.
- **Project Description** (`project_description`, text, optional): Briefly describe the project in this field.
- **Project Deadline** (`project_deadline`, date, required): Select the deadline for the project.
- **Project Scope** (`project_scope`, select_one, required): This field indicates whether the project scope includes "True" or "False" options. Select "True" if the project scope includes options.
- **Project Budget** (`project_budget`, number, optional): Enter the budget for the project, if applicable.
- **Project Goals** (`project_goals`, text, optional): Enter the project's goals.
- **Client Goals** (`client_goals`, text, optional): Enter the client's goals.
- **Project Status** (`project_status`, select_multiple, required): Select the project's status as "Active" or "Inactive".
- **Project Notes** (`project_notes`, note, optional): Enter any additional project notes.
- **Project Scope Options** (`project_scope_options`, text, optional): Enter any additional project scope options.
- **Status Options** (`status_options`, text, optional): Enter any additional status options.
- **Project Location** (`project_location`, text, optional): Enter any additional project location options.
- **Project Deadline 2** (`project_deadline_2`, date, optional): Enter any additional project deadline 2.
- **Project Notes 2** (`project_notes_2`, note, optional): Enter any additional project notes 2.
