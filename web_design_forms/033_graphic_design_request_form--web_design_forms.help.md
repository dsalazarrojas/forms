# Graphic Design Request Form - Help Guide
## Purpose
This form is used to request new graphic design projects from the design team. It should be filled out to initiate a new project, providing essential details about the project requirements. 

## How To Complete This Form
To ensure a smooth design process, please follow these steps:
1. Enter the Project Manager's name to ensure the project gets assigned to the right person.
2. Provide the Company name and its relevant details.
3. Enter a brief Description of the project, including its objectives and goals.
4. Specify the Project Name for the project.
5. Choose the Asset Type for the project, such as logo, banner, or social media graphic.
6. Select the required Color Scheme for the project.
7. Enter the Size of the design in pixels or inches.
8. If necessary, specify the Resolution of the design (e.g., 300 DPI).
9. Choose the File Format for the design, such as PNG, JPEG, or PDF.
10. Set a Deadline for the project, including the date when the design should be completed.
11. Enter a Budget for the project, in dollars or other currency.
12. Select the Asset Files needed for the project, such as images, logos, or other assets.
13. Enter any additional Comments about the project.
14. (Optional) Enter the name of the designer you would like to assign to the project.

## Field-by-Field Explanation
- **Project Manager** (required): Enter the name of the project manager, this will ensure the project gets assigned to the right person.
- **Company** (optional): Enter the name and details of the company or client.
- **Description** (optional): A brief description of the project, including its objectives and goals.
- **Project Name** (required): Enter a unique name for the project.
- **Asset Type** (optional): Choose the type of asset needed, such as logo, banner, or social media graphic.
	+ **Asset Types**: 
		+ Logo
		+ Banner
		+ Brand
		+ Social media
		+ Event poster
		+ Promotional material
		+ Illustration
		+ Other
- **Color Scheme** (required): Select the color scheme that will be used in the design.
	+ **Primary**: Main color scheme of the project.
	+ **Secondary**: Alternate color scheme for contrast or emphasis.
	+ **Accent**: Additional accent colors for highlight.
	+ **Background**: Background colors.
	+ **Custom**: Enter custom color scheme (not predefined colors).
- **Size** (optional): Enter the size of the design in pixels or inches.
- **Resolution** (optional): If necessary, specify the resolution of the design (e.g., 300 DPI).
- **File Format** (required): Choose the file format for the design, such as PNG, JPEG, or PDF.
	+ **PNG**: Portable Network Graphics file format.
	+ **JPEG**: Joint Photographic Experts Group file format.
	+ **GIF**: Graphics Interchange Format file format.
	+ **SVG**: Scalable Vector Graphics file format.
	+ **PDF**: Portable Document Format file format.
- **Deadline** (optional): Set a deadline for the project completion.
- **Budget** (optional): Enter the budget for the project.
- **Asset Files** (required): Select the files needed for the project.
	+ **File 1**
	+ **File 2**
	+ **File 3**
- **Comments** (optional): Additional comments about the project.
- **Assigned Designer** (optional): If you'd like to assign the project to a specific designer, enter their name.
