# Website Update Request Form - Help Guide
## Purpose
This form is for requesting updates to the website. It is intended for internal use, so please ensure that your request is relevant and not a duplicate.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter a brief description of the website update request in the **"Website Update Request"** field.
2. Provide additional information about the request in the **"Additional Information"** field.
3. Indicate if the change requires updates to the website's functionality or content in the **"Website Changes"** field. Select 'Yes' if the change is required, and 'No' otherwise.
4. If there are any specific notes or details you would like to share with the web development team, please provide them in the **"Notes"** field.

## Field-by-Field Explanation
* **"Website Update Request"**: A brief description of the website update request. Please provide a clear and concise explanation of the required changes.
* **"Additional Information"**: Provide any additional context or information that will help the web development team understand the request.
* **"Website Changes"**: Indicate if the change requires updates to the website's functionality or content. Select 'Yes' if the change is required, and 'No' otherwise.
* **"Notes"**: Any specific notes or details you would like to share with the web development team.
