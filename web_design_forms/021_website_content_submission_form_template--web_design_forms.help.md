# website_content_submission_form_template - Help Guide
## Purpose
This form is used to collect and manage submissions of website content from contributors.

## How To Complete This Form
To complete this form, please follow these steps:

1. Enter the **title** of the content in the text field provided.
2. Provide a brief **description** of the content.
3. Enter the **URL** associated with the content.
4. Tag the content with relevant keywords or **tags**.
5. Select the **category** of the content (e.g., Web Design, UI/UX, Web Development).
6. Choose the **status** of the content (e.g., Draft, Published, Archived).
7. If applicable, add the **author** who contributed the content.
8. Enter the **email** of the contributor.
9. Optionally, add the **phone** number of the contributor.
10. Provide the **date** the content was submitted.
11. Select the **time** the content was submitted.
12. Enter the content **body** in the text area provided.
13. If necessary, add a file attachment to the content.
14. Add any additional **notes** about the content.
15. Select the **submitted_by** contributor (choose one or multiple options).
16. Select the **created_by** contributor (choose one option).
17. Enter the **submitted** date and time.
18. Select the **submitted_time** of the content (choose one option).

## Field-by-Field Explanation

* **title** (text): Enter a brief title for the content.
* **description** (text): Provide a brief description of the content.
* **url** (text): Enter the URL associated with the content.
* **tags** (text): Tag the content with relevant keywords or phrases.
* **category** (select_one): Select the category of the content (e.g., Web Design, UI/UX, Web Development).
* **status** (select_one): Choose the status of the content (e.g., Draft, Published, Archived).
* **author** (text): If applicable, add the author who contributed the content.
* **email** (email): Enter the email of the contributor.
* **phone** (text): Optionally, add the phone number of the contributor.
* **date** (date): Provide the date the content was submitted.
* **time** (time): Select the time the content was submitted.
* **content** (text): Enter the content body in the text area provided.
* **file** (text): If necessary, add a file attachment to the content.
* **note** (note): Add any additional notes about the content.
* **note_label** (text): Enter a label for the note.
* **note_hint** (text): Enter a hint for the note.
* **note_required** (text): Enter a required note.
* **note_hint_2** (text): Enter a second hint for the note.
* **submitted_at** (date): Provide the submitted date of the content.
* **updated_at** (date): Enter the updated date of the content.
* **created_at** (date): Enter the created date of the content.
* **submitted_by** (select_multiple): Select the contributor(s) who submitted the content.
* **created_by** (select_one): Select the contributor who created the content.
* **submitted** (text): Enter the submitted date and time.
* **submitted_time** (time): Select the submitted time of the content.
