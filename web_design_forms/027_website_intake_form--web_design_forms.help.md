This guide will help you complete the Website Intake Form. The form is designed to collect essential information about new website projects. It is intended for clients to provide details about their website requirements, so our development team can create a tailored solution for them.
To complete the form, follow these steps:

1.  Enter your **User Name** in the text field. This is the name of the client who will be using our services.
2.  Enter your email address in the **Email** field. This should be a valid email address that we can use to contact you.
3.  Provide the **Website URL** of your existing website or the URL where you would like your new website to be hosted.
4.  Enter the **Project Name** of your website project.
5.  Choose the **Development Platform** of your website project (if you know what that is).
6.  Select the **Website Type** that best describes your project (E-commerce, Blog, Brochure, or Portfolio).
7.  Enter the **Budget** for your project (if you have a specific budget in mind).
8.  If you have a specific **Deadline** for the project, please enter it.
9.  Select the **Priority** of your project (High, Medium, or Low).
10. Enter any **Additional Info** about your project.
11. Optionally, add a **Project Description** to provide more context about your project.
12. If you have **Contact Info** that would be helpful, please provide it.
13. If you would like to **Chat with the Development Team**, select the relevant options.
14. If you would like to use a specific **Assigned Tool**, select from the available options.
15. If you would like to indicate the **Project Status**, select from the available options.
16. You can add any **Notes** about your project.
17. You can add **Tags** to your project to help our team track it better.

# Website Intake Form - Help Guide
## Purpose
The form is designed to collect essential information about new website projects so our development team can create a tailored solution for the client.
## How To Complete This Form
To complete the form, follow the steps outlined above.
## Field-by-Field Explanation
* **User Name (Text, Required)**: Enter your name.
* **Email (Email, Optional)**: Enter your email address.
* **Website URL (Text, Required)**: The URL of your existing website or where you would like your new website to be hosted.
* **Project Name (Text, Required)**: Enter the name of your project.
* **Development Platform (Text, Optional)**: If you know what that is, enter it.
* **Website Type (Select One, Required)**: Choose the type that best describes your project (E-commerce, Blog, Brochure, or Portfolio).
* **Budget (Text, Optional)**: Enter your budget if you have a specific one.
* **Deadline (Date, Optional)**: If you have a specific deadline for the project.
* **Priority (Select One, Required)**: Select the priority of your project (High, Medium, or Low).
* **Additional Info (Text, Optional)**: Enter any additional information about your project.
* **Project Description (Note, Optional)**: Provide more context about your project.
* **Contact Info (Text, Optional)**: If you have contact info that would be helpful.
* **Chat with Development Team (Select Multiple, Required)**: Select the options that apply to you.
* **Assigned Tool (Select One, Optional)**: If you would like to use a specific tool.
* **Project Status (Select One, Optional)**: If you would like to indicate the status of your project.
* **Notes (Note, Optional)**: Add any notes about your project.
* **Tags (Select Multiple, Optional)**: Add tags to help our team track your project better.
