# CCTV System Scoping Form - Help Guide
## Purpose
The CCTV System Scoping Form is a tool designed to gather essential information from clients to ensure that a comprehensive security solution is provided to meet their project requirements.

## How To Complete This Form
To complete this form, please follow these steps:

1. Provide a brief overview of your project, including the project name and site address.
2. Specify the type of site (residential, commercial, industrial, etc.) and provide an estimated total number of cameras required.
3. Determine the indoor/outdoor camera split ratio and minimum resolution requirements.
4. Decide on the required footage retention period, remote access needs, and night vision capabilities.
5. Choose your current network infrastructure status and audio recording needs.
6. Establish a target budget range and desired installation timeline.
7. If necessary, provide any additional technical requirements or constraints.
8. Finally, identify the contact person for the project.

## Field-by-Field Explanation
* **Project Name**: Please enter the name of your project.
	+ Type: `text`
	+ Required: `true`
* **Site Installation Address**: Enter the exact address of the site where the system will be installed.
	+ Type: `text`
	+ Required: `true`
* **Type of Site**: Choose the type of site that best describes your project.
	+ Options: `Residential`, `Commercial/Retail`, `Industrial/Warehouse`, `Public Space`, `Educational Institution`
	+ Required: `true`
* **Estimated Total Number of Cameras**: Provide an estimated total number of cameras required for your project.
	+ Type: `number`
	+ Required: `true`
* **Indoor vs Outdoor Camera Ratio**: Specify the split ratio of indoor to outdoor cameras (e.g., 50/50).
	+ Type: `text`
	+ Required: `true`
* **Minimum Resolution Required**: Choose the minimum resolution required for your project.
	+ Options: `2MP (1080p)`, `4MP (2K)`, `8MP (4K)`, `Special (Thermal/PTZ)`
	+ Required: `true`
* **Required Footage Retention (Days)**: Select the required footage retention period for your project.
	+ Options: `7 Days`, `14 Days`, `30 Days`, `60 Days`, `90 plus Days`
	+ Required: `true`
* **Is Remote Mobile/Web access required?**: Choose whether you need remote access to the system via mobile or web.
	+ Options: `True`, `False`
	+ Required: `true`
* **Night Vision/Low Light Requirements**: Determine the night vision capabilities required for your project.
	+ Options: `Standard IR`, `Full Color Night Vision`, `Not Required`
	+ Required: `true`
* **Current Network Infrastructure**: Choose your current network infrastructure status.
	+ Options: `New Installation (No network)`, `Existing PoE Network`, `Existing Analog Cabling`, `Wireless/WiFi Focus`
	+ Required: `true`
* **Is Audio Recording Required?**: Determine if audio recording is required for your project.
	+ Options: `True`, `False`
	+ Required: `true`
* **Target Project Budget Range**: Establish your target budget range for the project.
	+ Options: `Under $2,500`, `$2,500 - $5,000`, `$5,000 - $10,000`, `$10,000 plus`
	+ Required: `true`
* **Desired Installation Timeline**: Choose your desired installation timeline.
	+ Options: `Immediate (within 2 weeks)`, `Within 1 Month`, `1-3 Months`, `Planning Phase only`
	+ Required: `true`
* **Other Technical Requirements or Constraints**: If applicable, provide any additional technical requirements or constraints.
	+ Type: `text`
	+ Required: `false`
* **Project Contact Person**: Identify the contact person for the project.
	+ Type: `text`
	+ Required: `true`
