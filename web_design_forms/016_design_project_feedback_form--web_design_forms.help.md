# Design Project Feedback Form - Help Guide
## Purpose
The Design Project Feedback Form is a crucial tool for collecting feedback from users on a specific project. By providing feedback, users can help improve the project, and we appreciate your input. This guide will help you complete the form accurately and effectively.

## How To Complete This Form
To complete this form, follow these steps:
1. Fill in the **Project Name** field with the name of the project you are providing feedback on.
2. Answer the **Feedback Question**, which is where you can describe your experience with the project.
3. Provide an **Overall Rating**, if you wish, on a scale of 1-5.
4. Type in your **Feedback Comments** if you have specific points you'd like to make about the project.
5. Enter your **Email** address if you want to be contacted for follow-up questions or for more information.
6. Select the **Feedback Category** that best describes your feedback.
7. Choose the **Feedback Subcategory** that best matches your feedback (if applicable).
8. Leave **Date Created** and **Date Updated** fields blank, as they are for internal use only.

## Field-by-Field Explanation
- **Project Name** (`project_name`, text, required): Enter the name of the project you are providing feedback on.
  • This is the name of the project that you want to give feedback on.
  • For example, "My Awesome Project".
- **Feedback Question** (`feedback_question`, text, required): Answer this question, describing your experience with the project.
  • Describe your experience, thoughts, and feelings about the project.
  • Be as detailed as possible to help us understand your feedback.
- **Overall Rating** (`overall_rating`, number, optional): Rate the project on a scale of 1-5.
  • This rating will help us understand the general quality of the project.
  • If you're unsure, you can leave it blank.
- **Feedback Comments** (`feedback_comments`, note, optional): Add any specific points or comments about the project.
  • Share your thoughts and ideas about the project.
  • If you have something specific to say, this is the field to do it in.
- **Email** (`email`, email, required): Enter your email address if you want to be contacted for more information.
  • This is the email address we will use to get in touch with you.
  • Make sure it's correct for our follow-up questions.
- **Phone Number** (`phone_number`, text, optional): If you'd like to be contacted via phone, enter your number here.
  • Only enter your phone number if you'd like to be contacted via phone.
  • Otherwise, leave it blank.
- **Feedback Category** (`feedback_category`, select_one, required): Choose the category that best describes your feedback.
  • Select the category that best describes your feedback (e.g., positive, negative, neutral).
- **Feedback Subcategory** (`feedback_subcategory`, select_multiple, optional): Choose the subcategory that best describes your feedback (if applicable).
  • Select the subcategory that best describes your feedback (e.g., feature, design, functionality).
  • If not applicable, leave it blank.
- **Date Created** (`date_created`, date, optional): This field is for internal use only.
  • Do not fill this in as a user.
  • We will fill this out automatically.
- **Date Updated** (`date_updated`, date, optional): This field is for internal use only.
  • Do not fill this in as a user.
  • We will fill this out automatically.

## Tips
* Please be as specific and detailed as possible when filling out the form.
* If you're unsure about a field, leave it blank and we'll follow up with you.
* This form is for feedback on a specific project, so only provide feedback on that project. 
* If you have any issues or concerns about the project, contact us directly.
* We value your feedback and appreciate your input.
