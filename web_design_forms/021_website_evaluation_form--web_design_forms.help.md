# Website Evaluation Form - Help Guide

## Purpose
This form is used to evaluate a website's performance in various categories to ensure it meets the required standards and quality.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the website's title in the "Website Title" field.
2. Enter the website's URL in the "Website URL" field.
3. Evaluate the website's overall quality, user experience, web design, navigation, content, layout, mobile-friendliness, and speed.
4. Choose whether the website is mobile-friendly or not in the "Mobile Friendly" field.
5. Enter any additional feedback in the "Additional Feedback" field (optional).

## Field-by-Field Explanation

* **Website Title** (`website_title`, text, required): Enter the title of the website.
* **Website URL** (`website_domain`, text, required): Enter the URL of the website.
* **Overall Quality** (`overall_quality`, number, required): Rate the overall quality of the website (e.g., 1-10).
* **User Experience** (`user_experience`, number, required): Rate the user experience of the website (e.g., 1-10).
* **Web Design** (`web_design`, number, required): Rate the web design of the website (e.g., 1-10).
* **Navigation** (`navigation`, number, required): Rate the navigation of the website (e.g., 1-10).
* **Content** (`content`, number, required): Rate the content of the website (e.g., 1-10).
* **Layout** (`layout`, number, required): Rate the layout of the website (e.g., 1-10).
* **Mobile Friendly** (`mobile_friendly`, select_one, required): Choose whether the website is mobile-friendly or not.
* **Speed** (`speed`, number, required): Rate the speed of the website (e.g., 1-10).
* **Security** (`security`, number, required): Rate the security of the website (e.g., 1-10).
* **User Experience 2** (`user_experience_2`, text, optional): Enter any additional feedback about the user experience.
* **Additional Feedback** (`feedback`, text, optional): Enter any additional feedback about the website.

## Tips
* Be as specific as possible when evaluating each category.
* Use the rating scale provided (e.g., 1-10) to ensure consistency.
* Enter any additional feedback that may not be covered by the provided categories.
