# scc_website_feedback - Help Guide
## Purpose

The purpose of this form is to collect feedback from users on the quality of the website. This feedback will help us improve the website and services offered.

## How To Complete This Form

To complete this form, follow these steps:

1. Click on the "Rate Our Website" field and select a rating from 1 to 5.
2. Enter a score for the website in the "Rate Our Website Score" field.
3. In the "Feedback" field, type any comments or suggestions you have about the website.
4. If you have any additional comments, you can type them in the "Comments" field.
5. If you have any contact information, you can provide it in the "E-mail" and "Phone" fields.
6. If you have a name, you can provide it in the "Name" field.
7. Finally, click the "Submit" button to send your feedback.

## Field-by-Field Explanation

* **Rate Our Website** (1): Select a rating for the quality of the website.
* **Rate Our Website Score** (1): Enter a score for the website.
* **Feedback** (1): Type any comments or suggestions you have about the website.
* **Comments** (1): Type any additional comments you have.
* **E-mail** (1): If you have a preferred email address to reach you, enter it here.
* **Phone** (1): If you have a preferred phone number to reach you, enter it here.
* **Name** (1): If you have a name you'd like to be associated with your feedback, enter it here.
* **Submit** (1): Click to send your feedback to us.
