## page_not_found_feedback_form - Help Guide
## Purpose
The "page_not_found_feedback_form" is designed to collect feedback about page not found issues on the web. This form helps us understand where users encountered the problem and provides an opportunity for users to give us feedback on their experience.

## How To Complete This Form
1. Fill in the page number where you encountered the problem (Page Not Found).
2. Provide any relevant information about the link that led to the "Page Not Found" error (Page Link).
3. Select all that apply from the options for "How did it happen".
4. Choose the link that you clicked when the "Page Not Found" error occurred (Which link).
5. Type a brief description of what to fix in the "What to fix" field.
6. If you have any additional comments or suggestions, type them in the "Feedback" field.
7. Enter your email address in the "Email" field (this is not required, but helps us contact you if we need further information).

## Field-by-Field Explanation
* **Page Not Found** (`page_not_found`, text, not required): This field is for entering the page number where you encountered the "Page Not Found" error.
* **Page Link** (`page_link`, text, not required): This field is for entering any relevant information about the link that led to the "Page Not Found" error.
* **How did it happen** (`how_did_it_happen`, select_multiple, not required): This field is for selecting all that apply from the available options: "404 error", "broken link", or "non-existent page".
* **Which link** (`which_link`, select_one, not required): This field is for choosing the link that you clicked when the "Page Not Found" error occurred.
* **What to fix** (`what_to_fix`, text, not required): This field is for entering a brief description of what to fix in the "Page Not Found" issue.
* **Feedback** (`feedback`, text, not required): This field is for entering any additional comments or suggestions you have about your experience with the "Page Not Found" issue.
* **Email** (`email`, email, not required): This field is for entering your email address, which helps us contact you if we need further information.

## Tips
* Please be as specific as possible when entering the page number and link.
* If you have any additional information, such as browser or device type, please include it in the "Feedback" field.
* If you don't have an email address, you can leave this field blank.
* We appreciate your help in improving our web services!
