# Rate My Website Form - Help Guide
## Purpose
This form is designed to gather user feedback and improve the website's design and functionality.

## How To Complete This Form
To complete this form, follow these steps:

1. Choose the rating for the website by selecting one of the options on "Rate My Website" page.
2. Select all the features that you like about the website on "What do you like about our website?" page.
3. Select all the features that you dislike about the website on "What do you dislike about our website?" page.
4. Describe your experience with the website on "How would you describe your experience with our website?" page.
5. Select all the features that you liked about the website on "What did you like about our website?" page.

## Field-by-Field Explanation
### Rate My Website (Page 1)
* **Rate My Website** (`Rate My Website Form`, `select_one`, required: false): Select a rating for the website, indicating how good or bad you think it is.

* **How would you rate our website?** (`rate_my_website_form_page_2`, `select_one`, required: false): Select a rating from 1 to 5, indicating how good or bad you think the website is.

### What do you like about our website? (Page 3)
* **What do you like about our website?** (`rate_my_website_form_page_3`, `select_multiple`, required: false): Select all the features that you like about the website.

### What do you dislike about our website? (Page 4)
