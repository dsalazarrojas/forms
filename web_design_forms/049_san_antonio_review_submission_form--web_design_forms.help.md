# San Antonio Review Submission Form - Help Guide
## Purpose
This form is designed for users to submit reviews or ratings about a specific topic, allowing them to provide feedback, rate, or evaluate a submission. The form captures relevant information about the submission, including its title, author, date, and status.

### How To Complete This Form
To complete this form, follow these steps:
1. Review the submission form carefully and ensure it is relevant to the topic you are submitting about.
2. Check that the submission form is not a duplicate, ensuring that you are not submitting the same review or rating twice.
3. Fill in the required fields, starting with the submission form, and select the submission type as 'Yes' or 'No'.
4. Enter the title of the submission.
5. Provide the author's name and email (if applicable).
6. Select the submission category and year published.
7. Enter any relevant URLs, descriptions, keywords, and tags.
8. Add any attachments or files related to the submission.
9. Provide the submission status and date.
10. Enter the editor's name and select whether they have reviewed the submission.
11. Optionally, select any tags related to the submission.

### Field-by-Field Explanation

* **Submission Form** (Text, Optional): Enter the submission form content.
* **Submission Type** (Select One, Optional):
	+ 'Yes': Select 'Yes' to indicate that the submission is available to be reviewed.
	+ 'No': Select 'No' to indicate that the submission is not available to be reviewed.
* **Title** (Text, Optional): Enter a short title for the submission.
* **Author** (Text, Optional): Enter the author's name.
* **Year Published** (Number, Optional): Enter the year the submission was published.
* **URL** (Text, Optional): Enter the submission URL (if applicable).
* **Description** (Text, Optional): Enter a brief description of the submission.
* **Keywords** (Text, Optional): Enter relevant keywords related to the submission.
* **Tags** (Text, Optional): Enter any tags related to the submission.
* **Files** (Text, Optional): Enter any files related to the submission.
* **Notes** (Note, Optional): Enter any additional notes or comments about the submission.
* **Date** (Date, Optional): Enter the date of the submission.
* **Time** (Time, Optional): Enter the time of the submission.
* **Email** (Email, Optional): Enter the author's email (if applicable).
* **Phone** (Text, Optional): Enter the author's phone number (if applicable).
* **File** (Text, Optional): Enter any file related to the submission.
* **Attachment** (Text, Optional): Enter any attachment related to the submission.
* **Comment** (Text, Optional): Enter any comments about the submission.
* **Status** (Select One, Optional):
	+ 'Active': Select 'Active' to indicate that the submission is active.
	+ 'Inactive': Select 'Inactive' to indicate that the submission is inactive.
* **Author Email** (Email, Optional): Enter the author's email (if applicable).
* **Author URL** (Text, Optional): Enter the author's URL (if applicable).
* **Editorial Board** (Text, Optional): Enter any editorial board information related to the submission.
* **Editor** (Select One, Optional):
	+ 'Yes': Select 'Yes' to indicate that the editor has reviewed the submission.
	+ 'No': Select 'No' to indicate that the editor has not reviewed the submission.
* **Review** (Select Multiple, Optional):
	+ 'Yes': Select 'Yes' to indicate that the review has been completed.
	+ 'No': Select 'No' to indicate that the review has not been completed.

This guide is intended to help users understand the purpose and use of the San Antonio Review Submission Form. By following these steps, users can ensure that their submissions are properly filled out and submitted.
