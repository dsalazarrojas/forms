# wc_file_upload_form - Help Guide
## Purpose
The WC File Upload Form is a tool for uploading images and files, providing a structured way to collect essential metadata along with the uploaded content.

## How To Complete This Form
To complete this form, follow these steps:
1. **Upload image or file**: Select a file from your computer or device to upload. Supported file formats include JPG, PNG, GIF, and BMP.
2. **Add a note (Optional)**: If desired, provide a note for the uploaded file for further context or reference.
3. **Enter Recipient email**: Enter the email address to which you want to send the uploaded file.
4. **Select Upload Date and Time**: Choose the date and time you want the file to be uploaded.
5. **Specify File Size and Image Dimensions**: Enter the size of the uploaded file in bytes and the image dimensions in pixels (width and height).
6. **Choose File Type**: Select the file type from the dropdown menu (JPG, PNG, GIF, or BMP).

## Field-by-Field Explanation
* **Upload image**: Select a file from your computer or device for upload. Ensure it is in one of the supported formats (JPG, PNG, GIF, or BMP).
* **File note (Optional)**: A short description or note for the uploaded file, if you wish to provide additional context.
* **Recipient email**: Enter the email address of the person or department that should receive the file.
* **Upload date**: Choose the date for the file to be uploaded.
* **Upload time**: Choose the time for the file to be uploaded.
* **File size**: Enter the size of the uploaded file in bytes.
* **Image width**: Enter the width of the uploaded image in pixels.
* **Image height**: Enter the height of the uploaded image in pixels.
* **File type**: Select the format of the uploaded file from the dropdown menu (JPG, PNG, GIF, or BMP).
