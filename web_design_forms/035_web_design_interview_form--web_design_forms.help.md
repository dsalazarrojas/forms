# web_design_interview_form - Help Guide
## Purpose
The web design interview form is designed to gather information about web design projects. It collects essential details such as project name, description, deadline, budget, and other specific requirements. This form helps in organizing and categorizing projects, facilitating a smooth and efficient web design process.

## How To Complete This Form
To complete this form, follow these steps:
1. Provide the project name in the "Project Name" field.
2. Enter a brief description of the project in the "Project Description" field.
3. Enter the project deadline in the "Project Deadline" field in the required format.
4. Enter the project budget in the "Project Budget" field.
5. Select the project status from the "Project Status" dropdown.
6. Choose the design systems that apply to the project from the "Design System" dropdown. You can select multiple options.
7. Select the color scheme for the project from the "Color Scheme" dropdown. You can select multiple options.
8. Choose the font family for the project from the "Font Family" dropdown. You can select multiple options.
9. Select the project manager responsible for the project from the "Project Manager" dropdown.

## Field-by-Field Explanation

* **Project Name** (`Project Name`, text, required/optional): Enter the name of the web design project.
* **Client Name** (`client_name`, text, required/optional): Enter the name of the client.
* **Website URL** (`website_url`, text, required/optional): Enter the URL of the website.
* **Project Description** (`project_description`, text, required/optional): Enter a brief description of the project.
* **Project Deadline** (`project_deadline`, date, required/optional): Enter the deadline for the project in a date format.
* **Project Budget** (`project_budget`, number, required): Enter the budget for the project.
* **Project Scope** (`project_scope`, text, required/optional): Enter the scope of the project.
* **Project Status** (`project_status`, select_one, required): Select the status of the project (Active or Inactive).
* **Design System** (`design_system`, select_multiple, required): Select the design system(s) used for the project (Materialize, Tailwind, Bootstrap).
* **Color Scheme** (`color_scheme`, select_multiple, required): Select the color scheme(s) used for the project (Dark, Light, Pastel).
* **Font Family** (`font_family`, select_multiple, required): Select the font family used for the project (Arial, Times New Roman, Open Sans).
* **Project Manager** (`project_manager`, select_one, required): Select the project manager (Designer, Developer, Manager).
