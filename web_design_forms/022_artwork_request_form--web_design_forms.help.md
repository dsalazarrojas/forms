# Artwork Request Form - Help Guide
## Purpose
The Artwork Request Form is used to collect essential information from clients for a specific artwork request. This form will guide us in creating a custom artwork that meets the client's needs and preferences.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill out all required fields (*required* fields will be marked as such).
2. Select your preferred artistic style from the options provided.
3. Specify the required file formats for the artwork.
4. Enter the target dimensions for the artwork.
5. Describe how the artwork will be used.
6. Choose a hard deadline for the project.
7. If applicable, enter the maximum budget for the project.
8. Add any additional instructions or reference links.

## Field-by-Field Explanation

### Client Name (`client_full_name_req`)
* A text field for the client's name.

### Project Name (`project_name_req`)
* A text field for the project's name.

### Preferred Artistic Style (`style_preference`)
* A dropdown menu to select from options: 
  * Minimalist and Clean
  * Bold and Graphic
  * Retro/Vintage
  * Hand-drawn/Organic
  * High-tech/Modern

### Color Palette Preferences (`color_palette_notes`)
* A text field for listing specific hex codes or general colors.

### Required File Formats (`file_formats_needed`)
* A dropdown menu to select from:
  * PNG - Transparent background
  * SVG - Vector
  * JPEG - Standard image
  * AI/PSD - Source files
  * PDF - For print

### Target Dimensions (`final_dimensions_req`)
* A text field for specifying the dimensions, e.g., 1080x1080px or 8.5x11 inches.

### How Will This Artwork Be Used (`use_case_description`)
* A text field for describing how the artwork will be used, e.g., website header, social media ad, billboard.

### Hard Deadline (`project_deadline_req`)
* A date field for entering the hard deadline for the project.

### Maximum Budget for Project (`budget_limit_req`)
* A numeric field for entering the maximum budget for the project in USD.

### Additional Instructions or Inspiration Links (`additional_req_notes`)
* A text field for adding any additional instructions or reference links.
