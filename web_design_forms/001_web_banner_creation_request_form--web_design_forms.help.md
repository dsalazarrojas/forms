# Web Banner Creation Request Form - Help Guide
## Purpose
This form is used to request the creation of a web banner with specific details and options.

## How To Complete This Form
To complete this form, follow these steps:
1. Enter the title of the banner you want to create.
2. Select the type of banner you need.
3. Choose the size of the banner.
4. Select the color scheme for the banner.
5. Choose the font scheme for the banner.
6. Enter a brief description of the banner.
7. Set the deadline for the banner.
8. Upload the banner image.
9. Select the options for submission.
10. Provide any additional comments about the banner.
11. Enter your contact email and phone number.
12. Choose whether to use your email and phone number.
13. Enter the time for the banner creation.
14. Enter any notes about the banner.
15. Select the assigned tool for the banner creation.
16. Enter the category for the banner.
17. Enter a brief description of the banner.
18. Enter the output file for the banner.
19. (Optional) Enter any additional comments about the form.
20. (Optional) Enter the form ID and the person assigned to the banner.

## Field-by-Field Explanation
* **Title** (`1`, `text`, required): Enter a brief title for the banner.
* **Form Type** (`2`, `select_one`, required): Select the type of banner you need (e.g., Banner).
* **Banner Size** (`3`, `select_multiple`, required): Choose the size of the banner (e.g., Small, Medium, Large).
* **Color Scheme** (`4`, `select_one`, required): Select the color scheme for the banner (e.g., Blue, Red, Green).
* **Font Scheme** (`5`, `select_multiple`, required): Choose the font scheme for the banner (e.g., Arial, Helvetica, Times New Roman).
* **Description** (`6`, `text`, required): Enter a brief description of the banner.
* **Deadline** (`7`, `date`, required): Set the deadline for the banner creation.
* **Banner Image** (`8`, `text`, required): Upload or enter the banner image.
* **Submit** (`9`, `select_one`, required): Select the options for submission (e.g., Submit).
* **Additional Comments** (`10`, `select_multiple`, optional): Enter any additional comments about the banner.
* **Email** (`12`, `email`, required): Enter your contact email.
* **Phone** (`13`, `text`, required): Enter your contact phone number.
* **Use Email/Phone** (`14`, `select_one`, optional): Choose whether to use your email and phone number.
* **Time** (`15`, `time`, required): Enter the time for the banner creation.
* **Notes** (`16`, `note`, optional): Enter any notes about the banner.
* **Assigned Tool** (`17`, `text`, required): Select the assigned tool for the banner creation.
* **Category** (`18`, `text`, required): Enter the category for the banner.
* **Description** (`19`, `text`, required): Enter a brief description of the banner.
* **Output File** (`20`, `text`, required): Enter the output file for the banner.
* **Form ID** (`21`, `text`, optional): (Optional) Enter the form ID.
* **Assigned To** (`22`, `text`, optional): (Optional) Enter the person assigned to the banner.
* **Assigned User** (`23`, `text`, optional): (Optional) Enter the person assigned to the banner.
* **Form Comments** (`24`, `text`, optional): (Optional) Enter any comments about the banner.
* **Form Notes** (`25`, `text`, optional): (Optional) Enter any notes about the form.

## Tips
* Make sure to complete all required fields before submitting the form.
* Double-check your information for accuracy.
* Ensure that the banner details are clear and concise.
* Use the provided examples to guide your selections.
* If you have any questions or need further assistance, contact the assigned person or tool.
