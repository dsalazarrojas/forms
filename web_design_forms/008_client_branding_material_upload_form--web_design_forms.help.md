# Client Branding Material Upload Form - Help Guide
## Purpose
This form is designed to collect branding material from clients for the project. It will help us understand your project requirements, asset types, and priority level to ensure timely completion.

## How To Complete This Form
1. Fill out all required fields marked as required.
2. Select all applicable options for asset types and project details.
3. Upload relevant branding materials according to your project needs.
4. Confirm that you have the rights to share these assets.

## Field-by-Field Explanation

* **First Name** (`client_first_name`, text, required): Your legal first name.
* **Last Name** (`client_last_name`, text, required): Your legal last name.
* **Email Address** (`client_email`, email, required): Your primary contact email.
* **Phone Number** (`client_phone`, text, required): Your best contact number.
* **Company Name** (`company_name`, text, required): Your company's legal business name.
* **Project Name** (`project_name`, text, required): The name or reference for this project.
* **Project Type** (`project_type`, select_one, required): Select the type of project this is (e.g., Website Redesign, Brand Refresh, New Brand Launch).
* **Asset Type Being Uploaded** (`asset_type`, select_one, required): Select the category of branding materials you are uploading (e.g., Logo Files, Brand Guidelines, Color Palettes).
* **File Formats Included** (`file_format`, select_multiple, required): Select all applicable file formats (e.g., AI, EPS, SVG, PNG, JPG, PDF).
* **Brand Colors** (`brand_colors`, text, optional): If available, provide hex codes for your brand's primary colors.
* **Brand Fonts** (`brand_fonts`, text, optional): If known, provide font names used in your brand's materials.
* **Logo Variations Included** (`logo_variations`, select_multiple, optional): Select all applicable logo variations (e.g., Primary Logo, Secondary Logo, Icon Only).
* **Are Usage Guidelines Included?** (`usage_guidelines`, select_one, required): Confirm if usage guidelines are provided or needed.
* **Number of Files** (`file_count`, number, required): Approximate count of the total files uploaded.
* **Total File Size** (`total_size`, select_one, required): Select the approximate combined size of the uploaded files.
* **Purpose of Upload** (`upload_purpose`, text, required): Explain the purpose of uploading these materials.
* **Project Deadline** (`deadline_date`, date, required): Provide the project deadline.
* **Priority Level** (`priority_level`, select_one, required): Select the urgency level of this project (e.g., Low - No Rush, Medium - Within 2 Weeks, High - Within 1 Week).
* **Are These Final Approved Assets?** (`brand_approval_status`, select_one, required): Confirm if the assets are final approved or not.
* **Do Any Assets Require Licensing?** (`third_party_assets`, select_one, required): Confirm if any assets require licensing or are original.
* **Special Instructions** (`special_instructions`, text, optional): Provide any specific requirements or instructions for this project.
* **I Confirm I Have Rights to Share These Assets** (`authorization_statement`, select_one, required): Confirm that you have the rights to share these assets.
* **Submission Date** (`submission_date`, date, required): The date these materials were submitted.
