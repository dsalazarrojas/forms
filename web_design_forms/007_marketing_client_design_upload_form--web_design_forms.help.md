# Marketing Client Design Upload Form - Help Guide
## Purpose
The Marketing Client Design Upload Form is used to collect information about marketing client designs from end-users. This information includes project details, file uploads, project description, designer details, date, email, phone number, and comments. This form helps the team gather all necessary details before processing and uploading the client design files.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the project details.
2. Select the file formats you want to upload (e.g., image, PDF, Word, Excel, or Presentation).
3. Enter a project description.
4. Provide the designer's name and details.
5. Enter the date the project is due or created.
6. Enter the email address and phone number of the contact person.
7. Add any additional comments about the project.

## Field-by-Field Explanation

* **project_details**: This field asks for a brief project description. Please enter a short text that summarizes the project.
* **upload_files**: Select the file formats you want to upload (e.g., image, PDF, Word, Excel, or Presentation).
* **project_description**: This field is for a more detailed project description. Please enter a text that describes the project in more detail.
* **designer**: Enter the name of the person who designed the project.
* **date**: Enter the date the project is due or created.
* **email**: Enter the email address of the contact person.
* **phone**: Enter the phone number of the contact person.
* **comments**: Add any additional comments about the project.
