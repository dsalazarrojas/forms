# flight_punctuality_statistics_report - Help Guide
## Purpose
The flight_punctuality_statistics_report form is designed to collect and analyze flight punctuality data to help airlines and transportation agencies track and monitor flight schedules, delays, and cancellations.

## How To Complete This Form

1. Select the flight category you wish to report on:
	* On-Time Flights: Choose between Arrival Flight, Scheduled Flight, or Flight Status to view statistics.
2. Enter flight specific information:
	* Flight ID: Enter the unique identifier for the flight.
	* Flight Number: Enter the flight number.
	* Airport Code: Enter the airport code.
	* Scheduled Departure: Enter the scheduled departure time.
	* Actual Departure: Enter the actual departure time.
	* Flight Duration: Enter the flight duration.
3. Report on flight punctuality:
	* On-Time Flights: Select the percentage of on-time flights.
	* Flights Canceled: Select the number of canceled flights.
	* Flights Delayed: Select the number of delayed flights.
4. Analyze flight performance:
	* On-Time Performance: Select the on-time performance metrics.
	* Average Delay Time: Select the average delay time.
	* Maximum Delay Time: Select the maximum delay time.
	* Total Flights: Enter the total number of flights.
	* On-Time Flights 2: Enter the number of on-time flights.
	* Flights Canceled 2: Enter the number of canceled flights.
	* Flights Delayed 2: Enter the number of delayed flights.
	* Average Delay: Enter the average delay time.
	* Maximum Delay: Enter the maximum delay time.
	* On-Time Rate: Enter the on-time rate.
	* Flights Canceled Rate: Enter the canceled rate.
