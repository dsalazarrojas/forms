# Ride Service Availability Issue Report Form - Help Guide
## Purpose
This form is designed for reporting issues related to ride services such as buses, trains, or flights. It helps our team track and address problems with these services, ensuring we can provide accurate information to riders and improve our services overall.

## How To Complete This Form
To complete this form, please follow these steps:

1. Provide a brief description of the issue you experienced with the ride service.
2. Enter the name of the ride service that was affected (e.g., "Bus").
3. Select the type of ride service that was affected (e.g., "Bus", "Train", or "Flight").
4. Enter the location where the issue occurred.
5. If the issue occurred, enter the start and end times.
6. Report the current status of the ride service (e.g., "On time", "Delayed", "Cancelled", or "Unknown").
7. Enter the date you are reporting the issue.
8. If you are a rider, enter your rider ID number.

## Field-by-Field Explanation

* **description**: Enter a brief description of the issue you experienced with the ride service.
* **service name**: Enter the name of the ride service that was affected (e.g., "Bus", "Train", or "Flight").
* **service type**: Select the type of ride service that was affected (e.g., "Bus", "Train", or "Flight").
* **location**: Enter the location where the issue occurred.
* **start time**: Enter the start time of the issue if it occurred. If not applicable, leave blank.
* **end time**: Enter the end time of the issue if it occurred. If not applicable, leave blank.
* **service status**: Report the current status of the ride service (e.g., "On time", "Delayed", "Cancelled", or "Unknown").
* **report date**: Enter the date you are reporting the issue.
* **rider id**: If you are a rider, enter your rider ID number. If not applicable, leave blank.

## Tips
Please be as detailed as possible when reporting the issue, and make sure to report the issue accurately.
