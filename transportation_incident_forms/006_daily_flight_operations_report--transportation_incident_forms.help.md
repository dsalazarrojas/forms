# Daily Flight Operations Report - Help Guide
## Purpose
The Daily Flight Operations Report is a form designed to gather and record daily flight operations data. This report helps track and analyze flight performance, providing valuable insights for flight operations management.

## How To Complete This Form
1. Ensure you have all the necessary information about the flight you are reporting.
2. Select the correct "Flight ID" from the list of available options.
3. Enter the actual "Time of Departure" and "Actual Time of Arrival" for the flight.
4. Provide the correct "Flight Status" by selecting one of the available options (Scheduled, Delayed, Cancelled, or Diverted).
5. If the flight was delayed, select the reason for delay from the list of available options (Weather, Air Traffic, Aircraft, or Other).
6. Enter the flight duration in the "Flight Duration" field.
7. Submit the form once you have filled out all the required and optional fields.

## Field-by-Field Explanation
* **Flight Operations**:
	+ This field is for free text input, providing a space to describe the flight operations.
	+ Please enter a brief description of the flight operations, including any notable events or issues.
* **Flight ID**:
	+ This field is a dropdown list of available flight IDs.
	+ Select the correct flight ID from the list.
* **Flight Number**:
	+ This field is for free text input.
	+ Please enter the flight number, if available.
* **Date of Operation**:
	+ This field is for inputting the date of the flight operation.
	+ Use the format MM/DD/YYYY.
* **Time of Departure**:
	+ This field is for inputting the scheduled time of departure.
	+ Use the format HH:MM AM/PM.
* **Actual Time of Departure**:
	+ This field is for inputting the actual time of departure.
	+ Use the format HH:MM AM/PM.
* **Time of Arrival**:
	+ This field is for inputting the scheduled time of arrival.
	+ Use the format HH:MM AM/PM.
* **Actual Time of Arrival**:
	+ This field is for inputting the actual time of arrival.
	+ Use the format HH:MM AM/PM.
* **Flight Duration**:
	+ This field is for inputting the flight duration.
	+ Enter the actual duration of the flight.
* **Flight Status**:
	+ This field is a dropdown list of available flight status options (Scheduled, Delayed, Cancelled, or Diverted).
	+ Select the correct flight status.
* **Reason for Delay**:
	+ This field is a dropdown list of available reason for delay options (Weather, Air Traffic, Aircraft, or Other).
	+ Select the reason for delay, if applicable.
* **Other**:
	+ This field is for inputting any other reason for delay not listed in the options above.
	+ Please enter the reason for delay.
