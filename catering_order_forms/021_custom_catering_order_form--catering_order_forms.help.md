# Custom Catering Order Form - Help Guide
## Purpose
The purpose of this form is to gather information for a custom catering order for special events.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the menu items you would like to order for your event.
2. Enter the number of guests attending the event.
3. Provide some details about the event, such as the occasion or any specific requests.
4. Choose a date and time for the event.
5. Enter your contact information so we can reach out to you with any questions or updates.
6. Enter your email address so we can send you any confirmations or updates.
7. Enter your phone number so we can contact you with any last-minute questions or updates.

## Field-by-Field Explanation
### 1. Select Menu (`menu_selections`, select_multiple, required: false)
* This field allows you to select the menu items you would like to order for your event. Please choose from the available options to select the items that fit your needs.

### 2. Guest Count (`guest_count`, number, required: false)
* This field is used to enter the number of guests attending the event. Please make sure to enter a whole number.

### 3. Event Details (`event_details`, text, required: false)
* This field is used to provide some details about the event, such as the occasion or any specific requests. Please provide as much information as possible.

### 4. Date (`date`, date, required: false)
* This field is used to choose a date for the event. Please select a date that fits your event schedule.

### 5. Time (`time`, time, required: false)
* This field is used to choose a time for the event. Please select a time that fits your event schedule.

### 6. Contact Information (`contact_info`, text, required: false)
* This field is used to enter your contact information so we can reach out to you with any questions or updates. Please make sure to enter your name and any other relevant contact details.

### 7. Email (`email`, email, required: false)
* This field is used to enter your email address so we can send you any confirmations or updates. Please make sure to enter a valid email address.

### 8. Phone (`phone`, text, required: false)
* This field is used to enter your phone number so we can contact you with any last-minute questions or updates. Please make sure to enter a valid phone number.

# Tips
* Please make sure to fill in all required fields and provide accurate information to avoid any issues with the order.
* If you have any questions or concerns, please don't hesitate to contact us.
* We appreciate your feedback and suggestions to improve our service!
