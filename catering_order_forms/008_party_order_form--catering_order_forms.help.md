# Party Order Form - Help Guide
## Purpose
The Party Order Form is a form used to collect information about a party, including party details, guests, date, time, package details, services, location, and notes. This information will help the catering team prepare for and execute the party successfully.

## How To Complete This Form
To complete this form, follow the steps below:

1. Enter the party details, including the party name and any relevant information.
2. Select the number of guests attending the party.
3. Choose the party date and time.
4. Select the package details and any additional services required.
5. Choose the party location and any additional services required.
6. Enter the party price and any other relevant details.

## Field-by-Field Explanation
* **Party Details** (`party_details`, text, required): Enter the name and any other relevant information about the party.
* **Party Guests** (`party_guests`, number, optional): Enter the number of guests attending the party.
* **Party Date** (`party_date`, date, optional): Enter the date of the party.
* **Party Time** (`party_time`, text, optional): Enter the time of the party.
* **Package Details** (`package_details`, text, optional): Enter any additional information about the package chosen.
* **Package Services** (`package_services`, select multiple, optional): Select any additional services required for the party.
* **Package Services List** (`package_services_list`, select multiple, optional): Select any additional services required for the party.
* **Package Price** (`package_price`, number, optional): Enter the price of the package chosen.
* **Party Location** (`party_location`, select one, optional): Choose the location of the party.
* **Party Location List** (`party_location_list`, select one, optional): Choose the location of the party.
* **Additional Services** (`party_services_1`, select multiple, optional): Select any additional services required for the party.
* **Additional Services List** (`party_services_1_list`, select multiple, optional): Select any additional services required for the party.
* **Party Price** (`party`, number, optional): Enter the price of the party.
* **Party Location 1** (`party_location_1`, select one, optional): Choose the location of the party.
* **Party Location 1 List** (`party_location_1_list`, select one, optional): Choose the location of the party.
* **Package Price 1** (`package_price_1`, number, optional): Enter the price of the package.
* **Party Notes** (`party_notes`, note, optional): Enter any additional notes about the party.
* **Services** (`package_services_2`, select multiple, optional): Select any additional services required for the party.

## Tips
* Make sure to fill in all required fields to ensure accurate and efficient execution of the party.
* Double-check the party details to ensure accuracy.
* If you have any questions or concerns, contact the catering team for assistance.
