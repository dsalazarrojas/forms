# Amul Order Form - Help Guide
## Purpose
The Amul Order Form is used to collect order information from customers, including customer details, delivery details, product preferences, and payment information. This form helps in processing and confirming the orders.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the required fields as per the form.
2. Fill up all the fields marked as "required" in the form.
3. Select the desired options for each field as per the form options.

## Field-by-Field Explanation
* **Order Date** (id: 2, required: true): Enter the date of the order in the format MM/DD/YYYY.
* **Order Number** (id: 3, required: false): This field is for office use, please do not fill up this field.
* **Customer Name** (id: 5, required: true): Enter the customer's name.
* **Customer Type** (id: 6, required: true): Select the type of customer, either Individual, Retailer, Restaurant, Hotel, Institution, Distributor, or Other.
* **Contact Person** (id: 7, required: false): Enter the contact person's name.
* **Email Address** (id: 8, required: true): Enter the customer's email address for order confirmation.
* **Phone Number** (id: 9, required: true): Enter the customer's phone number.
* **Delivery Address** (id: 11, required: true): Enter the full street address for delivery.
* **City** (id: 12, required: true): Enter the city name.
* **State** (id: 13, required: true): Enter the state name.
* **ZIP/PIN Code** (id: 14, required: true): Enter the zip or pin code.
* **Requested Delivery Date** (id: 15, required: true): Enter the requested delivery date in the format MM/DD/YYYY.
* **Preferred Delivery Time** (id: 16, required: false): Select the preferred delivery time, either Morning (6am-12pm), Afternoon (12pm-6pm), Evening (6pm-10pm), or Any time.
* **Milk Type** (id: 18, required: false): Select all the types of milk that apply.
* **Milk Quantity** (id: 19, required: false): Enter the quantity of milk in liters.
* **Butter Type** (id: 21, required: false): Select all the types of butter that apply.
* **Butter Quantity** (id: 22, required: false): Enter the quantity of butter in kilograms.
* **Ghee Type** (id: 23, required: false): Select all the types of ghee that apply.
* **Ghee Quantity** (id: 24, required: false): Enter the quantity of ghee in liters/kg.
* **Cheese Type** (id: 26, required: false): Select all the types of cheese that apply.
* **Cheese Quantity** (id: 27, required: false): Enter the quantity of cheese in kilograms.
* **Ice Cream Flavors** (id: 29, required: false): Select all the ice cream flavors that apply.
* **Pack Size** (id: 30, required: false): Select the pack size of ice cream, either 500ml, 1L, 2L, Family pack, or Mixed packs.
* **Ice Cream Quantity** (id: 31, required: false): Enter the quantity of ice cream.
* **Yogurt Type** (id: 33, required: false): Select all the types of yogurt that apply.
* **Yogurt Quantity** (id: 34, required: false): Enter the quantity of yogurt in kilograms/liters.
* **Chocolate Type** (id: 36, required: false): Select all the types of chocolate that apply.
* **Chocolate Quantity** (id: 37, required: false): Enter the quantity of chocolate.
* **Is Discount Applicable** (id: 46, required: false): Select if discount is applicable, true or false.
* **Discount Percentage** (id: 47, required: false): Enter the discount percentage if applicable.
* **Are You a Previous Customer** (id: 49, required: false): Select if you are a previous customer.
* **How Did You Hear About Us** (id: 50, required: false): Select how you heard about us.
* **Additional Comments** (id: 51, required: false): Enter any special requirements.
* **Terms and Conditions** (id: 53, required: true): Select I agree to the terms and conditions.
* **Customer Signature** (id: 54, required: true): Type your full name as the customer signature.
* **Order Status** (id: 55, required: false): For office use only.
* **Payment Method** (id: 42, required: true): Select the payment method, either Cash on delivery, Credit/Debit card, UPI, Bank transfer, Credit account, or Other.
* **Payment Terms** (id: 43, required: false): Select the payment terms, either Immediate, 7 days, 15 days, 30 days, or Not applicable.
* **Estimated Order Total** (id: 45, required: false): Enter the estimated order total in currency.
* **Special Instructions** (id: 40, required: false): Enter any special requirements.
* **Previous Customer** (id: 49, required: false): Select if you are a previous customer.
* **Referral Source** (id: 50, required: false): Select how you heard about us.
* **Additional Comments** (id: 51, required: false): Enter any special requirements.

## Tips
* Please fill up all the required fields marked as required.
* Select all the options that apply for each field.
* Please note that some fields are for office use only.
* Please be clear and concise while filling up the form.
* If you are a previous customer, select the "Previous Customer" option.
* If you select "Credit account" as payment method, please fill up the "Payment Terms" field accordingly.
* If you select "Immediate" as payment terms, please make the payment immediately.
