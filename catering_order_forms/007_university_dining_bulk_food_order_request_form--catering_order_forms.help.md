# University Dining Bulk Food Order Request Form - Help Guide

## Purpose
This form is designed to request a bulk food order for events or functions within the university dining system. It is used to gather essential information from the event organizer to process the order.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter a brief description of the event or function to be held.
2. Select the category to which the form belongs (Catering Order Forms).
3. Enter the assigned tool used for the form (if applicable).
4. Choose the form ID (optional).
5. Specify the output file (if applicable).
6. Provide a description of the form (optional).
7. Enter the form title.
8. Select whether a category is yes or no.
9. Enter the form description.

## Field-by-Field Explanation

* **University Dining Bulk Food Order Request Form Description** (`university_dining_bulk_food_order_request_form_description`, text, optional): A brief description of the event or function requesting the bulk food order.
* **Catering Order Forms** (`catering_order_forms_category`, text, optional): The category to which the form belongs, typically "Catering Order Forms".
* **Assigned Tool** (`assigned_tool`, text, optional): The tool assigned to process the form, if any.
* **Form ID** (`form_id`, number, optional): A unique identifier for the form, if applicable.
* **Output File** (`output_file`, text, optional): The output file associated with the form, if applicable.
* **Description** (`description`, text, optional): A brief description of the form, if provided.
* **Form Title** (`form_title`, text, optional): The title of the form, which should be descriptive and relevant to the event or function.
* **Category** (`category`, select_one, optional): A selection of "Yes" or "No" to indicate whether the form is for a category or not.
* **Form Description** (`form_description`, text, optional): A detailed description of the form, if provided.
* **Assigned Tool** (`assigned_tool`, text, optional): The tool assigned to process the form, if any.
* **Form ID** (`form_id`, number, optional): A unique identifier for the form, if applicable.

## Tips
* Ensure that only one form is created per event to avoid duplication of orders.
* Be concise and clear in the description and title to ensure accurate processing of the order.
