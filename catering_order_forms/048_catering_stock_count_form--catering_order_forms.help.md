# Catering Stock Count Form - Help Guide
## Purpose
This form is used to record the stock count of items at different locations in the catering department. It helps management to track the current stock levels, identify any discrepancies, and determine if a reorder is required.
## How To Complete This Form
1. Select the location from the drop-down list where you are conducting the stock count.
2. Enter the date of the stock count.
3. Enter the time of the stock count.
4. Select the category of the item you are counting.
5. Enter the name of the item.
6. Choose the unit of measure for the item.
7. Enter the current quantity of the item on hand.
8. Enter the target par level (target quantity) for the item.
9. For items that are below par, list them in the "Items Below Par Level" field.
10. If there are any expired or damaged items, list them in the "Expired Items Found" and "Damaged Items Found" fields respectively.
11. Enter any additional comments or notes about the stock count.
12. Indicate if a reorder is required and if the supervisor has been informed.
13. Enter any other information about the stock count.

## Field-by-Field Explanation
* **Counter Name**: Enter your name as the counter who conducted the stock count.
* **Count Date**: Enter the date of the stock count.
* **Count Time**: Enter the time of the stock count.
* **Location**: Select the location where the stock count was conducted (e.g. Main Kitchen, Satellite Kitchen, etc.).
* **Category**: Select the category of the item being counted (e.g. Dry Goods, Canned Goods, etc.).
* **Item Name 1**: Enter the name of the first item being counted.
* **Unit 1**: Select the unit of measure for the first item (e.g. Each, Box, etc.).
* **Quantity 1**: Enter the current quantity of the first item on hand.
* **Par Level 1**: Enter the target quantity for the first item.
* **Item Name 2**: Enter the name of the second item being counted.
* **Unit 2**: Select the unit of measure for the second item.
* **Quantity 2**: Enter the current quantity of the second item on hand.
* **Par Level 2**: Enter the target quantity for the second item.
* **Item Name 3**: Enter the name of the third item being counted.
* **Unit 3**: Select the unit of measure for the third item.
* **Quantity 3**: Enter the current quantity of the third item on hand.
* **Par Level 3**: Enter the target quantity for the third item.
* **Item Name 4**: Enter the name of the fourth item being counted.
* **Unit 4**: Select the unit of measure for the fourth item.
* **Quantity 4**: Enter the current quantity of the fourth item on hand.
* **Par Level 4**: Enter the target quantity for the fourth item.
* **Item Name 5**: Enter the name of the fifth item being counted.
* **Unit 5**: Select the unit of measure for the fifth item.
* **Quantity 5**: Enter the current quantity of the fifth item on hand.
* **Par Level 5**: Enter the target quantity for the fifth item.
* **Items Below Par Level**: List any items that are below their target par level.
* **Expired Items Found**: List any expired items found during the stock count.
* **Damaged Items Found**: List any damaged items found during the stock count.
* **Shortage Notes**: Enter any additional comments or notes about the stock count.
* **Reorder Needed**: Indicate if a reorder is required for any of the items.
* **Supervisor Notified**: Indicate if the supervisor has been informed about the stock count.
* **Additional Comments**: Enter any other information about the stock count.
* **Location**: Select the location of the item (e.g. Main Kitchen, Satellite Kitchen, etc.).
* **Category**: Select the category of the item (e.g. Dry Goods, Canned Goods, etc.).
