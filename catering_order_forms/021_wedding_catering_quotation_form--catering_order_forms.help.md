# Wedding Catering Quotation Form - Help Guide
## Purpose
This form is used to collect information for a wedding catering quotation. Please fill it out completely and accurately to help us provide the best possible quote for your special day.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the form in its entirety, including all required fields.
2. Double-check your information for accuracy before submitting.
3. Make sure to save your progress if you need to come back later.

## Field-by-Field Explanation
### Wedding Details
* **Wedding Details** (`wedding_details`, text, optional): A brief description of the wedding event.
### Guests
* **Guests** (`guests`, number, optional): The estimated number of guests attending the wedding.
### Date
* **Date** (`date`, date, optional): The date of the wedding event.
### Menu
* **Menu** (`menu`, select multiple, optional): Please select which menu options you are interested in. Options are:
	+ 'Yes'
	+ 'No'
### Food Options
* **Food Options** (`food_options`, select multiple, optional): Please select which food options you are interested in. Options are:
	+ 'Yes'
	+ 'No'
### Drinks
* **Drinks** (`drinks`, select multiple, optional): Please select which drinks you are interested in. Options are:
	+ 'Yes'
	+ 'No'
### Wedding Theme
* **Wedding Theme** (`wedding_theme`, select one, optional): Please select the wedding theme. Options are:
	+ 'Yes'
	+ 'No'
### Budget
* **Budget** (`budget`, number, optional): A budget estimate for the event.
### Contact Details
* **Contact Details** (`contact_details`, note, optional): A note for contact details.
### Email
* **Email** (`email`, email, required): The email address of the person submitting the form.
### Phone
* **Phone** (`phone`, text, optional): A phone number of the person submitting the form.
### Address
* **Address** (`address`, text, optional): A physical address of the person submitting the form.
## Tips
* Please double-check your information for accuracy before submitting the form.
* Make sure to provide a valid budget estimate if you have one.
* If you have any special requests or questions, include them in the contact details field.
