# Corporate Catering Menu Order Form Template - Help Guide

## Purpose
The Corporate Catering Menu Order Form Template is a form designed to collect information about corporate catering orders. It is intended for corporate clients to place orders for catering services. This form is used to capture the details of the event, the catering options chosen, the quantity of food ordered, and the payment details.

## How To Complete This Form
To complete this form, follow these steps:

1. **Enter Event Details**: Fill in the "Event Details" field with the necessary information about the event.
2. **Choose Catering Options**: Select the catering option(s) that you would like to order from the list provided.
3. **Specify Quantity**: Enter the quantity of each catering option you have chosen.
4. **Enter Order Amount**: If the quantity of food ordered has changed, enter the new total order amount.
5. **Provide Payment Details**: Enter any additional payment information, if applicable.
