## How To Complete This Form

To complete this form, follow these steps:

1. Fill out the event details section, providing the date, start time, and location of the event.
2. Enter the estimated number of guests attending the event.
3. Select the type of event (e.g. wedding, birthday party, corporate function, etc.).
4. Choose your preferred cuisines for the catering menu.
5. Select the service style for the event (e.g. buffet, plated service, etc.).
6. If applicable, specify any dietary restrictions or special requests.
7. Enter the primary contact's name, email, and phone number for communication and quote delivery.
8. Provide any additional information about the event, such as special requests or questions.

## Field-by-Field Explanation

*   **Event Date**: Enter the date for your event.
    *   **Type**: Enter the date using the format `YYYY-MM-DD`.
    *   This field is required and should match the date of your event.
*   **Event Start Time**: What time do you expect the catering to start.
    *   **Type**: Enter the time using a 12-hour format (e.g. 02:00 PM).
    *   This field is required.
*   **Event Location**: Provide the full address or venue name.
    *   **Type**: Enter a text string for the location.
    *   This field is required.
*   **Estimated Guest Count**: Approximate number of people attending.
    *   **Type**: Enter a whole number (e.g. 50).
    *   This field is required.
*   **Event Type**: What kind of event is this.
    *   **Type**: Select one of the options from the dropdown list (e.g. Wedding, Birthday Party, Corporate Function, etc.).
    *   This field is required.
*   **Preferred Cuisines**: Select all that apply.
    *   **Type**: Select multiple options from the dropdown list.
    *   This field is optional.
*   **Service Style**: How would you like the food to be served.
    *   **Type**: Select one of the options from the dropdown list (e.g. Buffet, Plated Service, etc.).
    *   This field is required.
*   **Specify Dietary Restrictions**: Mention any allergies or special dietary needs (e.g. gluten-free, nut-free).
    *   **Type**: Enter a text string for the restrictions.
    *   This field is optional.
*   **Contact Name**: Full name of the primary contact.
    *   **Type**: Enter a text string for the contact name.
    *   This field is required.
*   **Contact Email**: We will send the quote to this address.
    *   **Type**: Enter a valid email address for the contact.
    *   This field is required.
*   **Contact Phone Number**: In case we need to clarify details quickly.
    *   **Type**: Enter a phone number for the contact.
    *   This field is required.
*   **Special Requests or Questions**: Any other details we should know.
    *   **Type**: Enter a text string for any additional information.
    *   This field is optional.
