# Macs Catering Order Form - Help Guide
## Purpose
This form is designed to collect information from customers to provide an efficient and effective catering service for their event.
## How To Complete This Form
- Fill in the required fields (denoted by *Required*).
- For select fields, select one or more options that apply to your needs.
- Review the form carefully before submitting it to ensure all required fields are completed accurately.
## Field-by-Field Explanation
* **Event Organiser**: Enter the name of the person or organisation responsible for the event.
* **Contact Person**: Enter the name of the contact person responsible for communication regarding the event.
* **Support Requested**: Check the boxes if you would like to request support from our team.
* **Food Requested**: Select the types of food you would like to have for your event (e.g., vegetarian, non-vegetarian).
* **Drinks Requested**: Select the types of drinks you would like to have for your event (e.g., coffee, tea, juice).
* **Equipment Required**: Select the types of equipment you need for the event (e.g., tables, chairs, microphones).
## Tips
- Make sure to submit the form at least 48 hours before the event date to allow sufficient time for preparation.
- Review the form carefully to ensure all required fields are completed accurately.
- If you have any special requests or requirements not listed here, please contact our support team directly.
