# Enhancement Request Form - Help Guide
## Purpose
The Enhancement Request Form is a tool used to collect enhancement requests from users. It helps us understand their needs and priorities development efforts.

## How To Complete This Form
To complete this form, follow these steps:

1. Provide your user input, including your name and any other relevant information.
2. Add details about the product or feature you are requesting an enhancement for.
3. Select the type of enhancement you are requesting.
4. Indicate the priority level of the enhancement.
5. Set the status of the enhancement request.
6. Provide a description of the enhancement.
7. If applicable, indicate the impact level of the enhancement.
8. Set a due date for the enhancement request.
9. If applicable, select the tool assigned to address the enhancement request.
10. Enter your email address and/or phone number for follow-up.

## Field-by-Field Explanation
* **User Input** (`user_input`, text, required: false): A field for you to enter your name or any other relevant information that will help us understand who is submitting the request.
* **Product Details** (`product_details`, text, required: false): Enter the name or description of the product or feature you are requesting an enhancement for.
* **Enhancement Type** (`enhancement_type`, select_one, required: false): Select the type of enhancement you are requesting (e.g., new feature, bug fix, etc.).
* **Priority** (`priority`, number, required: false): Indicate the priority level of the enhancement request (e.g., 1, 2, 3).
* **Status** (`status`, select_one, required: false): Set the status of the enhancement request (e.g., new, in progress, completed).
* **Description** (`description`, text, required: false): Provide a brief description of the enhancement request.
* **Impact Level** (`impact_level`, select_multiple, required: false): If applicable, select the impact level of the enhancement (e.g., high, medium, low).
* **Due Date** (`due_date`, date, required: false): Set a due date for the enhancement request.
* **Assigned Tool** (`assigned_tool`, select_one, required: false): If applicable, select the tool assigned to address the enhancement request.
* **Email** (`email_input`, email, required: false): Enter your email address for follow-up on the enhancement request.
* **Phone** (`phone_input`, text, required: false): Enter your phone number for follow-up on the enhancement request.
* **Comments** (`comments`, text, required: false): Add any additional comments or questions you have about the enhancement request.

## Tips
* Please fill out the form as thoroughly as possible to ensure that we have all necessary information to understand your enhancement request.
* You may not need to fill out all fields, but providing more information will help us better understand your needs.
* If you have any questions or concerns about the form, feel free to reach out to us at [support email address].
