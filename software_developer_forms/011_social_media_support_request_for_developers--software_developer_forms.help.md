# social_media_support_request_for_developers - Help Guide

## Purpose
This form is designed to help software developers report issues they are experiencing with social media support. It allows them to provide essential information to the support team so that the issue can be efficiently resolved.

## How To Complete This Form

To complete this form, follow these steps:

1. Fill in your contact information, including email and contact number.
2. Describe the issue you are experiencing with social media support in the "Issue Description" field.
3. Provide more details about the issue in the "Issue Details" field.
4. Choose which social media channel is associated with the issue (e.g., Facebook, Twitter, etc.).
5. Select how urgent you consider the issue to be.
6. Specify the expected resolution time.
7. Identify which developers are involved in the issue.
8. Attach any relevant files to the issue (e.g., images, videos, documents, code).
9. Add any additional comments about the issue.
10. Submit the form.

## Field-by-Field Explanation

* **Form Header** (`form_header`, note, not required): This is the header section of the form, which contains some introductory information.
* **User Info** (`user_info`, text, not required): Please enter your contact email and contact number so we can reach out to you for further clarification or updates on the issue.
* **Issue Description** (`issue_description`, text, not required): Describe the issue you are experiencing with social media support. Please be as detailed as possible.
* **Issue Details** (`issue_details`, text, not required): Add any additional information about the issue that will help us understand it better.
* **Social Media Channels** (`social_media_channels`, select_one, not required): Choose the social media channel associated with the issue (e.g., Facebook, Twitter, etc.).
* **Issue Priority** (`issue_priority`, select_one, not required): Select how urgent you consider the issue to be (e.g., Yes, No).
* **Expected Resolution Time** (`expected_resolution_time`, date, not required): Specify when you expect the issue to be resolved.
* **Developer Info** (`developer_info`, select_multiple, not required): Identify which developers are involved in the issue (e.g., Front-End Developer, Back-End Developer, etc.).
* **Additional Comments** (`additional_comments`, text, not required): Add any other details about the issue that might be helpful for us to know.
* **Attachment Files** (`attachment_files`, select_multiple, not required): If you have any relevant files (e.g., images, videos, documents, code) that can help us resolve the issue, please attach them here.
* **Email** (`email`, email, not required): Enter your contact email address so we can reach out to you.
* **Contact Number** (`contact_number`, text, not required): Enter your contact number so we can reach out to you.
* **Developer Response** (`developer_response`, time, not required): Please specify the time you are available to receive feedback from the developer.
