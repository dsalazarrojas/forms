# Program Removal Request Form - Help Guide
## Purpose
The **Program Removal Request Form** is used to request removal of a program from a user's account. This form is used to document the user's request and provide a clear understanding of their reason for requesting the removal.

## How To Complete This Form
To complete this form, follow these steps:
1. Enter the name of the program you would like to remove.
2. Provide your name and email address for communication purposes.
3. Enter a clear reason for requesting the removal of the program.
4. Add any additional comments or details about your request.
5. Select the "Agree" option to confirm your request.
6. Optionally, select a date and time for when you would like the program to be removed.
7. Enter the ID of the program you would like to remove.

## Field-by-Field Explanation
* **Enter Program Name**: Enter the name of the program you would like to remove. This will help us identify the program correctly.
* **Requester's Name**: Enter your name and email address so we can contact you regarding your request.
* **Email**: Enter a valid email address where we can contact you about your request.
* **Reason for Request**: Enter a clear and concise reason for requesting the removal of the program. This will help us understand your request and make the removal process smooth.
* **Additional Comments**: If you have any additional information or details to provide about your request, enter them here.
* **Agree**: Please select "I agree" to confirm that you understand that removing the program may have consequences and that you are aware of the terms and conditions.
* **Request Date/Time**: Optionally, select a date and time for when you would like the program to be removed. This will help us schedule the removal process.
* **Program ID**: Enter the ID of the program you would like to remove so we can locate it correctly.
