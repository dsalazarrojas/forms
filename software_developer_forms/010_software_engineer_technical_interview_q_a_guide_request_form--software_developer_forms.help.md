# Software Engineer Technical Interview Q&A Guide Request Form - Help Guide
## Purpose
This form is used to collect information from software developers for a technical interview Q&A guide request. It helps gather relevant details about the interview topics and categories.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter a title for the interview guide in the "Software Engineer Technical Interview Q&A Guide Request Form" field.
2. Choose whether the interview guide is related to a specific category in the "category" field.
3. Enter a brief description of the request in the "description" field.
4. Select the tool or platform that the interview guide will be output to in the "assigned_tool" field.
5. Enter the output file name in the "output file" field.

## Field-by-Field Explanation
* **Software Engineer Technical Interview Q&A Guide Request Form** (`title`, `text`, required/optional): Enter a title for the interview guide, which will be used to identify the guide.
* **category** (`category`, `select_multiple`, optional): Choose one or more categories that the interview guide is related to. This will help us understand the scope of the guide.
* **description** (`description`, `note`, optional): Enter a brief description of the request, including any relevant details about the interview guide.
* **description** (`description`, `text`, required): Enter a more detailed description of the request, including the specific topics and questions that will be covered.
* **assigned_tool** (`assigned_tool`, `select_one`, required): Choose the tool or platform that the interview guide will be output to, such as "chatjimmy" or "other".
* **output file** (`output_file`, `text`, optional): Enter the name of the output file that the interview guide will be saved as.

## Tips

* Make sure to fill out all required fields accurately and thoroughly.
* If you're unsure about a field, feel free to ask for clarification.
* This form is designed to be completed by software developers, so be as specific as possible about the interview topics and categories.
