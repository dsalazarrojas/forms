# Performance Review - Help Guide

## Purpose
The Performance Review form is designed to evaluate an employee's performance over a specified period. This form helps managers and employees track and document performance metrics, goals, and areas for improvement. It's used to identify strengths, weaknesses, and development opportunities, and to set future performance objectives.

## How To Complete This Form
To complete this form, please follow these steps:

1. Select the employee for whom you're conducting the performance review (employee_name).
2. Choose the relevant performance manager (performance_manager_name).
3. Specify the start and end dates of the performance review period.
4. Evaluate the employee's performance in various areas (performance_areas_of_emphasis, performance_areas_of_concern).
5. Document strengths and areas for improvement (strengths, areas_for_improvement).
6. Set goals and action items for future development (development_plan, action_items).
7. Set the next review date (next_review_date).
8. Rate the employee's overall performance using a scale (performance_score, performance_score_scale).
9. Add any comments from the performance manager (manager_comments).

## Field-by-Field Explanation

* **Employee Name** (employee_name): Enter the name of the employee being reviewed.
* **Performance Manager Name** (performance_manager_name): Enter the name of the person conducting the review.
* **Start Date** (start_date): Enter the start date of the performance review period.
* **End Date** (end_date): Enter the end date of the performance review period.
* **Job Title** (job_title): Enter the employee's job title.
* **Performance Review Period** (performance_review_period): Enter a brief description of the performance review period.
* **Overall Rating** (overall_rating): Rate the employee's overall performance on a scale (1-5).
* **Performance Areas of Emphasis** (performance_areas_of_emphasis): Select areas where the employee has demonstrated high performance.
* **Performance Areas of Concern** (performance_areas_of_concern): Select areas where the employee has demonstrated low performance.
* **Strengths** (strengths): Describe the employee's strengths and accomplishments.
* **Areas for Improvement** (areas_for_improvement): Identify areas where the employee needs to improve.
* **Development Plan** (development_plan): Outline a plan for the employee's future development.
* **Action Items** (action_items): List specific actions for the employee to take to improve performance.
* **Next Review Date** (next_review_date): Set the date for the next performance review.
* **Performance Score** (performance_score): Rate the employee's performance on a scale (1-5).
* **Performance Score Scale** (performance_score_scale): Select the score scale used for performance scoring.
* **Manager Comments** (manager_comments): Add any additional comments from the performance manager.
