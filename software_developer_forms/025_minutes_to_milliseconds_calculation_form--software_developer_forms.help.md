# Minutes To Milliseconds Calculation Form - Help Guide
## Purpose
This form is designed to convert time in minutes to milliseconds. It takes an input of time in minutes, selects a speed of light, and displays the result in different units.

## How To Complete This Form
1. **Input Time in Minutes**
	* Enter the time in minutes you want to convert.
2. **Select Speed of Light**
	* Choose the speed of light from the options provided: 300,000 m/s, 200,000 m/s, or 100,000 m/s.
3. **Select Units to Display**
	* Choose the units you want to display the result in: milliseconds, seconds, minutes, hours, or years.
4. **Calculate**
	* Click the "Calculate" button to perform the conversion.
5. **Result Time in Milliseconds**
	* The result of the conversion will be displayed in the selected units.

## Field-by-Field Explanation
* **Input Time in Minutes**
	* This field is where you enter the time in minutes you want to convert. It is a numeric field, so enter a number without any units.
* **Select Speed of Light**
	* This field is a dropdown menu where you select a speed of light from the options provided. Each option represents a different speed of light in meters per second.
* **Select Units to Display**
	* This field is a multi-select field where you choose the units you want to display the result in. You can select one or multiple units.
* **Calculate**
	* This field is a button that performs the conversion calculation.
* **Result Time in Milliseconds**
	* This field displays the result of the conversion in the selected units.

## Tips
* Make sure to enter a valid number for the input time in minutes.
* Select a speed of light that matches the actual speed of light you are using.
* Choose the units you want to display the result in carefully to get the desired output.
