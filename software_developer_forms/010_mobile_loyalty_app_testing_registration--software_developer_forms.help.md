# Mobile Loyalty App Testing Registration - Help Guide
## Purpose
This form is designed to collect user input for testing the mobile loyalty app. The information gathered will aid in identifying bugs, improving app performance, and ensuring a better user experience.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in your first name in the **First Name** field.
2. Enter your last name in the **Last Name** field.
3. Provide your email address in the **Email** field.
4. If applicable, enter your phone number in the **Phone** field.
5. Select whether you have an **Android** or **iPhone** device in the **Android or iPhone** field.
6. Choose the operating system of your device from the **Operating System** field.
7. Select the app version you are using.
8. Choose the date you would like to conduct the test in the **Test Date** field.
9. Set the start time for the test in the **Start Time** field.
10. Select the duration of the test in the **Test Duration** field.
11. If you have availability to test on weekends, select **Yes** or **No** in the **Available Days** field.
12. Select whether a testing tool will be assigned to you in the **Assigned Tool** field.
13. You can add any additional comments or feedback in the **Prophets Comments** field.
14. Enter any additional comments in the **Additional Comments** field.

## Field-by-Field Explanation
- **First Name** (text, required): Please enter your first name.
- **Last Name** (text, required): Please enter your last name.
- **Email** (email, required): Enter your email address where you can be contacted.
- **Phone** (text, optional): If you would like to be contacted via phone, enter your phone number.
- **Android or iPhone** (select_one, required): Select whether you have an **Android** or **iPhone** device.
- **Operating System** (select_multiple, optional): Select the operating system of your device.
- **App Version** (number, optional): Select the version of the app you are using.
- **Test Date** (date, required): Choose the date you would like to conduct the test.
- **Start Time** (time, optional): Set the start time for the test.
- **Test Duration** (number, required): Select the duration of the test.
- **Available Days** (select_multiple, optional): Select **Yes** or **No** if you have availability to test on weekends.
- **Assigned Tool** (select_one, required): Select whether a testing tool will be assigned to you.
- **Prophets Comments** (note, optional): Enter any additional comments or feedback.
- **Additional Comments** (note, optional): Enter any additional comments or feedback.
