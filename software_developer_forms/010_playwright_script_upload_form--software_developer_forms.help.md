# Playwright Script Upload Form - Help Guide
## Purpose
The Playwright Script Upload Form is used to upload, categorize, and track scripts related to testing, such as regression, sanity, or functional testing.

## How To Complete This Form
To complete this form, follow these steps:

1.  Select the "Script Upload" field and enter the title of the script.
2.  Enter context information in the "Context Information" field.
3.  Choose the "Upload Date" of when the script was uploaded.
4.  Select who uploaded the script from the "User Uploading" dropdown list.
5.  Select the "Review Status" of the script from the list, which can be "Approved", "Rejected", or "Pending".
6.  Choose the type of script from the "Script Type" dropdown list, which can be "Regression", "Sanity", or "Functional".
7.  Enter a brief description of the script in the "Script Description" field.
8.  Enter the version number of the script in the "Script Version" field.

## Field-by-Field Explanation

* **Script Upload**: This field is where you enter the title of the script.
	+ Type: Text
	+ Required: No
* **Context Information**: Enter any relevant context or additional information about the script.
	+ Type: Text
	+ Required: No
* **Upload Date**: Choose the date when the script was uploaded.
	+ Type: Date
	+ Required: No
* **User Uploading**: Select who uploaded the script from the dropdown list.
	+ Type: Select One
	+ Required: No
* **Review Status**: Choose the status of the script from the list, which can be "Approved", "Rejected", or "Pending".
	+ Type: Select Multiple
	+ Required: No
* **Script Type**: Choose the type of script from the dropdown list, which can be "Regression", "Sanity", or "Functional".
	+ Type: Select One
	+ Required: No
* **Script Description**: A brief description of the script.
	+ Type: Text
	+ Required: No
* **Script Version**: Enter the version number of the script.
	+ Type: Number
	+ Required: No

## Tips
- Make sure to fill out all relevant fields to ensure accurate script tracking.
- Review and update the script status periodically to keep the records up-to-date.
- Keep the version numbers updated to reflect changes in the script.
