This form is a feature request form designed to collect information about new feature requests from customers, teams, or other stakeholders. The form is used to capture essential details about the feature, such as its description, priority, and status. It also allows users to specify who requested the feature and provides an option to add additional notes.

The form is designed to be completed by anyone who wants to submit a feature request. It is not a mandatory form, and users are not forced to provide all the information. However, providing accurate and complete information will help us better understand and prioritize the feature requests.

The form is composed of multiple pages, each with its own set of fields. Each page is designed to collect specific information about the feature request.

## Feature Request Form - Help Guide

## Purpose
This form is designed to collect information about new feature requests from customers, teams, or other stakeholders.

## How To Complete This Form

To complete this form, follow these steps:

1. Click on the "Form Submission" page to begin filling out the form.
2. On the "Form Submission" page, you can add the feature description in the "Feature Description" field.
3. Specify who requested the feature by selecting the correct option from the "Requested By" dropdown menu.
4. Add your email address in the "Email" field, if applicable.
5. Provide your phone number in the "Phone Number" field, if applicable.
6. Enter the date and time when the feature was requested in the "Date of Request" and "Time of Request" fields, if applicable.
7. Select the priority of the feature request from the "Priority" dropdown menu.
8. Specify the status of the feature from the "Feature Status" dropdown menu.
9. Add any additional notes about the feature request in the "Notes" field, if applicable.

## Field-by-Field Explanation

* **Form Submission** (page 1):
	+ **Feature Description** (text): This field is where you can describe the feature that you are requesting. Please provide a clear and concise description of the feature.
* **Feature Request** (page 1):
	+ **Feature Request** (text): This field is where you can enter a brief description of the feature request.
* **Requested By** (page 2):
	+ **Requested By** (select_one): Select from the dropdown menu to specify who requested the feature. Please choose from the options "Customer", "Team", or "Both".
* **Email** (page 2):
	+ **Email** (email): If you are requesting the feature on behalf of someone else, please provide your email address.
* **Phone Number** (page 2):
	+ **Phone Number** (text): If you need to be contacted regarding the feature request, please provide your phone number.
* **Date of Request** (page 3):
	+ **Date of Request** (date): If you know when the feature was requested, please enter the date.
* **Time of Request** (page 3):
	+ **Time of Request** (time): If you know when the feature was requested, please enter the time.
* **Priority** (page 3):
	+ **Priority** (select_multiple): Select from the dropdown menu to specify the priority of the feature request. Please choose from the options "High", "Medium", or "Low".
* **Feature Status** (page 3):
	+ **Feature Status** (select_one): Select from the dropdown menu to specify the status of the feature request. Please choose from the options "In Development", "In Progress", "Done", or "Not Planned".
* **Notes** (page 3):
	+ **Notes** (note): This field is where you can add any additional notes about the feature request.

## Tips

* Please fill out the form as accurately and completely as possible to help us better understand and prioritize the feature requests.
* If you are unsure about any of the fields, please contact us and we will be happy to assist you.
* You can submit multiple feature requests in the form, one page at a time.
