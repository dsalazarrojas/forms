# Weeks To Milliseconds Calculation Form - Help Guide
## Purpose
The Weeks To Milliseconds Calculation Form is a simple tool for converting time units between weeks and milliseconds. It allows you to enter a value for either weeks or milliseconds and automatically calculates the equivalent value in the other unit.

## How To Complete This Form
To use this form, follow these steps:

1. Select whether you want to convert from weeks to milliseconds or from milliseconds to weeks.
2. Enter the value for the unit you selected in the corresponding field.
3. Click the "Calculate" button to perform the conversion.

## Field-by-Field Explanation
- **Weeks** (`input_weeks`, number, required): Enter the number of weeks you want to convert. This field is required.
  - This field is used to input the number of weeks you wish to convert.
- **Milliseconds** (`milliseconds`, number, required): Enter the number of milliseconds you want to convert. This field is required.
  - This field is used to input the number of milliseconds you wish to convert.
- **Result** (`calculate_result`, note, optional): The automatically generated result of the conversion. This field is not required.
  - This field displays the calculated result of the conversion in the selected unit.
