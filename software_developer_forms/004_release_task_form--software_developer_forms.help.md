# release_task_form - Help Guide
## Purpose
This form is used to create a new release task with specific details.

## How To Complete This Form
To complete this form, follow these steps:
1. Fill in the project name to identify the task.
2. Enter the start and end dates of the project.
3. Select the tool assigned to the project.
4. Choose a status (Open, Closed, or In Progress).
5. Set the priority level (High, Low, or Medium).
6. Add any additional notes if required.

## Field-by-Field Explanation
- **Project Name (1)**: Enter a brief description of the project.
- **Start Date (2)**: Enter the start date of the project.
- **End Date (3)**: Enter the end date of the project.
- **Assigned Tool (4)**: Select the tool used for the project from the options (Chatjimmy or Other).
- **Status (6)**: Choose the current status of the project (Open, Closed, or In Progress).
- **Due Date (7)**: Enter the date by which the project should be completed.
- **Priority (8)**: Select the priority level of the project (High, Low, or Medium).
- **Tags (9)**: Add any additional tags related to the project.
- **Notes (10)**: Add any notes or comments regarding the project.
