# Issue Tracking Form - Help Guide
## Purpose
The purpose of this form is to provide a structured way of reporting and tracking issues that need to be addressed in the software development process.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the `issue_tracking_form` field with a brief description of the issue.
2. Specify the `company_member` responsible for the issue (if applicable).
3. Provide a detailed `description` of the issue in the text field.
4. Enter the `report_date` and `report_time` fields to record when the issue was reported.
5. Choose whether the issue has been `assigned_to` someone (Yes/No).
6. Leave any additional `comments` in the text field.
7. If the issue requires a specific `assigned_tool`, enter it in this field.
8. In the `sync_apps` field, you can add any relevant information or notes about the issue.
9. In the `view_responses` field, you can add any relevant responses or comments related to the issue.

## Field-by-Field Explanation

* **issue_tracking_form**: This field should be filled in with a brief description of the issue.
* **company_member**: Enter the name of the company member responsible for the issue (if applicable). This field is not required.
* **description**: Provide a detailed description of the issue in this text field.
* **report_date**: Enter the date the issue was reported. This field is in date format (e.g. 2022-01-01).
* **report_time**: Enter the time the issue was reported. This field is in 24-hour time format (e.g. 14:30).
* **assigned_to**: Choose whether the issue has been assigned to someone (Yes/No).
* **comments**: Leave any additional comments related to the issue in this text field.
* **assigned_tool**: If the issue requires a specific tool or software, enter it in this field.
* **sync_apps**: In this field, you can add any relevant information or notes about the issue.
* **view_responses**: In this field, you can add any relevant responses or comments related to the issue.

## Tips

* Make sure to fill in all required fields.
* Use the `report_date` and `report_time` fields to record when the issue was reported.
* If the issue has been assigned to someone, make sure to choose "Yes" in the `assigned_to` field.
* Use the `comments` field to add any additional information related to the issue.
* If the issue requires a specific tool or software, enter it in the `assigned_tool` field.
