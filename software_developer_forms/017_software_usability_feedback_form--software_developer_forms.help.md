# software_usability_feedback_form - Help Guide
## Purpose
The software usability feedback form is designed to gather feedback on the usability of software applications. Fill out this form to share your thoughts, experiences, and suggestions for improvement.

## How To Complete This Form
1. Click on the "Submit" button to start filling out the form.
2. Fill out each field according to the instructions provided.
3. Make sure to fill out the required fields.
4. Review your answers before submission.

## Field-by-Field Explanation

* **User Experience (Text)**: Describe your overall experience with the software. Please be as detailed as possible.
* **Usability Problems (Select Multiple)**: Select all the problems you encountered with the software, such as:
	+ Bug
	+ Confusion
	+ Frustration
	+ Help needed
* **Suggestion/Feedback (Note)**: Share your thoughts, suggestions, or feedback on how the software can be improved.
* **Contact Info (Email)**: Provide your email address if you'd like to be contacted for follow-up questions or feedback.
* **Software (Select Multiple)**: Choose the software you were using when experiencing the usability issue, such as:
	+ Adobe Acrobat Pro
	+ Adobe Photoshop
	+ Adobe XD
	+ Other (please specify)
* **Platform (Select One)**: Select the platform you were using the software on:
	+ Windows
	+ macOS
	+ Linux
	+ Other (please specify)

## Tips
* Please be as specific as possible when answering the questions.
* If you're unsure about anything, you can always ask for clarification.
* You can always provide additional information or context that might be helpful for improving the software.
