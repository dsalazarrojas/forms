# Calculate Arctangent2 (atan2) Form - Help Guide
## Purpose
The Calculate Arctangent2 (atan2) Form is used to calculate the arctangent2 (arctangent) of a given input, which is the angle between two points in a 2D plane. This form takes the x and y coordinates as input and produces the arctangent2 value in the selected unit and with the desired decimal places.

## How To Complete This Form
To complete this form, follow these steps:

*   Enter the Y coordinate value in the "Y Value (numerator)" field.
*   Enter the X coordinate value in the "X Value (denominator)" field.
*   Select the output unit from the "Output Unit" dropdown. You can choose between Radians or Degrees.
*   Choose the number of decimal places in the result from the "Decimal Places in Result" dropdown.
*   Select the expected quadrant for the angle, if you're certain. This can be Quadrant I (x > 0, y > 0), Quadrant II (x < 0, y > 0), Quadrant III (x < 0, y < 0), Quadrant IV (x > 0, y < 0), or Not sure.
*   Optionally, provide additional information or notes about the calculation.

## Field-by-Field Explanation
### Y Value (numerator) (Required)
*   **Y Value (numerator)**: Enter the Y coordinate or numerator value.
*   **X Value (denominator)**: Enter the X coordinate or denominator value.
*   **Output Unit**: Select the unit for the arctangent2 value to be displayed in.
*   **Decimal Places in Result**: Choose the number of decimal places to display in the result.
*   **Expected Quadrant**: Select the quadrant where the angle is expected to lie.
*   **Angle Reference System**: Select the reference system for the angle, which can be Standard mathematical (counterclockwise from x-axis), Navigation/bearing (clockwise from north), or Other.
*   **Additional Notes or Context**: Provide any additional information about the calculation or angle.
*   **Your Email (optional)**: Provide an email address to receive the result or for follow-up.
*   **Save Results for Later Reference?**: Decide whether to save the result for later reference or not.
