# information_technology_survey - Help Guide
## Purpose
The purpose of this form is to gather information from end-users about their software development experience and technology usage.

## How To Complete This Form
To complete this form, follow these steps:

1. Select all the software you currently use for development, if any.
2. Provide a brief description of the context in which you use this software.
3. Choose your level of satisfaction with the software (optional).
4. Specify your current needs or challenges related to software development (optional).
5. Enter your contact information (email address) so we can reach out to you for further communication.

## Field-by-Field Explanation

* **Survey Context** (`survey_context`, text, required: false): This field is where you can describe the specific context in which you use the software. For example, you can specify if you use the software for personal projects or for professional purposes.
* **Software Used** (`software_used`, select_multiple, required: false): Select all the software you currently use for development. This can include operating systems like Windows, macOS, or Linux, or other software-specific tools. You can choose one or more options that apply to you.
* **Satisfaction** (`satisfaction`, number, required: false): If you'd like to share your level of satisfaction with the software, choose a number between 1 and 10, where 1 is very dissatisfied and 10 is very satisfied. This is an optional field, but it will help us understand your overall experience with the software.
* **Needs** (`needs`, text, required: false): Describe your current needs or challenges related to software development. This can include features you'd like to see added or difficulties you've encountered.
* **Contact Information** (`contact_info`, email, required: false): Provide your email address so we can contact you for follow-up questions or to thank you for your participation.

## Tips
* Be honest and specific when completing this form, as your input will help us shape our products and services.
* If you have trouble selecting software or have questions, feel free to reach out to us directly.
