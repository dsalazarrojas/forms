# Software Code Metrics Report Form - Help Guide
## Purpose
The Software Code Metrics Report Form is designed to collect data on software code metrics for projects within an organization. It is meant to capture specific metrics for a project, including project details and metrics such as code complexity, comment frequency, and code duplication.

## How To Complete This Form
1. Enter the **Project Name** (required field) to identify the project.
2. Enter the **Project ID** (required field) to uniquely identify the project within the organization.
3. Select the **Metric Categories** (required field) relevant to the project.
4. Select the **Code Complexity** (required field) to indicate the complexity level of the project code.
5. Select the **Comment Frequency** (optional field) to indicate the comment frequency in the project code.
6. Select the **Code Duplication** (optional field) to indicate the duplication level of the project code.
7. Enter the **Project Manager** (required field) name and email.
8. Select the **Project Status** (required field) to indicate the current status of the project.
9. Enter the **Status Comments** (optional field) to provide additional comments on the project status.
10. Enter the **Code Review Date** (required field) and **Code Review Time** (optional field) for the code review.
11. Enter the **Reviewer Name** (required field) and **Email** (optional field) for the reviewer.
12. Enter the **Review Comments** (required field) to provide feedback on the project code.
13. Enter **Metrics 1-10** (optional fields) to provide additional metrics for the project.

## Field-by-Field Explanation
* **Project Name (Project Name)**: Enter the name of the project to identify it within the organization.
* **Project ID (Project ID)**: Enter a unique identifier for the project within the organization.
* **Metric Categories (Metric Categories)**: Select the categories of metrics relevant to the project.
	+ **Yes** for relevant metrics
	+ **No** for irrelevant metrics
* **Code Complexity (Code Complexity)**: Select the complexity level of the project code.
	+ **Low** for simple code
	+ **Medium** for moderate code
	+ **High** for complex code
* **Comment Frequency (Comment Frequency)**: Select the frequency of comments in the project code.
	+ **Low** for infrequent comments
	+ **Medium** for moderate comments
	+ **High** for frequent comments
* **Code Duplication (Code Duplication)**: Select the duplication level of the project code.
	+ **Low** for low duplication
	+ **Medium** for moderate duplication
	+ **High** for high duplication
* **Project Manager (Project Manager)**: Enter the name of the project manager.
* **Email (Project Manager Email)**: Enter the email of the project manager.
* **Project Status (Project Status)**: Select the current status of the project.
	+ **Not Started** for projects not started
	+ **In Progress** for projects in progress
	+ **Done** for completed projects
* **Status Comments (Project Status Comments)**: Enter additional comments on the project status.
* **Code Review Date (Code Review Date)**: Enter the date of the code review.
* **Code Review Time (Code Review Time)**: Enter the time of the code review (optional).
* **Reviewer Name (Reviewer)**: Enter the name of the reviewer.
* **Email (Reviewer Email)**: Enter the email of the reviewer (optional).
* **Review Comments (Review Comments)**: Enter feedback on the project code.
* **Metrics 1-10 (Metrics 1-10)**: Enter additional metrics for the project.

Note: The optional fields are not required fields and can be filled out if additional information is desired.
