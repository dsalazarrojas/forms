# Days To Milliseconds Calculation Form - Help Guide
## Purpose

The Days To Milliseconds Calculation Form is a simple tool for converting between days and milliseconds. You can use this form to input either the number of days or the number of milliseconds and get the equivalent value in the other unit.

## How To Complete This Form

1. Select the unit you want to convert from. You can choose between "Days" and "Milliseconds".
2. Enter the value you want to convert. This is the number of days or milliseconds you want to convert.
3. Click on the "Calculate" button to get the equivalent value in the other unit.
4. The result will be displayed in the "Result" field.

## Field-by-Field Explanation

* **Days** (days_to_ms): A number field where you enter the number of days you want to convert.
	+ Type: Number
	+ Required: No
* **Milliseconds** (ms): A number field where you enter the number of milliseconds you want to convert.
	+ Type: Number
	+ Required: No
* **Calculate** (calculate): A dropdown menu where you select the unit to convert to. You can choose between "ms per day" and "days in ms".
	+ Type: Select One
	+ Required: No
* **Result** (result): A text field where the converted value is displayed.
	+ Type: Text
	+ Required: No

## Tips

* Make sure to select the correct unit to convert from and to.
* Double-check your input values for accuracy.
* The form will display the converted value in the "Result" field.
