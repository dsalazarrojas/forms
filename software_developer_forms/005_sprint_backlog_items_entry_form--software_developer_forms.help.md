# Sprint Backlog Items Entry Form - Help Guide
## Purpose
The Sprint Backlog Items Entry Form is a one-page overview of each sprint backlog item, designed for team members to input data on tasks and progress.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the sprint for which you want to input data.
2. Input the item's description.
3. Select the status of the item (Active or Inactive).
4. If applicable, input the estimated and actual hours spent.
5. If applicable, select the tasks associated with this item.
6. Review and submit your input.

## Field-by-Field Explanation

* **Select Sprint** (`select_sprint`): 
    A dropdown menu to choose the sprint for which you're inputting data.
* **Item Description** (`description`): 
    A text field where you can provide a brief description of the item.
* **Select Tasks** (`task_ids`): 
    A multi-select dropdown menu to choose which tasks are associated with this item.
* **Priority** (`priority`): 
    Not applicable in this form; please use other tools for priority assignment.
* **Estimated Hours** (`estimated_hours`): 
    Input the estimated hours expected to complete this item.
* **Actual Hours** (`actual_hours`): 
    Input the actual hours spent on this item.
* **Completed Hours** (`completed_hours`): 
    Input the hours completed for this item.
* **Status** (`status`): 
    Select 'Active' if the item is currently active, or 'Inactive' if it's not.
* **Review and Submit**: 
    Double-check your input and submit the form for review and update.
