# Password Reset Request Form - Help Guide
## Purpose
This form is used to reset your account password in case you've forgotten it.

## How To Complete This Form
To complete this form, follow these steps:

* Fill in your email address in the "Email" field.
* Select a security question and provide an answer to it in the "Security Question" field.
* Type your new desired password in the "New Password" field.
* Confirm your new password in the "Confirm New Password" field to ensure accuracy.
* Select "Submit" to proceed with the password reset process.

## Field-by-Field Explanation

* **User Agent** (`user_agent`, optional): Please enter your user agent information if you need to provide more context about your browser or client details.
* **Email** (`email_input`, email, required): Please enter your registered email address for password reset verification.
* **Security Question** (`security_question`, select_one, required): Select one of the provided security questions that match your identity verification.
* **Security Answer** (`security_answer`, text, optional): Please enter your answer to the chosen security question.
* **New Password** (`password_input`, text, optional): Enter your desired new password.
* **Confirm New Password** (`confirm_input`, text, optional): Confirm your new password to ensure accuracy and security.
* **Submit** (`submit_button`, select_multiple, required): Select "Yes" to confirm that you want to proceed with the password reset process. 

Note: This form requires a confirmation of the new password to prevent accidental password resets.
