# Developer Enrollment Form - Help Guide
## Purpose
This form is used to collect information from software developers about their enrollment in a program.

## How To Complete This Form
To complete this form, follow these steps:

1. Click on the "Enrollment Form" page.
2. Fill in the required and optional fields as necessary.
3. Scroll down to the "Agreement" page and read the terms of use carefully.
4. Check the box to indicate that you have read and agreed to the terms of use.

## Field-by-Field Explanation
### Enrollment Form
* **Title** (`title`, text, optional): This field is not visible in the form and is likely a placeholder.
* **Name** (`name`, text, optional): Enter your name as you would like to be known.
* **Email** (`email`, email, optional): Enter your email address. Please ensure it is a valid email address.
* **Phone** (`phone`, text, optional): Enter your phone number. This can be any format (e.g., 123-456-7890).
* **Program Name** (`program_name`, text, optional): Enter the name of the program you are enrolling in.
* **Program Type** (`program_type`, select one, optional): Select "Yes" or "No" to indicate if you are a part of the program.
* **Date of Birth** (`date_of_birth`, date, optional): Enter your date of birth in the format MM/DD/YY.
* **Start Date** (`start_date`, date, optional): Enter the start date of the program you are enrolling in.
* **End Date** (`end_date`, date, optional): Enter the end date of the program you are enrolling in.
* **Developer Type** (`developer_type`, select one, optional): Select "Yes" or "No" to indicate if you are a developer.
* **Agreement** (`agreement_checkbox`, note, optional): Check this box to indicate that you have read and agreed to the terms of use.
* **Terms of Use** (`terms_of_use`, note, optional): Check this box to indicate that you have read and agreed to the terms of use.
* **Agreement Text** (`agreement_text`, text, optional): This field is not visible in the form and is likely a placeholder.

Tips:
* Make sure to fill in all the fields as accurately as possible.
* Review the terms of use carefully before checking the boxes.
* This form is currently not set up to be required for all fields, so you can fill it in as per your preference.
