# Software Product Demo Request Form - Help Guide
## Purpose
The Software Product Demo Request Form is designed to gather information from software developers who want to request a demo of a software product. This form helps our team to understand the product they are interested in and schedule a demo at a convenient time for both parties.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill in the required fields (indicated by a star (*)):
	* Software Product: Select the software product you are interested in.
	* Demo Schedule: Select a convenient time for the demo.
	* Demo Date: Choose a date for the demo.
	* Demo Type: Select the type of demo you are requesting.
	* Demo Status: Select the current status of your demo request.
2. Fill in the optional fields:
	* Company: If you are representing a company, please enter your company name.
	* Contact Person: If you are interested in scheduling a demo with a specific person, please select their name.
	* Contact Email: Enter the email address of the contact person.
	* Contact Phone: Enter the phone number of the contact person.
	* Software Version: Select the software version you are interested in.
	* Demo Length: Select the desired length of the demo.
	* Product Owner: If you know the product owner, please enter their name.
	* Demo Type 2: Select the type of demo you are requesting (if different from the previous field).
	* Additional Comments: If you have any additional comments or requests, please enter them here.

## Field-by-Field Explanation
* **Software Product**: Select the software product you are interested in. This field will help us understand which product you want to see a demo of.
* **Company**: If you are representing a company, please enter your company name. This helps us to identify the company you are representing.
* **Contact Person**: If you are interested in scheduling a demo with a specific person, please select their name. This helps us to ensure that the demo is scheduled with the right person.
* **Contact Email**: Enter the email address of the contact person. This helps us to contact you with demo details and updates.
* **Contact Phone**: Enter the phone number of the contact person. This helps us to reach out to you if needed.
* **Software Version**: Select the software version you are interested in. This helps us to ensure that we are discussing the correct version.
* **Demo Schedule**: Select a convenient time for the demo. This ensures that we can schedule a demo at a time that works for both parties.
* **Demo Date**: Choose a date for the demo. This helps us to ensure that we are on the same page regarding the demo date.
* **Demo Type**: Select the type of demo you are requesting. This helps us to understand the scope of the demo.
* **Demo Length**: Select the desired length of the demo. This helps us to ensure that we have enough time for the demo.
* **Product Owner**: If you know the product owner, please enter their name. This helps us to contact them regarding the demo.
* **Demo Status**: Select the current status of your demo request. This helps us to track the demo request process.
* **Demo Type 2**: Select the type of demo you are requesting (if different from the previous field). This helps us to understand the scope of the demo.
* **Additional Comments**: If you have any additional comments or requests, please enter them here. This helps us to tailor the demo to your needs.

## Tips
* Please fill in all required fields to ensure that we can process your demo request efficiently.
* If you have any questions or concerns, please don't hesitate to contact us.
