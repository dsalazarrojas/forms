# software_incident_report_form - Help Guide
## Purpose
This form is used to collect information about software incidents that have occurred within the organization.

## How To Complete This Form

To complete this form, follow these steps:

1. Fill out the form with as much detail as possible for each field.
2. Review the form before submitting to ensure all required fields are filled.
3. If a field is not applicable, you can leave it blank.

## Field-by-Field Explanation

### Incident Details
* **incident_date**: Enter the date of the incident in the correct format (MM/DD/YYYY).
* **incident_time**: Enter the time of the incident in the correct format (HH:MM:SS).
* **incident_location**: Enter the location where the incident occurred.
* **incident_description**: Provide a brief description of what happened.
* **affected_users**: Check if any users were affected by the incident. If yes, select the users.
* **incident_type**: Check if the incident was intentional or not. If no, you can provide an alternate description in the **incident_type_other** field.

### Incident Severity and Impact
* **incident_severity**: Check which severity levels apply to the incident.
* **incident_impact**: Check if the incident had any impact on users or systems. If no, you can provide an alternate description in the **incident_impact_other** field.

### Incident Reporter
* **incident_reporter_name**: Enter your name as the reporter.
* **incident_reporter_email**: Enter your email address as the reporter.

### Additional Information
* **incident_type_other**: If the incident was not intentional, provide a description of the incident type.
* **incident_severity_other**: If no severity levels apply, provide a description of the incident severity.
* **incident_impact_other**: If no impact was felt, provide a description of the incident impact.
* **affected_users_other**: If no users were affected, provide a description of the affected users.
* **incident_reporter_email**: Enter your email address as the reporter.

Note: This form is designed to be filled out by a person who reported the incident. If you're filling out the form for someone else, please ask them to provide you with their details so you can fill out the form correctly.
