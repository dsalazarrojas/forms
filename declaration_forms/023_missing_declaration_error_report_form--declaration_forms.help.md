# Missing Declaration Error Report Form - Help Guide
## Purpose
The Missing Declaration Error Report Form is designed to report errors or discrepancies in declarations. This form helps users identify and track issues related to declarations, ensuring that the necessary steps are taken to correct them.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the type of declaration that is missing or incorrect (e.g., Missing Declaration, Duplicate Declaration, or Void Declaration).
2. Enter the date of the declaration in question.
3. Choose the department responsible for the declaration (e.g., 51163 or 66329).
4. Describe the impact of the issue on the project or work process.
5. Provide a detailed description of the problem.
6. (Optional) Attach relevant supporting documents to aid in resolving the issue.
7. Add any additional comments or information about the issue.

## Field-by-Field Explanation

* **declaration_type** (Select multiple): This field asks you to choose the type of declaration that is missing or incorrect. Select one or more of the options provided (e.g., Missing Declaration, Duplicate Declaration, or Void Declaration).
* **declaration_date**: This field is for entering the date of the declaration in question. Please use the standard date format (e.g., MM/DD/YY).
* **department_id** (Select one): This field is for selecting the department responsible for the declaration. Choose one of the options provided (e.g., 51163 or 66329).
* **impact**: This field is for describing the effect or consequence of the issue on the project or work process. Be as specific and detailed as possible.
* **description**: This field is for providing a detailed explanation of the problem.
* **supporting_documents** (Select multiple): This field allows you to attach relevant documents that support your report. You can choose one or more of the options provided (e.g., Document 1, Document 2, or Document 3). If not required, this field is optional.
* **comments**: This field is for adding any additional comments or information about the issue. This is an optional field.
