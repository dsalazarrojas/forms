# Language Preference Declaration Form - Help Guide
## Purpose
This form is designed to collect information about your language preferences, skills, and needs in a professional or educational context. This includes your preferred language, primary language, contact language, and translation needs, as well as questions about language proficiency and document language.

## How To Complete This Form
1. Select your preferred language from the options provided in each field.
2. You can select multiple languages in fields that allow multiple selections (e.g., primary language, contact language).
3. If you have no translation needs, select "None" in the translation needs field.
4. Answer the question about your primary English language proficiency (True, False, or Not sure).
5. Select the language in which documents are usually provided for your work.
6. Repeat the process for the second and third set of questions (Primary Language 2, Preferred Language 2, etc.).

## Field-by-Field Explanation

* **What is your preferred language?** (`preferred_language`, `select_one`, required/optional): Please select the language you prefer to use in your professional or educational activities.
* **What is your primary language?** (`primary_language`, `select_multiple`, required/optional): Please select all the languages you are fluent in, or those you use most frequently in your daily activities.
* **What is your preferred contact language?** (`preferred_contact_language`, `select_multiple`, required/optional): Please select the language you prefer to use for contact and communication.
* **How much translation needs do you have?** (`translation_needs`, `select_multiple`, required/optional): Please select all the languages in which you need translations.
* **Do you have a primary English language proficiency?** (`main_english_language`, `select_one`, required/optional): Please answer True if you are proficient in English, False if you are not, or Not sure if you are unsure.
* **What language are documents usually in for your work?** (`language_of_documents`, `select_multiple`, required/optional): Please select the language in which documents are usually provided for your work.
* **What is your preferred contact language?** (`preferred_language_2`, `select_multiple`, required/optional): Please select the language you prefer to use for contact and communication.
* **Primary Language 2** (`primary_language_2`, `select_multiple`, required/optional): Please select all the languages you are fluent in, or those you use most frequently in your daily activities.
* **Do you have a main English language proficiency?** (`main_english_language_2`, `select_one`, required/optional): Please answer True if you are proficient in English, False if you are not, or Not sure if you are unsure.
* **What translation needs do you have in your work?** (`language_needs`, `select_multiple`, required/optional): Please select all the languages in which you need translations.
* **Document Language** (`document_language`, `select_multiple`, required/optional): Please select the language in which documents are usually provided for your work.
* **Preferred Language 2** (`preferred_language_2`, `select_multiple`, required/optional): Please select the language you prefer to use for contact and communication.
* **Primary Language 3** (`primary_language_3`, `select_multiple`, required/optional): Please select all the languages you are fluent in, or those you use most frequently in your daily activities.
* **Do you have a primary English language proficiency?** (`main_english_language_3`, `select_one`, required/optional): Please answer True if you are proficient in English, False if you are not, or Not sure if you are unsure.

**Tips**

* Please answer each question honestly and accurately.
* If you are unsure about any question, please answer "Not sure" or ask for clarification.
* This form is designed to help us understand your language preferences and needs, and to provide you with better services and support.
