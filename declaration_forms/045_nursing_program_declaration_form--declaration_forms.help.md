# Nursing Program Declaration Form - Help Guide
## Purpose
This form is used to declare a nursing program. It collects information about the program, including its name, start and end dates, location, type, and other relevant details.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter your email address in the "user email" field. This is a required field for some purposes, but not for others. If you are unsure, check with the form administrator or refer to the form's purpose.
2. Enter your phone number in the "user phone" field. This field is not required.
3. Enter the name of the program in the "program name" field. This field is not required.
4. Enter the start date of the program in the "program start date" field. This field is not required.
5. Enter the end date of the program in the "program end date" field. This field is not required.
6. Enter the location of the program in the "program location" field. This field is not required.
7. Select the type of program from the "program type" field. You can choose from "BSc", "Diploma", or "Certificate". This field is not required.
8. Enter the length of the program in the "program length" field. This field is not required.
9. Select the status of the program from the "program status" field. You can choose from "Active", "Inactive", or "Pending". This field is not required.
10. Enter any additional details about the program in the "program details" field. This field is not required.
11. Select the primary language of the program from the "program english language" field. You can choose from "English", "French", or "Spanish". This field is not required.
12. If the program language is not English, enter the name of the language in the "program other language" field. This field is not required.
13. If the program uses multiple languages, select "Yes" or "No" from the "program_other_language" field. This field is not required.
14. Enter your name in the "user name" field. This field is not required.
15. Enter your address in the "user address" field. This field is not required.
16. Enter your city in the "user city" field. This field is not required.
17. Enter your state in the "user state" field. This field is not required.
18. Enter your country in the "user country" field. This field is not required.
19. Enter your postal code (zip or post code) in the "user_postal_code" field. This field is not required.

## Field-by-Field Explanation
* **User Email**: Enter your email address.
* **User Phone**: Enter your phone number.
* **Program Name**: Enter the name of the program.
* **Program Start Date**: Enter the start date of the program.
* **Program End Date**: Enter the end date of the program.
* **Program Location**: Enter the location of the program.
* **Program Type**: Select the type of program from the available options.
* **Program Length**: Enter the length of the program.
* **Program Status**: Select the status of the program from the available options.
* **Program Details**: Enter any additional information about the program.
* **Program English Language**: Select the primary language of the program.
* **Other Language**: If the program language is not English, enter the name of the language.
* **Program Other Language**: If the program uses multiple languages, select "Yes" or "No".
* **User Name**: Enter your name.
* **User Address**: Enter your address.
* **User City**: Enter your city.
* **User State**: Enter your state.
* **User Country**: Enter your country.
* **User Post Code**: Enter your postal code (zip or post code).
