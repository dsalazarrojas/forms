# motorsport_event_driver_declaration_form - Help Guide
## Purpose
The motorsport_event_driver_declaration_form is a form used to collect information about drivers participating in a motorsport event. This form is typically filled out as part of the event registration process.

## How To Complete This Form
To complete this form, follow these steps:

1. Find the motorsport_event_driver_declaration_form on the event website or application.
2. Review the form fields below to ensure you understand what each field is for.
3. Fill out the form with the required and optional information, making sure to follow the instructions for each field.
4. Submit the form to complete your declaration and registration for the event.

## Field-by-Field Explanation
* **Event ID** (`event_id`, Number, Optional): This field is used to identify the event you are declaring your participation in. If you are unsure which event ID to use, contact the event organizers.
* **Driver License Number** (`driver_license_number`, Text, Optional): Please enter your driver's license number if you have one. This helps the event organizers verify your identity.
* **Name** (`name`, Text, Optional): Please enter your full name.
* **Date of Birth** (`date_of_birth`, Date, Optional): Enter your date of birth in the format `YYYY-MM-DD`.
* **Emergency Contact Name** (`emergency_contact_name`, Text, Optional): If you have an emergency contact, please enter their name.
* **Emergency Contact Phone** (`emergency_contact_phone`, Text, Optional): If you have an emergency contact, please enter their phone number.
* **Emergency Contact Relationship** (`emergency_contact_relationship`, Select Multiple, Optional): If you have an emergency contact, please select how you are related to them (e.g., 'Yes' for a family member or 'No' for a friend).
* **Emergency Contact Email** (`emergency_contact_email`, Email, Optional): If you have an emergency contact, please enter their email address.

## Tips
* Make sure to fill out all the fields that apply to you.
* Ensure you enter accurate and up-to-date information.
* If you're unsure about any field, contact the event organizers for guidance.
* Review the form carefully before submitting it to avoid any issues.
