# Declaration Of Authenticity Form - Help Guide
## Purpose
This form is used to collect information about a user's identity and device details for verification purposes.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill in the required fields: title, declaration, signee_information, signee_title, signee_relationship, declaration_date, declaration_time, declaration_signed_by, declaration_signed_ip, declaration_device, declaration_note, form_id, user_agent, user_browser, declaration_ip, user_language, operating_system, user_os_version, declaration_device, device_type, screen_resolution, screen_orientation, device_width, device_height, device_timezone_offset.

## Field-by-Field Explanation
* **signers_information (Text)** (`signers_information`, Text, required): Enter a brief description of the signers.
* **declaration (Text)** (`declaration`, Text, required): Enter a description of the declaration.
* **signee_information (Text)** (`signee_information`, Text, required): Enter a brief description of the signee.
* **signee_title (Text)** (`signee_title`, Text, required): Enter the title of the signee.
* **signee_relationship (Text)** (`signee_relationship`, Text, required): Enter the relationship between the signers and signee.
* **declaration_date (Date)** (`declaration_date`, Date, required): Enter the date of the declaration.
* **declaration_time (Time)** (`declaration_time`, Time, required): Enter the time of the declaration.
* **declaration_signed_by (Select One)** (`declaration_signed_by`, Select One, required): Select whether the declaration was signed by the user or not.
* **declaration_signed_ip (Select One)** (`declaration_signed_ip`, Select One, required): Select whether the declaration was signed by the user's IP address or not.
* **declaration_note (Note)** (`declaration_note`, Note, required): Enter any notes about the declaration.
* **form_id (Text)** (`form_id`, Text, required): Enter the ID of the form.
* **user_agent (Text)** (`user_agent`, Text, required): Enter the user's agent information.
* **user_browser (Select Multiple)** (`user_browser`, Select Multiple, required): Select the user's browser type.
* **declaration_ip (Select One)** (`declaration_ip`, Select One, required): Select whether the declaration was signed by the user's IP address or not.
* **user_language (Select Multiple)** (`user_language`, Select Multiple, required): Select the user's language.
* **operating_system (Select Multiple)** (`operating_system`, Select Multiple, required): Select the user's operating system.
* **user_os_version (Select Multiple)** (`user_os_version`, Select Multiple, required): Select the user's OS version.
* **declaration_device (Select Multiple)** (`declaration_device`, Select Multiple, required): Select whether the declaration was signed by the user's device or not.
* **device_type (Select Multiple)** (`device_type`, Select Multiple, required): Select the type of the user's device.
* **screen_resolution (Select Multiple)** (`screen_resolution`, Select Multiple, required): Select the screen resolution of the user's device.
* **screen_orientation (Select Multiple)** (`screen_orientation`, Select Multiple, required): Select the screen orientation of the user's device.
* **device_width (Number)** (`device_width`, Number, required): Enter the width of the user's device.
* **device_height (Number)** (`device_height`, Number, required): Enter the height of the user's device.
* **device_timezone_offset (Number)** (`device_timezone_offset`, Number, required): Enter the time zone offset of the user's device.
