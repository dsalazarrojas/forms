# Gym Social Media Backdrop Order Form - Help Guide
## Purpose
The Gym Social Media Backdrop Order Form is used to collect information about a customer's social media backdrop orders.

## How To Complete This Form

1. Review the form fields carefully and answer accordingly.
2. Select the correct options for each field as per your order preferences.
3. Ensure that you're completing the form for a valid social media backdrop order.

## Field-by-Field Explanation

* **Backdrop Order** (`1`, `select_multiple`, required/optional: false): Select 'Yes' if you would like to place an order for a social media backdrop.
* **Logo Order** (`2`, `select_multiple`, required/optional: false): Select 'Yes' if you would like to order a logo for your social media backdrop.
* **Payments** (`3`, `select_multiple`, required/optional: false): Select 'Yes' if you have made payments for the order.
* **Gym Information** (`4`, `text`, required/optional: false): Provide a brief description of your gym or business.
* **Backdrop Type** (`5`, `select_multiple`, required/optional: false): Select the type of social media backdrop you're interested in.
* **Order Type** (`6`, `select_multiple`, required/optional: false): Select the type of order you're placing (e.g., new or existing order).
* **Customer Information** (`7`, `text`, required/optional: false): Enter any additional information about your business or gym (e.g., name, address).
* **Order Date** (`8`, `date`, required/optional: false): Enter the date on which you'd like to place the order. Please use the standard date format (YYYY-MM-DD).
