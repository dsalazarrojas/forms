# social_media_content_request_form - Help Guide
## Purpose
This form is designed to help you request social media content from our team. Please use this form to specify your requirements for a social media content request, and our team will create or schedule the content for you. 

## How To Complete This Form
To complete this form, follow these steps:
1. Choose the social media platform where you want the content to be posted (Facebook, Twitter, or Instagram).
2. Select the type of content you need (Post, Story, or Reels).
3. Briefly describe the content you require.
4. If applicable, select the date when you want the content to start and end.
5. Choose any relevant tags for the content.
6. Specify the social media manager responsible for the content.
7. If necessary, assign a tool for content creation.
8. Provide a unique form ID and category for the content request.
9. Briefly describe the content request.
10. Finally, select the output file format for the content.

## Field-by-Field Explanation

* **Social Media Platform** (`social_media_platform`, `select_one`, required: false): 
  Choose the social media platform where you want the content to be posted. 
  Select one of the following options: 
  - Facebook
  - Twitter
  - Instagram

* **Content Type** (`content_type`, `select_one`, required: false): 
  Select the type of content you need. 
  Choose one of the following options: 
  - Post
  - Story
  - Reels

* **Content Description** (`content_description`, `text`, required: false): 
  Briefly describe the content you require. 

* **Start Date** (`start_date`, `date`, required: false): 
  If you want the content to start on a specific date, select it here. 

* **End Date** (`end_date`, `date`, required: false): 
  If you want the content to end on a specific date, select it here. 

* **Content Tags** (`content_tags`, `select_multiple`, required: false): 
  Choose any relevant tags for the content. 
  Select multiple options: 
  - Tag 1
  - Tag 2
  - Tag 3

* **Social Media Manager** (`social_media_manager`, `text`, required: false): 
  Specify the social media manager responsible for the content. 

* **Assigned Tool** (`assigned_tool`, `select_one`, required: false): 
  If necessary, assign a tool for content creation. 
  Choose one of the following options: 
  - chatjimmy
  - Other

* **Form ID** (`form_id`, `number`, required: false): 
  Provide a unique form ID for the content request. 

* **Category** (`category`, `select_one`, required: false): 
  Choose a category for the content request. 
  Select one of the following options: 
  - Social Media Marketing Forms
  - Other

* **Description** (`description`, `text`, required: false): 
  Briefly describe the content request. 

* **Output File** (`output_file`, `select_one`, required: false): 
  Select the output file format for the content. 
  Choose one of the following options: 
  - 031 social media content request form--social media marketing forms
  - Other

* **Assigned Tool Name** (`assigned_tool_name`, `text`, required: false): 
  If necessary, specify the name of the assigned tool. 

* **Required** (`required`, `text`, required: true): 
  Confirm that the content request is complete and ready for review.
