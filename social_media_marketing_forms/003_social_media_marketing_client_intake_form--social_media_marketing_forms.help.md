# Social Media Marketing Client Intake Form - Help Guide
## Purpose

The Social Media Marketing Client Intake Form is used to gather information from clients to understand their social media marketing needs and preferences.

## How To Complete This Form

1. **Social Media Marketing Client Intake Form**: This is the title of the form and is not a field to fill in.
2. **Client Name**: Enter the full name of the client.
3. **Email**: Enter the email address of the client.
4. **Phone**: Enter the phone number of the client.
5. **Social Media Platforms**: Select all the social media platforms the client is interested in promoting (e.g., Facebook, Twitter, Instagram).
6. **Services**: Choose which services you would like us to provide (e.g., content creation, ad management, strategy development).
7. **Budget**: Enter a numerical value for the budget of the project.
8. **Notes**: Provide any additional notes or information about the client or project.
9. **Expectations**: Enter any specific expectations or requirements the client has for the project.
10. **Requirements**: Enter any specific requirements or constraints for the project.
11. **Goals**: Enter the goals of the project.
12. **Timeline**: Enter the expected start and end dates of the project.
13. **Review Date**: Enter the date by which you would like to have the project reviewed (not required).
14. **Review Time**: Enter the time by which you would like to have the project reviewed (not required).
15. **Assigned Tool**: Select whether you would like us to assign a specific tool to the project (e.g., Hootsuite, Buffer).
16. **Assigned User**: Select whether you would like to assign a specific user to the project (e.g., John Doe).
17. **Form Submission Status**: Select the status of the form submission (e.g., Active, Inactive).
18. **Notes Form Submission Status**: Select the status of the notes submission (e.g., Active, Inactive).
19. **Form Completion Date**: Enter the date by which you would like to have the form completed (not required).
20. **Form Completion Time**: Enter the time by which you would like to have the form completed (not required).
21. **Form Completion Note**: Provide any additional notes about the form completion.
22. **Notes Form Completion Status**: Select the status of the notes completion (e.g., Active, Inactive).
23. **Form Review Status**: Select the status of the form review (e.g., Active, Inactive).
24. **Form Revisions**: Enter the number of revisions expected for the form.
25. **Form Revision Comments**: Enter any comments about the expected revisions.
