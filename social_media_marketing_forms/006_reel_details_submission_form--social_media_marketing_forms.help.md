# Reel Details Submission Form - Help Guide

## Purpose
The Reel Details Submission Form is a tool for collecting submission details for a social media marketing campaign.

## How To Complete This Form
To complete this form, follow these steps:
1. Fill in the required fields with accurate and concise information.
2. Review each field carefully to ensure you're providing the correct details.
3. Submit the form when you've completed all the required fields.

## Field-by-Field Explanation
* **Reel Details (Page 1)** (`Reel Details Submission Form Page 1`, text, optional): 
  Enter a brief description of your submission, providing context for the creative brief and submission.
* **Creative Brief (Page 2)** (`Reel Details Submission Form Page 2`, text, optional): 
  Describe the creative brief or project requirements for the submission.
* **Submission (Page 3)** (`Reel Details Submission Form Page 3`, text, optional): 
  Provide a detailed description of the submission you're sharing.

## Tips
* Make sure to provide accurate and concise information for each field.
* If you're unsure about a field, refer to the form's purpose and description.
* Submit the form when you've completed all the required fields.
