# Social Media Engagement Metrics Report Form - Help Guide
## Purpose
This form is designed to collect information for a Social Media Engagement Metrics Report. The report will summarize engagement metrics for various social media platforms, including Facebook, Twitter, and Instagram.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the platforms for which you want to collect engagement metrics.
2. Choose the date range for which you want to collect metrics.
3. Fill in any other necessary fields, such as report title, description, and report type.

* **User Input** (`1`): Enter your name and any other relevant information. (optional)
* **Select Platform** (`2`): Choose the social media platforms for which you want to collect metrics. (Facebook, Twitter, Instagram)
