# Social Media Content Planning Form - Help Guide
## Purpose
The Social Media Content Planning Form is a tool used to plan and schedule social media content in a structured way.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the type of post or campaign you want to create (Post type: "Yes" or "No").
2. Decide who you want to target with your content (Target audience: select one or multiple options).
3. Choose the type of content you want to create (Content type: "Yes" or "No").
4. Add a detailed description of the content (Content details: a short paragraph).
5. Set the start date for the post or campaign (Start date: choose a date).
6. Set the end date for the post or campaign (End date: choose a date).
7. Select the platforms where you want to publish the content (Platforms: select one or multiple options).

## Field-by-Field Explanation

* **Post type (1)**: Select "Yes" if you want to create a new post, or "No" if you are planning to schedule a campaign.
* **Target audience (2)**: Choose the audience you want to target with your content. Select one or multiple options to create a diverse reach.
* **Content type (3)**: Select "Yes" if you want to create content that matches the chosen post type, or "No" if you don't want to specify.
* **Platforms (4)**: Choose where you want to publish the content, such as Facebook, Instagram, Twitter, etc.
* **Content details (5)**: Write a short paragraph describing the content you want to create, including its purpose and main message.
* **Start date (6)**: Set the date when you want to start publishing the content.
* **End date (7)**: Set the date when you want to stop publishing the content.
