# social_media_project_briefing_form - Help Guide
## Purpose
The social_media_project_briefing_form is used to create, manage, and track social media projects. This form captures essential project details, such as title, description, lead person, start and end dates, budget, target audience, project goal, status, category, and team members.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the project title and description in the corresponding fields.
2. Select the project lead person responsible for the project.
3. Set the start and end dates for the project.
4. Enter the project budget, if applicable.
5. Identify the target audience for the project.
6. Describe the project goal.
7. Choose the project status from the available options.
8. Select the project category from the available options.
9. Enter the number of team members involved in the project.
10. Click the "Submit" button to save your changes.

## Field-by-Field Explanation

* **Project Title** (text, optional): Enter a brief title for the project that describes its main objective.
* **Project Description** (text, optional): Provide a detailed description of the project, including its objectives and key deliverables.
* **Project Lead** (text, optional): Identify the person responsible for overseeing the project's progress.
* **Project Start Date** (date, optional): Enter the start date of the project.
* **Project Deadline** (date, optional): Enter the end date of the project.
* **Project Budget** (text, optional): Enter the allocated budget for the project, if applicable.
* **Target Audience** (text, optional): Identify the demographic or group of people the project aims to target.
* **Project Goal** (text, optional): Describe the main objective of the project.
* **Project Status** (select_one, optional): Select the current status of the project from the available options:
	+ Active: The project is currently active and being worked on.
	+ In Progress: The project is ongoing but not yet complete.
	+ On Hold: The project is temporarily paused or on hold.
	+ Cancelled: The project has been cancelled.
* **Project Category** (select_multiple, optional): Select the categories that apply to the project from the available options:
	+ Social Media Marketing: Projects focused on social media marketing strategies and activities.
	+ Social Media Advertising: Projects focused on social media advertising campaigns.
	+ Social Media Promotion: Projects focused on social media promotion, such as contests and giveaways.
	+ Social Media Contest: Projects focused on social media contests and competitions.
* **Team Members** (number, optional): Enter the number of team members involved in the project.
