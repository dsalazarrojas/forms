# Social Media Coverage Request Form - Help Guide
## Purpose
The Social Media Coverage Request Form is a tool for requesting targeted coverage on social media platforms. Use this form to submit your request and our team will review it to provide you with the best coverage options.

## How To Complete This Form
To complete this form, follow these steps:

1. Ensure that you have not already submitted a request for the event/campaign you are requesting coverage for.
2. Fill out the form with accurate and detailed information about your request.
3. Double-check your information for accuracy and completeness before submitting.

## Field-by-Field Explanation

* **User Information** (`user_information`, text, required: false): This field is optional, but it's always a good idea to fill it out so we can get in touch with you in case we need more information.
* **Media Requests** (`media_requests`, text, required: false): Describe the type of media coverage you are looking for (e.g. photos, videos, live streaming, etc.).
* **Social Media Channels** (`social_media_channels`, select_multiple, required: false): Select which social media channels you would like to be covered on (e.g. Twitter, Instagram, Facebook, etc.). You can select multiple channels if you have a multi-channel strategy.
* **Content Requests** (`content_requests`, text, required: false): Describe the type of content you are looking for (e.g. news articles, blog posts, social media posts, etc.).
* **Content Type** (`content_type`, select_multiple, required: false): Select the type of content you are looking for (e.g. text, image, video, etc.). You can select multiple content types if you have a diverse content strategy.
* **Content Length** (`content_length`, number, required: false): If you have a specific length in mind for the content (e.g. 500 words, 1-hour video, etc.), enter it here.
* **Start Date** (`start_date`, date, required: false): Enter the start date of the event/campaign you are requesting coverage for.
* **End Date** (`end_date`, date, required: false): Enter the end date of the event/campaign you are requesting coverage for.
* **Start Time** (`start_time`, time, required: false): If applicable, enter the start time of the event/campaign you are requesting coverage for.
* **End Time** (`end_time`, time, required: false): If applicable, enter the end time of the event/campaign you are requesting coverage for.
* **Content Description** (`content_description`, text, required: false): Provide a brief description of the content you are looking for.
* **Social Media Goals** (`social_media_goals`, text, required: false): Describe the specific social media goals you are trying to achieve with this campaign (e.g. increase engagement, drive traffic, etc.).
* **Target Audience** (`target_audience`, text, required: false): Describe the target audience for your campaign (e.g. age range, interests, etc.).
* **Contact Method** (`contact_method`, text, required: false): Select how you would like to be contacted (e.g. email, phone, etc.).
* **Contact Name** (`contact_name`, text, required: false): Enter the name of the person to contact.
* **Contact Email** (`contact_email`, email, required: false): Enter the email address of the person to contact.
* **Contact Phone** (`contact_phone`, text, required: false): Enter the phone number of the person to contact.
* **Contact Notes** (`contact_notes`, text, required: false): Add any additional notes or comments about your request.
