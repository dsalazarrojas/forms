# Social Media Embed Form - Help Guide
## Purpose
The Social Media Embed Form is used to collect information about a social media profile, including the platform, URL, email, phone number, and other relevant details. This form helps you to create a social media embed that can be used to connect with customers, partners, or other stakeholders.

## How To Complete This Form
To complete this form, please follow these steps:

1. Select the social media platform from the dropdown list (e.g. Facebook, Twitter, Instagram, LinkedIn, YouTube).
2. Enter the URL of the social media profile.
3. Enter the client's email address.
4. Enter the client's phone number.
5. (Optional) Enter the username of the social media profile.
6. (Optional) Enter a description of the social media profile.
7. (Optional) Select the category of the social media profile (e.g. Marketing, Product, Services, Other).
8. (Optional) Select multiple tags for the social media profile (e.g. Marketing, Product, Services, Other).
9. (Optional) Select the timezone of the social media profile (e.g. PST, EST, CST, MST, UTC).

## Field-by-Field Explanation
* **Social Media Platform** (`social_media_platform`, select_one): Select the social media platform from the dropdown list (e.g. Facebook, Twitter, Instagram, LinkedIn, YouTube).
* **URL** (`url`, text): Enter the URL of the social media profile.
* **Email** (`email`, email): Enter the client's email address.
* **Phone** (`phone`, text): Enter the client's phone number.
* **Username** (`username`, text): Enter the username of the social media profile (optional).
* **Description** (`description`, note): Enter a description of the social media profile (optional).
* **Category** (`category`, select_one): Select the category of the social media profile (e.g. Marketing, Product, Services, Other) (optional).
* **Tags** (`tags`, select_multiple): Select multiple tags for the social media profile (e.g. Marketing, Product, Services, Other) (optional).
* **Date Created** (`date_created`, date): Enter the date the social media profile was created (optional).
* **Timezone** (`time_zone`, select_one): Select the timezone of the social media profile (e.g. PST, EST, CST, MST, UTC) (optional).

## Tips
* Make sure to enter the correct URL of the social media profile.
* Use the correct timezone for the social media profile.
* Select the correct category and tags for the social media profile.
