# temperature_monitoring_device_program_application_form - Help Guide
## Purpose
The temperature monitoring device program application form is designed to collect relevant information about a temperature monitoring device program application.

## How To Complete This Form
To complete this form, follow these steps:
1. Fill out the facility address, phone number, contact person, facility type, device serial number, device description, start date, end date, and temperature range fields accurately and completely.
2. Ensure you are filling out the form as a representative of your facility.

## Field-by-Field Explanation

### Facility Address (1)
* Facility Address (`facility_address`, text, **required**): Enter the facility's address where the temperature monitoring device will be used.
*   This field should be the official address of your facility, such as a hospital or clinic.
*   Please ensure it is accurate and up-to-date.

### Facility Phone (2)
* Facility Phone (`facility_phone`, text, **required**): Enter the facility's phone number where you can be reached.
*   This field should be a valid phone number for the facility's contact person.
*   Please ensure it is accurate and up-to-date.

### Facility Contact Person (3)
* Facility Contact Person (`facility_contact_person`, text, **required**): Enter the name of the facility's contact person.
*   This field should be the name of the person who will be the point of contact for the temperature monitoring device program.
*   Please ensure it is accurate and up-to-date.

### Facility Type (4)
* Facility Type (`facility_type`, select_one, **required**): Select the type of facility where the device will be used.
*   Select one of the following options: Hospital, Clinic, Laboratory, Pharmacy, or Other.
*   Please select the option that best represents your facility's type.

### Device Serial Number (5)
* Device Serial Number (`device_serial_number`, number, **required**): Enter the serial number of the temperature monitoring device.
*   This field should contain the unique serial number assigned to the device.
*   Please ensure it is accurate and up-to-date.

### Device Description (6)
* Device Description (`device_description`, text, **required**): Enter a brief description of the temperature monitoring device.
*   This field should describe the device's model, manufacturer, and any other relevant details.
*   Please ensure it is accurate and up-to-date.

### Start Date (7)
* Start Date (`start_date`, date, **required**): Enter the start date of the temperature monitoring device program.
*   This field should be the date when the device will start being used.
*   Please ensure it is accurate and up-to-date.

### End Date (8)
* End Date (`end_date`, date, **required**): Enter the end date of the temperature monitoring device program.
*   This field should be the date when the device will stop being used.
*   Please ensure it is accurate and up-to-date.

### Temperature Range (9)
* Temperature Range (`temperature_range`, number, **required**): Enter the temperature range of the device.
*   This field should be the highest and lowest temperature values the device can measure.
*   Please ensure it is accurate and up-to-date.

## Tips

*   If you are unsure about any of the fields, please ask your supervisor or the program administrator for guidance.
*   Ensure you have all necessary approvals and signatures before submitting the form.
*   Review your answers carefully before submitting the form to ensure accuracy and completeness.
*   If you need help with the form, contact the program administrator or your supervisor.
