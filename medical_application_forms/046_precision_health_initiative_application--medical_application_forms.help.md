# Precision Health Initiative Application - Help Guide

## Purpose
The Precision Health Initiative Application form is designed to collect participant information and medical license details for the Precision Health Initiative program. This form is required to be completed by participants who wish to be part of this initiative.

## How To Complete This Form

1.  Review the form carefully and ensure you have all the necessary information before starting.
2.  Fill in the participant information on the first page, including participant details such as name, email, phone number, and address.
3.  Choose the correct options for interests and medical license details.
4.  Enter any additional notes or comments if necessary.
5.  Review your completed form for accuracy before submitting.

## Field-by-Field Explanation

*   **Application Information (Page 1: Application Information)**
    (`title`, `text`, required: false): Enter a brief title or subject for your application.
*   **Participant Details (Page 1: Application Information)**
    (`participant_details`, `text`, required: false): Enter any details about the participant.
*   **Interests (Page 2: Participant Details)**
    (`interests`, `select_multiple`, required: true): Select one or more interests from the provided options.
*   **Consent (Page 2: Participant Details)**
    (`consent`, `select_one`, required: true): Select the type of consent you are giving.
*   **Participant Interests (Page 3: Participant Interests)**
    (`participant_interests`, `number`, required: true): Enter the number of participant interests.
*   **Participant Name (Page 3: Participant Interests)**
    (`participant_name`, `text`, required: true): Enter the participant's name.
*   **Participant Email (Page 3: Participant Interests)**
    (`participant_email`, `email`, required: true): Enter the participant's email address.
*   **Participant Phone (Page 3: Participant Interests)**
    (`participant_phone`, `text`, required: true): Enter the participant's phone number.
*   **Participant Address (Page 3: Participant Interests)**
    (`participant_address`, `text`, required: true): Enter the participant's address.
*   **Research Program (Page 4: Research Program)**
    (`research_program`, `text`, required: true): Enter the research program name.
*   **Consent Date (Page 4: Research Program)**
    (`consent_date`, `date`, required: true): Enter the consent date.
*   **Medical License (Page 5: Medical License)**
    (`medical_license`, `text`, required: true): Enter medical license details.
*   **Medical License Number (Page 5: Medical License)**
    (`medical_license_number`, `text`, required: true): Enter medical license number.
*   **Medical License Type (Page 5: Medical License)**
    (`medical_license_type`, `select_one`, required: true): Select the type of medical license.
*   **Medical License Issue Date (Page 5: Medical License)**
    (`medical_license_issue_date`, `date`, required: true): Enter the medical license issue date.
*   **Medical License Expiration Date (Page 5: Medical License)**
    (`medical_license_expiration_date`, `date`, required: true): Enter the medical license expiration date.
*   **Note (Page 6: Note)**
    (`note`, `note`, required: false): Enter any additional notes or comments.
*   **Medical License Status (Page 6: Medical License)**
    (`medical_license_status`, `select_multiple`, required: false): Select the status of the medical license.
*   **Medical License Issued By (Page 6: Medical License)**
    (`medical_license_issued_by`, `text`, required: false): Enter the state or country where the license was issued.
*   **Medical License Issue Date (Page 6: Medical License)**
    (`medical_license_issued_date`, `date`, required: false): Enter the date the medical license was issued.
*   **Medical License Expiration Date (Page 6: Medical License)**
    (`medical_license_expiration_date`, `date`, required: false): Enter the date the medical license expires.
*   **Medical License License Number (Page 6: Medical License)**
    (`medical_license_license_number`, `text`, required: false): Enter the medical license number.
*   **Medical License Type 1 (Page 7: Medical License)**
    (`medical_license_type_1`, `text`, required: false): Enter medical license type 1.
*   **Medical License Type 2 (Page 7: Medical License)**
    (`medical_license_type_2`, `text`, required: false): Enter medical license type 2.
*   **Medical License Type 3 (Page 7: Medical License)**
    (`medical_license_type_3`, `text`, required: false): Enter medical license type 3.

Please fill out this form carefully and accurately to ensure the Precision Health Initiative Application is processed correctly. If you have any questions or need help with this form, please do not hesitate to contact us.
