## Patient Progress Report - Help Guide
## Purpose
The Patient Progress Report is a form used to track the progress of patients undergoing medical treatment. It is designed to be completed by healthcare professionals to gather information on a patient's condition, treatment, and progress. This form helps to identify areas of improvement and to monitor the patient's response to treatment.

## How To Complete This Form
To complete this form, follow these steps:

1. Review the patient's medical history and current condition.
2. Answer the questions according to your professional assessment.
3. Ensure that all required fields are completed, as indicated by the "required" field label.
4. If you are unsure about any field, consult with the patient or their medical records before proceeding.

## Field-by-Field Explanation
- **Patient Progress Report 1** (`patient_progress_report_1`, note, required: false): This is a free-text field where you can note any observations or comments about the patient's progress. This field is not required, but it can be useful for adding additional information that may not fit into other fields.
- **Medical Application Forms 1** (`medical_application_forms_1`, select_one, required: false): This field allows you to select whether the patient has been referred to medical applications, such as physical therapy or rehabilitation. Select "Yes" if the patient has been referred, and "No" if they have not.
- **Patient Progress Report 2** (`patient_progress_report_2`, text, required: false): This field is for recording any notes or comments about the patient's progress. It is intended for free-text entries.
- **Patient Progress Report 3** (`patient_progress_report_3`, time, required: false): This field is for recording the time elapsed since the patient's treatment started or has been in progress.
- **Patient Progress Report 4** (`patient_progress_report_4`, date, required: false): This field is for recording the date of the patient's last progress update.
- **Medical Application Forms 2** (`medical_application_forms_2`, select_multiple, required: false): This field allows you to select multiple medical applications that the patient has undergone, such as physical therapy, occupational therapy, etc.
- **Patient Progress Report 5** (`patient_progress_report_5`, number, required: false): This field is for recording numerical values about the patient's progress, such as the number of sessions attended or exercises completed.

## Tips
- Make sure to update the form regularly to reflect the patient's changing condition.
- Use clear and concise language when filling out the form.
- If you are unsure about any field, consult with the patient or their medical records before proceeding.
