# Wheelchair usage assessment checklist - Help Guide
## Purpose
This form is designed to assess the usage of wheelchairs for individuals with mobility impairments.

## How To Complete This Form
1. Review the form carefully and answer each question honestly.
2. Complete each section of the form, starting from the top.
3. For each question, select the correct answer from the options provided.
4. If an answer is not applicable, select "Not Applicable" in the relevant field.
5. If an answer requires a numerical value, enter the correct value in the relevant field.
6. Once you have completed all the sections, review your answers to ensure they are accurate and complete.

## Field-by-Field Explanation
* **Introduction** (`introduction`, note, required): This section provides a brief overview of the form and its purpose.
* **Wheelchair usage** (`wheelchair_usage`, select_multiple, required): This section assesses the individual's level of independence in using wheelchairs. Select all that apply:
	+ Independent
	+ Limited
	+ Dependent
* **Mobility** (`mobility`, text, required): This section collects information about the individual's mobility level. Please describe their current mobility level.
* **Independence** (`independence`, number, required): This section collects information about the individual's level of independence. Please enter a numerical value between 0 and 10, where 0 means fully dependent and 10 means fully independent.
* **Self-care** (`selfcare`, select_one, required): This section assesses the individual's self-care needs. Select one of the following:
	+ True
	+ False
	+ Not Applicable
* **Self-care frequency** (`selfcare_frequency`, number, required): This section collects information about how often the individual requires self-care. Please enter a numerical value.
* **Caregiver support** (`caregiver_support`, select_one, required): This section assesses the level of caregiver support the individual receives. Select one of the following:
	+ True
	+ False
	+ Not Applicable
* **Caregiver support frequency** (`caregiver_support_frequency`, number, required): This section collects information about how often the individual receives caregiver support. Please enter a numerical value.
* **Mobility aids** (`mobility_aids`, select_multiple, required): This section collects information about any mobility aids the individual uses. Select all that apply:
	+ Wheelchair
	+ Walker
	+ Canes
	+ Other
* **Mobility aids frequency** (`mobility_aids_frequency`, number, required): This section collects information about how often the individual uses mobility aids. Please enter a numerical value.
