# lab_test_referral_form - Help Guide
## Purpose
The lab test referral form is used to collect information about a patient and a lab test request, which is then sent to the lab or medical provider for processing.

## How To Complete This Form
1. **Enter the lab test referral**: Type in the details of the lab test referral in the "lab test referral" field.
2. **Enter the patient's name**: Type in the patient's name in the "patient name" field.
3. **Enter the patient's age**: Type in the patient's age in the number field.
4. **Select the test requested**: Choose one or more of the tests requested from the "test requested" dropdown menu.
5. **Enter the test date**: Type in the date the test is scheduled to take place.
6. **Enter the test time**: Type in the time the test is scheduled to take place (this field is optional).
7. **Enter the medical provider's information**: Type in the name and other details of the medical provider.
8. **Select the test type**: Choose the type of test the patient is scheduled to take.
9. **Enter the test location**: Type in the location where the test will take place.

## Field-by-Field Explanation
* **lab test referral**: This is the main description of the lab test referral, which should include the reason for the test and any other relevant information.
* **patient name**: This field should contain the name of the patient for whom the lab test is being referred.
* **patient age**: This field should contain the age of the patient.
* **test requested**: This field allows you to select one or more tests that are being requested for the patient.
* **test date**: This field should contain the date on which the lab test is scheduled to take place.
* **test time**: This field is optional and should contain the time on which the lab test is scheduled to take place.
* **medical provider**: This field should contain the name and other details of the medical provider who ordered the lab test.
* **test type**: This field allows you to select the type of test being requested.
* **test location**: This field should contain the location where the lab test will take place.
