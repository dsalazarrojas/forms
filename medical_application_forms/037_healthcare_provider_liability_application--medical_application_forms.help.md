# Healthcare Provider Liability Application - Help Guide
## Purpose
This form is used to collect and track liability information for healthcare providers.

## How To Complete This Form
1. Please fill out the form completely and accurately.
2. Verify that the provider is not already listed in our system before completing this form.
3. If you are unsure about any information, please ask for clarification or assistance.
