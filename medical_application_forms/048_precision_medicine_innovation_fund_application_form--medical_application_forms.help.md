# Precision Medicine Innovation Fund Application Form - Help Guide
## Purpose
The Precision Medicine Innovation Fund provides funding for innovative projects that leverage precision medicine approaches to improve human health. This form is used to submit applications for funding.

## How To Complete This Form
- Please complete the form carefully and accurately.
- Ensure that all required fields are filled in as they are mandatory for review.
- Use the provided options for the select fields to choose the most relevant option.
- If you're unsure about any field, consult with the relevant authority or project team.

## Field-by-Field Explanation

### **First Name** (`first_name`, text, **required**)
* This field is for your personal first name. Please enter your actual first name.

### **Last Name** (`last_name`, text, **required**)
* This field is for your personal last name. Please enter your actual last name.

### **Project Title** (`project_title`, text, **required**)
* This field is for the title of your project. It should accurately and concisely describe the project's purpose and objectives.

### **Project Description** (`project_description`, text, **required**)
* This field is for a detailed description of your project, including its goals, expected outcomes, and any relevant background information.

### **Project Location** (`project_location`, select_one, **required**)
* Please select the option that best describes the location of your project.

### **Funding Amount** (`funding_amount`, number, **required**)
* This field is for the amount of funding you are requesting. Please ensure it's reasonable and justified.

### **Funding Duration** (`funding_duration`, select_one, **required**)
* Please select the option that best describes the duration of your funding request.

### **Researcher Name** (`researcher_name`, text, **required**)
* This field is for the name of the principal researcher or investigator associated with the project.

### **Researcher Institution** (`researcher_institution`, text, **required**)
* This field is for the institution or organization associated with the researcher.

### **Review and Submission** (`form_page_5`, text, **optional**)
* This field is for any additional comments or notes. It's not required but may be useful for the review process.
