# Blood Donation Form - Help Guide

## Purpose
This form is used to collect information from potential blood donors. By filling out this form, you will be registering to become a blood donor and providing us with essential details about yourself. This information will help us assess your eligibility to donate blood and ensure a safe donation process.

## How To Complete This Form
To complete this form, simply fill out each required field with accurate and up-to-date information. Please note that fields marked as "required" must be filled out to submit the form. If you are unsure about any field, please consult the field's explanation below or contact our staff for guidance.

## Field-by-Field Explanation

* **First Name**: This is your given name as it appears on your government-issued ID.
	+ Type: `text`
	+ Required: Yes
* **Last Name**: This is your surname as it appears on your government-issued ID.
	+ Type: `text`
	+ Required: Yes
* **Date of Birth**: This is the date you were born, in the format MM/DD/YY.
	+ Type: `date`
	+ Required: Yes
* **Gender**: Please select your gender:
	+ Type: `select_one`
	+ Options: Male, Female, Other, Prefer not to say
	+ Required: Yes
* **Email Address**: This is the email address we will use to communicate with you about your donation.
	+ Type: `email`
	+ Required: Yes
* **Phone Number**: This is the phone number we can contact you at if needed.
	+ Type: `text`
	+ Required: Yes
* **Street Address**: This is your street address where you can be contacted at.
	+ Type: `text`
	+ Required: Yes
* **City**: This is the city where your street address is located.
	+ Type: `text`
	+ Required: Yes
* **State/Province**: This is the state or province your street address is located in.
	+ Type: `text`
	+ Required: Yes
* **ZIP/Postal Code**: This is the postal code of your street address.
	+ Type: `text`
	+ Required: Yes
* **Blood Type**: If known, please select your blood type:
	+ Type: `select_one`
	+ Options: O+, O-, A+, A-, B+, B-, AB+, AB-, Unknown
	+ Required: No
* **Weight (lbs)**: This is your weight in pounds.
	+ Type: `number`
	+ Required: Yes
* **Have you donated blood before?**: Check "Yes" if you have donated blood before, otherwise select "No".
	+ Type: `select_one`
	+ Options: Yes, No
	+ Required: Yes
* **Do you have any chronic health conditions?**: Check "Yes" if you have any chronic health conditions, otherwise select "No".
	+ Type: `select_one`
	+ Options: Yes, No
	+ Required: Yes
* **Are you currently taking medications?**: Check "Yes" if you are currently taking any medications, otherwise select "No".
	+ Type: `select_one`
	+ Options: Yes, No
	+ Required: Yes
* **Do you have any allergies?**: Check "Yes" if you have any allergies, otherwise select "No".
	+ Type: `select_one`
	+ Options: Yes, No
	+ Required: Yes
* **Family history of blood disorders?**: Check "Yes" if there is a family history of blood disorders, otherwise select "No" or "Unknown".
	+ Type: `select_one`
	+ Options: Yes, No, Unknown
	+ Required: Yes
* **Emergency Contact Name**: This is the name of the person we can contact in case of an emergency.
	+ Type: `text`
	+ Required: No
* **Emergency Contact Phone**: This is the phone number of the person we can contact in case of an emergency.
	+ Type: `text`
	+ Required: No
* **Registration Date**: This is the date your registration will be processed and updated in our system.
	+ Type: `date`
	+ Required: Yes

## Tips
Please make sure to fill out all required fields accurately and truthfully. If you are unsure about any field, please ask our staff for guidance. We are here to help you through the process.
