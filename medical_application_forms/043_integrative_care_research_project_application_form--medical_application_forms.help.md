# Integrative Care Research Project Application Form - Help Guide
## Purpose
The Integrative Care Research Project Application Form is designed to collect project-related information from applicants. It is intended for those who are eligible to submit a project proposal for the Integrative Care Research Project.

## How To Complete This Form
To complete this form, follow these steps:
1. Fill in the project details, including project objectives.
2. Provide information about the project team members, including their names and roles.
3. Select the project status, methodology, and project budget.
4. Choose the team organizer and team lead.
5. Add any additional notes or comments.

## Field-by-Field Explanation
* **Project Details**: Fill in the project's title and objectives. This should be a brief description of the project's goals and objectives.
* **Project Objectives**: Enter the project's objectives, which should be specific, measurable, achievable, relevant, and time-bound (SMART) goals.
* **Team Details**: Provide a brief description of the project team, including their names and roles.
* **Team Member 1**: Enter the name and role of the first team member. If you have more than 10 team members, please add their details in the subsequent fields.
* **Team Lead**: Select the team lead from the options provided.
* **Methodology**: Choose the project methodology from the options provided.
* **Project Status**: Select the project status from the options provided.
* **Project Budget**: Select the project budget from the options provided.
* **Location**: Enter the project location.
* **Project Status Description**: Provide a brief description of the project status.
* **Team Organizer**: Select the team organizer from the options provided.
* **Team Lead Description**: Enter a brief description of the team lead.
* **Notes**: Add any additional comments or notes about the project.
