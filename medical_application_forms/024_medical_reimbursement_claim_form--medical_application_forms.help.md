# Medical Reimbursement Claim Form - Help Guide
## Purpose
This form is intended to be used for medical reimbursement claims. It provides a structured format for applicants to submit their claims.

## How To Complete This Form
To complete this form, please follow these steps:
1. Select the correct answer for "Is this a valid claim?" in question 1.
2. Fill in the applicant's first name, last name, and address on page 2.
3. Fill in the medical service provider's name, address, and zip code on page 2.
4. Select the date of services provided in question 13.
5. Enter the total amount paid in question 14.
6. Select the claim status, submission status, and submitted on dates in questions 15, 16, and 17.
7. Enter the claim ID, claim date, medical condition, treatment cost, claim amount, and submit by and submitted to in questions 19, 20, 21, 22, 23, and 24.

## Field-by-Field Explanation

* **Is this a valid claim?** (1, Select One): Please indicate if this is a valid claim.
* **Applicant First Name** (2, Text): Enter the first name of the applicant.
* **Applicant Last Name** (3, Text): Enter the last name of the applicant.
* **Applicant Address Line 1** (4, Text): Enter the address line 1 of the applicant.
* **Applicant City** (5, Text): Enter the city of the applicant.
* **Applicant State** (6, Select One): Select the state of the applicant.
* **Applicant Zip** (7, Text): Enter the zip code of the applicant.
* **Medical Service Provider Name** (8, Text): Enter the name of the medical service provider.
* **Medical Service Provider Address Line 1** (9, Text): Enter the address line 1 of the medical service provider.
* **Medical Service Provider City** (10, Text): Enter the city of the medical service provider.
* **Medical Service Provider State** (11, Select One): Select the state of the medical service provider.
* **Medical Service Provider Zip** (12, Text): Enter the zip code of the medical service provider.
* **Date of Services** (13, Date): Select the date of services provided.
* **Total Amount Paid** (14, Number): Enter the total amount paid.
* **Claim Status** (15, Select One): Select the claim status.
* **Submission Status** (16, Select One): Select the submission status.
* **Submitted On** (17, Date): Select the date submitted.
* **Received On** (18, Date): Select the date received.
* **Claim ID** (19, Text): Enter the claim ID.
* **Claim Date** (20, Date): Enter the claim date.
* **Medical Condition** (21, Select One): Select the medical condition.
* **Medical Treatment Cost** (22, Number): Enter the medical treatment cost.
* **Claim Amount** (23, Number): Enter the claim amount.
* **Submitted By** (24, Text): Enter the person who submitted the claim.
* **Submitted To** (25, Text): Enter the person to whom the claim was submitted.

## Tips
* Please ensure all fields are filled out accurately and completely.
* Double check your information before submitting the form.
