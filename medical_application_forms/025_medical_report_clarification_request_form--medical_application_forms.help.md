# Medical Report Clarification Request Form - Help Guide
## Purpose
The Medical Report Clarification Request Form is designed to request clarification on medical reports that are missing or unclear information. This form helps providers identify areas where further clarification is needed and provides a clear way to communicate this need to other medical professionals.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the `patient_name` field with the name of the patient whose report is being requested for clarification.
2. Enter the `report_date` field with the date of the report that needs clarification.
3. Provide a brief description of the `clarification_question` field, explaining what clarification is needed.
4. Select whether the report requires the `provider_name` to be contacted (Yes/No).
5. Indicate whether the report requires medical `medical_specialty` knowledge (Yes/No).
6. Select the relevant medical specialty for the report (Yes/No).
7. Choose whether the report is related to a `question` that requires clarification (Yes/No).
8. Provide a clear and concise answer to the `answer` field, addressing the clarification question.
9. Enter any additional `request_reason` for clarification.
10. Use the `additional_info` field for any further information or comments that may be relevant.

## Field-by-Field Explanation
* **patient_name** (text): Enter the name of the patient whose report is being requested for clarification.
* **report_date** (date): Enter the date of the report that needs clarification.
* **clarification_question** (text): Provide a brief description of what clarification is needed for the report.
* **provider_name** (select_one): Select Yes if the report requires the provider to be contacted for further information.
* **medical_specialty** (select_multiple): Indicate whether the report requires medical knowledge from various specialties.
* **question** (select_one): Select Yes if the report is related to a question that requires clarification.
* **answer** (text): Provide a clear and concise answer to the clarification question.
* **request_reason** (text): Enter any additional reason for requesting clarification.
* **additional_info** (note): Use this field for any further information or comments that may be relevant.
