# <string> - Help Guide
## Purpose
This form is used to collect and maintain medical information of students. It's essential to have accurate and up-to-date medical records to ensure the student's health and well-being.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the student's **User Name**.
2. Provide the **Parent Name** of the student if required.
3. Enter the **Contact Phone** number (if applicable).
4. Enter the **Contact Email** (if applicable).
5. Fill in the student's **Address** (if applicable).
6. Enter the **Zip Code** (if applicable).
7. Fill in the **Date of Birth** of the student.
8. Provide the student's **Student Name** (if applicable).
9. Enter the **School Name** (if applicable).
10. Fill in the student's **Student ID** (if applicable).
11. Enter the **Contact Number** (if applicable).
12. Provide any **Medical History** information.
13. Specify the **Medical History Details** (if applicable).
14. Answer whether the student has ever been **Ever Sick**.
15. Answer whether the student has ever received **Ever Sick Prophets Treatment**.
16. Answer whether the student has ever had **Ever Inpatient Treatment**.
17. Answer whether the student has ever had **Ever Outpatient Treatment**.
18. Answer whether the student has ever been **Ever Hospitalized**.
19. Answer whether the student has ever had **Ever Surgery**.
20. Answer whether the student has ever been in **Ever Been in Therapy**.
21. Answer whether the student has ever had **Ever Mental Health Issue**.
22. Answer whether the student has ever been **Ever Physical Abuse**.
23. Answer whether the student has ever had **Ever Sexual Abuse**.
24. Answer whether the student has ever had **Ever Other**.

## Field-by-Field Explanation

- **User Name** (`user_name`, `Text`, required): This is the student's name for reference purposes.
*   **Parent Name** (`parent_name`, `Text`, required): This is the parent's name of the student if applicable.
*   **Contact Phone** (`contact_phone`, `Text`, optional): This is the phone number to contact in case of an emergency.
*   **Contact Email** (`contact_email`, `Email`, optional): This is the email address to contact in case of an emergency.
*   **Address** (`address`, `Text`, optional): This is the student's address for reference purposes.
*   **Zip Code** (`zip_code`, `Number`, optional): This is the zip code of the student's address.
*   **Date of Birth** (`date_of_birth`, `Date`, optional): This is the student's date of birth.
*   **Student Name** (`student_name`, `Text`, optional): This is the student's name (if different from the User Name).
*   **School Name** (`school_name`, `Text`, optional): This is the name of the school the student attends (if applicable).
*   **Student ID** (`student_id`, `Text`, optional): This is the student's ID number (if applicable).
*   **Contact Number** (`contact_number`, `Text`, optional): This is the contact number to contact in case of an emergency.
*   **Medical History** (`medical_history`, `Text`, optional): This is a field for providing any medical history information.
*   **Medical History Details** (`medical_history_details`, `Text`, optional): This is a field for providing any additional medical history details.
*   **Ever Sick** (`medical_history_ever_sick`, `Select One`, optional): This is a question asking whether the student has ever been sick.
*   **Ever Sick Prophets Treatment** (`medical_history_ever_s_prophets_treatment`, `Select One`, optional): This is a question asking whether the student has ever received sick prophets treatment.
*   **Ever Inpatient Treatment** (`medical_history_ever_inpatient_treatment`, `Select One`, optional): This is a question asking whether the student has ever received inpatient treatment.
*   **Ever Outpatient Treatment** (`medical_history_ever_outpatient_treatment`, `Select One`, optional): This is a question asking whether the student has ever received outpatient treatment.
*   **Ever Hospitalized** (`medical_history_ever_hospitalized`, `Select One`, optional): This is a question asking whether the student has ever been hospitalized.
*   **Ever Surgery** (`medical_history_ever_surgery`, `Select One`, optional): This is a question asking whether the student has ever undergone surgery.
*   **Ever Been in Therapy** (`medical_history_ever_been_in_therapy`, `Select One`, optional): This is a question asking whether the student has ever been in therapy.
*   **Ever Mental Health Issue** (`medical_history_ever_mental_health_issue`, `Select One`, optional): This is a question asking whether the student has ever had a mental health issue.
*   **Ever Physical Abuse** (`medical_history_ever_physical_abuse`, `Select One`, optional): This is a question asking whether the student has ever experienced physical abuse.
*   **Ever Sexual Abuse** (`medical_history_ever_sexual_abuse`, `Select One`, optional): This is a question asking whether the student has ever experienced sexual abuse.
*   **Ever Other** (`medical_history_ever_other`, `Select One`, optional): This is a question asking whether the student has ever had any other medical history issues.
