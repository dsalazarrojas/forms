# Prescription Management Access Form - Help Guide
## Purpose
The Prescription Management Access Form is used by medical staff to access and manage prescription information for patients. This form gathers essential information about a patient's prescription and is only for authorized personnel.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the patient's name in the "Patient Name" field.
2. Enter the patient's phone number in the "Patient Phone" field.
3. Enter the name of the medical provider in the "Medical Provider Name" field.
4. Enter the date the prescription was requested in the "Prescription Request Date" field.
5. Enter the prescription number in the "Prescription Number" field.
6. Enter the patient's age in the "Patient Age" field.
7. Enter the medical record number in the "Medical Record Number" field.
8. Select the type of prescription request from the "Prescription Request Type" field.
9. Select the status of the prescription from the "Prescription Status" field.

## Field-by-Field Explanation
* **Patient Name (text, required: false)**: Enter the patient's name.
* **Patient Phone (text, required: false)**: Enter the patient's phone number.
* **Medical Provider Name (text, required: false)**: Enter the medical provider's name.
* **Prescription Request Date (date, required: false)**: Enter the date the prescription was requested.
* **Prescription Number (text, required: false)**: Enter the prescription number.
* **Patient Age (number, required: false)**: Enter the patient's age.
* **Medical Record Number (text, required: false)**: Enter the medical record number.
* **Prescription Request Type (select_one, required: false)**: Select the type of prescription request (New Prescription, Refill, or Cancel Prescription).
* **Prescription Status (select_multiple, required: false)**: Select the status of the prescription (Approved, Denied, or Pending).
