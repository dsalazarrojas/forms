# echocardiography_credentialing_application - Help Guide

## Purpose

This form is used for credentialing applications for echocardiography professionals. It is designed to gather information about the professional's training, experience, and qualifications in the field of echocardiography.

## How To Complete This Form

1. Fill out the form completely and accurately, ensuring all required fields are filled out.
2. Review the form carefully to avoid duplication of effort.
3. Ensure that all relevant information is provided.

## Field-by-Field Explanation

* **Application Information** (1):
	+ A text field to provide general information about the application.
* **Training Verification** (2):
	+ A date field to indicate when the professional's training was verified.
* **Supporting Documentation** (3):
	+ A select multiple field to indicate whether supporting documentation is available.
	+ Options: Yes, No
* **Hospital Name** (4):
	+ A text field to enter the name of the hospital or institution.
* **Contact Information** (5):
	+ A text field to provide contact information for the professional.
* **Email** (6):
	+ An email field to enter the professional's email address.
* **Phone Number** (7):
	+ A number field to enter the professional's phone number.
* **Date** (8):
	+ A date field to indicate when the credentialing process was completed.
* **Time** (9):
	+ A time field to indicate when the credentialing process was completed.
* **Note** (10):
	+ A note field for any additional comments or information.
* **Echocardiography Credential** (11):
	+ A select one field to indicate the professional's credential level:
		+ Echocardiography
		+ Basic
		+ Advanced
		+ Fellow
		+ None
* **Credentialing Team** (12):
	+ A select multiple field to indicate whether the professional has interacted with the credentialing team:
		+ Yes
		+ No
* **Training Program** (13):
	+ A select multiple field to indicate whether the professional has completed a training program:
		+ Yes
		+ No
* **Hospital** (14):
	+ A select one field to indicate whether the professional works at the current hospital:
		+ Yes
		+ No
* **Training Verification Date** (15):
	+ A date field to indicate when the professional's training was verified.

## Tips

* Double-check the accuracy of all information before submitting the form.
* Ensure that all required fields are filled out.
* If you are unsure about any field, please consult with the credentialing team.
* If you are having trouble completing the form, please contact the credentialing team for assistance.
