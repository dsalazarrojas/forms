# Science Center Evaluation Form - Help Guide
## Purpose
The Science Center Evaluation Form is designed to gather feedback and evaluation from users about their experience at science centers. This form is used by science center staff or administrators to collect data on various aspects of their services, including the quality of exhibits, programs, and overall experience.

## How To Complete This Form

1. The form is divided into multiple pages, each with several fields.
2. Please answer each question carefully, making sure to provide as much detail as possible.
3. If you have a comment or feedback for a particular question, please type it in the corresponding field.
4. If you have no experience in a particular area, please choose "No" or select "None" as required.
5. Make sure to fill out all fields that are marked as "required".
6. Use the text fields to provide any additional comments or details that are not included in the select fields.
7. Once you have filled out all the required fields, click the "submit" button to complete and submit the form.

## Field-by-Field Explanation

* **first_page**: This is the first page of the form. Please fill out this page first.
* **second_page**: This is the second page of the form. If you are not asked to move on to the next page, please stay on this page.
* **science_areas**: Please select all areas of science that you have experience in. If you have experience in other areas not listed, please type it in the **science_areas_other** field.
* **science_areas_other**: If you have experience in other areas not listed, please select "Yes" and type in the text field.
* **science_centers**: Please select all science centers you have experience in. If you have experience in other centers not listed, please type it in the **science_centers_other** field.
* **overall_experience**: Please select your overall experience in science centers. If you have experience that does not fit into any of the options, please type it in the **overall_experience_other** field.
* **exhibits**: Please select all exhibits that you have experience with. If you have experience in other exhibits not listed, please type it in the **exhibits_other** field.
* **programs**: Please select all programs that you have experience with. If you have experience in other programs not listed, please type it in the **programs_other** field.
* **recommendations**: Please select all recommendations that you have experience with. If you have experience in other recommendations not listed, please type it in the **recommendations_other** field.
* **comments**: Please use this field to provide any additional comments or feedback about your experience at science centers.
* **first_name**: Please type in your first name.
* **email**: Please type in your email address.
* **phone**: Please type in your phone number.
* **submit**: This is the date and time you completed the form.
* **submit_time**: This is the time you completed the form.
* **science_areas_other_text**: If you selected "Yes" in the science_areas field, please type in the text field.
* **overall_experience_other**: If you selected "Yes" in the overall_experience field, please type in the text field.
* **exhibits_other**: If you selected "Yes" in the exhibits field, please type in the text field.
* **programs_other**: If you selected "Yes" in the programs field, please type in the text field.
* **recommendations_other**: If you selected "Yes" in the recommendations field, please type in the text field.
* **science_areas_other_text**: If you selected "Yes" in the science_areas field, please type in the text field.
* **overall_experience_other_text**: If you selected "Yes" in the overall_experience field, please type in the text field.
* **exhibits_other_text**: If you selected "Yes" in the exhibits field, please type in the text field.
* **programs_other_text**: If you selected "Yes" in the programs field, please type in the text field.
* **recommendations_other_text**: If you selected "Yes" in the recommendations field, please type in the text field.

## Tips
* Please make sure to answer all questions carefully and truthfully.
* If you need help or have any questions, don't hesitate to ask.
* The form is designed to be completed in a few minutes, so please take your time and answer all questions thoroughly.
* If you have any feedback or suggestions, please don't hesitate to share them with us.
