# Transcript Authorization Form - Help Guide
## Purpose
The Transcript Authorization Form is used to request access to a student's transcript. This form is typically completed by parents, guardians, or other authorized individuals who need access to a student's academic record.

## How To Complete This Form
To complete this form, follow the steps below:

1. Ensure you have a legitimate reason for submitting this form.
2. Complete each field accurately and completely.

## Field-by-Field Explanation
* **Student Name** (`student_name`, text, required: false): Enter the name of the student whose transcript you are requesting access to. Please ensure that this is the correct name as it appears on the transcript.
* **Relationship** (`relationship`, select_one, required: false): Select the relationship you hold to the student, e.g., Mother, Father, or Guardian.
* **Contact Number** (`contact_number`, text, required: false): Enter a valid phone number for the contact person. This number will be used as the primary point of contact for transcript access.
* **Student ID Number** (`student_id_number`, text, required: false): Enter the student's ID number as it appears on their transcript.

## Tips
- Ensure that you have the necessary permissions and information to submit this form.
- Only submit this form if you are not a duplicate request.
- If you are experiencing issues with this form, please contact our support team for assistance.
