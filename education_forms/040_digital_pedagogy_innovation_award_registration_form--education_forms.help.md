# Digital Pedagogy Innovation Award Registration Form - Help Guide
## Purpose
The "Digital Pedagogy Innovation Award Registration Form" is a tool used to collect and evaluate projects that demonstrate innovative uses of digital pedagogy in education. By filling out this form, you can register your project and have it considered for the award.

## How To Complete This Form
- Read through each section carefully before filling out the form.
- Make sure to fill out each required field (indicated by an asterisk *).
- Enter accurate and up-to-date information for each field.

## Field-by-Field Explanation
* **Project Details** (`project_details`, text, required: false): This field should be a brief description of your project, explaining what it's about and what makes it innovative.
* **Project Name** (`project_name`, text, required: false): Enter a brief name for your project that clearly describes it.
* **Name of Innovator** (`name_of_innovator`, text, required: false): Fill out the name of the person or team leading the project.
* **Institution** (`institution`, select_one, required: false): Select the institution that is associated with the project from the provided list (Institution A, Institution B, Institution C).
* **Project Type** (`project_type`, select_one, required: false): Choose the type of project from the options (Type A, Type B, Type C) that best fits your project.
* **Project Date** (`project_date`, date, required: false): Enter the date when your project was completed.
* **Email** (`email`, email, required: false): Enter a valid email address for contact and communication purposes.
* **Contact Name** (`contact_name`, text, required: false): Fill out the name of the person or team member who should be contacted.
* **Contact Email** (`contact_email`, email, required: false): Enter a valid email address for the contact person.
* **Contact Phone** (`contact_phone`, text, required: false): Enter a valid phone number for the contact person.
* **Project Status** (`project_status`, select_multiple, required: false): Select one or more of the statuses that best describe your project (Status A, Status B, Status C).
* **Notes** (`notes`, note, required: false): Enter any additional information or context about your project that you feel is relevant.
* **Institution URL** (`institution_url`, text, required: false): Enter the URL of the institution associated with the project.

## Tips
- Make sure all fields have valid and up-to-date information.
- If you are unsure about any field, contact us for clarification.
- This form is designed to be filled out once per project, so make sure you submit the correct project details.
