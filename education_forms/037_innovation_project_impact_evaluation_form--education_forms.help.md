# Innovation Project Impact Evaluation Form - Help Guide
## Purpose
This form helps project teams and administrators evaluate the impact of innovation projects, providing a systematic and standardized way to collect relevant information about project success, outcomes, and areas for improvement.

## How To Complete This Form

1. Select the project title and start and end dates to accurately reflect the project timeline.
2. Provide a brief description of the project.
3. Choose the project impact area(s) that apply to the project.
4. Enter the number of participants involved in the project.
5. Record the project location, if applicable.
6. Provide details about the project funding and outcomes.
7. Answer questions about project outcomes, impact, and indicators.
8. Select the evaluation period and frequency.
9. Specify who submitted the form and when.

## Field-by-Field Explanation

* **Project Title (required)**: Enter the title of the innovation project.
* **Project Description (optional)**: Provide a brief description of the project.
* **Project Start Date (required)**: Enter the date the project started.
* **Project End Date (required)**: Enter the date the project ended.
* **Project Start Time (required)**: Enter the time the project started.
* **Project End Time (required)**: Enter the time the project ended.
* **Project Impact Area (required)**: Select the area(s) where the project had a positive impact. Choose one or more of the following options:
	+ Yes
	+ No
* **Other (if above options do not apply) (optional)**: If the project had an impact in an area not listed above, provide a brief description.
* **Project Outcome (required)**: Describe the project outcome(s).
* **Project Participants (required)**: List the number of participants involved in the project.
* **Project Location (optional)**: Enter the location where the project took place.
* **Project Funding (optional)**: Provide details about the project funding.
* **Project Outcomes Measurable (optional)**: Describe the project outcomes that can be measured.
* **Project Impact Measurable (optional)**: Describe the project impact that can be measured.
* **Project Outcomes Indicators (optional)**: Describe the project outcomes that can be tracked.
* **Project Impact Indicators (optional)**: Describe the project impact that can be tracked.
* **Project Evaluation Period (required)**: Select the evaluation period for the project. Choose one of the following options:
	+ Quarterly
	+ Biannually
	+ Annually
* **Evaluation Frequency (required)**: Choose how often the project will be evaluated. Select one of the following options:
	+ Once
	+ More than once
* **Submitter (required)**: Specify who submitted the form. Choose one of the following options:
	+ Admin
	+ Staff
* **Submit Date (required)**: Enter the date the form was submitted.
* **Submit Time (required)**: Enter the time the form was submitted.
* **Evaluation Notes (required)**: Provide any additional comments or notes about the project evaluation.

## Tips

* Ensure you have all necessary information before submitting the form.
* Double-check the accuracy of your answers.
* Review the form before submitting to avoid errors.
