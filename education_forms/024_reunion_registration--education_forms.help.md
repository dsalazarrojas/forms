# Reunion Registration - Help Guide
## Purpose
The Reunion Registration form is used to collect information about upcoming reunions, enabling efficient organization and coordination of the event.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the title of the reunion in the `Reunion Registration` field.
2. Fill out the `Name` field with the name of the person or group attending the reunion.
3. In the `Family Members` field, select the applicable option to indicate whether or not family members will be attending.
4. For the `Event Date`, select the date of the reunion from the calendar.
5. Enter the `Start Time` and `End Time` of the reunion in the respective fields.
6. Choose a location for the reunion from the available options in the `Location` field.
7. Select the type of reunion (e.g., School, Family, Other) in the `Reunion Type` field.
8. Enter the name of the person coordinating the reunion in the `Contact Name` field.
9. Provide the email address of the person coordinating the reunion in the `Contact E-mail` field.
10. Enter the phone number of the person coordinating the reunion in the `Contact Phone` field.
11. Add any additional details about the event in the `Event Details` field.
12. If you have any other information to add, you can type it in the `Notes` field.

## Field-by-Field Explanation

* **Reunion Registration** (id: 1, label: Reunion Registration, required: true, type: text): Enter a brief title for the reunion.
* **Name** (id: 2, label: Name, required: false, type: text): Provide the name of the person or group attending the reunion.
* **Family Members** (id: 3, label: Family Members, required: true, type: select_multiple): Indicate whether family members will be attending the reunion. Select 'Yes' or 'No'.
* **Event Date** (id: 4, label: Event Date, required: false, type: date): Choose the date of the reunion from the calendar.
* **Start Time** (id: 5, label: Start Time, required: false, type: time): Enter the start time of the reunion.
* **End Time** (id: 6, label: End Time, required: false, type: time): Enter the end time of the reunion.
* **Location** (id: 7, label: Location, required: false, type: text): Select the location of the reunion.
* **Reunion Type** (id: 8, label: Reunion Type, required: false, type: select_one): Choose the type of reunion (e.g., School, Family, Other).
* **Contact Name** (id: 9, label: Contact Name, required: false, type: text): Enter the name of the person coordinating the reunion.
* **Contact E-mail** (id: 10, label: Contact E-mail, required: false, type: email): Provide the email address of the person coordinating the reunion.
* **Contact Phone** (id: 11, label: Contact Phone, required: false, type: text): Enter the phone number of the person coordinating the reunion.
* **Event Details** (id: 12, label: Event Details, required: false, type: note): Add any additional details about the event.
* **Notes** (id: 13, label: Notes, required: false, type: note): Add any other information about the reunion.

## Tips

* Please ensure that you have filled out all required fields.
* Review the form carefully to avoid errors.
* If you have any questions or concerns, contact the person coordinating the reunion.
