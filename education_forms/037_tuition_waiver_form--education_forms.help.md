# Tuition Waiver Form - Help Guide
## Purpose

This form is used to process tuition waivers for students, allowing you to select the waiver type and fill out relevant fields based on the number of students you are processing.

## How To Complete This Form

1. Select the waiver type for each student by choosing from the available options.
2. Fill out the relevant fields for each student, including name, student ID, email, and other required fields.
3. If you are processing multiple students, additional fields will be displayed to accommodate each student's information.

## Field-by-Field Explanation

- **Student Name** (Student Name, text, required/optional): Enter the student's name as it appears on their official documents.
- **Student ID** (Student ID, number, required/optional): Enter the student's ID number.
- **Tuition Amount** (Tuition Amount, number, required/optional): Enter the current tuition amount for the student.
- **Waiver Type** (Waiver Type, select one, required): Select the type of waiver to apply for (Full Tuition or Partial Tuition).
  - Select one option from the available options.
- **Start Date** (Start Date, date, required/optional): Enter the start date of the waiver.
- **End Date** (End Date, date, required/optional): Enter the end date of the waiver.
- **Reason for Waiver** (Reason for Waiver, note, required/optional): Enter a brief reason for the waiver.
- **Student Email** (Student Email, email, required/optional): Enter the student's email address.
- **Staff Name** (Staff Name, text, required/optional): Enter the name of the staff member involved.
- **Staff ID** (Staff ID, number, required/optional): Enter the staff member's ID number.
- **Tuition Type** (Tuition Type, select multiple, required): Select the type of fees to waive (Academic Fees, Other Fees, Total Fees).
  - Select one or more options from the available options.
- **Status** (Status, select multiple, required/optional): Select the status of the waiver (Active, Inactive).
  - Select one or more options from the available options.
- **Student Status** (Student Status, select multiple, required/optional): Select the status of the student (Active, Inactive).
  - Select one or more options from the available options.
- **Staff Department** (Staff Department, select one, required): Select the department of the staff member involved (Admissions, Financial Aid, Registrar).
  - Select one option from the available options.
- **Tuition Fees Waived** (Tuition Fees Waived, number, required/optional): Enter the amount of tuition fees waived.
- **Tuition Fees Remaining** (Tuition Fees Remaining, number, required/optional): Enter the remaining tuition fees.
- **Second Student Name** (Second Student Name, text, required/optional): Enter the name of the second student (if applicable).
- **Second Student ID** (Second Student ID, number, required/optional): Enter the ID number of the second student (if applicable).
- **Second Staff Name** (Second Staff Name, text, required/optional): Enter the name of the second staff member involved (if applicable).
- **Second Staff ID** (Second Staff ID, number, required/optional): Enter the ID number of the second staff member involved (if applicable).
- **Second Reason for Waiver** (Second Reason for Waiver, note, required/optional): Enter a brief reason for the waiver of the second student.
- **Second Student Email** (Second Student Email, email, required/optional): Enter the email address of the second student (if applicable).
- **Second Staff Email** (Second Staff Email, email, required/optional): Enter the email address of the second staff member involved (if applicable).
- **Second Staff Department** (Second Staff Department, select one, required/optional): Select the department of the second staff member involved (Yes, No).
  - Select one option from the available options.
- **Second Tuition Fees Waived** (Second Tuition Fees Waived, number, required/optional): Enter the amount of tuition fees waived for the second student.
