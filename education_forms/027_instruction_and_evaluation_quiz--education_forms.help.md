# Instruction And Evaluation Quiz - Help Guide
## Purpose
The purpose of this form is to help instructors create and evaluate quizzes for their students, collecting data on student performance.

## How To Complete This Form
To complete this form, follow these steps:

1. Begin by filling out the first text field (question_1) with the main question you want to ask your students.
2. In the second field (question_2), select the best option from the list of options (option 1 and option 2) that best answers the question.
3. In the third field (question_3), enter the date you want to use for the quiz.
4. In the fourth field (question_4), enter a note or comment about the quiz.
5. In the fifth field (question_5), enter the time you want to use for the quiz.
6. In the sixth field (question_6), enter a valid email address.
7. In the seventh field (question_7), enter more text about the quiz.
8. In the eighth field (question_8), select all that apply from the list of options (option 9, option 10, option 11).
9. In the ninth field (question_9), enter a number (e.g. a score or a value).

## Field-by-Field Explanation

* **section_label** (`section`, text, required: false): This field is a text field for you to enter a name or label for your section.
* **question_1** (`question_1`, text, required: false): This field is for entering the main question you want to ask your students.
* **question_2** (`question_2`, select_one, required: false): This field is a select one field where you can choose the best option from the list of options (option 1 and option 2) that best answers the question.
* **question_3** (`question_3`, date, required: false): This field is for entering the date you want to use for the quiz.
* **question_4** (`question_4`, note, required: false): This field is for entering a note or comment about the quiz.
* **question_5** (`question_5`, time, required: false): This field is for entering the time you want to use for the quiz.
* **question_6** (`question_6`, email, required: false): This field is for entering a valid email address.
* **question_7** (`question_7`, text, required: false): This field is for entering more text about the quiz.
* **question_8** (`question_8`, select_multiple, required: false): This field is a select multiple field where you can choose all that apply from the list of options (option 9, option 10, option 11).
* **question_9** (`question_9`, number, required: false): This field is for entering a number (e.g. a score or a value).

## Tips
* Make sure to enter valid email addresses in the email field.
* Be careful when entering dates and times as they should be in the correct format.
* Use the select multiple field to choose all that apply from the list of options.
