# Lunch And Learn Planning Form - Help Guide
## Purpose
The Lunch and Learn Planning Form is used to collect essential details about upcoming lunch and learn events. This form helps event organizers gather necessary information to plan and execute the event efficiently.

## How To Complete This Form
To complete this form, please follow these steps:
- Fill in the required fields with accurate and complete information.
- Review each field for clarity and correctness.

## Field-by-Field Explanation
* **Base Form Data** (`base_form_data`, text, optional): Enter any additional information not captured by other fields.
* **Event Name** (`event_name`, text, required): Enter the name of the event.
* **Event Details** (`event_details`, text, required): Provide a brief description of the event.
* **Event Date** (`event_date`, date, required): Enter the date of the event (in YYYY-MM-DD format).
* **Event Time** (`event_time`, time, required): Choose the start time of the event.
* **Location** (`venue`, text, required): Specify the location of the event.
* **Attendees** (`attendees`, select_multiple, required): Choose whether attendees are expected or not.
* **Speaker** (`speaker`, select_one, optional): Choose whether the event has a speaker or not.
* **Event Topics** (`event_topics`, text, optional): List any relevant topics discussed during the event.
* **Event Description** (`event_description`, text, optional): Enter any additional event information not captured elsewhere.
