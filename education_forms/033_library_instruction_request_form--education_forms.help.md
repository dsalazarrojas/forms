# Library Instruction Request Form - Help Guide
## Purpose
The Library Instruction Request Form is designed to facilitate the submission of requests for library instructional sessions, research consultations, or database training for students. This guide will walk you through the process of filling out the form and explain each field in detail.

## How To Complete This Form
To complete this form, please follow these steps:
1. Fill in the **Requestor** field with your name.
2. Enter the name of the **Instructor** who will be conducting the session.
3. Specify the name of the **Course** for which the session is being requested.
4. Choose the type of session you are requesting: **Library Instructional Session**, **Research Consultation**, **Database Training**, or **Other**.
5. Select a suitable date and time for the session.
6. Choose a **Duration** for the session.
7. Select a suitable **Room** for the session.
8. Specify any **Equipment** that is required for the session.
9. Enter any additional **Comments** you would like to share with the library staff.
10. Finally, click the submit button to send the form to the library staff.

## Field-by-Field Explanation

* **Requestor** (Required): The name of the person requesting the library session.
* **Instructor** (Required): The name of the instructor who will be conducting the session.
* **Course** (Required): The name of the course for which the session is being requested.
* **Session Type** (Required): Choose the type of session you are requesting: **Library Instructional Session**, **Research Consultation**, **Database Training**, or **Other**.
* **Date** (Required): Select a suitable date for the session.
* **Start Time** (Required): Enter the start time for the session.
* **End Time** (Required): Enter the end time for the session.
* **Duration** (Required): Choose the duration of the session.
* **Room** (Required): Select a suitable room for the session.
* **Equipment** (Required): Specify any equipment that is required for the session.
* **Comments** (Required): Enter any additional comments or details you would like to share with the library staff.
* **Form ID** (Optional): A unique ID assigned to the form by the system.
* **Assigned Tool** (Optional): Specify any tools or resources assigned to the form.
* **Created At** (Optional): Timestamp when the form was created.
* **Modified At** (Optional): Timestamp when the form was last modified.
* **Created By** (Optional): The name of the person who created the form.
* **Modified By** (Optional): The name of the person who last modified the form.
* **Assigned To** (Optional): The name of the person assigned to the form.
* **Assigned At** (Optional): Timestamp when the form was assigned to someone.
* **Modified At** (Optional): Timestamp when the form was last modified.
* **Status** (Optional): A text field for entering any status information.
* **Notes** (Optional): Any additional notes about the form.
* **Description** (Optional): A text field for entering any description of the form.
* **Category** (Optional): The category of the form.
