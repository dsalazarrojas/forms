# Education Assessment Method Audit Form - Help Guide
## Purpose

This form is designed to collect information about the education assessment methods and processes used in your institution. Your feedback and input will help us evaluate and improve the assessment process.

## How To Complete This Form

1. Answer each question carefully and honestly.
2. Please provide detailed explanations for your answers where possible.
3. If you have any additional comments or suggestions, please use the "Additional Comments" field.

## Field-by-Field Explanation

* **General Information**: Please provide your general contact information.
* **Assessment Frequency**: Select the frequency at which assessments are conducted. 
* **Assessment Methods**: Please select one of the methods used for assessment.
* **Assessment Principles**: Select all the principles that are applied in the assessment process. 
* **Review Process**: Please describe the review process used in the assessment. 
* **Review Frequency**: Select the frequency at which reviews are conducted. 
* **Assessment Data Sources**: Select all the sources used for the assessment data. 
* **Assessment Reporting**: Select the type of report used for assessment. 
* **Overall Satisfaction**: Rate your overall satisfaction with the assessment process. 
* **Open Ended Comments**: Please provide any additional comments or suggestions. 
* **Review Date**: Select the date of the last review. 
* **Review Time**: Select the time of the last review. 
* **Submitted By**: Select the user who submitted the assessment. 
* **Submitted At**: Select the time when the assessment was submitted. 
* **Submitted Date**: Select the date when the assessment was submitted. 
* **Submitted Date 1**: Select the first date when the assessment was submitted. 
* **Submitted Date 2**: Select the second date when the assessment was submitted. 
* **Submitted Date Time 2**: Select the date and time when the assessment was submitted. 
* **Submitted Time**: Select the time when the assessment was submitted. 
* **Email**: Please enter your email address. 
* **Phone**: Please enter your phone number. 
* **Additional Comments**: Please provide any additional comments or suggestions. 
* **Submitted Date and Time**: Select the date and time when the assessment was submitted. 

Please submit this form to provide us with your valuable feedback and suggestions.
