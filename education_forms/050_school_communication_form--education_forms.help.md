# School Communication Form - Help Guide
## Purpose
This form is designed to help schools communicate with parents, teachers, or both, through various channels such as email, phone, or meeting. It is used to send messages and attachments to parents, and to set communication preferences and frequency.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the parent's details in the "Parent Details" field.
2. Select the preferred method of communication from the "Communication Preferences" field (e.g., email, phone, or meeting).
3. Choose how often you want to communicate with the parent from the "Communication Frequency" field (e.g., weekly, bi-weekly, or monthly).
4. Enter the contact number of the parent in the "Contact Number" field.
5. Enter the email address of the parent in the "Email" field.
6. Write a message to the parent in the "Message" field.
7. If applicable, attach a file to the message by selecting "File" in the "Attachment" field.
8. Decide who you want to send the message to from the "Send To" field (e.g., teacher, parent, or both).
9. Choose when you want to send the message from the "Send At" field (e.g., now, later, or never).
10. If desired, attach a file to the message by selecting "File" in the "Attachment File" field.
11. Add any additional notes in the "Notes" field.

## Field-by-Field Explanation
- **Parent Details (required)**: Enter the details of the parent you are communicating with, such as their name and any other relevant information.
- **Communication Preferences (required)**: Select the preferred method of communication (e.g., email, phone, or meeting).
- **Communication Frequency (required)**: Choose how often you want to communicate with the parent (e.g., weekly, bi-weekly, or monthly).
- **Contact Number (required)**: Enter the contact number of the parent.
- **Email (required)**: Enter the email address of the parent.
- **Message (required)**: Write a message to the parent.
- **Attachment (required)**: If applicable, attach a file to the message by selecting "File".
- **Send To (required)**: Decide who you want to send the message to (e.g., teacher, parent, or both).
- **Send At (required)**: Choose when you want to send the message from the options provided (e.g., now, later, or never).
- **Attachment File (optional)**: If desired, attach a file to the message by selecting "File".
- **Notes (optional)**: Add any additional notes about the communication.
- **Send At**: Select when you want to send the message (e.g., now, later, or never).
