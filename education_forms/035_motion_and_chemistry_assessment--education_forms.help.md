# Motion And Chemistry Assessment - Help Guide
## Purpose
The Motion And Chemistry Assessment form is designed to evaluate students' performance in motion and chemistry classes. It helps teachers or administrators track student progress and provide feedback to students and parents.

## How To Complete This Form
To complete the form, follow these steps:

1. Navigate through the pages using the provided navigation buttons.
2. Fill out each page with the required information, starting from the first page (Main Page).
3. Ensure that all required fields are filled out before proceeding to the next page.

## Field-by-Field Explanation
### Main Page (Page 1)
* **Student Info** (Student Info, Select One, Required): Choose one of the provided options to select the student's information.
* **Student ID** (Student ID, Number, Required): Enter the student's ID number.
* **Student Name** (Student Name, Text, Required): Enter the student's name.
* **Student Parent Name** (Student Parent Name, Text, Optional): Enter the student's parent's name (if applicable).

### Student Info Page (Page 2)
* **Email** (Email, Email, Required): Enter the student's email address.
* **Phone Number** (Phone Number, Text, Optional): Enter the student's phone number.
* **Date** (Date, Date, Required): Enter the date of assessment.
* **Time** (Time, Time, Required): Enter the time of assessment.
* **Teacher Name** (Teacher Name, Text, Optional): Enter the teacher's name (if applicable).

### Motion and Chemistry Assessment Page (Page 3)
* **Motion Assessment** (Motion Assessment, Number, Required): Enter the student's assessment score for motion.
* **Chemistry Assessment** (Chemistry Assessment, Number, Required): Enter the student's assessment score for chemistry.
* **Additional Info** (Additional Info, Text, Optional): Enter any additional comments or information about the student.
* **Comments** (Comments, Text, Optional): Enter any comments about the student's performance.

### Second Assessment Page (Page 4)
* **Motion Assessment 2** (Motion Assessment 2, Number, Required): Enter the student's second assessment score for motion.
* **Chemistry Assessment 2** (Chemistry Assessment 2, Number, Required): Enter the student's second assessment score for chemistry.
* **Email 2** (Email 2, Email, Required): Enter the student's email address (if different from the first assessment).
* **Phone Number 2** (Phone Number 2, Text, Optional): Enter the student's phone number (if different from the first assessment).
* **Date 2** (Date 2, Date, Required): Enter the date of the second assessment.
* **Time 2** (Time 2, Time, Required): Enter the time of the second assessment.
* **Teacher Name 2** (Teacher Name 2, Text, Optional): Enter the teacher's name (if different from the first assessment).
* **Comments 2** (Comments 2, Text, Optional): Enter any comments about the student's performance at the second assessment.

## Tips
* Make sure to fill out all required fields before proceeding to the next page.
* Review each page carefully to ensure accuracy and consistency.
* Use the provided options for selecting student information and other fields as necessary.
* If you have any doubts or concerns, please contact the relevant authorities for clarification.
