# Student Co Op Form - Help Guide
## Purpose
The Student Co Op Form is used to collect information about students participating in co-op programs.

## How To Complete This Form
To complete this form, follow these steps:

1. Choose the student's name from the dropdown menu under "Student Information".
2. Enter the details of the co-op program in the "Co Op Details" field.
3. Select the start and end dates of the co-op program.
4. Enter the number of co-op hours worked.
5. Choose the supervisor's name from the dropdown menu under "Supervisor Information".
6. Enter any additional notes about the co-op program in the "Co Op Notes" field.
7. Select the institutions where the co-op program took place from the dropdown menu under "Institution Information".
8. Enter the student's email and phone number (if applicable).

## Field-by-Field Explanation

* **Student Information**: Choose the student's name from the dropdown menu to select the student's identity.
* **Co Op Details**: Enter the details of the co-op program, such as its duration, location, and tasks. This field is for entering free-text information about the co-op experience.
* **Start Date**: Enter the start date of the co-op program. This field is only available if the "Co Op Details" field is filled out.
* **End Date**: Enter the end date of the co-op program. This field is only available if the "Co Op Details" field is filled out.
* **Co Op Hours**: Enter the number of co-op hours worked. This field is only available if the "Co Op Details" field is filled out.
* **Supervisor Information**: Choose the supervisor's name from the dropdown menu to select the supervisor's identity.
* **Co Op Notes**: Enter any additional notes about the co-op program, such as accomplishments, challenges, and lessons learned.
* **Institution Information**: Choose the institutions where the co-op program took place from the dropdown menu to select the institutions' identities.
* **Email**: Enter the student's email. This field is optional and only available if the "Institution Information" field is filled out.
* **Phone**: Enter the student's phone number. This field is optional and only available if the "Institution Information" field is filled out.
* **Fax**: Enter the student's fax number. This field is optional and only available if the "Institution Information" field is filled out.

## Tips

* Make sure to fill out all required fields before submitting the form.
* Use clear and concise language in the "Co Op Details" and "Co Op Notes" fields to describe the co-op experience.
* Be accurate when selecting the student's name, supervisor's name, and institution's name to ensure correct records are kept.
* Use the "Start Date", "End Date", and "Co Op Hours" fields to keep track of important dates and details about the co-op program.
* Use the "Co Op Notes" field to add any additional context or comments about the co-op experience.
