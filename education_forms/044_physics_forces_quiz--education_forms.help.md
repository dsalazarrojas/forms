# Physics Forzes Quiz - Help Guide
## Purpose
This form is designed to test your understanding of various aspects of physics forces, including types of forces, their application, and the laws that govern them.

## How To Complete This Form
To complete this form, please follow these steps:

1. Read each question carefully and answer the required fields.
2. For text fields, provide a clear and concise answer.
3. For multiple-choice fields, select all applicable options.
4. Make sure to fill in all required fields, indicated by a asterisk (\*) next to the field label.

## Field-by-Field Explanation
* **What is a force?** (*): This field is the starting point for the quiz. Please provide a brief and clear answer to this question.
* **Types of forces**: This field is a multiple-choice question with four options: gravity, friction, normal, and tension. Select all types of forces that apply to the question.
* **Gravity question**: This is a text field where you will provide an answer to a question related to gravity.
* **Gravitational force**: This field asks for a numerical value representing the gravitational force. Make sure to enter a valid number.
* **Newtons Laws**: This field is a multiple-choice question where you will select all three laws that apply.
* **Force application**: This field is a single-choice question where you will select how forces are applied (contact or non-contact).
* **Physics forces question 2**: This is an optional text field where you can provide additional information related to physics forces.
* **Physics forces question 3**: This is another optional text field where you can provide more information about physics forces.

## Tips
* Make sure to answer all required fields.
* If you're unsure about a question, try to provide a clear and concise answer based on your best understanding.
* If you need more information or clarification about a question, feel free to ask.
