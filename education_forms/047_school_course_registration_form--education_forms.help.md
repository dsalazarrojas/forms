# School Course Registration Form - Help Guide
## Purpose
The School Course Registration Form is a tool for registering students, courses, and teachers' information in a school's administrative system. This form allows you to gather data necessary for course management and student tracking.

## How To Complete This Form

To register a course, follow these steps:
- Enter the student information, including name and grade level.
- Select the course details, such as start date, end date, and course name.
- Choose the course section from the given options.
- Fill in the course status and teacher's email.
- Add any additional notes or comments if necessary.

## Field-by-Field Explanation

* **Student Information (id: 6)**: Enter the student's name for the course.
* **Grade Level (id: 7)**: Choose the student's grade level.
* **Course Name (id: 8)**: Enter the name of the course.
* **Section Name (id: 9)**: Enter the section name if not already chosen.
* **Course Status (id: 10)**: Choose the course status (Pending, Approved, or Rejected).
* **Teacher Email (id: 15)**: Enter the teacher's email address.
* **Email (id: 13)**: Enter the student's email address.
* **Phone (id: 14)**: Enter the student's phone number.
* **Student Phone (id: 17)**: Enter the student's phone number.
* **Course Code (id: 20)**: Enter the course code.
* **School Code (id: 24)**: Enter the school code.
* **Section Note (id: 12)**: Add any notes for the section.
* **Grade Level Hint (id: 18)**: Enter a brief description of the student's grade level.
* **Course Code Hint (id: 21)**: Enter a brief description of the course code.
* **Course Name Hint (id: 22)**: Enter a brief description of the course name.
* **Course Status Hint (id: 23)**: Enter a brief description of the course status.
