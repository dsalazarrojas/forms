# Faculty Collaboration Effectiveness Index Survey - Help Guide
## Purpose
The Faculty Collaboration Effectiveness Index Survey is a tool to help you assess your collaboration experiences, satisfaction, and challenges as a faculty member. This survey aims to gather information on your collaboration effectiveness, identify areas for improvement, and provide suggestions for enhancing collaboration.

## How To Complete This Form
To complete this form, follow these steps:
1. Select the frequency of your collaboration activities for each category.
2. Choose the most important factor affecting collaboration from your perspective.
3. List any challenges you face in collaboration.
4. If you have any suggestions for improving collaboration, type them in the "Suggestions" field.
5. If you have any additional comments, please type them in the "Comments" field.

## Field-by-Field Explanation
* **How Often Do You Collaborate** (`collaboration_frequency`, select_multiple): This question asks about the frequency of your collaboration activities with your colleagues. Please select one or more of the options below:
	+ Never
	+ Rarely
	+ Occasionally
	+ Frequently
	+ Almost Always
* **What Do You Think Is the Most Important Factor Affecting Collaboration** (`collaboration_satisfaction`, select_one): This question asks you to identify the most important factor affecting collaboration. Please select one of the options below:
	+ Trust Among Team Members
	+ Clear Goals and Expectations
	+ Effective Communication
	+ Shared Resources and Responsibilities
	+ Other (please specify)
	+ None
* **What Are Some Challenges You Face in Collaboration** (`challenges`, select_multiple): This question asks about the obstacles you face in collaboration. Please select one or more of the options below:
	+ Time constraints
	+ Lack of Shared Resources
	+ Different Priorities
	+ Communication Breakdown
	+ Other (please specify)
	+ None
* **Do You Have Any Suggestions for Improving Collaboration** (`suggestions`, note): This field is for you to type any suggestions you have for improving collaboration. Please be as specific as possible.
* **Other (please specify)** (`collaboration_frequency_other`, text): This field is for you to type any additional information related to collaboration frequency that is not listed in the previous options.
* **Comments** (`comments`, note): This field is for you to type any additional comments or feedback you have about the survey.
