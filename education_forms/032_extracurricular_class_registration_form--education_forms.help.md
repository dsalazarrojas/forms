# Extracurricular Class Registration Form - Help Guide
## Purpose
The Extracurricular Class Registration Form is used to register students for extracurricular classes, sports, and clubs.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the student's name.
2. Enter the parent's name (if applicable).
3. Enter the student's email address.
4. Enter the student's phone number.
5. Enter the name of the extracurricular class or activity.
6. Enter the duration of the class (in weeks or months).
7. Enter the fees for the class.
8. Enter the date of the class.
9. Enter the time of the class.
10. Enter the location of the class.
11. Enter a brief description of the class.
12. Enter the name of the person organizing the class.
13. Enter any requirements for the class (e.g. equipment, dress code, etc.).
14. Enter the type of equipment needed for the class (if applicable).
15. Enter the dress code requirements for the class (if applicable).
16. Select the frequency of class meetings.
17. Select the type of fees for the class (e.g. one-time, monthly, etc.).
18. Select the status of the class registration (e.g. pending, approved, etc.).
19. Enter the parent's signature.
20. Enter the student's signature.
21. Enter the date and time of submission.

## Field-by-Field Explanation

* **Student Name**: Enter the student's full name as it appears on their records.
* **Parent Name**: Enter the parent's name if the student is a minor and requires a parent's signature. This is optional, but required for students under 18 years old.
* **Student Email**: Enter the student's email address for contact purposes.
* **Student Phone**: Enter the student's phone number for contact purposes.
* **Extracurricular Class Name**: Enter the name of the extracurricular class or activity being registered for.
* **Class Duration**: Enter the duration of the class in weeks or months.
* **Fees**: Enter the fees associated with the class, if any.
* **Class Date**: Enter the date of the class.
* **Class Time**: Enter the time of the class.
* **Class Location**: Enter the location of the class.
* **Class Description**: Enter a brief description of the class.
* **Class Organizer**: Enter the name of the person organizing the class.
* **Class Requirements**: Enter any requirements for the class, such as equipment, dress code, etc.
* **Equipment Needed**: Enter the type of equipment needed for the class, if applicable.
* **Dress Code**: Enter the dress code requirements for the class, if applicable.
* **Class Meetings**: Select the frequency of class meetings.
* **Fees Type**: Select the type of fees for the class, such as one-time, monthly, etc.
* **Class Status**: Select the status of the class registration, such as pending, approved, etc.
* **Parent Signature**: Enter the parent's signature if required.
* **Student Signature**: Enter the student's signature if required.
* **Submission Date/Time**: Enter the date and time of submission of the form.
