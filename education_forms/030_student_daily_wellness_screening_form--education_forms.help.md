# Student Daily Wellness Screening Form - Help Guide
## Purpose
This form is designed to gather information from students about their current health status. It is intended to be completed by parents or guardians on behalf of the student.

## How To Complete This Form
To complete this form, follow these steps:

1. Please select the options that best describe the student's current health status.
2. Select "No" for any symptoms that the student does not have.
3. If you are unsure or do not know the answer to a question, select "Don't know".
4. Complete all sections of the form accurately and completely.
5. Submit the form when finished.

## Field-by-Field Explanation
* **Has Fever** (`has_fever`, select_one, required): Please select "Fever" if the student has a fever, and "No Fever" if they do not.
* **Has Cough** (`has_cough`, select_multiple, required): Please select all symptoms that apply. For example, if the student has a cough and a sore throat, select both "Cough" and "Sore Throat".

* **Has Runny Stomach** (`has_runny_stomach`, select_multiple, required): Please select all symptoms that apply. For example, if the student has a runny stomach, select "Runny Stomach".
* **Has Headache** (`has_headache`, select_one, required): Please select "Headache" if the student has this symptom, and "No Headache" if they do not.

* **Has Confusion** (`has_confusion`, select_one, required): Please select "Confusion" if the student has this symptom, and "No Confusion" if they do not.

* **Has Other Symptom** (`has_other_symptom`, text, optional): If the student has any other symptoms not listed, please describe them here.

## Tips
* Please answer all questions honestly and to the best of your ability.
* If you are unsure about any of the questions, select "Don't know".
* If you have any concerns or questions about the form, please contact the school's health services or a medical professional.
