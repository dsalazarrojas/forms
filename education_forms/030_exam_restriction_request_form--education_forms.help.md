# Exam Restriction Request Form - Help Guide
## Purpose
This form is designed to help you request exam restrictions for a specific exam. This may include accommodations for students who need special assistance during the exam.

## How To Complete This Form
To complete this form, please follow these steps:

1.  Please fill out the "Exam Restriction Request" field with a brief description of the exam restriction you are requesting.
2.  Enter the student's name in the "Student Name" field.
3.  Enter the course ID number in the "Course ID" field.
4.  Select the accommodation type(s) that apply to the student's exam restriction in the "Accommodation Type" field. You can choose from pre-defined options or select "Other" and provide further explanation in the "Other Accommodation Type" field.
5.  If you selected "Other" in the "Accommodation Type" field, please enter a detailed description of the accommodation type in the "Other Accommodation Type" field.
6.  If you need to provide any supporting documentation for the exam restriction, please upload or attach it in the "Document" field.
7.  If you need to provide any additional information not covered in the "Document" field, you can enter it in the "Other Document" field.
8.  Please select who is submitting the request in the "Submitter" field. You can choose from pre-defined options or select "Other" and provide further explanation in the "Other Submitter" field.
9.  If you selected "Other" in the "Submitter" field, please enter a detailed description of who is submitting the request in the "Other Submitter" field.
10.  Finally, enter the department or unit that the exam is administered for in the "Department" field.

## Field-by-Field Explanation
* **Exam Restriction Request** (`Exam Restriction Request`, `text`, optional): Enter a brief description of the exam restriction you are requesting. This could include details about why the student needs accommodation, such as a disability-related need or a personal reason.
* **Student Name** (`Student Name`, `text`, optional): Enter the student's name who is requesting the exam restriction.
* **Course ID** (`Course ID`, `text`, optional): Enter the course ID number for the exam that the student needs accommodation for.
* **Accommodation Type** (`Accommodation Type`, `select_multiple`, optional): Select one or more of the pre-defined options for the accommodation type.
	+ **Accommodated**: The student has been accommodated in the past for this exam and needs continued support.
	+ **Not Accommodated**: The student does not need any accommodations for this exam.
	+ **No Response**: This option is not applicable for the current exam.
* **Other Accommodation Type** (`Other Accommodation Type`, `text`, optional): If you selected "Other" in the "Accommodation Type" field, enter a detailed description of the accommodation type here.
* **Document** (`Document`, `text`, optional): If you need to provide any supporting documentation for the exam restriction, upload or attach it here.
* **Other Document** (`Other Document`, `text`, optional): If you need to provide any additional information not covered in the "Document" field, enter it here.
* **Submitter** (`Submitter`, `select_one`, optional): Select who is submitting the request.
	+ **Student**: The student is submitting the request.
	+ **Instructor**: The instructor is submitting the request.
	+ **Other**: Select "Other" and enter a detailed description of who is submitting the request in the "Other Submitter" field.
* **Other Submitter** (`Other Submitter`, `text`, optional): If you selected "Other" in the "Submitter" field, enter a detailed description of who is submitting the request.
* **Department** (`Department`, `text`, optional): Enter the department or unit that the exam is administered for.
