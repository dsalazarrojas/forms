# Numeric Input Practice Form - Help Guide
## Purpose
This form is a practice form for users to get familiar with inputting numbers in different formats, such as text, number, time, date, select-one, select-multiple, email, and phone numbers.

## How To Complete This Form
To complete this form, simply navigate through the pages and fill out each field. You can input any value in each field, but please be aware that some fields may not accept certain types of input (e.g., a text field will only accept text input). 

## Field-by-Field Explanation
* **First question** (`numeric_input_1`, text, optional): This field allows you to input a text that represents a number, for example, "one", "ten", "twenty".
* **Basic calculation** (`numeric_input_2`, number, optional): This field expects a numerical value, such as "4" or "5.2".
* **Confidence level** (`confidence_level`, number, optional): This field also expects a numerical value, representing your confidence level, for example, "8" or "9".
* **Estimated time** (`time_estimate`, time, optional): This field is for inputting a time value, such as "12:00" or "3:30 PM".
* **Estimated date** (`date_estimate`, date, optional): This field is for inputting a date value, such as "2022-01-01" or "2022-01-31".
* **Select one** (`select_one_1`, select-one, optional): This field has three options: A, B, and C. Choose one option from the dropdown list.
* **Select multiple** (`select_multiple_1`, select_multiple, optional): This field also has three options: D, E, and F. You can select multiple options.
* **Email** (`email`, email, optional): This field expects a valid email address, such as "example@example.com".
* **Phone** (`phone`, text, optional): This field expects a phone number or any other text value.

## Tips
* Be sure to input values that are correct and relevant to the field type.
* Remember that some fields have options, so be sure to choose one option when selecting multiple options.
* This form is a practice form, so do not attempt to submit actual data.
* Have fun filling out this form!
