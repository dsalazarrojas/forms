# Sustainability Design Absence Form - Help Guide
## Purpose
The Sustainability Design Absence Form is a tool used to document and report on the absence of sustainability design in a project. It is designed to collect relevant data on project characteristics, absence reasons, and status.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the project's name, start date, and end date. Ensure that the start and end dates are accurate, as they are required fields.
2. Select the appropriate project type from the available options or type it in if not listed.
3. Provide a brief explanation for the absence reason.
4. If applicable, describe the absence impact on the project.
5. Choose the project status from the options provided.

## Field-by-Field Explanation
### Project name (Project name)
 * Project name: The name of the project.
### Start date (Start date)
 * Start date: The date when the project started.
### End date (End date)
 * End date: The date when the project ended.
### Project type (Project type)
 * Project type: A short description of the project type.
### Absence reason (Absence reason)
 * Absence reason: A brief explanation for the absence of sustainability design in the project.
### Absence impact (Absence impact)
 * Absence impact: An optional field to describe the impact of the absence on the project.
### Project status (Project status)
 * Project status: Select the status of the project from the available options (Status A, Status B, Status C).
### Comments (Comments)
 * Comments: Optional field for any additional comments or notes about the project.

## Tips
* Ensure that the project name, start date, and end date are accurate and correctly filled in.
* The absence reason should be a concise explanation of the absence of sustainability design.
* The absence impact is an optional field; if not applicable, leave it blank.
* The project status is a crucial field and should be selected carefully from the provided options.
* Use the comments field for any additional information or clarification about the project.
