# homeschool_survey - Help Guide
## Purpose
This form is designed to gather information from homeschooling parents or educators about their experiences and opinions on various aspects of homeschooling, including survey questions, homeschool experience, student performance, teacher support, and parent involvement.

## How To Complete This Form

1. Please select all that apply to the following questions:
	* Survey Questions
2. Provide a brief answer to the following questions:
	* Homeschool Experience
	* Teacher Support
	* Teacher Feedback
	* Student Participation
3. Enter your answer to the following question:
	* Parent Involvement
4. Choose one of the following:
	* Parent Satisfaction
5. You can provide additional comments or details on the following fields:
	* Student Performance
	* Student Attendance
	* Teacher Support Services
6. Select all that apply for Student Participation:
7. You can enter any additional comments or thoughts on Parent Satisfaction.

## Field-by-Field Explanation

* **Survey Questions** (`survey_questions`, select_multiple, required): This is a page where you will be asked to select all that apply regarding homeschooling questions.
* **Homeschool Experience** (`homeschool_experience`, text, optional): Please provide a brief description of your homeschooling experience.
* **Student Performance** (`student_performance`, text, optional): Please enter your answer about student performance.
* **Teacher Support** (`teacher_support`, select_one, optional): Please choose one of the following regarding teacher support.
* **Teacher Feedback** (`teacher_feedback`, text, optional): Please enter any feedback you have about teachers.
* **Parent Involvement** (`parent_involvement`, select_multiple, optional): Please select all that apply regarding parent involvement.
* **Student Attendance** (`student_attendance`, text, optional): Please enter your answer about student attendance.
* **Teacher Support Services** (`teacher_support_services`, text, optional): Please enter any additional comments about teacher support services.
* **Student Participation** (`student_participation`, select_multiple, optional): Please select all that apply for student participation.
* **Parent Satisfaction** (`parent_satisfaction`, text, optional): Please enter any thoughts or comments about parent satisfaction.
