# smp_3 - Help Guide
## Purpose
This form is used for collecting student and teacher data within educational settings.

## How To Complete This Form
To complete this form, follow the steps outlined above for each field.

## Field-by-Field Explanation
* **Student ID (student_id)**: A unique identifier for the student, typically a number.
* **Student Name (student_name)**: The full name of the student.
* **Student Grade (student_grade)**: The current grade of the student.
* **Student Grade Scale (student_grade_scale)**: A scale used to measure the student's grade.
* **Student Birth Date (student_birth_date)**: The date of the student's birth.
* **Teacher ID (teacher_id)**: A unique identifier for the teacher, usually a number.
* **Teacher Name (teacher_name)**: The full name of the teacher.
* **Teacher Email (teacher_email)**: The email address of the teacher.
* **Teacher Phone (teacher_phone)**: The phone number of the teacher.
* **School ID (school_id)**: A unique identifier for the school.
* **School Name (school_name)**: The full name of the school.
* **School Address (school_address)**: The address of the school.
* **School Post Code (school_postcode)**: The postal code or zip code of the school.
* **School City (school_city)**: The city of the school.

## Tips
Ensure all fields are accurately and completely filled out to provide the most accurate data.
