# preschool_booking_form - Help Guide
## Purpose
The preschool_booking_form is a form used to collect information from users for booking a preschool spot for a child.

## How To Complete This Form
To complete this form, follow these steps:

* Fill out the First Name field with the child's first name.
* Enter the child's Email address in the Email field.
* Enter the Phone number of the contact person in the Phone field.
* Select the Date of Birth of the child in the Date of Birth field using the date picker.
* Enter the name of the Preschool in the Preschool Name field.
* Choose the Booking Date for the child's enrollment in the Booking Date field using the date picker.
* Select the Start Date for the child's enrollment in the Start Date field using the date picker.
* Choose the End Date for the child's enrollment in the End Date field using the date picker.
* Enter the Time of the booking in the Time field.
* Enter the name of the Contact Person responsible for the booking in the Contact Person field.

## Field-by-Field Explanation
* **First Name** (`first_name`, text, optional): This field is used to capture the first name of the child.
* **Email** (`email`, email, optional): This field is used to capture the email address of the contact person.
* **Phone** (`phone`, text, optional): This field is used to capture the phone number of the contact person.
* **Date of Birth** (`dob`, date, optional): This field is used to capture the date of birth of the child.
* **Preschool Name** (`preschool_name`, text, optional): This field is used to capture the name of the preschool.
* **Booking Date** (`booking_date`, date, optional): This field is used to capture the date of the booking.
* **Start Date** (`start_date`, date, optional): This field is used to capture the start date of the enrollment.
* **End Date** (`end_date`, date, optional): This field is used to capture the end date of the enrollment.
* **Time** (`time`, time, optional): This field is used to capture the time of the booking.
* **Contact Person** (`contact_person`, text, optional): This field is used to capture the name of the contact person responsible for the booking.
