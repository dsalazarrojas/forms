# Assignment Planning Checklist - Help Guide
## Purpose
This form is designed to help educators plan and track assignments for students in a class, allowing them to gather and record crucial details about the assignments and monitor progress throughout.

## How To Complete This Form

1. Start by filling out the student-specific fields:
	* **Student Name**: Enter the student's full name.
	* **Student ID**: Enter the student's ID number.
2. Next, provide details about the assignment:
	* **Course Name**: Name of the course the student is enrolled in.
	* **Assignment Title**: Name of the assignment.
	* **Assignment Description**: Brief description of what the assignment requires.
	* **Date Assigned**: Date the assignment was given to the student.
3. Define the assignment's scope:
	* **Final Due Date**: Date the final assignment is due.
	* **Assignment Weight Percentage**: Percentage of weight the assignment carries in the overall course assessment.
	* **Learning Objectives**: Description of what the student is expected to learn.
4. Set up progress tracking:
	* **Priority Level**: Assign a priority level (High, Medium, or Low) based on the assignment's importance and urgency.
	* **Estimated Hours Needed**: Estimated time it takes to complete the assignment.
	* **Resources Needed**: List the resources the student requires to complete the assignment.
5. Track task-specific progress:
	* **Task 1**: Describe the first task in the assignment.
	* **Task 1 Due Date**: Date the first task is due.
	* **Task 1 Complete**: Check when the first task is completed.
6. Repeat the same steps for tasks 2 through 5, if applicable.
7. Finally, check in on potential obstacles and support needed:
	* **Potential Obstacles**: List any potential obstacles the student might face.
	* **Support Needed**: List any support the student requires.
8. Confirm the plan by recording the **Plan Created Date**.

## Field-by-Field Explanation

* **Student Name** (`student_name`, text, required): Enter the student's full name.
* **Student ID** (`student_id`, text, required): Enter the student's ID number.
* **Course Name** (`course_name`, text, required): Enter the course name the student is enrolled in.
* **Assignment Title** (`assignment_title`, text, required): Enter the name of the assignment.
* **Assignment Description** (`assignment_description`, text, required): Brief description of what the assignment requires.
* **Date Assigned** (`date_assigned`, date, required): Date the assignment was given to the student.
* **Final Due Date** (`final_due_date`, date, required): Date the final assignment is due.
* **Assignment Weight Percentage** (`assignment_weight`, number, required): Percentage of weight the assignment carries in the overall course assessment.
* **Learning Objectives** (`learning_objectives`, text, required): Description of what the student is expected to learn.
* **Priority Level** (`priority_level`, select_one, required): Assign a priority level (High, Medium, or Low) based on the assignment's importance and urgency.
* **Estimated Hours Needed** (`estimated_hours`, number, required): Estimated time it takes to complete the assignment.
* **Resources Needed** (`resources_needed`, select_multiple, required): List the resources the student requires to complete the assignment.
* **Task 1** (`task_1`, text, required): Describe the first task in the assignment.
* **Task 1 Due Date** (`task_1_due`, date, optional): Date the first task is due. (Leave blank if not applicable)
* **Task 1 Complete** (`task_1_complete`, select_one, required): Check when the first task is completed.
* **Task 2** (`task_2`, text, required): Describe the second task in the assignment.
* **Task 2 Due Date** (`task_2_due`, date, optional): Date the second task is due. (Leave blank if not applicable)
* **Task 2 Complete** (`task_2_complete`, select_one, required): Check when the second task is completed.
* **Task 3** (`task_3`, text, required): Describe the third task in the assignment.
* **Task 3 Due Date** (`task_3_due`, date, optional): Date the third task is due. (Leave blank if not applicable)
* **Task 3 Complete** (`task_3_complete`, select_one, required): Check when the third task is completed.
* **Task 4** (`task_4`, text, optional): Describe the fourth task in the assignment. (Leave blank if not applicable)
* **Task 4 Complete** (`task_4_complete`, select_one, optional): Check when the fourth task is completed. (Leave blank if not applicable)
* **Task 5** (`task_5`, text, optional): Describe the fifth task in the assignment. (Leave blank if not applicable)
* **Task 5 Complete** (`task_5_complete`, select_one, optional): Check when the fifth task is completed. (Leave blank if not applicable)
* **Potential Obstacles** (`potential_obstacles`, text, optional): List any potential obstacles the student might face.
* **Support Needed** (`support_needed`, text, optional): List any support the student requires.
* **First Milestone Check Date** (`milestone_check_1`, date, optional): Date for the first progress review.

## Tips

* Be thorough and accurate when filling out this form to ensure all details are captured.
* Use relevant dates and deadlines to track progress and due dates.
* Review each field carefully to avoid duplicating work.
* Consider adding additional fields or tasks as needed for specific assignments.
* Use this form consistently to maintain a clear and organized record of assignments and progress.
