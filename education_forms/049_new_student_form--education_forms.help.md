# New Student Form - Help Guide

## Purpose
The New Student Form is used to gather necessary information from new students, including their contact details, academic details, and other relevant data. This form is an essential part of the registration process, and it helps the institution to verify the students' identity and prepare them for their academic journey.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the first name and last name fields with the student's full name.
2. Enter the student's date of birth.
3. Provide a valid email address.
4. Enter a phone number (optional).
5. Select the grade level the student is enrolling for.
6. Choose the courses the student is registered for by selecting multiple options from the list.
7. Enter the student's number (if applicable).
8. Provide contact information for the parent or guardian (if applicable).
9. Add any notes for the teacher (if applicable).
10. Enter any registration procedures or comments (if applicable).
11. Enter the course description (if applicable).

## Field-by-Field Explanation

* **First Name (Required)** (`first_name`, text, required): Enter the student's first name.
* **Last Name (Required)** (`last_name`, text, required): Enter the student's last name.
* **Date of Birth (Required)** (`date_of_birth`, date, required): Enter the student's date of birth in the correct format (DD/MM/YYYY).
* **Email (Required)** (`email`, email, required): Enter a valid email address.
* **Phone (Optional)** (`phone`, text, required): Enter the student's phone number (optional).
* **Grade Level (Required)** (`grade_level`, number, required): Select the grade level the student is enrolling for (e.g., 1st, 2nd, 3rd, etc.).
* **Select Courses (Required)** (`course_selection`, select_multiple, required): Choose multiple courses from the list provided (e.g., 1st Semester, 2nd Semester, etc.).
* **Student Number (Required)** (`student_number`, text, required): Enter the student's student number (if applicable).
* **Parent Contact (Optional)** (`parent_contact`, text, required): Enter the parent or guardian's contact information (optional).
* **Teacher Note (Optional)** (`teacher_note`, note, required): Add any notes or comments for the teacher (if applicable).
* **Registration Procedures (Optional)** (`registration_procedures`, text, required): Enter any registration procedures or comments (if applicable).
* **Course Description (Optional)** (`course_description`, text, required): Enter a brief description of the course (if applicable).

Note: The fields marked as "optional" can be left blank if not applicable.
