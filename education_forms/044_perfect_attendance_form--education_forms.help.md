# Perfect Attendance Form - Help Guide
## Purpose
The Perfect Attendance Form is used to record and report on attendance at events or activities. This form collects information about the attendees' names and dates of attendance.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the name of the attendee or attendees.
2. Select the start date of the attendance.
3. Select the end date of the attendance.

## Field-by-Field Explanation
### Attendees Name
* **Attendees Name (attendees_name)**: Enter the name of the attendee or attendees. This field is not required, but if left blank, the form will not be saved.

### Start Date
* **Start Date (start_date)**: Select the date when the attendance started. This field is not required and should be left blank if the event spans multiple dates or has a variable start time.

### End Date
* **End Date (end_date)**: Select the date when the attendance ended. This field is not required and should be left blank if the event spans multiple dates or has a variable end time.

### Signature
* **Signature (signature)**: This field is not currently used for any specific functionality. You can leave it blank and it will not affect the form's functionality.

Note: The form is designed for general use and may require additional fields or modifications based on specific requirements.
