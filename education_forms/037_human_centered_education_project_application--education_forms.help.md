# Human Centered Education Project Application - Help Guide
## Purpose
The purpose of this form is to gather information for Human Centered Education project applications. 
## How To Complete This Form
To complete this form, follow these steps:

1. Provide your school's name in the School Name field.
2. Enter a brief description of your project proposal in the Project Proposal field.
3. List your project objectives in the Project Objectives field.
4. Indicate if you have any supporting documents by selecting Yes or No in the Supporting Documents field.
5. Enter the project start and end dates in the Project Start Date and Project End Date fields, respectively.
6. Enter the project budget in the Project Budget field.
7. Enter your contact information, including your email address, in the Contact Information field.

## Field-by-Field Explanation
* **School Name** (Text, Required): Enter the name of your school.
* **Project Proposal** (Text, Required): Briefly describe your project proposal.
* **Project Objectives** (Text, Required): List your project objectives.
* **Supporting Documents** (Select Multiple, Required): Indicate if you have any supporting documents. Options: Yes/No.
* **Project Start Date** (Date, Required): Enter the project start date.
* **Project End Date** (Date, Required): Enter the project end date.
* **Project Budget** (Number, Required): Enter the project budget.
* **Contact Information** (Email, Required): Enter your contact information, including your email address.

## Tips
Make sure to provide complete and accurate information for all fields. If you have any supporting documents, please attach them to your application.
