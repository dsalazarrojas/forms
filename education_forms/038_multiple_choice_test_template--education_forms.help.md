# Multiple Choice Test Template - Help Guide

## Purpose

This form is designed to be a basic multiple choice test template. It allows users to create a short, 4-question test with multiple choice options, along with a description of the question being asked.

## How To Complete This Form

1. Fill in the **Question Description** field with a description of the question being asked.
2. Select one of the available options in the **Multiple Choice Question** field.
3. Select one of the available options in the **Option A**, **Option B**, and **Option C** fields. Each of these fields should have one of the options selected.
4. Click on the **Submit** button when you're done.

## Field-by-Field Explanation

* **Multiple Choice Question** (select_one, required: false): This is where you select one of the multiple choice options for the question being asked.
* **Question Description** (text, required: true): This field should have a description of the question being asked, such as "What is the capital of France?".
* **Option A** (select_one, required: false): Select one of the available options for the first multiple choice question.
* **Option B** (select_one, required: false): Select one of the available options for the second multiple choice question.
* **Option C** (select_one, required: false): Select one of the available options for the third multiple choice question.
* **Submit** (text, required: true): Clicking this button will submit the form and allow you to create the test template. 

## Tips

* Make sure you fill in the **Question Description** field with a clear and concise description of the question being asked.
* Select one of the options in each of the **Multiple Choice Question**, **Option A**, and **Option C** fields.
