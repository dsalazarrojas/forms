# Program Outcomes Annual Report Form - Help Guide

## Purpose
The Program Outcomes Annual Report Form is a tool used to collect data on the achievements, assessment findings, and evaluation progress of a program. This form is part of the program evaluation process.

## How To Complete This Form
To complete this form, follow these steps:

1.  Fill in the required information for each field, making sure to answer each question accurately and thoroughly.
2.  Review and edit your answers before submitting the form.

## Field-by-Field Explanation

* **Program Outcomes Annual Report** (`Program Outcomes Annual Report Form`, `text`, required): This field is for entering the outcomes of the program for the reporting period.
* **Outcomes Achieved Program** (`Outcomes Achieved Program`, `text`, required): This field is for entering the outcomes achieved by the program during the reporting period.
* **Assessment Findings** (`Assessment Findings`, `text`, required): This field is for entering the assessment findings of the program during the reporting period.
* **Consistent Data Collection** (`Consistent Data Collection`, `select_multiple`, required): This field is for selecting the methods used to collect data for the program. Select all applicable methods.
* **Review Workflows** (`Review Workflows`, `select_one`, required): This field is for selecting the review workflows used for the program. Select one review workflow that applies.
* **Date Program Ended** (`Date Program Ended`, `date`, required): This field is for entering the date when the program ended.
* **Date Program Started** (`Date Program Started`, `date`, required): This field is for entering the date when the program started.
* **Program Goals** (`Program Goals`, `text`, required): This field is for entering the goals of the program.
* **Program Objectives** (`Program Objectives`, `text`, required): This field is for entering the objectives of the program.
* **Program Outcomes** (`Program Outcomes`, `text`, required): This field is for entering the outcomes of the program.
* **Assessment Findings Program** (`Assessment Findings Program`, `select_multiple`, required): This field is for selecting the assessment findings for the program. Select all applicable methods.
* **Program Evaluation Process** (`Program Evaluation Process`, `select_one`, required): This field is for selecting the program evaluation process used. Select one evaluation process that applies.
* **Date Program Evaluation** (`Date Program Evaluation`, `date`, required): This field is for entering the date of the program evaluation.
* **Program Evaluation Frequency** (`Program Evaluation Frequency`, `select_one`, required): This field is for selecting the evaluation frequency of the program. Select one evaluation frequency that applies.
* **Evaluation Team** (`Evaluation Team`, `text`, required): This field is for entering the evaluation team members.
* **Program Review Process** (`Program Review Process`, `text`, required): This field is for entering the program review process.
* **Program Improvement Areas** (`Program Improvement Areas`, `text`, required): This field is for entering the areas of improvement for the program.
* **Program Action Plan** (`Program Action Plan`, `text`, required): This field is for entering the action plan for the program.
* **Program Evaluation Summary** (`Program Evaluation Summary`, `text`, required): This field is for entering a summary of the program evaluation.
* **Next Evaluation Cycle** (`Next Evaluation Cycle`, `date`, required): This field is for entering the next evaluation cycle date.
* **Evaluation Cycle Length** (`Evaluation Cycle Length`, `number`, required): This field is for entering the evaluation cycle length.
* **Evaluation Frequency** (`Evaluation Frequency`, `select_multiple`, required): This field is for selecting the evaluation frequency of the program. Select all applicable frequencies.
* **Review Frequency** (`Review Frequency`, `select_multiple`, required): This field is for selecting the review frequency of the program. Select all applicable frequencies.
* **Evaluation Cycle Status** (`Evaluation Cycle Status`, `select_one`, required): This field is for selecting the evaluation cycle status. Select one status that applies.
* **Review Cycle Status** (`Review Cycle Status`, `select_one`, required): This field is for selecting the review cycle status. Select one status that applies.

## Tips
Please ensure that all fields are filled in accurately and thoroughly. Review and edit your answers before submitting the form. If you have any questions or need further clarification, please contact the program director or coordinator.
