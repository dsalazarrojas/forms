# Gallbladder Anatomy Quiz - Help Guide
## Purpose
The Gallbladder Anatomy Quiz is designed to assess users' knowledge about the gallbladder, a small organ located under the liver that plays a crucial role in the digestive system. The quiz consists of four questions that test users' understanding of the gallbladder's anatomy, functions, and related topics.

## How To Complete This Form
To complete the Gallbladder Anatomy Quiz, follow these steps:

1. Read each question carefully and answer them to the best of your ability.
2. Choose the correct answer from the provided options for questions 1, 2, and 3.
3. Enter your answer for question 4 (Anatomy Quiz Answer).
4. Submit your answers by filling out the form completely and accurately.

## Field-by-Field Explanation
- **Quiz Question 1** (select_one, required): This question asks about the primary function of the gallbladder. Choose the correct answer from the provided options.
- **Quiz Question 2** (select_multiple, required): This question asks about multiple aspects of the gallbladder's anatomy. Select all the correct options that apply.
- **Quiz Question 3** (select_one, required): This question asks about the location of the gallbladder in the body. Choose the correct answer from the provided options.
- **Quiz Question 4** (date, required): This question asks for the submission date of your answers. Enter the date in the required format (YYYY-MM-DD).
- **Anatomy Quiz Answer** (text, optional): If you have additional information or comments about the gallbladder, you can enter them here.
- **Quiz Submission Date** (date, required): This is the date and time when you submit your answers. The system will automatically fill this field with the current date and time, but you can override it if needed.

## Tips
- Make sure to answer each question carefully and thoroughly.
- If you are unsure about the answer to a question, choose the option that seems most likely correct.
- The quiz is meant to be a fun and educational experience. Don't hesitate to ask for help or clarification if you need it.
