# Functional Communication IEP Goal Tracking Form - Help Guide
## Purpose
The Functional Communication IEP Goal Tracking Form is a tool used to monitor and track a student's progress in achieving their functional communication goals. 

## How To Complete This Form
1. **Choose the communication goals** for the student by selecting one or more from the available options on the first page.
2. **Select the student's ID** by entering a number corresponding to the student's ID number.
3. **Enter student data** in the text field, providing any relevant information about the student.
4. **Choose the start and end dates** for the tracking period by selecting the dates using the date input fields.
5. **Select the communication frequency** by choosing one of the available options (1, 2, or 3) to indicate how often the student communicates with others.
6. **Add any notes** related to the student's progress or sessions in the notes field.
7. **Enter the student's email** (if applicable).

## Field-by-Field Explanation
* **Communication Goals** (`communication_goals`): Select one or more goals that the student is working towards, such as goal1, goal2, or goal3.
* **Student ID** (`student_id`): Enter the student's ID number for identification purposes.
* **Student Data** (`student_data`): Enter any relevant information about the student, such as their name, age, or class section.
* **Date Start** (`date_start`): Select the start date of the tracking period using the date input field.
* **Date End** (`date_end`): Select the end date of the tracking period using the date input field.
* **Communication Frequency** (`communication_frequency`): Choose one of the available options (1, 2, or 3) to indicate how often the student communicates with others.
* **Notes** (`notes`): Enter any notes or comments related to the student's progress or sessions.
* **Email** (`email`): Enter the student's email address, if applicable. 

## Tips
* Make sure to select the correct student ID to track the correct student's progress.
* Ensure the start and end dates are accurate to reflect the correct tracking period.
* Use the communication frequency option that best represents the student's communication pattern.
* Keep the notes field concise and clear to provide easy reference for future sessions.
