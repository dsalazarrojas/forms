# Course Cleanup Request Form - Help Guide
## Purpose
The Course Cleanup Request Form is used to request changes to a course's schedule or other details in the education system.

## How To Complete This Form
To complete this form, follow these steps:
1. Enter your email address in the "Email" field. This will help us contact you if we need more information.
2. Enter the name of the course that you need to make changes to.
3. If applicable, enter the course number associated with the course you are making changes to.
4. Select the department associated with the course you are making changes to.
5. If applicable, enter any schedule updates you need to make.
6. Enter the date you would like the changes to take effect.
7. Provide a brief reason for your request.
8. Add any additional comments or notes about your request.

## Field-by-Field Explanation
* **Email** (user_email, email, optional): Enter your email address so we can contact you if we need more information.
* **Course Name** (course_name, text, optional): Enter the name of the course you need to make changes to.
* **Course Number** (course_number, number, optional): If applicable, enter the course number associated with the course you are making changes to.
* **Department** (department, text, optional): Select the department associated with the course you are making changes to.
* **Schedule Update** (schedule_update, text, optional): If applicable, enter any schedule updates you need to make.
* **Date Request** (date_request, date, optional): Enter the date you would like the changes to take effect.
* **Reason Request** (reason_request, text, optional): Provide a brief reason for your request.
* **Comments** (comments, text, optional): Add any additional comments or notes about your request.
