# Teacher Class Verification Form - Help Guide

## Purpose
This form is used to verify the status of a student's class, collecting information on attendance, performance, and other relevant details.

## How To Complete This Form
1. Fill out the form completely, as required fields are marked with an asterisk \*.
2. Enter the student's name in the "student_name" field.
3. Enter the title of the student's course in the "student_course_title" field.
4. Select the start and end dates for the class using the respective date fields.
5. Choose the student's current attendance status and class status using the select options provided.
6. Sign the form with your teacher's signature.
7. Optionally, add any remarks or comments about the student's performance.
8. Review the information before submitting the form.

## Field-by-Field Explanation

* **student_name** (Text): Enter the student's name as per your records.
* **student_course_title** (Text): Enter the title of the course the student is enrolled in.
* **start_date** (Date): Select the start date of the class.
* **end_date** (Date): Select the end date of the class.
* **attendance_status** (Select One): Choose the student's current attendance status (Active or Inactive).
* **student_class_status** (Select One): Choose the student's current class status (Active or Inactive).
* **teacher_signature** (Text): Sign the form with your teacher's signature.
* **student_signature** (Text): Sign the form with the student's signature.
* **remarks** (Note): Optionally add any remarks or comments about the student's performance.
* **teacher_comments** (Note): Optionally add any comments about the student's performance.
* **class_participation** (Number): Not currently used, but available for future implementation.

## Tips

* Make sure to fill out all required fields.
* Review the information carefully before submitting the form.
* Use the select options provided for attendance and class status.
* If you have any additional comments, use the remarks or teacher comments field.
