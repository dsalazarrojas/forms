# Pioneer Station - Help Guide
## Purpose
The "Pioneer Station" form is a generic student registration or information collection form used to gather details about students in an educational setting.

## How To Complete This Form
1. Fill out the form with your basic student details.
2. Enter your student's information in each of the provided fields.
3. Submit the completed form for further processing.

## Field-by-Field Explanation

* **Student Name** (`student_name`, text, optional): Enter the student's name.
* **Email** (`email`, email, optional): Enter the student's email address.
* **Phone** (`phone`, text, optional): Enter the student's phone number.
* **Date of Birth** (`date_of_birth`, date, optional): Enter the student's date of birth.
* **Gender** (`gender`, select_one, optional): Select the student's gender from the provided options (Male, Female).
* **Student Type** (`student_type`, select_multiple, optional): Select the type(s) of student that best describes the student (Regular, Homeschooled, Online).
* **Note** (`note`, note, optional): Enter any additional notes or comments about the student.
* **Assigned Tool** (`assigned_tool`, text, optional): Enter the tool assigned to the student.
* **Category** (`category`, text, optional): Enter the category related to the student.
* **Subcategory** (`subcategory`, text, optional): Enter the subcategory related to the student.
* **Tags** (`tags`, text, optional): Enter any relevant tags or keywords related to the student.
* **Description** (`description`, text, optional): Enter a brief description of the student.

## Tips
* Ensure you fill out all required fields accurately and truthfully.
* Use the correct format for date of birth (mm/dd/yyyy).
* Use the select options for Gender and Student Type as provided.
* Use the correct label format for tags and description fields.
