# Remote Teaching Tools Faculty Inquiry Form - Help Guide
## Purpose
The "Remote Teaching Tools Faculty Inquiry Form" is designed to gather your feedback and experiences on using remote teaching tools in your classes. Your input is essential to help us improve the support and resources provided for remote teaching.

## How To Complete This Form
1. Please answer each question to the best of your ability.
2. Select all options that apply for multiple-choice questions.
3. Be as descriptive as possible in the text fields.
4. If you have any suggestions or comments, please provide them in the "Suggestions" field.
5. If you have encountered any technical issues, please check the "Technical Issues" checkbox.

## Field-by-Field Explanation

* **What kind of remote teaching technology have you used?** (remote_teaching_tools)
	+ Select all the remote teaching technologies you have used, such as Zoom, Google Meet, or Skype.
* **What was most helpful in terms of remote teaching technology?** (teaching_technology_helpfulness)
	+ Choose the option that best describes your experience with remote teaching technology.
* **How would you rate your overall satisfaction with remote teaching technology?** (overall_satisfaction)
	+ This question is optional, but if you have used remote teaching technology, please rate your satisfaction level (1-5).
* **What kind of support would you like to see for remote teaching technology?** (support_type)
	+ Choose all the types of support you would like to see, such as technical support or training.
* **How many times have you used remote teaching technology?** (usage_count)
	+ Enter the number of times you have used remote teaching technology.
* **Do you have any suggestions for improving remote teaching technology?** (suggestions)
	+ Provide any suggestions or ideas you have for improving remote teaching technology.
* **Do you have any other comments?** (comments)
	+ Provide any additional feedback or comments about your experience with remote teaching technology.
* **Have you encountered any technical issues with remote teaching technology?** (technical_issues)
	+ Check the "Yes" checkbox if you have encountered any technical issues.
* **What features do you think are essential for effective remote teaching?** (essential_features)
	+ Choose all the features you think are essential for effective remote teaching, such as video conferencing or polling.
* **Have you received adequate support for remote teaching technology?** (adequate_support)
	+ Choose the option that best describes your experience.
* **What other tools or platforms have you used for remote teaching?** (other_tools)
	+ If you have used other tools or platforms for remote teaching, list them here and specify if they are not on the list.
