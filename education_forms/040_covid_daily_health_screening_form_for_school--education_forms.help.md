# COVID Daily Health Screening Form For School - Help Guide

## Purpose
The COVID Daily Health Screening Form is used to assess a student's health status to ensure they are safe to attend school. It's a mandatory form that needs to be completed by students before entering the school premises. It's used to identify any potential risks of COVID-19 transmission and take necessary precautions to prevent the spread of the virus.

## How To Complete This Form
1. Fill out the required fields (marked as "true" in the form) completely and accurately.
2. If you are unsure about any question, select "Unsure" as the answer.
3. Make sure to answer all questions truthfully, as this information will be used to determine your clearance to attend school.

## Field-by-Field Explanation

* **Student Name** (daily_student_name, text, true): Enter your full name as it appears on your identification documents.
* **Date of Birth** (daily_date_of_birth, date, true): Enter your date of birth in MM-DD-YYYY format (e.g., 01-01-2000).
* **Grade Level** (daily_grade_level, text, true): Enter your current grade level (e.g., 6th, 11th, etc.).
* **Screening Date** (daily_screening_date, date, true): Enter the date of this screening in MM-DD-YYYY format.
* **Parent or Guardian Name** (daily_parent_name, text, false): Enter the name of your parent or guardian, if applicable.
* **Parent or Guardian Phone** (daily_parent_phone, phone, false): Enter the phone number of your parent or guardian, if you need to contact them.
* **Do You Have a Fever** (daily_fever, select_one, true): Select "True" if you have a temperature of 100.4F or higher. If unsure, select "Unsure".
* **Do You Have a Cough** (daily_cough, select_one, true): Select "True" if you have a new or worsening cough. If unsure, select "Unsure".
* **Do You Have Shortness of Breath** (daily_shortness_of_breath, select_one, true): Select "True" if you experience difficulty breathing or chest pain. If unsure, select "Unsure".
* **Loss of Taste or Smell** (daily_loss_taste_smell, select_one, true): Select "True" if you have a new loss of taste or smell. If unsure, select "Unsure".
* **Body Aches or Fatigue** (daily_body_aches, select_one, true): Select "True" if you experience unusual muscle aches or tiredness. If unsure, select "Unsure".
* **Sore Throat** (daily_sore_throat, select_one, true): Select "True" if you have a sore throat or difficulty swallowing. If unsure, select "Unsure".
* **Headache** (daily_headache, select_one, true): Select "True" if you have an unusual headache. If unsure, select "Unsure".
* **Nausea or Vomiting** (daily_nausea_vomiting, select_one, true): Select "True" if you experience stomach upset or vomiting. If unsure, select "Unsure".
* **Close Contact with Someone Ill** (daily_close_contact, select_one, true): Select "True" if you have been near someone who is sick. If unsure, select "Unsure".
* **Contact with COVID-19 Positive Person** (daily_covid_positive_contact, select_one, true): Select "True" if you have been in contact with someone who tested positive for COVID-19. If unsure, select "Unsure".
* **Cleared to Attend School Today** (daily_cleared_to_attend, select_one, true): Select "True" if you are cleared to attend school based on your screening answers. If not, select "No, not cleared to attend". If conditional clearance, select "Conditional clearance". 
* **Reason for Non-Clearance if Applicable** (daily_reason_if_not_cleared, text, false): Enter the reason why you are not cleared to attend school, if applicable.
* **Follow-Up Needed** (daily_follow_up_needed, select_one, false): Select the follow-up action required, if any. Options include No follow-up, Parental notification, Physician consultation, Stay home and monitor, Get tested.
* **Date and Time Screening Completed** (daily_screening_complete_date, time, true): Enter the date and time when this screening was finished. 

Note: Please make sure to answer all questions truthfully, as this information will be used to determine your clearance to attend school.
