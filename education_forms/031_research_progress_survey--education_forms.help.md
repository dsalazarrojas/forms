# Research Progress Survey - Help Guide

## Purpose
This form is designed to track the progress of research projects. It collects information about the project's title, milestone date, challenges, researcher's name, research group, research area, milestone description, stakeholders involved, and feedback or comments.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the "Project Info" field to provide a brief description of the research project.
2. Choose the "Milestone Date" field to input the date of the milestone or significant event in the project.
3. In the "Challenge Info" field, describe any challenges or issues faced during the project.
4. Enter the researcher's name and research group in the respective fields.
5. Select the "Research Area" field to specify the area of research.
6. Write a description of the milestone in the "Milestone Description" field.
7. Select multiple stakeholders involved in the project from the "Stakeholder List" field.
8. Provide any feedback or comments in the "Feedback Description" field.

## Field-by-Field Explanation
* **Project Info (Project Info)** (Required: False) : A brief description of the project.
* **Milestone Date (Milestone Date)** (Required: False) : The date of the milestone or significant event in the project.
* **Challenge Info (Challenge Info)** (Required: False) : A description of any challenges or issues faced during the project.
* **Researcher Name (Researcher Name)** (Required: False) : The name of the researcher.
* **Research Group (Research Group)** (Required: False) : The research group or organization.
* **Research Area (Research Area)** (Required: False) : The area of research.
* **Milestone Description (Milestone Description)** (Required: False) : A description of the milestone.
* **Stakeholder List (Stakeholder List)** (Required: False) : A list of stakeholders involved in the project.
* **Feedback Description (Feedback Description)** (Required: False) : Any feedback or comments about the project.

# Tips
* Make sure to provide accurate and relevant information in each field.
* Double-check the "Stakeholder List" field to ensure all necessary stakeholders are included.
* Use clear and concise language in the "Feedback Description" field.
