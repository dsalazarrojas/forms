# Peer Learning Exchange Program Application - Help Guide
## Purpose
The Peer Learning Exchange Program Application form is designed to collect information from individuals interested in participating in the Peer Learning Exchange Program. The program aims to connect individuals with similar interests and skills to facilitate learning and knowledge sharing.

## How To Complete This Form
To complete this form, follow the steps below:

1. Enter your School Name, which should be the name of the school or institution you are affiliated with.
2. Indicate your Participant Details by selecting one or more options from the dropdown list.
3. Choose your Learning Interests by selecting one option from the dropdown list.
4. Select your Teaching Skills, if applicable.
5. Enter your Learning Goals, which should be a brief description of your learning objectives.
6. Enter your Participant Email, which should be a valid email address that we can use to contact you.
7. Enter your Participant Phone, which should be a valid phone number that we can use to contact you.
8. Choose the Program Start Date for the program you wish to participate in.

## Field-by-Field Explanation

* **School Name** (School Name, text, optional): This is the name of the school or institution you are affiliated with.
* **Participant Details** (Participant Details, select_multiple, optional): Please select one or more options from the dropdown list to indicate your participant details.
	+ 'Yes': Indicates that you are a participant in the program.
	+ 'No': Indicates that you are not a participant in the program.
* **Learning Interests** (Learning Interests, select_one, optional): Select one option from the dropdown list to indicate your learning interests.
	+ 'Yes': Indicates that you are interested in learning.
	+ 'No': Indicates that you are not interested in learning.
* **Teaching Skills** (Teaching Skills, select_multiple, optional): If you have teaching skills, please select one or more options from the dropdown list.
	+ 'Yes': Indicates that you have teaching skills.
	+ 'No': Indicates that you do not have teaching skills.
* **Learning Goals** (Learning Goals, text, optional): Enter a brief description of your learning objectives, such as what you hope to achieve or accomplish through the program.
* **Participant Email** (Participant Email, email, optional): Enter a valid email address that we can use to contact you.
* **Participant Phone** (Participant Phone, text, optional): Enter a valid phone number that we can use to contact you.
* **Program Start Date** (Program Start Date, date, optional): Choose the date you wish to start the program.
