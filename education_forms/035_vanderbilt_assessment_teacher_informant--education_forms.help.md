# Vanderbilt Assessment Teacher Informant - Help Guide
## Purpose
The Vanderbilt Assessment Teacher Informant form is a tool used to collect information from teachers about their students. This form is used to gather data for assessment or evaluation purposes.

## How To Complete This Form
To complete this form, follow these steps:
1. Review the pages of the form and understand what information needs to be collected.
2. Fill out the text fields with relevant and accurate information about your student.
3. Select one of the options in the select_one field, making sure to choose the most appropriate option.
4. Repeat the process for each page of the form.

## Field-by-Field Explanation
* **Text Field 1** (teacher_informant_form, text, required): This field is for providing a general description or comment about the student.
* **Select One Field 2** (teacher_informant_form_2, select_one, required): This field is for selecting one of the given options. Please choose the option that best describes the student.
* **Text Field 3** (teacher_informant_form_3, text, optional): This field is for providing additional information or context about the student, but it is not mandatory.

## Tips
* Please make sure to fill out all required fields accurately and completely.
* If you need to provide additional information, use the text field on page 3.
* If you are unsure about any field, review the page label to understand its purpose.
