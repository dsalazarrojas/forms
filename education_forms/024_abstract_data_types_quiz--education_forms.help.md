# Abstract Data Types Quiz - Help Guide
## Purpose
This form is designed for participants to gauge their understanding of Abstract Data Types.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in your details in the "Participant Information" section.
2. Answer each question in the "Quiz Questions" section.
3. Select the correct option for each question.
4. Submit the form when you are finished.

## Field-by-Field Explanation
* **-- Participant Information --** (`participant_name`, `participant_email`, `course_or_program`, `participant_name`):
	+ This section is required to identify the participant and verify their identity.
	+ Please fill in your full name, email address, and course or program name.
* **Which of the following best describes a Stack** (`q1_stack_definition`):
	+ A Stack is a data structure that follows the Last-In, First-Out (LIFO) principle.
	+ Think of a stack of plates, where plates are added and removed from the top.
* **Which operations are fundamental to a Queue** (`q2_queue_operations`):
	+ A Queue follows the First-In, First-Out (FIFO) principle.
	+ Select all operations that apply to a Queue: Enqueue, Dequeue, Push, Pop, and Peek.
* **What is a key advantage of a Linked List over an Array** (`q3_linked_list_advantage`):
	+ A Linked List has dynamic size with efficient insertion and deletion.
	+ Linked Lists use less memory than Arrays.
* **In a Binary Search Tree, which property must hold true** (`q4_binary_tree_property`):
	+ Each node has at most two children.
	+ Each left child is less than its parent, and each right child is greater than its parent.
* **What is the primary purpose of a Hash Table** (`q5_hash_table_purpose`):
	+ A Hash Table is used for fast key-value lookup.
	+ It is not used for maintaining sorted order.
* **What is an Abstract Data Type (ADT)** (`q6_adt_definition`):
	+ An ADT is a mathematical model that defines a set of operations and their behavior.
	+ It is not a specific implementation in a programming language.
* **Which of the following are common graph traversal algorithms** (`q7_graph_traversal`):
	+ Select all that apply: Breadth-First Search (BFS), Depth-First Search (DFS), and Linear Search.
* **A Priority Queue typically uses which underlying data structure** (`q8_priority_queue`):
	+ A Priority Queue typically uses a Heap.
* **What is the defining characteristic of a Set data type** (`q9_set_characteristic`):
	+ Elements are not duplicate.
* **What is the average time complexity for searching in a balanced Binary Search Tree** (`q10_time_complexity`):
	+ The average time complexity is O(log n).
* **How confident are you in your understanding of Abstract Data Types** (`confidence_level`):
	+ Select your level of confidence: Very confident, Somewhat confident, Neutral, Not very confident, Not confident at all.
