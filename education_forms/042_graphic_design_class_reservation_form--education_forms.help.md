# Graphic Design Class Reservation Form - Help Guide
## Purpose
This form is used to collect information for a Graphic Design Class, gathering essential details about students and courses. The form is designed to ensure accurate and efficient collection of data.

## How To Complete This Form
1. Fill out the student section with your name, email, address, and contact number.
2. Select the course you wish to attend, including the course name, type, and duration.
3. Choose the start and end dates for the course, if applicable.
4. Provide a contact number and payment method for payment processing.
5. Optionally, add any additional remarks or comments for the course.

## Field-by-Field Explanation

* **Student Name**: Enter your full name as you would like it to be displayed.
* **Course Name**: Select the name of the course you wish to attend.
* **Start Date**: Enter the start date of the course, if applicable.
* **End Date**: Enter the end date of the course, if applicable.
* **Instructor Name**: Enter the name of the instructor leading the course.
* **Contact Number**: Provide a contact number for payment processing and communication.
* **Student Email**: Enter your email address for course communication.
* **Course Type**: Select the type of course you wish to attend (e.g., graphic design principles, visual design, etc.).
* **Course Description**: Provide a brief description of the course content.
* **Course Location**: Enter the location of the course (e.g., online, on-site, etc.).
* **Time Slot**: Choose the time slot for the course.
* **Available Slots**: Select the number of available slots for the course.
* **Reserved Slots**: Select the number of slots already reserved for the course.
* **Reserved By**: If a slot is reserved, enter the name of the person reserving it.
* **Course Fees**: Enter the fees for the course.
* **Payment Method**: Select the payment method for the course (e.g., online payment, bank transfer, etc.).
* **Remarks**: Add any additional remarks or comments about the course.
* **Status**: Select the current status of the course (e.g., Approved, Pending, Cancelled).
* **Course Status**: Select the type of course (e.g., Active, Completed, Cancelled).
* **Class Start Date**: Enter the start date of the class.
* **Class End Date**: Enter the end date of the class.
* **Class Status**: Select the status of the class (e.g., Active, Completed, Cancelled).
