# Prion Disease Knowledge Quiz - Help Guide
## Purpose
The Prion Disease Knowledge Quiz is designed to assess your understanding of prion disease, a type of infectious agent that can be transmitted through contaminated food, water, or other sources.

## How To Complete This Form
To complete this form, follow these steps:

* Read the questions carefully and select the correct answers.
* Select "Yes" or "No" for each question, depending on your knowledge and understanding.
* Fill out the "Completed By" field with the name of the person completing the form.
* Fill out the "Submitter Email" field with a valid email address.
* Ensure that the "Date Completed" field is filled out in the correct format (MM/DD/YYYY).
* Click the "Submit" button to submit your responses.

## Field-by-Field Explanation

* **Introduction** (`text`, optional): A brief introduction to the quiz. Please provide a short description of your understanding of the prion disease.
* **Questions** (`select_one`, optional): Select "Yes" if you are knowledgeable about prion disease, and "No" if you are not. Please note that this question is designed to gauge your basic understanding of prion disease.
* **Answers** (`select_multiple`, optional): Select all the correct answers to the questions. Please make sure to choose only the correct options from the list.
* **Submit** (`text`, optional): This field is not required, but if you have any additional comments or information to provide, you can type them in here.
* **Date Completed** (`date`, required): Please fill out this field in the format MM/DD/YYYY (e.g., 01/01/2022). This will help us track the date you completed the quiz.
* **Time Completed** (`time`, optional): Select the time you completed the quiz in the format HH:MM AM/PM (e.g., 02:30 PM).
* **Completed By** (`select_one`, optional): Please select "Yes" if you completed the quiz accurately, and "No" if you did not.
* **Submitter** (`email`, optional): This is the email address of the person submitting the quiz.
* **Submitter Email** (`email`, optional): This is the email address of the person submitting the quiz, which should match the email address you provided above.
