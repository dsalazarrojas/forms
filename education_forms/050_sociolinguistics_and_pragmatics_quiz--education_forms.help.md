# Sociolinguistics And Pragmatics Quiz - Help Guide
## Purpose
This form is designed to collect data for educational purposes, specifically in the fields of sociolinguistics and pragmatics.

## How To Complete This Form
1. Select a category for your quiz from the options provided.
2. Enter a title for your quiz that accurately represents its content.
3. Provide a description of your quiz.
4. Choose an assigned tool from the options provided.
5. Enter the path where you would like the output file to be saved.
6. Enter the name of the output file.
7. Select the file extension for the output file.
8. Enter the submitted date and time of the quiz.
9. Confirm if the quiz was submitted at a specific time zone.
10. Enter the time of submission.
11. Enter a file path for the output file.
12. Enter a unique form ID.
13. Select the format of the output file.
14. Enter the time of submission.
15. Enter any additional form IDs.

## Field-by-Field Explanation

* **Form Title** (`form_title`, `text`, required): Enter a title for your quiz that accurately represents its content.
* **Category** (`category`, `select_one`, required): Select a category for your quiz from the options provided.
* **Description** (`description`, `text`, required): Provide a description of your quiz.
* **Assigned Tool** (`assigned_tool`, `select_one`, required): Choose an assigned tool from the options provided.
* **Output File** (`output_file`, `text`, required): Enter the path where you would like the output file to be saved.
* **Output File Name** (`output_file_name`, `text`, required): Enter the name of the output file.
* **Output File Extension** (`output_file_extension`, `select_one`, required): Select the file extension for the output file.
* **Output Path** (`output_path`, `text`, required): Enter the path where you would like the output file to be saved.
* **Submitted At** (`submitted_at`, `date`, required): Enter the date and time of submission.
* **Submitted By** (`submitted_by`, `select_one`, required): Confirm if the quiz was submitted.
* **Submitted At Time Zone** (`submitted_at_time_zone`, `select_one`, required): Confirm if the submission was at a specific time zone.
* **Submitted At Time** (`submitted_at_time`, `time`, required): Enter the time of submission.
* **Output Path Path** (`output_path_path`, `text`, optional): Enter a file path for the output file.
* **Form ID** (`form_id`, `text`, required): Enter a unique form ID.
* **Output File Format** (`output_file_format`, `select_one`, required): Select the format of the output file.
* **Submitted At Time 2** (`submitted_at_time_2`, `time`, required): Enter the time of submission.
* **Form IDs** (`form_ids`, `text`, required): Enter any additional form IDs.

Note: The optional field **Output Path Path** is not currently required but may be used for future development purposes.
