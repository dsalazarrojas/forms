# Quiz Form With A Calculated Number Of Correct Answers - Help Guide
## Purpose
This form is designed to track user responses to questions, with the option to calculate the number of correct answers. It is likely used in an educational context to assess user knowledge or skills.

## How To Complete This Form
To complete this form, follow these steps:
1. Review the questions carefully and select the correct answers for each question.
2. Fill in the answers in the corresponding question fields.
3. The form will automatically calculate the number of correct answers.

## Field-by-Field Explanation
* **Calculated Answers** (`calculated_answers`, number, optional): This field will display the calculated number of correct answers after you have filled in all the questions.

* **Questions 1** (`questions_1`, select_multiple, optional): This field contains multiple-choice questions. Select all the correct answers that apply to you.
* **Questions 2** (`questions_2`, select_multiple, optional): This field contains multiple-choice questions. Select all the correct answers that apply to you.
