# Menstruation Education Workshop Form - Help Guide
## Purpose

This form is designed to collect essential details for the Menstruation Education Workshop. It's a crucial tool to ensure that the workshop runs smoothly and efficiently. Please fill out the form accurately and completely to help us better understand your needs.

## How To Complete This Form

1. Fill out the form in the following sections:
	* **Workshop details**: Provide a brief description of the workshop.
	* **Date**: Enter the date of the workshop.
	* **Time**: Enter the time of the workshop.
	* **Attendees**: Select all the attendees who will be participating in the workshop.
	* **Comments**: Add any additional comments or notes about the workshop.
	* **Form ID**: Enter a unique identifier for the form, which will be automatically generated.
	* **Assigned Tool**: Select the tool assigned for the workshop (e.g., chatjimmy).
	* **Output File**: If there's an output file for the workshop, upload it here.

## Field-by-Field Explanation

* **Workshop details**: A brief description of the workshop, including its purpose and objectives.
* **Date**: The date on which the workshop will take place.
* **Time**: The time at which the workshop will start.
* **Attendees**: A list of participants who will be attending the workshop. You can select multiple attendees from the provided options.
* **Comments**: Any additional comments or notes about the workshop.
* **Form ID**: A unique identifier for the form, which will be automatically generated.
* **Assigned Tool**: The tool assigned for the workshop, which helps identify the resources needed.
* **Output File**: If there's an output file for the workshop, you can upload it here.

## Tips

* Make sure to fill out all the required fields, indicated by an asterisk (\*) in the label.
* If you're unsure about any field, refer to the workshop organizers or your colleagues for clarification.
* Use the provided options for attendees to avoid typos or errors.
* If you need to add any additional information, use the comments field.
* The Assigned Tool field is critical, so please select the correct tool for the workshop.
* The Output File field is optional, but if there's an output file, please upload it to ensure it's properly linked to the workshop.
