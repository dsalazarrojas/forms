# Inclusive Curriculum Developer Application Form - Help Guide
## Purpose
The Inclusive Curriculum Developer Application Form is a tool used to propose new curriculum development projects. It is intended to gather information about the proposed project, including its category, title, and descriptions. 

## How To Complete This Form
Before filling out this form, make sure you have a clear idea of the project you want to propose. The form is divided into several pages, each with its own fields. Please fill out the form as follows:

1. **Education Forms/Job Application Forms** (`education_forms`, `select_multiple`, optional): Choose one or more options from the dropdown menu that apply to your proposed project. This field is used to indicate the type of educational form your project will cover. 
2. **Title** (`title`, `text`, optional): Enter a short title of your proposed project. This should be a concise description of the project.
3. **Description** (`description`, `text`, optional): Enter a brief description of your proposed project. This should be a detailed description of the project, including its goals and objectives.
4. **Category** (`category`, `select_one`, optional): Choose one option from the dropdown menu that best describes the category of your proposed project. This field is used to categorize your project for easier tracking and reference.
5. **Category 1** (`category_1`, `text`, optional): Enter a brief description of the category of your proposed project. This field is used to provide more detail about the category of your project.
6. **Category 2** (`category_2`, `text`, optional): Enter another brief description of the category of your proposed project. This field is used to provide more detail about the category of your project.
7. **Category 3** (`category_3`, `text`, optional): Enter another brief description of the category of your proposed project. This field is used to provide more detail about the category of your project.
8. **Description 1** (`description_1`, `text`, optional): Enter a brief description of the description of your proposed project. This field is used to provide more detail about the description of your project.
9. **Description 2** (`description_2`, `text`, optional): Enter another brief description of the description of your proposed project. This field is used to provide more detail about the description of your project.
10. **Description 3** (`description_3`, `text`, optional): Enter another brief description of the description of your proposed project. This field is used to provide more detail about the description of your project.
11. **Output File** (`output_file`, `text`, optional): Enter the expected output file name of your proposed project. This is used to track the output of your project.
12. **Assigned Tool** (`assigned_tool`, `text`, optional): Enter the tool that will be used to implement your proposed project. This field is used to track the tool used in your project.

## Tips
- Please make sure to fill out all required fields correctly.
- You can choose multiple options for "Education Forms/Job Application Forms" if your project covers both types of forms.
- You can leave "Description 1", "Description 2", and "Description 3" fields blank if your project does not require them.
- You can leave "Category 1", "Category 2", and "Category 3" fields blank if your project does not have a complex category structure.
- You can leave "Output File" and "Assigned Tool" fields blank if your project does not require them.
- If you are unsure about any field, please ask your project approver for clarification.
