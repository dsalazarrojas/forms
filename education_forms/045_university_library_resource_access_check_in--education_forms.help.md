# university_library_resource_access_check_in - Help Guide
## Purpose
The "university_library_resource_access_check_in" form is used to track the access of library resources by users. This form helps library staff to record and manage resource usage, ensuring the accurate tracking of resources and their status.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the "Resource Type" to identify the type of resource being checked in.
2. Enter the "User Type" to categorize the user accessing the resource (e.g., Student, Staff, Faculty, Guest).
3. Enter the "User Name" and "Email" fields to identify the user accessing the resource.
4. Enter the "Resource Name" to specify the name of the resource being checked in.
5. Select the "Check-in Time" and "Check-out Time" fields to record the time of access.
6. Enter the "Check-in Date" and "Check-out Date" fields to record the date of access.
7. Optionally, add "Comments" for any additional information or notes.
8. Enter "Visitor Details" if additional information about the visitor is required.

## Field-by-Field Explanation
* **Resource ID** (Number): This field is used to identify the resource being checked in.
* **User Type** (Select One): Choose the type of user accessing the resource (e.g., Student, Staff, Faculty, Guest).
	+ This helps in categorizing and tracking user types for reporting and access control purposes.
* **User Name** (Text): Enter the name of the user accessing the resource.
* **Email** (Email): Enter the email address of the user accessing the resource.
* **Resource Name** (Text): Enter the name of the resource being checked in.
* **Resource Type** (Select One): Choose the type of resource being checked in (e.g., Book, DVD, Game Console).
	+ This helps in tracking and categorizing resource types for reporting and inventory purposes.
* **Check-in Time** (Time): Record the time when the user accessed the resource.
* **Check-in Date** (Date): Record the date when the user accessed the resource.
* **Check-out Time** (Time): Record the time when the user finished accessing the resource.
* **Check-out Date** (Date): Record the date when the user finished accessing the resource.
* **Comments** (Note): Add any additional comments or notes about the access.
* **Visitor Details** (Text): Enter any additional information about the visitor, if required.

## Tips
* Ensure that you have the necessary permission to access the resource.
* Double-check the resource ID to avoid duplication.
* Complete all required fields to ensure accurate tracking and reporting.
