# Poster Submission Form - Help Guide
## Purpose
The Poster Submission Form is a tool used to collect information about student projects. It is essential to fill out this form accurately to ensure that the project details are correctly recorded and easily accessible.

## How To Complete This Form
- Start by carefully reading the form header to understand the purpose and any specific instructions.
- Fill out the "Student Name" field with the student's name exactly as it appears in official records.
- In the "Project Name" field, enter the name of the project, following the format "Project Name (Year)".
- Provide a brief description of the project in the "Project Description" field.
- Enter the date the project was completed or started in the "Project Date" field using the format YYYY-MM-DD.
- Enter the student's email address in the "Student Email" field.
- Enter the student's phone number in the "Student Phone" field.
- Select the project category by choosing from the drop-down menu in the "Project Category" field. Please ensure you choose the correct category as it directly affects how the project is recorded.

## Field-by-Field Explanation
- **Student Name** (Student Name, text, Required): This field is for the student's name exactly as it appears in official records. 
- **Project Name** (Project Name, text, Required): This field should include the project's name and the year it was completed. For example, "Project Name (Year)".
- **Project Description** (Project Description, text, Optional): A brief description of the project helps to provide additional context.
- **Project Date** (Project Date, date, Optional): Enter the date the project was completed or started using the format YYYY-MM-DD.
- **Student Email** (Student Email, email, Optional): Enter the student's email address.
- **Student Phone** (Student Phone, text, Optional): Enter the student's phone number.
- **Project Category** (Project Category, select_one, Optional): Select the project category from the provided options to ensure accurate recording and categorization of the project.
- **Form Footer** (Form Footer, note, Required): A note for internal use, do not fill this field.

## Tips
- Always ensure you have all necessary information before filling out the form.
- Double-check the project category selection as it directly affects project recording.
- Keep the project description brief but informative.
- If a field is marked as required, ensure you fill it out accurately.
- Use the YYYY-MM-DD format for dates.
