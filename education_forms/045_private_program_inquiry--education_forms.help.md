# Private Program Inquiry - Help Guide
## Purpose
This form is used to collect information from users about their private program preferences. Fill out this form to express your interest in a program.

## How To Complete This Form
To complete this form, simply follow these steps:
1. Select your preferred program type (e.g., Dance, Music, Fitness).
2. Choose your preferred dates and session duration.
3. Provide details about your program of choice.
4. Enter your contact information.
5. Select your preferred contact method (e.g., Phone, Email, In-person).
6. Provide any additional contact method details.
7. Enter other relevant program information such as type, session type, session details, program date, session time, program name, program length, program frequency, and program status.

## Field-by-Field Explanation
### Preferred program type
* **Preferred program type** (`preferred_program_type`, `select_multiple`, required: false)
	+ This field allows you to choose which program type you are interested in, such as Dance, Music, or Fitness.

### Preferred dates
* **Preferred dates** (`preferred_dates`, `date`, required: false)
	+ Enter the dates you are available to participate in the program.

### Preferred time
* **Preferred time** (`preferred_time`, `time`, required: false)
	+ Enter the time you are available to participate in the program.

### Session length
* **Session length** (`session_length`, `number`, required: false)

### Program details

### Program length
