# self_appraisal_form - Help Guide
## Purpose
This self-appraisal form is used for students to evaluate their own performances, progress, or status in a course or educational setting.

## How To Complete This Form
To complete this form, follow these steps:
1. Select the appropriate self-appraisal options for each question. For example, you can choose "Yes" or "No" for certain questions.
2. Fill out the student's name and number as required.
3. If necessary, select an evaluation type (e.g., "Yes" or "No") and an appraisal form status (e.g., "Active" or "Inactive").
4. Optionally, enter an evaluation comment or submit a score (as a number) for the assessment.
5. Confirm that you have submitted the form.

## Field-by-Field Explanation

* **Self-Appraisal** (`self_appraisal_form`, select_multiple, required: false): This question is used to select the relevant options for your self-appraisal. Choose all applicable answers from the provided options.
* **Student Name** (`student_name`, text, required: false): This is your name as a student in the course.
* **Student Number** (`student_number`, text, required: false): Enter your student ID or number.
* **Evaluation Type** (`evaluation_type`, select_one, required: false): This question asks if you are being evaluated.
* **Evaluation Date** (`evaluation_date`, date, required: false): This is the date when you were evaluated.
* **Appraisal Form Status** (`appraisal_form_status`, select_one, required: false): This question asks what your current appraisal form status is.
* **Submitted By** (`submitted_by`, select_one, required: false): This question asks if you have submitted this form.
* **Submitted By Role** (`submitted_by_role`, select_one, required: false): This question asks what role you are submitting this form for.
* **Submission Date** (`submission_date`, date, required: false): This is the date when you submitted this form.
* **Evaluation Comments** (`evaluation_comments`, text, required: false): You can add any additional comments or feedback for the assessment.
* **Evaluation Score** (`evaluation_score`, number, required: false): This is your score for the assessment.
* **Evaluation Status** (`evaluation_status`, select_one, required: false): This question asks what the status of your evaluation is.
