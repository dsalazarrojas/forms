## Erasmus+   Application Form For Youth Exchange - Help Guide

### Purpose
The Erasmus+ Application Form For Youth Exchange is a tool used to collect information from youth participants and their host organizations. This form is used to track and manage youth exchange applications, allowing users to monitor the status of each application.

### How To Complete This Form
To complete this form, follow these steps:

1. Fill in the participant's details, including their name, birthdate, email, and mobile number.
2. Provide the organization's details, including the name, address, website, email, and phone number.
3. Fill in the application details, including the application status and deadline.
4. Enter the youth exchange details, including the name, start and finish dates, and duration.
5. Add any additional notes or comments about the participant or application.

### Field-by-Field Explanation

- **Youth Exchange Form** (`youth_exchange_form`, text, required: false): This is the title of the form, which should be filled in with the name of the youth exchange.
- **Participant Details** (`participant_details`, text, required: false): This field is used to enter any additional details about the participant.
- **Participant Name** (`participant_name`, text, required: false): Enter the name of the participant.
- **Participant Birthdate** (`participant_birthdate`, date, required: false): Enter the participant's birthdate.
- **Participant Email** (`participant_email`, email, required: false): Enter the participant's email address.
- **Participant Mobile** (`participant_mobile`, text, required: false): Enter the participant's mobile number.
- **Organization Details** (`organization_details`, text, required: false): This field is used to enter any additional details about the host organization.
- **Organization Name** (`organization_name`, text, required: false): Enter the name of the host organization.
- **Organization Address** (`organization_address`, text, required: false): Enter the address of the host organization.
- **Organization Website** (`organization_website`, text, required: false): Enter the website of the host organization.
- **Organization Email** (`organization_email`, email, required: false): Enter the email address of the host organization.
- **Organization Phone** (`organization_phone`, text, required: false): Enter the phone number of the host organization.
- **Application Details** (`application_details`, text, required: false): This field is used to enter any additional details about the application.
- **Application Deadline** (`application_deadline`, date, required: false): Enter the deadline for the application.
- **Application Status** (`application_status`, select_one, required: false): Select the current status of the application from the options: Active, In progress, Closed, Cancelled.
- **Youth Exchange Details** (`youth_exchange_details`, text, required: false): This field is used to enter any additional details about the youth exchange.
- **Call ID** (`call_id`, text, required: false): Enter the call ID for the application.
- **Youth Exchange Name** (`youth_exchange_name`, text, required: false): Enter the name of the youth exchange.
- **Participant Status** (`participant_status`, select_multiple, required: false): Select the current status of the participant from the options: Active, In progress, Closed, Cancelled.
- **Youth Exchange Start Date** (`youth_exchange_start_date`, date, required: false): Enter the start date of the youth exchange.
- **Youth Exchange Finish Date** (`youth_exchange_finish_date`, date, required: false): Enter the finish date of the youth exchange.
- **Youth Exchange Duration** (`youth_exchange_duration`, text, required: false): Enter the duration of the youth exchange.
- **Youth Exchange Description** (`youth_exchange_description`, text, required: false): Enter a brief description of the youth exchange.
- **Notes** (`notes`, note, required: false): Add any additional notes or comments about the participant or application.

### Tips

* Make sure to fill in all required fields accurately and completely.
* Double-check the application status to ensure it reflects the current state of the application.
* Enter any additional details or notes to help track and manage the application.
* If you are unsure about any field or option, please contact the support team for assistance.
