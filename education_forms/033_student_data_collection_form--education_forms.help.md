# Student Data Collection Form - Help Guide

## Purpose
The Student Data Collection Form is intended to collect and store student data for educational purposes.

## How To Complete This Form
To complete this form, please follow the steps below:

1. Fill in the required fields with accurate and up-to-date information.
2. For fields with options, select the most relevant or applicable option.
3. If a field is not applicable, please leave it blank or select "N/A" if specified as an option.

## Field-by-Field Explanation
* **Student Id** (`student_id`, Number, Optional): Enter the student's identification number.
* **Student Name** (`student_name`, Text, Optional): Enter the student's name in full.
* **Student Prophet** (`student_prophet`, Select, Optional): Select the student's prophet or school affiliation.
* **Grade Level** (`grade_level`, Select Multiple, Optional): Select all applicable grade levels for the student.
* **School Name** (`school_name`, Text, Optional): Enter the student's school name.
* **Class Name** (`class_name`, Text, Optional): Enter the student's class name.
* **Student Performance** (`student_performance`, Time, Optional): Record the student's performance in the given time period.
* **Student Attendance** (`student_attendance`, Number, Optional): Record the student's attendance for the given period.
* **Student Behavior** (`student_behavior`, Note, Optional): Record any notable behavior or incidents involving the student.
* **Student Email** (`student_email`, Email, Optional): Enter the student's email address.
* **Student Phone** (`student_phone`, Text, Optional): Enter the student's phone number.
* **Student Address** (`student_address`, Text, Optional): Enter the student's home address.
* **Student Dob** (`student_dob`, Date, Optional): Record the student's date of birth.
* **Student Notes** (`student_notes`, Note, Optional): Record any additional notes or comments about the student.
* **Student Status** (`student_status`, Select, Optional): Select the current student status.
