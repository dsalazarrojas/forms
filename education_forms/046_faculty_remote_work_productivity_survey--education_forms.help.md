# Faculty Remote Work Productivity Survey - Help Guide
## Purpose
This survey is designed to gather feedback from faculty members about their experiences with remote work productivity. Your input will help administrators and decision-makers understand how faculty members are using remote work arrangements and what challenges they face while working from home.

## How To Complete This Form

1. This survey consists of multiple pages. Please fill out each page completely and honestly.
2. For select fields, select one or multiple options that apply to you.
3. For text fields, provide a brief description or answer in the space provided.
4. If you have additional information to provide that is not listed in the options, use the "Other" field at the end of each section.

## Field-by-Field Explanation

* **faculty_remote_work_productivity_survey_form** (`title`, text, optional):
    * This is the title of the form.
    * It is not a required field.
* **challenges** (`challenges`, select_one, optional):
    * Select one of the following:
        + Time management
        + Technical issues
        + Communication
        + Collaboration
        + Other (please specify in the "Other" field below)
* **satisfaction_level** (`satisfaction_level`, select_multiple, optional):
    * Select all that apply:
        + Very satisfied
        + Somewhat satisfied
        + Not satisfied
        + Neutral
        + Very dissatisfied
* **productivity** (`productivity`, number, optional):
    * Enter a number between 0 and 100 to indicate your current productivity level.
* **work_from_home_frequency** (`work_from_home_frequency`, time, optional):
    * Enter the frequency of work from home, using the format "X days per week" (e.g., 2 days per week).
* **work_from_home_duration** (`work_from_home_duration`, date, optional):
    * Enter the duration of work from home, using the format "X months" (e.g., 6 months).
* **work_from_home_location** (`work_from_home_location`, text, optional):
