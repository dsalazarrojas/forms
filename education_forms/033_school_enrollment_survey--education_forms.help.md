# School Enrollment Survey - Help Guide
## Purpose
The "School Enrollment Survey" form is designed to collect demographic and educational information about students and their families for enrollment purposes.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill in the required fields, which are marked as required.
2. Select options for multiple-choice fields such as "Student Interests", "Parent Education", and "Family Status".
3. Enter dates in the "Student Date of Birth" and "Student Birthdate" fields in the format "YYYY-MM-DD".

## Field-by-Field Explanation
- **Parent Details**: Enter the name and contact information of the parent or guardian.
  - (text input, not required)
- **Student Information**: Enter general information about the student, such as name and interests.
  - (text input, not required)
- **Family Background**: Enter additional details about the family.
  - (text input, not required)
- **Academic Details**: Enter academic information about the student, such as education level and school.
  - (text input, not required)
- **Contact Information**: Enter contact information for the parent or guardian.
  - (text input, not required)
- **Parent Work Status**: Enter the work status of the parent or guardian.
  - (text input, not required)
- **Student Interests**: Select the student's interests.
  - (select multiple options, not required)
- **Parent Education**: Select the parent's education level.
  - (select one option, not required)
- **Student Education**: Select the student's education level.
  - (select one option, not required)
- **Student Age**: Enter the student's age.
  - (number input, not required)
- **Student Date of Birth**: Enter the student's date of birth in the format "YYYY-MM-DD".
  - (date input, not required)
- **Student School**: Enter the student's school.
  - (text input, not required)
- **Parent Occupation**: Enter the parent's occupation.
  - (text input, not required)
- **Student Education**: Select the student's education level.
  - (select one option, not required)
- **Student Address**: Enter the student's address.
  - (text input, not required)
- **Parent Phone**: Enter the parent's phone number.
  - (text input, not required)
- **Parent Email**: Enter the parent's email address.
  - (email input, not required)
- **Student Interests**: Select the student's interests.
  - (select multiple options, not required)
- **Student Language**: Select the student's language.
  - (select one option, not required)
- **Student Gender**: Select the student's gender.
  - (select one option, not required)
- **Student Birthdate**: Enter the student's date of birth.
  - (date input, not required)
- **Parent Language**: Select the parent's language.
  - (select one option, not required)
- **Student Hobbies**: Select the student's hobbies.
  - (select multiple options, not required)
- **Family Status**: Select the family status.
  - (select one option, not required)
- **Family Type**: Select the family type.
  - (select one option, not required)

## Tips
- Please ensure all required fields are filled before submitting the form.
- If you are unsure about any field, please ask your parent or guardian for help.
- If you have any further questions or concerns, please contact the school administration.
