# Orientation Log Submission - Help Guide
## Purpose
The Orientation Log Submission form is used to collect and store important information about orientation sessions, including attendee details, session specifics, and facilitator information. This form is essential for ensuring accurate and reliable records of orientation sessions.

## How To Complete This Form
To complete this form, please follow these steps:

1. Enter the attendee's details, including their name and any other relevant information.
2. Select the type of orientation session (e.g., New Hire, New Student, etc.).
3. Choose the topics that were covered during the session.
4. Provide feedback about the session, if any.
5. Enter the date and time of the session.
6. Enter the duration of the session.
7. Enter any additional notes about the session.
8. Enter the location of the session.
9. Enter the name of the session facilitator(s).
10. Enter any additional notes about the session facilitator(s).
11. Select any additional facilitators who participated in the session.
12. Enter any additional notes about the session.

## Field-by-Field Explanation
* **User Details**: Enter the attendee's name and any other relevant information about them.
* **Orientation Type**: Select the type of orientation session (e.g., New Hire, New Student, etc.).
* **Topics Covered**: Choose the topics that were covered during the session.
* **Feedback**: Provide feedback about the session, if any.
* **Orientation Date**: Enter the date of the session.
* **Orientation Time**: Enter the time of the session.
* **Session Duration**: Enter the duration of the session.
* **Session Notes**: Enter any additional notes about the session.
* **Session Location**: Enter the location of the session.
* **Session Facilitator**: Enter the name of the session facilitator(s).
* **Session Facilitators**: Select any additional facilitators who participated in the session.
* **Session Notes (Facilitator)**: Enter any additional notes about the session facilitator(s).
* **New Hire**: Select this option for new hire orientations.
* **New Student**: Select this option for new student orientations.
* **New Employee**: Select this option for new employee orientations.
* **New Faculty**: Select this option for new faculty orientations.
* **New Staff**: Select this option for new staff orientations.
* **New Parent**: Select this option for new parent orientations.
* **New Volunteer**: Select this option for new volunteer orientations.
* **Other**: Select this option for any other type of orientation.
* **Introduction**: Select this option for introductions.
* **Policies**: Select this option for policies.
* **Code of Conduct**: Select this option for code of conduct.
* **Emergency Procedures**: Select this option for emergency procedures.
* **Other**: Select this option for any other topics that were covered during the session.
* **John**: Select this option for John as a session facilitator.
* **Jane**: Select this option for Jane as a session facilitator.
* **Joe**: Select this option for Joe as a session facilitator.

## Tips
* Please ensure that only one submission is made per session.
* If you're unsure about any field, please refer to the above explanations for clarification.
* If you have any questions or concerns, please reach out to your supervisor or administrator.
