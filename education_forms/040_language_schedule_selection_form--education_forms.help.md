# Language Schedule Selection Form - Help Guide
## Purpose
The Language Schedule Selection Form is a tool for students to select their preferred language schedule for a course. It is used to gather information for scheduling purposes.

## How To Complete This Form
To complete the form, follow these steps:

1. Select a course from the "Select Course" dropdown menu.
2. Choose a schedule from the "Select Schedule" dropdown menu.
3. Select a language from the "Select Language" dropdown menu.
4. Enter any additional comments or notes in the "Additional Comments" text field.
5. Enter your email address in the "Email" text field.
6. Enter your phone number in the "Phone Number" text field.
7. Select a date from the calendar for the "Select Date" field.
8. Select a time from the time picker for the "Select Time" field.
9. Select a language schedule from the "Select Language Schedule" dropdown menu.
10. Enter a course ID in the "Select Course ID" text field.

## Field-by-Field Explanation
### Select Course
* **Select Course** (`course_select`, select_multiple, required: false): This field is a dropdown menu where you can select one or multiple courses for which you want to schedule a language course.
*   Please select one or multiple courses that you are interested in.

### Select Schedule
* **Select Schedule** (`schedule_select`, select_one, required: false): This field is a dropdown menu where you can select a schedule for the course(s) you have chosen.
*   Please select a schedule that suits your availability.

### Select Language
* **Select Language** (`language_select`, select_one, required: false): This field is a dropdown menu where you can select a language for the course(s) you have chosen.
*   Please select a language that you are proficient in.

### Additional Comments
* **Additional Comments** (`note`, note, required: false): This is a text field where you can add any additional comments or notes about your selection.
*   Use this field to provide any additional information that is relevant to your selection.

### Email
* **Email** (`email`, email, required: false): This field is where you can enter your email address.
*   Please enter your student email address.

### Phone Number
* **Phone Number** (`phone`, text, required: false): This field is where you can enter your phone number.
*   Please enter your student phone number.

### Select Date
* **Select Date** (`date`, date, required: false): This field is a calendar where you can select a date.
*   Please select a date for the scheduling.

### Select Time
* **Select Time** (`time`, time, required: false): This field is a time picker where you can select a time.
*   Please select a time for the scheduling.

### Select Language Schedule
* **Select Language Schedule** (`language_schedule_select`, select_one, required: false): This field is a dropdown menu where you can select a language schedule.
*   Please select a language schedule that suits your needs.

### Select Course ID
* **Select Course ID** (`course_id`, number, required: false): This field is where you can enter a course ID.
*   Please enter the course ID.

### Phone Number
* **Phone Number** (`phone`, text, required: false): This field is where you can enter your phone number.
*   Please enter your student phone number.
