# Fellow Program Alumni Contact Update Form - Help Guide
## Purpose
The Fellow Program Alumni Contact Update Form is designed to collect and update contact information from fellow program alumni. This form will help us keep you informed about the program's activities, developments, and opportunities.

## How To Complete This Form
To complete this form, please fill in the following fields:
*   First name (required)
*   Last name (required)
*   Email address (required)
*   Phone number (optional)
*   Address (optional)
*   Organization (optional)
*   Role in the program (optional)
*   Current job title (optional)
*   Update method:
    +   Yes: You would like to receive updates about the program via email, phone, or mail.
    +   No: You do not want to receive updates about the program.
*   Preferred method:
    +   Yes: You would like to receive updates about the program via email, phone, or mail.
    +   No: You do not want to receive updates about the program.
*   Update frequency:
    +   Yes: You would like to receive updates about the program as often as possible.
    +   No: You would like to receive updates about the program less frequently.
*   Last update date (optional)
*   Last update time (optional)

## Field-by-Field Explanation
*   **First name**: Please enter your first name as it appears on your official documents.
*   **Last name**: Please enter your last name as it appears on your official documents.
*   **Email**: Please enter your email address where you can be reached for updates and information.
*   **Phone**: Please enter your phone number if you would like to be contacted via phone.
*   **Address**: Please enter your current address where you can be contacted if needed.
*   **Organization**: Please enter the name of your current organization if you are working or studying at one.
*   **Role**: Please enter your role in the program, such as student, participant, or collaborator.
*   **Job title**: Please enter your current job title if you are employed or have a specific role in the program.
*   **Update method**: Select how you would like to receive updates about the program (yes or no).
*   **Preferred method**: Select how you would like to receive updates about the program (yes or no).
*   **Update frequency**: Select how frequently you would like to receive updates about the program (yes or no).
*   **Last update date**: Please enter the date of your last update.
*   **Last update time**: Please enter the time of your last update.

## Tips
*   Please ensure that your information is accurate and up-to-date.
*   If you have any questions or concerns, please contact us for assistance.
*   This form is intended for program administrators to collect your contact information and preferences.
*   You can complete this form only once for each individual.
