# Question Addition Guide - Help Guide
## Purpose
This form is used to add a new question to the system. Please ensure that the question you are adding is relevant and not a duplicate of an existing question. If you are adding a new question for the same topic, please consider checking the existing questions in that topic before proceeding.

## How To Complete This Form
To add a new question, follow these steps:

* Fill out the form with the required information.
* Select the correct "Question Type" from the options provided.
* Enter the "Question Text" in the text box.
* Add any "Question Tags" as relevant.
* Choose a "Submit Time" and "Review" status.
* Select a "Team Reviewer" and enter their "Email" and "Phone" if necessary.
* Enter any "Review Comment" from the reviewer.
* Enter the "Submitter" and their "Email" and "Phone" if necessary.
* Enter any "Submitter Comment" from the submitter.

## Field-by-Field Explanation
### First Page (Text)
* **First Page** (`first_page`, text, optional): Enter a brief description of the question you are adding.

### Question Type (Select One)
* **Question Type** (`question_type`, select_one, optional): Select the type of question you are adding (e.g., Quiz, Assessment, Survey).

### Question Text (Text)
* **Question Text** (`question_text`, text, optional): Enter the text of the question you are adding.

### Question Tags (Text)
* **Question Tags** (`question_tags`, text, optional): Add any relevant tags to the question.

### Submit Time (Date)
* **Submit Time** (`submit_time`, date, optional): Select the date and time when the question was submitted.

### Review (Select One)
* **Review** (`review`, select_one, optional): Choose the status of the question (Review and Approve, Approve, Approve and Review).

### Team Reviewer (Text)
* **Team Reviewer** (`team_reviewer`, text, optional): Select the reviewer's name.

### Team Reviewer Email (Email)
* **Team Reviewer Email** (`team_reviewer_email`, email, optional): Enter the reviewer's email address.

### Team Reviewer Phone (Text)
* **Team Reviewer Phone** (`team_reviewer_phone`, text, optional): Enter the reviewer's phone number.

### Reviewer Comment (Text)
* **Review Comment** (`reviewer_comment`, text, optional): Enter any comments from the reviewer.

### Submitter (Text)
* **Submitter** (`submitter`, text, optional): Enter the submitter's name.

### Submitter Email (Email)
* **Submitter Email** (`submitter_email`, email, optional): Enter the submitter's email address.

### Submitter Phone (Text)
* **Submitter Phone** (`submitter_phone`, text, optional): Enter the submitter's phone number.

### Submitter Comment (Text)
* **Submitter Comment** (`submitter_comment`, text, optional): Enter any comments from the submitter.

Note: All fields are optional unless marked as required.
