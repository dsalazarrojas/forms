# Daily Submission Form - Help Guide
## Purpose
The Daily Submission Form is designed to collect daily submissions from users for tracking and logging purposes.

## How To Complete This Form

1. Select the submission type from the options provided.
2. Choose the date and time of the submission.
3. Enter the category of the submission.
4. Fill in the submitter's name.
5. Provide the submitter's email address.
6. Enter the submitter's phone number.
7. Select the location of the submission.
8. Add any additional notes about the submission.
9. (Optional) Attach files or URLs to support the submission.
10. Select any additional submitter details as needed.

## Field-by-Field Explanation

* **submission_type**: Select the type of submission you are making (e.g., Option 1, Option 2, Option 3).
* **date_submitted**: Enter the date of the submission in the format MM/DD/YYYY.
* **category**: Enter the category of the submission.
* **name**: Enter the name of the submitter.
* **email**: Enter the email address of the submitter.
* **phone**: Enter the phone number of the submitter.
* **location**: Enter the location of the submission.
* **notes**: Select any additional notes about the submission.
* **attachments**: Provide any attachments to support the submission (e.g., images, documents).
* **file_upload**: Upload a file to support the submission.
* **file_url**: Enter a URL of a file to support the submission.
* **submitter_url**: Enter a URL associated with the submitter.
* **submitter_email**: Enter the email address of the submitter.
* **submitter_phone**: Enter the phone number of the submitter.
* **submitter_location**: Enter the location of the submitter.
* **submitter_notes**: Select any additional notes about the submitter.
* **submitter_attachments**: Provide any attachments associated with the submitter.
* **submitter_file_upload**: Upload a file associated with the submitter.
* **submitter_file_url**: Enter a URL of a file associated with the submitter.
* **submitter_url**: Enter a URL associated with the submitter.
* **submitter_phone**: Enter the phone number of the submitter.
