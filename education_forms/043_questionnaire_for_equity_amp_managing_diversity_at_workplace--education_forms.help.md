# Questionnaire For Equity & Managing Diversity At Workplace - Help Guide
## Purpose
This form is designed to collect data and information for the purpose of equity and managing diversity at the workplace. It is used to gather feedback, insights, or data for analysis, which is then used to create a report or output file.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter a title for the form in the "Form Title" field.
2. Select a category for the form from the dropdown options.
3. If required, enter a brief description of the form in the "Description" field.
4. Enter the name of the output file in the "Output File Name" field.
5. Select the type of output file you want to create (e.g., PDF, CSV, Excel) in the "File Type" field.
6. Enter the size of the output file in the "File Size" field.
7. If required, select the tool assigned for the form from the dropdown options.
8. Enter help messages for the form as needed in the "Help Message" fields.

## Field-by-Field Explanation
* **Form Title** (text, required): Enter a title for the form that will be displayed for reference.
* **Form Category** (select one, optional): Select a category for the form from the dropdown options. This helps to group similar forms together.
* **Description** (text, optional): Enter a brief description of the form if needed.
* **Output File Name** (text, required): Enter the name of the output file that will be generated based on the form data.
* **File Type** (select one, optional): Select the type of output file you want to create (e.g., PDF, CSV, Excel).
* **File Size** (number, required): Enter the size of the output file in bytes or kilobytes.
* **Assigned Tool** (select one, optional): If required, select the tool assigned for the form from the dropdown options.
* **Help Message 1, 2, 3** (text, optional): Enter help messages as needed for the form users.
