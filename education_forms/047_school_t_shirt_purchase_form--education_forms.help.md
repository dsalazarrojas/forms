# School T Shirt Purchase Form - Help Guide
## Purpose
This form is used to record and process orders for school t-shirt purchases made by students.

## How To Complete This Form
To complete this form, follow these steps:
1. Select the student size from the list of options.
2. Choose the t-shirt size from the same options.
3. Enter the amount of student fee the student is paying for the shirt.
4. If the student is a member of a class, select the class name.
5. Enter the total fee paid by the student.
6. Choose the method of payment (e.g. Cash, Credit Card, Bank Transfer).
7. Enter the date of the order.

## Field-by-Field Explanation
* **School T Shirt Purcase Form**: This is the title of the form, which is displayed at the top of the form.
* **Student Size**: Select the size that best fits the student. For example, if you select "S", it means the student is in size Small.
* **T Shirt Size**: Choose the size of the t-shirt the student wants to buy. This should match the student's size if possible.
* **Student Fee**: Enter the fee the student is paying for the t-shirt. This can be any amount.
* **Class Affiliation**: If the student is a member of a class, select the class name to record the affiliation.
* **Student Fee Total**: Enter the total amount paid by the student.
* **Payment Method**: Choose how the student paid for the t-shirt. For example, if you select "Cash", it means the student paid in cash.
* **Order Date**: Enter the date the order was placed. This is the date the form was completed by the student.
