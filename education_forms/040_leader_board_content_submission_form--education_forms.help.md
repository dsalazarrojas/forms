# Leader Board Content Submission Form - Help Guide
## Purpose
The Leader Board Content Submission Form is designed to allow users to submit information about a form to be displayed on the Leader Board.

## How To Complete This Form
To complete this form, follow these steps:
1. Enter the **Form Name** in the "Form Name" field.
2. Enter the **Form Content** in the "Form Content" field.
3. Enter the **Form URL** in the "Form URL" field, if applicable.
4. Select the **Form Type** from the provided options.
5. Select the **Form Category** from the provided options.
6. Add any relevant **Form Tags** (optional).
7. Enter the **Form Author** name (optional).

## Field-by-Field Explanation
* **Form Name (text)**: Enter a brief name for the form that will be displayed on the Leader Board.
* **Form Content (text)**: Enter a brief description or summary of the form content.
* **Form URL (text)**: Enter the URL of the form, if it has a website associated with it.
* **Form Type (select_one)**: Select the type of form from the provided options.
* **Form Category (select_one)**: Select the category of the form from the provided options.
* **Form Tags (select_multiple)**: Enter a comma-separated list of tags that describe the form content (optional).
* **Form Author (text)**: Enter the author's name of the form (optional).
