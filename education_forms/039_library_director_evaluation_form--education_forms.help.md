# Library Director Evaluation Form - Help Guide

## Purpose

This form is designed to gather feedback and evaluations from library users. It will help us understand your opinions and experiences with our library services and resources. Your input will be valuable in identifying areas for improvement and making informed decisions for the betterment of the library.

## How To Complete This Form

* Review each question carefully and select the best option that applies to your experience.
* Answer each question thoroughly, as your feedback is essential in helping us improve our services.
* If you have additional comments or suggestions, please use the "Additional comments" field to provide more information.

## Field-by-Field Explanation

* **Library Director Evaluation Form (1, 11)**: This is the title of the form.
* **What do you value most when giving feedback (2)**: Please select "Yes" if you value feedback that is:
	+ Helpful and actionable
	+ Constructive and respectful
	+ Timely and relevant
	+ Honest and open
* **Feedback question 1 (3)**: Please type in your thoughts about what you value most when giving feedback.
* **Feedback question 2 (4)**: Please select "Yes" if you value feedback that is:
	+ Specific and detailed
	+ Well-structured and organized
	+ Relevant to the library's goals and objectives
	+ Positive and supportive
* **Feedback question 2 answer (5)**: Please type in your thoughts about feedback question 2.
* **Feedback question 3 (6)**: Please select "Yes" if you value feedback that includes:
	+ Multiple perspectives

* **Feedback question 3 answer 1 (7)**: Please type in your thoughts about feedback question 3.
* **Feedback question 3 answer 2 (8)**: Please type in your thoughts about feedback question 3.

	+ Timely and prompt

* **Feedback question 4 answer (10)**: Please type in your thoughts about feedback question 4.

* **Contact number (13)**: Please enter your contact number if you want to be contacted by phone.
