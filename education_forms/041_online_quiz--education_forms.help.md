# Online Quiz - Help Guide
## Purpose
The "Online Quiz" form is designed for users to create and customize a quiz that meets specific requirements, such as selecting a category, grade level, subject, and length of the quiz.

## How To Complete This Form
To complete the "Online Quiz" form effectively:

1.  Choose a category that best fits the quiz's content.
2.  Select the grade level that the quiz is intended for.
3.  Choose the subjects that the quiz covers.
4.  Determine the length of the quiz, which can be 10, 20, 30, 40, or 50 questions.
5.  Optionally, select a time and date for the quiz.

## Field-by-Field Explanation

*   **Category** (`Category`, `select_multiple`, required): Choose a category from the list of available options (Math, Science, Social Studies, etc.).
    This field helps to ensure that the quiz is aligned with the correct subject area.
*   **Grade Level** (`Grade Level`, `select_one`, required): Select the grade level for which the quiz is intended (1-3, 4-6, 7-9, 10).
    This field helps to narrow down the target audience for the quiz.
*   **Subject** (`Subject`, `select_multiple`, required): Select the subject(s) covered in the quiz (English, Science, Math, History, Foreign Language, Art, Music, etc.).
    This field ensures that the quiz focuses on relevant topics and subjects.
*   **Quiz Length** (`Quiz Length`, `select_one`, required): Choose the number of questions in the quiz (10, 20, 30, 40, 50).
    This field helps users set an appropriate number of questions for the quiz.
*   **Time** (`Time`, `time`, optional): If applicable, select the time for the quiz.
    This field allows for scheduling flexibility.
*   **Date** (`Date`, `date`, optional): If applicable, select the date for the quiz.
    This field also allows for scheduling flexibility.
*   **Email** (`Email`, `email`, optional): Enter a contact email address.
    This field serves as a means of communication and contact.
*   **Phone** (`Phone`, `text`, optional): Enter a phone number.
    This field might be used for additional contact or scheduling purposes.
*   **Note** (`Note`, `note`, optional): Add any additional notes or comments.
    This field provides a space for users to include supplementary information.

Note: This guide focuses on the most relevant fields for the form's purpose and omits unnecessary or ambiguous fields.
