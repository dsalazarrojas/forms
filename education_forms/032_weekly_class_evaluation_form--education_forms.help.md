# Weekly Class Evaluation Form - Help Guide
## Purpose
The Weekly Class Evaluation Form is a tool designed to gather feedback from students on their weekly class experiences. This form helps teachers to assess the effectiveness of the class and identify areas of improvement.

## How To Complete This Form
To complete this form, follow these steps:

1.  Answer the question "What did the class learn this week?" in the text field. This is an optional field, and you can type any relevant information about what you learned or what you would like to learn more about.
2.  Rate the class' performance this week by typing a number between 1 and 10. This will give the teacher an idea of your overall satisfaction with the class.
3.  Select one of the engagement levels from 1 to 10, as described in the hint, to rate how you felt about the class' engagement this week.
4.  Choose any suggestions for next week from the drop-down list. You can select as many suggestions as you like.
5.  Type any comments or feedback you have about the class in the text field.
6.  Upload any relevant files or materials that you would like to share with the teacher.

## Field-by-Field Explanation

* **What did the class learn this week?** (`questions`, `text`, optional): Please provide any information about what you learned or would like to learn more about this week.
* **Class performance this week?** (`class_performance`, `number`, required): Rate the class' overall performance this week by typing a number between 1 and 10.
* **How was the class' engagement this week?** (`engagement`, `select_one`, required): Select a number from 1 to 10 to rate how you felt about the class' engagement this week.
* **Any suggestions for next week?** (`suggestions_for_next_week`, `select_multiple`, optional): Choose any suggestions you have for next week from the drop-down list.
* **Any comments?** (`comments`, `note`, optional): Type any additional comments or feedback you have about the class.
* **File uploads** (`file_uploads`, `text`, optional): Upload any relevant files or materials that you would like to share with the teacher.
