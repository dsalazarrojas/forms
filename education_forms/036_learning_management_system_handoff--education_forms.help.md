# Learning Management System Handoff - Help Guide
## Purpose
This form is used to document the handoff between owners of a training management system. It collects information necessary for a smooth transition, including the details of the current and new owners, training programs, and other relevant data.

## How To Complete This Form
To complete this form, follow these steps:
1. Enter the ID of the form that corresponds with this handoff.
2. Enter the name and email of the current owner.
3. Enter the date of the transition.
4. Enter the name and email of the new owner.
5. Enter the details of the transition.
6. Select the relevant training program(s) and document type(s) involved in the transition.
7. Enter any additional training data, training time, and training duration.
8. Select the status of the training.
9. Enter any additional comments or notes about the training.
10. Repeat steps 6-9 for any additional training information if necessary.

## Field-by-Field Explanation

* **form_id**: Enter the ID of the form that corresponds with this handoff. (Required)
* **owner_name**: Enter the name of the current owner. (Required)
* **owner_email**: Enter the email of the current owner. (Required)
* **transition_date**: Enter the date of the transition. (Required)
* **new_owner_name**: Enter the name of the new owner. (Required)
* **new_owner_email**: Enter the email of the new owner. (Required)
* **transition_details**: Enter the details of the transition. (Required)
* **system_url**: This field is not required and can be left empty if no system URL is provided. (Optional)
* **training_program**: Select the training program involved in this transition. (Required)
* **document_type**: Select the document type involved in this transition. (Required)
* **notes**: This field is not required and can be left empty if no notes are provided. (Optional)
* **form_submission_url**: This field is not required and can be left empty if no form submission URL is provided. (Optional)
* **training_data**: Enter additional training data. (Required)
* **training_time**: Enter the time spent on training. (Required)
* **training_duration**: Enter the duration of the training. (Required)
* **training_status**: Select the status of the training. (Required)
* **training_comments**: Enter additional comments about the training. (Required)
* **training_notes**: This field is not required and can be left empty if no notes are provided. (Optional)
* **form_submission_url**: This field is not required and can be left empty if no form submission URL is provided. (Optional)
* **system_url**: This field is not required and can be left empty if no system URL is provided. (Optional)
* **training_program_2**: Select the training program involved in this transition. (Required)
* **document_type_2**: Select the document type involved in this transition. (Required)
* **notes_2**: This field is not required and can be left empty if no notes are provided. (Optional)
* **form_submission_url_2**: This field is not required and can be left empty if no form submission URL is provided. (Optional)
* **assigned_to**: Select the person assigned to the new owner. (Required)

Note: Ensure that you provide valid and accurate information when filling out this form to ensure a smooth handoff process. If you are unsure about any field, please consult the relevant documentation or contact the owner of the form for further assistance.
