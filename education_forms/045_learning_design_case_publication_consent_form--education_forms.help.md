# Learning Design Case Publication Consent Form - Help Guide
## Purpose
This form is designed to obtain consent from individuals involved in learning design cases for publication. It is intended for use in academic or professional settings where learning design cases are being developed or documented.

## How To Complete This Form
To complete this form, please follow these steps:

1. Select the type of case study you are submitting:
	* Research
	* Project
	* Pilot
	* Implementation
2. Answer if the case study is anonymous or not:
	* Yes
	* No
3. Provide your name and organization (if applicable):
	* Type your name in the text field
	* Type your organization's name in the text field

## Field-by-Field Explanation

* **What type of case study is this?**: This field is a dropdown menu where you can select the type of case study you are submitting. This will help categorize and filter the cases for future use.
* **Is this case study anonymous?**: This field is a dropdown menu where you can select whether the case study is anonymous or not.
* **Your Name**: This text field is where you can type your name if you are submitting the form on your own behalf. If you are submitting on behalf of someone else, please type their name.
* **Organisation**: This text field is where you can type your organization's name (if applicable).

## Tips
* Please ensure you have the authority to submit the form on behalf of someone else.
* Please ensure you have obtained the necessary consent from individuals involved in the case study.
* If you have any concerns about data protection or submission, please contact form@gic.mx.
