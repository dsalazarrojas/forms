# need-help-education-forms - Help Guide
## Purpose
This form is used to provide support and guidance for education-related topics. The purpose of this form is to gather information about the user's education needs, allowing our team to offer relevant assistance.

## How To Complete This Form
To complete this form, follow these steps:
- Click on the "Need Help" title field and enter a brief description of your education-related need.
- Select the "Education Forms" category from the dropdown menu.
- In the description field, provide a detailed description of your education topic or concern.
- If applicable, enter the specific tool assigned to you for this education-related task, or select from the list of available tools.

## Field-by-Field Explanation

* **Need Help?** (`form_title`, text, optional): This field is where you can briefly describe the education-related topic or issue you need help with.
* **Education Forms** (`category`, select_one, required): Select "Education Forms" to indicate that you are seeking help with an education-related topic.
* **Description** (`description`, text, optional): Please provide a detailed description of the education topic or concern you are experiencing.
* **Assigned Tool** (`assigned_tool`, text, optional): If a specific tool has been assigned to you for this education-related task, enter it here, or select from the available tools in the dropdown menu.

## Tips
- Make sure to provide clear and concise information in the description field to help our team better understand your education-related need.
- If a specific tool has been assigned, ensure you select it correctly to avoid confusion.
- If you are unsure about any field or option, please reach out to our support team for assistance.
