# Totalitarianism Knowledge Quiz - Help Guide
## Purpose
The Totalitarianism Knowledge Quiz is a form used to collect information for the education form category. It is designed to gather data on specific fields related to the quiz, such as the title, category, and output file information.

## How To Complete This Form
1. Start by filling out the **Totalitarianism Knowledge Quiz** field with the title of the quiz.
2. Select the **Category** field to choose the category this quiz belongs to.
3. In the **Quiz type** field, select whether the quiz is online or offline.
4. In the **Form Ids** field, select the form IDs that this quiz is associated with.
5. In the **Assigned Tool** field, select the tool assigned to this quiz.
6. Fill out the **Output File** fields with the desired output file information.
7. Optionally, select additional categories for this quiz.

## Field-by-Field Explanation
* **Totalitarianism Knowledge Quiz**: Enter the title of the quiz, which will be displayed on the quiz page. This field is required.
* **Category**: Choose the category this quiz belongs to. This field is not required.
* **Description**: This field is currently not used, so you can leave it empty. However, if you need to add a description, enter it here.
* **Quiz type**: Select whether the quiz is online or offline. This field is required.
* **Form Ids**: Select the form IDs that this quiz is associated with. This field is required.
* **Output File**: Enter the output file information, which will be used to generate the quiz results. This field is not required.
* **Output File 2**: This field is another output file option, which is not used in this guide but can be used if needed. This field is not required.
* **Category**: Choose additional categories for this quiz. This field is not required.
