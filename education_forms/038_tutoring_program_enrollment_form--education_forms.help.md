# Tutoring Program Enrollment Form - Help Guide
## Purpose
This form is used to collect information about a student's enrollment in a tutoring program, including their personal details, program status, and assigned tutor. This form helps track and monitor progress, and provides valuable data for program evaluation and improvement.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter your first name and last name in the respective fields.
2. Enter your email address and phone number.
3. Select the program enrollment date and duration from the provided options.
4. Enter the program start date.
5. Select the program status (In Progress, Completed, or Discontinued).
6. Enter any additional program notes.
7. Select the tutoring frequency (Daily, Weekly, or Bi-weekly).
8. Enter the tutoring start date.
9. Select the tutoring status (In Progress, Completed, or Discontinued).
10. Enter any additional tutoring notes.
11. Enter your student ID and program ID (if applicable).
12. Select the assigned tutor from the provided list.
13. Enter the assigned room and time (if applicable).
14. Select the assigned date and status (if applicable).
15. Enter any assigned notes (if applicable).
16. Enter the institution (if applicable).
17. Select the assigned instructor from the provided list.

## Field-by-Field Explanation
* **First Name**: Enter your first name.
* **Last Name**: Enter your last name.
* **Email**: Enter your email address.
* **Phone**: Enter your phone number.
* **Program Enrollment Date**: Select the date you enrolled in the program.
* **Program Duration**: Select the duration of the program (1 month, 3 months, or 6 months).
* **Program Start Date**: Enter the date the program started.
* **Program Status**: Select the status of the program (In Progress, Completed, or Discontinued).
* **Program Notes**: Enter any additional notes about the program.
* **Tutoring Frequency**: Select how often you are tutored (Daily, Weekly, or Bi-weekly).
* **Tutoring Start Date**: Enter the date you started tutoring.
* **Tutoring Status**: Select the status of your tutoring (In Progress, Completed, or Discontinued).
* **Tutoring Notes**: Enter any additional notes about the tutoring.
* **Student ID**: Enter your student ID (if applicable).
* **Program ID**: Enter your program ID (if applicable).
* **Assigned Tutor**: Select the tutor assigned to you from the provided list.
* **Assigned Room**: Enter the room assigned to you (if applicable).
* **Assigned Time**: Enter the time assigned to you (if applicable).
* **Assigned Date**: Select the date assigned to you (if applicable).
* **Assigned Status**: Select the status of your assignment (Available, Unavailable, or Completed).
* **Assigned Notes**: Enter any additional notes about your assignment.
* **Institution**: Enter the institution you are affiliated with (if applicable).
* **Assigned Instructor**: Select the instructor assigned to you from the provided list.
