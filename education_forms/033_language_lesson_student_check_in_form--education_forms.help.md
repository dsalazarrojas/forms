# Language Lesson Student Check In Form - Help Guide
## Purpose
This form is used to record student attendance and other relevant information during language lessons. It helps instructors track student presence, note taking, and other important details.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the attendance status of the student using the "Student Attendance" field. Options include "Present", "Absent", and "Tardy".
2. Enter the student's name and ID number in the "Student Name" and "Student ID" fields, respectively.
3. Enter the student's email address in the "Student Email" field if available.
4. Select the date and time of the lesson using the "Lesson Date" and "Lesson Time" fields, respectively.
5. Optionally, enter any additional notes or comments about the student's session in the "Session Notes" field.

## Field-by-Field Explanation
* **Student Checkin**: Select the attendance status of the student (Present, Absent, Tardy).
* **Lesson Date**: Enter the date of the lesson.
* **Lesson Time**: Enter the time of the lesson.
* **Student Name**: Enter the name of the student.
* **Student ID**: Enter the ID number of the student.
* **Lesson Location**: Enter the location of the lesson (optional).
* **Tutor Notes**: Enter any notes or comments about the student's session (optional).
* **Student Email**: Enter the student's email address (optional).
* **Student Phone**: Enter the student's phone number.
* **Session Notes**: Enter any additional notes or comments about the session (optional).
* **Student Attendance**: Select all attendance status of the student (Present, Absent, Tardy).
* **Form Submitter**: Select who submitted the form (Tutors, Administrators, Students).
* **Form Modified**: Record the date and time the form was last modified (optional).
* **Form Submitter**: Select who submitted the form (Tutors, Administrators, Students).
* **Form Submitted By**: Select the device used to submit the form (Desktop, Mobile, Tablet).
* **Form IP Address**: Enter the IP address of the device used to submit the form (optional).
* **Form User Agent**: Enter the user agent of the device used to submit the form (optional).
* **Form Session ID**: Enter the ID of the session (optional).
* **Session Status**: Enter the status of the session (optional).
* **Session Duration**: Enter the duration of the session (optional).
* **Form Version**: Record the version of the form (optional).
* **Form Modified**: Record the date and time the form was last modified (optional).
