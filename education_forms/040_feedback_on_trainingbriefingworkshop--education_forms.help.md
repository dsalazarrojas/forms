# Feedback On TrainingBriefingWorkshop - Help Guide
## Purpose
This form is designed to collect feedback from users after attending a training briefing workshop.

## How To Complete This Form
To complete this form, simply go through each page and fill out the required information.

## Field-by-Field Explanation
- **Feedback on Training Briefing Workshop** (`feedback_on_training_briefing_workshop`, note, required/optional): Please provide your overall feedback on the training briefing workshop you attended.
  - If you don't have any feedback, you can leave this section blank.
- **Assigned Tool** (`assigned_tool`, select_one, required/optional): Please select whether the assigned tool was useful to you.
  - Select "Yes" if the tool was useful, and "No" if it was not.
- **Assigned Tool** (`assigned_tool`, select_multiple, required/optional): Please select all the tools that were assigned to you during the workshop.
  - Select each tool that was assigned to you, even if you didn't use it.
  - Select "No" for any tool that was not assigned to you.

## Tips
- Make sure to be as specific as possible when providing feedback on the training briefing workshop.
- Select all tools that were assigned to you, even if you didn't use them.
- This form is intended to be quick and easy to fill out, so please take a few minutes to complete it.
