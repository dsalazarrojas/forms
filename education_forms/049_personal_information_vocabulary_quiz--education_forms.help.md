# Personal Information Vocabulary Quiz - Help Guide
## Purpose
The Personal Information Vocabulary Quiz form is designed to gather various types of data from users, including general knowledge, personal details, contact information, and other personal information. The form is intended to be a starting point for users to learn new vocabulary or as a foundation for further analysis.

## How To Complete This Form

To complete this form, follow these steps:

1. Review each page of the form carefully to ensure you answer all the required questions.
2. Start with the first page, "General Knowledge 1", and answer any questions presented there.
3. Continue to each subsequent page, answering questions and providing any requested information.
4. Make sure to answer all questions truthfully and accurately.
5. Double-check your answers before submitting the form.

## Field-by-Field Explanation

### General Knowledge 1 
* **General Knowledge 1** (`General Knowledge 1`, `text`, optional): This section is intended to gather general information about the user's knowledge and experiences. Please provide a brief answer to this question.

### Personal Details 1 
* **Personal Details 1** (`Personal Details 1`, `number`, optional): This field is intended to gather numerical information about the user's personal details. Please enter a number that best represents your response.

### Contact Info 1 
* **Contact Info 1** (`Contact Info 1`, `text`, optional): This field is intended to gather contact information from the user. Please provide the requested contact information.

### Personal Info 2 
* **Personal Info 2** (`Personal Info 2`, `select_one`, optional): This field is a multiple choice question where you need to select one option from the available choices.

### Contact Number 1 
* **Contact Number 1** (`Contact Number 1`, `text`, optional): This field is intended to gather contact number information from the user. Please provide the requested contact number.

### Email 1 
* **Email 1** (`Email 1`, `email`, optional): This field is intended to gather email information from the user. Please provide a valid email address.

### Personal Info 3 
* **Personal Info 3** (`Personal Info 3`, `select_multiple`, optional): This field is a multiple choice question where you need to select multiple options from the available choices.

### General Knowledge 2 
* **General Knowledge 2** (`General Knowledge 2`, `text`, optional): This section is intended to gather more general information about the user's knowledge and experiences. Please provide a brief answer to this question.

## Tips
- Make sure to answer all questions truthfully and accurately.
- Double-check your answers before submitting the form.
- If you have any doubts or concerns, please contact the administrator for assistance.
