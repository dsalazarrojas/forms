# Sentence Type Identification Quiz - Help Guide
## Purpose
The Sentence Type Identification Quiz is a form used to collect user feedback and data for the "Sentence Type Identification" task. The form asks users to identify the type of sentence they are presented with and provide examples to illustrate each type.

## How To Complete This Form
1. Select the type of sentence from the options provided for each example sentence.
2. Provide a brief description of each example sentence.
3. Enter your name and other metadata as prompted.

## Field-by-Field Explanation
* **type_of_sentence** (`declarative`, `interrogative`, `imperative`, `exclamatory`): Select the type of sentence from the options provided. Declarative sentences state a fact or opinion, interrogative sentences ask a question, imperative sentences give a command or instruction, and exclamatory sentences express strong emotion.
* **example_sentence1**, **example_sentence2**, ..., **example_sentence10** (text): Provide a brief description of each example sentence to illustrate the selected type.
* **answer** (`number`): Enter the number of correct answers selected.
* **score** (`number`): Enter the score (not clear what this field is for).
* **category** (`Education`, `Other`): Select the category of the form.
* **description** (`text`): Enter a brief description of why you selected the form (not clear what this field is for).
* **submitted_by** (`text`): Enter your name.
* **submitted_at** (`date`): Enter the date and time you submitted the form.
* **submitted_by_user** (`User 1`, `User 2`, `User 3`): Select the user who completed the form.
* **form_completed_at** (`date`): Enter the date and time the form was completed.
* **form_completed_by** (`User 1`, `User 2`, `User 3`): Select the user who completed the form.
* **tool_used** (`Tool 1`, `Tool 2`, `Tool 3`): Select the tool used to complete the form.
* **notes** (`text`): Enter any additional comments or notes.
* **completed** (`True`, `False`): Enter whether the form was completed.
* **status** (`Complete`, `Incomplete`): Select the status of the form.
* **notes_2** (`text`): Enter any additional comments or notes (not clear what this field is for).
