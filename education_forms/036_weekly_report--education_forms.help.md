# Weekly Report - Help Guide

## Purpose
The Weekly Report form is designed to collect student's progress and activities from one week. It captures information about the session topic, activities completed, activities planned, goals achieved, goals in progress, and any notes the student wants to share.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in your Student Id to identify yourself.
2. Provide the Session Topic for the current week.
3. Describe the Session Notes for the current week.
4. List the Activities Completed during the week.
5. List the Activities Planned for the next week.
6. Share the Goals Achieved and Goals In Progress for the current week.
7. Add any Notes that you want to share with the report.

## Field-by-Field Explanation
* **Student Id**: (`weekly_report_student_id`, text, optional): Enter your student ID.
* **Session Topic**: (`weekly_report_session_topic`, text, optional): Describe the topic of the current session.
* **Session Notes**: (`weekly_report_session_notes`, text, optional): Provide notes about the current session.
* **Activities Completed**: (`weekly_report_activities_completed`, text, optional): List the activities completed during the week.
* **Activities Planned**: (`weekly_report_activities_planned`, text, optional): List the activities planned for the next week.
* **Goals Achieved**: (`weekly_report_goals_achieved`, text, optional): List the goals achieved during the week.
* **Goals In Progress**: (`weekly_report_goals_in_progress`, text, optional): List the goals that you are currently making progress on.
* **Notes**: (`weekly_report_notes`, text, optional): Share any additional notes for the report.

## Tips
- Be sure to fill in all the required fields for accurate reporting.
- Use the provided fields to ensure a comprehensive report.
- If you're unsure about any field, refer back to this help guide or contact support for clarification.
