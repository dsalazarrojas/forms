# Remote Learning Request Form - Help Guide
## Purpose
The "Remote Learning Request Form" is a tool for parents or guardians to submit a request for learning experiences or resources for their student. This form is used to gather information to assess the suitability of a remote learning arrangement for the student.

## How To Complete This Form
To complete this form, please follow these steps:

1. **Submit a Request**: Start by filling out the form completely, providing as much detail as possible.
2. Review and Edit: Review your submission for accuracy before submitting it to your school or institution.

## Field-by-Field Explanation

* **Parent Requesting Learning**:
	+ Label: Parent Requesting Learning
	+ Type: Text Field
	+ Purpose: Use this field to enter your name as the parent or guardian making the request.
* **Grade Level**:
	+ Label: Grade Level
	+ Type: Number Field
	+ Purpose: Indicate the current grade level of the student.
* **Student Name**:
	+ Label: Student Name
	+ Type: Text Field
	+ Purpose: Enter the name of the student who will be accessing the remote learning experience.
