# Student Guest Bringing Request Form - Help Guide
## Purpose
The purpose of this form is to allow students to request permission to bring guests to events hosted by their schools.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill out the form with the required information.
2. Select the correct school from the list provided.
3. Enter the date of the event.
4. Enter the student's name and email address.
5. Enter any contact information for the school.
6. Select the type of event and provide any special requests.
7. Enter the number of guests the student wants to bring.
8. Select the approvers for the request.
9. Select the status of the request (Pending, Approved, or Rejected).
10. Enter any comments for the event organizers.
11. Click the "Submit" button to submit the form.

## Field-by-Field Explanation
- **Student Guest Bringing Request** (`student_guest_bringing_form`): This is the main title of the form.
- **School** (`school_id`): Select the school that is hosting the event.
- **Date Of Event** (`date_of_event`): Enter the date of the event.
- **Student Name** (`student_name`): Enter the name of the student making the request.
- **Student Email** (`student_email`): Enter the email address of the student.
- **Contact Info** (`contact_info`): Enter any additional contact information for the school.
- **Event Type** (`event_type`): Select the type of event.
- **Event Details** (`event_details`): Enter any additional details about the event.
- **Number Of Guests** (`number_of_guests`): Enter the number of guests the student wants to bring.
- **Special Requests** (`special_requests`): Enter any special requests the student has.
- **Approved By** (`approved_by`): Select the approvers for the request.
- **Approved Date** (`approved_date`): Enter the date the request was approved.
- **Status** (`status`): Select the current status of the request (Pending, Approved, or Rejected).
- **Comments** (`comments`): Enter any comments for the event organizers.
- **Submit** (`submit`): Click the "Submit" button to submit the form.
- **School Name** (`school_name`): Enter the name of the school hosting the event.
- **School Address** (`school_address`): Enter the address of the school.
- **School Contact** (`school_contact`): Enter any contact information for the school.
- **School Phone** (`school_phone`): Enter the phone number of the school.
- **School Email** (`school_email`): Enter the email address of the school.
- **School Fax** (`school_fax`): Enter the fax number of the school.
- **School Website** (`school_website`): Enter the website of the school.
- **School Logo** (`school_logo`): Enter the logo of the school.
- **Event Start Time** (`event_start_time`): Enter the start time of the event.
- **Event End Time** (`event_end_time`): Enter the end time of the event.
