# Documentation Team Social Media Reporter Application - Help Guide
## Purpose
This form is used to gather information from the documentation team about their social media reporting activities.

## How To Complete This Form
To complete this form, follow the steps below:

1. Select the relevant page and field you wish to complete.
2. If a field is required, please fill it out according to the instructions.
3. If a field has options, select the relevant option from the dropdown list.
4. If a field requires a date/time input, enter the correct date and time according to the format specified.
5. If a field requires a text input, type in the relevant information according to the instructions.

## Field-by-Field Explanation
- **Social Media Behaviors** (`documentation_team_social_media_reporter_application_page_1`, text, optional): This field is where you can describe your social media behaviors, such as which platforms you use and how often you use them.
- **Team Members Reporting** (`documentation_team_social_media_reporter_application_page_2`, select multiple, optional): Select all the team members who have reported on social media.
- **Reporting Frequency** (`documentation_team_social_media_reporter_application_page_3`, date, optional): Please enter the date and time you last reported on social media. Use the format `YYYY-MM-DD` for dates and `HH:MM:SS` for times.
- **Reporting Start Time** (`documentation_team_social_media_reporter_application_page_4`, time, optional): Please enter the start time of your last reporting session.
- **Reporting End Time** (`documentation_team_social_media_reporter_application_page_5`, time, optional): Please enter the end time of your last reporting session.
- **Reported By** (`documentation_team_social_media_reporter_application_page_6`, select one, required): Please select who reported this information from the following options: chatjimmy, johndoe, janesmith.
- **Reporting Comments** (`documentation_team_social_media_reporter_application_page_7`, text, optional): This field is for any additional comments or feedback on your reporting session.
- **Reported** (`documentation_team_social_media_reporter_application_page_8`, text, optional): If you have reported on a specific platform or channel, please enter the platform or channel name here.
- **Reporting Channel** (`documentation_team_social_media_reporter_application_page_9`, select one, optional): Please select which social media platform you reported on from the following options: facebook, twitter, instagram, other.
- **Reporting Platform** (`documentation_team_social_media_reporter_application_page_10`, select one, optional): Please select which platform you reported on from the following options: website, blog, newsletter, other.
- **Reporting Link** (`documentation_team_social_media_reporter_application_page_11`, select one, optional): Please select which type of link you reported on from the following options: url, link, reference.
- **Reporting Platform URL** (`documentation_team_social_media_reporter_application_page_12`, text, optional): If you selected a link type, please enter the URL here.
- **Reporting Notes** (`documentation_team_social_media_reporter_application_page_13`, text, optional): This field is for any additional notes or feedback on your reporting session.
