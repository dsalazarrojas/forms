# Homeschool Support Program Admission Form - Help Guide
## Purpose
The Homeschool Support Program Admission Form is designed to collect information from interested students who wish to enroll in the Homeschool Support Program. This form will help us understand your homeschool needs and preferences.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill in the required fields with the requested information.
2. Make sure to provide as much detail as possible in each field.
3. Select the options that best apply to your situation.
4. Once you've filled out all the fields, click the 'Submit' button to send us your application.

## Field-by-Field Explanation

* **First Name**: Your name is the first part of your identity that we need to know.
	+ Please enter your first name in this field.
* **Last Name**: Your last name is the second part of your identity that we need to know.
	+ Please enter your last name in this field.
* **Email**: This is your email address that we can use to contact you.
	+ Please enter a valid email address in this format: `example@domain.com`.
* **Program Start Date**: This is the date when you plan to start the program.
	+ Choose a date from the calendar in the format `MM/DD/YYYY`.
* **Program Type**: Choose the type of program you are interested in.
	+ Select one of the following options:
		- Homeschool
		- Virtual
		- Hybrid
* **Student Grade Level**: Choose the grade level of the student.
	+ Select one of the following options:
		- Preschool
		- Elementary
		- Middle School
		- High School
* **Student Ages**: Choose the age range of the student.
	+ Select one or more of the following options:
		- 5-10
		- 11-14
		- 15-18
* **Educational Goals**: Describe your educational goals for the student.
	+ Please enter a brief description of your goals.
* **Educational Background**: Describe the student's educational background.
	+ Please enter a brief description of the student's background.
* **Parental Involvement**: Choose the level of involvement of the parents or guardians.
	+ Select one of the following options:
		- Low
		- Moderate
		- High
* **Special Needs**: Check if the student has any special needs.
	+ Select one or more of the following options:
		- Yes
		- No
* **Contact Name**: If you are not the student, please enter the name of the contact person.
	+ Please enter the name of the contact person.
* **Contact Email**: If you are not the student, please enter the email of the contact person.
	+ Please enter a valid email address in this format: `example@domain.com`.
* **Contact Phone**: If you are not the student, please enter the phone number of the contact person.
	+ Please enter a valid phone number in the format `XXX-XXX-XXXX`.
* **Contact Relationship**: Choose the relationship between the contact person and the student.
	+ Select one of the following options:
		- Parent
		- Guardian
		- Other
* **Additional Information**: Please provide any additional information that you feel is relevant to your application.
	+ Please enter a brief description of your application.
* **Program Start Time**: This is the time when you plan to start the program.
	+ Choose a time in the 24-hour clock format `HH:MM`.
* **Program End Time**: This is the time when you plan to end the program.
	+ Choose a time in the 24-hour clock format `HH:MM`.
* **Program Duration**: This is the number of weeks you plan to participate in the program.
	+ Please enter a whole number of weeks.
* **Program Frequency**: Choose how often you plan to participate in the program.
	+ Select one of the following options:
		- Weekly
		- Bi-Weekly
		- Monthly
* **Program Days**: Choose the days of the week you plan to participate in the program.
	+ Select one or more of the following options:
		- Monday
		- Tuesday
		- Wednesday
		- Thursday
		- Friday
* **Program Schedule**: Please provide a brief description of the program schedule.
	+ Please enter a brief description of your schedule.
* **Program Cost**: This is the expected program cost.
	+ Please enter a whole number or a price range in the format `X.X`.
* **Program Cost Details**: Please provide any additional details about the program cost.
	+ Please enter a brief description of your cost details.
* **Submit**: Click this button to send your application.
* **Cancel**: Click this button to cancel your application.

Tips:
* Make sure to double-check your input before submitting the application.
* If you have any doubts, please do not hesitate to contact us for help.
* We will review your application and get back to you as soon as possible.
