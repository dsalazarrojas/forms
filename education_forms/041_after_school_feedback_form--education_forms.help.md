# After School Feedback Form - Help Guide

## Purpose
The purpose of this form is to gather feedback from parents, guardians, and other stakeholders about their experience with the after-school program. This feedback is used to continuously improve the program and better serve its participants.

## How To Complete This Form

1. Please fill out the form completely and honestly.
2. For each field, select the best answer that applies to your experience.
3. Be as specific as possible when providing your feedback.

## Field-by-Field Explanation

* **Respondent Information**: This section is for you to provide some basic information about yourself.
	+ **Name (optional)**: Enter your name if you wish to remain anonymous or if you are a parent/guardian.
* **Your Role**: Select the best answer that describes your relationship to the after-school program (Parent/Guardian, Student, Teacher, Program Staff, Administrator, or Other).
* **Student Name**: Enter the name of the student who participated in the program.
* **Student Grade Level**: Select the current grade level of the student.
* **Program Name**: Select the name of the after-school program.
* **Program Duration**: Choose how long the student has been participating in the program.
* **Program Schedule**: Select the days the program takes place.
* **Overall Satisfaction**: Rate your overall satisfaction with the program (1-5 scale).
* **Program Organization**: Rate the program's organization (1-5 scale).
* **Staff Quality**: Rate the quality of the program staff (1-5 scale).
* **Curriculum Relevance**: Rate how relevant the program curriculum is to the student's interests (1-5 scale).
* **Skill Development**: Rate how well the program develops the student's skills (1-5 scale).
* **Safety Measures**: Rate the safety measures in place (1-5 scale).
* **Facility Condition**: Rate the condition of the facilities (1-5 scale).
* **Supervision Quality**: Rate the quality of supervision (1-5 scale).
* **Communication Frequency**: Select how often the program communicates with parents/guardians.
* **Communication Clarity**: Rate how clear the communications from the program are (1-5 scale).
* **Information Updates**: Rate whether you are kept informed about program updates and events (1-5 scale).
* **Student Enjoyment**: Rate how much the student enjoys participating in the program (1-5 scale).
* **Student Participation**: Rate how actively the student participates in the program (1-5 scale).
* **Student Behavior Improvement**: Rate whether the student's behavior has improved since joining the program (1-5 scale).
* **Academic Performance**: Rate whether the program has positively impacted the student's academic performance (1-5 scale).
* **Program Strengths**: Provide any strengths you think the program has.
* **Areas for Improvement**: Provide any areas the program could be improved.
* **Additional Comments**: Add any additional comments or feedback you may have.
* **Recommendation Likelihood**: Rate how likely you are to recommend this program to other families (1-5 scale).
