# Student Behavior Tracking Form - Help Guide
## Purpose
The Student Behavior Tracking Form is used by teachers to document and track student behavior during observations, assessments, or other educational activities. This form helps teachers to understand individual students' progress, performance, and areas of improvement.

## How To Complete This Form
1.  Fill out the form for each student observed, providing accurate and detailed information about their behavior.
2.  Make sure to select the correct options for each field based on your observations.
3.  Enter any additional notes or comments as necessary.

## Field-by-Field Explanation

* **Student Name** (`student_name`, Text, Optional): Enter the student's name as recorded in the school's records or as you know it.
* **Student ID** (`student_id`, Number, Optional): Enter the student's ID as recorded in the school's records or as you know it.
* **Behavior Date** (`behavior_date`, Date, Optional): Enter the date of the observation or activity.
* **Observation** (`observation`, Text, Optional): Describe the student's behavior during the observation or activity.
* **Student Location** (`student_location`, Text, Optional): Note the student's location during the observed period.
* **Time Observed** (`time_observed`, Time, Optional): Note the time of the observation or activity.
* **Category of Behavior** (`category_behavior`, Select Multiple, Required): Select all categories of behavior that were observed. Examples include Option 1, Option 2, and Option 3.
* **Notes** (`notes`, Note, Optional): Enter any additional notes or comments about the observation or activity.
* **Student Behavior Score** (`student_behavior_score`, Number, Optional): Enter a score for the student's behavior, if applicable.
* **Teacher Name** (`teacher_name`, Text, Optional): Enter your name as the teacher conducting the observation.
* **Teacher ID** (`teacher_id`, Text, Optional): Enter your ID as the teacher conducting the observation.
* **Email** (`email`, Email, Optional): Enter your email address, if you want to be contacted about the form.
* **Phone** (`phone`, Text, Optional): Enter your phone number, if you want to be contacted about the form.
* **Student Attendance** (`student_attendance`, Select One, Required): Check if the student was in attendance during the observed period.
* **Student Participation** (`student_participation`, Select One, Required): Check if the student was participating in class during the observed period.
* **Student Progress** (`student_progress`, Select Multiple, Required): Select all categories of student progress. Examples include On track, Not on track, and Unknown.
* **Student Demeanor** (`student_demeanor`, Select Multiple, Optional): Select all categories of student demeanor. Examples include Cooperative, Uncooperative, and Neutral.
* **Student Focus** (`student_focus`, Select Multiple, Optional): Select all categories of student focus. Examples include On task, Off task, and Focused on other students.
* **Student Involvement** (`student_involvement`, Select Multiple, Optional): Select all categories of student involvement. Examples include High, Medium, and Low.
* **Student Disengagement** (`student_disengagement`, Select Multiple, Optional): Select all categories of student disengagement. Examples include High, Medium, and Low.
* **Student Emotional State** (`student_emotional_state`, Select Multiple, Optional): Select all categories of student emotional state. Examples include Happy, Sad, and Neutral.
* **Student Body Language** (`student_body_language`, Select Multiple, Optional): Select all categories of student body language. Examples include Open, Closed, and Uncertain.
* **Teacher Support** (`teacher_support`, Select Multiple, Optional): Select all categories of teacher support. Examples include High, Medium, and Low.
* **Classroom Environment** (`classroom_environment`, Select Multiple, Optional): Select all categories of classroom environment. Examples include Cooperative, Competitive, and Uncertain.
* **Additional Notes** (`notes`, Note, Optional): Enter any additional notes or comments about the observation or activity.

## Tips

* Make sure to select the correct options for each field based on your observations.
* Enter accurate and detailed information to help teachers understand student behavior.
* Keep in mind that this form is part of a larger educational framework, and its completion and analysis would be part of a comprehensive student evaluation and development plan.
