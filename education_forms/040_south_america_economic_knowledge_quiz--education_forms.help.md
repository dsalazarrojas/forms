# South America Economic Knowledge Quiz - Help Guide
## Purpose
The South America Economic Knowledge Quiz is designed to assess the knowledge of users about the economy of South America, specifically in terms of country and economic indicators.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the correct country from the options for each question.
2. Choose the correct economic indicator from the options provided.
3. For questions with multiple-choice answers, select the correct option.

## Field-by-Field Explanation
* **South America Economy Questions**: This section presents questions about the economy of each country in South America. Select the correct answer for each question.
* **South America Country**: Select the correct country from the options provided.
* **Economic Indicator**: This field presents options for economic indicators such as GDP, Inflation, Unemployment, GDP Growth, and Population. Choose the correct indicator that best matches each question.
* **Question One, Question Two, Question Three, Question Four**: Each of these fields presents a question about the economy of South America. Type your answer in the text field.
* **Answer One, Answer Two, Answer Three, Answer Four**: Select the correct answer for each question.

## Tips
* Please ensure that you are familiar with the basics of South American economy before completing this form.
* Review each question carefully and choose the correct answer to each question.
* If you are unsure about a question, you can leave it blank or select "I don't know" as an option.
