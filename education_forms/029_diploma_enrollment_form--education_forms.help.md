# <string> - Help Guide
## Purpose
This form is used to gather information for diploma enrollment. Please complete this form if you have been assigned a tool to use for your diploma program.

## How To Complete This Form
1. Select the relevant option in the "education category" field.
2. Fill in the brief description of your diploma program in the "description" field.
3. If applicable, provide the name of the tool assigned to you for this program in the "assigned tool" field.
4. If you have been assigned a tool, provide the URL for access in the "assigned tool url" field.
5. Finally, click the "Submit" button to complete the form.

## Field-by-Field Explanation
* **education_category** (`education_category`, select_one, required/optional): Select the category that best describes your diploma program.
* **description** (`description`, text, required/optional): Briefly describe your diploma program.
* **assigned_tool** (`assigned_tool`, text, required/optional): If you have been assigned a tool for this program, enter the name of the tool.
* **assigned_tool_url** (`assigned_tool_url`, text, required/optional): If you have been assigned a tool, enter the URL for access.
