# Student Records Update Form - Help Guide
## Purpose
The Student Records Update Form is a tool used to update student information in the Student Records system. This form helps to ensure that student data is accurate and up-to-date, preventing duplication of records and maintaining consistency across the system.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the Student ID of the student whose record you want to update.
2. Fill in the first name and last name fields with the student's correct information.
3. Enter the student's email address.
4. Enter the student's phone number.
5. Choose the student's grade level(s) from the provided options.
6. Select the student's school status.
7. Choose the student's record status.
8. Select the user who updated the student record.
9. (Optional) Select multiple grade levels if the student is enrolled in more than one.

## Field-by-Field Explanation

* **Student ID (1)**: Enter the Student ID of the student whose record you want to update.
* **First Name (2)**: Fill in the first name of the student.
* **Last Name (3)**: Fill in the last name of the student.
* **Email (4)**: Enter the student's email address.
* **Phone (5)**: Enter the student's phone number.
* **Grade Level (6)**: Choose the student's grade level from the options provided.
* **Grade Levels (7)**: (Optional) Select multiple grade levels if the student is enrolled in more than one.
* **School (8)**: Choose the student's school status.
* **Student Record Status (9)**: Choose the student's record status.
* **Updated By (10)**: Select the user who updated the student record.
* **Grade Levels (11)**: (Optional) Select multiple grade levels if the student is enrolled in more than one.

## Tips

* Make sure to enter the correct Student ID to update the correct record.
* Use the provided options to select the correct grade levels and school status.
* If the student is enrolled in more than one grade level, select all applicable levels.
* Use this form to update existing student records, do not use it to create new records.
