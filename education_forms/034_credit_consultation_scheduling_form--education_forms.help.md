# credit_consultation_scheduling_form - Help Guide
## Purpose
This form is used to schedule a credit consultation with a customer. It collects relevant information about the customer, consultation schedule, and other necessary details for a successful consultation.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the customer's name in the "customer_name" field.
2. Select the type of credit from the "credit_type" dropdown menu (e.g., Cash, Credit Card, Loan).
3. Choose a date and time for the consultation using the "schedule_date" and "schedule_time" fields.
4. Enter the consultant's name in the "consultant_name" field.
5. Provide the customer's contact number in the "contact_number" field.
6. Add any additional notes about the consultation in the "note" field.
7. Enter the customer's email address in the "email" field.
8. Enter the customer's address in the "customer_address" field.
9. Select the location for the consultation in the "schedule_location" field.
10. Choose the assigned user for the consultation in the "assigned_user" field.
11. Select the tool to be used for the consultation in the "assigned_tool" field.
12. Enter the start time and end time of the consultation in the "schedule_date_time" and "schedule_end_time" fields.
13. Set the duration of the consultation in the "schedule_duration" field.
14. Enter the customer's ID in the "customer_id" field.
15. Set the status of the consultation to "Scheduled", "Completed", or "Cancelled" using the "credit_consultation_status" field.
16. Enter the start time of the consultation in the "schedule_start_time" field.
17. Enter any additional message for the customer in the "customer_message" field.
18. Enter the end time of the consultation in the "schedule_end_time" field.
19. Enter the ID of the credit consultation in the "credit_consultation_id" field.
20. Set the date of the credit consultation in the "credit_consultation_date" field.

## Field-by-Field Explanation

* **customer_name** (Text, Required): Enter the customer's name.
* **credit_type** (Select One, Required): Choose the type of credit (e.g., Cash, Credit Card, Loan).
* **schedule_date** (Date, Required): Choose a date for the consultation.
* **schedule_time** (Time, Required): Choose a time for the consultation.
* **consultant_name** (Text, Required): Enter the consultant's name.
* **contact_number** (Text, Required): Enter the customer's contact number.
* **note** (Note, Required): Add any additional notes about the consultation.
* **email** (Email, Required): Enter the customer's email address.
* **customer_address** (Text, Required): Enter the customer's address.
* **schedule_location** (Text, Required): Select the location for the consultation.
* **assigned_user** (Text, Required): Choose the assigned user for the consultation.
* **assigned_tool** (Text, Required): Select the tool to be used for the consultation.
* **schedule_date_time** (Date, Required): Choose a date and time for the consultation.
* **customer_id** (Text, Required): Enter the customer's ID.
* **credit_consultation_status** (Select One, Required): Set the status of the consultation to "Scheduled", "Completed", or "Cancelled".
* **schedule_start_time** (Time, Required): Enter the start time of the consultation.
* **customer_message** (Text, Required): Enter any additional message for the customer.
* **schedule_end_time** (Time, Required): Enter the end time of the consultation.
* **schedule_duration** (Number, Required): Set the duration of the consultation.
* **credit_consultation_id** (Text, Required): Enter the ID of the credit consultation.
* **credit_consultation_date** (Date, Required): Set the date of the credit consultation.

Note: All fields marked as "Required" must be filled in.
