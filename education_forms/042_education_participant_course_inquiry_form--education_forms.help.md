# Education Participant Course Inquiry Form - Help Guide
## Purpose
This form is designed to gather information from individuals interested in participating in educational courses.

## How To Complete This Form
- To complete this form, please fill out all the required fields. If a field is not required, you can leave it blank.
- Make sure to fill out the form accurately and completely to ensure that your inquiry is processed efficiently.
- If you are a foreign language learner, please select your preferred language from the options provided in the "Preferred Language" field.

## Field-by-Field Explanation
- **What is your course of interest**: This field is where you should type in the name of the course you are inquiring about. Please be specific and provide as much detail as possible.
  * **Name**: This field is where you should type in your full name.
  * **E-mail**: This field is where you should type in your email address.
  * **Contact Number**: This field is where you should type in your contact number.
  * **Preferred Language**: This field is where you should select your preferred language from the options provided.
  * **Course Type**: This field is where you should select the type of course you are interested in (e.g. Bachelor Degree, Master Degree, Doctorate Degree).
  * **Course Level**: This field is where you should select the level of the course you are interested in (e.g. Basic, Intermediate, Advanced).
  * **Preferred Format**: This field is where you should select the preferred format of the course (e.g. Online, In-person, Hybrid).
  * **Start Date**: This field is where you should type in the start date of the course.
  * **End Date**: This field is where you should type in the end date of the course.
  * **Start Time**: This field is where you should type in the start time of the course.
  * **End Time**: This field is where you should type in the end time of the course.
  * **Duration**: This field is where you should type in the duration of the course.
  * **Location**: This field is where you should type in the location of the course.
  * **Instructor Name**: This field is where you should type in the name of the instructor.
