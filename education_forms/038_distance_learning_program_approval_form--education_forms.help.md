# Distance Learning Program Approval Form - Help Guide
## Purpose

The Distance Learning Program Approval Form is used to request approval for a distance learning program offered by an institution. This form helps the institution provide necessary information about the program to the approving authority, who will review and decide on the program's approval status.

## How To Complete This Form

To complete this form, follow these steps:

1. Enter the name of the program you are requesting approval for in the "Program name" field.
2. Provide the address of the institution offering the program in the "Institution address" field.
3. Enter the phone number of the institution in the "Institution phone" field.
4. In the "Program description" field, provide a brief description of your program to help approvers understand its scope and content.
5. Choose the start date of the program in the "Start date" field.

## Field-by-Field Explanation

* **Program name** (`program_name`, text, required: false): Enter the name of the program you are requesting approval for.
* **Institution address** (`institution_address`, text, required: false): Enter the address of the institution offering the program.
* **Institution phone** (`institution_phone`, text, required: false): Enter the phone number of the institution offering the program.
* **Program description** (`program_description`, text, required: false): Provide a brief description of the program to help approvers understand its scope and content.
* **Start date** (`program_start_date`, date, required: false): Select the start date of the program.

## Tips

* Make sure to provide accurate and complete information for all fields to ensure a smooth approval process.
* If you have any questions or need assistance with filling out this form, contact the approving authority directly.
* This form is designed for one-time approval requests. If you need to make changes to an approved program, contact the approving authority for further instructions.
