# term_1_78_enrichment_registration - Help Guide
## Purpose
This form is used to register for the Term 1-78 Enrichment program. Please fill out the form accurately and completely to ensure that your application is processed correctly.

## How To Complete This Form
To complete this form, please follow these steps:

1. Begin by reviewing the pages of the form, which include:
	* Page 1: This page contains general information about the program, including the class name and location.
	* Each subsequent page will have additional fields to fill out.

## Field-by-Field Explanation
* **Class Name** (`class_name`, text, required): Please enter the name of the class or program you are registering for.
* **Class Number** (`class_number`, number, required): Please enter the class number or program ID.
* **Class Type** (`class_type`, select one, required): Please select the type of class or program you are registering for.
* **Student Name** (`student_name`, text, required): Please enter your name as it appears on your official documents.
* **Class Schedule** (`class_schedule`, date, required): Please enter the start and end dates of the class or program.
* **Class Start Date** (`class_start_date`, date, required): Please enter the start date of the class or program.
* **Class End Date** (`class_end_date`, date, required): Please enter the end date of the class or program.
* **Student Email** (`student_email`, email, required): Please enter your official email address.
* **Student Phone** (`student_phone`, text, required): Please enter your contact phone number.
* **Term 1-78 Enrichment Registration Page Comment** (`term_1_78_enrichment_registration_page_comment`, note, required): Please provide any additional comments about your registration.
* **Class Location** (`class_location`, text, required): Please enter the physical location of the class or program.
* **Class Time** (`class_time`, time, required): Please enter the time of the class or program.
* **Student Notes** (`student_notes`, text, required): Please enter any additional comments or notes about your registration.

## Tips
* Make sure to fill out all required fields accurately and completely.
* If you are unsure about any of the fields, please refer to the form pages or the program description for clarification.
* Please note that this form is designed to be completed by registered students. If you are not a registered student, you will not be able to submit this form.
* If you have any issues with the form or need assistance, please contact the program administrators for support.
