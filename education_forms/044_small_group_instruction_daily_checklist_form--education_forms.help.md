# Small Group Instruction Daily Checklist Form - Help Guide
## Purpose
The Small Group Instruction Daily Checklist Form is designed to gather information about daily activities or sessions, providing a structured way to track and evaluate progress.

## How To Complete This Form
1. **Fill out the form fields with the required information**:
	* **Small Group Instruction Activity Name**: Enter the name of the activity or session you are reporting on.
	* **Category**: Choose the category of the activity or session.
	* **Description**: Provide a brief description of the activity or session.
	* **Assigned Tool**: Mention the tool assigned to the group or session.
2. **Select the correct progress status**:
	* **Student Progress**: Indicate the progress of the student using the options provided (Option A or Option B).
3. **Add any additional comments or notes**:
	* **Output File**: If applicable, provide a file or attachment related to the activity or session.
	* **Additional Comments**: Enter any extra comments or observations about the session.
	* **Notes**: Enter any notes or reminders about the session (optional).
	* **Teacher Comments**: Enter any comments or feedback from the teacher (optional).
	* **Student Progress Notes**: Enter any notes or observations about student progress (optional).

## Field-by-Field Explanation
* **Small Group Instruction Activity Name** (`form_name`, text, required): Enter the name of the activity or session you are reporting on.
* **Category** (`category`, select_one, required): Choose the category of the activity or session from the provided options.
* **Description** (`description`, text, required): Provide a brief description of the activity or session.
* **Assigned Tool** (`assigned_tool`, text, required): Mention the tool assigned to the group or session.
* **Category Copy** (`category_copy`, select_one, required): Indicate if this activity or session is a copy of another category (Yes or No).
* **Student Progress** (`student_progress`, checkbox, required): Select the progress status of the student using the provided options (Option A or Option B).
* **Output File** (`output_file`, text, required): If applicable, provide a file or attachment related to the activity or session.
* **Additional Comments** (`additional_comments`, note, required): Enter any extra comments or observations about the session.
* **Notes** (`notes`, note, optional): Enter any notes or reminders about the session (not required).
* **Teacher Comments** (`teacher_comments`, note, optional): Enter any comments or feedback from the teacher (not required).
* **Student Progress Notes** (`student_progress_notes`, note, optional): Enter any notes or observations about student progress (not required).
