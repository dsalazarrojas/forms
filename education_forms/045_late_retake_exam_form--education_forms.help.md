# Late Retake Exam Form - Help Guide
## Purpose
This form is used to request a retake for a student in a class. It captures information needed to review and evaluate the request.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill in the required information for the class for which you are requesting a retake.
2. Select the valid reason for requesting the retake.
3. Enter any excusatory reasons for the retake.
4. Choose a date and time for the original exam.
5. Identify the teacher assigned to the class.
6. Enter the student's ID.
7. Provide any remarks or comments related to the request.
8. Finally, submit the form.

## Field-by-Field Explanation
- **Late Retake Exam Form for Class 1** (Late Retake Exam Form for Class 1, text, required/optional): Enter the class for which you are requesting a retake.
- **Class 1** (Class 1, select one, optional): Select the class you are requesting a retake for.
- **Class 2** (Class 2, select one, optional): Select the class you are taking instead of the originally assigned class.
- **Class 3** (Class 3, select one, optional): Select the class you are taking instead of the originally assigned class.
- **Reason for requesting retake** (Reason for requesting retake, text, optional): Enter a valid reason for requesting the retake.
- **Excuses** (Excuses, text, optional): Enter any excusatory reasons for the retake.
- **Date of Exam** (Date of Exam, date, optional): Enter the date of the original exam.
- **Time of Exam** (Time of Exam, time, optional): Enter the time of the original exam.
- **Assigned Teacher** (Assigned Teacher, text, optional): Enter the name of the teacher assigned to the class.
- **Student ID** (Student ID, text, optional): Enter the student's ID.
- **Remarks** (Remarks, text, optional): Enter any remarks or comments related to the request.
- **Submitted On** (Submitted On, date, optional): Enter the date and time you submitted the form.
- **Submitted By** (Submitted By, text, optional): Enter your name.
