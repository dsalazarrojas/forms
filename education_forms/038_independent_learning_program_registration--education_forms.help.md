# independent_learning_program_registration - Help Guide
## Purpose
The independent learning program registration form is used to collect data on self-directed learning initiatives. This form helps administrators track and manage participant engagement, program status, and other relevant details.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the Program Details section with relevant information about the program.
2. Provide details about the participant in the Participant Details section.
3. Select the program type and status from the respective dropdown menus.
4. If necessary, add participant notes for further context.

## Field-by-Field Explanation
- **Program Details** (`program_details`, text, required: false): Enter a brief description of the program, including its title, duration, and any other relevant details.
- **Participant Details** (`participant_details`, text, required: false): Enter the participant's name, email, and any other relevant contact information.
- **Program Type** (`program_type`, select_one, required: false): Select "Yes" if the program is an active, self-directed learning initiative, or "No" if it is not.
- **Program Status** (`program_status`, select_one, required: false): Select "Active" if the program is currently running, or "Inactive" if it has been completed or terminated.
- **Participant Program Status** (`participant_program_status`, select_one, required: false): Select "Active" if the participant is currently engaged in the program, or "Inactive" if they have completed or withdrawn.
- **Participant Notes** (`participant_notes`, note, required: false): Add any additional notes about the participant, such as their progress or concerns.
