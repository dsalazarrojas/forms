# Teacher Performance Evaluation Questionnaire - Help Guide
## Purpose
The Teacher Performance Evaluation Questionnaire is designed to assess a teacher's performance based on 12 key areas: teaching style, communication skills, lesson planning, student engagement, classroom management, subject matter expertise, feedback and concerns, overall evaluation, teacher performance, teacher recommendation, student feedback, and parental feedback.

## How To Complete This Form
To complete this form, please follow these steps:

* Review the 12 evaluation criteria and select the appropriate option for each criterion.
* Ensure that you answer all required questions, marked with an asterisk (\*).
* Use the "Select One" option for criteria that have only one answer, and "Select Multiple" for criteria that have multiple answers.
* You can provide additional comments or feedback in the "Feedback and Concerns" text field.

## Field-by-Field Explanation
* **Teaching Style (\*)**: Select one: Positive, Negative
This question assesses the teacher's teaching style, whether it is positive or negative.
* **Communication Skills (\*)**: Select Multiple: Effective, Ineffective
This question evaluates the teacher's communication skills with students, peers, and parents.
* **Lesson Planning (\*)**: Select One: True, False
This question examines the teacher's ability to create and implement effective lesson plans.
* **Student Engagement (\*)**: Select One: High, Low
This question measures the teacher's ability to engage students in the learning process.
* **Classroom Management (\*)**: Select One: Good, Poor
This question assesses the teacher's classroom management skills, such as maintaining order and discipline.
* **Subject Matter Expertise (\*)**: Select One: Strong, Weak
This question evaluates the teacher's knowledge and expertise in the subject matter they teach.
* **Feedback and Concerns**: Text field for any feedback or concerns about the teacher's performance.
* **Overall Evaluation (\*)**: Select One: High, Low
This question provides a general evaluation of the teacher's performance across all criteria.
* **Teacher Performance (\*)**: Select One: High, Low
This question assesses the teacher's overall performance based on the evaluation criteria.
* **Teacher Recommendation (\*)**: Select One: Strongly Agree, Somewhat Agree
This question determines whether the teacher is recommended for promotion or continued service.
* **Student Feedback (\*)**: Select One: Positive, Negative
This question gathers feedback from students about the teacher's performance.
* **Parental Feedback (\*)**: Select One: Positive, Negative
This question collects feedback from parents about the teacher's performance.
* **Staff Feedback (\*)**: Select One: Positive, Negative
This question gathers feedback from staff members about the teacher's performance.

Note: The fields marked with an asterisk (*) are required questions. Please ensure that you answer all required questions.
