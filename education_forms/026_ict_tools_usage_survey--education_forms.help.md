# ict_tools_usage_survey - Help Guide
## Purpose
This form is designed to collect information about the usage and satisfaction of ICT tools used in the educational sector.

## How To Complete This Form
To complete this form, please answer the questions honestly and thoroughly. Select the options that best fit your experience with the ICT tools mentioned. If you have used other ICT tools not listed, please describe them in the "Other ICT tools used" field.

## Field-by-Field Explanation
* **Ict Tools Usage Survey** (`form_header`, note, not required): This is the introductory section of the form.
* **ICT tool used** (`tool_used`, select_multiple, not required): Please select all the ICT tools you have used (e.g., "Yes" to indicate you have used a tool, and "No" otherwise).
* **How often do you use this ICT tool** (`tool_frequency`, select_one, not required): Select how frequently you use the ICT tool (e.g., "Never", "Rarely", "Sometimes", or "Often").
* **How important is this ICT tool for your work** (`tool_importance`, number, not required): Rate the importance of the ICT tool for your work, with higher numbers indicating higher importance.
* **How satisfied are you with this ICT tool** (`tool_satisfaction`, number, not required): Rate your satisfaction with the ICT tool, with higher numbers indicating higher satisfaction.
* **What would you like to improve in this ICT tool** (`tool_improvement`, text, not required): Provide suggestions or ideas for improvements to the ICT tool.
* **Other ICT tools used** (`other_tools`, text, not required): Describe any other ICT tools you use, not listed above.
* **Description of other ICT tools used** (`other_tools_description`, text, not required): Provide a brief description of the other ICT tools used.
* **Assigned ICT tool** (`assigned_tool`, select_one, not required): Select which ICT tool you were assigned to use (e.g., "Chat", "Google", "Microsoft", "Other", or "Default").
* **Form Footer** (`form_footer`, note, not required): This is the closing section of the form.
* **Comments** (`comments`, text, not required): Provide any additional comments or feedback about the ICT tools or the survey process.
