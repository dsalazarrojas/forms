# executive_program_project_submission - Help Guide
## Purpose
This form is used to collect project submission information from users, specifically for executive programs.

## How To Complete This Form
To complete this form, please follow these steps:

1. Enter the project title, which is a required field that should be a concise and descriptive title of the project.
2. Provide a brief description of the project, which is an optional field that can be left blank if not required.
3. Select the submission date, which is the date the project was submitted.
4. Choose the submission status, which can be either "Active" or "Inactive" depending on the project's current status.
5. Upload two files, "File 1" and "File 2", which are required fields that should be relevant to the project.

## Field-by-Field Explanation
* **Project Title** (`project_title`, text, required): Enter the project title, which should be a concise and descriptive title of the project.
* **Project Description** (`project_description`, text, optional): Provide a brief description of the project, if required.
* **Submission Date** (`submission_date`, date, required): Select the date the project was submitted.
* **Submission Status** (`submission_status`, select_one, required): Choose the submission status, which can be either "Active" or "Inactive" depending on the project's current status.
* **File 1** (`file1`, text, required): Upload a file relevant to the project.
* **File 2** (`file2`, text, required): Upload another file relevant to the project.

## Tips
* Make sure to enter accurate and up-to-date information to ensure correct tracking and management of the executive programs.
* If you are unsure about any field, please consult with the relevant executive team or project manager.
