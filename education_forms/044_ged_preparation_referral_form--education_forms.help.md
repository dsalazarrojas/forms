# GED Preparation Referral Form - Help Guide
## Purpose
This form is used to refer individuals or educational institutions to our GED preparation support team. It helps in assigning the right person to work with each case, ensuring that the support is provided in a timely and efficient manner.

## How To Complete This Form
1. Choose whether the referral is for an individual or an educational institution.
2. Select the type of program that the referral is for.
3. Enter the email address of the individual or institution.
4. Enter the phone number of the individual or institution.
5. Enter the date and time of the referral.
6. Select the tool assigned to work with the case.
7. Select the type of output file that will be used.
8. Enter the form ID and title.
9. Choose the category for the referral.
10. Enter the description of the referral.
11. Select the category for the form.
12. Select the user who will be assigned to work with the case.
13. Select the category for the tool.
14. Select the version of the tool.
15. Enter the name of the user who created the referral.
16. Enter the name of the user who updated the referral.
17. Enter the date and time the referral was created.
18. Enter the date and time the referral was updated.

## Field-by-Field Explanation

* **individual/educational_institution** (`individual`, `select_multiple`, required): Choose whether the referral is for an individual or an educational institution.
* **program_type** (`program_type`, `select_one`, required): Select the type of program that the referral is for.
* **email** (`email`, `email`, required): Enter the email address of the individual or institution.
* **phone** (`phone`, `text`, required): Enter the phone number of the individual or institution.
* **date** (`date`, `date`, required): Enter the date of the referral.
* **time** (`time`, `time`, required): Enter the time of the referral.
* **assigned_tool** (`assigned_tool`, `select_one`, required): Select the tool assigned to work with the case.
* **output_file** (`output_file`, `select_one`, required): Select the type of output file that will be used.
* **form_id** (`form_id`, `number`, required): Enter the form ID.
* **form_title** (`form_title`, `text`, required): Enter the title of the form.
* **category** (`category`, `select_one`, required): Choose the category for the referral.
* **description** (`description`, `text`, required): Enter the description of the referral.
* **form_category** (`form_category`, `select_one`, required): Choose the category for the form.
* **assigned_user** (`assigned_user`, `select_one`, required): Select the user who will be assigned to work with the case.
* **tool_name** (`tool_name`, `text`, required): Enter the name of the tool.
* **tool_category** (`tool_category`, `select_one`, required): Choose the category for the tool.
* **tool_version** (`tool_version`, `select_one`, required): Select the version of the tool.
* **created_by** (`created_by`, `text`, required): Enter the name of the user who created the referral.
* **updated_by** (`updated_by`, `text`, required): Enter the name of the user who updated the referral.
* **created_at** (`created_at`, `date`, required): Enter the date and time the referral was created.
* **updated_at** (`updated_at`, `date`, required): Enter the date and time the referral was updated.
* **created_by_user** (`created_by_user`, `select_one`, required): Select the user who created the referral.
* **updated_by_user** (`updated_by_user`, `select_one`, required): Select the user who updated the referral.
