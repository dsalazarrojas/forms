# openLearningResourceContributionRequestForm - Help Guide
## Purpose
The openLearningResourceContributionRequestForm is a form designed to collect information from submitters about their open learning resources. This form helps to categorize, license, and track the submission's status in the database.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the submission form with the required information, including the title, description, and submission date.
2. Select the category and license for the resource from the provided options.
3. Enter the URL of the resource and any additional tags or notes.
4. Select the submission status and review status.
5. Add any comments or license notes.
6. Fill in the submitter's email, name, affiliation, institution, and URL.
7. Provide a URL for the submitter's profile or website.
8. Add any additional submitter notes.

## Field-by-Field Explanation
### Submission
* **Submission** (`submission`, `text`, required): Enter a brief title for the resource being submitted.
* **Category** (`category`, `select_one`, required): Select the category for the resource from the options provided (Open Source or Other).
* **License** (`license`, `select_one`, required): Select the license for the resource from the options provided (CC0, CC-BY, CC-BY-SA, CC-BY-ND, or Other).
* **Resource URL** (`resource_url`, `text`, optional): Enter the URL of the resource being submitted.
* **Description** (`description`, `text`, required): Enter a brief description of the resource.
* **Tags** (`tags`, `text`, optional): Enter any additional tags for the resource (comma-separated).
* **Email** (`submitter_email`, `email`, optional): Enter the submitter's email address.
* **Name** (`submitter_name`, `text`, optional): Enter the submitter's name.
* **Affiliation** (`submitter_affiliation`, `text`, optional): Enter the submitter's affiliation.
* **Institution** (`submitter_institution`, `text`, optional): Enter the submitter's institution.
* **URL** (`submitter_url`, `text`, optional): Enter the submitter's URL or website.
* **Review status** (`review_status`, `select_one`, optional): Select the review status for the resource (Not reviewed, In progress, Reviewed, Approved, or Rejected).
* **Comments** (`comments`, `text`, optional): Enter any comments about the resource.
* **License notes** (`license_notes`, `text`, optional): Enter any additional license notes.
* **Submission date** (`submission_date`, `date`, optional): Enter the submission date of the resource.
* **Submission time** (`submission_time`, `time`, optional): Enter the submission time of the resource.
* **Notes** (`submitter_notes`, `text`, optional): Enter any additional submitter notes.
* **Submission URL** (`submission_url`, `text`, optional): Enter the URL of the submission.
* **License URL** (`license_url`, `text`, optional): Enter the URL of the license.
* **License version** (`license_version`, `text`, optional): Enter the version of the license.
* **Submission status** (`submission_status`, `select_one`, optional): Select the submission status (In progress, Approved, Rejected, or Archived).
* **Submission status notes** (`submission_status_notes`, `text`, optional): Enter any additional submission status notes.
* **Submitter URL** (`submitter_url`, `text`, optional): Enter the submitter's URL or website.
* **Submitter URL title** (`submitter_url_title`, `text`, optional): Enter the title of the submitter's URL.
* **Submitter URL description** (`submitter_url_description`, `text`, optional): Enter the description of the submitter's URL.

## Tips
* Make sure to double-check all the fields before submitting the form.
* If you are submitting a resource that is already in the database, do not fill out this form again.
* If you are unsure about any of the fields, feel free to ask for help.
