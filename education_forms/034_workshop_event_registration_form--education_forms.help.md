# Workshop Event Registration Form - Help Guide
## Purpose

The Workshop Event Registration Form is designed to collect relevant information about an event, including the event name, attendee details, dates, and other essential specifics.

## How To Complete This Form

1. Start by filling in the event name in the "event_name" field.
2. Select all the attendees for the event in the "attendee names" field.
3. Enter the email address in the "email" field.
4. Choose the correct dates for the event in the "date" and "event_finish" fields.
5. Fill in the workshop duration in the "workshop_duration" field.
6. Select the correct instructor name in the "instructor name" field (if applicable).
7. Confirm the event registration in the "registration confirmation" field.
8. Enter any workshop details in the "workshop details" field (if applicable).
9. Select the aim of the workshop in the "workshop aim" field (if applicable).
10. Fill in the registration fee in the "registration fee" field (if applicable).
11. Choose the payment method in the "payment method" field.
12. Select the event status in the "event status" field.
13. Select the workshop location in the "workshop location" field.
14. Choose the start and end dates of the event in the "event start" and "event finish" fields.
15. Enter the event duration in the "event duration" field.
16. Select the workshop organizer in the "workshop organizer" field (if applicable).
17. Select the workshop coordinators in the "workshop coordinators" field (if applicable).
18. Enter any notes about the event in the "event notes" field (if applicable).
19. Select the participants in the "workshop participants" field (if applicable).
20. Enter the expected attendance for the event in the "event attendance" field (if applicable).
21. Select the workshop evaluation method in the "workshop evaluation" field (if applicable).
22. Enter any additional comments in the "additional comments" field (if applicable).
23. Fill in the contact details in the "contact details" field (if applicable).

## Field-by-Field Explanation

* **Event Name (event_name)**: Enter the name of the workshop event.
* **Attendee Names (attendee names)**: Select all the attendees for the event.
* **Email (email)**: Enter the email address of the event organizer or point of contact.
* **Date (date)**: Choose the correct date of the event.
* **Time (time)**: Enter the correct time of the event.
* **Workshop Duration (workshop_duration)**: Enter the duration of the workshop in hours or minutes.
* **Instructor Name (instructor name)**: Select the name of the workshop instructor (if applicable).
* **Registration Confirmation (registration confirmation)**: Confirm that the event has been registered.
* **Workshop Details (workshop details)**: Enter any additional details about the workshop.
* **Workshop Aim (workshop aim)**: Select the aim of the workshop (if applicable).
* **Registration Fee (registration fee)**: Enter the fee for the workshop registration (if applicable).
* **Payment Method (payment method)**: Choose the payment method for the workshop.
* **Event Status (event status)**: Select the status of the event.
* **Workshop Location (workshop location)**: Select the location of the workshop.
* **Event Start (event start)**: Choose the start date of the event.
* **Event Finish (event finish)**: Choose the end date of the event.
* **Event Duration (event duration)**: Enter the duration of the event.
* **Workshop Organizer (workshop organizer)**: Select the workshop organizer (if applicable).
* **Workshop Coordinators (workshop coordinators)**: Select the workshop coordinators (if applicable).
* **Event Notes (event notes)**: Enter any notes about the event (if applicable).
* **Workshop Participants (workshop participants)**: Select the participants in the workshop (if applicable).
* **Event Attendance (event attendance)**: Enter the expected attendance for the event (if applicable).
* **Workshop Evaluation (workshop evaluation)**: Select the evaluation method for the workshop (if applicable).
* **Additional Comments (additional comments)**: Enter any additional comments (if applicable).
* **Contact Details (contact details)**: Enter any contact details (if applicable).
