# Medical Care Supplement Class Enrollment Form - Help Guide
## Purpose
This form is used to collect information from students enrolling in medical care supplement classes.

## How To Complete This Form
To complete this form, please provide the following details:

### Step 1: Fill out the required fields marked as "Required" and provide any optional information as needed.

### Step 2: Ensure you have completed all fields correctly and accurately before submitting the form.

## Field-by-Field Explanation

* **Student Status** (`Student Status`, select_one, required): Please select the correct status of the student (Student/Non-Student).
* **Student Name** (`Student Name`, text, required): Please enter the student's name.
* **Student Email** (`Student Email`, email, required): Please enter the student's email address.
* **Student ID** (`Student ID`, number, required): Please enter the student's ID number.
* **Contact Number** (`Contact Number`, text, required): Please enter the contact number of the student.
* **Enrollment Date** (`Enrollment Date`, date, required): Please select the date of enrollment.
* **School Name** (`School Name`, text, required): Please enter the name of the school.
* **Department** (`Department`, text, required): Please enter the department of the student.
* **Instructor ID** (`Instructor ID`, number, required): Please enter the ID of the instructor.
* **Course ID** (`Course ID`, number, required): Please enter the ID of the course.
* **Enrollment Fee** (`Enrollment Fee`, number, required): Please enter the fee for enrollment.
* **User Input** (`User Input`, text, optional): This field is not required for the student, but it's for additional user input.
* **Student Information** (`Student Information`, text, optional): This field is not required for the student, but it's for additional student information.
