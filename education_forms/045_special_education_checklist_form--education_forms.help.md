# special_education_checklist_form - Help Guide
## Purpose
The special education checklist form is used to gather information about a student's special education needs. This information will be used to provide the student with the necessary support and resources.

## How To Complete This Form
To complete this form, follow these steps:
1. Enter the student's name in the **student_name** field.
2. Enter the student's ID in the **student_id** field.
3. Enter the student's date of birth in the **date_of_birth** field using the YYYY-MM-DD format.
4. Select the student's educational background from the options listed under **educational_background**.
5. For the **accommodations_needed** field, select all the accommodations the student requires (e.g., Speech Therapy, Occupational Therapy, Physical Therapy).
6. For the **services_needed** field, select all the services the student requires (e.g., IEP, IEP-Modified). Note that this field is optional.
7. In the **notes** field, provide any additional information about the student's needs or circumstances.
8. If you have the student's email, enter it in the **email** field.
9. If you have the student's phone number, enter it in the **phone** field.

## Field-by-Field Explanation
* **student_name**: Enter the student's name as it appears on their identification.
* **student_id**: Enter the student's unique identification number.
* **date_of_birth**: Enter the student's date of birth in the YYYY-MM-DD format.
* **educational_background**: Select the student's educational background from the options:
	+ General Ed
	+ Special Ed
	+ Gifted Ed
* **accommodations_needed**: Select all the accommodations the student requires from the options:
	+ Speech Therapy
	+ Occupational Therapy
	+ Physical Therapy
* **services_needed**: Select all the services the student requires from the options:
	+ IEP
	+ IEP-Modified
* **notes**: Provide any additional information about the student's needs or circumstances.
* **email**: If applicable, enter the student's email address.
* **phone**: If applicable, enter the student's phone number.
