# <string> - Help Guide
## Purpose
The "<string>" form is used to gather information from parents and teachers for parent-teacher conferences. This form helps parents and teachers schedule and confirm conference appointments.

## How To Complete This Form
To complete this form, follow these steps:

1.  Fill in the required fields with the necessary information.
2.  Choose the preferred availability from the options provided.
3.  Select the conference type and duration.
4.  Confirm the conference details.

## Field-by-Field Explanation
- **Parent Name** (`parent_name`, text, required): Enter the name of the parent.
- **Parent Email** (`parent_email`, email, required): Enter the parent's email address.
- **Parent Phone** (`parent_phone`, text, required): Enter the parent's phone number.
- **Conference Date** (`conference_date`, date, required): Select the date of the parent-teacher conference.
- **Conference Time** (`conference_time`, time, required): Select the time of the parent-teacher conference.
- **Conference Note** (`conference_note`, text, required): Enter any additional notes or comments for the conference.
- **Teacher Name** (`teacher_name`, text, required): Enter the name of the teacher.
- **Teacher Email** (`teacher_email`, email, required): Enter the teacher's email address.
- **Teacher Phone** (`teacher_phone`, text, required): Enter the teacher's phone number.
- **Teacher Availability** (`teacher_availability`, select_one, required): Select the teacher's availability (morning, afternoon, or evening).
- **Parent Availability** (`parent_availability`, select_multiple, required): Select the parent's availability (morning, afternoon, or evening).
- **Conference Start Date** (`conference_start_date`, date, required): Select the start date of the parent-teacher conference.
- **Conference End Date** (`conference_end_date`, date, required): Select the end date of the parent-teacher conference.
- **Conference Duration** (`conference_duration`, number, required): Enter the duration of the parent-teacher conference.
- **Teacher Availability Multiple** (`teacher_availability_multiple`, select_multiple, required): Select the teacher's multiple availability (morning, afternoon, or evening).
- **Conference Type** (`conference_type`, select_one, required): Select the type of conference (meeting, discussion, or presentation).
- **Notes** (`notes`, text, required): Enter any additional notes or comments for the conference.
- **Confirmed** (`confirmed`, text, required): Confirm the conference details.
- **Canceled** (`canceled`, text, required): If the conference is canceled, enter the reason for cancellation.
- **Parent Availability Time** (`parent_availability_time`, select_multiple, required): Select the parent's availability time (morning, afternoon, or evening).
- **Conference Confirmed Time** (`conference_confirmed_time`, select_multiple, required): Select whether the conference is confirmed or not.
- **Teacher Confirmed** (`teacher_confirmed`, text, required): Confirm whether the teacher is available or not.
- **Parent Confirmed** (`parent_confirmed`, text, required): Confirm whether the parent is available or not.
- **Canceled Conference** (`canceled_conference`, text, required): If the conference is canceled, enter the reason for cancellation.

The form will guide you through the process of scheduling and confirming parent-teacher conferences.
