# Breeding Management Knowledge Quiz - Help Guide
## Purpose
This form is designed to assess your knowledge in breeding management. It consists of 12 questions that cover various aspects of breeding, including genetic diversity, pedigree analysis, and record keeping.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill in your participant name and email address in the first two fields.
2. Select your breeding experience level.
3. Answer the 12 multiple-choice questions, selecting the correct answer for each one.
4. If you want to, select additional areas you would like to learn more about in the breeding management field.
5. Provide any additional comments or feedback in the final field.

## Field-by-Field Explanation
* **Participant Name**: (`participant_name`, text, required): Enter your full name.
* **Email Address**: (`participant_email`, email, required): Enter your email address.
* **Breeding Experience Level**: (`experience_level`, select_one, required): Select your background in breeding, from Beginner to Expert.
* **Quiz Date**: (`quiz_date`, date, required): Today's date, which is automatically populated.
* **Primary Goal of Selective Breeding**: (`question_1`, select_one, required): Select the best answer from the options:
	+ To increase genetic diversity
	+ To improve specific desirable traits in animals
	+ To reduce breeding costs
	+ To eliminate record keeping
* **What does Inbreeding Coefficient Measure?**: (`question_2`, select_one, required): Select the correct answer from the options:
	+ The cost of breeding animals
	+ The probability of inheriting two copies of the same allele from a common ancestor
	+ The number of offspring produced
	+ The age of breeding animals
* **Most Important Factor in a Breeding Program**: (`question_3`, select_one, required): Select the most important factor from the options:
	+ Animal size
	+ Genetic health and trait consistency
	+ Coat color
	+ Animal age
* **Breed Standard**: (`question_4`, select_one, required): Select the correct definition from the options:
	+ The minimum price for breeding animals
	+ A detailed description of ideal characteristics for a breed
	+ The maximum number of offspring allowed
	+ The age animals must be before breeding
* **Recommended Health Screening**: (`question_5`, select_multiple, required): Select all that apply from the options:
	+ Hip dysplasia screening
	+ Genetic testing
	+ Temperament testing
	+ Dental evaluation
* **Purpose of Pedigree Analysis**: (`question_6`, select_one, required): Select the best answer from the options:
	+ To determine animal prices
	+ To understand genetic lineage and potential hereditary issues
	+ To calculate breeding costs
	+ To schedule breeding dates
* **Breeding Evaluation Frequency**: (`question_7`, select_one, required): Select the recommendation from the options:
	+ Once annually
	+ Before each breeding
	+ Never
	+ Only when problems arise
* **Linebreeding Definition**: (`question_8`, select_one, required): Select the correct definition from the options:
	+ Mating unrelated animals
	+ Mating animals that share common ancestors
	+ Selecting for single traits only
	+ Preventing all breeding
* **Essential Record for Breeding Management**: (`question_9`, select_multiple, required): Select all important records from the options:
	+ Pedigree records
	+ Health and genetic screening results
	+ Performance records
	+ Breeding dates and offspring data
* **Genetic Diversity Benefit**: (`question_10`, select_one, required): Select the primary benefit from the options:
	+ Reduced trait variation
	+ Increased production costs
	+ Better adaptation and disease resistance
	+ Faster breeding cycles
* **Age for Breeding Suitability Evaluation**: (`question_11`, select_one, required): Select the recommendation from the options:
	+ As newborns
	+ At sexual maturity with sufficient development
	+ Only after first offspring
	+ Never before age 10 years
* **Maintaining Records Benefits**: (`question_12`, select_multiple, required): Select all benefits from the options:
	+ Track genetic traits
	+ Identify health problems early
	+ Improve future breeding decisions
	+ Comply with regulations
* **Breeding Knowledge Self-Assessment**: (`knowledge_assessment`, select_one, required): Rate your breeding management knowledge after completing the quiz:
	+ Needs improvement
	+ Basic understanding
	+ Good understanding
	+ Excellent mastery
* **Areas to Improve**: (`areas_to_improve`, select_multiple, optional): Select areas you would like to learn more about from the options:
	+ Genetic testing and selection
	+ Health screening protocols
	+ Breed standards and judging
	+ Record keeping systems
	+ Ethical breeding practices
* **Additional Comments**: (`additional_comments`, text, optional): Enter any feedback or comments.
