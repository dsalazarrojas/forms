# Educational Administration Onboarding Form - Help Guide
## Purpose
The Educational Administration Onboarding Form is a tool used to gather essential information about new hires in an educational institution. This form helps ensure that accurate and complete data is collected, enabling the new hire to be properly integrated into the institution's administrative systems.

## How To Complete This Form
To complete the form, follow these steps:

1.  Enter the details of the new hire, including their name, position, job title, start date, and end date.
2.  Provide their educational background and work location (if applicable).
3.  Indicate their language proficiency and native language.
4.  Select the school(s) and district(s) associated with the new hire.
5.  Choose the department(s) they will be working in.
6.  Specify their level of experience, language proficiency, and education level.
7.  Indicate whether they hold any relevant licenses.

## Field-by-Field Explanation
- **New Hire Details**: Enter the name and other details of the new hire.
  - **New Hire Name**: Enter the full name of the new hire.
  - **New Hire Position**: Select "Yes" or "No" to indicate if the new hire's position is full-time, part-time, or contract.
  - **New Hire Job Title**: Enter the job title of the new hire.
  - **New Hire Start Date**: Enter the date the new hire started working.
  - **New Hire End Date**: Enter the date the new hire ended their position.
- **New Hire Education Background**: Provide a brief description of the new hire's educational background.
- **New Hire Experience**: Enter any relevant work experience the new hire has.
- **New Hire Work Location**: Select "Yes" or "No" to indicate if the new hire will be working from home or in an office.
- **New Hire Phone**: Enter the new hire's contact phone number.
- **New Hire Email**: Enter the new hire's email address.
- **School Name**: Enter the name of the new hire's school or institution.
- **School ID**: Enter the ID number of the new hire's school or institution.
- **District ID**: Enter the ID number of the new hire's district or school area.
- **New Hire Department**: Select the department(s) the new hire will be working in.
- **New Hire School Type**: Select "Yes" or "No" to indicate if the new hire is a teacher or staff member.
- **New Hire Grade Level**: Select the grade level(s) the new hire will be working with.
- **New Hire Subject Area**: Select the subject area(s) the new hire will be teaching or working in.
- **New Hire Language**: Select the languages the new hire speaks or is proficient in.
- **New Hire Language Proficiency**: Select the new hire's language proficiency level.
- **New Hire Native Language**: Select "Yes" or "No" to indicate if English is the new hire's native language.
- **New Hire Education Level**: Select the new hire's education level.
- **New Hire License**: Select "Yes" or "No" to indicate if the new hire holds any relevant licenses.
