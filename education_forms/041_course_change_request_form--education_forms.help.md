# Course Change Request Form - Help Guide

## Purpose
The purpose of this form is to request changes to course attributes, such as status, assigned tools, or other updates. It is used by faculty members to formally propose changes to courses, ensuring all necessary information is provided for efficient processing.

## How To Complete This Form
To complete this form correctly, follow these steps:
1. **Fill Out Required Fields**: Complete the fields marked as "required" with the correct information. This typically includes providing a valid course ID.
2. **Choose Relevant Options**: Select the options that accurately reflect the nature of your request.
3. **Provide Additional Context (Optional)**: While not all fields are required, providing additional context in the "Comments" field can help the reviewer understand your request more clearly.

## Field-by-Field Explanation
- **Student Id**: This is an optional field used for tracking purposes, but it's not typically relevant for most course change requests. Enter your student ID if you're making a request for a course that affects you directly.
- **Reason**: This field provides an opportunity to give a clear explanation for the change you're proposing, which will help in the evaluation process.
- **Course Id**: Enter the ID of the course you're requesting changes for.
- **New Course Id**: Enter the ID of the new course that the change is related to, if applicable.
- **Faculty Approval**: Indicate how you wish the change to be treated, such as "Approve," "Deny," or "Pending" for further review.
- **Comments**: Add any additional comments that might be relevant to your request for the change.
- **Status**: Select the new status you wish to assign to the course, such as "New," "Open," or "Closed."
- **Assigned Tool**: Choose the tools you wish to have assigned or unassigned from the course.
- **Created By**: This field is usually populated automatically and should be left unchanged unless you wish to override it.
- **Updated By**: Like "Created By," this field is typically populated automatically and should be left as is unless you have a specific reason to edit it.

## Tips
- Make sure to enter accurate information for each field to avoid delays or unnecessary revisions.
- Be clear in your "Reason" for the change to facilitate smooth processing.
- Select options that accurately reflect your request to avoid confusion.
- Keep the "Comments" field for additional, non-required information to help reviewers understand your request better.
