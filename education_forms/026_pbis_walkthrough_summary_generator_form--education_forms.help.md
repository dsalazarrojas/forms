# PBIS Walkthrough Summary Generator Form - Help Guide
## Purpose
This form is designed to help users create a summary report of a walkthrough process. It collects information such as category, description, and tool assignment to generate a summary report.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the title of the form in the "Enter Form Title" field.
2. Select the relevant category (e.g., Education Forms, Information Request Forms).
3. Provide a brief description of the walkthrough process in the "Description" field.
4. If applicable, select the assigned tool (chatjimmy or Other).
5. Optionally, provide an output file name in the "Output File" field.
6. If applicable, fill in the "Form IDs" field.
7. Select the relevant category (e.g., Education Forms) in the "Category" field.
8. Enter a brief description of the form in the "Description 2" field.
9. Optionally, provide an output file name in the "Output File 2" field.
10. If applicable, select the assigned tool (chatjimmy or Other) in the "Assigned Tool 2" field.

* **Enter Form Title** (text, required): Enter the title of the form that you want to create a summary report for.
* **Select Category** (select multiple, not required): Choose the category that best describes the form (e.g., Education Forms, Information Request Forms).
* **Description** (text, not required): Provide a brief description of the walkthrough process.
* **Assigned Tool** (select one, not required): Select the tool that was used for the walkthrough process (chatjimmy or Other).
* **PBIS Walkthrough Summary** (text, not required): This field is currently empty and not visible in the form, but it might be used for future development.
* **Output File** (text, not required): Enter a name for the output file that will be generated (e.g., walkthrough_summary.txt).
* **Form IDs** (text, not required): If you want to specify form IDs for the walkthrough process, enter them here.
* **Category** (select one, not required): Select the category that best describes the form (e.g., Education Forms, Information Request Forms).
* **Description 2** (text, not required): Provide a brief description of the form.
* **Output File 2** (text, not required): Enter a name for the output file that will be generated (e.g., form_summary.txt).
* **Assigned Tool 2** (select one, not required): Select the tool that was used for the walkthrough process (chatjimmy or Other).
* **Form Title** (text, not required): Enter the title of the form that you want to create a summary report for.
