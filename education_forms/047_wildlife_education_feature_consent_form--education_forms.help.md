# Wildlife Education Feature Consent Form - Help Guide
## Purpose
This form is used to record the consent of users to use a specific feature or module in the wildlife education feature. It is used to collect information about the feature, including the category, description, form data, created date, and updated date.

## How To Complete This Form
To complete this form, please follow these steps:

1.  Select the category of the feature by choosing one of the options provided.
2.  Enter a brief description of the feature in the provided text field.
3.  If necessary, enter any additional data related to the form in the "form_data" field.
4.  Enter the date the form was created and the date it was last updated.

## Field-by-Field Explanation
*   **Category** (Education Forms, Other, Forms): Select one of the provided options to indicate the category of the feature.
*   **Description** (text, required): Enter a brief description of the feature.
*   **Form Data** (text, optional): Enter any additional data related to the form if necessary.
*   **Created At** (date, required): Enter the date the form was created.
*   **Updated At** (date, required): Enter the date the form was last updated.
*   **Deleted At** (date, optional): Enter the date the form was deleted if it has been deleted.
