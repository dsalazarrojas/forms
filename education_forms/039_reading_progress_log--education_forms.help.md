# reading_progress_log - Help Guide
## Purpose
The reading_progress_log form is designed to track a student's reading progress, goals, and activities.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the student's unique "Student ID" number.
2. Select the "Date" of the reading activity.
3. Choose the "Reading Activity" (e.g., "Reading a chapter, reading a book, etc.").
4. Select the "Reading Level" (e.g., "1", "2", etc.).
5. Enter the "Reading Time" (in minutes).
6. Enter the "Book Title".
7. Enter the "Author".
8. Select the "Reading Frequency" (e.g., "Every day, 2-3 times a week, etc.")).
9. Choose the "Reading Duration" (e.g., "15-30 minutes, 1-2 hours, etc.")).
10. Select the "Reading Goal" (e.g., "Reach 1-100 pages, 100-500 pages, etc.")).
11. Choose the "Reading Level Progress" (e.g., "A", "B", etc.).
12. Enter any additional comments about the student's reading level.
13. If applicable, select any additional "Reading Goals" (e.g., "Finish 5-10 chapters, etc.")).
14. Enter any comments about reading aloud or reading comprehension.

## Field-by-Field Explanation

* **Student ID (1)**: Enter the student's unique identifier (required).
* **Date (2)**: Enter the date of the reading activity (required).
* **Reading Activity (3)**: Choose the type of reading activity (e.g., reading a book, reading a chapter, etc.) (required).
* **Reading Level (4)**: Select the current reading level (e.g., 1, 2, etc.) (optional).
* **Reading Time (5)**: Enter the time spent reading (in minutes) (optional).
* **Book Title (6)**: Enter the title of the book being read (required).
* **Author (7)**: Enter the author of the book (optional).
* **Reading Frequency (11)**: Select how often the student reads (required).
* **Reading Duration (12)**: Select the time spent reading (required).
* **Reading Goal (13)**: Select the student's reading goal (required).
* **Reading Level Progress (14)**: Select the current reading level progress (optional).
* **Reading Level Comment (15)**: Enter any comments about the student's reading level (optional).
* **Read Aloud (16)**: Enter any comments about reading aloud (optional).
* **Reading Comprehension (17)**: Enter any comments about reading comprehension (optional).
