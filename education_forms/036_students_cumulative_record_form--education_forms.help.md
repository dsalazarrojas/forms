# Students Cumulative Record Form - Help Guide
## Purpose
This form is used to collect and document information about students, including their name, student ID, grade level, student grade, courses, term start and end dates, note, email, and contact phone number. The form helps in maintaining a record of students' cumulative data which is crucial for student tracking and assessment.

## How To Complete This Form
1. **Fill out the form accurately**: Ensure that all required fields are completed and all information is correct and up-to-date.
2. **Use clear and concise formatting**: Use standard formatting for dates (e.g., MM/DD/YYYY) and phone numbers (e.g., (123) 456-7890).
3. **Use the correct options**: Select the correct grade level and course selections from the provided options.

## Field-by-Field Explanation

* **Student Name**: This field is used to input the student's name.
* **Student ID**: This field is used to input the student's ID number.
* **Grade Level**: This field is used to select the student's grade level, which is a crucial piece of information for student tracking.
* **Student Grade**: This field is used to input the student's grade, which can be used to assess student progress.
* **Course 1**: This field is used to select the student's courses. Select all relevant courses that the student is taking.
* **Course 2**: This field is used to select additional courses that the student is taking.
* **Term Start Date**: This field is used to input the term start date, which marks the beginning of the academic term.
* **Term End Date**: This field is used to input the term end date, which marks the end of the academic term.
* **Note**: This field is used to input any additional notes or comments about the student.
* **Email**: This field is used to input the student's email address.
* **Phone Number**: This field is used to input the student's contact phone number.

## Tips
* Ensure that all information is accurate and up-to-date.
* Use standard formatting for dates and phone numbers.
* If a student has multiple courses, select all relevant courses in the "Course 1" and "Course 2" fields.
