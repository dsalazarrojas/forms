# Music Theory Quiz - Help Guide
## Purpose
The Music Theory Quiz form is used to create interactive quizzes on music theory concepts for educational purposes.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the category for your quiz from the dropdown menu.
2. Provide a brief description of the quiz.
3. Check if the quiz can be filled out on any device and if it can be shared with students.
4. Customize the quiz by selecting whether it can be customized or not.
5. Choose the output file format for the quiz.

## Field-by-Field Explanation
* **Category** (`category`, select_one, required: false): Choose the category for your quiz from the dropdown menu.
* **Description** (`description`, text, required: false): Enter a brief description of your quiz.
* **Description** (`music_theory_quiz_description`, text, required: false): Enter a detailed description of your quiz.
* **Can be filled out on any device** (`can_be_filled_out_anywhere`, text, required: false): Check if your quiz can be filled out on any device.
* **Can be customized** (`can_be_customized`, select_one, required: false): Select whether your quiz can be customized or not.
* **Can be shared with students** (`can_be_shared`, select_one, required: false): Select whether your quiz can be shared with students.
* **Output File** (`output_file`, text, required: false): Choose the output file format for your quiz.
* **Assigned Tool** (`assigned_tool`, text, required: false): Enter the assigned tool for your quiz.
* **Music Theory Quiz** (`music_theory_quiz`, text, required: false): Enter the title of your quiz.
