# Global Project Topic Submission Form - Help Guide
## Purpose

This form is designed to collect project topic information from users, ensuring consistency and standardization in project submissions.

## How To Complete This Form

1. Fill in the required fields with accurate and complete information.
2. Choose the correct options for category, location, and submitter type.
3. Attach any required documents, if applicable.
4. Review and submit the form for review and approval.

## Field-by-Field Explanation

* **Project Name** (Project Name, Text, Required): Enter a concise and descriptive name for your project.
* **Category** (Category, Select One, Required): Choose the relevant category for your project from the available options (Project or Education).
* **Description** (Description, Text, Required): Provide a brief description of your project.
* **Location** (Location, Select Multiple, Required): Select all relevant locations related to your project (New York, California, Chicago, Other).
* **Date** (Date, Date, Required): Enter the date you expect the project to start and end.
* **Time** (Time, Time, Required): Enter the time you expect the project to start and end.
* **Required Documents** (Required Documents, Select Multiple, Required): Choose all relevant documents that need to be attached with your project submission (Project Plan, Budget Plan).
* **Lead Person** (Lead Person, Text, Required): Enter the name of the person in charge of the project.
* **Email** (Email, Email, Required): Enter the email address of the person submitting the project.
* **Phone** (Phone, Text, Required): Enter the phone number of the person submitting the project.
* **Submitter** (Submitter, Select One, Required): Choose if you are submitting as an Organization or Individual.
* **Submitter Department** (Submitter Department, Text, Required): Enter the department of the submitter.
* **Project Topic** (Project Topic, Text, Required): Enter a brief description of the project topic.
* **Submitted By** (Submitted By, Note, Required): Enter the name of the person submitting the project.
* **Submitted On** (Submitted On, Time, Required): Enter the date and time the project was submitted.
* **Assigned To** (Assigned To, Select Multiple, Required): Choose all team members assigned to the project (Jimmy, John).
* **Project Status** (Project Status, Select One, Required): Choose the status of the project (Approved, Rejected, Pending, In Progress).
* **Project Type** (Project Type, Select One, Required): Choose the type of project (Project Type 1, Project Type 2, Project Type 3, Project Type 4).
* **Submitted On Date** (Submitted On Date, Date, Required): Enter the date the project was submitted.
* **Submitted On Time** (Submitted On Time, Time, Required): Enter the time the project was submitted.
* **Assigned Tool** (Assigned Tool, Text, Required): Enter the tool assigned to the project.
* **Assigned To** (Assigned To, Text, Required): Enter the name of the person assigned to the project.
* **Submitter Email** (Submitter Email, Email, Required): Enter the email address of the person submitting the project.
* **Submitter Phone** (Submitter Phone, Text, Required): Enter the phone number of the person submitting the project.
* **Comments** (Comments, Note, Required): Add any additional comments or notes about the project.
