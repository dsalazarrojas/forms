# Dual Language Program Application - Help Guide
## Purpose
The Dual Language Program Application form is designed to collect demographic and program-related information about students enrolled in the Dual Language Program.

## How To Complete This Form

1. **Provide the necessary information**: Fill in the form with accurate and complete answers to each question.
2. **Answer questions clearly**: Ensure that you answer each question truthfully and accurately.
3. **Submit the form**: Once you have completed the form, click the "Submit" button to send the information for review.
