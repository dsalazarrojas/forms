# Mnbaby Form Đăng Ký Nhập Học Trường Mầm Non Baby - Help Guide
## Purpose
This form is used for registering children for preschools, allowing parents to easily and quickly provide required information for the enrollment process.

## How To Complete This Form
To complete this form, follow these steps:

1. **Category**: Select the category related to the child (e.g., "Education").
2. **Description**: Provide a brief description of the child and their needs.
3. **Form Name**: Enter the name of the form, which will be used as a reference.
4. **Assigned Tool**: Select the tool assigned for the child (e.g., "chatjimmy").
5. **Output File**: Enter a file name or path where the output will be generated.
6. **Form Title**: Enter a title for the form, which will be used as a heading.
7. **Form Description**: Provide a detailed description of the form and its contents.
8. **Form Category**: Enter a category for the form (e.g., "Preschool Enrollment").
9. **Form Version**: Enter the version number of the form.
10. **Created Date**: This field will be automatically populated with the current date.
11. **Updated Date**: This field will be automatically populated with the current date.
12. **Status**: Select the status of the form (e.g., "active", "draft", or "archived").
13. **Form ID**: Enter a unique identifier for the form.
14. **Output File**: Enter a file name or path where the output will be generated.

## Field-by-Field Explanation
* **Form ID** (`form_id`, text, required): This field is used to uniquely identify the form.

* **Output File** (`output_file`, text, required): Enter a file name or path where the output will be generated.
* **Form Title** (`form_title`, text, optional): Enter a title for the form, which will be used as a heading.
* **Form Description** (`form_description`, text, optional): Provide a detailed description of the form and its contents.
* **Form Category** (`form_category`, text, optional): Enter a category for the form (e.g., "Preschool Enrollment").
* **Form Version** (`form_version`, text, optional): Enter the version number of the form.
* **Created Date** (`created_at`, date, required): This field will be automatically populated with the current date.
* **Updated Date** (`updated_at`, date, required): This field will be automatically populated with the current date.
