# Global Interconnections Quiz - Help Guide
## Purpose
The Global Interconnections Quiz is a form designed to test students' knowledge of globalization, technology, and international links. It's intended to help educators run quick online assessments and collect results in one place.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the relevant categories from the list to confirm that this form is related to education and quizzes.
2. Enter a brief description of the quiz, describing what it tests and how it contributes to the assessment process.
3. Decide whether or not the quiz is assigned a tool, and if so, which one.

## Field-by-Field Explanation
* **Category Label**: (`category_label`, select_multiple, required/optional): 
  Please select all that apply to confirm that this form is related to both Education and Quizzes.
* **Global Interconnections Quiz Form**: (`goals_label`, note, required/optional): 
  This field is a label for the form, providing a brief description of what it is.
* **Global Interconnections Quiz Form Description**: (`description_label`, text, required/optional): 
  Describe the purpose and scope of the Global Interconnections Quiz, explaining what it tests and its value in assessment.
* **Assigned Tool**: (`assigned_tool_label`, select_multiple, required/optional): 
  Decide whether the quiz is assigned a tool, selecting 'Yes' if it is, and 'No' if not.
