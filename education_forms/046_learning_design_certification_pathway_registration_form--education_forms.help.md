# Learning Design Certification Pathway Registration Form - Help Guide

## Purpose
This form is for registering learning design certification pathways for instructors or administrators to create and track pathways for students. Please ensure that you are filling out this form correctly and accurately, as it will be used to track and certify student progress.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the form title at the top of the page. This is the name of the pathway that will be displayed to students.
2. Select the category of the form from the dropdown menu. This will help us categorize and track the pathway.
3. Provide a description of the form, explaining what it covers and what students will learn from it.
4. If you want to associate this form with a specific tool, select it from the dropdown menu. This will help us track the tools used in the pathway.
5. Enter the unique identifier for the form, which is used to track and reference the pathway.
6. If you want to upload an output file for the pathway, please provide the file location or URL.

## Field-by-Field Explanation

* **Form Title** (`form_title`, required): This is the name of the pathway that will be displayed to students. Please enter a clear and concise title that describes the purpose of the pathway.
* **Category** (`category`, optional): This is the category of the form, which helps us track and organize the pathways. Please select from the options provided:
	+ Education Forms
	+ Other
* **Description** (`description`, required): This is the description of the form, explaining what it covers and what students will learn from it. Please provide a clear and concise description.
* **Assigned Tool** (`assigned_tool`, optional): This is the tool associated with the form, which helps us track the tools used in the pathway. Please select from the options provided:
	+ chatjimmy
	+ other
* **Form ID** (`form_id`, required): This is the unique identifier for the form, which is used to track and reference the pathway. Please enter a unique number for each form.
* **Output File** (`output_file`, optional): If you have uploaded an output file for the pathway, please provide the location or URL where it can be found.
* **Form Version** (`form_version`, optional): This is the version of the form, which helps us track updates and changes made to the pathway. Please enter the version number of the form.

## Tips
Please ensure that you have filled out all required fields and uploaded any necessary output files. If you are unsure about any of the fields, please consult with the relevant instructor or administrator.
