# Sine Calculator Form - Help Guide
## Purpose
This form is designed to calculate specific values for sine waves. Users can input parameters like sine value, wave type, and frequency to get the calculated output. The form is intended for educational purposes or to quickly perform simple sine wave calculations.

## How To Complete This Form
To complete the form, follow these steps:
1. Enter the value of the sine wave.
2. Select the type of wave (sine or other).
3. Enter the frequency of the wave.
4. Enter the phase shift of the wave (optional).

## Field-by-Field Explanation

* **Sine Value Input** (1, number, optional): This field is where you input the value of the sine wave. It's a numerical value that represents the amplitude of the wave.
* **Wave Type** (2, select_one, optional): Choose the type of wave you want to calculate (sine or other).
* **Frequency** (3, number, optional): Enter the frequency of the wave, which is the number of cycles per second.
* **Phase Shift** (4, number, optional): Enter the phase shift of the wave, which is the initial phase of the wave in radians. This field is optional and only relevant if you want to calculate a wave with a phase shift.
