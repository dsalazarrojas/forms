# Class Attendance Card Form - Help Guide
## Purpose
This form is used to track student attendance in a class.

## How To Complete This Form

To complete this form, follow these steps:

1. Fill in the student's full name, ID number, and date of birth in the corresponding fields.
2. Select the student's grade level from the dropdown menu.
3. Enter the class or course name where the student is attending.
4. Record the teacher's name who is supervising the class.
5. Indicate the academic year and semester or term the student is attending.
6. Record the date of this class session.
7. Choose the student's attendance status (Present, Absent - Excused, Absent - Unexcused, Late Arrival, Early Departure).
8. If the student is late or early, record the arrival and departure times.
9. If applicable, choose the reason for absence or late arrival.
10. Enter any additional details about the absence or late arrival.
11. If makeup work is needed, select 'True'.
12. Self-assess the level of participation in class (Very active, Active, Moderate, Minimal, Did not participate).
13. Enter any notes for the teacher's reference.
14. Record the name of the person verifying the information.
15. Record the date the information was verified.

## Field-by-Field Explanation
* **Student Full Name**: This field is used to record the student's full name.
* **Student ID Number**: This field is used to record the student's school identification number.
* **Date of Birth**: This field is used to record the date of the student's birth (in MM/DD/YYYY format).
* **Grade Level**: This field is used to select the student's grade level.
* **Class or Course Name**: This field is used to record the name of the class or course the student is attending.
* **Teacher Name**: This field is used to record the name of the teacher supervising the class.
* **Academic Year**: This field is used to select the academic year the student is attending (e.g., 2025-2026).
* **Semester or Term**: This field is used to select the semester or term the student is attending (e.g., Fall Semester).
* **Attendance Date**: This field is used to record the date of this class session.
* **Attendance Status**: This field is used to select the student's attendance status (e.g., Present, Absent - Excused).
* **Arrival Time**: This field is used to record the time the student arrived if they were late.
* **Departure Time**: This field is used to record the time the student departed if they left early.
* **Reason for Absence or Late Arrival**: This field is used to select the reason for the student's absence or late arrival (if applicable).
* **Additional Details**: This field is used to enter any additional information about the absence or late arrival.
* **Makeup Work Needed**: This field is used to select whether makeup work is needed for the absence.
* **Level of Participation in Class**: This field is used to self-assess the level of participation in class.
* **Teacher Notes**: This field is used to record any notes for the teacher's reference.
* **Verified By**: This field is used to record the name of the person verifying the information.
* **Verification Date**: This field is used to record the date the information was verified.
