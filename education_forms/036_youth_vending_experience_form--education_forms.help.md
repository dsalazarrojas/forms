# Youth Vending Experience Form - Help Guide

The Youth Vending Experience Form is designed to collect information about a specific youth event. Event organizers or administrators can use this form to provide details about the event, which can be useful for promotion, coordination, or record-keeping purposes.

1. Fill out each page of the form, following the prompts provided.

* **Event Date** (`event_date`, date, required: false): Enter the date of the event in the standard date format (e.g., MM/DD/YYYY).
* **Event Time** (`event_time`, time, required: false): Enter the time of the event in the standard time format (e.g., 08:00 AM).
* **Venue** (`venue`, text, required: false): Enter the location where the event will take place.
* **Address** (`address`, text, required: false): Enter the physical address of the venue.
* **City** (`city`, text, required: false): Enter the city where the event will be held.
* **State** (`state`, text, required: false): Enter the state where the event will be held.
* **Zip Code** (`zip_code`, text, required: false): Enter the zip code of the venue's location.
* **Contact Person** (`contact_person`, text, required: false): Enter the name of the person responsible for the event.
* **Email** (`email`, email, required: false): Enter the email address of the contact person.
* **Phone** (`phone`, text, required: false): Enter the phone number of the contact person.
