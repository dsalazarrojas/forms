# Academic Software Needs Survey - Help Guide
## Purpose
The purpose of this survey is to gather information about your software needs and preferences for academic work. Your input will help guide future IT purchasing and licensing decisions to ensure we provide you with the right tools to support your academic activities.

## How To Complete This Form
To complete this form, please follow these steps:

* Select your primary role within the institution (e.g., Student, Faculty, Researcher, etc.)
* Choose your department or school
* List all the software tools you currently use for academic work (e.g., Microsoft Office Suite, Google Workspace, etc.)
* Rate your satisfaction with the current software tools available to you
* Indicate if there are any software tools you need that are not currently available or licensed
* If yes, list the specific software tools you need
* Confirm whether you receive adequate training on the software tools provided
* Select the software training topics that would be most useful to you
* Indicate the devices you primarily use for academic work (e.g., Desktop computer, Laptop, Tablet, etc.)
* Choose the operating system you primarily use
* Specify your preferred cloud storage for academic files (e.g., Google Drive, OneDrive, etc.)
* Describe the biggest challenge you face with academic software
* Provide any additional suggestions for improving software availability or support

## Field-by-Field Explanation

### Your primary role
**(Respondent role)** (<name>, required/optional: true)
Your primary role within the institution (e.g., Student, Faculty, Researcher, etc.). Please select the one that best describes your position.

### Department or school
( <department>, required: true)
The department or school you belong to. Please enter the name of your department or school.

### Software tools currently used
**(Which software tools do you currently use for academic work)** (<name>, required: true)
List all the software tools you use for academic work (e.g., Microsoft Office Suite, Google Workspace, etc.). Select all that apply.

### Satisfaction with current software tools
**(How satisfied are you with the software tools currently available to you)** (<name>, required: true)
Rate your satisfaction with the current software tools provided to you. Please select one of the options from Very dissatisfied to Very satisfied.

### Unmet software needs
**(Are there software tools you need that are not currently available or licensed?)** (<name>, required: true)
Indicate if you need any software tools that are not currently available or licensed. Please select one of the options: True, False, or Not sure.

### Software tools needed
**(If yes, please list the software tools you need)** (<name>, required: false)
If you selected "True" for the previous question, list the specific software tools you need. Please include software name and intended purpose.

### Training on software tools
**(Do you feel you receive adequate training on the software tools provided?)** (<name>, required: true)
Confirm whether you receive adequate training on the software tools provided. Please select one of the options: Yes - training is sufficient, Somewhat - more training would help, or No - training is inadequate.

### Software training topics
**(What software training topics would be most useful?)** (<name>, required: false)
Select the software training topics that would be most useful to you. Please select all that apply.

### Devices used for academic work
**(What devices do you primarily use for academic work?)** (<name>, required: true)
Indicate the devices you primarily use for academic work (e.g., Desktop computer, Laptop, Tablet, etc.). Please select all that apply.

### Operating System
**(Which operating system do you primarily use?)** (<name>, required: true)
Choose the operating system you primarily use. Please select one of the options: Windows, macOS, Linux, ChromeOS, or Other.

### Cloud Storage
**(Which cloud storage do you prefer for academic files?)** (<name>, required: true)
Specify your preferred cloud storage for academic files. Please select one of the options: Google Drive, OneDrive, Dropbox, Institutional cloud storage, or None - I use local storage.

### Biggest Challenge
**(What is the biggest challenge you face with academic software?)** (<name>, required: false)
Describe the biggest challenge you face with academic software. Please provide a brief description.

### Additional Suggestions
**(Any additional suggestions for improving software availability or support?)** (<name>, required: false)
Provide any additional suggestions for improving software availability or support. Please provide a brief description.
