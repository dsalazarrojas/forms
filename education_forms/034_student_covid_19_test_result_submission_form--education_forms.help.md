# Student COVID 19 Test Result Submission Form - Help Guide
## Purpose
The Student COVID 19 Test Result Submission Form is designed to collect test result data from students. This form is used to capture relevant information about a student's COVID-19 test result, including the test result, date of the test, symptoms experienced, who submitted the test result, and other general information.

## How To Complete This Form
1. Fill out the form completely and accurately.
2. Select the correct COVID-19 test result (Positive, Negative, or Pending).
3. Input the date the test was taken.
4. Provide any symptoms experienced.
5. Choose who submitted the test result (Mr. Teacher, Ms. Teacher, or Other).
6. Optional: Add any additional notes or comments.
7. If necessary, upload files related to the test result.

## Field-by-Field Explanation
* **General Info (1)**: This field is a text input field where you can enter any general information about the test result.
* **COVID 19 Test Result (2)**: Select the correct test result (Positive, Negative, or Pending).
* **Result Date (3)**: This field is a date input field where you can input the date the test was taken.
* **Symptoms (4)**: In this text input field, describe any symptoms you experienced after taking the test.
* **Submitted By (5)**: Select who submitted the test result (Mr. Teacher, Ms. Teacher, or Other).
* **Submission Date (6)**: This field is a date input field where you can input the date the test result was submitted.
* **Notes (7)**: Enter any additional comments or notes related to the test result. This field is optional.
* **Upload File (8)**: If you have any files related to the test result, such as a test report, upload them here.
* **Upload Files (9)**: Similar to the previous field, you can upload multiple files related to the test result.
