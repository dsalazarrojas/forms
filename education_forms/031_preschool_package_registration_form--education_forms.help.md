# Preschool Package Registration Form - Help Guide

## Purpose
This form is used to register a preschool package, collecting information from parents or guardians to ensure accurate and comprehensive data for educational programs and services.

## How To Complete This Form
1. Please fill in the required fields, marked with an asterisk (\*).
2. For fields with multiple options, select the relevant choice that best describes your answer.
3. If you need help with a specific field, please refer to the Field-by-Field Explanation section below.

## Field-by-Field Explanation

* **Parent Name** (`parent_name`, text, \*): Enter the name of the parent or guardian submitting the form.
* **Student Name** (`student_name`, text, \*): Enter the name of the student being registered.
* **Email** (`email`, email, \*): Enter a valid email address for communication purposes.
* **Phone** (`phone`, text, \*): Enter the phone number of the parent or guardian.
* **Preferred Session** (`session_preferences`, select_one): Select 'Yes' if you have a preferred session time, or 'No' if you do not.
* **Session Time** (`session_time`, time, optional): If you selected 'Yes' for Preferred Session, choose a specific time for the session.
* **Channel** (`channel`, select_multiple): Select all applicable channels for communication (Yes/No).
* **Notes** (`notes`, note, optional): Add any additional comments or information about the student.
* **Assigned User** (`assigned_user`, select_one): Select the user who will be handling the student's package.
* **Parent Notes** (`parent_notes`, note, optional): Add any additional comments or information from the parent.
* **Student Notes** (`student_notes`, note, optional): Add any additional comments or information about the student.
* **Channel Source** (`channel_source`, select_one): Select the source of the channel (Yes/No).
* **Preferred Session Time** (`preferred_session_time`, time, optional): If you selected 'Yes' for Preferred Session, choose a specific time for the session.
* **Channel Leading Source** (`channel_leading_source`, select_multiple): Select all applicable leading sources for the channel (Yes/No).
* **Assigned Form ID** (`assigned_form_id`, text, \*): Enter a unique identifier for the form.
* **Channel Source ID** (`channel_source_id`, text, optional): Enter a source ID for the channel.
* **Session Time ID** (`session_time_id`, text, optional): Enter a session time ID.
* **Assigned Form Name** (`assigned_form_name`, text, optional): Enter a name for the form.
* **Assigned Form Category** (`assigned_form_category`, text, optional): Enter a category for the form.
* **Parent Name 2** (`parent_name_2`, text, \*): Enter the name of the parent or guardian 2.
* **Student Name 2** (`student_name_2`, text, \*): Enter the name of the student 2.
* **Channel ID** (`channel_id`, text, optional): Enter a channel ID.
* **Preferred Session (2)** (`preferred_session`, select_one): Select 'Yes' if you have a preferred session time 2, or 'No' if you do not.
* **Notes 2** (`notes_2`, note, optional): Add any additional comments or information about the student 2.
* **Form ID** (`form_id`, text, \*): Enter a unique identifier for the form.

Please note that some fields are marked as required (\*), which means they must be filled in for the form to be submitted.
