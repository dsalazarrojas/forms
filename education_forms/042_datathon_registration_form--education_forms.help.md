# Datathon Registration Form - Help Guide
## Purpose
This form is designed to collect information from participants, teams, and teams' representatives for the Datathom event. It helps us to gather essential details for event organization and coordination.

## How to Complete This Form
To complete this form, follow these steps:
1. Enter the participant's first name in the "Participant First Name" field.
2. Enter the participant's last name in the "Participant Last Name" field.
3. If you are a team representative, enter your team's name in the "Team Name" field.
4. Select the participant's role in the "Role" field (Software Engineer, Data Scientist, Product Manager).
5. Enter the participant's email in the "Participant Email" field.
6. Enter the participant's phone number in the "Participant Phone Number" field.
7. Enter the Datathon name in the "Datathon Name" field.
8. Select the Datathon date in the "Datathon Date" field.
9. Select the Datathon time in the "Datathon Time" field.
10. Enter the Datathon location in the "Datathon Location" field.
11. If applicable, enter any additional information in the "Additional Info" field.
12. If applicable, enter the Datathom name in the "Datathom Name 2" field.
13. If applicable, enter the participant's email in the "Participant Email 2" field.
14. If applicable, enter the participant's last name in the "Participant Last Name 2" field.
15. If applicable, enter the Datathom date in the "Datathom Date 2" field.
16. If applicable, enter the Datathom time in the "Datathom Time" field.
17. If applicable, enter the participant's first name in the "Participant First Name 2" field.
18. If applicable, enter the team's email in the "Team Email" field.
19. If applicable, enter the team's first name in the "Team First Name" field.
20. If applicable, enter the team's last name in the "Team Last Name" field.
21. If applicable, enter the team size in the "Team Size 2" field.
22. If applicable, enter the participant's phone number in the "Participant Phone Number 2" field.

## Field-by-Field Explanation

* **Participant First Name**: Enter the first name of the participant.
* **Participant Last Name**: Enter the last name of the participant.
* **Company**: Enter the name of the company or organization that the participant is from.
* **Role**: Select the role of the participant (Software Engineer, Data Scientist, Product Manager).
* **Team Name**: If applicable, enter the name of the team.
* **Team Size**: If applicable, enter the size of the team.
* **Participant Email**: Enter the email of the participant.
* **Participant Phone Number**: Enter the phone number of the participant.
* **Datathom Name**: Enter the name of the event (only for team representatives).
* **Datathom Date**: Select the date of the event.
* **Datathom Time**: Select the time of the event.
* **Datathom Location**: Enter the location of the event.
* **Additional Info**: Enter any additional information about the event.
* **Participant Email 2**: If applicable, enter the email of the team representative.
* **Participant Last Name 2**: If applicable, enter the last name of the team representative.
* **Datathom Name 2**: If applicable, enter the name of the event.
* **Datathom Date 2**: If applicable, enter the date of the event.
* **Datathom Time 2**: If applicable, enter the time of the event.
* **Participant First Name 2**: If applicable, enter the first name of the team representative.
* **Team Email**: If applicable, enter the email of the team.
* **Team First Name**: If applicable, enter the first name of the team.
* **Team Last Name**: If applicable, enter the last name of the team.
* **Team Size 2**: If applicable, enter the size of the team.
* **Participant Phone Number 2**: If applicable, enter the phone number of the team representative.
* **Participant Email 3**: If applicable, enter the email of the team representative.

Note: Some fields are not required, but are optional and depend on the specific context and requirements of the event.
