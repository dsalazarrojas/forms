# Education Session Booking Form - Help Guide
## Purpose
The Education Session Booking Form is a tool for users to schedule new sessions for their account. It is used to book sessions at a specific time and date.

## How To Complete This Form

To complete this form, follow these steps:

* Select the form from the available options.
* Fill in the form with the required information.
* Ensure that the form is accurate and up-to-date.

## Field-by-Field Explanation

* **Booking Form** (booking_form, text, optional): This field is a text input where you can enter any relevant information about the booking.
* **Session Name** (session_name, text, optional): Enter the name of the session you are booking.
* **Booking Date** (booking_date, date, optional): Select the date you want to book the session.
* **Booking Time** (booking_time, time, optional): Select the time you want to book the session.
* **Session Duration** (session_duration, text, optional): Enter the duration of the session.
* **Start Time** (start_time, time, optional): Select the start time of the session.
* **End Time** (end_time, time, optional): Select the end time of the session.
* **Session Type** (session_type, select_one, optional): Choose the type of session you are booking (Yes/No).
* **Session Details** (session_details, text, optional): Enter any additional information about the session.
