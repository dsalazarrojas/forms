# Pre Program Survey - Help Guide
## Purpose
The Pre Program Survey is designed to collect information about users' interest in various programs, educational background, and contact information. This will help us better understand your needs and preferences and provide you with the most relevant information and resources.

## How To Complete This Form
To complete this form, simply follow these steps:

1. Answer each question in the best way you can.
2. Make sure to fill out all required fields (indicated by the word "required" in the field label).
3. If you're unsure about any field, provide the best answer you can.
4. Scroll down to the next page to see more fields.

## Field-by-Field Explanation
### Program Interested
* **Program Interested** (`program_interested`, text, false): This field asks about your interest in various programs. Please provide a brief description of what you're interested in.
### Program Length
* **Program Length** (`program_length`, number, false): This field asks for the length of the program you're interested in. Please enter the number of months or years.
### Program Level
* **Program Level** (`program_level`, select_one, false): This field asks about your educational level. Select the level that best matches your current or desired level of education.
### Other (Program Length)
* **Other (Program Length)** (`program_length_other`, text, false): This field is for providing more information about the program length if it doesn't fit into the typical categories.
### Phone Number
* **Phone Number** (`phone_number`, text, false): This field asks for your phone number. Please enter your phone number in the format XXX-XXX-XXXX.
### Email Address
* **Email Address** (`email_address`, email, false): This field asks for your email address. Please enter your email address in the format [yourname@example.com](mailto:yourname@example.com).
### Program Start Date
* **Program Start Date** (`program_start_date`, date, false): This field asks for the start date of the program you're interested in. Please use the standard date format (MM/DD/YYYY).
### Program Start Time
* **Program Start Time** (`program_start_time`, time, false): This field asks for the start time of the program you're interested in. Please use the 24-hour clock format (HH:MM).
 
Please note that all fields are optional, unless otherwise specified. If you need assistance or have questions, please don't hesitate to ask.
