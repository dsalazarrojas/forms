# Transformative Education Leadership Program Application - Help Guide
## Purpose
The Transformative Education Leadership Program Application form is designed to collect information from individuals applying for the program. Please complete this form accurately and thoroughly to ensure your application is considered for the program.

## How To Complete This Form
To complete this form, follow the instructions below.

1. **Program Name**: Enter the name of the program you are applying for.
2. **Institution**: Enter the name of the institution associated with the program.
3. **School District Name**: Enter the name of the school district associated with the program (if applicable).
4. **Email**: Enter a valid email address associated with your application.
5. **Phone Number**: Enter a valid phone number associated with your application.
6. **Start Date**: Enter the start date of the program (if applicable).
7. **End Date**: Enter the end date of the program (if applicable).
8. **Type of Institution**: Select the type of institution you are affiliated with from the list below:
	* Option 1
	* Option 2
	* Option 3
9. **Areas of Education**: Select all applicable areas of education from the list below:
	* Option 1
	* Option 2
	* Option 3
10. **Note**: Enter any additional comments or notes you have about your application.

## Field-by-Field Explanation
* **Program Name (1)**: The name of the program you are applying for. This is a text field where you can enter the name of the program.
* **Institution (2)**: The name of the institution associated with the program. This is a text field where you can enter the name of the institution.
* **School District Name (3)**: The name of the school district associated with the program (if applicable). This is a text field where you can enter the name of the school district.
* **Email (4)**: A valid email address associated with your application. This is a text field with email validation to ensure a valid format.
* **Phone Number (5)**: A valid phone number associated with your application. This is a text field with validation to ensure a valid format.
* **Start Date (6)**: The start date of the program (if applicable). This is a date field where you can enter a date in the format MM/DD/YYYY.
* **End Date (7)**: The end date of the program (if applicable). This is a date field where you can enter a date in the format MM/DD/YYYY.
* **Type of Institution (8)**: A select field with three options:
	* Option 1
	* Option 2
	* Option 3
* **Areas of Education (9)**: A select multiple field with three options:
	* Option 1
	* Option 2
	* Option 3
* **Note (10)**: A text field for any additional comments or notes you have about your application.

## Tips
* Please ensure that all required fields are completed accurately and thoroughly.
* If you are unsure about any field, please contact the program administrators for clarification.
* Double-check your email and phone number formats before submitting your application.
