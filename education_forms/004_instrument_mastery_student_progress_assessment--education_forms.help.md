# Instrument Mastery Student Progress Assessment - Help Guide
## Purpose
This form is used to assess the student's progress and mastery level in playing a musical instrument.

## How To Complete This Form
To complete this form, follow these steps:

1. Please provide the instrument played by the student.
2. Indicate how many times per week the student practices.
3-8: Select the current mastery level of the student for each level (1-10).
9-11: Indicate how long the student typically practices for and how many times they practice in a session.
12-14: Select the level of interest and motivation the student has in music.
15-16: Select whether there are any obstacles preventing the student from practicing and the primary reason if so.
17-18: Select the student's level of interest and motivation in music.
