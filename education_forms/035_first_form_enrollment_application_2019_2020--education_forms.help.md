# First form enrollment application 2019 2020 - Help Guide

## Purpose
This form is intended to collect information from students for the first form enrollment application for the 2019-2020 period. The form will be used to gather essential details for the enrollment process.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter your information in the required fields.
2. For the "Education Forms" field, select one of the available options from the dropdown menu.
3. For the "Education Forms 2" field, select all relevant options from the list.
4. Review your selections before submitting the form.

## Field-by-Field Explanation
- **First Form Enrollment Application 2019 2020** (`text`, required: false): Enter your name and other relevant details in this field. This field is not required, but it's a good idea to provide some basic information for reference.
- **Education Forms** (`select_one`, required: false): Select one option from the list. This field is used to gather more specific information related to education forms.
	+ Option 1: Select this option for [briefly describe the option, e.g., "For students who have completed high school education"]
	+ Option 2: Select this option for [briefly describe the option, e.g., "For students who have completed vocational training"]
- **Education Forms 2** (`select_multiple`, required: false): Select all relevant options from the list. This field is used to gather more specific information related to additional education forms.
