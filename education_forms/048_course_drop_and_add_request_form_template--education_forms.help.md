# course_drop_and_add_request_form_template - Help Guide
## Purpose
The purpose of this form is to allow students to request to drop or add a course. Fill out this form to submit a request to make changes to your course schedule.

## How To Complete This Form
To complete this form, follow these steps:
1. Enter your name as it appears on your student ID.
2. Enter the name of the course you would like to add or drop.
3. Provide the reason you would like to add or drop the course.
4. Select the start date of the course you would like to add.
5. Select the end date of the course you would like to drop.
6. (Optional) Add any additional comments or notes about your request in the advisor note field.

## Field-by-Field Explanation
* **User** (`1`, text, required): Enter your name as it appears on your student ID.
* **Course** (`2`, text, required): Enter the name of the course you would like to add or drop.
* **Reason** (`3`, text, required): Provide the reason you would like to add or drop the course.
* **Start Date** (`4`, date, required): Select the start date of the course you would like to add.
* **End Date** (`5`, date, required): Select the end date of the course you would like to drop.
* **Advisor Note** (`6`, note, optional): Add any additional comments or notes about your request. 

## Tips
* Make sure to fill out the form completely and accurately to ensure your request is processed correctly.
* If you're unsure about any part of the form, consult with your academic advisor or institutional support staff.
