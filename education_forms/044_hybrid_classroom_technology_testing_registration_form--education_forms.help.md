# Hybrid Classroom Technology Testing Registration Form - Help Guide
## Purpose
This form is designed to help us understand your experience and interest in hybrid classroom technology testing. Your input will help us better plan our testing process and provide a more efficient and effective user experience.

## How To Complete This Form
Please read each field carefully and select the appropriate response that best suits your situation. Do not worry if you are not sure about a specific field; just provide your best answer and we will make sure to clarify any doubts.

## Field-by-Field Explanation

* **demo_details** (`select_multiple`, required: false): This field asks if you have participated in a demo or trial run of our hybrid classroom technology. Please select all the options that apply to you:
	+ Yes (I have participated)
	+ No (I have not participated)
* **participant_details** (`text`, required: false): Please provide a brief description of your role or position at your organization (e.g., teacher, student, staff member).
* **testing_schedule** (`date`, required: false): If you have a preferred date for the testing, please provide it in the format YYYY-MM-DD.
* **technology_details** (`select_one`, required: false): This field asks about your interest in specific technologies. Please select one of the following:
	+ Yes (I am interested in exploring this technology)
	+ No (I have no interest in this technology)
* **testing_preferences** (`select_multiple`, required: false): If applicable, please select all the technologies you would like to test:
	+ [List the options corresponding to the technologies listed in the technology_details field]
* **participant_email** (`email`, required: false): Please provide your email address so we can contact you with further instructions or updates.
* **participant_phone** (`text`, required: false): Please provide your phone number so we can reach you if needed.

## Tips
- Make sure to provide accurate and honest information.
- If you are unsure about any field, please don't hesitate to ask.
- This form is meant to be a brief and quick assessment; please complete it within 10-15 minutes.
- You are not committing to participate in any testing or trial run by completing this form. We will follow up with further instructions and confirmation if your input is selected for testing.
