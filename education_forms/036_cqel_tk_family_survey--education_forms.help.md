# CQEL TK Family Survey - Help Guide
## Purpose
The CQEL TK Family Survey is designed to gather information about families' knowledge, perceptions, and experiences with Transitional Kindergarten (TK) programs. This information will help educators and administrators tailor TK programs to better meet the needs of families and children.

## How To Complete This Form
1. Answer each question as accurately and honestly as possible.
2. Read each question carefully and follow the instruction to ensure you're providing the correct information.
3. If you're unsure about any question, feel free to ask for clarification.
4. Please complete the form in its entirety before submitting.

## Field-by-Field Explanation

### Family Name (1)
* **Family Name** (`family_name`, text, required): Enter the last name of your family.

### Parent or Guardian Name (2)
* **Parent or Guardian Name** (`parent_name`, text, required): Enter the name of the person completing the survey.

### Email Address (3)
* **Email Address** (`email`, email, required): Enter your email address for communication purposes.

### Phone Number (4)
* **Phone Number** (`phone`, text, required): Enter your phone number.

### Child Name (5)
* **Child Name** (`child_name`, text, required): Enter the name of the child considering TK.

### Child Date of Birth (6)
* **Child Date of Birth** (`child_age`, date, required): Enter the child's date of birth.

### Currently Attending School (7)
* **Currently Attending School** (`current_school`, text, optional): If your child is currently attending school, enter the name of the school or preschool.

### How Much Do You Know About Transitional Kindergarten (8)
* **How Much Do You Know About Transitional Kindergarten** (`tk_knowledge`, select_one, required): Select how familiar you are with TK:
	+ Very familiar
	+ Somewhat familiar
	+ Heard of it
	+ Not familiar

### Where Did You Learn About TK (9)
* **Where Did You Learn About TK** (`tk_information_source`, select_multiple, optional): Select all the places where you learned about TK:
	+ School or district website
	+ Flyer or brochure
	+ Word of mouth
	+ Social media
	+ News article
	+ Other parent
	+ Have not heard about it

### Understand Benefits of TK Program (10)
* **Understand Benefits of TK Program** (`tk_benefit_understanding`, select_one, required): Select your level of understanding about the benefits of TK:
	+ True
	+ Somewhat
	+ False

### Is Your Child Ready for TK (11)
* **Is Your Child Ready for TK** (`child_readiness`, select_one, required): Select how ready you believe your child is for TK:
	+ Yes, definitely ready
	+ Probably ready
	+ Uncertain
	+ Probably not ready
	+ Not ready

### Concerns About Child's Readiness (12)
* **Concerns About Child's Readiness** (`readiness_concerns`, text, optional): If you have any concerns about your child's readiness, provide them here.

### Likelihood of Enrolling Your Child in TK (13)
* **Likelihood of Enrolling Your Child in TK** (`tk_enrollment_likelihood`, select_one, required): Select the likelihood of enrolling your child in TK:
	+ Very likely
	+ Likely
	+ Maybe
	+ Unlikely
	+ Very unlikely

### Barriers to TK Enrollment (14)
* **Barriers to TK Enrollment** (`enrollment_barriers`, select_multiple, optional): If you have any barriers to enrolling your child in TK, select all that apply:
	+ Cost or tuition
	+ Transportation issues
	+ Program timing or schedule
	+ Prefer other options
	+ Uncertain about program
	+ Work schedule conflicts
	+ None

### Preferred TK Program Location (15)
* **Preferred TK Program Location** (`tk_location_preference`, text, optional): If you have a preferred location for the TK program, enter it here.

### Most Important Program Features (16)
* **Most Important Program Features** (`program_features_importance`, select_multiple, optional): Select the top three features that are most important to you for the TK program:
	+ Academic preparation
	+ Social-emotional learning
	+ Play-based learning
	+ Bilingual instruction
	+ Arts and music
	+ Physical activity
	+ Small class size

### How to Receive Program Information (17)
* **How to Receive Program Information** (`feedback_communication`, select_multiple, optional): Select how you would like to receive information about the TK program:
	+ Email
	+ Phone call
	+ Text message
	+ In-person meeting
	+ Community event
	+ Website
	+ Social media

### Would You Like More Information About TK (18)
* **Would You Like More Information About TK** (`more_information`, select_one, required): Select if you would like more information about TK:
	+ True
	+ False

### Willing to Share Information About TK with Other Families (19)
* **Willing to Share Information About TK with Other Families** (`willing_advocate`, select_one, optional): If you're willing to share information about TK with other families, select:
	+ True
	+ Maybe
	+ False

### Additional Comments or Suggestions (20)
* **Additional Comments or Suggestions** (`additional_comments`, text, optional): Share any additional comments or suggestions about the TK program.

Note: This help guide is based on the provided YAML fields and is intended to be a comprehensive and practical resource for families completing the CQEL TK Family Survey. If you have any questions or need further clarification, please don't hesitate to ask.
