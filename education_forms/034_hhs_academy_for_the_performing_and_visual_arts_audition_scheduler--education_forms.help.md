# Hhs Academy For The Performing And Visual Arts Audition Scheduler - Help Guide
## Purpose
This form is designed for students to submit information about their auditions for the Performing and Visual Arts at HHS Academy.

## How To Complete This Form
To complete this form, follow the instructions above.

## Field-by-Field Explanation
* **Student Name** (`Student Name`, text, required): This is the name of the student who is submitting the form.
* **Email Address** (`Email Address`, email, required): This is the contact information for the student's parent or guardian.
* **Phone** (`Phone`, text, optional): This is the phone number of the student or parent.
* **Audition Date** (`Audition Date`, date, optional): This is the date of the audition. If not specified, the default date will be used.
* **Audition Time** (`Audition Time`, time, optional): This is the time of the audition. If not specified, the default time will be used.
* **Audition Type** (`Audition Type`, select_one, required): This is the type of audition the student is applying for: Instrumental, Vocal, Dance, or Theatre.
* **Audition Instrument** (`Audition Instrument`, text, optional): This is the instrument the student will be auditioning with.
* **Audition Dance Style** (`Audition Dance Style`, text, optional): This is the dance style the student will be auditioning with.
* **Additional Information** (`Additional Information`, text, optional): This is any additional information about the audition the student would like to share.
* **Audition Attendance** (`Audition Attendance`, select_multiple, required): This is the student's attendance status for the audition: Present or Absent.
* **Comment** (`Comment`, text, optional): This is any comments or feedback the student would like to provide.
* **Parent Email** (`Parent Email`, email, optional): This is the email address of the parent or guardian.
* **Parent Phone** (`Parent Phone`, text, optional): This is the phone number of the parent or guardian.
* **Parent Comments** (`Parent Comments`, text, optional): This is any comments or feedback from the parent or guardian.
* **Audition Confirmation Status** (`Audition Confirmation Status`, select_one, required): This is the status of the student's audition: Pending, Approved, or Rejected.
* **Audition Confirmation Date** (`Audition Confirmation Date`, date, optional): This is the date the audition was confirmed.
* **Audition Confirmation Time** (`Audition Confirmation Time`, time, optional): This is the time the audition was confirmed.
* **Student Comments** (`Student Comments`, text, optional): This is any comments or feedback from the student.
* **Parent Comments** (`Parent Comments`, text, optional): This is any comments or feedback from the parent or guardian.
* **Form Submission Date** (`Form Submission Date`, date, required): This is the date the form was submitted.
* **Form Submission Time** (`Form Submission Time`, time, required): This is the time the form was submitted.
* **Assigned Tool** (`Assigned Tool`, text, optional): This is any other information to attach to the submission.
* **Created By** (`Created By`, text, optional): This is the name of the person who created the form.

## Tips
* Make sure to fill in all required fields to ensure successful submission.
* Use the correct format for dates and times (e.g., MM/DD/YY for dates, HH:MM for times).
* If you are unsure about any field, please ask your parent or guardian for assistance.
