# University Student Course Load Check In - Help Guide

## Purpose
The University Student Course Load Check In form is designed to verify student course enrollment and availability. This form is used by students, instructors, or academic administrators to ensure accurate data collection and to identify any discrepancies or inconsistencies in course load.

## How To Complete This Form
1. Review the relevant semester and student information before proceeding.
2. Fill out the form accurately and completely.
3. Ensure that you have the necessary permissions or access rights to complete the form.

## Field-by-Field Explanation

* **Semester** (`semester`, select_one, required): Select the semester for which you are checking in the student's course load.
    * Example: If the current semester is Spring 2023, select "Yes".
* **Student Name** (`student_name`, select_multiple, required): Confirm the student's name who is being checked in.
    * Example: If the student's name is John Doe, select "Yes".
* **Current Semester** (`current semester`, date, required): Enter the current semester's date.
    * Example: If the current semester is Spring 2023, enter the date 2023-01-01.
* **Course ID** (`course_id`, select_one, required): Confirm if the student is enrolled in any courses.
    * Example: If the student is enrolled in Course ID 12345, select "Yes".
* **Total Hours** (`total_hours`, number, required): Enter the total number of hours the student is enrolled in for the semester.
    * Example: If the student is enrolled in 10 hours per week, enter 40.
* **Check In Status** (`check_in_status`, select_one, required): Select the student's current check in status.
    * Example: If the student is active, select "Active".
* **Comments** (`comments`, note, optional): Add any comments or notes about the student's course load.
    * Example: If the student has a special request, add a note about it.
* **Email** (`email`, email, optional): Enter the student's email address.
    * Example: If the student's email is john.doe@example.com, enter it.
* **Phone** (`phone`, text, optional): Enter the student's phone number.
    * Example: If the student's phone number is 123-456-7890, enter it.
* **Last Updated** (`last_updated`, date, optional): Enter the date of the last update.
    * Example: If the last update was 2022-01-01, enter the date.
* **Assigned Tool** (`assigned_tool`, select_one, optional): Confirm if a tool has been assigned to the student.
    * Example: If a tool has been assigned, select "Yes".
* **Assigned User** (`assigned_user`, select_one, optional): Confirm the user assigned to the student.
    * Example: If a user has been assigned, select "Yes".
* **Form ID** (`form_id`, select_one, optional): Confirm if the form has been assigned to the student.
    * Example: If a form has been assigned, select "Yes".
* **Category** (`category`, select_one, optional): Confirm the category of the form.
    * Example: If the category is "University Student Course Load", select "Yes".
* **Form Description** (`form_description`, note, optional): Add a description of the form.
    * Example: If the form is used for course load checking, add a note about it.
* **Assigned Tool** (`form_assigned_tool`, select_one, optional): Confirm if a tool has been assigned to the form.
    * Example: If a tool has been assigned, select "Yes".
* **Assigned User** (`form_assigned_user`, select_one, optional): Confirm the user assigned to the form.
    * Example: If a user has been assigned, select "Yes".
* **Form Output File** (`form_output_file`, select_one, optional): Confirm if a file has been assigned to the form.
    * Example: If a file has been assigned, select "Yes".

## Tips
* Ensure that you have reviewed the course load for the relevant semester and student information before proceeding.
* Fill out the form accurately and completely.
* If you are unsure about any field or the purpose of the form, please contact the designated authority for guidance.
* Avoid duplicate or redundant entries, as this will lead to data duplication and errors.
