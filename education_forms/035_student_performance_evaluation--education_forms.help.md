# Student Performance Evaluation - Help Guide
## Purpose
The Student Performance Evaluation form is used to gather information on a student's performance, progress, and attendance. It helps educators to assess a student's strengths and weaknesses and provide targeted support to improve their performance.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the student's name in the "Student Name" field.
2. Select the assessment date from the calendar.
3. Choose whether the student has been assessed ("Yes" or "No").
4. Select the subject(s) the student has been assessed on ("Yes" or "No" for multiple subjects).
5. Enter a numerical grade if applicable.
6. Add any additional comments about the student's performance.
7. Choose whether the student has made progress ("Yes" or "No").
8. Indicate the student's attendance status ("Yes" or "No").
9. Select the evaluation method used (e.g., observation, test, etc.).
10. Enter the evaluation result.
11. Choose any additional recommendations for the student's improvement.
12. Add any additional comments about the student's performance.

## Field-by-Field Explanation

* **Student Name** (student_name, text, required):
	+ Enter the student's name as it appears on their record.
* **Assessment Date** (assessment_date, date, optional):
	+ Select the date of the assessment from the calendar.
* **Assessment Type** (assessment_type, select_one, optional):
	+ Choose whether the student has been assessed ("Yes" or "No").
* **Subject** (subject, select_multiple, optional):
	+ Select the subject(s) the student has been assessed on.
* **Grade** (grade, number, optional):
	+ Enter a numerical grade if applicable.
* **Comments** (comments, note, optional):
	+ Add any additional comments about the student's performance.
* **Student Progress** (student_progress, select_one, optional):
	+ Choose whether the student has made progress ("Yes" or "No").
* **Student Attendance** (student_attendance, select_one, optional):
	+ Indicate the student's attendance status ("Yes" or "No").
* **Evaluation Method** (evaluation_method, text, required):
	+ Select the evaluation method used (e.g., observation, test, etc.).
* **Evaluation Result** (evaluation_result, text, required):
	+ Enter the evaluation result.
* **Recommendation** (recommendation, select_multiple, optional):
	+ Choose any additional recommendations for the student's improvement.
* **Additional Comments** (additional_comments, text, optional):
	+ Add any additional comments about the student's performance.
