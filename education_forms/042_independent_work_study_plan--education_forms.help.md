# Independent Work Study Plan - Help Guide

## Purpose
This form is used to track and manage independent work projects, providing a clear and structured approach to documenting study goals, schedules, and progress. It helps ensure that all required information is captured accurately and efficiently, facilitating effective collaboration and decision-making among team members and project managers.

## How To Complete This Form
To complete this form, follow these steps:

1. Provide user information (page 1) with the necessary details.
2. Enter the study project name and other project-specific details (page 2).
3. Define the start and end dates for the study project (pages 3-4).
4. Record the total study hours allocated for the project (page 5).
5. Specify your study goals and progress (pages 6-7).
6. Enter the completed hours and expected completion date for the project (pages 8-9).
7. Select the submitted-by and submitted-to details (pages 10-11).
8. Choose the project manager and project status (pages 12-13).
9. Enter comments from the project manager (page 14) and review status (page 15).
10. Select the review status and comments from the reviewer (pages 16-17).
11. Enter the review comments and reviewer details (pages 18-19).
12. Specify the submitted date and approved-by details (pages 20-21).

## Field-by-Field Explanation

* **User Info (page 1)** (`user_info`, text, required: false)
	+ Enter your name and any other relevant information about yourself.
* **Study Project (page 2)** (`study_project`, text, required: true)
	+ Enter the name of the study project you are working on.
* **Start Date (page 3)** (`start_date`, date, required: false)
	+ Enter the start date of the project.
* **End Date (page 4)** (`end_date`, date, required: false)
	+ Enter the end date of the project.
* **Study Hours (page 5)** (`study_hours`, number, required: true)
	+ Enter the total study hours allocated for the project.
* **Goals (page 6)** (`goals`, text, required: false)
	+ Define your study goals and objectives.
* **Progress (page 7)** (`progress`, select_one, required: true)
	+ Select your current progress: Option 1, Option 2, or Option 3.
* **Completed Hours (page 8)** (`completed_hours`, number, required: true)
	+ Enter the total completed hours for the project.
* **Expected Completion Date (page 9)** (`expected_completion_date`, date, required: true)
	+ Enter the expected completion date for the project.
* **Comments (page 10)** (`comments`, text, required: false)
	+ Add any comments or notes about the project.
* **Submitted By (page 11)** (`submitted_by`, email, required: true)
	+ Enter your email address for submission.
* **Submitted To (page 12)** (`submitted_to`, select_multiple, required: true)
	+ Select the people or departments submitted to.
* **Project Manager (page 13)** (`project_manager`, text, required: true)
	+ Enter the name of the project manager.
* **Project Status (page 14)** (`project_status`, select_one, required: true)
	+ Select the current project status: Option 1, Option 2, or Option 3.
* **Comments from Project Manager (page 15)** (`comments_from_project_manager`, text, required: false)
	+ Add any comments or notes from the project manager.
* **Review Status (page 16)** (`review_status`, select_one, required: false)
	+ Select the review status: Option 1, Option 2, or Option 3.
* **Approved (page 17)** (`approved`, select_one, required: true)
	+ Select whether the project is approved: Option 1, Option 2.
* **Submitted (page 18)** (`submitted`, select_one, required: true)
	+ Select whether the project is submitted: Option 1, Option 2.
* **Review Comments (page 19)** (`review_comments`, text, required: false)
	+ Add any comments or notes from the reviewer.
* **Reviewer (page 20)** (`reviewer`, text, required: false)
	+ Enter the name of the reviewer.
* **Review Date (page 21)** (`review_date`, date, required: false)
	+ Enter the review date.
* **Comments from Reviewer (page 22)** (`comments_from_reviewer`, text, required: false)
	+ Add any comments or notes from the reviewer.
* **Review Status (page 23)** (`review_status`, select_one, required: false)
	+ Select the review status: Option 1, Option 2, or Option 3.
* **Submitted Date (page 24)** (`submitted_date`, date, required: true)
	+ Enter the submitted date.
* **Approved By (page 25)** (`approved_by`, select_one, required: true)
	+ Select who approved the project: Option 1, Option 2.

**Tips**

* Make sure to fill out all required fields accurately and completely.
* Double-check for any errors before submission.
* Review and submit multiple times for best results.
