# Transcript Release Authorization Form - Help Guide
## Purpose
This form is used to obtain authorization for the release of a student's transcript.

## How To Complete This Form
- Fill out the form completely and accurately with the student's information.
- Select the grade level of the student from the options provided.
- Select the type(s) of authorization to be granted.
- Ensure all required fields are completed before submitting the form.

## Field-by-Field Explanation
* **School Name** (`school_name`, text, required: false): This field is for the name of the school the student attended. If you are not sure about the school, please do not fill out this field.
* **Student Last Name** (`student_last_name`, text, required: false): This field is for the student's last name.
* **Student First Name** (`student_first_name`, text, required: false): This field is for the student's first name.
* **Date of Birth** (`date_of_birth`, date, required: false): This field is for the student's date of birth. Please enter the date in the YYYY-MM-DD format (e.g. 1999-06-15).
* **Student ID Number** (`student_id_number`, number, required: false): This field is for the student's ID number. If you're not sure about this number, you might want to try to look it up in our student database.
* **Grade Level** (`grade_level`, select_one, required: true): This field is for the student's current grade level. Select the correct grade level from the options provided.
* **Authorization Type** (`authorization_type`, select_multiple, required: true): This field is for the type of authorization to be granted. Select all applicable types from the options provided.
* **Signature Date** (`signature_date`, date, required: false): This field is for the date the form was signed.
* **Signature** (`signature_name`, text, required: false): This field is for the signature of the person granting authorization.

## Tips
* Please ensure that all required fields are completed before submitting the form.
* If you are unsure about a field, do not fill it out. Instead, reach out to the relevant department for clarification.
* A valid form submission requires both grade level and authorization type to be selected.
* If you need help with any part of this form, contact our support team.
