# Online Course Retention Factors Survey - Help Guide
## Purpose
The purpose of this form is to collect data on various aspects of online courses, including course title, student level, course level, enrollment period, and more, to analyze and improve the effectiveness of online courses.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out each page of the form carefully, providing the requested information for each field.
2. Make sure to provide accurate and honest answers, as this data will be used to improve the quality of online courses.
3. If you are unsure about any field, refer to the field-by-field explanation below for more information.

## Field-by-Field Explanation
### Page 1: 
* **Course Title** (`course_title`, required/optional): This field is for the title of the online course. Please enter the exact title of the course, including any relevant course numbers or codes.
* **Institution** (`institution`, required/optional): This field is for the institution where the course is offered. Please enter the name of the institution, such as a university or college.
* **Student Level** (`student_level`, required/optional): This field is for the level of the students enrolled in the course. Please select from the options provided: Level 1, Level 2, or Level 3.
* **Course Level** (`course_level`, required/optional): This field is for the level of the course itself. Please enter a numerical value, such as 1-5, where 1 is beginner and 5 is advanced.
* **Enrollment Period** (`enrollment_period`, required/optional): This field is for the period of enrollment for the course. Please select from the options provided: Summer, Fall, Winter, or Spring.
* **Enrollment Date** (`enrollment_date`, required/optional): This field is for the date of enrollment for the course. Please enter the date in the format mm/dd/yyyy.
* **Course Length** (`course_length`, required/optional): This field is for the length of the course. Please enter a numerical value, such as 1-12 weeks.

### Page 2:
* **Student Count** (`student_count`, required/optional): This field is for the number of students enrolled in the course. Please enter a numerical value.
* **Course Type** (`course_type`, required/optional): This field is for the type of course. Please enter a brief description of the course, such as online lecture or online lab.
* **Course Status** (`course_status`, required/optional): This field is for the status of the course. Please enter a brief description of the course, such as active or inactive.
* **Retention Rate** (`retention_rate`, required/optional): This field is for the rate of course retention. Please enter a numerical value, such as 0-100%.
* **Graduation Rate** (`graduation_rate`, required/optional): This field is for the graduation rate of the course. Please select from the options provided: High, Low, or Medium.

### Page 3:
* **Course Satisfaction** (`course_satisfaction`, required/optional): This field is for the satisfaction of the course. Please enter a numerical value, such as 1-5, where 1 is dissatisfied and 5 is satisfied.
* **Student Satisfaction** (`student_satisfaction`, required/optional): This field is for the satisfaction of the students. Please select from the options provided: Satisfied, Unsatisfied, or Neutral.
* **Institutional Support** (`institutional_support`, required/optional): This field is for the level of institutional support. Please select from the options provided: High, Low, or Medium.
* **Financial Aid** (`financial_aid`, required/optional): This field is for the financial aid provided to students. Please enter a brief description of the financial aid, such as grants or scholarships.
* **Course Evaluation** (`course_evaluation`, required/optional): This field is for the evaluation of the course. Please select from the options provided: Strongly Agree, Somewhat Agree, Neutral, Somewhat Disagree, or Strongly Disagree.
* **Instructor Quality** (`instructor_quality`, required/optional): This field is for the quality of the instructor. Please select from the options provided: Excellent, Good, Fair, or Poor.
* **Course Materials** (`course_materials`, required/optional): This field is for the materials provided for the course. Please select from the options provided: Good, Fair, or Poor.
* **Student Resources** (`student_resources`, required/optional): This field is for the resources provided to students. Please select from the options provided: Sufficient, Insufficient, or Not Applicable.
* **Feedback** (`feedback`, required/optional): This field is for any additional feedback about the course. Please enter a brief description of the feedback.
* **Email** (`email`, required/optional): This field is for contact information. Please enter a valid email address.
* **Phone** (`phone`, required/optional): This field is for contact information. Please enter a valid phone number.
* **Notes** (`notes`, required/optional): This field is for any additional notes about the course. Please enter a brief description of the notes.

## Tips
* Make sure to provide accurate and honest answers, as this data will be used to improve the quality of online courses.
* If you are unsure about any field, refer to the field-by-field explanation above for more information.
* This form is designed to be user-friendly and easy to navigate, making it simple for users to provide the necessary information.
