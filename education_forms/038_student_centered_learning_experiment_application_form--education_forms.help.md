# Student Centered Learning Experiment Application Form - Help Guide
## Purpose
This form is designed to collect information about a student-centered learning experiment from a teacher. The form aims to gather details about the project, the teacher, and various student demographics to support the evaluation and implementation of the experiment.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the required fields with accurate and relevant information.
2. Make sure to select the correct options for each field as needed.
3. Review the form carefully before submitting it to ensure all required fields are filled in correctly.

## Field-by-Field Explanation

* **Project Name** (`project_name`, text, required): Enter the name of the project or initiative being evaluated.
* **Project Lead** (`project_lead`, email, optional): Enter the email address of the person leading the project.
* **Project Location** (`project_location`, text, optional): Enter the location where the project is being conducted.
* **Project Description** (`project_description`, text, required): Enter a brief description of the project.
* **Project Start Date** (`project_start_date`, date, optional): Enter the start date of the project if applicable.
* **Project End Date** (`project_end_date`, date, optional): Enter the end date of the project if applicable.
* **School** (`school`, select_one, required): Select 'Yes' if the project is conducted in a school.
* **Grade Level** (`grade_level`, select_multiple, required): Select the grade level(s) of students involved in the project. You can select multiple options.
* **Department** (`department`, text, optional): Enter the department or subject area of the project.
* **Teacher Name** (`teacher_name`, text, optional): Enter the name of the teacher involved in the project.
* **Teacher Email** (`teacher_email`, email, optional): Enter the email address of the teacher.
* **Teacher Phone** (`teacher_phone`, text, required): Enter the phone number of the teacher.
* **Teacher Note** (`teacher_note`, note, required): Enter any additional notes or comments from the teacher.
* **Student Count** (`student_count`, number, required): Enter the number of students involved in the project.
* **Student Grade Level** (`student_grade_level`, select_one, required): Select the grade level of the students involved in the project.
* **Student Gender** (`student_gender`, select_multiple, required): Select the gender of the students involved in the project. You can select multiple options.
* **Other Student Info** (`other_student_info`, text, optional): Enter any additional information about the students.
* **Teacher Qualification** (`teacher_qualification`, text, optional): Enter the qualification of the teacher involved in the project.
* **Project Funding** (`project_funding`, text, optional): Enter any funding information related to the project.
* **Project Duration** (`project_duration`, select_one, required): Select 'Yes' if the project has a fixed duration.
* **Parent Permission** (`parent_permission`, select_one, required): Select 'Yes' if parent permission is required for the project.
* **Student Attendance** (`student_attendance`, select_multiple, required): Select the attendance status of the students involved in the project. You can select multiple options.
* **Student Engagement** (`student_engagement`, select_multiple, required): Select the engagement status of the students involved in the project. You can select multiple options.
* **Project Status** (`project_status`, select_multiple, required): Select the status of the project. You can select multiple options.
* **Submitted By** (`submitted_by`, text, optional): Enter the name of the person who submitted the form.

## Tips
* Make sure to enter accurate and relevant information for each field.
* Select the correct options for each field as needed.
* Review the form carefully before submitting it to ensure all required fields are filled in correctly.
