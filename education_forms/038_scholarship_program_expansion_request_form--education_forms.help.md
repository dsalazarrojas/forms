# Scholarship Program Expansion Request Form - Help Guide
## Purpose
The Scholarship Program Expansion Request Form is used to request expansion of a scholarship program. It provides a structured way to submit detailed information about the program you are interested in expanding.

## How To Complete This Form
To complete this form, follow these steps:
1. Select the correct category of the scholarship program you are interested in expanding.
2. Enter a detailed description of the scholarship program, including its title, category, and status.
3. Provide the necessary information about the assigned tool and output file related to this program.
4. Select the status of the form (Active or Inactive) and provide additional comments or notes as necessary.
5. Review all fields for accuracy before submitting the form.

## Field-by-Field Explanation

* **Form Category (Category)** (`Form Category`, select_one, Required): Select the category for the scholarship program you are requesting expansion for. Choose either Education or Other to classify your request.
* **Form Description (Form Description)** (`Form Description`, text, Optional): Briefly describe the scholarship program you are interested in expanding. This field provides context for the committee to evaluate your request.
* **Assigned Tool (Assigned Tool)** (`Assigned Tool`, text, Optional): Identify the tool assigned to this form. This information helps the committee understand the scope of the expansion request.
* **Form ID (Form ID)** (`Form ID`, text, Optional): Provide the ID for this scholarship program. This information helps the committee track and manage multiple requests.
* **Form Notes (Form Notes)** (`Form Notes`, text, Optional): Add any additional comments or notes related to this form. This field is for providing extra context or clarifying information.
* **Form Status (Form Status)** (`Form Status`, select_one, Required): Select the status of the form (Active or Inactive). This field helps the committee understand the current state of the request.
* **Category (Category)** (`Category`, text, Optional): Enter the category for the scholarship program. This field provides further classification for the program.
* **Description (Description)** (`Description`, text, Optional): Enter a detailed description of the scholarship program. This field provides a comprehensive understanding of the program.
* **Output File (Output File)** (`Output File`, text, Optional): Indicate the output file related to this program. This field helps the committee understand the expected output or results.
* **Form Notes 2 (Form Notes 2)** (`Form Notes 2`, text, Optional): This field is for providing extra comments or notes related to the form.
* **Category (Category)** (`Category`, select_one, Required): Select the category for the scholarship program (Education or Other).
* **Form Description (Form Description)** (`Form Description`, text, Optional): Enter a detailed description of the scholarship program.
* **Output File 2 (Output File 2)** (`Output File 2`, text, Optional): Indicate the output file for this scholarship program.
* **Form Notes 3 (Form Notes 3)** (`Form Notes 3`, text, Optional): This field is for providing extra comments or notes related to the form.

## Tips
* Ensure that you have a valid reason for requesting the expansion and that the program you are requesting is not already active or has an existing expansion request in progress.
* Fill out all fields accurately and thoroughly to ensure efficient processing of your request.
* Review all fields before submitting the form to ensure that your request is complete and accurate.
