# Creation Archiving Form - Help Guide

## Purpose
This form is used to collect information and metadata for the creation and archiving of items. It captures essential details such as the creation date, description, category, keywords, and tags related to the item, as well as information about the item's creator and archivist, including their department and contact details. This form helps ensure that all relevant information is accurately recorded and easily accessible for future reference.

## How To Complete This Form
To complete this form, follow these steps:

* Review the form carefully to understand the required and optional fields.
* Fill in the required fields (if any).
* Select relevant options from the dropdown menus for fields such as category and additional file type.
* Enter text descriptions for fields such as description, keywords, and archivist notes.
* Upload any necessary additional files, such as images, videos, or audio files.
* Review your entries for accuracy and completeness before submitting the form.

## Field-by-Field Explanation

* **Creation Date** (`creation_archiving_form_creation_date`, date): Enter the date when the item was created.
* **Description** (`creation_archiving_form_description`, text, optional): Provide a brief description of the item.
* **Creator** (`creation_archiving_form_creator`, text, optional): Enter the name or username of the item's creator.
* **Category** (`creation_archiving_form_category`, select one, optional): Select a category for the item from the options: Art, Science, Other.
* **Keywords** (`creation_archiving_form_keywords`, select multiple, optional): Select one or more relevant keywords for the item from the options: Art, Science, Technology, Other.
* **Tags** (`creation_archiving_form_tags`, select multiple, optional): Select one or more relevant tags for the item from the options: Art, Science, Technology, Other.
* **Image** (`creation_archiving_form_image`, text, optional): Enter the URL or file path of the item's image.
* **Video** (`creation_archiving_form_video`, text, optional): Enter the URL or file path of the item's video.
* **Audio** (`creation_archiving_form_audio`, text, optional): Enter the URL or file path of the item's audio.
* **Document** (`creation_archiving_form_document`, text, optional): Enter the URL or file path of the item's document.
* **Additional file** (`creation_archiving_form_additional_file`, text, optional): Upload an additional file related to the item.
* **Additional File Type** (`creation_archiving_form_additional_file_type`, select one, optional): Select the type of additional file from the options: pdf, mp3, mp4, image.
* **Archivist** (`creation_archiving_form_archivist`, text, optional): Enter the name or username of the archivist.
* **Department** (`creation_archiving_form_archivist_department`, text, optional): Enter the department of the archivist.
* **Archivist Email** (`creation_archiving_form_archivist_email`, email, optional): Enter the email address of the archivist.
* **Archivist Phone** (`creation_archiving_form_archivist_phone`, text, optional): Enter the phone number of the archivist.
* **Archivist Notes** (`creation_archiving_form_archivist_notes`, note, optional): Enter any additional notes or comments from the archivist.
