# online-physio-course-registration-form - Help Guide
## Purpose
This form allows users to register for online physio courses. Users must provide their user and contact information, select a course, and provide specific details about the course start date and duration.

## How To Complete This Form
To complete this form, follow these steps:
1. Fill in your user information on page 1.
2. On page 2, fill in your contact information and select the course you wish to register for.
3. On page 3, select the start date and duration of the course.

## Field-by-Field Explanation
* **User info** (User info, Text, Required): Enter your name and other user details as required.
* **Contact info** (Contact info, Text, Required): Enter your contact information, including any relevant details that can be used to contact you.
* **Select course** (Select course, Select Multiple, Optional): Choose the course you wish to register for. You can select multiple courses if you wish.
* **Start date** (Start date, Date, Required): Choose the start date of the course you wish to register for.
* **Duration** (Duration, Number, Required): Enter the duration of the course you wish to register for.
* **Time** (Time, Time, Optional): Select the time of the course you wish to register for. This field is not required, but can be useful for planning purposes.
* **Note** (Note, Note, Optional): Enter any additional note about the course you wish to register for.
* **Submit** (Submit, Text, Required): Click this button to submit your registration information.

## Tips
Please ensure that you fill in all required fields before submitting the form. The "Select course" field is optional, but selecting "No" will prevent you from registering for any course.
