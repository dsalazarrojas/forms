# Student Media Network Feedback - Help Guide
## Purpose
The Student Media Network Feedback form is designed to allow students to provide feedback on the media services provided by K-State. This feedback helps the media team understand what content is preferred, what content is missing, and areas for improvement.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the relevant media categories (newspaper, TV, radio, podcasts) that you want to provide feedback on.
2. Indicate your preferred content types (News, Entertainment, Sports).
3. Rate your satisfaction with the current media content.
4. Provide any additional suggestions or comments.

## Field-by-Field Explanation

* **General Information** (`general_info`, text, required): Enter a brief description of your feedback.
* **Newspapers** (`newspaper`, select_multiple, required): Select all the newspapers that you regularly read or would like to see more content from (e.g., The Collegian).
* **TV** (`television`, select_multiple, required): Select all the TV stations that you regularly watch or would like to see more content from (e.g., K-State 24/7).
* **Digital Channels** (`digital_channels`, select_multiple, optional): Select all the digital channels that you regularly use or would like to see more content from (e.g., K-State Today).
* **Radio** (`radio`, select_multiple, required): Select all the radio stations that you regularly listen to or would like to see more content from (e.g., K-State Media Network Radio).
* **Podcasts** (`podcasts`, select_multiple, required): Select all the podcasts that you regularly listen to or would like to see more content from (e.g., K-State Podcast).
* **Content Preferences** (`content_preferred`, select_multiple, required): Indicate your preferred content types (e.g., News, Entertainment, Sports).
* **Satisfaction Rating** (`satisfaction_rating`, number, required): Rate your satisfaction with the current media content on a scale from 1-5.
* **Suggestions** (`suggestions`, text, optional): Provide any additional suggestions or comments about the media services.
