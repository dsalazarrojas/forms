# Physics Exam Checklist - Help Guide

## Purpose
This form is designed to help collect information for a physics exam, including student details, exam dates and times, materials needed, rules to be followed, and confirmations from both students and teachers.

## How To Complete This Form
- Please fill out the form accurately and honestly for each field.
- Ensure that all required fields are filled before submitting.
- If a field is not applicable, please leave it blank.
- Double-check that you have filled out all required and optional fields.

## Field-by-Field Explanation
- **Student Information** (`Student Information`, text, required/optional): This section is meant for students to provide basic information about themselves.
- **Test Date** (`Test Date`, date, optional): This field is for recording the date of the physics exam.
- **Test Time** (`Test Time`, time, optional): This field is for recording the time of the physics exam.
- **Material Request** (`Material Request`, text, required/optional): List any materials that students might need for the exam.
- **Rule Acknowledgement** (`Rule Acknowledgement`, text, optional): Read and agree to the rules set for the exam, if any.
- **Special Requirements** (`Special Requirements`, text, optional): List any special requirements for the exam.
- **Student Confirmation** (`Student Confirmation`, text, required/optional): Confirm that all information provided is true.
- **Teacher Confirmation** (`Teacher Confirmation`, text, required/optional): Confirm that all information provided is true from the teacher's end.
