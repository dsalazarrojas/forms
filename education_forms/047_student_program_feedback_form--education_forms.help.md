# Student Program Feedback Form - Help Guide
## Purpose
The Student Program Feedback Form is a tool for students who have completed a student program to share their feedback and experiences with the program. This feedback will help the program organizers to improve and better serve students in the future.

## How To Complete This Form
To complete the form, simply fill out the form sections one by one. Start by filling out section 1, which asks for the name of the student program you are providing feedback on. Then, move on to section 2 and fill out your name as a student. After that, you will find more fields to complete.

## Field-by-Field Explanation
* **Student Program Name** (`student_program_name`, text, required: false): Please enter the name of the student program you are providing feedback on. If you are not sure, type the name of the program as it appears on our website.
* **Program Name** (`program_name`, text, required: false): This field is not required, but if you'd like to include a specific program name in your feedback, you can do so.
* **Student Name** (`student_name`, text, required: false): This is your name as a student. Please make sure it's correct so we can contact you for more feedback if needed.
* **Feedback Text** (`feedback_text`, text, required: false): In this field, please write any feedback or comments you have about your experience in the program. This can include positive or negative comments, and will help us improve the program.
* **Date Completed** (`date_completed`, date, required: false): If you're able to recall, please provide the date you completed the program. This helps us track the feedback over time.
* **Program Rating** (`program_rating`, number, required: false): This is an optional rating to give us an idea of your overall satisfaction with the program. Please choose one of the four options (Very Satisfying, Somewhat Satisfying, Somewhat Unsatisfying, Very Unsatisfying).
* **Would Recommend** (`would_recommend`, select_multiple, required: false): Let us know if you would recommend this program to others. You can choose 'Yes', 'No', or 'Undecided' depending on your experience.

## Tips
* Please be as specific as possible when writing your feedback, so we can act on it.
* If you have any concerns or suggestions, make sure to include them in the feedback text field.
* If you are not sure about something, or have any questions, feel free to contact us.
