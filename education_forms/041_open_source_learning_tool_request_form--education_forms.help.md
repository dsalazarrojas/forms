# open_source_learning_tool_request_form - Help Guide
## Purpose

The open-source learning tool request form is designed to gather information from users about potential open-source learning tools they are interested in. This form helps us understand what types of tools users are looking for and what features they require.

## How To Complete This Form

1. Select a category for the tool you are interested in.
2. Enter a brief description of the tool.
3. Enter the name of the tool.
4. Enter your contact email (optional).
5. Provide any additional notes or comments (optional).
6. Submit the form.

## Field-by-Field Explanation

* **Category** (`category`, select_one, required): Choose the category that best fits the tool you are interested in. This will help us understand which type of tool you are looking for.
* **Tool Description** (`description`, text, optional): Enter a brief description of the tool you are interested in. This can include its features, benefits, and any specific requirements you have.
* **Tool Name** (`tool_name`, text, optional): Enter the name of the tool.
* **Contact Email** (`email`, email, optional): Enter your email address so we can contact you for further discussion.
* **Notes** (`note`, note, optional): Provide any additional notes or comments about the tool.
* **Submit** (`submit`, select_multiple, required): Select the option to submit the form.

Note: Please do not fill out this form if you are looking for a tool that is already available or has been previously requested. This form is intended for new and innovative ideas.
