# Open Source Education Tool Adoption Survey - Help Guide
## Purpose
The purpose of this survey is to gather information about the open source education tools used in your educational institution.

## How To Complete This Form
To complete this form, please follow these steps:

1. Please answer all the questions truthfully, as much as possible.
2. Please make sure to answer all the required questions (marked as `required: true` in the form).
3. You can skip questions that are not relevant to your context.
4. If you have any questions or concerns, please contact us.
