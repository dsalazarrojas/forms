# LEAP Scholarship Application - Help Guide
## Purpose
The "LEAP Scholarship Application" form is designed to collect information from individuals applying for a scholarship. The form is composed of multiple pages, each with its own set of questions or fields that are used to determine eligibility and gather necessary documents.

## How To Complete This Form
To complete the "LEAP Scholarship Application" form, please follow these steps:

1. Answer the questions on each page, providing as much detail as possible. Make sure to review each page carefully before proceeding.
2. For text fields, type your answer directly into the provided boxes. For select fields, choose the most accurate response from the options provided.
3. Upload any required documents as instructed on the upload_documents page.
4. Review each page carefully to ensure all required fields are completed.
