# virtual_education_fair_form - Help Guide
## Purpose
The Virtual Education Fair Form is designed to collect information for virtual education events, including organizer and attendee details, event information, and session specifics.

## How To Complete This Form
1. Fill in the required fields, which are marked with an asterisk (\*).
2. Enter the organizer's email address in the "Organizer Email" field.
3. Select the event date in the "Event Date" field (optional).
4. Enter the event time in the "Event Time" field (optional).
5. Enter the event location in the "Event Location" field (required).
6. Enter the attendee's name in the "Attendee Name" field (optional).
7. Enter the attendee's email address in the "Attendee Email" field (required).
8. Enter the attendee's institution in the "Institution" field (optional).
9. Enter the institution representative's name in the "Institution Representative" field (optional).
10. Enter the institution's email address in the "Institution Email" field (required).
11. Enter the event link in the "Event Link" field (required).
12. Enter the label for the event link in the "Event Link Label" field (optional).
13. Select the type of event link in the "Event Link Type" field (optional, with options: url, pdf, link, external).
14. Enter the session ID in the "Session ID" field (optional).
15. Enter the session name in the "Session Name" field (required).
16. Enter the session time in the "Session Time" field (optional).
17. Enter the event start date in the "Event Start" field (optional).
18. Enter the event end date in the "Event End" field (optional).
19. Enter an alternative location if different from the main event location in the "Event Location (Other)" field (optional).
19. Enter a description for the event link in the "Event Link Description" field (optional).

## Field-by-Field Explanation

* **Organizer Email**: Enter the email address of the event organizer. (required)
* **Event Date**: Enter the date of the event (optional).
* **Event Time**: Enter the time of the event (optional).
* **Event Location**: Enter the location where the event will take place (required).
* **Attendee Name**: Enter the name of the person attending the event (optional).
* **Attendee Email**: Enter the email address of the person attending the event (required).
* **Institution**: Enter the name of the institution the attendee is representing (optional).
* **Institution Representative**: Enter the name of the representative of the institution (optional).
* **Institution Email**: Enter the email address of the institution (required).
* **Event Link**: Enter the URL or link to the event (required).
* **Event Link Label**: Enter a label for the event link (optional).
* **Event Link Type**: Select the type of event link (optional, with options: url, pdf, link, external).
* **Session ID**: Enter the ID of the session (optional).
* **Session Name**: Enter the name of the session (required).
* **Session Time**: Enter the time of the session (optional).
* **Event Start**: Enter the start date of the event (optional).
* **Event End**: Enter the end date of the event (optional).
* **Event Location (Other)**: Enter an alternative location for the event (optional).
* **Event Link Description**: Enter a description of the event link (optional).
