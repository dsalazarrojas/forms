# Teacher Cadet Tutors 2020 - Help Guide
## Purpose
This form is designed to gather feedback from teachers on whether they have tutored students who are teacher cadets in 2020.

## How To Complete This Form
To complete this form, follow these steps:

1. Please select whether you tutored any teacher cadets in 2020.
2. If you selected "Yes" in the first question, please select the category of teacher cadets you tutored (Bahamas or Other).
3. If you have any additional comments or details about your experience, please type them in the text field.

## Field-by-Field Explanation

* **Teacher Cadets in 2020** (`teacher_cadet_tutors_2020`, `select_multiple`, required/optional): Please select whether you tutored any teacher cadets in 2020. If you did not tutor any, please select "No".
* **Category** (`teacher_cadet_tutors_2020_category`, `select_one`, optional): If you selected "Yes" for the first question, please select the category of teacher cadets you tutored. If you selected "No", this field is not relevant.
* **Comments** (`teacher_cadet_tutors_2020_description`, `text`, optional): Please use this field to provide any additional comments or details about your experience tutoring teacher cadets in 2020.
* **Form ID** (`teacher_cadet_tutors_2020_form_id`, `number`, optional): This field is not currently in use, but it may be used in the future for tracking purposes.

## Tips

* Please only complete this form if you have tutored students who are teacher cadets in 2020.
* If you have any questions or concerns about this form, please contact the form administrator.
