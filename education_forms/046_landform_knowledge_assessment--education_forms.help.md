# landform_knowledge_assessment - Help Guide
## Purpose
The purpose of this form is to collect information about different types of landforms, including their characteristics and features.

## How To Complete This Form
1. Select the correct type of landform from the options provided in the "Which landform is this?" field.
2. Answer the questions about the landform's features and attributes in the "Answer this question" field.
3. Select the correct options for the landform's type, features, and attributes in the respective fields.
