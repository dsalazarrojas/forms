# Project Intake Form - Help Guide
## Purpose
The Project Intake Form is used to collect information about a project, including its name, description, budget, timeline, status, personnel, and location.

## How To Complete This Form
To complete the form, follow these steps:
1. Enter the project name in the "Project Name" field.
2. Briefly describe the project in the "Project Description" field.
3. Estimate the project budget in the "Estimated Budget" field.
4. Enter the project start and end dates in the "Project Start Date" and "Project End Date" fields, respectively.
5. Select the current project status (Open, Closed, or In Progress) in the "Project Status" field.
6. Enter the name of the project manager in the "Project Manager" field.
7. Select the department responsible for the project (Department A, Department B, or Department C) in the "Department" field.
8. Provide the location of the project (e.g., campus or building) in the "Location" field.

## Field-by-Field Explanation
* **Project Name** (required): Enter a brief and descriptive name for the project.
* **Project Description** (optional): Briefly describe the project.
* **Estimated Budget** (optional): Estimate the total budget for the project.
* **Project Start Date** (optional): Enter the start date of the project.
* **Project End Date** (optional): Enter the end date of the project.
* **Project Status** (optional): Select the current status of the project (Open, Closed, or In Progress).
* **Project Manager** (optional): Enter the name of the project manager.
* **Department** (optional): Select the department responsible for the project (Department A, Department B, or Department C).
* **Location** (optional): Enter the location of the project (e.g., campus or building).

## Tips
* Make sure to fill out all required fields.
* Double-check the estimated budget to ensure accuracy.
* Enter specific and accurate dates for the project start and end dates.
* Select the correct project status and department.
* Enter a detailed location (e.g., campus or building) to aid in project tracking and coordination.
