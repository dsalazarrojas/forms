# Project Planning Form - Help Guide

## Purpose
The project planning form is used for creating new projects or editing existing ones. It captures essential information about the project, including the project lead, name, start and end dates, status, and other relevant details.

## How To Complete This Form
To complete this form:

1. Fill out the project name, start and end dates, and status fields as required.
2. Select the project lead and their email address (if applicable).
3. Choose the project category and lead status (if applicable).
4. Ensure all fields are filled out accurately and correctly.
