# School Directory Form - Help Guide
## Purpose
This form is used to collect and store information about schools, students, and their families. The form will help us understand the demographic details of each student and their family, enabling us to better serve and support them.

## How To Complete This Form
To complete this form, follow these steps:

1.  Review each field carefully and enter accurate information for each student and their family.
2.  Make sure to fill out each field with the most up-to-date information available.
3.  Double-check your entries for accuracy before submitting the form.

## Field-by-Field Explanation

* **family_name** (Text): This field is for the student's family name. Please enter the name of the student's family.
* **school_name** (Text): This field is for the name of the school where the student is currently attending. Please enter the name of the school.
* **student_name** (Text): This field is for the student's name. Please enter the student's name.
* **grade_level** (Text): This field is for the student's grade level. Please enter the student's current grade level (Elementary, Middle, High, or College).
* **family_income** (Number): This field is for the family's income. Please enter the family's income.
* **student_age** (Number): This field is for the student's age. Please enter the student's age.
* **school_email** (Email): This field is for the school's email address. Please enter the school's email address.
* **phone_number** (Text): This field is for the school's phone number. Please enter the school's phone number.
* **family_phone** (Text): This field is for the family's phone number. Please enter the family's phone number.
* **address** (Text): This field is for the school's address. Please enter the school's address.
* **student_email** (Email): This field is for the student's email address. Please enter the student's email address.
* **student_phone** (Text): This field is for the student's phone number. Please enter the student's phone number.
* **family_member_type** (Select Multiple): This field is for the type of family member. Please select one or more of the following: Mother, Father, Guardian, or Other.
* **student_grade_level** (Select One): This field is for the student's grade level. Please select one of the following: Elementary, Middle, High, or College.
* **school_start_date** (Date): This field is for the date the school started. Please enter the date the school started.
* **school_end_date** (Date): This field is for the date the school ended. Please enter the date the school ended.
* **student_start_date** (Date): This field is for the date the student started attending school. Please enter the date the student started attending school.
* **student_end_date** (Date): This field is for the date the student ended attending school. Please enter the date the student ended attending school.
* **note** (Note): This field is for additional notes about the student or family. Please enter any relevant notes.
* **family_note** (Note): This field is for additional notes about the family. Please enter any relevant notes.
* **student_status** (Select One): This field is for the student's status. Please select one of the following: Active, Inactive, Suspended, or Withdrawn.
* **family_status** (Select One): This field is for the family's status. Please select one of the following: Active, Inactive, Suspended, or Withdrawn.
* **student_language** (Select One): This field is for the student's native language. Please select one of the following: English, Spanish, French, or Other.
* **family_language** (Select One): This field is for the family's native language. Please select one of the following: English, Spanish, French, or Other.
* **assigned_user** (Select One): This field is for the user assigned to the student's directory. Please select one of the following: chatjimmy, other.

## Tips
* Please make sure to review each field carefully before submitting the form to ensure accurate and up-to-date information.
* If you're unsure about any field, please contact the relevant authorities or seek clarification before completing the form.
* This form is designed to collect information about students and families; if you're submitting on behalf of someone, make sure to have their consent before doing so.
