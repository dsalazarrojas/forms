# School Event Registration Form - Help Guide
## Purpose
The School Event Registration Form is used to collect information about school events. This form is meant for registering events related to schools.

## How To Complete This Form
To complete this form, follow these steps:

1.  Enter your first name in the "First Name" field.
2.  Enter your last name in the "Last Name" field.
3.  Enter your school's ID in the "School ID" field.
4.  Select the date of the event from the calendar in the "Date" field.
5.  Choose the time of the event from the available options in the "Time" field.
6.  Select the category of the event from the options provided in the "Category" field.
7.  Enter your email address in the "Email" field.
8.  Enter your phone number in the "Phone" field.
9.  Enter the name of the school event in the "School Event Name" field.
10. Enter a brief description of the event in the "School Event Description" field.
11. Choose the start time of the event from the available options in the "Event Start Time" field.
12. Choose the end time of the event from the available options in the "Event End Time" field.
13. Enter the date of the event in the "Event Date" field.

## Field-by-Field Explanation

*   **First Name** (`first_name`, text, required): Enter your first name.
*   **Last Name** (`last_name`, text, required): Enter your last name.
*   **School ID** (`school_id`, number, required): Enter your school's ID number.
*   **Date** (`date`, date, required): Select the date of the event using the calendar provided.
*   **Time** (`time`, time, required): Choose the time of the event from the available options.
*   **Category** (`category`, select_one, required): Select the category of the event from the options provided.
*   **Email** (`email`, email, required): Enter your email address associated with the school or event.
*   **Phone** (`phone`, text, required): Enter a valid phone number for the school or event.
*   **School Event Name** (`school_event_name`, text, required): Enter the name of the event.
*   **School Event Description** (`school_event_description`, text, required): Enter a brief description of the event.
*   **Event Start Time** (`event_start_time`, time, required): Choose the start time of the event from the available options.
*   **Event End Time** (`event_end_time`, time, required): Choose the end time of the event from the available options.
*   **Event Date** (`event_date`, date, required): Enter the date of the event.

Note: Each field is marked as required or optional, please respect these indications for accurate data submission.
