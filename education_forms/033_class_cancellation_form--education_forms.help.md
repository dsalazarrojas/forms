# Class Cancellation Form - Help Guide
## Purpose
This form is used for class cancellations. Please ensure that you are using it for the correct reason and that you have the necessary permissions and approvals before proceeding.

## How To Complete This Form
To complete this form, start from the first field and fill it out completely before proceeding to the next. Each field is essential to providing a comprehensive cancellation report.

## Field-by-Field Explanation
* **Teacher or Instructor Name** (`teacher_name`, text, required): Please enter the full name of the instructor or teacher cancelling the class.
* **Email Address** (`teacher_email`, email, required): Enter the email address associated with the school's email system or your personal email. This will help the students receive updates and notifications about the class cancellation.
* **Phone Number** (`teacher_phone`, text, optional): Provide the phone number where students can contact you regarding the class cancellation. This is not required but may help with communication.
* **Department or Division** (`department`, text, optional): Enter the department or division name where the class belongs.
* **Class or Course Name** (`class_name`, text, required): Type the class or course name (e.g., Mathematics 101) being cancelled.
* **Section Number** (`class_section`, text, optional): If the class has sections, enter the section number to identify it specifically.
* **Course Code** (`class_code`, text, optional): Enter the course code for the class (e.g., MATH101-001).
* **Original Class Date** (`original_date`, date, required): Enter the date the class was originally scheduled.
* **Original Class Time** (`original_time`, time, required): Enter the original scheduled time of the class.
* **Type of Cancellation** (`cancellation_type`, select_one, required): Select the reason for the cancellation from the available options.
* **Reason for Cancellation** (`cancellation_reason`, select_one, required): Select the reason for the cancellation from the provided options.
* **Additional Details** (`reason_details`, text, optional): If you need to provide further information about the cancellation, this is the field to use.
* **Rescheduled Date** (`reschedule_date`, date, optional): If you're rescheduling the class, enter the new date. Leave this field blank if not rescheduling.
* **Rescheduled Time** (`reschedule_time`, time, optional): Enter the new time of the rescheduled class if rescheduling.
* **Rescheduled Location** (`reschedule_location`, text, optional): If you're changing the location, provide the new location details.
* **Is a Makeup Class Required** (`makeup_class_required`, select_one, required): Choose whether a makeup class is required or not.
* **Will There Be an Alternative Assignment** (`alternative_assignment`, select_one, required): Select whether students will be given an alternative assignment or not.
* **Assignment Details** (`assignment_details`, text, optional): Describe the alternative assignment or provide additional details.
* **How Will Students Be Notified** (`notification_method`, select_multiple, required): Choose all the methods to be used for student notification.
* **Has Notification Been Sent** (`notification_sent`, select_one, required): Report whether the student notification has been sent or not.
* **Has Your Supervisor Been Notified** (`supervisor_notified`, select_one, required): Report whether your supervisor has been informed about the cancellation.
* **Additional Comments or Instructions** (`additional_comments`, text, optional): Use this field for any additional comments or instructions that may be necessary for students or the administration.
