# Online Exam Result Submission Form Template - Help Guide

## Purpose

This form is used to record the results of online exams, including student data, exam results, and other relevant information. It's essential to complete this form accurately to ensure that the exam results are recorded correctly.

## How To Complete This Form

1. Fill out the form with the required information, including student data, exam result, submission date, examiner comments, and other relevant details.
2. Select the correct options for "E-signature" and "Examiner Position".
3. Ensure that you complete all required fields (marked as "required") before submitting the form.
4. Review your entries carefully before submitting the form to ensure accuracy and completeness.

## Field-by-Field Explanation

### Page 1: Exam Submission Form

* **Exam Submission Form** (`exam_submission_form`, text, false): This field is a placeholder for any additional comments or information about the exam submission. You can add any relevant details here.

### Page 2: Student Data

* **Student Data** (`student_data`, text, false): Enter the student's name, date of birth, or any other relevant information about the student.

### Page 3: Exam Result

* **Exam Result** (`exam_result`, text, true): Enter the student's exam score or result.

### Page 4: Submission Date

* **Submission Date** (`submission_date`, date, true): Enter the date and time the exam was submitted.

### Page 5: Examiner Comments

* **Examiner Comments** (`examiner_comments`, text, false): Add any comments or feedback from the examiner about the exam.

### Page 6: E-signature

* **E-signature** (`e_signature`, select_multiple, true): Select one of the options to indicate the type of E-signature used.
	+ Option 1: Option 1
	+ Option 2: Option 2
	+ Option 3: Option 3

### Page 7: Examiner Name

* **Examiner Name** (`examiner_name`, text, true): Enter the name of the examiner who administered the exam.

### Page 8: Examiner Position

* **Examiner Position** (`examiner_position`, select_one, true): Select the examiner's position.
	+ Option 1: Option 1
	+ Option 2: Option 2
	+ Option 3: Option 3
	+ Option 4: Option 4

### Page 9: School Name

* **School Name** (`school_name`, text, true): Enter the name of the school where the exam was administered.

### Page 10: Exam Score

* **Exam Score** (`exam_score`, number, true): Enter the student's exam score.

## Tips

* Ensure that you complete all required fields (marked as "required").
* Review your entries carefully before submitting the form to ensure accuracy and completeness.
* Use the correct format for the "Submission Date" field (MM/DD/YYYY).
* If you have any doubts or questions, contact your exam administrator for assistance.
