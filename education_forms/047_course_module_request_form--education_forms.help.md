# Course Module Request Form - Help Guide
## Purpose
The Course Module Request Form is used to request a new course module for approval.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill in the required fields as follows:
	* Enter the **Course Module Name**: This is the title of the course module you wish to request.
	* Enter the **Course Module Code**: This is a unique identifier for the course module.
	* Select the **Module Type** from the dropdown menu.
2. Select the optional fields as needed:
	* **Module Level**: Choose the level at which the module will be offered.
	* **Course Credits**: Enter the number of credits associated with the module.
	* **Start Date**: Enter the date when the module will start.
	* **End Date**: Enter the date when the module will end.
	* **Status**: Select the current status of the module (Active, Pending, or Archived).
3. Add any additional information as needed in the **Description** field.

## Field-by-Field Explanation
* **Course Module Name**: Enter the name of the course module.
* **Course Module Code**: Enter a unique identifier for the course module.
* **Module Type**: Select the type of module you are requesting (e.g., Option 1, Option 2, Option 3).
* **Module Level**: Choose the level at which the module will be offered (Option 1, Option 2, Option 3).
* **Course Credits**: Enter the number of credits associated with the module.
* **Start Date**: Enter the date when the module will start.
* **End Date**: Enter the date when the module will end.
* **Status**: Select the current status of the module (Active, Pending, or Archived).
* **Description**: Enter a description of the module to provide additional context.
* **Review Comments**: Enter any review comments or feedback about the module. 

## Tips
* Please ensure that you fill in all required fields to ensure that your request is processed correctly.
* Use clear and concise language in the **Description** field to provide a good understanding of the module.
* Review the **Review Comments** field for any feedback or suggestions from reviewers.
