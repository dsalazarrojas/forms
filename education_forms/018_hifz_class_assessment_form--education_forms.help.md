# hifz_class_assessment_form - Help Guide
## Purpose
The hifz_class_assessment_form is a tool used to assess and report progress of a class in an educational or training context. It helps track the start date, duration, number of participants, and other metrics that contribute to the class's progress.

## How To Complete This Form
To complete this form, follow these steps:
- Fill out each field with the relevant information.
- For select_multiple and select_one fields, choose one or multiple options that apply to your class.
- For date fields, enter the date in the correct format (YYYY-MM-DD).
- For email fields, enter a valid email address.
- For text fields, enter any additional notes or comments about the class.
- Review your form to ensure all required fields are filled out.

## Field-by-Field Explanation

* **Class Progress** (`hifz_class_progress`, number, not required): This field is for entering the progress of the class.
* **Participants** (`hifz_class_participants`, select_multiple, not required): Select one or multiple students that are participating in the class.
* **Start Date** (`hifz_class_start_date`, date, not required): Enter the start date of the class in the format YYYY-MM-DD.
* **Duration** (`hifz_class_duration`, number, not required): This field is for entering the duration of the class.
* **Assessment Frequency** (`hifz_class_assessment_frequency`, select_one, not required): Choose how frequently the class is assessed.
	+ Every week: Assess every week.
	+ Quarterly: Assess at the end of each quarter.
	+ Monthly: Assess at the end of each month.
* **Total Sheets Assessed** (`hifz_class_total_sheets_assessed`, number, not required): Enter the total number of sheets assessed.
* **Total Corrected** (`hifz_class_total_corrected`, number, not required): Enter the total number of corrected sheets.
* **Assessments** (`hifz_class_assessments`, select_multiple, not required): Select one or multiple assessment types.
	+ Corrected: The assessment was corrected.
	+ Partially Corrected: The assessment was partially corrected.
	+ Not Corrected: The assessment was not corrected.
* **Progress** (`hifz_class_progress_percent`, number, not required): Enter the progress of the class as a percentage.
* **Note** (`hifz_class_note`, note, not required): Enter any additional notes or comments about the class.
* **Email** (`hifz_class_email`, email, not required): Enter the email address of the person responsible for the class.
* **Phone** (`hifz_class_phone`, text, not required): Enter the phone number of the person responsible for the class.
* **Address** (`hifz_class_address`, text, not required): Enter the address of the person responsible for the class.

## Tips

* If you're unsure about any of the fields, refer back to the purpose and explanation of the form.
* Fill out the form as accurately and thoroughly as possible to ensure the progress of the class is accurately reported.
