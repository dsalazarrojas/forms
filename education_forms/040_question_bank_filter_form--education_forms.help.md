# Question Bank Filter Form - Help Guide
## Purpose
The Question Bank Filter Form is a tool used to filter and search through the question bank to find specific questions based on various criteria.
## How To Complete This Form
To complete this form, follow these steps:

1. Select a subject area from the dropdown list.
2. Choose a grade level for the questions you want to search for.
3. Select the type of question you are looking for (e.g., single choice, multiple choice, etc.).
4. If necessary, specify a question bank ID to narrow down your search results.
5. You can also add a search term to search for questions that contain specific keywords.
6. Finally, select any relevant subject areas, grade levels, instruction levels, and subject areas IDs to further filter your search results.

## Field-by-Field Explanation
### Subject Area
* **Subject Area** (`subject_area`, `select_one`, required: false): Select a subject area from the dropdown list to narrow down your search results to questions within that specific subject area.

### Grade Level
* **Grade Level** (`grade_level`, `select_one`, required: false): Choose a grade level to filter search results to questions suitable for that grade level.

### Type of Question
* **Type of Question** (`type_of_question`, `select_multiple`, required: false): Select the type of question you are looking for, such as single choice or multiple choice.

### Question Type
* **Question Type** (`question_type`, `select_multiple`, required: false): Select the type of question you are looking for, such as multiple choice or true/false.

### Question Bank ID
* **Question Bank ID** (`question_bank_id`, `number`, required: false): If you know the ID of a specific question bank, you can enter it here to search for questions within that bank.

### Search Term
* **Search Term** (`search_term`, `text`, required: false): Add a search term to search for questions that contain specific keywords.

### Subject Areas
* **Subject Areas** (`subject_areas`, `select_multiple`, required: false): Select relevant subject areas to further filter search results.

### Grade Levels
* **Grade Levels** (`grade_levels`, `select_multiple`, required: false): Select relevant grade levels to further filter search results.

### Instructional Level IDs
* **Instructional Level IDs** (`instruction_level_ids`, `select_multiple`, required: false): Select relevant instructional level IDs to further filter search results.

### Subject Areas IDs
* **Subject Areas IDs** (`subject_areas_ids`, `select_multiple`, required: false): Select relevant subject areas IDs to further filter search results.

### Grade Level IDs
* **Grade Level IDs** (`grade_level_ids`, `select_multiple`, required: false): Select relevant grade level IDs to further filter search results.

## Tips
* You can select multiple options for each field if necessary.
* Use the search term to search for questions that contain specific keywords.
* You can use the filter form multiple times to narrow down your search results.
* Make sure to select relevant fields to ensure accurate search results.
