# Education Systems Design Project Application Form - Help Guide
## Purpose
This form is used to collect information about an education systems design project. The project details, team leadership, location, start and end dates, budget, description, status, supporting documents, comments, category, education level, and type are all essential components of the project.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the correct project details.
2. Choose the appropriate team leadership role.
3. Select the project location(s) that apply.
4. Enter the project start and end dates.
5. Enter the project budget.
6. Enter the project description.
7. Choose the project status.
8. Upload any supporting documents.
9. Add any additional comments.
10. Select the project category.
11. Choose the education level(s) that apply.
12. Select the project type.

## Field-by-Field Explanation

* **Project Details** (`project_details`, text, required: false): Enter a brief description of the project.
* **Team Leadership** (`team_leadership`, select_one, required: false): Select the type of team leadership involved in the project. Options:
	+ School/University Representative
	+ Project Team Lead
	+ Program Director
	+ Other (please specify)
* **Project Location** (`project_location`, select_multiple, required: false): Choose the location(s) where the project is taking place. Options:
	+ School/University
	+ Community
	+ Other (please specify)
* **Project Start Date** (`project_start_date`, date, required: false): Enter the start date of the project.
* **Project End Date** (`project_end_date`, date, required: false): Enter the end date of the project.
* **Project Budget** (`project_budget`, number, required: false): Enter the project budget.
* **Project Description** (`project_description`, text, required: false): Enter a detailed description of the project.
* **Project Status** (`project_status`, select_one, required: false): Choose the project status. Options:
	+ Active
	+ Completed
	+ Inactive
* **Supporting Documents** (`supporting_documents`, note, required: false): Upload any supporting documents related to the project.
* **Additional Comments** (`additional_comments`, text, required: false): Enter any additional comments about the project.
* **Project Category** (`project_category`, select_one, required: false): Select the category of the project. Options:
	+ Grant
	+ Innovation
	+ Design
* **Education Level** (`education_level`, select_multiple, required: false): Choose the education level(s) involved in the project. Options:
	+ High School
	+ University
	+ College
* **Project Type** (`project_type`, select_one, required: false): Select the type of project. Options:
	+ Design
	+ Innovation
	+ Development
