# Doctoral Program Completion Rate Report - Help Guide
## Purpose
This form is used to collect data on the completion rate of doctoral programs, including status, type, and other relevant details.

## How To Complete This Form
1. **Program Status**: Select the current status of the program. Choose between "Active" or "Inactive".
2. **Program Type**: Select all relevant program types that the program you are reporting on applies to. Choose between "Yes" or "No" for each type.
3. **Institution**: Enter the name of the institution where the program is located.
4. **Cohort**: Enter the cohort year of the program.
5. **Start Date**: Enter the start date of the program.
6. **End Date**: Enter the end date of the program.
7. **Completion Rate**: Enter the completion rate of the program as a percentage.
8. **Total Programs Completed**: Enter the total number of programs completed.
9. **Total Students Enrolled**: Enter the total number of students enrolled.
10. **Total Students Completed**: Enter the total number of students completed.
11. **Total Students Active**: Enter the total number of students active.
12. **Total Students Inactive**: Enter the total number of students inactive.
13. **Program Type Options**: Select all additional program types that apply.
14. **Institution Options**: Select all institutions that apply.
15. **Program Status Options**: Select all statuses that apply.
16. **Completion Rate Options**: Select all completion rate options.
17. **Start Date Options**: Select the start date option that applies.
18. **End Date Options**: Select the end date option that applies.
19. **Year 01**: Select the year 01 option that applies.
20. **Year 02**: Select the year 02 option that applies.
21. **Year 03**: Select the year 03 option that applies.
22. **Year 04**: Select the year 04 option that applies.
23. **Notes**: Enter any additional notes about the program.
24. **Email**: Enter your email address for contact.
