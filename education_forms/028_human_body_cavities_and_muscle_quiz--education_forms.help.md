# Human Body Cavities And Muscle Quiz - Help Guide
## Purpose
This form is designed to educate users about human body cavities and muscle attachment points. It is intended to test users' knowledge and understanding about the topics.

## How To Complete This Form
To complete this form, follow these steps:

1. Answer the multiple-choice questions with the correct options provided.
2. Describe the body cavities and muscle attachment points in the text fields.
3. Make sure to answer all required questions, as indicated by the "required" label.

## Field-by-Field Explanation

* **what_is_a_body_cavity** (Page 1):
	+ **Label:** what_is_a_body_cavity
	+ **Type:** text
	+ **Purpose:** Describe the definition of a body cavity. A body cavity is an empty space within the body that is lined with tissue or a membrane.
* **where_do_muscles_attach_to_bone** (Page 2):
	+ **Label:** where_do_muscles_attach_to_bone
	+ **Type:** select_one
	+ **Options:** chest, back, abdomen
	+ **Purpose:** Select where muscles attach to bones in the body. Muscles attach to bones through tendons.
* **describe_a_body_cavity** (Page 3):
	+ **Label:** describe_a_body_cavity
	+ **Type:** text
	+ **Purpose:** Describe a body cavity, e.g., the skull's cavity.
* **what_do_muscles_do** (Page 4):
	+ **Label:** what_do_muscles_do
	+ **Type:** text
	+ **Purpose:** Describe the function of muscles in the body, e.g., movement, support, etc.
* **what_parts_of_the_body_have_cavities** (Page 5):
	+ **Label:** what_parts_of_the_body_have_cavities
	+ **Type:** select_one
	+ **Options:** head, brain, heart
	+ **Purpose:** Select parts of the body that have cavities, e.g., skull, chest cavity.
* **what_parts_of_the_body_have_muscles** (Page 6):
	+ **Label:** what_parts_of_the_body_have_muscles
	+ **Type:** select_multiple
	+ **Options:** arms, legs, back, abdomen
	+ **Purpose:** Select parts of the body that have muscles, e.g., arms, legs, back, abdomen.
* **give_example_of_a_body_cavity** (Page 7):
	+ **Label:** give_example_of_a_body_cavity
	+ **Type:** text
	+ **Purpose:** Provide an example of a body cavity, e.g., the skull's cavity.
* **what_are_muscle_groups** (Page 8):
	+ **Label:** what_are_muscle_groups
	+ **Type:** text
	+ **Purpose:** Describe muscle groups, e.g., muscles in the arms, legs, etc.
* **describe_body_parts** (Page 9):
	+ **Label:** describe_body_parts
	+ **Type:** text
	+ **Purpose:** Describe parts of the body, e.g., the heart.
* **what_is_the_body_system** (Page 10):
	+ **Label:** what_is_the_body_system
	+ **Type:** select_one
	+ **Options:** nervous system, circulatory system, musculoskeletal system
	+ **Purpose:** Select the body system that the question is referring to, e.g., musculoskeletal system.
