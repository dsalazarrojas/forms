# Student Stress Survey - Help Guide
## Purpose
The Student Stress Survey is a tool designed to help us understand the levels of stress that students experience in various aspects of their lives. By completing this form, you will help us identify areas where students feel stressed and provide insight into the sources of this stress.

## How To Complete This Form
- Please answer each question truthfully and accurately.
- Choose the most relevant option for each question.
- Do not hesitate to ask if you have any questions or concerns.

## Field-by-Field Explanation

* **Student Stress Survey** (`student_stress_survey`, Note, Not Required): This is a brief overview of the survey. Please take your time to read the questions and instructions before proceeding.

* **Demographic Questions** (`demographic_questions`, Select Multiple, Not Required): Please answer "Yes" or "No" to the following question:
	+ Do you feel highly stressed by family and relationships? 
	+ Do you feel highly stressed by schoolwork and grades?
	+ Do you feel highly stressed by finances?
	+ Do you feel highly stressed by health and physical activity?
	+ Do you feel highly stressed by academic expectations?
	+ Do you feel highly stressed by social media?

* **How stressed do you feel?** (`stress_level`, Select One, Not Required): Please select one of the following options:
	+ Highly Stressed
	+ Moderately Stressed
	+ Slightly Stressed
	+ Not Stressed

* **What stressors affect you?** (`stressors`, Select Multiple, Not Required): Please choose the most relevant options from the list:
	+ Schoolwork and grades
	+ Family and relationships
	+ Finances
	+ Health and physical activity
	+ Academic expectations
	+ Social media
	+ Other (please specify)

* **Schoolwork and Grades** (`schoolwork_and_grades`, Select One, Not Required): Please select one of the following options:
	+ Highly Stressed
	+ Moderately Stressed
	+ Slightly Stressed
	+ Not Stressed

* **Family and Relationships** (`family_and_relationships`, Select One, Not Required): Please select one of the following options:
	+ Highly Stressed
	+ Moderately Stressed
	+ Slightly Stressed
	+ Not Stressed

* **Finances** (`finances`, Select One, Not Required): Please select one of the following options:
	+ Highly Stressed
	+ Moderately Stressed
	+ Slightly Stressed
	+ Not Stressed

* **Health and Physical Activity** (`health_and_physical_activity`, Select One, Not Required): Please select one of the following options:
	+ Highly Stressed
	+ Moderately Stressed
	+ Slightly Stressed
	+ Not Stressed

* **Academic Expectations** (`academic_expectations`, Select One, Not Required): Please select one of the following options:
	+ Highly Stressed
	+ Moderately Stressed
	+ Slightly Stressed
	+ Not Stressed

* **Social Media** (`social_media`, Select One, Not Required): Please select one of the following options:
	+ Highly Stressed
	+ Moderately Stressed
	+ Slightly Stressed
	+ Not Stressed

## Tips
