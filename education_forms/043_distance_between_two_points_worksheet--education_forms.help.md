# Distance Between Two Points Worksheet - Help Guide
## Purpose
This form is designed to calculate the distance between two points on a coordinate plane.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the x-coordinate of the first point in the `x1` field.
2. Enter the y-coordinate of the first point in the `y1` field.
3. Enter the x-coordinate of the second point in the `x2` field.
4. Enter the y-coordinate of the second point in the `y2` field.
5. Select the relevant option in the `option` field to specify the type of distance calculation you want to perform (e.g., Euclidean distance, Manhattan distance, etc.).
6. If necessary, select multiple options in the `option` field to specify additional calculation parameters.
7. Enter a date and time for the calculation, if required (e.g., for historical purposes).
8. Enter a phone number or email, if you want to associate with the calculation (e.g., for further contact).
9. Optionally, add a note for the calculation context or reference.

## Field-by-Field Explanation
* **x1** (`input_x1`, `number`, required: false): The x-coordinate of the first point.
* **x2** (`input_x2`, `number`, required: false): The x-coordinate of the second point.
* **y1** (`input_y1`, `number`, required: false): The y-coordinate of the first point.
* **y2** (`input_y2`, `number`, required: false): The y-coordinate of the second point.
* **distance** (`input_distance`, `number`, required: false): The calculated distance between the two points.
* **option** (`select_option`, `select_one`, required: false): Select the type of distance calculation you want to perform (e.g., Euclidean distance, Manhattan distance, etc.).
* **option** (`select_option`, `select_multiple`, required: true): Select additional calculation parameters (if applicable).
* **date** (`input_date`, `date`, required: false): The date for the calculation (if required).
* **time** (`input_time`, `time`, required: false): The time for the calculation (if required).
* **email** (`input_email`, `email`, required: false): Enter your email address for further contact (if required).
* **phone** (`input_phone`, `text`, required: false): Enter your phone number for further contact (if required).
* **note** (`input_note`, `note`, required: false): Add a note for the calculation context or reference (if required).
