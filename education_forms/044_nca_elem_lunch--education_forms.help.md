# NCA Elem Lunch - Help Guide
## Purpose
This form is used to collect information about student lunches, including meal type, food allergies, and other relevant details.

## How To Complete This Form
To complete this form, follow these steps:

1. Please fill in the required fields, which are marked with an asterisk (\*). 
   - Enter the Student ID to identify the student.
   - Select the Meal Type from the available options (Breakfast, Lunch, or Dinner).
   - Enter the Parent Name, which is also a required field.
   - Enter a valid Email address for the student and parent.
   - You may also enter additional information such as Food Allergies, Medical Conditions, Meal Notes, and Student Lunch Balance, if required.

## Field-by-Field Explanation
- **Elementary Lunch** (`text`, required/optional): This field is not applicable in this form as it only appears on the first page and is not a field to be filled. 
- **Student ID** (`number`, required): Enter the student's ID to identify them in the system.
- **School ID** (`text`, optional): This field is not required, but you can enter the school's ID for reference.
- **Student Name** (`text`, optional): Enter the student's name, if required.
- **Parent Name** (`text`, required): Enter the parent's name to ensure accurate communication.
- **Meal Type** (`select_one`, required): Select the type of meal being provided (Breakfast, Lunch, or Dinner).
- **Food Allergies** (`select_multiple`, optional): Select any food allergies the student has (Peanuts, Eggs, Gluten, or Other).
- **Medical Conditions** (`select_multiple`, optional): Select any medical conditions the student may have (None, Severe Allergy, Food Allergy, or Other).
- **Meal Notes** (`note`, optional): Add any relevant notes about the meal.
- **Food Notes** (`text`, optional): Enter any additional notes about the food provided.
- **Email** (`email`, required): Enter a valid Email address for the student and parent.
- **Phone** (`text`, optional): Enter the phone number of the student or parent, if required.
- **Address** (`text`, optional): Enter the student's home address, if required.
- **Student Email** (`email`, optional): Enter the student's email address, if required.
- **Parent Email** (`email`, optional): Enter the parent's email address, if required.
- **School Name** (`text`, optional): Enter the school name, if required.
- **School Address** (`text`, optional): Enter the school address, if required.
- **Teacher Name** (`text`, optional): Enter the teacher's name, if required.
- **Teacher Email** (`email`, optional): Enter the teacher's email address, if required.
- **Date** (`date`, optional): Enter the date of the meal, if required.
- **Time** (`time`, optional): Enter the time of the meal, if required.
- **Student Lunch Balance** (`number`, optional): Enter the student's lunch balance, if required.
- **Teacher Lunch Balance** (`number`, optional): Enter the teacher's lunch balance, if required.
- **School Lunch Balance** (`number`, optional): Enter the school's lunch balance, if required.
- **Total Lunch Balance** (`number`, optional): Enter the total lunch balance, if required.

## Tips
- Please ensure that all required fields are filled in.
- Double-check the accuracy of the information entered. 
- If any field is not applicable, do not enter anything for it. 
- The form can be filled in multiple pages, each with a different set of fields.
