# open_source_curriculum_testing_registration - Help Guide
## Purpose
This form is used for registering open-source curriculum tests. Users need to provide information about pilots, test versions, user identifiers, contact details, and test periods to complete the form.

## How To Complete This Form
To complete this form, follow these steps:
1. Enter the pilot name in the "Pilot Name" field.
2. Input the test version in the "Test Version" field.
3. Enter your user ID in the "User ID" field.
4. Provide your contact email in the "Contact Email" field.
5. Enter your contact phone number in the "Contact Phone" field.
6. Select the start date of the test period in the "Start Date" field.
7. Select the end date of the test period in the "End Date" field.

## Field-by-Field Explanation
### Pilot Name (Pilot Name)
* **Pilot Name**: Enter the name of the pilot or the person in charge of the test.

### Test Version (Test Version)
* **Test Version**: Input the version of the test you're registering.

### User ID (User ID)
* **User ID**: Enter a unique identifier for the user responsible for this test.

### Contact Email (Contact Email)
* **Contact Email**: Provide the email address where the user can be contacted for further information.

### Contact Phone (Contact Phone)
* **Contact Phone**: Enter the phone number where the user can be reached for further information.

### Start Date (Start Date)
* **Start Date**: Select the date when the test period begins. This field is optional.

### End Date (End Date)
* **End Date**: Select the date when the test period ends. This field is optional.
