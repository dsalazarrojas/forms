# student_device_check_out_form - Help Guide
## Purpose
The student_device_check_out_form is a document that captures information about a student's device checkout. It is used to track the type of device, date, student and teacher IDs, and device status.

## How To Complete This Form
To fill out this form, follow these steps:

1. Enter the **Device Name** in the text field (page 1, field 1).
2. Select the **Device Type** from the available options (page 1, field 2).
3. Enter the **Checkout Date** using the date picker (page 1, field 3). 
4. Enter the **Student ID** in the number field (page 1, field 4).
5. Enter the **Teacher ID** in the number field (page 1, field 5).
6. Select the **Device Status** from the available options (page 1, field 6).
7. Enter any additional **Notes** about the device in the text field (page 1, field 7).

## Field-by-Field Explanation

* **Device Name (page 1, field 1)** (`Device Name`, `text`, required: false): Enter the name of the device that is being checked out.
* **Device Type (page 1, field 2)** (`Device Type`, `select_one`, required: false): Select the type of device being checked out. Options include Laptop, Tablet, Smartphone, and Other.
* **Checkout Date (page 1, field 3)** (`Checkout Date`, `date`, required: false): Enter the date when the device was checked out.
* **Student ID (page 1, field 4)** (`Student ID`, `number`, required: false): Enter the student's ID number.
* **Teacher ID (page 1, field 5)** (`Teacher ID`, `number`, required: false): Enter the teacher's ID number.
* **Device Status (page 1, field 6)** (`Device Status`, `select_one`, required: false): Select the current status of the device. Options are Active, Inactive, and Pending.
* **Notes (page 1, field 7)** (`Notes`, `note`, required: false): Enter any additional notes about the device.
