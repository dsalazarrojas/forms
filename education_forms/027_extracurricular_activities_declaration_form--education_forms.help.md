# extracurricular_activities_declaration_form - Help Guide
## Purpose
The purpose of this form is to collect information about a student's extracurricular activities.

## How To Complete This Form
1. Select all the sports, clubs, and activities that the student is participating in.
2. For the "School Club or Activity Name" field, enter the name of the activity or club the student is participating in.
3. For the "School Club or Activity Position" field, enter the position the student holds in the activity or club.
4. If the student is participating in sports, select the corresponding sport in the "Sport" field.
5. If the student is participating in other activities, enter the name and position of the activity or club in the respective fields.

## Field-by-Field Explanation
- **Sports**: Select all the sports the student is participating in.
- **Clubs**: Select all the clubs or organizations the student is participating in.
- **Other Activities**: Select all the other activities the student is participating in.
- **School Club or Activity Name**: Enter the name of the activity or club the student is participating in.
- **School Club or Activity Position**: Enter the position the student holds in the activity or club.
- **Sport**: Select "Yes" if the student is participating in any sports.
- **Club or Activity**: Enter the name of the activity or club the student is participating in.
- **Position**: Enter the position the student holds in the activity or club.

## Tips
- Make sure to select all the activities that the student is participating in.
- If the student is unsure about their participation, they can always update their answers at a later time.
- If a student is not participating in any extracurricular activities, they should simply answer "No" to all fields.
