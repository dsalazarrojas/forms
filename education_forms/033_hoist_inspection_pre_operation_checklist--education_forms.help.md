# Hoist Inspection Pre Operation Checklist - Help Guide
## Purpose
The Hoist Inspection Pre Operation Checklist is a form designed to help crane operators and supervisors inspect cranes before operation to ensure they are in good working condition and safe for use.

## How To Complete This Form
To complete this form, follow these steps:

1. Review the form carefully and answer each field truthfully.
2. For fields with multiple options, select all applicable values.
3. Enter any additional comments or notes for the inspector's attention.
4. Submit the form to finalize the inspection.

## Field-by-Field Explanation
* **crane_operators** (select_multiple): Check if crane operators are available or not. Select 'Yes' if there are qualified crane operators on site.
* **goals** (text): Provide any specific goals or objectives for the current operation, such as lifting a heavy load or reaching a specific height.
* **safety_procedure** (select_one): Choose the safety procedure to be followed during the operation. Select from options A1, A2, or A3.
* **inspection_items** (select_multiple): Check the inspection items that need to be performed before operation. Select all applicable items.
* **crane_status** (select_one): Evaluate the crane's status before operation. Select from Good, Warning, or Critical.
* **comments** (text): Enter any additional comments or notes for the inspector's attention.
* **crane_operators_2** (select_multiple): Check if additional crane operators are available or not. Select 'Yes' if there are more operators on site.
* **goals_2** (select_multiple): Provide any additional specific goals or objectives for the current operation.
* **safety_procedure_2** (note): Enter any additional safety procedures or notes for the inspector's attention.
* **inspection_items_2** (select_multiple): Check the additional inspection items that need to be performed before operation. Select all applicable items.
* **comments_2** (text): Enter any additional comments or notes for the inspector's attention.
