# Extracurricular Program Audit Form - Help Guide
## Purpose
The Extracurricular Program Audit Form is designed to collect information about extracurricular programs offered by schools and organizations. This form helps to evaluate the quality of these programs, identify areas for improvement, and make informed decisions about their continuation or modification.

## How To Complete This Form
To complete this form, follow these steps:

1. **Program Name**: Enter the name of the extracurricular program being audited.
2. **School ID**: Enter the ID of the school or organization offering the program.
3. **Program Type**: Select the type of program (e.g., High School, Middle School, College/University, Community Center, or Youth Organization).
4. **Program Level**: Select the level of the program (e.g., Level 1, Level 2, Level 3, Level 4, or Level 5).
5. **Program Description** and **Program Objectives**: Enter a brief description and objectives of the program.
6. **Program Outcomes**: Select the outcomes of the program (e.g., Outcome 1, Outcome 2, Outcome 3).
7. **Evaluation Criterion**: Select the evaluation criterion for the program (e.g., Criterion 1, Criterion 2, Criterion 3, Criterion 4).
8. **Evaluation Process**: Select the evaluation process for the program (e.g., Process 1, Process 2, Process 3).
9. **Improvement Needs**: Enter any areas where the program needs improvement.
10. **Quality Control**: Select the quality control measure for the program (e.g., Control 1, Control 2, Control 3).
11. **Date Submitted**: Enter the date the form was submitted.
12. **Time Submitted**: Enter the time the form was submitted.
13. **Reviewer Name**: Enter the name of the reviewer.
14. **Reviewer Title**: Enter the title of the reviewer.
15. **Reviewer Email**: Enter the email of the reviewer.
16. **Reviewer Phone**: Enter the phone number of the reviewer.
17. **School Admin Email**: Enter the email of the school admin responsible for the program.
18. **School Admin Phone**: Enter the phone number of the school admin.
19. **School Admin Name**: Enter the name of the school admin.
20. **School Admin Department**: Select the department of the school admin (e.g., Department 1, Department 2, Department 3).
21. **Submitted By**: Select who submitted the form (e.g., By School, By Reviewer).
22. **Date Submitted**: Enter the date the form was submitted.
23. **Reviewer Signature**: Select the signature of the reviewer (e.g., Signature 1, Signature 2, Signature 3).

## Field-by-Field Explanation

* **Program Name** (`program_name`, text, required): Enter the name of the extracurricular program being audited.
* **School ID** (`school_id`, text, required): Enter the ID of the school or organization offering the program.
* **Program Type** (`program_type`, select_one, required): Select the type of program (e.g., High School, Middle School, College/University, Community Center, or Youth Organization).
* **Program Level** (`program_level`, select_multiple, required): Select the level of the program (e.g., Level 1, Level 2, Level 3, Level 4, or Level 5).
* **Program Description** (`program_description`, text, required): Enter a brief description of the program.
* **Program Objectives** (`program_objectives`, text, required): Enter a brief description of the program's objectives.
* **Program Outcomes** (`program_outcomes`, select_multiple, required): Select the outcomes of the program (e.g., Outcome 1, Outcome 2, Outcome 3).
* **Evaluation Criterion** (`evaluation_criterion`, select_one, required): Select the evaluation criterion for the program (e.g., Criterion 1, Criterion 2, Criterion 3, Criterion 4).
* **Evaluation Process** (`evaluation_process`, select_multiple, required): Select the evaluation process for the program (e.g., Process 1, Process 2, Process 3).
* **Improvement Needs** (`improvement_needs`, text, required): Enter any areas where the program needs improvement.
* **Quality Control** (`quality_control`, select_one, required): Select the quality control measure for the program (e.g., Control 1, Control 2, Control 3).
* **Date Submitted** (`date_submitted`, date, required): Enter the date the form was submitted.
* **Time Submitted** (`time_submitted`, time, required): Enter the time the form was submitted.
* **Reviewer Name** (`reviewer_name`, text, required): Enter the name of the reviewer.
* **Reviewer Title** (`reviewer_title`, text, required): Enter the title of the reviewer.
* **Reviewer Email** (`reviewer_email`, email, required): Enter the email of the reviewer.
* **Reviewer Phone** (`reviewer_phone`, text, required): Enter the phone number of the reviewer.
* **School Admin Email** (`school_admin_email`, email, required): Enter the email of the school admin responsible for the program.
* **School Admin Phone** (`school_admin_phone`, text, required): Enter the phone number of the school admin.
* **School Admin Name** (`school_admin_name`, text, required): Enter the name of the school admin.
* **School Admin Department** (`school_admin_department`, select_one, required): Select the department of the school admin (e.g., Department 1, Department 2, Department 3).
* **Submitted By** (`submitted_by`, select_one, required): Select who submitted the form (e.g., By School, By Reviewer).
* **Date Submitted** (`submitted`, date, required): Enter the date the form was submitted.
* **Reviewer Signature** (`reviewer_signature`, select_one, required): Select the signature of the reviewer (e.g., Signature 1, Signature 2, Signature 3).

**Tips**

* Make sure to fill out all the required fields.
* Select the correct options for each field.
* Double-check your entries for accuracy.
* Review the form carefully before submitting it.
* If you have any questions or concerns, contact your school or reviewer for assistance.
