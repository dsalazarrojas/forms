# Interdisciplinary Learning Collaboration Application Form - Help Guide
## Purpose
This form is designed to facilitate the submission of applications for interdisciplinary learning collaborations. It gathers relevant information about the collaboration, project lead, collaboration type, budget, submission date, review status, review comments, approval decision, and approval comments. The form is intended for individuals who wish to collaborate on a specific project.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the main form with the required information.
2. Choose the project lead and collaboration type from the provided options.
3. Select the collaboration options for Section 3.
4. Enter the collaboration description.
5. Choose the project budget.
6. Enter the submission date.
7. Select the review status.
8. Enter the review comments.
9. Choose the approval decision.
10. Enter the approval comments.
11. Fill out the submitter information (name, email, phone, etc.).
12. Enter any additional comments from the submitter.

## Field-by-Field Explanation

* **Project Lead** (`id: 5`, type: select_one, optional): Choose the lead person for the collaboration project. This is an important step in identifying the person responsible for the project's success.
* **Project Co-Lead** (`id: 6`, type: select_one, optional): Choose an additional lead person for the collaboration project, if necessary.
* **Collaboration Type** (`id: 7`, type: select_multiple, optional): Select the type of collaboration (e.g., Option 1, Option 2).
* **Collaboration Description** (`id: 8`, type: text, optional): Enter a brief description of the collaboration.
* **Project Budget** (`id: 9`, type: select_one, optional): Choose the budget for the project (e.g., Option 1, Option 2, Option 3).
* **Submission Date** (`id: 10`, type: date, optional): Enter the date the collaboration was submitted.
* **Review Status** (`id: 11`, type: select_one, optional): Select the review status (e.g., Option 1, Option 2).
* **Review Comments** (`id: 12`, type: text, optional): Enter any comments from the review process.
* **Approval Decision** (`id: 13`, type: select_one, optional): Choose the approval decision for the collaboration.
* **Approval Comments** (`id: 14`, type: text, optional): Enter any comments from the approval process.
* **Submitter** (`id: 15`, type: text, optional): Enter your name as the submitter.
* **Submitter Email** (`id: 16`, type: email, optional): Enter your email address as the submitter.
* **Submitter Phone** (`id: 17`, type: text, optional): Enter your phone number as the submitter.
* **Submitter Name** (`id: 18`, type: text, optional): Enter your name as the submitter.
* **Submitter Institution** (`id: 19`, type: text, optional): Enter your institution as the submitter.
* **Submitter Department** (`id: 20`, type: text, optional): Enter your department as the submitter.
* **Submitter Position** (`id: 21`, type: text, optional): Enter your position as the submitter.
* **Submitter Title** (`id: 22`, type: text, optional): Enter your title as the submitter.
* **Submitter Affiliation** (`id: 23`, type: text, optional): Enter your affiliation as the submitter.
* **Submitter Address** (`id: 24`, type: text, optional): Enter your address as the submitter.
* **Submitter Comments** (`id: 25`, type: text, optional): Enter any additional comments from the submitter.
