# Course Listing Submission Form - Help Guide
## Purpose
The Course Listing Submission Form is used to collect and display information about a course, including its details, instructors, and status.

## How To Complete This Form
1. Select the "New Class Details" section and enter the course title, start and end dates, duration, and other relevant details.
2. Indicate whether the course has instructors, and if so, provide their email addresses.
3. Choose the status of the course, such as active or inactive, and provide a note or comment if necessary.
4. Select the class level, such as high or low, and choose the relevant tags for the course.
5. Set the class schedule and time as needed.
6. Enter the class location and capacity.
7. Enter the class fees.
8. Choose the class status and provide a status date and time.
9. Enter any additional class status comments or notes.

## Field-by-Field Explanation

* **New Class Details** (`new_class_details`, text, optional): Enter a brief description of the new class.
* **Class Start Date** (`class_start_date`, date, optional): Enter the start date of the class.
* **Class End Date** (`class_end_date`, date, optional): Enter the end date of the class.
* **Instructors** (`instructors`, select multiple, optional): Indicate if the course has instructors, and if so, select "Yes" and provide their email addresses in the "Course Instructors Emails" field.
* **Instructors** (`course_instructors`, select multiple, optional): Confirm if the course has instructors selected in the previous field.
* **Course Description** (`course_description`, note, optional): Enter a brief description of the course.
* **Course Objectives** (`course_objectives`, select multiple, optional): Indicate if the course has objectives, and if so, select "Yes".
* **Course Outcomes** (`course_outcomes`, select multiple, optional): Indicate if the course has outcomes, and if so, select "Yes".
* **Class Duration** (`class_duration`, number, optional): Enter the duration of the class in whole numbers.
* **Class Level** (`class_level`, select one, optional): Select the level of the class, such as high or low.
* **Course Tags** (`course_tags`, select multiple, optional): Select the relevant tags for the course.
* **Class Schedule** (`class_schedule`, date, optional): Enter the class schedule as needed.
* **Class Time** (`class_time`, time, optional): Enter the class time as needed.
* **Class Location** (`class_location`, text, optional): Enter a text description of the class location.
* **Class Capacity** (`class_capacity`, number, optional): Enter the class capacity.
* **Class Fees** (`class_fees`, number, optional): Enter the class fees.
* **Class Status** (`class_status`, select one, optional): Choose the status of the class, such as active or inactive.
* **Class Status Date** (`class_status_date`, date, optional): Enter the status date of the class.
* **Class Status Time** (`class_status_time`, time, optional): Enter the status time of the class.
* **Class Status Note** (`class_status_note`, note, optional): Enter any additional class status notes.
* **Class Status Comment** (`class_status_comment`, note, optional): Enter any additional class status comments.
* **Class Status Update** (`class_status_update`, select multiple, optional): Select the status update of the class.
* **Course Instructors** (`course_instructors`, select multiple, optional): Confirm the course instructors selected in the previous field.
* **Course Instructors Emails** (`course_instructors_emails`, text, optional): Enter the email addresses of the course instructors.
* **Class Instructor Status** (`class_instructor_status`, select one, optional): Choose the status of the course instructors, such as active or inactive.
* **Class Instructor Comments** (`class_instructor_comments`, note, optional): Enter any additional comments about the course instructors.

## Tips
* Please fill out the form completely and accurately.
* Double-check the fields for any required or optional constraints.
* If you are unsure about any field, consult with the relevant authorities or double-check the course's status in the system.
* Enter relevant and accurate information to avoid errors or misinterpretation.
