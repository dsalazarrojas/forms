# Language Course Registration Form - Help Guide
## Purpose
This form is used to register students for a language course. It collects information about a student's personal details, course specifics, and enrollment dates to facilitate the registration process.

## How To Complete This Form
To complete this form, follow these steps:
1. Fill in your First Name and Last Name in the respective fields.
2. Enter your Email address for contact purposes.
3. Provide your Student ID for identification.
4. Enter the Course Code of the language course you're registering for.
5. Enter the Language Code of the course.
6. Specify your Student Level (e.g., beginner, intermediate, advanced).
7. Mention the Course Duration and Total Classes for the course.
8. Enter the number of Remaining Classes you need to attend.
9. Select the Start Date and Start Time for the course.
10. Choose the End Date and End Time for the course.
10. Finally, provide the Teacher Name who will be handling your course.

## Field-by-Field Explanation
* **First Name** (Text, Required): Enter your first name.
* **Last Name** (Text, Required): Enter your last name.
* **Email** (Email, Optional): Enter your email address for contact purposes.
* **Course Code** (Text, Optional): Enter the code of the course you're registering for.
* **Student ID** (Text, Optional): Enter your student ID for identification.
* **Date of Birth** (Date, Optional): Enter your date of birth, as required for some courses.
* **Date of Registration** (Date, Optional): Select the date you're registering for the course.
* **Time of Registration** (Time, Optional): Select the time you're registering for the course.
* **Language Code** (Text, Optional): Enter the language code of the course (e.g., English, Spanish, French).
* **Student Level** (Text, Optional): Enter your student level (e.g., beginner, intermediate, advanced).
* **Course Duration** (Text, Optional): Enter the duration of the course.
* **Total Classes** (Number, Optional): Enter the total number of classes for the course.
* **Remaining Classes** (Number, Optional): Enter the number of classes you still need to attend.
* **Start Date** (Date, Optional): Select the start date of the course.
* **Start Time** (Time, Optional): Select the start time of the course.
* **End Date** (Date, Optional): Select the end date of the course.
* **End Time** (Time, Optional): Select the end time of the course.
* **Teacher Name** (Text, Optional): Enter the name of your course teacher.
* **Teacher Name** was replaced with **Teacher Name** (Text, Optional) in the original form fields. I have kept this field as optional to maintain consistency with the original form structure.
