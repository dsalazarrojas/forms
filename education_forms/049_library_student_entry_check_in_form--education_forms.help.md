# Library Student Entry Check In Form - Help Guide
## Purpose
The "Library Student Entry Check In Form" is used to record student entries into the library. This form helps library staff track student attendance and manage their stay in the library.

## How To Complete This Form
To fill out this form, follow these steps:

1. Enter the student's name in the "Student Name" field.
2. Type the student's number in the "Student Number" field.
3. Select the student's grade level from the "Student Grade Level" field.
4. Enter the student's library card ID number in the "Student Library Card ID" field.
5. Choose the reason for the student's entry into the library using the "Check In Reason" field.
6. Select the student's current status as "In School", "Out of School", or "Other" using the "Student Status" field.
7. Provide any additional comments about the student's behavior or activity in the "Student Comments" field.

## Field-by-Field Explanation

* **Student Entry Check In** (Page 1, not a field, but a form header)
* **Student Name** (Page 2, text field): Enter the student's name as it appears on their student ID or library card.
* **Student Number** (Page 2, text field): Type the student's number as it appears on their student ID or library card.
* **Student Grade Level** (Page 3, text field): Select the grade level of the student (e.g., Grade 1, Grade 2, etc.).
* **Student Library Card ID** (Page 4, text field): Enter the student's library card ID number.
* **Check In Time** (Page 5, time field): Select the time the student entered the library.
* **Check In Date** (Page 6, date field): Select the date the student entered the library.
* **Check In Reason** (Page 7, text field): Enter the reason for the student's entry into the library (e.g., Study, Research, etc.).
* **Check Out Time** (Page 8, time field): Select the time the student is expected to leave the library. (Optional)
* **Check Out Date** (Page 9, date field): Select the date the student is expected to leave the library. (Optional)
* **Student Status** (Page 10, select multiple field): Choose the student's status as "In School", "Out of School", or "Other".
* **Student Comments** (Page 11, text field): Provide any additional comments about the student's behavior or activity in the library.
* **Student Status** (Page 10, select multiple field) and **Student Comments** (Page 11, text field) are optional and only required for specific reasons.

Note: Some fields may be required or optional depending on your specific library's policies and procedures. If you're unsure, please consult your library staff.
