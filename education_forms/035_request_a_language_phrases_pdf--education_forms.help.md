# Request A Language Phrases PDF - Help Guide

## Purpose
This form is designed to request a language phrases PDF that meets your specific needs. Please provide the purpose of your request to help us create a tailored PDF.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the language level you require from the dropdown menu.
2. Choose the delivery method you prefer for the PDF.
3. Select all languages you require.
4. Select all purposes for your request.
5. Provide any additional information about the language phrases PDF you need.

## Field-by-Field Explanation
* **education_form**: (text, optional) Enter any additional information about your educational background.
* **Request form**: (text, optional) Enter any additional information about your request.
* **Language Phrases PDF**: (text, optional) Enter any additional information about the language phrases PDF you need.
* **Language Level** (`language_level`, required): Select the level of language difficulty you require.
	+ Language Level 1: Beginner
	+ Language Level 2: Intermediate
	+ Language Level 3: Advanced
	+ Language Level 4: Proficient
* **Purpose** (`purpose`, required): Select all purposes for your request.
	+ Purpose 1
	+ Purpose 2
	+ Purpose 3
* **Delivery Method** (`delivery_method`, required): Select the delivery method you prefer.
	+ Delivery Method 1
	+ Delivery Method 2
	+ Delivery Method 3
* **Language** (`language`, required): Select all languages you require.
	+ English
	+ Spanish
	+ French
	+ German
* **Level** (`level`, optional, number): Enter a numerical value for the level of difficulty.
