# ethics_committee_approval_form - Help Guide
## Purpose
The ethics committee approval form is a simplified form designed to track and verify the approval process of research projects within an institution or organization.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the project details section with the necessary information about the project.
2. Choose the research area that the project belongs to (e.g., Animal Research or Human Research).
3. Select the review cycle for the project (e.g., Cycle 1, Cycle 2, or Cycle 3).
4. Choose the committee(s) that will review and approve the project.
5. Enter the researcher's name and institution's information.
6. Provide a brief description of the project.

## Field-by-Field Explanation
### project_details
* **Project Details** (`project_details`, text, optional): This field is used to enter a brief description of the project. Please include any relevant details about the project, such as the project's name, goal, or objective.

### research_area
* **Research Area** (`research_area`, select_one, optional): This field allows you to select the research area that the project belongs to. Please choose the option that best matches your project's category (e.g., Animal Research or Human Research).

### approval_date
* **Approval Date** (`approval_date`, date, optional): This field is used to enter the date when the project was approved. If the project has not been approved, please leave this field blank.

### review_cycle
* **Review Cycle** (`review_cycle`, select_multiple, optional): This field allows you to select the review cycle for the project. Please choose the cycle that matches the project's review status (e.g., Cycle 1, Cycle 2, or Cycle 3).

### committee_approval
* **Committee Approval** (`committee_approval`, select_multiple, optional): This field is used to select the committee(s) that will review and approve the project. Please choose the committee(s) that are relevant to your project.

### researcher_name
* **Researcher Name** (`researcher_name`, text, optional): This field is used to enter the name of the researcher who is responsible for the project.

### research_institution
* **Research Institution** (`research_institution`, text, optional): This field is used to enter the name of the research institution where the project is conducted.

### research_institution_address
* **Research Institution Address** (`research_institution_address`, text, optional): This field is used to enter the address of the research institution where the project is conducted.

### project_description
* **Project Description** (`project_description`, text, optional): This field is used to enter a brief description of the project. Please include any relevant details about the project's objective, methodology, or expected outcomes.
