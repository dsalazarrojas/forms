# Co Curricular Participation Documentation - Help Guide
## Purpose
The purpose of this form is to collect information about a student's co-curricular activities, such as sports, arts, and academic clubs, to help the school track their participation and engagement in these programs. This information is used to monitor student involvement and provide insight into the student's development and growth.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the student's name in the "Student Full Name" field.
2. Enter the student's ID number in the "Student ID Number" field.
3. Select the current grade level of the student in the "Grade Level" field.
4. Enter the name of the co-curricular activity the student is participating in.
5. Select the type of activity (e.g., Sports, Arts, etc.) in the "Activity Type" field.
6. Enter the date the student started participating in the activity.
7. If applicable, enter the date the student stopped participating in the activity.
8. Enter the average number of hours the student spends on the activity per week.
9. If applicable, enter the leadership position the student holds in the activity.
10. Enter any achievements or accomplishments earned from the activity.
11. Enter the skills developed through the activity.
12. Enter the name and contact information of the activity advisor or coach.
13. If applicable, attach supporting evidence for the activity (e.g., photos, certificates, etc.).
14. Select whether supporting evidence is attached or not.

## Field-by-Field Explanation

* **Student Full Name** (`student_name`, text, required): Enter the student's full name.
* **Student ID Number** (`student_id`, text, required): Enter the student's ID number.
* **Documentation Date** (`documentation_date`, date, required): Enter the date this documentation is being submitted.
* **School or Institution Name** (`school_name`, text, required): Enter the name of the school or institution the student is affiliated with.
* **Grade Level** (`grade_level`, select_one, required): Select the student's current grade level (e.g., 9th, 10th, etc.).
* **Co-Curricular Activity Name** (`activity_name`, text, required): Enter the name of the co-curricular activity the student is participating in.
* **Activity Type** (`activity_type`, select_one, required): Select the type of activity (e.g., Sports, Arts, etc.).
* **Participation Start Date** (`participation_start_date`, date, required): Enter the date the student started participating in the activity.
* **Participation End Date** (`participation_end_date`, date, optional): If the student is no longer participating, enter the date they stopped.
* **Average Hours Per Week** (`hours_per_week`, number, required): Enter the average number of hours the student spends on the activity per week.
* **Leadership Position Held** (`leadership_role`, text, optional): If applicable, enter the leadership position the student holds in the activity.
* **Achievements or Accomplishments** (`achievements`, text, optional): Enter any achievements or accomplishments earned from the activity.
* **Skills Developed** (`skills_developed`, text, required): Enter the skills gained from participating in the activity.
* **Activity Advisor or Coach Name** (`advisor_name`, text, required): Enter the name of the activity advisor or coach.
* **Advisor Email or Phone** (`advisor_contact`, email, optional): Enter the contact information of the activity advisor or coach.
* **Supporting Evidence Attached** (`supporting_evidence`, select_one, required): Select whether supporting evidence is attached or not.

Note: This guide is intended to be user-friendly and easy to understand. If you have any questions or concerns, please don't hesitate to reach out for assistance.
