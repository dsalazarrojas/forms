# Digital Learning Resource Request Form - Help Guide
## Purpose
This form is designed to collect information from users about digital learning resources they would like to request. The purpose of this form is to gather details about the resource, including its name, URL, and department or field it belongs to.

## How To Complete This Form
To complete this form, follow these steps:

1.  Enter a brief description of the resource you are requesting in the **Description** field.
2.  Select the type of resource you are requesting from the **Resource Type** dropdown menu.
3.  Enter the name of the resource in the **Resource Name** field.
4.  Provide the URL of the resource in the **Resource URL** field.
5.  Choose the department or field where the resource is relevant from the **Department** dropdown menu.
6.  Click the **Submit** button to submit your request.

## Field-by-Field Explanation

*   **Digital Learning Resource Request**: This field is a text field where you can enter a brief description of the resource you are requesting. 
*   **Name**: This field is used to store the name of the person submitting the request.
*   **Email**: This field is used to store the email address of the person submitting the request.
*   **Description**: This field is a text field where you can enter a brief description of the resource you are requesting.
*   **Resource Type**: This field is a dropdown menu where you can select the type of resource you are requesting.
*   **Resource Name**: This field is used to store the name of the resource you are requesting.
*   **Resource URL**: This field is used to store the URL of the resource you are requesting.
*   **Department**: This field is a dropdown menu where you can select the department or field where the resource is relevant.
*   **Submit**: This field is a button that will submit your request.
