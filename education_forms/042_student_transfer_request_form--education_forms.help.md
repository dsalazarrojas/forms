# Student Transfer Request Form - Help Guide
## Purpose
The Student Transfer Request Form is designed to collect information necessary for handling a student's transfer request efficiently.

## How To Complete This Form
To complete this form, follow these steps:

1. Determine if the student is being transferred. If so, select 'Yes' for the "Transfer Student" field.
2. Enter the teacher's name and email in the corresponding fields.
3. Enter the student's name.
4. Indicate the student's new class by selecting 'Yes' for "Student Class" if applicable.
5. Provide a reason for the transfer in the "Reason" field.
6. Enter the new class details in the "New Class" field.
7. Enter the date of the transfer if necessary.

## Field-by-Field Explanation
* **Transfer Student**: Select 'Yes' if the student is being transferred. If not, select 'No'.
* **Teacher Name**: Enter the teacher's name who is associated with the student.
* **Teacher Email**: Enter the teacher's email address. This will be used for communication purposes.
* **Teacher Phone**: Enter the teacher's phone number. This field is optional.
* **Student Name**: Enter the student's name.
* **Student Class**: Select 'Yes' if the student is transferring to a new class. If not, select 'No'.
* **Reason**: Provide a brief explanation for the transfer.
* **New Class**: Enter the details of the new class the student is transferring to.
* **Date**: Enter the date of the transfer if necessary.
