# prophets - Help Guide
## Purpose
The "prophets" form is designed to collect information about officer-related data.

## How To Complete This Form
To complete this form, follow these steps:
1. Make sure you have all the required information and permissions before starting to fill out the form.
2. Enter your officer ID number in the "Officer ID" field.
3. Select the correct shift from the "Shift" dropdown menu.
4. Enter the start and end times in the "Start Time" and "End Time" fields, respectively.
5. Provide any relevant events that occurred during your shift in the "Events" field.
6. Enter any notes or comments in the "Notes" field.
7. Select the submitted date and time in the "Submitted Date" and "Submitted Time" fields, respectively.
8. If applicable, enter the assigned tool information in the "Assigned Tool" fields.
9. Review and verify all the information entered before submitting the form.

## Field-by-Field Explanation
* **Officer ID** (`officer_id`, number, **Required**): Enter your unique officer ID number.
* **Shift** (`shift`, select_one, **Required**): Select the correct shift from the dropdown menu.
* **Start Time** (`start_time`, time, **Optional**): Enter the start time of your shift.
* **End Time** (`end_time`, time, **Optional**): Enter the end time of your shift.
* **Events** (`events`, text, **Optional**): Enter any relevant events that occurred during your shift.
* **Notes** (`notes`, text, **Optional**): Enter any notes or comments about your shift.
* **Submitted Date** (`submitted_date`, date, **Optional**): Select the date you are submitting this form.
* **Submitted Time** (`submitted_time`, time, **Optional**): Select the time you are submitting this form.
* **Assigned Tool** (`assigned_tool`, text, **Optional**): Enter any assigned tool information.
* **Assigned Tool ID** (`assigned_tool_id`, text, **Optional**): Enter the assigned tool ID information.
* **Assigned Tool Name** (`assigned_tool_name`, text, **Optional**): Enter the assigned tool name information.
* **Duty Report** (`duty_report`, text, **Optional**): Enter any duty report information.
* **Duty Report ID** (`duty_report_id`, text, **Optional**): Enter the duty report ID information.
* **Officer Name** (`officer_name`, text, **Optional**): Enter your officer name.
* **Officer Name ID** (`officer_name_id`, text, **Optional**): Enter your officer name ID.
* **Officer Name Full** (`officer_name_full`, text, **Optional**): Enter your full officer name.
* **Officer Name Last** (`officer_last`, text, **Optional**): Enter your last officer name.
* **Duty Type** (`duty_type`, select_one, **Optional**): Select the duty type from the dropdown menu.
* **Duty Type ID** (`duty_type_id`, text, **Optional**): Enter the duty type ID information.
* **Duty Type Name** (`duty_type_name`, text, **Optional**): Enter the duty type name information.
* **Officer ID 2** (`officer_id_2`, text, **Optional**): Enter any additional officer ID information.
* **Officer Name Full ID** (`officer_name_full_id`, text, **Optional**): Enter any additional officer name full ID information.
* **Officer Last ID** (`officer_last_id`, text, **Optional**): Enter any additional officer last ID information.
* **Officer Last** (`officer_last`, text, **Optional**): Enter any additional officer last information.
* **Officer Last Name** (`officer_last_name`, text, **Optional**): Enter any additional officer last name information.
