# Student And Teacher Records Form - Help Guide
## Purpose
This form is designed to collect various types of information related to students and teachers within an educational institution.

## How To Complete This Form
To complete this form, follow these steps:
1. Fill in the student section (fields 1-10) with information for each student.
2. Fill in the teacher section (fields 11-20) with information for each teacher.
3. Ensure that you have filled out all required fields, although it seems all fields are optional.

## Field-by-Field Explanation

* **Student (1)**: Enter student's name and other relevant information.
* **Teacher (11)**: Enter teacher's name and other relevant information.
* **Enrollment (3, 6, 14)**: Enter student or teacher's enrollment information.
* **Onboarding (4, 8, 15)**: Enter student or teacher's onboarding information.
* **Directory Management (5, 12)**: Enter student or teacher's directory management information.
* **Student Enrollment (7)**: Enter student's enrollment information.
* **Staff Enrollment (7)**: Enter staff's enrollment information.
* **Student Onboarding (9)**: Enter student's onboarding information.
* **Staff Onboarding (9)**: Enter staff's onboarding information.
* **Student Directory (10)**: Enter student's directory information.
* **Staff Directory (10)**: Enter staff's directory information.
* **Student Registration (13)**: Enter student's registration information.
* **Staff Registration (13)**: Enter staff's registration information.
* **Student Information (14)**: Enter student's information.
* **Staff Information (15)**: Enter staff's information.
* **Student Update (16)**: Enter student's update information.
* **Staff Update (16)**: Enter staff's update information.
* **Student Record (18)**: Enter student's record information.
* **Staff Record (18)**: Enter staff's record information.
* **Student Profile (20)**: Enter student's profile information.
* **Staff Profile (20)**: Enter staff's profile information.
* **Student Data (22)**: Enter student's data information.
* **Staff Data (22)**: Enter staff's data information.
* **Student Status (24)**: Enter student's status information.
* **Staff Status (24)**: Enter staff's status information.
