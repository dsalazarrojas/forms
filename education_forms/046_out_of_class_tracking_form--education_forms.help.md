# out_of_class_tracking_form - Help Guide
## Purpose
The out_of_class_tracking_form is used to track student attendance and performance in a class setting.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the student's name in the "Student Name" field.
2. Select the date the student was out of class in the "Date Out of Class" field.
3. Provide a reason for the student's absence in the "Reason Out of Class" field.
4. Enter the student's ID number in the "Student ID" field.
5. Select the class name in the "Class Name" field.
6. Enter the teacher's name in the "Teacher Name" field.
7. Enter the student's attendance ID in the "Student Attendance ID" field.
8. Enter the teacher's ID number in the "Teacher ID" field.
9. Enter another student's name in the "Another Student Name" field (this field seems to be redundant, but it might be used for a different purpose).
10. Select the class duration in the "Class Duration" field.
11. Select the student's attendance status in the "Student Attendance Status" field.
12. Select the teacher's attendance status in the "Teacher Attendance Status" field.
13. Select the class location in the "Class Location" field.
14. Select the class type in the "Class Type" field.
15. Select the class status in the "Class Status" field.
16. Add any additional notes in the "Notes" field.
17. Select the student's status in the "Student Status" field.
18. Select the student's grade in the "Student Grade" field.
