# Grow Children Registration Form - Help Guide
## Purpose
This form is designed to collect information about students and their associated details for an education system.

## How To Complete This Form

To complete this form, please follow these steps:

1. Fill in the `Student Information` section with the student's general details.
2. Enter the `Student Name` in the field provided.
3. Select the `Class` option for the student's class status.
4. Enter the `Date of Birth` of the student.
5. Enter the `Parent Details` in the field provided.
6. Enter the `Parent Name`.
7. Enter the `Contact` information for the parent.
8. Enter the `Email` address of the student.
9. Enter the `Phone` number of the student.
10. Enter the `Address` of the student.
11. Enter any additional `Note` about the student.
12. Select the `Assigned Tool` and `Assigned Tool ID` for the student.
13. Enter the `Assigned Tool Name` for the student.
14. Select the `Assigned User` and `Assigned User ID` for the student.
15. Enter the `Parent Address` of the student.
16. Select the `Assigned Tool Type` for the student.
17. Select the `Assigned User Type` for the student.
18. Enter the `Form ID` for the student.
19. Enter the `Assigned User Email` of the student.
20. Enter the `Assigned User Phone` of the student.
21. Enter the `Assigned User Address` of the student.
22. Enter any additional `Note` about the assigned user.

## Field-by-Field Explanation

* **Student Information** (Text, Required: false): 
  This is the section where you will find general information about the student.
* **Student Name** (Text, Required: false): 
  Enter the name of the student.
* **Class** (Select Multiple, Required: false): 
  Select the class status of the student.
* **Date of Birth** (Date, Required: false): 
  Enter the date of birth of the student.
* **Parent Details** (Text, Required: false): 
  Enter the parent details.
* **Parent Name** (Text, Required: false): 
  Enter the name of the parent.
* **Contact** (Text, Required: false): 
  Enter the contact information of the parent.
* **Email** (Email, Required: false): 
  Enter the email address of the student.
* **Phone** (Text, Required: false): 
  Enter the phone number of the student.
* **Address** (Text, Required: false): 
  Enter the address of the student.
* **Note** (Note, Required: false): 
  Enter any additional note about the student.
* **Assigned Tool** (Text, Required: false): 
  Select the tool assigned to the student.
* **Assigned Tool ID** (Text, Required: false): 
  Enter the ID of the assigned tool.
* **Assigned Tool Name** (Text, Required: false): 
  Enter the name of the assigned tool.
* **Assigned User** (Text, Required: false): 
  Select the user assigned to the tool.
* **Assigned User ID** (Text, Required: false): 
  Enter the ID of the assigned user.
* **Parent Address** (Text, Required: false): 
  Enter the address of the parent.
* **Assigned Tool Type** (Text, Required: false): 
  Select the type of tool assigned to the student.
* **Assigned User Type** (Text, Required: false): 
  Select the type of user assigned to the tool.
* **Form ID** (Text, Required: false): 
  Enter the ID of the form.
* **Assigned User Email** (Email, Required: false): 
  Enter the email address of the assigned user.
* **Assigned User Phone** (Text, Required: false): 
  Enter the phone number of the assigned user.
* **Assigned User Address** (Text, Required: false): 
  Enter the address of the assigned user.
* **Assigned User Note** (Note, Required: false): 
  Enter any additional note about the assigned user.
* **Assigned User Note Text** (Text, Required: false): 
  Enter any additional text about the assigned user.
* **Assigned User** (Text, Required: false): 
  Select the user assigned to the tool.
* **Assigned User ID** (Text, Required: false): 
  Enter the ID of the assigned user.
