# Student Exchange Application - Help Guide
## Purpose
This form is designed to collect information for student exchange programs, allowing users to input details about the student and host institution. The form has multiple sections to gather specific information about the student's and host's educational background, program details, and contact information.

## How To Complete This Form
To complete this form, follow the instructions below:

1. Fill out the student's information (fields 1-4).
2. Fill out the host institution's information (fields 5-20).
3. Review and submit the form.

## Field-by-Field Explanation

* **Student Info** (field 1): A text field for the student's name, university name, and other relevant details.
* **Student Program** (field 2): Select one of the options (High School, University, or College) to indicate the student's current program.
* **Academic Level** (field 3): Select multiple options to indicate the student's academic level (High School Diploma, Associate's Degree, Bachelor's Degree, Master's Degree, or Doctoral Degree).
* **Host Info** (field 4): A text field for the host institution's name and other relevant details.
* **Host Program** (field 5): Select one of the options (High School, University, or College) to indicate the host institution's program.
* **Host Education** (field 6): Select multiple options to indicate the host institution's academic level (High School Diploma, Associate's Degree, Bachelor's Degree, Master's Degree, or Doctoral Degree).
* **Host Program Duration** (field 7): A date field for the host program's duration.
* **Host Program Start Date** (field 8): A date field for the host program's start date.
* **Host Program End Date** (field 9): A date field for the host program's end date.
* **Host Program Duration** (field 10): A number field for the host program's duration (e.g., number of months).
* **Student Exchange Duration** (field 11): A number field for the duration of the student exchange program.
* **Host Currency** (field 12): A text field for the host institution's currency.
* **Host Language** (field 13): Select one of the options (English, Spanish, or French) to indicate the host institution's language.
* **Host Exchange Rate** (field 14): A number field for the host exchange rate.
* **Student Currency** (field 15): A text field for the student's currency.
* **Student Language** (field 16): Select one of the options (English, Spanish, or French) to indicate the student's language.
* **Student Exchange Rate** (field 17): A number field for the student's exchange rate.
* **Student Exchange Fees** (field 18): A number field for the student exchange fees.
* **Host Address** (field 19): A text field for the host institution's address.
* **Student Address** (field 20): A text field for the student's address.
* **Host Email** (field 21): A text field for the host institution's email address.
* **Student Email** (field 22): A text field for the student's email address.
* **Host Phone** (field 23): A text field for the host institution's phone number.
* **Student Phone** (field 24): A text field for the student's phone number.
* **Submission** (field 25): A note field for any additional comments or notes from the student or host institution.

## Tips

* Be accurate and thorough when filling out the form.
* Review the fields carefully before submitting the form.
* If you have any questions or concerns, please contact the exchange program administrators.
