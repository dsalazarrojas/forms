# University Thesis Support Inquiry Form - Help Guide
## Purpose
This form is used to collect information about a thesis support inquiry from students, advisors, or department staff.

## How To Complete This Form

To complete this form, follow these steps:

1. Fill out the required fields, marked with an asterisk (*).
2. Provide accurate and relevant information about the university, program, and department related to the support request.
3. Choose a suitable follow-up method for the support request.
4. Fill out the submission information section, including the submitter's name and contact details.
5. Review and submit the form.

## Field-by-Field Explanation
* **University name (text)** (`university_name`, Not required)
	+ This field is used to specify the name of the university related to the support request.
* **Program name (text)** (`program_name`, Not required)
	+ This field is used to specify the name of the program related to the support request.
* **Department name (text)** (`department_name`, Not required)
	+ This field is used to specify the name of the department related to the support request.
* **Thesis title (text)** (`thesis_title`, Not required)
	+ This field is used to specify the title of the thesis related to the support request.
* **Advisor name (text)** (`advisor_name`, Not required)
	+ This field is used to specify the name of the advisor related to the thesis.
* **Contact number (text)** (`contact_number`, Not required)
	+ This field is used to provide a contact number for further communication.
* **Email (text)** (`email`, Not required)
	+ This field is used to provide an email address for further communication.
* **University URL (text)** (`university_url`, Not required)
	+ This field is used to specify the URL of the university related to the support request.
* **Support request (text)** (`support_request`, Not required)
	+ This field is used to describe the support request in detail.
* **Follow-up date (date)** (`follow_up_date`, Not required)
	+ This field is used to specify the date for follow-up on the support request.
* **Follow-up time (time)** (`follow_up_time`, Not required)
	+ This field is used to specify the time for follow-up on the support request.
* **Follow-up method (select)** (`follow_up_method`, Required)
	+ This field is used to select a suitable follow-up method (Phone, Email, In person, Video call).
* **Additional information (text)** (`additional_info`, Not required)
	+ This field is used to provide any additional information related to the support request.
* **Submitted by (select)** (`submitted_by`, Required)
	+ This field is used to specify who submitted the support request (Student, Advisor, Department staff, Other).
* **Submitted name (text)** (`submitted_name`, Not required)
	+ This field is used to specify the name of the submitter.
* **Submission date (date)** (`submission_date`, Not required)
	+ This field is used to specify the date of submission.
* **Submission time (time)** (`submission_time`, Not required)
	+ This field is used to specify the time of submission.
* **Submission method (text)** (`submission_method`, Not required)
	+ This field is used to specify the method of submission.
* **Submitter (text)** (`submitter`, Not required)
	+ This field is used to specify the name of the submitter.
* **Submitter department (text)** (`submitter_department`, Not required)
	+ This field is used to specify the department of the submitter.
* **Submitter title (text)** (`submitter_title`, Not required)
	+ This field is used to specify the title of the submitter.
* **Submitter program (text)** (`submitter_program`, Not required)
	+ This field is used to specify the program of the submitter.
* **Submitter university (text)** (`submitter_university`, Not required)
	+ This field is used to specify the university of the submitter.
* **Submitter email (text)** (`submitter_email`, Not required)
	+ This field is used to specify the email of the submitter.
* **Submitter phone (text)** (`submitter_phone`, Not required)
	+ This field is used to specify the phone number of the submitter.

## Tips
- Please ensure that all required fields are filled out to ensure a proper review of your support request.
- If you are unsure about any field, please consult with your supervisor or department staff.
- The follow-up method should be chosen based on the submitter's preference and the department's communication protocol.
