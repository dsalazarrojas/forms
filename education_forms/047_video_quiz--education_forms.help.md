# Video Quiz - Help Guide
## Purpose
The Video Quiz form is used to create a new video quiz with custom settings for sharing and embedding.

## How To Complete This Form
To complete this form, follow these steps:
- Fill in the **Category** field with the desired category for the video quiz.
- In the **Description** field, provide a brief summary of the video quiz.
- In the **Embedded Video URL** field, enter the URL of the video to be embedded in the quiz.
- In the **Custom CSS** field, enter any custom CSS code for styling the video quiz.
- In the **Embed Code** field, enter the code for the video embed.
- In the **Video Quiz Title** field, enter the title of the video quiz.
- In the **Embed Button Label** field, enter the label for the embed button.
- In the **Embed Button URL** field, enter the URL of the embed button.
- In the **Embed Button Target** field, select the target of the embed button (self, parent, or blank).
- In the **Embed Button Type** field, select the type of embed button (iframe, lightbox, modal, new window, or none).
- In the **Share Button Label** field, enter the label for the share button.
- In the **Share Button URL** field, enter the URL of the share button.
- In the **Share Button Target** field, select the target of the share button (self, parent, or blank).
- In the **Share Button Type** field, select the type of share button (iframe, lightbox, modal, new window, or none).
- In the **Custom CSS Class** field, enter any custom CSS class for the video quiz.
- In the **Custom JS** field, enter any custom JavaScript code.
- In the **Custom CSS File** field, enter any custom CSS file path.
- In the **Share Via Email** field, enter the email address to share the video quiz.
- In the **Share Via Link** field, enter the link to share the video quiz.
- In the **Share Via Embed** field, enter the embed code to share the video quiz.
- In the **Custom HTML** field, enter any custom HTML code.
- In the **Video Player ID** field, enter any custom video player ID.
- In the **Share Via Facebook** field, enter the URL to share the video quiz on Facebook.
- In the **Share Via Twitter** field, enter the URL to share the video quiz on Twitter.
