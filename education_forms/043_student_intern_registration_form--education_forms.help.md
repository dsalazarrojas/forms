# Student Intern Registration Form - Help Guide

## Purpose
This form is used to register a student for an internship program.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter student information on the first page.
2. Fill out the student's name on the second page.
3. Provide the student's email address on the third page.
4. Enter the student's phone number on the fourth page.
5. Enter the course name on the fifth page.
6. Select the start date for the internship on the sixth page.
7. Select the end date for the internship on the seventh page.
8. Enter the student's ID number on the eighth page.

## Field-by-Field Explanation

* **Student Information** (Page 1):
	+ This page collects basic student information. Please provide a brief description of the student.
* **Student Name** (Page 2):
	+ Enter the name of the student, as it appears on their official documents.
* **Student Email** (Page 3):
	+ Enter the student's email address where they can be reached for communication.
* **Student Phone** (Page 4):
	+ Enter the student's phone number where they can be reached for communication.
* **Course Name** (Page 5):
	+ Enter the name of the course the student is enrolled in.
* **Start Date** (Page 6):
	+ Select the date the internship is expected to start.
* **End Date** (Page 7):
	+ Select the date the internship is expected to end.
* **Student ID** (Page 8):
	+ Enter the student's ID number, if applicable.

## Tips
- Ensure that you have the necessary permissions to fill out this form.
- Double-check the dates and information you provide to ensure accuracy.
- If you have any questions or issues, please contact the relevant department or support team for assistance.
