# educational_program_recommendation_form - Help Guide
## Purpose
This form is used to express opinions or feedback about educational programs.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter your name in the `name` field.
2. Enter your email address in the `email` field.
3. Select the name of the educational program you are recommending in the `program_name` field.
4. Choose the level of the course (High, Low, etc.) in the `course_level` field.
5. If the course level is not listed, please enter the course level in the `course_level_other` field.
6. If you are a faculty member, check the corresponding box in the `faculty_member` field.
7. If you are not a faculty member, please enter your reason for not being a faculty member in the `faculty_member_other` field.
8. Choose whether the department is included in the program in the `department` field.
9. If the department is not listed, please enter the department in the `department_other` field.
10. Enter the length of the program in the `program_length` field.
11. If the program length is not listed, please enter the program length in the `program_length_other` field.
12. Choose whether the program type is included in the program in the `program_type` field.
13. If the program type is not listed, please enter the program type in the `program_type_other` field.
14. Choose whether you recommend this program or not in the `recommendation` field.
15. If you have any other recommendation, please enter it in the `recommendation_other` field.
16. Enter any additional comments about the program in the `comments` field.

## Field-by-Field Explanation

* **Name (name)**: Enter your name.
* **Email (email)**: Enter your email address.
* **Program Name (program_name)**: Enter the name of the educational program you are recommending.
* **Course Level (course_level)**: Choose the level of the course (High, Low, etc.).
*   If you do not see your course level listed, enter it in the `course_level_other` field.
* **Faculty Member (faculty_member)**: Check if you are a faculty member.
*   If you are not a faculty member, enter your reason for not being a faculty member in the `faculty_member_other` field.
* **Department (department)**: Check if the department is included in the program.
*   If the department is not listed, enter it in the `department_other` field.
* **Program Length (program_length)**: Enter the length of the program.
*   If the program length is not listed, enter it in the `program_length_other` field.
* **Program Type (program_type)**: Check if the program type is included in the program.
*   If the program type is not listed, enter it in the `program_type_other` field.
*   * **Recommend this Program (recommendation)**: Check if you recommend this program.
*   If you have any other recommendation, enter it in the `recommendation_other` field.
*   * **Additional Comments (comments)**: Enter any additional comments about the program.

Note: The fields labeled "other" are for users to enter their own information if the standard options do not apply to them.
