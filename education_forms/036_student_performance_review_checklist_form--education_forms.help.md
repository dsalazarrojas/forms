# Student Performance Review Checklist Form - Help Guide
## Purpose
This form is designed to help instructors assess a student's performance and progress. It's used to gather information about a student's overall performance, progress, and goals, as well as to note any comments or suggestions from the instructor. This data can be used to inform future educational decisions and to provide guidance to the student.

## How To Complete This Form

To complete this form, follow these steps:

1. Enter the student's information, including their name.
2. Select their overall performance level.
3. Record the date of the last evaluation or review.
4. Add any comments or notes about the student's progress.
5. List any additional comments or suggestions for the student.
6. Evaluate the student's progress and overall performance level.
7. Record any additional comments or suggestions.

## Field-by-Field Explanation

* **Student Info** (`student_info`, text, not required): Enter the student's basic information for identification purposes.
* **Overall Performance** (`overall_performance`, select_one, not required): Choose from the options "Yes" or "No" to indicate the student's overall performance level.
* **Date Last Seen** (`date_last_seen`, date, not required): Record the date of the last evaluation or review.
* **Student Comments** (`student_comments`, note, not required): Add any comments or notes about the student's progress.
* **Instructor Comments** (`instructor_comments`, note, not required): Add any comments or notes from the instructor.
* **Performance Level** (`performance_level`, select_one, not required): Choose from the options "High" or "Low" to indicate the student's performance level.
* **Student Progress** (`student_progress`, select_multiple, not required): List any progress or accomplishments the student has made.
* **Student Goals** (`student_goals`, select_multiple, not required): List any goals or objectives the student has set.
* **Additional Comments** (`additional_comments`, note, not required): Add any additional comments or suggestions.
* **Student Progress Overall** (`student_progress_overall`, text, not required): Record any comments or observations about the student's progress.
* **Student Name Checklist** (`student_name_checklist`, text, not required): Record the student's name as a check list for easier reference.
* **Performance Level Label** (`performance_level_label`, text, not required): Record a label for the student's performance level.
* **Student Info Label** (`student_info_label`, text, not required): Record a label for the student's information.
* **Student Name** (`student_name`, text, not required): Enter the student's name for identification purposes.
* **Student Goals Label** (`student_goals_label`, text, not required): Record a label for the student's goals.
