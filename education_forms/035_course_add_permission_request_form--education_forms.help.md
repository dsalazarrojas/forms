# Course Add Permission Request Form - Help Guide

## Purpose
This form is used to request permission to add a course to the platform that is currently restricted or closed. 

## How To Complete This Form
To complete this form, please follow the steps below:

1. Fill out your personal information in the "Requester's Name", "Requester's Email", and "Requester's Phone" fields.
2. Provide a clear and concise reason for why you need to access the course in the "Reason" field.
3. Enter the name of the course you are requesting access to in the "Course Name" field.
4. Indicate if the course is restricted or closed in the "Restricted or Closed Course" field.
5. If you are requesting to add the course for someone else, please enter their name in the "Submitter's Name" field.
6. If this is a re-submission, please select "Form Submissions" to "Yes" or "No" to indicate whether this is a new or a re-submission.

## Field-by-Field Explanation

* **Requester's Name**: Enter your name so we can identify you as the person requesting access.
* **Requester's Email**: Enter your email address so we can contact you about your request.
* **Requester's Phone**: Enter your phone number so we can contact you about your request.
* **Reason**: Provide a brief description of why you need access to the course.
* **Course Name**: Enter the exact name of the course you are requesting access to.
* **Restricted or Closed Course**: Select "Restricted" if the course is restricted, "Closed" if the course is closed.
* **Approval Date**: Leave this field blank unless you are certain about when the course will be approved. This field is only for informational purposes.
* **Approval Time**: Like the "Approval Date" field, this field is only for informational purposes and can be left blank.
* **Additional Info**: If you have any additional information that would help us process your request, you can enter it here.
* **Comments**: If you have any comments or feedback about your request, you can enter it here.
* **Form Submissions**: If this is a re-submission, select "Yes" to indicate that this is a new submission. If this is a new submission, select "No". 

## Tips
Please make sure to provide accurate and complete information in all fields. This will help us process your request efficiently. If you have any questions or need help, please don't hesitate to contact us.
