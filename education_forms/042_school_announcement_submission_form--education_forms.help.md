# School Announcement Submission Form - Help Guide
## Purpose
The School Announcement Submission Form is used by school staff to submit announcements to be displayed on the school's communication channels. This form helps to streamline the process of creating and disseminating important announcements to students, staff, and parents.

## How To Complete This Form
1. Fill in the required fields as follows:
   - **Staff Update**: Briefly describe the update or changes related to the announcement.
   - **Announcement Details**: Provide a detailed description of the announcement.
   - **Date Scheduled**: Enter the date the announcement is scheduled to take place.
   - **Publication Status**: Select the status of the announcement (Published, Unpublished, Scheduled, or Cancelled).
   - **Announcement Audience**: Choose the audience for the announcement (Students, Staff, Faculty, or Parents).
   - **School Name**: Enter the name of the school.
   - **Contact Name**: Enter your name as the contact person for the announcement.
   - **Contact Email**: Enter your email address.
   - **Contact Phone**: Enter your phone number.
   - **Staff Name**: Enter the name of the staff member submitting the announcement.
   - **Announcement Message**: Compose a brief message about the announcement.
   - **Announcement File**: If applicable, upload any relevant files or attachments.
   - **Submission Note**: Provide any additional notes about the submission.
   - **Submission Status**: Select the status of the submission (Completed, In Progress, Pending, or Cancelled).
   - **Submission Comment**: Add any additional comments about the submission.
   - **Submission Form ID**: Enter the ID of the submission form (optional).
   - **Submission User ID**: Enter your ID as the user submitting the form (optional).
   - **Submission IP**: Record the IP address of the user submitting the form (optional).
   - **Submission User Agent**: Note the User Agent used by the user submitting the form (optional).
   - **Submission User OS**: Note the Operating System used by the user submitting the form (optional).
2. Review and submit the form once all required fields are filled.
