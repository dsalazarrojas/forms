# read_a_thon_participation_form - Help Guide

## Purpose

The read-a-thon participation form is a tool used to track student participation in a read-a-thon event. This form helps to collect information about a student's reading goals, progress, and status, and is intended for educational use.

## How To Complete This Form

1. Start by filling out the form with the required information, which includes:
	* `student_name`: Enter the name of the student participating in the read-a-thon.
	* `parent_name`: Enter the name of the student's parent or guardian.
	* `school_name` and `school_email`: Enter the name and email address of the school the student attends.
2. Set the `student_grade` field to the student's current grade level.
3. Set the `student_reading_goal` field to the number of minutes the student hopes to read during the read-a-thon.
4. Select the student's `participant_status` by choosing one of the available options.
5. Select the student's address from the available options in the `student_address` field.
6. Select the parent or guardian's permission level by choosing one of the available options in the `parent_permission` field.
7. Select the type of participant the student is (e.g., individual, team, etc.) by choosing one of the available options in the `participant_type` field.
8. Optionally, set the `student_goal` field to a specific date for the student to reach their reading goal by.
9. Optionally, set the `start_date` and `end_date` fields to specify the start and end dates of the read-a-thon event.
10. Add any additional notes or comments about the student's participation in the `notes` field.
11. Finally, submit the completed form.

## Field-by-Field Explanation

* **read_thon_participation_form_label**: Enter a title for the form, which should be a descriptive name for the event or program.
	* Required: No
* **student_name_label** (student_name): Enter the name of the student participating in the read-a-thon.
	* Required: Yes
* **parent_name_label** (parent_name): Enter the name of the student's parent or guardian.
	* Required: Yes
* **student_grade_label** (student_grade): Set the student's current grade level.
	* Required: Yes
* **school_name_label** (school_name): Enter the name of the school the student attends.
	* Required: Yes
* **school_email_label** (school_email): Enter the email address of the school.
	* Required: Yes
* **student_reading_goal_label** (student_reading_goal): Set the number of minutes the student hopes to read during the read-a-thon.
	* Required: No
* **participant_status_label** (participant_status): Select one of the available participant status options.
	* Required: No
* **student_address_label** (student_address): Select the student's address from the available options.
	* Required: No
* **parent_permission_label** (parent_permission): Select the parent or guardian's permission level.
	* Required: No
* **participant_type_label** (participant_type): Select the type of participant the student is (e.g., individual, team, etc.).
	* Required: No
* **participant_goal_label** (participant_goal): Set a specific date for the student to reach their reading goal by.
	* Required: No
* **start_date_label** (start_date): Set the start date of the read-a-thon event.
	* Required: No
* **end_date_label** (end_date): Set the end date of the read-a-thon event.
	* Required: No
* **notes_label** (notes): Add any additional notes or comments about the student's participation.
	* Required: No
* **form_id_label** (form_id): Enter a form ID number.
	* Required: No

# Tips

* Please fill out this form with accurate and truthful information about the student's participation in the read-a-thon.
* If you are a parent or guardian, please ensure that the student understands their reading goal and is committed to reaching it.
* If you have any questions or need assistance with the form, contact the read-a-thon organizers or administrators.
* This form is intended for informational purposes only and will not be used for any other reason without your consent.
