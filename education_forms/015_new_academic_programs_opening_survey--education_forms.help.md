# New Academic Programs Opening Survey - Help Guide
## Purpose
The New Academic Programs Opening Survey is a form used to collect information about new academic programs that are opening up at an institution. This information will help the administration and staff better understand the new programs and their details.

## How To Complete This Form
To complete this form, follow the instructions below:

1. Please answer all the questions accurately and thoroughly.
2. Make sure to fill in all required fields (indicated by a star *).
3. Select the correct options for the questions that are marked as "select_one".
4. Enter your name and email address if you want to receive any updates or notifications regarding the new program.

## Field-by-Field Explanation

* **New Academic Programs Opening Survey**: This is the title of the form, and it will help you know what the form is about.
* *academic_category*: Please indicate if the new program is a part of a new academic category or not.
* **course_name**: Enter the name of the new academic program.
* **course_description**: Write a detailed description of the new academic program.
* *expected_students*: Enter the expected number of students for the new program.
* *program_length*: Enter the length of the new program.
* **start_date**: Enter the start date of the new program (in the format MM/DD/YYYY).
* **end_date**: Enter the end date of the new program (in the format MM/DD/YYYY).
* **instructor**: Enter the name of the instructor for the new program.
* **contact_person**: Enter the name and email of the contact person for the new program.

## Tips
* Please make sure to fill in all required fields correctly.
* If you have any questions or doubts, contact the institution's administration or support staff.
* If you need to update any information, please use this form again to provide the latest details.
