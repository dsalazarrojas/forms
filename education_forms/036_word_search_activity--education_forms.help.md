# Word Search Activity - Help Guide

## Purpose
The Word Search Activity form allows users to create a customized word search puzzle with specific parameters. This form is designed to provide options for grid size, grid orientation, background color, font, and word list type.

## How To Complete This Form

1. Select the grid size for the word search puzzle. Choose from options 10x10, 12x12, 15x15, or 20x20.
2. Choose the grid orientation: Horizontal or Vertical.
3. Select the background color for the puzzle: White or Blue.
4. Choose the font color for the puzzle: Black or Blue.
5. Select the font size for the puzzle: 10pt, 12pt, or 14pt.
6. Choose the font style for the puzzle: Normal, Italic, or Oblique.
7. Select the word count for the puzzle: 5, 10, or 15.
8. Choose the word type for the puzzle: Word list, Phrase list, or Mixed list.
9. Select the word description for the puzzle: Brief, Short, or Long.
10. Optionally, provide an example of the word list.

## Field-by-Field Explanation

* **Grid Size** (10x10, 12x12, 15x15, 20x20): Choose the size of the grid for the word search puzzle.
* **Grid Orientation** (Horizontal, Vertical): Choose the orientation of the grid for the puzzle.
* **Grid Orientation Label** (Text): Enter a label for the grid orientation (optional).
* **Grid Cells** (Yes, No): Choose whether the puzzle should have grid cells or not.
* **Background Color** (White, Blue): Choose the background color for the puzzle.
* **Background Image** (Text): Enter the path to the background image (optional).
* **Font Color** (Black, Blue): Choose the font color for the puzzle.
* **Font Size** (10pt, 12pt, 14pt): Choose the font size for the puzzle.
* **Font Style** (Normal, Italic, Oblique): Choose the font style for the puzzle.
* **Word Count** (5, 10, 15): Choose the number of words to include in the puzzle.
* **Word Type** (Word list, Phrase list, Mixed list): Choose the type of word list to include in the puzzle.
* **Word Description** (Brief, Short, Long): Choose a brief or long description for the puzzle.
* **Word List** (Text): Enter a list of words to include in the puzzle.
* **Word List Example** (Text): Enter an example of the word list (optional).
* **Word Description** (Select): Choose a description for the word list (Brief, Short, Long).
* **Word Count** (Select): Choose the number of words to include in the list.
* **Word Type** (Select): Choose the type of word list to include (Word list, Phrase list, Mixed list).
