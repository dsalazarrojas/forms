# Faculty Recognition Program Support Request Form - Help Guide
## Purpose
The Faculty Recognition Program Support Request Form is a tool for submitting requests for recognition of outstanding faculty members within your educational institution. This form is designed to gather essential information about the event, faculty member, and recognition details.

## How To Complete This Form

1. **Select "Institution":** Choose the institution where the faculty member works or affiliated with. This will help the recognition program team identify the correct department and faculty member.
2. **Enter "Department":** Provide the department where the faculty member is currently working or affiliated with.
3. **Enter "Faculty Name" and "Faculty Title":** These fields are self-explanatory and should be completed with the relevant information.
4. **Select the "Recognition Category":** Choose the category for recognition from the provided options (Award, Honorable Mention, Meritorious Performance).
5. **Provide a reason for recognition**: If you want to explain why the faculty member should be recognized, please do so in the "Reason for Recognition" field.
6. **Date of Event**: If the recognition event has occurred, select the date of the event. Otherwise, this field is not required.
7. **Time of Event**: This field is only required if the event occurred on a specific date. If not, select '00:00' to indicate that it didn't occur during a specific time.
8. **Event Type**: Choose the type of event from the provided options (Conference, Workshop, Seminar, Symposium, Other).
9. **Recognition Date**: Set the date when the recognition should take place.
10. **Review Date**: Set the date by which the review of the recognition request should be completed.

## Field-by-Field Explanation

* **Institution** (Required): The institution where the faculty member works or is affiliated with.
* **Department** (Required): The department where the faculty member is currently working or affiliated with.
* **Faculty Name** (Required): The name of the faculty member being recognized.
* **Faculty Title** (Required): The title of the faculty member being recognized.
* **Recognition Category** (Required): Select one or more categories for recognition (Award, Honorable Mention, Meritorious Performance).
* **Reason for Recognition** (Optional): A brief explanation for why the faculty member should be recognized.
* **Date of Event** (Optional): The date of the event where the recognition took place.
* **Time of Event** (Optional): The time of the event where the recognition took place. If not applicable, select '00:00'.
* **Event Type** (Required): Choose the type of event from the provided options (Conference, Workshop, Seminar, Symposium, Other).
* **Recognition Date** (Required): The date when the recognition should take place.
* **Review Date** (Required): The date by which the review of the recognition request should be completed.

## Tips

* Ensure that you are submitting a unique and accurate request.
* Review the form carefully before submitting to avoid errors.
* If you are unsure about any field, you can contact the support team for assistance.
