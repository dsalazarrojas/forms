# graduate_school_interview_form - Help Guide
## Purpose
The Graduate School Interview Form is designed to collect information from interviewers and reviewers about a candidate's performance during a graduate school interview.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the form for each candidate individually.
2. Ensure that each form has a unique candidate ID.
3. Provide accurate and concise information about the candidate.

## Field-by-Field Explanation

* **Candidate Details** (text):
	+ This field is used to input the candidate's name, date of birth, and other relevant details.
	+ Please enter the candidate's name and any other relevant information in this field.
* **Interview Schedule** (date):
	+ This field is used to input the date and time of the interview.
	+ Please enter the date and time of the interview in the format MM/DD/YY or YYYY-MM-DD.
* **Evaluation** (select one):
	+ This field is used to select the overall evaluation of the candidate's performance.
	+ Select 'Yes' if the candidate performed well, and 'No' if they did not perform well.
* **Candidate Status** (select multiple):
	+ This field is used to select the candidate's status in the graduate school program.
	+ Please select all relevant statuses, such as 'Active', 'Inactive', or both.
* **Assigned Reviewer** (select one):
	+ This field is used to select whether the candidate has been assigned a reviewer.
	+ Select 'Yes' if the candidate has been assigned a reviewer, and 'No' if they have not.
* **Reviewer Notes** (text):
	+ This field is used to input any notes from the reviewer.
	+ Please enter any additional comments or information from the reviewer.
* **Candidate Score** (number):
	+ This field is used to input the candidate's overall score.
	+ Please enter a number between 1 and 5, where 1 is low and 5 is high.
* **Assigned Tool** (select one):
	+ This field is used to select the tool assigned to the candidate.
	+ Please select the tool used for the interview, such as 'chatjimmy' or 'tool2'.
* **Other Tools** (select multiple):
	+ This field is used to select any other tools used during the interview.
	+ Please select all tools used, such as 'tool1', 'tool2', or 'tool3'.
* **Comments** (text):
	+ This field is used to input any additional comments about the candidate.
	+ Please enter any relevant comments or observations about the candidate's performance.

## Tips
* Please ensure that all fields are filled out accurately and completely.
* If you are unsure about any field, please consult the relevant guidelines or your supervisor.
