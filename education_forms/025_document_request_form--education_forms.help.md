# Document Request Form - Help Guide
## Purpose
The Document Request Form is used to collect information about a student's document requests, such as transcripts, diplomas, or certifications. This form helps administrative or support staff to gather the necessary details to process the document requests efficiently.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the User Name field with the name of the student or individual requesting the document.
2. Enter the Student ID number in the Student ID field.
3. Select the type of document being requested (e.g., Transcript, Diploma, or Certification) in the Document Type field.
4. Enter the student's Date of Birth in the Date Of Birth field.
5. Enter the date the document was originally requested in the Document Date field.
6. Choose the current status of the document request (e.g., Requested, Issued, or Completed) in the Document Status field.
7. Provide a brief reason for requesting the document in the Reason For Request field.
8. Optionally enter a contact phone number in the Contact Phone field (if applicable).

## Field-by-Field Explanation

* **User Name** (Text Field): This field is optional and requires only a text entry. Please fill in the name of the student or individual requesting the document.
* **Student ID** (Number Field): Enter the student's identification number, if applicable.
* **Document Type** (Select One Field): Choose the type of document being requested (e.g., Transcript, Diploma, Certification).
* **Date Of Birth** (Date Field): Enter the student's date of birth.
* **Document Date** (Date Field): Enter the date the document was originally requested.
* **Document Status** (Select One Field): Choose the current status of the document request (e.g., Requested, Issued, Completed).
* **Reason For Request** (Text Field): Provide a brief explanation of why the document is being requested.
* **Contact Phone** (Text Field): If necessary, enter a contact phone number for further communication.
