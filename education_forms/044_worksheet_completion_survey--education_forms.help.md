# Worksheet Completion Survey - Help Guide
## Purpose
This guide will help you complete the Worksheet Completion Survey form, which is designed to gather feedback on the completion of worksheets in your classroom.

## How To Complete This Form
To complete this form, follow these steps:

* Read through each section carefully and select the best response for each question.
* For the select_one and select_multiple questions, choose the option that best describes your experience.
* For the select_multiple question, select all the options that apply to you.
* For the text field, type any additional comments or thoughts you have.

## Field-by-Field Explanation
### Page 1: Survey Completion
* **Survey Completion** (`survey_completion_survey`, select_multiple): Select all the ways in which you completed the worksheet, if any. This includes "Yes" or "No" options.
* **Clarity** (`worksheet_clarity`, select_one): How clear was the content?
	+ Choose "Clear" if the content was easy to understand.
	+ Choose "Somewhat clear" if the content was somewhat easy to understand, but some parts were confusing.
	+ Choose "Not clear" if the content was difficult to understand.
* **Instructional Materials** (`instructional_materials`, select_multiple): Select all the materials you use most often when creating worksheets.
	+ Choose "Textbook" if you use textbooks as a primary source.
	+ Choose "Online resources" if you use online resources like websites or videos.
	+ Choose "Handouts" if you use handouts or printed materials.
	+ Choose "Other (please specify)" if you use other materials not listed here.
* **Engagement** (`engagement`, select_one): How engaging was the content?
	+ Choose "Engaging" if the content was interesting and held your attention.
	+ Choose "Somewhat engaging" if the content was somewhat interesting, but not fully engaging.
	+ Choose "Not engaging" if the content was boring or uninteresting.
* **Learning Outcomes** (`learning_outcomes`, select_one): To what extent did this worksheet help you achieve the desired learning outcomes?
	+ Choose "Achieved the learning outcomes" if the worksheet helped you achieve the desired outcomes.
	+ Choose "Mostly achieved the learning outcomes" if the worksheet mostly helped you achieve the desired outcomes.
	+ Choose "Did not achieve the learning outcomes" if the worksheet did not help you achieve the desired outcomes.
* **Ease of Use** (`ease_of_use`, select_one): How easy was it to use?
	+ Choose "Easy to use" if the worksheet was simple and straightforward to use.
	+ Choose "Somewhat easy to use" if the worksheet was somewhat simple and straightforward to use.
	+ Choose "Not easy to use" if the worksheet was difficult to use.
* **Comments** (`comments`, text): Please add any additional comments or thoughts about the worksheet.
* **Tool** (`assigned_tool`, select_one): Choose the tool that was used to create this worksheet.
	+ Choose "Tool 1" if you used a certain tool to create the worksheet.
	+ Choose "Tool 2" if you used another tool to create the worksheet.
	+ Choose "Tool 3" if you used a third tool to create the worksheet.

## Tips
* Be honest in your responses. This will help us understand your experience with the worksheet.
* Select only the options that apply to you.
* If you have any additional comments or thoughts, please add them in the comments field.
