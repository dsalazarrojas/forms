# Early Childhood Guardian Interview Form - Help Guide
## Purpose
This form is designed to gather essential information about the child's developmental abilities and needs. It is intended for use by caregivers or educators to assess the child's progress and identify potential areas of support. The information collected will help inform early childhood services and programs tailored to the child's requirements.

## How To Complete This Form

1. Fill in the child's name in the designated field.
2. Select the guardian's relationship to the child (e.g., parent, grandparent, etc.).
3. Choose the child's gender.
4. Enter the child's age (in years).
5. Provide the guardian's contact number and email (if applicable).
6. Select the child's special needs (if any).
7. Choose the child's diet preferences.
8. Indicate if the child takes any medication or food supplements.
9. Select any allergies the child has.
10. Indicate any medical conditions the child has.
11. Select the child's ability to perform physical actions (e.g., crawl, sit, stand, etc.).
12. Select the child's communication abilities (e.g., speaking, counting, etc.).

## Field-by-Field Explanation
* **Child Name**: Enter the child's name accurately and as it is written on their identification documents.
* **Guardian Relationship**: Choose how the guardian is related to the child (e.g., parent, grandparent, etc.).
* **Child Gender**: Select the child's gender (e.g., Male, Female, Other).
* **Child Age**: Enter the child's age in years.
* **Guardian Contact Number**: Enter the guardian's contact number (e.g., phone number, email).
* **Guardian Contact Email**: Enter the guardian's email (if applicable).
* **Child Special Needs**: Select any special needs the child may have (e.g., physical, emotional, developmental, etc.).
* **Child Diet**: Select the child's dietary preferences (e.g., vegetarian, vegan, etc.).
* **Medication/Medication**: Select if the child takes any medication or food supplements (e.g., vitamins, etc.).
* **Allergies**: Select any allergies the child has.
* **Medical Conditions**: Indicate if the child has any medical conditions.
* **Child Able To Crawl**: Select if the child is able to crawl.
* **Child Able To Sit Up**: Select if the child is able to sit up.
* **Child Able To Stand Up**: Select if the child is able to stand up.
* **Child Able To Climb Ladder**: Select if the child can climb a ladder.
* **Child Can Say First Word**: Select if the child can say their first word.
* **Child Can Say Complete Sentence**: Select if the child can speak complete sentences.
* **Child Can Identify Family Members**: Select if the child can identify their family members.
* **Child Can Count Tens**: Select if the child can count to ten.
* **Child Can Count Hundreds**: Select if the child can count to one hundred.
* **Child Can Count Thousands**: Select if the child can count to one thousand.
* **Child Can Recount**: Select if the child can recount numbers.
* **Child Can Recite Name**: Select if the child can recite their name.
* **Child Can Recite Full Name**: Select if the child can recite their full name.
* **Child Can Recite Age**: Select if the child can say their age.
