# Pedagogical Innovation Pilot Application Form - Help Guide
## Purpose
This form is designed to support educational institutions in applying for pedagogical innovation pilots. It gathers necessary information to assess and implement the innovation.

## How To Complete This Form
To complete this form, please follow these steps:

1. Enter your school name.
2. Provide your name and contact details (contact person, email, and department).
3. Indicate the project name and type.
4. Enter a brief description of the innovation.
5. Enter the start and end dates for the project.
6. Specify the project's budget.
7. Describe the expected outcomes of the innovation.
8. Optionally, provide any additional comments about the project.
9. Upload relevant files or project URLs, if applicable.
10. Indicate the project category and status.
11. Select the required tags for the project.
12. Finally, preview and submit your application.

## Field-by-Field Explanation

* **School Name**: Enter the name of the school or institution applying for the pedagogical innovation pilot.
* **Contact Person**: Provide the name and contact details of the contact person for the project.
* **E-mail**: Enter a valid email address for the contact person.
* **Department**: Enter the department or unit responsible for the innovation.
* **Role**: Indicate the role of the contact person within the institution (e.g., teacher, admin, etc.).
* **Project Name**: Enter a brief title or name for the innovation project.
* **Description**: Provide a concise description of the innovation, including its goals and objectives.
* **Start Date**: Enter the start date of the innovation project.
* **End Date**: Enter the end date of the innovation project.
* **Location**: Specify the location(s) where the innovation will be implemented.
* **Budget**: Enter the budget allocated for the innovation project.
* **Expected Outcome**: Describe the expected outcomes of the innovation, including any positive impacts on students or the institution.
* **Evaluation**: Provide any comments or feedback about the innovation's evaluation process.
* **Submission Date**: Enter the date of submission of the application.
* **School URL**: Enter the URL of the school or institution's website.
* **Project URL**: Enter any relevant project URL(s), if applicable.
* **File Upload**: Upload any supporting files, like project plans or documents.
* **File Type**: Indicate whether a file is required or not.
* **Project Type**: Indicate whether the project is internal or external to the institution.
* **Category**: Select the category of the innovation, if applicable.
* **Status**: Indicate the status of the project (e.g., Active, Inactive).
* **Tags**: Select any relevant tags for the project, like keywords or themes.
* **Comments**: Enter any additional comments about the project, if necessary.
* **Submit**: Review and submit your application after filling out all required fields.
