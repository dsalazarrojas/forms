# Pedagogical Innovation Showcase Consent Form - Help Guide
## Purpose
This form is designed to collect information about a teaching project, including the project leader's contact details and a description of the project, to facilitate communication and collaboration among project stakeholders.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the Project Leader Name in the "Project Leader Name" field.
2. Enter the Project Leader Email address in the "Project Leader Email" field.
3. Enter the Project Leader Phone number in the "Project Leader Phone" field.
4. Enter a title for the teaching project in the "Teaching Project Title" field.
5. Enter a description of the teaching project in the "Teaching Project Description" field.
6. Enter a title for the student work associated with the project in the "Student Work Title" field.
7. Enter a description of the student work in the "Student Work Description" field.

## Field-by-Field Explanation
* **Project Leader Name** (`project_leader_name`, text, optional): Enter the name of the person leading the teaching project.
* **Project Leader Email** (`project_leader_email`, email, optional): Enter the email address of the person leading the teaching project.
* **Project Leader Phone** (`project_leader_phone`, text, optional): Enter the phone number of the person leading the teaching project.
* **Teaching Project Title** (`teaching_project_title`, text, optional): Enter a brief title for the teaching project.
* **Teaching Project Description** (`teaching_project_description`, text, optional): Enter a description of the teaching project.
* **Student Work Title** (`student_work_title`, text, optional): Enter a brief title for the student work associated with the project.
* **Student Work Description** (`student_work_description`, text, optional): Enter a description of the student work associated with the project.

## Tips
* Make sure to enter accurate contact information for the project leader.
* Keep the project and student work descriptions concise and clear.
* If you are unsure about any of the fields, please feel free to ask for clarification.
