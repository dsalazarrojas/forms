# University Educational Tool Order Form - Help Guide
## Purpose
This form is designed to collect information from users regarding their educational tool requests.

## How To Complete This Form
To complete this form, please fill out each section with the required information. The form is divided into several fields that are categorized into different sections. Please follow the instructions below for each section.

## Field-by-Field Explanation
### University Educational Tool Order Form
This is the title of the form, which does not require any input from the user.

### University Educational Tool Order Form
This field is a text input field where you can enter any additional information about your request. Enter your thoughts or comments here.

### Department (Select One)
Choose whether the educational tool is related to your department or not.

### Tool Description
This field is a text input field where you can describe the tool you are requesting. Enter a brief description of the tool here.

### Requested Date
Please enter the date when the tool is requested.

### Requested Time
This field is a time input field where you can indicate when the tool is requested. Enter the time in 24-hour format (e.g., 14:00).

### Tool Type (Select Multiple)
Choose the type of tool you are requesting.

### Tool Location
This field is a text input field where you can specify the location where the tool will be used.

### Requester Information
Please enter the name of the person or department that requested the tool.

### E-mail Requester
Enter the email address of the person or department that requested the tool.

### Phone Requester
Enter the phone number of the person or department that requested the tool.

### Note (Requester)
This field is a text input field where you can add any additional notes or comments about the request.

### Assigned Tool
Check this field if the tool has been assigned to the requester.

### Status
Choose the status of the tool request (Active or Inactive).

### Review Note
This field is a text input field where you can add any additional comments or feedback about the request.

### Form ID
This is a unique identifier for the form and does not require any input from the user.
