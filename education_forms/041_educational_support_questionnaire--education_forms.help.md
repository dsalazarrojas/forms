# Educational Support Questionnaire - Help Guide

## Purpose
This form is designed to gather information about the educational support needs of students or learners. It asks questions about the type of support required, the reasons for the support, and other relevant details.

## How To Complete This Form

To complete this form, follow these steps:

1. Select "Educational Support" from the first question.
2. Choose "Yes" or "No" to answer the following questions:
   * "Category"
   * "Category Educational Support Questionnaire 2"
3. Enter any additional details in the "Description" field.
4. Optionally, select "Yes" or "No" if you have any specific tools assigned to you for support.
5. Enter the "Form ID" if applicable.
6. Choose "Yes" or "No" if you need an output file.
7. Enter any additional details in the "Description Educational Support Questionnaire 2" field if applicable.

## Field-by-Field Explanation

* **Educational Support** (`educational_support_questionnaire`, text, required/optional): This is the main field where you can describe the type of educational support needed.
* **Category** (`category_educational_support_questionnaire`, select_one, optional): Choose "Yes" if you need educational support for your students.
* **Description** (`description_educational_support_questionnaire`, text, optional): Enter any additional details about the educational support required.
* **Assigned Tool** (`assigned_tool_educational_support_questionnaire`, text, optional): If you have any specific tools assigned to you for support, enter them here.
* **Educational Support Questionnaire Category** (`educational_support_questionnaire_category`, select_one, optional): Choose "Yes" if this support is related to your category.
* **Form ID** (`form_id_educational_support_questionnaire`, number, optional): Enter the ID of the form, if applicable.
* **Output File** (`output_file_educational_support_questionnaire`, text, optional): Choose "Yes" if you need an output file.
* **Description Educational Support Questionnaire 2** (`description_educational_support_questionnaire_2`, text, optional): Enter any additional details about the educational support required.
* **Category Educational Support Questionnaire 2** (`category_educational_support_questionnaire_2`, select_one, optional): Choose "Yes" if this support is related to your category.
* **Form ID** (`form_id_educational_support_questionnaire_2`, number, optional): Enter the ID of the form, if applicable.
