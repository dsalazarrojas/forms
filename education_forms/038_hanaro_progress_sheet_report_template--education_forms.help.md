# Hanaro Progress Sheet Report Template - Help Guide
## Purpose
The Hanaro Progress Sheet Report Template is a form used to track and report on student progress in reading, listening, speaking, and understanding skills. It is designed to provide a comprehensive overview of a student's development, allowing educators to assess and evaluate their performance.

## How To Complete This Form
To complete this form, follow these steps:
1. Fill in the student's name.
2. Enter the student's number.
3. Record the progress made in reading, listening, speaking, and understanding skills.
4. Add any relevant notes or comments for each skill.
5. Set goals for each skill.
6. Enter the date the progress was completed.

## Field-by-Field Explanation

* **Form Data** (`form_data`, text, optional): This field is not used in this template.
* **Student Name** (`student_name`, text, optional): Enter the student's name as it appears on their records.
* **Student Number** (`student_number`, number, optional): Enter the student's number as assigned by the institution.
* **Reading Progress** (`reading_progress`, number, optional): Record the progress made in reading skills.
* **Listening Progress** (`listening_progress`, number, optional): Record the progress made in listening skills.
* **Speaking Progress** (`speaking_progress`, number, optional): Record the progress made in speaking skills.
* **Understanding Progress** (`understanding_progress`, number, optional): Record the progress made in understanding skills.
* **Reading Notes** (`reading_progress_notes`, text, optional): Add any notes or comments for reading skills.
* **Listening Notes** (`listening_progress_notes`, text, optional): Add any notes or comments for listening skills.
* **Speaking Notes** (`speaking_progress_notes`, text, optional): Add any notes or comments for speaking skills.
* **Understanding Notes** (`understanding_progress_notes`, text, optional): Add any notes or comments for understanding skills.
* **Reading Comments** (`reading_comments`, text, optional): Record any comments or feedback on reading skills.
* **Listening Comments** (`listening_comments`, text, optional): Record any comments or feedback on listening skills.
* **Speaking Comments** (`speaking_comments`, text, optional): Record any comments or feedback on speaking skills.
* **Understanding Comments** (`understanding_comments`, text, optional): Record any comments or feedback on understanding skills.
* **Reading Goals** (`reading_goals`, text, optional): Set goals for reading skills.
* **Listening Goals** (`listening_goals`, text, optional): Set goals for listening skills.
* **Speaking Goals** (`speaking_goals`, text, optional): Set goals for speaking skills.
* **Understanding Goals** (`understanding_goals`, text, optional): Set goals for understanding skills.
* **Additional Comments** (`additional_comments`, text, optional): Add any additional comments or feedback.
* **Reading Comments 1** (`reading_comments_1`, text, optional): Record any comments or feedback on reading skills.
* **Reading Comments 2** (`reading_comments_2`, text, optional): Record any comments or feedback on reading skills.
* **Reading Comments 3** (`reading_comments_3`, text, optional): Record any comments or feedback on reading skills.
* **Date Completed** (`date_completed`, date, optional): Enter the date the progress was completed.
