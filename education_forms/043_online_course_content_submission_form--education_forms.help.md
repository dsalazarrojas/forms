# Online Course Content Submission Form - Help Guide
## Purpose
This form is designed for submitting online course content. It collects information such as course title, category, description, and more to facilitate the review and management of courses.

## How To Complete This Form
To complete this form, follow these steps:
- Fill in the course title, which is the name of the course you are submitting.
- Select the course category, which can be Math, Science, English, or Social Studies.
- Provide a brief description of the course.
- Enter the submission date, which is the date you are submitting the course.
- Enter the instructor's name, who will be associated with the course.
- Upload any relevant course files, if applicable.
- Leave review comments for the reviewer if you want to communicate any specific details.
- Finally, choose the course status, which can be Draft, Published, or Archived.

## Field-by-Field Explanation
### 1. **Course Title** (`course_title`, text, optional)
The course title is the name of the course you are submitting.

### 2. **Course Category** (`course_category`, select_one, required)
Select the category of the course, which can be Math, Science, English, or Social Studies.

### 3. **Course Description** (`course_description`, text, optional)
Provide a brief description of the course.

### 4. **Submission Date** (`submission_date`, date, optional)
Enter the date you are submitting the course.

### 5. **Instructor Name** (`instructor_name`, text, optional)
Enter the name of the instructor associated with the course.

### 6. **Course Files** (`course_files`, text, optional)
Upload any relevant course files if applicable.

### 7. **Review Comments** (`review_comments`, text, optional)
Leave review comments for the reviewer if you want to communicate any specific details.

### 8. **Course Status** (`course_status`, select_multiple, required)
Choose the course status, which can be Draft, Published, or Archived.

### 9. **Course Tags** (`course_tags`, text, optional)
Enter any relevant course tags or keywords.
