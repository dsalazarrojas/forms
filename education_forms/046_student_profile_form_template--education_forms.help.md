# Student Profile Form Template - Help Guide
## Purpose
This form is a template for collecting and storing student profile information. It can be used by institutions to gather data on students' demographics, educational background, and interests.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the student's name in the `student_name` field.
2. Enter the student's email address in the `student_email` field.
3. Enter the student's phone number in the `student_phone` field.
4. Select the student's date of birth from the calendar in the `student_date_of_birth` field.
5. Choose the student's current program of study from the options in the `student_program` field.
6. Select all relevant courses the student is enrolled in from the options in the `student_course` field. You can select multiple courses.
7. Enter any additional comments about the student in the `student_interests` field.
8. Add any additional comments about the student in the `student_additional_comments` field.
9. Indicate whether parent permission is required or not in the `student_parent_permission` field.

## Field-by-Field Explanation
* **student_name (Text, optional)**: Enter the student's name.
* **student_email (Email, optional)**: Enter the student's email address.
* **student_phone (Text, optional)**: Enter the student's phone number.
* **student_date_of_birth (Date, optional)**: Select the student's date of birth from the calendar.
* **student_program (Select One, optional)**: Choose the student's current program of study (High school, Undergraduate, Graduate).
* **student_course (Select Multiple, optional)**: Select all relevant courses the student is enrolled in (Science, Arts, Humanities).
* **student_interests (Text, optional)**: Enter any additional comments about the student's interests.
* **student_additional_comments (Text, optional)**: Add any additional comments about the student.
* **parent_permission (Select One, optional)**: Indicate whether parent permission is required or not (True, False).
