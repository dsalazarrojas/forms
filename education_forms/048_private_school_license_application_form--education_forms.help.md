# private_school_license_application_form - Help Guide
## Purpose
This form is for private schools to apply for a license. It gathers information about the user, school, educational program, and school finances.

## How To Complete This Form
To complete this form, follow these steps:

1. Provide your user information on page 1.
2. Enter school information, including details about the educational program, on page 2.
3. Add more educational program details on page 3.
4. Provide school financial information on page 4.
5. Include school financial details on page 5.
6. Add additional financial information on page 6.
7. Review and submit your application on page 7.
