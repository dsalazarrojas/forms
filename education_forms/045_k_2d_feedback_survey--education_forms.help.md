# k_2d_feedback_survey - Help Guide
## Purpose

This form is designed to collect feedback from various stakeholders (students, parents, and teachers) regarding the quality of a 2D feedback survey. The purpose of this form is to gather opinions and experiences of the stakeholders in order to improve the 2D feedback system.

## How To Complete This Form

1. Please fill out this form to provide feedback on the 2D feedback survey.
2. Select the relevant options for each field to accurately reflect your experience.
3. Make sure to fill out all required fields.
4. If you are unsure of any field, please ask for help.

## Field-by-Field Explanation

* **General Information**: This field is a text box where you can provide any general comments or feedback about the 2D feedback survey.
* **Teacher Feedback**: Please select all that apply to provide feedback about the 2D feedback survey from a teacher's perspective.
* **Student Parent Feedback**: Please select all that apply to provide feedback about the 2D feedback survey from a student's parent perspective.
* **Teacher Survey**: Please select all that apply to provide feedback about the 2D feedback survey from a teacher's perspective.
* **Student Survey**: Please select all that apply to provide feedback about the 2D feedback survey from a student's perspective.
* **Parent Survey**: Please select all that apply to provide feedback about the 2D feedback survey from a parent's perspective.
* **Comments**: This field is for any additional comments or feedback about the 2D feedback survey.
* **Email**: Please enter a valid email address where you would like to receive feedback on this form.
* **Phone**: Enter a valid phone number where you can be reached.
* **Date**: Select the date on which you are submitting this form.
* **Time**: Select the time on which you are submitting this form.
* **Submitted By**: Please select who submitted this form (Student, Parent, Teacher).
* **Submitted By Other**: Please enter other information about who submitted this form.
* **Submitted By Email**: Please enter a valid email address where the form was submitted from.
* **Submitted By Phone**: Enter a valid phone number where the form was submitted from.
* **Submitted By Date**: Select the date on which this form was submitted.
* **Submitted By Time**: Select the time on which this form was submitted.

## Tips

* Please be as detailed as possible when providing feedback.
* Make sure to fill out all required fields.
* If you have any questions, feel free to ask for help.
