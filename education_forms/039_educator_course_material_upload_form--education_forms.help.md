# Educator Course Material Upload Form - Help Guide
## Purpose
The Educator Course Material Upload Form is a tool for educators to upload course materials to the system for review and approval. This form allows you to upload multiple course materials at once, including course descriptions, tags, and files.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the School Name field with the name of the school where the course is offered.
2. Provide the name of the course in the Course Name field.
3. Enter a brief description of the course in the Course Description field.
4. Select the relevant tags for the course in the Course Tags field. You can select multiple tags by holding down the Ctrl key (or Command key on Mac) while clicking on the tags.
5. Upload any relevant files related to the course in the Uploaded File field.
6. Enter the name of the course instructor in the Instructor Name field.
7. Select the course level (Beginner, Intermediate, or Advanced) in the Course Level field.
8. Enter the date of the course in the Course Date field in the format `YYYY-MM-DD`.
9. Set the course duration in the Course Duration field.
10. Describe the course outcome in the Course Outcome field.
11. Enter the location of the course file in the Course File Location field.
12. (Optional) Select additional tags for the course in the Course Tags 2 field.
13. (Optional) Upload additional files related to the course in the Uploaded File 2 field.
14. (Optional) Select the level of the course (Beginner, Intermediate, or Advanced) in the Course Level 2 field.
15. (Optional) Set the time of the course in the Course Time 2 field.
16. (Optional) Set the duration of the course in the Course Duration 2 field.
17. (Optional) Describe the outcome of the course in the Course Outcome 2 field.
18. (Optional) Enter the location of the course file in the Course File Location 2 field.
19. (Optional) Select additional tags for the course in the Course Tags 3 field.
20. (Optional) Upload additional files related to the course in the Uploaded File 3 field.
21. (Optional) Enter the version of the course in the Course Version 2 field.
