# framing-floor - Help Guide
## Purpose
This form is used to gather information from users about their experience with the framing floor.

## How To Complete This Form
To complete this form, follow these steps:

1. Select a choice from the "Component Choices" dropdown menu.
2. Enter a number value for the "Quality Score" field, indicating your assessment of the component.
3. If you have any additional comments or feedback, type them in the "Comments" field.

## Field-by-Field Explanation
* **Component Choices** (select_one):
	+ A dropdown menu to choose one of the options: choice-1, choice-2, or choice-3.
* **Quality Score** (number):
	+ Enter a number value to indicate your assessment of the component.
* **Comments** (note):
	+ A text field for any additional comments or feedback you have about the component.

## Tips
* Make sure to select only one choice from the "Component Choices" dropdown menu.
* The "Quality Score" field requires a numerical value.
* You can type any additional comments or feedback in the "Comments" field, but it is not required.
* If you are unsure about any field, please ask for clarification.
