# in_class_quiz - Help Guide
## Purpose
The in_class_quiz form is used to collect data on the in-class quiz experience.

## How To Complete This Form
1. Fill out the form in its entirety, including the Quiz Start field, which indicates the start of the quiz.
2. Select the answer to the question "questions" by choosing one or more options from the list.
3. Finally, select the answer to the question "Submit Quiz" by choosing one option from the list.

## Field-by-Field Explanation
* **Quiz Start**: This field is the starting point of the quiz, indicating when the quiz began.
* **questions**: This field asks whether the participant found the quiz challenging. Please select all that apply from the options provided.
* **Submit Quiz**: This field asks if the participant is ready to submit their quiz completion status. Select the option that best describes their experience.

## Tips
* Please answer all questions truthfully to ensure accurate data collection.
* If you have any issues with the form, please contact the support team for assistance.
