# stem_education_subscription_form - Help Guide
## Purpose
The stem_education_subscription_form is a form designed to collect information about educational programs in the field of STEM.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the "Program Title" field with the title of the educational program you'd like to submit.
2. Enter the "Institution Name" where the program is offered.
3. Provide a brief description of the program in the "Program Description" field.
4. If the program has a start date, enter it in the "Start Date" field. If it doesn't, you can leave this field blank.
5. Similarly, if the program has an end date, enter it in the "End Date" field. If it doesn't, you can leave this field blank.
6. Select the type of program (Option 1, Option 2, or Option 3) in the "Program Type" dropdown menu.
7. Enter the email address associated with the program or the contact person's email.

## Field-by-Field Explanation
### Program Title
* **Program Title** (`Program Title`, text, required: false): Enter the title of the educational program you'd like to submit.

### Institution Name
* **Institution Name** (`Institution Name`, text, required: false): Enter the name of the institution offering the program.

### Program Description
* **Program Description** (`Program Description`, text, required: false): Provide a brief description of the program.

### Start Date
* **Start Date** (`Start Date`, date, required: false): If the program has a start date, enter it in this field. If it doesn't, you can leave this field blank.

### End Date
* **End Date** (`End Date`, date, required: false): If the program has an end date, enter it in this field. If it doesn't, you can leave this field blank.

### Program Type
* **Program Type** (`Program Type`, select_one, required: false): Select the type of program you're submitting (Option 1, Option 2, or Option 3).

### Email
* **Email** (`Email`, email, required: false): Enter the email address associated with the program or the contact person's email.

## Tips
- Make sure to fill in all required fields to ensure your submission is complete.
- Double-check the entered data for accuracy before submitting.
- If you're unsure about any field or have questions, contact your designated form administrators or the form's author for assistance.
