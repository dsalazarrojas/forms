# iep_student_progress_high_school - Help Guide
## Purpose
This form is used to track student progress in an Individualized Education Program (IEP) for high school students.

## How To Complete This Form

### Step 1: Enter Student Information

* **Student Name** (`student_name`, text, optional): Enter the student's name as it appears on their official records.
* **Student ID** (`student_id`, number, optional): Enter the student's unique identification number.
* **Date of Birth** (`student_date_of_birth`, date, optional): Enter the student's date of birth.

### Step 2: Record Progress Dates

* **IEP Process Start Date** (`iep_process_date_start`, date, optional): Record the date when the IEP process started.
* **IEP Process End Date** (`iep_process_date_end`, date, optional): Record the date when the IEP process ended.

### Step 3: Assess Proficiencies

* **Student Grade Level** (`student_grade_level`, select_one, optional): Select the student's grade level.
* **Student English Proficiency** (`student_english_proficiency`, select_multiple, optional): Select whether the student is proficient in English.
* **Student Math Proficiency** (`student_math_proficiency`, select_multiple, optional): Select whether the student is proficient in Math.
* **Student Reading Proficiency** (`student_reading_proficiency`, select_multiple, optional): Select whether the student is proficient in Reading.
* **Student Writing Proficiency** (`student_writing_proficiency`, select_multiple, optional): Select whether the student is proficient in Writing.
* **Student Behavioral Goals** (`student_behavioral_goals`, select_multiple, optional): Select whether the student has Behavioral Goals.
* **General Education Classrooms** (`general_education_classrooms`, select_multiple, optional): Select whether the student has access to General Education Classrooms.
* **Student Academic Goals** (`student_academic_goals`, select_multiple, optional): Select whether the student has Academic Goals.
* **Student Social Goals** (`student_social_goals`, select_multiple, optional): Select whether the student has Social Goals.

### Step 4: Document Goals and Objectives

* **IEP Goals** (`iep_goals`, select_multiple, optional): Select whether the student has IEP Goals.
* **IEP Objectives** (`iep_objectives`, select_multiple, optional): Select whether the student has IEP Objectives.

### Step 5: Record Interventions and Progress

* **IEP Interventions** (`iep_interventions`, text, optional): Enter any IEP Interventions implemented.
* **IEP Progress Notes** (`iep_progress_notes`, text, optional): Record the IEP Progress Notes.
* **IEP Progress Frequency** (`iep_progress_frequency`, select_one, optional): Select the IEP Progress Frequency.
* **IEP Progress Status** (`iep_progress_status`, select_one, optional): Select the IEP Progress Status.

### Step 6: Set Next Steps and Review

* **IEP Next Step** (`iep_next_step`, text, optional): Record the IEP Next Step.
* **IEP Progress Date** (`iep_progress_date`, date, optional): Record the IEP Progress Date.
* **IEP Reviewer** (`iep_reviewer`, text, optional): Record the IEP Reviewer.
* **IEP Review Date** (`iep_review_date`, date, optional): Record the IEP Review Date.
