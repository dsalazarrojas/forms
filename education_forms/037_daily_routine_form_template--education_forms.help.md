# Daily Routine Form Template - Help Guide
## Purpose
This form is used to collect information about the daily routine of a user. The data collected will be used in educational or research settings to gain insights about user behaviors.

## How To Complete This Form

### Introduction
To complete this form, follow the instructions for each page below. Please ensure that you understand each question before proceeding.

### Page 1: Morning Start Time
* Please select the time you start your day in the morning.

### Page 2: Activities
* Select all activities that apply to you. You can choose multiple activities.
* Options: 'Yes' and 'No'

### Page 3: Notes
* Please provide any additional notes or comments about your daily routine.

### Page 4: Email (Optional)
* If you have any email address that you'd like to provide for contact purposes, please enter it here.

## Field-by-Field Explanation

* **morning_start** (`time`, required: false): This field allows you to select the time you start your day. Please select the time that best represents the start of your day.
* **activities** (`select_multiple`, required: false): This field allows you to select multiple activities that apply to you. Please select all activities that you participate in during the day.
* **notes** (`note`, required: false): This field is for any additional notes or comments about your daily routine.
* **email** (`email`, required: false): This field is for any email address you'd like to provide for contact purposes.
