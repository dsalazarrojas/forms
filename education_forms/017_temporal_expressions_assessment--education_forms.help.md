# Temporal Expressions Assessment - Help Guide
## Purpose
The Temporal Expressions Assessment is a tool to evaluate an individual's understanding and ability to reason about temporal expressions, which are essential in various fields such as linguistics, philosophy, and cognitive science.

## How To Complete This Form
1. Please answer each question carefully, providing your response in the corresponding text field.
2. For questions with multiple options, select the most appropriate answer from the list.
3. If you are unsure about any question, feel free to provide comments or additional information to clarify your response.
4. You can take as much time as needed to complete the form, and there is no specific time limit.

## Field-by-Field Explanation

* **Quiz Question**: This is the first question on the form where you will be presented with a specific temporal expression, and you need to provide a response in the text field.
	+ Type: text
	+ Required: false
* **Answer**: Please provide your response to the quiz question in this text field.
	+ Type: text
	+ Required: false
* **Confidence Rating**: This question is optional and allows you to rate your confidence level in your response, but it's not required.
	+ Type: number
	+ Required: false
* **Writing Task**: This is an optional text field where you can provide additional information or comments about your response.
	+ Type: text
	+ Required: false
* **Comments**: This is an optional text field where you can provide any additional comments or clarification about your response.
	+ Type: text
	+ Required: false
* **Writing Task Rating**: This question is optional and allows you to rate the quality of the writing task.
	+ Type: select_multiple
	+ Required: false
	+ Options: Excellent, Good, Fair, Poor
* **Quiz Score**: This is an optional question where you can provide a score for the quiz question.
	+ Type: number
	+ Required: false
* **Time Spent**: This is an optional question where you can provide the time spent on the quiz question.
	+ Type: number
	+ Required: false
* **Assessment Comments**: This is an optional text field where you can provide any comments or feedback about the assessment.
	+ Type: text
	+ Required: false
* **Quiz Correct**: This is an optional question where you can indicate whether the quiz question was correct or incorrect.
	+ Type: select_one
	+ Required: false
	+ Options: Correct, Incorrect
* **Quiz Incorrect**: This is an optional question where you can indicate whether the quiz question was incorrect.
	+ Type: select_one
	+ Required: false
	+ Options: Correct, Incorrect
* **Quiz Unsure**: This is an optional question where you can indicate whether you were unsure about the quiz question.
	+ Type: select_one
	+ Required: false
	+ Options: Correct, Incorrect, Unsure

## Tips
* Please answer each question carefully and thoughtfully.
* Take as much time as needed to complete the form.
* If you are unsure about any question, please provide comments or additional information to clarify your response.
* The information collected from this form will be used for research and educational purposes only.
