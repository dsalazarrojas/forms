# Yearbook Student Superlatives 2019 - Help Guide
## Purpose
The purpose of this form is to gather information about student superlatives for the Yearbook 2019.

## How To Complete This Form
To complete this form, please follow these steps:

1. Review the form carefully and make sure you have the necessary information required for the questions.
2. Fill in the First Name, Last Name, and Student Gender fields with the correct information.
3. Select the correct answers for the Student Gender, First Name (F), First Name (M), Last Name (F), and Last Name (M) fields based on the student's actual identity.
4. Choose the correct Student Type fields by selecting the relevant options or filling in the text fields as necessary.
5. Ensure that you are filling in the correct information for the Student Type fields.

## Field-by-Field Explanation
* **First Name** (`first_name`, text, required): Enter the student's first name.
* **Last Name** (`last_name`, text, required): Enter the student's last name.
* **Student Gender** (`student_gender`, select_one, optional): Select 'Yes' if the student is male, or 'No' if the student is female. If the student's gender is not male or female, select 'Other' and fill in the `Other` field with the correct information.
* **Other** (`student_gender_other`, text, optional): Fill in this field if the student's gender is not male or female.
* **First Name (F)** (`first_name_female`, select_one, optional): Select 'Yes' if the student's first name is female, or 'No' if not. If not applicable, select 'Other'.
* **First Name (M)** (`first_name_male`, select_one, optional): Select 'Yes' if the student's first name is male, or 'No' if not. If not applicable, select 'Other'.
* **Last Name (F)** (`last_name_female`, select_one, optional): Select 'Yes' if the student's last name is female, or 'No' if not. If not applicable, select 'Other'.
* **Last Name (M)** (`last_name_male`, select_one, optional): Select 'Yes' if the student's last name is male, or 'No' if not. If not applicable, select 'Other'.
* **Student Type** (`student_type`, select_multiple, optional): Select all relevant categories that the student fits into (e.g., 'Yes' for student, 'Yes' for student group, etc.).
* **Student Type: Student** (`student_type_student`, text, optional): Fill in this field if the student type is student.
* **Student Type: Other** (`student_type_other`, text, optional): Fill in this field if the student's type is not student.
* **Student Type: Student Group** (`student_type_student_group`, select_multiple, optional): Select 'Yes' for the student group categories that the student belongs to.

## Tips
* Please ensure that the information provided is accurate and consistent with the actual information on file.
* If a student's gender is not male or female, please select 'Other' and fill in the `Other` field with the correct information.
* If a student's type is not student, please fill in the `Student Type: Other` field with the correct information.
