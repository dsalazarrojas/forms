# volunteer_activity_monitoring_form - Help Guide

## Purpose
The volunteer_activity_monitoring_form is used to gather information about a volunteer's activity, including their participation status, hours completed, and other relevant details. This form helps track and monitor volunteer activities, allowing for better management and coordination.

## How To Complete This Form

- **User Activity**: Enter a brief description of the volunteer's activity, such as a project or event they are participating in.
- **Volunteer Name**: Enter the name of the volunteer who is participating in the activity.
- **Project**: Enter the name of the project the volunteer is working on.
- **Activity Start Date**: Enter the start date of the activity.
- **Activity End Date**: Enter the end date of the activity.
- **Volunteer Participation Status**: Select the volunteer's participation status, which can be Active, Inactive, or Pending.
- **Hours Completed**: Enter the number of hours the volunteer has completed for the activity.
- **Activity Type**: Select the type of activity the volunteer is participating in, which can be Community Service, Fundraising, Education, or Other.
- **Project Location**: Enter the location of the project or activity.

## Field-by-Field Explanation
- **User Activity** (`User Activity`, text, optional): A brief description of the volunteer's activity.
- **Volunteer Name** (`Volunteer Name`, text, optional): The name of the volunteer participating in the activity.
- **Project** (`Project`, text, optional): The name of the project the volunteer is working on.
- **Activity Start Date** (`Activity Start Date`, date, optional): The start date of the activity.
- **Activity End Date** (`Activity End Date`, date, optional): The end date of the activity.
- **Volunteer Participation Status** (`Volunteer Participation Status`, select multiple, optional): The participation status of the volunteer, which can be Active, Inactive, or Pending.
- **Hours Completed** (`Hours Completed`, number, optional): The number of hours the volunteer has completed for the activity.
- **Activity Type** (`Activity Type`, select one, optional): The type of activity the volunteer is participating in, which can be Community Service, Fundraising, Education, or Other.
- **Project Location** (`Project Location`, text, optional): The location of the project or activity.

## Tips
- Make sure to accurately and honestly report participation status and hours completed.
- Double-check the activity details to ensure accuracy and prevent duplicates.
- If a volunteer is no longer participating in an activity, make sure to update their status accordingly.
