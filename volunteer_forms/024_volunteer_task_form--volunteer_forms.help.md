# Volunteer Task Form - Help Guide
## Purpose
The Volunteer Task Form is a tool used to track volunteer tasks and report progress on their completion status. It is designed to be used by volunteers to accurately report their progress and provide necessary information for task completion.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the task you are reporting progress on. You can choose from task_1, task_2, or task_3.
2. Enter your progress as "Completed" or "Not Completed" in the "date_completed" field.
3. Add any notes or comments you have about the task in the "notes" field.

## Field-by-Field Explanation

* **task_1** (text): This is the text field where you report your progress on the first task.
* **date_completed_1** (date): Report the date you completed task 1 or select "Not Completed" if the task is not finished yet.
* **completed_1** (select_one): Select "Completed" to indicate that you have finished task 1.
* **notes_1** (note): Add any additional comments or information about task 1 here.
* **task_2** (text): This is the text field where you report your progress on the second task.
* **date_completed_2** (date): Report the date you completed task 2 or select "Not Completed" if the task is not finished yet.
* **completed_2** (select_one): Select "Completed" to indicate that you have finished task 2.
* **notes_2** (note): Add any additional comments or information about task 2 here.
* **task_3** (text): This is the text field where you report your progress on the third task.
* **date_completed_3** (date): Report the date you completed task 3 or select "Not Completed" if the task is not finished yet.
* **completed_3** (select_one): Select "Completed" to indicate that you have finished task 3.
* **notes_3** (note): Add any additional comments or information about task 3 here.
