# Social Work Appointment Request Form - Help Guide
## Purpose
This form is used to request social work appointments from volunteers. Please fill out the form carefully to ensure that your request is processed correctly.

## How To Complete This Form
1. Select the "Social Work" service type as this is the only available option for this form.
2. Choose the preferred session duration from the available options (30m, 60m, or 90m).
3. Select the preferred location for the appointment (In-person or Virtual).
4. Choose the available time slots for the appointment from the options provided (09:00 AM, 10:00 AM, or 11:00 AM).
5. Provide the assigned tool ID, which is a unique identifier for the tool assigned to you.
6. Select the calendar to sync the appointment with (Google or Microsoft Exchange).
7. Fill out the comments and notes fields if necessary.

## Field-by-Field Explanation
* **Volunteer Name**: Enter your name as a volunteer.
* **Email**: Enter your email address for communication purposes.
* **Phone Number**: Enter your phone number for potential follow-up calls.
* **Available Start Date**: Choose the date you are available to start the social work appointment.
* **Available End Date**: Choose the date you are available to end the social work appointment.
* **Service Type**: Select "Social Work" as this is the only available option for this form.
* **Session Duration**: Choose the session duration from the available options (30m, 60m, or 90m).
* **Location**: Select "In-person" or "Virtual" for the appointment location.
* **Schedule**: Choose the available time slots for the appointment (09:00 AM, 10:00 AM, or 11:00 AM).
* **Assigned Tool**: Enter the assigned tool ID, which is a unique identifier for the tool assigned to you.
* **Comments**: Enter any additional comments or notes about the appointment.
* **Service Location**: Select the location where you will be providing the service (Zoom or Google Meet).
* **Tool ID**: Enter the unique ID for the tool assigned to you.
* **Sync Calendar**: Select the calendar to sync the appointment with (Google or Microsoft Exchange).

Note: Please ensure that you have the required tools and permissions to complete this form accurately.
