# Volunteer Signup Form - Help Guide
## Purpose
This form is used to collect information for volunteer activities. It's meant to be completed by those interested in volunteering for specific projects.

## How To Complete This Form
To complete this form, follow these steps:
1. Start by filling out the form with your details and project selections.
2. Enter your participant details, including email and phone number (if applicable).
3. Select your chosen projects and tasks that you're interested in volunteering for.
4. Choose the start and end dates for the volunteer event.
5. Enter the start and end times for the volunteer event (if applicable).
6. Add any additional participant information if needed.
7. Review your form for accuracy before submitting.

## Field-by-Field Explanation
* **Volunteer Form**: This is the main section where you'll enter your basic details.
	+ Type: Text
	+ Required: No
* **Participant Details**: Enter your participant information here.
	+ Type: Text
	+ Required: No
* **Project Selection**: Choose the projects you're interested in volunteering for.
	+ Type: Select Multiple
	+ Required: No
	+ Options: Option 1, Option 2, Option 3
* **Task Selection**: Select the tasks you'd like to volunteer for within your chosen projects.
	+ Type: Select Multiple
	+ Required: No
	+ Options: Option 4, Option 5
* **Start Date**: Enter the start date of the volunteer event.
	+ Type: Date
	+ Required: No
* **End Date**: Enter the end date of the volunteer event.
	+ Type: Date
	+ Required: No
* **Start Time**: Enter the start time of the volunteer event (if applicable).
	+ Type: Time
	+ Required: No
* **End Time**: Enter the end time of the volunteer event (if applicable).
	+ Type: Time
	+ Required: No
* **Participant Info**: Add any additional participant information that's relevant to the event.
	+ Type: Note
	+ Required: No
* **Participant Email**: Enter the participant's email address.
	+ Type: Email
	+ Required: No
* **Participant Phone**: Enter the participant's phone number.
	+ Type: Text
	+ Required: No

## Tips
- Double-check your details for accuracy before submitting.
- Make sure to fill out a new form for each volunteer event.
