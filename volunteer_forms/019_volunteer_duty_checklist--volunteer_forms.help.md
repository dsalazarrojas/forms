# Volunteer Duty Checklist - Help Guide
## Purpose
The Volunteer Duty Checklist is designed to provide a clear overview of tasks assigned to volunteers, track completion status, and record relevant details.

## How To Complete This Form
1. Select the assigned volunteer(s) from the "assignee" field.
2. Choose the task status from the "task status" field (completed or incomplete).
3. Enter the due date in the "due date" field.
4. If required, choose the assigned tool from the "assigned tool" field.
5. Optionally, enter comments in the "comments" and "task notes" fields.

## Field-by-Field Explanation
* **Task List** (Text): Enter a brief summary of the task(s) assigned to the volunteer(s).
* **Assignee** (Select One): Select the volunteer(s) to whom the task(s) are assigned.
* **Task Status** (Select Multiple): Track whether the task has been completed or is still incomplete.
* **Due Date** (Date): Set a specific date when the task should be completed by.
* **Comments** (Text): Enter additional comments about the task.
* **Task Notes** (Text): Add extra notes about the task (optional).
* **Assigned Tool** (Select One): Choose the tool used or relevant to the task.
* **Additional Comments** (Text): Enter extra comments about the task (optional).
