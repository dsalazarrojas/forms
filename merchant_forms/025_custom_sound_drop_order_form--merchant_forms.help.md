# custom_sound_drop_order_form - Help Guide
## Purpose
The custom_sound_drop_order_form is a form used to collect information from merchants for custom sound drop orders.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter a brief title for the custom sound drop order in the **Title** field.
2. Select the **Artist** who created the custom sound drop.
3. Choose the **Drop Type** from the provided options.
4. Select the **Drop Status** from the provided options (e.g., available, sold, etc.).
5. Add any additional **Notes** about the order in the text area.
6. Enter the **Contact Info** of the merchant in the text field.
7. Enter the **Email** address of the merchant.

## Field-by-Field Explanation
* **Title** (Text): Enter a brief title for the custom sound drop order.
* **Artist** (Text): Select the artist who created the custom sound drop.
* **Drop Type** (Select One): Choose the type of custom sound drop (e.g., Drop Type 1, Drop Type 2, Drop Type 3).
* **Drop Status** (Select Multiple): Select the status of the custom sound drop (e.g., Drop Status 1, Drop Status 2, Drop Status 3).
* **Notes** (Note): Add any additional information about the order.
* **Contact Info** (Text): Enter the contact information of the merchant.
* **Email** (Email): Enter the email address of the merchant.

## Tips
* Make sure to fill in all the required fields before submitting the form.
* Double-check the **Drop Status** selection to ensure it accurately reflects the current state of the custom sound drop.
* Enter a clear and concise **Title** that describes the custom sound drop order.
* Use the **Notes** field to add any additional context or details about the order.
