# Shipping Quote Form - Help Guide
## Purpose
The "Shipping Quote Form" is used to request shipping quotes for orders, providing merchants with a structured way to collect necessary information from both the shipper and the ship-to address.

## How To Complete This Form

1.  Fill in the required fields (marked with * in the field label) with the necessary information. 
2.  Select the appropriate shipping rate calculation method and service type for your order.
3.  Enter the shipper's information to ensure accurate shipping quotes.
4.  Enter the ship-to address information for accurate shipping calculations.
5.  If you have any additional comments or notes for the shipping quote, you may type them into the "Shipping Quote" field.
6.  Select a ship date for the order if you have it.

## Field-by-Field Explanation

*  **Shipping Quote Request** (Shipping Quote Request, text, Not required): Enter your request for a shipping quote.
*  **Shipping Details** (Shipping Details, text, Not required): If you have any additional information about the package, please enter it here.
*  **Shipping Rate Calculation** (Shipping Rate Calculation, select_one, Not required): Select how you want the shipping rate to be calculated (USPS, Canada Post, UPS, FedEx, DHL).
*  **Shipping Service** (Shipping Service, select_multiple, Not required): Select the shipping service you need for your order (Ground, Express, Priority).
*  **Ship To Address** (Ship To Address, text, Not required): Enter the ship-to address for accurate shipping calculations.
*  **City** (City, text, Not required): Enter the city name of the ship-to address.
*  **State** (State, text, Not required): Enter the state of the ship-to address.
*  **Zip** (Zip, text, Not required): Enter the zip code of the ship-to address.
*  **Shipping Method** (Shipping Method, select_multiple, Not required): Select the shipping method for your order (Ground, Express).
*  **Payment Method** (Payment Method, select_multiple, Not required): Select the payment method for your order (Credit Card, PayPal, Bank Transfer).
*  **Order Value** (Order Value, number, Not required): Enter the value of the order to ensure accurate shipping calculations.
*  **Ship From Country** (Ship From Country, select_one, Not required): Select the country of the ship-from address (USA, Canada, UK).
*  **Ship From State** (Ship From State, select_multiple, Not required): Select the state of the ship-from address (California, New York, Texas).
*  **Ship From City** (Ship From City, text, Not required): Enter the city name of the ship-from address.
*  **Ship From Zip** (Ship From Zip, text, Not required): Enter the zip code of the ship-from address.
*  **Ship To Country** (Ship To Country, select_multiple, Not required): Select the country of the ship-to address (USA, Canada, UK).
*  **Ship To State** (Ship To State, select_multiple, Not required): Select the state of the ship-to address (California, New York, Texas).
*  **Ship To City** (Ship To City, text, Not required): Enter the city name of the ship-to address.
*  **Ship To Zip** (Ship To Zip, text, Not required): Enter the zip code of the ship-to address.
*  **Ship To Phone** (Ship To Phone, text, Not required): Enter the phone number of the ship-to address.
*  **Ship To Email** (Ship To Email, email, Not required): Enter the email address of the ship-to address.
*  **Ship To Note** (Ship To Note, text, Not required): Enter any additional notes for the ship-to address.
*  **Ship From Note** (Ship From Note, text, Not required): Enter any additional notes for the ship-from address.
*  **Shipping Quote** (Shipping Quote, note, Not required): Enter any additional comments for the shipping quote.
*  **Ship Date** (Ship Date, date, Not required): Select the ship date for the order if you have it.
