# Custom Label Order Form - Help Guide
## Purpose
The Custom Label Order Form is designed to collect information from merchants for custom label orders. This form helps merchants provide accurate and complete order information for further processing.

## How To Complete This Form
1. Fill in the required fields with accurate information.
2. Review the form for any errors or missing information before submission.

## Field-by-Field Explanation
- **Custom Label**: This is where you input custom label details.
	+ Please fill in the label description.
- **Merchant Info**: Enter merchant information in this field.
	+ This field is used to store merchant information.
- **Order Details**: Enter order details in this field.
	+ This field is used for storing order details.
- **Product Info**: Input product information in this field.
	+ This field is used for product related information.
- **Customer Info**: Enter customer information in this field.
	+ This field is used to store customer information.
- **Order Status**: Select the current status of the order from the provided options.
	+ Options: In Progress, Completed, Cancelled.
- **Shipping Details**: Fill in the shipping details.
	+ This field is used for shipping information.
- **Payment Method**: Select the payment method used for the order from the provided options.
	+ Options: Credit Card, PayPal, Other.
- **Payment Status**: Select the current status of the payment from the provided options.
	+ Options: Processed, Pending, Cancelled.
- **Customer Email**: Enter customer email.
	+ This field is used to store customer email.
- **Customer Phone**: Enter customer phone number.
	+ This field is used to store customer phone number.
- **Note**: Some fields are optional, please fill in only if necessary.
