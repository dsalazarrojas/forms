# international_shipping_form - Help Guide
## Purpose
This form is used to determine the international shipping mode and details of a package. It's meant for packages being shipped internationally and is not required for domestic shipping.

## How To Complete This Form
To complete this form, follow these steps:
1. Select the correct shipping mode: If you are shipping from the same country, select 'Yes' for "Ship from Country". If you are shipping from another country, select 'No'.
2. Choose the shipping location: Select 'Yes' or 'No' for each location based on the actual shipping location.
3. Fill out the required fields: Make sure to fill out the fields that are marked as required, even if they are optional for you.
