# Summer T Shirt Order Form - Help Guide
## Purpose
The Summer T Shirt Order Form is a form used by customers to submit their orders for summer t-shirts. It is essential to fill out this form accurately and completely to ensure that your order is processed correctly.

## How To Complete This Form

1. **Order Page**: Enter a brief description of the item you would like to order (e.g., size, color, design).
2. **Do You Want A T Shirt?**: Choose whether you want to order a t-shirt or not. Select 'Yes' if you wish to proceed with your order.
3. **Quantity**: Enter the number of t-shirts you would like to order. For example, if you want 2 t-shirts, enter '2'.
4. **Size**: Select the size of t-shirt you prefer. Please note that size options are only available if you selected 'Yes' to ordering a t-shirt.
5. **Shipping Information**: Enter your shipping address or any additional shipping instructions (e.g., shipping method, delivery date).
6. **Payment Method**: Enter the payment method you wish to use (e.g., credit card number, PayPal).
7. **Confirm**: Confirm that you have accurately filled out the form by entering 'Confirmed' in the space provided.

## Field-by-Field Explanation

* **Order Page** (`Order Page`, text, optional): Enter a brief description of the item you would like to order.
* **Do You Want A T Shirt?** (t_shirt_select, select multiple, optional): Choose whether you want to order a t-shirt or not. Select 'Yes' if you wish to proceed with your order.
* **Quantity** (quantity, number, optional): Enter the number of t-shirts you would like to order.
* **Size** (size, select one, optional): Select the size of t-shirt you prefer. Please note that size options are only available if you selected 'Yes' to ordering a t-shirt.
* **Shipping Information** (shipping, text, optional): Enter your shipping address or any additional shipping instructions.
* **Payment Method** (payment, text, optional): Enter the payment method you wish to use.
* **Confirm** (confirm, text, required): Confirm that you have accurately filled out the form by entering 'Confirmed'.
