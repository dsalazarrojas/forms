# credit_card_authorization_form - Help Guide
## Purpose
The credit_card_authorization_form is designed to collect user information for the purpose of credit card authorization or verification.

## How To Complete This Form

1. Fill in the First Name field with the user's first name as it appears on their credit card.
2. Fill in the Last Name field with the user's last name as it appears on their credit card.
3. Enter the user's Email address.
4. Enter the user's Phone number.
5. Fill in the Address field with the user's address as it appears on their credit card.
6. Fill in the City field with the user's city as it appears on their credit card.
7. Select the user's state from the State dropdown list.
8. Enter the user's ZIP code.
9. Select the type of credit card from the Credit Card Type dropdown list.
10. Enter the Card Number of the credit card.
11. Select the Security Code from the Security Code dropdown list.
12. Select the Expiration Month from the Expiration Month dropdown list.
13. Select the Expiration Year from the Expiration Year dropdown list.

## Field-by-Field Explanation

* **First Name** (`first_name`, text, required): Enter the user's first name as it appears on their credit card.
* **Last Name** (`last_name`, text, required): Enter the user's last name as it appears on their credit card.
* **Email** (`email`, email, required): Enter the user's email address.
* **Phone** (`phone`, text, optional): Enter the user's phone number.
* **Address** (`address`, text, optional): Enter the user's address as it appears on their credit card.
* **City** (`city`, text, optional): Enter the user's city as it appears on their credit card.
* **State** (`state`, select_one, optional): Select the user's state from the list.
* **Zip** (`zip`, number, required): Enter the user's ZIP code.
* **Credit Card Type** (`credit_card_type`, select_multiple, optional): Select the type of credit card from the list.
* **Card Number** (`card_number`, text, required): Enter the credit card number as it appears on the card.
* **Security Code** (`security_code`, select_one, optional): Select the security code from the list.
* **Expiration Date** (`expiration_date`, date, required): Select the expiration date of the credit card.
* **Expiration Month** (`expiration_month`, select_one, optional): Select the month of the expiration date of the credit card.
* **Expiration Year** (`expiration_year`, select_one, optional): Select the year of the expiration date of the credit card.

## Tips

* Ensure that all required fields are completed before submitting.
* Double-check that the credit card type matches the actual card type.
* Enter accurate expiration date and month.
* Ensure that the ZIP code is accurate.
