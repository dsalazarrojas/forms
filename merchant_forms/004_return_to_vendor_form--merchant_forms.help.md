# Return To Vendor Form - Help Guide

## Purpose
The Return To Vendor Form is designed to facilitate the return of products to vendors for restocking or replacement. This form helps to gather information on the reason for return, customer requests, product details, and return dates to process the return efficiently.

## How To Complete This Form

To complete this form, follow these steps:

1. Fill out the form completely, including all required and optional fields.
2. Provide a clear and concise reason for return in the "Reason For Return" field.
3. Enter any customer requests or comments in the "Customer Request" field.
4. Enter the product ID in the "Product ID" field.
5. Select the return date from the calendar in the "Return Date" field.
6. Select the time of return in the "Time Of Return" field.
7. Once you have filled out all the fields, click the submit button to complete the form.

## Field-by-Field Explanation
* **Reason For Return** (`reason_for_return`, text, optional): Enter a clear and concise reason for return.
* **Customer Request** (`customer_request`, text, optional): Enter any customer requests or comments related to the return.
* **Product ID** (`product_id`, number, optional): Enter the product ID of the item being returned.
* **Return Date** (`return_date`, date, optional): Select the date the item will be returned.
* **Time Of Return** (`time_of_return`, time, optional): Select the time the item will be returned.
* **Reason For Return** (`reason_for_return`, text, optional): Enter a detailed reason for return (same as "Reason For Return", please note this field is optional but has the same label as a field on the previous page, this field is only required if the form is duplicated or reloaded).
