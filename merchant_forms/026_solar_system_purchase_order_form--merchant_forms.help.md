# Solar System Purchase Order Form - Help Guide

## Purpose

This form is used to record details related to a solar system purchase order for merchants.

## How To Complete This Form

1.  Fill out the form completely, ensuring that all required fields are accurate and up-to-date.
2.  Enter relevant information for the Merchant Name field, as it appears on the merchant's invoice.
3.  Choose the correct System Type (Residential or Commercial) from the dropdown menu.
4.  Enter the Supplier Name, which is used to identify the merchant's supplier.
5.  Enter the Purchase Order Date, which is the date the order was placed.
6.  Select the Order Status from the dropdown menu, indicating the current state of the order.
7.  Enter the Customer Name, which is the name of the customer who purchased the system.
8.  Enter the contact phone number for the customer.
9.  Add any additional order notes or comments.
10.  Enter the customer's email address.
11.  Enter the System Price, which is the cost of the solar system being purchased.
12.  Enter the Merchant ID for tracking purposes.
13.  Enter any additional order details.
14.  Enter the quantity of the solar system being purchased.
15.  Select the Payment Method used for the purchase (Cash, Check, or Bank Transfer).
16.  Enter the cost of the solar system.
17.  Enter any comments from the merchant.
18.  Enter any additional notes about the system.
19.  Select the Payment Status from the dropdown menu, indicating the current state of the payment.
20.  Enter the date and time of the order.
21.  Enter the System ID, which is used to track the system.
22.  Enter any comments from the merchant.
23.  Enter any other payment method used (e.g., credit card).
24.  Enter the payment terms, if any.
25.  Finally, select the Merchant Status from the dropdown menu, indicating the status of the merchant.

## Field-by-Field Explanation

* **Merchant Name** (`merchant_name`, text, required): The name of the merchant who is purchasing the solar system.
* **System Type** (`system_type`, select_one, required): The type of solar system being purchased (Residential or Commercial).
* **Supplier Name** (`supplier_name`, text, required): The name of the supplier providing the solar system.
* **Purchase Order Date** (`purchase_order_date`, date, required): The date the order was placed.
* **Order Status** (`order_status`, select_multiple, required): The current status of the order (Received, Shipped, Cancelled, Pending).
* **Customer Name** (`customer_name`, text, required): The name of the customer who purchased the solar system.
* **Contact Phone** (`contact_phone`, text, required): The customer's contact phone number.
* **Order Notes** (`order_notes`, text, required): Any additional notes or comments about the order.
* **Email** (`email`, email, required): The customer's email address.
* **System Price** (`system_price`, number, required): The cost of the solar system.
* **Merchant ID** (`merchant_id`, text, required): The merchant ID for tracking purposes.
* **Order Details** (`order_details`, text, required): Any additional details about the order.
* **System Quantity** (`system_quantity`, number, required): The quantity of solar systems being purchased.
* **Payment Method** (`payment_method`, select_one, required): The method used for payment (Cash, Check, Bank Transfer).
* **System Cost** (`system_cost`, number, required): The cost of the solar system.
* **Merchant Comments** (`merchant_comments`, text, required): Any comments from the merchant.
* **System Notes** (`system_notes`, text, required): Any additional notes about the system.
* **Payment Status** (`payment_status`, select_one, required): The current status of the payment (Received, Pending, Refunded, Cancelled).
* **Order Date** (`order_date`, date, required): The date and time of the order.
* **Order Time** (`order_time`, time, required): The time of the order.
* **System ID** (`system_id`, text, required): The ID of the solar system.
* **Merchant Comments** (`merchant_comments`, text, required): Any comments from the merchant.
* **Other Payment Method** (`payment_method_other`, text, required): Any other payment method used (e.g., credit card).
* **Payment Terms** (`payment_terms`, text, required): The payment terms, if any.
* **Merchant Status** (`merchant_status`, select_multiple, required): The status of the merchant (Active, Inactive, Pending, Cancelled).

Note: All required fields are marked as required in the above explanations. Ensure that all required fields are filled out accurately and completely.
