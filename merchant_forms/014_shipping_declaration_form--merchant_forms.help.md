# Shipping Declaration Form - Help Guide
## Purpose
This form is used to declare your shipped packages, providing essential information about the package and shipper. Please complete the form accurately to ensure smooth shipping and tracking processes.

## How To Complete This Form
1.  Select the package type from the options provided.
2.  Select any applicable shipper company options.
3.  Enter a brief description of the package.
4.  Enter the package weight and value.
5.  Enter the shipper name and other contact information.
6.  Enter the shipper address details.
7.  Describe the package contents.
8.  Enter package length, width, and height.
9.  Enter any relevant package tracking numbers.
10.  Select the date and time of shipment.
11.  Optionally, enter any additional notes about the shipment.

## Field-by-Field Explanation
* **Package Type** (`package_type`, `select_one`):
	+ Select the type of package you are declaring. Options include Option 1, Option 2, and Option 3.
* **Shipper Company** (`shipper_company`, `select_multiple`):
	+ Select any applicable shipper company options for your business.
* **Package Description** (`package_description`, `text`):
	+ Enter a brief description of the package contents.
* **Package Weight** (`package_weight`, `number`):
	+ Enter the weight of the package in kilograms.
* **Package Value** (`package_value`, `number`):
	+ Enter the value of the package.
* **Shipper Name** (`shipper_name`, `text`):
	+ Enter the name of the shipper.
* **Shipper Address** (`shipper_address`, `text`):
	+ Enter the shipper's address in the format of street, city, state, and postcode.
* **Shipper City** (`shipper_city`, `text`):
	+ Enter the shipper's city.
* **Shipper State** (`shipper_state`, `text`):
	+ Enter the shipper's state.
* **Shipper Postcode** (`shipper_postcode`, `text`):
	+ Enter the shipper's postcode.
* **Shipper Country** (`shipper_country`, `text`):
	+ Enter the shipper's country.
* **Package Contents** (`package_contents`, `text`):
	+ Enter a brief description of the package contents.
* **Package Length** (`package_length`, `number`):
	+ Enter the length of the package.
* **Package Width** (`package_width`, `number`):
	+ Enter the width of the package.
* **Package Height** (`package_height`, `number`):
	+ Enter the height of the package.
* **Shipper Email** (`shipper_email`, `email`):
	+ Enter the shipper's email address.
* **Shipper Phone** (`shipper_phone`, `text`):
	+ Enter the shipper's phone number.
* **Shipper Note** (`shipper_note`, `note`):
	+ Enter any additional notes about the shipment.
* **Package Date Shipped** (`package_date_shipped`, `date`):
	+ Enter the date the package was shipped.
* **Package Time Shipped** (`package_time_shipped`, `time`):
	+ Enter the time the package was shipped.
* **Merchant ID** (`merchant_id`, `text`):
	+ Enter the merchant's ID number.
* **Package ID** (`package_id`, `text`):
	+ Enter the package ID number.
* **Package Serial Number** (`package_serial_number`, `text`):
	+ Enter the package serial number.
* **Package Type Serial Number** (`package_type_serial_number`, `text`):
	+ Enter the package type serial number.
* **Package Tracking Number** (`package_tracking_number`, `text`):
	+ Enter the package tracking number.

**Tips**

* Ensure that all required fields are filled accurately and completely.
* Double-check the package details for any mistakes before submitting the form.
* If you need help or have any questions, contact us for assistance.
