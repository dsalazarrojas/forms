# Screen Printing Order Form - Help Guide
## Purpose
The Screen Printing Order Form is used to collect and store information for screen printing orders.

## How To Complete This Form
To complete this form, simply navigate through the pages and fill out the relevant fields as prompted. You can save your progress and return to the form at any time.

## Field-by-Field Explanation
### Order Information
• **Order Information** (`order_information`, text): Enter a brief description of the order or any relevant information about the order.

### Order Details
• **Order Details** (`order_details`, text): Enter any additional details about the order, such as special instructions or requests.

### Shipping Details
• **Order Shipping** (`order_shipping`, text): Enter shipping information, including any relevant shipping instructions or requests.

### T-Shirt Information
• **T-Shirt Info** (`tshirt_info`, text): Enter any relevant information about the t-shirt being printed, such as the design or color.

### Payment Information
• **Payment Info** (`payment_info`, text): Enter payment information, including payment method and any relevant details.

### Review
• **Review** (`review`, text): Enter any review or feedback about the order or the printing process.

### T-Shirt Color Information
• **T-Shirt Color Info** (`tshirt_color_info`, select_one): Select whether or not the t-shirt has any specific color requirements.

• **T-Shirt Color** (`tshirt_color`, select_multiple): Select all applicable colors for the t-shirt.

### T-Shirt Image
• **T-Shirt Image** (`tshirt_image`, text): Enter the image to be printed on the t-shirt.

### T-Shirt Price
• **T-Shirt Price** (`tshirt_price`, number): Enter the price of the printed t-shirt.

### T-Shirt Quantity
• **T-Shirt Quantity** (`tshirt_quantity`, number): Enter the quantity of t-shirts to be printed.

### T-Shirt Type
• **T-Shirt Type** (`tshirt_type`, select_one): Select the type of t-shirt being printed.

### T-Shirt Status
• **T-Shirt Status** (`tshirt_status`, select_one): Select the status of the t-shirt, either Active or Inactive.

### T-Shirt Status Notes
• **T-Shirt Status Notes** (`tshirt_status_note`, text): Enter any notes about the t-shirt's status.

• **T-Shirt Status Notes 2** (`tshirt_status_note_2`, text): Enter any additional notes about the t-shirt's status.

• **T-Shirt Design Info 2** (`tshirt_design_info_2`, text): Enter any additional information about the t-shirt's design.

• **T-Shirt Design Info 3** (`tshirt_design_info_3`, text): Enter any further information about the t-shirt's design.

• **T-Shirt Design Info 4** (`tshirt_design_info_4`, text): Enter any additional details about the t-shirt's design.

• **T-Shirt Design Info 5** (`tshirt_design_info_5`, text): Enter any other information about the t-shirt's design.

• **T-Shirt Design Info 6** (`tshirt_design_info_6`, text): Enter any further details about the t-shirt's design.
