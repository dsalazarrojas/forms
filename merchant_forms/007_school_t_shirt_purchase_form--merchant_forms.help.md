# School T Shirt Purchase Form - Help Guide
## Purpose
This form is used to record purchases of school t-shirts by students.

## How To Complete This Form
To complete this form, follow these steps:

* Fill out the form completely and accurately.
* Enter the student's name.
* Select the student's activity from the options listed.
* Enter the class name, if applicable.
* Choose the class size from the options listed.
* Enter the purchase price of the t-shirt.
* Choose the payment method used for the purchase.
* If applicable, enter the student fee and class fee associated with the purchase.
* Enter the school name for the school the student attends.
* Enter the date of the purchase.

## Field-by-Field Explanation

* **Student Name**: This is the name of the student who purchased the t-shirt.
* **Student Activity**: This is the activity the student is involved in, such as sports, clubs, etc. Select the corresponding option that best describes the student's activity.
* **Class Name**: This is the name of the class the student is in, if applicable. If the student is not in a class, leave this field blank.
* **Class Size**: This is the size of the class the student is in. Select the corresponding option that best describes the class size.
* **Purchase Price**: This is the price the student paid for the t-shirt.
* **Payment Method**: This is the method used to pay for the purchase, such as cash, credit card, etc. Select the corresponding option that best describes the payment method.
* **Student Fee**: This is any additional fee the student paid for the t-shirt, if applicable.
* **School Name**: This is the name of the school the student attends.
* **Class Fee**: This is any additional fee the class paid for the t-shirt, if applicable.
* **Purchase Date**: This is the date the t-shirt was purchased.
