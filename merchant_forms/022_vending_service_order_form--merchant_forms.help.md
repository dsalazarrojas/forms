# vending_service_order_form - Help Guide
## Purpose

The vending_service_order_form is used for submitting a restocking order for a vending machine. This form collects necessary information to determine the best course of action for restocking the machine.

## How To Complete This Form

1. Fill out the form with accurate and complete information. Make sure to submit the form only when a restock is actually needed.
2. Review each field carefully and enter the correct information.

## Field-by-Field Explanation

* **Provider Information** (Text): Enter the name or contact information of the person or entity submitting the restock order.
* **Machine Information** (Text): Enter a brief description or identification number of the vending machine that needs restocking.
* **Restock Request** (Text): Provide a clear and concise reason for the restock request. This can include information about the items that need to be replenished.
* **Quantity Requested** (Number): Enter the quantity of items that need to be restocked.
* **Quantity Ordered** (Number): Enter the quantity of items that were ordered for restocking.
* **Quantity Received** (Number): Enter the quantity of items that were actually received.
* **Restock Status** (Select One): Select the current restock status:
	+ Available: The items are available for restocking.
	+ In Transit: The items are in transit to the location for restocking.
	+ Delayed: There are delays in the restocking process.
	+ Cancelled: The restock request has been cancelled.
* **Comments** (Note): Enter any additional comments or notes about the restock request.
* **Submitted By** (Select One): Select the role of the person or entity submitting the restock order:
	+ admin
	+ manager
	+ customer
* **Submitted On** (Date): Enter the date the restock order was submitted.
* **Submitted At** (Time): Enter the time the restock order was submitted.

## Tips

* Make sure to submit accurate and complete information to ensure the restocking process goes smoothly.
* Double-check the form before submitting to avoid errors.
* If you have any questions or concerns about the restock process, contact the designated authority for assistance.
