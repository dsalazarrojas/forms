# Wine Order Form - Help Guide
## Purpose
The Wine Order Form is used to create new wine orders. This form allows authorized users to input customer information, select wines, specify quantities, and add order notes.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the customer's name in the text field marked "Customer Name".
2. Select one or more options from the "Select Wine" dropdown menu to indicate whether the order includes wine or not.
3. Enter the quantity of wine ordered in the text field marked "Quantity".
4. Enter the date and time of the order in the date and time fields marked "Order Date" and "Order Time", respectively.
5. Enter the customer's phone number in the text field marked "Customer Phone".
6. Enter the customer's email address in the text field marked "Customer Email".
7. Add any additional notes about the order in the text field marked "Order Notes".

## Field-by-Field Explanation
- **Customer Name**: Enter the name of the person or organization placing the order.
- **Select Wine**: Choose whether the order includes wine or not. If you select "Yes", you will be able to add wines to the order. If you select "No", you will not be able to add wines.
- **Quantity**: Enter the number of units of wine ordered.
- **Order Date**: Enter the date the order is to be fulfilled.
- **Order Time**: Enter the time the order is to be fulfilled.
- **Customer Phone**: Enter the phone number of the person or organization placing the order.
- **Customer Email**: Enter the email address of the person or organization placing the order.
- **Order Notes**: Enter any additional comments or instructions about the order.

## Tips
- Always enter accurate and complete information to avoid delays or errors in processing the order.
- Ensure that you have the necessary permissions to access the form.
- Review the form carefully before submitting it, ensuring that all required fields are filled out correctly.
- Use the "Select Wine" field to accurately indicate whether the order includes wine or not.
