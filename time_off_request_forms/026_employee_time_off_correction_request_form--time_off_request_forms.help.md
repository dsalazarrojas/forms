# Employee Time Off Correction Request Form - Help Guide
## Purpose
This form is intended for employees to submit corrections to their previously submitted time off requests. If you need to adjust the dates or details of a pre-existing time off request, please fill out this form.

## How To Complete This Form
- Please review the fields below and fill out the form accurately.
- You can access the fields by clicking on the corresponding icons or buttons in your time off request history.
- Ensure the new start and end dates are accurate and within company policy.
- Once you have filled out all required fields, click "Submit" to send the request for processing.

## Field-by-Field Explanation

* **Employee Time Off Correction Request Form** (<code>employee_time_off_correction_request_form</code>, <code>text</code>, Optional): This is the main text field where you will write a clear and concise description of the correction needed. Be as detailed as possible so the HR representative can efficiently process your request.
* **Time off start date** (<code>time_off_start_date</code>, <code>date</code>, Required): Enter the corrected start date of your time off request. This will replace the original start date submitted during the initial request.
* **Time off end date** (<code>time_off_end_date</code>, <code>date</code>, Required): Enter the corrected end date of your time off request. This will replace the original end date submitted during the initial request.

## Tips
- Make sure to fill out the form accurately and completely to avoid delays in processing.
- If you are unsure about any field or have questions, contact the HR department for assistance.
- Please allow 2-3 business days for processing time off correction requests.
