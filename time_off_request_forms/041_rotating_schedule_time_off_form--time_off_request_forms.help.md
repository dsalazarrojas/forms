# rotating_schedule_time_off_form - Help Guide
## Purpose
The "Rotating Schedule Time Off Form" is used to request time off from your rotating schedule. This form helps you to submit a request for a specific time off period and receive approval from your manager.

## How To Complete This Form
To submit a time off request using this form, follow the steps below:

1. Select the "Time Off Request" option from the list on the left (Page 1).
2. Choose the date from which you would like to start your time off (Page 2, start_date field).
3. Choose the date on which you would like to end your time off (Page 2, end_date field).
4. Provide a reason for your time off request (Page 3, reason field).
5. Select whether your manager's approval is required for this request (Page 4, Manager Approval field).
6. Enter your employee ID (Page 5, employee_id field).

## Field-by-Field Explanation
* **Time Off Request** (`Yes/No`, select_multiple, optional): Select "Yes" if you would like to request time off, "No" otherwise.
* **start_date** (`Date`, date, optional): Choose the date from which you would like to start your time off. Please format the date as MM/DD/YY or YYYY-MM-DD.
* **end_date** (`Date`, date, optional): Choose the date on which you would like to end your time off. Please format the date as MM/DD/YY or YYYY-MM-DD.
* **reason** (`text`, text, optional): Provide a brief explanation for your time off request.
* **Manager Approval** (`Yes/No`, select_one, optional): Select "Yes" if you would like to submit your request for manager's approval, "No" otherwise.
* **Employee ID** (`number`, number, optional): Enter your employee ID.

## Tips
* Ensure you have a valid employee ID before submitting your request.
* Make sure to provide a clear reason for your time off request.
* If you select "Yes" for Manager Approval, your request will be routed to your manager for review.
* If you are unsure about any field, please contact your supervisor or HR representative for assistance.
