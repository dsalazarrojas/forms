# Wildfire Evacuation Time Off Form - Help Guide
## Purpose
This form is used to notify your manager that you will be taking time off from work due to a wildfire evacuation. Please fill out this form with accurate and complete information so that your manager can process your request efficiently.

## How To Complete This Form
- Please fill out each field accurately and truthfully.
- If a field is marked as `required`, it must be completed.
- Use the provided examples as a reference if needed.
- If you need help or have questions, contact your human resources representative.

## Field-by-Field Explanation

* **Wildfire Evacuation Time Off Reason (`wildfire_evacuation_time_off_reason`):**
  Please briefly describe the reason for your time off due to a wildfire.

* **Wildfire Start Date (`wildfire_start_date`):**
  Enter the date that the wildfire started, if known.

* **Wildfire End Date (`wildfire_end_date`):**
  Enter the date that the wildfire ended, if known.

* **Wildfire Estimated Return Date (`wildfire_estimated_return_date`):**
  Provide an estimated date that you will return to work, if known.

* **Wildfire Evacuation Location (`wildfire_evacuation_location`):**
  Specify the location of the wildfire, if known.

* **Alternate Contact (`alternate_contact`):**
  If you need to provide an alternate contact person, enter their name and phone number.

* **Additional Info (`additional_info`):**
  Provide any additional information that may be helpful for your manager to know.

* **Employee Name (`employee_name`):**
  Enter your name as it appears on your employee ID badge or your name in the HR system.

* **Employee ID (`employee_id`):**
  Enter your employee ID number as it appears on your employee ID badge or in the HR system.

* **Employee Department (`employee_department`):**
  Enter your department as it appears in the HR system.
