# PTO Request Form - Help Guide

## Purpose
This form is used to request time off for personal or professional reasons. Please fill out the form below to submit a request for time off.

## How To Complete This Form
To complete this form, please follow these steps:

1. Select the start and end dates of your time off.
2. Indicate how many days off you are requesting.
3. Check the box next to each reason for your time off (e.g. "Yes" for vacation, "No" for sick leave).
4. Provide your employee ID and name.

## Field-by-Field Explanation
### Start Date 
- **Start Date** (`start_date`, `date`, optional): This is the date you wish to start your time off. Please enter the start date in YYYY-MM-DD format.

### End Date 
- **End Date** (`end_date`, `date`, optional): This is the date you wish to end your time off. Please enter the end date in YYYY-MM-DD format.

### Days Off Requested 
- **Days Off Requested** (`days_off_requested`, `number`, optional): This is the number of days you are requesting off. Please enter the actual number of days you need.

### Days Off Approved 
- **Days Off Approved** (`days_off_approved`, `number`, optional): This is a placeholder field that will be populated automatically once your request is approved.

### Manager Acknowledgement 
- **Manager Acknowledgement** (`manager_acknowledgement`, `select_one`, optional): Check "Yes" if your manager has acknowledged your time off request, or "No" if they have not.

### Reason for Time Off 
- **Reason for Time Off** (`reason_for_time_off`, `select_multiple`, optional): Check the reasons for your time off from the list provided. You can select more than one reason if applicable.

### Start Time 
- **Start Time** (`start_time`, `time`, optional): This is the time of day when you wish to start your time off. Please enter in 24-hour format (e.g., 08:00 for 8am).

### End Time 
- **End Time** (`end_time`, `time`, optional): This is the time of day when you wish to end your time off. Please enter in 24-hour format (e.g., 17:00 for 5pm).

### Employee ID 
- **Employee ID** (`employee_id`, `number`, optional): This is your unique employee ID. Please enter the actual ID number.

### Employee Name 
- **Employee Name** (`employee_name`, `text`, optional): This is your full name. Please enter your actual name.

## Tips
- Please ensure that you have permission from your manager before submitting this form.
- Make sure to enter accurate dates and time to avoid any scheduling conflicts.
- If you have any questions or concerns, please reach out to your HR department.
