# Focus Group Time Off Form - Help Guide
## Purpose
The purpose of this form is to request time off from your supervisor. Please fill out the form completely to ensure accurate review and processing.
## How To Complete This Form
To complete this form, follow these steps:
- Select the user who requested the time off from the options below.
- Enter the focus group name you are requesting time off from.
- Select the start date of your time off.
- Select the end date of your time off.
- Choose the reason for your request from the options provided.
- Select the status of your request (e.g., Approved, Denied, Pending).
- Choose the name of your manager who is reviewing this request.
- Choose whether or not there are manager comments regarding this request.
- Select the name of the employee submitting this request.
- Select the department you belong to.

## Field-by-Field Explanation
* **User Input** (Select One):
	+ Select the user who requested the time off from the options provided.
* **Focus Group Name**:
	+ Enter the name of the focus group you are requesting time off from.
* **Time Off Start Date** (Date):
	+ Select the start date of your time off.
* **Time Off End Date** (Date):
	+ Select the end date of your time off.
* **Reason for Request** (Select One):
	+ Choose the reason for your time off request from the options provided.
* **Approval Status** (Select Multiple):
	+ Select the status of your request (e.g., Approved, Denied, Pending).
* **Manager Name** (Select Multiple):
	+ Choose the name of your manager who is reviewing this request.
* **Manager Comments** (Select Multiple):
	+ Choose whether or not there are manager comments regarding this request.
* **Employee Name** (Select Multiple):
	+ Select the name of the employee submitting this request.
* **Department** (Select Multiple):
	+ Select the department you belong to.
## Tips
- Make sure you have filled in all required fields accurately.
- Check the status of your request after it has been reviewed by your supervisor.
