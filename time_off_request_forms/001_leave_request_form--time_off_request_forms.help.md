# Leave Request Form - Help Guide
## Purpose
This form is used to record and manage employee leave requests, providing a structured approach to collect necessary information for evaluation and processing.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the employee's name in the "Employee Name" field.
2. Select the start date of the leave in the "Start Date" field.
3. Select the end date of the leave in the "End Date" field.
4. Provide a brief reason for the leave in the "Reason for Leave" field.
5. Choose the type of leave from the available options (e.g., Leave for Vacation, Leave for Sick, Leave for Emergency).
6. Select the return date if the leave is for an extended period.
7. Specify the duration of the leave in the "Leave Duration" field.
8. Choose the current status of the leave from the available options (e.g., Pending, Approved, Declined, Cancelled).
9. Optional: Add any comments from the manager in the "Manager Comments" field.

## Field-by-Field Explanation
* **Employee Name (Employee Name)**: Enter the name of the employee submitting the leave request.
* **Start Date (Start Date)**: Select the date from which the employee wants to take leave.
* **End Date (End Date)**: Select the date on which the employee wants to return from leave.
* **Reason for Leave (Reason for Leave)**: Enter a brief explanation for the leave request.
* **Leave Type (Leave Type)**: Select the type of leave (e.g., Vacation, Sick, Emergency).
* **Return Date (Return Date)**: If the leave is for an extended period, select the date on which the employee is expected to return.
* **Leave Duration (Leave Duration)**: Enter the number of days for the leave.
* **Leave Status (Leave Status)**: Choose the current status of the leave (e.g., Pending, Approved, Declined, Cancelled).
* **Manager Comments (Manager Comments)**: Optional comments from the manager for further review or discussion.

## Tips

* Ensure that all required fields are completed before submitting the form.
* Double-check the accuracy of the dates entered.
* Choose the correct leave type to ensure proper processing.
* If you're unsure about any field, consult with your HR or management for clarification.
