# Student Technology Survey - Help Guide
## Purpose

This Student Technology Survey is designed to gather information about students' and teachers' use and attitudes towards technology in educational settings. The survey aims to provide insights that can inform decision-making about technology integration in the classroom.

## How To Complete This Form

1. Carefully read each question and understand what is being asked.
2. Choose the answer that best describes your situation or attitude.
3. Select one option from the options provided for each question.
4. Ensure that you have answered all questions before submitting the form.

## Field-by-Field Explanation

* **Student uses ICT**: This question is about how often you use Information and Communication Technologies (ICT) in your daily life. Please select one of the options:
	+ Always: You use ICT all the time.
	+ Frequently: You use ICT most of the time.
	+ Rarely: You use ICT occasionally.
	+ Never: You never use ICT.
* **Does the student use ICT at home?:** This question is about whether you use ICT for personal or recreational purposes outside of school. Please select one of the options:
	+ True: Yes, you do use ICT at home.
	+ False: No, you do not use ICT at home.
* **Does the student use ICT outside class?:** This question is about whether you use ICT for purposes outside of school, such as on social media, online games, or other activities. Please select one of the options:
	+ True: Yes, you do use ICT outside class.
	+ False: No, you do not use ICT outside class.
* **Teacher support:** This question is about how often your teacher uses ICT in lessons. Please select all options that apply:
	+ Always: Your teacher always uses ICT in lessons.
	+ Frequently: Your teacher frequently uses ICT in lessons.
* **Student interest in using ICT:** This question is about your interest in using ICT for educational purposes. Please select one of the options:
	+ High: You are very interested in using ICT.
	+ Medium: You are moderately interested in using ICT.
	+ Low: You are not very interested in using ICT.
* **Teacher interest in using ICT:** This question is about your teacher's interest in using ICT for educational purposes. Please select one of the options:
	+ High: Your teacher is very interested in using ICT.
	+ Medium: Your teacher is moderately interested in using ICT.
	+ Low: Your teacher is not very interested in using ICT.
* **Expected use in the classroom:** This question is about how often you expect to use ICT in the classroom. Please select one of the options:
	+ High: You expect to use ICT most of the time.
	+ Medium: You expect to use ICT occasionally.
	+ Low: You do not expect to use ICT much.
* **Expected use in the classroom 2:** This question is similar to the previous one and is meant to double-check your expectations. Please select one of the options:
	+ High: You expect to use ICT most of the time.
	+ Medium: You expect to use ICT occasionally.
	+ Low: You do not expect to use ICT much.
* **Teacher expectancy:** This question is about how much you expect your teacher to use ICT in the classroom. Please select one of the options:
	+ High: You expect your teacher to use ICT most of the time.
	+ Medium: You expect your teacher to use ICT occasionally.
	+ Low: You do not expect your teacher to use ICT much.
* **Teacher expectancy 2:** This question is similar to the previous one and is meant to double-check your expectations. Please select one of the options:
	+ High: You expect your teacher to use ICT most of the time.
	+ Medium: You expect your teacher to use ICT occasionally.
	+ Low: You do not expect your teacher to use ICT much.

## Tips

* Please answer each question truthfully and to the best of your ability.
* If you are unsure about a question, please select the option that best describes your situation.
* If you have any questions or need further clarification about any question, please contact the form creators.
* You can submit the form once you have answered all questions and are satisfied with your answers.
* Please review this guide carefully before submitting the form to ensure you have understood the questions and have provided accurate answers.
