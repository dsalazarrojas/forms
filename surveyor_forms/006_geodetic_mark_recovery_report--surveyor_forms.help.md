# Geodetic Mark Recovery Report - Help Guide
## Purpose
The Geodetic Mark Recovery Report is a form used to track the status and recovery of geodetic marks. This form helps surveyors and other professionals in the field to document their work and provide a standardized way to report on the recovery of these marks.

## How To Complete This Form
To complete the form, follow these steps:

1. Select the current status of the control point from the options provided.
2. Enter the location of the control point as it is currently known.
3. Enter the date of recovery, when the mark was last recovered.
4. (Optional) Upload any relevant photos of the control point.
5. (Optional) Enter any additional comments or notes about the control point.
6. (Optional) Enter any additional photos related to the control point.
7. (Optional) Enter any comments or notes about the control point.
8. (Optional) Enter any status update notes.
9. Enter the name of the surveyor who recovered the mark.
10. Enter the project ID (if applicable).
11. Enter the asset ID (if applicable).
12. Select the type of geodetic survey point being recovered.
13. Enter the date of the survey.
14. (Optional) Enter the elevation of the control point.
15. (Optional) Enter any additional remarks.

## Field-by-Field Explanation
* **Control Point Status**: Select the current status of the control point from the options provided. This will help track the mark's status.
* **Location**: Enter the location of the control point as it is currently known. This will help with future reference.
* **Recovery Date**: Enter the date of recovery, when the mark was last recovered. This will help track the mark's history.
* **Photos**: (Optional) Upload any relevant photos of the control point. These photos can be helpful for reference and documentation.
* **Photo Comments**: (Optional) Enter any comments or notes about the photos.
* **Upload Photo**: (Optional) Upload additional photos related to the control point.
* **Upload Additional Photos**: (Optional) Upload more photos related to the control point.
* **Comments**: (Optional) Enter any comments or notes about the control point.
* **Status Update Notes**: (Optional) Enter any status update notes.
* **Surveyor Name**: Enter the name of the surveyor who recovered the mark.
* **Project ID**: (Optional) Enter the project ID (if applicable).
* **Asset ID**: (Optional) Enter the asset ID (if applicable).
* **Geodetic Control Point Number**: (Optional) Enter the geodetic control point number.
* **Geodetic Survey Point Type**: Select the type of geodetic survey point being recovered.
* **Survey Date**: Enter the date of the survey.
* **Control Point Elevation**: (Optional) Enter the elevation of the control point.
* **Remarks**: (Optional) Enter any additional remarks.
