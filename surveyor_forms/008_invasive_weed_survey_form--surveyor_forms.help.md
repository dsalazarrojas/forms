# Invasive Weed Survey Form - Help Guide

## Purpose
The Invasive Weed Survey Form is designed to gather information about invasive weed sightings and sightings dates. The form is used to collect data from surveyors in the field who have identified instances of invasive weeds. This information is essential for monitoring and managing invasive weed populations.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter your Surveyor ID (ID number assigned to you).
2. Enter the location ID (a unique number assigned to the location where the invasive weed was spotted).
3. Enter the location name (a descriptive name for the location where the invasive weed was spotted).
4. Record the date you first noticed the invasive weed (in YYYY-MM-DD format).
5. Select all the types of invasive weeds that you observed (choose one or more options).
6. Enter the quantity of the invasive weed plants you observed.
7. Indicate the priority level of follow-up required (choose one option).
8. Add any additional notes about the sighting.

## Field-by-Field Explanation

* **Surveyor ID (1)**: Enter your unique ID number assigned to you as a surveyor.
* **location_id (2)**: Enter the location ID number assigned to the location where the invasive weed was spotted.
* **location_name (3)**: Enter a descriptive name for the location where the invasive weed was spotted, such as a park or field name.
* **sighting_date (4)**: Enter the date you first noticed the invasive weed in the format YYYY-MM-DD (e.g., 2022-07-25).
* **plant_type (5)**: Select all the types of invasive weeds you observed. You can choose one or more options from the list.
* **plant_quantity (6)**: Enter the number of invasive weed plants you observed.
* **follow_up_priority (7)**: Indicate the priority level of follow-up required for the sighting (choose one option).
* **notes (8)**: Add any additional notes or comments about the sighting.
* **follow_up_date (9)**: Enter the date for any follow-up action (in YYYY-MM-DD format, but only if necessary).
