# Property Release Form - Help Guide
## Purpose
The Property Release Form is a document that facilitates the transfer of ownership of a property. It's used to collect crucial information about the property, the owner, and the buyer, ensuring a smooth and legal transaction process.

## How To Complete This Form
To fill out the Property Release Form, follow these steps:
1. Start by providing the property owner's details.
2. Enter the property location, including the address.
3. Specify the type of property being sold or transferred.
4. Mention the property value.
5. Enter the buyer's name and contact information.
6. Complete the form by providing the necessary details for both the property owner and the buyer.

* **Property Type** (`property_type`, text, required: false): Specify the type of property being sold or transferred, e.g., house, apartment, commercial building, etc.
* **Property Value** (`property_value`, text, required: false): Enter the value or sale price of the property.
