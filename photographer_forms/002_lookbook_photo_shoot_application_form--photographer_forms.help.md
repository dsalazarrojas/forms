# lookbook_photo_shoot_application_form - Help Guide
## Purpose
The lookbook_photo_shoot_application_form is a tool for photographers and models to submit applications for photo shoots. It is designed to gather essential information about the shoot, including the date, location, photographer's and model's experience, equipment, and rates.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the form with the required information.
2. Ensure that all fields are filled out accurately and truthfully.
3. Double-check your submission date to ensure it is correct.

## Field-by-Field Explanation

* **Form Title** (`form_title`, text, required): This is the title of the photo shoot, which should be a brief description of the project.
* **Photographer Name** (`photographer_name`, text, required): This is the name of the photographer submitting the application.
* **Photographer Email** (`photographer_email`, email, required): This is the email address of the photographer submitting the application.
* **Contact Info** (`photographer_contact_info`, text, required): This is a brief description of how the photographer can be contacted.
* **Photographer Phone** (`photographer_phone`, text, required): This is the phone number of the photographer submitting the application.
* **Photographer Website** (`photographer_website`, text, required): This is the website of the photographer submitting the application.
* **Model Name** (`model_name`, text, required): This is the name of the model submitting the application.
* **Model Email** (`model_email`, email, required): This is the email address of the model submitting the application.
* **Model Contact Info** (`model_contact_info`, text, required): This is a brief description of how the model can be contacted.
* **Model Phone** (`model_phone`, text, required): This is the phone number of the model submitting the application.
* **Model Website** (`model_website`, text, required): This is the website of the model submitting the application.
* **Shoot Date** (`shoot_date`, date, required): This is the date of the photo shoot.
* **Shoot Time** (`shoot_time`, time, required): This is the time of the photo shoot.
* **Shoot Location** (`shoot_location`, text, required): This is the location of the photo shoot.
* **Shoot Description** (`shoot_description`, text, required): This is a brief description of the photo shoot.
* **Photographer Experience** (`photographer_experience`, text, required): This is a brief description of the photographer's experience.
* **Photographer Equipment** (`photographer_equipment`, text, required): This is a list of the equipment the photographer will be bringing to the shoot.
* **Photographer Rate** (`photographer_rate`, number, required): This is the rate the photographer is charging for the shoot.
* **Model Experience** (`model_experience`, text, required): This is a brief description of the model's experience.
* **Model Equipment** (`model_equipment`, text, required): This is a list of the equipment the model will be bringing to the shoot.
* **Model Rate** (`model_rate`, number, required): This is the rate the model is charging for the shoot.
* **Shoot Details** (`shoot_details`, text, required): This is a brief description of any specific details about the shoot.
* **Model Availability** (`model_availability`, text, required): This is a brief description of the model's availability for the shoot.
* **Photographer Notes** (`photographer_notes`, text, optional): This is any additional information the photographer wants to provide about the shoot.
* **Submission Date** (`submission_date`, date, required): This is the date the application was submitted.
