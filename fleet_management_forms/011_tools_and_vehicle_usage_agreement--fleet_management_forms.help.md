# Tools And Vehicle Usage Agreement - Help Guide
## Purpose
The "Tools And Vehicle Usage Agreement" form is used to record and report the usage of tools and vehicles within an organization. This form helps to ensure that usage is properly documented and accounted for, facilitating better management and maintenance of tools and vehicles.

## How To Complete This Form
To complete this form, follow these steps:

1. **Select the tool and vehicle IDs**: If provided, enter the corresponding tool and vehicle IDs in the respective fields (`tool_id` and `vehicle_id`).
2. **Enter tool and vehicle names**: Provide the names of the tools and vehicles used (`tool_name` and `vehicle_name`).
3. **Indicate tool and vehicle usage status**: Choose whether the tool and vehicle were used or not (`tool_type` and `vehicle_type`).
4. **Enter user details**: Enter your employee ID and name (`user_id` and `user_name`).
5. **Record start and end dates and times**: Enter the start and end dates and times of usage (`start_date`, `start_time`, `end_date`, `end_time`).
6. **Update odometer reading and fuel level**: Enter the odometer reading and fuel level for the vehicle used (`odometer_reading` and `fuel_level`).
7. **Add comments**: Provide any additional comments related to the tool and vehicle usage.

## Field-by-Field Explanation
### Tool ID (`tool_id`, number, required: false)
Enter the ID of the tool used.

### Vehicle ID (`vehicle_id`, number, required: false)
Enter the ID of the vehicle used.

### Tool Name (`tool_name`, text, required: false)
Enter the name of the tool used.

### Vehicle Name (`vehicle_name`, text, required: false)
Enter the name of the vehicle used.

### Tool Type (`tool_type`, select, required: false)
Indicate whether the tool was used (`Yes` or `No`).

### Vehicle Type (`vehicle_type`, select, required: false)
Indicate whether the vehicle was used (`Yes` or `No`).

### User ID (`user_id`, number, required: false)
Enter your employee ID.

### User Name (`user_name`, text, required: false)
Enter your name as an employee.

### Start Date (`start_date`, date, required: false)
Enter the start date of usage.

### Start Time (`start_time`, time, required: false)
Enter the start time of usage.

### End Date (`end_date`, date, required: false)
Enter the end date of usage.

### End Time (`end_time`, time, required: false)
Enter the end time of usage.

### Odometer Reading (`odometer_reading`, number, required: false)
Enter the odometer reading of the vehicle used.

### Fuel Level (`fuel_level`, number, required: false)
Enter the fuel level of the vehicle used.

### Comments (`comments`, note, required: false)
Provide any additional comments related to the tool and vehicle usage.
