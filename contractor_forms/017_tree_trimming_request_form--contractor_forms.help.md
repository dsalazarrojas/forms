# Tree Trimming Request Form - Help Guide
## Purpose

The Tree Trimming Request Form is designed to collect information from customers to request tree trimming services. This form helps us understand their needs and schedule the necessary services for a safe and efficient tree trimming process.

## How To Complete This Form

1. Fill in the required fields with accurate information.
2. Select all services needed for the tree trimming request.
3. Provide a clear request date and time.
4. Select the tree species, size, and location.
5. Add any additional information about the tree and the request.
6. Review and submit the form.

## Field-by-Field Explanation

* **Tree Trimming Request** (`tree_trimming_request_form`): This field is a free text area where you can provide a brief description of the tree trimming request.
* **Contact Name** (`contact_name`): Please enter your name as the person requesting the service.
* **Contact Email** (`contact_email`): Enter a valid email address to receive updates and notifications about the tree trimming process.
* **Phone Number** (`phone_number`): This field is optional but recommended for any further contact or clarification.
* **Address** (`address`): Enter the address or location where the tree is located.
* **Services Needed** (`services_needed`): Select all the services required for the tree trimming, such as tree trimming, removal, shaping, or chopping.
* **Tree Trimming** (`service_1`): If tree trimming is selected, this field will appear, and you can select the specific option(s) required.
* **Tree Removal** (`service_2`): If tree removal is selected, this field will appear, and you can select the specific option(s) required.
* **Tree Shaping** (`service_3`): If tree shaping is selected, this field will appear, and you can select the specific option(s) required.
* **Tree Chopping** (`service_4`): If tree chopping is selected, this field will appear, and you can select the specific option(s) required.
* **Request Date** (`request_date`): Choose the date when you would like the tree trimming to take place.
* **Request Time** (`request_time`): Choose the specific time for the tree trimming.
* **Tree Species** (`tree_species`): Select the type of tree species for accurate assessment.
* **Tree Size** (`tree_size`): Select the size of the tree for accurate assessment.
* **Tree Height** (`tree_height`): If necessary, enter the exact height of the tree for accurate assessment.
* **Tree Condition** (`tree_condition`): Select the condition of the tree for accurate assessment.
* **Tree Location** (`tree_location`): Enter the specific location of the tree.
* **Additional Info** (`additional_info`): Provide any additional information about the tree or the request.
* **Notes** (`notes`): Add any further comments or instructions for the service provider.
* **Tree Diameter** (`tree_diameter`): If necessary, enter the diameter of the tree for accurate assessment.
* **Tree Height Range** (`tree_height_range`): If necessary, select the height range of the tree for accurate assessment.
