# Construction Project Progress Report - Help Guide

## Purpose
The Construction Project Progress Report is a document that provides information about the current status of a construction project. This report is used to track progress, identify issues, and communicate project information to stakeholders.

## How To Complete This Form

1. Select the report date from the calendar provided.
2. Enter the start and end dates of the reporting period.
3. Enter the project name and project number (if applicable).
4. Select the project manager's name.
5. Enter the site location (project address).
6. Enter the overall progress percentage of the project.
7. Choose the current schedule status of the project (e.g., ahead of schedule, on schedule, slightly behind, etc.).
8. Choose the current budget status of the project (e.g., under budget, on budget, slightly over budget, etc.).
9. Describe the work completed and planned during the reporting period.
10. List any milestones achieved or upcoming during this period.
11. Provide a summary of labor hours and headcount.
12. List any active subcontractors working on the project.
13. Describe the status of materials delivery and usage.
14. Describe the status of equipment usage and any issues.
15. Report any safety incidents or issues.
16. Provide safety metrics (e.g., days without incident, TRIR, etc.).
17. Describe any quality issues.
18. List any inspections completed during this period.
19. List any change orders issued.
20. Describe any problems affecting progress.
21. List any RFIs submitted.
22. Indicate if progress photos are attached to the report.
23. Enter the name of the person preparing the report.

## Field-by-Field Explanation

* **Report Date** (`report_date`, **date**, required): Enter the date of this progress report.
* **Reporting Period Start** (`report_period_start`, **date**, required): Enter the start date of the reporting period.
* **Reporting Period End** (`report_period_end`, **date**, required): Enter the end date of the reporting period.
* **Project Name** (`project_name`, **text**, required): Enter the name of the construction project.
* **Project Number** (`project_number`, **text**, optional): Enter the project reference number.
* **Project Manager** (`project_manager`, **text**, required): Enter the name of the project manager.
* **Project Address** (`project_address`, **text**, required): Enter the site location (project address).
* **Overall Progress Percentage** (`overall_progress`, **number**, required): Enter the current progress percentage of the project.
* **Schedule Status** (`schedule_status`, **select_one**, required): Choose the current schedule status of the project.
* **Budget Status** (`budget_status`, **select_one**, required): Choose the current budget status of the project.
* **Work Completed This Period** (`work_completed_period`, **text**, required): Describe the work done during this reporting period.
* **Work Planned for Next Period** (`work_planned_next`, **text**, required): Describe the work planned for the next period.
* **Milestones Achieved** (`milestones_achieved`, **text**, optional): List any milestones achieved this period.
* **Upcoming Milestones** (`milestones_upcoming`, **text**, optional): List any upcoming milestones.
* **Labor Summary** (`labor_summary`, **text**, required): Enter a summary of labor hours and headcount.
* **Active Subcontractors** (`subcontractors_active`, **text**, optional): List any active subcontractors working on the project.
* **Materials Status** (`materials_status`, **text**, required): Describe the status of materials delivery and usage.
* **Equipment Status** (`equipment_status`, **text**, optional): Describe the status of equipment usage and any issues.
* **Safety Incidents** (`safety_incidents`, **text**, optional): Report any safety incidents or issues.
* **Safety Metrics** (`safety_metrics`, **text**, optional): Enter any safety metrics (e.g., days without incident, TRIR, etc.).
* **Quality Issues** (`quality_issues`, **text**, optional): Describe any quality issues.
* **Inspections Completed** (`inspections_completed`, **text**, optional): List any inspections completed during this period.
* **Change Orders** (`change_orders`, **text**, optional): List any change orders issued.
* **Issues or Delays** (`issues_delays`, **text**, optional): Describe any problems affecting progress.
* **RFIs Submitted** (`rfis_submitted`, **text**, optional): List any RFIs submitted.
* **Progress Photos** (`photos_attached`, **select_one**, optional): Indicate if progress photos are attached.
* **Report Prepared By** (`reporter_name`, **text**, required): Enter the name of the person preparing the report.

Note: The fields marked as optional may be omitted if not applicable to the project.
