# Excavation Safety Checklist - Help Guide
## Purpose
The Excavation Safety Checklist is a form used by site supervisors to collect data on excavation site safety concerns, precautions, and equipment usage. It helps to ensure that the site has been properly assessed and prepared for excavation work.

## How To Complete This Form
To complete this form, please follow these steps:

1. Enter the name of the contractor or company performing the excavation work.
2. Provide the address of the site where the excavation will take place.
3. Enter the name of the supervisor or person in charge of the site.
4. Enter the start and end dates of the excavation work.
5. Describe the site and any specific hazards or safety concerns that need to be addressed.
6. If applicable, select "Yes" to indicate that there are safety concerns on the site. If not applicable, select "No".
7. Provide any relevant safety precautions that have been taken.
8. Select "Yes" if you used any specialized equipment, such as trenching or excavation equipment. If not applicable, select "No".
9. Describe any specialized equipment used during the excavation.

## Field-by-Field Explanation
* **Contractor Name** (`contractor_name`, text, optional): Enter the name of the contractor or company performing the excavation work.
* **Site Address** (`site_address`, text, optional): Provide the address of the site where the excavation will take place.
* **Supervisor Name** (`supervisor_name`, text, optional): Enter the name of the supervisor or person in charge of the site.
* **Start Date** (`start_date`, date, optional): Enter the start date of the excavation work.
* **End Date** (`end_date`, date, optional): Enter the end date of the excavation work.
* **Site Description** (`site_description`, text, optional): Describe the site and any specific hazards or safety concerns that need to be addressed.
* **Safety Concerns** (`safety_concerns`, select_multiple, optional): If applicable, select "Yes" to indicate that there are safety concerns on the site. If not applicable, select "No".
* **Precautions** (`precautions`, text, optional): Provide any relevant safety precautions that have been taken.
* **Equipment Used** (`equipment_used`, select_one, optional): Select "Yes" if you used any specialized equipment, such as trenching or excavation equipment. If not applicable, select "No".
* **Equipment Description** (`equipment_description`, text, optional): Describe any specialized equipment used during the excavation.
