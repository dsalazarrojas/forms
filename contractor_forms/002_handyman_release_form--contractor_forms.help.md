# Handyman Release Form - Help Guide
## Purpose
This form is used by contractors to release or hand over a job to a client, providing essential details about the job, task, and release conditions.

## How To Complete This Form

1. Ensure that you have all the necessary details about the job, task, and release conditions ready before starting the form.
2. Fill in the required fields (indicated by an asterisk `*`) completely and accurately.
3. Use clear and concise language in the text fields.
4. Ensure that the release date and time are correct.

## Field-by-Field Explanation

* **Handyman Release Form** (`handyman_release_form`, text, optional): This field is not required but can be used to provide a brief summary of the release form.
* **Job Details** (`job_details`, text, optional): Enter a description of the job, including any relevant details about the task.
* **Task Description** (`task_description`, text, optional): Describe the task that needs to be released.
* **Task Location** (`task_location`, text, optional): Specify the location where the task will be released.
* **Release Date** (`release_date`, date, optional): Enter the date on which the task is to be released.
* **Release Time** (`release_time`, time, optional): Enter the time when the task is to be released.
* **Release Signature** (`signature`, text, optional): Provide your signature to confirm that the task has been released.
* **Print Date** (`print_date`, date, optional): This field is currently not in use but is a placeholder for potential future implementation.

## Tips

* Ensure that you have all necessary permissions and approvals before submitting the form.
* Double-check the entered details for accuracy before submitting.
* Use the release date and time as the actual release date and time for the task.
