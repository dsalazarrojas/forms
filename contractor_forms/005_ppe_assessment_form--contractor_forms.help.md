# PPE Assessment Form - Help Guide
## Purpose
The PPE Assessment Form is used to record the assessment of Personal Protective Equipment (PPE) for workers. This form is intended to ensure that PPE is properly assessed and reviewed regularly to ensure workers' safety.

## How To Complete This Form
To complete this form, please follow these steps:

1. Review the form carefully and ensure that all required fields are completed.
2. Enter the correct information for each field, as described in the field-by-field explanation below.

## Field-by-Field Explanation

* **ppe_assessment_form** (Required: false): This field is not actually displayed in the form, it seems to be a placeholder for the form title. Please ignore this field.
* **ppe_conducted_by** (Required: true): Enter the name of the person conducting the PPE assessment.
* **ppe_location** (Required: true): Enter the location where the PPE assessment was conducted.
* **ppe_equipment** (Required: false): Check if Personal Protective Equipment is available at the location. Select 'Yes' if available, 'No' otherwise.
* **ppe_hazards** (Required: true): Check for potential hazards present at the location. Select 'Yes' if hazards are present, 'No' otherwise.
* **ppe_control_measures** (Required: false): Check which control measures are in place for the identified hazards. Select 'Yes' for each relevant control measure.
* **ppe_responsible_personnel** (Required: false): Enter the name of the person responsible for the PPE.
* **ppe_reviewed_by** (Required: false): Enter the name of the person who reviewed the PPE assessment.
* **ppe_reviewed_date** (Required: true): Enter the date when the PPE assessment was reviewed.
* **ppe_next_review** (Required: false): If a review is due, enter the date for the next review.
* **ppe_review_frequency** (Required: true): Select how frequently the PPE assessment will be reviewed (quarterly, semiannually, or yearly).
* **ppe_completed** (Required: true): Check if the PPE assessment is completed. Select 'completed' if complete, 'not completed' if not.
