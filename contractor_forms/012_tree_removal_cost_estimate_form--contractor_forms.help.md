# Tree Removal Cost Estimate Form - Help Guide
## Purpose
This form is used to gather information from customers about the cost of removing a tree. The goal is to get a quote for tree removal services and provide additional information to the customer.

## How To Complete This Form
To complete this form, follow these steps:

1. **Fill out all required fields**:
   * **Contact Name**: Enter the name of the person who requested the tree removal service.
   * **Contact Phone**: Enter the phone number of the contact person.
   * **Tree Height**: Enter the height of the tree in feet.
   * **Removal Date**: Enter the date you would like the tree to be removed.
   * **Stump Type**: Check if the stump will be ground up or removed.
   * **Tree Type**: Select whether the tree is a tree or not.

2. **Enter any additional information**:
   * **Tree Removal Request**: Enter a brief description of the tree removal request.
   * **Tree Location**: Enter the location of the tree.
   * **Notes**: Enter any additional comments or information about the tree removal request.

## Field-by-Field Explanation
* **Tree Removal Request**: A brief description of the tree removal request.
* **Contact Name**: The name of the person who requested the tree removal service.
* **Contact Phone**: The phone number of the contact person.
* **Tree Type**: A select option to indicate if the tree is a tree or not.
* **Tree Height**: The height of the tree in feet.
* **Stump Type**: A select option to indicate if the stump will be ground up or removed.
* **Tree Location**: The location of the tree.
* **Removal Date**: The date you would like the tree to be removed.
* **Notes**: A note field for any additional comments or information about the tree removal request.

## Tips
* Make sure to fill out all required fields.
* If the tree is not a tree, select "No" for the Tree Type field.
* If the stump will not be removed, select "No" for the Stump Type field.
