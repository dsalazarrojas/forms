# Responsive Maintenance Request Form - Help Guide

## Purpose
The Responsive Maintenance Request Form is used for requesting maintenance tasks that require a response from contractors or facility management. This form is used to provide details about the maintenance request, including the equipment involved, location, and contact information. It is essential to fill out the form completely and accurately to ensure that the maintenance request is handled efficiently.

## How To Complete This Form

1. **Fill out all required fields**: Make sure to fill out all required fields, marked with a red asterisk (\*). These fields include:
	* Assigned Tool
	* (You can only see the assigned tool options after filling out this field)

2. **Select the correct options**: Choose the correct options for the following fields:
	* Equipment: Choose 'Yes' if you need service on equipment, 'No' otherwise
	* Location: Choose 'Yes' for all locations that apply
	* Category: Choose 'Yes' for the specific category of the maintenance request

3. **Provide detailed information**: Be as descriptive as possible in the fields:
	* Maintenance Request: Describe the issue or problem with the equipment
	* Comments: Add any additional comments or notes about the maintenance request

4. **Submit the form**: Once you have filled out all the fields, click the 'Submit' button to send the maintenance request.

## Field-by-Field Explanation

* **Assigned Tool** (`Assigned Tool`, select_one, required): Select the assigned tool from the list of options to specify which tool is being used for the maintenance request.
* **Category** (`Category`, select_one, required): Select 'Yes' for the specific category of the maintenance request.
* **Location** (`Location`, select_multiple, required): Choose all locations where the maintenance request is needed.
* **Equipment** (`Equipment`, select_one, required): Choose 'Yes' to indicate that the maintenance request is related to equipment.
* **Comments** (`Comments`, select_multiple, required): Add any additional comments or notes about the maintenance request.
* **Email** (`Email`, email, required): Enter your email address for contact purposes.
* **Phone** (`Phone`, text, required): Enter your phone number for contact purposes.
* **Address** (`Address`, text, required): Enter your address for contact purposes.
* **Description** (`Description`, text, required): Describe the issue or problem with the equipment.
* **Date** (`Date`, date, required): Enter the date when you need the maintenance request to be fulfilled.
* **Time** (`Time`, time, required): Enter the time when you need the maintenance request to be fulfilled.
* **Contractor Details** (`Contractor Details`, text, optional): Enter any additional information about the contractor.
* **Maintenance Request** (`Maintenance Request`, text, optional): Enter any additional details about the maintenance request.
* **Submit** (`Submit`, text, required): Click this button to submit the form.

## Tips

* Be as detailed as possible in the fields to ensure that the maintenance request is handled efficiently.
* Review the form carefully before submitting it to ensure that all required fields are filled out.
* Make sure to enter a valid email address and phone number to ensure that you can be contacted about the maintenance request.
* If you are unsure about any field, contact your supervisor or maintenance manager for guidance.
