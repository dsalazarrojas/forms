# Construction Progress Report Form - Help Guide
## Purpose
The Construction Progress Report Form is a tool used to track and report on the current status of ongoing construction projects. It helps project stakeholders stay informed about the project's progress and any challenges or issues that may be affecting it.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the **Project name** where it's being reported on. This is a required field and should be filled out accurately.
2. Select the **Report date** for this progress report. This is also a required field and helps us track the timeline of your project's progress.
3. Enter the name of the **Reporting contractor** company submitting the progress report. This is a required field and helps us associate your report with your company.
4. Provide a **Work completed summary**, briefly describing the activities completed during the reporting period.
5. If there are any **Issues and delays**, please list them here. This field is optional, but helps us stay informed about any challenges you're facing.
6. If there have been any **Safety incidents**, please report them here. This field is also optional, but essential for maintaining a safe working environment.
7. Describe your **Plan for next reporting period**, including key tasks and milestones.
8. If applicable, enter the **Percent complete** of the project at the time of reporting.

## Field-by-Field Explanation
- **Project name**: A required field to specify the project being reported on.
  • Type: text
  • Required: yes
  • Hint: Project being reported on
- **Report date**: A required field for tracking the date of this report.
  • Type: date
  • Required: yes
  • Hint: Date of this report
- **Reporting contractor**: A required field specifying the company submitting the report.
  • Type: text
  • Required: yes
  • Hint: Company submitting the progress report
- **Work completed summary**: A brief description of activities completed during the reporting period.
  • Type: text
  • Required: yes
  • Hint: Brief description of activities completed
- **Issues and delays**: Optional field for reporting any current issues affecting the schedule.
  • Type: text
  • Required: no
  • Hint: Note any current issues affecting schedule
- **Safety incidents**: Optional field for reporting any safety incidents.
  • Type: text
  • Required: no
  • Hint: Number or brief description of incidents
- **Plan for next reporting period**: A required field outlining key tasks and milestones for the next reporting period.
  • Type: text
  • Required: yes
  • Hint: Key tasks planned for the next period
- **Percent complete**: Optional field for estimating the percent complete at the time of reporting.
  • Type: number
  • Required: no
  • Hint: Estimated percent complete at reporting
