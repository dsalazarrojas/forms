# Home Renovation Checklist - Help Guide
## Purpose
The Home Renovation Checklist form is used to collect project details, budget information, timeline, and contact details for home renovation projects.

## How To Complete This Form
To complete this form, follow these steps:

1. Review the project details section and enter the project's name in the "home_renovation_project_details" field.
2. Enter the project budget in the "project_budget" field.
3. Enter the project start and completion dates in the "project_start_date" and "project_completion_date" fields, respectively.
4. Select the project type from the "project_type" dropdown menu.
5. Choose the current project status from the "project_status" dropdown menu.
6. Enter the contractor's name in the "contractor_name" field.
7. Enter the contact number in the "contact_number" field.
8. Enter the project manager's name in the "project_manager_name" field.
9. Enter the project manager's email address in the "project_manager_email" field.
10. Enter the project manager's phone number in the "project_manager_phone" field.
11. Add any project notes or comments in the "project_notes" field.
12. Enter the project's address in the "project_address" field.

## Field-by-Field Explanation
* **Home Renovation Project Details** (`home_renovation_project_details`): Enter a brief description of the home renovation project.
* **Project Budget** (`project_budget`): Enter the estimated budget for the project.
* **Project Start Date** (`project_start_date`): Enter the start date of the project.
* **Project Completion Date** (`project_completion_date`): Enter the expected completion date of the project.
* **Project Type** (`project_type`): Select the type of project (e.g., renovation, repair, expansion).
* **Project Status** (`project_status`): Choose the current status of the project (e.g., Active, In Progress, Completed).
* **Contractor Name** (`contractor_name`): Enter the name of the contractor or builder.
* **Contact Number** (`contact_number`): Enter the contact number of the project manager or contractor.
* **Project Manager Name** (`project_manager_name`): Enter the name of the project manager.
* **Project Manager Email** (`project_manager_email`): Enter the email address of the project manager.
* **Project Manager Phone** (`project_manager_phone`): Enter the phone number of the project manager.
* **Project Notes** (`project_notes`): Add any additional comments or notes about the project.
* **Project Address** (`project_address`): Enter the physical address of the project location.
