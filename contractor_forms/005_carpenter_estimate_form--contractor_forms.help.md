# Carpenter Estimate Form - Help Guide
## Purpose
This form is designed to gather all necessary information for a carpenter to create an accurate estimate for a project.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the customer's full name.
2. Provide their phone number and email address.
3. Enter the customer's project address.
4. Select the type of carpentry project.
5. Describe the project's scope and details.
6. Choose the project's location type.
7. Select the scope of work involved.
8. Choose the desired project timeline.
9. If applicable, enter the preferred start date.
10. Provide any additional project specifications.
11. Specify project dimensions or square footage.
12. Enter material preferences.
13. Choose the desired finish type.
14. Select the design style or aesthetic.
15. List any special requirements or custom features.
16. Check for any visible structural issues or concerns.
17. Enter the approximate budget range.
18. Add any additional notes or questions.

## Field-by-Field Explanation

* **Customer Full Name (Customer Full Name)** (`customer_name`, `text`, **required**): Enter the customer's full name as it appears on their ID or documents.
* **Phone Number (customer_phone`, `text`, **required**): Enter the customer's phone number for communication purposes.
* **Email Address (customer_email`, `email`, **required**): Enter the customer's email address for communication purposes.
* **Project Address (customer_address`, `text`, **required**): Enter the customer's project address where the work will be done.
* **Type of Carpentry Project (project_type`, `select_one`, **required**): Select the primary type of carpentry project (e.g., Cabinet Installation, Door and Frame Installation, etc.).
* **Detailed Project Description (project_description`, `text`, **required**): Describe the scope of work needed for the project.
* **Project Location Type (project_location`, `select_one`, **required**): Choose the project location type (Interior, Exterior, Both).
* **Scope of Work (scope_of_work`, `select_multiple`, **required**): Check all that apply for the scope of work involved (e.g., Measurement and Planning, Material Sourcing, etc.).
* **When do you need this project completed? (project_timeline`, `select_one`, **required**): Select the desired project timeline (e.g., Within 1 week, Within 2 weeks, etc.).
* **Preferred Start Date (project_start_date`, `date`, **optional**): Enter the preferred start date if applicable.
* **Project Dimensions or Square Footage (project_dimensions`, `text`, **required**): Provide measurements or area for the project.
* **Material Preferences (materials_preference`, `text`, **optional**): Specify preferred wood types or materials.
* **Desired Finish Type (finish_type`, `select_one`, **optional**): Choose the desired finish type (e.g., Stained, Painted, etc.).
* **Design Style or Aesthetic (design_style`, `select_one`, **optional**): Select the design style or aesthetic (e.g., Traditional, Modern, etc.).
* **Special Requirements or Custom Features (special_requirements`, `text`, **optional**): List any unique specifications or custom features.
* **Any visible structural issues or concerns (structural_assessment`, `text`, **optional**): Check for any visible structural issues or concerns.
* **Budget Range (budget_range`, `select_one`, **optional**): Approximate the budget for the project (e.g., Under $500, $500 - $1,000, etc.).
* **Additional Notes or Questions (additional_notes`, `text`, **optional**): Add any additional notes or questions for the carpenter's reference.

Note: Fields marked as **required** are necessary for the carpenter to complete the estimate accurately.
