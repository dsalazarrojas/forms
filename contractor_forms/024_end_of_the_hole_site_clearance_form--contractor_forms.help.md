# End Of The Hole Site Clearance Form - Help Guide
## Purpose
The End Of The Hole Site Clearance Form is used to document the end-of-hole site clearance process for a given site. It ensures that all necessary work has been completed and all required documentation has been captured before leaving the site.

## How To Complete This Form
1. Fill out the form completely and accurately, making sure to provide all required information for each field.
2. Ensure that the Site Inspection section is accurate, as it reflects the status of site-specific activities.
3. Verify that all fields are filled out before submitting the form.

## Field-by-Field Explanation
* **Site Details (site_details)**: Enter a brief description or title of the site.
* **Site Clearance (site_clearance)**: Enter the clearance status of the site, as per your discretion.
* **Clearance Details (clearance_details)**: Enter any additional details necessary for the clearance process.
* **Contractor Details (contractor_details)**: Enter any details or information relevant to the contractor or personnel involved with the site work.
* **Site Inspection (site_inspection)**: Select all the options that accurately describe the site inspection status, including:
  * Option 1: Site Inspection Not Conducted
  * Option 2: Site Inspection Conducted but not fully completed
  * Option 3: Site Inspection Fully Completed
  * Option 4: Site Inspection Not Required
  * Option 5: Site Inspection Deferred

## Tips
- Double-check all fields before submitting the form to ensure accuracy.
- Make sure to save and submit the form once all fields are filled out.
- If you need to revisit or update the form, use the "Save and Continue" feature for future modifications.
