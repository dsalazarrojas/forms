# Contract Management Tool Requisition Form - Help Guide
## Purpose

<thinking>
This form is used by requestors to submit a formal request for the use of a new contract management tool to the organization. This form helps to gather necessary information from the requestor to assess the business needs and requirements for the tool. By completing this form, the requestor will be able to provide a clear and comprehensive description of their needs, which will then be reviewed and evaluated by relevant stakeholders for approval.
</thinking>

## How To Complete This Form

To complete this form, please follow these steps:

1. Fill in the required information for each field, marked as "Required" in the form.
2. If a field is not required, you can leave it blank.
3. For select fields, choose the most appropriate option that best describes your needs.
4. Ensure that all fields are accurately filled out to ensure that your request is processed correctly.

## Field-by-Field Explanation

* **Requestor Name** (`requestor_name`, `text`, required): Enter your full name as the person submitting this request.
* **Requestor Title** (`requestor_title`, `text`, required): Enter your job title or role within the organization.
* **Department** (`department`, `select_one`, required): Select the department you belong to from the provided options.
* **Request Date** (`request_date`, `date`, required): Enter the date the request was made.
* **Tool Name** (`tool_name`, `text`, required): Enter the name of the software or tool being requested.
* **Tool Vendor** (`tool_vendor`, `text`, required): Enter the company providing the tool.
* **Tool Category** (`tool_category`, `select_one`, required): Select the category of the tool from the provided options.
* **Business Justification** (`business_justification`, `text`, required): Explain why this tool is needed.
* **Current Process** (`current_process`, `text`, required): Describe how you currently manage this type of task or process.
* **Pain Points** (`pain_points`, `text`, required): Describe the problems this tool will solve or improve upon.
* **Expected Benefits** (`expected_benefits`, `select_multiple`, required): Select the expected benefits of using this tool.
* **Number of Users** (`number_of_users`, `number`, required): Enter the number of users that will be using the tool.
* **User Types** (`user_types`, `select_multiple`, required): Select the types of users that will be using the tool from the provided options.
* **Licensing Model** (`licensing_model`, `select_one`, not required): If applicable, select the type of license you will be using.
* **Estimated Cost** (`estimated_cost`, `number`, required): Enter the annual cost of the tool.
* **Budget Code** (`budget_code`, `text`, required): Enter the cost center for the budget.
* **Funding Source** (`funding_source`, `text`, required): Describe where the funding for this request comes from.
* **Implementation Timeline** (`implementation_timeline`, `select_one`, required): Select the time frame for deploying the tool.
* **Integration Requirements** (`integration_requirements`, `text`, not required): If applicable, describe any integration requirements for the tool.
* **Security Requirements** (`security_requirements`, `select_multiple`, required): Select any security needs for the tool from the provided options.
* **IT Approval Status** (`it_approval_status`, `select_one`, required): Select the status of IT's review.
* **Legal Approval Status** (`legal_approval_status`, `select_one`, required): Select the status of legal's review.
* **Priority Level** (`priority_level`, `select_one`, required): Select the level of priority for this request.
* **Requested Start Date** (`requested_start_date`, `date`, required): Enter the date when you would like to start using the tool.
* **Additional Comments** (`additional_comments`, `text`, not required): If you have any other information to add, enter it here.
