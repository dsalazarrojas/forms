# Moving Inventory Form - Help Guide
## Purpose
This form is used to document the movement of items within or between locations. It helps track the items that have been moved, their quantity, and other relevant details.

## How To Complete This Form
1. Select the "location_from" field and enter the name of the location from which the items were moved.
2. Select the "location_to" field and enter the name of the location to which the items were moved.
3. In the "date_moved" field, select the date on which the items were moved.
4. In the "item_count" field, enter the total number of items moved.
5. In the "item_type" field, select whether the items moved are 'Yes' or 'No' (e.g., furniture, equipment, etc.).
6. In the "item_description" field, provide a brief description of the items moved.
7. In the "item_condition" field, select all the conditions that apply to the items moved (e.g., 'Yes' for items that are in good condition).
8. In the "moved_by" field, enter the name of the person or group responsible for moving the items.

## Field-by-Field Explanation
* **location_from (text)**: The location from which the items were moved.
* **location_to (text)**: The location to which the items were moved.
* **date_moved (date)**: The date on which the items were moved.
* **item_count (number)**: The total number of items moved.
* **item_type (select_one)**: Indicates whether the items moved are a specific type (e.g., furniture, equipment, etc.).
	+ Select 'Yes' if the items are of the specified type.
	+ Select 'No' otherwise.
* **item_description (text)**: A brief description of the items moved.
* **item_condition (select_multiple)**: Select all the conditions that apply to the items moved.
	+ Select 'Yes' for each condition that applies.
* **moved_by (text)**: The name of the person or group responsible for moving the items.
