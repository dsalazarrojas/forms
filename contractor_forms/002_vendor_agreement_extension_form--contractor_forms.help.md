# Vendor Agreement Extension Form - Help Guide
## Purpose
This form is used to extend the terms of an existing contract between a client and a vendor. It's used to update the contract's duration or status.

## How To Complete This Form
To complete this form, follow these steps:

1.  Please fill in the form with the required information and ensure that you're filling out the correct fields for your contract.
2.  Review the form carefully before submitting it to ensure that all fields are completed accurately.

*   **Vendor Agreement Extension Form (page 1)**:
    +  **Agreement Extension Form**:
        `vendor_agreement_extension_form` (text, text, optional)
        This field is used to input the name or description of the agreement extension.
    +  **Vendor Name**:
        `vendor_name` (text, text, optional)
        Please fill in the name of the vendor.
    +  **Contract ID**:
        `contract_id` (number, number, optional)
        If available, please input the contract ID number.
*   **Vendor Information (page 2)**:
    +  **Extension Date**:
        `extension_date` (date, date, optional)
        This field is used to input the date when the agreement extension takes effect.
    +  **Extension Reason**:
        `extension_reason` (text, text, optional)
        Please provide the reason for the agreement extension.
    +  **Renewal Status**:
        `renewal_status` (select_one, select_one, optional)

    +  **Renewal Date**:
        `renewal_date` (date, date, optional)
        This field is used to input the date when the contract will be renewed.
    +  **Renewal Reason**:
        `renewal_reason` (text, text, optional)

*   **Signatures**:
    +  **Vendor Signature**:
        `vendor_signature` (text, text, optional)

    +  **Client Signature**:
        `client_signature` (text, text, optional)

*   **Contract Information (page 3)**:
    +  **Contract Status**:
        `contract_status` (select_one, select_one, optional)
        Choose the current status of the contract:
        *   Active: The contract is still active and valid.
        *   Inactive: The contract has ended or is no longer active.
    +  **Contract Type**:
        `contract_type` (select_one, select_one, optional)
        Choose whether the contract is active or inactive:
        *   Yes: The contract is active and in effect.
        *   No: The contract is inactive and not in effect.
    +  **Contract Amount**:
        `contract_amount` (number, number, optional)
        Please input the amount or value of the contract.
    +  **Contract Start Date**:
        `contract_start_date` (date, date, optional)

    +  **Contract End Date**:
        `contract_end_date` (date, date, optional)
        This field is used to input the end date of the contract.
    +  **Vendor Address**:
        `vendor_address` (text, text, optional)
        Please input the address of the vendor.
*   **Submit**:
