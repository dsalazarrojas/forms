# Site Visit Form - Help Guide
## Purpose
The Site Visit Form is designed to collect site visit information, which is essential for monitoring and maintaining a site's status. This form helps in tracking site visit details, such as location, date, time, notes, and other relevant information.

## How To Complete This Form

To complete this form, follow these steps:

1. Enter the **site visit location** (required) in the `site_visit_location` field.
2. Select the **date** (optional) of the site visit using the calendar icon.
3. Enter the **time** (optional) of the site visit.
4. Provide any additional **notes** (optional) about the site visit.
5. Enter your **phone number** (optional) for contact purposes.
6. Enter your **email address** (optional) for contact purposes.
7. Select the **site visit status** (required):
	* **Site Visit Complete**: The site visit has been successfully completed.
	* **Site Visit Pending**: The site visit is still pending or pending further action.
	* **Site Visit Cancelled**: The site visit has been cancelled.
8. You can also add any additional **comments** (optional) about the site visit.
9. For **attachments** (optional), select the option that applies to your site visit.
10. Select any relevant **tags** (optional) for the site visit.
11. If necessary, select any **employees** (optional) involved in the site visit.
12. Check if there are any **supervisors** (optional) involved in the site visit.
13. Select whether there are any **customers** (optional) involved in the site visit.
14. Check if there are any **contracts** (optional) involved in the site visit.
15. Select whether there are any **tasks** (optional) associated with the site visit.
16. Finally, enter any additional **comments** (optional) about the site visit.

## Field-by-Field Explanation

* **Site Visit Location**: Enter the location of the site visit.
* **Site Visit Date**: Enter the date of the site visit.
* **Site Visit Time**: Enter the time of the site visit.
* **Site Visit Notes**: Add any additional notes about the site visit.
* **Site Visit Phone**: Enter your phone number for contact purposes.
* **Site Visit Email**: Enter your email address for contact purposes.
* **Site Visit Status**: Select the status of the site visit from the options provided:
	+ **Site Visit Complete**: The site visit has been successfully completed.
	+ **Site Visit Pending**: The site visit is still pending or pending further action.
	+ **Site Visit Cancelled**: The site visit has been cancelled.
* **Site Visit Comments**: Add any additional comments about the site visit.
* **Site Visit Attachments**: Select whether attachments are required for the site visit.
* **Site Visit Tags**: Select any relevant tags for the site visit.
* **Site Visit Employees**: Select any employees involved in the site visit.
* **Site Visit Supervisors**: Select whether any supervisors are involved in the site visit.
* **Site Visit Customers**: Select whether any customers are involved in the site visit.
* **Site Visit Contracts**: Select whether any contracts are involved in the site visit.
* **Site Visit Tasks**: Select whether any tasks are involved in the site visit.
* **Site Visit Additional Comments**: Add any additional comments about the site visit.
* **Site Visit Contractor Form ID**: Enter the contractor form ID (optional).
* **Site Visit Form ID**: Enter the site visit form ID (optional).
* **Site Visit Client ID**: Enter the client ID (optional).
* **Site Visit Project Name**: Enter the project name (optional).
* **Site Visit Project ID**: Enter the project ID (optional).
* **Site Visit Project Number**: Enter the project number (optional).
* **Site Visit Project Code**: Enter the project code (optional).
