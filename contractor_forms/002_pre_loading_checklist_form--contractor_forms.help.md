# Pre Loading Checklist Form - Help Guide
## Purpose
The Pre Loading Checklist Form is used to confirm that all necessary tasks and systems have been completed before proceeding with the loading process. This form aims to provide a standardized and efficient way to ensure that all critical steps are taken into account.

## How To Complete This Form
To complete this form, follow these steps:

1. Review each field carefully and select the appropriate options for each section.
2. Select "Yes" for fields that have been completed and "No" for fields that have not.
3. Enter relevant details in text fields, such as email and phone numbers.
4. Use the provided options to select the status of each task or system.
5. Make sure to complete all required fields, as indicated by the "required" label.

## Field-by-Field Explanation

* **Confirm Completed Tasks** (confirm_completed_tasks, select_multiple, required): Confirm that all previously completed tasks have been completed correctly.
	+ Select "Yes" if all tasks have been completed, "No" otherwise.
* **Confirm Equipment Loaded** (confirm_equipment_loaded, select_multiple, required): Confirm that all necessary equipment has been loaded correctly.
	+ Select "Yes" if all equipment has been loaded, "No" otherwise.
* **Confirm Circuit Breaker** (confirm_circuit_breaker_tested, select_multiple, false): Confirm that the circuit breaker has been tested.
	+ Select "Yes" if the circuit breaker has been tested, "No" otherwise. (Note: This field is not required.)
* **Confirm Circuit Breaker Test Note** (confirm_circuit_breaker_tested_note, note, false): Enter any relevant notes or comments about the circuit breaker test.
* **Confirm Circuit Breaker Email** (confirm_circuit_breaker_tested_email, email, false): Enter the email address of the person responsible for the circuit breaker test.
* **Confirm Circuit Breaker Phone** (confirm_circuit_breaker_tested_phone, text, false): Enter the phone number of the person responsible for the circuit breaker test.
* **Confirm All Equipment Loaded** (confirm_all_equipment_loaded, select_multiple, required): Confirm that all equipment has been loaded correctly.
	+ Select "Yes" if all equipment has been loaded, "No" otherwise.
* **Confirm All Equipment Loaded Note** (confirm_all_equipment_loaded_note, note, false): Enter any relevant notes or comments about the loading of all equipment.
* **Confirm All Equipment Loaded Email** (confirm_all_equipment_loaded_email, email, false): Enter the email address of the person responsible for the loading of all equipment.
* **Confirm All Equipment Loaded Phone** (confirm_all_equipment_loaded_phone, text, false): Enter the phone number of the person responsible for the loading of all equipment.
* **Confirm Critical Systems** (confirm_critical_systems, select_multiple, required): Confirm that all critical systems have been completed.
	+ Select "Yes" if all critical systems have been completed, "No" otherwise.
* **Confirm Critical Systems Test Note** (confirm_critical_systems_note, note, false): Enter any relevant notes or comments about the critical systems test.
* **Confirm Critical Systems Email** (confirm_critical_systems_email, email, false): Enter the email address of the person responsible for the critical systems test.
* **Confirm Critical Systems Phone** (confirm_critical_systems_phone, text, false): Enter the phone number of the person responsible for the critical systems test.

## Tips

* Make sure to answer all required fields truthfully.
* Use relevant details in text fields for accurate contact information.
* Review each field carefully to ensure accurate completion of tasks and systems.
