# Project Change Order Form - Help Guide

## Purpose
The Project Change Order Form is used to document and process changes to a project. It captures essential details about the project and its changes, ensuring that all parties involved are informed and aligned.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the **Project Details** (page 1) with the relevant information about the project.
2. On **Change Details** (page 2), describe the project change and provide any supporting documentation (if applicable).
3. On **Documents** (page 3), upload any relevant supporting documents for the project change.
4. Decide whether to **Collect Electronic Signatures** (page 4). If yes, select the options for electronic signature collection.
5. Choose the **Contractor Forms** (page 5) that apply to the project change.
6. Review and confirm the submission on **Review and Submit** (page 6).

## Field-by-Field Explanation
### Project Details (required)
* **Project Details** (1): Enter a brief description of the project, including the project name, location, and any other relevant details.

### Change Details (required)
* **Change Details** (2): Describe the project change, including the reason for the change, the expected impact on the project timeline, and any other relevant information.

### Documents (optional)
* **Documents** (3): Attach supporting documents that relate to the project change, such as photos, videos, or other digital media.

### E-Signature Collection (optional)
* **E-Signature Collection** (4): Decide whether to collect electronic signatures for the project change. If yes, select the options for electronic signature collection.

### Contractor Forms (required)
* **Contractor Forms** (5): Select the contractor forms that apply to the project change, such as Form 1, Form 2, or Form 3.

### Review and Submit (required)
* **Review and Submit** (6): Confirm that all information has been entered correctly and submit the form for processing.

## Tips
- Make sure to provide accurate and detailed information in **Project Details** and **Change Details** to ensure clarity and understanding.
- Attach only relevant supporting documents in **Documents**, as unnecessary attachments can slow down the submission process.
- If collecting electronic signatures, ensure that all parties involved are aware of the process.
- Select the correct **Contractor Forms** based on the project requirements.
- Double-check the submission before confirming in **Review and Submit**.
