# Construction Handover Form - Help Guide
## Purpose
This form is used to document the handover process of a construction project, gathering information on the project's details, completion status, and handover process.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the **Handover Date** of the project.
2. Fill in the **Project Name**, which is the name of the completed project.
3. Provide the **Project Address**, which is the full site address.
4. Enter the **Contractor Name**, which is the name of the general contractor company.
5. Enter the **Contractor Contact**, which is the primary contact person for the project.
6. Enter the **Contractor Email** and **Contractor Phone**, which are the contact details for the general contractor company.
7. Enter the **Client Name**, which is the project owner or recipient.
8. Enter the **Client Email** and **Client Phone**, which are the contact details for the client.
9. Select the **Project Completion Date**, which is the date when the work was finished.
10. Enter the **Final Contract Value**, which is the total project cost.
11. Select the **Punch List Status**, which indicates the current status of the punch list.
12. List any **Remaining Punch List Items**.
13. List any **Warranties and Guarantees** provided.
14. Select the **Warranty Period**, which is the duration of warranty coverage.
15. Check if **Equipment Manuals** were provided.
16. List any **Keys and Access Devices** handed over.
17. Select which **Systems Were Demonstrated** to the client.
18. Check if **Final Inspection Passed**.
19. Check if the **Certificate of Occupancy** has been issued.
20. Check if **Lien Waivers** have been submitted.
21. Select the **Final Payment Status**.
22. Select the level of **Client Satisfaction**.
23. Enter any **Client Comments** or feedback.
24. Sign the **Contractor Signature** with full name.
25. Sign the **Client Signature** with full name.

## Field-by-Field Explanation

*   **Handover Date**: Enter the date when the project handover was completed.
*   **Project Name**: Enter the name of the completed project.
*   **Project Address**: Enter the full site address of the project.
*   **Contractor Name**: Enter the name of the general contractor company.
*   **Contractor Contact**: Enter the primary contact person for the project.
*   **Contractor Email**: Enter the email address of the general contractor company.
*   **Contractor Phone**: Enter the phone number of the general contractor company.
*   **Client Name**: Enter the name of the project owner or recipient.
*   **Client Email**: Enter the email address of the client.
*   **Client Phone**: Enter the phone number of the client.
*   **Project Completion Date**: Select the date when the work was finished.
*   **Final Contract Value**: Enter the total project cost.
*   **Punch List Status**: Select the current status of the punch list.
*   **Remaining Punch List Items**: List any outstanding items.
*   **Warranties Provided**: List any warranties and guarantees provided.
*   **Warranty Period**: Select the duration of warranty coverage.
*   **Manuals Provided**: Check if equipment manuals were provided.
*   **Keys and Access Devices**: List keys, remotes, access cards handed over.
*   **Systems Demonstrated**: Select which systems were demonstrated to the client.
*   **Final Inspection Passed**: Check if the final inspection was completed.
*   **Certificate of Occupancy**: Check if the certificate of occupancy has been issued.
*   **Lien Waivers**: Check if lien waivers have been submitted.
*   **Final Payment Status**: Select the status of the final payment.
*   **Client Satisfaction**: Select the level of client satisfaction.
*   **Client Comments**: Enter any client feedback or comments.
*   **Contractor Signature**: Sign with full name as contractor.
*   **Client Signature**: Sign with full name as client.
