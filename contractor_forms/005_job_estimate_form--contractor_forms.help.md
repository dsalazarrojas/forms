# Job Estimate Form - Help Guide
## Purpose
The Job Estimate Form is designed to help users estimate and manage projects by collecting key details such as project name, customer information, project schedule, cost, and personnel involvement.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the project name.
2. Provide the customer name.
3. Enter a brief description of the project.
4. Enter the project start date.
5. Enter the project end date.
6. Estimate the project cost.
7. Specify the number of job hours.
8. Enter the project location.
9. Choose the project status.
10. Select the job manager(s) responsible for the project.

## Field-by-Field Explanation
* **project name**: Enter the name of the project, such as "New Marketing Campaign" or "Software Development Project".
* **customer name**: Enter the name of the customer or client associated with the project.
* **project description**: Briefly describe the project in a few sentences or a short paragraph.
* **project start date**: Enter the date when the project is scheduled to begin.
* **project end date**: Enter the date when the project is expected to be completed.
* **project cost**: Estimate the total cost of the project.
* **job hours**: Enter the estimated number of hours required to complete the project.
* **project location**: Enter the location where the project will take place, such as "Headquarters" or "Remote".
* **project status**: Select the current status of the project, such as "Not Started", "In Progress", or "Completed".
* **job manager**: Select one or more individuals who will be responsible for managing and overseeing the project.
