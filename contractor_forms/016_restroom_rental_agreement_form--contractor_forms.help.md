# Restroom Rental Agreement Form - Help Guide
## Purpose
This form is used to collect information about events or activities that will be held in facilities with restrooms. The form will help the facility manager or event organizer understand the nature of the event, contact details, and other relevant information.

## How To Complete This Form
To complete this form, please follow these steps:

* Fill out the form with the required information for the event or activity.
* Select the correct event type from the options provided.
* Enter the date and start time of the event, if applicable.
* Provide the number of people attending the event.
* Enter the address of the event location.
* Provide the contact person's name and phone number.
* Enter the contact person's email address (if available).
* Add any additional notes about the event or activity.
* Select the approve signature option (if required).

## Field-by-Field Explanation
* **Event Type** (`contract_type`): Select the type of event or activity (Event Type 1, Event Type 2, Event Type 3).
* **Event Date** (`event_date`): Enter the date of the event in the format MM/DD/YYYY.
* **Start Time** (`start_time`): Enter the start time of the event in the 24-hour format (HH:MM).
* **Number of Prostitutes** (`prostitutes`): Enter the expected number of people attending the event.
* **Location** (`location`): Enter the address of the event location.
* **Contact Person** (`contact_name`): Enter the name of the contact person responsible for the event.
* **Phone Number** (`phone`): Enter the phone number of the contact person.
* **Email** (`email`): Enter the email address of the contact person (if available).
* **Notes** (`notes`): Add any additional information about the event or activity.
* **Approve Signature** (`approve_signature`): Select one or more approve signatures from the options provided.

## Tips
* Make sure to fill out the form accurately and completely to ensure that the facility manager or event organizer has the necessary information to prepare for the event.
* If you are unsure about any of the fields, please ask the facility manager or event organizer for clarification.
* This form is a crucial part of the event planning process, and your accuracy and attention to detail are appreciated.
