# Porcelain Slab Agreement Form - Help Guide

## Purpose
The Porcelain Slab Agreement Form is a comprehensive agreement used to document the installation of a porcelain slab by a customer. This form captures essential details about the customer, the installation process, and the agreement's status.

## How To Complete This Form
1. Select the relevant information from the General Information page.
2. Enter the Slab Details and Agreement Details on the respective pages.
3. Sign and date the form accordingly.
4. Enter the Customer's contact information and agreement details on the final page.

## Field-by-Field Explanation

- **General Information** (`1 - John`, `2 - Jane`, `Select One`): Select the relevant information about the customer to proceed with the agreement.
  - This field allows you to choose between two pre-defined options for the customer.
  - Select the correct option to continue with the agreement.

- **Slab Details** (`text`): Enter the details about the slab to be installed.
  - This field is a text box where you can enter the specific details about the slab.

- **Agreement Details** (`1 - I agree to install the porcelain slab on 123 Main Street`, `2 - I disagree to install the porcelain slab on 123 Main Street`, `Select One`): Select the relevant agreement details.
  - This field allows you to choose between two pre-defined options for the agreement details.
  - Select the correct option to proceed with the agreement.

- **Signature** (`text`): Sign the agreement to indicate acceptance.
  - This field is a text box where you can sign your name to indicate acceptance of the agreement.

- **Date Installed** (`date`): Enter the date of installation.
  - This field is a date field where you can select the date of installation.

- **Installation Notes** (`text`): Enter any additional notes about the installation process.
  - This field is a text box where you can enter any additional notes about the installation.

- **Contact Info** (`text`): Enter the contact information of the customer.
  - This field is a text box where you can enter the customer's contact information.

- **Address** (`text`, `Required`): Enter the address of the customer.
  - This field is a text box where you can enter the customer's address.

- **Customer Acceptance Date** (`date`, `Required`): Enter the date of customer acceptance.
  - This field is a date field where you can select the date of customer acceptance.

- **Customer Acceptance Status** (`1 - Accepted`, `2 - Denied`, `Select One`): Select the status of customer acceptance.
  - This field allows you to choose between two pre-defined options for customer acceptance status.
  - Select the correct option to proceed with the agreement.

- **Customer Signature Date** (`date`): Enter the date of customer signature.
  - This field is a date field where you can select the date of customer signature.

- **Customer Signature** (`text`, `Required`): Sign the agreement to indicate acceptance.
  - This field is a text box where you can sign your name to indicate acceptance of the agreement.

- **Installer Name** (`text`, `Required`): Enter the name of the installer.
  - This field is a text box where you can enter the name of the installer.

- **Installer Employee ID** (`text`, `Required`): Enter the employee ID of the installer.
  - This field is a text box where you can enter the employee ID of the installer.

- **Installation Date** (`date`, `Required`): Enter the date of installation.
  - This field is a date field where you can select the date of installation.

- **Installation Time** (`time`): Enter the time of installation.
  - This field is a time field where you can select the time of installation.

- **Customer Name** (`text`, `Required`): Enter the name of the customer.
  - This field is a text box where you can enter the customer's name.

- **Agreement Status** (`1 - Active`, `2 - Inactive`, `Select One`): Select the status of the agreement.
