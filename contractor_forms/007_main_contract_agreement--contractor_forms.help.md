# Main Contract Agreement - Help Guide
## Purpose
This form is used for clients and contractors to agree on the terms and conditions of a project or service provided. It captures essential details such as client and project information, payment terms, contract duration, and contract status.

## How To Complete This Form
1. Review the form carefully and ensure you have all necessary information before starting.
2. Fill out the form with the required and optional details for the client and project.
3. Review the payment terms, contract duration, and contract status.
4. Select the agreement status and termination reasons (if applicable).
5. Sign and date the form as the client and contractor.

## Field-by-Field Explanation
* **Client Details**: <label>Enter the client's name, address, and contact information.</label>
	+ Type: text
	+ Required: Optional
* **Project Details**: <label>Enter the project name, description, and location.</label>
	+ Type: text
	+ Required: Optional
* **Payment Terms**: <label>Enter the payment terms, such as amount, frequency, and method.</label>
	+ Type: text
	+ Required: Optional
* **Contract Duration**: <label>Enter the contract duration in date format (start and end dates).</label>
	+ Type: text
	+ Required: Optional
* **Agreement Status**: <label>Select "Yes" if the contract is active, "No" if it is inactive.</label>
	+ Type: select_one
	+ Required: Optional
	+ Options: Active, Inactive
* **Other Agreement Status**: <label>Select "Yes" if there are other agreement status options not listed.</label>
	+ Type: select_multiple
	+ Required: Optional
	+ Options: Yes, No
* **Termination Details**: <label>Enter the termination details, if applicable.</label>
	+ Type: text
	+ Required: Optional
* **Contract Terms**: <label>Enter the contract terms, such as conditions and obligations.</label>
	+ Type: text
	+ Required: Optional
* **Termination Reasons**: <label>Select "Yes" if termination reasons apply, "No" otherwise.</label>
	+ Type: select_one
	+ Required: Optional
	+ Options: Yes, No
* **Other Termination Reasons**: <label>Select "Yes" if there are other termination reasons not listed.</label>
	+ Type: select_multiple
	+ Required: Optional
	+ Options: Yes, No
* **Client Signature**: <label>Enter the client's signature.</label>
	+ Type: text
	+ Required: Optional
* **Contractor Signature**: <label>Enter the contractor's signature.</label>
	+ Type: text
	+ Required: Optional
* **Client Signature Date**: <label>Enter the date the client signed the contract.</label>
	+ Type: date
	+ Required: Optional
* **Contractor Signature Date**: <label>Enter the date the contractor signed the contract.</label>
	+ Type: date
	+ Required: Optional
* **Contract Start Date**: <label>Enter the start date of the contract.</label>
	+ Type: date
	+ Required: Optional
* **Contract End Date**: <label>Enter the end date of the contract.</label>
	+ Type: date
	+ Required: Optional
* **Contract Status**: <label>Select "Active" or "Inactive" to indicate the contract status.</label>
	+ Type: select_one
	+ Required: Optional
	+ Options: Active, Inactive
