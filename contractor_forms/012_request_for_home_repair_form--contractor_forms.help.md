# Request For Home Repair Form - Help Guide
## Purpose
The Request For Home Repair Form is designed to gather information from customers or users who require home repair services. This form helps the repair team to efficiently process and fulfill requests in a structured and organized manner.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill out the required fields as accurately and thoroughly as possible.
2. Ensure that all fields are filled out with the correct information to avoid duplication and ensure relevance.
3. Review the form for any errors or inaccuracies before submission.

## Field-by-Field Explanation

* **Contact Name** (`contact_name`, `text`, required): This field is for the contact name of the person making the request. Please provide your full name as it appears on your identification.
* **Contact Email** (`contact_email`, `email`, optional): This field is for your contact email address, which will be used for communication purposes. Please ensure that it's a valid email address that you have access to.
* **Contact Phone** (`contact_phone`, `text`, optional): This field is for your contact phone number, which will be used for communication purposes. Please provide a valid phone number that you have access to.
* **Home Address** (`home_address`, `text`, required): This field is for the address of the location where the repair service is required. Please provide a valid address where the repair service will be performed.
* **Service Description** (`service_description`, `text`, optional): This field is for a detailed description of the service required. Please describe the repair service needed in a clear and concise manner.
* **Service Type** (`service_type`, `select_one`, optional): This field is for selecting the type of service required. Please choose "Yes" if you require the service, or "No" if it's not required.
* **Repair Request Date** (`repair_request_date`, `date`, optional): This field is for selecting the date when the repair service is required. Please choose a valid date.
* **Repair Request Time** (`repair_request_time`, `time`, optional): This field is for selecting the time when the repair service is required. Please choose a valid time.
* **Assigned Tool** (`assigned_tool`, `text`, required): This field is for the assigned tool for the repair service. Please provide a valid tool name.
* **Assigned Tool ID** (`assigned_tool_id`, `text`, optional): This field is for the assigned tool ID. Please provide a valid tool ID if required.
* **Request Priority** (`request_priority`, `select_one`, optional): This field is for selecting the priority of the request. Please choose "Yes" for high priority or "No" for low priority.
* **Request Status** (`request_status`, `select_one`, optional): This field is for selecting the status of the request. Please choose "Active" for active requests or "Inactive" for inactive requests.
* **Assigned User** (`assigned_user`, `text`, required): This field is for the assigned user for the repair service. Please provide a valid user name.
* **Assigned User ID** (`assigned_user_id`, `text`, optional): This field is for the assigned user ID. Please provide a valid user ID if required.
* **Service Area** (`service_area`, `text`, optional): This field is for selecting the service area. Please provide a valid service area if required.
* **Work Order Number** (`work_order_number`, `text`, required): This field is for the work order number. Please provide a valid work order number.
* **Request Date** (`request_date`, `date`, optional): This field is for selecting the date when the repair service is required. Please choose a valid date.
* **Request Time** (`request_time`, `time`, optional): This field is for selecting the time when the repair service is required. Please choose a valid time.
* **Notes** (`notes`, `text`, optional): This field is for any additional notes or comments regarding the repair service. Please provide any relevant information.
* **Completed Status** (`completed_status`, `select_one`, optional): This field is for selecting the status of the completed request. Please choose "Active" for active requests or "Inactive" for inactive requests.
* **Completed Date** (`completed_date`, `date`, optional): This field is for selecting the date when the repair service was completed. Please choose a valid date.
* **Completed Time** (`completed_time`, `time`, optional): This field is for selecting the time when the repair service was completed. Please choose a valid time.
* **Request Form ID** (`request_form_id`, `text`, required): This field is for the request form ID. Please provide a valid request form ID.
* **Assigned Tool Name** (`assigned_tool_name`, `text`, required): This field is for the assigned tool name. Please provide a valid tool name.

## Tips
* Please ensure that all required fields are filled out accurately and thoroughly.
* Double-check the form for any errors or inaccuracies before submission.
* If you're unsure about any field or have any questions, please contact the repair service team for clarification.
