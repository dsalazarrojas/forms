# Property Maintenance Request - Help Guide
## Purpose
The Property Maintenance Request form is used to submit, update, or manage maintenance requests for a property. It captures essential information about the maintenance request, including request details, requester information, and status updates.

## How To Complete This Form
To complete this form, follow these steps:

1. Review the form sections and identify the fields that require your input.
2. Fill out the required fields:
	* Is this a new request? (Yes/No)
	* Request Status (Active/Inactive)
3. Fill out the optional fields:
	* Maintenance Request Details
	* Requester Information (if not pre-filled)
	* Requester Email (if not pre-filled)
	* Requester Phone (if not pre-filled)
	* Maintenance Type
	* Requestor Information (if not pre-filled)
	* Requestor Email (if not pre-filled)
	* Requestor Phone (if not pre-filled)
	* Status
	* Status Note
	* Requested By
	* Requested By Email
	* Requested By Phone
	* Status Date
4. Review the form before submitting it to ensure all required fields are filled.

## Field-by-Field Explanation

* **Maintenance Request Details**: Enter a brief description of the maintenance request.
* **Is this a new request?**: Indicate whether this is a new maintenance request or an update to an existing one. If you select 'New', this field will appear on the form. If you select 'Update', you will be able to select the ID of the existing request to update.
* **Request Status**: Select whether the request is active or inactive.
* **Requester Information**: Enter any additional information about the person submitting the request.
* **Requester Email**: Enter the email address of the person submitting the request.
* **Requester Phone**: Enter the phone number of the person submitting the request.
* **Maintenance Type**: Enter the type of maintenance required.
* **Requestor Information**: Enter any additional information about the person performing the maintenance.
* **Requestor Email**: Enter the email address of the person performing the maintenance.
* **Requestor Phone**: Enter the phone number of the person performing the maintenance.
* **Status**: Enter any status updates.
* **Status Note**: Enter any additional status updates.
* **Requested By**: Enter the name of the person requesting the maintenance.
* **Requested By Email**: Enter the email address of the person requesting the maintenance.
* **Requested By Phone**: Enter the phone number of the person requesting the maintenance.
* **Status Date**: Enter the date when the status was last updated.

## Tips

* Please ensure that all required fields are filled.
* If you are updating an existing request, make sure to select the correct request ID.
* If the form is automatically generated with some fields pre-filled, review and update them as necessary.
