# Project Consultant Estimate Form - Help Guide
## Purpose
The Project Consultant Estimate Form is used to gather information from project consultants about the services they offer and the scope of the project. This form provides a clear and concise way for consultants to provide an estimate for a project.

## How To Complete This Form
To complete this form, follow these steps:

1. Review the form and make sure you understand what is being asked.
2. Fill in the required fields with accurate and detailed information about the services you will provide and the scope of the project.
3. Make sure to check the "Required" fields, as these are essential for the project estimate.

## Field-by-Field Explanation
### Consultant Services
* **Consultant Services** (`consultant_services`, `text`, Required: false): This field is for you to describe the services you will provide as a consultant for the project.

### Project Scope
* **Project Scope** (`project_scope`, `text`, Required: false): This field is for you to describe the scope of the project, including any specific tasks or deliverables that you will be responsible for.

### Proposed Costs
* **Proposed Costs** (`proposed_costs`, `number`, Required: false): This field is for you to estimate the costs associated with the services you will provide. Please enter a numerical value for the proposed costs.

## Tips
* Make sure to fill in all the required fields, as these are essential for the project estimate.
* Double-check your information for accuracy before submitting the form.
* If you are unsure about any of the fields, contact the project lead or project manager for clarification.
* This form should only be used for projects where the consultant is providing services and not for internal projects or projects where the consultant is not providing services.
