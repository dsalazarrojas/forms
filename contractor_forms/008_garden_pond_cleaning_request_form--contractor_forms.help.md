# garden_pond_cleaning_request_form - Help Guide
## Purpose
This form is designed for users to submit a request for cleaning of the garden pond. This form is used to provide detailed information about the request, including the category, date, and time of the cleaning. It also captures contact information and status of the request.
## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the form title and description.
2. Select a category for the cleaning request (e.g. Garden Pond, Pond Cleaning, or Other).
3. Enter the date and time of when you would like to schedule the cleaning.
4. Enter your contact email and phone number.
5. Select the status of the request (e.g., Active, Disabled, or Cancelled).
6. Add any additional comments about the cleaning request.
7. Submit the form.

## Field-by-Field Explanation

* **Garden Pond Cleaning Request Form** (`form_title`, `text`, required/optional: false):
	+ Enter a brief title of the cleaning request.
* **Category** (`form_category`, `select_one`, required/optional: false):
	+ Select the category of the cleaning request (e.g., Garden Pond, Pond Cleaning, or Other).
* **Description** (`form_description`, `text`, required/optional: false):
	+ Enter a detailed description of the cleaning request.
* **Date** (`form_date`, `date`, required/optional: false):
	+ Enter the date when you would like to schedule the cleaning.
* **Time** (`form_time`, `time`, required/optional: false):
	+ Enter the time when you would like to schedule the cleaning.
* **Email** (`form_email`, `email`, required/optional: false):
	+ Enter your email address.
* **Phone** (`form_phone`, `text`, required/optional: false):
	+ Enter your phone number.
* **Asssigned Tool** (`form_assigned_tool`, `text`, required/optional: false):
	+ Enter the tool that should be assigned for the cleaning request.
* **Status** (`form_status`, `select_one`, required/optional: false):
	+ Select the status of the request (e.g., Active, Disabled, or Cancelled).
* **Comments** (`form_comments`, `text`, required/optional: false):
	+ Enter any additional comments about the cleaning request.
* **Submit** (`form_submit`, `text`, required/optional: false):
	+ Click the submit button to send the form.
