# Punch List Form - Help Guide
## Purpose
The punch list form is a tool used to document and track tasks and their status in a project.

## How To Complete This Form
To complete the form, follow these steps:

1. Select the relevant tasks from the list provided under "Tasks".
2. Choose the correct due date for the selected tasks.
3. Indicate the completion status of each task by selecting "True" if completed, "False" if not completed, or "Pending" if the status is not yet determined.
4. Assign each task to a team member by selecting their name from the list under "Assigned To".
5. Add any additional notes or comments regarding the task under "Notes".

## Field-by-Field Explanation
* **Tasks** (`Tasks`, `select_multiple`, required: false): Select the tasks you want to document and track. This field allows you to choose multiple tasks from the provided list.
* **Due Date** (`Due Date`, `date`, required: false): Enter the due date for the selected tasks. This field is used to track the deadline for each task.
* **Completed** (`Completed`, `select_one`, required: false): Indicate the completion status of each task by selecting "True" if completed, "False" if not completed, or "Pending" if the status is not yet determined.
* **Assigned To** (`Assigned To`, `select_one`, required: false): Assign each task to a team member by selecting their name from the list. This field helps in tracking task responsibilities.
* **Notes** (`Notes`, `note`, required: false): Add any additional comments or notes about the task under this field. This can be used to gather more information or provide context about each task.
