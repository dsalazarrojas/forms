# Moving Items Information Form - Help Guide
## Purpose
The Moving Items Information Form is designed to collect detailed information about items being moved, including their name, weight, size, description, value, and other relevant details.

## How To Complete This Form
1. Fill out the form with the required information about the item(s) being moved.
2. Complete each field with accurate and relevant details.
3. Review the form for completeness and correctness before submitting.

## Field-by-Field Explanation

* **Moving Information** (Text): Enter a brief description of the moving process, including the item(s) involved.
* **Item Name** (Text): Enter the name of the item being moved.
* **Item Weight** (Number): Enter the weight of the item being moved.
* **Item Size** (Select One):
	+ 'Yes': Indicates the item is large and requires special handling.
	+ 'No': Indicates the item is standard size.
* **Item Description** (Text): Enter a detailed description of the item being moved.
* **Item Value** (Number): Enter the value of the item being moved.
* **Item Condition** (Select Multiple):
	+ 'Yes': Indicates the item is in good condition.
	+ 'No': Indicates the item is damaged or in poor condition.
* **Item Serial Number** (Text): Enter the serial number of the item (if applicable).
* **Item Type** (Select One):
	+ 'Yes': Indicates the item is a high-value or priority item.
	+ 'No': Indicates the item is standard or low-priority.
* **Date Purchased** (Date): Enter the date the item was purchased.
* **Warranty Start** (Date): Enter the start date of the item's warranty.
* **Warranty End** (Date): Enter the end date of the item's warranty.
* **Warranty Status** (Select One):
	+ 'Active': Indicates the item is still under warranty.
	+ 'Inactive': Indicates the item is no longer under warranty.
* **Item Status** (Select One):
	+ 'Active': Indicates the item is available for use.
	+ 'Inactive': Indicates the item is not available for use.
* **Item Notes** (Text): Enter any additional notes or comments about the item.
* **Item Location** (Text): Enter the location where the item is currently located.
* **Item Image** (Text): Enter a URL or description of the item's image (if applicable).
* **Item Price** (Number): Enter the price of the item being moved.
* **Item Serial Number 2** (Text): Enter the serial number of the second item (if applicable).
* **Item Weight 2** (Number): Enter the weight of the second item being moved.
* **Item Size 2** (Number): Enter the size of the second item being moved.
* **Item Description 2** (Text): Enter a detailed description of the second item being moved.
* **Item Value 2** (Number): Enter the value of the second item being moved.
* **Item Warranty Start 2** (Date): Enter the start date of the second item's warranty.
* **Item Status 2** (Select One):
	+ 'Active': Indicates the second item is available for use.
	+ 'Inactive': Indicates the second item is not available for use.

## Tips
* Be thorough and accurate when filling out each field.
* Review the form for completeness before submission.
* Ensure that duplicate information is not entered, and that each field is filled out with the most up-to-date information.
