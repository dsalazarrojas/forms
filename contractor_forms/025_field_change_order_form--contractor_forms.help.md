# Field Change Order Form - Help Guide
## Purpose
The Field Change Order Form is used to document and manage changes made to fields in a project. Project managers can use this form to track and update the status of field changes, including the reasons for the change, the date the change was requested, and the current status of the change.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the **Client Info** field with the name and contact information of the person submitting the change request.
2. Enter the **Project Id** number, if applicable.
3. Provide a **Description** of the change being requested.
4. Specify the **Reason** for the change.
5. Enter the **Request Date** when the change was first requested.
6. Enter the **Order Number**, if applicable.
7. Enter the **Order Date**, if applicable.
8. Provide information about the **Contractor Info**, if applicable.
9. Select the **Change Status** of the change (Completed, Pending, In Progress, or Cancelled).
10. Select the **Priority** of the change (High, Medium, Low, or Normal).

## Field-by-Field Explanation

* **Client Info (Client Info)**: Enter the name and contact information of the person submitting the change request.
* **Project Id (Project Id)**: Enter the project ID number, if applicable.
* **Description (Description)**: Provide a brief description of the change being requested.
* **Reason (Reason)**: Specify the reason for the change.
* **Request Date (Request Date)**: Enter the date when the change was first requested.
* **Order Number (Order Number)**: Enter the order number, if applicable.
* **Order Date (Order Date)**: Enter the order date, if applicable.
* **Contractor Info (Contractor Info)**: Provide information about the contractor making the change.
* **Change Status (Change Status)**: Select the current status of the change (Completed, Pending, In Progress, or Cancelled).
* **Priority (Priority)**: Select the priority of the change (High, Medium, Low, or Normal).
* **Comments (Comments)**: Enter any additional comments about the change.

## Tips

* Make sure to enter accurate information about the client and project.
* Keep the description of the change clear and concise.
* Choose the correct change status and priority for the change.
* If the change is cancelled, make sure to select "Cancelled" as the change status.
