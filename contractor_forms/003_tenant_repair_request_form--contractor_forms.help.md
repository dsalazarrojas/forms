# Tenant Repair Request Form - Help Guide
## Purpose
The Tenant Repair Request Form is a tool for tenants to report any maintenance issues in their rented properties. This form helps landlords and property managers to identify and address these issues promptly.

## How To Complete This Form
To complete this form, follow these steps:

1.  Fill out the form completely, providing all required information.
2.  Ensure that only one request per tenant is submitted.
3.  Be as descriptive as possible when filling out the issue description field.

## Field-by-Field Explanation

* **Form Section 1** (`form_section_1`, note, required: false): This is a note field for any introductory information or context about the repair request.
* **Tenant Info** (`tenant_info`, number, required: false): Enter your name and/or property address to help us identify your account.
* **Issue Description** (`issue_description`, text, required: false): Describe the issue in detail, including the location and nature of the problem.
* **Issue Type** (`issue_type`, select_one, required: false): Select the type of issue you are experiencing (e.g., Leaky faucet, Broken light, Clogged drain, etc.).
* **Issue Priority** (`issue_priority`, select_multiple, required: false): Indicate the urgency of the issue by selecting High, Medium, or Low.
* **Requested By** (`requested_by`, select_one, required: false): Choose who submitted this request (Landlord, Property Manager, or Other).
* **Contact Information** (`contact_information`, note, required: false): This is an optional field for you to provide your contact information (first and last name, email, phone number, and address).
* **Date Submitted** (`date_submitted`, date, required: false): Enter the date you submitted this request.
* **Date Completed** (`date_completed`, date, required: false): If applicable, enter the date the repair was completed.
* **Comments** (`comments`, note, required: false): Provide any additional comments or information about the issue.

## Tips

* Be thorough in your description of the issue to help us understand the problem better.
* If you have already submitted a request for the same issue, please do not submit another one.
* This form is for maintenance requests only; for rent payment or other non-maintenance issues, please contact your property manager directly.
