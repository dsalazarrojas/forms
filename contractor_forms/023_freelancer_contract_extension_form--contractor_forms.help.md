# Freelancer Contract Extension Form - Help Guide
## Purpose
The Freelancer Contract Extension Form is used to extend the contract for a freelancer. This form is intended to be completed by both the client and the freelancer to update the contract start and end dates.

## How To Complete This Form
To complete this form, follow these steps:

1. Ensure that you have the necessary information and approvals to complete the form.
2. Fill in the fields as prompted:
	* **Contract ID**: Enter the ID of the contract you wish to extend.
	* **New Start Date**: Enter the new start date for the contract extension.
	* **New End Date**: Enter the new end date for the contract extension.
	* **Reason for Extension**: Provide a brief explanation for the contract extension.
	* **Client Comments**: Enter any additional comments or notes from the client.
	* **Freelancer Comments**: Enter any additional comments or notes from the freelancer.
3. Click the "Submit" button to complete the form.

## Field-by-Field Explanation
### Contract ID
* **Contract ID** (`contract_id`, `number`, required/optional: false): This field is used to enter the ID of the contract you wish to extend. Please enter the contract ID as a number.

### New Start Date
* **New Start Date** (`new_start_date`, `date`, required/optional: false): This field is used to select the new start date for the contract extension. Select a date that is after the current contract end date.

### New End Date
* **New End Date** (`new_end_date`, `date`, required/optional: false): This field is used to select the new end date for the contract extension. Select a date that is after the new start date.

### Reason for Extension
* **Reason for Extension** (`reason_for_extension`, `text`, required/optional: false): This field is used to provide a brief explanation for the contract extension. Please enter a clear and concise explanation for the contract extension.

### Client Comments
* **Client Comments** (`client_comments`, `text`, required/optional: false): This field is used for the client to enter any additional comments or notes about the contract extension.

### Freelancer Comments
* **Freelancer Comments** (`freelancer_comments`, `text`, required/optional: false): This field is used for the freelancer to enter any additional comments or notes about the contract extension.

### Client Signature
* **Client Signature** (`client_signature`, `text`, required/optional: false): This field is used for the client to digitally sign the contract extension. Please enter your name as a digital signature.
