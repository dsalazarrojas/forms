# Rotary Membership Form - Help Guide
## Purpose
The Rotary Membership Form is designed to collect information from individuals interested in joining the Rotary Club. It helps the club administrators understand the candidate's preferences and interests, ensuring a more informed decision-making process.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter your name in the "Name" field.
2. Provide your email address in the "Email" field.
3. Enter your phone number in the "Phone" field.
4. Select a date of interest in the "Date" field.
5. Answer the "Membership Type" question with "Yes" or "No".
6. If you answered "Yes", select the membership plan(s) that interest you from the "Membership Plan" field.
7. Read and understand the terms of your chosen membership plan in the "Membership Plan Terms" field.
8. Describe your desired membership plan in the "Membership Plan Description" field.
9. Select the start and end dates for your desired membership plan.

## Field-by-Field Explanation
### User Input 1 - Name
* **Name** (text, required): Enter your full name as it appears on your identification.

### User Input 2 - Email
* **Email** (email, required): Provide a valid email address for communication purposes.

### User Input 3 - Phone
* **Phone** (text, required): Enter your phone number for contact and communication.

### User Input 4 - Date
* **Date** (date, optional): Select the date you are interested in joining the Rotary Club or a specific date for your membership plan.

### User Input 5 - Membership Type
* **Membership Type** (select_one, optional): Answer with "Yes" if you are interested in becoming a member of the Rotary Club.

### User Input 6 - Membership Plan
* **Membership Plan** (select_multiple, optional): If you answered "Yes" to membership, select the plan(s) that interest you. 

### User Input 7 - Membership Plan Terms
* **Membership Plan Terms** (note, optional): Read and understand the terms of your chosen membership plan.

### User Input 8 - Membership Plan Description
* **Membership Plan Description** (note, optional): Describe your desired membership plan in a few sentences.

### User Input 9 - Membership Plan Start Date
* **Membership Plan Start Date** (date, optional): Select the start date for your desired membership plan.

### User Input 10 - Membership Plan End Date
* **Membership Plan End Date** (date, optional): Select the end date for your desired membership plan.

### User Input 11 - Submit
* **Submit** (text, required): Review and submit your membership application.
