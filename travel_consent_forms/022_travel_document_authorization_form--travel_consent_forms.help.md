# Travel Document Authorization Form - Help Guide
## Purpose
The purpose of this form is to authorize parent/guardian permission for a child to travel, providing a clear and concise document that outlines the child's travel details and ensures their safety while abroad. This form ensures that all relevant information is collected to provide a comprehensive overview of the child's travel plans, including their travel dates, destination, and type of travel document.

## How To Complete This Form
To complete this form, please follow these steps:
1. Fill out the form completely and accurately to provide all required information.
2. Select the relevant options for each field.
3. Ensure that all required fields are completed before submitting the form.

## Field-by-Field Explanation

* **Parent Information (#1)**: This section collects the parent/guardian's basic details such as their identification number.
* **Parent Permission to Travel (#2)**: Please select either "Yes" or "No" to indicate whether the child is allowed to travel. If "Yes", provide further information in the following fields.
* **Travel Document Type (#3)**: Choose the type of travel document the child will be using for travel (e.g. Travel Passport, State ID, Visa).
* **Travel Document Number (#4)**: Enter the specific number or ID number of the travel document selected in the previous field.
* **Travel Start Date (#5)**: Enter the start date of the child's travel in the format MM/DD/YY.
* **Travel End Date (#6)**: Enter the end date of the child's travel in the format MM/DD/YY.
* **Travel Destination (#7)**: Enter the country/ city/region the child will be traveling to.
* **Travel Arrangements (#8)**: Enter any additional travel information such as travel companions, flight information, etc.
