# Agent Credentials Verification Form - Help Guide
## Purpose

The Agent Credentials Verification Form is a critical document used by insurance companies to verify the credentials of insurance agents. This form collects essential information about the agent's identification, education, and work history, ensuring that their credentials are accurate and up-to-date.

## How To Complete This Form

1.  To begin, ensure you have all necessary documents and information ready.
2.  Fill in the required fields accurately and completely.
3.  Review each section for completeness and accuracy before moving to the next.
4.  If you are unsure about any field, refer to the field-by-field explanation below.

## Field-by-Field Explanation

*   **Agent Full Name** (`agent_full_name`, text, required): Enter the full legal name of the insurance agent.
*   **Agent ID Number** (`agent_id_number`, text, required): Enter the unique identifier assigned to the agent.
*   **Agent Email** (`agent_email`, email, required): Enter the agent's official email address.
*   **Agent Phone** (`agent_phone`, text, required): Enter the agent's phone number.
*   **Agent Address** (`agent_address`, text, required): Enter the agent's business address.
*   **Insurance License Number** (`insurance_license_number`, text, required): Enter the agent's insurance license number.
*   **License Issue Date** (`license_issue_date`, date, required): Enter the date when the license was issued.
*   **License Expiry Date** (`license_expiry_date`, date, required): Enter the date when the license expires.
*   **Licensing State/Jurisdiction** (`licensing_state_jurisdiction`, text, required): Enter the state or jurisdiction that issued the license.
*   **Highest Education Level** (`highest_education_level`, select_one, required): Select the agent's highest level of education from the provided options.
*   **Degree Field** (`degree_field`, text, optional): Enter the field of study if applicable.
*   **Professional Certifications** (`professional_certifications`, text, optional): List any professional certifications held by the agent.
*   **Continuing Education Credits** (`continuing_education_credits`, number, optional): Enter the number of continuing education credits completed.
*   **Current Employer** (`current_employer`, text, required): Enter the name of the agent's current employer.
*   **Employment Start Date** (`employment_start_date`, date, required): Enter the date when the agent started with the current employer.
*   **Previous Employers** (`previous_employers`, text, optional): List previous employers in the insurance industry.
*   **Credentials Verification Status** (`credentials_verification_status`, select_one, required): Select the current status of credential verification from the provided options.
*   **Verification Officer Name** (`verification_officer_name`, text, optional): Enter the name of the officer conducting the verification.
*   **Verification Date** (`verification_date`, date, optional): Enter the date when verification was completed.
*   **Additional Notes** (`additional_notes`, text, optional): Add any additional notes about the credential verification.

Please review each field carefully to ensure accuracy and completeness. If you are unsure about any field, refer to this guide or contact the relevant authorities for clarification.
