# Business Insurance Account Review Form - Help Guide
## Purpose
This form is used to review and analyze the current status of a business insurance account. It helps insurance agents to gather necessary information about the account's risk profile, coverage, and any potential issues that require attention.

## How To Complete This Form
1. Ensure you have all the necessary information and documents related to the account before starting the review.
2. Complete each field accurately and thoroughly, as your input will be used to inform decisions about the account's insurance coverage.
3. Select the correct options for each field based on the account's specific details.
4. Be sure to note any suggested adjustments or issues that require follow-up.

## Field-by-Field Explanation

* **Client name (<name>, <type>, required/optional)**:
	+ This field is used to collect the client's name.
	+ Please enter the exact spelling and format as it appears on the business's paperwork or documents.
* **Policy number (<name>, <type>, required/optional)**:
	+ This field is used to collect the account's policy number.
	+ Enter the current policy identifier, if available.
* **Coverage types (<name>, <type>, required/optional)**:
	+ Select all the types of coverage that apply to the account.
	+ Liability, Property, Business interruption, and Workers compensation are the available options.
* **Premium amount (<name>, <type>, required/optional)**:
	+ This field is used to collect the current annual premium.
	+ Enter the exact amount as it appears on the account's paperwork or billing statements.
* **Last claim date (<name>, <type>, required/optional)**:
	+ If there have been any claims, enter the date of the most recent one.
	+ Use the format MM/DD/YYYY.
* **Changes to risk profile (<name>, <type>, required/optional)**:
	+ Indicate if there have been any material changes to the account's risk profile since the last review.
	+ Select "True" if there have been changes, "False" otherwise.
* **Suggested adjustments (<name>, <type>, required/optional)**:
	+ Provide any recommended changes to the account's coverage or limits.
	+ Enter a clear and concise description of the suggested adjustments.
* **Follow up required (<name>, <type>, required/optional)**:
	+ Determine if an agent needs to follow up with the account for next steps.
	+ Select "True" if follow-up is required, "False" otherwise.
* **Agent notes (<name>, <type>, required/optional)**:
	+ Enter any internal notes about the account for the account manager's reference.
	+ Keep this field concise and focused on the agent's thoughts and observations.

## Tips
* Always review the account's paperwork and documents before completing this form.
* Double-check the accuracy of your input to ensure it matches the account's actual status.
* If you're unsure about any field or question, consult with your supervisor or colleague.
* Remember to review this form regularly to ensure the account's coverage and limits are up-to-date and adequate.
