# Last Will And Testament Questionnaire - Help Guide
## Purpose
This form is designed to collect the necessary information for a comprehensive Last Will And Testament, ensuring that the deceased's wishes are respected and their loved ones are taken care of.

## How To Complete This Form
To complete this form, please follow these steps:

1. Start by filling out the Relatives To Notify field with the names and contact information of the relatives that need to be notified after the person's passing.
2. Select the Executor Details field to choose who will be responsible for carrying out the deceased's wishes after their passing.
3. In the Estate Description field, describe the deceased's estate, including any properties, assets, and debts.
4. In the Beneficiaries field, select the primary and co-beneficiaries of the estate.
5. Enter the values of the properties mentioned in the estate description in the Property Values field.
6. List any other assets that are not mentioned in the estate description in the Other Assets field.
7. Select which properties are part of the estate in the Real Estate field.
8. List any debts that need to be settled after the person's passing in the Debts field.
9. Select which financial institutions are part of the estate in the Financial Institutions field.
10. List which vehicles are part of the estate in the Vehicles field.
11. List which pets are part of the estate in the Pets field.
12. Estimate the funeral expenses in the Funeral Expenses field.
13. Estimate the probate fees in the Probate Fees field.
14. List any other expenses related to the estate in the Other Expenses field.
15. Provide a description of the assets in the Assets Description field.
16. Enter any important information or instructions for the executor in the Executor Notes field.

## Field-by-Field Explanation
* **Relatives To Notify** (`relatives_to_notify`, text, required/optional): Please list the names and contact information of the relatives that need to be notified after the person's passing.
* **Executor Details** (`executor_details`, select_one, required/optional): Select who will be responsible for carrying out the deceased's wishes after their passing.
* **Estate Description** (`estate_description`, text, required/optional): Describe the deceased's estate, including any properties, assets, and debts.
* **Beneficiaries** (`beneficiaries`, select_multiple, required/optional): Select the primary and co-beneficiaries of the estate.
* **Property Values** (`property_values`, number, required/optional): Enter the values of the properties mentioned in the estate description.
* **Other Assets** (`other_assets`, text, required/optional): List any other assets that are not mentioned in the estate description.
* **Real Estate** (`real_estate`, select_multiple, required/optional): Select which properties are part of the estate.
* **Debts** (`debts`, select_multiple, required/optional): List any debts that need to be settled after the person's passing.
* **Financial Institutions** (`financial_institutions`, select_multiple, required/optional): Select which financial institutions are part of the estate.
* **Vehicles** (`vehicles`, select_multiple, required/optional): List which vehicles are part of the estate.
* **Pets** (`pets`, select_multiple, required/optional): List which pets are part of the estate.
* **Funeral Expenses** (`funeral_expenses`, number, required/optional): Estimate the expenses related to the funeral.
* **Probate Fees** (`probate_fees`, number, required/optional): Estimate the fees associated with probate.
* **Other Expenses** (`other_expenses`, text, required/optional): List any other expenses related to the estate.
* **Assets Description** (`assets_description`, text, required/optional): Provide a description of the assets.
* **Executor Notes** (`executor_notes`, text, required/optional): Enter any important information or instructions for the executor.
