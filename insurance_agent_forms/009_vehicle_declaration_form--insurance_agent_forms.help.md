# vehicle-declaration-form - Help Guide
## Purpose
This form is intended to collect vital information about a vehicle's usage and insurance details for insurance purposes.

## How To Complete This Form
1. Start by filling out the vehicle usage section:
	* Vehicle Usage: Provide a description of the vehicle's usage (e.g., private car, commercial vehicle, etc.).
2. Move on to the vehicle details:
	* Vehicle Make: Enter the make of the vehicle (e.g., Toyota, Ford, etc.).
	* Vehicle Model: Enter the model of the vehicle (e.g., Corolla, F-150, etc.).
	* Vehicle Year: Enter the year the vehicle was manufactured.
	* Vehicle Registration: Enter the vehicle registration number or license plate number.
3. Complete the driver and owner information:
	* Driver License: Enter the driver's license number (if applicable).
	* Driver Name: Enter the driver's name (if applicable).
	* Vehicle Owner: Enter the vehicle's owner name and contact information.
4. Fill out the usage and insurance details:
	* Vehicle Usage Date: Enter the date the vehicle was last used.
	* Vehicle Usage Time: Enter the time the vehicle was last used (if applicable).
	* Vehicle Usage Duration: Describe the duration of the vehicle usage (e.g., hour, day, etc.).
	* Vehicle Usage Start Date: Enter the date the vehicle usage started.
	* Vehicle Usage End Date: Enter the date the vehicle usage ended (if applicable).
5. Insurance information:
	* Vehicle Insurance: Select the insurance company providing coverage (e.g., Insurance Company A, B, etc.).
	* Vehicle Insurance Start Date: Enter the start date of the insurance policy.
	* Vehicle Insurance End Date: Enter the end date of the insurance policy (if applicable).
	* Vehicle Insurance Status: Select the status of the insurance policy (Active or Inactive).
	* Vehicle Insurance Type: Select the type of insurance coverage (e.g., Full Coverage, Liability Coverage, etc.).
6. Finally, provide any additional vehicle usage remarks.

## Field-by-Field Explanation
- **Vehicle Usage** (1, text, required): A description of the vehicle's usage (e.g., private car, commercial vehicle, etc.).
- **Vehicle Make** (2, text, required): The make of the vehicle (e.g., Toyota, Ford, etc.).
- **Vehicle Model** (3, text, required): The model of the vehicle (e.g., Corolla, F-150, etc.).
- **Vehicle Year** (4, number, required): The year the vehicle was manufactured.
- **Vehicle Registration** (5, text, required): The vehicle registration number or license plate number.
- **Driver License** (6, text, required): The driver's license number (if applicable).
- **Driver Name** (7, text, required): The driver's name (if applicable).
- **Vehicle Owner** (8, text, required): The vehicle's owner name and contact information.
- **Vehicle Usage Date** (9, date, required): The date the vehicle was last used.
- **Vehicle Usage Time** (10, time, required): The time the vehicle was last used (if applicable).
- **Vehicle Usage Duration** (11, text, required): A description of the duration of vehicle usage (e.g., hour, day, etc.).
- **Vehicle Usage Start Date** (12, date, required): The date the vehicle usage started.
- **Vehicle Usage End Date** (13, date, required): The date the vehicle usage ended (if applicable).
- **Vehicle Insurance** (14, select_one, required): The insurance company providing coverage (e.g., Insurance Company A, B, etc.).
- **Vehicle Insurance Start Date** (15, date, required): The start date of the insurance policy.
- **Vehicle Insurance End Date** (16, date, required): The end date of the insurance policy (if applicable).
- **Vehicle Insurance Status** (17, select_one, required): The status of the insurance policy (Active or Inactive).
- **Vehicle Insurance Type** (18, select_one, required): The type of insurance coverage (e.g., Full Coverage, Liability Coverage, etc.).
- **Vehicle Owner Contact** (19, text, required): The vehicle's owner name and contact information.
- **Vehicle Usage Remark** (20, note, required): Any additional vehicle usage remarks.
- **Vehicle License Status** (21, select_one, required): The status of the vehicle's license (Valid or Invalid).
- **Vehicle Insurance Company** (22, select_one, required): The insurance company providing coverage.
- **Vehicle Insurance Agency** (23, select_one, required): The insurance agency providing coverage.
- **Vehicle Insurance Coverage** (24, select_one, required): The type of insurance coverage (e.g., Full, Partial, etc.).
- **Vehicle Insurance Renewal** (25, select_one, required): Whether the insurance policy is renewable (True or False).
