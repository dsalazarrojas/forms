# Progress Monitoring Form - Help Guide
## Purpose
The Progress Monitoring Form is used to track and update the status of projects, helping project administrators and team members get insights into project progress and make informed decisions.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter a brief description of the project in the "Project info" field.
2. Provide a detailed description of the project in the "Project description" field.
3. Select the current status of the project in the "Current status" field.
4. Enter the progress percentage in the "Progress percent" field.
5. Enter the due date in the "Due date" field.
6. Record the last update in the "Last update" field.
7. Enter any additional notes about the project in the "Notes" field.
8. Enter the email address of the project owner or administrator in the "Email" field.
9. Enter the phone number of the project owner or administrator in the "Phone" field.
10. Select the person assigned to the project in the "Assigned to" field.
11. Enter the start date of the project in the "Project start date" field.

## Field-by-Field Explanation
* **Project info** (`project_info`, text, optional): A brief description of the project.
* **Project description** (`project_description`, text, optional): A detailed description of the project.
* **Current status** (`current_status`, select_one, optional): The current status of the project.
	+ Not started
	+ In progress
	+ Done
* **Progress percent** (`progress_percent`, number, optional): The progress percentage of the project.
* **Due date** (`due_date`, date, optional): The due date of the project.
* **Last update** (`last_update`, date, optional): The last update date of the project.
* **Notes** (`notes`, note, optional): Additional notes about the project.
* **Email** (`email`, email, optional): The email address of the project owner or administrator.
* **Phone** (`phone`, text, optional): The phone number of the project owner or administrator.
* **Assigned to** (`assigned_to`, select_one, optional): The person assigned to the project.
	+ John Doe
	+ Jane Doe
	+ Jim Johnson
* **Project start date** (`project_start_date`, date, optional): The start date of the project.
