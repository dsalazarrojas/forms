# Remote Boiler Monitoring Log Form - Help Guide
## Purpose
The Remote Boiler Monitoring Log Form is used to track and monitor the status and performance of remote boilers. It captures essential details about each boiler, including location, status, and maintenance history. This form helps maintenance teams and facility managers to efficiently record and analyze data for effective boiler operation and maintenance.

## How To Complete This Form
To fill out the Remote Boiler Monitoring Log Form, follow these steps:

1. Select the correct **Boiler** and **Location** from the dropdown menus.
2. Enter the **Start Date** and **Start Time** when the monitoring session begins.
3. Enter the **End Date** and **End Time** when the monitoring session ends.
4. Set the **Check Interval** to schedule regular checks for the boiler.
5. Provide any additional **Comments** about the monitoring session or issues encountered.
6. Enter the **Form Assigned** date and time if applicable.
7. Select the **Form Version** if a version is available.
8. Enter the **Assigned To** if the form is assigned to someone.
9. Enter the **Location Name**, **Boiler Name**, **Location Code**, **Building Code**, and **Unit Number** for the boiler's details.
10. Set the **Status** and **Active Status** to indicate the current status of the boiler.
11. Enter the **Active Status Notes** and **Active Status Reason** to provide further details about the active status.

## Field-by-Field Explanation

* **Boiler**: Select the correct boiler from the dropdown menu.
* **Location**: Select the correct location from the dropdown menu.
* **Start Date**: Enter the start date of the monitoring session.
* **Start Time**: Enter the start time of the monitoring session.
* **End Date**: Enter the end date of the monitoring session.
* **End Time**: Enter the end time of the monitoring session.
* **Check Interval**: Set the schedule for regular checks on the boiler.
* **Comments**: Provide additional comments about the monitoring session.
* **Form Assigned**: Enter the date and time the form was assigned, if applicable.
* **Form Version**: Select the version of the form if available.
* **Assigned To**: Enter the name or ID of the person assigned to the form, if applicable.
* **Location Name**: Enter the name of the location where the boiler is situated.
* **Boiler Name**: Enter the name of the boiler.
* **Location Code**: Enter the location code for the boiler's location.
* **Building Code**: Enter the building code for the boiler's location.
* **Unit Number**: Enter the unit number for the boiler's location.
* **Status**: Set the current status of the boiler.
* **Active Status**: Set the active status of the boiler.
* **Active Status Notes**: Provide additional notes about the active status.
* **Active Status Reason**: Enter the reason for the active status.
