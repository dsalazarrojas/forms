# remote_workforce_monitoring_dashboard_request - Help Guide
## Purpose
This form is used to create a new request for a remote workforce monitoring dashboard. It is meant to collect essential details about the dashboard, such as its category, description, assigned tool, and output file, to ensure that the request is properly fulfilled.

## How To Complete This Form
To complete this form, please follow the instructions below:

1. Enter a title for your remote workforce monitoring dashboard request.
2. Select the category that best describes your request (e.g., Monitoring Forms, Request Forms).
3. Describe your request in as much detail as possible.
4. Choose the tool that will be used to fulfill this request (e.g., chatjimmy, other).
5. Enter the IDs of the forms related to this request.
6. Specify the output file for this request.
7. Add any additional description or comments about your request.

## Field-by-Field Explanation
* **What is the name of your remote workforce monitoring dashboard request?** (`form_title`, text, required): This field allows you to enter a title for your dashboard request.
* **What is the category of your request?** (`category`, select_one, required): This field helps us understand the type of request you are making. Please select one of the provided options (Monitoring Forms, Request Forms).
* **Describe your request in as much detail as possible.** (`description`, text, required): This field is where you can provide a detailed description of your dashboard request.
* **Which tool will be used to fulfill this request?** (`assigned_tool`, select_one, required): Please select the tool that will be used to create your dashboard (e.g., chatjimmy, other).
* **Enter the IDs of the forms related to this request.** (`form_ids`, text, required): Enter the IDs of the forms that this request is associated with.
* **What is the output file for this request?** (`output_file`, text, required): Enter the output file for this dashboard request.
* **Additional description.** (`description_2`, text, optional): This field allows you to add any additional information or comments about your request.
