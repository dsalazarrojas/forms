# incident_response_monitoring_form - Help Guide
## Purpose
This form is designed to collect and monitor information about incidents in a timely and effective manner.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the required fields with accurate and relevant information about the incident.
2. Ensure that all required fields are completed before submitting the form.

## Field-by-Field Explanation

* **Summary** (incident_summary): A brief summary of the incident.
* **Summary** (incident_summary_text): Enter a detailed description of the incident.
* **Category** (incident_category): The category of the incident (e.g., security, technical, etc.).
* **Category** (incident_category_value): The value of the category (e.g., phishing, bug, etc.).
* **Category Type** (incident_category_type): The type of category (e.g., high, medium, low, etc.).
* **Category Type Value** (incident_category_type_value): The value of the category type (e.g., high, critical, etc.).
* **Severity** (incident_severity): The severity of the incident (e.g., critical, high, medium, low, etc.).
* **Severity Value** (incident_severity_value): The value of the severity (e.g., critical, high, etc.).
* **Response Plan** (incident_response_plan): The response plan for the incident.
* **Response Plan Text** (incident_response_plan_text): Enter a detailed description of the response plan.
* **Status** (incident_status): The status of the incident (e.g., active, pending, resolved, etc.).
* **Status** (incident_status_value): The value of the status (e.g., pending, active, resolved, etc.).
* **Status Text** (incident_status_text): Enter a detailed description of the status.
* **Status Date** (incident_status_date): The date of the last update of the incident status.
* **Status Date Time** (incident_status_date_time): The time of the last update of the incident status.
* **Response Time** (incident_response_time): The time of the response to the incident.
* **Response Time Unit** (incident_response_time_unit): The unit of the response time (e.g., minutes, hours, etc.).
* **Response Time Value** (incident_response_time_value): The value of the response time.
* **Last Updated** (incident_last_updated): The last updated time of the incident.
* **Next Update** (incident_next_update): The next update time of the incident.
* **Note** (incident_note): Additional comments or notes about the incident.
