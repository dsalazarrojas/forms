# Security Surveillance Review Request - Help Guide
## Purpose
The "Security Surveillance Review Request" form is used to request video review and incident documentation. Fill out the form accurately and thoroughly to ensure the correct information reaches the review board.

## How To Complete This Form
To complete the form, follow these steps:

1.  Select the relevant options for each field as instructed below.
2.  Fill in the required fields and add any additional comments or explanations where necessary.
3.  Review your submission before submitting it for review.

## Field-by-Field Explanation

*   **Incident Details** (incident_details): Describe the incident you are requesting review for. This should include the date and time of the incident, if known.
*   **Supporting Files** (supporting_files): If you have any relevant documentation or evidence related to the incident, select "Yes" here.
*   **Request Video Review** (request_video_review): Choose whether you would like to request video review for the incident. Select "Yes" if you want the reviewer to watch the video footage.
*   **Video Location** (video_location): If the video is available, provide the location of the video.
*   **Review Requestor** (review_requestor): Select "Yes" if you are the requestor of the review.
*   **Reviewer** (reviewer): Select "Yes" if you are the reviewer assigned to this incident.
*   **Review Requestor Note** (review_requestor_note): Add any additional comments or explanations from the requestor.
*   **Reviewer Note** (reviewer_note): Add any additional comments or explanations from the reviewer.
*   **Incident Date** (incident_date): Enter the date of the incident if known.
*   **Incident Time** (incident_time): Enter the time of the incident if known.
*   **Security Teams** (security_teams): List the security teams involved in the incident. Select "Yes" if any team is involved.
*   **Facilities** (facilities): If the incident occurred in a facility, select "Yes" here.
*   **Offices** (offices): If the incident occurred in an office, select "Yes" here.
*   **Campuses** (campuses): If the incident occurred on a campus, select "Yes" here.
*   **Facilities Note** (facilities_note): Add any additional comments or explanations about the facilities involved.
*   **Offices Note** (offices_note): Add any additional comments or explanations about the offices involved.
*   **Campuses Note** (campuses_note): Add any additional comments or explanations about the campuses involved.
*   **Incident Status** (incident_status): Select the status of the incident as "Active" or "Inactive".
*   **Incident Category** (incident_category): Select the category of the incident.
*   **Incident Subcategory** (incident_subcategory): Select the subcategory of the incident.
*   **Security Teams** (security_teams): List the security teams involved in the incident. Select "Yes" if any team is involved.
*   **Facilities Note** (facilities_note), **Offices Note** (offices_note), and **Campuses Note** (campuses_note) provide space for any additional comments or explanations related to the incident location and its impact on facilities and offices.

Please fill the form accurately and thoroughly, and ensure you are not duplicating an existing request.
