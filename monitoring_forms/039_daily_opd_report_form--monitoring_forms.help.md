# Daily OPD Report Form - Help Guide
## Purpose
The Daily OPD Report Form is used to collect information about the Outpatient Department's daily activity and performance.

## How To Complete This Form
To complete this form, follow these steps:

1. Navigate through the pages and fill in the required information for each page.
2. Each page will have a specific set of questions or fields that you will need to fill in.
3. Click 'Next' or 'Continue' to move to the next page.
4. When you have completed the form, click 'Submit' to submit the data.

## Field-by-Field Explanation

- **outpatient_department_activity** (`page_1`, text, optional): This field is used to record any notable activities or events that occurred in the Outpatient Department during the day.
  - Please provide a brief description of any significant events or activities that occurred.
  - You can type in as much detail as necessary.

- **patient_volume** (`page_2`, select_multiple, optional): This field is used to report the volume of patients seen by the Outpatient Department during the day.
  - You can select 'Yes' or 'No' for each of the following:
    • Did we see any new patients today?
    • Did we have any return patients today?

- **trends_for_reporting** (`page_3`, note, optional): This field is used to note any trends or observations that can be reported for performance indicators.
  - Please provide any notable trends or observations that can be used for reporting.
  - You can type in as much detail as necessary.

- **hospital_clinics** (`page_4`, select_one, optional): This field is used to report which hospital clinics were operational during the day.
  - You can select 'Yes' or 'No' for each of the following:
    • Were any hospital clinics operational today?

- **internal_reporting** (`page_5`, text, optional): This field is used for internal reporting purposes.
  - Please provide any internal reporting information.
  - You can type in as much detail as necessary.
