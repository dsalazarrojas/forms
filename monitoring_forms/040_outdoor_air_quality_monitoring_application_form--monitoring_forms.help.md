# Outdoor Air Quality Monitoring Application Form - Help Guide
## Purpose
This form collects information about outdoor air quality monitoring projects, including project details, monitoring locations, and expected outcomes.

## How To Complete This Form

To complete this form, follow these steps:

1. Fill in the project title and any other required fields.
2. Provide details about the project's organization and monitoring locations.
3. Select the expected outdoor air quality data sources and specify the duration of the project.
4. Describe the purpose and equipment used for the project.
5. Specify the expected outdoor air quality data and how it will be stored and analyzed.

## Field-by-Field Explanation

* **Organization Name** (`organization_name`, text, optional): Enter the name of the organization responsible for the project.
* **Project Details** (`project_details`, text, optional): Provide a brief description of the project's scope and objectives.
* **Monitoring Locations** (`monitoring_locations`, select_multiple, optional): Select the locations where monitoring will take place. Options: Yes/No.
* **Start Date** (`start_date`, date, optional): Enter the date when the project is expected to start.
* **End Date** (`end_date`, date, optional): Enter the date when the project is expected to end.
* **Duration** (`duration`, number, optional): Specify the project's duration.
* **Purpose** (`purpose`, text, optional): Describe the project's purpose.
* **Equipment Description** (`equipment_description`, text, optional): Describe the equipment used for the project.
* **Expected Outdoor Air Quality Data Sources** (`expected_outdoor_air_quality_data_sources`, select_multiple, optional): Select the expected data sources. Options: Good/Poor.
* **Data Handling** (`data_handling`, text, optional): Describe how the project will handle the data.
* **Monitoring Frequency** (`monitoring_frequency`, select_one, optional): Select the monitoring frequency. Options: Yes/No.
* **Sampling Locations** (`sampling_locations`, select_multiple, optional): Select the locations where sampling will take place. Options: Yes/No.
* **Sampling Frequency** (`sampling_frequency`, select_one, optional): Select the sampling frequency. Options: Yes/No.
* **Sample Type** (`sample_type`, select_one, optional): Select the type of sample. Options: Yes/No.
* **Sample Size** (`sample_size`, text, optional): Describe the sample size.
* **Sampling Method** (`sampling_method`, select_one, optional): Select the sampling method. Options: Yes/No.
* **Monitoring Duration** (`monitoring_duration`, number, optional): Specify the project's duration.
* **Sampling Frequency Interval** (`sampling_frequency_interval`, text, optional): Describe the sampling frequency interval.
* **Sampling Start Date** (`sampling_start_date`, date, optional): Enter the date when sampling will start.
* **Sampling End Date** (`sampling_end_date`, date, optional): Enter the date when sampling will end.
* **Expected Outdoor Air Quality Data** (`expected_outdoor_air_quality_data`, text, optional): Describe the expected data.
* **Data Storage** (`data_storage`, text, optional): Describe how the data will be stored.
* **Data Analysis** (`data_analysis`, text, optional): Describe how the data will be analyzed.
* **Report Frequency** (`report_frequency`, select_one, optional): Select the report frequency. Options: Yes/No.
* **Submission** (`submission`, note, optional): Enter any additional comments or notes about the project.
