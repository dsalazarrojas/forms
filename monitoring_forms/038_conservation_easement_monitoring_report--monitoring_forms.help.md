# Conservation Easement Monitoring Report - Help Guide

## Purpose
This report form is used to record conservation easement monitoring data. It captures details of each monitoring visit, including date, year, and property information.

## How To Complete This Form
1. Fill in the required information on each page.
2. Start with the date of the monitoring visit.
3. Enter the year of the monitoring visit.
4. Provide the easement's name and identifier.
5. Enter the property's name and address.
6. Select the county and state where the property is located.
7. Enter the total property size in acres.
8. Enter the acreage covered by the easement.
9. Enter the landowner's name and contact information.
10. Enter the name of the person conducting the monitoring visit.
11. Enter the name of the organization or land trust responsible for the monitoring.
12. Enter the weather conditions during the monitoring visit.
13. Select the method of access to the property.
14. Enter the condition of access routes.
15. Choose the type of habitats present on the property.
16. Check any wildlife observed during the monitoring visit.
17. Check any threatened or endangered species present.
18. Enter any water features (e.g., streams, ponds, or wetlands).
19. Enter any water quality observations.
20. Assess the overall vegetation condition on the property.
21. Check if any invasive species were observed.
22. Enter any structures on the property (e.g., buildings, fences).
23. Enter any permitted uses observed on the property.
24. Check if any easement violations were observed.
25. Enter any details about the observed violations.
26. Select the threats to conservation values identified.
27. Enter details about identified threats.
28. Assess the condition of property markers.
29. Assess the condition of conservation signs.
30. Enter the number of photographs taken during the visit.
31. Enter the locations of photographs taken.
32. Check if follow-up is required and choose the urgency level.
33. Enter any details for follow-up.
34. Enter an overall assessment of the property condition.
35. Check if conservation values are being protected.
36. Enter any recommendations for property management.
37. Sign the form to authenticate the monitoring visit.
38. Enter the landowner's name for acknowledgement.
39. Save or submit the form.

## Field-by-Field Explanation

* **Report Date (1)**: The date of the monitoring visit.
* **Report Year (2)**: The year of the monitoring visit.
* **Easement Name (3)**: The name of the conservation easement.
* **Easement ID Number (4)**: The unique identifier of the easement.
* **Property Name (5)**: The name of the property.
* **Property Address (6)**: The physical address or location of the property.
* **County (7)**: The county where the property is located.
* **State (8)**: The state where the property is located.
* **Total Acreage (9)**: The total size of the property in acres.
* **Easement Acreage (10)**: The acres covered by the easement.
* **Landowner Name (11)**: The current property owner's name.
* **Landowner Contact (12)**: The landowner's phone or email contact information.
* **Monitor Name (13)**: The name of the person conducting the monitoring visit.
* **Monitor Organization (14)**: The name of the land trust or organization conducting the monitoring.
* **Weather Conditions (15)**: The weather conditions during the monitoring visit.
* **Method of Access (16)**: The method used to access the property.
* **Access Condition (17)**: The condition of access routes.
* **Habitat Types Present (18)**: Select all habitats present on the property.
* **Wildlife Observed (19)**: List any wildlife observed during the monitoring visit.
* **Threatened or Endangered Species (20)**: Check if any threatened or endangered species are present.
* **Water Features (21)**: Enter any water features (e.g., streams, ponds, or wetlands).
* **Water Quality Observations (22)**: Enter any water quality observations.
* **Vegetation Condition (23)**: Assess the overall condition of vegetation on the property.
* **Invasive Species Present (24)**: Check if any invasive species are observed.
* **Structures on Property (25)**: Enter any structures on the property (e.g., buildings, fences).
* **Permitted Uses Observed (26)**: Enter any permitted uses observed on the property.
* **Violations Observed (27)**: Check if any easement violations were observed.
* **Violations Details (28)**: Enter any details about observed violations.
* **Threats Identified (29)**: Select any threats to conservation values identified.
* **Threats Details (30)**: Enter details about identified threats.
* **Boundary Markers Condition (31)**: Assess the condition of property markers.
* **Signage Condition (32)**: Assess the condition of conservation signs.
* **Photographs Taken (33)**: Enter the number of photographs taken during the visit.
* **Photo Locations (34)**: Enter the locations of photographs taken.
* **Follow-Up Required (35)**: Check if follow-up is required and select the urgency level.
* **Follow-Up Details (36)**: Enter any details for follow-up.
* **Overall Property Condition (37)**: Enter an overall assessment of the property condition.
* **Conservation Values Status (38)**: Check if conservation values are being protected.
* **Recommendations (39)**: Enter any recommendations for property management.
* **Monitor Signature (40)**: Sign the form to authenticate the monitoring visit.
* **Landowner Acknowledgement (41)**: Enter the landowner's name for acknowledgement.
