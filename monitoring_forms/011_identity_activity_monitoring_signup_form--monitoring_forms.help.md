# Identity Activity Monitoring Signup Form - Help Guide
## Purpose
The Identity Activity Monitoring Signup Form is used to provide information and settings for Identity Activity Monitoring. This form allows users to opt-in or opt-out of monitoring activities on their account.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the **Form Title** field with a title for your monitoring activity (optional).
2. Provide your **Full Name**, **Email**, and **Phone** number.
3. Select your **Role** from the options provided (User, Admin, or Manager).
4. Choose your **Monitoring Method** (Alerts, Email, or SMS).
5. Choose your **Notification Method** (Alerts, Email, or SMS).
6. Specify your **Monitoring Frequency** (Daily, Weekly, or Monthly).
7. Select the start and end dates for monitoring using the **Start Monitoring** and **End Monitoring** fields.
8. Add any additional **Notes** regarding your monitoring activity.
9. Specify the URL of your Unified Threat Management (UTM) system, if applicable.
10. Choose whether to **Allow** or **Deny** IP addresses to be whitelisted or blacklisted.
11. If applicable, provide IP addresses to be whitelisted or blacklisted.
12. If applicable, specify IP ranges for whitelisting or blacklisting.

## Field-by-Field Explanation

* **Form Title** (Optional): Enter a title for your monitoring activity.
* **Full Name**: Enter your full name.
* **Email**: Enter your email address.
* **Phone**: Enter your phone number.
* **Role** (`User`, `Admin`, `Manager`): Select your role to receive monitoring notifications.
* **Monitoring Method** (`Alerts`, `Email`, `SMS`): Choose how you want to receive monitoring notifications.
* **Notification Method** (`Alerts`, `Email`, `SMS`): Choose how you receive notifications.
* **Monitoring Frequency** (`Daily`, `Weekly`, `Monthly`): Specify how often you want to receive monitoring notifications.
* **Start Monitoring**: Specify the start date for monitoring.
* **End Monitoring**: Specify the end date for monitoring.
* **Notes**: Add any additional comments or notes regarding your monitoring activity.
* **UTM URL** (Optional): If you have a Unified Threat Management (UTM) system, enter the URL.
* **IP Whitelist** (`Allow`, `Deny`): Choose whether to allow or deny IP addresses to be whitelisted.
* **IP Blacklist** (`Allow`, `Deny`): Choose whether to allow or deny IP addresses to be blacklisted.
* **IP Whitelist Range** (Optional): If applicable, specify IP ranges to be whitelisted.
* **IP Blacklist Range** (Optional): If applicable, specify IP ranges to be blacklisted.
* **IP Whitelist IP List** (Optional): If applicable, list IP addresses to be whitelisted.
* **IP Blacklist IP List** (Optional): If applicable, list IP addresses to be blacklisted.
* **IP Blacklist IP Range** (Optional): If applicable, specify IP ranges to be blacklisted.
* **IP Whitelist IP Range** (Optional): If applicable, specify IP ranges to be whitelisted.
* **IP Address** (Optional): If applicable, specify a single IP address.
* **Agree** (`Agree`, `Decline`): You must agree that this form is not for commercial use.
