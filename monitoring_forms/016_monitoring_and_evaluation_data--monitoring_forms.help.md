# Monitoring And Evaluation Data - Help Guide
## Purpose
This form is used to collect data on the monitoring and evaluation process of an organization's performance. It helps gather information on monitoring start and end dates, reporting frequency, reporting methods, evaluation start and end dates, monitoring goals, targets, and status.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the "Organization" field with your organization's name.
2. Select the start and end dates for the monitoring process in the "Monitoring Start Date" and "Monitoring End Date" fields, respectively.
3. Choose the frequency of reporting in the "Frequency of reporting" field, which can be "Monitoring every 6 months", "Monitoring quarterly", "Monitoring monthly", or "Monitoring daily".
4. Select the reporting methods used in the "Reporting method" field, which can be "Email", "SMS", or "Phone".
5. If necessary, provide more details on the reporting frequency in the "Reporting frequency details" field.
6. Fill in the start and end dates for the reporting frequency in the "Reporting frequency start date" and "Reporting frequency end date" fields, respectively.
7. Select the start and end dates for the evaluation process in the "Evaluation start date" and "Evaluation end date" fields, respectively.
8. Define the monitoring goal and target in the "Monitoring goal objective" and "Monitoring goal target" fields, respectively.
9. Specify the status of the monitoring target in the "Monitoring target status" field, which can be "Achieved" or "Not achieved".
10. Provide comments on the monitoring target in the "Monitoring target comment" field, if necessary.

## Field-by-Field Explanation
### Organization (`organization`, text, required: false)
The "Organization" field is where you can input your organization's name.

### Monitoring Start Date (`monitoring_start_date`, date, required: false)
This field is used to select the start date of the monitoring process.

### Monitoring End Date (`monitoring_end_date`, date, required: false)
This field is used to select the end date of the monitoring process.

### Frequency of reporting (`frequency_of_reporting`, select_one, required: false)
Choose how often you report on the monitoring process. Options are:

*   Monitoring every 6 months
*   Monitoring quarterly
*   Monitoring monthly
*   Monitoring daily

### Reporting frequency details (`reporting_frequency_details`, text, required: false)
If you choose one of the above options, you can provide additional details on your reporting frequency.

### Reporting method (`reporting_method`, select_multiple, required: false)
Select the methods used for reporting. Options are:

*   Email
*   SMS
*   Phone

### Reporting frequency start date (`reporting_frequency_start_date`, date, required: false)
This field is used to select the start date of the reporting frequency.

### Reporting frequency end date (`reporting_frequency_end_date`, date, required: false)
This field is used to select the end date of the reporting frequency.

### Evaluation start date (`evaluation_start_date`, date, required: false)
This field is used to select the start date of the evaluation process.

### Evaluation end date (`evaluation_end_date`, date, required: false)
This field is used to select the end date of the evaluation process.

### Monitoring goal objective (`monitoring_goal_objective`, text, required: false)
 Define your monitoring goal objective.

### Monitoring goal target (`monitoring_goal_target`, text, required: false)
 Define your monitoring goal target.

### Monitoring target status (`monitoring_target_status`, select_one, required: false)
Select the status of your monitoring target. Options are:

*   Achieved
*   Not achieved

### Monitoring target comment (`monitoring_target_comment`, text, required: false)
Provide comments on your monitoring target, if necessary.

## Tips
*   Be accurate and thorough when filling out this form.
*   Ensure that the data collected is reliable and useful for evaluation and reporting purposes.
*   If you need help or have questions, contact form@gic.mx.
