# Home Curfew Monitoring Request Form - Help Guide
## Purpose
The Home Curfew Monitoring Request Form is used to request monitoring for a home curfew, typically for a minor. This form is used to gather information from the contact person, including their contact details, monitoring location, and scheduling preferences.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the contact person's details, including their phone number, email, and name.
2. Select the monitoring location where the curfew will be monitored.
3. Choose the scheduled time for the monitoring.
4. Select the duration of the monitoring.
5. Add any additional comments or notes about the monitoring request.
6. Select the preferred contact method (phone, email, or in person).
7. Confirm the monitoring schedule by selecting a time slot.

## Field-by-Field Explanation

* **Contact Person** (`contact_person`, text, **Required**): Enter the name of the person in charge of monitoring the curfew.
* **Phone Number** (`phone_number`, number, **Required**): Enter the contact person's phone number for follow-up purposes.
* **Email** (`email`, email, **Required**): Enter the contact person's email address for follow-up purposes.
* **Start Date** (`start_date`, date, **Optional**): If you have a specific start date for the monitoring, enter it here.
* **Start Time** (`start_time`, time, **Optional**): If you have a specific start time for the monitoring, enter it here.
* **End Date** (`end_date`, date, **Optional**): If you have a specific end date for the monitoring, enter it here.
* **End Time** (`end_time`, time, **Optional**): If you have a specific end time for the monitoring, enter it here.
* **Monitoring Location** (`monitoring_location`, select_one, **Required**): Select the location where the curfew will be monitored.
* **Comments** (`comments`, note, **Optional**): Add any additional comments or notes about the monitoring request.
* **Contact Method** (`contact_method`, select_one, **Optional**): Select the preferred contact method (phone, email, or in person).
* **Scheduled Time** (`scheduled_time`, select_one, **Required**): Select the scheduled time slot for the monitoring.
* **Scheduled Duration** (`scheduled_duration`, select_one, **Required**): Select the duration of the monitoring.
* **Notes** (`notes`, note, **Optional**): Add any additional comments or notes about the monitoring request.
* **Follow Up** (`follow_up`, text, **Optional**): Add any follow-up information.
* **Contact Person Name** (`contact_person_name`, text, **Optional**): Enter the name of the contact person.
* **Contact Person Phone** (`contact_person_phone`, text, **Optional**): Enter the contact person's phone number.
* **Contact Person Email** (`contact_person_email`, email, **Optional**): Enter the contact person's email address.
* **Agency ID** (`agency_id`, text, **Optional**): Enter the agency ID for the monitoring request.
* **Monitoring Request** (`monitoring_request`, text, **Required**): Enter a brief description of the monitoring request.
* **Scheduled Date** (`scheduled_date`, date, **Optional**): If you have a specific date for the monitoring, enter it here.
* **Scheduled Time** (`scheduled_time`, time, **Optional**): If you have a specific time for the monitoring, enter it here.
