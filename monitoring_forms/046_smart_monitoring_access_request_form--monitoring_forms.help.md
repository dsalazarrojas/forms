# Smart Monitoring Access Request Form - Help Guide
## Purpose
The Smart Monitoring Access Request Form is used to request access to monitoring tools for equipment, systems, or infrastructure. This form helps the requestor and assigned personnel manage and prioritize access requests efficiently.

## How To Complete This Form
1. Enter the User Name associated with the request.
2. Provide the Team ID that has been assigned to the user.
3. Select a date for the Access Request Date.
4. Enter the Monitor ID, which is the unique identifier for the monitor being accessed.
5. Enter a detailed Description of the request.
6. Enter the Requestor's Name for tracking purposes.
7. Choose the Department related to the request (optional).
8. Enter the Location related to the request (optional).
9. Select the type of Request Type (Monitoring or Maintenance).
10. Choose the Status of the request (Pending, Approved, or Rejected).
11. Select the person to whom the request is Assigned To.
12. Indicate if the assigned tool will be used (Yes or No).

## Field-by-Field Explanation
* **User Name**: <User Name> (`text`, required): Enter the name associated with this access request.
* **Team ID**: <Team ID> (`number`, required): Enter the Team ID assigned to you.
* **Access Request Date**: <Access Request Date> (`date`, required): Select the date for the access request.
* **Monitor ID**: <Monitor ID> (`text`, required): Enter the Monitor ID, which is the unique identifier for the monitor being accessed.
* **Description**: <Description> (`text`, required): Provide a detailed description of the request.
* **Requestor Name**: <Requestor Name> (`text`, required): Enter the Requestor's Name for tracking purposes.
* **Department**: <Department> (`text`, optional): Enter the Department related to the request (if any).
* **Location**: <Location> (`text`, optional): Enter the Location related to the request (if any).
* **Request Type**: <Request Type> (`select_one`, required): Select 'Monitoring' or 'Maintenance' for the request type.
* **Status**: <Status> (`select_multiple`, required): Choose the status of the request (Pending, Approved, or Rejected).
* **Assigned To**: <Assigned To> (`select_one`, required): Select the person to whom the request is assigned.
* **Assigned Tool**: <Assigned Tool> (`select_multiple`, required): Indicate if the assigned tool will be used (Yes or No).

## Tips
* Ensure you have the necessary permissions to submit this form.
* Verify that the request is not a duplicate by checking recent or ongoing requests.
* Be clear and concise in your description and selection of fields to facilitate efficient processing of your request.
