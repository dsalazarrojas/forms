# Graphite Monitoring Log Form - Help Guide
## Purpose
The Graphite Monitoring Log Form is used to record monitoring events in the Graphite system.

## How To Complete This Form
To complete this form, follow these steps:

1. Click on the "Submit" button to begin.
2. Select the appropriate options for each field as prompted.
3. Fill out the required fields (indicated by "" next to the field label).
4. Provide any additional comments or notes in the "notes" field.

## Field-by-Field Explanation
### Graphite Monitoring Log

* **graphite_monitoring_log**: This is the title of the monitoring log.
    (Note: This is a required field.)

* **date**: This is the date on which the monitoring was performed.
    (Note: This is a required field.)

* **time**: This is the time of day the monitoring was performed.
    (Note: This is not a required field.)

* **graphite_level**: This field allows you to select the level of monitoring performed (High, Low).
    (Note: This is a required field.)

* **location**: This is the location where the monitoring was performed.
    (Note: This is not a required field.)

* **notes**: This is a free-form text field for any additional comments or notes.
    (Note: This is not a required field.)

* **graphite_monitoring**: This field allows you to select if the monitoring was performed (Yes, No).
    (Note: This is not a required field.)

* **graphite_monitoring_2**: This field allows you to select if the monitoring was performed (Yes, No).
    (Note: This is not a required field.)

* **graphite_notes**: This is a free-form text field for any additional comments or notes.
    (Note: This is not a required field.)
* **graphite_location**: This is the location where the monitoring was performed.
    (Note: This is not a required field.)
 
# Tips

* Please ensure that you have all necessary information ready before submitting the form.
* If you have any questions or need help, do not hesitate to ask.
* Duplicate entries can lead to confusion and data inconsistency, so please do not submit this form more than once.
