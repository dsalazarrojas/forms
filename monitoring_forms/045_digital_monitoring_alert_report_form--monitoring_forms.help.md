# Digital Monitoring Alert Report Form - Help Guide

## Purpose
The purpose of this form is to report and document incidents or system alerts that require attention or action from the monitoring team. This form is used to gather information about the incident, its details, and the current status.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the "System Alerts" page to report any system alerts.
2. Describe the incident details in the "Incident Details" field.
3. If applicable, attach relevant evidence from the options provided in the "Attached Evidence" field.
4. Choose the current status of the incident from the options in the "Incident Status" field.
5. Enter the date and time of the incident in the "Incident Date" and "Incident Time" fields. 
6. Provide a detailed description of the incident in the "Incident Description" field.

## Field-by-Field Explanation
### System Alerts
* **System Alerts** (`system_alerts`, `text`, optional): This is the first page of the form where you can report any system alerts. Enter a brief description of the alert.

### Incident Details
* **Incident Details** (`incident_details`, `text`, optional): Provide a detailed description of the incident, including its severity and any relevant context.

### Attached Evidence
* **Attached Evidence** (`attached_evidence`, `select_multiple`, required): Select all relevant evidence related to the incident. You can choose from the following options:
	+ Option 1
	+ Option 2
	+ Option 3

### Incident Status
* **Incident Status** (`incident_status`, `select_one`, required): Choose the current status of the incident from the following options:
	+ Option 1
	+ Option 2
	+ Option 3

### Incident Date
* **Incident Date** (`incident_date`, `date`, optional): Enter the date of the incident.

### Incident Time
* **Incident Time** (`incident_time`, `time`, optional): Enter the time of the incident.

### Incident Description
* **Incident Description** (`incident_description`, `text`, optional): Provide a detailed description of the incident.

## Tips
* Make sure to attach all relevant evidence to support your report.
* Choose the most accurate status of the incident from the options.
* Enter the correct date and time of the incident.
* Provide a clear and concise description of the incident.
