# SSH Audit Log Form - Help Guide
## Purpose
The SSH Audit Log Form is used to record and review details about SSH sessions. This form helps you keep track of session information for future reference and troubleshooting.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the title of the SSH session in the "SSH Session" field.
2. Provide a brief summary of the session details in the "Session Details" field.
3. If applicable, enter the information for the user who initiated the session in the "User Activity" field.
4. In the "Session Summary" field, provide a brief overview of the session.
5. Enter the IP address of the SSH host in the "SSH Host" field.
6. If applicable, enter the port used for the SSH connection in the "SSH Port" field.
7. Enter the user's name in the "SSH User" field.
8. Enter the SSH key used for the connection in the "SSH Key" field.
9. If applicable, enter the start and end times of the session in the "Session Start Time" and "Session End Time" fields.
10. If applicable, enter the duration of the session in the "Session Duration" field.

## Field-by-Field Explanation
* **SSH Session**: Enter a brief title for the SSH session.
* **Session Details**: Enter a short description of the session.
* **User Activity**: Enter the user's name and any notable actions taken during the session.
* **Session Summary**: Enter a brief summary of the session.
* **SSH Host**: Enter the IP address of the SSH host.
* **SSH Port**: Enter the port used for the SSH connection, if applicable.
* **SSH User**: Enter the user's name who initiated the session.
* **SSH Key**: Enter the SSH key used for the connection.
* **Session Start Time**: Enter the start time of the session, if applicable.
* **Session End Time**: Enter the end time of the session, if applicable.
* **Session Duration**: Enter the duration of the session, if applicable.

## Tips
* Make sure to provide accurate and relevant information about the SSH session.
* If you're unsure about any field, you can leave it blank or ask for assistance.
* This form is for logging and tracking purposes; be as detailed as possible.
