## Surveillance Monitoring Form - Help Guide
## Purpose
The Surveillance Monitoring Form is used to record information about surveillance monitoring activities, such as checking on the status of a particular location or situation, and reporting any issues or concerns that have been identified.

## How To Complete This Form
To complete this form, follow these steps:

* Ensure that the location you are monitoring is correct, as this information will be used to determine what type of surveillance monitoring activity is being performed.
* Select the correct options for "Location" to indicate whether the location is currently being monitored or not.
* Enter the "Event Date" for the date of the monitoring activity.
* Enter the "Start Time" and "End Time" for the duration of the monitoring activity.
* Enter any "Notes" about the monitoring activity, if applicable.
* Select the "Assigned User" who is currently performing the monitoring activity, if applicable.
* Select the "Assigned Team" who is currently performing the monitoring activity, if applicable.

## Field-by-Field Explanation
* **Location** (`location`, select_multiple, required): This field indicates whether the location is currently being monitored or not. Select "Yes" if the location is being monitored, and "No" if it is not.
* **Event Date** (`event_date`, date, required): Enter the date of the monitoring activity.
* **Start Time** (`start_time`, time, required): Enter the start time of the monitoring activity.
* **End Time** (`end_time`, time, required): Enter the end time of the monitoring activity.
* **Notes** (`notes`, text, optional): Enter any additional notes or comments about the monitoring activity, if applicable.
* **Assigned User** (`assigned_user`, select_one, optional): Select the user who is currently performing the monitoring activity, if applicable.
* **Assigned Team** (`assigned_team`, select_multiple, optional): Select the team who is currently performing the monitoring activity, if applicable.
