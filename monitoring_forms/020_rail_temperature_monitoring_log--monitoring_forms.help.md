# Rail Temperature Monitoring Log - Help Guide
## Purpose
The Rail Temperature Monitoring Log is a tool used to record and track rail temperature monitoring data. It helps ensure that rail temperature monitoring activities are accurately documented and reported.

## How To Complete This Form
1.  Review the available options for each field on each page and select the appropriate information for the specific rail temperature monitoring activity.
2.  Ensure that all required fields are filled in completely.
3.  If a field is not required, you may leave it blank.
4.  Click on "Submit" to record and save your entry in the system.

## Field-by-Field Explanation

* **Rail Temperature Monitoring Log** (`title`, `note`, required: false): This is a title field for the form. It is an optional field where you can enter a brief description or title for the rail temperature monitoring log.
* **Rail Temperature 2** (`name`, `select_one`, required: false): Select an option from the list to indicate the specific activity being monitored.
* **Rail Temperature 3** (`name`, `select_multiple`, required: false): Select multiple options from the list to indicate the specific activities being monitored.
* **Rail Temperature 4** (`name`, `date`, required: false): Enter a date in the format 'YYYY-MM-DD' to record the monitoring activity on that specific date.
* **Rail Temperature 5** (`name`, `time`, required: false): Enter a time in the format 'HH:MM' to record the monitoring activity at that specific time.

## Tips
- Review each field carefully before completing the form.
- Make sure to select the correct options for the specific activity being monitored.
- Enter dates and times in the correct format.
- Ensure that all required fields are completed before submitting the form.
- If you are unsure about any field, do not hesitate to contact your supervisor or support team.
