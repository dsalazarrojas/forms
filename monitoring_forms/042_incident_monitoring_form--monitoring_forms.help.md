# Incident Monitoring Form - Help Guide
## Purpose

The Incident Monitoring Form is a tool used to collect and track information about incidents that occur within the organization. This form is designed to help users report and monitor incidents in a structured and organized way.

## How To Complete This Form

To complete this form, please follow these steps:

1. Select the type of incident that occurred (e.g. Type 1, Type 2, Type 3)
2. Enter a brief description of the incident in the Incident Description field
3. Choose the status of the incident (e.g. Active, Resolved, Inactive)
4. Choose the priority of the incident (e.g. High, Medium, Low)
5. Enter the date and time of the incident
6. Enter any additional details or notes about the incident in the Incident Notes field
7. Select the responsible party or person for the incident
8. Select the person who reported the incident
9. Select the person who reviewed the incident
10. Select the person who closed the incident
