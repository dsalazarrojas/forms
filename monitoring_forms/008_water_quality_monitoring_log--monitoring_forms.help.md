# Water Quality Monitoring Log - Help Guide

## Purpose
The Water Quality Monitoring Log is a form used to record and track water quality monitoring events. This form is used to collect information about the site being monitored, the parameter being measured, and the results of the monitoring event.

## How To Complete This Form

1. Select the "Sampling Event" option from the dropdown menu to indicate the type of event being monitored.
2. Enter the "Date" and "Time" of the monitoring event.
3. Enter the "Parameter Name" and "Parameter Value" for the parameter being measured.
4. Select the "Sampling Frequency" of the event, which can be Daily, Weekly, Monthly, Quarterly, Semi-Annual, or Annual.
5. Enter the "Sample Location" where the monitoring event took place.
6. Enter the "Site ID" of the site being monitored.
7. Select the "Sample Type" of the sample collected, which can be Water, Sediment, or Other.
8. Enter any additional "Note" about the monitoring event.
9. Enter the "Monitoring Event ID" of the event being monitored.
10. Enter the "Assigned Tool" used for the monitoring event.
11. Enter the "Email" and "Phone" contact information of the person responsible for the monitoring event.

## Field-by-Field Explanation

* **Sampling Event** (Water Quality Monitoring Log Form): Select the type of monitoring event being conducted.
* **Date**: Enter the date of the monitoring event.
* **Time**: Enter the time of the monitoring event.
* **Parameter Name**: Enter the name of the parameter being measured.
* **Parameter Value**: Enter the value of the parameter being measured.
* **Sampling Frequency**: Select the frequency of the monitoring event.
* **Sample Location**: Enter the location where the monitoring event took place.
* **Site ID**: Enter the ID of the site being monitored.
* **Sample Type**: Select the type of sample collected.
* **Assigned Tool**: Enter the tool used for the monitoring event.
* **Email**: Enter the contact email of the person responsible for the monitoring event.
* **Phone**: Enter the contact phone number of the person responsible for the monitoring event.
* **Note**: Enter any additional notes about the monitoring event.
* **Monitoring Event ID**: Enter the ID of the monitoring event.
* **Sampling Event ID**: Enter the ID of the sampling event.
* **Sample ID**: Enter the ID of the sample collected.
* **Sample IDs**: Enter multiple IDs of the samples collected.
* **Parameter IDs**: Enter multiple IDs of the parameters measured.
* **Monitoring Event IDs**: Enter multiple IDs of the monitoring events.
