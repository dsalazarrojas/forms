# Pharmaceutical Process Monitoring Log - Help Guide
## Purpose
The Pharmaceutical Process Monitoring Log is a form used to record and track various aspects of the pharmaceutical production process. This form helps monitor and analyze the production process, identify trends and patterns, and make data-driven decisions.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the **Batch ID** field with the unique identifier of the batch being produced.
2. Enter the **Equipment ID** of the machine or equipment used during the production process.
3. Select the **Production Shift** during which the batch was produced.
4. Enter the **Batch Number** of the specific batch being recorded.
5. Enter the start time of the production process in the **Start Time** field.
6. Enter the end time of the production process in the **End Time** field.
7. Add any relevant comments about the batch in the **Batch Comments** field.
8. Select the **Production Status** of the batch from the provided options (Active or Inactive).
9. (Optional) If the production status is not listed as Active or Inactive, enter a description of the status in the **Production Status** field.
10. Provide a reason for the production status in the **Production Status Reason** field.

## Field-by-Field Explanation
- **Batch ID** (1): A unique identifier for the batch being produced.
  - Type: Number
  - Required: False
- **Equipment ID** (2): The ID of the machine or equipment used during the production process.
  - Type: Number
  - Required: False
- **Production Shift** (3): The shift during which the batch was produced.
  - Type: Number
  - Required: False
- **Batch Number** (4): The specific batch number being recorded.
  - Type: Number
  - Required: False
- **Start Time** (5): The start time of the production process.
  - Type: Time
  - Required: False
- **End Time** (6): The end time of the production process.
  - Type: Time
  - Required: False
- **Batch Comments** (7): Comments about the batch.
  - Type: Text
  - Required: False
- **Production Status** (8): Select the production status of the batch.
  - Type: Select One
  - Required: False
  - Options: Active, Inactive
- **Production Status** (9): (Optional) If the production status is not listed as Active or Inactive, enter a description of the status.
  - Type: Text
  - Required: False
- **Production Status Reason** (10): Provide a reason for the production status.
  - Type: Text
  - Required: False
