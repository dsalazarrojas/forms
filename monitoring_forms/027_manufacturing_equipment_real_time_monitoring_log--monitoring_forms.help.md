# Manufacturing Equipment Real Time Monitoring Log - Help Guide
## Purpose

The purpose of this form is to collect real-time monitoring data from manufacturing equipment. This data will help in tracking and analyzing equipment performance, issue resolution, and associated information for further decision-making.

## How To Complete This Form

1.  Fill in the required fields marked as such.
2.  Select the correct options from the dropdown menus.
3.  Enter date fields in the correct format (DD/MM/YYYY or MM/DD/YYYY).
4.  Enter text fields according to the given hints.
5.  Save or submit the form once you have filled in all required fields.

## Field-by-Field Explanation

* **Equipment Performance** (`equipment_performance`, text, optional): A text field where you can describe the performance of the equipment.
* **Issue Description** (`issue_description`, text, required): Enter a detailed description of the issue.
* **Shift** (`shift`, select_one, required): Select 'Yes' if the shift is active or 'No' if it's not.
* **Equipment Status** (`equipment_status`, select_multiple, optional): Select all the statuses that apply to the equipment (Active or Inactive).
* **Issue Status** (`issue_status`, select_one, required): Select 'Active' if the issue is active or 'Inactive' if it's not.
* **Machine ID** (`machine_id`, number, required): Enter the unique ID of the machine.
* **Issue Type** (`issue_type`, text, optional): Describe the type of issue.
* **Shift Start Time** (`shift_start_time`, date, required): Enter the start time of the shift in the correct format (DD/MM/YYYY or MM/DD/YYYY).
* **Shift End Time** (`shift_end_time`, time, required): Enter the end time of the shift in 12-hour format (HH:MM).
* **Issue Start Time** (`issue_start_time`, date, required): Enter the start time of the issue.
* **Issue End Time** (`issue_end_time`, date, optional): Enter the end time of the issue.
* **Notes** (`notes`, text, optional): Enter any additional notes related to the issue.
* **Email** (`email`, email, optional): Enter your contact email address for follow-up actions.
* **Phone** (`phone`, text, optional): Enter your contact phone number for follow-up actions.
* **Contact** (`contact`, text, optional): Enter your name for follow-up actions.
* **Assigned To** (`assigned_to`, text, optional): Enter the name of the person assigned to handle the issue.
* **Shift** (`shift`, select_one, required): Select 'Yes' if the shift is active or 'No' if it's not.
* **Issue Priority** (`issue_priority`, select_one, required): Select 'Yes' if the issue is of high priority or 'No' if it's not.
* **Reopened Issues** (`issue_reopened`, select_one, optional): Select 'Yes' if the issue is reopened or 'No' if it's not.
* **Shift Start Date** (`shift_start_date`, date, required): Enter the start date of the shift.
* **Shift End Date** (`shift_end_date`, date, required): Enter the end date of the shift.
* **Issue Start Date** (`issue_start_date`, date, required): Enter the date when the issue started.
* **Issue End Date** (`issue_end_date`, date, optional): Enter the date when the issue ended.
* **Assigned Tool** (`assigned_tool`, text, optional): Enter the tool assigned to handle the issue.
* **Form Version** (`form_version`, text, optional): Enter the form version number.
