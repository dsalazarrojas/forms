# Monitoring Refusal Form - Help Guide

## Purpose
This form is used to document a monitoring refusal, where a user can input details about why a monitoring activity was refused. The form is used to track and store information about refused monitoring activities, which can be useful for future reference and for identifying recurring patterns or issues.

## How To Complete This Form
To complete this form, follow these steps:
1. Fill in the **Monitoring Refusal Form Data** section with any relevant details about the monitoring refusal.
2. Choose the **reason** for the refusal from the drop-down menu, which provides three options: Not Applicable, Not Known, or Refusal.
3. If additional information is needed, provide it in the **reason_note** text box.
4. If follow-up actions were taken or need to be taken, add them to the **follow_up_actions** text box.
5. Specify the next **next_steps**, which can be any additional actions that will be taken after the refusal.
6. Select one or more **incident_status** from the drop-down menu, which indicates the status of the incident.
7. If a **follow_up_date** is necessary, enter the date on which follow-up action will be taken.
8. If a specific time is required for the follow-up action, select the **follow_up_time** in the format HH:MM.
9. Choose the **follow_up_user** who will be performing the follow-up action from the drop-down menu.
10. Select the method of communication for the follow-up action, which can be Call, Email, or SMS.
11. Finally, add any additional **notes** about the refusal.

## Field-by-Field Explanation

* **Monitoring Refusal Form Data**: This is a text field where you can enter any relevant details about the monitoring refusal.
* **reason**: This drop-down menu provides three options for the reason of refusal. You can choose Not Applicable, Not Known, or Refusal.
* **reason_note**: This text field is where you can provide additional information about the reason for refusal.
* **follow_up_actions**: This text field is for adding any additional follow-up actions that need to be taken.
* **next_steps**: This text field is for specifying the next steps to be taken after the refusal.
* **incident_status**: This drop-down menu provides three options for the incident status. You can select Active, Closed, or Refused.
* **follow_up_date**: This date field is for entering the date on which follow-up action will be taken.
* **follow_up_time**: This time field is for selecting the time of follow-up action in the format HH:MM.
* **follow_up_user**: This drop-down menu provides a list of users who can perform the follow-up action. You can select one or more users from the list.
* **follow_up_method**: This drop-down menu provides three options for the method of communication for the follow-up action. You can select Call, Email, or SMS.
* **notes**: This text field is for adding any additional notes about the refusal.

Remember to fill in all the necessary fields to provide a complete and accurate record of the monitoring refusal.
