# Microorganism Growth Control Survey - Help Guide

## Purpose
The "Microorganism Growth Control Survey" form is designed to collect information about microorganism growth control practices, parameters, and frequency from different types of labs.

## How To Complete This Form
To complete this form, follow these steps:

1.  Select the type of lab where the microorganism growth control practices are used (microbiology, biochemical, molecular biology, etc.).
2.  Describe the microbial control practices used in the facility.
3.  Select the type of lab (microbiology, biochemical, molecular biology, etc.).
4.  Choose multiple control methods (inoculation, subculturing, incubation, etc.).
5.  Record the growth control parameters.
6.  Describe how growth medium control is performed.
7.  Record the growth temperature control.
8.  Record the growth rate control.
9.  Select another control method (autoclaving, sterilization, decontamination, etc.).
10. Select multiple control methods (inoculation, subculturing, incubation, etc.).
11. Describe how samples are handled.
12. Record the control frequency.
13. Add any additional notes about the microorganism growth control practices.

## Field-by-Field Explanation

*   **microbial_control_practices**: A text field for describing the microbial control practices used in the facility.
    *   **Required**: No
    *   **Type**: Text
*   **facility_info**: A text field for collecting information about the facility.
    *   **Required**: No
    *   **Type**: Text
*   **lab_info**: A select_one field for choosing the type of lab (microbiology, biochemical, molecular biology, etc.).
    *   **Required**: No
    *   **Type**: Select One
*   **control_methods**: A select_multiple field for selecting multiple control methods (inoculation, subculturing, incubation, etc.).
    *   **Required**: No
    *   **Type**: Select Multiple
*   **growth_control_parameters**: A date field for recording growth control parameters.
    *   **Required**: No
    *   **Type**: Date
*   **growth_medium_control**: A time field for recording growth medium control.
    *   **Required**: No
    *   **Type**: Time
*   **growth_temperature_control**: A number field for recording growth temperature control.
    *   **Required**: No
    *   **Type**: Number
*   **growth_rate_control**: A number field for recording growth rate control.
    *   **Required**: No
    *   **Type**: Number
*   **control_method_2**: A select_one field for selecting another control method (autoclaving, sterilization, decontamination, etc.).
    *   **Required**: No
    *   **Type**: Select One
*   **control_method_3**: A select_multiple field for selecting multiple control methods (inoculation, subculturing, incubation, etc.).
    *   **Required**: No
    *   **Type**: Select Multiple
*   **sample_handling**: A text field for describing sample handling.
    *   **Required**: No
    *   **Type**: Text
*   **control_frequency**: A number field for recording control frequency.
    *   **Required**: No
    *   **Type**: Number
*   **notes**: A note field for collecting any additional notes about the microorganism growth control practices.
    *   **Required**: No
    *   **Type**: Note

## Tips
*   Make sure to complete all required fields.
*   Be as specific as possible when describing the control methods and parameters.
*   Use the correct type of lab when completing the form.
*   Review the form carefully before submitting it.
*   If you have any questions or concerns, contact the form administrator.
