# Vessel Impact Monitoring Log Form - Help Guide
## Purpose
The Vessel Impact Monitoring Log Form is used to track and document incidents affecting vessels, such as environmental hazards, human error, or equipment failures.
## How To Complete This Form
To complete the form, follow these steps:

1. Enter the incident date in the `incident_date` field.
2. Select the person or entity that reported the incident from the `reported_by` dropdown list.
3. Enter the name of the marina related to the incident in the `marina_name` field.
4. Enter the location of the incident in the `location` field.
5. Select the type of boat affected by the incident from the `boat_type` dropdown list.
6. Enter the name of the boat affected by the incident in the `boat_name` field.
7. Select the type of incident from the `incident_type` dropdown list.
8. Describe the incident in the `description` field.
9. Select the level of impact from the `impact_type` dropdown list.
10. Select the severity of the incident from the `severity` dropdown list.
11. Enter any comments about the incident in the `comments` field.
12. Select the team assigned to follow up on the incident from the `assigned_to` dropdown list.
13. Select the status of the incident from the `status` dropdown list.
14. Select the follow-up status from the `follow_up_status` dropdown list.
15. Enter any comments about the follow-up in the `follow_up_comments` field.
16. Select the team assigned to follow up on the incident from the `follow_up_assigned_to` dropdown list.

## Field-by-Field Explanation
* **Incident Date** (`incident_date`, `date`, required): Enter the date of the incident.
* **Reported By** (`reported_by`, `select_one`, required): Select the person or entity that reported the incident.
* **Marina** (`marina_name`, `text`, required): Enter the name of the marina related to the incident.
* **Location** (`location`, `text`, required): Enter the location of the incident.
* **Boat Type** (`boat_type`, `select_one`, required): Select the type of boat affected by the incident.
* **Boat Name** (`boat_name`, `text`, required): Enter the name of the boat affected by the incident.
* **Incident Type** (`incident_type`, `select_one`, required): Select the type of incident.
* **Description** (`description`, `text`, required): Describe the incident.
* **Impact Type** (`impact_type`, `select_one`, required): Select the level of impact.
* **Severity** (`severity`, `select_one`, required): Select the severity of the incident.
* **Comments** (`comments`, `text`, required): Enter any comments about the incident.
* **Assigned To** (`assigned_to`, `select_one`, required): Select the team assigned to follow up on the incident.
* **Status** (`status`, `select_one`, required): Select the status of the incident.
* **Follow Up Status** (`follow_up_status`, `select_one`, required): Select the follow-up status.
* **Follow Up Comments** (`follow_up_comments`, `text`, required): Enter any comments about the follow-up.
* **Follow Up Assigned To** (`follow_up_assigned_to`, `select_one`, required): Select the team assigned to follow up on the incident.
* **Follow Up Status** (`follow_up_status`, `select_one`, required): Select the follow-up status.
