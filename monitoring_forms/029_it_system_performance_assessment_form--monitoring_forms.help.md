# IT System Performance Assessment Form - Help Guide
## Purpose
The IT System Performance Assessment Form is used to collect information about the performance of IT systems. This form is intended to be filled out by individuals with direct knowledge of the systems being assessed.

## How To Complete This Form
1. Please fill out each section of the form with the requested information.
2. For fields that are not applicable, please leave them blank.
3. If you are unsure about any of the information required, it is recommended to consult with the relevant IT teams before filling out this form.

## Field-by-Field Explanation
### General Information (Page 1)
* **General Information** (`general_info`, text, not required): Please enter a brief description of the IT system being assessed.

### Performance Data (Page 2)
* **Performance Data** (`performance_data`, text, not required): Enter any additional performance data that may be relevant to the assessment.

### System Information (Page 3)
* **System Information** (`system_info`, text, not required): Enter information about the system's hardware, software, and configuration.

### Network Information (Page 4)
* **Network Information** (`network_info`, text, not required): Enter information about the network configuration and any relevant network-related issues.

### Server Information (Page 5)
* **Server Information** (`server_info`, text, not required): Enter information about the server's configuration and any relevant server-related issues.

### Database Information (Page 6)
* **Database Information** (`database_info`, text, not required): Enter information about the database configuration and any relevant database-related issues.

### Storage Information (Page 7)
* **Storage Information** (`storage_info`, text, not required): Enter information about the storage configuration and any relevant storage-related issues.

### CPU Information (Page 8)
* **CPU Information** (`cpu_info`, text, not required): Enter information about the CPU configuration and any relevant CPU-related issues.

### Memory Information (Page 9)
* **Memory Information** (`memory_info`, text, not required): Enter information about the memory configuration and any relevant memory-related issues.

### CPU Usage (Page 10)
* **CPU Usage** (`cpu_usage`, number, not required): Enter the current CPU usage as a percentage.
* **CPU Count** (`cpu_count`, number, not required): Enter the number of CPU cores.
* **CPU Percent** (`cpu_percent`, number, not required): Enter the current CPU usage as a percentage.
* **Select One** (`select_one`, select_one, not required): Select one of the options to indicate the current CPU usage status.

### Memory Usage (Page 11)
* **Memory Usage** (`memory_usage`, number, not required): Enter the current memory usage as a percentage.
* **Memory Count** (`memory_count`, number, not required): Enter the number of memory modules.
* **Memory Percent** (`memory_percent`, number, not required): Enter the current memory usage as a percentage.
* **Select Multiple** (`select_multiple`, select_multiple, not required): Select multiple of the options to indicate the current memory usage status.

### I/O Usage (Page 12)
* **I/O Usage** (`io_usage`, number, not required): Enter the current I/O usage as a percentage.
* **I/O Count** (`io_count`, number, not required): Enter the number of I/O operations.
* **I/O Percent** (`io_percent`, number, not required): Enter the current I/O usage as a percentage.
* **Select Multiple** (`select_multiple`, select_multiple, not required): Select multiple of the options to indicate the current I/O usage status.

### Additional Information (Page 13)
* **Date** (`date`, date, not required): Enter the date of the assessment.
* **Time** (`time`, time, not required): Enter the time of the assessment.
* **Note** (`note`, note, not required): Enter any additional comments or notes related to the assessment.
* **Email** (`email`, email, not required): Enter your email address for contact information.
* **Phone** (`phone`, text, not required): Enter your phone number for contact information.
