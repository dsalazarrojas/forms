# Temperature Monitoring Device Program Application Form - Help Guide
## Purpose
This form is used to collect information for an organization's application to the Temperature Monitoring Device Program. Please provide accurate and complete details to ensure a smooth review process.

## How To Complete This Form

1. Please fill out the form with the following sections:
	* Facility Details: Enter a brief description of your facility.
	* Facility Owner: Enter the name of the facility owner.
	* Contact Person: Enter the name of the contact person.
	* Facility Address: Enter the physical address of the facility.
	* Monitoring Device Details: Enter details about the monitoring device being used.
	* Device Location: Enter the location of the monitoring device within the facility.
	* Monitoring Start Date: Enter the date you started monitoring with the device.
	* Monitoring End Date: Enter the date you plan to stop monitoring with the device.
	* Device Status: Select the status of the monitoring device (Active, Inactive, or Pending).

## Field-by-Field Explanation

* **Facility Details**: A brief description of your facility.
* **Facility Owner**: The name of the facility owner.
* **Contact Person**: The name of the contact person responsible for the device.
* **Facility Address**: The physical address of the facility.
* **Monitoring Device Details**: Enter details about the monitoring device being used, including model, make, and serial number.
* **Device Location**: Enter the specific location of the device within the facility.
* **Monitoring Start Date**: Enter the date you started monitoring with the device (in the format MM/DD/YYYY).
* **Monitoring End Date**: Enter the date you plan to stop monitoring with the device (in the format MM/DD/YYYY).
* **Device Status**: Select the status of the monitoring device from the options:
	+ **Active**: The device is currently in use.
	+ **Inactive**: The device is not currently in use.
	+ **Pending**: The status is pending review or approval.

## Tips

* Be as accurate and complete as possible when filling out this form.
* If you need to add or update information, please contact the temperature monitoring program staff.
* This form is designed to ensure a thorough review process. Thank you for your cooperation.
