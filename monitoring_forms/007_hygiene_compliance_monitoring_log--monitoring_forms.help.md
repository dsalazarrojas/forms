# Hygiene Compliance Monitoring Log - Help Guide
## Purpose
The Hygiene Compliance Monitoring Log form is used to monitor and record the compliance status of various areas within a facility, equipment, or procedure. This form helps facility management staff and supervisors to identify potential issues and ensure that corrective actions are taken to maintain compliance.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the area that needs to be monitored (e.g., Facility A, Equipment B, Procedure C).
2. Choose the time of day when the monitoring took place (e.g., Morning, Afternoon, Evening).
3. Describe any issues found in the area (e.g., "No soap available" or "Equipment not properly sanitized").
4. Record the action taken to address the issue (e.g., "Ordered more soap" or "Scheduled for replacement").
5. Indicate if the supervisor verified the issue and the action (e.g., "Yes" or "No").
6. If the supervisor verified, enter the date of verification.
7. Optionally, provide additional comments or notes about the monitoring process.
8. Enter the form ID for the specific form being completed.

## Field-by-Field Explanation

* **Select Area (`select_one`, required/optional):** Choose the area that needs to be monitored, such as a facility, equipment, or procedure.
* **Select Time (`select_one`, required/optional):** Select the time of day when the monitoring took place.
* **Document Issues (`text`, required):** Describe any issues found in the area, such as no soap available or equipment not properly sanitized.
* **Record Action (`text`, required):** Describe the action taken to address the issue, such as ordering more soap or scheduling equipment replacement.
* **Supervisor Verify (`select_one`, required):** Check if the supervisor verified the issue and the action taken.
* **Comments (`text`, optional):** Provide additional comments or notes about the monitoring process, if needed.
* **Assigned to (`select_one`, optional):** Check if the issue is assigned to someone for resolution.
* **Assigned Date (`date`, optional):** If the issue is assigned to someone, enter the date when it was assigned.
* **Notes (`text`, optional):** Add any additional notes about the monitoring process.
* **Form ID (`text`, required):** Enter the unique ID for the form being completed.

## Tips

* Make sure to select the correct area and time when completing the form.
* Be as specific as possible when documenting issues and the actions taken.
* Use the supervisor verification field to ensure that all issues are properly addressed and resolved.
* If an issue is assigned to someone, make sure to enter the assigned date and name of the person.
* Use the comments field to provide any additional context or information about the issue and resolution.
