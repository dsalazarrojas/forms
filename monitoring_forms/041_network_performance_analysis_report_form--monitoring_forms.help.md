# Network Performance Analysis Report Form - Help Guide
## Purpose
The Network Performance Analysis Report Form is used to collect and track information about network performance, issues, and tasks associated with network monitoring.

## How To Complete This Form
To complete this form, please follow these steps:

1. Select the category that best describes the type of report you are submitting.
2. Enter a brief description of the issue or performance metric being monitored.
3. Enter the name of the network being analyzed.
4. Enter the location of the network being analyzed.
5. Provide a detailed description of the issue or performance metric.
6. Select the date of the performance measurement.
7. Enter the network performance metrics (e.g., availability, latency, jitter, packet loss).
8. Select the current status of the network (Critical, Warning, Normal, Unknown).
9. Select the status of the issue (Pending, Resolved, Open).
10. Enter any comments or notes about the issue or performance metric.
11. If applicable, select the type of issue (Hardware, Software, Network).
12. Select any categories that are applicable to the issue or performance metric (Category 1, Category 2).
13. Select if any attachments are required.
14. Select the type of issue (Hardware, Software, Network).
15. Finally, submit the report.

## Field-by-Field Explanation
- **Category**: Select the category that best describes the type of report you are submitting (Monitoring, Reporting, Analysis).
  - This field allows you to identify the type of report you are creating.
- **Description**: Enter a brief description of the issue or performance metric being monitored.
  - This field provides a brief summary of the issue or performance metric.

- **Performance Date**: Select the date of the performance measurement.
  - This field identifies the date the performance metric was measured.
- **Network Performance**: Enter the network performance metrics (e.g., availability, latency, jitter, packet loss).
  - This field enters the metrics of the network performance (e.g., availability, latency, jitter, packet loss).

- **Latency**: Enter the latency metric.

- **Jitter**: Enter the jitter metric.
