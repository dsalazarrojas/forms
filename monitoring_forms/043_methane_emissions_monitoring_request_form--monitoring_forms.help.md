# Methane Emissions Monitoring Request Form - Help Guide

## Purpose
This form is designed to collect information about site visits, monitoring frequencies, and other relevant details for methane emissions monitoring.

## How To Complete This Form

1. Enter a title for the form in the **Form Title** field.
2. Select the **Category** as "Monitoring Forms" or "Other Forms" from the dropdown menu.
3. Provide a brief description of the site visit in the **Description** field.
4. Enter the site ID, name, address, and contact information in their respective fields.
5. Select the visit frequency from the options provided or specify "Other (please specify)" if not listed.
6. Enter the start and end dates of the site visit, if applicable.
7. Provide any additional comments about the site visit in the **Site Visit Comments** field.
8. Attach any relevant photos or files to the site visit in the **Site Visit Photos** and **Attachments** fields, if applicable.
9. Enter any other relevant details about the site visit in the **Site Visit Other Details** field.
10. Enter any submission notes about the form in the **Form Submission Notes** field.
11. Enter any suggestions for future site visits in the **Site Visit Suggestions** field.
12. Indicate the status of the site visit as "Pending", "In Progress", or "Completed".
13. Enter the scheduled date and time of the site visit, if applicable.
14. Enter the submitter's name and contact information.

## Field-by-Field Explanation

* **Form Title** (1, text, optional): Enter a title for the form that describes the purpose of the site visit.
* **Category** (2, select_one, optional): Select the category for the form as "Monitoring Forms" or "Other Forms".
* **Description** (3, text, optional): Provide a brief description of the site visit.
* **Description (English)** (4, text, optional): Enter a description of the site visit in English.
* **Site ID** (5, number, optional): Enter the site ID number.
* **Site Name** (6, text, optional): Enter the name of the site.
* **Site Address** (7, text, optional): Enter the address of the site.
* **Site Contact** (8, text, optional): Enter the contact information for the site.
* **Visit Frequency** (9, select_one, optional): Select the visit frequency from the options provided or specify "Other (please specify)" if not listed.
* **Visit Start Date** (10, date, optional): Enter the start date of the site visit, if applicable.
* **Visit End Date** (11, date, optional): Enter the end date of the site visit, if applicable.
* **Site Visit Comments** (12, text, optional): Provide any additional comments about the site visit.
* **Site Visit Photos** (13, note, optional): Attach any relevant photos to the site visit.
* **Attachments** (14, text, optional): Attach any files related to the site visit.
* **Site Visit Other Details** (15, text, optional): Enter any other relevant details about the site visit.
* **Form Submission Notes** (16, note, optional): Enter any submission notes about the form.
* **Site Visit Suggestions** (17, text, optional): Enter any suggestions for future site visits.
* **Visit Frequency (English)** (18, text, optional): Enter the visit frequency in English.
* **Other (please specify)** (19, text, optional): Enter any other visit frequency not listed.
* **Email** (20, email, optional): Enter the email address of the submitter.
* **Phone** (21, text, optional): Enter the phone number of the submitter.
* **Site Visit Status** (22, select_multiple, optional): Indicate the status of the site visit as "Pending", "In Progress", or "Completed".
* **Site Visit Scheduled Date** (23, date, optional): Enter the scheduled date of the site visit, if applicable.
* **Site Visit Scheduled Time** (24, time, optional): Enter the scheduled time of the site visit, if applicable.
* **Submitter** (25, text, optional): Enter the name of the submitter.

## Tips

* Ensure that all fields are completed accurately and completely.
* If a field is not applicable, leave it blank.
* Attach relevant photos and files to provide context to the site visit.
* Enter any additional comments or suggestions to help future site visits.
* Use the "Other (please specify)" option for frequencies not listed.
* Check the status of the site visit and update it accordingly.
* Enter the submitter's name and contact information accurately.
