# Fire Safety Hazard Assessment - Help Guide
## Purpose
The Fire Safety Hazard Assessment form is designed to help facility managers or building owners identify potential fire safety hazards in their facility. This form is used to assess the presence or absence of certain fire safety features and risks.

## How To Complete This Form

To complete this form, follow these steps:

1. Review each field carefully and provide the requested information for your specific fire safety assessment.
2. Answer each question truthfully, and if unsure, please provide a best-effort answer.
3. Ensure that you have access to the required information before proceeding.

## Field-by-Field Explanation

* **Fire Safety Hazard Assessment**
	+ Label: Fire Safety Hazard Assessment
	+ Type: Note
	+ Required: No
	+ Description: A brief description of the fire safety hazard assessment being performed (e.g., annual fire safety inspection).
* **Fire Safety Hazard Risk**
	+ Label: Fire Safety Hazard Risk
	+ Type: Select One
	+ Required: No
	+ Description: Indicate if there is a fire safety hazard risk present (Yes/No).
* **Fire Hydrant System**
	+ Label: Fire Hydrant System
	+ Type: Select Multiple
	+ Required: No
	+ Description: Indicate if the fire hydrant system is present and functioning properly (Yes/No).
* **Fire Extinguisher**
	+ Label: Fire Extinguisher
	+ Type: Text
	+ Required: No
	+ Description: Enter the number of fire extinguishers available on the premises.
* **Fire Supervision Plan**
	+ Label: Fire Supervision Plan
	+ Type: Number
	+ Required: No
	+ Description: Enter the number of fire supervision plans available on the premises.
* **Fire Drill Procedure**
	+ Label: Fire Drill Procedure
	+ Type: Select One
	+ Required: No
	+ Description: Indicate if a fire drill procedure is in place (Yes/No).
* **Fire Safety Training**
	+ Label: Fire Safety Training
	+ Type: Text
	+ Required: No
	+ Description: Enter the number of fire safety training records available on the premises.
* **Emergency Contact**
	+ Label: Emergency Contact
	+ Type: Email
	+ Required: No
	+ Description: Enter the email address of the emergency contact person.
* **Fire Inspector**
	+ Label: Fire Inspector
	+ Type: Select Multiple
	+ Required: No
	+ Description: Indicate if a fire inspector is on site or assigned to the facility (Yes/No).
* **Fire Inspection Frequency**
	+ Label: Fire Inspection Frequency
	+ Type: Select One
	+ Required: No
	+ Description: Indicate if fire inspections are performed at regular intervals (Yes/No).

## Tips

* Be honest and thorough when completing this form to ensure accurate fire safety hazard assessment.
* Review and update your submission regularly to reflect any changes in fire safety features or risks.
* If unsure about any field, please provide a best-effort answer or consult with the relevant authorities.
