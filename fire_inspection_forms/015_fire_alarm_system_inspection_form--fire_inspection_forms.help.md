# Fire Alarm System Inspection Form - Help Guide
## Purpose

The Fire Alarm System Inspection Form is used to inspect and record the results of fire alarm system tests. This form helps track and report the status of fire alarm systems, ensuring they are functioning correctly and in compliance with relevant regulations.

## How To Complete This Form

1. Fill in the form completely and accurately.
2. For "System Type", select all applicable types of fire alarm systems, such as sprinkler system, fire alarm system, or fire suppression system.
3. Mark "Installed" if the system is currently in operation.
4. If applicable, report the results of the latest annual test, including any notes or comments.
5. Indicate the frequency of annual testing, if required.
6. Report the date and time of the last test, including any notes or comments.
7. Enter any additional notes or comments about the last test.

## Field-by-Field Explanation

* **Fire Alarm System Inspection Form**: This is the title of the form.
* **System Type**: Select all types of fire alarm systems that apply to this inspection. Options include:
	+ Sprinkler system
	+ Fire alarm system
	+ Fire suppression system
* **Installed**: Mark this field if the system is currently in operation.
* **Alarm Annul Test Results**: Enter the results of the last annual test, including any notes or comments.
* **Last Test Date**: Enter the date of the last annual test.
* **Last Annual Test**: Mark this field if the last annual test was done.
* **System is in Operation**: Mark this field if the system is currently in operation.
* **System is Programmed to Annually Test**: Mark this field if the system is programmed to test annually.
* **System has Annually Test**: Mark this field if the system has undergone an annual test.
* **System is Tested Annually**: Mark this field if the system is tested annually.
* **System Annually Test Passed**: Mark this field if the last annual test was successful.
* **System Annually Test Failed**: Mark this field if the last annual test was not successful.
* **System Annually Test Not Required**: Mark this field if the system does not require annual testing.
* **System Annually Test Results Notes**: Enter any notes or comments about the results of the last annual test.
* **System Annually Test Frequency**: Select the frequency of annual testing for this system, options include:
	+ Weekly
	+ Monthly
	+ Quarterly
	+ Annually
* **System Annually Test Frequency Notes**: Enter any notes or comments about the frequency of annual testing.
* **System Annually Test Last Frequency**: Enter the last frequency of testing.
* **System Annually Test Last Frequency Notes**: Enter any notes or comments about the last frequency of testing.
* **System Annually Test Last Date**: Enter the date of the last annual test.
* **System Annually Test Last Date Notes**: Enter any notes or comments about the last test date.
* **System Annually Test Last Time**: Enter the time of the last test.
* **System Annually Test Last Time Notes**: Enter any notes or comments about the last test time.
* **System Annually Test Last Duration**: Enter the duration of the last test.
* **System Annually Test Last Duration Notes**: Enter any notes or comments about the last test duration.
* **Assigned To**: Enter the name and title of the person responsible for maintaining the fire alarm system.
