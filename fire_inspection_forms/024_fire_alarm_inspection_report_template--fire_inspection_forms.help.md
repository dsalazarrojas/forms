# Fire Alarm Inspection Report Template - Help Guide

## Purpose
This form is designed to collect information about fire alarm systems, including their inspection details, installation, and maintenance. It is intended to be used by inspectors to report on the status of fire alarm systems in various locations.

## How To Complete This Form

1. Ensure you have the necessary information and resources to complete the form accurately.
2. Read each field carefully to understand the required information.
3. Fill in the required fields with the correct information.
4. Submit the completed form for review and further action.

## Field-by-Field Explanation

* **Fire Alarm Inspection Report Template** (`fire_alarm_inspection_report_template`, text, required): This is the title of the form, which should be filled in accurately to reflect the purpose of the form.
* **Malfunctioning Fire Alarm System** (`malfunctioning_system`, select_one, required): Check the box if the fire alarm system is malfunctioning.
* **Inspection Date** (`inspection_date`, date, required): Enter the date of the inspection in the correct format (yyyy-mm-dd).
* **Inspector's Name** (`inspector_name`, text, required): Enter your name as the inspector.
* **Inspector's Signature** (`inspector_signature`, note, optional): This field is intended for your signature, but is not required.
* **Fire Alarm System Manufacturer** (`fire_alarm_system_manufacturer`, text, optional): Enter the manufacturer of the fire alarm system, if known.
* **Fire Alarm System Model** (`fire_alarm_system_model`, text, required): Enter the model number of the fire alarm system.
* **Fire Alarm System Model Year** (`fire_alarm_system_model_year`, number, optional): Enter the model year of the fire alarm system, if known.
* **Fire Alarm System Installation Date** (`fire_alarm_system_installation_date`, date, required): Enter the date of the fire alarm system's installation.
* **Fire Alarm Inspection Location** (`fire_alarm_inspection_location`, select_multiple, required): Select all locations where the fire alarm system was inspected.
* **Fire Alarm Inspection Time** (`fire_alarm_inspection_time`, time, optional): Enter the time of the inspection, if known.
* **Fire Alarm Servicing Company** (`fire_alarm_servicing_company`, text, optional): Enter the name of the company that services the fire alarm system, if known.
* **Fire Alarm Serial Number** (`fire_alarm_serial_number`, text, optional): Enter the serial number of the fire alarm system, if known.
* **Fire Alarm System Warranty** (`fire_alarm_system_warranty`, select_one, required): Check the box if the fire alarm system is under warranty.
* **Fire Alarm System Warranty Expiration Date** (`fire_alarm_system_warranty_expiration_date`, date, optional): Enter the expiration date of the fire alarm system's warranty, if known.
* **Comments** (`comments`, note, optional): Enter any additional comments or notes regarding the fire alarm system inspection.
