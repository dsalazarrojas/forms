# influencer_contest_authorization_form - Help Guide
## Purpose
This form is designed for internal use within a company or organization to collect information from influencers related to a contest or campaign. It helps in gathering details about the brand, contest type, start and end dates, location, and contact information.

## How To Complete This Form
To complete this form, follow these steps:

1.  Enter the brand name you represent in the "Brand Name" field.
2.  Select the type of contest or campaign you are participating in from the "Contest Type" dropdown options.
3.  If applicable, input the start and end dates of the contest in the respective fields.
4.  Enter the location related to the contest in the "Location" field.
5.  Provide any additional contact information in the "Contact Info" field.

## Field-by-Field Explanation
*   **Brand Name** (Brand Name, text, optional): Enter the name of the brand you represent.
*   **Contest Type** (Contest Type, select_one, required): Select the type of contest or campaign you are participating in. Options include choice a, choice b, and choice c.
*   **Start Date** (Start Date, date, optional): If the contest has a start date, enter it here.
*   **End Date** (End Date, date, optional): If the contest has an end date, enter it here.
*   **Location** (Location, text, optional): Input the location related to the contest.
*   **Contact Info** (Contact Info, text, optional): Enter any additional contact information for the contest.

## Tips
*   Ensure all required fields are completed to submit the form successfully.
*   If a contest type is not specified or not known, please choose the most relevant option available.
