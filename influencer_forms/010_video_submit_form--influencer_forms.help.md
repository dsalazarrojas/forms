# Video Submit Form - Help Guide

## Purpose

This video submit form is designed to collect metadata and information about a video from an influencer or content creator. The form will help you collect title, description, tags, categories, and other details about the video.

## How To Complete This Form

1. Fill out the "Video Title" field with the title of the video.
2. Provide a brief description of the video in the "Video Description" field.
3. For "Upload Video", please enter the video ID or upload the video file if required.
4. If applicable, select the relevant tags for the video.
5. Choose the categories that best describe the video.
6. Click the "Submit" button to complete the form.

## Field-by-Field Explanation

* **Submit Video** (text): Enter a short title for the video.
* **Video Title** (text): Enter a brief title for the video.
* **Video Description** (text): Enter a short description for the video.
* **Upload Video** (text): Enter the video ID or upload the video file if required.
* **Tags** (select multiple): Select relevant tags for the video, such as 'Yes' or 'No' if applicable.
* **Categories** (select multiple): Choose the categories that best describe the video.
* **Category** (text): Enter a specific category for the video.
* **Video ID** (text): Enter the video ID.
* **Upload Video Hint** (text): Not applicable for user input.
* **Submit Video Hint** (text): Not applicable for user input.
* **Tag hint** (text): Not applicable for user input.
* **Category Hint** (text): Not applicable for user input.
* **Submit** (text): Click to submit the form after filling out all required fields. 

## Tips

* Ensure that you fill out all required fields before submitting the form.
* Double-check that you select the correct tags and categories for the video.
* If you are not sure about a category or tag, you can ask for clarification or advice.
* Please ensure that the video title and description accurately represent the content of the video.
