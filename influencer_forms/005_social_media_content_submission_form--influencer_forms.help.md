# social_media_content_submission_form - Help Guide
## Purpose
This form is used to collect metadata about social media content submissions, such as the platform on which it was posted, the type of content, and other relevant details.

## How To Complete This Form
To complete this form, simply follow these steps:

1. Select the social media platform where the content was posted (Step 1: Social Media Platforms).
2. Choose the type of content that was posted (Step 2: Content Type).
3. (Optional) Select additional platforms where the content was posted (Step 3: Client Platforms).
4. Specify how often the content was posted (Step 4: Post Frequency).
5. Enter the time of posting (Step 5: Post Time).
6. Enter the date of posting (Step 6: Post Date).
7. Select the status of the post (Step 7: Post Status).
8. Describe the content in brief (Step 8: Description).
9. Enter the URL of the content (Step 9: URL).
10. Tag the content with relevant hashtags (Step 10: Tags).
11. Upload any associated image (Step 11: Image).

## Field-by-Field Explanation
* **Social Media Platforms** (Step 1): Select the platform on which the content was posted. Choose from the list of available platforms: Instagram, Facebook, Twitter, TikTok, or YouTube.
* **Client Platforms** (Step 3): If applicable, select any other platforms where the content was also posted.
* **Content Type** (Step 2): Choose the type of content that was posted, such as text, image, or video.
* **Post Frequency** (Step 4): Specify how often the content was posted, using a number to indicate the frequency (e.g. 1, 2, 3 times, etc.).
* **Post Time** (Step 5): Enter the time of posting using the 24-hour clock format (e.g. 14:30).
* **Post Date** (Step 6): Enter the date of posting using the YYYY-MM-DD format (e.g. 2022-02-15).
* **Post Status** (Step 7): Select the status of the post, such as draft, published, or archived.
* **Description** (Step 8): Enter a brief description of the content.
* **URL** (Step 9): Enter the URL of the content if applicable.
* **Tags** (Step 10): Choose relevant hashtags to tag the content, such as #hashtag1, #hashtag2, etc.
* **Image** (Step 11): If applicable, upload an associated image with the content.
