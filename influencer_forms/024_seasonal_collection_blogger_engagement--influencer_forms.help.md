# seasonal_collection_blogger_engagement - Help Guide
## Purpose
This form is used to collect information about blogger engagement related to seasonal collections.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the Seasonal Campaign that the blogger is participating in or has participated in.
2. Choose the social media links that the blogger uses.
3. Enter the blogger's Email address.
4. Enter the blogger's Phone number.
5. Choose the preferred outreach method(s) for the blogger.
6. (Optional) Provide any additional notes about the blogger.
7. If applicable, select the date and time when the engagement was created and updated.

## Field-by-Field Explanation

### Bloggers (1)
- **Bloggers**: This field is where you will enter the name or identifier of the blogger.
	+ Type: Text field
	+ Required: No
	+ Hint: Not required, but can be useful to identify the blogger.

### Seasonal Campaign (2)
- **Seasonal Campaign**: This field is where you will select the campaign that the blogger is participating in or has participated in.
	+ Type: Select one field
	+ Required: Yes
	+ Hint: Select the campaign that is relevant to the blogger's engagement.

### Social media links (3)
- **Social media links**: This field is where you will select the social media platforms that the blogger uses.
	+ Type: Select multiple field
	+ Required: Yes
	+ Hint: Select all applicable social media platforms that the blogger uses.

### Email (4)
- **Email**: This field is where you will enter the blogger's email address.
	+ Type: Email field
	+ Required: Yes
	+ Hint: Enter the blogger's primary email address.

### Phone (5)
- **Phone**: This field is where you will enter the blogger's phone number.
	+ Type: Text field
	+ Required: Yes
	+ Hint: Enter the blogger's primary phone number.

### Outreach Preferences (6)
- **Outreach Preferences**: This field is where you will choose the preferred outreach method(s) for the blogger.
	+ Type: Select multiple field
	+ Required: No
	+ Hint: Choose how you would like to contact the blogger (e.g., phone, email, mail).

### Note (7)
- **Note**: This field is for additional notes about the blogger.
	+ Type: Text field
	+ Required: No
	+ Hint: Use this field for any additional information that may be relevant to the blogger's engagement.

### Created (8)
- **Created**: This field is for the date and time when the engagement was created.
	+ Type: Date field
	+ Required: No
	+ Hint: This field is only applicable if you want to track the creation date and time of the engagement.

### Updated (9)
- **Updated**: This field is for the date and time when the engagement was updated.
	+ Type: Time field
	+ Required: No
	+ Hint: This field is only applicable if you want to track the last update date and time of the engagement.

### Data (10)
- **Data**: This field is for any additional information about the blogger.
	+ Type: Text field
	+ Required: No
	+ Hint: Use this field for any additional data that may be relevant to the blogger's engagement.
