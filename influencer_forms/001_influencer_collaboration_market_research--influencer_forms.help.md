# Influencer Collaboration Market Research - Help Guide
## Purpose
This form is designed to collect information for the creation and management of influencer collaboration market research. It captures critical data such as form name, category, description, and output file type to create and configure market research forms tailored to specific needs.

## How To Complete This Form
1. Ensure you're familiar with the form's purpose and that it's not already available in the system.
2. Fill in the required fields marked as "true" under the "Required" column in the form's schema.
3. For the "Category" field, select the correct category from the provided options.
4. For the "Form Description" field, provide a detailed description of the form.
5. Select the correct "Output File" type from the provided options.
6. Enter a valid "Category ID" if it's not auto-generated.
7. Enter a description for the "Category Description" field if needed.
8. Enter relevant keywords for the "Category Keywords" field if needed.
9. Optionally, enter a description for the "Form Description" field.
10. Review and submit the form once all required fields are filled.

## Field-by-Field Explanation

* **Form Name (text, required)**: Enter a unique and descriptive name for the form.
* **Category (select_one, required)**: Select the category for the form from the provided options.
* **Description (note, not required)**: Provide a detailed description of the form.
* **Form ID (number, not required)**: Enter a valid ID for the form.
* **Assigned Tool (select_one, not required)**: Select the tool assigned to the form.
* **Output File (select_one, required)**: Select the output file type for the form.
* **Category ID (number, required)**: Enter a valid category ID.
* **Category Description (text, not required)**: Enter a description for the category.
* **Category Keywords (text, not required)**: Enter relevant keywords for the category.
* **Form Description (text, not required)**: Provide a description of the form.
* **Form Name is duplicated on the Category page as Form Name field 1 (text, required)**: Enter a unique and descriptive name for the form.
* **Other fields may have been excluded from this explanation due to the provided schema structure not specifying a label, but they should be filled based on the intended use and purpose of the form**.
