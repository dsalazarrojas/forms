# Influencer Partnership Extension Form - Help Guide
## Purpose
This form is used to request an extension of an existing influencer partnership. It is intended for brands and their representatives to provide additional information to support their extension request.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill in your brand's name and the name of the campaign you are requesting an extension for.
2. Select the start and end dates of the extension period.
3. Provide a brief description of the reason for the extension request.
4. Select the type of brand (e.g., Option 1, Option 2, or Option 3).
5. Select the partner agreement (e.g., Option 1 or Option 2).
6. Add any relevant notes or comments.
7. If applicable, provide the contact information of your brand manager and partner manager.
8. Finally, provide the reason for termination of the partnership, if applicable.

## Field-by-Field Explanation
* **Brand Name** (1): Enter the name of your brand.
* **Campaign Name** (2): Enter the name of the campaign you are requesting an extension for.
* **Start Date** (3): Select the start date of the extension period.
* **End Date** (4): Select the end date of the extension period.
* **Description** (5): Provide a brief description of the reason for the extension request.
* **Brand Type** (6): Select the type of brand you are representing (e.g., Option 1, Option 2, or Option 3).
* **Contact Person** (7): Enter the name of the person who will be the point of contact for your brand.
* **Contact Phone** (8): Enter the phone number of the contact person.
* **Partner Agreement** (9): Select the type of agreement you are using (e.g., Option 1 or Option 2).
* **Notes** (10): Add any additional notes or comments.
* **Email** (11): Enter the email address of the brand manager.
* **Phone Number** (12): Enter the phone number of the brand manager.
* **Address** (13): Enter the physical address of the brand manager.
* **Agreement** (14): Enter any relevant agreement details.
* **Extension Type** (15): Select the type of extension being requested (e.g., Option 1, Option 2, or Option 3).
* **Reason For Extension** (16): Provide a brief description of the reason for the extension request.
* **Expected End Date** (17): Select the expected end date of the extension period.
* **Reason For Termination** (18): Provide a brief description of the reason for termination of the partnership, if applicable.
* **Comments** (19): Add any additional comments.
* **Brand Manager** (20): Enter the name of the brand manager.
* **Brand Manager Email** (21): Enter the email address of the brand manager.
* **Brand Manager Phone** (22): Enter the phone number of the brand manager.
* **Brand Manager Address** (23): Enter the physical address of the brand manager.
* **Partner Manager** (24): Enter the name of the partner manager.
* **Partner Manager Email** (25): Enter the email address of the partner manager.
