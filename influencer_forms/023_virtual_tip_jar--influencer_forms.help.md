# Virtual Tip Jar - Help Guide
## Purpose

This form is designed to be used in service-based industries where service workers interact directly with customers. It allows users to create a virtual tip jar, collecting tips for service workers.

## How To Complete This Form

1. Fill out the form completely. The form has several fields to collect information and provide feedback.
2. Start by selecting the "Service Worker" field, where you can enter the name of the service worker.
3. Next, enter the "Tip Amount" field with the amount of tip you'd like to give.
4. Choose the "Tip Currency" from the available options (USD, CAD, EUR).
5. In the "Tip Message" field, write any message you'd like to include with the tip (optional).
6. Enter the "Service Worker Email" field with the service worker's email address.
7. If you'd like to add any additional contact information for the service worker, enter their phone number in the "Service Worker Phone" field.
8. If the service worker doesn't have a standard tool assigned, select "other" in the "Assigned Tool" field and enter the specific tool in the "Other" field.

## Field-by-Field Explanation

* **Service Worker** (service_worker_service_worker, text, optional): Enter the name of the service worker you'd like to give a tip to.
* **Tip Amount** (tip_amount, number, optional): Enter the amount of tip you'd like to give (e.g., 5.00).
* **Tip Currency** (tip_currency, select_one, optional): Choose the currency of the tip (USD, CAD, EUR).
* **Tip Message** (tip_message, note, optional): Write a message to include with the tip (optional).
* **Service Worker Email** (service_worker_email, email, optional): Enter the service worker's email address.
* **Service Worker Phone** (service_worker_phone, text, optional): Enter the service worker's phone number.
* **Assigned Tool** (assigned_tool, select_one, optional): Select whether the service worker has a standard tool assigned or "other".
* **Other** (assigned_tool_other, text, optional): If "other" is selected, enter the specific tool used by the service worker.
