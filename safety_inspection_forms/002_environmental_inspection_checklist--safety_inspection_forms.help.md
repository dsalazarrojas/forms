# environmental_inspection_checklist - Help Guide
## Purpose
This form is designed to collect safety inspection information about a building's environment and fire extinguishing system. Completing this form will help identify potential risks and guide the implementation of preventive measures to minimize harm.

## How To Complete This Form
1. Ensure you have the necessary permissions and authorization to complete this form.
2. Carefully read each section and answer all questions accurately.
3. Fill in the required fields with the relevant information.
4. Select the correct options for select fields.
5. Add any additional notes or comments where applicable.

## Field-by-Field Explanation
* **Building Address** (`building_address`, text, optional): Enter the building's address, which is necessary for location-specific safety and emergency response.
* **Building Type** (`building_type`, select_one, optional): Select the type of building, such as "Building", "Residential", "Commercial", or "Industrial".
* **Date of last Inspection** (`date_of_last_inspection`, date, optional): Enter the date of the last environmental inspection.
* **Time of last Inspection** (`time_of_last_inspection`, time, optional): Enter the time of the last environmental inspection.
* **Building Age** (`building_age`, number, optional): Enter the building's age.
* **Building Use** (`building_use`, select_one, optional): Select the building's use, such as "Building", "Residential", "Commercial", or "Industrial".
* **Building Location** (`building_location`, text, optional): Enter the building's location.
* **Contact Person** (`contact_person`, text, optional): Enter the contact person's name and title.
* **Contact Phone** (`contact_phone`, text, optional): Enter the contact person's phone number.
* **Building Area** (`building_area`, text, optional): Enter the building's area.
* **Number of Floors** (`number_of_floors`, number, optional): Enter the number of floors in the building.
* **Building Height** (`building_height`, number, optional): Enter the building's height.
* **Fire Extinguishing System** (`fire_extinguishing_system`, select_multiple, optional): Select the status of the fire extinguishing system, such as "Working", "Non-Working", or "N/A".
* **Fire Extinguishing System 2** (`fire_extinguishing_system_2`, select_multiple, optional): Select the status of the fire extinguishing system 2, such as "Working", "Non-Working", or "N/A".
* **Fire Extinguishing System Notes** (`fire_extinguishing_system_notes`, note, optional): Add any notes or comments about the fire extinguishing system.
* **Fire Extinguishing System Description** (`fire_extinguishing_system_description`, text, optional): Enter a description of the fire extinguishing system.
* **Fire Extinguishing System Location** (`fire_extinguishing_system_location`, text, optional): Enter the location of the fire extinguishing system.
* **Sprinkler System Status** (`sprinkler_system_status`, select_one, optional): Select the status of the sprinkler system, such as "Active" or "Inactive".
* **Electrical Systems** (`electrical_systems`, text, optional): Enter any notes or comments about the electrical systems.
* **Fire Extinguishing System Type** (`fire_extinguishing_system_type`, select_multiple, optional): Select the type of fire extinguishing system, such as "Wet Pipe System" or "Dry Pipe System".
* **Fire Extinguishing System Description 2** (`fire_extinguishing_system_description_2`, text, optional): Enter a description of the fire extinguishing system 2.
* **Electrical Systems Notes** (`electrical_systems_notes`, note, optional): Add any notes or comments about the electrical systems.
* **Fire Extinguishing System Testing** (`fire_extinguishing_system_testing`, select_one, optional): Select whether the fire extinguishing system has been tested, such as "True" or "False".
* **Fire Extinguishing System Testing Frequency** (`fire_extinguishing_system_testing_frequency`, select_multiple, optional): Select the testing frequency of the fire extinguishing system, such as "Annually" or "Bi-Annually".
* **Fire Extinguishing System Testing Frequency 2** (`fire_extinguishing_system_testing_frequency_2`, select_multiple, optional): Select the testing frequency 2 of the fire extinguishing system.
