# Fire Alarm System Monthly Check - Help Guide
## Purpose
The purpose of this form is to document the monthly safety inspection of the fire alarm system in your facility. This includes checking the system's status, testing its functionality, and recording important details about the inspection process.

## How To Complete This Form
1. **Monthly Check**: Start by confirming that you have conducted the monthly check on the fire alarm system. This field is optional and allows you to acknowledge that you have performed the check.
2. **System Status**: Select the status of the system from the available options. This is a critical field as it helps identify any issues with the system.
3. **System Tested**: Select which tests were performed on the system. This helps in identifying what needs to be checked and what has been checked already.
4. **Details**: Provide any additional details about the tests performed. This can include any issues or observations noted during the inspection.
5. **Fire Alarm Tested**: Enter the date the fire alarm system was tested. This is an important field to record when the test was conducted.
6. **Time Tested**: Enter the time the system was tested. Make sure to use the 24-hour clock format.
7. **Battery Status**: Select the status of the system's battery, which can be Good, Low, or Unknown. This field is crucial as it ensures the system's power supply is adequate.
8. **Battery Capacity**: Select the capacity of the system's battery, which can be High, Medium, or Low. This ensures the system can function correctly in case of an emergency.
9. **Inspection Frequency**: Select how often the system is inspected, which can be Monthly, Bi-Monthly, or Quarterly. This field helps in scheduling future inspections.
10. **Inspection Next Scheduled**: Enter the date of the next scheduled inspection. This ensures the system is checked at regular intervals.
11. **Inspection Next Scheduled Time**: Enter the time of the next scheduled inspection. Use the 24-hour clock format.
12. **Last Tested**: Select when the system was last tested, which can be 1, 2, or 3 months ago. This helps in tracking when the system was last inspected.
13. **Last Tested Date**: Enter the date the system was last tested.
14. **Technician's Name**: Enter the name of the technician who performed the inspection and testing.
15. **Technician's Phone**: Enter the phone number of the technician who performed the inspection.
16. **Comments**: Add any comments or notes about the inspection process or the system.
17. **Signature**: Sign off on the inspection, indicating that you have completed it accurately.
18. **Facility**: Enter the name of the facility where the system is located.
19. **Building**: Enter the building where the system is located.
20. **Location**: Enter the specific location within the building where the system is installed.
21. **Notes**: Add any additional notes about the inspection or system.
22. **Additional Notes**: Add any extra comments or observations from the inspection.
23. **Action Plan**: Document any actions that need to be taken based on the inspection results.
24. **Action Plan Implementation**: Document the plan to implement any actions identified.
25. **Next Action**: Identify what actions are pending based on the inspection results, which can be None, Scheduled, or In Progress.

## Tips
- Always follow the standard procedures for conducting monthly checks on the fire alarm system.
- Be thorough and accurate when completing the form to ensure the system's status and any issues are recorded correctly.
- Consult with your supervisor or someone familiar with the process if you have any doubts or questions about the form.
