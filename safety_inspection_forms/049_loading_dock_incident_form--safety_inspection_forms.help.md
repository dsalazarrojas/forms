# Loading Dock Incident Form - Help Guide

## Purpose

This form is designed to collect information about loading dock incidents, including incident dates, descriptions, types, locations, witness presence and statements, injuries, damage amounts and descriptions, causes, and corrective actions taken.

## How To Complete This Form

1.  Select the date the incident occurred from the date picker.
2.  Enter a brief description of the incident in the description field.
3.  Indicate if the incident was of type "Yes" or "No" using the incident_type field.
4.  List all locations involved in the incident using the select_multiple format in the incident_location field.
5.  Check the witness box for each witness present at the incident. Enter the number of witnesses in the witness_count field. Provide a statement from each witness in the witness statement field.
6.  Check the injury box for each witness. Enter the severity of injury using the select_multiple format in the incident_injuries field.
7.  Enter the amount of damage using the number format in the damage_amount field.
8.  Provide a brief description of the damage using the damage description field.
9.  Choose the cause of the incident using the select_one format in the incident_cause field.
10. Enter a description of the incident cause using the incident_cause_description field.
11.  If any corrective actions were taken, enter them in the corrective actions field.
12.  Finally, select the person or team member assigned to the incident using the assigned field.
