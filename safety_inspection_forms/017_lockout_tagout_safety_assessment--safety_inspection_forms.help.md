# Lockout Tagout Safety Assessment - Help Guide
## Purpose
The Lockout Tagout Safety Assessment form is a tool used to evaluate the effectiveness and compliance of lockout/tagout procedures for equipment in your facility. This form is essential in identifying potential hazards and ensuring that all necessary safety measures are in place for equipment shutdowns and startups.
## How To Complete This Form

1. Please select "Lockout and Tagout" for the lockout procedure type if your facility uses standard procedures for shutdown and startup of equipment.
2. For other procedures not listed, select "Other - Specify" and provide details in the "Hazards Identified" field.
3. Identify any hazards or risks associated with the equipment during inspection. Select all applicable hazards from the "Hazards Identified" field.
4. List any employee responsibilities identified during the inspection in the "Employee Responsibilities" field. Select all applicable employees from the list.
5. Specify the equipment location where the inspection was performed.
6. Select the type of equipment inspected (e.g., machine, tool, or other).
7. Indicate the type of lockout/tagout tag used.
8. Specify the location of the lockout/tagout tag (e.g., on the equipment, near the equipment, or other).
9. Enter the lockout/tagout tag number (if applicable).
10. Specify the location of the lockout/tagout tag number (e.g., on the equipment, near the equipment, or other).
11. Identify the person or department responsible for maintenance supervision.
12. Select "True" if the lockout/tagout procedure is documented.
13. Select "True" if the lockout/tagout procedure has been trained.
14. Select "True" if the lockout/tagout tag location has been verified.
15. Select "True" if lockout/tagout tag verification is required.
16. Select "True" if maintenance supervision verification is required.
17. Select "True" if the lockout/tagout tag is verified.
18. Select "True" if the lockout/tagout procedure is verified.
19. Select "True" if the lockout/tagout safety assessment is verified.

## Tips

* Please complete this form carefully and accurately to ensure a thorough assessment of the lockout/tagout procedures.
* If you're unsure about any field, refer to your facility's lockout/tagout procedures manual or consult with a supervisor.
* Make sure to select "True" or "False" for questions that require verification.
* If you select "Other - Specify" for any field, provide a brief description of the alternative procedure used.
* Review your answers before submitting the form to ensure accuracy and completeness.
