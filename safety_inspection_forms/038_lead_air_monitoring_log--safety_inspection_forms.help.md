# Lead Air Monitoring Log - Help Guide
## Purpose
The Lead Air Monitoring Log is designed to collect data on lead monitoring at various job sites. This form is used to track and record important data for analysis and reporting.

## How To Complete This Form
1. Choose the correct job sites from the "Job Sites" dropdown list on each page.
2. Enter the date of the monitoring in the "Date" field.
3. Select the correct sampling location and method for each location from the respective dropdown lists.
4. Enter the number of samples collected and the lead reading values for each location.
5. Repeat the process for each location.

## Field-by-Field Explanation
* **Job Sites**: Select all the job sites that were monitored. This field is used to choose which job sites you want to monitor.
* **Date**: Enter the date of the monitoring. This field is used to track when the monitoring took place.
* **Sampling Location**: Select the correct location where the monitoring took place. This field is used to track the location where the samples were collected.
* **Sampling Method**: Select the correct method used for sampling. This field is used to track the method used for sampling.
* **Samples Collected**: Enter the number of samples collected at each location. This field is used to track the number of samples collected.
* **Lead Reading**: Enter the lead reading values for each location. This field is used to track the lead reading values.
* **Sampling Location 2**, **Sampling Method 2**, **Samples Collected 2**, **Lead Reading 2**, etc.: Repeat the process for each location.
* **Note**: Please ensure that you are filling out the correct location for each page and field.
