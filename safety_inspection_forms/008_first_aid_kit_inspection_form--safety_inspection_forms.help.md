# first aid kit inspection form - Help Guide
## Purpose

The purpose of this form is to collect information about the inspection of a first aid kit. This form is used to ensure that the first aid kit is properly inspected and reported on.

## How To Complete This Form

To complete this form, follow these steps:

1. Answer all questions carefully and accurately.
2. Ensure that you have the necessary information about the first aid kit available.
3. Check off any items that are present and in good condition.
4. Check off any items that are missing or not in good condition.
5. Complete any necessary fields for reporting.

## Field-by-Field Explanation

* **Location** (`location`): Enter the location where the first aid kit was inspected (e.g., office, school, hospital, etc.).
* **First Aid Kit Location** (`first_aid_kit_location`): Enter the physical location of the first aid kit (e.g., on a wall, in a cabinet, etc.).
* **Kit Contents** (`kit_contents`): Select all items that are present in the first aid kit (e.g., Kit A, Kit B, Kit C, etc.).
* **First Aid Kit Contents** (`kit_contents_checklist`): Select all items that are present in the first aid kit (e.g., Bandages, Antiseptic wipes, Antihistamine, etc.).
* **First Aid Kit Contents** (`kit_contents_checklist`): Select whether the first aid kit contains any of the items listed (e.g., Yes/No).
* **First Aid Kit Contents** (`first_aid_kit_contents`): Select whether the first aid kit contains any of the items listed (e.g., Yes/No).
* **Date Checked** (`date_checked`): Enter the date the first aid kit was inspected.
* **Checked By** (`checked_by`): Enter the name of the person who inspected the first aid kit.

## Tips

* Make sure to inspect the first aid kit regularly and report any discrepancies.
* If any items are missing or not in good condition, replace or repair them as necessary.
* Keep the first aid kit in a clean, dry, and accessible location.
* Make sure to follow all relevant regulations and procedures when inspecting and maintaining the first aid kit.
