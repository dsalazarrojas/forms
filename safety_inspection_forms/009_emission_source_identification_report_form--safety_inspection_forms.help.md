# Emission Source Identification Report Form - Help Guide
## Purpose
The Emission Source Identification Report Form is used to collect information about observed emission sources in a facility. This form helps identify and track emission sources, which are sources that release pollutants into the environment.

## How To Complete This Form
To complete this form, follow these steps:

1. Select all observed emission sources for the facility from the "Observed Emission Sources" field.
2. Enter the Facility ID, Emission Source ID, and other relevant information for each observed emission source.
3. Choose the Reporting Frequency (e.g., 1 day, 1 week, Monthly) and select the Reported Date and Reported Time for each emission source.
4. Enter the Reporting Location and Reporter Name, and include any additional Reporting Notes if necessary.
5. Enter the Facility Name, Address, Phone, Email, and Notes for the facility.
6. Enter the Emission Source Name, Address, Phone, Email, and Notes for each emission source.
7. Choose the Facility Status (Active, Inactive, Unknown) and Emission Source Status (Active, Inactive, Unknown) for each facility and emission source.
8. Select the Facility Type (Industrial, Commercial, Residential) and Emission Source Type (Industrial, Commercial, Residential) for each facility and emission source.
9. Choose the Facility Category (Yes, No) and Emission Source Category (Yes, No) for each facility and emission source.
10. Review and submit the form to report the observed emission sources.

## Field-by-Field Explanation
* **Observed Emission Sources**: Select all observed emission sources for the facility from the list.
* **Facility ID**: Enter the ID of the facility.
* **Emission Source ID**: Enter the ID of the emission source.
* **Reporting Frequency**: Choose the frequency of reporting (e.g., 1 day, 1 week, Monthly) for each emission source.
* **Reporting Frequency (Other)**: Enter any other reporting frequency not listed in the options.
* **Reported Date**: Enter the date the emission source was reported.
* **Reported Time**: Enter the time the emission source was reported.
* **Reporting Location**: Enter the location where the emission source was reported.
* **Reporter Name**: Enter the name of the person reporting the emission source.
* **Reporter Contact**: Enter the contact information for the person reporting the emission source.
* **Reporting Notes**: Enter any additional notes about the reported emission source.
* **Facility Name**: Enter the name of the facility.
* **Facility Address**: Enter the address of the facility.
* **Facility Phone**: Enter the phone number of the facility.
* **Facility Email**: Enter the email of the facility.
* **Facility Notes**: Enter any additional notes about the facility.
* **Facility Status**: Choose the status of the facility (Active, Inactive, Unknown).
* **Emission Source Name**: Enter the name of the emission source.
* **Emission Source Address**: Enter the address of the emission source.
* **Emission Source Phone**: Enter the phone number of the emission source.
* **Emission Source Email**: Enter the email of the emission source.
* **Emission Source Notes**: Enter any additional notes about the emission source.
* **Emission Source Status**: Choose the status of the emission source (Active, Inactive, Unknown).
* **Facility Type**: Choose the type of facility (Industrial, Commercial, Residential).
* **Emission Source Type**: Choose the type of emission source (Industrial, Commercial, Residential).
* **Facility Category**: Choose whether or not the facility is a category (Yes, No).
* **Emission Source Category**: Choose whether or not the emission source is a category (Yes, No).
