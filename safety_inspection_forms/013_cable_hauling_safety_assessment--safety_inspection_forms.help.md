# Cable Hauling Safety Assessment - Help Guide
## Purpose
The Cable Hauling Safety Assessment form is designed to evaluate the safety of cable hauling systems in various locations. The form ensures that all necessary checks are performed to guarantee the safe operation of the system.

## How To Complete This Form
1. Fill in the inspector's name, date of inspection, and site location to identify the inspector and location of the assessment.
2. Choose the type of cable system being inspected.
3. Evaluate the condition of the cable, anchor points, and pulley system.
4. Confirm if the load capacity has been verified and if safety devices are present and functional.
5. Check if emergency brakes have been tested and if operators are properly certified.
6. Record any safety hazards identified and necessary corrective actions.
7. Determine if the overall safety assessment is safe to operate.

## Field-by-Field Explanation

* **Inspector Name (1)**: Enter the name of the safety inspector performing the assessment.
* **Inspection Date (2)**: Enter the date of the safety assessment.
* **Site Location (3)**: Enter the site location where the cable hauling system is being used.
* **Company Name (4)**: Enter the name of the contracting company.
* **Cable System Type (5)**: Choose the type of cable hauling system being inspected.
* **Cable Diameter (6)**: Select the size of the main cable.
* **Cable Condition (7)**: Evaluate the overall condition of the cable.
* **Anchor Points Inspected (8)**: Confirm if all anchor points were checked.
* **Cable Tension Check (9)**: Check if the cable is properly tensioned.
* **Pulley System Condition (10)**: Evaluate the state of the pulleys and sheaves.
* **Load Capacity Verified (11)**: Confirm if the load capacity has been verified.
* **Safety Devices Present (12)**: Confirm if all safety devices are present and functional.
* **Emergency Brake Tested (13)**: Confirm if the emergency brake has been tested.
* **Operator Certification (14)**: Confirm if the operator is properly certified.
* **PPE Compliance (15)**: Check if workers are wearing proper PPE.
* **Weather Conditions (16)**: Record the weather conditions during the inspection.
* **Hazards Identified (17)**: List any safety hazards found.
* **Corrective Actions (18)**: Enter any necessary corrective actions.
* **Overall Safety Assessment (19)**: Determine if the system is safe to operate.
* **Next Inspection Date (20)**: Enter the date of the next required inspection.
* **Inspector Signature (21)**: Enter the inspector's signature or initials.
* **Additional Notes (22)**: Record any other safety observations.
