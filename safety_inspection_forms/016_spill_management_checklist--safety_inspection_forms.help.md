# Spill Management Checklist - Help Guide

## Purpose
This form is designed to collect and document information related to spills, such as the location, description, and response to the incident. It helps in maintaining a safe working environment and ensuring compliance with safety regulations.

## How To Complete This Form

1. **Spill Incident Form**: This is the main section for describing the incident. Please provide a brief description of what happened.
2. **Spill Location**: Please provide the exact location where the spill occurred.
3. **Spill Date/Time**: Enter the date and time when the spill occurred.
4. **Spill Size**: Please select the appropriate size of the spill from the options provided:
	* Small
	* Medium
	* Large
5. **Spill Type**: Select the type of spill that occurred:
	* Chemical
	* Oil
	* Water
6. **Spill Response**: Briefly describe the action taken in response to the spill.
7. **Spill Documentation**: If any documentation or evidence related to the spill is available, please attach it here.

## Field-by-Field Explanation

* **Spill Incident Form** (`spill_incident_form`, text, not required): A brief description of the spill incident.
* **Spill Location** (`spill_location`, text, not required): The exact location where the spill occurred.
* **Spill Description** (`spill_description`, text, not required): A detailed description of what happened during the spill.
* **Spill Date/Time** (`spill_date_time`, date, not required): The date and time when the spill occurred.
* **Spill Size** (`spill_size`, select_multiple, not required): The size of the spill. Options: Small, Medium, Large.
* **Spill Type** (`spill_type`, select_one, not required): The type of spill. Options: Chemical, Oil, Water.
* **Spill Response** (`spill_response`, text, not required): A brief description of the action taken in response to the spill.
* **Spill Documentation** (`spill_documentation`, text, not required): Any documentation or evidence related to the spill.
