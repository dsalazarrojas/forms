# Smoke Detector Inspection Form - Help Guide
## Purpose
This form is designed to gather information about the status of smoke detectors in various locations.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill in the Inspection Location page with the location where the smoke detector is installed.
2. On the next page, enter the details about the smoke detector:
   * Smoke Detector ID 1: Enter the identification number of the first smoke detector.
   * Smoke Detector ID 2: Enter the identification number of the second smoke detector (if applicable).
   * Inspection Date: Enter the date of the inspection using the calendar tool.
   * Inspection Time: Enter the time of the inspection using the clock tool.
   * Smoke Detector Status 1: Select the status of the first smoke detector:
     - Not functioning
     - Operating
     - Not present
   * Smoke Detector Status 2: Select the status of the second smoke detector (if applicable):
     - Not functioning
     - Operating
     - Not present
   * Inspection Note: Enter any additional notes about the inspection.

## Field-by-Field Explanation
- **Inspection Location**: Enter the location where the smoke detector is installed.
- **Smoke Detector ID 1**: Enter the identification number of the first smoke detector.
- **Smoke Detector ID 2**: Enter the identification number of the second smoke detector (if applicable).
- **Inspection Date**: Enter the date of the inspection using the calendar tool.
- **Inspection Time**: Enter the time of the inspection using the clock tool.
- **Smoke Detector Status 1**: Select the status of the first smoke detector:
  - Not functioning: The smoke detector is not working properly.
  - Operating: The smoke detector is working correctly.
  - Not present: The smoke detector is not present in the location.
- **Smoke Detector Status 2**: Select the status of the second smoke detector (if applicable):
  - Not functioning: The smoke detector is not working properly.
  - Operating: The smoke detector is working correctly.
  - Not present: The smoke detector is not present in the location.
- **Inspection Note**: Enter any additional notes about the inspection.
