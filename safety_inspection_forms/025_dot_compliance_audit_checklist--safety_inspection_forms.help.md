# DOT Compliance Audit Checklist - Help Guide
## Purpose
The DOT Compliance Audit Checklist is a form used to collect information about a vehicle's registration status, driver's qualifications, and vehicle condition.

## How To Complete This Form
To complete this form, follow the instructions below:

1. Select the correct options from the dropdown menus for each section.
2. Enter any required text fields with the correct information.
3. Ensure that all required fields are completed before submitting the form.

## Field-by-Field Explanation
### Vehicle Registration (ID 1)
* **Vehicle Registration**: Select the current status of the vehicle's registration (Active, Inactive, or Expired).
### Driver License (ID 2)
* **Driver License**: Select all driver licenses that apply (Active or Inactive).
### Vehicle Inspection (ID 3)
* **Vehicle Inspection**: Select the result of the vehicle's last inspection (Passed or Failed).
### Vehicle Equipment (ID 4)
* **Vehicle Equipment**: Select the condition of the vehicle's equipment (Good, Fair, or Poor).
### Vehicle Maintenance (ID 5)
* **Vehicle Maintenance**: Select whether the vehicle is maintained regularly (Yes or No).
### Vehicle Defect (ID 6)
* **Vehicle Defect**: Select whether the vehicle has any defects (Yes or None).
### Vehicle Weight (ID 8)
* **Vehicle Weight**: Enter the weight of the vehicle.
### Vehicle Length (ID 9)
* **Vehicle Length**: Enter the length of the vehicle.
### Vehicle Width (ID 10)
* **Vehicle Width**: Enter the width of the vehicle.
### Vehicle Height (ID 11)
* **Vehicle Height**: Enter the height of the vehicle.
### Vehicle Speed Limit (ID 12)
* **Vehicle Speed Limit**: Select the speed limit of the vehicle (0, 10, 20, or 30).
### Vehicle Gross Weight Rating (ID 13)
* **Vehicle Gross Weight Rating**: Select the class of the vehicle (Class A, Class B, or Class C).
### Vehicle Use (ID 14)
* **Vehicle Use**: Select all applicable uses of the vehicle (Passenger or Cargo).
### Year (ID 15)
* **Year**: Enter the year of the vehicle.
### Make (ID 16)
* **Make**: Enter the make of the vehicle.
### Model (ID 17)
* **Model**: Enter the model of the vehicle.
### Vehicle VIN (ID 18)
* **Vehicle VIN**: Enter the Vehicle Identification Number of the vehicle.
### Driver Name (ID 19)
* **Driver Name**: Enter the name of the driver.
### Driver Address (ID 20)
* **Driver Address**: Enter the address of the driver.
### Vehicle Type (ID 21)
* **Vehicle Type**: Select all applicable types of vehicles (Tractor or Trailer).
### Driver License Number (ID 22)
* **Driver License Number**: Enter the driver's license number.
### Vehicle License Plate (ID 23)
* **Vehicle License Plate**: Enter the license plate number of the vehicle.
### Driver License State (ID 24)
* **Driver License State**: Enter the state of the driver's license.
### Vehicle Inspection Date (ID 25)
* **Vehicle Inspection Date**: Enter the date of the last vehicle inspection.

Note: The above fields are required and must be completed for the form to be submitted.
