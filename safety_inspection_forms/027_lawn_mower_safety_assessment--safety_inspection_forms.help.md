# lawn_mower_safety_assessment - Help Guide
## Purpose
This form is designed to assess the safety of lawn mowers used for various purposes. It helps operators and supervisors evaluate the safety status of lawn mowers and identify any potential hazards that may need attention.

## How To Complete This Form
1. Read each field carefully and answer all questions accurately.
2. If a field is not applicable, select the "Not Applicable" option.
3. If you are unsure about any question, please ask your supervisor or refer to the relevant safety guidelines.

## Field-by-Field Explanation

### Page 1: Operator Precedence
* **Is Operator Preceded** (`operator_precedence`, select_multiple, required/optional): This question helps to identify if the operator is preceded by the manufacturer or a supervisor. Select all applicable options.
	+ Operator is preceded by the manufacturer
	+ Operator is not preceded by the manufacturer
	+ Operator is not preceded by manufacturer or a coworker
	+ Other, please specify

### Page 2: Personal Protection Equipment
* **Personal Protection Equipment** (`personal_protection_equipment`, select_one, required/optional): This question determines if the operator has access to and is using necessary personal protection equipment. Select the correct option.
	+ Helmet
	+ Safety glasses
	+ Ear protection
	+ Gloves
	+ None of the above

### Page 3: Mower Condition
* **Lawn Mower Condition** (`mower_condition`, select_multiple, required/optional): This question helps to identify if the mower is well-maintained or not. Select all applicable options.
	+ Well-maintained
	+ Not well-maintained
	+ Not applicable

### Page 4: Fuel Type
* **Type of Fuel** (`fuel_type`, select_one, required/optional): This question determines if the mower uses gasoline, diesel, or electric fuel. Select the correct option.
	+ Gasoline
	+ Diesel
	+ Electric
	+ Other, please specify

### Page 5: Fuel Capacity
* **Fuel Capacity** (`fuel_capacity`, number, required/optional): This question helps to record the fuel capacity of the mower. Enter the capacity in gallons.

### Page 6: Hours Worked
* **Hours Worked** (`hours_worked`, number, required/optional): This question records the number of hours the operator has worked with the mower. Enter the total hours.

### Page 7: Date of Last Maintenance
* **Date of Last Maintenance** (`date_of_last_maintenance`, date, required/optional): This question determines the date of the last maintenance of the mower. Enter the date.

### Page 8: Date of Last Training
* **Date of Last Training** (`date_of_last_training`, date, required/optional): This question determines the date of the last training the operator received. Enter the date.

### Page 9: Mower Type
* **Type of Mower** (`mower_type`, select_one, required/optional): This question determines the type of mower being used. Select the correct option.
	+ Walk-behind
	+ Walk-behind with attachment
	+ Ride-on
	+ Other, please specify

### Page 10: Operator Experience
* **Operator Experience** (`operator_experience`, select_one, required/optional): This question helps to identify the operator's experience level. Select the correct option.
	+ Less than 1 year
	+ 1-2 years
	+ 3-5 years
	+ More than 5 years

### Page 11: Hazard Control Precautions
* **Hazard Control Precautions** (`hazard_control_precautions`, select_one, required/optional): This question determines if precautions are taken while using the mower. Select the correct option.
	+ Precautions taken
	+ No precautions taken
	+ Not applicable

### Page 12: Safety Equipment
* **Safety Equipment** (`safety_equipment`, select_multiple, required/optional): This question determines if the operator has access to and uses necessary safety equipment. Select all applicable options.
	+ Hardhat
	+ Safety glasses
	+ Ear protection
	+ Gloves
	+ None of the above

### Page 13: Supervisor Information
* **Supervisor Name** (`supervisor_name`, text, required/optional): This question asks for the name of the supervisor.
* **Supervisor Phone** (`supervisor_phone`, text, required/optional): This question asks for the supervisor's phone number.
* **Supervisor Email** (`supervisor_email`, email, required/optional): This question asks for the supervisor's email.
* **Supervisor Department** (`supervisor_department`, text, required/optional): This question asks for the supervisor's department.

### Page 14: Operator Comments
* **Operator Comments** (`operator_comments`, note, required/optional): This question allows the operator to provide comments or concerns.

### Page 15: Supervisor Comments
* **Supervisor Comments** (`supervisor_comments`, note, required/optional): This question allows the supervisor to provide comments or concerns.

### Page 16: Equipment Maintenance
* **Is Equipment Maintenance Needed** (`is_equipment_maintenance_needed`, select_one, required/optional): This question determines if the equipment needs maintenance. Select the correct option.
	+ 'True'
	+ 'False'
* **Equipment Maintenance Description** (`equipment_maintenance_description`, text, required/optional): This question asks for a description of the equipment maintenance needed.

### Page 17: Submission Information
* **Date Submitted** (`date_submitted`, date, required/optional): This question determines the date the form was submitted.
* **Approved by** (`approved_by`, text, required/optional): This question asks for the name of the person approving.
* **Submitted by** (`submitted_by`, select_one, required/optional): This question determines who submitted the form. Select the correct option.
	+ Employee
	+ Supervisor
	+ Other, Please Specify
* **Submitted By Phone** (`submitted_by_phone`, text, required/optional): This question asks for the phone number of the person submitting.

## Tips
* Complete the form thoroughly and accurately.
* Refer to relevant safety guidelines if unsure about any questions.
* If a field is not applicable, select the "Not Applicable" option.
* Ensure the information provided is up-to-date and accurate.
* Review the form carefully before submission.
