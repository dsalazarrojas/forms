# Safety Plan Template - Help Guide
## Purpose
The Safety Plan Template is designed to help create and maintain safety plans and procedures for your workplace. This guide will walk you through each field of the form to help you complete it correctly.

## How To Complete This Form
To complete this form, follow these general steps:

1. Fill out the required fields.
2. Select the correct options for each field based on your workplace's safety procedures and plans.
3. Review your answers carefully to ensure accuracy and completeness.

## Field-by-Field Explanation
### Category (category, id: 2)
* Label: category
* Required: yes
* Explanation: Select "Yes" if this safety plan is related to a specific category of safety procedures. This will help organize and filter your safety plans in the system.

### Description (description, id: 3)
* Label: description
* Required: no
* Explanation: Provide a brief description of the safety plan or procedure being created or updated. This will help identify the plan's purpose and content.

### Safety Procedures (safety_procedures, id: 6)
* Label: safety_procedures
* Required: yes
* Explanation: Select "Yes" for each safety procedure that is part of this safety plan.

### Safety Plan Status (safety_plan_status, id: 13)
* Label: safety_plan_status
* Required: yes
* Explanation: Select "Active" or "Inactive" to indicate the current status of the safety plan.

### Next Safety Check (next_safety_check, id: 15)
* Label: next_safety_check
* Required: no
* Explanation: Select the date for the next planned safety check.

### Next Safety Check Time (next_safety_check_time, id: 16)
* Label: next_safety_check_time
* Required: no
* Explanation: Select the time for the next planned safety check.

### Next Safety Check (next_safety_check_date, id: 25)
* Label: next_safety_check_date
* Required: no
* Explanation: Select the date for the next planned safety check.

### Assigned Tool (assigned_tool, id: 4)
* Label: assigned_tool
* Required: no
* Explanation: Select "Yes" if a tool is assigned to this safety plan or procedure.

### Assigned Safety Equipment (assigned_safety_equipment, id: 9)
* Label: assigned_safety_equipment
* Required: no
* Explanation: Select "Yes" for each safety equipment that is assigned to this safety plan or procedure.

### Assigned Safety Equipment Description (assigned_safety_equipment_description, id: 10)
* Label: assigned_safety_equipment_description
* Required: no
* Explanation: Provide a brief description of the assigned safety equipment.

### Safety Equipment Status (safety_equipment_status, id: 11)
* Label: safety_equipment_status
* Required: no
* Explanation: Select "Active" or "Inactive" to indicate the status of assigned safety equipment.

### Safety Equipment Status Description (safety_equipment_status_description, id: 12)
* Label: safety_equipment_status_description
* Required: no
* Explanation: Provide a brief description of the safety equipment status.

### Assigned Safety User (assigned_safety_user, id: 19)
* Label: assigned_safety_user
* Required: no
* Explanation: Select "Yes" if a safety user is assigned to this safety plan or procedure.

### Next Safety Check User (next_safety_check_user, id: 20)
* Label: next_safety_check_user
* Required: no
* Explanation: Select "Yes" if a user is assigned to the next safety check.

### Safety Plan Review Date (safety_plan_review_date, id: 21)
* Label: safety_plan_review_date
* Required: no
* Explanation: Select the date for the safety plan review.

### Safety Plan Review Time (safety_plan_review_time, id: 22)
* Label: safety_plan_review_time
* Required: no
* Explanation: Select the time for the safety plan review.

### Assigned Safety Reviewer (assigned_safety_reviewer, id: 24)
* Label: assigned_safety_reviewer
* Required: no
* Explanation: Select "Yes" if a safety reviewer is assigned to this safety plan or procedure.

Please note that some fields may be hidden or disabled based on your selection in other fields, such as the Assigned Tool or Assigned Safety Equipment fields. Be sure to review your answers carefully to avoid errors.
