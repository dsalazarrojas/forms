# Snow Conditions Report - Help Guide
## Purpose
The Snow Conditions Report is a form used to gather data about snow conditions on a specific area or location. This report is likely intended for use by personnel responsible for snow-related operations such as snow removal, maintenance, or emergency response. 
## How To Complete This Form
1. Please ensure the form is not already completed for the same location and time period.
2. Fill in the required and optional fields as described below.

## Field-by-Field Explanation
* **snow_depth** (1, number, required: false): Report the depth of the snow on the ground, if any.
* **snow_ice_cover** (2, text, required: true): Describe the presence and type of ice cover, if any.
* **snow_surface_type** (3, select_one, required: false): Check if the snow surface is 'Yes' or 'No'. This field likely indicates whether the snow has a surface type that is relevant for operations or response.
* **avalanche_forecast** (4, date, required: false): Enter the date of the avalanche forecast, if applicable.
* **snow_snowpack** (5, select_multiple, required: true): Select 'Yes' for any of the following that apply:
	+ 'Yes'
* **snow_temperature** (6, number, required: false): Report the temperature of the snow, if applicable.
* **snow_wind** (7, select_one, required: true): Select 'Yes' or 'No' to indicate if there is wind.
* **snow_comments** (8, note, required: false): Enter any additional comments or notes related to snow conditions. 

## Tips
Please fill in all required fields (snow_ice_cover, snow_snowpack, snow_wind).
