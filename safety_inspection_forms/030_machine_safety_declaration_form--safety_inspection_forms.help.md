# Machine Safety Declaration Form - Help Guide
## Purpose
The Machine Safety Declaration Form is used to collect information about each machine in use, ensuring that it complies with safety standards and regulations. This form helps in maintaining accurate records and preventing accidents.

## How To Complete This Form
To complete this form, follow these steps:

1. Review the machine's details, type, and manufacturer.
2. Enter the machine's serial number.
3. Provide the machine's model.
4. List the safety standards and features of the machine.
5. Enter any user input or comments.
6. Select the options that apply to your machine.

## Field-by-Field Explanation

* **Machine Details**: Enter a brief description of the machine, including its name, location, and any other relevant details.
* **Machine Type**: Specify the type of machine, e.g., crane, excavator, etc.
* **Serial Number**: Enter the serial number of the machine, if available.
* **Manufacturer**: Enter the name and address of the machine's manufacturer.
* **Model**: Enter the model number of the machine.
* **Safety Standards**: List the safety standards and features that are applicable to this machine, e.g., CE, UL, etc.
* **Safety Features**: List any additional safety features installed on the machine.
* **User Input**: Enter any comments or notes about the machine.
* **Submit Options**: Select the options that apply to your machine, e.g., Option 1, Option 2, etc.
