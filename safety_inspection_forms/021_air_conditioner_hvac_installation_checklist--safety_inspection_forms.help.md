# Air Conditioner (HVAC) Installation Checklist - Help Guide
## Purpose
The purpose of this form is to ensure that all necessary steps are taken during the installation of air conditioners (HVAC) and other related equipment. This form guides the technician through the process of documenting and verifying the installation, including pre-installation inspections, electrical and refrigerant checks, and post-installation testing.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the form for each air conditioner installation, using the provided template as a guide.
2. Ensure that all fields are filled out accurately and completely.
3. Review each section carefully to ensure that all necessary steps are taken and all requirements are met.
4. Sign off on the form once all sections are complete and satisfactory.

## Field-by-Field Explanation

* **Technician Name**: Full name of installing technician, required for tracking and accountability.
* **Technician ID**: Employee or license number of the installing technician, required for verification and tracking.
* **Installation Date**: Date of installation, required for record-keeping and maintenance scheduling.
* **Customer Name**: Full name of the customer, required for communication and record-keeping.
* **Installation Address**: Full address of the installation, required for site visits and maintenance scheduling.
* **Unit Type**: Type of HVAC unit being installed, select from options: Central air conditioner, Heat pump, Ductless mini-split, Window unit, Package unit, Commercial rooftop.
* **Unit Brand**: Manufacturer brand of the unit, required for warranty and support purposes.
* **Unit Model Number**: Model number of the unit, required for warranty and support purposes.
* **Unit Serial Number**: Serial number of the unit, required for warranty and support purposes.
* **Unit Capacity (tons)**: Cooling capacity of the unit, required for sizing and performance verification.
* **SEER Rating**: Seasonal Energy Efficiency Ratio of the unit, required for energy efficiency verification.
* **Pre-Installation Inspection Completed**: Was site inspected before installation, select from options: True, False.
* **Electrical Requirements Verified**: Were electrical specs met, select from options: True, False, Not applicable.
* **Refrigerant Lines Check**: Are lines properly installed, select from options: True, False, Not applicable.
* **Ductwork Inspection**: Condition of existing ductwork, select from options: Good condition, Fair condition, Poor condition, New ductwork installed, Not applicable.
* **Thermostat Installed**: Was thermostat installed, select from options: Yes, new, Yes, existing used, False.
* **Thermostat Type**: Type of thermostat, select from options: Manual, Programmable, Smart/WiFi, Not applicable.
* **Condensate Drain Check**: Is drain properly connected, select from options: Yes, properly installed, Yes, needs adjustment, False, Not applicable.
* **Airflow Measurement (CFM)**: Measured airflow, required for performance verification.
* **Refrigerant Charge Verified**: Is charge correct, select from options: True, False, Adjusted.
* **Suction Pressure (PSI)**: Measured suction pressure, optional for advanced performance verification.
* **Head Pressure (PSI)**: Measured head pressure, optional for advanced performance verification.
* **Temperature Differential (F)**: Return vs supply temp difference, required for performance verification.
* **Safety Controls Tested**: Were all safety controls verified, select from options: Yes, all tested, Some tested, False.
* **Unit Level and Secure**: Is unit properly mounted, select from options: True, False.
* **Insulation Check**: Is insulation properly installed, select from options: True, False, Not applicable.
* **Customer Instruction Provided**: Did you explain operation to customer, select from options: True, False.
* **Manual and Documentation Provided**: Were manuals given to customer, select from options: True, False.
* **Work Area Cleaned**: Was area cleaned after installation, select from options: True, False.
* **Final Test Run Completed**: Was system tested in all modes, select from options: True, False.
* **Issues Found**: Any issues during installation, optional for reporting purposes.
* **Technician Signature**: Digital signature of the installing technician, required for verification and record-keeping.
* **Customer Signature**: Customer approval signature, required for verification and record-keeping.
* **Checklist Status**: Overall completion status, select from options: Complete, all items passed, Complete, minor issues noted, Incomplete, follow-up needed.
