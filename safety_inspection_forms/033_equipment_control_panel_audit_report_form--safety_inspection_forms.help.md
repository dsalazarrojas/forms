# Equipment Control Panel Audit Report Form - Help Guide
## Purpose
The Equipment Control Panel Audit Report Form is used to document the results of an inspection or audit of an equipment control panel. The form is used to identify any issues or concerns with the equipment, its condition, and provide recommendations for improvement or repair.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the equipment ID number in the "Equipment ID" field. This is the unique identifier for the equipment.
2. Enter the location where the equipment is installed in the "Location" field.
3. Select "Yes" or "No" for "Panel Type" to indicate if the panel is functioning correctly.
4. For "Condition", select all that apply from the list to describe the equipment's current state.
5. Enter any findings or observations in the "Findings" field.
6. Select "Yes" or "No" for "Recommendations" to indicate if any are needed.
7. Enter the date the audit was completed in the "Date Completed" field.
8. Select "Yes" or "No" for "Completed By" to indicate who completed the audit.

## Field-by-Field Explanation
* **Equipment ID** (`equipment_id`, text, not required): Enter the unique identifier for the equipment, as provided by the manufacturer or supplier.
* **Location** (`location`, text, not required): Enter the location where the equipment is installed, e.g., room number, floor, or building name.
* **Panel Type** (`panel_type`, select_one, not required): Select "Yes" if the panel is functioning correctly, "No" otherwise.
* **Condition** (`panel_condition`, select_multiple, not required): Select all that apply to describe the equipment's current state, e.g., dirty, malfunctioning, or in need of repair.
* **Findings** (`findings`, text, not required): Enter any notable findings or observations about the equipment.
* **Recommendations** (`recommendations`, select_multiple, not required): Select "Yes" if any recommendations are needed, and describe them in the "Findings" field.
* **Date Completed** (`date_completed`, date, not required): Enter the date the audit was completed, in the format YYYY-MM-DD.
* **Completed By** (`completed_by`, select_multiple, not required): Select "Yes" if you completed the audit, "No" otherwise.

## Tips
* Make sure to provide accurate and detailed information when completing this form.
* Review the equipment's manual and relevant documentation before filling out the form.
* If you are unsure about any information, consult with the equipment's manufacturer or supplier.
