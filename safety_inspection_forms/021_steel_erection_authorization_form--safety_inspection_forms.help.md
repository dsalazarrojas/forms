# Steel Erection Authorization Form - Help Guide
## Purpose
This form is used to collect information related to steel erection activities, including project details, personnel involved, and authorization.

## How To Complete This Form

1.  Select the correct project number from the provided options.
2.  Enter the date of acceptance, which is the date the project was accepted by the client.
3.  Enter the date of completion, which is the date the project was finished.
4.  Enter the name of the contractor's supervisor.
5.  Enter the name of the site supervisor.
6.  Enter the authorization date.
7.  Enter the authorization hours.
8.  For optional fields:
    8.1.  Enter the crane capacity if applicable.
    8.2.  Enter the crane operating location.
    8.3.  Enter the crane operating area.
    8.4.  Enter the crane height if applicable.
    8.5.  Enter the crane weight if applicable.
    8.6.  Enter the crane description if applicable.
    8.7.  Enter the crane type if applicable.
    8.8.  Enter the crane operator's name if applicable.
    8.9.  Enter the crane operator's phone number if applicable.
    8.10.  Enter the crane location if applicable.
    8.11.  Enter the crane hours if applicable.
    8.12.  Enter crane notes if applicable.
    8.13.  Enter the safety inspector's name if applicable.
    8.14.  Enter the safety inspector's signature if applicable.
    8.15.  Enter the authorized person's name if applicable.
    8.16.  Enter the authorized date if applicable.
    8.17.  Enter the authorized hours if applicable.
    8.18.  Enter remarks if applicable.

## Field-by-Field Explanation

*   **Project Number** (`project_number`, `number`, required): Enter the project number for which you are collecting this information.
*   **Date Of Acceptance** (`date_of_acceptance`, `date`, required): Enter the date the project was accepted by the client.
*   **Date Of Completion** (`date_of_completion`, `date`, required): Enter the date the project was finished.
*   **Contractor Supervisor Name** (`contractor_supervisor_name`, `text`, required): Enter the name of the contractor's supervisor.
*   **Site Supervisor Name** (`site_supervisor_name`, `text`, required): Enter the name of the site supervisor.
*   **Authorization Date** (`authorization_date`, `date`, required): Enter the date of authorization.
*   **Authorization Hours** (`authorization_hours`, `number`, required): Enter the authorization hours.
*   **Crane Capacity** (`crane_capacity`, `text`, optional): Enter the crane capacity if applicable.
*   **Crane Operating Location** (`crane_operating_location`, `text`, optional): Enter the crane operating location if applicable.
*   **Crane Operating Area** (`crane_operating_area`, `text`, optional): Enter the crane operating area if applicable.
*   **Crane Height** (`crane_height`, `number`, optional): Enter the crane height if applicable.
*   **Crane Weight** (`crane_weight`, `number`, optional): Enter the crane weight if applicable.
*   **Crane Description** (`crane_description`, `text`, optional): Enter the crane description if applicable.
*   **Crane Type** (`crane_type`, `text`, optional): Enter the crane type if applicable.
*   **Crane Operator Name** (`crane_operator_name`, `text`, optional): Enter the crane operator's name if applicable.
*   **Crane Operator Phone Number** (`crane_operator_phone_number`, `text`, optional): Enter the crane operator's phone number if applicable.
*   **Crane Location** (`crane_location`, `text`, optional): Enter the crane location if applicable.
*   **Crane Hours** (`crane_hours`, `time`, optional): Enter the crane hours if applicable.
*   **Crane Notes** (`crane_notes`, `note`, optional): Enter crane notes if applicable.
*   **Safety Inspector Name** (`safety_inspector_name`, `text`, optional): Enter the safety inspector's name if applicable.
*   **Safety Inspector Signature** (`safety_inspector_signature`, `text`, optional): Enter the safety inspector's signature if applicable.
*   **Authorized Person** (`authorized_person`, `text`, optional): Enter the authorized person's name if applicable.
*   **Authorized Date** (`authorized_date`, `date`, optional): Enter the authorized date if applicable.
*   **Authorized Hours** (`authorized_hours`, `time`, optional): Enter the authorized hours if applicable.
*   **Remarks** (`remarks`, `text`, optional): Enter remarks if applicable.
