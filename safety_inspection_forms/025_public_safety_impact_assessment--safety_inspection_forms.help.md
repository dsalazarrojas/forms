# Public Safety Impact Assessment - Help Guide
## Purpose
The Public Safety Impact Assessment form is used to evaluate the potential risks and impacts of a project on public safety. This form is designed to help project teams identify and assess potential risks and mitigation measures related to public safety.

## How To Complete This Form
To complete this form, please follow these steps:

1. Enter the name of the project in the "project-name" field.
2. Select the location where the project will take place from the dropdown menu.
3. Identify the level of risk associated with the project by selecting from the "risk-level" dropdown menu.
4. In the "Risk Assessment" field, provide a detailed description of the potential risks associated with the project.
5. If applicable, list any mitigation measures that can be taken to reduce or eliminate the risks identified in the "Risk Assessment" field.

## Field-by-Field Explanation

* **project-name** (project-name, text, required): This is the name of the project that is being assessed. Please enter the name of the project in this field.
* **location** (location, select_one, required): This is the location where the project will take place. Please select the correct option from the dropdown menu.
* **risk-level** (risk-level, select_multiple, required): This is the level of risk associated with the project. Please select from the dropdown menu to identify the risk level (Low, Medium, High).
* **Risk Assessment** (Risk Assessment, text, required): This is a detailed description of the potential risks associated with the project. Please provide a clear and concise explanation of the risks identified.
* **Mitigation Measures** (Mitigation Measures, text, optional): This is an optional field where you can list any mitigation measures that can be taken to reduce or eliminate the risks identified. If no mitigation measures are available, please leave this field blank.
