# Manual Handling Safety Assessment - Help Guide
## Purpose
The Manual Handling Safety Assessment form is used to gather information about manual handling tasks, their associated risks, and the necessary next steps to ensure a safe working environment.

## How To Complete This Form
To complete this form, follow these steps:

1. Review the form sections carefully and ensure you have a good understanding of the questions being asked.
2. For each field, select the most appropriate response based on your knowledge and judgment.

## Field-by-Field Explanation

* **Introduction** (Introduction): A note section where you can provide any background information related to the manual handling task being assessed.

* **Manual Handling Tasks** (`manual_handling_tasks`): This field allows you to select all relevant manual handling tasks associated with the assessed task. If you are unsure of the tasks involved, please describe them in the introduction field.

* **Risks Assessed** (`risks_assessed`): Select the level of risk associated with the manual handling task. The options are:
	+ High: The task poses significant risks to the person performing it.
	+ Low: The task poses minimal risks to the person performing it.
	+ Moderate: The task poses some risks to the person performing it.

* **Assessment Frequency** (`assessment_frequency`): Select how often the manual handling task is assessed. The options are:
	+ Yes: The task is regularly assessed.
	+ No: The task is not regularly assessed.

* **Next Steps** (`next_steps`): This field allows you to select all necessary next steps to complete the assessment. If you are unsure of the steps involved, please describe them in the introduction field.

* **Training Required** (`training_required`): Select if training is required for the task or not. The options are:
	+ Yes: Training is necessary for the task.
	+ No: No training is required for the task.

* **Action Plan** (`action_plan`): Select all necessary actions to complete the assessment. If you are unsure of the actions involved, please describe them in the introduction field.

* **Follow-up** (`follow_up`): This field allows you to select all necessary follow-up actions to complete the assessment. If you are unsure of the steps involved, please describe them in the introduction field.

* **Review and Update** (`review_and_update`): Select if a review and update of the assessment is necessary. The options are:
	+ Yes: A review and update of the assessment is required.
	+ No: No review and update is required.

* **Training Program** (`training_program`): Select if a training program is required for the task. The options are:
	+ Yes: A training program is necessary for the task.
	+ No: No training program is required for the task.

Note: Ensure you answer all questions truthfully, and if you are unsure of any aspect of the assessment, please seek guidance from a qualified professional.
