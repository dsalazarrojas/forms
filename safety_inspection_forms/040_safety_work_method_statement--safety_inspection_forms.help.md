# Safety Work Method Statement - Help Guide
## Purpose

This form is used to collect and document information about a specific safety work method statement. It helps in maintaining a record of safety-related activities, projects, or tasks within an organization.

## How To Complete This Form

1. Fill in the **Title** field with a brief title or name of the safety work method statement.
2. Select the **Category** that best describes the type of safety work being performed (e.g., "Yes" for specific categories).
3. Provide a detailed **Description** of the safety work method statement, including its scope, objectives, and any other relevant details.
4. If necessary, add **Instructions** for carrying out the safety work method statement.
5. Enter the **Organization ID**, which might be an internal ID or a reference number specific to the organization's safety records.
6. Optionally, you can select an **Assigned Tool**, if applicable.
7. If required, specify the **Output File**, where the results or report of the safety work method statement will be stored.
8. (Not required) Fill in the **Form ID**, which might be a system-assigned ID or a reference number for tracking and record-keeping.

## Field-by-Field Explanation

* **Title** (text, required): Enter a brief title for the safety work method statement.
* **Category** (select_one, required): Select the category that best describes the type of safety work being performed.
	+ This field is essential for organizing and categorizing safety-related activities for easier reference and analysis.
* **Description** (text, required): Provide a detailed description of the safety work method statement, including its scope, objectives, and any other relevant information.
	+ This field helps in clearly understanding the safety work being performed and its goals.
* **Instructions** (text, optional): If necessary, add instructions for carrying out the safety work method statement.
	+ This field can be useful for reference when the safety work is being implemented.
* **Organization ID** (number, required): Enter the organization's ID or a reference number specific to the organization's safety records.
	+ This field helps in tracking and referencing the safety work method statement within the organization's records.
* **Assigned Tool** (text, optional): Select an assigned tool, if applicable.
	+ This field might be used for specific safety work that requires a particular tool or equipment.
* **Output File** (text, optional): Specify the output file where the results or report of the safety work method statement will be stored.
	+ This field is useful when the safety work method statement generates a report or document that needs to be tracked.
* **Form ID** (number, optional): Fill in the form ID, which might be a system-assigned ID or a reference number for tracking and record-keeping.
	+ This field might be used internally for system purposes and tracking.

## Tips

- Ensure the information in this form accurately reflects the safety work method statement.
- Review this guide before proceeding to ensure you understand the form's purpose and each field's requirements.
- If you have any further questions or concerns, please reach out to your organization's safety department or support team.
