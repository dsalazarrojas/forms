# Rope Access Daily Safety Checklist - Help Guide
## Purpose
The Rope Access Daily Safety Checklist is a tool designed to ensure that rope access work is performed safely. This form is meant to be used by rope access technicians to check their own safety and that of their team members before starting work at height.
## How To Complete This Form
To complete the form, follow these steps:
* Read each field carefully and select the correct option that applies to your situation.
* Make sure to answer all required fields (indicated by `required: true`).
* Review your answers for accuracy and completeness.
## Field-by-Field Explanation
* **Work at Height**: (`Work at Height`, `select_one`, `required: false`)
  Select whether you will be working at height.
  * Rope access only: Select this option if you will be working at height using rope access.
  * Ropeless access: Select this option if you will be working at height without using rope access.
* **Harness System**: (`Harness System`, `select_one`, `required: false`)
  Select the type of harness system you will be using:
  * Self-retrievable descent device: Select this option if you will be using a self-retrievable descent device.
  * Rope grab line: Select this option if you will be using a rope grab line.
  * Rope anchor: Select this option if you will be using a rope anchor.
  * No harness system: Select this option if you will not be using a harness system.
* **Fall Zone**: (`Fall Zone`, `select_one`, `required: false`)
  Select the fall zone you will be working in:
  * Fall zone 1: Select this option if you will be working in a fall zone 1.
  * Fall zone 2: Select this option if you will be working in a fall zone 2.
  * No fall zone: Select this option if you will not be in a fall zone.
* **Weather Conditions**: (`Weather Conditions`, `select_multiple`, `required: false`)
  Select the current weather conditions:
  * Clear: Select this option if the weather is clear.
  * Cloudy: Select this option if the weather is cloudy.
  * Rain: Select this option if it is raining.
  * Snow: Select this option if it is snowing.
  * Wind: Select this option if there is wind.
* **Personal Equipment**: (`Personal Equipment`, `select_multiple`, `required: false`)
  Select the personal equipment you will be using:
  * Hard hat: Select this option if you will be using a hard hat.
  * Safety harness: Select this option if you will be using a safety harness.
  * Safety glasses: Select this option if you will be using safety glasses.
  * Safety harness inspection checklist: Select this option if you will be using a safety harness inspection checklist.
* **Safety Procedures**: (`Safety Procedures`, `select_multiple`, `required: false`)
  Select the safety procedures you will be following:
  * Proper inspection: Select this option if you will be performing a proper inspection.
  * Correct usage: Select this option if you will be using the equipment correctly.
  * Emergency procedures: Select this option if you will be prepared for emergencies.
* **Team Leadership**: (`Team Leadership`, `select_multiple`, `required: false`)
  Select the team leadership you will be following:
  * Lead person: Select this option if you will be led by a lead person.
  * Assistant lead: Select this option if you will be led by an assistant lead.
  * Team member: Select this option if you will be part of a team.
* **Emergency Contacts**: (`Emergency Contacts`, `select_multiple`, `required: false`)
  Select the emergency contacts you have:
  * First aid kit: Select this option if you have a first aid kit available.
  * Emergency phone number: Select this option if you have an emergency phone number.
  * Emergency contact name: Select this option if you have an emergency contact name.
* **Rescue Equipment**: (`Rescue Equipment`, `select_multiple`, `required: false`)
  Select the rescue equipment you will be using:
  * Rope grab line: Select this option if you will be using a rope grab line.
  * Rescue line: Select this option if you will be using a rescue line.
  * Rescue device: Select this option if you will be using a rescue device.
* **Communication**: (`Communication`, `select_multiple`, `required: false`)
  Select the communication methods you will be using:
  * Two-way radio: Select this option if you will be using a two-way radio.
  * Cell phone: Select this option if you will be using a cell phone.
  * Radio phone: Select this option if you will be using a radio phone.
## Tips
* Make sure to answer all required fields before submitting the form.
* Review your answers for accuracy and completeness.
* Keep the form up-to-date with any changes in your situation.
