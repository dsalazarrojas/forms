# Trailer Towing Safety Checklist - Help Guide
## Purpose
This form is designed to gather information for a trailer towing safety inspection to ensure that the trailer and its equipment are in good working order before towing.

## How To Complete This Form
1. Fill out the form by following the instructions for each field.
2. Provide the required information for each field.
3. Review the form for completeness before submitting.

## Field-by-Field Explanation
* **Safety Pre-Inspection Checklist** (`title`, `text`, not required): This field serves as a title for the form and is not editable.
* **Driver Name** (`driver_name`, `text`, not required): Enter your name as the driver of the trailer.
* **Trailer Number** (`trailer_number`, `text`, not required): Enter the number of the trailer being inspected.
* **Towing Vehicle Type** (`towing_vehicle_type`, `select_one`, not required): Select the type of vehicle being used for towing (e.g., Tandem Axle, Single Axle).
* **Vehicle Weight** (`vehicle_weight`, `number`, not required): Enter the weight of the trailer in kilograms.
* **Cargo Securement Location** (`cargo_securement_location`, `text`, not required): Describe the location of any cargo securing equipment used.
* **Vehicle Condition** (`vehicle_condition`, `text`, not required): Describe the condition of the trailer and its equipment.
* **Trailer Brakes** (`trailer_brakes`, `select_multiple`, not required): Select all that apply:
	+ Good Working Order
	+ Poor or Inoperable
	+ N/A
* **Safety Helmets** (`safety_helmets`, `select_multiple`, not required): Select all that apply:
	+ True
	+ False
* **Seatbelts** (`seatbelts`, `select_multiple`, not required): Select all that apply:
	+ True
	+ False
* **Trailer Lighting System** (`trailer_lighting_system`, `select_multiple`, not required): Select all that apply:
	+ Working Order
	+ N/A
* **Trailer Refueling System** (`trailer_refueling_system`, `select_multiple`, not required): Select all that apply:
	+ Working Order
	+ N/A
* **Fire Extinguisher** (`fire_extinguisher`, `select_multiple`, not required): Select all that apply:
	+ Present
	+ Absent
* **First Aid Kit** (`first_aid_kit`, `select_multiple`, not required): Select all that apply:
	+ Present
	+ Absent
* **Safety Reflector** (`safety_reflector`, `select_multiple`, not required): Select all that apply:
	+ Present
	+ Absent
* **Safety Helmet** (`safety_helmet`, `select_multiple`, not required): Select all that apply:
	+ Present
	+ Absent
* **Trailer Number Plate** (`trailer_number_plate`, `text`, not required): Enter the number plate of the trailer.
* **Trailer License Plate** (`trailer_license_plate`, `text`, not required): Enter the license plate of the trailer.
* **Safety Inspection Date** (`safety_inspection_date`, `date`, not required): Enter the date of the safety inspection (format: YYYY-MM-DD).
* **Driver Signature** (`driver_signature`, `text`, not required): Sign your name as the driver of the trailer.
* **Safety Checklist** (`safety_checklist`, `text`, not required): Describe any safety checklists used during the inspection.
* **Safety Inspection Time** (`safety_inspection_time`, `time`, not required): Enter the time of the safety inspection (format: HH:MM).
* **Safety Inspection Location** (`safety_inspection_location`, `text`, not required): Describe the location of the safety inspection.
* **Driver Comment** (`driver_comment`, `text`, not required): Enter any comments from the driver.
* **Safety Inspector Name** (`safety_inspector_name`, `text`, not required): Enter the name of the safety inspector.
