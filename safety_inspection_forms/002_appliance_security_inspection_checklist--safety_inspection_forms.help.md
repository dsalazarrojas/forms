# Appliance Security Inspection Checklist - Help Guide
## Purpose
The Appliance Security Inspection Checklist is a tool for security inspectors to ensure a comprehensive and efficient inspection process.

## How To Complete This Form

1. Fill in the necessary contact information: 
   - **Inspection Date**: Enter the date when the security inspection took place.
   - **Inspection Time**: Indicate the time when the inspection began.
   - **Inspector Name**: Enter the full name of the security inspector.
   - **Inspector ID**: Provide the employee or badge identification number of the inspector.
   - **Location Name**: Type in the name of the facility or location being inspected.
   - **Location Address**: Enter the full address of the inspection site.

2. Select the **Appliance Category**: Choose the type of appliances at this location from the provided options (Kitchen Appliances, Laundry Appliances, HVAC Systems, Security Equipment, Mixed Categories).

3. Evaluate the status of **Electrical Safety Check**: Select the status of electrical connections and wiring from the options (Pass, Fail, Not Applicable).

4. Enter **Electrical Safety Notes**: Provide any additional notes about the electrical inspection, if necessary.

5. Check the status of **Physical Security Check**: Select the status of physical security measures from the options (Pass, Fail, Needs Improvement).

6. Verify the status of **Access Control Verification**: Choose the status of access control systems from the options (Verified, Not Verified, System Offline).

7. Check the status of **Surveillance Equipment Status**: Choose the status of surveillance cameras and monitors from the options (Fully Operational, Partially Operational, Non-Operational, Not Installed).

8. Check the status of **Fire Safety Equipment**: Select the status of fire extinguishers and alarms from the provided options (Inspected and Current, Needs Inspection, Expired, Not Present).

9. Ensure **Emergency Exits Clear**: Select whether all emergency exits are clear from the options (Yes - All Clear, No - Obstructions Found, Not Applicable).

10. Identify any **Hazard Identification**: Choose any hazards found during the inspection from the provided options (Exposed Wiring, Blocked Exits, Leaking Appliances, Damaged Cords, Overloaded Circuits, None Identified).

11. Provide detailed **Hazard Details**: Enter a detailed description of any identified hazards.

12. List **Corrective Actions Needed**: Enter any actions required to address the identified issues, if necessary.

13. Select the **Priority Level**: Choose the urgency level for corrective actions from the options (Critical - Immediate Action Required, High - Action Within 24 Hours, Medium - Action Within 7 Days, Low - Schedule for Maintenance).

14. Check if a **Follow-up Required**: Select whether a follow-up inspection is needed from the options (True, False).

15. Schedule a **Follow-up Date**: Enter the scheduled date for a follow-up inspection, if necessary.

16. Sign with your **Inspector Signature**: Digital signature or typed name of the inspector.

17. Confirm **Inspection Complete**: Select whether the inspection is finished from the options (Yes - Inspection Complete, No - Inspection Incomplete).
