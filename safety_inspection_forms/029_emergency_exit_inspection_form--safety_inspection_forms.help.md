# Emergency Exit Inspection Form - Help Guide
## Purpose
The Emergency Exit Inspection Form is a tool used to document and ensure the safety features of emergency exits in a building or facility.

## How To Complete This Form
1. Ensure you have access to the emergency exits in question.
2. Complete the form for each emergency exit.
3. Enter the required information for each field.

## Field-by-Field Explanation

* **Emergency Exit Location (`emergency_exit_location`)**: Describe the location of the emergency exit. This field should be completed with the exact location of the exit, such as "near the front entrance" or "on the east side of the building".
* **Emergency Exit Signs (`emergency_exit_signs`)**: Describe the safety signs present at the emergency exit. For example, if the exit has a "Fire Exit" sign, enter "Fire Exit".
* **Fire Exit (`fire_exit`)**: Indicate if the exit is a fire exit. Enter 'True' if the exit is a fire exit, 'False' otherwise.
* **Fire Exit Distance (`fire_exit_distance`)**: Measure the distance from the nearest fire exit to the nearest fire exit sign. Enter a numerical value in the corresponding units (e.g., 10 feet).
* **Fire Exit Distance Unit (`fire_exit_distance_unit`)**: Select the unit of measurement for the fire exit distance (e.g., feet, meters).
* **Fire Exit Width (`fire_exit_width`)**: Measure the width of the fire exit. This is the width of the exit opening, not the width of the corridor or hallway.
* **Emergency Exit Width (`emergency_exit_width`)**: This field is similar to fire_exit_width, but may be used to capture additional information about the exit. Describe its purpose in the field below.
* **Emergency Exit Width Description (`emergency_exit_width_description`)**: Describe the purpose and function of the emergency exit width measurement.
* **Fire Exit Height (`fire_exit_height`)**: Measure the height of the fire exit.
* **Exit Door Width (`exit_door_width`)**: Measure the width of the exit door.
* **Door Height (`door_height`)**: Measure the height of the exit door.
* **Safety Signs (`safety_signs`)**: Indicate if safety signs are present at the emergency exit. Enter 'True' if safety signs are present, 'False' otherwise.
* **Safety Signs Description (`safety_signs_description`)**: Describe the safety signs present at the emergency exit.
* **Exit Signs Frequency (`exit_signs_frequency`)**: Measure the frequency of exit signs present at the emergency exit.
* **Door Signs Description (`door_signs_description`)**: Describe the safety signs present at the exit door.
* **Exit Signs (`exit_signs`)**: Describe the safety signs present at the emergency exit.
* **Emergency Exit Location (`emergency_exit_location`)**: Describe the location of the emergency exit.
* **Fire Exit Description (`fire_exit_description`)**: Describe the fire exit.
* **Safety Exit Location (`safety_exit_location`)**: Describe the location of the safety exit.
* **Emergency Exit Width Description (`emergency_exit_width_description`)**: Describe the purpose and function of the emergency exit width measurement.
* **Notes (`notes`)**: Enter any additional comments or notes about the emergency exit.
* **Exit Location Description (`exit_location_description`)**: Describe the location of the exit.
* **Door Exit Description (`door_exit_description`)**: Describe the exit door.
