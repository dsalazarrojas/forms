# Building Access Security Assessment Form - Help Guide
## Purpose
The Building Access Security Assessment Form is used to evaluate the security and safety of a building or facility. It helps identify potential vulnerabilities and provides recommendations for improvements.

## How To Complete This Form
To complete this form, follow these steps:

*   Enter the assessor's name, title, and contact information (fields 1-4).
*   Enter the building's name and address (fields 7-8).
*   Select the building type (field 9).
*   Enter the number of floors and access points (fields 10-11).
*   Choose the access control system in place (field 12).
*   Assess the system's condition (field 13).
*   Evaluate the surveillance system (field 14).
*   Enter the number of cameras (field 15).
*   Determine the alarm system's status (field 16).
*   Identify the level of security personnel (field 17).
*   Choose the visitor management process (field 18).
*   Select the external security measures (field 19).
*   Identify any vulnerabilities found (field 20).
*   Assess the overall risk level (field 21).
*   Enter any security recommendations (field 22).
*   Provide any immediate actions needed (field 23).
*   Determine if re-assessment is required (field 24).
*   Certify the accuracy of the assessment (field 25).

## Field-by-Field Explanation
*   **Assessor Name** (`assessor_name`, text, required): Enter your full name as the person completing this assessment.
*   **Assessor Title** (`assessor_title`, text, required): Enter your job title or position.
*   **Department** (`department`, text, required): Enter the department or section of the organization responsible for the facility's security and safety.
*   **Email Address** (`email`, email, required): Enter your contact email address.
*   **Phone Number** (`phone`, text, required): Enter your contact phone number.
*   **Assessment Date** (`assessment_date`, date, required): Enter the date of the assessment.
*   **Building Name** (`building_name`, text, required): Enter the name of the building or facility.
*   **Building Address** (`building_address`, text, required): Enter the full address of the building or facility.
*   **Building Type** (`building_type`, select_one, required): Select the type of facility (e.g., Office Building, Residential Complex, Mixed Use, etc.).
*   **Total Floors** (`total_floors`, number, required): Enter the total number of floors in the building.
*   **Total Entry Points** (`total_entry_points`, number, required): Enter the total number of access points in the building.
*   **Access Control System** (`access_control_system`, select_one, required): Select the type of access control system in place (e.g., Card Access System, Biometric System, etc.).
*   **System Condition** (`system_condition`, select_one, required): Assess the current condition of the access control system (e.g., Excellent, Good, Fair, etc.).
*   **Surveillance System** (`surveillance_system`, select_one, required): Evaluate the surveillance system's coverage (e.g., Full Coverage, Partial Coverage, etc.).
*   **Number of Cameras** (`camera_count`, number, optional): Enter the approximate number of cameras in the building.
*   **Alarm System** (`alarm_system`, select_one, required): Determine the status of the alarm system (e.g., Fully Operational, Partially Operational, Not Operational, etc.).
*   **Security Personnel** (`security_personnel`, select_one, required): Identify the level of security personnel (e.g., 24/7 Staffed, Business Hours Only, etc.).
*   **Visitor Management** (`visitor_management`, select_one, required): Choose the visitor management process (e.g., Formal Check-in Required, Sign-in Log Only, etc.).
*   **Perimeter Security** (`perimeter_security`, select_multiple, required): Select the external security measures in place (e.g., Fencing, Gates, Bollards, etc.).
*   **Vulnerabilities Identified** (`vulnerabilities_found`, select_multiple, required): Identify any vulnerabilities found during the assessment.
*   **Overall Risk Level** (`risk_level`, select_one, required): Assess the overall risk level (e.g., Low Risk, Moderate Risk, etc.).
*   **Security Recommendations** (`recommendations`, text, required): Enter any key security recommendations.
*   **Priority Actions** (`priority_actions`, text, optional): Enter any immediate actions needed.
*   **Follow-up Required** (`follow_up_required`, select_one, required): Determine if re-assessment is required (e.g., Yes - Within 30 Days, etc.).
*   **Assessor Certification** (`assessor_certification`, select_one, required): Certify the accuracy of the assessment (e.g., Yes - I Certify, False).
