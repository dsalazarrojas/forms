### Factory Accident Incident Form - Help Guide

The Factory Accident Incident Form is designed to report and track factory accidents, including their details and status. This form provides a structured way for employees to report incidents, ensuring accurate and consistent data collection.

### How To Complete This Form

To complete this form, follow these steps:

1.  Select the correct options from the dropdown or radio buttons, if available.
2.  Enter the required information in the text fields, if any.
3.  Ensure all fields are filled out accurately and completely before submission.

### Field-by-Field Explanation

*   **Accident Date** (date, optional): Enter the date the accident occurred.
*   **Accident Type** (select_one, optional): Check if the accident was an incident or not.
    +   If the accident was an incident, select "Yes".
    +   If not, select "No".
*   **Location** (text, optional): Enter the location where the incident occurred.
*   **Incident Description** (text, optional): Provide a detailed description of the incident.
*   **Injury Type** (select_multiple, optional): Check if any injuries were sustained during the incident.
    +   If injuries were sustained, select "Yes".
    +   If not, select "No".
*   **Affected Employees** (text, optional): List the employees who were affected by the incident.
*   **Witness** (text, optional): If there were witnesses, enter their names here.
*   **Reporting Employee** (text, optional): Enter the name of the employee reporting the incident.
*   **Incident Cause** (text, optional): Provide a detailed description of the incident's cause.
*   **Incident Cause Code** (text, optional): Enter any relevant codes related to the incident cause.
*   **Prevention Plan** (text, optional): Describe the measures to be taken to prevent similar incidents in the future.
*   **Safety Measures** (text, optional): Outline any safety measures taken to mitigate or prevent the incident.
*   **Incident Status** (select_one, optional): Check the current status of the incident.
    +   If the incident is active, select "Active".
    +   If inactive, select "Inactive".
*   **Incident Status Code** (text, optional): Enter any relevant status codes related to the incident.

### Tips

*   Ensure all fields are filled out completely and accurately.
*   Review the form before submission to ensure all required information is included.
*   If there's any further questions or concerns, contact your supervisor or HR department.
