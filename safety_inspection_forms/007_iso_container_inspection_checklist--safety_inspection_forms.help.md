# ISO Container Inspection Checklist - Help Guide
## Purpose
The ISO Container Inspection Checklist is a form designed to inspect and assess the condition of ISO containers used for safe storage and transportation of goods. This form will help identify any potential safety concerns or issues with the container.

## How To Complete This Form
1. Review the form carefully to understand what each field means and what information is required.
2. Select the correct options for each field based on the actual condition of the container.
3. Ensure that all required fields are filled out correctly.
4. If a field is not applicable, please mark it as "N/A" (Not Applicable) and provide a brief explanation in the "Additional Comments" section.

## Field-by-Field Explanation

* **General Info**: This field is used to capture general information about the container, such as its location, date, and time of inspection.
* **Condition of ISO Container**: This field is used to rate the overall condition of the container. Select "Good" if the container is in good condition, "Poor" if it's in a poor condition, or "Critical" if it's critical.
* **Container Labeling**: This field is used to rate the labeling of the container. Select all the options that apply. This includes "Proper Labeling", "Proper Labeling but not readable", "Missing Label", or "Incorrect Labeling".
* **Container Condition**: This field is used to inspect and check if the container is in good condition. You must check if the container is in good condition. 
* **Seal Type**: This field is used to inspect and check if all seals are properly applied. Select all the options that apply. This includes "Proper Seal Application", "Missing Seal", "Improper Seal Application", or "Seal is broken".
* **Seal Condition**: This field is used to inspect and check the condition of the seal. Select all the options that apply. This includes "Good", "Damaged", or "Broken".
* **Container Size and Weight**: This field is used to check if the container is the correct size and weight. You must check if the container is the correct size and weight. 

## Tips
* Ensure that all fields are filled out accurately and truthfully.
