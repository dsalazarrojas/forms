# Graphite Monitoring Log Form - Help Guide
## Purpose
This form is used to record and track monitoring data for graphite, including the date and location of monitoring, type of monitoring, and output file details.

## How To Complete This Form
1. Fill out the form completely and accurately.
2. Enter the date of the monitoring in the "Date of Monitoring" field.
3. Enter the location of the monitoring in the "Location of Monitoring" field.
4. Select the type of monitoring from the "Monitoring Type" dropdown menu.
5. Specify the level of monitoring from the "Monitoring Level" dropdown menu.
6. Enter any comments regarding the monitoring in the "Comments" field.
7. Select the tool used for monitoring from the "Assigned Tool" dropdown menu.
8. Enter your contact email address in the "Email" field.
9. Enter your contact phone number in the "Phone" field.
10. Upload the output file, if applicable.
11. Enter the name of the output file in the "Output File Name" field.
12. Enter any comments about the output file in the "Output File Comments" field.
13. Enter the size of the output file in bytes.
14. Select the format of the output file from the "Output File Format" dropdown menu.
15. Enter the path to the output file, if applicable.

## Field-by-Field Explanation
* **Graphite Monitoring Log Form**: This is the title of the form, which should be left blank as it is automatically populated.
* **Date of Monitoring**: Enter the date of the monitoring event.
* **Location of Monitoring**: Enter the location where the monitoring was performed, such as a building or equipment ID.
* **Monitoring Type**: Select the type of monitoring performed, such as graphite monitoring, air monitoring, or water monitoring.
* **Monitoring Level**: Select the level of monitoring, which could be high, medium, or low.
* **Comments**: Enter any additional comments or notes about the monitoring event.
* **Assigned Tool**: Select the tool used for the monitoring, such as "chatjimmy" or other.
* **Email**: Enter your contact email address.
* **Phone**: Enter your contact phone number.
* **Output File**: Upload any output files from the monitoring event, if applicable.
* **Output File Name**: Enter the name of the output file.
* **Output File Comments**: Enter any comments about the output file.
* **Output File Size**: Enter the size of the output file in bytes.
* **Output File Format**: Select the format of the output file, which could be PDF, Excel, or CSV.
* **Output File Path**: Enter the path to the output file, if applicable.
