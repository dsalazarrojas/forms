# Stormwater Discharge Quality Report - Help Guide

## Purpose
This form is used to collect information on stormwater discharges that occur in the community's watersheds.

## How To Complete This Form
To complete this form, please follow these steps:

1. Select the type of stormwater discharge from the options provided.
2. Enter the date of the event.
3. Provide the location of the discharge.
4. If applicable, attach an image or video of the discharge.
5. Add any additional notes about the event.

## Field-by-Field Explanation

* **Stormwater Discharge Event** (`stormwater_discharge_event`): Enter a description of the stormwater discharge event.
* **Event Type** (`stormwater_discharge_event_type`): Choose the type of stormwater discharge from the options provided. (e.g. Waterway Discharge, Other)
* **Date** (`event_date`): Enter the date of the event in the format MM/DD/YYYY.
* **Location** (`stormwater_discharge_location`): Enter the location of the discharge.
* **Stormwater Discharge Quality** (`stormwater_discharge_quality`): Enter any information about the quality of the stormwater discharge.
* **Notes** (`notes`): Add any additional notes or comments about the event.
* **Stormwater Discharge Image** (`stormwater_discharge_image`): If you have an image of the discharge, upload it here.
* **Stormwater Discharge Video** (`stormwater_discharge_video`): If you have a video of the discharge, select "Yes" from the options provided.

## Tips
* Make sure to enter accurate and complete information about the event.
* Attach any supporting images or videos that can be used to document the event.
* Review the information carefully before submitting the form.
