# Material Disinfection Assessment - Help Guide
## Purpose
The Material Disinfection Assessment form is designed to evaluate the effectiveness of disinfection methods used on facilities. It is intended to gather information on facility types, disinfection methods, follow-up actions, and ratings of disinfection quality. This form will help assess the quality of disinfection processes and identify areas for improvement.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the type of facility from the options provided.
2. Enter the name of the facility (if applicable).
3. Choose the disinfection method used.
4. Indicate if a follow-up action is required.
5. Rate the quality of disinfection using two numerical ratings.
6. Provide any additional follow-up details (if applicable).
7. Select the next step to be taken based on the assessment.

## Field-by-Field Explanation
### Facility Type
* **Facility Type** (`facility_type`, `select_one`, optional): Select the type of facility being assessed (e.g., Chemical, Biological, Radioactive, Other)

### Facility Name
* **Facility Name** (`facility_name`, `text`, optional): Enter the name of the facility (if applicable)

### Disinfection Method
* **Disinfection Method** (`disinfection_method`, `select_one`, optional): Choose the method used for disinfection (e.g., Steam, Chemical, Other, None)

### Follow Up Action
* **Follow Up Action** (`follow_up_action`, `select_one`, optional): Indicate if a follow-up action is required (e.g., No Follow-up Required, Additional Training Required, Corrective Action Required, Other)

### Rating 1
* **Rating 1** (`rating1`, `number`, optional): Rate the quality of disinfection using a numerical value

### Rating 2
* **Rating 2** (`rating2`, `number`, optional): Rate the quality of disinfection using a numerical value

### Follow-Up Details
* **Follow-Up Details** (`follow_up_details`, `note`, optional): Provide any additional details regarding follow-up actions

### Next Step
* **Next Step** (`next_step`, `select_one`, optional): Select the next step to be taken based on the assessment (e.g., Complete, Escalate, Review)

### Next Step Details
* **Next Step Details** (`next_step_details`, `text`, optional): Enter any additional information regarding the next step

## Tips

* Please ensure that you have selected the correct facility type and disinfection method.
* Ratings 1 and 2 should reflect the quality of disinfection, with higher values indicating better quality.
* Use the follow-up details field to provide any additional context or information.
* Select the next step based on the assessment, and enter any additional details as needed.
