# Truck Packout Checklist - Help Guide
## Purpose
The Truck Packout Checklist is a form used to collect and document vital information about a truck's packout, ensuring a safe and efficient transportation process.

## How To Complete This Form
To complete this form, follow the steps below:

1. Select the "Vehicle Details" page and enter the Vehicle Number, Make, and Model of the truck being inspected.
2. Proceed to the "Driver Info" page and enter the driver's name, phone number, and license plate number.
3. On the "Vehicle Condition" page, describe the vehicle's current condition, including any existing damage or wear and tear.
4. For "Loading Details", provide the description of the cargo being transported.
5. Enter the "Cargo Securement" page to ensure the cargo is properly secured in the truck.
6. On the "Cargo Weight" page, input the weight of the cargo being transported.
7. Finally, enter the "Vehicle Location" page to specify the truck's location during inspection.

## Field-by-Field Explanation

* **Vehicle Details**
	+ (Vehicle Number, text, required)
	+ Enter the unique identification number assigned to the truck.
* **Driver Info**
	+ (Driver's Name, text, optional)
	+ Enter the name of the driver assigned to the truck.
	+ (Phone Number, text, optional)
	+ Enter the contact phone number of the driver.
	+ (License Plate Number, text, optional)
	+ Enter the license plate number of the truck.
* **Vehicle Condition**
	+ (Vehicle Condition, text, optional)
	+ Describe the current condition of the truck, including any existing damage or wear and tear.
* **Loading Details**
	+ (Loading Details, text, optional)
	+ Provide a description of the cargo being transported.
* **Cargo Securement**
	+ (Cargo Securement, number, required)
	+ Ensure the cargo is properly secured in the truck, and input the value.
* **Cargo Weight**
	+ (Cargo Weight, number, optional)
	+ Input the weight of the cargo being transported.
* **Vehicle Location**
	+ (Vehicle Location, text, optional)
	+ Specify the location of the truck during inspection.

Note: The optional fields can be left blank if not applicable to the specific situation.
