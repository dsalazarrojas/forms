# Fire Alarm System Monitoring Form - Help Guide
## Purpose
The Fire Alarm System Monitoring Form is used to track and monitor the status of fire alarm systems in facilities. This form helps to ensure that fire alarm systems are functioning properly and meet the required standards and regulations.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the required information for each field, making sure to provide accurate and complete details.
2. Review and confirm the data entered in each field.
3. Sign and date the form to indicate that it has been reviewed and approved.

## Field-by-Field Explanation

* **Form Header** (`form_header`, text, optional): This field is for the title of the form. You can enter a brief description of the fire alarm system being monitored.
* **Facility Name** (`facility_name`, text, optional): Enter the name of the facility being monitored.
* **Monitoring System** (`monitoring_system`, text, optional): Describe the monitoring system used in the facility.
* **Alarm Location** (`alarm_location`, text, optional): Identify the location of the fire alarm system within the facility.
* **Zone Description** (`zone_description`, text, optional): Provide a brief description of the zone being monitored.
* **Alarm Type** (`alarm_type`, text, optional): Specify the type of alarm being monitored.
* **Alarm Location Coordinates** (`alarm_location_coordinates`, text, optional): Enter the coordinates or location information for the alarm.
* **Alarm Description** (`alarm_description`, text, optional): Describe the alarm and its functionality.
* **Last Test Date** (`last_test_date`, date, optional): Record the date of the last test or inspection of the system.
* **Last Test Result** (`last_test_result`, select_one, optional): Check the results of the last test or inspection:
	+ Select "Working" if the system was functioning correctly.
	+ Select "Not Working" if the system was not functioning correctly.
* **Next Test Date** (`next_test_date`, date, optional): Schedule the next test or inspection date for the system.
* **Last Inspection Date** (`last_inspection_date`, date, optional): Record the date of the last inspection or audit of the system.
* **Next Inspection Date** (`next_inspection_date`, date, optional): Schedule the next inspection or audit date for the system.
* **Fire Alarm System Certificate** (`fire_alarm_system_certificate`, select_one, optional): Check the certification status of the system:
	+ Select "Certified" if the system is certified and meets the required standards.
	+ Select "Not Certified" if the system is not certified and does not meet the required standards.
* **Fire Inspection Certificate** (`fire_inspection_certificate`, select_one, optional): Check the certification status of the fire inspection:
	+ Select "Certified" if the inspection is certified and meets the required standards.
	+ Select "Not Certified" if the inspection is not certified and does not meet the required standards.
* **Fire Alarm System Certificate** (`fire_alarm_system_certificate`, select_one, optional): This field is redundant with "Fire Alarm System Certificate" and can be ignored.
* **Fire Inspection Certificate** (`fire_inspection_certificate`, select_one, optional): This field is redundant with "Fire Inspection Certificate" and can be ignored.
* **Comments** (`comments`, text, optional): Add any additional comments or notes about the fire alarm system.
* **Signature** (`signature`, text, optional): Sign the form to indicate that it has been reviewed and approved.
* **Reviewer Signature** (`reviewer_signature`, text, optional): Sign and date the form as the reviewer.
* **Reviewer Name** (`reviewer_name`, text, optional): Enter your name as the reviewer.
* **Reviewer Title** (`reviewer_title`, text, optional): Enter your title or position as the reviewer.
* **Reviewer Email** (`reviewer_email`, text, optional): Enter your email address as the reviewer.
* **Reviewer Phone** (`reviewer_phone`, text, optional): Enter your phone number as the reviewer.
* **Reviewer Date** (`reviewer_date`, date, optional): Enter the date and time of the review.
* **Reviewer Time** (`reviewer_time`, time, optional): Enter the time of the review.

Note: All fields marked as "optional" can be left blank if not applicable.
