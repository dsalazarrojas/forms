## Field-by-Field Explanation

### Purpose
This form is used to document the results of a safety inspection of high voltage equipment.

### How To Complete This Form

1.  Select the type of equipment being inspected from the drop-down menu.
2.  Enter the location of the equipment, if applicable.
3.  Provide the serial number of the equipment, if available.
4.  Report the last maintenance date, if applicable.
5.  Report the next maintenance date, if applicable.
6.  Enter your name as the inspector.
7.  Record the date and time of the inspection.
8.  Assess the condition of the equipment using the provided options.
9.  Enter any findings or observations about the equipment.
10.  Create an action plan for future maintenance.
11.  Add any comments or notes about the inspection.
12.  Report the current status of the equipment using the provided options.

### Field-by-Field Explanation

*   **Equipment Type** (`high_voltage_equipment_inspection_report/1/equipment_type`, select_one):
    *   Select the correct type of equipment being inspected, such as High Voltage or Low Voltage.
*   **Equipment Location** (`high_voltage_equipment_inspection_report/2/equipment_location`, text):
    *   Enter the location where the equipment is situated, if applicable.
*   **Serial Number** (`high_voltage_equipment_inspection_report/3/serial_number`, text):
    *   Enter the serial number of the equipment, if available.
*   **Last Maintenance Date** (`high_voltage_equipment_inspection_report/4/last_maintenance_date`, date):
    *   Report the date of the last maintenance or service performed on the equipment, if applicable.
*   **Next Maintenance Date** (`high_voltage_equipment_inspection_report/5/next_maintenance_date`, date):
    *   Report the date of the next scheduled maintenance or service, if applicable.
*   **Inspector Name** (`high_voltage_equipment_inspection_report/6/inspector_name`, text):
    *   Enter your name as the authorized inspector.
*   **Date Inspected** (`high_voltage_equipment_inspection_report/7/date_inspected`, date):
    *   Record the date and time of the inspection.
*   **Time Inspected** (`high_voltage_equipment_inspection_report/8/time_inspected`, time):
    *   Record the time of the inspection.
*   **Condition** (`high_voltage_equipment_inspection_report/9/condition`, select_one):
    *   Assess the condition of the equipment using the provided options, such as Good, Fair, or Poor.
*   **Findings** (`high_voltage_equipment_inspection_report/10/findings`, note):
    *   Enter any findings or observations about the equipment.
*   **Action Plan** (`high_voltage_equipment_inspection_report/11/action_plan`, note):
    *   Create an action plan for future maintenance or repairs.
*   **Comments** (`high_voltage_equipment_inspection_report/12/comments`, text):
    *   Add any comments or notes about the inspection.
*   **Equipment Status** (`high_voltage_equipment_inspection_report/13/equipment_status`, select_multiple):
    *   Report the current status of the equipment using the provided options, such as Functional, Out of Service, or In Maintenance.
