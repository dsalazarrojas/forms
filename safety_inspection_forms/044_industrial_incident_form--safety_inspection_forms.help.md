# industrial_incident_form - Help Guide
## Purpose
The industrial_incident_form is used to report and document industrial incidents that occur within the organization. This form is essential for identifying root causes and taking corrective actions to prevent future incidents.

## How To Complete This Form
To complete this form, follow the steps below:

1. Review the form carefully and ensure you have all the necessary information before proceeding.
2. Complete all the required fields (marked as required) to the best of your ability.
3. Provide as much detail as possible for each field, especially for fields that are not required.
4. If you are unsure about any field, please ask for clarification or assistance from your supervisor or HR representative.

## Field-by-Field Explanation

### General Information (Page 1)
* **General Information**: This section is for providing a brief overview of the incident.
	+ **Label**: General Information
	+ **Type**: text
	+ **Required**: false

### Incident Type (Page 1)
* **Incident Type**: Choose the type of incident that occurred.
	+ **Label**: Incident Type
	+ **Type**: select_one
	+ **Options**: Mechanical, Electrical, Chemical
	+ **Required**: false

### Incident Date (Page 1)
* **Incident Date**: Enter the date the incident occurred.
	+ **Label**: Incident Date
	+ **Type**: date
	+ **Required**: false

### Incident Time (Page 1)
* **Incident Time**: Enter the time the incident occurred.
	+ **Label**: Incident Time
	+ **Type**: time
	+ **Required**: false

### Incident Location (Page 1)
* **Incident Location**: Enter the location where the incident occurred.
	+ **Label**: Incident Location
	+ **Type**: text
	+ **Required**: false

### Incident Description (Page 1)
* **Incident Description**: Provide a detailed description of what happened.
	+ **Label**: Incident Description
	+ **Type**: text
	+ **Required**: false

### Incident Status (Page 1)
* **Incident Status**: Choose the current status of the incident.
	+ **Label**: Incident Status
	+ **Type**: select_one
	+ **Options**: Active, Closed, Under Investigation
	+ **Required**: false

### Root Cause (Page 1)
* **Root Cause**: Enter the root cause of the incident.
	+ **Label**: Root Cause
	+ **Type**: text
	+ **Required**: false

### Preventive Action (Page 1)
* **Preventive Action**: Enter the actions taken to prevent similar incidents in the future.
	+ **Label**: Preventive Action
	+ **Type**: text
	+ **Required**: false

## Tips
* Be as thorough as possible when filling out this form.
* If you are unsure about any field, please ask for clarification or assistance.
* Please note that this form is used for reporting and documenting incidents only and is not for reporting near misses or close calls.
