# shopping_mall_emergency_exit_inspection_form - Help Guide

## Purpose
The shopping_mall_emergency_exit_inspection_form is designed to assess the safety and emergency exit protocols of a shopping mall, ensuring that all necessary measures are in place to maintain a safe environment.

## How To Complete This Form

1. Select the options for each field based on your observations during the inspection.
2. Answer each question truthfully, without any bias or influence from external factors.
3. Complete all required fields to ensure that your submission is valid.

## Field-by-Field Explanation

* **Emergency Exit Path** (1, text): Describe the path of the emergency exit, including the location and any obstacles or hazards that might impede access.
* **Exit Signs** (2, select_multiple): Select all exit signs that you observed, such as Fire Exit, Emergency Exit, and Safety Exit.
* **Exit Doors** (3, number): Count the number of exit doors you found, including any obstacles or hazards around them.
* **Emergency Alarm System** (4, select_one): Check if you observed an emergency alarm system.
* **Fire Extinguishers** (5, select_multiple): Select the status of fire extinguishers, such as Available, Not Available, or N/A.
* **Emergency Exits Marked** (6, select_one): Check if emergency exits are well-marked and easily identifiable.
* **Fire Drills** (7, select_one): Check if regular fire drills are conducted to ensure preparedness.
* **Emergency Exit Signs Visible** (8, select_one): Check if emergency exit signs are visible and easily identifiable.
* **Fire Extinguisher in Room** (9, select_one): Check if fire extinguishers are present in each room.
* **Emergency Exit Path Well Lit** (10, select_one): Check if the emergency exit path is well-lit and easily identifiable.
* **Emergency Exit Signs in Room** (11, select_one): Check if emergency exit signs are present in each room.
* **Exit Doors Opened** (12, select_one): Check if all exit doors are opened for emergency exit.
* **Fire Extinguishers in Room** (13, select_one): Check if fire extinguishers are present in each room.
* **Emergency Contact** (14, text): Provide the contact information of the person responsible for emergency response.
* **Comments** (15, note): Add any additional comments or observations about the emergency exit system.
* **Date Completed** (16, date): Enter the date and time of completion of the inspection.
* **Employee Signoff** (17, select_one): Check if the employee has signed off on the inspection.

Note: This form is intended to be completed by someone who has inspected the shopping mall's emergency exit system. If you are not the person responsible for completing this form, please do not submit it.
