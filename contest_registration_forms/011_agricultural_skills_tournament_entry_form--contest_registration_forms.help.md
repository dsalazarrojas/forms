# Agricultural Skills Tournament Entry Form - Help Guide
## Purpose
The purpose of this form is to gather information from contestants who wish to participate in the Agricultural Skills Tournament. The form will be used to collect essential details about the contestant, including their name, age, contact information, and event categories they are interested in participating in. This information is crucial for event communications, team management, and accommodation planning.

## How To Complete This Form
1. Fill in the form with the required fields, marked with an asterisk (\*).
2. Ensure that you complete the form accurately and thoroughly, as it will be used to create materials for the event.
3. If you are entering as part of a team, provide the team name in the "Team name" field.
4. Select the event categories you are interested in participating in from the dropdown list.
5. If you have any dietary restrictions, please specify them in the "Dietary restrictions" field.
6. If you have any accessibility or special needs, indicate them in the "Accessibility or special needs" field.
7. Read and agree to the consent for media release by selecting "True" in the "Consent for media release" field.

## Field-by-Field Explanation
* **Contestant name**: Enter your full name as it should appear on materials.
* **Age**: Enter your age.
* **Contact email**: Enter your email address for event communications.
* **Phone number**: Enter your mobile or daytime contact number. (This field is optional.)
* **Team name**: If you are entering as part of a team, enter the team name here. (This field is optional.)
* **Event categories**: Select all the categories you are interested in participating in. You can select multiple categories.
* **Emergency contact name and phone**: Provide the name and phone number of an emergency contact.
* **Dietary restrictions**: If you have any dietary restrictions, specify them here.
* **Accessibility or special needs**: If you have any accessibility or special needs, indicate them here.
* **Consent for media release**: Select "True" to give permission for the event organizers to use photos or videos of you.
