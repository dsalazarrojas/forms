# Raffle Basket Theme Submission - Help Guide

## Purpose
The Raffle Basket Theme Submission form is designed for users to submit theme ideas for a raffle basket event. This form collects essential information about the theme, including the school or nonprofit organization, theme name, estimated value, and user contact details.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the correct option for "School or Nonprofit" to indicate whether the theme submission is from a school or a nonprofit organization.
2. Enter the "Theme Name" and provide a brief description of the theme.
3. Estimate the "Estimated Value" of the theme and select the correct currency.
4. (Optional) Upload an image for the "Raffle Basket Image URL" if desired.
5. Provide any additional "Theme Ideas" for the theme submission.
6. Enter your "User Name," "Email," and "Phone" to contact you for further information.
7. If applicable, provide the school's "School District," "School City," "School State," and "School Zip" information.
8. Add any "Submission Notes" to provide additional context.
9. Finally, review your submission for accuracy and submit it for review.

## Field-by-Field Explanation

* **School or Nonprofit** (`school_or_nonprofit`, select_one, required): Choose whether the theme submission is from a school or a nonprofit organization.
* **Theme Name** (`theme_name`, text, required): Enter a brief name for the theme submission.
* **Theme Description** (`theme_description`, text, required): Describe the theme submission in a few words.
* **Estimated Value** (`estimated_value`, number, required): Estimate the value of the theme submission.
* **Estimated Value Currency** (`estimated_value_currency`, select_one, required): Select the currency of the estimated value (e.g., USD, EUR, JPY, CNY).
* **Raffle Basket Image URL** (`raffle_basket_image`, text, optional): Upload an image URL for the theme submission if desired.
* **Theme Ideas** (`theme_ideas`, text, optional): Add any additional theme ideas for the submission.
* **Submission Date** (`submission_date`, date, optional): Provide the submission date for the theme.
* **Submission Time** (`submission_time`, time, optional): Provide the submission time for the theme.
* **User Name** (`user_name`, text, required): Enter your name as the user submitting the theme.
* **Email** (`email`, email, required): Enter your email address for contact purposes.
* **Phone** (`phone`, text, required): Enter your phone number for contact purposes.
* **School District** (`school_district`, text, optional): Provide the school district (if applicable).
* **School City** (`school_city`, text, optional): Provide the school city (if applicable).
* **School State** (`school_state`, text, optional): Provide the school state (if applicable).
* **School Zip** (`school_zip`, text, optional): Provide the school zip code (if applicable).
* **Submission Notes** (`submission_notes`, text, optional): Add any additional submission notes.
* **School Name** (`school_name`, text, optional): Enter the school name (if applicable).
* **School Address** (`school_address`, text, optional): Enter the school address (if applicable).
* **School Phone** (`school_phone`, text, optional): Enter the school phone number (if applicable).
* **School Email** (`school_email`, email, optional): Enter the school email (if applicable).
* **School URL** (`school_url`, text, optional): Enter the school URL (if applicable).
* **School Facebook URL** (`school_facebook_url`, text, optional): Enter the school Facebook URL (if applicable).
* **School Instagram URL** (`school_instagram_url`, text, optional): Enter the school Instagram URL (if applicable).
* **Submission Status** (`submission_status`, text, optional): Enter the submission status for the theme submission.

## Tips

* Be sure to review your submission for accuracy before submitting it.
* If you have any issues or concerns, contact the event organizers for assistance.
* Ensure you have permission from the relevant parties to submit the theme on behalf of a school or nonprofit organization.
