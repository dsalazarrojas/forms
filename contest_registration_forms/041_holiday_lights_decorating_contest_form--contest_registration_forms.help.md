# Holiday Lights Decorating Contest Form - Help Guide
## Purpose
This form is designed to collect information for the Holiday Lights Decorating Contest. Please fill out the form with accurate and complete details to ensure a successful submission.

## How To Complete This Form
To complete this form, follow these steps:

1.  Enter your contest entry information in the fields below.
2.  Ensure that all required fields are filled out correctly.
3.  Review your submission before submitting it.

## Field-by-Field Explanation
* **Entry Type** (`entry_type`): Choose the type of entry you are submitting: residential, commercial, or other.
* **Address** (`address`): Enter the address of the location being decorated.
* **House Number** (`house_number`): Enter the house number of the location being decorated.
* **Zip Code** (`zip_code`): Enter the zip code of the location being decorated.
* **Contact Phone** (`contact_phone`): Enter a phone number for contact purposes.
* **Entry Image** (`entry_image`): Optional - enter a description of the image you'd like to submit (max 200 characters).
* **Entry Description** (`entry_description`): Optional - enter a brief description of the entry.
* **Entry Date** (`entry_date`): Optional - select the date of the event or event date (format: YYYY-MM-DD).
* **Entry Time** (`entry_time`): Optional - select the time of the event or event time (format: 24-hour clock format).
* **Entry Latitude** (`entry_latitude`): Optional - enter the latitude of the location being decorated (required for accurate map display).
* **Entry Longitude** (`entry_longitude`): Optional - enter the longitude of the location being decorated (required for accurate map display).

## Tips
* Ensure all required fields are filled out correctly.
* Double-check your submission for accuracy before submitting.
* Use the correct format for date and time fields.
