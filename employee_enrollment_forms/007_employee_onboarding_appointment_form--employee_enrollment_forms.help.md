# Employee Onboarding Appointment Form - Help Guide
## Purpose
This form is used to collect information about new hires, including their job title, date of birth, start date, email, phone number, availability, work location, manager's name, email, and phone number. This data will help HR and management teams prepare for the new hire's integration into the organization.

## How To Complete This Form
To complete this form, please follow these steps:

1. Review the form carefully and ensure you have all the necessary information before starting.
2. Fill out the New Hire Information section with the new hire's details.
3. Select the job title that best represents the new hire's role in the organization.
4. Enter the new hire's date of birth.
5. Choose their start date and time.
6. Enter their email address and phone number.
7. Indicate their availability as a full-time, part-time, or contract employee.
8. Provide the location where the new hire will be working.
9. Enter the manager's name and contact information.

## Field-by-Field Explanation
- **New Hire Information**: Enter the new hire's details, such as name, job title, and other relevant information.
	+ Type: Text
	+ Required: False
- **Job Title**: Select the job title that best represents the new hire's role in the organization.
	+ Type: Text
	+ Required: False
- **Date of Birth**: Enter the new hire's date of birth.
	+ Type: Date
	+ Required: False
- **Start Date**: Choose the new hire's start date and time.
	+ Type: Time
	+ Required: False
- **Email**: Enter the new hire's email address.
	+ Type: Email
	+ Required: False
- **Phone Number**: Enter the new hire's phone number.
	+ Type: Text
	+ Required: False
- **Schedule Appointment**: Indicate whether the new hire is available or not available for an appointment.
	+ Type: Select Multiple
	+ Required: False
- **Availability**: Choose the new hire's availability as a full-time, part-time, or contract employee.
	+ Type: Select One
	+ Required: True
- **Work Location**: Provide the location where the new hire will be working.
	+ Type: Text
	+ Required: False
- **Manager Name**: Enter the manager's name.
	+ Type: Text
	+ Required: False
- **Manager Email**: Enter the manager's email address.
	+ Type: Email
	+ Required: False
- **Manager Phone**: Enter the manager's phone number.
	+ Type: Text
	+ Required: False
