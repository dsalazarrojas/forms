# new-employee-access-form - Help Guide
## Purpose
The purpose of this form is to collect information for new employee access to company resources and systems.

## How To Complete This Form
1. Review the form carefully and understand the purpose of each field.
2. Fill out each field accurately and completely.
3. Submit the form to ensure that the new employee has the correct level of access.

## Field-by-Field Explanation

* **new-hire-details** (Page 1, Text): This field is intended to collect the new employee's basic details, including their title, job description, and other relevant information.
* **answers** (Page 2, Select Multiple): This field allows you to select multiple options that apply to the new employee's role and responsibilities. Please select all the options that are relevant to your position.
* **manager-answers** (Page 3, Select One): This field allows you to select the option that best describes your role as a manager or supervisor.
* **date-of-birth** (Page 4, Date): This field is for the new employee's date of birth.
* **job-title** (Page 5, Text): This field is for the new employee's job title.
* **job-description** (Page 6, Text): This field is for the new employee's job description.
* **job-status** (Page 7, Select One): This field allows you to select the status of the new employee's job.
* **job-category** (Page 8, Text): This field is for the new employee's job category.
* **date-of-joining** (Page 9, Date): This field is for the new employee's date of joining.
* **contact-info** (Page 10, Text): This field is for the new employee's contact information.
* **manager-name** (Page 11, Text): This field is for the new employee's manager's name.
* **manager-email** (Page 12, Email): This field is for the new employee's manager's email address.
* **manager-phone** (Page 13, Text): This field is for the new employee's manager's phone number.
* **manager-address** (Page 14, Text): This field is for the new employee's manager's address.
* **manager-title** (Page 15, Text): This field is for the new employee's manager's title.
* **manager-answers** (Page 16, Select Multiple): This field allows the new employee to select multiple options that apply to their role and responsibilities.
* **job-role** (Page 17, Text): This field is for the new employee's job role.
* **manager-department** (Page 18, Text): This field is for the new employee's manager's department.
* **manager-supervisor** (Page 19, Text): This field is for the new employee's manager's supervisor.
* **manager-reporting-manager** (Page 20, Text): This field is for the new employee's manager's reporting manager.
* **confirm-form-submission** (Page 21, Text): This field is for confirming that you have accurately completed the form.
* **new-employee-access-form** (Page 22, Date): This field is for selecting a date for the new employee's access form submission.
* **new-employee-access-form-page-23** (Page 23, Text): This field is for additional information.
* **new-employee-access-form-page-24** (Page 24, Note): This field is for any additional comments or information.
* **new-employee-access-form-page-25** (Page 25, Select One): This field allows you to select an option that applies to your role and responsibilities.
