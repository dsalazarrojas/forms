# Puppy Structure Evaluation Form - Help Guide
## Purpose
This form is used to collect information about a puppy's structure, including breed, sex, age, height, weight, and other physical characteristics. The information collected will be used by veterinary professionals to conduct a physical examination and provide guidance on the puppy's care and treatment.

## How To Complete This Form
1. Answer all fields truthfully and accurately.
2. Provide information about the puppy's owner and contact information.
3. Describe the puppy's physical characteristics, such as sex, breed, and age.
4. Answer questions about the puppy's physical structure, such as height, weight, coat length, gait, movement, coat type, tail type, head shape, muzzle type, teeth condition, eye shape, bite type, body type, tail length, ear set position, and overall impression.

## Field-by-Field Explanation

* **Owner Information** (`owner_information`, text, required/optional): Enter the owner's name and contact information.
* **Owner Name** (`owner_name`, text, required/optional): Enter the owner's name.
* **Owner Contact** (`owner_contact`, text, required/optional): Enter the owner's contact information (phone number and/or email).
* **Puppy Information** (`puppy_information`, note, required/optional): This field is not applicable for data entry. Skip or leave blank.
* **Breed** (`breed`, select_one, required/optional): Select 'Yes' if the puppy is a purebred or mixed-breed puppy, or 'No' if it's a mixed-breed or unknown.
* **Sex** (`sex`, select_one, required/optional): Select 'Yes' if the puppy is male, or 'No' if it's female.
* **Age in Months** (`age_in_months`, number, required/optional): Enter the puppy's age in months.
* **Height in Cm** (`height_in_cm`, number, required/optional): Enter the puppy's height in centimeters.
* **Weight in Lbs** (`weight_in_lbs`, number, required/optional): Enter the puppy's weight in pounds.
* **Coat Length** (`coat_length`, number, required/optional): Enter the puppy's coat length in centimeters.
* **Gait** (`gait`, select_one, required/optional): Select 'Yes' if the puppy has a normal gait, or 'No' if it has an abnormal gait.
* **Movement** (`movement`, text, required/optional): Describe the puppy's movement or gait in detail.
* **Coat Type** (`coat_type`, select_one, required/optional): Select 'Yes' if the puppy has a short or long coat, or 'No' if it has a wire or curly coat.
* **Tail Type** (`tail_type`, select_one, required/optional): Select 'Yes' if the puppy has a docked or undocked tail, or 'No' if it has a natural or unnatural tail.
* **Head Shape** (`head_shape`, select_one, required/optional): Select 'Yes' if the puppy has a normal head shape, or 'No' if it has an abnormal head shape.
* **Muzzle Type** (`muzzle_type`, select_one, required/optional): Select 'Yes' if the puppy has a normal muzzle type, or 'No' if it has an abnormal muzzle type.
* **Teeth Condition** (`teeth_condition`, text, required/optional): Describe the puppy's teeth condition in detail.
* **Eye Shape** (`eye_shape`, select_one, required/optional): Select 'Yes' if the puppy has a normal eye shape, or 'No' if it has an abnormal eye shape.
* **Bite Type** (`bite_type`, text, required/optional): Describe the puppy's bite type in detail.
* **Body Type** (`body_type`, select_one, required/optional): Select 'Yes' if the puppy has a normal body type, or 'No' if it has an abnormal body type.
* **Tail Length** (`tail_length`, number, required/optional): Enter the puppy's tail length in centimeters.
* **Ear Set Position** (`ear_set_position`, text, required/optional): Describe the puppy's ear set position in detail.
* **Overall Impression** (`overall_impression`, text, required/optional): Provide an overall impression of the puppy's structure and physical condition.
 

Please ensure that you complete the form accurately and truthfully. If you are unsure about any of the fields or questions, please ask your veterinarian or veterinary technician for guidance.
