# Book Advance Release Request - Help Guide
## Purpose
This form is used to request advance releases of books for review, feature articles, interviews, or other purposes. 

## How To Complete This Form
1. Fill out the form with accurate and up-to-date information about the book and your request.
2. Ensure all fields are filled out as required.
3. Double-check your information before submitting the form.

## Field-by-Field Explanation
* **Request Date** (`request_date`, date, required): The date you are requesting the advance release for. 
* **Requester Name** (`requester_name`, text, required): The name of the individual or organization requesting the advance release. 
* **Email Address** (`requester_email`, email, required): The email address of the individual or organization requesting the advance release. 
* **Phone Number** (`requester_phone`, text, required): The phone number of the individual or organization requesting the advance release. 
* **Organization** (`organization`, text, required): The organization or publication requesting the advance release. 
* **Organization Type** (`organization_type`, select_one, required): The type of organization requesting the advance release (e.g. Media Outlet, Book Review Publication, etc.). 
* **Professional Credentials** (`professional_credentials`, text, required): Any relevant professional credentials, such as title, credentials, or publications. 
* **Book Title Requested** (`book_title`, text, required): The title of the book being requested. 
* **Book Author** (`book_author`, text, required): The author of the book being requested. 
* **Book ISBN** (`book_isbn`, text, required): The ISBN of the book being requested. 
* **Scheduled Publication Date** (`book_publication_date`, date, required): The scheduled publication date of the book. 
* **Number of Advance Copies Requested** (`advance_copies_requested`, number, required): The number of advance copies requested. 
* **Preferred Format** (`format_preference`, select_one, required): The preferred format for the advance release (e.g. Hardcover, Paperback, eBook, etc.). 
* **Intended Use of Advance Copy** (`intended_use`, select_one, required): The intended use of the advance copy (e.g. Book Review, Feature Article, Interview, etc.). 
* **Publication Platform** (`publication_platform`, text, required): Where the book will be published or featured. 
* **Estimated Audience Reach** (`audience_reach`, number, optional): The estimated number of people that will read or see the review or feature. 
* **Planned Publication Date of Review** (`planned_publication_date`, date, required): The planned publication date of the review or feature. 
* **Can You Respect Publication Embargo** (`embargo_acceptable`, select_one, required): Are you willing to respect the publication embargo of the book. 
* **If No - Explain Concerns** (`embargo_concern_explanation`, text, optional): If no, explain why you cannot respect the publication embargo. 
* **Previous Coverage of This Author** (`previous_coverage`, text, optional): Any previous coverage of this author. 
* **Similar Books Recently Reviewed** (`similar_books_reviewed`, text, optional): Any similar books recently reviewed by this author. 
* **Shipping Address** (`shipping_address`, text, required): The address where the advance release should be shipped to. 
* **City - State - Zip** (`shipping_city_state_zip`, text, required): The city, state, and zip code of the shipping address. 
* **Permission to Use in Press Releases** (`press_release_authorization`, select_one, required): Are you willing to authorize the use of the book in press releases. 
* **I Certify the Above Information is Accurate** (`request_certification`, select_one, required): Do you certify that the above information is accurate. 

## Tips
* Double-check your information for accuracy before submitting the form. 
* Ensure all fields are filled out as required. 
* We may ask for further clarification or additional information before sending the advance release.
