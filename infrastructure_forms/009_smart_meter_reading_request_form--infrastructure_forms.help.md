# Smart Meter Reading Request Form - Help Guide
## Purpose
The Smart Meter Reading Request Form is designed to collect information from customers for smart meter readings, allowing them to monitor and manage their energy usage.

## How To Complete This Form

1. Please ensure you have not previously submitted a request for the same meter ID.
2. Select the meter ID from the options provided.
3. Choose a preferred date for the reading.
4. Enter your name, email, and phone number to help us contact you with any updates or information.
5. If applicable, select the days you are available for the reading.
6. Enter the start and end time of the reading.
7. Provide any additional notes or instructions to assist with the reading process.

## Field-by-Field Explanation

* **Customer info**: This field is optional and allows you to enter a brief description of your request, if needed.
	+ **Meter ID**: Select the unique ID associated with your smart meter to help us identify your specific meter.
	+ This field is optional, and selecting a value will enable us to process your request more efficiently.
* **Meter ID**: 
	+ Select the meter ID from the provided options or enter a new ID if it is not listed.
* **Preferred date**: 
	+ Choose a date for the reading.
* **Instructions**: 
	+ Enter any specific instructions for the meter reading, such as any safety concerns or special considerations.
* **Customer name**: 
	+ Enter your full name for our records.
* **Customer email**: 
	+ Enter your valid email address for communication and updates.
* **Customer phone**: 
	+ Enter your phone number for us to contact you with updates or information.
* **Meter reading date**: 
	+ Select a date for the reading.
* **Schedule reading**: 
	+ Select the days you are available for the reading.
	+ Note: Select one or more options.
* **Start time**: 
	+ Enter the start time of the reading.
* **End time**: 
	+ Enter the end time of the reading.
* **Note**: 
	+ Enter any additional comments or instructions for the reading process.

## Tips

* Please ensure that the meter ID you select is accurate to avoid any errors or delays.
* If you have any special requests or concerns, please include them in the 'Note' field.
* If you have any questions or need clarification on any field, please contact us using the provided contact information.
* Please review your form for accuracy before submitting it to avoid any issues with processing.
