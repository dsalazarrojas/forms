# Solar Roof Implementation Application Form - Help Guide
## Purpose
The Solar Roof Implementation Application Form is a tool used to collect and store data for solar roof projects. This form serves as a starting point for project stakeholders to provide details about their solar roof projects.

## How To Complete This Form
1. Select the options for each field according to your project's details. If you're unsure about any field, please ask for help.
2. Review each field for accuracy before submission.

## Field-by-Field Explanation

* **Project Details** (`project_details`):
	+ This field allows you to confirm if your project involves solar roof implementation.
* **Project Address** (`project_address`):
	+ Enter your project's address.
* **Project Status** (`project_status`):
	+ Select the status of your project from the options provided.
* **Roof Condition** (`roof_condition`):
	+ Indicate the condition of your roof.
* **Roof Type** (`roof_type`):
	+ Choose the type of roof you have.
* **Building Type** (`building_type`):
	+ Select the type of building you're applying for.
* **Roof Area** (`roof_area`):
	+ Enter the square footage of your roof.
* **Installed Systems** (`installed_systems`):
	+ Select the systems installed for your solar roof project.
* **Solar Capacity (Watts)** (`solar_capacity_watts`):
	+ Enter the total solar capacity in watts.
* **Expected Revenue** (`expected_revenue`):
	+ Choose the expected revenue for your project from the options provided.

## Tips
* Please fill in the form accurately and truthfully.
* Review each field carefully before submission.
* If you have any questions or concerns, please reach out to the project team.
