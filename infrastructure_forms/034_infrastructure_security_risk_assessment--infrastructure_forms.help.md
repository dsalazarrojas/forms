# infrastructure_security_risk_assessment - Help Guide
## Purpose
The "infrastructure_security_risk_assessment" form is used to evaluate and document the security risk associated with a specific site or infrastructure.

## How To Complete This Form
1. Select "Yes" or "No" for the "Site Evaluation" field to indicate if the site has been evaluated.
2. Enter the "Evaluation Date" of when the evaluation was conducted.
3. Enter the name of the site being evaluated.
4. Enter a numerical value for the "Risk Rating" to indicate the level of risk associated with the site.
5. Enter a description of the risk associated with the site.
6. Select "Yes" or "No" for "Risk Impact" to indicate if the risk has a significant impact.
7. Select "Yes" or "No" for "Risk Likelihood" to indicate if the risk is likely to occur.
8. Select "Yes" or "No" for "Site Security Controls" to indicate if the site has adequate security controls.
9. Select the "Remediation Status" to indicate the status of the remediation efforts.
10. Enter the "Location" of the site being evaluated.
11. Enter a numerical value for the "Security Rating" to indicate the level of security.
12. Enter any additional notes about the site.
13. Select "Yes" or "No" for "Site Visit" to indicate if a site visit has been conducted.
14. Select "Active" or "Inactive" for "Evaluation Status" to indicate the status of the evaluation.
15. Select "Good", "Fair", "Poor" for "Security Rating Scale" to indicate the level of security.
16. Enter any comments about the security rating.
17. Enter the "Site Elevation" of the site (optional).
18. Enter any comments about the site.
19. Enter a numerical value for "Security Controls Rating" to indicate the level of security controls.
20. Enter the "Remediation Plan" to indicate the plan for remediation efforts.
21. Select "Active" or "Inactive" for "Remediation Status" to indicate the status of remediation efforts.
22. Enter the "Risk Assessment Date" of when the risk assessment was conducted.
23. Enter the "Site Visit Date" of when the site visit was conducted (optional).
24. Enter any actions planned for remediation.
25. Enter any notes about the site visit.
