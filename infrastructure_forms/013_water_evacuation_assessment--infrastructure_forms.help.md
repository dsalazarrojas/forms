# Water Evacuation Assessment - Help Guide
## Purpose
The Water Evacuation Assessment form is designed to collect information about water evacuation incidents, including the issue description, location, evacuation method, and any photos or notes relevant to the incident.

## How To Complete This Form
1. Please provide a brief description of the issue you are experiencing with water evacuation.
2. Enter the location where the issue occurred, including any relevant details such as address, city, or landmark.
3. Select the method used for evacuation, if applicable (e.g., Dry-Down, Other, Pumping, Suction Truck).
4. Add any additional notes or comments about the issue.
5. Upload up to 8 photos to help illustrate the issue.
6. Enter the date and time the issue occurred, if known.

## Field-by-Field Explanation

* **Issue Description** (`issue_description`, text, required): A brief description of the issue you are experiencing with water evacuation.
* **Location** (`issue_location`, text, required): The location where the issue occurred, including any relevant details such as address, city, or landmark.
* **Evacuation Method** (`evacuation_method`, select_multiple, required): Select the method used for evacuation, if applicable (e.g., Dry-Down, Other, Pumping, Suction Truck).
* **Notes** (`notes`, note, required): Additional notes or comments about the issue.
* **Photo 1-8** (`photo1-8`, note, required): Upload up to 8 photos to help illustrate the issue.
* **Issue Date** (`issue_date`, date, required): The date the issue occurred, if known.
* **Issue Time** (`issue_time`, time, required): The time the issue occurred, if known.
* **Issue Location Notes** (`issue_location_notes`, note, required): Any additional notes or comments about the location of the issue.
