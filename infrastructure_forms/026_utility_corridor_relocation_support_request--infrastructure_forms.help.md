# Utility Corridor Relocation Support Request - Help Guide

## Purpose
The Utility Corridor Relocation Support Request form is used to gather information about utility corridor relocation needs for a project. This form will be used to coordinate with stakeholders to ensure a smooth project process.

## How To Complete This Form
To complete this form, follow these steps:

1. Review the project details and ensure that you are submitting for the correct project.
2. Fill out the project details section with the correct information.
3. Provide details about the location where the utility corridor will be moved.
4. Enter the project start and end dates.
5. Upload any relevant documents that support the relocation request.
6. If necessary, upload any additional documents that may be required.
7. Confirm whether the project involves a contractor, utility company, or public agency.
8. Click submit to complete the form.

## Field-by-Field Explanation

* **Project Details** (`project_details`, text, required): This field is used to provide a brief description of the project. Please enter the name and a short description of the project.
* **Location** (`location`, text, required): This field is used to specify the location where the utility corridor will be relocated. Please enter the exact address or location identifier.
* **Project Start Date** (`project_start_date`, date, required): This field is used to enter the start date of the project.
* **Project End Date** (`project_end_date`, date, required): This field is used to enter the end date of the project.
* **Upload Documents** (`upload_documents`, text, optional): This field allows you to upload any relevant documents that support the relocation request.
* **Upload Additional Documents** (`upload_additional_documents`, text, optional): This field allows you to upload any additional documents that may be required for the project.
* **Contractor** (`contractor`, select_one, optional): This field indicates if a contractor is involved in the project. Please select 'Yes' if a contractor is involved.
* **Utility Company** (`utility_company`, select_one, optional): This field indicates if a utility company is involved in the project. Please select 'Yes' if a utility company is involved.
* **Public Agency** (`public_agency`, select_one, optional): This field indicates if a public agency is involved in the project. Please select 'Yes' if a public agency is involved.
