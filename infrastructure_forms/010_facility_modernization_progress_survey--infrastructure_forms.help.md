# Facility Modernization Progress Survey - Help Guide
## Purpose
The purpose of this form is to track the status and start dates of each phase of the facility modernization project.

## How To Complete This Form
1. Answer each question carefully, ensuring that you describe the current status of each phase accurately.
2. For each phase that has started, fill out the phase status and start date fields.
3. If a phase has not started, leave the corresponding fields blank.
4. For Phase 8, fill out the status and start date fields if it has started, or describe its status if it has not.

## Field-by-Field Explanation
* **Phase 1 Status** (`phase_1_status`, text, required): Describe the current status of Phase 1.
* **Phase 2 Start Date** (`phase_2_start_date`, date, required): Approximate date when Phase 2 started.
* **Phase 2 Status** (`phase_2_status`, text, required): Describe the current status of Phase 2.
* **Phase 3 Status** (`phase_3_status`, text, required): Describe the current status of Phase 3.
* **Phase 3 Start Date** (`phase_3_start_date`, date, required): Approximate date when Phase 3 started.
* **Phase 4 Status** (`phase_4_status`, text, required): Describe the current status of Phase 4.
* **Phase 4 Start Date** (`phase_4_start_date`, date, required): Approximate date when Phase 4 started.
* **Phase 5 Status** (`phase_5_status`, text, required): Describe the current status of Phase 5.
* **Phase 5 Start Date** (`phase_5_start_date`, date, required): Approximate date when Phase 5 started.
* **Phase 6 Status** (`phase_6_status`, text, required): Describe the current status of Phase 6.
* **Phase 6 Start Date** (`phase_6_start_date`, date, required): Approximate date when Phase 6 started.
* **Phase 7 Status** (`phase_7_status`, text, required): Describe the current status of Phase 7.
* **Phase 7 Start Date** (`phase_7_start_date`, date, required): Approximate date when Phase 7 started.
* **Phase 8 Status** (`phase_8_status`, text, optional): Describe the status of Phase 8, if it has started.
* **Phase 8 Start Date** (`phase_8_start_date`, date, optional): Approximate date when Phase 8 started, if it has started.
* **Phase 8 Status 2** (`phase_8_status_2`, select, required): If Phase 8 has progressed, choose whether it is progressing or not.
* **Phase 8 Status 2 Hint**: If you choose "Not Progressing", you can describe why Phase 8 has not progressed.
  Note: This field is only shown if Phase 8 has started.
