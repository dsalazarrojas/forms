# energy_simulation_input_form - Help Guide
## Purpose
The energy_simulation_input_form is designed to collect project data for energy simulation purposes. This form helps gather necessary information about a building's characteristics to assess its energy efficiency and identify areas for improvement.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the project data option that applies to your project.
2. Choose the building type that best describes the project.
3. Select the building size that is relevant to the project.
4. Choose the climate zone of the project location.
5. Enter the project location in the text field.
6. Enter the building address in the text field.
7. Select the primary building use (e.g., commercial, residential, industrial).
8. Enter the building design year.
9. Enter the project team name.
10. Enter the project lead name.
11. Enter the project contact information.
12. Select the project status (active or inactive).
13. Choose the building age range.
14. Select the climate type (e.g., tropical, desert, temperate, or continental).
15. Select the energy simulation method (e.g., ASHRAE, DOE, eQUEST).
16. Select the energy simulation scope (e.g., building, site, component).

## Field-by-Field Explanation

* **Project Data**: Select the option that best describes the project.
* **Building Type**: Choose the building type that best matches the project (e.g., Small Commercial, Large Commercial, High-rise Building, Residential, Industrial).
* **Building Size**: Select the building size that best describes the project (e.g., Small, Medium, Large).
* **Climate Zone**: Choose the climate zone that best matches the project location (e.g., 1, 2, 3, 4).
* **Project Location**: Enter the project location in plain text.
* **Building Address**: Enter the building address in plain text.
* **Building Use**: Select the primary building use (e.g., Commercial, Residential, Industrial, Agricultural).
* **Building Design Year**: Enter the year the building was designed.
* **Project Team Name**: Enter the name of the project team.
* **Project Lead Name**: Enter the name of the project lead.
* **Project Contact Info**: Enter the contact information for the project.
* **Project Status**: Select the project status (e.g., Active, Inactive).
* **Building Age**: Choose the building age range (e.g., 0-20, 21-40, 41-60).
* **Climate Type**: Select the climate type (e.g., Tropical, Desert, Temperate, Continental).
* **Energy Simulation Method**: Select the energy simulation method (e.g., ASHRAE, DOE, eQUEST).
* **Energy Simulation Scope**: Select the energy simulation scope (e.g., Building, Site, Component).

Note: The form requires project data to be accurate and relevant to the selected options.
