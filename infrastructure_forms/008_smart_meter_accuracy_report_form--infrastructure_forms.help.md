# Smart Meter Accuracy Report Form - Help Guide
## Purpose
This form is used to report any accuracy issues with a smart meter. It collects information about the meter's ID, readings, test results, and other relevant details.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the **Report Date** in the format YYYY-MM-DD.
2. Enter the **Meter ID** of the smart meter in question.
3. Select up to three **Meter Readings** that have been taken on the meter.
4. Enter the **Test Results** of the accuracy tests performed on the meter.
5. Attach evidence files for the **Evidence Attachments** section if necessary.
6. Select the **Utility Contact Details** and **Energy Contact Details** related to the meter.
7. Enter any additional **Notes** about the issue.
8. Choose the **Report Type** to categorize the report.
9. Select the **Submit Report** option to submit the report.
10. Enter the **Email to** address if you want to receive email notifications.
11. Enter the **Phone Number** if you want to receive phone calls.
12. Enter the **Form Title** if you want to add a title to the report.
13. Enter the **Report Date** and **Submit Date** in the format YYYY-MM-DD.
14. Enter the **Submit Time** in the format HH:MM:SS.
15. Select the **Report Status** to indicate the current status of the report.
16. Enter the **User ID**, **User Name**, and **User Email** if you are submitting the report on behalf of a user.
17. Enter the **User Phone** if you want to provide a phone number for the user.
18. Enter the **Assigned Tool** if a specific tool was used to perform the accuracy tests.
19. Enter the **Submitter** name if you are submitting the report on behalf of someone else.

## Field-by-Field Explanation
* **Report Date**: Date when the report was submitted. (YYYY-MM-DD)
* **Meter ID**: Unique identifier of the smart meter being reported.
* **Meter Readings**: Select up to three meter readings taken on the meter.
*   *Meter Reading 1*: First meter reading taken.
*   *Meter Reading 2*: Second meter reading taken.
*   *Meter Reading 3*: Third meter reading taken.
* **Test Results**: Results of the accuracy tests performed on the meter.
* **Evidence Attachments**: Attach files as evidence to support the report. (e.g., images, videos).
*   *File 1*: First file attachment.
*   *File 2*: Second file attachment.
*   *File 3*: Third file attachment.
* **Utility Contact Details**: Select the utility company related to the meter.
*   *Utility A*: First utility company option.
*   *Utility B*: Second utility company option.
*   *Utility C*: Third utility company option.
* **Energy Contact Details**: Select the energy provider related to the meter.
*   *Energy A*: First energy provider option.
*   *Energy B*: Second energy provider option.
*   *Energy C*: Third energy provider option.
* **Notes**: Additional comments or notes about the issue.
* **Report Type**: Categorize the report (e.g., error, discrepancy, etc.).
*   *Report Type 1*: First report type option.
*   *Report Type 2*: Second report type option.
*   *Report Type 3*: Third report type option.
* **Submit Report**: Select the option to submit the report.
*   *Submit Report 1*: First submit report option.
*   *Submit Report 2*: Second submit report option.
*   *Submit Report 3*: Third submit report option.
* **Email to**: Enter the email address to receive notifications.
* **Phone Number**: Enter the phone number to receive calls.
* **Form Title**: Enter a title for the report.
* **Report Date**: Date when the report was created. (YYYY-MM-DD)
* **Submit Date**: Date when the report was submitted. (YYYY-MM-DD)
* **Submit Time**: Time when the report was submitted. (HH:MM:SS)
* **Report Status**: Status of the report (e.g., pending, resolved, etc.).
*   *Report Status 1*: First report status option.
*   *Report Status 2*: Second report status option.
*   *Report Status 3*: Third report status option.
* **User ID**: Unique identifier of the user submitting the report.
* **User Name**: Name of the user submitting the report.
* **User Email**: Email of the user submitting the report.
* **User Phone**: Phone number of the user submitting the report.
* **Assigned Tool**: Name of the tool used to perform accuracy tests.
* **Submitter**: Name of the person submitting the report.

## Tips

* Please ensure that you have all the necessary information and attachments before submitting the report.
* Review your entries carefully before submitting the report.
* If you need to submit multiple reports for the same issue, use the same form but with different report dates.
