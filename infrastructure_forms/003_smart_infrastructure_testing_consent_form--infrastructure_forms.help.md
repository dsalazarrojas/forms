# smart_infrastructure_testing_consent_form - Help Guide
## Purpose
This form collects information and obtains consent from testing participants and other relevant parties involved in infrastructure testing.

## How To Complete This Form

To complete this form, follow these steps:

1. Select the relevant participants and contractors involved in the testing process.
2. Fill in the test project details, including the test location, date, and duration.
3. Provide consent for participant and observer contracts.
4. Enter project manager details, including consent and contract information.

## Field-by-Field Explanation

* **Testing Participants** (`id: 1`): Select all participants involved in the testing process.
	+ This field is not required.
	+ You can select multiple options from the dropdown list.
* **Testing Contractors** (`id: 2`): Select the contractors involved in the testing process.
	+ This field is not required.
	+ You can select one option from the dropdown list.
* **Test Project** (`id: 3`): Enter the test project details.
	+ This field is not required.
	+ Enter the project name or description.
* **Test Location** (`id: 4`): Enter the location where the test will take place.
	+ This field is not required.
	+ Enter the address or location name.
* **Test Date** (`id: 5`): Enter the date when the test will take place.

## Tips

* Make sure to review each field carefully and select the correct options for your specific testing project.
