# Digital Infrastructure Development Application - Help Guide
## Purpose
The Digital Infrastructure Development Application form is used to collect information about digital infrastructure development projects. This form gathers essential details about each project, including title, description, technical requirements, timelines, and contact information.

## How To Complete This Form

To complete this form, follow these steps:

1. Enter a brief title for the project in the **Project Title** field. This title will serve as a concise summary of the project.
2. In the **Project Description** field, provide a brief description of the project in a few sentences.
3. Select the **Technical Requirements** of the project from the available options.
4. Enter the **Project Timelines** in the required format (e.g., YYYY-MM-DD).
5. Enter the name of the **Organization** associated with the project.
6. Enter the name of the **Contact Person** for the project.
7. Enter the **Contact Email** of the contact person.
8. Enter the **Contact Phone** number of the contact person.
9. Select the **Category** of the project from the available options.
10. Select the **Assigned Tool** for the project from the available options.
11. Upload the **Output File** relevant to the project, if required.

## Field-by-Field Explanation

* **Project Title** (`project_title`, text, required): Enter a brief title for the project.
* **Project Description** (`project_description`, text, required): Describe the project in a few sentences.
* **Technical Requirements** (`technical_requirements`, select_one, required): Select the technical requirements of the project. Available options are Option 1, Option 2, and Option 3.
* **Project Timelines** (`project_timelines`, date, required): Enter the project timelines in the required format (e.g., YYYY-MM-DD).
* **Organization** (`organization`, text, required): Enter the name of the organization associated with the project.
* **Contact Person** (`contact_person`, text, required): Enter the contact person's name.
* **Contact Email** (`contact_email`, email, required): Enter the contact person's email.
* **Contact Phone** (`contact_phone`, text, required): Enter the contact person's phone number.
* **Review Notes** (`review_notes`, note, optional): Enter any review notes about the project.
* **Category** (`category`, select_one, required): Select the category of the project from the available options.
* **Assigned Tool** (`assigned_tool`, select_one, required): Select the assigned tool for the project from the available options.
* **Output File** (`output_file`, text, required): Upload the output file relevant to the project.

## Tips

* Make sure to fill in all required fields accurately and thoroughly.
* If you are unsure about any field, refer to the available options or ask for clarification.
* Review your entries carefully before submitting the form to ensure that all information is correct.
* If you need to upload a file, make sure it is in a supported format.
