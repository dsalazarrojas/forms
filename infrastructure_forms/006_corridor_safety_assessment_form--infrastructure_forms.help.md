# Corridor Safety Assessment Form - Help Guide

## Purpose
This form is designed to help facility managers or safety professionals assess the safety of corridors within their facilities. It is intended to be used to identify potential hazards, document risk levels, and schedule corrective actions.

## How To Complete This Form

1. To get started, please fill in the required fields:
	* If the corridor has a hazard, choose the risk level (Low, Moderate, High)
	* If the corridor has a hazard, describe the corrective action to be taken
	* If a hazard exists, confirm if it has been risk assessed
2. For scheduled tasks, fill in the date for the next inspection and the date this assessment was completed

## Field-by-Field Explanation

* **Hazard Identification (Corridor Safety Assessment Form)**:
	+ A free-text field to describe any hazards found in the corridor.
* **Risk Severity (Low, Moderate, High)**:
	+ Select the risk level of the hazard identified. Low indicates a relatively minor risk, Moderate indicates a moderate risk, and High indicates a significant risk.
* **Corrective Action**:
	+ A free-text field to describe the action to be taken to mitigate the hazard.
* **Facility Manager**:
	+ A free-text field to record the facility manager's name or contact information.
* **Risk Assessed**:
	+ Confirm if the hazard has been risk assessed. Select True if the hazard has been assessed, and False otherwise.
* **Inspection Schedule (Date)**:
	+ Enter the date for the next scheduled inspection of the corridor.
* **Next Inspection (Date)**:
	+ Enter the date by which this assessment is to be completed.
* **Completed Date**:
	+ Record the date this assessment was completed.

## Tips
- Please ensure that all required fields are filled in.
- If a hazard is identified, take note of the corrective action to be taken and schedule the next inspection accordingly.
