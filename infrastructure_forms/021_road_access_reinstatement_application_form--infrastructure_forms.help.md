# Road Access Reinstatement Application Form - Help Guide

## Purpose
The Road Access Reinstatement Application Form is designed for municipalities and utility contractors to collaborate on reinstatement projects. This form helps gather necessary information to facilitate the reinstatement process.

## How To Complete This Form
To complete this form, please follow these steps:

1. Review the form instructions and ensure you are submitting a new request for an existing project.
2. Fill out the form completely, providing accurate and relevant information for each field.
3. Select the correct options for each field from the provided choices.

## Field-by-Field Explanation

* **Project Details** (`project_details`): Enter a brief description of the project, including its location and purpose.
* **Project Schedule** (`project_schedule`): Select the applicable permits issued for the project:
	+ Permit 1
	+ Permit 2
	+ Permit 3
* **Permits Issued** (`permits_issued`): Select the permits issued for the project:
	+ Permit 1
	+ Permit 2
	+ Permit 3
* **Project Documents** (`project_documents`): Upload any relevant project documents, such as plans and reports.
* **Project Manager Name** (`project_manager_name`): Enter the name of the project manager.
* **Project Manager Email** (`project_manager_email`): Enter the email address of the project manager.
* **Utility Contractor Name** (`utility_contractor_name`): Enter the name of the utility contractor.
* **Utility Contractor Company** (`utility_contractor_company`): Enter the company name of the utility contractor.
* **Municipality Name** (`municipality_name`): Enter the name of the municipality.
* **Project Start Date** (`project_start_date`): Enter the start date of the project.
* **Project End Date** (`project_end_date`): Enter the end date of the project.
* **Reinstatement Type** (`reinstatement_type`): Select the type of reinstatement:
	+ Road Closure
	+ Utility Installation
	+ Other
* **Reinstatement Description** (`reinstatement_description`): Provide a brief description of the reinstatement project.
* **Reinstatement Reason** (`reinstatement_reason`): Explain the reason for the reinstatement project.
* **Municipality Contact Name** (`municipality_contact_name`): Enter the name of the municipality contact person.
* **Municipality Contact Email** (`municipality_contact_email`): Enter the email address of the municipality contact person.
* **Municipality Contact Phone** (`municipality_contact_phone`): Enter the contact phone number of the municipality.
* **Utility Contractor Contact Name** (`utility_contractor_contact_name`): Enter the name of the utility contractor contact person.
* **Utility Contractor Contact Email** (`utility_contractor_contact_email`): Enter the email address of the utility contractor contact person.
* **Utility Contractor Contact Phone** (`utility_contractor_contact_phone`): Enter the contact phone number of the utility contractor.
* **Project Status** (`project_status`): Select the current project status:
	+ In Progress
	+ Complete
	+ Cancelled
* **Reinstatement Status** (`reinstatement_status`): Select the reinstatement status:
	+ Complete
	+ Partial
	+ Cancelled
* **Project Notes** (`project_notes`): Provide any additional project notes.
* **Municipality Signature** (`municipality_signature`): Upload or enter the signature of the municipality representative.
* **Utility Contractor Signature** (`utility_contractor_signature`): Upload or enter the signature of the utility contractor representative.

Tips:

* Ensure all fields are filled out accurately and completely.
* Double-check for spelling and grammar errors before submitting the form.
* If you have any questions or concerns, please contact the relevant authorities or project manager.
