# flood_resilience_improvement_application_form - Help Guide
## Purpose
This form is used to collect and track information about flood resilience improvement projects, including project details, status, and supporting documents.

## How To Complete This Form
To complete this form, please follow these steps:

1. Provide a brief description of the project, including its objectives and goals.
2. Select the current project status from the given options.
3. Choose the flood zone where the project is located.
4. Select the relevant council responsible for the project.
5. Identify the property owner(s) involved with the project.
6. If required, upload any supporting documents relevant to the project.
7. Add any additional notes or comments about the project.

## Field-by-Field Explanation
* **Project Details** (`project_details`): A brief description of the project, including its objectives and goals.
* **Project Description** (`project_description`): A more detailed description of the project, explaining its scope and purpose.
* **Supporting Documents** (`supporting_documents`): A text box to upload any relevant supporting documents for the project.
* **Project Status** (`project_status`): Select the current status of the project from the given options.
	+ In progress: The project is currently active and ongoing.
	+ Completed: The project has been completed successfully.
	+ Cancelled: The project has been cancelled or terminated.
* **Project Manager** (`project_manager`): The person or organization responsible for overseeing the project.
* **Flood Zone** (`flood_zone`): Select the flood zone where the project is located.
* **Council** (`council`): Select the relevant council responsible for the project.
* **Property Owner** (`property_owner`): Identify the property owner(s) involved with the project.
* **Supporting Documents Upload** (`supporting_documents_upload`): A text box to upload any additional supporting documents for the project.
* **Notes** (`notes`): A text box for any additional comments or notes about the project.

## Tips
* Make sure to fill out all required fields.
* Use the provided options for project status, flood zone, council, and property owner.
* Ensure that you upload any relevant supporting documents for the project.
* Keep the project description and notes concise and clear.
