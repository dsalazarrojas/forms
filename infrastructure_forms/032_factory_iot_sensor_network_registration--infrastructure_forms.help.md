# Factory IoT Sensor Network Registration - Help Guide
## Purpose
This form is used to register a Factory IoT Sensor Network.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the Network Identifier, a unique identifier for the factory's IoT sensor network.
2. Select the type of sensor you are registering (e.g., temperature, humidity, pressure).
3. Enter the Installation Date, the date when the sensor was installed.
4. Provide the Location, where the sensor is installed.
5. If required, enter the Sensor Type ID, a unique identifier for the sensor type.

## Field-by-Field Explanation

* **Network Identifier** (`network_identifier`, text, required):
	+ This field requires a unique identifier for the factory's IoT sensor network.
	+ Please use a descriptive name that distinguishes this network from others.
* **Sensor Type** (`sensor_type`, select_one, optional):
	+ Select the type of sensor you are registering (e.g., temperature, humidity, pressure).
	+ This field helps categorize the sensor type for easier management and tracking.
* **Installation Date** (`installation_date`, date, required):
	+ Enter the date when the sensor was installed, in a standard date format (yyyy-mm-dd).
	+ This field is crucial for tracking sensor installation history and maintenance schedules.
* **Location** (`location`, text, required):
	+ Provide the location where the sensor is installed, e.g., a specific room or a floor in the factory.
	+ This field helps with sensor placement and troubleshooting.
* **Sensor Type ID** (`sensor_type_id`, number, optional):
	+ If required, enter a unique identifier for the sensor type, as provided by the sensor manufacturer or supplier.
	+ This field is useful for detailed sensor configuration and maintenance.

## Tips
- Ensure that you enter accurate and complete information to avoid errors.
- If you are unsure about any field, consult the relevant factory documentation or contact the relevant department for assistance.
- Review your entries before submitting the form to ensure that they are correct and complete.
