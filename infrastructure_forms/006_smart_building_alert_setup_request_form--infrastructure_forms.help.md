# smart_building_alert_setup_request_form - Help Guide
## Purpose
This form is used to set up and customize smart building alerts for various types of events.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the building for which you want to set up the alert.
2. Choose the alert type (High, Low, Medium).
3. Select the trigger type (Temperature, Humidity, Pressure).
4. Choose your notification preferences (SMS, Email, Phone).
5. Enter the alert name and description.
6. Add any relevant building notes.
7. Set the trigger value (e.g., temperature threshold).
8. Set the trigger value 2 (e.g., humidity threshold).
9. Choose the start time for the alert.
10. Choose the end time for the alert.
11. Select the repeat frequency (Daily, Weekly, Monthly).

## Field-by-Field Explanation

* **Request Info** (text, optional): Enter a brief description of the reason for setting up the alert.
* **Select Building** (select_one, optional): Select the building for which you want to set up the alert.
* **Alert Type** (select_one, optional): Choose the type of alert you want to set up (High, Low, Medium).
* **Trigger Type** (select_one, optional): Select the type of event that will trigger the alert (Temperature, Humidity, Pressure).
* **Notification Preferences** (select_multiple, optional): Choose how you want to receive notifications (SMS, Email, Phone).
* **Alert Name** (text, optional): Enter a name for the alert.
* **Description** (text, optional): Enter a description of the alert.
* **Building Notes** (note, optional): Add any relevant notes about the building.
* **Trigger Value** (number, optional): Enter the trigger value for the alert (e.g., temperature threshold).
* **Trigger Value 2** (number, optional): Enter the second trigger value (e.g., humidity threshold).
* **Start Time** (time, optional): Set the start time for the alert.
* **End Time** (time, optional): Set the end time for the alert.
* **Repeat Frequency** (select_multiple, optional): Choose how often the alert should repeat (Daily, Weekly, Monthly).

## Tips
* Make sure to enter the correct building for which you want to set up the alert.
* Double-check the alert type, trigger type, and notification preferences to ensure they match your needs.
* Use the building notes to add any relevant information about the building.
* Test the alert after setting it up to ensure it works as expected.
