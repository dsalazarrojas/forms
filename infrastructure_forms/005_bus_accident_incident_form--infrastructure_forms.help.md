# Bus Accident Incident Form - Help Guide
## Purpose
The Bus Accident Incident Form is a comprehensive tool used to report and document bus accidents. This form helps gather essential information to identify the cause, severity, and resolution of the incident, and to provide a clear account of what happened.

## How To Complete This Form
1. Review the form carefully and gather all necessary information about the incident before proceeding.
2. Complete each section of the form accurately and truthfully, using your best judgment and available information.
3. If any fields are not applicable or not available, indicate so in the corresponding field.

## Field-by-Field Explanation

* **Incident Date** (`incident_date`, required): Enter the date and time of the accident in the format `YYYY-MM-DD` and `HH:MM:SS`.
	+ Please ensure the date and time are accurate, including the year, month, and day of the month.
	+ Use a 24-hour clock for the time.
* **Incident Time** (`incident_time`, required): Enter the exact time of the incident in the format `HH:MM:SS`.
	+ Use a 24-hour clock.
* **Location** (`location`, required): Enter the street address or intersection where the accident occurred.
	+ Please provide a specific address or intersection, including the city, state, and ZIP code (if available).
* **Weather Conditions** (`weather_conditions`, required): Select the weather conditions at the time of the incident from the options: Clear, Cloudy, Rainy, Snowy, Foggy, Icy, or Other.
	+ Use the options provided to indicate the weather conditions.
* **Bus Number** (`bus_number`, required): Enter the fleet identification number of the bus.
	+ This is usually a unique number assigned to the bus by the operator or maintenance department.
* **License Plate** (`license_plate`, required): Enter the vehicle license plate number of the bus.
	+ This is the plate number assigned to the bus by the state.
* **Bus Driver Name** (`bus_driver_name`, required): Enter the name of the bus driver involved in the incident.
	+ This may be the driver's full name, including first, middle, and last name.
* **Driver Employee ID** (`driver_employee_id`, required): Enter the driver's employee ID number.
	+ This is usually a unique number assigned to the driver by the operator or HR department.
* **Driver Contact Number** (`driver_contact`, required): Enter the phone number of the bus driver.
	+ This may be a cell phone number or other contact number.
* **Number of Passengers Aboard** (`passengers_count`, required): Enter the total number of passengers on the bus at the time of the incident.
	+ Count all passengers on the bus, including drivers.
* **Accident Details** (`accident_details`, optional): Enter a brief description of the incident.
	+ This can include details about what happened before, during, and after the incident.
* **Type of Accident** (`accident_type`, required): Select the type of accident from the options: Collision with Vehicle, Collision with Fixed Object, Rollover, Pedestrian Incident, Passenger Injury Inside Bus, Mechanical Failure, or Other.
	+ Use the options provided to indicate the type of accident.
* **Other Vehicle Involved** (`other_vehicle_involved`, required): Select Yes or No to indicate if other vehicles were involved.
	+ Choose "Yes" only if other vehicles were involved in the incident.
* **Other Vehicle Details** (`other_vehicle_details`, optional): Enter a brief description of the other vehicles involved.
	+ This can include details about the make, model, and license plate of the other vehicles.
* **Detailed Description of Incident** (`accident_description`, required): Enter a detailed and accurate description of what happened during the incident.
	+ This should include all relevant details about the incident.
* **Passenger Injuries Reported** (`passengers_injuries`, required): Enter the number of passengers injured.
	+ Count all passengers injured during the incident.
* **Driver Injured** (`driver_injured`, required): Select Yes or No to indicate if the driver was injured.
	+ Choose "Yes" only if the driver was injured during the incident.
* **Injury Severity** (`injury_severity`, required): Select the severity of the injuries from the options: Minor, Moderate, Severe, Critical.
	+ Use the options provided to indicate the severity of the injuries.
* **Ambulance Called** (`ambulance_called`, required): Select Yes or No to indicate if emergency medical services were called.
	+ Choose "Yes" only if emergency medical services were called to the scene.
* **Police Report Filed** (`police_report`, required): Select Yes or No to indicate if a police report was filed.
	+ Choose "Yes" only if a police report was filed.
* **Police Report Number** (`police_report_number`, optional): Enter the police report number, if available.
	+ This may be the report number assigned by the police department.
* **Witness Names and Contacts** (`witness_information`, optional): Enter the names and contact information of any witnesses.
	+ This can include witness names, phone numbers, and addresses.
