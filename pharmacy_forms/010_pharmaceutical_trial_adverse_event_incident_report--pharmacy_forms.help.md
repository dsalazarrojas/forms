# Pharmaceutical Trial Adverse Event Incident Report - Help Guide
## Purpose
The Pharmaceutical Trial Adverse Event Incident Report form is used to collect information about adverse events that have occurred during pharmaceutical trials. This form helps in gathering data on the nature of the event, the treatment administered, the action taken, and other relevant details to assess the safety and efficacy of the trial.

## How To Complete This Form
- Carefully read and understand the form instructions before filling it out.
- Fill out each section accurately and comprehensively.
- Ensure that all required fields are filled in before submitting the form.
- If you are unsure about any field, refer to the "Field-by-Field Explanation" section for clarification.

## Field-by-Field Explanation

* **Patient Information** (Page 1): This section is used to gather personal details about the patient, such as their demographic information. Please fill out this section accurately and completely.
* **Incident Report** (Page 2): Describe the adverse event that occurred during the trial. Please be as specific as possible about what happened.
* **Event Details** (Page 3): Select the event date and time from the options provided. Additionally, select the duration of the event from the provided options.
*   • **Event Date**: Date on which the adverse event occurred.
*   • **Event Date (if within the last 3 months)**: Date on which the adverse event occurred, if within the last 3 months.
*   • **Event Time**: Time at which the event occurred.
*   • **Duration**: Length of time the event lasted.
* **Adverse Event Details** (Page 4): Provide a detailed description of the adverse event.
* **Treatment Administered** (Page 5): Select the medication, dosage, and route of administration for the treatment that was given to the patient.
*   • **Medication**: Select the name of the medication administered.
*   • **Dosage**: Amount of medication administered.
*   • **Route of Administration**: Route in which the medication was administered.
* **Action Taken** (Page 6): Choose the actions taken to address the adverse event.
*   • **Action Taken 1**: Select the first action taken.
*   • **Action Taken 2**: Select the second action taken.
*   • **Action Taken 3**: Select the third action taken.
* **Follow Up Information** (Page 7): Enter any additional information about the follow-up process.
* **Follow-up Plan** (Page 8): Enter details about the planned follow-up schedule.
* **Next Follow-up Date** (Page 9): Enter the date on which the next follow-up is scheduled.
*   • **Date**: Date of the next scheduled follow-up.
* **Follow-up Status** (Page 10): Select the status of the follow-up.
*   • **Completed**: Follow-up completed.
*   • **Due**: Follow-up is due.
*   • **Not Due**: Follow-up is not due.
* **Follow-up Comments** (Page 11): Enter any additional comments about the follow-up.
* **Incident Status** (Page 12): Select the status of the incident.
*   • **Reported**: Incident has been reported.
*   • **Resolved**: Incident has been resolved.
*   • **Unknown**: Incident status is unknown.
* **Incident Reporter** (Page 13): Select who reported the incident.
*   • **Research Site**: Incident reported by the research site.
*   • **Study Coordinator**: Incident reported by the study coordinator.
*   • **Other**: Incident reported by other.
* **Reporter Phone** (Page 14): Enter the phone number of the incident reporter.
* **Reporter Email** (Page 15): Enter the email address of the incident reporter.

# Tips
- Double-check all fields for accuracy and completeness before submitting the form.
- If you are unsure about any field, refer to the "Field-by-Field Explanation" section for clarification.
- Ensure that you have all necessary information before submitting the form.
- If you need to make any changes or updates, refer to the original form instructions for guidance.
