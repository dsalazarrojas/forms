# hand_hygiene_observation_form - Help Guide
## Purpose
This form is used to collect information on hand washing practices among patients and staff in a clinical setting.

## How To Complete This Form

* Fill out the form for a specific patient or staff member.
* Make sure you are not duplicating an existing observation.
* Answer each field according to your actual observation.

## Field-by-Field Explanation

* **Patient Information (<patient_info>, Text, Required: No)**:
	+ Enter the patient's name and ID number.
* **Date (<date_observed>, Date, Required: No)**:
	+ Enter the date you observed the patient or staff member's hand washing practice.
* **Observed By (<observation_by, Text, Required: No)**:
	+ Enter your name and ID number.
* **Hand Washing Technique (<hand_washing_technique, Select One, Required: No)**:
	+ Choose one of the following options:
		- Hand Hygiene Hand Sanitizer
		- Hand Hygiene Gloves
		- Hand Hygiene Soap
* **Hand Washing Location (<hand_washing_location, Select Multiple, Required: No)**:
	+ Choose one or multiple of the following options:
		- Bathroom Sink
		- Bathroom Sink (Handwashing Station)
		- Other
* **Hand Washing Frequency (<hand_washing_frequency, Select Multiple, Required: No)**:
	+ Choose one or multiple of the following options:
		- Frequently
		- Occasionally
		- Rarely
		- Never
* **Hand Washing Duration (<hand_washing_duration, Number, Required: No)**:
	+ Enter the duration of hand washing in minutes.
* **Other Location (<hand_washing_other_location, Text, Required: No)**:
	+ Enter any other location where hand washing was observed.
* **Other Frequency (<hand_washing_other_frequency, Text, Required: No)**:
	+ Enter the frequency of hand washing at other locations.
* **Other Duration (<hand_washing_other_duration, Text, Required: No)**:
	+ Enter the duration of hand washing at other locations.
* **Observed Completed (<observation_completed, Date, Required: No)**:
	+ Enter the date you completed the observation.
* **Hand Washing Comments (<hand_washing_comments, Text, Required: No)**:
	+ Enter any comments about the hand washing practice.
* **Completed By (<observation_completed_by, Text, Required: No)**:
	+ Enter your name and ID number.
* **Completed At (<observation_completed_at, Time, Required: No)**:
	+ Enter the time you completed the observation.
* **Comments (<comments, Text, Required: No)**:
	+ Enter any other comments about the observation.
* **Other (<hand_washing_other, Text, Required: No)**:
	+ Enter any other information about the hand washing practice.
* **Hand Washing Frequency Comments (<hand_washing_frequency_comments, Text, Required: No)**:
	+ Enter any comments about the hand washing frequency.
* **Hand Washing Duration Comments (<hand_washing_duration_comments, Text, Required: No)**:
	+ Enter any comments about the hand washing duration.
