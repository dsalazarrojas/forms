# personal_health_tracker_form - Help Guide
## Purpose
This form is designed to collect personal health metrics from users. It is intended for individuals to track their daily activities, habits, and overall well-being. This form is not intended for clinical use or diagnosis; it is a personal tool for users to monitor their health over time.

## How To Complete This Form
To complete this form, simply select the options that apply to you for each category. You can choose as many or as few options as you'd like for each category. You do not need to complete every field if you don't have information to report.

## Field-by-Field Explanation

### Daily Metrics (Select one or more metrics that apply)
- **Weight**: Select this option if you've tracked your weight on a given day.
- **Body Temperature**: Select this option if you've taken your body temperature on a given day.
- **Heart Rate**: Select this option if you've tracked your heart rate on a given day.
- **Blood Pressure**: Select this option if you've tracked your blood pressure on a given day.
- **Blood Oxygen Saturation**: Select this option if you've monitored your blood oxygen saturation on a given day.
- **Glucose**: Select this option if you've tested your blood glucose on a given day.
- **Blood Glucose**: Select this option if you've monitored your blood glucose on a given day.

### Sleep (Select one or more metrics that apply)
- **Duration Hours**: Select this option if you've tracked the number of hours you've slept on a given day.
- **Quality**: Select this option if you've assessed the quality of your sleep on a given day.
- **Medication**: Select this option if you've taken any medication that affects your sleep on a given day.
- **Sleep Disruptions**: Select this option if you've experienced any disruptions to your sleep on a given day.

### Activity (Select one or more metrics that apply)
- **Exercise**: Select this option if you've engaged in any physical activity on a given day.
- **Mobility**: Select this option if you've had any mobility issues on a given day.
- **Medication**: Select this option if you've taken any medication that affects your activity on a given day.
- **Other Activities**: Select this option if you've engaged in any other activities on a given day that are not mentioned above.

### Mood (Select one or more options that apply)
- **Anxious**: Select this option if you've felt anxious on a given day.
- **Sad**: Select this option if you've felt sad on a given day.
- **Frustrated**: Select this option if you've felt frustrated on a given day.
- **Other Mood**: Select this option if you've experienced any other mood on a given day.
- **None**: Select this option if you've not experienced any of the above moods on a given day.

### Notes (Optional)
- **Notes**: This field is an optional text field for you to add any additional information or comments about your health on a given day.

## Tips
Remember to track your health metrics consistently to get the most accurate picture of your health over time. This form is designed to be used for personal tracking purposes, so don't hesitate to choose as many or as few options as apply to you. If you have any concerns or questions, please reach out to your healthcare provider for guidance.
