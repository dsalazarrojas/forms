# Skin Check Form - Help Guide
## Purpose
The Skin Check Form is used to collect information about the skin health and medical history of patients. This form helps healthcare professionals gather essential details about a patient's skin concerns, medical history, and planned treatments.

## How To Complete This Form
To complete this form, follow these steps:

1. Review the form carefully and answer each question accurately.
2. Select the appropriate option for each question, if applicable.
3. Fill in the date and time of the last examination and next examination, if applicable.
4. Provide detailed descriptions in the text field for skin findings, if necessary.
5. Make sure to answer all required fields.

## Field-by-Field Explanation
* **Skin concerns** (`skin_concerns`, `note`, not required): Please describe any skin concerns you have, such as redness, itchiness, or other issues.
* **Medical history** (`medical_history`, `select_multiple`, not required): Indicate whether you have a medical history, if so, select 'Yes', or if not, select 'No'.
* **Which is the most important concern?** (`skin_concerns_important`, `select_one`, not required): If you have multiple skin concerns, select the one that is most important to you.
* **Date last examined** (`date_last_examined`, `date`, not required): If you have been examined by a healthcare professional recently, please enter the date of the last examination.
* **Time last examined** (`time_last_examined`, `time`, not required): If you have been examined by a healthcare professional recently, please enter the time of the last examination.
* **Skin findings** (`skin_findings`, `text`, not required): Please provide a detailed description of any noticeable skin findings, such as rashes, lesions, or sores.
* **Most important finding** (`skin_findings_important`, `select_one`, not required): If you have multiple skin findings, select the one that is most important to you.
* **Treatment planned** (`treatment_planned`, `select_multiple`, not required): Indicate whether treatment has been planned, if so, select 'Yes', or if not, select 'No'.
* **Date next examined** (`date_next_examined`, `date`, not required): If you have a next examination scheduled, please enter the date of the next examination.
* **Time next examined** (`time_next_examined`, `time`, not required): If you have a next examination scheduled, please enter the time of the next examination.
