# Covid 19 Daily Status Update Form - Help Guide
## Purpose
This form is used to gather information about patients' daily health status during a Covid-19 outbreak. It is a daily report that healthcare professionals need to fill out for each patient they are caring for.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the relevant information from each category.
2. Fill out the required fields marked as "required" in the form.
3. Leave optional fields blank if not applicable.

## Field-by-Field Explanation
* **Medical Team** (`medical_team`, `select_multiple`): 
  Select whether the patient is currently under the care of a medical team. This can be 'Yes' or 'No'.
* **Patient** (`patient`, `select_multiple`):
  Select whether the patient is currently under observation, treatment, or other medical care. This can be 'Yes' or 'No'.
* **Vaccination Status** (`vaccination_status`, `select_one`):
  Select the patient's current vaccination status. This can be 'Active' or 'Inactive'.
* **Vaccination Date** (`vaccination_date`, `date`):
  Enter the date of the patient's last vaccination, if any. Leave blank if not applicable.
* **Symptoms** (`symptoms`, `text`):
  Describe any symptoms the patient is experiencing, such as fever, cough, or difficulty breathing.
* **Test Results** (`test_results`, `text`):
  Enter any test results or lab findings related to the patient's Covid-19 status.
* **Contact History** (`contact_history`, `text`):
  List any contacts the patient has had with others who have been diagnosed with Covid-19.
* **Hospitalization** (`hospitalization`, `select_one`):
  Select whether the patient is currently hospitalized. This can be 'Yes' or 'No'.
* **Medical Condition** (`medical_condition`, `select_multiple`):
  Select any pre-existing medical conditions the patient has, such as diabetes or heart disease.
* **Notes** (`notes`, `note`):
  Add any additional comments or notes about the patient's status.

## Tips
- Always select 'Yes' or 'No' for options where applicable.
- Use the notes field for any additional information that is not covered by the other fields.
- Fill out the form at the end of each shift, or as soon as you have updated information about the patient. 
- If you are unsure about any information, leave the field blank and note it in the notes field. 
- Make sure to update the form every time the patient's status changes.
