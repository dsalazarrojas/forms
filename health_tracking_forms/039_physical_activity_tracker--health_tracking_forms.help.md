# Physical Activity Tracker - Help Guide
## Purpose
The Physical Activity Tracker form is designed to help you record and monitor your physical activities. This form will help you set goals, track progress, and analyze your habits.
## How To Complete This Form
To complete this form, follow these steps:

1.  Select the type of activity you performed (e.g., walking, running, swimming, cycling).
2.  Choose the intensity of the activity (e.g., low, high).
3.  Select how often you performed the activity (e.g., daily, weekly, monthly).
4.  Enter the duration of the activity in minutes.
5.  Record the distance traveled during the activity in kilometers or miles.
6.  Add any additional notes about the activity.
7.  If necessary, add an embed link, URL, title, or description.
8.  If adding an embed, select the image or video type.
9.  Enter the width and height of the embed if applicable.
10.  Finally, align the embed accordingly.

## Field-by-Field Explanation
* **Track Your Activities** (`physical_activity_tracker_form`): This is the main title of the form.
* **Activity Type** (`physical_activity_tracker_form_activity_type`): Select the type of activity you performed, such as walking, running, swimming, or cycling.
* **Activity Intensity** (`physical_activity_tracker_form_intensity`): Choose the intensity of the activity, such as low, high.
* **How Often** (`physical_activity_tracker_form_frequency`): Select how often you performed the activity, such as daily, weekly, or monthly.
* **Duration (minutes)** (`physical_activity_tracker_form_duration`): Enter the duration of the activity in minutes.
* **Distance (km or miles)** (`physical_activity_tracker_form_distance`): Record the distance traveled during the activity in kilometers or miles.
* **Notes** (`physical_activity_tracker_form_notes`): Add any additional notes about the activity.
* **Embed Link** (`physical_activity_tracker_form_embed_link`): If you added an embed, select this option to link to it.
* **Embed URL** (`physical_activity_tracker_form_embed_url`): If you added an embed, enter the URL of the embed.
* **Embed Title** (`physical_activity_tracker_form_embed_title`): If you added an embed, enter the title of the embed.
* **Embed Description** (`physical_activity_tracker_form_embed_description`): If you added an embed, enter a description of the embed.
* **Embed Image** (`physical_activity_tracker_form_embed_image`): If you added an embed, select the image type.
* **Embed Video** (`physical_activity_tracker_form_embed_video`): If you added an embed, select the video type.
* **Embed Audio** (`physical_activity_tracker_form_embed_audio`): If you added an embed, select the audio type.
* **Embed Code** (`physical_activity_tracker_form_embed_code`): If you added an embed, enter any additional code.
* **Embed Script** (`physical_activity_tracker_form_embed_script`): If you added an embed, enter the script.
* **Embed Style** (`physical_activity_tracker_form_embed_style`): If you added an embed, select the style.
* **Embed Width** (`physical_activity_tracker_form_embed_width`): If you added an embed, enter the width.
* **Embed Height** (`physical_activity_tracker_form_embed_height`): If you added an embed, enter the height.
* **Embed Align** (`physical_activity_tracker_form_embed_align`): If you added an embed, select the alignment.

This guide assumes that users understand how to fill out the form, and therefore, does not include step-by-step instructions for each field. If you need clarification on any of the fields, please refer back to this guide.
