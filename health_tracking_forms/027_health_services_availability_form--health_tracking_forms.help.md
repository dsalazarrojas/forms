# health_services_availability_form - Help Guide
## Purpose
This form is designed to collect information about health services availability to help healthcare providers manage their schedules and services.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the services offered by your health organization (e.g., "service 1", "service 2", "service 3").
2. Choose the days of the week on which you are available (e.g., Monday, Tuesday, Wednesday, Thursday, Friday, Saturday, Sunday).
3. Enter any additional contact information for patients to use when inquiring about services.
4. You may also need to enter other details such as assigned tool, output file, form ID, form category, description, and form version, but these are less commonly used fields.

## Field-by-Field Explanation
- **Patient Inquiries** (`patient_inquiries`, text, optional): Enter any additional details you'd like to provide about patient inquiries.
- **Services Offered** (`services_offered`, select_one, optional): Select the services offered by your health organization.
  - This field allows you to choose one service option.
- **Availability Days** (`availability_days`, select_multiple, required): Choose the days of the week on which you are available.
  - You must select at least one day.
- **Contact Info** (`contact_info`, text, optional): Enter any additional contact information for patients to use when inquiring about services.
- **Assigned Tool** (`assigned_tool`, text, optional): Enter the name of the assigned tool.
- **Output File** (`output_file`, text, optional): Enter the name of the output file.
- **Form ID** (`form_id`, text, optional): Enter the ID of the form.
- **Form Category** (`form_category`, text, optional): Enter the category of the form.
- **Form Description** (`form_description`, text, optional): Enter a description of the form.
- **Assigned Tool Name** (`assigned_tool_name`, text, optional): Enter the name of the assigned tool.
- **Category** (`category`, text, optional): Enter the category.
- **Description** (`description`, text, optional): Enter a description.
- **Output File Name** (`output_file_name`, text, optional): Enter the name of the output file.
- **Form Ids** (`form_ids`, text, optional): Enter the IDs of the form.
- **Category Name** (`category_name`, text, optional): Enter the name of the category.
- **Description Name** (`description_name`, text, optional): Enter the name of the description.
- **Assigned Tool Version** (`assigned_tool_version`, text, optional): Enter the version of the assigned tool.
- **Output File Version** (`output_file_version`, text, optional): Enter the version of the output file.
- **Assigned Tool Version Name** (`assigned_tool_version_name`, text, optional): Enter the name of the assigned tool version.
- **Form Version** (`form_version`, text, optional): Enter the version of the form.
- **Form Version 2** (`form_version_2`, text, optional): Enter the second version of the form.
- **Form Version Name** (`form_version_name`, text, optional): Enter the name of the form version.
- **Version** (`version`, text, optional): Enter the version.
- **Version Name** (`version_name`, text, optional): Enter the name of the version.

Note: This form appears to have some fields with similar labels, which may be a result of a template or design convention. Be cautious not to confuse them when completing the form.
