# monthly_drug_inventory_form - Help Guide
## Purpose
The monthly_drug_inventory_form is used to track the current status of assets within a given month. This form helps ensure that all assets are accounted for, up to date, and accurate. It's a crucial tool for inventory management and reporting.

## How To Complete This Form
1. Fill out all required fields: `business_id`, `inventory_date`, and `notes` are marked as required fields. Make sure to provide accurate and up-to-date information in these fields.
2. Provide asset-specific details: Complete the fields related to the asset, such as `asset_quantity`, `asset_unit`, `asset_status`, `asset_category`, `asset_tags`, and `asset_location`.
3. Review and confirm: Double-check all fields before submitting the form.

## Field-by-Field Explanation

* **Business id** (`business_id`): This field is used to identify the business entity associated with the asset. Enter the correct business identifier.
* **Inventory date** (`inventory_date`): Enter the date for the inventory being recorded.
* **Asset value** (`asset_value`): Enter the monetary value of the asset.
* **Asset description** (`asset_description`): Provide a brief description of the asset.
* **Asset quantity** (`asset_quantity`): Enter the number of assets in inventory.
* **Asset unit** (`asset_unit`): Specify the unit of measurement for the asset quantity.
* **Asset serial number** (`asset_serial_num`): Enter the asset's serial number.
* **Asset model number** (`asset_model_num`): Enter the asset's model number.
* **Asset manufacturer** (`asset_manufacturer`): Enter the manufacturer of the asset.
* **Asset status** (`asset_status`): Choose the current status of the asset (Available, Lost, Stolen, or Damaged).
* **Asset category** (`asset_category`): Select a category for the asset.
* **Asset tags** (`asset_tags`): Select any relevant tags for the asset.
* **Asset location** (`asset_location`): Enter the current location of the asset.
* **Asset condition** (`asset_condition`): Describe the current condition of the asset.
* **Asset notes** (`asset_notes`): Enter any additional notes about the asset.
* **Asset tags 2** (`asset_tags2`): Select any relevant tags for the asset.
* **Asset serial number 2** (`asset_serial_num2`): Enter the asset's serial number.
* **Asset model number 2** (`asset_model_num2`): Enter the asset's model number.
* **Asset manufacturer 2** (`asset_manufacturer2`): Enter the manufacturer of the asset.
* **Asset status 2** (`asset_status2`): Choose the current status of the asset.
* **Business id 2** (`business_id2`): Select the business identifier for the asset.
* **Asset category 2** (`asset_category2`): Select a category for the asset.
* **Business id 3** (`business_id3`): Select the business identifier for the asset.
* **Asset tags 2** (`asset_tags2`): Select any relevant tags for the asset.
* **Asset serial number 2** (`asset_serial_num2`): Enter the asset's serial number.
* **Asset model number 2** (`asset_model_num2`): Enter the asset's model number.
* **Asset manufacturer 2** (`asset_manufacturer2`): Enter the manufacturer of the asset.

Note: In the fields that are marked as "select_multiple" or "select_one", select all that apply from the given options. If unsure of any field or option, consult with the asset administrator.
