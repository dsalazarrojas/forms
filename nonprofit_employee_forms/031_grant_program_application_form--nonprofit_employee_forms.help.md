# grant_program_application_form - Help Guide
## Purpose
The grant program application form is used to collect information from non-profit organizations about their grant programs. This form is used to gather details about the grant program the applicant is interested in, including the program name, grant amount, grant type, and grant status.

## How To Complete This Form
To complete the grant program application form, follow these steps:

1. Fill out the grant program details section, including the program name and grant amount.
2. Select the grant type (yes or no).
3. Select the grant status (active or inactive).
4. Provide details about the applicant and their organization.
5. Enter the applicant's name.
6. Enter the applicant's organization name.
7. Enter the contact person's name.
8. Enter the contact person's email address.
9. Enter the contact person's phone number.

## Field-by-Field Explanation

* **Grant Program Details** (Grant Program Details, text, required):
	+ This section is used to enter the details of the grant program, including the program name and grant amount.
* **Program Name** (program_name, text, required):
	+ Enter the name of the grant program you are interested in applying to.
* **Grant Amount** (Grant Amount, number, required):
	+ Enter the amount of the grant you are applying for.
* **Grant Type** (Grant Type, select_one, required):
	+ Select 'Yes' if the grant is for a specific amount, 'No' if it is not.
* **Grant Status** (Grant Status, select_multiple, required):
	+ Select 'Active' if the grant is currently active, 'Inactive' if it is not.
* **Applicant Details** (Applicant Details, text, required):
	+ Enter a brief description of the applicant and their organization.
* **Applicant Name** (Applicant Name, text, required):
	+ Enter the name of the applicant.
* **Applicant Organization** (Applicant Organization, text, required):
	+ Enter the name of the applicant's organization.
* **Contact Name** (Contact Name, text, required):
	+ Enter the name of the contact person.
* **Contact E-mail** (Contact E-mail, email, required):
	+ Enter the email address of the contact person.
* **Contact Phone** (Contact Phone, text, required):
	+ Enter the phone number of the contact person.

## Tips

* Please ensure that you have not already filled out this form for the same grant program in a previous application.
* Double-check your entries for accuracy before submitting the form.
* If you have any questions or issues while filling out the form, contact the relevant organization or support team for assistance.
