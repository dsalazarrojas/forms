# Generic Volunteer Application Form - Help Guide
## Purpose
The Generic Volunteer Application Form is designed to collect information from potential volunteers to match them with suitable opportunities. Please fill out the form accurately and thoroughly to ensure a successful volunteer match.

## How To Complete This Form

1. Start by filling out the form completely, including all required fields (marked as "required" in the form).
2. Double-check your information for accuracy before submitting the form.
3. Be honest and realistic when providing your availability and preferences.

## Field-by-Field Explanation

* **First Name**: Please enter your first name as you would like it to appear in our records.
	+ Type: Text field
	+ Required: Not required
* **Email**: Enter your primary email address where you can be reached for communication purposes.
	+ Type: Email field
	+ Required: Not required
* **Phone**: Provide your phone number where you can be reached for last-minute updates or changes.
	+ Type: Text field
	+ Required: Not required
* **Address**: Enter your address for contact and delivery purposes.
	+ Type: Text field
	+ Required: Not required
* **City**: Enter the city where you live.
	+ Type: Text field
	+ Required: Not required
* **State**: Enter the state where you reside.
	+ Type: Text field
	+ Required: Not required
* **Zip**: Enter your zip code for delivery and address verification purposes.
	+ Type: Text field
	+ Required: Not required
* **Emergency Contact**: Provide the name and contact information of a person to contact in case of an emergency.
	+ Type: Text field
	+ Required: Not required
* **Volunteer Hours**: If you're able to volunteer for a specific number of hours per week, please enter that number here.
	+ Type: Number field
	+ Required: Not required
* **Volunteer Frequency**: Select how often you'd like to volunteer. Please choose one of the following options:
	+ Type: Select one field
	+ Required: Not required
	+ Options: Label 1, Label 2, Label 3
* **Volunteer Role**: Select the volunteer role you're interested in. Please choose one of the following options:
	+ Type: Select one field
	+ Required: Not required
	+ Options: Option 1, Option 2
* **Shift**: Select the shift(s) you're interested in volunteering for. Please choose one or more of the following options:
	+ Type: Select multiple field
	+ Required: Not required
	+ Options: Option 1, Option 2, Option 3
* **Date**: If you have a specific date in mind for volunteering, please enter it here.
	+ Type: Date field
	+ Required: Not required
* **Time**: If you have a specific time in mind for volunteering, please enter it here.
	+ Type: Time field
	+ Required: Not required
* **Duration**: If you'd like to volunteer for a specific duration, please enter that here.
	+ Type: Text field
	+ Required: Not required
* **Frequency**: Select the frequency of your volunteer sessions. Please choose one of the following options:
	+ Type: Select one field
	+ Required: Not required
	+ Options: Option 1, Option 2, Option 3

## Tips

* Double-check your information for accuracy before submitting the form.
* Be honest and realistic when providing your availability and preferences.
* If you have any questions or concerns, please don't hesitate to contact us.
