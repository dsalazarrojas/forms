# Community Service Report Form - Help Guide
## Purpose
The Community Service Report Form is used to report community service activities to the organization. This form helps the organization track and document the work done in the community, which can be used for reporting purposes, such as to the board of directors or external funders.

## How To Complete This Form
To complete this form, follow these steps:

1.  Fill in the **Reporter full name**, which should be your full name as an employee of the organization.
2.  Enter the **Reporting date**, which is the date you are submitting this report.
3.  Select the **Program name**, which is the name of the program or activity you are reporting on.
4.  Provide a brief **Summary of activities**, which should describe the activities and outcomes of the community service.
5.  If applicable, enter the **Number of participants**, which should be the number of attendees or volunteers.
6.  Describe **Notable outcomes and impact**, which should highlight measurable results if available.
7.  If any **Issues encountered** were experienced, describe them in this field.
8.  If you have attached **Attachments summary**, which can include photos or documents, list them here.

## Field-by-Field Explanation
* **Reporter full name**: 
  • Type: text
  • Required: true
  • Hint: Person completing the report
* **Reporting date**: 
  • Type: date
  • Required: true
  • Hint: Date of report submission
* **Program name**: 
  • Type: text
  • Required: true
  • Hint: Program or activity being reported on
* **Summary of activities**: 
  • Type: text
  • Required: true
  • Hint: Brief narrative of activities and outcomes
* **Number of participants**: 
  • Type: number
  • Required: false
  • Hint: Count of attendees or volunteers
* **Notable outcomes and impact**: 
  • Type: text
  • Required: false
  • Hint: Describe measurable results if available
* **Issues encountered**: 
  • Type: text
  • Required: false
  • Hint: Note any challenges and recommended actions
* **Attachments summary**: 
  • Type: text
  • Required: false
  • Hint: List attached photos or documents
* **Attachments**: 
  • Type: text
  • Required: false
  • Hint: List attached photos or documents
