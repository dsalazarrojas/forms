# Virtual Shift Report For Volunteers - Help Guide
## Purpose
The Virtual Shift Report For Volunteers form is used to report volunteer work hours and shifts. This form is intended for volunteers to accurately and completely report their work hours and any relevant details about their shifts.

## How To Complete This Form
To complete this form, follow these steps:

1. Ensure you have the following information ready:
	* Shift start time
	* Shift date
	* Shift start date (if different from shift date)
	* Volunteer name
	* Nonprofit employee name (if applicable)
	* Shift report comments (if applicable)
	* Shift report frequency
	* Volunteer role and organizations
2. Start by filling out the volunteer shift report form. If you are unsure about any field, refer to the field-by-field explanation below.

## Field-by-Field Explanation
### 1. Volunteer Shift Report
* **Volunteer Shift Report** (`shift_start_time`, `shift_date`, `shift_start_date`): This section is used to record the start time, date, and start date of the volunteer shift.
* **Volunteer Name** (`volunteer_name`): Enter your name as a volunteer.
* **Volunteer Shift Hours Worked** (`volunteer_shift_hours_worked`): Report the hours you have worked during the shift.
* **Volunteer Shift Report Comments** (`volunteer_shift_report_comments`): Enter any comments or notes about the shift, if necessary.
* **Nonprofit Employee** (`nonprofit_employee_id`): Enter the name of the nonprofit employee you reported to. This is an optional field, but it helps us keep track of who reported to whom.
* **Volunteer Organizations** (`volunteer_organizations`): Check if you are affiliated with any volunteer organizations. This field is used to determine if you have an association with any organizations.
* **Volunteer Role** (`volunteer_role`): Check your role as a volunteer, if you have any. This field is used to understand your position within any associated organizations.
* **Shift Date** (`shift_date`): Enter the date of the shift.
* **Shift Start Date** (`shift_start_date`): Enter the start date of the shift. This field is only necessary if the shift start date differs from the shift date.
* **Volunteer Shift Report Frequency** (`volunteer_shift_report_frequency`): Check the frequency of your volunteer shifts, if applicable.
* **Nonprofit Employee** (`nonprofit_employee_id`): Enter the name of the nonprofit employee you reported to. This field is optional, but it helps us keep track of who reported to whom.

## Tips
* Please double-check all fields for accuracy before submitting the form.
* Make sure to report all shifts, even if they are part of the same event or project.
* If you have any questions or concerns, refer back to this guide for clarity.
