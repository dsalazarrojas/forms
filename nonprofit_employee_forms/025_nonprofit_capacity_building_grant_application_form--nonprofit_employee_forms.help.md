# Nonprofit Capacity Building Grant Application Form - Help Guide
## Purpose
This form is used to collect information for the Nonprofit Capacity Building Grant Application, which is used to support the development of nonprofit organizations through grants.

## How To Complete This Form
To complete this form, follow these steps:

1. Review the form carefully to ensure you are familiar with the questions and the information required.
2. Answer each question accurately and completely, providing as much detail as possible.
3. Make sure to fill in all required fields (indicated by *required: true*).

## Field-by-Field Explanation
### Nonprofit Capacity Building Grant Form
* **Nonprofit Capacity Building Grant Form** (`nonprofit_capacity_building_grant_form`, text, *optional*): This is the title of the form. While optional, it is recommended that you enter a descriptive title to help the grant committee understand the focus of the application.
### Nonprofit Organization
* **Nonprofit Organization** (`nonprofit_organization`, select_one, *optional*): This question asks if the applicant is a nonprofit organization. Please select "Yes" if the applicant is a nonprofit organization.
### Nonprofit Organization Address
* **Nonprofit Organization Address** (`nonprofit_organization_address`, text, *optional*): This question asks for the address of the nonprofit organization. Enter the full address, including the street address, city, state, and zip code.
### Contact Person
* **Contact Person** (`contact_person`, text, *optional*): Enter the name and title of the person responsible for completing this form.
### Contact Email
* **Contact Email** (`contact_email`, email, *optional*): Enter the contact email of the person responsible for completing this form. Make sure to enter a valid email address.
### Contact Phone
* **Contact Phone** (`contact_phone`, text, *optional*): Enter the contact phone number of the person responsible for completing this form.
### Project Title
* **Project Title** (`project_title`, text, *optional*): Enter a brief title for the project or initiative the nonprofit organization is applying for funding.
### Project Description
* **Project Description** (`project_description`, text, *optional*): Provide a detailed description of the project or initiative the nonprofit organization is applying for funding.
