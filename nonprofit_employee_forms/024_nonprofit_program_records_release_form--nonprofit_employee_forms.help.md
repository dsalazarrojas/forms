# Nonprofit Program Records Release Form - Help Guide
## Purpose
This form is used by nonprofit employees to release records related to a nonprofit program. It's essential to complete this form accurately and honestly to ensure the proper completion of the records release process.

## How To Complete This Form
To complete this form, follow these steps:

1. Start by selecting the correct category of the form from the options provided in the "Category" field. This will help ensure that the correct records are released for the intended purpose.
2. Provide a brief description of the reason for releasing the records in the "Description" field.
3. Select the nonprofit employer(s) from the list of options provided in the "Nonprofit Employer" field. This will help ensure that the correct records are associated with the correct employer.

## Field-by-Field Explanation

* **Category**: (`Nonprofit Employee Forms`, `select_one`, required: false)
	+ This field allows you to select the type of form you are completing. Please choose the option that best describes the purpose of the form.
* **Description**: (`Description`, `text`, required: false)
	+ Please provide a brief description of the reason for releasing the records. This will help ensure that the records are released for the correct purpose.
* **Nonprofit Employer**: (`Nonprofit Employer`, `select_multiple`, required: false)
	+ Select the nonprofit employer(s) associated with the records you are releasing. This will help ensure that the records are accurately associated with the correct employer.
