# Stock Donation Form - Help Guide
## Purpose
The Stock Donation Form is used to collect information about stock donations from non-profit employees.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill in the required fields:
	* Category: Select the category of the donation (e.g. Nonprofit Employee Forms).
	* Description: Enter a brief description of the stock donation.
	* Form ID: Enter a unique ID for the form.
	* Donor Name: Enter the name of the donor.
	* Donor E-mail: Enter the email of the donor.
	* Number of prophets: Enter the number of stock shares being donated.
	* Share Type: Select the type of stock share being donated (e.g. Stock).
	* Share Value: Enter the value of the stock share.
	* Total Value: Enter the total value of the stock donation.
	* Form Submission Date: Enter the date the form was submitted.
	* Status: Select the status of the form (e.g. Pending, Approved, Declined).
2. If applicable, complete the optional fields:
	* Phone number: Enter the phone number of the donor (optional).
	* Comments: Add any additional comments about the donation (optional).
	* Notes: Add any notes about the donation (optional).
	* Remarks (1-7): Add any additional remarks about the donation (optional).
