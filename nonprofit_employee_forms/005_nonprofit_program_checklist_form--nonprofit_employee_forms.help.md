# Nonprofit Program Checklist Form - Help Guide
## Purpose
The Nonprofit Program Checklist Form is a tool used to gather information about a nonprofit organization's program. This form helps the organization provide detailed and consistent information about its program to relevant parties.

## How To Complete This Form
1. Fill in the fields according to the required and optional fields. Required fields are marked with an asterisk (*). If you're unsure about any field, refer to the Field-by-Field Explanation section.
2. Double-check your information before submitting the form.

## Field-by-Field Explanation
- **Organization Name** (*): Enter the name of the nonprofit organization.
  - Type: text
  - Required: true
  - Hint: This is the name of the nonprofit organization.
- **Contact Number**: Enter the contact number of the nonprofit organization.
  - Type: text
  - Required: false

- **Email Address**: Enter the email address of the nonprofit organization.
