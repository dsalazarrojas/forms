# Community Outreach Checklist Form - Help Guide
## Purpose
The Community Outreach Checklist Form is a tool used to document and track non-profit employee outreach activities and events. It helps to gather information about the activity, such as the outreach lead, date, location, and primary objective.

## How To Complete This Form
To complete this form, follow these steps:

1. Provide the name of the person responsible for the outreach activity (Outreach lead).
2. Enter the date the outreach activity is scheduled or completed.
3. Enter the location where the outreach activity took place (Outreach location).
4. Describe the primary objective of the outreach activity.
5. (Optional) If applicable, provide a brief list of tasks completed as part of the outreach activity.
6. (Optional) If applicable, specify the number of volunteers required or involved in the outreach activity.
7. (Optional) If applicable, list any materials distributed during the outreach activity.
8. (Optional) If applicable, document any measurable outcomes or metrics from the outreach activity.
9. (Optional) If applicable, identify any follow-up actions required after the outreach activity.

## Field-by-Field Explanation

* **Outreach lead name** (required): Enter the name of the person responsible for the outreach activity.
* **Date of activity** (required): Enter the date the outreach activity is scheduled or completed.
* **Outreach location** (required): Enter the venue or neighborhood where the outreach activity took place.
* **Primary objective** (required): Describe the main goal of the outreach activity.
* **Tasks completed** (optional): If applicable, provide a brief list of tasks completed as part of the outreach activity.
* **Volunteers needed** (optional): If applicable, specify the number of volunteers required or involved in the outreach activity.
* **Materials distributed** (optional): If applicable, list any materials distributed during the outreach activity.
* **Outcomes and metrics** (optional): If applicable, document any measurable outcomes or metrics from the outreach activity.
* **Follow up actions** (optional): If applicable, identify any follow-up actions required after the outreach activity.

## Tips
- Make sure to fill out all the required fields (Outreach lead name, Date of activity, Outreach location, and Primary objective).
- If a field is not applicable, you can leave it blank or indicate "N/A" (not applicable).
