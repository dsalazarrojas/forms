# Square Church Donation Form - Help Guide
## Purpose
The Square Church Donation Form is designed to collect information from donors for a specific church project.

## How To Complete This Form
To complete this form, please follow these steps:

1. Enter the Donor Name and Donor Phone number.
2. Provide the Donor Email address for communication.
3. Describe the Project Description in detail.
4. Specify the Amount Donated.
5. Enter any additional notes or messages in the Donor Message field.
6. Select the Payment Method (Cash, Credit Card, or PayPal).
7. Enter any other relevant Donor Information, such as Donor Name 2, Donor Organization, Project Location, Donor Zip, Donor Country, and Donor State.
8. Select the Project Status (Active, Inactive, or Completed).
9. Enter the Project Start Date and Project End Date (if applicable).
10. Specify the Project Budget (if applicable).
11. Enter the Donor Address, Project Notes, and Donor Date of Birth (if applicable).

## Field-by-Field Explanation
* **Donor Name**: Please enter the name of the donor.
* **Donor Phone**: Enter the phone number of the donor.
* **Donor Email**: Enter the email address of the donor for communication.
* **Project Description**: Describe the project in detail.
* **Amount Donated**: Specify the amount donated.
* **Donor Message**: Enter any additional notes or messages from the donor.
* **Payment Method**: Select the method of payment (Cash, Credit Card, or PayPal).
* **Donor Name 2**: Enter any additional name of the donor.
* **Donor Organization**: Enter the name of the donor organization.
* **Project Location**: Enter the location of the project.
* **Donor Zip**: Enter the zip code of the donor.
* **Donor Country**: Select the country of the donor (United States, Canada, or Mexico).
* **Donor State**: Enter the state of the donor.
* **Donor Street**: Enter the street address of the donor.
* **Project Status**: Select the status of the project (Active, Inactive, or Completed).
* **Project Start Date**: Enter the start date of the project.
* **Project End Date**: Enter the end date of the project.
* **Project Budget**: Specify the budget of the project.
* **Project Budget 2**: Enter any additional budget details.
* **Donor Address**: Enter the address of the donor.
* **Project Notes**: Enter any additional notes on the project.
* **Donor Date of Birth**: Enter the date of birth of the donor.
* **Donor Date of Birth 2**: Enter any additional date of birth details.

**Tips:**

* Please ensure that you enter accurate and complete information for each field.
* If you are unsure about any field, please refer to the project coordinator or the donor for clarification.
* The form is designed to be user-friendly and easy to navigate. If you have any issues while filling the form, please contact the project coordinator or the system administrator for assistance.
