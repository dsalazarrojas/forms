# Final Grant Application Form - Help Guide
## Purpose
The Final Grant Application Form is a tool used to collect and track non-profit employee grant information. This form is designed to ensure accuracy and completeness of grant data for easier management and processing.

## How To Complete This Form
1. Please fill out the form with accurate and complete information.
2. Ensure you have all required fields completed before submitting the form.
3. Review the form carefully before submitting it to the designated authority.

## Field-by-Field Explanation

* **Application Date** (`application_date`): Enter the date of the grant application.
*  The date should be in the format `YYYY-MM-DD` and should be the date the grant was applied for.
* 
* **Applicant Name** (`applicant_name`): Enter the name of the applicant.
*  This is the name of the individual or non-profit applying for the grant.
* 
* **Grant Award Title** (`grant_award_title`): Enter the title of the grant award.
*  This is the title of the grant that is being applied for.
* 
* **Grant Amount** (`grant_amount`): Enter the amount of the grant.
*  This is the total amount of the grant being applied for.
* 
* **Grant Funding Start** (`grant_funding_start`): Enter the start date of the grant funding.
*  This is the date when the grant funding will begin.
* 
* **Grant Funding End** (`grant_funding_end`): Enter the end date of the grant funding.
*  This is the date when the grant funding will end.
* 
* **Application Status** (`application_status`): Select the current application status.
*  Select one of the following options: 
  + Pending 
  + Approved 
  + Denied 
* 
* **Application Notes** (`application_notes`): Enter any additional notes about the application.
*  This is for any additional comments or details about the application.
* 
* **Assigned User** (`assigned_user`): Enter the name of the assigned user.
*  This is the name of the user assigned to the grant.
* 
* **Grant Type** (`grant_type`): Select the type of grant.
*  Select one of the following options: 
  + Nonprofit 
  + Foundation 
  + Government 
* 
* **Grant Urgency** (`grant_urgency`): Enter any urgency of the grant.
*  This is for any additional comments or details about the grant.
* 
* **Grant Funds Status** (`grant_funds_status`): Enter any status of the grant funds.
*  This is for any additional comments or details about the grant funds.
* 
* **Notes** (`notes`): Enter any additional notes.
*  This is for any additional comments or details.
* 
* **Grant Application Date** (`grant_application_date`): Enter the date the grant was applied for.
*  This is the date the grant was applied for and should be in the format `YYYY-MM-DD`.
* 
* **Grant Fund Request** (`grant_fund_request`): Enter the amount of the grant fund request.
*  This is the total amount of the grant fund being requested.
* 
* **Grant Funder** (`grant_funder`): Enter the name of the grant funder.
*  This is the name of the individual or organization providing the grant funding.
* 
* **Grant Funder Type** (`grant_fund_type`): Select the type of grant funder.
*  Select one of the following options: 
  + Government 
  + Nonprofit 
  + Foundation 
* 
* **Grant Funding Source** (`grant_funding_source`): Enter any source of the grant funding.
*  This is for any additional comments or details about the grant funding source.
* 
* **Application Deadline** (`application_deadline`): Enter the deadline for the application.
*  This is the date by which the grant application must be submitted.
* 
* **Grant Total Amount** (`grant_total_amount`): Enter the total amount of the grant.
*  This is the total amount being requested for the grant.
* 
* **Grant Currency** (`grant_currency`): Select the currency of the grant.
*  Select one of the following options: 
  + USD 
  + Other 
* 
* **Grant Frequency** (`grant_frequency`): Select the grant frequency.
*  Select one of the following options: 
  + Once 
  + Other 
* 
* **Grant Start Date** (`grant_start_date`): Select the start date of the grant.
*  Select one of the following options: 
  + January 
  + February 
  + March 
  + April 
  + May 
  + June 
  + July 
  + August 
  + September 
  + October 
  + November 
  + December 
* 
* **Grant End Date** (`grant_end_date`): Select the end date of the grant.
*  Select one of the following options: 
  + January 
  + February 
  + March 
  + April 
  + May 
  + June 
  + July 
  + August 
  + September 
  + October 
  + November 
  + December 
* 
* **Grant Funding Type** (`grant_funding_type`): Select the type of grant funding.
*  Select one of the following options: 
  + Recurring 
  + Non-Recurring 
  + One-time 

**Tips:**

* Double-check for accuracy and completeness before submitting the form.
* Review the form carefully before submitting it to the designated authority.
* If you are unsure about any field or requirement, please reach out to the designated authority for assistance.
