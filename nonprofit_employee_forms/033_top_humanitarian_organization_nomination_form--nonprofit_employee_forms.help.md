# Top Humanitarian Organization Nomination Form - Help Guide
## Purpose
The Top Humanitarian Organization Nomination Form is used to formally nominate individuals who have made a significant impact in their field and have demonstrated exceptional humanitarian service. This form is used to gather information about the nominee and the nominator, and to ensure that the nomination is accurate and complete.

## How To Complete This Form
To complete this form, please follow these steps:

1. Enter the email address of the user nominating the individual.
2. Enter the name of the organization being nominated.
3. Provide a reason for the nomination, describing the nominee's exceptional service.
4. Select the nominee's name from the list of options.
5. Enter the nominee's email address.
6. Enter the nominee's phone number.
7. Select the nominee's address from the list of options.
8. Select the nominee's position from the list of options.
9. Select the nominee's category from the list of options.
10. Select the category of the organization being nominated from the list of options.
11. Select the nature of the organization being nominated from the list of options.
12. Select the regions served by the organization from the list of options.
13. Select the nature of the nominee from the list of options.
14. Select the type of the nominee from the list of options.
15. Select the education of the nominee from the list of options.
16. Enter the number of years the nominee has been nominated.
17. Select any awards the nominee has received.
18. Indicate whether the nominee speaks languages other than the ones listed.
19. Indicate whether the nominee works in the region of service.
20. Select any organizations the nominee has served.

## Field-by-Field Explanation

* **Nominate User** (1, Email, required): Enter the email address of the user nominating the individual.
* **Nominated Organization** (2, Text, required): Enter the name of the organization being nominated.
* **Reason For Nomination** (3, Note, required): Provide a reason for the nomination, describing the exceptional service of the nominee.
* **Nominee Name** (4, Select One, required): Select the nominee's name from the list of options.
* **Nominee Email** (5, Email, required): Enter the nominee's email address.
* **Nominee Phone** (6, Text, required): Enter the nominee's phone number.
* **Nominee Address** (7, Select Multiple, required): Select the nominee's address from the list of options.
* **Nominee Position** (8, Select One, required): Select the nominee's position from the list of options.
* **Nominee Category** (9, Select One, required): Select the nominee's category from the list of options.
* **Organization Category** (10, Select One, required): Select the category of the organization being nominated from the list of options.
* **Organization Nature** (11, Select One, required): Select the nature of the organization being nominated from the list of options.
* **Region Served** (12, Select Multiple, required): Select the regions served by the organization from the list of options.
* **Nominee Nature** (13, Select One, required): Select the nature of the nominee from the list of options.
* **Nominee Type** (14, Select One, required): Select the type of the nominee from the list of options.
* **Nominee Education** (15, Select One, required): Select the education of the nominee from the list of options.
* **Number of Years Nominated** (16, Number, required): Enter the number of years the nominee has been nominated.
* **Nominee Awards** (17, Select Multiple, required): Select any awards the nominee has received.
* **Nominee Languages** (18, Select Multiple, required): Indicate whether the nominee speaks languages other than the ones listed.
* **Region Of Service** (19, Select Multiple, required): Indicate whether the nominee works in the region of service.
* **Nominee Organizations Served** (20, Select Multiple, required): Select any organizations the nominee has served.
