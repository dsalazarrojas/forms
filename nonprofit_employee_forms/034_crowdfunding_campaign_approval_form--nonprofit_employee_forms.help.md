# Crowdfunding Campaign Approval Form - Help Guide
## Purpose
The Crowdfunding Campaign Approval Form is used to gather information about a crowdfunding campaign, allowing campaign owners or managers to provide updates on their campaign's status and details.

## How To Complete This Form

1. Ensure you have all necessary information about the campaign ready.
2. Fill out the form with accurate and up-to-date information for all required fields.
3. Select the correct status for the campaign from the options provided.
4. Provide a brief description of the campaign.
5. Enter the budget and goal for the campaign.
6. Fill out any additional fields as necessary, such as the campaign's location, URL, and other relevant details.

## Field-by-Field Explanation

* **Campaign Status** (`campaign_status`, select_one, required): Select the current status of the campaign from the options: Active, Pending, or Closed.
* **Campaign Description** (`project_description`, text, required): Write a brief description of the campaign.
* **Campaign Budget** (`campaign_budget`, number, required): Enter the total budget for the campaign.
* **Campaign Goal** (`campaign_goal`, number, required): Set the fundraising goal for the campaign.
* **Campaign Creator Details** (`creator_details`, text, optional): Provide any additional information about the campaign creator.
* **Creator's Name** (`campaign_owner`, text, required): Enter the name of the campaign creator.
* **Project Location** (`project_location`, text, optional): Enter the location of the campaign, if applicable.
* **Campaign URL** (`campaign_url`, text, optional): Provide a URL to access the campaign.
* **Project Image** (`project_image`, text, optional): Upload a relevant image or file for the campaign.
* **Project Video** (`project_video`, text, optional): Link to a video about the campaign.
* **Project File** (`project_file`, text, optional): Upload any relevant files for the campaign.
* **Organizer's Name** (`campaign_organizer`, text, optional): Enter the name of the campaign organizer.
* **Manager's Name** (`campaign_manager`, text, optional): Enter the name of the campaign manager.
* **Status Note** (`campaign_status_note`, text, optional): Provide any additional notes about the campaign status.
* **Status Comment** (`campaign_status_comment`, text, optional): Add any comments about the campaign status.
* **Status Date** (`campaign_status_date`, date, optional): Enter the date of the last status update.
* **Status Time** (`campaign_status_time`, time, optional): Enter the time of the last status update.
* **Status User** (`campaign_status_user`, text, optional): Enter the name of the user who made the last status update.
* **Status Email** (`campaign_status_email`, email, optional): Enter the email of the user who made the last status update.
* **Status Phone** (`campaign_status_phone`, text, optional): Enter the phone number of the user who made the last status update.
* **Status Note 2** (`campaign_status_note`, text, optional): Provide another additional note about the campaign status.
