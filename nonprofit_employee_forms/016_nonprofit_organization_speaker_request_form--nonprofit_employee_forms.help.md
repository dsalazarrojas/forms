# Nonprofit Organization Speaker Request Form - Help Guide

## Purpose
The Nonprofit Organization Speaker Request Form is designed to collect information from potential speakers for events organized by nonprofit organizations. The form helps event organizers determine whether a speaker is a good fit for their event and ensures that all relevant details are captured.

## How To Complete This Form

To complete this form, follow these steps:

1. Fill in the required fields with the necessary information.
2. Review each field carefully to ensure that you have provided accurate and complete information.
3. Submit the form when you have finished filling it out.

## Field-by-Field Explanation
### Event Information (1)
* **Event Information**: This is the main section for event details.
* **Event Coordinator**: Please provide the name and contact information of the person coordinating the event.
### Speaker Information (2)
* **Speaker Information**: This is the main section for speaker biographical information.
### Speaker Details (3)
* **Speaker Details**: Please provide any additional details about the speaker, including requirements and qualifications.
### Speaker Requirements (4)
* **Speaker Requirements**: If applicable, please specify the number of speakers needed for the event.
### Event Date (5)
* **Event Date**: The date of the event.
### Event Time (6)
* **Event Time**: The time of the event.
### Event Location (7)
* **Event Location**: The venue of the event.
### Event Type (8)
* **Event Type**: The type of event (e.g. conference, seminar, etc.). Choose one from the dropdown list.
### Event Length (9)
* **Event Length**: The duration of the event. Please provide a numerical value in minutes.
### Speaker Fee (10)
* **Speaker Fee**: The speaker's fee or compensation for the event.
### Speaker Expense (11)
* **Speaker Expense**: The speaker's expenses or reimbursement needs for the event.
### Speaker Experience (12)
* **Speaker Experience**: Any relevant experience or qualifications the speaker has.
### Event Organizers (13)
* **Event Organizers**: A list of event organizers or hosts.
### Event Organizers Contact (14)
* **Event Organizers Contact**: Contact information for event organizers.
