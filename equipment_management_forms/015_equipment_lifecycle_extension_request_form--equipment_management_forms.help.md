# Equipment Lifecycle Extension Request Form - Help Guide
## Purpose
The Equipment Lifecycle Extension Request Form is designed to collect information and request approval for equipment lifecycle extensions, which can include upgrading, replacing, or repurposing equipment.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter your user information (page 1).
2. Provide details about the equipment in need of extension (page 2).
3. Choose whether approval is required for the equipment extension (page 3).
4. Add any additional review comments or information (page 4).
5. Enter any submit comments or updates (page 5).

## Field-by-Field Explanation
### User Information (page 1)
* **User Information (User Information, text, required: false)**: Enter your name and any relevant contact information so that we can get back to you with updates on your equipment lifecycle extension request.

### Equipment Information (page 2)
* **Equipment Information (Equipment Information, text, required: false)**: Describe the equipment in need of extension, including its current status and any relevant details.

### Approval Information (page 3)
* **Approval Information (Approval Information, select multiple, required: false)**: Check if approval is required for the equipment extension. If yes, select "Yes" to indicate that approval is needed. If not, select "No".

### Review Information (page 4)
* **Review Information (Review Information, text, required: false)**: Add any additional comments or information that will help us in reviewing your equipment lifecycle extension request.

### Submit Information (page 5)
* **Submit Information (Submit Information, text, required: false)**: Enter any updates or comments you would like to submit along with your equipment lifecycle extension request.
