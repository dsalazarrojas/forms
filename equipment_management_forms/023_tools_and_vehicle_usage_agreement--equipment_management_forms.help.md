# Tools And Vehicle Usage Agreement - Help Guide
## Purpose
This form is used to collect information about the usage of tools and vehicles within the organization. It is a necessary step before releasing or returning tools and vehicles, and is intended to ensure that all relevant parties are aware of who has used them and when they were returned.

## How To Complete This Form
1. Please select the correct option for who used the equipment, either 'Yes' or 'No'.
2. Select who approved the equipment use from the available options (Approved User, Supervisor, Manager, Administrator, or Other).
3. Enter the expected return date for the equipment.
4. Enter the actual return date for the equipment.

## Field-by-Field Explanation
* **Tools And Vehicle Usage Agreement Page 1** (`tools_and_vehicle_usage_agreement_page_1`): This section is a general information page for the form, providing context and instructions for the user.
* **Tools And Vehicle Usage Agreement Section** (`tools_and_vehicle_usage_agreement_section`): This section is not applicable as it is a note field.
* **Who Used The Equipment** (`who_used_the_equipment`): This field is used to indicate whether the equipment was used or not. Please select 'Yes' if the equipment was used, or 'No' if it was not used.
* **Who Approved The Equipment** (`who_approved_the_equipment`): This field is used to select who approved the use of the equipment. Choose from the available options (Approved User, Supervisor, Manager, Administrator, or Other).
* **Expected Return Date** (`expected_return_date`): This field is used to enter the expected return date for the equipment.
* **Actual Return Date** (`actual_return_date`): This field is used to enter the actual return date for the equipment.

## Tips
- Please ensure that all fields are completed accurately and thoroughly.
- This form should be reviewed and filled out for each tool or vehicle before it is released or returned.
- If an equipment's return date changes, please update the actual return date field accordingly.
