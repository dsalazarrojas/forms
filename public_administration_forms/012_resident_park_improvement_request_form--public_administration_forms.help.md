# Resident Park Improvement Request Form - Help Guide

## Purpose
The Resident Park Improvement Request Form is used to submit requests for improvements to a resident park. This form helps park administrators track and manage these requests efficiently.

## How To Complete This Form
To complete this form, follow these steps:
1. Fill in the `park_name` field with the name of the park where the improvement is requested.
2. Provide a detailed description of the improvement in the `request_description` field.
3. Enter the name of the person submitting the request in the `contact_name` field.
4. Fill in the contact email of the person submitting the request in the `contact_email` field.
5. Enter the contact phone number of the person submitting the request in the `contact_phone` field (this is optional).
6. In the `request_details` field, provide any additional information about the request.
7. Select the type of park in the `park_type` field (e.g., Park, Recreational, or Sports).
8. Choose the priority level of the request in the `priority_level` field (e.g., High, Medium, or Low).
9. Select the status of the request in the `status` field (e.g., Open, In Progress, or Closed).

## Field-by-Field Explanation
* **park_name**: Enter the name of the park where the improvement is requested.
* **request_description**: Provide a detailed description of the improvement.
* **contact_name**: Enter the name of the person submitting the request.
* **contact_email**: Enter the contact email of the person submitting the request.
* **contact_phone**: Enter the contact phone number of the person submitting the request (if not providing an email).
* **request_details**: Provide any additional information about the request.
* **park_type**: Select the type of park (e.g., Park, Recreational, or Sports).
* **priority_level**: Choose the priority level of the request (e.g., High, Medium, or Low).
* **status**: Select the status of the request (e.g., Open, In Progress, or Closed).

## Tips
* Please make sure to fill in all the required fields accurately and completely.
* If you have any questions or concerns, contact your supervisor or the form administrator.
* Before submitting the request, double-check that it is not a duplicate and that your submission is accurate and complete.
