# Public Space Usage Survey Form - Help Guide
## Purpose
The Public Space Usage Survey Form is a tool for gathering information about users' experiences and preferences regarding public spaces.

## How To Complete This Form
- Please take a few minutes to review the form and fill it out as accurately as possible.
- Make sure to answer each question honestly, and provide details where applicable.
- You can select multiple options where applicable (e.g., multiple types of public spaces or a favorite area within the space).

## Field-by-Field Explanation
- **User Input**: This is a note field where you can provide any additional information or comments you'd like to share.
  - This is an open-ended field where you can enter any information you feel is relevant or important.
- **How often do you visit this public space?**: This question is used to understand how often you visit public spaces.
  - Please select a number that reflects your actual visits.
- **What type of public space is this?**: This question is used to categorize the type of public space.
  - Please choose as many options as applicable (e.g., if you visit both parks and plazas, select both).
- **Time spent in the public space**: This question is used to estimate how much time you spend in the public space.
  - Choose the option that best represents the amount of time you typically spend there.
- **Favorite area within this public space**: This question is used to understand if you have a preference for a specific area within the public space.
  - Please select 'Yes' if you have a favorite area, and 'No' if not.
- **Additional Comments**: This is another open-ended field where you can enter any additional information or feedback about your experiences in public spaces.
  - This is a great place to share any thoughts or ideas you have about public spaces.

## Tips
- Please be honest and accurate when answering the questions.
- If you're unsure about an option, choose the one that best represents your thoughts.
- If you have any additional comments or thoughts, use the 'Additional Comments' field.
