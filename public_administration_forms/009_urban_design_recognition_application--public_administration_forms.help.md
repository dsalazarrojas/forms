# Urban Design Recognition Application - Help Guide
## Purpose
The Urban Design Recognition Application form is designed to gather project details, locations, and other relevant information for urban design recognition purposes. It's a critical tool for users to submit projects for evaluation and recognition.

## How To Complete This Form
To complete the form, follow these steps:

1.  Provide the project title and description in the **Project Details** and **Project Description** sections, respectively.
2.  In the **Project Locations** section, select all applicable locations where the project was executed or is relevant to.
3.  Add any supporting files or images in the **Supporting Files** and **Project Images** sections.
4.  Select the submitter from the **Submitted By** dropdown menu.
5.  Optionally, add jurors or jury members in the **Jury Members** section.
6.  Enter the date and time of submission in the **Submitted Date** and **Submitted Time** sections.

## Field-by-Field Explanation
### Project Details
*   **Project Details** (`project_details`, text, optional): Enter a brief title of the project.
### Project Locations
*   **Project Locations** (`project_locations`, select_multiple, optional): Select all applicable locations where the project was executed or is relevant to.
### Project Description
*   **Project Description** (`project_description`, text, optional): Enter a detailed description of the project.
### Supporting Files
*   **Supporting Files** (`supporting_files`, text, optional): Add any supporting files or documents relevant to the project.
### Project Images
*   **Project Images** (`project_images`, text, optional): Upload project images or provide URLs to external images.
### Submitted By
*   **Submitted By** (`submitted_by`, select_one, required): Select the submitter of the project.
### Jury Members
*   **Jury Members** (`jury_members`, select_multiple, optional): Select jurors or jury members who participated in the project.
### Submitted Date
*   **Submitted Date** (`submitted_date`, date, optional): Enter the date of submission.
### Submitted Time
*   **Submitted Time** (`submitted_time`, time, optional): Enter the time of submission.

## Tips
*   Ensure that all required fields are completed accurately.
*   Use the provided options or upload supporting files/images to enhance the project submission.
*   Review the form carefully before submission to ensure accuracy and completeness.
