# Government Service Program Audit Form - Help Guide
## Purpose
The Government Service Program Audit Form is used to collect and track information about government services programs, including program details, review progress, and follow-up dates.

## How To Complete This Form
To complete this form, please follow these steps:

1. Enter the program name in the "Program Name" field.
2. Select the date the program was submitted in the "Date Submitted" field.
3. Select the program officer's name from the "Program Officer Name" field (if applicable).
4. Enter the evaluation criteria for the program in the "Evaluation Criteria" field (if applicable).
5. Select the services provided by the program in the "Program Services" field.
6. Enter the review date in the "Review Date" field.
7. Enter the contact details for the program in the "Contact Details" field.
8. Enter the email address for the program in the "Email Address" field.
9. Select the department responsible for the program in the "Department" field.
10. Select the review status of the program in the "Review Status" field.
11. Enter the next review date in the "Next Review Date" field.
12. Enter the last updated date in the "Last Updated" field (if applicable).
13. Enter any additional comments or notes about the program in the "Comments" field (if applicable).
14. Select the submitted by date in the "Submitted By" field (if applicable).
15. Select the submitted to department in the "Submitted To" field.
16. Enter the follow-up date in the "Follow Up Date" field.
17. Select the follow-up status of the program in the "Follow Up Status" field.
18. Enter the review comments in the "Review Comments" field (if applicable).
19. Enter the action items for the program in the "Action Items" field (if applicable).
20. Enter the follow-up comments in the "Follow Up Comments" field (if applicable).
21. Enter the next follow-up date in the "Next Follow Up Date" field (if applicable).
22. Enter the review completion date in the "Review Completed" field.
23. Select the followed-up date in the "Followed Up" field (if applicable).

## Field-by-Field Explanation
* **Program Name** (1, text, required): Enter the name of the government services program.
* **Date Submitted** (2, date, required): Select the date the program was submitted.
* **Program Officer Name** (3, text, optional): Enter the name of the program officer responsible for the program.
* **Evaluation Criteria** (4, text, optional): Enter the evaluation criteria for the program.
* **Program Services** (5, select_multiple, required): Select the services provided by the program.
* **Review Date** (6, date, required): Enter the review date of the program.
* **Comments** (7, text, optional): Enter any additional comments or notes about the program.
* **Contact Details** (8, text, required): Enter the contact details for the program.
* **Email Address** (9, email, required): Enter the email address for the program.
* **Department** (11, select_one, required): Select the department responsible for the program.
* **Review Status** (12, select_one, required): Select the review status of the program.
* **Next Review Date** (13, date, required): Enter the next review date of the program.
* **Last Updated** (14, date, optional): Enter the last updated date of the program.
* **Review Completed** (24, date, required): Enter the review completion date of the program.
* **Followed Up** (25, date, optional): Select the followed-up date of the program.
* **Program Officer Name** (3, text, optional) - This field is for entering the name of the program officer responsible for the program.

* **Follow Up Status** (19, select_one, required) - Select the follow-up status of the program.
