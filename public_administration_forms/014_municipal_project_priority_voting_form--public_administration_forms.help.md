# Municipal Project Priority Voting Form - Help Guide
## Purpose
The Municipal Project Priority Voting Form is designed to collect project information and prioritize projects based on the needs of the municipality. This form is used to submit project ideas, provide details, and vote on the priority level of each project.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the project title to give the project a brief and descriptive name.
2. Add a project description to provide more information about the project.
3. Choose the category of the project from the options below.
4. Select the priority level of the project from the options below.
5. Enter the budget for the project, if applicable.
6. Provide the location for the project.
7. Enter the start and end dates for the project, if applicable.
8. Enter the contact information for the person working on the project.
9. Select the current status of the project from the options below.
10. Add any additional notes about the project.

## Field-by-Field Explanation

### Project Title
* **Project Title** (`project_title`, text, optional): Enter a brief and descriptive name for the project.

### Project Description
* **Project Description** (`project_description`, text, optional): Provide more information about the project.

### Project Category
* **Project Category** (`project_category`, select_one, optional): Choose the category of the project from the options:
	+ Infrastructure
	+ Community Development
	+ Environmental Protection

### Project Priority
* **Project Priority** (`project_priority`, select_multiple, optional): Select the priority level of the project from the options:
	+ Yes
	+ No

### Project Budget
* **Project Budget** (`project_budget`, number, optional): Enter the budget for the project, if applicable.

### Project Location
* **Project Location** (`project_location`, text, optional): Provide the location for the project.

### Project Start Date
* **Project Start Date** (`project_start_date`, date, optional): Enter the start date for the project, if applicable.

### Project End Date
* **Project End Date** (`project_end_date`, date, optional): Enter the end date for the project, if applicable.

### Contact Information
* **Contact Name** (`contact_name`, text, optional): Enter the name of the person working on the project.
* **Contact Email** (`contact_email`, email, optional): Enter the email of the person working on the project.
* **Contact Phone** (`contact_phone`, text, optional): Enter the phone number of the person working on the project.

### Project Status
* **Project Status** (`project_status`, select_one, optional): Select the current status of the project from the options:
	+ Not Started
	+ Ongoing
	+ Completed

### Project Notes
* **Project Notes** (`project_notes`, note, optional): Add any additional notes about the project.

### Additional Tips

* Make sure to fill in all required fields.
* Use clear and concise language for project titles and descriptions.
* Select the correct category and priority level for the project.
* Enter accurate contact information.
* Use the correct format for date fields.
