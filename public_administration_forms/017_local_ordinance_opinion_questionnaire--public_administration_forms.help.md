# Local Ordinance Opinion Questionnaire - Help Guide
## Purpose
The Local Ordinance Opinion Questionnaire form is used to gather user feedback and opinions on local ordinances. This form helps identify areas of improvement, clarify ambiguities, and facilitate more informed decision-making within the local administration.

## How To Complete This Form

To complete this form, follow these steps:

1. Select the relevant options for each field that best describe your thoughts and opinions.
2. Provide a brief description of the ordinance in the "Description" field.
3. If you have any additional comments or feedback, type them in the "Additional feedback" field.
4. Make sure to fill out all fields that are marked as required.
5. When you are finished, review your answers carefully before clicking the "Submit" button.

## Field-by-Field Explanation

* **How familiar are you with the local ordinances?** (`community_feedback`, select_multiple):
	+ Choose all options that apply to describe your level of familiarity with local ordinances.
* **Ordinance name** (`ordinance_name`, text):
	+ Type in the name of the relevant local ordinance.
* **Description** (`description`, text):
	+ Briefly describe the ordinance.
* **Name** (`contact_name`, text):
	+ Type in your name for contact purposes.
* **Email** (`contact_email`, email):
	+ Enter your email address for communication.
* **Phone number** (`contact_phone`, text):
	+ Type in your phone number.
* **Additional feedback** (`feedback`, note):
	+ Share any additional thoughts or opinions you may have.
* **Category** (`category`, select_one):
	+ Choose a category related to the ordinance.
* **Subcategory** (`subcategory`, select_one):
	+ Select a subcategory related to the ordinance.
* **Question ID** (`question_id`, number):
	+ This field is for internal use and should not be filled out by users.
* **Submission Date** (`submission_date`, date):
	+ This field is automatically filled out when the form is submitted.
* **Submission Time** (`submission_time`, time):
	+ This field is automatically filled out when the form is submitted.
* **Location** (`location`, select_one):
	+ Choose a location related to the ordinance.
* **Address** (`address`, text):
	+ Type in the address related to the ordinance.
* **Comments** (`comments`, select_multiple):
	+ Choose all options that apply to describe your comments.
* **Other comments** (`comments_other`, text):
	+ Type in any additional comments.
* **File Attachment** (`attachment`, text):
	+ This field is for uploading attachments, but it is not required.
* **Attachment URL** (`attachment_url`, text):
	+ This field is for uploading attachments, but it is not required.
* **Attachment note** (`attachment_note`, note):
	+ Type in a note about the attachment.
* **Submit** (`submit_button`, text):
	+ Review and submit your form carefully.
* **Back** (`back_button`, text):
	+ Go back to the previous page.
* **Cancel** (`cancel_button`, text):
	+ Cancel the form submission.
* **Next** (`next_button`, text):
	+ Move on to the next page.
* **Previous** (`prev_button`, text):
	+ Go back to the previous page.
* **Form Footer** (`form_footer`, text):
	+ This field is not required and is for additional information.
