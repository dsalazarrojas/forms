# Public Transport Usage Change Report Form - Help Guide
## Purpose
This form is used to report changes to public transport usage.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter a title for the report in the "Public Transport Usage Change Report Form" field.
2. Select the category of change made (e.g. "Option 1", "Option 2", "Option 3") in the "category" field.
3. Describe the change made in the "description" field.
4. Provide a detailed description of the change in the "form_description" field.
5. If applicable, specify the tool used for the change in the "assigned_tool" field.
6. Enter a unique identifier for the report in the "form_id" field.
7. Specify the desired output file in the "output_file" field.

## Field-by-Field Explanation

* **Public Transport Usage Change Report Form** (`form_title`, text, required):
  Enter a title for the report, such as "Public Transport Usage Change Report for January 2023".
* **Category** (`category`, select_one, optional):
  Select the category of the change made, such as "Option 1" or "Option 2".
* **Description** (`description`, text, required):
  Describe the change made, including details about what was changed and why.
* **Detailed Description** (`form_description`, text, required):
  Provide a detailed explanation of the change, including any relevant details or background information.
* **Assigned Tool** (`assigned_tool`, text, optional):
  If applicable, specify the tool used to make the change, such as "Transport Manager" or "Public Transport App".
* **Form ID** (`form_id`, text, required):
  Enter a unique identifier for the report, such as a code or number.
* **Output File** (`output_file`, text, required):
  Specify the desired output file, such as "report.pdf" or "change_report.csv".
