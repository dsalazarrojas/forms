# grant_application - Help Guide
## Purpose
This form is for organizations or individuals to apply for grants. It collects information about grant amounts, durations, and statuses.

## How To Complete This Form
1. Fill out the grant application form sections as prompted.
2. Enter the applicant organization's name and contact information (pages 1-3).
3. Enter grant details, including grant amount, duration, and status (pages 5-7).
4. Enter additional grant details for up to 4 grant applications (pages 8-11).

## Field-by-Field Explanation

* **grant_application_form** (Page 1, Text): Enter a brief description of your grant application.
* **applicant_organization** (Page 2, Text): Enter the name of the organization or individual applying for the grant.
* **grant_amount** (Page 3, Number): Enter the grant amount requested.
* **grant_duration** (Page 4, Time): Enter the grant duration.
* **contact_email** (Page 5, Email): Enter the contact email of the applicant.
* **contact_phone** (Page 6, Text): Enter the contact phone number of the applicant.
* **contact_address_1**, **contact_address_2** (Pages 7-8, Text): Enter the contact address of the applicant.
* **grant_purpose** (Page 9, Text): Enter a brief description of the grant purpose.
* **grant_status** (Page 10, Select One): Select the current status of the grant application (In progress, Approved, Denied).
* **grant_notes** (Page 11, Note): Enter any additional notes about the grant application.
* **grant_date** (Page 12, Date): Enter the grant date.
* **grant_time** (Page 13, Time): Enter the grant time.
* **grant_amount_2** (Page 14, Number): Enter the grant amount for this grant application.
* **grant_duration_2** (Page 15, Time): Enter the grant duration for this grant application.
* **grant_status_2** (Page 16, Select One): Select the current status of this grant application (In progress, Approved, Denied).
* **grant_date_2** (Page 17, Date): Enter the grant date for this grant application.
* **grant_amount_3** (Page 18, Number): Enter the grant amount for this grant application.

* **grant_notes_2** (Page 22, Note): Enter any additional notes about this grant application.
* **grant_application_form_2**, **grant_application_form_3**, **grant_application_form_4** (Pages 23-25, Text): Enter any additional grant application information.
