# Public Sector Parental Leave Of Absence Form - Help Guide
## Purpose
The Public Sector Parental Leave Of Absence Form is used to process parental leave requests from employees in the public sector. This form allows employees to submit their leave request and provides managers with the necessary information to review and approve or deny the request.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the Employee ID number.
2. Select the start and end dates of the leave period.
3. Enter the manager's ID number.
4. Add the manager's name and email.
5. Provide a brief explanation of the request reason.
6. Select the manager's approval status (Approved, Denied, or Pending).
7. Select the status of the leave request (Pending, Approved, or Denied).
8. Choose whether the leave request has been assigned to a manager (Yes or No).
9. Select the due date of the leave request.

## Field-by-Field Explanation
### Employee Id
* **Employee Id** (`employee_id`, number, required/optional): Enter the employee's unique ID number.

### Start Date
* **Start Date** (`start_date`, date, optional): Select the start date of the leave period.

### End Date
* **End Date** (`end_date`, date, optional): Select the end date of the leave period.

### Manager Id
* **Manager Id** (`manager_id`, number, optional): Enter the manager's ID number.

### Manager Name
* **Manager Name** (`manager_name`, text, optional): Enter the manager's name.

### Manager Email
* **Manager Email** (`manager_email`, email, optional): Enter the manager's email address.

### Manager Phone
* **Manager Phone** (`manager_phone`, text, optional): Enter the manager's phone number.

### Manager Note
* **Manager Note** (`manager_note`, note, optional): Enter any additional comments or notes from the manager.

### Employee Note
* **Employee Note** (`employee_note`, note, optional): Enter any additional comments or notes from the employee.

### Request Reason
* **Request Reason** (`request_reason`, text, optional): Briefly explain the reason for the leave request.

### Manager Approval
* **Manager Approval** (`manager_approval`, select_one, optional): Select the manager's approval status (Approved, Denied, or Pending).

### Status
* **Status** (`status`, select_multiple, optional): Select the status of the leave request (Pending, Approved, or Denied).

### Assigned To
* **Assigned To** (`assigned_to`, select_one, optional): Choose whether the leave request has been assigned to a manager (Yes or No).

### Assigned Date
* **Assigned Date** (`assigned_date`, date, optional): Select the date the leave request was assigned to a manager.

### Due Date
* **Due Date** (`due_date`, date, optional): Select the due date of the leave request.

### Request Type
* **Request Type** (`request_type`, select_one, optional): Select the type of leave request (Personal, Family, or Other).

### Manager Id 1, 2, 3, 4
* **Manager Id 1** (`manager_id_1`, number, optional): Enter the ID number of the first manager.
* **Manager Id 2** (`manager_id_2`, number, optional): Enter the ID number of the second manager.
* **Manager Id 3** (`manager_id_3`, number, optional): Enter the ID number of the third manager.
* **Manager Id 4** (`manager_id_4`, number, optional): Enter the ID number of the fourth manager.

### Manager Name 1, 2, 3
* **Manager Name 1** (`manager_name_1`, text, optional): Enter the name of the first manager.
* **Manager Name 2** (`manager_name_2`, text, optional): Enter the name of the second manager.
* **Manager Name 3** (`manager_name_3`, text, optional): Enter the name of the third manager.

## Tips
* Be sure to enter accurate and up-to-date information.
* Review the form carefully before submitting it.
* If you are a manager, make sure to have the necessary permissions to view and approve leave requests.
