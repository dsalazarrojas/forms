# Civic Issue Report Form - Help Guide
## Purpose
The Civic Issue Report Form is designed to collect information about various civic issues reported by citizens. This form is intended to be used by citizens to report issues they encounter in their community, and the information collected will be used by city officials to address these issues.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the type of issue you are reporting from the "Issue Category" dropdown menu.
2. Enter the location of the issue, including the address or nearest intersection.
3. Select the type of location where the issue is occurring.
4. Describe the issue in detail in the "Detailed Description" field.
5. Indicate the severity level of the issue.
6. Enter the date and time when you first noticed the issue.
7. If you have reported this issue before, indicate how you previously reported it.
8. If you reported this issue previously, enter the reference number of the previous report.
9. Check if the issue poses a safety hazard.
10. Select all the populations affected by the issue, if applicable.
11. Enter your full name, email address, and phone number.
12. Decide if you would like to remain anonymous.
13. Upload any photos or relevant information about the issue, if applicable.
14. Add any additional comments about the issue, if needed.

## Field-by-Field Explanation

* **Issue Category** (1): Select the type of issue you are reporting from the dropdown menu.
	+ Potholes and Road Damage
	+ Streetlight Outage
	+ Graffiti or Vandalism
	+ Trash or Debris
	+ Drainage Problems
	+ Sidewalk Damage
	+ Park Maintenance
	+ Noise Complaint
	+ Public Safety Concerns
	+ Other
* **Location of Issue** (2): Enter the address or nearest intersection where the issue is occurring.
* **Location Type** (3): Select the type of location where the issue is occurring.
	+ Residential Street
	+ Main Road or Highway
	+ Public Park
	+ Sidewalk
	+ Public Building
	+ School Zone
	+ Commercial Area
	+ Other
* **Detailed Description** (4): Describe the issue in detail.
* **Severity Level** (5): Indicate the urgency level of the issue.
	+ Critical - Immediate attention needed
	+ High - Should be addressed within 24 hours
	+ Medium - Should be addressed within a week
	+ Low - Can be addressed during regular maintenance
* **Date Issue Was Observed** (6): Enter the date when you first noticed the issue.
* **Time Observed** (7): Enter the approximate time when you noticed the issue.
* **Is This a Recurring Issue** (8): If you have reported this issue before, indicate yes or no.
* **Previous Report Number** (9): If you reported this issue before, enter the reference number of the previous report.
* **Does This Pose a Safety Hazard** (10): Check if the issue poses a safety concern.
* **Who Is Affected by This Issue** (11): Select all the populations affected by the issue, if applicable.
	+ Pedestrians
	+ Cyclists
	+ Motorists
	+ Children
	+ Elderly or Disabled
	+ Local Residents
	+ Business Owners
	+ General Public
* **Your Full Name** (12): Enter your full name.
* **Your Email Address** (13): Enter your email address for follow-up purposes.
* **Your Phone Number** (14): Enter your phone number for follow-up purposes.
* **Would You Like to Remain Anonymous** (15): Decide if you would like to remain anonymous.
* **Photo Upload Instructions** (16): Upload any relevant photos or information about the issue, if applicable.
* **Additional Comments** (17): Add any additional information about the issue, if needed.

## Tips
* Please ensure that you fill out the form accurately and completely.
* If you are unsure about any field, please refer to this guide for clarification.
* If you have previously reported an issue, the city will notify you that your report has already been received.
* If you need to report the issue again, you can do so and the city will ensure that your report is not duplicated.
