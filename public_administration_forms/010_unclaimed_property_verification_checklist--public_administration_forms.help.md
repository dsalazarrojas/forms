# Unclaimed Property Verification Checklist - Help Guide
## Purpose
The purpose of this form is to gather information and verify the status of unclaimed properties. Use this form to track and manage unclaimed properties in an organized and efficient manner.

## How To Complete This Form
To complete this form, follow these steps:

1. Review the property's details and confirm that you have the necessary permissions to access and update the property's information.
2. Answer each question accurately and thoroughly, providing as much detail as possible.
3. Use the provided options to select relevant information about the property and its status.

## Field-by-Field Explanation
* **Intensity and track claim reviews** (Page 1):
	+ A brief description of the property's status.
* **Customer** (Page 2):
	+ Select "True" if the property is currently being claimed by a customer.
	+ Select "False" if the property is not being claimed.
* **Property Type** (Page 3):
	+ Select the type of property that is being verified (e.g., Real, Personal, Other).
* **Property Description** (Page 4):
	+ A brief description of the property's details.
* **Property Value** (Page 5):
	+ The current value of the property.
* **Upload Documents** (Page 6):
	+ Attach relevant documents related to the property.
* **Review Date** (Page 7):
	+ The date when the property was last reviewed.
* **Review Time** (Page 8):
	+ The time when the property was last reviewed.
* **Customer Name** (Page 9):
	+ The name of the customer who is currently claiming the property.
* **Customer Email** (Page 10):
	+ The email address of the customer who is currently claiming the property.
* **Customer Phone** (Page 11):
	+ The phone number of the customer who is currently claiming the property.
* **Verification Team** (Page 12):
	+ Select the team that is responsible for verifying the property (e.g., Team 1, Team 2, Team 3).

## Tips
* Be thorough and accurate when filling out this form.
* Use the provided options to ensure that you are selecting the correct information about the property and its status.
* If you are unsure about any information, please consult with the relevant teams or experts for clarification.
