# politicalEventProtestIncidentReportForm - Help Guide
## Purpose
The "Political Event Protest Incident Report Form" is a document designed to collect information about incidents related to political protests, demonstrations, or rallies. This form is useful for gathering data on event details, location, and any supporting evidence.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the date of the incident from the calendar.
2. Choose the type of event that occurred (e.g., Rally, Demonstration, March, etc.).
3. Provide a detailed description of the incident.
4. If applicable, add any supporting evidence.
5. If you have images or videos of the incident, upload them.
6. If there are reports related to the incident, enter them in the text field.

## Field-by-Field Explanation

### 1. Political Event Protest Date
* **Label:** Political Event Protest Date
* **Type:** Date
* **Required:** No
* **Description:** Enter the date of the incident using the calendar.

### 2. Political Event Name
* **Label:** Political Event Name
* **Type:** Text
* **Required:** No
* **Description:** Enter the name of the event, e.g., "Rally for Change" or "Student Demonstration".

### 3. Event Type
* **Label:** event_type
* **Type:** Select One
* **Required:** Yes
* **Description:** Choose the type of event from the list provided: Rally, Demonstration, March, Protest, Sit-in, Strike, Boycott, or Riot.

### 4. Location
* **Label:** location
* **Type:** Text
* **Required:** No
* **Description:** Enter the location of the incident, e.g., "Central Park" or "City Square".

### 5. Event Description
* **Label:** Event Description
* **Type:** Text
* **Required:** No
* **Description:** Please provide a detailed description of the event, including the number of participants and any notable actions taken.

### 6. Supporting Evidence
* **Label:** Supporting Evidence
* **Type:** Text
* **Required:** No
* **Description:** If you have any supporting evidence, such as images or videos, attach them to this field.

### 7. Images/Videos
* **Label:** Images/Videos
* **Type:** Text
* **Required:** No
* **Description:** If you have images or videos of the incident, upload them to this field.

### 8. Reports
* **Label:** Reports
* **Type:** Text
* **Required:** No
* **Description:** If there are reports related to the incident, enter them in this field.
