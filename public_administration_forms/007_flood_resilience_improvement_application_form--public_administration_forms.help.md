# Flood Resilience Improvement Application Form - Help Guide
## Purpose
This form is used to gather information from authorized users to support flood resilience improvements. If you are not authorized to complete this form, please contact your administrator for assistance.

## How To Complete This Form
To complete this form, follow these steps:

1. Read the purpose of the form and ensure you are authorized to complete it.
2. Fill in the required fields, marked with an asterisk (*).
3. For select_one, select_one and select_multiple fields, choose the correct option from the dropdown list.
4. Double-check that you have provided accurate and complete information before submitting the form.

## Field-by-Field Explanation

* **Project Description** (`project_description`, text, not required): This field is used to provide a brief description of the project or initiative related to flood resilience improvements.
	+ Please enter a concise and clear description of the project.
* **Supporting Documents** (`supporting_documents`, select_multiple, not required): This field is used to indicate if supporting documents are available or not. If yes, you will be able to upload or attach the documents.
	+ Choose "Yes" if you have supporting documents to provide.
* **Council** (`council`, select_one, not required): This field is used to indicate if the council is involved in the project.
	+ Choose "Yes" if the council is involved.
* **Agency** (`agency`, select_one, not required): This field is used to indicate if the agency is involved in the project.
	+ Choose "Yes" if the agency is involved.
* **Property Owner** (`property_owner`, select_one, not required): This field is used to indicate if the property owner is involved in the project.
	+ Choose "Yes" if the property owner is involved.
* **Project Manager** (`project_manager`, select_one, not required): This field is used to indicate if the project manager is involved in the project.
	+ Choose "Yes" if the project manager is involved.

## Tips
* Ensure that you have completed all required fields before submitting the form.
* Double-check the accuracy and completeness of the information you provide before submitting the form.
