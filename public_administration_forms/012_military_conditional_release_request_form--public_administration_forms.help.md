# Military Conditional Release Request Form - Help Guide

## Purpose
This form is designed to request a conditional release from active duty for military personnel. It requires the completion of several fields that will guide the reviewer in making an informed decision.

## How To Complete This Form
1.  Begin by completing the "Unit Administrator" field, which requires the unit administrator's name.
2.  Select one or more military goals that the release is contingent upon. This will help the reviewer understand the reason for the release.
3.  Enter the unit's name where the request is being made from.
4.  Provide the release date, if applicable.
5.  Describe the reason for the release, if not already covered by the military goals selected.
6.  Include the unit administrators' signature, ensuring they have approved the request.
7.  Add the unit's name for verification purposes.
8.  Enter the date signed by the unit administrator.
9.  Include the supervisor's signature, if applicable.
10.  Enter the supervisor's name and rank, if applicable.
11.  Add the date signed by the supervisor.
12.  Identify the commander's name, if applicable.
13.  Enter the commander's rank, if applicable.
14.  Include the commander's signature, if applicable.
15.  Add the date signed by the commander.

## Field-by-Field Explanation
*   *Unit Administrator* (`Unit Administrator`, `text`, required): Enter the name of the unit administrator who is signing this request.
*   *Military Goals* (`Military Goals`, `select_multiple`, required): Select one or more military goals that the release is contingent upon. This will help the reviewer understand the reason for the release.
*   *Unit Name* (`Unit Name`, `text`, required): Enter the name of the unit where this request is being made from.
*   *Release Date* (`Release Date`, `date`, optional): Provide the release date, if applicable.
*   *Reason for Release* (`Reason for Release`, `text`, optional): Describe the reason for the release, if not already covered by the military goals selected.
*   *Unit Administrators Signature* (`Unit Administrators Signature`, `text`, required): Include the unit administrator's signature, ensuring they have approved the request.
*   *Unit Name Signature* (`Unit Name Signature`, `text`, required): Add the unit's name for verification purposes.
*   *Date Signed* (`Date Signed`, `date`, required): Enter the date signed by the unit administrator.
*   *Supervisor* (`Supervisor`, `text`, optional): Include the supervisor's signature, if applicable.
*   *Name* (`Name`, `text`, optional): Enter the supervisor's name, if applicable.
*   *Rank* (`Rank`, `text`, optional): Enter the supervisor's rank, if applicable.
*   *Date* (`Date`, `date`, optional): Enter the date signed by the supervisor.
*   *Commander* (`Commander`, `text`, optional): Identify the commander's name, if applicable.
*   *Commander Name* (`Commander Name`, `text`, optional): Enter the commander's name, if applicable.
*   *Commander Rank* (`Commander Rank`, `text`, optional): Enter the commander's rank, if applicable.
*   *Signature* (`Signature`, `text`, optional): Include the commander's signature, if applicable.
*   *Commander Signature Date* (`Commander Signature Date`, `date`, optional): Enter the date signed by the commander.

## Tips
- Ensure all fields are completed accurately and with attention to detail.
- Double-check the unit administrator's signature and date signed for authenticity.
- If applicable, ensure the supervisor and commander's signatures and dates are also verified.
- This form is for official use only, and not for personal or recreational purposes.
