# Father's Day Cookie Order Form - Help Guide
## Purpose
This form is used to place an order for Father's Day cookies. The order details collected will be used to create a special gift for a father or father figure on Father's Day.

## How To Complete This Form
To complete this form, follow these steps:
1. Select the shape of the cookie you would like to order.
2. Choose the size of the cookie you would like.
3. Type a personalized message to make the cookie gift extra special.
4. Enter your name (if you want a personalized message).
5. Select the date and time you would like the order to be delivered.
6. Select the time you would like the order to be delivered.
7. Add any additional comments or messages about the order.

## Field-by-Field Explanation

* **Cookie Shape** (`Cookie Shape`, select_one):
  This field allows you to choose the shape of the cookie. Please select the shape that you like best from the options available.

* **Cookie Size** (`Cookie Size`, select_one):
  This field allows you to choose the size of the cookie. Please select the size that you like best from the options available.

* **Personalized Message** (`Personalized Message`, text):
  This field is where you can add a special message to make the cookie gift extra special. Type a message that you think the father or father figure will love.

* **Name** (`Name`, text):
  If you want a personalized message on the cookie, please enter the name of the father or father figure.

* **Order Date** (`Order Date`, date):
  Select the date you would like the order to be delivered. Please use the date format MM/DD/YY.

* **Order Time** (`Order Time`, time):
  Select the time you would like the order to be delivered. Please use the 24-hour format.

* **Delivery Time** (`Delivery Time`, time):
  Select the time you would like the order to be delivered. Please use the 24-hour format.

* **Cookie Message** (`Cookie Message`, text):
  Add any additional comments or messages about the order. This will help us understand your request better.

## Tips
* Make sure to select the correct date and time for delivery.
* If you have any special requests, please let us know in the `Cookie Message` field.
* If you are unsure about anything, please contact us for assistance.
