# Private Chef Service Inquiry - Help Guide
## Purpose
This form is used to collect information from clients who are interested in hiring a private chef for a special event or occasion. It is essential to fill out the form accurately and completely to ensure that we can effectively cater to your needs.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill in your First Name, Last Name, Email, Phone, and Address in the respective fields.
2. Choose the type of service you require (e.g., 'Yes' for private chef services).
3. Provide a brief description of the service you need (in the Service Description field).
4. Select the date and time you would like the service to be provided.
5. Optionally, you can include a Message to Client and/or a Message From Chef.
6. Choose the service status (e.g., 'Active' for currently available).
7. Choose the assigned status (e.g., 'Active' for currently assigned).
8. Choose the assigned user status (e.g., 'Active' for currently assigned).
9. Check if you are submitting this form as a client.
10. Finally, select the form submitted status (e.g., 'Yes' for this form has been submitted).

## Field-by-Field Explanation

* **First Name** (`first_name`, text, Required): Enter your first name.
* **Last Name** (`last_name`, text, Required): Enter your last name.
* **Email** (`email`, email, Required): Enter your email address.
* **Phone** (`phone`, text, Required): Enter your phone number.
* **Address** (`address`, text, Required): Enter your address.
* **Service Type** (`service_type`, select_one, Required): Choose 'Yes' if you require private chef services.
* **Service Description** (`service_description`, text, Required): Briefly describe the service you require.
* **Date** (`date`, date, Required): Select the date you would like the service to be provided.
* **Time** (`time`, time, Required): Select the time you would like the service to be provided.
* **Note** (`note`, note, Required): Include any additional comments or notes regarding your request.
* **Assigned To** (`assigned_to`, select_one, Required): Choose 'Yes' if you have assigned someone to this service.
* **Chef Name** (`chef_name`, text, Required): Enter the name of the chef assigned to this service.
* **Chef Service Type** (`chef_service_type`, select_one, Required): Choose 'Yes' if this is a chef service.
* **Client Name** (`client_name`, text, Required): Enter your name as a client.
* **Client Phone** (`client_phone`, text, Required): Enter your phone number as a client.
* **Client Email** (`client_email`, email, Required): Enter your email address as a client.
* **Client Address** (`client_address`, text, Required): Enter your address as a client.
* **Message To Client** (`message_to_client`, text, Required): Include a message to the client.
* **Message From Chef** (`message_from_chef`, text, Required): Include a message from the chef.
* **Message To Chef** (`message_to_chef`, text, Required): Include a message to the chef.
* **Message From Client** (`message_from_client`, text, Required): Include a message from the client.
* **Service Status** (`service_status`, select_one, Required): Choose 'Active' if this service is currently available.
* **Assigned Status** (`assigned_status`, select_one, Required): Choose 'Active' if this service is currently assigned.
* **Assigned User Status** (`assigned_user_status`, select_one, Required): Choose 'Active' if this service is currently assigned to a user.
* **Form Submitted By** (`form_submitted_by`, select_one, Required): Check 'Yes' if this form has been submitted.

## Tips

* Please ensure that you fill out all required fields accurately and completely.
* If you have any questions or concerns, please reach out to our support team.
* Please review all fields carefully before submitting this form.
