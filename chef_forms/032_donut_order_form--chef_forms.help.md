# Donut Order Form - Help Guide
## Purpose
The Donut Order Form is designed to collect customer information and donut order details for processing orders. Use this form to gather all necessary information for a new donut order.

## How To Complete This Form
To complete this form, follow these steps:

*   Enter your order details in the required fields marked with \*\* (e.g., customer name, email).
*   For optional fields, you can choose to provide as much information as you like or leave blank if not applicable.
*   Ensure you fill out all the required fields for a successful submission.

## Field-by-Field Explanation
*   **Donut Type (donut_type)**: Select the type of donut you'd like to order. This field is optional.
*   **Donut Size (donut_size)**: Choose the size of donut you prefer. This field is optional.
*   **Flavor Preference (donut_flavor)**: Select your preferred donut flavor. This field is optional.
*   **Customer Name (customer_name)**: Enter your name as the customer placing the order. This is a required field.
*   **Email (email)**: Enter your email address for order confirmation and any further communication. This is a required field.
*   **Phone (phone)**: Provide your phone number for order updates or any urgent communication. This is an optional field.
*   **Order Date (order_date)**: Select the date you'd like to pick up or have your donuts delivered on. This field is optional.
*   **Order Time (order_time)**: Choose the time you'd like to pick up or have your donuts delivered on. This field is optional.
*   **Special Instructions (special_instructions)**: Add any special requests or instructions for your order, if needed. This field is optional.
*   **Donut Order ID (donut_order_id)**: This is a system-generated field and should not be filled out by customers.
*   **Customer Notes (customer_notes)**: Add any notes or comments about your order. This field is optional.
*   **Donut Quantity (donut_quantity)**: Enter the number of donuts you'd like to order. This field is optional.
