# Restaurant Cook Evaluation Form - Help Guide
## Purpose
This form is designed to evaluate the performance of a restaurant cook based on various criteria.

## How To Complete This Form

1. Please complete the form by providing your feedback on the cook's performance. You can select one of the options for each field, or leave it blank if you prefer not to answer.
2. If you're not sure about a particular field, you can also leave it blank and proceed with the rest of the form.

## Field-by-Field Explanation
* **Restaurant Cook Evaluation Form**:
	+ This is the title of the form. Please leave it as it is.
* **Cook Performance**:
	+ This field evaluates the cook's performance. Please select 'Yes' if you think the cook performed well, or 'No' if not.
* **Restaurant Performance**:
	+ This field assesses the restaurant's overall performance. Please select 'Yes' for all the areas that apply.
* **Food Quality**:
	+ This field checks the quality of the food served. Please select 'Good' if the food was good, or 'Poor' if not.
* **Cleanliness**:
	+ This field evaluates the cleanliness of the restaurant. Please select 'Yes' if the restaurant was clean, or 'No' if not.
* **Food Temperature**:
	+ This field checks if the food was served at the right temperature. Please select 'Yes' if it was, or 'No' if not.
* **Service Attitude**:
	+ This field assesses the attitude of the service staff. Please select 'Yes' for all the areas that apply.
* **Overall Satisfaction**:
	+ This field evaluates your overall satisfaction with the dining experience. Please select 'Satisfied' if you were satisfied, or 'Dissatisfied' if not.
* **Feedback**:
	+ This is a text field where you can provide any additional feedback about your experience.

## Tips
* Please be honest and provide your genuine feedback.
* You can select multiple options for fields like 'Restaurant Performance' and 'Service Attitude' if they apply.
* If you have any additional comments or suggestions, please use the 'Feedback' field to provide them.
