# Frozen Meal Order Form - Help Guide
## Purpose
The Frozen Meal Order Form is designed to collect orders from customers for frozen meals. This form helps our kitchen staff prepare and pack the correct meals according to customer preferences.

## How To Complete This Form
To complete this form, please follow these steps:
1. Select the type of meal you would like to order (Beef, Chicken, Vegan, Seafood, or Vegetarian).
2. Choose the serving size (Small, Medium, or Large).
3. If you have any special requests or instructions, please add them in the note field.
4. Fill in your contact first name, which will be used to address your order.

## Field-by-Field Explanation
* **Meal Type** (`meal_type`, select_one, required/optional): Choose the type of meal you would like to order (Beef, Chicken, Vegan, Seafood, or Vegetarian).
* **Serving Size** (`serving_size`, select_one, required/optional): Select the serving size of the meal you ordered (Small, Medium, or Large).
* **Meal Description** (`meal_description`, text, required/optional): Add any additional details about your order, such as any allergies or preferences.
* **Special Instructions** (`special_instructions`, note, required/optional): If you have any special requests or instructions, please add them here.
* **Contact First Name** (`contact_first_name`, text, required): Fill in your first name so we can address your order correctly.

## Tips
- Be sure to select only one meal type option.
- Choose a serving size that suits your needs.
- If you have any special requests, please add them in the note field.
- Fill in your first name correctly to ensure accurate order handling.
