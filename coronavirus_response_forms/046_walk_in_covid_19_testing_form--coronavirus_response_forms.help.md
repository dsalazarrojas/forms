# Walk In COVID 19 Testing Form - Help Guide
## Purpose
The Walk In COVID-19 Testing Form is used to collect information for conducting COVID-19 testing.

## How To Complete This Form

To complete this form, follow these steps:
- Enter your name in the required format (e.g., John Doe).
- Enter your date of birth in the date format (e.g., 01/01/1999).
- Enter your phone number for contact.
- Enter your home address (if applicable).
- If you have an insurance card, enter the card number.
- If you have any medical conditions, describe them in the text box.
- If you have any test results, enter them in the text box.
- If you were referred by a doctor, select 'Yes' in the corresponding field.
- If you have a doctor's phone number, enter it.
- Enter the date you were tested.
- Select the time you were tested.
- If the sample was collected, select 'Yes'.
- If the test result is available, select 'Yes'.
- If you have any comments on the test result, enter them.
- Enter the date the test result was received.
- If the lab result is available, select 'Active' or 'Inactive'.
- If the lab result is available, enter the date it was received.
- If you have any comments on the lab result, enter them.

## Field-by-Field Explanation

* **First Name** (first_name, text, required): Enter your given name (e.g., John).
* **Last Name** (last_name, text, required): Enter your surname (e.g., Doe).
* **Date of Birth** (date_of_birth, date, required): Enter the date you were born in the standard date format (e.g., 01/01/1999).
* **Phone Number** (phone_number, text, optional): Enter your phone number for contact.
* **Home Address** (address, text, optional): Enter your home address if you have one.
* **Insurance Card Number** (insurance_card_number, text, optional): Enter your insurance card number if you have one.
* **Medical Conditions** (medical_conditions, text, optional): Describe any medical conditions you have.
* **Test Results** (test_results, text, optional): Enter any test results you may have.
* **Doctor Referral** (doctor_referral, select_one, optional): If you were referred by a doctor, select 'Yes'.
* **Doctor Phone Number** (doctor_phone_number, text, optional): Enter your doctor's phone number if you have it.
* **Test Date** (test_date, date, required): Enter the date you were tested.
* **Time of Collection** (time_of_collection, time, required): Select the time you were tested.
* **Sample Type** (sample_type, select_one, required): Select 'Yes' if the sample was collected.
* **Result Type** (result_type, select_one, required): Select 'Yes' if the test result is available.
* **Test Site** (test_site, text, optional): Enter the location where you were tested.
* **Medical Office** (medical_office, text, optional): Enter the name of your medical office if you have one.
* **Patient ID** (patient_id, text, optional): Enter your patient ID if you have one.
* **Test Result Status** (test_result_status, select_one, required): Select the status of the test result (Active or Inactive).
* **Test Result Date** (test_result_date, date, required): Enter the date the test result was received.
* **Lab Result** (lab_result, text, optional): Enter the lab result if available.
* **Patient Condition** (patient_condition, text, optional): Enter any information about your condition.
* **Lab Result Status** (lab_result_status, select_one, optional): Select the status of the lab result (Active or Inactive).
* **Lab Result Date** (lab_result_date, date, optional): Enter the date the lab result was received.
* **Test Result Comment** (test_result_comment, text, optional): Enter any comments about the test result.
* **Test Result Comment 2** (test_result_comment2, text, optional): Enter any additional comments about the test result.
