# Travel Compliance Form - Help Guide
## Purpose
The Travel Compliance Form is a document used to collect information about an individual's travel history, travel reason, travel dates, travel location, travel duration, return location, and travel documents, among other details. This form is likely used in a business or organizational setting to ensure compliance with travel policies.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the form completely and accurately.
2. Provide all necessary information about your travel history, travel reason, travel dates, travel location, travel duration, return location, and travel documents.
3. Select the correct options for each field.

## Field-by-Field Explanation

* **Traveler Info (Page 1)**:
	+ *Traveler Info*: This field is a text input where you can provide any relevant information about yourself as a traveler.
* **Travel History (Page 1)**:
	+ *Travel History*: This field is a select multiple option where you can choose the countries you have traveled to in the past. Select all applicable countries.
* **Travel Reason (Page 1)**:
	+ *Travel Reason*: In this text field, please specify the reason for your travel.
* **Travel Dates (Page 1)**:
	+ *Travel Dates*: This field is a date input where you can select the start and end dates of your trip.
* **Travel Location (Page 1)**:
	+ *Travel Location*: This field is a text input where you can enter the city or country you are traveling to.
* **Travel Duration (Page 1)**:
	+ *Travel Duration*: This field is a numeric input where you can select the number of days you will be traveling.
* **Return Location (Page 1)**:
	+ *Return Location*: This field is a text input where you can enter the city or country you will return to.
* **Travel Documents (Page 1)**:
	+ *Travel Documents*: This field is a note input where you can attach any relevant travel documents, such as your passport or boarding pass.
* **Travel Status (Page 2)**:
	+ *Travel Status*: This field is a select one option where you can indicate whether you are currently on a trip.
* **Travel Comments (Page 2)**:
	+ *Travel Comments*: This field is a text input where you can provide any additional comments about your travel.
* **Form Complete (Page 2)**:
	+ *Form Complete*: This field is a select one option where you can indicate whether you have completed the form accurately.
* **E Signature (Page 2)**:
	+ *E Signature*: This field is a select one option where you can indicate whether you have electronically signed the form.

Note: Fields 8 (Travel Documents) and 12 (E Signature) are not required fields. 

Tips:
- Please fill out the form completely and accurately.
- Review your answers carefully before submitting the form.
- If you are unsure about any of the fields, please contact your supervisor or HR representative for clarification.
