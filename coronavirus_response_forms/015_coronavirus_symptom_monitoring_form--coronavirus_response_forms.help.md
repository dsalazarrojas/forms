# Coronavirus Symptom Monitoring Form - Help Guide
## Purpose
This form is used to collect information about a person's symptoms related to the coronavirus. It is intended for healthcare professionals to monitor and track the progression of the disease.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the required fields, marked with an asterisk (\*) on the form.
2. For each select\_one and select\_multiple field, select the answer that best matches your symptoms.
3. For the text fields, enter as much detail as possible.
4. If you have other symptoms not listed here, please include them in the "Other symptoms" field.
5. Ensure that you have filled out all the required fields before submitting the form.

## Field-by-Field Explanation

* **Cough** (`cough`, select\_one, \*: True/False): This field asks about the presence of a cough. Select "True" if you have a cough, and "False" if you do not.
* **Runny nose or congestion** (`runny\_nose`, select\_multiple, \*: True/False): This field asks about the severity of your runny nose or congestion. Select "None", "Slight", "Moderate", or "Severe" depending on how bad your symptoms are.
* **Sore throat** (`sore\_throat`, select\_one, \*: True/False): This field asks about the presence of a sore throat. Select "True" if you have a sore throat, and "False" if you do not.
* **Shortness of breath** (`shortness\_of\_breath`, select\_one, \*: True/False): This field asks about whether you are experiencing shortness of breath. Select "True" if you are experiencing shortness of breath, and "False" if you are not.
* **Fatigue** (`fatigue`, select\_one, \*: True/False): This field asks about the presence of fatigue. Select "True" if you are experiencing fatigue, and "False" if you are not.
* **Headache** (`headache`, select\_one, optional): This field asks about the presence of a headache. Select "True" if you have a headache, and "False" if you do not.
* **Muscle pain** (`muscle\_pain`, select\_one, optional): This field asks about the presence of muscle pain. Select "True" if you have muscle pain, and "False" if you do not.
* **Diarrhea** (`diarrhea`, select\_one, optional): This field asks about the presence of diarrhea. Select "True" if you have diarrhea, and "False" if you do not.
* **Abdominal pain** (`abdominal\_pain`, select\_one, optional): This field asks about the presence of abdominal pain. Select "True" if you have abdominal pain, and "False" if you do not.
* **Confusion** (`confusion`, select\_one, optional): This field asks about the presence of confusion. Select "True" if you are experiencing confusion, and "False" if you are not.
* **Other symptoms** (`other\_symptoms`, text, optional): This field is for any other symptoms you are experiencing that are not listed here.
* **Contact info** (`contact\_info`, text, \*: True/False): This field is for your contact information. Please include your name and any relevant contact information.
* **Medical history** (`medical\_history`, text, optional): This field is for any relevant medical history you may have.
* **Travel history** (`travel\_history`, text, optional): This field is for any recent travel history.
* **Hospitalization** (`hospitalization`, number, optional): This field is not currently used, please do not fill it out.
* **Medical attention** (`medical\_attention`, select\_one, optional): This field asks about whether you have received medical attention. Select "True" if you have received medical attention, and "False" if you have not.
* **Vaccination status** (`vaccination\_status`, select\_one, optional): This field asks about your vaccination status. Select "Not vaccinated", "Partially vaccinated", or "Fully vaccinated" depending on your status.
* **Test result** (`test\_result`, select\_one, optional): This field asks about the result of your test. Select "Negative", "Positive", or "Inconclusive" depending on your test result.
* **Test result date** (`test\_result\_date`, date, optional): This field is for the date of your test result.
* **Test result time** (`test\_result\_time`, time, optional): This field is for the time of your test result.
* **Symptoms start date** (`symptoms\_start\_date`, date, optional): This field is for the date when your symptoms started.
* **Symptoms start time** (`symptoms\_start\_time`, time, optional): This field is for the time when your symptoms started.
* **Symptoms end date** (`symptoms\_end\_date`, date, optional): This field is for the date when your symptoms ended.
* **Symptoms end time** (`symptoms\_end\_time`, time, optional): This field is for the time when your symptoms ended.
