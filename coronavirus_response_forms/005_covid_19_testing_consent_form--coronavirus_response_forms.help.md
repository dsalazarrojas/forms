# COVID 19 Testing Consent Form - Help Guide
## Purpose
This form is used to collect patient information and consent for COVID-19 testing.

## How To Complete This Form
To complete this form, follow these steps:

1. **Patient Information**: Complete the patient's name, date of birth, age, email address, and phone number.
2. **Medical History**: Answer the questions about allergies, chronic medical conditions, and current medications.
3. **Testing Information**: Specify the reason for testing and preferred test type.
4. **Consent and Acknowledgment**: Read and agree to the testing procedure, results communication, and data privacy.
5. **Emergency Contact**: Provide the name and phone number of your emergency contact.

## Field-by-Field Explanation
### Patient Information:
* **Patient Full Name**: Your full name, as it appears on official documents.
	+ Type: text
	+ Required: true
* **Date of Birth**: Your birthdate in MM/DD/YYYY format.
	+ Type: date
	+ Required: true
* **Age**: Your age in years.
	+ Type: number
	+ Required: true
* **Gender**: Your self-identified gender.
	+ Type: select_one
	+ Required: true
* **Email Address**: Your email address for communication.
	+ Type: email
	+ Required: true
* **Phone Number**: Your phone number for communication.
	+ Type: text
	+ Required: true

### Medical History:
* **Do you have any allergies to medications**: Check if you have allergies.
	+ Type: select_one
	+ Required: true
* **If yes, please specify**: Provide details about your allergies.
	+ Type: text
	+ Required: false
* **Do you have chronic medical conditions**: Check if you have chronic conditions.
	+ Type: select_one
	+ Required: true
* **Please describe your conditions**: Describe your chronic conditions.
	+ Type: text
	+ Required: false
* **Are you currently taking any medications**: Check if you are taking medications.
	+ Type: select_one
	+ Required: true

### Testing Information:
* **Reason for COVID-19 Testing**: Specify why you need to be tested.
	+ Type: select_one
	+ Required: true
* **Preferred Test Type**: Select your preferred test type.
	+ Type: select_one
	+ Required: true
* **Are you currently experiencing symptoms**: Check if you have symptoms.
	+ Type: select_one
	+ Required: true

### Consent and Acknowledgment:
* **I understand the testing procedure and its risks**: Check if you understand the procedure.
	+ Type: select_one
	+ Required: true
* **I consent to COVID-19 testing**: Check if you agree to be tested.
	+ Type: select_one
	+ Required: true
* **I authorize sharing of results via**: Select the methods to share your results.
	+ Type: select_multiple
	+ Required: true
* **I understand my data will be kept confidential and used only for COVID-19 testing purposes**: Check if you agree to data privacy.
	+ Type: select_one
	+ Required: true

### Emergency Contact:
* **Emergency Contact Name**: Provide the name of your emergency contact.
	+ Type: text
	+ Required: false
* **Emergency Contact Phone**: Provide the phone number of your emergency contact.
	+ Type: text
	+ Required: false
