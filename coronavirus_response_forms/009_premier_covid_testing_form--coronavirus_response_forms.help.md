# Premier COVID Testing Form - Help Guide
## Purpose
The Premier COVID Testing Form is a tool used to collect necessary information from patients for COVID-19 testing. This form is designed to gather details about the patient, the test type, test result, and laboratory or medical clinic specifics.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the relevant information about the patient from the "Patient Info" page.
2. Choose the type of test that was performed on the patient from the "Test Type" page.
3. Enter the patient's name, test date, phone number, and email address in the respective fields.
4. Select the location where the test was performed from the "Test Location" page.
5. Choose the method used for sample collection from the "Sample Collection Method" page.
6. Enter the test result and other relevant details about the test.

## Field-by-Field Explanation
* **Patient Info (Text)**: Enter the patient's information, such as name and phone number.
* **Test Type (Select One)**: Choose the type of test that was performed on the patient.
* **Patient Name (Text)**: Enter the patient's name.
* **Test Date (Date)**: Enter the date on which the test was performed.
* **Patient Phone (Text)**: Enter the patient's phone number.
* **Patient Email (Email)**: Enter the patient's email address.
* **Medical Clinic Name (Text)**: Enter the name of the medical clinic or laboratory where the test was performed.
* **Doctor Signature (Note)**: Enter the doctor's signature for verification purposes.
* **Patient Notes (Note)**: Enter any additional notes about the patient's condition or test result.
* **Test Location (Select One)**: Choose the location where the test was performed.
* **Sample Collection Method (Select One)**: Choose the method used for sample collection.
* **Sample Collection Date (Date)**: Enter the date on which the sample was collected.
* **Other Test Type (Text)**: Enter any other type of test that was performed.
* **Patient Age (Text)**: Enter the patient's age.
* **Other Test Type Details (Text)**: Enter any other details about the test type.
* **Doctor Name (Text)**: Enter the doctor's name.
* **Other Test Type Details 2 (Text)**: Enter any other details about the test type.
* **Patient Phone 2 (Text)**: Enter the patient's phone number (if different from the primary phone number).
* **Sample Type (Select One)**: Choose the type of sample collected.
* **Doctor Phone (Text)**: Enter the doctor's phone number.
* **Other Sample Type (Text)**: Enter any other type of sample collected.
* **Patient DOB (Date)**: Enter the patient's date of birth.
* **Doctor Notes (Note)**: Enter any notes from the doctor about the patient's condition.

Note: This guide is based on the provided form structure and fields. The fields and their labels may be subject to change based on the form's actual implementation and usage.
