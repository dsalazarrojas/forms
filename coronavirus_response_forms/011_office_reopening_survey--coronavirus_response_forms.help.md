# Office Reopening Survey - Help Guide
## Purpose
This form is used to gather information about the status of your office reopening plans. Please provide as much detail as possible to help us track the reopening process.

## How To Complete This Form
1. Answer each question to the best of your ability.
2. If you are unsure about a particular question, you can select "Still Considering" or "Unsure" as an option.
3. If you have any comments or feedback, please use the "Reopening Comments" field.

## Field-by-Field Explanation

* **Is the office ready to reopen?** (`office_reopening_survey_1`): This question is used to determine if the office is currently ready to reopen. Select "Open" if the office is ready to reopen, "Not Yet" if it is not ready, or "Still Considering" if you are still deciding.
* **What date do you plan to reopen?** (`reopening_date_planned`): This question is used to determine the planned reopening date of the office. Select the date on which you plan to reopen the office.
* **How many employees can fit in the office?** (`office_capacity`): This question is used to determine the maximum number of employees that can be in the office at one time. Enter a number that represents the maximum capacity.
* **Are you going to implement safety measures like hand sanitizer and masks?** (`safety_measures`): This question is used to determine if you will have safety measures in place. Select "True" if you will have safety measures, "False" if not, or "Unsure" if you are still deciding.
* **What testing would be necessary for employees?** (`employee_testing`): This question is used to determine the type of testing that will be necessary for employees. Select all that apply.
* **Are employees required to be vaccinated?** (`employee_vaccination`): This question is used to determine if employees are required to be vaccinated. Select "True" if they are, "False" if not, or "Unsure" if you are still deciding.
* **Will remote work be available after reopening?** (`remote_work_options`): This question is used to determine if remote work will be available after the office reopens. Select all that apply.
* **How many employees can fit in the office with social distancing?** (`office_capacity_percent`): This question is used to determine the maximum number of employees that can fit in the office with social distancing measures in place. Enter a number that represents the maximum capacity.
* **What is the estimated cost of reopening?** (`reopening_costs`): This question is used to determine the estimated cost of reopening the office. Enter a number that represents the estimated cost.
* **Are there any employee concerns or comments?** (`employee_concerns`): This question is used to gather any employee concerns or comments about the reopening process.
* **What is the planned reopening date?** (`reopening_timeline`): This question is used to determine the planned reopening date of the office. Select a date on which you plan to reopen the office.
* **Is the office currently open?** (`reopening_status`): This question is used to determine if the office is currently open or not. Select "True" if it is open, "False" if not.
* **Any comments or suggestions?** (`reopening_comments`): This question is used to gather any comments or suggestions about the reopening process.
* **Email address to contact?** (`email_address`): This question is used to gather the email address of the person to contact in case of emergency.
* **Phone number to contact?** (`phone_number`): This question is used to gather the phone number of the person to contact in case of emergency.
* **Emergency contact person?** (`emergency_contact`): This question is used to gather the name and contact information of the emergency contact person.
* **Reopening notes?** (`reopening_notes`): This question is used to gather any additional notes about the reopening process.
* **Employee feedback?** (`employee_feedback`): This question is used to determine if employees have provided feedback about the reopening process. Select "True" if they have, "False" if not.
* **How often do you want to reopen the office?** (`reopening_frequency`): This question is used to determine how often you want to reopen the office. Select all that apply.
* **Reopening capacity 1-6?** (`reopening_capacity_1-6`): This question is used to determine the maximum capacity of the office at different times (1-6). Enter a number that represents the maximum capacity at each time period.
