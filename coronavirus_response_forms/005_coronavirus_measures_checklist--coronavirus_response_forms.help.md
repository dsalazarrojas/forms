# coronavirus_measures_checklist - Help Guide
## Purpose
The purpose of this form is to track and monitor individual responses to the coronavirus (COVID-19) pandemic.

## How To Complete This Form
To complete this form, simply follow the instructions below.

## Field-by-Field Explanation
- **Check Symptoms** (`check_symptoms`, `text`, required: false): Check if you or anyone in your household has any symptoms of COVID-19, such as cough, fever, or shortness of breath.
- **Take Temperature** (`take_temperature`, `number`, required: false): If you have taken a temperature, enter it here. If not, just leave this blank.
- **Check Vaccination Status** (`check_vaccination_status`, `select_multiple`, required: false): If you're a healthcare worker, please select 'Vaccinated', if you haven't been vaccinated, select 'Not vaccinated', or if you're unsure, select 'Unknown'.
- **Check Travel History** (`check_travel_history`, `select_multiple`, required: false): Check any recent international travel or if you have been in contact with a confirmed case.
- **Symptom Status** (`check_symptom_status`, `select_multiple`, required: false): Check your current symptom status: if you have any symptoms, select 'Active symptoms', if you're feeling fine, select 'None', or if you've recovered, select 'Recovered'.
- **Check Contact** (`check_contact`, `select_multiple`, required: false): Check if you've been in contact with anyone with COVID-19 or if you've been exposed to the virus.
- **Temperature** (`check_temperature`, `number`, required: false): If you've taken a temperature, enter it here. If not, just leave this blank.
- **Travel Status** (`check_travel_status`, `select_one`, required: false): Select your current travel status, which can be 'No travel plans', 'Traveling', or 'Recently returned to work'.
- **Note** (`note`, `note`, required: false): If you have any additional comments or concerns, enter them here.
- **Email** (`email`, `email`, required: false): Enter your email address for follow-up contact, if required.

## Tips
- Be honest and accurate when answering the questions.
- Only fill out the sections that apply to you.
- If you're unsure about any question, just select 'Unknown' or 'Not Applicable'.
