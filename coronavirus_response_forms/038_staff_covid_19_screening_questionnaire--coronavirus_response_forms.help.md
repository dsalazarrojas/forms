# Staff Covid 19 Screening Questionnaire - Help Guide
## Purpose
The Staff Covid 19 Screening Questionnaire is designed to gather information from employees about their recent travel history, potential exposure to Covid-19, and symptoms they may be experiencing. This form helps to identify potential risks and ensure that employees are not at risk of infecting others in the workplace. Please only complete this form if you are an employee of the organization and have not already done so.

## How To Complete This Form
To complete this form, simply follow the instructions below:

1.  Read the form carefully before starting.
2.  Answer the questions based on your actual experience and knowledge.
3.  Select all the relevant options that apply to you.
4.  Ensure that all required fields are filled out before submitting the form.

## Field-by-Field Explanation

- **Staff Covid 19 Screening Questionnaire** (1, text, optional): This is the name of the form. Please do not edit this field.
- **Employee Information** (2, select_multiple, optional): Please select all relevant options regarding your employment status and department within the organization. This could include:
	+ Option 1: Active Employee
	+ Option 2: Retired Employee
	+ Option 3: Other (please specify)
- **Contact Information** (3, text, optional): Provide your contact information, including your name, email address, and phone number.
- **Questions** (4, select_multiple, optional): Please answer the following questions:
	+ Option 4: Yes
	+ Option 5: No
	+ Option 6: Other (please specify)
- **Travel History** (5, select_multiple, optional): If you have traveled recently, please select all the destinations you have visited:
	+ Option 7: Domestic (within the country)
	+ Option 8: International (outside the country)
	+ Option 9: Other (please specify)
- **Symptoms** (6, select_multiple, optional): If you are experiencing any of the following symptoms, please select them:
	+ Option 10: Fever
	+ Option 11: Cough
	+ Option 12: Other (please specify)
- **Exposure** (7, select_multiple, optional): If you have been exposed to someone with Covid-19, please select the relevant options:
	+ Option 13: Directly with an infected person
	+ Option 14: Indirectly (e.g., shared a room with someone with Covid-19)
	+ Option 15: Other (please specify)
- **Medical Clearance** (8, select_one, optional): If you are cleared by a healthcare professional to return to work, please select:
	+ Option 16: Yes
	+ Option 17: No
	+ Option 18: Other (please specify)
- **Testing Status** (9, text, optional): If you have been tested for Covid-19, please provide the test result.
- **Follow-up** (10, text, optional): If you need any further information or have any questions, please provide your follow-up contact information.
