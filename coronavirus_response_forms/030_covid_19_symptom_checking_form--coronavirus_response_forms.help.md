# Covid 19 Symptom Checking Form - Help Guide
## Purpose
This form is designed to help identify potential COVID-19 symptoms and assess risk factors for infection.

## How To Complete This Form
To complete this form, please follow these steps:

1. Enter your name in the "patient_name" field.
2. Select all the symptoms that you are currently experiencing from the "symptoms" dropdown menu.
3. Answer the "risk_factors" question by selecting the most relevant option from the dropdown menu.

## Field-by-Field Explanation

* **Patient Name**: Enter your name as you would like to be referred to in this assessment. This field is required.
	+ Type: Text
	+ Required: True
* **Symptoms**: Select all the symptoms that you are currently experiencing. These symptoms are used to assess the severity of your condition.
	+ Type: Select Multiple
	+ Required: False
*   *Fever*: Select this option if you have a temperature above 100.4°F (38°C)
*   *Fatigue*: Select this option if you feel extremely tired or weak.
*   *Coughing*: Select this option if you are coughing.
*   *Chest pain*: Select this option if you are experiencing pain in your chest.
*   *Headache*: Select this option if you have a headache.
*   *Loss of taste or smell*: Select this option if you have lost your sense of taste or smell.
*   *Nausea or vomiting*: Select this option if you are experiencing nausea or vomiting.
*   *Dizziness or lightheadedness*: Select this option if you feel dizzy or lightheaded.
*   *Difficulty breathing*: Select this option if you are having trouble breathing.
*   *Confusion or difficulty concentrating*: Select this option if you are experiencing confusion or difficulty concentrating.
*   *Muscle or body aches*: Select this option if you are experiencing muscle or body aches.
*   *Severe pain*: Select this option if you are experiencing severe pain.
*   *Sore Throat*: Select this option if you have a sore throat.
*   *Shortness of breath*: Select this option if you are experiencing shortness of breath.
*   *Diarrhea*: Select this option if you are experiencing diarrhea.
*   *Runny nose or stuffy nose*: Select this option if you have a runny or stuffy nose.
*   *Coughing up blood*: Select this option if you are coughing up blood.
* **Risk Factors**: Select the option that best describes your current situation.
	+ Type: Select One
	+ Required: True
*   *None*: Select this option if you don't have any risk factors.
*   *Family member with COVID-19 symptoms*: Select this option if a family member has COVID-19 symptoms.
*   *Close contact with someone with COVID-19*: Select this option if you have been in close contact with someone who has COVID-19.
*   *Recent travel to a COVID-19 hotspot*: Select this option if you have recently traveled to an area with reported COVID-19 cases.
*   *Recent exposure to someone with COVID-19*: Select this option if you have recently been exposed to someone with COVID-19.
*   *Recent international travel in the past 2 weeks*: Select this option if you have recently traveled internationally.
*   *Recent cruise ship travel*: Select this option if you have recently traveled on a cruise ship.

## Tips

* Please answer honestly and accurately to ensure the best possible assessment.
* If you are unsure about any of the symptoms or risk factors, please consult a medical professional for guidance.
* This form is for informational purposes only and is not a substitute for medical diagnosis or treatment.
