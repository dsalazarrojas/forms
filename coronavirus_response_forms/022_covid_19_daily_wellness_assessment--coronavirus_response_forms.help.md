# COVID 19 Daily Wellness Assessment - Help Guide
## Purpose
The COVID-19 Daily Wellness Assessment is a self-assessment tool designed to evaluate an individual's overall health and well-being during the COVID-19 pandemic.

## How To Complete This Form
To complete this form, simply fill out the required fields and select the options that best describe your current health status.

## Field-by-Field Explanation

* **Assessment Date**: Please enter the date of the assessment in MM/DD/YYYY format.
* **Assessment Time**: Enter the time of the assessment.
* **Name**: Enter your name as it appears on your identification document.
* **ID Number**: Enter your ID number as assigned by your institution or organization.
* **Department or School**: Enter your department or school affiliation.
* **Overall Health Today**: Select one of the following options to describe your overall health status:
	+ Excellent
	+ Good
	+ Fair
	+ Poor
* **Do you have a fever today?**: Select one of the following options:
	+ Yes
	+ No
* **Temperature Reading**: If you have a fever, enter your temperature in degrees Fahrenheit (e.g., 102°F).
* **Respiratory Symptoms**: Select all that apply:
	+ Cough
	+ Shortness of breath
	+ Sore throat
	+ Runny nose
	+ Sneezing
	+ None
* **Other Symptoms**: Select all that apply:
	+ Headache
	+ Body aches
	+ Chills
	+ Fatigue
	+ Loss of taste or smell
	+ Nausea or vomiting
	+ Diarrhea
	+ None
* **Have you felt well in the past 24 hours?**: Select one of the following options:
	+ Yes
	+ No
* **COVID-19 Exposure in Past 24 Hours**: Select one of the following options:
	+ Yes
	+ No
	+ Unsure
* **Household Member in Quarantine**: Select one of the following options:
	+ Yes
	+ No
* **Stress Level**: Select one of the following options:
	+ No stress
	+ Low stress
	+ Moderate stress
	+ High stress
	+ Extreme stress
* **Anxiety Level**: Select one of the following options:
	+ No anxiety
	+ Mild anxiety
	+ Moderate anxiety
	+ Severe anxiety
* **Sleep Quality Last Night**: Select one of the following options:
	+ Excellent
	+ Good
	+ Fair
	+ Poor
* **Wellness Check Result**: Select one of the following options:
	+ Cleared to attend
	+ Recommend staying home
	+ Seek medical evaluation
* **Ready to Participate in Activities**: Select one of the following options:
	+ Yes
	+ No

## Tips
* Be honest and accurate when answering the questions.
* If you are unsure about any question, select the option that best describes your current situation.
* If you have any additional concerns or symptoms not listed, please enter them in the "Additional Wellness Concerns" field.
