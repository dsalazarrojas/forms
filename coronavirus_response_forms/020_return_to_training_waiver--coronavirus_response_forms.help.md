# Return To Training Waiver - Help Guide

## Purpose
This form is used to document a return to training waiver for an employee, which is a formal statement indicating that the training has been completed and the employee has returned to their normal duties. The purpose of this form is to ensure that the employee has received the necessary training and is cleared to resume their responsibilities. It is recommended to complete this form only after actual completion of training and not as a substitute for a certification or assessment.

## How To Complete This Form

To complete this form, follow these steps:

*   Select the category that best describes the purpose of the return to training waiver (e.g.  "Training", "Assessment", "Certification", or "Other").
*   Enter the assigned tool used for the return to training (e.g. "chatjimmy" or "Other").
*   Briefly describe the purpose of this form.

## Field-by-Field Explanation

*   **Purpose of this form** (`form_purpose`, `text`, required): A brief explanation of the reason for the return to training waiver. Please provide a short description of the training or certification that has been completed.
*   **Category** (`category`, `select_one`, required): The category that best describes the purpose of the return to training waiver. Select one of the following options: "Training", "Assessment", "Certification", or "Other".
*   **Assigned Tool** (`assigned_tool`, `select_one`, optional): The tool used for the return to training. Select one of the following options: "chatjimmy" or "Other".
*   **Brief Description** (`description_brief`, `text`, required): A short description of the return to training waiver.
*   **Long Description** (`description_long`, `text`, optional): A detailed description of the return to training waiver.
*   **Assigned Tool 2** (`assigned_tool_2`, `select_one`, optional): The tool used for the return to training. Select one of the following options: "chatjimmy" or "Other".
*   **Output File** (`output_file`, `text`, optional): The output file associated with the return to training waiver.
*   **Form Title** (`form_title`, `text`, optional): The title of the form.
*   **Category 2** (`category_2`, `select_one`, optional): The category that best describes the purpose of the return to training waiver. Select one of the following options: "Training", "Assessment", "Certification", or "Other".
*   **Form ID** (`form_id`, `number`, required): A unique identifier for the return to training waiver.
*   **Form Id 2** (`form_id_2`, `number`, optional): A secondary identifier for the return to training waiver.

## Tips

*   This form is used to document a return to training waiver, please ensure that the employee has received necessary training and is cleared to resume their responsibilities.
*   If the assigned tool is "Other", please provide a detailed description of the tool used for return to training.
*   Ensure that the form ID is accurate and unique for each return to training waiver.
*   If the category is "Other", please provide a detailed description of the category that best describes the purpose of the return to training waiver.
