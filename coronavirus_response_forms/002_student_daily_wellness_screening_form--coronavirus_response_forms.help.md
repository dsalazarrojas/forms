# Student Daily Wellness Screening Form - Help Guide

## Purpose

The purpose of this form is to collect information on COVID-19 symptoms and travel history from students. This information will help the school administrators and healthcare professionals to identify potential cases of COVID-19 and take necessary steps to prevent its spread.

## How To Complete This Form

1. **Parent or Guardian Information**: This section is where you can enter the parent or guardian's name, email, and phone number.
2. **Student Information**: Enter your own name, email, and any other relevant student information.
3. **COVID-19 Symptoms**: Check all the symptoms that you are experiencing or have experienced in the past 14 days.
4. **Travel Information**: Select the type of travel you have done in the past 14 days (domestic or international).
5. **Recent Travel History**: Enter the date of your most recent domestic or international travel.
6. **Contact Information**: Enter your phone number and email address where you can be reached for follow-up questions or contact tracing.
7. **Emergency Contact**: Enter the name of the emergency contact, their relationship to you, and their phone number.
8. **School Information**: Enter your school name and the grade level you are in.
9. **Student Symptoms**: Report any symptoms you are experiencing on a scale of 0 to 3.

## Field-by-Field Explanation

* **Parent or Guardian Information** (`Parent or Guardian Information`, `text`, required/optional): Enter the name and contact information of the parent or guardian.
* **Student Information** (`Student Information`, `text`, required/optional): Enter your name, email, and any other relevant student information.
* **COVID-19 Symptoms** (`COVID-19 Symptoms`, `select_multiple`, required): Check all the symptoms that you are experiencing or have experienced in the past 14 days.
	+ Fever: Check this box if you have a fever.
	+ Cough: Check this box if you have a cough.
	+ Shortness of breath: Check this box if you have shortness of breath.
	+ Fatigue: Check this box if you are feeling tired.
	+ Muscle or body aches: Check this box if you have muscle or body aches.
	+ Headache: Check this box if you have a headache.
	+ Sore throat: Check this box if you have a sore throat.
	+ Runny nose/congestion: Check this box if you have a runny nose or congestion.
	+ Diarrhea: Check this box if you have diarrhea.
	+ Nausea or vomiting: Check this box if you have nausea or vomiting.
	+ New loss of taste or smell: Check this box if you have lost your sense of taste or smell.
	+ New loss of appetite: Check this box if you are not interested in food.
	+ Confusion or difficulty concentrating: Check this box if you are confused or having trouble concentrating.
	+ New numbness or tingling in hands or feet: Check this box if you have numbness or tingling in your hands or feet.
	+ Feeling like I am going to pass out: Check this box if you feel like you are going to pass out.
* **Travel Information** (`Travel Information`, `select_multiple`, required): Select the type of travel you have done in the past 14 days.
	+ Domestic: Select this box if you have traveled domestically.
	+ International: Select this box if you have traveled internationally.
* **Recent Travel History** (`Recent Travel History`, `date`, required): Enter the date of your most recent domestic or international travel.
* **Contact Information** (`Contact Information`, `text`, required/optional): Enter your phone number and email address where you can be reached for follow-up questions or contact tracing.
* **Emergency Contact** (`Emergency Contact`, `text`, required/optional): Enter the name of the emergency contact, their relationship to you, and their phone number.
* **School Information** (`School Information`, `text`, required/optional): Enter your school name and the grade level you are in.
* **Student Symptoms** (`Student Symptoms`, `number`, required): Report any symptoms you are experiencing on a scale of 0 to 3.
* **Emergency Contact Relationship** (`Emergency Contact Relationship`, `select_one`, required): Select the relationship of the emergency contact to you.
	+ Mother: Select this box if the emergency contact is your mother.
	+ Father: Select this box if the emergency contact is your father.
	+ Guardian: Select this box if the emergency contact is your guardian.
	+ Other: Select this box if the emergency contact is someone else.
* **School Attended** (`School Attended`, `select_one`, required): Select the school you attend.
	+ Local: Select this box if you attend a local school.
	+ Out-of-Local: Select this box if you attend a school out-of-local.
* **Grade Level** (`Grade Level`, `select_one`, required): Select your grade level.
	+ K-12: Select this box if you are in grades K-12.
	+ 9-12: Select this box if you are in grades 9-12.
	+ College: Select this box if you are in college.
	+ University: Select this box if you are in university.
* **Student Symptoms** (`Student Symptoms`, `text`, required/optional): Report any symptoms you are experiencing.
* **Phone** (`Phone`, `number`, required/optional): Enter your phone number.
* **Phone2** (`Phone2`, `text`, required/optional): Enter your phone number (if different).
* **Emergency Contact Phone** (`Emergency Contact Phone`, `text`, required): Enter the phone number of the emergency contact.
* **School Grade** (`School Grade`, `select_one`, required): Select the grade level you are in.
	+ K-12: Select this box if you are in grades K-12.
	+ 9-12: Select this box if you are in grades 9-12.
	+ College: Select this box if you are in college.
	+ University: Select this box if you are in university.
