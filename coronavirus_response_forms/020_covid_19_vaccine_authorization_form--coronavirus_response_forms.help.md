# COVID 19 Vaccine Authorization Form - Help Guide
## Purpose
This form is a critical tool for public health officials and organizations to collect and review information about COVID-19 vaccination programs. It helps ensure that requests align with public health guidelines and regulations.

## How To Complete This Form

To complete this form, follow these steps:

1. Fill in the requestor's name and title.
2. Enter the email address and phone number of the person submitting the request.
3. Enter the organization's name, type, address, city, state, and zip code.
4. Select the purpose of the authorization request (e.g., employee vaccination program, customer access requirements).
5. Estimate the number of individuals to be vaccinated.
6. Identify the target groups for vaccination (e.g., employees, customers, visitors).
7. Select the proposed vaccination timeline.
8. Choose the vaccine type preference (e.g., Pfizer, Moderna).
9. Describe how the organization plans to manage the vaccination program.
10. Determine the location where vaccinations will be administered (e.g., on-site facility, off-site clinic).
11. Explain the plan for keeping records and verifying vaccination data.
12. Identify the funding source for the vaccination program.
13. (Optional) If you anticipate any challenges with the vaccination program, describe them.
14. Explain how you plan to address potential challenges.
15. (Optional) If you need support or resources from the government, describe what you need.
16. Certify that the information provided is accurate.

## Field-by-Field Explanation
* **Requestor Full Name** (1, Text, Required): This is the name of the person submitting the request.
* **Position or Title** (2, Text, Required): This is the title or position of the person submitting the request.
* **Email Address** (3, Email, Required): This is the email address of the person submitting the request.
* **Phone Number** (4, Text, Required): This is the phone number of the person submitting the request.
* **Organization Information** (5, Note, Not Required): This is a note field for organizational information, if needed.
* **Organization or Business Name** (6, Text, Required): This is the name of the organization or business requesting access to COVID-19 vaccines.
* **Type of Organization** (7, Select One, Required): This is the type of organization (e.g., government agency, healthcare facility).
* **Organization Address** (8, Text, Required): This is the address of the organization requesting access to COVID-19 vaccines.
* **City** (9, Text, Required): This is the city where the organization is located.
* **State** (10, Text, Required): This is the state where the organization is located.
* **Zip Code** (11, Text, Required): This is the zip code where the organization is located.
* **Authorization Request Purpose** (12, Select One, Required): This is the purpose of the authorization request (e.g., employee vaccination program, customer access requirements).
* **Estimated Number of Individuals to be Vaccinated** (14, Number, Required): This is an estimate of the number of individuals to be vaccinated.
* **Target Groups for Vaccination** (15, Select Multiple, Required): This is a list of groups to be vaccinated (e.g., employees, customers, visitors).
* **Proposed Vaccination Timeline** (16, Select One, Required): This is the proposed timeline for vaccination.
* **Vaccine Type Preference** (17, Select One, Required): This is the preferred type of vaccine (e.g., Pfizer, Moderna).
* **Vaccination Implementation Plan** (19, Text, Required): This is a description of how the organization plans to manage the vaccination program.
* **Vaccination Site Location** (20, Select One, Required): This is the location where vaccinations will be administered (e.g., on-site facility, off-site clinic).
* **Plan for Record Keeping and Verification** (21, Text, Required): This is the plan for keeping records and verifying vaccination data.
* **Funding Source for Vaccination Program** (22, Select One, Required): This is the source of funding for the vaccination program (e.g., organization funds, government funds).
* **Anticipated Barriers or Challenges** (24, Text, Not Required): This is a field for describing potential challenges with the vaccination program.
* **Strategy to Address Barriers** (25, Text, Not Required): This is a field for explaining how to address potential challenges.
* **Support or Resources Needed from Government** (26, Text, Not Required): This is a field for describing what support or resources are needed from the government.
* **I Certify this Authorization Request is Accurate** (27, Select One, Required): This is a certification that the information provided is accurate.
