# Parent Guardian Attestation - Help Guide
## Purpose
The Parent Guardian Attestation form is designed to gather information about a student's health and well-being, specifically in relation to potential COVID-19 exposure or symptoms. This form is used to report if a student or parent has exhibited any symptoms or if they will be attending school.

## How To Complete This Form
1. Please fill out the form with the requested information.
2. Make sure to answer all the required fields marked with an asterisk (*).
3. If you're unsure about any field, feel free to contact the school administration for guidance.

## Field-by-Field Explanation
* **Student Name**: 
  • Enter the student's full name as it appears on their official records.
* **Parents Name**:
  • Enter the parent or guardian's name as it appears on their official records.
* **Student ID Number**:
  • Enter the student's identification number or student ID.
* **Parents Phone**:
  • Enter the parent or guardian's phone number.
* **Parents Email**:
  • Enter the parent or guardian's email address.
* **Has Student Exhibited Any Symptoms**:
  • Select "Yes" if the student has exhibited any symptoms related to COVID-19.
  • Select "No" if the student has not exhibited any symptoms.
* **Have the Parents Exhibited Any Symptoms**:
  • Select "Yes" if the parent or guardian has exhibited any symptoms related to COVID-19.
  • Select "No" if the parent or guardian has not exhibited any symptoms.
* **When did you start showing symptoms**:
  • Enter the date when the parent or guardian started showing symptoms.
* **Will the Student be attending school**:
  • Select "Yes" if the student will be attending school.
  • Select "No" if the student will not be attending school.
* **Will you be attending school**:
  • Select "Yes" if the parent or guardian will be attending school.
  • Select "No" if the parent or guardian will not be attending school.
