# fire_rescue_aerosolized_procedure_report_form - Help Guide
## Purpose
The fire_rescue_aerosolized_procedure_report_form is a tool used to gather information from lead medical professionals who respond to fire rescue situations involving aerosolized procedures. This form helps in collecting details about the incident, the medical team involved, and any additional context relevant to the response.

## How To Complete This Form
1. Start by selecting the correct page with the "lead_medic_info" label.
2. Complete the fields on this page with the required information.

## Field-by-Field Explanation
* **lead_medic_info (text, text, false):** This field is where you can input any relevant information about the incident, including any specific details about the medical response.
	+ Please provide a brief description of the incident.
* **hidden_section (text, text, false):** This section is for capturing any additional context or information that is not publicly available.
	+ Please use this field for sensitive or confidential information only.
* **hidden_section_1 (text, text, false):** This section is another opportunity to provide any additional details that are not already covered in the previous fields.
	+ Please note that this field is not visible by default, as indicated by its label.
