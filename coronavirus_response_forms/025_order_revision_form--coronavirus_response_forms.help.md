# order_revision_form - Help Guide
## Purpose
The "Order Revision Form" is used to collect information for order revisions, enabling the order revision team to efficiently process and address requests from customers or clients.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill in the required fields, indicated by the asterisk (\*) symbol.
2. Choose the relevant reasons for the revision using the "revision_reason" field.
3. Enter the date of the revision in the "revision_date" field.
4. Add any additional notes or comments in the "note" field.
5. Enter the Order ID to be revised in the "order_id" field.
6. If applicable, select the option to cancel the order in the "cancel_order_label" field.
7. Choose the email notification options in the "email_sent" field.

## Field-by-Field Explanation
* **Revision Reason (revision_reason)**: Select the reason for the order revision.
* **Revision Date (revision_date)**: Enter the date of the revision (in date format, e.g., MM/DD/YYYY).
* **Phone (phone)**: Enter any phone number related to the order revision.
* **Notes (note)**: Add any additional comments or notes about the order revision.
* **Order ID (order_id)**: Enter the ID of the order to be revised.
* **Cancel Order (cancel_order_label)**: If applicable, select this option to cancel the order.
* **Submit Options (submit)**: Choose the option to submit the form.
* **Email (email)**: Enter the email address to receive the order revision update.
* **Email Notification (email_sent)**: Choose the email notification option for the order revision update.
