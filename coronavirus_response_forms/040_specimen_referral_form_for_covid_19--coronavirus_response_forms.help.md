# Specimen Referral Form For COVID 19 - Help Guide
## Purpose
The Specimen Referral Form is a critical document used to track and manage the specimen collection, transport, and testing process for COVID-19 testing. It is essential to gather accurate and complete information to ensure proper specimen processing and testing.

## How To Complete This Form

To complete this form, please follow these steps:

1.  Review each field carefully and ensure that you have accurate information before filling out the form.
2.  Fill out all required fields (indicated by \*).
3.  If a field is optional, please fill it out if you have the necessary information.

## Field-by-Field Explanation

* **Specimen Info** (`specimen_info`, text, optional): Please provide a brief description of the specimen being referred.
* **Specimen Status** (`specimen_status`, select_one, optional): Select the status of the specimen, either "New" or "Old".
* **Specimen Type** (`specimen_type`, select_multiple, optional): Select the type of specimen, either "Swab", "Tissue", or "Blood".
* **Specimen Collected** (`specimen_collected`, date, optional): Please enter the date the specimen was collected.
* **Collected Time** (`collected_time`, time, optional): Enter the time the specimen was collected.
* **Specimen Sent to Lab** (`specimen_sent_to_lab`, select_one, optional): Check "True" if the specimen has been sent to the lab.
* **Specimen Arrival Time** (`specimen_arrival_time`, time, optional): Enter the time the specimen arrived at the lab.
* **Specimen Status Updated** (`specimen_status_updated`, date, optional): Please enter the date the specimen status was updated.
* **Specimen Receipt Date** (`specimen_receipt_date`, date, optional): Enter the date the specimen was received at the lab.
* **Specimen Result Received** (`specimen_result_received`, select_one, optional): Check "True" if the specimen result has been received.
* **Specimen Result Date** (`specimen_result_date`, date, optional): Enter the date the specimen result was received.
* **Contact Info Collected** (`contact_info_collected`, text, optional): Please provide any contact information collected for the specimen.
* **Patient Info Collected** (`patient_info_collected`, text, optional): Please provide any patient information collected.
* **Laboratory Info Collected** (`laboratory_info_collected`, text, optional): Please provide any laboratory information collected.
* **Specimen Collected By** (`specimen_collected_by`, select_multiple, optional): Select who collected the specimen, either "Centre" or "Laboratory".
* **Laboratory Name** (`laboratory_name`, text, optional): Please provide the name of the laboratory.
* **Laboratory Contact** (`laboratory_contact`, text, optional): Please provide the contact information for the laboratory.
* **Laboratory Address** (`laboratory_address`, text, optional): Please provide the address of the laboratory.
* **Specimen Transported By** (`specimen_transported_by`, select_multiple, optional): Check "True" if the specimen was transported by the selected option.
* **Transport Method** (`transport_method`, select_one, optional): Select the transport method, either "Car" or "Bike".
* **Specimen Transported To** (`specimen_transported_to`, select_multiple, optional): Select where the specimen was transported, either "Laboratory" or "Centre".
* **Transport Date** (`transport_date`, date, optional): Enter the date the specimen was transported.
* **Transport Time** (`transport_time`, time, optional): Enter the time the specimen was transported.
* **Transport Vehicle** (`transport_vehicle`, select_one, optional): Select the vehicle used for transport, either "Car" or "Bike".

Note:
Please ensure that all required fields are filled out accurately to ensure proper specimen processing and testing. If you have any doubts or concerns, please contact the relevant authorities for assistance.
