# Event Cancellation Form - Help Guide
## Purpose
This form is for event attendees to request cancellation of an event, which will prompt the event organiser to process the request.

## How To Complete This Form
1.  Fill out all required fields.
2.  Enter the Event Status (e.g., Event Cancelled).
3.  Provide any additional context with Notes, if applicable.

## Field-by-Field Explanation
- **Event Title** (`event_title`, text, required): Enter the title of the event you want to cancel.
- **Event Date** (`event_date`, date, required): Select the date of the event you want to cancel.
- **Reason** (`reason`, text, optional): If you'd like to provide more context for the event cancellation, enter a brief explanation here.
- **Refund Amount** (`refund_amount`, number, optional): If applicable, enter the refund amount you're requesting.
- **User Email** (`user_email`, email, required): Enter the email address of the account holder who registered for the event.
- **User Phone** (`user_phone`, text, optional): If you'd like to provide a phone number, enter it here for faster contact.
- **Event Status** (`event_status`, select_one, required): Select the status of the event you're requesting to cancel (e.g., Event Cancelled, Event Rescheduled, etc.).
- **Notes** (`notes`, text, optional): If additional notes are necessary, enter them here.
- **Event Date 1** (`event_date_1`, date, optional): Another date-related field (it seems to be a duplicate of event_date, please ensure you only fill this out if you've selected "Event Status" to "Event Rescheduled"). 

## Tips
- Make sure to fill out all required fields accurately to ensure the cancellation process is initiated correctly.
- If you need help or have further questions, contact us at [insert contact email/number here].
