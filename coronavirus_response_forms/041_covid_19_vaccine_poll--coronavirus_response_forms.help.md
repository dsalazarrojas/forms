# COVID 19 Vaccine Poll - Help Guide
## Purpose
This form is designed to collect information from employees about their willingness to be vaccinated against COVID-19, and their preferences for vaccination timing and location.

## How To Complete This Form
1. Please fill out the form completely, including all required fields.
2. Select your responses from the provided options for each field.
3. If you have any concerns or questions, please elaborate in the text fields provided.

## Field-by-Field Explanation

* **Full Name** (Page 1, 1. **respondent_name**, Text, Required): Enter your full name as it appears on your identification documents.
* **Employee ID** (Page 1, 2. **employee_id**, Text, Required): Enter your employee ID number as assigned by HR.
* **Department or Division** (Page 1, 3. **department**, Text, Required): Select your department or division within the company.
* **-- Vaccination Poll --** (Page 1, 4. **poll_section**, Note, Not Required): This is a placeholder for the form header.
* **Are you willing to be vaccinated against COVID-19** (Page 1, 5. **willing_to_be_vaccinated**, Select One, Required): Choose your response to being vaccinated:
	+ True: I am willing to be vaccinated.
	+ False: I am not willing to be vaccinated.
	+ Unsure: I am unsure about being vaccinated.
	+ Already vaccinated: I have already been vaccinated.
* **If willing, when would you like to be vaccinated** (Page 1, 6. **vaccination_timeline**, Select One, Required): Choose your preferred timeline:
	+ As soon as possible.
	+ Within 1-2 weeks.
	+ Within 1 month.
	+ Within 2-3 months.
	+ Flexible.
	+ Not applicable.
* **Vaccine Type Preference** (Page 1, 7. **vaccine_preference**, Select One, Required): Select your preferred vaccine type:
	+ Pfizer.
	+ Moderna.
	+ Johnson and Johnson.
	+ No preference.
	+ Unsure.
	+ Not applicable.
* **Which Dose Are You Interested In** (Page 1, 8. **dose_type**, Select One, Required): Select your preferred dose:
	+ First dose.
	+ Second dose.
	+ Booster dose.
	+ Multiple doses.
	+ Not applicable.
* **-- Concerns and Information --** (Page 2, 9. **concerns_section**, Note, Not Required): This is a placeholder for the form section header.
* **Main Concern About Vaccination** (Page 2, 10. **main_concern**, Select One, Required): Select your main concern:
	+ Safety.
	+ Side effects.
	+ Effectiveness.
	+ Allergies.
	+ Medical conditions.
	+ Personal beliefs.
	+ Religious reasons.
	+ Lack of information.
	+ Trust.
	+ Cost.
	+ Other.
	+ None.
* **Please elaborate on your concern** (Page 2, 11. **concern_details**, Text, Not Required): If you have a concern that is not listed above, please provide more information about it.
* **What information would help your decision** (Page 2, 12. **information_needed**, Select Multiple, Not Required): Select all that apply:
	+ Safety data.
	+ Efficacy information.
	+ Side effects list.
	+ FAQ document.
	+ Video testimonial.
	+ Medical expert advice.
	+ Employer statement.
	+ Other.
* **-- Health Status --** (Page 3, 13. **health_section**, Note, Not Required): This is a placeholder for the form section header.
* **Do you consider yourself at higher risk** (Page 3, 14. **high_risk**, Select One, Required): Select your response:
	+ True.
	+ False.
	+ Unsure.
	+ Prefer not to answer.
* **Have you had COVID-19 before** (Page 3, 15. **health_conditions**, Select One, Required): Select your response:
	+ True.
	+ False.
	+ Unsure.
* **-- Work Location --** (Page 4, 17. **work_location_section**, Note, Not Required): This is a placeholder for the form section header.
* **Primary Work Location** (Page 4, 18. **work_location**, Select One, Required): Select your primary work location:
	+ Office.
	+ Remote.
	+ Hybrid.
	+ On-site facility.
	+ Multiple locations.
* **Regular public contact in your work** (Page 4, 19. **public_contact**, Select One, Required): Select your response:
	+ True.
	+ False.
* **-- Logistics Preferences --** (Page 5, 20. **logistics_section**, Note, Not Required): This is a placeholder for the form section header.
* **Preferred Vaccination Location** (Page 5, 21. **preferred_location**, Select One, Required): Select your preferred location:
	+ On-site at workplace.
	+ Nearby clinic.
	+ Pharmacy.
	+ Healthcare provider office.
	+ Mobile clinic.
	+ Home.
	+ No preference.
* **Preferred Time for Vaccination** (Page 5, 22. **preferred_time**, Select One, Required): Select your preferred time:
	+ Morning.
	+ Afternoon.
	+ Evening.
	+ During work hours.
	+ Outside work hours.
	+ Flexible.
* **Willing to take time off work for vaccination** (Page 5, 23. **time_off**, Select One, Required): Select your response:
	+ True.
	+ False.
	+ Unsure.
* **-- Additional Comments --** (Page 6, 24. **comments_section**, Note, Not Required): This is a placeholder for the form section header.
* **Any Additional Comments or Suggestions** (Page 6, 25. **additional_comments**, Text, Not Required): If you have any additional comments or suggestions, please provide them here.
