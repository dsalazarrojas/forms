# Student Parent Handbook Acknowledgment Form - Help Guide
## Purpose
This form is to acknowledge that students and parents have received and understood the student parent handbook.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill in your Student Name and Parent Name in the respective fields.
2. If your Student ID is available, please enter it.
3. Attach a copy of the student/parent handbook to the form.
4. Sign the Parent Signature Date and Student Signature Date with the current date.
5. Select the Submit option to finalize your acknowledgment.

## Field-by-Field Explanation
### Student Name (Student Name)
 Student Name is the name of the student completing this form.

### Parent Name (Parent Name)
Parent Name is the name of the parent/guardian completing this form on behalf of the student.

### Student ID (Student ID)
This is the student's identification number. Enter it if available.

### Attach Handbook (Handbook Attachment)
 Attach a copy of the student/parent handbook to the form.

### Parent Signature Date (Parent Signature Date)
Date on which the parent completes and signs this form.

### Student Signature Date (Student Signature Date)
Date on which the student completes and signs this form.

### Submit (Submit)
Select the option to finalize your acknowledgment. Please choose from Student Parent Handbook Acknowledgment Form or Other.
