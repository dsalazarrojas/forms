# COVID 19 Lab Report Form - Help Guide
## Purpose
The COVID 19 Lab Report Form is designed to collect detailed information about COVID-19 lab tests, including laboratory details, patient information, test results, and clinical interpretations. This form is intended for tracking and recording lab reports related to COVID-19.

## How To Complete This Form
To complete this form accurately, follow these steps:

1. Enter the Laboratory Name in the "Laboratory Name" field (required).
2. Select the Report Date in the "Report Date" field (required).
3. Enter the Lab Report ID in the "Lab Report ID" field (required).
4. Provide the Patient's Name in the "Patient Name" field (required).
5. Enter the Date of Birth for the patient in the "Date of Birth" field (required).
6. Enter the Patient ID or Medical Record Number in the "Patient ID or Medical Record Number" field (optional).
7. Enter the patient's Email Address in the "Email Address" field (required).
8. Enter the patient's Phone Number in the "Phone Number" field (optional).
9. Select the Type of Test from the "Type of Test" dropdown (required).
10. Select the Specimen Type from the "Specimen Type" dropdown (required).
11. Enter the Specimen Collection Date in the "Specimen Collection Date" field (required).
12. Enter the Specimen Collection Time (optional).
13. Select the Test Result from the "Test Result" dropdown (required).
14. Enter the CT Value (if applicable) in the "CT Value (if applicable)" field (optional).
15. Enter any Additional Result Notes in the "Additional Result Notes" field (optional).
16. Provide the Clinical Interpretation in the "Clinical Interpretation" field (optional).
17. Enter any Recommendations for the patient in the "Recommendations" field (optional).
18. Enter the Technician's Name in the "Technician Name" field (required).
19. Enter the Reviewing Physician's Name in the "Reviewing Physician Name" field (required).
20. Select the Date Reviewed in the "Date Reviewed" field (required).

## Field-by-Field Explanation

* **Laboratory Name (Lab Name)** (`{2}`): Enter the name of the laboratory that conducted the test.
* **Report Date (report_date)** (`{3}`): Enter the date the test was conducted.
* **Lab Report ID (lab_id)** (`{4}`): Enter the unique identifier for the lab report.
* **Patient Name (patient_name)** (`{6}`): Enter the name of the patient who underwent the test.
* **Date of Birth (date_of_birth)** (`{7}`): Enter the patient's date of birth.
* **Patient ID or Medical Record Number (patient_id)** (`{8}`): Enter the patient's ID or medical record number (if available).
* **Email Address (patient_email)** (`{9}`): Enter the patient's email address.
* **Phone Number (patient_phone)** (`{10}`): Enter the patient's phone number (if available).
* **Type of Test (test_type)** (`{12}`): Select the type of test conducted (e.g., RT-PCR, Rapid Antigen, etc.).
* **Specimen Type (specimen_type)** (`{13}`): Select the type of specimen collected (e.g., nasopharyngeal swab, etc.).
* **Specimen Collection Date (specimen_collection_date)** (`{14}`): Enter the date the specimen was collected.
* **Specimen Collection Time (specimen_collection_time)** (`{15}`): Enter the time the specimen was collected (if available).
* **Test Result (test_result)** (`{17}`): Select the test result (e.g., Positive, Negative, etc.).
* **CT Value (if applicable) (ct_value)** (`{18}`): Enter the CT value (if applicable).
* **Additional Result Notes (result_notes)** (`{19}`): Enter any additional notes about the test result.
* **Clinical Interpretation (clinical_interpretation)** (`{21}`): Enter the clinical interpretation of the test result.
* **Recommendations (recommendations)** (`{22}`): Enter any recommendations for the patient.
* **Technician Name (technician_name)** (`{24}`): Enter the name of the technician who conducted the test.
* **Reviewing Physician Name (reviewing_physician)** (`{25}`): Enter the name of the reviewing physician.
* **Date Reviewed (review_date)** (`{26}`): Select the date the test result was reviewed.
