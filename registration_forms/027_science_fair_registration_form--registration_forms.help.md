# Science Fair Registration Form - Help Guide
## Purpose
The Science Fair Registration Form is used to register students for a science fair, allowing them to participate in the event.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the student's name in the "Student Name" field.
2. Fill in the student's address in the "Student Address" field.
3. Enter the student's phone number in the "Student Phone" field.
4. Enter the student's email address in the "Student Email" field.
5. Enter the name of the science project in the "Science Project Name" field.
6. Provide a brief description of the science project in the "Science Project Description" field.
7. Select the category of the science project from the "Project Category" field.
8. If necessary, select additional categories for the science project from the "Project Category Select Options" field.

## Field-by-Field Explanation

* **Registration Form** (Registration Form, text, required: false): This is the main form section where you can enter any additional information you want to share with the science fair organizers.
* **Student Name** (Student Name, text, required: false): Enter the student's full name.
* **Student Address** (Student Address, text, required: false): Enter the student's home address.
* **Student Phone** (Student Phone, text, required: false): Enter the student's phone number.
* **Student Email** (Student Email, email, required: false): Enter the student's email address.
* **Science Project Name** (Science Project Name, text, required: false): Enter a brief name of the science project.
* **Science Project Description** (Science Project Description, text, required: false): Enter a brief description of the science project.
* **Project Category** (Project Category, select one, required: false): Select the category of the science project. Options include "Yes" and "No".
* **Project Category Select Options** (Project Category Select Options, select multiple, required: false): Select additional categories for the science project.
* **Category 1** (Category 1, text, required: false): Select the first category for the science project.
* **Category 2** (Category 2, text, required: false): Select the second category for the science project.
* **Category 3** (Category 3, text, required: false): Select the third category for the science project.
* **Category 4** (Category 4, text, required: false): Select the fourth category for the science project.
* **Category 5** (Category 5, text, required: false): Select the fifth category for the science project.
