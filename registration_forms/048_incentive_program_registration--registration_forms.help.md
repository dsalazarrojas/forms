# Incentive Program Registration - Help Guide
## Purpose
This form is used to register an Incentive Program with the necessary details of the program and participant. Completing this form will help us process your program for further actions.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the **Program Name**, **Program Type**, and **Program Status** sections with the relevant information.
2. Enter your **Participant Name**, **Email**, **Phone Number**, **Company**, and **Address**.
3. Select the **Program Type** and **Program Status** from the dropdown menus.
4. Choose your **Time Zone**.
5. Add any additional **Notes** or **Participant Notes** if necessary.
6. Select your **Participant Signature** and **Program Manager Signature**.
7. Review your information carefully and submit the form.

## Field-by-Field Explanation
* **Program Name** (Text, Required): Enter the name of the program.
* **Program Type** (Select Multiple, Optional): Select the type of program (Option 1, Option 2, Option 3).
* **Participant Name** (Text, Optional): Enter your name as a participant.
* **Participant Email** (Email, Optional): Enter your email address.
* **Participant Phone** (Text, Optional): Enter your phone number.
* **Participant Company** (Text, Optional): Enter your company name.
* **Program Status** (Select One, Optional): Select the status of the program (Active or Inactive).
* **Start Date** (Date, Optional): Enter the start date of the program.
* **End Date** (Date, Optional): Enter the end date of the program.
* **Time Zone** (Time, Optional): Select your time zone.
* **Participant Address** (Text, Optional): Enter your address.
* **Program Location** (Text, Optional): Enter the location of the program.
* **Notes** (Note, Optional): Add any additional notes about the program.
* **Participant Notes** (Note, Optional): Add any additional notes from the participant.
* **Participant Signature** (Select One, Optional): Select your signature option (Option 1, Option 2, Option 3).
* **Form Submission Date** (Date, Optional): This is the date and time when the form was submitted.
* **Form Submission Time** (Time, Optional): This is the time when the form was submitted.
* **Participant IP Address** (Text, Optional): Enter your IP address.
* **Participant User Agent** (Text, Optional): Enter your user agent.
* **Participant Accepts Terms** (Select One, Optional): Select whether you accept the terms (True or False).
* **Participant Agrees to Terms** (Select One, Optional): Select whether you agree to the terms (True or False).
* **Program Manager Notes** (Note, Optional): Add any additional notes from the program manager.
* **Participant Comments** (Text, Optional): Enter any comments from the participant.
* **Program Manager Comment** (Text, Optional): Enter any comments from the program manager.
* **Program Manager Signature** (Select One, Optional): Select the program manager's signature option (Option 1, Option 2, Option 3).

Note: The fields marked as "Optional" can be left blank if not applicable.
