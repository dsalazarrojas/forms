# CNC Project Registration Form - Help Guide
## Purpose
The CNC Project Registration Form is a crucial step in the CNC project registration process. It helps us gather essential information about your project, ensuring that we can provide you with the best possible service and outcome.

## How To Complete This Form
- Read the instructions carefully before starting the form.
- Make sure to fill out all required fields.
- Use a clear and concise format for your answers.
- Review the form before submitting it to ensure accuracy and completeness.

## Field-by-Field Explanation
### Page 1: Requester Information
* **Requester Name** (`requester_name`, `text`, required): Enter your full name as the requester.
* **Email Address** (`email_address`, `email`, required): Enter your email address to receive project updates.
* **Phone Number** (`phone_number`, `text`, required): Enter your best contact number.
* **Organization** (`organization`, `text`, required): Enter your company or institution name.

### Page 2: Project Information
* **Project Name** (`project_name`, `text`, required): Enter a name for your project.
* **Project Description** (`project_description`, `text`, required): Provide a brief overview of your project.
* **Project Type** (`project_type`, `select_one`, required): Select the category of your project (e.g., Prototype Development, Production Run, etc.).
* **Material Type** (`material_type`, `select_one`, required): Select the type of material to be machined (e.g., Aluminum, Steel, etc.).

### Page 3: Project Details
* **Material Specifications** (`material_specifications`, `text`, optional): Enter the grade or alloy of the material if applicable.
* **Part Dimensions** (`part_dimensions`, `text`, required): Enter the dimensions of the part.
* **Tolerance Requirements** (`tolerances_required`, `text`, required): Specify the precision requirements for the part.
* **Quantity Needed** (`quantity_needed`, `number`, required): Enter the number of parts required.

### Page 4: Project Resources
* **Design Files Status** (`design_files`, `select_one`, required): Indicate if you have CAD files or other design documents available.
* **Surface Finish Requirements** (`surface_finish`, `select_one`, required): Specify the desired finish quality for the part.
* **Secondary Operations Needed** (`secondary_operations`, `select_multiple`, required): Select any additional operations required for the part (e.g., Heat Treating, Hard Coating, etc.).
* **Quality Requirements** (`quality_requirements`, `select_one`, required): Specify the level of inspection required for the part (e.g., Standard Inspection, First Article Inspection, etc.).

### Page 5: Project Timeline
* **Budget Range** (`budget_range`, `select_one`, required): Estimate the budget for the project.
* **Project Deadline** (`deadline`, `date`, required): Enter the date by which you need the project completed.
* **Urgency Level** (`urgency_level`, `select_one`, required): Indicate the level of urgency for the project (e.g., Rush, High, Medium, etc.).

### Page 6: Additional Information
* **How Did You Hear About Us** (`how_did_you_hear`, `select_one`, optional): Specify how you became aware of our services.
* **Additional Requirements** (`additional_requirements`, `text`, optional): Enter any special requirements or needs for the project.
* **Additional Comments** (`additional_comments`, `text`, optional): Provide any other relevant information about the project.

Please note that all fields marked as "required" are mandatory and must be filled out accurately to ensure that we can provide you with the best possible service. If you have any questions or concerns, don't hesitate to reach out to us.
