# Recurring Appointment Confirmation Form - Help Guide

## Purpose
The recurring appointment confirmation form is used to confirm and set up recurring appointments with clients.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the required fields, which are marked with an asterisk (\*).
2. Enter the service provider's name and any relevant notes.
3. Choose the recurring type and frequency from the options provided.
4. Enter any additional appointment details and notes.
5. Confirm your email address and phone number (optional).

## Field-by-Field Explanation

* **Service Provider**: The service provider's name and any notes about the appointment.
* **Appointment Date**: The date of the appointment that you are confirming.
* **Appointment Time**: The time of the appointment that you are confirming.
* **Client Name**: The client's name who has the appointment.
* **Appointment Details**: Any additional details about the appointment, such as location or purpose.
* **Next Appointment Date**: The date of the next recurring appointment (optional).
* **Next Appointment Time**: The time of the next recurring appointment (optional).
* **Recurring Type**: The type of recurrence, such as weekly, bi-weekly, or monthly.
* **End Date**: The date to stop the recurring appointments (optional).
* **End Time**: The time to stop the recurring appointments (optional).
* **Recurring Frequency**: A text description of the recurrence frequency (optional).
* **Service Provider Notes**: Any notes about the service provider.
* **Client Notes**: Any notes about the client.
* **Email**: The service provider's email address (optional).
* **Phone**: The service provider's phone number (optional).

## Tips
- Make sure to fill in all required fields.
- If you need to add a new recurring appointment, create a new form submission.
- If you need to update an existing recurring appointment, use the "Next Appointment Date" field to reference the existing appointment.
