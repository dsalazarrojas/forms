# Group Selection Form - Help Guide
## Purpose
The Group Selection Form is a form for users to select attributes related to a group. It's used to configure group settings or preferences.

## How To Complete This Form
To complete this form, follow these steps:

1. Review each page of the form, as each one asks for different attributes.
2. For each field, select the relevant options that apply to your group.

## Field-by-Field Explanation
* **Group Selection** (`group_selection_form`, select_one): Select "Yes" if the group is selected, otherwise select "No".
* **Group Preferences** (`group_preferences`, select_multiple): Select all the preferences that apply to your group.
* **Availability** (`availability`, time): This field is not currently used in this form. It might be a placeholder for a future implementation.
* **Group Committees** (`group_committees`, select_multiple): Select all the committees that apply to your group.
* **Group Clubs** (`group_clubs`, select_multiple): Select all the clubs that apply to your group.

Note: The "Availability" field is not currently used, but it's included for future reference and potential expansion of this form.
