# E Lmis Registration Form - Help Guide
## Purpose
This form is used to register facilities with E Lmis. It captures essential details about the facility and its users.

## How To Complete This Form
To complete this form, please follow these steps:

1. Enter your ELMIS facility ID in the "ELMIS Facility ID" field.
2. Enter the facility name in the "Facility Name" field.
3. Select the "User Type" of the facility.
4. Enter the facility's email address and phone number.
5. Provide the facility's address and location.
6. Enter the facility's date and time of registration.
7. Enter any additional information about the facility.

## Field-by-Field Explanation

* **ELMIS Facility ID** (`1`, `text`, required): Enter your ELMIS facility ID.
* **Facility Name** (`2`, `text`, required): Enter the name of the facility.
* **User Type** (`3`, `select_one`, required): Select the type of user for the facility.
* **Facility Type** (`4`, `select_one`, required): Select the type of facility.
* **User Name** (`5`, `text`, required): Enter the name of the user.
* **User Email** (`6`, `email`, required): Enter the email address of the user.
* **Facility Email** (`7`, `email`, optional): Enter the email address of the facility (not required).
* **Facility Phone** (`8`, `text`, required): Enter the phone number of the facility.
* **Facility Location** (`9`, `text`, required): Enter the location of the facility.
* **Facility Address** (`10`, `text`, required): Enter the address of the facility.
* **Facility Postal Code** (`11`, `text`, required): Enter the postal code of the facility.
* **Facility Description** (`12`, `text`, optional): Enter any additional information about the facility (not required).
* **Facility Contact Person** (`13`, `text`, optional): Enter the name of the contact person (not required).
* **Facility Additional Info** (`14`, `text`, optional): Enter any additional information about the facility (not required).
* **Facility Status** (`15`, `text`, optional): Enter the status of the facility (not required).
* **Facility Date Registered** (`16`, `date`, required): Enter the date the facility was registered.
* **Facility Time Registered** (`17`, `time`, required): Enter the time the facility was registered.
* **Facility User Type** (`18`, `text`, optional): Enter the type of user for the facility (not required).
* **Facility User Name** (`19`, `text`, optional): Enter the name of the user (not required).
* **Facility User Email** (`20`, `email`, optional): Enter the email address of the user (not required).
* **Facility User Phone** (`21`, `text`, optional): Enter the phone number of the user (not required).
* **Facility User Location** (`22`, `text`, optional): Enter the location of the user (not required).
* **Facility User Address** (`23`, `text`, optional): Enter the address of the user (not required).
* **Facility User Postal Code** (`24`, `text`, optional): Enter the postal code of the user (not required).
* **Submit** (`25`, `text`, required): Click this button to submit the registration form.
