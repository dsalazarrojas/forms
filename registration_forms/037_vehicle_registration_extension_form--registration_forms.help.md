# vehicle_registration_extension_form - Help Guide

## Purpose
This form is used to collect information about a vehicle's registration extension, including details about the vehicle, driver, and extension status.

## How To Complete This Form

To complete this form, you will need to provide information about the vehicle and the driver. This includes:

*   Vehicle Registration Information (Page 1)
*   Driver Information (Page 2)
*   Vehicle License (Page 3)
*   Vehicle Mileage (Page 4)
*   Vehicle Mechanical Information (Page 5)
*   Driver Conduct (Page 6)
*   Vehicle Extension (Page 7)
*   Driver Conduct Agreement (Page 8)
*   Vehicle Extension Agreement (Page 9)
*   Vehicle Extension Details (Page 10)
*   Vehicle Extension Reason (Page 11)
*   Vehicle Extension Start Date (Page 12)
*   Vehicle Extension End Date (Page 13)
*   Vehicle Extension Period (Page 14)
*   Vehicle Extension Notes (Page 15)
*   Vehicle Extension Agreed (Page 16)
*   Vehicle Extension Date (Page 17)
*   Vehicle Extension Comments (Page 18)

## Field-by-Field Explanation

*   **Vehicle Registration Information (Vehicle Info, text, required)**: Enter the vehicle's registration information.
*   **Driver Information (Driver Info, text, required)**: Enter the driver's information.
*   **Vehicle License (Vehicle License, text, required)**: Enter the license number and issuing agency.
*   **Vehicle Mileage (Vehicle Mileage, number, required)**: Enter the current mileage of the vehicle.
*   **Vehicle Mechanical Info (Vehicle Mechanical Info, select_one, required)**: Choose the type of vehicle (New, Used, Lease, or Auction).
*   **Driver Conduct (Driver Conduct, select_multiple, required)**: Check if the vehicle has been involved in any accidents or incidents.
*   **Vehicle Extension (Vehicle Ext, select_one, required)**: Check if the vehicle is extended.
*   **Driver Conduct Agreement (Driver Conduct Agreement, select_one, required)**: Agree or disagree with the driver's conduct.
*   **Vehicle Extension Agreement (Vehicle Extension Agreement, select_one, required)**: Agree or disagree with the vehicle extension.
*   **Vehicle Extension Details (Vehicle Extension Details, text, required)**: Enter the details of the vehicle extension.
*   **Vehicle Extension Reason (Vehicle Extension Reason, text, required)**: Enter the reason for the vehicle extension.
*   **Vehicle Extension Start Date (Vehicle Extension Start Date, date, required)**: Enter the start date of the vehicle extension.
*   **Vehicle Extension End Date (Vehicle Extension End Date, date, required)**: Enter the end date of the vehicle extension.
*   **Vehicle Extension Period (Vehicle Extension Period, number, required)**: Enter the extension period in months.
*   **Vehicle Extension Notes (Vehicle Extension Notes, note, optional)**: Enter any additional notes about the vehicle extension.
*   **Vehicle Extension Agreed (Vehicle Extension Agreed, select_one, required)**: Check if the vehicle extension is agreed.
*   **Vehicle Extension Date (Vehicle Extension Date, date, required)**: Enter the date for the vehicle extension.
*   **Vehicle Extension Comments (Vehicle Extension Comments, text, optional)**: Enter any additional comments about the vehicle extension.

**Note:** All required fields are marked as required.

**Tips:** Please ensure that all required fields are filled in accurately and completely. If you are unsure about any information, please seek clarification from the relevant authorities.
