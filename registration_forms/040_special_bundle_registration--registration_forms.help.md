# Special Bundle Registration - Help Guide

## Purpose
This form is for registering a special bundle, which is a collection of related items or events. The purpose of this form is to gather information about the bundle, including its details and participants.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the required fields: First name, Last name, Email, Phone, Address, City, State, Zip, Date, Time, and Event info. These fields are marked as "required" and cannot be left blank.
2. Select the relevant options for Promotion type.
3. Add any additional information in the Additional info field.
4. Select the relevant options for Participant group and Participant status.
5. Enter the participant count.
6. Select the relevant options for Participant size.
7. Enter any participant notes, if necessary.
8. Select the relevant options for Participant status 2 (if applicable).
9. Enter the participant info.
10. Enter the participant count 2 (if applicable).
11. Select the relevant options for Event info (if applicable).

## Field-by-Field Explanation

* **First name** (`First name`, `text`, required): Enter your first name.
* **Last name** (`Last name`, `text`, required): Enter your last name.
* **Email** (`Email`, `email`, required): Enter your email address.
* **Phone** (`Phone`, `text`, required): Enter your phone number.
* **Address** (`Address`, `text`, required): Enter your address.
* **City** (`City`, `text`, required): Enter the city.
* **State** (`State`, `text`, required): Enter the state.
* **Zip** (`Zip`, `text`, required): Enter the zip code.
* **Date** (`Date`, `date`, required): Enter the date in the format MM/DD/YYYY.
* **Time** (`Time`, `time`, required): Enter the time in the format HH:MM:SS.
* **Additional info** (`Additional info`, `note`, optional): Enter any additional information about the bundle.
* **Promotion type** (`Promotion type`, `select_multiple`, required): Select the promotion type (Option A, Option B, or Option C).
* **Promo code** (`Promo code`, `text`, optional): Enter a promo code (if applicable).
* **Event info** (`Event info`, `text`, optional): Enter information about the event.
* **Participant info** (`Participant info`, `text`, required): Enter participant information.
* **Participant count** (`Participant count`, `number`, required): Enter the participant count.
* **Participant group** (`Participant group`, `select_one`, required): Select the participant group (Option 1, Option 2, or Option 3).
* **Participant size** (`Participant size`, `select_multiple`, required): Select the participant size (Option X, Option Y, or Option Z).
* **Participant status** (`Participant status`, `select_multiple`, required): Select the participant status (Option 1, Option 2, or Option 3).
* **Participant notes** (`Participant notes`, `text`, optional): Enter any participant notes.
* **Participant status 2** (`Participant status 2`, `select_multiple`, optional): Select the participant status 2 (Option A, Option B, or Option C).
* **Participant info** (`Participant info`, `text`, required): Enter participant information.
* **Participant count 2** (`Participant count 2`, `number`, optional): Enter the participant count 2.
* **Event info** (`Event info`, `text`, optional): Enter information about the event.
* **Participant status 3** (`Participant status 3`, `select_multiple`, optional): Select the participant status 3 (Option 1, Option 2, or Option 3).

Note: Some fields are marked as "optional" but are still required for a successful submission.
