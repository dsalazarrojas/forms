# Customer Registration Form - Help Guide
## Purpose
This form is used for customer registration, allowing customers to provide their details and interact with the loyalty program.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the customer's name in the "Customer Name" field.
2. Enter the customer's email address in the "Email" field.
3. Enter the customer's phone number in the "Phone" field.
4. Select the "Program Date" for the customer's program.
5. Select the "Program Start Date" for the customer's program.
6. Select the "Program End Date" for the customer's program.
7. Enter the customer's membership start date in the "Customer Since" field.
8. Enter the customer's loyalty program ID.
9. Choose the customer's rewards status.
10. Choose the rewards status for the customer's program.
11. Enter the points earned by the customer.
12. Enter the program points.
13. Enter the customer's rewards earned.
14. Enter the customer's program rewards balance.
15. Enter the customer's rewards status.
16. Enter the customer's program rewards balance.
17. Enter the customer's rewards earned.
18. Enter the customer's program rewards balance.
19. Enter the customer's notes.

* **Program Date** (`program_date`, Date, Required/Optional: Optional): Select the date for the customer's program.
* **Program Start Date** (`program_start_date`, Date, Required/Optional: Optional): Select the start date for the customer's program.
* **Program End Date** (`program_end_date`, Date, Required/Optional: Optional): Select the end date for the customer's program.
* **Customer Since** (`customer_since`, Date, Required/Optional: Optional): Enter the customer's membership start date.

* **Customer Rewards** (`customer_rewards`, Select Multiple, Required/Optional: Optional): Choose the rewards status for the customer's program.
* **Loyalty Program Status** (`loyalty_program_status`, Text, Required/Optional: Optional): Enter the customer's loyalty program status.
* **Program Rewards Status** (`program_rewards_status`, Text, Required/Optional: Optional): Enter the customer's program rewards status.
* **Program Rewards** (`program_rewards`, Select One, Required/Optional: Optional): Choose the rewards status for the customer's program.
* **Points Earned** (`points_earned`, Number, Required/Optional: Optional): Enter the customer's points earned.
* **Program Points** (`program_points`, Number, Required/Optional: Optional): Enter the customer's program points.
