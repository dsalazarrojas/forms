# pine_needles_registration_form - Help Guide
## Purpose
This form is used to collect registration information for participants.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the participant's information on the first page.
2. Select the type of pine needles the participant is registering for (if you want to).
3. Fill in the collection event and date (if you want to).
4. Enter the participant's email address (if you want to).
5. Fill in the participant's phone number (if you want to).
6. Click the "Submit" button to submit the form.

## Field-by-Field Explanation
- **Participant Information** (participant_information, text, optional): Enter the participant's details in this field. This is where you can add a brief description or any relevant information about the participant.
- **Pine Needles Type** (pine_needles_type, select_one, optional): Select the type of pine needles you are registering for from the options: Pine Needles - Green, Pine Needles - Yellow, or Pine Needles - Red.
- **Collection Event** (collection_event, text, optional): Describe the collection event that this registration is associated with.
- **Collection Event Date** (collection_event_date, date, optional): Enter the date of the collection event.
- **Participant Email** (participant_email, email, optional): Enter the participant's email address.
- **Participant Phone** (participant_phone, text, optional): Enter the participant's phone number.
- **Submit** (submit, text, optional): Click this button to submit the form.

## Tips
- Make sure to fill in all required fields correctly.
- You can leave optional fields blank if not applicable.
- Review the form before submitting to ensure accuracy.
