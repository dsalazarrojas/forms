# Enterprise Change Strategy Course Registration - Help Guide
## Purpose
This form is intended for participants to register for the Enterprise Change Strategy Course.

## How To Complete This Form
- Please fill out all the required fields (Participant Name, Email, Phone, Session Type, and Policy Agreement).
- You can enter any additional information in the Session Preferences Note field.
- If you have any dietary restrictions or special requests, please include them in the Session Preferences Note field.

## Field-by-Field Explanation
- **Participant Name**: <i>Participant Name</i> (Required)
    Enter the name of the participant registering for the course.
    - Example: John Doe
- **Email**: <i>Email</i> (Required)
    Enter a valid email address for the participant.
    - Example: johndoe@example.com
- **Phone**: <i>Phone</i> (Required)
    Enter the participant's phone number.
    - Example: 123-456-7890
- **Date**: <i>Date</i> (Optional)
    Enter the date of the session (if applicable).
- **Time**: <i>Time</i> (Optional)
    Enter the time of the session (if applicable).
- **Session Type**: <i>Session Type</i> (Required)
    Select one of the available session types (e.g., Session 1, Session 2, Session 3).
    - Example: Session 1
- **Session Date**: <i>Session Date</i> (Optional)
    Enter the date of the session (if applicable).
- **Session Time**: <i>Session Time</i> (Optional)
    Enter the time of the session (if applicable).
- **Policy Agreement**: <i>Policy Agreement</i> (Required)
    Select 'Yes' to agree to the course policies.
    - Example: 'Yes'
- **Terms and Conditions**: <i>Terms and Conditions</i> (Optional)
    Read and agree to the course terms and conditions.
    - This field is informational only and is not required.
- **Session Preferences Note**: <i>Session Preferences Note</i> (Optional)
    Enter any additional information about the participant's session preferences.

## Tips
- Please ensure that all required fields are completed before submitting the form.
- If you are unsure about any field, contact the course administrators for assistance.
- If you have any other questions or concerns, feel free to contact the course administrators.
