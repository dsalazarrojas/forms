# Open Source Curriculum Testing Registration - Help Guide
## Purpose
The Open Source Curriculum Testing Registration form is a tool used to collect feedback and validate the usability and relevance of our open-source curriculum.

## How To Complete This Form
1. Click on the "Registration Form" tab.
2. Enter your name and email address in the corresponding fields.
3. Enter your phone number and date of registration.
4. If you are taking the course, select one option from the "Select One" dropdown menu.
5. If you are registering multiple courses, select multiple options from the "Select Multiple" dropdown menu.
6. Enter your decimal value in the "Decimal" field.
7. Enter an integer value in the "Integer" field.
8. Select one integer option from the "Select One Integer" dropdown menu.
9. Select multiple integer options from the "Select Multiple Integer" dropdown menu.
10. Enter text information in the "Text" fields.
11. Select one text option from the "Select One Text" dropdown menu.
12. Enter date and time information in the "Date/Time" field.
13. Enter note information in the "Note" field.
