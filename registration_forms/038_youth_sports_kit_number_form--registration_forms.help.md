# Youth Sports Kit Number Form - Help Guide
## Purpose
The Youth Sports Kit Number Form is designed to collect and update information about a youth athlete's sports kit. Please use this form to provide accurate and up-to-date details about an athlete's kit number.

## How To Complete This Form
1. Make sure you have the correct athlete's information before filling out this form.
2. Review the form carefully before submitting to ensure all required fields are completed.
3. Follow the instructions for each field as outlined below.

## Field-by-Field Explanation
### Page 1: Youth Sports Kit Number
* **Youth Sports Kit Number** (`youth_sports_kit_number`, number, not required): Enter the youth sports kit number associated with the athlete.

### Page 2: Additional Kit Information
* **Sports Kit Number** (`youth_sports_kit_number_2`, text, not required): Enter any other relevant information about the kit number (e.g. kit serial number).
* **Athlete Name** (`athlete_name`, text, not required): Enter the name of the athlete associated with the kit.
* **Team Name** (`team_name`, text, not required): Enter the name of the team associated with the kit.
* **Sport Name** (`sport_name`, text, not required): Enter the name of the sport played with the kit.

### Page 3: Kit Details
* **Kit Size** (`kit_size`, select one, not required): Select the size of the sports kit:
	+ Small
	+ Medium
	+ Large
* **Kit Location** (`kit_location`, text, not required): Enter the location of the kit (e.g. locker room, equipment room).
* **Kit Status** (`kit_status`, select one, not required): Select the status of the kit:
	+ Available
	+ Allocated
	+ Reserved
	+ Lost
	+ Damaged
* **Kit Issue** (`kit_issue`, text, not required): Enter any issue or problem with the kit (e.g. damaged strap, missing parts).
* **Kit Comments** (`kit_comments`, text, not required): Enter any additional comments about the kit.

## Tips
- Please ensure that all fields are completed accurately to avoid errors.
- If you are unsure about any field, please contact the relevant staff member for guidance.
