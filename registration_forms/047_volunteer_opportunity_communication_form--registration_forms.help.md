# Volunteer Opportunity Communication Form - Help Guide
## Purpose
This form is used for registering and communicating opportunities for volunteers to join events, projects, or activities.

## How To Complete This Form
To use this form, follow the steps outlined above.

## Field-by-Field Explanation

* **Opportunity Id**: A unique identifier for the opportunity. This field is not required.
* **Opportunity Status**: The current status of the opportunity (Active, Closed, Completed, or Cancelled). This field is required.
* **Opportunity Tags**: Select all tags that apply to this opportunity. These tags help to categorize and filter opportunities. This field is required.
* **Opportunity Description**: A brief description of the opportunity. This field is not required.
* **Opportunity Start Date**: The date and time when the opportunity starts. This field is not required.
* **Opportunity End Date**: The date and time when the opportunity ends. This field is not required.
* **Opportunity Start Time**: The start time of the opportunity. This field is not required.
* **Opportunity End Time**: The end time of the opportunity. This field is not required.
* **Opportunity Location**: The location where the opportunity takes place. This field is not required.
* **Opportunity Priority**: The level of priority assigned to this opportunity. This field is not required.
* **Volunteer Name**: The name of the primary volunteer. This field is not required.
* **Volunteer Email**: The email of the primary volunteer. This field is not required.
* **Volunteer Phone**: The phone number of the primary volunteer. This field is not required.
* **Volunteer Name 2**: The name of the secondary volunteer. This field is not required.
* **Volunteer Email 2**: The email of the secondary volunteer. This field is not required.
* **Volunteer Phone 2**: The phone number of the secondary volunteer. This field is not required.
* **Volunteer Tags**: Select all tags that apply to this volunteer. These tags help to categorize and filter volunteers. This field is not required.
* **Assigned Tool**: The communication method used to assign to the volunteer (Chat, Email, SMS, or Voice). This field is required.
* **Contact Email**: The email of the contact person. This field is not required.
* **Contact Phone**: The phone number of the contact person. This field is not required.
* **Opportunity Priority**: The level of priority assigned to this opportunity. This field is not required.
* **Volunteer Priority**: The level of priority assigned to this volunteer. This field is not required.
* **Volunteer Manager Id**: The ID of the volunteer manager. This field is not required.
* **Created By**: The person who created the opportunity. This field is not required.
* **Modified By**: The person who last modified the opportunity. This field is not required.
* **Created At**: The date and time when the opportunity was created. This field is not required.
* **Updated At**: The date and time when the opportunity was last updated. This field is not required.
