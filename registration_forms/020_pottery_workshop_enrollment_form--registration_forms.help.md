# Pottery Workshop Enrollment Form - Help Guide
## Purpose
This form is used to register participants for the Pottery Workshop. Please fill in the form accurately to ensure you are registered for the correct sessions and can receive potential follow-up from the workshop organizers.

## How To Complete This Form

1.  Review each session time and select "Yes" if you are interested in attending that session.
2.  Enter your Participant Name in the provided text field.
3.  Enter your Contact E-mail address in the format of [your_email@example.com](https://example.com).
4.  Enter your Participant Phone number in the format of XXX-XXX-XXXX.
5.  If you have any additional information or comments, you can provide it in the Participant Note field.

## Field-by-Field Explanation

* **Session Time 1** (`session_time_1`, `select_one`, required/optional): Please select "Yes" if you would like to attend the first session, and "No" otherwise.
* **Session Time 2** (`session_time_2`, `select_one`, optional): Please select "Yes" if you would like to attend the second session, and "No" otherwise.
* **Session Time 3** (`session_time_3`, `select_one`, optional): Please select "Yes" if you would like to attend the third session, and "No" otherwise.
* **Participant Name** (`participant_name`, `text`, required): Enter your name as you would like to be referred to during the workshop.
* **Contact E-mail** (`contact_email`, `email`, required): Enter your email address in the format [your_email@example.com](https://example.com).
* **Participant Phone** (`participant_phone`, `text`, optional): Enter your phone number in the format XXX-XXX-XXXX.
* **Participant Note** (`participant_note`, `note`, optional): Provide any additional information or comments for the workshop organizers.

## Tips

* Please make sure to fill in all required fields (marked with *) to avoid any errors.
* If you are unsure about any of the session times or have any questions, please contact the workshop organizers.
