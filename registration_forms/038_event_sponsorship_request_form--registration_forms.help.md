# Event Sponsorship Request Form - Help Guide
## Purpose
The Event Sponsorship Request Form is designed to collect information from event organizers to request sponsorship for their events. Please review the form carefully and ensure that all required fields are completed accurately.

## How To Complete This Form
1. Review the form pages and determine which information applies to your event.
2. Enter the necessary information for each field.
3. Submit the form once you have completed all the required fields.

## Field-by-Field Explanation
* **Event Sponsorship Request Form (Page 1, Title)**: This is the title of the form, which should be filled with the name of your event.
* **Event Sponsorship Request Form (Page 1, Organization Name)**: Enter the name of your organization or company hosting the event.
* **Event Sponsorship Request Form (Page 1, Contact Person)**: Enter the name of the person responsible for the event.
* **Event Sponsorship Request Form (Page 1, Contact Email)**: Enter the email address of the person responsible for the event.
* **Event Sponsorship Request Form (Page 1, Phone)**: Enter the phone number of the person responsible for the event.
* **Event Sponsorship Request Form (Page 1, Event Date)**: Enter the date of the event.
* **Event Sponsorship Request Form (Page 1, Event Time)**: Enter the time of the event.
* **Event Sponsorship Request Form (Page 1, Organization Address)**: Enter the physical address of the event location.
* **Event Sponsorship Request Form (Page 1, Contact Person Email)**: Enter the email address of the person responsible for the event.
* **Event Sponsorship Request Form (Page 2)**: This page is left blank for potential additional details, please add any information that is not already covered on Page 1.

## Tips
* Ensure all required fields are completed accurately to avoid errors.
* If you are unsure about any field, contact the sponsor team for clarification.
* Please submit the form only once for each event.
