# Event Attendance Monitoring Form - Help Guide
## Purpose
The Event Attendance Monitoring Form is designed for event organizers or administrators to track attendee information, preferences, and other relevant details for events.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the relevant options for each form group on each page.
2. Enter any required text inputs, such as event titles and descriptions.
3. Enter dates and times as needed.
4. Input email addresses and phone numbers for each form group as required.
5. Review each page and ensure that all required fields are completed.

## Field-by-Field Explanation

* **Title** (`event_attendance_monitoring_form_first_page`): Enter a brief title for the event. This will be the title displayed on the form.
* **First Page Form Group** (`event_attendance_monitoring_first_page_form_group`): Select one or more options for this form group.
* **First Page Form Group Label** (`event_attendance_monitoring_first_page_form_group_label`): Enter a label for the selected form group option.
* **First Page Form Group Text Input** (`event_attendance_monitoring_first_page_form_group_text_input`): Enter any additional text information for this form group.
* **Second Page** (`event_attendance_monitoring_form_second_page`): Enter any event-specific information on this page.
* **Second Page Form Group** (`event_attendance_monitoring_form_second_page_form_group`): Select one option for this form group.
* **Second Page Form Group Label** (`event_attendance_monitoring_form_second_page_form_group_label`): Enter a label for the selected form group option.
* **Second Page Date Input** (`event_attendance_monitoring_form_second_page_date_input`): Enter the date of the event.
* **Second Page Time Input** (`event_attendance_monitoring_form_second_page_time_input`): Enter the time of the event.
* **Second Page Form Group Phone Input** (`event_attendance_monitoring_form_second_page_form_group_phone_input`): Enter a phone number for this form group.
* **Third Page** (`event_attendance_monitoring_form_third_page`): Enter any additional information on this page.
* **Third Page Form Group** (`event_attendance_monitoring_form_third_page_form_group`): Select one or more options for this form group.
* **Third Page Form Group Label** (`event_attendance_monitoring_form_third_page_form_group_label`): Enter a label for the selected form group option.
* **Third Page Form Group E-mail** (`event_attendance_monitoring_form_third_page_form_group_email_input`): Enter an email address for this form group.
* **Third Page Form Group Phone** (`event_attendance_monitoring_form_third_page_form_group_phone_input`): Enter a phone number for this form group.
* **Third Page Form Group Text Input** (`event_attendance_monitoring_form_third_page_form_group_text_input`): Enter any additional text information for this form group.
* **Third Page Form Group Note** (`event_attendance_monitoring_form_third_page_form_group_note_input`): Enter a note for this form group.
* **Third Page Form Group Decimal Input** (`event_attendance_monitoring_form_third_page_form_group_decimal_input`): Enter a decimal number for this form group.
* **Third Page Form Group Integer Input** (`event_attendance_monitoring_form_third_page_form_group_integer_input`): Enter an integer number for this form group.
* **Fourth Page** (`event_attendance_monitoring_form_fourth_page`): Enter any final information on this page.
* **Fourth Page Form Group** (`event_attendance_monitoring_form_fourth_page_form_group`): Select one or more options for this form group.
* **Fourth Page Form Group Label** (`event_attendance_monitoring_form_fourth_page_form_group_label`): Enter a label for the selected form group option.
* **Fourth Page Form Group Date Input** (`event_attendance_monitoring_form_fourth_page_form_group_date_input`): Enter a date for this form group.
* **Fourth Page Time Input** (`event_attendance_monitoring_form_fourth_page_time_input`): Enter a time for this form group.
* **Fourth Page Form Group Phone Input** (`event_attendance_monitoring_form_fourth_page_form_group_phone_input`): Enter a phone number for this form group.
* **Fourth Page Form Group E-mail** (`event_attendance_monitoring_form_fourth_page_form_group_email_input`): Enter an email address for this form group.
