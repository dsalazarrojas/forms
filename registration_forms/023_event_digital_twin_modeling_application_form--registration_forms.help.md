# Event Digital Twin Modeling Application Form - Help Guide
## Purpose
This form is used to collect information about an event's digital twin modeling application. It is used by the internal team to review and process event proposals.

## How To Complete This Form
To fill out this form, follow the instructions below:

1. Start by selecting the type of event you are proposing.
2. Enter the start and end dates of the event.
3. Provide the name of the organizer and the location of the event (if applicable).
4. Enter the expected number of attendees.
5. Enter the budget for the event.
6. Enter a brief description of the event.
7. If the event type is not found in the provided options, use the "Other Event Type" field to specify it.
8. Choose the category and subcategory of the event from the provided options.
9. Enter the time of the event (if applicable).
10. Select the status of the event from the provided options.
11. Enter the email and phone number of the contact person (if applicable).
12. Add any additional notes about the event.
13. Upload any relevant files or documents (if applicable).

## Field-by-Field Explanation
* **Event Type (id: 2)**: This field allows you to select the type of event you are proposing.
* **Start Date (id: 3)**: This field is used to enter the start date of the event.
* **End Date (id: 4)**: This field is used to enter the end date of the event.
* **Organizer (id: 5)**: This field is used to enter the name of the event's organizer.
* **Location (id: 6)**: This field is used to enter the location of the event (if applicable).
* **Attendees (id: 7)**: This field is used to enter the expected number of attendees.
* **Budget (id: 8)**: This field is used to enter the budget for the event.
* **Description (id: 9)**: This field is used to enter a brief description of the event.
* **Other Event Type (id: 10)**: This field is used to specify an event type that is not found in the provided options.
* **Event Category (id: 11)**: This field is used to select the category of the event from the provided options.
* **Event Sub Category (id: 12)**: This field is used to select the subcategory of the event from the provided options.
* **Time (id: 13)**: This field is used to enter the time of the event (if applicable).
* **Event Status (id: 14)**: This field is used to select the status of the event from the provided options.
* **Email (id: 15)**: This field is used to enter the email of the contact person (if applicable).
* **Phone (id: 16)**: This field is used to enter the phone number of the contact person (if applicable).
* **Notes (id: 17)**: This field is used to add any additional notes about the event.
* **File (id: 18)**: This field is used to upload any relevant files or documents (if applicable).
* **File 2 (id: 19)**: This field is used to upload any additional relevant files or documents (if applicable).
* **File 3 (id: 20)**: This field is used to upload any additional relevant files or documents (if applicable).

## Tips
- Please fill out the form accurately and thoroughly.
- Make sure to select the correct options for each field.
- Use the "Other Event Type" field if the event type is not found in the provided options.
- Use the "Event Category" and "Event Sub Category" fields to select the correct options for your event.
- Use the "Time" field to enter the time of the event (if applicable).
- Use the "Event Status" field to select the correct status of the event.
