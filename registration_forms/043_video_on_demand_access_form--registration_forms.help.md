# Video On Demand Access Form - Help Guide

## Purpose
The Video On Demand Access Form is a user-facing form designed to collect information from users who want to access video content on demand. This form ensures that users can access the content only once and verifies user identity.

## How To Complete This Form

1. Fill out the form with the required information.
2. Select the correct options for each field as needed.
3. Ensure that you provide the correct format for the date and time fields.
4. Provide a valid reason for accessing the content in the "Access Reason" field.

## Field-by-Field Explanation

* **User ID**: A unique identifier for the user.
* **User Email**: The email address associated with the user account.
* **User Phone**: The phone number associated with the user account.
* **Video On Demand Access Form**: This field is not applicable, as it is a label for the form.
* **Video On Demand Access Form**: This field is for users to confirm that they are accessing the content on demand. Select "Yes" if this is the case.
* **Video On Demand Access URL**: This field is not applicable, as it is not a field that the user needs to fill out.
* **Video On Demand Access Date**: The date on which the user wants to access the content. Ensure that the date is in the format YYYY-MM-DD.
* **Video On Demand Access Time**: The time on which the user wants to access the content. Ensure that the time is in the format HH:MM:SS.
* **Access Reason**: The reason why the user is accessing the content on demand. This field is optional but recommended to provide additional context.

## Tips
* Ensure that you provide accurate and correct information to ensure that your request for access is processed successfully.
