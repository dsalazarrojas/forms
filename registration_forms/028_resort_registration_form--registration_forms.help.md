# Resort Registration Form - Help Guide

## Purpose
The Resort Registration Form is a tool for event organizers to collect attendee information and event details.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out your first name and last name in the corresponding fields.
2. Enter your email address in the Email field.
3. Provide your phone number in the Phone field.
4. Select a date for the event in the Date field (YYYY-MM-DD format is recommended).
5. Enter the time of the event in the Time field.
6. Enter any additional notes about the event in the Notes field.
7. If applicable, select the event location from the dropdown menu.
8. Indicate whether an assigned user will be present at the event in the Assigned user field.
9. If applicable, select which tool will be assigned to the event in the Form assigned tool field.

## Field-by-Field Explanation

* **First name (Text)**: Enter your first name.
* **Last name (Text)**: Enter your last name.
* **Email (Email)**: Enter a valid email address that will be used to communicate with you.
* **Phone (Text)**: Enter your phone number.
* **Date (Date)**: Select the date of the event (YYYY-MM-DD format recommended).
* **Time (Time)**: Enter the time of the event.
* **Notes (Notes)**: Enter any additional comments or notes about the event.
* **Event date (Date)**: Select the date of the event.
* **Event time (Time)**: Enter the time of the event.
* **Event location (Select Multiple)**: Select the location where the event will take place.
* **Assigned user (Select One)**: Indicate whether an assigned user will be present at the event.
* **Form assigned tool (Select One)**: If applicable, select which tool will be assigned to the event.
