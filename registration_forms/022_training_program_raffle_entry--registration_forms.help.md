# training_program_raffle_entry - Help Guide
## Purpose
This form is used to create a new training program raffle entry.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out all the required fields, marked as *Required*.
2. Ensure that all fields have a valid value before submitting the form.
3. Review the form carefully before submitting it.

## Field-by-Field Explanation
- **Raffle Name** (`raffle_name`, text, *Required*): Enter the name of the raffle.
- **Organization** (`organization`, text, *Required*): Enter the name of the organization hosting the raffle.
- **Email** (`email`, email, *Required*): Enter the email of the person responsible for the raffle.
- **Contact Phone** (`contact_phone`, text, *Required*): Enter the phone number of the person responsible for the raffle.
- **Raffle Date** (`raffle_date`, date, *Required*): Enter the date of the raffle.
- **Raffle Time** (`raffle_time`, time, *Required*): Enter the time of the raffle.
- **Draw Date** (`draw_date`, date, *Required*): Enter the date of the draw.
- **Number of Entries** (`entry_count`, number, *Required*): Enter the number of entries in the raffle.
- **Prize** (`prize`, text, *Required*): Enter a brief description of the prize.
- **Details** (`details`, text, *Required*): Enter any additional details about the raffle.
- **Rules** (`rules`, text, *Required*): Enter the rules of the raffle.
- **Rules Text** (`rules_text`, text, *Optional*): Enter any additional text for the rules.
- **Terms** (`terms`, text, *Optional*): Enter any terms and conditions.
- **Terms Text** (`terms_text`, text, *Optional*): Enter any additional text for the terms.
