# Online Event Registration - Help Guide
## Purpose
This form is used to register and collect information for online events. The form is designed to gather essential details about the event, including its name, date, and time. This data will be used to manage event registrations and facilitate communication with attendees.

## How To Complete This Form
To complete this form, please follow these steps:

*   Enter the event details on the first page:
    *   Enter the event name in the text field provided.
    *   Enter the event date in the format YYYY-MM-DD.
    *   Enter the event time in 24-hour format.

## Field-by-Field Explanation

*   *Event Name* (`event_name`, `text`, required: false): Enter the name of the event.
*   *Event Date* (`event_date`, `date`, required: false): Enter the date of the event in the format YYYY-MM-DD.
*   *Event Time* (`event_time`, `time`, required: false): Enter the time of the event in 24-hour format.

## Tips

*   Please ensure that the date and time entered match the actual event schedule.
*   If you have any issues or concerns while filling out the form, please contact us at form@gic.mx.
