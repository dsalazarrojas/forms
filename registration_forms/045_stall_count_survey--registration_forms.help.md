# Stall Count Survey - Help Guide
## Purpose
The purpose of this form is to collect data on the number of stalls at a specific event and the total number of visitors.

## How To Complete This Form
To complete this form, follow the steps above in the "To Complete This Form" section.

## Field-by-Field Explanation
*   **Event Name** (Event Name, text, Required): The event name field is where you enter the name of the event. This field is required.
*   **Stall Count** (Stall Count, number, Optional): This field is where you enter the total number of stalls at the event. If an event has a large number of stalls, enter the correct number.
*   **Total Visitors** (Total Visitors, number, Optional): This field is where you enter the total number of visitors to the event. Enter the correct number of visitors for accurate data counting.
*   **Visitor Engagement** (Visitor Engagement, number, Optional): This field is where you enter a measure of visitor engagement at the event. This could be a subjective measure and can be used to evaluate the success of the event.
