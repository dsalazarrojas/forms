# League Signup Form Template - Help Guide

## Purpose
This form is designed to collect information from users interested in joining a league, such as sports teams, game tournaments, or online communities. The collected data will be used to manage league registrations and provide details to the organizers.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the required information, including the league name, event date, and event time.
2. Provide a brief description of the league.
3. Enter the event name and date in the respective fields.
4. Select the event date and time according to the options provided.

## Field-by-Field Explanation

* **League Name**: This field is where you enter the name of the league you are interested in joining. 
* **League Description**: This field is a brief description of the league, which will help others understand what the league is about.
* **Event Name**: This field is where you enter the name of the event that the league is associated with. 
* **Event Date**: This field is where you select the date of the event that the league is associated with. 
* **Event Time**: This field is where you select the time of the event that the league is associated with.

## Tips
* Make sure to fill in the required information accurately and completely.
* Double-check the event date and time before submitting the form.
* If you have any questions or concerns, contact form@gic.mx.
