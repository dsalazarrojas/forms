# Lease Renewal Event Registration - Help Guide
## Purpose
This form is designed to collect registration information for lease renewal events. Please complete this form to let us know you're interested in attending or participating in the event.

## How To Complete This Form
To complete this form, follow these steps:
1. Fill out the Event Details section with the necessary information.
2. Provide your contact information in the Contact Information section.
3. Choose your RSVP response in the RSVP section.
4. If you'd like to receive updates on this event, select one of the options in the Contact Preferences section.
5. If you have any feedback or suggestions, use the Questions section.
6. Finally, use the Notes section to add any additional comments or information.

## Field-by-Field Explanation
### 1. **Event Details** (`event_details`, `text`, required)
Provide a brief description of the event you're registering for.

### 2. **Contact Information** (`contact_info`, `text`, required)
Enter your name, email, and phone number separated by commas.

### 3. **RSVP** (`rsvp`, `select_multiple`, required)
Select your RSVP response: 
* RSVP Yes: You'll be attending the event.
* RSVP No: You won't be attending the event.
* Unable to Attend: You've been unable to attend.

### 4. **Contact Preferences** (`contact_preferences`, `select_one`, required)
Choose how you'd like to be contacted:
* Email: We'll contact you via email.
* Phone: We'll contact you via phone call.
* Both: We'll contact you both via email and phone.

### 5. **Would you like to receive updates on this event?** (`question_1`, `checkbox`, optional)
Check the box if you'd like to receive updates on this event.

### 6. **Would you like to provide feedback on this event?** (`question_2`, `checkbox`, optional)
Check the box if you'd like to provide feedback on this event.

### 7. **Would you like to suggest a new event topic?** (`question_3`, `checkbox`, optional)
Check the box if you'd like to suggest a new event topic.

### 8. **Notes** (`notes`, `text`, optional)
Add any additional comments or information here.
