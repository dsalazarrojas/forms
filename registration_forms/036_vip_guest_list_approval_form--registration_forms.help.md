# VIP Guest List Approval Form - Help Guide
## Purpose
The VIP Guest List Approval Form is used to collect and verify the information of VIP guests for an event.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the first name of the guest.
2. Enter the last name of the guest.
3. Enter the email address of the guest.
4. Enter the phone number of the guest.
5. Select the VIP Code that corresponds to the guest's status.
6. Select the event name that the guest will be attending.
7. Enter any special notes or instructions for the guest.
8. Choose the date of the event (optional).

## Field-by-Field Explanation
* **First Name** (1): Enter the first name of the guest.
* **Last Name** (2): Enter the last name of the guest.
* **Email** (3): Enter the email address of the guest.
* **Phone** (4): Enter the phone number of the guest.
* **Organization** (5): If the guest is representing an organization, enter the name of the organization (optional).
* **Title** (6): If the guest has a title or position, enter it here (optional).
* **VIP Code** (7): Select the code that corresponds to the guest's status (e.g. Code A, Code B, or Code C).
* **Event Name** (8): Select the name of the event that the guest will be attending (e.g. Event A, Event B, or Event C).
* **Special Notes** (9): Enter any special instructions or notes for the guest (optional).
* **Date** (10): Choose the date of the event (optional, but recommended for accurate guest tracking).
