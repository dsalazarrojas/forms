# Checkbook Register Form - Help Guide
## Purpose
The Checkbook Register Form is designed to provide a structured and organized way to record and update account information, including account holder details, transaction dates, amounts, and categories.

## How To Complete This Form
To complete this form, follow the steps outlined above.

## Field-by-Field Explanation

* **Account Holder Full Name**: Enter the account holder's full name.
* **Account Number (Last 4 Digits)**: Enter the account number's last 4 digits for tracking purposes.
* **Register Period Month**: Select the relevant month for the transaction from the dropdown menu.
* **Transaction Date**: Enter the date of the transaction.
* **Transaction Type**: Choose the type of transaction from the dropdown menu.
* **Check Number (if applicable)**: If this is a check transaction, enter the check number.
* **Description / Memo**: Enter a brief description or memo for the transaction.
* **Withdrawal (-) / Payment Amount ($)**: If the transaction is a withdrawal or payment, enter the amount.
* **Deposit (+) / Credit Amount ($)**: If the transaction is a deposit or credit, enter the amount.
* **Is this transaction tax deductible**: Check if the transaction is tax deductible.
* **Expense / Income Category**: Choose the relevant category for the transaction from the dropdown menu.
* **Updated Running Balance ($)**: If you want to update the running balance manually, enter the new balance.
* **Additional Notes**: Optionally, add additional notes about the transaction.
