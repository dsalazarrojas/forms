# Counseling Skills Workshop Enrollment Form - Help Guide
## Purpose
The purpose of this form is to collect information from users enrolling in the Counseling Skills Workshop.

## How To Complete This Form
1. Fill out the form in the spaces provided, following the guidelines below.
2. Double-check that all required fields are completed accurately and thoroughly.
3. Make sure to select the correct payment method and enrollment date/time.

## Field-by-Field Explanation

* **Enrollment Workshop Title** (`workshop_title`, text, required/optional):
This field is where you can enter a brief description or title of the workshop you are enrolling in. Enter any relevant details that will help us understand which workshop you are registering for.
* **Participant First Name** (`first_name`, text, required/optional):
Enter the first name of the participant enrolling.
* **Participant Last Name** (`last_name`, text, required/optional):
Enter the last name of the participant enrolling.
* **Participant Email** (`email`, email, required/optional):
Enter the email address of the participant enrolling. This will be used for correspondence regarding the workshop.
* **Participant Phone** (`phone`, text, required/optional):
Enter the participant's phone number. This can be used for further communication if necessary.
* **Participant Address** (`address`, text, required/optional):
Enter the participant's address. This can be used for further communication if necessary.
* **Enrollment Date** (`workshop_date`, date, required/optional):
Enter the date you are enrolling for the workshop.
* **Enrollment Time** (`workshop_time`, time, required/optional):
Enter the time you are enrolling for the workshop.
* **Payment Method** (`payment_method`, select_one, required/optional):
Select one of the following options for payment:
	+ Check
	+ Credit Card
	+ Online Payment

## Tips
- Please fill out the form accurately and thoroughly.
- Double-check the form for any errors before submission.
- Make sure to select the correct payment method and enrollment date/time.
- If you have any questions, please do not hesitate to contact us.
