# Team Recognition Event Registration Form - Help Guide
## Purpose
This form is designed to collect information about upcoming team recognition events. Please fill it out carefully to ensure accurate and complete data.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the required fields:
	* Team Name: Enter the name of the team participating in the event.
	* Event Date: Enter the date of the event.
	* Event Organizer: Enter the name of the person or organization responsible for the event.
	* Contact Person: Select the contact person for the event (Yes or No).
	* Event Type: Select the type of event (Yes or No).
	* Start Time: Enter the start time of the event.
	* End Time: Enter the end time of the event.
	* Venue: Enter the location of the event.
	* Event Status: Select the status of the event (Active or Inactive).
	* RSVP By: Enter the date by which RSVPs are required.
	* RSVP Status: Select the RSVP status (Active or Inactive).
2. Optional fields:
	* Team Members: Select the members of the team participating in the event.
	* Event Description: Provide a brief description of the event.
	* Event Comments: Add any additional comments about the event.

## Field-by-Field Explanation

* **Team Name** (`team_name`, required): Enter the name of the team participating in the event.
* **Event Date** (`event_date`, required): Enter the date of the event in the correct format (YYYY-MM-DD).
* **Team Members** (`team_members`, required): Select each team member attending the event (Yes or No).
* **Event Organizer** (`event_organizer`, required): Enter the name of the person or organization responsible for the event.
* **Contact Person** (`contact_person`, required): Select the contact person for the event (Yes or No).
* **Event Type** (`event_type`, required): Select the type of event (Yes or No).
* **Start Time** (`start_time`, required): Enter the start time of the event in the correct format (HH:MM).
* **End Time** (`end_time`, required): Enter the end time of the event in the correct format (HH:MM).
* **Venue** (`venue`, required): Enter the location of the event.
* **Event Status** (`event_status`, required): Select the status of the event (Active or Inactive).
* **RSVP By** (`rsvp_by`, required): Enter the date by which RSVPs are required.
* **RSVP Status** (`rsvp_status`, required): Select the RSVP status (Active or Inactive).
* **Event Comments** (`event_comments`, optional): Provide any additional comments about the event.
* **Event Description** (`event_description`, optional): Add a brief description of the event.

## Tips
* Make sure to fill in all required fields accurately and completely.
* Be precise when entering dates and times.
* If unsure about any field, please contact the event organizer or team lead.
* This form is for internal use only. Any sensitive or confidential information should not be shared.
