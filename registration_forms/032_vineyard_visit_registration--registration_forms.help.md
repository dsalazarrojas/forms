# Vineyard Visit Registration - Help Guide
## Purpose
This form is designed to collect visitor information and tour preferences for a vineyard visit.

## How To Complete This Form
To complete this form, please follow these steps:

1.  Fill out the fields in the order they appear.
2.  Select the correct options from the drop-down menus.
3.  Ensure all required fields are completed.

## Field-by-Field Explanation

*  **User Details** (`user_details`, text, optional):
    This field is for you to enter your name and any other details you would like to share with us.
*  **Tour Preferences** (`tour_preferences`, select_multiple, optional):
    Select one or more of the following tour types:
    •   Walking Tour
    •   Guided Tour
    •   Tasting Tour
*  **Guest Details** (`guest_details`, text, optional):
    If you are visiting with others, please provide their names and contact information here.
*  **Special Requests** (`special_requests`, note, optional):
    If you have any special requests or requirements, please let us know here.
*  **Submit** (`submit`, select_one, required):
    Select this option to submit your completed form.
*  **Tour Type** (`tour_type`, select_one, optional):
    Select a tour type:
    •   Tour
    •   Tasting
*  **Preferred Time** (`preferred_time`, time, optional):
    If you have a preferred time for your tour, please enter it here.
*  **Email** (`email`, email, optional):
    This field is for you to enter your email address so we can contact you.

## Tips
Please review each field carefully before proceeding to ensure accurate information. If you have any questions or concerns, please contact us at form@gic.mx.
