# learning_center_registration_form - Help Guide
## Purpose
This form is used to register new learners with a learning center, providing essential information for effective management and communication.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the name of the new learner in the **New Learner** field.
2. Provide the contact person's name in the **Contact Person** field.
3. Enter the contact person's email address in the **Email** field.
4. Provide the contact person's phone number in the **Phone** field.
5. Select the learning center from the list in the **Learning Center** field.
6. Choose the student program(s) from the list in the **Student Program** field (e.g., High School, College, University).
7. Enter the student's grade (if applicable) in the **Student Grade** field.
8. Enter the learning level in the **Learning Level** field.
9. Select the start date for the learner's program in the **Start Date** field.
10. Select the end date for the learner's program in the **End Date** field.

## Field-by-Field Explanation
### New Learner (id: 1)
- **New Learner**: Enter the name of the new learner.
### Contact Person (id: 2)
- **Contact Person**: Provide the name of the contact person for the learner.
### Email (id: 3)
- **Email**: Enter the contact person's email address.
### Phone (id: 4)
- **Phone**: Provide the contact person's phone number.
### Learning Center (id: 5)
- **Learning Center**: Select the learning center from the list provided.
### Student Program (id: 6)
- **Student Program**: Choose one or multiple student programs (e.g., High School, College, University).
### Student Grade (id: 7)
- **Student Grade**: Enter the student's grade level (if applicable).
### Learning Level (id: 8)
- **Learning Level**: Enter the learning level of the student.
### Start Date (id: 9)
- **Start Date**: Select the start date for the learner's program.
### End Date (id: 10)
- **End Date**: Select the end date for the learner's program.

## Tips
- Please make sure to fill out the form accurately and completely.
- If you are unsure about any field, refer to the field-by-field explanation above.
- If you have any questions or need assistance, please contact the learning center administration.
