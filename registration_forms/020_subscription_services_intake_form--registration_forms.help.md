# Subscription Services Intake Form - Help Guide

## Purpose
The "Subscription Services Intake Form" is used to collect information about subscription services, including company details, service types, contact information, billing cycles, and payment gateways.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the company name and service type in the respective fields.
2. Provide the contact name and email address.
3. Fill in the service start and end dates, billing cycle, and billing frequency.
4. Select the payment gateway and enter the payment gateway ID (if applicable).
5. Choose the billing status and subscription status.
6. Enter the subscription start and end dates.
7. Provide any additional information, such as subscription type and frequency.

## Field-by-Field Explanation
### Company Name
* **company name**: This field is used to enter the company name associated with the subscription service.
*   *Type:* `text`, *Required*: False*

### Service Type
* **service type**: Enter the type of service being subscribed to.
*   *Type*: `text`, *Required*: False*

### Contact Name
* **contact name**: Enter the name of the contact person.
*   *Type*: `text`, *Required*: False*

### Email
* **email**: Enter the contact email address.
*   *Type*: `email`, *Required*: False

### Phone
* **phone**: Enter the phone number.
*   *Type*: `text`, *Required*: False

### Service Start Date
* **service start date**: Enter the date the service started.
*   *Type*: `date`, *Required*: False

### Service End Date
* **service end date**: Enter the date the service will end.
*   *Type*: `date`, *Required*: False

### Billing Cycle
* **billing cycle**: Enter the billing cycle frequency.
*   *Type*: `text`, *Required*: False

### Billing Frequency
* **billing frequency**: Enter the frequency of billing.
*   *Type*: `text`, *Required*: False

### Payment Gateway
* **payment gateway**: Enter the payment gateway used for the service.
*   *Type*: `text`, *Required*: False

### Payment Gateway ID
* **payment gateway id**: Enter the ID of the payment gateway (if applicable).
*   *Type*: `text`, *Required*: False

### Billing Status
* **billing status**: Select the status of the billing cycle.
*   *Type*: `select_one`, *Required*: False

### Billing Start Date
* **billing start date**: Enter the start date of the billing cycle.
*   *Type*: `date`, *Required*: False

### Billing End Date
* **billing end date**: Enter the end date of the billing cycle.
*   *Type*: `date`, *Required*: False

### Payment Gateway 2
* **payment gateway 2**: Enter the second payment gateway used for the service.
*   *Type*: `text`, *Required*: False

### Payment Method
* **payment method**: Enter the payment method used for the service.
*   *Type*: `text`, *Required*: False

### Subscription Start Date
* **subscription start date**: Enter the start date of the subscription.
*   *Type*: `date`, *Required*: False

### Subscription End Date
* **subscription end date**: Enter the end date of the subscription.
*   *Type*: `date`, *Required*: False

### Subscription Status
* **subscription status**: Select the status of the subscription.
*   *Type*: `select_multiple`, *Required*: False

### Subscription Type
* **subscription type**: Enter the type of subscription.
*   *Type*: `text`, *Required*: False

### Subscription Frequency
* **subscription frequency**: Enter the frequency of subscription.
*   *Type*: `text`, *Required*: False

## Tips

*   Ensure you fill out all required fields accurately.
*   Double-check your entries before submitting the form.
*   If you have any questions or concerns, contact your administrator.
*   This form is for authorized personnel only.
