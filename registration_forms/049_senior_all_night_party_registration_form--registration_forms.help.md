# Senior All Night Party Registration Form - Help Guide
## Purpose
The Senior All Night Party Registration Form is a tool used to gather information from senior citizens who wish to participate in an All Night Party event. The form helps to ensure that all necessary details are captured in one place.

## How To Complete This Form

To complete this form, follow these steps:

* Select the event ID to associate this registration with a specific event.
* Enter your name as required.
* Provide your phone number for easy contact purposes.
* Choose if you will be attending the event by selecting "Yes" or "No".
* Add any guest details if you are bringing someone along.
* Enter your contact email address.
* Provide a brief description of the event.
* Specify the number of attendees you will be bringing.
* Choose the RSVP date.
* Select the start and end time of the event.
* Enter the address of the event.
* Write a brief description of the event.
* Specify the venue of the event.
* Enter the date and start/end time of the event.
* Specify the number of attendees.
* Choose the status of the event (Active, Inactive, or Deleted).
* Add any notes about the event.

## Field-by-Field Explanation

* **Event Id (Select One)**: Choose the event ID associated with this registration.
* **Name (Text)**: Enter your name for contact purposes.
* **Phone (Text)**: Provide your phone number for easy contact.
* **RSVP (Select Multiple)**: Choose "Yes" if you will be attending the event, "No" otherwise.
* **Guest Details (Note)**: Add any guest details if you are bringing someone along.
* **Contact (Email)**: Enter your email address for further contact.
* **Event Details (Text)**: Provide a brief description of the event.
* **Attendees (Number)**: Specify the number of attendees you will be bringing.
* **RSVP Date (Date)**: Choose the date you RSVP.
* **Start Time (Time)**: Select the start time of the event.
* **End Time (Time)**: Select the end time of the event.
* **Address (Text)**: Enter the address of the event venue.
* **Event Description (Text)**: Write a brief description of the event.
* **Venue (Text)**: Specify the venue of the event.
* **Event Date (Date)**: Choose the date of the event.
* **Event Start Time (Time)**: Select the start time of the event.
* **Event End Time (Time)**: Select the end time of the event.
* **Attendees Count (Number)**: Specify the number of attendees.
* **Created By (Text)**: This field is not editable and displays the username of the user who created this event.
* **Updated By (Text)**: This field is not editable and displays the username of the user who updated this event.
* **Created At (Date)**: This field displays the date and time the event was created.
* **Updated At (Date)**: This field displays the date and time the event was last updated.
* **Status (Select One)**: Choose the status of the event (Active, Inactive, or Deleted).
* **Notes (Note)**: Add any notes about the event.
