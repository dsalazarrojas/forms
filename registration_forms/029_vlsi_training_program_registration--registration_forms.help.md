# VLSI Training Program Registration - Help Guide
## Purpose
The VLSI Training Program Registration form is designed to gather information from participants for the VLSI training program. This includes details about the participant's information, session preferences, and other essential data.

## How To Complete This Form
To complete this form, follow these steps:

*   Start by selecting the "User Information" page.
*   Enter the participant's User ID, if provided.
*   Select the correct date for the session from the calendar.
*   Choose the time slot for the session.
*   Enter the course location.
*   Enter the session duration.
*   In the "Participant Preferences" field, type a brief description of the participant's expectations or requirements.
*   In the "Participant Mission" field, type a brief description of the participant's mission or objective for the session.
*   For the "Session Preferences" field, select "Yes" or "No" to indicate whether the participant has any preferences for the session.
*   In the "Session Preferences 2" field, select one or more options that apply to the participant's session preferences.
*   Finally, in the "Participant Details" field, enter any additional information about the participant.

## Field-by-Field Explanation
*   **User Information (<type> text, <required> false)**: Enter the participant's User ID or any other relevant information.
*   **Session Date (<type> date, <required> false)**: Choose the date for the session by selecting a date from the calendar.
*   **Session Time (<type> time, <required> false)**: Select the time slot for the session.
*   **Course Location (<type> text, <required> false)**: Enter the location of the session.
*   **Session Duration (<type> number, <required> false)**: Enter the length of the session in hours or minutes.
*   **Participant Preferences (<type> text, <required> false)**: Type a brief description of the participant's expectations or requirements.
*   **Participant Mission (<type> text, <required> false)**: Type a brief description of the participant's mission or objective for the session.
*   **Session Preferences (<type> select_one, <required> false)**: Select "Yes" or "No" to indicate whether the participant has any preferences for the session.
*   **Session Preferences 2 (<type> select_multiple, <required> false)**: Select one or more options that apply to the participant's session preferences.
*   **Participant Details (<type> text, <required> false)**: Enter any additional information about the participant.
