# Win Event Tickets - Help Guide
## Purpose
The purpose of this form is to create a new win event ticket, providing details such as event organizers, ticket name, dates, price, quantity, availability, description, image, and URL.

## How To Complete This Form
To complete this form, please follow the steps below:

1. Fill in the required fields with accurate information.
2. Ensure that you only fill in the relevant fields with the information you have.
3. If a field is not required, you can leave it empty.

## Field-by-Field Explanation
* **Event Organizers** (`event_organizer`, `text`, required: false): Enter the name of the event organizer.
* **Event Name** (`ticket_name`, `text`, required: false): Enter the name of the event ticket.
* **Ticket Start Date** (`ticket_start`, `date`, required: false): Enter the start date of the event ticket.
* **Ticket End Date** (`ticket_end`, `date`, required: false): Enter the end date of the event ticket.
* **Ticket Price** (`ticket_price`, `number`, required: false): Enter the price of the ticket.
* **Ticket Quantity** (`ticket_quantity`, `number`, required: false): Enter the number of tickets available for the event.
* **Ticket Availability** (`ticket_availability`, `text`, required: false): Enter any additional information about the ticket availability.
* **Ticket Description** (`ticket_description`, `text`, required: false): Enter a brief description of the event ticket.
* **Ticket Image** (`ticket_image`, `text`, required: false): Enter the name of the ticket image file.
* **Ticket Image URL** (`ticket_image_url`, `text`, required: false): Enter the URL of the ticket image.
* **Ticket URL** (`ticket_url`, `text`, required: false): Enter the URL associated with the ticket.

## Tips
* Double-check the required fields before submitting the form.
* Ensure that the information is accurate and up-to-date.
* If you're unsure about any field, please contact your administrator for assistance.
