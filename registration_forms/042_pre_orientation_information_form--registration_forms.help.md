# Pre-Orientation Information Form - Help Guide
## Purpose
The Pre-Orientation Information Form is used to collect information about new students and their emergency contacts before they enter the institution.

## How To Complete This Form
To complete this form, follow these steps:

1. Please fill out all the required fields.
2. Use the correct format for date fields (mm/dd/yyyy).
3. For select_one fields, select only one option from the list.
4. Enter a valid email address in the email fields.
5. Fill out all fields accurately and consistently.

## Field-by-Field Explanation

* **New Student Information (`new_student`, text, required/optional):** Enter the name of the new student.
* **Student ID (`student_id`, number, required/optional):** Enter the student's ID number.
* **Student Name (`student_name`, text, required/optional):** Enter the student's name.
* **Date of Birth (`date_of_birth`, date, required/optional):** Enter the student's date of birth in mm/dd/yyyy format.
* **Address (`address`, text, required/optional):** Enter the student's address.
* **Contact Number (`contact_number`, text, required/optional):** Enter the student's contact number.
* **Email (`email`, email, required/optional):** Enter the student's email address.
* **Parent Name (`parent_name`, text, required/optional):** Enter the parent's name if applicable.
* **Parent Contact Number (`parent_contact_number`, text, required/optional):** Enter the parent's contact number if applicable.
* **Parent Email (`parent_email`, email, required/optional):** Enter the parent's email address if applicable.
* **Emergency Contact Name (`emergency_contact_name`, text, required/optional):** Enter the emergency contact's name.
* **Emergency Contact Number (`emergency_contact_number`, text, required/optional):** Enter the emergency contact's number.
* **Emergency Contact Relation (`emergency_contact_relation`, select_one, required/optional):** Select the relation of the emergency contact from the list (Mother, Father, Brother, Sister, Friend, Other).
* **Emergency Contact Relation Other (`emergency_contact_relation_other`, text, required/optional):** Enter any other relation not listed.
* **Alternate Emergency Contact Number (`emergency_contact_alternate_number`, text, required/optional):** Enter an alternate emergency contact number.
* **Student Status (`student_status`, select_one, required/optional):** Select the student's status from the list (Student, Employee, Parent, Other).
* **Student Start Date (`student_start_date`, date, required/optional):** Enter the student's start date.
* **Student End Date (`student_end_date`, date, required/optional):** Enter the student's end date.
* **Parent Status (`parent_status`, select_one, required/optional):** Select the parent's status from the list (Active, Inactive).
* **Parent Start Date (`parent_start_date`, date, required/optional):** Enter the parent's start date.
* **Parent End Date (`parent_end_date`, date, required/optional):** Enter the parent's end date.
* **Emergency Contact Address (`emergency_contact_address`, text, required/optional):** Enter the emergency contact's address.
* **Emergency Contact Phone (`emergency_contact_phone`, text, required/optional):** Enter the emergency contact's phone number.
* **Emergency Contact Email (`emergency_contact_email`, email, required/optional):** Enter the emergency contact's email address.
* **Emergency Contact Other (`emergency_contact_other`, text, required/optional):** Enter any other emergency contact information.
