# eviction_intake_form - Help Guide
## Purpose
The Eviction Intake Form is designed to collect information from tenants about the reasons for eviction. This form will be used to determine the eligibility status of the tenant and gather details about the property and tenant involved.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill out the form completely and accurately.
2. Ensure that all fields are filled out with the most up-to-date information.
3. If you are unsure about any field, please ask for clarification before proceeding.

## Field-by-Field Explanation
* **Tenant Info** (`tenant_info`, text, required/optional): This field is used to collect the basic information about the tenant.
* **Reason for Eviction** (`reason_for_eviction`, text, required/optional): This field is used to provide the reason for the eviction.
* **Reason Date** (`reason_date`, date, required/optional): This field is used to provide the date of the reason for eviction.
* **Tenant Status** (`tenant_status`, select_one, required): This field is used to determine the eligibility status of the tenant. Please select one of the following options:
	+ Eligible
	+ Not Eligible
* **Reason** (`reason`, text, required/optional): This field is used to provide any additional information about the reason for eviction.
* **Tenant Name** (`tenant_name`, text, required/optional): This field is used to collect the name of the tenant.
* **Property Owner** (`property_owner`, text, required/optional): This field is used to collect the name of the property owner.
* **Property Address** (`property_address`, text, required/optional): This field is used to collect the address of the property.

## Tips
* Please ensure that all information provided is accurate and up-to-date.
* If you are unsure about any field, please ask for clarification before proceeding.
* This form will only be used for the purpose of determining the tenant's eligibility status.
* The completion of this form is mandatory to proceed with the eligibility determination process.
