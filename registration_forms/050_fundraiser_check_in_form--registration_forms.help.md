> # Fundraiser Check In Form - Help Guide
## Purpose
The Fundraiser Check In Form is designed to collect information from attendees, organizers, and speakers at various events, such as fundraisers, events, and registrations.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the required fields, marked with an asterisk (\*). The form will guide you through the process.
2. Enter your name, organization (if applicable), contact phone number, and email address.
3. Select your role in the event (Attendee, Organizer, or Speaker).
4. Enter the event start time and date.
5. Enter the name of the fundraiser you are associated with.
6. Enter the name of the event.
7. Add any additional notes about the event (optional).
8. Select the relevant event category (Fundraiser, Event, or Registration).
9. Select the relevant form type (Fundraiser, Event, or Registration).
10. Select the tool assigned to you (chatjimmy, chatjimmy2, or chatjimmy3).
11. Select the form ID (optional).
12. Select the output file to generate (050 fundraiser check in form--registration forms, 050 fundraiser check in form--forms, or 050 fundraiser check in form--forms 2).
13. Select the output file path (path/to/output1, path/to/output2, or path/to/output3).
14. Click the "Submit" button to finalize your entry.

## Field-by-Field Explanation
* **Name**: Enter your name.
* **Organization**: Enter your organization's name (if applicable).
* **Contact Phone**: Enter your contact phone number.
* **Email**: Enter your email address.
* **Role**: Select your role in the event (Attendee, Organizer, or Speaker).
* **Time**: Enter the event start time.
* **Date**: Enter the event start date.
* **Fundraiser**: Enter the name of the fundraiser you are associated with.
* **Event**: Enter the name of the event.
* **Notes**: Add any additional notes about the event (optional).
* **Event Category**: Select the relevant event category (Fundraiser, Event, or Registration).
* **Form**: Select the relevant form type (Fundraiser, Event, or Registration).
* **Assigned Tool**: Select the tool assigned to you (chatjimmy, chatjimmy2, or chatjimmy3).
* **Form ID**: Select a form ID (optional).
* **Output File**: Select the output file to generate (050 fundraiser check in form--registration forms, 050 fundraiser check in form--forms, or 050 fundraiser check in form--forms 2).
* **Output File Path**: Select the output file path (path/to/output1, path/to/output2, or path/to/output3).
* **Submit**: Click this button to finalize your entry.
