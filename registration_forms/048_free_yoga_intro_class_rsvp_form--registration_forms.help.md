# Free Yoga Intro Class RSVP Form - Help Guide
## Purpose
This form is used to register for a free yoga intro class. It is designed to collect basic contact information and class preferences from interested participants.

## How To Complete This Form

To complete this form, follow these steps:

1. Provide your basic contact information in the **Contact Fields** field.
2. Select your class preferences in the **Class Fields** field.
3. Provide any additional class preferences or comments in the **RSVP Fields** field.
4. If you have any further comments or questions, use the **RSVP Fields 2** field.

## Field-by-Field Explanation

* **RSVP Fields** (`rsvp_fields`, text, required): Please provide your basic contact information, including name, email, and phone number.
* **Contact Fields** (`contact_fields`, text, optional): If you have any other contact information you'd like to share, such as a social media handle or website, you can enter it here.
* **Class Fields** (`class_fields`, text, required): Please select which yoga class you are interested in attending.
* **RSVP Fields 2** (`rsvp_fields_2`, text, optional): If you have any additional comments or questions, please provide them here.

**Tips**

* Make sure to enter your correct contact information so that we can follow up with you after the class.
* If you are unsure about which class to choose, please don't hesitate to ask and we will be happy to help.
