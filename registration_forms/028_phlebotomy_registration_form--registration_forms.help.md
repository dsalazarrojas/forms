# Phlebotomy Registration Form - Help Guide
## Purpose
The Phlebotomy Registration Form is designed to collect information from users for the purpose of registration. This form is used to gather basic contact information, course preferences, and resource details to facilitate efficient and effective communication.

## How To Complete This Form
To complete the form, follow these steps:

1. Provide your first name in the "First Name" field.
2. Enter your last name in the "Last Name" field.
3. Enter your email address in the "Email" field. Please ensure it is a valid email address.
4. Add your phone number in the "Phone" field, if applicable.
5. Select the course you are interested in from the "Course" dropdown menu.
6. Choose the resource type(s) that apply to you from the "Resource Type" dropdown menu. You can select multiple resources if necessary.
7. If you have an ID related to the resource you selected, enter it in the "Resource ID" field.

## Field-by-Field Explanation

* **First Name (text, required: no)**: Please enter your first name as it should be used for official purposes.
* **Last Name (text, required: no)**: Enter your last name as it should be used for official purposes.
* **Email (email, required: yes)**: Enter a valid email address to ensure you can receive updates and notifications.
* **Phone (text, required: no)**: Enter your phone number if you would like to be contacted by phone.
* **Course (select_one, required: no)**: Select the course you are interested in from the list provided.
* **Resource Type (select_multiple, required: no)**: Choose the resource type that applies to you from the list provided. You can select multiple resources if necessary.
* **Resource ID (number, required: no)**: If you have an ID related to the resource you selected, enter it here.
