# R&D Program Subscription Form - Help Guide
## Purpose
This form is used to register users in the R&D program for the company.

## How To Complete This Form
To complete this form, simply fill in the required information and select your preferred options. If you're unsure about any field, please refer to the "Field-by-Field Explanation" section below.

## Field-by-Field Explanation

* **User Name** (`user_name`, text, optional): Enter your name as it appears on your ID or official documents.
* **Email** (`email`, email, optional): Enter your official email address associated with your company ID.
* **Phone** (`phone`, text, optional): Enter your contact phone number for any additional inquiries or updates.
* **Department** (`department`, text, optional): Select the department you belong to in the company.
* **Role** (`role`, text, optional): Select your role within the company (e.g., developer, researcher, etc.).
* **Program Name** (`program_name`, text, optional): Select the name of the R&D program you want to register in.
* **Project Name** (`project_name`, text, optional): Select the name of the project you want to register in.
* **Start Date** (`start_date`, date, optional): Select the date you want to start participating in the program.
* **End Date** (`end_date`, date, optional): Select the date you want to end participating in the program.
* **Subscription Type** (`subscription_type`, text, optional): Choose how you want to subscribe to the program (e.g., full-time, part-time, etc.).
* **Frequency** (`frequency`, select_one, optional): Choose how often you want to participate in the program (e.g., Weekly, Bi-Weekly, etc.).
* **Payment Method** (`payment_method`, select_one, optional): Choose the method of payment for the program (e.g., Credit Card, Bank Transfer, etc.).
* **Payment Cycle** (`payment_cycle`, select_one, optional): Choose the payment cycle for the program (e.g., Monthly, Quarterly, etc.).
