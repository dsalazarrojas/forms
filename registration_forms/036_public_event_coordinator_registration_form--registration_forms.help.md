# Public Event Coordinator Registration Form - Help Guide

## Purpose
The Public Event Coordinator Registration Form is a tool used to collect information about upcoming events coordinated by the public. This form helps event coordinators and administrators understand the event's requirements and make necessary arrangements.

## How To Complete This Form
To complete this form, please follow these steps:

* Please select the correct event type (Yes/No).
* Fill in the event title and coordinator name accurately.
* Enter the event date and time correctly.
* Provide the event location and contact phone number.
* Enter the event's contact email address.
* Specify the event's capacity.
* Enter a brief description of the event.
* Select the event's status (Active/Inactive).
* Add any additional notes or comments.
* Enter the event's status date and time, if applicable.

## Field-by-Field Explanation
* **Event Type** (`event_type`, `select_one`, required): Please select "Yes" if the event is a coordinated event.
* **Coordinator Name** (`coordinator_name`, `text`, required): Enter the name of the public event coordinator.
* **Event Title** (`event_title`, `text`, required): Enter the title of the event.
* **Event Date** (`event_date`, `date`, required): Enter the date of the event in the correct format (YYYY-MM-DD).
* **Event Time** (`event_time`, `time`, required): Enter the time of the event in the correct format (HH:MM AM/PM).
* **Event Location** (`event_location`, `text`, required): Enter the location where the event will take place.
* **Contact Phone** (`contact_phone`, `text`, required): Enter the contact phone number of the event coordinator or administrator.
* **Contact Email** (`contact_email`, `email`, required): Enter the contact email address of the event coordinator or administrator.
* **Event Capacity** (`event_capacity`, `number`, optional): Specify the maximum number of attendees allowed.
* **Event Description** (`event_description`, `note`, optional): Enter a brief description of the event.
* **Event Status** (`event_status`, `select_multiple`, required): Select the status of the event (Active/Inactive).
* **Event Status Note** (`event_status_note`, `note`, optional): Add any additional notes about the event's status.
* **Event Status Comment** (`event_status_comment`, `text`, optional): Add any additional comments about the event's status.
* **Event Status Date** (`event_status_date`, `date`, optional): Enter the date the event's status was last updated.
* **Event Status Time** (`event_status_time`, `time`, optional): Enter the time the event's status was last updated.
* **Coordinator Phone** (`coordinator_phone`, `text`, required): Enter the phone number of the event coordinator.
