# Toastmasters Enrollment Form - Help Guide
## Purpose
This form is used to register and enroll for Toastmasters events.

## How To Complete This Form
1. Fill out the form in its entirety. The form is divided into several pages, each covering different aspects of the event information.
2. Review each field carefully before submitting the form to ensure accuracy.
3. Make sure to submit the form before the event start date to allow timely processing.

## Field-by-Field Explanation

* **User Information**:
	+ <label>User Information</label> (1, text, required/optional): Enter your name and any other relevant contact information.
* **Event Name**:
	+ <label>Event Name</label> (2, text, required/optional): Enter the name of the event you are enrolling for.
* **Event Start Date**:
	+ <label>Event Start Date</label> (3, date, required/optional): Select the start date of the event.
* **Event Start Time**:
	+ <label>Event Start Time</label> (4, time, required/optional): Select the start time of the event.
* **Event End Date**:
	+ <label>Event End Date</label> (5, date, required/optional): Select the end date of the event.
* **Event Location**:
	+ <label>Event Location</label> (6, text, required/optional): Enter the location of the event.
* **Event Address**:
	+ <label>Event Address</label> (7, text, required/optional): Enter the address of the event location.
* **Event Organizers**:
	+ <label>Event Organizers</label> (8, select_one, required/optional): Check if there are event organizers.
* **Event Organizer Phone**:
	+ <label>Event Organizer Phone</label> (9, text, required/optional): Enter the phone number of the event organizer.
* **Event Organizer Email**:
	+ <label>Event Organizer Email</label> (10, email, required/optional): Enter the email of the event organizer.
* **Event Description**:
	+ <label>Event Description</label> (11, note, required/optional): Enter a brief description of the event.
* **Club Information**:
	+ <label>Club Information</label> (12, text, required/optional): Enter any additional information about the club.
* **Club Name**:
	+ <label>Club Name</label> (13, text, required/optional): Enter the name of the club.
* **Club Abbreviation**:
	+ <label>Club Abbreviation</label> (14, text, required/optional): Enter the abbreviation of the club.
* **Club Number**:
	+ <label>Club Number</label> (15, text, required/optional): Enter the club number.
* **District Name**:
	+ <label>District Name</label> (16, text, required/optional): Enter the district name.

## Tips

* Make sure to double-check the fields before submitting to avoid errors.
* If you're unsure about any field, contact the Toastmasters administrators.
* This form is only for Toastmasters events, so only use it for events associated with Toastmasters.
