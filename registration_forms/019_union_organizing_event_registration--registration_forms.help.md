# Union Organizing Event Registration - Help Guide
## Purpose

This form is used to register events for union organizing activities. It provides a structured way for unions to collect and submit information about their organizing efforts.

## How To Complete This Form

To complete this form, you will need to provide the following information about the event:

1. First Name
2. Last Name
3. Email
4. Phone
5. Session Preferences (select multiple)
6. Sessions (select one)
7. Event Date
8. Start Time
9. End Time
10. Session Length
11. Registration Date
12. Event Description
13. Event Location
14. Session Topics
15. Additional Notes
16. Union Name
17. Union Address
18. Union Contact
19. Union Email
20. Union Phone
21. Organizer
22. Organizer Email
23. Organizer Phone
24. Attendee Count
25. Registration Type (select one)

## Field-by-Field Explanation

* **First Name** (`first_name`, text, required): This is your first name.
* **Last Name** (`last_name`, text, required): This is your last name.
* **Email** (`email`, email, required): This is the email address associated with your account.
* **Phone** (`phone`, text, required): This is your phone number.
* **Session Preferences** (`session_preferences`, select_multiple, optional): Select multiple sessions you are interested in attending. You can select multiple sessions.
* **Sessions** (`session_sessions`, select_one, optional): Select one session that you are interested in attending.
* **Event Date** (`event_date`, date, optional): This is the date of the event.
* **Start Time** (`start_time`, time, optional): This is the start time of the event.
* **End Time** (`end_time`, time, optional): This is the end time of the event.
* **Session Length** (`session_length`, number, optional): This is the length of each session.
* **Registration Date** (`registration_date`, date, optional): This is the date of registration.
* **Event Description** (`event_description`, text, optional): This is a brief description of the event.
* **Event Location** (`event_location`, text, optional): This is the location of the event.
* **Session Topics** (`session_topics`, text, optional): This is a brief description of the topics covered in the session.
* **Additional Notes** (`additional_notes`, note, optional): This is a field for any additional notes about the event.
* **Union Name** (`union_name`, text, optional): This is the name of the union.
* **Union Address** (`union_address`, text, optional): This is the address of the union.
* **Union Contact** (`union_contact`, text, optional): This is the contact person for the union.
* **Union Email** (`union_email`, email, optional): This is the email address of the union.
* **Union Phone** (`union_phone`, text, optional): This is the phone number of the union.
* **Organizer** (`organizer`, text, optional): This is the name of the person organizing the event.
* **Organizer Email** (`organizer_email`, email, optional): This is the email address of the organizer.
* **Organizer Phone** (`organizer_phone`, text, optional): This is the phone number of the organizer.
* **Attendee Count** (`attendee_count`, number, optional): This is the number of attendees expected.
* **Registration Type** (`registration_type`, select_one, optional): This is the type of registration (in-person, online, or hybrid).

Note: Please make sure to fill out all required fields (marked as required) before submitting the form.
