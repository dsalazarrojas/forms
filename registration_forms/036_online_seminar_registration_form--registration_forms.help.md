# Online Seminar Registration Form - Help Guide
## Purpose
This form is used to register a new online seminar. 
## How To Complete This Form
To complete this form, follow the steps below:

1. Select the seminar registration status.
2. Input the seminar title.
3. Input the seminar description.
4. Input the seminar start date and time.
5. Input the seminar end date and time.
6. Input the seminar capacity.
7. Input the seminar location.
8. Input the seminar price.
9. Input the seminar registration fee.
10. Input the user first name.
11. Input the user last name.
12. Input the user email.
13. Input the user phone.
14. Input the user address.
15. Input the seminar notes.
16. Input the user comments.
17. Input any seminar attachment.
18. Input seminar agenda.
19. Input seminar facilitator.
20. Input seminar speaker.
21. Input seminar co-speaker.
22. Input seminar organizer.

## Field-by-Field Explanation

* **Seminar Registration Status** (`seminar_registration_status`, `select_one`): Select whether the seminar is registered or not.
* **Seminar Title** (`seminar_title`, `text`): Input the title of the seminar.
* **Seminar Description** (`seminar_description`, `text`): Input the description of the seminar.
* **Seminar Start Date** (`seminar_start_date`, `date`): Input the start date of the seminar.
* **Seminar Start Time** (`seminar_start_time`, `time`): Input the start time of the seminar.
* **Seminar End Date** (`seminar_end_date`, `date`): Input the end date of the seminar.
* **Seminar End Time** (`seminar_end_time`, `time`): Input the end time of the seminar.
* **Seminar Capacity** (`seminar_capacity`, `number`): Input the number of people that can attend the seminar.
* **Seminar Location** (`seminar_location`, `text`): Input the location of the seminar.
* **Seminar Price** (`seminar_price`, `number`): Input the price of the seminar.
* **Seminar Registration Fee** (`seminar_registration_fee`, `number`): Input the registration fee of the seminar.
* **User First Name** (`user_first_name`, `text`): Input the first name of the user.
* **User Last Name** (`user_last_name`, `text`): Input the last name of the user.
* **User Email** (`user_email`, `email`): Input the email of the user.
* **User Phone** (`user_phone`, `text`): Input the phone of the user.
* **User Address** (`user_address`, `text`): Input the address of the user.
* **Seminar Notes** (`seminar_notes`, `note`): Input any notes about the seminar.
* **User Comments** (`user_comments`, `text`): Input any comments about the user.
* **Seminar Attachment** (`seminar_attachment`, `text`): Input any attachment related to the seminar.
* **Seminar Agenda** (`seminar_agenda`, `text`): Input the agenda of the seminar.
* **Seminar Facilitator** (`seminar_facilitator`, `text`): Input the facilitator of the seminar.
* **Seminar Speaker** (`seminar_speaker`, `text`): Input the speaker of the seminar.
* **Seminar Co-Speaker** (`seminar_co_speaker`, `text`): Input the co-speaker of the seminar.
* **Seminar Organizer** (`seminar_organizer`, `text`): Input the organizer of the seminar.
