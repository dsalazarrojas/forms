# Community Impact Project Registration - Help Guide
## Purpose
This guide will walk you through the process of completing the Community Impact Project Registration form.

## How To Complete This Form
1. Ensure you have all the required information ready before starting the form. This includes:
	* Project Lead Full Name
	* Project Lead Email Address
	* Project Lead Phone Number
	* Proposed Project Title
	* Primary Impact Category
	* Primary Project Goal
	* Estimated Number of Direct Beneficiaries
	* Anticipated Project Duration
	* Total Required Budget Estimate
	* Detailed Description of Project Activities
	* Date of Project Registration
2. Fill in the required fields with accurate and complete information.
3. Select the most fitting Primary Impact Category and Project Duration for your project.

## Field-by-Field Explanation
* **Project Lead Full Name**: Enter the full name of the person responsible for the project.
* **Project Lead Email Address**: Enter the email address of the project lead.
* **Project Lead Phone Number**: Enter the phone number of the project lead.
* **Proposed Project Title**: Enter a short descriptive name for the project.
* **Primary Impact Category**: Choose the category that best fits your project from the given options.
* **Primary Project Goal**: Describe the main outcome you hope to achieve with the project.
* **Estimated Number of Direct Beneficiaries**: Provide an estimate of how many people the project will directly serve.
* **Anticipated Project Duration**: Select the expected duration of the project from the given options.
* **Total Required Budget Estimate**: Enter the total budget for the project in US Dollars.
* **Detailed Description of Project Activities**: Provide a detailed description of the specific steps you will take to achieve the project's goal.
* **Date of Project Registration**: Enter the date the project is being registered.
* **I agree to follow community project guidelines**: Confirm that you will abide by the community project guidelines by selecting "Yes, I agree".
