# School Event Registration Form - Help Guide
## Purpose

This form is used to register and collect details about school events, which will be used for organizational and administrative purposes.

## How To Complete This Form

1. Fill in the required fields as accurately as possible. If a field is not required, fill it in according to your preference.
2. Review each field carefully before submitting the form.
3. Ensure that you have provided all necessary information before submitting the form.

## Field-by-Field Explanation

* **School Event Details (School Event Details)** (`1`, text, **required: false**): Enter a brief description of the event.
* **Event Date (Event Date)** (`2`, date, **required: false**): Enter the date of the event in the format MM/DD/YYYY.
* **Event Start Time (Event Start Time)** (`3`, time, **required: false**): Enter the start time of the event in 24-hour format (HH:MM).
* **Event End Time (Event End Time)** (`4`, time, **required: false**): Enter the end time of the event in 24-hour format (HH:MM).
* **Event Location (Event Location)** (`5`, text, **required: false**): Enter the location of the event.
* **Contact Details (Contact Details)** (`6`, text, **required: false**): Enter any contact information that may be relevant for the event.
* **Email (Email)** (`7`, email, **required: false**): Enter the email address associated with the event.
* **Phone (Phone)** (`8`, text, **required: false**): Enter the phone number associated with the event.
* **Assigned Staff (Assigned Staff)** (`9`, select_one, **required: false**): Choose whether the event is assigned to a staff member or not. Options are 'Yes' and 'No'.
* **Staff Name (Staff Name)** (`10`, text, **required: false**): Enter the name of the staff member assigned to the event, if applicable.

## Tips

* Make sure to double-check your answers to ensure accuracy.
* If you're unsure about a particular field, refer back to the form instructions if you need clarification.
* If you need further assistance, contact the relevant personnel for support.
