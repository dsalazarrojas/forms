# gaming_convention_panel_slot_booking_form - Help Guide
## Purpose
This guide explains the purpose and usage of the gaming convention panel slot booking form.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter your name in the User Name field to identify yourself.
2. Enter your email address in the Email Address field for contact purposes.
3. Select the event ID that corresponds to the event you wish to schedule.
4. Select the time slots for the start and end of the panel using the Start Time and End Time fields.
5. Choose the room for the panel from the Room Name dropdown list.
6. Enter a description of the panel in the Panel Description field.
7. Select the type of event from the Event Type dropdown list.
8. Choose the start and end dates for the panel from the Start Date and End Date fields.
9. Enter the duration of the panel in the Event Duration field.
10. Select the status of the event as Active or Inactive in the Event Status field.
11. Choose the tags or categories for the event in the Event Tags field.
12. Enter the capacity limit for the event in the Event Capacity field.
13. Enter the capacity limit for the room in the Room Capacity field.
14. Choose the tags or categories for the user in the User Tags field.

## Field-by-Field Explanation
### User Name (User Name)
*   **User Name** (`user_name`, `text`, required/optional): This field is used to identify the user who is scheduling or managing the panel slot. Enter your name to associate your identity with the panel slot.

### Email Address (email_address)
*   **Email Address** (`email`, required/optional): Enter your email address for contact purposes, in case the convention organizers need to reach you about the panel slot.

### Event ID (event_id)
*   **Event ID** (`number`, required/optional): Choose the event ID that corresponds to the event you wish to schedule. This helps to identify the specific event being scheduled.

### Start Time (start_time)
*   **Start Time** (`time`, required/optional): Select the time slot for the panel to start.

### End Time (end_time)
*   **End Time** (`time`, required/optional): Choose the time slot for the panel to end.

### Room Name (room_name)
*   **Room Name** (`select_one`, required/optional): Select the room for the panel from the given options.

### Panel Description (panel_description)
*   **Panel Description** (`text`, required/optional): Provide a description of the panel, including details about its content or topics.

### Event Type (event_type)
*   **Event Type** (`select_multiple`, required/optional): Choose the type of event from the given options, such as workshop, panel discussion, etc.

### Start Date (start_date)
*   **Start Date** (`date`, required/optional): Select the start date for the panel.

### End Date (end_date)
*   **End Date** (`date`, required/optional): Choose the end date for the panel.

### Event Start Time (event_start_time)
*   **Event Start Time** (`time`, required/optional): Select the start time for the panel.

### Event End Time (event_end_time)
*   **Event End Time** (`time`, required/optional): Choose the end time for the panel.

### Event Duration (event_duration)
*   **Event Duration** (`number`, required/optional): Enter the duration of the panel.

### Event Status (event_status)
*   **Event Status** (`select_one`, required/optional): Choose the status of the event as Active or Inactive.

### Event Tags (event_tags)
*   **Event Tags** (`select_multiple`, required/optional): Select the tags or categories for the event.

### Event Capacity (event_capacity)
*   **Event Capacity** (`number`, required/optional): Enter the capacity limit for the event.

### Room Capacity (room_capacity)
*   **Room Capacity** (`number`, required/optional): Enter the capacity limit for the room.

### User Tags (user_tags)
*   **User Tags** (`select_multiple`, required/optional): Select the tags or categories for the user.

## Tips
*   Be sure to fill out all required fields carefully and accurately.
*   If you are unsure about any field or option, consult with the convention organizers or refer to the convention's documentation and guidelines.
