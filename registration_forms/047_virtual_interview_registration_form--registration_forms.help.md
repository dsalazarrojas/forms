# Virtual Interview Registration Form - Help Guide
## Purpose
This form is used to collect necessary information from users for virtual interviews. This includes personal details, job information, and scheduling preferences.

## How To Complete This Form
To complete this form, follow these steps:

* Fill out all required fields (marked as "true") with accurate and up-to-date information.
* Provide a valid email address for communication purposes.
* Choose your preferred language for the interview.
* Select the type of interview you are interested in (video, phone, or in-person).
* If you are unable to attend a virtual interview, please provide your work location.
* You may add any comments or remarks related to the interview.
* If you have a resume, please upload it.
* You can provide your job description and work experience if you want.

## Field-by-Field Explanation
* **First Name** (First Name, text, required):
	+ Input your first name for identification purposes.
* **Last Name** (Last Name, text, required):
	+ Input your last name for identification purposes.
* **Email** (Email, email, required):
	+ Enter a valid email address for communication purposes.
* **Job Title** (Job Title, text, required):
	+ Input your current or desired job title.
* **Resume** (Resume, text, optional):
	+ If available, upload your resume for review.
* **Date and Time** (Date and Time, date, required):
	+ Select a date and time for the interview.
* **Preferred Language** (Preferred Language, select multiple, required):
	+ Choose your preferred language for the interview.
* **Interview Type** (Interview Type, select one, required):
	+ Select the type of interview you prefer (video, phone, or in-person).
* **Location** (Location, text, optional):
	+ If you are unable to attend a virtual interview, provide your work location.
* **Comments** (Comments, note, optional):
	+ Add any comments or remarks related to the interview.
* **Resume Link** (Resume Link, text, optional):
	+ If available, provide a link to your resume.
* **Job Description** (Job Description, text, optional):
	+ Provide a brief description of your job responsibilities.
* **Work Experience** (Work Experience, text, optional):
	+ Describe your work experience.
* **Skills** (Skills, text, optional):
	+ List your relevant skills.
* **Education** (Education, text, optional):
	+ Provide your education background.
* **Work Hours** (Work Hours, text, optional):
	+ Input your work hours per week.
* **Work Status** (Work Status, select one, required):
	+ Select your current work status (working or looking).
* **Job Level** (Job Level, select one, optional):
	+ If available, select your current job level (senior, junior, or intern).
* **Job Category** (Job Category, select one, optional):
	+ If available, select your job category (full-time, part-time, or freelance).
* **Job Type** (Job Type, select one, required):
	+ Select the type of job you are looking for (remote, on-site, or hybrid).
* **Job Schedule** (Job Schedule, select one, optional):
	+ If available, select your preferred job schedule (mon-fri, 9am-5pm, or flexible).
* **Salary** (Salary, select one, required):
	+ Select your salary expectations (negotiable, fixed, or range).
* **Job Openings** (Job Openings, select one, optional):
	+ If available, select the number of job openings you are interested in (multiple or single).
* **Job Position** (Job Position, select one, optional):
	+ If available, select the type of job position you are looking for (full-time, part-time, or temporary).
