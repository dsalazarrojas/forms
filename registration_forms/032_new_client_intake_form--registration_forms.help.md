# New Client Intake Form - Help Guide
## Purpose
This form is designed to gather information from new clients that will be used to create their care plan.

## How To Complete This Form
To complete this form, simply follow these steps:

1. Fill in the required information for each page.
2. Be as detailed as possible when answering each question.
3. Make sure to review each page to ensure all necessary information is provided.
