# Mobile Accessories Event Registration - Help Guide
## Purpose
This form is designed to collect registration information from individuals interested in attending a mobile accessories event. It's essential to complete this form to provide your details and express your interests.

## How To Complete This Form
1. Fill in the form with your first name and last name in the relevant fields.
2. Enter your email address in the email field. This is where we will contact you with further event details.
3. If you have a phone number, enter it in the phone field.
4. Indicate whether you're interested in the event by selecting "Yes" in the event interest field.
5. Choose which services you'd like to sign up for by selecting multiple options in the sign up for field.
6. Enter the date of the event in the event date field in the desired format (e.g., DD/MM/YY or MM/DD/YY).
7. Select the event time in the event time field.
8. Add any additional notes or comments about the event in the notes field.
9. If you have an assigned tool, enter its name in the assigned tool field.

## Field-by-Field Explanation
* **first name** (`first_name`, `text`, **required**): Enter your first name.
* **last name** (`last_name`, `text`, **required**): Enter your last name.
* **email** (`email`, `email`, **required**): Enter a valid email address.
* **phone** (`phone`, `text`, **optional**): Enter your phone number (if you have one).
* **event interest** (`event_interest`, `select_one`, **optional**): Select "Yes" if you're interested in the event.
* **sign up for** (`sign_up_for`, `select_multiple`, **optional**): Choose which services you'd like to sign up for.
* **event date** (`event_date`, `date`, **optional**): Enter the date of the event in the desired format.
* **event time** (`event_time`, `time`, **optional**): Select the time of the event.
* **notes** (`notes`, `note`, **optional**): Add any additional comments or questions you have about the event.
* **assigned tool** (`assigned_tool`, `text`, **optional**): Enter the name of the tool you've been assigned, if applicable.
