# Beginner S Functional Calisthenics Boot Camp - Help Guide
## Purpose
This form is for registering for the Beginner S Functional Calisthenics Boot Camp, a fitness program designed for individuals interested in starting a functional fitness journey.

## How To Complete This Form
To complete this form, follow these steps:

1. Read through the form carefully to understand the questions and sections.
2. Answer each question honestly and thoroughly, providing as much detail as possible.
3. Make sure to review your answers for accuracy before submitting the form.

## Field-by-Field Explanation
- **-- Denver Bar Squad Registration --**
  • This is the introduction section of the form, providing some background information about the boot camp.
- **Full Name**
  • Please enter your full name as it appears on your government-issued ID or passport.
  • This field is required.
- **Email Address**
  • Enter your active email address where you can be reached for further information and updates.
  • This field is required for communication purposes.
- **Phone Number**
  • Enter your phone number where you can be reached for further information and updates.
  • This field is required.
- **-- Fitness Background --**
  • This section is for background information about your fitness experience and current activity level.
- **Current physical activity level**
  • Select one of the options to describe your current level of physical activity:
    + Sedentary (Little to no exercise)
    + Lightly active (1-2 times per week)
    + Moderately active (3-4 times per week)
    + Very active (Daily exercise)
  • This field is required.
- **Previous experience with calisthenics or bodyweight training?**
  • Select one of the options to describe your level of experience:
    + None - Complete beginner
    + Some basic movements (Pushups, Squats)
    + Intermediate level
  • This field is required.
- **Do you have any injuries or physical limitations?**
  • If yes, please describe your injury or limitation in detail.
  • This field is not required, but please provide accurate information if applicable.
- **-- Boot Camp Selection --**
  • This is a note section, providing information about the boot camp program.
- **Preferred Start Date**
  • Select one of the available start dates for the boot camp:
    + Monday, March 2nd
    + Saturday, March 7th
    + Monday, April 6th
  • This field is required.
- **Preferred Time Slot**
  • Select one of the available time slots:
    + Morning (6:00 AM)
    + Evening (6:30 PM)
    + Weekend Morning (9:00 AM)
  • This field is required.
- **What is your primary goal for this boot camp?**
  • Select one of the available goals:
    + Build Strength
    + Learn Bodyweight Skills
    + Weight Loss
    + General Fitness
    + Improve Mobility
  • This field is required.
- **-- Liability Waiver and Consent --**
  • This is a note section, providing information about the liability waiver and consent.
- **I assume all risks of participation in high-intensity training**
  • Select one of the options to agree or disagree with the waiver:
    + I Accept and Agree
    + Other
  • This field is required.
- **May we use photos/videos of the training for social media?**
  • Select one of the options:
    + True
    + False
  • This field is optional.
- **Date**
  • This is the date of signing the liability waiver and consent.
  • This field is required.
- **How did you hear about Denver Bar Squad?**
  • Select one of the available options:
    + Instagram / Social Media
    + Friend Referral
    + Local Event
    + Search Engine
    + Other
  • This field is optional.
