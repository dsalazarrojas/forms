# Green Transport Initiative Application Form - Help Guide
## Purpose
This form is used to collect information about Green Transport Initiative projects. It is intended for applicants who wish to apply for funding or support for their projects.

## How To Complete This Form
To complete this form, please follow these steps:
1. Review each page carefully to ensure you have all the necessary information.
2. Fill out each page in the following order:
	* Project Details
	* Applicant Information
	* Project Location
	* Project Type
	* Grant Amount
	* Project Start Date
	* Project End Date
	* Project Budget
	* Contact Information
	* Grant Committee Reviewers
	* Grant Manager Reviewers
	* Grant Manager Comments
	* Applicant Phone
	* Grant Manager Email
	* Project Manager
	* Project Website
	* Project Facebook
	* Project Twitter
	* Project Instagram
	* Project LinkedIn
	* Project YouTube
	* Project Website 2
	* Project Facebook 2
	* Project Twitter 2
	* Project Instagram 2

## Field-by-Field Explanation

* **Project Details** (`project_details`, text, not required): Please provide a brief description of the project.
* **Applicant Information** (`applicant_info`, text, not required): Please provide your contact information, including your name and email address.
* **Project Location** (`project_location`, text, not required): Please provide the location where the project will be carried out.
* **Project Type** (`project_type`, select_one, not required): Please select the type of project you are applying for (Green Transport, Green Energy, Green Building).
* **Grant Amount** (`grant_amount`, number, not required): Please provide the amount of grant you are applying for.
* **Project Start Date** (`project_start_date`, date, not required): Please provide the start date of the project.
* **Project End Date** (`project_end_date`, date, not required): Please provide the end date of the project.
* **Project Budget** (`project_budget`, number, not required): Please provide the budget of the project.
* **Contact Information** (`contact_info`, text, not required): Please provide your contact information, including your name and email address.
* **Grant Committee Reviewers** (`grant_committee_reviewers`, select_multiple, not required): Please select the reviewers from the grant committee who will be reviewing your project.
* **Grant Manager Reviewers** (`grant_manager_reviewers`, select_multiple, not required): Please select the grant managers who will be reviewing your project.
* **Grant Manager Comments** (`grant_manager_comment`, note, not required): Please provide any additional comments from the grant manager.
* **Applicant Phone** (`applicant_phone`, text, not required): Please provide your phone number.
* **Grant Manager Email** (`grant_manager_email`, email, not required): Please provide the email address of the grant manager.
* **Project Manager** (`project_manager`, text, not required): Please provide the project manager's name and email address.
* **Project Website** (`project_website`, text, not required): Please provide the website address of the project.
* **Project Facebook** (`project_facebook`, text, not required): Please provide the Facebook address of the project.
* **Project Twitter** (`project_twitter`, text, not required): Please provide the Twitter address of the project.
* **Project Instagram** (`project_instagram`, text, not required): Please provide the Instagram address of the project.
* **Project LinkedIn** (`project_linkedin`, text, not required): Please provide the LinkedIn address of the project.
* **Project YouTube** (`project_youtube`, text, not required): Please provide the YouTube address of the project.
* **Project Website 2** (`project_website_2`, text, not required): Please provide the website address of the project (if applicable).
* **Project Facebook 2** (`project_facebook_2`, text, not required): Please provide the Facebook address of the project (if applicable).
* **Project Twitter 2** (`project_twitter_2`, text, not required): Please provide the Twitter address of the project (if applicable).
* **Project Instagram 2** (`project_instagram_2`, text, not required): Please provide the Instagram address of the project (if applicable).
