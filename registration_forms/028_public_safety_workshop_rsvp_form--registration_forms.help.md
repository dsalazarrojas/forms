# public_safety_workshop_rsvp_form - Help Guide
## Purpose
The Public Safety Workshop RSVP form is designed for users to respond to an invitation for the Public Safety Workshop. This form helps the workshop organizers keep track of attendees and allows users to provide their details and preferences.

## How To Complete This Form
To complete this form, follow these steps:

1. Review the form's fields and ensure you have all the required information handy.
2. Scroll down to each section and fill in the details as requested.
3. For the RSVP status field, select one of the available options that best represents your current status.
4. In the comments field, add any additional information you want to share with the organizers.
5. If you have an email address and/or phone number, you can fill them in as well.

## Field-by-Field Explanation
* **Public Safety Workshop Details**: This is an optional section for the workshop details. You can leave this section blank if you don't want to provide this information.
* **Participant Information**: This section is optional for participants' details. You can fill in your details if you want to provide this information.
* **RSVP Status**: Choose one of the following options:
	+ Option 1: Select this if you are attending the workshop.
	+ Option 2: Select this if you are not attending.
	+ Option 3: Select this for other RSVP statuses, like "maybe" or not responding.
* **Comments**: Use this field to add any additional comments or information you want to share with the organizers.
* **Email**: Fill in your email address if you want to be contacted by the workshop organizers.
* **Phone Number**: If you want to provide your phone number for further communication, fill it in here.
