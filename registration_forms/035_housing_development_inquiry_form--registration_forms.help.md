# housing_development_inquiry_form - Help Guide
## Purpose
This form is used to gather information about new projects for housing development.

## How To Complete This Form
- Fill out the form completely and honestly.
- Provide specific details about each project.
- Make sure to fill out all required fields.

## Field-by-Field Explanation
- **New Project** (`new_project`, `text`, required): Enter the name of the new project.
- **Project Details** (`project_details`, `select_multiple`, not required): Select 'Yes' if the project involves multiple projects, otherwise select 'No'.
- **Contact Person** (`contact_person`, `email`, required): Enter the contact person's email address.
- **Contact Details** (`contact_details`, `note`, not required): Enter any additional contact details for the project.
- **Contact Telephone** (`contact_telephone`, `text`, required): Enter the contact person's telephone number.
- **Contact Other** (`contact_other`, `text`, not required): Enter any other contact details for the project.
- **Email** (`email`, `email`, required): Enter a valid email address for the project.
- **Comments** (`comments`, `text`, not required): Enter any comments about the project.
- **New Project 2** (`new_project_2`, `time`, not required): Set the project duration.
- **Project Status** (`project_status`, `select_one`, not required): Select the project status as 'Active' or 'Inactive'.
- **Follow Up** (`follow_up`, `date`, required): Set the follow-up date for the project.
- **Project Location** (`project_location`, `select_multiple`, not required): Select whether the project is located in-house or elsewhere.
- **Project Type** (`project_type`, `select_one`, not required): Select whether the project is a new project or not.
- **Project Category** (`project_category`, `select_one`, not required): Select the project category.
- **Project Subcategory** (`project_subcategory`, `select_one`, not required): Select the project subcategory.
- **Project Description** (`project_description`, `text`, required): Enter a brief description of the project.
- **Follow Up Frequency** (`follow_up_frequency`, `select_one`, not required): Select the follow-up frequency.
- **Project Deadline** (`project_deadline`, `time`, not required): Set the project deadline.
- **Project Start Date** (`project_start_date`, `date`, not required): Set the project start date.
- **Project End Date** (`project_end_date`, `date`, not required): Set the project end date.
- **Project Lead** (`project_lead`, `select_one`, not required): Select whether the project lead is active.
- **Project Lead Details** (`project_lead_details`, `text`, not required): Enter additional project lead details.
- **Project Lead Contact** (`project_lead_contact`, `email`, not required): Enter the project lead contact information.
- **Project Address** (`project_address`, `text`, not required): Enter the project address.
- **Follow up** (`submit`, `select_one`, not required): Select whether to submit the form.
