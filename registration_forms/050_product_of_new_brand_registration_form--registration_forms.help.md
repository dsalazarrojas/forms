# Product Of New Brand Registration Form - Help Guide
## Purpose
This form is used to register new products with the company. It is designed to collect necessary information about the product, such as its name, description, and assigned tool. This information will be used to create a new product in the catalog. 

## How To Complete This Form
To complete this form, follow these steps:

1.  Enter the brand name of the new product.
2.  Enter a brief description of the product.
3.  Enter the email address of the individual or team responsible for the product.
4.  Enter the phone number of the individual or team responsible for the product.
5.  Select the tool that this product has been assigned to.
6.  Select the applicable form IDs for this product.
7.  Enter any additional output file information, if needed.

## Field-by-Field Explanation

*   **Brand Name (Brand Name, text, Required):** Enter the name of the brand that the product belongs to.
*   **Product Name (Product Name, text, Required):** Enter a brief name for the product.
*   **Description (Description, text, Required):** Provide a short description of the product.
*   **Email (Email, email, Required):** Enter the email address of the individual or team responsible for the product.
*   **Phone (Phone, text, Required):** Enter the phone number of the individual or team responsible for the product.
*   **Assigned Tool (Assigned Tool, select_one, Required):** Select the tool to which this product has been assigned.
*   **Form IDs (Form IDs, select_multiple, Required):** Select the applicable form IDs for this product.
*   **Output File (Output File, text, Optional):** Enter any additional output file information, if needed.

## Tips
*   Please ensure that you are entering the correct brand name and product name.
*   Be concise in your description, as it will be used to help describe the product in the catalog.
*   Select the correct assigned tool and form IDs to ensure the product is correctly categorized and can be easily managed by the relevant teams.
