# Office Space Tour Registration - Help Guide
## Purpose
The Office Space Tour Registration form is used to collect information for an Office Space Tour.

## How To Complete This Form

This form has several fields that need to be filled out to complete the tour registration process. Please fill out the form carefully and make sure to provide accurate information.

## Field-by-Field Explanation

* **Tour Request** (`tour_request`, text, optional): This field is for the user to describe their tour request. Please provide a brief description of what you would like to see during the tour.
* **Contact Information** (`contact_info`, text, optional): This field is for the user to provide their contact information, such as their name and contact details.
* **Contact Name** (`contact_name`, text, optional): This field is for the user to provide their name, which will be used for follow up purposes.
* **Contact Email** (`contact_email`, email, optional): This field is for the user to provide their email address, which will be used for follow up purposes.
* **Contact Phone** (`contact_phone`, text, optional): This field is for the user to provide their phone number, which will be used for follow up purposes.
* **Tour Date** (`tour_date`, date, optional): This field is for the user to select the date they would like to schedule the tour for.
* **Tour Time** (`tour_time`, time, optional): This field is for the user to select the time they would like to schedule the tour for.
* **Tour Duration** (`tour_duration`, number, optional): This field is for the user to select the duration of the tour in minutes.
* **Tour Type** (`tour_type`, select_multiple, optional): This field allows the user to select one or more types of tour options. Options are:
	+ Option 1
	+ Option 2
	+ Option 3
* **Follow Up** (`follow_up`, note, optional): This field is for the user to provide additional follow up information.
* **Notes** (`notes`, note, optional): This field is for the user to provide any additional notes or comments about the tour.
* **Submit** (`submit`, select_one, optional): This field is not actually a submission button, but rather an option for the user to select which option is the best fit for their tour request.
* **Tour Date 2** (`tour_date2`, date, optional): This field is for the user to select a second tour date.
* **Tour Time 2** (`tour_time2`, time, optional): This field is for the user to select a second tour time.
* **Tour Duration 2** (`tour_duration2`, number, optional): This field is for the user to select a second tour duration in minutes.
* **Follow Up 2** (`follow_up2`, note, optional): This field is for the user to provide additional follow up information for the second tour.
* **Notes 2** (`notes2`, note, optional): This field is for the user to provide any additional notes or comments about the second tour.

## Tips

* Please make sure to fill out all the fields carefully and accurately.
* If you need to provide multiple tours, please fill out each tour's fields separately.
* If you have any questions or need help, please contact the tour administrator.
* The tour administrator will follow up with you after completing this form.

Note: This help guide is for informational purposes only and may not be up-to-date or accurate. Please refer to the tour administrator for any further questions or concerns.
