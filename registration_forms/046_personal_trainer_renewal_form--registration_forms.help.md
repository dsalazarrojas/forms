# personal_trainer_renewal_form - Help Guide
## Purpose
The personal trainer renewal form is used to update the trainer's information, including new clients, training programs, services offered, and package details.

## How To Complete This Form
To complete this form, follow these steps:
1. Fill in the required fields.
2. Choose the training program and package that apply to the new client.
3. Select the services that will be offered to the client.
4. Provide any additional details about the package.
5. Review and submit the form.

## Field-by-Field Explanation
* **Trained By** (text, Trained By, required: false): Enter the name of the person who trained the client.
* **New Client Info** (text, New Client Info, required: false): Enter any new client information that has changed.
* **Training Program** (select one, Training Program, required: false): Choose the training program that applies to the new client:
	+ Program 1
	+ Program 2
	+ Program 3
	+ Program 4
* **Client Details** (text, Client Details, required: false): Enter any additional details about the client.
* **Services** (select multiple, Services, required: false): Select the services that will be offered to the client:
	+ Service 1
	+ Service 2
	+ Service 3
	+ Service 4
* **Package** (select one, Package, required: false): Choose the package that applies to the new client:
	+ Package 1
	+ Package 2
	+ Package 3
* **Package Details** (text, Package Details, required: false): Enter any additional details about the package.

## Tips
* Make sure to fill in all the required fields.
* Choose the correct training program and package that applies to the new client.
* Select all the services that will be offered to the client.
