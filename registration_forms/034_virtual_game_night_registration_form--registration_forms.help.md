# Virtual Game Night Registration Form - Help Guide
## Purpose
This form is used to register for Virtual Game Nights, providing essential information to the Game Master so they can prepare for the event.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the Game Night Details page (Page 1) with the relevant information about the Virtual Game Night.
2. Enter the Participant Information (Page 2) with details about the players attending.
3. Fill out the Player Name, Game Name, and other fields on Page 3-5 as necessary.
4. Provide your Contact Email and Phone (if applicable) on Page 6.
5. Confirm your Game Master and Game Type (if applicable) on Page 7-8.

## Field-by-Field Explanation
* **Game Night Details**: Enter a brief description of the game night, including date, time, and any notable events.
* **Participant Information**: Enter the number of players attending and any additional notes about the participants.
* **Player Name**: Enter the name of the player.
* **Game Name**: Enter the name of the game being played.
* **Date Played**: Enter the date the game was played (in YYYY-MM-DD format).
* **Game System Version**: Enter the version of the game being used.
* **Player Level**: Enter the player's level (e.g., beginner, intermediate, advanced).
* **Game System Experience**: Enter any experience with the game system.
* **Player Age**: Enter the age of the player.
* **Contact Email**: Enter your email address for contact purposes.
* **Contact Phone**: Enter your phone number (if applicable).
* **Game Master**: Enter the name of the Game Master (if applicable).
* **Game Type**: Enter the type of game being played (e.g., board game, card game, etc.).
* **Platform**: Enter the platform on which the game is being played (e.g., online, in-person, etc.).
* **Players**: Enter the number of players attending.
* **Game System**: Enter the game system being used (e.g., Xbox, PlayStation, etc.).
* **Game Version**: Enter the version of the game being used.
* **Game System Version 2**: Enter any additional information about the game system version.
* **Game Name 2**: Enter the name of the second game being played.
* **Player Name 2**: Enter the name of the second player.
* **Game Master 2**: Enter the name of the second Game Master (if applicable).
* **Game Type 2**: Enter the type of the second game being played.
* **Players 2**: Enter the number of players attending the second game.
* **Platform 2**: Enter the platform on which the second game is being played.
* **Game System Experience 2**: Enter any experience with the second game system.
* **Game System Version 2**: Enter any additional information about the second game system version.
