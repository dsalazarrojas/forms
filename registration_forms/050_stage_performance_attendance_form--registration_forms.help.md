# Stage Performance Attendance Form - Help Guide
## Purpose
The Stage Performance Attendance Form is designed to collect information about stage performances, including details about the performance, the performer, and the event. This form helps to track and record attendance and feedback from events, which can be useful for event organizers, performers, and attendees. Please ensure that you are using this form for its intended purpose and not duplicating existing forms.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the necessary information in the corresponding fields, making sure to fill out all required fields.
2. Be as concise and accurate as possible when providing details about the performance.
3. If you are unsure about any field, refer to the field-by-field explanation below.

## Field-by-Field Explanation

* **Performance details** (`performance_details`): Enter a brief description of the stage performance, including the name of the performance and any other relevant details.
* **Performer** (`performer`): Enter the name of the performer or artist who performed.
* **Performance time** (`performance_time`): Enter the duration of the performance, for example, "30 minutes" or "1 hour".
* **Performance start time** (`performance_start_time`): Enter the start time of the performance, using 24-hour format (e.g., "14:00").
* **Performance end time** (`performance_end_time`): Enter the end time of the performance, using 24-hour format (e.g., "15:00").
* **Event date** (`event_date`): Enter the date of the event.
* **Feedback** (`feedback`): Provide any feedback or comments about the performance, event, or form.
* **Attendance** (`attendance`): Enter the number of attendees or audience members present at the performance.
* **Comments** (`comments`): Provide additional comments or notes about the performance, event, or form.

## Tips
* Make sure to double-check your entries for accuracy and completeness before submitting the form.
* If you need to add any additional information not covered by this form, consider contacting the form creators or event organizers.
* If you are filling out the form for someone else, ensure you have their permission to do so.
