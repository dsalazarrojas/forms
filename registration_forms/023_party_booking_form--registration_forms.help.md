# party_booking_form - Help Guide
## Purpose
This form is for booking parties, events, or gatherings. It helps gather information about the event, its participants, and the host. Fill it out to provide the necessary details for a successful event.

## How To Complete This Form
1. Start by filling out the first page, which is the Party Booking Form page.
2. Fill out the fields as prompted, making sure to provide accurate information for each field.
3. Once you've filled out all the fields, submit the form.

## Field-by-Field Explanation
* **Party Booking Form** (`party_booking_form_page_1`, text, optional): Fill out a brief description of the event, if desired. This field is optional, but it's a good idea to provide a short introduction or context for the event.
* **Guest Name** (`guest_name`, text, optional): Enter the name(s) of the guest(s) attending the event.
* **Event Name** (`event_name`, text, optional): Enter the name of the event or gathering.
* **Event Date** (`event_date`, date, optional): Select the date for the event. This field accepts date formats in the format MM/DD/YYYY.
* **Event Time** (`event_time`, time, optional): Select the time for the event. This field accepts time formats in the format HH:MM. 

## Tips
* Make sure to fill out all the required fields accurately.
* Double-check your information for accuracy before submitting the form.
* If you have any questions or concerns, feel free to contact us at form@gic.mx.
