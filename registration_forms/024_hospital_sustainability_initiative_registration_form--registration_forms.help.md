# Hospital Sustainability Initiative Registration Form - Help Guide
## Purpose
The Hospital Sustainability Initiative Registration Form is designed for participants to register their participation and provide information about themselves, their events, and their hospitals. This form is used to collect and process data for the sustainability initiative.

## How To Complete This Form
1. Fill in the required fields (marked as required): Participant Name, Hospital Name, Hospital Location, Department, Role, Event Start Date, Event Start Time, Event End Date, Event End Time, Participant Arrival Time, Participant Image, Participant File, Participant Video, and Hospital Image.
2. If applicable, fill in the optional fields (not marked as required): Event ID, Participant Email, Participant Phone, Participant Note, Event Type, Event Status, Participant Deduction, Participant Comment, Hospital Video, Hospital File, and Hospital Video Description.

## Field-by-Field Explanation
- **Participant Name** (`participant_name`, text, required): Enter the name of the participant.
- **Event ID** (`event_id`, number, optional): Enter the event ID if applicable.
- **Participant Email** (`participant_email`, email, optional): Enter the participant's email address.
- **Participant Phone** (`participant_phone`, text, optional): Enter the participant's phone number.
- **Participant Note** (`participant_note`, text, optional): Enter any additional notes about the participant.
- **Hospital Name** (`hospital_name`, text, required): Enter the name of the hospital.
- **Hospital Location** (`hospital_location`, text, required): Enter the location of the hospital.
- **Department** (`department`, text, required): Enter the department of the hospital.
- **Role** (`role`, text, required): Enter the role of the participant in the hospital.
- **Event Type** (`event_type`, select_one, optional): Select 'Yes' if the event is a sustainability initiative event.
- **Event Status** (`event_status`, select_one, optional): Select the status of the event (Event Scheduled, Event Ended, Event In Progress).
- **Event Start Date** (`event_start_date`, date, required): Enter the start date of the event.
- **Event Start Time** (`event_start_time`, time, required): Enter the start time of the event.
- **Event End Date** (`event_end_date`, date, required): Enter the end date of the event.
- **Event End Time** (`event_end_time`, time, required): Enter the end time of the event.
- **Participant Arrival Time** (`participant_arrival_time`, time, required): Enter the participant's arrival time.
- **Participant Image** (`participant_image`, note, required): Upload an image of the participant.
- **Participant File** (`participant_file`, text, required): Upload a file about the participant.
- **Participant Video** (`participant_video`, text, required): Upload a video about the participant.
- **Hospital Image** (`hospital_image`, note, optional): Upload an image of the hospital (if applicable).
- **Hospital File** (`hospital_file`, text, optional): Upload a file about the hospital (if applicable).
- **Hospital Video** (`hospital_video`, text, optional): Upload a video about the hospital (if applicable).
- **Hospital Video Description** (`hospital_video_description`, text, optional): Enter a description of the hospital video (if applicable).
- **Participant Deduction** (`participant_deduction`, text, optional): Enter any deductions or comments about the participant.
- **Participant Comment** (`participant_comment`, text, optional): Enter any additional comments about the participant.
- **Participant Video** (`participant_video`, text, optional): This field seems to be a duplicate of the "Participant Video" field, please check with the form owner to clarify the intent. (Required for now, but this should be reviewed).
- **Tips**: Please ensure that all required fields are filled in before submission to avoid any errors or incomplete data.
