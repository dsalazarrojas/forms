# Environmental Impact Review Registration - Help Guide

## Purpose
The Environmental Impact Review Registration form is used to register projects that require an environmental impact review. This form collects information about project details, agency involvement, and review deadlines.

## How To Complete This Form

1. Fill in the project's registration number.
2. Provide a brief description of the project in the "Project Details" field.
3. Enter the agency's name and contact information (email and phone number) in their respective fields.
4. Choose whether the project requires a review in the "Review Requests" field.
5. Select the project status (Open, In Progress, or Closed) in the "Project Status" field.
6. Set the review deadlines (start and end dates) and start date for the review process.
7. Finally, submit the form to register the project for the environmental impact review process.

## Field-by-Field Explanation

* **Project Registration** (`project_registration`, number, required): Enter the project's registration number, which is a unique identifier for the project.
* **Project Details** (`project_details`, text, required): Provide a brief description of the project, including its purpose and scope.
* **Agency Details** (`agency_details`, text, required): Enter the agency's name and contact information, including their email address and phone number.
* **Consultant Details** (`consultant_details`, text, optional): Enter the consultant's name and contact information, including their email address and phone number. This field is optional as some projects may not require a consultant.
* **Review Requests** (`review_requests`, select multiple, required): Check the box if the project requires a review.
* **Review Deadlines** (`review_deadlines`, date, required): Set the end date for the review process.
* **Review Start Date** (`review_start_date`, time, required): Set the start date for the review process.
* **Review End Date** (`review_end_date`, time, required): Set the end date for the review process.
* **Project Status** (`project_status`, select one, required): Select the current status of the project (Open, In Progress, or Closed).
* **Agency Email** (`agency_email`, email, required): Enter the agency's email address.
* **Agency Phone** (`agency_phone`, text, required): Enter the agency's phone number.

## Tips
* Make sure to fill in all required fields accurately and completely.
* Double-check the project's registration number and agency's contact information for accuracy.
* Ensure the review deadlines and start date align with the project's schedule.
* Select the correct project status to reflect its current state.
