# professional_event_registration_form - Help Guide
## Purpose
This form is used for registering a professional event, providing necessary details such as event name, dates, type, location, and contact information.

## How To Complete This Form

To complete this form, please follow these steps:

1. Review the form sections carefully and ensure you have all the required information before proceeding.
2. Select the appropriate options for each field as prompted.
3. Fill in the event details such as event name, start date, end date, event type, event location, event description, event status, and event link.
4. Enter the contact person and contact email for the event.

## Field-by-Field Explanation

* **Main Details** (`Yes/No`, required: false):
	+ Select "Yes" if you are registering a new event.
	+ Select "No" if you are updating an existing event details.
* **Event Name** (`text`, required: false):
	+ Enter a brief and descriptive name of the event.
* **Start Date** (`date`, required: false):
	+ Enter the start date of the event in the required format (YYYY-MM-DD).
* **End Date** (`date`, required: false):
	+ Enter the end date of the event in the required format (YYYY-MM-DD).
* **Event Type** (`select_one`, required: false):
	+ Choose the type of event (In-person, Online).
* **Event Location** (`text`, required: false):
	+ Enter the location of the event.
* **Event Capacity** (`number`, required: false):
	+ Enter the expected number of attendees for the event.
* **Event Description** (`text`, required: false):
	+ Enter a brief description of the event.
* **Event Status** (`select_one`, required: false):
	+ Choose the status of the event (Scheduled, Confirmed, Postponed).
* **Event Link** (`text`, required: false):
	+ Enter a link to the event website or additional information.
* **Contact Person** (`text`, required: false):
	+ Enter the name of the person responsible for the event.
* **Contact E-mail** (`email`, required: false):
	+ Enter the email address of the contact person.

## Tips

* Ensure that all fields are filled in accurately and thoroughly.
* Double-check the event details before submitting the form.
* If you are unsure about any field, please consult with the event owner or contact us for assistance.
