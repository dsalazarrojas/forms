# Virtual Shopping Assistant Demo Registration - Help Guide
## Purpose
This guide will walk you through completing the Virtual Shopping Assistant Demo Registration form, which is used to register leads for a virtual shopping assistant demo. This form will be used by the sales team to gather information from the lead and schedule demo sessions.

## How To Complete This Form

To complete this form, follow these steps:

1. Fill out the required information, including:
   * Phone: Enter the lead's phone number
   * Email: Enter the lead's email address
2. Fill out any additional information as desired, including:
   * Lead Details: Enter any relevant details about the lead
   * Goals: Enter the lead's goals for the virtual shopping assistant demo
   * Preferred Time Slots: Select the lead's preferred time slots for the demo
   * Notes: Enter any additional notes about the lead
   * Category: Enter the lead's category
   * Description: Enter a description of the lead
   * Assigned Tool: Select the tool to be used for communication with the lead (e.g. Chat, Email, Phone, SMS, WhatsApp, or Slack)
   * Form ID: Enter a unique ID number
   * Output File: Enter the output file number
   * Assigned Tool 2: Select the second tool to be used for communication with the lead (e.g. Chat, Email, Phone, SMS, WhatsApp, or Slack)
   * Assigned Tool 3: Select the third tool to be used for communication with the lead (e.g. Chat, Email, Phone, SMS, WhatsApp, or Slack)

## Field-by-Field Explanation

* **Lead Details**: Enter any relevant details about the lead. This field is optional.
* **Goals**: Enter the lead's goals for the virtual shopping assistant demo. This field is optional.
* **Preferred Time Slots**: Select the lead's preferred time slots for the demo. This field is a select multiple field, allowing you to select one or more time slots.
* **Email**: Enter the lead's email address. This field is optional but required for communication.
* **Phone**: Enter the lead's phone number. This field is optional.
* **Notes**: Enter any additional notes about the lead. This field is optional.
* **Category**: Enter the lead's category. This field is optional.
* **Description**: Enter a description of the lead. This field is optional.
* **Output File**: Enter the output file number. This field is optional.
* **Assigned Tool**: Select the tool to be used for communication with the lead (e.g. Chat, Email, Phone, SMS, WhatsApp, or Slack). This field is optional.
* **Assigned Tool 2**: Select the second tool to be used for communication with the lead (e.g. Chat, Email, Phone, SMS, WhatsApp, or Slack). This field is optional.
* **Assigned Tool 3**: Select the third tool to be used for communication with the lead (e.g. Chat, Email, Phone, SMS, WhatsApp, or Slack). This field is optional.

## Tips

* Make sure to fill out all required fields.
* Be as specific as possible when entering information in the fields.
* If you are unsure about any field, contact the sales team for assistance.
