# Change Of Address Request Form - Help Guide
## Purpose
The Change of Address Request Form is used to request changes to an individual's address. This form is typically used by individuals who are moving to a new address and need to update their records with the organization.

## How To Complete This Form
To complete this form, follow these steps:

1. Select a date for the request.
2. Enter the individual's name.
3. Enter the individual's date of birth (if applicable).
4. Enter the individual's identification number or account number (if applicable).
5. Enter the individual's email address and phone number.
6. Enter the current address details (street, city, state, and zip code).
7. Enter the number of years the individual has been at the current address.
8. Enter the new address details (street, city, state, and zip code).
9. Select the effective date of the change.
10. Select a reason for the move (if desired).
11. List previous addresses (if requested by the organization).
12. Select how you would like to receive confirmations (if applicable).
13. Indicate if documentation has been attached (if applicable).
14. Confirm the accuracy of the information provided.

## Field-by-Field Explanation
* **Request Date (ID 1)**: The date on which this change of address request is submitted.
* **Person's Name (ID 2)**: The individual's full legal name.
* **Date of Birth (ID 3)**: A verification date used to confirm identity.
* **Identification or Account Number (ID 4)**: A government-issued ID or account number for verification.
* **Email Address (ID 5)**: The individual's contact email address.
* **Phone Number (ID 6)**: The individual's contact phone number.
* **Current Address - Street (ID 7)**: The street address of the current location.
* **Current Address - City (ID 8)**: The city of the current location.
* **Current Address - State (ID 9)**: The state or province of the current location.
* **Current Address - Zip Code (ID 10)**: The postal code of the current location.
* **Years at Current Address (ID 11)**: The number of years the individual has been at the current address.
* **New Address - Street (ID 12)**: The street address of the new location.
* **New Address - City (ID 13)**: The city of the new location.
* **New Address - State (ID 14)**: The state or province of the new location.
* **New Address - Zip Code (ID 15)**: The postal code of the new location.
* **Effective Date of Change (ID 16)**: The date on which the address change will take effect.
* **Reason for Moving (ID 17)**: The reason for the address change (optional).
* **List Previous Addresses (ID 18)**: A list of previous addresses, if requested by the organization.
* **Notification Preference (ID 19)**: How to receive confirmations, if applicable.
* **Documentation Attached (ID 20)**: Indication of whether documentation has been attached.
* **I Verify This Information is Correct (ID 21)**: Confirmation of the accuracy of the information provided.
