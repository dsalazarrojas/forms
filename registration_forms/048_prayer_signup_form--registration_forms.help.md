# Prayer Signup Form - Help Guide
## Purpose
The Prayer Signup Form is a registration form designed to collect information from users who wish to participate in a prayer session. This form is required for all attendees.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in your full name in the "Full Name" field.
2. Enter your email address in the "Email" field. Please ensure this is a valid email address that you will have access to.
3. Choose the correct "Event" from the dropdown menu. If you are unsure, please contact the event organizer.
4. Select a date for the prayer session from the date picker. If no date is selected, you can leave it blank.
5. Choose a time for the prayer session from the time picker. If no time is selected, you can leave it blank.
6. You can add any notes or comments you would like to share with the prayer team in the "Note" field.
7. If you have a prayer request, you can share it in the "Prayer Request" field.

## Field-by-Field Explanation
* **Full Name (Text)**: Enter your full name as it appears on your official documents. This is a required field, so make sure to fill it in accurately.
* **Email (Email, Required)**: Enter a valid email address that you will have access to.
* **Phone (Text, Optional)**: You can enter your phone number if you would like to be contacted for any last-minute reminders or updates.
* **Event (Select One, Required)**: Choose the correct event from the dropdown menu. If you are unsure, please contact the event organizer.
* **Date (Date, Optional)**: Select a date for the prayer session. If no date is selected, you can leave it blank.
* **Time (Time, Optional)**: Choose a time for the prayer session. If no time is selected, you can leave it blank.
* **Note (Note, Optional)**: Add any notes or comments you would like to share with the prayer team.
* **Prayer Request (Text, Optional)**: Share any prayer requests you would like to make with the prayer team.
