# HR Collaboration Networking Event Registration - Help Guide

## Purpose
The HR Collaboration Networking Event Registration form is designed to collect information about attendees, including their interests, consent, and details for the HR Collaboration Networking Event. This information will be used to plan and organize the event effectively.

## How To Complete This Form

To complete this form, please follow these steps:

1. **Enter your event details**: Fill in the Event Name, Location, and Date fields with the details of the event you are registering for.
2. **Provide event details**: Enter the Start Date, End Date, and Time of the event. If applicable, also fill in the Duration field to specify the event duration.
3. **Specify event capacity**: Enter the Capacity field to indicate the number of attendees expected at the event.
4. **Add event description and tags**: Enter a brief description of the event and add any relevant tags to help identify it.
5. **Enter event organizer details**: Fill in the Organizer, Title, and Organization fields with the name, title, and organization name of the event organizer.
6. **Enter attendee details**: Answer the Attendees' Interests questions to indicate their interests in attending the event. If attending, provide consent by selecting an option from the Consent field.
7. **Enter contact information**: If you are the event organizer or have any other contact information, fill in the Name, Email, Phone, and Note fields.
8. **Complete any other fields**: Fill in any other fields that apply to you, such as Employees, Manager, Department, Job Title, Work Email, and Work Phone.

## Field-by-Field Explanation

* **Event Name**: Enter the name of the event, e.g., "HR Collaboration Networking Event".
*   **Location**: Enter the location of the event, e.g., "Conference Room, Building 3".
*   **Start Date**: Enter the date of the event start, using the format "MM/DD/YYYY".
*   **End Date**: Enter the date of the event end, using the format "MM/DD/YYYY".
*   **Time**: Enter the time of the event, using the format "HH:MM AM/PM".
*   **Duration**: Enter the duration of the event, e.g., "1 hour".
*   **Capacity**: Enter the number of attendees expected at the event.
*   **Description**: Enter a brief description of the event.
*   **Tags**: Enter any relevant tags to help identify the event.
*   **Organizer**: Enter the name of the event organizer.
*   **Title**: Enter the title of the event organizer.
*   **Organization**: Enter the name of the event organizer's organization.
*   **Name**: Enter your name as the attendee or event contact.
*   **Email**: Enter your email address.
*   **Phone**: Enter your phone number.
*   **Note**: Enter any additional notes for the event contact.
*   **Attendees' Interests**: Select "Yes" if you are interested in attending the event, and "No" otherwise.
*   **Consent**: Select your consent option for attending the event.
*   **Consent Note**: Enter any additional notes for your consent.
*   **Employees**: Select "Yes" if you are attending as an employee, and "No" otherwise.
*   **Manager**: Select "Yes" if you are attending as a manager, and "No" otherwise.
*   **Department**: Select "Yes" if you are attending from a department, and "No" otherwise.
*   **Job Title**: Select "Yes" if you have a job title, and "No" otherwise.
*   **Work Email**: Enter your work email address.
*   **Work Phone**: Enter your work phone number.

Note: The form has been designed to be user-friendly and easy to navigate. If you have any questions or need further assistance, please do not hesitate to ask.
