# solo_event_registration_form - Help Guide
## Purpose
The solo_event_registration_form is used to register a solo event. This form captures essential details about the event, including its name, date, start and end time, organizer, attendee name, email, and phone number.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the event name in the "Event Name" field.
2. Select the date of the event in the "Event Date" field.
3. Choose the start time of the event in the "Event Start Time" field.
4. Choose the end time of the event in the "Event End Time" field.
5. Enter the name of the event organizer in the "Organizer" field.
6. Enter the name of the attendee in the "Attendee Name" field.
7. Enter the email of the attendee in the "Attendee Email" field.
8. Enter the phone number of the attendee in the "Attendee Phone" field.

## Field-by-Field Explanation
* **Event Name** (`event_name`, text, required: false): Enter the name of the event you are registering.
* **Event Date** (`event_date`, date, required: false): Select the date of the event.
* **Event Start Time** (`event_start_time`, time, required: false): Choose the start time of the event.
* **Event End Time** (`event_end_time`, time, required: false): Choose the end time of the event.
* **Organizer** (`organizer`, text, required: false): Enter the name of the event organizer.
* **Attendee Name** (`attendee_name`, text, required: false): Enter the name of the attendee.
* **Attendee Email** (`attendee_email`, email, required: false): Enter the email of the attendee.
* **Attendee Phone** (`attendee_phone`, text, required: false): Enter the phone number of the attendee.

## Tips
- Ensure that you fill in all the required fields accurately and completely to ensure successful registration.
- If you're unsure about any field, refer to the event details provided by the event organizer.
- If you're registering a recurring event, please use the "recurring_event_registration_form" instead.
