# Intercessors Event Registration - Help Guide
## Purpose
This form is used to collect information from attendees for intercessors events, allowing the organizers to tailor the event according to their interests and preferences.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the session you would like to attend by choosing one option from the Session Selection dropdown list.
2. Indicate your volunteer interests by selecting multiple options from the Volunteer Interest list.
3. Fill in your attendee details in the text field provided.
4. Provide the date of the event by selecting the date from the calendar.
5. Select the event time by choosing the time from the time dropdown list.
6. Choose the session start and end times by selecting the times from the time dropdown lists.
7. Indicate the session length in hours.

## Field-by-Field Explanation
* **Session Selection** (`session_selection`, select_one, required: false): Choose the session you would like to attend from the dropdown list.
* **Volunteer Interest** (`volunteer_interest`, select_multiple, required: false): Select multiple volunteer interests to express your willingness to help.
* **Attendee Details** (`attendee_details`, text, required: false): Provide any additional information about yourself as an attendee.
* **Event Date** (`event_date`, date, required: false): Select the date of the event from the calendar.
* **Event Time** (`event_time`, time, required: false): Choose the time of the event from the time dropdown list.
* **Session Start Time** (`session_start_time`, time, required: false): Select the start time of the session from the time dropdown list.
* **Session End Time** (`session_start_time`, time, required: false): Select the end time of the session from the time dropdown list. (Note: There seems to be a typo in the original YAML. The field name is "session_start_time" but it should likely be "session_end_time" to match the label and purpose.)
* **Session Length** (`session_length`, number, required: false): Indicate the session length in hours.
* **Event Location** (`event_location`, text, required: false): Enter the location of the event.

## Tips

* Please ensure to select the correct session and start/end times to ensure you can attend the event.
* If you are interested in multiple sessions, select the option that best represents your preferences.
* Be accurate when providing attendee details to ensure the organizers have accurate information.
* If you are unsure about the event date or location, contact the event organizers for confirmation.
