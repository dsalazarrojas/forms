# Networking Event Registration Form - Help Guide
## Purpose
This form is designed to collect information from attendees for a Networking Event. Please note that this form is not affiliated with, endorsed by, or derived from any form platform. It was created using publicly available metadata as inspiration.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the `event_details` page with the necessary information about the event.
2. Move on to the `attendee_details` page and enter the relevant details about the attendee.

## Field-by-Field Explanation

* **Event Details (event_details)**: This field is where you can enter information about the event. Please provide the title, location, date, and any other relevant details about the event.
* **Attendee Details (attendee_details)**: This field is where you can enter information about the attendees. Please provide the attendee's name, contact information, and any other relevant details about them.
* **Note (note)**: This field is an optional field for any additional notes or comments you may want to add about the attendee or event.

## Tips
- Make sure to fill out the form completely and accurately to ensure that the data is recorded correctly.
- If you are unsure about any field, you can contact [form@gic.mx](mailto:form@gic.mx) for assistance.
