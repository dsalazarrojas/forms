# Nurse Anesthetist Registration Form - Help Guide

## Purpose
The Nurse Anesthetist Registration Form is designed to collect information from nurse anesthetists for registration and verification purposes. The form is used to gather contact details, education background, certification information, and licensure data.

## How To Complete This Form

To complete this form, please follow these steps:

1. Fill in your **First Name** in the "First Name" field (page 1). Enter your name as it is recorded on your identification documents.
2. Fill in your **Last Name** in the "Last Name" field (page 1). Enter your name as it is recorded on your identification documents.
3. Enter your **Address** in the "Address" field (page 1). Provide your mailing address as it is recorded on your identification documents.
4. Enter your **Email** in the "Email" field (page 1). This will be used for communication purposes.
5. Enter your **Phone** number in the "Phone" field (page 1). This will be used for communication purposes.
6. Enter your **Fax** number in the "Fax" field (page 1). This will be used for communication purposes.
7. Enter your **Date Of Birth** in the "Date Of Birth" field (page 2). Enter in the format MM/dd/yyyy.
8. Enter your **Date Of Completion** in the "Date Of Completion" field (page 2). Enter in the format MM/dd/yyyy.
9. Enter your **Nurse ID Number** in the "Nurse ID Number" field (page 2). Enter the number assigned to you by the relevant authority.
10. Select your **License Type** from the "License Type" field (page 3). Choose from Active, Inactive, or Expired.
11. Select **Yes/No** for **Medical School Attended** (page 3). If you have attended medical school, select "Yes". If not, select "No".
12. Select **Yes/No** for **Medical School Degree** (page 3). If you have a degree from medical school, select "Yes". If not, select "No".
13. Select **Yes/No** for **Medical Board License** (page 3). If you have a medical board license, select "Yes". If not, select "No".
14. Select **Yes/No** for **Certification Number** (page 3). If you have a certification number, select "Yes". If not, select "No".
15. Enter your **Certification Date** in the "Certification Date" field (page 3). Enter in the format MM/dd/yyyy.
16. Select **Yes/No** for **Specialty** (page 4). If you have a specialty, select "Yes". If not, select "No".
17. Select **Yes/No** for **State License Issued** (page 4). If you have a state license, select "Yes". If not, select "No".
18. Enter your **State License Expire Date** in the "State License Expire Date" field (page 4). Enter in the format MM/dd/yyyy.
19. Select **Yes/No** for **US Nurse License Issued** (page 4). If you have a US nurse license, select "Yes". If not, select "No".
20. Enter your **US Nurse License Expire Date** in the "US Nurse License Expire Date" field (page 4). Enter in the format MM/dd/yyyy.
21. Select **Yes/No** for **Medical Malpractice Claim** (page 5). If you have a medical malpractice claim, select "Yes". If not, select "No".
22. Select **Yes/No** for **Professional Boards** (page 5). If you have passed professional boards, select "Yes". If not, select "No".
