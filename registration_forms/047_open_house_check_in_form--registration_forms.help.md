# Open House Check In Form - Help Guide
## Purpose
The Open House Check In Form is designed to collect information from visitors, agents, and staff for events and open houses. This form helps us track attendance, note-taking, and other relevant details. Please ensure you're completing this form only once for each event.

## How To Complete This Form
To complete this form, follow these steps:

1. Start by filling out your personal details:
	* Enter your first name in the First Name field.
	* Enter your last name in the Last Name field.
	* Provide your email address in the Email field.
	* Enter your phone number in the Phone field.
2. Enter the event details:
	* Select the event date from the calendar in the Event Date field.
	* Enter the agent's name in the Agent Name field.
	* Enter the agent's phone number in the Agent Phone field.
	* Choose the lead status (Open House Lead or Not a Lead) in the Lead Status field.
3. Add any additional notes about the event in the Notes field.
4. Complete the event address:
	* Enter the event address in the Event Address field.
	* Select the event city from the dropdown list in the Event City field.
	* Select the event state from the dropdown list in the Event State field.
	* Enter the event zip code in the Event Zip field.
5. Add any event-specific notes in the Event Notes field.
6. Finally, enter your user ID and the event ID, if applicable.

## Field-by-Field Explanation

* **First Name** (Text, Required): Enter your first name.
* **Last Name** (Text, Required): Enter your last name.
* **Email** (Email, Required): Enter your email address.
* **Phone** (Text, Optional): Enter your phone number.
* **Event Date** (Date, Required): Select the event date from the calendar.
* **Agent Name** (Text, Optional): Enter the agent's name.
* **Agent Phone** (Text, Optional): Enter the agent's phone number.
* **Lead Status** (Select One, Optional): Choose whether this is an Open House Lead or Not a Lead.
* **Notes** (Note, Optional): Add any notes about yourself or the event.
* **Event Address** (Text, Optional): Enter the event address.
* **Event City** (Select One, Optional): Select the event city from the dropdown list.
* **Event State** (Select One, Optional): Select the event state from the dropdown list.
* **Event Zip** (Text, Optional): Enter the event zip code.
* **Event Notes** (Note, Optional): Add any notes about the event.
* **User ID** (Text, Optional): Enter your user ID, if applicable.
* **Event ID** (Text, Optional): Enter the event ID, if applicable.
* **Date** (Date, Optional): Enter the event date.
* **Time** (Time, Optional): Enter the event time.
* **Event Time** (Time, Optional): Enter the event time.
* **Event** (Text, Optional): Enter the event name.

## Tips
* Please ensure that you're only completing this form once for each event.
* For lead status, choose Open House Lead only if the visitor is interested in the event or property.
* Use the Event Notes field to note any important details about the event or visitor.
* If you have any issues or concerns while filling out this form, feel free to reach out to us for assistance.
