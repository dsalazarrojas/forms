# Pet Rescue Intake Form - Help Guide

## Purpose
The Pet Rescue Intake Form is designed to collect information about pet rescues for an animal shelter or similar organization. This form helps gather essential details about the pet and its owner, which will aid in providing proper care and support for the pet.

## How To Complete This Form

To complete this form, follow the steps below:

1. Select the relevant options for the pet owner's status by choosing "Yes" or "No" for questions about the pet owner's relationship with the pet.
2. Enter the pet's name in the "pet_name" field.
3. Choose the pet's breed from the available options.
4. Select the pet's age by choosing multiple options (e.g., "Yes" for 1-year-old, "Yes" for 2-year-old, etc.).
5. Select the pet's type from the available options.
6. Enter the date of the pet's rescue in the "rescue_date" field using the correct date format (YYYY-MM-DD).
7. Provide the location where the pet was rescued from in the "intake_location" field.
8. Enter the owner's email address in the "owner_email" field.

## Field-by-Field Explanation
* **pet_owner**: 
  * Type: Select One
  * Label: pet_owner
  * Purpose: Indicate if the owner is the pet's owner. This field helps the organization understand the owner's relationship with the pet.
* **pet_name**:
  * Type: Text
  * Label: pet_name
  * Purpose: Enter the pet's name.
* **pet_breed**:
  * Type: Select One
  * Label: pet_breed
  * Purpose: Choose the pet's breed from the available options.
* **pet_age**:
  * Type: Select Multiple
  * Label: pet_age
  * Purpose: Select the pet's age by choosing multiple options.
* **pet_type**:
  * Type: Select One
  * Label: pet_type
  * Purpose: Select the pet's type from the available options.
* **rescue_date**:
  * Type: Date
  * Label: rescue_date
  * Purpose: Enter the date the pet was rescued in the correct format (YYYY-MM-DD).
* **intake_location**:
  * Type: Text
  * Label: intake_location
  * Purpose: Provide the location where the pet was rescued from.
* **owner_email**:
  * Type: Email
  * Label: owner_email
  * Purpose: Enter the owner's email address for contact and communication purposes.
