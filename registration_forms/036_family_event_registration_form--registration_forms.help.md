# Family Event Registration Form - Help Guide
## Purpose
This form is used to collect event registration information for family events, providing a convenient and structured way for event hosts to gather necessary details about their events.

## How To Complete This Form
To complete this form, follow these steps:

1. Start by filling out the **Event Details** page with the name and brief description of the event.
2. Move on to the **Ticket Information** page, where you can indicate whether tickets are available for the event and, if so, select the number of tickets you require.
3. On the **Contact Information** page, enter the host's contact information, including their phone number and email.
4. Proceed to the **Event Date** and **Event Time** page to provide the date and time of the event.
5. Next, enter the **Event Location** and **Event Description** fields with the details of the event's location and a brief description.
6. On the **Event Host** page, enter the host's contact information, including their name, email, phone number, and address.
7. Finally, enter the **Guest Information** page with the guest's contact information, including their name, phone number, and email.

## Field-by-Field Explanation
### Event Details
* **Event Details** (`Event Details`, text, optional): Enter the name and brief description of the event.

### Ticket Information
* **Ticket Information** (`Ticket Information`, text, optional): Indicate whether tickets are available for the event and, if so, select the number of tickets you require.

### Contact Information
* **Contact Information** (`Contact Information`, text, optional): Enter the host's contact information, including their name, phone number, and email.

### Event Date
* **Event Date** (`Event Date`, date, optional): Enter the date of the event.

### Event Time
* **Event Time** (`Event Time`, time, optional): Enter the time of the event.

### Event Location
* **Event Location** (`Event Location`, text, optional): Enter the location of the event.

### Event Description
* **Event Description** (`Event Description`, text, optional): Enter a brief description of the event.

### Event Tickets
* **Tickets** (`Event Tickets`, select multiple, optional): Select the number of tickets you require for the event.

### Ticket Type
* **Ticket Type** (`Ticket Type`, select one, optional): Select whether tickets are available for the event.

### Ticket Price
* **Ticket Price** (`Ticket Price`, number, optional): Enter the price of each ticket.

### Ticket Quantity
* **Ticket Quantity** (`Ticket Quantity`, number, optional): Enter the number of tickets required.

### Event Capacity
* **Event Capacity** (`Event Capacity`, number, optional): Enter the total capacity of the event.

### Registration Fee
* **Registration Fee** (`Registration Fee`, number, optional): Enter the registration fee for the event.

### Event Host
* **Event Host** (`Event Host`, text, optional): Enter the host's name.

### Event Host Email
* **Event Host Email** (`Event Host Email`, email, optional): Enter the host's email.

### Event Host Phone
* **Event Host Phone** (`Event Host Phone`, text, optional): Enter the host's phone number.

### Event Host Address
* **Event Host Address** (`Event Host Address`, text, optional): Enter the host's address.

### Event Host Note
* **Event Host Note** (`Event Host Note`, note, optional): Enter any additional notes from the host.

### Guest Information
* **Guest Information** (`Guest Information`, text, optional): Enter the guest's contact information, including their name, phone number, and email.

### Guest Name
* **Guest Name** (`Guest Name`, text, optional): Enter the guest's name.

### Guest Address
* **Guest Address** (`Guest Address`, text, optional): Enter the guest's address.

### Guest Phone
* **Guest Phone** (`Guest Phone`, text, optional): Enter the guest's phone number.

### Guest Email
* **Guest Email** (`Guest Email`, email, optional): Enter the guest's email.

### Guest Note
* **Guest Note** (`Guest Note`, note, optional): Enter any additional notes from the guest.

### Form Submission
* **Form Submission** (`Form Submission`, text, optional): Enter any additional comments about the form submission.

## Tips
* Be thorough when filling out the form, as incomplete information may lead to delays or errors.
* Review each field carefully to ensure accurate and complete information is entered.
