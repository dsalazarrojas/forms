# Rally Class Registration Form - Help Guide
## Purpose
The Rally Class Registration Form is designed to collect participant information for a rally class. This form is used to register participants and their corresponding details.

## How To Complete This Form
To complete this form, follow the steps below:

1.  Fill in the required fields for each participant, including first and last name, email, phone number, participant name, participant email, and class date.
2.  Ensure the confirm email field matches the email provided earlier.
3.  Choose the appropriate instructor and payment type from the available options.
4.  Add participant notes and instructor notes for additional information.
5.  Finally, click the "Submit" button to complete your registration.

## Field-by-Field Explanation
*   **First Name** (`first_name`, text, required): This field is used to record the participant's first name.
*   **Last Name** (`last_name`, text, required): This field is used to record the participant's last name.
*   **Email** (`email`, email, required): This field is used to record the participant's email address.
*   **Confirm Email** (`email_confirmation`, email, required): This field is used to confirm the participant's email address.
*   **Phone** (`phone`, text, required): This field is used to record the participant's phone number.
*   **Participant Name** (`participant_name`, text, required): This field is used to record the participant's name for the class.
*   **Class Date** (`class_date`, date, required): This field is used to record the date of the class.
*   **Participant Email** (`participant_email`, email, required): This field is used to record the participant's email address for class communication.
*   **Instructor** (`instructor`, select_one, required): This field is used to select the instructor for the class.
*   **Event Date** (`event_date`, date, required): This field is used to record the date of the event.
*   **Participant Notes** (`participant_notes`, note, required): This field is used to record any additional notes about the participant.
*   **Instructor Notes** (`instructor_notes`, note, required): This field is used to record any additional notes about the instructor.
*   **Payment Type** (`payment_type`, select_one, required): This field is used to select the payment type for the class.
*   **Submit** (`submit`, text, required): This field is used to complete the registration.
