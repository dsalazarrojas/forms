# Primary School Enrollment Form - Help Guide
## Purpose
The Primary School Enrollment Form is a document used to gather essential information about students applying for or enrolling in a primary school. This form is intended to collect personal details that will help the school administration process the enrollment smoothly.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the student's name accurately.
2. Enter the student's birthdate.
3. Input the student's school name.
4. Enter the student's email address (if available).
5. Enter the student's phone number (if available).

## Field-by-Field Explanation

* **Student Name (Student Name, Text, Required)**: This field is where you'll input the student's full name.
* **Student Birthdate (Student Birthdate, Date, Required)**: Enter the student's birthdate, as it is an essential detail for the school's record.
* **School Name (Student School Name, Text, Required)**: Enter the name of the school the student will be attending or is already attending.
* **Student Email (Student Email, Email, Optional)**: If the student has an email address, please enter it here. This will help the school maintain communication with the student or the student's family.
* **Student Phone (Student Phone, Text, Optional)**: If the student has a phone number, please input it here. This will be helpful for contact and communication purposes.

## Tips

* Ensure accuracy and correctness when filling in the form details.
* Double-check that all fields are filled accurately before submitting the form.
* If you're enrolling or applying for a student, please fill in the form once for each student to avoid duplication.
* Contact the school for any queries or assistance required while filling this form.
