# Vial Vault Registration Form - Help Guide
## Purpose
The Vial Vault Registration Form is used to register vials, providing critical information about their storage conditions and related details. This form helps to ensure accurate records and efficient inventory management.

## How To Complete This Form
To complete the form, follow these steps:

1. Choose the correct vial type from the select one options.
2. Enter the number of vials.
3. Select a storage start date.
4. Enter the contact name, email, and phone number.
5. Select the submitter name.

## Field-by-Field Explanation
* **Vial Type**: Select one of the following options:
	+ Red
	+ Green
	+ Blue
* **Vial Quantity**: Enter the number of vials you are registering.
* **Storage Start Date**: Enter the date when the storage is scheduled to start.
* **Contact Name**: Enter the name of the person in charge of the storage.
* **Contact Email**: Enter the email address of the person in charge of the storage.
* **Contact Phone**: Enter the phone number of the person in charge of the storage.
* **Submitter**: Select one of the following options:
	+ chatjimmy
	+ Other
* **Storage Location**: Enter the address where the vials are stored.
* **Storage Notes**: Enter any additional comments or notes about the storage conditions.
* **Storage Address**: Enter the address of the storage location.
* **Storage City**: Enter the city of the storage location.
* **Storage Zip**: Enter the zip code of the storage location.
* **Storage State**: Enter the state of the storage location.
* **Storage Country**: Enter the country of the storage location.
* **Storage Region**: Enter the region of the storage location.
* **Storage Street**: Enter the street address of the storage location.
* **Storage Suite**: Enter the suite or unit number of the storage location.
* **Storage Notes 2**: Enter any additional comments or notes about the storage conditions.
* **Storage Facility**: Enter the facility name of the storage location.
* **Storage Floor**: Enter the floor number of the storage location.
* **Storage Building**: Enter the building name of the storage location.
* **Storage Room**: Enter the room number of the storage location.
* **Storage Elevator**: Enter the elevator number of the storage location.
* **Storage Unit**: Enter the unit number of the storage location.
* **Submitter Name**: Enter the name of the person submitting the form.

**Tips**

* Double-check all fields for accuracy before submission.
* If unsure, consult with the relevant personnel or the form's purpose.
