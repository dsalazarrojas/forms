# mentorship_session_registration_form - Help Guide

## Purpose
This form is for registering participants for mentorship sessions. It collects information about the participant's details, session preferences, and submission preferences.

## How To Complete This Form

### Step 1: Fill out the participant information section

*   Participant Info: Enter a brief description of the participant (e.g., student name, ID, or other identifier).
*   Participant Name: Enter the name of the participant.
*   Participant Email: Enter the email address of the participant.
*   Participant Phone: Enter the phone number of the participant.

### Step 2: Select the organization type

*   Organization: Select the type of organization the participant is affiliated with (Mentorship Organization, Non-Profit Organization, or Government).

### Step 3: Specify the mentor information

*   Mentor Info: Choose the type of mentor (Mentor or Other) for the participant.

### Step 4: Provide session details

*   Date of Interest: Select the date of interest for the session.
*   Date of Session: Choose the date of the session.
*   Time of Session: Select the time of the session.
*   Session Length: Enter the duration of the session.
*   Session Type: Select the type of session (One-on-One Session, Group Session, or Virtual Session).
*   Session Frequency: Choose the frequency of the session (Daily, Weekly, or Biweekly).

### Step 5: Specify submission preferences

*   Session Topic: Enter a brief description of the session topic.
*   Notes: Add any additional notes about the session.
*   Submission Type: Select the type of submission (Manual, Auto, or Manual/Auto).
*   Submission Date: Enter the date of submission.
*   Submission Time: Select the time of submission.
*   Submission Status: Select the status of submission (Pending, Approved, or Rejected).
*   Mentorship Type: Select the type of mentorship (Mentorship, CoMentorship, or Both).
*   Session Status: Select the status of the session (Active, Inactive, or Scheduled).
*   Participant Agreement: Select the participant's agreement (Agreed, Declined, or No Agreement).

### Tips

*   Make sure to fill out all required fields.
*   Review your information carefully before submitting.
*   If you have any questions or need help, contact your administrator.
