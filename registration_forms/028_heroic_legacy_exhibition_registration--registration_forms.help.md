# Heroic Legacy Exhibition Registration - Help Guide
## Purpose
This guide will walk you through how to complete the Heroic Legacy Exhibition Registration form to ensure a smooth and successful submission process.

## How To Complete This Form
To complete this form, follow these steps:

1. **Enter your Exhibition Name**: Type the name of your exhibition in the field provided.
2. **Enter your Participant Name**: If you are the participant, enter your name in this field. Please note that this is an optional field, so you can leave it blank if you are submitting on behalf of someone else.
3. **Enter your Artwork Title**: Type the title of the artwork you are submitting.
4. **Enter your Artwork Description**: Provide a brief description of your artwork.
5. **Enter your Participant Email**: If you have a personal email associated with the exhibition, enter it here.
6. **Enter your Participant Phone**: If you have a phone number associated with the exhibition, enter it here.
7. **Upload Artwork Upload**: You will be able to upload a digital image of your artwork here. Please note that this field is optional.
8. **Select Artwork Type**: Choose the type of artwork you are submitting from the provided options.

## Field-by-Field Explanation

* **Exhibition Name**: This field is required and should contain the name of the exhibition you are submitting your artwork for.
  * Type: text
  * Purpose: Identifies the exhibition name

* **Participant Name**: This field is optional and should contain the name of the participant submitting their artwork. If left blank, the participant's name will be assumed to be the one submitting.
  * Type: text
  * Purpose: Identifies the participant's name

* **Artwork Title**: This field is optional and should contain a brief title of the artwork being submitted.
  * Type: text
  * Purpose: Identifies the artwork title

* **Artwork Description**: This field is optional and should contain a brief description of the artwork being submitted.
  * Type: text
  * Purpose: Provides additional information about the artwork

* **Participant Email**: This field is optional and should contain the email address of the participant or artist.
  * Type: email
  * Purpose: Provides contact information for the participant

* **Participant Phone**: This field is optional and should contain the phone number of the participant or artist.
  * Type: text
  * Purpose: Provides contact information for the participant

* **Artwork Upload**: This field is optional and allows you to upload a digital image of your artwork.
  * Type: text
  * Purpose: Enables you to upload artwork image

* **Artwork Type**: This field is optional and should contain the type of artwork you are submitting from the provided options.
  * Type: select_one
  * Purpose: Identifies the type of artwork

## Tips
* Please ensure that all required fields are completed before submitting the form.
* If you are experiencing technical difficulties with the form, please contact our support team for assistance.
* Please note that the uploaded artwork will be reviewed and curated before being featured in the exhibition.
