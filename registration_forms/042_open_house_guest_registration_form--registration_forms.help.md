# open_house_guest_registration_form - Help Guide
## Purpose
This form is designed for registering guests to an open house event. The form will be filled by the event's agents to collect essential information from guests who are expected to attend the open house.

## How To Complete This Form
1. Fill out the form completely and accurately.
2. Enter your Agent Name to identify yourself as an event agent.
3. If your agency has sent you, enter the name of the Agency you are representing.
4. Enter your contact Phone number for easy communication.
5. Provide a valid Email address for follow-up and communication.
6. Indicate the Event Time of the visit, using 24-hour format (e.g., 14:00).
7. Select the Event Date of the visit from the calendar.
8. Enter Property Details about the location and features of the property.
9. Enter a Lead Message with any specific requests or concerns.
10. If applicable, provide Agent Comments about the guest's behavior or any issues that may arise.
11. Optionally, add Visitor Comments if you have any feedback or notes about the guest.

## Field-by-Field Explanation

* **Agent Name** (`Agent Name`, text, required): Your name as an event agent.
* **Agency** (`Agency`, text, optional): If you are representing an agency, enter its name.
* **Phone** (`Phone`, text, optional): Enter your contact phone number for easy communication.
* **Email** (`Email`, email, required): Enter a valid email address for follow-up and communication.
* **Event Time** (`Event Time`, time, optional): Indicate the time of the visit using 24-hour format (e.g., 14:00).
* **Event Date** (`Event Date`, date, required): Select the date of the visit from the calendar.
* **Property Details** (`Property Details`, text, required): Enter information about the location and features of the property.
* **Lead Message** (`Lead Message`, text, required): Enter a Lead Message with any specific requests or concerns.
* **Agent Comments** (`Agent Comments`, text, optional): If applicable, provide comments about the guest's behavior or any issues that may arise.
* **Visitor Comments** (`Visitor Comments`, text, optional): If you have any feedback or notes about the guest, add them here.

Note: Make sure to fill out the required fields (Agent Name, Email, Event Date, and Property Details, and Lead Message) as they are essential for accurate guest data collection.
