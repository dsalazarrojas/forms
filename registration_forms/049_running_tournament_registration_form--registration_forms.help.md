# running_tournament_registration_form - Help Guide
## Purpose
The "running_tournament_registration_form" is a form designed to collect information from participants for a running tournament. This form is used to gather essential details such as participant names, contact information, team details, and event specifics. The form ensures that all necessary information is collected accurately and efficiently.

## How To Complete This Form
To complete this form, follow these steps:
1. Fill in the required fields marked with an asterisk (\*) in each section.
2. Double-check the accuracy of all the information provided before submission.
3. Review each field's label for a clear understanding of what it represents.

## Field-by-Field Explanation

- **Participant Name** (`participant_name`, `text`, required): Enter the name of the participant. This is the name of the person registering for the tournament.
*   **Email** (`participant_email`, `email`, required): Enter the email address of the participant. This will be used for communication and updates.
*   **Phone** (`participant_phone`, `text`, optional): Enter the phone number of the participant. This is not required but can be useful for contact purposes.
*   **Team Members** (`team_members`, `number`, required): Enter the number of team members participating in the tournament. This is crucial for team-related information.
*   **Team Tier** (`team_tier`, `select_one`, required): Select the tier of the team. Options include 1st place, 2nd place, 3rd place.
*   **Event Date** (`event_date`, `date`, required): Enter the date of the event. This is a crucial field for scheduling purposes.
*   **Event Time** (`event_time`, `time`, required): Enter the time of the event. This is also a key field for timing purposes.
*   **Location** (`location`, `text`, required): Enter the location of the event. This helps with logistics and directions.
*   **Age Group** (`age_group`, `select_one`, required): Select the age group of the participant. Options include 18-29, 30-39, 40-49, 50-59, 60-69, 70+.
*   **Gender** (`gender`, `select_one`, required): Select the gender of the participant. Options include Male, Female, Non-Binary.
*   **Shirt Size** (`shirt_size`, `select_one`, required): Select the shirt size of the participant. Options include Small, Medium, Large.
*   **Participant Number** (`participant_number`, `number`, required): Enter a unique participant number. This helps in identifying participants.
*   **Division** (`division`, `select_one`, required): Select the division of the participant. Options include Division 1, Division 2, Division 3, Division 4, Division 5.
*   **Event Tier** (`event_tier`, `select_one`, required): Select the tier of the event. Options include 1st place, 2nd place, 3rd place.
*   **Confirm Participant Name** (`confirm_participant_name`, `checkbox`, required): Confirm the participant name. This is a critical field for accuracy.
*   **Confirm Team Members** (`confirm_team_members`, `checkbox`, required): Confirm the team members. This ensures that team information is accurate.
*   **Confirm Event Date** (`confirm_event_date`, `checkbox`, required): Confirm the event date. This field checks for date accuracy.
*   **Confirm Age Group** (`confirm_age_group`, `checkbox`, required): Confirm the age group of the participant. This is essential for age-related considerations.

Note: Please ensure that all fields marked with an asterisk (\*) are completed accurately and truthfully to avoid any issues during the registration process.
