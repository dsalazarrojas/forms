# Educational Technology Expo Registration Form - Help Guide
## Purpose

The Educational Technology Expo Registration Form is designed to collect registration information from participants for the event. It serves to gather crucial details for event organization and planning.

## How To Complete This Form

1.  Please fill out the form with accurate and complete information for each page.
2.  Start from top to bottom, completing each page in sequence.
3.  Ensure all required fields are filled out before proceeding to the next page.
4.  Review the provided hints and explanations for specific field requirements or formats.

## Field-by-Field Explanation

### Page 1: Participant Name

*   *Participant Name*: This field is for your name as a participant in the Educational Technology Expo.
    *Type*: text
    *Required*: No
    *Hint*: Fill out your name as it should be displayed on event materials and communications.

### Page 2: Email Address

*   *Email Address*: This is your contact email address for event-related communications.
    *Type*: email
    *Required*: No
    *Hint*: Format should be in the standard email format (username@domain.com).

### Page 3: Role

*   *Role*: Please select the role you are attending the event in (e.g., exhibitor, speaker, guest).
    *Type*: text
    *Required*: No
    *Hint*: Choose a role that best represents your attendance purpose.

### Page 4: Company

*   *Company*: If you are attending on behalf of a company, please fill out this field with your company name.
    *Type*: text
    *Required*: No
    *Hint*: Company name should be in the format "Company Name" or "Company Name, Inc."

### Page 5: Phone

*   *Phone*: This is your contact phone number for event-related communications.
    *Type*: text
    *Required*: No
    *Hint*: Format should be in the standard phone number format (e.g., 123-456-7890).

### Page 6: Time of Day

*   *Time of Day*: Please select your available time slot for the event.
    *Type*: time
    *Required*: No
    *Hint*: Format should be in 24-hour time format (e.g., 14:00 for 2 PM).

### Page 7: Date

*   *Date*: This field is for your preferred event date.
    *Type*: date
    *Required*: No
    *Hint*: Format should be in the standard date format (DD/MM/YYYY).

### Page 8: Event Type

*   *Event Type*: Please select the type of event you are attending.
    *Type*: select\_one
    *Required*: No
    *Hint*: Choose a type that best represents your event purpose.

### Page 9: Attendee Number

*   *Attendee Number*: If this is a group, please fill out the number of attendees.
    *Type*: number
    *Required*: No
    *Hint*: Please fill in the number of people in your group.

### Page 10: Note

*   *Note*: If you have any additional information or comments for the event organizers, please fill out this field.
    *Type*: note
    *Required*: No
    *Hint*: Keep it brief, only for important comments or details.

## Tips

*   Please ensure all fields with specific formats are filled out correctly.
*   If you have any issues or concerns, contact event organizers for assistance.
*   Review your submission before submitting to ensure it is complete and accurate.
