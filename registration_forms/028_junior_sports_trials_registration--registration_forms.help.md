# junior-sports-trials-registration - Help Guide
## Purpose
This form is designed to register participants for Junior Sports Trials, a program aimed at promoting sports activities among children. The form captures contact information and preference selections for trial events.

## How To Complete This Form
1. Fill out the form completely and accurately.
2. Review each field carefully to ensure you've provided the correct information.
3. If you encounter any issues or have questions, please contact the trial organizers.

## Field-by-Field Explanation
* **Registration Form** (Registration Form, text, required/optional): This is the title of the form that you are submitting.
* **Name** (Name, text, required/optional): Enter your name as it should appear on your participant certificate.
* **Contact Number** (Contact Number, text, required/optional): Provide your contact number so we can reach you if necessary.
* **Email** (Email, email, required/optional): Enter your email address so we can reach you with updates.
* **select one** (select one, select_one, required/optional): Please select 'Yes' if you are interested in participating in the trials.
* **select multiple** (select multiple, select_multiple, required/optional): Select all the sports activities you are interested in participating in during the trials.
* **Date** (Date, date, required/optional): Choose the trial date you would like to participate in.
* **Time** (Time, time, required/optional): Select the trial time slot you would like to participate in.
* **Note** (Note, note, required/optional): Add any additional comments or information about your participation.
* **select one 2** (select one 2, select_one, required/optional): Please select 'Yes' if you are interested in participating in the trials for the next season.
* **select multiple 2** (select multiple 2, select_multiple, required/optional): Select all the sports activities you are interested in participating in during the trials for the next season.
* **select one 3** (select one 3, select_one, required/optional): Please select 'Yes' if you are interested in participating in the trials for the next year.
* **select multiple 3** (select multiple 3, select_multiple, required/optional): Select all the sports activities you are interested in participating in during the trials for the next year.
* **select one 4** (select one 4, select_one, required/optional): Please select 'Yes' if you are interested in participating in the trials for the subsequent year.
* **select multiple 4** (select multiple 4, select_multiple, required/optional): Select all the sports activities you are interested in participating in during the trials for the subsequent year.
