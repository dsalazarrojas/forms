# New Student Welcome Event Registration - Help Guide
## Purpose
This form is used to register new students for a welcome event. It allows you to gather information about the student, including their name, email, program, status, and other relevant details. This form is not mandatory, but rather a way to provide more information to help us better understand and prepare for the welcome event.

## How To Complete This Form
To complete this form, simply follow these steps:

1. Enter the student's name in the "Student Name" field.
2. Enter the student's email address in the "Student Email" field.
3. Select the student's program (e.g., High School Diploma, College/University Degree, or Certificate of Completion).
4. Choose the student's status (e.g., Active, Inactive, or Unknown).
5. Enter any additional information about the student's program status (if applicable).
6. Select the welcome event date and time.
7. Enter the event location.
8. Add any additional notes about the student.
9. Enter the student's phone number.

## Field-by-Field Explanation

* **Title**: New Student Welcome Event Registration
	+ This is the title of the form.
* **Student Name**: student_name (Text, Optional)
	+ Enter the student's name as it appears on their ID or other official documents.
* **Student Email**: student_email (Email, Optional)
	+ Enter the student's email address, if available.
* **Student Program**: student_program (Select One, Optional)
	+ Select the student's program (e.g., High School Diploma, College/University Degree, or Certificate of Completion).
* **Student Status**: student_status (Select Multiple, Optional)
	+ Choose the student's status (e.g., Active, Inactive, or Unknown).
* **Student Program Status**: student_program_status (Text, Optional)
	+ Enter any additional information about the student's program status.
* **Welcome Event Date**: welcome_event_date (Date, Optional)
	+ Select the date of the welcome event.
* **Welcome Event Time**: welcome_event_time (Time, Optional)
	+ Select the time of the welcome event.
* **Event Location**: event_location (Text, Optional)
	+ Enter the location of the welcome event.
* **Notes**: notes (Note, Optional)
	+ Add any additional notes about the student.
* **Phone**: phone (Text, Optional)
	+ Enter the student's phone number.
