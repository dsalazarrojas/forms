# Creator Circle Registration.report - Help Guide
## Purpose
The Creator Circle Registration.report form is a tool used to onboard new creators onto a platform or marketplace. It collects necessary information about the creator to facilitate their registration and integration into the platform.

## How To Complete This Form
To complete this form, follow these steps:
1. Fill in the fields as required and/or optional, depending on your specific needs.
2. Make sure to provide accurate and up-to-date information about yourself as a creator.
3. Review the form carefully before submitting it to ensure that all required fields are filled in correctly.

## Field-by-Field Explanation

* **Creator Details (Creator Details, text, required: false)**: This field is used to collect the creator's personal details.
* **First Name (First Name, text, required: false)**: This field is for your first name.
* **Last Name (Last Name, text, required: false)**: This field is for your last name.
* **Email (Email, email, required: false)**: This field is for your email address.
* **Phone (Phone, text, required: false)**: This field is for your phone number.
* **Creator Type (Creator Type, select_one, required: false)**: This field allows you to select your creator type.
* **Application Review (Application Review, select_multiple, required: false)**: This field allows you to select multiple application review options.
* **Creator Programs (Creator Programs, select_one, required: false)**: This field allows you to select a creator program.
* **Onboarded (Onboarded, text, required: false)**: This field is used to collect onboarded information.
* **Onboard Date (Onboard Date, date, required: false)**: This field is for the date of onboard.
* **Onboard Time (Onboard Time, time, required: false)**: This field is for the time of onboard.
* **Onboard Status (Onboard Status, select_one, required: false)**: This field allows you to select an onboard status.
* **Additional Comments (Additional Comments, note, required: false)**: This field is for additional comments.
* **Category (Category, select_one, required: false)**: This field allows you to select a category.
* **Subcategory (Subcategory, select_one, required: false)**: This field allows you to select a subcategory.
* **Tag (Tag, text, required: false)**: This field is for a tag.
* **Creator Bio (Creator Bio, text, required: false)**: This field is for a creator bio.
* **Creator Profile (Creator Profile, text, required: false)**: This field is for a creator profile.
* **Creator Website (Creator Website, text, required: false)**: This field is for your website.
* **Facebook (Facebook, select_one, required: false)**: This field allows you to select your Facebook profile.
* **Twitter (Twitter, select_one, required: false)**: This field allows you to select your Twitter profile.
* **Instagram (Instagram, select_one, required: false)**: This field allows you to select your Instagram profile.
* **TikTok (TikTok, select_one, required: false)**: This field allows you to select your TikTok profile.
* **YouTube (YouTube, select_one, required: false)**: This field allows you to select your YouTube profile.
* **Twitch (Twitch, select_one, required: false)**: This field allows you to select your Twitch profile.
* **Discord (Discord, select_one, required: false)**: This field allows you to select your Discord profile.

**Tips**: 
Please review each field carefully and ensure that you fill out as much information as possible to provide a comprehensive overview of yourself as a creator. This will help us better understand your needs and integrate you onto the platform seamlessly.
