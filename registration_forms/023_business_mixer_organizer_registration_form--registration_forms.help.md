# Business Mixer Organizer Registration Form - Help Guide

## Purpose

This form is designed to collect event details from business mixer organizers to help them register their events. Please fill out this form with accurate and complete information to promote and manage your event effectively.

## How To Complete This Form

1. Fill out the required fields (marked as "required" in the form).
2. Enter the event details as prompted, including your name, email, phone number, organization name, event name, date, start and end times, location, expected attendees, event type, target audience, registration fee, and other relevant details.
3. Select the correct options for event features such as catering, alcohol service, and audio-visual requirements.
4. Add any additional notes or special requirements for the event.
5. Confirm your registration by submitting the form.

## Field-by-Field Explanation

* **Organizer Name**: Please enter your full name as the event organizer.
* **Organizer Email**: Enter your email address for event communication.
* **Organizer Phone**: Enter your contact phone number.
* **Organization Name**: Enter the name of the organizing entity.
* **Event Name**: Enter the name of the mixer event.
* **Event Date**: Enter the date of the mixer.
* **Event Start Time**: Enter the start time of the event.
* **Event End Time**: Enter the end time of the event.
* **Event Location**: Enter the full venue address.
* **Expected Attendees**: Enter the approximate number of attendees.
* **Event Type**: Select the type of event (e.g., Networking mixer, Industry meetup, etc.).
* **Target Audience**: Select the target audience for the event (e.g., General business, Specific industry, etc.).
* **Registration Fee**: Select the registration fee for the event (e.g., Free, Under $25, etc.).
* **Catering Provided**: Select if food will be served (e.g., Yes - full meal, Yes - appetizers, etc.).
* **Alcohol Served**: Select if alcohol will be available (e.g., Yes - open bar, Yes - cash bar, etc.).
* **AV Requirements**: Select any audio-visual requirements for the event (e.g., Microphone, Projector, etc.).
* **Registration Deadline**: Enter the last day to register for the event.
* **Special Requirements**: Enter any special needs or accommodations for the event.
* **Marketing Channels**: Select how you will promote this event (e.g., Email, Social media, Website, etc.).
* **Additional Notes**: Enter any other information for the registration system.
