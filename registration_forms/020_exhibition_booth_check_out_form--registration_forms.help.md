# Exhibition Booth Check Out Form - Help Guide
## Purpose
The Exhibition Booth Check Out Form is used to gather information about the status of an exhibition booth after an event. This form is used to confirm that the booth has been properly checked out by the event manager, technical teams, and exhibition representatives.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the `Event Name` field with the name of the event that took place at the booth.
2. Enter the `Event Date` in the format MM/DD/YYYY.
3. Fill in the `Exhibition Booth Number` field with the number of the booth.
4. Select the correct `Booth Identifier` from the options provided.
5. For the `Electricity` field, select whether the booth requires 120v or 200w electricity.
6. Fill in the `Water` field with the amount of water required for the booth.
7. Select whether the `Internet` is required for the booth.
8. Select whether `Audio-Visual` is required for the booth.
9. Select the `Hearing/Ventilation/Air Conditioning` field with the required amount.
10. For `Audio-Visual Tech`, select whether it is required for the booth.
11. Enter the `Event Manager Email` address of the manager responsible for the event.
12. Fill in the `Exhibition Contact` field with the contact information of the exhibition representative.
13. Select whether the `Exhibition Manager` is present.
14. Fill in the `Exhibition Booth Representative` field with the representative's name.
15. Select one or more `Service Requirements` from the options provided.
16. Select whether `Services Require` is required for the booth.
17. Fill in the `Notes` field with any additional comments or notes about the booth.
18. Select whether the `Exhibition Booth Check Out Form` has been filled out correctly.
19. Select whether the `Exhibition Booth Check Out Form Checked` by exhibition manager.
20. Select whether the `Exhibition Booth Confirmation` has been given.
21. Select whether the `Exhibition Booth Check Out Form Submitted` has been submitted.
22. Select whether the `Exhibition Booth Check Out Form Checked by Exhibition Manager` has been checked.
23. Select whether the `Exhibition Booth Check Out Form Checked by Technical Teams` has been checked.
