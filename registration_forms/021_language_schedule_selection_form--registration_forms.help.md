# language_schedule_selection_form - Help Guide
## Purpose
This form is used to select language schedules for students.

## How To Complete This Form
To complete this form, follow these steps:
1. Select the appropriate institution affiliation from the **institution_id** field.
2. Choose the **semester** in which the language schedule will take place.
3. Select the **course schedule id**, **language id**, and **instructor id** from their respective dropdown menus.
4. Enter the **start date**, **end date**, **start time**, and **end time** for the language schedule.
5. Select the maximum number of students allowed to enroll in the schedule from the **max_students** field.
6. Select the **parent id** and **language schedule** from their respective dropdown menus.
7. Repeat steps 2-6 for additional language schedules as needed.

## Tips
* Make sure to select the correct institution affiliation for each language schedule.
* Be careful when selecting the start and end dates and times for each schedule.
* Ensure that you have selected the correct course, instructor, and section for each language schedule.
* Enter accurate student names and parent id's for each language schedule.
* Select the correct maximum number of students allowed to enroll in each schedule.
