# Spoken Word Event Reservation Form - Help Guide
## Purpose
This form is used to register a new event and gather essential details from attendees for RSVP purposes.

## How To Complete This Form
To fill out this form, follow these steps:

1. **Event Name**: Enter a descriptive name for your event.
2. **Event Organizer**: Enter your name or the name of the person organizing the event.
3. **Email**: Enter your email address, which will be used for communication purposes.
4. **Phone Number**: This is an optional field for you to provide your contact number.
5. **Event Date**: Choose the date of your event using the date picker.
6. **Event Time**: Choose the time of your event using the time picker.
7. **Event Organizer Name**: Enter the name of the person or organization hosting the event.
8. **Description**: Enter a brief description of your event.
9. **Event Location**: Enter the location of your event.
10. **Event Capacity**: Enter the maximum number of attendees you can accommodate.
11. **Registration Status**: Select whether the event is Open, Closed, or Cancelled.
12. **Registration Limit**: Select whether the event has a limited or unlimited capacity.

## Field-by-Field Explanation

* **Event Name (required)**: Enter a descriptive name for your event. This will be used to identify the event among other events.
* **Event Organizer (required)**: Enter your name or the name of the person organizing the event.
* **Email (required)**: Enter your email address, which will be used for communication purposes.
* **Phone Number (optional)**: This is an optional field for you to provide your contact number.
* **Event Date (required)**: Choose the date of your event using the date picker. Make sure to select a date that works for you.
* **Event Time (required)**: Choose the time of your event using the time picker. This helps attendees plan their schedules.
* **Event Organizer Name (optional)**: Enter the name of the person or organization hosting the event.
* **Description (optional)**: Enter a brief description of your event. This helps attendees get a better idea of what to expect.
* **Event Location (optional)**: Enter the location of your event. This is helpful for attendees who want to know where to go.
* **Event Capacity (required)**: Enter the maximum number of attendees you can accommodate. This helps ensure that the event is not overbooked.
* **Registration Status (required)**: Select whether the event is Open, Closed, or Cancelled. This helps attendees understand the event's status.
* **Registration Limit (optional)**: Select whether the event has a limited or unlimited capacity. This helps event organizers manage the number of attendees.
