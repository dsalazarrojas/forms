# skills_class_registration_form - Help Guide
## Purpose
This form is designed to collect registration information from participants for a skills class. It is meant to be completed once for each participant, and should not be used for participants who have already registered for a class.

## How To Complete This Form
1. Fill out the participant details page with the required information.
2. Select the classes you would like to register for.
3. Choose a preferred date and time for the class.
4. Enter your participant email and phone number.
5. Add any additional participant notes if necessary.
6. Select the class start date if applicable.

## Field-by-Field Explanation
* **Participant details (Participant details, text, optional)**: Enter a brief description of yourself, such as your name, title, or organization.
* **Class selections (Class selections, select multiple, optional)**: Select the classes you are interested in registering for.
* **Preferred date (Preferred date, date, optional)**: Choose a date that you would prefer to start the class.
* **Preferred time (Preferred time, time, optional)**: Choose a time that you would prefer to start the class.
* **Participant email (Participant email, email, optional)**: Enter your email address to receive class updates and notifications.
* **Participant phone (Participant phone, text, optional)**: Enter your phone number for emergency contact purposes.
* **Participant notes (Participant notes, note, optional)**: Add any additional information about yourself or your registration that may be helpful for the class instructor or staff.
* **Class start date (Class start date, date, optional)**: Select the start date of the class you would like to register for.
