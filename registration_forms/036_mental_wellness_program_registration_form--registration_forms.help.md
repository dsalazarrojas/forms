# mental_wellness_program_registration_form - Help Guide
## Purpose
The mental wellness program registration form is used to register mental wellness programs for individuals who seek support and resources for their mental well-being. By filling out this form, you'll be able to provide essential information about your program to help us better understand your needs and offer tailored support.

## How To Complete This Form
To complete this form, please follow the steps below:

1. Ensure you have all the required information before proceeding.
2. Fill in your Organization Name, which should be the name of the organization or group offering the mental wellness program.
3. Provide the name and contact details of the Contact Person responsible for the program.
4. Enter the Email address and Phone number of your organization.
5. Select the Start and End dates of the program.
6. Specify the Location of the program.
7. Choose the Program Type (Yes or No).
8. Provide a detailed description of the program.
9. Estimate the Expected and Actual number of participants for the program.
10. Indicate the Status of the program (Active or Inactive).
11. Add any additional Notes about the program.
12. Enter any Follow-up Notes that the contact person would like to share.
13. Select the Assigned Tool (Chatjimmy or Other).

## Field-by-Field Explanation
* **Organization Name (Organization Name)** (text, required): Enter the name of your organization or group offering the mental wellness program.
* **Contact Person (Contact Person)** (text, required): Provide the name and contact details of the person responsible for the program.
* **Email (Email)** (email, required): Enter the email address of your organization or contact person.
* **Phone (Phone)** (text, required): Provide the phone number of your organization or contact person.
* **Start Date (Start Date)** (date, required): Enter the start date of the program.
* **End Date (End Date)** (date, required): Enter the end date of the program.
* **Location (Location)** (text, required): Specify the location of the program.
* **Program Type (Program Type)** (select_one, required): Select Yes if the program is active, No if it is not.
* **Program Description (Program Description)** (text, required): Provide a detailed description of the program.
* **Expected Participants (Expected Participants)** (number, required): Estimate the number of participants expected for the program.
* **Actual Participants (Actual Participants)** (number, required): Enter the actual number of participants for the program.
* **Status (Status)** (select_one, required): Choose Active if the program is active, Inactive if it is not.
* **Notes (Notes)** (note, required): Add any additional notes about the program.
* **Follow Up Notes (Follow Up Notes)** (note, required): Enter any follow-up notes that the contact person would like to share.
* **Assigned Tool (Assigned Tool)** (select_multiple, required): Select Chatjimmy as the assigned tool, or choose Other if a different tool is used.
