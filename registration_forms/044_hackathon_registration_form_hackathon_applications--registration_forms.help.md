# Hackathon Registration Form Hackathon Applications - Help Guide
## Purpose
This form is intended for hackathon participants to register for a hackathon event.

## How To Complete This Form
To complete this form, follow these steps:

1. Determine whether you are registering as an individual or a team.
2. Fill in your name.
3. Provide your email address.
4. Enter your phone number.
5. Enter your address.
6. Select the event types you are interested in (e.g., Yes for each type that applies).
7. If you are a team member, select Yes for Team Members.
8. Enter the name of the team leader (if applicable).

## Field-by-Field Explanation
* **Individual or Team (individual_or_team_label)**: Select "Yes" if you are registering as an individual, or "No" if you are registering as a team.
* **Name (name_label)**: Enter your name as it should be listed in the event registration.
* **Email (email_label)**: Enter a valid email address that you regularly check for event updates.
* **Phone (phone_label)**: Enter your phone number that we can use to contact you in case of any updates or changes.
* **Address (address_label)**: Enter your physical address that we can use to deliver any event materials or updates.
* **Event Type (event_type_label)**: Select "Yes" for each event type that interests you.
* **Team Members (team_members_label)**: If you are a team member, select "Yes" to indicate that you are part of a team.
* **Team Leader (team_leader_label)**: If you are a team member and this is the team lead, enter their name as you would like it to be listed in the event registration. If not a team lead, leave this field blank.

## Tips
* Make sure to select the correct event types that interest you.
* If you are a team member, make sure to have the team lead's consent before registering them as the team leader.
