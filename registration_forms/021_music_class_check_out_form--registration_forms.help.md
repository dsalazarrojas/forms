# Music Class Check Out Form - Help Guide
## Purpose
This form is designed to gather information from students about their music class experience. It's used by instructors or administrators to track student attendance and gather feedback.

## How To Complete This Form
To complete this form, follow these steps:

* Fill out all the required fields (if any). If a field is marked as optional, you can skip it if you're not comfortable providing that information.
* For the "Student Name" field, please enter your name as you would like to be recognized in the music class record.
* For the "Music Class" field, select one of the options provided to indicate if you attended or not.
* For the "Attendance" field, select one of the options provided to indicate your attendance status.
* For the "Feedback" field, select all the options that apply to your experience.
* For the "Email" field, enter your email address if you'd like to be contacted about your music class experience.
* For the "Phone" field, enter your phone number if you'd like to be contacted about your music class experience.
* For the "Instructor Name" field, enter the name of your music class instructor.
* Review your form for accuracy before submitting. Double-check that you've filled out all required fields and that your selections are correct.

## Field-by-Field Explanation
* **Student Name** (`student_name`, text, required): Enter your name as you would like to be recognized in the music class record.
* **Music Class** (`music_class`, select_one, optional): Indicate if you attended or not.
* **Attendance** (`attendance`, select_one, optional): Select your attendance status.
* **Feedback** (`feedback`, select_multiple, optional): Choose all the options that apply to your experience.
* **Email** (`email`, text, optional): Enter your email address if you'd like to be contacted about your music class experience.
* **Phone** (`phone`, text, optional): Enter your phone number if you'd like to be contacted about your music class experience.
* **Instructor Name** (`instructor_name`, text, optional): Enter the name of your music class instructor.
