# match_setup_survey - Help Guide
## Purpose
This form is used to collect participant information and preferences for a match setup.

## How To Complete This Form
1. Start by completing the event info and participant info fields on the first page.
2. Continue to the next page where you will find more participant preferences, including select options and text fields.
3. For each field, ensure you complete all required fields, but skip optional fields if not applicable.
4. Review your responses before submission.
