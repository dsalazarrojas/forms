# Portfolio Review Appointment Form - Help Guide
## Purpose

This form is used to schedule a portfolio review appointment for a client.

## How To Complete This Form

1. Fill out all the required fields (marked as "required" in the form).
2. Select the preferred date and time for the review meeting.
3. Choose whether you want email and/or phone notifications for the review meeting.
4. Select the time slots that are available for the review meeting.
5. Enter any additional meeting details (e.g., meeting location, notes).
6. Choose whether you want follow-up reminders and notifications.
7. Select the next follow-up time and method.

## Field-by-Field Explanation

### 1. Client Name
* (`client_name`, text, required)
  This is the name of the client for whom the portfolio review appointment is scheduled.

### 2. Preferred Date
* (`preferred_date`, date, required)
  This is the preferred date for the portfolio review appointment. Please select the date from the calendar picker.

### 3. Preferred Time
* (`preferred_time`, time, required)
  This is the preferred time for the portfolio review appointment. Please select the time from the dropdown menu.

### 4. Details
* (`details`, text, optional)
  This is an optional field for entering any additional details about the review meeting.

### 5. Time Slots
* (`time_slots`, select_multiple, required)
  Please select the time slots that are available for the review meeting.

### 6. Available Time Slots
* (`available_time_slots`, select_one, required)
  Please select whether you are available for the review meeting during the selected time slots.

### 7. Appointment Date
* (`appointment_date`, date, required)
  This is the date of the scheduled portfolio review appointment.

### 8. Appointment Time
* (`appointment_time`, time, required)
  This is the time of the scheduled portfolio review appointment.

### 9. Reminder
* (`reminder`, select_one, optional)
  Please select whether you want a reminder for the review meeting.

### 10. Email Notification
* (`email_notification`, text, optional)
  If you selected "Yes" for the reminder, you can enter your email address here for email notifications.

### 11. Phone Notification
* (`phone_notification`, text, optional)
  If you selected "Yes" for the reminder, you can enter your phone number here for phone notifications.

### 12. Meeting Location
* (`meeting_location`, text, optional)
  This is an optional field for entering the location of the review meeting.

### 13. Meeting Notes
* (`meeting_notes`, text, optional)
  This is an optional field for entering any additional notes about the review meeting.

### 14. Meeting Duration
* (`meeting_duration`, number, optional)
  This is an optional field for entering the duration of the review meeting.

### 15. Meeting Start Time
* (`meeting_start_time`, time, optional)
  This is an optional field for entering the start time of the review meeting.

### 16. Meeting End Time
* (`meeting_end_time`, time, optional)
  This is an optional field for entering the end time of the review meeting.

### 17. Meeting Start Date
* (`meeting_start_date`, date, optional)
  This is an optional field for entering the start date of the review meeting.

### 18. Meeting End Date
* (`meeting_end_date`, date, optional)
  This is an optional field for entering the end date of the review meeting.

### 19. Follow-up Reminder
* (`follow_up_reminder`, text, optional)
  Please select whether you want follow-up reminders and notifications.

### 20. Next Follow-up Time
* (`next_follow_up_time`, select_one, required)
  Please select the next follow-up time.

### 21. Follow-up Note
* (`follow_up_note`, text, optional)
  This is an optional field for entering any additional follow-up notes.

### 22. Next Follow-up Method
* (`next_follow_up_method`, select_one, required)
  Please select the next follow-up method.

### 23. Follow-up Date
* (`follow_up_date`, date, optional)
  This is an optional field for entering the follow-up date.

### 24. Follow-up Time
* (`follow_up_time`, time, optional)
  This is an optional field for entering the follow-up time.

## Tips

* Please ensure that you fill out all required fields before submitting the form.
* If you are not sure about any of the fields, please contact your administrator for assistance.
* If you have any additional questions or concerns, please contact your administrator for further guidance.
