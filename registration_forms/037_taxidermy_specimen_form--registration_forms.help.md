# taxidermy_specimen_form - Help Guide
## Purpose
This form is used to collect information about taxidermy specimens for record-keeping and research purposes.

## How To Complete This Form
- Please fill out each field accurately and thoroughly.
- Make sure to select unique specimen IDs to avoid duplicate submissions.
- For fields with multiple options, select all applicable choices.

## Field-by-Field Explanation

* **Specimen Type** (`specimen_type`, select_one, required): Select the category of the specimen, such as Bird, Mammal, Reptile, Fish, or Insect.
* **Specimen Size** (`specimen_size`, select_multiple, required): Choose all that apply from Small, Medium, or Large.
* **Taxidermy Level** (`taxidermy_level`, select_multiple, required): Select all that apply from Beginner, Intermediate, or Advanced.
* **Taxidermy Techniques Used** (`taxidermy_techniques_used`, select_multiple, required): Choose all applicable techniques from Skinning, Mounting, Proportional, or Re-stuffing.
* **Taxidermy Materials Used** (`taxidermy_materials_used`, select_multiple, required): Select all applicable materials from Wax, Glass, Hair, or Wood.
* **Taxidermy Coloring Method** (`taxidermy_coloring_method`, select_multiple, required): Choose all that apply from Paint, Dye, Spray, or None.
* **Specimen Condition** (`specimen_condition`, select_multiple, required): Select all that apply from Excellent, Good, Fair, or Poor.
* **Taxidermy Techniques** (`taxidermy_techniques`, select_multiple, required): Please choose all applicable techniques from Skinning, Mounting, Proportional, or Re-stuffing.
* **Taxidermy Tools Used** (`taxidermy_tools_used`, select_multiple, required): Select all that apply from Clamp, Rivet, Bonesaw, Hammers.
* **Taxidermy Location** (`taxidermy_location`, select_multiple, required): Choose all that apply from Studio, Workshop, Field, or Museum.
* **Taxidermy Date** (`taxidermy_date`, date, required): Enter the date the taxidermy was completed.
* **Submission Date** (`submission_date`, date, required): Enter the date the specimen was submitted.
* **Specimen Weight** (`specimen_weight`, number, optional): If applicable, enter the weight of the specimen.
* **Taxidermy Cost** (`taxidermy_cost`, number, optional): If applicable, enter the cost of the taxidermy project.
* **Taxidermy Time** (`taxidermy_time`, time, optional): If applicable, enter the time spent on the taxidermy project.
* **Taxidermy Notes** (`taxidermy_notes`, text, optional): Provide any additional information about the taxidermy project.
* **Submission Notes** (`submission_notes`, text, optional): Provide any additional information about the submission.
