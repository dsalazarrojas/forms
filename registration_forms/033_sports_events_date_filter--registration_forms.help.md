# sports_events_date_filter - Help Guide
## Purpose
The sports_events_date_filter form is designed to collect information about sports events, allowing users to filter these events by date for planning and management purposes.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the Event you are interested in from the dropdown menu.
2. Enter the Start Date of the event.
3. Enter the End Date of the event.
4. Select the Date Filter for the event (e.g., day, week, month).
5. Select the Timezone for the event.
6. Fill in the Email and Payment Status fields as necessary.
7. Fill in the User Status and Event Status fields as necessary.
8. Enter any additional Event Details as necessary.
9. Enter the User Details and Event 1-6 information as necessary.

## Field-by-Field Explanation

* **Select Event**: Choose the specific event for which you want to filter dates. 
* **Start Date**: Enter the start date of the event.
* **End Date**: Enter the end date of the event.
* **Date Filter**: Choose the date filter type (e.g., day, week, month).
* **Timezone**: Select the timezone of the event.
* **Email**: Enter the event contact's email address.
* **Payment Status**: Select the payment status of the event (e.g., paid, pending, cancelled).
* **User Status**: Select the user's status (e.g., registered, pending, not registered).
* **Event Status**: Select the event status (e.g., active, inactive, cancelled).
* **Event Details**: Add any additional event details as necessary.
* **User Details**: Enter the user's details as necessary.
* **Event 1-6**: Select the event type (e.g., basketball, tennis, football) for each event.

## Tips

* Please ensure you are filling in the required fields before submitting the form.
* Review your selections carefully before submitting the form.
* If you are unsure about any field or option, contact your administrator for assistance.
