# event_host_registration_form - Help Guide
## Purpose
The event host registration form is designed to collect information from event hosts about their event, including details such as event name, date, location, and host contact information. This form helps the organizers to gather essential data for event coordination and communication purposes.

## How To Complete This Form
To complete the form, follow these steps:

1. Select the correct event host information on the first page.
2. Fill in the event name, event date, event location, and host contact information (email, phone, address, city, state, country).
3. Choose the host's preferred event currency.
4. Select the host's language of communication.
5. Add any additional event details, such as event description and event URL.

## Field-by-Field Explanation
* **Event Host Information**: Provide the name and details of the event host.
	+ **Host Name**: Enter the name of the person or organization hosting the event.
	+ **Email**: Enter the host's email address.
* **Event Name**: Enter the name of the event.
* **Event Date**: Enter the date of the event.
* **Event Location**: Enter the location of the event.
* **Host Phone**: Enter the host's phone number.
* **Event Description**: Provide a brief description of the event.
* **Event URL**: Enter the URL of the event (if applicable).
* **Event Image**: Upload an image related to the event (if applicable).
* **Event Host Notes**: Add any additional notes about the event host.
* **Host Email**: Enter the host's email address.
* **Host Phone**: Enter the host's phone number.
* **Host Address**: Enter the host's address.
* **Host City**: Enter the city where the host resides.
* **Host State**: Select the state where the host resides.
* **Host Country**: Select the country where the host resides.
* **Host Language**: Select the language the host prefers to communicate in.
* **Host Currency**: Select the currency used by the host.
* **Host Country of Employment**: Enter the country where the host works.
* **Host Employment Type**: Enter the type of employment the host has.
* **Host Workplace**: Enter the host's workplace.
* **Host Work Phone**: Enter the host's work phone number.
* **Host Work Email**: Enter the host's work email address.

## Tips

* Make sure to enter accurate and up-to-date information.
* Use the format specified for each field (e.g., YYYY-MM-DD for dates).
* Double-check your inputs before submitting the form.
* If you're unsure about any field, contact the event coordinator or administrator for assistance.
