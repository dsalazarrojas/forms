# Attendance Tracker Requisition Form - Help Guide

## Purpose
The Attendance Tracker Requisition Form is used to request and track attendance at events/meetings. It gathers essential information to ensure the event runs smoothly and efficiently.

## How To Complete This Form

1.  Review the form carefully to ensure all required fields are filled out accurately.
2.  Start with the Requisition Information section where you will provide your name and contact email.
3.  Fill out the Event Information section with the event name, date, start and end times, and location.
4.  Specify the expected attendance and the type of tracking system required.
5.  Choose the method of tracking and select which data fields to collect.
6.  Decide on reporting requirements and special needs or constraints.
7.  Confirm department approval and provide a budget code if applicable.
8.  Add any additional notes.

## Field-by-Field Explanation

* **Requisition Date** (Required, Date): Date of the event request.
* **Requisition Number** (Not Required, Text): Reference number for the request.
* **Requested By** (Required, Text): Name of the person requesting the event.
* **Requester Email** (Required, Email): Contact email of the requester.
* **Event Name** (Required, Text): Name of the event or meeting.
* **Event Date** (Required, Date): Date when the event occurs.
* **Event Start Time** (Required, Time): Start time of the event.
* **Event End Time** (Required, Time): End time of the event.
* **Event Location** (Required, Text): Where the event will be held.
* **Expected Attendance** (Required, Number): Estimated number of attendees.
* **Type of Tracker Needed** (Required, Select One): Digital Form, Paper Register, etc.
* **Tracking Method** (Required, Select One): Self-Check-In, Staff Check-in, etc.
* **Data Collection Fields** (Required, Select Multiple): Choose information to collect: Name, ID Number, Email, Phone, Organization, Department, Time In/Out, Purpose.
* **Reporting Requirements** (Optional, Select Multiple): Attendance List, Attendance Summary, Time Analysis, etc.
* **Number of Check-In Stations** (Optional, Number): How many devices/stations needed.
* **Internet Availability** (Required, Select One): Yes, No, Limited, Unknown.
* **Special Requirements** (Optional, Text): Any special needs or constraints.
* **Department Approval** (Required, Select One): Yes, No, Pending.
* **Budget Code** (Optional, Text): Cost allocation code if applicable.
* **Additional Notes** (Optional, Text): Any other information needed.
