# Doula Networking Event Registration - Help Guide
## Purpose
The Doula Networking Event Registration form is designed for individuals who want to register for a Doula networking event. This form helps us gather essential information to manage event logistics and participant expectations.

## How To Complete This Form
To fill out this form correctly, please follow these steps:

*   Fill out all the required fields (marked with an asterisk \*).
*   Enter your First name, Last name, and Email address correctly.
*   Provide a valid Phone number (if applicable).
*   Enter your Date of Birth (DD/MM/YYYY format).
*   Select the Event date and Event time (HH:MM format) of the event you're attending.
*   Enter the Location of the event (e.g., venue name, city, state).
*   Provide a brief Description of your skills, experience, or what you're hoping to get out of this event.

## Field-by-Field Explanation
*   **First name**: Enter your first name, as you would like it to be displayed on any event materials or communications. 
*   **Last name**: Enter your last name, as you would like it to be displayed on any event materials or communications.
*   **Email**: Enter a valid email address that you check regularly. This will be used for event communications and updates.
*   **Phone**: If applicable, enter a phone number where you can be reached for event-related matters.
*   **Date of Birth**: Enter your date of birth in DD/MM/YYYY format (e.g., 15/02/1990).
*   **Time**: Select the time of the event you're attending (HH:MM format, e.g., 14:00).
*   **Event date**: Select the date of the event you're attending (DD/MM/YYYY format, e.g., 15/02/2024).
*   **Event time**: Select the time of the event you're attending (HH:MM format, e.g., 14:00).
*   **Location**: Enter the name of the venue or location where the event is taking place (e.g., "New York City Hall").
*   **Description**: Provide a brief description of your skills, experience, or what you're hoping to get out of this event (e.g., "I'm a Doula with 3 years of experience in supporting pregnant women during labor and postpartum care.").
