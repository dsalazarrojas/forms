# Skincare Product Testing Registration Form - Help Guide
## Purpose
This form is designed to collect information from users about their skincare experiences and preferences in order to better understand their needs.

## How To Complete This Form
- Please fill out the form completely and accurately.
- Make sure to provide information about yourself, such as your first and last name, email address, and birth date.
- Be honest about your skin type and concerns.
- Choose the correct product type and brand you are interested in testing.
- If you have any notes or comments, please include them in the "Notes" field.

## Field-by-Field Explanation
### 1. First Name
* **First Name**: This is the first name of the user, which will be used to address the user personally.
*   Type: text
*   Required: false

### 2. Last Name
*   **Last Name**: This is the last name of the user, which will be used to address the user personally.
*   Type: text
*   Required: false

### 3. Email
*   **Email**: This is the user's email address, which will be used to contact the user.
*   Type: email
*   Required: false

### 4. Birth Date
*   **Birth Date**: This is the user's date of birth, which will help us understand their age group.
*   Type: date
*   Required: false

### 5. Product Name
*   **Product Name**: This is the name of the skincare product the user is interested in testing.
*   Type: text
*   Required: false

### 6. Product Type
*   **Product Type**: This is the type of skincare product the user is interested in testing (e.g., cream, serum, etc.).
*   Type: text
*   Required: false

### 7. Test Length
*   **Test Length**: This is the length of time the user would like to test the product.
*   Type: text
*   Required: false

### 8. Gender
*   **Gender**: This is the user's gender, which will help us understand their skin concerns.
*   Type: select_one
*   Options: Male, Female, Other, Prefer Not to Say
*   Required: false

### 9. Skin Type
*   **Skin Type**: This is the user's skin type (e.g., Normal, Sensitive, Oily, Dry, Combination).
*   Type: select_multiple
*   Options: Normal, Sensitive, Oily, Dry, Combination
*   Required: false

### 10. Skin Concern
*   **Skin Concern**: This is the user's skin concern (e.g., Acne, Aging, Dehydrated, etc.).
*   Type: select_multiple
*   Options: Acne, Aging, Dehydrated, Hyper-Pigmentation, Other
*   Required: false

### 11. Test Product
*   **Test Product**: This is the name of the skincare product the user is interested in testing.
*   Type: text
*   Required: false

### 12. Product Brand
*   **Product Brand**: This is the brand of the skincare product the user is interested in testing.
*   Type: text
*   Required: false

### 13. How Often
*   **How Often**: This is how often the user would like to test the product (e.g., daily, weekly, etc.).
*   Type: text
*   Required: false

### 14. Why Test
*   **Why Test**: This is why the user would like to test the product (e.g., for a special occasion, for personal use, etc.).
*   Type: text
*   Required: false

### 15. Notes
*   **Notes**: This is a text field where the user can include any additional comments or notes about their skin concerns or product preferences.
*   Type: note
*   Required: false

### 16. Email
*   **Email**: This is the user's email address, which will be used to contact the user.
*   Type: email
*   Required: false

## Tips
- Please be honest and accurate when filling out the form.
- If you have any questions or concerns, please contact us.
- We will use the information collected from this form to improve our product offerings.
