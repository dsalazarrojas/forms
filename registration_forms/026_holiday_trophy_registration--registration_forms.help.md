# Holiday Trophy Registration - Help Guide
## Purpose
The Holiday Trophy Registration form is designed to collect participant information for a holiday event. The form is used to register participants for the event, gathering essential details such as name, email, phone number, and other relevant information.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the required fields with accurate and complete information.
2. Select the correct options for each field, such as participant's gender, t-shirt size, and shoe size.
3. Review your answers carefully before submitting the form.

## Field-by-Field Explanation
* **Participant Name** (`participant_name`, `text`, optional): Enter the participant's name.
* **Participant Email** (`participant_email`, `email`, optional): Enter the participant's email address.
* **Participant Phone** (`participant_phone`, `text`, optional): Enter the participant's phone number.
* **Participant Email Confirmed** (`participant_email_confirmed`, `select_multiple`, optional): Select 'Yes' if the participant's email has been confirmed; otherwise, select 'No'.
* **Yes/No** (`participant_email_confirmed_yes_no`, `select_multiple`, optional): If participant's email is confirmed, select 'True'; otherwise, select 'False'.
* **Note** (`participant_email_confirmed_note`, `note`, optional): Add any notes about the participant's email confirmation.
* **Participant Address** (`participant_address`, `text`, optional): Enter the participant's address.
* **Participant City** (`participant_city`, `text`, optional): Enter the participant's city.
* **Participant State** (`participant_state`, `text`, optional): Enter the participant's state.
* **Participant Zip** (`participant_zip`, `text`, optional): Enter the participant's zip code.
* **Participant Country** (`participant_country`, `text`, optional): Enter the participant's country.
* **Date of Birth** (`participant_dob`, `date`, optional): Enter the participant's date of birth.
* **Participant Gender** (`participant_gender`, `select_one`, optional): Select the participant's gender.
* **Participant Age** (`participant_age`, `number`, optional): Enter the participant's age.
* **Participant T-Shirt Size** (`participant_tshirt_size`, `select_one`, optional): Select the participant's t-shirt size.
* **Participant T-Shirt Color** (`participant_tshirt_color`, `select_one`, optional): Select the participant's preferred t-shirt color.
* **Participant T-Shirt Color (Prefer)** (`participant_tshirt_color_prefer`, `select_one`, optional): Select the participant's t-shirt color preference.
* **Participant Shoes Size** (`participant_shoes_size`, `select_multiple`, optional): Select the participant's shoe size.
* **Participant Shoes Type** (`participant_shoes_type`, `select_multiple`, optional): Select the participant's shoe type.
* **Participant Shoes Color** (`participant_shoes_color`, `select_multiple`, optional): Select the participant's shoe color.
* **Participant Shirt Size** (`participant_shirt_size`, `select_multiple`, optional): Select the participant's shirt size.
* **Participant Shirt Type** (`participant_shirt_type`, `select_multiple`, optional): Select the participant's shirt type.
* **Participant Shirt Color** (`participant_shirt_color`, `select_multiple`, optional): Select the participant's shirt color.
