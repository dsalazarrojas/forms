# Alternate Pick Up Person Form - Help Guide
## Purpose
This form is used to register an individual authorized to pick up a child on behalf of a parent or guardian. The form ensures that the school has the necessary information to verify the identity and authorization of the person picking up the child.

## How To Complete This Form
1. Fill in the required fields marked as "Required" with an asterisk (\*).
2. Select the correct relationship of the alternate person to the child.
3. Ensure that all fields are filled out accurately and completely.
4. Sign and date the form, and have it witnessed if necessary.

## Field-by-Field Explanation

* **Parent/Guardian Name** (`parent_guardian_name`, text, \*): Fill in the full name of the parent or guardian.
* **Relationship to Child** (`relationship_to_child`, select_one, \*): Select the relationship of the alternate person to the child. Options include:
	+ Mother
	+ Father
	+ Legal guardian
	+ Foster parent
	+ Other
* **Email Address** (`email_address`, email, \*): Fill in the contact email address of the alternate person.
* **Phone Number** (`phone_number`, text, \*): Fill in the primary contact phone number of the alternate person.
* **Alternate Phone** (`alternate_phone`, text, optional): Fill in a backup contact number of the alternate person.
* **Home Address** (`home_address`, text, \*): Fill in the full address of the alternate person.
* **Child First Name** (`child_first_name`, text, \*): Fill in the first name of the child.
* **Child Last Name** (`child_last_name`, text, \*): Fill in the last name of the child.
* **Child Date of Birth** (`child_date_of_birth`, date, \*): Fill in the date of birth of the child in MM/DD/YYYY format.
* **Child Grade/Class** (`child_grade_class`, text, \*): Fill in the grade or classroom of the child.
* **School Year** (`school_year`, text, \*): Fill in the academic year of the child.
* **Alternate Person 1 Full Name** (`alternate_person_1_name`, text, \*): Fill in the full name of the alternate person 1.
* **Alternate Person 1 Relationship** (`alternate_person_1_relationship`, text, \*): Select the relationship of the alternate person 1 to the child.
* **Alternate Person 1 Phone** (`alternate_person_1_phone`, text, \*): Fill in the contact number of the alternate person 1.
* **Alternate Person 1 Email** (`alternate_person_1_email`, email, optional): Fill in the contact email of the alternate person 1.
* **Alternate Person 1 Address** (`alternate_person_1_address`, text, optional): Fill in the full address of the alternate person 1.
* **Alternate Person 1 Date of Birth** (`alternate_person_1_dob`, date, optional): Fill in the date of birth of the alternate person 1 in MM/DD/YYYY format.
* **Alternate Person 1 ID Type** (`alternate_person_1_id_type`, select_one, \*): Select the type of ID the alternate person 1 will show:
	+ Driver license
	+ State ID
	+ Passport
	+ Military ID
	+ Other government ID
* **Alternate Person 1 ID Number** (`alternate_person_1_id_number`, text, optional): Fill in the ID number of the alternate person 1.
* **Alternate Person 1 Authorization Dates** (`alternate_person_1_authorization_dates`, text, optional): Fill in when the alternate person 1 is authorized.
* **Alternate Person 2 Full Name** (`alternate_person_2_name`, text, optional): Fill in the full name of the alternate person 2.
* **Alternate Person 2 Relationship** (`alternate_person_2_relationship`, text, optional): Select the relationship of the alternate person 2 to the child.
* **Alternate Person 2 Phone** (`alternate_person_2_phone`, text, optional): Fill in the contact number of the alternate person 2.
* **Alternate Person 2 Email** (`alternate_person_2_email`, email, optional): Fill in the contact email of the alternate person 2.
* **Alternate Person 2 ID Type** (`alternate_person_2_id_type`, select_one, optional): Select the type of ID the alternate person 2 will show:
	+ Driver license
	+ State ID
	+ Passport
	+ Military ID
	+ Other government ID
	+ Not applicable
* **Alternate Person 2 ID Number** (`alternate_person_2_id_number`, text, optional): Fill in the ID number of the alternate person 2.
* **Pickup Restrictions** (`pickup_restrictions`, text, optional): Fill in any pickup restrictions.
* **Custody Agreement** (`custody_agreement`, select_one, \*): Select whether there are any custody restrictions:
	+ No restrictions
	+ Yes, documentation on file
	+ Yes, see attached
* **Custody Documentation** (`custody_documentation`, text, optional): Attach any relevant custody documentation.
* **Emergency Pickup Only** (`emergency_pickup`, select_one, \*): Select whether this is for emergency pickup only:
	+ No, regular pickup allowed
	+ Yes, emergencies only
	+ Yes, specific dates only
* **Password/Code Word** (`password_code`, text, optional): Fill in an optional security measure.
* **Special Instructions** (`special_instructions`, text, optional): Fill in any special notes.
* **Authorization Duration** (`authorization_duration`, select_one, \*): Select how long the authorization is valid:
	+ Entire school year
	+ Current semester only
	+ Specific dates only
	+ Until revoked
* **Parent/Guardian Signature** (`parent_signature`, select_one, \*): Select whether the form is signed:
	+ I authorize the above individuals
	+ Not yet signed
* **Signature Date** (`signature_date`, date, \*): Fill in the date signed.
* **Witness Name** (`witness_name`, text, optional): Fill in the name of the witness.
* **For School Office Use Only** (`school_office_use`, text, optional): Fill in any staff notes.
* **Form Received Date** (`form_received_date`, date, optional): Fill in the date the form was received.
* **Staff Initials** (`staff_initials`, text, optional): Fill in the initials of the staff processing the form.
