# Event Access Authorization Form - Help Guide
## Purpose
This form is used to request access authorization for an event.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the form with accurate and complete information about your event.
2. Provide your email and phone number so that we can contact you with any questions or concerns.
3. Select the staff members, attendees, and vendors who should have access to the event.
4. Choose the access levels and permission for the event.
5. Enter the start and end times and dates for the event.

## Field-by-Field Explanation
* **Event Access Authorization Form Data** (Event Access Authorization Form Data, text, optional): Enter a brief description of your event.
* **Event Organizer Email** (Event Organizer Email, text, optional): Enter the email of the event organizer.
* **Event Organizer Phone** (Event Organizer Phone, text, optional): Enter the phone number of the event organizer.
* **Event Organizer Name** (Event Organizer Name, text, optional): Enter the name of the event organizer.
* **Staff Members** (Staff Members, select multiple, optional): Select the staff members who should have access to the event.
* **Attendees** (Attendees, select multiple, optional): Select the attendees who should have access to the event.
* **Vendors** (Vendors, select multiple, optional): Select the vendors who should have access to the event.
* **Access Levels** (Access Levels, select one, optional): Choose the access level for the event.
* **Permission** (Permission, select multiple, optional): Choose the permission for the event.
* **Event Start Time** (Event Start Time, time, optional): Enter the start time of the event.
* **Event Start Date** (Event Start Date, date, optional): Enter the start date of the event.
* **Event End Time** (Event End Time, time, optional): Enter the end time of the event.
* **Event End Date** (Event End Date, date, optional): Enter the end date of the event.
