# telecommunications_service_registration - Help Guide
## Purpose
This form is used for registering telecommunications services, which requires gathering essential details for successful service installation and management.

## How To Complete This Form
To complete this form, follow these steps:
1. Fill in the registration form with your contact information and service details.
2. Select the relevant plans and installation details for your service.
3. Provide any additional information or notes as needed.

## Field-by-Field Explanation

* **Registration (1)** (text, required): Enter your service request details.
* **Plan (2)** (select_one, required): Select the plan for your new telecomm service.
* **Installation (3)** (note, required): Add any specific installation instructions or requests.
* **Email (4)** (email, required): Enter your email address.
* **Phone (5)** (text, required): Enter your phone number.
* **Date (6)** (date, required): Select the installation date.
* **Time (7)** (time, required): Select the installation time.
* **Customer Details (8)** (text, required): Enter your customer's details.
* **Additional Info (9)** (note, optional): Add any additional information about your service request.
* **Customer Notes (10)** (note, optional): Add any notes about the customer.
* **Telecom Notes (11)** (note, optional): Add any additional notes about the telecomm service.
* **Service Type (12)** (select_one, required): Select the type of service.
* **Installation Type (13)** (select_one, required): Select the type of installation.
* **Installation Date (14)** (date, required): Select the installation date.
* **Installation Time (15)** (time, required): Select the installation time.
* **Customer Email (16)** (email, required): Enter your customer's email address.
* **Customer Phone (17)** (text, required): Enter your customer's phone number.
* **Customer Address (18)** (text, required): Enter your customer's address.
* **Customer City (19)** (text, required): Enter your customer's city.
* **Customer State (20)** (text, required): Enter your customer's state.
* **Customer Zip (21)** (text, required): Enter your customer's zip code.
* **Customer Notes (22)** (note, required): Add any notes about the customer.
* **Telecom Notes (23)** (note, required): Add any additional notes about the telecomm service.
* **Telecom Plan (24)** (select_multiple, required): Select the relevant plans for your service.
* **Telecom Installation Status (25)** (select_one, required): Select the installation status.
