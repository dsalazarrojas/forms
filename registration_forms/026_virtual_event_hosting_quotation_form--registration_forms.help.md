# Virtual Event Hosting Quotation Form - Help Guide
## Purpose
This form is used to gather essential information from event organizers to create a quotation for virtual events. It is intended to help event planners and managers collect necessary details about the event, allowing them to provide an accurate quote to the client.

## How To Complete This Form
To complete this form, follow these steps:

1. Start by providing a title for the event in the "Event Details" section.
2. Enter the event dates and time in the "Event Dates" and "Event Time" fields respectively.
3. Describe the event in the "Event Description" field.
4. Select the event location from the options provided in the "Event Location" field.
5. Specify the event capacity in the "Event Capacity" field.
6. Choose the event type (event manager, event coordinator, or event lead) in the "Event Planner" field.
7. Enter the client's budget in the "Budget" field.
8. Provide the client's contact information, including their email address in the "Client Contact" field.
9. Enter any additional notes about the client in the "Client Note" field.
10. Finally, read and agree to the "Event Terms and Conditions" to proceed with the quotation process.

## Field-by-Field Explanation
* **Event Details**: This section is used to collect the title, dates, time, description, location, and capacity of the event.
* **Event Description**: A brief description of the event.
* **Event Dates**: The start and end dates of the event.
* **Event Time**: The start and end time of the event.
* **Event Location**: The physical location of the event.
* **Event Capacity**: The maximum number of attendees for the event.
* **Event Planner**: Select the type of event planner responsible for the event (event manager, event coordinator, or event lead).
* **Client Details**: This section is used to collect the client's budget, contact information, and any additional notes.
* **Budget**: The client's budget for the event.
* **Client Contact**: The client's email address and any additional contact information.
* **Client Note**: Any additional notes about the client.
* **Quotation Details**: This section is currently empty.
* **Event Terms and Conditions**: Please read and agree to these terms before proceeding with the quotation process.
