# Empowerment Movement Registration Form - Help Guide
## Purpose
The Empowerment Movement Registration Form is designed to register participants in the Empowerment Movement program, which aims to support individuals or organizations in achieving their goals.

## How To Complete This Form
1. Ensure you have all necessary information ready before starting to fill out the form.
2. Begin by filling out the required fields, indicated by an asterisk (\*).
3. Select the correct program type (Empowerment or Support) from the dropdown menu.
4. Enter the participant's name, email, phone number, zip code, and participant city.
5. Choose the languages you are proficient in and the languages you would like to communicate with the participant in (for participant's language).
6. Enter any other language(s) the participant would like to communicate in (if not listed).
7. Optionally, enter the participant's address, phone extension, and any notes you have about the participant.

## Field-by-Field Explanation
* **Participant Name**: This is the name of the participant registering for the program.
* **Phone**: This field is for the participant's phone number.
*   <del>This field is not required for participant's registration, however, it is used for follow-up communication.</del>
* **Email**: This is the participant's email address, used for contact purposes.
* **Organization**: This field is for the organization the participant is associated with (if applicable).
* **Workshop Type**: This dropdown menu asks for the type of program the participant wants to enroll in (Empowerment or Support).
* **Program Start Date**: This field is for the start date of the program (if applicable).
* **Program End Date**: This field is for the end date of the program (if applicable).
* **Program Time**: This field is for the time of the program (if applicable).
* **Workshop Location**: This field is for the location of the workshop (if applicable).
* **Participant Notes**: This field is for any additional notes about the participant.
* **Participant Address**: This field is for the participant's physical address.
* **Participant City**: This field is for the city where the participant resides.
* **Participant State**: This field is for the state where the participant resides.
* **Participant Zip**: This field is for the participant's zip code.
* **Language**: This dropdown menu asks for the languages you are proficient in.
* **Participant Language**: This field allows you to select multiple languages you can communicate with the participant in.
* **Participant Language Other**: This field is for any other languages the participant would like to communicate in (if not listed).
* **Participant Email**: This field is for the participant's email address.
* **Participant Phone**: This field is for the participant's phone number.
* **Participant Phone Extension**: This field is for the participant's phone extension.
* **Participant Program Type**: This field asks for the type of program the participant is seeking (Empowerment, Support, or Both).
* **Participant Program Type**: This field is for any other type of program the participant would like to be enrolled in (if not listed).
* **Participant Language Other 2**: This field is for any other languages the participant would like to communicate in (if not listed).

## Tips
* Please ensure that all required fields are filled out before submitting the form.
* Select the languages you are proficient in and the languages you would like to communicate with the participant accurately.
* If a language is not listed, you can enter it in the "Participant Language Other" or "Participant Language Other 2" field.
