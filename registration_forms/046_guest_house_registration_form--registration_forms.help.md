# Guest House Registration Form - Help Guide
## Purpose
The purpose of this form is to register a guest house, hotel, resort, or other type of property with the system.

## How To Complete This Form
1. Fill in the required fields with accurate and correct information.
2. Check the box to agree to the terms of service.
3. Review the form for any errors before submitting.

## Field-by-Field Explanation
* **Proprietor Name** (Required): Enter the name of the first proprietor.
* **Property Name** (Required): Enter the name of the property.
* **Contact Email** (Required): Enter the email of the first proprietor.
* **Contact Phone** (Required): Enter the phone number of the first proprietor.
* **Property Type** (Required): Select the type of property (Guest House, Hotel, Resort, Bed and Breakfast, Hostel).
* **Property Address** (Required): Enter the address of the property.
* **Property Description** (Optional): Enter a brief description of the property.
* **Property Image URL** (Required): Select up to 3 images for the property.
* **More Property Images** (Optional): Select more images for the property.
* **Property Price** (Required): Enter the price of the property.
* **Property Status** (Optional): Select whether the property is active or inactive.
* **Property Location** (Required): Select the location of the property (Europe, Asia, Australia, Africa, North America).
* **Property Currency** (Required): Select the currency of the property (USD, EUR, JPY, CNY, INR).
* **Property Rate** (Required): Select the rate of the property (Per Day, Per Week, Per Month, Per Year).
* **Property Services** (Required): Select the services offered by the property (Free Wi-Fi, Breakfast Included, Parking Available).
* **Proprietor Name 2** (Required): Enter the name of the second proprietor.
* **Email 2** (Optional): Enter the email of the second proprietor.
* **Phone 2** (Optional): Enter the phone number of the second proprietor.
* **Property Address 2** (Optional): Enter the address of the second property.
* **Property Status 2** (Optional): Select whether the second property is active or inactive.
* **Property Type 2** (Optional): Select the type of the second property.
* **Property Location 2** (Optional): Select the location of the second property.
* **Property Currency 2** (Optional): Select the currency of the second property.
* **Property Rate 2** (Optional): Select the rate of the second property.
* **Note** (Optional): Enter any additional information about the property.
* **Proprietor Name 2** (Optional): Enter the name of the second proprietor.
* **Phone 2** (Optional): Enter the phone number of the second proprietor.

Note: Please make sure to enter all required fields, and only fill in optional fields if necessary. If you are unsure about any field, please refer to the system's documentation or contact us for assistance.
