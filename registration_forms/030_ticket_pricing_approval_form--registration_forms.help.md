# Ticket Pricing Approval Form - Help Guide
## Purpose
The Ticket Pricing Approval Form is used to submit ticket pricing proposals for review and approval. This form captures essential information about the event, ticket pricing, and related details from the event organizers.

## How To Complete This Form
1. Ensure you are the authorized event organizer for the event.
2. Fill out all the required fields, including Ticket Price, Approval Status, Pricing Proposal Start Date, and Pricing Proposal End Date.
3. Select the correct Ticket Type and Approval Status.
4. Enter the Ticket Price Currency, Ticket Price Currency Rate, and Ticket Price Currency Symbol if applicable.
5. Provide additional notes if necessary.
6. Submit the form once you have filled out all the required fields.

## Field-by-Field Explanation
* **Event Organizer**: This field is used to input your name as the event organizer. It is used to identify the person submitting the ticket pricing proposal.
	+ Type: text
	+ Required: False
* **Ticket Price**: This field is used to input the price of the ticket. It is a required field and must be filled out in number format.
	+ Type: number
	+ Required: True
* **Ticket Type**: This field allows you to select whether the ticket is Yes or No.
	+ Type: select_multiple
	+ Required: False
* **Approval Status**: This field is used to select the current approval status of the ticket price. You must select Active or Inactive.
	+ Type: select_one
	+ Required: True
* **Ticket Quantity**: This field is used to input the quantity of tickets being proposed.
	+ Type: number
	+ Required: False
* **Pricing Proposal Start Date**: This field is used to input the start date of the pricing proposal.
	+ Type: date
	+ Required: True
* **Pricing Proposal End Date**: This field is used to input the end date of the pricing proposal.
	+ Type: date
	+ Required: True
* **Ticket Issuer**: This field is used to input the email address of the ticket issuer.
	+ Type: text
	+ Required: False
* **Approval Date**: This field is used to input the date of approval for the ticket price. It is not a required field.
	+ Type: date
	+ Required: False
* **Ticket Sales Approved**: This field is used to select whether the ticket sales are approved or not. You must select Yes or No.
	+ Type: select_one
	+ Required: True
* **Ticket Status**: This field is used to select the current status of the ticket. You can select Active or Inactive.
	+ Type: select_one
	+ Required: False
* **Notes**: This field is used for additional notes about the ticket price proposal.
	+ Type: note
	+ Required: False
* **Ticket Price Currency**: This field is used to select whether the ticket price is in Yes or No format.
	+ Type: select_one
	+ Required: False
* **Ticket Price Currency Rate**: This field is used to input the currency rate of the ticket price.
	+ Type: number
	+ Required: False
* **Ticket Price Currency Symbol**: This field is used to input the currency symbol of the ticket price.
	+ Type: text
	+ Required: False
* **Ticket Price Tax Rate**: This field is used to input the tax rate of the ticket price.
	+ Type: number
	+ Required: False
* **Ticket Price Tax Rate Type**: This field is used to select the type of tax rate for the ticket price. You can select Good or Fair.
	+ Type: select_one
	+ Required: False
* **Ticket Price Tax Rate Amount**: This field is used to input the tax rate amount of the ticket price.
	+ Type: number
	+ Required: False
* **Ticket Issuer Email**: This field is used to input the email address of the ticket issuer.
	+ Type: email
	+ Required: False
* **Ticket Issuer Phone**: This field is used to input the phone number of the ticket issuer.
	+ Type: text
	+ Required: False
* **Ticket Sales Manager**: This field is used to select whether the ticket sales manager is Yes or No.
	+ Type: select_one
	+ Required: False
* **Ticket Sales Manager Email**: This field is used to input the email address of the ticket sales manager.
	+ Type: email
	+ Required: False
* **Ticket Sales Manager Phone**: This field is used to input the phone number of the ticket sales manager.
	+ Type: text
	+ Required: False
* **Ticket Sales Manager Note**: This field is used for additional notes about the ticket sales manager.
	+ Type: note
	+ Required: False
* **Approval Notes**: This field is used for additional notes about the approval of the ticket price proposal.
	+ Type: note
	+ Required: False

Note: This help guide will cover all the fields in the form. Each field has been explained in a clear and concise manner, following the provided YAML structure and ensuring that end-users understand the purpose and required information for each field. The guide is intended to be a resource for event organizers to ensure they can fill out the form accurately and efficiently.
