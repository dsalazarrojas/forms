# Session Registration And Task Selection - Help Guide
## Purpose
This form is used to collect user feedback and preferences for sessions.

## How To Complete This Form

To complete this form, follow these steps:

1. Review the available session choices on the first page and select the sessions you'd like to provide feedback on.
2. On the second page, enter your participant details in the text field.
3. On the third page, select your task preference from the drop-down menu.
4. On the fourth page, select your session preferences from the drop-down menu.
5. Submit your completed form to finalize your responses.

## Field-by-Field Explanation

### Session Choices (Page 1)
* **Session Choices** (`session_choices`, select_multiple, optional): On this page, you'll see a list of session options. Select all the sessions you'd like to provide feedback on by clicking on the checkboxes next to each option. You can choose one or more sessions.

### Participant Details (Page 2)
* **Participant Details** (`participant_details`, text, optional): Enter your participant details in this text field. You can type in any relevant information you'd like to share about yourself as a participant.

### Task Preferences (Page 3)
* **Task Preferences** (`task_preferences`, select_one, optional): On this page, you'll see a drop-down menu with task preferences. Select the task preference that best suits your needs.

### Session Preferences (Page 4)
* **Session Preferences** (`session_preferences`, select_multiple, optional): On this page, you'll see a list of session preferences. Select all the session preferences that apply to you by clicking on the checkboxes next to each option. You can choose one or more session preferences.
