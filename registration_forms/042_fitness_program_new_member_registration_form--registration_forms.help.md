# Fitness Program New Member Registration Form - Help Guide
## Purpose
This form is used to register a new member in the fitness program. Please use this form only if you have not already registered for the program.

## How To Complete This Form
1. Ensure you have not already registered for the fitness program.
2. Fill out the form completely and accurately.
3. Select your membership type and gym location as needed.

## Field-by-Field Explanation
* **First Name** (`first_name`, text, optional): Enter your first name as it is written on your identification documents.
* **Last Name** (`last_name`, text, optional): Enter your last name as it is written on your identification documents.
* **Email** (`email`, email, optional): Enter your active email address where we can contact you.
* **Phone Number** (`phone_number`, text, optional): Enter a contact number where we can reach you if needed.
* **Date of Birth** (`date_of_birth`, date, optional): Enter your date of birth in the format 'MM/DD/YYYY'.
* **Membership Type** (`membership_type`, select_one, optional): Select the type of membership you are interested in joining.
* **Select Membership Type** (`select_membership_type`, select_multiple, optional): Select any additional membership options you would like to have.
* **Gym Location** (`gym_location`, select_one, optional): Select the gym location where you plan to work out.
* **Select Gym Location** (`select_gym_location`, select_multiple, optional): Select any additional gym locations you would like to have access to.
* **Emergency Contact Name** (`emergency_contact_name`, text, optional): Enter the name of the emergency contact person.
