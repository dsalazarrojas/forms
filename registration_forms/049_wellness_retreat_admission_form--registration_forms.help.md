# Wellness Retreat Admission Form - Help Guide

## Purpose

This form is for individuals to register for a wellness retreat. It is designed to collect user information and preferences to provide a personalized experience.

## How To Complete This Form

To complete this form, follow these steps:

1. Fill in your user information on page 1, including your name and any other relevant details.
2. On page 2, provide any additional preferences you have for the retreat, such as dietary restrictions or special requests.
3. Finally, add any additional information you would like to provide in the notes section on page 3.

## Field-by-Field Explanation

* **User Information** (Page 1, required)
	+ **Title**: This is a text field where you can enter your name.
	+ **Type**: Text input field.
	+ **Required**: Yes, this field is required to complete the form.
* **Preferences** (Page 2, optional)
	+ **Title**: This is a text field where you can specify any preferences or requirements you have for the retreat.
	+ **Type**: Text input field.
	+ **Required**: No, this field is optional.
* **Notes** (Page 3, optional)
	+ **Title**: This is a text field for any additional information or comments you would like to share.
	+ **Type**: Text area with note functionality.
	+ **Required**: No, this field is optional.
