# Dance Class Check In Form - Help Guide
## Purpose
The Dance Class Check In Form is designed to help dance class administrators record student attendance and track student information for each dance class.

## How To Complete This Form
To complete this form, follow these steps:
1. Enter the Dance Class ID.
2. Enter your Instructor ID.
3. Enter the Student Name(s) attending the class.
4. Choose the attendance status for each student.
5. Select the date and time of the class.

## Field-by-Field Explanation
- **Dance Class ID**: Enter the unique ID for the dance class.
  * Type: Text
  * Required: No

- **Instructor ID**: Enter your Instructor ID.
  * Type: Text
  * Required: No

- **Student Name**: Enter the name of each student attending the class.
  * Type: Text
  * Required: No

- **Student Attendance**: Choose 'True', 'False', or 'Maybe' for each student's attendance status.
  * Type: Select Multiple
  * Required: No

- **Date**: Select the date of the dance class.
  * Type: Date
  * Required: No

- **Time**: Select the time of the dance class.
  * Type: Time
  * Required: No

## Tips
* Please make sure to fill in all the required fields (none in this form, but it's always a good practice to double-check).
* If you're unsure about any field, contact the form creator at form@gic.mx.
* Remember to review your entries before submitting the form to ensure accuracy.
