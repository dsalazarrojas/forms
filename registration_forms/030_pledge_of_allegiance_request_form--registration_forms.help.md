# pledge_of_allegiance_request_form - Help Guide
## Purpose
The purpose of this form is to collect information about the school and students participating in the pledge of allegiance.

## How To Complete This Form
1. Please fill out the form accurately and thoroughly.
2. Review the form carefully to ensure all required fields are filled.
3. Submit the form once complete.

## Field-by-Field Explanation
- **School Name** (`school_name`, `text`, required/optional): This field is for entering the name of the school.
  - Please enter the full name of the school.
- **Student Name** (`student_name`, `text`, required/optional): This field is for entering the name of the student.
  - Please enter the full name of the student.
- **Date and Time** (`date_and_time`, `date`, required/optional): This field is for selecting the date and time of the pledge of allegiance.
  - Please select the date and time of the event.
- **Teacher Name** (`teacher_name`, `text`, required/optional): This field is for entering the name of the teacher.
  - Please enter the full name of the teacher.
- **Teacher ID** (`teacher_id`, `number`, required/optional): This field is for entering the ID number of the teacher.
  - Please enter the teacher's ID number (if applicable).
- **Teacher Email** (`teacher_email`, `email`, required/optional): This field is for entering the email address of the teacher.
  - Please enter the teacher's email address (if applicable).
- **Student ID** (`student_id`, `number`, required/optional): This field is for entering the ID number of the student.
  - Please enter the student's ID number (if applicable).
- **Student Name ID** (`student_name_id`, `number`, required/optional): This field is for entering a unique ID associated with the student name.
  - Please enter the student name ID number (if applicable).
- **Student Name 2** (`student_name_2`, `text`, required/optional): This field is for entering an additional name of a student.
  - Please enter the full name of the additional student (if applicable).

## Tips
- Please review the form carefully before submission to avoid errors.
- If you are unsure about any field, please reach out to the form administrator for clarification.
- If you have completed this form previously, please ensure that the information is up-to-date and accurate.
