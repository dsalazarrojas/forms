# E Commerce Payment Integration Registration - Help Guide
## Purpose
This form is used to register an E Commerce Payment Integration with the system. This integration is used to connect your E Commerce platform to the system, allowing you to process payments and manage orders seamlessly.

## How To Complete This Form
To complete this form, please follow the steps below:

1. Click on the "business_details" field and enter your business name, address, and other relevant details.
2. Select the payment gateway you want to use for your E Commerce platform from the "payment_gateway" dropdown menu.
3. Enter your API key, API secret, and API username for the selected payment gateway in the corresponding fields.
4. Enter any additional technical details about the integration in the "technical_details" field.
5. Provide a name for the integration in the "integration_name" field.
6. Enter your email and phone number so that we can contact you in case of any issues.
7. Add any notes or comments about the integration in the "notes" field.

## Field-by-Field Explanation
* **Business Details** (business_details): Enter the name and address of your business.
* **Payment Gateway** (payment_gateway): Select the payment gateway you want to use for your E Commerce platform (e.g. Amazon, Stripe, PayPal, or Other).
* **API Key** (api_key): Enter your API key for the selected payment gateway.
* **API Secret** (api_secret): Enter your API secret for the selected payment gateway.
* **API Username** (api_username): Enter your API username for the selected payment gateway.
* **API Password** (api_password): Enter your API password for the selected payment gateway.
* **Technical Details** (technical_details): Enter any additional technical details about the integration.
* **Integration Name** (integration_name): Provide a name for the integration.
* **Email** (email): Enter your email address so that we can contact you in case of any issues.
* **Phone** (phone): Enter your phone number so that we can contact you in case of any issues.
* **Notes** (notes): Add any notes or comments about the integration.
* **Created By** (created_by): This field is automatically populated with the user's name who created the integration.
* **Created At** (created_at): This field is automatically populated with the date and time when the integration was created.
