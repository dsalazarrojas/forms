# process_simulation_software_registration - Help Guide
## Purpose
This form is used to register simulation software with our organization. It collects information about the software's title, vendor, and other relevant details.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill out the required fields, marked with an asterisk (\*).
2. Select the correct options for each field from the dropdown menus where provided.
3. Enter your contact information in the required fields.

## Field-by-Field Explanation
* **Software Title** (`title`, text, required/optional): Enter the title of the software being registered.
* **Vendors Name** (`vendor_name`, text, required/optional): Enter the name of the vendor company.
* **License Type** (`license_type`, select_one, required): Select the type of license associated with the software.
* **Use Details** (`use_details`, text, required/optional): Enter any additional details about the software's use case.
* **Intended Use Type** (`use_type`, select_one, required): Select the intended use type of the software.
* **Team Information** (`team_info`, text, required/optional): Enter any relevant team information related to the software.
* **Tool Type** (`tool_type`, select_one, required): Select the type of tool the software is classified as.
* **Team Members** (`team_members`, select_multiple, required): Indicate if the software is part of a team effort. Select 'Yes' if it is, and 'No' if not.
* **Email** (`email`, email, required): Enter the email address of the contact person.
* **Phone** (`phone`, text, required): Enter the contact person's phone number.
* **Address** (`address`, text, optional): Enter the address of the vendor company.
* **Country** (`country`, text, optional): Enter the country of the vendor company.
* **Consent** (`consented`, select_one, required): Indicate if you have the authority to register the software.
* **Consent Terms** (`consented_terms`, text, optional): Enter any consent terms related to the software.
* **Additional Comments** (`additional_comments`, text, optional): Enter any additional comments about the software.
* **Company** (`company`, text, optional): Enter the name of the company associated with the software.
* **Contact Person** (`contact_person`, text, optional): Enter the name of the contact person.
* **Company Address** (`company_address`, text, optional): Enter the address of the company.
* **Zip** (`zip`, text, optional): Enter the zip code of the company.
* **City** (`city`, text, optional): Enter the city of the company.
* **State** (`state`, text, optional): Enter the state of the company.
* **Country** (`country`, text, optional): Enter the country of the company.
* **Additional Terms** (`additional_terms`, text, optional): Enter any additional terms related to the software.

Note that some fields are marked as optional, but please ensure that all required fields are filled out accurately and completely before submitting the form.
