# vip_experience_registration - Help Guide
## Purpose
This form is used to register and manage VIP experiences. Fill out the form to provide necessary details for event planning and management.

## How To Complete This Form
1. Fill out the form with the required information for each field.
2. Ensure all required fields are filled out before submitting the form.
3. Review the form carefully before submitting to avoid errors.

## Field-by-Field Explanation
- **Date** (`1`, `date`): Select the date of the VIP experience.
  - Please enter the date of the experience in the correct format (YYYY-MM-DD).
  
- **Time** (`2`, `time`): Select the time of the VIP experience.
  - Please enter the time in 24-hour format (HH:MM).

- **Experience** (`3`, `select_multiple`): Choose whether the experience is "Yes" or "No".
  - Select "Yes" if the experience has occurred or will occur.

- **Guests** (`4`, `number`): Enter the number of guests attending the experience.
  - Please enter a whole number, as fractional or decimal numbers are not allowed.

- **Notes** (`5`, `note`): Enter any additional notes about the experience.
  - This field is not required, but it can be useful for providing more context.

- **Email** (`6`, `email`): Enter a valid email address for contact.
  - Please enter a valid email address that can be used for communication.

- **Phone** (`7`, `text`): Enter a valid phone number for contact.
  - Please enter a valid phone number that can be used for communication.

- **Consistency** (`8`, `select_one`): Check if the experience is consistent.
  - Select "Yes" if the experience is consistent, "No" otherwise.

- **Agreement** (`9`, `text`): Agree to the terms and conditions.
  - Please read and agree to the terms and conditions before proceeding.

- **Message** (`10`, `text`): Enter any additional message or comments.
  - This field is for providing more information or comments about the experience.
