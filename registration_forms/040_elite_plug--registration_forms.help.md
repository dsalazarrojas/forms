# Elite Plug - Help Guide

## Purpose
The Elite Plug form is a registration form designed to collect various types of user information for Elite Plug, a platform for users to engage with elite content. This form is intended to collect user data for registration purposes.

## How To Complete This Form
To complete the form, follow the steps below:

1. Fill out the user fields as required and applicable.
2. Review the form for completeness and accuracy before submission.

## Field-by-Field Explanation

* **User Info** (`user_info`, text, optional): This field is for users to provide a brief description of themselves.
* **User Name** (`user_name`, text, optional): This is the name of the user to be registered.
* **User Email** (`user_email`, email, optional): Enter a valid email address for the user.
* **User Phone** (`user_phone`, text, optional): This is the user's contact phone number.
* **User Date** (`user_date`, date, optional): Select the date on which the user wishes to register.
* **User Time** (`user_time`, time, optional): Select the time on which the user wishes to be registered.
* **User Note** (`user_note`, note, optional): This field allows users to add any additional comments or notes.
* **User Select One** (`user_select_one`, select_one, optional): Choose one of the options provided for the user to select.
* **User Select Multiple** (`user_select_multiple`, select_multiple, optional): Choose multiple options from the list provided.
* **User Decimal** (`user_decimal`, number, optional): Enter a decimal number for the user.
* **User Integer** (`user_integer`, number, optional): Enter an integer number for the user.
* **Prophets** (`prophets`, select_one, optional): Select one of the prophet options provided.
* **Prophets List** (`prophets_list`, select_multiple, optional): Select multiple prophet options from the provided list.

## Tips

* Make sure to enter accurate and valid information to ensure a smooth registration process.
* If you encounter any errors or issues with the form, please contact our support team.
* The form is designed to be completed once for each user registration.
