# move_software_training_registration - Help Guide
## Purpose
This form is used for registering users for software training sessions. It is intended for users to provide their training team name, attendee details, session choices, goals and objectives, session start date, session end date, start time, and end time.

## How To Complete This Form
1. Fill out the form in a new browser tab or window.
2. Select the "Next" button to proceed to the next page.
3. Fill out each page completely before proceeding to the next one.
4. Select the "Submit" button when you have completed the form.

## Field-by-Field Explanation
* **Training Team Name** (`training_team_name`, text, optional): Enter the name of your training team.
* **Attendee Details** (`attendee_details`, select_one, optional): Select "Yes" if you are attending the session.
* **Session Choices** (`session_choices`, select_multiple, optional): Select all applicable session choices from the list.
* **Goals and Objectives** (`goals_and_objectives`, text, optional): Enter your goals and objectives for the training session.
* **Session Start Date** (`session_start_date`, date, optional): Enter the start date of the session.
* **Session End Date** (`session_end_date`, date, optional): Enter the end date of the session.
* **Start Time** (`start_time`, time, optional): Enter the start time of the session.
* **End Time** (`end_time`, time, optional): Enter the end time of the session.

## Tips
* Make sure to fill out each field completely before proceeding to the next page.
* Use the correct format for dates (YYYY-MM-DD) and times (HH:MM).
* Select all applicable session choices for the best experience.
* Enter your goals and objectives clearly and concisely.
* Double-check your answers before submitting the form.
