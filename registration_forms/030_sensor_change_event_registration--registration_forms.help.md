# Sensor Change Event Registration - Help Guide
## Purpose
This form is used to register sensor change events, which is an essential process for maintaining sensor health and accuracy. It ensures that all relevant information is accurately recorded in a single location, allowing for efficient monitoring and analysis.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the Event Organiser's name in the "Event Organiser" field.
2. Provide the name of the event in the "Event Name" field.
3. Select the start date of the event in the "Start Date" field.
4. Choose the type of event from the "Event Type" dropdown menu.
5. Select the status of the event from the "Event Status" dropdown menu.

## Field-by-Field Explanation
* **Event Organiser** (`event_organizer`, text, not required): Enter the name of the person or entity responsible for organizing the event.
* **Event Name** (`event_name`, text, not required): Provide a brief title for the event, such as "Sensor Maintenance Schedule" or "Sensor Replacement".
* **Start Date** (`start_date`, date, not required): Select the start date of the event from the calendar.
* **Event Type** (`event_type`, select_one, required): Choose the type of event from the list:
	+ Sensor Change Event
	+ Other (please specify in the "Event Name" field)
* **Event Status** (`event_status`, select_multiple, not required): Select one or more statuses that apply to the event:
	+ Scheduled
	+ Completed
	+ Cancelled

## Tips
* Double-check your submission to ensure that you're registering the event only once.
* If you're unsure about a field, refer to this help guide for clarification.
* If you've already registered the same event, you may not be able to complete this form again. However, please double-check your previous submissions to ensure you're not duplicating the event.
