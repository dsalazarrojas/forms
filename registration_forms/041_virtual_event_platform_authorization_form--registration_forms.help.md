# Virtual Event Platform Authorization Form - Help Guide
## Purpose
The Virtual Event Platform Authorization Form is used to collect information from participants for a virtual event, ensuring they meet the necessary requirements and agree to the event terms.

## How To Complete This Form
1. Please fill out all required fields (marked as "Required" in bold).
2. For the "Participant Name" and "Participant Email" fields, enter the participant's actual name and email address.
3. For the "Participant Phone" field, enter the participant's phone number.
4. For the "Participant Requirements" field, select "True" if the participant meets the requirements, and "False" if they do not.
5. For the "Agreement and Consent" field, select all the boxes that apply to the participant.
6. For the "Event Requirements" field, select "True" if the participant meets the event requirements, and "False" if they do not.
7. The "Additional Participant Notes" field is optional and can be used to provide any additional information about the participant.
8. The "Additional Participant Information" field is also optional and can be used to provide any further details about the participant.

## Field-by-Field Explanation
* **Event Name**: Enter the name of the virtual event you are authorizing the participant to attend.
* **Participant Name**: Enter the participant's actual name.
* **Participant Email**: Enter the participant's actual email address.
* **Participant Phone**: Enter the participant's phone number.
* **Participant Requirements**: Select "True" if the participant meets the requirements for the event, and "False" if they do not.
* **Agreement and Consent**: Select all the boxes that apply to the participant.
* **Event Requirements**: Select "True" if the participant meets the event requirements, and "False" if they do not.
* **Additional Participant Notes**: Provide any additional information about the participant.
* **Additional Participant Information**: Provide any further details about the participant.
