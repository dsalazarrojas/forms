# Non Resident Organizer Registration - Help Guide
## Purpose
This form is designed for non-resident organizers to register their events with our organization. It collects essential information about the event and the non-resident organizer, which will help us process and manage the event details.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the required fields (marked as "required") with accurate and complete information.
2. For the "Non Resident Organizer Type" field, select one of the options provided to categorize your event type.
3. Ensure that the "Event Start Date" and "Event End Date" fields are correctly entered in the format MM/DD/YY.
4. Enter the event details in the "Event Details" field.
5. Fill in the non-resident organizer's contact information, including name, address, organization, phone, and email.
6. Finally, click the "Submit" button to complete the registration process.

## Field-by-Field Explanation
### 1. Non Resident Organizer Registration
* **Non Resident Organizer Registration** (`non_resident_organizer_registration`, text, required): Provide a brief description of the event or purpose of the non-resident organizer's registration.
### 2. Event Details
* **Event Details** (`event_details`, text, required): Enter a detailed description of the event, including its objectives, goals, and any other relevant information.
### 3. Organizer Info
* **Organizer Info** (`organizer_info`, text, required): Enter the non-resident organizer's name and contact information.
### 4. Contact Info
* **Contact Info** (`contact_info`, text, required): Enter the non-resident organizer's contact information, including name, address, phone, and email.
### 5. Non Resident Organizer Type
* **Non Resident Organizer Type** (`non_resident_organizer_type`, select_one, required): Select the type of non-resident organizer (Option 1, Option 2, or Option 3).
### 6. Event Start Date
* **Event Start Date** (`event_start_date`, date, required): Enter the start date of the event in the format MM/DD/YY.
### 7. Event End Date
* **Event End Date** (`event_end_date`, date, required): Enter the end date of the event in the format MM/DD/YY.
### 8. Event Duration
* **Event Duration** (`event_duration`, number, required): Enter the duration of the event in days.
### 9. Event Start Time
* **Event Start Time** (`event_start_time`, time, required): Enter the start time of the event in 24-hour format (HH:MM).
### 10. Event End Time
* **Event End Time** (`event_end_time`, time, required): Enter the end time of the event in 24-hour format (HH:MM).
### 11. Venue Details
* **Venue Details** (`venue_details`, text, required): Enter the details of the event venue.
### 12. Event Program
* **Event Program** (`event_program`, text, required): Enter the program or agenda of the event.
### 13. Non Resident Organizer Contact
* **Non Resident Organizer Contact** (`non_resident_organizer_contact`, text, required): Enter the non-resident organizer's contact information.
### 14. Email
* **Email** (`email`, email, required): Enter the non-resident organizer's email address.
### 15. Phone
* **Phone** (`phone`, text, required): Enter the non-resident organizer's phone number.
### 16. Non Resident Organizer Name
* **Non Resident Organizer Name** (`non_resident_organizer_name`, text, required): Enter the non-resident organizer's name.
### 17. Non Resident Organizer Address
* **Non Resident Organizer Address** (`non_resident_organizer_address`, text, required): Enter the non-resident organizer's address.
### 18. Non Resident Organizer Organization
* **Non Resident Organizer Organization** (`non_resident_organizer_organization`, text, required): Enter the non-resident organizer's organization.
### 19. Non Resident Organizer Phone
* **Non Resident Organizer Phone** (`non_resident_organizer_phone`, text, required): Enter the non-resident organizer's phone number.
### 20. Non Resident Organizer Email
* **Non Resident Organizer Email** (`non_resident_organizer_email`, email, required): Enter the non-resident organizer's email address.
### 21. Event Venue
* **Event Venue** (`event_venue`, text, required): Enter the event venue.
### 22. Non Resident Organizer Venue
* **Non Resident Organizer Venue** (`non_resident_organizer_venue`, text, required): Enter the non-resident organizer's venue.
### 23. Non Resident Organizer Notes
* **Non Resident Organizer Notes** (`non_resident_organizer_notes`, note, required): Enter any additional notes or comments about the non-resident organizer.
### 24. Submit
* **Submit** (`submit`, text, required): Click this button to complete the registration process.
