# Forest Conservation Project Registration Form - Help Guide
## Purpose
This form is used to register new forest conservation projects. It collects essential information about the project, including its details, contact information, forest information, and submission date.

## How To Complete This Form
- Review the form carefully to ensure you are registering a valid project.
- Fill in all required fields (Project Type, Project Status, Project Category).
- Fill in non-required fields as necessary.
- Upload supporting files and documents (if required).

## Field-by-Field Explanation
* **Project Details** (`project_details`):
	+ Enter a brief description of your project.
* **Contact Info** (`contact_info`):
	+ Enter your contact name and details.
* **Forest Information** (`forest_info`):
	+ Enter information about the forest related to your project.
* **Submission** (`submission`):
	+ Enter a brief description of your project.
* **Email** (`email`):
	+ Enter a valid email address of the project manager or contact.
* **Phone** (`phone`):
	+ Enter the phone number of the project manager or contact.
* **Project Type** (`project_type`):
	+ Select the type of project you are registering.
* **Project Start Date** (`project_start_date`):
	+ Enter the start date of your project.
* **Project End Date** (`project_end_date`):
	+ Enter the end date of your project.
* **Project Budget** (`project_budget`):
	+ Enter the budget allocated for your project.
* **Submission Date** (`submission_date`):
	+ Enter the date of your project submission.
* **File Upload** (`file_upload`):
	+ Upload any supporting files or documents related to your project.
* **Latitude** (`latitude`):
	+ Enter the latitude of the project location.
* **Longitude** (`longitude`):
	+ Enter the longitude of the project location.
* **Location** (`location`):
	+ Enter the location of your project.
* **Project Status** (`project_status`):
	+ Select the current status of your project.
* **Project Category** (`project_category`):
	+ Select the category of your project.
* **Team Members** (`team_members`):
	+ List the team members involved in your project.
* **Project Manager** (`project_manager`):
	+ Enter the name of the project manager.
* **Contact Name** (`contact_name`):
	+ Enter the name of the contact person.
* **Contact Phone** (`contact_phone`):
	+ Enter the phone number of the contact person.
* **Contact Email** (`contact_email`):
	+ Enter the email address of the contact person.
* **Organization** (`organization`):
	+ Enter the name of the organization related to your project.
* **Notes** (`notes`):
	+ Enter any additional notes about your project.
* **Project Manager Email** (`project_manager_email`):
	+ Enter the email address of the project manager.
