# Simple Event Registration Form - Help Guide
## Purpose

This form is used to register an event, collect attendee information, and manage event details.

## How To Complete This Form

1. Fill in the required fields:
	* **Event Name**: Enter the name of the event.
	* **Event Date**: Enter the date of the event.
	* **Event Time**: Enter the time of the event.
	* **Event Type**: Choose the type of event (Registration, Cancellation, or Other).
	* **Event Status**: Choose the status of the event (Pending, Confirmed, or Cancelled).
	* **Event Host**: Enter the name of the event host.
	* **Event Host Phone**: Enter the phone number of the event host.
	* **Event Host Email**: Enter the email of the event host.
2. Provide optional information:
	* **Event Description**: Enter a brief description of the event.
	* **Event Venue**: Enter the location of the event.
	* **Event Status Message**: Enter a message about the event status.
3. Fill in attendee information:
	* **Attendee Name**: Enter the name of the attendee.
	* **Attendee Email**: Enter the email of the attendee.
	* **Attendee Phone**: Enter the phone number of the attendee.
	* **Attendee Event Date**: Enter the date of the attendee's event.
	* **Attendee Event Time**: Enter the time of the attendee's event.
	* **Attendee Event Venue**: Enter the location of the attendee's event.
	* **Attendee Event Type**: Choose the type of event the attendee is attending (Registration, Cancellation, or Other).
	* **Attendee Status**: Choose the status of the attendee (Registered, Confirmed, or Cancelled).
	* **Attendee Status Message**: Enter a message about the attendee's status.
