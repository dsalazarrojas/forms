# Season Pass Access Form - Help Guide
## Purpose

This form allows users to register for a season pass access with their organization's season pass program.

## How To Complete This Form

To complete this form, follow the steps below:

1. Enter your user information on the first page.
2. Select one or more season pass types that you want to access.
3. Check if you are affiliated with an organization and select the correct organization from the list.
4. If your season pass has an expiration date, select the corresponding date.
5. Provide any additional information about your season pass access.

## Field-by-Field Explanation

* **User Information** (`user_info`, text, required): 
This section is where you enter your user information. This could be any relevant details such as your name, contact number, or any other information that your organization may need to know about you.
* **Season Pass Type** (`season_pass_type`, select_multiple, required): 
Select one or more options to determine what type of season pass you want to access. The options are:
	+ 'Yes'
	+ 'No'
	+ Other
* **Organization Information** (`organization_info`, select_one, required): 
Select your organization from the provided options, or select 'Other' if your organization is not listed. If you choose 'Other', please provide details about your organization.
* **Expiration Date** (`expiration_date`, date, required (optional)): 
If your season pass has an expiration date, select it from the calendar.
* **Additional Information 1** (`additional_info`, text, optional): 
This is an optional field where you can provide any additional details about your season pass access.
* **Additional Information 2** (`additional_info_2`, text, optional): 
This is an optional field where you can provide any additional details about your season pass access.
