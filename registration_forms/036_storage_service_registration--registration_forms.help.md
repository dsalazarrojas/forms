# Storage Service Registration - Help Guide
## Purpose
The Storage Service Registration form is used to collect information for storage services registrations.

## How To Complete This Form
1. Select the storage type from the options provided.
2. Enter the storage capacity (if required).
3. Enter the move-in and move-out dates and times (if required).
4. Select the method of move-in and move-out (person or delivery).
5. Enter the move-in instructions and phone number (if required).
6. Enter the move-out instructions and phone number (if required).
7. Select the storage facility type (self or partner).
8. Enter the email and phone number (if required).
9. Enter the storage address, city, state, country, and zip code (if required).
10. Add any additional notes.

## Field-by-Field Explanation
* **Storage Type** (storage_type): Select the type of storage service you are registering.
* **Storage Capacity** (storage_capacity): Enter the total capacity of the storage unit (e.g., number of units).
* **Move-in Date** (move_in_date): Enter the date on which you will start using the storage service.
* **Move-in Time** (move_in_time): Enter the time on which you will start using the storage service.
* **Move-out Date** (move_out_date): Enter the date on which you will stop using the storage service.
* **Move-out Time** (move_out_time): Enter the time on which you will stop using the storage service.
* **Storage Duration** (storage_duration): Enter the duration of storage usage (if required).
* **Move-in Person** (move_in_person): Enter the person or company name who will be moving in.
* **Move-in Details** (move_in_details): Select the method of move-in (person or delivery).
* **Move-in Instructions** (move_in_instructions): Enter instructions for the move-in process.
* **Move-in Instructions Phone** (move_in_instructions_phone): Enter a phone number for move-in instructions.
* **Move-out Person** (move_out_person): Enter the person or company name who will be moving out.
* **Move-out Details** (move_out_details): Select the method of move-out (person or delivery).
* **Move-out Instructions** (move_out_instructions): Enter instructions for the move-out process.
* **Move-out Instructions Phone** (move_out_instructions_phone): Enter a phone number for move-out instructions.
* **Storage Facility** (storage_facility): Select whether the storage facility is self or partner.
* **Email** (email): Enter the email address associated with the storage service.
* **Phone** (phone): Enter a phone number associated with the storage service.
* **Address** (address): Enter the address of the storage facility.
* **City** (city): Enter the city of the storage facility.
* **State** (state): Enter the state of the storage facility.
* **Country** (country): Enter the country of the storage facility.
* **Zip** (zip): Enter the zip code of the storage facility.
* **Notes** (notes): Enter any additional notes about the storage service.
