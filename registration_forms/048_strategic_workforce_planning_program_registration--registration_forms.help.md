# Strategic Workforce Planning Program Registration - Help Guide
## Purpose
The Strategic Workforce Planning Program Registration form is used to register and manage sessions for the workforce planning program. This form allows you to select and register attendees, provide their details and preferences, and manage the organization of sessions.

## How To Complete This Form
To complete this form, follow these steps:

1. Select whether the session is yes or no.
2. Select whether the attendee needs assistance or not.
3. Select the training session (yes or no).
4. Enter the registration date.
5. Enter the attendee's name.
6. Enter the attendee's email address.
7. Enter the attendee's phone number.
8. Add any additional notes for the attendee.
9. Select whether the teams' organizers are involved (yes or no).
10. Add any comments from the attendee.
11. Select the session start and end dates.
12. Add any additional information for the attendee.

## Field-by-Field Explanation
* **Session Selection (<name>Session Selection</name>, <type>Select Multiple</type>, required/optional):** Please select whether the session is yes or no.
  * If you select yes, the attendee will be registered for the session.
  * If you select no, the attendee will not be registered.
* **Attendee Needs (<name>Attendee Needs</name>, <type>Select Multiple</type>, required/optional):** Please select whether the attendee needs assistance or not.
  * If you select yes, the attendee will be flagged as requiring assistance.
  * If you select no, the attendee will not be flagged as requiring assistance.
* **Training Session (<name>Training Session</name>, <type>Select One</type>, required/optional):** Please select the training session (yes or no).
  * If you select yes, the attendee will be registered for the training session.
  * If you select no, the attendee will not be registered.
* **Registration Date (<name>Registration Date</name>, <type>Date</type>, required/optional):** Enter the date the attendee registered for the session.
* **Attendee Name (<name>Attendee Name</name>, <type>Text</type>, required/optional):** Enter the name of the attendee.
* **Attendee E-mail (<name>Attendee E-mail</name>, <type>Email</type>, required/optional):** Enter the email address of the attendee.
* **Attendee Phone (<name>Attendee Phone</name>, <type>Text</type>, required/optional):** Enter the phone number of the attendee.
* **Notes (<name>Notes</name>, <type>Note</type>, required/optional):** Add any additional notes for the attendee.
* **Training Teams Organizers (<name>Training Teams Organizers</name>, <type>Select One</type>, required/optional):** Select whether the teams' organizers are involved (yes or no).
  * If you select yes, the teams will be notified of the session.
  * If you select no, the teams will not be notified.
* **Attendee Comments (<name>Attendee Comments</name>, <type>Text</type>, required/optional):** Add any comments from the attendee.
* **Session Start Date (<name>Session Start Date</name>, <type>Date</type>, required/optional):** Select the start date of the session.
* **Session End Date (<name>Session End Date</name>, <type>Date</type>, required/optional):** Select the end date of the session.
* **Attendee Additional Info (<name>Attendee Additional Info</name>, <type>Text</type>, required/optional):** Add any additional information for the attendee.
* **Attendee Attendance (<name>Attendee Attendance</name>, <type>Select One</type>, required/optional):** Select whether the attendee will attend the session (yes or no).
  * If you select yes, the attendee will attend the session.
  * If you select no, the attendee will not attend the session.

## Tips
* Make sure to select the correct session and training teams organizers to ensure accurate registration and notification.
* Enter accurate and complete information for the attendee to avoid confusion.
* Use the attendee's comments and additional info to tailor the session to their needs.
