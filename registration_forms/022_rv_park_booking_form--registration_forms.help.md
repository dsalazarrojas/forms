# rv park booking form - Help Guide

## Purpose
The "rv park booking form" is a tool for users to provide information regarding their visit to an rv park. This form helps park staff gather necessary details for a smooth and enjoyable stay.

## How To Complete This Form
1. Click on the "Submit" button to begin filling out the form.
2. Fill out the required and optional fields with the requested information.
3. Ensure that all required fields are filled out before proceeding.
4. Review the form for any errors or missing information before submission.

## Field-by-Field Explanation
* **Park Information (1)**: 
  Park Information is a text box for users to input the name of the park they are visiting.
* **Guest Information (2)**: 
  Guest Information is a text box for users to input their name, contact information, and other relevant details.
* **Dates (3)**: 
  Dates is a text box for users to input their arrival and departure dates.
* **Spot Type (4)**: 
  Spot Type allows users to select the type of spot they require, e.g. RV, Motorhome, Trailer, etc.
* **Spot Size (5)**: 
  Spot Size allows users to select the size of the spot they require, e.g. Small, Medium, Large, etc.
* **Park Name (6)**: 
  Park Name is a text box for users to input the name of the park they are visiting.
* **Guest Name (7)**: 
  Guest Name is a text box for users to input their name.
* **Phone (8)**: 
  Phone is a text box for users to input their phone number.
* **Email (9)**: 
  Email is a text box for users to input their email address.
* **Reservation Date (10)**: 
  Reservation Date is a date field for users to input their reservation date.
* **Reservation Time (11)**: 
  Reservation Time is a time field for users to input their reservation time.
* **Spot Location (12)**: 
  Spot Location is a multiple-select box for users to select the location of their spot, e.g. Row 1, Row 2, etc.
* **Spot Number (13)**: 
  Spot Number is a text box for users to input their spot number.
* **Comments (14)**: 
  Comments is a text box for users to input any comments they may have.
* **Special Requests (15)**: 
  Special Requests is a multiple-select box for users to select any special requests, e.g. Wi-Fi, Pet-friendly, etc.
* **Arrival Date (16)**: 
  Arrival Date is a date field for users to input their arrival date.
* **Departure (17)**: 
  Departure is a date field for users to input their departure date.
* **Park Rules (18)**: 
  Park Rules is a text box for users to input any park rules they may have.
* **Special Instructions (19)**: 
  Special Instructions is a text box for users to input any special instructions.
* **Park Rating (20)**: 
  Park Rating is a number field for users to input their rating of the park.
* **Guest Rating (21)**: 
  Guest Rating is a number field for users to input their rating of the park.
* **Comments (22)**: 
  Comments is a text box for users to input any comments they may have.
* **Park Service (23)**: 
  Park Service is a text box for users to input any park services they may require.
* **Park Contact Number (24)**: 
  Park Contact Number is a text box for users to input their park contact number.
* **Guest Notes (25)**: 
  Guest Notes is a text box for users to input any notes they may have.
