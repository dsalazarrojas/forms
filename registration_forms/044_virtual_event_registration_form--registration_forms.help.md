# Virtual Event Registration Form - Help Guide
## Purpose
The Virtual Event Registration Form is a tool for registering virtual events. This form collects essential information about the event, such as the event name, date, and attendees. The form also captures contact information for event organizers and attendees.

## How To Complete This Form
To complete this form, follow these steps:

1.  Enter your name and contact information in the fields marked as required.
2.  Provide the name of the event, including the date and start and end time.
3.  Fill out the description of the event, if desired.
4.  Select the registration type and purchase option for the event.
5.  Enter lists of attendees, as required.

## Field-by-Field Explanation
* **First Name** (Text, Required): Enter your first name.
* **Email** (Email, Required): Enter your email address.
* **Phone** (Text, Required): Enter your phone number.
* **Name Of Organization** (Text, Required): Enter the name of your organization.
* **Event Name** (Text, Required): Enter the name of the virtual event.
* **Event Date** (Date, Required): Enter the date of the virtual event.
* **Start Time** (Time, Required): Enter the start time of the virtual event.
* **End Time** (Time, Required): Enter the end time of the virtual event.
* **Description** (Text, Optional): Enter a description of the virtual event, if desired.
* **Registration Type** (Select One, Required): Select the type of registration for the virtual event.
* **Purchase Option** (Select Multiple, Optional): Select the options for purchasing virtual event tickets.
* **Note** (Note, Optional): Enter any additional comments or notes about the virtual event.
* **Email CC** (Email, Optional): Enter the email addresses to CC on the virtual event registration.
* **Phone CC** (Text, Optional): Enter the phone numbers to CC on the virtual event registration.
* **Purchase Order** (Select One, Required): Select the purchase order option for the virtual event.
* **List** (Text, Required): Enter the list of attendees for the virtual event.
* **List 2** (Text, Required): Enter the second list of attendees for the virtual event.
* **List 3** (Text, Required): Enter the third list of attendees for the virtual event.
* **List 4** (Text, Optional): Enter any additional lists of attendees, if desired.
* **List 5** (Text, Optional): Enter any additional lists of attendees, if desired.
* **List 6** (Text, Optional): Enter any additional lists of attendees, if desired.
* **List 7** (Text, Optional): Enter any additional lists of attendees, if desired.
* **List 8** (Text, Optional): Enter any additional lists of attendees, if desired.
* **List 9** (Text, Optional): Enter any additional lists of attendees, if desired.
* **List 10** (Text, Optional): Enter any additional lists of attendees, if desired.

Note: Required fields are marked with an asterisk (\*) symbol.
