# Dance Class Enrollment Form - Help Guide
## Purpose
The Dance Class Enrollment Form is used to collect information from students enrolling in dance classes, including contact details and class schedule preferences.

## How To Complete This Form
To complete the form, follow these steps:

1. Enter your Student Name in the "Student Name" field.
2. Enter your Student Email address in the "Student Email" field.
3. Enter your Student Phone number in the "Student Phone" field.
4. Enter your Student Address in the "Student Address" field.
5. Enter the Student City where you reside in the "Student City" field.
6. Enter the Student State where you reside in the "Student State" field.
7. Select the Dance Style you are interested in enrolling for:
	* Ballet
	* Contemporary
	* Hip Hop
	* Jazz
	* Tap
8. Select all classes you are interested in enrolling for from the provided options:
	* Jazz Class
	* Ballet Class
	* Contemporary Class
	* Hip Hop Class
	* Tap Class
9. If applicable, enter the Class Start and Class End Time for your preferred class schedule.

## Field-by-Field Explanation
* **Student Name**:
  * This is the field where you can enter your name.
  * Type: Text
  * Required: No
* **Student Email**:
  * This is the field where you can enter your email address.
  * Type: Email
  * Required: No
* **Student Phone**:
  * This is the field where you can enter your phone number.
  * Type: Text
  * Required: No
* **Student Address**:
  * This is the field where you can enter your home address.
  * Type: Text
  * Required: No
* **Student City**:
  * This is the field where you can enter the city where you reside.
  * Type: Text
  * Required: No
* **Student State**:
  * This is the field where you can enter the state where you reside.
  * Type: Text
  * Required: No
* **Dance Style**:
  * This is the field where you can select the dance style you are interested in.
  * Type: Select One
  * Required: Yes
* **Class Name**:
  * This is the field where you can select all classes you are interested in enrolling for.
  * Type: Select Multiple
  * Required: Yes
* **Class Start Time**:
  * This is the field where you can enter the start time of your preferred class schedule.
  * Type: Time
  * Required: No
* **Class End Time**:
  * This is the field where you can enter the end time of your preferred class schedule.
  * Type: Time
  * Required: No
* **Enrollment Date**:
  * This is the field where you can enter the date you plan to enroll for your dance class.
  * Type: Date
  * Required: No
