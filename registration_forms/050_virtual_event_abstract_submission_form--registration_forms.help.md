# Virtual Event Abstract Submission Form - Help Guide
## Purpose
The Virtual Event Abstract Submission Form is used to collect information from users about their event submission. Users will be asked about their presentation, its presenters, and other relevant details.

## How To Complete This Form
To complete this form, please follow these steps:
1.  Fill out the abstract submission form, providing a clear and concise description of your presentation.
2.  Select the presenters for your presentation and list their affiliations.
3.  Enter the email address of the first presenter.
4.  Add phone numbers for the presenters.
5.  Describe the presentation details.
6.  Upload files related to the presentation.
7.  Provide any additional comments.

## Field-by-Field Explanation

### Abstract Submission
*   **Abstract Submission**: Please enter a brief description of your presentation.
    *   Type: Text field
    *   Required: No

### Presenters
*   **Presenters**: Choose the presenters for your presentation.
    *   Type: Select from options: Speaker, Other
    *   Required: No

### Affiliations
*   **Affiliations**: Select the affiliations for each presenter.
    *   Type: Multiple selections from options: Affiliate 1, Affiliate 2, Affiliate 3
    *   Required: No

### E-mail Address
*   **E-mail Address**: Enter the email address of the first presenter.
    *   Type: Email
    *   Required: No

### Phone Number
*   **Phone Number**: Add phone numbers for the presenters.
    *   Type: Text field
    *   Required: No

### Presentation Details
*   **Presentation Details**: Enter a description of your presentation.
    *   Type: Text field
    *   Required: No

### Submission Date
*   **Submission Date**: This will be used to record the date of submission.
    *   Type: Date field
    *   Required: No

### Submission Time
*   **Submission Time**: Record the time of submission.
    *   Type: Time field
    *   Required: No

### Selected Files
*   **Selected Files**: Upload files related to your presentation.
    *   Type: File upload field
    *   Required: No

### Additional Comments
*   **Additional Comments**: Leave any additional comments for the organizers.
    *   Type: Text field
    *   Required: No

### Event Details
*   **Event Details**: Enter any details relevant to the event.
    *   Type: Text field
    *   Required: No

By following this guide, users should be able to fill out the Virtual Event Abstract Submission Form accurately and efficiently. If any questions arise, feel free to reach out to the organizers for further assistance.
