# Technology Innovation Registration - Help Guide
## Purpose
This form is used for registering new technologies and events with a focus on innovation. 

## How To Complete This Form

1. Fill in the title of the innovation.
2. Provide the name and email of the innovator.
3. Enter a description of the innovation.
4. Select the category of the innovation.
5. Input the event details, including the start and end dates and times.
6. Select the status of the innovation.
7. Upload any file related to the innovation (optional).
8. Add any notes about the innovation (optional).
9. Submit the form.

## Field-by-Field Explanation

* **Technology Innovation Submission** (`Technology Innovation Submission`, text, **required**): Input the title of the innovation.
* **Name Of Innovator** (`name_of_innovator`, text, **required**): Enter the name of the innovator.
* **Email** (`email`, email, **required**): Enter the email of the innovator.
* **Innovation Description** (`innovation_description`, text, **required**): Enter a description of the innovation.
* **File to Upload** (`file_to_upload`, text, optional): Upload any file related to the innovation.
* **Technology Category** (`technology_category`, select_one, **required**): Select the category of the innovation.
* **Event Location** (`event_location`, text, optional): Enter the location of the event.
* **Event Start Date** (`event_start_date`, date, **required**): Input the start date of the event.
* **Event End Date** (`event_end_date`, date, **required**): Input the end date of the event.
* **Event Start Time** (`event_start_time`, time, **required**): Input the start time of the event.
* **Event End Time** (`event_end_time`, time, **required**): Input the end time of the event.
* **Innovation Status** (`innovation_status`, select_multiple, **required**): Select the status of the innovation.
* **Technology Name** (`technology_name`, text, optional): Input the name of the technology.
* **Innovation Tag** (`innovation_tag`, text, optional): Enter a tag for the innovation.
* **Notes** (`notes`, note, optional): Add any notes about the innovation.
* **Submit** (`submit_button`, text, **required**): This is a submit button.
* **Success Message** (`success_message`, text, optional): This field is not currently used.
* **Technology Tags** (`technology_tags`, text, optional): Enter any tags for the technology.
* **Technology Url** (`technology_url`, text, optional): Input the URL of the technology.
* **Event Url** (`event_url`, text, optional): Input the URL of the event.
* **Event Name** (`event_name`, text, optional): Input the name of the event.
* **Event Start Date Time** (`event_start_date_time`, date, optional): Input the start date and time of the event.
* **Event End Date Time** (`event_end_date_time`, date, optional): Input the end date and time of the event.
* **Innovation Tags List** (`innovation_tags_list`, text, optional): Enter a list of tags for the innovation.
* **Submitted By** (`submitted_by`, text, optional): Input the name of the person who submitted the innovation.
