# Remote Work Culture Event Registration Form - Help Guide
## Purpose
This form is designed to collect information about remote work culture events, allowing us to understand the scope and details of each event. Please ensure that the event you register is not already registered, and if it is, you will be notified and asked to choose a new name.

## How To Complete This Form
- Please fill in your details, including your first and last name.
- Enter a valid email address for contact purposes.
- Provide a phone number for further contact or communication.
- Specify the name of the event, date, and time of the event.
- Mention the location where the event will take place.
- Write a brief description of the event.
- Finally, indicate the number of participants that can attend the event.

## Field-by-Field Explanation
- **First Name** (text): This is your first name. Please enter it accurately.
- **Last Name** (text): This is your last name. Please enter it accurately.
- **Email** (email): Please enter a valid email address for contact purposes.
- **Phone** (text): This is your phone number. Enter it for further contact or communication.
- **Event Name** (text): This is the name of the event you are registering.
- **Event Date** (date): Enter the date of the event, in the format dd/mm/yyyy.
- **Event Time** (time): Enter the time of the event.
- **Event Location** (text): This is the location where the event will take place.
- **Event Description** (text): Provide a brief description of the event.
- **Event Capacity** (number): Indicate the number of participants that can attend the event.
- **Event Capacity** (text): This is a duplicate of Event Capacity. Please ignore it.
 
## Tips
- Ensure that you register events that are not already registered. If an event is already registered, you may not be able to register it again.
- Fill the form accurately, ensuring all information is correct. This will help the event organizers with planning and execution.
