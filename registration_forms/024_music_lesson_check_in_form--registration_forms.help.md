# Music Lesson Check In Form - Help Guide

## Purpose
This form is designed to collect data on music lessons, including the date and time of the lesson, teacher and student identification, and notes on the topic covered during the lesson. The form allows teachers to efficiently track and record student attendance and lesson information.

## How To Complete This Form
To complete this form, please follow these steps:
1. Enter the date of the lesson in the format `YYYY-MM-DD` in the `lesson_date` field.
2. Select the time of the lesson in the format `HH:MM` in the `lesson_time` field.
3. Type in the teacher's ID number or name in the `teacher_id` field.
4. Type in the student's ID number or name in the student_id` field.
5. Enter the topic being covered during the lesson in the `lesson_topic` field.
6. Add any additional notes about the lesson in the `notes` field.
7. Enter your name or username in the `submitted_by` field.

## Field-by-Field Explanation

* **music lesson check in form data**: This field allows you to enter additional information or comments about the lesson, if needed.
	+ Type: `text`
	+ Required: No
* **Lesson Date**: Enter the date of the lesson in `YYYY-MM-DD` format (e.g., `2022-03-16`).
	+ Type: `date`
	+ Required: No
* **Lesson Time**: Select the time of the lesson in `HH:MM` format (e.g., `14:30`).
	+ Type: `time`
	+ Required: No
* **Teacher ID**: Enter the teacher's ID number or name.
	+ Type: `text`
	+ Required: No
* **Student ID**: Enter the student's ID number or name.
	+ Type: `text`
	+ Required: No
* **Lesson Topic**: Enter the topic being covered during the lesson.
	+ Type: `text`
	+ Required: No
* **Notes**: Add any additional notes or comments about the lesson.
	+ Type: `text`
	+ Required: No
* **Submitted By**: Enter your name or username.
	+ Type: `text`
	+ Required: No

## Tips
