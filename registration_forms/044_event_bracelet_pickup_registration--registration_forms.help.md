# Event Bracelet Pickup Registration - Help Guide
## Purpose
This form is used to collect and confirm information from attendees regarding their wristband pickup preferences. It serves as a crucial component of the event management process.

## How To Complete This Form

1. Start by filling out the **Event Details** fields to provide information about the event.
2. In the **Wristband Info** field, select the relevant option to specify the wristband type.
3. In the **Attendee Info** field, choose the relevant options for the attendee information.
4. Select the preferred **Location** for wristband pickup.
5. Fill out the **Notes** field with any additional comments or information.
6. Confirm all the provided information by selecting the correct options in the **Confirm** fields.

## Field-by-Field Explanation

* **Event Details** (Text): Enter the event details such as event type or status.
* **Wristband Info** (Select One): Select the type of wristband you are interested in.
* **Attendee Info** (Select Multiple): Choose the attendee information options that apply to you.
* **Location** (Select One): Choose the location where you would like to pick up your wristband.
* **Notes** (Text): Add any additional comments or information.
* **Confirm Event Details** (Select One): Confirm the event details provided earlier.
* **Confirm Attendee Info** (Select Multiple): Confirm the attendee information options selected earlier.
* **Confirm Wristband Info** (Select One): Confirm the wristband type selected earlier.
* **Confirm Notes** (Text): Confirm any additional comments or information added in the **Notes** field.
* **Confirm Location** (Select One): Confirm the location selected earlier.
* **Confirm Event Details 1/2** (Text): Confirm any additional event details.
* **Confirm Attendee Details** (Text): Confirm the attendee details.
* **Confirm Wristband Info 1/2** (Select One): Confirm the wristband information options.
* **Confirm Notes** (Text): Confirm the notes field.
