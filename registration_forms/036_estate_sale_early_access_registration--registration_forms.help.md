# Estate Sale Early Access Registration - Help Guide
## Purpose
The Estate Sale Early Access Registration form is used to collect essential details about an estate sale event. It helps organizers to provide accurate and timely information about the event to attendees and other stakeholders.

## How To Complete This Form
To complete this form, follow these steps:

1. Start by filling out the form's fields with the required and optional details about your estate sale event.
2. Enter the number of attendees you expect to invite in the **Attendee Capacity** field.
3. Enter the date and time of the event in the **Event Date** and **Event Time** fields.
4. Provide any additional early access details in the **Early Access Details** field.
5. List the names of the attendees in the **Attendees** field.
6. Enter the location of the event in the **Event Location** field.
7. If applicable, enter the early entry start and end dates in the **Early Entry Start Date** and **Early Entry End Date** fields.
8. Optionally, add any additional notes about the event in the **Notes** field.

## Field-by-Field Explanation

* **Early Access Registration** (`early_access_registration`, text, optional): Enter a brief description of the early access registration process.
* **Attendee Capacity** (`attendee_capacity`, number, optional): Enter the expected number of attendees for the event.
* **Event Date** (`event_date`, date, optional): Enter the date of the event.
* **Event Time** (`event_time`, time, optional): Enter the time of the event.
* **Early Access Details** (`early_access_details`, text, optional): Enter any additional details about early access.
* **Early Access Appointments** (`early_access_appointments`, text, optional): Enter any appointments related to early access.
* **Notes** (`notes`, note, optional): Enter any additional notes about the event.
* **Attendees** (`attendees`, select_one, true): Select the names of attendees from the list.
* **Event Location** (`event_location`, text, optional): Enter the location of the event.
* **Early Entry Start Date** (`early_entry_start_date`, date, optional): Enter the start date of early entry.
* **Early Entry End Date** (`early_entry_end_date`, date, optional): Enter the end date of early entry.
* **Event Start Date** (`event_start_date`, date, optional): Enter the start date of the event.
* **Event End Date** (`event_end_date`, date, optional): Enter the end date of the event.

This guide will help you fill out the Estate Sale Early Access Registration form accurately and efficiently.
