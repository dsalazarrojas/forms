# National ID Delivery Form - Help Guide
## Purpose
This form is designed to collect information about national ID delivery details for efficient and secure processing. Please fill out the form accurately and thoroughly to ensure correct delivery.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the "National ID Number" field with the relevant national ID number.
2. Choose the type of national ID from the options provided.
3. Select the preferred delivery method and location.
4. Enter the date and time of delivery.
5. Choose the current status of the national ID delivery.
6. Add any additional notes or comments.

## Field-by-Field Explanation
* **National ID Form** (national_id_form, text, optional): This field is used to enter the national ID number.
* **Recipient Name** (recipient_name, text, optional): This field is used to enter the recipient's name.
* **National ID Type** (national_id_type, select_one, optional): This field is used to select the type of national ID from the options provided.
* **National ID Number** (national_id_number, text, optional): This field is used to enter the national ID number.
* **Delivery Method** (delivery_method, select_one, optional): This field is used to select the preferred delivery method.
* **Delivery Location** (delivery_location, select_one, optional): This field is used to select the preferred delivery location.
* **Delivery Date** (delivery_date, date, optional): This field is used to enter the date of delivery.
* **Delivery Time** (delivery_time, time, optional): This field is used to enter the time of delivery.
* **Delivery Status** (delivery_status, select_one, optional): This field is used to select the current status of the national ID delivery.
* **Notes** (notes, note, optional): This field is used to add any additional notes or comments.

## Tips
- Make sure to fill out all required fields to ensure accurate processing.
- Double-check the information entered before submitting the form.
- For any issues or concerns, contact form@gic.mx.
