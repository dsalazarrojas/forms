# Resource Person Information Form - Help Guide
## Purpose
The Resource Person Information Form is designed to collect information about resource persons for internal use within the organization.
## How To Complete This Form
Fill out this form with the relevant information about the resource person.
1. Start on the "Main Page" where you will find the general information about the form.
2. Fill in the "Name" field with the name of the resource person.
3. Input the "Job Title" of the resource person in the respective field.
4. Select the relevant "Job Type" from the list provided.
5. Provide the "Work Email" of the resource person in the field.
6. Input the "Phone Number" of the resource person in the field.
7. In the "Work Address" field, provide the work address of the resource person.
8. Input the "Availability" start date in the date field.
9. Input the "Availability End" date in the date field.
10. In the "Qualifications List", provide any relevant qualifications or skills of the resource person.
## Field-by-Field Explanation
* **Name** (text): A field to input the name of the resource person.
* **Job Title** (text): A field to specify the job title of the resource person.
* **Job Type** (multiple selection): Select from the list of predefined job types to indicate the resource person's role.
* **Work Email** (email): A field to input the work contact email of the resource person.
* **Phone Number** (text): A field to input the work contact phone number of the resource person.
* **Work Address** (note): A field to input the work address of the resource person.
* **Availability** (date): A field to input the start date of the resource person's availability.
* **Availability End** (date): A field to input the end date of the resource person's availability.
* **Qualifications List** (text): A field to input any relevant qualifications or skills of the resource person.
# Tips
* Please ensure that you're not duplicating an existing record.
* Please fill out the form with accurate and relevant information.
