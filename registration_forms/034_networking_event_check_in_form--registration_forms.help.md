# Networking Event Check In Form - Help Guide
## Purpose
The Networking Event Check In Form is used to record the attendance status and details of attendees at a networking event or other type of meeting. This form helps event organizers track attendance, manage check-in processes, and gather essential information about attendees.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the required fields with accurate and up-to-date information.
2. Select the correct event type from the options provided.
3. Indicate the attendee's check-in status as "Checked In", "Not Checked In", or "Unknown" depending on their attendance.
4. Add any relevant notes about the attendee, if needed.
5. Submit the form for review and updates.

## Field-by-Field Explanation

* **Event Name**: The name of the event where the attendee is registered.
	+ Type: Text field
	+ Required: Yes
* **Attendee First Name**: Enter the first name of the attendee.
	+ Type: Text field
	+ Required: Yes
* **Attendee Last Name**: Enter the last name of the attendee.
	+ Type: Text field
	+ Required: Yes
* **Event Start Time**: The start time of the event.
	+ Type: Date field
	+ Required: Yes
* **Event End Time**: The end time of the event.
	+ Type: Time field
	+ Required: Yes
* **Attendee Organization**: The organization the attendee represents or is affiliated with.
	+ Type: Text field
	+ Required: Yes
* **Attendee Title**: Optionally, enter the attendee's title or position within their organization.
	+ Type: Text field
	+ Required: No
* **Attendee Email**: Enter the attendee's email address.
	+ Type: Email field
	+ Required: Yes
* **Attendee Phone**: Enter the attendee's phone number.
	+ Type: Text field
	+ Required: Yes
* **Checkin Status**: Select the attendee's check-in status from the provided options (Checked In, Not Checked In, or Unknown).
	+ Type: Select One field
	+ Required: No
* **Notes**: Add any additional information or comments about the attendee, if needed.
	+ Type: Note field
	+ Required: No
* **Organization**: Optionally, enter the organization the attendee is registered from or affiliated with.
	+ Type: Text field
	+ Required: No
* **Event Type**: Select the type of event from the provided options (Networking Event, Conference, or Meeting).
	+ Type: Select One field
	+ Required: Yes
* **Location**: Enter the location of the event.
	+ Type: Text field
	+ Required: Yes

## Tips

* Ensure all required fields are completed accurately and up-to-date.
* Use the correct event type to categorize the event.
* Select the correct check-in status for the attendee.
* Use the notes field for any additional information or comments about the attendee.
* Review the form carefully before submission to ensure accuracy and completeness.
