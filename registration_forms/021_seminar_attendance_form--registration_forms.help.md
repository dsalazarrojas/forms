# Seminar Attendance Form - Help Guide
## Purpose
This form is used for seminar attendees to provide their information to seminar organizers.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill out the "Attendee name" field with the name of the attendee.
2. Enter the email of the attendee in the "Attendee email" field.
3. Enter the phone number of the attendee in the "Attendee phone" field.
4. If the seminar you are attending has a date, select it in the "Seminar date" field.
5. If the seminar you are attending has a time, select it in the "Seminar time" field.
6. Select your attendance status in the "Attendee status" field: Attending, Not Attending, or Maybe.
7. If you have any additional information you'd like to share with the seminar organizer, enter it in the "Additional info" field.

## Field-by-Field Explanation
* **Seminar Attendance Form Input**: This is the title of the form.
* **Attendee name**: Enter the name of the attendee (e.g., John Doe).
* **Attendee email**: Enter the email of the attendee (e.g., johndoe@example.com).
* **Attendee phone**: Enter the phone number of the attendee (e.g., 123-456-7890).
* **Seminar date**: Select the date of the seminar if provided.
* **Seminar time**: Select the time of the seminar if provided.
* **Attendee status**: Select your status for attending the seminar from the following options:
	+ Attending
	+ Not Attending
	+ Maybe
* **Additional info**: If you have any additional information, please share it here. This is a free-form text field for any other details you'd like to provide.
