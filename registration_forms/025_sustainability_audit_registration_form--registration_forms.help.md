# Sustainability Audit Registration Form - Help Guide

## Purpose
This form is used to register for a sustainability audit with the organization. It helps the auditor gather information from the organization and allows the organization to manage the registration process and assign a tool to the auditor.

## How To Complete This Form
1. **Select "Yes" or "No" for Audit Request**: Choose whether you want to register for a sustainability audit.
2. **Enter Audit Date**: Enter the date you want to conduct the audit.
3. **Enter Contact Name**: Enter your name and title (e.g., John Doe, Sustainability Specialist).
4. **Enter Contact E-mail**: Enter your email address.
5. **Enter Preferred Date**: Enter your preferred date for the audit (leave blank if you have no preference).
6. **Enter Contact Phone**: Enter your phone number (including area code and extension).
7. **Add Notes**: Enter any additional comments or instructions for the auditor.
8. **Select Assigned Tool**: Choose the tool you want to be assigned for the audit from the options provided, or select "Custom" if you have a different tool in mind.

## Field-by-Field Explanation
* **Audit Request**: 
	+ This field is used to indicate whether you want to register for a sustainability audit.
	+ Please select "Yes" if you want to register, and "No" if you don't.
* **Audit Date**: 
	+ Enter the date you want to conduct the audit.
	+ If you leave this field blank, the system will default to the current date.
* **Contact Name**: 
	+ Enter your name and title (e.g., John Doe, Sustainability Specialist).
	+ This field is used to identify you as the auditor.
* **Contact E-mail**: 
	+ Enter your email address.
	+ This field is used to contact you for further instructions or updates.
* **Preferred Date**: 
	+ Enter your preferred date for the audit.
	+ If you leave this field blank, the system will default to your available dates.
* **Contact Phone**: 
	+ Enter your phone number (including area code and extension).
	+ This field is used for contacting you in case of further instructions or updates.
* **Note**: 
	+ Enter any additional comments or instructions for the auditor.
	+ This field is optional and can be used to provide more context or information.
* **Assigned Tool**: 
	+ Select the tool you want to be assigned for the audit from the options provided.
	+ If you select "Custom", you can specify a different tool in the comments field.
