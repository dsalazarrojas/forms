  # Machine Performance Benchmark Registration - Help Guide
## Purpose
The purpose of this form is to register the performance benchmarks of machines in the database.
## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the required fields with accurate information about the machine, including the manufacturer, model, and engine type.
2. Select the appropriate options for the machine's performance characteristics, such as whether it has a certain type of fuel or emission standards.
3. Enter any additional information that may be relevant to the machine's performance, such as operating hours or fuel efficiency.
4. Check that the machine is not a duplicate in the database and submit the form.

## Field-by-Field Explanation
* **Machine Performance Benchmark Registration** (`1`, `text`, required): Enter a brief description of the machine's performance benchmark.
* **Manufacturer Name** (`2`, `text`, required): Enter the name of the machine's manufacturer.
* **Machine Model** (`3`, `text`, required): Enter the model or type of the machine.
* **Machine Type** (`4`, `select_one`, not required): Select 'Yes' if the machine has this type of performance characteristic.
* **Machine Rating** (`5`, `text`, required): Enter the machine's performance rating.
* **Engine Type** (`6`, `text`, required): Enter the type of engine used in the machine.
* **Horsepower** (`7`, `number`, required): Enter the machine's horsepower rating.
* **Torque** (`8`, `number`, required): Enter the machine's torque rating.
* **Operating Hours** (`9`, `number`, required): Enter the number of operating hours on the machine.
* **Fuel Type** (`10`, `select_one`, not required): Select 'Yes' if the machine uses this type of fuel.
* **Fuel Efficiency** (`11`, `text`, required): Enter the machine's fuel efficiency rating.
* **Emissions Standards** (`12`, `select_one`, required): Select 'Yes' if the machine meets the emissions standards.
* **Emissions Tested** (`13`, `text`, not required): Enter any additional information about the machine's emissions testing.
* **Transmission Type** (`14`, `select_one`, not required): Select 'Yes' if the machine has this type of transmission.
* **Transmission Type Other** (`15`, `text`, not required): Enter any additional information about the machine's transmission type.
* **Engine Number** (`16`, `text`, not required): Enter the machine's engine number.
* **Transmission Number** (`17`, `text`, not required): Enter the machine's transmission number.
* **Engine Capacity** (`18`, `text`, not required): Enter the machine's engine capacity.
* **Transmission Capacity** (`19`, `text`, not required): Enter the machine's transmission capacity.
* **Horsepower Tested** (`20`, `text`, not required): Enter any additional information about the machine's horsepower testing.
* **Operating Conditions** (`21`, `text`, required): Enter a brief description of the machine's operating conditions.
* **Operating Hours Tested** (`22`, `text`, not required): Enter any additional information about the machine's operating hours.
* **Emissions Certificate** (`23`, `select_one`, not required): Select 'Yes' if the machine has an emissions certificate.
* **Certification Status** (`24`, `select_one`, not required): Select the machine's certification status.
* **Comments** (`25`, `note`, not required): Enter any additional comments about the machine's performance benchmark.
