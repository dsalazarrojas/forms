# drivers_license_class_registration - Help Guide
## Purpose
The form is designed to collect information for registering students for a driving license class, including class type, contact details, driving school information, schedule, payment method, and other relevant details.

## How To Complete This Form
1. Start by selecting the "Yes" or "No" option for "Class Type" (Field 1).
2. Enter the student's name in the "Student Name" field (Field 2).
3. Enter the student's email address in the "Student Email" field (Field 3).
4. Enter the student's phone number in the "Student Phone" field (Field 4).
5. Select the driving school from the available options in the "Driving School" field (Field 5).
6. Choose the schedule date for the class in the "Schedule Date" field (Field 6).
7. Choose the schedule time for the class in the "Schedule Time" field (Field 7).
8. Enter the class duration in the "Class Duration" field (Field 8).
9. Select the payment method for the class in the "Payment Method" field (Field 9).
10. Enter any additional payment information in the "Payment Info" field (Field 10).
11. Enter the total payment for the class in the "Total Payment" field (Field 11).
12. Add any relevant notes in the "Notes" field (Field 12).
13. Select the class level (High or Low) in the "Class Level" field (Field 13).
14. Enter any additional class level information in the "Class Level Info" field (Field 14).
15. (Optional) Enter the schedule date for an additional class in the "Schedule Date 2" field (Field 15).
16. (Optional) Enter the schedule time for an additional class in the "Schedule Time 2" field (Field 16).
17. (Optional) Enter the class duration for an additional class in the "Class Duration 2" field (Field 17).
18. (Optional) Enter the total payment for an additional class in the "Total Payment 2" field (Field 18).
19. (Optional) Add any additional notes for an additional class in the "Notes 2" field (Field 19).
20. Select whether the driver's license type is applicable (Field 20).
21. Select whether the driver's license class type is applicable (Field 21).
22. Enter the student's license number in the "Student License Number" field (Field 22).
23. Select the license number type in the "License Number Type" field (Field 23).
24. Enter any instructor information in the "Instructor Info" field (Field 24).

* **Student Phone** (Field 4, text, optional): Enter the student's phone number.

* **Schedule Date** (Field 6, date, required): Choose the schedule date for the class.
* **Schedule Time** (Field 7, time, required): Choose the schedule time for the class.
* **Class Duration** (Field 8, number, required): Enter the class duration.
* **Payment Method** (Field 9, select_one, required): Select the payment method for the class.
* **Payment Info** (Field 10, text, optional): Enter any additional payment information.
* **Total Payment** (Field 11, number, optional): Enter the total payment for the class.
* **Notes** (Field 12, note, optional): Add any relevant notes for the class.
* **Class Level** (Field 13, select_one, required): Select the class level (High or Low).
* **Class Level Info** (Field 14, text, optional): Enter any additional class level information.
* **Schedule Date 2** (Field 15, date, optional): (Optional) Enter the schedule date for an additional class.
* **Schedule Time 2** (Field 16, time, optional): (Optional) Choose the schedule time for an additional class.
* **Class Duration 2** (Field 17, number, optional): (Optional) Enter the class duration for an additional class.
