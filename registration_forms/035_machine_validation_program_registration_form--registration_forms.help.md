# Machine Validation Program Registration Form - Help Guide
## Purpose
The Machine Validation Program Registration Form is used to register machines for the program. 

## How To Complete This Form
To complete the form, follow the steps below:

1. Start by providing user input in the "User Input" section. This includes any information about yourself or the person submitting the form.
2. Next, fill out the "Machine Details" section with relevant information about the machine being registered.
3. In the "Machine Type" section, select the type of machine you are registering.
4. For "Machine Model", select any applicable models for the machine.
5. In the "Machine Year" and "Machine Hours" fields, enter the year and hours of the machine, respectively.
6. Provide the machine's location in the "Machine Location" field.
7. If applicable, upload an image of the machine in the "Machine Image" field.
8. Add any notes regarding the machine in the "Machine Notes" field.
9. Add any notes for your reference in the "User Notes" field.
10. Finally, click the "Submit" button to complete and submit your registration.

## Field-by-Field Explanation
* **User Input** (id: 1, name: user_input, required: false): Enter your name and any other relevant information about yourself.
* **Machine Details** (id: 2, name: machine_details, required: false): Provide any relevant details about the machine being registered, such as its serial number or make and model.
* **Machine Type** (id: 3, name: machine_type, required: false): Select the type of machine you are registering (e.g., "Yes" or "No").
* **Machine Model** (id: 4, name: machine_model, required: false): Select any applicable models for the machine being registered.
* **Machine Year** (id: 5, name: machine_year, required: false): Enter the year of the machine.
* **Machine Hours** (id: 6, name: machine_hours, required: false): Enter the machine's operational hours.
* **Machine Location** (id: 7, name: machine_location, required: false): Enter the location of the machine.
* **Machine Image** (id: 8, name: machine_image, required: false): Upload an image of the machine (if applicable).
* **Machine Notes** (id: 9, name: machine_notes, required: false): Add any notes about the machine in this field.
* **User Notes** (id: 10, name: user_notes, required: false): Add any notes for your reference in this field.
* **Submit** (id: 11, name: submit, required: false): Click the "Submit" button to complete and submit your registration.

Note: Please ensure that you review all fields and ensure that the form is complete before submitting it.
