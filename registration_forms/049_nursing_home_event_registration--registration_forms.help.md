# Nursing Home Event Registration - Help Guide
## Purpose
The Nursing Home Event Registration form is used to record events happening in the facility, such as resident or guest arrivals, departures, or other events. This information is crucial for staff to track and manage these events efficiently.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the relevant option for "Resident or Guest Registration" to indicate whether the event is related to a resident or guest.
2. Enter the name of the resident or guest if applicable.
3. Choose the date of the event.
4. Select the time of the event.
5. Enter the contact number of the person to be contacted in case of an emergency.
6. Provide the email address of the person to be contacted in case of an emergency.
7. Select the type of event (e.g., Nursing Home Event, Other, or Birthday Party).
8. Include any additional notes about the event.
9. Specify the name of the staff member responsible for the event.

## Field-by-Field Explanation
* **Resident or Guest Registration** (`residency`, `select_multiple`, optional): This field indicates whether the event is related to a resident or guest within the facility. Select "Yes" if the event is for a resident, "No" if it's for a guest.
* **Resident Name** (`resident_name`, `text`, optional): Enter the name of the resident if the event is for a resident.
* **Guest Name** (`guest_name`, `text`, optional): Enter the name of the guest if the event is for a guest.
* **Date** (`date`, `date`, optional): Choose the date of the event.
* **Time** (`time`, `time`, optional): Select the time of the event.
* **Contact Number** (`contact_number`, `text`, optional): Enter the contact number of the person to be contacted in case of an emergency.
* **Email** (`email`, `email`, optional): Provide the email address of the person to be contacted in case of an emergency.
* **Event Type** (`event_type`, `select_one`, optional): Select the type of event (e.g., Nursing Home Event, Other, or Birthday Party).
* **Notes** (`notes`, `note`, optional): Include any additional notes about the event.
* **Staff Name** (`staff_name`, `text`, optional): Specify the name of the staff member responsible for the event.

## Tips
* Make sure to register each event accurately and consistently to ensure efficient tracking and reporting.
* If you're unsure about any field, refer to the nursing home's policies and procedures for guidance.
* Double-check your entries before submitting the form to avoid errors.
