# Workforce Development Week Registration Form - Help Guide
## Purpose
This form is for attendees to register for events during Workforce Development Week. To register, please select the event you are interested in and provide the required information for that event.

## How To Complete This Form
To complete this form, follow these steps:

1. Review the available events on the next page.
2. Select the event you are interested in attending.
3. Fill in the relevant information for that event, including event details such as date, time, and location.
4. Optionally, select the speaker and speaker bio for that event.
5. Click the "Submit" button to complete your registration.

## Field-by-Field Explanation
### 1. **Registration** (Required: False)
* Registration: Enter a brief description of your registration for the selected event.

### 2. **Attendee** (Required: False)
* Attendee: Enter your name or the name of the person attending the event.

### 3. **Contact Information** (Required: False)
* Contact Information: Enter any additional contact information you would like to share with the event organizers.

### 4. **Event Type** (Required: False)
* Event Type: Select the type of event you are interested in attending (Option 1, Option 2, or Option 3).

### 5. **Date** (Required: False)
* Date: Enter the date of the event.

### 6. **Start Time** (Required: False)
* Start Time: Enter the start time of the event.

### 7. **End Time** (Required: False)
* End Time: Enter the end time of the event.

### 8. **Session** (Required: False)
* Session: Enter a brief description of the session you are attending.

### 9. **Session Details** (Required: False)
* Session Details: Enter any additional details about the session you are attending.

### 10. **Session Leader** (Required: False)
* Session Leader: Enter the name of the session leader.

### 11. **Session Location** (Required: False)
* Session Location: Enter the location of the session.

### 12. **Session Capacity** (Required: False)
* Session Capacity: Enter the number of attendees the session can hold.

### 13. **Session Max Capacity** (Required: False)
* Session Max Capacity: Enter the maximum capacity of the session.

### 14. **Event Start Date** (Required: False)
* Event Start Date: Enter the start date of the event.

### 15. **Event End Date** (Required: False)
* Event End Date: Enter the end date of the event.

### 16. **Session Duration** (Required: False)
* Session Duration: Enter the duration of the session.

### 17. **Speaker** (Required: False)
* Speaker: Select the speaker you would like to attend.

### 18. **Speaker Bio** (Required: False)
* Speaker Bio: Enter a brief bio of the speaker.

### 19. **Speaker Image** (Required: False)
* Speaker Image: Enter the image of the speaker.

### 20. **Event Description** (Required: False)
* Event Description: Enter a brief description of the event.

### 21. **Event Location** (Required: False)
* Event Location: Enter the location of the event.

### 22. **Event Capacity** (Required: False)
* Event Capacity: Enter the number of attendees the event can hold.

### 23. **Event Max Capacity** (Required: False)
* Event Max Capacity: Enter the maximum capacity of the event.

### 24. **Submit** (Required: False)
* Submit: Click this button to complete your registration.

Please note that this form is for informational purposes only and the provided fields are subject to change. It is recommended that you review the form carefully before completing it.
