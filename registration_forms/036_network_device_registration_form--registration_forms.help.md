# Network Device Registration Form - Help Guide
## Purpose
The Network Device Registration Form is used for administrative purposes to track and document network devices, their details, and the users associated with them.

## How To Complete This Form

To complete this form, please follow these steps:

1. Select the relevant page (Network Device Registration or Device Details).
2. Fill out the required fields for the selected page.
3. Verify that all required fields are complete before proceeding.
4. Review the form for accuracy before submitting.

## Field-by-Field Explanation

* **Network Device Registration**: Select this page to register a new network device. 
	+ This field is not required for registration, but it helps the administrator to identify the page.
* **Device Details**: Enter details about the device, such as its serial number, model, and description.
	+ This field is not required, but it helps the administrator to understand the device's specifications.
* **Contact Details**: Enter information about the user associated with the device, including their name, email, and phone number.
	+ This field is not required, but it helps the administrator to contact the user in case of any issues.
* **Registration Details**: Enter date and time the device was registered.
	+ This field is not required, but it helps the administrator to track the registration date and time.
* **Device Type**: Select the type of device being registered (Server, Router, Switch).
	+ This field is not required, but it helps the administrator to categorize devices by type.
* **Network Location**: Select the location of the device within the network (Office, Home, Other).
	+ This field is not required, but it helps the administrator to track the device's location within the network.
* **Serial Number**: Enter the device's serial number.
	+ This field is not required, but it helps the administrator to identify the device.
* **IP Address**: Enter the device's IP address.
	+ This field is not required, but it helps the administrator to identify the device within the network.
* **MAC Address**: Enter the device's MAC address.
	+ This field is not required, but it helps the administrator to identify the device.
* **Device Name**: Enter the device's name.
	+ This field is not required, but it helps the administrator to identify the device.
* **User Name**: Enter the user's name associated with the device.
	+ This field is not required, but it helps the administrator to identify the user.
* **User Email**: Enter the user's email address.
	+ This field is not required, but it helps the administrator to contact the user.
* **User Phone**: Enter the user's phone number.
	+ This field is not required, but it helps the administrator to contact the user.
* **Date Registered**: Enter the date the device was registered.
	+ This field is not required, but it helps the administrator to track the registration date.
* **Time Registered**: Enter the time the device was registered.
	+ This field is not required, but it helps the administrator to track the registration time.
* **Note**: Enter any additional notes about the device.
	+ This field is not required, but it helps the administrator to add any extra information.

## Tips

* Please ensure that all required fields are completed before submitting the form.
* Double-check for correct spelling and accuracy before submitting the form.
* If you have any questions or concerns, contact your supervisor or helpdesk for assistance.
