# Performance Event Registration - Help Guide
## Purpose

This form is designed to collect information about a performance event for planning and organization purposes. It helps event planners gather essential details about the event, including its title, venue, dates, start and end time, and a brief description.

## How To Complete This Form

1.  Navigate to the Performance Event Registration form.
2.  Click on the form link to start filling out the form.
3.  Fill out the required and optional fields as necessary.
4.  Review your entries carefully before submitting the form.
5.  Click on the "Submit" button to complete the registration process.

## Field-by-Field Explanation

*   **Event Planner (Event Planner)**: This field is a text area where you can enter the name of the person in charge of the event. It is not a mandatory field.
*   **Event Venue (Event Venue)**: Enter the location where the event will take place.
*   **Event Title (Event Title)**: Enter a brief title for the event.
*   **Event Dates (Event Dates)**: Select the dates of the event from the given options.
*   **Start Time (Start Time)**: Enter the start time of the event.
*   **End Time (End Time)**: Enter the end time of the event.
*   **Event Description (Event Description)**: A brief description of the event.
*   **Performance Details (Performance Details)**: Enter any additional details about the event performance.

## Tips

*   Make sure to enter accurate and complete information to ensure the event is properly registered.
*   If you are unsure about any information, please consult with the event planner or relevant authorities.
