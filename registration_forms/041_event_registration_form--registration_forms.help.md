# Event Registration Form - Help Guide
## Purpose
The Event Registration Form is a user-facing form designed to collect event registration information from participants. This form is used to gather personal details, event specifics, and payment information for event registration purposes.

## How To Complete This Form
To complete the Event Registration Form, follow these steps:

1. Fill out the form by entering your First Name and Last Name in the First Name and Last Name fields, respectively.
2. Enter your Email address in the Email field. Ensure it is a valid email address.
3. Provide your Phone number in the Phone field.
4. Select the type of event you are registering for by choosing an option from the Event Type dropdown list.
5. Enter the date of the event in the Event Date field in the YYYY-MM-DD format.
6. Select the start time of the event from the Event Time dropdown list.
7. Enter the event venue in the Event Venue field.
8. Enter the Registration Fee amount, which is not mandatory.
9. Choose the payment method from the Payment Method dropdown list.
10. Add any additional comments about your registration in the Comments field.
11. Enter a brief description of the event in the Event Description field, which is optional.

## Field-by-Field Explanation
- **First Name** (`first_name`, Text, Required): Enter your first name.
- **Last Name** (`last_name`, Text, Not Required): Enter your last name.
- **Email** (`email`, Email, Not Required): Enter a valid email address.
- **Phone** (`phone`, Text, Not Required): Enter your phone number.
- **Event Type** (`event_type`, Select One, Required): Select the type of event you are registering for.
- **Event Date** (`event_date`, Date, Not Required): Enter the date of the event in the YYYY-MM-DD format.
- **Event Time** (`event_time`, Time, Not Required): Select the start time of the event.
- **Event Venue** (`event_venue`, Text, Not Required): Enter the event venue.
- **Registration Fee** (`registration_fee`, Number, Not Required): Enter the registration fee amount.
- **Payment Method** (`payment_method`, Select One, Required): Choose the payment method.
- **Comments** (`comments`, Note, Not Required): Add any additional comments about your registration.
- **Event Description** (`event_description`, Text, Not Required): Enter a brief description of the event.
