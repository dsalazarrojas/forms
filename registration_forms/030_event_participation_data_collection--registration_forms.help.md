# Event Participation Data Collection - Help Guide
## Purpose
This form is designed to collect data about event participation, providing a structured and organized format for capturing essential details. 

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the event title and provide a brief description of the event.
2. Add information about the event attendees, including their names, contact details, and any other relevant details.
3. Specify the event start and end dates and times.
4. Enter the event's organizer's name and contact details.
5. Record the number of attendees and any additional notes about the event.

## Field-by-Field Explanation

* **Event Participation Data Collection** (`event_participation_data_collection_page1`, text, optional): This is the title of the form and a brief description of what it collects data about. Enter a title and a brief description of the event.
* **Event Attendee Info** (`event_attendee_info`, text, optional): Enter information about the attendees, including their names, contact details, and any other relevant details.
* **Event Details** (`event_details`, text, optional): Provide a brief description of the event, including its purpose, location, and any other relevant details.
* **Event Start Date** (`event_start_date`, date, optional): Enter the start date of the event. This field is a date picker, so choose a date from the calendar or enter it manually.
* **Event Start Time** (`event_start_time`, time, optional): Enter the start time of the event. This field is a time picker, so choose a time from the list.
* **Event End Date** (`event_end_date`, date, optional): Enter the end date of the event. This field is a date picker, so choose a date from the calendar or enter it manually.
* **Event End Time** (`event_end_time`, time, optional): Enter the end time of the event. This field is a time picker, so choose a time from the list.
* **Event Organizer** (`event_organizer`, text, optional): Enter the name of the event's organizer and their contact details.
* **Event Attendance** (`event_attendance`, text, optional): Record the number of attendees for the event.
* **Event Notes** (`event_notes`, note, optional): Add any additional notes or comments about the event. This field is a free text area for capturing extra information.
