# Music School Competition Tournament Entry Form - Help Guide
## Purpose
The Music School Competition Tournament Entry Form is a mandatory document required for students to participate in the music school competitions. It helps to gather essential information about each student's performance, their category of participation, and other relevant details.

## How To Complete This Form

1.  **Fill in the student's name**: Enter the student's first name in the "First name" field and last name in the "Last name" field.
2.  **Add student grade level**: Select the student's grade level from the provided options.
3.  **Enter school details**: Type in the student's school name and address in their respective fields.
4.  **Provide teacher information**: Enter the teacher's name, email, and qualifications in their respective fields.
5.  **Enter student event details**: Select the event name, date, and time of the competition from the provided options.
6.  **Specify student category**: Choose the student's category of participation (Vocal or Instrumental).
7.  **Enter ensemble details**: Type in the student's ensemble (group) details if applicable.
8.  **Choose teacher qualifications**: Select the teacher's education level from the provided options.
9.  **Select student instrument**: Select the student's instrument of choice.
10. **Enter parent information**: Enter the parent's name and confirm permission for the student's participation.
11. **Enter student dietary needs**: Specify any dietary requirements or allergies the student may have.
12. **Enter signature**: Both the parent and student must provide their signatures to confirm the information provided.

## Field-by-Field Explanation
* **First name** (`student_first_name`, text, required): Enter the student's first name. 
* **Last name** (`student_last_name`, text, required): Enter the student's last name. 
* **Grade** (`student_grade`, number, required): Select the student's grade level.
* **School** (`student_school`, text, required): Type in the student's school name.
* **Teacher name** (`teacher_name`, text, required): Enter the teacher's name.
* **Teacher email** (`teacher_email`, email, required): Enter the teacher's email address.
* **Parent name** (`parent_name`, text, required): Enter the parent's name.
* **Parent email** (`_this field is not present in the form`): This field is not present in the form, so it will not be included in the explanation. 
* **Address** (`student_address`, text, required): Type in the student's address.
* **Contact number** (`contact_number`, text, required): Enter the contact number of the parent or guardian.
* **Event name** (`event_name`, select_one, required): Select the event name from the provided options.
* **Event date** (`event_date`, date, required): Select the date of the competition.
* **Event time** (`event_time`, time, required): Select the time of the competition.
* **Category** (`student_category`, select_multiple, required): Select the student's category of participation (Vocal or Instrumental).
* **Ensemble** (`student_ensemble`, text, required): Type in the student's ensemble details.
* **Teacher education level** (`teacher_education_level`, select_one, required): Select the teacher's education level from the provided options.
* **Instrument** (`student_instrument`, select_multiple, required): Select the student's instrument of choice.
* **Teacher qualifications** (`teacher_qualification`, text, required): Type in the teacher's qualifications.
* **Dietary needs** (`student_dietary_needs`, text, required): Specify any dietary requirements or allergies the student may have.
* **Parent permission** (`parent_permission`, select_one, required): Confirm parent permission for the student's participation.
* **Parent signature** (`parent_signature`, text, required): Enter the parent's signature.
* **Student signature** (`student_signature`, text, required): Enter the student's signature.
* **Event organizer** (`event_organizer`, text, required): Type in the event organizer's name.
* **Co-organizer** (`event_co_organizer`, text, required): Type in the co-organizer's name.
* **Notes** (`student_notes`, text, optional): Enter any additional notes if necessary.
* **Form submitter** (`form_submitter`, text, optional): This field can be left blank as it's not required for form submission.

## Tips

* Ensure all fields are filled accurately and truthfully.
* Review the form carefully before submission to avoid errors.
* If you are unsure about any field, please contact the competition organizers.
* Please note that incomplete or false information may affect the student's participation in the competition.
