# Event Planning Intake Form - Help Guide
## Purpose
The Event Planning Intake Form is a tool used to gather information about an event, including event details, dates, times, and other relevant particulars. This information helps us tailor our services to your specific needs.

## How To Complete This Form
1. Fill out the form completely and accurately to provide us with a clear understanding of your event's requirements.
2. Ensure that you have reviewed all fields carefully before submitting the form.

## Field-by-Field Explanation
- **Event Type** (event_planning_form_10, select_one, Required): Select the type of event you are planning, such as a meeting, conference, wedding, etc.
- **Event Date** (event_planning_form_2, Date, Required): Enter the date of the event. Please use the date format `mm/dd/yyyy`.
- **Event Time** (event_planning_form_3, Time, Required): Enter the time of the event in 24-hour format (`HH:MM`).
- **Event Name** (event_planning_form_4, text, Not Required): Enter a brief name or title for the event.
- **Client Name** (event_planning_form_5, text, Not Required): Enter the name of the person or organization hosting the event.
- **Contact Information** (event_planning_form_6, text, Not Required): Enter the contact information for the person or organization hosting the event.
- **Event Description** (event_planning_form_7, text, Not Required): Enter a brief description of the event, including any important details or specifics.
- **Event Location** (event_planning_form_8, text, Not Required): Enter the location of the event, including the address and any other relevant details.
- **Event Size** (event_planning_form_9, Number, Not Required): Enter the estimated number of guests attending the event.
- **Event Type 1** (event_planning_form_10, Select One, Required): Select the type of event from the provided options.
- **Number of Guests** (event_planning_form_11, Number, Not Required): Enter the expected number of guests attending the event.
- **Special Requirements** (event_planning_form_12, text, Not Required): Enter any special requirements or requests for the event.
- **Additional Notes** (event_planning_form_13, Note, Not Required): Add any additional notes or comments about the event.
- **Contact Person** (event_planning_form_14, text, Not Required): Enter the name of the person responsible for the event.

**Tips:**
- Double-check all fields for accuracy before submitting the form.
- Use the provided options for Event Type to ensure we understand the nature of your event correctly.
- If you have any special requests or requirements, please specify them in the Special Requirements field.
- If you need to add any additional information or comments, use the Additional Notes field.
