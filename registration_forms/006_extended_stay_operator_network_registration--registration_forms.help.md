# Extended Stay Operator Network Registration - Help Guide
## Purpose
The Extended Stay Operator Network Registration form is a tool used for registering operators in the network. Operators can register their details, property type, and other relevant information to be part of the network.

## How To Complete This Form

1. Fill in the **Operator Name** field with the name of the operator.
2. Provide the **Property Details** in the **Property Details** field.
3. Enter the **Address** of the operator's property.
4. Enter the **Email** address of the operator in the **Email** field.
5. Enter the **Phone** number of the operator in the **Phone** field.
6. Add any additional **Notes** about the operator in the **Notes** field.
7. Select the **Operator Type** from the options **Individual**, **Business**, or **Organization**.
8. Indicate whether the operator is part of the **Operator Network** by selecting **Yes** or **No**.
9. Provide a brief description of the **Network Description**.
10. Select the **Network** the operator is affiliated with from the options **Network A**, **Network B**, or **Network C**.
11. Select the type of **Property Type** from the options **Hotel**, **Motel**, **Resort**, or **Other**.
12. Enter the **Property Name** of the operator's property.
13. Add any additional **Notes** about the property in the **Notes** field.

## Field-by-Field Explanation

* **Operator Name**: Enter the name of the operator as it appears on their official documents.
* **Property Details**: Provide a brief description of the operator's property.
* **Address**: Enter the address of the operator's property.
* **Email**: Enter the operator's email address.
* **Phone**: Enter the operator's phone number.
* **Notes**: Add any additional information about the operator.
* **Operator Type**: Select the type of operator you are registering (Individual, Business, or Organization).
* **Operator Network**: Indicate whether the operator is part of the Operator Network.
* **Network Description**: Provide a brief description of the network the operator is affiliated with.
* **Network**: Select the network the operator is affiliated with.
* **Property Type**: Select the type of property the operator is registering (Hotel, Motel, Resort, or Other).
* **Property Name**: Enter the name of the operator's property.
* **Notes**: Add any additional information about the property.
* **Submit**: Click this button to submit the form.

## Tips

* Make sure to double-check the information you enter to ensure accuracy.
* If you are unsure about any field, contact the relevant authorities for clarification.
* This form is designed to be filled out by operators who are registering themselves or their properties in the network.
* Please be honest and accurate when filling out the form to avoid any issues.
