# Travel Partner Appreciation Event RSVP Form - Help Guide

## Purpose
This form is designed to collect RSVP information from travel partners for an appreciation event.

## How To Complete This Form
To complete this form, simply fill in the required information and submit. Please make sure to provide the correct email address and phone number for the guest. If you are unsure about the date or time, please check the event details with the event organizers.

## Field-by-Field Explanation
* **Guest Name** (`travel_partner_appreciation_event_rsvp_form`, text, optional): Please fill in the name of the guest attending the event.
* **Email** (`email`, email, optional): Enter the email address of the guest. This will be used for communication about event details and logistics.
* **Phone** (`phone`, text, optional): Fill in the phone number of the guest. This will be used for last-minute event updates.
* **Date** (`travel_partner_appreciation_event_rsvp_form_date`, date, optional): Please select the specific date you plan to attend the event. Make sure to choose the correct date from the calendar provided.
* **Time** (`travel_partner_appreciation_event_rsvp_form_time`, time, optional): Choose the time slot you plan to attend the event. Make sure to select the correct time that suits you best.

## Tips
* Double-check the information you provide to ensure accuracy.
* If you need to make any changes or cancellations, please contact the event organizers directly.
* The event organizers will be in touch with you regarding any updates or changes to the event details.
