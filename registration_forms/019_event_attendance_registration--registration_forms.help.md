# Event Attendance Registration - Help Guide
## Purpose
This form is used to register event attendance for staff members. It collects information about the event, attendees, and registration details to help administrators track and manage event attendance efficiently.

## How To Complete This Form

To complete this form, follow these steps:

1. Fill in the event details (page 1).
2. Select the attendees who will be attending the event (page 2).
3. Enter your email address (page 3) and phone number (page 4).
4. Provide the date and time of the event (page 5).
5. Enter any additional notes about the event (page 7).
6. Confirm the attendee details (page 8).
7. Confirm the payment details (page 9).
8. Confirm the registration details (page 10).
9. Confirm the event details (page 11).

## Field-by-Field Explanation

* **Event Details** (page 1, text): Enter a brief description of the event you are registering for.
* **Attendees** (page 2, select_multiple): Select "Yes" if you will be attending the event. 
* **Email** (page 3, email): Enter your email address.
* **Phone** (page 4, text): Enter your phone number.
* **Date** (page 5, date): Enter the date of the event.
* **Time** (page 5, time): Enter the time of the event.
* **Notes** (page 7, note): Enter any additional notes about the event.
* **Attendee Details** (page 8, select_multiple): Confirm if you will attend as a staff member or not.
* **Payment Details** (page 9, select_multiple): Confirm if you will pay for the event or not.
* **Registration Details** (page 10, select_multiple): Confirm if you are registering for the event or not.
* **Event Details** (page 11, select_multiple): Confirm if the event is internal or external. 

## Tips

* Please ensure that you have the necessary permission and clearance to attend the event.
* If you need to cancel your registration, please contact the event coordinator.
* If you have any issues with the form, please reach out to the IT department.
