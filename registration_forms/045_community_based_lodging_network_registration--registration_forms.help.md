# Community Based Lodging Network Registration - Help Guide
## Purpose
This form is designed to help hosts register their lodging offering with the Community Based Lodging Network. It gathers necessary information about the host and their lodging to facilitate a safe and enjoyable experience for both hosts and guests.

## How To Complete This Form
To complete this form, follow these steps:

1. Ensure you have all the necessary information about your lodging and yourself as a host.
2. Select the correct options for each field, paying attention to the required fields marked with a star (*).
3. Fill in all the required fields.
4. Review your responses carefully before submitting the form.

## Field-by-Field Explanation
- **Registration Information** (1): This is the section header for the form. There is no actual input field for this label.
- **Registration Date (2)**: The date on which you registered this lodging offering.
- **Registration ID (3)**: A unique reference number for this registration.
- **Host Information (4)**: A section to provide details about yourself as the host.
  * **Host Name (5)**: Your full name.
  * **Host Email (6)**: Your contact email address.
  * **Host Phone (7)**: Your contact phone number.
  * **Host Address (8)**: The address of your lodging.
  * **Host City (9)**: The city of your lodging.
  * **Host State (10)**: The state or province of your lodging.
  * **Host ZIP Code (11)**: The ZIP or postal code of your lodging.
- **Lodging Information (12)**: A section to provide details about the lodging.
  * **Lodging Type (13)**: The type of lodging you offer (e.g., Private Room, Shared Room, Entire Home, etc.).
  * **Number of Guests (14)**: The maximum number of guests you can host.
  * **Number of Bedrooms (15)**: The number of bedrooms available.
  * **Number of Beds (16)**: The number of beds available.
  * **Number of Bathrooms (17)**: The number of bathrooms available.
- **Amenities (18)**: Select all the amenities you offer, such as Wi-Fi, kitchen access, laundry facilities, etc.
- **Accessibility Features (19)**: Select all the accessibility features you offer, such as wheelchair accessibility, step-free entry, etc.
- **Availability (20)**: Select when your lodging is available (e.g., weekdays, weekends, weekly, monthly).
- **Pricing (21)**: This is a section for additional information about your pricing.
  * **Nightly Rate (22)**: The rate per night in USD.
  * **Weekly Rate (23)**: The rate per week in USD.
  * **Monthly Rate (24)**: The rate per month in USD.
  * **Pricing Type (25)**: Your pricing model (e.g., free, donation-based, market rate).
- **Guest Preferences (26)**: Any preferences for guests.
- **House Rules (27)**: Any rules you want guests to be aware of.
- **Background Check (28)**: If you have undergone a background check.
- **References Available (29)**: If you can provide references.
- **Photos Available (30)**: If you have photos of the lodging.
- **Additional Description (31)**: Any additional information about your lodging.
- **Agreement (32)**: Confirm you agree to follow the network's guidelines and policies.

Note: The asterisks (*) mark required fields.
