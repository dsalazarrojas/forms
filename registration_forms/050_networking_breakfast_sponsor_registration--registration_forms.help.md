# Networking Breakfast Sponsor Registration - Help Guide
## Purpose
The purpose of this form is to allow sponsors to register for the Networking Breakfast event. This form is used to collect sponsor details and sponsorship package choices.

## How To Complete This Form
To complete this form, follow these steps:
1. Fill in your sponsor details.
2. Choose your sponsorship package.
3. Confirm your sponsorship.
4. Add any additional contact information if needed.

## Field-by-Field Explanation
- **Sponsor Details** (Text): This field is used to input sponsor information. Please fill in the required fields as prompted.
  - **Package Choices** (Select Multiple): Select one or multiple sponsorship packages that you would like to be included in.
  - **Confirm Sponsor** (Select One): Confirm that you are a sponsor for the event.
  - **Company Name** (Text): If you are a company, please input your company name.
  - **Contact First Name** (Text): Input your first name for contact purposes.
  - **Contact Last Name** (Text): Input your last name for contact purposes.
  - **Email** (Email): Input your email address for contact purposes.
  - **Phone** (Text): Input your phone number for contact purposes.
  - **Website** (Text): Input your website URL if you have one.
  - **Package Description** (Text): If you want to provide a description of your sponsorship package, please input it here.
  - **Sponsor Logo** (Note): You can upload or input your sponsor logo.
  - **Confirmation Date** (Date): This field is used to select a confirmation date for your sponsorship.
  - **Sponsor Type** (Select One): Choose whether you are an individual, company, or group.
  - **Address** (Text): If you want to input your address for billing or other purposes.
  - **City** (Text): Input your city for contact purposes.
  - **State** (Text): Input your state for contact purposes.
  - **Zip** (Text): Input your zip code for contact purposes.
  - **Bio** (Text): If you want to provide a bio for your company or group.
  - **Social Facebook** (Text): Input your Facebook URL or username.
  - **Social Twitter** (Text): Input your Twitter URL or username.
  - **Social Instagram** (Text): Input your Instagram URL or username.
  - **Social LinkedIn** (Text): Input your LinkedIn URL or username.
  - **Other (Please specify)** (Text): If you want to input a different social media platform.
  - **Notes** (Note): You can input any additional notes or comments.
  - **Confirmation Date** (Date): This field is not used, but is a placeholder for future date fields.
