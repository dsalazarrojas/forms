# Registration Filter Form - Help Guide
## Purpose
The Registration Filter Form is a tool used to filter and categorize registered participants based on their demographic and registration information.

## How To Complete This Form
To complete this form, follow these steps:

* Select the relevant filters you want to apply to narrow down the participant list.
* Choose from the provided options for each filter.
* Fill in the required fields (if applicable) and leave the optional fields blank if not necessary.

## Field-by-Field Explanation
### **Registration Filter** (1)
Select all applicable options to include/exclude specific groups of participants.
* This field determines whether you want to include or exclude participants based on the options selected.

### **Categories** (2)
Select a specific category or categories to narrow down the participant list.
* This field allows you to select specific categories of participants to focus on.

### **Participant Status** (3)
Select the current status of the participant to filter the participant list accordingly.
* This field represents the active or inactive status of participants.

### **Registration Type** (4)
Select the type of registration to filter the participant list.
* This field determines the type of registration (e.g., yes or no).

### **Participant Age Range** (5)
Enter the participant's age range to filter the participant list.
* This field is used to filter participants based on their age.

### **Attendee Type** (6)
Select the type of attendee to filter the participant list.
* This field determines the type of participant (e.g., yes or no).

### **Registration Date** (7)
Select the registration date to filter the participant list.
* This field allows you to select a specific date or date range.

### **Event Status** (8)
Select the status of the event to filter the participant list.
* This field determines the status of the event (e.g., active or inactive).

### **Registration Method** (9)
Select the registration method to filter the participant list.
* This field determines the method of registration (e.g., yes or no).

### **Registration Source** (10)
Select the source of registration to filter the participant list.
* This field determines the source of registration (e.g., yes or no).

### **Attendee Name** (11)
Enter the attendee's name to filter the participant list.
* This field is used to search for a specific participant by name.

## Tips
* Make sure to select all applicable options for each filter to ensure accurate results.
* If a field is not required, leave it blank if not necessary.
* Review your selections before submitting the form to ensure accuracy.
