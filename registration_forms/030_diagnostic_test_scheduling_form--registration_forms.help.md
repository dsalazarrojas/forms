# Diagnostic Test Scheduling Form - Help Guide
## Purpose
The Diagnostic Test Scheduling Form is a critical tool used to schedule and manage diagnostic tests for patients. It captures key information about each test, allowing for efficient and accurate scheduling.

## How To Complete This Form
To complete this form, follow these steps:

1. Ensure that you have all the necessary information about the patient and the test.
2. Select the type of test (e.g., Blood Test, Imaging Test) that you want to schedule.
3. Fill in the patient's details, including any additional comments or notes.
4. Choose the date and time of the test.
5. Select the provider who will be conducting the test.
6. Set the test status (e.g., Not Scheduled, Scheduled, Completed).
7. Finally, enter any additional notes or comments.

## Field-by-Field Explanation
* **Patient Info** (`test_scheduling_form_patient_info`): This field allows you to enter essential details about the patient, including any additional comments or notes.
* **Test Type** (`test_scheduling_form_test_type`): Choose the type of test you want to schedule, such as Blood Test or Imaging Test. If neither option is suitable, use the "Other Test" field to enter a custom test type.
* **Test Type (Other)** (`test_scheduling_form_test_type_other`): If the previous option is "Other," use this field to enter a custom test type.
* **Date** (`test_scheduling_form_date`): Enter the date for the scheduled test.
* **Time** (`test_scheduling_form_time`): Enter the time for the scheduled test.
* **Test Status** (`test_scheduling_form_test_status`): Set the test status to Not Scheduled, Scheduled, or Completed.
* **Provider** (`test_scheduling_form_provider`): Select the healthcare provider who will be conducting the test.
* **Notes** (`test_scheduling_form_notes`): Enter any additional comments or notes about the test or patient.
