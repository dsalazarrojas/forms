# Plans Examination Registration - Help Guide
## Purpose
The purpose of this form is to register a new examination plan. It is used to capture relevant information about a project, including its name, details, lead name, plan documents, project type, and start and end dates.

## How To Complete This Form
1. Fill in the project name in the **Project Name** field. This is a text field that requires the name of the project.
2. Provide a brief description of the project in the **Project Details** field. This is a text field where you can enter any additional information about the project.
3. Enter the name of the person leading the project in the **Lead Name** field. This is a text field that requires the name of the lead person.
4. Choose whether there are plan documents for the project in the **Plan Documents** field. This is a selection field where you can choose between 'Yes' and 'No'.
5. Select the type of project in the **Project Type** field. This is a selection field where you can choose between 'Type A', 'Type B', and 'Type C'.
6. Fill in the start date of the project in the **Start Date** field. This is a date field where you can enter the start date of the project.
7. Fill in the end date of the project in the **End Date** field. This is a date field where you can enter the end date of the project.

## Field-by-Field Explanation
* **Project Name (text, required)**: Enter the name of the project.
* **Project Details (text, required)**: Provide a brief description of the project.
* **Lead Name (text, required)**: Enter the name of the person leading the project.
* **Plan Documents (select_multiple, optional)**: Choose whether there are plan documents for the project ('Yes' or 'No').
* **Project Type (select_one, optional)**: Select the type of project ('Type A', 'Type B', 'Type C').
* **Start Date (date, optional)**: Enter the start date of the project.
* **End Date (date, optional)**: Enter the end date of the project.

## Tips
* Make sure to fill out all required fields accurately and completely.
* Double-check your responses before submitting the form.
* If you are unsure about any field, please contact the relevant authorities for clarification.
* If you are filling out this form for the first time, please make sure to review the form carefully to ensure you have all the necessary information.
