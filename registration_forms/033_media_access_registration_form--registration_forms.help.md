# media-access-registration-form - Help Guide
## Purpose
This form is used to register media access for events, allowing individuals to request access and provide necessary information for coordination.

## How To Complete This Form
To complete this form, please follow these steps:

1. Provide general information about yourself, including your contact information and media access needs.
2. Specify the event you are requesting access for, including the event name, start and end dates, and start and end times.
3. Confirm your email address and phone number for contact purposes.
4. Select the type of access you require (photo, video, interview, or all).
5. Specify the type of event (conference, seminar, workshop, or other).
6. Confirm that you are submitting this form for the correct event.

## Field-by-Field Explanation

* **General Information**
  * **General Info** (text, not required): Provide a brief description of yourself and your purpose for requesting media access.
  * **Contact Info** (text, not required): Provide your name and any other contact information you'd like to include.
* **Event Information**
  * **Event Info** (text, not required): Provide any additional information about the event you are requesting access for.
  * **Event Access** (text, not required): Describe the type of access you require for the event (e.g., photo, video, interview).
* **Media Access**
  * **Media Access** (text, not required): Confirm your media access needs.
  * **Event Access Type** (select_multiple, not required): Select the type of access you require (photo, video, interview, or all).
* **Event Details**
  * **Event Start Date** (date, required): Specify the start date of the event.
  * **Event End Date** (date, required): Specify the end date of the event.
  * **Event Start Time** (time, required): Specify the start time of the event.
  * **Event Location** (text, required): Specify the location of the event.
  * **Event Type** (select_one, required): Choose the type of event (conference, seminar, workshop, or other).
* **Emergency Contact**
  * **Emergency Contact** (text, not required): Provide the contact information of an emergency contact.
* **Confirmation and Event Details**
  * **Confirm Email** (email, required): Confirm your email address.
  * **Event Name** (text, required): Specify the name of the event.
  * **Event Name Other** (text, not required): Provide any additional information about the event name.
  * **Event Name List** (text, not required): Enter a list of event names if you have multiple events.
  * **Event Description** (select_one, required): Confirm if the event is a press conference.
  * **Event Type** (select_one, required): Choose the type of event.
  * **Event Start Date** (date, required): Specify the start date of the event.
  * **Event End Date** (date, required): Specify the end date of the event.
  * **Event Start Time** (time, required): Specify the start time of the event.
  * **Event Location** (text, required): Specify the location of the event.
  * **Event Location Other** (text, not required): Provide any additional information about the event location.
* **Media Information**
  * **Media Type** (select_one, required): Choose the type of media you are representing (journalist, photographer, or other).
  * **Other Media Type** (text, not required): If you selected "other" for media type, provide any additional information.
  * **Media Name** (text, required): Confirm your name.
  * **Affiliation** (text, required): Specify your affiliation.
* **Confirmation**
  * **Confirm** (select_one, required): Confirm that you are submitting this form for the correct event.
  * **Confirm Email** (email, required): Confirm your email address.
  * **Confirm Phone Number** (text, required): Confirm your phone number.
