# Baby Wishes Collection - Help Guide
## Purpose
The Baby Wishes Collection form is designed to collect messages and wishes for a baby's milestone events, such as birthdays, baptisms, or other special occasions. This form allows well-wishers to share their thoughts, congratulations, and love with the baby's family, and also gives them the option to choose how their message will be published.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the well-wisher's name in the **Well wisher name** field.
2. In the **Message to the baby and family** field, write a heartfelt message for the baby and their family. Keep it brief and sweet!
3. Choose the **Relationship to family** to indicate how you know the baby's family (e.g., Friend, Relative, Colleague, Neighbor, Other).
4. Decide if you'd like your message to be **Published on social media or keepsake** (you can choose 'False' if you don't want it to be shared).
5. Select your **Delivery preference for keepsake** (Digital or Physical).
6. If you'd like to be contacted for follow-up, enter your **Contact email**.
7. Enter your **Submitter location** (City, State, or any other location that makes sense).
8. Choose the **Submission date** (the date you're submitting your message, which will be recorded).
9. Add any additional **Privacy notes** about how you'd like the message to be used and stored.
10. If you have anything else you'd like to share, use the **Additional comments** field.

## Field-by-Field Explanation

* **Well wisher name**: Enter the name of the person sending the message.
	+ Type: text
	+ Optional
* **Message to the baby and family**: Write a heartfelt message for the baby and their family.
	+ Type: text
	+ Required
	+ Hint: Keep messages brief.
* **Relationship to family**: Indicate how you know the baby's family (e.g., Friend, Relative, Colleague, Neighbor, Other).
	+ Type: select_one
	+ Optional
* **Permission to publish message**: Decide if you'd like your message to be **Published on social media or keepsake**.
	+ Type: select_one
	+ Optional
	+ Options: 'True', 'False'
* **Delivery preference for keepsake**: Select the type of keepsake you'd like (Digital or Physical).
	+ Type: select_one
	+ Optional
* **Contact email**: Enter your contact email if you'd like to be contacted for follow-up.
	+ Type: email
	+ Optional
* **Submitter location**: Enter the location where you're submitting this message (e.g., City, State).
	+ Type: text
	+ Optional
* **Submission date**: Choose the date you're submitting this message.
	+ Type: date
	+ Required
* **Privacy notes**: Add any additional notes about how you'd like the message to be used and stored.
	+ Type: note
	+ Optional
* **Additional comments**: Add any additional comments or thoughts you'd like to share.
	+ Type: text
	+ Optional
