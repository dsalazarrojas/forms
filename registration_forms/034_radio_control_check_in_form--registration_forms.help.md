# radio_control_check_in_form - Help Guide
## Purpose
The "radio_control_check_in_form" is a form used to check in users to an event. It helps event organizers or administrators to track who is present at the event and their status.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the name of the event you are attending in the "Event Name" field.
2. Select the time you checked in to the event in the "Check In Time" field.
3. Enter your event ID, if applicable.
4. Check your check-in status (e.g., "checked in", "late", etc.) in the "Check In Status" field.
5. Enter the current status of the event in the "Event Status" field.
6. If assigned a tool, select the assigned tool from the options provided in the "Assigned Tool" field.
7. Add any additional notes in the "Notes" field.
8. Enter your email address in the "Email" field.

## Field-by-Field Explanation
* **Event Name**: Enter the name of the event you are attending.
* **Check In Time**: Select the time you checked in to the event.
* **Event ID**: If you have an event ID, enter it here. This is usually provided to you by the event organizer.
* **Check In Status**: Check your current status (e.g., "checked in", "late", etc.).
* **Event Status**: Enter the current status of the event.
* **Assigned Tool**: If a tool has been assigned to you for the event, select it from the options provided.
* **Notes**: Add any additional notes or comments about your attendance.
* **Email**: Enter your email address for contact purposes.
