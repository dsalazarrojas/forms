# Corporate Event Intake Form - Help Guide
## Purpose
The purpose of this form is to gather details about corporate events, ensuring accurate and efficient event management.

## How To Complete This Form
To fill out this form, follow these steps:

1. Enter the company name associated with the event.
2. Select the type of event (Corporate, Networking, Conference, Seminar, or Trade Show).
3. Provide the date and time of the event.
4. Enter the location of the event.
5. Write a brief description of the event.
6. Enter the name of the event organizer or contact person.
7. Provide the contact email and phone number of the event organizer.
8. Enter the event capacity (number of attendees).
9. Add any additional event details in the notes field.
10. Set the registration deadline.
11. Indicate whether event registration is open or not.
12. Enter the event venue.
13. Set the event cost (optional).

## Field-by-Field Explanation

* **Company Name (text)**: Enter the name of the company associated with the event.
* **Event Type (select_one)**: Choose the type of event from the options (Corporate, Networking, Conference, Seminar, or Trade Show).
* **Event Date (date)**: Select the date of the event.
* **Event Time (time)**: Enter the time of the event.
* **Location (text)**: Enter the location of the event.
* **Event Description (text)**: Briefly describe the event.
* **Event Organizer (text)**: Enter the name of the event organizer or contact person.
* **Contact Person (text)**: Enter the name of the contact person (same as event organizer if applicable).
* **Contact E-mail (email)**: Enter the contact email of the event organizer.
* **Contact Phone (text)**: Enter the contact phone number of the event organizer.
* **Event Capacity (number)**: Enter the event capacity (number of attendees).
* **Event Details (note)**: Add any additional event details in this notes field.
* **Registration Deadline (date)**: Set the deadline for event registration.
* **Registration Open (select_multiple)**: Indicate whether event registration is open or not.
* **Event Venue (text)**: Enter the event venue.
* **Event Cost (number)**: Enter the event cost (optional).
