# Material Traceability Innovation Registration Form - Help Guide
## Purpose
This form is used to register new innovation projects in the Material Traceability system. It captures essential details about the project, including its status, category, and other relevant information.

## How To Complete This Form
To complete this form, follow these steps:

1. Review the form carefully to ensure that you have all the necessary information to complete it accurately.
2. Select the correct options for each field based on your knowledge of the project.
3. Make sure to submit the form only once for each new project.

## Field-by-Field Explanation

* **Innovation Ideas** (select_multiple): 
	+ This field is used to indicate if the innovation has ideas or not.
	+ Select 'Yes' if the innovation has ideas, 'No' otherwise.

* **Name** (text): 
	+ This field is used to enter the name of the innovation project.

* **Email** (email): 
	+ This field is used to enter the email address of the project submitter.

* **Phone** (text): 
	+ This field is used to enter the phone number of the project submitter.

* **Date** (date): 
	+ This field is used to enter the date the project was started.

* **Time** (time): 
	+ This field is used to enter the time the project was started.

* **Category** (select_one): 
	+ This field is used to select the category of the innovation project.

* **Sub Category** (select_one): 
	+ This field is used to select the sub category of the innovation project.

* **Location** (text): 
	+ This field is used to enter the location of the project.

* **Notes** (note): 
	+ This field is used to enter any additional notes about the project.

* **Innovation Type** (select_one): 
	+ This field is used to select the type of innovation project.

* **Idea Description** (text): 
	+ This field is used to enter a description of the idea or innovation project.

* **Innovation Stage** (select_one): 
	+ This field is used to select the stage of the innovation project.

* **Status** (select_one): 
	+ This field is used to select the status of the innovation project.

* **Idea** (select_one): 
	+ This field is used to select if the innovation is an idea or not.

* **Product** (select_one): 
	+ This field is used to select if the innovation is a product or not.

* **Service** (select_one): 
	+ This field is used to select if the innovation is a service or not.

* **Other** (select_one): 
	+ This field is used to select if the innovation is of other type or not.

* **Other Description** (text): 
	+ This field is used to enter a description of the other type of innovation.

* **Submitted By** (select_one): 
	+ This field is used to select who submitted the project.

* **Title** (select_one): 
	+ This field is used to select the title of the project submitter.

* **Role** (select_one): 
	+ This field is used to select the role of the project submitter.

* **Department** (select_one): 
	+ This field is used to select the department of the project submitter.

## Tips
* Make sure to complete the form accurately and thoroughly.
* Review the form carefully before submitting it.
* If you're unsure about any field, consult with your departmental authority.
