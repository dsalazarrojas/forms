# MDM Only Device Enrollment Form - Help Guide
## Purpose
This form is designed to register or enroll devices within an organization or business. Fill out this form to provide necessary information about the device and its status.

## How To Complete This Form
To complete this form, follow these steps:

*   Fill out each section with the required information.
*   Make sure to provide accurate and relevant information for each field.

## Field-by-Field Explanation

*   **User Input** (`user_input`, text, optional): Enter any additional information about the device or reason for enrollment.
*   **Device Info** (`device_info`, text, optional): Provide details about the device, including its type, brand, or model number.
*   **Contact Info** (`contact_info`, text, optional): Enter your contact information so that we can reach out to you for further assistance.
*   **IT Info** (`it_info`, text, optional): Provide any relevant IT-specific information about the device.
*   **Request Details** (`request_details`, text, optional): Add any additional details or requests related to the device.
*   **Additional Comments** (`additional_comments`, text, optional): Add any other relevant comments or information about the device.
*   **Device Serial** (`device_serial`, text, optional): Enter the device's serial number for identification purposes.
*   **Device Model** (`device_model`, text, optional): Provide the device's model number for accurate identification.
*   **OS Version** (`os_version`, text, optional): Enter the device's operating system version.
*   **Enrollment Status** (`enrollment_status`, select-one, optional): Select one of the following options:
    +   **active**: The device is currently active and enrolled.
    +   **inactive**: The device is no longer active or enrolled.
    +   **pending**: The device's enrollment status is pending or in review.
*   **Assigned Tool** (`assigned_tool`, select-one, optional): Select one of the following options:
    +   **Jotform**: The device is assigned to Jotform.
    +   **Other**: The device is assigned to another tool.
*   **Assigned User** (`assigned_user`, select-one, optional): Select one of the following options:
    +   **chatjimmy**: The device is assigned to chatjimmy.
    +   **user1**: The device is assigned to user1.
    +   **user2**: The device is assigned to user2.
    +   **other**: The device is assigned to another user.

Note: The fields marked as optional may not be necessary for the form's purpose, but providing accurate and relevant information will help ensure a smooth enrollment process.
