# Gym Trial Class Registration Form - Help Guide
## Purpose
The Gym Trial Class Registration Form is designed to collect necessary information from users who want to register for a trial class at the gym. This form ensures that the gym administration has all the required details to prepare for your visit.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill out the form completely and accurately.
2. Select your preferred class type (Group Class, Private Class, or Personal Training).
3. Choose your preferred class days (Monday to Sunday).
4. Select your preferred class time (using the time picker).
5. Add any additional notes if you have any special requests or requirements.
6. Double-check your input before submitting the form.

## Field-by-Field Explanation

* **Title: Gym Trial Class Registration Form**: This is the heading of the form, indicating that this is the Gym Trial Class Registration Form.
* **Name (Name)**: Enter your full name as it appears on your identification documents.
* **Email (Email)**: Enter your valid email address where you can be contacted for further information.
* **Phone (Phone)**: Enter your phone number where you can be contacted for further information or confirmation.
* **Class Type (Class Type)**:
	+ Select the type of class you are interested in:
		- **Group Class**: A class with other people.
		- **Private Class**: A one-on-one class with a trainer.
		- **Personal Training**: A customized workout plan with a trainer.
* **Preferred Class Days (Preferred Class Days)**:
	+ Choose one or more days you are available to attend a class:
		- **Monday**
		- **Tuesday**
		- **Wednesday**
		- **Thursday**
		- **Friday**
		- **Saturday**
		- **Sunday**
* **Preferred Class Time (Preferred Class Time)**: Select a time slot for your class using the time picker. Please be aware that class times are subject to change.
* **Notes (Notes)**: Add any additional information you would like to share with the gym administration, such as any medical conditions or physical limitations. This is optional.

## Tips

- Please fill out the form accurately and completely to ensure a smooth registration process.
- Make sure to select your preferred class type and days correctly, as this will help the gym administration prepare for your visit.
- If you have any questions or concerns, don't hesitate to contact the gym administration.
