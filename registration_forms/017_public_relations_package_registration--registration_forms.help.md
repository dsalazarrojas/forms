# public-relations-package-registration - Help Guide
## Purpose
The Public Relations (PR) package registration form is used to collect and track information about registered PR packages. This form is essential for maintaining a database of registered packages and their associated data.

## How To Complete This Form
To complete this form, follow these steps:

1. Start by filling out the contact information page. 
   This page includes fields such as Email, Phone, Address, City, and State. 
   These fields are used to store contact information for the person or organization submitting the PR package. 

2. Move on to the PR package details page. 
   This page includes fields such as PR Package Details, Prospects, and Relationships. 
   These fields are used to store information about the PR package, including the type of package, potential prospects, and relationships associated with it. 

3. Proceed to the campaign timelines page. 
   This page includes fields such as Campaign Start Date, Campaign End Date, and Submission Date. 
   These fields are used to store information about the campaign, including the start and end dates, and the date of submission. 

4. Finally, move on to the submission status page. 
   This page includes fields such as Submission Status, Submission Time, and Notes and Feedback. 
   These fields are used to store the status of the submission, including the time of submission, and any notes or feedback associated with it.

## Field-by-Field Explanation
* **Contact Information** (`Contact Information`, text, required): This field is used to collect contact information for the person or organization submitting the PR package. 
* **PR Package Details** (`PR Package Details`, text, required): This field is used to store information about the PR package, including its description or details. 
* **Prospects and Relationships** (`Prospects and Relationships`, select_multiple, required): This field is used to select multiple prospects and relationships associated with the PR package. 
* **Campaign Timelines** (`Campaign Timelines`, text, required): This field is used to store information about the campaign, including its start and end dates, and submission date. 
* **Contact Preference** (`Contact Preference`, text, required): This field is used to store the contact preference of the person or organization submitting the PR package. 
* **Email Preferences** (`Email Preferences`, text, required): This field is used to store email preferences of the person or organization submitting the PR package. 
* **Notes and Feedback** (`Notes and Feedback`, text, required): This field is used to store notes and feedback associated with the PR package submission. 
* **Submission Status** (`Submission Status`, select_one, required): This field is used to store the status of the submission, including whether it is Draft, Published, or In Progress. 
* **Submission Date** (`Submission Date`, date, required): This field is used to store the date of submission. 
* **Submission Time** (`Submission Time`, time, required): This field is used to store the time of submission.
