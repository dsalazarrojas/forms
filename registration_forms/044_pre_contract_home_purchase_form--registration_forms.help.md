# Pre Contract Home Purchase Form - Help Guide

## Purpose
This form is used to collect information from both the buyer and seller for a pre-contract home purchase. The data collected will be used for the contract creation process.

## How To Complete This Form

1. **First Time Buyer** (`first_time_buyer`, select_one, required): Select "Yes" if this is the buyer's first time purchasing a home.
2. **Seller Contact Information** (`seller_contact`, text, required): Enter the seller's contact information.
3. **Buyer Contact Information** (`buyer_contact`, text, required): Enter the buyer's contact information.
4. **Property Type** (`property_type`, select_one, required): Select "Yes" if the property is a residential property.
5. **Property Status** (`property_status`, select_one, required): Select "Active" if the property is active in the market.
6. **Property Address** (`property_address`, text, optional): Enter the property address.
7. **Property Address Line 2** (`property_address_line_2`, text, optional): Enter the property address line 2.
8. **Property City** (`property_city`, select_one, required): Select the city of the property.
9. **Property State** (`property_state`, select_one, required): Select the state of the property.
10. **Property Zip** (`property_zip`, text, optional): Enter the property zip code.
11. **Property Country** (`property_country`, select_one, optional): Select the country of the property (if applicable).
12. **Pre-Contract Agreement** (`pre_contract_agreement`, select_multiple, optional): Select all applicable pre-contract agreements (if applicable).
13. **Loan Terms** (`loan_terms`, select_one, optional): Select the loan terms (if applicable).
14. **Contract Type** (`contract_type`, select_one, required): Select the type of contract.
15. **Contract Date** (`contract_date`, date, required): Enter the contract date in the format YYYY-MM-DD.
16. **Contract Time** (`contract_time`, time, optional): Enter the contract time (if applicable).
17. **Property Price** (`property_price`, number, required): Enter the property price.
18. **Buyer Credit Score** (`buyer_credit_score`, select_one, required): Select the buyer's credit score.
19. **Seller Credit Score** (`seller_credit_score`, select_one, optional): Select the seller's credit score (if applicable).
20. **Loan Amount** (`loan_amount`, number, required): Enter the loan amount.
21. **Loan Term** (`loan_term`, select_one, required): Select the loan term.
22. **Interest Rate** (`interest_rate`, number, required): Enter the interest rate.
23. **Property Notes** (`property_notes`, note, optional): Enter any additional property notes.
24. **Buyer Notes** (`buyer_notes`, note, optional): Enter any additional buyer notes.
25. **Seller Notes** (`seller_notes`, note, optional): Enter any additional seller notes.

## Tips

* Ensure that all required fields are filled out to ensure accurate data collection.
* If you are unsure about any of the information, consult the relevant parties or seek guidance from the contract creation team.
* Double-check the entered information for accuracy before submission.
