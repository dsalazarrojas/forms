# Crowd Flow Simulation Application Form - Help Guide
## Purpose
The Crowd Flow Simulation Application Form is designed to gather information about a project's registration forms, including details such as project title, description, start and end dates, contact information, and participant details. This form helps project organizers gather necessary data to manage and coordinate project activities effectively.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the "Registration Forms Project Details" section to begin.
2. Enter the project title, a brief description of the project, and select the start and end dates of the project.
3. Provide contact information for the project lead, including name, email, and phone number.
4. Enter the number of participants involved in the project.
5. Add any additional participant details.
6. Specify the project location.

## Field-by-Field Explanation

* **Project Title** (project_title, text, required): Enter the name of your project.
* **Project Description** (project_description, text, required): Provide a brief description of your project.
* **Project Start Date** (project_start_date, date, required): Select the start date of your project.
* **Project End Date** (project_end_date, date, required): Select the end date of your project.
* **Project Lead Contact** (project_lead_contact, text, required): Enter the name of the project lead.
* **Project Lead Email** (project_lead_email, email, required): Enter the email address of the project lead.
* **Project Lead Phone** (project_lead_phone, text, required): Enter the phone number of the project lead.
* **Project Lead Address** (project_lead_address, text, required): Enter the address of the project lead.
* **Number of Participants** (number_of_participants, number, required): Enter the number of participants involved in the project.
* **Participant Details** (participant_details, text, required): Add any additional information about the project participants.
* **Project Location** (project_location, text, required): Specify the location of the project.

## Tips
* Double-check your input for accuracy and completeness before submitting the form.
* Make sure to use a valid email address and phone number for the project lead contact information.
* Enter the correct number of participants and project location to ensure accurate planning and coordination.
