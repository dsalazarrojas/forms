# Yoga Mat Customization Order Form - Help Guide
## Purpose
The Yoga Mat Customization Order Form is designed to collect information from customers for a custom-made yoga mat. This form is used to gather details about their preferred mat length, width, color, and design to create a unique mat tailored to their needs.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the customer information section by providing your name and email address.
2. Choose the length of the mat you would like to order.
3. Select the width of the mat you would like to order.
4. Select the color of the mat from the available options.
5. Choose the design(s) you would like to have on your mat.
6. Select your preferred payment method.

## Field-by-Field Explanation

* **Customer Name** (`customer_name`, text, required): Please enter your name as it appears on your identification.
* **Customer Email** (`customer_email`, email, required): Enter a valid email address where we can contact you.
* **Mat Length** (`mat_length`, number, required): Select the length of the mat you would like to order. Please note that mat length is measured in centimeters.
* **Mat Width** (`mat_width`, number, required): Select the width of the mat you would like to order. Please note that mat width is measured in centimeters.
* **Mat Color** (`mat_color`, select_one, required): Choose the color of the mat from the available options.
* **Mat Design** (`mat_design`, select_multiple, required): Select one or more designs to be printed on your mat.
* **Payment Method** (`payment_method`, select_one, required): Select the payment method you would like to use for this order.
* **Order Comments** (`order_comments`, note, optional): If you have any additional comments or requests for your order, please enter them here.
* **Customer Phone** (`customer_phone`, text, optional): Enter your phone number for easier contact if needed.

## Tips

* Please double-check your selections before submitting the form to ensure accuracy.
* We will contact you via the email address you provided if we need any additional information.
* If you have any questions or concerns, please don't hesitate to contact us.
