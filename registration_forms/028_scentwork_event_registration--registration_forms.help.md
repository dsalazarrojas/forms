# Scentwork Event Registration - Help Guide
## Purpose
The purpose of this form is to collect information from participants to an event related to scentwork, such as search and rescue operations.

## How To Complete This Form

1. Fill in your participant's name and other personal details if necessary.
2. Enter the name of the event you are participating in, which is optional but helps the organizers.
3. Select the date of the event using the date field.
4. Enter the event time if necessary.
5. Finally, add your participant's email address which will be used as a contact point for event organizers.

## Field-by-Field Explanation

### Participant Name
 Participant Name (required/optional)
 Participant's full name that you will be using for this event.

### Participant Email
 Participant Email (required/optional)
 Your up-to-date email address that we will use to contact you.

### Event Name
 Event Name (required/optional)
 Name of the event you are participating in.

### Event Date
 Event Date
 Date of the event in which you will be participating.

### Event Time
 Event Time
 Time of the event in which you will be participating. 

## Tips
Please ensure that your email address is up-to-date to avoid any miscommunication. If you have any questions or need help with the event, please contact the organizers using your provided email address.
