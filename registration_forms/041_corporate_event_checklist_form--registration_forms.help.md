# Corporate Event Checklist Form - Help Guide

## Purpose
The Corporate Event Checklist Form is used to gather essential details about corporate events, allowing us to efficiently organize and track event information. 

## How To Complete This Form
To complete this form, simply follow these steps:
1. Fill in the **Event Name**, providing a brief description of the event.
2. Select the **Event Date** for the event.
3. Choose the **Event Time** of the event.
4. Enter the **Event Agenda**, providing any specific details about the event's schedule.
5. Input the **Event Location**, where the event will take place.
6. Choose from the list of available **Attendees**, selecting all relevant individuals attending the event.
7. Add any **Event Notes**, any additional comments or information about the event.

## Field-by-Field Explanation
* **Event Name** (`event_name`, text, required): A brief title or description of the event.
* **Event Date** (`event_date`, date, required): The date of the event.
* **Event Time** (`event_time`, time, required): The time of the event.
* **Event Agenda** (`event_agenda`, number, optional): A numerical representation of the event's agenda (e.g., 1-5, etc.).
* **Event Location** (`event_location`, text, optional): The venue or location of the event.
* **Attendees** (`attendees_list`, select multiple, optional): A list of attendees, select all relevant individuals.
* **Event Notes** (`event_notes`, note, optional): Additional comments or information about the event.
