# Yoga Class Booking Form - Help Guide
## Purpose

This form is used to book a yoga class that suits your preferences. Please fill in the required fields to submit your booking request.

## How To Complete This Form

1. Fill in your First Name, Last Name, and Email address.
2. Enter a valid Phone Number.
3. Choose your preferred Class Type(s) by checking the corresponding box(es).
4. Select your preferred Day(s) of the week.
5. Select your preferred Class Time.
6. Enter the Start Date of the class (any date will be accepted).
7. Enter the End Date of the class (any date will be accepted).
8. Add any additional Notes about your class booking request.

## Field-by-Field Explanation

* **First Name** (`First Name`, text, required): Enter your full first name.
* **Last Name** (`Last Name`, text, required): Enter your full last name.
* **Email** (`Email`, email, required): Enter your valid email address.
* **Phone Number** (`Phone Number`, text, required): Enter your phone number.
* **Class Type** (`Class Type`, select_multiple, optional): Choose the type(s) of class you're interested in booking.
	+ Check 'Yes' for each type that applies.
* **Preferred Days** (`Preferred Days`, select_one, optional): Select a single day that suits you best.
* **Class Time** (`Class Time`, select_one, optional): Select a single class time that works for you.
* **Start Date** (`Start Date`, date, optional): Enter the date you want to start the class.
* **End Date** (`End Date`, date, optional): Enter the date you want to end the class.
* **Notes** (`Notes`, text, optional): Add any additional notes or requests about your class booking.

## Tips

- Please fill in the required fields accurately and thoroughly.
- Select all preferences that apply for Class Type.
- Make sure to enter valid dates for Start Date and End Date.
