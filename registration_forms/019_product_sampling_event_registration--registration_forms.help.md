# Product Sampling Event Registration - Help Guide
## Purpose
The Product Sampling Event Registration form is designed to collect information from potential attendees to tailor the event to their needs and preferences.

## How To Complete This Form
1. Fill out the form completely to ensure that your event preferences are captured accurately.
2. Make sure to provide your correct contact information to receive updates and notifications about the event.
3. If you have any specific needs or requirements, please specify them in the "Event Details" or "Additional Comments" fields.

## Field-by-Field Explanation
* **First Name** (`first_name`, text, optional): Please enter your first name.
* **Email** (`email`, email, optional): Enter a valid email address that we can use to contact you.
* **Company** (`company`, text, optional): If you represent a company, please enter your company name.
* **Job Title** (`job_title`, text, optional): Enter your job title if it's relevant to your role or responsibilities.
* **Department** (`department`, text, optional): Enter your department name if it's applicable.
* **Sample Preferences** (`sample_preferences`, select_multiple, optional):
	+ Select "Yes" if you're interested in receiving product samples.
	+ Select "No" if you're not interested.
* **Date of Birth** (`date_of_birth`, date, optional): Enter your date of birth for our records.
* **Event Details** (`event_details`, text, optional): Describe any specific event details or requirements you may have.
* **Dietary Restrictions** (`dietary_restrictions`, select_multiple, optional):
	+ Select "Yes" if you have dietary restrictions.
	+ Select "No" if you don't have any restrictions.
* **Contact Number** (`contact_number`, text, optional): Enter your contact number for us to reach you.
* **Contact Email** (`contact_email`, email, optional): Enter a valid email address for us to contact you.
* **Company Address** (`company_address`, text, optional): If you represent a company, enter your company address.
* **Event Date** (`event_date`, date, optional): Enter the date of the event.
* **Event Time** (`event_time`, time, optional): Enter the time of the event.
* **Event Location** (`event_location`, text, optional): Enter the event location.
* **Event Start Time** (`event_start_time`, time, optional): Enter the start time of the event.
* **Event End Time** (`event_end_time`, time, optional): Enter the end time of the event.
* **Event Duration** (`event_duration`, text, optional): Enter the duration of the event.
* **Event Type** (`event_type`, select_one, optional):
	+ Select "Yes" if you're interested in this type of event.
	+ Select "No" if you're not interested.
* **Other (please specify)** (`event_type_other`, text, optional): If you have any other event type preferences, describe them here.
* **Product Sample** (`product_sample`, select_multiple, optional):
	+ Select "Yes" if you're interested in receiving product samples.
	+ Select "No" if you're not interested.
* **Other (please specify)** (`product_sample_other`, text, optional): If you have any other product sample preferences, describe them here.
* **Other (please specify)** (`event_details_other`, text, optional): If you have any other event details that don't fit into the other categories, describe them here.
* **Additional Comments** (`additional_comments`, text, optional): Add any other comments or information you'd like to share about this event registration.
* **Terms and Conditions** (`terms_and_conditions`, text, optional): Please review and acknowledge our terms and conditions.

Please note that all fields are optional unless specified otherwise in the form.
