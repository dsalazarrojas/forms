# Function Sheet Submission Form - Help Guide
## Purpose
This form is used to provide details about a function sheet submission. You will need to fill out the form with relevant information about the event, including the title, date, time, location, and other relevant details.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the required fields with accurate information about the event.
2. Select the correct options for the function sheet type and assigned tool.
3. Enter your email address to be contacted about the submission.
4. Upload any relevant files or notes about the submission.

## Field-by-Field Explanation
* **Event Title** (`event_title`, text, required): Enter a brief description of the event.
* **Event Date** (`event_date`, date, required): Enter the date of the event.
* **Event Time** (`event_time`, time, required): Enter the start time of the event.
* **Event Description** (`event_description`, text, required): Provide a detailed description of the event.
* **Event Organizer** (`event_organizer`, text, required): Enter the name of the event organizer.
* **Event Location** (`event_location`, text, required): Enter the location of the event.
* **Function Sheet Type** (`function_sheet_type`, select_multiple, required): Select the type of function sheet submission you are making. (Option 1, Option 2, Option 3)
* **Function Sheet Submitter** (`function_sheet_submitter`, email, required): Enter your email address so we can contact you about the submission.
* **Function Sheet Submission Date** (`function_sheet_submission_date`, date, required): Enter the date of the submission.
* **Function Sheet Submission Time** (`function_sheet_submission_time`, time, required): Enter the time of the submission.
* **Function Sheet Notes** (`function_sheet_notes`, note, required): Provide any additional notes or comments about the submission.
* **Assigned Tool** (`assigned_tool`, select_one, required): Select the tool assigned to the submission. (Chatjimmy, Other)
* **Event Category** (`event_category`, select_one, required): Select the category of the event. (Registration Forms, Other)
* **Function Sheet Category** (`function_sheet_category`, select_one, required): Select the category of the function sheet submission. (Registration Forms, Other)
* **Function Sheet File Upload** (`function_sheet_file_upload`, text, required): Upload any relevant files or documents about the submission.
* **Function Sheet Comments** (`function_sheet_comments`, text, required): Enter any comments or remarks about the submission.
