# Garden Event Email Signup - Help Guide
## Purpose
This form is designed to collect information from potential attendees for a garden event. It is not a mandatory registration form, and users can choose to provide their details if they wish to attend the event.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter your name
2. Enter your email address
3. If you are interested in attending the event, select 'Yes' for 'Garden Event'
4. Enter the date you would like to attend the event
5. Enter the time you would like to attend the event
6. Enter the venue where you would like to attend the event (optional)
7. Add any additional notes you'd like to share with the event organizers (optional)

## Field-by-Field Explanation
* **Garden Event**: This field is a yes/no selection indicating whether you are interested in attending the event.
* **Name**: Enter your name as you would like to be referred to by the event organizers.
* **Email**: Enter your email address so the event organizers can contact you with event details.
* **Phone**: You can optionally enter your phone number for the event organizers to contact you.
* **Garden Event Date**: Enter the date you would like to attend the event. Select a date from the available options or enter a custom date.
* **Garden Event Time**: Enter the time you would like to attend the event. Select a time from the available options or enter a custom time.
* **Garden Event Venue**: Enter the venue where you would like to attend the event. This field is optional.
* **Notes**: Add any additional notes or comments you'd like to share with the event organizers. This field is optional.
