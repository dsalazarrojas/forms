# Virtual Reality Music Festival Registration Form - Help Guide
## Purpose
This form is designed to collect information from attendees for a Virtual Reality Music Festival. The data collected will be used by festival organizers to manage registrations, event details, and payments.

## How To Complete This Form
To complete this form, follow these steps:

1. Provide your First Name and Last Name in the respective fields.
2. Enter your email address in the E-mail field.
3. Enter your phone number in the Phone field.
4. Enter a password in the Password field (please note that this field is not secure and should not be used for sensitive information).
5. Select the Date of the event in the Event Date field.
6. Select the Event Time in the Event Time field.
7. Select the Event Time Ending in the Event Time Ending field.
8. Enter the Event Location in the Event Location field.
9. Select the type of event from the Event Type dropdown menu (e.g., VR Fest, Music Fest, Other).
10. Select the type(s) of event ending from the Event Ending dropdown menu (e.g., VR Fest, Music Fest, Other).
11. Enter the Ticket Price in the Ticket Price field.
12. Enter the Ticket Discount in the Ticket Discount field.
13. Enter the Ticket Quantity in the Ticket Quantity field.
14. Select the Payment Method from the dropdown menu (e.g., Card, Bank, Other).
15. Enter the Payment Information in the Payment Info field (e.g., payment details specific to the selected payment method).
16. Add any additional notes about your registration or event in the Note field.
17. Enter a brief description of the event in the Event Description field.
18. Enter any additional event details in the Event Details field.

## Field-by-Field Explanation
* **First Name** (Text, Required): Enter your first name.
* **Last Name** (Text, Required): Enter your last name.
* **E-mail** (Email, Required): Enter your email address.
* **Phone** (Text, Required): Enter your phone number.
* **Password** (Text, Optional): Enter a password (please note that this field is not secure and should not be used for sensitive information).
* **Event Date** (Date, Required): Select the date of the event.
* **Event Time** (Time, Required): Select the time of the event.
* **Event Time Ending** (Time, Required): Select the ending time of the event.
* **Event Location** (Text, Required): Enter the location of the event.
* **Event Type** (Select One, Required): Select the type of event (e.g., VR Fest, Music Fest, Other).
* **Event Ending** (Select Multiple, Required): Select the type(s) of event ending (e.g., VR Fest, Music Fest, Other).
* **Ticket Price** (Number, Required): Enter the price of the ticket.
* **Ticket Discount** (Number, Optional): Enter any ticket discount applicable.
* **Ticket Quantity** (Number, Optional): Enter the quantity of tickets purchased.
* **Payment Method** (Select One, Required): Select the payment method (e.g., Card, Bank, Other).
* **Payment Info** (Text, Optional): Enter payment details specific to the selected payment method.
* **Note** (Note, Optional): Add any additional notes or comments about your registration or event.
* **Event Description** (Text, Optional): Enter a brief description of the event.
* **Event Details** (Text, Optional): Enter any additional event details.
* **Event Location** (Text, Required): Enter the location of the event.
