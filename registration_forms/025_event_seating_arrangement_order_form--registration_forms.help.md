# Event Seating Arrangement Order Form - Help Guide
## Purpose
This form is used to collect information about events from event organizers. It helps event organizers to submit their event details, seating preferences, and contact information for efficient event planning and coordination.

## How To Complete This Form
1. Fill in the form with the following details:
	* Event name (required)
	* Event description (optional)
	* Guest count (required)
	* Seating preferences:
		+ Seat type (yes/no)
		+ Seat row (yes/no)
		+ Seat column (yes/no)
	* Contact number (required)
	* Contact email (required)

## Field-by-Field Explanation
- **Event name** (`event name`, text, required): Fill in the name of the event.
- **Event description** (`event description`, text, optional): Provide a brief description of the event.
- **Guest count** (`guest count`, number, required): Enter the total number of guests attending the event.
- **Seat type** (`seat type`, select_multiple, required): Check 'Yes' if the event requires seat type preferences. 
- **Seat row** (`seat row`, select_multiple, required): Check 'Yes' if the event requires seat row preferences. 
- **Seat column** (`seat column`, select_multiple, required): Check 'Yes' if the event requires seat column preferences. 
- **Special Requests** (`special request`, text, optional): Enter any special requests or notes for the event organizer.
- **Special request** (`special request`, text, optional): This field is a redundant label for `Special Requests` and is provided for redundancy. 
- **Contact number** (`contact number`, text, required): Enter the contact number of the event organizer.
- **Contact email** (`contact email`, email, required): Enter the email address of the event organizer.

## Tips
- Ensure that you enter accurate and up-to-date information to avoid any last-minute adjustments.
- Double-check that all required fields are completed to facilitate efficient event planning and coordination.
- If you have any special requests or notes for the event organizer, enter them under 'Special Requests' or 'Special request'.
