# Spring Break Day Camp Registration Form - Help Guide

## Purpose
This form is designed for registering campers for the Spring Break Day Camp. It collects basic information about the camper, including their name, contact details, and fee status.

## How To Complete This Form

1. Fill in the required fields to register the camper.
2. Enter the camper's name in the "Camper Name" field.
3. Enter the camper's email address in the "Camper Email" field.
4. Enter the camper's phone number in the "Camper Phone" field.
5. Choose the fee status for the camper in the "Camper Fee Status" field.
6. If applicable, attach a file with fee payment information in the "Camper Fee File" field.
7. Add any additional notes about the camper in the "Camper Notes" field.
8. Click the "Submit" button to complete the registration process.

## Field-by-Field Explanation

* **Camper Info**: Enter a brief description of the camper.
* **Camper Name**: Enter the name of the camper, including first and last name.
* **Parent Name**: Enter the name of the camper's parent or guardian.
* **Camper Email**: Enter the camper's email address for communication purposes.
* **Camper Phone**: Enter the camper's phone number.
* **Camper Fee**: Enter the fee for the Spring Break Day Camp.
* **Camper Fee Status**: Select "Paid" if the fee has been paid, "Unpaid" otherwise.
* **Camper Fee File**: Attach a file with payment information if the fee is unpaid.
* **Camper Notes**: Add any additional notes or comments about the camper.
