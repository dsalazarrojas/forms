# Past Players Event Registration - Help Guide
## Purpose
The Past Players Event Registration form is used to collect and store information about past events involving players.

## How To Complete This Form
To complete this form, follow these steps:
1. Select the event date using the date picker input field.
2. Enter the event start time in the 12-hour format (e.g., 02:00).
3. Enter the name of the event.
4. Enter the name of the team involved in the event.
5. Enter the name and email address of the player participating in the event.
6. Enter the player's phone number and address.
7. Choose the status of the event by selecting "Active" or "Inactive" using the dropdown menu.
8. Choose the RSVP status of the player by selecting "Pending", "Confirmed", or "Declined" using the dropdown menu.
9. If desired, add a note about the event.

## Field-by-Field Explanation
* **Event Date**: Enter the date of the event using the date picker calendar.
* **Event Start Time**: Enter the start time of the event in the 12-hour format (e.g., 02:00).
* **Event Name**: Enter the name of the event (e.g., tournament, game, or competition).
* **Team Name**: Enter the name of the team participating in the event.
* **Player Name**: Enter the name of the player participating in the event.
* **Player Email**: Enter the player's email address.
* **Player Phone**: Enter the player's phone number.
* **Player Address**: Enter the player's address.
* **Event Status**: Choose the status of the event as "Active" or "Inactive".
* **RSVP Status**: Choose the RSVP status of the player as "Pending", "Confirmed", or "Declined".
* **Note**: Add any additional notes or comments about the event if needed.
* **Submit**: Click the "Submit" button to complete and save the form.

## Tips
* Make sure to fill out all required fields to ensure accurate record-keeping.
* Use the date picker to select the event date for precise formatting.
* Double-check the event status and RSVP status for consistency with actual event outcomes.
