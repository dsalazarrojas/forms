# Animal Therapy Program Registration - Help Guide

## Purpose
This form is for registering participants in the Animal Therapy Program. The goal of this program is to provide a supportive and inclusive environment for individuals to interact with animals and receive therapy. The form helps us understand your needs, preferences, and requirements to tailor the program to your needs.

## How To Complete This Form

1. Fill out the form completely and accurately.
2. Be honest and truthful in your answers.
3. If you need help or have questions, please contact us.

## Field-by-Field Explanation

* **Full Name (participant_name)** (`participant_name`, text, required): Enter your first and last name.
* **Date of Birth (date_of_birth)** (`date_of_birth`, date, required): Enter your date of birth in MM/DD/YYYY format.
* **Email Address (email)** (`email`, email, required): Enter your contact email address.
* **Phone Number (phone)** (`phone`, text, required): Enter your phone number.
* **Street Address (address)** (`address`, text, required): Enter your current address.
* **City (city)** (`city`, text, required): Enter your city.
* **State or Province (state)** (`state`, text, required): Enter your state or province.
* **ZIP or Postal Code (zip_code)** (`zip_code`, text, required): Enter your ZIP or postal code.
* **Emergency Contact Name (emergency_contact_name)** (`emergency_contact_name`, text, required): Enter the full name of the emergency contact.
* **Emergency Contact Phone (emergency_contact_phone)** (`emergency_contact_phone`, text, required): Enter the phone number of the emergency contact.
* **Emergency Contact Relationship (emergency_contact_relationship)** (`emergency_contact_relationship`, text, required): Describe the relationship between you and the emergency contact.
* **How Were You Referred to This Program (referral_source)** (`referral_source`, select_one, required): Select how you were referred to this program (e.g., Healthcare Provider, Mental Health Professional, School or Educational Institution, etc.).
* **Referring Professional Name (referring_professional)** (`referring_professional`, text, optional): If applicable, enter the name of the referring professional.
* **Type of Therapy Program (program_type)** (`program_type`, select_one, required): Select the type of therapy program you prefer (e.g., Individual Animal-Assisted Therapy, Group Animal-Assisted Therapy, etc.).
* **What Are Your Therapy Goals (therapy_goals)** (`therapy_goals`, select_multiple, required): Select all the goals you have for the therapy program (e.g., Reduce Anxiety, Improve Mood, etc.).
* **Do You Have an Animal Preference (animal_preference)** (`animal_preference`, select_one, required): Select your animal preference (e.g., Dogs, Cats, Horses, etc.).
* **Please Describe Animal Concerns (animal_concerns)** (`animal_concerns`, text, optional): If applicable, describe any concerns you have about animals.
* **Do You Have Any Animal Allergies (animal_allergies)** (`animal_allergies`, select_one, required): Select if you have any allergies to animals.
* **Allergy Details (allergy_details)** (`allergy_details`, text, optional): If you have allergies, describe them.
* **Previous Experience with Animals (animal_experience)** (`animal_experience`, select_one, required): Select your previous experience with animals (e.g., Extensive, Some, Limited, No, etc.).
* **Describe Your Experience (experience_details)** (`experience_details`, text, optional): If applicable, describe your experience with animals.
* **Do You Have Any Fears Related to Animals (animal_fears)** (`animal_fears`, select_one, required): Select if you have any fears related to animals.
* **Please Describe Your Fears (fear_details)** (`fear_details`, text, optional): If you have fears, describe them.
* **Relevant Medical or Psychological Conditions (medical_conditions)** (`medical_conditions`, text, optional): If applicable, describe any relevant medical or psychological conditions that may affect your participation.
* **Current Medications (current_medications)** (`current_medications`, text, optional): If applicable, list your current medications.
* **Preferred Session Time (session_preference)** (`session_preference`, select_one, required): Select your preferred session time (e.g., Morning, Afternoon, etc.).
* **Preferred Days (preferred_days)** (`preferred_days`, select_multiple, required): Select the days you prefer for sessions.
* **Desired Session Frequency (session_frequency)** (`session_frequency`, select_one, required): Select your desired session frequency (e.g., Weekly, Bi-Weekly, etc.).
* **Do You Need Transportation Assistance (transportation_needs)** (`transportation_needs`, select_one, required): Select if you need transportation assistance.
* **Do You Have Any Accessibility Requirements (accessibility_needs)** (`accessibility_needs`, select_one, required): Select if you have any accessibility requirements.
* **Accessibility Details (accessibility_details)** (`accessibility_details`, text, optional): If you have requirements, describe them.
* **Insurance Provider (insurance_info)** (`insurance_info`, text, optional): If applicable, enter your insurance provider.
* **Insurance ID Number (insurance_id)** (`insurance_id`, text, optional): If applicable, enter your insurance ID number.
* **Payment Method (payment_method)** (`payment_method`, select_one, required): Select your payment method (e.g., Insurance, Self-Pay, etc.).
* **I Consent to Participate in Animal-Assisted Therapy (consent_to_treatment)** (`consent_to_treatment`, select_one, required): Select if you consent to participate in animal-assisted therapy.
* **I Accept the Liability Waiver (liability_waiver)** (`liability_waiver`, select_one, required): Select if you accept the liability waiver.
* **I Understand Confidentiality Policies (confidentiality_agreement)** (`confidentiality_agreement`, select_one, required): Select if you understand the confidentiality policies.
* **Electronic Signature (participant_signature)** (`participant_signature`, text, required): Type your full name.
* **Guardian Signature (guardian_signature)** (`guardian_signature`, text, optional): If under 18, type the guardian's name.
* **Registration Date (registration_date)** (`registration_date`, date, required): This field will be automatically populated with the current date.

## Tips

* Please answer all questions honestly and accurately.
* If you need help or have questions, please contact us.
* The form is required for registration in the Animal Therapy Program.
* You will be contacted to confirm your registration after submitting the form.
