# Senior Citizen Appreciation Lunch RSVP Form - Help Guide

## Purpose
This form is designed to collect RSVP details from senior citizens attending the appreciation lunch event.

## How To Complete This Form

To complete this form, follow these steps:

1. Provide your name and contact information in the first section.
2. Choose your preferred event date and time.
3. Add any personal message or comments you'd like to share with the organizers.
4. Decide if you can attend the event and select your category preferences.
5. Enter any organizational details if applicable.
6. Select the event type you're interested in attending.
7. Enter any additional attendees' details if needed.
8. Finally, review your information and submit the form.

## Field-by-Field Explanation

- **RSVP Name** (`rsvp_name`, `text`, required: false): Enter your name as it should be displayed on the invitation and event materials.
- **Email** (`email`, `email`, required: false): If you have any email address you'd like to provide, please enter it.
- **Phone** (`phone`, `text`, required: false): If you'd like to be contacted before or after the event, please provide your phone number.
- **Date** (`date`, `date`, required: false): Select the event date from the available options or provide the date manually.
- **Time** (`time`, `time`, required: false): Choose the event time that suits you best from the provided options.
- **Message** (`message`, `note`, required: false): Share any comments or questions you have regarding the event.
- **Event Date** (`event_date`, `date`, required: false): Select the event date for which you're RSVPing.
- **Event Time** (`event_time`, `time`, required: false): Choose the event time that suits you best.
- **RSVP** (`rsvp`, `select_one`, required: false): Indicate whether you can or cannot attend the event.
- **Category** (`category`, `select_multiple`, required: false): Choose which categories you're interested in attending.
- **Organization** (`organization`, `text`, required: false): If you're associated with an organization, please provide the name and contact details.
- **Role** (`role`, `text`, required: false): If you'd like to specify your role within the organization, please provide details.
- **Event Type** (`event_type`, `select_one`, required: false): Select which event type you're interested in attending.
- **Event Description** (`event_description`, `text`, required: false): If you'd like to share more details about the event, please write a brief description.
- **Attendees** (`attendees`, `number`, required: false): If you're bringing any guests, please specify the number.

## Tips

* Be honest about your availability to ensure accurate event planning.
* If unsure about any field, you can ask the organizers for clarification.
* Review your information carefully before submitting the form to avoid errors.
