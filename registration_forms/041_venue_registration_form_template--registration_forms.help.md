# Venue Registration Form Template - Help Guide

## Purpose
The Venue Registration Form Template is used to register event venues with necessary details such as event information, attendee info, and payment details.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the event information (page 1).
2. Provide event details (page 2).
3. Enter attendee information (page 3).
4. Enter payment information (page 4).
5. Add any additional attendee notes (page 5).
6. Choose the payment method (page 6).
7. Enter the total number of attendees (page 7).
8. Set the registration date (page 8).
9. Select the type of event (page 9).
10. Mark the payment status (page 10).
11. Enter any special requests (page 11).
12. Add any additional notes (page 12).

## Field-by-Field Explanation
* **Event Info** (`event_info`, text, required: false): Enter a brief description of the event.
* **Event Details** (`event_details`, text, required: false): Provide a more detailed description of the event.
* **Attendee Info** (`attendee_info`, text, required: false): Enter information about the attendees, such as their names and contact details.
* **Payment Info** (`payment_info`, text, required: false): Enter the payment information, including the amount paid and payment method.
* **Attendee Notes** (`attendee_notes`, text, required: false): Add any additional notes about the attendees.
* **Payment Method** (`payment_method`, select_one, required: false): Choose the payment method used for the event registration (e.g., Cash, Card).
* **Total Attendees** (`total_attendees`, number, required: false): Enter the total number of attendees.
* **Registration Date** (`registration_date`, date, required: false): Set the date of the event registration.
* **Event Type** (`event_type`, select_one, required: false): Choose the type of event (e.g., Conference, Meet and Greet).
* **Payment Status** (`payment_status`, select_multiple, required: false): Mark the payment status of the event registration (e.g., Paid, Pending, Cancelled).
* **Special Requests** (`special_requests`, text, required: false): Enter any special requests or comments.
* **Notes** (`notes`, text, required: false): Add any additional notes about the event registration.
