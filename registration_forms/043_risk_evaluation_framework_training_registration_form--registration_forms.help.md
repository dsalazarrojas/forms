# risk_evaluation_framework_training_registration_form - Help Guide
## Purpose

This form is for registering participants in a training session. It helps trainers or administrators gather essential information about participants, such as their contact details and status in the training session.

## How To Complete This Form

1.  Fill in the **Participant Info** section with the participant's basic details.
2.  Select the **Training Sessions** attended or scheduled for the participant.
3.  Enter any additional details in the **Participant Details** field.
4.  Enter the **Registration Date** when the participant registered.
5.  Provide the participant's **Participant Phone** number.
6.  Enter the participant's **Participant Email** address.
7.  If applicable, assign a specific **Assigned Tool** to the participant.
8.  Add any additional **Participant Notes** as needed.

## Field-by-Field Explanation

*   **Participant Info**: 
    *   **Participant Info**: This section is for the participant's name and any other relevant information about them.
    *   **Type: Text**: This is a text field where you can enter any relevant details about the participant.
*   **Training Sessions**: 
    *   **Training Sessions**: This field is used to track whether the participant has attended or will attend a specific training session.
    *   **Type: Select Multiple**: You can select one or more options from this field, depending on the participant's status in the training sessions.
*   **Participant Details**: 
    *   **Participant Details**: This field is for any additional details not captured in other fields.
    *   **Type: Text**: This is a text field where you can enter any relevant details about the participant.
*   **Registration Date**: 
    *   **Registration Date**: This field is used to log the date the participant registered for the training.
    *   **Type: Date**: You can select a date from this field.
*   **Participant Phone**: 
    *   **Participant Phone**: This field is used to capture the participant's phone number.
    *   **Type: Text**: This is a text field where you can enter the participant's phone number.
*   **Participant Email**: 
    *   **Participant Email**: This field is used to collect the participant's email address.
    *   **Type: Email**: You can enter the participant's email address in this field.
*   **Assigned Tool**: 
    *   **Assigned Tool**: This field might be used to assign a specific tool to the participant.
    *   **Type: Text**: This is a text field where you can enter the participant's assigned tool.
*   **Participant Notes**: 
    *   **Participant Notes**: This field could be used for additional notes or comments about the participant.
    *   **Type: Note**: This is a note field where you can enter any additional comments about the participant.

## Tips

- Ensure you fill in all required fields accurately to ensure proper participant information is captured.
- Double-check the participant's contact information for correctness.
- Use the **Participant Notes** field to add any additional comments or details about the participant.
