# Class Enrollment Request Form - Help Guide
## Purpose
The purpose of this form is to allow students to request enrollment in a class of their choice. The form captures relevant information required to process the request, including contact details, class selection, and other supporting information.

## How To Complete This Form
To complete this form, please ensure you have the necessary information and access to the selected class options. Fill in the form accurately and honestly, and submit it once complete.

## Field-by-Field Explanation

* **Applicant Full Name** (`applicant_name`, text, required): This is the full name of the student requesting enrollment.
* **Email Address** (`email_address`, email, required): Enter the student's email address for correspondence purposes.
* **Phone Number** (`phone_number`, text, required): Provide the student's phone number for further communication.
* **Date of Birth** (`date_of_birth`, date, required): Enter the student's date of birth in MM/DD/YYYY format.
* **Mailing Address** (`mailing_address`, text, required): Enter the student's mailing address, including street, city, state, and ZIP code.
* **Current School or Institution** (`current_school`, text, optional): If applicable, enter the name of the student's current school or institution.
* **Current Grade Level** (`grade_level`, select_one, required): Select the student's current grade level.
* **Current GPA** (`gpa`, number, optional): If applicable, enter the student's current GPA.
* **Class You Want to Enroll In** (`requested_class`, select_one, required): Select the class the student wishes to enroll in.
* **Why Do You Want to Take This Class?** (`class_reason`, text, required): Enter the student's motivation for taking the class.
* **Do You Have Related Experience?** (`related_experience`, select_one, required): Indicate whether the student has experience in the subject area of the selected class.
* **Please Describe Your Experience** (`experience_details`, text, optional): If yes, provide details on the experience.
* **Preferred Class Schedule** (`preferred_schedule`, select_multiple, required): Select the student's preferred class schedule.
* **Is This Your Top Choice?** (`enrollment_priority`, select_one, required): Indicate the student's priority level for the selected class.
* **What Are Your Alternative Class Choices?** (`alternative_classes`, text, optional): List other classes the student would consider if not accepted into the first choice.
* **School Counselor Name** (`counselor_name`, text, optional): If applicable, enter the name of the school counselor.
* **Counselor Email** (`counselor_email`, email, optional): For verification purposes, enter the email of the school counselor.
* **Do You Have Parent or Guardian Consent?** (`parent_consent`, select_one, required): If under 18, indicate whether parent or guardian consent has been given.
* **How Will You Get to Class?** (`transportation_plan`, select_one, optional): Select the student's transportation plan.
* **Do You Need Financial Aid Information?** (`financial_aid`, select_one, optional): Indicate whether the student requires financial aid information.
* **Additional Comments or Questions** (`additional_comments`, text, optional): Use this space to provide any additional comments or questions.
 
Note: Some fields are not required but are optional and intended to support the student's enrollment request.
