# Paint And Sip Class Registration - Help Guide
## Purpose
This form is used to register for a Paint And Sip class and track progress.

## How To Complete This Form
To complete this form, simply fill in the required information in each field. If a field is not required, you can leave it blank. Here's a step-by-step guide:

1. Fill in your **Full Name** (Field 2).
2. Enter your **Email** (Field 3) to receive updates and notifications about the class.
3. Provide your **Phone Number** (Field 4) so we can contact you.
4. Select the **Class Selection** (Field 6) to indicate if you are attending the class.
5. Choose your **Payment Selection** (Field 7) to indicate if you have made payment.
6. Enter any additional **Note** (Field 8) about your progress or concerns.
7. If you have made payment, choose the **Payment Method** (Field 9) you used.
8. Enter the **Class Name** (Field 10) you are registered for.
9. Enter the **Class Start Date** (Field 11) of the class you are registered for.
10. Enter the **Class Start Time** (Field 12) of the class you are registered for.
11. Select the **Class Duration** (Field 13) in minutes.
12. Select the **Class End Time** (Field 14) of the class you are registered for.
13. Enter the **Class End Date** (Field 15) of the class you are registered for.
14. Enter the **Student Number** (Field 16) assigned to you.
15. Enter your **Address** (Field 17) for correspondence.
16. Select the **Class Status** (Field 18) of your class (Active or Inactive).
17. Select the **Payment Status** (Field 20) of your payment (Active or Inactive).
18. Select if you have **Class Attended** (Field 22) the class.
19. Select if you have **Student Attended** (Field 23) the class.
20. Enter the **Instructor** (Field 24) name if applicable.
21. Enter the **Total Classes Attended** (Field 25) if applicable.

* **Full Name**: Your full name for registration purposes.

* **Student Number**: The student number assigned to you.

* **Class Status**: Select 'Active' to indicate you are actively attending the class, or 'Inactive' to indicate otherwise.
