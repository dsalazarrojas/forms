# Motor Carrier Registration Form - Help Guide
## Purpose
This form is used to register a carrier, providing the required information to update the carrier's status, address, phone number, and other details.

## How To Complete This Form
1. Start by filling out the "Main Information" section, which includes the carrier's basic details.
2. Proceed to fill out the "Carrier Details" section, which provides more specific information about the carrier.
3. In the "Registration Status" section, select the relevant status options that apply to the carrier.
4. Fill out the "Carrier Address" section with the carrier's address.
5. Enter the carrier's phone number in the "Carrier Phone" field.
6. Enter the carrier's email in the "Carrier Email" field.
7. Fill out the "Carrier Status 2" to "Carrier Status 7" sections with the relevant status options.
8. In the "Notes" section, add any additional comments or information about the carrier.
9. If required, upload a file in the "File Upload" field.
10. Enter the carrier's file URL in the "File URL" field.

## Tips

* Double-check the "Carrier Status" fields to ensure that you select the correct options for the carrier.
* Be careful when entering dates and phone numbers, as they are crucial for the carrier's registration.
* Use the "Notes" field to add any additional information that may be relevant to the carrier's registration.
* If required, upload a file about the carrier to provide more information.
* Enter the carrier's file URL if you've uploaded a file.
* Review the form carefully before submitting it to ensure that all required fields are filled out accurately.
