# immigration_call_questionnaire - Help Guide

## Purpose
This form is used to collect information from applicants regarding their immigration status, travel documents, and other relevant details. It is essential to complete this form accurately and thoroughly to ensure that your information is up-to-date and correct.

## How To Complete This Form
To complete this form, please follow these steps:

1. Review each field carefully and ensure you have the necessary information.
2. Fill in your details accurately and concisely.
3. Select the correct options for each field as required.
4. Double-check your responses for accuracy before submitting the form.

## Field-by-Field Explanation

### 1. **first_name** (`first_name`, text, required)
	* Enter your first name in this field.
	* Please note that this field is required.

### 2. **last_name** (`last_name`, text, required)
	* Enter your last name in this field.
	* Please note that this field is required.

### 3. **date_of_birth** (`date_of_birth`, date, optional)
	* If applicable, enter the date of your birth in the format 'mm/dd/yyyy'.
	* If not applicable, you can leave this field blank.

### 4. **place_of_birth** (`place_of_birth`, text, optional)
	* If applicable, enter the place of your birth.
	* If not applicable, you can leave this field blank.

### 5. **contact_number** (`contact_number`, text, optional)
	* If you have a contact number, enter it in this field.
	* If not, leave this field blank.

### 6. **immigration_status** (`immigration_status`, select, optional)
	* Select 'Active' if you are currently an immigrant.
	* Select 'Inactive' if you are not an immigrant.
	* Select one of the options that best describes your status.

### 7. **immigration_type** (`immigration_type`, select, optional)
	* Select 'Yes' if you are an immigrant.
	* Select 'No' if you are not an immigrant.

### 8. **date_of_arrival** (`date_of_arrival`, date, optional)

### 9. **country_of_residence** (`country_of_residence`, text, optional)

### 10. **purpose_of_travel** (`purpose_of_travel`, text, optional)

### 11. **travel_documents** (`travel_documents`, select, optional)

### 12. **current_residence** (`current_residence`, select, optional)

	* Select 'No' if you currently reside in your country of birth.
	* Select one of the options that best describes your residence status.

### 13. **previous_residence** (`previous_residence`, select, optional)

### 17. **family_status** (`family_status`, select, optional)
