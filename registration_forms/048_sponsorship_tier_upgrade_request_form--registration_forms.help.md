# Sponsorship Tier Upgrade Request Form - Help Guide
## Purpose
This form is designed to help organizations upgrade their sponsorship tier. To use this form, please follow the steps below.

## How To Complete This Form
1. Fill out the form completely.
2. Provide the required information for your organization.

## Field-by-Field Explanation
* **Organization** (`organization`, `text`, required: false): Please enter your organization's name.
* **Sponsorship Tier** (`sponsorship_tier`, `select_one`, required: false): Select the sponsorship tier you wish to upgrade to. You can choose from the following options: 
  - Bronze
  - Silver
  - Gold
  - Platinum
* **Date Upgraded** (`date_upgraded`, `date`, required: false): This is the date you would like to upgrade to the selected sponsorship tier.
* **Date Request Submitted** (`date_request_submitted`, `date`, required: false): This is the date your request was submitted.
* **Email Address** (`email_address`, `email`, required: false): Please enter your organization's email address.
* **Phone Number** (`phone_number`, `text`, required: false): Please enter your organization's phone number.

## Tips
* Please ensure that you are submitting a new request for a sponsorship tier upgrade. If you have already submitted a request for an upgrade, please do not submit another request.
* Make sure to fill out all required fields to ensure that your request is processed correctly.
