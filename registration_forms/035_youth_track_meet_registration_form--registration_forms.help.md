# Youth Track Meet Registration Form - Help Guide
## Purpose
This form is used for registering youth athletes for various events and meet-related activities.

## How To Complete This Form
To complete this form, follow the instructions below.

## Field-by-Field Explanation

* **School Info** (1, text, required)
	+ This field is used to capture information about the school the athlete is from.
* **Event Selections** (2, select_multiple, optional)
	+ Select the events you are interested in participating in. You can choose multiple events.
* **Youth Athlete Details** (3, note, optional)
	+ Enter a brief description of the athlete, including their name, age, and any special needs.
* **Parent Consent** (4, number, required)
	+ Enter the number of parents or guardians you are authorizing.
* **Contact Info** (5, text, optional)
	+ Enter the contact information for the parent or guardian who will be responsible for the athlete.
* **School Info 2** (6, text, required)
	+ Enter the name of the school the athlete is from.
* **Emergency Contact** (7, email, optional)
	+ Enter an email address or phone number of a contact person in case of an emergency.
* **Event Selections 2** (8, select_one, optional)
	+ Select the event you are interested in participating in. You can only choose one event.
* **Event Type** (9, time, required)
	+ Enter the type of event (e.g., competition, practice, etc.).
* **Event Type 2** (10, date, required)
	+ Enter the date of the event.
* **Event Date** (11, select_multiple, required)
	+ Select the date of the event. You can choose multiple dates.
* **Event Start Time** (12, number, required)
	+ Enter the start time of the event.
* **Event Duration** (13, text, optional)
	+ Enter the duration of the event (e.g., 1 hour, 2 hours, etc.).
* **Event End Time** (14, text, required)
	+ Enter the end time of the event.
* **School Name** (15, text, optional)
	+ Enter the name of the school the athlete is from.
* **School Name 2** (16, text, required)
	+ Enter the name of the school the athlete is from.
* **School Address** (17, text, required)
	+ Enter the address of the school the athlete is from.
* **Event Name** (18, text, required)
	+ Enter the name of the event.
* **Event Name 2** (19, text, required)
	+ Enter the name of the event.
* **Event Details** (20, text, required)
	+ Enter any additional details about the event.
* **Event Details 2** (21, text, optional)
	+ Enter any additional details about the event.
* **Event Location** (22, text, required)
	+ Enter the location of the event.
* **Event Location 2** (23, text, required)
	+ Enter the location of the event.
* **Event Notes** (24, note, optional)
	+ Enter any additional notes about the event.
* **Event Notes 2** (25, note, optional)
	+ Enter any additional notes about the event.

## Tips
- Make sure to fill out all required fields accurately.
- Select events and locations carefully, as they will impact event logistics.
- Enter contact information for parents and guardians accurately.
- Double-check event details to ensure accuracy and consistency.
- If you are unsure about any field, please ask for clarification.
