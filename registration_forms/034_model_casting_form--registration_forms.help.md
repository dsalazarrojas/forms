# Model Casting Form - Help Guide
## Purpose
The Model Casting Form is designed to collect information about models and their related projects, including agencies, locations, and dates. This form is crucial for managing model casting processes and ensuring that all required details are captured accurately.

## How To Complete This Form
To complete the Model Casting Form, follow these steps:

1. Ensure you have all the required information, including model type, name, image, agency name, phone number, email, website, address, project details, and project location.
2. Fill in the form's fields with the necessary information. The form is divided into sections, making it easier to find the relevant fields.
3. Review and correct any errors before submitting the form.

## Field-by-Field Explanation

* **Form ID** (form_id, number, required): This is the unique identifier for the form. Enter a number to register the form.
* **Model Type** (model_type, select_one, required): Select the type of model you are casting, such as "Model Actor", "Model Dancer", or "Model Singer".
* **Model Name** (model_name, text, required): Enter the name of the model you are casting.
* **Model Image** (model_image, text, optional): Provide an image of the model for reference (optional).
* **Agency Name** (agency_name, text, required): Enter the name of the agency responsible for the model.
* **Agency Phone** (agency_phone, text, required): Enter the phone number of the agency.
* **Agency Email** (agency_email, email, required): Enter the email address of the agency.
* **Agency Website** (agency_website, text, required): Enter the website of the agency.
* **Agency Address** (agency_address, text, required): Enter the address of the agency.
* **Project Details** (project_details, text, required): Enter a brief description of the project, including details about the model's role and responsibilities.
* **Project Location** (project_location, text, required): Enter the location where the project will take place.
* **Start Date** (start_date, date, optional): Enter the start date of the project (if applicable).
* **End Date** (end_date, date, optional): Enter the end date of the project (if applicable).

**Tips**

* Ensure all fields are filled in accurately and completely to avoid errors.
* Review the form before submitting to ensure all required fields are completed.
* If you're unsure about any field, refer to the relevant section of this guide for clarification.
