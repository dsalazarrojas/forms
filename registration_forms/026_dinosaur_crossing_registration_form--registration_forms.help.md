# Dinosaur Crossing Registration Form - Help Guide

## Purpose
The Dinosaur Crossing Registration Form collects information from participants who wish to join the event.

## How To Complete This Form
1. Fill out the form data page with general information about yourself.
2. Provide specific information about the dinosaur participating in the event on the dinosaur data page.
3. Select the event data and event location information on the respective pages.
4. Choose the contact data and submission status on the respective pages.
5. Add any additional notes or comments in the "Form Notes" section.
6. Finally, submit the form to complete the registration process.

## Field-by-Field Explanation

* **Form Data** (id: 1, text, required: false)
	+ This is the first page of the form where you can fill out general information about yourself.
* **Dinosaur Data** (id: 2, text, required: false)
	+ Enter specific information about the dinosaur participating in the event.
* **Event Data** (id: 3, select_one, required: true)
	+ Select "Yes" or "No" to indicate if you are participating in the event.
* **Registration Data** (id: 4, select_multiple, required: true)
	+ Select "Yes" or "No" to indicate your registration status for the event.
* **Contact Data** (id: 5, select_one, required: true)
	+ Select "Yes" or "No" to indicate your contact information for the event.
* **Form Submitted** (id: 6, text, required: true)
	+ Enter the date and time the form was submitted.
* **Event Details** (id: 7, text, required: false)
	+ Add any additional notes or comments about the event.
* **Event Location** (id: 8, text, required: false)
	+ Enter the location of the event.
* **Event Time** (id: 9, time, required: false)
	+ Select the time of the event.
* **Submission Status** (id: 10, note, required: false)
	+ Check the status of your form submission.
* **Registration Date** (id: 11, date, required: false)
	+ Enter the date of registration.
* **Event Date** (id: 12, date, required: false)
	+ Enter the date of the event.
* **Event Time** (id: 13, time, required: false)
	+ Select the time of the event.
* **Event Location** (id: 14, text, required: false)
	+ Enter the location of the event.
* **Notes** (id: 15, note, required: false)
	+ Add any additional comments or notes about the event.
* **Email** (id: 16, email, required: false)
	+ Enter your email address.
* **Phone** (id: 17, text, required: false)
	+ Enter your phone number.
* **Name** (id: 18, text, required: false)
	+ Enter your name.
* **Event Type** (id: 19, select_one, required: true)
	+ Select the type of event you are participating in.
* **Form Notes** (id: 20, note, required: false)
	+ Add any additional comments or notes about the form.
* **Event Name** (id: 21, text, required: false)
	+ Enter the name of the event.
* **Start Date** (id: 22, date, required: false)
	+ Enter the start date of the event.
* **End Date** (id: 23, date, required: false)
	+ Enter the end date of the event.
* **Description** (id: 24, text, required: false)
	+ Add a description of the event.
* **Address** (id: 25, text, required: false)
	+ Enter the address of the event location.
