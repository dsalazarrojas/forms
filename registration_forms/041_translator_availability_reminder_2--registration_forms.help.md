# Translator Availability Reminder 2 - Help Guide
## Purpose
The Translator Availability Reminder 2 form is a tool for translators to report their availability and productivity. This information will be used internally to plan projects and allocate resources effectively.

## How To Complete This Form
To complete this form, please follow these steps:

1. For each translator, select either "Yes" or "No" to indicate their availability.
2. For the dates, enter the start and end dates of the project or period you are reporting on.
3. Enter the number of words you are able to translate per day.
4. Select the days of the week you are available to work on.
