# Promotional Event Records Release Form - Help Guide
## Purpose
The Promotional Event Records Release Form is used to capture information related to promotional events, ensuring that participants' consents and releases are obtained correctly. This form helps in organizing events and managing promotional materials.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the number of participants attending the event in the "event_participant_number" field.
2. Provide the name of the participant in the "participant_name" field.
3. Record the event date in the "event_date" field.
4. Enter the number of participants in the "event_participant_count" field.
5. Select the options for "promotional_materials_sharing_consent" that apply to the participant.
6. If required, sign the "participant_signature" field.
7. Choose the participant's consent from the "participant_consent" field.
8. Choose the participant's agreement from the "participant_agreement" field.
9. (Optional) Note any information about the event host in the "event_host" field.

## Field-by-Field Explanation

* **event_participant_number** (text, required): Enter the number of participants attending the event.
* **participant_name** (text, required): Enter the name of the participant.
* **event_date** (date, required): Record the date of the event.
* **event_participant_count** (number, required): Enter the number of participants in the event.
* **promotional_materials_sharing_consent** (select multiple, required): Select the options that apply to the participant for sharing promotional materials.
* **participant_signature** (note, not required): If required, sign this field with a physical signature.
* **participant_consent** (select one, required): Choose the participant's consent option.
* **participant_agreement** (select one, required): Choose the participant's agreement option.
* **event_host** (note, not required): (Optional) Enter any information about the event host.

## Tips
- Make sure to fill out all required fields correctly.
- Review the "promotional_materials_sharing_consent" options carefully before making a selection.
- Ensure that participant signature, consent, and agreement are properly obtained before proceeding.
- Enter accurate event date and participant count information.
