# Student Information Collection Form - Help Guide
## Purpose
The Student Information Collection Form is designed to collect student data for administrative and academic purposes.
## How To Complete This Form
To complete the form, start by ensuring that you have all required fields populated and that optional fields are filled out accurately if necessary.
## Field-by-Field Explanation
* **Student ID** (`student_id`, number, required/optional): Enter the student's unique identification number if you have it.
* **Name** (`name`, text, required): Enter the student's full name.
* **Email** (`email`, email, required): Enter a valid email address for the student.
* **Student Number** (`student_number`, number, optional): Enter the student's number if applicable.
* **Grade Level** (`grade_level`, select_one, required): Select the student's current grade level from the available options.
* **Class ID** (`class_id`, number, optional): Enter the class ID number if applicable.
* **Subject** (`subject_id`, select_one, required): Select the subject the student is enrolled in from the available options.
* **Student Notes** (`student_notes`, note, required): Provide any additional notes or comments about the student.
* **Parent Permission** (`parent_permission`, select_multiple, optional): If applicable, select whether or not the parent has given permission.
* **Date Created** (`created_at`, date, required): This field is automatically populated and not editable.
## Tips
- Ensure all required fields are filled out accurately to avoid form submission errors.
- Use the available options for select fields to make the correct choice.
- If you're unsure about any field, refer to your school's policies or consult with a school administrator.
