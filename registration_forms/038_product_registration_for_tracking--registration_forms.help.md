# Product Registration For Tracking - Help Guide
## Purpose
The "Product Registration For Tracking" form is designed to collect information about a product's registration for tracking purposes. This form helps to ensure that the product can be tracked correctly, and any errors or duplication can be avoided.

## How To Complete This Form
To complete this form, please follow the instructions below:

1. Fill out the required fields marked as "Required" with the correct information.
2. For fields with a "Select One" or "Select Multiple" type, choose the correct option from the list.
3. Enter the correct information in the "Text" fields.
4. Select the correct format for the "Date" and "Time" fields.
5. Ensure that you've filled out all the required fields accurately and completely.

## Field-by-Field Explanation
* **Product ID** (`product_id`, number, Required): Enter the unique product ID.
* **User Name** (`user_name`, text, Required): Enter the name of the user who registered the product.
* **Email** (`email`, email, Required): Enter a valid email address.
* **Contact Number** (`contact_number`, text, Required): Enter the contact number of the user.
* **Address** (`address`, note, Required): Enter the address of the user.
* **Product Description** (`product_description`, text, Required): Enter a brief description of the product.
* **Purchase Date** (`purchase_date`, date, Required): Select the date of purchase in the correct format (e.g., YYYY-MM-DD).
* **Purchase Time** (`purchase_time`, time, Required): Select the time of purchase in the correct format (e.g., 12:00).
* **Purchase Location** (`purchase_location`, select_one, Required): Select the location of purchase from the list.
* **Purchase Method** (`purchase_method`, select_multiple, Required): Select the method of purchase from the list.
* **Purchase Details** (`purchase_details`, note, Required): Enter any additional details about the purchase.
* **Tracking Status** (`tracking_status`, select_one, Required): Select the current tracking status from the list.
* **Tracking Comments** (`tracking_comments`, text, Required): Enter any comments about the tracking status.
* **User Comments** (`user_comments`, text, Required): Enter any comments from the user.
* **Form Submission** (`form_submit`, select_one, Required): Select the form submission status from the list.
* **Submit Date** (`submit_date`, date, Required): Select the date of submission in the correct format (e.g., YYYY-MM-DD).
* **Submit Time** (`submit_time`, time, Required): Select the time of submission in the correct format (e.g., 12:00).
* **Submit Location** (`submit_location`, select_one, Required): Select the location of submission from the list.
* **Submit Comments** (`submit_comments`, text, Required): Enter any comments about the submission status.
* **Tracking Link** (`tracking_link`, text, Optional): Enter the tracking link (if applicable).
* **Tracking Code** (`tracking_code`, text, Optional): Enter the tracking code (if applicable).
* **Tracking Status Update** (`tracking_status_update`, select_one, Optional): Select the status of the tracking update from the list.
* **Tracking Status Comments** (`tracking_status_comments`, text, Optional): Enter any comments about the tracking status update.
* **Brand Name** (`brand_name`, text, Optional): Enter the brand name of the product (if applicable).
* **Product Category** (`product_category`, text, Optional): Enter the category of the product (if applicable).

Note: This help guide is for the user's reference, and it is essential to review it carefully before filling out the form.
