# Talent Retention Strategy Session Registration Form - Help Guide
## Purpose
The Talent Retention Strategy Session Registration Form is designed to collect information for a Talent Retention Strategy Session. This form is intended to be filled out by participants to provide details about their session. 

## How To Complete This Form
- Carefully fill out each section of the form, taking into account the hints and explanations provided for each field.
- Ensure that you are not duplicating any existing sessions.

## Field-by-Field Explanation

* **Registration Form** (1, text, required): Enter the title of the session.
* **Email** (2, email, required): Enter your email address. This should match the one you used to create your account.
* **Description** (3, text, required): Enter a brief description of the session.
* **Participant Name** (4, text, required): Enter the name of the participant.
* **Participant Email** (5, email, required): Enter the email address of the participant.
* **Title** (6, text, required): Enter a brief title for the session.
* **Start Time** (7, time, required): Select the start time of the session.
* **End Time** (8, time, required): Select the end time of the session.
* **Duration** (9, number, required): Enter the duration of the session in minutes.
* **Location** (10, text, required): Enter the location of the session.
* **Status** (11, select_one, required): Select the status of the session (Open, Closed, or In Progress).
* **Status Date** (12, date, required): Select the date of the session status update.
* **Status Time** (13, time, required): Select the time of the session status update.
* **Comments** (14, text, required): Enter any comments about the session.
* **Participant Comments** (15, text, required): Enter comments about the participant's session.
* **Participant Status** (16, select_multiple, required): Select the status of the participant (Active, Inactive, or Pending).
* **Participant Location** (17, select_one, required): Select the location of the participant (Office, Remote, or Hybrid).
* **Participant Status Date** (18, date, required): Select the date of the participant's status update.
* **Participant Status Time** (19, time, required): Select the time of the participant's status update.
* **Participant Notes** (20, text, required): Enter any notes about the participant.
* **Version** (21, number, required): Enter the version of the form.
* **Status Updated** (22, time, required): Select the time when the status was updated.
* **Updated By** (23, text, required): Enter the name of the user who updated the session.
* **Last Updated** (24, time, required): Select the time when the session was last updated.
* **Last Updated By** (25, text, required): Enter the name of the user who last updated the session.
* **Last Updated Time** (26, time, required): Select the time when the session was last updated.
