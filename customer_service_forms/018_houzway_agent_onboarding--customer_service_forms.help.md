# houzway_agent_onboarding - Help Guide
## Purpose
The houzway_agent_onboarding form is used to onboard new agents for the Houzway platform, ensuring a smooth and effective onboarding experience.

## How To Complete This Form
1. Fill out the form with the required information.
2. Select the correct onboarding status from the available options.
3. Provide any necessary comments or notes about the onboarding process.
4. Date and time of the onboarding session should be accurately entered.
5. Ensure that all information is accurate and complete.

## Field-by-Field Explanation

* **Onboarding Status**: (`onboarding_status`, `select_one`, true)
	+ This field is used to determine the agent's current onboarding status.
	+ Select the correct option that best describes their current state: Option 1, Option 2, or Option 3.
* **Onboarding Comments**: (`onboarding_comments`, `text`, false)
	+ This field is used to provide any comments or notes about the onboarding process.
	+ Enter any relevant information that may be helpful for future reference.
* **Onboarding Date**: (`onboarding_date`, `date`, false)
	+ This field is used to record the date of the onboarding session.
	+ Enter the date in the correct format (YYYY-MM-DD).
* **Onboarding Time**: (`onboarding_time`, `time`, false)
	+ This field is used to record the time of the onboarding session.
	+ Enter the time in the correct format (HH:MM AM/PM).
* **User Input Form**: (`user_input_form`, `text`, false)
	+ This field is a generic input field for any other relevant information.
	+ Enter any information that is not covered by the other fields.
 

## Tips
* Ensure that all information is accurate and complete.
* Double-check the onboarding status to reflect the agent's current state.
* Keep the onboarding comments concise and relevant.
* Date and time entries should be in the correct format.
