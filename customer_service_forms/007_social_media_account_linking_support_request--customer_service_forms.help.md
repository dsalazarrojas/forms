# Social Media Account Linking Support Request - Help Guide
## Purpose
This form is designed to help you if you are experiencing issues with linking your social media account to our platform.

## How To Complete This Form
To complete this form, please follow these steps:

1.  Fill in the "Account Linking Issue" field with a brief description of the problem you are experiencing.
2.  Enter your email address in the "Email" field so we can contact you for further assistance.
3.  If you have a phone number, please enter it in the "Phone" field.
4.  Select the social media platform you are experiencing issues with from the "Social Media Platform" dropdown menu.
5.  In the "Description" field, provide more details about the issue you are experiencing.
6.  Indicate the expected resolution time in the "Expected Resolution Time" field.
7.  If you have any additional information that may help us assist with your issue, enter it in the "Additional Information" field.
8.  If you have any relevant attachments (e.g., screenshots, error messages), upload them in the "Attachments" field.

## Field-by-Field Explanation
* **Account Linking Issue** (`Account Linking Issue`, required): Enter a brief description of the problem you are experiencing with linking your social media account.
* **Email** (`Email`, required): Enter your email address so we can contact you for further assistance.
* **Phone** (`Phone`, optional): If you have a phone number, enter it so we can contact you if needed.
* **Social Media Platform** (`Social Media Platform`, optional): Select the social media platform you are experiencing issues with.
*   *Example: If you are experiencing issues with your Facebook account, select "Facebook"*
* **Description** (`Description`, required): Provide more details about the issue you are experiencing.
* **Expected Resolution Time** (`Expected Resolution Time`, optional): Indicate the expected resolution time for your issue. This will help us prioritize your request.
*   *Example: If you expect a resolution within 1 day, select "1 day"*
* **Additional Information** (`Additional Information`, optional): If you have any additional information that may help us assist with your issue, enter it here.
* **Attachments** (`Attachments`, optional): If you have any relevant attachments (e.g., screenshots, error messages), upload them here.

Note: Please ensure you have attached relevant files before submitting the form.
