# Color Street Wishlist - Help Guide
## Purpose
The purpose of this form is to allow customers to express their interest in specific Color Street sets, such as solids, glitters, designs/art, and French manicure options. This information will be used to determine which sets to relaunch in the future.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter your name and email address in the required fields.
2. Select the specific sets you are interested in by typing them into the corresponding text fields (Solids I'm interested in, Glitters I'm interested in, Designs/Art I'm interested in, and French Manicure I'm interested in).
3. If you have a current Color Street Stylist, enter their name in the "Who is your current Color Street Stylist?" field.
4. If you'd like to be notified if these sets are relaunched, select "True" in the "Would you like to be notified if these are relaunched?" field.
5. Indicate which set is your absolute number one priority by typing it into the "Which set is your absolute number one priority?" field.
6. If you have any additional comments or feedback, enter them in the "Anything else you want to share?" field.

## Field-by-Field Explanation
* **Your Name**: Enter your name as it appears on your identification.
* **Your Email**: Enter your email address where you can be reached for updates.
* **-- My Color Street Interest --**: This section allows you to select specific sets you are interested in.
	+ **Solids I'm interested in**: List the specific solids you are interested in.
	+ **Glitters I'm interested in**: List the specific glitters you are interested in.
	+ **Designs/Art I'm interested in**: List the specific designs/art options you are interested in.
	+ **French Manicure I'm interested in**: List the specific French manicure options you are interested in.
* **Would you like to be notified if these are relaunched?**: Select "True" if you want to be notified when these sets are relaunched.
* **Who is your current Color Street Stylist?**: If you have a current Color Street Stylist, enter their name here.
* **Which set is your absolute number one priority?**: Type the set that is your absolute number one priority.
* **Anything else you want to share?**: Provide any additional comments or feedback you have.
