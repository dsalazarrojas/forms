# Bug Tracker Form - Help Guide
## Purpose

This form is used to report bugs and issues with our products or services. Please fill out the form with as much detail as possible to help our support team resolve the issue effectively.

## How To Complete This Form

1. Fill out each field with the required information.
2. Make sure to include a clear and concise description of the issue.
3. Attach any relevant screenshots or logs if possible.

## Field-by-Field Explanation

* **Date Submitted (`submission_date`)**: The date you are submitting this report.
	+ Type: `date`
	+ Required: Yes
* **Issue Title (`issue_title`)**: A one-line summary of the bug or issue.
	+ Type: `text`
	+ Required: Yes
* **Issue Description (`issue_description`)**: A detailed explanation of what went wrong.
	+ Type: `text`
	+ Required: Yes
* **Browser Used (`browser_used`)**: The browser you were using when the issue occurred.
	+ Type: `select_one`
	+ Required: Yes
* **Browser Version (`browser_version_info`)**: The version number of your browser.
	+ Type: `text`
	+ Required: No
* **Operating System (`operating_system_used`)**: The operating system you were using.
	+ Type: `select_one`
	+ Required: Yes
* **Urgency Level (`urgency_level`)**: The priority level for resolution.
	+ Type: `select_one`
	+ Required: Yes
* **Steps to Reproduce (`reproduction_steps`)**: Exact steps to trigger the bug.
	+ Type: `text`
	+ Required: Yes
* **Expected Result (`expected_result`)**: What the user expected to happen.
	+ Type: `text`
	+ Required: Yes
* **Actual Result (`actual_result`)**: What actually happened.
	+ Type: `text`
	+ Required: Yes
* **Frequency (`frequency`)**: How often the issue occurs.
	+ Type: `select_one`
	+ Required: Yes
* **Your Name (`submitter_name`)**: Your full name.
	+ Type: `text`
	+ Required: Yes
* **Email Address (`submitter_email`)**: Your email address for support team follow-up.
	+ Type: `email`
	+ Required: Yes
* **Phone Number (`submitter_phone`)**: Your phone number (optional).
	+ Type: `text`
	+ Required: No
* **Account ID (`account_id`)**: Your account ID (if applicable).
	+ Type: `text`
	+ Required: No
* **Screenshot or Logs Attached (`screenshot_attached`)**: Whether you have attached a screenshot or logs.
	+ Type: `select_one`
	+ Required: No
