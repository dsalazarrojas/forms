# SharePoint Helpdesk Request - Help Guide

## Purpose
The SharePoint Helpdesk Request form allows you to send requests to the IT team for various types of help and support. This form helps the IT team prioritize and resolve issues efficiently.

## How To Complete This Form
To complete this form, follow these steps:
1. Fill out the "User Information" section with your name and email.
2. Provide detailed descriptions of the issues you are experiencing in the "Issue Details" field.
3. Select the relevant options for "Site Updates," "Group Members," and "Issue Type" according to your needs.
4. Choose your priority level for the issue.
5. Select the status of the issue.
6. Select who the issue has been assigned to.
7. Choose the "Created By," "Updated By," and "Closed By" options according to your role in the issue resolution.
8. Optionally, add any tags or comments in the "Tags" and "Comments" fields.

## Field-by-Field Explanation
* **User Information** (User Information, text, optional): Enter your name and email address to help the IT team contact you regarding your request.
* **Name** (Name, text, optional): Enter your name to help the IT team identify you as the requestor.
* **Email** (Email, email, optional): Enter your email address to enable the IT team to contact you regarding your request.
* **Issue Details** (Issue Details, note, optional): Describe the issue you are experiencing in as much detail as possible.
* **Site Updates** (Site Updates, select multiple, optional): Select "Yes" if you are requesting help with site updates.
* **Group Members** (Group Members, select multiple, optional): Select "Yes" if you are requesting help with group members.
* **Issue Type** (Issue Type, select one, optional): Select the type of issue you are experiencing.
* **Priority** (Priority, select one, optional): Select the priority level of the issue (e.g., low, medium, high).
* **Status** (Status, select one, optional): Select the status of the issue (e.g., active, inactive).
* **Assigned To** (Assigned To, select one, optional): Select who the issue has been assigned to.
* **Created At** (Created At, date, optional): Enter the date the issue was created.
* **Updated At** (Updated At, date, optional): Enter the date the issue was last updated.
* **Closed At** (Closed At, date, optional): Enter the date the issue was closed.
* **Description** (Description, text, optional): Describe the issue in more detail.
* **Resolution** (Resolution, text, optional): Enter the resolution of the issue.
* **Tags** (Tags, text, optional): Enter any relevant tags to help the IT team categorize and resolve your issue.
* **Comments** (Comments, note, optional): Add any comments or feedback regarding your issue.
* **Created By** (Created By, select one, optional): Select who created the issue.
* **Updated By** (Updated By, select one, optional): Select who last updated the issue.
* **Closed By** (Closed By, select one, optional): Select who closed the issue.
* **Created At 2** (Created At 2, date, optional): Enter the date the issue was created (not to be used for issues created before this form is implemented).
* **Updated At 2** (Updated At 2, date, optional): Enter the date the issue was last updated (not to be used for issues created before this form is implemented).
* **Closed At 2** (Closed At 2, date, optional): Enter the date the issue was closed (not to be used for issues created before this form is implemented).
* **Assigned To 2** (Assigned To 2, select one, optional): Select who the issue has been assigned to (not to be used for issues created before this form is implemented).
* **Custom** (Custom, note, optional): Add any additional comments or details not covered by other fields.
