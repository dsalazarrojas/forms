# Website Update Request Form - Help Guide
## Purpose
The "Website Update Request Form" is used to submit updates to our website. This form helps us understand the changes you need and provides a way for you to communicate with our support team.

## How To Complete This Form
To complete this form, simply fill in the required fields with the requested information. If you need assistance with a specific field, refer to the field-by-field explanation below.

## Field-by-Field Explanation
* **Website Input** (`Website Input`, `text`, required): Enter a detailed description of the website update you require.
* **Email** (`email`, optional): Enter the email address you would like to use for communication about your website update.
* **Phone** (`Phone`, optional): Enter the phone number you would like to use for communication about your website update.
* **Website URL** (`Website URL`, required): Enter the URL of the website you are updating.
* **Description** (`Description`, optional): Enter a brief description of the website update.
* **Update Type** (`Update Type`, required): Select the type of update you are requesting. Choose from "urgent", "minor", or "major".
* **Contact Name** (`Contact Name`, required): Enter your name for communication purposes.
* **Contact Email** (`Contact Email`, optional): Enter your email address for communication purposes.
* **Contact Phone** (`Contact Phone`, optional): Enter your phone number for communication purposes.
* **Agency Name** (`Agency Name`, optional): If you are representing an agency, enter their name here.
* **Agency Contact** (`Agency Contact`, optional): If you are representing an agency, enter the contact person's name here.
* **Agency Email** (`Agency Email`, optional): If you are representing an agency, enter their email address here.
* **Agency Phone** (`Agency Phone`, optional): If you are representing an agency, enter their phone number here.
* **Message** (`Message`, required): Enter a detailed message about the website update.
* **Submit** (`Submit`, required): Click this button to submit your form.
* **Date** (`Date`, optional): Enter the date of the website update.
* **Time** (`Time`, optional): Enter the time of the website update.
* **Note** (`Note`, optional): Enter any additional notes about the website update.
* **Note Input** (`Note Input`, text, optional): Enter any additional information about the website update.
* **Note Text** (`Note Text`, text, optional): Enter any additional text about the website update.
* **Note Date** (`Note Date`, date, optional): Enter the date of the website update note.
* **Note Time** (`Note Time`, time, optional): Enter the time of the website update note.
* **Note Select One** (`Note Select One`, select_one, optional): Select any additional options for the website update note.
* **Note Select Multiple** (`Note Select Multiple`, select_multiple, optional): Select multiple additional options for the website update note.
* **Note Email** (`Note Email`, email, optional): Enter the email address of the person to contact for the website update note.

## Tips
* Please ensure all required fields are filled before submitting the form.
* If you have any questions or concerns, feel free to contact us.
* We will review and process your website update request as soon as possible.
