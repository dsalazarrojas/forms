# Customer Order Form - Help Guide
## Purpose
This form is used for tracking and managing customer orders, allowing customer service representatives or sales teams to record and update order information.

## How To Complete This Form
To complete this form, follow these steps:
1. Enter the customer order information in the "customer order form" field (ID: 1).
2. Provide details about the order in the "order details" field (ID: 2).
3. Enter customer information in the "customer info" field (ID: 3).
4. Select the current order status (ID: 4) from the available options.
5. Enter the order date (ID: 5) using the date format (YYYY-MM-DD).
6. Enter the order time (ID: 6) in 24-hour format (HH:MM:SS).
7. Enter the total value of the order (ID: 7) as a numerical value.
8. Add any additional notes about the order (ID: 8) in the text box.

## Field-by-Field Explanation

* **Customer Order Form (ID: 1)**
	+ Description: Enter the customer order information.
	+ Input type: Text field.
* **Order Details (ID: 2)**
	+ Description: Provide details about the order, such as description or notes.
	+ Input type: Text field.
* **Customer Info (ID: 3)**
	+ Description: Enter customer information such as name, address, etc.
	+ Input type: Text field.
* **Order Status (ID: 4)**
	+ Description: Select the current status of the order from the available options (New, Pending, Cancelled).
	+ Input type: Select one option.
* **Order Date (ID: 5)**
	+ Description: Enter the date the order was placed in the format YYYY-MM-DD.
	+ Input type: Date field.
* **Order Time (ID: 6)**
	+ Description: Enter the time the order was placed in 24-hour format (HH:MM:SS).
	+ Input type: Time field.
* **Order Total (ID: 7)**
	+ Description: Enter the total value of the order as a numerical value.
	+ Input type: Number field.
* **Order Notes (ID: 8)**
	+ Description: Add any additional notes about the order.
	+ Input type: Text box.
