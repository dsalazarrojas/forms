# Bug Tracking Form - Help Guide
## Purpose
The Bug Tracking Form is a tool used for reporting and tracking bugs within our system.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in all required fields (marked as "Required" above).
2. Ensure that you have all necessary information before submitting the form.
3. Double-check your answers to ensure accuracy.

## Field-by-Field Explanation

* **Bug ID Number**: A unique ID assigned to each bug report. It can be auto-generated or manually assigned.
* **Report Date**: The date and time when the bug was discovered. Please use the standard date format MM/DD/YYYY.
* **Bug Summary**: A short and concise title of the issue.
* **Detailed Description**: A complete description of the bug, including steps to reproduce and expected outcome.
* **Severity Classification**: The impact level of the bug. Choose from: Critical, High, Medium, Low.
* **Bug Status**: The current state of the bug. Choose from: New, In Progress, Resolved, On Hold, Closed.
* **Affected Module**: The part of the system affected by the bug. (Optional)
* **Affected Version**: The software version with the bug. (Required)
* **Reproduction Environment**: The operating system and browser combination where the bug was found. (Required)
* **Reproduction Procedure**: A step-by-step guide on how to reproduce the bug. (Required)
* **Expected Outcome**: A description of how the bug should behave. (Required)
* **Actual Outcome**: A description of how the bug currently behaves. (Required)
* **Assigned To**: The developer or tester responsible for fixing the bug. (Optional)
* **Reporter Name**: The person who reported the bug. (Required)
* **Reporter Email**: The contact email for further clarifications. (Required)
* **Supporting Attachments**: Whether or not you have attached supporting files like screenshots or logs. (Optional)
* **Resolution Date**: The date and time when the bug was fixed. (Optional)

Tips:

- Double-check your answers for accuracy.
- Attach any supporting files that might help the development team fix the bug.
- If you're not sure about anything, ask for clarification. 

This guide will ensure that you're able to effectively report bugs and provide all necessary information for the development team to fix the issue.
