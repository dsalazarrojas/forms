# Complaint Resolution Intake Form - Help Guide
## Purpose
The Complaint Resolution Intake Form is designed to collect essential information from customers about their complaints or issues related to a company's products or services.

## How To Complete This Form
1. Fill in the date and time the complaint was received.
2. Provide the assigned complaint ID.
3. Enter the customer's full name.
4. Enter the customer's contact email.
5. Enter the customer's contact phone number.
6. If applicable, enter the customer's mailing address.
7. Indicate the customer's relationship to the company.
8. If relevant, enter any account numbers related to the complaint.
9. Describe how the complaint was received (e.g., phone call, email, website form).
10. Select the primary category of the complaint (e.g., product quality, service delay).
11. Enter a brief title summarizing the issue.
12. Provide a detailed description of the problem.
13. If relevant, enter the date when the incident occurred.
14. If relevant, enter the location where the incident occurred.
15. If relevant, enter any products or services involved.
16. If applicable, enter order numbers related to the complaint.
17. If relevant, enter the transaction amount.
18. Indicate if the customer has previously complained about an issue.
19. Select the urgency level of the complaint.
20. Select the impact level of the complaint.
21. Describe what the customer expects as a resolution.
22. Assign the complaint to a specific person or group.
23. Select the department responsible for handling the complaint.
24. Set a resolution deadline.
25. Set the initial status of the complaint.
26. Add any additional information.
27. Attach any supporting documents.
28. Review and confirm all fields before submitting the form.

## Field-by-Field Explanation
* **Intake Date** (`intake_date`, required): Enter the date the complaint was received.
* **Intake Time** (`intake_time`, optional): Enter the time the complaint was received.
* **Complaint ID** (`complaint_id`, required): Enter the assigned complaint ID number for reference.
* **Customer Name** (`customer_name`, required): Enter the customer's full name.
* **Customer Email** (`customer_email`, required): Enter the customer's contact email address.
* **Customer Phone** (`customer_phone`, required): Enter the customer's contact phone number.
* **Customer Address** (`customer_address`, optional): If applicable, enter the customer's mailing address.
* **Customer Type** (`customer_type`, required): Select the customer's relationship to the company (e.g., new customer, existing customer).
* **Account Number** (`account_number`, optional): If relevant, enter any account numbers associated with the complaint.
* **How Was Complaint Received** (`complaint_source`, required): Select the channel through which the complaint was received (e.g., phone call, email).
* **Complaint Category** (`complaint_category`, required): Select the primary category of the complaint (e.g., product quality, service delay).
* **Complaint Subject** (`complaint_subject`, required): Enter a brief title summarizing the issue.
* **Detailed Description** (`complaint_description`, required): Provide a detailed description of the problem.
* **Incident Date** (`incident_date`, required): If relevant, enter the date when the incident occurred.
* **Incident Location** (`incident_location`, optional): If relevant, enter the location where the incident occurred.
* **Products Involved** (`products_involved`, optional): If relevant, enter any products or services associated with the complaint.
* **Services Involved** (`services_involved`, optional): If relevant, enter any services associated with the complaint.
* **Order Number** (`order_number`, optional): If relevant, enter any order numbers related to the complaint.
* **Transaction Amount** (`transaction_amount`, optional): If relevant, enter the value of the transaction.
* **Previous Complaints** (`previous_complaints`, required): Indicate if the customer has previously complained about an issue.
* **Priority Level** (`priority_level`, required): Select the urgency level of the complaint (e.g., critical, high, medium).
* **Severity Level** (`severity_level`, required): Select the impact level of the complaint (e.g., severe, high, moderate).
* **Customer Expected Resolution** (`expected_resolution`, required): Describe what the customer expects as a resolution.
* **Assigned To** (`assigned_to`, required): Assign the complaint to a specific person or group.
* **Assigned Department** (`assigned_department`, required): Select the department responsible for handling the complaint (e.g., customer service, technical support).
* **SLA Deadline** (`sla_deadline`, required): Set a resolution deadline.
* **Initial Status** (`initial_status`, required): Set the initial status of the complaint (e.g., new, in progress, pending).
* **Intake Notes** (`intake_notes`, optional): Enter any additional information or context.
* **Attachments** (`attachments`, optional): Attach any supporting documents or evidence.

Note: This help guide is based on the provided YAML schema and assumes that all fields are correctly filled in accordingly to ensure accurate complaint data is captured.
