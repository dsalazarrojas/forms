# IBSL Release Of Information_Brannon - Help Guide
## Purpose
This form is designed to facilitate the release of information related to the Brannon incident, enabling authorized personnel to manage and document the process.

## How To Complete This Form

To complete this form, follow these steps:
* Review the form purpose and ensure you have the necessary permissions and approvals.
* Fill in the fields as required, providing the necessary information for each field.
* Ensure that you have reviewed and understood the process before submitting the form.

## Field-by-Field Explanation

* **Release of information brannon** (`release_of_information_brannon`, text, optional): Enter the relevant information related to the Brannon incident.
* **Customer service forms** (`customer_service_forms`, select_multiple, optional): Select all relevant customer service forms that need to be released.
* **Release date** (`release_date`, date, optional): Enter the date when the information is to be released.
* **Release time** (`release_time`, time, optional): Enter the time when the information is to be released.
* **Assigned tool** (`assigned_tool`, text, optional): Enter the tool assigned for this release.
* **Assigned tool** (second instance, text, optional): Please note that this field is identical to the above field and seems to be a duplicate. Enter the tool assigned for this release. Please ensure only one instance of this field is completed.
* **Form ids** (`form_ids`, number, optional): Enter the IDs of the forms to be released.
* **Form ids** (second instance, text, optional): Please note that this field is identical to the above field and seems to be a duplicate. Enter the IDs of the forms to be released. Please ensure only one instance of this field is completed.
* **Output file** (`output_file`, select_multiple, optional): Select whether to output a file for this release.
* **Title** (`title`, text, optional): Enter a title for this release of information.
*   Please note that all fields are optional unless specified otherwise.

## Tips

* Ensure you have reviewed and understood the process before completing this form.
* Please only complete this form if you have the necessary permissions and approvals.
* If you are unsure about any field, please consult with your supervisor or team lead.
* Please ensure to complete only one instance of identical fields (e.g., `assigned_tool`, `form_ids`).
