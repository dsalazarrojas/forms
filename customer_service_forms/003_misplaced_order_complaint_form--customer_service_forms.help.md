# misplaced_order_complaint_form - Help Guide
## Purpose
The misplaced order form is used to report issues with misplaced orders, allowing customer support to efficiently track and resolve such problems.

## How To Complete This Form
To report a misplaced order, please follow the steps below:

1.  Fill in the customer name to identify the person reporting the issue.
2.  Enter the exact order number to help us locate the order.
3.  Describe the misplaced item as accurately as possible.
4.  Report the date and time the item was discovered to be misplaced.
5.  Provide a clear reason for why the item was misplaced.
6.  Give a detailed description of the misplaced item to aid in identification.

## Field-by-Field Explanation
*   **Misplaced Order Form** (`misplaced_order_form`, text, optional): A brief description of the issue with the misplaced order.
*   **Order Number** (`order_number`, number, required): The exact number of the misplaced order to help locate it.
*   **Misplaced Item** (`misplaced_item`, text, optional): A brief description of the item that was misplaced.
*   **Date** (`misplaced_date`, date, optional): The date the item was discovered to be misplaced.
*   **Time** (`misplaced_time`, time, optional): The time the item was discovered to be misplaced.
*   **Reason** (`misplaced_reason`, text, optional): A clear explanation of why the item was misplaced.
*   **Item Description** (`misplaced_item_description`, text, optional): A detailed description of the misplaced item to aid in identification.
*   **Customer Name** (`customer_name`, text, optional): The name of the person reporting the misplaced order.

## Tips
*   If you are unsure about any of the fields, please contact our support team for assistance.
*   Ensure the order number is accurate to ensure the misplaced order can be located quickly.
*   Provide as much detail as possible for the misplaced item description to aid in identification.
