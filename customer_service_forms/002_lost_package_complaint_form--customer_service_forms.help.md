# Lost Package Complaint Form - Help Guide

## Purpose
The Lost Package Complaint Form is used to report a lost package and provide essential details about the incident. It helps the shipping company to track and investigate the issue efficiently.

## How To Complete This Form
1. Make sure you have already checked with the delivery carrier and confirmed that your package is indeed lost. If you have not checked, please do not submit this form.
2. Fill out the form carefully, providing as much information as you can about the incident.
3. If you are having difficulty with the form, please contact our customer service team for assistance.

## Field-by-Field Explanation

* **Customer Name** (`customer_name`, text, **required**): Please enter the name of the customer filing the complaint.
* **Customer Email** (`customer_email`, email, **required**): Enter the email address associated with the account or used to contact you.
* **Customer Phone** (`customer_phone`, text, **required**): Provide your phone number for further communication.
* **Package Tracking Number** (`package_tracking_number`, text, **required**): Enter the tracking number assigned to the lost package.
* **Package Type** (`package_type`, text, **required**): Specify the type of package being reported (e.g., parcel, box, or pallet).
* **Date Lost** (`date_missing`, date, **optional**): If you know the date the package was lost, provide it in the format `YYYY-MM-DD`.
* **Time Lost** (`time_missing`, time, **optional**): If you know the time the package was lost, provide it in the format `HH:MM:SS`.
* **Reason for Loss** (`reason_for_loss`, text, **required**): Describe the circumstances surrounding the loss of the package (e.g., theft, damage, or misplacement).
* **Lost Location** (`lost_location`, text, **required**): Indicate where the package was last seen before it got lost (e.g., city, town, or specific address).
* **Lost Date** (`lost_date`, date, **optional**): If you know the date the package was last seen before it got lost, provide it in the format `YYYY-MM-DD`. 
* **Lost Time** (`lost_time`, time, **optional**): If you know the time the package was last seen before it got lost, provide it in the format `HH:MM:SS`. 

Note: If you are unable to determine the exact date or time, please provide any available information about the incident.
