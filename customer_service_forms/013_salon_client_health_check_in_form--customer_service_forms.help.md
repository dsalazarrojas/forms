# salon_client_health_check_in_form - Help Guide
## Purpose
This form is designed to collect information about a client's health status, medical history, and emergency contact details, to ensure that the salon or spa has accurate and up-to-date information to provide personalized and safe services.

## How To Complete This Form
To complete this form, please follow these steps:

1. Start by providing your current client state. This can be a simple text entry.
2. If you have any medical history, please provide a brief description in the text field.
3. If you have any allergies, please list them in the text field.
4. If you are currently taking any medications, please list them in the text field.
5. If you have any medical conditions, please provide a brief description in the text field.
6. If you have a medical condition, please provide a brief description of your current state in the text field.
7. Please provide the name and contact information of the person you would like to be contacted in case of an emergency.
8. If applicable, please describe your relationship with this emergency contact person.

## Field-by-Field Explanation
* **client_state** (Text): Please enter your current state (e.g., healthy, sick, injured).
* **medical_history** (Text): If you have any relevant medical history, please enter a brief description.
* **allergies** (Text): If you have any allergies, please list them.
* **current_medications** (Text): If you are currently taking any medications, please list them.
* **current_medications_allergies** (Text): If any of the medications you are currently taking have any allergies, please list them.
* **medical_condition** (Text): If you have any medical conditions, please provide a brief description.
* **medical_condition_description** (Text): If you have a medical condition, please provide a brief description of your current state.
* **emergency_contact_person** (Text): Please provide the name of the person you would like to be contacted in case of an emergency.
* **emergency_contact_number** (Text): Please provide the contact information of the emergency contact person.
* **emergency_contact_relationship** (Text): If applicable, please describe your relationship with the emergency contact person.

## Tips
* Please be as detailed as possible when filling out this form.
* If you have any questions or concerns, feel free to ask your salon or spa staff for assistance.
