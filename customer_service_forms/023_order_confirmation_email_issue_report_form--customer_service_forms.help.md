# order_confirmation_email_issue_report_form - Help Guide
## Purpose
The "order_confirmation_email_issue_report_form" is used to report issues with order confirmation emails sent to customers. This form helps support agents track and resolve problems with these emails.

## How To Complete This Form
To report an issue with an order confirmation email, follow these steps:

1. Enter the unique form ID (`form_id`) to associate the report with the correct order.
2. Describe the issue with the order confirmation email (`order_details`).
3. Enter the email address associated with the issue (`email_address`).
4. Explain the issue in detail (`email_issue_description`).
5. Provide the customer's name (`customer_name`).
6. Select the current status of the order (`order_status`).
7. Enter the email address of the support team member or agent who will follow up on the issue (`support_email`).
8. Choose the follow-up actions to take on the issue (`follow_up_action`).
9. Provide any additional follow-up details (`follow_up_details`, optional).
10. Enter any relevant notes or comments about the issue (`notes`).
11. Confirm who submitted the report (`submitted_by`).

## Field-by-Field Explanation

* **Form ID (`form_id`, required, number):** A unique identifier for the order.
* **Order Details (`order_details`, optional, text):** Describe the issue with the order confirmation email.
* **Email Address (`email_address`, required, email):** The email address associated with the issue.
* **Email Issue Description (`email_issue_description`, required, text):** Explain the issue in detail.
* **Customer Name (`customer_name`, required, text):** The customer's name.
* **Order Status (`order_status`, required, select_one):** Select the current status of the order.
* **Support Email (`support_email`, required, email):** Enter the email address of the support team member or agent who will follow up on the issue.
* **Follow-up Action (`follow_up_action`, required, select_multiple):** Choose the follow-up actions to take on the issue.
* **Follow-up Details (`follow_up_details`, optional, text):** Provide any additional follow-up details.
* **Notes (`notes`, required, note):** Enter any relevant notes or comments about the issue.
* **Submitted By (`submitted_by`, required, text):** Confirm who submitted the report.

## Tips
* Be as detailed as possible when describing the issue in the `email_issue_description` and `follow_up_details` fields.
* Ensure that you're not duplicating a previously reported issue.
* If the issue has already been resolved, please select "Closed" as the order status.
* If you have any further questions or concerns, please contact the support team.
