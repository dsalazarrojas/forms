# Close Out - Help Guide
## Purpose
This form is designed to collect information about the closure of customer service cases. The purpose of this form is to record the resolution and closure of customer service cases in a structured format, ensuring that all relevant details are captured and reviewed by supervisors.

## How To Complete This Form

1. **Customer Service Close-Out Form**: Fill out this form to document the resolution and closure of customer service cases. Ensure that the case has been fully resolved and closed before filling out this form.
2. **Case or Ticket Number**: Enter the case or ticket number for reference.
3. **Close-Out Date**: Select the date the case was closed.
4. **Close-Out Time**: Select the time the case was closed.
5. **Agent Name**: Enter the name of the agent handling the case.
6. **Agent ID**: Enter the ID of the agent handling the case.
7. **Customer Name**: Enter the customer's name.
8. **Customer ID**: Enter the customer's ID.
9. **Customer Contact Information**: Enter the customer's contact information (email or phone number).
10. **Issue Category**: Select the category of the issue (e.g. Product Inquiry, Technical Support, etc.).
11. **Original Issue Description**: Briefly summarize the original issue.
12. **Priority Level**: Select the priority level of the issue (e.g. Low, Medium, High, etc.).
13. **Date Case Opened**: Select the date the case was opened.
14. **Total Handling Time**: Enter the total time spent on handling the case.
15. **Number of Contacts**: Enter the number of times the customer was contacted.
16. **Contact Methods Used**: Select all applicable methods of contact used (e.g. phone, email, live chat, etc.).
17. **Resolution Status**: Select the status of the resolution (e.g. Fully Resolved, Partially Resolved, etc.).
18. **Resolution Description**: Describe how the issue was resolved.
19. **Root Cause**: Select the root cause of the issue (e.g. User Error, Product Defect, etc.).
20. **Actions Taken**: Select all applicable actions taken to resolve the issue (e.g. Troubleshooting, product replacement, etc.).
21. **Refund Amount**: If applicable, enter the amount refunded to the customer.
22. **Credit Issued**: Select if credit was issued to the customer.
23. **Credit Amount**: If credit was issued, enter the amount.
24. **Is Follow-Up Required**: Select if follow-up is required.
25. **Follow-Up Date**: If follow-up is required, select the date for follow-up.
26. **Reason for Follow-Up**: Describe the reason for follow-up (if applicable).
27. **Customer Satisfaction**: Select the customer's level of satisfaction (if collected).
28. **Customer Feedback**: Enter any comments from the customer.
29. **Was Escalation Required**: Select if escalation was required.
30. **Lessons Learned**: Enter any lessons learned from the case.
31. **Additional Case Notes**: Enter any other relevant information about the case.
32. **Agent Signature**: Type the agent's full name.
33. **Supervisor Review Required**: Select if supervisor review is required.

## Tips

* Ensure that the case has been fully resolved and closed before filling out this form.
* Fill out all required fields.
* Select the correct category and priority level for the issue.
* Use the correct contact methods and resolution status.
* Enter accurate and complete information about the case.
* Review the form before submitting to ensure accuracy and completeness.
* If escalation was required, ensure that it was properly documented.
* If follow-up is required, schedule it according to the follow-up date.
* Review the customer's level of satisfaction and provide feedback (if collected).
* Document any lessons learned from the case.
* Enter any other relevant information about the case in the "Additional Case Notes" field.
