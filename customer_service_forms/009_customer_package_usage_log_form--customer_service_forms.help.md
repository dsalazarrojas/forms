# prophets - Help Guide
## Purpose
The "prophets" form is designed to collect information from customers who are experiencing package-related issues. This form helps our customer service team gather the necessary details to assist the customer.

## How To Complete This Form

To complete this form, follow these steps:

* Ensure you have all the necessary details and information at hand before starting to fill out the form.
* Begin by providing your **Customer Name**, which should match the name of the person submitting this form.
* Next, provide the **Package ID**, if you have it available.
* Please select the date when the issue occurred.
* Enter the start time when the issue began.
* Enter the end time when the issue ended.
* If applicable, provide your **User ID** for reference.
* In the **Package Status** field, select all options that apply from the list of choices (Package Active, Package Suspended, Package Expired).
* Finally, provide a detailed description of the **Usage Details** of your issue.
* If you are submitting this form on behalf of the customer, provide the date you are submitting this form as the **Submission Date**.

## Field-by-Field Explanation

* **Customer Name**: The name of the person submitting this form, which should match the actual name of the customer.
* **Package ID**: A unique identifier for the package experiencing the issue, if available.
* **Date**: The date when the issue occurred.
* **Start Time**: The start time when the issue began.
* **End Time**: The end time when the issue ended.
* **User ID**: If you are a customer service representative, enter your own User ID for reference.
* **Package Status**: Select all options that apply from the list of package statuses to describe the state of the customer's package.
* **Usage Details**: A detailed description of the issue or usage details of the customer's package.
* **Submission Date**: If you are submitting this form on behalf of the customer, enter the date you are submitting this form as the submission date.
* **prophets**: Note: This field is not a typical label. Please provide detailed usage details of the customer's package, as it's currently labeled as "prophets" which is not a conventional field label.
