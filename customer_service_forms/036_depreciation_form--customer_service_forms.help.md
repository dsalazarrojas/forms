# Depreciation Form - Help Guide
## Purpose
The purpose of this form is to track and update asset values for depreciation purposes.

## How To Complete This Form
To complete this form, follow these steps:

1.  Choose the type of asset you are reporting from the list of options in the "Asset Type" field.
2.  Enter the name of the asset in the "Asset Name" field.
3.  Enter the current value of the asset in the "Asset Value" field.
4.  Select the date the asset was acquired from the calendar or manually input the date in the "Asset Date Acquired" field.
5.  Enter the depreciation rate as a percentage in the "Asset Depreciation Rate" field.
6.  Enter the number of years or months over which the depreciation is calculated in the "Asset Depreciation Period" field.
7.  Calculate the total depreciation value by multiplying the asset value by depreciation rate and depreciation period. The result should be input in the "Asset Depreciation Value" field.
8.  Finally, enter the asset's remaining value after depreciation in the "Asset Last Value" field.

## Field-by-Field Explanation

*   **Asset Type** (`select_multiple`, `Yes` or `No`): Choose whether the asset is a tangible or intangible asset.
    *   Select the correct option for your asset type.
*   **Asset Name** (`text`): A descriptive name for the asset.
    *   Enter a clear and concise name for the asset.
*   **Asset Value** (`number`): The current value of the asset.
    *   Enter the asset's current value.
*   **Asset Date Acquired** (`date`): The date the asset was acquired.
    *   Select the acquisition date from the calendar or manually input the date.
*   **Asset Depreciation Rate** (`number`): The rate at which the asset's value decreases over time.
    *   Enter the depreciation rate as a percentage.
*   **Asset Depreciation Period** (`number`): The number of years or months over which the depreciation is calculated.
    *   Enter the depreciation period in years or months.
*   **Asset Depreciation Value** (`number`): The total value of depreciation calculated based on asset value and depreciation rate.
    *   Calculate the depreciation value using the asset value and depreciation rate.
*   **Asset Last Value** (`number`): The asset's value after depreciation.
    *   Enter the asset's remaining value after depreciation.

## Tips
*   Double-check the asset type and depreciation rate to ensure accurate calculations.
*   Review the asset's history for any prior depreciation values.
*   Consult the asset's documentation or speak with the asset's owner if unsure about any field.
*   Ensure the asset's depreciation value is up-to-date and accurate.
