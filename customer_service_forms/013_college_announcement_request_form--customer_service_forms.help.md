# College Announcement Request Form - Help Guide
## Purpose

This form is used to submit a college event announcement to be published on the college website and other promotional materials.

## How To Complete This Form

To complete this form, please follow these steps:

1. Make sure you have the necessary permissions from your department or organization to submit an event.
2. Fill out your name, email address, and phone number as the requestor.
3. Provide the title and details of the event, including the date, start and end times, location, and event category.
4. Estimate the expected number of attendees and specify if the event is open to the general public or not.
5. Indicate if registration is required for the event and provide any registration link or process details.
6. Add any special requirements or considerations for the event.
7. Upload any promotional materials, such as event flyers or images.
8. Specify the announcement deadline for the event.

## Field-by-Field Explanation

* **Requester Name (1)**: Please enter your full name as the person submitting this event request.
* **Email Address (2)**: Enter your email address for contact purposes.
* **Phone Number (3)**: Provide your phone number.
* **Department or Organization (4)**: Specify the department or organization submitting this event request.
* **Event Title (5)**: Name of the event to be announced.
* **Event Date (6)**: Date of the event.
* **Event Start Time (7)**: The time the event will begin.
* **Event End Time (8)**: The time the event will end. (If left blank, the event will be assumed to end at the same time as the start time.)
* **Event Location (9)**: Where the event will take place.
* **Building or Room Number (10)**: The building or room number for the event location.
* **Event Category (11)**: Type of event (e.g., Academic, Sports, Cultural).
* **Event Description (12)**: Detailed description of the event.
* **Expected Attendance (13)**: Estimated number of attendees.
* **Is this event open to the general public? (14)**: Check if the event is open to everyone or not.
* **Registration Required (15)**: Indicate if registration is necessary for the event.
* **Registration Link or Process (16)**: Provide any registration link or process details.
* **Admission Cost (17)**: Price or fee for the event. (Leave blank if free.)
* **Event Contact Person (18)**: Name of the primary contact person.
* **Contact Email for Event (19)**: Email address of the primary contact person.
* **Event Flyer or Image Included (20)**: Upload any promotional materials for the event.
* **Announcement Deadline (21)**: Date by which the event should be announced.
* **Special Announcements or Requirements (22)**: Any special considerations for the event announcement.
