# Wish List Full Spring - Help Guide
## Purpose
The "wish_list_full_spring" form is used to create or edit a wish list for a specific spring product or event. It helps to gather relevant information such as catalog items and notes.

## How To Complete This Form
To complete the form, follow these steps:
1. Review the form sections and ensure you understand what information is being requested.
2. For the "Wish List Full Spring Catalog" field, select the relevant catalog items that apply to the wish list.
3. If necessary, add notes or comments using the "Note" field.
4. Enter any other required details, such as email and phone number, in their respective fields.

## Field-by-Field Explanation
* **Wish List Full Spring** (`id: 1`): Enter a brief title for the wish list.
* **Wish List Full Spring Catalog** (`id: 2`): Select one from the available options, e.g., "-.report -catalog -inventory" or "Other".
* **Wish List Full Spring Note** (`id: 3`): Enter any additional comments or descriptions about the wish list.
* **Wish List Full Spring Catalog Item 1** (`id: 4`): Select multiple items from the available options, e.g., "item 1", "item 2", "item 3".
* **Wish List Full Spring Catalog Item 2** (`id: 5`): Select multiple items from the available options, e.g., "item 1", "item 2", "item 3".
* **Wish List Full Spring Note 2** (`id: 6`): Enter any additional comments or descriptions about the wish list.
* **Wish List Full Spring Note 3** (`id: 7`): Enter any additional comments or descriptions about the wish list.
* **Wish List Full Spring Email** (`id: 8`): Enter a valid email address.
* **Wish List Full Spring Phone** (`id: 9`): Enter a valid phone number.
* **Wish List Full Spring Date** (`id: 10`): Choose a date that is relevant to the wish list.
* **Wish List Full Spring Time** (`id: 11`): Choose a time that is relevant to the wish list.

## Tips
* Be sure to review all fields carefully before submitting the form to ensure accuracy and completeness.
* If you're unsure about any field, refer back to this guide or contact your administrator for assistance.
* Double-check the form fields for any required information.
