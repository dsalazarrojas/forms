# customer_search_filter_form - Help Guide
## Purpose
The customer search filter form is designed to help customers quickly and easily search for specific information related to their searches. It allows them to filter their search results based on various criteria such as customer information and search criteria.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the desired search criteria from the "Search Criteria" field.
2. Choose how to filter the results using the "Filter By" dropdown menu.
3. Enter any additional information in the "Customer Information" field if necessary.
4. Select the date and time range for the search using the "Date" and "Time" fields if applicable.
5. Click the submit button to apply the filter and view the search results.

## Field-by-Field Explanation
* **Search Criteria** (`search_criteria`, `text`, optional): This field allows you to select the specific criteria you want to search for. You can choose from a variety of options such as product, location, or other relevant search criteria.
* **Filter By** (`filter_by`, `select_one`, required): This field allows you to choose how you want to filter the search results. Select from the available options such as by product, by location, or by other criteria.
* **Customer Information** (`customer_info`, `text`, optional): This field is where you can enter any additional information about the customer that may be relevant to your search.
* **Date** (`date`, `date`, optional): If you want to search by date, select the specific date range for the search.
* **Time** (`time`, `time`, optional): If you want to search by time, select the specific time range for the search.
* **Search Filter Form** (`search_filter_form`, `text`, optional): This field is not actually part of the form, but rather the label for the "Search Criteria" field. It's included here to provide context and clarity.

## Tips
* Make sure to select a valid search criteria and filter type to get accurate search results.
* Use the "Customer Information" field to provide any additional information that may be relevant to your search.
* Remember to select a valid date and time range if you're searching by these criteria.
