# Pre Install Agreement - Help Guide
## Purpose
This form is used to collect customer information and installation details before a new installation is done.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the customer's information in the "Customer" field. You can select either "Individual" or "Business".
2. Enter the customer's email address in the "Email" field.
3. Enter the install date in the "Install Date" field using the date format.
4. Enter the install time in the "Install Time" field using the time format.
5. Add any additional installation notes in the "Installation Notes" field.
6. Enter the customer's phone number in the "Phone Number" field.

## Field-by-Field Explanation
* **Customer Information** (`pre_install_agreement_form`, text, required/optional): This field is where you enter the customer's information. Please select "Individual" or "Business" from the dropdown menu to indicate the type of customer.
* **Customer** (`customer_details`, select_one, required/optional): This field lets you choose between "Individual" and "Business" for the type of customer.
* **Email** (`customer_email`, text, required/optional): Enter the customer's email address in this field.
* **Install Date** (`install_date`, date, required/optional): Enter the date of the installation in the desired format.
* **Install Time** (`install_time`, time, required/optional): Enter the time of the installation.
* **Installation Notes** (`installation_notes`, note, required/optional): Add any additional notes about the installation in this field.
* **Phone Number** (`phone_number`, text, required/optional): Enter the customer's phone number.
