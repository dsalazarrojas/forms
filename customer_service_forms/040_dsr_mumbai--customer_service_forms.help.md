# dsr_mumbai - Help Guide
## Purpose
The "dsr_mumbai" form is a tool for sales teams to collect sales-related data from customers or end-users. It's meant to gather information about sales periods, teams, persons involved, regions, dates, times, amounts, notes, emails, and phone numbers.

## How To Complete This Form
To complete this form correctly, please follow these steps:

1. Review the form instructions and make sure you understand the purpose and requirements of the form.
2. Ensure that you're only completing the form once per sales period to avoid duplication.
3. Fill in all relevant fields with accurate and complete information.
4. Double-check your input for any errors or missing fields.

## Field-by-Field Explanation

* **Sales Period**: Enter the sales period for the data you're providing. This field is a numerical input field.
* **Sales Team**: Select 'Yes' if you're filling out this form as part of a sales team, or 'No' if you're not. This field is a dropdown select option.
* **Sales Person**: Select all applicable sales persons involved in the sales process. This field is a multiple select option.
* **Sales Region**: Select 'Yes' if you're filling out this form for a specific sales region, or 'No' if you're not. This field is a dropdown select option.
* **Sales Date**: Enter the date for the sales event or process. This field is a date input field.
* **Sales Time**: Enter the time for the sales event or process. This field is a time input field.
* **Sales Amount**: Enter the amount involved in the sales process. This field is a numerical input field.
* **Sales Note**: Enter any additional comments or notes about the sales process. This field is a text input field for notes.
* **Sales Email**: Enter your contact email address. This field is an email input field.
* **Sales Phone**: Enter your contact phone number. This field is a text input field for phone numbers.

## Tips
* Make sure to provide accurate and complete information in all fields.
* If you're unsure about any field, please contact the sales team or relevant authority for clarification.
* Double-check your input for any errors or missing fields before submitting the form.
