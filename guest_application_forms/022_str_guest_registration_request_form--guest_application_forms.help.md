# str_guest_registration_request_form - Help Guide
## Purpose
The str_guest_registration_request_form is a crucial document for guests to provide their registration information. This guide will walk you through each field, ensuring that guests understand the purpose and requirements for a smooth registration process.

## How To Complete This Form
1. **Provide your name**: Enter your name in the text box labeled "guest_name".
2. **Scan ID copy**: Upload a copy of your ID for verification purposes.
3. **Enter ID number**: Enter your ID number in the number field.
4. **Agree to house rules**: Select "Yes" if you agree to the house rules.
5. **Provide contact information (optional)**: If you wish to provide your contact phone number or email address, you can do so in the corresponding fields.
6. **Review and agree to the terms (optional)**: If you wish to review and agree to the terms, you can do so in the note field.
7. **Upload ID (if necessary)**: If you have an ID that requires uploading, please select the type and provide the number and expiration date if applicable.
8. **Scan ID (if necessary)**: If you have an ID that requires scanning, please select the type and upload the scan.
9. **Submit the form**: Once you've completed all the required fields, click the "submit" button to complete the registration process.

## Field-by-Field Explanation

* **guest_name** (Text, Required): Enter your name for registration purposes.
* **id_scan_copy** (Text, Required): Upload a copy of your ID for verification.
* **id_number** (Number, Required): Enter your ID number.
* **agree_to_house_rules** (Select Multiple, Required): Select "Yes" if you agree to the house rules.
* **email** (Email, Optional): If you wish to provide your email address for contact purposes.
* **contact_phone** (Text, Optional): If you wish to provide your phone number for contact purposes.
* **agreement** (Note, Optional): Review and agree to the terms if you wish to do so.
* **agreement_date** (Date, Required): Enter the date you agreed to the terms.
* **agreement_time** (Time, Optional): Enter the time you agreed to the terms.
* **submit** (Text, Required): Click this button to complete the registration process.
* **upload_id** (Text, Optional): Upload your ID if required.
* **id_type** (Select One, Required): Select the type of ID you are uploading.
* **id_number** (Number, Optional): Enter the ID number if uploading an ID.
* **id_expire** (Select One, Optional): Select the expiration date type of your ID.
* **id_expire** (Date, Optional): Enter the expiration date of your ID.
* **id_scan** (Text, Optional): Upload a scan of your ID if required.
* **id_scan_type** (Select One, Required): Select the type of ID scan you are uploading.
* **terms** (Note, Optional): Review and agree to the terms if you wish to do so.
