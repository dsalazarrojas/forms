# Functional Strength Training Assessment Form - Help Guide
## Purpose
This form is designed to collect information about a client's fitness goals and training expectations.

## How To Complete This Form
1.  Select the relevant options for "Training Goals" by choosing one or more goals you want to achieve through training.
2.  Input your personal details in the "Client Info" text box.
3.  Describe your training expectations in the "Training Expectations" text box.
4.  Input any relevant personal data in the "Client Data" text box.
5.  Provide information about the specific training program you are interested in in the "Training Program" text box.
6.  Select a date for the assessment in the "Assessment Date" field.
7.  Select a time for the assessment in the "Assessment Time" field.

## Field-by-Field Explanation

*   **Client Info**: This is a text box where you can provide your personal details.
    *   This field is optional.
*   **Training Goals**: Select one or more goals you want to achieve through training.
    *   This field is optional.
*   **Training Expectations**: Describe your training expectations in this text box.
    *   This field is optional.
*   **Client Data**: Input any relevant personal data here.
    *   This field is optional.
*   **Training Program**: Provide information about the specific training program you are interested in.
    *   This field is optional.
*   **Assessment Date**: Select a date for the assessment using the standard date format (e.g., MM/DD/YYYY).
    *   This field is optional.
*   **Assessment Time**: Select a time for the assessment using the 24-hour clock format (e.g., HH:MM AM/PM).
    *   This field is optional.
