# EMT Field Training Checklist - Help Guide
## Purpose
The EMT Field Training Checklist is a tool used to record and track the completion of EMT field training sessions. It's intended to ensure that all necessary information is captured accurately and consistently, making it easier to evaluate and improve the effectiveness of training programs.

## How To Complete This Form
To fill out the EMT Field Training Checklist, follow these steps:

1. Enter relevant information about the training session, including the session's details (id 1: session_info).
2. Identify the training site where the session took place (id 2: training_site).
3. Provide the name of the trainer who led the session (id 3: trainer_name).
4. Select the EMT team(s) that attended the session (id 4: emt_team).
5. Record the duration of the session (id 5: session_duration) in minutes.
6. Enter the contact phone number of the participant or attendee (id 6: phone_number).
7. Add any notes or observations about the session (id 7: session_notes).
8. Mark the status of the session (id 8: session_status).
9. Confirm the session status (id 9: confirm_session_status).

## Field-by-Field Explanation
### id 1: session_info (Training Session Info)
* A text input field to provide details about the training session, such as date, time, and location.

### id 2: training_site (Training Site)
* A text input field to record the site where the training session occurred.

### id 3: trainer_name (Trainer Name)
* A text input field to enter the name of the trainer who conducted the session.

### id 4: emt_team (EMT Team)
* A multiple-select field to choose which EMT team attended the session. Select all relevant teams that attended.

### id 5: session_duration (Session Duration)
* A numeric input field to record the length of the session in minutes.

### id 6: phone_number (Phone Number)
* A text input field to enter the contact phone number of the participant or attendee.

### id 7: session_notes (Notes)
* A free-text input field for any additional comments or observations about the session.

### id 8: session_status (Session Status)
* A select-one field to mark the status of the session as either "Completed" or "Not Completed".

### id 9: confirm_session_status (Confirmation)
* A select-one field to confirm the status of the session as either "Completed" or "Not Completed".
