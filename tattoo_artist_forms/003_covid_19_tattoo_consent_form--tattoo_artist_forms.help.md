# COVID 19 Tattoo Consent Form - Help Guide
## Purpose
This form is designed to collect client information and provide a comprehensive understanding of the client's health, preferences, and consent for the tattoo procedure.

## How To Complete This Form
- Please fill out the form accurately and completely with your personal and demographic details.
- For medical history, select 'True' or 'False' for skin conditions, allergies, and blood thinners usage. 
- Select the correct answer for your COVID-19 and vaccination status.
- For tattoo details, select the desired location and size for the tattoo.
- Read through the consent and acknowledgment section carefully and select 'I agree' for each statement.

## Field-by-Field Explanation

* **Client Full Name (Client Full Name, Text, Required)**: Please fill out your full name as it appears on your government-issued ID.
* **Date of Birth (Client Date of Birth, Date, Required)**: Enter your date of birth in the required format (MM/DD/YYYY).
* **Email Address (Client Email, Email, Required)**: Enter your email address for communication purposes.
* **Phone Number (Client Phone, Text, Required)**: Enter your phone number for contact purposes.
* **-- Tattoo Details -- (Tattoo Section, Note, Optional)**: This is an open note section where you can add any details about the tattoo you want.
* **Location on Body (Tattoo Location, Select One, Required)**: Choose the location on your body where you want to place the tattoo.
* **Estimated Size (Tattoo Size, Select One, Required)**: Choose the size of the tattoo from the provided options (Small - 1-2 inches, Medium - 2-4 inches, Large - 4-6 inches, Extra large - 6+ inches).
* **Color Preference (Tattoo Color, Text, Optional)**: If you have a specific color preference for the tattoo, enter it here.
* **-- Health and Medical History -- (Health Section, Note, Optional)**: This is an open note section where you can add any medical history or health concerns.
* **Current COVID-19 Status (Current Covid Status, Select One, Required)**: Select 'Never had COVID-19', 'Recovered from COVID-19', 'Currently positive', or 'Unsure' for your current COVID-19 status.
* **Vaccination Status (Vaccination Status, Select One, Required)**: Select 'Fully vaccinated', 'Partially vaccinated', or 'Not vaccinated' for your vaccination status.
* **Do you have any skin conditions (Skin Conditions, Select One, Required)**: Select 'True' if you have any skin conditions, 'False' otherwise.
* **If yes, please describe (Skin Conditions Details, Text, Optional)**: If you have skin conditions, describe them briefly in this section.
* **Do you have any ink allergies (Allergies, Select One, Required)**: Select 'True' if you have any ink allergies, 'False' otherwise.
* **Are you taking blood thinners or anticoagulants (Blood Thinners, Select One, Required)**: Select 'True' if you are taking blood thinners or anticoagulants, 'False' otherwise.
* **Are you currently pregnant (Pregnancy, Select One, Required)**: Select 'True' if you are currently pregnant, 'False' otherwise.
* **-- Consent and Acknowledgment -- (Consent Section, Note, Optional)**: This is an open note section where you can add any consent or acknowledgment statement.
* **I understand and accept the risks associated with getting a tattoo (Consent Understand Risks, Select One, Required)**: Select 'I agree' if you understand and accept the risks associated with getting a tattoo.
* **I am aware of COVID-19 transmission risks in close-contact activities (Consent Covid Aware, Select One, Required)**: Select 'I agree' if you are aware of COVID-19 transmission risks in close-contact activities.
* **I agree to follow proper aftercare instructions (Consent Aftercare, Select One, Required)**: Select 'I agree' if you agree to follow proper aftercare instructions.
* **I release the tattoo artist and studio from liability (Consent Liability Waiver, Select One, Required)**: Select 'I agree' if you release the tattoo artist and studio from liability.
* **Client Signature or Digital Consent (Signature Acknowledge, Text, Required)**: By signing this form, you consent to the tattoo procedure. Please sign your name and date below.
* **Scheduled Appointment Date (Appointment Date, Date, Optional)**: This is where you can select the date and time for your scheduled appointment.
