# interior_design_project_consultation_form - Help Guide
## Purpose
The interior design project consultation form helps gather and record essential project details for consultation and project management purposes.

## How To Complete This Form
To complete this form, follow these steps:

* Fill out the project name and description.
* Provide the client's name and contact information, including their email and phone number.
* Select the project status (In progress, On hold, or Completed).
* Choose the project type (Residential, Commercial, or Industrial).
* Input the project start and deadline dates.
* Enter the project address and manager's contact information.
* Finally, input the project budget.

## Field-by-Field Explanation
* **Project name**: <project_name> (<name>, <text>, required/optional): Enter the name of the project.
* **Project description**: <project_description> (<name>, <text>, required/optional): Briefly describe the project in a few sentences.
* **Client name**: <client_name> (<name>, <text>, required/optional): Enter the client's name.
* **Client email**: <client_email> (<name>, <email>, required/optional): Enter the client's email address.
* **Client phone**: <client_phone> (<name>, <text>, required/optional): Enter the client's phone number.
* **Project status**: <project_status> (<name>, <select_one>, required/optional): Select the project status (In progress, On hold, or Completed).
* **Project type**: <project_type> (<name>, <select_one>, required/optional): Choose the project type (Residential, Commercial, or Industrial).
* **Project start date**: <project_start_date> (<name>, <date>, required/optional): Enter the project start date.
* **Project deadline**: <project_deadline> (<name>, <date>, required/optional): Enter the project deadline.
* **Project address**: <project_address> (<name>, <text>, required/optional): Enter the project address.
* **Project manager**: <project_manager> (<name>, <text>, required/optional): Enter the project manager's name.
* **Project manager email**: <project_manager_email> (<name>, <email>, required/optional): Enter the project manager's email address.
* **Project budget**: <project_budget> (<name>, <number>, required/optional): Enter the project budget.
