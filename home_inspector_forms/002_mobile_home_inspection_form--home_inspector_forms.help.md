# Mobile Home Inspection Form - Help Guide
## Purpose
The mobile home inspection form is designed to collect information about a mobile home's address, type, size, and other relevant details to facilitate a thorough and accurate inspection process.

## How To Complete This Form
1. Begin by entering the mobile home's address in the "Mobile Home Address" field.
2. Select the type of mobile home by choosing from the available options in the "Mobile Home Type" field.
3. Enter the mobile home's square footage, number of beds, and number of baths in the respective fields.
4. Choose the type of heat used in the mobile home by selecting from the available options in the "Mobile Home Type of Heat" field.
5. Select the type of walls used in the mobile home by choosing from the available options in the "Mobile Home Walls" field.
6. Enter any additional comments or notes in the "Mobile Home Comments" field.
7. Add any relevant pictures or videos of the mobile home, if applicable.
8. Enter the date of the inspection in the "Mobile Home Inspection Date" field.
9. Enter the price of the mobile home, if applicable.
10. Enter a description of the mobile home's lot condition in the "Mobile Home Lot Condition" field.
11. Enter any notes or observations about the mobile home's condition in the "Mobile Home Notes" field.

## Field-by-Field Explanation

* **Mobile Home Address**: Enter the address of the mobile home being inspected.
* **Mobile Home Type**: Choose the type of mobile home, which can be Manufactured, Traditional, Modular, Panel, Double Wide, Single Wide, Townhouse, Multi Family, Duplex, or Other.
* **Mobile Home Sqft**: Enter the square footage of the mobile home.
* **Mobile Home Beds**: Enter the number of beds in the mobile home.
* **Mobile Home Baths**: Enter the number of baths in the mobile home.
* **Mobile Home Sqft Living**: Enter the living square footage of the mobile home.
* **Mobile Home Lot Size**: Enter the size of the mobile home's lot, if applicable.
* **Mobile Home Year Built**: Enter the year the mobile home was built.
* **Mobile Home Type of Heat**: Choose the type of heat used in the mobile home, which can be Electric, Gas, Propane, Oil, Heat Pump, Solar, or Other.
* **Mobile Home Walls**: Choose the type of walls used in the mobile home, which can be Brick, Vinyl, Stucco, Aluminum, Wood, or Other.
* **Mobile Home Comments**: Enter any additional comments or observations about the mobile home.
* **Mobile Home Pictures**: Add any relevant pictures of the mobile home, if applicable.
* **Mobile Home Video**: Add any relevant videos of the mobile home, if applicable.
* **Mobile Home Documents**: Add any relevant documents related to the mobile home, if applicable.
* **Mobile Home Inspector**: Choose the inspector's name, which can be Mobile Home Inspector 1, Mobile Home Inspector 2, Mobile Home Inspector 3, or Other.
* **Mobile Home Inspection Date**: Enter the date of the inspection.
* **Mobile Home Price**: Enter the price of the mobile home, if applicable.
* **Mobile Home Lot Condition**: Enter a description of the mobile home's lot condition, which can be Excellent, Good, Fair, Poor, or Other.
* **Mobile Home Notes**: Enter any notes or observations about the mobile home's condition.
* **Mobile Home Inspection Report**: Enter any additional comments or notes about the inspection process or findings.
* **Mobile Home Ugly**: Enter any additional notes or comments about the mobile home's condition, if applicable.
* **Mobile Home Lot Condition**: This field is not used.
