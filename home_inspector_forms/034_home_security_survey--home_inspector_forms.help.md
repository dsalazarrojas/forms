# Home Security Survey - Help Guide
## Purpose
This form is used to conduct a thorough home security survey. The survey aims to assess the presence of security risks in a home and determine if there are any security measures in place to mitigate them.

## How To Complete This Form
Please follow these steps to complete the form:

1. Start by filling out the **Client Information** field with the client's details.
2. In the **Security Risks** section, select all the security risks that are present in the home.
3. In the **Security Measures** section, indicate if there are any security measures in place to prevent security risks.
4. Add any comments or suggestions for improvement in the **Comments** field.
5. Select the **Assigned Tool** used for the inspection.
6. Finally, add your **Client Signature** and **Inspector Signature** to confirm that the form has been completed and reviewed.

## Field-by-Field Explanation
* **Introduction**: This is a brief note section where you can provide an introduction to the survey.
* **Client Information**: Please fill out this field with the client's name, address, and contact information.
* **Security Risks**: Select all the security risks that are present in the home. These options are:
	+ Are there any security risks present in the home?
* **Vulnerable Areas**: Describe the areas in the home that are vulnerable to security risks.
* **Security Measures**: Indicate if there are any security measures in place to prevent security risks. These options are:
	+ Are there any security measures in place to prevent security risks?
	+ True
	+ False
* **Comments**: Add any comments or suggestions for improvement.
* **Assigned Tool**: Select the tool or equipment used for the inspection.
* **Client Signature**: Please add your client's signature to confirm that they have reviewed the form.
* **Inspector Signature**: Add your signature as the home inspector to confirm that you have completed the form and reviewed the results.
* **Date of Inspection**: Please select the date of the inspection using the date format (YYYY-MM-DD).
