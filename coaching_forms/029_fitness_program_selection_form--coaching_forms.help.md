# Fitness Program Selection Form - Help Guide
## Purpose
The purpose of this form is to collect fitness program information and selections from clients and trainers. It is used to ensure that trainers can provide a tailored and effective program for each client based on their requirements.

## How To Complete This Form
1. Select the trainer and client you want to complete the form for.
2. Complete the client's details, including phone number and email.
3. Choose the program selection options that best fit the client's needs.
4. Enter the review date and time, if applicable.
5. Complete any additional review notes, if applicable.

## Field-by-Field Explanation

* **Program Selection**: Select one or multiple programs that best fit the client's needs.
* **Client Details**: Enter the client's details, including their phone number and email.
* **Trainer Selection**: Select the trainer who will be working with the client.
* **Gym Selection**: Select the gym where the client will be working out.
* **Review Notes**: Enter any additional notes for the review, if applicable.
* **Date**: Enter the date of the review, if applicable.
* **Time**: Enter the time of the review, if applicable.
* **Phone Number**: Enter the client's phone number.
* **Email**: Enter the client's email.
* **Notes**: Enter any additional notes about the client or program, if applicable.
* **Review Status**: Select the status of the review (Active or Inactive).
* **Review Date**: Enter the date of the review, if applicable.
* **Review Time**: Enter the time of the review, if applicable.
* **Review Notes 2**: Enter any additional review notes, if applicable.
* **Review Notes 3**: Enter any additional review notes, if applicable.
* **Trainer Name**: Enter the trainer's name.
* **Trainer Email**: Enter the trainer's email.
* **Trainer Phone**: Enter the trainer's phone number.
* **Notes**: Enter any additional notes about the client or program, if applicable.
