# Employee Coaching Form - Help Guide
## Purpose
This form is for internal coaching activities to collect information about employee coaching, goals, coaching dates, coaching methods, and next steps.

## How To Complete This Form

To complete this form, follow the instructions below:

1. Fill in the required and optional fields as instructed.
2. Make sure to select the correct coaching dates from the available options.
3. Choose the coaching method that best suits the employee's needs.
4. Add any additional notes or next steps in the designated fields.

## Field-by-Field Explanation

* **Employee Coaching Form**: This is the title of the form.
* **Goals** (`employee_coaching_form`, number, not required): This field is used to input the employee's goals.
* **Goals Description** (`goals_description`, text, not required): This field is for describing the goals in more detail.
* **Coaching Dates** (`coaching_dates`, select multiple, not required): Select the coaching dates from the available options. This field is used to input multiple dates for coaching sessions.
* **Coaching Time** (`coaching_time`, time, not required): This field is used to input the coaching time.
* **Coaching Location** (`coaching_location`, text, not required): This field is for inputting the coaching location.
* **Coaching Method** (`coaching_method`, select one, not required): This field is used to select the coaching method (phone, video, or email).
* **Next Steps** (`next_steps`, text, not required): This field is for inputting the next steps or actions to be taken.
* **Notes** (`notes`, note, not required): This field is for adding any additional notes about the coaching session.
* **Employee** (`employee_id`, number, not required): This field is for inputting the employee's ID.
* **Employee** (not to be confused with above, this is likely for linking to another employee form): This field is for inputting the employee's ID.
*   The coaching method field should be used to select how the employee wants to receive coaching, such as phone or video calls.
*   The coaching dates field should be used to input the dates of the coaching sessions.
*   The coaching time field should be used to input the time of the coaching sessions.
*   The coaching location field should be used to input the location of the coaching sessions.
*   The next steps field should be used to input any additional actions or steps to be taken after the coaching session.
*   The notes field is for adding any additional comments or notes about the coaching session.
*   The employee field should be used to input the employee's ID.

## Tips

*   Please make sure to input accurate and relevant information in the form.
*   Ensure the coaching method, dates, time, location, next steps, and notes are inputted correctly.
*   If you are unsure about any of the fields, please reach out to the coach or HR team for assistance.
