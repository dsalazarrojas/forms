# Coaching Client Agreement Form - Help Guide
## Purpose
This form is used to document the agreement between you and your client, including coaching services, payment terms, and confidentiality. It is essential to review the form carefully and ensure that it accurately reflects the agreed-upon terms between you and your client.

## How To Complete This Form

1. Fill out the form accurately and thoroughly, including all required fields.
2. Ensure that you understand the terms and conditions outlined in the form.
3. Review each field carefully and select the correct options.

## Field-by-Field Explanation
* **Coach Full Name** (`1`, `text`, required): This is the legal name of the coach.
* **Coach Email** (`2`, `email`, required): This is the contact email of the coach.
* **Coach Phone** (`3`, `text`, required): This is the contact phone number of the coach.
* **Coaching Business Name** (`4`, `text`, optional): This is the name of the coaching practice.
* **Client Full Name** (`5`, `text`, required): This is the legal name of the client.
* **Client Email** (`6`, `email`, required): This is the contact email of the client.
* **Client Phone** (`7`, `text`, required): This is the contact phone number of the client.
* **Client Address** (`8`, `text`, optional): This is the client's mailing address.
* **Agreement Effective Date** (`9`, `date`, required): This is the date when the agreement starts.
* **Coaching Services Description** (`10`, `text`, required): This is a description of the coaching services provided.
* **Session Package** (`11`, `select_one`, required): Select one of the following session packages:
	+ Single Session
	+ 3 Session Package
	+ 6 Session Package
	+ 12 Session Package
	+ Monthly Package
	+ Custom Arrangement
* **Session Length** (`12`, `select_one`, required): Select one of the following session lengths:
	+ 30 Minutes
	+ 45 Minutes
	+ 60 Minutes
	+ 90 Minutes
	+ 120 Minutes
* **Session Delivery Method** (`13`, `select_one`, required): Select one of the following session delivery methods:
	+ In Person
	+ Video Call
	+ Phone Call
	+ Hybrid
* **Total Investment** (`14`, `select_one`, required): Select one of the following total investments:
	+ Under $500
	+ $500-$1000
	+ $1001-$2500
	+ $2501-$5000
	+ Over $5000
* **Payment Terms** (`15`, `select_one`, required): Select one of the following payment terms:
	+ Full Payment in Advance
	+ 50 Percent Deposit Required
	+ Pay Per Session
	+ Monthly Installments
* **Client Coaching Goals** (`16`, `text`, required): Describe the client's coaching goals.
* **Client Commitments** (`17`, `text`, required): Describe the client's commitments.
* **Coach Commitments** (`18`, `text`, required): Describe the coach's commitments.
* **Cancellation Policy Terms** (`19`, `select_one`, required): Select one of the following:
	+ Yes I Understand
	+ No I Need Review
* **Cancellation Notice Period** (`20`, `select_one`, required): Select one of the following:
	+ 12 Hours
	+ 24 Hours
	+ 48 Hours
	+ 72 Hours
* **Late Cancellation Fee** (`21`, `select_one`, required): Select one of the following:
	+ Yes I Understand
	+ 'False'
* **Rescheduling Policy** (`22`, `select_one`, required): Select one of the following:
	+ Yes I Understand
	+ No I Need Review
* **Confidentiality Terms Accepted** (`23`, `select_one`, required): Select one of the following:
	+ Yes I Accept
	+ 'False'
* **Liability Limitations Understood** (`24`, `select_one`, required): Select one of the following:
	+ Yes I Understand
	+ No I Need Clarification
* **Medical Disclaimer Acknowledged** (`25`, `select_one`, required): Select one of the following:
	+ Yes I Acknowledge
	+ 'False'
* **Results Disclaimer Acknowledged** (`26`, `select_one`, required): Select one of the following:
	+ Yes I Acknowledge
	+ 'False'
* **Communication Between Sessions** (`27`, `select_one`, required): Select one of the following:
	+ Email Only
	+ Phone Only
	+ Email and Phone
	+ Scheduled Calls Only
	+ Emergency Only
* **Homework or Assignments Expected** (`28`, `select_one`, optional): Select one of the following:
	+ Yes I Expect Assignments
	+ No Assignments
	+ Optional Assignments
* **Termination Policy Understood** (`29`, `select_one`, required): Select one of the following:
	+ Yes I Understand
	+ No I Need Review
* **I Agree to All Terms and Conditions** (`30`, `select_one`, required): Select one of the following:
	+ Yes I Agree
	+ 'False'
* **Coach Agrees to All Terms** (`31`, `select_one`, required): Select one of the following:
	+ Yes I Agree
	+ 'False'
* **Date of Agreement** (`32`, `date`, required): This is the date when the agreement is signed.

## Tips
* Ensure that the form is completed accurately and thoroughly.
* Review each field carefully to avoid errors.
* Discuss any questions or concerns with the coach before signing the agreement.
