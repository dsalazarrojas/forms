# Manager Feedback Coaching Registration Form - Help Guide
## Purpose
The Manager Feedback Coaching Registration Form is used to collect information from managers on their coaching preferences.

## How To Complete This Form
To complete this form, follow these steps:
1. Fill out the form completely and accurately with your information.
2. Choose the relevant options for your coaching preferences.

## Field-by-Field Explanation

* **First Name** (`first_name`, text, required): Enter your first name.
* **Email** (`email`, email, optional): Enter your email address. This will be used to contact you.
* **Phone** (`phone`, text, optional): Enter your phone number. This will be used to contact you.
* **What would you like to do?** (`select_one_manager_feedback`, select_one, optional): Choose one of the options:
	+ Manager 1
	+ Manager 2
	+ Manager 3
* **Select multiple managers** (`select_multiple_managers`, select_multiple, optional): Select multiple managers from the options:
	+ Manager 1
	+ Manager 2
	+ Manager 3
* **Note to self** (`note`, note, optional): Enter any additional comments or notes about your coaching preferences.
* **Date** (`date`, date, optional): Select the date of the coaching session.
* **Time** (`time`, time, optional): Select the time of the coaching session.
* **Coaching type** (`select_one_coaching_type`, select_one, optional): Choose one of the options:
	+ Type 1
	+ Type 2
	+ Type 3
* **Select multiple coaching types** (`select_multiple_coaching_types`, select_multiple, optional): Select multiple coaching types from the options:
	+ Type 1
	+ Type 2
	+ Type 3

## Tips
* Make sure to fill out the form completely and accurately.
* Check the "Select multiple managers" and "Select multiple coaching types" fields for multiple selections.
