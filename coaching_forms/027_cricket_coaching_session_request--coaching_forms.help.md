# cricket_coaching_session_request - Help Guide
## Purpose
The cricket coaching session request form is designed to gather necessary information about the coaching session. This includes details about the participant, coaching session, and coach's experience. The form ensures accuracy and prevents duplicate entries by checking for participant and coaching session details.

## How To Complete This Form
To complete this form, please follow these steps:
1. Enter the participant's first name and last name in the respective fields.
2. Provide the participant's email and confirm it for verification purposes.
3. Enter the participant's phone number.
4. Specify the participant's details.
5. Choose whether the coaching session is available or not.
6. Select the coaching level.
7. Set the session date and time.
8. Specify the session duration.
9. Enter the coaching session details.
10. Set the coaching fee.
11. Choose whether the coaching fee is frequent or one-time.
12. Enter the participant's age.
13. Select the participant's gender.
14. Select the participant's grade.
15. Enter the participant's school.
16. Enter the participant's coach's name.
17. Describe the participant's coach's experience.
18. List the coach's qualifications.
19. Enter any session notes.
20. Provide the participant's agreement.
21. Provide the coach's agreement.

## Field-by-Field Explanation
- **First name** (1, Text, Required): Enter the participant's first name.
- **Last name** (2, Text, Required): Enter the participant's last name.
- **Email** (3, Email, Required): Enter the participant's email address.
- **Confirm Email** (4, Email, Required): Confirm the participant's email address for verification purposes.
- **Phone** (5, Text, Required): Enter the participant's phone number.
- **Participant details** (6, Text, Required): Enter any relevant details about the participant.
- **Coaching type** (7, Select One, Required): Choose whether the coaching session is available or not.
- **Coaching level** (8, Select One, Required): Select the coaching level required.
- **Session date** (9, Date, Required): Set the coaching session date.
- **Session time** (10, Time, Required): Set the coaching session time.
- **Session duration** (11, Number, Required): Specify the coaching session duration in minutes or hours.
- **Session details** (12, Text, Required): Enter any additional details about the coaching session.
- **Coaching fee** (13, Number, Required): Set the coaching fee.
- **Coaching fee frequency** (14, Select One, Required): Choose whether the coaching fee is frequent or one-time.
- **Participant age** (15, Number, Required): Enter the participant's age.
- **Participant gender** (16, Select One, Required): Select the participant's gender.
- **Participant grade** (17, Select One, Required): Select the participant's grade.
- **Participant school** (18, Text, Required): Enter the participant's school.
- **Participant coach** (19, Text, Required): Enter the coach's name.
- **Coach name** (20, Text, Required): Enter the coach's name.
- **Coach experience** (21, Text, Required): Describe the coach's experience.
- **Coach qualifications** (22, Text, Required): List the coach's qualifications.
- **Session notes** (23, Text, Required): Enter any session notes.
- **Participant agreement** (24, Text, Required): Provide the participant's agreement.
- **Coaching agreement** (25, Text, Required): Provide the coach's agreement.
