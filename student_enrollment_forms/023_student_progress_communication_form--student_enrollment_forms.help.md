# Student Progress Communication Form - Help Guide

## Purpose
The Student Progress Communication Form is used to collect and document student's progress, providing a structured and organized way to communicate updates and observations about students' performance, behavior, and overall well-being.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the student's progress status from the dropdown menu.
2. Enter the student's name in the text field.
3. Choose the date and time of the visit using the date and time input fields.
4. Add any comments or observations from the educator in the note field.
5. Enter the parent's email address.
6. Enter the parent's phone number.
7. Rate the student's performance as Good or Fair.
8. Add any comments or feedback from the parent in the note field.

## Field-by-Field Explanation

* **Student Progress** (`select_multiple`, required: false): This field allows you to select the student's progress status from the dropdown menu. Please choose 'Yes' if the student is making progress, or 'No' if not.
* **Student Name** (`text`, required: false): Enter the student's name in this field.
* **Date of Visit** (`date`, required: false): Choose the date of the visit using the date input field.
* **Time of Visit** (`time`, required: false): Choose the time of the visit using the time input field.
* **Educator Comments** (`note`, required: false): Add any comments or observations from the educator about the student's progress in this field.
* **Email** (`email`, required: false): Enter the parent's email address so they can be notified of any updates or concerns.
* **Parent Phone** (`text`, required: false): Enter the parent's phone number so they can be contacted with updates or concerns.
* **Student Performance Rating** (`select_one`, required: false): Rate the student's performance as Good or Fair.
* **Parent Comments** (`note`, required: false): Add any comments or feedback from the parent about the student's progress in this field.

## Tips
Please make sure to fill out this form accurately and thoroughly, as it will help ensure that students' progress is properly documented and communicated with parents.
