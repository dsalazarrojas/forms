# OPRF Enrollment Form - Help Guide
## Purpose
The OPRF Enrollment Form is used to collect student demographic data, including school name, student name, parent name, contact information, and academic details. This form helps the system to create a student profile and assigns them to the correct program or school.

## How To Complete This Form
1. Fill out all required fields (indicated by *).
2. Choose the correct grade level and school year from the dropdown menus.
3. Enter your school name, student name, parent name, email, student phone number, and student email address in the designated text fields.
4. Select the program name if applicable.

## Field-by-Field Explanation

### School Name
* **School Name** (Text): Enter the name of the school where the student is currently attending or interested in attending.

### Grade Level
* **Grade Level** (Select): Select the student's current grade level.
 
 ### School Year
* **School Year** (Select): Select the student's current school year.

### Student Name
* **Student Name** (Text): Enter the student's name.

### Parent Name
* **Parent Name** (Text): Enter the parent's name.

### Email
* **Email** (Email): Enter the student's email address.

### Student Phone
* **Student Phone** (Text): Enter the student's phone number.

### Student Email
* **Student Email** (Email): Enter the student's email address.

### Program Name
* **Program Name** (Text): Select the program the student is interested in or currently enrolled in.

Note: Please make sure to fill out the form accurately and completely to ensure the correct student profile is created.
