# Independent Learning Program Registration - Help Guide
## Purpose
The "Independent Learning Program Registration" form is designed to collect essential information from students participating in the independent learning program. This form gathers data to ensure a seamless experience for both students and program administrators.

## How To Complete This Form
1. Please select the appropriate "Program Type" from the available options (Online or On-campus).
2. Enter your "Start Date" and "End Date" if applicable, using the correct date format (DD/MM/YYYY or MM/DD/YYYY).
3. Provide details about the program in the "Program Details" text field.
4. Select "Program Location" based on the offered options (Yes or No).
5. Enter your "Contact Email" address, which should follow the example format provided (example@example.com).
6. Fill in your "Contact Phone" number, following the expected format.
7. Enter your "Student Name" in the text field.
8. Select your "Enrollment Status" from the available options (Active or Inactive).

## Field-by-Field Explanation
* **Program Type**: Select the type of program you are registering for. Choose from "Online" or "On-campus" to indicate the type of educational setting.
* **Start Date**: The date from which the program starts. Enter a valid date using the DD/MM/YYYY or MM/DD/YYYY format.
* **End Date**: The date when the program ends. Leave this field blank if you don't have an end date. Enter a valid date using the DD/MM/YYYY or MM/DD/YYYY format.
* **Program Details**: Enter a detailed description of the program in which you are enrolled.
* **Program Location**: Specify whether the program is offered online or not. Choose "Yes" if it's an online program or "No" otherwise.
* **Contact Email**: Enter your email address for contact purposes. Follow the format example@example.com for correct input.
* **Contact Phone**: Enter your phone number. This field is for contact purposes.
* **Student Name**: Enter your name as it should be displayed on your student records.
* **Enrollment Status**: Select whether you are actively enrolled or not enrolled in the program. Choose from "Active" or "Inactive" based on your current status.
