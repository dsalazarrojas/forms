# Change Management Report Form - Help Guide
## Purpose
The Change Management Report Form is used to document and track the status of change requests within your organization. This form helps to ensure that changes are properly documented, tracked, and closed.

## How To Complete This Form

To complete this form, follow these steps:

* Fill out the report date to indicate when the report was completed.
* Enter the Change Request ID to associate the report with the correct change.
* Provide a title for the change.
* Describe the change and its objectives.
* Select the type of report (Implementation Report, Post-Implementation Review, Change Status Update, or Change Closure Report).
* Select the current implementation status (Scheduled, In Progress, Completed, Delayed, On Hold, Cancelled).
* If applicable, enter the actual implementation date.
* If applicable, provide a comparison between planned and actual implementation.
* If applicable, enter the percentage of completion.
* If applicable, describe any scope changes.
* If applicable, describe any issues encountered.
* If applicable, describe how issues were resolved.
* Select whether success metrics were met (All Met, Mostly Met, Partially Met, Not Met).
* Provide feedback from stakeholders.
* If applicable, enter the level of resistance encountered.
* If applicable, enter the budget status (On Budget, Under Budget, Over Budget, Not Tracked).
* If applicable, enter the budget variance amount.
* If applicable, rate the performance of resources.
* Summarize key lessons learned from the change.
* Provide recommendations for future changes.
* List any follow-up actions required.
* Select the final status of the change (Closed, Pending Closure, Reopened, On Hold).

## Field-by-Field Explanation
* **Report Date**: Enter the date this report was completed.
* **Change Request ID**: Enter the ID of the change request.
* **Change Title**: Enter a brief title for the change.
* **Change Description**: Describe the change and its objectives.
* **Report Type**: Select the type of report (Implementation Report, Post-Implementation Review, Change Status Update, or Change Closure Report).
* **Implementation Status**: Select the current implementation status (Scheduled, In Progress, Completed, Delayed, On Hold, Cancelled).
* **Actual Implementation Date**: If applicable, enter the date the change was actually implemented.
* **Comparison - Planned vs Actual**: If applicable, provide a comparison between planned and actual implementation.
* **Percentage Complete**: If applicable, enter the percentage of completion.
* **Changes to Scope**: If applicable, describe any scope changes made.
* **Issues or Problems Encountered**: If applicable, describe any issues or problems encountered.
* **How Issues Were Resolved**: If applicable, describe how issues were resolved.
* **Success Metrics Achievement**: Select whether success metrics were met (All Met, Mostly Met, Partially Met, Not Met).
* **Stakeholder Feedback**: Provide feedback from stakeholders.
* **Level of Resistance Encountered**: If applicable, enter the level of resistance encountered.
* **Budget Status**: If applicable, enter the budget status (On Budget, Under Budget, Over Budget, Not Tracked).
* **Budget Variance**: If applicable, enter the budget variance amount.
* **Resource Performance**: If applicable, rate the performance of resources.
* **Lessons Learned**: Summarize key lessons learned from the change.
* **Recommendations for Future Changes**: Provide recommendations for future changes.
* **Follow-up Actions**: If applicable, list any follow-up actions required.
* **Change Request Closure Status**: Select the final status of the change (Closed, Pending Closure, Reopened, On Hold).
