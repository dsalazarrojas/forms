# Field Change Order Form - Help Guide
## Purpose
The Field Change Order Form is used to request changes to fields. It is a formal process to ensure that all changes are documented and reviewed.

## How To Complete This Form
To complete this form, follow these steps:

1.  Enter the field ID of the field you wish to change.
2.  Provide a valid reason for the change.
3.  Enter any additional notes about the change.
4.  Select the submitter (person or people) who is submitting the change order.
5.  Optionally, specify other individuals who are involved in the change order.
6.  Choose the goal of the change order.
7.  If applicable, provide a specific email address to contact.
8.  Enter your contact phone number.
9.  Add any additional comments about the change order.

## Field-by-Field Explanation
* **Field ID** (Field ID, number, **required**): Enter the number of the field you wish to change.
* **Field Name** (Field Name, text, not required): Enter a brief description of the field being changed.
* **Reason** (Reason, text, **required**): Enter a detailed explanation for the change.
* **Notes** (Notes, note, not required): Add any additional comments about the change.
* **Submitter** (Submitter, select multiple, not required): Select the individual or group submitting the change order.
* **Other Submitters** (Other Submitters, text, **required**): If there are multiple individuals involved in the change order, enter their names here.
* **Goal** (Goal, select one, not required): Select the purpose of the change order.
* **Goal Other** (Goal Other, text, **required**): If the goal is not listed, enter the purpose of the change.
* **Submitter Department** (Submitter Department, select one, not required): If applicable, select the department responsible for the change order.
* **Other Submitter Department** (Other Submitter Department, text, **required**): If there are multiple departments involved, enter their names here.
* **Field Change Order Date** (Field Change Order Date, date, not required): Enter the date when the change order was placed.
* **Field Change Order Time** (Field Change Order Time, time, not required): Enter the time when the change order was placed.
* **Field Change Order Email** (Field Change Order Email, email, not required): Enter an email address to contact the submitter.
* **Field Change Order Phone** (Field Change Order Phone, text, not required): Enter the submitter's phone number.
* **Field Change Order Note** (Field Change Order Note, note, not required): Add any additional comments about the change order.
