# Work Change Order Form - Help Guide
## Purpose
The Work Change Order Form is used to request changes to work orders. This form captures the essential information required to process the change order, including the type of change, description, and estimate.

## How To Complete This Form
1. Click on the "Submit Form" button once you have completed all the required fields.
2. Ensure you fill out each field as instructed below.

## Field-by-Field Explanation

* **General Information** (`general_information`, `text`, optional):
    This field is used to enter a brief description of the general information related to the change order.
* **Change Description** (`change_description`, `text`, optional):
    This field is used to enter a detailed description of the change.
* **Change Type** (`change_type`, `select_one`, optional, options: `new`, `modify`, `cancel`, `delete`):
    This field allows you to select the type of change (new, modify, cancel, or delete).
* **Change Date** (`change_date`, `date`, optional):
    This field is used to enter the date of the change.
* **Change By** (`change_by`, `time`, optional):
    This field is used to enter the time of the change.
* **Description** (`change_description_details`, `text`, optional):
    This field is used to enter a detailed description of the change.
* **Change Order Number** (`change_order_number`, `number`, optional):
    This field is used to enter the change order number.
* **Original Estimate** (`original_estimate`, `number`, optional):
    This field is used to enter the original estimate.
* **Change Estimate** (`change_estimate`, `number`, optional):
    This field is used to enter the new change estimate.
* **Change Reason** (`change_reason`, `text`, optional):
    This field is used to enter a brief description of the reason for the change.

## Tips
* Make sure to fill out each field carefully and accurately, as the information provided will be used to process your change order.
* Ensure you select the correct change type (new, modify, cancel, or delete) to accurately reflect the nature of the change.
* If you are unsure about any of the fields, please contact the relevant team members for assistance.
* Before submitting the form, please review all fields to ensure accuracy and completeness.
