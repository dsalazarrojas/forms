# Subscription Amendment Form - Help Guide
## Purpose
The Subscription Amendment Form is used to make changes to an existing subscription. This form allows you to update the customer's information, such as their name and email, and confirm the changes before applying them.

## How To Complete This Form

1. Enter the **Customer ID** of the subscription you want to amend. This is a unique identifier for the customer and is required to select the correct subscription.
2. If you are making changes to the customer's information, enter their **New Name** and **New Email**.
3. If you are making changes to the customer's information, provide a brief **Reason for Amendment** explaining the changes you are making.
4. Enter the customer's **Current Email** to confirm that the changes will be applied correctly.
5. Confirm the changes by selecting **Yes** from the **Confirm** field.
6. Optionally, select **Yes** from the **Submit 2** field to cancel the changes.

## Field-by-Field Explanation

* **Customer ID** (1): Enter the customer ID of the subscription you want to amend.
* **New Name** (2): Enter the customer's new name if you are making changes.
* **New Email** (3): Enter the customer's new email if you are making changes.
* **Reason for Amendment** (4): Provide a brief reason for the amendment, explaining the changes you are making.
* **Customer's Current Email** (7): Enter the customer's current email address to confirm the changes.
* **Confirm** (5): Confirm the changes by selecting **Yes**.
* **Submit 2** (11): Optionally, select **Yes** to cancel the changes.
* **Customer's Old Name** (10), **Customer's Old Email** (8), and **Reason Old** (9): These fields are not required for the standard process, but might be useful for debugging or auditing purposes.
* **Email Old** (8): Enter the old email address if you are making changes.
* **Reason Old** (9): Enter the reason for the old email changes. 

## Tips

* Make sure to enter the correct customer ID to select the correct subscription.
* Double-check the customer's current email address to confirm the changes.
* If you are not making any changes, you can select **Yes** from the **Confirm** field to submit the form without making any changes.
* If you are making changes and want to cancel them, select **Yes** from the **Submit 2** field.
