# multiple_choice_recurring_subscriptions - Help Guide
## Purpose
The multiple choice recurring subscription form allows users to select a subscription service, specify the subscription type and start date, and optionally define the frequency and end date of their subscription.

## How To Complete This Form
1. Click the "Select a Subscription" page to choose from available options.
2. Fill out the subscription type page, if applicable.
3. Input the subscription start date or leave it blank if no end date is set.
4. Input the subscription end date or leave it blank if no end date is set.
5. Choose the subscription frequency or leave it blank if not required.

## Field-by-Field Explanation
### Select a Subscription
* **Select a Subscription** (`subscribe_to_service`, `select_one`, not required): Choose the subscription service you would like to subscribe to.
### Subscription Type
* **Subscription Type** (`subscription_type`, `select_one`, not required): Select the type of subscription you would like to get, if applicable.
### Subscription Start Date
* **Subscription Start Date** (`recurring_subscription_start_date`, `date`, not required): Input the date when your subscription starts, or leave blank for no end date.
### Subscription End Date
* **Subscription End Date** (`recurring_subscription_end_date`, `date`, not required): Input the date when your subscription ends, or leave blank for no end date.
### Subscription Frequency
* **Subscription Frequency** (`recurring_subscription_frequency`, `select_one`, not required): Choose the frequency of your subscription, if applicable.

## Tips
* Ensure that the subscription type and frequency are only filled out if they are required for the selected service.
* Use the start date to define when your subscription begins.
* Leave the start date blank to indicate that the subscription has no start date.
* Use the end date to define when your subscription ends.
* Leave the end date blank to indicate that the subscription has no end date.
* Choose the subscription frequency from the given options to specify when your subscription will recur.
