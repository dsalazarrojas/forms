# Software Premium Membership Access Form - Help Guide
## Purpose
This form is designed to collect information from customers who wish to access premium membership for software.

## How To Complete This Form
To complete this form, please follow these steps:

1. Please fill out the required fields (customer_name, email, and role) completely.
2. Select the relevant options for software_version, intent, company_type, inquiry_type, customer_success, team, plan, and timezone.
3. Enter any additional information in the text fields (company, contact, other_details).

## Field-by-Field Explanation

* **Software Premium Membership Access** (`software_premium_membership_access`, text): This field is where you can enter any additional details about why you are interested in accessing premium membership.
* **Customer Name** (`customer_name`, text): Please enter your name as it appears on your company's records.
* **Email** (`email`, email): Please enter your company email address for contact and communication purposes.
* **Company** (`company`, text): If you have a company, please enter its name. If you are an individual, you can leave this field blank.
* **Role** (`role`, select_one): Please select your role from the options provided. This will help us tailor the premium membership experience to your needs.
* **Software Version** (`software_version`, select_multiple): Please select the software version(s) you are interested in accessing premium membership for.
* **Intent** (`intent`, select_one): Please select the type of support or service you are looking for.
* **Company Type** (`company_type`, select_one): Please select the type of company you represent.
* **Inquiry Type** (`inquiry_type`, select_one): Please select the type of inquiry you have.
* **Customer Success** (`customer_success`, select_one): Please select how you measure customer success.
* **Team** (`team`, select_one): Please select the team you are interested in accessing premium membership for.
* **Plan** (`plan`, select_one): Please select the plan that best meets your needs.
* **Contact** (`contact`, text): If you have any specific contact information, please enter it here.
* **Timezone** (`timezone`, time): If you have a specific timezone you prefer to work in, please enter it here.
* **Software Version Other** (`software_version_other`, text): If none of the software version options match your needs, please enter your own version number.
* **Plan Other** (`plan_other`, text): If none of the plan options match your needs, please enter your own plan details.
* **Company Other** (`company_other`, text): If you have an other company that you would like to access premium membership for, please enter its name.
* **Customer Success Other** (`customer_success_other`, text): If you measure customer success in a way not listed, please explain here.
* **Team Other** (`team_other`, text): If you have another team that you would like to access premium membership for, please enter its name.
* **Contact Other** (`contact_other`, text): If you have any other contact information, please enter it here.
* **Timezone Other** (`timezone_other`, text): If you have a specific timezone you prefer to work in, please enter it here.
* **Date Other** (`date_other`, date): If you have a specific date for your premium membership, please enter it here.
* **Other Details** (`other_details`, text): If you have any other details or comments, please enter them here.

## Tips
Please fill out this form completely and accurately to ensure that we can provide you with the best possible experience. If you are unsure about any of the fields, please do not hesitate to contact us for assistance.
