# Emergency Claim Form - Help Guide

## Purpose
The Emergency Claim Form is designed to collect information from individuals who need to report an emergency medical claim. This form is used to capture essential details about the claim, ensuring it is processed efficiently and effectively.

## How To Complete This Form
1. Select the relevant fields as required, marked with a red asterisk (*).
2. Fill out the contact information form, selecting either "Yes" or "No" as to whether you have the necessary documentation.
3. In the "Claim Details" text field, provide a detailed description of the incident as much as possible.
4. Enter the date of the injury using the date format specified on the provided calendar tool.
5. Fill out the "Time of Injury" field using the 24-hour clock format.
6. Provide a detailed description of the injury in the "Description of Injury" text field.
7. If applicable, upload the supporting "Medical Report" documentation.

## Field-by-Field Explanation

* **Contact Info Form** (`contact_form`, `select_multiple`, required/optional): This form is used to determine if you have any supporting documentation such as medical reports or witness statements. Select 'Yes' if you have the necessary documentation, or 'No' if not.
* **Claim Details** (`claim_details`, `text`, required/optional): This field is used to provide a detailed description of the incident. Please provide as much information as you can about the injury, including any contributing factors or circumstances.
* **Date of Injury** (`date_of_injury`, `date`, required/optional): Enter the date of the injury using the date format provided on the calendar tool.
* **Time of Injury** (`time_of_injury`, `time`, required/optional): Fill out the "Time of Injury" field using the 24-hour clock format. For example, 14:30 for 2:30 PM.
* **Description of Injury** (`injury_description`, `text`, required/optional): Provide a detailed description of the injury, including any symptoms or effects experienced.
* **Medical Report** (`medical_report`, `text`, required/optional): If applicable, attach the supporting medical report documentation. This will help the claim process.
