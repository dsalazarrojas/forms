# Vendor Agreement Extension Form - Help Guide
## Purpose
This form is used to record and manage vendor agreements and extensions for our organization. It collects information about vendor agreements, such as ID, name, extension dates, contract details, extension reason, and status.
## How To Complete This Form
To complete this form, follow these steps:

1. Enter the **Vendor Agreement ID** (required): This is the unique ID assigned to the vendor agreement.
2. Enter the **Vendor Name** (optional): If provided, please enter the name of the vendor associated with this agreement.
3. Enter the **Extension Date** (optional): This is the date on which the agreement was extended.
4. Enter the **Contract Number** (optional): This is the ID of the contract associated with this agreement.
5. Enter the **Contract Start Date** (optional): This is the start date of the contract.
6. Enter the **Contract End Date** (optional): This is the end date of the contract.
7. Select the **Extension Reason** (optional): This is a free-text field to explain the reason for the extension.
8. Select the **Extension Term** (required): This option determines how long the agreement was extended for, such as 6 months, 1 year, or 2 years.
9. Enter the **Next Review Date** (optional): This is the date on which the agreement will next be reviewed.
10. Add any **Notes** (optional): This is a free-text field for any additional comments or notes about the agreement.
11. Select the **Assigned User** (optional): This is the user who is primarily responsible for this agreement.
12. Select the **Assigned Tool** (optional): This is the tool associated with this agreement.
13. Select the **Extension Status** (required): This option determines the status of the extension, which can be either Active or Inactive.
14. Enter the **Created At** (readonly): This is the date on which the agreement was created.
15. Enter the **Updated At** (readonly): This is the date on which the agreement was last updated.
16. Enter the **Deleted At** (readonly): This is the date on which the agreement was deleted.
17. Enter the **Deleted By** (readonly): This is the user who deleted the agreement.
18. Enter the **Deleted Reason** (readonly): This is the reason why the agreement was deleted.
19. Enter the **Assigned By** (readonly): This is the user who assigned this agreement.
20. Enter the **Created By** (readonly): This is the user who created this agreement.
21. Enter the **Updated By** (readonly): This is the user who last updated this agreement.
22. Select the **Extension Term Length** (required): This option determines how long the agreement was extended for, such as 6 months, 1 year, or 2 years.
23. Select the **Extension Type** (required): This option determines the type of extension, which can be either Contract Renewal or Contract Extension.
24. Enter the **Renewal Date** (optional): This is the date on which the agreement will be renewed.
25. Enter the **Vendor Contract ID** (optional): This is the ID of the contract associated with this agreement.
