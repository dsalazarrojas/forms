# Table Saw Extension Request Form - Help Guide
## Purpose
The Table Saw Extension Request Form is used to request an extension to a table saw in our organization. This form is required for all table saw requests to ensure accurate and efficient processing.

## How To Complete This Form
To complete this form, please follow these steps:

1. Enter a title for the request in the "Form Title" field.
2. Choose the category for the table saw from the "Category" dropdown menu.
3. Provide a brief description of the extension request in the "Description" field (optional).
4. Check the "Supervisor Review" box if the extension request requires a supervisor's review.
5. Select the date the table saw is required by in the "Date" field.
6. If applicable, select the extension date from the "Extension Date" field.
7. Enter your name and any relevant details in the "Form Submitter" field.

## Field-by-Field Explanation
* **Form Title** (`form_title`, text, required): Enter a brief title for the request.
* **Category** (`category`, select_one, required): Select the category for the table saw from the dropdown menu. This will help us understand the context and priority of the request.
* **Description** (`description`, text, optional): Provide a brief description of the extension request. This will help us understand the reasons behind the request.
* **Supervisor Review** (`supervisor_review`, select_multiple, required): Check this box if the extension request requires a supervisor's review.
* **Date** (`date`, date, required): Select the date the table saw is required by.
* **Extension Date** (`extension_date`, date, optional): If applicable, select the extension date for the table saw.
* **Form Submitter** (`form_submitter`, text, optional): Enter your name and any relevant details for us to contact you.

## Tips
* Make sure to complete all required fields before submitting the form.
* If you are unsure about any field, please reach out to your supervisor or support team for assistance.
* Please do not reuse a request for the same table saw. If you need to request an extension for the same table saw, please create a new form.
