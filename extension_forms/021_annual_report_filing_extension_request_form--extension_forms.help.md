# Annual Report Filing Extension Request Form - Help Guide
## Purpose
This form is used to request an extension for filing an annual report.

## How To Complete This Form
- Please ensure you have all necessary information before starting to fill out the form.
- Enter the required details in each field accurately and thoroughly.
- Review the form for completeness before submission.

## Field-by-Field Explanation
* **Company Legal Name** (`company_name`, text, required): Enter the official registered name of the company.
* **Company ID or Registration Number** (`company_id`, text, optional): If applicable, provide the registration or identification number of the company.
* **Contact Person Name** (`contact_person`, text, required): Enter the name of the primary contact person for this request.
* **Contact Person Title** (`contact_title`, text, optional): Enter the position or role of the contact person.
* **Email Address** (`contact_email`, email, required): Enter the primary contact email of the contact person.
* **Phone Number** (`contact_phone`, text, required): Enter the contact phone number of the contact person.
* **Filing Jurisdiction** (`filing_jurisdiction`, text, required): Enter the state or country of filing.
* **Original Filing Deadline** (`original_deadline`, date, required): Enter the original due date for the report.
* **Current Fiscal Year** (`current_fiscal_year`, text, required): Enter the fiscal year for the report being filed.
* **Type of Annual Report** (`report_type`, select_one, required): Choose the type of annual report (e.g., Annual Report - 10-K, Annual Report - Form 20-F, etc.).
* **Number of Days Extension Requested** (`requested_extension_days`, number, required): Enter the number of additional days needed.
* **New Proposed Deadline** (`new_proposed_deadline`, date, required): Enter the target date for submission.
* **Primary Reason for Extension** (`primary_reason`, select_one, required): Choose the primary reason for the extension request (e.g., Delayed audit completion, External audit firm delays, etc.).
* **Detailed Explanation** (`reason_details`, text, required): Provide specific circumstances for the extension request.
* **Have prior extensions been requested?** (`prior_extensions`, select_one, required): Choose if prior extensions have been requested.
* **Audit Status** (`audit_status`, select_one, required): Choose the status of the audit (e.g., Not yet started, In progress, etc.).
* **External Auditor Name** (`auditor_name`, text, optional): If applicable, enter the name of the audit firm or person.
* **Auditor Contact Information** (`auditor_contact`, text, optional): If applicable, enter the contact information of the auditor.
* **Financial Close Status** (`financial_close_status`, select_one, required): Choose the status of the financial close (e.g., Not started, In progress, etc.).
* **Expected Completion Date** (`expected_completion`, date, required): Enter when the report will be ready.
* **Describe any hardship circumstances** (`hardship_circumstances`, text, optional): If applicable, describe any extreme challenges affecting ability to file.
* **Compliance History** (`compliance_history`, select_one, required): Choose the compliance history (e.g., Always filed on time, Occasionally requested extensions, etc.).
* **Board Approval Obtained** (`board_approval`, select_one, optional): If applicable, choose if board approval has been obtained.
* **Supporting documentation attached** (`supporting_documentation`, select_one, required): Choose if supporting documentation is attached or will be provided separately.
