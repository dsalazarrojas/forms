# Environmental License Extension Application - Help Guide
## Purpose
The Environmental License Extension Application form is designed to gather information and supporting documents for an environmental license extension request. To complete this form, please follow the instructions below.

## How To Complete This Form

1. Fill in the **Extension Request** page with a brief description of the reason for requesting an extension.
2. Enter your **Organization Name** in the provided text field.
3. Enter your **Email** address in the format `example@example.com`.
4. Enter your **Phone** number, if applicable.
5. Select **Yes** or **No** to indicate if you are requesting an extension for a permit.
6. Enter the **Permit ID**, a unique identifier for the permit you are requesting to extend.
7. Choose the **Permit Expiration Date**, the date you are requesting the extension to be valid until.
8. Enter the **Renewal Fee**, if applicable.
9. Select **Yes** or **No** to indicate if there is a reason for the renewal.
10. Enter any additional **Notes** regarding your request.
11. Upload **Attachment 1**, **Attachment 2**, **Attachment 3**, **Attachment 4**, **Attachment 5**, **Attachment 6**, **Attachment 7**, **Attachment 8**, **Attachment 9**, **Attachment 10**, **Attachment 11**, and **Attachment 12**, if required.

## Field-by-Field Explanation

* **Extension Request (Text)**: A brief description of the reason for requesting an extension.
* **Organization Name (Text)**: The name of your organization making the request.
* **Email (Email)**: The email address where you can be contacted regarding your request.
* **Phone (Text)**: Your organization's phone number.
* **Permit Type (Select One)**: Indicate if you are requesting an extension for a permit.
* **Permit ID (Number)**: The unique identifier for the permit you are requesting to extend.
* **Permit Expiration Date (Date)**: The date you are requesting the extension to be valid until.
* **Renewal Fee (Number)**: The fee for renewing the permit.
* **Reason For Renewal (Select One)**: Indicate if there is a reason for the renewal.
* **Notes (Note)**: Any additional comments or information regarding your request.
* **Attachment 1**, **Attachment 2**, **Attachment 3**, **Attachment 4**, **Attachment 5**, **Attachment 6**, **Attachment 7**, **Attachment 8**, **Attachment 9**, **Attachment 10**, **Attachment 11**, and **Attachment 12** (Text): Uploading any supporting documents required for your request.

Note: This form is subject to change. Please ensure that you are using the latest version of the form.
