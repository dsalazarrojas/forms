# Theater Performance Extension Request Form - Help Guide
## Purpose
The Theater Performance Extension Request Form is used to request an extension for a scheduled theater performance. It helps to gather information necessary to make a decision on whether the performance can be extended and if so, what type of extension is requested.

## How To Complete This Form
To complete this form, follow these steps:

1.  Enter the **Performance Date** of the original scheduled performance.
2.  Enter the **Production Title** of the performance.
3.  Enter the **Venue** where the performance will be held.
4.  Enter the **Production Start Date** and **Production End Date** of the performance.
5.  Provide a brief **Extension Request** explaining why an extension is needed.
6.  Specify the **Reason For Extension**, giving details about the reason for the request.
7.  Choose the **Extension Request Type** from the options provided.
8.  Review and select the **Approval Status** of your request.

## Field-by-Field Explanation
### Performance Date
*   **Performance Date** (Date, Optional): Enter the original date of the performance.

### Production Title
*   **Production Title** (Text, Optional): Enter the title of the production, e.g., "Hamlet" or "Romeo and Juliet".

### Venue
*   **Venue** (Text, Optional): Enter the name of the venue where the performance will be held, e.g., "Theater X" or "Grand Opera House".

### Production Start Date
*   **Production Start Date** (Date, Optional): Enter the start date of the production.

### Production End Date
*   **Production End Date** (Date, Optional): Enter the end date of the production.

### Extension Request
*   **Extension Request** (Text, Optional): Provide a brief explanation of why an extension is needed.

### Reason For Extension
*   **Reason For Extension** (Text, Optional): Give details about the reason for the request.

### Extension Request Type
*   **Extension Request Type** (Select, Optional): Choose the type of extension requested, e.g., "Additional Performance Date" or "Extension of Existing Dates".

### Approval Status
*   **Approval Status** (Select, Optional): Review and select the status of your request, e.g., "Pending", "Approved", or "Rejected".

## Tips
*   Be as clear and concise as possible when filling out the form.
*   Provide as much detail as possible for each field to support your request.
*   Review your information carefully before submitting the form to ensure accuracy.
