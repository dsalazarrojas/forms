# real_estate_contact_form - Help Guide
## Purpose
The real_estate_contact_form is designed to collect information from users interested in searching for real estate properties and contacting the owner or agent for more information.

## How To Complete This Form
To complete this form, follow the steps below:

1. Enter your property search criteria in the **Property Search** field.
2. If applicable, select one or more **Property Features** that interest you.
3. Choose your **Contact Method** (Call, Email, or Message).
4. Enter your **Email** (if contacting via Email).
5. Enter your **Phone** (if contacting via Phone).
6. Type in a brief **Message** with any additional information about the property you're interested in.

## Field-by-Field Explanation
* **Property Search**: A text field where you can enter a property address or any other search criteria.
* **Contact Details**: A required text field where you need to enter your contact information (e.g., name, address).
* **Email**: A text field where you need to enter your email address to receive responses.
* **Phone**: A text field where you can enter your phone number to receive calls.
* **Message**: A required text field where you need to type a brief message with any additional information about the property.
* **Contact Method**: A select field where you can choose how you'd like to be contacted (Call, Email, or Message).
* **Property Features**: A select multiple field where you can choose any property features that interest you (e.g., Pool, Parking, Balcony).
