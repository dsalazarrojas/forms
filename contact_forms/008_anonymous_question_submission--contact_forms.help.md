# Anonymous Question Submission - Help Guide
## Purpose
The anonymous question submission form is designed to allow users to submit questions related to specific topics without requiring them to provide personal identifying information. This form helps to ensure that the questions are addressed in a timely and non-duplicative manner.

## How To Complete This Form
To complete this form, follow these steps:

1. Choose the most relevant topic from the provided options.
2. Type in the question you would like to have answered in the provided text box.
3. (Optional) If you'd like to provide additional context or background information to help answer your question, you can do so in the optional text box.
4. (Optional) If you're willing to be contacted for follow-up questions, select "True" in the "Allow anonymous follow-up" dropdown.
5. (Optional) Select the urgency level of your question (Low, Medium, High).
6. Click "Submit" to submit your question.

## Field-by-Field Explanation
* **Question topic** (required):
    * Label: Question topic
    * Description: Choose the most relevant topic from the provided options (General inquiry, Policy, Program details, Technical support, or Other).
* **Question** (required):
    * Label: Question
    * Description: Enter the full text of the question you'd like to have answered.
* **Urgency level** (optional):
    * Label: Urgency level
    * Description: Select the urgency level of your question (Low, Medium, High).
* **Allow anonymous follow-up** (optional):
    * Label: Allow anonymous follow-up if clarification needed
    * Description: If you're willing to be contacted for follow-up questions, select "True".
* **Additional context** (optional):
    * Label: Additional context
    * Description: Provide optional background information to help answer your question.
* **Submit**
    * Label: Submit
    * Description: Click "Submit" to submit your question for processing.
