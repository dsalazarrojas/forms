# full_width_contact_page_responsive - Help Guide

## Purpose
This form is used to collect contact information from users on a contact page.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in your **First Name** (`first_name`) in the text field provided.
2. Enter your **Email** (`email`) in the text field provided.
3. Enter your **Contact Number** (`contact_number`) in the text field provided.
4. If you have a **Website URL** (`website_url`), please enter it in the text field provided.
5. Provide a brief **Description** (`description`) of yourself or your organization in the text field provided.
6. Select the **Submit** button to proceed with the submission.
7. If you need to embed custom code or script for advanced functionality, enter it in the **Embed Code** (`embed_code`) and provide a brief description in **Embed Description** (`embed_description`).

## Field-by-Field Explanation

* **First Name** (`first_name`, text, optional): Enter your first name in this field.
* **Email** (`email`, email, optional): Enter your valid email address in this field.
* **Contact Number** (`contact_number`, text, required): Enter your contact number in this field.
* **Website URL** (`website_url`, text, optional): If you have a website, enter its URL here.
* **Description** (`description`, note, optional): Provide a brief description of yourself or your organization.
* **Submit** (`submit_button`, select_one, optional): Select this button to initiate the submission process.
* **Embed Code** (`embed_code`, text, optional): Enter custom code for advanced functionality.
* **Embed Description** (`embed_description`, text, optional): Provide a brief description of the embedded code.
* **Embed Script** (`embed_script`, text, optional): Enter the script for the embedded code.
