# Contact Form With Upload Function - Help Guide
## Purpose
The Contact Form With Upload Function is a multi-purpose form designed to receive files and descriptions of user requests. This guide will walk you through the form fields and how to complete it.

## How To Complete This Form
1. Fill out the required fields: Full Name, Email Address, Upload Description, and Consent to Process Uploaded Files.
2. Provide your contact information (Full Name and Email Address) so we can get back to you.
3. Describe the files you will upload and their purpose (Upload Description).
4. If you have any additional comments or details, feel free to add them (Additional Comments).
5. If you have files to upload, you can either attach them via email or use the provided upload link (File Upload Instructions).
6. If necessary, select the priority of your request (Request Priority).
7. Select the types of files you will be uploading (Supported File Types).
8. Finally, confirm that you own the rights to the files and consent to process them (Consent to Process Uploaded Files).

## Field-by-Field Explanation
* **-- Upload Inquiry --**: This is a note field to describe the purpose of the form. You can use it to explain what you are submitting and why.
* **Full name**: This is a required field to identify who is submitting the files. Enter your full name as you would like to be referred to.
* **Email address**: This is a required field for us to contact you about your submission. Enter a valid email address.
* **Phone number**: This is an optional field to provide an alternative contact method. Enter your phone number if you prefer to be contacted via phone.
* **Upload description**: This is a required field to describe the files you will be uploading. Be as detailed as possible about the purpose and contents of the files.
* **File upload instructions**: This is a note field to describe how you will be uploading the files. You can either attach them via email or use the provided upload link.
* **Supported file types**: This is a select multiple field to choose the types of files you will be uploading. Common supported formats include PDF, JPG, PNG, DOCX, and CSV.
* **Maximum file size**: This is a text field to estimate the size of the files you will be uploading. This helps us prepare for large submissions.
* **Request priority**: This is a select one field to select how urgent your request is. Choose from Normal, High, or Urgent.
* **Consent to process uploaded files**: This is a required field to confirm that you own the rights to the files and consent to our processing them.
* **Additional comments**: This is a text field for any additional comments or details about your submission.

## Tips
* Be as detailed as possible in the Upload Description field.
* Use the File Upload Instructions field to let us know if you plan to attach files via email or use the provided upload link.
* If you select High or Urgent as the Request Priority, our team will handle your submission with extra care and attention.
* Confirm that you own the rights to the files you are uploading and consent to our processing them.
* If you have any additional comments, please let us know in the Additional Comments field.
