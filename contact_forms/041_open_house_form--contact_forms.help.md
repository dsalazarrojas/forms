# open_house_form - Help Guide
## Purpose
The "open_house_form" is a form designed to collect information about events, including their name, date, time, location, contact details, and any additional description or URL.

## How To Complete This Form

1. To complete this form, start by entering the required event name in the "Event name" field.
2. Select the date of the event in the "Event date" field.
3. Choose the time of the event in the "Event time" field.
4. (Optional) Enter the location of the event in the "Event location" field.
5. Enter the contact email address in the "Email" field.
6. Enter the contact phone number in the "Phone" field.
7. (Optional) Add a description of the event in the "Event description" field.
8. (Optional) Enter the URL related to the event in the "Event url" field.

## Field-by-Field Explanation

- **Event name** (Text, Required): This field is for the name of the event. Enter a brief and descriptive title for the event.
- **Event date** (Date, Required): Select the date of the event from the calendar.
- **Event time** (Time, Required): Choose the time of the event.
- **Event location** (Text, Optional): If the event has a specific location, enter it here. This field is not required.
- **Email** (Email, Required): Enter a contact email address associated with the event.
- **Phone** (Text, Required): Enter a contact phone number associated with the event.
- **Event description** (Text, Optional): Add a brief description of the event. This field is not required.
- **Event url** (Text, Optional): If there is a website or URL related to the event, enter it here. This field is not required.
