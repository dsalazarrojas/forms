# real_property_contact_form - Help Guide
## Purpose
The real_property_contact_form is used to track and document interactions with potential customers or clients in the real estate industry. It captures relevant details such as user contact information, property details, and follow-up dates and times.

## How To Complete This Form

1. Start by filling out the required fields: User Email, Property Address, Property Type, Contact Number, User Name, Property Price, Contact Date, and Contact Source.
2. For the select fields (Property Type, Real Estate Agent, Real Estate Office, Real Estate Broker, Real Estate Manager, Contact Source), select the relevant options from the dropdown list.
3. You may also want to add additional notes for follow-up and property status.
4. Fill out any other optional fields that are relevant to your specific needs.

## Field-by-Field Explanation

* **User Email** (`user_email`, email, required): Enter the user's email address.
* **Property Address** (`property_address`, text, required): Enter the address of the property being inquired about.
* **Property Type** (`property_type`, select_one, required): Select the type of property from the available options (Condo, House, Townhouse).
* **Real Estate Agent** (`real_estate_agent`, select_multiple, required): Select the real estate agent associated with this contact.
* **Contact Number** (`contact_number`, text, required): Enter the contact number of the user.
* **User Name** (`user_name`, text, required): Enter the user's name.
* **Property Price** (`property_price`, number, required): Enter the price of the property.
* **Contact Date** (`contact_date`, date, required): Enter the date of the contact.
* **Contact Source** (`contact_source`, select_one, required): Select the source of the contact (Source 1, Source 2, Source 3).
* **Note** (`note`, note, optional): Add any additional notes about the contact.
* **Follow Up Date** (`follow_up_date`, date, optional): Enter the follow-up date for this contact.
* **Follow Up Time** (`follow_up_time`, time, optional): Enter the follow-up time for this contact.
* **Follow Up Note** (`follow_up_note`, note, optional): Add any notes about the follow-up.
* **Real Estate Office** (`real_estate_office`, select_one, optional): Select the real estate office associated with this contact.
* **Real Estate Manager** (`real_estate_manager`, select_one, optional): Select the real estate manager associated with this contact.
* **Real Estate Broker** (`real_estate_broker`, select_one, optional): Select the real estate broker associated with this contact.
* **Real Estate Office Options** (`real_estate_office_options`, select_multiple, optional): Select any additional options related to the real estate office.
* **Property Status** (`property_status`, select_one, required): Select the status of the property (Condo, House, Townhouse).
* **Follow Up Note** (`follow_up_note`, note, optional): Add any notes about the follow-up.
* **Real Estate Manager Options** (`real_estate_manager_options`, select_multiple, optional): Select any additional options related to the real estate manager.
* **Follow Up Number** (`follow_up_number`, text, optional): Enter the follow-up number for this contact.
* **Real Estate Office Options** (`real_estate_office_options`, select_multiple, optional): Select any additional options related to the real estate office.
* **User Message** (`user_message`, text, optional): Enter a message from the user.
* **Follow Up Date** is not a typo, the correct field is "Follow Up Date" with "id: 8" and "label: Contact Date".

## Tips

* Make sure to fill out all required fields to ensure accurate record keeping.
* Use the select fields to choose the most accurate options for each field.
* You can add notes for follow-up and property status to provide additional context.
* This form is designed to track and document interactions with potential customers or clients, so be thorough and accurate in your fill-out.
