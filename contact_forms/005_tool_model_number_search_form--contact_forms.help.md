# Tool Model Number Search Form - Help Guide
## Purpose
The Tool Model Number Search Form is designed to help users find specific tools or models based on their model numbers. This form aims to gather information about the tool model number, such as the tool type and other relevant details.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the model number of the tool you are looking for in the "Tool Model Number" field.
2. (Optional) If you know the type of tool, select the corresponding option from the "Tool Type" dropdown menu.
3. Click the "Submit" button to begin the search.
4. If no results are found, a "No Results" note will be displayed.
5. If the tool is not found, a "No Tool Found" note will be displayed.

## Field-by-Field Explanation
* **Tool Model Number** (`tool_model_number`, text, optional): Enter the model number of the tool you are looking for. This can be a partial or complete model number.
* **Tool Type** (`tool_type`, select_one, optional): Choose the type of tool you are searching for. Selecting a tool type can help narrow down the search results. If you don't know the tool type, you can leave this field blank.
* **Submit** (`submit`, note, not applicable): This is a placeholder field for the submit button. You do not need to fill this field.
* **No Results** (`no_results`, note, not applicable): This field is displayed when no results are found.
* **No Tool Found** (`no_tool_found`, note, not applicable): This field is displayed when the tool is not found.
