# Hover Contact Card - Help Guide
## Purpose
The Hover Contact Card form is used to gather contact information for a hover card, which can display in an interactive or hover-over card. This information includes first and last names, email, phone number, company, job position, profile image, and background image or color.

## How To Complete This Form
To complete the Hover Contact Card form, follow these steps:
1. Fill out the required information (First Name, Last Name, Email).
2. Provide optional information such as Company, Position, Image, and Background.
3. Enter any additional details as needed.

## Field-by-Field Explanation
### **First Name** (`First Name`, Text, Required)
Enter your first name as it should appear in the hover card.

### **Last Name** (`Last Name`, Text, Required)
Enter your last name as it should appear in the hover card.

### **Email** (`Email`, Email, Required)
Enter your valid email address.

### **Phone** (`Phone`, Text, Optional)
Enter your phone number if you wish to have it displayed in the hover card.

### **Company** (`Company`, Text, Optional)
Enter the name of your company as it should appear in the hover card.

### **Position** (`Position`, Text, Optional)
Enter your job position as it should appear in the hover card.

### **Image** (`Image`, Text, Optional)
Enter a URL to the profile image you wish to display in the hover card.

### **Background Image** (`Background Image`, Text, Optional)
Enter a URL to the background image you wish to display in the hover card. This should be a valid image URL.

### **Background Color** (`Background Color`, Text, Optional)
Enter a valid hex color code for the background color of the hover card.

## Tips
- Ensure the email address is valid and in a correct format.
- Use a valid image URL for background and profile images.
- Use a valid hex code for background color.
- Fill out all required fields (First Name, Last Name, and Email) to save and submit the form.
