# Lawyer Contact Information Form - Help Guide
## Purpose
The Lawyer Contact Information Form is used to collect contact information from both clients and lawyers for internal communication and record-keeping purposes.

## How To Complete This Form
To complete this form, follow these steps:

* Fill out all required fields with accurate and complete information.
* For fields with options, select the corresponding value from the dropdown list.
* Make sure to enter dates in the correct format (MM/DD/YY).

## Field-by-Field Explanation
### Client Name
* Client Name (`client_name`, text, required/optional): Enter the name of the client.

### Email
* Email (`email`, email, required/optional): Enter the client's email address.

### Phone Number
* Phone Number (`phone_number`, text, required/optional): Enter the client's phone number.

### Client Address
* Client Address (`client_address`, text, required/optional): Enter the client's address.

### City
* City (`client_city`, text, required/optional): Enter the city where the client is located.

### State
* State (`state`, select_one, required/optional): Select the state where the client is located.

### Zip Code
* Zip Code (`zip_code`, text, required/optional): Enter the client's zip code.

### Country
* Country (`country`, select_one, required/optional): Select the country where the client is located.

### Law Firm
* Law Firm (`law_firm`, text, required/optional): Enter the name of the law firm.

### Law Firm Address
* Law Firm Address (`law_firm_address`, text, required/optional): Enter the address of the law firm.

### Law Firm City
* Law Firm City (`law_firm_city`, text, required/optional): Enter the city where the law firm is located.

### Law Firm State
* Law Firm State (`law_firm_state`, select_one, required/optional): Select the state where the law firm is located.

### Law Firm Zip Code
* Law Firm Zip Code (`law_firm_zip_code`, text, required/optional): Enter the zip code of the law firm.

### Law Firm Country
* Law Firm Country (`law_firm_country`, select_one, required/optional): Select the country where the law firm is located.

### Lawyer Contact Number
* Lawyer Contact Number (`lawyer_contact_number`, text, required/optional): Enter the contact number of the lawyer.

### Lawyer Name
* Lawyer Name (`lawyer_name`, text, required/optional): Enter the name of the lawyer.

### Lawyer Email
* Lawyer Email (`lawyer_email`, email, required/optional): Enter the email address of the lawyer.

### Lawyer Phone Number
* Lawyer Phone Number (`lawyer_phone_number`, text, required/optional): Enter the phone number of the lawyer.

### Lawyer Address
* Lawyer Address (`lawyer_address`, text, required/optional): Enter the address of the lawyer.

### Lawyer City
* Lawyer City (`lawyer_city`, text, required/optional): Enter the city where the lawyer is located.

### Lawyer State
* Lawyer State (`lawyer_state`, select_one, required/optional): Select the state where the lawyer is located.

### Lawyer Zip Code
* Lawyer Zip Code (`lawyer_zip_code`, text, required/optional): Enter the zip code of the lawyer.

### Lawyer Country
* Lawyer Country (`lawyer_country`, select_one, required/optional): Select the country where the lawyer is located.

### Date of Birth
* Date of Birth (`date_of_birth`, date, required/optional): Enter the date of birth of the lawyer in the format MM/DD/YY.

### Contact Method
* Contact Method (`contact_method`, select_one, required/optional): Select the method of contact (Phone, Email, In-person).

Note: If you are unsure about any of the fields, please contact the relevant contact person to confirm.
