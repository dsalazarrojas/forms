# Limousine Service Inquiry Form - Help Guide
## Purpose
This form is designed to collect information from customers about their limousine service needs. It will help us to better understand their requirements and provide them with a suitable limousine service experience.

## How To Complete This Form
To complete this form, simply follow these steps:
1. Fill in the fields below with the required information.
2. Ensure that you provide accurate and complete information to help us serve you better.
3. Review your submission before submitting it to us.

## Field-by-Field Explanation

* **Pickup Location**: Please enter the exact address or name of the location where you would like to be picked up.
* **Pickup Date**: Select the date when you would like to be picked up. Please use the format "month/day/year" (e.g., 02/25/2022).
* **Pickup Time**: Choose the time when you would like to be picked up. Please use the 24-hour format (e.g., 14:00 for 2:00 PM).
* **Dropoff Location**: Enter the exact address or name of the location where you would like to be dropped off.
* **Dropoff Date**: Select the date when you would like to be dropped off. Please use the format "month/day/year" (e.g., 02/25/2022).
* **Dropoff Time**: Choose the time when you would like to be dropped off. Please use the 24-hour format (e.g., 14:00 for 2:00 PM).
* **Special Requests**: If you have any special requests (e.g., champagne, flowers, or music), please list them here so we can accommodate your needs.

## Tips
- Double-check your submission for accuracy before submitting it to us.
- If you have any questions or concerns, feel free to contact us at form@gic.mx.
