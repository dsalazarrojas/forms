## PTA Event Suggestion Contact Form - Help Guide

## Purpose
This form is used to suggest events to be organized by the PTA. The form allows you to submit a new event suggestion with details such as event type, date, and location. The form helps the PTA to collect and manage event suggestions from the community.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the required fields (Name, Email, Date, and (optional) Event Type).
2. Select the Type of Event from the dropdown menu.
3. Enter the event date in the date field. Make sure to use a standard date format (e.g., YYYY-MM-DD).
4. If desired, select the Time of the event.
5. Choose the location where the event will take place from the dropdown menu.
6. Optionally, enter your Phone number and Suggestion.
7. Optionally, enter any Comments about the event.
8. Click the submit button to send your event suggestion.

## Field-by-Field Explanation

* **Name** (id: 2, required): Enter your name so we can contact you about your event suggestion.
* **Email** (id: 3, required): Enter your email address so we can reach out to you about your event suggestion.
* **Phone** (id: 4, optional): Enter your phone number if you want to be contacted about your event suggestion.
* **Suggestion** (id: 5, optional): Enter a brief description of your event suggestion.
* **Comment** (id: 6, optional): Enter any additional comments or details about your event.
* **Type of Event** (id: 7, optional): Select one or more types of events that you are suggesting. Available options are: Event, Fundraiser, Game, Meeting.
* **Date** (id: 8, required): Enter the date of the event in the standard date format (e.g., YYYY-MM-DD).
* **Time** (id: 9, optional): Enter the time of the event, if applicable.
* **Location** (id: 10, optional): Select the location where the event will take place. Available options are: Homecoming Dance, School.
* **Event Suggestion** (id: 1, label): This is the main field for entering your event suggestion.
