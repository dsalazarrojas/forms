# Tell A Friend Form - Help Guide
## Purpose
The Tell A Friend Form is designed to allow you to send a personal message or notification to a friend, colleague, or acquaintance. Fill out the form below to share information about a product or resource.

## How To Complete This Form
To complete the form, follow these steps:

* Click on the "Tell A Friend" page.
* Fill in the required fields: Friend Name, Friend Email, Product Url, and Product Name.
* Optionally, you can add a Friend Message, Assigned Tool, User Agent, User Ip, Form Category, or other fields as needed.
* Click the "Submit" button to send the message.

## Field-by-Field Explanation
* **Tell A Friend** (text): A short description of the form's purpose.
* **Friend Name** (text, required): The name of the person you want to send the message to.
* **Friend Email** (email, required): The email address of the person you want to send the message to.
* **Friend Phone** (text, optional): The phone number of the person you want to send the message to (if applicable).
* **Product Url** (text, required): The URL of the product or resource you want to share.
* **Product Name** (text, required): The name of the product or resource.
* **Friend Message** (text, optional): A personal message to include with the notification.
* **Assigned Tool** (select_one, optional): The tool associated with the message (if applicable).
* **User Agent** (text, optional): The user agent ID (if applicable).
* **User Ip** (number, optional): The user IP (if applicable).
* **Form Category** (select_multiple, optional): The category of the form (if applicable).
* **Created By** (time, optional): The timestamp of when the form was created (if applicable).
* **Updated By** (date, optional): The timestamp of when the form was updated (if applicable).
* **Output File** (text, optional): The output file (if applicable).
* **Form Id** fields (text, optional): Form ID fields for internal use.
* **Form Id 2**, **Form Id 3**, etc. (text, optional): Additional form ID fields for internal use.

Note: Some fields are optional and only appear if you have specific requirements or need to include additional information.
