# household_survey_for_child_development_form - Help Guide
## Purpose
The "household_survey_for_child_development_form" is used to gather information about households and their children to assess their safety and well-being.

## How To Complete This Form
To complete this form, please follow these steps:

1. Enter the `household_id`, if applicable.
2. Enter the `household_name` of the household.
3. Enter the number of children living in the household using the `number_of_children` field.
4. Enter the number of adults living in the household using the `number_of_adults` field.
5. Enter the `child_id` of the child you are inquiring about, if applicable.
6. Enter the `child_name` of the child you are inquiring about, if applicable.
7. Select the safety status of the child using the `safety_status` field. This field is required.
8. If applicable, select the wellbeing status of the child using the `wellbeing_status` field.
9. Enter the email of the parent/guardian, if you wish to be contacted.
10. Enter the phone number of the parent/guardian, if you wish to be contacted.
11. Enter any additional notes or comments you would like to include.

## Field-by-Field Explanation
* **household_id**: Enter the unique identifier for the household, if applicable. This field is not required.
* **household_name**: Enter the name of the household. This field is not required.
* **number_of_children**: Enter the number of children living in the household.
* **number_of_adults**: Enter the number of adults living in the household.
* **child_id**: Enter the unique identifier for the child you are inquiring about, if applicable. This field is not required.
* **child_name**: Enter the name of the child you are inquiring about, if applicable. This field is not required.
* **safety_status**: Select the safety status of the child. This field is required and has three options: "safe", "not safe", "unsure".
* **wellbeing_status**: Select the wellbeing status of the child. This field is not required and has three options: "well", "not well", "unsure".
* **email**: Enter the email of the parent/guardian, if you wish to be contacted. This field is not required.
* **phone**: Enter the phone number of the parent/guardian, if you wish to be contacted. This field is not required.
* **note**: Enter any additional notes or comments you would like to include. This field is not required.
