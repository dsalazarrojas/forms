# Student Internet Access At Home Feedback Form - Help Guide
## Purpose
This form is designed to gather information about students' home internet access and its impact on their daily lives.

## How To Complete This Form
To complete this form, please follow these steps:

1. Answer each field according to your true feelings and experiences.
2. Please select the options that best describe your situation.
3. If you're unsure or don't know the answer, please choose "Not sure" or "Not at all important".
4. Make sure to review your answers before submitting the form.

## Field-by-Field Explanation

* **Internet Access at Home** (`internet_access_at_home`, note, optional): This field is to gather information about your internet access at home. Please select "True" if you have access, "False" if you don't, or "Not sure" if you're not sure.
* **How I Feel** (`feel`, number, optional): This field is to rate your feelings about having internet access at home. Please select a number from 1 to 10, where 1 is "Not at all important" and 10 is "Very important".
* **Time Spent** (`time_spent`, time, optional): This field is to estimate the time you spend online. Please select a time range that best describes how much time you usually spend online.
* **Internet at School** (`internet_at_school`, select_one, optional): This field is to ask about your internet access at school. Please select "True" if you have access, "False" if you don't, or "Not sure" if you're unsure.
* **Parent Involvement** (`parent_involvement`, select_multiple, optional): This field is to ask about your parents' involvement in providing internet access. Please select all that apply: "True" if they are involved, "False" if they're not, or leave blank if you're unsure.
* **Device Used** (`device`, select_one, optional): This field is to ask about the device you use for online activities. Please select Laptop/Desktop, Smartphone, or Tablet.
* **Network Speed** (`network_speed`, select_one, optional): This field is to ask about your internet network speed. Please select "Fast" or "Slow".
* **Internet Access** (`internet_access`, select_multiple, optional): This field is to ask about your available internet access. Please select all that apply: "True" if you have access, "False" if you don't, or "Not enough" if it's limited.
* **Feel Important** (`feel_important`, select_multiple, optional): This field is to rate how important you feel the internet is for your daily life. Please select all that apply: "Important", "Not important", or "Not at all important".
* **Parent Knowledge** (`parent_knowledge`, select_one, optional): This field is to ask about your parents' knowledge about online safety and security. Please select "High", "Low", or "No answer".

Please note that all fields are optional, and you can skip any field if you're unsure or don't have the information.
