# Student Stress Survey - Help Guide
## Purpose
The Student Stress Survey is designed to gather information on various aspects of student life, including demographic information, academic pressures, school climate, and overall stress levels. This data will help schools understand student stress levels and inform initiatives to improve student support and resources.

## How To Complete This Form
To complete this form, simply select your answers to each question. Please note that you can select multiple options for some fields. If you are unsure about any of the fields, you can always reach out to the administrators for clarification.

## Field-by-Field Explanation
* **Student Stress Survey** (`student_stress_survey`, select multiple, not required): Select all that apply from the options provided.
* **Demographic Info** (`demographic_info`, select one, not required): Select your demographic information (Male, Female, Other).
* **School Work Hours** (`school_work`, number, not required): Enter the number of hours you spend on school work per day.
* **School Work Days** (`school_work_days`, number, not required): Enter the number of days you spend on school work per week.
* **Free Time Activities** (`free_time_activities`, select multiple, not required): Select all that apply from the options provided.
* **Family Support** (`family_support`, select one, not required): Select if you receive family support (True, False).
* **School Support** (`school_support`, select one, not required): Select if you receive school support (True, False).
* **Teacher Support** (`teacher_support`, select one, not required): Select if you receive teacher support (True, False).
* **Student Support Group** (`student_support_group`, select one, not required): Select if you are part of a student support group (True, False).
* **Sleep** (`sleep`, number, not required): Enter the number of hours you sleep per night.
* **Exercise** (`exercise`, select one, not required): Select if you exercise regularly (True, False).
* **Exercise Frequency** (`exercise_frequency`, select one, not required): Select the frequency of your exercise (Daily, Several times a week, Rarely).
* **Stress Level** (`stress_level`, select one, not required): Select your current stress level (High, Medium, Low).
* **School Climate** (`school_climate`, select one, not required): Select the climate of your school (Positive, Negative, Neutral).
* **Academic Pressure** (`academic_pressure`, select one, not required): Select the academic pressure you feel (High, Medium, Low).
* **Time Management** (`time_management`, select one, not required): Select your time management skills (High, Medium, Low).
* **Self-Confidence** (`self_confidence`, select one, not required): Select your self-confidence level (High, Medium, Low).
* **Teacher Support Frequency** (`teacher_support_frequency`, select one, not required): Select the frequency of teacher support you receive (Daily, Several times a week, Rarely).
* **Student Support Group Frequency** (`student_support_group_frequency`, select one, not required): Select the frequency of student support group you attend (Daily, Several times a week, Rarely).
* **Student Support Group Quality** (`student_support_group_quality`, select one, not required): Select the quality of support you receive from student support group (High, Medium, Low).
* **Teacher Support Quality** (`teacher_support_quality`, select one, not required): Select the quality of support you receive from teachers (High, Medium, Low).
* **School Workload** (`school_workload`, select one, not required): Select the workload you have (High, Medium, Low).
* **Free Time Activities Frequency** (`free_time_activities_frequency`, select one, not required): Select the frequency of free time activities you do (Daily, Several times a week, Rarely).
* **School Climate Quality** (`school_climate_quality`, select one, not required): Select the quality of school climate (High, Medium, Low).

## Tips
* Please answer honestly, and try to select the most accurate option for each field.
* If you have any questions or concerns, feel free to reach out to the administrators.
* You can select multiple options for fields like `Free Time Activities` and `Student Support Group` to reflect your experiences.
* You can always reach out to the administrators if you need any clarification or assistance.
