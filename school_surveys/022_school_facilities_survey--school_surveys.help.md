# School Facilities Survey - Help Guide
## Purpose
This form is used to collect information about the condition and equipment of school facilities. The goal is to gather data on various aspects of facilities, including their condition, safety, accessibility, maintenance, and more.

## How To Complete This Form
1. Please fill in the survey title to describe the survey.
2. Enter the school ID to identify the school being surveyed.
3. Enter the building ID to identify the building within the school.
4. Enter the name of the facility being surveyed.
5. For each of the following questions, select the answer that best describes the current state of the facility:
	* If facilities in the school are in good condition.
	* If facilities in the school are in fair condition.
	* If facilities in the school are not surveyed.
6. Enter any additional comments about the condition of the facilities.
7. For each of the following questions, select the answer that best describes the current state of the facility:
	* If the school has good safety.
	* If the school has fair safety.
8. Enter any additional comments about the safety of the facilities.
9. For each of the following questions, select the answer that best describes the current state of the facility:
	* If the school has good accessibility.
	* If the school has fair accessibility.
10. Enter any additional comments about the accessibility of the facilities.
11. Select if facilities have been surveyed.
12. Enter any additional comments about facilities that have been surveyed.
13. For each of the following questions, select the answer that best describes the current state of the facility:
	* If facilities have priority for maintenance.
	* If facilities do not have priority for maintenance.
14. Enter any additional comments about facilities maintenance.
15. For each of the following questions, select the answer that best describes the current state of the facility:
	* If facilities have necessary equipment.
	* If facilities do not have necessary equipment.
16. Enter any additional comments about facilities equipment.
17. For each of the following questions, select the answer that best describes the current state of the facility:
	* If facilities have necessary furniture.
	* If facilities do not have necessary furniture.
18. Enter any additional comments about facilities furniture.
19. For each of the following questions, select the answer that best describes the current state of the facility:
	* If facilities have good lighting.
	* If facilities have fair lighting.

20. Enter any additional comments about facilities lighting.
21. For each of the following questions, select the answer that best describes the current state of the facility:
	* If facilities have good temperature control.
	* If facilities have fair temperature control.
	* If facilities do not have good temperature control.
22. Enter any additional comments about facilities temperature.
