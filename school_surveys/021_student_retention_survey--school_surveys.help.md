# Student Retention Survey - Help Guide
## Purpose
The Student Retention Survey is designed to collect data on student retention, including reasons for leaving, support systems, and relevant dates. This data will help schools understand the reasons behind student departures and identify areas for improvement.
## How To Complete This Form
To complete this form, please follow these steps:

1. Enter the student's ID number in the "Student ID" field (Field 1).
2. Enter the teacher's name in the "Teacher Name" field (Field 2).
3. Answer the questions in the "Reasons for Students Leaving" section (Field 3).
4. If the student has any other reason for leaving that is not listed, please specify it in the "Other Reasons for Students Leaving" field (Field 4).
5. Answer the questions in the "Reasons for Teachers Leaving" section (Field 5).
6. If the teacher has any other reason for leaving that is not listed, please specify it in the "Other Reasons for Teachers Leaving" field (Field 6).
7. Select the teacher support system that best describes the support provided to the student (Field 7).
8. If the teacher has any other support system that is not listed, please specify it in the "Other Teacher Support System" field (Field 8).
9. Select the student support system that best describes the support provided to the student (Field 9).
10. If the student has any other support system that is not listed, please specify it in the "Other Student Support System" field (Field 10).
11. Please provide any comments or feedback from the teacher in the "Teacher Comments" field (Field 11).
12. Please provide any comments or feedback from the student in the "Student Comments" field (Field 12).
13. Enter the school ID number in the "School ID" field (Field 13).
14. Enter the grade level of the student in the "Grade Level" field (Field 14).
15. Select the date of student retention (Field 15).
16. Select the date of teacher survey (Field 16).

## Field-by-Field Explanation

* **Student ID (Field 1)** (`student_id`, Number, Required): Enter the student's ID number.
* **Teacher Name (Field 2)** (`teacher_name`, Text, Required): Enter the teacher's name.
* **Reasons for Students Leaving (Field 3)** (`student_reasons_left`, Select Multiple, Required): Answer the questions in this section to understand why the student left the school.
* **Other Reasons for Students Leaving (Field 4)** (`student_reasons_left_other`, Text, Optional): If the student has any other reason for leaving that is not listed, please specify it here.
* **Reasons for Teachers Leaving (Field 5)** (`teacher_reasons_left`, Select Multiple, Required): Answer the questions in this section to understand why the teacher left the school.
* **Other Reasons for Teachers Leaving (Field 6)** (`teacher_reasons_left_other`, Text, Optional): If the teacher has any other reason for leaving that is not listed, please specify it here.
* **Teacher Support Systems (Field 7)** (`teacher_support`, Select One, Optional): Select the teacher support system that best describes the support provided to the student.
* **Other Teacher Support System (Field 8)** (`teacher_support_other`, Text, Optional): If the teacher has any other support system that is not listed, please specify it here.
* **Student Support Systems (Field 9)** (`student_support`, Select Multiple, Optional): Select the student support system that best describes the support provided to the student.
* **Other Student Support System (Field 10)** (`student_support_other`, Text, Optional): If the student has any other support system that is not listed, please specify it here.
* **Teacher Comments (Field 11)** (`teacher_comments`, Text, Optional): Please provide any comments or feedback from the teacher.
* **Student Comments (Field 12)** (`student_comments`, Text, Optional): Please provide any comments or feedback from the student.
* **School ID (Field 13)** (`school_id`, Number, Optional): Enter the school ID number.
* **Grade Level (Field 14)** (`grade_level`, Number, Optional): Enter the grade level of the student.
* **Student Retention Date (Field 15)** (`student_retention_date`, Date, Required): Select the date of student retention.
* **Teacher Survey Date (Field 16)** (`teacher_survey_date`, Date, Required): Select the date of teacher survey.
