# Extracurricular Stipend Survey - Help Guide

## Purpose

The Extracurricular Stipend Survey is a form designed to collect information about the extracurricular stipends provided by schools to their students. This form will help us understand the types of extracurricular activities and advisors supported by schools, which will inform our decisions on future stipend programs.

## How To Complete This Form

To complete this form, please follow these steps:

1. Select the relevant options for each field, based on your school's extracurricular activities and stipend policies.
2. Fill out the required fields, marked with an asterisk (\*).
3. Enter any additional comments or notes in the designated fields.

## Field-by-Field Explanation

* **School Club Advisors** (`school_club_advisors`):
	+ This field is used to list the advisors for the school's extracurricular activities. Please provide a list of the names and titles of the advisors.
* **Mentors** (`mentors`):
	+ This field is used to select the number of mentors available for the extracurricular activities. Please select the number that best represents your school's situation.
	+ Options: 1, 2, or 3 mentors
* **Spring Coaches** (`spring_coaches`):
	+ This field is used to select the number of spring coaches available for the extracurricular activities. Please select the number that best represents your school's situation.
	+ Options: 1, 2, or 3 spring coaches
* **Extracurricular Activities** (`extracurricular_activities`):
	+ This field is used to select the types of extracurricular activities offered by your school. Please select all the activities that apply.
	+ Options: 1, 2, or 3 activities
* **Stipend Amount** (`stipend_amount`):
	+ This field is used to enter the stipend amount provided to students for extracurricular activities. Please enter a number.
* **Stipend Frequency** (`stipend_frequency`):
	+ This field is used to select the frequency of stipend payments. Please select one of the following options:
	+ 1: Monthly
	+ 2: Quarterly
	+ 3: Semesterly
* **Stipend Payout Method** (`stipend_payout_method`):
	+ This field is used to select the method of stipend payment. Please select one of the following options:
	+ 1: Cheque
	+ 2: Direct Deposit
	+ 3: Electronic Transfer
* **Payment Method** (`payment_method`):
	+ This field is used to enter the method of payment used for stipends. Please enter a text description of the payment method used by your school.
* **Notes** (`notes`):
	+ This field is used to enter any additional notes or comments about the extracurricular stipends provided by your school.
* **Email** (`email`):
	+ This field is used to enter the contact email of the person responsible for managing extracurricular stipends.
* **Phone** (`phone`):
	+ This field is used to enter the contact phone number of the person responsible for managing extracurricular stipends.
* **Time** (`time`):
	+ This field is not applicable for this form.
* **Date** (`date`):
	+ This field is not applicable for this form.
* **Extra Comments** (`extra_comments`):
	+ This field is used to enter any additional comments or notes about the extracurricular stipends provided by your school.
* **Additional Notes** (`additional_notes`):
	+ This field is used to enter any additional notes or comments about the extracurricular stipends provided by your school.
