# School Cheating Survey - Help Guide
## Purpose
This form is designed to gather information from students about their experiences with cheating in schools. It aims to understand the frequency and nature of cheating behavior among students. This information will be used to inform strategies to prevent and address cheating in educational settings.

## How To Complete This Form
To complete this form, please follow these steps:

1. Answer each question in the space provided.
2. Ensure you provide as much detail as possible in your responses.
3. If you are unsure about the purpose of any question, refer to the field-by-field explanation below for further guidance.

## Field-by-Field Explanation

- **What is the name of the student?** (`student_survey`, text, required: false): This field asks for the name of the student being surveyed.
  Please provide the student's full name as they are known in the school.
  This information will be used to identify the student and their experiences.

- **Student name** (`student_name`, text, required: false): This field is for additional information or clarification about the student's name.
  You may use this field if the student's name is not well-known or has a nickname.
  Provide any relevant details that will help identify the student.

- **What is the name of the teacher?** (`teacher_survey`, text, required: false): This field asks for the name of the teacher involved in the cheating incident.
  Please provide the teacher's full name as they are known in the school.
  This information will be used to identify the teacher and their role in the incident.

- **Class name** (`class_name`, text, required: false): This field is for additional information or clarification about the class involved.
  You may use this field if the class name is not well-known or has a nickname.
  Provide any relevant details that will help identify the class.

- **Student ID** (`student_id`, number, required: false): This field asks for the student's identification number.
  Please provide the student's ID if it is available.
  This information will be used to cross-check the student's identity.

- **Student age** (`student_age`, number, required: false): This field asks for the age of the student.
  Please provide the student's age as accurately as possible.
  This information will be used to understand the student's development stage.

- **Teacher ID** (`teacher_id`, number, required: false): This field asks for the teacher's identification number.
  Please provide the teacher's ID if it is available.
  This information will be used to cross-check the teacher's identity.

- **Class ID** (`class_id`, number, required: false): This field asks for the class's identification number.
  Please provide the class's ID if it is available.
  This information will be used to cross-check the class's identity.

- **Gender** (`student_gender`, text, required: false): This field asks for the student's gender.
  Please select the student's gender as accurately as possible.
  This information will be used to understand the student's demographic.

- **What is cheating?** (`cheating_what`, text, required: false): This field asks for a description of the cheating incident.
  Please provide as much detail as possible about the cheating incident.
  This information will be used to understand the nature of the cheating behavior.

## Tips

* Be honest and accurate in your responses.
* Provide any relevant supporting information or evidence that can help understand the cheating incident.
* If you are unsure about any question, please refer to the field-by-field explanation above for further guidance.
