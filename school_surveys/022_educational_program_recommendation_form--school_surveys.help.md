# educational-program-recommendation-form - Help Guide
## Purpose
The "Educational Program Recommendation Form" is designed to gather feedback and suggestions on the effectiveness and quality of our educational programs. The purpose of this form is to help us identify areas of improvement and make informed decisions about our programs.

## How To Complete This Form
To complete this form, please follow these steps:

* Please ensure that you have all necessary information and materials before starting.
* Review each page of the form, and complete each field according to the instructions provided below.

## Field-by-Field Explanation
* **Student Name**: <Student Name> (`student_name`, text, required: false): Please enter your name as it appears on your university ID or passport.
* **Program Name**: <Program Name> (`program_name`, text, required: false): Please enter the name of the program you are providing feedback on.
* **Faculty Member Name**: <Faculty Member Name> (`faculty_member_name`, text, required: false): If you have a faculty member's name, please enter it here. If not, you can leave this field blank.
* **Faculty Member Identification**: <Faculty Member Identification> (`faculty_identification`, text, required: false): Please enter any faculty member's ID or other identifying information, if available.
* **Program Satisfaction**: <Program Satisfaction> (`program_satisfaction`, select_one, required: false): Please select one of the following options to describe your overall satisfaction with the program:
	+ Excellent
	+ Good
	+ Fair
	+ Poor
* **Recommend Program**: <Recommend Program> (`recommend_program`, select_multiple, required: false): Please indicate whether you would recommend the program to others:
	+ True
	+ False
	+ Undecided
* **Comments**: <Comments> (`comments`, note, required: false): Please provide any additional comments or feedback you have about the program.
* **Email**: <Email> (`email`, email, required: false): If you would like to be contacted for further discussion, please enter your email address.
* **Phone**: <Phone> (`phone`, text, required: false): If you would like to be contacted, please enter your phone number.

Note: Please only complete this form if you have first-hand experience with the program and are providing your honest and constructive feedback.
