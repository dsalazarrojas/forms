# Language Course Evaluation Form - Help Guide
## Purpose
The Language Course Evaluation Form is designed to collect feedback and evaluations from students, teachers, and parents about a language course. It helps us to improve our language courses and provide better services to our students.

## How To Complete This Form
1. Select the category that best describes who is filling out this form:
	* Student
	* Teacher
	* Parent
2. Fill out the form carefully and truthfully.
3. Make sure to answer all required fields.

## Field-by-Field Explanation
* **language_course_evaluation_form_student** (`1`, `number`, required): This is a unique identifier for the student who is filling out this form.
* **course_title** (`2`, `text`, required): Enter the title of the language course being evaluated.
* **evaluation_date** (`3`, `date`, required): Enter the date of the evaluation in the format `YYYY-MM-DD`.
* **evaluation_time** (`4`, `time`, required): Enter the time of the evaluation in the format `HH:MM`.
* **overall_satisfaction** (`5`, `number`, required): Rate your overall satisfaction with the language course on a scale from 1 to 10.
* **language_proficiency** (`6`, `number`, required): Rate your language proficiency with the language course on a scale from 1 to 10.
* **teacher_feedback** (`7`, `text`, required): Share any feedback or comments you have for the teacher of the language course.
* **student_feedback** (`8`, `text`, required): Share any feedback or comments you have for the language course.
* **evaluation_comments** (`9`, `text`, required): Add any additional comments or feedback about the language course.
* **additional_comments** (`10`, `text`, required): Add any additional comments or feedback about the language course.
* **student_name** (`11`, `text`, optional): Enter your name if you are a student filling out this form.
* **email** (`12`, `email`, required): Enter your email address for contact purposes.
* **phone** (`13`, `text`, required): Enter your phone number for contact purposes.
* **evaluation_form_submitted_by** (`14`, `select_one`, required): Select who is submitting this form:
	+ Student
	+ Teacher
	+ Parent
* **evaluation_form_submitted_to** (`15`, `select_multiple`, required): Select who this form is submitted to:
	+ Student
	+ Teacher
	+ Parent
* **evaluation_form_language** (`16`, `select_one`, required): Select the language of the language course:
	+ English
	+ Spanish
	+ French
	+ German
	+ Chinese
* **evaluation_form_level** (`17`, `select_multiple`, required): Select the level of the language course:
	+ Beginner
	+ Intermediate
	+ Advanced
* **evaluation_form_programs** (`18`, `select_multiple`, required): Select the programs offered by the language course:
	+ Language and Culture
	+ Listening and Speaking
	+ Reading and Writing
* **evaluation_form_ages** (`19`, `select_multiple`, required): Select the age group of the students:
	+ 13-18
	+ 18-25
	+ 25-60
* **evaluation_form_days** (`20`, `select_multiple`, required): Select the days of the language course:
	+ Monday
	+ Tuesday
	+ Wednesday
	+ Thursday
	+ Friday
	+ Saturday
	+ Sunday
* **evaluation_form_hours** (`21`, `select_multiple`, required): Select the hours of the language course:
	+ 9:00-10:00
	+ 10:00-11:00
	+ 11:00-12:00
	+ 12:00-13:00
	+ 13:00-14:00
	+ 14:00-15:00
* **evaluation_form_weeks** (`22`, `select_one`, required): Select the frequency of the language course:
	+ Once
	+ Twice
	+ Three times or more
* **evaluation_form_frequency** (`23`, `select_multiple`, required): Select the frequency of the language course:
	+ Weekly
	+ Daily
	+ Monthly
* **evaluation_form_language_level** (`24`, `select_one`, required): Select the language level of the language course:
	+ Beginner
	+ Intermediate
	+ Advanced
* **evaluation_form_comments** (`25`, `text`, required): Add any additional comments or feedback about the language course.

## Tips
