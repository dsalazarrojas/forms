# School Construction Update Survey - Help Guide

## Purpose
This form is designed to collect information about school construction projects. It is intended for school administrators and authorized officials to provide updates on project status, construction suppliers, budget, and contact information.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the school project name and location from the provided options.
2. Enter the project start and end dates, if applicable.
3. Indicate whether construction suppliers are involved in the project. If yes, enter their names in the 'Construction Suppliers' field.
4. Provide information about the school's budget and authorized officials.
5. Select or enter the project status, if it is not applicable, enter 'Other' and specify the status.
6. Enter any additional comments or observations about the project.
7. Provide contact information for the school's administrators, including contact name, email, phone number, department, and position.

## Field-by-Field Explanation

* **School Project Name (1)** (`school_project_name`, required): Enter the name of the school construction project.
* **Project Location (2)** (`project_location`, select_one): Select the location of the school project from the options provided.
* **Project Start Date (3)** (`project_start_date`, date): Enter the start date of the project, if known.
* **Project End Date (4)** (`project_end_date`, date): Enter the end date of the project, if known.
* **School Administrators (5)** (`school_administrators`, text): Enter the name of the school administrators involved in the project.
* **Construction Suppliers (6)** (`construction_suppliers`, select_multiple): Select 'Yes' if construction suppliers are involved in the project. If 'No', leave blank.
* **Construction Supplier Other (7)** (`construction_suppliers_other`, text): If construction suppliers are involved and not listed in the options, enter their names here.
* **Budget Authorized Officials (8)** (`budget_authorized_officials`, text): Enter the names of the authorized officials responsible for the budget.
* **Project Status (9)** (`project_status`, select_one): Select the status of the project from the options provided. If not applicable, select 'Other' and specify the status.
* **Project Status Other (10)** (`project_status_other`, text): If project status is 'Other', enter the status here.
* **Project Comments (11)** (`project_comments`, note): Enter any comments or observations about the project.
* **Contact Email (12)** (`contact_email`, email, required): Enter the email address of the contact person.
* **Contact Phone (13)** (`contact_phone`, text, required): Enter the phone number of the contact person.
* **Contact Name (14)** (`contact_name`, text, required): Enter the name of the contact person.
* **Contact Department (15)** (`contact_department`, text, required): Enter the department of the contact person.
* **Contact Position (16)** (`contact_position`, text, required): Enter the position of the contact person.
* **Contact Office (17)** (`contact_office`, text, optional): Enter the office of the contact person.
* **Contact Ext (18)** (`contact_ext`, text, optional): Enter any additional contact information.
* **Contact Ext 2 (19)** (`contact_ext2`, text, optional): Enter any additional contact information.
* **Contact Other (20)** (`contact_other`, text, optional): Enter any other contact information.
* **School Name (21)** (`school_name`, text, required): Enter the name of the school.
* **Building Name (22)** (`building_name`, text, required): Enter the name of the building.
* **Room Name (23)** (`room_name`, text, required): Enter the name of the room.
* **Floor Number (24)** (`floor_number`, number, required): Enter the floor number of the building.
* **Floor Area (25)** (`floor_area`, number, required): Enter the floor area of the building.
