# School Extracurricular Interest Poll Form - Help Guide
## Purpose
This form is designed to help the school administration understand students' interests in various extracurricular activities. It will help them to organize relevant activities and resources to cater to students' needs.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the activities you are interested in from each category.
2. Make sure to answer each question thoroughly.
3. You can select multiple options for each category.
4. If you have any other activities not listed here that you are interested in, please use the "other_clubs" field.

## Field-by-Field Explanation
* **what_clubs_do_you_enjoy** (`clubs_interest`, select_multiple, not required): This field asks about the clubs you enjoy participating in. Select all the clubs that you have interest in.
* **favorite_sports_or_activities** (`sports_interest`, select_multiple, not required): This field asks about your favorite sports or activities. Select all the sports or activities that you enjoy or have interest in.
* **favorite_enrichment_activities** (`enrichment_interest`, select_multiple, not required): This field asks about your favorite enrichment activities. Select all the enrichment activities that you have interest in.
* **other_clubs** (`other_clubs_interest`, select_multiple, not required): If there are any other clubs or activities not listed here that you are interested in, please select them in this field.

## Tips
* Make sure to complete the form thoroughly and honestly.
* You can skip any field if you are not interested in any of the activities.
* If you have any questions or concerns, please contact the school administration.
