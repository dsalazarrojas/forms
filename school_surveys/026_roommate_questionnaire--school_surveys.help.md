# Roommate Questionnaire - Help Guide
## Purpose
The Roommate Questionnaire is a form designed to gather information about individuals in a school or shared living environment. Its purpose is to help understand the characteristics, preferences, and needs of potential roommates.

## How To Complete This Form
To complete the form, follow these steps:

1. Review each section carefully and only fill out the fields that apply to you.
2. For fields with dropdown or multiple-choice options, select the correct answer from the provided list.
3. For text fields, type your answer in the provided field.
4. Review each field carefully to ensure you are providing accurate information.
5. Once you have completed all relevant sections, submit the form.

## Field-by-Field Explanation
### Introduction
* **Introduction** (`intro`, `note`, required: false): This field is a note that serves as an introduction to the form. It is not a field to be filled out, but rather a guide to understanding the purpose of the form.

### Personal Details
* **Name** (`name`, `text`, required: false): This field is for your first name. Please type your first name in the space provided.
* **Age** (`age`, `number`, required: false): This field is for your age. Please type your age in the box.
* **Height** (`height`, `number`, required: false): This field is for your height. Please type your height in the box.

### Second Set of Information
* **Name** (`name_2`, `select_one`, required: false): This field is to select a name from the provided list. Please choose the correct name from the list.
* **Age** (`age_2`, `number`, required: false): This field is for the age of the person selected. Please type the age of the selected person.
* **Interests** (`interests_2`, `select_multiple`, required: false): This field is for the interests of the selected person. Select all that apply from the provided list.
* **Expectations** (`expectations_2`, `select_one`, required: false): This field is to select the expectations of the selected person. Choose the correct option from the list.

### Third Set of Information
* **Name** (`name_3`, `select_one`, required: false): This field is to select a name from the provided list. Please choose the correct name.
* **Age** (`age_3`, `number`, required: false): This field is for the age of the selected person. Please type the age of the selected person.
* **Interests** (`interests_3`, `select_multiple`, required: false): This field is for the interests of the selected person. Select all that apply from the provided list.
* **Expectations** (`expectations_3`, `select_one`, required: false): This field is to select the expectations of the selected person. Choose the correct option from the list.

### Contact Information
* **Email** (`email`, `email`, required: false): This field is for your email address. Please type your email address in the box.
* **Phone Number** (`phone`, `text`, required: false): This field is for your phone number. Please type your phone number in the box.
* **Address** (`address`, `text`, required: false): This field is for your address. Please type your address in the box.

### Tips
* Please review each field carefully before submitting the form to ensure accuracy.
* If you are unsure about a field, it is okay to ask for help.
* If you need to duplicate information, please fill out the form again, but make sure to clearly indicate which one is the updated version.
