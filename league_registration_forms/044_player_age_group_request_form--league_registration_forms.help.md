# Player Age Group Request Form - Help Guide

## Purpose
This form is designed to request information from players to determine their age group for registration in a league or competition.

## How To Complete This Form
1. Answer each question carefully and honestly.
2. Make sure to complete all required fields (if any).
3. If you are unsure about any question, please contact us for clarification.
4. Review your answers before submitting the form.

## Field-by-Field Explanation
### Player Age Group Request Form 1
* **Player Age Group Request Form 1** (`player_age_group_request_form_1`, text, required: false): This field is where you will enter your age group. Please enter the correct age group according to your age.
*   For example, if you are 18-24 years old, you should select "18-24".

### Player Age Group Request Form 2
* **Player Age Group Request Form 2** (`player_age_group_request_form_2`, text, required: false): This field is optional and not required. You can enter any relevant information about your age group.

### Player Age Group Request Form 3
* **Player Age Group Request Form 3** (`player_age_group_request_form_3`, select_one, required: false): This field is for indicating whether you are available to participate in the competition. Please select 'Yes' or 'No' accordingly.
*   If you select 'No', please provide a brief explanation in the optional field below.

### Player Age Group Request Form 4
* **Player Age Group Request Form 4** (`player_age_group_request_form_4`, select_multiple, required: false): This field is for indicating which type of competition you are interested in participating in. You can select multiple options.
*   Please select all the options that apply to you.

### Player Age Group Request Form 5
* **Player Age Group Request Form 5** (`player_age_group_request_form_5`, date, required: false): This field is for entering your availability date. Please select a date you are available to participate.

### Player Age Group Request Form 6
* **Player Age Group Request Form 6** (`player_age_group_request_form_6`, time, required: false): This field is for entering your availability time. Please select a time you are available.

### Player Age Group Request Form 7
* **Player Age Group Request Form 7** (`player_age_group_request_form_7`, select_one, required: false): This field is for indicating whether you have played this competition before. Please select 'Yes' or 'No' accordingly.
*   If you select 'No', please provide a brief explanation in the optional field below.

### Player Age Group Request Form 8
* **Player Age Group Request Form 8** (`player_age_group_request_form_8`, text, required: false): This field is optional and not required. You can enter any additional comments or information about yourself.
*   Please use this field to provide any relevant details about your registration.
