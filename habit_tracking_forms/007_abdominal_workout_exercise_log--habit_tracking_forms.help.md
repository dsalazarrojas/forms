# Abdominal Workout Exercise Log - Help Guide
## Purpose
This form is designed to record the details of abdominal exercises performed during a workout session, allowing for easy tracking and analysis of progress over time.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the **Name of participant** to identify the person performing the workout.
2. Enter the **Date of workout** to record the date of the session.
3. Enter the **Time of workout** (optional) to record the start and end times of the session.
4. Enter the **Total workout duration in minutes** to record the overall length of the workout.
5. Select the exercises performed and record their corresponding details:
	* Enter the **Exercise 1 - Name** to select the type of exercise performed.
	* Enter the **Exercise 1 - Number of sets** to record the number of sets completed.
	* Enter the **Exercise 1 - Reps per set (or seconds for holds)** to record the number of reps or seconds spent on each set.
6. If additional exercises were performed, select them from the options and record their details.
7. Enter the **Overall workout intensity** to rate the overall intensity of the workout.
8. Rate the **Current soreness level (1-10)** to indicate the level of soreness experienced.
9. Add any **Additional notes or observations** about the workout.

## Field-by-Field Explanation

* **Name of participant** (`participant_name`): A text field to identify the person performing the workout.
* **Date of workout** (`workout_date`): A date field to record the date of the workout.
* **Trainer name (if applicable)** (`trainer_name`): A text field for trainers or instructors to record their name if they were present during the workout.
* **Time of workout** (`workout_time`): A time field to record the start and end times of the workout (optional).
* **Total workout duration in minutes** (`total_duration_minutes`): A number field to record the overall length of the workout.
* **Exercise 1 - Name** (`exercise_1_name`): A select-one field to select the type of exercise performed.
* **Exercise 1 - Number of sets** (`exercise_1_sets`): A number field to record the number of sets completed.
* **Exercise 1 - Reps per set (or seconds for holds)** (`exercise_1_reps`): A number field to record the number of reps or seconds spent on each set.
* **Exercise 2 - Name** (`exercise_2_name`): A select-one field to select the type of exercise performed (optional).
* **Exercise 2 - Number of sets** (`exercise_2_sets`): A number field to record the number of sets completed (optional).
* **Exercise 2 - Reps per set (or seconds for holds)** (`exercise_2_reps`): A number field to record the number of reps or seconds spent on each set (optional).
* **Exercise 3 - Name** (`exercise_3_name`): A select-one field to select the type of exercise performed (optional).
* **Exercise 3 - Number of sets** (`exercise_3_sets`): A number field to record the number of sets completed (optional).
* **Exercise 3 - Reps per set (or seconds for holds)** (`exercise_3_reps`): A number field to record the number of reps or seconds spent on each set (optional).
* **Overall workout intensity** (`intensity_level`): A select-one field to rate the overall intensity of the workout.
* **Current soreness level (1-10)** (`soreness_level`): A number field to rate the level of soreness experienced.
* **Additional notes or observations** (`notes`): A text field for any additional comments or observations about the workout.

## Tips
* Make sure to enter accurate information to ensure correct tracking and analysis of progress.
* Use the form to record each workout session to monitor progress over time.
* Consider using this form for multiple workouts to track changes and trends.
