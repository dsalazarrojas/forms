# Book Entry Form - Help Guide
## Purpose
The Book Entry Form is designed to collect and store information about books in a structured and organized manner. This form helps users keep track of their reading history, book collections, and personal reading preferences.

## How To Complete This Form

1.  **Entry Date**: This field is required and should be completed with the date you are logging this book. This is the date you are submitting the entry, not the publication date of the book.
2.  **Book Title**: This field is required and should be filled with the full title of the book.
3.  **Author**: This field is required and should be completed with the full name of the book's author.
4.  **Additional Authors or Contributors**: This field is optional and should be used to list any co-authors, editors, or translators.
5.  **Publisher**: This field is optional and should be completed with the name of the book's publisher.
6.  **Publication Year**: This field is optional and should be filled with the year the book was published.
7.  **ISBN 10**: This field is optional and should be completed with the 10-digit ISBN if available.
8.  **ISBN 13**: This field is optional and should be completed with the 13-digit ISBN if available.
9.  **Number of Pages**: This field is required and should be completed with the total number of pages in the book.
10. **Book Format**: This field is required and should be selected from the provided options (Hardcover, Paperback, eBook, Audiobook, Mass Market Paperback, Trade Paperback).
11.  **Primary Genre**: This field is required and should be selected from the provided options (Fiction, Non-Fiction, Mystery, Romance, Science Fiction, Fantasy, Historical Fiction, Biography, Self-Help, Educational, Children, Young Adult).
12.  **Sub-Genre**: This field is optional and should be completed with a more specific genre category.
13.  **Book Condition**: This field is required and should be selected from the provided options (New, Like New, Very Good, Good, Fair, Poor).
14.  **How Did You Acquire This Book**: This field is required and should be selected from the provided options (Purchased New, Purchased Used, Gift, Library, Borrowed, Book Swap, Found).
15.  **Date Acquired**: This field is optional and should be completed with the date you acquired the book.
16.  **Purchase Price**: This field is optional and should be completed with the price you paid for the book.
17.  **Current Location**: This field is optional and should be completed with the current storage location of the book.
18.  **Reading Status**: This field is required and should be selected from the provided options (Not Started, Currently Reading, Completed, DNF Did Not Finish, Rereading).
19.  **Date Started Reading**: This field is optional and should be completed with the date you started reading the book.
20.  **Date Finished Reading**: This field is optional and should be completed with the date you finished reading the book.
21.  **Personal Rating**: This field is optional and should be selected from the provided options (5 Stars Excellent, 4 Stars Very Good, 3 Stars Good, 2 Stars Fair, 1 Star Poor, Not Yet Rated).
22.  **Tags or Keywords**: This field is optional and should be completed with any additional tags or keywords for organization.
23.  **Personal Notes**: This field is optional and should be used to add any additional notes about the book.

## Field-by-Field Explanation

*   **Entry Date**: Date you are logging this book.
*   **Book Title**: Full title of the book.
*   **Author**: Full name of the book's author.
*   **Additional Authors or Contributors**: List any co-authors, editors, or translators.
*   **Publisher**: Name of publisher.
*   **Publication Year**: Year the book was published.
*   **ISBN 10**: 10-digit ISBN if available.
*   **ISBN 13**: 13-digit ISBN if available.
*   **Number of Pages**: Total number of pages in the book.
*   **Book Format**: Format of this book (Hardcover, Paperback, eBook, Audiobook, etc.).
*   **Primary Genre**: Main genre category (Fiction, Non-Fiction, Mystery, Romance, etc.).
*   **Sub-Genre**: More specific genre category.
*   **Book Condition**: Current condition of the book (New, Like New, Very Good, etc.).
*   **How Did You Acquire This Book**: Source where you got this book (Purchased New, etc.).
*   **Date Acquired**: Date you acquired the book.
*   **Purchase Price**: Price you paid for the book.
*   **Current Location**: Where the book is currently stored.
*   **Reading Status**: Have you read this book (Not Started, Currently Reading, etc.).
*   **Date Started Reading**: Date you began reading the book.
*   **Date Finished Reading**: Date you completed reading the book.
*   **Personal Rating**: Your rating of the book.
*   **Tags or Keywords**: Additional tags for organization.
*   **Personal Notes**: Additional notes about the book.

## Tips

*   Be accurate and detailed in your input. This will ensure that the data stored in the Book Entry Form is accurate and useful.
*   Double-check your answers before submitting the form to avoid errors.
*   Use the form fields as a guideline to record and store information about your books in a structured and organized way.
