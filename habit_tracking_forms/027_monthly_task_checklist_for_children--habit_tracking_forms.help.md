# monthly_task_checklist_for_children - Help Guide
## Purpose
This form is designed to track the progress of monthly tasks for children, 
allowing parents or teachers to monitor and evaluate the completion of tasks 
over time.

## How To Complete This Form
To complete this form, follow these steps:

1. Start by selecting the tasks that need to be completed.
2. Estimate the effort required to complete each task.
3. Record any challenges that were encountered.
4. Sign and date the form to confirm completion.
5. Schedule the next review and frequency of reviews.
6. Record any review notes.

## Field-by-Field Explanation

* **Monthly Task Checklist**: 
    - This section allows you to select the tasks that need to be completed. 
    - Select all applicable tasks from the list.

    - Select High, Medium, or Low to indicate the level of effort required.
