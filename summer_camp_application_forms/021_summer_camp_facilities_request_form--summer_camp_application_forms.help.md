# Summer Camp Facilities Request Form - Help Guide
## Purpose
This form is used to request facilities at a summer camp for a specific event. Please fill out this form with the required information to help us process your request efficiently.

## How To Complete This Form
1. Fill out the form completely and accurately.
2. Provide a detailed description of the event.
3. Enter the start and end dates of the event.
4. Specify the number of guests attending the event.
5. Enter the contact information for the person submitting the form.
6. Select the facilities required for the event.
7. Add any additional notes or comments about the event.
8. Review and submit the form once complete.

## Field-by-Field Explanation

* **Summer Camp Request (summer_camp_request)**: This is the title of the event, and a brief description of what is happening at the summer camp.
* **Facilities**: Describe the facilities you are requesting to use.
* **Description (description)**: Provide a detailed description of the event, including the purpose and expectations.
* **Start Date (start_date)**: Enter the start date of the event.
* **End Date (end_date)**: Enter the end date of the event.
* **Number of Guests (number_of_guests)**: Specify the total number of guests attending the event.
* **Contact Name (contact_name)**: Enter the name of the person submitting this form.
* **Contact Email (contact_email)**: Enter the email address of the person submitting this form.
* **Contact Phone (contact_phone)**: Enter the phone number of the person submitting this form.
* **Camp Name (camp_name)**: Enter the name of the summer camp.
* **Camp Address (camp_address)**: Enter the address of the summer camp.
* **Facilities Requested (facilities_requested)**: Select the facilities you require for the event from the list below:
	+ Sports field
	+ Swimming pool
	+ Camp grounds
	+ Playground
* **Notes (notes)**: Add any additional comments or information about the event.
* **Assigned Tool (assigned_tool)**: This field is intended for internal use, please leave blank.
* **Form ID (form_id)**: This field is intended for internal use, please leave blank.
* **Output File (output_file)**: This field is intended for the output of the form, please leave blank.
