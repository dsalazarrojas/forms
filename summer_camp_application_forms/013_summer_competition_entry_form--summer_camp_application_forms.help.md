# Summer Competition Entry Form - Help Guide
## Purpose
The purpose of this form is to collect information from individuals interested in participating in the summer carnival event. It is essential to fill out the form accurately to be considered for the competition.

## How To Complete This Form
1.  Ensure you have read and agreed to the Terms and Conditions before proceeding.
2.  Select "Yes" or "No" for the events you would like to participate in:
   a.  Event 1
   b.  Event 2
3.  Review the form before submitting to ensure you have filled out all required fields and made the correct selections for the events.
4.  Submit the form for processing.

## Field-by-Field Explanation
### Summer Competition Entry Form
*   **Summer Competition Entry Form** (`title`, `text`, required): This field is a brief title of the form. Please ensure it is filled out accurately as it serves as a header for the form.

### Event 1
*   **Event 1** (`event_1`, `select_multiple`, required: false): Select "Yes" if you would like to participate in Event 1. You can choose to participate in multiple events, so feel free to select "Yes" for more than one event if applicable.
*   **Event 2** (`event_2`, `select_multiple`, required: false): Select "Yes" if you would like to participate in Event 2. You can choose to participate in multiple events, so feel free to select "Yes" for more than one event if applicable.

### Terms and Conditions
*   **Terms and Conditions** (`terms_and_conditions`, `note`, required: true): This field contains the terms and conditions of the competition. Please read it carefully and select "I have read and agreed to the Terms and Conditions" if you have understood the terms and conditions. If you have any questions, please contact the event administrators before proceeding.

## Tips
*   Please ensure you have filled out all required fields and made the correct selections for the events you would like to participate in.
*   If you have any questions or concerns, please contact the event administrators.
*   This form is intended to prevent duplicate entries, so please fill it out accurately to avoid delays in processing your application.
