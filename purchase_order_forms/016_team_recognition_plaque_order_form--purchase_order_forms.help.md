# Team Recognition Plaque Order Form - Help Guide
## Purpose
This form is used to order a team recognition plaque, a physical award that is meant to be a token of appreciation for a team or group.

## How To Complete This Form
1. Enter the name of the team being recognized.
2. Enter the name of the team leader.
3. Enter the contact email address of the person filling out the form.
4. Choose a payment method (Stripe or PayPal).
5. Select the size of the team being recognized (Large, Medium, or Small).
6. Select the size of the plaque you would like to order (2x4, 3x5, or 4x6).
7. Select the material of the plaque you would like (Aluminum, Stainless Steel, or Wood).
8. If you would like to include a message on the plaque, enter it in the text field.

## Field-by-Field Explanation

* **Team Name** (`team_name`, Text, Required): Enter the name of the team being recognized.
* **Team Leader's Name** (`team_leader_name`, Text, Optional): Enter the name of the team leader, if desired.
* **Contact Email** (`contact_email`, Email, Required): Enter the email address of the person filling out the form.
* **Payment Method** (`payment_method`, Select One, Required): Choose whether to pay with Stripe or PayPal.
* **Team Size** (`team_size`, Select One, Required): Select the size of the team being recognized (Large, Medium, or Small).
* **Team Size Other** (`team_size_other`, Text, Optional): Enter a custom team size if it is not listed in the options.
* **Plaque Size** (`plaque_size`, Select One, Required): Select the size of the plaque you would like to order (2x4, 3x5, or 4x6).
* **Plaque Material** (`plaque_material`, Select One, Required): Select the material of the plaque you would like (Aluminum, Stainless Steel, or Wood).
* **Message for Plaque** (`message_for_plaque`, Text, Optional): Enter a message to be included on the plaque, if desired.
