# Corporate Stationery Order Form - Help Guide
## Purpose
This form is designed to collect information for the corporate stationery order. Please ensure you have the authority to order stationery on behalf of your department before filling out this form. This form should only be used once per order, so please do not submit multiple forms for a single order.

## How To Complete This Form
Before filling out this form, ensure you have all the necessary information ready. To begin, select the department for which you are ordering stationery. Then, select the type of stationery you need. Please choose one or more from the options provided.

## Field-by-Field Explanation
* **Order Details (`order_details`, text, optional)**: Use this field to provide a brief description of your stationery order. Please provide any relevant details about the quantity, size, and color of stationery you are ordering.
* **Department (`department_ordering`, select, optional)**: Select the department for which you are ordering stationery. This will help ensure that the stationery is ordered correctly and delivered to the right team.
	+ Options: Marketing, Sales, Support
* **Stationery Type (`stationery_type`, select multiple, optional)**: Select the type(s) of stationery you need. You can choose one or more from the options provided.
	+ Options: Paper, Pen, Pencil
