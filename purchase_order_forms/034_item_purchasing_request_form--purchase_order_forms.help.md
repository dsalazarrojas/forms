# Item Purchasing Request Form - Help Guide
## Purpose
The Item Purchasing Request Form is used for internal teams to request items. Fill it out completely and accurately to ensure a smooth purchasing process.

## How To Complete This Form

1. Fill in the **Item Purchaser** field with the name of the person or team who needs to purchase or use the item.
2. In the **Contact Info** field, select how the item will be used (by the item purchaser or another item purchaser).
3. In the **Item Details** field, describe the item you are requesting (e.g., quantity, model, color).
4. Enter the **Request Date** when you need the item, using the date format MM/DD/YYYY.
5. In the **Price Info** field, provide any relevant pricing information (e.g., budget, budget source).
6. If additional details are required, provide them in the **Further Details** field.

## Field-by-Field Explanation

* **Item Purchaser** (`item_purchaser`, text, optional): The name of the person or team requesting the item.
* **Contact Info** (`contact_info`, select_one, optional, Item Purchaser / Another Item Purchaser): Indicate who will be using or responsible for the item purchased (either the item purchaser or another item purchaser).
* **Item Details** (`item_details`, text, optional): A detailed description of the item being requested (e.g., quantity, model, color).
* **Request Date** (`request_date`, date, optional): The date when you need the item, in the format MM/DD/YYYY.
* **Price Info** (`price_info`, text, optional): Any relevant pricing information (e.g., budget, budget source).
* **Further Details** (`further_details`, text, optional): Any additional information that might be helpful for the purchasing process.

## Tips
* Fill out the form accurately and completely to ensure a smooth purchasing process.
* Check if a similar request for the same item is already in the system before submitting another one to avoid duplication.
* If you need help or have questions, contact the system administrators at form@gic.mx.
