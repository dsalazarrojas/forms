# Art Gallery Exhibition Supplies Order Form - Help Guide

## Purpose
The Art Gallery Exhibition Supplies Order Form is used to place orders for exhibition supplies, such as wall paint, display cases, pedestals, lighting equipment, signage, security equipment, packing materials, installation tools, cleaning supplies, and more. This form will guide you through the process of ordering the necessary supplies for your exhibition.

## How To Complete This Form

### Step 1: Enter Basic Information
* **Order Date** (`order_date`): The date of order submission, in the format YYYY-MM-DD.
* **Exhibitor Name** (`exhibitor_name`): The name of the exhibitor or artist.
* **Gallery Name** (`gallery_name`): The name of the gallery.
* **Contact Email** (`contact_email`): The email address used for order confirmation.
* **Contact Phone** (`contact_phone`): The phone number for contact purposes.

### Step 2: Specify Exhibition Details
* **Exhibition Name** (`exhibition_name`): The name of the exhibition.
* **Exhibition Dates** (`exhibition_dates`): The start and end dates of the exhibition.
* **Delivery Date Needed** (`delivery_date_needed`): The date when supplies are needed.

### Step 3: Select Supplies and Equipment
* **Wall Paint** (`wall_paint`): The quantity of wall paint needed (optional).
* **Paint Color** (`paint_color`): The preferred paint color (optional).
* **Hanging System** (`hanging_system`): Select the type of hanging system needed (Wire and Hooks, Track System, Standalone Pedestals, Wall Mounts, or None Needed).
* **Display Cases** (`display_cases`): The number of display cases needed (optional).
* **Pedestals** (`pedestals`): The number of pedestals needed (optional).
* **Pedestal Height** (`pedestal_height`): The preferred pedestal height (optional).

### Step 4: Additional Services and Supplies
* **Lighting Equipment** (`lighting_equipment`): Select the lighting equipment needed (Track Lights, Spotlights, LED Panels, Display Case Lighting, Floor Lamps, or None Needed).
* **Signage Needed** (`signage_needed`): Select the signage items needed (Exhibition Title Sign, Artist Name Plates, Artwork Labels, Directional Signs, Price Tags, or None Needed).
* **Security Equipment** (`security_equipment`): Select the security equipment needed (Display Case Locks, Alarm Sensors, Security Cameras, Rope Barriers, Security Tags, or None Needed).
* **Packing Materials** (`packing_materials`): Select the packing materials needed (Bubble Wrap, Foam Sheets, Art Boxes, Packing Tape, Labels, or None Needed).
* **Installation Tools** (`installation_tools`): Select the installation tools needed (Drill, Level, Measuring Tape, Screwdrivers, Hammer, Ladder, or None Needed).
* **Cleaning Supplies** (`cleaning_supplies`): Select the cleaning supplies needed (Glass Cleaner, Microfiber Cloths, Dusters, Vacuum, or None Needed).

### Step 5: Confirm Order Details
* **Quantity Description** (`quantity_description`): Describe the quantities for selected items (optional).
* **Special Requirements** (`special_requirements`): Enter any special requirements or custom needs (optional).
* **Installation Help** (`installation_help`): Indicate if installation assistance is needed (Yes - Full Installation, Yes - Partial Installation, or No - Self Install).
* **Budget Estimate** (`budget_estimate`): Select an estimated budget for the order (Under $500, $500-$1,000, $1,000-$2,500, $2,500-$5,000, or Over $5,000).
* **Payment Method** (`payment_method`): Select the payment method (Credit Card, Invoice, Purchase Order, Check, or Other).
* **Purchase Order Number** (`purchase_order_number`): Enter the PO number if applicable.
* **Additional Comments** (`additional_comments`): Enter any other information or comments.

## Tips
* Ensure that all required fields are completed accurately and thoroughly.
* Review and double-check the order before submission.
* If unsure about any field, refer to the relevant department or contact for clarification.
* If you have any additional comments or special requirements, please enter them in the "Additional Comments" field.
