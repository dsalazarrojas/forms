# Voucher Check Request Form - Help Guide
## Purpose
The Voucher Check Request Form is used to create a voucher check request, which is used to request a voucher for a specific reason.

## How To Complete This Form
To complete the form, follow these steps:

1. **Enter the title of the voucher check request** (Voucher Check Request Form): Enter a brief description of the voucher check request.
2. **Select the category of the voucher** (Voucher Category): Choose the category that best fits the voucher being requested.
3. **Describe the voucher** (Voucher Description): Enter a brief description of the voucher.
4. **Enter the date for the voucher** (Date): Enter the date for which the voucher is being requested.
5. **Enter the time for the voucher** (Time): Enter the time for which the voucher is being requested.
6. **Enter the amount of the voucher** (Amount): Enter the total amount of the voucher.
7. **Select the currency of the voucher** (Currency): Choose the currency that the voucher will be paid in.
8. **Enter the currency symbol of the voucher** (Currency Symbol): Enter the symbol of the currency chosen in the previous step.

## Field-by-Field Explanation
* **Voucher Check Request Form (form_title)**: Enter a brief description of the voucher check request.
* **Voucher Category (form_category)**: Choose the category that best fits the voucher being requested.
	+ Options: Option 1, Option 2, Option 3
* **Voucher Description (form_description)**: Enter a brief description of the voucher.
* **Date (form_date)**: Enter the date for which the voucher is being requested. Format: YYYY-MM-DD.
* **Time (form_time)**: Enter the time for which the voucher is being requested. Format: HH:MM AM/PM.
* **Amount (form_amount)**: Enter the total amount of the voucher.
* **Currency (form_currency)**: Choose the currency that the voucher will be paid in.
	+ Options: Option 1, Option 2, Option 3
* **Currency Symbol (form_currency_symbol)**: Enter the symbol of the currency chosen in the previous step.
