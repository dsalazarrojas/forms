# Purchase Order History Report Request Form - Help Guide
## Purpose
This form is used to request historical data from the Purchase Order History Report for a specific subset of customers. Fill out this form to collect information from customers and receive a report on their purchase orders.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill out all relevant fields with the customer's information.
2. Provide the purchase order ID for the specific orders you would like to see the report for.
3. Choose the start and end dates of the report period.
4. Review and submit the form.

## Field-by-Field Explanation
* **Purchase Order History Report Request Form** (`form_start`): This is the header of the form, which is not editable.
* **Customer Information** (`customer_info`): Please provide the customer's name, contact number, and email address.
* **Purchase Order ID** (`purchase_order_id`): Enter the ID of the purchase order for which you would like to see the report.
* **Report Start Date** (`report_start_date`): Enter the start date of the report period.
* **Report End Date** (`report_end_date`): Enter the end date of the report period.
* **Customer Name** (`customer_name`): Enter the customer's name.
* **Contact Number** (`contact_number`): Enter the customer's contact number.
* **Email** (`email`): Enter the customer's email address.
* **Purchase Order Date** (`purchase_order_date`): Enter the date of the purchase order.
* **Purchase Order Amount** (`purchase_order_amount`): Enter the total amount of the purchase order.
* **Tips**: Please note that this form should not be filled out for every single purchase order, as it can be seen as an abuse of the system. If you need to see multiple reports, please contact our support team to discuss alternative options.
