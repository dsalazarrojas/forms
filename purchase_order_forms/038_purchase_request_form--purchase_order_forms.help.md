# Purchase Request Form - Help Guide
## Purpose
The Purchase Request Form is used to collect information for internal purchase requests within the organization.

## How To Complete This Form
1. Fill out the form completely and accurately.
2. Provide all required fields (marked as "required" in the form).
3. Ensure that all fields are up-to-date and accurate.
4. Submit the form.

## Field-by-Field Explanation

* **Purchase Date (page 2, field 2)**: A field to input the date of the purchase request. Please enter the date in the correct format (e.g., YYYY-MM-DD).
* **Purchase Time (page 2, field 3)**: A field to input the time of the purchase request. Please enter the time in the correct format (e.g., 12:00).
* **Purchase Amount (page 2, field 4)**: A field to input the amount of the purchase request. Please enter a numeric value.
* **Requester (page 2, field 6)**: The field to input the person making the purchase request.
* **Request Type (page 2, field 7)**: A field to select the type of request (Item or Service).
* **Itemized List (page 2, field 8)**: A field to select multiple items for the purchase request. Please choose from the available options.
* **Email (page 2, field 9)**: The field to input the email address of the requester.
* **Phone (page 2, field 10)**: The field to input the phone number of the requester.
* **Department (page 2, field 11)**: A field to select the department making the purchase request. Please choose from the available options.
* **Request Status (page 2, field 12)**: A field to select the status of the request (New, Approved, or Denied).
* **Comments (page 2, field 13)**: A field to input any additional comments about the purchase request.
* **Attachments (page 2, field 14)**: A field for uploading attachments related to the purchase request.
* **Submitter (page 3, field 15)**: The field to input the name of the person submitting the purchase request.
* **Submitter Department (page 3, field 16)**: A field to select the department of the person submitting the purchase request. Please choose from the available options.
* **Submitter Email (page 3, field 17)**: The field to input the email address of the person submitting the purchase request.
* **Submitter Phone (page 3, field 18)**: The field to input the phone number of the person submitting the purchase request.
* **Submitter Job Title (page 3, field 19)**: The field to input the job title of the person submitting the purchase request.
* **Submitter Company (page 3, field 20)**: The field to input the company name of the person submitting the purchase request.
* **Submitter Address (page 3, field 21)**: The field to input the address of the person submitting the purchase request.
* **Submitter City (page 3, field 22)**: The field to input the city of the person submitting the purchase request.
* **Submitter State (page 3, field 23)**: The field to input the state of the person submitting the purchase request.
* **Submitter Postal Code (page 3, field 24)**: The field to input the postal code of the person submitting the purchase request.
* **Submitter Country (page 3, field 25)**: The field to input the country of the person submitting the purchase request.
