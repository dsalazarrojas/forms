# Fall/Winter 2020 Color Street Order Form - Help Guide
## Purpose

This form is a tool for customers to order their Fall/Winter 2020 Color Street merchandise. It will help guide the ordering process for the products you wish to purchase.

## How To Complete This Form

To use this form, follow these steps:

1. Ensure you are in the correct category for Fall/Winter 2020 products.
2. Review the form carefully before submission to ensure all required fields are completed accurately.
3. Submit the form after reviewing and completing it.

## Field-by-Field Explanation

* **Fall 2020 Line** (`fall_winter_2020_line_only`, select_multiple, optional): This field allows you to select one or more lines of Fall 2020 Color Street products. Select all that apply to your order.
* **Sets** (`sets`, select_one, optional): This field asks whether the product sets are available. Please select 'Available' if you want to purchase sets, or 'Not Available' if you do not.
* **Sets 2** (`sets_2`, select_one, optional): This field also asks whether the product sets are available. Please select 'Available' if you want to purchase sets, or 'Not Available' if you do not.
* **Sets 3** (`sets_3`, select_one, optional): Similar to the previous field, this asks whether the product sets are available. Select 'Available' if you wish to purchase, or 'Not Available' if not.
* **Sets 4** (`sets_4`, select_one, optional): This final field also asks whether product sets are available. Choose 'Available' if you want to purchase, or 'Not Available' if you do not.

## Tips

* Review your selections carefully before submission.
* Double-check that all fields are filled out accurately before submitting the form.
* If you have any questions or issues with the form, contact [form@gic.mx](mailto:form@gic.mx).
