# Yukrev Bites Order Form - Help Guide
## Purpose
This form is designed to collect information for purchase orders from customers.

## How To Complete This Form

To complete this form, please follow these steps:

1. Fill out all required fields, denoted by \* (asterisk).
2. Select the desired item from the "Item" field.
3. Choose your desired payment method from the "Payment Method" field.
4. Fill out the remaining fields as needed.

## Field-by-Field Explanation

* **Customer Name (1)**: The name of the customer placing the order. This field is required.
* **Order Date (2)**: The date the order was placed. This field is optional.
* **Order Time (3)**: The time the order was placed. This field is optional.
* **Customer Email (4)**: The email address of the customer. This field is optional.
* **Customer Phone (5)**: The phone number of the customer. This field is optional.
* **Item (6)**: Select the type of item being ordered from the dropdown menu.
* **Order Notes (7)**: Additional notes about the order. This field is optional.
* **Order Total (8)**: The total cost of the order. This field is optional.
* **Customer Address (9)**: The street address of the customer. This field is optional.
* **Customer City (10)**: The city of the customer's address. This field is optional.
* **Customer State (11)**: The state of the customer's address. This field is optional.
* **Customer Postal Code (12)**: The postal code of the customer's address. This field is optional.
* **Payment Method (13)**: Select the payment method to be used for the order. This field is required.
* **Customer Zip (14)**: The zip code of the customer's address. This field is optional.
* **Order Status (15)**: The status of the order. This field is optional and can be updated by administrators.

## Tips

* Please ensure that all required fields are completed before submitting the form.
* If you are unsure about any information, please contact your supervisor or administrator for guidance.
