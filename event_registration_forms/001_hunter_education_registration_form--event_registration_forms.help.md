# Hunter Education Registration Form - Help Guide
## Purpose
The Hunter Education Registration Form is designed to collect information from hunters for event registration purposes. This form is used to gather essential details about the hunter's identification, event participation, and contact information. Completing this form accurately and thoroughly will ensure that the hunter's registration is processed correctly and efficiently.

## How To Complete This Form
To complete this form, please follow these steps:

1. Ensure you have all the necessary information and documents required for the event.
2. Fill out the form completely and accurately.
3. Review each field carefully to ensure you are providing the correct information.

## Field-by-Field Explanation

* **Hunter ID** (`hunter_id`, `number`, required): Please enter your hunter ID number.
* **Hunter Name** (`hunter_name`, `text`, required): Enter your name as it appears on your hunter license.
* **Event ID** (`event_id`, `number`, required): Enter the event ID number assigned to this event.
* **Name on Certificate** (`hunter_name_on_certificate`, `text`, required): Enter your name as it will appear on your certificate, if applicable.
* **Hunter License Number** (`hunter_license_number`, `text`, required): Enter your hunter license number.
* **Hunter License Date** (`hunter_license_date`, `date`, required): Enter the date your hunter license was issued.
* **Hunter Edu Date** (`hunter_edu_date`, `date`, required): Enter the date you completed your hunter education course.
* **Apha ID** (`hunter_apha_id`, `text`, optional): If you have an Apha ID, please enter it.
* **Apha Class** (`hunter_apha_class`, `select_one`, optional): If you have taken an Apha class, select 'Yes' or 'No'.
* **Event Date** (`event_date`, `date`, required): Enter the date of the event you are registering for.
* **Event Start Time** (`event_start_time`, `time`, required): Enter the start time of the event.
* **Event End Time** (`event_end_time`, `time`, required): Enter the end time of the event.
* **Hunter Contact Phone** (`hunter_contact_phone`, `text`, required): Enter your phone number.
* **Hunter Road Map** (`hunter_road_map`, `text`, optional): If you have a road map, enter it here.
* **Hunter Email** (`hunter_email`, `text`, optional): If you have an email address, enter it here.
* **Hunter Educator** (`hunter_educator`, `select_multiple`, optional): If you have taken an educator class, select 'Yes' or 'No'.
* **Hunter Additional Notes** (`hunter_additional_notes`, `note`, optional): If you have any additional notes, enter them here.
* **Hunter Event Educator** (`hunter_event_educator`, `text`, required): Enter the name of the educator leading the event.
* **Hunter Event Educator Phone** (`hunter_event_educator_phone`, `text`, optional): If the event educator has a phone number, enter it here.
* **Hunter Event Educator Email** (`hunter_event_educator_email`, `text`, optional): If the event educator has an email address, enter it here.
* **Hunter Event Educator Additional Notes** (`hunter_event_educator_additional_notes`, `note`, optional): If you have any additional notes for the event educator, enter them here.
* **Hunter Additional Notes 2** (`hunter_additional_notes2`, `note`, optional): If you have any additional notes, enter them here.
* **Hunter Road Map 2** (`hunter_road_map2`, `text`, optional): If you have a second road map, enter it here.
* **Hunter Road Map 3** (`hunter_road_map3`, `text`, optional): If you have a third road map, enter it here.
