# Event Staffing Orientation Survey - Help Guide
## Purpose
This guide will walk you through the Event Staffing Orientation Survey form. It's designed to be completed by event staff who attended an event to provide feedback and comments on their experience.

## How To Complete This Form

To complete this form, simply follow the steps below:

1. Review each page of the form carefully.
2. Answer each question to the best of your ability.
3. Make sure to complete all required fields.

## Field-by-Field Explanation

- **Event Staffing Orientation** (`event_staffing_orientation_survey_page_1`): This section is for you to provide any comments or feedback about the event's staffing orientation. Please type in your thoughts, observations, or questions.
  - **Type**: A free-text field for comments.
  - **Required**: No, this field is not required.

- **Event Feedback** (`event_staffing_orientation_survey_page_2`): Please select all that apply:
  - **Type**: Select multiple options.
  - **Required**: No, this field is not required.

  - **Yes**: Select this option if you have received sufficient feedback or information about the event.
  - **No**: Select this option if you feel you did not receive enough feedback or information about the event.

- **Event Comments** (`event_staffing_orientation_survey_page_3`): This section is for you to provide any additional comments or feedback about the event. Please type in your thoughts, observations, or questions.
  - **Type**: A free-text field for comments.
  - **Required**: No, this field is not required.

- **Event Satisfaction** (`event_staffing_orientation_survey_page_4`): Please select one of the following options:
  - **Type**: Select one option.
  - **Required**: No, this field is not required.

  - **Satisfied**: Select this option if you feel you received sufficient feedback or information about the event.
  - **Dissatisfied**: Select this option if you feel you did not receive enough feedback or information about the event.

- **Event Feedback** (`event_staffing_orientation_survey_page_5`): This section is for you to provide any additional comments or feedback about the event. Please type in your thoughts, observations, or questions.
  - **Type**: A free-text field for comments.
  - **Required**: No, this field is not required.

- **Staff Feedback** (`event_staffing_orientation_survey_page_6`): Please select all that apply:
  - **Type**: Select multiple options.
  - **Required**: No, this field is not required.

  - **Yes**: Select this option if you received sufficient feedback or information from staff about the event.
  - **No**: Select this option if you did not receive enough feedback or information from staff about the event.

- **Event Comments** (`event_staffing_orientation_survey_page_7`): This section is for you to provide any additional comments or feedback about the event. Please type in your thoughts, observations, or questions.
  - **Type**: A free-text field for comments.
  - **Required**: No, this field is not required.

- **Event Satisfaction** (`event_staffing_orientation_survey_page_8`): Please select one of the following options:
  - **Type**: Select one option.
  - **Required**: No, this field is not required.

  - **Satisfied**: Select this option if you feel you received sufficient feedback or information from staff about the event.
  - **Dissatisfied**: Select this option if you did not receive enough feedback or information from staff about the event.

## Tips

- Make sure to answer all questions honestly.
- If you're unsure about any question, please feel free to ask.
- If you have any concerns or questions, please reach out to the event organizers.
