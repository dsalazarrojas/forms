# Shopping Event Registration - Help Guide
## Purpose
The Shopping Event Registration form is used to gather information about an event and its attendees. It includes fields for event title, attendee details, event date, event time, location, notes, status, shopping list, and additional event details.

## How To Complete This Form
1. Fill in the **Event Information** field with the title of the event.
2. Enter the **Attendee Name**, **Attendee Email**, and **Attendee Phone** to register the attendee.
3. Select the **Event Date** and **Event Time** for the event.
4. Enter the **Event Location** where the event will take place.
5. Add any **Event Notes** if necessary.
6. Select the current **Event Status** (Registered, Unregistered, Cancelled).
7. Provide **Attendee Details** if required.
8. Select the items on the **Shopping List** for the attendee.
9. Add any **Event Details** if necessary.
10. Choose the **Event Type** of the event.
11. Select the relevant **Event Tags** for the event.
12. Review your entries before submitting the form.

## Field-by-Field Explanation
* **Event Information (Text, Required: False)**: This is the title of the event.
* **Attendee Name (Text, Required: False)**: The name of the person attending the event.
* **Attendee Email (Email, Required: False)**: The email address of the person attending the event.
* **Attendee Phone (Text, Required: False)**: The phone number of the person attending the event.
* **Event Date (Date, Required: False)**: The date of the event.
* **Event Time (Time, Required: False)**: The time of the event.
* **Event Location (Text, Required: False)**: The location of the event.
* **Event Notes (Note, Required: False)**: Any additional notes for the event.
* **Event Status (Select One, Required: False)**: The current status of the event (Registered, Unregistered, Cancelled).
* **Attendee Details (Text, Required: False)**: Additional details about the attendee.
* **Shopping List (Select Multiple, Required: False)**: A list of items the attendee wants to purchase.
* **Event Details (Text, Required: False)**: Additional details about the event.
* **Event Type (Select One, Required: False)**: The type of the event.
* **Event Tags (Select Multiple, Required: False)**: Multiple tags assigned to the event.
* **Event Tags 2-12 (Select Multiple, Required: False)**: Multiple tags assigned to the event, with a separate field for each.
