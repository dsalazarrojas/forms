# Fashion Talent Sign Out Sheet - Help Guide
## Purpose
The Fashion Talent Sign Out Sheet is used to document the reasons for a talent's sign-out from a fashion event, such as a backstage, fittings, or studio session. This form helps to ensure that all events are properly documented and that necessary information is captured.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the reason for the talent's sign-out from the provided options (Backstage, Fittings, or Studio).
2. Enter the talent's name in the provided text field.
3. Enter the date of the event in the date field.
4. Enter the time of the event in the time field.
5. If applicable, enter the talent's agency name in the text field.
6. Add any additional notes about the event in the notes field (optional).
7. If the event took place in a location other than our studio, enter the event location in the text field (optional).
8. Enter the talent's ID number, which is used to identify them in our system (required).

## Field-by-Field Explanation

* **Sign-out Reason**: This field is used to select the reason for the talent's sign-out. Choose one of the provided options: Backstage, Fittings, or Studio.
* **Talent Name**: This field is used to enter the talent's name. Please ensure that you enter the correct name as it appears on their identification documents.
* **Event Date**: This field is used to enter the date of the event. Use the date in the format MM/DD/YYYY.
* **Event Time**: This field is used to enter the time of the event. Use the time in the format HH:MM AM/PM.
* **Talent Agency**: This field is used to enter the agency name, if applicable. If not applicable, leave this field blank.
* **Notes**: This field is used to add any additional information or comments about the event. This is optional, and you can leave it blank if not needed.
* **Event Location**: This field is used to enter the location of the event, if it took place at a location other than our studio. This field is optional and not required if the event took place in our studio.
* **Talent ID**: This field is used to enter the talent's unique ID number, which is used to identify them in our system. This field is required and must be completed for accurate tracking and reporting.
