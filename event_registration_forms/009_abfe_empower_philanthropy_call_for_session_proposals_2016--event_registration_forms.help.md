## Field-by-Field Explanation

### How To Complete This Form

1.  Review the form carefully and ensure that you have all the necessary information to complete it.
2.  Fill in the required fields (denoted by \*).
3.  Be as concise as possible while still providing the necessary details.
4.  Proofread the form for errors before submitting it.

### Field-by-Field Explanation

* **Full name of primary presenter** (`presenter_full_name`, text, *required*): This field collects the name of the primary presenter. Enter the presenter's full name as it should be displayed in the conference program.
* **Job title** (`presenter_title`, text, *required*): Enter the job title of the primary presenter.
* **Organization name** (`organization_name`, text, *required*): Enter the name of the primary presenter's organization.
* **Email address** (`presenter_email`, email, *required*): Enter the email address of the primary presenter.
* **Phone number** (`presenter_phone`, text, *required*): Enter the phone number of the primary presenter.
* **Co-presenter name (if applicable)** (`co_presenter_name`, text, *optional*): If applicable, enter the name of any co-presenters.
* **Co-presenter organization (if applicable)** (`co_presenter_organization`, text, *optional*): If applicable, enter the organization of any co-presenters.
* **Proposed session title** (`session_title`, text, *required*): Enter the proposed session title.
* **Preferred session format** (`session_format`, select_one, *required*): Select the preferred session format (e.g., Workshop, Panel Discussion, Presentation, Lightning Talk, Roundtable Discussion).
* **Which conference track does your session best fit** (`session_track`, select_one, *required*): Select the conference track where your session best fits (e.g., Grantmaking Strategies, Community Engagement, Diversity, Equity and Inclusion, Nonprofit Capacity Building, Philanthropic Innovation, Leadership Development).
* **Session description and abstract** (`session_description`, text, *required*): Provide a 200-300 word summary of the proposed session.
* **List 2-3 key learning objectives** (`learning_objectives`, text, *required*): List the 2-3 key learning objectives for attendees.
* **Intended audience** (`target_audience`, select_multiple, *required*): Select all the intended audiences for this session (e.g., Foundation Executives, Program Officers, Nonprofit Leaders, Emerging Professionals, Board Members, Community Advocates).
* **Session experience level** (`audience_experience_level`, select_one, *required*): Select the experience level of the session (e.g., Beginner, Intermediate, Advanced, All Levels).
* **Audio-visual or technology requirements** (`av_requirements`, text, *optional*): If necessary, list any audio-visual or technology requirements for the session.
* **Have you presented at a conference or event before?** (`previous_presentation_experience`, select_one, *required*): Indicate whether you have previously presented at a conference or event.
* **Brief presenter biography** (`presenter_bio`, text, *required*): Enter a brief bio of the presenter(s) in 100-150 words.
* **Any additional information or special requests** (`additional_notes`, text, *optional*): If necessary, provide any additional information or special requests for the session.

## Tips

* Ensure that you have all the necessary information to complete the form accurately.
* Proofread the form for errors before submitting it.
* If you have any questions or concerns, feel free to contact the conference organizers.
