# Cue Operator Booking Form - Help Guide
## Purpose
This form is designed to help event planners book cue operators for specific events.

## How To Complete This Form
1. Select the event date from the calendar provided.
2. Choose the event time from the options listed.
3. Fill out the event location, organizer, and venues accordingly.
4. Indicate if cue operators are present for the event by selecting 'Yes' or 'No'.

## Field-by-Field Explanation
* **Event Date** (`event_date`, date, required: false): Select the date of the event from the calendar provided.
* **Event Time** (`event_time`, time, required: false): Choose the event time from the options listed.
* **Event Location** (`event_location`, text, required: false): Enter the location of the event.
* **Event Organizer** (`event_organizer`, text, required: false): Enter the name of the event organizer.
* **Event Venues** (`event_venues`, text, required: false): Enter the venue(s) where the event will take place.
* **Cue Operators** (`cue_operators`, select_multiple, required: false): Check if cue operators are present for the event by selecting 'Yes' or 'No'.

## Tips
* Make sure to select the correct event date and time to ensure cue operators are allocated correctly.
* Be accurate when filling out the event location, organizer, and venue(s) to avoid errors.
* Remember to indicate if cue operators are present for the event to allow correct allocation.
