# Herbal Plant Exploration Registration - Help Guide
## Purpose
The purpose of this form is to register for an herbal plant exploration event. Please fill out the form to provide the necessary information for event management and participant coordination.

## How To Complete This Form
To complete this form, follow the steps below:

1. Fill out the required fields:
	* First Name: Your first name.
	* Last Name: Your last name (family name).
	* Email: Your email address for communication.
	* Phone: Your phone number for contact.
	* Event Date: The date of the event.
	* Event Time: The time of the event.
	* Group Name: The name of the group participating in the event.
	* Group Type: The type of group participating in the event.
	* Event Type: The type of event.
	* Event Leader: The person leading the event.
2. Fill out the optional field:
	* Event Description: A brief description of the event.

## Field-by-Field Explanation

### First Name
* **First Name** (Text, required): Enter your first name.

### Last Name
* **Last Name** (Text, required): Enter your family last name.

### Email
* **Email** (Email, required): Enter your email address for communication and event updates.

### Phone
* **Phone** (Text, required): Enter your phone number for contact and event reminders.

### Event Date
* **Event Date** (Date, required): Select the date of the event.

### Event Time
* **Event Time** (Time, required): Select the time of the event.

### Group Name
* **Group Name** (Text, required): Enter the name of the group participating in the event.

### Group Type
* **Group Type** (Text, required): Enter the type of group participating in the event.

### Event Type
* **Event Type** (Text, required): Enter the type of event (e.g., workshop, seminar, meeting).

### Event Leader
* **Event Leader** (Text, required): Enter the person leading the event.

### Event Description
* **Event Description** (Text, optional): Enter a brief description of the event for reference and promotion.

### Tips
* Please make sure to fill out all required fields.
* Enter accurate and up-to-date information to ensure smooth event coordination.
* If you have any questions or concerns, contact the event organizers.
