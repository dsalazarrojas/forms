# event_attendance_monitoring_form - Help Guide
## Purpose
The Event Attendance Monitoring Form is designed to collect information about event attendees. This form allows users to input event details and attendee information, as well as register the date of attendance. The form is intended to monitor and record event attendance for monitoring and analysis purposes.

## How To Complete This Form

1. Start by filling out the "Event Details" section, which includes information about the event you are attending. This section is optional but recommended for accurate event tracking.
2. Move on to the "Attendee Details" section, where you can enter information about the attendees of the event.
3. Finally, select the "Registration Date" of the event, which is the date you attended or are registering for.

## Field-by-Field Explanation
* **Event Details** (Event Details, text, optional): Enter a brief description or name of the event you are attending or monitoring.
* **Attendee Details** (Attendee Details, text, optional): Enter information about the attendees, such as names, quantities, or other relevant details.
* **Registration Date** (Registration Date, date, optional): Enter the date you attended the event or the date you are registering for the event.

## Tips
* Be sure to accurately fill out each section to ensure accurate event tracking.
* If you are unsure about a particular field, feel free to contact us at form@gic.mx.
