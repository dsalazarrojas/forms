# Urban Planning Event Registration - Help Guide
## Purpose

This form is designed to help urban planning professionals register events, conferences, and workshops in an organized and efficient manner. It gathers crucial information about the event and its participants, allowing the organizers to better understand the needs and requirements of attendees.

## How To Complete This Form

1. Fill in the event title to describe the purpose and topic of the event.
2. Enter the event date and time in the format specified.
3. If applicable, select the options for the participant's dietary preferences and food allergies.
4. Enter the participant's name, email, and phone number for contact purposes.
5. Provide details about the participant's vehicles, if applicable.
6. Add any additional notes about the event or participant.

## Field-by-Field Explanation

* **Event Name**: A brief description of the event.
* **Event Date**: The date of the event in the format specified.
* **Event Time**: The time of the event in the format specified.
* **Participant Name**: The name of the person participating in the event.
* **Participant Email**: The participant's email address for communication purposes.
* **Participant Phone**: The participant's phone number for contact.
* **Participant Diet**: Select the participant's dietary preferences (e.g., Vegetarian, Vegan, Omnivore, Pescatarian).
* **Participant Food Allergy**: Check 'Yes' if the participant has a food allergy.
* **Participant Vehicles**: Check 'Yes' if the participant has a vehicle (e.g., car, bus, bike).
* **Event Location**: A brief description of the event location.
* **Event Notes**: Additional information or comments about the event.

## Tips

* Be as detailed as possible when filling out the form.
* Review the form carefully to ensure all required fields are filled out.
* If you are unsure about any field, please contact the event organizers for clarification.
* This form is intended to be a guide for urban planning professionals, so please refer to the provided documentation for further clarification.
