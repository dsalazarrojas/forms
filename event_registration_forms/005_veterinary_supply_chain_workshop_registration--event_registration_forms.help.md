# Veterinary Supply Chain Workshop Registration - Help Guide
## Purpose
This form is designed to collect information from attendees or individuals interested in attending the Veterinary Supply Chain Workshop. The event details and attendee data will be used to manage event registration, track participation, and potentially for follow-up communication.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the **Event Details** section.
   - Select the **Event Date** for the workshop you want to attend.
   - Choose the **Start Time** and **End Time** for the event.

2. Move on to the **Event Type** section:
   - Select the type of event you are attending: **Clinic**, **Supplier**, **School**, or **Association**.

## Field-by-Field Explanation
* **Event Details** (Page 1):
  + **Event Date**: Enter the date of the event in the format mm/dd/yyyy (e.g., 01/15/2023).
  + **Start Time**: Enter the start time of the event in the format hh:mm AM/PM (e.g., 08:00 AM).
  + **End Time**: Enter the end time of the event in the format hh:mm AM/PM (e.g., 05:00 PM).
* **Event Type** (Page 2):
  + **Event Type**: Select one of the event categories:
    - **Clinic**: For events associated with a veterinary clinic or related to clinical practices.
    - **Supplier**: For events related to product or service suppliers in the veterinary supply chain.
    - **School**: For events held at or related to veterinary schools or educational institutions.
    - **Association**: For events associated with veterinary associations or related to professional groups.

## Tips
- Please double-check your input for accuracy to ensure correct event registration.
- If you have any special requests or requirements, you can include them in the **Event Details** section.
- If you have any questions or concerns, contact the event organizers using the provided contact information.
