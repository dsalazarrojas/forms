# group_class_planning_survey - Help Guide
## Purpose
This form is used to collect information for planning group classes. It's crucial to complete this form accurately to ensure the best possible outcome for your class.

## How To Complete This Form
To complete this form, follow these steps:

1. Review each section carefully to ensure you understand the purpose and requirements for each field.
2. Select the appropriate options for each field based on your needs and constraints.
3. Fill in any text fields with accurate and complete information.
4. Submit the form once you have completed all required fields.

## Field-by-Field Explanation

### **Group Class Preferences** (Group Class Preferences, Note, Required: False)
Please describe your group class preferences, if any.

### **Class Type** (Class Type, Select One, Required: False)
Select whether your class will be 'Yes' or 'No'.

### **Class Location** (Class Location, Select One, Required: False)
Select whether your class will be 'Yes' or 'No'.

### **Class Time** (Class Time, Select One, Required: False)
Select whether your class will be 'Yes' or 'No'.

### **Class Duration** (Class Duration, Select One, Required: False)
Select whether your class will be 'Yes' or 'No'.

### **Class Frequency** (Class Frequency, Select Multiple, Required: False)
Select multiple options for your class frequency.

### **Class Start Time** (Class Start Time, Select One, Required: False)
Select whether your class will be 'Yes' or 'No'.

### **Instructor Name** (Instructor Name, Text, Required: False)
Enter the name of your instructor.

### **Instructor Email** (Instructor Email, Email, Required: False)
Enter your instructor's email address.

### **Instructor Phone** (Instructor Phone, Text, Required: False)
Enter your instructor's phone number.

### **Class Start Date** (Class Start Date, Date, Required: False)
Enter the start date of your class.

### **Class End Time** (Class End Time, Time, Required: False)
Enter the end time of your class.

### **Class Location** (Class Location, Select One, Required: False)
Select whether your class will be 'Yes' or 'No'.
