# exhibition_management_training_form - Help Guide
## Purpose
The "Exhibition Management Training Form" is a tool used to collect and manage information about training sessions, participants, and events. This form is essential for event organizers to track and manage participant data, session details, and event specifics.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the correct "Event Details" page.
2. Fill in the required and optional fields as needed.
3. Move to the "Participant Info" page.
4. Complete the participant information (name, email, phone, etc.).
5. Fill in the "Training Session Details" page.
6. Complete the session details (title, description, start and end dates and times, etc.).
7. Review and submit the form.
