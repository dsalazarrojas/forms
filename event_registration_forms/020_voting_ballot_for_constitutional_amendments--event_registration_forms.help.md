# Voting Ballot For Constitutional Amendments - Help Guide
## Purpose
This form is designed to capture voting information related to constitutional amendments within an organization. It is to be used to record the voting methods used for each amendment.

## How To Complete This Form
- Start by filling in the required fields, which include "Constitutional Amendment 2", "Constitutional Amendment 4", "Event Location", etc.
- Fill in the other fields as required and according to the guidelines provided in each field's hint.
- Review the form carefully before submission to ensure all required fields are filled in correctly.
