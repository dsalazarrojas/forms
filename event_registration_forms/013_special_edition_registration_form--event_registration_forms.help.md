## Field-by-Field Explanation

* **Form Title** (`form_title`, text, required): Enter a brief title for your event registration form.
* **Event Name** (`event_name`, text, required): Enter the name of the event you're registering for.
* **Event Date** (`event_date`, date, required): Enter the date of the event.
* **Event Start Time** (`event_start_time`, time, required): Enter the start time of the event.
* **Email** (`email`, email, optional): Enter your email address, which may or may not be confirmed.
* **Email Confirmed** (`email_confirmed`, select_one, optional): Select whether your email has been confirmed.
* **Phone** (`phone`, text, optional): Enter your phone number.
* **Notes** (`notes`, note, optional): Add any additional notes about the event.
* **Event Address** (`event_address`, text, optional): Enter the address of the event location.
* **Event City** (`event_city`, text, optional): Enter the city of the event location.
* **Event State** (`event_state`, text, optional): Enter the state of the event location.
* **Event Country** (`event_country`, text, optional): Enter the country of the event location.
* **Event Zip/Postcode** (`event_zip`, text, optional): Enter the zip/postcode of the event location.
* **Event Capacity** (`event_capacity`, text, optional): Enter the expected capacity of the event.
* **Event Capacity Confirmed** (`event_capacity_confirmed`, select_one, optional): Select whether the event capacity has been confirmed.
* **Event Type** (`event_type`, text, optional): Enter the type of event.
* **Event Type Confirmed** (`event_type_confirmed`, select_one, optional): Select whether the event type has been confirmed.
* **Event Start Time (UTC)** (`event_start_time_utc`, time, optional): Enter the start time of the event in UTC (Coordinated Universal Time).
* **Earliest Event Start Time** (`event_earliest_start_time`, time, optional): Enter the earliest event start time.

This form requires the following confirmations:
*   Event Capacity
*   Event Type
*   Event Start Time (UTC)
*   Event Start Time

Please make sure to confirm these details accurately to ensure successful event registration.
