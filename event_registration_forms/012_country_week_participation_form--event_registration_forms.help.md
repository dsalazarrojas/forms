# <string> - Help Guide
## Purpose
This guide explains the "Event Registration Form" and its usage.

## How To Complete This Form
1. Start by providing the event organizer's details, including their name and email.
2. Specify the school name if relevant.
3. Choose the country focus of the event.
4. Set the start and end dates of the event.
5. Provide the event location if necessary.
6. Indicate the event organizer's availability.
7. Leave any additional notes about the event.

## Field-by-Field Explanation
* **Event Organizer's Name**: A required field for the name of the person organizing the event.
* **School Name**: The name of the school associated with the event, if applicable.
* **Event Organizer's Email**: A required field for the email address of the event's organizer.
* **Event Organizer's Phone**: An optional field for the phone number of the event's organizer.
* **Country Focus**: A select-one field to choose the country in focus for the event, with options including Afghanistan, United States, Canada, Australia, and United Kingdom.
* **Event Start Date**: A required date field to input the start date of the event.
* **Event End Date**: A required date field to input the end date of the event.
* **Event Location**: An optional field to provide the location of the event.
* **Event Organizer's Availability**: An optional multi-select field to choose the available time slots for the event's organizer.
* **Notes**: An optional field for any additional notes about the event.

## Tips
* Ensure that all required fields are filled in to successfully submit the form.
* Be mindful of the country focus selected to ensure accurate event representation.
