# Documentary Team Accommodation Form - Help Guide
## Purpose

The purpose of this form is to gather essential details about the documentary team's accommodation requirements for an event. This information will help us to arrange for their accommodations efficiently.

## How To Complete This Form

1. **Start by filling out the required fields**: Please make sure to fill out all the fields marked as "required" in the form.
2. **Enter the event name and dates**: Fill out the "Event Name" field with the name of the event you are attending, and enter the "Start Date" and "End Date" fields with the corresponding dates.
3. **Provide accommodation details**: Enter the "Accommodation Name", "Address", "City", "State", and "Post Code" for the accommodation you have chosen.
4. **Specify accommodation type**: Select the type of accommodation you have booked, such as "Hotel", "Motel", "Resort", "Hostel", or "Airbnb".
5. **Add contact information**: Enter your contact number so we can reach out to you for further arrangements.

## Field-by-Field Explanation

* **Event Name** (`event_name`, Text, Required): The name of the event you are attending.
* **Start Date** (`start_date`, Date, Required): The date you will be arriving at the accommodation.
* **End Date** (`end_date`, Date, Required): The date you will be departing from the accommodation.
* **Accommodation Name** (`accommodation_name`, Text, Required): The name of the accommodation you have booked.
* **Accommodation Type** (`accommodation_type`, Select One, Optional): The type of accommodation you have chosen. (e.g., Hotel, Motel, Resort, Hostel, Airbnb)
* **Address** (`address`, Text, Required): The address of the accommodation.
* **City** (`city`, Text, Required): The city where the accommodation is located.
* **State** (`state`, Text, Required): The state where the accommodation is located.
* **Post Code** (`post_code`, Text, Required): The postal code of the accommodation.
* **Contact Number** (`contact_number`, Text, Optional): Your contact number for any follow-up inquiries.
