# Release Form Submission - Help Guide
## Purpose
The "Release Form Submission" is a form designed to collect information from participants about their activity or event. It is required for all participants to submit the form, which will be verified and reviewed by organizers to ensure a smooth and secure event.

## How To Complete This Form
To complete the form, please follow these steps:

1. Fill in all the required fields marked with an asterisk (*) asterisk. The required fields are:
	* **Participant Name**: Enter the name of the participant, which is necessary for identification and records.
	* **Email Address**: Enter the participant's email address, which is used for communication and verification purposes.
	* **Release Date**: Enter the release date, which is the date the participant will be released from the event.
	* **Release Time**: Enter the release time, which is the time the participant will be released from the event.
2. Fill in the optional fields as needed:
	* **Participant Information**: This field is optional and can be used to provide additional information about the participant.
	* **Activity Details**: This field is optional and can be used to provide more details about the activity or event.
	* **Event Details**: This field is optional and can be used to provide more details about the event.
	* **Participant Signature**: This field is optional and can be used for the participant to sign the form.
	* **Participant Phone**: This field is optional and can be used to provide the participant's phone number.
	* **Participant Date of Birth**: This field is optional and can be used to provide the participant's date of birth.
	* **Participant Address**: This field is optional and can be used to provide the participant's address.
	* **Participant Note**: This field is optional and can be used to provide any additional notes about the participant.
3. Click on the "Submit" button to submit the form.
