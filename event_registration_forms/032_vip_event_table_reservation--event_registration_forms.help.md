# VIP Event Table Reservation - Help Guide

## Purpose
This form is designed to collect information for the VIP Event Table Reservation, allowing users to reserve a table for a special event. The form is used to gather essential details such as guest information, reservation details, and payment information.

## How To Complete This Form
To complete this form successfully, please follow these steps:

1. Fill in the required fields with accurate information.
2. Ensure that all required fields are filled in before submitting the form.

## Field-by-Field Explanation

* **Name**: Enter the name of the guest.
	+ Type: text
	+ Required: true
* **Email**: Enter the email of the guest.
	+ Type: email
	+ Required: true
* **Phone**: Enter the phone number of the guest.
	+ Type: text
	+ Required: true
* **Number of Guests**: Specify the number of guests attending the event.
	+ Type: number
	+ Required: true
* **Special Requests**: Enter any special requests or requirements for the guest.
	+ Type: text
	+ Required: false
* **Event**: Enter the event details.
	+ Type: text
	+ Required: false
* **Date**: Select the date of the event.
	+ Type: date
	+ Required: true
* **Time**: Select the time of the event.
	+ Type: time
	+ Required: true
* **Table Type**: Choose between VIP or Standard tables.
	+ Type: select_one
	+ Options: vip, standard
	+ Required: true
* **Reservation Time**: Choose a specific time slot for the reservation.
	+ Type: time
	+ Required: true
* **Payment Method**: Choose the payment method (Visa, Mastercard, or Amex).
	+ Type: select_one
	+ Options: visa, mastercard, amex
	+ Required: true
* **Payment Method Other**: Enter a different payment method (optional).
	+ Type: text
	+ Required: false
* **Confirmation Message**: This field will be populated with a confirmation message.
	+ Type: text
	+ Required: true
* **Number of Guests (VIP)**: Specify the number of guests for the VIP table.
	+ Type: number
	+ Required: true
* **Special Requests (VIP)**: Enter any special requests or requirements for the VIP table.
	+ Type: text
	+ Required: false
* **Event Date**: Select the date of the event for the VIP table.
	+ Type: date
	+ Required: true
* **Event Time**: Select the time of the event for the VIP table.
	+ Type: time
	+ Required: true
* **Table Type**: Choose between VIP or Standard tables for the VIP table.
	+ Type: select_one
	+ Options: vip, standard
	+ Required: true

## Tips

* Ensure that all required fields are filled in before submitting the form.
* Double-check the accuracy of the information entered, especially dates and times.
* For special requests or requirements, please be as detailed as possible.
* Payment information will be processed securely.
