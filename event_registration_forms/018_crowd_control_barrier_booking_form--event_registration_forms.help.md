# crowd_control_barrier_booking_form - Help Guide
## Purpose
This form is used to book and manage crowd control barrier events. It is a crucial tool for event organizers to provide necessary information about their events to the crowd control system.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the **Event Name** in the provided text field. This is the name of the event that you are booking the crowd control barrier for.
2. Select the **Event Start Date** using the date input field in the format mm/dd/yyyy. This is the date and time when the event is scheduled to start.
3. Choose the **Event Type** from the list of options provided. This could be a Ceremony, Wedding, Conference, Concert, or Other.
4. Enter the **Event Location** in the provided text field. This is the address or location of where the event is being held.
5. Enter the **Event Organizer's Name** in the provided text field. This is the name of the person or organization hosting the event.
6. Enter the **Event Organizer's Email** in the provided email input field. This is the email address of the event's contact person.
7. Enter the **Event Organizer's Phone Number** in the provided text field. This is the phone number of the event's contact person.
8. Optionally, enter any **Notes** about the event in the provided text area. This is an optional field for event organizers to provide additional information about their event.
9. Select the **Event Booking Status** from the list of options provided. This indicates whether the event is Available, Reserved, Booked, or Not Available.
10. Select the **Booking User** from the list of options provided. This is the user that is booking the event.
11. Optionally, enter any **Additional Notes** about the event in the provided text area. This is an optional field for users to provide additional information about their booking.
12. Select the **Event Booking Status** from the list of options provided. This indicates the current status of the booking.

## Field-by-Field Explanation

* **Event Name (1)**: Enter the name of the event, e.g., "John Doe's Wedding".
* **Event Start Date (2)**: Enter the date and time when the event is scheduled to start, e.g., "12/25/2024 09:00".
* **Event Type (3)**: Choose the type of event from the list, e.g., "Wedding".
* **Event Location (4)**: Enter the address or location of where the event is being held, e.g., "123 Main St, Anytown, USA".
* **Event Organizer (5)**: Enter the name of the person or organization hosting the event, e.g., "Jane Doe".
* **Event Organizer Email (6)**: Enter the email address of the event's contact person, e.g., "jane.doe@example.com".
* **Event Organizer Phone (7)**: Enter the phone number of the event's contact person, e.g., "123-456-7890".
* **Notes (8)**: Optionally, enter any additional notes about the event.
* **Event Booking Status (9)**: Select the status of the booking, e.g., "Available".
* **Additional Notes (10)**: Optionally, enter any additional notes about the booking.
* **Event Booking Status (11)**: Select the current status of the booking.
* **Booking User (12)**: Select the user who is booking the event.
* **Event Booking Status (13)**: Select the current status of the booking.
