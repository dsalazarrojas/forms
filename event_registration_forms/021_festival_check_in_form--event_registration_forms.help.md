# Festival Check In Form - Help Guide
## Purpose
The Festival Check In Form is designed to gather essential information from festival attendees, including event registration details, attendee information, and check-in information. This form is used to verify attendee identities and ensure a smooth check-in process during the event.

## How To Complete This Form
To complete the form successfully, follow these steps:

1. Start by filling in the Event Registration Form, which includes a text field for you to input your event registration details.
2. Proceed to fill in the Attendee Information section, which is a required field containing information about the attendee.
3. In the Festival Information section, select one or more options from the provided list to provide more information about the festival.
4. Finally, enter your Check In Information, which is a required date field.

## Field-by-Field Explanation
* **Event Registration Form** (`text`, Required/Optional: Optional): This field is for event registration details. Please provide your event registration information in this field.
* **Attendee Information** (`text`, Required): This field is for attendee details. Please provide accurate and complete information about the attendee.
* **Festival Information** (`select_multiple`, Required): Select one or more options from the provided list to provide more information about the festival.
* **Check In Information** (`date`, Required): Enter the date for check in. Please ensure the date is accurate and correct.

## Tips
- Be precise when filling in the Attendee Information field to avoid any issues during the check-in process.
- Select all relevant options for the Festival Information field to provide a comprehensive understanding of the attendee's festival experience.
- Double-check the Check In Information date to ensure it is correct and up-to-date.
