# Food Festival Attendance Form - Help Guide
## Purpose
The Food Festival Attendance Form is designed to collect information from event attendees. Please fill out this form to ensure a smooth and enjoyable experience at the festival.

## How To Complete This Form
1. Fill out the form with the required information.
2. Review the fields below for further clarification.

## Field-by-Field Explanation

* **Event ID** (`event_id`, number, required/optional): This field is not required for most attendees. If you need to access specific information about the festival, please provide your event ID.
* **Event Name** (`event_name`, text, **required**): Please provide the name of the event you're attending.
* **Attendee Name** (`attendee_name`, text, optional): If you want to be recognized as an attendee, please fill in your name. This is not required for most attendees.
* **Attendee Phone** (`attendee_phone`, text, optional): If you'd like to be contacted for any festival-related updates, please provide your phone number.
* **Event Date** (`event_date`, date, optional): The date of the event is usually not needed for attendees.
* **Event Time** (`event_time`, time, optional): The time of the event is not required for most attendees.
* **Food Items** (`food_items`, select_multiple, optional): Please select which food items you'd like to try during the festival.
* **Event Location** (`event_location`, text, optional): The festival location is usually provided at the event's website or in the event invitation.
* **Event Notes** (`event_notes`, note, optional): If you have any special requests or notes, please provide them here.
* **Event Email** (`event_email`, email, optional): Please do not provide your email address unless you'd like to be contacted about festival updates.
* **Assigned User** (`assigned_user`, select_one, **required**): Please select the person responsible for your event experience.
* **Event Status** (`event_status`, select_one, **required**): Please select the status of your event (pending, confirmed, or cancelled).
* **Event Organizer** (`event_organizer`, select_one, **required**): Please select who organized this event (Event Organizer One, Two, or Three).

## Tips
- Double-check your event details before filling out the form.
- If you're unsure about any field, refer to the field-by-field explanation above.
- If you have any questions, contact your event organizer.
