# Lunch And Learn Template - Help Guide
## Purpose
The Lunch And Learn Template form is designed to collect information about upcoming events, such as lunch and learn sessions, workshops, or other activities. This form is intended to provide a structured way to register events and collect relevant details.

## How To Complete This Form
To complete this form, follow the instructions below:

1. Enter your email address in the **user_email** field.
2. Enter your name in the **user_name** field.
3. Select a **date** for the event, using the date format MM/DD/YYYY.
4. Choose a **time** for the event, using the 12-hour clock format.
5. Select the **event_type** by choosing one of the options provided.
6. In the **event_type_options** field, select one of the specific event types (option 1, option 2, or option 3) that corresponds to the **event_type** selected in the previous step.
7. Provide a brief description of the event in the **event_description** field.
8. Enter the location of the event in the **event_location** field.

## Field-by-Field Explanation

* **user_email** (user_email, email, required: false): Enter your email address to be contacted for follow-up and event reminders.
* **user_name** (user_name, text, required: false): Enter your name to be listed as a participant for the event.
* **date** (date, date, required: false): Select the date of the event in the MM/DD/YYYY format.
* **time** (time, time, required: false): Choose the time of the event using the 12-hour clock format.
* **event_type** (event_type, select_one, required: false): Select the type of event (e.g., workshop, seminar, etc.).
* **event_type_options** (event_type_options, select_one, required: true): Select one of the specific event types provided, which corresponds to the **event_type** selected in the previous step.
* **event_description** (event_description, note, required: false): Provide a brief description of the event.
* **event_location** (event_location, text, required: false): Enter the location of the event.

## Tips

* Make sure to select a valid date and time for the event.
* Choose an event type that accurately represents the nature of the event.
* Be as detailed as possible in the event description.
* Enter the correct location for the event.
* If the event has specific options for the event type, please make sure to select one of them in the **event_type_options** field.
