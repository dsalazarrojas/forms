# Virtual Family Event Attendance Form - Help Guide
## Purpose
This form is designed to collect information and track updates about virtual family events, including attendee details and event status.

## How To Complete This Form

1. Fill out the event details section to provide information about the event.
2. Enter attendee information, including first name, last name, and email.
3. Track event status and updates.
4. Update your own status as an attendee.
5. Provide comments or feedback as an attendee.

## Field-by-Field Explanation

* **Event Details**
  * **Event Title**: Provide a brief title of the event.
  * **Event Start Date**: Date of the event.
  * **Event Start Time**: Time of the event.
  * **Event End Date**: Date of the event end.
  * **Event End Time**: Time of the event end.
  * **Event RSVP Count**: Number of people attending the event.
  * **Event Capacity**: Maximum number of attendees allowed.
  * **Event Comments**: Comments from event organizers.
  * **Event Status**: Current status of the event (Active, Pending, Completed).
  * **Event Status 2**: Current status of the event (Active, Pending, Completed).
  * **Event Notes 2**: Additional notes about the event.
* **Event Attendee Info**
  * **Event Attendee Info**: Information about the event attendees.
  * **Form Submitted By**: User who submitted this form.
  * **Form Submitted Date**: Date and time of form submission.
  * **Form Submitted Time**: Time of form submission.
* **Attendee Information**
  * **Attendee First Name**: First name of the attendee.
  * **Attendee Last Name**: Last name of the attendee.
  * **Attendee Email**: Email of the attendee.
  * **Attendee Phone**: Phone number of the attendee.
  * **Attendee Comments**: Comments from the attendee.
  * **Attendee Status**: Current status of the attendee (Confirmed, Pending, Not Attending).
  * **Attendee RSVP Count**: Number of times this attendee has RSVPed.
  * **Attendee Comments 2**: Comments from the attendee.
  * **Attendee Notes**: Additional notes about the attendee.
* **Event Tracking**
  * **Event Status 2**: Current status of the event.
  * **Event Notes 2**: Additional notes about the event.

## Tips

* Make sure to fill out all required fields accurately and completely.
* Use the comments section to provide any additional information or feedback.
* Review and update your information regularly to ensure it reflects your current status.
