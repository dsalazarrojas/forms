# Event Registration And Preorder Form - Help Guide
## Purpose
The Event Registration And Preorder Form is a multi-page form that collects information from users for event registration and product preorders. 

## How To Complete This Form
To complete the form, start at the beginning of the form and fill out the sections in order. Each section will be explained in further detail below. Please make sure to fill out all required fields as they are marked.

## Field-by-Field Explanation
- **Event Registration** (`event_registration_and_preorder_form_page_1`, text, required: false): This is the first section of the form where you will enter your event registration details. It is not required to fill out this section.
- **Product Preorder** (`product_preorder_form_page_2`, select_one, required: false): In this section, you will select one product from the options provided.
- **Registration Details** (`registration_details_form_page_3`, text, required: true): This section is crucial as it is a required field. Please provide your full name and any other relevant registration details you think might be useful for the event.
- **Event Details** (`event_details_form_page_4`, select_multiple, required: false): Select any event details you are interested in. You can select multiple event details.
- **Payment** (`payment_form_page_5`, number, required: true): Please enter the amount you want to pay.
- **Payment Method** (`payment_method_form_page_6`, select_one, required: false): Select the payment method of your choice. 

## Tips
- Please fill out all required fields accurately and completely.
- If you encounter any difficulties during the process, please don't hesitate to reach out to a support team member for assistance.
- Make sure to review the form carefully before submitting to avoid any errors.
