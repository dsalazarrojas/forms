# wedding-venue-check-out-form - Help Guide
## Purpose
This form is designed to aid wedding event planners in verifying the status of rental properties after an event has taken place.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter your event planner information in the first field, including your name and any relevant contact details.
2. Provide your name in the second field.
3. Describe your contact information in the third field.
4. Confirm with the venue manager in the fourth field.
5. Indicate if the rental property was returned in the fifth field.
6. Check if the rental property was damaged in the sixth field. If it was, select 'Yes' from the dropdown menu.
7. Add any additional feedback about the event or rental property in the seventh field.

## Field-by-Field Explanation

* **Event Planner Information** (`event_planner_information`, text, optional):
	+ This field is where you enter your details as the event planner, including any relevant contact information.
* **Event Planner Name** (`event_planner_name`, text, required):
	+ Please enter your name as the event planner.
* **Contact Information** (`contact_information`, text, optional):
	+ Describe any contact details you have, including phone numbers, email addresses, or other relevant contact information.
* **Venue Manager Confirmation** (`venue_manager_confirmation`, text, required):
	+ Confirm with the venue manager that they have received this form.
* **Rental Returned** (`rental_returned`, select_multiple, required):
	+ Check if the rental property was returned in good condition.
	+ If it was not returned, please select the corresponding option.
* **Rental Damaged** (`rental_damaged`, select_one, optional):
	+ Check if the rental property was damaged during the event.
	+ If it was, please select 'Yes' from the dropdown menu.
* **Feedback** (`feedback`, text, optional):
	+ Add any additional feedback or comments about the event or rental property.

## Tips
- Make sure to complete all required fields to ensure accurate submission.
- Double-check the condition of the rental property before submitting the form.
- Keep the feedback field concise and clear to facilitate efficient communication.
