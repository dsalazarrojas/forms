# Global Event Team Orientation RSVP - Help Guide
## Purpose
This form is used to register event team members for a global event team orientation. The form is designed to collect information about the team members' details, roles, session preferences, special requirements, attendance, and other relevant information.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the Event Details section with the name of the event you are attending.
2. Select your role(s) from the Roles section. This is where you indicate your position within the team.
3. Choose your session preferences from the Session Preferences section. This is where you indicate if you have any special needs or requests for the sessions.
4. Check if you have any special requirements from the Special Requirements section. This is where you can indicate if you need any specific assistance or accommodations.
5. If you are attending the event, indicate your attendance in the Attendance section. Please note that this is a required field.
6. Fill in your Roles Details if you have any specific roles-related information to share.
7. If applicable, provide the event start date in the Event Start section.

## Field-by-Field Explanation

### Event Details (Page 1)
* **Event Details** (`event_details`, text, optional): This field is used to enter the name of the event you are attending. Please type the full name of the event in the text box.

### Roles (Page 2)
* **Roles** (`roles`, select_one, optional): Select one or more of the following options:
	+ Team: You are a team member.
	+ Management: You are in a management role.
	+ Support: You are in a support role.
	+ Leadership: You are in a leadership role.
	+ Other: Select this option if your role is not listed above.

### Session Preferences (Page 3)
* **Session Preferences** (`session_preferences`, select_multiple, optional): Select all that apply:
	+ Yes: You have a specific request or need for a session.
	+ No: You do not have any special requests.

### Special Requirements (Page 4)
* **Special Requirements** (`special_requirements`, select_multiple, optional): Select all that apply:
	+ Yes: You require special assistance or accommodations.
	+ No: You do not require any special assistance or accommodations.

### Attendance (Page 5)
* **Attendance** (`attendance`, number, optional): If you are attending the event, please indicate the number of people you are attending with.

### Roles Details (Page 6)
* **Roles Details** (`roles_details`, text, optional): This field is used to enter any additional details about your roles.

### Event Start (Page 7)
* **Event Start** (`event_start`, date, optional): If you know the start date of the event, please enter it in this field.

## Tips
* Please make sure to fill out all required fields to ensure your registration is complete.
* If you are unsure about any field, please feel free to ask your event coordinator for clarification.
* If you have any other questions or concerns, please don't hesitate to reach out to us.
