# Scuba Diving Gear Checklist Form - Help Guide
## Purpose
The Scuba Diving Gear Checklist Form is used by scuba diving event organizers to collect information from attendees on their scuba diving gear.

## How To Complete This Form
1. Select all the scuba diving gear you have with you.
2. Choose the status of each equipment (New, Used, or Broken).
3. Check the equipment you are bringing.
4. Select any missing equipment you will need for the event.
5. If you have any special equipment, select it.
6. Enter any other equipment not listed.
7. Add any notes about your gear.

## Field-by-Field Explanation
* **Diving_Gear_Form**: This form collects the scuba diving gear information from the attendee. (Text field)
* **Personal_Equipment**: Choose all the scuba diving equipment you have with you. (Select multiple options)
	+ **Mask**: Select if you have a mask.
	+ **Fins Regulator**: Select if you have a regulator.
	+ ... (rest of the options)
* **Equipment_Status**: Choose the status of each equipment (New, Used, or Broken). (Select one option)
* **Checked_Equipment**: Check the equipment you are bringing with you. (Select multiple options)
* **Missing_Equipment**: Select the equipment you will need for the event but do not have. (Select multiple options)
* **Special_Equipment**: Select any special scuba diving equipment you have. (Select multiple options)
* **Other_Equipment**: If you have any other scuba diving equipment not listed, enter it here. (Text field)
* **Notes**: Add any additional notes about your scuba diving gear. (Note field)
