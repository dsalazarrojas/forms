# LinkedIn Workshop Registration - Help Guide
## Purpose
The LinkedIn Workshop Registration form is designed to collect information from attendees and event details for a workshop. The form helps event organizers gather necessary data to manage the event smoothly.

## How To Complete This Form
To complete the form, follow these steps:

1. Fill in the "Attendee Details" section with your name and any other relevant details you want to provide.
2. Select your name from the list in the "Attendee Info" section, if you see it in the list (otherwise, you can leave it blank).
3. In the "Event Details" section, provide a brief description of the event.
4. Enter the date and time of the event in the "Date and Time" section.
5. Provide any other relevant registration information in the "Registration Info" section.

## Field-by-Field Explanation
* **Attendee Details** (`Attendee Details`, text, required/optional): This section allows you to provide any additional details about yourself as an attendee.
* **Attendee Info** (`Attendee Info`, select_multiple, required/optional): This section allows you to select your name from the list of options, if it is available. If not, you can leave it blank.
* **Event Details** (`Event Details`, text, required/optional): This section is for you to describe the event you are registering for.
* **Date and Time** (`Date and Time`, date, required/optional): Enter the date and time of the event.
* **Registration Info** (`Registration Info`, text, required/optional): This section is for any additional information you want to provide about your registration.

## Tips
* Make sure to fill in all required fields to ensure successful submission.
* If you are unsure about any field, you can ask the event organizer for clarification.
* You can also contact the event organizer with any questions or concerns.
