# Race Bib Clips Collection Form - Help Guide
## Purpose
The Race Bib Clips Collection Form is designed to collect data on race bib clips, including event information, race details, and bib collection data. This form ensures that accurate and comprehensive data is collected for analysis and reporting.

## How To Complete This Form
To complete this form, please fill in the following fields:

1. **event_name** (text): Enter the name of the event you are reporting on.
2. **event_id** (number): Enter the ID number of the event.
3. **event_code** (text): Enter the code associated with the event.
4. **event_date** (date): Enter the date of the event.
5. **event_time** (time): Enter the time of the event.
6. **event_location** (text): Enter the location of the event.
7. **event_type** (select one): Select the type of event (e.g., Option 1, Option 2, or Option 3).
8. **race_name** (text): Enter the name of the race.
9. **race_id** (number): Enter the ID number of the race.
10. **race_code** (text): Enter the code associated with the race.
11. **race_date** (date): Enter the date of the race.
12. **race_time** (time): Enter the time of the race.
13. **race_location** (text): Enter the location of the race.
14. **bibs_collected** (select multiple): Select the options that apply to the bibs collected (e.g., Option 1, Option 2, or Option 3).
15. **bibs_returned** (select multiple): Select the options that apply to the bibs returned (e.g., Option 1, Option 2, or Option 3).
16. **total_bibs** (number): Enter the total number of bibs collected.
17. **returned_bibs** (number): Enter the number of bibs returned.
18. **unaccounted_bibs** (number): Enter the number of unaccounted bibs.
19. **comments** (text): Enter any additional comments about the bib collection.
20. **notes** (text): Enter any additional notes about the bib collection.
21. **race_bib_clips_returned** (select multiple): Select the options that apply to the bib clips returned (e.g., Option 1, Option 2, or Option 3).
22. **bib_returned** (select multiple): Select the options that apply to the bib returned (e.g., Option 1, Option 2, or Option 3).
23. **bib_returned_reason** (select multiple): Select the reason for returning the bibs (e.g., Option 1, Option 2, or Option 3).
