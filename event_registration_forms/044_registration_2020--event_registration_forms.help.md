# Registration 2020 - Help Guide
## Purpose
The Registration 2020 form is designed to collect registration information for events. Fill out this form to provide your personal details and event specifics.

## How To Complete This Form
1. Fill in your full name, email, and phone number on the registration form.
2. Choose the start and end dates of the event.
3. Select the start and end times of the event.
4. Provide a description of the event, if desired.
5. Review your information and submit the form.

## Field-by-Field Explanation

* **Full Name** (`name`, text, required): Enter your full name as it should appear on your event registration.
* **Email** (`email`, email, required): Enter your valid email address.
* **Phone** (`phone`, text, optional): Enter your phone number, if you want to be contacted.
* **Address** (`address`, text, optional): Enter your address, if you want to be reached.
* **Start Date** (`start_date`, date, optional): Select the start date of the event.
* **End Date** (`end_date`, date, optional): Select the end date of the event.
* **Event Start Time** (`event_start_time`, time, optional): Select the start time of the event.
* **Event End Time** (`event_end_time`, time, optional): Select the end time of the event.
* **Description** (`description`, text, optional): Provide a description of the event, if desired.
* **Event Start Date** (`event_start_date`, date, optional): Select the date the event starts.
* **Event End Date** (`event_end_date`, date, optional): Select the date the event ends.
* **Event Start Time** (`event_start_time`, time, optional): Select the start time of the event.
* **Event End Time** (`event_end_time`, time, optional): Select the end time of the event.
* **Event Description** (`event_description`, text, optional): Provide a description of the event, if desired.

Note: All fields are optional, but it's recommended to fill out all the fields for a complete event registration.
