# Roleplay Session Registration - Help Guide
## Purpose
The Roleplay Session Registration form is used to create and manage roleplay events, such as tabletop RPGs, LARPing, and similar activities. This form helps you to provide necessary details about the event, including its name, type, duration, and other relevant information to ensure a smooth and engaging experience for participants.

## How To Complete This Form
To complete this form, follow these steps:

1. **Fill out the required fields**: Make sure to complete all fields marked as "required". These fields are essential for the event to be successful and well-organized.
2. **Choose the correct event type**: Select the type of event from the list to ensure that participants understand what to expect.
3. **Enter event details**: Provide the event name, start and end dates, start and end times, event venue, session duration, and maximum number of participants.
4. **Enter contact information**: Enter the contact email and phone number for the event host or organizer.
5. **Provide guidelines**: Enter any guidelines or rules that participants should follow during the event.
6. **Enter session notes**: Add any additional notes or information about the session that will help participants understand the event better.
7. **Add additional info**: Enter any additional information that you feel is relevant to the event.

## Field-by-Field Explanation

* **Event Name**: Enter the name of the event, which will be displayed to participants and used for reference.
* **Event Type**: Select the type of event from the list provided. This helps participants understand the type of activity or game being held.
* **Start Date**: Enter the date when the event will start.
* **End Date**: Enter the date when the event will end.
* **Start Time**: Enter the start time of the event.
* **End Time**: Enter the end time of the event.
* **Event Venue**: Enter the location where the event will take place.
* **Session Duration**: Enter the duration of the event in hours or minutes.
* **Max Participants**: Enter the maximum number of participants allowed for the event.
* **Guidelines**: Enter any rules or guidelines that participants must follow during the event.
* **Event Host**: Enter the name or contact information of the event host or organizer.
* **Contact Email**: Enter the email address of the event host or organizer.
* **Contact Phone**: Enter the phone number of the event host or organizer.
* **Session Notes**: Enter any additional notes or information about the session that will help participants understand the event better.
* **Additional Info**: Enter any additional information that you feel is relevant to the event.

Note: The session notes and additional info fields are optional and can be left blank if not necessary.
