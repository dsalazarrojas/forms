# Ski Event Sponsorship Application - Help Guide
## Purpose
This form is used to collect information about a ski event sponsorship application, including the event's name, type, location, start and end dates, and website.

## How To Complete This Form

To complete this form, follow these steps:

1. Provide a clear and concise description of your event.
2. Select the type of event (Yes or No).
3. Enter the name of the event location.
4. Enter the start and end dates of the event.
5. Enter the website associated with the event.

## Field-by-Field Explanation

* **Ski Event Sponsorship Application** (`sponsorship_application`, text, required): This field is the main description of your event. Please provide a clear and concise description of your event.
* **Event Name** (`event_name`, text, optional): Enter the name of your event.
* **Event Type** (`event_type`, select_one, optional): Select the type of event (Yes or No). Please note that this field is used to categorize the event.
* **Event Location** (`event_location`, text, optional): Enter the name of the location where the event will take place.
* **Start Date** (`start_date`, date, optional): Enter the start date of the event.
* **End Date** (`end_date`, date, optional): Enter the end date of the event.
* **Event Website** (`event_website`, text, optional): Enter the website associated with the event.

* Be sure to fill out the form accurately and completely.
