# Fundraising Event Permission Form - Help Guide
## Purpose
This form is used to obtain permission for a participant to attend a fundraising event. It collects information about the participant, their contact details, and the event date and time.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill in the participant's name.
2. Select whether participant permission is obtained or not.
3. Enter the participant's contact information (phone number and email).
4. Fill in the participant's name who will be the contact person for this participant.
5. Fill in the contact person's phone number.

## Field-by-Field Explanation
### 1. Event Name
* **Event Name** (`event_name`, text, required)
	+ Please fill in the name of the event you are attending.

### 2. Participant Name
* **Participant Name** (`participant_name`, text, required)
	+ Please fill in the name of the participant.

### 3. Guardian Permission
* **Guardian Permission** (`guardian_permission`, select_one, required)
	+ Select whether participant permission is obtained or not.
	+ Options: Participant permission is not obtained., Participant permission is obtained., Unable to obtain participant permission.

### 4. Participant Contact Info
* **Participant Contact Info** (`participant_contact_info`, text, optional)
	+ Please provide any additional contact information for the participant.

### 5. Event Date
* **Event Date** (`event_date`, date, required)
	+ Please fill in the date of the event.

### 6. Event Time
* **Event Time** (`event_time`, time, required)
	+ Please fill in the time of the event.

### 7. Participant Permission Note
* **Participant Permission Note** (`participant_permission_note`, note, optional)
	+ Please add any additional notes about participant permission.

### 8. Participant Permission Details
* **Participant Permission Details** (`participant_permission_details`, text, optional)
	+ Please provide any additional details about participant permission.

### 9. Contact Person Name
* **Contact Person Name** (`contact_person_name`, text, required)
	+ Please fill in the name of the contact person.

### 10. Contact Person Phone
* **Contact Person Phone** (`contact_person_phone`, text, required)
	+ Please fill in the phone number of the contact person.

### 11. Participant Email
* **Participant Email** (`participant_email`, email, required)
	+ Please fill in the email of the participant.
