# Event Invitation Form Template - Help Guide
## Purpose
The Event Invitation Form Template is used to collect information about an event, including event details, host, location, dates and times, RSVP deadline, address, notes, dietary preferences, and RSVP status.

## How To Complete This Form

1. Fill out the "Event Details" section with the event title and a brief description of the event.
2. Enter the name and contact information of the event host in the "Event Host" field.
3. Provide the event location in the "Event Location" field.
4. Enter the start and end dates of the event in the "Event Start Date" and "Event End Date" fields.
5. Enter the start and end times of the event in the "Event Start Time" and "Event End Time" fields.
6. Set the RSVP deadline in the "RSVP Deadline" field.
7. Enter the event address in the "Event Address" field.
8. Add any additional notes about the event in the "Notes" field.
9. Choose the dietary preferences for the event (e.g. vegetarian, vegan, gluten-free) in the "Dietary Preferences" field.
10. Select the RSVP status of the event (e.g. attending, not attending, maybe attending) in the "RSVP Status" field.
11. Enter any additional event details in the "Additional Details" field.

## Field-by-Field Explanation

* **Event Details** (event_invitation_form_template): Enter a brief description of the event.
* **Event Host** (event_host): Enter the name and contact information of the person hosting the event.
* **Event Location** (event_location): Provide the physical location of the event.
* **Event Start Date** (event_start_date): Enter the date of the event.
* **Event End Date** (event_end_date): Enter the end date of the event.
* **Event Start Time** (event_start_time): Enter the start time of the event.
* **Event End Time** (event_end_time): Enter the end time of the event.
* **RSVP Deadline** (rsvp_deadline): Set the deadline for attendees to RSVP.
* **Event Address** (event_address): Enter the physical address of the event.
* **Notes** (event_notes): Add any additional notes about the event.
* **Dietary Preferences** (event_dietary_preferences): Choose the dietary preferences for the event (e.g. vegetarian, vegan, gluten-free).
* **RSVP Status** (event_rsvp): Select the RSVP status of the event (e.g. attending, not attending, maybe attending).
* **Additional Details** (event_additional_details): Enter any additional event details.

## Tips

* Ensure that all required fields are filled out before submitting the form.
* Use the template ID to track and manage event invitations.
* Review and update the form regularly to ensure that the information is accurate and up-to-date.
* Use the information collected from this form to send invitations and track RSVPs.
