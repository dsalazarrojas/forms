# dj_appointment_form - Help Guide
## Purpose
This form is for clients to book a DJ appointment or event with relevant details.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the event details, including the event type and any other relevant information in the first field.
2. Provide your email address in the second field.
3. Add the event location and any additional details about the event in the third field.
4. In the fourth field, enter your phone number for easier contact.
5. In the fifth field, select whether the event is a "Yes" or "No" event type.
6. Provide any notes or additional comments about the event in the sixth field.
7. Add any client notes about the specific event in the seventh field.
8. Indicate the DJ's availability by selecting "Yes" or "No" in the eighth field.
9. If desired, provide your scheduling preferences in the ninth field.
10. Finally, enter any additional information about the event that is not covered in the previous fields.

## Field-by-Field Explanation

* **Event Details (event_details)**: Enter a brief description of the event or booking request. This field is required.
* **Email (client_email)**: Enter your email address to be contacted about the booking and any updates or queries.
* **Location (event_location)**: This field is not required, but it's recommended that you provide the location where the event will take place for the DJ's benefit.
* **Phone (client_phone)**: Enter your phone number so the DJ can easily reach you to discuss the booking.
* **Event Type (event_type)**: Select "Yes" if this is a recurring event or "No" if it's a one-time booking.
* **Event Details (event_details)**: A note field for adding any additional comments or information about the event.
* **Client Notes (client_notes)**: A note field for you to add any specific details about the event that the DJ should know.
* **DJ Availability (dj_availability)**: Indicate if the DJ is available for the event by selecting "Yes" or "No".
* **Scheduling Preferences (scheduling_preferences)**: Enter any specific preferences for scheduling, such as time slots or availability.
* **Additional Info (additional_info)**: Enter any extra information that is not covered by the previous fields.
