# volleyball_open_gym_registration - Help Guide
## Purpose
The Volleyball Open Gym registration form allows participants to register for a volleyball session by providing essential details. This form is designed for the volleyball open gym event and should only be used for this specific event.

## How To Complete This Form
To complete this form, follow these steps:
- Click on the link to access the form.
- Fill in the Session Details page with the required information.
- Proceed to the next page for the participant's details, which includes:
  - Participant Name
  - Participant Email
  - Participant Phone
  - Session Date and Time (format: dd/mm/yyyy HH:MM am/pm)
  - Session Duration
  - Number of Participants
  - Session Notes
- Finally, provide Additional Notes and Session Notes if necessary.
- Review and submit the form.

## Field-by-Field Explanation
- **Session Details**: Enter the session information, such as date and time.
  * Label: Session Details
  * Type: text
  * Required: no
  * Hint: session_details
- **Participant Name**: Enter the name of the participant.
  * Label: Participant Name
  * Type: text
  * Required: no
  * Hint: participant_name
- **Participant Email**: Enter the participant's email address.
  * Label: Participant Email
  * Type: email
  * Required: no
  * Hint: participant_email
- **Participant Phone**: Enter the participant's phone number.
  * Label: Participant Phone
  * Type: text
  * Required: no
  * Hint: participant_phone
- **Session Date and Time**: Enter the date and time of the session (format: dd/mm/yyyy HH:MM am/pm).
  * Label: Session Date and Time
  * Type: date
  * Required: no
  * Hint: session_date_and_time
- **Session Duration**: Enter the duration of the session.
  * Label: Session Duration
  * Type: number
  * Required: no
  * Hint: session_duration
- **Number of Participants**: Enter the number of participants attending the session.
  * Label: Number of Participants
  * Type: number
  * Required: no
  * Hint: number_of_participants
- **Participant Type**: Select 'Yes' or 'No' to indicate if the participant is a member.
  * Label: Participant Type
  * Type: select_one
  * Required: no
  * Hint: participant_type
- **Additional Notes**: Add any additional comments or notes.
  * Label: Additional Notes
  * Type: note
  * Required: no
  * Hint: additional_notes
- **Session Notes**: Add any notes for the session.
  * Label: Session Notes
  * Type: note
  * Required: no
  * Hint: session_notes

## Tips
- Make sure to fill in all required fields.
- Use the correct format for the Session Date and Time field.
- If you are a member, select 'Yes' for Participant Type.
- Use the additional notes and session notes fields to provide any important details or reminders for the session.
