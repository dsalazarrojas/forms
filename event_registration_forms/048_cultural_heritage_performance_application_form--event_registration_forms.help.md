# Cultural Heritage Performance Application Form - Help Guide
## Purpose
The Cultural Heritage Performance Application Form is designed to collect event registration information for cultural heritage performances. This form helps us gather essential details about each event, including event details, date, location, and performance details. It also collects contact information for communication purposes and allows submitters to provide additional information if needed.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the event details, including the event date and location.
2. Provide performance details, including any relevant information about the event.
3. Select the correct event type from the options provided.
4. Enter your contact information (email and phone number) for us to get in touch with you.
5. Add any additional information if necessary.
6. Double-check your entries for accuracy and completeness before submitting.

## Field-by-Field Explanation
* **Event Details** (`event_details`, text, required: false): Enter a brief description of the event, including its name and nature (e.g., concert, play, dance recital).
* **Event Date** (`event_date`, date, required: false): Enter the date of the event.
* **Event Location** (`event_location`, text, required: false): Enter the venue or location where the event will take place.
* **Performance Details** (`performance_details`, text, required: false): Add any additional details about the performance, such as music type, language, or dress code.
* **Performer Details** (`performer_details`, text, required: false): If applicable, provide information about the performers, such as their names and roles.
* **Event Time** (`event_time`, time, required: false): Enter the start and end times of the event.
* **Contact Info** (`contact_info`, text, required: false): Enter your name, email, and phone number so we can get in touch with you about the event.
* **Event Type** (`event_type`, select_one, required: false): Select the type of event from the options provided (e.g., Yes, No).
* **Select Event Type** (`select_event_type`, text, required: false): This field is not currently used.
* **Performance Length** (`performance_length`, number, required: false): Enter the length of the performance in minutes or hours.
* **Performance Length Units** (`performance_length_units`, text, required: false): Specify the units for the performance length (e.g., minutes, hours).
* **Additional Info** (`additional_info`, text, required: false): Add any extra comments or notes about the event.
* **Select Additional Info** (`select_additional_info`, text, required: false): This field is not currently used.
* **Email** (`email`, email, required: false): Enter your email address.
* **Phone** (`phone`, text, required: false): Enter your phone number.
* **Confirm Phone** (`confirm_phone`, text, required: false): Confirm your phone number.
* **Submitter Info** (`submitter_info`, text, required: false): Enter a brief description of yourself.
* **Submitter Email** (`submitter_email`, email, required: false): Enter your email address.
* **Submitter Phone** (`submitter_phone`, text, required: false): Enter your phone number.
* **Confirm Submitter Email** (`confirm_submitter_email`, email, required: false): Confirm your email address.

Note: Some fields are not currently used in the form design, but it's essential to include them in the help guide for future reference and consistency.
