# Group Package Registration Form - Help Guide
## Purpose
The Group Package Registration Form is used to register a group package for an event. This form is intended for authorized users who have been granted access to create and manage event groups. It is essential to complete this form accurately and correctly to ensure that participant registration and billing are processed smoothly.

## How To Complete This Form
To complete this form, follow these steps:

1. Make sure you have been authorized to access this form.
2. Select the correct event group from the dropdown menu.
3. Fill in the participant information, including participant name and email address.
4. Provide the group details, such as any additional information about the group.
5. Select the payment method for the group (credit card or other).
6. Review and submit the form for review and processing.

## Field-by-Field Explanation
### Participant Information
* **Participant Name** (`participant_name`, text, required): Enter the name of the participant who is registering the group package. This is a required field.
* **Participant Email** (`participant_email`, email, required): Enter the email address of the participant who is registering the group package. This is a required field and must be a valid email address.

### Group Details
* **Group Details** (`group_details`, text, optional): This field is used to provide any additional information about the group, such as a description or notes.

### Payment Method
* **Payment Method** (`payment_method`, select_one, optional): Select the payment method for the group, either credit card or other. If you select "other", you will need to provide additional information about the payment method in the "Package Preferences" section.

### Package Preferences
* **Package Preferences** (`package_preferences`, text, optional): If you selected "other" as the payment method, provide any additional information about the payment method or preferences for the group.

### Tips
* Please ensure that you have entered accurate and complete information for all fields.
* Review the form carefully before submission to avoid errors and ensure correct processing.
* If you have any questions or issues with the form, contact your administrator for assistance.
