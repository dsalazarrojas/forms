# Group Fitness Class Access Form - Help Guide
## Purpose
This form is used to collect participant information for a group fitness class. It helps class organizers track participant details, access, and status.

## How To Complete This Form
To complete this form, please follow these steps:

1. Select the participant details (Participant 1, Participant 2, or Participant 3) that you want to register for the class.
2. Choose the participant's access to the class (Participant 1, Participant 2, or Participant 3).
3. Enter the class details (date) and class time.
4. Select the participant's status (Confirmed, Waiting List, or Declined).
5. Add any participant notes.
6. Enter the participant's email address.
7. Enter the participant's phone number.
8. Provide any additional information about the participant.
9. Add any additional participant notes.

## Field-by-Field Explanation
### Group Fitness Class Access Form (`group_fitness_class_access_form`, Text)
This is the main form title.

### Participant Details (`participant_details`, Select One)
* Select the participant you want to register for the class.
* Choose one of the available participants (Participant 1, Participant 2, or Participant 3).

### Participant Access (`participant_access`, Select Multiple)
* Choose the participants who will have access to the class.
* Select one or more of the available participants (Participant 1, Participant 2, or Participant 3).

### Class Details (`class_details`, Date)
* Enter the date of the class.
* Please use the format `YYYY-MM-DD`.

### Class Time (`class_time`, Time)
* Enter the time of the class.
* Please use the `HH:MM` format.

### Participant Status (`participant_status`, Select One)
* Select the participant's status.
* Choose from Confirmed, Waiting List, or Declined.

### Participant Notes (`participant_notes`, Note)
* Enter any additional notes about the participant.
* This field allows you to add any relevant information about the participant.

### Participant Email (`participant_email`, Email)
* Enter the participant's email address.
* Please use the standard email format (`name@domain.com`).

### Participant Phone (`participant_phone`, Text)
* Enter the participant's phone number.
* Please use the `XXX-XXX-XXXX` format.

### Participant Additional Info (`participant_additional_info`, Text)
* Enter any additional information about the participant.
* This field allows you to provide any other relevant details.

### Participant Additional Notes (`participant_additional_notes`, Text)
* Enter any additional notes about the participant.
* This field allows you to add any other relevant information.

## Tips
* Make sure to select the correct participant details and access.
* Double-check the class details and participant status.
* Enter accurate contact information for the participant.
* Use this form only for authorized personnel to avoid duplication of effort.
