# st_patrick_s_day_pub_crawl_sign_up_form - Help Guide
## Purpose
This form is for registering participants for the St. Patrick's Day pub crawl event. It's used by event organizers to collect necessary information from attendees.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter your start time for the event.
2. Provide your participant name and any additional name if necessary.
3. Enter your email address for contact.
4. Enter your phone number for contact.
5. Select one or multiple options for the event activities.
6. Enter the date of the event (if applicable).
7. Add any additional note or comments if needed.

## Field-by-Field Explanation
- **Start Time** (`start_time`, `time`, required/optional): Enter the time you plan to start the event.
- **Participant Name** (`participant_name`, `text`, required/optional): Enter your name or additional participant name.
- **Email** (`email`, `email`, required/optional): Enter your valid email address for event contact.
- **Phone Number** (`phone_number`, `text`, required/optional): Enter your phone number for event contact.
- **Select One** (`select_one`, `select_one`, required): Select one or multiple options for the event activities. 
- **Select Multiple** (`select_multiple`, `select_multiple`, required): Select one or multiple options for the event activities. Note: This field is similar to "Select One" but allows for multiple selections.
- **Date** (`date`, `date`, required/optional): Enter the date of the event if applicable.
- **Additional Participant Name** (`participant_name`, `text`, required/optional): Enter the name of any additional participant.
- **Note** (`note`, `note`, required/optional): Add any additional note or comments for event organizers.
