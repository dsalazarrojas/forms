# DJ Recommendation Form - Help Guide
## Purpose

The DJ Recommendation Form is used to provide a suggestion for a DJ to be booked for an event. This form should only be filled out by authorized event planners or users with access to the event's planning data.

## How To Complete This Form

1. Fill out the **Event Planner ID** field with the ID of the event planner or user who is filling out the form.
2. Enter your **Name** in the **Name** field.
3. Enter your **Email** address in the **Email** field.
4. Type in your **DJ Suggestion** for the event in the **DJ Suggestion** field.
5. Select the **Music Genre** for the event from the available options.
6. Enter the **Event Name** in the **Event Name** field.
7. Choose the **Event Date** for the event.
8. Enter the **Event Venue** (optional) and provide any additional comments in the **Note** field.

## Field-by-Field Explanation
* **Event Planner ID** (`event_planner_id`, number, required): This is a unique identifier for the event planner or user who is filling out this form. Please enter the correct ID to ensure that your submission is properly attributed.
* **Name** (`name`, text, required): This is your name and should be entered in full. This is used to address you in any further communication related to the event.
* **Email** (`email`, email, required): Please enter your email address so that we can contact you with further information about the event.
* **DJ Suggestion** (`dj_suggestion`, text, required): This is where you can type in your DJ suggestion for the event. Please provide a detailed description of the DJ's name, contact information, and any other relevant details.
* **Music Genre** (`music_genre`, select_multiple, required): Select the type of music that you would like the DJ to play during the event. Please choose as many options as applicable from the dropdown list.
* **Event Name** (`event_name`, text, required): Enter the name of the event in this field. This should be a clear and concise name that will help identify the event in our system.
* **Event Date** (`event_date`, date, required): Select the date of the event from the calendar. Please choose a date that is in the future to ensure that the event is properly scheduled.
* **Event Venue** (`event_venue`, text, optional): If applicable, enter the name and address of the event venue. This will help us to provide accurate information to the selected DJ.
* **Note** (`note`, note, optional): If you have any additional comments or information about the event, please enter them in this field. This will help us to provide better support to the selected DJ.

## Tips

* Make sure to fill out all the required fields correctly before submitting the form.
* Please select only one event planner ID per form submission.
* If you have any questions or concerns, please reach out to our event planning team for assistance.
