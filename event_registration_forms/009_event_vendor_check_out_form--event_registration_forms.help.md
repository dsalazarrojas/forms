# event-vendor-check-out-form - Help Guide
## Purpose
The "event-vendor-check-out-form" is a form used to collect information from event vendors for processing payments and other administrative tasks. This form is typically filled out by event vendors to provide details about their payments and events.

## How To Complete This Form
To complete this form, follow these steps:
1. Review the form carefully to understand what information is required and what options are available.
2. Select the appropriate payment method from the "Payment Method" dropdown.
3. Enter the correct payment amount in the "Payment Amount" field.
4. Select the payment date from the calendar picker.
5. Enter the event name and other vendor information as requested.

## Field-by-Field Explanation
* **Event Vendor Information**: This section collects general information about the event vendor.
* **Payment Method**: Select the payment method used for the transaction. This can be one of the following: Payment Option A, Payment Option B, or Payment Option C.
* **Payment Amount**: Enter the amount paid for the transaction. Note that this is a numerical field and should be free of any formatting or currency symbols.
* **Payment Date**: Select the date of the payment transaction. This is a date field and should be in the standard date format (YYYY-MM-DD).
* **Event Name**: Enter the name of the event associated with this payment.
* **Vendor Name**: Enter the name of the vendor responsible for this payment.
* **Vendor Address**: Enter the address of the vendor responsible for this payment.
* **Payment Status**: Select the status of the payment: Pending, Paid, or Overdue.
* **Payment Note**: Enter any additional notes about the payment.
* **Vendor Phone**: Enter the phone number of the vendor responsible for this payment.
* **Vendor Email**: Enter the email address of the vendor responsible for this payment.
* **Vendor Notes**: Enter any additional notes about the vendor.

## Tips
* Make sure to select the correct payment method and payment date to ensure accurate processing.
* Double-check the vendor information to ensure it matches the actual vendor's details.
* Use the "Payment Note" field to add any relevant notes or comments about the payment.
* Use the "Vendor Notes" field to add any additional information about the vendor.
