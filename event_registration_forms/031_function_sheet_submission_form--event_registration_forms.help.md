# Function Sheet Submission Form - Help Guide
## Purpose
The Function Sheet Submission Form is a tool used to submit event details to ensure accurate and efficient event management. It gathers essential information about an event, making it easier for organizers and attendees to track and follow up on event progress.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the Event Name field to provide a brief and descriptive title of the event.
2. Enter the Event Start Date and Event End Date in the respective fields using the date format MM/DD/YY or YYYY/MM/DD, depending on your preference.
3. Type in the Event Location, which is the physical location where the event will take place.
4. Provide the Event Organizer's contact information, including their name, contact information, and email address.
5. Select the Event Venues option to indicate if the event will be held at a specific venue or not.
6. Enter the Event Organizer's contact information and email address.
7. Fill in the Event Registration Start Date and Event Registration End Date, which are the dates when event registration will begin and end.
8. Select the Event Registration Status option to update the event's status.

## Field-by-Field Explanation

* **Event Name** (`event_name`, `text`, required): Enter a brief and descriptive name of the event.
* **Event Start Date** (`event_start_date`, `date`, required): Enter the start date of the event in the format MM/DD/YY or YYYY/MM/DD.
* **Event End Date** (`event_end_date`, `date`, required): Enter the end date of the event in the format MM/DD/YY or YYYY/MM/DD.
* **Event Location** (`event_location`, `text`, required): Type in the physical location where the event will take place.
* **Event Organizer** (`event_organizer`, `text`, required): Enter the name of the event organizer.
* **Event Description** (`event_description`, `text`, required): Enter a brief description of the event.
* **Event Venues** (`event_venues`, `select_multiple`, required): Select whether the event will be held at a specific venue or not.
* **Event Organizer Contact Info** (`event_organizer_contact_info`, `text`, required): Enter the contact information of the event organizer.
* **Event Organizer Email** (`event_organizer_email`, `email`, required): Enter the email address of the event organizer.
* **Event Organizer Website** (`event_organizer_website`, `text`, optional): Provide the event organizer's website, if applicable.
* **Event Registration Start Date** (`event_registration_start_date`, `date`, required): Enter the start date of event registration in the format MM/DD/YY or YYYY/MM/DD.
* **Event Registration End Date** (`event_registration_end_date`, `date`, required): Enter the end date of event registration in the format MM/DD/YY or YYYY/MM/DD.
* **Event Registration Status** (`event_registration_status`, `select_one`, required): Select the event registration status to update the event's status.
