# Highlight Request Form - Help Guide
## Purpose

The Highlight Request Form is used to submit a request for a highlight or highlight package for an event. This form should only be filled out by authorized users who have not already submitted a similar request.

## How To Complete This Form

1. Select **Submit Request**: Choose the option to submit a new request.
2. Choose the **Event Type**: Select the type of event for which you are submitting the request.
3. Enter the **Start Date** and **End Date**: Provide the dates for the event.
4. Enter the **Highlight Request**: Provide a brief description of the highlight or highlight package you are requesting.
5. Enter the **Request Description**: Provide a detailed description of the event and the highlight request.
6. (Optional) Enter the **Contact Name**, **Contact Email**, **Contact Phone**, and **Contact Address**: If you are not the main point of contact, enter your name and contact information for the person or group responsible for the event.

## Field-by-Field Explanation

* **Submit Request**: A selection to indicate whether you are submitting a new request (Yes) or not (No).
* **Event Type**: A selection of the type of event for which you are submitting the request.
* **Start Date**: A date field for the start date of the event.
* **End Date**: A date field for the end date of the event.
* **Highlight Request**: A text field for the requested highlight or highlight package.
* **Request Description**: A text field for a detailed description of the event and the highlight request.
* **Contact Name**: A text field for the name of the person or group responsible for the event (optional).
* **Contact Email**: An email field for the email address of the person or group responsible for the event (optional).
* **Contact Phone**: A text field for the phone number of the person or group responsible for the event (optional).
* **Contact Address**: A text field for the address of the person or group responsible for the event (optional).

## Tips

* Make sure to fill out all required fields to ensure that your request is successfully submitted.
* Double-check your information for accuracy to avoid errors.
* If you have any questions or concerns, contact the event organizer or administrator.
