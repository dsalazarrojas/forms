# Event Planning Contract Form - Help Guide
## Purpose
The Event Planning Contract Form is a comprehensive form used to collect information about events, including event details, client requirements, and payment terms. This form helps event planners and organizers plan and coordinate events efficiently.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the event details, including the event date and time, event duration, and event location.
2. Describe the event in detail using the event description field.
3. Specify the client's requirements and needs.
4. Choose the payment method (credit, debit, or cash) and add any additional payment terms.
5. Select the services you plan to provide (Photography, Catering, Decor, Sound System, or Music).

## Field-by-Field Explanation

* **Event Date** (`event_date`, date, required/optional): Enter the date of the event.
* **Event Time** (`event_time`, time, required/optional): Enter the time of the event.
* **Event Duration** (`event_duration`, number, required/optional): Enter the duration of the event in hours.
* **Event Location** (`event_location`, text, required/optional): Enter the location where the event will take place.
* **Event Description** (`event_description`, text, required/optional): Briefly describe the event.
* **Client Requirements** (`client_requirements`, text, required/optional): List any specific requirements the client has.
* **Payment Terms** (`payment_terms`, text, required/optional): Specify any payment terms or conditions.
* **Payment Method** (`payment_method`, select_one, required/optional): Choose how the client will pay (credit, debit, or cash).
* **Services Provided** (`services_provided`, select_multiple, required/optional): Select the services you will provide (Photography, Catering, Decor, Sound System, or Music).

## Tips

* Double-check your entries for accuracy and completeness to avoid misunderstandings.
* Make sure to review this form carefully before submitting it to ensure all required and optional fields are filled in.
* If you need help or clarification on any field, don't hesitate to ask the event planner or organizer.
