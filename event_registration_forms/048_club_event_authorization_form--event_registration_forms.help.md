# Club Event Authorization Form - Help Guide
## Purpose
The Club Event Authorization Form is used by clubs to request authorization for events, ensuring that the event complies with relevant policies and guidelines. Fill out this form to get authorization for your event.

## How To Complete This Form
To complete this form, please follow these steps:
1.  Fill out each section thoroughly and accurately.
2.  Review all fields for their respective labels and hints to ensure completeness and consistency.
3.  Submit the form for review and approval once you have filled out all required fields.

## Field-by-Field Explanation

• **Club or Organization Name** (`club_name`): Enter the name of the club hosting the event.
• **Event Organizer Name** (`event_organizer`): Enter the primary person responsible for organizing the event.
• **Event Organizer Email** (`organizer_email`): Provide the contact email of the event organizer for communication.
• **Organizer Phone** (`organizer_phone`): Enter the phone number of the event organizer for communication.
• **-- Event Details --**: This section contains information about the event.
  • **Event Name or Title** (`event_name`): Enter the name of the event.
  • **Type of Event** (`event_type`): Select the type of event from the provided options.
  • **Event Date** (`event_date`): Enter the date of the event.
  • **Event Time** (`event_time`): Enter the start time of the event.
  • **Event Duration** (`event_duration`): Enter the length of the event.
• **-- Event Location --**: This section contains location information about the event.
  • **Event Location** (`event_location`): Enter the full address or venue name of the event.
  • **Location Type** (`location_type`): Select the type of location from the provided options.
  • **Venue Contact Person** (`venue_contact`): Enter the name of the person at the venue for coordination.
• **-- Attendance Information --**: This section contains information about who will attend.
  • **Expected Number of Attendees** (`expected_attendance`): Enter an approximate number of attendees.
  • **Types of Attendees** (`attendee_types`): Select the types of attendees from the provided options.
• **-- Event Activities --**: This section contains a description of the event activities.
  • **Description of Activities** (`activity_description`): Enter a description of what attendees will do.
• **Will Alcohol Be Served** (`alcohol_service`): Select whether alcohol will be served at the event.
• **Will Food Be Served** (`food_service`): Select whether food will be served at the event.
• **-- Safety and Risk Assessment --**: This section contains safety information about the event.
  • **Potential Safety or Liability Risks** (`risk_assessment`): Enter any potential safety or liability risks.
  • **Safety Measures or Precautions** (`safety_measures`): Enter how you will ensure safety.
• **Do you request authorization for this event** (`approval_status`): Select whether you request authorization for the event.
