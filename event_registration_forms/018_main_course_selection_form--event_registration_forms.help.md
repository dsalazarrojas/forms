# Main Course Selection Form - Help Guide
## Purpose
The Main Course Selection Form is designed to collect information from users regarding their course selection preferences.

## How To Complete This Form
To complete this form, follow these steps:

1. Select your preferred Main Course from the options provided:
	* Vegetarian
	* Non-Vegetarian
	* Vegan
2. Select your preferred Second Course from the options provided:
	* Salad
	* Soup
	* Grilled Meat
3. Select your preferred Third Course from the options provided:
	* Fruit
	* Chocolate
	* Cheese
4. (Optional) If you wish to provide a Meal Time, select the time of day you would like to have the meal.
	* Note: This field is not required and only visible if you select an option for Main, Second, and Third Courses.

## Field-by-Field Explanation
### **Main Course** (`Main Course`, select_one, required: false)
This field allows you to select your preferred Main Course. Please choose one of the three options:
	* Vegetarian
	* Non-Vegetarian
	* Vegan

### **Second Course** (`Second Course`, select_one, required: false)
This field allows you to select your preferred Second Course. Please choose one of the three options:
	* Salad
	* Soup
	* Grilled Meat

### **Third Course** (`Third Course`, select_one, required: false)
This field allows you to select your preferred Third Course. Please choose one of the three options:
	* Fruit
	* Chocolate
	* Cheese

### **Meal Time** (time, required: false)
This field allows you to specify the time of day you would like to have the meal. However, this field is optional and only visible if you select options for Main, Second, and Third Courses. Please select from the following formats:
	* HH:MM AM/PM/24H
	* Example: 12:00 PM

## Tips
* Please select one option for each course to ensure proper submission.
* If you wish to skip any courses, simply do not fill out that field.
* If you select an option for Meal Time, ensure that it matches the correct 24-hour format.
