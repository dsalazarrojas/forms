# Cross Functional Collaboration Session Registration Form - Help Guide
## Purpose
This form is used to register information about cross-functional collaboration sessions.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the required fields, such as Team Name and Session Name.
2. Select relevant options for Session Objectives, Session Type, and Session Hashtag List.
3. Enter relevant details for Session Description, Session Outcomes, and Session Hashtag.
4. Add participants to the Participant List.
5. Enter contact information, including Project Manager and Project Manager Email.
6. Review and submit the form.

## Field-by-Field Explanation

* **Registration Session ID** (`registration_session_id`, number, not required): A unique ID for the session.
* **Team Name** (`team_name`, text, not required): The name of the team participating in the session.
* **Session Name** (`session_name`, text, not required): The name of the session.
* **Start Date** (`start_date`, date, not required): The date the session will take place.
* **Session Start Time** (`start_time`, time, not required): The start time of the session.
* **End Date** (`end_date`, date, not required): The end date of the session.
* **Session End Time** (`end_time`, time, not required): The end time of the session.
* **Location** (`location`, text, not required): The location of the session.
* **Contact Person** (`contact_person`, text, not required): The person to contact for more information.
* **Email** (`email`, email, not required): The email address of the contact person.
* **Phone Number** (`phone`, text, not required): The phone number of the contact person.
* **Participant List** (`participant_list`, select_multiple, not required): A list of participants in the session. You can select multiple options from the list.
* **Participant List Item** (`participant_list_item`, text, not required): A specific participant in the session.
* **Session Notes** (`notes`, text, not required): Additional notes about the session.
* **Session Objectives** (`session_objectives`, select_one, not required): A list of objectives for the session. You can select one option from the list.
* **Session Description** (`session_description`, text, not required): A brief description of the session.
* **Session Type** (`session_type`, select_one, not required): Whether the session is a yes or no answer. You can select one option from the list.
* **Session Topic** (`session_topic`, text, not required): The topic of the session.
* **Session Outcomes** (`session_outcomes`, text, not required): The expected outcomes of the session.
* **Session Hashtag** (`session_hashtag`, text, not required): A unique hashtag for the session.
* **Session Hashtag List** (`session_hashtag_list`, select_multiple, not required): A list of hashtags for the session. You can select multiple options from the list.
* **Team Hashtag** (`team_hashtag`, text, not required): A unique hashtag for the team.
* **Team Hashtag List** (`team_hashtag_list`, select_multiple, not required): A list of hashtags for the team. You can select multiple options from the list.
* **Project Manager** (`project_manager`, text, not required): The project manager in charge of the session.
* **Project Manager Email** (`project_manager_email`, text, not required): The email address of the project manager.

Note: Some fields are not required, but they are still important for providing relevant information about the session. Make sure to fill them in if you have the necessary information.
