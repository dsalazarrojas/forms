# Workshop Facilitator Payment Form - Help Guide
## Purpose
This form is used by workshop facilitators to provide their payment information and details for an event.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in your workshop facilitator information:
	* First Name (First)
	* Last Name (Last)
2. Enter your payment details:
	* Payment Method (Visa, Mastercard, Amex, Discover)
	* Amount (in numeric format, e.g., 100.00)
	* Payment Details (a brief description of the payment)
3. Select the workshop details:
	* Workshop Name
	* Workshop Date (in date format, e.g., 2022-01-01)
	* Workshop Time (in time format, e.g., 14:00)
	* Workshop Location (a brief description of the workshop location)
	* Total Participants (a numeric count)
4. Add workshop facilitator information:
	* Workshop Facilitator ID
	* Event Name
	* Participant Count (a numeric count)
	* Workshop Duration (a brief description of the workshop duration)
