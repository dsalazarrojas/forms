# Special Bundle Registration - Help Guide
## Purpose
This form is used to register participants for an event, capturing their details and preferences.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the required and optional fields as relevant to your participation in the event.
2. For each field, provide as much information as you need to, but be aware that some fields are optional.
3. Review your submission carefully before submitting.

## Field-by-Field Explanation
* **Participant Information**: Enter your name, if you wish to share your participant information.
* **Participant Email**: Enter your email address, if you wish to be contacted about event details.
* **Participant Phone**: Enter your phone number, if you wish to be contacted about event details.
* **Participant Notes**: If you have any additional comments or information you wish to share, enter them here.
* **Participant Name**: If you have not already done so, enter your participant name here.
* **Event Date**: Enter the date of the event, if you have it.
* **Event Time**: Enter the start time of the event, if you have it.
* **Participant Role**: Select the role you will be playing during the event (e.g., Event Host, Event Speaker, Participant).
* **Event Location**: Enter the location of the event, if you have it.

## Tips
* Make sure to fill out all required fields before submitting.
* Use the Participant Name field to help identify you with event materials or follow-up communication.
* Use the Participant Email and Participant Phone fields to ensure you receive important event updates and communication.
* If you have a specific role, select it in the Participant Role field to help with event organization and coordination.
