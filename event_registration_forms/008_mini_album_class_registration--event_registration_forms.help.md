This guide is intended for end users who need to complete the Mini Album Class Registration form. The purpose of this form is to collect information from users registering for a Mini Album Class event. To prevent data duplication, please do not register multiple times for the same event. If you are unsure about your registration status, contact the event organizers for clarification.

## Mini Album Class Registration - Help Guide
## Purpose
This form is used to register for a Mini Album Class event. Please fill out the form accurately to ensure that your registration is processed correctly.

## How To Complete This Form
1. Fill out the required fields (marked as `required` in the form) carefully.
2. Double-check that you have filled out all required fields before submitting the form.
3. If you are registering for a Mini Album Class, select the correct class from the drop-down menu.

## Field-by-Field Explanation
* **First name** (`user_first_name`, text, **optional**): Enter your first name as it appears on your identification documents.
* **Last name** (`user_last_name`, text, **optional**): Enter your last name as it appears on your identification documents.
* **Email** (`email`, email, **optional**): Enter your email address for contact purposes.
* **Phone** (`phone`, text, **optional**): Enter your phone number for contact purposes.
* **Class** (`user_class`, select_one, **required**): Select the Mini Album Class you are registering for. Please note that this is a required field to ensure accurate event organization.
* **Message** (`user_message`, text, **optional**): Enter any additional comments or messages if necessary.
* **Event Date** (`event_date`, date, **optional**): If you need to specify a specific event date, enter it here.
* **Event Time** (`event_time`, time, **optional**): If you need to specify a specific event time, enter it here.
* **Assigned Tool** (`assigned_tool`, select_one, **required**): Select the tool assigned to you for the event. Please note that this is a required field for event organization and tool management.
* **Comments** (`user_comments`, note, **optional**): Enter any additional comments or notes if necessary.
* **Submission Date** (`submission_date`, date, **optional**): This field is automatically populated when you submit the form.
* **Submission Time** (`submission_time`, time, **optional**): This field is automatically populated when you submit the form.

Note that all fields marked as `required` are mandatory to complete the registration process.
