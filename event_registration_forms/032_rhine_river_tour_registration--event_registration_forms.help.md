# Rhine River Tour Registration - Help Guide

## Purpose

The Rhine River Tour Registration form is designed to gather information from tour operators and their parties for the Rhine River tour. This form is used to register tour operators and their parties, ensuring that they have the necessary details to participate in the tour. Please ensure that you have all the required information before submitting the form.

## How To Complete This Form

1.  Select the tour operator from the list of options provided.
2.  Enter the name of the person registering for the tour (if the party size is 1).
3.  Select the party size and type.
4.  Enter the tour date.
5.  Enter the accommodation details, including address, phone number, and email.
6.  Enter any additional accommodation notes.
7.  Enter any notes for the tour operator.
8.  Enter the confirm email address and confirm date (not to be confused with the accommodation email address).
9.  Enter the party name, phone number, and email address.
10.  Review your information before submitting the form.

## Field-by-Field Explanation

*   **Tour Operator (Select One) (Optional)**: Select the tour operator from the list of options provided.
*   **Name (Text) (Required)**: Enter the name of the person registering for the tour (if the party size is 1).
*   **Party Size (Select Multiple) (Optional)**: Select the number of people in the party.
*   **Party Type (Select One) (Optional)**: Select the type of party (Adults, Children, Group).
*   **Tour Date (Date) (Optional)**: Select the date of the tour.
*   **Travel Duration (Time) (Optional)**: Select the duration of the tour.
*   **Arrival Date (Date) (Required)**: Select the date of arrival.
*   **Accommodation Type (Select One) (Optional)**: Select the type of accommodation (Hotel, Hostel, Airbnb).
*   **Accommodation Address (Text) (Required)**: Enter the address of the accommodation.
*   **Accommodation Phone (Text) (Required)**: Enter the phone number of the accommodation.
*   **Accommodation Email (Email) (Required)**: Enter the email address of the accommodation.
*   **Accommodation Notes (Text) (Optional)**: Enter any additional information about the accommodation.
*   **Notes (Text) (Required)**: Enter any notes for the tour operator.
*   **Confirm Email (Email) (Required)**: Enter the email address to confirm.
*   **Confirm Date (Date) (Optional)**: Select the confirm date.
*   **Party Name (Text) (Required)**: Enter the name of the party.
*   **Party Phone (Text) (Required)**: Enter the phone number of the party.
*   **Party Email (Text) (Required)**: Enter the email address of the party.
