# Hospital Communication Excellence Forum Registration - Help Guide
## Purpose
This form is for event registrants to provide information about their events, allowing us to review and process their registration.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill out the Event Information section with the relevant details about your event.
2. Select the type of event you are registering (Webinar, Conference, or Workshop).
3. Provide any additional registration details if needed.
4. Enter the attendee's information, including name, email, and phone number.
5. Specify any accessibility needs or dietary requirements.
6. Select a payment method (Credit Card, Invoice, or Other) and provide any additional information if needed.

## Field-by-Field Explanation
### Event Information
* **Event Information** (`event_info`, text, optional): Enter a brief description of your event.
### Event Type
* **Event Type** (`event_type`, select_one, optional): Select the type of event you are registering (Webinar, Conference, or Workshop).
### Registration Details
* **Registration Details** (`registration_details`, text, optional): Provide any additional registration details if needed.
### Attendee Information
* **Attendee Information** (`attendee_info`, text, optional): Enter the attendee's name.
### Event Date
* **Event Date** (`event_date`, date, optional): Select the date of the event.
### Event Time
* **Event Time** (`event_time`, time, optional): Select the time of the event.
### Attendee Name
* **Attendee Name** (`attendee_name`, text, optional): Enter the attendee's name.
### Attendee Email
* **Attendee Email** (`attendee_email`, email, optional): Enter the attendee's email address.
### Attendee Phone
* **Attendee Phone** (`attendee_phone`, text, optional): Enter the attendee's phone number.
### Accessibility Needs
* **Accessibility Needs** (`accessibility_needs`, select_multiple, optional): Specify any accessibility needs, such as Wheelchair Accessible or Sign Language Interpreter.
### Dietary Information
* **Dietary Information** (`dietary_info`, select_multiple, optional): Select any dietary requirements, such as Vegetarian or Vegan.
### Additional Dietary Notes
* **Additional Dietary Notes** (`dietary_note`, text, optional): Enter any additional dietary notes.
### Payment Method
* **Payment Method** (`payment_method`, select_one, optional): Select how you would like to pay (Credit Card, Invoice, or Other).
### Other Payment Method
* **Other Payment Method** (`other_payment_method`, text, optional): If you selected "Other" as the payment method, provide any additional information.
