# Team Social Event Registration - Help Guide
## Purpose
This form is for team members to register for social events. Please fill it out to let us know if you will be attending or have any dietary needs or activity preferences.

## How To Complete This Form
To complete this form, simply follow these steps:

1. Provide your name for the team social event.
2. Choose whether you will be attending by selecting "Yes" or "No" from the RSVP field.
3. If you have any dietary needs, select all that apply.
4. If you have any activity preferences, select "Yes" or "No".
5. Enter your email address so we can contact you about the event.
6. Enter your phone number for emergency contact purposes.
7. Provide any additional comments you would like to share with the team.
8. Select the date you will RSVP by.

## Field-by-Field Explanation
* **Team Social Event Name** (<type:text>): Enter the name of the team event you are registering for.
* **RSVP (<type:select_one>): Choose "Yes" to indicate that you will attend the event, or "No" if you will not be attending.
* **Dietary Needs (<type:select_multiple>): If you have any dietary restrictions or needs, select all that apply.
* **Activity Preference (<type:select_one>): If you have a preference for certain types of activities, select "Yes" if you enjoy them, or "No" if not.
* **Email** (<type:email>): Enter your email address so we can contact you about the event.
* **Phone** (<type:text>): Enter your phone number for emergency contact purposes.
* **Comments** (<type:note>): Provide any additional comments or information you would like to share with the team.
* **RSVP Date** (<type:date>): Select the date you will RSVP by.

## Tips
* Please make sure to select "Yes" or "No" for RSVP and dietary needs to ensure we can plan the event accordingly.
* If you have any special requests or needs, please include them in the comments field.
* If you are unable to attend, you can simply select "No" for RSVP.
