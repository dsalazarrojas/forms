# indoor_activity_registration_form - Help Guide
## Purpose
This form is designed to collect participant information and event details for indoor activities.

## How To Complete This Form
To complete this form, please follow these steps:
1. Fill in the required fields (denoted by *) with your information.
2. Answer any additional questions that are relevant to your participation in the indoor activity.

## Field-by-Field Explanation
### Participant Info
* **Participant Info** (<type>: text, required: false): Please enter your name.
### Event Info
* **Event Info** (<type>: text, required: false): Please describe the event you are registering for.
### Participant Preferences
* **Participant Preferences** (<type>: text, required: false): If you have any special requests or requirements, please describe them here.
### Event Details
* **Event Details** (<type>: text, required: false): If you have any additional information about the event, please describe it here.
### Participant Availability
* **Participant Availability** (<type>: text, required: false): Please let us know when you are available to attend the event.
### Registration Info
* **Registration Info** (<type>: text, required: false): If you have any information about your registration, please describe it here.
### Emergency Contacts
* **Emergency Contacts** (<type>: text, required: false): If you would like to provide us with emergency contact information, please do so here.
### Additional Info
* **Additional Info** (<type>: text, required: false): If you have any additional information you would like to share, please do so here.
### Payment Info
* **Payment Info** (<type>: text, required: false): If you are paying for your participation, please describe your payment method here.
### Participant Details
* **Participant Details** (<type>: text, required: false): If you would like to provide us with more details about yourself, please do so here.
### Event Details 2
* **Event Details 2** (<type>: text, required: false): If you have any additional event details to share, please do so here.

## Tips
* Please make sure to fill in all required fields (*).
* If you have any doubts or questions, please contact the event organizers.
* You can add or modify fields as per your preferences.
