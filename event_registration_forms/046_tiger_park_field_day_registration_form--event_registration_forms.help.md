# Tiger Park Field Day Registration Form - Help Guide
## Purpose
This form is used to register an event at Tiger Park. It's intended for users to provide their contact information and event details for events relevant to their role at Tiger Park.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter your name in the "Name" field.
2. Enter your contact email and phone number (if applicable) in their respective fields.
3. Fill in the event details:
	* Event name
	* Date of the event (in date format)
	* Start time of the event (in time format)
	* Duration of the event
	* Entrance fee (in the selected currency)
4. Specify whether the event requires registration or not.
5. Choose the number of attendees for the event (Yes/No).

## Field-by-Field Explanation

* **Name** (text, required): Enter your name as it appears on your identification documents.
* **contact_email** (email, optional): Enter your contact email address.
* **contact_phone** (text, optional): Enter your contact phone number (if available).
* **contact_email_alternate** (text, optional): This field is not clearly labeled, but it seems to be an alternate contact email. Enter an alternate contact email address if you have one.
* **event** (text, optional): Enter the name of the event you want to register.
* **event_date** (date, optional): Enter the date of the event in the format `MM/DD/YYYY`.
* **event_start_time** (time, optional): Enter the start time of the event in the format `HH:MM AM/PM`.
* **event_duration** (number, optional): Enter the duration of the event.
* **event_entrance_fee** (number, optional): Enter the entrance fee of the event.
* **event_entrance_fee_currency** (text, optional): Select the currency of the entrance fee.
* **event_registration_type** (select_one, optional): Choose "Yes" if the event requires registration, "No" otherwise.
* **event_registration_type_options** (text, optional): This field is not clearly labeled, but it seems to be an alternate option for event registration type. You can enter any additional information about event registration type if needed.
* **event_registration_type_label** (text, optional): This field is not clearly labeled, but it seems to be a label for the event registration type options. You can enter a descriptive label for the event registration type options.
* **event_attendee_count** (select_multiple, optional): Choose "Yes" if the event has attendees, "No" otherwise.
* **event_attendee_count_description** (text, optional): This field is not clearly labeled, but it seems to be a description for the event attendee count. You can enter any additional information about event attendee count.
* **event_attendee_count** (select_multiple, optional): Choose "Yes" if the event has attendees, "No" otherwise.
* **event_attendee_count_options** (text, optional): This field is not clearly labeled, but it seems to be an option for event attendee count. You can enter any alternative options for event attendee count.
