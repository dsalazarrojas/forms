# Team Scores Import Form - Help Guide
## Purpose
The Team Scores Import Form is used to import team scores for a specific event. This form should be used by authorized users to import scores for events that are not yet complete or for events that have been rescheduled.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the **Team Name** (Field 2) and **Event Name** (Field 6) of the event.
2. Enter the **League Name** (Field 7) and **League ID** (Field 25) of the event.
3. Enter the **Match Date** (Field 10) and **Match Time** (Field 9) of the event.
4. Enter the **Team ID** (Field 11) and **Match ID** (Field 12) of the team.
5. Enter the **Team Scored** (Field 13), **Opponent Scored** (Field 14), **Team Points** (Field 15), and **Opponent Points** (Field 16) for the match.
6. Select the **Match Outcome** (Field 17) and **Match Status** (Field 18) for the match.
7. Select the **Match Result Status** (Field 19) and choose **Confirmed** if the score is correct, or **Pending** if the score is still pending.
8. Enter any additional notes for the **Match Status Note** (Field 20) and **Match Details Note** (Field 21).
9. Click on the **Submit** (Field 22) button to save the changes.

## Field-by-Field Explanation

* **Team Name** (`team_name`, required): Enter the name of the team that played the match.
* **Event Name** (`event_name`, required): Enter the name of the event where the match was played.
* **League Name** (`league_name`, required): Enter the name of the league where the match was played.
* **League ID** (`league_id`, required): Enter the ID of the league where the match was played.
* **Team ID** (`team_id`, optional): Enter the ID of the team that played the match.
* **Match Date** (`match_date`, required): Enter the date of the match.
* **Match Time** (`match_time`, required): Enter the time of the match.
* **Match ID** (`match_id`, required): Enter the ID of the match.
* **Team Scored** (`team_scored`, required): Enter the score scored by the team.
* **Opponent Scored** (`opponent_scored`, required): Enter the score scored by the opponent.
* **Team Points** (`team_points`, required): Enter the points scored by the team.
* **Opponent Points** (`opponent_points`, required): Enter the points scored by the opponent.
* **Match Outcome** (`match_outcome`, required): Select the outcome of the match (Win, Draw, or Loss).
* **Match Status** (`match_status`, required): Select the status of the match (Completed, Scheduled, or Pending).
* **Match Result Status** (`match_result_status`, optional): Select the status of the match result (Confirmed, Pending, or Unknown).
* **Match Status Note** (`match_status_note`, optional): Enter any additional notes for the match status.
* **Match Details Note** (`match_details_note`, optional): Enter any additional notes for the match details.
* **Submit** (`submit_button`, optional): Click to save the changes.
* **Additional Notes** (`notes`, optional): Enter any additional notes for the event.
 
Tips:

* Make sure to enter the correct team name, event name, and league name to avoid errors.
* Double-check the scores and match outcome before submitting the changes.
* If the score is pending, select the pending status for the match result status.
