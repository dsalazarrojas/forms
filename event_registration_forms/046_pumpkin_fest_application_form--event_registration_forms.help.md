# Pumpkin Fest Application Form - Help Guide
## Purpose
The Pumpkin Fest Application Form is a registration form designed to collect information from applicants who want to participate in the Pumpkin Fest event. The form is used to gather relevant details about the applicant, including their contact information, event preferences, and other necessary details. Completing this form will help the Pumpkin Fest organization to manage the event more efficiently and ensure that the right attendees are registered for the event.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in your First Name and Last Name in the corresponding fields.
2. Enter your Email address and Phone number (if applicable).
3. Select your Category of interest (if applicable).
4. Choose your preferred Event Type (if applicable).
5. Provide your Event Date and Event Time for the event you plan to attend.
6. You can add a Description and Event Location if you want to share more information about your event.
7. If you have a Note you want to share with the event organizers, you can add it here.
8. Review all fields for accuracy and submit your application.

## Field-by-Field Explanation

* **First Name** (`first_name`, text, required): Please fill in your first name here. This will be used to identify you as an attendee of the event.
* **Last Name** (`last_name`, text, required): Please fill in your last name here. This will be used to identify you as an attendee of the event.
* **Email** (`email`, email, required): Enter your email address here. This will be your primary contact method for communication about the event.
* **Phone** (`phone`, text, optional): If you have a phone number, please enter it here. This can be used by the event organizers to contact you if needed.
* **Category** (`category`, select_one, optional): If you are interested in a specific category, please select the corresponding option here. This will help the event organizers to manage the event more efficiently.
* **Event Type** (`event_type`, select_one, optional): If you are interested in attending a specific type of event, please select the corresponding option here.
* **Event Date** (`event_date`, date, required): Please select the date you plan to attend the event here.
* **Event Time** (`event_time`, time, required): Please select the time you plan to attend the event here.
* **Description** (`description`, text, optional): If you want to share more information about your event, you can add a description here.
* **Event Location** (`event_location`, text, optional): If you want to share more information about the location of your event, you can add it here.
* **Note** (`note`, note, optional): If you have any additional note you want to share with the event organizers, you can add it here.
