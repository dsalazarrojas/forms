# Free Yoga Intro Class RSVP Form - Help Guide
## Purpose
The Free Yoga Intro Class RSVP Form is intended to collect information about attendees who are interested in attending a free yoga class. This form will help the event organizers prepare for the class, ensuring that there are enough resources and materials for each attendee.

## How To Complete This Form

*   Please carefully review all the fields below and complete the form in its entirety.
*   Make sure to enter accurate and complete information for each field to ensure that your response is processed correctly.

## Field-by-Field Explanation
*   **Name** (`name`, `text`, required: false): Enter your name as you would like it to be displayed for the class.
*   **Email** (`email`, `email`, required: false): Enter your valid email address.
*   **Phone** (`phone`, `text`, required: false): Enter your phone number (optional).
*   **RSVP** (`rsvp`, `select_one`, required: false): Choose "Yes" if you can attend the class, or "No" if you cannot.
*   **Class Date** (`class_date`, `date`, required: false): Select the date for which you would like to attend the class.
*   **Class Time** (`class_time`, `time`, required: false): Select the time for which you would like to attend the class.
*   **Number of Attendees** (`number_of_attendees`, `number`, required: false): If attending with someone, enter the number of people coming with you.
*   **Comments** (`comments`, `text`, required: false): Enter any additional comments or questions you may have about the class.
