# interior_design_workshop_booking_form - Help Guide
## Purpose
This form is designed to collect essential information for booking an interior design workshop. It includes details about the participant and the event organizer.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in your participant information: 
   * Participant Name: Enter your full name.
   * Participant Email: Enter a valid email address.
   * Participant Phone: Enter your phone number.
   * Participant Address: Enter your physical address.
   * Participant City: Enter the city where you live.
   * Participant State: Enter the state where you live.
   * Participant Zip: Enter your zip code.
   * Participant Country: Enter the country where you live.
2. Enter your event information: 
   * Event Date: Select the date of the event. 
   * Event Time: Select the time of the event.
3. Complete the event organizer's information: 
   * Event Organizer: Enter the name of the event organizer.
   * Event Organizer Email: Enter the email address of the event organizer.
   * Event Organizer Phone: Enter the phone number of the event organizer.
   * Event Organizer Address: Enter the address of the event organizer.
   * Event Organizer City: Enter the city where the event organizer lives.
   * Event Organizer State: Enter the state where the event organizer lives.
   * Event Organizer Country: Enter the country where the event organizer lives.
   * Event Organizer Zip: Enter the zip code of the event organizer.
4. Add any additional information (optional):
   * Participant Notes: Enter any additional information about yourself.
   * Form Additional Information: Enter any additional information about the event.
5. Confirm your payment option:
   * Form Payment: Select your payment option.
6. Review and submit the form.
