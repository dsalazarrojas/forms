# Fundraising Event Extension Form - Help Guide
## Purpose
This form is used to collect information from participants in fundraising events.

## How To Complete This Form

1. Fill in the required fields as accurately as possible.
2. Review the form for completeness and correctness.
3. Submit the form to complete the registration process.

## Field-by-Field Explanation

* **Event Details** (`event_details`, text, required: false): Enter a brief description of the event.
* **Participant Details** (`participant_details`, text, required: false): Enter participant information, including name, email, and phone number.
* **Donations** (`donations`, text, required: false): Enter the donation amount and other details.
* **Participant Feedback** (`feedback`, text, required: false): Provide any feedback or comments about the event.
* **Participant Donations** (`participant_donations`, text, required: false): Enter participant's donation details.
* **Participant Feedback** (`participant_feedback`, text, required: false): Provide participant's feedback about the event.
* **Event Participants** (`event_participants`, text, required: false): Enter participant information for the event.
* **Participant Donation Amounts** (`participant_donation_amounts`, text, required: false): Enter participant's donation amounts.
* **Participant Pledge Details** (`participant_pledge_details`, text, required: false): Enter participant's pledge details.
* **Donation Amount** (`donation_amount`, number, required: false): Enter the donation amount.
* **Participant Name** (`participant_name`, text, required: false): Enter participant's name.
* **Participant Email** (`participant_email`, email, required: false): Enter participant's email.
* **Participant Phone** (`participant_phone`, text, required: false): Enter participant's phone number.
* **Participant Notes** (`participant_notes`, text, required: false): Enter participant's notes.
* **Participant Donation Status** (`participant_donation_status`, text, required: false): Enter participant's donation status.
* **Event Title** (`event_title`, text, required: false): Enter event title.
* **Event Start Date** (`event_start_date`, date, required: false): Enter event start date.
* **Event End Date** (`event_end_date`, date, required: false): Enter event end date.
* **Event Time** (`event_time`, time, required: false): Enter event time.
* **Participant Start Date** (`participant_start_date`, date, required: false): Enter participant's start date.
* **Participant End Date** (`participant_end_date`, date, required: false): Enter participant's end date.
* **Participant Status** (`participant_status`, text, required: false): Enter participant's status.
* **Event Status** (`event_status`, text, required: false): Enter event status.
* **Participant Donor Status** (`participant_donor_status`, text, required: false): Enter participant's donor status.
* **Participant Donor Amount** (`participant_donor_amount`, text, required: false): Enter participant's donor amount.

Note: All fields are optional, but please fill them out as accurately as possible for better data collection.
