# event_photography_contract - Help Guide
## Purpose
The event_photography_contract form is designed to collect necessary information for an event photography contract. This form helps event organizers or managers gather essential details from clients and photographers to facilitate smooth event execution and communication.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill in the event name and description to provide a clear understanding of the event.
2. Enter the event date and time, which is crucial for scheduling and logistical purposes.
3. Choose the photographer and client to associate with the event.
4. Confirm whether the client and photographer agree to the contract terms, which is essential for event execution and legal compliance.

## Field-by-Field Explanation

* **event-photographer**: 
	+ This field is used to input the name of the photographer assigned to the event.
	+ Please enter the full name of the photographer.
* **event-client**: 
	+ This field is used to input the name of the client or event organizer.
	+ Please enter the full name of the client.
* **event-date**: 
	+ This field is used to input the date of the event.
	+ Use the standard date format (YYYY-MM-DD) to ensure accurate scheduling.
* **event-time**:
	+ This field is used to input the start time of the event.
	+ Use the standard time format (HH:MM) to ensure accurate scheduling.
* **event-name**: 
	+ This field is used to input a brief description of the event.
	+ Keep it concise and focused on event details.
* **event-description**: 
	+ This field is used to provide a brief description of the event.
	+ Keep it concise and relevant to the event type.
* **contract-term**: 
	+ This field is used to input any special terms or requirements for the event.
	+ Be as specific as possible to ensure understanding and compliance.
* **client-agreement**: 
	+ This field is used to confirm the client's agreement to the contract terms.
	+ Select 'Yes' to indicate agreement.
* **photographer-agreement**: 
	+ This field is used to confirm the photographer's agreement to the contract terms.
	+ Select 'Yes' to indicate agreement.

## Tips
- Double-check the accuracy of the input data to avoid errors.
- Ensure that the photographer and client are correctly associated with the event.
- If there are any special requirements or terms that need to be added, use the 'contract-term' field to include them.
