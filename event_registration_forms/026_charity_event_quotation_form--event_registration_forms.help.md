# Charity Event Quotation Form - Help Guide
## Purpose
This form is designed to collect all necessary information to create a quotation for a charity event. Please fill out all required fields to ensure a complete and accurate quotation.

## How To Complete This Form
- Fill out all required fields, indicated by a `*` symbol.
- If a field is optional, fill it out if you have additional information to provide.
- Use the provided hints for guidance on what to enter in each field.

## Field-by-Field Explanation

* **Organization Name** (`organization_name`, text, required): Enter the name of the charity organization hosting the event.
* **Contact Name** (`contact_name`, text, required): Enter the name of the primary contact person for the event.
* **Contact Email** (`contact_email`, email, required): Enter the email address of the primary contact person.
* **Contact Phone** (`contact_phone`, text, required): Enter the phone number of the primary contact person.
* **Event Name** (`event_name`, text, required): Enter the title of the event.
* **Event Type** (`event_type`, select_one, required): Select the category of the event (e.g. Gala dinner, Charity auction, etc.).
* **Event Date** (`event_date`, date, required): Enter the date the event is scheduled for.
* **Event Location** (`event_location`, text, required): Enter the name of the venue where the event will take place.
* **Expected Number of Guests** (`expected_guests`, number, required): Estimate the number of people attending the event.
* **Venue Rental Cost** (`venue_rental`, number, optional): If applicable, enter the cost of renting the venue.
* **Catering Cost Estimate** (`catering_cost`, number, optional): If applicable, enter an estimate for food and beverage costs.
* **Audio Visual Equipment Cost** (`audio_visual_cost`, number, optional): If applicable, enter the cost of audio visual equipment (e.g. sound and projection).
* **Decoration Cost Estimate** (`decoration_cost`, number, optional): If applicable, enter an estimate for decoration costs (e.g. flowers, decor).
* **Entertainment Cost** (`entertainment_cost`, number, optional): If applicable, enter the cost of performers or DJ.
* **Marketing and Promotion Cost** (`marketing_cost`, number, optional): If applicable, enter an estimate for advertising and promotion costs.
* **Staffing Cost** (`staffing_cost`, number, optional): If applicable, enter the cost of event staff.
* **Miscellaneous Costs** (`miscellaneous_cost`, number, optional): If applicable, enter other expenses related to the event.
* **Total Estimated Cost** (`total_estimate`, number, required): Sum all costs to get a total estimated cost.
* **Payment Terms** (`payment_terms`, select_one, required): Select the payment terms (e.g. 50% deposit 50% after, Full payment upfront, etc.).
* **Quotation Valid Until** (`quotation_valid_until`, date, required): Enter the date the quotation is valid until.
* **Additional Notes** (`additional_notes`, text, optional): Enter any additional terms or conditions that need to be considered.
