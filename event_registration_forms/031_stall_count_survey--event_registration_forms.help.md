# Stall Count Survey - Help Guide
## Purpose
The Stall Count Survey is designed to collect data on stall counts and engagement levels at events. This data will help events teams optimize their events, make informed decisions, and improve the overall experience for their attendees.

## How To Complete This Form
To fill out this form, follow these steps:

* Select the event for which you are filling out the survey. Make sure to enter the correct Event ID for accurate representation.
* Enter the name of the event in the Event Title field.
* Choose a date for the event.
* Enter the start time of the event.
* Enter the end time of the event.
* Enter the total number of stalls present at the event.
* Enter the total number of attendees at the event.
* Enter the total number of engaged stalls at the event.
* Determine the average time spent per stall and select the option that best represents this value.
* Determine the overall engagement level of the event and select the option that best represents this value.

## Field-by-Field Explanation

* **Stall Name**: This is the name of the event being surveyed, usually representing the name of the event or the title of the event.
* **Event ID**: Please enter the unique identifier for the event. This field is required to ensure that the data is associated correctly with the event.
* **Event Title**: This field should contain the title or name of the event being surveyed.
* **Date**: This field is for selecting the date on which the event took place.
* **Start Time**: This field is for entering the start time of the event. Make sure to use the correct 24-hour time format.
* **End Time**: This field is for entering the end time of the event. Make sure to use the correct 24-hour time format.
* **Stall Count**: Please enter the total number of stalls present at the event. If you are unsure, please refer to your event records.
* **Total Attendees**: Please enter the total number of attendees at the event.
* **Engaged Stalls**: Please enter the total number of engaged stalls at the event.
* **Average Time per Stall**: This field should contain the average time spent per stall. Select the option that best represents this value.
* **Engagement Level**: This field should contain the overall engagement level of the event. Select the option that best represents this value, using the following options:
	+ High: The event had a high level of engagement.
	+ Medium: The event had a medium level of engagement.
	+ Low: The event had a low level of engagement.
