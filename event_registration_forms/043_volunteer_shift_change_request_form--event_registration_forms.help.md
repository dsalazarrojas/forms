The `volunteer_shift_change_request_form` form is designed to be used by volunteers who need to request changes to their assigned shifts. This form allows volunteers to provide details about the reason for the change, the new shift start and end times, and any conflicts that may arise from the change. The form is used to facilitate smooth and efficient communication between volunteers and event organizers, ensuring that any conflicts are addressed promptly.

The form will not be used for:

* Creating new volunteer shifts
* Managing volunteer availability
* Tracking volunteer hours

To complete this form, follow these steps:

## How To Complete This Form

1.  Select the "Volunteer Shift" field and enter the shift you would like to modify.
2.  Enter the "Event Date" when the shift change needs to take place.
3.  Enter the "Shift ID" of the shift you would like to modify, if applicable.
4.  Enter your name as the "Volunteer Name" so that your request can be easily identified.
5.  Briefly describe the reason for the change in the "Reason for Change" field.
6.  Enter the current "Shift Start Time", "Shift End Time", "Preferred Shift Start Time", and "Available Shift Start Time" fields as they currently stand.
7.  If the shift change conflicts with another event, enter the "Conflict Start Time" and "Conflict End Time" fields.
8.  Enter the new "Shift Start Time" and "New Shift End Time" fields according to your preferences.
9.  Finally, click "Submit Request" to send your request to the event organizers.

## Field-by-Field Explanation

*   **Volunteer Shift**: Enter the shift you would like to modify.
*   **Event Date**: Enter the date when the shift change needs to take place.
*   **Shift ID**: Enter the ID of the shift you would like to modify, if applicable.
*   **Volunteer Name**: Enter your name so that your request can be easily identified.
*   **Reason for Change**: Briefly describe the reason for the shift change.
*   **Shift Start Time**: Enter the current start time of the shift.
*   **Shift End Time**: Enter the current end time of the shift.
*   **Preferred Shift Start Time**: Enter the start time you prefer for the shift change.
*   **Available Shift Start Time**: Enter any available times you have for the shift change.
*   **New Shift Start Time**: Enter the new start time of the shift after the change.
*   **Conflict Start Time**: Enter the time that conflicts with the shift change.
*   **Conflict End Time**: Enter the end time that conflicts with the shift change.
*   **New Shift End Time**: Enter the new end time of the shift after the change.
*   **Submit Request**: Enter your request and submit it to the event organizers.
*   **Cancel Request**: Cancel your request and remove it from the queue.

## Tips

*   Before submitting your request, double-check that the provided fields are accurate and up-to-date.
*   Be clear and concise when describing the reason for the shift change.
*   If the shift change conflicts with another event, make sure to provide the necessary information to help resolve the conflict.
