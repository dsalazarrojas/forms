# Holiday Run & Cycle Registration - Help Guide
## Purpose
The purpose of this guide is to provide a step-by-step explanation of the Holiday Run & Cycle registration form.

## How To Complete This Form
To complete this form, follow the steps outlined above.

## Field-by-Field Explanation
- **Participant Name** (participant_name, text, required: false): Enter the name of the participant, including their first and last name.
- **Participant Email** (participant_email, email, required: false): Enter the participant's email address.
- **Waiver Consent** (waiver_consent, select_one, required: false): Select "True" if you consent to the event waiver or "False" if you do not.
- **T-shirt Size** (tshirt_size, select_multiple, required: false): Choose your preferred T-shirt size from the available options.
- **Event Date** (event_date, date, required: false): Enter the date of the event in the format MM/DD/YY.
- **Event Time** (event_time, time, required: false): Enter the time of the event in the format HH:MM AM/PM.
- **Participant Phone** (participant_phone, text, required: false): Enter the participant's phone number.
- **Participant Address** (participant_address, text, required: false): Enter the participant's address.

## Tips
- If you're unsure about any field, refer back to the explanation above for guidance.
- Some fields are optional, so feel free to leave them blank if not applicable.
- Ensure you fill out all required fields before submitting the form.
- Review your submission before submitting to ensure accuracy.
- If you have any questions or issues, contact [support email or phone number].
