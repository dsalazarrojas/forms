# film production intake form - Help Guide

## Purpose
This form is used to gather information about a film production project. It includes details about the project, crew availability, budget estimates, and other relevant production information. This form is designed to be completed by project leads, producers, or other stakeholders who need to provide project details to the production team.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the project details, including the title, project lead, and production company.
2. Select all relevant crew members who are available for the project.
3. Enter the budget estimates for the project.
4. Choose the filming locations and dates for the project.
5. Select the start time for the project.
6. Add any additional notes about the project.
7. Enter your email and phone number for communication.
8. Choose the type of production (e.g., film, TV, commercial).
9. Add any additional notes about the project.
10. Set the submission date and time for the project.

## Field-by-Field Explanation
- **Project Details** (`project_details`, `text`, required): This field is for entering the project's title, which will be used as a reference for the production team.
- **Crew Availability** (`crew_availability`, `select_multiple`, required): Select all crew members who are available to work on the project. This will help the production team plan and schedule the project accordingly.
- **Budget Estimates** (`budget_estimates`, `number`, required): Enter the estimated budget for the project in dollars.
- **Filming Locations** (`filming_locations`, `select_multiple`, required): Choose the locations where the film will be shot.
- **Filming Dates** (`filming_dates`, `date`, required): Enter the dates when the filming will take place.
- **Filming Times** (`filming_times`, `select_one`, required): Select the start time for the project.
- **Notes** (`notes`, `text`, required): Add any additional notes about the project that may be helpful for the production team.
- **Email** (`email`, `email`, required): Enter your email address for communication with the production team.
- **Phone** (`phone`, `text`, required): Enter your phone number for communication with the production team.
- **Project Lead** (`project_lead`, `text`, required): Enter the name of the project lead.
- **Production Company** (`production_company`, `text`, required): Enter the name of the production company.
- **Production Type** (`production_type`, `select_one`, required): Choose the type of production (e.g., film, TV, commercial).
- **Project Notes** (`project_notes`, `text`, required): Add any additional notes about the project.
- **Production Notes** (`production_notes`, `text`, required): Add any additional notes about the project's production process.
- **Submission Date** (`submission_date`, `date`, required): Set the date when the project will be submitted.
- **Submission Time** (`submission_time`, `time`, required): Set the time when the project will be submitted.

Note: Please make sure to fill in all required fields.
