# Stage Performance Release Form - Help Guide
## Purpose
This guide explains how to complete the Stage Performance Release Form.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill in the required fields with accurate and complete information about the event.
2. Review each field carefully before proceeding.

## Field-by-Field Explanation

### Event Organizer
* **Event Organizer** (`event_organizer`, text, required): Enter the name of the person or organization responsible for organizing the event.
* **Artist Name** (`artist_name`, text, required): Enter the name of the artist or performer.
* **Event Date** (`event_date`, date, required): Enter the date of the event in the format YYYY-MM-DD.
* **Release Type** (`release_type`, select_one, required): Choose from recordings, photographs, or broadcasts.
* **Release Organizer** (`release_organizer`, text, required): Enter the name of the person or organization responsible for releasing the event.
* **Email** (`email`, email, required): Enter a valid email address for contact purposes.
* **Phone** (`phone`, text, required): Enter a valid phone number for contact purposes.
* **Agreement Signed By** (`agreement_signed_by`, text, required): Enter the name of the person signing the agreement.
* **Event Name** (`event_name`, text, required): Enter a brief description of the event.
* **Event Description** (`event_description`, text, optional): Enter a longer description of the event (optional).
* **Performance Length** (`performance_length`, number, optional): Enter the length of the performance.
* **Recording Device** (`recording_device`, select_multiple, optional): Choose from audio, video, or live.
* **Broadcast Type** (`broadcast_type`, select_one, optional): Choose from internet, radio, or television.
* **Agreement Signed** (`agreement_signed`, note, required): This field should be checked if the agreement has been signed.
* **Agreement Date** (`agreement_date`, date, required): Enter the date of the agreement.
* **Agreement Time** (`agreement_time`, time, required): Enter the time of the agreement.
* **Recording Location** (`recording_location`, text, required): Enter the location where the performance was recorded.
* **Release Terms** (`release_terms`, text, required): Enter any release terms or conditions.
* **Event Type** (`event_type`, text, required): Enter the type of event (e.g. concert, play, etc.).
* **Performance Start Time** (`performance_start_time`, time, required): Enter the start time of the performance.
* **Event End Time** (`event_end_time`, time, required): Enter the end time of the event.
* **Performance Duration** (`performance_duration`, number, required): Enter the duration of the performance.
* **Recording Duration** (`recording_duration`, number, required): Enter the duration of the recording.
* **Broadcast Location** (`broadcast_location`, text, required): Enter the location where the performance was broadcast.
* **Notes** (`notes`, note, optional): Enter any additional comments or notes about the event.

Please ensure that all required fields are filled in accurately and thoroughly.
