# Esports Tournament Registration Form - Help Guide
## Purpose
This form is designed to collect information about esports tournaments, including event details, participant information, and game specifications.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill in the event name, team name, and event date.
2. Select the event type (e.g., esports tournaments, online tournaments).
3. Provide a brief description of the event.
4. If applicable, select the game platform and game version.
5. Enter any additional details as required or needed.

## Field-by-Field Explanation

* **Event Name** (required): Enter the name of the event.
* **Team Name** (optional): Enter the name of the team participating in the event.
* **Event Date** (optional): Enter the date of the event (in MM/DD/YYYY format).
* **Event Time** (optional): Enter the time of the event (in HH:MM format).
* **Location** (optional): Enter the location of the event.
* **Contact Person** (optional): Enter the name of the contact person responsible for the event.
* **Event Type** (optional): Select the type of event (e.g., esports tournaments, online tournaments).
* **Event Format** (optional): Select the format of the event (e.g., 1v1, 2v2, 3v3, etc.).
* **Team Size** (optional): Enter the size of the team participating in the event. (Note: This field might be removed or modified if the event type already implies the team size.)
* **Game Platform** (optional): Select the game platform used for the event (e.g., PC, console, mobile, online).
* **Game Version** (optional): Enter any additional details about the game version.

## Tips
* Make sure to fill in all required fields.
* Use specific and relevant information for each field.
* If unsure about any field, refer to the example use cases or consult with a representative.

Note: This help guide is based on the provided YAML fields and is subject to change if the form or its fields are modified.
