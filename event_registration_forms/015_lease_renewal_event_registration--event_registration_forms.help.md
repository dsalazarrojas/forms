# lease_renewal_event_registration - Help Guide
## Purpose
This form is used to register events, specifically lease renewal events, to help organizers collect relevant information in an organized and structured way.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the type of event from the "What type of event is this?" dropdown menu.
2. Enter the date of the event in the "event_date" field.
3. Choose the time of the event in the "event_time" field.
4. Enter the name of the person attending the event in the "attendee_name" field.
5. Enter the email address of the attendee in the "attendee_email" field.
6. Enter the phone number of the attendee in the "attendee_phone" field.
7. For the "How many guests are you planning to bring?" question, select the number of guests from 1 to 3.
8. Answer the "Are you planning on staying overnight?" question with "True" or "False".

## Field-by-Field Explanation
* **event_name**: Enter the name of the event you're registering for.
* **event_date**: Enter the date of the event in the format of YYYY-MM-DD.
* **event_time**: Choose the time of the event from the available options.
* **attendee_name**: Enter the name of the person attending the event.
* **attendee_email**: Enter the email address of the person attending the event.
* **attendee_phone**: Enter the phone number of the person attending the event.
* **What type of event is this?**: Select the type of event from the dropdown menu, which should be one of the following options: Lease Renewal Event, Other, or Event.
* **How many guests are you planning to bring?**: Select the number of guests you're planning to bring from 1 to 3.
* **Are you planning on staying overnight?**: Answer this question with "True" or "False" to indicate if you will be staying overnight or not.

## Tips
Make sure to fill out all required fields, and provide accurate and complete information to ensure successful event registration.

Please note that this help guide is specific to this form, and might not cover all the possible event types or scenarios. If you're unsure about any field, please consult with the event organizer or the form creators for further clarification.
