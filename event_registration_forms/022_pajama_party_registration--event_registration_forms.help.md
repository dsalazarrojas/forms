# Pajama Party Registration - Help Guide
## Purpose
This form is used to register for a Pajama Party event. It collects essential details about the event, including event details, attendee information, and logistical arrangements. Please complete the form to ensure a smooth and enjoyable experience for all attendees.

## How To Complete This Form
To complete this form, follow these steps:

* Fill in the required fields with accurate information.
* Review each field carefully to ensure you're providing the correct details.
* Submit the form once you're finished.

## Field-by-Field Explanation

* **Event Details** (`1`, `text`, required: `false`): Enter a brief description of the event.
* **Attendee Info** (`2`, `text`, required: `false`): Provide details about the people attending the event.
* **Event Preferences** (`3`, `text`, required: `false`): Describe any specific preferences or requests for the event.
* **Pajama Clad Choices** (`4`, `select_multiple`, required: `false`): Choose one or more options for Pajama Clad, such as `Pajamas` or `Pajama Party Hat`.
* **Pajama Party Time** (`5`, `select_one`, required: `false`): Select the desired Pajama Party time from the available options: `6:00 AM`, `7:00 AM`, `8:00 AM`, `9:00 AM`, `10:00 AM`, `11:00 AM`, `12:00 PM`, or `1:00 PM`.
* **Event Date** (`6`, `date`, required: `false`): Enter the date of the event.
* **Event Start Time** (`7`, `time`, required: `false`): Enter the start time of the event.
* **Event Venue** (`8`, `select_one`, required: `false`): Choose the event venue from the available options: `School Hall` or `Community Center`.
* **Event Organizer** (`9`, `select_one`, required: `false`): Select the event organizer from the available options: `Student`, `Teacher`, or `Parent`.
* **Contact Number** (`10`, `number`, required: `false`): Enter a contact number where you can be reached.
* **Email Address** (`11`, `email`, required: `false`): Enter an email address where you can be reached.
* **Note** (`12`, `note`, required: `false`): Add any additional information or comments about the event.
