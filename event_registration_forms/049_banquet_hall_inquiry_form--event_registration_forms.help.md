# Banquet Hall Inquiry Form - Help Guide
## Purpose
The Banquet Hall Inquiry Form is designed to gather information from potential clients or event organizers to understand their event needs, preferences, and requirements.

## How To Complete This Form
1. Read through the form carefully and answer each question accurately.
2. Fill in all required fields, marked with an asterisk (\*).
3. Provide specific and detailed information whenever possible.
4. Review your answers before submitting the form.

## Field-by-Field Explanation

* **Full Name** (`inquirer_full_name`, Text, required): Your full name.
* **Email Address** (`inquirer_email`, Email, required): Your contact email address.
* **Phone Number** (`inquirer_phone`, Text, required): Your phone number.
* **Organization** (`organization`, Text, optional): The name of your organization or group.
* **Event Type** (`event_type`, Select One, required): Select the type of event you are planning (e.g., Wedding Reception, Corporate Event, Birthday Party, etc.).
* **Event Name** (`event_name`, Text, optional): The title of your event.
* **Preferred Date** (`preferred_date`, Date, required): Select your preferred date for the event.
* **Alternate Date** (`alternate_date`, Date, optional): Select an alternate date in case the preferred date is not available.
* **Event Start Time** (`event_start_time`, Time, required): Select the start time of your event.
* **Event End Time** (`event_end_time`, Time, required): Select the end time of your event.
* **Expected Number of Guests** (`expected_guests`, Number, required): Estimate the number of guests attending your event.
* **Guest Count Range** (`guest_count_range`, Select One, required): Select the approximate size of your event.
* **Room Preference** (`room_preference`, Select One, optional): Select the preferred room arrangement (e.g., Grand Ballroom, Main Hall, etc.).
* **Catering Needed** (`catering_needed`, Select One, required): Select whether you need catering services (yes/no).
* **Bar Service** (`bar_service`, Select One, optional): Select whether you want bar service (yes/no).
* **Setup Style** (`setup_style`, Select One, optional): Select the seating arrangement you prefer (e.g., Round Tables, Long Tables, etc.).
* **Audio-Visual Requirements** (`audio_visual_requirements`, Select Multiple, optional): Select any audio-visual equipment you may need (e.g., Microphone, Projector, etc.).
* **Decoration Policy** (`decoration_policy`, Select One, optional): Select whether you will decorate the event or need help with it.
* **Budget Range** (`budget_range`, Select One, optional): Select an estimated budget range for your event.
* **Parking Requirements** (`parking_requirements`, Select One, optional): Select any special parking needs.
* **Accessibility Needs** (`accessibility_needs`, Select Multiple, optional): Select any special accessibility requirements.
* **How Did You Hear About Us** (`how_heard_about`, Select One, optional): Select how you heard about us (e.g., Website, Social Media, etc.).
* **Tour Requested** (`tour_requested`, Select One, required): Select whether you want to schedule a tour.
* **Preferred Tour Date** (`preferred_tour_date`, Date, optional): Select a preferred date for the tour.
* **Additional Questions** (`additional_questions`, Text, optional): Ask any additional questions you may have.
* **Special Requests** (`special_requests`, Text, optional): Provide any special requirements or requests.
* **Best Time to Contact** (`best_time_to_contact`, Select One, optional): Select a preferred time to contact you.

## Tips

* Be specific and detailed in your answers to ensure we can provide accurate quotes and services.
* If you have any questions or concerns, please don't hesitate to contact us.
* We will review and respond to your form as soon as possible.
