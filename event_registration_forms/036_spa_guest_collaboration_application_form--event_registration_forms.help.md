# Spa Guest Collaboration Application Form - Help Guide
## Purpose
The Spa Guest Collaboration Application Form is designed to collect information from potential spa guests who want to collaborate with the spa. This form is meant to be filled out by guests who are interested in partnering with the spa to provide services, promote products, or participate in events.

## How To Complete This Form
To complete this form, follow these steps:

1. Review the form carefully and ensure you have all the necessary information ready.
2. Complete all the fields as accurately and thoroughly as possible.
3. Make sure to submit the form only once, as duplicate applications will not be accepted.

## Field-by-Field Explanation
* **Collaboration Application Form** (Required): This is the main application form. Please provide a clear and concise description of your proposal.
* **Guest Information** (Optional): This field is for additional details about the guest, such as contact information, business card, or any other relevant information.
* **Collaboration Programs** (Optional, Select Multiple):
	+ **Spa Day Pass**: Select this option if you are interested in offering spa day passes to your guests.
	+ **Memberships**: Select this option if you are interested in offering memberships to your guests.
	+ **Packages**: Select this option if you are interested in offering packages to your guests.
* **Special Programs** (Optional, Select One):
	+ **Programs**: Select this option if you are interested in offering custom programs to your guests.
	+ **Workshops**: Select this option if you are interested in hosting workshops for your guests.
* **Guest Preferences** (Optional): This field is for any additional details or preferences you would like to share with the spa team.
* **Interactions** (Optional): This field is for any further comments or interactions with the spa team.

## Tips
* Please ensure that all fields are filled out accurately and thoroughly.
* If you are unsure about any field, please reach out to the spa team for clarification.
* Only submit one application per guest, as duplicate applications will not be accepted.
* The spa team will review your application and may contact you for further discussions or negotiations.
