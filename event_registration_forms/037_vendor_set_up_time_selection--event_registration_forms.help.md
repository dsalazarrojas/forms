# Vendor Set Up Time Selection - Help Guide
## Purpose
This form is for vendors to select their set up time for an event. Please fill out the form to provide us with your preferences.

## How To Complete This Form
1. Select the time of day you would like to arrive at the event location.
2. Choose the details you need for your set up.
3. Provide your move-in date and time.

## Field-by-Field Explanation

* **Vendor Set Up Time Selection** (`vendor_set_up_time_selection_form`, text, optional): Please select the time you would like to arrive at the event location.
* **Select One Move In Time** (`select_one_move_in_time`, select_one, optional): Choose whether you will be arriving during the morning, afternoon, or evening. If other is selected, please provide a specific time in the "Move In Time" field.
* **Select Multiple Set Up Details** (`select_multiple_set_up_details`, select_multiple, optional): Select all that apply to provide us with the details you need for your set up. Electrical, Internet, Water, and Parking are options that may be relevant to your needs.
* **Move In Date** (`move_in_date`, date, optional): Please provide the date you will be arriving at the event location.
* **Move In Time** (`move_in_time`, time, optional): If you selected "Other" in the "Select One Move In Time" field, provide the specific time you will be arriving.

## Tips
* If you selected "Other" in the "Select One Move In Time" field, please make sure to provide a specific time in the "Move In Time" field.
* If you have any questions or concerns, please contact us.
