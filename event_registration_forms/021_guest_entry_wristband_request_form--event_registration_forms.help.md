# guest_entry_wristband_request_form - Help Guide

## Purpose
The <strong>guest_entry_wristband_request_form</strong> is used to collect information about an upcoming event. This form is used to record event details and request wristband approval. 

The form is used to ensure that all necessary information is collected in a standardized format, making it easier to review and process event requests. By providing clear and concise event information, the form helps to increase the chances of successful event execution.

Before proceeding with this form, please make sure you are not resubmitting a previously submitted request. Resubmitting a request can lead to unnecessary work for our team and cause confusion in the processing of requests.

## How To Complete This Form
To complete this form, follow the steps outlined below:

1. Enter the required information for the event, including the <strong>Event Date</strong>, <strong>Event Time</strong>, and <strong>Event Location</strong>.
2. Select the correct <strong>Wristband Request</strong> for the event.
3. If applicable, select the required <strong>Approval</strong> options for the event.
4. Add any additional <strong>Notes</strong> about the event.
5. Enter your <strong>Phone Number</strong> (optional).
6. Select the <strong>Approved</strong> option to indicate the event status.

## Field-by-Field Explanation

* **Event Information (id: 1)**: Enter a brief description of the event.
* **Wristband Request (id: 2)**: Choose the correct option for the event.
  - Label 1: Select this option for event type A.
  - Label 2: Select this option for event type B.
  - Label 3: Select this option for event type C.
* **Approval (id: 3)**: Select all the approval options that apply to the event.
  - Option 1: Select this option if the event is approved.
  - Option 2: Select this option if the event is not approved.
  - Option 3: Select this option if the event has a conditional approval.
* **Notes (id: 4)**: Add any additional information about the event.
* **Event Date (id: 5)**: Enter the date of the event (MM/DD/YYYY).
* **Event Time (id: 6)**: Enter the time of the event (HH:MM AM/PM).
* **Event Location (id: 7)**: Enter the location of the event.
* **Phone Number (id: 8)**: Enter your phone number for contact purposes (optional).
* **Approved (id: 9)**: Select 'True' to indicate the event is approved, or 'False' to indicate the event is not approved.
