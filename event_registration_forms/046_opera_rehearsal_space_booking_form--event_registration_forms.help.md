# Opera Rehearsal Space Booking Form - Help Guide
## Purpose
This form is for booking the opera rehearsal space. Please fill out this form to request access to the space.

## How To Complete This Form
To complete this form, simply fill in the required fields and click "Submit" at the end. Please make sure to fill in all required fields (marked as "required") before submitting the form.

## Field-by-Field Explanation
- **Name (1)** (`Name`, text, required): Fill in the name of your group/organization.
- **Email (2)** (`Email`, email, optional): Enter your email address. This field is optional, but helps our team reach out to you with important updates.
- **Organization Name (3)** (`Organization Name`, text, optional): If you're booking on behalf of an organization, fill in the name of your organization.
- **Production Start Date (4)** (`Production Start Date`, date, optional): If you have a start date for your production, enter it here.
- **Production End Date (5)** (`Production End Date`, date, optional): If you have an end date for your production, enter it here.
- **Rehearsal Start Time (6)** (`Rehearsal Start Time`, time, optional): If you have a start time for your rehearsal, enter it here.
- **Rehearsal End Time (7)** (`Rehearsal End Time`, time, optional): If you have an end time for your rehearsal, enter it here.
- **Rehearsal Start Date (8)** (`Rehearsal Start Date`, date, optional): If you have a start date for your rehearsal, enter it here.
- **Rehearsal End Date (9)** (`Rehearsal End Date`, date, optional): If you have an end date for your rehearsal, enter it here.
- **Venue (10)** (`Venue`, select multiple, optional): Check if you need the space with or without a venue.
- **Space (11)** (`Space`, text, required): Fill in the space you are looking for.
- **Seats (12)** (`Seats`, number, optional): If you need a specific number of seats, fill it in here.
- **Space Type (13)** (`Space Type`, select one, optional): Check if you need the space with or without certain features.
- **Booking Start Date (14)** (`Booking Start Date`, date, optional): If you have a start date for your booking, enter it here.
- **Booking End Date (15)** (`Booking End Date`, date, optional): If you have an end date for your booking, enter it here.
- **Comments (16)** (`Comments`, text, optional): Add any additional comments or notes about your booking.
- **User ID (17)** (`User ID`, number, optional): If you have a user ID, please enter it here.

## Tips
Please make sure to fill in all required fields before submitting the form. If you have any questions or need further assistance, feel free to contact our support team.
