# Youth Club Incident Form - Help Guide
## Purpose
This form is designed to collect information about incidents that occurred within a youth club environment, including details about the incident, its location, cause, and outcome.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the date and time of the incident.
2. Describe the location where the incident occurred.
3. Provide a detailed description of what happened.
4. Specify the cause of the incident.
5. Indicate if anyone was injured.
6. If injuries occurred, provide a description.
7. Describe the outcome of the incident.

## Field-by-Field Explanation

* **Incident Date** (`incident_date`, date, required/optional: false): Enter the date the incident occurred.
* **Incident Time** (`incident_time`, time, required/optional: false): Enter the time the incident occurred.
* **Incident Location** (`incident_location`, text, required/optional: false): Describe the location where the incident occurred.
* **Incident Description** (`incident_description`, text, required/optional: false): Provide a detailed description of what happened.
* **Incident Cause** (`incident_cause`, text, required/optional: false): Specify the cause of the incident.
* **Injuries** (`incident_injuries`, text, required/optional: false): Indicate if anyone was injured.
* **Injuries Description** (`incident_injuries_description`, text, required/optional: false): If anyone was injured, provide a description of the injuries.
* **Incident Outcome** (`incident_outcome`, text, required/optional: false): Describe the outcome of the incident.

## Tips

* Be sure to fill out each field accurately and completely.
* If a field is not relevant to the incident, leave it blank or mark it as not applicable.
* If you are unsure about any field, ask for assistance from the youth club staff.
