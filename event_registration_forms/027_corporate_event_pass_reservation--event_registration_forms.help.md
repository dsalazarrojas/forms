# corporate_event_pass_reservation - Help Guide
## Purpose
This form is used to register corporate event passes and reserve passes for corporate events.

## How To Complete This Form
- Read the form carefully and fill out all required fields to ensure accurate and complete information.
- Select the correct company from the dropdown menu.
- Enter the employee's name.
- Enter the employee's email address.
- Enter the employee’s phone number (if required).
- Select the pass type (standard or premium).
- Select the event date.
- Select the event time.
- Enter the event location.
- Enter any additional event details.
- Select the start and end dates for the reservation.
- Enter any notes or comments about the event.
- Enter any details about the assigned tool.
- Enter the desired output file format.

## Field-by-Field Explanation
* **Company** (Select One, Required): Select the company you are representing.
* **Employee Name** (Text, Optional): Enter your name.
* **Employee Email** (Email, Optional): Enter your email address.
* **Employee Phone** (Text, Optional): Enter your phone number.
* **Pass Type** (Select One, Optional): Select the type of pass you want to reserve (standard or premium).
* **Event Date** (Date, Optional): Select the date of the event.
* **Event Time** (Time, Optional): Select the time of the event.
* **Event Location** (Text, Optional): Enter the location of the event.
* **Event Details** (Text, Optional): Enter any additional details about the event.
* **Reservation Start Date** (Date, Optional): Select the start date of the reservation.
* **Reservation End Date** (Date, Optional): Select the end date of the reservation.
* **Notes** (Text, Optional): Enter any notes or comments about the event.
* **Assigned Tool** (Text, Optional): Enter any details about the assigned tool.
* **Output File** (Text, Optional): Enter the desired output file format.
* **Event Type** (Select One, Optional): Select the type of event (meeting, conference, or workshop).
* **Event Size** (Select One, Optional): Select the size of the event (small, medium, or large).
* **Pass Type Details** (Text, Optional): Enter any details about the pass type.
* **Company 2** (Text, Optional): Enter any additional company information.
* **Employee Details** (Text, Optional): Enter any details about the employee.
* **Tool Details** (Text, Optional): Enter any details about the tool.
* **Event Details 2** (Text, Optional): Enter any additional event details.
* **Notes 2** (Text, Optional): Enter any additional notes or comments.
* **Event Description** (Text, Optional): Enter a brief description of the event.
* **Event Date 2** (Date, Optional): Select a second event date.
* **Event Location 2** (Text, Optional): Enter the location of the second event.
* **Event Size 2** (Select One, Optional): Select the size of the second event.
* **Event Type 2** (Select One, Optional): Select the type of the second event.
