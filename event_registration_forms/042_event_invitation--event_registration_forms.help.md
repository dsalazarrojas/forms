# Event Invitation - Help Guide
## Purpose
The purpose of this guide is to provide a step-by-step explanation of the Event Invitation form, ensuring that users understand the form's requirements and can fill it out correctly.

## How To Complete This Form
To complete this form, follow the instructions below:

1. Enter a brief and descriptive title of the event in the `Event Title` field.
2. Provide your name and contact information in the `Host Name` field.
3. Enter the name of the event in the `Event Name` field.
4. Specify the date of the event in the `Event Date` field. Make sure to use the correct date format (YYYY-MM-DD).
5. Enter the start and end time of the event in the `Event Start Time` and `Event End Time` fields, respectively.
6. Enter the location of the event in the `Location` field.
7. (Optional) Provide a brief description of the event in the `Description` field.
8. Choose the venue of the event from the options in the `Event Venue` field.
9. Select the type of event from the options in the `Event Type` field.
10. If applicable, enter the capacity of the event in the `Event Capacity` field.
11. Choose the ticket type from the options in the `Event Tickets` field.
12. Enter your email address in the `Email` field.
13. (Optional) Enter your phone number in the `Phone` field.
14. If the event has an online presence, enter the event URL in the `Event URL` field.

## Field-by-Field Explanation
- **Event Title** (`form_title`, required/optional): Enter a brief and descriptive title of the event that will help attendees quickly understand what the event is about.
- **Host Name** (`host_name`, required/true): This field is for the host or organizer's contact information. Please enter your name as the host of the event.
- **Event Name** (`event_name`, required/true): Enter the name of the event you are inviting people to.
- **Event Date** (`event_date`, required/true): Enter the date of the event using the YYYY-MM-DD format.
- **Event Start Time** (`event_start_time`, required/true): Enter the start time of the event.
- **Event End Time** (`event_end_time`, required/true): Enter the end time of the event.
- **Location** (`location`, required/true): Enter the physical location of the event.
- **Description** (`event_description`, optional/true): Provide a brief description of the event to give attendees an idea of what to expect.
- **Event Venue** (`event_venue`, optional/true): Choose the venue of the event from the available options.
- **Event Type** (`event_type`, optional/true): Select the type of event from the available options.
- **Event Capacity** (`event_capacity`, optional/true): Enter the capacity of the event, if applicable.
- **Event Tickets** (`event_tickets`, optional/true): Choose the ticket type from the available options.
- **Email** (`email`, required/true): Enter your email address as the host or contact person.
- **Phone** (`phone`, optional/true): Enter your phone number, if you wish to be contacted by attendees.
- **Event URL** (`event_url`, optional/true): If the event has an online presence, enter the URL of the event website or platform.

## Tips
- Make sure to fill out all required fields to avoid any issues or conflicts during the event registration process.
- Review the event information carefully before submitting the form to ensure accuracy and completeness.
