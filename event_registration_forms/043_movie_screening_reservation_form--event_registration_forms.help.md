# movie_screening_reservation_form - Help Guide
## Purpose
This form is intended for users to reserve a movie screening by providing movie details, screening time, and other necessary information to finalize the reservation.

## How To Complete This Form

To complete this form, follow the steps below:

1. Select the movie title for the screening (Movie Screening Details).
2. Select the preferred screening time (Screening Time).
3. Enter the seat number you wish to reserve.
4. Input the reservation date and time.
5. Add any additional notes (Notes).
6. Select the preferred payment method (Payment Method).
7. Input the card number for the chosen payment method.
8. Confirm the expiration date of the card.
9. Confirm the CVV (Card Verification Value) number of the card.
10. Input the ZIP code for the billing address.
11. Confirm the email address associated with the reservation.
12. Confirm the phone number associated with the reservation.
13. Confirm the card number and payment method (same as steps 6-7).
14. Confirm the expiration date of the card (same as step 8).
15. Confirm the CVV number of the card (same as step 9).
16. Confirm the ZIP code for the billing address (same as step 10).

## Field-by-Field Explanation

* **Movie Screening Details**: Select the movie title for the screening you wish to reserve.
* **Screening Time**: Choose the time for the screening you want to attend.
* **Seat Number**: Enter the seat number you wish to reserve.
* **Reservation Date**: Input the date you wish to make the reservation.
* **Reservation Time**: Input the time you wish to make the reservation.
* **Notes**: Add any additional comments or notes about your reservation.
* **Payment Method**: Select the payment method you wish to use (Cash, Credit Card, or PayPal).
* **Card Number**: Input the card number for the chosen payment method.
* **Expiration Date**: Confirm the expiration date of the card.
* **CVV**: Confirm the CVV number of the card.
* **ZIP Code**: Input the ZIP code for the billing address.
* **Confirm Email**: Confirm the email address associated with the reservation.
* **Confirm Phone**: Confirm the phone number associated with the reservation.
* **Confirm Card Number**: Confirm the card number (same as "Card Number").
* **Confirm Expiration Date**: Confirm the expiration date of the card (same as "Expiration Date").
* **Confirm CVV**: Confirm the CVV number of the card (same as "CVV").
* **Confirm ZIP Code**: Confirm the ZIP code for the billing address (same as "ZIP Code").
* **Confirm Payment Method**: Confirm the payment method you have chosen (same as "Payment Method").
* **Confirm Seat Number**: Confirm the seat number you wish to reserve.
* **Confirm Reservation Date**: Confirm the reservation date you have chosen.
* **Confirm Reservation Time**: Confirm the reservation time you have chosen.
* **Confirm Notes**: Confirm any additional comments or notes about your reservation.
* **Confirm Email**: Confirm the email address associated with the reservation (same as "Confirm Email").
* **Confirm Phone**: Confirm the phone number associated with the reservation (same as "Confirm Phone").
