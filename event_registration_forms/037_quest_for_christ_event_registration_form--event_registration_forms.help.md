# Quest For Christ Event Registration Form - Help Guide
## Purpose
The Quest For Christ Event Registration Form is used to collect event-related information from attendees. This form helps us understand who is attending the event, what type of event it is, and other relevant details.

## How To Complete This Form
1. Fill in the required fields as indicated by the asterisk (\*) symbol.
2. Provide accurate information in all fields, as we'll use this data to manage event attendees and their associated details.
3. If a field is marked as optional, you can leave it blank or fill it in as needed.
