# Stage Setup Intake Form - Help Guide
## Purpose
The Stage Setup Intake Form is designed to collect event setup information from users to ensure accurate and efficient event registration.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the event name and any other relevant details.
2. Select a date for the event.
3. Choose a time for the event start and end.
4. Provide the location of the event.
5. Enter the stage name and any specific requirements.
6. Add any event planner contact information.
7. Add any additional event notes.

## Field-by-Field Explanation
* **Event Name** (`event_name`, text, required): Enter the name of the event.
* **Event Date** (`event_date`, date, required): Select the date of the event.
* **Event Start Time** (`event_start_time`, time, required): Choose the start time of the event.
* **Event End Time** (`event_end_time`, time, required): Choose the end time of the event.
* **Event Location** (`event_location`, text, optional): Enter the location of the event.
* **Stage Name** (`stage_name`, text, optional): Enter the name of the stage.
* **Event Details** (`event_details`, text, optional): Add any additional event details.
* **Stage Requirements** (`stage_requirements`, text, optional): Enter any specific stage requirements.
* **Event Planner** (`event_planner`, text, optional): Enter the event planner's contact information.
* **Event Notes** (`event_notes`, text, optional): Add any additional event notes.
