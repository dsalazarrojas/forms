# Event Sponsorship Extension Form - Help Guide
## Purpose
The Event Sponsorship Extension Form is a tool used by event organizers to collect information from potential sponsors about their interest in sponsoring an event or conference.

## How To Complete This Form
To complete this form, follow these steps:

1. Provide the title of the event you are interested in sponsoring, if applicable.
2. Answer the question about your willingness to sponsor, with an option to indicate if you are or are not interested.
3. Enter your name and contact information if you are interested in sponsoring.
4. Select the type of sponsorship you are offering, if applicable (e.g. monetary, product/service provision, etc.).
5. If applicable, enter the amount of sponsorship you are offering.
6. Enter your email and phone number so that event organizers can contact you for further discussion.

## Field-by-Field Explanation
* **Event Sponsor** (`event_sponsorship_name`): Enter the title of the event you are interested in sponsoring. If the event has not been assigned a title yet, you can leave this field blank.
* **Sponsor** (`sponsor_type`): Select 'Yes' if you are interested in sponsoring the event, or 'No' if you are not interested.
* **Contact Name** (`sponsor_contact_name`): Enter your name so that event organizers can contact you for further discussion.
* **Company** (`company`): Enter your company name if you are representing a business.
* **Sponsor Type** (`sponsor_type`): Select the type of sponsorship you are offering, if applicable (e.g. monetary, product/service provision, etc.). If you are not sure about the types of sponsorships available, you can ask the event organizers for more information.
* **Sponsorship Amount** (`sponsorship_amount`): Enter the amount of sponsorship you are offering, if applicable.
* **Email** (`email`): Enter your email address so that event organizers can contact you for further discussion.
* **Phone** (`phone`): Enter your phone number so that event organizers can contact you for further discussion.
* **Phone (again)** (`phone`): This is a duplicate field for your phone number.
