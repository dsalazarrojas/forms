# Team Recognition Event Request Form - Help Guide
## Purpose
This form is used to request and coordinate a team recognition event.

## How To Complete This Form
To complete this form, follow the steps below:

1.  Fill out the Event Date field with the date you would like the team recognition event to take place on.
2.  Enter the Event Time field with the start time of the event.
3.  Select the Event Location (Venue) field with the exact name of the venue where the event will be held.
4.  Enter the Event Address field with the physical address of the venue.
5.  Enter the City field with the city of the venue's location.
6.  Enter the State/Province field with the state or province where the venue is located.
7.  Enter the Postal Code field with the postal code or zip code of the venue.
8.  Enter the Requesting Team Member Name field with the name of the team member requesting the recognition.
9.  Enter the Team Name field with the name of the team being recognized.
10.  Select the Recognition Type field with the type of recognition being requested.
11.  Enter the Brief Description of Event field with a brief description of the event.
12.  Optionally, enter Additional Notes if you have any other important information about the event.

## Field-by-Field Explanation
* **Event Date**: Enter the date you would like the team recognition event to take place on. Use the date in the format `mm/dd/yyyy`. Please ensure this date is accurate and feasible.
* **Event Time**: Enter the start time of the event in 24-hour format. For example, 02:00 PM would be 14:00.
* **Event Location (Venue)**: Enter the exact name of the venue where the event will be held.
* **Event Address**: Enter the physical address of the venue, including the street, number, and building.
* **City**: Enter the city where the venue is located.
* **State/Province**: Enter the state or province where the venue is located.
* **Postal Code**: Enter the postal code or zip code of the venue.
* **Requesting Team Member Name**: Enter the name of the team member requesting the recognition.
* **Team Name**: Enter the name of the team being recognized.
* **Recognition Type**: Select the type of recognition being requested.
* **Brief Description of Event**: Enter a brief description of the event, including the reason for recognition.
* **Additional Notes**: You can enter any additional information about the event in this field if you need to.
