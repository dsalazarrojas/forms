# Swartz Creek Community Schools - Help Guide
## Purpose
This form is designed for registering events at Swartz Creek Community Schools. It helps us gather information about upcoming events and their details.

## How To Complete This Form
To complete this form, please follow these steps:
1. Fill in the required fields with accurate information about the event.
2. Select the appropriate event type(s) from the provided options.
3. Click on the "Submit" button to send the form.

## Field-by-Field Explanation

* **Event Details**: This is the main information page for the event.
* **Event Name**: The name of the event. Please provide a brief and descriptive title for the event.
* **Event Date**: The date of the event. Please use the standard date format (YYYY-MM-DD).
* **Event Time**: The time of the event. Use the 12-hour clock format (HH:MM AM/PM).
* **Event Location**: The venue or location of the event.
* **Event Description**: A brief description of the event.
* **Contact Person**: The person to contact for further information about the event.
* **Contact Phone**: The phone number of the contact person.
* **Contact Email**: The email address of the contact person.
* **Submit**: Click on this button to send the form.
* **Event Type**: Please select the type of event this is (e.g., Event Type 1, Event Type 2, Event Type 3).
* **Event Date 2**: (Optional) If this event repeats, please provide the date(s) of subsequent events.
* **Event Time 2**: (Optional) If this event repeats, please provide the time of subsequent events.
* **Event Location 2**: (Optional) If this event repeats, please provide the location(s) of subsequent events.
* **Event Description 2**: (Optional) If this event repeats, please provide a brief description of subsequent events.
* **Contact Person 2**: (Optional) If this event repeats, please provide the person(s) to contact for further information.
* **Contact Phone 2**: (Optional) If this event repeats, please provide the phone number(s) of the contact person(s).
* **Contact Email 2**: (Optional) If this event repeats, please provide the email address(es) of the contact person(s).
* **Submit 2**: (Optional) If this event repeats, please click on this button to send the form.
* **Notes**: Any additional comments or information about the event.

## Tips
Please fill in the form accurately and thoroughly to help us manage events effectively. If you have any questions or need further assistance, please don't hesitate to contact us.
