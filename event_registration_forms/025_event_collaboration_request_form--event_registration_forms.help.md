# Event Collaboration Request Form - Help Guide
## Purpose
This form is for event organizers or coordinators to request collaboration from sponsors or other entities for their events.

## How To Complete This Form
To complete this form, please follow these steps:

1.  Determine whether or not you want to request collaboration (page 1).
2.  Fill out the event details (page 2).
3.  Specify the event start and end dates (page 3).
4.  Provide the event location and organizer information (page 4).
5.  Specify whether or not the event has partners (page 5).
6.  Submit a proposal for the event (page 6).
7.  Provide the event budget (page 7).
8.  Specify the event terms and conditions (page 8).
9.  Describe the details of the collaboration request (page 9).
10.  Specify the details of any sponsorship (page 10).
11.  Provide the contact information for the event sponsor (page 11).
12.  Provide the deadline for sponsorship consideration (page 12).

## Field-by-Field Explanation
- **Collaboration Request** (page 1, type: select_one, required: true): Choose 'Yes' to request collaboration from sponsors for your event.
  - **Event Name** (page 2, type: text, required: true): Enter the name of your event.
  - **Event Description** (page 2, type: text, required: true): Provide a brief description of your event.
  - **Event Start Date** (page 3, type: date, required: true): Enter the start date of your event.
  - **Event End Date** (page 3, type: date, required: true): Enter the end date of your event.
  - **Event Location** (page 4, type: text, required: true): Provide the location of your event.
  - **Event Organizer** (page 4, type: text, required: true): Enter the name and contact information of the event organizer.
  - **Event Partners** (page 5, type: select_multiple, required: true): Choose whether or not the event has partners.
  - **Event Proposal** (page 6, type: text, required: true): Submit a proposal for your event.
  - **Event Budget** (page 7, type: number, required: true): Enter the budget for your event.
  - **Event Terms and Conditions** (page 8, type: text, required: true): Specify any terms and conditions for the event.
  - **Collaboration Request Details** (page 9, type: text, required: true): Describe the details of your collaboration request.
  - **Sponsorship Details** (page 10, type: text, required: true): Describe the details of any sponsorship you are seeking.
  - **Sponsorship Contact** (page 11, type: email, required: true): Enter the contact email for the sponsor.
  - **Sponsorship Phone** (page 11, type: text, required: true): Enter the phone number for the sponsor.
  - **Event Terms** (page 12, type: text, required: true): Specify any terms and conditions for the event.
  - **Event Terms and Conditions** (page 12, type: text, required: true): Specify any additional terms and conditions for the event.
  - **Sponsors** (page 13, type: select_multiple, required: false): Choose whether or not you are looking for sponsors.
  - **Event Organizer Email** (page 14, type: email, required: true): Enter the email of the event organizer.
  - **Event Organizer Phone** (page 14, type: text, required: true): Enter the phone number of the event organizer.
  - **Sponsors Email** (page 15, type: email, required: false): Enter the email of the sponsor (if applicable).
  - **Sponsors Phone** (page 15, type: text, required: false): Enter the phone number of the sponsor (if applicable).
  - **Event Sponsorship Deadline** (page 16, type: date, required: true): Enter the deadline for sponsorship consideration.

## Tips
- Ensure that all fields are filled out accurately and thoroughly.
- Review the form carefully before submission to avoid errors.
- Be prepared to provide additional information as needed.
