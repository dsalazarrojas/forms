# Holiday Stress Workshop Feedback - Help Guide
## Purpose
The Holiday Stress Workshop Feedback form is designed to collect feedback from participants after attending the workshop. Your input will help us understand what you enjoyed, what you didn't, and how we can improve future workshops.

## How To Complete This Form
To complete this form, follow these steps:

1. Provide your participant name and email address (if you'd like to be contacted for follow-up questions).
2. Answer the question "What do you like" to give us an idea of what you enjoyed most about the workshop.
3. Rate your stress levels before and after the workshop on a scale of 0-5.
4. Provide any suggestions or comments you might have for us to improve future workshops.
5. Let us know how you'd like to be contacted for follow-up questions (if you'd like to be contacted).

## Field-by-Field Explanation
* **Holiday Stress Workshop Feedback** (`holiday_stress_workshop_feedback`): Please write a short message describing what you enjoyed most about the workshop.
* **Participant Name** (`participant_name`): Please enter your name as you'd like to be addressed.
* **Email** (`email`): If you'd like to be contacted for follow-up questions, please provide your email address. We'll only contact you if you've given us permission.
* **Stress Levels** (`stress_levels`): Rate your stress levels before and after the workshop on a scale of 0-5.
* **Suggestions** (`suggestions`): Do you have any suggestions on how we can improve future workshops?
* **Contact Us** (`Would you like to be contacted for follow-up questions`): Please select how you'd like to be contacted (Email, Phone, Both, or No preference).
* **How Would You Like to Be Contacted?** (`How would you like to be contacted?`): This question is only visible if you've selected to be contacted in the previous question. Please select one of the options provided.
* **Do You Have Any Comments?** (`Do you have any comments?`): Is there anything else you'd like to share with us about your experience with the workshop?
