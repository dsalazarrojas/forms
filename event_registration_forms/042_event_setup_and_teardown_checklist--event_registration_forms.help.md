# event-setup-and-teardown-checklist - Help Guide
## Purpose
The event-setup-and-teardown-checklist form is designed to aid event planners in preparing and executing events. It helps to identify the tasks involved in setting up and tearing down an event.

## How To Complete This Form
To complete this form, follow these steps:
- Fill out each section according to the event's specific needs and circumstances.
- Review and adjust the fields as necessary to ensure accuracy and relevance.
- Make sure to fill out all required fields, marked with an asterisk (*) if any.

## Field-by-Field Explanation
* **Event Planning Tasks** (`event_planning_tasks`, text, optional): This field is for any general event planning tasks that need to be completed. Type in any relevant information or tasks that are not covered in other sections.
* **Vendor Coordinators Checklist** (`vendor_coordinators_checklist`, select_multiple, optional): Indicate whether you need to coordinate with vendors for specific tasks. Select 'Yes' for tasks that require vendor coordination and 'No' otherwise.
* **Setup Timeline** (`setup_timeline`, date, optional): Enter the date on which you need to start setting up for the event.
* **Venue Coordinators Checklist** (`venue_coordinators_checklist`, select_multiple, optional): Check if you need to coordinate with venue staff for specific tasks. Select 'Yes' for tasks that require venue coordination and 'No' otherwise.
* **Event Executive Checklist** (`event_executive_checklist`, select_multiple, optional): Check if you need to coordinate with event executives for specific tasks. Select 'Yes' for tasks that require event executive coordination and 'No' otherwise.
* **Vendors Checklist** (`vendors_checklist`, select_multiple, optional): Check if you need to coordinate with vendors for specific tasks. Select 'Yes' for tasks that require vendor coordination and 'No' otherwise.
* **Event Executive Checklist 2** (`event_executive_checklist_2`, select_multiple, optional): Check if you need to coordinate with event executives for specific tasks. This field is similar to the previous one and should be used to cover any additional tasks that the first field does not cover.

## Tips
- Review and adjust the form according to your specific event needs.
- Ensure that all required fields are filled out.
- If a field is unclear, try to use the best-effort explanation provided here or contact your event organizer for clarification.
