# Hackathon Data Release Form - Help Guide
## Purpose
This form is intended to capture participant consent and project information for the Hackathon data release. It will help us understand participant preferences and project details to proceed with data release.

## How To Complete This Form
To complete this form, please follow the instructions below:

1. Select one of the options for each question, and make sure to answer all the required questions.
2. Enter your responses into the corresponding text fields.
3. Make sure to review your answers carefully before submitting the form.
