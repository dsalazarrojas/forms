# educational_game_developers_roundtable_registration - Help Guide

## Purpose
This form is for registration to an event focused on educational game development. It aims to gather information from attendees, including their contact details, professional roles, and interests.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter your first name in the "First name" field.
2. Enter your last name in the "Last name" field.
3. Enter your email address in the "Email" field.
4. Select your role(s) from the "Role" dropdown menu (choose one or multiple options).
5. If you have a company, enter its name in the "Company" field.
6. Select your session interests from the "Session interests" dropdown menu (choose one or multiple options).
7. If you have any discussion topics in mind, provide them in the "Discussion topics" text field.

## Field-by-Field Explanation

### First name
* **First name** (`first_name`, text, optional): Enter your first name here.

### Last name
* **Last name** (`last_name`, text, optional): Enter your last name here.

### Email
* **Email** (`email`, email, optional): Enter your email address here. This should be a valid email address that can be used to contact you.

### Role
* **Role** (`role`, select_one, optional): Select your role among:
	+ Developer
	+ Game Designer
	+ Educator

### Company
* **Company** (`company`, text, optional): If you have a company, enter its name here.

### Session interests
* **Session interests** (`session_interests`, select_multiple, optional): Select one or multiple session interests among:
	+ Game Development
	+ Game Design
	+ Game Research

### Discussion topics
* **Discussion topics** (`discussion_topics`, text, optional): If you have any discussion topics in mind, provide them here.

### Submit
* **Submit** (`submit`, note, optional): Click this button to submit your registration.
