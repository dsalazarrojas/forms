# Networking Event Attendee Registration - Help Guide
## Purpose
This form is used to register attendees for a networking event. It collects basic information such as name, contact details, interests, and preferences to ensure a smooth and enjoyable experience for all attendees. Please fill out the form with accurate and up-to-date information.

## How To Complete This Form
To register for the networking event, please follow these steps:

1. Enter your name and email address in the corresponding fields.
2. Select your interests from the list, as they will help us understand what you're passionate about and what you're looking for at the event.
3. If you have any preferences or additional details you'd like to share, type them in the "Additional Details" field.
4. Confirm that you have attended events like this before, and select the correct option.
5. Enter the date and time of the event. Please use the correct format for the date (dd/mm/yyyy).
6. If applicable, specify which tool you'll be using during the event.

## Field-by-Field Explanation

* **Name**: Please enter your full name as it appears on your business card or introduction.
* **Email**: Enter a valid email address where you can be reached for follow-up communication.
* **Phone**: Enter your primary phone number where you can be reached.
* **Interests**: Select all the areas that interest you (e.g., IT, Marketing, Finance, etc.). This will help us tailor the event to your interests.
* **Preferences**: If you have any special preferences or requests, please type them here.
* **Address**: Enter your work or personal address for our records.
* **Organization**: Enter your current or previous company name.
* **Bio**: Briefly describe yourself and what you do.
* **Job Title**: Enter your current job title.
* **Additional Details**: If you have any other information you'd like to share, type it here.
* **Confirm Event**: Please select the correct option for how many events like this you've attended.
* **Event Date**: Enter the date of the event in the correct format (dd/mm/yyyy).
* **Event Time**: Enter the time of the event.
* **Assigned Tool**: If you're assigned a specific tool for the event, enter it here.

Note: All fields with a red star (*) are required.
