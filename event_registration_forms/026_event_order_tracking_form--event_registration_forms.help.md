# Event Order Tracking Form - Help Guide
## Purpose
The Event Order Tracking Form is used to monitor and track event orders, capturing important details about attendees, payments, and other relevant information.

## How To Complete This Form
To complete the form, follow these steps:

1. Select the relevant options for each field based on the available options.
2. Enter the required information in the corresponding fields.
3. Review the form for accuracy before submitting it.

## Field-by-Field Explanation
* **Event Order Tracking Form** (`text`): Enter a name for the event order.
* **Attendee Information** (`select_one`): Choose the correct option from the list of attendees.
* **Payment Status** (`select_multiple`): Select all applicable payment statuses.
* **Specific Requests** (`text`): Enter any specific requests or notes related to the event order.
* **Notes** (`text`): Add any additional comments or notes about the event order.
* **Order Date** (`date`): Enter the date of the event order.
* **Order Time** (`time`): Enter the time of the event order.
* **Contact Info** (`text`): Enter the contact information for the event order.
* **Email** (`email`): Enter the email address of the event order contact.
* **Phone** (`text`): Enter the phone number of the event order contact.
* **Assigned Tool** (`text`): Enter the tool assigned to the event order.
* **Status** (`select_one`): Choose the current status of the event order.
* **Order Comments** (`text`): Add any comments or notes about the event order.
* **Payment Amount** (`number`): Enter the payment amount received for the event order.
* **Payment Method** (`text`): Enter the payment method used for the event order.
* **Order ID** (`text`): Enter the unique ID of the event order.

## Tips
* Make sure to fill out all required fields to ensure accurate tracking.
* Double-check the form for accuracy before submitting.
* Keep the form up-to-date to reflect any changes to the event order.
