# Event Seating Arrangement Complaint Form - Help Guide
## Purpose
This form is for event participants to report any seating arrangement complaints or concerns related to an event they attended. Please note that you're reporting an issue related to your own experience at the event.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the category that best describes your issue (Event or Stage).
2. Provide the necessary information in the text fields, such as the seat number and row.
3. Describe the issue that occurred using the "description" field.
4. Enter your contact information (email and phone number) so that we can reach out to you for further discussion.
5. Click the "submit" button to submit your report.

## Field-by-Field Explanation

### 1. **Seat Arrangement** (`seat_arrangement`, text, optional)
This field allows you to describe the seating arrangement you experienced. Try to be as specific as possible about what was reported to you.

### 2. **Event Date** (`event_date`, date, optional)
Please enter the date of the event for which you're reporting the issue.

### 3. **Seat Number** (`seat_number`, number, optional)
Enter the number of the seat where you experienced the issue.

### 4. **Seat Row** (`seat_row`, number, optional)
Enter the row number of the seat where you experienced the issue.

### 5. **Description** (`description`, text, optional)
Provide a detailed description of what happened during the event.

### 6. **Email** (`email`, email, optional)
Enter your email address so that we can contact you for further discussion.

### 7. **Phone** (`phone`, text, optional)
Enter your phone number so that we can contact you for further discussion.

### 8. **Category** (`category`, select_one, optional)
Select the category that best describes your issue:
	* Event (related to the event's overall experience)
	* Stage (related to the stage or presentation)
	* Other (for any other issue not related to the event or stage)

### 9. **Submit** (`submit`, text, optional)
Click this button to submit your report.
