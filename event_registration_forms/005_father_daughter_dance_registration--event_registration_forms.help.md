# Father Daughter Dance Registration - Help Guide
## Purpose
This form is designed to collect information for the Father Daughter Dance event registration. Please fill out the form accurately and completely to ensure that the event organizers can provide the best experience for you and your guests.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the **First Name** field with your full name.
2. Provide your **Last Name** in the corresponding field.
3. Enter your email address in the **Email** field.
4. Select the **Event Date** for the event.
5. Choose the **Event Time** for the event.
6. Enter the **Number of Guests** you plan to bring.
7. Add a message if you have any specific requests or comments.
8. If applicable, enter your **Phone** number.
9. Select the **Category** of the event (e.g., Category 1, Category 2, Category 3).
10. Select any relevant options from the **Select One** field (e.g., Option 1, Option 2, Option 3).
11. Select multiple options from the **Select Multiple** field (e.g., Option 1, Option 2, Option 3, Option 4).
12. Add any additional notes in the **Note** field.
13. Choose the **Event Type** (e.g., Event Type 1, Event Type 2, Event Type 3).
14. Enter the **Event Location** where the event will take place.
15. Enter the name of the person or team assigned to handle your event (in the **Assigned To** field).
16. Enter the name of the tool or resource assigned to your event (in the **Assigned Tool** field).
17. Choose the **Event Status** (e.g., Event Status 1, Event Status 2, Event Status 3).
18. Select the date when the event was created (not editable).
19. Select the date when the event was last updated (not editable).
20. Select the date when the event was deleted (not editable).
21. Enter the name of the person who deleted the event (in the **Deleted By** field).
22. Select the date when the event was deleted (not editable).
23. Enter the name of the person who assigned the event (in the **Assigned By** field).
24. Enter the name of the person who created the event (in the **Created By** field).
25. Enter any additional information or category for the event (in the **Category** field).

## Field-by-Field Explanation
* **First Name** (Text): Enter your full name.
* **Last Name** (Text): Enter your last name.
* **Email** (Email): Enter your email address.
* **Event Date** (Date): Select the date of the event.
* **Event Time** (Time): Choose the time of the event.
* **Number of Guests** (Number): Enter the number of guests you plan to bring.
* **Message** (Note): Add any additional comments or requests.
* **Phone** (Text): Enter your phone number.
* **Category** (Select One): Select the event category (e.g., Category 1, Category 2, Category 3).
* **Select One** (Select One): Select one option from the list (e.g., Option 1, Option 2, Option 3).
* **Select Multiple** (Select Multiple): Select multiple options from the list (e.g., Option 1, Option 2, Option 3, Option 4).
* **Note** (Note): Add any additional notes.
* **Event Type** (Select One): Select the event type (e.g., Event Type 1, Event Type 2, Event Type 3).
* **Event Location** (Text): Enter the location of the event.
* **Assigned To** (Text): Enter the name of the person assigned to handle your event.
* **Assigned Tool** (Text): Enter the name of the tool or resource assigned to your event.
* **Event Status** (Select One): Select the event status (e.g., Event Status 1, Event Status 2, Event Status 3).
* **Created At** (Date): Not editable, automatically filled by the system.
* **Updated At** (Date): Not editable, automatically filled by the system.
* **Deleted At** (Date): Not editable, automatically filled by the system.
* **Deleted By** (Text): Enter the name of the person who deleted the event.
* **Assigned By** (Text): Enter the name of the person who assigned the event.
* **Created By** (Text): Enter the name of the person who created the event.
* **Category** (Text): Enter any additional information or category for the event.
