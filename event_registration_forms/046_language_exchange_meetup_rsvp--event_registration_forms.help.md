# Language Exchange Meetup RSVP - Help Guide
## Purpose
This guide will help you complete the Language Exchange Meetup RSVP form correctly and effectively.

## How To Complete This Form

1. Select the language you are willing to speak on the language exchange meetup event.
2. Choose your current level of language skill to help the organizers plan the meetup sessions.
3. Indicate if you are interested in learning a new language.
4. Confirm your attendance by selecting the RSVP option.
5. Provide any additional comments or questions you may have.
6. Submit your email address and phone number for contact purposes.

## Field-by-Field Explanation

* **Language Spoken** (`language_spoken`, select_one, required): Select the language you are willing to speak on the meetup event.
* **Level of Language Skill** (`level_of_language_skill`, select_one, required): Choose your current level of language skill to help the organizers plan the meetup sessions. 
* **Language to Learn** (`language_to_learn`, select_one, required): Indicate if you are interested in learning a new language.
* **RSVP** (`rsvp`, select_one, required): Confirm your attendance by selecting the correct option.
* **Comment** (`comment`, note, required): Provide any additional comments or questions you may have.
* **Email** (`email`, email, required): Submit your email address for contact purposes.
* **Phone** (`phone`, text, required): Submit your phone number for contact purposes.
* **Event Registration Form** (`event_registration_form`, text, required): This field is not relevant for the user to fill out, but is included for system generated purposes.
* **Name** (`name`, text, required): Your name is required for event registration purposes.
* **Availability** (`availability`, time, not required): This field is not necessary for the user to fill out, but is provided for system internal management.
* **Availability Time** (`availability_time`, time, not required): This field is not necessary for the user to fill out, but is provided for system internal management.
* **Event Date** (`event_date`, date, not required): This field is not necessary for the user to fill out, but is provided for system internal management.
* **Meetup Date** (`meetup_date`, date, not required): This field is not necessary for the user to fill out, but is provided for system internal management.
* **Event Meetup Time** (`event_meetup_time`, time, not required): This field is not necessary for the user to fill out, but is provided for system internal management.
* **Meetup Time** (`meetup_time`, time, not required): This field is not necessary for the user to fill out, but is provided for system internal management.
* **Event Meetup ID** (`event_meetup_id`, text, not required): This field is not necessary for the user to fill out, but is provided for system internal management.
* **Language Exchange Meetup ID** (`language_exchange_meetup_id`, text, not required): This field is not necessary for the user to fill out, but is provided for system internal management.

Note: Some fields are not required for the user to fill out and are provided for system internal purposes. Please do not worry about filling them out as they are not relevant for your meetup RSVP.
