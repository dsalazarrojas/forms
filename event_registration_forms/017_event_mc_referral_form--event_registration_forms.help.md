# Event MC Referral Form - Help Guide
## Purpose
This guide will walk you through completing the Event MC Referral Form, a vital tool for event planners and coordinators to gather necessary information about events.

## How To Complete This Form
1. **Event Title**: Enter the title or name of the event you wish to register. Make sure it is accurately and completely filled out.
2. **Event Date**: Select the date of the event you wish to register. This is a required field, so ensure you fill it out correctly.
3. **Event Time**: Choose the time of the event. It is essential to get this information right, as it will help in the coordination process.
4. **Referral Name**: Enter the name of the referral you are dealing with. This is also a required field.
5. **Referral Position**: From the options provided, select the position or title associated with the referral. This selection is required to categorize referrals accurately.
6. **Referral Phone**: Enter the phone number of the referral. Ensure it is accurate and up to date.
7. **Referral Email**: Enter the email address of the referral. This is a required field for communication.
8. **Event MC Name**: Enter the name of the event MC. This information is critical for event coordination.
9. **Event MC Phone**: Enter the phone number of the event MC. Ensure it is accurate for contact purposes.
10. **Event MC Email**: Enter the email address of the event MC. This is a required field for communication and coordination.
11. **Event MC Position**: Enter the position or title of the event MC. This helps in organizing and categorizing events.
12. **Event Notes**: If necessary, add any additional notes about the event. While not required, it is helpful for further context and reference.
13. **Event Status**: Select the status of the event from the provided options: Approved, Pending, or Rejected. This is a required field for event tracking.
14. **Assigned Tool**: Enter the tool assigned to the event. This ensures that the correct tools are allocated for the event.
## Field-by-Field Explanation
* **Event Title** (`event_mc_referral_form`, `text`, required): Enter the name or title of the event you wish to register.
* **Event Date** (`event_name`, `date`, required): Select the date of the event you are registering.
* **Event Time** (`event_time`, `time`, required): Choose the time of the event accurately.
* **Referral Name** (`referral_name`, `text`, required): Enter the name of the referral you are dealing with.
* **Referral Position** (`referral_position`, `select_one`, required): From the options provided, select the position or title associated with the referral.
* **Referral Phone** (`referral_phone`, `text`, required): Enter the phone number of the referral accurately.
* **Referral Email** (`referral_email`, `email`, required): Enter the email address of the referral for effective communication.
* **Event MC Name** (`event_mc_name`, `text`, required): Enter the name of the event MC.
* **Event MC Phone** (`event_mc_phone`, `text`, required): Enter the phone number of the event MC for contact purposes.
* **Event MC Email** (`event_mc_email`, `email`, required): Enter the email address of the event MC for communication and coordination.
* **Event MC Position** (`event_mc_position`, `text`, required): Enter the position or title of the event MC.
* **Event Notes** (`event_notes`, `note`, optional): Add any additional notes about the event if necessary, but not required.
* **Event Status** (`event_status`, `select_multiple`, required): Select the status of the event from the provided options: Approved, Pending, or Rejected.
* **Assigned Tool** (`assigned_tool`, `text`, required): Enter the tool assigned to the event accurately.
## Tips
- Double-check your entries for accuracy before submitting the form.
- Ensure that all required fields are filled in thoroughly.
- If you are unsure about any field, consult with the relevant stakeholders for clarification.
