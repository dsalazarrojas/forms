# voice-over-recording-reservation-form - Help Guide

## Purpose
This form is designed for clients to reserve a voice-over recording project. It gathers essential information from clients, including the project title, event details, and participant contact details. The form helps the studio and artist prepare for the session and ensures that all necessary information is exchanged before the recording takes place.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the project title and event details, including the event name, date, and time.
2. Provide the client's contact information, such as their name, email, and phone number.
3. Enter the artist's contact information, including their name, email, and phone number.
4. Add the studio's contact information, including their name and address.
5. If applicable, specify the project URL and session notes.
6. Choose the event tags (Audio, Video, or Live Drawing) that best describe the project.
7. Select the artist's availability (Mon - Fri, Sat, Sun, or Mon, Tue, Wed, Thu, Fri).
8. Specify the project status (New, In Progress, or Completed).

## Field-by-Field Explanation

* **Form Title** (id: 1, name: form_title, label: Form Title, type: text, required: false):
  Enter a brief title for the project.
* **Event Name** (id: 2, name: event_name, label: Event Name, type: text, required: false):
  Enter the name of the event for which you are reserving the voice-over recording project.
* **Project Name** (id: 3, name: project_name, label: Project Name, type: text, required: false):
  Enter the name of the project or the name of the client's company.
* **Event Date** (id: 4, name: event_date, label: Event Date, type: date, required: false):
  Enter the date of the event for which you are reserving the voice-over recording project.
* **Event Time** (id: 5, name: event_time, label: Event Time, type: time, required: false):
  Enter the time of the event for which you are reserving the voice-over recording project.
* **Event Date End** (id: 6, name: event_date_end, label: Event Date End, type: date, required: false):
  Enter the end date of the event for which you are reserving the voice-over recording project.
* **Project Duration** (id: 7, name: project_duration, label: Project Duration, type: number, required: false):
  Enter the expected duration of the project.
* **Client Name** (id: 8, name: client_name, label: Client Name, type: text, required: false):
  Enter the client's name.
* **Client Email** (id: 9, name: client_email, label: Client Email, type: email, required: false):
  Enter the client's email address.
* **Client Phone** (id: 10, name: client_phone, label: Client Phone, type: text, required: false):
  Enter the client's phone number.
* **Artist Name** (id: 11, name: artist_name, label: Artist Name, type: text, required: false):
  Enter the artist's name.
* **Artist Email** (id: 12, name: artist_email, label: Artist Email, type: email, required: false):
  Enter the artist's email address.
* **Artist Phone** (id: 13, name: artist_phone, label: Artist Phone, type: text, required: false):
  Enter the artist's phone number.
* **Studio Name** (id: 14, name: studio_name, label: Studio Name, type: text, required: false):
  Enter the name of the studio.
* **Studio Address** (id: 15, name: studio_address, label: Studio Address, type: text, required: false):
  Enter the address of the studio.
* **Project URL** (id: 16, name: project_url, label: Project URL, type: text, required: false):
  Enter the URL for the project, if applicable.
* **Session Notes** (id: 17, name: session_notes, label: Session Notes, type: text, required: false):
  Enter any additional notes for the session.
* **Event Tags** (id: 18, name: event_tags, label: Event Tags, type: select_multiple, required: false):
  Select the event tags that best describe the project (Audio, Video, or Live Drawing).
* **Artist Availability** (id: 19, name: artist_availability, label: Artist Availability, type: select_one, required: false):
  Select the artist's availability for the project (Mon - Fri, Sat, Sun, or Mon, Tue, Wed, Thu, Fri).
* **Project Status** (id: 20, name: project_status, label: Project Status, type: select_one, required: false):
  Specify the project status (New, In Progress, or Completed).

## Tips
* Make sure to fill in all required fields to ensure that the form is complete.
* Double-check the event details to ensure that they are accurate.
* If you have any questions or concerns, feel free to contact the studio or artist directly.
