# JENS_BIRTHDAY_CRUISE - Help Guide
## Purpose
The JENS BIRTHDAY CRUISE form is designed to collect essential information for the event planning process. This guide will walk you through each step to complete the form accurately and efficiently.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the event name in the **Event Name** field (optional).
2. Enter the start date of the event in the **Start Date** field (optional).
3. Enter the arrival date in the **Arrival Date** field (optional).
4. Enter the departure date in the **Departure Date** field (optional).
5. Select the group size for the event in the **Group Size** field (optional).
6. Enter the contact name in the **Contact Name** field (optional).
7. Enter the contact email in the **Email** field (optional).
8. Enter the contact phone number in the **Phone** field (optional).
9. Add any additional event notes in the **Event Notes** field (optional).
10. Finally, select an assigned tool for the event from the available options in the **Assigned Tool** field.

## Field-by-Field Explanation

* **Event Name**: The name of the event, such as "Jens' Birthday Cruise".
* **Start Date**: The date when the event starts.
* **Arrival Date**: The date when participants arrive for the event.
* **Departure Date**: The date when the event ends.
* **Group Size**: The number of people attending the event.
* **Contact Name**: The name of the person responsible for the event.
* **Email**: The email of the person responsible for the event.
* **Phone**: The phone number of the person responsible for the event.
* **Event Notes**: Additional information or comments about the event.
* **Assigned Tool**: The tool assigned to the event, which can be "chatjimmy" or "Other". Please select the correct option based on your event's requirements.
