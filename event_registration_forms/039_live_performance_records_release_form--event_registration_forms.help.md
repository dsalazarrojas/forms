# Live Performance Records Release Form - Help Guide
## Purpose
The Live Performance Records Release Form is a tool used to document and release records of live events. It captures essential details about the event, including the event organizer, artist, date, time, location, event duration, and recording devices used during the event.

## How To Complete This Form
To complete this form, follow these steps:

1. **Enter the event organizer's name**: In this field, type the name of the person or organization that organized the live event.
2. **Select the artist involved**: Choose the artist who performed during the event.
3. **Enter the event name**: Provide a clear and concise name for the event.
4. **Select the date of the event**: Use the calendar to choose the date on which the event took place.
5. **Select the time of the event**: Choose the time of the event using the provided time picker.
6. **Enter the location of the event**: Type the venue or location where the event occurred.
7. **Enter the event duration**: Type the length of the event in hours or minutes.
8. **Choose recording devices used**: Select which recording devices were used during the event (e.g., audio or video).
9. **Choose if audio files were recorded**: Select whether audio files were recorded during the event.
10. **Choose if video files were recorded**: Select whether video files were recorded during the event.

## Field-by-Field Explanation
* **Event Organizer (text)**: Enter the name of the person or organization that organized the event.
* **Artist (text)**: Choose the artist who performed during the event.
* **Event Name (text)**: Provide a clear and concise name for the event.
* **Date of Event (date)**: Select the date on which the event took place using the calendar.
* **Time of Event (time)**: Choose the time of the event using the time picker.
* **Location of Event (text)**: Type the venue or location where the event occurred.
* **Event Duration (number)**: Type the length of the event in hours or minutes.
* **Recording Devices (select_multiple)**: Choose which recording devices were used during the event (e.g., audio or video).
* **Audio Files (select_multiple)**: Select whether audio files were recorded during the event.
* **Video Files (select_multiple)**: Select whether video files were recorded during the event.

## Tips
- Ensure you have accurate information about the event before completing this form.
- Double-check your selections for accuracy to avoid errors.
- If unsure about any field, refer to the event organizer or artist for confirmation.
