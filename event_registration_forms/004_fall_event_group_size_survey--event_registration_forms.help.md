# Fall Event Group Size Survey - Help Guide
## Purpose
The Fall Event Group Size Survey is a tool used by event organizers to collect information about the number of people attending a fall event. This data will help them plan and execute the event successfully.

## How To Complete This Form
To complete this form, follow these steps:

1. Answer the required and optional questions as accurately as possible.
2. Provide the correct event type (Fall, Summer, or Other).
3. Enter the number of attendees.
4. Select the event date and time.
5. Add any additional notes or comments.
6. Enter your email address (optional).
7. Enter your phone number (optional).

## Field-by-Field Explanation
### Event Group Size
* **Event Group Size** (`event_group_size`, `number`, required/optional): Enter the number of people attending the event. If you are unsure, estimate the number of attendees.

### Event Type
* **Event Type** (`event_type`, `select_one`, required/optional): Select the type of event (Fall, Summer, or Other). This helps the event organizer understand the nature of the event.

### None
* **None** (`none`, `text`, required/optional): Leave this field blank, as it is not applicable.

### Attendees
* **Attendees** (`attendees`, `number`, required/optional): Enter the number of people attending the event. This is crucial for event planning and organization.

### Event Date
* **Event Date** (`event_date`, `date`, required/optional): Select the date of the event. This helps the event organizer schedule the event accordingly.

### Event Time
* **Event Time** (`event_time`, `time`, required/optional): Select the time of the event. This helps the event organizer plan the event timing.

### Notes
* **Notes** (`notes`, `note`, required/optional): Add any additional comments or notes about the event. This helps the event organizer understand the event better.

### Email
* **Email** (`email`, `email`, required/optional): Enter your email address. This helps the event organizer contact you if needed.

### Phone
* **Phone** (`phone`, `text`, required/optional): Enter your phone number. This helps the event organizer contact you if needed.
