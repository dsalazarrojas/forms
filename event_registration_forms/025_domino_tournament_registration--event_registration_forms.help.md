# domino_tournament_registration - Help Guide
## Purpose
This form is used to collect registration information for a domino tournament.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the required fields marked with \*.
2. Make sure to select the correct options for "Tournament Info" and "Participation".
3. Provide all necessary details for "Player Details", "Contact Info", "Player Info", "Player Details 2", "Player Details 4", "Player Details 11", "Player Formation".
4. Select the correct number of team members and players participating for "Team Members" and "Player Participation".
5. Enter the correct dates for "Tournament Info 5", "Tournament Info 6", and "Tournament Info 7".
6. Select the correct team tier for "Team Tier" (if applicable).
7. Fill in the correct options for "Tournament Info 8", "Tournament Info 9", "Tournament Info 10", "Tournament Info 11", and "Tournament Info 12".

## Field-by-Field Explanation
* **Player Details (1)** (`title`, `text`, required): Enter the player's name and other relevant details.
* **Team Details (2)** (`title`, `text`, required): Enter the team's name and other relevant details.
* **Contact Info (3)** (`title`, `text`, required): Enter the player's or team's contact email.
* **Player Info (4)** (`title`, `text`, optional): Enter additional player details.
* **Tournament Info (5)** (`title`, `select_one`, required): Select the type of tournament (e.g. Option 1, Option 2).
* **Participation (6)** (`title`, `select_one`, required): Select whether the player is participating as a team or individual.
* **Player Details 2 (7)** (`title`, `number`, required): Enter the number of players participating.
* **Player Details 3 (8)** (`title`, `select_multiple`, optional): Select the player's formation (e.g. Option 1, Option 2).
* **Player Details 4 (9)** (`title`, `select_one`, required): Select the player's detail (e.g. Option 1, Option 2).
* **Team Participation (10)** (`title`, `number`, required): Enter the team size.
* **Team Members (11)** (`title`, `text`, required): Enter the team members' names.
* **Player Participation (12)** (`title`, `number`, required): Enter the number of players participating.
* **Team Tier (13)** (`title`, `number`, optional): Select the team tier (e.g. Option 1, Option 2).
* **Player Formation (14)** (`title`, `text`, required): Enter the player's formation.
* **Tournament Info 2 (15)** (`title`, `date`, required): Enter the tournament start date.
* **Tournament Info 3 (16)** (`title`, `date`, required): Enter the tournament end date.
* **Tournament Info 4 (17)** (`title`, `text`, required): Enter other tournament details.
* **Tournament Info 5 (18)** (`title`, `number`, required): Enter the tournament duration.
* **Tournament Info 6 (19)** (`title`, `number`, required): Enter the tournament start time.
* **Tournament Info 7 (20)** (`title`, `number`, required): Enter the tournament end time.
* **Tournament Info 8 (21)** (`title`, `select_one`, required): Select other tournament info (e.g. Option 1, Option 2).
* **Tournament Info 9 (22)** (`title`, `number`, required): Enter the tournament prize amount.
* **Tournament Info 10 (23)** (`title`, `number`, required): Enter the tournament entry fee.
* **Tournament Info 11 (24)** (`title`, `number`, required): Enter the tournament max players.
* **Tournament Info 12 (25)** (`title`, `number`, required): Enter the tournament min players.
