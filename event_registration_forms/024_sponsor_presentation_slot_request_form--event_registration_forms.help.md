# Sponsor Presentation Slot Request Form - Help Guide

## Purpose
This form is used by event organizers to request a presentation slot for a sponsor's presentation in a conference or event. The form gathers information from the sponsor about their presentation, session requirements, contact information, and event details.

## How To Complete This Form

To complete this form successfully, follow these steps:

1. Fill in all required fields marked with an *.
2. Be as detailed and accurate as possible with the event and sponsor information.
3. Make sure to select one or more time slots that work best for your event.

## Field-by-Field Explanation

*   **Event Details** (`event_details`)
    Required: No
    A brief description of the event, including the title and any other relevant details.
*   **Sponsor Session Details** (`sponsor_session_details`)
    Required: Yes
    A brief description of the sponsor's session, including the topic and any other relevant details.
*   **Time Slot Requests** (`time_slot_requests`)
    Required: Yes
    Select one or more time slots that work best for your event.
*   **Sponsor Contact Info** (`sponsor_contact_info`)
    Required: No
    Sponsor's contact information, including their name, email address, and phone number.
*   **Event Date** (`event_date`)
    Required: Yes
    The date of the event.
*   **Event Time** (`event_time`)
    Required: Yes
    The time of the event.
*   **Sponsor Name** (`sponsor_name`)
    Required: Yes
    The name of the sponsor.
*   **Sponsor Email** (`sponsor_email`)
    Required: Yes
    The sponsor's email address.
*   **Sponsor Phone** (`sponsor_phone`)
    Required: Yes
    The sponsor's phone number.
*   **Presentation Title** (`presentation_title`)
    Required: Yes
    A brief title of the sponsor's presentation.
*   **Presentation Description** (`presentation_description`)
    Required: No
    A brief description of the sponsor's presentation.
*   **Presentation Tags** (`presentation_tags`)
    Required: No
    Tags or keywords related to the sponsor's presentation.
*   **Sponsor Requirements** (`sponsor_requirements`)
    Required: Yes
    Any special requirements for the sponsor's session.
*   **More Sponsor Requirements** (`sponsor_requirements_2`)
    Required: No
    Any additional requirements for the sponsor's session.
*   **Sponsor Session Requirements** (`sponsor_session_requirements`)
    Required: No
    Any special requirements for the sponsor's session.
*   **More Sponsor Session Requirements** (`sponsor_session_requirements_2`)
    Required: No
    Any additional requirements for the sponsor's session.
*   **Sponsor Session Requirements 3** (`sponsor_session_requirements_3`)
    Required: No
    Any further additional requirements for the sponsor's session.
*   **Sponsor Session Notes** (`sponsor_session_notes`)
    Required: No
    Any additional notes for the sponsor's session.
*   **Event Location** (`event_location`)
    Required: Yes
    The location of the event.
*   **Sponsor Website** (`sponsor_website`)
    Required: No
    The sponsor's website.
*   **Sponsor Social Media** (`sponsor_social_media`)
    Required: No
    The sponsor's social media handle.
*   **Sponsor Session Image** (`sponsor_session_image`)
    Required: No
    The image to be used for the sponsor's session.
*   **Sponsor Session Video** (`sponsor_session_video`)
    Required: No
    The video to be used for the sponsor's session.
*   **Confirmation** (`confirmation`)
    Required: Yes
    A confirmation statement that the form has been filled out correctly.

**Note:** Please review the form carefully before submission to ensure all required fields are completed accurately and truthfully.
