# Wedding Invitation Printing Quote Request Form - Help Guide

## Purpose
This form is used to request a quote for wedding invitation printing services.

## How To Complete This Form
To complete this form, please follow the steps below:
1. Select the type of event for which you are requesting a quote (e.g., Invitation, Poster, Brochure, or Menu).
2. Choose the size of the event (e.g., Small, Medium, or Large).
3. Select the type of paper you would like to use for printing (e.g., Cardstock, Cotton, or Linen).
4. Choose the color of the paper (e.g., White, Black, or Red).
5. Decide on the folding type of the paper (e.g., Folded or Not Folded).
6. Select the shape of the paper (e.g., Square or Round).
7. Choose the printing method (e.g., Digital, Offset, or Laser).
8. Enter the quantity of invitations you need.
9. Enter the contact person's name.
10. Enter their email address.
11. Enter their phone number.
12. Add any additional comments or information about the order.

## Field-by-Field Explanation

* **Wedding Invitation Printing Quote Request**: This field is a text input where you can enter a brief description of the wedding invitation printing quote request.
* **EventType**: This field is a drop-down menu where you can select the type of event for which you are requesting a quote (e.g., Invitation, Poster, Brochure, or Menu).
* **EventSize**: This field is a drop-down menu where you can select the size of the event (e.g., Small, Medium, or Large).
* **PaperType**: This field is a drop-down menu where you can select the type of paper you would like to use for printing (e.g., Cardstock, Cotton, or Linen).
* **PaperColor**: This field is a drop-down menu where you can select the color of the paper (e.g., White, Black, or Red).
* **PaperFoldingType**: This field is a drop-down menu where you can decide on the folding type of the paper (e.g., Folded or Not Folded).
* **PaperShape**: This field is a drop-down menu where you can select the shape of the paper (e.g., Square or Round).
* **PrintMethod**: This field is a drop-down menu where you can select the printing method (e.g., Digital, Offset, or Laser).
* **Quantity**: This field is a numeric input where you can enter the number of invitations you need.
* **ContactPerson**: This field is a text input where you can enter the contact person's name.
* **ContactEmail**: This field is an email input where you can enter the contact person's email address.
* **ContactPhone**: This field is a text input where you can enter the contact person's phone number.
* **AdditionalComments**: This field is a text area where you can add any additional comments or information about the order.
