# pt_experience_session_registration - Help Guide

## Purpose
This form is designed to register participants for a session. It collects participant information, session details, and optional session notes.

## How To Complete This Form

To complete this form, follow these steps:

1. Fill in the participant's information, including their name and email address.
2. Select the correct session to register for by choosing "Yes" from the dropdown menu.
3. Enter the start and end dates of the session.
4. Optionally, provide any additional session notes if necessary.

## Field-by-Field Explanation

* **Participant Information** (`participant_details`, text, Required):
	+ This section collects the participant's details, including their name and email address.
* **Select Session** (`session_selection`, select_one, Required):
	+ Select the session you want to register for by choosing "Yes" from the dropdown menu.
* **Start Date** (`start_date`, date, Required):
	+ Enter the start date of the session in YYYY-MM-DD format.
* **End Date** (`end_date`, date, Required):
	+ Enter the end date of the session in YYYY-MM-DD format.
* **Participant Name** (`participant_name`, text, Required):
	+ Enter the participant's name.
* **Participant E-mail** (`participant_email`, email, Required):
	+ Enter the participant's email address.
* **Session Type** (`session_type`, select_one, Optional):
	+ This field is not strictly required, but you can select the session type if applicable.
* **Session Notes** (`session_notes`, note, Optional):
	+ This field is for providing additional context or notes about the session.

## Tips

* Make sure to enter the participant's email address correctly to ensure you receive any relevant notifications.
* If you have trouble selecting a session, check that your session options match the available sessions.
* If you need to provide session notes, please use a clear and concise format to make it easier for the session leader to understand your needs.
