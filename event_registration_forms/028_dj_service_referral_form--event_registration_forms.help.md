# DJ Service Referral Form - Help Guide
## Purpose
The DJ Service Referral Form is a tool for referring DJs to others. It helps collect information about the event, the referring DJ, and the referred DJ for efficient referrals.

## How To Complete This Form
To complete this form, follow these steps:
1. Select the "Submit" option from the "Submit this form" field to start the referral process.
2. Fill out the form with the required information for the event, referring DJ, and referred DJ.
3. Provide a clear and brief referral message in the "referral_message" field.

## Field-by-Field Explanation
### Form Header
* **Form Header**: (Text, Not Required)
	+ This is the header of the form, providing a brief introduction to the form's purpose.

### Client Name
* **Client Name**: (Text, Not Required)
	+ Please enter the name of the client or company associated with this referral.

### Contact Email
* **Contact Email**: (Email, Not Required)
	+ Enter the email address of the contact person for this referral.

### Contact Phone
* **Contact Phone**: (Text, Not Required)
	+ Provide the phone number of the contact person for this referral.

### Event Name
* **Event Name**: (Text, Not Required)
	+ Enter the name of the event associated with this referral.

### Event Date
* **Event Date**: (Date, Not Required)
	+ Select the date of the event.

### Event Time
* **Event Time**: (Time, Not Required)
	+ Select the time of the event.

### Event Details
* **Event Details**: (Text, Not Required)
	+ Briefly describe the event.

### DJ Name
* **DJ Name**: (Text, Not Required)
	+ Enter the name of the referred DJ.

### DJ Contact Email
* **DJ Contact Email**: (Email, Not Required)
	+ Provide the email address of the referred DJ.

### DJ Contact Phone
* **DJ Contact Phone**: (Text, Not Required)
	+ Enter the phone number of the referred DJ.

### DJ Website
* **DJ Website**: (Text, Not Required)
	+ Enter the website URL of the referred DJ.

### DJ Social Media
* **DJ Social Media**: (Text, Not Required)
	+ Enter the social media handle of the referred DJ.

### DJ Rate
* **DJ Rate**: (Number, Not Required)
	+ Enter the rate or price of the referred DJ.

### Referral Reason
* **Referral Reason**: (Text, Not Required)
	+ Provide the reason for this referral.

### Referred DJ Name
* **Referred DJ Name**: (Text, Not Required)
	+ Enter the name of the referred DJ.

### Referred DJ Website
* **Referred DJ Website**: (Text, Not Required)
	+ Enter the website URL of the referred DJ.

### Referred DJ Phone
* **Referred DJ Phone**: (Text, Not Required)
	+ Enter the phone number of the referred DJ.

### Referred DJ Email
* **Referred DJ Email**: (Email, Not Required)
	+ Enter the email address of the referred DJ.

### Referral Message
* **Referral Message**: (Text, Not Required)
	+ Provide a brief message for the referral.

### Submit this form
* **Submit this form**: (Select One, Required)
	+ Select "Submit" to complete the referral submission. Alternatively, select "Other" to provide a different submission option.
	+ Note: This field is required to submit the form.
