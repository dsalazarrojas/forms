# Outdoor Projection Mapping Application Form - Help Guide
## Purpose
The Outdoor Projection Mapping Application Form is designed for registering events that involve outdoor projection mapping applications. This form helps users provide essential information about the event, including project proposal, project name, event date, event time, vendor information, event location, and event description.

## How To Complete This Form

1. Click on the "Start" button to begin filling the form.
2. Fill in the required fields:
   * Project Proposal
   * Project Name
   * Event Date
   * Event Time
   * Event Location
3. Add any additional information you have about the event in the "Event Description" field.
4. Click on the "Submit" button to submit your application.

## Field-by-Field Explanation

* **Project Proposal** (`project_proposal`, text, required):
  This field is a brief description of the event or project you are registering.
* **Project Name** (`project_name`, text, required):
  This field is the name of the project or event you are registering.
* **Event Date** (`event_date`, date, required):
  This field is where you enter the date of the event.
* **Event Time** (`event_time`, time, required):
  This field is where you enter the time of the event.
* **Event Location** (`event_location`, text, required):
  This field is where you enter the location of the event.
* **Event Description** (`event_description`, text, required):
  This field is a detailed description of the event.
* **Vendor Information** (`vendor_information`, text, optional):
  This field is for any additional information about the vendor or service provider.
* **Event Registration** (`event_registration_form`, text, optional):
  This field is an additional note for event registration.
