# Grant Application Check In Form - Help Guide
## Purpose
The Grant Application Check In Form is used for tracking and verifying grant applications.

## How To Complete This Form
To complete this form, follow these steps:

1. Review the provided fields and ensure you have all necessary information.
2. Fill out the required fields as accurately as possible.
3. For fields with options, select the relevant choice that best applies to your situation.
4. Double-check your answers before submitting the form.

## Field-by-Field Explanation

* **Grant Details** (`grant_application_check_in_form_1`, text, required/optional): This field is intended for providing a brief description of the grant application. Please enter a short description of the grant you are applying for.
* **Applicant Information** (`grant_application_check_in_form_2`, select_one, required/optional): This field asks for the type of information related to the applicant. Select the relevant option that best describes the applicant's information (Name, Address, or Phone).
* **Date of Birth** (`grant_application_check_in_form_3`, date, required/optional): This field is for entering the date of birth of the applicant. Please use the standard date format (yyyy-mm-dd).
* **Application Status** (`grant_application_check_in_form_4`, select_multiple, required/optional): This field indicates the status of the grant application. Select all relevant statuses that apply to your situation (Pending, Approved, or Denied).
* **Application Type** (`grant_application_check_in_form_5`, select_one, required/optional): This field categorizes the type of grant application. Select the relevant option that best describes the grant type (Grant, Fellowship, or Award).
* **Grant Award Amount** (`grant_application_check_in_form_6`, number, required/optional): This field is for entering the amount of the grant award. Please enter a numerical value.
* **Grant Category** (`grant_application_check_in_form_7`, select_one, required/optional): This field classifies the grant category. Select the relevant option that best describes the grant category (Category 1, Category 2, or Category 3).
* **Grant Description** (`grant_application_check_in_form_8`, text, required/optional): This field provides a brief description of the grant. Please enter a short description.
* **Grant Date** (`grant_application_check_in_form_9`, date, required/optional): This field is for entering the date the grant was granted. Please use the standard date format (yyyy-mm-dd).
* **Grant Time** (`grant_application_check_in_form_10`, time, required/optional): This field is for entering the time the grant was granted. Please use a 24-hour format (hh:mm:ss).

## Tips
- Double-check your answers before submitting the form to ensure accuracy.
- If you are unsure about any field, refer to the relevant authority for guidance.
- This form is for internal use; please do not share sensitive or confidential information.
