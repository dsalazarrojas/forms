# VIP Guest List Approval Form - Help Guide

## Purpose
This form is used to collect and manage approval for VIP guests attending events. It is meant to be used by event organizers to review and approve or deny guest requests.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the name of the event for which you are requesting approval.
2. Provide the contact person responsible for the guest's attendance.
3. Select the desired approval type for the guest's attendance (Full Approval, Partial Approval, or Denial).
4. Enter any additional approval notes if necessary.
5. Enter the guest's email address.
6. Enter the guest's phone number.
7. Enter the date of the event.

## Field-by-Field Explanation
* **Event Name** (`event_name`, text, optional): Enter the name of the event for which you are requesting approval.
* **Contact Person** (`contact_person`, text, optional): Enter the name of the person responsible for the guest's attendance.
* **Guest List** (`guest_list`, select_multiple, optional): Select whether the guest should be included in the guest list (Yes) or not (No).
* **Approval Type** (`approval_type`, select_one, optional): Select the approval type for the guest's attendance (Full Approval, Partial Approval, or Denial).
* **Approval Notes** (`approval_notes`, text, optional): Enter any additional comments or notes for the approval decision.
* **Email** (`email`, email, optional): Enter the guest's email address for communication purposes.
* **Phone** (`phone`, text, optional): Enter the guest's phone number for communication purposes.
* **Date** (`date`, date, optional): Enter the date of the event for which approval is being requested. 

Note: This form is not required, but if left empty, will still be accepted. 

## Tips
* Always enter accurate and complete information to ensure smooth communication and event planning.
* Review and update this form regularly to keep your event guest list up-to-date. 

This form is designed for event organizers to review and manage guest requests for events. If you have any further questions or concerns, please reach out to your supervisor or IT department.
