# New Year's Celebration Sponsorship Form - Help Guide
## Purpose
The New Year's Celebration Sponsorship Form is used for collecting sponsorship information from event sponsors for the New Year's Celebration.

## How To Complete This Form
To complete this form, follow the steps outlined in the above explanation.

## Field-by-Field Explanation
* **Sponsor Name**: Enter the sponsor's name.
* **Event Name**: Enter the name of the event.
* **Event Date**: Enter the date of the event in the format of YYYY-MM-DD.
* **Event Time**: Enter the time of the event in the 24-hour format, HH:MM.
* **Sponsor Type**: Select the type of sponsorship.
* **Sponsorship Amount**: Enter the amount of the sponsorship.
* **Sponsor Email**: Enter the sponsor's email address.
* **Sponsor Phone**: Enter the sponsor's phone number.
* **Sponsor Message**: Enter any additional message from the sponsor.
* **Payment Type**: Choose the method of payment.
* **Payment Method**: Select the method of payment if paying online.
* **Sponsorship Promotion**: If applicable, choose the sponsor's promotion.
* **Assigned Tool**: Enter the assigned tool number, if applicable.
* **Output File**: Enter the name or reference of the output file, if applicable.
* **Form ID**: Enter the ID of this form, if applicable.
* **Category**: Enter the category or type of sponsorship, if applicable.
* **Assigned Jimmy**: Enter the name of the assigned staff member, if applicable.
* **Jimmy**: Enter the name of the staff member, if applicable.
* **jimmy**: Enter the name of the staff member, if applicable.
* **Output File 2**: Enter the name or reference of the output file 2, if applicable.
* **Description**: Enter a description of the sponsorship, if applicable.
* **Form IDs**: Enter the list of form IDs, if applicable.
* **Output File**: Enter the name or reference of the output file, if applicable.
* **Output File 3**: Enter the name or reference of the output file 3, if applicable.
* **Output File 4**: Enter the name or reference of the output file 4, if applicable.
