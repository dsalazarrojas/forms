# Parent Teacher Conference Intake Form - Help Guide
## Purpose
The Parent Teacher Conference Intake Form is designed to gather essential information from parents and teachers to facilitate effective and productive parent-teacher conferences. This form helps to ensure that both parties are informed and prepared for the conference.

## How To Complete This Form
To complete this form successfully, please follow these steps:
1. Fill out the form with the required information, which is marked as "required" in the form.
2. Be as detailed and accurate as possible, especially when filling out the "Reason For Conference" field.
3. Choose the appropriate tool (Chat, Video, or Phone) for the conference from the "Assigned Tool" field.
4. Ensure that the email and phone numbers provided are correct.

## Field-by-Field Explanation
* **Conference Date** (`conference_date`, date, optional): This field is used to select the date of the conference. Please enter the date in the format `MM/DD/YYYY` (e.g., 01/15/2024).
* **Start Time** (`start_time`, time, optional): This field is used to select the start time of the conference. Please enter the time in the format `HH:MM AM/PM` (e.g., 02:00 PM).
* **End Time** (`end_time`, time, optional): This field is used to select the end time of the conference. Please enter the time in the format `HH:MM AM/PM` (e.g., 03:00 PM).
* **Parent Name** (`parent_name`, text, optional): This field is used to enter the name of the parent(s) involved in the conference.
* **Teacher Name** (`teacher_name`, text, optional): This field is used to enter the name of the teacher involved in the conference.
* **Reason For Conference** (`reason_for_conference`, text, optional): This field is used to describe the purpose or topic of the conference. Please be as detailed as possible to help facilitate a productive conversation.
* **Comments** (`comments`, text, optional): This field is used to add any additional comments or notes for the conference.
* **Assigned Tool** (`assigned_tool`, select_one, optional): This field is used to select the medium for the conference (Chat, Video, or Phone). Please choose the tool that best suits your needs.
* **Email** (`email`, email, optional): This field is used to enter the email address of the parent or guardian.
* **Phone** (`phone`, text, optional): This field is used to enter the phone number of the parent or guardian.

## Tips
* Be sure to double-check the form before submitting it to ensure that all required fields are filled out correctly.
* If you have any questions or concerns about the form or the conference, please don't hesitate to reach out to the relevant authority.
* If you need to make any changes or corrections to the form, please do so before the conference.
