## Volunteer Event Idea Poll - Help Guide
## Purpose
The Volunteer Event Idea Poll form is designed to collect event ideas and suggestions from volunteers. The purpose of this form is to gather input and suggestions on potential events that can be organized, allowing event organizers to get a better understanding of the volunteers' preferences and ideas.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the type of event you would like to suggest. You can choose from "Option 1", "Option 2", or "Option 3".
2. Enter the name of the event you would like to suggest.
3. Provide the location where you would like to hold the event.
4. Write a short description of your event idea.

## Field-by-Field Explanation

* **EventType** (`EventType`, select_one, required): Select the type of event you would like to suggest.
* **EventName** (`EventName`, text, optional): Enter the name of the event you would like to suggest. This can be as short or as long as you need it to be.
* **Location** (`Location`, text, optional): If you have a specific location in mind for the event, enter it here.
* **Event Ideas** (`Event Ideas`, text, optional): This is the main section where you can describe your event idea. Try to be as detailed as possible, but keep it brief and clear.
* **Idea Description** (`Idea Description`, text, optional): Provide a short description of your event idea. This can be a brief summary or a more detailed explanation, depending on your preference.

## Tips
* Be creative with your event ideas! Think about what would be interesting and engaging for the volunteers.
* Keep your descriptions clear and concise.
* If you have any questions or need help, feel free to contact us at form@gic.mx.
