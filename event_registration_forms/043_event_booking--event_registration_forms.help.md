# event_booking - Help Guide
## Purpose
The "event_booking" form is used to book events, such as conferences or meetings. It gathers information about the event, including the type, date, start and end times, venue, location, description, and status.

## How To Complete This Form
To complete this form, follow these steps:

1.  Select the type of event from the "Event Type" dropdown menu.
2.  Input the date of the event in the "Event Date" field.
3.  Input the start time of the event in the "Event Start Time" field.
4.  Input the end time of the event in the "Event End Time" field.
5.  Input the name of the event venue in the "Event Venue" field.
6.  Input the location of the event in the "Event Location" field.
7.  (Optional) Provide a brief description of the event in the "Event Description" field.
8.  (Optional) Input the event booking ID in the "Event Booking ID" field.
9.  Select the status of the event from the "Event Status" dropdown menu.

*   **Event Type** (`Event Type`, Select One, Required): Choose the type of event (e.g., conference, meeting, workshop).
*   **Event Date** (`Event Date`, Date, Required): Input the date of the event.
*   **Event Start Time** (`Event Start Time`, Time, Required): Input the start time of the event.
*   **Event End Time** (`Event End Time`, Time, Required): Input the end time of the event.
*   **Event Venue** (`Event Venue`, Text, Required): Input the name of the event venue (e.g., conference hall, meeting room).
*   **Event Location** (`Event Location`, Text, Required): Input the location of the event (e.g., downtown area, park).
*   **Event Description** (`Event Description`, Text, Optional): (Optional) Provide a brief description of the event.
*   **Event Booking ID** (`Event Booking ID`, Number, Optional): (Optional) Input the event booking ID. This field is not used for any validation purpose.
*   **Event Status** (`Event Status`, Select One, Optional): Select the status of the event (e.g., active, inactive, pending).
