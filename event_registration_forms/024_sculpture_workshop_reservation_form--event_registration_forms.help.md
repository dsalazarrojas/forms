# Sculpture Workshop Reservation Form - Help Guide
## Purpose
This form is designed to collect participant information and workshop details for a sculpture workshop or seminar. It ensures that participants can provide necessary details for a well-structured and organized event experience.

## How To Complete This Form
- Start by filling out the required fields (indicated by an asterisk \*), as they are necessary for the workshop organizers to know your participation details.
- Fill out the "Workshop Details" section (page 1) with the name of the event, date, or any other relevant workshop information.

## Field-by-Field Explanation
- **Workshop Details** (`workshop_details`, text, required): This section is for participants to describe the workshop they are registering for, including its name or title.
- **Participant Information** (`participant_info`, text, required): Please provide your name and any other relevant personal details.
- **Available Workshops** (`workshop_dates`, select multiple, required): Select the available workshop dates you would like to attend. Please note that you can choose multiple dates.
- **Workshop Time** (`workshop_time`, time, required): Enter the exact time for the workshop you selected.
- **Participant Name** (`participant_name`, text, required): Enter your name as the participant.
- **Email** (`email`, email, required): Enter a valid email address that we can use to contact you about the event.
- **Phone Number** (`phone`, text, not required): This is an optional field where you can provide your phone number for further communication.
- **Message** (`participant_message`, text, not required): If you have any specific message for the workshop organizers, use this field to communicate with them.

## Tips
- Ensure all required fields are filled out to prevent errors or form submission failures.
- You can select multiple dates for the available workshops.
- If you encounter any issues during the form submission process, feel free to contact the form creators at form@gic.mx.
