# event_staff_scheduling_booking_form - Help Guide
## Purpose
This form is used to collect staff scheduling information for events.

## How To Complete This Form
To complete this form, please follow these steps:

*   Navigate through the form pages using the navigation buttons.
*   On each page, provide the required information for that page.
*   Once you have completed all the pages, click the "Submit" button to review and submit your answers.

## Field-by-Field Explanation
*   **Form** (`1`): This is the starting page of the form, where you can begin by entering your information.
    *   This field is not actually a field but a page indicator.
*   **Roles** (`2`): Please select the roles you would like to take on for this event.
    *   You can select multiple roles by holding down the Ctrl key (Windows) or Command key (Mac) while clicking on the roles.
*   **Scheduling** (`3`): Please enter the date you are available for this event.
    *   You can select a date in the format `YYYY-MM-DD`.
*   **Availability** (`4`): Please select the time slots you are available for this event.
    *   This is a date field but with a specific format `HH:MM - HH:MM`.
*   **Note** (`5`): Please provide any additional notes or information you may have about your availability.
    *   This is a text field where you can enter any information you need to provide.
*   **Additional Info** (`6`): This is a final text field for any additional information you may need to provide.
    *   Please enter any relevant information you may need to share. 

## Tips
*   Make sure to provide accurate information, especially for your availability.
*   Select all the roles you are interested in participating in.
*   Review your answers before submitting to ensure everything is accurate.
*   If you are unsure about any information, please reach out to event organizers for clarification.
