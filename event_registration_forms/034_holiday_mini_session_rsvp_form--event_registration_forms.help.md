# holiday_mini_session_rsvp_form - Help Guide
## Purpose
This form is used to collect RSVP information for a holiday mini session event. It is designed to gather essential details from users such as event name, contact information, and guest information.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill in the **Event Name** field with the name of the event you are attending.
2. Enter your **Contact Name** in the field labeled "Contact Name" to let the host know how to contact you.
3. Select the **Date** of the event you are attending.
4. Choose the time of the event you plan to attend in the **Time** field.
5. Provide the **Guest Count** field with the number of guests you plan to bring along.
6. Enter your **Email** in the field labeled "Email" so the host or organizer can get in touch with you.
7. Enter your **Phone** number in the field labeled "Phone" in case the host or organizer needs to reach you.
8. (Optional) Write a brief description of the event in the **Event Description** field.
9. Enter your **RSVP Message** if there's anything else you'd like to let the host or organizer know.
10. Confirm your event name to ensure it matches with the host or organizer.
11. Write a message to the host or organizer in the **Contact Message** field.
12. Select whether you will be attending the event or if you will be bringing any guests in the **Guest List** field.
13. If you're attending, select "Yes" from the **Guest List** options. If you're bringing guests, select "Yes" for yourself and the number of guests you're bringing in the **Guest Count** field.

## Field-by-Field Explanation

* **Event Name** (`event_name`, text, required): Enter the name of the event you are attending.
* **Contact Name** (`contact_name`, text, required): Enter your name or the name of the person responsible for contacting you.
* **Date** (`date`, date, required): Select the date of the event you plan to attend.
* **Time** (`time`, time, required): Choose the time you plan to attend the event.
* **Guest Count** (`guest_count`, number, required): Enter the total number of guests you plan to bring along.
* **Email** (`email`, email, required): Enter your email address so the host or organizer can contact you.
* **Phone** (`phone`, text, required): Enter your phone number for the host or organizer to reach you.
* **Event Description** (`event_description`, text, optional): Provide a brief description of the event.
* **RSVP Message** (`rsvp_message`, text, optional): Leave a message for the host or organizer.
* **Event Name Confirmation** (`event_name_confirmation`, text, required): Confirm your event name to ensure it matches with the host or organizer's records.
* **Contact Message** (`contact_message`, text, required): Write a message to the host or organizer.
* **Guest List** (`guest_list`, select_multiple, required): Select if you will be attending and if you'll be bringing any guests.
* **Guest List Add** (`guest_list_add`, select_one, required): If you're bringing guests, select "Yes" to confirm their attendance.
