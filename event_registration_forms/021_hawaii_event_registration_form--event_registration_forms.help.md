# hawaii_event_registration_form - Help Guide
## Purpose
The "hawaii_event_registration_form" is a tool for collecting information from users registering for events in Hawaii. Fill out this form to provide your event details and other relevant contact information.

## How To Complete This Form
To complete this form, follow these steps:

1. **Go to the first page: Event Details**
	* Enter your event title and description in the "Event Details" field.
	* This is the main section where you can provide a brief overview of your event.
2. **Go to the second page: Contact Info**
	* Enter your name and contact information in the "Contact Info" field.
	* This is where you can provide your name, email, and phone number or any other relevant contact details.
3. **Optional: Payment Details (third page)**
	* If you want to provide payment information, enter it in the "Payment Details" field.
	* Please note that this section is optional and only needed if payment is required for your event.
4. **Optional: Duplicate Event Details (fourth page)**
	* If you have more information about your event, you can enter it in the "Event Details" field.
	* This is intended for additional event details that don't fit in the first "Event Details" field.

## Field-by-Field Explanation
* **Event Details (Page 1)**:
	+ **Event Details** (`event_details`, text, required/optional): Enter a brief description of your event.
* **Contact Info (Page 2)**:
	+ **Contact Info** (`contact_info`, text, required/optional): Enter your name and any other relevant contact information.
* **Payment Details (Page 3)**:
	+ **Payment Details** (`payment_details`, text, required/optional): If required, enter your payment information here.
* **Event Details (Page 4)**:
	+ **Event Details** (`event_details`, text, required/optional): Enter any additional event details that don't fit in the first "Event Details" field.

## Tips
* Please make sure to fill out all required fields, especially the first "Event Details" field.
* If you have any questions or need help with the form, contact us at: form@gic.mx
