# theater-festival-form-braintree - Help Guide
## Purpose
Theater Festival Form Braintree is designed to collect information about upcoming events in the theater festival. It's used to gather details from users, organizers, and other stakeholders to ensure a well-organized event.

## How To Complete This Form
1. Ensure you have all the necessary information and permissions to fill out this form accurately.
2. Review each field carefully to ensure you're providing accurate and complete information.
3. Fill out the form once for each event you're registering.

## Field-by-Field Explanation
* **First Name (text)**: Enter your first name.
* **Last Name (text)**: Enter your last name.
* **Age (number)**: Enter your age.
* **Email (email)**: Enter your email address.
* **Contact Phone (text)**: Enter your contact phone number.
* **Event Type (select_one)**: Choose the type of event you're registering for (e.g., Event A, Event B, Event C).
* **Performance Time (time)**: Enter the time of the event performance.
* **Event Date (date)**: Enter the date of the event.
* **Notes (note)**: Add any additional comments or notes about the event.
* **Event Name (text)**: Enter the name of the event.
* **Event Location (text)**: Enter the location of the event.
* **Event Description (text)**: Enter a brief description of the event.
* **Role (select_one)**: Choose your role in the event (e.g., Participant, Organizer, Sponsor).
* **Other Role (text)**: If none of the above roles apply, enter your role here.
* **Form ID (number)**: This field is not intended for user input; it's likely used for internal tracking purposes.
* **Assigned Tool (text)**: Enter the tool or equipment assigned to you for the event.
* **Created At (date)**: This field is not intended for user input; it's automatically populated.
* **Updated At (date)**: This field is not intended for user input; it's automatically populated.
* **Created By (select_one)**: Choose who created the event (e.g., User 1, User 2, User 3).
* **Created By (text)**: If none of the above options apply, enter the person who created the event.
* **Updated By (select_one)**: Choose who last updated the event (e.g., User 1, User 2, User 3).
* **Updated By (text)**: If none of the above options apply, enter the person who last updated the event.
* **User ID (text)**: This field is not intended for user input; it's automatically populated.
* **User Password (text)**: This field is not intended for user input; it's automatically populated.

Note: Please be aware of fields that are not intended for user input and fill out only the required fields accurately. If you're unsure about any field, please reach out to the event organizers or support team for guidance.
