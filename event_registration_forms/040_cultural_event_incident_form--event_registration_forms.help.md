# cultural event incident form - Help Guide
## Purpose
The "Cultural Event Incident Form" is designed to collect information about incidents or issues that occurred during cultural events. This form is intended for event organizers, staff, or attendees to report and document such incidents, which can be used for safety, security, or quality control purposes.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the "Event Date" field and choose the date on which the incident occurred.
2. In the "Event Location" field, enter the name of the location where the incident took place.
3. Select the "Incident Type" from the dropdown menu to describe the type of incident that happened (e.g., Event, Activity, or Other).
4. Provide a brief description of the incident in the "Incident Description" field.

## Field-by-Field Explanation

* **Event Date** (`event_date`, date, optional): Enter the date on which the incident occurred.
* **Event Location** (`event_location`, text, optional): Enter the name of the location where the incident took place.
* **Incident Type** (`incident_type`, select_one, required): Select the type of incident that happened:
	+ Event: A planned event or performance took place, but something went wrong.
	+ Activity: An activity or action was carried out during the event.
	+ Other: Describe the type of incident not listed above.
* **Incident Description** (`incident_description`, text, optional): Describe the incident in as much detail as possible, including what happened and any relevant context.
