# NGO Event Logistics Application Form - Help Guide
## Purpose
This form is designed to collect information about events hosted by NGOs (Non-Governmental Organizations) for event logistics purposes.

## How To Complete This Form
To complete this form, please answer the questions accurately and thoroughly. You can navigate through the pages using the page navigation buttons (Next and Previous).

## Field-by-Field Explanation
* **Event Logistics** (Event Logistics, text, required): This field is used to enter a brief description of the event.
* **Event Details** (Event Details, text, required): Enter a detailed description of the event, including its purpose, objectives, and any specific requirements.
* **Contact Info** (Contact Info, text, required): Provide your contact information, including name, email, and phone number.
* **Event Location** (Event Location, text, required): Enter the physical location of the event.
* **Event Sponsorships** (Event Sponsorships, text, required): List any sponsors or supporters involved in the event.
* **Event Participants** (Event Participants, text, required): Provide a list of expected participants, including their names, roles, and affiliations.
* **Event Dietary** (Event Dietary, text, required): Mention any dietary restrictions or preferences for the event participants.
* **Event Equipment** (Event Equipment, text, required): List any equipment or resources required for the event.
* **Event Safety** (Event Safety, text, required): Describe any specific safety measures or protocols in place for the event.
* **Event Certifications** (Event Certifications, text, required): List any certifications or credentials required for event participants.
* **Event Insurance** (Event Insurance, text, required): Provide details about any insurance coverage for the event.
* **Event Logistics** (Event Logistics, text, required): Enter any logistical information, such as setup and teardown procedures.
* **Event Other** (Event Other, text, required): Provide any other important information about the event.
* **Event Comments** (Event Comments, text, required): Enter any additional comments or notes about the event.
* **Event Agreement** (Event Agreement, text, required): Confirm that you have read and agree to the event terms and conditions.
* **Event Venue** (Event Venue, text, required): Enter the name and address of the event venue.
* **Event Food and Beverage** (Event Food and Beverage, text, required): List any food and beverage services provided for the event.
* **Event Transportation** (Event Transportation, text, required): Describe any transportation arrangements or recommendations for the event.
* **Event Parking** (Event Parking, text, required): Provide details about parking options and availability for the event.
* **Event Speaker** (Event Speaker, text, required): Enter the name and bio of the event speaker.
* **Event Speaker Bio** (Event Speaker Bio, text, required): Enter a detailed bio of the event speaker.
* **Event Speaker Photo** (Event Speaker Photo, text, required): Upload a photo of the event speaker.
* **Event Speaker Info** (Event Speaker Info, text, required): Enter any additional information about the event speaker.
* **Event Speaker Requirements** (Event Speaker Requirements, text, required): List any specific requirements or expectations for the event speaker.
* **Event Speaker Availability** (Event Speaker Availability, text, required): Provide the availability and schedule of the event speaker.

## Tips
* Please ensure that all required fields are completed accurately and thoroughly.
* Double-check your answers for any errors or inconsistencies.
* If you have any doubts or questions, contact the event organizers for clarification.
* This form is for event logistics purposes only and is not intended for commercial or promotional use.
