# Auditorium Reservation Form - Help Guide
## Purpose
The purpose of this form is to gather information about an event being held in our auditorium. This information will help us understand your requirements so we can provide the best possible service.

## How To Complete This Form

1. Fill out the form completely and accurately to ensure we can prepare for your event.
2. Use the "Event Name" field to provide a brief name of your event.
3. Choose the type of event from the options listed.
4. Provide a brief description of the event.
5. Choose the date and start time of the event.
6. Indicate the number of hours needed for setup.
7. Estimate the number of attendees for your event.
8. Choose the preferred auditorium size based on the number of attendees.
9. Determine the seating arrangement for your event.
10. Indicate if a stage is needed and the level of setup required.
11. Specify any special lighting or audio requirements.
12. Indicate if parking spaces are needed and approximate numbers.
13. Decide if catering or food services are needed.
14. If necessary, provide extra information about additional tables and chairs.
15. Decide if alcoholic beverages will be served.
16. Provide the name of the organization or company holding the event.
17. Enter the name of the person coordinating the event.
18. Enter the email address and phone number of the event coordinator.
19. If necessary, provide any special requests or accommodations.
20. If you have an estimated budget for the event, you can provide it (optional).

## Field-by-Field Explanation

* **Reservation Request Date** (1, date, required): Date you are making the reservation.
* **Event Name** (2, text, required): Name of the event.
* **Event Type** (3, select one, required): What kind of event.
* **Event Description** (4, text, required): Brief description of the event.
* **Event Date** (5, date, required): When will the event occur.
* **Event Start Time** (6, time, required): What time does the event begin.
* **Event End Time** (7, time, required): What time does the event end.
* **Setup Time Needed** (8, number, required): Hours needed for setup.
* **Expected Attendance** (9, number, required): Approximate number of attendees.
* **Preferred Auditorium Size** (10, select one, required): Room capacity needed.
* **Theater Seating Arrangement** (11, select one, required): How should seating be arranged.
* **Stage or Platform Needed** (12, select one, required): Will you need a raised stage.
* **Lighting Requirements** (13, select multiple, optional): Special lighting needed.
* **Audio Requirements** (14, select multiple, optional): Sound system needs.
* **Parking Space Needed** (15, number, optional): Approximate number of spaces.
* **Catering or Food Service** (16, select one, required): Will catering be provided.
* **Additional Tables and Chairs** (17, text, optional): Extra furniture needed.
* **Alcoholic Beverages** (18, select one, optional): Will alcohol be served.
* **Organization/Company Name** (19, text, required): Name of organization holding event.
* **Event Coordinator Name** (20, text, required): Name of person coordinating.
* **Event Coordinator Email** (21, email, required): Email for confirmation.
* **Event Coordinator Phone** (22, text, required): Contact phone number.
* **Special Requests or Accommodations** (23, text, optional): Any special needs.
* **Event Budget (Optional)** (24, number, optional): Estimated budget for event.

## Tips

* Double-check your answers to ensure they are accurate and complete.
* Use the options provided for select fields to help guide your selection.
* If unsure about any field, please contact us for assistance.
* We will review and confirm your reservation request as soon as possible.
