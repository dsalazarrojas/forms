# Cross Country Event Registration - Help Guide
## Purpose
The Cross Country event registration form is designed to collect information about runners and their event preferences. This information will be used to manage the event registration process effectively.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the runner's details on the first page.
2. Select the waivers that the runner agrees to on the second page.
3. Specify the runner's race preferences on the third page.
4. Enter the start and finish times on the fourth page.
5. Enter the distance to be run on the fifth page.
6. Fill in the runner's name and contact information on the sixth and seventh pages.

## Field-by-Field Explanation

* **Runner Details** (`runner_details`, `text`, required: false): This field is used to enter the runner's details.
* **Waivers** (`waivers`, `select_multiple`, required: false): Select the waivers that the runner agrees to. Please note that the runner is allowed to select multiple waivers.
* **Race Preferences** (`race_preferences`, `text`, required: false): This field is used to specify the runner's race preferences. You can enter any information that you think is relevant to the event.
* **Start Time** (`start_time`, `time`, required: false): Enter the start time of the runner's participation.
* **Finish Time** (`finish_time`, `time`, required: false): Enter the finish time of the runner's participation.
* **Distance Run** (`distance_run`, `number`, required: false): Enter the distance the runner plans to run.
* **Runner Name** (`runner_name`, `text`, required: false): Enter the name of the runner.
* **Runner Phone** (`runner_phone`, `text`, required: false): Enter the runner's phone number.
* **Runner Email** (`runner_email`, `email`, required: false): Enter the runner's email address.

Note: All fields marked as required are mandatory and must be filled in. If a field is not marked as required, it is optional.
