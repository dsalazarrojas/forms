# Mascot Registration Form - Help Guide
## Purpose
This form is designed to collect information from users about their mascot registration.

## How To Complete This Form
Please follow these general steps to complete the form:

1. Fill in all required fields with accurate and complete information.
2. Double-check your details before submitting the form.
3. If you need to add any additional resources like images or videos, make sure to upload them according to the guidelines.

## Field-by-Field Explanation
### 1. **Enter your name**
 * Label: Enter your name
 * Type: text
 * Required: true
This field is for your name. Please type it in as it appears on your official documents.

### 2. **Enter your mascot info**
 * Label: Enter your mascot info
 * Type: text
 * Required: true
This field is for any additional information about your mascot. Please be as detailed as possible.

### 3. **Email**
 * Label: Email
 * Type: email
 * Required: true
This field is for your email address. Please enter a valid email that you use to communicate.

### 4. **Phone**
 * Label: Phone
 * Type: text
 * Required: true
This field is for your phone number. Please enter a valid phone number that you use to communicate.

### 5. **Mascot image**
 * Label: Mascot image
 * Type: text
 * Required: true
This field is for your mascot's image. Please upload a valid image file that is not too large.

### 6. **Mascot video**
 * Label: Mascot video
 * Type: text
 * Required: false
This field is for your mascot's video. Please upload a valid video file that is not too large. This field is optional.

### 7. **Note**
 * Label: Note
 * Type: note
 * Required: false
This field is for any additional comments or notes about your mascot. Please be as detailed as possible. This field is optional.
