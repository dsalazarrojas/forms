## Purpose
The Lightsaber Workshop Registration form is used to collect information from participants and event organizers for a lightsaber workshop. This form helps the organizers to gather necessary details for the session, such as participant information, session details, and payment information.

## How To Complete This Form
To complete this form, follow these steps:

1. **Enter Event Organizer's Information**: This is an optional field, but it's recommended to be filled in for the workshop's records.
2. **Enter Participant's Information**: This section requires all the following details:
	* **Participants**: Enter the number of participants attending the workshop.
	* **Participant Name**: Enter the name of each participant.
	* **Participant Email**: Enter the email address of each participant.
	* **Participant Phone**: Enter the phone number of each participant.
3. **Select Session Details**: Choose the session date, time, duration, and capacity.
4. **Select Lightsaber Model**: Choose one or more lightsaber models for the workshop.
5. **Payment Information**: Enter the payment amount and method.
6. **Registration Date**: Enter the date of registration.
7. **Additional Notes**: This is an optional field for any additional comments or notes from the participant or event organizer.
