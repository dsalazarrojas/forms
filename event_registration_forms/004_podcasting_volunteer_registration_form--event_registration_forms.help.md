# Podcasting Volunteer Registration Form - Help Guide
## Purpose
This form is designed to collect information from potential volunteers for a podcasting event.

## How To Complete This Form
To complete this form, follow these steps:

1. Select your volunteer type from the list of options.
2. Enter your name and email address.
3. Provide your phone number.
4. Choose a role for the event.
5. Enter the event ID, event name, event date, event start time, and event end time.
6. Finally, enter the event location.

## Field-by-Field Explanation
* **Volunteer Type**:
	+ Select one or more options that best describe your role as a volunteer, such as "volunteer", "staff", or "volunteer-staff".
* **Name**: 
	+ Enter your full name as it should appear in event communications.
* **Email**:
	+ Enter your email address that we can use to contact you about event details.
* **Phone**:
	+ Enter your phone number so we can contact you in case of last-minute event changes.
* **Role**:
	+ Choose "Yes" if you are interested in taking on a role during the event, or "No" if you are not.
* **Event ID**:
	+ Enter the event ID number provided to you by the event organizer.
* **Event Name**:
	+ Enter the name of the event you are registering for.
* **Event Date**:
	+ Enter the date of the event.
* **Event Start Time**:
	+ Enter the start time of the event.
* **Event End Time**:
	+ Enter the end time of the event.
* **Event Location**:
	+ Enter the location of the event.
