# Venue Options Form - Help Guide
## Purpose
This form is used to collect venue-specific information for an event.

## How To Complete This Form
To complete this form, simply follow these steps:
1. Fill out the form in order, page by page.
2. Make sure to fill out all required fields, marked with an asterisk (\*).
3. Use the provided options to select the correct answer for each field.

## Field-by-Field Explanation
* **Venue** (`venue`, `text`, required: false): This field is used to capture the name or description of the venue.
* **Venue Type** (`venue_type`, `select_one`, required: false): This field is used to select the type of venue you are registering (e.g., Venue 1, Venue 2, Venue 3).
* **Costs** (`costs`, `number`, required: false): This field is used to capture any costs associated with the venue (e.g., rental fees, catering costs, etc.).
* **Payment Info** (`payment_info`, `text`, required: false): This field is used to capture any payment information for the venue (e.g., payment methods, payment terms, etc.).
* **Indoor Amenities** (`indoor_amenities`, `select_multiple`, required: false): This field is used to select any indoor amenities offered by the venue (e.g., Parking Lot, Restrooms, Free Wi-Fi).
* **Outdoor Amenities** (`outdoor_amenities`, `select_multiple`, required: false): This field is used to select any outdoor amenities offered by the venue (e.g., Parking Lot, Outdoor Seating Area, Green Space).
* **Contact Info** (`contact_info`, `select_one`, required: false): This field is used to select the contact person or person responsible for the venue.
* **Contact Phone** (`contact_phone`, `text`, required: false): This field is used to capture the phone number of the contact person.
* **Contact Email** (`contact_email`, `email`, required: false): This field is used to capture the email address of the contact person.

## Tips
* Make sure to double-check your answers for accuracy.
* If you're unsure about a particular field, refer to the venue's documentation or contact the event organizer.
* This form is designed to be completed by event organizers, so please fill it out clearly and accurately.
