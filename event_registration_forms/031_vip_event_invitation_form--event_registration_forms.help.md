# VIP Event Invitation Form - Help Guide
## Purpose
The "VIP Event Invitation Form" is designed to register VIP events, providing essential details about the event and its invitees.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the required fields with accurate information.
2. Ensure that you select the correct event status and invitation method.
3. Add any additional notes or comments as necessary.

## Field-by-Field Explanation

* **Event Name** (event_name): Enter the name of the event you're inviting the VIPs to.
* **Event Date** (event_date): Enter the date of the event. Make sure to use the correct date format (MM/DD/YYYY).
* **Event Time** (event_time): Enter the time of the event.
* **Event Location** (event_location): Enter the location of the event.
* **Invitees** (invitee_list): Select the types of people invited (Client, Guest, or Staff).
* **Event Status** (event_status): Select the current status of the event (Active, Completed, or Cancelled).
* **Event Organizer** (event_organizer): Enter the name of the event organizer.
* **Event Organizer Phone** (event_organizer_phone): Enter the phone number of the event organizer (optional).
* **Event Organizer Email** (event_organizer_email): Enter the email of the event organizer.
* **Event Organizer Address** (event_organizer_address): Enter the address of the event organizer (optional).
* **Client Phone** (client_phone): Enter the phone number of the client.
* **Client Email** (client_email): Enter the email of the client.
* **Client Address** (client_address): Enter the address of the client.
* **Client Company** (client_company): Enter the name of the client's company (optional).
* **Client Title** (client_title): Enter the title of the client (optional).
* **Event Invitation** (event_invitation): Enter any additional comments or invitation message.
* **Event Invitation Status** (event_invitation_status): Enter the status of the invitation (optional).
* **VIP Event Invitation** (vip_event_invitation): Enter any VIP-specific details or invitation message (optional).
* **VIP Status** (vip_status): Enter the VIP status (optional).
* **VIP Level** (vip_level): Enter the VIP level (optional).
* **VIP Note** (vip_note): Add any additional comments or notes about the VIP invitation (optional).

Tips: 

* Make sure to fill in all required fields.
* Ensure that the event details and invitee information are accurate.
* Use clear and concise language when filling in the additional fields.
