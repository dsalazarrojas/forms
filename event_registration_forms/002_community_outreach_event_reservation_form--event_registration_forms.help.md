# Community Outreach Event Reservation Form - Help Guide
## Purpose
This form is used to register and manage community outreach events in the space. It provides information about the event, including details about the event type, date, time, and attendees, as well as the contact information of the event organizer.

## How To Complete This Form
To complete this form, follow these steps:

1. Provide a clear and concise description of your event in the "Event Details" section.
2. Enter the name of your event.
3. Select the type of event (e.g., Workshop, Conference, etc.).
4. Enter the date and start/end times for your event.
5. Enter the estimated number of attendees for your event.
6. Provide contact information (name, email, and phone number) for the event organizer.
7. If applicable, enter the name of the organization hosting the event.
8. Select the preferred room setup for your event.
9. Indicate if any equipment (e.g., projector, microphone, etc.) is needed.
10. If catering is required, select the correct option.
11. Describe any accessibility requirements or needs.
12. Enter any additional requests or comments.
