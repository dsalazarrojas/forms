# Event Load In And Load Out Form - Help Guide
## Purpose
This form is used to record load-in and load-out events, including event details, dates, times, and locations. This information helps in tracking and managing these events efficiently.

## How To Complete This Form

1. Fill in the required fields with accurate information about the load-in event.
2. Choose the date and time of the load-in event from the available date and time options.
3. Select the load-in location from the available options.
4. If applicable, fill in the unload-out event information.
5. Choose the date and time of the unload-out event from the available date and time options.
6. Select the unload-out location from the available options.

## Field-by-Field Explanation

* **Load In Event** (`load_in_event`, text, optional): Enter a brief description of the load-in event.
* **Load In Date** (`load_in_date`, date, required): Choose the date of the load-in event from the available dates.
* **Load In Time** (`load_in_time`, time, required): Select the time of the load-in event from the available times.
* **Load In Location** (`load_in_location`, text, required): Enter the name of the load-in location.
* **Unload Out Event** (`unload_out_event`, text, optional): Enter a brief description of the unload-out event.
* **Unload Out Date** (`unload_out_date`, date, required): Choose the date of the unload-out event from the available dates.
* **Unload Out Time** (`unload_out_time`, time, required): Select the time of the unload-out event from the available times.
* **Unload Out Location** (`unload_out_location`, text, required): Enter the name of the unload-out location.

## Tips

* Ensure that the load-in and load-out events are accurately described to facilitate proper tracking and management.
* Double-check the dates and times to prevent errors in event scheduling.
* Verify the locations to ensure they are correct and up-to-date.
