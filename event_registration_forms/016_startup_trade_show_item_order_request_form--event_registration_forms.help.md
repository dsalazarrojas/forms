# Startup Trade Show Item Order Request Form - Help Guide
## Purpose
The "Startup Trade Show Item Order Request Form" is used to collect information from startup companies that are participating in a trade show. This form helps the event organizers to better understand the startup's needs and preferences for the event.

## How To Complete This Form
To complete this form, follow these steps:

1. Provide your event details, including your company name and any additional event details you'd like to share with us.
2. Select the items you would like to have on display at the trade show.
3. Specify your event date and any other relevant event details.
4. Provide your contact information, including your email and phone number.
5. Choose who from your company will be responsible for this trade show event.
6. Add any additional event details or notes you'd like to share with us.

## Field-by-Field Explanation

* **Event Details**: This field is for you to enter any relevant event details, such as your company name and any additional information you'd like to share with us.
  * Type: text
  * Required: Optional
* **Item Requests**: This field allows you to select the items you would like to have on display at the trade show. Please select as many or as few items as you need.
  * Type: select_multiple
  * Required: Optional
* **Scheduled Delivery**: This field is for you to select a date for your items to be delivered. This is not required, and you can select any date that suits your needs.
  * Type: date
  * Required: Optional
* **Item Notes**: This field is for you to add any additional notes about the items you're requesting.
  * Type: text
  * Required: Optional
* **Event Name**: This field is for you to enter the name of the event you are participating in.
  * Type: text
  * Required: Optional
* **Event Date**: This field is for you to select the date of the event you are participating in.
  * Type: date
  * Required: Optional
* **Item Request List**: This field is for you to select a list of items you would like to have on display at the trade show. Please select as many or as few items as you need.
  * Type: select_multiple
  * Required: Optional
* **Contact Email**: This field is for you to enter your contact email address.
  * Type: email
  * Required: Optional
* **Contact Phone**: This field is for you to enter your contact phone number.
  * Type: text
  * Required: Optional
* **Assigned To**: This field is for you to select who from your company will be responsible for this trade show event.
  * Type: select_one
  * Required: Optional
* **Event Details Notes**: This field is for you to add any additional event details or notes you'd like to share with us.
  * Type: text
  * Required: Optional
