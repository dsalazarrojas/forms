# Event Attendance Declaration Form - Help Guide

## Purpose
The Event Attendance Declaration Form is a tool for event organizers to track event attendees and their details. It's used to gather essential information about the event, such as attendance numbers, attendee information, and event status.

## How To Complete This Form
To complete this form, follow the steps below:

1. Fill in the Event Date field with the date of the event you're registering for.
2. Enter the Time Arrived field with the time you arrived at the event.
3. In the Event Attendance Type field, select one or many from the given options to specify your attendance type.
4. Fill in the Attendee Name field with the name of the person attending the event.
5. Enter a valid Email in the Email field.
6. Provide your Phone number in the Phone field.
7. If you're part of a team, fill in the Team Name field with your team's name.
8. If you're a team lead, enter your Team Lead name in the Team Lead field.
9. Enter the size of your team in the Team Size field.
10. Provide any relevant Event Details in the Event Details field.
11. Add any additional Notes about your attendance or the event.
12. If applicable, enter the Event Location where the event took place.
13. Select the Event Status from the given options (Active, Inactive, or Pending).
14. If applicable, select the Assigned Tool from the given options.

## Field-by-Field Explanation

* **Event Date** (`event_date`, date, required: false): Enter the date of the event you're registering for.
* **Time Arrived** (`time_arrived`, time, required: false): Enter the time you arrived at the event.
* **Event Attendance Type** (`event_attendance_type`, select_multiple, required: false): Choose one or many from the given options to specify your attendance type.
* **Attendee Name** (`attendee_name`, text, required: false): Fill in the name of the person attending the event.
* **Email** (`attendee_email`, email, required: false): Enter a valid Email.
* **Phone** (`attendee_phone`, text, required: false): Provide your Phone number.
* **Team Name** (`team_name`, text, required: false): If you're part of a team, fill in the Team Name field with your team's name.
* **Team Lead** (`team_lead`, text, required: false): If you're a team lead, enter your Team Lead name in the Team Lead field.
* **Team Size** (`team_size`, number, required: false): Enter the size of your team.
* **Event Details** (`event_details`, note, required: false): Provide any relevant Event Details.
* **Notes** (`notes`, note, required: false): Add any additional Notes about your attendance or the event.
* **Event Location** (`event_location`, text, required: false): If applicable, enter the Event Location where the event took place.
* **Event Status** (`event_status`, select_one, required: false): Select the Event Status from the given options (Active, Inactive, or Pending).
* **Assigned Tool** (`assigned_tool`, select_one, required: false): If applicable, select the Assigned Tool from the given options.
