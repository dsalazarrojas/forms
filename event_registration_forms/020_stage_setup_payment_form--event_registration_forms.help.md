# Stage Setup Payment Form - Help Guide
## Purpose
This form is designed to handle stage setup payment setup for events. It is a critical part of the event registration process, ensuring that all necessary details are captured accurately.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the required information in each field, making sure to enter accurate and relevant details.
2. Review each field carefully to ensure you have entered the correct information.
3. Submit the form once you have completed all required fields.

## Field-by-Field Explanation

* **Event Organizer**: Enter the name of the event organizer. This is a required field for event registration.
* **Service Date**: Select the date of the service. This field is required for accurate scheduling.
* **Service Time**: Choose the time of the service. This field helps in coordinating the service schedule.
* **Service Details**: Enter a brief description of the service. This field provides context for the service being offered.
* **Payment Method**: Select the method of payment for the service. Options include 'Yes', 'No', and 'Other' for flexibility.
* **Price**: Enter the price of the service. This field is essential for billing purposes.
* **Notes**: Add any additional notes or comments about the service. This field helps in clarifying any doubts or concerns.
* **Email**: Enter the contact email for the event organizer. This field ensures smooth communication.
* **Phone**: Enter the contact phone number for the event organizer. This field aids in easy communication.
* **Assigned User**: Choose the user assigned to the service. Options include 'Yes', 'No', and 'Other' for flexibility.
* **Submit**: Confirm that the information is accurate and complete before submitting the form. Select 'Yes' or 'No' to proceed or indicate 'Other' if necessary.
* **Service Type**: Select the type of service being offered. Options include 'Yes', 'No', and 'Other' for flexibility.
* **Event Category**: Choose the category of the event. Options include 'Yes', 'No', and 'Other' for flexibility.
* **Assigned Tool**: Select the tool assigned to the service. Options include 'Yes', 'No', and 'Other' for flexibility.
* **Service Status**: Select the status of the service. Options include 'Yes', 'No', and 'Other' for flexibility.
* **Service Type Status**: Choose the status of the service type. Options include 'Yes', 'No', and 'Other' for flexibility.
* **Assigned User 2**: Select the second user assigned to the service. Options include 'Yes', 'No', and 'Other' for flexibility.
* **Notes 2**: Add any additional notes or comments about the service. This field helps in clarifying any doubts or concerns.
* **Payment Terms**: Enter the payment terms for the service. This field is essential for billing purposes.
* **Payment Terms Status**: Select the status of the payment terms. Options include 'Yes', 'No', and 'Other' for flexibility.
* **Event Category 2**: Choose the category of the second event. Options include 'Yes', 'No', and 'Other' for flexibility.
* **Assigned Tool 2**: Select the tool assigned to the second event. Options include 'Yes', 'No', and 'Other' for flexibility.
* **Service Status 2**: Select the status of the second service. Options include 'Yes', 'No', and 'Other' for flexibility.
* **Service Type 2**: Choose the type of the second service. Options include 'Yes', 'No', and 'Other' for flexibility.

## Tips

* Double-check your input to ensure accuracy before submitting the form.
* Use clear and concise language for all entries.
* If unsure about any field, refer to the event organizer or the event team for guidance.
* This form is for single-instance completion; avoid duplicate submissions.
