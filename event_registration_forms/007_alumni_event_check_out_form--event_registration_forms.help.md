# Alumni Event Check Out Form - Help Guide
## Purpose
The Alumni Event Check Out Form is used to document the attendance and check-out details of alumni attendees at events held by the organization. This form helps staff track key information, including attendee names, event titles, and check-out times, ensuring accurate record-keeping and facilitating post-event follow-up and planning.

## How To Complete This Form
To complete the Alumni Event Check Out Form, follow these steps:

1.  Enter the **Attendee name**, which is the full name of the person checking out.
2.  Enter the **Event name**, which is the title of the event the attendee is attending or has attended.
3.  Enter the **Check out time**, which is the time of departure for the attendee.
4.  If applicable, enter the **Payment collected at check out**, which represents any payment made during the event or check-out process.
5.  Optionally, select **Follow up needed**, if any follow-up action is required after the event.
6.  Provide any **Items returned**, which are items collected from the attendee at the time of check-out.
7.  Rate your **Event satisfaction rating**, from 1 to 5, to help us evaluate the event's quality.
8.  Add any relevant **Staff notes**, for internal use by event staff.

## Field-by-Field Explanation
- **Attendee name**: Enter the full name of the attendee, as it will be used for check-in and follow-up purposes.
  * Type: Text
  * Required: Yes
  * Hint: Full name used at check-in
- **Event name**: Enter the title of the event the attendee is attending or has attended.
  * Type: Text
  * Required: Yes
  * Hint: Title of the event
- **Check out time**: Enter the time of departure for the attendee.
  * Type: Time
  * Required: Yes
  * Hint: Time of departure
- **Event satisfaction rating**: Rate your satisfaction with the event from 1 to 5.
  * Type: Select One (1-5)
  * Required: No
  * Hint: Rate from 1 to 5
- **Items returned**: List any items returned at check-out.
  * Type: Text
  * Required: No
  * Hint: List any items returned at check-out
- **Payment collected at check out**: Enter any payment made during the event or check-out process.
  * Type: Number
  * Required: No
  * Hint: Enter amount if applicable
- **Follow up needed**: Select yes if follow up is required.
  * Type: Select One
  * Required: No
  * Hint: Select yes if follow up is required
- **Staff notes**: Enter any internal notes for event staff.
  * Type: Text
  * Required: No
  * Hint: Internal notes for event staff
