# Lunch Trade Participation Form - Help Guide
## Purpose
This form is used to register a participant for the lunch trade event. It will guide you through the necessary steps to provide your information and preferences for the event.

## How To Complete This Form
1. Read through the form carefully and ensure you have all the necessary information before submitting.
2. Fill out the form with your accurate and complete information.
3. Review your submission carefully before submitting it.

## Field-by-Field Explanation
* **Participant Information** (`participant_info`): Enter your name and any other relevant participant information.
* **Start Time** (`start_time`): Choose the time you would like to start the lunch trade. Please enter the time in 24-hour format (e.g., 13:00 for 1:00 PM).
* **Finish Time** (`finish_time`): Choose the time you would like to finish the lunch trade.
* **Participant Name** (`name`): Enter your name.
* **Email** (`email`): Enter your email address. Please ensure it is accurate and active.
* **Phone Number** (`phone_number`): Enter your phone number. This is not required but can be helpful for communication purposes.
* **Participant Preferences** (`participant_preferences`): If you have any special requests or preferences (e.g., dietary restrictions), please enter them here.
* **Vegetarian** (`preference_1`): If you are a vegetarian, select "True". If you are not vegetarian, select "False".
* **Vegan** (`preference_2`): If you are a vegan, select "True". If you are not vegan, select "False".
* **Other** (`preference_3`): If you have any other preferences not listed, select "True". If you do not have any other preferences, select "False".
* **Preference 4** (`preference_4`): Select "Yes" if you have this preference and "No" if you do not.
* **Other Preference** (`other_p`): If you have any other preference not listed, please enter it here.
* **Notes** (`participant_notes`): If you have any additional information you would like to share, please enter it here.
* **Agree** (`participant_agree`, `participant_agree_2`, `participant_agree_3`, `participant_agree_4`, `participant_agree_5`, `participant_agree_6`, `participant_agree_7`): Select "True" to agree to the terms and conditions of the lunch trade. Select "False" if you do not agree.
* **More Information** (`participant_info_2`): If you have any additional information you would like to share, please enter it here.
* **Additional Info 2** (`participant_info_2_1`): If you have any additional information you would like to share, please enter it here.
