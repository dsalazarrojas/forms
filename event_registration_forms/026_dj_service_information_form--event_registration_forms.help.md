# DJ Service Information Form - Help Guide

## Purpose

This form is for clients to provide information about their upcoming event to the DJ service provider.


## How To Complete This Form

1. Please fill out the form with your event details and requirements.
2. Select the event type (DJ Set, Event Party, etc.).
3. Enter your contact number so we can reach you for any follow-up questions.
4. Choose the date and time for the service.
5. Provide the venue where the event will be held.
6. Add any additional description or instructions for the DJ.
7. Select the music style(s) you'd like us to play.
8. Specify any equipment you have or need.
9. Choose the event type (Wedding, Birthday, etc.).
10. Select your music preferences (Upbeat, Slow, etc.).
11. Enter the price you are willing to pay for the service.
12. Choose the service type (Dance, Play, etc.).
13. If you have any special requests, please let us know in the note field.

## Field-by-Field Explanation

* **event_type**: Please select the type of event you are hosting (e.g. DJ Set, Event Party).
* **dj_name**: Enter your name or the name of the person who will be responsible for the event.
* **contact_number**: Your contact number so we can reach you for any follow-up questions or details.
* **service_date**: Choose the date for the service.
* **start_time**: Select the start time for the service.
* **end_time**: Select the end time for the service.
* **venue**: Enter the location where the event will be held.
* **description**: Provide any additional information or instructions for the DJ.
* **music_style**: Select the music style(s) you'd like us to play (e.g. Rock, Pop, etc.).
* **equipment**: Specify any equipment you have or need for the service.
* **event_type**: Select the type of event you are hosting (e.g. Wedding, Birthday, etc.).
* **music_preferences**: Select your music preferences (e.g. Upbeat, Slow, etc.).
* **price**: Enter the price you are willing to pay for the service.
* **service_type**: Choose the type of service you need (e.g. Dance, Play, etc.).
* **special_request**: If you have any special requests, please let us know in this field.

This form is designed to be easy to understand and complete. If you have any questions or need further clarification, please don't hesitate to contact us!
