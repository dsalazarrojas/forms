# Transparency Audit Conference Registration - Help Guide

## Purpose
This form is designed to collect information from attendees for the Transparency Audit Conference. The form is divided into two main sections: attendee information and session preferences.

## How To Complete This Form

1. **Form Name**: Enter the name of the event or conference you are registering for. This field is not required but is useful for organization purposes.
2. **Attendee Email**: Enter the email address of the attendee. This field is required to ensure that the attendee can receive updates and notifications about the conference.
3. **Attendee Name**: Enter the name of the attendee. This field is not required but is useful for internal purposes.
4. **Attendance Mode**: Choose the attendance mode for the conference. Options include "Yes" and "No". This field is not required but is useful for organization purposes.
5. **Sessions**: Select the sessions you would like to attend. Each session has two options: "Yes" and "No". This field is not required but is useful for organization purposes.
6. **Session 1-9**: Choose which sessions you would like to attend from Session 1 to Session 9. Each session has two options: "Yes" and "No".
7. **Attendee Notes**: Enter any additional notes or comments you have about your attendance. This field is not required but is useful for internal purposes.
8. **Attendee Phone**: Enter the phone number of the attendee. This field is not required but is useful for internal purposes.
9. **Form Submission**: This field is not required but is useful for organization purposes.

## Field-by-Field Explanation

* **Form Name** (`form_name`, `text`, optional): Enter the name of the event or conference.
* **Attendee Email** (`attendee_email`, `email`, required): Enter the email address of the attendee to ensure updates and notifications.
* **Attendee Name** (`attendee_name`, `text`, optional): Enter the name of the attendee for internal purposes.
* **Attendance Mode** (`attendance_mode`, `select_multiple`, optional): Choose the attendance mode for the conference.
* **Sessions** (`session_preferences`, `select_multiple`, optional): Select the sessions you would like to attend.
* **Session 1-9** (`session_1-session_9`, `select_one`, optional): Choose the sessions you would like to attend from Session 1 to Session 9.
* **Attendee Notes** (`attendee_notes`, `text`, optional): Enter any additional notes or comments about your attendance.
* **Attendee Phone** (`attendee_phone`, `text`, optional): Enter the phone number of the attendee for internal purposes.
* **Form Submission** (`form_submit`, `note`, optional): This field is not required but is useful for organization purposes.
