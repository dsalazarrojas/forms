# Mentorship Program Access Form - Help Guide

## Purpose
The Mentorship Program Access Form is designed to gather information from users who are participating or interested in the mentorship program. This form aims to collect relevant details for the program's management, tracking, and evaluation.

## How To Complete This Form

1. Select the Mentorship Program Id (Program Id) from the available options.
2. Enter your Name.
3. Provide your Email.
4. Enter your Phone number.
5. Select the Start Date for the mentorship program.
6. Select the End Date for the mentorship program.
7. Enter the Description of the mentorship program.
8. Select the Mentee Id (Mentee Id) from the available options.
9. Choose the Mentorship Program Type.
10. Select the Status of the mentorship program.
11. Choose the Relationship Type.
12. Enter any additional Notes about the mentorship program.
13. Enter the Location of the mentorship program.
14. Enter the URL for the mentorship program.
15. Enter the URL Title for the mentorship program.
16. Enter the External Id for the mentorship program.
17. Enter the Created By user who started the program.
18. Enter the Last Updated (Date and Time) of the mentorship program.
19. Enter the Last Updated By user who last updated the program.
20. Enter the Last Updated User Id of the user who last updated the program.
21. Enter the Last Updated User Ip (Ip address) of the user who last updated the program.
22. Enter the Last Updated User Name of the user who last updated the program.
23. Enter the Last Updated User Location of the user who last updated the program.

## Field-by-Field Explanation

* **Program Id**: Select the Mentorship Program Id to identify the program you are registering for.
* **Name**: Enter your name for the mentorship program registration.
* **Email**: Enter your email address for further contact and correspondence.
* **Phone**: Enter your phone number for any follow-up communication.
* **Start Date**: Select the start date for the mentorship program.
* **End Date**: Select the end date for the mentorship program.
* **Description**: Briefly describe the mentorship program to help the management team understand its scope.
* **Mentee Id**: Select the Mentee Id from the available options to connect with the mentee.
* **Mentorship Program Type**: Choose the type of mentorship program you are registering for.
* **Status**: Select the status of the mentorship program.
* **Relationship Type**: Choose the relationship type for the mentorship program.
* **Notes**: Enter any additional information or comments about the mentorship program.
* **Location**: Enter the location where the mentorship program will be held.
* **Url**: Enter the URL for the mentorship program.
* **Url Title**: Enter the title for the URL of the mentorship program.
* **External Id**: Enter the external Id for the mentorship program.
* **Created By**: Enter the user who created the mentorship program.
* **Last Updated (Date and Time)**: Enter the last updated date and time of the mentorship program.
* **Last Updated By**: Enter the user who last updated the mentorship program.
* **Last Updated User Id**: Enter the user Id of the user who last updated the mentorship program.
* **Last Updated User Ip**: Enter the IP address of the user who last updated the mentorship program.
* **Last Updated User Name**: Enter the name of the user who last updated the mentorship program.
* **Last Updated User Location**: Enter the location of the user who last updated the mentorship program.

## Tips
- Please ensure that you select the correct Program Id and Mentee Id to avoid any confusion or duplication.
- Double-check your entries for accuracy, completeness, and correctness.
- Enter any relevant information about the mentorship program to help the management team make informed decisions.
- If you are unsure about any field, please ask for help or clarification.
