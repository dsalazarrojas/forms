# Gamified Learning Challenge Registration - Help Guide
## Purpose
This form is used to register participants for a gamified learning challenge. A gamified learning challenge is an event or activity that involves game-like elements to make learning more engaging and interactive. Participants can register individually or as part of a team.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the required information for each field.
2. Review your responses for accuracy before submitting the form.

## Field-by-Field Explanation
### Participant Name
* **Participant Name**: <participant_name> - Enter the name of the participant, either as an individual or as part of a team.

### Team Name
* **Team Name**: <team_name> - Enter the name of the team you are registering for, if applicable. If you are registering as an individual, leave this field blank.

### Challenge Name
* **Challenge Name**: <challenge_name> - Enter the name of the challenge you are registering for. This field is required.

### Challenge Type
* **Challenge Type**: <challenge_type> - Select whether you are registering as an individual or as part of a team. This field is required.

### Team Members
* **Team Members**: <team_members> - If you are registering as part of a team, select all members who will be participating. If you are registering as an individual, leave this field blank.

### Start Date
* **Start Date**: <start_date> - Enter the date on which the challenge will begin. This field is required.

### End Date
* **End Date**: <end_date> - Enter the date on which the challenge will end. This field is required.

### Location
* **Location**: <location> - Enter the location where the challenge will take place. This field is required.

### Team Size
* **Team Size**: <team_size> - Enter the number of team members. This field is required.

### Max Team Size
* (Note): This is a hint indicating the maximum team size for this challenge. It is not editable.

### Participant Email
* **Participant Email**: <participant_email> - Enter the email address of the participant. This field is required.

### Participant Phone
* **Participant Phone**: <participant_phone> - Enter the phone number of the participant. This field is required.

### Note
* **Note**: <participant_note> - Enter any additional notes or comments about the participant. This field is optional.
