## Purpose
The purpose of the Summer Camp Reservation Form is to gather information about the summer camp reservations for a child. This form asks about the child's name, age, parent's contact information, preferred diet, and preferred schedule.
 
## How To Complete This Form
To complete this form, follow these steps:
1. Select the answer for "Summer Camp Reservation" question.
2. Enter the name of the child.
3. Enter the name of the child.
4. Enter the age of the child.
5. Enter the parent's email address.
6. Enter the parent's phone number.
7. Select the preferred diet for the child.
8. Select the preferred schedule for the child, choosing one or more options.
9. Select one of the options for "Preferred Schedule" if applicable.
10. Select one or more options for "Preferred Schedule Option" if applicable.
11. Confirm the submission of the form by selecting "Yes".
 
## Field-by-Field Explanation
* **Summer Camp Reservation** (`summer_camp_reservation_form`, select_multiple, required): Select whether the child will be attending summer camp. This is the first question on the form.
* **Name** (`name`, text, required): Enter the name of the child.
* **Name of Child** (`name_of_child`, text, required): Enter the name of the child again.
* **Age of Child** (`age_of_child`, text, required): Enter the age of the child.
* **Parent Email** (`parent_email`, email, required): Enter the parent's email address.
* **Parent Phone** (`parent_phone`, text, required): Enter the parent's phone number.
* **Preferred Diet** (`preferred_diet`, select_one, required): Select the preferred diet for the child.
* **Preferred Schedule** (`preferred_schedule`, select_multiple, required): Select the preferred schedule for the child, choosing one or more options.
* **None** (`preferred_schedule_option`, select_multiple, required): Select one or more options for the "Preferred Schedule" if applicable.
* **Submit** (`submit`, select_one, required): Confirm the submission of the form by selecting "Yes".
 
## Tips
* Please make sure to enter accurate and complete information for all fields.
* The preferred schedule and diet selections will be used to create a personalized schedule for the child.
* Please select "Yes" to confirm the submission of the form.
