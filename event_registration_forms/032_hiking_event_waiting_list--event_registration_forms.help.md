# Hiking Event Waiting List - Help Guide

## Purpose
The purpose of this form is to register hikers for a hiking event. This form helps event organizers collect necessary information about each hiker, including their name, start and end dates, event type, number of participants, and contact details (phone number and email).

## How To Complete This Form
To complete this form, please follow the steps below:

1. Enter the title of the event ("Hiking Event Waiting List") as a heading on this page.
2. On the **Registration Form** page, fill out the required fields:
	* **Hikers Name**: Enter the name of each hiker.
	* **Start Date** and **End Date**: Enter the start and end dates of the event.
	* **Event Type**: Select "Yes" or "No" to indicate if this event is available to hikers.
	* **Number of Participants**: Enter the number of participants in the event.
3. If you want to provide additional contact information, you can optionally enter:
	* **Contact Phone**: Enter a phone number where the event organizer can be contacted.
	* **Contact Email**: Enter an email address where the event organizer can be contacted.

## Field-by-Field Explanation
* **Registration Form (1)**:
	+ **Hikers Name (hikers_name)**: Enter the name of each hiker.
* **Hikers Name (hikers_name)**:
	+ This field is required to collect the name of each hiker.
* **Start Date (start_date)**:
	+ Enter the start date of the event.
* **End Date (end_date)**:
	+ Enter the end date of the event.
* **Event Type (event_type)**:
	+ Select "Yes" to indicate if this event is available to hikers. If you select "No", it means the event is not open to hikers.
* **Number of Participants (num_participants)**:
	+ Enter the number of participants in the event.
* **Contact Phone (contact_phone)**:
	+ This field is optional and is used to provide a phone number where the event organizer can be contacted.
* **Contact Email (contact_email)**:
	+ This field is optional and is used to provide an email address where the event organizer can be contacted.
