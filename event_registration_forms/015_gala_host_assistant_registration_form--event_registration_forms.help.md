# Gala Host Assistant Registration Form - Help Guide
## Purpose
This form is used to register as a host assistant for galas. If you're interested in volunteering your time and services for an event, please fill out this form to be considered for assignment.

## How To Complete This Form
To complete this form, simply follow the steps below:

1. Fill out the required information:
	* First Name
	* Last Name
	* Email
	* Phone Number
2. Select your Experience Level
3. Choose which days you are Available:
4. Select your category and Subcategory (optional)
5. Select your Status:
6. Add any additional Comments (optional)

## Field-by-Field Explanation
### First Name 
* **First Name** (text): Enter the first name of the assistant.
### Last Name 
* **Last Name** (text): Enter the last name of the assistant.
### Email 
* **Email** (email): Enter the email address of the assistant.
### Phone Number 
* **Phone Number** (number): Enter a 10-digit number for the assistant's phone number.
### Experience Level 
* **Experience Level** (select_one): Select the experience level of the assistant, which includes 0-1 year, 1-2 years, 2-5 years, or More than 5 years.
### Available Dates 
* **Available Dates** (select_multiple): Choose the dates on which the assistant is available.
### Assigned Tool 
* **Assigned Tool** (text): This field is not required and can be used to specify any assigned tool for the assistant.
### Description 
* **Description** (note): This field is optional and can be used to provide any additional description of the assistant's services.
### Category 
* **Category** (select_one): Select the category of the assistant, which includes Event Assistant, Host Assistant, Event Coordinator, or Event Manager.
### Subcategory 
* **Subcategory** (select_one): Select the subcategory of the assistant, which includes Gala, Reception, Wedding, Birthday, or Holiday.
### Status 
* **Status** (select_one): Select the status of the assistant, which includes Available or Not Available.
### Comments 
* **Comments** (note): Add any additional comments about the assistant's services.
 

## Tips
* Please ensure that you are only completing this form once, as duplicates may cause confusion and unnecessary work for the event planners.
* Double-check all information for accuracy before submitting the form.
