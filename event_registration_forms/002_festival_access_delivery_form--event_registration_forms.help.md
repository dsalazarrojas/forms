# Festival Access Delivery Form - Help Guide
## Purpose
This form is used to register an attendee for a festival.

## How To Complete This Form
To complete this form, follow the instructions below:

1. Fill in the festival name and date in the corresponding fields.
2. Select the event type that best describes the event you are registering for.
3. Select the type of ticket(s) you are requesting.
4. Fill in any additional notes that you would like to provide.

## Field-by-Field Explanation

* **Festival Name** (`text`, `required`: false): Please enter the name of the festival you are registering for.
* **Festival Date** (`date`, `required`: false): Please enter the date of the festival you are registering for.
* **Festival Time** (`time`, `required`: false): Please enter the time of the festival you are registering for.
* **Festival Location** (`text`, `required`: false): Please enter the location of the festival you are registering for.
* **Attendee First Name** (`text`, `required`: false): Please enter the first name of the attendee.
* **Attendee Last Name** (`text`, `required`: false): Please enter the last name of the attendee.
* **Attendee Email** (`email`, `required`: false): Please enter the email of the attendee.
* **Attendee Phone** (`text`, `required`: false): Please enter the phone number of the attendee.
* **Attendee Notes** (`note`, `required`: false): Please enter any additional notes about the attendee.
* **Event Type** (`select_one`, `required`: false): Please select the type of event that best describes the event you are registering for.
* **Ticket Type** (`select_multiple`, `required`: false): Please select the type of ticket(s) you are requesting.

## Tips
* Make sure to fill out all required fields (if any) to ensure accurate processing of your registration.
* If you are unsure about any of the fields, please contact the festival organizer or staff member for clarification.
* Double check your information before submitting the form to ensure accuracy.
