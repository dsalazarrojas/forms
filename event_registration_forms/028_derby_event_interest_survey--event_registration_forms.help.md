# Derby Event Interest Survey - Help Guide
## Purpose
The Derby Event Interest Survey is a simple, online form designed to gather information from users about their interests in attending a derby event. This form helps event organizers understand who is interested in participating in the event and tailor their offerings accordingly.

## How To Complete This Form
To complete this form, please follow these steps:

1. Review the available options for each field and select the relevant ones that apply to you.
2. Fill out the required fields (marked as "Required" in the form).
3. Provide any additional information you deem relevant in the "Note" field.

## Field-by-Field Explanation

* **Main Page** (`event_interest_survey_1`, `note`, Optional): This is the introduction page of the form. Please review the information provided and proceed to the next page.
* **Event Information** (`event_interest_survey_2`, `text`, Optional): Please provide a brief description of the event that interests you the most.
* **Event Dates** (`event_dates`, `select_multiple`, Optional): This field allows you to indicate if you are available for the event on multiple dates. Select all dates that apply.
* **Event Venue** (`event_venue`, `select_one`, Optional): Please select the venue where you would like the event to be held.
* **Event Time** (`event_time`, `time`, Optional): If you have a preferred time for the event, please select it.
* **Event Dates 2** (`event_dates_2`, `select_multiple`, Optional): Similar to "Event Dates", this field is asking if you are available for the event on multiple dates. Select all dates that apply.
* **Venue 2** (`event_venue_2`, `select_one`, Optional): Please select one of the available venues.
* **Email** (`email`, `email`, Optional): If you have a specific email address associated with you, please provide it.
* **Phone** (`phone`, `text`, Optional): Please provide your phone number for any follow-up communication.
* **Note** (`note`, `note`, Optional): If you have any additional information or comments about your interest in the event, please provide them here.

## Tips

* Please be as specific as possible when providing information about your interests and availability.
* If you are unsure about any of the fields, please don't hesitate to contact event organizers for clarification.
* Your input is valuable to us, and we appreciate your participation in this survey!
