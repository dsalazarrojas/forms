# Event Packing Checklist - Help Guide
## Purpose
This form is used to collect information from event organizers to ensure that all necessary items are packed for an event.

## How To Complete This Form
To complete this form, follow these steps:

1. Select all the items that need to be packed for the event from the options provided in the "Item List" field.
2. Indicate the status of each item as "Packed" or "Not Pack" using the "Status" field.
3. Add any relevant notes about each item in the "Notes" field.
4. Enter the date and time of the event in the "Date of Event" and "Time of Event" fields.
5. Enter your contact email and phone number in the "Contact Email" and "Contact Phone" fields.
6. Enter the quantity of each item to be packed in the "Quantity" field.
7. Enter a brief description of each item in the "Description" fields.

## Field-by-Field Explanation

* **Item List** (`item_list`, Select Multiple): Select all the items that need to be packed for the event from the options provided.
* **Status** (`item_status`, Select One): Indicate the status of each item as "Pack" or "Not Pack".
* **Notes** (`notes`, Note): Enter any additional notes about each item.
* **Date of Event** (`date_event`, Date): Enter the date of the event.
* **Time of Event** (`time_event`, Time): Enter the time of the event.
* **Contact Email** (`contact_email`, Email): Enter your contact email address.
* **Contact Phone** (`contact_phone`, Text): Enter your contact phone number.
* **Quantity** (`item_quantity`, Number): Enter the quantity of each item to be packed.
* **Name** (`item_name`, Text): Enter a brief description of each item.
* **Description** (`item_description`, Text): Enter a detailed description of each item.
