# Urban Redevelopment Forum Registration Form - Help Guide
## Purpose
The purpose of this form is to collect registration information from individuals attending events, conferences, or meetings. This includes event name, attendee's name and contact information.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the required fields with accurate information.
2. Make sure to use a valid email address for the Email field.
3. Enter a phone number in the Phone field (optional).
4. Select a date in the Date field (if applicable).
5. Enter a time in the Time field (if applicable).

## Field-by-Field Explanation
### Event Name
* **Event Name (text, optional)**: Enter the name of the event you are attending.

### Attendee Name
* **Attendee Name (text, optional)**: Enter your name as it should be listed on the event's attendee list.

### Email
* **Email (email, optional)**: Enter a valid email address that you check regularly.

### Phone
* **Phone (text, optional)**: Enter your phone number for contact purposes.

### Date
* **Date (date, optional)**: Enter the date of the event if applicable.

### Time
* **Time (time, optional)**: Enter the time of the event if applicable.
