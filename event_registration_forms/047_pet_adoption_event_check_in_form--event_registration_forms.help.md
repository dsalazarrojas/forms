# Pet Adoption Event Check In Form - Help Guide
## Purpose
The Pet Adoption Event Check In Form is designed to collect information about pets that are participating in an adoption event.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the pet's name in the "Pet Name" field.
2. Select the pet's species from the "Pet Species" dropdown menu.
3. Choose the pet's type from the "Pet Type" dropdown menu.
4. Select the pet's breed from the "Pet Breed" dropdown menu.
5. Enter the pet's age in the "Pet Age" field.
6. Select the pet's color from the "Pet Color" dropdown menu.
7. Enter the date of the event the pet will participate in.
8. Enter the time the event will start.
9. Enter the time the pet will be checked in.
10. Provide the pet owner's name in the "Pet Owner" field.
11. Enter the pet owner's contact number.
12. Add any additional comments or notes in the "Additional Comments" field.

## Field-by-Field Explanation
* **Pet Name (1)** (`pet_name`, text, required): Enter the name of the pet participating in the event.
* **Pet Species (2)** (`pet_species`, select_one, required): Select the species of the pet (e.g., Cat, Dog, Bird, Fish, Reptile, Other).
* **Pet Type (3)** (`pet_type`, select_multiple, required): Choose the type of pet (e.g., Domestic Cat, Domestic Dog, Other, Unknown).
* **Pet Breed (4)** (`pet_breed`, select_multiple, required): Select the breed of the pet (e.g., Yes, No, Unknown).
* **Pet Age (5)** (`pet_age`, number, required): Enter the age of the pet.
* **Pet Color (6)** (`pet_color`, select_multiple, required): Select the color of the pet (e.g., Black, Brown, Green, Gray, White).
* **Event Date (7)** (`event_date`, date, required): Enter the date of the event the pet will participate in.
* **Event Start Time (8)** (`event_start_time`, time, required): Enter the time the event will start.
* **Check In Time (9)** (`check_in_time`, time, required): Enter the time the pet will be checked in.
* **Pet Owner (10)** (`pet_owner`, text, required): Provide the name of the pet owner.
* **Contact Number (11)** (`contact_number`, text, required): Enter the contact number of the pet owner.
* **Additional Comments (12)** (`additional_comments`, text, required): Add any additional comments or notes about the pet.

Note: Please ensure that all required fields are completed accurately and thoroughly.
