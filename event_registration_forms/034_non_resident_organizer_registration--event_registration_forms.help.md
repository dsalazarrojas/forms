# Non Resident Organizer Registration - Help Guide
## Purpose
This form is for non-resident organizers to register their events with the organization. It gathers information about the event, including details about the event itself, the organizer's contact information, and the status of the review process.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the relevant fields and fill in the required information, making sure to provide accurate and complete data.
2. Make sure to select the correct options for "Contact Method" and "Event Type" fields.
3. Double-check that you've filled in all required fields (marked as "Required") and ensure they're accurate.
4. Review your filled form for any errors before submitting it.

## Field-by-Field Explanation
* **Non-Resident Event** (`non_resident_event_id`): Enter the ID of the non-resident event to be registered.
* **Name** (`name`): Enter your name as it should appear on official records and communication.
* **Email** (`email`): Enter your email address where you can be reached.
* **Phone** (`phone_number`): Enter your contact phone number.
* **Contact Method** (`contact_method`): Choose how you prefer to be contacted (Phone, Email, or Mail).
* **Event Date** (`event_date`): Select the date of the event.
* **Event Time** (`event_time`): Select the time of the event.
* **Organizer Name** (`organizer_name`): Enter the name of the event organizer (if different from you).
* **Event Organizer** (`event_organizer`): If there is an event organizer different from you, enter their name.
* **Followup Required** (`followup_required`): Decide if followup is required after the review process. If unsure, mark "False".
* **Note** (`note`): Enter any additional information you'd like to provide about the event.
* **Review Status** (`review_status`): Select the status of your event in the review process (Approved, Pending, or Rejected).
* **Non-Resident Event 2** (`non_resident_event_id_2`): Enter the ID of another non-resident event (if applicable).
* **Event Type** (`event_type`): Choose the type of event (Conference, Meeting, or Workshop).
* **Venue Name** (`venue_name`): Enter the name of the venue where the event takes place.
* **Venue Address** (`venue_address`): Enter the venue's address.
* **Venue City** (`venue_city`): Enter the city of the venue.
* **Venue State** (`venue_state`): Enter the state of the venue.
* **Venue Postal Code** (`venue_postal_code`): Enter the postal code of the venue.
* **Contact Person** (`contact_person`): Enter the name of the contact person (if different from you).
* **Additional Info** (`additional_info`): Enter any additional information about the event.
* **Review Date** (`review_date`): Select the date of the review (if applicable).
* **Review Status 2** (`review_status_2`): Select the status of your event in the review process (Approved, Pending, or Rejected).
* **Event Description** (`event_description`): Enter a description of the event.
* **Non-Resident Event 3** (`non_resident_event_id_3`): Enter the ID of another non-resident event (if applicable).

## Tips
- Make sure to double-check all fields for accuracy and completeness before submitting.
- Review the "Review Status" fields to understand the current status of your event in the review process.
- If you have any questions or need help, contact the relevant personnel for assistance.
