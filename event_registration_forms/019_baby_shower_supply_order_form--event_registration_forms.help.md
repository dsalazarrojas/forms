# Baby Shower Supply Order Form - Help Guide
## Purpose
This form is designed for baby shower organizers to order supplies for their events. It helps to ensure that the right supplies are ordered and delivered on time.

## How To Complete This Form
1. Enter the **Organizer name**, the person responsible for ordering the supplies.
2. Choose the **Event date** when the supplies are needed.
3. Specify the **Item needed** (e.g., diapers, wipes, etc.).
4. Enter the **Quantity required** for the item.
5. If you have a preferred supplier, enter their name in **Supplier preference**.
6. Enter the **Delivery address** where the supplies should be delivered.
7. If applicable, select a **Desired delivery date and time window**.
8. Provide your **Contact phone number** for delivery queries.
9. If you have a **Budget code or account**, enter it for internal accounting purposes.
10. Add any **Order notes**, if you need to provide additional information.

## Field-by-Field Explanation
* **Organizer name (1)**: The name of the person responsible for the baby shower supplies order.
* **Event date (2)**: The date when the supplies are needed.
* **Item needed (3)**: Specify the item you need to order (e.g., diapers, wipes, etc.).
* **Quantity required (4)**: Enter the number of units you need for the item.
* **Supplier preference (5)**: If you have a preferred supplier, enter their name.
* **Delivery address (6)**: Where the supplies should be delivered.
* **Desired delivery date (7)**: If applicable, select a date and time window for delivery.
* **Contact phone (8)**: Provide your phone number for delivery queries.
* **Budget code or account (9)**: Enter your budget code or account for internal accounting purposes.
* **Order notes (10)**: Add any additional information that may be helpful for the order.
