# product_innovation_showcase_rsvp - Help Guide
## Purpose
This form is designed to collect RSVPs from attendees to a product innovation showcase event, gathering information about event details, session interests, and other relevant information.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the **Event Details** section, providing the necessary information about the event you are interested in attending.
2. Select the sessions you are interested in by choosing multiple options from the **Session Interests** field.
3. If you have any special requirements, such as accessibility needs or dietary restrictions, please provide them in the **Special Requirements** field.
4. Enter your **Email** address so we can contact you with event updates and information.
5. Provide your **Phone** number (optional) if you prefer to be contacted by phone.
6. Select the date and time of the event you plan to attend from the **Session Date** and **Session Time** fields.
7. Finally, choose your RSVP type from the options provided in the **RSVP Type** field.

## Field-by-Field Explanation
* **Event Details (event_details)**: This field is for providing information about the event you are interested in attending.
* **Name (name)**: This field is for your name.
* **Session Interests (session_interest)**: This is a multiple-choice field where you can select the sessions you are interested in attending.
* **Special Requirements (special_requirements)**: If you have any special requirements, such as accessibility needs or dietary restrictions, please provide them in this field.
* **Email (email)**: Please enter your email address so we can contact you with event updates and information.
* **Phone (phone)**: This field is optional, but if you prefer to be contacted by phone, please provide your phone number.
* **Session Date (session_date)**: Select the date of the event you plan to attend.
* **Session Time (session_time)**: Select the time of the event you plan to attend.
* **RSVP Type (rsvp_type)**: Choose your RSVP type from the provided options.
