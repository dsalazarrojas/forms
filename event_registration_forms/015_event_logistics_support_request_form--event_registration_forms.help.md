# Event Logistics Support Request Form - Help Guide

## Purpose
The Event Logistics Support Request Form is a tool used by event organizers to request support services from the logistics team. This guide will walk you through the process of completing the form and explain each field in detail.

## How To Complete This Form
To complete the form, please follow these steps:

1.  Fill in the event title and description in the respective fields.
2.  Provide the category of the event by selecting the relevant option from the dropdown list.
3.  Enter the requested start and end dates for the event.
4.  Specify the location details including city, state/province, country, and postal/zip code.
5.  Add the contact person's name, phone number, email, and organization information.
6.  Provide the vendor name and email if applicable.
7.  Enter the event status as active or inactive.
8.  Finally, review your input and submit the form.

## Field-by-Field Explanation
* **Event Title**: Enter a brief title of the event.
* **Category**: Select the category of the event from the dropdown list.
* **Requested Start Date**: Enter the date when the event is expected to start.
* **Requested End Date**: Enter the date when the event is expected to end.
* **Location**: Enter the name of the location where the event will take place.
* **Location Address**: Enter the address of the location where the event will take place.
* **City**: Enter the city where the event will take place.
* **State/Province**: Enter the state or province where the event will take place.
* **Country**: Enter the country where the event will take place.
* **Postal/Zip**: Enter the postal code or zip code of the location where the event will take place.
* **Contact Person**: Enter the name of the person responsible for the event.
* **Contact Phone**: Enter the phone number of the person responsible for the event.
* **Contact Email**: Enter the email of the person responsible for the event.
* **Organization**: Enter the name of the organization responsible for the event.
* **Department**: Enter the department of the organization responsible for the event.
* **Role**: Enter the role of the person responsible for the event.
* **Team Member Name**: Enter the name of the team member responsible for the event.
* **Team Member Email**: Enter the email of the team member responsible for the event.
* **Event Type**: Select whether the event is yes or no.
* **Vendor Name**: Enter the name of the vendor responsible for the event.
* **Vendor Email**: Enter the email of the vendor responsible for the event.
* **Event Description**: Enter a brief description of the event.
* **Event Category**: Select the category of the event from the dropdown list.
* **Requested Budget**: Enter the budget for the event.
* **Event Status**: Select the status of the event as active or inactive.
