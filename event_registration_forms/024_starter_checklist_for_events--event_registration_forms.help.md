# Starter Checklist For Events - Help Guide
## Purpose
This form is designed to streamline the process of registering and managing events, ensuring that all relevant details are captured efficiently and effectively.

## How To Complete This Form
1. To get started, fill out the Event Details page with the event's title, which will serve as a reference for future actions.
2. Move on to the Event Name field and enter a unique and descriptive name for the event.
3. Enter the Event Date and Event Time fields with the corresponding dates and times for the event.
4. Provide the Event Location and Event Description fields with the relevant details.
5. If necessary, add any Event Notes to elaborate on the event's specifics.
6. Select the Event Status from the drop-down menu, which can be Active, Inactive, or Cancelled.
7. In the Task List field, choose the tasks associated with the event.
8. If you're concerned about deadlines, enter the Deadline Date and Deadline Time fields accordingly.
9. Decide whether to enable or disable the Reminder feature by selecting from the Reminder field.
10. Finally, specify who is assigned to the event in the Assigned Users field.

## Field-by-Field Explanation
* **Event Details**: A brief title for the event to serve as a reference for future actions.
* **Event Name**: A unique and descriptive name for the event, which will help identify it in the system.
* **Event Date**: The date when the event is scheduled to take place.
* **Event Time**: The time when the event will commence.
* **Event Location**: The physical location or virtual platform where the event will occur.
* **Event Description**: A detailed account of the event's objectives, expectations, and other relevant details.
* **Event Notes**: Additional notes or comments related to the event.
* **Event Status**: Select from Active, Inactive, or Cancelled to reflect the event's current status.
* **Task List**: A list of tasks linked to the event, allowing you to track progress.
* **Deadline Date**: The date by which tasks or actions must be completed.
* **Deadline Time**: The time by which tasks or actions must be completed.
* **Reminder**: Decide whether to enable or disable reminders for the event.
* **Assigned Users**: The individuals or teams responsible for the event's execution.
* **Created By**: The person who created the event.
* **Created At**: The timestamp when the event was created.
