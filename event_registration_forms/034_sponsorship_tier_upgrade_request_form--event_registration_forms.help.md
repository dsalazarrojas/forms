# Sponsorship Tier Upgrade Request Form - Help Guide
## Purpose
This form is used by sponsors to upgrade their sponsorship tier for a specific event. To access this form, you should have already completed the event registration process and be logged in as a sponsor. If you haven't completed the registration process or are not a sponsor, you will not be able to access this form.

## How To Complete This Form
To complete this form, follow these steps:

1. Make sure you have already registered for the event and are logged in as a sponsor.
2. Choose the correct answer to the "Registration form" question, depending on whether you want to submit a registration form or not.
3. Select the sponsorship tier you wish to upgrade to (Bronze, Silver, or Gold).
4. Enter the Event ID of the event you want to upgrade the sponsorship tier for.
5. Enter the name of the event you're upgrading the sponsorship tier for.
6. Enter the name of the sponsor you're representing.
7. Enter your email address for communication with the event organizers.
8. Enter your phone number for the sponsor (if applicable).
9. Provide any additional information about your upgrade request in the "Upgrade details" field.
10. Add any review or comment in the "Review and comment" field (optional).
11. Confirm that you're requesting a sponsorship tier upgrade by selecting "True" in the "Confirm upgrade" field.

## Field-by-Field Explanation

* **Registration form** (select_multiple, required): This field is used to indicate whether you want to submit a registration form or not. Select "Yes" if you want to submit a registration form, and "No" if you don't.
* **Sponsorship Tier** (select_one, required): This field allows you to select the sponsorship tier you want to upgrade to. Choose from the options: Bronze, Silver, or Gold.
* **Event ID** (number, optional): This field is used to enter the Event ID of the event you want to upgrade the sponsorship tier for.
* **Event name** (text, optional): This field is used to enter the name of the event you're upgrading the sponsorship tier for.
* **Sponsor name** (text, optional): This field is used to enter the name of the sponsor you're representing.
* **Sponsor email** (email, optional): This field is used to enter your email address for communication with the event organizers.
* **Sponsor phone** (text, optional): This field is used to enter your phone number for the sponsor (if applicable).
* **Upgrade details** (text, optional): This field is used to provide any additional information about your upgrade request.
* **Review and comment** (text, optional): This field is used to add any review or comment for the event organizers.
* **Confirm upgrade** (select_one, optional): This field is used to confirm that you're requesting a sponsorship tier upgrade by selecting "True" or "False".
