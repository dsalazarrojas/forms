# Fundraising Event Incident Form - Help Guide
## Purpose
This form is used to report incidents that occurred during fundraising events. Please complete it if any unusual or unexpected events took place, such as equipment malfunction, accidents, or unexpected circumstances that affected the event.

## How To Complete This Form
1. Select the correct Event Organizer from the list.
2. Enter the date the incident occurred using the format mm/dd/yyyy.
3. If the incident happened at a specific time, enter the time in 24-hour format (e.g., 14:00 for 2 PM).
4. Choose the correct Incident Location from the list.
5. Select the correct Incident Type from the list.
6. Enter a brief description of the incident in the text box.
7. Choose all actions taken to address the incident from the list.
8. Enter the name or title of the person reporting the incident.
9. Enter the contact phone number of the person reporting the incident.
10. Enter the contact email of the person reporting the incident.

## Field-by-Field Explanation
- **Event Organizer**: Select the person or organization responsible for the event. This will help us to direct feedback or support to the correct person.
	* Required: No
	* Type: Text box
* **Incident Date**: Enter the date the incident occurred, using the format mm/dd/yyyy.
	* Required: No
	* Type: Date field
* **Incident Time**: If the incident happened at a specific time, enter it in 24-hour format (e.g., 14:00 for 2 PM).
	* Required: No
	* Type: Time field
* **Incident Location**: Choose the location where the incident happened.
	* Required: No
	* Type: Select one option
* **Incident Type**: Select the type of incident that occurred.
	* Required: No
	* Type: Select one option
* **Incident Description**: Briefly describe what happened during the incident.
	* Required: No
	* Type: Text box
* **Action Taken**: Choose all actions taken to address the incident.
	* Required: No
	* Type: Select multiple options
* **Incident Reporter**: Enter the name or title of the person reporting the incident.
	* Required: No
	* Type: Text box
* **Contact Phone**: Enter the contact phone number of the person reporting the incident.
	* Required: No
	* Type: Text box
* **Contact Email**: Enter the contact email of the person reporting the incident.
	* Required: No
	* Type: Email field

## Tips
- Be as detailed as possible when describing the incident to help us understand what happened.
- If you're unsure about any field, please ask for help or clarification before submitting the form.
- This form will help us to improve our event planning and execution, so please fill it out accurately and completely.
