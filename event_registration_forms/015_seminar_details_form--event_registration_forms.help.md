# Seminar Details Form - Help Guide
## Purpose

This form is used to collect details about a seminar, including the seminar title, attendee name, attendee email, and attendee phone number.

## How To Complete This Form

1.  To complete this form, simply fill in the required fields with the relevant information.
2.  The fields marked as "Required" are those that must be completed for the form to be considered complete.

## Field-by-Field Explanation

*   **Seminar Details** (`seminal details_form`, `text`, required: false):
    This field is for the seminar title. Please enter a brief description of the seminar.
*   **Seminar Title** (`seminar_title`, `text`, required: false):
    This field is for the title of the seminar. Please enter the actual title of the seminar.
*   **Attendee Name** (`attendee_name`, `text`, required: false):
    This field is for the name of the attendee. Please enter the name of the person attending the seminar.
*   **Attendee Email** (`attendee_email`, `email`, required: false):
    This field is for the email of the attendee. Please enter a valid email address for the attendee.
*   **Attendee Phone** (`attendee_phone`, `text`, required: false):
    This field is for the phone number of the attendee. Please enter a valid phone number for the attendee.

## Tips

*   If you are unsure about any field, please ask for clarification.
*   If you need to add or remove fields, please contact the form administrator.
*   Remember to double-check all fields for accuracy before submitting the form.
