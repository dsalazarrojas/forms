# event_planning_payment_form - Help Guide
## Purpose
The event_planning_payment_form is used to collect payment and attendee information for events.

## How To Complete This Form
To complete this form, follow these steps:
1. Fill in the event details in the "Event Details" field.
2. Select "Yes" or "No" in the "Attendee Details" field to indicate whether the attendee is attending the event.
3. Enter the event date in the "Event Date" field.
4. Select "Yes" or "No" in the "Payment Details" field to indicate if the payment has been made.
5. Select "Yes" or "No" in the "Payment Method" field to choose the payment method.
6. Enter the payment amount in the "Payment Amount" field.
7. Enter the attendee's name in the "Attendee Name" field.
8. Enter the attendee's email in the "Attendee Email" field.
9. Enter the attendee's phone number in the "Attendee Phone" field.
10. Select the payment status in the "Payment Status" field.
11. Enter the total amount to be paid in the "Total Amount" field.
12. Enter a description of the event in the "Event Description" field (optional).
13. Enter the organizer's information in the "Organizer Information" field (optional).
14. Enter the event location in the "Event Location" field (optional).
15. Select the event start and end time in the "Event Date Time", "Event Start Time", "Event End Time" and "Attendee Start Time" and "Attendee End Time" fields (optional).

## Field-by-Field Explanation

* **Event Details** (`Event Details`, text, required): Enter the event details, such as event name, description, etc.
* **Attendee Details** (`Attendee Details`, select_multiple, required): Select "Yes" to indicate that the attendee is attending the event.
* **Event Date** (`Event Date`, date, required): Enter the date of the event.
* **Payment Details** (`Payment Details`, select_one, required): Select "Yes" to indicate if the payment has been made.
* **Payment Method** (`Payment Method`, select_one, required): Select "Yes" to choose the payment method.
* **Payment Amount** (`Payment Amount`, number, required): Enter the payment amount.
* **Attendee Name** (`Attendee Name`, text, required): Enter the attendee's name.
* **Attendee Email** (`Attendee Email`, email, required): Enter the attendee's email address.
* **Attendee Phone** (`Attendee Phone`, text, required): Enter the attendee's phone number.
* **Payment Status** (`Payment Status`, note, required): Select the payment status.
* **Total Amount** (`Total Amount`, number, required): Enter the total amount to be paid.
* **Event Description** (`Event Description`, text, optional): Enter a description of the event.
* **Organizer Information** (`Organizer Information`, text, optional): Enter the organizer's information.
* **Event Location** (`Event Location`, text, optional): Enter the event location.
* **Event Date Time** (`Event Date Time`, time, optional): Select the event date and time.
* **Event Start Time** (`Event Start Time`, time, optional): Select the event start time.
* **Event End Time** (`Event End Time`, time, optional): Select the event end time.
* **Attendee Start Time** (`Attendee Start Time`, time, optional): Select the attendee start time.
* **Attendee End Time** (`Attendee End Time`, time, optional): Select the attendee end time.

Note: Fields marked as "required" must be filled in. Fields marked as "optional" are not required but may be useful for providing additional information.
