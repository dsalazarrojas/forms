# parent-teacher-conference-time-off-form - Help Guide
## Purpose
This form is used to request time off for parent-teacher conferences, meetings, and other work-related events. Ensure that you are using this form for work-related reasons only.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the required information on each page.
2. Review the form before submission to ensure all information is accurate.

## Field-by-Field Explanation

* **Conference Date (Page 1)**: Enter the date of the conference or event you are attending.
* **Time Off Start Time (Page 1)**: Select the start time of your time off for the event.
* **Time Off End Time (Page 1)**: Select the end time of your time off for the event.
* **Duration (Page 1)**: Enter the number of hours or minutes you will be taking off for the event.
* **Reason (Page 1)**: Briefly describe the reason for your time off request.
* **Event Type (Page 1)**: Choose the type of event you are attending, such as Parent-Teacher Conference, Meeting, or Professional Development.
* **Comments (Page 1)**: Add any additional comments or notes about your time off request.
* **Email (Page 2)**: Enter your email address for communication purposes.
* **Phone (Page 2)**: Enter your phone number for communication purposes.
* **Event Location (Page 2)**: Enter the location of the event you are attending.
* **Event Description (Page 2)**: Briefly describe the event you are attending.
* **Assigned Tool (Page 2)**: Choose the tool assigned to you for the event, such as Chatjim or Other.
* **Output File (Page 2)**: This field is not applicable as it is not a required field.

Note: The event type options should only be selected for work-related events. If unsure, please refer to your supervisor or HR representative.
