# event_ticketing_portal_access_form - Help Guide
## Purpose
This form is designed to collect event registration information from event organizers and attendees. It helps to streamline the process of accessing the event ticketing portal.

## How To Complete This Form
To complete this form, follow these steps:
1. Provide event organizer information, including any relevant details about the event.
2. Enter event information, such as event date and time.
3. Select the ticket type and quantity required.
4. Enter contact details, including email and phone number (optional).
5. Add any additional notes or comments about the form submission.

## Field-by-Field Explanation

* **Event Organiser Information** (`event_organizer_info`, text, optional): Enter details about the event organizer, including their name, contact information, or any other relevant details.
* **Event Information** (`event_info`, text, optional): Provide a brief description of the event, including the event date, venue, or any other relevant details.
* **Attendee Information** (`attendee_info`, text, optional): Enter information about the attendees, including their name, contact details, or any other relevant information.
* **Ticket Type** (`ticket_type`, select_one, optional): Select the type of ticket required, such as "Ticket", "VIP", "Combo", or "Other".
* **Ticket Quantity** (`ticket_quantity`, number, optional): Enter the number of tickets required.
* **Ticket Price** (`ticket_price`, number, optional): Enter the price of the ticket.
* **Event Date** (`event_date`, date, optional): Select the date of the event.
* **Event Time** (`event_time`, time, optional): Select the time of the event.
* **Email** (`email`, email, optional): Enter the contact email address of the attendee or event organizer.
* **Phone** (`phone`, text, optional): Enter the phone number of the attendee or event organizer.
* **Note** (`note`, note, optional): Enter any additional notes or comments about the form submission.

## Tips
* Make sure to fill in all required fields to ensure a smooth form submission process.
* Use the "Ticket Type" field to select the correct type of ticket required.
* Use the "Ticket Quantity" field to enter the correct number of tickets required.
