# Participant Preamble Form - Help Guide
## Purpose
This form is used to collect basic information for event participants. Please fill out the form completely, and make sure to enter the correct details for each participant.

## How To Complete This Form
1. Fill out the form completely with accurate information about the participant.
2. Ensure that all required fields are filled out.
3. Review your entries carefully before submitting the form.

## Field-by-Field Explanation
* **Event Name** (id: 1, text, required): Enter the name of the event for which the participant is registering. This information will help us keep track of the event's identity.
* **Participant Name** (id: 2, text, required): Enter the participant's name. This will help us address the participant correctly.
* **E-Mail** (id: 3, email, required): Enter the participant's email address. This will be used for communication and verification purposes.
* **Phone** (id: 4, text, required): Enter the participant's contact phone number. This will help us reach out in case of any last-minute updates or changes.
* **Start Date** (id: 5, date, required): Enter the date the participant will start participating in the event. Please use the correct format (e.g., YYYY-MM-DD).
* **End Date** (id: 6, date, required): Enter the date the participant will end participating in the event. Please use the correct format (e.g., YYYY-MM-DD).
* **Start Time** (id: 7, time, required): Enter the time the participant will start participating in the event. Please use the correct 24-hour format (e.g., HH:MM).
* **End Time** (id: 8, time, required): Enter the time the participant will end participating in the event. Please use the correct 24-hour format (e.g., HH:MM).
* **Description** (id: 9, text, required): Enter a brief description of the participant's role or purpose in the event. This will help us understand their involvement.

## Tips
- Make sure to enter accurate and up-to-date information.
- Double-check that all required fields are filled out.
- In case of any doubts or issues, please contact us for assistance.
