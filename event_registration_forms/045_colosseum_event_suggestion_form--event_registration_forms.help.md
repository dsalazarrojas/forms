# Colosseum Event Suggestion Form - Help Guide
## Purpose
The Colosseum Event Suggestion Form is a tool for users to suggest new events to be hosted at the Colosseum. Filling out this form will help event organizers gather all necessary information to evaluate and potentially host the event.

## How To Complete This Form
To complete this form, simply follow these steps:
- Fill out each field with the required and optional information as prompted.
- Make sure to fill out all required fields (event title, event description, preferred date).

## Field-by-Field Explanation
### Your Name
* **Your name**: A field to enter your name for follow-up purposes.
### Contact Email
* **Contact email**: A field to enter your contact email address for follow-up communications.
### Event Title
* **Event title**: A short title for the suggested event, no more than a few words.
### Event Description
* **Event description**: A brief summary of the event format, including any details that might be helpful for event organizers.
### Preferred Date
* **Preferred date**: The date you would like the event to be held on. Please use the YYYY-MM-DD format (e.g., 2022-01-01).
### Target Audience
* **Target audience**: A brief description of who the event is intended for.
### Estimated Attendance
* **Estimated attendance**: An approximate number of people expected to attend the event.
### Resources Needed
* **Resources needed**: A list of any special equipment or staffing requirements for the event.
### Additional Comments
* **Additional comments**: Any other information you think might be helpful for event organizers to review your suggestion.
