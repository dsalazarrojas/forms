# exhibition_enquiry_form - Help Guide
## Purpose
This form is used for registering exhibitions, allowing users to provide information about an upcoming event.

## How To Complete This Form
1. Start by filling out the first page with the exhibition title and details.
2. On the second page, select the type of exhibition and any additional details, sponsors, or organizers involved.

## Field-by-Field Explanation
* **Exhibition Enquiry Form Page 1** (`exhibition_enquiry_form_page_1`, text, Required): 
This page is the main entry page, where users input basic exhibition information.
* **Exhibition Details** (`exhibition_enquiry_form_page_1_exhibition_details_label`, text, Required): 
Enter the title, date, and venue of the exhibition.
* **Exhibition Type** (`exhibition_enquiry_form_page_1_exhibition_type_label`, select_one, Required): 
Select 'Yes' if you are registering an exhibition or 'No' if not.
* **Exhibition Type Options** (`exhibition_enquiry_form_page_1_exhibition_type_options_label`, select_multiple, Optional): 
Select multiple options (if applicable) to provide more details about the type of exhibition.
* **Sponsorship Type** (`exhibition_enquiry_form_page_1_sponsorship_type_label`, select_one, Optional): 
Select 'Yes' if the exhibition is sponsored or 'No' if not.
* **Sponsorship Type Options** (`exhibition_enquiry_form_page_1_sponsorship_type_options_label`, select_multiple, Optional): 
Select multiple options (if applicable) to provide more details about the sponsorship.
* **Event Details** (`exhibition_enquiry_form_page_1_event_details_label`, text, Required): 
Provide any relevant details about the event that are not already covered on the first page.
* **Additional Notes** (`exhibition_enquiry_form_page_1_additional_notes_label`, text, Optional): 
Enter any additional information or comments.
* **Organizers** (`exhibition_enquiry_form_page_1_organizers_label`, select_multiple, Optional): 
Select multiple organizers (if applicable) to provide more details about the event organization.
* **Exhibition Enquiry Form Page 2** (`exhibition_enquiry_form_page_1`, text, Required): 
This page is the second page for the form where you can select and confirm the details entered in Page 1.
* **Yes** (`exhibition_enquiry_form_page_1_exhibition_type_options_label`, select_one, Optional): 
Select "Yes" if you are registering an event or "No" if not.
* **Yes** (`exhibition_enquiry_form_page_1_sponsorship_type_options_label`, select_one, Optional): 
Select "Yes" if the event is sponsored or "No" if not.
* **Yes** (`exhibition_enquiry_form_page_1_organizers_label`, select_multiple, Optional): 
Select "Yes" if the event is organized by multiple people or "No" if not.

## Tips
* Make sure to provide accurate and complete information to ensure that your exhibition is registered correctly.
* Check the form carefully before submitting to avoid any errors or misunderstandings.
