# Smart Lodging Technology Workshop Registration - Help Guide
## Purpose
This form is designed for attendees to register for the Smart Lodging Technology Workshop. It captures necessary information to facilitate the event's organization and management. Please note that you should only register once for the event, and you will receive a confirmation email with the event details.

## How To Complete This Form
To complete the form, follow these steps:
1. Fill out the required fields (indicated by an asterisk *).
2. Enter your name and email address in the corresponding fields.
3. Select your preferred session interests from the dropdown list.
4. Specify any special requirements or requests in the text field.
5. Enter your phone number and time zone information.
6. Choose your preferred output format and event category.
7. Specify any additional notes or comments.

## Field-by-Field Explanation

* **Event Title** (`event_title`, text, optional): This field is for the title of the event you are interested in attending. Enter the title to help us understand which event you are registering for.
* **Attendee Details** (`attendee_details`, text, optional): Enter your name and any other relevant details about yourself.
* **Session Interests** (`session_interests`, select_multiple, optional): Select all the sessions that interest you. You can choose multiple sessions by holding down the Ctrl key (PC) or Command key (Mac).
* **Special Requirements** (`special_requirements`, text, optional): If you have any special requirements or requests, please specify them here.
* **Phone Number** (`phone_number`, text, optional): Enter your phone number.
* **Email** (`email`, email, optional): Enter your email address.
* **Event Date** (`event_date`, date, optional): Enter the date of the event you are registering for.
* **Time** (`time`, time, optional): Enter the time of the event you are registering for.
* **Additional Notes** (`note`, note, optional): Enter any additional notes or comments about your registration.
* **Event Category** (`event_category`, select_one, optional): Choose the category of the event you are registering for (Workshop, Seminar, or Training).
* **Output Format** (`output_format`, select_one, optional): Choose the output format you prefer (PDF or HTML).
* **Output Filename** (`output_filename`, text, optional): Enter the filename for your output.
* **Output Path** (`output_path`, text, optional): Enter the path where you want to save your output.
* **Session Title** (`session_title`, text, optional): Enter the title of the session you are interested in.
* **Session Description** (`session_description`, text, optional): Enter a brief description of the session you are interested in.
* **Attendee List** (`attendee_list`, select_multiple, optional): Select whether you want to receive the attendee list.
* **File Size Limit** (`output_filesize_limit`, number, optional): Enter the file size limit you want to set.
* **Time Zone** (`timezone`, text, optional): Enter your time zone.
* **Time Zone Abbreviations** (`time_zone_abbreviations`, text, optional): Enter the time zone abbreviations.
* **Time Zone Offsets** (`time_zone_offset`, text, optional): Enter the time zone offsets.
* **Session Id** (`session_id`, select_one, optional): Choose the session ID from the dropdown list.
* **Event Id** (`event_id`, select_one, optional): Choose the event ID from the dropdown list.
* **Output Path Type** (`output_path_type`, select_one, optional): Choose the output path type (relative or absolute).
* **Output Path** (`output_path`, text, optional): Enter the output path.
* **Output Filename** (`output_filename`, text, optional): Enter the output filename.

Note: This help guide is based on the provided YAML fields and is intended to be a general guide for understanding the form. If you have any specific questions or need further clarification, please don't hesitate to ask.
