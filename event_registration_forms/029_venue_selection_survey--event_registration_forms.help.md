# venue_selection_survey - Help Guide
## Purpose
This form is designed to collect information about events, specifically regarding the selection of venues. It helps in planning and organization of events.

## How To Complete This Form
- Fill out the form carefully and make sure to fill in all the required fields.
- Select all options that apply to the event from the multiple-choice questions.
- Enter accurate information in the text fields.

## Field-by-Field Explanation
- **Venue Selection** (Yes/No): 
  Choose "Yes" if the event will be held at a venue, "No" otherwise.
  This field is used to determine if the event will be held at a venue.
  Required: No

- **Date of Event**:
  Enter the date of the event in the format "YYYY-MM-DD".
  This field is used to record the date of the event.
  Required: No

- **Start Time**:
  Enter the start time of the event in the format "HH:MM AM/PM".
  This field is used to record the start time of the event.
  Required: No

- **End Time**:
  Enter the end time of the event in the format "HH:MM AM/PM".
  This field is used to record the end time of the event.
  Required: No

- **Venue Name**:
  Enter the name of the venue where the event will be held.
  This field is used to record the name of the venue.
  Required: No

- **Venue Address**:
  Enter the address of the venue where the event will be held.
  This field is used to record the address of the venue.
  Required: No

- **Venue Capacity**:
  Enter the maximum capacity of the venue where the event will be held.
  This field is used to record the maximum capacity of the venue.
  Required: No

- **Venue Rating**:
  Enter the rating of the venue, if applicable.
  This field is used to record the rating of the venue.
  Required: No

## Tips
- Make sure to fill out all the fields accurately and completely.
- If a field is not applicable, select "No" or leave it blank.
- If you have any doubts, please contact the event organizer.
