# facility_setup_sign_off - Help Guide
## Purpose
The "facility_setup_sign_off" form is used to capture and manage facility-related information for administrative or operational purposes.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the **Project Manager Name** in the "Project Manager Name" field. This is the person responsible for overseeing the facility project.
2. Enter the **Coordinators' Name** in the "Coordinator Name" field. This is the person assisting the project manager.
3. Type the **Facility Location** in the "Facility Location" field.
4. Enter the **Date of Completion** by selecting the date when the facility is expected to be completed.
5. Select the **Time of Completion** by choosing the time of day when the facility is expected to be completed.
6. Choose the **Facility Setup Status** from the dropdown options: "Completed", "Pending", or "Not Started".
7. Add any additional **Comments** about the facility setup process in the "Comments" field.
8. Enter the **Email** of the person responsible for the facility setup, if applicable.
9. Finally, enter the **Phone** number of the person responsible for the facility setup, if applicable.

## Field-by-Field Explanation
* **Project Manager Name**: Enter the name of the person responsible for overseeing the facility project.
* **Coordinator Name**: Enter the name of the person assisting the project manager.
* **Facility Location**: Type the location of the facility.
* **Date of Completion**: Enter the date when the facility is expected to be completed.
* **Time of Completion**: Select the time of day when the facility is expected to be completed.
* **Facility Setup Status**: Choose the status of the facility setup: "Completed", "Pending", or "Not Started".
* **Comments**: Add any additional comments about the facility setup process.
* **Email**: Enter the email of the person responsible for the facility setup, if applicable.
* **Phone**: Enter the phone number of the person responsible for the facility setup, if applicable.
