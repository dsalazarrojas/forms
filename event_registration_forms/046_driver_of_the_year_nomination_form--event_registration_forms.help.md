# prophets_of_the_year_nomination_form - Help Guide
## Purpose
This form is used to collect information for the Prophets of the Year nomination event.

## How To Complete This Form
1.  To complete this form, fill out each field with the requested information.
2.  Please ensure that all required fields are filled out accurately.
3.  If you have any questions or need further clarification, use the contact number or email address provided.

## Field-by-Field Explanation
*   **First Name** (1): The first name of the individual being nominated.
    *   Type: text
    *   Required: yes
*   **Last Name** (2): The last name of the individual being nominated.
    *   Type: text
    *   Required: yes
*   **Contact Number** (3): The contact number of the individual being nominated.
    *   Type: text
    *   Required: yes
*   **Email Address** (4): The email address of the individual being nominated.
    *   Type: email
    *   Required: yes
*   **Event Location** (5): The location where the event took place.
    *   Type: text
    *   Required: yes
*   **Event Date** (6): The date of the event.
    *   Type: date
    *   Required: yes
*   **Event Time** (7): The time of the event.
    *   Type: time
    *   Required: yes
*   **Event Type** (8): The type of event (Event, Meeting, or Workshop).
    *   Type: select_one
    *   Required: yes
*   **Event Organizer** (9): The name of the event organizer or individual responsible for the event.
    *   Type: text
    *   Required: yes
*   **Event Description** (10): A brief description of the event.
    *   Type: text
    *   Required: yes
*   **Submission** (11): Enter your comments or any additional information about the nomination.
    *   Type: text
    *   Required: yes

## Tips
*   Please ensure that all required fields are filled out accurately and completely.
*   If you have any questions or need further clarification, use the contact number or email address provided.
*   Enter your comments or additional information regarding the nomination in the "submission" field.
