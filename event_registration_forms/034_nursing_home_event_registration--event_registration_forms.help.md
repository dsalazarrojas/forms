# Nursing Home Event Registration - Help Guide

## Purpose

This guide helps you understand the purpose and requirements of the Nursing Home Event Registration form, ensuring you fill it out correctly and accurately.

## How To Complete This Form

To complete this form, please follow these steps:

1. Enter the resident's name in the "Resident Name" field.
2. Enter the guest's name in the "Guest Name" field.
3. Choose the correct relationship between the resident and the guest in the "Relationship" field.
4. Select the event date in the "Event Date" field.
5. Choose the event time in the "Event Time" field.
6. Enter the event location in the "Event Location" field.
7. Enter the number of guests attending in the "Number of Guests" field.
8. Choose the type of event from the "Event Type" field.
9. Select the correct dietary restrictions, if any, in the "Dietary Restrictions" field.
10. If applicable, enter any special requests in the "Special Requests" field.
11. Enter the emergency contact information in the "Emergency Contact" field.
12. Enter any additional event notes in the "Event Notes" field.
13. If applicable, select the event start and end times in the "Event Start Time" and "Event End Time" fields, respectively.
14. If applicable, enter the event duration in the "Event Duration" field.
15. Select the event fees, if applicable, in the "Event Fees" field.
16. Enter any other fee, if applicable, in the "Other Fee" field.
17. Select the currency of the event fees, if applicable, in the "Event Fees Currency" field.
18. Enter the billing information, if applicable, in the "Billing Info" field.
19. Select the payment method in the "Payment Method" field.
20. Enter any payment details, if applicable, in the "Payment Details" field.
21. Enter your signature, as the resident, in the "Resident Signature" field.
22. Enter your signature, as a guest, in the "Guest Signature" field.
23. Finally, indicate if the event was attended in the "Event Attended" field.

## Field-by-Field Explanation

* **Resident Name** (`resident_name`, text, required): Enter the name of the resident.
* **Guest Name** (`guest_name`, text, required): Enter the name of the guest.
* **Contact Person** (`contact_person`, text, optional): Enter a contact person for the resident or guest.
* **Relationship** (`relationship`, select_one, required): Choose the relationship between the resident and the guest.
* **Event Date** (`event_date`, date, optional): Select the date of the event.
* **Event Time** (`event_time`, time, optional): Select the time of the event.
* **Event Location** (`event_location`, text, required): Enter the location of the event.
* **Number of Guests** (`number_of_guests`, number, required): Enter the number of guests attending the event.
* **Event Type** (`event_type`, select_one, required): Choose the type of event.
* **Dietary Restrictions** (`dietary_restrictions`, text, optional): Enter any dietary restrictions.
* **Special Requests** (`special_requests`, note, optional): Enter any special requests.
* **Emergency Contact** (`emergency_contact`, text, optional): Enter the emergency contact information.
* **Event Notes** (`event_notes`, text, optional): Enter any additional event notes.
* **Event Start Time** (`event_start_time`, time, optional): Select the start time of the event.
* **Event End Time** (`event_end_time`, time, optional): Select the end time of the event.
* **Event Duration** (`event_duration`, number, optional): Enter the duration of the event.
* **Event Fees** (`event_fees`, select_multiple, optional): Select the event fees, if applicable.
* **Other Fee** (`event_fees_other`, text, optional): Enter any other event fee.
* **Event Fees Currency** (`event_fees_currency`, select_one, optional): Select the currency of the event fees.
* **Billing Info** (`billing_info`, text, optional): Enter the billing information.
* **Payment Method** (`payment_method`, select_one, required): Select the payment method.
* **Payment Details** (`payment_details`, text, optional): Enter any payment details.
* **Resident Signature** (`resident_signature`, text, required): Enter your signature as the resident.
* **Guest Signature** (`guest_signature`, text, required): Enter your signature as a guest.
* **Event Attended** (`event_attended`, select_one, required): Indicate if the event was attended.
