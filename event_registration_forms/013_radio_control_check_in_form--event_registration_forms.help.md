# radio_control_check_in_form - Help Guide
## Purpose
This form is designed to collect basic participant information and check-in time for event registrations or participations.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the participant's information:
	* Enter the participant's name in the `participant_name` field.
	* Enter the participant's email address in the `participant_email` field.
2. Check-in time:
	* Select the check-in time from the available options, or enter a custom time.

## Field-by-Field Explanation

* **Participant Info** (`participant_info`, text, optional): Enter any additional information about the participant, if necessary.
* **Participant Name** (`participant_name`, text, optional): Enter the name of the participant who is checking in.
* **Participant Email** (`participant_email`, email, optional): Enter the email address associated with the participant.
* **Check-in Time** (`check_in_time`, time, optional): Select the time when the participant is checking in, or enter a custom time if available.

## Tips

* Make sure to enter the participant's name and email correctly to ensure accurate contact information.
* If you need to add any additional participant information, use the `participant_info` field.
* Check-in time is optional, but it can be helpful for event organizers to track participant arrival and departure times.
