# Event Space Rental Payment Form - Help Guide
## Purpose
The Event Space Rental Payment Form is used to register events and rent event spaces for the duration of the event.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the **Event details** field with a brief description of the event.
2. Select **Event space** as either "Yes" or "No" to indicate if the event requires a rented event space.
3. Choose the **Payment method** by selecting one or more of the available options (credit card or bank transfer).
4. Enter the **Payment amount** for the event space rental.
5. Select the start and end dates for the **Event start date** and **Event end date**.
6. Choose the start and end times for the **Event start time** and **Event end time**.
7. Select the **Payment status** for the event, either "paid" or "pending".

## Field-by-Field Explanation
* **Event details**: A brief description of the event (text, required)
* **Event space**: A checkbox to indicate if the event requires a rented event space (select_one, required)
* **Payment method**: A selection of payment methods (credit card or bank transfer, select_multiple, required)
* **Payment amount**: The amount to be paid for the event space rental (number, required)
* **Event start date**: The start date of the event (date, required)
* **Event end date**: The end date of the event (date, required)
* **Event start time**: The start time of the event (time, required)
* **Event end time**: The end time of the event (time, required)
* **Payment status**: The current status of the payment (select_multiple, required, options: paid, pending)

## Tips
* Make sure to fill in all required fields to ensure successful form submission.
* Review your selections carefully to ensure accuracy and completeness.
