# Student Conference Time Preference Form - Help Guide
## Purpose

This form is designed to collect information about your availability and preferences for a student conference event. This will help us understand your schedule and language requirements to provide the best possible experience for you.

## How To Complete This Form

To complete this form, follow these steps:

1. Select the start time for the event from the available options.
2. Choose the end time for the event from the available options.
3. Select your preferred language for the event (if applicable).
4. Choose which languages you require for the event (if applicable).
5. Select which time slots are available for you during the event (if applicable).
6. If you have any specific schedule preferences, please describe them in the notes section.
7. Repeat step 6 multiple times to list all your schedule preferences.
