# New Student Welcome Event Registration - Help Guide
## Purpose
This form is designed to collect information from new students to help us tailor the welcome event to their needs and interests.

## How To Complete This Form
1. Fill out the form carefully, providing accurate and truthful information.
2. Ensure all required fields are completed.
3. Review your answers before submitting the form.

## Field-by-Field Explanation
- **New Student Information** (1): Please enter your name and any other identifying details you'd like us to know.
- **Event Details** (2): Briefly describe the event you are interested in attending or any specific activities you are interested in.
- **Student Programming Language** (3): Indicate if you have prior knowledge of programming languages.
  - Select 'Yes' if you have experience with programming languages.
  - Select 'No' if you are new to programming languages.
- **Student Interests** (4): Select all the areas that you are interested in, such as 'Yes' or 'No', to help us tailor the event to your preferences.
- **Email** (5): Enter your email address so we can contact you with event information.
- **Phone** (6): Enter your phone number so we can contact you in case of event changes or last-minute updates.
- **Student Programming Experience** (7): If you have experience with programming, please specify the number of years you've been programming.
- **Student Event Contribution** (8): Please indicate how much time you are willing to spend on the event, if any. This will help us plan the event schedule accordingly.

## Tips
- Be honest when answering the fields, as this information will help us tailor the event to your needs.
- If you are unsure about any field, please reach out to the event organizers for clarification.
- Please review your answers carefully before submitting the form to ensure accuracy.
