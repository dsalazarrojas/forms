# Press Table Allocation Request Form - Help Guide
## Purpose
The Press Table Allocation Request Form is designed to facilitate the allocation of press tables for events. This form is used to collect information from event organizers and public relations teams to request press table allocations for their events.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the required fields (marked as "required") with the requested information.
2. Select the correct options for the "Media Type" and "Event Type" fields.
3. Enter a valid email address and phone number in the "Email" and "Phone" fields, respectively.
4. Enter a brief description of the event in the "Event Description" field.
5. Add any additional notes or comments in the "Additional Notes" field.

## Field-by-Field Explanation
* **Press Table Allocation Request**: A text field for entering a brief description of the press table allocation request.
* **Event Name**: The name of the event, which is used to identify the event for which the press table allocation is being requested.
* **Media Type**: Select the type of media that will be attending the event from the dropdown list:
	+ **Press Kit**: A press kit is a package of media materials provided by the event organizer.
	+ **Press Kit with Photo Op**: A press kit with photo opportunities.
	+ **Press Kit with Video Prophets**: A press kit with video opportunities.
* **Quantity of Media**: Enter the number of media expected to attend the event.
* **Table Number**: Enter the number of tables allocated for the press.
* **Seating Requirements**: Enter any special seating requirements for the media.
* **Contact Name**: The name of the contact person for the event.
* **Email**: A valid email address for the contact person.
* **Phone**: A valid phone number for the contact person.
* **Company**: Enter the company associated with the media.
* **Event Date**: Enter the date of the event.
* **Event Start Time**: Enter the start time of the event.
* **Event End Time**: Enter the end time of the event.
* **Event Venue**: Enter the location of the event.
* **Event Type**: Select the type of event from the dropdown list:
	+ **Conference**
	+ **Seminar**
	+ **Workshop**
* **Event Status**: Select the status of the event from the dropdown list:
	+ **Open**
	+ **Closed**
	+ **Private**
* **Contact Phone**: A valid phone number for the contact person.
* **Contact Email**: A valid email address for the contact person.
* **Event Description**: A brief description of the event.
* **Additional Notes**: Add any additional comments or notes about the event.
* **Event Status Note**: Add any additional comments or notes about the event status.
* **Table Allocation Status**: Select the status of the table allocation from the dropdown list:
	+ **Allocated**
	+ **Unallocated**
	+ **Preliminary Approved**
	+ **Approved**
	+ **Rejected**
* **Allocation Note**: Add any additional comments or notes about the table allocation status.

* **Allocation Note**: (Note: This field is identical to "Event Status Note" and "Allocation Note".)
