# room_count_survey - Help Guide
## Purpose
The "room_count_survey" form is designed to gather information about an event, including the type, size, and room requirements, to help event planners and venue management make informed decisions.

## How To Complete This Form
To fill out this form, follow these steps:

1.  Select the type of event by choosing from the given options (Conference, Meeting, Wedding, or Other).
2.  Enter the number of attendees attending the event.
3.  Choose the type of room that will be used for the event from the provided options (Large Meeting Room, Small Meeting Room, Breakout Room, or Other).
4.  Enter the number of rooms available at the venue.
5.  Enter the number of rooms planned to be used for the event.
6.  Enter the maximum capacity of the main event room.
7.  If applicable, select any other rooms that need to be reserved.
8.  Finally, provide any special requests or details that the venue needs to know about this event.

## Field-by-Field Explanation
*   **What type of event is this?** (`<event_type>`, select_one): This field is used to determine the nature of the event. Choose the correct option that best describes the event type.
*   **How many attendees are attending the event?** (`<event_size>`, number): Enter the number of people attending the event.
*   **What type of room will be used for the event?** (`<room_type>`, select_multiple): Select all applicable room types that will be used for the event.
*   **How many rooms are available at the venue?** (`<room_availability>`, number): Enter the total number of rooms available at the venue.
*   **How many rooms are you planning to use?** (`<room_usage>`, number): Enter the number of rooms planned to be used for the event.
*   **What is the maximum capacity of the main event room?** (`<room_capacity>`, number): Enter the maximum capacity of the main event room.
*   **Are there any other rooms that need to be reserved?** (`<other_rooms>`, select_multiple): If other rooms are required, select the relevant options.
*   **Is there anything special the venue needs to know about this event?** (`<special_requests>`, note): Use this field to provide any unique details or requests that the venue needs to be aware of.
