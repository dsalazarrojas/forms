# events_hospitality_consultation_form - Help Guide
## Purpose
The events_hospitality_consultation_form is designed to collect information about events, including services required, dates, start and end times, location, and additional notes, to aid in the planning and execution of events with hospitality consultations.

## How To Complete This Form
To complete this form, please follow these steps:

1. Ensure you have all the required information about the event before starting.
2. Scroll through the form pages to select the relevant services required for the event.
3. Enter the dates of the event, including the start and end times.
4. Provide the location of the event.
5. Add any additional notes about the event.

## Field-by-Field Explanation
### Page 1: Event Details
* **Event Details** (`event_details`, `note`, not required): This is a free-text field where you can enter any information about the event.
### Page 2: Services
* **Services** (`services`, `select_multiple`, required): Select all the services that will be required for the event. This field allows you to choose multiple services from the options provided.
### Page 3: Event Dates
* **Event Dates** (`event_dates`, `date`, not required): Enter the dates of the event.
### Page 4: Event Start Time
* **Event Start Time** (`event_start_time`, `time`, not required): Enter the start time of the event.
### Page 5: Event End Time
* **Event End Time** (`event_end_time`, `time`, not required): Enter the end time of the event.
### Page 6: Event Location
* **Event Location** (`event_location`, `text`, not required): Enter the location of the event.
### Page 7: Event Notes
* **Event Notes** (`event_notes`, `text`, not required): Add any additional notes about the event. 

## Tips
* Ensure you fill out all required fields to avoid errors when submitting the form.
* If you have any further questions or concerns, please reach out to the form administrators at form@gic.mx.
