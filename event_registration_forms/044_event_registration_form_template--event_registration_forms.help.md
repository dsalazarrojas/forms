# Event Registration Form Template - Help Guide

## Purpose

This form is designed to collect information about events that can be used for various purposes such as event management, tracking, and reporting. It's essential to provide accurate and relevant data to ensure effective event handling.

## How To Complete This Form

To complete this form, follow the instructions below:

1. **Fill in the event details**: Enter the title and description of the event, including the start and end dates and times. This will help you track and schedule events accurately.
2. **Add event location and contact information**: Provide the event location, contact name, email, phone number, and address. This will help ensure that attendees can reach out to you for any questions or concerns.
3. **Specify event category and tags**: Select the relevant event category and add any additional tags that describe the event. This will help with event filtering and searching.
4. **Choose event status and registrants**: Choose whether the event is active or not, and indicate if there are registrants. This will help with event visibility and planning.
5. **Add event notes and assigned tool**: Provide any additional notes or comments about the event, and specify the assigned tool or platform. This will help with event tracking and management.
6. **Review and submit**: Once you've filled in all the necessary information, review the form to ensure that everything is accurate and complete. Then, submit the form to save your event details.

## Field-by-Field Explanation

### Event Registration Form

* **Event Name** (`event_name`): Enter the name of the event, e.g., "Company Conference 2023".
* **Event Description** (`event_description`): Briefly describe the event, e.g., "Annual company conference for employees and partners."
* **Event Start Date** (`event_start_date`): Enter the start date of the event in the format `YYYY-MM-DD`.
* **Event End Date** (`event_end_date`): Enter the end date of the event in the format `YYYY-MM-DD`.
* **Event Start Time** (`event_start_time`): Enter the start time of the event in the format `HH:MM AM/PM`.
* **Event Location** (`event_location`): Enter the location of the event, e.g., "123 Main St, New York, NY".
* **Event Description** (`event_description`): Briefly describe the event again.
* **Registrants** (`registrants`): Choose whether there are registrants for the event (`Yes`, `No`, or `Other`).
* **Event Status** (`event_status`): Choose the status of the event (`Yes`, `No`, or `Other`).
* **Contact Name** (`contact_name`): Enter your name and contact information for the event.
* **Contact Email** (`contact_email`): Enter your email address for event inquiries.
* **Contact Phone** (`contact_phone`): Enter your phone number for event inquiries.
* **Contact Address** (`contact_address`): Enter your physical address for event inquiries.
* **Event Category** (`event_category`): Select the relevant category for the event, e.g., "Conference".
* **Event Venue** (`event_venue`): Enter the venue name and address if different from the contact address.
* **Event Tags** (`event_tags`): Add any additional tags that describe the event, e.g., "Marketing, Sales, and Product Management".
* **Event Notes** (`event_notes`): Add any additional comments or notes about the event.
* **Assigned Tool** (`assigned_tool`): Specify the tool or platform assigned for the event.
* **Event Type** (`event_type`): Enter the type of event, e.g., "Conference", "Webinar".
* **Event Priority** (`event_priority`): Choose the event priority level (`Number` value).
* **Event Status 2** (`event_status_2`): Choose the status of the event, e.g., "Active", "Inactive".
* **Event Tags 2** (`event_tags_2`): Add any additional tags that describe the event.
* **Event Description 2** (`event_description_2`): Briefly describe the event again.
* **Event Location 2** (`event_location_2`): Enter the location of the event.
* **Event Start Time 2** (`event_start_time_2`): Enter the start time of the event in the format `HH:MM AM/PM`.
