# Special Event Permit Request Form - Help Guide
## Purpose
This form is used to request a special event permit for an event. The purpose of this form is to gather necessary information from the event organizer to process and approve the permit.

## How To Complete This Form
1. Fill out the form with accurate and complete information about the event.
2. Review each field carefully to ensure all necessary information is provided.
3. If a field is marked as optional, fill it out if it pertains to the event.
4. Submit the form to the relevant authorities for processing and approval.

## Field-by-Field Explanation

* **Event Info (event_info)**: A brief description of the event.
* **Contact Info (contact_info)**: The contact information of the event organizer.
* **Event Location (event_location)**: The location where the event will take place.
* **Event Date (event_date)**: The date of the event.
* **Event Time (event_time)**: The start time of the event.
* **Event End Time (event_time_end)**: The end time of the event.
* **Event Duration (event_duration)**: The length of the event in hours or minutes.
* **Event Organizer (event_organizer)**: The person or organization responsible for the event.
* **Event Organizer Email (event_organizer_email)**: The email address of the event organizer.
* **Event Organizer Phone (event_organizer_phone)**: The phone number of the event organizer.
* **Event Location Address (event_location_address)**: The address of the event location.
* **Event Location City (event_location_city)**: The city where the event will take place.
* **Event Location State (event_location_state)**: The state where the event will take place.
* **Event Location Zip (event_location_zip)**: The zip code of the event location.
* **Event Location Country (event_location_country)**: The country where the event will take place.
* **Additional Info (additional_info)**: Any additional information about the event.
* **Permit Type (permit_type)**: The type of permit being requested (e.g., Special Event, Festival, Parade, Fair, etc.).
* **Permit Type Other (permit_type_other)**: If the permit type is not listed, describe the other type of permit.
* **Payment Info (payment_info)**: Information about the payment method and amount.
* **Payment Method (payment_method)**: The method of payment (e.g., Bank, Credit, Check, etc.).
* **Payment Method Other (payment_method_other)**: If the payment method is not listed, describe the other method.
* **Submitter Name (submitter_name)**: The name of the person submitting the form.
* **Submitter Contact Info (submitter_contact_info)**: Contact information of the person submitting the form.
* **Submitter Email (submitter_email)**: The email address of the person submitting the form.
* **Submitter Phone (submitter_phone)**: The phone number of the person submitting the form.

Note: This form requires the following fields to be filled out: event_info, contact_info, event_location, event_date, event_time, event_time_end, event_duration, event_organizer, event_organizer_email, event_organizer_phone, event_location_address, event_location_city, event_location_state, event_location_zip, event_location_country, and permit_type.
