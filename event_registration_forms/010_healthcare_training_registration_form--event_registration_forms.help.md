# Healthcare Training Registration Form - Help Guide
## Purpose
This form is used for registering participants in a healthcare training program.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the participant information section, including the participant's name, contact number, and email address.
2. Select the participant type and program type from the respective dropdown menus.
3. Choose the payment option and payment method from the respective dropdown menus.
4. Select the participant status and program status from the respective dropdown menus.
5. Enter the start and end dates for the participant and program.
6. Review and submit the form.

## Field-by-Field Explanation
* **Participant Information**: This section collects the basic contact details of the participant, including their name, contact number, and email address.
* **Contact Number**: Enter the participant's contact number.
* **Email Address**: Enter the participant's email address.
* **Phone Number**: Enter the participant's phone number.
* **Payment Details**: Enter the payment details, if applicable.
* **Participant Type**: Select the type of participant from the dropdown menu.
* **Payment Option**: Select the payment option from the dropdown menu.
* **Participant Status**: Select the participant's status from the dropdown menu.
* **Start Date**: Enter the start date of the participant's program.
* **End Date**: Enter the end date of the participant's program.
* **Participant Name**: Enter the participant's name.
* **Payment Method**: Select the payment method from the dropdown menu.
* **Participant Program**: Select the participant's program from the dropdown menu.
* **Participant Program Status**: Select the participant's program status from the dropdown menu.
* **Participant Payment Status**: Select the participant's payment status from the dropdown menu.
* **Participant Type Status**: Select the participant's type status from the dropdown menu.
* **Participant Program Type**: Select the participant's program type from the dropdown menu.
* **Participant Start Date**: Enter the start date of the participant's program.
* **Participant End Date**: Enter the end date of the participant's program.
* **Participant Program Status Date**: Enter the status date of the participant's program.
* **Participant Program Payment Status Date**: Enter the payment status date of the participant's program.
* **Participant Program Participant Status**: Select the participant's program participant status from the dropdown menu.
* **Participant Type Participant Status**: Select the participant's type participant status from the dropdown menu.
* **Participant Status Payment Status**: Select the participant's status payment status from the dropdown menu.
