# Calendar Reception Confirmation Form - Help Guide

## Purpose

This form is used to confirm your attendance and details for an event. Please fill out this form to help us prepare for the event and ensure that we can accommodate your needs.

## How To Complete This Form

1.  Fill out the form carefully and honestly.
2.  Make sure to complete all required fields.
3.  Review your answers carefully before submitting.

## Field-by-Field Explanation

* **Your Name** (Guest Name, text, required): Enter your full name as you would like to be addressed.
* **Email Address** (Email Address, email, required): Enter your email address where we can contact you for event updates and confirmations.
* **Phone Number** (Phone Number, text, required): Enter your contact phone number in case we need to reach you.
* **Event Name** (Event Name, text, required): Enter the name of the event you will be attending.
* **Event Date** (Event Date, date, required): Enter the date of the event.
* **Event Time** (Event Time, time, required): Enter the time of the event.
* **Attendance Status** (Attendance Status, select_one, required): Select your status:
	+ Yes, definitely attending
	+ Probably attending
	+ Not sure yet
	+ Probably not attending
	+ No, cannot attend
* **Number of Guests** (Number of Guests, number, optional): Enter the total number of guests attending with you.
* **Guest Names** (Guest Names, text, optional): Enter the names of additional guests attending with you.
* **Dietary Requirements** (Dietary Requirements, text, optional): If you have any food restrictions or allergies, please mention them here.
* **Meal Preference** (Meal Preference, select_one, optional):
	+ No preference
	+ Beef
	+ Chicken
	+ Fish
	+ Vegetarian
	+ Vegan
	+ Gluten-free
* **Beverage Preference** (Beverage Preference, select_one, optional):
	+ No preference
	+ Wine
	+ Beer
	+ Soft drinks
	+ Water
	+ Coffee or tea
* **Accessibility Needs** (Accessibility Needs, text, optional): If you need any special accommodations, please let us know.
* **Transportation Needed** (Transportation Needed, select_one, optional):
	+ False
	+ Yes, need information
	+ Yes, need arrangement
* **Parking Needed** (Parking Needed, select_one, optional):
	+ True
	+ False
* **Hotel Accommodation Needed** (Hotel Accommodation Needed, select_one, optional):
	+ False
	+ Yes, please send information
	+ Yes, need booking assistance
* **Special Requests** (Special Requests, text, optional): If you have any special requests or notes, please mention them here.
* **How Did You Hear** (How Did You Hear About This Event, select_one, optional):
	+ Invitation
	+ Email
	+ Social media
	+ Website
	+ Friend or colleague
	+ Other
* **Looking Forward To** (Looking Forward To, text, optional): Let us know what you are most excited about.
* **Additional Comments** (Additional Comments, text, optional): Any other information you would like to share with us.

Note: All required fields are marked with an asterisk (\*). Please make sure to complete them accurately and carefully.
