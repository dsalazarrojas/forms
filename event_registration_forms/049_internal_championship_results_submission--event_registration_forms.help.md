# Internal Championship Results Submission - Help Guide
## Purpose
This form is used to submit internal championship results, including event details, champion information, and submission status.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the event details, such as event name and date.
2. Select the champion of the event from the options provided.
3. Choose the competition type from the options provided.
4. Enter any additional notes or comments about the event.
5. Choose the submission status, either Pending, Approved, or Denied.

## Field-by-Field Explanation
* **Event Details** (Event Details, text, required: false): Enter a brief description of the event, including event name and date.
* **Champion** (Champion, select_one, required: false): Select the champion of the event from the options provided.
* **Event Name** (Event Name, text, required: false): Enter the name of the event.
* **Event Date** (Event Date, date, required: false): Enter the date of the event in the format MM/DD/YY.
* **Event Time** (Event Time, time, required: false): Enter the time of the event in the format HH:MM AM/PM.
* **Competition Name** (Competition Name, text, required: false): Enter the name of the competition.
* **Competition Type** (Competition Type, select_multiple, required: false): Choose one or multiple competition types from the options provided.
* **Judge Score** (Judge Score, number, required: false): Enter the score given by a judge, if applicable.
* **Score Sheet** (Score Sheet, text, required: false): Enter any additional score sheet information, if applicable.
* **Notes** (Notes, text, required: false): Enter any additional notes or comments about the event.
* **Submission Status** (Submission Status, select_one, required: false): Choose the submission status, either Pending, Approved, or Denied.
