# Rooftop Event Registration Form - Help Guide
## Purpose
The Rooftop Event Registration Form is designed to collect event-specific information and event organizer's contact details.

## How To Complete This Form
1. Fill in the event organizer's contact information in sections 1-5.
2. Enter the event specifics in sections 6-25.

## Field-by-Field Explanation
* **Event Organizer** (Text, required: false): This field is for the event organizer's name.
* **Event Name** (Text, required: false): Enter a brief description of the event.
* **Start Date** (Date, required: false): Select the date the event starts.
* **End Date** (Text, required: false): Enter the end date of the event.
* **Event Location** (Text, required: false): Describe the location of the event.
* **Event Description** (Text, required: false): Provide a detailed description of the event.
* **Event Organizer Email** (Email, required: false): Enter the event organizer's email address.
* **Event Organizer Phone** (Text, required: false): Enter the event organizer's phone number.
* **Event Organizer Organization** (Text, required: false): Mention the event organizer's organization or company.
* **Event Organizer Job Title** (Text, required: false): Enter the event organizer's job title.
* **Start Time** (Time, required: false): Select the time the event begins.
* **End Time** (Time, required: false): Choose the time the event ends.
* **Attendees** (Select multiple, required: false): Choose if attendees will attend or not.
* **Attendee Name** (Text, required: false): Enter the attendee's name.
* **Attendee Email** (Email, required: false): Enter the attendee's email address.
* **Attendee Phone** (Text, required: false): Enter the attendee's phone number.
* **Attendee Organization** (Text, required: false): Enter the attendee's organization or company.
* **Attendee Job Title** (Text, required: false): Enter the attendee's job title.
* **Event Type** (Select one, required: false): Choose the event type (e.g., registration, exhibition, conference, workshop, festival, or meeting).
* **Venue** (Text, required: false): Describe the venue.
* **Address** (Text, required: false): Enter the address.
* **City** (Text, required: false): Enter the city.
* **State** (Text, required: false): Enter the state or region.
* **Zip** (Text, required: false): Enter the zip code.
* **Notes** (Note, required: false): Enter any additional notes about the event.
