# Language School Education Expo Lead Generation Form - Help Guide
## Purpose
This form is used to collect information about a Language School Education Expo lead generation event. It helps us gather details about the event, its status, and contact information.

## How To Complete This Form
To complete this form, simply follow these steps:
1. Select the type of event from the provided options.
2. Enter the name of the person in charge of the event (if applicable).
3. Fill in the event name (if applicable).
4. Choose a date for the event.
5. Select the time of the event.
6. Choose whether the event is located indoors or outdoors (if applicable).
7. Enter the contact email (if applicable).
8. Enter the contact phone number (if applicable).
9. Add any additional notes about the event.
10. Choose the status of the event (active or inactive).
11. If the event type is not in the provided options, enter it in the "Other Event Type" field.
12. Enter any additional details about the event.
13. Enter the website of the event (if applicable).
14. Enter the Facebook event link (if applicable).
15. Enter the Twitter event link (if applicable).
16. Enter the Instagram event link (if applicable).
17. Enter the LinkedIn event link (if applicable).
18. Enter the YouTube event link (if applicable).

## Field-by-Field Explanation

* **Event Type**: Select whether this is a real event or not. Choose one of the provided options.
* **Contact Person**: Enter the name of the person in charge of the event, if applicable. This field is optional.
* **Event Name**: Enter the name of the event, if applicable. This field is optional.
* **Event Date**: Enter the date of the event in the format MM/DD/YY or DD/MM/YY.
* **Event Time**: Enter the time of the event in the format 12:00 AM or 12:00 PM.
* **Event Location**: Choose whether the event is located indoors or outdoors, if applicable.
* **Email**: Enter the email of the person in charge of the event, if applicable. This field is optional.
* **Phone**: Enter the contact phone number, if applicable. This field is optional.
* **Notes**: Add any additional notes or comments about the event.
* **Event Status**: Choose the status of the event as active or inactive.
* **Other Event Type**: If the event type is not in the provided options, enter it here.
* **Event Details**: Enter any additional details about the event.
* **Event Website**: Enter the website of the event, if applicable.
* **Facebook Event**: Enter the Facebook event link, if applicable.
* **Twitter Event**: Enter the Twitter event link, if applicable.
* **Instagram Event**: Enter the Instagram event link, if applicable.
* **LinkedIn Event**: Enter the LinkedIn event link, if applicable.
* **YouTube Event**: Enter the YouTube event link, if applicable.

## Tips

* Make sure to fill in all required fields.
* Double-check your event type to ensure it matches the actual event.
* If you're unsure about any field, leave it out or contact us for clarification.
* This form will help us keep track of events and provide better services to you.
