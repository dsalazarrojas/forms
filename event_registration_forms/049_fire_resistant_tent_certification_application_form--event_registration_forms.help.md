# Fire Resistant Tent Certification Application Form - Help Guide
## Purpose

This form is for collecting and verifying Fire Resistant Tent (FRT) certification data.

## How To Complete This Form

1. Please select all applicable event registration forms (e.g., "Yes" for forms that are applicable).
2. Enter the unique ID assigned to this form.
3. Provide a brief description of the FRT.
4. Choose the category that best fits this FRT.
5. Indicate whether the FRT has undergone fire resistance tests (e.g., "Yes" for tests that were conducted).
6. Select the certification status of the FRT (e.g., "certified" for a certified FRT, "not certified" for one that is not, or "pending" for one that is still being reviewed).
7. Choose the date the FRT was certified (if applicable).
8. Fill in the certification date in the correct format (DD/MM/YYYY).

## Field-by-Field Explanation

* **Event Registration Forms**: 
  * Type: Select Multiple
  * Description: Indicate which event registration forms that this FRT is applicable to.
  * Example: "Yes" for forms that apply, "No" otherwise.
* **Form IDs**: 
  * Type: Number
  * Description: Enter the unique ID assigned to this form.
  * Note: This field is used for identification purposes.
* **Assigned Tool**: 
  * Type: Text
  * Description: Enter the tool assigned to this FRT.
  * Note: This field can be left empty if no tool is assigned.
* **Description**: 
  * Type: Text
  * Description: Enter a brief description of the FRT.
  * Note: This can be a brief text explaining the purpose or features of the FRT.
* **Category**: 
  * Type: Select One
  * Description: Choose the category that best fits this FRT.
  * Example: Select from the options provided (e.g., category1, category2, category3, category4).
* **Fire Resistant Test Results**: 
  * Type: Select Multiple
  * Description: Indicate whether the FRT has undergone fire resistance tests.
  * Example: "Yes" for tests conducted, "No" otherwise.
* **Certification Status**: 
  * Type: Select One
  * Description: Select the certification status of this FRT.
  * Example: "certified" for certified FRTs, "not certified" for non-certified ones, "pending" for those still under review.
* **Certification Date**: 
  * Type: Date
  * Description: Enter the date the FRT was certified (if applicable).
