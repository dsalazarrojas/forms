# Danceblue 2016 Programming Committee - Help Guide
## Purpose
The Danceblue 2016 Programming Committee form is used to collect and manage event registration information for the Danceblue 2016 event.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the required fields with the correct information about the event.
2. Review the form carefully before submitting it.

## Field-by-Field Explanation
- **Event Registration Forms** (`id: 1`, `type: text`): This is the title of the form, which is not required to be filled.
- **Title** (`id: 2`, `type: text`, required: false): Enter the title of the event.
- **Description** (`id: 3`, `type: text`, required: false): Enter a brief description of the event.
- **Category** (`id: 4`, `type: text`, required: false): Choose the category of the event. (Note: If you're unsure, leave this field blank.)
- **Program Name** (`id: 5`, `type: text`, required: false): Enter the name of the program associated with the event.
- **Start Date** (`id: 6`, `type: date`, required: false): Enter the start date of the event.
- **Start Time** (`id: 7`, `type: time`, required: false): Enter the start time of the event.
- **Venue** (`id: 8`, `type: text`, required: false): Enter the venue of the event.
- **Notes** (`id: 9`, `type: note`, required: false): Enter any additional notes about the event.
- **Program Participants** (`id: 10`, `type: select_multiple`, required: false): Select whether the event is a program participant or not.
- **Email** (`id: 11`, `type: email`, required: false): Enter the email address of the event organizer or contact person.
- **Phone** (`id: 12`, `type: text`, required: false): Enter the phone number of the event organizer or contact person.
- **Additional Notes** (`id: 13`, `type: text`, required: false): Enter any additional notes or comments about the event.

## Tips
- Ensure that you have all the necessary information about the event before filling out this form.
- Review the form carefully to avoid errors.
- If you're unsure about any field, contact the event organizers for clarification.
