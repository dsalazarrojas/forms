# Vendor Booth Image Upload Form - Help Guide

## Purpose
The Vendor Booth Image Upload Form collects information about an exhibitor's booth for exhibition management purposes.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the exhibitor's name in the "Exhibitor Name" field.
2. Upload a relevant image for the vendor booth.
3. Provide detailed information about the vendor in the "Vendor Details" field.
4. Enter the booth address in the "Booth Address" field.
5. Select the type of booth from the options provided.
6. Add a brief description of the booth in the "Booth Description" field.
7. Provide the name of the contact person in the "Contact Person" field.
8. Enter a valid email address in the "Email" field (if required).
9. Provide the contact person's phone number in the "Phone" field (if required).
10. If uploading a file, select the type and check if it's a "Yes" or "No".
11. Optionally, set the file size.

## Field-by-Field Explanation
* **Exhibitor Name** (`exhibitor_name`, text, required): Enter the name of the exhibitor.
* **Image** (`image`, text, required): Upload a relevant image for the vendor booth.
* **Vendor Details** (`vendor_details`, text, required): Provide detailed information about the vendor.
* **Booth Address** (`booth_address`, text, required): Enter the booth's address.
* **Booth Type** (`booth_type`, select_one, optional): Select the type of booth from the options provided.
* **Booth Description** (`booth_description`, text, optional): Add a brief description of the booth.
* **Contact Person** (`contact_person`, text, required): Provide the name of the contact person.
* **Email** (`email`, email, optional): Enter a valid email address for the contact person (if required).
* **Phone** (`phone`, text, optional): Enter the contact person's phone number (if required).
* **Upload File** (`upload_file`, text, optional): Optionally, upload a file related to the vendor booth.
* **File Type** (`file_type`, select_multiple, optional): If uploading a file, select the type from the options provided.
* **File Size** (`file_size`, number, optional): Optionally, set the file size (if uploading a file).
