# investment_oversight_conference_registration - Help Guide
## Purpose
The investment oversight conference registration form is designed to collect information from attendees for the purpose of planning and executing the conference effectively.

## How To Complete This Form
To complete this form, follow these steps:
1. Fill in the **event_details** field with a brief description of the event.
2. Select your **attendance_participation** status from the dropdown options (In-person, Virtual, Declined, Other, or No Response).
3. In the **attendee_details** field, provide any additional information about yourself as an attendee.
4. If you have any special requirements (e.g., accommodations, dietary restrictions), describe them in the **special_requirements** field.
5. Leave any additional comments or questions in the **comments** field.

## Field-by-Field Explanation
* **event_details**: A short description of the event (e.g., conference theme, speaker topics, date, time).
* **attendance_participation**: Select your participation status for the event (In-person, Virtual, Declined, Other, or No Response).
	+ Note: This field is not required, but it's essential to provide accurate attendance information for the organizers.
* **attendee_details**: Provide any additional information about yourself as an attendee (e.g., name, email, phone number).
* **special_requirements**: Describe any special requirements you have (e.g., accommodations, dietary restrictions).
* **comments**: Leave any additional comments or questions you have about the event.

## Tips
* Make sure to provide accurate attendance information to help the organizers plan the event effectively.
* If you have any special requirements, please specify them clearly to ensure proper arrangements can be made.
