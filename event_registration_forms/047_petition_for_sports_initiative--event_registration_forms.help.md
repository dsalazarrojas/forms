# Petition For Sports Initiative - Help Guide
## Purpose
The Petition For Sports Initiative form is used to gather information about a new sports-related event. This includes details such as the event title, category, and location.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the title of your sports initiative in the "petition_for_sports" field.
2. Select the category of your event in the "Category" field.
3. Provide a brief description of your event in the "Description" field.
4. Enter the ID of the category in the "category_id" field.
5. Select whether this event is an open event ("Yes") or not ("No") in the "event_type" field.
6. Enter the ID of the event type in the "event_type_id" field.
7. Enter the name of the sport in the "sport" field.
8. Enter the location of the event in the "Location" field.
9. Enter the start date of the event in the "start_date" field.
10. Enter the end date of the event in the "end_date" field.
11. Enter the start time of the event in the "start_time" field.
12. Enter the end time of the event in the "end_time" field.

## Field-by-Field Explanation
### **1. petition_for_sports** (Text)
Enter the title of your sports initiative.

### **2. Category** (Text)
Select the category of your event.

### **3. Description** (Text)
Provide a brief description of your event.

### **4. category_id** (Number)
Enter the ID of the category.

### **5. event_type** (Select One)
Select whether this event is an open event ("Yes") or not ("No").

### **6. event_type_id** (Number)
Enter the ID of the event type.

### **7. sport** (Text)
Enter the name of the sport.

### **8. Location** (Text)
Enter the location of the event.

### **9. start_date** (Date)
Enter the start date of the event.

### **10. end_date** (Date)
Enter the end date of the event.

### **11. start_time** (Time)
Enter the start time of the event.

### **12. end_time** (Time)
Enter the end time of the event.

Note: The fields labeled with "ID" (e.g., "event_type_id") are likely used as references or keys to look up additional information about the event.
