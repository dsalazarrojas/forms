# cultural_event_leave_form - Help Guide
## Purpose
The cultural event leave form is a tool for employees to register for cultural events. It is designed to keep track of event attendance and provide valuable information for event planning and coordination.

## How To Complete This Form
To complete this form, follow these steps:
1. Fill in the employee ID number in the "employee_id" field.
2. Select the date of the event you would like to attend from the calendar in the "event_date" field.
3. Choose the time slot you would like to attend from the available options in the "event_time" field.

## Field-by-Field Explanation
* **employee_id** (`employee_id`, number, required: false): Enter your employee ID number to identify yourself as the attendee.
* **event_date** (`event_date`, date, required: false): Select the date of the event you would like to attend from the calendar.
* **event_time** (`event_time`, time, required: false): Choose the time slot you would like to attend from the available options.
  Tip: If you're unsure about the format of the date and time fields, refer to our company calendar for guidance.
  Note: Please check the box if you wish to receive updates and information about the event.
