# Team Collaboration Training Form - Help Guide
## Purpose
This form is used to collect information from participants and trainers for team collaboration training sessions.

## How To Complete This Form
1. Fill in the form with your participant information if you are a participant, or with session information if you are a trainer.
2. Make sure to fill in all the required fields.
3. Use the available options to select the correct training session status.
4. Use the text fields for additional comments or notes if required.
5. Finally, review and submit your form.

## Field-by-Field Explanation

### 1. Participant Name (<participant_name>)
 Participant Name is a text input field for participants to fill in their name.

* Type: text
* Required: optional

### 2. Email (<email>)
Email is an email input field for participants to fill in their email address.

* Type: email
* Required: optional

### 3. Phone Number (<phone_number>)
 Phone Number is a text input field for participants to fill in their phone number.

* Type: text
* Required: optional

### 4. Training Session (<training_session>)
 Training Session is a select-one input field for selecting the training session status.

* Type: select_one
* Required: optional

### 5. Feedback (<feedback>)
 Feedback is a text input field for participants to provide feedback about the training session.

* Type: text
* Required: optional

### 6. Comments (<comments>)
 Comments is a text area input field for participants to provide additional comments about the training session.

* Type: note

### 7. Participant Information (<participant_info>)
