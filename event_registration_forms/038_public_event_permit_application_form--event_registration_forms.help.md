# Public Event Permit Application Form - Help Guide
## Purpose
This form is designed to collect information about a public event that requires a permit. It is used by event organizers to apply for a permit and provide the necessary details about the event.

## How To Complete This Form
To complete this form, follow these steps:

1. Please fill in the event details such as date, location, and type.
2. Provide the contact information of the event organizer.
3. Select the event category from the given options.
4. Enter the start and end times of the event.

## Field-by-Field Explanation

### 1. **Event Details** (`Event Details`, `text`, required: false)
Please provide a brief description of the event.

### 2. **Event Date and Time** (`Event Date and Time`, `date`, required: false)
Enter the date and time of the event. Please use the format mm/dd/yyyy and hh:mm AM/PM.

### 3. **Event Organizer Details** (`Event Organizer Details`, `text`, required: false)
Provide the name and title of the event organizer.

### 4. **Event Organizers Contact** (`Event Organizers Contact`, `text`, required: false)
Enter the contact information of the event organizer, including their phone number and email.

### 5. **Event Location** (`Event Location`, `text`, required: false)
Enter the location where the event will take place.

### 6. **Event Type** (`Event Type`, `select_one`, required: false)
Select the type of event from the given options.

### 7. **Event Category** (`Event Category`, `select_one`, required: false)
Select the category of the event from the given options.

### 8. **Start Time** (`Start Time`, `time`, required: false)
Enter the start time of the event. Please use the format hh:mm AM/PM.

### 9. **End Time** (`End Time`, `time`, required: false)
Enter the end time of the event. Please use the format hh:mm AM/PM.
