# Process Digitization Summit Registration - Help Guide
## Purpose
The Process Digitization Summit Registration form is designed to collect information from attendees, presenters, and sponsors for the Process Digitization Summit. This information will be used to plan and organize the event.
## How To Complete This Form
To complete the form, follow these steps:

1.  Please fill out the required fields. The form fields with a star (*) are required and must be filled out in order to submit the form.
2.  Review each field carefully and make sure to enter accurate information.
3.  Use the options for each field as a guide to ensure you are providing the correct information.
