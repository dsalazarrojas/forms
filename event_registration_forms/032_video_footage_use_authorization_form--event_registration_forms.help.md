# Video Footage Use Authorization Form - Help Guide
## Purpose
This form is for video footage use authorization. Fill out the form with the requested information, and you will be granted authorization to use the specified video footage for your event.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the appropriate registration form type from the "Event Registration Forms" drop-down menu.
2. Enter the title of the project you are authorizing.
3. Provide a brief description of the project.
4. Enter a title for the video footage you are authorizing.

## Field-by-Field Explanation
* **Event Registration Forms** (`select_multiple`, required/optional): Select the type of event registration form you need to complete the authorization process. This will help us to determine the correct usage rights for your event.
* **Project Title** (`text`, required/optional): Enter the title of your project to ensure that we can identify it correctly. This is a crucial field to provide accurate information about your project.
* **Project Description** (`text`, required/optional): Provide a brief description of your project so we can understand the context and purpose of your use of the video footage.
* **Video Title** (`text`, required/optional): Enter a title for the video footage you are authorizing to ensure that we can identify it correctly.

## Tips
* Please make sure to provide accurate information for all fields to ensure smooth processing of your request.
* If you are unsure about any of the information required, please contact the event organizer or the person who created this form.
* Note that this form is for video footage use authorization, so please ensure that you are using the footage for legitimate purposes only.
