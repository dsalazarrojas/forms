# Study Leader Appreciation RSVP - Help Guide
## Purpose
The purpose of this form is to allow Study Leaders to RSVP for upcoming events and provide necessary details for the event.

## How To Complete This Form
To complete this form, please follow the instructions below:

1. Select the "event_name" field and type the name of the event you are RSVP'ing for.
2. In the "guest_count" field, enter the number of guests that will be attending with you.
3. In the "message" field, provide any additional comments or notes about the event.
4. In the "event_date" field, select the date of the event from the calendar.
5. In the "event_time" field, select the time of the event from the time picker.
6. In the "message_of_thanks" field, provide a message of thanks to the Study Leader team.
7. In the "will_attend" field, select "True" if you will be attending the event, and "False" otherwise.
8. In the "will_cancel" field, select "True" if you will not be able to attend, and "True" if you will not be able to confirm your response.
9. In the "reason_for_not_attending" field, provide a brief explanation if you are unable to attend the event.

## Field-by-Field Explanation

* **event_name** (text, required): Enter the name of the event you are RSVP'ing for.
* **guest_count** (number, optional): Enter the number of guests that will be attending with you.
* **message** (text, optional): Provide any additional comments or notes about the event.
* **event_date** (date, required): Select the date of the event from the calendar.
* **event_time** (time, required): Select the time of the event from the time picker.
* **message_of_thanks** (text, optional): Provide a message of thanks to the Study Leader team.
* **will_attend** (select_one, required): Select "True" if you will be attending the event, and "False" otherwise.
* **will_cancel** (select_one, required): Select "True" if you will not be able to confirm your response, and "False" otherwise.
* **reason_for_not_attending** (text, optional): Provide a brief explanation if you are unable to attend the event.

## Tips
* Please make sure to provide accurate information, especially the event date and time.
* If you are unable to attend the event, please provide a clear reason for your non-attendance.
* If you have any questions or concerns about the form, please don't hesitate to reach out to us.
