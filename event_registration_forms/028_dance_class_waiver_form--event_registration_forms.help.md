# Dance Class Waiver Form - Help Guide
## Purpose
This form is designed to collect participant information and waiver for dance class attendance.

## How To Complete This Form
- Please fill in the form accurately and completely to ensure that all relevant information is recorded.
- Ensure that you fill out all required fields.
- If a field is optional, fill it out if you have the necessary information.

## Field-by-Field Explanation
* **Studio Address (1)**: Enter the address of the dance studio where the class will be held.
* **Parent Name (2)**: Enter the name of your parent or guardian.
* **Emergency Contact Name (3)**: Enter the name of the person or organization you would like to contact in case of an emergency.
* **Emergency Contact Relationship (4)**: Describe the relationship between you and the emergency contact (e.g., mother, father, sister).
* **Emergency Contact Phone (5)**: Enter the phone number of the emergency contact.
* **Parent Signature (6)**: Sign here to confirm that you have read, understand, and agree to the waiver below.
* **Studio Signature (7)**: Sign here to confirm that you have read, understand, and agree to the waiver below.
* **Participant Consent (8)**: By signing below, you acknowledge that you understand and agree to the waiver of liability, etc.
* **Waiver Text (9)**: This is a text area where the waiver can be typed in. Please fill in the waiver text here.
* **Date of Birth (10)**: Enter your date of birth in the format MM/DD/YYYY.
* **Emergency Contact (11)**: Enter the name of the person or organization you would like to contact in case of an emergency.
* **Medical Information (12)**: Enter any relevant medical information that we should know about you.
* **Medical Condition (13)**: If you have any medical conditions that may affect your participation, enter a description here.
* **Medical Procedure (14)**: If you have undergone any medical procedures, enter a description here.
* **Medical Medication (15)**: If you take any medications, enter a description here.
* **Medical Notes (16)**: Enter any additional medical notes here.
* **Medical Allergies (17)**: If you have any allergies, enter a description here.
* **Medical Equipment (18)**: If you need any specific medical equipment, enter a description here.
* **Medical Condition Notes (19)**: If you have any medical condition notes, enter a description here.
* **Participant Medical Notes (20)**: Enter any additional medical notes for the participant.
* **Participant Allergy (21)**: If you have any allergies, enter a description here.
* **English Proficiency (22)**: Select the language you are proficient in.
* **Participant Other (23)**: If you selected "Other" for English Proficiency, please enter the language here.
* **Medical Equipment Other (24)**: If you need any specific medical equipment, enter a description here.
* **Medical Equipment Notes (25)**: Enter any additional medical notes for medical equipment.
