# Trade Fair Exhibitor Mixer RSVP Form - Help Guide
## Purpose
This form is intended for trade fair exhibitors to RSVP to the mixer event hosted by the trade fair organization.

## How To Complete This Form
To complete this form, please follow these steps:
1. Answer the question on the "Intro page" (page 1) briefly if you would like.
2. Select your response to the question "Do you plan to attend" (page 2).
3. Enter your estimated headcount (page 3) if you would like.
4. If you have any headcount-related questions or concerns, you can enter them in the "Estimated headcount hint" field (page 4).
5. Select any dietary preferences from the list of options for "Food preference" (page 5).
6. If you have any questions or requests related to food, you can enter them in the "Do you have any food questions or requests?" field (page 6).
7. If you have any special requests, such as accessibility concerns, you can enter them in the "Do you have any special requests?" field (page 7).
8. If you have any other notes or comments, you can enter them in the "Any other notes" field (page 8).

## Field-by-Field Explanation
* **Intro page (page 1)**: A brief introduction to the form where you can add any information you would like.
* **Do you plan to attend (page 2)**: Select "Yes" if you plan to attend the mixer event, "No" if you do not plan to attend, or "Maybe" if you're unsure.
* **Estimated headcount (page 3)**: Enter your estimated number of people attending with you.
* **Estimated headcount hint (page 4)**: If you have any headcount-related questions or concerns, enter them here.
* **Food preference (page 5)**: Select any dietary preferences, such as Vegetarian, Vegan, Gluten free, or Meat.
* **Do you have any food questions or requests? (page 6)**: If you have any questions or requests related to food, enter them here.
* **Do you have any special requests? (page 7)**: If you have any special requests, such as accessibility concerns, enter them here.
* **Any other notes (page 8)**: Enter any other notes or comments you would like to add.
