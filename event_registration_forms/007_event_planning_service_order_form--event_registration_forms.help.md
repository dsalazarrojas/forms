# Event Planning Service Order Form - Help Guide

## Purpose
This form is used to gather information from clients or customers about their event planning needs. It helps the event planning service provider understand the client's requirements, preferences, and expectations, allowing them to tailor their services accordingly.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the service type that best fits your event planning needs.
2. Provide the location where the event will take place.
3. Enter the date and start time of the event.
4. Specify the duration of the event.
5. Indicate the number of guests attending the event.
6. Choose the type of event (e.g., meeting, conference, or seminar).
7. Add any additional notes or information about the event.

## Field-by-Field Explanation

* **Service Order Form** (text, required/optional): This is the main field where you can provide a brief description of your event planning needs.
* **Select Service Type** (select_one, required/optional): Choose from Basic Service, Premium Service, or Custom Service to select the level of service you require. This will help the event planning service provider understand the scope of their work.
* **Event Location** (text, required/optional): Enter the physical location where the event will take place.
* **Event Date** (date, required/optional): Enter the date of the event in YYYY-MM-DD format.
* **Event Start Time** (time, required/optional): Select the start time of the event in 24-hour format (e.g., 09:00).
* **Event Duration** (number, required/optional): Indicate the length of time the event will last in hours.
* **Number of Guests** (number, required/optional): Enter the estimated number of guests attending the event.
* **Event Type** (select_multiple, required/optional): Choose one or more from Meeting, Conference, or Seminar to indicate the type of event.
* **Additional Notes** (note, required/optional): Add any additional information or specific requests you have for the event planning service provider.

## Tips
* Make sure to fill out all required fields to ensure the event planning service provider has a clear understanding of your needs.
* Use the "Select Service Type" field to specify the level of service you require, as this will impact the scope of work and pricing.
* If you have any specific requirements or requests, add them in the "Additional Notes" field.
