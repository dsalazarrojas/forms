# Event Ticketing Subscription Form - Help Guide
## Purpose
This form is designed to collect information for event ticketing purposes, enabling users to subscribe to events with customized options.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter your event details in the "Event Ticketing Subscription" field on page 1.
2. Describe your event goals in the "Goals" field on page 2.
3. Select one or more input fields that you need for your event from the "Input Fields" drop-down menu on page 3. Available options are:

	* Payment Gateway
	* Payment Method
	* Event Info
	* Time
	* Date
	* Event Date
	* Time In
	* Time Out
	* Time Zone
	* Currency
	* Amount
	* Discount
	* Event Type
	* Location

## Field-by-Field Explanation
* **Event Ticketing Subscription** (`event_ticketing_subscription_form`, text, required: false):
	+ This is the main field where you can enter your event title or description.
* **Goals** (`event_ticketing_form_goals`, text, required: false):
	+ Describe the objectives or goals of your event.
* **Input Fields** (`event_ticketing_form_input_fields`, select_one, required: false):
	+ Select one or more input fields that you need for your event from the available options:
		+ Payment Gateway
		+ Payment Method
		+ Event Info
		+ Time
		+ Date
		+ Event Date
		+ Time In
		+ Time Out
		+ Time Zone
		+ Currency
		+ Amount
		+ Discount
		+ Event Type
		+ Location
