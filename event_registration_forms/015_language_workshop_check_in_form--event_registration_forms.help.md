# <string> - Help Guide
## Purpose
This form is used to create a record of an event registration, capturing essential details about the event and participant.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the Event ID, which is a unique identifier for the event.
2. Provide the participant's name.
3. Enter the participant's email address.
4. Enter the participant's phone number.
5. Select the session type (e.g., English or French).
6. Enter the Session ID, which is a unique identifier for the session.
7. Add any questions or notes about the workshop (this field is a free-form text input).
8. Add any notes about the participant (this field is a free-form text input).
9. Repeat the workshop questions field to add additional questions or notes (this field is optional and can be used for follow-up questions or comments).

## Field-by-Field Explanation
* **Event ID**: Enter the unique identifier for the event.
	+ Type: number
	+ Required: false
* **Participant Name**: Enter the name of the participant attending the event.
	+ Type: text
	+ Required: false
* **Participant Email**: Enter the participant's email address.
	+ Type: email
	+ Required: false
* **Participant Phone**: Enter the participant's phone number.
	+ Type: text
	+ Required: false
* **Session Type**: Select the language of the session (e.g., English or French).
	+ Type: select_one
	+ Required: false
* **Session ID**: Enter the unique identifier for the session.
	+ Type: number
	+ Required: false
* **Workshop Questions**: Add any questions or notes about the workshop.
	+ Type: note
	+ Required: false
* **Participant Notes**: Add any notes about the participant.
	+ Type: note
	+ Required: false
* **Workshop Questions 2**: Repeat the workshop questions field for additional questions or notes.
	+ Type: note
	+ Required: false

## Tips
- Make sure to enter accurate and clear information to ensure that the event registration is complete and up-to-date.
