# Crystal Meditation Experience Registration - Help Guide
## Purpose
This form is used to register for the Crystal Meditation Experience event. It gathers basic information about attendees and event details.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in your **Attendee Name**.
2. Enter your **Email** address.
3. Provide your **Phone** number (if needed).
4. Select the **Event Date** and **Event Time** for the event.
5. Choose the **Event Type** (Meditation, Yoga, or Other).
6. Specify the **Attendee Count** (number of attendees).
7. Add any additional **Note** you'd like to include.
8. If applicable, select the **Assigned User** and **Assigned Tool** for the event.
9. If you have an output file, provide the **Output File** name.
10. If necessary, fill in the **Form ID** (usually provided by the system).

## Field-by-Field Explanation

* **Attendee Name**: Enter the name of the attendee, as it will appear in the event records.
* **Email**: Provide your email address so that we can contact you with event updates and reminders.
* **Phone**: Enter your phone number if you need to be contacted by phone.
* **Event Date**: Choose the date of the event from the calendar provided.
* **Event Time**: Select the time of the event from the available time slots.
* **Event Type**: Select the type of event you are interested in (Meditation, Yoga, or Other).
* **Attendee Count**: Enter the number of attendees you are planning to bring with you.
* **Note**: Add any additional information you'd like to include about the event or your registration.
* **Assigned User**: If you're attending under a specific user's supervision, select their name here.
* **Assigned Tool**: Select the tool that has been assigned to you for the event (chatjimmy or None).
* **Output File**: Provide the name of any output files generated for you.
* **Form ID**: Enter the unique Form ID provided to you for this event (usually provided by the system).

Note: This help guide assumes the form is used for event registration; if the actual use case differs, please refer to your organization's specific instructions or contact the form maintainer.
