# Temporary Accommodation Request Form - Help Guide

## Purpose
This form is used to request temporary accommodation for events or bookings. It is essential to fill out this form accurately and completely to ensure that your accommodation needs are met.

## How To Complete This Form

To complete this form, follow the steps below:

1. Select the type of accommodation you require:
   - Click on "Event Registration Forms" or "Booking Forms" from the dropdown menu.

## Field-by-Field Explanation

### Page 1: Event Registration Forms, Booking Forms

- **Event Registration Forms** (`event_registration_forms`, `select_one`, required/optional):
    + This field allows you to choose between Event Registration Forms and Booking Forms.
    + Choose the correct option based on the type of form you need to fill out.

### Page 1: Event Registration Forms, Booking Forms

- **accommodation_request_form** (`accommodation_request_form`, `select_multiple`, required/optional):
    + This field allows you to select the type of accommodation request you need.
    + Choose "Request Accommodation" if you need to request temporary accommodation.
    + Choose "Confirm Accommodation Request" if you already have an existing accommodation request.

### Page 1: Event Registration Forms, Booking Forms

- **accommodation_request_date** (`accommodation_request_date`, `date`, required/optional):
    + This field is used to enter the date you need temporary accommodation for.
    + Format: MM/DD/YYYY (e.g., 01/01/2022)

### Page 1: Event Registration Forms, Booking Forms

- **accommodation_request_time** (`accommodation_request_time`, `time`, required/optional):
    + This field is used to enter the time you need temporary accommodation for.
    + Format: 12:00 PM (e.g., 02:00 PM)

### Page 1: Event Registration Forms, Booking Forms

- **accommodation_request_duration** (`accommodation_request_duration`, `number`, required/optional):
    + This field is used to enter the duration of your temporary accommodation need.
    + Enter the number of days or hours you require accommodation for.

### Page 1: Event Registration Forms, Booking Forms

- **accommodation_request_type** (`accommodation_request_type`, `select_one`, required/optional):
    + This field allows you to choose the type of accommodation you require.
    + Choose "Short-term housing solution" if you need accommodation for a short period.
    + Choose "Long-term housing solution" if you need accommodation for an extended period.

### Page 1: Event Registration Forms, Booking Forms

- **accommodation_request_status** (`accommodation_request_status`, `select_one`, required/optional):
    + This field is used to check the status of your accommodation request.
    + Check "Pending" if your request is still in process.
    + Check "Approved" if your request has been approved.
    + Check "Declined" if your request has been declined.

### Page 1: Event Registration Forms, Booking Forms

- **accommodation_request_notes** (`accommodation_request_notes`, `note`, required/optional):
    + This field is used to enter any additional comments or notes about your accommodation request.
    + You can add any relevant information about your accommodation needs.

### Page 1: Event Registration Forms, Booking Forms

- **user_notes** (`user_notes`, `note`, required/optional):
    + This field is used to enter any additional comments or notes about your request.
    + You can add any relevant information about your request.

## Tips

- Make sure to fill out all required fields accurately and completely.
- Review your form before submitting it to ensure that all information is correct.
- If you are unsure about any field, contact the event organizer or booking administrator for assistance.
