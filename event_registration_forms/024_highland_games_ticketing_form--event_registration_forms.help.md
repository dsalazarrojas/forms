# Highland Games Ticketing Form - Help Guide

## Purpose
The Highland Games Ticketing Form is used to collect and record information about event attendees for the Highland Games event.

## How To Complete This Form
1.  Start by filling in the basic details of the attendee, including their name and email address. If the attendee's email address is not provided, please leave it blank.
2.  Select the type of ticket the attendee is purchasing, if applicable.
3.  Add any additional notes about the attendee, if necessary.
4.  Fill in the date and time the attendee is attending the event.
5.  Choose who submitted the form.
6.  Select the submitter's contact phone number and email address, if applicable.
7.  Enter any additional notes about who submitted the form.

## Field-by-Field Explanation

*   **event_name** (`highland_games_ticketing_form_1`, text, required/optional): Enter the name of the event you are registering for, which is "Highland Games".
*   **attendee_name** (`highland_games_ticketing_form_2`, text, required/optional): Enter the name of the person registering for the event.
*   **attendee_email** (`highland_games_ticketting_form_3`, email, required/optional): Enter the email address of the person registering for the event, if known.
*   **attendee_phone** (`highland_games_ticketting_form_4`, text, required/optional): Enter the phone number of the person registering for the event, if known.
*   **ticket_type** (`highland_games_ticketing_form_5`, select_one, required/optional): Select the type of ticket the attendee is purchasing, if applicable.
*   **attendee_notes** (`highland_games_ticketting_form_6`, note, required/optional): Add any additional notes about the attendee, if necessary.
*   **attendee_date** (`highland_games_ticketting_form_7`, date, required/optional): Enter the date the attendee is attending the event.
*   **attendee_time** (`highland_games_ticketting_form_8`, time, required/optional): Enter the time the attendee is attending the event.
*   **submitter** (`highland_games_ticketting_form_9`, select_one, required/optional): Choose who submitted the form.
*   **submitter_phone** (`highland_games_ticketting_form_10`, text, required/optional): Enter the phone number of the person submitting the form, if known.
*   **submitter_email** (`highland_games_ticketting_form_11`, email, required/optional): Enter the email address of the person submitting the form, if known.
*   **submitter_date** (`highland_games_ticketting_form_12`, date, required/optional): Enter the date the form was submitted.
*   **submitter_time** (`highland_games_ticketting_form_13`, time, required/optional): Enter the time the form was submitted.
*   **submitter_notes** (`highland_games_ticketting_form_14`, note, required/optional): Add any additional notes about who submitted the form, if necessary.
