# videography_project_submission_permission_form - Help Guide
## Purpose

The <i>videographic Project Submission Permission Form</i> is used to collect information from clients about their videography projects, including project details, client contact information, and other relevant data. This form is an essential tool in the project submission process.

## How To Complete This Form

To complete this form, please follow these steps:

1. Fill in the project details in the "Project Name", "Project Description", and "Project Location" fields.
2. Enter your contact information in the "Client Contact Email", "Client Contact Phone", and "Form Submitter Email", "Form Submitter Phone" fields.
3. Select the "Client Agreement Status" as appropriate.
4. Provide a brief description of the project in the "Client Comments" field.
5. Add any additional comments or details about the project in the "Project Comments" field.
6. Select the project status as "Active" or "Inactive" in the "Project Status" field.
7. Enter the project start and end dates in the "Project Start Date" and "Project End Date" fields.
8. Fill in the "Project Terms", "Project Copyright", and "Client Agreement" fields with the relevant details.
9. Add any additional information about the project in the "Project Image", "Project Video", and "Project Audio" fields.
10. Finally, review all the information provided and submit the form.

## Field-by-Field Explanation

* **Project Name**: Enter the name of the project.
* **Project Description**: Briefly describe the project.
* **Project Location**: Enter the location where the project took place.
* **Client Contact Email**: Enter the email address of the client or their representative.
* **Client Contact Phone**: Enter the phone number of the client or their representative.
* **Client Name**: Enter the name of the client or their representative.
* **Client Title**: Enter the title of the client or their representative.
* **Project Start Date**: Enter the start date of the project.
* **Project End Date**: Enter the end date of the project.
* **Project Status**: Select the current status of the project as "Active" or "Inactive".
* **Client Permissions**: Enter the client's permissions or requirements for the project.
* **Project Permissions**: Enter the project's permissions or requirements.
* **Project Terms**: Enter the terms of the project.
* **Project Copyright**: Enter the copyright information of the project.
* **Client Agreement**: Enter the client's agreement or contract terms.
* **Client Comments**: Add any additional comments or details about the client.
* **Project Comments**: Add any additional comments or details about the project.
* **Project Image**: Attach an image related to the project.
* **Project Video**: Attach a video related to the project.
* **Project Audio**: Attach an audio file related to the project.
* **Form Submitter**: Enter the name of the person submitting the form.
* **Form Submitter Email**: Enter the email address of the person submitting the form.
* **Form Submitter Phone**: Enter the phone number of the person submitting the form.
* **Client Agreement Status**: Select the status of the client's agreement as "Yes" or "No".

Note: Please ensure that all required fields are filled in before submitting the form.
