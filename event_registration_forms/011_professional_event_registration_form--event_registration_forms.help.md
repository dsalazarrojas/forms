# Professional Event Registration Form - Help Guide

## Purpose
This form is used to collect information about professional events hosted by the event organizers. It includes fields for event details, attendee information, and additional comments.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the required fields (Event Name, Event Date, Event Time, and Event Location) with the relevant information about the event.
2. For the "Registrants" field, select "Yes" if the event is open to the public or "No" if it's by invitation only.
3. Fill in the "Attendee Name", "Attendee Email", and "Attendee Phone" fields with the contact information of the attendees.
4. In the "Additional Comments" field, add any extra information about the event that you think would be helpful for the organizers.

## Field-by-Field Explanation

* **Event Name** (text): A field to enter the name of the event.
* **Event Date** (date): A field to enter the date of the event.
* **Event Time** (time): A field to enter the time of the event.
* **Event Location** (text): A field to enter the location of the event.
* **Registrants** (select multiple): Select "Yes" if the event is open to the public or "No" if it's by invitation only.
* **Attendee Name** (text): A field to enter the attendee's name.
* **Attendee Email** (email): A field to enter the attendee's email address.
* **Attendee Phone** (text): A field to enter the attendee's phone number.
* **Additional Comments** (note): A text area to enter any extra comments about the event.
 

## Tips
* Make sure to fill in all the required fields before submitting the form.
* Double-check the information you enter in each field to ensure it is accurate and up-to-date.
