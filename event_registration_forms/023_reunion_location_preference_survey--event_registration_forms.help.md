# Reunion Location Preference Survey - Help Guide
## Purpose
This form is used to collect information from attendees on their preferred location for the reunion, their likelihood of attending, and other relevant details such as dates and contact information.

## How To Complete This Form
To complete this form, simply follow these steps:

1. Select your preferred location(s) for the reunion from the list provided.
2. Indicate how likely you are to attend the reunion by selecting from the options provided.
3. If you have a preferred date for the reunion to start, select it. If you have no preference, simply select "null".
4. If you have a preferred date for the reunion to end, select it. If you have no preference, simply select "null".
5. If you have any notes or comments about the reunion, type them in the "Do you have any notes?" field.
6. If you would like to receive updates about the reunion, enter your email address.
7. If you would like to provide your phone number for further contact, type it in the "Your phone number" field.

## Field-by-Field Explanation

* **What is your preferred reunion location** (location\_preference): Select all locations that you would prefer for the reunion. You can select multiple locations.
* **How likely are you to attend** (attendance\_likelihood): Indicate your level of commitment to attending the reunion. Select from the options provided.
* **What date works best for the reunion** (start\_date, end\_date): Choose a date that works best for you, or select "null" if you have no preference.
* **Do you have any notes?** (note): If you have any comments or suggestions about the reunion, type them in this field.
* **Your email address** (email): If you want to receive updates about the reunion, enter your email address.
* **Your phone number** (phone): If you would like to provide your phone number for further contact, type it in this field.
