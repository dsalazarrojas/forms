# e_sports_event_complaint_form - Help Guide
## Purpose
The E Sports Event Complaint Form is designed to collect information about E Sports events, allowing users to report or complain about issues they experienced during the event.

## How To Complete This Form
To complete this form, follow these steps:
1. Select or enter the event details, date, and time.
2. Enter the event location.
3. Provide a detailed description of the issue or complaint.
4. Specify the problem experienced during the event.
5. If necessary, upload supporting documents or evidence for the complaint.

## Field-by-Field Explanation
### E Sports Event Details
* **E Sports Event Details** (`e_sports_event_details`, `text`, required): Enter the event name or description.
### Event Date
* **Event Date** (`event_date`, `date`, required): Select or enter the event date.
### Event Time
* **Event Time** (`event_time`, `time`, required): Select or enter the event start time.
### Event Location
* **Event Location** (`event_location`, `text`, required): Enter the event location.
### Description
* **Description** (`description`, `text`, required): Provide a detailed description of the issue or complaint.
### Event Problem
* **Event Problem** (`event_problem`, `text`, required): Enter the specific problem or issue experienced during the event.
### E Sports Event Complaint Form Attachments
* **E Sports Event Complaint Form Attachments** (`e_sports_event_complaint_form_attachments`, `text`, optional): Upload supporting documents or evidence for the complaint. Please note that this field accepts PDF, DOCX, and DOCM files.

## Tips
* Be as detailed as possible when describing the issue or complaint.
* Make sure to upload supporting documents or evidence if necessary.
* If you are unsure about any field, contact the relevant authorities or event organizers for assistance.
