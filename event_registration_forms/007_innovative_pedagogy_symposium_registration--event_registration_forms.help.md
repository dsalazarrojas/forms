# innovative-pedagogy-symposium-registration - Help Guide
## Purpose
The "innovative-pedagogy-symposium-registration" form is used to collect information about the attendees for the symposium.
## How To Complete This Form
To complete this form, follow the steps below:

1. Fill in the required fields, which are:
	* Attendee Name
	* Institution
	* Email
2. Optionally, provide additional information:
	* Role
	* Session Interests (select one or more sessions you are interested in)
	* Accessibility Needs (select one or more accessibility needs you have)
	* Phone (optional)

## Field-by-Field Explanation

* **Attendee Name** (id: 2, required): Enter the attendee's name.
* **Institution** (id: 3, required): Enter the institution or organization the attendee is affiliated with.
* **Role** (id: 4, optional): Indicate the attendee's role (e.g., presenter, speaker, participant).
* **Session Interests** (id: 5, optional): Select one or more sessions that the attendee is interested in attending.
	+ Session 1
	+ Session 2
	+ Session 3
* **Accessibility Needs** (id: 6, optional): Select one or more accessibility needs the attendee has (e.g., Visual Impairment, Hearing Impairment).
	+ None
	+ Visual Impairment
	+ Hearing Impairment
	+ Speech or Communication Impairment
	+ Mobility Impairment
* **Email** (id: 7, required): Enter the attendee's email address.
* **Phone** (id: 8, optional): Enter the attendee's phone number.

## Tips
* Make sure to fill in all the required fields (Attendee Name, Institution, and Email) to ensure proper registration.
* If you have accessibility needs, please select them from the options provided.
* You can select multiple session interests.
