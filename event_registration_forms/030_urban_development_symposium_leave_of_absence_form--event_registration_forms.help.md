# urban_development_symposium_leave_of_absence_form - Help Guide
## Purpose
The urban development symposium leave of absence form is used to report a leave of absence due to an event or symposium. This form captures essential information about the attendee, event details, absence dates, reason for absence, and other relevant details. It is designed to facilitate easy and accurate tracking of attendance and absence records.

## How To Complete This Form
To complete this form, follow these steps:

* Fill in the required and optional fields as instructed.
* Ensure you enter accurate and complete information in each field.

## Field-by-Field Explanation
* **Attendee Information** (attendee_info):
	+ Enter the details of the attendee (e.g., name, contact information).
	+ This field is optional.
* **Event Details** (event_details):
	+ Provide any additional information about the event (e.g., event title, date, location).
	+ This field is optional.
* **Date Of Absence** (date_of_absence):
	+ Select or enter the start date of absence.
	+ This field is optional.
* **Reason For Absence** (reason_for_absence):
	+ Choose a valid reason for absence from the options provided.
	+ This field is optional.
* **Expected Return Date** (expected_return_date):
	+ Enter the expected return date.
	+ This field is optional.
* **Actual Return Date** (actual_return_date):
	+ Enter the actual return date.
	+ This field is optional.
* **Comments** (comments):
	+ Enter any additional comments about the absence.
	+ This field is optional.
* **Email** (email):
	+ Enter the attendee's email address.
	+ This field is optional.
* **Phone** (phone):
	+ Enter the attendee's phone number.
	+ This field is optional.
* **Assigned To** (assigned_to):
	+ Enter the person assigned to handle the leave of absence.
	+ This field is optional.
* **Status** (status):
	+ Choose the current status of the absence (e.g., approved, pending, rejected).
	+ This field is optional.
* **Submitted On** (submitted_on):
	+ The date the form was submitted.
	+ This field is optional.
* **Submitted By** (submitted_by):
	+ The person who submitted the form.
	+ This field is optional.

## Tips
* Make sure to provide accurate and complete information in each field.
* If you are unsure about any field, please contact the assigned person for assistance.
* This form is designed to be completed by attendees who need to report a leave of absence due to an event or symposium.
