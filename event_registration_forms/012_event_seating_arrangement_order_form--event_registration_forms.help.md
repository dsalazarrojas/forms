# Event Seating Arrangement Order Form - Help Guide
## Purpose
This form is used to provide information on your seating preferences, special requests, contact information, and other event-specific requirements. It is intended to help event organizers create accurate and timely seating arrangements and provide catering services tailored to your needs.

## How To Complete This Form
To complete this form, follow these steps:

1. Answer each question as accurately and thoroughly as possible.
2. Please indicate your seating preferences and any special requests.
3. Provide your contact information and dietary restrictions (if any).
4. Specify your event preferences.

## Field-by-Field Explanation

* **Seating Preferences** (`Seating preferences`, `text`, required: false)
Seating preferences are a list of specific seating requirements. Please indicate if you have any specific seating requests such as high chair, wheelchair, etc.

* **Table Number** (`table_number`, `number`, required: false)
Indicate the table number you would like to be seated at, if any.

* **Seating Priority** (`Seating priority`, `select_one`, required: false)
Select 'Yes' if you have a high priority seating request.

* **Special Requests** (`Special Requests`, `note`, required: false)
If you have any specific requests, please provide details in this field.

* **Contact Information** (`Contact Information`, `select_multiple`, required: false)
Please specify if you have any contact information that you'd like to share with event organizers.

* **Dietary Restrictions** (`Dietary Restrictions`, `select_multiple`, required: false)
Check 'Yes' for any dietary restrictions you may have.

* **Guest Details** (`Guest Details`, `text`, required: false)
Please provide any additional guest information.

* **Event Preferences** (`Event Preferences`, `select_multiple`, required: false)
Specify any event-specific preferences you may have.

## Tips
- Be as accurate and clear as possible when providing information.
- If you're unsure about any field, please ask event organizers for clarification.
- Completion of this form is optional but recommended for efficient seating arrangements.
