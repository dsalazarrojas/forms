# healthy_sexuality_event_registration - Help Guide
## Purpose
This form is designed to collect information for the registration of events related to healthy sexuality topics.

## How To Complete This Form
To complete this form, follow these steps:

1. Start by filling in the required fields, such as the **Workshop Title**, **Date**, and **Start Time**.
2. Provide detailed information about the event, including the **Event Description** and **Event Requirements**.
3. Collect participant information, including **Participant Name**, **Participant Email**, and **Participant Phone**.
4. Consider the participant's preferences, such as **Participant Preferred Language** and **Participant Dietary Restrictions**.
5. Add any additional details about the participant, such as **Participant Additional Details**.
6. Provide contact information for the event organizer, including **Contact Name**, **Contact Email**, and **Contact Phone**.
7. Specify the event duration and maximum number of participants, including **Event Duration** and **Event Maximum Participants**.
8. Set up submission tracking, if necessary, using the **Submission Tracking** field.

## Field-by-Field Explanation

* **Workshop Title**: Enter a brief title of the workshop or event.
* **Date**: Enter the date of the event.
* **Start Time**: Enter the start time of the event.
* **End Time**: Enter the end time of the event.
* **Venue**: Enter the location of the event.
* **Event Type**: Select the type of event (Workshop, Session, or Other).
* **Participant Name**: Enter the name of the participant.
* **Participant Email**: Enter the email address of the participant.
* **Participant Phone**: Enter the phone number of the participant.
* **Participant Preferred Language**: Select the participant's preferred language (English, Spanish, or French).
* **Participant Additional Details**: Add any additional information about the participant.
* **Participant Dietary Restrictions**: Select any dietary restrictions for the participant (Vegetarian, Non-Vegetarian, or Vegan).
* **Organizer Name**: Enter the name of the event organizer.
* **Event Description**: Provide a detailed description of the event.
* **Event Requirements**: Specify any requirements for the event.
* **Participant Requirements**: Specify any requirements for participants.
* **Contact Name**: Enter the name of the contact person.
* **Contact Email**: Enter the email address of the contact person.
* **Contact Phone**: Enter the phone number of the contact person.
* **Event Start Time**: Enter the start time of the event.
* **Event End Time**: Enter the end time of the event.
* **Event Duration**: Enter the duration of the event in hours.
* **Event Maximum Participants**: Enter the maximum number of participants for the event.
* **Participant Maximum Participants**: Enter the maximum number of participants per participant.
* **Submission Tracking**: Enable submission tracking for the event.
