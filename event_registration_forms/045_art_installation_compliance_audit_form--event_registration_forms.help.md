# Art Installation Compliance Audit Form - Help Guide
## Purpose
The Art Installation Compliance Audit Form is designed to ensure that art installations are safe, accessible, and compliant with relevant standards. This form is used to audit art installations and identify areas where remediation is required.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill in your name and role as the auditor.
2. Select a date for the audit.
3. Enter the title of the art installation being audited.
4. Specify the location of the art installation (gallery number/site).
5. Evaluate the structural integrity and mounting security of the installation.
6. Assess the presence of tripping or physical hazards.
7. Determine if the installation meets fire safety and exit path compliance.
8. Check if the electrical and lighting components are safe and secure.
9. Confirm that documentation and signage are accurate and compliant.
10. Verify insurance documents for the installation.
11. Check the accuracy of signage (artist, title, year).
12. Evaluate the accessibility of the installation for visitors with disabilities.
13. Determine the overall audit status and identify any areas requiring remediation.
14. Provide any remediation instructions if necessary.
15. Specify if a follow-up audit is required.
16. Enter your digital signature.
17. Select the time of completion.

## Field-by-Field Explanation

* **Auditor Name**: Enter your name as the auditor.
* **Date of Audit**: Select the date of the audit.
* **Art Installation Title**: Enter the title of the art installation being audited.
* **Location - Gallery Number - Site**: Enter the location of the art installation (gallery number/site).
* **Structural Integrity and Mounting Security**: Evaluate if the work is safely secured according to specifications. Select "Compliant" if it is secure, "Minor Adjustment Needed" if it needs minor adjustments, or "Non-compliant - Safety Hazard" if it is not secure.
* **Absence of Tripping or Physical Hazards**: Assess if there are any tripping or physical hazards. Select "Compliant" if there are no hazards, "Non-compliant" if there are hazards.
* **Fire Safety and Exit Path Compliance**: Check if the installation meets fire safety and exit path compliance. Select "Compliant" if it does, "Non-compliant" if it does not.
* **Electrical and Lighting Safety (If Applicable)**: Evaluate the electrical and lighting components for safety. Select "Compliant" if they are secure, "Needs Maintenance" if they require maintenance, or "N/A" if they are not applicable.
* **Insurance Documentation Verified for Installation**: Confirm that insurance documents for the installation have been verified. Select "True" if they have been verified, "False" if they have not.
* **Signage Accuracy (Artist, Title, Year)**: Check the accuracy of signage (artist, title, year). Select "Accurate" if it is accurate, "Corrections Required" if corrections are required.
* **ADA - Accessibility Standards Met**: Assess if the installation meets ADA accessibility standards for visitors with disabilities. Select "Fully Accessible" if it does, "Partially Accessible" if it does not fully meet the standards, or "Not Accessible" if it does not meet the standards at all.
* **Overall Audit Status**: Determine the overall audit status. Select "Passed - No Further Action" if the installation meets all standards, "Conditional Pass - Minor Adjustments Required" if minor adjustments are needed, "Failed - Immediate Remediation Required" if remediation is required.
* **Remediation Instructions**: If the installation failed or conditionally passed, provide remediation instructions.
* **Is a follow-up audit required?**: Evaluate if a follow-up audit is required. Select "True" if it is required, "False" if it is not.
* **Auditor Digital Signature (Type Name)**: Enter your digital signature.
* **Time of Completion**: Select the time of completion.
