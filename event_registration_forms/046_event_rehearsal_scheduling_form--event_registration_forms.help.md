# Event Rehearsal Scheduling Form - Help Guide
## Purpose
The Event Rehearsal Scheduling Form is used to schedule an event rehearsal.
## How To Complete This Form
To complete this form, follow these steps:

1. Enter the title of the event rehearsal in the "Schedule Details" field.
2. Select the time you want the event rehearsal to take place in the "Rehearsal Time" field.
3. Choose the date for the event rehearsal in the "Rehearsal Date" field.
4. Select the location for the event rehearsal in the "Rehearsal Location" field.
5. Enter any additional notes about the event rehearsal in the "Notes" field.
6. Enter the duration of the event rehearsal in the "Rehearsal Duration" field.
7. Choose the time zone for the event rehearsal in the "Rehearsal Time Zone" field.
8. Select the participants for the event rehearsal in the "Rehearsal Participants" field.
9. Choose the time zone for the event rehearsal in the "Rehearsal Time Zone" field (this field is identical to the previous one, but has a different ID).

## Field-by-Field Explanation

* **Schedule Details**: This field is used to enter the title of the event rehearsal. Enter the title in the text box provided.
* **Rehearsal Time**: This field is used to select the time for the event rehearsal. Choose a time from the options provided that works best for you.
* **Rehearsal Date**: This field is used to select the date for the event rehearsal. Choose a date from the calendar provided that works best for you.
* **Rehearsal Location**: This field is used to select the location for the event rehearsal. Enter the location in the text box provided.
* **Notes**: This field is used to enter any additional notes about the event rehearsal. Enter any relevant information in the text box provided.
* **Rehearsal Duration**: This field is used to select the duration of the event rehearsal. Enter a number that represents how long the event rehearsal will last.
* **Rehearsal Time Zone**: This field is used to select the time zone for the event rehearsal. Choose a time zone from the options provided that works best for you.
* **Rehearsal Participants**: This field is used to select the participants for the event rehearsal. Choose one or more participants from the options provided that will be attending.
* **Rehearsal Schedule**: This field is used to select the scheduled date for the event rehearsal. Choose a date for the event rehearsal.
* **Rehearsal Time Zone** (ID 10): This field is identical to the previous "Rehearsal Time Zone" field, but has a different ID.
* **Rehearsal Participants**: This field is used to select the participants for the event rehearsal. Choose one or more participants from the options provided that will be attending.
