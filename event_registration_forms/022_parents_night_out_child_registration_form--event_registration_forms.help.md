# Parents' Night Out Child Registration Form - Help Guide
## Purpose
The "Parents' Night Out Child Registration Form" is a form used for parents to register their child for an event or outing. This form collects essential information about the child, including their name, relationship with the registering parent, contact details, dietary requirements, and any allergies or special needs. By filling out this form, you will be able to provide the necessary information to ensure a safe and enjoyable experience for your child.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill out the child's name in the "child_name" field.
2. Select the relationship you have with the registering child (e.g., "Yes" for parent, "No" for guardian, etc.) in the "relationship" field.
3. Enter the phone number of the registering parent or guardian in the "phone_number" field.
4. Enter the email address of the registering parent or guardian in the "email" field.
5. If you have any additional information about the child that we should be aware of, you can enter it in the "additional_info" field.
6. If the child has any dietary requirements, please select the corresponding option in the "child_diet" field.
7. If the child has any allergies or special needs, please select the corresponding options in the "allergy_list" field.
8. If the registering parent or guardian has any special permission needs, you can select the corresponding option in the "parent_permission" field.
9. If you are registering for an event that has a specific start and end time, please select the time in the "event_time" field.
10. If you are registering for an event on a specific date, please select the date in the "event_date" field.
11. If you have any other specific details about the event you'd like to include, you can enter them in the "event_details" field.

## Field-by-Field Explanation

* **child_name** (text, required): Enter the name of the child you are registering.
* **relationship** (select one, required): Select the relationship you have with the registering child (e.g., "Yes" for parent, "No" for guardian, etc.).
* **phone_number** (text, required): Enter the phone number of the registering parent or guardian.
* **email** (email, required): Enter the email address of the registering parent or guardian.
* **additional_info** (note, optional): If you have any additional information about the child that we should be aware of, enter it here.
* **child_diet** (select multiple, optional): Select the dietary options that apply to the child (e.g., "Yes" for vegetarian, "No" for non-vegetarian).
* **allergy_list** (select multiple, optional): Select any allergies or special needs the child has (e.g., "Yes" for peanut allergy, "No" for no allergy).
* **parent_permission** (time, optional): If the registering parent or guardian has any special permission needs, select the corresponding option.
* **event_time** (date, optional): If you are registering for an event that has a specific start and end time, select the time.
* **event_date** (date, optional): If you are registering for an event on a specific date, select the date.
* **event_details** (text, optional): Enter any other specific details about the event you'd like to include.
