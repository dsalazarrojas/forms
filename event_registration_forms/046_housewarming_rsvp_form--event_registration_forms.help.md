> # housewarming_rsvp_form - Help Guide
## Purpose
The housewarming_rsvp_form is a simple form designed to collect guest information and housewarming details from event attendees.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the "Guest Information" page with your name and any other relevant details.
2. Move on to the "Housewarming Details" page and provide any additional information about the housewarming event.
3. On the final page, select "Attending" to indicate whether you will be attending the event.

## Field-by-Field Explanation
### Guest Information (Page 1)
* **Guest Information**: This page is where you provide your name and any other relevant details about yourself. Please fill out this page completely.
### Housewarming Details (Page 2)
* **Housewarming Details**: This page is where you provide additional information about the housewarming event. Please type in any notes or comments you have about the party.
### Attending (Page 3)
* **Attending**: This is a simple yes or no question to let us know if you will be attending the housewarming party. Select "True" if you will be attending and "False" otherwise. This field is required, so please make sure to answer accurately.
## Tips
* Make sure to answer the "Attending" question accurately, as it will help the host plan the event accordingly.
* You can type in any additional comments or information on the "Housewarming Details" page to make sure the host has all the necessary information.
* If you have any special requests or needs, please make sure to include them in the "Housewarming Details" page.
