# Corporate Fundraising Event Reservation Form - Help Guide
## Purpose
This form is used to register for corporate fundraising events organized by a partner company. Fill out this form to reserve a spot and provide necessary information for event planning.

## How To Complete This Form
1. **Fill out each section completely and accurately**.
2. **Submit the form once you have finished**.

## Field-by-Field Explanation

* **Event Details (id: 1)**: Please enter a brief description of the event.
* **Attendee Info (id: 2)**: Enter the name and contact information of the person attending the event.
* **Contact Info (id: 3)**: Enter the contact information of the person registering for the event.
* **Meal Preferences (id: 4)**: If you have dietary restrictions, please select the meal preference that best fits your needs. Options are:
	+ Yes
	+ No
* **Special Requests (id: 5)**: If you have any special requests for the event, please describe them here.
* **Company Details (id: 6)**: Enter any additional information about your company related to this event registration.
* **Payment Info (id: 7)**: Enter the payment method and details for this event registration.
* **Event Questions (id: 8)**: If you have any questions or comments about the event, please describe them here.

## Tips
* Make sure to fill out all required fields completely and accurately.
* If you have any questions or need help with filling out this form, contact the event organizers.
* If you are unable to attend, please cancel your registration to avoid any confusion.
