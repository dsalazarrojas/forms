# Pre Event Client Information Form - Help Guide
## Purpose
This form collects essential information from clients for event registration purposes.

## How To Complete This Form
1. Start by filling out the required fields: **Name**, **email**, **Phone**, and **Event Location**. These fields are marked as "required" and cannot be skipped.
2. Enter your **Event Date** (mm/dd/yyyy) and **Event Time** (12:00 PM) if you're registering for an event.
3. Select the assigned **Event Coordinator** from the dropdown list.
4. Optionally, add any additional **Event Details** if needed.
5. Provide any additional **Client Notes** regarding the event.
6. Select who submitted the form from the dropdown list.
7. Optionally, provide the **Event ID** if applicable.

## Field-by-Field Explanation

* **Name** (Text, Required): Enter your name as you would like to be listed for the event.
* **email** (Email, Required): Enter your valid email address.
* **Phone** (Text, Required): Enter your phone number in the format 123-456-1234.
* **Event Date** (Date, Optional): Enter the event date in the mm/dd/yyyy format (e.g., 12/01/2022).
* **Event Time** (Time, Optional): Enter the event time in the 12:00 PM format.
* **Event Location** (Text, Required): Enter the location of the event.
* **Event Details** (Text, Optional): Add any additional information about the event.
* **Client Notes** (Text, Optional): Enter any additional notes about the client.
* **Assigned Event Coordinator** (Select One, Optional): Select who will be coordinating the event.
* **Form Submitter** (Select One, Optional): Select who is submitting the form.
* **Event ID** (Select One, Optional): Enter the event ID (e.g., '23899').
* **Client Notes** is a text field to enter client specific notes. Please use this to provide additional notes about the client.
* **Assigned Event Coordinator Label** is a placeholder label for the coordinator's name.
* **Form Submitter Label** is a placeholder label for the submitters name.
* **Event Location** is required field and needs to have a valid address.
 
Note to the form designer: You may want to consider renaming "Client Notes" to something more specific like "Client Contact Information" to avoid confusion with the "Event Details" field.
