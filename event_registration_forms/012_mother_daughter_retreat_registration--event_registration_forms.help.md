# Mother Daughter Retreat Registration - Help Guide

## Purpose
The Mother-Daughter Retreat Registration form is designed for registering mother-daughter pairs for a special retreat. The form gathers necessary information to ensure a smooth and enjoyable experience for both mothers and daughters. Please complete this form to provide the required details for the retreat.

## How To Complete This Form
To complete this form, please follow these steps:

1. **Fill in each section** according to the explanations below.
2. Confirm your answers and submit the form.

## Field-by-Field Explanation

* **Event Details (mother_daughter_retreat_details)**: Enter a brief description of the event or retreat you are planning. This is an optional field.
* **Dates (mother_daughter_event_dates)**: Select the dates when the event will take place. Please choose both 'Yes' and 'No' options, indicating the time frame when the event will happen.
* **Consent (mother_daughter_event_consent)**: Confirm that you have obtained the necessary consent for your daughter to participate in the event.
* **Special Needs (mother_daughter_special_needs)**: If your daughter has any special needs or requirements, please specify them here. This is an optional field.
* **Additional Info (mother_daughter_additional_info)**: Enter any additional information you'd like to share about your daughter's needs or requirements. This is an optional field.
* **Retreat Type (mother_daughter_retreat_type)**: Choose the type of retreat you are planning (likely referring to the type of event or activity).
* **Organizer Details (mother_daughter_organizer_details)**: Provide any necessary details about the person or organization responsible for the event. This is an optional field.
* **Special Requests (mother_daughter_special_requests)**: If there are any special requests you have for the event organizers, please specify them here. This is an optional field.
* **Event Organizer (mother_daughter_event_organizer)**: Confirm if the event will have an organizer or leader. 
* **Organizer Email (mother_daughter_event_organizer_email)**: Enter the contact email of the event organizer. This is a required field.
* **Organizer Phone (mother_daughter_event_organizer_phone)**: Enter the contact phone number of the event organizer. This is an optional field.
* **Retreat Location (mother_daughter_retreat_location)**: Specify the location of the retreat. This is a required field.
* **Notes (mother_daughter_event_notes)**: Leave any additional notes or comments for the event organizers here. This is an optional field.
