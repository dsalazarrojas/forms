# scheduling_setup_and_customer_notification_form - Help Guide
## Purpose
This form is designed to collect customer information and schedule setup details for a specific event or appointment. It includes fields for customer contact information, appointment preferences, and scheduling details.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill in the **customer_info** field with the customer's name, address, and any other relevant contact information.
2. In the **appointment_details** field, provide a brief description of the scheduled event or appointment.
3. In the **notification_preferences** field, select how you would like to be notified:
	* By phone (text) only
	* By email only
	* By both phone (text) and email
	* By email and phone (text)
4. Enter the **schedule_date** field with the desired date for the event or appointment.
5. Select the **schedule_time** field with the preferred start time for the event or appointment.
6. Enter the **schedule_duration** field with the expected length of the event or appointment.
7. Choose the **schedule_time_of_day** field with the preferred start time for the event or appointment (e.g., AM, PM, etc.).
8. Enter the **schedule_start_date** field with the start date of the event or appointment.
9. Select the **schedule_start_time** field with the start time of the event or appointment.
10. Enter the **schedule_end_date** field with the end date of the event or appointment.
11. Select the **schedule_end_time** field with the end time of the event or appointment.
12. Enter the **customer_email** field with the customer's email address.
13. Enter the **customer_phone** field with the customer's phone number.

## Field-by-Field Explanation

* **customer_info**: Enter the customer's name, address, and any other relevant contact information.
* **appointment_details**: Provide a brief description of the scheduled event or appointment.
* **notification_preferences**: Select how you would like to be notified: by phone (text) only, by email only, by both phone (text) and email, or by email and phone (text).
* **schedule_date**: Enter the desired date for the event or appointment.
* **schedule_time**: Select the preferred start time for the event or appointment.
* **schedule_duration**: Enter the expected length of the event or appointment.
* **schedule_time_of_day**: Choose the preferred start time for the event or appointment (e.g., AM, PM, etc.).
* **schedule_start_date**: Enter the start date of the event or appointment.
* **schedule_start_time**: Select the start time of the event or appointment.
* **schedule_end_date**: Enter the end date of the event or appointment.
* **schedule_end_time**: Select the end time of the event or appointment.
* **customer_email**: Enter the customer's email address.
* **customer_phone**: Enter the customer's phone number.
