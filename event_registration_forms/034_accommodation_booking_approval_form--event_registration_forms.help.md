# Accommodation Booking Approval Form - Help Guide

## Purpose
The Accommodation Booking Approval Form is used to collect and approve accommodation requests for events and conferences.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in your name and email address as the person requesting the accommodation.
2. Enter the name and date of the event requiring accommodation.
3. Choose the accommodation type you need (e.g., Single Room, Double Room, etc.).
4. Indicate the number of guests requiring accommodation.
5. Select whether the accommodation budget has been approved.
6. If approved, enter the budget amount allocated for the accommodation.
7. Enter the name and address of the accommodation provider.
8. Add any additional comments or details about the booking.

## Field-by-Field Explanation

* **Requester Name** (`requester_name`, text, required): Enter your full name as the person requesting the accommodation.
* **Requester Email** (`requester_email`, email, required): Enter your email address as the person requesting the accommodation.
* **Requester Phone** (`requester_phone`, text, required): Enter your phone number as the person requesting the accommodation.
* **Event Name** (`event_name`, text, required): Enter the name of the event for which accommodation is being requested.
* **Event Date** (`event_date`, date, required): Enter the date of the event.
* **Check In Date** (`check_in_date`, date, required): Enter the date when accommodation is needed.
* **Check Out Date** (`check_out_date`, date, required): Enter the date when accommodation is no longer needed.
* **Accommodation Type** (`accommodation_type`, select_one, required): Choose the type of accommodation you require (e.g., Single Room, Double Room, etc.).
* **Number of Guests** (`number_of_guests`, number, required): Enter the total number of people requiring accommodation.
* **Special Accommodation Needs** (`special_accommodation_needs`, text, optional): If you have any special requirements for the accommodation, enter them here.
* **Budget Approved** (`budget_approved`, select_one, required): Select whether the accommodation budget has been approved.
* **Budget Amount** (`budget_amount`, number, optional): If approved, enter the approved budget amount for accommodation.
* **Accommodation Provider** (`accommodation_provider`, text, required): Enter the name of the hotel or accommodation provider.
* **Accommodation Address** (`accommodation_address`, text, required): Enter the address of the accommodation.
* **Booking Reference Number** (`booking_reference_number`, text, optional): If available, enter the reference number for the booking.
* **Approval Status** (`approval_status`, select_one, required): Select the current status of the booking approval (e.g., Pending, Approved, etc.).
* **Approval Reason** (`approval_reason`, text, optional): If the booking is not approved, enter the reason for denial.
* **Approved By** (`approved_by`, text, optional): If approved, enter the name of the person approving the booking.
* **Approval Date** (`approval_date`, date, optional): If approved, enter the date when approval was granted.
* **Additional Comments** (`additional_comments`, text, optional): Add any additional comments about the booking.

Note: The Accommodation Booking Approval Form is a critical part of the event planning process, and accurate completion of this form ensures that all necessary information is captured and approved before making any bookings.
