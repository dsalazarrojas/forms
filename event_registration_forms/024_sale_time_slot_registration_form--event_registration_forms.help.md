# Sale Time Slot Registration Form - Help Guide
## Purpose
The Sale Time Slot Registration Form is used to register sale time slots for sales-related activities. This form helps ensure that all necessary information is collected and stored accurately, preventing duplication and errors.

## How To Complete This Form
To complete this form, follow these steps:

1. Complete all the required fields on each page.
2. Enter your details in the **Sale Details** page (page 1).
3. Enter the customer's details in the **Customer Details** page (page 2).
4. Indicate whether time slots are available or not in the **Time Slot Available** page (page 3).
5. Select the sale time slot in the **Sale Time Slot** page (page 4).
6. Enter any contact details in the **Contact Details** page (page 5).
7. Select any sale time slot options in the **Sale Time Slot Options** page (page 6).

## Field-by-Field Explanation

* **Sale Details** (`sale_details`, text, required): Enter the details of the sale, such as the sale type and any specific information related to the sale.
* **Customer Details** (`customer_details`, email, required): Enter the customer's email address. This is a required field to ensure that the customer can be contacted.
* **Time Slot Available** (`time_slot_available`, select_one, required): Indicate whether time slots are available or not. This field is used to determine the status of the time slot.
* **Sale Time Slot** (`sale_time_slot`, date, required): Select the sale time slot from the available options.
* **Contact Details** (`contact_details`, text, required): Enter any contact details for the customer, such as their phone number or address.
* **Sale Time Slot Options** (`sale_time_slot_options`, select_multiple, required): Select any sale time slot options from the available choices.
