# Sponsorship Package Delivery Form - Help Guide
## Purpose
The Sponsorship Package Delivery Form is a crucial document for recording and tracking sponsorship package details. It helps to maintain accurate records and facilitate smooth communication between the sponsor and the event organizers. This form ensures that all necessary information is captured and delivered to the correct parties.

## How To Complete This Form
1. **Fill out the form completely**: Enter all required fields, including the sponsor's name, delivery method, and delivery details.
2. **Select the correct sponsorship package**: Choose the relevant sponsorship package from the available options.
3. **Specify the delivery method and date**: Choose the preferred delivery method and specify the delivery date and time.
4. **Provide contact information**: Enter the sponsor's contact number and email address.
5. **Enter event details**: Select the relevant event name, event type, and event status.
6. **Enter delivery address**: Provide the delivery address, city, state, zip, and country details.

## Field-by-Field Explanation
* **User email**: Enter a valid email address for communication purposes.
* **Sponsor name**: Enter the name of the sponsor or organization providing the sponsorship package.
* **Delivery method**: Select the method of delivery, which can be Airborne, Ground, or Courier.
* **Delivery date**: Specify the date of delivery in the format MM/DD/YYYY.
* **Delivery time**: Specify the time of delivery in the format HH:MM.
* **Event name**: Select the name of the event from the available options.
* **Contact number**: Enter the sponsor's contact number for communication purposes.
* **Notes**: Enter any additional notes or comments about the sponsorship package.
* **Form submitted by**: Enter the name of the person submitting the form.
* **Event type**: Select the type of event, which can be Type A, Type B, or Type C.
* **Event status**: Select the status of the event, which can be Status A, Status B, or Status C.
* **Delivery address**: Enter the address where the sponsorship package will be delivered.
* **Delivery city**: Enter the city where the sponsorship package will be delivered.
* **Delivery state**: Enter the state where the sponsorship package will be delivered.
* **Delivery zip**: Enter the zip code where the sponsorship package will be delivered.
* **Delivery country**: Enter the country where the sponsorship package will be delivered.
* **Delivery street**: Enter the street where the sponsorship package will be delivered.
* **Event organizer**: Enter the name of the event organizer (optional).
* **Non-profit**: Check if the sponsor is a non-profit organization (optional).
* **Delivery date range**: Specify the date range of delivery (optional).
* **Delivery time range**: Specify the time range of delivery (optional).
* **Sponsorship package**: Select the relevant sponsorship package from the available options.
* **Event venue**: Enter the venue where the event will be held (optional).
* **Delivery method details**: Enter any additional details about the delivery method (optional).
* **Additional notes**: Enter any additional comments or notes about the sponsorship package (optional).
