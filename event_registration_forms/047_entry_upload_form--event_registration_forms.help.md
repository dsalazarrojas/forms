# Entry Upload Form - Help Guide
## Purpose

This form is used to upload entries, allowing users to provide relevant information about the uploaded files. It is a minimalistic form with only three fields.

## How To Complete This Form

1. **Upload File**: Please select the file you wish to upload from your local device. This field is optional, meaning you don't have to provide a file if you don't want to.
2. **Name Of Upload**: Enter a name or title for the uploaded file. This field is also optional, and it's a free-form text input.
3. **Date Of Upload**: If you want to provide a date for the uploaded file, you can select it from the calendar. This field is optional as well.

## Field-by-Field Explanation

* **Upload File** (`upload_file`, text, optional): Upload a file from your local device. You can choose any type of file you like, but please ensure it's relevant to the entry you're uploading.
* **Name Of Upload** (`name_of_upload`, text, optional): Give a title or name to the uploaded file. This will help identify the file and make it easier to find later.
* **Date Of Upload** (`date_of_upload`, date, optional): If you have a specific date associated with the uploaded file, select it from the calendar. This will help with organization and tracking.

## Tips

* Make sure to provide accurate and relevant information about the uploaded file, especially in the "Name Of Upload" field.
* If you're unsure about any of the fields, feel free to contact form@gic.mx for assistance.
