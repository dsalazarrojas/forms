# Performance Venue Partnership Application Form - Help Guide
## Purpose
The Performance Venue Partnership Application Form is designed to collect information from artists and venue partners who want to collaborate for events or performances. This guide will walk you through each field and how to fill out the form accurately.

## How to Complete This Form
To complete the form, please go through each section carefully and fill out the required information. The form is divided into several fields, each with a specific purpose. You can fill out the form in any order, but it's recommended to complete it from top to bottom for clarity.

## Field-by-Field Explanation
### Venue Name
* **Venue Name** (text, required): Enter the name of the venue where the event will take place.

### Venue Address
* **Venue Address** (text, required): Provide the address of the venue where the event will occur. This will help the partnership coordinators contact you if needed.

### Contact Phone
* **Contact Phone** (text, required): Enter a valid phone number where you can be reached for further information or questions.

### Contact Email
* **Contact Email** (email, required): Enter a valid email address where you can be reached for further information or questions.

### Venue Type
* **Venue Type** (select_one, required): Select the type of venue where the event will take place (e.g., Theater, Bar, Park).

### Performance Dates
* **Performance Dates** (date, required): Enter the dates when the event will occur. Use the format: MM/DD/YYYY.

### Performance Time
* **Performance Time** (time, required): Enter the start and end time of the performance. Use the format: HH:MM (24-hour format).

### Application Notes
* **Application Notes** (note, optional): If you have any additional information or comments, you can add it here.

### Artist Contact Info
* **Artist Contact Info** (text, optional): Provide any relevant contact information for the artist or team members involved in the event.

### Event Details
* **Event Details** (text, optional): Give a brief description of the event, including the type of performance, expected audience size, and any other relevant details.

### Partnership Terms
* **Partnership Terms** (text, optional): If you have any specific requirements or expectations for the partnership, list them here.

### Artist Agreement
* **Artist Agreement** (select_multiple, required): Select all agreements that apply (Accept, Reject).

Note: This form is for partnership applications and is not intended for event ticket sales or general contact information.
