# Event Merit Form - Help Guide
## Purpose
This form is used to register an event with the system, ensuring its inclusion in the event calendar.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out all the required fields, which are marked with an asterisk (*).
2. Be as accurate and complete as possible when filling out the form.
3. If you are unsure about any field, please contact the event organizer or refer to the provided hints.

## Field-by-Field Explanation

* **Event Organizer (*)**: Enter the name of the person or organization responsible for the event.
* **Event Name (*)**: Enter the name of the event, which will be displayed in the event calendar.
* **Event Date (*)**: Enter the date of the event in the format MM/DD/YYYY.
* **Event Time (*)**: Enter the time of the event in the format HH:MM AM/PM.
* **Event Location (*)**: Enter the physical location of the event.
* **Sponsor Name (*)**: Enter the name of the person or organization sponsoring the event.
* **Sponsor Email (*)**: Enter the email address of the sponsor.
* **Sponsor Phone (*)**: Enter the phone number of the sponsor.
* **Sponsorship Details (*)**: Enter any additional details about the sponsorship.
* **Sponsor Address**: This field is optional and can be used to provide a physical address for the sponsor.
* **Sponsor Website**: This field is optional and can be used to provide a website for the sponsor.
* **Payment Method**: Select the method of payment for the sponsorship (Bank Transfer, Check, or Other).
* **Payment Terms**: This field is optional and can be used to specify any terms or conditions for payment.
* **Notes**: This field is optional and can be used to provide any additional notes or comments about the event.
* **Submit**: Click this button to submit the form after filling out all required fields.
* **Confirm**: Confirm that you have accurately filled out the form before submitting.
