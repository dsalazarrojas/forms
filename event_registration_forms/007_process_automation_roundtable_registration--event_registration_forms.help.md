# Process Automation Roundtable Registration - Help Guide
## Purpose
This form is designed to register attendees for a roundtable event on process automation. The event provides a platform for attendees to discuss and learn about process automation-related topics.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out each field with the required information.
2. Review your responses before submitting the form.
3. Ensure that all required fields are filled out.
4. Click the submit button to register for the event.

## Field-by-Field Explanation

* **Event Date (1)** (`event_date`, date, required: false)
This field collects the date of the event. Choose the date for which you wish to register.
* **Event Time (2)** (`event_time`, time, required: false)
This field collects the time of the event. Select the time slot for which you wish to register.
* **Event Topic (3)** (`event_topic`, select_one, required: false)
This field indicates your interest in the event topic. Select 'Yes' if you are interested in the event topic, 'No' otherwise.
* **Attendee Name (4)** (`attendee_name`, text, required: false)
This field collects your name as an attendee. Please fill this field with your name as it should appear on our registration list.
* **Attendee Email (5)** (`attendee_email`, email, required: false)
This field collects your email address as an attendee. Please fill this field with a valid email address.
* **Attendee Phone (6)** (`attendee_phone`, text, required: false)
This field collects your phone number as an attendee. Please fill this field with your phone number.
* **Participation Consent (7)** (`participation_consent`, select_one, required: false)
This field indicates your consent to participate in the event. Select 'Yes' if you agree to participate, 'No' otherwise.
* **Topic Interests (8)** (`topic_interests`, select_multiple, required: false)
This field indicates the topics you are interested in. Select all relevant topics that interest you.
* **Additional Comments (9)** (`additional_comments`, text, required: false)
This field provides an opportunity for you to add any additional comments or information about your registration.

Note: If any field is marked as required, please ensure it is filled out. Failure to do so may result in your registration not being processed correctly.
