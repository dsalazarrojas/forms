# Motorsport Event Tracker - Help Guide
## Purpose
This form is used to track motorsport events, providing a comprehensive platform to collect and store event details.

## How To Complete This Form
1. Fill in the event details, including event name, date, description, and location.
2. Select the event category and status.
3. Choose the event results and registrations.
4. Enter notes and tags for the event.
5. Add any relevant files or links associated with the event.
6. Update the event status as needed.

## Field-by-Field Explanation

* **Event Details** (`event_details`): Enter a brief description of the event.
* **Event Name** (`event_name`): Enter the name of the event.
* **Date** (`date`): Enter the date of the event.
* **Event Location** (`event_location`): Enter the location of the event.
* **Event Description** (`event_description`): Enter a detailed description of the event.
* **Event Time** (`event_time`): Enter the start and end time of the event.
* **Event Category** (`event_category`): Select the type of motorsport event (e.g., 'Yes' for yes or 'No' for no).
* **Event Status** (`event_status`): Select the current status of the event (e.g., 'Active' or 'Inactive').
* **Event Result** (`event_result`): Select the outcome of the event (e.g., 'Yes' for yes or 'No' for no).
* **Incident Notes** (`incident_notes`): Enter any notes related to incidents or issues that occurred during the event.
* **Event Organizer** (`event_organizer`): Enter the name of the event organizer.
* **Event Sponsor** (`event_sponsor`): Enter the name of the event sponsor.
* **Event Venue** (`event_venue`): Select the event venue (e.g., 'Yes' for yes or 'No' for no).
* **Event Registrations** (`event_registrations`): Select whether the event has registrations (e.g., 'Yes' for yes or 'No' for no).
* **Event Notes** (`event_notes`): Enter notes about the event.
* **Event Tags** (`event_tags`): Select the event tags (e.g., 'Yes' for yes or 'No' for no).
* **Event File** (`event_file`): Upload any relevant files or link to the event file.
* **Event URL** (`event_url`): Enter the URL associated with the event.
* **Event Status Update** (`event_status_update`): Enter any status updates related to the event.
* **Event Category ID** (`event_category_id`): Enter the category ID.
* **Event Venue ID** (`event_venue_id`): Enter the venue ID.
* **Event Registrations ID** (`event_registrations_id`): Enter the registrations ID.
* **Event Tags ID** (`event_tags_id`): Enter the tags ID.
* **Event File ID** (`event_file_id`): Enter the file ID.
* **Event URL ID** (`event_url_id`): Enter the URL ID.

Note: Some fields may have specific instructions or requirements. Please refer to the relevant sections for more information on each field.
