# Topic Suggestion Form For Sharing Session - Help Guide
## Purpose
The purpose of this form is to collect suggestions for sharing sessions from users. To provide relevant and useful topics, please make sure the suggestions are related to the session you are attending.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill out the form on each page according to the provided fields.
2. Make sure to provide a brief explanation for each suggested topic.
3. Indicate whether or not the topic is already assigned to a tool.

## Field-by-Field Explanation

* **Topic Suggestion Form For Sharing Session** (`event_registration_forms_s1`, text, required): Please enter a brief explanation for the topic you are suggesting for the sharing session.
* **Topic Suggestion Form For Sharing Session** (`sharing_session_topics_suggested`, text, required): Enter a brief description of the topic you are suggesting for the sharing session. This field is required.
* **Assigned Tool** (`assigned_tool`, select_one, optional): Check "Yes" if the topic is already assigned to a tool, or "No" if it's not.
* **Event Registration Forms S2** (`event_registration_forms_s2`, text, optional): Please enter any additional information related to the event registration forms for the sharing session.

## Tips
* Make sure to provide clear and concise descriptions for each suggested topic.
* Avoid duplicating suggestions, as the goal is to suggest unique topics.
* If you're unsure about what to suggest, refer to the session's purpose or discussion points for inspiration.
