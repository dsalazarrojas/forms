# Fullscreen Event RSVP Responsive Form - Help Guide
## Purpose
This form is designed to collect RSVP information from event attendees, providing the organizer with essential details about the event, such as the number of attendees, event description, and event date and time.

## How To Complete This Form
To complete this form, follow these steps:

1.  Fill out the RSVP Information section with your name and contact information.
2.  Provide a detailed description of the event in the Event Details section.
3.  Choose the number of people attending in the Event RSVP section.
4.  If necessary, add any additional information about the event in the Additional Information section.
5.  Summarize the event in a few words in the Summary section.
6.  Confirm your event registration in the Event Registration section by selecting one of the provided options.
7.  Confirm your RSVP in the Confirm RSVP section by selecting 'Yes' or 'No'.
8.  Input the event date and time in the Event Date and Event Time sections.

## Field-by-Field Explanation
### RSVP Information
*   **Name (text, required):** Fill in your name to let the event host know who you are.
*   **Contact Information (text, required):** Provide your contact information, such as phone number or email, in case the host needs to reach you.
*   **Event Details (text, required):** Describe the event in detail so that the host can get a clear understanding of what to expect.
*   **Event RSVP (select_one, required):** Choose the number of people attending the event.
*   **Additional Information (text, optional):** Add any extra details you want to share with the host about the event.
*   **Summary (text, required):** Write a short summary of the event in a few words.
*   **Event Registration (checkbox, required):** Confirm your event registration by selecting one of the provided options.
*   **Submit RSVP (radio, required):** Confirm your RSVP by selecting one of the provided options.
*   **Confirm RSVP (checkbox, required):** Confirm your attendance by selecting 'Yes' or 'No'.
*   **Event Date (date, required):** Input the date of the event.
*   **Event Time (time, required):** Input the start and end time of the event.

## Tips
*   Make sure to fill out all the required fields correctly to ensure the host has accurate and complete information about your attendance.
*   Be detailed in the Event Details and Summary sections to help the host plan the event effectively.
