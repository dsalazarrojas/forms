# Annual Event Donation Form - Help Guide
## Purpose
This form is designed to collect information from donors about their annual event donations. It helps to ensure that all necessary details are captured for accurate and efficient donation processing and event planning.

## How To Complete This Form
1. Fill in your name and select your donor type (individual or organization).
2. Provide your contact email address.
3. Select the event you are supporting.
4. Choose the type of donation (monetary or in-kind).
5. If making an in-kind donation, describe it.
6. If you would like to be recognized, select your preference.
7. Indicate if you need a tax receipt.
8. If sponsoring, choose your sponsorship level.
9. If applicable, enter the estimated value of your in-kind donation.
10. Choose your payment method.
11. If applicable, select your credit card type.
12. If your donation is in honor or memory of someone, provide the name(s).
13. If you want to be recognized, select your preference.
14. If you need a receipt, select yes or no.
15. Indicate if your employer will match your donation.
16. If you are interested in volunteering, select yes or no.
17. Select if you want to receive marketing communications.
18. Finally, select all that apply for how you heard about us.

## Field-by-Field Explanation

* **Donor Name (1)**: Enter your name as it appears on your identification.
* **Donor Type (2)**: Select individual or organization to indicate your type of donor.
* **Organization Name (3)**: If you are an organization, enter your official name.
* **Email Address (4)**: Enter your contact email address.
* **Phone Number (5)**: Enter your best contact number.
* **Mailing Address (6)**: Provide your full address for receipt purposes.
* **Event Name (7)**: Select the event you are supporting.
* **Event Date (8)**: Enter the date of the event.
* **Donation Type (9)**: Choose the type of donation you are making (monetary or in-kind).
* **Donation Amount (10)**: Enter the amount of your donation.
* **Donation Frequency (11)**: Select how often you would like to donate (one-time, monthly, quarterly, or annually).
* **Sponsorship Level (12)**: If sponsoring, choose the sponsorship level.
* **In-Kind Description (13)**: Describe your in-kind donation.
* **Estimated Value (14)**: Enter the estimated value of your in-kind donation.
* **Payment Method (15)**: Choose your payment method (credit card, debit card, check, bank transfer, etc.).
* **Card Type (16)**: If using a credit or debit card, select the type (Visa, MasterCard, American Express, Discover, etc.).
* **In Honor or Memory Of (17)**: If your donation is in honor or memory of someone, enter their name(s).
* **Recognition Preference (18)**: Select how you would like to be recognized (publicly, anonymously, name only, etc.).
* **Receipt Needed (19)**: Indicate if you need a receipt.
* **Employer Matching (20)**: Check if your employer will match your donation.
* **Volunteer Interest (21)**: Select if you are interested in volunteering.
* **Marketing Communications (22)**: Select if you want to receive marketing communications.
* **How Did You Hear About Us (23)**: Select all that apply for how you heard about us.
* **Additional Comments (24)**: Provide any additional information you would like to share.
