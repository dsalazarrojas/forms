# HR Data Governance Forum Registration Form - Help Guide
## Purpose
The HR Data Governance Forum Registration Form is used to collect information about event registrations for the HR department.

## How To Complete This Form

1. Enter the event title in the "Event Registration Form" field.
2. Select the event time zone in the "Time Zone" field.
3. Choose the event topic in the "Event Topic" field.
4. Add any additional notes or details in the "Note" field.
5. Click the "Submit" button to complete the form.

## Field-by-Field Explanation

* **Event Registration Form**: Enter the title of the event you are registering for. This is the main title of the event.
* **Name**: Enter your name as you would like it to be displayed on the event registration. This field is not required.
* **Email**: Enter your email address for contact purposes. This field is not required.
* **Phone**: Enter your phone number for contact purposes. This field is not required.
* **Time**: Enter the time of the event. This field is not required.
* **Date**: Enter the date of the event. This field is not required.
* **Time Zone**: Select the time zone of the event location. This field is not required.
* **Timezone**: Enter the time zone offset from UTC. This field is not required.
* **Select Multiple**: Select one or more options from the provided list. This field is not required.
* **Note**: Add any additional notes or details about the event. This field is not required.
* **Event Type**: Select the type of event (e.g. "Type 1", "Type 2", etc.). This field is not required.
* **Event Details**: Enter any additional details about the event. This field is not required.
* **Session Details**: Enter any additional details about the session. This field is not required.
* **Session Start**: Enter the start time of the session. This field is not required.
* **Session End**: Enter the end time of the session. This field is not required.
* **Event Start**: Enter the start date of the event. This field is not required.
* **Event End**: Enter the end date of the event. This field is not required.
* **Attendees Count**: Enter the number of attendees expected. This field is not required.
* **Attendees List**: Enter a list of attendees expected. This field is not required.
* **Attendees Interest**: Enter any special interest or requirements of the attendees. This field is not required.
* **Session Topic**: Select the topic of the session. This field is not required.
* **Session Duration**: Enter the duration of the session. This field is not required.
* **Session Time**: Enter the time of the session. This field is not required.
* **Event Topic**: Select the topic of the event. This field is not required.
* **Submit**: Click this button to complete and submit the form.
