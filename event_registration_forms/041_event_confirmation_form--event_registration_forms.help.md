# event_confirmation_form - Help Guide
## Purpose
The event_confirmation_form is designed to collect information about past or upcoming events, making it easier to track and manage event details.

## How To Complete This Form
To fill out this form, follow these steps:

1. Enter the title of the event in the **event_confirmation_form** field.
2. Select the date of the event by using the date picker or typing it manually in the **date_of_event** field.
3. Enter the time of the event in the **time_of_event** field.
4. Estimate the number of expected attendees in the **expected_attendees** field.
5. If you can, provide an update on the actual number of attendees that attended in the **actual_attendees** field.

## Field-by-Field Explanation

* **event_confirmation_form** (event_confirmation_form_page, text, required): Enter a brief title of the event to help identify and reference it.
* **date_of_event** (date_of_event, date, required): Select or input the date when the event took place or is scheduled to occur.
* **time_of_event** (time_of_event, time, required): Enter the time of the event in 24-hour format.
* **expected_attendees** (expected_attendees, number, required): Estimate the expected number of attendees for the event.
* **actual_attendees** (actual_attendees, text, required): If available, provide an update on the actual number of attendees that attended the event.

## Tips

* Make sure to fill out the form accurately and consistently to ensure the event details are up-to-date.
* If you're unsure about any of the fields, refer to your event planning documentation or reach out to the event organizer for clarification.
* Double-check your inputs before submitting the form to ensure everything is correct.
* If you have any issues or questions while filling out the form, contact the form administrator for assistance.
