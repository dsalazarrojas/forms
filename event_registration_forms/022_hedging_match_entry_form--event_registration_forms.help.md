# hedging_match_entry_form - Help Guide
## Purpose
The hedging match entry form is used to register an entry in a hedging match, a risk management tool used by financial institutions to mitigate risk in a portfolio by using a derivative instrument.

## How To Complete This Form
To complete this form, follow these steps:
1. Select the "hedge_type" field to specify the type of hedge you want to register (Long Hedge, Short Hedge, Market Hedge, or Other).
2. Choose the "underlying_asset" field to select the type of asset being hedged (Stock, Bond, Currency, or Other).
3. In the "match_timing" field, enter the date of the match.
4. If applicable, enter the "match_start_time" field with the start time of the match.

## Field-by-Field Explanation
- **Hedge Type** (`hedge_type`, select_one, required/optional): Select the type of hedge you want to register (Long Hedge, Short Hedge, Market Hedge, or Other).
- **Underlying Asset** (`underlying_asset`, select_multiple, required/optional): Choose the type of asset being hedged (Stock, Bond, Currency, or Other).
- **Match Timing** (`match_timing`, date, required/optional): Enter the date of the match.
- **Match Start Time** (`match_start_time`, time, required/optional): Enter the start time of the match, if applicable.

## Tips
- Double-check that you have selected the correct hedge type and underlying asset to ensure accurate and consistent data entry.
- Enter the match timing and start time carefully to avoid errors.
- Review and approve the form before submission to ensure accuracy and relevance.
