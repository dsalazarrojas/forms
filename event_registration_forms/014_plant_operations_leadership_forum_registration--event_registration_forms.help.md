# plant_operations_leadership_forum_registration - Help Guide
## Purpose
This form is designed to collect information from attendees and organizers for the plant operations leadership forum. It includes fields for event details, attendee information, session interests, and accessibility needs.

## How To Complete This Form
To complete this form, simply follow the instructions below.

## Field-by-Field Explanation
### 1. **Event Details** (text, required)
* This field is where you should provide a brief description of the event, including any relevant information such as date, time, and location.

### 2. **Attendee Details** (text, optional)
* This field is for providing any additional information about the attendee, such as name, email, or contact number.

### 3. **Session Interests** (select multiple, required)
* Select all the sessions that you are interested in attending. Please note that this field allows you to choose multiple sessions.

### 4. **Accessibility Needs** (text, optional)
* If you have any accessibility needs or requirements, please describe them in this field. This information will help us provide better accommodations for you during the event.

## Tips
* Please ensure that you have selected all relevant session interests to ensure you receive notifications and reminders.
* If you have any special accessibility needs, please describe them clearly in the Accessibility Needs field.
* If you have any questions or concerns, please contact us at form@gic.mx.
