# Manuscript Demonstration Form - Help Guide
## Purpose
The Manuscript Demonstration Form is used to register and showcase manuscripts, providing essential details about the manuscript, its status, location, and other relevant information.

## How To Complete This Form

1. Fill in the following information:
	* **Form Title (1)**: A brief title describing the manuscript.
	* **First Name (2)**: Your first name.
	* **Last Name (3)**: Your last name.
	* **Manuscript Title (4)**: A brief title of the manuscript.
	* **Author (5)**: The author of the manuscript.
	* **Manuscript Status (6)**: The current status of the manuscript, such as "Is a draft" or "Published".
	* **Dissertation Date (7)**: The date of the manuscript's demonstration.
2. Choose the following options:
	* **Manuscript Status (6)**: Select "Is a draft" or "Published" for the manuscript's status.
	* **Is Event (12)**: Select "True" if the manuscript is an event, "False" otherwise.
	* **Is Public (13)**: Select "True" if the manuscript is public, "False" otherwise.
	* **Is Free (14)**: Select "True" if the manuscript is free, "False" otherwise.
	* **Is Discount (16)**: Select "True" if the manuscript is on discount, "False" otherwise.
3. Fill in the following information (if required):
	* **Manuscript Description (10)**: A short description of the manuscript.
	* **Address (20)**: The address related to the manuscript.
	* **City (22)**: The city related to the manuscript.
	* **State (23)**: The state related to the manuscript.
	* **Country (24)**: The country related to the manuscript.
4. Fill in the following if applicable:
	* **Price (15)**: The price of the manuscript.
	* **Discount Price (17)**: The price of the manuscript with discount.
	* **Phone (19)**: The phone number related to the manuscript.
	* **Postal Code (21)**: The postal code related to the manuscript.

## Field-by-Field Explanation

* **Form Title (1)** (`form_title`, text, optional): A brief title describing the manuscript.
* **First Name (2)** (`form_first_name`, text, optional): Your first name.
* **Last Name (3)** (`form_last_name`, text, optional): Your last name.
* **Manuscript Title (4)** (`form_manuscript_title`, text, optional): A brief title of the manuscript.
* **Author (5)** (`form_author`, text, optional): The author of the manuscript.
* **Manuscript Status (6)** (`form_manuscript_status`, text, optional): The current status of the manuscript.
* **Dissertation Date (7)** (`form_demonstration_date`, date, optional): The date of the manuscript's demonstration.
* **Is a Draft (8)** (`form_is_draft`, select_one, optional): Select "Is a draft" if the manuscript is a draft, "Published" otherwise.
* **Dissertation Location (9)** (`form_demonstration_location`, text, optional): The location of the manuscript's demonstration.
* **Manuscript Description (10)** (`form_manuscript_description`, text, optional): A short description of the manuscript.
* **Additional Notes (11)** (`form_additional_notes`, note, optional): Any additional notes related to the manuscript.
* **Is Event (12)** (`form_is_event`, select_one, optional): Select "True" if the manuscript is an event, "False" otherwise.
* **Is Public (13)** (`form_is_public`, select_one, optional): Select "True" if the manuscript is public, "False" otherwise.
* **Is Free (14)** (`form_is_free`, select_one, optional): Select "True" if the manuscript is free, "False" otherwise.
* **Price (15)** (`form_price`, number, optional): The price of the manuscript.
* **Is Discount (16)** (`form_is_discount`, select_one, optional): Select "True" if the manuscript is on discount, "False" otherwise.
* **Discount Price (17)** (`form_discount_price`, number, optional): The price of the manuscript with discount.
* **Email (18)** (`form_email`, email, optional): The email related to the manuscript.
* **Phone (19)** (`form_phone`, text, optional): The phone number related to the manuscript.
* **Address (20)** (`form_address`, text, optional): The address related to the manuscript.
* **Postal Code (21)** (`form_postal_code`, text, optional): The postal code related to the manuscript.
* **City (22)** (`form_city`, text, optional): The city related to the manuscript.
* **State (23)** (`form_state`, text, optional): The state related to the manuscript.
* **Country (24)** (`form_country`, text, optional): The country related to the manuscript.
* **Agree (25)** (`form_agree`, select_multiple, optional): Select "I have read and agreed to the terms and conditions" or "I have not read and agreed to the terms and conditions".
