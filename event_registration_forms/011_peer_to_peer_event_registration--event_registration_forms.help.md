# Peer To Peer Event Registration - Help Guide

## Purpose
This form is designed to collect necessary information from attendees for peer-to-peer events, which are events where attendees can interact and learn from each other.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the event title and description.
2. Select the start and end dates for the event.
3. Provide the location of the event.
4. Select all roles that apply to the event (e.g. speaker, moderator, attendee).
5. Choose your role preferences (e.g. Yes/No).
6. Select all event tags that apply (e.g. workshop, conference, meetup).
7. Choose all organizers that will be managing the event.
8. Select all options that apply for attendee details (e.g. name, email, phone number).
9. Choose the type of event (e.g. in-person, virtual).
10. Select the event status (e.g. Active, Inactive).
11. Decide if food will be provided.
12. Decide if a babysitter will be provided.
13. Select all event tags that apply.
14. Choose all organizers that will be managing the event.
15. Select all options that apply for attendee details.

## Field-by-Field Explanation

* **Event Title** (`event_title`, text, optional): A brief description of the event.
* **Event Description** (`event_description`, text, optional): A detailed description of the event.
* **Start Date** (`start_date`, date, optional): The start date of the event.
* **End Date** (`end_date`, date, optional): The end date of the event.
* **Location** (`location`, text, optional): The location of the event.
* **Roles** (`roles`, select_multiple, optional): Select all roles that apply (e.g. speaker, moderator, attendee).
* **Roles Options** (`roles_options`, text, optional): Please select all roles that apply.
* **Role Preferences** (`role_preferences`, select_one, optional): Choose your role preferences (e.g. Yes/No).
* **Consent** (`consent`, select_one, optional): Choose to give consent (e.g. Yes/No).
* **Attendee Details** (`attendee_details`, select_one, optional): Choose to provide attendee details (e.g. Yes/No).
* **Attendee Details Options** (`attendee_details_options`, text, optional): Please provide attendee details.
* **Event Type** (`event_type`, select_one, optional): Choose the type of event (e.g. in-person, virtual).
* **Event Status** (`event_status`, select_one, optional): Choose the event status (e.g. Active, Inactive).
* **Has Food** (`has_food`, select_one, optional): Decide if food will be provided (e.g. Yes/No).
* **Has Babysitter** (`has_babysitter`, select_one, optional): Decide if a babysitter will be provided (e.g. Yes/No).
* **Event Tags** (`event_tags`, select_multiple, optional): Select all event tags that apply (e.g. workshop, conference, meetup).
* **Event Tags Options** (`event_tags_options`, text, optional): Please select all event tags that apply.
* **Organizers** (`organizers`, select_multiple, optional): Choose all organizers that will be managing the event.
* **Organizers Options** (`organizers_options`, text, optional): Please select all organizers that apply.
