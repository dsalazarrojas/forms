# Incentive Program Registration - Help Guide
## Purpose
The Incentive Program Registration form is used to collect information about incentive programs submitted for registration. This form helps us to track and process these submissions efficiently.

## How To Complete This Form
- Fill out all required fields (marked as "required" in the form).
- Enter accurate and complete information in each field.
- Ensure all date fields are in the correct format (mm/dd/yyyy).

## Field-by-Field Explanation
- **Program Information**: Provide a brief description of the incentive program.
  * **First Name**: Enter the first name of the contact person associated with the program.
  * **Program Name**: Enter the name of the incentive program.
  * **Program Date**: Enter the date of the program (mm/dd/yyyy).
  * **Program Type**: Select the type of program (Incentive Program or Program).
  * **Contact Person**: Enter the name of the person associated with the program.
  * **Contact Email**: Enter the email of the contact person.
  * **Phone**: Enter the phone number of the contact person.
  * **Organization**: Enter the name of the organization associated with the program.
  * **Department**: Enter the department of the organization associated with the program.
  * **Address**: Enter the address of the organization.
  * **City**: Enter the city of the organization's address.
  * **State**: Select the state where the organization is located (California, New York, Florida).
  * **Zip**: Enter the zip code of the organization's address.
  * **Comments**: Enter any additional comments about the program.
  * **Submission Date**: This will auto-fill upon form submission, indicating the date of submission.
  * **Submitted By**: Enter the name of the person submitting the form.
  * **Submitted**: This will auto-fill upon form submission, indicating the date of submission.

# Tips
- Double-check all fields before submitting the form to ensure accurate and complete information.
- If you have any doubts or questions about the form, contact the relevant authorities for clarification.
