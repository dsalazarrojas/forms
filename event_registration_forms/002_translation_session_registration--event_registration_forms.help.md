# Translation Session Registration - Help Guide
## Purpose
This form is used to register and manage translation sessions.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the Session Registration Form section.
2. Specify whether the session has a language pair.
3. Input the session date and start/end time.
4. Select the participant's language pair (if applicable).
5. Provide the participant's name, email, and availability.
6. Input the coordinator's name, email, and phone number.
7. Update the session status.
8. Add any participant and coordinator comments.
9. Provide the session location and session notes.
10. Specify the participant's language level (if applicable).

## Field-by-Field Explanation

* **Session Registration Form**: This form contains general session details, such as date and time information.
* **Session Language Pair**: Choose whether this session has a language pair. Select 'Yes' if the session involves translation between two languages.
* **Session Date**: Enter the date of the translation session.
* **Session Start Time**: Enter the start time of the translation session.
* **Session End Time**: Enter the end time of the translation session.
* **Session Language Pair (Repeat)**: If the session involves translation between multiple language pairs, select all applicable options.
* **Participant Name**: Enter the name of the participant in the translation session.
* **Participant Email**: Enter the participant's email address.
* **Participant Language Known**: Choose whether the participant's language is known or not.
* **Participant Language Not Known**: If the participant's language is not known, select the languages they do not know.
* **Participant Availability**: Choose the participant's availability (e.g., 'Yes' to indicate they are available).
* **Participant Phone**: Enter the participant's phone number.
* **Coordinator Name**: Enter the name of the coordinator managing the session.
* **Coordinator Email**: Enter the coordinator's email address.
* **Coordinator Phone**: Enter the coordinator's phone number.
* **Session Status**: Update the session status as Active or Inactive.
* **Participant Comments**: Add any comments or notes from the participant.
* **Coordinator Comments**: Add any comments or notes from the coordinator.
* **Session Location**: Enter the location of the translation session.
* **Session Notes**: Add any additional session notes.
* **Participant Language Level**: Choose the participant's language level (e.g., High or Low).
* **Participant Language Level Other**: If the participant's language level is not listed, enter the level.
* **Participant Language Level Other Notes**: Add any additional notes about the participant's language level.
* **Coordinator Language Level**: Choose the coordinator's language level (e.g., High or Low).
* **Coordinator Language Level Other**: If the coordinator's language level is not listed, enter the level.
* **Coordinator Language Level Other Notes**: Add any additional notes about the coordinator's language level.

Note: The required fields are marked as "Required" in the form fields. Please ensure you fill in all required fields before submitting the form.
