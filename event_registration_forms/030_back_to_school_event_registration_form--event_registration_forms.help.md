# Back To School Event Registration Form - Help Guide
## Purpose
The Back To School Event Registration Form is designed for parents or guardians to register their child for a school event. 

## How To Complete This Form
To complete the form, follow these steps:
1. Fill out the form with the required information.
2. Ensure all fields are filled out correctly and according to the instructions.
3. Review the form for accuracy before submitting.

## Field-by-Field Explanation
* **Parent or Guardian Full Name** (`parent_guardian_name`, text, required): Fill out the full name of the parent or guardian.
* **Email Address** (`email`, email, required): Enter the email address for event confirmation.
* **Phone Number** (`phone`, text, required): Enter the contact number of the parent or guardian.
* **Home Address** (`home_address`, text, required): Fill out the full street address of the parent or guardian.
* **Student Name** (`student_name`, text, required): Enter the name of the student attending.
* **Student Grade Level** (`student_grade`, select_one, required): Select the current or upcoming grade level of the student.
* **School Name** (`school_name`, text, required): Enter the name of the school the student attends.
* **Event Date** (`event_date`, date, required): Select the date you will attend.
* **Preferred Time Slot** (`event_time`, select_one, required): Choose a time slot you would prefer.
* **Number of Family Members Attending** (`number_attending`, number, required): Enter the total number of family members attending.
* **Will Siblings Attend?** (`siblings_attending`, select_one, required): Check if other children will be attending.
* **Sibling Names and Grades** (`sibling_names`, text, optional): List the names and grades of siblings.
* **Activities of Interest** (`activities_interested`, select_multiple, required): Choose the activities you would like to participate in.
* **Interested in Volunteering?** (`volunteer_interest`, select_one, optional): Check if you would like to volunteer.
* **Volunteer Tasks You Can Help With** (`volunteer_tasks`, select_multiple, optional): Select the volunteer tasks you can help with.
* **T-Shirt Sizes Needed** (`t_shirt_sizes`, text, optional): If applicable, enter the T-shirt sizes needed.
* **Dietary Needs for Refreshments** (`dietary_needs`, text, optional): List any allergies or restrictions.
* **Need Transportation Assistance?** (`transportation_needed`, select_one, optional): Check if you need help getting to the event.
* **Questions or Concerns** (`questions_concerns`, text, optional): Write anything you would like to ask or share.
* **How Did You Hear About Event** (`how_heard_about_event`, select_one, optional): Choose the source of information about the event.
* **Registration Date** (`registration_date`, date, required): Enter the date of this registration.
