# Outstanding Online Forum Nomination Form - Help Guide

## Purpose
The Outstanding Online Forum Nomination Form is designed to collect information about potential events that deserve to be recognized as outstanding. This form helps to identify exceptional events in various categories, allowing them to be considered for official recognition.

## How To Complete This Form
To complete this form, follow these steps:

1. Review the purpose of the form and make sure this is the right form for your needs.
2. Fill out each field according to the explanations below.

## Field-by-Field Explanation
### 1. **User Information** (`user_info`, text, optional):
	* This field is used to record the submitter's name and contact information.
	* Please provide your name and any additional contact details if you wish to be reached for follow-up questions or updates.

### 2. **Event Information** (`event_info`, text, optional):
	* This field is used to describe the event being nominated.
	* Please provide a brief description of the event you'd like to nominate, including its name and type (e.g., conference, workshop, festival, etc.).

### 3. **Nomination Information** (`nomination_info`, text, optional):
	* This field is used to explain why you are nominating this event.
	* Please provide a concise explanation of what makes this event outstanding and deserving of recognition.

### 4. **Contact Details** (`contact_details`, text, optional):
	* This field is used to provide any additional contact information or context for the nomination.
	* Please include any relevant contact details or context that would be helpful for further discussion or follow-up.

### 5. **Submit** (`submit`, text, optional):
	* This field is used to confirm your submission.
	* Please review all fields carefully before submitting.

## Tips
* Make sure to review all fields carefully before submitting.
* If you have any questions or need clarification, feel free to contact [form@gic.mx](mailto:form@gic.mx).
* Duplicate submissions will not be accepted, so please ensure that your nomination is unique and submitted only once.
