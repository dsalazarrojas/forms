# Sports Events Date Filter - Help Guide
## Purpose
The Sports Events Date Filter form is designed to help event organizers and participants filter sports events based on date-related criteria, making it easier to find specific events within a certain date range or on specific dates.

## How To Complete This Form
To use this form, simply follow the instructions for each field, and you'll be able to filter sports events according to your desired date criteria.

## Field-by-Field Explanation

* **Event Start Date** (`event_start_date`, date, required: false): This field allows you to select a specific start date for the event. You can choose any date in the format `YYYY-MM-DD`.
* **Event End Date** (`event_end_date`, date, required: false): Similar to the start date field, this field allows you to select a specific end date for the event in the format `YYYY-MM-DD`.
* **Date Range** (`event_date_range`, select_multiple, required: false): This field provides a list of pre-defined date ranges. You can select one or more date ranges to filter events that fall within these time periods. The available date ranges are '2024-01-01', '2024-01-15', and '2024-02-01'.
* **Event Start Time** (`event_start_time`, time, required: false): Unfortunately, this field is currently empty and has no specific explanation, as it is currently not applicable in the given form configuration. However, if this field were populated in the future, it would likely allow users to select a specific start time for the event.

## Tips
- Make sure to select the correct date format as `YYYY-MM-DD`.
- You can select multiple date ranges in the `Date Range` field.
- This form is designed to be user-friendly and efficient, allowing you to quickly filter sports events based on date criteria.
