# Virtual Office Booking Form - Help Guide
## Purpose
This form is designed to help users book a virtual office room for meetings, conferences, or training sessions. It is intended to gather necessary information to create, edit, or cancel a virtual office booking.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter your user ID.
2. Select the start date for the booking.
3. Select the end date for the booking.
4. Choose the type of room you want to book (Meeting Room, Conference Room, or Training Room).
5. Enter the name of the room you want to book.
6. Specify the duration of the booking in hours.
7. Select the start time for the booking.
8. Select the end time for the booking.
9. Choose the status of the booking (Pending, Confirmed, or Cancelled).
10. Provide a brief description of the booking (optional).

## Field-by-Field Explanation
### user_id (Required)
* **user_id**: A unique identifier for the user submitting the form.
* This field is required to ensure that only authorized users can book virtual office rooms.

### start_date (Required)
* **start_date**: The start date of the booking.
* Enter the date in the format YYYY-MM-DD.

### end_date (Required)
* **end_date**: The end date of the booking.
* Enter the date in the format YYYY-MM-DD.

### room_type (Required)
* **room_type**: Select the type of room you want to book (Meeting Room, Conference Room, or Training Room).
* Choose the room type that best suits your needs.

### room_name (Required)
* **room_name**: Enter the name of the room you want to book.
* Make sure to enter the correct room name to ensure booking correctness.

### booking_duration (Required)
* **booking_duration**: Specify the duration of the booking in hours.
* Enter the number of hours you need to book the room for.

### start_time (Required)
* **start_time**: Select the start time for the booking.
* Enter the start time in the format HH:MM AM/PM.

### end_time (Required)
* **end_time**: Select the end time for the booking.
* Enter the end time in the format HH:MM AM/PM.

### booking_status (Required)
* **booking_status**: Choose the status of the booking (Pending, Confirmed, or Cancelled).
* Select the status that best reflects your current booking status.

### booking_description (Optional)
* **booking_description**: Provide a brief description of the booking.
* This field is optional and helps with room preparation and documentation.
