# Custom Pop Up Banner Order Form - Help Guide

## Purpose
The form is designed to collect order information for custom pop-up banners.

## How To Complete This Form
To complete this form, simply fill in the required fields with the requested information:
- **Title**: Enter a brief title for your custom pop-up banner.
- **Category**: Choose a category for your banner.
- **Description**: Provide a brief description of your banner.
- **Form ID**: Enter a unique ID for your form, if you're using this feature.
- **Output File**: Choose where to save the output file for your banner.
- **Assigned Tool**: Select the tool assigned for your banner.

## Field-by-Field Explanation

* **Title** (`title`, text, **required**): Enter a brief title for your custom pop-up banner. This will be displayed in the banner.
* **Category** (`category`, text, **required**): Choose a category for your banner. This will help us group banners with similar purposes.
* **Description** (`description`, text, **optional**): Provide a brief description of your banner. This can help us understand the context of your banner.
* **Form ID** (`formid`, text, **optional**): Enter a unique ID for your form, if you're using this feature. This will help us identify your form and ensure it's not duplicated.
* **Output File** (`output_file`, text, **optional**): Choose where to save the output file for your banner. This will help you keep a record of your banner's details.
* **Assigned Tool** (`assigned_tool`, text, **optional**): Select the tool assigned for your banner. This will help us understand which tool is used for your banner.

## Tips
* Be as concise as possible when filling in the title and description fields.
* Ensure that the form ID is unique and not duplicated.
* If you're unsure about any field, please ask for clarification.
