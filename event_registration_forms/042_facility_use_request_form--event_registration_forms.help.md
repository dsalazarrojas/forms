# Facility Use Request Form - Help Guide
## Purpose
This form is used to record information about an organization's event usage of our facility. This data helps us keep track of the facility's usage and manage it efficiently.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill in your organization's name.
2. Enter the name of the event.
3. Select the date of the event.
4. Choose the start time and duration of the event.
5. Specify the purpose for which you are using our facility.
6. List the individuals or team that will be using our facility.
7. Select the date when your event actually used our facility.

## Field-by-Field Explanation

* **Organization Name** (text): Enter the name of your organization.
* **Event Name** (text): Enter the name of the event.
* **Event Date** (date): Choose the date of the event.
* **Event Time** (time): Choose the start time of your event.
* **Event Duration** (number): Enter the duration of your event in minutes or hours.
* **Facility Used For** (text): Describe the purpose for which you are using our facility.
* **Facility Used By** (text): List the individuals or team that will be using our facility.
* **Facility Used Date** (date): Select the date when your event actually used our facility.

## Tips
- Please ensure that you have the necessary permissions and approvals before submitting this form.
- If an organization is planning to use the facility multiple times, please submit a separate form for each occurrence.
- If you are unsure about any information or have questions, please contact our support team.
