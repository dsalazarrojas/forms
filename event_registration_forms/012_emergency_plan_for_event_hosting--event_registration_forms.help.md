# <string> - Help Guide
## Purpose
The Event Registration Form is a crucial tool used to document and organize events. This form captures essential information about events, including details about event organizers, participants, and emergency procedures. The form is designed to ensure accurate and comprehensive data collection, facilitating effective event management and planning.

## How To Complete This Form
To fill out this form, follow these steps:

1.  Enter the title of the event in the **Event Name** field.
2.  Enter the contact person's name in the **Contact Name** field.
3.  Enter the contact person's phone number in the **Contact Number** field.
4.  Enter the contact person's email address in the **Contact Email** field.
5.  Select the emergency contacts for the event in the **Emergency Contacts** field.
6.  Provide a detailed description of the safety protocols for the event in the **Safety Protocols** field.
7.  Enter the location of the event in the **Location** field.
8.  Enter the date of the event in the **Event Date** field.
9.  Enter the time of the event in the **Event Time** field.
10. Select the event venue in the **Event Venue** field.
11. Enter any additional notes about the event in the **Event Notes** field.
12. Select additional contacts for the event in the **Additional Contacts** field.
13. Describe the emergency procedures for the event in the **Emergency Procedures** field.
14. Enter the name of the emergency contact person in the **Emergency Contact** field.
15. Select the status of the event in the **Event Status** field.
16. Choose the type of event in the **Event Type** field.
17. Determine the size of the event in the **Event Size** field.
18. Select the type of event (Large or Medium) in the **Event Type 2** field.
19. Select the status of the event (Active or Inactive) in the **Event Status 2** field.
20. Enter the date of the second event in the **Event Date 2** field.
21. Select additional contacts for the second event in the **Additional Contacts 2** field.
22. Enter the name of the person organizing the event in the **Event Organizer** field.
23. Describe the emergency procedure for the event in the **Emergency Procedure** field.
24. Enter the venue of the second event in the **Event Venue 2** field.
