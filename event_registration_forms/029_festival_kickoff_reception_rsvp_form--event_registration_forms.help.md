# Festival Kickoff Reception RSVP Form - Help Guide
## Purpose
The Festival Kickoff Reception RSVP Form is designed to collect information about attendees for the festival kickoff reception. This form will help us ensure an accurate headcount, gather contact details, and confirm event preferences.

## How To Complete This Form

1. Fill out the form completely and accurately.
2. Ensure all required fields are filled out.
3. Review the form carefully before submitting.

## Field-by-Field Explanation

* **name** (text, required):
	+ Enter your name as it should be listed on the reception materials.
* **guest_name** (text, required):
	+ Enter the name of your guest (if applicable).
* **email** (email, required):
	+ Enter a valid email address that we can use to contact you.
* **phone** (text, required):
	+ Enter your phone number that we can use to contact you.
* **date** (date, required):
	+ Select the date you will be attending the reception from the provided options.
* **time** (time, required):
	+ Select the time you will be attending the reception from the provided options.
* **attendance** (select one, required):
	+ Choose whether you will be attending the reception (True) or not (False).
* **guests** (select multiple, required):
	+ Select which guests you will be bringing with you (Guest 1, Guest 2, etc.).
* **note** (note, optional):
	+ If you have any additional comments or information, feel free to add them here.
* **email_confirmation** (email, optional):
	+ Enter a confirmation email address (if different from the previous field).
* **phone_confirmation** (text, optional):
	+ Enter a confirmation phone number (if different from the previous field).
* **note_confirmation** (note, optional):
	+ Add any additional comments or information.
* **method** (select one, optional):
	+ Choose how you prefer to receive the event invitation (Online, Mail, Phone, Onsite).
* **methods** (select multiple, optional):
	+ Select which methods you prefer for invitations (Online, Mail, Phone, Onsite).
* **attendance_method** (select one, optional):
	+ Choose whether you will be attending the reception (True or False).
* **guests_method** (select multiple, optional):
	+ Select which guests you will be bringing with you (Guest 1, Guest 2, etc.).
* **date** (date, optional):
	+ Select an optional date for the event.
* **time** (time, optional):
	+ Select an optional time for the event.
* **event_date** (select one, optional):
	+ Select a date for the event from the provided options.
* **event_time** (select one, optional):
	+ Select a time for the event from the provided options.
* **event_location** (select one, optional):
	+ Select a location for the event from the provided options.
* **event_method** (select one, optional):
	+ Choose a method for the event invitation (Online, Mail, Phone, Onsite).
* **event_note** (select one, optional):
	+ Choose whether to receive event notes (True or False).
* **rsvp** (select one, required):
	+ Choose whether to RSVP for the event (True or False).
* **rsvp_method** (select one, optional):
	+ Choose a method for the RSVP confirmation (Online, Mail, Phone, Onsite).

## Tips

* Please review the form carefully before submitting to ensure all required fields are filled out.
* If you have any questions or need help with the form, contact us.
