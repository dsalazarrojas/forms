# Finishing Tips And Checklist - Help Guide
## Purpose
The "Finishing Tips And Checklist" form is intended to gather essential information about events, activities, or tasks. It consists of three main sections: "Finishing Tips", "Checklist", and "Event Details". By providing accurate and relevant input, you'll be able to generate a comprehensive report that will help you complete tasks and events efficiently.

## How To Complete This Form
To complete the form, follow these steps:
1. Start by filling out the "Finishing Tips" section, which includes free-form text fields that allow you to provide specific details about the event.
2. In the "Checklist" section, select the tasks you have completed or are working on for the event. You can choose multiple tasks.
3. Finally, in the "Event Details" section, select the specific event details that apply to your situation.

## Field-by-Field Explanation
### Finishing Tips
* **<label>: Finishing Tips** (`title`, text, optional): Provide any specific tips or advice that will help you complete the event efficiently.

### Checklist
* **<label>: Checklist** (`task`, select multiple, optional): Select the tasks you have completed or are working on for the event. Choose one or more of the options provided.

### Event Details
* **<label>: Event Details** (`event_details`, select_one, optional): Select the details that apply to your situation, such as specific settings or circumstances.

## Tips
- Be sure to fill out each section completely to ensure accurate and comprehensive results.
- If a task is not relevant, select "None of the above" to indicate this.
- If you have any specific concerns or need clarification, feel free to contact the form creators at form@gic.mx.
