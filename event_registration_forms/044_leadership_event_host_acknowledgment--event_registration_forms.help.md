# Leadership Event Host Acknowledgment - Help Guide
## Purpose

This form is used by hosts or coordinators to confirm that a leadership event has taken place.

## How To Complete This Form

To complete this form, please follow the steps above.

## Field-by-Field Explanation

* **Form Start**: Introduction to the form.
* **Event Name**: A text input field where you should enter the name of the event.
* **Event Date**: A field to select the date of the event in the standard date format (MM/dd/yyyy).
* **Event Time**: A field to select the time of the event in the 24-hour time format (HH:mm).
* **Host Name**: A text input field where you should enter your name as the host or event coordinator.
* **Host Role**: A text input field where you should enter your role in the event.
* **Host Email**: A field to enter your email address for contact purposes.
* **Confirmation**: A dropdown field with three options: Confirmed, Not Confirmed, and Not Applicable. Please select "Confirmed" if you have received all necessary information, resources, or support for the event.
* **Form End**: Conclusion to the form.

## Tips

* Please ensure that the event has occurred and you are the rightful host or coordinator before filling out the form.
* Be accurate when filling out the event date and time.
* Enter your correct email address to ensure that we can contact you in case of any issues or follow-ups.
* If you have not received the necessary information, resources, or support for the event, please select "Not Confirmed" in the confirmation field.
* Review your information carefully before submitting the form to prevent any errors.
