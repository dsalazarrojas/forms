# event_host_registration_form - Help Guide

## Purpose
The purpose of this form is to collect information from event hosts to create a new event.

## How To Complete This Form
To complete this form, follow these steps:

1. Make sure you have the necessary permissions to create events in the system.
2. Fill out the form with the required information:
	* Event host name
	* Event name
	* Event date
	* Event time
	* Contact name
	* Email address
	* Phone number
	* Event description
	* Venue

## Field-by-Field Explanation

* **Event host**: Enter your name as the event host.
* **Event name**: Enter the name of the event.
* **Event date**: Enter the date of the event (in the format MM/DD/YYYY).
* **Event time**: Enter the time of the event (in the format HH:MM AM/PM).
* **Contact name**: Enter the name of the contact person for the event.
* **Email address**: Enter the email address of the contact person.
* **Phone number**: Enter the phone number of the contact person.
* **Event description**: Enter a brief description of the event.
* **Venue**: Enter the location of the event.

## Tips
* Make sure to double-check the information before submitting the form.
* If you need help, contact the event management team.
* If you have any questions or concerns, please don't hesitate to reach out.
