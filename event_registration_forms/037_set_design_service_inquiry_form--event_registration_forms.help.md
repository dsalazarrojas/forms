# Set Design Service Inquiry Form - Help Guide
## Purpose
The purpose of this form is to gather information about your event or production project so we can provide you with the best possible design service.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the required fields with accurate and relevant information about your project.
2. Select the correct service name and type from the options provided.
3. Enter the project name and project type.
4. Choose the start and end dates for your project.
5. If applicable, provide the service location.
6. Enter your contact information, including a valid contact number and email.
7. Provide a detailed description of the service you require.

## Field-by-Field Explanation

* **Service Name (<service_name>):** Enter the name of the service you are inquiring about.
* **Service Type (<service_type>):** Select the type of service you require, either Set Design Service or Set Production Service.
* **Project Name (<project_name>):** Enter the name of the project you are inquiring about.
* **Project Type (<project_type>):** Select the type of project you are producing, either Event or Production.
* **Start Date (<start_date>):** Enter the start date of your project.
* **End Date (<end_date>):** Enter the end date of your project.
* **Service Location (<service_location>):** If your project requires a specific location, enter it here (optional).
* **Contact Number (<contact_number>):** Enter your contact number so we can reach you.
* **Contact Email (<contact_email>):** Enter your email address so we can communicate with you.
* **Service Details (<service_details>):** Provide a detailed description of the service you require.
