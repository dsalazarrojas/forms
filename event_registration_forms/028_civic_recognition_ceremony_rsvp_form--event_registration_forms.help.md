# Civic Recognition Ceremony RSVP Form - Help Guide
## Purpose
This form is used to collect information for the Civic Recognition Ceremony.

## How To Complete This Form
To complete this form, follow these steps:

1. Please fill out all required fields (marked as required).
2. Enter your name and email address in the corresponding fields.
3. Specify the number of guests attending with you.
4. If you have any dietary requirements or specific needs, please mention them in the "Dietary requirements" field.
5. If you have any accessibility needs, please describe them in the "Accessibility needs" field.
6. If you wish to participate in the program, select "True".
7. If you consent to event photos, select "True".
8. If you have any additional notes for the organizers, please provide them in the "Additional notes" field.
9. Finally, select the current date from the "Submission date" field.

## Field-by-Field Explanation
* **Attendee name** (`attendee_name`, text, required): Please enter your full name.
* **Email address** (`email`, email, required): Enter your email address for RSVP confirmation.
* **Number of guests** (`number_of_guests`, number, required): Include yourself in the count.
* **Dietary requirements** (`dietary_requirements`, text, optional): Specify food allergies or preferences.
* **Seating preference** (`seating_preference`, text, optional): Describe your accessibility or preferred area.
* **Interest in participating in program** (`program_participation`, select_one, optional): Select "True" if you wish to participate.
* **Accessibility needs** (`accessibility_needs`, text, optional): Indicate any required accommodations.
* **Consent for event photos** (`photo_consent`, select_one, optional): Select "True" if you consent to photos.
* **Additional notes** (`additional_notes`, text, optional): Provide any additional information for the organizers.
* **Submission date** (`submission_date`, date, required): Select the current date.
