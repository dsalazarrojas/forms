# Workplace Recognition Event Registration - Help Guide

## Purpose
This form is used to register events within the workplace. Please fill it out to provide necessary information about the event and its associated details.

## How To Complete This Form

1. Ensure you have the necessary permissions and authority to register events.
2. Fill out the form accurately and thoroughly.
3. Provide all required fields. Required fields are marked with an asterisk (*) or indicated as "required" in the field-by-field explanation.

## Field-by-Field Explanation

* **Name** (1, text, required): Enter the name of the person registering the event.
* **Email** (2, email, required): Enter your email address to allow for easy communication and verification.
* **Phone** (3, text, required): Enter your phone number for additional contact information.
* **Event Name** (4, text, required): Enter the name of the event to be recognized.
* **Event Date** (5, date, required): Select the date of the event.
* **Start Time** (6, time, required): Choose the start time of the event.
* **End Time** (7, time, required): Choose the end time of the event.
* **Additional Details** (8, text, optional): Provide any additional information about the event (e.g., location, description).
* **Attendees** (9, select multiple, required): Indicate if attendees are expected or not. Choose 'Yes' if the event is open to attendees, or 'No' if it's not.
* **Manager** (10, select one, required): Indicate if the manager is aware of and will be attending the event. Choose 'Yes' if the manager is attending, or 'No' if they are not.

## Tips
* Double-check your entries for accuracy before submitting.
* Ensure you have the necessary permissions and authority to register events.
* If unsure about any field, please contact the relevant authorities or the event organizer for clarification.
