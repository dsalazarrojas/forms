# Nonprofit Appreciation Gala RSVP Form - Help Guide
## Purpose
The Nonprofit Appreciation Gala RSVP Form is designed to collect information from guests and attendees for the gala event. This form helps event organizers gather necessary details such as event preferences, guest details, and RSVP responses.

## How To Complete This Form
To fill out the form, follow these steps:

1. Provide event details (Page 1)
	* Enter a brief description of your event preferences, but this field is not required.
2. Enter Guest Name (Page 2)
	* Type in the name of the guest attending the event.
3. Enter Email (Page 3)
	* Enter the email address of the guest, which will be used for further communication.
4. RSVP (Page 4)
	* Select 'Yes' if you will attend the event and 'No' if you will not.
5. Number of Guests (Page 5)
	* Choose the number of guests who will attend with you (1-3).
6. Organization (Page 6)
	* Optionally, enter the organization name associated with the guest's attendance.
7. Message (Page 7)
	* Leave a brief message or note if desired.
8. Additional RSVP Information (Page 8)
	* If you have any other RSVP details, type them in this field.

## Field-by-Field Explanation

* **Event Details (Event Details)**: This field is optional and allows you to provide any additional details about your event preferences.
* **Guest Name (Guest Name)**: Enter the name of the guest attending the event.
* **Email (Email)**: Enter the email address of the guest, which will be used for further communication.
* **RSVP (RSVP)**: Select 'Yes' if you will attend the event and 'No' if you will not.
* **Number of Guests (Guests)**: Choose the number of guests who will attend with you (1-3).
* **Organization (Organization)**: Optionally, enter the organization name associated with the guest's attendance.
* **Message (Message)**: Leave a brief message or note if desired.
* **Additional RSVP Information (RSVP Other)**: If you have any other RSVP details, type them in this field.

## Tips

* Please fill out this form only once per guest to ensure accurate tracking.
* Make sure to select 'Yes' or 'No' for the RSVP field accurately.
* If you have any special requests or needs, you can mention them in the 'Message' or 'RSVP Other' field.
* Ensure all required fields (RSVP and Number of Guests) are completed.
