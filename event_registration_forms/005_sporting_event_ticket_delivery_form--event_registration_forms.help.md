# Sporting Event Ticket Delivery Form - Help Guide
## Purpose
The Sporting Event Ticket Delivery Form is used to collect information about sporting event tickets, including event details, ticket details, delivery options, and payment methods.

## How To Complete This Form
1. Read through each field carefully and provide accurate information.
2. Fill out the form in the following sequence:
   - event_info
   - ticket_info
   - contact_info
   - ticket_details
   - payment_info
   - ticket_status
   - delivery_info
   - delivery_status
   - order_info
   - shipping_info
   - billing_info
   - event_info_2
   - payment_method
   - payment_status
   - order_status
   - payment_info_2
   - shipping_info_2
   - event_status
   - ticket_type
   - ticket_price
   - ticket_quantity
   - delivery_date
   - delivery_time
   - notes

## Field-by-Field Explanation
* **event_info** (text, text, optional): Enter a brief description of the sporting event.
* **ticket_info** (text, text, optional): Enter a brief description of the ticket.
* **contact_info** (text, text, optional): Enter the contact information of the person delivering the ticket.
* **ticket_details** (text, text, optional): Enter any additional details about the ticket.
* **payment_info** (text, text, optional): Enter the payment information for the ticket.
* **ticket_status** (text, text, optional): Enter the status of the ticket.
* **delivery_info** (text, text, optional): Enter the delivery information for the ticket.
* **delivery_status** (text, text, optional): Enter the delivery status.
* **order_info** (text, text, optional): Enter any other relevant order information.
* **shipping_info** (text, text, optional): Enter shipping information for the ticket.
* **billing_info** (text, text, optional): Enter billing information for the ticket.
* **event_info_2** (text, text, optional): Enter a brief description of the event.
* **payment_method** (select_one, yes/no, optional): Select the payment method used for the ticket.
* **payment_status** (text, text, optional): Enter the payment status.
* **order_status** (text, text, optional): Enter the order status.
* **payment_info_2** (text, text, optional): Enter any additional payment information.
* **shipping_info_2** (text, text, optional): Enter shipping information for the ticket.
* **event_status** (text, text, optional): Enter the status of the event.
* **ticket_type** (select_one, yes/no, optional): Select the type of ticket.
* **ticket_price** (number, text, optional): Enter the price of the ticket.
* **ticket_quantity** (number, text, optional): Enter the quantity of the ticket.
* **delivery_date** (date, text, optional): Enter the delivery date.
* **delivery_time** (time, text, optional): Enter the delivery time.
* **notes** (note, text, optional): Enter any additional notes about the ticket.

Note: Please fill out the form according to the sequence mentioned above for accurate and efficient completion of the ticket delivery process. If you have any questions or concerns, please reach out to our support team for assistance.
