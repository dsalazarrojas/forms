# Travel Sustainability Hackathon Registration Form - Help Guide
## Purpose
This form is designed to collect registration information from attendees of the Travel Sustainability Hackathon. By filling out this form, you will be able to participate in the event and contribute your ideas and expertise to the sustainability in travel discussion.

## How To Complete This Form
To complete this form, follow these steps:

1. Go through each page and fill out the required fields.
2. For each field, make sure to provide accurate and relevant information.
3. If you need help or have questions, contact the event organizers.

## Field-by-Field Explanation
### Page 1: Registration
* **Registration** (`title`, `text`, required: false): This page is the first page of the form. It is not required to fill out, but it's a good idea to write something here to let the organizers know that you are interested in attending the event.
### Page 2: Personal Details
* **Personal Details** (`personal_details`, `text`, required: true): Fill out this field with your personal details, such as your name, address, and any other relevant contact information.
### Page 3: Contact Information
* **Contact Information** (`contact_information`, `email`, required: true): Enter your email address and any other contact information you would like to share with the event organizers.
### Page 4: Travel Plans
* **Travel Plans** (`travel_plans`, `text`, required: false): If you have any travel plans related to the hackathon, such as transportation or accommodation arrangements, fill out this field.
### Page 5: Special Requests
* **Special Requests** (`special_requests`, `text`, required: false): If you have any special requests or needs, such as dietary restrictions or mobility issues, fill out this field.
### Page 6: Emergency Contacts
* **Emergency Contacts** (`emergency_contacts`, `text`, required: false): If you have emergency contacts that the event organizers should know about, fill out this field.
### Page 7: Payment Method
* **Payment Method** (`payment_method`, `select_one`, required: true): Select one of the payment methods below:
	+ **Bank Transfer**: If you want to pay via bank transfer, select this option.
	+ **Credit Card**: If you want to pay via credit card, select this option.
	+ **Cash**: If you want to pay via cash, select this option.
* **Payment Method Other** (`payment_method_other`, `text`, required: false): If you selected "Other" as your payment method, fill out this field with the name of the method.
### Page 8: Payment Method
* **Payment Method** (`payment_method`, `select_one`, required: true): This field is the same as page 7, so please refer to that explanation. 

Note: This guide will help you fill out the form correctly and make the most out of your experience. If you have any questions or need help, contact the event organizers.
