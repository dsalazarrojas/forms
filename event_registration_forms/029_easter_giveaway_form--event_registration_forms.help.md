# easter giveaway form - Help Guide
## Purpose
The Easter Giveaway form is used to register for the Easter event. Please fill out the form accurately and completely to ensure that you are registered for the event.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out all required fields, marked with *asterisks* (*).
2. For the `Easter Preference` field, select the type of Easter event you wish to participate in from the provided options.
3. In the `Event Type` field, select the type of event you wish to participate in from the provided options.
4. For the `Terms and Conditions` field, select "I agree" if you accept the terms and conditions of the event.

## Field-by-Field Explanation

* **First Name (text, required):** Enter your first name in this field.
* **Last Name (text, required):** Enter your last name in this field.
* **Email (email, required):** Enter your valid email address in this field. Please note that the email address will be used for communication about the event.
* **Birthday (date, required):** Enter your birthday in the format MM/DD/YYYY.
* **Phone (text, optional):** Enter your phone number in this field, if you wish to be contacted for the event.
* **Easter Preference (select_one, required):** Select the type of Easter event you wish to participate in from the options provided. Please note that this field will help us to better plan and organize the event for you.
* **Friend (text, optional):** If you are attending with a friend, enter their name in this field.
* **Family Member (text, optional):** If you are attending with a family member, enter their name in this field.
* **Event Type (select_multiple, required):** Select the type of event you wish to participate in from the options provided.
* **Comments (note, optional):** If you have any comments or suggestions for the event, please provide them in this field.
* **Terms and Conditions (select_one, required):** Select "I agree" if you accept the terms and conditions of the event.

Note: All fields with *asterisks* are required fields. Please ensure that all these fields are filled out accurately and completely to avoid delays in processing your application.
