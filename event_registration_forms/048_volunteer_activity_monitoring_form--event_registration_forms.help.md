# Volunteer Activity Monitoring Form - Help Guide
## Purpose
The form is for tracking volunteer activities, including event types, dates, names, and hours worked by volunteers. This information helps to monitor volunteer engagement and optimize resources for future events.

## How To Complete This Form
To complete this form, follow these steps:

1.  Select the type of event being monitored (Volunteer, Community Project, or Event).
2.  Enter the date of the event.
3.  Enter the name of the activity.
4.  Enter the start and end times of the activity.
5.  Provide the number of volunteers who participated.
6.  Enter the total hours worked by volunteers.
7.  Add any comments about the event.
8.  If applicable, enter the volunteer's name and email.

## Field-by-Field Explanation

* **Event Type** (`event_type`, `select_one`, required: false):
    This field is used to categorize the type of event being monitored. Select one of the following options: Volunteer, Community Project, or Event.
* **Event Date** (`event_date`, `date`, required: false):
    Enter the date of the event in the format MM/dd/yyyy.
* **Activity Name** (`activity_name`, `text`, required: false):
    Provide a brief name for the activity.
* **Start Time** (`activity_start_time`, `time`, required: false):
    Enter the start time of the activity in 24-hour format (HH:MM).
* **End Time** (`activity_end_time`, `time`, required: false):
    Enter the end time of the activity in 24-hour format (HH:MM).
* **Volunteer Count** (`volunteer_count`, `number`, required: false):
    Enter the number of volunteers who participated in the activity.
* **Volunteer Hours Worked** (`volunteer_hours_worked`, `number`, required: false):
    Enter the total hours worked by volunteers for the activity.
* **Comments** (`comments`, `note`, required: false):
    Add any additional comments about the event.
* **Volunteer Name** (`volunteer_name`, `text`, required: false):
    If applicable, enter the name of the volunteer.
* **Volunteer Email** (`volunteer_email`, `email`, required: false):
    If applicable, enter the email address of the volunteer.

## Tips
- Be as detailed as possible when filling out the form to ensure accurate tracking.
- Verify the event type and activity name for proper categorization.
- Review the form for any errors or discrepancies before submission.
