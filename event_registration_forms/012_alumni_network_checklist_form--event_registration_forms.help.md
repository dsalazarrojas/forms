# Alumni Network Checklist Form - Help Guide
## Purpose
The Alumni Network Checklist Form is used to collect information about an attendee's participation in a networking event or session.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the attendee's full name in the "Attendee name" field.
2. Indicate whether the attendee checked in by selecting "True" or "False" in the "Checked in" field.
3. List the sessions attended by the attendee in the "Sessions attended" field.
4. Select "True" or "False" for "Interested in networking" and "Interested in volunteering" to indicate the attendee's interest in these areas.
5. Mark "True" or "False" for "Follow up needed" if a follow-up is required.
6. Provide internal staff notes about the attendee in the "Staff notes" field.

## Field-by-Field Explanation
### 1. **Attendee name** (`attendee_name`, text, required)
This field is used to capture the full name of the attendee. Please enter the attendee's name as it appears on official records or identification.

### 2. **Checked in** (`checked_in`, select_one, required)
Indicate whether the attendee has checked in by selecting "True" for "Yes" or "False" for "No".

### 3. **Sessions attended** (`session_attended`, text, optional)
List the sessions or activities the attendee participated in during the event. This field is not required, but it helps track the attendee's engagement and participation.

### 4. **Interested in networking** (`networking_interest`, select_one, optional)
Select "True" if the attendee is interested in networking, and "False" otherwise.

### 5. **Interested in volunteering** (`volunteer_interest`, select_one, optional)
Select "True" if the attendee is interested in volunteering, and "False" otherwise.

### 6. **Follow up needed** (`follow_up_needed`, select_one, optional)
Mark "True" if a follow-up action is required for the attendee, and "False" otherwise.

### 7. **Staff notes** (`staff_notes`, text, optional)
Enter any internal notes or comments about the attendee. This is for staff reference only and will not be shared with the attendee.
