# Thanksgiving Meal Kit Waitlist - Help Guide
## Purpose
This form is used to register for the Thanksgiving Meal Kit program. If you're interested in participating, please fill out this form to provide your contact information and preferences.

## How To Complete This Form
1. Fill out the form completely and accurately.
2. Provide a valid email address for confirmation and notification purposes.
3. Select your dietary preferences or other relevant options.
4. Enter the date and time of the event or service you'd like to participate in.
5. Provide a valid zip code for the location of the event or service.
6. Enter your phone number for contact purposes.
7. Provide a brief note or message if needed.

## Field-by-Field Explanation

* **Form Submission** (`form_submission`, text, optional): This field is used to provide a brief description of your interest in participating in the program.
* **Name** (`name`, text, optional): Enter your name for identification purposes.
* **Email** (`email`, email, optional): Enter a valid email address for confirmation and notification purposes.
* **Phone** (`phone`, text, optional): Enter your phone number for contact purposes.
* **Select Option 1** (`select_option_1`, select_one, optional): Select your preferred option for the Thanksgiving Meal Kit.
* **Select Option 2** (`select_option_2`, select_multiple, optional): Select multiple options for the Thanksgiving Meal Kit.
* **Date** (`date`, date, optional): Enter the date you'd like to participate in the event or service.
* **Time** (`time`, time, optional): Enter the time you'd like to participate in the event or service.
* **Note** (`note`, note, optional): Provide a brief note or message if needed.
* **Event Date** (`event_date`, date, optional): Enter the date of the event or service.
* **Event Start Time** (`event_start_time`, time, optional): Enter the start time of the event or service.
* **Event End Time** (`event_end_time`, time, optional): Enter the end time of the event or service.
* **Event Address** (`event_address`, text, optional): Enter the address of the event or service.
* **Event City** (`event_city`, text, optional): Enter the city of the event or service.
* **Event State** (`event_state`, text, optional): Enter the state of the event or service.
* **Event Zip** (`event_zip`, text, optional): Enter the zip code of the event or service.
* **Event Country** (`event_country`, text, optional): Enter the country of the event or service.
* **Email 2** (`email_2`, email, optional): Enter an alternate email address for confirmation and notification purposes.
* **Phone 2** (`phone_2`, text, optional): Enter an alternate phone number for contact purposes.
* **Note 2** (`note_2`, note, optional): Provide an alternate brief note or message if needed.
* **Select Option 3** (`select_option_3`, select_one, optional): Select your preferred option for the event or service.
* **Select Option 4** (`select_option_4`, select_multiple, optional): Select multiple options for the event or service.
* **Date 2** (`date_2`, date, optional): Enter the date you'd like to participate in the alternate event or service.
* **Time 2** (`time_2`, time, optional): Enter the time you'd like to participate in the alternate event or service.
* **Note 3** (`note_3`, note, optional): Provide an alternate brief note or message if needed.
