# Holiday Card Signature Form - Help Guide

## Purpose
This form is for gathering information from users for event planning and organization purposes.

## How To Complete This Form
To complete this form, follow the steps outlined above.

## Field-by-Field Explanation
* **First name** (`1`, text, required): Enter your first name.
* **Last name** (`2`, text, required): Enter your last name.
* **Message** (`3`, text, optional): If you have a message you'd like to share, enter it here.
* **Email** (`4`, email, required): Enter your email address.
* **Phone** (`5`, text, optional): Enter your phone number.
* **Holiday Card Signature** (`6`, note, optional): Sign your name.
* **Signature count** (`7`, number, optional): This field is not applicable for most users.
* **School** (`8`, select_one, optional): Select the school you attend or have attended.
* **Organization** (`9`, select_multiple, optional): Select the organization you belong to or represent.
* **Date** (`10`, date, optional): Enter the date of the event (if applicable).
* **Time** (`11`, time, optional): Enter the time of the event (if applicable).
* **Event date** (`12`, select_one, optional): Choose the event date (if applicable).
* **Event time** (`13`, select_one, optional): Choose the event time (if applicable).
* **Gift** (`14`, select_multiple, optional): Select the gift you would like to receive or give.
* **Event location** (`15`, select_multiple, optional): Choose the event location.
* **Event description** (`16`, note, optional): Enter a brief description of the event.
* **School type** (`17`, select_one, optional): Select the type of school (Public, Private, or Charter).
* **School grade** (`18`, select_one, optional): Select the school grade level (Elementary, Middle School, or High School).
* **Gift message** (`19`, note, optional): Enter a message for the gift.
* **Event venue** (`20`, select_multiple, optional): Choose the event venue (Theater, Museum, or Park).
* **School name** (`21`, select_multiple, optional): Select the school name (Elementary School, High School, or University).
* **Event details** (`22`, note, optional): Enter a description of the event details.
* **School location** (`23`, select_multiple, optional): Choose the school location (City, Town, or Country).
* **Event attendee** (`24`, select_multiple, optional): Select the event attendees (Adult, Child, or Group).
* **School phone** (`25`, text, optional): Enter the school phone number (if applicable).

## Tips
* Please note that some fields are optional and can be skipped if not applicable.
* Be accurate and truthful when filling out the form to ensure accurate event planning and organization.
