# Game Setup Form - Help Guide
## Purpose
The Game Setup Form is used to collect information for game setup purposes, such as setting up game sessions, selecting players, game mode, schedule matches, game rules, event organizer, and community club.

## How To Complete This Form
To complete this form, follow these steps:

1. Review the form sections and understand what information is required for each section.
2. Fill in the game session details, including any relevant text information.
3. Select the players that will be participating in the game session.
4. Choose the game mode for the session (e.g., Yes/No).
5. Set the schedule matches for the game session (use a date format, e.g., MM/DD/YYYY).
6. Select the game rules that will be applied during the session (e.g., Yes/No).
7. Identify the event organizer for the session (e.g., Yes/No).
8. Select the community club that will be hosting the session (e.g., Yes/No).

## Field-by-Field Explanation
- **Game Session Details (game_session_details)**: A text field for entering any relevant details about the game session.
  - Type: Text
  - Required: Optional
- **Players (players)**: A multiple selection field where you can choose which players will participate in the session.
  - Type: Select Multiple
  - Required: Optional
- **Game Mode (game_mode)**: A selection field where you can choose the game mode for the session (e.g., Yes/No).
  - Type: Select One
  - Required: Optional
- **Schedule Matches (schedule_matches)**: A date field for setting the schedule matches for the session.
  - Type: Date
  - Required: Optional
- **Game Rules (game_rules)**: A selection field where you can choose the game rules that will be applied during the session (e.g., Yes/No).
  - Type: Select One
  - Required: Optional
- **Event Organizer (event_organizer)**: A selection field where you can identify the event organizer for the session (e.g., Yes/No).
  - Type: Select One
  - Required: Optional
- **Community Club (community_club)**: A selection field where you can choose the community club that will host the session (e.g., Yes/No).
  - Type: Select One
  - Required: Optional

## Tips
- Be sure to fill in all required fields (if any) before submitting the form.
- Double-check your selections and details before submitting the form.
- If you have any questions or need help, contact your event organizer or support team.
