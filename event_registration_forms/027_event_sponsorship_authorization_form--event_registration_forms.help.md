# event_sponsorship_authorization_form - Help Guide

## Purpose
The event_sponsorship_authorization_form is used to collect sponsorship authorization for events that require it. This form is typically used to gather information about the event, such as its name, date, time, and sponsor details, which will be reviewed and approved by event organizers.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the required fields with the relevant information about the event and its sponsor.
2. Review each field explanation below to ensure you understand what information is being collected.

## Field-by-Field Explanation
* **Event Sponsorship Authorization Form** (page 1, event_sponsorship_form)
	+ (Label: Event Sponsorship Authorization Form, Type: text, Required: false)
	+ This page serves as a cover page for the form. You do not need to fill in any information here, unless you are required to provide a specific title or description for the form.
* **Sponsor Name** (page 2, sponsor_name)
	+ (Label: sponsor_name, Type: text, Required: false)
	+ Enter the name of the sponsor responsible for this event.
* **Sponsor Email** (page 2, sponsor_email)
	+ (Label: sponsor_email, Type: email, Required: false)
	+ Enter the email of the sponsor responsible for this event.
* **Sponsor Company** (page 2, sponsor_company)
	+ (Label: sponsor_company, Type: text, Required: false)
	+ Enter the name of the sponsor's company.
* **Sponsor Title** (page 2, sponsor_title)
	+ (Label: sponsor_title, Type: text, Required: false)
	+ Enter the title of the sponsor responsible for this event.
* **Sponsor Phone** (page 2, sponsor_phone)
	+ (Label: sponsor_phone, Type: text, Required: false)
	+ Enter the phone number of the sponsor responsible for this event.
* **Event Name** (page 3, event_name)
	+ (Label: event_name, Type: text, Required: false)
	+ Enter the name of the event.
* **Event Date** (page 3, event_date)
	+ (Label: event_date, Type: date, Required: false)
	+ Enter the date of the event.
* **Event Time** (page 3, event_time)
	+ (Label: event_time, Type: time, Required: false)
	+ Enter the time of the event.

## Tips
* Make sure to fill in all required fields for the event sponsorship authorization form.
* Review each field carefully to ensure you have entered the correct information.
* If you are unsure about any field, contact the event organizers for clarification.
