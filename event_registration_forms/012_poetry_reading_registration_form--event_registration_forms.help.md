# Poetry Reading Registration Form - Help Guide
## Purpose
The Poetry Reading Registration Form is used to collect information from attendees and performers for a poetry reading event. This form ensures that all necessary details are collected for a successful event.

## How To Complete This Form
To complete this form, follow these steps:

1.  Fill out the event details (page 1).
2.  Provide attendee information (page 2).
3.  Enter contact information (page 3).
4.  Provide performer information (page 4).
5.  Specify event date and time (page 5).
6.  Determine the performance duration (page 6).
7.  Choose the event type (page 7).
8.  Select the type of event (page 8).
9.  Enter performer name and contact information (pages 9-11).
10. Enter event organizer information (page 12).
11. Provide event URL and registration notes (page 13).
12. Enter attendee name and contact information (pages 14-16).

## Field-by-Field Explanation
*   **Event Details** (`event_details`, text, required/optional): Enter a brief description of the event.
*   **Attendee Details** (`attendee_details`, text, required/optional): Enter a brief description of the attendee.
*   **Contact Info** (`contact_info`, text, required/optional): Enter contact information for event organizers.
*   **Performer Details** (`performer_details`, text, required/optional): Enter a brief description of the performer.
*   **Event Date** (`event_date`, date, required/optional): Enter the date of the event.
*   **Event Time** (`event_time`, time, required/optional): Enter the time of the event.
*   **Performance Duration** (`performance_duration`, number, required/optional): Enter the duration of the performance.
*   **Registration Type** (`registration_type`, select_one, required/optional): Choose the type of event registration.
*   **Event Type** (`event_type`, select_multiple, required/optional): Select the type of event (e.g., poetry reading, workshop, conference, panel discussion).
*   **Performer Name** (`performer_name`, text, required/optional): Enter the name of the performer.
*   **Performer Email** (`performer_email`, email, required/optional): Enter the email of the performer.
*   **Phone Number** (`phone_number`, text, required/optional): Enter the phone number of the performer.
*   **Performer Experience** (`performer_experience`, text, required/optional): Enter the experience of the performer.
*   **Bio** (`bio`, text, required/optional): Enter a brief bio of the performer.
*   **Performance Title** (`performance_title`, text, required/optional): Enter the title of the performance.
*   **Performance Description** (`performance_description`, text, required/optional): Enter a brief description of the performance.
*   **Contact Name** (`contact_name`, text, required/optional): Enter the name of the event contact.
*   **Contact Email** (`contact_email`, email, required/optional): Enter the email of the event contact.
*   **Contact Phone Number** (`contact_phone_number`, text, required/optional): Enter the phone number of the event contact.
*   **Event Organizer** (`event_organizer`, text, required/optional): Enter the name of the event organizer.
*   **Event URL** (`event_url`, text, required/optional): Enter the URL of the event.
*   **Registration Notes** (`registration_notes`, text, required/optional): Enter any additional registration notes.
*   **Attendee Name** (`attendee_name`, text, required/optional): Enter the name of the attendee.
*   **Attendee Email** (`attendee_email`, email, required/optional): Enter the email of the attendee.
*   **Registration Notes** (`registration_notes`, text, required/optional): Enter any additional registration notes.

## Tips
*   Ensure that you complete all required fields accurately and thoroughly.
*   If a field is marked as optional, feel free to provide any additional information that you think is relevant.
*   If you are unsure about any field, please contact the event organizers for clarification.
