# Fashion Label Launch RSVP Form - Help Guide
## Purpose
The Fashion Label Launch RSVP Form is designed to collect RSVPs from attendees for various fashion-related events. This form helps event organizers track event registrations in a structured and organized manner.

## How To Complete This Form
To complete this form, follow these steps:

1.  Select the correct event to RSVP to from the "Event Registration Forms" field.
2.  Enter your name and contact information in the "RSVP Forms" field.
3.  Confirm your RSVP in the "Event Registration Forms" field.

## Field-by-Field Explanation
* **Event Registration Forms** (`event_registration_forms_rsvp_forms`, text, required): Select the event you want to RSVP to from this dropdown list. This field is necessary to ensure you are registered for the correct event.
* **RSVP Forms** (`rsvp_forms`, text, optional): Enter your name and contact information here. This field is optional, but it's recommended to provide your details so we can contact you about the event.
* **Event Registration Forms** (`event_registration_forms`, text, required): Please note that this field is a duplicate of `event_registration_forms_rsvp_forms`. However, it is still required for the form to function properly. Enter your RSVP confirmation here.
