# Township Ride Registration Form - Help Guide
## Purpose
The Township Ride Registration Form is used to register events, such as rides, events, and tours, with the township. This form collects information about the event, including its type, start and end dates, duration, capacity, and any additional notes.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the type of event (Ride, Event, or Tour) in the "Event Type" field.
2. Enter the event's start date and end date in the "Event Start Date" and "Event End Date" fields, respectively.
3. Choose the capacity of the event from the "Capacity" field.
4. Add any additional notes about the event in the "Notes" field.
5. Fill in the "Name" field with the name of the event organizer or contact person.
6. Enter the "Email" and "Phone" fields with the contact information of the event organizer or contact person.

## Field-by-Field Explanation
* **Event Type (id: 5)**: Choose the type of event (Ride, Event, or Tour) that you are registering.
* **Name (id: 2)**: Enter the name of the event organizer or contact person.
* **Email (id: 3)**: Enter the email address of the event organizer or contact person.
* **Phone (id: 4)**: Enter the phone number of the event organizer or contact person.
* **Event Start Date (id: 6)**: Enter the date when the event will start.
* **Event End Date (id: 7)**: Enter the date when the event will end.
* **Event Duration (id: 8)**: Enter the duration of the event.
* **Capacity (id: 9)**: Choose the capacity of the event (20, 50, or 100).
* **Notes (id: 10)**: Add any additional notes about the event.
* **Event Registration (id: 1)**: This field is not actually required, but it's likely a placeholder for event description or details.
