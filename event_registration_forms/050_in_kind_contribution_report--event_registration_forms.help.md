# in_kind_contribution_report - Help Guide
## Purpose
The "in_kind_contribution_report" form is used to report non-cash contributions received by an organization in the context of specific events.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the **Event Date** of the event for which you are reporting the in-kind contribution.
2. Fill in the **Event Name** with the name of the event.
3. Provide a brief **In-Kind Contribution Description** of the contribution (e.g., goods, services, or time provided).
4. Enter the **Non-Cash Donations** amount (if applicable).
5. Enter the **Non-Cash Value** of the in-kind contribution (e.g., the monetary value of the goods or services provided).
6. Select the **Event Type** that best categorizes the event (e.g., fundraising event, awareness event, etc.).
7. Select all **Event Status** that apply to the event (e.g., completed, cancelled, or ongoing).

## Field-by-Field Explanation

* **Event Date** (ID 1): Enter the date of the event for which you are reporting the in-kind contribution.
* **Event Name** (ID 2): Enter the name of the event.
* **In-Kind Contribution Description** (ID 3): Provide a brief description of the in-kind contribution (e.g., goods, services, or time provided).
* **Non-Cash Donations** (ID 4): Enter the amount of in-kind donations received (if applicable).
* **Non-Cash Value** (ID 5): Enter the monetary value of the in-kind contribution.
* **Event Type** (ID 6): Select the event type that best categorizes the event (e.g., fundraising event, awareness event, etc.).
* **Event Status** (ID 7): Select all status that apply to the event (e.g., completed, cancelled, or ongoing).

## Tips
- Ensure that the event information aligns with the event type and status.
- If the form is being used to report a single event, ensure that the event date is correct.
- If the form is being used to report multiple events, ensure that each event's information is accurately reflected.
- Review the form carefully before submitting to ensure that all required fields are completed and that the information is accurate. 

Note: The required fields are marked with an asterisk (*) symbol in the help guide for easier identification.
