# Media Release Authorization Form - Help Guide

## Purpose
The Media Release Authorization Form is used to gather information from participants of events, such as photo, video, or live stream captures, to obtain their consent for the use of their likeness or image in media. This form is an essential document that helps us ensure we have the necessary permissions to use their image or likeness for promotional, educational, or other purposes.

## How To Complete This Form
To complete this form, follow these steps:

1.  Review the form carefully and make sure you understand the questions and the options provided.
2.  Fill out the required fields as indicated.
3.  Answer all questions truthfully and accurately.
4.  Submit the form once you have completed it.

## Field-by-Field Explanation

* **Event Registration Form** (1):
    The Event Registration Form asks for your basic event registration information. This includes the event name, date, and other relevant details. You can enter your event name, date, and any other relevant details in this field.
* **Media Release** (2):
    Select "True" if you agree to the use of your likeness or image in media. Select "False" if you do not give your consent.
* **Likeness in Media** (3):
    Please provide a brief description of any likeness or images you do not wish to be included in media. For example, you might not want your face or name to be featured prominently in a photo or video.
* **Consent Date** (4):
    If you select "True" in the Media Release field, the Consent Date is the date on which you are granting permission for the use of your likeness or image. Please enter the date on which you are granting this permission.

## Tips
*   Please answer all questions honestly and accurately.
*   If you have any concerns or questions, please contact us.
*   If you are unsure about any of the fields or options, please ask for clarification before submitting the form.
