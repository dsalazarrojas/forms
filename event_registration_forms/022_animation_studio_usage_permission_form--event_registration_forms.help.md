# Animation Studio Usage Permission Form - Help Guide
## Purpose
The Animation Studio Usage Permission Form is used to obtain usage permissions from clients for animations produced by the studio. This form helps to ensure that both parties have a clear understanding of how the animation will be used and by whom.

## How To Complete This Form
To complete this form, please follow these steps:

1.  Provide your client's information, including name, company/brand name, and email address.
2.  Enter the project name and a brief description of the work.
3.  Select the type of project (e.g., commercial, educational, entertainment, etc.).
4.  Specify how you want to use this work (e.g., portfolio, case study, social media marketing, etc.).
5.  Grant permission to the studio for promotional use, feature as a case study, and industry award submissions.
6.  Specify where and for how long you want this work to be shared (e.g., website, social media platforms, education institutions, etc.).
7.  Choose the credit format you prefer for the studio's work.

## Field-by-Field Explanation
- **Client Name** (`client_name`, text, required): Enter your full name.
- **Company/Brand Name** (`company_name`, text, required): Enter your organization name.
- **Email Address** (`email_address`, email, required): Enter your contact email address.
- **Project Name** (`project_name`, text, required): Enter the name of the animation project.
- **Project Description** (`project_description`, text, required): Enter a brief description of the work.
- **Project Type** (`project_type`, select_one, required): Select the type of project (e.g., commercial, educational, entertainment, etc.).
- **Project Completion Date** (`completion_date`, date, optional): Enter the date the project was completed.
- **How do you want to use this work** (`usage_type`, select_multiple, required): Select all intended uses (e.g., portfolio, case study, social media marketing, etc.).
- **Permission for studio promotional use** (`promotional_use`, select_one, required): Grant permission for studio promotional use (e.g., yes, with credit, yes anonymously, etc.).
- **Permission to feature as case study** (`case_study_permission`, select_one, required): Grant permission to feature as a case study (e.g., yes, full case study, yes with confidentiality, etc.).
- **Permission for industry award submissions** (`award_submission`, select_one, optional): Grant permission for industry award submissions (e.g., yes, for any awards, yes specific awards only, etc.).
- **Distribution Scope** (`distribution_scope`, select_multiple, optional): Specify where you want this work to be shared (e.g., website, social media platforms, education institutions, etc.).
- **Specific Social Media Platforms Approved** (`social_media_platforms`, select_multiple, optional): Specify which social media platforms you approve for sharing this work.
- **Duration of Usage Permission** (`permission_duration`, select_one, required): Select how long you want this permission to last (e.g., perpetual, 1 year, 2 years, etc.).
- **Specific End Date if Applicable** (`end_date`, date, optional): If applicable, enter the specific end date for this permission.
- **How should the studio be credited** (`credit_requirements`, select_one, required): Select how you want the studio to be credited (e.g., animation by studio name, animated by studio name, etc.).
- **Custom Credit Format** (`custom_credit`, text, optional): If you have a custom credit format, describe it here.
- **I grant the above usage permissions** (`legal_agreement`, select_one, required): Acknowledge agreement to all terms.

## Tips

* Please make sure you understand the intended use of the animation before completing this form.
* Be specific about how you want to use this work and how you want to be credited.
* Make sure to review all fields carefully before submitting the form.
* If you have any questions or concerns, please contact the studio.
