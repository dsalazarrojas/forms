# Charity Event Supplies Order Form - Help Guide
## Purpose
The Charity Event Supplies Order Form is designed to collect information for charity event supplies orders, ensuring efficient and accurate ordering processes.

## How To Complete This Form

1. **Order Number** (`order_number`, text, optional): Enter a unique identifier for this order, if desired.
2. **Order Date** (`order_date`, date, required): Enter the date when this order is being placed.
3. **Supplies Needed By Date** (`needed_by_date`, date, required): Enter the date when you need these supplies.
4. **Event Details**
   - **Event Name** (`event_name`, text, required): Enter the name of the charity event.
   - **Event Date** (`event_date`, date, required): Enter the date of the charity event.
   - **Event Location** (`event_location`, text, required): Enter the location of the charity event.
   - **Expected Number of Guests** (`expected_guests`, number, required): Enter the number of people expected to attend the event.
5. **Supplies Needed**
   - **Primary Supply Category** (`supply_category`, select_one, required): Choose a category from the list of options provided:
     - Decorations
     - Table Setup
     - Signage
     - Serving Materials
     - Audio-Visual
     - Furniture
     - Linens
     - Tableware
     - Other
   - **Specific Items Needed** (`specific_items`, text, required): List all items you need to order.
   - **Quantities for Each Item** (`quantities`, text, required): Enter the quantity of each item needed.
   - **Color or Design Preferences** (`color_preferences`, text, optional): Enter any specific colors or styles required.
6. **Logistics**
   - **Delivery Address** (`delivery_address`, text, required): Enter the delivery address where supplies should be delivered.
   - **Delivery Contact Person** (`delivery_contact`, text, required): Enter the name of the person receiving the delivery.
   - **Contact Phone Number** (`contact_phone`, text, required): Enter the phone number for delivery coordination.
7. **Optional Fields**
   - **Estimated Budget for Supplies** (`estimated_budget`, number, optional): Enter the budget in dollars.

## Tips
- Make sure to fill in all required fields to ensure accurate and efficient processing.
- If you have any special requirements or instructions, use the **Special Instructions or Notes** field to include them.
- Double-check the form before submission to ensure all fields are filled correctly.

Note: This help guide is based on the provided YAML and assumes that all fields are as intended. If any field's label, type, or options are unclear, please clarify through further instructions or corrections.
