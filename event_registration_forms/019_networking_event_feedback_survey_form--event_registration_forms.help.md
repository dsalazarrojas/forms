# Networking Event Feedback Survey Form - Help Guide
## Purpose
This survey form is designed to collect feedback from attendees of networking events to help us understand their experience and identify areas for improvement.

## Tips
* Be as accurate and detailed as possible when filling out this form to help us improve future events.
* If you have any additional comments or suggestions, please use the open-ended text fields to provide more information.
* Please select all the options that apply to your experience with the event.
