# Alumni Gift Delivery Form - Help Guide
## Purpose
This form is used to collect information about the recipient of an alumni gift and schedule its delivery.

## How To Complete This Form
To complete the form, follow the steps outlined above.

## Field-by-Field Explanation
* **Recipient name (Required)**: Enter the full name of the person receiving the gift.
* **Delivery address (Required)**: Enter the street address, city, state, and postal code of the gift recipient.
* **Preferred delivery date**: Select a date for the gift delivery. If left blank, the system will default to the current date.
* **Gift type (Required)**: Choose the type of gift to be delivered from the available options (Bouquet, Merchandise, Certificate).
* **Special instructions**: Enter any special instructions for the delivery, such as a specific delivery location.
* **Sender name (Required)**: Enter your name as the person arranging the delivery.
* **Contact phone (Required)**: Enter your phone number in case the delivery courier needs to contact you.
* **Confirmation email**: Enter an email address to send a delivery confirmation email to. If left blank, the system will not send a confirmation email.
