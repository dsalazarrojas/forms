# Statement Of Persons Needed Form - Help Guide
## Purpose
This form is used to collect information about the persons involved in an event to ensure that they can be contacted and communicated with before, during, and after the event. The purpose of this form is to gather essential details such as names, contact information, and a brief statement to help event organizers coordinate with attendees.

## How To Complete This Form
To complete this form, follow these steps:

* Read the form carefully and ensure you have all the required information before starting.
* Fill in the required fields with accurate and up-to-date information.
* For each field, use the following guidelines:
	+ **First Name**: Enter the person's given name (e.g., John).
	+ **Last Name**: Enter the person's last name (e.g., Doe).
	+ **Email**: Enter the person's contact email address.
	+ **Phone**: Enter the person's contact phone number.
	+ **Statement**: Enter a brief statement about the person's role or involvement in the event.

## Field-by-Field Explanation

* **First Name**: The given name of the person (e.g., John). Enter the person's first name in this field.
* **Last Name**: The surname of the person (e.g., Doe). Enter the person's last name in this field.
* **Email**: Enter the person's email address where they can be reached for event-related purposes.
* **Phone**: Enter the person's phone number where they can be contacted for event-related purposes.
* **Statement**: Write a brief description of the person's role or involvement in the event. This will help event organizers know how to interact with them.

## Tips
* Ensure that the information you provide is accurate and up-to-date.
* Double-check that all required fields are filled in before submitting the form.
* If you have any questions or concerns, contact the event organizers for clarification.
