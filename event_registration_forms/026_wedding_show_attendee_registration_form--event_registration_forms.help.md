# Wedding Show Attendee Registration Form - Help Guide
## Purpose
The purpose of this form is to collect and track registration information from attendees of the wedding show. Please fill out the form with your details to participate in the event.

## How To Complete This Form
- Fill out the form completely and accurately.
- Make sure to review each field carefully before submitting.
- If you're unsure about any field, please ask a staff member for assistance.

## Field-by-Field Explanation
* **Event Details**: Enter any relevant details about the event you're attending.
	+ Type: text
	+ Required: false
* **Guest Information**: Enter your guest's personal details.
	+ Type: text
	+ Required: false
* **Contact Information**: Select your title (Mr, Mrs, Ms, or Other).
	+ Type: select_multiple
	+ Required: false
* **Guest Name**: Enter your guest's name.
	+ Type: text
	+ Required: false
* **Phone Number**: Enter your guest's phone number.
	+ Type: text
	+ Required: false
* **Email**: Enter your guest's email address.
	+ Type: text
	+ Required: false
* **Event Details**: Enter any additional details about the event you're attending.
	+ Type: text
	+ Required: false
* **Company Name**: Enter your company's name (if applicable).
	+ Type: text
	+ Required: false
* **Company Information**: Enter any relevant company information (if applicable).
	+ Type: text
	+ Required: false
* **Job Title**: Enter your job title (if applicable).
	+ Type: text
	+ Required: false
* **Company Phone**: Enter your company's phone number (if applicable).
	+ Type: text
	+ Required: false
* **Website**: Enter your company's website (if applicable).
	+ Type: text
	+ Required: false
* **Notes**: Add any additional notes or comments (if applicable).
	+ Type: text
	+ Required: false
