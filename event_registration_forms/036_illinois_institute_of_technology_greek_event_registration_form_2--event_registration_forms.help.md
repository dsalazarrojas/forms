# Illinois Institute of Technology Greek Event Registration Form 2 - Help Guide
## Purpose
This form is designed for registering events within the Illinois Institute of Technology Greek community. It captures essential details about the event, including the event name, date, time, venue, and host information. Additionally, it allows users to specify their RSVP status and preferences, such as food preferences and any special requests. The form also includes fields for additional notes and event importance flags.

## How To Complete This Form

To complete this form, follow these steps:

* Enter the **Event Name**, which should be a brief title of the event.
* Select the **Date** of the event using the calendar picker.
* Choose the **Start Time** and **End Time** of the event using the time picker.
* Specify the **Event Venue**, where the event will take place.
* Add a detailed **Event Description** to help others understand the purpose of the event.
* Select the **Event Host** and provide their **Email** and **Phone Number** for contact purposes.
* Specify the **Number of Guests** attending the event.
* Choose the **Food Preferences** for the guests, such as vegetarian, vegan, or other options.
* If necessary, add any **Special Request** for the event.
* Confirm your **RSVP Status** by selecting 'True' or 'False'.
* If you are RSVPing, specify the **RSVP By** date and time.
* If you are RSVPing, add a message in the **RSVP Message** field.
* Add any **Additional Notes** about the event.
* Finally, click submit to register the event.

## Field-by-Field Explanation

* **Event Name** (`text`, Optional): Enter a brief title of the event.
* **Date** (`date`, Optional): Select the date of the event using the calendar picker.
* **Start Time** (`time`, Optional): Choose the start time of the event using the time picker.
* **End Time** (`time`, Optional): Choose the end time of the event using the time picker.
* **Event Venue** (`text`, Optional): Specify the location of the event.
* **Event Description** (`note`, Optional): Add a detailed description of the event to help others understand its purpose.
* **Event Host** (`text`, Optional): Select the host of the event.
* **Event Host Email** (`email`, Optional): Provide the email of the event host for contact purposes.
* **Event Host Phone** (`text`, Optional): Provide the phone number of the event host.
* **Event Host Address** (`text`, Optional): Specify the address of the event host.
* **Number of Guests** (`number`, Optional): Specify the number of guests attending the event.
* **Food Preferences** (`select_multiple`, Optional): Choose the food preferences for the guests.
* **Special Request** (`text`, Optional): Add any special requests for the event.
* **RSVP** (`select_one`, Required): Confirm your RSVP status by selecting 'True' or 'False'.
* **RSVP By** (`date`, Optional): If RSVPing, specify the RSVP date.
* **RSVP Time** (`time`, Optional): If RSVPing, specify the RSVP time.
* **RSVP Message** (`note`, Optional): Add a message to your RSVP.
* **Additional Notes** (`note`, Optional): Add any additional notes about the event.
* **isImportant** (`text`, Optional): Flag the event as important.
* **isActive** (`text`, Optional): Flag the event as active.
* **isPublic** (`text`, Optional): Flag the event as public.
* **created_by** (`text`, Optional): Automatically populated with the creator's name.
* **created_at** (`text`, Optional): Automatically populated with the creation date.
* **updated_by** (`text`, Optional): Automatically populated with the updater's name.
* **updated_at** (`text`, Optional): Automatically populated with the update date.
