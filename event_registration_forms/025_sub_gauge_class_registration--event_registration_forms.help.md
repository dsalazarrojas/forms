# Sub Gauge Class Registration - Help Guide
## Purpose
The Sub Gauge Class Registration form is a tool for instructors and staff to register students for sub-gauge classes. This form gathers essential information about students who wish to enroll in these specialized training sessions.

## How To Complete This Form
To complete this form, follow these steps:

1. Start by filling out the Participant Details page.
2. On the Preferred Class Dates page, select your preferred dates for the class.
3. Provide the required information on the Attendee Information page.
4. Enter the Class Scheduling details, if applicable.
5. Fill out the Shooting Range Details page, if necessary.
6. Provide any additional Event Information.
7. Enter the Training Provider Details, if relevant.
8. Enter the Class Info details.
9. Fill out the Sub Gauge Details.
10. Enter the Sub Gauge Class Scheduling, if applicable.
11. Finally, provide any Notes or comments.

## Field-by-Field Explanation

* **Participant Details**: Enter your name and any other contact information that you want to be associated with your sub-gauge class registration.
* **Preferred Class Dates**: Select your preferred dates for the class. You can choose one or multiple dates, as indicated by the 'Yes' and 'No' options.
* **Attendee Information**: Please enter any relevant information about yourself, such as your instructor certification or experience level.
* **Class Scheduling**: Enter any scheduling information for the class, such as the start and end times.
* **Shooting Range Details**: Enter any details about the shooting range where the class will take place.
* **Event Info**: Provide any additional information about the event or class.
* **Training Provider Details**: Enter any details about the training provider, such as their contact information.
* **Class Info**: Enter any details about the class, such as the topic or agenda.
* **Sub Gauge Details**: Fill out this field to provide any specific details about the sub-gauge class.
* **Sub Gauge Class Scheduling**: Enter any scheduling information for the sub-gauge class.
* **Sub Gauge Class Registration**: Enter any additional information about the sub-gauge class registration.
* **Notes**: Add any notes or comments about your registration or class experience.

Tips: Make sure to double-check your entries for accuracy and completeness, and ask for help if you are unsure about any field.
