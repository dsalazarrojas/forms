# Event Planner Referral Form - Help Guide
## Purpose
This form is designed to be used by event planners to refer their clients to our service, providing us with valuable information to understand the client's needs and the planner's referral source.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill out each field accurately and completely.
2. Ensure that all required fields are filled out.
3. Review each field for relevance and accuracy before submitting the form.

## Field-by-Field Explanation

* **First Name** (`event_planner_referral_form_1`, text, required): Enter the client's first name.
* **Last Name** (`event_planner_referral_form_2`, text, required): Enter the client's last name.
* **Email** (`event_planner_referral_form_11`, email, required): Enter the client's email address.
* **Phone** (`event_planner_referral_form_12`, text, required): Enter the client's phone number.
* **Referral Reason** (`event_planner_referral_form_5`, text, required): Describe why the client is being referred to our service.
* **How Did You Find Us?** (`event_planner_referral_form_6`, select multiple, required): Choose how the client found us from the list of options.
* **Event** (`event_planner_referral_form_7`, select one, required): Select the event type that the client is being referred for.
* **Referral Source** (`event_planner_referral_form_13`, select one, required): Choose the source of the referral.
* **Referral Type** (`event_planner_referral_form_14`, select one, required): Choose the type of referral.
* **Referral Message** (`event_planner_referral_form_15`, text, required): Enter a message to the client.
* **Note** (`event_planner_referral_form_10`, note, optional): Add any additional information or notes about the referral.

## Tips
* Be sure to review each field carefully before submitting the form.
* If a field is not required, you still need to enter the correct information to ensure accurate processing.
* If you have any questions or concerns about this form, please contact us.
