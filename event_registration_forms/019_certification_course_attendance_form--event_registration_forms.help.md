# Certification Course Attendance Form - Help Guide
## Purpose
This form is used to record and track attendance information for certification courses. It captures details such as attendance date, course name, session number, instructor name, session start and end times, location, and attendee information including names, IDs, and arrival and departure times.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the required fields with the relevant information for the certification course.
2. Enter the attendance date.
3. Enter the course name.
4. Enter the course code (if available).
5. Enter the session number.
6. Enter the instructor name.
7. Enter the session start and end times.
8. Enter the session location.
9. Enter the total number of attendees present.
10. Enter any attendance notes.
11. Enter the name of the person submitting the form.
12. Sign your name as the submitter.

## Field-by-Field Explanation
* **Attendance Date** (`attendance_date`, date, required): The date on which the course session took place.
* **Course Name** (`course_name`, text, required): The name of the certification course.
* **Course Code** (`course_code`, text, optional): The identification code for the course (if applicable).
* **Session Number** (`session_number`, number, required): The number of the session attended.
* **Instructor Name** (`instructor_name`, text, required): The name of the course instructor.
* **Session Start Time** (`session_start_time`, time, required): The start time of the session.
* **Session End Time** (`session_end_time`, time, required): The end time of the session.
* **Session Location** (`location`, text, required): The location where the session was held.
* **Total Number of Attendees** (`total_attendees`, number, required): The total number of people present at the session.
* **Attendance Notes** (`attendance_notes`, text, optional): Any additional notes or comments about attendance.
* **Form Submitted By** (`submitted_by`, text, required): The name of the person submitting the form.
* **Submission Signature** (`submission_signature`, text, required): Sign your name as the submitter.
* **Attendee 1 Name** (`attendee_name_1`, text, required): The full name of the first attendee.
* **Attendee 1 ID** (`attendee_id_1`, text, optional): The student or employee ID of the first attendee.
* **Attendee 1 Arrival Time** (`arrival_time_1`, time, optional): The time of arrival for the first attendee.
* **Attendee 1 Departure Time** (`departure_time_1`, time, optional): The time of departure for the first attendee.
* **Attendee 2 Name** (`attendee_name_2`, text, optional): The full name of the second attendee.
* **Attendee 2 ID** (`attendee_id_2`, text, optional): The student or employee ID of the second attendee.
* **Attendee 2 Arrival Time** (`arrival_time_2`, time, optional): The time of arrival for the second attendee.
* **Attendee 2 Departure Time** (`departure_time_2`, time, optional): The time of departure for the second attendee.
* **Attendee 3 Name** (`attendee_name_3`, text, optional): The full name of the third attendee.
* **Attendee 3 ID** (`attendee_id_3`, text, optional): The student or employee ID of the third attendee.
* **Attendee 3 Arrival Time** (`arrival_time_3`, time, optional): The time of arrival for the third attendee.
* **Attendee 3 Departure Time** (`departure_time_3`, time, optional): The time of departure for the third attendee.
* **Attendance Notes** (`attendance_notes`, text, optional): Any additional notes or comments about attendance.
