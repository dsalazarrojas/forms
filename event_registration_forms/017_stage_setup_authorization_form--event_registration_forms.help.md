# Stage Setup Authorization Form - Help Guide
## Purpose
The Stage Setup Authorization Form is used for planning and authorization of event set-ups. It helps users manage event details, assign staff, and track setup status.

## How To Complete This Form
To complete this form, follow these steps:

1. Ensure you have all required information before starting the form.
2. Select the relevant event details from the "Event Details" field.
3. Enter your contact information in the "Contact Name", "Contact Email", and "Contact Phone" fields.
4. Select the assigned tool from the "Assigned Tool" field.
5. Choose the event status from the "Event Status" field.
6. Select the event type from the "Event Type" field.
7. Choose the event category from the "Event Category" field.
8. Select the event subcategory from the "Event Subcategory" field.
9. Choose the event tags from the "Event Tags" field.
10. Select the event priority from the "Event Priority" field.
11. Enter any additional event planner notes in the "Event Planner Notes" field.
12. Enter any comments in the "Event Planner Comments" field.

## Field-by-Field Explanation
* **Event Details**: Select one or multiple events from the given options. This field is used to categorize or manage events.
* **Event Status**: Choose the status of the event (Active, Inactive, or Archived). This field is used to track the event's status.
* **Event Type**: Select the type of event (Conference, Meetup, or Workshop). This field is used to classify the event's type.
* **Event Category**: Choose the category of the event (Public Event, Private Event, or Internal Event). This field is used to categorize the event's category.
* **Event Subcategory**: Select the subcategory of the event (Event A, Event B, or Event C). This field is used to further categorize the event's subcategory.
* **Event Tags**: Select multiple tags for the event (Tag 1, Tag 2, or Tag 3). This field is used to add additional metadata to the event.
* **Event Priority**: Choose the priority of the event (High or Low). This field is used to determine the event's priority.
* **Assigned Tool**: Select the tool assigned to the event (chatjimmy or other). This field is used to assign a tool to the event.
* **Assigned User**: Select the user responsible for the event (John, Jane, or Jim). This field is used to assign a user to the event.
* **Event Planner Notes**: Enter any additional notes about the event. This field is used to add any additional information about the event.
* **Event Planner Comments**: Enter any comments about the event. This field is used to add any comments about the event.
* **Stage Setup Status**: Choose the status of the setup (Approved, In Progress, or Rejected). This field is used to track the status of the setup.
* **Stage Setup Complete**: Choose whether the setup is complete or not (True or False). This field is used to determine if the setup is complete.
* **Contact Name**: Enter the contact name.
* **Contact Email**: Enter the contact email.
* **Contact Phone**: Enter the contact phone number.
* **Created By**: Select the user who created the event (John, Jane, or Jim). This field is used to track who created the event.
* **Stage Setup Complete**: Enter any notes about the setup being complete.
* **Date**: Enter the date of the event.
* **Start Time**: Enter the start time of the event.
* **End Time**: Enter the end time of the event.
* **Duration**: Enter the duration of the event.
* **Notes**: Enter any additional notes about the event.
