# dinner_event_donation_form - Help Guide
## Purpose
The dinner_event_donation_form allows attendees to register for a dinner event and optionally select specific items or quantities they would like to request.
## How To Complete This Form
To complete this form, please follow these steps:
1. Fill in your attendee information in the **Attendee Info** page.
2. On the **Requested Items** page, select the item(s) you would like to request by checking the boxes next to the item(s).
3. On the **Quantity** page, enter the quantity of each selected item you would like to request.
4. On the **Additional Notes** page, provide any additional information you would like to share with us.

## Field-by-Field Explanation
* **Attendee Info** (`text`, **required**):
	+ This is where you enter your attendee information, such as your name and contact details.
* **Requested Items** (`select_multiple`, **optional**):
	+ Select one or more items from the list that you would like to request.
* **Quantity** (`number`, **optional**):
	+ Enter the quantity of each selected item you would like to request.
* **Additional Notes** (`text`, **optional**):
	+ Provide any additional information about your request or event preferences.
