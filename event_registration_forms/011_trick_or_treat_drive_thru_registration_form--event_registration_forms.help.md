# Trick Or Treat Drive Thru Registration Form - Help Guide

## Purpose
This form is for registering attendees and staff for a Trick or Treat drive-thru event. It collects necessary information for event organization and execution.

## How To Complete This Form

1. Fill out the form with the required fields marked as "required".
2. Enter your name (First and Last) and email address to register yourself and any other staff member or trick or treater.
3. Select your T-shirt size and the number of trick or treaters attending with you.
4. Enter any relevant costume details and special requests, if applicable.
5. Select the assigned tool or personnel for the event.
6. Enter the date and start and end times for the event.
7. Choose the location for the event.
8. Add any additional event notes or trick or treat notes if needed.
9. Enter a brief event description, if desired.
10. Select the individuals assigned to work with you for the event.

### Field-by-Field Explanation

* **First Name** (`first_name`, text, required):
	+ Enter your first name.
* **Last Name** (`last_name`, text, required):
	+ Enter your last name.
* **Email** (`email`, email, required):
	+ Enter your email address.
* **Phone** (`phone`, text, required):
	+ Enter your phone number.
* **T-Shirt Size** (`t_shirt_size`, select_one, required):
	+ Select your T-Shirt size (S, M, L).
* **Trick or Treaters** (`trick_or_treaters`, number, required):
	+ Enter the number of individuals attending with you.
* **Costume** (`costume`, text, optional):
	+ Enter any relevant costume information.
* **Special Requests** (`special_requests`, note, optional):
	+ Enter any special requests or notes about your participation.
* **Assigned to** (`assigned_to`, select_multiple, required):
	+ Select the assigned tool or personnel for the event.
* **Event Date** (`event_date`, date, required):
	+ Enter the date for the event.
* **Event Start Time** (`event_start_time`, time, required):
	+ Enter the start time for the event.
* **Event End Time** (`event_end_time`, time, required):
	+ Enter the end time for the event.
* **Assigned Tool** (`assigned_tool`, select_multiple, optional):
	+ Select the assigned tool or personnel for the event.
* **Event Location** (`event_location`, text, required):
	+ Enter the location for the event.
* **Event Description** (`event_description`, text, optional):
	+ Enter a brief description of the event.
* **Event Notes** (`event_notes`, note, optional):
	+ Enter any additional notes for the event.
* **Trick or Treaters Count** (`trick_or_treaters_count`, number, optional):
	+ Enter the number of individuals attending with you.
* **Event Trick or Treat Time** (`trick_or_treat_time`, time, optional):
	+ Enter the trick or treat time.
* **Trick or Treat Count** (`trick_or_treaters_count`, number, optional):
	+ Enter the number of individuals attending with you.
* **Trick or Treat Time End** (`trick_or_treat_time_end`, time, optional):
	+ Enter the end time for the trick or treat time.
* **Trick or Treat Time End Range** (`trick_or_treat_time_end_range`, text, optional):
	+ Enter the end time range for the trick or treat time.
* **Trick or Treaters Count Range** (`trick_or_treaters_count_range`, text, optional):
	+ Enter the number range for the individuals attending with you.
* **Trick or Treat Description** (`trick_or_treat_description`, text, optional):
	+ Enter a brief description of the trick or treat session.
* **Trick or Treat Notes** (`trick_or_treat_notes`, note, optional):
	+ Enter any additional notes or comments about the trick or treat session.
