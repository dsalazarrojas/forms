# Event Recording Consent Acknowledgement Form - Help Guide

## Purpose
This form is used to gather the necessary information and consent from event participants for event recordings.

## How To Complete This Form
1. Please select the correct recording method that will be used for this event. You can choose "Video," "Audio," or "None" as per the event's requirements.
2. Enter the date of the event. Please note that this date is required.
3. Enter the time of the event. Like the date, this is a mandatory field.
4. If you are attending an in-person event, please provide the location where the event will take place. However, this field is optional.
5. If you are participating in an online or virtual event, you do not need to fill this field. If you have any comments or feedback regarding the location, you can provide them in the "Additional Comments" field.
6. Enter the duration of the event. While not required, this field helps with event planning.
7. If you would like to be contacted, please enter your name. However, this field is optional.
8. Enter your email address so that we can contact you regarding event recordings. This field is required.
9. If you have a phone number, please enter it for further communication. However, this field is optional.
10. In the "Additional Comments" field, you can add any comments or feedback you may have regarding the event or the recording process. This field is optional.

## Field-by-Field Explanation

* **Event Recording** (Event Recording, text, required): This field is the first step in the consent process. Please select the method of recording that best suits your event needs.
* **Recording Method** (recording_method, select_multiple, required): Choose how your event will be recorded: Video, Audio, or None.
* **Recording Location** (recording_location, text, optional): Enter the location of the event, if applicable. If not, please ignore this field.
* **Recording Purpose** (recording_purpose, text, optional): This field is not currently used and should be ignored.
* **Event Date** (event_date, date, required): Enter the date of the event in the correct format (YYYY-MM-DD).
* **Event Time** (event_time, time, required): Enter the time of the event in the correct format (HH:MM AM/PM).
* **Event Location** (event_location, text, optional): Enter the location of the event, if applicable. If not, you can provide comments in the "Additional Comments" field.
* **Event Duration** (event_duration, number, optional): Enter the duration of the event in minutes.
* **Contact Name** (contact_name, text, optional): If you'd like to be contacted, please enter your name here.
* **Contact E-mail** (contact_email, email, required): Enter the email address where you can be reached for event recordings.
* **Contact Phone** (contact_phone, text, optional): If you'd like to be contacted via phone, please enter your number here.
* **Additional Comments** (additional_comments, note, optional): Add any additional comments or feedback you may have regarding the event or the recording process.
