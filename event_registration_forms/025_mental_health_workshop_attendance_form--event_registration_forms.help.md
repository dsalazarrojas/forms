# Mental Health Workshop Attendance Form - Help Guide
## Purpose

The Mental Health Workshop Attendance Form is used to register participants for mental health workshops. It collects information about the participant, the workshop, and other relevant details.

## How To Complete This Form

1. Fill out the form completely and accurately.
2. Ensure that all required fields are filled out.
3. Double-check your responses before submitting the form.

## Field-by-Field Explanation

* **Participant Name**: A text field for the participant's name. This is a required field.
* **Email**: A text field for the participant's email. This is a required field.
* **Phone**: A text field for the participant's phone number. This is an optional field.
* **Mental Health Specialty**: A select one menu for the participant's mental health specialty. Options include "Yes" and "No". This is an optional field.
* **Workshop Name**: A text field for the workshop name. This is a required field.
* **Workshop Date**: A date field for the workshop date. This is a required field.
* **Workshop Time**: A time field for the workshop time. This is a required field.
* **Workshop Location**: A text field for the workshop location. This is a required field.
* **Event ID**: A number field for the workshop event ID. This is an optional field.
* **Assigned Tool**: A select one menu for the assigned tool. Options include "chatjimmy", "chatjimmy 2", and "chatjimmy 3". This is an optional field.
* **Participant Survey**: A select multiple menu for the participant's survey status. Options include "True", "False", and "unsure". This is an optional field.
* **Workshop Length**: A number field for the workshop length. This is a required field.
* **Participant Status**: A select one menu for the participant's status. Options include "present", "absent", and "declined". This is an optional field.
* **Participant Status Note**: A note field for the participant's status note. This is an optional field.

## Tips

* Double-check your responses before submitting the form.
* Ensure that all required fields are filled out. 
* This form is intended for mental health workshops only, and should not be used for other purposes.
