# shared_workspace_reservation_form - Help Guide
## Purpose
The shared workspace reservation form is used to reserve a shared workspace for an event. This form captures essential information about the event, including the date, time, location, and event details, to ensure accurate and efficient event planning.

## How To Complete This Form
Follow the steps outlined above to complete the form.

## Field-by-Field Explanation
- **Email** (user_email): Enter your email address to associate with the event.
- **Reservation Date** (reservation_date): Select the date of the event.
- **Time** (reservation_time): Enter the start time of the event.
- **End Date** (reservation_end_date): Enter the end date of the event.
- **Event Name** (event_name): Enter the name of the event.
- **Event Location** (event_location): Enter the location of the event.
- **Event Details** (event_details): Enter additional notes about the event.
- **Number of Guests** (number_of_guests): Enter the number of guests attending the event.
- **Start Time** (reservation_start_time): Enter the start time of the event.
- **End Time** (reservation_end_time): Enter the end time of the event.
- **Start Date** (event_start_date): Enter the start date of the event.
- **End Date** (event_end_date): Enter the end date of the event.
- **Organizer** (event_organizer): Enter the name of the event organizer.
- **Organizer Email** (event_organizer_email): Enter the email of the event organizer.
- **Organizer Phone** (event_organizer_phone): Enter the phone number of the event organizer.
- **Notes** (event_notes): Enter any additional notes about the event.
- **Shared Space** (shared_space): Enter the shared space where the event will take place.
- **Shared Space ID** (shared_space_id): Enter the ID of the shared space.
- **Event Status** (event_status): Select the status of the event (active or inactive).
- **Event Status Options** (event_status_options): Select additional event status options.
- **Event Status Label** (event_status_label): Enter a label for the event status.
- **Event Status Value** (event_status_value): Enter a value for the event status.
- **Event Status Note** (event_status_note): Enter a note about the event status.
- **Assigned to** (assigned_to): Enter the name of the person assigned to the event.
- **Assigned Tool** (assigned_tool): Enter the tool assigned to the event.

This guide is designed to be concrete, concise, and practical, providing step-by-step instructions on how to complete the form accurately and efficiently.
