# event_supplies_requisition_form - Help Guide
## Purpose
The event supplies requisition form is used to request supplies and resources to support events. It helps event organizers and coordinators gather information about the event, the supplies needed, and any specific requirements or restrictions.

## How To Complete This Form
1. Complete each page of the form in order.
2. On page 1, enter the event title and description.
3. On page 2, list the supplies and resources needed for the event.
4. On page 3, add any additional comments or notes.

## Field-by-Field Explanation

* **title** (`title`, text, required): Enter a brief title for the event.
* **event_description** (`title`, text, required): Provide a short description of the event.
* **supplies_and_resources** (`title`, text, required): List the supplies and resources needed for the event.
* **additional_comments** (`title`, text, optional): Add any additional comments or notes about the event or supplies needed.

## Tips
- Please provide as much detail as possible when listing supplies and resources.
- If you need any specific requirements or restrictions, make sure to mention them in the supplies and resources list.
- Use a separate line for each item in the supplies and resources list.
- You can add any additional comments or notes about the event on page 3.
