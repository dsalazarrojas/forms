# Assembly Project Form - Help Guide
## Purpose
This form is used to collect and record crucial information about an assembly project, enabling project managers and team leaders to track and manage project progress and resources effectively.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the project name in the "Assembly Project Name" field.
2. Select the lead supervisor from the available team members.
3. List all team members assigned to the project.
4. Enter the project's start and target completion dates in the "Project Start Date" and "Target Completion Date" fields respectively.
5. Provide a list of required materials needed for the project.
6. If necessary, mention any tooling and machinery requirements.
7. Add any necessary safety precautions or notes for team members.
8. Enter the total budget allocated for the project.
9. Select the current project status from the provided options.
10. Add any status notes or obstacles that need to be addressed.

## Field-by-Field Explanation
* **Assembly Project Name (Assembly Project Name)**: Enter the project's name.
* **Lead Supervisor (Lead Supervisor)**: Select the team leader responsible for overseeing the project.
* **Team Members Assigned (Team Members Assigned)**: List all team members involved in the project.
* **Project Start Date (Project Start Date)**: Enter the date when the project is expected to start.
* **Target Completion Date (Target Completion Date)**: Enter the date by which the project should be completed.
* **List of Required Materials (List of Required Materials)**: Provide a list of materials required for the project.
* **Tooling and Machinery Requirements (Tooling and Machinery Requirements)**: Specify any tooling and machinery requirements for the project. (Note: This field is optional.)
* **Safety Precautions (Safety Precautions)**: Add any safety precautions or notes for team members to follow.
* **Total Budget Allocated (Total Budget Allocated)**: Enter the total budget allocated for the project in USD.
* **Current Project Status (Current Project Status)**: Select the current project status from the provided options.
* **Status Notes and Obstacles (Status Notes and Obstacles)**: Add any status notes or obstacles that need to be addressed. (Note: This field is optional.)
