This form is used for exhibitors to book an internet connection for their booth at an event. The form collects information about the exhibitor, their contact details, event information, and technical requirements for the internet connection. The form is designed to be completed by the exhibitor and submitted to the event organizers for processing. The event organizers will review the submitted forms to ensure that they can provide the necessary resources to meet the exhibitor's requirements. This form is a one-time submission form and does not require repeated submissions for the same event.

## Booth Internet Connection Booking Form - Help Guide

## Purpose
The Booth Internet Connection Booking Form is used to provide exhibitors with the necessary information to book an internet connection for their booth at an event.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill in the exhibitor's name and contact person's name in the "Exhibitor Name" and "Contact Person" fields respectively.
2. Enter the contact person's email address in the "Email Address" field.
3. Enter the contact person's phone number in the "Phone Number" field.
4. Fill in the name of the event in the "Event Name" field.
5. Select the date of the event in the "Event Date" field.
6. Enter the booth number assigned to the exhibitor in the "Booth Number" field.
7. Select the type of internet connection needed (e.g. WiFi, Ethernet, etc.) in the "Internet Connection Type Needed" field.
8. Select the intended use of the internet connection (e.g. point of sale, video streaming, etc.) in the "Intended Internet Usage" field.
9. Select the estimated bandwidth needed for the connection in the "Estimated Bandwidth Need" field.
10. Enter the number of devices that need to be connected to the internet in the "Number of Devices to Connect" field.
11. If needed, select "Yes, need backup" in the "Need Backup Connectivity" field.
12. If needed, select "Yes, need assistance" in the "Technical Setup Support Needed" field.
13. Select the priority of the connection in the "Connection Priority" field.
14. If there are any special requirements, enter them in the "Special Requirements" field.

## Field-by-Field Explanation

* **Exhibitor Name** (`exhibitor_name`, `text`, required): Enter your company or name as the exhibitor.
* **Contact Person** (`contact_person`, `text`, required): Enter the full name of the contact person.
* **Email Address** (`contact_email`, `email`, required): Enter the contact email address of the contact person.
* **Phone Number** (`contact_phone`, `text`, required): Enter the contact phone number of the contact person.
* **Event Name** (`event_name`, `text`, required): Enter the name of the event.
* **Event Date** (`event_date`, `date`, required): Select the date of the event.
* **Booth Number** (`booth_number`, `text`, required): Enter the booth number assigned to you.
* **Internet Connection Type Needed** (`connection_type`, `select_one`, required): Select the type of internet connection needed (e.g. WiFi, Ethernet, etc.).
* **Intended Internet Usage** (`internet_usage`, `select_multiple`, required): Select the intended use of the internet connection (e.g. point of sale, video streaming, etc.).
* **Estimated Bandwidth Need** (`bandwidth_requirement`, `select_one`, required): Select the estimated bandwidth needed for the connection.
* **Number of Devices to Connect** (`number_of_devices`, `number`, required): Enter the number of devices that need to be connected to the internet.
* **Need Backup Connectivity** (`backup_connectivity`, `select_one`, required): If needed, select "Yes, need backup".
* **Technical Setup Support Needed** (`setup_support`, `select_one`, required): If needed, select "Yes, need assistance".
* **Connection Priority** (`connection_priority`, `select_one`, required): Select the priority of the connection (e.g. critical, important, etc.).
* **Special Requirements** (`special_requirements`, `text`, required): If there are any special requirements, enter them here.

Note: Some fields may have additional guidance or instructions in the hints provided. Please follow those guidelines when filling out the form.
