# Product Anniversary Celebration RSVP - Help Guide
## Purpose
This form is used to RSVP to a product anniversary celebration event. Please fill out the form carefully to ensure accurate information is submitted.

## How To Complete This Form
1. Review the form carefully and ensure you have completed all required fields.
2. Fill in the Event Name field with the actual name of the event.
3. If attending, select the number of guests in the Guest Count field.
4. In the Guest Preferences field, select any dietary restrictions or preferences you have.
5. Enter the Event Date for the celebration in the Event Date field.
6. Enter the Event Time for the celebration in the Event Time field.
7. Fill in the Event Location field with the location of the event.
8. To confirm your attendance, select 'True' in the RSVP field.
9. If you have any additional comments, please provide them in the Comment field.

## Field-by-Field Explanation
- **Event Name** (`event_name`, Text, Optional): This field is where you enter the name of the event. Please provide the actual name of the event being celebrated.
- **Guest Count** (`guest_count`, Number, Optional): If attending, please enter the number of guests you will bring with you to the event.
- **Guest Preferences** (`guest_preferences`, Select Multiple, Optional): Select any dietary restrictions or preferences you have, such as Vegetarian or Vegan.
- **Event Date** (`event_date`, Date, Optional): This field is for the date of the event. Please enter the date in the correct format.
- **Event Time** (`event_time`, Time, Optional): This field is for the time of the event. Please enter the time in the 24 hour format (e.g., 14:00 for 2:00 PM).
- **Event Location** (`event_location`, Text, Optional): Fill in the location of the event, such as the venue or address.
- **RSVP** (`rsvp`, Select One, Required): To confirm your attendance, please select 'True' in this field.
- **Comment** (`comment`, Note, Optional): If you have any additional comments or information about your attendance, please enter them here.
