# Event Decorator Nomination Form - Help Guide
## Purpose
The Event Decorator Nomination Form is designed to collect information about a potential event decorator to help identify them for participation in an event.

## How To Complete This Form

1.  Fill out the form with accurate information about the event planner.
2.  Provide details about the nominee, including their experience and status.
3.  Fill out the event details, such as the nomination date, time, event name, start and end dates, status, and type.
4.  Select the appropriate status for the event and nominee.
5.  Enter any additional notes or tags about the event and nominee.

## Field-by-Field Explanation
* **Event Planner Info** (Event Planner Info, text, required/optional): This field is for the planner of the event. Enter a brief description of who is responsible for planning the event.
* **Nominee Info** (Nominee Info, text, required/optional): Enter details about the person or entity being nominated for the event.
* **Nominee Experience** (Nominee Experience, text, required/optional): Provide information about the nominee's past experience in event decorating, such as any notable events they have participated in.
* **Nomination Date** (Nomination Date, date, required/optional): Enter the date of the nomination.
* **Nomination Time** (Nomination Time, time, required/optional): Enter the time the nomination was made, if known.
* **Event Info** (Event Info, text, required/optional): Enter a brief description of the event, including any relevant information about what the event is.
* **Event Date** (Event Date, date, required/optional): Enter the start date of the event.
* **Event Time** (Event Time, time, required/optional): Enter the start time of the event, if known.
* **Event Status** (Event Status, select_one, required/optional): Select the status of the event from the following options: Active, Inactive, or Pending.
* **Nominee Status** (Nominee Status, select_one, required): Select the status of the nominee from the following options: Active, Inactive, or Pending.
* **Nominee Name** (Nominee Name, text, required/optional): Enter the name of the nominee.
* **Nominee Title** (Nominee Title, text, required/optional): Enter the title or position of the nominee.
* **Event Description** (Event Description, text, required/optional): Enter a detailed description of the event, including any relevant details.
* **Event Notes** (Event Notes, text, required/optional): Enter any additional notes or comments about the event.
* **Event Category** (Event Category, text, required/optional): Enter the category or type of the event.
* **Event Type** (Event Type, text, required/optional): Enter the type of the event, such as a concert or festival.
* **Event Tags** (Event Tags, text, required/optional): Enter any relevant tags or keywords for the event.
* **Nominee Tags** (Nominee Tags, text, required/optional): Enter any relevant tags or keywords for the nominee.
* **Nomination Reason** (Nomination Reason, text, required/optional): Enter the reason for the nomination.
* **Event ID** (Event ID, text, required/optional): Enter the ID of the event.
* **Event Name** (Event Name, text, required/optional): Enter the name of the event.
* **Event Start Date** (Event Start Date, date, required/optional): Enter the start date of the event.
* **Event End Date** (Event End Date, date, required/optional): Enter the end date of the event, if known.
