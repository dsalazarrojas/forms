# Event Venue Contract Form - Help Guide
## Purpose
The Event Venue Contract Form is used to capture essential details of event venue contracts for accurate processing and follow-up.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the event venue contract status (`Event Venue Contract Status`).
2. Enter event booking details (if necessary).
3. Select a date and time for the event (`Event Venue Contract Date` and `Event Venue Contract Time`).
4. Enter the duration of the event (`Event Venue Contract Duration`).
5. Fill in the contract price (`Event Venue Contract Price`).
6. Select the person submitting the form (`Event Venue Contract Form Submitted By`).
7. Add any relevant notes about the event contract (`Event Venue Contract Notes`).
8. Enter the venue manager's email address (`Venue Manager Email`).

## Field-by-Field Explanation

* **Event Venue Contract** (`event_venue_contract_form`): 
    * Type: Text
    * Purpose: Enter a brief description of the event contract.
* **Event Venue Booking Details** (`event_venue_booking_details`): 
    * Type: Select one option from the dropdown menu
    * Purpose: Select the booking type.
* **Event Venue Contract Notes** (`event_venue_contract_notes`): 
    * Type: Text
    * Purpose: Enter any relevant notes about the event contract.
* **Venue Manager Email** (`venue_manager_email`): 
    * Type: Email
    * Purpose: Enter the venue manager's email address.
* **Event Venue Contract Date** (`event_venue_contract_date`): 
    * Type: Date
    * Purpose: Select the date of the event.
* **Event Venue Contract Time** (`event_venue_contract_time`): 
    * Type: Time
    * Purpose: Select the time of the event.
* **Event Venue Contract Duration** (`event_venue_contract_duration`): 
    * Type: Text
    * Purpose: Enter the duration of the event.
* **Event Venue Contract Price** (`event_venue_contract_price`): 
    * Type: Number
    * Purpose: Enter the contract price.
* **Event Venue Contract Status** (`event_venue_contract_status`): 
    * Type: Select multiple options from the dropdown menu
    * Purpose: Select the status of the event contract.
* **Event Venue Contract Form Submitted By** (`event_venue_contract_form_submitted_by`): 
    * Type: Select multiple options from the dropdown menu
    * Purpose: Select who submitted the form.
* **Event Venue Contract Form** (`event_venue_contract_form`): 
    * Type: Text
    * Purpose: This field is not currently used and can be ignored.
