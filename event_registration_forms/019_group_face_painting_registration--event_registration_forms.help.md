# group_face_painting_registration - Help Guide
## Purpose
This form is used to register and manage events for face painting services.

## How To Complete This Form
1. Enter the title of the event.
2. Enter the name of the group or organization hosting the event.
3. Enter the name of the school or organization hosting the event.
4. Select the type of event (e.g., Event Type, Face Painting Event, Birthday Party, etc.).
5. Enter the preferred dates for the event.
6. Enter contact information for the person responsible for the event.
7. Enter any special requests or requirements for the event.
8. Enter the number of children and adults attending the event.
9. Select the length of the event.
10. Enter the start and end times for the event.
11. Enter the date of the event.
12. Select the size of the group attending the event.
13. Enter any special requirements or notes for the event.
14. Enter details about the event venue.
15. Enter the address of the event venue.
16. Enter the city where the event is located.
17. Select the state where the event is located.
18. Enter the zip code of the event venue.
19. Select the type of special equipment needed for the event (e.g., Paint, Easel, Paintbrush).
20. Enter any additional event notes or details.
21. Select the payment method for the event.

## Field-by-Field Explanation

* **title**: Enter the title of the event that is being registered.
* **group_name**: Enter the name of the group or organization hosting the event.
* **school_name**: Enter the name of the school or organization hosting the event.
* **event_type**: Select the type of event (e.g., Event Type, Face Painting Event, Birthday Party, etc.).
* **event_dates**: Enter the preferred dates for the event.
* **contact_person**: Enter the contact information for the person responsible for the event.
* **contact_phone**: Enter the phone number for the person responsible for the event.
* **special_requests**: Enter any special requests or requirements for the event.
* **event_venue**: Enter details about the event venue.
* **number_of_children**: Enter the number of children attending the event.
* **number_of_adults**: Enter the number of adults attending the event.
* **event_length**: Select the length of the event.
* **start_time**: Enter the start time for the event.
* **end_time**: Enter the end time for the event.
* **event_date**: Enter the date of the event.
* **group_size**: Select the size of the group attending the event.
* **special_requirements**: Enter any special requirements or notes for the event.
* **event_venue_details**: Enter details about the event venue.
* **event_venue_address**: Enter the address of the event venue.
* **event_venue_city**: Enter the city where the event is located.
* **event_venue_state**: Select the state where the event is located.
* **event_venue_postal_code**: Enter the zip code of the event venue.
* **special_equipment**: Select the special equipment needed for the event (e.g., Paint, Easel, Paintbrush).
* **event_notes**: Enter any additional event notes or details.
* **payment_method**: Select the payment method for the event.
