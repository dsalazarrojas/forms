# Catering Equipment Check Out Form - Help Guide

## Purpose
The Catering Equipment Check Out Form is a crucial document used to request the check out of catering equipment for events and functions. It ensures that all necessary information is collected to facilitate a smooth event experience.

## How To Complete This Form
To complete this form, please follow the instructions below:

1. Enter your **Requester Name** and **Company Name** in the corresponding fields. This information will help us identify you and your organization.
2. Enter your **Email Address** and **Phone Number**, which we will use to contact you for any inquiries or updates.
3. Enter the **Check-out Date** and **Expected Return Date** for the equipment, ensuring that you return the equipment on the agreed-upon date.
4. Provide the **Event Name**, **Event Date**, and **Event Location** details to help us plan and prepare for the event.
5. If required, enter the number of **Tables Requested**, including the type of tables you need (e.g., Round 60-inch, Round 72-inch, Rectangular 6-foot, etc.).
6. If required, enter the number of **Chairs Requested**, including the type of chairs you need (e.g., Folding Chairs, Banquet Chairs, Chiavari Chairs, etc.).
7. If required, enter the number of **Linens Requested**, and select the preferred **Linen Color**.
8. If required, enter any **Serving Equipment** needed (e.g., chafing dishes, platters, etc.).
9. If required, enter any **Audio-Visual Equipment** needed (e.g., microphones, speakers, projectors, etc.).
10. If required, enter any other **Other Equipment** needed.
11. Indicate whether you need **Delivery Required** and if so, select the option.
12. Indicate whether you need **Setup Required** and if so, select the option.
13. Enter the **Deposit Amount**, which is the security deposit for the equipment.
14. Confirm if the **Deposit Paid**.
15. Confirm that you have accepted the **Terms and Conditions**.
16. If required, enter any **Special Instructions** for the event.
17. Enter any **Staff Notes** for internal use.

## Field-by-Field Explanation

* **Requester Name** (`requester_name`, text, required): Enter your full name as the person requesting the equipment check out.
* **Company Name** (`company_name`, text, required): Enter the name of your company or organization.
* **Email Address** (`email`, email, required): Enter your email address to receive updates and inquiries.
* **Phone Number** (`phone`, text, required): Enter your contact phone number to receive updates and inquiries.
* **Check-out Date** (`checkout_date`, date, required): Enter the date when you would like to check out the equipment.
* **Expected Return Date** (`expected_return_date`, date, required): Enter the date when you expect to return the equipment.
* **Event Name** (`event_name`, text, required): Enter the name of the event or function.
* **Event Date** (`event_date`, date, required): Enter the date of the event or function.
* **Event Location** (`event_location`, text, required): Enter the location of the event or function.
* **Tables Requested** (`tables_requested`, number, optional): If needed, enter the number of tables required. Please specify the type of tables (e.g., Round 60-inch, Round 72-inch, etc.).
* **Table Type** (`table_type`, select_one, optional): Select the type of tables needed (e.g., Round 60-inch, Round 72-inch, etc.).
* **Chairs Requested** (`chairs_requested`, number, optional): If needed, enter the number of chairs required. Please specify the type of chairs (e.g., Folding Chairs, Banquet Chairs, etc.).
* **Chair Type** (`chair_type`, select_one, optional): Select the type of chairs needed (e.g., Folding Chairs, Banquet Chairs, etc.).
* **Linens Requested** (`linens_requested`, number, optional): If needed, enter the number of linens required.
* **Linen Color** (`linen_color`, text, optional): Select the preferred linen color.
* **Serving Equipment** (`serving_equipment`, text, optional): Enter any serving equipment needed (e.g., chafing dishes, platters, etc.).
* **Audio-Visual Equipment** (`audio_visual`, text, optional): Enter any audio-visual equipment needed (e.g., microphones, speakers, projectors, etc.).
* **Other Equipment** (`other_equipment`, text, optional): Enter any other equipment needed.
* **Delivery Required** (`delivery_required`, select_one, required): Indicate whether you need delivery services.
* **Setup Required** (`setup_required`, select_one, required): Indicate whether you need setup service.
* **Deposit Amount** (`deposit_amount`, number, required): Enter the security deposit amount.
* **Deposit Paid** (`deposit_paid`, select_one, required): Confirm if the deposit has been paid.
* **Terms and Conditions Accepted** (`terms_accepted`, select_one, required): Confirm that you have accepted the terms and conditions.
* **Special Instructions** (`special_instructions`, text, optional): Enter any special requirements or instructions for the event.
* **Staff Notes** (`staff_notes`, text, optional): Enter any internal staff notes.

Note to reader: This help guide is for informational purposes only. Please use it as a reference to understand the form's fields and their purpose. If you have any questions or need further clarification, please don't hesitate to contact us.
