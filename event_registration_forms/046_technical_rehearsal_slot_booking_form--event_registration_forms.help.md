# Technical Rehearsal Slot Booking Form - Help Guide

## Purpose
This form is used to collect information for technical rehearsal slot bookings.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the event venue field with the location where the technical rehearsal will take place.
2. Provide any technical requirements that need to be met for the rehearsal.
3. Enter the tech rehearsal time and date.
4. Enter the event date and start and end times.
5. Specify the duration of the tech rehearsal.
6. Select any technical requirements that apply to the rehearsal.
7. Enter the contact name, email, and phone number for the person booking the slot.
8. Select the assigned tool for the technical rehearsal.
9. Add any notes or comments for the booker or event venue.
10. Specify the booking status (pending, confirmed, or cancelled).
11. Choose the event type.
12. Add any additional requirements or comments for the booker or event venue.
13. Enter comments for the booker or event venue.
14. Confirm if the event venue is confirmed or not.
15. Enter any comments for the booker or event venue.

## Field-by-Field Explanation

* **Event Venue** (`event_venue`, text, required: false): Enter the location where the technical rehearsal will take place.
* **Technical Requirements** (`technical_requirements`, text, required: false): Provide any technical requirements that need to be met for the rehearsal.
* **Tech Rehearsal Time** (`tech_rehearsal_time`, date, required: false): Enter the time for the technical rehearsal.
* **Event Date** (`event_date`, date, required: false): Enter the date for the technical event.
* **Event Start Time** (`event_start_time`, time, required: false): Enter the start time for the event.
* **Event End Time** (`event_end_time`, time, required: false): Enter the end time for the event.
* **Tech Rehearsal Duration** (`tech_rehearsal_duration`, number, required: false): Specify the duration of the tech rehearsal in hours.
* **Tech Rehearsal Requirements** (`tech_rehearsal_requirements`, text, required: false): Provide any technical requirements that apply to the rehearsal.
* **Technical Requirements List** (`technical_requirements_list`, select_multiple, required: false): Select any technical requirements that apply to the rehearsal.
* **Contact Name** (`contact_name`, text, required: false): Enter the name of the person booking the slot.
* **Contact Email** (`contact_email`, email, required: false): Enter the email address of the person booking the slot.
* **Contact Phone** (`contact_phone`, text, required: false): Enter the phone number of the person booking the slot.
* **Assigned Tool** (`assigned_tool`, select_one, required: false): Select the assigned tool for the technical rehearsal.
* **Notes** (`notes`, note, required: false): Add any notes or comments for the booker or event venue.
* **Booking Status** (`booking_status`, select_one, required: false): Specify the booking status (pending, confirmed, or cancelled).
* **Event Type** (`event_type`, text, required: false): Choose the type of event.
* **Notes For Booker** (`notes_for_booker`, text, required: false): Add any additional notes or comments for the booker.
* **Additional Requirements** (`additional_requirements`, text, required: false): Enter any additional requirements or comments for the booker or event venue.
* **Comments For Booker** (`comments_for_booker`, text, required: false): Enter comments or feedback for the booker or event venue.
* **Comments For Event Venue** (`comments_for_event_venue`, text, required: false): Enter comments or feedback for the event venue.
* **Event Venue Confirmation** (`event_venue_confirmation`, select_one, required: false): Confirm if the event venue is confirmed or not.
* **Comments For Event Venue** (`comments_for_event_venue`, text, required: false): Enter comments or feedback for the event venue.
* **Comments For Booker** (`comments_for_booker`, text, required: false): Enter comments or feedback for the booker.
* **Assigned User** (`assigned_user`, text, required: false): Enter the name of the assigned user.
* **Tech Rehearsal Start Date** (`tech_rehearsal_start_date`, date, required: false): Enter the start date for the tech rehearsal.

Note: Some fields are optional and can be left blank.
