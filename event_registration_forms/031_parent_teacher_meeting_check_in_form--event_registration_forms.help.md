# parent_teacher_meeting_check_in_form - Help Guide
## Purpose
The purpose of this form is to collect information for a meeting check-in between parents and teachers, ensuring everyone is accounted for and on the same page.

## How To Complete This Form
To complete this form, follow these steps:

* Click on the "Submit" button to begin filling out the form.
* Fill in the required fields (none are marked as required on this form, but please fill in as much information as possible).
* Select the parent(s) you would like to register for the meeting using the "contact_info" field.
* Choose the date and time of the meeting using the "meeting_date" and "meeting_time" fields.
* Enter the location of the meeting using the "meeting_location" field.
* Add any comments or notes about the meeting using the "comments" field.
* Once you have filled out all the fields, click "Submit" to submit the form.

## Field-by-Field Explanation
* **meeting_check_in_info** (parent_teacher_meeting_check_in_form_page_1, text, optional): A short description of the meeting check-in, including any relevant details.
* **contact_info** (contact_info, select_one, optional): Select the parent(s) you would like to register for the meeting.
	+ Choose from the options: "parent 1", "parent 2", "parent 3"
* **meeting_date** (meeting_date, date, optional): Enter the date of the meeting.
* **meeting_time** (meeting_time, time, optional): Enter the time of the meeting.
* **meeting_location** (meeting_location, text, optional): Enter the location of the meeting.
* **comments** (comments, text, optional): Add any comments or notes about the meeting.
 
## Tips
* Please ensure that you are only providing information for the meeting if you have the necessary permissions.
* If you need more details or clarification, do not hesitate to ask.
* If you have any issues or concerns while filling out the form, reach out to the form administrator.
* Please review all the fields carefully before submitting the form to avoid mistakes.
* You can also use this form to check in for other events or meetings, just adjust the fields accordingly.
