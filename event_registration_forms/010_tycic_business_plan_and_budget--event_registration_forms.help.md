# Tycic Business Plan And Budget - Help Guide
## Purpose
The "Tycic Business Plan And Budget" form is designed to collect information from users about the Junior Contest event. This form is used to gather essential details for the event.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill in the title of the event in the "Junior Contest" field.
2. Provide a brief description of the event in the "Get The Details" field.
3. Select the category for the event in the "Category" field.
4. If applicable, indicate if the event is a school project in the "School Project" field.
5. Optionally, provide additional details or notes about the event in the "Good Idea" and "Work With A Budget", "Useful" fields.
6. Make sure to fill out all required fields (marked as *required*) before submitting the form.

## Field-by-Field Explanation

* **Junior Contest** (`event_registration_form`, *required*): Enter the title of the event.
* **Good Idea** (`junior_contest_idea`, *optional*): Provide a brief description of the idea or concept behind the event.
* **Work With A Budget** (`budget`, *optional*): Enter any relevant budget information for the event.
* **Get The Details** (`description`, *required*): Enter a brief description of the event.
* **Category** (`category`, *required*): Select the category for the event.
* **School Project** (`school_project`, *optional*): Indicate if the event is a school project.
* **Useful** (`useful`, *optional*): Provide any additional details or notes about the event.
* **Plan Ahead** (`planning_ahead`, *optional*): Enter any relevant planning information for the event.

## Tips
* Make sure to fill out all required fields before submitting the form.
* Double-check your answers for accuracy before submitting.
* If you need help or have questions, please contact form@gic.mx.
