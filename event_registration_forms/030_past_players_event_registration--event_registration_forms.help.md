# Past Players Event Registration - Help Guide
## Purpose
This form is used to register and collect information for past events. It ensures that your registration data is accurate and up-to-date for event management.

## How To Complete This Form

1. Start by filling out the required fields: **Event Name**, **Event Date**, **Event Time**, **Email**, **Number of Attendees**, **Event Type**, **Event Category**, and **Output File**.
2. Choose the appropriate **Event Type** and **Event Category** that best fit your event from the provided options.
3. Select the correct options for **Output File** and **RSVP**.
4. If you're not required to fill out any other fields, you can skip them. Otherwise, fill them out accordingly.

## Field-by-Field Explanation

* **Event Name** (`event_name`, text, required): Enter the name of the event you're registering for.
* **Event Date** (`event_date`, date, required): Enter the date of the event you're registering for.
* **Event Time** (`event_time`, time, required): Enter the time of the event you're registering for.
* **Email** (`event_email`, email, required): Enter your email address.
* **Number of Attendees** (`attendees`, number, required): Enter the number of people attending the event.
* **Event Type** (`event_type`, select_one, required): Choose the type of event from the provided options.
*   *Event Type 1*
*   *Event Type 2*
*   *Event Type 3*
*   Select the option that best describes your event.
* **Event Category** (`event_category`, select_one, required): Choose the category of the event from the provided options.
*   *Category 1*
*   *Category 2*
*   *Category 3*
*   Select the option that best describes your event.
* **Output File** (`output_file`, select_one, required): Select whether or not to generate an output file for the event.
*   *True*
*   *False*
*   Choose the option that best fits your needs.
* **RSVP** (`rsvp`, select_multiple, required): Select whether or not you'll be able to attend the event.
*   *True*
*   *False*
*   You can choose one or both options, depending on your availability.
* **Form IDs** (`form_ids`, text, optional): If you need to enter form IDs, do so here.
* **Description** (`description`, text, optional): Enter a brief description of the event.
* **Assigned Tool** (`assigned_tool`, text, optional): If applicable, enter the tool assigned to your event.
* **Notes** (`notes`, text, optional): Enter any additional notes about the event.

Please fill out the required fields accurately and thoroughly to ensure your event registration data is up-to-date. If you have any doubts, you can always contact the event management team for assistance.
