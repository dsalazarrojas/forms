# Roaring Camp Car Event 2018 - Help Guide
## Purpose
This form is used for event registration and requires the following information: contact method, event date, event start and end times, event location, event description, and the assigned tool.

## How To Complete This Form
To fill out this form, follow the instructions below.

## Field-by-Field Explanation

* **First Name** (1, text, required/optional): Enter your first name here.
* **Last Name** (2, text, required/optional): Enter your last name here.
* **Email** (3, email, required/optional): Enter your email address here.
* **Contact Method** (4, select_one, required): Choose your contact method.
*   - Call: You can be contacted by phone.
*   - Message: You can be contacted by message.
*   - Email: You can be contacted by email.
* **Event Date** (5, date, required): Enter the date of the event.
* **Event Start Time** (6, time, required): Enter the start time of the event.
* **Event End Time** (7, time, required): Enter the end time of the event.
* **Event Location** (8, text, required/optional): Enter the location of the event.
* **Event Description** (9, text, required/optional): Enter a brief description of the event.
* **Assigned Tool** (10, select_one, required): This field will be automatically populated by the event staff based on your event role.
