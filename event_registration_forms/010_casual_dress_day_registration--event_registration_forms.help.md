# Casual Dress Day Registration - Help Guide
## Purpose
The Casual Dress Day Registration form is used to gather information for attendees of the event. Please fill out this form to ensure accurate attendance records and to receive updates and communications about the event.

## How To Complete This Form
1. Fill in your **Registrant name** (required) in the text field.
2. Enter your **Email address** (required) in the email field.
3. If you are representing a **Team or department**, enter its name.
4. If a **Shirt size** is provided, select the corresponding option from the dropdown menu.
5. If you would like to make a **Payment option for donations**, select one of the options (Optional).
6. If you have **Dietary needs**, describe them in the text field.
7. Please indicate your consent to **Event photos** by selecting the corresponding option (Optional).
8. If you need to provide **Emergency contact details**, fill in the name and phone number.
9. If you have **Accessibility requirements**, describe them in the text field.
10. Fill in any **Additional notes** you would like the event organizers to be aware of.

## Field-by-Field Explanation

* **Registrant name** (Registrant name, text, required): 
Enter the full name of the person registering for the event.
* **Email address** (Email address, email, required): 
Please enter the email address where you can be reached for updates and communications.
* **Team or department** (Team or department, text, optional): 
If you are representing a team or department, please enter the name.
* **Shirt size** (Shirt size, select_one, optional): 
Select the shirt size you will be wearing.
* **Payment option for donations** (Payment option for donations, select_one, optional): 
Select how you would like to make a donation, if applicable.
* **Dietary needs** (Dietary needs, text, optional): 
Please describe any dietary needs you may have.
* **Consent to event photos** (Consent to event photos, select_one, optional): 
Please select if you permit the use of your image at the event.
* **Emergency contact details** (Emergency contact details, text, optional): 
Please fill in the name and phone number of an emergency contact person.
* **Accessibility requirements** (Accessibility requirements, text, optional): 
Please describe any accessibility needs you may have.
* **Additional notes** (Additional notes, text, optional): 
Please enter any additional information you would like the event organizers to be aware of.
