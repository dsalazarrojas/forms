# Event Host Nomination Form - Help Guide

## Purpose
This form is used to collect information about potential event hosts for a given event.

## How To Complete This Form

To complete this form, follow these steps:

1. Enter the title of the event you are nominating as a potential host. This is the name of the event as it will be presented to the audience.
2. Enter the name of the host(s) of the event.
3. Enter the email address of the host.
4. Enter the phone number of the host (optional).
5. Select a date for the event (optional, but recommended if the event has not occurred yet).
6. Select the time of day for the event (optional, but recommended if the event has not occurred yet).
7. Enter the location of the event.
8. Provide a brief description of the event.
9. Select the assigned tools for the event from the available options (optional).
10. Select the categories of the event from the available options (optional).

## Field-by-Field Explanation

* **Event Host Nominations** (`event_host_nominations`, `text`, required: false): Enter the name of the event you are nominating.
* **Host Name** (`host_name`, `text`, required: false): Enter the name(s) of the host(s).
* **Host Email** (`host_email`, `email`, required: false): Enter the email address of the host.
* **Host Phone** (`host_phone`, `text`, required: false): Enter the phone number of the host.
* **Event Date** (`event_date`, `date`, required: false): Select a date for the event.
* **Event Time** (`event_time`, `time`, required: false): Select the time of day for the event.
* **Event Location** (`event_location`, `text`, required: false): Enter the location of the event.
* **Event Description** (`event_description`, `note`, required: false): Provide a brief description of the event.
* **Assigned Tools** (`assigned_tools`, `select_multiple`, required: false): Select the tools assigned for the event from the options:
	+ Chatjimmy
	+ Other
* **Event Categories** (`event_categories`, `select_multiple`, required: false): Select the categories of the event from the options:
	+ Yes
	+ No

Note: The fields marked as required: false are not mandatory, but providing the required information will help administrators evaluate the suitability of the nominated host.
