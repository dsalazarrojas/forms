# Holiday Luncheon Entrée Selection - Help Guide
## Purpose

The Holiday Luncheon Entrée Selection form is designed to collect information from guests attending a holiday luncheon event. This form aims to gather details about the guests' preferences, such as their entrée choice and dietary restrictions.

## How To Complete This Form

To complete this form, follow these steps:

1.  Start by filling out the form on the first page, where you can select the name of the event.
2.  On the second page, provide your details as a guest, including your name and any other relevant information.
3.  On the third page, choose your preferred entrée from the available options.
4.  On the fourth page, select any dietary restrictions you may have, such as vegetarian, vegan, or gluten-free.
5.  Finally, on the fifth page, select a date to RSVP for the event.

## Field-by-Field Explanation

*   **Holiday Luncheon Entrée Selection**: This is the title of the form. Select the name of the holiday luncheon event to which you are applying.
*   **Guest Details**:
    + **Name**: Enter your name as you would like to be addressed during the event.
*   **Entrée Choice**: Select your preferred entrée option:
    + **Vegetarian Lasagna**
    + **Chicken Fajitas**
    + **Seafood Paella**
*   **Dietary Restriction**:
    + **Vegetarian**: If you follow a vegetarian diet, select this option.
    + **Vegan**: If you follow a vegan diet, select this option.
    + **Gluten-free**: If you require a gluten-free diet, select this option.
    + **Pork-free**: If you require a pork-free diet, select this option.
*   **RSVP**: Choose a date to RSVP for the event. This is where you can select a date to confirm your attendance at the holiday luncheon.
*   **Time**:
    + This field is not currently populated in the provided YAML, but it would be expected to have a time component for the event.

Note: The field for Time is not populated in the given YAML data, but it would be expected to be included in the form for a proper event registration form.
