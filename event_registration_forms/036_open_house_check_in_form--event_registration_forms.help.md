# Open House Check In Form - Help Guide
## Purpose
The Open House Check In Form is a tool for collecting information from attendees during open houses. It is designed to gather details about the guests, including their names, contact information, event details, and lead status. This information helps agents follow up with potential leads and track event performance.

## How To Complete This Form
To complete the form accurately, follow these steps:

1. Enter your First Name and Last Name in the respective fields.
2. Enter your Email (if applicable).
3. Select the correct Guest Type from the options provided.
4. Add any relevant Guest Comments if necessary.
5. Enter the Event Date and Time (if applicable).
6. Provide Agent Comments (if necessary).
7. Select the Referral Source from the options provided or enter a custom source in the Referral Source Other field.
8. Enter the Referral Source Other Description (if applicable).
9. Specify the Lead Follow-up Date (if necessary).
10. Select the Lead Status from the options provided.
11. Enter Lead Follow-up Notes (if necessary).
12. Enter Event Details (if necessary).
13. Enter Agent Follow-up Notes (if necessary).
14. Enter your Agent Name.
15. Enter your Agent Phone Number (if applicable).
16. Enter your Agent Email (if applicable).
17. Enter your Agent Address (if applicable).
18. Enter Event ID (if necessary).
19. Enter Agent Comments (if necessary).

## Field-by-Field Explanation
* **First Name** (`open_house_checkin_form`, `text`, `true`): Enter your first name as it appears on your name badge.
* **Last Name** (`first_name`, `text`, `true`): Enter your last name as it appears on your name badge.
* **Email** (`email`, `text`, `false`): Enter your email address if you have one. (This field is not required.)
* **Phone** (`phone`, `text`, `false`): Enter your phone number if you have one. (This field is not required.)
* **Guest Type** (`guest_type`, `select_multiple`, `true`): Choose the type of guest you are (Guest, Realtor, or Other).
* **Guest Comments** (`guest_comments`, `note`, `false`): Add any comments about the guest if necessary.
* **Event Date** (`event_date`, `date`, `false`): Enter the date of the event.
* **Time** (`time`, `time`, `false`): Enter the time of the event.
* **Agent Comments** (`agent_comments`, `note`, `false`): Add any comments about the agent if necessary.
* **Referral Source** (`referral_source`, `select_one`, `true`): Choose how you found out about the event (Social Media, Online Listing, Open House Flyer, or Other).
* **Referral Source Other** (`source_other`, `text`, `false`): If you chose 'Other' for Referral Source, enter the source in this field.
* **Referral Source Other Description** (`source_other_description`, `text`, `false`): Enter a brief description of the Referral Source Other.
* **Lead Follow-up Date** (`lead_follow_up_date`, `date`, `false`): Enter the date for the next lead follow-up.
* **Lead Status** (`lead_status`, `select_one`, `true`): Choose the current status of the lead (New Lead, Follow Up Needed, Lead Qualified, or Lead Converted).
* **Lead Follow-up Notes** (`lead_follow_up_notes`, `note`, `false`): Add any notes about the lead follow-up.
* **Event Details** (`event_details`, `note`, `false`): Enter any relevant event details.
* **Agent Follow-up Notes** (`agent_follow_up_notes`, `note`, `false`): Add any notes about the agent follow-up.
* **Agent Name** (`agent_name`, `text`, `true`): Enter your name as the agent.
* **Agent Phone** (`agent_phone`, `text`, `false`): Enter your phone number as the agent.
* **Agent Email** (`agent_email`, `text`, `false`): Enter your email as the agent.
* **Agent Address** (`agent_address`, `text`, `false`): Enter your address as the agent.
* **Event ID** (`event_id`, `text`, `false`): Enter the event ID.
* **Agent Comments** (`agent_comments`, `note`, `false`): Add any comments from the agent.
* **Total Visitors** (`total_visitors`, `number`, `false`): Enter the total number of visitors for the event.

Please fill out the form accurately and completely to ensure that the collected data is useful for future lead follow-ups and event performance tracking. If you have any questions or need further clarification, feel free to ask.
