# Conference Attendance Verification Form - Help Guide
## Purpose

This form is used to verify the attendance of participants at a conference. It is designed to collect information about attendees, including their name, registration ID, and confirmation of sessions attended. The form is completed by a staff member who verifies the attendance of attendees after they have checked in to the conference.

## How To Complete This Form

To complete this form, please follow these steps:

1. Enter the name of the attendee as registered.
2. Enter the registration ID provided at registration.
3. Record the date the attendee checked in.
4. If applicable, list the sessions attended by the attendee.
5. Confirm if a badge was scanned for the attendee.
6. If not required, record the attendee's signature electronically (for internal note only).
7. Enter your name as the verifier.
8. Add any comments about the verification process.
9. Record the time the attendance was confirmed.
10. Select the final confirmation status of the attendance.

## Field-by-Field Explanation

* **Attendee name (Attendee name)**: Enter the name of the attendee as registered.
* **Registration ID (Registration ID)**: Enter the registration ID provided at registration.
* **Check in date (Check in date)**: Enter the date the attendee checked in to the conference.
* **Sessions attended (Sessions attended)**: If the attendee attended sessions, list them here (e.g., session ID 1, session ID 2, etc.).
* **Badge scanned confirmation (Badge scanned confirmation)**: Select 'True' if the attendee's badge was scanned, 'False' otherwise.
* **Attendee signature instructions (Attendee signature instructions)**: This is a placeholder for any notes about the attendee's signature.
* **Verifier name (Verifier name)**: Enter your name as the staff member verifying attendance.
* **Verifier comments (Verifier comments)**: Add any notes about the verification process.
* **Verification time (Verification time)**: Record the time the attendance was confirmed.
* **Confirmation status (Confirmation status)**: Select 'Confirmed' if the attendee's attendance was confirmed, 'Unconfirmed' otherwise.
