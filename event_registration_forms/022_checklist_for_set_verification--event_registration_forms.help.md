# Checklist For Set Verification - Help Guide
## Purpose
The purpose of this form is to ensure that all production and technical aspects of a stage set are verified and ready for an event.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the event title and production lead manager information on the "Event Title" and "Production Lead Manager" fields respectively.
2. Select the date and time of verification on the "Verification Date and Time" field.
3. Enter the set location or stage name in the "Set Location / Stage Name" field.
4. For each technical aspect of the stage set, select the corresponding status from the provided options (e.g. "Verified", "In Progress", "Pending", etc.).
5. Enter any additional findings or comments in the "Detailed Findings or Deficiencies" field, if necessary.
6. Select the overall set readiness status from the "Overall Set Readiness" options.
7. Sign off as the production supervisor in the "Production Supervisor Sign-off" field.

## Field-by-Field Explanation

* **Event Title**: Enter the title of the event that this set is being prepared for.
* **Production Lead Manager**: Enter the name of the production lead manager responsible for the event.
* **Verification Date and Time**: Select the date and time when the verification was performed.
* **Set Location / Stage Name**: Enter the name of the stage set being verified.
* **Stage Structural Integrity Confirmed**: Select the status of the stage structure's integrity (e.g. "Verified - Safe", "Minor Adjustment Needed", "Unsafe - Do Not Use").
* **Lighting Rigs and Trussing Secure**: Select the status of the lighting rigs and trussing (e.g. "Verified", "In Progress", "Pending").
* **Audio Systems and Monitor Mix Tested**: Select the status of the audio systems and monitor mix (e.g. "Verified", "Audio Issues Noted", "Not Tested").
* **Backup Power Systems Ready**: Select the status of the backup power systems (e.g. "True", "False").
* **All Hero Props Accounted For**: Select the status of the hero props (e.g. "Complete", "Items Missing", "Items Damaged").
* **Scenery Placement Matches Floor Plan**: Select the status of the scenery placement (e.g. "Matches", "Deviation Noted").
* **Detailed Findings or Deficiencies**: Enter any additional findings or comments about the stage set.
* **Overall Set Readiness**: Select the overall readiness status of the stage set (e.g. "GO - Ready for Show", "HOLD - Pending Fixes", "NO GO - Major Safety Risk").
* **Assigned Tech for Remediation**: Enter the name of the technician assigned to perform any necessary repairs or fixes.
* **Production Supervisor Sign-off**: Sign off as the production supervisor to confirm that the stage set is ready for the event.
