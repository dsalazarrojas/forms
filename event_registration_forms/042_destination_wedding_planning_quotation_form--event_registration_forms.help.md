# Destination Wedding Planning Quotation Form - Help Guide
## Purpose
This form is used to create a quotation for a destination wedding. It helps event planners gather information about the couple's event and provides a professional quote for their services.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the Couple Name field with the name of the couple getting married.
2. Enter the Event Date in the format of mm/dd/yyyy.
3. Select the Start Time and End Time of the event.
4. Enter the Event Time Zone, if applicable.
5. Enter the Wedding Date, if different from the Event Date.
6. Enter the Location of the event.
7. Enter the Number of Guests attending the event.
8. Enter the Contact Phone Number and Contact Email of the couple.
9. Select the Event Type from the options provided.
10. Enter the Venue of the event.
11. Enter a Description of the event.
12. Select the Services required for the event from the options provided.
13. Enter the Estimated Cost of the event.
14. Enter the Budget for the event.
15. Enter any additional Notes about the event.
16. Enter the Assigned Tool, if applicable.
17. Enter the Output File, if applicable.
18. Enter the Form ID, if applicable.
19. Enter the Form Category, if applicable.
20. Enter the Form Description, if applicable.
21. Enter the Form Assigned Tool, if applicable.
22. Enter the Form Assigned Date, if applicable.

## Field-by-Field Explanation
* **Couple Name** (`couple_name`, text, required/optional): Enter the name of the couple getting married.
* **Event Date** (`event_date`, date, required/optional): Enter the date of the event in the format of mm/dd/yyyy.
* **Start Time** (`start_time`, time, required/optional): Select the start time of the event.
* **End Time** (`end_time`, time, required/optional): Select the end time of the event.
* **Event Time Zone** (`event_time_zone`, text, required/optional): Enter the time zone of the event, if applicable.
* **Wedding Date** (`wedding_date`, date, required/optional): Enter the date of the wedding, if different from the Event Date.
* **Location** (`location`, text, required/optional): Enter the location of the event.
* **Number of Guests** (`number_of_guests`, number, required/optional): Enter the number of guests attending the event.
* **Contact Phone Number** (`contact_phone_number`, text, required/optional): Enter the contact phone number of the couple.
* **Contact Email** (`contact_email`, email, required/optional): Enter the contact email of the couple.
* **Event Type** (`event_type`, select_one, required/true): Select the type of event from the options provided.
* **Venue** (`venue`, text, required/optional): Enter the venue of the event.
* **Description** (`description`, text, required/optional): Enter a description of the event.
* **Services** (`services`, select_multiple, required/true): Select the services required for the event from the options provided.
* **Estimated Cost** (`estimated_cost`, number, required/optional): Enter the estimated cost of the event.
* **Budget** (`budget`, number, required/optional): Enter the budget for the event.
* **Notes** (`notes`, text, required/optional): Enter any additional notes about the event.
* **Assigned Tool** (`assigned_tool`, text, required/optional): Enter the assigned tool, if applicable.
* **Output File** (`output_file`, text, required/optional): Enter the output file, if applicable.
* **Form ID** (`form_id`, text, required/optional): Enter the form ID, if applicable.
* **Form Category** (`form_category`, text, required/optional): Enter the form category, if applicable.
* **Form Description** (`form_description`, text, required/optional): Enter the form description, if applicable.
* **Form Assigned Tool** (`form_assigned_tool`, text, required/optional): Enter the form assigned tool, if applicable.
* **Form Assigned Date** (`form_assigned_date`, date, required/optional): Enter the form assigned date, if applicable.
