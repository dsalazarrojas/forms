# cultural-showcase-afterparty-rsvp - Help Guide
## Purpose

This form is used to collect information from guests attending the cultural showcase's after-party event. It will help us ensure we have accurate headcount and dietary needs for catering and seating arrangements.

## How To Complete This Form

1. Click on the "Submit" button to start the form.
2. Fill out the form with the requested information for each guest.
3. Make sure to fill out all required fields (indicated by *asterisk).
4. Review your form before submitting to ensure all fields are complete and accurate.

## Field-by-Field Explanation

* **Guest Count** (`guest_quantity`, number, not required): Please enter the number of guests attending the after-party with you.
* **Guest Name** (`guest_name`, text, not required): Enter the name of the guest.
* **Guest Email** (`guest_email`, email, not required): Enter the email address of the guest (if applicable).
* **Guest Phone** (`guest_phone`, text, not required): Enter the phone number of the guest (if applicable).
* **Dietary Needs** (`dietary_need`, select_one, not required): Select any dietary needs for the guest from the options provided.
* **RSVP Response** (`rsvp_response`, select_multiple, not required): Indicate if the guest is attending the event by selecting "True", "False", or "Maybe".
* **RSVP Guest Count** (`rsvp_guest_count`, number, not required): Enter the number of guests this RSVP response applies to.
* **RSVP Attendance Time** (`rsvp_attendance_time`, time, not required): Enter the expected attendance time for the guest.
* **Comments** (`comments`, text, not required): Enter any additional comments or information about the guest.

## Tips

* Make sure to fill out all required fields accurately to ensure we can provide the best experience for our guests.
* If a guest has no dietary needs, please select "None" or do not select any option.
* If a guest is unsure about attending, please select "Maybe" for the RSVP Response.
* If you need to add or remove a guest, please fill out a new form for each guest.
