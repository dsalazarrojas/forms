# Powerlifting Event Registration Form - Help Guide
## Purpose
This form is designed to register participants for powerlifting events. It collects information about the event and the participant, including event name, athlete name, date, time, and location. This form is essential for event organizers to gather relevant details about events and participants, and for participants to provide their details in a structured and efficient manner.

## How To Complete This Form

To complete this form, follow these steps:

1.  Enter the event name in the "Event Name" field. This is the name of the event you are registering for.
2.  Enter your name as the athlete in the "Athlete Name" field.
3.  Select the date of the event from the calendar in the "Date" field.
4.  Choose the time of the event from the time picker in the "Time" field.
5.  Enter the location of the event in the "Location" field.

## Field-by-Field Explanation

*   **Event Name** (`event_name`, text, optional): Enter the name of the event you are registering for.
*   **Athlete Name** (`athlete_name`, text, optional): Enter your name as the athlete participating in the event.
*   **Date** (`date`, date, optional): Select the date of the event from the calendar.
*   **Time** (`time`, time, optional): Choose the time of the event from the time picker.
*   **Location** (`location`, text, optional): Enter the location of the event where it will take place.
