# Heart Health Walk Sponsorship Form - Help Guide
## Purpose
This form is used for registration of sponsors for the "Heart Health Walk" event.

## How To Complete This Form

### To complete this form, please follow these steps:

1. **Fill in the participant name**: This field is required and should be filled in with the full name of the participant.
2. **Enter the event name**: This field is optional, but entering the event name can help the organizers track which events the sponsor is supporting.
3. **Enter sponsor information**: This section is used to capture the contact information of the sponsor, including name, type, email, phone number, and website.
4. **Enter payment details**: This section is used to track the payment status and method of the sponsor.
5. **Enter sponsorship status**: This field indicates the status of the sponsor's registration, which can be Unverified, Verified, or Rejected.

## Field-by-Field Explanation

### 1. **participant_name** (required)
* Label: participant_name
* Type: text
* Purpose: This field is used to capture the name of the participant registering for the event.

### 2. **event_name** (optional)
* Label: event_name
* Type: text
* Purpose: This field is used to specify the event the participant is registering for.

### 3. **sponsor_name** (optional)
* Label: sponsor_name
* Type: text
* Purpose: This field is used to capture the name of the sponsor.

### 4. **sponsor_type** (optional)
* Label: sponsor_type
* Type: select_one
* Purpose: This field is used to specify the type of sponsor (Corporate Sponsor, Individual Sponsor, or Group Sponsor).

### 5. **sponsor_email** (optional)
* Label: sponsor_email
* Type: email
* Purpose: This field is used to capture the email address of the sponsor.

### 6. **sponsor_phone** (optional)
* Label: sponsor_phone
* Type: text
* Purpose: This field is used to capture the phone number of the sponsor.

### 7. **contribution_amount** (optional)
* Label: contribution_amount
* Type: number
* Purpose: This field is used to track the amount of the sponsor's contribution.

### 8. **payment_method** (optional)
* Label: payment_method
* Type: select_one
* Purpose: This field is used to specify the method of payment (Check/Cash or Online Payment).

### 9. **sponsor_address** (optional)
* Label: sponsor_address
* Type: text
* Purpose: This field is used to capture the address of the sponsor.

### 10. **sponsor_city** (optional)
* Label: sponsor_city
* Type: text
* Purpose: This field is used to capture the city of the sponsor.

### 11. **sponsor_state** (optional)
* Label: sponsor_state
* Type: text
* Purpose: This field is used to capture the state of the sponsor.

### 12. **sponsor_zip** (optional)
* Label: sponsor_zip
* Type: text
* Purpose: This field is used to capture the zip code of the sponsor.

### 13. **sponsor_notes** (optional)
* Label: sponsor_notes
* Type: note
* Purpose: This field is used to capture any additional notes from the sponsor.

### 14. **sponsor_website** (optional)
* Label: sponsor_website
* Type: text
* Purpose: This field is used to capture the website of the sponsor.

### 15. **payment_status** (optional)

### 19. **sponsorship_status** (optional)
