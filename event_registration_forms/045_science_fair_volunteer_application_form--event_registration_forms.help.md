# Science Fair Volunteer Application Form - Help Guide
## Purpose
This form is used to collect information from individuals who wish to volunteer at the science fair. It's a required field for anyone wanting to participate.

## How To Complete This Form

To complete this form, follow the steps below:

1. **Page 1 - Volunteer Information**

	* Fill out the following fields for the volunteer:
		+ **First Name**: Enter the first name of the volunteer.
		+ **Last Name**: Enter the last name of the volunteer. (Note: This field is not required but is useful for identification purposes.)
		+ **Email**: Enter the email of the volunteer.
		+ **Phone Number**: Enter the phone number of the volunteer.
		+ **Role**: Select the role the volunteer wants to take on.
		+ **Event Date**: Select the date of the science fair event.
		+ **Event Time**: Select the time of the science fair event.
		+ **Availability**: Select when the volunteer is available to work during the science fair.
		+ **Additional Information**: Provide any additional information the volunteer would like to share.

	* Ensure that you fill out all the required fields for the volunteer.

2. **Page 2 - Submitter Information**

	* Fill out the following fields for the submitter:
		+ **Submitter Name**: Enter your name as the person submitting the application.
		+ **Submitter Email**: Enter your email as the person submitting the application.
		+ **Submitter Phone Number**: Enter your phone number as the person submitting the application.
		+ **Submitter Role**: Select your role as the person submitting the application.
		+ **Event Description**: Provide a brief description of the event.
		+ **Message to Organizers**: Provide any additional information you would like to share with the organizers.
		+ **Science Fair Location**: Enter the location of the science fair.
		+ **Science Fair Date**: Select the date of the science fair.
		+ **Science Fair Time**: Select the time of the science fair.
		+ **Science Fair Duration**: Select how long the science fair will last.
		+ **Role Description**: Provide a brief description of the role the volunteer is taking on.
		+ **Submitter Agreement**: Confirm that you are willing to participate in the science fair as a volunteer.

## Field-by-Field Explanation

* **First Name**: Enter the first name of the volunteer.
* **Last Name**: Enter the last name of the volunteer. (Note: This field is not required but is useful for identification purposes.)
* **Email**: Enter the email of the volunteer. (Note: This field is required for communication purposes.)
* **Phone Number**: Enter the phone number of the volunteer. (Note: This field is not required but is useful for emergency contact purposes.)
* **Role**: Select the role the volunteer wants to take on. (Note: Select from Volunteer, Judge, or Organizer.)
* **Event Date**: Select the date of the science fair event. (Note: This field is required and should match the date of the science fair.)
* **Event Time**: Select the time of the science fair event. (Note: This field is required and should match the time of the science fair.)
* **Availability**: Select when the volunteer is available to work during the science fair. (Note: Select from Morning, Afternoon, or All Day.)
* **Additional Information**: Provide any additional information the volunteer would like to share. (Note: This field is not required but is useful for the organizers to know.)
* **Submitter Name**: Enter your name as the person submitting the application. (Note: This field is required and should match the name of the person submitting the application.)
* **Submitter Email**: Enter your email as the person submitting the application. (Note: This field is required and should match the email of the person submitting the application.)
* **Submitter Phone Number**: Enter your phone number as the person submitting the application. (Note: This field is not required but is useful for emergency contact purposes.)
* **Submitter Role**: Select your role as the person submitting the application. (Note: Select from Volunteer, Judge, or Organizer.)
* **Event Description**: Provide a brief description of the event. (Note: This field is required and should be a brief description of the science fair.)
* **Message to Organizers**: Provide any additional information you would like to share with the organizers. (Note: This field is not required but is useful for the organizers to know.)
* **Science Fair Location**: Enter the location of the science fair. (Note: This field is required and should match the location of the science fair.)
* **Science Fair Date**: Select the date of the science fair. (Note: This field is required and should match the date of the science fair.)
* **Science Fair Time**: Select the time of the science fair. (Note: This field is required and should match the time of the science fair.)
* **Science Fair Duration**: Select how long the science fair will last. (Note: Select from Morning, Afternoon, or All Day.)
* **Role Description**: Provide a brief description of the role the volunteer is taking on. (Note: This field is not required but is useful for the organizers to know.)
* **Submitter Agreement**: Confirm that you are willing to participate in the science fair as a volunteer. (Note: This field is required and should be checked as 'I agree to participate in the science fair as a volunteer'.)
* **Submission Date**: Enter the date and time the application was submitted. (Note: This field is required and will be auto-populated.)
* **Submission Time**: Enter the time the application was submitted. (Note: This field is required and will be auto-populated.)
* **Submitted By**: Enter your name as the person submitting the application. (Note: This field is required and should match the name of the person submitting the application.)

## Tips

* Ensure that you fill out all the required fields for both the volunteer and the submitter.
* Double-check that you fill out the correct fields for each page.
* If you are unsure about any field, please contact the organizers for clarification.
* The form will not be used for any other purpose than for organizing volunteers for the science fair.
