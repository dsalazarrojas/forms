# sports_event_officials_report - Help Guide
## Purpose
The purpose of this form is to gather information about sports events, allowing users to report details about the events they have attended or participated in.

## How To Complete This Form
To complete this form, follow these steps:

*   Fill out your User Name for reference purposes only. This information will not be shared or used for any other purpose.
*   Select the Event Type to indicate the type of event you are reporting (yes/no).
*   Provide the Event Name as the name of the event being reported.
*   Enter the Date of Event, in the format MM/DD/YY.
*   Enter the Time of Event, in the format 12:00 AM or 12:00 PM.
*   Specify the Event Location where the event took place.
*   Provide the Official Name of the official(s) involved or present at the event.
*   Indicate the Official Role of the official(s) by selecting yes/no from the options provided.
*   Enter the Event Details, providing any additional information relevant to the event.
*   Share any Observations you may have about the event.

## Field-by-Field Explanation
*   **User Name (text)**: A field for you to enter your name for reference.
*   **Event Type (select one)**: Choose yes or no to specify if the event is of the type being reported.
*   **Event Name (text)**: Enter the name of the event being reported.
*   **Date of Event (date)**: Enter the date of the event, in MM/DD/YY format.
*   **Time of Event (time)**: Enter the time of the event, in 12-hour format 12:00 AM or 12:00 PM.
*   **Event Location (text)**: Enter the location of the event.
*   **Official Name (text)**: Enter the name of the official(s) involved or present at the event.
*   **Official Role (select one)**: Indicate if the official(s) had a role in the event by selecting yes or no from the options provided.
*   **Event Details (text)**: Enter any additional information about the event you feel is relevant.
*   **Observations (text)**: Share any observations or comments you have about the event.
