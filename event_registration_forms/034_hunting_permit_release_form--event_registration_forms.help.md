# Hunting Permit Release Form - Help Guide
## Purpose
The Hunting Permit Release Form is used to release hunting permits for registered participants. This form is used to capture the participant's details, confirm the release date of their permit, and obtain their consent for the permit release.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the participant's registration information on page 1.
2. Enter the participant's phone number.
3. Enter the release date of the permit.
4. Confirm the participant's consent.
5. Add any additional notes if necessary.
6. Enter event details if required.

## Field-by-Field Explanation
### Registration Information (Page 1)
* **Registration Information (event_registration_forms)**: This section is used to capture the participant's registration information. Please fill in the required details.

### Participant Details
* **Participant Details (participant_details)**: This section is used to capture the participant's name and other relevant details. Please enter the participant's name and other required details.

### Participant Phone
* **Participant Phone (participant_phone)**: This is the participant's phone number. Please enter the participant's phone number to ensure we can contact them for any updates or issues with their permit.

### Hunting Permit Details
* **Hunting Permit Details (hunting_permit_details)**: This section is not required to be filled. Please do not enter any information here if it is not applicable.

### Release Date
* **Release Date (release_date)**: This is the date when the permit is released. Please select the date when the permit is about to be released.

### Consent
* **Consent (consent)**: This section is used to confirm the participant's consent for the permit release. Please tick the box to confirm their consent.

### Notes
* **Notes (notes)**: This section is optional and used to capture any additional notes or comments. Please enter any relevant information here if required.

### Event Details
* **Event Details (event_details)**: This section is optional and used to capture any event details. Please enter the event details if required.

## Tips
* Please ensure that you have filled in all required fields before submitting the form.
* Please ensure that you have obtained the participant's consent before releasing their permit.
* Please keep the participant informed of the permit release date.
* Please keep a record of the permit release dates and participant details for future reference.
