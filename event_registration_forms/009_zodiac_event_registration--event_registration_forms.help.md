# zodiac_event_registration_form - Help Guide
## Purpose
The zodiac_event_registration_form is used to register participants for events related to zodiac signs.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out each field with the required information.
2. For text fields, enter the relevant text in the specified format.
3. For date fields, use the standard date format (MM/DD/YYYY).
4. For select fields, choose from the provided options.
5. For participant type fields, select all applicable participant types.
6. Review your entries for accuracy before submitting.

## Field-by-Field Explanation

* **First Name** (id: 1, text, required): Enter the first name of the participant.
* **Last Name** (id: 2, text, required): Enter the last name of the participant.
* **Date of Birth** (id: 3, date, required): Enter the participant's date of birth in the standard date format (MM/DD/YYYY).
* **Email** (id: 4, email, required): Enter the participant's email address.
* **Phone** (id: 5, text, required): Enter the participant's phone number.
* **Participant Type** (id: 6, select_multiple, required): Select all applicable participant types.
* **Participant A Details** (id: 7, note, required): Provide details for participant A, if applicable.
* **Participant B Details** (id: 8, note, required): Provide details for participant B, if applicable.
* **Event Details** (id: 9, note, required): Enter event-specific details.
* **Zodiac Sign** (id: 10, select_one, required): Select the participant's zodiac sign from the options provided.
* **Registration Date** (id: 11, date, required): Enter the registration date in the standard date format (MM/DD/YYYY).
* **Registration Time** (id: 12, time, required): Enter the registration time in 24-hour format (HH:MM).
* **Participant Count** (id: 13, number, required): Enter the number of participants attending the event.
* **Participant Count Hint** (id: 14, text, required): Enter a hint or note about the participant count.
* **Comments** (id: 15, text, required): Enter any comments or additional notes.
* **Event ID** (id: 16, text, required): Enter the event ID or code.

**Tips:**

* Double-check the participant's date of birth for accuracy.
* Make sure to select all applicable participant types.
* Provide clear and concise event details.
* Enter accurate and up-to-date registration date and time.
