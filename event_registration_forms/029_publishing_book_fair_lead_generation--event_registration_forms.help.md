# Publishing Book Fair Lead Generation - Help Guide
## Purpose
The Publishing Book Fair Lead Generation form is used to collect information for publishing book fairs, specifically for lead generation.

## How To Complete This Form

1. Fill out the form with the required fields.
2. Ensure that the "Event Name", "Event Date", "Event Time", "Event Address", "Email", and "Phone" fields are completed accurately.
3. Select the appropriate "Event Type" from the list.
4. Select as many relevant categories for the "Event Category" as needed.
5. If applicable, add any "Event Details" in the "Event Details" field.
6. Confirm if the event has "Qualifications" for attendees and select accordingly.
7. If necessary, provide additional "Follow-up Details" in the "Follow-up Details" field.

## Field-by-Field Explanation

* **Event Name (1)** (`event_name`, Required): Enter the name of the publishing book fair event.
* **Event Date (2)** (`event_date`, Required): Enter the date of the publishing book fair event.
* **Event Time (3)** (`event_time`, Required): Enter the time of the publishing book fair event.
* **Event Address (4)** (`event_address`, Required): Enter the address of the publishing book fair event.
* **Email (5)** (`email`, Required): Enter the email address of the event contact or responsible person.
* **Phone (6)** (`phone`, Required): Enter the phone number of the event contact or responsible person.
* **Event Type (7)** (`event_type`, Required): Select the type of event from the list:
	+ Option 1
	+ Option 2
	+ Option 3
* **Event Category (8)** (`event_category`, Required): Select as many categories that apply to the event:
	+ Category 1
	+ Category 2
	+ Category 3
* **Event Details (9)** (`event_details`, Optional): Add any additional information about the event in this field.
* **Qualification (10)** (`qualification`, Required): Confirm if the event has qualifications for attendees, and select accordingly:
	+ Qualified
	+ Not Qualified
* **Follow-up Details (11)** (`follow_up_details`, Optional): Provide any additional details that require follow-up action.
