# Event Insurance Request Form - Help Guide

## Purpose

This form is used to request insurance for events. Please fill out the required fields to provide your event insurance request.

## How To Complete This Form

1. Please fill out the Event Insurance Request Form completely and accurately.
2. Make sure to provide all required fields marked with an asterisk (\*) or denoted as required in the field label.
3. Use the correct format for date and time fields (e.g., YYYY-MM-DD and HH:MM AM/PM).
4. Use a valid contact email address in the contact-email field.
5. If you need to request multiple types of coverage, select all applicable options in the coverage-type field.

## Field-by-Field Explanation

* **Event Insurance Request Form** (*required*): This is the main heading for the form. Please do not fill out this field.
* **Event Name** (*required*): Enter the name of the event you are requesting insurance for.
* **Event Date** (*required*): Enter the date of the event (YYYY-MM-DD).
* **Event Time** (*required*): Enter the time of the event (HH:MM AM/PM).
* **Event Location** (*optional*): Enter the location of the event.
* **Event Description** (*optional*): Provide a brief description of the event.
* **Insurance Request Amount** (*required*): Enter the amount of insurance you are requesting.
* **Risk Assessment** (*required*): Provide a brief description of the risk assessment.
* **Liability Insurance** (*required*): Select 'Yes' if you are requesting liability insurance, otherwise select 'No'.
* **Coverage Type** (*required*): Select all applicable types of coverage you are requesting.
* **Insurance Coverage Start Date** (*required*): Enter the start date of the insurance coverage (YYYY-MM-DD).
* **Insurance Coverage End Date** (*required*): Enter the end date of the insurance coverage (YYYY-MM-DD).
* **Contact Name** (*required*): Enter the name of the contact person.
* **Contact Email** (*required*): Enter the email address of the contact person.
* **Contact Phone** (*required*): Enter the phone number of the contact person.
* **Contact Phone Extension** (*optional*): Enter the contact phone extension (if applicable).
* **Contact Street** (*optional*): Enter the contact street address.
* **Contact City** (*optional*): Enter the contact city.
* **Contact State** (*optional*): Enter the contact state.
* **Contact Zip** (*optional*): Enter the contact zip code.
* **Contact Country** (*optional*): Enter the contact country.
* **Contact Company** (*optional*): Enter the contact company name.
* **Contact Position** (*optional*): Enter the contact position.
* **Risk Description** (*optional*): Provide a brief description of the risk.
* **Event Type** (*optional*): Enter the type of event.
