# Public Space Usage Application Form - Help Guide

## Purpose
This form is used to collect information for public space usage applications.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the type of event from the options provided.
2. Enter the start and end dates for the event.
3. Enter the start and end times for the event.
4. Provide the name of the event.
5. Add a brief description of the event.
6. Enter the name of the contact person.
7. Enter the contact email.
8. Enter the contact phone number.
9. Enter the name of the organization.

## Field-by-Field Explanation

* **What type of event** (`event_type`, Select One, required: false):
    The "What type of event" field allows you to select the type of event you are applying for. Please choose from the options provided, which include "Conference", "Workshop", "Meeting", or "Other".
* **Start date** (`start_date`, Date, required: false):
    Enter the start date of the event. This is the date when the event will begin.
* **End date** (`end_date`, Date, required: false):
    Enter the end date of the event. This is the date when the event will conclude.
* **Start time** (`start_time`, Time, required: false):
    Enter the start time of the event. This is the time when the event will begin.
* **End time** (`end_time`, Time, required: false):
    Enter the end time of the event. This is the time when the event will conclude.
* **Event name** (`event_name`, Text, required: false):
    Enter a brief name for the event. This will be used to identify the event.
* **Event description** (`event_description`, Note, required: false):
    Provide a brief description of the event. This can be a short paragraph describing what the event is about.
* **Contact person** (`contact_person`, Text, required: false):
    Enter the name of the person responsible for the event.
* **Contact email** (`contact_email`, Email, required: false):
    Enter the email address of the contact person.
* **Contact phone** (`contact_phone`, Text, required: false):
    Enter the phone number of the contact person.
* **Organization** (`organization`, Text, required: false):
    Enter the name of the organization hosting or sponsoring the event.
