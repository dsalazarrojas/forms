# corporate_event_checklist_form - Help Guide
## Purpose
This form is designed to collect information about a corporate event.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the title of the event in the "Event Title" field.
2. Select the date of the event in the "Event Date" field.
3. Enter the location of the event in the "Event Location" field.
4. Choose the event planner from the dropdown menu in the "Event Planner" field.
5. Select all relevant tasks associated with the event in the "Event Tasks" field.

## Field-by-Field Explanation
### Event Title
* **Event Title** (`event_title`, text, optional): Enter the name or title of the event.

### Event Date
* **Event Date** (`event_date`, date, optional): Select the date of the event.

### Event Location
* **Event Location** (`event_location`, text, optional): Enter the location of the event.

### Event Planner
* **Event Planner** (`event_planner`, select_one, required): Choose the person or team responsible for planning the event.

### Event Tasks
* **Event Tasks** (`event_tasks`, select_multiple, required): Select all relevant tasks associated with the event.

## Tips
* Make sure to select the correct event date and location to ensure that the event is properly documented and communicated to attendees.
* Choose the correct event planner to ensure that the correct person is responsible for the event's organization and coordination.
* Select all relevant tasks to help the event planner plan and prepare for the event's success.
