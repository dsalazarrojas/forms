# Family Event Registration Form - Help Guide
## Purpose
This form is designed for users to register event details, including ticket information, contact information, and event logistics.

## How To Complete This Form

1.  Please select all the necessary fields as per your event details.
2.  Ensure you fill in all the required fields (if any) accurately.
3.  Review the form before submitting.

## Field-by-Field Explanation

*   **Event Tickets**: Please select the ticket information for the event. This will help us understand your event requirements.
    *   **Event Details**: Provide the event description and other relevant event details.
    *   **Contact Information**: Enter the contact person's name, phone number, email address, and other contact details if required.
    *   **Event Date**: Choose the date and time for the event.
    *   **Event Address**: Provide the event address.
    *   **Contact Address**: Enter the contact person's address if required.
    *   **Payment Method**: Select the payment method (if any) and specify the payment amount if necessary.
    *   **Payment Terms**: Provide any payment terms and conditions if required.
    *   **Event Notes**: Enter any additional notes about the event.
    *   **Family Members**: Confirm if the event is for family members.
    *   **Family Size**: Enter the family size.
    *   **Event Description**: Provide a detailed description of the event.
    *   **Event Location**: Enter the event location.
    *   **Contact Phone**: Enter the contact person's phone number.
    *   **Contact Phone Extension**: Enter the contact person's phone extension if required.
    *   **Alternate Contact Phone**: Enter the alternate contact person's phone number if required.
    *   **Contact Email**: Enter the contact person's email address.
    *   **Contact Fax**: Enter the contact person's fax number if required.

Note: Please ensure you fill in all the required fields accurately for successful event registration.
