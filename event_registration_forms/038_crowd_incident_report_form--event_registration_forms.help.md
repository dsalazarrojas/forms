# Crowd Incident Report Form - Help Guide

## Purpose
The purpose of this form is to collect information about incidents that have occurred at a crowded event or venue. 

## How To Complete This Form
To complete this form, follow these steps:
1. Enter the event date when the incident occurred.
2. Provide the name of the event.
3. Enter the location where the incident took place.
4. Provide a detailed description of what happened.
5. Enter the density of the crowd that was present.
6. Select the composition of the crowd.
7. Enter the size of the crowd that was present.
8. Enter the time when the incident occurred.
9. List any safety concerns that may have contributed to the incident.
10. Select the outcome of the incident.
11. Indicate if an officer was assigned to deal with the incident.
12. Upload any images that support the incident report.
13. Enter your name as the person submitting the report.
14. (Optional) Enter the date of the incident.
15. (Optional) Enter the time the report was submitted.
16. Select the person or organization to whom the report was submitted.
17. Enter a unique number for the incident report.
18. Select the status of the incident report.
19. Enter a unique ID for the incident report.
20. If necessary, enter the tool used to capture the incident image.
21. Enter the URL of the incident image.
22. Enter the type of incident image.
23. Enter a description of the incident image.
24. Enter the date the incident image was captured.
25. Enter the person who reported the incident.

## Field-by-Field Explanation
* **Event Date** (`event_date`, date, **required**): Enter the date when the event took place.
* **Event Name** (`event_name`, text, optional): Enter the name of the event.
* **Event Location** (`event_location`, text, optional): Enter the location where the incident occurred.
* **Incident Description** (`incident_description`, text, optional): Provide a detailed description of what happened.
* **Crowd Density** (`crowd_density`, number, optional): Enter the density of the crowd that was present.
* **Crowd Composition** (`crowd_composition`, select_one, optional): Select the composition of the crowd.
* **Crowd Size** (`crowd_size`, number, optional): Enter the size of the crowd that was present.
* **Time Incident Occurred** (`time_incident_occurred`, time, optional): Enter the time when the incident occurred.
* **Safety Concerns** (`safety_concerns`, text, optional): List any safety concerns that may have contributed to the incident.
* **Incident Outcome** (`incident_outcome`, select_one, optional): Select the outcome of the incident.
* **Assigned Officer** (`assigned_officer`, select_multiple, optional): Indicate if an officer was assigned to deal with the incident.
* **Incident Image** (`incident_image`, note, optional): Upload any images that support the incident report.
* **Submitted By** (`submitted_by`, text, optional): Enter your name as the person submitting the report.
* **Incident Date** (`incident_date`, date, optional): Enter the date the incident occurred (if not already selected in Event Date).
* **Time Report Submitted** (`time_report_submitted`, time, optional): Enter the time the report was submitted (if not already selected in Event Date).
* **Report Submitted To** (`report_submitted_to`, select_one, optional): Select the person or organization to whom the report was submitted.
* **Incident Report Number** (`incident_report_number`, number, optional): Enter a unique number for the incident report.
* **Incident Report Status** (`incident_report_status`, select_one, optional): Select the status of the incident report.
* **Incident Report ID** (`incident_report_id`, number, optional): Enter a unique ID for the incident report.
* **Assigned Tool** (`assigned_tool`, text, optional): If necessary, enter the tool used to capture the incident image.
* **Incident Image URL** (`incident_image_url`, text, optional): Enter the URL of the incident image.
* **Incident Image Type** (`incident_image_type`, select_one, optional): Select the type of incident image.
* **Incident Image Description** (`incident_image_description`, text, optional): Enter a description of the incident image.
* **Incident Image Capture Date** (`incident_image_capture_date`, date, optional): Enter the date the incident image was captured.
* **Incident Reported By** (`incident_reported_by`, text, optional): Enter the person who reported the incident.

## Tips
* Please ensure that you have not already submitted a report for this incident.
* Please provide as much detail as possible in each field.
* If you have any images or supporting evidence, upload them with your report.
* If you are unsure about any of the fields, please contact the relevant authorities for clarification.
