# Volunteer Program Attendance Form - Help Guide
## Purpose
The Volunteer Program Attendance Form is a tool for event organizers to track the attendance of volunteers in their programs. This form helps to ensure that all volunteers are accounted for and that any issues can be addressed promptly.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter your notes about the volunteer's attendance (this is optional).
2. Select the confirmation status of the volunteer.

## Field-by-Field Explanation
* **Volunteer Program Attendance Form**: Enter the name of the volunteer program or event that this form is for. This is the main title of the form and will help identify the purpose of the form.
* **Notes**: Enter any additional comments or information about the volunteer's attendance. This field is optional and can be used to provide context or details about the volunteer's experience.
* **Confirmation**: Select whether the volunteer has arrived or not. This field is required and will help the event organizer confirm the volunteer's presence. The options are:
	+ **Confirmed**: The volunteer has arrived and is present.
	+ **Not Confirmed**: The volunteer has not arrived or is not present.

## Tips
* Make sure to fill in all required fields to ensure accurate tracking of volunteer attendance.
* Enter clear and concise notes about the volunteer's attendance to help event organizers understand any issues or concerns.
* Select the confirmation status carefully to ensure that the volunteer is accurately accounted for.
