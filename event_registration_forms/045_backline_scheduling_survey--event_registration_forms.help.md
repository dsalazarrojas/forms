# Backline Scheduling Survey - Help Guide

## Purpose
This form is used to collect information from artists and their representatives to schedule backline equipment and services for performances. Please complete this form to provide accurate and timely information to our production team.

## How To Complete This Form
To complete this form, please select the relevant fields and provide all required information. Some fields have specific instructions or formats. For example:
* When entering a time, use the format `HH:MM` (e.g., `14:00` for 2 PM).
* When specifying the number of crew members, include only whole numbers.
* For select fields, choose from the available options.

## Field-by-Field Explanation

* **Artist or Band Name** (`artist_name`): Enter the name of the performing act.
* **Contact Person Name** (`contact_name`): Enter the name of the tour manager or contact person.
* **Contact Email** (`contact_email`): Enter the email address of the contact person, in the format `email@example.com`.
* **Contact Phone** (`contact_phone`): Enter the phone number of the contact person.
* **Event Name** (`event_name`): Enter the name of the event or tour.
* **Event Date** (`event_date`): Enter the date of the performance, in the format `MM/DD/YYYY`.
* **Venue Name** (`venue_name`): Enter the name of the performance venue.
* **Stage Assignment** (`stage_assignment`): Select the stage where the performance will take place from the available options (e.g., Main Stage, Second Stage, etc.).
* **Scheduled Performance Time** (`performance_time`): Enter the time of the performance, in the format `HH:MM` (e.g., `14:00` for 2 PM).
* **Set Duration** (`set_duration`): Select the expected duration of the performance from the available options (e.g., 30 minutes, 45 minutes, etc.).
* **Preferred Soundcheck Time** (`soundcheck_time`): Enter the preferred time for soundcheck, in the format `HH:MM` (e.g., `10:00` for 10 AM).
* **Backline Equipment Needed** (`backline_requirements`): Select the equipment required for the performance from the available options (e.g., Drum kit, Bass amplifier, etc.).
* **Drum Kit Preference** (`drum_kit_preference`): If you have specific preferences for the drum kit, enter them here.
* **Amplifier Preferences** (`amplifier_preferences`): If you have specific preferences for amplifiers, enter them here.
* **Keyboard Requirements** (`keyboard_requirements`): If you have specific requirements for keyboards, enter them here.
* **Monitor Needs** (`monitor_needs`): Enter the number of monitors required.
* **Microphone Count** (`microphone_count`): Enter the number of microphones required.
* **Special Requests** (`special_requests`): If you have any unique equipment needs, enter them here.
* **Stage Plot Provided** (`stage_plot_provided`): Select whether you will provide a stage plot or not.
* **Input List Provided** (`input_list_provided`): Select whether you will provide an input list or not.
* **Number of Crew Members** (`crew_count`): Enter the number of crew members attending the performance.
* **Preferred Load-In Time** (`load_in_time`): Enter the preferred load-in time, in the format `HH:MM` (e.g., `08:00` for 8 AM).
* **Parking Needs** (`parking_needs`): Enter the number of parking passes required.
* **Hospitality Requests** (`hospitality_requests`): If you have any food or beverage requests, enter them here.
* **Additional Notes** (`additional_notes`): Enter any other information for the production team.
