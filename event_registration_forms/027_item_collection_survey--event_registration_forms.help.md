# Item Collection Survey - Help Guide

## Purpose
The Item Collection Survey is a form used to gather information about items that are being collected in the event registration process. This form is used to capture details about the item, its condition, and the contact information of the person responsible for its collection.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the relevant fields to collect information about the item.
2. Fill in the required fields with accurate information about the item.
3. Review and submit the form for final confirmation.

## Field-by-Field Explanation

* **Customer Survey Form** (`customer_survey_form`, text, required: false): This field is not applicable as it seems to be a placeholder. Please disregard this field.
* **Item Information** (`item_info`, text, required: false): Enter a brief description of the item being collected.
* **Item Condition** (`item_condition`, text, required: false): Describe the condition of the item, e.g., new, used, refurbished, etc.
* **Item Type** (`item_type`, select multiple, required: false):
	+ Select all categories that apply to the item being collected.
* **Item Value** (`item_value`, number, required: false): Enter the value of the item, if applicable.
* **Purchase Date** (`purchase_date`, date, required: false): Enter the date the item was purchased or collected.
* **Purchase Time** (`purchase_time`, time, required: false): Enter the time the item was purchased or collected.
* **Contact Name** (`contact_name`, text, required: false): Enter the name of the person responsible for the item's collection.
* **Contact Email** (`contact_email`, email, required: false): Enter the email address of the person responsible for the item's collection.
* **Contact Phone** (`contact_phone`, text, required: false): Enter the phone number of the person responsible for the item's collection.
* **Item Location** (`item_location`, text, required: false): Describe the location where the item was collected or is currently located.
* **Item Status** (`item_status`, select one, required: false):
	+ Select the status of the item being collected, either Active or Inactive.
