# Virtual Trade Show Registration Form - Help Guide

## Purpose
The purpose of this form is to collect essential information from users registering for the Virtual Trade Show. This information will be used for various purposes, including event organization and networking.

## How To Complete This Form
1. Fill out the form fields below to provide us with your details and preferences for the Virtual Trade Show.
2. Review each field carefully to ensure you provide accurate and complete information.
3. Submit the form once you have filled out all the required fields.

## Field-by-Field Explanation
### 1. **Event Registration Form** (event_registration_form)
* This is the first section of the form, where you can enter your response to the event.
* Type: text
* Required: false

### 2. **Event Details** (event_details)
* This section is where you can provide more information about the event you are attending.
* Type: text
* Required: false

### 3. **Name** (name)
* Please enter your name as you would like it to be displayed during the event.
* Type: text
* Required: false

### 4. **Email** (email)
* Enter your email address so we can contact you with event updates and information.
* Type: email
* Required: false

### 5. **Phone** (phone)
* If you would like to be contacted by phone, please provide your phone number.
* Type: text
* Required: false

### 6. **Company** (company)
* Enter the name of your company.
* Type: text
* Required: false

### 7. **Position** (position)
* Please select your position within the company.
* Type: select_one
* Required: false

### 8. **Company (Select One)** (company)
* This field is a dropdown menu of company options.
* Type: select_one
* Required: false

### 9. **Event Type** (event_type)
* Please select the type of event you are attending.
* Type: select_multiple
* Required: false

### 10. **Date** (date)
* Enter the date you plan to attend the event.
* Type: date
* Required: false

### 11. **Time** (time)
* Please select the time you plan to attend.
* Type: time
* Required: false

### 12. **Address** (address)
* Enter the address of your location.
* Type: text
* Required: false

### 13. **City** (city)
* Enter the city of your location.
* Type: text
* Required: false

### 14. **State** (state)
* Enter the state of your location.
* Type: text
* Required: false

### 15. **Zip** (zip)
* Enter the zip code of your location.
* Type: text
* Required: false

## Tips
* Please make sure to fill out all required fields accurately and completely.
* If you have any questions or concerns, feel free to contact us.
* We appreciate your participation in the Virtual Trade Show.
