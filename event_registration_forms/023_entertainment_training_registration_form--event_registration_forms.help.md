# entertainment_training_registration_form - Help Guide
## Purpose
The entertainment_training_registration_form is designed to collect information from participants in an entertainment training event. It gathers details such as participant contact information, payment method, and workshop specifics to ensure a smooth and successful event.

## How To Complete This Form

1. Fill in all required fields as accurately as possible.
2. Review the form carefully before submission.
3. If you are unsure about any field, consult the event organizer for clarification.

## Field-by-Field Explanation

* **participant information (page 1)**: This section includes general participant details.
	+ **participant name**: Enter the name of the participant as it appears on their ID or personal documents.
* **email (page 1)**: Enter the participant's email address for communication purposes.
* **participant type (page 1)**: Select the participant type from the options provided (student, instructor, staff).
* **workshop name (page 1)**: Enter the name of the workshop the participant is attending.
* **training start date (page 1)**: Enter the start date of the workshop.
* **training end date (page 1)**: Enter the end date of the workshop.
* **training days (page 1)**: Enter the number of days the workshop will last.
* **participant status (page 1)**: Select the participant's status from the options provided (confirmed, pending, cancelled).
* **participant status note (page 1)**: Enter any additional notes about the participant's status.
* **additional info (page 1)**: Enter any additional information about the participant that is relevant to the event.
* **payment method (page 2)**: Select the payment method used by the participant (online payment, offline payment, payment pending).
* **payment status (page 2)**: Select the payment status from the options provided (paid, unpaid, payment pending).
* **payment method note (page 2)**: Enter any additional notes about the payment method.
* **participant email (page 2)**: Enter the participant's email address (if different from page 1).
* **participant phone (page 2)**: Enter the participant's phone number.
* **participant address (page 2)**: Enter the participant's address.
* **workshop location (page 2)**: Enter the location of the workshop.
* **instructor name (page 2)**: Enter the name of the instructor.
* **instructor email (page 2)**: Enter the email address of the instructor.
* **instructor phone (page 2)**: Enter the phone number of the instructor.
* **instructor address (page 2)**: Enter the address of the instructor.
* **course description (page 2)**: Enter a brief description of the course or workshop.
* **course materials (page 2)**: Enter any materials or equipment needed for the workshop.
* **workshop schedule (page 2)**: Enter the schedule of the workshop.
