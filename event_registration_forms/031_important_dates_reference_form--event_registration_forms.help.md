# Important Dates Reference Form - Help Guide

## Purpose
The purpose of this form is to gather and store information about upcoming and past events, including their dates, locations, and other notable details.

## How To Complete This Form
To complete this form, follow the steps below:

1. Ensure you have all necessary information about the event, including dates, start and end times, location, and any other relevant details.
2. Scroll through the form pages to select the relevant fields to fill in.
3. Fill in each field according to the label and any provided hints.

## Field-by-Field Explanation
### Page 1: Event Registration Date
* **Event Registration Date** (`event_registration_form_date`, date, optional): Enter the date you registered the event.

### Page 1: Event Registration Date
* **Start Date** (`event_start_date`, date, optional): Enter the start date of the event.

### Page 1: Event Registration Date
* **End Date** (`event_end_date`, date, optional): Enter the end date of the event.

### Page 1: Event Registration Date
* **Event Registration Time** (`event_registration_form_time`, time, optional): Enter the time of event registration.

### Page 1: Event Registration Date
* **Start Time** (`event_start_time`, time, optional): Enter the start time of the event.

### Page 1: Event Registration Date
* **End Time** (`event_end_time`, time, optional): Enter the end time of the event.

### Page 2: Event Details
* **Event Location** (`event_location`, text, optional): Enter the physical location of the event.

### Page 2: Event Details
* **Event Note** (`event_note`, note, optional): Enter any additional comments or notes about the event.

### Page 3: Event Contact Information
* **Event Email** (`event_email`, email, optional): Enter the email address of the event organizer or contact person.

* **Event Phone** (`event_phone`, text, optional): Enter the phone number of the event organizer or contact person.

## Tips
* Make sure to fill in all required fields, if any.
* Double-check the information provided to ensure accuracy.
* If you're unsure about any field, consult the event organizer or refer to the provided hints.
