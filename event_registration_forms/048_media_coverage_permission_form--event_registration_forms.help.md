# Media Coverage Permission Form - Help Guide
## Purpose
This form is used to obtain media coverage permissions for events, including photography, recording, and other forms of media coverage. It is used by event organizers to inform participants about the terms of media coverage and by participants to provide information about their media use.

## How To Complete This Form

1.  Please review the form carefully and ensure that you have the necessary permissions and approvals from the event organizers and participants before completing it.
2.  Select the correct options for each field based on your needs and requirements.
3.  Ensure that you provide accurate and detailed information in each field.

## Field-by-Field Explanation

* **Event Registration Form** (`event_registration_form`, text, required/optional): This field is for event organizers to provide a brief description of the event.
* **Event Participants** (`event_participants`, select_multiple, required/optional): Please select whether participants will be present at the event.
* **Photographer Information** (`photographer_info`, text, required/optional): If you are a photographer, please provide your name and contact information.
* **Equipment List** (`equipment_list`, select_multiple, required/optional): Please select the type of equipment you will use (e.g., camera, microphone, etc.).
* **Recording Information** (`recording_info`, text, required/optional): If you are recording, please provide details about the type of recording you will do (e.g., video, audio, etc.).
* **Media Use** (`media_use`, select_multiple, required/optional): Please select the type of media use you will make of the event (e.g., print, online, etc.).
* **Permission Type** (`permission_type`, select_one, required/optional): Please select the type of permission you are seeking (e.g., yes, no, etc.).
* **Permission Date** (`permission_date`, date, required/optional): If permission is granted, please enter the date you wish to start using the media coverage.
* **Permission Time** (`permission_time`, time, required/optional): If permission is granted, please enter the time you wish to start using the media coverage.
* **Permission Note** (`permission_note`, note, required/optional): If there are any additional comments or conditions for the permission, please enter them here.
* **Event Name** (`event_name`, text, required/optional): Please enter the name of the event.
* **Event Dates** (`event_dates`, select_multiple, required/optional): Please select the dates of the event.
* **Event Location** (`event_location`, text, required/optional): Please enter the location of the event.
* **Event Organizer** (`event_organizer`, text, required/optional): Please enter the name of the event organizer.
* **Photo Credit Line** (`photo_credit_line`, select_one, required/optional): Please select whether a photo credit line is required.
* **Recording Credit Line** (`recording_credit_line`, text, required/optional): If you are recording, please provide the credit line for the recording.

## Tips

* Please ensure that you provide accurate and detailed information in each field.
* Please review the form carefully and ensure that you have the necessary permissions and approvals from the event organizers and participants before sharing any media coverage of the event.
* If you have any questions or concerns about the form, please contact the event organizer or our support team.
