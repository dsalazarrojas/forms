# exhibition_booth_complaint_form - Help Guide
## Purpose
This form is for reporting issues or concerns related to exhibition booths at events. It helps event organizers and staff track and resolve problems efficiently.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the title of the form as it will appear in the system.
2. Enter the name of the exhibitor or company related to the complaint.
3. Choose the type of complaint (select multiple options if applicable).
4. Provide details about the issue or concern.
5. Select the current status of the resolution.
6. Enter the date when the issue occurred.

## Field-by-Field Explanation
* **Exhibition Booth Complaint Form** (`exhibition_booth_complaint_form`, Text, Optional): Enter a brief title for the complaint or issue.
* **Exhibitor Name** (`exhibitor_name`, Text, Optional): Enter the name of the exhibitor or company related to the complaint.
* **Complaint Type** (`complaint_type`, Select Multiple, Optional): Select one or more types of complaint from the provided options (e.g., "complaint type 1", "complaint type 2", "complaint type 3").
* **Complaint Details** (`complaint_details`, Text, Optional): Describe the issue or concern in detail, including any relevant details or evidence.
* **Resolution Status** (`resolution_status`, Select One, Optional): Choose the status of the resolution, selecting either "resolved", "pending", or "closed".
* **Incident Date** (`date`, Date, Optional): Enter the date when the incident occurred.

## Tips

* Please fill out as many fields as necessary and provide as much detail as possible to efficiently communicate with the event staff.
* Ensure the form is filled out only once for each unique issue or concern.
* If an issue is resolved, update the resolution status accordingly.
* If multiple issues occur with the same exhibitor, use the same form but fill out new complaint details for each issue.
