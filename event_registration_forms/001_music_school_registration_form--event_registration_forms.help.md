# Music School Registration Form - Help Guide
## Purpose
This form is designed to gather essential information from students and their parents for music class enrollment. It helps to streamline the registration process, ensuring accuracy and preventing errors.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the student's name in the "Student Name" field.
2. Enter the student's email address in the "Student Email" field.
3. Enter the student's phone number in the "Student Phone" field.
4. Enter the parent's name in the "Parent Name" field.
5. Enter the parent's email address in the "Parent Email" field.
6. Choose whether the student will attend class on a specific day(s) in the "Class Days" field.
7. Select the class start time that suits the student best.
8. Choose whether the student will be learning a specific instrument in the "Instrument" field.
9. If the student will be learning a different instrument, enter the name in the "Other" field.
10. Add any additional notes about the student in the "Student Notes" field.
11. If you have a specific class start time, choose "Yes" and enter the time in the "Class Start Time Other" field.

## Field-by-Field Explanation
* **Student Name** (text): Enter the student's name as it appears on their identification.
* **Student Email** (email): Enter a valid email address that the student can use for communication.
* **Student Phone** (text): Enter the student's phone number for emergency contact purposes.
* **Parent Name** (text): Enter the parent's name for contact purposes.
* **Parent Email** (email): Enter a valid email address that the parent can use for communication.
* **Class Days** (select_one): Choose the day(s) you want the student to attend classes, e.g., Monday, Tuesday, Wednesday, etc.
* **Class Start Time** (time): Select the time the student starts classes. If you have a specific time, you can select "Yes" and enter the time.
* **Instrument** (select_one): Choose if the student will be learning a specific instrument. Options are "Yes" or "No".
*   **Instrument Other** (text): If the student is learning a different instrument, enter the name of the instrument here.
*   **Student Notes** (text): Add any additional notes about the student for our reference.
*   **Class Start Time Other** (time): If you have a specific class start time, choose "Yes" and enter the time.
