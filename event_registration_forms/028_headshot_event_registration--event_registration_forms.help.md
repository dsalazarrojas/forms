# Headshot Event Registration - Help Guide
## Purpose

This guide will walk you through the Headshot Event Registration form. The form is designed for registering attendees for the Headshot event, which can have multiple sessions. 

## How To Complete This Form

1. Select the event date for which you would like to attend.
2. Choose the event time for which you would like to attend.
3. Enter your name and email address so we can get in touch with you.
4. Select the Headshot Session(s) you would like to attend (you can select multiple sessions).
5. Enter the name and email address of the person who organized this event.
6. Enter the name of the event you are registering for.
7. Review and agree to the consent terms.
8. Add any additional information you would like to share.

## Field-by-Field Explanation

- **Event Date** (`event_registration_form_headshot_date`): Enter the date of the event for which you would like to register.
  * This field is a calendar field where you can select the date of the event.

- **Event Time** (`event_registration_form_headshot_time`): Select the time of the event for which you would like to register.
  * This field is a time field where you can select the time of the event.

- **Organizer Name** (`event_registration_form_organizer_name`): Enter the name of the person who organized this event.
  * This field is for the name of the person responsible for this event.

- **Organizer Email** (`event_registration_form_organizer_email`): Enter the email address of the person who organized this event.
  * This field is for the email address of the person responsible for this event.

- **Event Name** (`event_registration_form_event_name`): Enter the name of the event you are registering for.
  * This field is for the name of the event.

- **Headshot Session** (`event_registration_form_headshot_session`): Select the Headshot Session(s) you would like to attend.
  * This field allows you to choose one or more sessions.

- **Attendee Name** (`event_registration_form_attendee_name`): Enter your name.
  * This field is for your name.

- **Attendee Email** (`event_registration_form_attendee_email`): Enter your email address so we can get in touch with you.
  * This field is for your email address.

- **Consent** (`event_registration_form_consent`): Review and agree to the consent terms.
  * This field requires you to agree to the terms.

- **Notes** (`event_registration_form_notes`): Add any additional information you would like to share about this registration.
  * This field is for additional comments or information.

- **Additional Info** (`event_registration_form_additional_info`): Add any additional information you would like to share.
  * This field is for any additional comments or information.

**Tips**

* Please ensure to select the correct event date and time.
* Double-check the organizer's name and email address.
* Select the correct Headshot Session(s) you would like to attend.
* Review and agree to the consent terms.
* If you have any additional information, please add it in the "Additional Info" field.
