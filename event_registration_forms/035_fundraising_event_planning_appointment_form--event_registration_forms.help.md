# fundraising_event_planning_appointment_form - Help Guide
## Purpose
This form is used to plan and schedule events with appointments that need to be coordinated.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the Event Details section, providing a brief description of the event.
2. In the Plan Event Appointment section, enter the appointment details, including the start and end times.
3. Add any additional notes or comments in the Event Notes section.
4. Enter the email addresses of the event organizers in the Email Address field.
5. Enter the phone number of the event organizers in the Phone Number field.
6. Select the date of the event from the calendar.
7. Select the event organizers from the list of options.
8. Select the event participants from the list of options.
9. Add any additional notes or comments in the Notes field.
10. Click the Submit button to complete the form.

## Field-by-Field Explanation
* **Event Details** (`event_details`, text, optional): Enter a brief description of the event.
* **Plan Event Appointment** (`event_planning_appointment`, text, optional): Enter the appointment details, including start and end times.
* **Start Time** (`start_time`, time, optional): Enter the start time of the event.
* **End Time** (`end_time`, time, optional): Enter the end time of the event.
* **Event Notes** (`event_notes`, text, optional): Add any additional notes or comments about the event.
* **Email Address** (`email_address`, email, optional): Enter the email address of the event organizers.
* **Phone Number** (`phone_number`, text, optional): Enter the phone number of the event organizers.
* **Event Date** (`event_date`, date, optional): Select the date of the event from the calendar.
* **Event Organizers** (`event_organizers`, select_multiple, optional): Select the event organizers from the list of options.
* **Event Participants** (`event_participants`, select_multiple, optional): Select the event participants from the list of options.
* **Notes** (`notes`, text, optional): Add any additional notes or comments about the event.
* **Submit** (`submit`, text, optional): Click this button to complete the form.
