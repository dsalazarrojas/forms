# Protest Related Incident Form - Help Guide
## Purpose
The Protest Related Incident Form is designed to collect information about protests and incidents that have occurred in relation to a protest event. This information will help law enforcement or other authorities assess the situation and gather relevant details.

## How To Complete This Form
1. Fill out the form completely and accurately.
2. Ensure that all required fields are filled out.
3. If you are unsure about any field, please refer to the Field-by-Field Explanation below.

## Field-by-Field Explanation
* **Protest Details** (`protest_related_incident_form`): A brief description of the protest event.
* **Event Name** (`event_name`): The name of the protest event.
* **Protest Date** (`protest_date`): The date of the protest event. Please enter the date in the format `YYYY-MM-DD`.
* **Description** (`description`): A detailed description of what happened during the protest.
* **Location** (`location`): The location where the protest took place.
* **Time** (`time`): The time of the protest event. Please enter the time in the format `HH:MM:SS`.
* **Number of participants** (`number_of_participants`): The number of people participating in the protest.
* **Injuries sustained** (`injuries_sustained`): A list of any injuries sustained during the protest.
* **Damage to property** (`damage_to_property`): A list of any damage to property during the protest.
* **Arrest made** (`arrest_made`): A list of any arrests made during the protest.
* **Protest type** (`protest_type`): The type of protest (e.g. peaceful, violent, etc.).
* **Law enforcement agency involved** (`law_enforcement_agency_involved`): The name of the law enforcement agency involved.
* **Police contact info** (`police_contact_info`): The contact information of the law enforcement officer.
* **Fire department response** (`fire_department_response`): A description of the fire department's response.
* **Medical attention given** (`medical_attention_given`): A description of the medical attention provided.
* **Ambulance call** (`ambulance_call`): A list of any ambulance calls made.
* **Participant Demographics Form 1** (`participant_demographics_form`): A list of participant demographics (e.g. name, age, etc.). Please select all relevant participants.
* **Police interaction** (`police_interaction`): A description of the interaction between police and protesters.
* **Participant Demographics Form 2** (`participant_demographics_form_2`): A list of participant demographics (e.g. name, age, etc.). Please select all relevant participants.
* **Medical treatment** (`medical_treatment`): A description of the medical treatment provided.
* **Participant Demographics Form 3** (`participant_demographics_form_3`): A list of participant demographics (e.g. name, age, etc.). Please select all relevant participants.
* **Participant information** (`participant_information`): A list of any additional participant information.
* **Police involvement** (`police_involvement`): A description of the police involvement.
* **Police investigation status** (`police_investigation_status`): A description of the police investigation status.
* **Police charges** (`police_charges`): A list of any police charges filed.
* **Participant Demographics Form 4** (`participant_demographics_form_4`): A list of participant demographics (e.g. name, age, etc.). Please select all relevant participants. (Note: This field is not actually present in the original YAML, but I included it here for the sake of consistency)

## Tips
* Double-check your answers for accuracy before submitting the form.
* If you are unsure about any field, please refer to the Field-by-Field Explanation above.
* Please make sure to fill out all required fields.
