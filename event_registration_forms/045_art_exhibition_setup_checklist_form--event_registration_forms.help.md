# Art Exhibition Setup Checklist Form - Help Guide
## Purpose

This form is a checklist to help you set up and prepare for an art exhibition. It covers essential tasks related to event information, artwork preparation, venue preparation, signage and information, logistics and services, and staff and planning.

## How To Complete This Form

1. Read through each section carefully and ensure you understand the required tasks.
2. Answer each question truthfully, based on your current situation.
3. Fill out each field according to your progress and completion status.
4. Review and revise as necessary.

## Field-by-Field Explanation

* **Exhibition Name** (`exhibition_name`, text, required): Enter the name of the exhibition.
* **Exhibition Date** (`event_date`, date, required): Enter the date of the exhibition.
* **Setup Date** (`setup_date`, date, required): Enter the date when you will start setting up for the exhibition.
* **Setup Coordinator Name** (`coordinator_name`, text, required): Enter the name of the person responsible for setting up the exhibition.
* **All Artwork Catalogued and Inventoryed** (`artwork_catalogued`, select_one, required): Confirm if all artwork has been catalogued and inventoryed.
* **All Artwork Condition Checked** (`artwork_condition`, select_one, required): Confirm if all artwork has been condition checked.
* **All Artwork Insured** (`artwork_insured`, select_one, required): Confirm if all artwork is insured.
* **Display Specifications Ready for Each Piece** (`display_specs_ready`, select_one, required): Confirm if display specifications are ready for each piece.
* **Walls Prepared and Painted** (`walls_prepared`, select_one, required): Confirm if walls are prepared and painted (if necessary).
* **All Lighting Tested and Adjusted** (`lighting_tested`, select_one, required): Confirm if all lighting is tested and adjusted.
* **Climate Control Operational** (`climate_control`, select_one, required): Confirm if climate control is operational.
* **Security Measures in Place** (`security_measures`, select_one, required): Confirm if security measures are in place (alarms, cameras, security personnel).
* **Entrance and Directional Signage Installed** (`entrance_signage`, select_one, required): Confirm if entrance and directional signage is installed.
* **All Artwork Labels and Descriptions Ready** (`artwork_labels`, select_one, required): Confirm if all artwork labels and descriptions are ready (title, artist, date, price if applicable).
* **Exhibition Title Prominently Displayed** (`exhibition_title_display`, select_one, required): Confirm if the exhibition title is prominently displayed.
* **Refreshment Area Set Up** (`refreshment_setup`, select_one, required): Confirm if the refreshment area is set up (beverages, snacks, etc.).
* **Seating and Rest Areas Arranged** (`seating_arranged`, select_one, required): Confirm if seating and rest areas are arranged (if needed).
* **Restroom Access Available** (`restroom_access`, select_one, required): Confirm if restrooms are clearly marked and accessible.
* **Staff Trained on Exhibition Details** (`staff_trained`, select_one, required): Confirm if staff is trained on exhibition details (artwork information, emergency procedures).
* **Exhibition Ready for Opening** (`opening_ready`, select_one, required): Confirm if the exhibition is ready for opening (all items above completed).

## Tips

* Make sure to review and revise the form as necessary to reflect your progress.
* If you are unsure about any field, please seek assistance from a colleague or supervisor.
* This form is a tool to help you stay organized and ensure a successful exhibition.
