# event_planning_intake_form - Help Guide
## Purpose
This form is designed for event planners to collect and record essential details about an event.

## How To Complete This Form
To complete this form, follow these steps:
1. Fill in the **general_info** field with a brief overview of the event.
2. Select the **event_type** field with the relevant type of event (e.g., conference, workshop, party).
3. Provide the **event_location** field with the address or venue of the event.
4. In the **event_description** field, give a detailed description of the event.
5. Enter your **contact_info** in the corresponding field so that we can get in touch with you.
6. Fill in the **event_details** field with any additional information about the event.

## Field-by-Field Explanation
* **event_type** (select_one, required): Choose the type of event (e.g., conference, workshop, party).
* **event_date** (date, optional): Enter the date of the event (yyyy-mm-dd).
* **event_time** (time, optional): Enter the time of the event (hh:mm).
* **event_duration** (number, optional): Enter the duration of the event in minutes.
* **general_info** (text, optional): A brief description of the event.
* **event_location** (text, optional): The address or venue of the event.
* **event_description** (text, optional): A detailed description of the event.
* **contact_info** (text, optional): Contact information for follow-up purposes.
