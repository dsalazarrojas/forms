# Youth Initiative Program Application Form - Help Guide
## Purpose
The purpose of this form is to collect information from students to register themselves for the Youth Initiative Program.

## How To Complete This Form
1. To complete this form, navigate through the different pages using the tabs at the top.
2. Fill out each page with the required information. You can leave fields blank if you don't have the information or if it's not applicable.
3. Review each page carefully before proceeding.
4. Make sure to save your progress regularly to avoid losing any information.

## Field-by-Field Explanation

* **Contact Information** (`contact_information`, text, required: false): This is where you provide basic information about yourself.
* **Basic Contact** (`basic_contact`, text, required: false): This is where you provide more detailed contact information, such as phone number, email, etc.
* **Talents and Interests** (`student_talent`, text, required: false): This is where you list your talents and interests, such as music, art, sports, etc.
* **Parent Contact** (`parent_contact`, text, required: false): This is where you provide contact information for a parent or guardian.
* **Emergency Contact** (`emergency_contact`, text, required: false): This is where you provide contact information for an emergency contact.
* **Interests** (`student_interests`, select_multiple, required: false): This is where you select your interests from the list.
* **Talents** (`student_talents`, select_multiple, required: false): This is where you select your talents from the list.
* **Skills** (`student_skills`, select_multiple, required: false): This is where you select your skills from the list.
* **Subjects** (`student_subjects`, select_multiple, required: false): This is where you select your subjects of interest from the list.

## Tips
* Make sure to save your progress regularly to avoid losing any information.
* If you have any questions or issues, please contact us for assistance.
* Double-check your information before submitting the form to ensure accuracy.
