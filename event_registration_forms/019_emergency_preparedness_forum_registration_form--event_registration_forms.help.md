# Emergency Preparedness Forum Registration Form - Help Guide

## Purpose

This form is used for registering participants in the Emergency Preparedness Forum. It captures critical information about the participant, their emergency contact, and their training background.

## How To Complete This Form

1. Review the form carefully before starting to fill it out.
2. Ensure you have all the necessary information before proceeding.
3. Fill out the form in the following order: Registration Information, Participant Info, Emergency Contact, Participant Details, and finally, click the "Submit" button.

## Field-by-Field Explanation

* **Registration Information** (<type>: text, <required>: false): This is the title of the form. Please do not modify this field.
* **Participant Info** (<type>: text, <required>: true): This is where you provide basic information about yourself as the participant. 
  *   Enter your name in this field.
* **Emergency Contact** (<type>: text, <required>: true): Provide information for your emergency contact.
  *   Enter the phone number for your emergency contact.
* **Emergency Phone** (<type>: number, <required>: false): If you have an emergency phone number, enter it here. This is not required.
* **Emergency Email** (<type>: email, <required>: false): If you have an emergency email, enter it here. This is not required.
* **Participant Name** (<type>: text, <required>: true): Enter your name as the participant.
* **Participant Organizational Affiliation** (<type>: text, <required>: false): If you have an organizational affiliation, enter it here.
* **Participant Role** (<type>: text, <required>: false): If you have a specific role in your organization, enter it here.
* **Participant Position** (<type>: text, <required>: false): If you have a specific position in your organization, enter it here.
* **Participant Title** (<type>: text, <required>: false): If you have a title, enter it here.
* **Participant Department** (<type>: text, <required>: false): If you have a department, enter it here.
* **Participant Job Title** (<type>: text, <required>: false): If you have a job title, enter it here.
* **Participant Work Email** (<type>: email, <required>: false): If you have a work email, enter it here.
* **Participant Work Phone** (<type>: text, <required>: false): If you have a work phone number, enter it here.
* **Participant Work Location** (<type>: text, <required>: false): If you have a work location, enter it here.
* **Emergency Contact Relationship** (<type>: select_one, <required>: true): Select the relationship between you and your emergency contact.
* **Participant Training Level** (<type>: select_multiple, <required>: true): Select the level of training you have completed.
* **Participant Training Interests** (<type>: select_multiple, <required>: false): Select the training interests you have.
* **Participant Agency** (<type>: text, <required>: false): If you represent an agency, enter it here.
* **Participant Agency Address** (<type>: text, <required>: false): If you have an agency address, enter it here.
* **Participant Agency City** (<type>: text, <required>: false): If you have a city for your agency, enter it here.
* **Participant Agency State** (<type>: text, <required>: false): If you have a state for your agency, enter it here.
* **Participant Agency Zip** (<type>: text, <required>: false): If you have a zip for your agency, enter it here.
* **Participant Agency Country** (<type>: text, <required>: false): If you have a country for your agency, enter it here.
* **Submit** (<type>: text, <required>: false): Click this button to submit your registration.
