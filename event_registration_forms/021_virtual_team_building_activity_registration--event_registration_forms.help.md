# Virtual Team Building Activity Registration - Help Guide
## Purpose
This form is used to collect information for virtual team building activities, including team details, dates, and registration settings.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the **Team Name** of your team.
2. Select the **Start Date** and **End Date** of the activity.
3. Provide a brief description of the **Activity Title** and **Activity Description**.
4. Enter the **Location** of the activity.
5. If applicable, select the **Organizer**.
6. Enter the **Capacity** of the activity (if applicable).
7. Choose the **Time Slots** for the activity (if applicable).
8. Select the **Timezone** and **Language** for the activity.
9. Enter your email address and select the **Time Format** for the activity.
10. Configure the registration link settings (if applicable).

## Field-by-Field Explanation

* **Team Name** (Team Name, text, required): Enter the name of your team.
* **Start Date** (Start Date, date, required): Select the start date of the activity.
* **End Date** (End Date, date, required): Select the end date of the activity.
* **Activity Title** (Activity Title, text, required): Enter a brief title for the activity.
* **Activity Description** (Activity Description, text, optional): Provide a brief description of the activity.
* **Location** (Location, text, required): Enter the location of the activity.
* **Organizer** (Organizer, text, optional): If applicable, enter the name of the activity organizer.
* **Capacity** (Capacity, number, optional): Enter the capacity of the activity (if applicable).
* **Time Slots** (Time Slots, select multiple, optional): Choose the time slots for the activity (if applicable).
* **Time Slots Options** (Time Slots Options, select one, optional): Select the time slot option (if applicable).
* **Timezone** (Timezone, select one, required): Select the timezone for the activity.
* **Language** (Language, select one, required): Select the language for the activity.
* **Time Format** (Time Format, select one, required): Select the time format for the activity.
* **Registration Link** (Registration Link, select one, optional): Configure the registration link settings (if applicable).
* **Registration Link Label** (Registration Link Label, text, optional): Enter a label for the registration link (if applicable).
* **Registration Link Url** (Registration Link Url, text, optional): Enter the URL of the registration link (if applicable).
* **Registration Link Target** (Registration Link Target, text, optional): Enter the target of the registration link (if applicable).
* **Registration Link Type** (Registration Link Type, select one, optional): Select the type of registration link (if applicable).
* **Registration Link Style** (Registration Link Style, select one, optional): Select the style of registration link (if applicable).
* **Registration Link Background Color** (Registration Link Background Color, select one, optional): Select the background color of the registration link (if applicable).
* **Registration Link Text Color** (Registration Link Text Color, select one, optional): Select the text color of the registration link (if applicable).
* **Registration Link Target Window** (Registration Link Target Window, number, optional): Enter the target window for the registration link (if applicable).
* **Participant Email** (Participant Email, email, required): Enter your email address for registration.
* **Timezone** (Timezone, select one, required): Confirm the timezone for the activity.
* **Registration Link Target Window** (Registration Link Target Window, number, optional): This field is not required and only appears if the registration link settings are configured. Enter the target window for the registration link.
* **Language** (Language, select one, required): Select the language for the activity.
* **Time Format** (Time Format, select one, required): Select the time format for the activity.

## Tips
* Please ensure that you are registering for the correct team and event.
* Double-check the timezone and language settings for accuracy.
* Enter a valid email address for registration.
* If you are unsure about any of the fields, contact the event organizer or refer to the event invitation.
