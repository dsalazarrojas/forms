# Event Cancellation Form - Help Guide
## Purpose
The Event Cancellation Form is used to report event cancellations, allowing event organizers to process the cancellation and refund (if applicable) in a structured and efficient way.
## How To Complete This Form
To complete this form, follow these steps:
1. Fill in your User Information (page 1).
2. Provide Event Details (page 2).
3. Specify the Cancellation Reason (page 3).
4. If applicable, select the Refund Amount and Refund Method (page 4).
5. Add any Comments about the cancellation (page 5).
6. Enter your Contact Information (page 6).
7. Confirm whether you are canceling the event (page 7).
8. Confirm whether a refund will be issued (page 8).
9. Confirm whether you agree with the Cancellation Reason (page 9).
## Field-by-Field Explanation

* **User Information** (`user_info`, text, optional): Please fill in your personal details such as name and contact information.
* **Event Details** (`event_details`, text, optional): Provide a brief description of the event you are canceling.
* **Cancellation Reason** (`reason`, text, optional): Select the reason for the cancellation.
* **Refund Amount** (`refund_amount`, number, optional): If applicable, enter the amount you are requesting for a refund.
* **Refund Method** (`refund_method`, select_one, optional): Select the method you would like to use for the refund.
* **Comments** (`comments`, text, optional): Add any additional comments about the cancellation.
* **Contact Info** (`contact_info`, email, optional): Enter your contact information so we can reach out to you.
* **Confirm Cancellation** (`confirm_cancel`, select_multiple, optional): Confirm whether you are canceling the event.
* **Confirm Refund** (`confirm_refund`, select_multiple, optional): Confirm whether you are requesting a refund.
* **Confirm Cancellation Reason** (`confirm_cancel_reason`, select_multiple, optional): Confirm whether you agree with the Cancellation Reason.

Note: All fields are optional unless marked as required.
