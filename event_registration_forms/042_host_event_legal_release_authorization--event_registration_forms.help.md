# Host Event Legal Release Authorization - Help Guide
## Purpose
This form is a legal release authorization form for event participants. It aims to collect necessary information from event hosts about their event details, participants, and permissions.

## How To Complete This Form
To complete this form, follow the steps below:
1.  Determine if the participant is a host or not. Select "Yes" or "No" to indicate if the participant is the event host.
2.  List all participant names in the "Participant Names" field.
3.  List all services and products provided to participants in the "Participant Services and Products" field.
4.  Provide a detailed list of participant services and products in the "Participant Services and Products List" field.
5.  Describe participant responsibilities in the "Participant Responsibilities" field.
6.  Grant or deny permission to the event host using the "Event Host Permission" field.
7.  Provide a detailed list of event host permission in the "Event Host Permission List" field.

## Field-by-Field Explanation

*   **Event Host** (`event_host`, select_one, required: false): This field asks if the participant is an event host. Select "Yes" if the participant is the event host, and "No" otherwise.
*   **Participant Names** (`participant_names`, text, required: false): This field is used to list all participant names. This is a text area where you can input one or multiple participant names separated by commas or new lines.
*   **Participant Services and Products** (`participant_services_and_products`, text, required: false): This field is used to list all services and products provided to participants. This is a text area where you can input one or multiple services and products separated by commas or new lines.
*   **Participant Services and Products List** (`participant_services_and_products_list`, text, required: false): This is a detailed list of participant services and products. Input one or multiple services and products in this text field.
*   **Participant Responsibilities** (`participant_responsibilities`, text, required: false): This field is used to describe participant responsibilities. Input a brief description of the participant's responsibilities.
*   **Event Host Permission** (`event_host_permission`, select_one, required: false): This field is used to grant or deny permission to the event host. Select "Yes" to grant permission, and "No" to deny permission.
*   **Event Host Permission List** (`event_host_permission_list`, text, required: false): This is a detailed list of event host permission. Input one or multiple permissions in this text field.

## Tips
- This form is not required for all events, but it is recommended for events with multiple participants.
- The form is designed to be completed by the event host.
- The form should be reviewed carefully before submission to ensure all necessary information is provided.
