# Signage Requisition Form - Help Guide
## Purpose
The Signage Requisition Form is a tool used to collect information about events that need signage. The form helps event organizers and participants request signage support from the internal signage team.

## How To Complete This Form
To complete the Signage Requisition Form, follow these steps:

* Ensure you have all the necessary information about the event.
* Read through each section of the form carefully and fill in the required fields.
* Double-check your entries for accuracy before submitting the form.

## Field-by-Field Explanation

* **Event Registration Forms** (`event_registration_forms_title`): Enter a brief title for the event (e.g., "Summer Concert Series").
* **Event Type** (`event_type`): Select the type of event from the drop-down list (e.g., "Report", "Presentation", "Concert", etc.).
* **Event Date** (`event_date`): Enter the date of the event in the required format (e.g., "2024-02-15").
* **Event Time** (`event_time`): Enter the time of the event in the required format (e.g., "14:00").
* **Signage Type** (`signage_type`): Select the type of signage required for the event from the drop-down list (e.g., "Banner", "Logo", etc.).
* **Signage Location** (`signage_location`): Enter the location where the signage will be displayed (e.g., "Lobby", "Theater", etc.).
* **Event Description** (`event_description`): Provide a brief description of the event (e.g., "Summer concert featuring [artist name]").
* **Contact Person** (`contact_person`): Enter the name of the person responsible for the event.
* **Contact Phone** (`contact_phone`): Enter the phone number of the person responsible for the event.
* **Contact Email** (`contact_email`): Enter the email address of the person responsible for the event.
* **Organization** (`organization`): Enter the name of the organization hosting the event.

## Tips
* Ensure you have the necessary permissions and approvals before requesting signage support.
* Double-check your entries for accuracy before submitting the form.
* If you need help or have questions, contact the internal signage team.
