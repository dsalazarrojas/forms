# Event Planner Request Form - Help Guide
## Purpose
This form is designed for event planners to request and provide information about upcoming events. It helps in creating a comprehensive event request that includes details about the event, set-up, media, catering, and fundraiser information.

## How To Complete This Form

* Fill out the form completely and carefully, making sure the information provided is accurate and up-to-date.
* Review each field to ensure you're entering the correct information.
* Use the available options for fields like Set-up Type, Media Type, Catering, and Fundraiser Type to select the relevant options.

## Field-by-Field Explanation

* **Event Information** (`event_information`, text, optional):
	+ Enter a brief description of the event.
* **Set-up Information** (`set_up_information`, text, optional):
	+ Enter any additional information about the set-up for the event.
* **Media Information** (`media_information`, text, optional):
	+ Enter information about the media to be used for the event (e.g., video, audio, image).
* **Catering Information** (`catering_information`, text, optional):
	+ Enter details about the catering for the event.
* **Fundraiser Information** (`fundraiser_information`, text, optional):
	+ Enter information about the fundraiser for the event.
* **Event Name** (`event_name`, text, optional):
	+ Enter the name of the event.
* **Event Date** (`event_date`, date, optional):
	+ Select the date of the event.
* **Event Time** (`event_time`, time, optional):
	+ Select the time of the event.
* **Set-up Type** (`set_up_type`, select_one, optional):
	+ Select the type of set-up required for the event.
* **Set-up Location** (`set_up_location`, text, optional):
	+ Enter the location of the set-up.
* **Catering** (`catering`, select_multiple, optional):
	+ Select the catering options that apply to the event.
* **Event Description** (`event_description`, text, optional):
	+ Enter a brief description of the event.
* **Media Type** (`media_type`, select_one, optional):
	+ Select the type of media to be used for the event.
* **Media URL** (`media_url`, text, optional):
	+ Enter the URL of the media to be used for the event.
* **Event Size** (`event_size`, select_multiple, optional):
	+ Select the size of the event.
* **Event Type** (`event_type`, select_one, optional):
	+ Select the type of event (public or private).
* **Event Budget** (`event_budget`, number, optional):
	+ Enter the budget for the event.
* **Event Venue** (`event_venue`, text, optional):
	+ Enter the location of the event.
* **Fundraiser Description** (`fundraiser_description`, text, optional):
	+ Enter a brief description of the fundraiser.
* **Fundraiser Type** (`fundraiser_type`, select_one, optional):
	+ Select the type of fundraiser.
* **Event Status** (`event_status`, select_one, optional):
	+ Select the status of the event (pending or confirmed).
* **Event Note** (`event_note`, note, optional):
	+ Enter any additional notes about the event.
* **Submit** (`submit`, text, optional):
	+ Review and submit the form.
