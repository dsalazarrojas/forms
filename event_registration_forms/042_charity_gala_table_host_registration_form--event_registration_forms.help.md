# Charity Gala Table Host Registration Form - Help Guide
## Purpose
The Charity Gala Table Host Registration Form is used to collect information from hosts and their guests attending the charity gala. It is essential to complete the form accurately to ensure a smooth and enjoyable experience for everyone.

## How To Complete This Form
To complete the form, follow these steps:

1. Enter your first and last name in the Host First Name and Host Last Name fields.
2. Enter your contact email address in the Email Address field.
3. Enter your contact phone number in the Phone Number field.
4. If applicable, enter your company or organization's name in the Company or Organization field.
5. Enter the name of the gala event in the Gala Event Name field.
6. Select the date of the gala event in the Event Date field.
7. Choose your table sponsorship level from the Table Sponsorship Level options.
8. Enter the expected number of guests attending in the Expected Number of Guests field.
9. Select the status of your guest list submission in the Guest List Status field.
10. If applicable, list your guests' names in the Guest Names field.
11. Choose your preferred table location from the Table Location Preference options (if applicable).
12. If applicable, enter any dietary requirements for your guests in the Dietary Requirements for Table field.
13. Select whether you would like to add a wine package to your table (if applicable).
14. If applicable, select an additional donation amount to support the charity.
15. Choose how you would like to be recognized in the program (if applicable).
16. Select your preferred payment method (if applicable).
17. Confirm your commitment to filling your table (if applicable).
18. Enter any additional comments or special requests in the Additional Comments field (if applicable).

## Field-by-Field Explanation

* **Host First Name** (`host_first_name`, Text, Required): Enter your first name.
* **Host Last Name** (`host_last_name`, Text, Required): Enter your last name.
* **Email Address** (`host_email`, Email, Required): Enter your contact email address.
* **Phone Number** (`host_phone`, Text, Required): Enter your contact phone number.
* **Company or Organization** (`company_name`, Text, Optional): If applicable, enter your company or organization's name.
* **Gala Event Name** (`gala_name`, Text, Required): Enter the name of the gala event.
* **Event Date** (`gala_date`, Date, Required): Select the date of the gala event.
* **Table Sponsorship Level** (`table_sponsorship`, Select One, Required): Choose your table sponsorship level.
* **Expected Number of Guests** (`expected_guests`, Number, Required): Enter the expected number of guests attending your table.
* **Guest List Status** (`guest_list_status`, Select One, Required): Select the status of your guest list submission.
* **Guest Names** (`guest_names`, Text, Optional): If applicable, list your guests' names.
* **Table Location Preference** (`table_preferences`, Select One, Optional): If applicable, choose your preferred table location.
* **Dietary Requirements for Table** (`dietary_requirements`, Text, Optional): If applicable, enter any dietary requirements for your guests.
* **Wine Package Addition** (`wine_package`, Select One, Optional): Select whether you would like to add a wine package to your table.
* **Additional Donation** (`additional_donation`, Select One, Optional): If applicable, select an additional donation amount to support the charity.
* **Recognition Preference** (`recognition_preference`, Select One, Required): Choose how you would like to be recognized in the program.
* **Payment Method** (`payment_method`, Select One, Required): Select your preferred payment method.
* **Do You Commit to Filling Your Table** (`host_commitment`, Select One, Required): Confirm your commitment to filling your table.
* **Additional Comments** (`additional_comments`, Text, Optional): Enter any additional comments or special requests.
