# Healthcare Service Improvement Workshop Registration - Help Guide
## Purpose
The "Healthcare Service Improvement Workshop Registration" form is used to collect and organize information about upcoming healthcare service improvement workshops. This information includes workshop details, participant information, and registration settings.

## How To Complete This Form
To complete this form, please follow these steps:

1. Enter the workshop name in the "Workshop Name" field.
2. Enter your name in the "Name" field.
3. Enter your email address in the "Email" field.
4. Enter your phone number in the "Phone" field.
5. Select a date for the workshop in the "Date" field.
6. Select a time for the workshop in the "Time" field.
7. Enter any additional workshop details in the "Workshop Details" field.
8. Select the topics to be covered in the workshop from the list in the "Workshop Topics" field.
9. Select the type of registration from the options provided in the "Registration Type" field.
10. Add any comments about the workshop in the "Comments" field.
11. Select the status of the workshop from the options provided in the "Workshop Status" field.
12. Select the start and end dates for the workshop in the "Workshop Start Date" and "Workshop End Date" fields.
13. Select the start and end times for the workshop in the "Workshop Start Time" and "Workshop End Time" fields.
14. Enter the workshop location in the "Workshop Location" field.
15. Enter the workshop duration in the "Workshop Duration" field.
16. Enter the participant limit for the workshop in the "Participant Limit" field.
17. Enter the current participant count for the workshop in the "Participant Count" field.
18. Select the date when registration opens and closes in the "Registration Open" and "Registration Close" fields.
19. Enter any additional notes about the workshop in the "Workshop Notes" field.
20. Upload an image for the workshop in the "Workshop Image" field.

## Field-by-Field Explanation
- **Workshop Name** (`Workshop Name`, text, required/optional): Enter the name of the workshop that is being registered.
- **Name** (`Name`, text, required/optional): Enter your name for contact purposes.
- **Email** (`Email`, email, required/optional): Enter your email address for contact purposes.
- **Phone** (`Phone`, text, required/optional): Enter your phone number for contact purposes.
- **Date** (`Date`, date, required/optional): Select the date of the workshop.
- **Time** (`Time`, time, required/optional): Select the time of the workshop.
- **Workshop Details** (`Workshop Details`, text, required/optional): Enter any additional details about the workshop.
- **Workshop Topics** (`Workshop Topics`, select_multiple, required/optional): Select the topics to be covered in the workshop.
- **Registration Type** (`Registration Type`, select_one, required/optional): Select the type of registration for the workshop.
- **Comments** (`Comments`, note, required/optional): Add any comments about the workshop.
- **Workshop Status** (`Workshop Status`, select_one, required/optional): Select the status of the workshop.
- **Workshop Start Date** (`Workshop Start Date`, date, required/optional): Select the start date of the workshop.
- **Workshop End Date** (`Workshop End Date`, date, required/optional): Select the end date of the workshop.
- **Workshop Start Time** (`Workshop Start Time`, time, required/optional): Select the start time of the workshop.
- **Workshop End Time** (`Workshop End Time`, time, required/optional): Select the end time of the workshop.
- **Workshop Location** (`Workshop Location`, text, required/optional): Enter the location of the workshop.
- **Workshop Duration** (`Workshop Duration`, number, required/optional): Enter the duration of the workshop.
- **Participant Limit** (`Participant Limit`, number, required/optional): Enter the participant limit for the workshop.
- **Participant Count** (`Participant Count`, number, required/optional): Enter the current participant count for the workshop.
- **Registration Open** (`Registration Open`, date, required/optional): Select the date when registration opens.
- **Registration Close** (`Registration Close`, date, required/optional): Select the date when registration closes.
- **Workshop Notes** (`Workshop Notes`, note, required/optional): Enter any additional notes about the workshop.
- **Workshop Image** (`Workshop Image`, text, required/optional): Upload an image for the workshop.

## Tips
- Please ensure that you have the necessary permissions to access this form.
- If you are unsure about any field or form setting, please consult the form's creator or a supervisor.
- This form is designed for healthcare service improvement workshops, so please provide accurate and relevant information.
