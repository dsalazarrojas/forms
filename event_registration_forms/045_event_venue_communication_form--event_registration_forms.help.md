# Event Venue Communication Form - Help Guide

## Purpose
This form is designed to collect event-specific information from users, including event name, location, date, start and end times, description, contact information (name, email, and phone number), and attached documents.

## How To Complete This Form

1. Fill out each field with accurate and relevant information.
2. For the **event name**, enter the name of the event you are submitting.
3. For the **event location**, enter the address of the event venue.
4. Select the **event date** for the event.
5. Enter the **start time** for the event.
6. Enter the **end time** for the event.
7. Provide a brief **event description** to give context about the event.
8. Enter the name of the **event contact person**.
9. Enter the **event contact email** of the person you are submitting the event for.
10. Enter the **event contact phone** number for the person you are submitting the event for (optional).
11. Upload any **attached documents** related to the event.

## Field-by-Field Explanation

* **event venue name**: Enter the name of the event venue to identify it uniquely.
* **event venue location**: Enter the address of the event location to ensure attendees know where it is.
* **event date**: Select the date for the event from the calendar provided.
* **start time**: Select the start time for the event from the clock icon.
* **end time**: Select the end time for the event from the clock icon.
* **event description**: Provide a brief description of the event to give context.
* **event contact name**: Enter the name of the person responsible for the event.
* **event contact email**: Enter the email address of the person responsible for the event.
* **event contact phone**: Enter the phone number of the person responsible for the event (optional).
* **attached documents**: Upload any relevant documents attached to the event, such as maps or schedules.

## Tips
- Make sure to fill out all required fields accurately.
- Use standard date and time formats (e.g., YYYY-MM-DD and HH:MM AM/PM).
- If you have attached documents, upload them to share with event organizers and attendees.
