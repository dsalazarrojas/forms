# virtual_product_demo_registration_form - Help Guide
## Purpose
This form is used to register for a virtual product demo event. To get started, click the "Submit" button below.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the details requested in the form, making sure to provide the required information (indicated by asterisks \*).
2. Click the "Submit" button to send the form.

## Field-by-Field Explanation

* **New Product Demo (\`new_product_demo\`)**: Enter a brief description of the new product being demoed. Please provide as much detail as possible to help us understand the product's features and value.
* **Available Slots (\`available_slots\`)**: Choose the available slots that you would like to attend during the demo event. Select all the slots that apply to you.
* **Scheduled Time (\`scheduled_time\`)**: Select the time you would like to attend the demo event. Please choose a time that works best for you.
* **Appointment Time (\`appointment_time\`)**: Let us know if you would like to schedule an appointment during the demo event. Select "Yes" if you would like to schedule an appointment, and "No" otherwise.

## Tips
* Make sure to fill in all required fields (indicated by asterisks \*).
* If you have any questions or need help with completing this form, please don't hesitate to contact our support team.
* Please note that the demo event schedule is subject to change, and we will notify you if there are any changes.
