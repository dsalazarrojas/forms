# Joint Spiritual Revival Invitation - Help Guide
## Purpose
The Joint Spiritual Revival Invitation form is designed to gather information from guests and sponsors for a specific event. This form is meant to collect RSVP responses, event details, and other relevant information to ensure a smooth and enjoyable experience for all attendees.

## How To Complete This Form
To complete this form, follow these steps:

1.  Fill in the required fields: **Is Attending**, **Event Dates**, **Event Time**, and **Event Location**. If you're not attending, please indicate **Is Sponsored** and provide the required sponsor details.
2.  Select your **RSVP Response** for the event (if applicable).
3.  Fill in your **Guest Details**, **Guest Preferences**, and **Event Description**.
4.  If you have any **Special Requests**, please provide additional information in the **Special Request Details** field.
5.  If you're a sponsor, please indicate **Is Sponsored** and provide the required sponsor details.

## Field-by-Field Explanation

* **Is Attending** (ID 12, Type: select_one, Required): Check this box if you plan to attend the event.
* **Is Sponsored** (ID 18, Type: select_one, Required): Check this box if the event is sponsored.
* **Event Dates** (ID 5, Type: date, Required): Select the dates of the event.
* **Event Time** (ID 6, Type: time, Required): Select the time of the event.
* **Event Location** (ID 7, Type: text, Required): Enter the address of the event location.
* **Event Description** (ID 17, Type: text, Required): Briefly describe the event.
* **RSVP Response** (ID 2, Type: select_multiple, Optional): Choose one or multiple response options for the event.
* **Guest Details** (ID 3, Type: text, Optional): Enter any relevant details about your guests.
* **Guest Preferences** (ID 4, Type: text, Optional): Enter your guests' preferences.
* **Phone Number** (ID 9, Type: text, Optional): Enter your phone number.
* **Email Address** (ID 10, Type: email, Optional): Enter your email address.
* **Contact Person** (ID 8, Type: text, Optional): Enter the name of the person in charge.
* **Email Address** (ID 22, Type: email, Optional): Enter the email address of the person in charge.
* **Notes and Comments** (ID 11, Type: note, Optional): Add any additional notes or comments about the event.
* **Comments** (ID 13, Type: note, Optional): Add any additional comments about the event.
* **Additional Comments** (ID 14, Type: note, Optional): Add any additional comments about the event.
* **Special Requests** (ID 15, Type: text, Optional): Enter any special requests.
* **Special Request Details** (ID 16, Type: text, Optional): Enter additional details about your special requests.
* **Sponsor Name** (ID 19, Type: text, Optional): Enter the name of the sponsor.
* **Sponsor Details** (ID 20, Type: text, Optional): Enter additional details about the sponsor.
* **Sponsor Phone Number** (ID 21, Type: text, Optional): Enter the sponsor's phone number.
* **Sponsor Email Address** (ID 22, Type: email, Optional): Enter the sponsor's email address.
* **Sponsor Comments** (ID 23, Type: note, Optional): Add any comments from the sponsor.
* **Sponsor Additional Comments** (ID 24, Type: note, Optional): Add any additional comments from the sponsor.
* **Submission Details** (ID 25, Type: text, Optional): Enter any submission details.
