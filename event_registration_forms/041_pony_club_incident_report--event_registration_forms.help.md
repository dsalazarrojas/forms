# Pony Club Incident Report - Help Guide
## Purpose
This form is used to record incidents that occurred during Pony Club activities, such as accidents, injuries, or other significant events. Please use this form to provide a clear and accurate report of what happened, including dates, locations, and any details that may be relevant to the incident.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the **Activity Date** field with the date of the incident.
2. Enter the **Report Date** field with the date you are submitting the report.
3. Select the **Incident Location** from the dropdown menu (e.g., Home, School, Park, or Other).
4. Provide a detailed description of what happened in the **Incident Description** field.
5. List any participants in the **Incident Participants** field.
6. Specify any injuries sustained by participants in the **Incident Injuries** field (choose one or more from the dropdown menu).
7. Describe the **Incident Outcome**, selecting the option that best summarizes what happened (e.g., No action taken, First aid given, Parent contacted, etc.).
8. Add any additional notes about the incident in the **Incident Notes** field.
9. If applicable, provide the names and contact information of any witnesses in the **Witness Names** and **Witness Contact** fields.

## Field-by-Field Explanation

* **Activity Date** (Date): Enter the date the incident occurred.
* **Report Date** (Date): Enter the date you are submitting this report.
* **Incident Location** (Select One): Choose where the incident happened (e.g., Home, School, Park, Other).
* **Incident Description** (Text): Provide a detailed description of what happened.
* **Incident Participants** (Text): List any participants in the incident.
* **Incident Injuries** (Select Multiple): Specify any injuries sustained by participants (e.g., Minor, Moderate, Severe).
* **Incident Outcome** (Select One): Describe the outcome of the incident (e.g., No action taken, First aid given, Parent contacted, etc.).
* **Incident Notes** (Note): Add any additional notes about the incident.
* **Witness Names** (Text): Provide the names of any witnesses.
* **Witness Contact** (Text): Enter contact information for any witnesses (if applicable).
