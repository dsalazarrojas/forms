# Team Recognition Event Registration Form - Help Guide
## Purpose
This form is used to register teams for recognition events, providing essential details about the team and the event.

## How To Complete This Form

1. Select the team's ID from the provided options or input a new ID if it is not listed.
2. Enter the date of the event in the format `YYYY-MM-DD`.
3. Enter the name of the team being recognized.
4. Enter the email address of the team leader.
5. Enter the phone number of the team leader (optional).
6. Enter the team's address (optional).
7. Provide a brief description of the event.
8. Select the RSVP status for the event (`Yes` or `No`).
9. Enter the event's description (optional).
10. Select the event's venue (optional).
11. Enter the time of the event (HH:MM AM/PM format).
12. Select the team's attendance status for the event (`Yes` or `No`).
13. Enter the team's capacity for the event (optional).
14. Select the event's booking status (`Active` or `Inactive`).
15. Enter the date of the event booking (optional).
16. Select the time of the event booking (HH:MM AM/PM format) (optional).
17. Select the event's booking status (`Active` or `Inactive`) to confirm the status of the event.
18. Enter any additional comments about the event.

## Field-by-Field Explanation

* **Team Id (1)**: A unique identifier for the team participating in the event.
* **Event Date (2)**: The date of the event in `YYYY-MM-DD` format.
* **Team Name (3)**: The name of the team being recognized.
* **Team Leader Email (4)**: The email address of the team leader.
* **Team Leader Phone (5)**: The phone number of the team leader (optional).
* **Team Address (6)**: The address of the team (optional).
* **Event Description (7)**: A brief description of the event (optional).
* **RSVP By (8)**: Select `Yes` if the team member will attend the event, or `No` otherwise.
* **RSVP Message (9)**: A message for the team members to communicate their RSVP status (optional).
* **Event Venue (10)**: The location where the event will take place (optional).
* **Event Time (11)**: The time of the event in HH:MM AM/PM format (optional).
* **Team Attendance (12)**: Select `Yes` if the team will attend the event, or `No` otherwise.
* **Team Capacity (13)**: The number of team members attending the event (optional).
* **Event Booking Status (14)**: Select `Active` if the event is active, or `Inactive` otherwise.
* **Event Booking Date (15)**: The date of the event booking (optional).
* **Event Booking Time (16)**: The time of the event booking (HH:MM AM/PM format) (optional).
* **Event Booking Status (17)**: Select `Active` if the event is active, or `Inactive` otherwise.
* **Comments (18)**: Additional comments about the event (optional).
