# Event Planner Nomination Form - Help Guide
## Purpose
The Event Planner Nomination Form is used to collect information from both the event planner and the nominator for an event. This form is used for internal nomination and event planning purposes.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the required fields for the nominator:
   * Nominator Name: Enter the name of the person or organization nominating the event planner.
   * Nominator Email: Enter the email address of the person or organization nominating the event planner.
   * Nominator Phone: Enter the phone number of the person or organization nominating the event planner.
   * Nominator Organization: Enter the organization name of the person or organization nominating the event planner.
   * Nominator Title: Enter the title of the person or organization nominating the event planner.
   * Nominator Message: Enter any additional information about the nominator.
   * Nominator Agreement: Confirm that the information provided is accurate.
2. Fill in the required fields for the event planner:
   * Event Planner Name: Enter the name of the event planner.
   * Event Planner Email: Enter the email address of the event planner.
   * Event Planner Phone: Enter the phone number of the event planner.
3. If necessary, provide any additional information about the event planner with Additional Info.
4. Review and submit the form.

## Field-by-Field Explanation

* **Nomination Form**: A text area where you can enter any additional information about the nomination.
* **Nominator Name**: The name of the person or organization nominating the event planner.
* **Nominator Email**: The email address of the person or organization nominating the event planner.
* **Nominator Phone**: The phone number of the person or organization nominating the event planner.
* **Nominator Organization**: The organization name of the person or organization nominating the event planner.
* **Nominator Title**: The title of the person or organization nominating the event planner.
* **Nominator Message**: A text area where you can enter any additional information about the nominator.
* **Nominator Agreement**: A select-one field to confirm that the information provided is accurate.
* **Event Planner Name**: The name of the event planner.
* **Event Planner Email**: The email address of the event planner.
* **Event Planner Phone**: The phone number of the event planner.
* **Additional Info**: A text area where you can enter any additional information about the event planner.
* **Nominator Agreement**: A select-one field to confirm that the information provided is accurate.

## Tips

* Make sure to fill in all required fields.
* Review your submissions before submitting the form.
* Use the form for internal nomination and event planning purposes only.
