# Treasury Partnership Event Registration - Help Guide
## Purpose
This form is designed for users to register events related to treasury partnerships. Please fill out the form with the required information to ensure your event is properly recorded.

## How To Complete This Form
1. Scroll through the form, following the instructions for each page.
2. Enter your event title and description in the "Event Details" page.
3. Provide the necessary information for each attendee on the "Attendee Details" page.
4. Specify your session preferences on the "Session Preferences" page.
5. Select your preferred sessions on the "Session Choices" page.
6. Leave a comment or note on the "Note" page, if necessary.

## Field-by-Field Explanation

- **Event Details** (Event Details, text, required): Enter the title and brief description of your event related to a treasury partnership.
- **Attendee Details** (Attendee Details, text, required): Provide the names and affiliations of the attendees, if applicable.
- **Session Preferences** (Session Preferences, text, required): Specify your session interests or preferences. Please include any relevant information about your event schedule.
- **Session Choices** (Session Choices, select multiple, optional): Select one or more sessions from "Session A," "Session B," and "Session C." This is optional, and you can select all, some, or no sessions.
- **Note** (Note, note, optional): Leave a comment or note about your event, if needed. This field is for free-form text entry or comments.

## Tips
- Be sure to complete all required fields for a successful event registration.
- If you have any questions or concerns, please contact us at form@gic.mx.
