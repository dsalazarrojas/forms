# Sponsorship Approval Form - Help Guide

## Purpose
The Sponsorship Approval Form is a document used by event organizers to collect information from potential sponsors for events they are hosting. It helps them to assess the sponsor's agreement and status regarding their sponsorship.

## How To Complete This Form

To complete this form accurately, follow these steps:

1. Fill out the required fields with the relevant information.
2. Ensure that you have permission to complete the form on behalf of your organization or entity.
3. Review the form carefully before submission to avoid any errors.

## Field-by-Field Explanation

### Event Organizers
* **Event Organizers** (`event_organizer`, `text`, required): Enter the name of the event organizer or the company/organization hosting the event.

### Sponsor Name
* **Sponsor Name** (`sponsor_name`, `text`, required): Enter the name of the sponsor who will be providing the sponsorship.

### Sponsor Email
* **Sponsor Email** (`sponsor_email`, `email`, required): Enter the email address of the sponsor.

### Event Name
* **Event Name** (`event_name`, `text`, required): Enter a brief description or name of the event.

### Sponsorship Amount
* **Sponsorship Amount** (`sponsorship_amount`, `number`, required): Enter the amount of the sponsorship provided by the sponsor.

### Agreement Date
* **Agreement Date** (`agreement_date`, `date`, required): Enter the date when the agreement was made or accepted by both parties.

### Agreement Time
* **Agreement Time** (`agreement_time`, `time`, required): Enter the time of the agreement when it was made or accepted by both parties.

### Sponsor Phone
* **Sponsor Phone** (`sponsor_phone`, `text`, required): Enter the phone number of the sponsor.

### Sponsor Message
* **Sponsor Message** (`sponsor_message`, `note`, required): Enter a brief message or note from the sponsor.

### Sponsor Details
* **Sponsor Details** (`sponsor_details`, `note`, required): Enter any additional details about the sponsor.

### Event Details
* **Event Details** (`event_details`, `note`, required): Enter a brief description or details about the event.

### Event Location
* **Event Location** (`event_location`, `text`, required): Enter the location of the event.

### Event Start Time
* **Event Start Time** (`event_start_time`, `time`, required): Enter the start time of the event.

### Event Start Date
* **Event Start Date** (`event_start_date`, `date`, required): Enter the start date of the event.

### Event End Time
* **Event End Time** (`event_end_time`, `time`, required): Enter the end time of the event.

### Event End Date
* **Event End Date** (`event_end_date`, `date`, required): Enter the end date of the event.

### Event Duration
* **Event Duration** (`event_duration`, `text`, required): Enter the duration of the event.

### Sponsor Notes
* **Sponsor Notes** (`sponsor_notes`, `note`, required): Enter any notes or additional comments from the sponsor.

### Notes to Sponsor
* **Notes to Sponsor** (`notes_to_sponsor`, `note`, required): Enter any notes or comments to be communicated to the sponsor.

### Sponsor Agreement
* **Sponsor Agreement** (`sponsor_agreement`, `select_multiple`, required): Select if the sponsor has agreed to the terms.

### Sponsor Status
* **Sponsor Status** (`sponsor_status`, `select_one`, required): Select the sponsor's status as Active, Inactive, or Pending.

### Event Status
* **Event Status** (`event_status`, `select_one`, required): Select the event's status as Active, Inactive, or Pending.

### Event Type
* **Event Type** (`event_type`, `select_one`, required): Select the type of event as Event, Webinar, or Workshop.

### Event Venue
* **Event Venue** (`event_venue`, `select_one`, required): Select if the event will be held online or in person.

### Event Currency
* **Event Currency** (`event_currency`, `select_one`, required): Select the currency of the event sponsorship.

## Tips
* Make sure to fill out the form accurately and completely to avoid any issues with the sponsor or event organizers.
* Review the form carefully before submission to ensure that all required fields are filled out correctly.
* If you are unsure about any field, please contact the event organizers or sponsor for clarification.
