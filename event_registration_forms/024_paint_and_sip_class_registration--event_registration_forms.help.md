# Paint And Sip Class Registration - Help Guide

## Purpose
The Paint And Sip Class Registration form is a tool for event organizers to collect information about upcoming art-themed events and their registration details.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the form carefully and accurately with your information.
2. Select the correct event type (Yes/No) to indicate if you are registering for the event.
3. Enter your start and end dates for the event.
4. Select your start and end times for the event.
5. Provide the location of the event.
6. Enter your contact name and contact email for any further communication.
7. Enter your contact phone number for any further communication.
8. Choose the payment gateway you would like to use for the event (Stripe, PayPal, or Bank Transfer).
9. If you would like to use a different payment gateway, select "Other" and enter the name of the custom payment gateway in the "other_payment_gateway" field.

## Field-by-Field Explanation

* **Paint And Sip Class Registration**: This field is a text field that allows you to enter any additional comments or notes about your registration.
* **event_type**: Select "Yes" if you are registering for the event, "No" otherwise.
* **start_date**: Enter the start date of the event.
* **end_date**: Enter the end date of the event.
* **start_time**: Select the start time of the event.
* **end_time**: Select the end time of the event.
* **location**: Enter the location of the event.
* **contact_name**: Enter your name for contact purposes.
* **contact_email**: Enter your email for contact purposes.
* **contact_phone**: Enter your phone number for contact purposes.
* **registration_date**: Enter the date of your registration.
* **registration_time**: Enter the time of your registration.
* **registration_fee**: Enter the fee you are willing to pay for the event.
* **payment_gateway**: Select the payment gateway you would like to use (Stripe, PayPal, or Bank Transfer).
* **payment_gateway_other**: Select "Other" if you would like to use a different payment gateway.
* **other_payment_gateway**: Enter the name of the custom payment gateway if you selected "Other" in the previous field.
* **note**: Enter any additional comments or notes about your registration.

Note: All fields marked as "required" are mandatory and must be filled out to complete the form.
