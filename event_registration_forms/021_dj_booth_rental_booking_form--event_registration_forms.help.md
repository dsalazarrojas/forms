# DJ Booth Rental Booking Form - Help Guide
## Purpose
The "DJ Booth Rental Booking Form" is a user-facing form designed to collect information from users interested in renting a DJ booth for an event. This form is not a real booking system, but rather a tool to gather necessary details for event organizers to facilitate the booking process.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the event name in the "event name" field.
2. Select the event date using the calendar picker or type in the date in the "event date" field.
3. Enter the event start time in the "event start time" field.
4. Fill in your first name and last name in the corresponding fields.
5. Enter your email address in the "email" field.
6. Provide your phone number in the "phone" field.
7. Select your preferred payment method from the dropdown list in the "payment method" field.
8. Enter the payment amount in the "payment amount" field.

## Field-by-Field Explanation
### Event Name
* **event_name** (event name, required: no): Enter the name of the event where you would like to rent a DJ booth for.

### Event Date
* **event_date** (event date, required: no): Select the date of the event using the calendar picker or type in the date in the format MM/DD/YY.

### Event Start Time
* **event_start_time** (event start time, required: no): Enter the start time of the event in 12-hour format (e.g., 08:00 AM).

### First Name
* **first_name** (first name, required: no): Enter your first name as it appears on your identification documents.

### Last Name
* **last_name** (last name, required: no): Enter your last name as it appears on your identification documents.

### Email
* **email** (email, required: no): Enter a valid email address that we can use to contact you.

### Phone
* **phone** (phone, required: no): Enter your phone number as it appears on your identification documents.

### Payment Method
* **payment_method** (payment method, required: no): Select your preferred payment method from the dropdown list: Stripe, PayPal, or Credit Card.

### Payment Amount
* **payment_amount** (payment amount, required: no): Enter the total payment amount for the booking.

## Tips

* Please ensure that you provide accurate and valid information in all fields.
* If you have any questions or concerns, do not hesitate to contact us.
* This form is not a real booking system, but rather a tool to gather necessary details for event organizers to facilitate the booking process.
