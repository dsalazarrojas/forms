# Tree Planting Event Photo Release Consent - Help Guide
## Purpose
The purpose of this form is to obtain the necessary permissions from event attendees to use their photos and videos for various purposes.

## How To Complete This Form
1. Review each field carefully and determine the correct options for each media type.
2. Fill out each field accurately and truthfully.
3. Read and agree to the terms and conditions stated.

## Field-by-Field Explanation
* **Photo Title** (`photo_title`, text, optional):
	+ This field is for the title of the photo.
* **Photo Date** (`photo_date`, date, optional):
	+ This field is for the date the photo was taken.
* **Photo Time** (`photo_time`, time, optional):
	+ This field is for the time the photo was taken.
* **Photo Location** (`photo_location`, text, optional):
	+ This field is for the location where the photo was taken.
* **Photo Media Type** (`photo_media_type`, select_one, optional):
	+ This field determines the type of photo or video media being released, such as Still Image or Video.
* **Photo Description** (`photo_description`, text, optional):
	+ This field is for a brief description of the photo.
* **Video Title** (`video_title`, text, optional):
	+ This field is for the title of the video.
* **Video Date** (`video_date`, date, optional):
	+ This field is for the date the video was taken.
* **Video Time** (`video_time`, time, optional):
	+ This field is for the time the video was taken.
* **Video Location** (`video_location`, text, optional):
	+ This field is for the location where the video was taken.
* **Photo Release** (`photo_release`, text, optional):
	+ This field is for the photo release statement.
* **Photo Credit** (`photo_credit`, text, optional):
	+ This field is for the name of the photographer or videographer.
* **Photo Credit Name** (`photo_credit_name`, text, optional):
	+ This field is for the name of the person credited in the photo.
* **Photo Credit Email** (`photo_credit_email`, email, optional):
	+ This field is for the email of the person credited in the photo.
* **Photo Credit Phone** (`photo_credit_phone`, text, optional):
	+ This field is for the phone number of the person credited in the photo.
* **Photo Credit Website** (`photo_credit_website`, text, optional):
	+ This field is for the website of the person credited in the photo.
* **Photo Credit Additional Info** (`photo_credit_additional_info`, text, optional):
	+ This field is for any additional information about the credit.
* **Photo Credit Agreement** (`photo_credit_agreement`, text, optional):
	+ This field is for any agreement or consent given by the credited person.
* **Photo Review** (`photo_review`, text, optional):
	+ This field is for any review or comment on the photo.
* **Photo Share** (`photo_share`, text, optional):
	+ This field is for specifying where the photo will be shared.
* **Photo Anonymous** (`photo_anonymous`, text, optional):
	+ This field is for stating if the photo is to be shared anonymously.
* **Photo Agreement** (`photo_agreement`, text, optional):
	+ This field is for any photo usage agreement.
* **Video Release** (`video_release`, text, optional):
	+ This field is for the video release statement.
* **Video Agreement** (`video_agreement`, text, optional):
	+ This field is for any video usage agreement.

## Tips
* Read each field carefully before filling it out.
* Make sure to fill out each field accurately and truthfully.
* Review the entire form before submitting.
