# Sweet 16 Event RSVP - Help Guide
## Purpose
This form is designed for event organizers to collect necessary information from attendees about events. It helps in tracking event registrations, RSVPs, and other event-related details.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the "Event Info" field with a brief description of the event.
2. Provide the "Guest Info" field with information about the guest(s) attending the event.
3. Optionally, provide your name if you're attending as a guest.
4. If you need to contact you, please provide your phone number.
5. Enter your email address for easy communication.
6. Add any event-specific details in the "Event Details" field (if required or necessary).
7. Select whether you're "Yes" or "No" to attending the event (multiple selections allowed).
8. Optionally, add comments about your RSVP status or any event-related comments.
9. Select the type of event (e.g., "Yes" or "No" for a specific event type).
10. Provide the event's date in the correct format (DD/MM/YYYY).
11. Select the event's time in the format (HH:MM AM/PM).
12. Enter the event's location.
13. If applicable, specify the event's time zone.
14. Add any event-specific notes.
15. Enter the number of guests attending the event.
16. Select your RSVP response ("Yes" or "No").
17. Optionally, add any RSVP-specific notes.
18. If you're the event organizer or have a role in organizing the event, fill in the "Event Organizer" fields with your contact information.
19. Finally, submit the form.
