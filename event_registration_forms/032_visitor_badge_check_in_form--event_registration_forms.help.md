# Visitor Badge Check In Form - Help Guide
## Purpose
This form is used to collect user information and event details for badge check-in purposes.

## How To Complete This Form
To complete this form, follow these steps:
1.  Select the "User Info" page and fill in your name, contact email, and contact phone number.
2.  Then, move to the "Event Info" page and enter the event name and date.
3.  Next, select the "Badge Info" page and enter the badge type, badge number, and notes if necessary.
4.  Finally, you may add any additional notes in the "Notes" section.

## Field-by-Field Explanation
* **User Info** (`text`, required: false):
	+ This field is for entering your name and contact information.
* **Event Info** (`text`, required: false):
	+ Enter the event name and date to provide context.
* **Badge Info** (`text`, required: false):
	+ Enter the badge type and number for accurate badge issuance.
* **Notes** (note, required: false):
	+ Add any additional information or notes regarding the visitor's visit.
