# Health Anxiety Workshop Registration Form - Help Guide
## Purpose
This form is used for registering participants to the Health Anxiety Workshop. It collects essential information about the participant's healthcare forms, description, recognition, workshop cycle, time, date, outro, and assigned tool.

## How To Complete This Form
To complete this form, follow these steps:
1. Select the applicable healthcare forms for the participant.
2. Provide a detailed description of the participant's health anxiety issue.
3. Choose the relevant recognition options (e.g., acknowledgment, recognition).
4. Select the event registration forms required for the workshop (if any).
5. Select the cycle of the health anxiety habit (if applicable).
6. Choose the time and date of the workshop.
7. Provide a note for the outro of the workshop (if necessary).
8. Optionally, select additional event registration forms.

## Field-by-Field Explanation
* **Registration Form**: This field is where you can enter any additional information about the participant.
* **Healthcare Forms**: Select the healthcare forms that apply to the participant. This will help us understand the participant's medical background.
* **Description**: Briefly describe the participant's health anxiety issue to help us better understand their needs.
* **Recognition**: Choose the recognition type (e.g., acknowledgment, recognition, awareness) that the participant is looking for.
* **Cycle of the Health Anxiety habit**: Select the cycle of the health anxiety habit if it's relevant to the participant's issue.
* **Time of the Health Anxiety Workshop**: Choose the time slot for the workshop.
* **Date of the Health Anxiety Workshop**: Select the date of the workshop.
* **Outro of the Workshop**: Provide a note for the outro of the workshop (if necessary).
* **Event Registration Forms**: Select additional event registration forms required for the workshop (if any).
* **Assigned Tool**: Enter any specific tool assigned to the participant, if applicable.
