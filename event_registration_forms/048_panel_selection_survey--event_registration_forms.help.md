# Panel Selection Survey - Help Guide
## Purpose
The Panel Selection Survey form is designed to help you select a panel of speakers or organizers for an event or conference. This form will guide you through the selection process, ensuring that you gather all the necessary information.

## How To Complete This Form
To complete this form, follow these steps:

1. Choose the Event Organizer from the drop-down list.
2. Select the speaker applications for each speaker.
3. Set the Start and End Dates for the panel session.
4. Enter the Speaker Name, Speaker Email, and Speaker Phone number for each speaker.
5. Enter a brief description of the panel, topic, and speaker bios for each speaker.

## Field-by-Field Explanation
* **Event Organizer 1**: Select the event organizer from the drop-down list.
* **Speaker 1 Application**: Select all applications for Speaker 1.
* **Start Date**: Enter the start date of the panel session (format: YYYY-MM-DD).
* **End Date**: Enter the end date of the panel session (format: YYYY-MM-DD).
* **Speaker Name 1**: Enter the name of Speaker 1.
* **Speaker Email 1**: Enter the email address of Speaker 1.
* **Speaker Phone 1**: Enter the phone number of Speaker 1.
* **Speaker Name 2**: Enter the name of Speaker 2.
* **Speaker Email 2**: Enter the email address of Speaker 2.
* **Speaker Phone 2**: Enter the phone number of Speaker 2.
* **Speaker Name 3**: Enter the name of Speaker 3.
* **Speaker Email 3**: Enter the email address of Speaker 3.
* **Speaker Phone 3**: Enter the phone number of Speaker 3.
* **Speaker Name 4**: Enter the name of Speaker 4.
* **Speaker Email 4**: Enter the email address of Speaker 4.
* **Speaker Phone 4**: Enter the phone number of Speaker 4.
* **Speaker Name 5**: Enter the name of Speaker 5.
* **Speaker Name 6**: Enter the name of Speaker 6.
* **Speaker Bio 1**: Enter a brief bio for Speaker 1.
* **Speaker Bio 2**: Enter a brief bio for Speaker 2.
* **Speaker Bio 3**: Enter a brief bio for Speaker 3.
* **Speaker Bio 4**: Enter a brief bio for Speaker 4.
* **Speaker Bio 5**: Enter a brief bio for Speaker 5.
* **Panel Description**: Enter a brief description of the panel.
* **Panel Topic**: Select the topic of the panel from the drop-down list.
* **Speaker Bio 6**: Enter a brief bio for Speaker 6.
* **Availability**: Enter the availability of the panel (format: YYYY-MM-DD).

## Tips
* Double-check all fields for accuracy before submitting the form.
* Ensure that all speaker information is up-to-date and complete.
* If a speaker is not listed, please add them to the system first.
