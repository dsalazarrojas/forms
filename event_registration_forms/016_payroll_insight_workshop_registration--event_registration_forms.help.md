# Payroll Insight Workshop Registration - Help Guide

## Purpose
This form is for registering for the Payroll Insight Workshop. The form will be used to collect attendee information for the workshop.

## How To Complete This Form
To complete this form, please follow these steps:

1. Select the sessions you would like to attend by choosing from the options provided.
2. Enter your personal information, including your first and last name.
3. Provide your email address and phone number so that we can contact you with further instructions.
4. Enter the date of the event, if applicable.
5. Review and submit your form.

## Field-by-Field Explanation

* **Select Sessions** (`session_selection`, select_multiple, required: false): Select the sessions you would like to attend by choosing from the options provided. You can select multiple sessions if you wish.
* **Session 1** (`session_1`, text, required: false): Enter Session 1 information if you have selected to attend Session 1.
* **Session 2** (`session_2`, select_one, required: false): Select whether or not you will attend Session 2.
* **First Name** (`first_name`, text, required: false): Enter your first name.
* **Last Name** (`last_name`, text, required: false): Enter your last name.
* **Email** (`email`, email, required: false): Enter a valid email address so that we can contact you with further instructions.
* **Phone** (`phone`, text, required: false): Enter your phone number so that we can contact you with further instructions.
* **Event Date** (`event_date`, date, required: false): Enter the date of the event, if applicable.
