# Recyclable Booth Construction Application Form - Help Guide
## Purpose
The Recyclable Booth Construction Application Form is used to collect information for an event registration application for a recyclable booth construction event.

## How To Complete This Form
1. Fill out the Event Registration Form (Page 1) with your event details.
2. Provide your contact information in the Contact Information section.
3. Review and confirm the event details in the Event Confirmation section.
4. Upload any relevant files or attachments in the File section.
5. Submit the completed form to complete the application process.

## Field-by-Field Explanation

* **Event Registration Form (Page 1)**: This section includes fields for event location, event type, and event description.
	+ **Event Location**: Select the correct location for your event from the options provided. This will help us confirm the event location.
	+ **Event Type**: Choose the type of event from the options provided. This will help us determine the event's requirements and logistics.
	+ **Event Description**: Provide a brief description of the event, including any specific details or requirements.
* **Event Details**: This section includes fields for event date, event time, and booth designs.
	+ **Event Date**: Enter the date of your event in the date format (e.g., MM/DD/YYYY).
	+ **Event Time**: Enter the time of your event in the time format (e.g., 12:00 PM).
	+ **Booth Designs**: Indicate whether you have booth designs or not.
* **Contact Information**: This section includes fields for contact person, contact email, contact phone, and event organizer information.
	+ **Contact Person**: Provide the name of the person responsible for the event.
	+ **Contact Email**: Enter the email address of the contact person.
	+ **Contact Phone**: Enter the phone number of the contact person.
	+ **Event Organizer**: Provide the name of the event organizer.
	+ **Event Organizer Email**: Enter the email address of the event organizer.
	+ **Event Organizer Phone**: Enter the phone number of the event organizer.
* **Event Confirmation**: This section includes fields to confirm the event details.
	+ **Confirm Event Location**: Indicate whether you are confirming the event location.
	+ **Confirm Event Type**: Indicate whether you are confirming the event type.
	+ **Confirm Event Date**: Indicate whether you are confirming the event date.
* **Booth Requirements**: This section includes fields for booth requirements.
	+ **Booth Size**: Enter the size of the booth.
	+ **Booth Materials**: Describe the materials you plan to use for the booth.
* **Booth Setup and Takedown Times**: This section includes fields for booth setup and takedown times.
	+ **Booth Setup Time**: Enter the estimated time to set up the booth.
	+ **Booth Takedown Time**: Enter the estimated time to take down the booth.
* **Special Requests**: This section includes a field for any special requests.
	+ **Special Requests**: Provide any special requests or requirements for the event.
* **Event Notes**: This section includes a field for event notes.
	+ **Event Notes**: Provide any additional information about the event.
* **File**: This section includes a field for uploading files.
	+ **File**: Upload any relevant files or attachments for the event.
