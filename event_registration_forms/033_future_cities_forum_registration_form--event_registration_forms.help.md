# Future Cities Forum Registration Form - Help Guide
## Purpose
This form is designed to gather information from attendees for event planning purposes.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill out the form accurately and completely.
2. Ensure that all required fields are filled out.

## Field-by-Field Explanation

* **Registration Date** (`registration_date`, date, false): This field is not required, but it is recommended to fill out if you know the date you will be attending the event.
* **Attendee Name** (`attendee_name`, text, false): Please enter your name as it appears on official documents.
* **Email** (`email`, email, false): Please enter your email address to facilitate communication with event organizers.
* **Phone** (`phone`, text, false): This field is intended for you to enter a phone number where you can be reached.
* **Registration Time** (`registration_time`, time, false): If you have already registered for the event, this field is not relevant.
* **Event Details** (`event_details`, note, false): Use this field to provide any additional information about your attendance or preferences.
* **Event Preferences** (`preferences`, select_one, false): Please select "Yes" if you have any special requests or needs, and "No" if you do not.
* **Registration Method** (`registration_method`, select_multiple, true): Please select the method by which you are registering for the event (e.g., online, in-person, etc.).
* **Event Attendee Type** (`event_attendee_type`, select_multiple, true): Please select the type of attendee you are registering as (e.g., speaker, sponsor, etc.).
* **Attendee Type** (`attendee_type`, select_one, true): Please select the type of attendee you are registering as (e.g., individual, organization, etc.).
* **Additional Comments** (`additional_comments`, text, false): Use this field to provide any additional information you feel is relevant to your attendance.
* **Assigned Tool** (`assigned_tool`, text, false): This field is not currently used.
* **Output File** (`output_file`, text, false): This field is not currently used.
* **Form ID** (`form_id`, text, false): This field is not currently used, but may be used for tracking purposes.
