# Virtual Event Abstract Submission Form - Help Guide

## Purpose
The Virtual Event Abstract Submission Form is designed to collect necessary information from speakers and organizers for virtual events. This form helps to streamline the submission process and ensures that all required information is provided.

## How To Complete This Form
1. Please fill out the form with accurate and up-to-date information.
2. Make sure to complete all required fields to ensure successful submission.
3. Review your submission before finalizing it.

## Field-by-Field Explanation

* **Event Submission**: This field is the main submission text for the event. Please provide a concise and clear abstract of your presentation. (~250-300 words)
* **Speaker Name**: This field is for the name of the speaker. Please ensure it matches the name you use in your professional communications.
* **Speaker Email**: This field is for the speaker's contact email. Please use a valid email address that the speaker checks regularly.
* **Speaker Phone**: This field is for the speaker's phone number. This will help with follow-up and scheduling.
* **Presentation Topic**: This field is for the topic of your presentation. Keep it concise and clear.
* **Presentation Abstract**: This field is for the detailed abstract of your presentation. Please use this space to provide more context about your topic.
* **Workshop Proposal**: This field is for any workshop-related proposals. If not applicable, please leave it blank.
* **Event Dates**: This field is for the dates of the event. If not applicable, please leave it blank.
* **Event Location**: This field is for the location of the event. If not applicable, please leave it blank.
* **Event Organizer**: This field is for the event organizer's information. If not applicable, please leave it blank.
* **Submission Confirmation**: Please confirm that your submission is accurate and complete.
* **Submission Date**: This field is for the date you submit your abstract. It will be filled in automatically.
* **Submission Time**: This field is for the time of submission. It will be filled in automatically.
* **Submission Time Zone**: This field is for the submission time zone. It will be filled in automatically.
* **Speaker Bio**: This field is for a brief bio of the speaker. Please keep it concise.
* **Submission Files 1-10**: These fields are for uploading submission files such as videos, presentations, and other supporting materials. Please select the correct file types and upload relevant files.

## Tips
* Review your submission before finalizing it to ensure accuracy and completeness.
* Use a valid email address and phone number for communication.
* Keep submission files relevant and up-to-date.
