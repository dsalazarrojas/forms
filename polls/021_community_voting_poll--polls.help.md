# Community Voting Poll - Help Guide
## Purpose
The Community Voting Poll form is designed to gather opinions and votes from community members on a specific topic. This form is a tool for collecting feedback and understanding the views of the community on a particular issue or decision.

## How To Complete This Form
To complete the form, follow these steps:
1. Enter your **Participant name** in the "Participant name" field if you wish to be identified as a public participant or leave it empty if you prefer to vote anonymously (optional).
2. Enter your **Participant email address** if you want to be contacted for verification or confirmation purposes (optional).
3. Provide a short **Poll topic description** in the text field. This should briefly describe the issue or topic being voted on.
4. Select one of the available **Voting choices** from the dropdown menu, such as "Option A", "Option B", or "Option C".
5. If you have additional comments or feedback on your vote, you can provide them in the **Additional comments** field (optional).

## Field-by-Field Explanation
- **Participant name**: Enter your name to be identified as a public participant or leave it empty for an anonymous vote.
  - Type: Text
  - Required: Optional
  - Hint: Optional for public ballots

- **Participant email**: Enter your email address for verification or confirmation purposes.
  - Type: Email
  - Required: Optional
  - Hint: For verification if needed

- **Poll topic**: Enter a brief description of the issue being voted on.
  - Type: Text
  - Required: True

- **Voting choices**: Select one option from the dropdown menu.
  - Type: Select One
  - Required: True
  - Options: Option A, Option B, Option C, Abstain

- **Additional comments**: Provide any additional feedback or comments on your vote.
  - Type: Text
  - Required: Optional
  - Hint: Optional feedback on your vote

## Tips
- Make sure to enter a valid email address if you want to be contacted for verification or confirmation.
- Choose only one voting option from the dropdown menu.
- If you want to provide additional feedback, use the "Additional comments" field.
