# workshop_session_quality_poll - Help Guide
## Purpose
The workshop session quality poll is a feedback form designed to gather opinions from workshop attendees on the quality of the session they attended. The goal is to collect constructive feedback to improve future workshop sessions.

## How To Complete This Form
To complete this form, follow these steps:

1. Please select the "Overall Quality" rating by choosing a number between 1 (poor) and 10 (excellent).
2. Answer "Yes" or "No" to questions about what could be improved and what aspects of the session improved.
3. Provide any comments or suggestions in the "Suggestions" text field.
4. Add any comments or feedback in the "Comments" text field.
5. Rate the session's overall quality and submit your feedback.

## Field-by-Field Explanation
* **Introduction**: A brief summary of your experience with the session.
	+ Type: Note (optional)
* **Overall Quality**: Rate the session's overall quality, with 1 being poor and 10 being excellent.
	+ Type: Number (optional)
* **Session Quality**: Choose "Yes" if you thought the session was well-structured and engaging. If not, select "No".
	+ Type: Number (optional)
* **What Improves**: Choose "Yes" if you noticed improvements in the session, otherwise "No".
	+ Type: Select Multiple (optional)
* **What Improves To**: If you chose "Yes", select what specifically improved.
	+ Type: Select One (optional)
* **What Improves By**: If you chose "Yes", select what specifically improved.
	+ Type: Select One (optional)
* **Suggestions**: Provide any suggestions on how to improve future sessions.
	+ Type: Text (optional)
* **Comments**: Share any additional comments or feedback.
	+ Type: Text (optional)
* **Rating**: Rate the session's overall quality, with 1 being poor and 10 being excellent.
	+ Type: Number (optional)
* **Submission**: This is the submission field, where you can write any final comments or feedback.
	+ Type: Note (optional)
