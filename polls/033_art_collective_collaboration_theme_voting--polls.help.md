# Art Collective Collaboration Theme Voting - Help Guide
## Purpose
The Art Collective Collaboration Theme Voting form is designed to collect information from users about their preferences and interests regarding various themes within an art collective context. It's used to gauge users' interests in different theme options and their willingness to participate in the collaboration process.

## How To Complete This Form
1. Fill out the required fields (Member Name, Email Address, Voting Date, Theme 1 Name, Theme 2 Name, Theme 3 Name, Top Choice, and Interest in Participation) completely.
2. For each theme, fill out the corresponding fields (Theme 1 Description, Theme 1 Interest, Theme 2 Description, Theme 2 Interest, Theme 3 Description, and Theme 3 Interest).
3. Select the correct vote for each theme by choosing 'True' or 'False' for the corresponding fields.
4. Choose your top choice from the given theme options.
5. Provide any additional feedback or suggestions in the collaboration ideas section.
6. Select your interest in participating in this collaboration process.

## Field-by-Field Explanation

* **Member Name** (`voter_name`, required): Please enter your name as a member of the art collective.
* **Email Address** (`voter_email`, required): Enter your email address for identification purposes.
* **Member Since** (`member_since`, optional): If you'd like to specify when you've joined the art collective.
* **Voting Date** (`voting_date`, required): Select the date for which you're casting your vote.
* **Theme 1 Name** (`theme_1_name`, required): Enter the name of the first theme you'd like to vote on.
* **Theme 1 Description** (`theme_1_description`, optional): Provide a brief description of the first theme you've chosen.
* **Interest in Theme 1** (`theme_1_interest`, required): Choose how interested you are in the first theme:
	+ Very interested
	+ Interested
	+ Neutral
	+ Less interested
	+ Not interested
* **Vote for Theme 1** (`theme_1_vote`, required): Select whether you're voting for or against the first theme.
* **Theme 2 Name** (`theme_2_name`, required): Enter the name of the second theme you'd like to vote on.
* **Theme 2 Description** (`theme_2_description`, optional): Provide a brief description of the second theme you've chosen.
* **Interest in Theme 2** (`theme_2_interest`, required): Choose how interested you are in the second theme:
	+ Very interested
	+ Interested
	+ Neutral
	+ Less interested
	+ Not interested
* **Vote for Theme 2** (`theme_2_vote`, required): Select whether you're voting for or against the second theme.
* **Theme 3 Name** (`theme_3_name`, required): Enter the name of the third theme you'd like to vote on.
* **Theme 3 Description** (`theme_3_description`, optional): Provide a brief description of the third theme you've chosen.
* **Interest in Theme 3** (`theme_3_interest`, required): Choose how interested you are in the third theme:
	+ Very interested
	+ Interested
	+ Neutral
	+ Less interested
	+ Not interested
* **Vote for Theme 3** (`theme_3_vote`, required): Select whether you're voting for or against the third theme.
* **Top Choice** (`top_choice`, required): Choose your top theme from the given options:
	+ Theme 1
	+ Theme 2
	+ Theme 3
	+ No preference
* **Collaboration Ideas or Suggestions** (`collaboration_ideas`, optional): Provide any additional ideas or suggestions for the collaboration process.
* **Interest in Participating** (`participation_interest`, required): Choose your level of interest in participating in this collaboration:
	+ Very interested
	+ Interested
	+ Maybe
	+ Not interested

Note: This guide is based on the provided YAML fields and the assumption that the form is intended to be a voting system for themes within an art collective context.
