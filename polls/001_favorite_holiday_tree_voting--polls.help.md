# Favorite Holiday Tree Voting - Help Guide
## Purpose
The purpose of this form is to collect votes from users on their favorite holiday trees.

## How To Complete This Form
To complete this form, follow these steps:

1. Make sure you are eligible to participate by answering "Yes" to the "Are you eligible?" question.
2. Select "I am human" as the captcha response to prove you are not a robot.
3. Browse the list of trees and select the ones you like the most.
4. You can select multiple trees if you want.
5. If you want to, provide any additional comments in the text field.
