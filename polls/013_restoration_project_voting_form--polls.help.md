# Restoration Project Voting Form - Help Guide
## Purpose
This form is designed to gather feedback and ratings from users on a restoration project. The project aims to improve and evaluate projects based on user input. Please take a few minutes to fill out this form and provide your honest opinion.

## How To Complete This Form
To complete this form, simply follow these steps:

1. Fill out each field according to your thoughts and opinions on the restoration project.
2. Make sure to fill out all required fields (marked as "required") to ensure your feedback is submitted correctly.
3. Review your answers before submitting the form to ensure everything is accurate.

## Field-by-Field Explanation
- **What is the project title**: This is the title of the restoration project you are providing feedback on.
  - Type: text
  - Purpose: Enter a brief title of the project
  - Required: false
- **What is the project description**: This is a brief description of the project.
  - Type: text
  - Purpose: Enter a short description of the project
  - Required: false
- **Select initiatives**: Choose the initiatives that apply to the project.
  - Type: select_multiple
  - Purpose: Choose all applicable initiatives
  - Required: false
- **Init 1**: Choose the first initiative for the project.
  - Type: select_one
  - Purpose: Select one initiative for the project
  - Required: false
- **Init 2**: Choose the second initiative for the project.
  - Type: select_one
  - Purpose: Select one initiative for the project
  - Required: false
- **What is your rating**: This is your rating of the project.
  - Type: number
  - Purpose: Enter your rating of the project
  - Required: false
- **Rating 1**: Choose your rating for the project.
  - Type: select_one
  - Purpose: Select your rating for the project
  - Required: false
- **What are your comments**: This is an optional field for any additional comments you'd like to add.
  - Type: text
  - Purpose: Enter any additional comments or thoughts about the project
  - Required: false
- **Email address**: Enter your email address for project updates or follow-up.
  - Type: email
  - Purpose: Enter your email address for updates and follow-up
  - Required: false
- **Phone number**: Enter your phone number for project updates or follow-up.
  - Type: text
  - Purpose: Enter your phone number for updates and follow-up
  - Required: false
- **Date**: Enter the date you are submitting this form.
  - Type: date
  - Purpose: Enter the date you are submitting this form
  - Required: false
- **Time**: Enter the time you are submitting this form.
  - Type: time
  - Purpose: Enter the time you are submitting this form
  - Required: false
- **Additional notes**: Add any additional notes about the project.
  - Type: note
  - Purpose: Enter any additional notes or thoughts about the project
  - Required: false
