# Learning Model Selection Form - Help Guide

## Purpose
The Learning Model Selection Form is used to create or manage learning resources such as lessons, curricula, or assessments in educational settings.

## How To Complete This Form
To complete this form, follow the steps below:

1. Select the relevant information from the options provided in each field.
2. Review the form thoroughly before submission.

## Field-by-Field Explanation
* **School Year Selection** (`school_year_selection`, `select_one`, required: false): This field allows you to select the school year that the learning model is associated with. Choose the relevant option from the dropdown menu.
* **Teacher** (`teacher`, `select_one`, required: false): This field is for selecting the teacher who is creating or managing the learning model.
* **Student** (`student`, `select_one`, required: false): This field is for selecting the student who the learning model is related to.
* **Learning Path** (`learning_path_selection`, `select_multiple`, required: false): In this field, select all relevant learning paths that the learning model is associated with.
* **Subject** (`subject`, `text`, required: false): Enter the education subject related to the learning model.
* **Level** (`level`, `select_one`, required: false): Choose the level of education that the learning model is relevant to.
* **Class** (`class`, `select_one`, required: false): Select the class that the learning model is associated with.
* **Start Date** (`start_date`, `date`, required: false): Enter the start date of the learning model. This field is typically used for events that have a start date.
* **End Date** (`end_date`, `date`, required: false): Enter the end date of the learning model. This field is typically used for events that have an end date.
* **Start Time** (`start_time`, `time`, required: false): Select the start time of the learning model.
* **End Time** (`end_time`, `time`, required: false): Select the end time of the learning model.
* **Note** (`note`, `note`, required: false): Use this field to add any additional notes or comments related to the learning model.
* **Email** (`email`, `email`, required: false): Enter the email address of the person responsible for the learning model.
* **Phone** (`phone`, `text`, required: false): Enter the phone number of the person responsible for the learning model.
* **Category** (`category`, `select_one`, required: false): Select the category that the learning model belongs to.
* **Description** (`description`, `text`, required: false): Enter a detailed description of the learning model.
* **Assigned Tool** (`assigned_tool`, `select_one`, required: false): Select the tool assigned to the learning model.
* **Output File** (`output_file`, `select_one`, required: false): Select the output file associated with the learning model.

## Tips
* Ensure that you are in the correct context for this form, such as a teacher or administrator.
* Review the form thoroughly before submission to prevent errors.
* Use the available fields to provide complete and accurate information for the learning model.
