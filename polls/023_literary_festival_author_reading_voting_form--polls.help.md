# Literary Festival Author Reading Voting Form - Help Guide
## Purpose
This form is designed to collect feedback and ratings from festival attendees on their experience with author readings at the literary festival.

## How To Complete This Form
1. Fill out all required fields with your information:
	* First name
	* Last name (if applicable)
	* Email address
	* Rating of the author reading
	* Additional feedback
2. Select optional fields as per your preference:
	* Phone number
	* Select one option from multiple choices
	* Select multiple options from multiple choices
	* Date of the event
	* Time of the event

## Field-by-Field Explanation
* **First Name**: Enter your first name as it is known to you.
* **Last Name**: Enter your last name as it is known to you (if applicable).
* **Email**: Enter your email address to receive feedback and follow-up information.
* **Rate the Author Reading**: Select one of the options to rate your experience with the author reading:
	+ Option 1
	+ Option 2
	+ Option 3
	+ Option 4
	+ Option 5
* **Additional Feedback**: Type in any additional comments or thoughts you have about the author reading.
* **Phone**: Enter your phone number if you would like to receive follow-up information (optional).
* **Select One**: Select one option from the list:
	+ Option 1
	+ Option 2
	+ Option 3
* **Select Multiple**: Select multiple options from the list:
	+ Option 1
	+ Option 2
	+ Option 3
* **Date**: Enter the date of the event (optional).
* **Time**: Enter the time of the event (optional).
* **Select Multiple Two**: Select multiple options from the list:
	+ Yes
	+ No

## Tips
* Please fill out all required fields to ensure your feedback is included in the analysis.
* Use the optional fields to provide additional information if you have a specific opinion or comment about the author reading.
