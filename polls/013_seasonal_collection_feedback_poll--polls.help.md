# Seasonal Collection Feedback Poll - Help Guide
## Purpose
This form is designed to collect feedback on the latest seasonal collection. Your input will help us understand what worked well and what could be improved in the next collection.

## How To Complete This Form
To provide effective feedback, please fill out the form in a sequential and honest manner. Start by selecting the correct season and answer each question according to your experience with the seasonal collection. If you have any additional feedback or questions, please provide it in the text box provided for that purpose.

## Field-by-Field Explanation

* **How did we do?** (<label>): This field is a text box where you can describe your overall impression of the seasonal collection.
* **What was the most interesting item in the latest collection?** (<label>):
	+ Select "Yes" if you found an item particularly intriguing or appealing.
	+ Select "No" if none of the items caught your attention.
* **What season is the collection from?** (<label>): Choose the correct season that the collection is related to.
* **Would you consider purchasing a seasonal collection like this again?** (<label>):
	+ Select "True" if you would be interested in purchasing a similar collection.
	+ Select "False" if you are not interested.
* **What price would be too high for this collection?** (<label>): If you have a number in mind, enter it here. Please note that this field is optional.
* **Any additional feedback?** (<label>): If you have any other thoughts or comments about the collection, please type them here.
* **Your email** (<label>): Enter your email address so we can follow up with you if needed.
* **Your name** (<label>): Provide your name so we can identify you and address your feedback.
* **When did you visit?** (<label>): Select the date you visited the collection.
* **At what time did you visit?** (<label>): Select the time you visited the collection.

Note: All fields marked as required are necessary for us to gather accurate feedback, so please make sure to fill them out carefully.
