# Youth Smartphone Feature Poll - Help Guide
## Purpose
This form is used to collect opinions or preferences from a youth smartphone user base.

## How To Complete This Form

1. Click on this form to start the process.
2. Fill in your age.
3. Answer the relationship status question by selecting one or both options.
4. Answer the smartphone brand question by selecting one option.
5. Answer the operating system question by selecting one option.
6. Answer the smartphone model question by selecting one option.
7. For each of the feature priority questions, select the features that are most important to you.
