# Scheduling Poll - Help Guide
## Purpose
The Scheduling Poll form is used to schedule meetings and events with attendees and send reminders to specific senders.

## How To Complete This Form
To complete this form, follow these steps:
1. Select the "Schedule Meeting" option from the first field.
2. Choose the start date and start time for the meeting from the respective fields.
3. Enter the location of the meeting.
4. Select the end date and end time of the meeting.
5. Add a description of the meeting.
6. Choose who to include as attendees.
7. Determine if you want to repeat the meeting.
8. Select the timezone for the meeting.
9. Set up reminders for the meeting, including the frequency and send method.
10. Choose specific senders to send reminders to.

## Field-by-Field Explanation
* **Schedule Meeting** (`schedule_poll_1`, `select_multiple`, required): Choose the type of meeting you are scheduling (e.g., meeting, conference, etc.).
* **Start Date** (`start_date_2`, `date`, required): Enter the date of the meeting.
* **Start Time** (`start_time_2`, `time`, required): Enter the start time of the meeting.
* **Location** (`location_2`, `text`, required): Enter the location of the meeting.
* **End Date** (`end_date_2`, `date`, required): Enter the end date of the meeting.
* **End Time** (`end_time_2`, `time`, required): Enter the end time of the meeting.
* **Description** (`description_2`, `text`, required): Enter a brief description of the meeting.
* **Attendees** (`attendees_2`, `select_multiple`, required): Choose who to include as attendees.
* **Repeat** (`repeat_2`, `select_one`, required): Determine if you want to repeat the meeting.
* **Timezone** (`timezone_2`, `select_one`, required): Select the timezone for the meeting.
* **Reminders** (`reminders_2`, `select_multiple`, required): Set up reminders for the meeting.
* **Reminder Frequency** (`reminder_frequency_2`, `select_multiple`, required): Choose the frequency of reminders.
* **Reminder Send Method** (`reminder_send_method_2`, `select_multiple`, required): Select the method to send reminders.
* **Poll Reminder Senders** (`poll_reminder_senders_2`, `select_multiple`, required): Choose specific senders to send reminders to.
* **Poll Reminder Body** (`poll_reminder_body_1`, `text`, required): Enter the content of the reminder.
* **Poll Reminder Senders 3** (`poll_reminder_sender_1`, `select_one`, required): Select the sender for the reminder.
* **Poll Reminder Sender 2** (`poll_reminder_sender_2`, `select_one`, required): Select the sender for the reminder.
* **Poll Reminder Sender 3** (`poll_reminder_sender_3`, `select_one`, required): Select the sender for the reminder.
* **Poll Reminder Sender 4** (`poll_reminder_sender_4`, `select_one`, required): Select the sender for the reminder.
