# Top Fail Voting Survey - Help Guide
## Purpose
This form is designed to collect information about common failures or shortcomings in a particular area or organization. It is meant to help identify and rate these failures, providing a better understanding of areas that need improvement.

## How To Complete This Form
To complete this form, follow these steps:

1. **Top Fail**: Provide a brief description of a failure or shortcoming.
2. **Severity Rating**: Rate the severity of the failure on a scale from 1 to n (if n is specified, otherwise, it is an open-ended rating).
3. **Explanation**: Provide a detailed explanation of the failure.
4. **Explanation 2**: Provide a second explanation of the failure, if necessary.
5. **Fail Type** (multiple fields): Categorize each failure as "Yes" or "No" to indicate whether it is present or not.

## Field-by-Field Explanation

* **Top Fail** (top_fail_voting_survey_form): A brief description of a failure or shortcoming. This field is not required.
* **Severity Rating** (severity_rating): Rate the severity of the failure on a scale from 1 to n. This field is not required.
* **Explanation** (explanation): Provide a detailed explanation of the failure. This field is not required.
* **Explanation 2** (explanation_2): Provide a second explanation of the failure, if necessary. This field is not required.
* **Fail Type** (fail_type): Categorize the failure as "Yes" or "No" to indicate whether it is present or not.
* **Fail Type 2** (fail_type_2): Categorize the second failure as "Yes" or "No" to indicate whether it is present or not.
* **Fail Type 3** (fail_type_3): Categorize the third failure as "Yes" or "No" to indicate whether it is present or not.
* **Fail Type 4** (fail_type_4): Categorize the fourth failure as "Yes" or "No" to indicate whether it is present or not.
* **Fail Type 5** (fail_type_5): Categorize the fifth failure as "Yes" or "No" to indicate whether it is present or not.

Tips:

* Please be as brief as possible when filling out the "Top Fail" field.
* You can rate the severity of the failure on a scale from 1 to n, if specified.
* You can provide as many explanations as necessary for each failure.
* Use "Yes" or "No" to categorize each failure type.
