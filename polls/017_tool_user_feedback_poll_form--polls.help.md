# Tool User Feedback Poll Form - Help Guide
## Purpose

This form is designed to collect your feedback about a tool you've interacted with. Your input is valuable and helps us improve and refine our tools for better user experience.

## How To Complete This Form

1. Please fill out the form completely and accurately.
2. Make sure to select the correct satisfaction level and improvement suggestion options.
3. Describe any issue you encountered in the "Issue Description" field.

## Field-by-Field Explanation

* **Product ID**: A unique identifier for the tool you're providing feedback on. If you're unsure, you can leave this field blank.
* **Name**: Your name or username associated with the tool account. This helps us understand which user account is submitting the feedback.
* **Email**: Your email address associated with the tool account. This field is optional but helps us contact you if we need more information.
* **Comments**: Any additional thoughts or comments you'd like to share about your experience with the tool.
* **Satisfaction Level**: Select one of the three levels of satisfaction:
	+ High: You're extremely satisfied with the tool.
	+ Medium: You're somewhat satisfied, but there's room for improvement.
	+ Low: You're not satisfied and would like to provide more feedback.
* **Issue Description**: Describe the specific issue you encountered with the tool. If no issue was found, please leave this field blank.
* **Improvement Suggestion**: Suggest ways we could improve the tool to better serve you. Be specific and detailed in your suggestions.
* **Assigned Tool**: Select which tool this feedback is about (ChatJ or Other).
* **Category**: You can add any additional category or tag to help us better understand your feedback.
* **Description**: A short description of your feedback.
* **Form ID**: A unique identifier for the form you're submitting. This is for internal use only.
* **Form Description**: A short description of the form you're submitting. This is for internal use only.
