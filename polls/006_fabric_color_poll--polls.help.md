# Fabric Color Poll - Help Guide
## Purpose
The Fabric Color Poll is a survey designed to gather your opinions and preferences on fabric colors. Your feedback will help us understand what you like and dislike about our fabric colors, and will inform our decisions on future product development.

## How To Complete This Form
To complete this form, please follow these steps:
1. Select your answer from the options provided for each question.
2. Be honest and thorough in your responses.
3. Review your answers carefully before submitting.

## Field-by-Field Explanation
* **fabric_color_poll_1_label** (`fabric_color_poll_1_name`, select_one, required: false): This question asks if you prefer a certain fabric color. Please select "Yes" if you like the color, and "No" if you don't.
* **fabric_color_preferences** (`fabric_color_preferences`, text, required: false): This is a free-text field where you can describe your fabric color preferences. Please be as descriptive as possible.
* **fabric_color_preferences_description** (`fabric_color_preferences_description`, note, required: false): This is an optional field where you can provide additional information about your fabric color preferences. It's a good place to elaborate on your answers to the previous question.
* **fabric_color_preferences_category** (`fabric_color_preferences_category`, select_multiple, required: false): Please select all that apply from the options provided.
* **fabric_color_preferences_subcategory** (`fabric_color_preferences_subcategory`, select_one, required: false): This question asks if you prefer a certain subcategory of fabric colors. Please select "Yes" if you like the subcategory, and "No" if you don't.
* **fabric_color_preferences_subcategory_description** (`fabric_color_preferences_subcategory_description`, time, required: false): This field is not used in this form, it's likely a placeholder for a future feature.
* **fabric_color_preferences_subcategory_category** (`fabric_color_preferences_subcategory_category`, select_multiple, required: false): Please select all that apply from the options provided.
* **fabric_color_preferences_subcategory_subcategory** (`fabric_color_preferences_subcategory_subcategory`, number, required: false): This question asks you to select a numerical value for this subcategory. Please enter a number between 1 and 10.
* **fabric_color_preferences_subcategory_subcategory_description** (`fabric_color_preferences_subcategory_subcategory_description`, text, required: false): This is a free-text field where you can describe your answer to the previous question in more detail.

## Tips
* Be honest and thorough in your responses.
* Only answer each question once.
* If you're unsure about a question, please ask for clarification before submitting.
