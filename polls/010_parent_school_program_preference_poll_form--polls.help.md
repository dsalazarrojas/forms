# parent_school_program_preference_poll_form - Help Guide
## Purpose
This form is used to collect preferences from parents about the school programs they are interested in for their children.

## How To Complete This Form
To complete this form, follow these steps:

* Answer the multiple-choice questions in Section 1, "School program preferences", by selecting all the options that apply to your interests.
* If you have any other programs in mind that are not listed, you can specify them in the "Other programs" field.
* If you have any additional comments, please provide them in the "Comments" field.
* If you would like to be contacted, please provide your Email and Phone number in the respective fields.

## Field-by-Field Explanation
* **School program preferences** (select_multiple, required: no): Select all the school programs that interest you by choosing each option.
* **School ID** (text, required: no): Enter a unique ID for the school program you are interested in (e.g., a name or a number).
* **Program Priority 1** (select_one, required: no): Choose one program that is a priority for you.
* **Program Priority 2** (select_one, required: no): Choose another program that is a priority for you.
* **Program Priority 3** (select_one, required: no): Choose a third program that is a priority for you.
* **Program Priority 4** (select_one, required: no): Choose a fourth program that is a priority for you.
* **Program Priority 5** (select_one, required: no): Choose a fifth program that is a priority for you.
* **Program Priority 6** (select_one, required: no): Choose a sixth program that is a priority for you.
* **Other programs** (text, required: no): If there are other programs you are interested in that are not listed, please specify them here.
* **Comments** (note, required: no): Provide any additional comments or thoughts about the school programs.
* **Email** (email, required: no): If you would like to be contacted, please provide your email address.
* **Phone** (text, required: no): If you would like to be contacted, please provide your phone number.
