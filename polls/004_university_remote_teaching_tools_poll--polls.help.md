# university_remote_teaching_tools_poll - Help Guide
## Purpose
The university_remote_teaching_tools_poll form is designed to collect input from users about their experiences and opinions regarding remote teaching tools.

## How To Complete This Form
To complete this form, simply follow the instructions below:

1. Answer each question to the best of your ability.
2. Fill out each field in the format provided.
3. Make sure to save your progress as you go, as there is no save feature.

## Field-by-Field Explanation
### 1. **Platform usage**
 (`platform_usage`, text, required/optional: false)
This field asks about the platforms used for remote teaching. Please provide a brief description of the platforms you use, such as "Zoom", "Microsoft Teams", "Google Meet", etc.

### 2. **What are your priority areas for improvement?**
 (`priority_areas`, select_one, required/optional: false)
Choose one of the options below that best answers the question:

* Yes: This area is a priority for improvement.
* No: This area is not a priority for improvement.

### 3. **Submission preferences**
 (`submission_preferences`, date, required/optional: false)
Please enter your preferred date for submission in the format MM/DD/YYYY.

### 4. **Teaching platforms used**
 (`teaching_platforms`, select_multiple, required/optional: false)
Select all the platforms you use for remote teaching:
* Yes: This platform is used.
* No: This platform is not used.

### 5. **Feedback**
 (`feedback`, note, required/optional: false)
Provide any additional comments, questions, or concerns you have about remote teaching tools.
 
## Tips
* Be honest and thorough in your answers.
* If you're unsure about any field, please ask for clarification.
* Please do not submit the same response more than once.
