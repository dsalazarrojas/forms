# public_art_installation_voting_form - Help Guide

## Purpose
The purpose of this form is to gather information and votes for public art installations. Users will be asked to provide details about the proposed installations, including their title, name, type, description, and image/video/audio URLs. The form will also collect votes on the installations, including dates, times, locations, and email addresses.

## How To Complete This Form
To complete this form, users will need to fill in all required fields accurately. Please ensure that you provide correct and clear information for each field.

## Field-by-Field Explanation
* **Proposed Installation**: 
  - **Proposed Installation Name**: The title of the proposed installation (text). <Required>
* **Proposed Installation Name**: The name of the proposed installation (text). <Required>
* **Installation Type**: The type of installation (select one: sculpture, installation, or other). <Required>
* **Installation Description**: A description of the proposed installation (text).
* **Why Vote for Installation**: Optional comments on why you vote for the installation (text).
* **Feedback**: Optional comments on the proposed installation (text).
* **Installation Vote**: Vote on whether or not to install the proposed installation (select multiple: True, False, or undecided). <Required>
* **Email**: The user's email address (text, required).
* **Phone**: Optional phone number (text).
* **Additional Comments**: Optional comments on the proposed installation (text).
* **Installation ID**: The ID of the proposed installation (text, required).
* **Installation Image**: Optional image URL of the proposed installation (text).
* **Installation Video**: Optional video URL of the proposed installation (text).
* **Installation Audio**: Optional audio URL of the proposed installation (text).
* **Installation Image URL**: Optional URL of the proposed installation image (text).
* **Installation Video URL**: Optional URL of the proposed installation video (text).
* **Installation Audio URL**: Optional URL of the proposed installation audio (text).
* **Installation Tags**: Optional tags for the proposed installation (text).
* **Installation Location**: Optional location of the proposed installation (text).
* **Installation Date**: The date of the installation (date, required).
* **Installation Time**: The time of the installation (time, required).
* **Installation Date Time**: The date and time of the installation (date, required).
* **Installation Start Time**: The start time of the installation (time, required).
* **Installation End Time**: The end time of the installation (time, required).
* **Installation Location Lat**: The latitude of the installation location (number, required).
* **Installation Location Long**: The longitude of the installation location (number, required).

## Tips
Please fill in all required fields accurately and carefully.
