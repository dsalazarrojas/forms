# Rotary Representative Election Survey - Help Guide
## Purpose
The Rotary Representative Election Survey is used to collect data on nominations and votes for the rotary representative election. The purpose of this form is to gather information from users to help in the election process.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the survey title and category.
2. Provide a brief description of the survey.
3. Choose one nomination from the options.
4. Choose multiple nominations from the options (if applicable).
5. Choose the candidate to vote for.
6. Input the vote weight (if applicable).
7. Input the submission date and time (if applicable).

## Field-by-Field Explanation
* **Survey Title** (`survey_title`, text, required): The title of the survey.
* **Category** (`category`, text, required): The category of the survey.
* **Description** (`description`, text, required): A brief description of the survey.
* **Nominations** (`nominations`, select_one, required): Choose one nomination from the options.
* **Nomination 2** (`nomination_2`, select_multiple, optional): Choose multiple nominations from the options (if applicable).
* **Vote For** (`vote_for`, select_one, required): Choose the candidate to vote for.
* **Vote Weight** (`vote_weight`, number, optional): Input the vote weight (if applicable).
* **Submission Date** (`submission_date`, date, optional): Input the submission date.
* **Submission Time** (`submission_time`, time, optional): Input the submission time (if applicable).

## Tips
* Make sure to fill in all required fields.
* If you are choosing multiple nominations, make sure to separate them with commas.
* If you are inputting a vote weight, make sure it is a number.
* If you are inputting a submission date and time, make sure to use the correct format (YYYY-MM-DD HH:MM:SS).
* If you have any questions or concerns, please contact the form administrators.
