# library_digital_media_interest_poll - Help Guide
## Purpose
This form is designed to gather user feedback on their usage and needs of digital media libraries in a library setting. The feedback gathered will help improve the services offered by the library.

## How To Complete This Form

1.  Select your answer to each question using the options provided.
2.  For text fields, please provide a brief description or comment.
3.  Make sure to answer all questions that apply to you.

## Field-by-Field Explanation

- **library digital media usage**: This question asks whether you have used digital media libraries.
  * Type: select\_multiple
  * Options: 'Yes', 'No'
  * This field determines whether you have used digital media libraries.
- **usage satisfaction**: This question asks for your satisfaction level with your experience with digital media libraries.
  * Type: text
  * This field allows you to provide a brief description of your satisfaction level.
- **future needs**: This question asks whether you need any new digital media libraries in the future.
