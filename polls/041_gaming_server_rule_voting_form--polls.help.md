# Gaming Server Rule Voting Form - Help Guide
## Purpose
The Gaming Server Rule Voting Form is designed to collect votes on rules for a gaming server. Server administrators use this form to gather data on the popularity of certain rules among server users and administrators.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the name of the server in the "Server Name" field.
2. Provide a brief description of the rule you are voting on in the "Rule Description" field.
3. Select the type of rule you are voting on from the "Rule Type" field.
4. Indicate how often you think the rule should be enforced by selecting from "Rule Frequency" options.
5. Vote on whether you think Option A should be enforced by selecting either "Yes" or "No" from the "Vote Option A" field.
6. Vote on whether you think Option B should be enforced by selecting either "Yes" or "No" from the "Vote Option B" field.
7. If you think the server should implement Option C, vote "Yes" or "No" in the "Vote Option C" field.
8. If you have any additional feedback, type it in the "Feedback" field.

## Field-by-Field Explanation
* **Server Name**: Enter the name of the server you are voting on. This field is not required.
* **Rule Description**: Provide a brief description of the rule you are voting on.
* **Rule Type**: Select the type of rule you are voting on from the options provided. Options include "Yes" and "No".
* **Rule Frequency**: Indicate how often you think the rule should be enforced. Options include "Yes" and "No".
* **Vote Option A**: Vote on whether you think Option A should be enforced. Select either "Yes" or "No".
* **Vote Option B**: Vote on whether you think Option B should be enforced. Select either "Yes" or "No".
* **Vote Option C**: Vote on whether you think Option C should be enforced. Select either "Yes" or "No".
* **Submit Vote**: You must submit your vote to complete the form. Select "Yes" to submit your vote.
* **Feedback**: If you have any additional feedback or suggestions, type them in this field. This field is not required.

Note: The "Submit Feedback" field is not required, but it is intended for server administrators to gather additional feedback or suggestions from users.
