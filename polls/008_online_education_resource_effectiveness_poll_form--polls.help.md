# Online Education Resource Effectiveness Poll Form - Help Guide
## Purpose
This form is used to gather feedback on the effectiveness of online education resources in polls. Please provide honest and clear feedback about your experience with the resources.

## How To Complete This Form
1. To start, fill in the **Online Education Resource Effectiveness Poll** title with a brief description of the resource you are providing feedback on.
2. Select the **Category** from the dropdown menu that best fits the resource you are providing feedback on.
3. In the **Description** field, add a brief description of the resource and your experience with it.
4. Enter the **Form ID** if you know it, which is a unique identifier for the resource.
5. In the **Assigned Tool** field, enter the tool used for the resource.
6. If applicable, provide the **Output File** if it's relevant to your feedback.
7. Finally, enter the **Output File Path** where the file can be located.

## Field-by-Field Explanation
* **Online Education Resource Effectiveness Poll** (form_title): Enter a brief description of the resource you are providing feedback on.
* **Category** (category): Choose the category that best fits the resource.
* **Description** (description): Add a brief description of the resource and your experience with it.
* **Form ID** (form_id): Enter the unique identifier for the resource, if known.
* **Assigned Tool** (assigned_tool): Enter the tool used for the resource.
* **Output File** (output_file): If applicable, provide the output file relevant to your feedback.
* **Output File Path** (output_file_path): Enter the location of the output file.
* **Category Name** (category_name): This field is not relevant to the form's purpose and should be ignored.
* **Form ID** (form_id): This field is not necessary but can be useful for tracking purposes.
* **Assigned Tool** (assigned_tool): Enter the tool used for the resource.
* **Output File** (output_file): If applicable, provide the output file relevant to your feedback.
* **Output File Path** (output_file_path): Enter the location of the output file.
