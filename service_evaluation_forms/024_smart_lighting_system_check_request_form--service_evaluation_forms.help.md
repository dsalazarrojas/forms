# Smart Lighting System Check Request Form - Help Guide
## Purpose
The purpose of this form is to collect information about a Smart Lighting System issue that needs to be addressed.

## How To Complete This Form

To complete this form, follow these steps:

*   Fill in your first name in the "First Name" field.
*   Enter your last name in the "Last Name" field.
*   Provide your email address in the "Email" field. This will be used for communication.
*   Enter your phone number in the "Phone" field. This is optional but recommended for follow-up calls.
*   Describe the issue you're experiencing with the "Describe Issue" field. This will help the support team understand the problem.
*   Select the type of Smart Lighting System that's causing the issue using the "System Type" dropdown menu.
*   Choose the location where the issue is happening from the "Location" dropdown menu.
*   Indicate the priority level of the issue using the "Priority" dropdown menu (High, Medium, or Low).
*   Select the preferred agent to be assigned to handle the issue from the "Assigned Agent" dropdown menu.

## Field-by-Field Explanation

*   **First Name** (`first_name`, `text`, required: false): This is your first name that will be used for identification purposes.
*   **Last Name** (`last_name`, `text`, required: false): This is your last name that will be used for identification purposes.
*   **Email** (`email`, `email`, required: false): Provide your email address to receive updates and communications about the issue.
*   **Phone** (`phone`, `text`, required: false): This is an optional field for you to enter your phone number. It's recommended for the support team to follow up with you.
*   **Describe Issue** (`issue_description`, `text`, required: false): This field is for a brief description of the Smart Lighting System issue you are experiencing.
*   **System Type** (`system_type`, `select_one`, required: false):
    +   If you're experiencing issues with your LED lighting system, choose "LED".
    +   If you're experiencing issues with your Halogen lighting system, choose "Halogen".
    +   If you're experiencing issues with your Fluorescent lighting system, choose "Fluorescent".
*   **Location** (`system_location`, `select_multiple`, required: false):
    +   If the issue is happening in the kitchen, choose "Kitchen".
    +   If the issue is happening in the bedroom, choose "Bedroom".
    +   If the issue is happening in the bathroom, choose "Bathroom".
    +   If the issue is happening in the living room, choose "Living Room".
    +   If the issue is happening in the hallway, choose "Hallway".
    +   If the issue is happening in an office, choose "Office".
*   **Priority** (`priority`, `select_one`, required: false):
    +   If the issue is urgent and needs immediate attention, choose "High".
    +   If the issue is moderately important, choose "Medium".
    +   If the issue is relatively minor, choose "Low".
*   **Assigned Agent** (`assigned_agent`, `select_one`, required: false):
    +   If you prefer to work with Jim, choose "Jim".
    +   If you prefer to work with Jimmy, choose "Jimmy".
    +   If you prefer to work with Jane, choose "Jane".
