# Cyber Security Checklist - Help Guide
## Purpose
The purpose of this form is to assess the security measures in place for a service, including the evaluation of various security items and the categorization of the service under different security categories.

## How To Complete This Form
To complete this form, follow these steps:

1. Select all the applicable security items from the list provided in the "Security Checklist Items" section.
2. Choose the correct category for the service from the list in the "Category" section.
3. Select the tool used for the security assessment from the list in the "Assigned Tool" section.
4. Enter the name of the person submitting the form from the list in the "Submitted By" section.
5. Optionally, provide additional information and comments in the "Notes" section.
6. Enter the email address and phone number of the contact person.
7. Select the date and time when the form was submitted.

## Field-by-Field Explanation
* **Service Evaluation Forms**: This field is for selecting the type of service evaluation form.
	+ Type: Text input field.
	+ Required: Yes.
	+ Explanation: This field is for selecting the type of service evaluation form, which will determine the specific security items that will be assessed.
* **Security Checklist Items**: This field is for selecting the applicable security items that should be evaluated.
	+ Type: Multiple-select input field.
	+ Required: Yes.
	+ Explanation: This field is for selecting all the security items that should be evaluated for the service, such as "Check the firewall" or "Check the intrusion detection system".
* **Notes**: This field is for providing additional information and comments about the security assessment.
	+ Type: Text input field.
	+ Required: No.
	+ Explanation: This field is for entering any additional information or comments about the security assessment.
* **Email**: This field is for entering the email address of the contact person.
	+ Type: Email input field.
	+ Required: No.
	+ Explanation: This field is for entering the email address of the contact person.
* **Phone**: This field is for entering the phone number of the contact person.
	+ Type: Text input field.
	+ Required: No.
	+ Explanation: This field is for entering the phone number of the contact person.
* **Date**: This field is for selecting the date when the form was submitted.
	+ Type: Date input field.
	+ Required: No.
	+ Explanation: This field is for selecting the date when the form was submitted.
* **Time**: This field is for selecting the time when the form was submitted.
	+ Type: Time input field.
	+ Required: No.
	+ Explanation: This field is for selecting the time when the form was submitted.
* **Category**: This field is for selecting the category of the service being evaluated.
	+ Type: Single-select input field.
	+ Required: Yes.
	+ Explanation: This field is for selecting the category of the service being evaluated, such as "Category 1" or "Category 2".
* **Assigned Tool**: This field is for selecting the tool used for the security assessment.
	+ Type: Single-select input field.
	+ Required: Yes.
	+ Explanation: This field is for selecting the tool used for the security assessment, such as "Chatjimmy" or "Other".
* **Submitted By**: This field is for selecting the person submitting the form.
	+ Type: Single-select input field.
	+ Required: Yes.
	+ Explanation: This field is for selecting the person submitting the form, such as "John" or "Jane".
