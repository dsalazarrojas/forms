# Service Status Record - Help Guide
## Purpose
The "Service Status Record" form is a tool used to track the status of service requests. It provides a centralized and organized way to view and manage service requests.

## How To Complete This Form
To complete this form, follow these steps:

1. Ensure you have all the required information to complete the form accurately.
2. Fill out the form fields as prompted.

## Field-by-Field Explanation

* **Status**: This field is used to indicate the current status of the service request. You can select from the following options:
	+ Open: The service request is new and has not been processed yet.
	+ In Progress: The service request is being worked on.
	+ Closed: The service request has been completed.
	+ Cancelled: The service request has been cancelled.
* **Request Number**: This field is for the internal reference number of the service request.
* **Customer Name**: This field is for the name of the customer who submitted the service request.
* **Service Request Date**: This field is for the date when the service request was submitted.
* **Service Request Time**: This field is for the time when the service request was submitted.
* **Service Request Details**: This field is for any additional information about the service request.
* **Service Request Status**: This field is for the current status of the service request. Select from the options above.
* **Service Request Comments**: This field is for any additional comments or notes about the service request.
* **Assigned To**: This field is for the team member assigned to work on the service request. Select from the following options:
	+ chatjimmy
	+ John
	+ Jane
* **Follow Up Date**: This field is for the date when the service request is due for follow-up.
* **Follow Up Time**: This field is for the time when the service request is due for follow-up.
* **Follow Up Details**: This field is for any additional information about the follow-up schedule.
* **Follow Up Status**: This field is for the current status of the follow-up schedule. Select from the options above.
* **Follow Up Comments**: This field is for any additional comments or notes about the follow-up schedule.
* **Updated By**: This field is for the team member who last updated the service request status.
* **Updated By**: This field is for the team member who last updated the service request status.

## Tips

* Make sure to fill out all required fields accurately and completely.
* Update the status and assignments regularly to reflect the actual progress of the service request.
* Use the follow-up fields to schedule and track follow-up activities.
