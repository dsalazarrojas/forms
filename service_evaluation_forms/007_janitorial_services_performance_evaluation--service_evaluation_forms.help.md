# janitorial_services_performance_evaluation - Help Guide
## Purpose
This form is designed to evaluate the performance of janitorial services provided to a facility or organization.
## How To Complete This Form
To complete this form, follow these steps:

1. Read each question carefully and answer accordingly.
2. Complete all the required fields.

## Field-by-Field Explanation
- **What is the purpose of this evaluation form?**
  * The first field is a text field where you can enter the purpose of this evaluation form.
  * Please provide a brief description of the purpose of this evaluation form.
  * This field is optional.
- **How would you rate the overall quality of the services provided?**
  * This question asks you to rate the overall quality of the services provided to you.
  * The options are:
    + Very Good
    + Good
    + Fair
    + Poor
  * Please select the option that best describes your experience.
  * This field is required.
- **Which areas of the services met your expectations?**
  * This question asks you to select all the areas where the services met your expectations.
  * The options are:
    + Excellent
    + Good
    + Fair
    + Poor
  * Please select all the options that apply.
  * This field is required.
- **Were the janitorial staff courteous and respectful?**
  * This question asks you to indicate whether the janitorial staff were courteous and respectful.
  * The options are:
    + Yes
    + No
  * Please select the option that best describes your experience.
  * This field is required.
- **Did the janitorial staff meet the required standards for cleanliness and organization?**
  * This question asks you to rate the janitorial staff's performance in terms of cleanliness and organization.
  * The options are:
    + Yes
    + No
  * Please select the option that best describes your experience.
  * This field is required.
- **Would you recommend the services to others?**
  * This question asks you to indicate whether you would recommend the services to others.
  * The options are:
    + Yes
    + No
  * Please select the option that best describes your experience.
  * This field is required.
- **What date would you like to schedule the next evaluation?**
  * This question asks you to input the date you would like to schedule the next evaluation.
  * Please enter the date in the correct format (mm/dd/yyyy).
  * This field is required.
- **How would you rate the communication between the janitorial staff and you/your team?**
  * This question asks you to rate the communication between the janitorial staff and you/your team.
  * The options are:
    + Excellent
    + Good
    + Fair
    + Poor
  * Please select the option that best describes your experience.
  * This field is required.
- **What time do you expect the next evaluation?**
  * This question asks you to input the time you would like to schedule the next evaluation.
  * Please enter the time in 12-hour format (e.g., 2 PM).
  * This field is not required.
- **Do you have any comments or feedback on the services?**
  * This question allows you to provide any comments or feedback you have about the services.
  * Please use this space to provide detailed feedback.
  * This field is not required.
- **How would you rate the timeliness of the services?**
  * This question asks you to rate the timeliness of the services provided.
  * The options are:
    + Very Good
    + Good
    + Fair
    + Poor
  * Please select the option that best describes your experience.
  * This field is required.
- **Are the janitorial staff properly equipped with the necessary cleaning supplies?**
  * This question asks you to indicate whether the janitorial staff are properly equipped with the necessary cleaning supplies.
  * The options are:
    + Yes
    + No
  * Please select the option that best describes your experience.
  * This field is required.
