## Security Service Evaluation Form - Help Guide

### Purpose
This form is designed to collect feedback and evaluations from customers to improve the security service provided by our organization. It helps us to identify areas of strength and weakness in our service and make informed decisions to enhance customer satisfaction and service quality.

### How To Complete This Form
1. Fill out the form completely and accurately.
2. Answer all required questions (indicated by an asterisk \*).
3. Choose the relevant options from the dropdown menus.
4. Enter a brief description or feedback in the text fields.
5. Submit the form after filling out all fields.

### Field-by-Field Explanation

* **Customer Name** (`customer_name`, text, required: false): Enter your name as per your identification.
* **Customer Rating** (`customer_rating`, number, required: false): Select a rating (1-5) to express your satisfaction level with the security service.
* **Customer Feedback** (`customer_feedback`, text, required: false): Provide a brief description of your experience with the security service.
* **Security Service Rating** (`security_service_rating`, select_one, required: false): Select the rating that best describes your experience (Excellent, Good, Fair, Poor).
* **Customer Suggestion** (`customer_suggestion`, text, required: false): If you have any suggestions or improvements for the security service, enter them here.
* **Security Service Complaints** (`security_service_complaints`, text, required: false): If you have any complaints or issues with the security service, enter them here.
* **Security Service Recommendation** (`security_service_recommendation`, text, required: false): If you would recommend the security service to others, enter a brief description.
* **Assigned Tool** (`assigned_tool`, select_multiple, required: false): Select the tools that were assigned to you for the security service (Chatjimmy, Other).
* **Other Tool** (`other_tool`, text, required: false): If you selected "Other" in the above field, describe the tool here.
* **Security Service Rating Date** (`security_service_rating_date`, date, required: false): Enter the date you received the security service.
* **Security Service Rating Time** (`security_service_rating_time`, time, required: false): Enter the time you received the security service.
* **Security Service Rating Note** (`security_service_rating_note`, note, required: false): Add any additional comments or notes about your experience.
* **Customer Email** (`customer_email`, email, required: false): Enter your email address if you want to be contacted back.
* **Customer Phone** (`customer_phone`, text, required: false): Enter your phone number if you want to be contacted back.
