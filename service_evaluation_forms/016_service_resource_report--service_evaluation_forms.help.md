# service_resource_report - Help Guide
## Purpose

The "service_resource_report" form is designed to gather information about the availability and capacity of various resources within a service. This form helps to document and track the current status of resources, ensuring accurate data for future planning and decision-making.

## How To Complete This Form

To complete this form, follow these steps:

1. Review the form carefully to ensure you have the necessary information.
2. Select the correct options for each field to provide accurate data.
3. Fill in the form with the requested information.
4. Submit the form to update the resource records.

## Field-by-Field Explanation

* **Service Resource Report** (`service_resource_report_form`, text, required): Enter a brief description of the resource being reported on, including its name and any relevant details.
* **Resource Availability** (`resource_availability`, select_multiple, optional): Select all the options that apply to the current availability of the resource, such as "Yes" or "No".
* **Service Capacity** (`service_capacity`, number, optional): Enter the current capacity of the resource, if applicable.

## Tips

* Be accurate when filling in the form, as the data will be used for future planning and decision-making.
* Ensure you have the necessary information before submitting the form.
* If a resource has multiple capacities (e.g., different levels of availability for different periods), submit separate reports for each capacity level.
* If the resource is not applicable, mark "No" under "Resource Availability" to indicate this.
