# Summer Competition Entry Form - Help Guide
## Purpose
The Summer Competition Entry Form is designed to collect information about participants who want to register for a summer competition.

## How To Complete This Form
To fill out the form, please follow these steps:

1. Select all the events you want to participate in by checking the boxes for each event.
2. For each event you select, provide a brief description of your name (e.g., "John Doe" for Event 1).
3. Enter your name and other contact information in the text fields.
4. Make sure to review and select "Consent to Terms and Conditions".

## Field-by-Field Explanation

    Select all the events you want to participate in. This field is required and allows you to choose multiple events.
- **Event 1** (`event_1`, `select_one`): 
    Select "Yes" if you want to participate in Event 1. This field is part of the "Events" field and is required for those participating in Event 1.
