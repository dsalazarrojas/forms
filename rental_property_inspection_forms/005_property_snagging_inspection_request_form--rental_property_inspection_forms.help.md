## How To Complete This Form
## Field-by-Field Explanation

### Page 1: Property Snagging Inspection Request Form

* **Property Snagging Inspection Request Form** (`Property Snagging Inspection Request Form`, text, **required**): This is the main title of the form, which should be filled in with the specific property snagging inspection request.
* **Rental Property Inspection Forms** (`Rental Property Inspection Forms`, select_multiple, **required**): Select the type of inspection request you are making. Options are Inspection Request, Maintenance Request, and Other.
* **Property Details** (`Property Details`, text, **optional**): Enter a brief description of the property that needs inspection.
* **Inspection Date** (`Inspection Date`, date, **required**): Enter the date of the inspection.
* **Inspection Time** (`Inspection Time`, time, **required**): Enter the time of the inspection.
* **Property Status** (`Property Status`, select_one, **required**): Select the status of the property. Options are New, Existing, and Vacant.
* **Property Condition** (`Property Condition`, select_multiple, **required**): Select the condition of the property. Options are Excellent, Fair, and Poor.

### Page 2: Property Information

* **Home Address** (`Home Address`, text, **required**): Enter the address of the property that needs inspection.
* **Property Manager** (`Property Manager`, text, **required**): Enter the name and contact information of the property manager.
* **Contact Number** (`Contact Number`, text, **required**): Enter the contact number of the property manager.
* **Email Address** (`Email Address`, email, **required**): Enter the email address of the property manager.
* **Note (Optional)** (`Note (Optional)`, note, **optional**): Enter any additional notes or comments about the property.

### Page 3: Property Specifications

* **Property Size** (`Property Size`, select_multiple, **required**): Select the size of the property. Options are Small, Medium, and Large.
* **Property Type** (`Property Type`, select_multiple, **required**): Select the type of property. Options are Single-Family, Multi-Family, and Townhouse.
* **Property Use** (`Property Use`, select_multiple, **required**): Select the use of the property. Options are Residential, Commercial, and Industrial.
* **Property Subtype** (`Property Subtype`, select_multiple, **optional**): Select the subtype of the property. Options are Yes and No.
* **Property Description** (`Property Description`, select_multiple, **optional**): Select if the property has a description. Options are Yes and No.

### Page 4: Assignment and Maintenance

* **Assigned To** (`Assigned To`, text, **optional**): Select the person assigned to handle the inspection request.
* **Property Owner** (`Property Owner`, text, **required**): Enter the name of the property owner.
* **Maintenance Request Description** (`Maintenance Request Description`, select_multiple, **optional**): Select if maintenance request is needed. Options are Yes and No.
* **Maintenance Request Status** (`Maintenance Request Status`, select_multiple, **optional**): Select the status of the maintenance request. Options are Active and Inactive.
* **Maintenance Request Type** (`Maintenance Request Type`, select_multiple, **optional**): Select the type of maintenance request. Options are Yes and No.
* **Property ID** (`Property ID`, number, **required**): Enter the ID of the property.
* **Property Location** (`Property Location`, text, **optional**): Enter the location of the property.
* **Property Subtype** (`Property Subtype`, select_multiple, **optional**): Select the subtype of the property. Options are Yes and No.
* **Assigned To** (`Assigned To`, text, **optional**): Select the person assigned to handle the maintenance request.

### Page 5: Additional Information

* **Property Owner** (`Property Owner`, text, **optional**): Enter the name of the property owner.
* **Property Subtype** (`Property Subtype`, select_multiple, **optional**): Select the subtype of the property. Options are Yes and No.
* **Property Description** (`Property Description`, select_multiple, **optional**): Select if the property has a description. Options are Yes and No.

## Tips

* Make sure to complete all required fields to ensure efficient processing of the inspection request.
* If you are unsure about any field, please reach out to the property manager or the assigned person for clarification.
* Please note that all fields are case sensitive.
