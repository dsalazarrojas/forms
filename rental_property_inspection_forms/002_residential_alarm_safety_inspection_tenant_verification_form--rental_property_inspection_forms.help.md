# Residential Alarm Safety Inspection Tenant Verification Form - Help Guide

## Purpose
This form is designed to collect information about the safety and security features of a residential alarm system in a rental property. The form aims to ensure that the alarm system is working properly and meeting the necessary safety standards.

## How To Complete This Form

1.  To complete this form, please select all relevant options that apply to your property's alarm system. This will help the form administrator accurately assess the system's status.
2.  Ensure that all fields are filled out completely and accurately, as this information will be used to determine the safety and security status of your property's alarm system.
3.  If you are unsure about any of the fields or questions, please contact your property manager or landlord for guidance.

## Field-by-Field Explanation

*   **Tenant Verification (1)** (`tenant_verification`, select_multiple): Select all the options that apply to you as a tenant. This field will help the form administrator understand your role and involvement with the alarm system.
*   **Alarm System Status (2)** (`alarm_system_status`, select_one): Choose one of the options to describe the current status of your alarm system. You can select either "Landlord," "Property Manager," or "Tenant."
*   **System Functionality Tested (3)** (`system_functionality_tested`, date): Enter the date when the system's functionality was last tested.
*   **Tenant Signature (4)** (`tenant_signature`, note): Provide a note with your signature, confirming that the information provided is accurate and true.
*   **Property Address (5)** (`property_address`, text): Enter the address of the rental property being inspected.
*   **Alarm Type (6)** (`alarm_type`, select_one): Select the type of alarm system installed in the property, such as Fire, Police, or Medical.
*   **Alarm Activation Method (7)** (`alarm_activation_method`, select_one): Choose the method used to activate the alarm system, such as Key, Card, or Keypad.
*   **Keyless Entry Enabled (8)** (`keyless_entry_enabled`, number): Enter the number of ways to enter the property without a key, if any.
*   **Alarm Sounds Volume (9)** (`alarm_sounds_volume`, number): Enter the volume level of the alarm sounds, if applicable.
*   **System Tested Date (10)** (`system_tested_date`, date): Enter the date when the system was last tested.
*   **System Tested By (11)** (`system_tested_by`, select_one): Choose who last tested the system, such as Technician, Property Manager, or Tenant.
*   **Alarm Sounds (12)** (`alarm_sounds`, select_one): Select whether or not the alarm sounds are enabled.
*   **Alarm Sounds Duration (13)** (`alarm_sounds_duration`, number): Enter the duration of the alarm sounds, if applicable.
*   **Test Notes (14)** (`test_notes`, select_multiple): Select all the options that apply to your understanding of the alarm system's tests.
*   **Alarm Type Frequency (15)** (`alarm_type_frequency`, select_one): Select the frequency of the alarm system's type, such as 1x, 2x, or 3x.
*   **Alarm Sounds Test Notes (16)** (`alarm_sounds_test_notes`, note): Enter any notes about the alarm system's sounds, if applicable.
