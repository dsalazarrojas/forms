# Rental Property Self Inspection Form - Help Guide

## Purpose
The Rental Property Self Inspection Form is used to inspect and update the status of rental properties. This form helps property managers or administrators to accurately collect and record information about the property's current state.

## How To Complete This Form
To complete this form, follow these steps:
1. Enter the "Rental Property Address" to identify the property that needs inspection.
2. Enter the "Contact Person" who is responsible for the property.
3. Enter the "Contact Email" and "Contact Phone" numbers of the person.
4. Select the "Property Type" to specify the type of property.
5. Select the "Property Status" from the provided options (Active, Inactive, Leased, Vacant, or Unknown).
6. Enter the "Inspection Date" and "Inspection Time" if required.
7. Review and submit the form for processing.

## Field-by-Field Explanation
* **Rental Property Address (1)**: Enter the address of the rental property.
* **Contact Person (2)**: Enter the name of the person responsible for the property.
* **Contact Email (3)**: Enter the email address of the contact person.
* **Contact Phone (4)**: Enter the phone number of the contact person.
* **Property Type (5)**: Select the type of property (e.g., apartment, house, etc.).
* **Property Status (6)**: Select the current status of the property from the options (Active, Inactive, Leased, Vacant, or Unknown).
* **Inspection Date (7)**: Enter the date of the inspection (if required).
* **Inspection Time (8)**: Enter the time of the inspection (if required).

## Tips
* Make sure to update the form accurately to reflect the current state of the property.
* If any discrepancies are found between the form and actual property status, address them promptly.
* This form should only be used for self-inspection purposes, and any errors or discrepancies should be reported to the relevant authorities.
* Review and submit the form carefully before processing for accurate results.
