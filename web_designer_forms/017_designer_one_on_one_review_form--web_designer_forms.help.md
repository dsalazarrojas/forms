# Designer One On One Review Form - Help Guide
## Purpose
This form is a tool for designers to provide feedback and critique on each other's work. It is meant to facilitate a one-on-one review session between two individuals.

## How To Complete This Form
To complete this form, follow these steps:

* Enter a title for the review session in the `Designer One On One Review Form Title` field.
* Provide feedback and critique in the `Feedback` field.
* Choose whether to schedule a critique session (`Schedule Critique Session`).
* Indicate your availability for critiques (`Critique Frequency`).
* Select a date and time for the review session (`Review Session Date` and `Review Session Time`).
* Choose your preferred feedback format (`Feedback Schedule`).
* Select the formats you prefer for feedback (`Feedback Format`).
* Add a note about your review frequency (`Review Frequency Note`).
* Enter your email address (`Email`).
* Enter your phone number (`Phone`).

## Field-by-Field Explanation
* **Designer One On One Review Form Title** (`title`, `text`, required/optional): Enter a title for the review session.
* **Feedback** (`feedback`, `text`, required/optional): Provide feedback and critique on the designer's work.
* **Schedule Critique Session** (`schedule_critique_session`, `select_one`, required/optional): Choose whether to schedule a critique session.
	+ Select `Yes` if you want to schedule a critique session.
	+ Select `No` if you don't want to schedule a critique session.
* **Critique Frequency** (`critique_frequency`, `select_multiple`, required/optional): Indicate your availability for critiques.
	+ Select `Yes` if you are available for critiques.
	+ Select `No` if you are not available for critiques.
* **Review Session Date** (`review_session_date`, `date`, required/optional): Select a date for the review session.
* **Review Session Time** (`review_session_time`, `time`, required/optional): Select a time for the review session.
* **Feedback Schedule** (`feedback_schedule`, `select_one`, required/optional): Choose your preferred feedback format.
	+ Select `Yes` if you prefer feedback in this format.
	+ Select `No` if you don't prefer feedback in this format.
* **Feedback Format** (`feedback_format`, `select_multiple`, required/optional): Select the formats you prefer for feedback.
	+ Select `Yes` if you prefer feedback in this format.
	+ Select `No` if you don't prefer feedback in this format.
* **Review Frequency Note** (`review_frequency_note`, `note`, required/optional): Add a note about your review frequency.
* **Email** (`email`, `email`, required/optional): Enter your email address.
* **Phone** (`phone`, `text`, required/optional): Enter your phone number.

## Tips

* Please make sure to fill out all required fields.
* If a field is optional, fill it out if you feel it's necessary for the review process.
* Use the feedback and critique provided in this form to guide the designer in improving their skills and knowledge.
* If you have any questions or concerns, feel free to reach out to the designer or the review administrator.
