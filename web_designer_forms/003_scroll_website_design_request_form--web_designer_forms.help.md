# Scroll Website Design Request Form - Help Guide
## Purpose
The Scroll Website Design Request Form is used to collect project details and requirements for a web design project. It will help us understand your project's needs and ensure that we can deliver a high-quality design that meets your expectations.

## How To Complete This Form
To complete this form, simply fill in the required fields with your project information. Please make sure to provide as much detail as possible, but do not worry if you need help with any field. Our team will review and assist you with any questions or concerns.

## Field-by-Field Explanation
* **Scroll Website Design Request Form**: This is the project title. Please give your project a unique and descriptive title.
* **Project Details**: Provide a brief description of your project, including any relevant information about the project's scope and objectives.
* **Website Domain**: Enter the domain of the website you want to design. This will help us understand the project's context.
* **Target Audience**: Describe the people who will be using the website, such as your customers, employees, or users.
* **Design Style**: Briefly describe the design style you are looking for, such as modern, minimalistic, or creative.
* **Color Scheme**: Specify the color scheme you prefer for the website, including any specific colors you like or dislike.
* **Website Name**: Provide the name of the website, if you have one already in mind.
* **Design Elements**: List any specific design elements you would like to include or exclude, such as logos, images, or videos.
* **Design Notes**: Add any additional notes or details about the design you would like to include.
* **Email Address**: Enter your email address so we can contact you about your project.
* **Phone Number**: Provide your phone number in case we need to discuss your project.
* **Website URL**: Enter the URL of the website you would like to design, if you have one already available.
* **Project Deadline**: Specify a deadline for the project, including the date and time.
* **Project Deadline Time**: Specify the time of day you would like to have the project completed.
* **Assigned Tool**: Choose the tool we will use to design the website, such as Webflow, Figma, or Sketch.
* **Assigned Tool Other**: If you have a preferred tool not listed, specify it here.
* **Submitted By**: Enter your name or the name of the person submitting the project.
* **Date Submitted**: Enter the date you submitted the project.
* **Time Submitted**: Enter the time you submitted the project.
* **Project Notes**: Add any additional notes or comments about the project.
* **Scroll Website URL**: Enter the URL of the website, if you have one already available.
* **Scroll Website Status**: Choose the status of the project, such as New, Design In Progress, Design Complete, Ready for Review, or Ready for Development.
* **Scroll Website Priority**: Choose the priority level of the project, such as High, Medium, or Low.
* **Scroll Website Description**: Provide a brief description of the project's purpose and objectives.
* **Submitted By**: Enter your name or the name of the person submitting the project.

Please note that all fields are optional, but the project status and priority fields are required to ensure we can track and manage your project efficiently. If you have any questions or need help with any field, please don't hesitate to contact us.
