# Website Showcase Application Form - Help Guide
## Purpose

This form is used to submit a website showcase application. Fill out the form to provide information about your website, including contact details, website details, and other relevant data.

## How To Complete This Form

To complete this form, follow these steps:

1. Fill out all the required fields, marked with a red asterisk (*). This will ensure that your application is complete and submitted successfully.
2. For each field, enter the required information as instructed in the Field-by-Field Explanation section.
3. Review your application before submitting to ensure that all required fields are filled out correctly.

## Field-by-Field Explanation

### User Info
* **User Info**: Enter your name, email, and other contact information.

### Website Details
* **Website URL**: Enter the URL of your website.
* **Website Name**: Enter the name of your website.

### Portfolio Items
* **Portfolio Items**: This field allows you to select whether you have a portfolio or not. Select 'Yes' if you have a portfolio, 'No' otherwise.

### Contact Info
* **Email**: Enter your email address.
* **Phone**: Enter your phone number.

### Submit Information
* **Submit Date**: Enter the date when you submitted the application.
* **Submit Time**: Enter the time when you submitted the application.
* **Submit Note**: Enter any additional notes about your submission.

### Assignee
* **Assignee**: Select whether you want the application to be assigned to someone or not. Select 'Yes' if you want to assign, 'No' otherwise.

### Assigned Tool
* **Assigned Tool**: Select whether you want to assign a tool to the application or not. Select 'Yes' if you want to assign, 'No' otherwise.

### Output File
* **Output File**: This field is not used in the application process.

### Form ID
* **Form ID**: This field is not used in the application process.

### Description
* **Description**: Enter a brief description of your website.

### Category
* **Category**: Select a category for your website.

### Assigned To
* **Assigned To**: This field is not used in the application process.

### Notes
* **Notes**: Enter any additional notes about your application.

### Submitter
* **Submitter**: This field is not used in the application process.

Note: The form has multiple fields, and each field has its own instructions for completion. Please follow the instructions carefully to ensure a successful submission.
