# Accounting Task Management Board - Help Guide
## Purpose
This form is designed to manage accounting tasks, allowing you to track and prioritize tasks, set deadlines, and assign responsibilities. It serves as a centralized platform for coordinating tasks and increasing team efficiency.

## How To Complete This Form
To complete this form, follow these steps:

1.  Enter a **Task Title** that accurately and briefly describes the task.
2.  Enter a **Task Description** that provides a detailed overview of what needs to be done.
3.  Assign the task to the **Assigned To** person, who will be responsible for its completion.
4.  Choose the **Task Category**, which categorizes the task as Bookkeeping, Reconciliation, Tax Preparation, Financial Reporting, Audit Support, Budget Planning, Payroll, or Other.
5.  Select the **Priority Level** based on its urgency as Low, Medium, High, or Critical.
6.  Set the **Due Date** when this task needs to be completed.
7.  Enter the **Estimated Hours to Complete**, if applicable.
8.  Select the **Task Status**, which can be Not Started, In Progress, Review, Completed, On Hold, or Cancelled.
9.  (Optional) Choose the **Project Phase**, where this task belongs to one of Planning, Execution, Review, or Closing phases.
10. (Optional) List any **Dependencies** that this task has on other tasks.
11. (Optional) Specify the **Required Resources** needed to complete this task.
12. (Optional) List any **Related Documents** that are essential to the task.
13. (Optional) Define the **Completion Criteria**, which outlines what makes the task complete.
14. (Optional) Mark if this task **Requires Review** by another team member.

## Field-by-Field Explanation

*   **Task Title**: Enter a brief title for the accounting task.
    *   Type: `text`
    *   Required: Yes
*   **Task Description**: Describe the task in detail, including what needs to be done and any relevant details.
    *   Type: `text`
    *   Required: Yes
*   **Assigned To**: Select the person responsible for completing this task.
    *   Type: `text`
    *   Required: Yes
*   **Task Category**: Choose the type of accounting task.
    *   Type: `select_one`
    *   Required: Yes
*   **Priority Level**: Select the priority level of this task, which can be Low, Medium, High, or Critical.
    *   Type: `select_one`
    *   Required: Yes
*   **Due Date**: Set the date by which this task must be completed.
    *   Type: `date`
    *   Required: Yes
*   **Estimated Hours to Complete**: Estimate the number of hours expected to complete the task. (Optional)
    *   Type: `number`
    *   Required: No
*   **Task Status**: Indicate the current status of this task.
    *   Type: `select_one`
    *   Required: Yes
*   **Project Phase**: Select the phase of the project to which this task belongs. (Optional)
    *   Type: `select_one`
    *   Required: No
*   **Dependencies**: List any tasks that this task depends on. (Optional)
    *   Type: `text`
    *   Required: No
*   **Required Resources**: Specify resources needed to complete this task. (Optional)
    *   Type: `text`
    *   Required: No
*   **Related Documents**: List essential documents or files related to this task. (Optional)
    *   Type: `text`
    *   Required: No
*   **Completion Criteria**: Define what makes this task complete. (Optional)
    *   Type: `text`
    *   Required: No
*   **Review Required**: Indicate if this task requires review by another team member. (Optional)
    *   Type: `select_one`
    *   Required: No
