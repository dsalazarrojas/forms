# Financial Transaction Log - Help Guide
## Purpose

The Financial Transaction Log form is used to record financial transactions, such as income and expenses, to help accountants track and analyze financial activities accurately.

## How To Complete This Form

1. Fill out the form with the required information for each field, as marked.
2. Ensure that you're providing accurate and relevant information for each field.
3. Review the form carefully before submitting it.

## Field-by-Field Explanation

* **Transaction Date (1)**: Date of the transaction. Enter the date in the format MM/DD/YYYY.
* **Transaction Amount (2)**: The amount of the transaction. Please enter a numerical value.
* **Transaction Description (3)**: A brief description of the transaction. This can be a few words or a short paragraph.
* **Transaction Type (4)**: Select all that apply:
	+ Income
	+ Expense
	+ Payment
* **Category (5)**: Select one:
	+ Salary
	+ Bills
	+ Investments
	+ Other
* **Subcategory (6)**: Select all that apply:
	+ Yes
	+ No
* **Transaction Currency (7)**: Select one:
	+ USD
	+ EUR
	+ CNY
	+ JPY
* **Transaction Ref (8)**: A reference or ID for the transaction, if applicable.
* **Transaction Notes (9)**: Additional notes or comments about the transaction.
* **Account Number (10)**: The account number associated with the transaction.
