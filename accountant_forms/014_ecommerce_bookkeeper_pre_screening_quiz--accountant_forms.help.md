# Ecommerce Bookkeeper Pre Screening Quiz - Help Guide

## Purpose
The Ecommerce Bookkeeper Pre Screening Quiz is a form designed to quickly identify potential bookkeepers for an ecommerce role based on their experience, qualifications, and availability. This form aims to ensure that candidates have the necessary skills and qualifications to handle the financial tasks associated with managing an online store.

## How To Complete This Form
To complete this form, simply follow the instructions below:

1. Fill out each field as accurately as possible, based on the information you have about the candidate.
2. Select all applicable options for each field, using the dropdown menus or checkboxes.
3. Submit the form once you have completed all required fields.

## Field-by-Field Explanation
### 1. Candidate Info
* **Candidate Info** (`candidate_info`, text, required: false): Please enter the candidate's name and any additional contact information you have.

### 2. Years Experience
* **Years Experience** (`years_experience`, text, required: false): Please enter the number of years the candidate has worked as a bookkeeper.

### 3. Accounting Software
* **Accounting Software** (`accounting_software`, select_multiple, required: false): Select all accounting software the candidate has experience with, such as QuickBooks, Xero, or Sage.

### 4. Bookkeeper Qualification
* **Bookkeeper Qualification** (`bookkeeper_qualification`, select_one, required: false): Select the highest certification the candidate holds, such as Certified Bookkeeper or Certified Public Accountant.

### 5. Language Skills
* **Language Skills** (`language_skills`, select_multiple, required: false): Select all languages the candidate is proficient in, such as English, French, or Spanish.

### 6. Bookkeeper Certification
* **Bookkeeper Certification** (`bookkeeper_certification`, select_multiple, required: false): Select all certifications the candidate holds, such as CPA, CPA (Australia), or CIMA.

### 7. Availability
* **Availability** (`availability`, select_one, required: false): Select the candidate's availability, such as Full-time, Part-time, or Remote.

### 8. Work Type
* **Work Type** (`work_type`, select_multiple, required: false): Select the type of work the candidate is available for, such as Full-time, Part-time, or Freelance.
