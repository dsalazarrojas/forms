# Expense Request Form - Help Guide
## Purpose
This form is used to submit an expense report to the accounting department for processing.

## How To Complete This Form
To complete this form, follow these steps:

1.  Select the correct expense category (e.g., "Yes" or "No") that aligns with your expense request.
2.  Enter the date of the expense in the format MM/DD/YYYY.
3.  Enter the amount of the expense.
4.  Provide a detailed description of the expense.
5.  Select "Yes" or "No" to indicate who submitted the request.
6.  Choose "Yes" or "No" to indicate if the manager's review is required.
7.  Select the status of the expense (e.g., "Active" or "Inactive").
8.  Choose "Yes" or "No" to specify the type of expense.

## Field-by-Field Explanation

* **Expense Category** (`Expense Category`, select_one, required: false): Select the category that aligns with your expense request.
* **Expense Date** (`Expense Date`, date, required: false): Enter the date of the expense in the format MM/DD/YYYY.
* **Expense Amount** (`Expense Amount`, number, required: false): Enter the total amount of the expense.
* **Expense Description** (`Expense Description`, text, required: false): Provide a detailed description of the expense.
* **Submitted By** (`Submitted By`, select_multiple, required: false): Indicate if the expense request was submitted by you or someone else.
* **Manager Review** (`Manager Review`, select_one, required: false): Choose if the manager's review is required for the expense.
* **Expense Status** (`Expense Status`, select_one, required: false): Select the status of the expense (e.g., "Active" or "Inactive").
* **Expense Type** (`Expense Type`, select_one, required: false): Specify the type of expense (e.g., "Yes" or "No").

## Tips
- Ensure that you have not submitted an expense request recently before completing this form.
- Review the fields carefully before submitting the request to avoid errors.
