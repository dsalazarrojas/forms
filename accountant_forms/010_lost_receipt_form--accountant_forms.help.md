# lost_receipt_form - Help Guide
## Purpose
The lost_receipt_form is a form used to collect information from employees regarding lost receipts related to expenses they have incurred. This form will help the accounting team to track and process such expenses efficiently.

## How To Complete This Form
1. Complete each field as instructed, making sure to fill out all the required fields before proceeding to the next page.
2. Start by filling out the Employee Details page, which includes fields for Employee ID, etc.
3. Proceed to the Receipt Details page, where you will need to fill out fields for Receipt Date and Total Amount.
4. On the next page, select the Expense Category and provide a short description of the expense in the Expense Description field.
5. On the Receipt Status page, select whether the receipt has been received or not.

## Field-by-Field Explanation

* **Expense Description** (Field 3, `expense_description`, required): Enter a brief description of the expense.
* **Receipt Date** (Field 4, `receipt_date`, required): Enter the date when the receipt was issued.
* **Total Amount** (Field 7, `total_amount`, required): Enter the total amount of the expense.
* **Expense Category** (Field 5, `expense_category`, required): Select the category of the expense (e.g., Accounting, Miscellaneous).
* **Expense Subcategory** (Field 6, `expense_subcategory`, optional): Select the subcategory of the expense (e.g., Office Supplies, Equipment, Services).
* **Receipt Status** (Field 8, `receipt_status`, required): Select whether the receipt has been received (e.g., Received, Not Received).
* **Employee Details** (Field 1, `employee_details`, optional): This field is not currently active, but may be used for future enhancements. For now, please leave it blank.
* **Receipt Details** (Field 2, `receipt_details`, optional): This field is not currently active, but may be used for future enhancements. For now, please leave it blank.

## Tips
Make sure to fill out all the required fields before proceeding to the next page. If you are unsure about any field, please contact the accounting team for assistance.
