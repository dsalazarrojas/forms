# invoice_search_form - Help Guide
## Purpose
The invoice search form is a tool designed to assist you in finding specific invoices based on search parameters. This form allows you to input information to narrow down your search and quickly get the list of matched invoices.

## How To Complete This Form
1. To start, simply click on the 'Search' button.
2. In the search parameters section, you can input one or more values for the following fields:
3. Fill in the 'Client Name', 'Invoice Number', or 'Client Phone' fields with the information you're looking for.
4. Optionally, select a start and/or end date for the time period you wish to search for.
5. Press the 'Search' button after filling in all required fields to get the results.

## Field-by-Field Explanation

* **Search** (text, required, optional): Enter the search term to find the invoices. This is the primary search field. You can input any keyword, phrase, or part of a phrase related to the invoice.
* **Invoice Number** (text, optional): Enter the invoice number you're looking for. If you have the invoice number, this field is a quick way to narrow down your search.
* **Client Name** (text, optional): Enter the name of the client whose invoice you're searching for.
* **Client Phone** (text, optional): Enter the client's phone number. Be aware that this field requires a valid phone number format.
* **Client Email** (email, optional): Enter the client's email address. Be sure to include the '@' symbol for a valid format.
* **Start Date** (date, optional): Select the start date of the time period you wish to search for. This will help you find invoices from a specific date forward.
* **End Date** (date, optional): Select the end date of the time period you wish to search for. This will help you find invoices up to a specific date.
* **Client Phone** (text, optional): Enter the client's phone number. Be aware that this field requires a valid phone number format.
* **Client Email** (email, optional): Enter the client's email address. Be sure to include the '@' symbol for a valid format.
* **Client Name** (text, optional): Enter the name of the client whose invoice you're searching for.

**Tips**

* You can leave some of the fields empty if you're not sure about or don't want to fill them in.
* The search results will show invoices that match the criteria you've set.
* You can always reset the form and start a new search by clicking on the 'Search' button.
