# Financial Document Request Form - Help Guide
## Purpose
This form is used to collect information about financial documents requested by taxpayers. It helps in understanding what type of financial document is needed, its status, and the due date for its submission.

## How To Complete This Form
1. Review the form and ensure that you are eligible to fill it out.
2. Select "Yes" or "No" in the "Document Details" section to indicate if a financial document is required.
3. If you selected "Yes", proceed to the next page to provide additional information.
4. Select the "Document Type" that you are requesting from the dropdown menu.
5. Enter the "Document Date" and "Document Due Date" using the calendar icon to select the dates.
6. Enter the "Document Amount" if required.
7. Select the "Document Status" as "Active" or "Inactive" accordingly.
8. Review all the information provided before submitting the form.

## Field-by-Field Explanation
* **Financial Document Request Form** (`title`, `note`, required/optional): This is the title of the form, which is displayed at the top of the page.
* **Document Details** (`financial_document_request_form_2_page`, `select_one`, optional): Select "Yes" or "No" to indicate if a financial document is required.
* **Taxpayer Information** (`financial_document_request_form_3_page`, `select_multiple`, optional): If you selected "Yes" in the previous question, select "Yes" or "No" to indicate if the taxpayer information is required.
* **Document Type** (`financial_document_request_form_4_page`, `select_one`, optional): Select the type of financial document you are requesting from the dropdown menu.
* **Document Date** (`financial_document_request_form_5_page`, `date`, optional): Enter the date of the financial document using the calendar icon.
* **Document Due Date** (`financial_document_request_form_6_page`, `date`, optional): Enter the due date of the financial document using the calendar icon.
* **Document Amount** (`financial_document_request_form_7_page`, `number`, optional): Enter the amount of the financial document if required.
* **Document Status** (`financial_document_request_form_8_page`, `select_one`, optional): Select the status of the financial document as "Active" or "Inactive" accordingly.
