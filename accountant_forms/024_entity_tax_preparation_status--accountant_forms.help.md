# Entity Tax Preparation Status - Help Guide
## Purpose
The Entity Tax Preparation Status form is used to track the tax preparation status of entities. This form helps accountants and tax professionals keep track of the current status of tax preparation for various entities.

## How To Complete This Form

1. **Select the Entity Type**: Choose the type of entity you are preparing taxes for from the options provided. This could be Accounting, Audit, Tax, Financial Planning, or Consulting.
2. Fill out any other relevant fields as necessary, such as providing a tax preparer's contact information or selecting the assigned tool.

## Field-by-Field Explanation

* **Entity Type**: Select the type of entity you are preparing taxes for. This helps categorize and filter the entities in the system.
  - **label:** Entity Type (`entity_type`, select_multiple)
  - **options:** Accounting, Audit, Tax, Financial Planning, Consulting
* **Tax Preparer**: Enter the name of the tax preparer or the person responsible for preparing the tax return. This is an optional field but can be useful for tracking contacts.
  - **label:** Tax Preparer (`tax_preparer`, text)
  - **options:** None
* **Tax Preparer Phone**: Enter the phone number of the tax preparer or the person responsible for preparing the tax return. This is an optional field but can be useful for tracking contacts.
  - **label:** Tax Preparer Phone (`tax_preparer_phone`, text)
  - **options:** None
* **Tax Preparer Email**: Enter the email of the tax preparer or the person responsible for preparing the tax return. This is an optional field but can be useful for tracking contacts.
  - **label:** Tax Preparer Email (`tax_preparer_email`, email)
  - **options:** None
* **Tax Preparer Notes**: Enter any additional notes about the tax preparer or the person responsible for preparing the tax return.
  - **label:** Tax Preparer Notes (`tax_preparer_note`, note)
  - **options:** None
* **Assigned Tool**: Choose the tool assigned to the tax preparation process. Options include chatjimmy or chatbot.
  - **label:** Assigned Tool (`assigned_tool`, select_one)
  - **options:** chatjimmy, chatbot
* **Submitted**: Enter the number of tax returns submitted. This field is optional but can help track progress.
  - **label:** Submitted (`submitted`, number)
  - **options:** None
* **Tax Return Due Date**: Enter the due date for the tax return. This field is optional but can help track deadlines.
  - **label:** Tax Return Due Date (`tax_return_due_date`, date)
  - **options:** None
* **Tax Return Submission Date**: Enter the date the tax return was submitted. This field is optional but can help track progress.
  - **label:** Tax Return Submission Date (`tax_return_submission_date`, date)
  - **options:** None
* **Tax Return Filing Status**: Select the status of the tax return, such as Filing or Not Filing.
  - **label:** Tax Return Filing Status (`tax_return_filing_status`, select_one)
  - **options:** Filing, Not Filing
* **Notes**: Enter any additional comments about the tax preparation status. This field is optional.
  - **label:** Notes (`notes`, note)
  - **options:** None
* **Entity Tax Preparation Status**: Select the status of the entity's tax preparation, such as Filing or Not Filing.
  - **label:** Entity Tax Preparation Status (`entity_tax_preparation_status`, select_one)
  - **options:** Filing, Not Filing
* **Entity Tax Preparation Comments**: Enter any additional comments about the entity's tax preparation status. This field is optional.
  - **label:** Entity Tax Preparation Comments (`entity_tax_preparation_comments`, text)
  - **options:** None
* **Tax Preparation Status**: Select the status of the tax preparation, such as In Progress, Completed, Not Started, Cancelled, or On Hold.
  - **label:** Tax Preparation Status (`tax_preparation_status`, select_one)
  - **options:** In Progress, Completed, Not Started, Cancelled, On Hold

Please ensure that all relevant fields are completed accurately to maintain a clear overview of the entity's tax preparation status.
