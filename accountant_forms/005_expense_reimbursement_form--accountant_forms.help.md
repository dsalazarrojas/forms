# Expense Reimbursement Form - Help Guide
## Purpose
The Expense Reimbursement Form is designed to collect information about expenses incurred during business trips or work-related activities. This form helps to track and manage expense records accurately, ensuring that all necessary details are captured for auditing and reimbursement purposes.

## How To Complete This Form
To complete this form, follow these steps:

* Start by filling out the User Input section, which is a required field that asks for a brief introduction and explanation of the expense.
* Select the appropriate expense type (Cash, Credit Card, or Other) in the Expense Type field.
* Enter the date of the expense in the Date field.
* Enter the amount of the expense in the Amount field.
* Provide a description of the expense in the Description field.
* Choose a category for the expense (Food, Transportation, or Accommodation) in the Category field.
* If necessary, add an attachment for additional information in the Attachment field (not required).
* Finally, select the Submit option to complete the form.

## Field-by-Field Explanation
### 1. User Input (id: 1, Label: User Input, type: text, required: true)
* This field is a required field where you can enter a brief introduction and explanation of the expense.

### 2. Expense Type (id: 2, Label: Expense Type, type: select_multiple, required: true)
* Select the type of expense incurred (Cash, Credit Card, or Other).

### 3. Date (id: 3, Label: Date, type: date, required: true)
* Enter the date of the expense in the format of YYYY-MM-DD.

### 4. Amount (id: 4, Label: Amount, type: number, required: true)
* Enter the amount of the expense.

### 5. Description (id: 5, Label: Description, type: text, required: true)
* Provide a description of the expense.

### 6. Category (id: 6, Label: Category, type: select_one, required: true)
* Choose a category for the expense (Food, Transportation, or Accommodation).

### 7. Attachment (id: 7, Label: Attachment, type: note, required: false)
* If necessary, add an attachment for additional information.

### 8. Submit (id: 8, Label: Submit, type: select_one, required: false)
* Select the Submit option to complete and send the form.
* Alternatively, select Other to save the form as a draft or for further action.
