# Quarterly Financial Performance Report - Help Guide
## Purpose
The Quarterly Financial Performance Report is a form that captures feedback and information on the quarterly financial report.

## How To Complete This Form
1. Choose whether you have reviewed the quarterly financial performance report by selecting "Yes" or "No" in the "Quarter" section.
2. If you have financial or operations data updates, provide them in the corresponding fields. You do not have to complete these fields if you do not have any updates.
3. If you have any comments, please provide them in the "Comments" field.
4. Select the "Financial Performance Metrics" and "Operations Performance Metrics" fields by choosing "Yes" or "No" for each metric.
5. If you have submitted the report, select "Yes" in the "Submit" field.
6. Finally, provide your email and phone number for contact purposes.
7. If you have any additional notes or files to attach, use the "Notes" and "File Upload" fields.

## Field-by-Field Explanation
- **Quarter**: Choose "Yes" if you have reviewed and accepted the quarterly financial performance report, or "No" otherwise.
- **Financial Data Updates**: Provide any financial data updates you have.
- **Operations Data Updates**: Provide any operations data updates you have.
- **Comments**: Share your comments or suggestions on the report.
- **Financial Performance Metrics**: Select "Yes" for each financial performance metric you are meeting or exceeding.
- **Operations Performance Metrics**: Select "Yes" for each operations performance metric you are meeting or exceeding.
- **Submit**: Select "Yes" to indicate that you have submitted the report.
- **Email**: Enter your email address for contact purposes.
- **Phone**: Enter your phone number for contact purposes.
- **Notes**: Add any additional notes or comments you would like to attach to the report.
- **File Upload**: Upload any relevant files to attach to the report.
