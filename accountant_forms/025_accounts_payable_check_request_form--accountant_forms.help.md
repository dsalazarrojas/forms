# Accounts Payable Check Request Form - Help Guide

## Purpose

The Accounts Payable Check Request Form is used to request payments to be made to vendors or payees.

## How To Complete This Form

1. Fill out the form in a logical and sequential manner.
2. Ensure all required fields are completed.
3. Use the available information as a guide to provide accurate and complete information.

## Field-by-Field Explanation

* **Requester name** (Required): The name of the person requesting the payment.
* **Vendor name** (Required): The name of the vendor or payee.
* **Vendor contact** (Optional): The phone or email for the vendor, if applicable.
* **Invoice number** (Required): The reference number from the vendor invoice.
* **Amount requested** (Required): The total amount to be paid.
* **Currency** (Required): Select the currency for the payment.
* **Payment method** (Required): Select the payment method to be used.
* **Department charge** (Optional): The department or cost center to charge the payment to.
* **Accounting code** (Optional): The ledger or GL code for the expense.
* **Approval signature** (Required): Type the full name to authorize payment.
* **Approval date** (Required): The date of manager approval.
* **Notes** (Optional): Any special payment instructions.

Note: Required fields are marked as 'Required'. Ensure these fields are completed accurately to avoid delays in processing.
