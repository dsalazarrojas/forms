# corporate_tax_audit_request_application_form - Help Guide
## Purpose
The corporate tax audit request application form is used to collect information for corporate tax audit requests. This form is typically completed by users to provide details about the audit request, including category, description, supporting documents, defined audit periods, authorized contact, contact phone, assigned tool, notes, and submitted by.

## How To Complete This Form

To complete this form, follow these steps:

1. Select the category of the audit request from the options provided.
2. Provide a detailed description of the audit request.
3. Select the supporting documents relevant to the audit request.
4. Define the audit periods for the request.
5. Enter the authorized contact person's email address.
6. Enter the authorized contact person's phone number.
7. Select the tool assigned to the audit request.
8. Add any additional notes about the audit request.
9. Select who submitted the request (Finance Team, Auditor, or Accounting Firm).

## Field-by-Field Explanation

* **Title** (`title`, text, not required): This is the title of the corporate tax audit request application form. It should be descriptive and accurately reflect the purpose of the form.
* **Category** (`category`, select_one, not required): Choose a category for the audit request from the options provided. This will help organize the requests in the system.
* **Description** (`description`, text, not required): Provide a detailed description of the audit request. This should include any relevant information about the request.
* **Supporting Documents** (`supporting_documents`, select_multiple, not required): Select the supporting documents relevant to the audit request from the options provided.
* **Defined Audit Period** (`defined_audit_periods`, date, not required): Define the audit periods for the request.
* **Authorized Contact** (`authorized_contact`, email, not required): Enter the authorized contact person's email address.
* **Contact Phone** (`contact_phone`, text, not required): Enter the authorized contact person's phone number.
* **Assigned Tool** (`assigned_tool`, select_one, not required): Select the tool assigned to the audit request from the options provided.
* **Notes** (`notes`, note, not required): Add any additional notes about the audit request.
* **Submitted By** (`submitted_by`, select_one, not required): Select who submitted the request (Finance Team, Auditor, or Accounting Firm).
