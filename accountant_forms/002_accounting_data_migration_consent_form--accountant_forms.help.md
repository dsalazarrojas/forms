# Accounting Data Migration Consent Form - Help Guide
## Purpose
This form is used to gather information and consent from clients before performing a data migration.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill in the Client Company Name field with the legal name of your company.
2. Enter the full name of the person authorizing the data migration in the Authorized Representative Name field.
3. Fill in the Representative Title field with the job title of the person authorizing the migration.
4. Provide a valid email address in the Contact Email Address field for communication regarding the migration.
5. Enter a valid phone number in the Contact Phone Number field for migration-related inquiries.
6. Enter the name of your current accounting system in the Current Accounting System field.
7. Enter the name of the accounting system you wish to migrate to in the Target Accounting System field.
8. Select the data types you wish to migrate using the Data Types to Migrate field.
9. If you have a preferred migration date, enter it in the Preferred Migration Date field.
10. Confirm that your current system data has been backed up using the Backup Verification field.
11. Give your consent to the data migration using the Consent Agreement field.
12. If you have any special requirements or restrictions, provide them in the Additional Requirements or Restrictions field.
13. Finally, enter the date of authorization in the Signature Date field.
