# income_statement_form - Help Guide
## Purpose
The income statement form is designed to collect financial data for calculation and analysis.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the relevant financial data for each field.
2. Ensure that all required fields are completed.
3. Review and adjust the data as necessary.

## Field-by-Field Explanation
* **Revenue 1** (`revenue_1`, Number, Required): Enter the revenue for the current period.
* **Cost of Goods Sold 1** (`cost_of_goods_sold_1`, Number, Required): Enter the cost of goods sold for the current period.
* **Gross Profit 1** (`gross_profit_1`, Number, Required): The difference between revenue and cost of goods sold.
* **Operating Expenses 1** (`operating_expenses_1`, Number, Required): Enter the operating expenses for the current period.
* **Operating Income 1** (`operating_income_1`, Number, Required): The operating income for the current period.
* **Net Income 1** (`net_income_1`, Number, Required): The net income for the current period.
* **Income Tax 1** (`income_tax_1`, Number, Optional): Enter any income tax for the current period.
* **Other Incomes 1** (`other_incomes_1`, Text, Optional): Enter any other incomes for the current period.
* **Other Expenses 1** (`other_expenses_1`, Text, Optional): Enter any other expenses for the current period.
* **Net Investment Income 1** (`net_investment_income_1`, Text, Optional): Enter any net investment income for the current period.
* **Total Assets 1** (`total_assets_1`, Number, Required): Enter the total assets for the current period.
* **Total Liabilities 1** (`total_liabilities_1`, Number, Required): Enter the total liabilities for the current period.
* **Equity 1** (`equity_1`, Number, Required): Enter the equity for the current period.
* **Current Assets 1** (`current_assets_1`, Number, Required): Enter the current assets for the current period.
* **Non-Current Assets 1** (`non_current_assets_1`, Number, Required): Enter the non-current assets for the current period.
* **Current Liabilities 1** (`current_liabilities_1`, Number, Required): Enter the current liabilities for the current period.
* **Non-Current Liabilities 1** (`non_current_liabilities_1`, Number, Required): Enter the non-current liabilities for the current period.
* **Total Equity 1** (`total_equity_1`, Number, Required): Enter the total equity for the current period.
* **Cash 1** (`cash_1`, Number, Required): Enter the cash for the current period.
* **Accounts Payable 1** (`accounts_payable_1`, Text, Optional): Enter any accounts payable for the current period.
* **Account Payable 1** (`account_payable_1`, Text, Optional): Enter any account payable for the current period.
* **Other Payables 1** (`other_payables_1`, Text, Optional): Enter any other payables for the current period.
* **Net Sales 1** (`net_sales_1`, Number, Required): Enter the net sales for the current period.
* **Total Receivable 1** (`total_receivable_1`, Text, Optional): Enter any total receivable for the current period.
