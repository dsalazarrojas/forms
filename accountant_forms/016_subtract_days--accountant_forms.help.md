# subtract_days - Help Guide
## Purpose
This form is designed to calculate the date that results from subtracting a specified number of days from a selected date.

## How To Complete This Form
1. Select the date from which you want to subtract days using the **Date Picker** field.
2. Enter the number of days to subtract in the **Days to Subtract** field.
3. Click submit to get the resulting date in the **Result** field.

## Field-by-Field Explanation
* **Date Picker** (`date`, required): Choose the date from which you want to subtract days. This field allows you to pick a date using a calendar interface.
* **Days to Subtract** (`number`, required): Enter the number of days to subtract from the selected date. Please ensure you enter a whole number.
* **Result** (`text`, required): This field displays the resulting date after subtracting the specified number of days from the selected date.

## Tips
* Make sure to select the correct date and enter the correct number of days to get accurate results.
* The resulting date is displayed in the format YYYY-MM-DD.
