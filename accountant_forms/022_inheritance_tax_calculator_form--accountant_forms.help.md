# Inheritance Tax Calculator Form - Help Guide
## Purpose
This form is designed to provide users with an estimate of the tax implications of their inheritance, based on the provided details.

## How To Complete This Form
To complete this form, simply fill in the required information for each field. Please make sure to select the correct estate type and enter valid numbers for the estate value and beneficiaries count.

## Field-by-Field Explanation
* **Estate Value** (`Estate Value`, `number`, required: false): Enter the total value of the estate.
* **Estate Type** (`Estate Type`, `select_one`, required: false): Select the type of estate from the options provided (Death, Life, Charitable Remainder).
* **Beneficiaries Count** (`Beneficiaries Count`, `number`, required: false): Enter the number of beneficiaries.
* **Beneficiary Inheritance** (`Beneficiary Inheritance`, `number`, required: false): Enter the amount each beneficiary is set to inherit.
* **Executor Name** (`Executor Name`, `text`, required: false): Enter the name of the executor.
* **Executor Phone** (`Executor Phone`, `text`, required: false): Enter the phone number of the executor.
* **Executor Email** (`Executor Email`, `email`, required: false): Enter the email address of the executor.
* **Estate Administrators** (`Estate Administrators`, `select_multiple`, required: false): Select the names of the estate administrators from the provided options (John, Jane, Other).
* **Estate Admin Phone** (`Estate Admin Phone`, `text`, required: false): Enter the phone number of the estate administrator(s).
* **Executor Name** (`Executor Name`, `text`, required: false) and **Executor Email** (`Executor Email`, `email`, required: false) are redundant fields. Please ignore these for now.

## Tips
* Please enter the correct estate value and number of beneficiaries to ensure accurate tax calculations.
* The estate type and beneficiary information will be used to determine tax rates and implications. Make sure to select and enter accurate information.
* If you are unsure about any field, feel free to contact us for assistance.
