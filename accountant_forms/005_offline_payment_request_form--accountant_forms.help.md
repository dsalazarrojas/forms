# Offline Payment Request Form - Help Guide
## Purpose
This form is designed to collect information for offline payment processing. It should only be used when payment is not made online.

## How To Complete This Form
To fill out this form accurately and efficiently, follow these steps:

1. Review the form fields and understand their requirements.
2. Make sure to select "payment_method" correctly, either as Cash, Check, or Other.
3. If you selected "Other", provide a clear explanation in the "payment_method_other" field.
4. Fill out any other required fields accurately and thoroughly.

## Field-by-Field Explanation
* **Offline Payment Request Form** (1): A brief description of the form purpose.
* **Order Number** (2): A unique identifier for the order being paid for. (Optional)
* **Salary Reference Number** (3): A number associated with the employee's salary. (Optional)
* **Payment Method** (4): Select one of the available options (Cash, Check, or Other). (Required)
* **Other Payment Method** (5): If you selected "Other", provide a clear explanation. (Optional)
* **Remarks** (6): A note for any additional information. (Optional)
* **Employee Name** (7): The name of the employee being paid. (Optional)
* **Date** (8): The date of the payment. (Optional)
* **Time** (9): The time of the payment. (Optional)
* **Email** (10): The email of the payment recipient. (Optional)
* **Phone** (11): The phone number of the payment recipient. (Optional)
* **Assigned Tool** (12): Select one of the available options (chatjimmy, chatjimmy2, chatjimmy3). (Required)
* **Form ID** (13): A unique identifier for the form. (Optional)
* **User ID** (14): The ID of the user submitting the form. (Optional)
* **Created At** (15): The date the form was created. (Optional)
* **Updated At** (16): The date the form was last updated. (Optional)
* **Deleted At** (17): The date the form was deleted. (Optional)
* **Created By** (18): The user who created the form. (Optional)
* **Updated By** (19): The user who last updated the form. (Optional)
* **Deleted By** (20): The user who deleted the form. (Optional)
* **Created At 2** (21): A duplicate of the "created_at" field. (Optional)
