# Financial Ledger Submission - Help Guide
## Purpose
This form is designed for financial institutions to collect and submit financial ledger information. It helps the institution gather accurate and detailed data on their financial activities.

## How To Complete This Form
To complete this form, please follow these steps:

1. Select the reporting period for which you are submitting the financial ledger.
2. Choose the financial institution(s) associated with the ledger.
3. Enter the account number for the financial institution.
4. Specify the start date of the ledger.
5. Specify the end date of the ledger.
6. If necessary, add any additional details about the financial institution.
7. Enter your name as the submitter.
8. Enter the date of submission.

## Field-by-Field Explanation

* **Reporting Period** (`reporting_period`, select_one): Select the reporting period for which you are submitting the financial ledger (January-December).
* **Financial Institution** (`financial_institution`, select_multiple): Choose one or multiple financial institutions from the available options (Bank, Credit Union, Savings, Other).
* **Account Number** (`account_number`, text): Enter the account number for the financial institution.
* **Ledger Start Date** (`ledger_start_date`, date): Enter the start date of the ledger.
* **Ledger End Date** (`ledger_end_date`, date): Enter the end date of the ledger.
* **Financial Institution Details** (`financial_institution_details`, note): Add any additional details about the financial institution if necessary.
* **Submitter** (`submitter`, text): Enter your name as the submitter.
* **Submission Date** (`submission_date`, date): Enter the date of submission.
