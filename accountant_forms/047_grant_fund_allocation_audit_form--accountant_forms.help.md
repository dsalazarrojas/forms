# Grant Fund Allocation Audit Form - Help Guide
## Purpose
The Grant Fund Allocation Audit Form is used to verify and audit the allocation of grant funds within an organization. It helps to collect and track information about grant funding sources, allocation dates, amounts, and purposes, and the current status of the funds.

## How To Complete This Form
To complete this form, follow the steps below:

*   Start by selecting the appropriate page from the top navigation bar.
*   Complete the required fields marked with an asterisk (\*) as they are marked as required in the form schema.
*   Use the provided options in the select fields to choose the correct answers.
*   Enter the required details in the text fields.
*   Once you have completed all the fields, select the "Submit" button to submit the form.

## Field-by-Field Explanation

*   **Grant Funding Source** (`grant_funding_source`, select_one, required: false): This field is used to indicate whether the grant funding source is available or not. Select "Yes" if the grant funding source is available, "No" otherwise.
*   **Fund Allocation Date** (`fund_allocation_date`, date, required: false): This field is used to enter the date of the grant fund allocation. Enter the date in a standard date format (DD/MM/YY).
*   **Grant Funding Amount** (`grant_funding_amount`, number, required: false): This field is used to enter the amount of the grant funding. Enter the amount in numerical format.
*   **Grant Allocation Percentage** (`grant_allocation_percentage`, number, required: false): This field is used to enter the percentage of the grant funding that has been allocated.
*   **Allocated for Purpose** (`allocated_for_purpose`, select_one, required: false): This field is used to indicate whether the grant has been allocated for a specific purpose or not. Select "Yes" if it has been allocated for a specific purpose, "No" otherwise.
*   **Fund Usage Status** (`fund_usage_status`, select_multiple, required: false): This field is used to indicate the current status of the grant fund. Select all the status that apply (Active, Inactive).
*   **Grant Funding Source Details** (`grant_funding_source_details`, text, required: true): This field is used to enter more details about the grant funding source.
*   **Grant Funding Amount Details** (`grant_funding_amount_details`, text, required: true): This field is used to enter more details about the grant funding amount.
*   **Total Allocations** (`total_allocations`, number, required: false): This field is used to enter the total allocation of the grant funding.
*   **Grant Allocation Audit Notes** (`grant_allocation_audit_notes`, text, required: false): This field is used to enter any audit notes about the grant fund allocations.
*   **Form Submit Button** (`form_submit_button`, select_one, required: false): This field is used to submit or reset the form. Select "Submit" to submit the form or "Reset" to reset the form to its original state.
