# Accounting Data Review Request Form - Help Guide
## Purpose
The Accounting Data Review Request Form is designed to gather information for a review of specific accounting data. This form ensures that all necessary details are captured to facilitate an efficient review process.

## How To Complete This Form
- Fill out the form in one session, as leaving it incomplete or partially filled may cause delays.
- Ensure that all required fields are completed accurately.
- If a field is not applicable or not relevant, please leave it blank.
- Double-check your email address for correct formatting.
- Choose one option for the "Review Reason" and "Priority Level" fields.
- For "Data Types to Review", select all relevant types.
- For "Reviewer Assignment", select the preferred reviewer if you want to assign it to a specific person.
- In "Special Instructions or Requirements", provide any specific details that might be helpful for the reviewer.
- If any documents are required for the review, list them in "Supporting Documents Needed".
- Click "Submit" to send the form to the accounting team.

## Field-by-Field Explanation
- **Requester Name**: Enter the full name of the person or department requesting the review.
- **Requester Department**: Enter the department that the request is coming from.
- **Requester Email**: Enter a valid email address for communication regarding the review.
- **Reason for Review**: Select the reason for the review from the provided options: "Period-end close verification", "Audit preparation", "Discrepancy investigation", "Compliance requirement", "Management inquiry", or "Other".
- **Review Period Start Date**: Enter the beginning date of the accounting period to be reviewed.
- **Review Period End Date**: Enter the ending date of the accounting period to be reviewed.
- **Data Types to Review**: Select all the types of accounting data to be reviewed, such as "General Ledger", "Accounts Receivable", "Accounts Payable", "Cash Flow", "Fixed Assets", "Revenue Recognition", "Expense Categories", and "Intercompany Transactions".
- **Priority Level**: Choose the priority level of the review: "Low", "Medium", "High", "Critical".
- **Requested Completion Date**: Enter the date when you need the review completed.
- **Suggested Reviewer Assignment**: If you want to assign the review to a specific person, choose "Specific accountant - please specify", and enter their name. Otherwise, select "Any available staff" or "Internal team only".
- **Special Instructions or Requirements**: If there are any specific instructions or requirements for the review, enter them here.
- **Supporting Documents Needed**: List any documents that are required for the review.

## Tips
- Be as detailed as possible when filling out the form.
- Avoid submitting duplicate requests.
- If unsure about any field, it is best to consult with the accounting team before submitting the form.
- Ensure all required fields are completed accurately.
