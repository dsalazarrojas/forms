# Franchise Tax Extension Form - Help Guide
## Purpose
This form is designed to help you request an extension for filing franchise taxes for an entity. Please fill out the form accurately to ensure a smooth extension process.

## How To Complete This Form
1. Please fill in the form title at the top of the page.
2. Select the category for your form submission.
3. Provide a detailed description of the entity and the reason for the extension request.
4. Specify the tool assigned to process the extension request (optional).
5. Enter the form ID (if applicable).
6. Enter a description of the form (optional but recommended).
7. Select the user who submitted this form (required).

## Field-by-Field Explanation

* **Franchise Tax Extension Form**:
	+ Type: text field
	+ Mandatory: no
	+ Description: Enter the form title.
* **Category**:
	+ Type: select-one dropdown menu
	+ Mandatory: no
	+ Description: Select the category for your form submission (e.g., Accountant Forms, Financial Forms, Tax Forms).
* **Description**:
	+ Type: text field
	+ Mandatory: yes
	+ Description: Provide a detailed description of the entity and the reason for the extension request.
* **Output File**:
	+ Type: text field
	+ Mandatory: no
	+ Description: Enter the output file (if applicable).
* **Assigned Tool**:
	+ Type: select-one dropdown menu
	+ Mandatory: no
	+ Description: Specify the tool assigned to process the extension request (if applicable).
* **Form ID**:
	+ Type: number field
	+ Mandatory: no
	+ Description: Enter the form ID (if applicable).
* **Description 1**:
	+ Type: text field
	+ Mandatory: yes
	+ Description: Enter a detailed description of the entity (optional but recommended).
* **Description 2**:
	+ Type: text field
	+ Mandatory: no
	+ Description: A franchise tax extension form is used to request an extension on filing the franchise taxes for an entity.
* **Submitted By**:
	+ Type: select-one dropdown menu
	+ Mandatory: yes
	+ Description: Select the user who submitted this form.
