# Payment Prioritization Request Form - Help Guide

## Purpose
The Payment Prioritization Request Form is a tool used by accountants to request payment from clients or vendors. The form collects information about the payment request, including vendor details, payment amount, rationale, and payment status. This form helps to prioritize payments based on urgency, department, and status.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the "Payment Request" page.
2. Enter a brief description of the payment request in the text field.
3. Move to the "Vendor Information" page.
4. Enter the vendor's name or details in the text field.
5. Move to the "Payment Amount" page.
6. Enter the payment amount in the numeric field.
7. Move to the "Rationale" page.
8. Enter a brief explanation of the reason for the payment request in the text field.
9. Move to the "Payment Date" page.
10. Select a date for the payment to be made.
11. Move to the "Payment Time" page.
12. Select a time for the payment to be made.
13. Move to the "Urgency" page.
14. Select the urgency level for the payment request (Urgent, High, Medium, or Low).
15. Move to the "Payment Status" page.
16. Select the payment status (In Process, Approved, or Rejected).
17. Move to the "Department" page.
18. Select the department(s) responsible for the payment request (Yes or No).
19. Move to the "Email" page.
20. Enter the email address of the client or vendor.
21. Move to the "Phone" page.
22. Enter the phone number of the client or vendor.

## Field-by-Field Explanation
* **Payment Request** (`form_1`, text, optional): Enter a brief description of the payment request in this text field.
* **Vendor Information** (`form_2`, text, optional): Enter the vendor's name or details in this text field.
* **Payment Amount** (`form_4`, number, optional): Enter the payment amount in the numeric field. Please ensure that the amount is accurate to avoid delays or errors in processing the payment.
* **Rationale** (`form_5`, text, optional): Enter a brief explanation of the reason for the payment request in this text field. This field helps the accountant understand the purpose of the payment request.
* **Payment Date** (`form_7`, date, optional): Select a date for the payment to be made.
* **Payment Time** (`form_8`, time, optional): Select a time for the payment to be made.
* **Urgency** (`form_6`, select_multiple, required): Select the urgency level for the payment request (Urgent, High, Medium, or Low).
* **Payment Status** (`form_9`, select_one, required): Select the payment status (In Process, Approved, or Rejected).
* **Department** (`form_10`, select_multiple, required): Select the department(s) responsible for the payment request (Yes or No).
* **Email** (`form_11`, email, optional): Enter the email address of the client or vendor.
* **Phone** (`form_12`, text, optional): Enter the phone number of the client or vendor.

## Tips
* Ensure that all required fields are completed before submitting the form.
* Double-check the accuracy of the payment amount and date before submitting the form.
* If you are unsure about the urgency or department responsible for the payment request, please consult with the relevant personnel before submitting the form.
