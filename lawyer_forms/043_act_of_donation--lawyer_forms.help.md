# Act Of Donation - Help Guide
## Purpose
This form is used to document the details of the "Act Of Donation" in a legal manner. It is used to transfer ownership of assets between parties.

## How To Complete This Form
To complete this form, please fill in the fields with the required information. Start with the donor's information, then move on to the donee's details, and so on.

## Field-by-Field Explanation
* **Donor information (1)**: This field is for the donor's contact information. Please fill in the name and any other relevant details.
* **Donor name (2)**: This field is for the full name of the person donating the asset. Please enter the name as it appears on official documents.
* **Donee name (3)**: This field is for the full name of the person receiving the asset. Please enter the name as it appears on official documents.
* **Asset description (4)**: Please provide a detailed description of the asset being donated. Include any relevant details about its condition, serial numbers, or other identifying features.
* **Asset identification (5)**: If the asset has a serial number, registration, or other unique identifier, please enter it here.
* **Donation date (6)**: Enter the date when the asset is being transferred to the donee.
* **Consideration statement (7)**: Check the box if there is no payment consideration involved in the donation. If there is a payment, select "Nominal consideration" and provide details.
* **Witnesses (8)**: If witnesses are required, enter their names and contact information here.
* **Notarization required (9)**: Check this box if notarization is required for this donation.
* **Signatures (10)**: Please provide the donor and donee typed names as they would appear on the final documents.
* **Additional notes (11)**: Any additional details or conditions that need to be noted should be entered here.

Tips:
* Make sure to fill in all required fields accurately and thoroughly.
* Double-check the asset's description and identification to ensure they match the actual asset.
* If notarization is required, make sure to follow the necessary procedures.
* Review this form carefully before submitting to ensure all details are correct.
