# Murder Case Analysis Survey - Help Guide
## Purpose

The Murder Case Analysis Survey is a form designed to collect information about murder cases. This form will aid in the analysis of the case and help in tracking and managing the status of the case.

## How To Complete This Form

1. Please complete all required fields. The "Case Status" field is mandatory.
2. Fill in the relevant information for each field.
3. Use the "Additional Notes" field for any additional information that you would like to provide.

## Field-by-Field Explanation

### Crime Scene

* **Crime Scene** (`crime_scene`, text, required/optional): This section will help us understand the circumstances surrounding the crime.

### Victim Information

* **Victim Information** (`victim_info`, text, required/optional): Please provide any available information about the victim, such as name, age, and any other relevant details.

### Suspect Information

* **Suspect Information** (`suspect_info`, text, required/optional): Provide any available information about the suspect, such as name, age, and any other relevant details.

### Case Status

* **Case Status** (`case_status`, select_one, required): Please select "Active" if the case is currently being investigated, and "Inactive" if the case is closed or not currently being investigated.

### Crime Details

* **Crime Details** (`crime_details`, text, required/optional): Please provide any additional information about the crime, such as the date and time it occurred, and any other relevant details.

### Additional Notes

* **Additional Notes** (`additional_info`, note, required/optional): This is a free-form text field for providing any additional information that you would like to provide about the case.
