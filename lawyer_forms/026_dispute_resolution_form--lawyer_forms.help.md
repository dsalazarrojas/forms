# dispute_resolution_form - Help Guide
## Purpose
This form is used to document and resolve disputes between parties. It helps to provide a clear and concise record of the dispute, its type, and the resolution method and outcome.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the **Dispute_type** field from the dropdown menu to indicate the type of dispute.
2. Enter the details about **Party_1** and **Party_2** in the respective fields.
3. Select the **Date** on which the dispute occurred or is scheduled to occur.
4. Provide a **Description** of the dispute, including all relevant details.
5. Choose the **Resolution_method** from the dropdown menu to indicate the method used to resolve the dispute.
6. Enter the **Outcome** of the dispute in the provided field.
7. Enter a brief **Resolution** of the dispute.
8. Optionally, add any additional comments or notes in the **Comments** field.
9. Upload any supporting files for the dispute in the **File_1** to **File_15** fields, as needed.

## Field-by-Field Explanation

* **Dispute_resolution_form_page_1**: This is the first page of the form, where you will begin to document the dispute.
* **Party_1**: This field is for entering information about the first party involved in the dispute.
* **Party_2**: This field is for entering information about the second party involved in the dispute.
* **Dispute_type**: This field allows you to select the type of dispute from a dropdown menu.
* **Date**: This field is for entering the date on which the dispute occurred or is scheduled to occur.
* **Description**: This field is for providing a detailed description of the dispute.
* **Resolution_method**: This field is for selecting the method used to resolve the dispute.
* **Outcome**: This field is for entering the outcome of the dispute.
* **Resolution**: This field is for entering a brief description of the resolution.
* **Comments**: This field is optional and allows you to add any additional comments or notes about the dispute.
* **File_1** to **File_15**: These fields are for uploading supporting files for the dispute, if necessary.

Note: The file fields can be used to attach supporting evidence, such as emails, contracts, or other relevant documents.
