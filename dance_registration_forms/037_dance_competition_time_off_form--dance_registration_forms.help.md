# Dance Competition Time Off Form - Help Guide
## Purpose
The Dance Competition Time Off Form is used to collect information about dance events, schedules, and dancer attendance. This includes competition start and end dates and times, rehearsal schedules, and event attendance. 

## How To Complete This Form

1. Fill out the form in a new window or tab.
2. Start with the form's title field, which is the name of the dance event.
3. Enter your name and email address in the "Dancer Name" and "Dancer Email" fields respectively.
4. Provide your contact phone number in the "Contact Phone" field.
5. Enter the request reason for the time off in the "Request Reason" field.
6. Select the start date and time of the dance event in the "Event Start Date" and "Event Start Time" fields.
7. Select the end date and time of the dance event in the "Event End Date" and "Event End Time" fields.
8. Enter the start date and time of the rehearsal in the "Rehearsal Start Date" and "Rehearsal Start Time" fields.
9. Enter the end date and time of the rehearsal in the "Rehearsal End Date" and "Rehearsal End Time" fields.
10. Choose the dance style for the event in the "Dance Style" field.
11. Indicate your attendance plans for the event in the "Event Attendance" field.
12. Check if you plan to attend the rehearsal in the "Rehearsal Attendance" field.
13. Enter any additional notes in the "Note" field.
14. Assign the form to a specific staff member in the "Assigned To" field.

## Field-by-Field Explanation

* **Form Title** (`text`, required/optional): Enter the name of the dance event.
* **Dancer Name** (`text`, required/optional): Enter your name as a dancer.
* **Dancer Email** (`email`, required/optional): Enter your email address for communication purposes.
* **Contact Phone** (`text`, required/optional): Provide your contact phone number.
* **Request Reason** (`text`, required/optional): Enter the reason you need to take time off.
* **Event Start Date** (`date`, required/optional): Select the start date of the dance event.
* **Event Start Time** (`time`, required/optional): Select the start time of the dance event.
* **Event End Date** (`date`, required/optional): Select the end date of the dance event.
* **Event End Time** (`time`, required/optional): Select the end time of the dance event.
* **Rehearsal Start Date** (`date`, required/optional): Enter the start date of the rehearsal.
* **Rehearsal Start Time** (`time`, required/optional): Enter the start time of the rehearsal.
* **Rehearsal End Date** (`date`, required/optional): Enter the end date of the rehearsal.
* **Rehearsal End Time** (`time`, required/optional): Enter the end time of the rehearsal.
* **Dance Style** (`select_one`, required/optional): Choose the dance style for the event (Ballet, Contemporary, Hip Hop, Jazz, Modern, Other).
* **Rehearsal Attendance** (`select_multiple`, required/optional): Indicate if you plan to attend the rehearsal (True, False, maybe).
* **Event Attendance** (`select_multiple`, required/optional): Indicate if you plan to attend the event (True, False, maybe).
* **Note** (`note`, required/optional): Enter any additional notes.
* **Assigned To** (`text`, required/optional): Assign the form to a specific staff member.

## Tips

* Ensure all required fields are completed to avoid missing any essential information.
* Double-check the form's fields for accuracy and completeness.
* If you have any doubts or questions, please contact the event management team.
* This form is designed to be completed in a clear and concise manner.
