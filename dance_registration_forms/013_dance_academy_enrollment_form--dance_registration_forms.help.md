# Dance Academy Enrollment Form - Help Guide
## Purpose
This form is designed to collect essential information about a student and their class preferences for the dance academy.

## How To Complete This Form
To complete this form, please fill in the required fields and select relevant options for each section. Make sure to double-check your information before submitting the form.

## Field-by-Field Explanation

* **Student Name** (`student_name`, `text`, required): Enter the student's full name as it appears on their official documents.
* **Email** (`email`, `email`, required): Please enter a valid email address for the student.
* **Phone** (`phone`, `text`, optional): Enter the student's phone number, if applicable.
* **Birth Date** (`birth_date`, `date`, optional): Select the student's birth date (if known).
* **Class Level** (`class_level`, `select_one`, required): Choose the student's class level.
* **Class Frequency** (`class_frequency`, `select_multiple`, required): Select all applicable class frequencies for the student.
* **Emergency Contact First Name** (`emergency_contact_first_name`, `text`, required): Enter the first name of the student's emergency contact.
* **Emergency Contact Last Name** (`emergency_contact_last_name`, `text`, required): Enter the last name of the student's emergency contact.
* **Emergency Contact Phone** (`emergency_contact_phone`, `text`, optional): Enter the student's emergency contact phone number, if applicable.
* **Class Interest** (`class_interest`, `select_one`, required): Choose the student's class interest.
* **Parent/Guardian Consent** (`student_parent_consent`, `select_one`, required): Select whether the parent/guardian provides consent for the student to participate.
* **Additional Information** (`additional_info`, `note`, optional): Enter any additional information about the student.
* **Student's dietary restrictions** (`student_diet_restrictions`, `select_one`, optional): Select any dietary restrictions the student may have.
* **Student's Medical Info** (`student_medical_info`, `select_one`, optional): Select any medical information about the student.
* **Student's Allergies** (`student_allergies`, `select_multiple`, optional): Select any allergies the student may have.
* **Teacher's Name** (`teacher_name`, `text`, required): Enter the teacher's name.
* **Teacher's Email** (`teacher_email`, `email`, required): Enter the teacher's email address.
* **Teacher's Phone** (`teacher_phone`, `text`, optional): Enter the teacher's phone number, if applicable.
* **Class Start Date** (`class_start_date`, `date`, optional): Select the class start date.
* **Teacher Experience** (`teacher_experience`, `select_multiple`, optional): Select the teacher's experience.
* **Teacher's Degree** (`teacher_degree`, `select_one`, optional): Select the teacher's degree.
* **Teacher Certifications** (`teacher_certifications`, `select_multiple`, optional): Select the teacher's certifications.
* **Class End Date** (`class_end_date`, `date`, optional): Select the class end date.
* **Class Duration** (`class_duration`, `number`, required): Enter the class duration in hours.
* **Student ID** (`student_id`, `text`, required): Enter a unique student ID.
