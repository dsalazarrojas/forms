# open_day_appointment_scheduling - Help Guide
## Purpose
This form is for scheduling an open day appointment.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the required fields:
	* Guest name: Enter the name of the guest.
	* Guest email: Enter the email address of the guest.
	* Tour id: Enter the ID of the tour.
	* Event date: Select the date of the event.
	* Event time: Select the time of the event.
	* Guest phone: Enter the phone number of the guest.
2. The optional fields are:
	* First page: This is the first page of the form. It can be left blank.
	* Campus: This field is not required but can be used to specify the campus.
	* Event notes: This field is optional and can be used to add any additional notes about the event.

## Field-by-Field Explanation
- **Guest name (guest_name)**: Enter the name of the guest.
- **Guest email (guest_email)**: Enter the email address of the guest.
- **Tour id (tour_id)**: Enter the ID of the tour.
- **Event date (event_date)**: Select the date of the event.
- **Event time (event_time)**: Select the time of the event.
- **Guest phone (guest_phone)**: Enter the phone number of the guest.
- **First page (first_page)**: This is the first page of the form. It can be left blank.
- **Campus (campus)**: This field is optional and can be used to specify the campus.
- **Event notes (event_notes)**: This field is optional and can be used to add any additional notes about the event.
- **Time slot (time_slot)**: This field is not required but can be used to specify a preferred time slot for the appointment.
