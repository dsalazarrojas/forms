# science_center_tour_reservation_form - Help Guide
## Purpose
This form is for scheduling a Science Center tour. The information collected will be used to ensure that each tour is properly scheduled and that all necessary details are available.

## How To Complete This Form

* To complete this form, follow these steps:
1. Fill in all required fields marked with an asterisk (*).
2. Ensure that all information is accurate and up-to-date.
3. Check for any errors before submitting the form.

## Field-by-Field Explanation
* **tour_details**: 
	+ A short description of the tour you would like to schedule.
	+ Please keep this brief and concise.
* **school_name**:
	+ The name of the school visiting the Science Center.
	+ Make sure to spell it correctly.
* **date**:
	+ The date of the tour.
	+ Use the format `MM/DD/YYYY`.
* **start_time**:
	+ The start time of the tour.
	+ Use 12-hour time format (e.g., `09:00 AM`).
* **end_time**:
	+ The end time of the tour.
	+ Use 12-hour time format (e.g., `05:00 PM`).
* **number_students**:
	+ The total number of students in the tour group.
	+ Please enter a whole number.
* **contact_person**:
	+ The person responsible for contacting you or your school about the tour.
	+ Enter their name and title (e.g., `Ms. Smith, Teacher`).
* **phone**:
	+ The phone number of the contact person.
	+ Please use the international format (e.g., `123-456-7890`).
* **email**:
	+ The email of the contact person.
	+ Please use a valid email format (e.g., `john.doe@example.org`).
* **reservation_note**:
	+ Any additional information about the tour or your school.
	+ This is an optional field, but can be useful for the Science Center staff.
* **confirmation**:
	+ Indicate whether you have confirmed with your school about this tour.
	+ Select 'Yes' or 'No' from the dropdown list.
* **group_type**:
	+ Indicate whether this is a group tour or not.
	+ Select 'Yes' or 'No' from the dropdown list.
