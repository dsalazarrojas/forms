# Employee Holiday Gift Order Form - Help Guide
## Purpose
The Employee Holiday Gift Order Form is a tool used to order holiday gifts for employees, allowing them to choose their preferred gift and ensuring that the gifts are assigned and distributed correctly.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in your First Name and Last Name in the respective fields.
2. Select your preferred gift from the Gift Choice field.
3. Enter your Email address (if you have one).
4. Enter your Phone number.
5. Optionally, add any additional notes in the Note field.
6. Select the Date and Time for the gift to be delivered.
7. Choose the Category and Category 2 for the gift.
8. Select whether the gift will be assigned or not in the Assigned Form ID and Assigned Form IDs fields.
9. Choose the Assigned Tool and Assigned Tool 2.
10. Select the Category 3 and Category 4 for the gift.
11. Optionally, add a Description and Description 2 for the gift.
12. Finally, review your form before submitting it.

## Field-by-Field Explanation

* **First Name** (`first_name`, text, required): Enter your first name.
* **Last Name** (`last_name`, text, required): Enter your last name.
* **Gift Choice** (`gift`, select_multiple, required): Select the gift you prefer from the provided options.
* **Email** (`email`, email, optional): Enter your Email address (if you have one).
* **Phone** (`phone`, text, required): Enter your Phone number.
* **Note** (`note`, note, optional): Add any additional notes for the gift.
* **Date** (`date`, date, required): Select the Date for the gift to be delivered.
* **Time** (`time`, time, optional): Select the Time for the gift to be delivered.
* **Assigned Tool** (`assigned_tool`, select_one, required): Choose the tool for the gift.
* **Category** (`category`, select_multiple, required): Select the category for the gift.
* **Category 2** (`category2`, select_multiple, required): Select the category 2 for the gift.
* **Assigned Form ID** (`assigned_form_id`, number, optional): This field will display the ID of any existing order for the same employee.
* **Category 3** (`category3`, select_multiple, required): Select the category 3 for the gift.
* **Time 2** (`time2`, time, optional): Select the Time 2 for the gift.
* **Assigned Tool 2** (`assigned_tool2`, select_one, required): Choose the tool for the gift.
* **Description** (`description`, note, optional): Add a description for the gift.
* **Assigned Form ID 2** (`assigned_form_id2`, number, optional): This field will display the ID of any existing order for the same employee.
* **Assigned Form IDs 2** (`assigned_form_ids2`, select_multiple, optional): Select whether the gift will be assigned or not.
* **Category 4** (`category4`, select_multiple, required): Select the category 4 for the gift.
* **Description 2** (`description2`, note, optional): Add a description for the gift.
* **Assigned Form ID 2** (`assigned_form_id2`, number, optional): This field will display the ID of any existing order for the same employee.
* **Output File** (`output_file`, text, optional): This field is not currently in use.
* **Note 2** (`note2`, note, optional): Add any additional notes for the gift.
* **Date 2** (`date2`, date, optional): Select the Date 2 for the gift to be delivered.

This guide will help you complete the form correctly and avoid any confusion. If you have any questions or concerns, please refer to this guide or contact the human resources department.
