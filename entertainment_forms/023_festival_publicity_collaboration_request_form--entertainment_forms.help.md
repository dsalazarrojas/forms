# Festival Publicity Collaboration Request Form - Help Guide
## Purpose
This form is designed to request collaboration with a publicity team or media partner for a festival. It gathers essential information about the event and seeks feedback on collaboration requests and proposals.

## How To Complete This Form

To complete this form, follow these steps:

1. Enter the event title in the "event title" field.
2. Provide the event dates and location in their respective fields.
3. Add a description of the event in the "event description" field.
4. Specify the media and promotional proposals in their respective fields.
5. Upload a publicity image.
6. Indicate whether collaboration is requested in the "publicity collaboration request" field.
7. Check your collaboration response and media, promotional, and image proposal responses accordingly.
8. Add any comments regarding the request in the "publicity collaboration request form comments" field.

## Field-by-Field Explanation

* **Festival Publicity Collaboration Request** (`festival_publicity_collaboration_request_form_1`): A short description of the festival.
* **Event Title** (`event_title`): Enter the title of the festival or event.
* **Event Dates** (`event_dates`): Enter the dates of the festival or event.
* **Event Time** (`event_time`): Enter the start and end time of the festival or event.
* **Event Description** (`event_description`): Provide a brief description of the festival or event.
* **Media Proposal** (`media_proposal`): Suggest media coverage for the festival, such as press releases, interviews, or social media promotion.
* **Promotional Proposal** (`promotional_proposal`): Suggest promotional ideas, such as advertising, social media posts, or influencer partnerships.
* **Publicity Image** (`publicity_image`): Upload a publicity image or logo for the festival.
* **Event Location** (`event_location`): Enter the location of the festival or event.
* **Event Type** (`event_type`): Indicate the type of event or festival.
* **Event Organizer** (`event_organizer`): Enter the name of the event organizer or contact person.
* **Contact Details** (`contact_details`): Provide contact information for the event organizer or team.
* **Publicity Collaboration Request** (`publicity_collaboration_request`): Check if collaboration is requested.
* **Publicity Collaboration Response** (`publicity_collaboration_response`): Check if a collaboration response is provided.
* **Media Proposal Response** (`media_proposal_response`): Check if media proposal response is provided.
* **Promotional Proposal Response** (`promotional_proposal_response`): Check if promotional proposal response is provided.
* **Publicity Image Response** (`publicity_image_response`): Check if publicity image response is provided.
* **Publicity Collaboration Request Form Comments** (`publicity_collaboration_request_form_comments`): Add any comments about the collaboration request.
* **Publicity Collaboration Request Form 3** (`publicity_collaboration_request_form_3`): Check if a third option is provided for publicity collaboration.
* **Publicity Collaboration Request Form 4** (`publicity_collaboration_request_form_4`): Leave blank for comments. This field is not necessary but is left here to match the original form structure.
* **Publicity Collaboration Request Form 5** (`publicity_collaboration_request_form_5`): Check if a fifth option is provided for publicity collaboration.
