# Troupe Information Collection Form - Help Guide
## Purpose
This form is designed to collect information about a troupe for various purposes, such as event management, marketing, or organizational needs.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the **Troupe Name**, which should be the name of the performing troupe.
2. Provide a **Troupe Description**, which should give a brief overview of the troupe's style, genre, or type of performance.
3. Select the **Troupe Type** from the provided options (e.g., Theatrical, Acrobatic, Juggling, or Other).
4. Enter the **Main Contact** information, including the **Contact Title** and **Contact EMail**.
5. Enter the **Contact Phone** number of the main contact person.
6. Provide the **Troupe Venue** where the troupe performs.
7. Enter the **Troupe Performance Dates** in the required format (e.g., YYYY-MM-DD).
8. Enter the **Troupe Performance Time** in the required format (e.g., HH:MM AM/PM).
9. Enter the **Troupe Performance Length** in the required format (e.g., number of minutes or hours).

## Field-by-Field Explanation

* **Troupe Name**: Enter the name of the performing troupe.
* **Troupe Description**: Provide a brief overview of the troupe's style, genre, or type of performance.
* **Troupe Type**: Select the type of performance (e.g., Theatrical, Acrobatic, Juggling, or Other).
* **Main Contact**: Enter the contact information of the main person responsible for the troupe.
* **Contact Title**: Enter the title of the main contact person.
* **Contact EMail**: Enter the email address of the main contact person.
* **Contact Phone**: Enter the phone number of the main contact person.
* **Troupe Venue**: Enter the location where the troupe performs.
* **Troupe Performance Dates**: Enter the dates of the performance in the required format (e.g., YYYY-MM-DD).
* **Troupe Performance Time**: Enter the time of the performance in the required format (e.g., HH:MM AM/PM).
* **Troupe Performance Length**: Enter the length of the performance in the required format (e.g., number of minutes or hours).
* **Troupe Agreement**: Enter any relevant agreements or terms associated with the troupe.
* **Troupe Performance Location**: Enter the location where the troupe performs (note: this field might be redundant with the **Troupe Venue** field, but it's included for consistency).
