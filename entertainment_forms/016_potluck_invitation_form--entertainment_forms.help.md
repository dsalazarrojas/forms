# potluck_invitation_form - Help Guide
## Purpose
The potluck_invitation_form is designed to help host a potluck event by gathering essential information about the event and its participants.

## How To Complete This Form
To complete this form, simply fill out the fields as instructed below.

## Field-by-Field Explanation
- **Potluck Invitation** (`event_title`, text, optional): Enter a brief description of the potluck event.
- **Date** (`event_date`, date, optional): Enter the date of the potluck event.
- **Time** (`event_time`, time, optional): Enter the time of the potluck event.
- **Location** (`location`, text, optional): Enter the location of the potluck event.
- **Host Name** (`host_name`, text, optional): Enter the name of the person hosting the potluck.
- **Host Phone** (`host_phone`, text, optional): Enter the phone number of the person hosting the potluck.
- **Potluck Items** (`items`, select_multiple, optional): Choose which potluck items you will be bringing (yes/no).
  - Baked Goods
  - Finger foods
  - Drinks
  - Sides
  - Desserts
  - Main Course
  - Salads
  - Casseroles
  - Miscellaneous
- **Additional Message** (`message`, text, optional): Enter any additional message for the host.
- **Guest Name** (`guest_name`, text, optional): Enter the name of the guest attending the potluck.
- **Guest E-mail** (`guest_email`, email, optional): Enter the email of the guest attending the potluck.
- **Guest Phone** (`guest_phone`, text, optional): Enter the phone number of the guest attending the potluck.
- **RSVP** (`rsvp`, select_one, optional): Choose how the guest will RSVP (Attending, Not Attending, Undecided).
- **Special Notes** (`notes`, note, optional): Enter any special notes for the host.
- **Specialty Items** (`item10`, select_multiple, optional): Choose which specialty items you will be bringing (yes/no).
  - Yes
  - No
- **Potluck Theme** (`item11`, select_multiple, optional): Choose which potluck theme you will be using (yes/no).
  - Yes
  - No
- **Event Theme** (`item12`, select_multiple, optional): Choose which event theme you will be using (yes/no).
  - Yes
  - No
