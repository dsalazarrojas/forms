# DJ Request Form - Help Guide
## Purpose
The DJ Request Form is a tool for users to request a music event or performance. This form is intended for event planners to gather specific information from users about the type of music desired, details about the event, and other relevant data.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the title of the song you are requesting.
2. Enter the name of the artist performing the song.
3. Provide a brief description of why you are requesting this song.
4. Select the type of event or performance you are requesting this song for.
5. Enter a valid email address.
6. Enter a valid phone number.
7. If you have any additional comments or notes, please add them below.
8. Select whether a specific tool or equipment should be assigned to this event.
9. Optionally, provide a category for the event or performance (e.g., Entertainment).
10. Optionally, select any other relevant categories for the event or performance.
11. Optionally, provide a description of the event or performance.

## Field-by-Field Explanation

* **song_title (Text, Required)**: Enter the title of the song you are requesting.
* **artist (Text, Required)**: Enter the name of the artist performing the song.
* **song_requesting (Text, Required)**: Provide a brief description of why you are requesting this song.
* **event_type (Text, Required)**: Select the type of event or performance you are requesting this song for.
* **event_name (Text, Optional)**: Optionally, enter a brief description of the event or performance.
* **email (Email, Required)**: Enter a valid email address.
* **phone (Text, Required)**: Enter a valid phone number.
* **note (Text, Optional)**: If you have any additional comments or notes, please add them below.
* **assigned_tool (Select One, Required)**: Select whether a specific tool or equipment should be assigned to this event.
* **form_id (Number, Optional)**: Optionally, enter a unique identifier for this event or performance.
* **category (Select Multiple, Required)**: Optionally, select the category or categories for the event or performance (e.g., Entertainment).
* **description (Select Multiple, Optional)**: Optionally, provide a description of the event or performance, selecting from the available options.

## Tips

* Please ensure that all required fields are completed before submitting the form.
* Enter valid and accurate information to help the event planners plan the event effectively.
* If you have any questions or need assistance, please contact the event planning team.
