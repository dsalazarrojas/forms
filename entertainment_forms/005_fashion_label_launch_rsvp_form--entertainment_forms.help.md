# Fashion Label Launch RSVP Form - Help Guide

## Purpose
The Fashion Label Launch RSVP Form is a simple, one-page form designed for users to respond to a fashion event invitation. It gathers event details, RSVP status, guest information, and other relevant event-specific data.

## How To Complete This Form

1. **Event Details** (`event_details`, text, required): 
   This section is for users to provide the name of the event they are attending.
2. **RSVP Details** (`rsvp_details`, text, required): 
   This is where users can add any additional information about their RSVP, such as their table preferences or other specific requests.
3. **Guest Info** (`guest_info`, text, required): 
   Enter the names and contact information of the guests you are bringing, if any.
4. **RSVP Status** (`rsvp_status`, select_one, required): 
   Choose how you plan to attend the event - Attending, Not Attending, or Maybe.
5. **RSVP Comment** (`rsvp_comment`, text, optional): 
   Provide any additional comments about your RSVP.
6. **Email** (`email`, email, optional): 
   Enter your email address if you provide it, for event communication purposes.
7. **Phone** (`phone`, text, optional): 
   Enter your phone number if you want to be contacted for any last-minute changes or information.
8. **RSVP By** (`rsvp_by`, date, optional): 
   Enter the date you will be responding to this RSVP by.
9. **Event Time** (`event_time`, time, optional): 
   Choose the time of the event for reference.
10. **Event Date** (`event_date`, date, optional): 
   Select the date of the event for reference.

## Tips
- Be sure you are responding to a fashion event invitation.
- Provide accurate event details for easy event management.
- Fill out all relevant fields, but only those that are required.
- Use a valid email and phone number for event communication, if needed.
- RSVP by the specified date for accurate planning.

Please review the form carefully before submitting your RSVP response.
