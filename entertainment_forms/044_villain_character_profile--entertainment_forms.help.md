# Villain Character Profile - Help Guide
## Purpose
This form is designed to collect information about a villain character. It is used to gather data about their name, age, occupation, superpowers, weaknesses, motivations, lair, and goals.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the character's first name in the `first_name` field.
2. Enter the character's last name in the `last_name` field.
3. Enter the character's age in the `age` field.
4. Select the character's occupation from the available options in the `occupation` field.
5. Enter the character's height in the `height` field.
6. Enter the character's weight in the `weight` field.
7. Enter the character's evil laugh in the `evil_laugh` field.
8. Select the character's superpowers from the available options in the `superpowers` field.
9. Select the character's weaknesses from the available options in the `weaknesses` field.
10. Select the character's motivations from the available options in the `motivations` field.
11. Select the character's lair location from the available options in the `lair` field.
12. Select the character's ultimate goal from the available options in the `goal` field.

## Field-by-Field Explanation

* **First Name** (`first_name`, text, optional): Enter the character's first name.
* **Last Name** (`last_name`, text, optional): Enter the character's last name.
* **Age** (`age`, number, optional): Enter the character's age.
* **Occupation** (`occupation`, select_one, optional): Select the character's occupation from the available options (actor, actress, musician).
* **Height** (`height`, number, optional): Enter the character's height.
* **Weight** (`weight`, number, optional): Enter the character's weight.
* **Evil Laugh** (`evil_laugh`, text, optional): Enter a description of the character's evil laugh.
* **Superpowers** (`superpowers`, select_multiple, optional): Select the character's superpowers from the available options (telepathy, telekinesis, mind control).
* **Weaknesses** (`weaknesses`, select_multiple, optional): Select the character's weaknesses from the available options (weakness1, weakness2, weakness3).
* **Motivations** (`motivations`, select_multiple, optional): Select the character's motivations from the available options (power, revenge, chaos).
* **Lair** (`lair`, select_one, optional): Select the character's lair location from the available options (underground, fortress).
* **Goal** (`goal`, select_one, optional): Select the character's ultimate goal from the available options (world Domination, wealth, destruction).
