# Talent Appearance And Liability Form - Help Guide
## Purpose
The Talent Appearance And Liability Form is designed to collect information about a talent's appearance at an event. This includes the event name, date, time, location, and contact details.

## How To Complete This Form
1. Fill out the form in a clear and accurate manner.
2. Ensure that you have all the required information before submitting the form.
3. If you are unsure about any field, please refer to the field-by-field explanation section for clarification.

## Field-by-Field Explanation

* **Event Name** (text, required): Enter the name of the event where the talent will be appearing.
* **Date of Event** (date, required): Enter the date of the event in YYYY-MM-DD format (e.g., 2024-02-15).
* **Time of Event** (time, optional): Enter the time of the event if applicable.
* **Event Location** (text, optional): Enter the address of the event location.
* **Event Type** (text, optional): Enter a brief description of the type of event (e.g., concert, conference, etc.).
* **Talent Name** (text, optional): Enter the name of the talent appearing at the event.
* **Contact Number** (text, optional): Enter the contact number of the talent or representative.
* **Email Address** (email, required): Enter the email address of the talent or representative so we can contact them.
* **Signature** (text, optional): This is an optional field for adding any additional comments or information.
* **Consent** (select_one, required): Agree to the terms of the form by selecting one of the options provided.

## Tips
- Double-check all the fields for accuracy before submitting the form.
- If you need to make any changes to the form, please contact the event organizers for assistance.
- The information collected through this form will be used for event management purposes only.
