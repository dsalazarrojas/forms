# Playwriting Program Application - Help Guide
## Purpose

The Playwriting Program Application form is designed to gather information from applicants who wish to participate in the playwriting program. The form is used to assess the applicant's eligibility for the program.

## How To Complete This Form

To complete this form, please follow the steps below:

1. Fill in the required and optional fields as indicated in the form.
2. For multiple-choice fields, select the relevant options from the list.
3. Ensure that all required fields are completed before submitting the form.

## Field-by-Field Explanation

* **Playwright Details** (`playwright_details`, `text`, required: false)
This field allows you to provide a brief description of yourself as a playwright.
* **Writing Samples** (`writing_samples`, `select_multiple`, required: false)
Select the types of writing samples you have (e.g., plays, screenplays, etc.).
* **Workshop Labs** (`workshop_labs`, `select_one`, required: false)
Select whether you have experience in workshop labs (yes/no).
* **Motivation** (`motivation`, `text`, required: false)
Explain why you are interested in participating in the playwriting program.
* **Organization Type** (`organization_type`, `select_one`, required: false)
Select the type of organization you are affiliated with (e.g., theater company, school, etc.).
* **Theater Type** (`theater_type`, `select_one`, required: false)
Select the type of theater you are interested in (e.g., classical, modern, etc.).
* **School Type** (`school_type`, `select_one`, required: false)
Select the type of school you are interested in (e.g., primary, secondary, etc.).
* **Arts Organization** (`arts_organ`, `select_one`, required: false)
Select whether you are affiliated with an arts organization (yes/no).
* **Workshop Labs Details** (`workshop_labs_details`, `select_multiple`, required: false)
Select the specific workshop labs you have participated in (e.g., writing workshops, etc.).

## Tips

* Ensure that you provide accurate and detailed information in the form.
* Double-check the required fields before submitting the form.
* If you have any questions or concerns, please contact the program administrators for assistance.
