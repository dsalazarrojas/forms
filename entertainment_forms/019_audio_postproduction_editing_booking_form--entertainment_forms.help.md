# Audio Postproduction Editing Booking Form - Help Guide
## Purpose
This form is used to book audio postproduction editing services with our company. It is designed to collect necessary information from the client to ensure a smooth booking process.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill in your contact information, including your full name, email address, and phone number.
2. Provide details about your project, including the title, type, length, and format.
3. Select the services you need for your project.
4. Choose the current stage of your project.
5. Select the format of your source footage and audio.
6. Provide a preferred start date and deadline for the project.
7. Choose the delivery format for your final project.
8. Indicate the expected number of revision rounds.
9. Select your estimated budget for the project.
10. Add any special requirements or notes.
11. Optionally, let us know how you found our services.
12. Provide any additional comments or information.

## Field-by-Field Explanation
### 1. Client Full Name
* **Client Full Name**: Enter your full name as it should be displayed on our communication.
* **Type:** Text
* **Required:** Yes

### 2. Email Address
* **Email Address**: Enter your contact email address.
* **Type:** Email
* **Required:** Yes

### 3. Phone Number
* **Phone Number**: Enter your contact phone number.
* **Type:** Text
* **Required:** Yes

### 4. Company Name (Optional)
* **Company Name**: If applicable, enter the name of your production company or studio.
* **Type:** Text
* **Required:** No

### 5. Booking Date
* **Booking Date**: Enter the date of this booking request.
* **Type:** Date
* **Required:** Yes

### 6. Project Title
* **Project Title**: Enter the name or working title of your project.
* **Type:** Text
* **Required:** Yes

### 7. Project Type
* **Project Type**: Select the type of project (e.g., Film, Television, Documentary, etc.).
* **Type:** Select One
* **Required:** Yes

### 8. Project Length
* **Project Length**: Select the approximate runtime of your project (e.g., Under 5 minutes, 5-15 minutes, etc.).
* **Type:** Select One
* **Required:** Yes

### 9. Editing Services Needed
* **Editing Services Needed**: Select all services required for your project (e.g., Dialogue Editing, ADR Editing, etc.).
* **Type:** Select Multiple
* **Required:** Yes

### 10. Current Stage
* **Current Stage**: Select the current stage of your project (e.g., Pre-production, Principal photography, etc.).
* **Type:** Select One
* **Required:** Yes

### 11. Footage Format
* **Footage Format**: Select the format of your source footage (e.g., 4K UHD, 1080p HD, etc.).
* **Type:** Select One
* **Required:** Yes

### 12. Audio Format
* **Audio Format**: Select the format of your source audio (e.g., Stereo, 5.1 Surround, etc.).
* **Type:** Select One
* **Required:** Yes

### 13. Preferred Start Date
* **Preferred Start Date**: Enter the date when you prefer editing to begin.
* **Type:** Date
* **Required:** Yes

### 14. Deadline
* **Deadline**: Enter the final delivery deadline.
* **Type:** Date
* **Required:** Yes

### 15. Delivery Format
* **Delivery Format**: Select the required delivery format for your final project (e.g., Pro Tools Session, OMF, etc.).
* **Type:** Select One
* **Required:** Yes

### 16. Revision Rounds
* **Revision Rounds**: Indicate the expected number of revision rounds.
* **Type:** Select One
* **Required:** Yes

### 17. Budget Range
* **Budget Range**: Select your estimated budget for the project.
* **Type:** Select One
* **Required:** Yes

### 18. Special Requirements
* **Special Requirements**: Add any specific requirements or notes.
* **Type:** Text
* **Required:** No

### 19. How Did You Hear About Us
* **How Did You Hear About Us**: Select how you found our services (e.g., Referral, Website, etc.).
* **Type:** Select One
* **Required:** No

### 20. Additional Comments
* **Additional Comments**: Add any other information you want to share.
* **Type:** Text
* **Required:** No
