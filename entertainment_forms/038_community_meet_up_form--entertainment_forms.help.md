# Community Meet Up Form - Help Guide
## Purpose
This form is used to collect information from attendees for a community meetup event. Fill out this form to sign up for the event and share your preferences with the organizers.

## How To Complete This Form
To complete this form, follow these steps:
1. Enter your Attendee name in the **Attendee name** field.
2. Provide your **Email address** if you'd like to receive updates from the group.
3. Enter your **Phone number** if you'd like to be contacted for last-minute updates.
4. Select the date of the event from the calendar in the **Event date** field.
5. List the **Topics of interest** you'd like to discuss.
6. Choose whether you'll be bringing **materials to share**.
7. Specify any **Accessibility needs** you have.
8. Select **Consent to be photographed** to allow event photos to be taken.
9. Add any **Additional comments** you'd like to share with the organizers.

## Field-by-Field Explanation
* **Meet Up Details --** (`meetup_header`,  note, required: false): This is a heading for the form.
* **Attendee name** (`attendee_name`, text, required: true): Enter your full name for check-in purposes.
* **Email address** (`email`, email, required: false): Optional for group updates.
* **Phone number** (`phone`, text, required: false): Optional for last-minute updates.
* **Event date** (`event_date`, date, required: true): Select the date of the event.
* **Topics of interest** (`topics_of_interest`, text, required: false): List the topics you'd like to discuss.
* **Will you bring materials to share?** (`bring_materials`, select_one, required: false): Choose whether you'll be bringing materials to share.
* **Accessibility needs** (`accessibility_needs`, text, required: false): Specify any accommodations you require.
* **Consent to be photographed** (`consent_to_photo`, select_one, required: false): Agree to have event photos taken for group use.
* **Additional comments** (`additional_comments`, text, required: false): Share any additional information with the organizers.
