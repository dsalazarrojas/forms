# Narrator Selection Form - Help Guide
## Purpose
This form is designed to collect information about a narrator's profile, including their role, background, and contact details.

## How To Complete This Form

To complete this form, please follow these steps:

1. Fill in the blanks with the required and optional information about the narrator.
2. Select the relevant options for each field from the provided choices.
3. Provide any additional information you feel is necessary in the text fields.
4. Review your answers carefully before submitting the form.

## Field-by-Field Explanation

* **Author (1)**: Enter the name of the narrator.
* **Book Type (2)**: Select the type of book this narrator is for (e.g., Book, Audiobook, E-book).
* **Narrator Type (3)**: Select the type of narrator you are looking for (e.g., Male, Female, Male and Female).
* **Language (4)**: Select the language spoken by the narrator.
* **Accent (5)**: Enter the narrator's accent (e.g., neutral, American, British).
* **Experience Level (6)**: Select the narrator's experience level (e.g., High School, College, University, Postgraduate).
* **Education Level (7)**: Select the narrator's education level (e.g., High School, College, University, Postgraduate).
* **Contact Info (8)**: Select the contact method you prefer (e.g., Email, Phone, Skype, Other).
* **Bio (9)**: Provide a brief description of the narrator's background and qualifications.
