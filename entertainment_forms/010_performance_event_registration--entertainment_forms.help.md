# Performance Event Registration - Help Guide
## Purpose

The Performance Event Registration form is used to register details about a performance event, such as a concert, dance recital, or other performance-based event. This form helps event planners provide essential information about the event, including the event's schedule, location, and required skills.

## How To Complete This Form

To complete this form, follow these steps:

1. Fill out the "Event Planners Name" field with the name of the person responsible for the event.
2. Enter the "Venue Name" where the event will take place.
3. Provide "Performance Details" in the note field, including any relevant information about the event, such as the type of performance and the expected duration.
4. List the "Required Skills" needed for the event (e.g., singer, dancer, performer).
5. Select the "Preferred Date" for the event from the available dates.
6. Enter the start and end times for the event in the "Start Time" and "End Time" fields.
7. Specify the "Duration" of the event in hours.
8. Add any additional "Requirements" for the event in the note field.
9. Finally, enter the "Contact Phone" number for the event planner or contact person.

## Field-by-Field Explanation

* **Event Planners Name** (event_planner_name): Enter the name of the person responsible for planning the event.
* **Venue Name** (venue_name): Enter the name of the venue where the event will take place.
* **Performance Details** (performance_details): Provide a brief description of the event, including the type of performance and expected duration.
* **Required Skills** (required_skills): List the skills required for the event (e.g., singer, dancer, performer).
* **Preferred Date** (preferred_date): Select the date you prefer the event to take place. Note: If the date is not available, please choose the closest date.
* **Available Date** (available_date): This field is for informational purposes only and does not affect the event's acceptance. Please choose a date that works for you.
* **Start Time** (start_time): Enter the start time of the event in 24-hour format (e.g., 14:00).
* **End Time** (end_time): Enter the end time of the event in 24-hour format (e.g., 16:00).
* **Duration** (duration): Specify the duration of the event in hours.
* **Requirements** (requirements): Add any additional requirements or notes about the event.
* **Contact Phone** (contact_phone): Enter the phone number of the event planner or contact person.

## Tips

* Be sure to double-check the "Available Date" field to avoid registering duplicate events.
* If you're unsure about any of the fields, please ask the event planner or contact person for clarification.
