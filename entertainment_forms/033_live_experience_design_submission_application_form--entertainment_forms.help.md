# Live Experience Design Submission Application Form - Help Guide
## Purpose
The Live Experience Design Submission Application Form is designed to collect essential information about live experiences, including festivals, events, activations, and installations. This form is intended to provide clear and concise details about a submission.

## How To Complete This Form

To complete this form, follow these steps:

1. Start by providing a title for your submission.
2. Next, fill out the project details section.
3. In the main event description section, enter a brief description of your live experience.
4. Provide team information, including team name, team members, and team lead.
5. Enter event location details, including latitude and longitude.
6. Select the event type (festival, event, activation, or installation).
7. Enter the event's start and end dates.
8. Enter the budget for your live experience.
9. Select the event category.
10. Enter the event status.
11. Select additional documents to be submitted.

## Field-by-Field Explanation

* **Project Details (Project Details, id: 1)**: Enter a concise title and brief description of your project.
* **Main Event Description (Main Event Description, id: 2)**: Write a brief description of your live experience.
* **Team (Team, id: 3)**: Enter the name of your team.
* **Event Location (Event Location, id: 4)**: Enter the event location, including name and address.
* **Date and Time (Date and Time, id: 5)**: Enter the date and time of the event. (Format: MM/DD/YYYY)
* **Budget (Budget, id: 6)**: Enter the budget for your live experience.
* **Event Type (Event Type, id: 7)**: Select the type of event (festival, event, activation, or installation).
* **Venue Details (Venue Details, id: 8)**: Enter venue details, if applicable.
* **Event Description (Event Description, id: 9)**: Provide a detailed description of your live experience.
* **Submission (Submission, id: 10)**: Enter your name or contact information for follow-up.
* **Contact Info (Contact Info, id: 11)**: Enter your name, email, and phone number.
* **Event Location Lat (Event Location Lat, id: 12)**: Enter the latitude of the event location.
* **Event Location Long (Event Location Long, id: 13)**: Enter the longitude of the event location.
* **Event Location Alt (Event Location Alt, id: 14)**: Enter the altitude of the event location.
* **Team Name (Team Name, id: 15)**: Enter the name of your team.
* **Team Members (Team Members, id: 16)**: Enter team members' names.
* **Team Lead (Team Lead, id: 17)**: Enter the name of your team lead.
* **Event Budget (Event Budget, id: 18)**: Enter the budget for your live experience.
* **Event Category (Event Category, id: 19)**: Select the category of your live experience.
* **Event Status (Event Status, id: 20)**: Enter the status of your event (e.g., pending, approved, etc.).
* **Event Type (Event Type, id: 21)**: Select the type of event (festival, event, activation, or installation).
* **Event Start Date (Event Start Date, id: 22)**: Enter the start date of your event. (Format: MM/DD/YYYY)
* **Event End Date (Event End Date, id: 23)**: Enter the end date of your event. (Format: MM/DD/YYYY)
* **Submission Notes (Submission Notes, id: 24)**: Enter additional notes about your submission.
* **Submission Files (Submission Files, id: 25)**: Select additional documents to submit with your application (e.g., Document 1, Document 2, etc.).

Note: This form requires submission of at least one document to be considered complete.
