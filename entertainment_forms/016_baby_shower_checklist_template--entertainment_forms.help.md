# Baby Shower Checklist Template - Help Guide

## Purpose
The Baby Shower Checklist Template is a tool for planning and organizing a baby shower. It helps event planners or hosts to gather necessary information for a successful and enjoyable celebration.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter your name and title as the event planner or host in the **Organizer name** field.
2. Select the **Date of event** field and enter the date of the baby shower.
3. Enter the **Location of the baby shower** in the **Venue** field.
4. Estimate the **Number of guests invited**.
5. Indicate if **Catering arranged** is selected or not.
6. Select all the **Decorations needed** required for the event.
7. List the **Games and activities planned** for the celebration.
8. Choose a method for **Gift tracking**.
9. Estimate the **Estimated budget** for the event.
10. Add any **Final checklist notes** that need to be confirmed.

## Field-by-Field Explanation

* **Organizer name (text)**:
	+ Required: Optional
	+ Description: Enter your name and title as the event planner or host.
* **Date of event (date)**:
	+ Required: True
	+ Description: Select the date of the baby shower.
* **Venue (text)**:
	+ Required: False
	+ Description: Enter the location of the baby shower.
* **Number of guests invited (number)**:
	+ Required: True
	+ Description: Estimate the number of guests invited.
* **Catering arranged (select_one)**:
	+ Required: False
	+ Description: Select if catering is booked.
* **Decorations needed (select_multiple)**:
	+ Required: False
	+ Description: Select all the decorations required for the event (e.g., Balloons, Banners, Tableware, Centerpieces).
* **Games and activities planned (text)**:
	+ Required: False
	+ Description: List the games and activities planned for the celebration.
* **Gift tracking method (text)**:
	+ Required: False
	+ Description: Choose a method for tracking gifts, such as a list or a specific system.
* **Estimated budget (number)**:
	+ Required: False
	+ Description: Estimate the total cost of the event.
* **Final checklist notes (note)**:
	+ Required: False
	+ Description: Add any last-minute items to confirm before the event.

## Tips
* Use the information collected in this form to ensure a smooth and enjoyable baby shower celebration.
* Review and update the form regularly to reflect changes and new details.
