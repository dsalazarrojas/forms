# Tiger Park Field Day Registration Form - Help Guide
## Purpose
This form is used to register and manage events at Tiger Park. It captures essential details about the event, the person submitting the form, and any additional information.

## How To Complete This Form
- Please fill out the form in the provided format.
- Ensure that all required fields are completed.
- Review your information carefully before submitting the form.

## Field-by-Field Explanation

* **User Information** (user_info): Enter a brief description of the event or a brief message about the event.
* **Name** (name): Enter the name of the person submitting the form.
* **Email** (email): Enter the email address of the person submitting the form.
* **Event Date** (event_date): Select the date of the event.
* **Event Time** (event_time): Select the time of the event.
* **Number of Guests** (number_of_guests): Enter the number of people attending the event.
* **Event Type** (event_type): Select the type of event (e.g., sports, music, etc.).
* **Event Venue** (event_venue): Select the location of the event.
* **Contact Number** (contact_number): Enter a contact number (phone or other) for the event.
* **Additional Information** (additional_info): Enter any additional notes about the event.
* **Form Submitted By** (form_submitted_by): Select the person submitting the form (e.g., staff member, volunteer, etc.).
* **Form Submitter Title** (form_submitted_by_title): Select the title of the person submitting the form (e.g., Mr., Mrs., etc.).
* **Form Submitter Company** (form_submitted_by_company): Select the company or organization associated with the form submitter.
* **Form Submitter Position** (form_submitted_by_position): Select the position of the person submitting the form (e.g., manager, staff, etc.).
* **Form Submitter Email** (form_submitted_by_email): Enter the email address of the person submitting the form.
* **Form Submitter Phone** (form_submitted_by_phone): Enter a phone number for the person submitting the form.
* **Form Submitter Notes** (form_submitted_by_notes): Enter any additional notes about the person submitting the form.

Note: This guide assumes that the form is intended for internal use within Tiger Park. If this is not the case, please adjust the explanation accordingly.
