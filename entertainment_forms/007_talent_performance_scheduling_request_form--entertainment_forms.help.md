# Talent Performance Scheduling Request Form - Help Guide
## Purpose
The Talent Performance Scheduling Request Form is used to request a talent to perform on a specific date and time. This form collects information about the talent's availability, fee, and other requirements to ensure a smooth event.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the talent's details, including their name, type, and description.
2. Select the date for the event.
3. Choose the time for the event.
4. Check if the talent has a fee and enter the amount.
5. Indicate if the talent has a fee and the currency it's in.
6. Select the contact details for the talent (e.g., email, phone number).
7. Check if the talent has any requirements (e.g., equipment, space).
8. Select the talent's availability (e.g., morning, afternoon, evening).
9. Enter the event location and description.

## Field-by-Field Explanation

* **Talent details**: Enter the name of the talent, which could be a person or a group.
* **Date**: Select the date on which the event will take place.
* **Time**: Choose the time of the event.
* **Talent name**: Enter the name of the talent, which could be a person or a group.
* **Talent type**: Check if the talent has performed before (Yes/No).
* **Talent description**: Enter a brief description of the talent and their performance.
* **Event date**: Select the date on which the event will take place.
* **Talent fee**: Check if the talent has a fee (Yes/No).
* **Talent fee currency**: Select the currency for the talent fee (e.g., USD, Euro).
* **Talent fee amount**: Enter the amount of the talent's fee.
* **Contact details**: Select the contact methods for the talent (e.g., email, phone number).
* **Talent requirements**: Check if the talent has any specific requirements (e.g., equipment, space).
* **Talent availability**: Select the times of day the talent is available to perform (e.g., morning, afternoon, evening).
* **Event location**: Enter the location of the event.
* **Event description**: Enter a brief description of the event.

**Tips**

* Make sure to provide accurate information about the talent's details, fee, and requirements.
* Be clear about the event date, time, and location to avoid confusion.
* Double-check the talent's availability to ensure they can perform at the requested time.
