# Custom Jingle Collaboration Form - Help Guide
## Purpose

The Custom Jingle Collaboration Form is used to gather information from collaborators on a custom jingle collaboration project.

## How To Complete This Form

To complete the form, please follow these steps:

1. Fill out the form fields with the required information.
2. Select the correct "Jingle Type" option from the dropdown menu.
3. Ensure that all required fields are filled out, and the form is submitted correctly.

## Field-by-Field Explanation

* **Form Title** (`title`, text, required/false): Enter a title for the form. While optional, it's recommended to be descriptive and relevant to the project.
* **Jingle Project Title** (`jingle_project_title`, text, required/false): Enter the title of the jingle project. This will help identify the project among others.
* **Client Name** (`client_name`, text, required/false): Enter the name of the client this project is for.
* **Project Description** (`project_description`, text, required/false): Briefly describe the project, including any relevant details or requirements.
* **Jingle Type** (`jingle_type`, select_one, required/true): Choose the type of jingle you are creating (e.g., jingle style, jingle genre, jingle trend).
* **Project Timeline** (`project_timeline`, date, required/false): Enter the project's start and end dates (optional).
* **Project Deadline** (`project_deadline`, date, required/false): Enter the project's deadline date (optional).
* **Composer Name** (`composer_name`, text, required/false): Enter the name of the composer responsible for the jingle.
* **Contact Number** (`contact_number`, text, required/false): Enter the contact number for the collaborator or composer.
* **Email** (`email`, email, required/false): Enter a valid email address for the contact.
* **Custom Jingle Collaboration Form Comments** (`custom_jingle_collaboration_form_comments`, text, required/false): Add any additional comments or notes about the project.

## Tips

* Be accurate and thorough when filling out the form.
* If unsure about any field, please consult the project manager.
* This form is for tracking and managing custom jingle collaboration projects.
