# Stage Performance Slot Extension Request Form - Help Guide
## Purpose
The Stage Performance Slot Extension Request Form is used to request an extension to a performance slot, allowing you to adjust the scheduled end time of an event or rehearsal on the stage. This form helps you request a slot extension in case you need more time to perform.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill in the required fields with your information.
2. Select the category that best describes your event or rehearsal (Festivals, Venues, or Schools).
3. Choose the specific performance requests you need (Stage Time, Backstage Area, or Technical Requirements).
4. Add any additional notes or details you'd like to share.
5. Enter your email address and phone number so we can contact you with any updates.

## Field-by-Field Explanation
* **Performance Slot ID**: This is a unique ID assigned to your event or rehearsal.
* **Performer ID**: This is a unique ID assigned to you as a performer.
* **Stage Name**: Enter the name of the stage where your performance is scheduled.
* **Start Date**: The date you would like to adjust the performance start time for.
* **End Date**: The date you would like to adjust the performance end time for.
* **Duration**: The number of minutes you need for your performance.
* **Reason**: Provide a brief explanation for why you need an extension.
* **Assigned Tool**: This field is not currently used and is for internal purposes only.
* **Category**: Select the category that best describes your event or rehearsal (Festivals, Venues, or Schools).
* **Assigned Tool**: This field is not currently used and is for internal purposes only.
* **Notes**: Add any additional details or information you'd like to share with us.
* **Email**: Enter your email address so we can contact you with any updates.
* **Phone**: Enter your phone number so we can contact you with any updates.
* **Performance Request**: Select the specific performance requests you need (Stage Time, Backstage Area, or Technical Requirements).
