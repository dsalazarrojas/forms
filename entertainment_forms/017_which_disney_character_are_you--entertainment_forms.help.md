# Which Disney Character Are You? - Help Guide

## Purpose
This form is designed to help users have fun and guess which Disney character they are based on their answers.

## How To Complete This Form

1. Answer each question to the best of your ability.
2. Select one option from each select_one field.
3. Make sure to select only one option from each select_one field.

## Field-by-Field Explanation

* **Which Disney Character Are You** (`which_disney_character_are_you`, text, optional):
	+ This field is the main question of the form. Please answer this question based on your preferences.
* **Select A Disney Character** (`select_disney_character`, select_one, optional):
	+ Please select a Disney character that you think best represents you.
* **Confirm Your Selection** (`confirm_select`, select_one, optional):
	+ This field is used to confirm your previous selection. Please select the same character that you selected in the previous question.
* **Select Nemo** (`select_nemo`, select_one, optional):
	+ Please select "Nemo" if you think you are Nemo.
* **Select Woody** (`select_woody`, select_one, optional):
	+ Please select "Woody" if you think you are Woody.
* **Select Goofy** (`select_goofy`, select_one, optional):
	+ Please select "Goofy" if you think you are Goofy.
* **Select Mickey** (`select_mickey`, select_one, optional):
	+ Please select "Mickey" if you think you are Mickey.
* **Select Tink** (`select_tink`, select_one, optional):
	+ Please select "Tink" if you think you are Tink.
* **Select Dopey** (`select_dopey`, select_one, optional):
	+ Please select "Dopey" if you think you are Dopey.
* **Select Simba** (`select_simba`, select_one, optional):
	+ Please select "Simba" if you think you are Simba.
* **Select Buzz** (`select_buzz`, select_one, optional):
