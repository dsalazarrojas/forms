# live_show_rehearsal_slot_booking_form - Help Guide
## Purpose
This form is designed for booking a live show rehearsal slot.

## How To Complete This Form
1. Select the correct show for the rehearsal slot.
2. Choose the correct rehearsal for the selected show.
3. Select the correct slot for the rehearsal.
4. Choose a date for the rehearsal.
5. Fill out the required fields (show, rehearsal, slot, date, email, phone, and notes).

## Field-by-Field Explanation
* **Production Info** (1, text, required: false): Enter any relevant production information.
* **Show Details** (2, text, required: true): Enter details about the show.
* **Rehearsal Info** (3, text, required: false): Enter any additional information about the rehearsal.
* **Slot Details** (4, text, required: true): Enter details about the slot.
* **Booking Info** (5, text, required: false): Enter any booking information.
* **Contact Info** (6, text, required: false): Enter any contact information.
* **Notes** (7, text, required: false): Add any additional notes about the rehearsal.
* **Date** (8, date, required: true): Choose a date for the rehearsal.
* **Start Time** (9, time, required: false): Select the start time of the rehearsal.
* **End Time** (10, time, required: false): Select the end time of the rehearsal.
* **Select Show** (11, select_one, required: true): Choose the show for the rehearsal slot.
* **Select Rehearsal** (12, select_multiple, required: true): Choose the rehearsal for the selected show.
* **Select Slot** (13, select_one, required: true): Choose the slot for the rehearsal.
* **Select Date** (14, select_one, required: false): Choose the date for the rehearsal.
* **Select Start Time** (15, select_one, required: false): Choose the start time of the rehearsal.
* **Select End Time** (16, select_one, required: false): Choose the end time of the rehearsal.
* **Email** (17, email, required: true): Enter a valid email address.
* **Phone** (18, text, required: true): Enter a valid phone number.
* **Address** (19, text, required: false): Enter any address.
* **Production Manager** (20, text, required: false): Enter any production manager information.
* **Production Contact** (21, text, required: false): Enter any production contact information.
* **Notes** (22, text, required: false): Add any additional notes about the rehearsal.
* **Submit** (23, text, required: false): Click to submit the form.
* **Reset** (24, text, required: false): Click to reset the form.
* **Select Show 2** (25, select_one, required: false): Choose another show for the rehearsal.
