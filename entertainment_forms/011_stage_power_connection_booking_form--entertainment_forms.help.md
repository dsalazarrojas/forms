# stage_power_connection_booking_form - Help Guide
## Purpose
The stage_power_connection_booking_form is designed for event organizers to collect information about stage power connections.

## How To Complete This Form
1. Enter the event name in the **Event Name** field.
2. Select the event date from the calendar or enter it manually in the **Event Date** field.
3. Enter the event start time in the **Event Start Time** field.
4. Enter the total number of outlets required in the **Total Outlets** field.
5. Enter the total watts drawn in the **Watts Drawn** field.
6. Enter the voltage required in the **Voltage** field.
7. Enter any additional instructions or comments in the **Instructions** field.
8. Select the event contacts (Name, Email, or Phone) that need to be contacted for the event.

## Field-by-Field Explanation
* **Event Name** (`event_name`, text, required: false): Enter the name of the event, e.g., "Concert for Charity".
* **Event Date** (`event_date`, date, required: false): Select or enter the date of the event from the calendar or manually in the format `YYYY-MM-DD`.
* **Event Start Time** (`event_start_time`, time, required: false): Enter the start time of the event in `HH:MM` format.
* **Total Outlets** (`total_outlets`, number, required: false): Enter the total number of outlets required for the event.
* **Watts Drawn** (`watts_drawn`, number, required: false): Enter the total watts drawn for the event.
* **Voltage** (`voltage`, number, required: false): Enter the required voltage for the event.
* **Instructions** (`instructions`, text, required: false): Enter any additional instructions or comments about the event.
* **Event Contacts** (`event_contacts`, select_multiple, required: false): Select one or more event contacts (Name, Email, or Phone) that need to be contacted about the event.

## Tips
* Make sure to fill out all the required fields for accurate and efficient stage power connection services.
* If you're unsure about any field, please ask your event coordinator or technical support for clarification.
* Double-check the form before submitting to avoid errors.
