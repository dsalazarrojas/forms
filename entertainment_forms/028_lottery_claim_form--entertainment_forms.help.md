# lottery_claim_form - Help Guide
## Purpose

This form is used to collect information for a lottery claim. It is intended for individuals or organizations claiming a win in a lottery.

## How To Complete This Form

To complete this form, please follow the steps below:

1. Fill out all the fields with the required information.
2. Make sure to double-check your entries for accuracy.
3. If you are unsure about any field, feel free to ask for help.

## Field-by-Field Explanation

* **Claimant Information** (`submitter_details`, text, optional):
	+ Enter any additional information about the claimant, if needed.
* **Ticket Details** (`ticket_info`, text, optional):
	+ Describe the ticket that was won.
* **Winner Confirmation** (`win_confirmation`, number, optional):
	+ Confirm if the claim is a winner or not.
* **Win Date** (`win_date`, date, optional):
	+ Enter the date of the win.
* **Win Amount** (`win_amount`, number, optional):
	+ Enter the amount won.
* **Ticket ID** (`ticket_id`, select_multiple, optional):
	+ Select 'Yes' if the ticket is valid, 'No' otherwise.
* **Ticket Type** (`ticket_type`, select_one, optional):
	+ Select 'Yes' if the ticket is of the correct type, 'No' otherwise.
* **Claim Details** (`claim_details`, text, optional):
	+ Enter any additional details about the claim.
* **Confirmation** (`confirmation`, select_one, optional):
	+ Confirm if the claim is correct or not.
* **Submitter Confirmation** (`submitter_confirmation`, select_one, optional):
	+ Confirm if the submitter is the winner or not.
* **Submit** (`submit`, select_multiple, optional):
	+ Select 'Yes' if the claim is submitted, 'No' otherwise.
* **Submitter Details** (`submitter_details`, text, optional):
	+ Enter any additional information about the submitter.
* **Submitter Information** (`submitter_info`, text, optional):
	+ Enter any additional information about the submitter.
* **Submitter Contact** (`submitter_contact`, text, optional):
	+ Enter the submitter's contact information.
* **Submitter Email** (`submitter_email`, email, optional):
	+ Enter the submitter's email address.
* **Submitter Phone** (`submitter_phone`, text, optional):
	+ Enter the submitter's phone number.

## Tips

* Make sure to fill out all required fields.
* Double-check your entries for accuracy.
* If you are unsure about any field, feel free to ask for help.
