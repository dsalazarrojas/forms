# Live Show Visual Effects Booking Form - Help Guide
## Purpose
This form is used to collect information related to live show visual effects booking.

## How To Complete This Form
- Please fill out each page of the form carefully.
- For each field, provide accurate and complete information.
- If you are unsure about any field, please leave it blank or ask for clarification from the production team.

## Field-by-Field Explanation
- **Event Details**: This field is where you can provide a brief description of the event. Please be as detailed as possible.
  - Type: text
  - Required: false

* **Event Title**: This field is for the title of the event. Please provide a short and catchy title.
  - Type: text
  - Required: false

* **Event Venue**: In this field, please provide the name and location of the venue where the event will take place.
  - Type: text
  - Required: false

* **Performer**: Please indicate if the performer is available for the event.
  - Type: select_one
  - Options: Yes, No
  - Required: false

* **Event Type**: This field indicates the type of event. Please select all that apply.
  - Type: select_multiple
  - Options: Yes, No
  - Required: false

* **Event Start**: Enter the start time of the event in 24-hour format (HH:MM).
  - Type: time
  - Required: false

* **Event Finish**: Enter the finish time of the event in 24-hour format (HH:MM).
  - Type: time
  - Required: false

* **Contact Email**: Provide the email address of the contact person for the event.
  - Type: email
  - Required: false

* **Contact Phone**: Enter the phone number of the contact person.
  - Type: text
  - Required: false

* **Event Date**: Enter the date of the event in YYYY-MM-DD format.
  - Type: date
  - Required: false

* **Equipment Details**: Provide any special equipment requirements or details for the event.
  - Type: text
  - Required: false

* **Equipment Needed**: Indicate if any special equipment is needed for the event.
  - Type: select_multiple
  - Options: Yes, No
  - Required: false

* **Special Request**: If there are any special requests or requirements for the event, please list them here.
  - Type: text
  - Required: false

* **Notes**: Any additional comments or notes about the event.
  - Type: note
  - Required: false

* **Venue Details**: Provide any additional details about the venue, such as parking information.
  - Type: text
  - Required: false

* **Venue Address**: Enter the address of the venue.
  - Type: text
  - Required: false

* **Venue City**: Enter the city of the venue.
  - Type: text
  - Required: false

* **Venue State**: Indicate if the venue is in a specific state.
  - Type: select_one
  - Options: Yes, No
  - Required: false

* **Venue Zip**: Enter the zip code of the venue.
  - Type: text
  - Required: false

* **Venue Country**: Indicate the country where the venue is located.
  - Type: select_multiple
  - Options: Yes, No
  - Required: false

* **Production Company**: Provide the name of the production company.
  - Type: text
  - Required: false

* **Production Team**: Enter the name of the production team.
  - Type: text
  - Required: false

* **Promoter**: Enter the name of the promoter.
  - Type: text
  - Required: false

* **Production Contact**: Enter the contact information for the production team.
  - Type: text
  - Required: false
