# Theater Showcase Highlight Consent Form - Help Guide
## Purpose
This guide will walk you through the steps to complete the Theater Showcase Highlight Consent Form, ensuring you understand the form's purpose and how to fill it out correctly.

## How To Complete This Form
1. Ensure that you have the necessary permissions and approvals before filling out this form.
2. Fill out the form for each participant involved in the performance or event.
3. Answer all questions honestly and accurately.

## Field-by-Field Explanation

* **Participant Name (Participant Name)** (`participant_name`, text, not required): Fill in the name of the participant who will be involved in the performance or event.
* **Participant Email (Participant Email)** (`participant_email`, email, not required): Enter the email address of the participant or their parent/guardian.
* **Parent/Guardian Name (Parent/Guardian Name)** (`parent_name`, text, not required): Fill in the name of the parent or guardian of the participant, if applicable.
* **Parent/Guardian Email (Parent/Guardian Email)** (`parent_email`, email, not required): Enter the email address of the parent or guardian, if applicable.
* **Recording Permission (recording_permission, select_multiple, not required)**:
	+ Select 'Yes' if you agree to be recorded during the performance or event.
	+ Select 'No' if you do not agree to be recorded.
	+ Select 'Maybe' if you are unsure or have questions about recording.
* **Sharing Permission (sharing_permission, select_multiple, not required)**:
	+ Select 'Yes' if you agree to share your performance or event on platforms like social media or the internet.
	+ Select 'No' if you do not agree to share.
	+ Select 'Maybe' if you are unsure or have questions about sharing.
* **Educational Use (educational_use, select_multiple, not required)**:
	+ Select 'Yes' if you agree to allow the recording to be used for educational purposes.
	+ Select 'No' if you do not agree to allow educational use.
	+ Select 'Maybe' if you are unsure or have questions about educational use.
* **Recording Date (recording_date, date, not required)**: Enter the date of the recording, in the format MM/DD/YYYY.
* **Recording Time (recording_time, time, not required)**: Enter the time of the recording, in the format HH:MM AM/PM.
* **Notes (notes, note, not required)**: Add any additional comments or notes about the recording or event.
* **Consent Date (consent_date, date, not required)**: Enter the date you gave your consent, in the format MM/DD/YYYY.
* **Assigned Tool (assigned_tool, select_one, not required)**:
	+ Select 'chatjimmy' if you are using the chatjimmy tool.
	+ Select 'Other' if you are using another tool.

## Tips
* Be sure to answer all questions honestly and accurately.
* Review your answers carefully before submitting the form.
* If you have any questions or concerns, please contact the relevant authorities or personnel.
