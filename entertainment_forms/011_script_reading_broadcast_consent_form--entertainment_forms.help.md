# Script Reading Broadcast Consent Form - Help Guide
## Purpose
The Script Reading Broadcast Consent Form is used to register individuals for a script reading broadcast. It collects their contact information and preferences for the broadcast.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill out your **Name**, **Email**, and **Phone** fields with your current and accurate information.
2. Choose the type of broadcast you wish to participate in, either **Live**, **Pre-Recorded**, or select **Other** if you have a specific preference.
3. Enter the date you are available to participate in the **Broadcast Date** field. Please use the standard date format MM/DD/YYYY.
4. Enter the time you prefer to participate in the **Broadcast Time** field. Please use the 24-hour time format HH:MM.
5. Select your **Consent** to participate in the broadcast by checking the box for **True** or **False**.

## Field-by-Field Explanation
- **Name**: Enter your full name as you would like to be listed in the script reading broadcast.
  - Type: Text field, required
  - Hint: None
- **Email**: Enter a valid email address where you can be reached for communication about the broadcast.
  - Type: Email field, required
  - Hint: None
- **Phone**: Enter your phone number where you can be reached for last-minute details.
  - Type: Text field, required
  - Hint: None
- **Broadcast Type**: Select the type of broadcast you wish to participate in.
  - Type: Select one field, required
  - Hint: Choose Live, Pre-Recorded, or Other if you have a specific preference.
- **Broadcast Date**: Enter the date you are available to participate in the script reading broadcast.
  - Type: Date field, required
  - Hint: Use the standard date format MM/DD/YYYY.
- **Broadcast Time**: Enter the time you prefer to participate in the broadcast.
  - Type: Time field, required
  - Hint: Use the 24-hour time format HH:MM.
- **Consent**: Confirm your participation in the script reading broadcast by selecting True or False.
  - Type: Select multiple field, required
  - Hint: None
