# Party Bus Quote Request Form - Help Guide
## Purpose
The Party Bus Quote Request Form is designed to gather information from customers interested in booking a party bus for a special event or celebration.

## How To Complete This Form
To complete this form, follow the instructions below:
1. Fill in the required fields (indicated by a star *).
2. Select the correct date for the event from the calendar (event_date).
3. Choose the party bus size that suits your needs (party_size).
4. Enter the pickup location and drop-off location for the event (pickup_location and drop_off_location).
5. Provide contact information (contact_name, contact_phone, and contact_email).
6. Enter any additional comments or notes about the event (additional_comments).

## Field-by-Field Explanation
* **event_details** (<em>event_details</em>, text, *): Briefly describe the purpose of the event to help us better understand your needs.
* **event_date** (<em>event_date</em>, date, *): Select the date for the event from the calendar.
* **event_time** (<em>event_time</em>, time, *): Choose the time of the event.
* **party_size** (<em>party_size</em>, number, *): Indicate the number of guests attending the event.
* **pickup_location** (<em>pickup_location</em>, text, ): Enter the pickup location of the event.
* **drop_off_location** (<em>drop_off_location</em>, text, ): Enter the drop-off location of the event.
* **contact_name** (<em>contact_name</em>, text, *): Enter the name of the person responsible for the event.
* **contact_phone** (<em>contact_phone</em>, text, ): Enter the phone number of the contact person.
* **contact_email** (<em>contact_email</em>, email, *): Enter the email address of the contact person.
* **quote_details** (<em>quote_details</em>, text, ): Enter any additional information about the event (e.g., special requests).
* **additional_comments** (<em>additional_comments</em>, text, ): Enter any further comments or questions about the event.

## Tips
* Be as specific as possible when providing event details and contact information.
* If you need to make any changes to your event, please contact us directly.
* We will get back to you with a quote for your event once we receive this information.
