# Production Requirements For Live Performance - Help Guide
## Purpose
This form is designed to collect production requirements for live performances, including details about skills, dates, start times, and other essential information to ensure a smooth and successful production.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the production details in **Production Details** (Field 1) with the necessary information about the performance.
2. Select all required skills from the list in **Required Skills** (Field 3) that the production necessitates.
3. Enter the production's start time using the time format in **Production Start Time** (Field 5).
4. Add any relevant notes about the production in **Production Notes** (Field 6).
5. Enter your email address and contact phone number in **Email Address** and **Contact Phone** (Fields 7 and 8, respectively).
6. Fill out your name in **Contact Name** (Field 9).
7. Add any additional information about the production in **Additional Production Info** (Field 10).
8. Provide relevant files or documents related to the production in **Production Requirements Files** (Field 11).

## Field-by-Field Explanation
* **Production Requirements Form** (Field 1):
	+ This is a text field for entering production details.
* **Production Details** (Field 2):
	+ This field is also a text field for providing more in-depth information about the production.
* **Required Skills** (Field 3):
	+ This field is a select multiple field where you can choose the required skills for the production.
* **Production Dates** (Field 4):
	+ This field is a date field where you can enter the production dates.
* **Production Start Time** (Field 5):
	+ This field is a time field where you can enter the production's start time in the 24-hour format.
* **Production Notes** (Field 6):
	+ This field is a note field where you can add any additional notes about the production.
* **Email Address** (Field 7):
	+ This is the field for entering your email address.
* **Contact Phone** (Field 8):
	+ This field is for entering your contact phone number.
* **Contact Name** (Field 9):
	+ This field is for filling out your contact name.
* **Additional Production Info** (Field 10):
	+ This field is for providing extra information about the production.
* **Production Requirements Files** (Field 11):
	+ This is the field for uploading any relevant production requirement files or documents.
