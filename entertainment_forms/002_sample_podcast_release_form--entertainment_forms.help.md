# Sample Podcast Release Form - Help Guide
## Purpose
This form is used to collect information about the release of a new podcast episode.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the title of the podcast episode.
2. Fill out the date of the release.
3. Select the type of release (if applicable).
4. Choose the territories where the release will take place.
5. Specify the audio files associated with the episode.
6. Sign the release agreement.

## Field-by-Field Explanation

* **release_form**: This is the title of the form, which is also the name of the podcast episode.
* **name**: Enter the name of the person or organization releasing the episode.
* **date_of_event**: Enter the date the episode will be released.
* **audio_files**: Select whether audio files will be associated with this episode (Yes/No).
* **audio_files_2**: Select whether additional audio files will be associated with this episode (Yes/No).
* **release_type**: Choose the type of release (Exclusive/Non-Exclusive, if applicable).
* **territory**: Select the territories where the release will take place (Yes/No).
* **territory_2**: Select additional territories where the release will take place (Yes/No).
* **country**: Select the countries where the release will take place (Yes/No).
* **email**: Enter the email address of the person or organization releasing the episode.
* **signature**: Enter your name and signature.
* **date**: Enter the date the release was completed.
* **time**: Enter the time the release was completed.
* **duration**: Enter the duration of the episode.
* **audio_description**: Enter a brief description of the audio files associated with the episode.
* **audio_files_3**: Select whether additional audio files will be associated with this episode (Yes/No).
* **release_form_2**: Enter any additional comments or notes about the release.
* **audio_files_4**: Select additional territories where the release will take place (Yes/No).
* **territory_3**: Select additional countries where the release will take place (Yes/No).
* **territory_4**: Select additional regions where the release will take place (Yes/No).
* **release_agreement**: Enter the release agreement terms.
* **release_agreement_2**: Enter additional release agreement terms.
* **audio_description_2**: Enter a brief description of the audio files associated with the episode.
* **territory_5**: Select additional territories where the release will take place (Yes/No).
* **release_form_3**: Enter any additional comments or notes about the release.
