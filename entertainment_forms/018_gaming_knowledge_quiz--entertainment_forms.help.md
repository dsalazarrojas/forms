# Gaming Knowledge Quiz - Help Guide
## Purpose
This form is used to collect information from users about their gaming experiences or knowledge. It's a tool for the community to share and discuss various games, platforms, and genres.

## How To Complete This Form
To complete this form, follow these steps:

1. Answer the question about whether the game system is related to the game you're thinking about.
2. Select the platforms on which the game is available.
3. Choose the genres or types of games that the game falls under.
4. Enter the game's title.
5. Provide a brief description of the game.
6. Rate the game (good or fair).
7. Provide your name, email, phone number, and location (optional).
8. Select the type of game (yes or no).
9. Choose the game's version.
10. Enter any additional information about the game's scoring system.

## Field-by-Field Explanation
* **Game System Type** (`game_system_type`, optional): This question asks whether the game system is related to the game you're thinking about.
* **Platform** (`platform`, optional): Select all the platforms on which the game is available.
* **Genre** (`genre`, optional): Choose all the genres or types of games that the game falls under.
* **Game Title** (`game_title`, optional): Enter the title of the game.
* **Game Description** (`game_description`, optional): Provide a brief description of the game.
* **Score** (`score`, optional): Rate the game as good or fair.
* **Game Developer** (`game_developer`, optional): Select all the game developers associated with the game.
* **Game Publisher** (`game_publisher`, optional): Select all the game publishers associated with the game.
* **Release Year** (`release_year`, optional): Choose the release year of the game.
* **Game Image URL** (`game_image_url`, optional): Enter the URL of the game's image.
* **Game Video URL** (`game_video_url`, optional): Enter the URL of the game's video.
* **Gamer Name** (`gamer_name`, optional): Enter your name as a gamer.
* **Gamer Email** (`gamer_email`, optional): Enter your email address.
* **Gamer Phone** (`gamer_phone`, optional): Enter your phone number.
* **Gamer Location** (`gamer_location`, optional): Select your location.
* **Game Type** (`game_type`, optional): Choose whether the game is a yes or no type.
* **Game Version** (`game_version`, optional): Enter the game's version.
* **Score System** (`score_system`, optional): Enter the game's scoring system.
* **Game System** (`game_system`, optional): Select all the game systems associated with the game.
