# Event Information Sheet - Help Guide
## Purpose
This form is used to collect information about an event. It is designed to gather relevant details such as event date, start time, location, and description. This form helps event organizers and planners to provide a comprehensive overview of the event.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the required fields with the relevant information about the event.
2. Select the event status from the available options.
3. Choose the event type from the available options.
4. Fill in any additional text fields with the required information.
5. Make sure to review your answers before submitting the form.

## Field-by-Field Explanation
* **Event Date** (`event_date`, `date`, required: false): Enter the date of the event in YYYY-MM-DD format.
* **Start Time** (`start_time`, `time`, required: false): Enter the start time of the event in 24-hour format (HH:MM).
* **Event Location** (`event_location`, `text`, required: false): Enter the location where the event will take place.
* **Event Details** (`event_details`, `text`, required: false): Enter a brief description of the event, including any relevant details.
* **Organizer Name** (`organizer_name`, `text`, required: false): Enter the name of the person organizing the event.
* **Event Description** (`event_description`, `text`, required: false): Enter a detailed description of the event.
* **Contact Phone** (`contact_phone`, `text`, required: false): Enter the phone number of the contact person for the event.
* **Contact Email** (`contact_email`, `text`, required: false): Enter the email address of the contact person for the event.
* **Event Organizer** (`event_organizer`, `select_one`, required: false): Choose the role of the person organizing the event from the available options.
* **Event Status** (`event_status`, `select_multiple`, required: false): Select the status of the event from the available options.
* **Event Type** (`event_type`, `select_multiple`, required: false): Select the type of event from the available options.
* **Event End** (`event_date_end`, `date`, required: false): Enter the end date of the event in YYYY-MM-DD format.
* **Event Location 1** (`event_location_1`, `text`, required: false): Enter the first location of the event.
* **Event Location 2** (`event_location_2`, `text`, required: false): Enter the second location of the event.
