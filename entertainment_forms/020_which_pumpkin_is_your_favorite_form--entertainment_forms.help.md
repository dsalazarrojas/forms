# Which Pumpkin Is Your Favorite Form - Help Guide
## Purpose
This form is designed to collect users' favorite pumpkin choices for entertainment purposes.

## How To Complete This Form
To complete this form, simply select your favorite pumpkin(s) and provide a brief description if desired. Fill in the email address if you'd like to be contacted.

## Field-by-Field Explanation
* **Which pumpkin is your favorite? (<type: select_multiple>)**: Choose one or multiple pumpkins from the list. You can select up to three pumpkins.
	+ Select Pumpkin A, Pumpkin B, or Pumpkin C.
* **Pumpkin name (<type: text>)**: If you'd like to give your favorite pumpkin a name, provide it here. This is optional.
* **Pumpkin description (<type: note>)**: If you'd like to add a brief description of your favorite pumpkin, enter it here. This is optional.
* **Customer email (<type: email>)**: Provide your email address if you'd like to be contacted about your favorite pumpkin. This is optional but helps us to get back to you.
	+ Enter your email address as per standard email format (e.g., [name]@example.com).
