# Yell Low Creative Request - Help Guide
## Purpose
This form is used to collect information about projects in the "entertainment" category. It's meant for projects that are still in development or have already been completed.

## How To Complete This Form
To complete this form, follow the steps below:

1. Enter a brief description of the project in the "What is this project about" field.
2. Select "Yes" if the project has a client associated with it, and "No" otherwise.
3. Enter any specific requirements or details about the project in the "Creative Requirements" field.
4. Enter the project's budget in the "Project Budget" field.
5. Select the project start and end dates in the "Project Start Date" and "Project End Date" fields, respectively.
6. Choose the project status from the options provided in the "Project Status" field.
7. Enter any additional notes about the project in the "Project Notes" field.
8. Enter the project's email address in the "Project Email" field.
9. Enter the project's phone number in the "Project Phone" field.
10. If this form has been cloned from another form, select the original form's ID in the "Cloned from" field.

## Field-by-Field Explanation

* **What is this project about**
	+ A brief description of the project.
* **Project Client**
	+ Select "Yes" if the project has a client associated with it, and "No" otherwise.
* **Creative Requirements**
	+ Enter any specific requirements or details about the project.
* **Project Budget**
	+ Enter the project's budget.
* **Project Start Date**
	+ Select the project's start date.
* **Project End Date**
	+ Select the project's end date.
* **Project Status**
	+ Choose the project status from the options provided.
	+ Available options: Active, Inactive.
* **Project Notes**
	+ Enter any additional notes about the project.
* **Project Email**
	+ Enter the project's email address.
* **Project Phone**
	+ Enter the project's phone number.
* **Cloned from**
	+ If this form has been cloned from another form, select the original form's ID.
