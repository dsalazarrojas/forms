# Video Game Quiz - Help Guide
## Purpose
This form is designed to collect information about video games, including game name, player name, platform, genre, release date, game type, rating, and description.

## How To Complete This Form
1. **Start by filling out the form in sections**: Break down the form into smaller tasks, one section at a time.
2. **Game Name**: Enter the name of the game you're thinking of (if you're not sure, try to recall your favorite game's title).
3. **Player Name**: Enter your name or the name of the player/developer associated with the game.
4. **Game Platform**: Enter the platform on which the game is played (e.g., console, PC, mobile).
5. **Genre**: Select one or more genres that describe the game (e.g., Action, Adventure, Sports).
6. **Release Date**: Enter the release date of the game (if known).
7. **Game Type**: Select the type(s) of game you're considering (e.g., Single-player, Multi-player, Online Multi-player).
8. **Rating**: Rate the game based on a 5-point scale (0 = Very Poor, 1 = Average, 2 = Good, 3 = Very Good, 4 = Excellent).
9. **Description**: Provide a short description of the game (if applicable).

## Field-by-Field Explanation

* **Game Name** (game_name, text, required): Enter the name of the game you're thinking of.
* **Player Name** (player_name, text, required): Enter your name or the name of the player/developer associated with the game.
* **Game Platform** (game_platform, text, required): Enter the platform on which the game is played (e.g., console, PC, mobile).
* **Genre** (genre, select_one/many, required): Select one or more genres that describe the game (e.g., Action, Adventure, Sports).
	+ Select one or more from the options below:
		- Action
		- Adventure

		- Role-Playing
		- Simulation
* **Release Date** (release_date, date, optional): Enter the release date of the game (if known).
* **Game Type** (game_type, select_one/many, required): Select the type(s) of game you're considering.
	+ Select one or more from the options below:
		- Single-player
		- Multi-player
		- Online Multi-player
* **Rating** (rating, select_one, required): Rate the game based on a 5-point scale.
	+ Select one from the options below:
		- 0 = Very Poor
		- 1 = Average
		- 2 = Good
		- 3 = Very Good
		- 4 = Excellent
* **Description** (description, text, optional): Provide a short description of the game (if applicable).
