# Talent Gig Information Survey - Help Guide
## Purpose
The purpose of this form is to collect detailed information about talent gigs, including event name, performer's name, date, event type, performance time, location, event capacity, and additional comments or feedback.

## How To Complete This Form
1. **Event Name**: Enter the name of the event where the performer will be performing. (Text, Optional)
2. **Performer Name**: Enter the name of the performer. (Text, Optional)
3. **Gig Date**: Enter the date of the event. (Date, Optional)
4. **Event Type**: Select the type of event where the performer will be performing. (Select One, Required)
5. **Performance Time**: Enter the time of the performance. (Time, Optional)
6. **Event Location**: Enter the location where the event will take place. (Text, Optional)
7. **Event Capacity**: Enter the maximum number of people that can attend the event. (Number, Required)
8. **Performance Notes**: Enter any additional comments or notes about the performance. (Text, Optional)
9. **Additional Comments**: Enter any additional comments or feedback about the gig. (Text, Optional)
10. **Performer Feedback**: Enter any feedback or comments from the performer about the event. (Text, Optional)

## Field-by-Field Explanation
* **Event Name**: Enter the name of the event where the performer will be performing.
* **Performer Name**: Enter the name of the performer.
* **Gig Date**: Enter the date of the event in the format `YYYY-MM-DD`. For example, `2022-01-01`.
* **Event Type**: Select the type of event where the performer will be performing. You can choose from the following options:
	+ Option 1
	+ Option 2
	+ Option 3
* **Performance Time**: Enter the time of the performance in the format `HH:MM AM/PM`. For example, `7:00 PM`.
* **Event Location**: Enter the location where the event will take place.
* **Event Capacity**: Enter the maximum number of people that can attend the event.
* **Performance Notes**: Enter any additional comments or notes about the performance.
* **Additional Comments**: Enter any additional comments or feedback about the gig.
* **Performer Feedback**: Enter any feedback or comments from the performer about the event.
