# Entertainment Standards Acknowledgment - Help Guide
## Purpose
The Entertainment Standards Acknowledgment form is used to document and acknowledge the entertainment industry standards and agreements for a project. This form ensures that all parties involved in the project are aware of and agree to the standards and conditions set for the project.

## How To Complete This Form

1. Start by filling in the **Project Name**, which is a required field that should include the name of the project.
2. For the **Date Read**, select the date when the entertainment industry standards were read and understood by all parties.
3. The **Cast Agreed**, **Crew Agreed**, **Partner Agreed** fields are optional number fields. These fields are intended to track the number of agreements from cast, crew, and partners respectively.
4. In the **Roles** field, select all roles that have been agreed upon by the production team. This field allows multiple selections.
5. The **Project Details** field is for additional information about the project.
6. For the **Signatures**, select all signatures that have been obtained from parties involved in the project. This field allows multiple selections.
7. The **Date Signed** field is for the date when all parties signed the agreement.
8. The **Timestamp** field is for the time when the agreement was signed.
9. The **Assigned Tool** field is for the tool assigned to the user.
10. The **Form ID**, **Project ID**, and **User ID** fields are unique identifiers for the form, project, and user respectively.
11. The **User Name** field is for the name of the user filling out the form.
12. The **User Email**, **User Phone** fields are for the email address and phone number of the user.
13. The **Project Start Date** field is for the start date of the project.

## Field-by-Field Explanation

* **Project Name** (1, text, required): Enter the name of the project.
* **Date Read** (2, date, optional): Select the date when the entertainment industry standards were read and understood by all parties.
* **Cast Agreed** (3, number, optional): Enter the number of agreements from the cast.
* **Crew Agreed** (4, number, optional): Enter the number of agreements from the crew.
* **Partner Agreed** (5, number, optional): Enter the number of agreements from partners.
* **Roles** (6, select_multiple, optional): Select all roles that have been agreed upon.
* **Project Details** (7, text, optional): Enter any additional information about the project.
* **Signatures** (8, select_multiple, optional): Select all signatures that have been obtained from parties involved in the project.
* **Date Signed** (9, date, optional): Enter the date when all parties signed the agreement.
* **Timestamp** (10, time, optional): Enter the time when the agreement was signed.
* **Assigned Tool** (11, text, optional): Enter the tool assigned to the user.
* **Form ID** (12, text, optional): Enter the unique identifier for this form.
* **Project ID** (13, text, optional): Enter the unique identifier for the project.
* **User ID** (14, text, optional): Enter the unique identifier for the user.
* **User Name** (15, text, optional): Enter the name of the user filling out the form.
* **User Email** (16, email, optional): Enter the email address of the user.
* **User Phone** (17, text, optional): Enter the phone number of the user.
* **Project Start Date** (18, date, optional): Enter the start date of the project.

## Tips

* Make sure to fill out all required fields.
* Use the **Roles** field to select all roles that have been agreed upon.
* Use the **Signatures** field to select all signatures that have been obtained.
* Enter the **Date Signed** field with the date when all parties signed the agreement.
* Enter the **Timestamp** field with the time when the agreement was signed.
* Enter the **Form ID**, **Project ID**, and **User ID** fields with unique identifiers.
* Enter the **User Name**, **User Email**, and **User Phone** fields with the user's contact information.
* Enter the **Project Start Date** field with the start date of the project.
