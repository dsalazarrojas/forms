# Virtual Event Talent Sign Up Form - Help Guide
## Purpose
The Virtual Event Talent Sign Up Form is designed to collect information from performers who want to sign up for virtual events. This form is used to gather the necessary details for talent management and event organization.

## How To Complete This Form
To complete this form, please follow these steps:
1. Enter your Event Name. This field is used to identify the specific event you are signing up for.
2. Indicate if you will be performing at this event as Event Talent by selecting 'Yes' or 'No' from the options.
3. Enter the length of your performance in minutes. This will help event organizers manage the program and schedule.
4. Provide a brief description of your performance details, such as your act, music style, etc.

## Field-by-Field Explanation
* **Event Name** (`event_name`, `text`, required: false): Enter the name of the event you are signing up for.
* **Event Talent Type** (`event_talent_type`, `select_multiple`, required: false): Select 'Yes' if you will be performing at this event as Event Talent, 'No' otherwise.
* **Act Length** (`act_length`, `number`, required: false): Enter the length of your performance in minutes.
* **Performance Details** (`performance_details`, `text`, required: false): Enter a brief description of your performance, including your act, music style, etc.

## Tips
* Please ensure you enter the correct event name to ensure that your application is correctly associated with the correct event.
* Select 'Yes' only if you are confirmed to be performing at the event as Event Talent.
* Be as detailed as possible with your performance details to help the event organizers better plan the event.
