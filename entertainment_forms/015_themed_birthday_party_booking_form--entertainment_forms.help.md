# Themed Birthday Party Booking Form - Help Guide
## Purpose
This form is designed to collect information for a themed birthday party booking. The party organizers will use this information to create a memorable and fun celebration for the child and their guests.

## How To Complete This Form
To complete this form, please follow the steps below:

1. Fill in the party details.
2. Specify the number of guests attending the party.
3. Enter the date of birth of the child.
4. Choose the start time for the party.
5. Select the party time duration.
6. Choose a party theme.
7. Select a party color (e.g., red, blue, green, yellow).
8. Choose the music style for the party (e.g., pop, rock, jazz, hip-hop).
9. Specify any special requests (e.g., catering, cake, games).
10. Select the party venue (e.g., home, school, park).

## Field-by-Field Explanation
- **Party Details**: Enter a brief description of the party, including the birthday child's name and the party's purpose.
  - **Type**: Text field.
  - **Required**: Not required.
- **Guests**: Specify the number of guests attending the party.
  - **Type**: Number field.
  - **Required**: Not required.
- **Date Of Birth**: Enter the child's date of birth.
  - **Type**: Date field.
  - **Required**: Not required.
- **Start Time**: Choose the start time for the party.
  - **Type**: Time field.
  - **Required**: Not required.
- **Party Time**: Choose the party time duration.
  - **Type**: Time field.
  - **Required**: Not required.
- **Party Theme**: Choose a party theme.
  - **Type**: Text field.
  - **Required**: Not required.
- **Party Color**: Choose a party color (e.g., red, blue, green, yellow).
  - **Type**: Select One field.
  - **Required**: Not required.
- **Music Style**: Choose a music style (e.g., pop, rock, jazz, hip-hop).
  - **Type**: Select Multiple field.
  - **Required**: Not required.
- **Special Requests**: Specify any special requests (e.g., catering, cake, games).
  - **Type**: Select Multiple field.
  - **Required**: Not required.
- **Party Venue**: Choose the party venue (e.g., home, school, park).
  - **Type**: Select One field.
  - **Required**: Not required.
