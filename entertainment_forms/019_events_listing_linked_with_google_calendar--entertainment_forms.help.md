# Events Listing Linked With Google Calendar - Help Guide
## Purpose
This form is used to gather information about events that are linked or unlinked with a Google Calendar.

## How To Complete This Form
1. Fill in all required fields, indicated by an asterisk (\*).
2. Select "Yes" for events that are linked with a Google Calendar, and "No" otherwise.
3. For unlinked events, select multiple options from the "Unlinked Events" field.
4. Enter the event date in the format specified in the "Event Date" field (e.g., 2022-01-01).
5. Select the event time from the provided options or enter a custom time.
6. Enter the event location in the text field.
7. Provide a brief description of the event in the "Event Description" field.
8. Enter the Google Calendar link for events that are linked with a Google Calendar.

## Field-by-Field Explanation
* **User Input** (text): Enter any additional information about the event that is relevant to you.
* **User Email** (email): Enter your email address to help us contact you if needed.
* **User Phone** (text): Enter your phone number to help us contact you if needed.
* **Linked Event** (select_one): Select "Yes" if the event is linked with a Google Calendar, and "No" otherwise.
* **Unlinked Event** (select_multiple): Select multiple options to describe events that are not linked with a Google Calendar.
* **User Events** (select_multiple): Select multiple options to describe your event types (e.g., meeting, appointment, etc.).
* **Event Date** (date): Enter the date of the event in the format specified (e.g., 2022-01-01).
* **Event Time** (time): Select the event time from the provided options or enter a custom time.
* **Event Location** (text): Enter the location of the event.
* **Event Description** (text): Enter a brief description of the event.
* **Google Calendar Link** (text): Enter the link to the Google Calendar event if it is linked.

## Tips
- Make sure to enter accurate and complete information to help us better understand your events.
- If you are unsure about any field, please contact us for clarification.
