# Event Registration Form - Help Guide
## Purpose
The "Event Registration Form" is used for collecting information about events and attendees. It helps in organizing and managing events by gathering relevant details about the event and the people attending it.

## How To Complete This Form
1. Fill in the required fields: * Event Status * Registration Status * Event Image Size * Attendee Image Size
2. Choose the correct options for the following fields:
	* Registration Type
	* Event Image Size
	* Attendee Image Size

## Field-by-Field Explanation
* **Event Name (text)**: Enter the name of the event being registered.
	+ Required: No
	+ Hint: Event name is the title of the event.
* **Event Date (date)**: Enter the date of the event in the format mm/dd/yyyy.
	+ Required: No
	+ Hint: Event date should be in the format mm/dd/yyyy.
* **Event Time (time)**: Enter the time of the event in 12-hour format (e.g., 1:00 PM).
	+ Required: No
	+ Hint: Event time should be in 12-hour format.
* **Organizer Name (text)**: Enter the name of the person or organization hosting the event.
	+ Required: No
	+ Hint: Enter the name of the person or organization hosting the event.
* **Event Location (text)**: Enter the location of the event.
	+ Required: No
	+ Hint: Enter the physical location of the event.
* **Event Description (text)**: Enter a brief description of the event.
	+ Required: No
	+ Hint: Enter a brief description of the event.
* **Registration Type (select_one)**: Choose the type of registration:
	+ Event Registration
	+ In-Person Registration
	+ Both
	+ Required: Yes
	+ Hint: Choose the correct type of registration for the event.
* **Event Status (select_multiple)**: Choose the status of the event:
	+ Open
	+ Closed
	+ Pending
	+ Required: Yes
	+ Hint: Choose the correct status of the event.
* **Registration Status (select_one)**: Choose the status of the registration:
	+ Confirmed
	+ Declined
	+ Pending
	+ Required: Yes
	+ Hint: Choose the correct status of the registration.
* **Attendee Name (text)**: Enter the name of the attendee.
	+ Required: No
	+ Hint: Enter the name of the person attending the event.
* **Attendee Email (email)**: Enter the email of the attendee.
	+ Required: No
	+ Hint: Enter the email of the person attending the event.
* **Attendee Phone (text)**: Enter the phone number of the attendee.
	+ Required: No
	+ Hint: Enter the phone number of the person attending the event.
* **Attendee Address (text)**: Enter the address of the attendee.
	+ Required: No
	+ Hint: Enter the physical address of the person attending the event.
* **Notes (text)**: Enter any additional notes about the attendee.
	+ Required: No
	+ Hint: Enter any additional notes about the attendee.
* **Event Image (text)**: Upload the image of the event.
	+ Required: No
	+ Hint: Upload an image of the event.
* **Event Image Alt (text)**: Enter the alt text for the event image.
	+ Required: No
	+ Hint: Enter the alt text for the event image.
* **Event Image Width (number)**: Enter the width of the event image.
	+ Required: No
	+ Hint: Enter the width of the event image in pixels.
* **Event Image Height (number)**: Enter the height of the event image.
	+ Required: No
	+ Hint: Enter the height of the event image in pixels.
* **Event Image Size (select_one)**: Choose the size of the event image:
	+ 1x
	+ 2x
	+ 3x
	+ Required: Yes
	+ Hint: Choose the correct size of the event image.
* **Attendee Image (text)**: Upload the image of the attendee.
	+ Required: No
	+ Hint: Upload an image of the attendee.
* **Attendee Image Alt (text)**: Enter the alt text for the attendee image.
	+ Required: No
	+ Hint: Enter the alt text for the attendee image.
* **Attendee Image Width (number)**: Enter the width of the attendee image.
	+ Required: No
	+ Hint: Enter the width of the attendee image in pixels.
* **Attendee Image Height (number)**: Enter the height of the attendee image.
	+ Required: No
	+ Hint: Enter the height of the attendee image in pixels.
* **Attendee Image Size (select_one)**: Choose the size of the attendee image:
	+ 1x
	+ 2x
	+ 3x
	+ Required: Yes
	+ Hint: Choose the correct size of the attendee image.
* **Submission Time (time)**: Enter the submission time of the form.
	+ Required: No
	+ Hint: Enter the submission time of the form in 12-hour format (e.g., 1:00 PM).

## Tips
* Ensure all required fields are filled before submitting the form.
* Check the correct format for date, time, and number fields.
* Choose the correct size of the event and attendee images.
* Upload images of high quality and relevant to the event and attendee.
