# Stage Management Position Acceptance - Help Guide
## Purpose
This form is used to collect information on stage management position acceptances or rejections, ensuring accurate data for stage management operations.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the form for each stage management position that has been offered or accepted.
2. Make sure to enter accurate information in each field as it applies to your specific situation.
3. If a field does not apply, simply leave it blank.

## Field-by-Field Explanation
* **stage_management_position_acceptance_form** (`Stage Management Position Acceptance Form`, `text`, optional):
	+ This field is used to enter a brief description or notes regarding the stage management position.
* **job_offer_id** (`Job Offer ID`, `number`, optional):
	+ Enter the ID number of the job offer, if applicable.
* **job_start_date** (`Job Start Date`, `date`, optional):
	+ Enter the expected start date of the job.
* **role_expectations_agreement** (`Role Expectations Agreement`, `select_multiple`, optional):
	+ Select `Yes` if you agree to the role expectations. You can select multiple options.
* **signed_agreement** (`Signed Agreement`, `select_one`, optional):
	+ Select `Yes` if you have signed the agreement. This indicates that you have accepted the position.
* **comments** (`Comments`, `note`, optional):
	+ Enter any additional comments or notes regarding the position.
* **job_title** (`Job Title`, `text`, optional):
	+ Enter the title of the job.
* **job_status** (`Job Status`, `select_one`, optional):
	+ Select `Active` if the position is active. Select `Inactive` if the position is inactive.
* **manager_name** (`Manager Name`, `text`, optional):
	+ Enter the name of the manager.
* **manager_email** (`Manager Email`, `email`, optional):
	+ Enter the manager's email address.
* **manager_phone** (`Manager Phone`, `text`, optional):
	+ Enter the manager's phone number.
* **theatre_name** (`Theatre Name`, `text`, optional):
	+ Enter the name of the theatre.
* **theatre_email** (`Theatre Email`, `email`, optional):
	+ Enter the theatre's email address.
* **theatre_phone** (`Theatre Phone`, `text`, optional):
	+ Enter the theatre's phone number.
* **agreement_signed** (`Agreement Signed`, `select_one`, optional):
	+ Select `Yes` if you have signed the agreement. This indicates that you have accepted the position.

Please note that each field is optional, but accurate and up-to-date information will ensure effective stage management operations.
