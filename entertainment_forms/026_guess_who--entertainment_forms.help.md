# Guess Who!! - Help Guide
## Purpose
The purpose of this form is to collect information from users about a game they are familiar with. It is used to gather details about the game, such as its title, release year, genre, and player's name.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the title of the game in the "Guess Who!" field. This is a text field where you can type in the name of the game.
2. Enter the release year of the game in the "Release Year" field. This is a number field where you can type in the year the game was released.
3. Select the genre of the game from the dropdown menu in the "Game Genre" field. Choose from the options: Adventure, Action, Platformer, Puzzle, Racing, Role-playing, Strategy, Sports, or Other.
4. Enter the player's name in the "Player Name" field. This is the name of the person submitting the form.

## Field-by-Field Explanation
* **Guess Who!** (`game_name`, text, required: false): Enter the title of the game you are familiar with.
* **Release Year** (`game_year`, number, required: false): Type in the year the game was released.
* **Game Genre** (`game_genre`, select_one, required: false): Choose the genre of the game from the dropdown menu.
  * Select from: Adventure, Action, Platformer, Puzzle, Racing, Role-playing, Strategy, Sports, or Other.
* **Player Name** (`player_name`, text, required: false): Enter the name of the player who will be submitting this form.
