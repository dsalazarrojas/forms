# Film Scene Retake Request Form - Help Guide
## Purpose
This form is used to request a retake for a film scene, providing essential details to facilitate the process.

## How To Complete This Form

To complete this form, follow these steps:

1. Fill in the "Scene Request" field with a brief description of the reason for the retake.
2. Select the "Scene ID" field to identify which scene requires the retake.
3. Choose the "Preferred Date" for the retake.
4. Indicate the "Urgency Level" of the retake (high, medium, or low).
5. If necessary, provide "Supporting Files" that will aid in the understanding of the retake request.
6. Optionally, provide an "Review Status" note for further context.
7. If applicable, fill in the "Priority" field with any relevant details.
8. Select the "Assigned Tool" field to specify any equipment or tools required for the retake.
9. In the "Assigned To" field, specify the person or team responsible for the retake.

## Field-by-Field Explanation

* **Scene Request**: A brief description of the reason for the retake. Please provide a concise explanation.
* **Reason For Retake**: A more detailed description of the reason for the retake. Please provide a brief explanation.
* **Scene ID**: Select the ID number of the scene that requires the retake to help identify it.
* **Preferred Date**: Choose a date and time for the retake, taking into account the availability of the production crew.
* **Urgency Level**: Select the level of urgency for the retake, with high, medium, or low priority.
* **Supporting Files**: If necessary, attach any relevant files that will aid in understanding the retake request.
* **Review Status**: Add any additional notes for the review process, if desired.
* **Priority**: Specify any relevant details for the priority of the retake, if applicable.
* **Assigned Tool**: Identify any equipment or tools that are required for the retake.
* **Assigned To**: Specify the person or team responsible for the retake.

## Tips

* Make sure to fill in all required fields to ensure the retake request is properly communicated.
* Double-check the Scene ID to ensure it is accurate.
* Be mindful of the Urgency Level, as it will impact the scheduling and planning process.
* Attach any necessary Supporting Files to provide context.
* Review the request thoroughly before submitting, ensuring all information is accurate and complete.
