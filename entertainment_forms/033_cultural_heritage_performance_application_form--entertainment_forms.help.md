# Cultural Heritage Performance Application Form - Help Guide

## Purpose
This form is designed to collect information about a cultural heritage performance event. The collected information will be used to register your event with the organization managing cultural heritage events.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in your name, the name of the event, date and time, venue, and performance length.
2. Indicate whether the performance is a "Yes" or "No" (if you're not sure, you can choose "No").
3. Provide a brief description of the performance, if desired.
4. Enter your contact email and phone number (optional but recommended).
5. Upload any supporting documentation or files, if necessary.
6. Review and submit your application.

## Field-by-Field Explanation

* **Performer name**: This is where you enter your name as the performer. Please enter your name as it is professionally known or would like to be known.
* **Event name**: This is the name of the cultural heritage event you will be performing. Please make sure it is clear and descriptive.
* **Date and Time**: This is where you enter the date and time of the event. Please use the format `YYYY-MM-DD HH:MM`.
* **Venue**: This is the location where the event will take place. Please enter the venue name or describe the location.
* **Performance length**: This is the expected length of the performance, in hours and minutes. For example, "1 hour and 30 minutes".
* **Performance type**: This is where you indicate whether the performance is a "Yes" or "No". If unsure, you can choose "No".
* **Performance details**: This is an optional field where you can describe the performance in more detail, if desired.
* **Email**: This is where you enter your email address for contact purposes. Please make sure it is a valid email address.
* **Phone**: This is where you enter your phone number for contact purposes. Please make sure it is a valid phone number.
* **File**: This is where you can upload supporting documentation or files, if necessary.
* **Submit**: This is where you submit your application. Please make sure to review and confirm that all information is accurate before submitting.
* **Cancel**: This is a cancel button. If you change your mind or want to start over, you can click this button.

## Tips

* Please make sure to fill out as much information as possible to help us better understand and process your application.
* If you have any questions or concerns, please contact us at [insert contact info].
