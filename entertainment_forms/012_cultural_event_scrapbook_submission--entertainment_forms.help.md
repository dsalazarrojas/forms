# cultural_event_scrapbook_submission - Help Guide

## Purpose
The cultural_event_scrapbook_submission form is used to collect and store information about cultural events. This form helps users to document and showcase their experiences, memories, and reflections about events they have attended or participated in. It is a useful tool for cultural exchange, education, and research.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the type of event you want to submit (Event 1 or Event 2 or Event 3)
2. Enter the name of the event
3. Select the date of the event (using the date field)
4. Write a brief story about the event (in the Event Story field)
5. Upload a photo related to the event (in the Event Photo field)
6. Enter the location of the event (in the Event Location field)
7. Reflect on your experience (in the Event Reflection field)
8. Enter your email address (in the Email field)
9. Write a description of the event (in the Event Description field)
10. Add any additional notes about the event (in the Event Notes field)

## Field-by-Field Explanation
* **Event Type** (`event_type`, select_one, required: false):
	+ This field allows you to select the type of event you want to submit. Select the relevant option that best describes the event.
* **Event Name** (`event_name`, text, required: false):
	+ Enter the name of the event.
* **Event Date** (`event_date`, date, required: false):
	+ Select the date of the event using the date field.
* **Event Story** (`event_story`, text, required: true):
	+ Write a brief story about the event, describing your experience and memories.
* **Event Photo** (`event_photo`, text, required: false):
	+ Upload a photo related to the event, if available.
* **Event Location** (`event_location`, text, required: true):
	+ Enter the location where the event took place.
* **Event Reflection** (`event_reflection`, text, required: false):
	+ Reflect on your experience, sharing any thoughts, feelings, or insights you gained from the event.
* **Organization** (`organization`, text, required: false):
	+ If applicable, enter the name of the organization or group that hosted the event.
* **School** (`school`, text, required: false):
	+ If applicable, enter the name of the school or institution associated with the event.
* **Group** (`group`, text, required: false):
	+ If applicable, enter the name of the group or team that participated in the event.
* **Email** (`email`, email, required: true):
	+ Enter your email address for contact purposes.
* **Phone** (`phone`, text, required: false):
	+ Enter your phone number, if available.
* **Event Tags** (`event_tags`, select_multiple, required: false):
	+ Select multiple tags related to the event, for categorization and search purposes.
* **Event Description** (`event_description`, text, required: true):
	+ Write a detailed description of the event, including any relevant details.
* **Event Notes** (`event_notes`, text, required: false):
	+ Add any additional notes or comments about the event, if needed.

## Tips
* Please ensure you have permission to share your email address and other contact information.
* Proofread your submission for accuracy and completeness.
* You can add or remove tags as needed to best describe the event.
