# Halloween Trunk or Treat Event Interest Survey - Help Guide

## Purpose
This form is a survey for the Halloween Trunk or Treat Event Interest Survey. We need your input to help us understand who is interested in hosting or participating in this fun event. Please answer the questions carefully to help us plan the best event for our community.

## How To Complete This Form
To complete this form, simply fill in the required information and select the relevant options. Make sure to double-check your answers for accuracy before submitting the form.

## Field-by-Field Explanation
* **Parent Survey** (`parent_survey`, Select One, Required): 
  Please indicate if you are a parent or guardian who will be attending the event with your child. You can choose "True" if you will be attending and "False" if not.
* **Child** (`child_survey`, Select Multiple, Optional): 
  If you are a parent or guardian, please list the number of children you will be attending the event with (e.g., "Son", "Daughter", "Both", or "None").
* **Contact Number** (`contact_number`, Text, Required): 
  Please enter a phone number where we can reach you for more information about the event.
* **Email** (`email`, Email, Required): 
  Please enter a valid email address where we can send you more information about the event.
* **Event Details** (`event_details`, Note, Optional): 
  If you have any additional comments or ideas about the event, please use this field to share them with us.
* **Trick or Treat Time** (`trick_or_treat_time`, Date, Required): 
  Please select the date and time you would like the event to take place.
* **End Date** (`end_date`, Date, Required): 
  Please select the date the event will end.
* **Trick or Treat Location** (`trick_or_treat_location`, Text, Required): 
  Please enter the address or location where you would like the event to take place.

## Tips
* Please make sure to double-check your answers for accuracy before submitting the form.
* If you have any questions or concerns about the event, please contact us at the email address you provided.
