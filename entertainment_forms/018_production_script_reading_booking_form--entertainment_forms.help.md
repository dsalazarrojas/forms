# production_script_reading_booking_form - Help Guide
## Purpose
The "production_script_reading_booking_form" form is used to book and manage reading sessions for production scripts. It collects relevant information from customers or users, including project details, contact information, and script specifics.

## How To Complete This Form

1.  To start, fill in the project name in the designated field. This is a required field, and it's essential to enter the correct project name to associate with the reading session.
2.  Next, provide the contact title and contact name. These fields are optional but recommended to establish a point of contact for the reading session.
3.  Enter the email address of the contact person in the "Contact Email" field. This is an optional field but helps with follow-up communication.
4.  Enter the phone number of the contact person in the "Contact Phone" field. This is optional but facilitates easy communication.
5.  Choose 'Yes' or 'No' for the "Script Type" field to indicate whether the script is for production or not.
6.  Enter the name of the script in the designated field. This helps in identifying the specific script being read.
7.  Select the type of reading (yes or no) from the "Reading Type" field.
8.  Select a date for the booking from the calendar provided in the "Booking Date" field. Be sure to choose a date that is convenient for you and the contact person.
9.  Select the time for the reading session from the provided time options in the "Reading Time" field.
10.  Finally, enter the version of the script in the "Script Version" field, which is optional but helpful for reference.

## Field-by-Field Explanation

* **Project Name** (`Project Name`, `text`, required): Enter the name of the project you wish to book the reading session for.
* **Contact Title** (`Contact Title`, `text`, optional): Enter a title for the contact person to be used for follow-up communication.
* **Contact Name** (`Contact Name`, `text`, optional): Enter the name of the contact person.
* **Email** (`Email`, `email`, optional): Enter the email address of the contact person.
* **Phone** (`Phone`, `text`, optional): Enter the phone number of the contact person.
* **Script Type** (`Script Type`, `select_one`, optional): Select 'Yes' if the script is for production, 'No' otherwise.
* **Script Name** (`Script Name`, `text`, optional): Enter the name of the script being read.
* **Reading Type** (`Reading Type`, `select_one`, optional): Choose 'Yes' or 'No' for the type of reading.
* **Booking Date** (`Booking Date`, `date`, optional): Select a date for the reading session from the provided calendar.
* **Reading Time** (`Reading Time`, `time`, optional): Select a time for the reading session from the provided options.
* **Contact Email** (`Contact Email`, `email`, optional): Enter the email address of the contact person for follow-up communication.
* **Contact Phone** (`Contact Phone`, `text`, optional): Enter the phone number of the contact person.
* **Script Version** (`Script Version`, `text`, optional): Enter the version of the script being read, if applicable.
