# Entertainment Industry Gala RSVP - Help Guide
## Purpose
This form is for guests to RSVP for an event in the entertainment industry. You can provide your personal and professional information, as well as details about your arrival and preferences.
## How To Complete This Form
To complete this form, please follow these steps:
1. Fill in the required and optional fields as needed.
2. Make sure to provide accurate and up-to-date information.
3. Review and submit your RSVP before leaving the event.

## Field-by-Field Explanation
* **Event Name**: This field is not a required field, but it's a good idea to fill it in so that we can understand what event you are attending.
* **Guest Name**: Enter your name as you would like to be addressed during the event.
* **Job Title**: If you have a job title, please enter it here. This will help us understand your professional affiliation.
* **Email**: If you have a work email address, please enter it here. We will use this to contact you if needed.
* **Phone**: If you prefer to be contacted by phone, please enter your phone number here. We will only contact you if absolutely necessary.
* **Headcount**: If you are bringing a group, please enter the number of people in your group attending.
* **Dietary Restriction**: If you have any dietary restrictions, please select one of the options provided (Vegan, Vegetarian, Gluten-free, or None).
* **Food Preference**: If you have any preferences for food, please select all that apply (Appetizer, Main Course, Dessert, or None).
* **Arrival Time**: If you know when you will arrive, please enter the time here.
* **Arrival Date**: If you know the date you will arrive, please enter the date here.
* **Note**: If you have any additional information or comments, please enter them here.
* **Company Name**: If you are representing a company, please enter the name here.
* **Job Title (Company)**: If you have a job title at your company, please enter it here.
* **Job Function**: If you have a job function at your company, please enter it here.
* **Job Department**: If you have a department at your company, please enter it here.
* **Job Level**: If you have a job level at your company, please enter it here.
* **Contact Method**: If you prefer to be contacted by a specific method (phone, email, or in-person), please enter it here.
* **Confirm**: Please confirm that you are attending the event.
* **Arrival Mode**: If you are planning to arrive by car, public transportation, or by walk, please select one of the options provided.
* **Parking Info**: If you will be bringing a car, please enter any necessary parking information.
* **Arrival Info**: If you have any specific arrival information (e.g. flight number), please enter it here.
* **Additional Info**: If you have any additional information or comments, please enter them here.
