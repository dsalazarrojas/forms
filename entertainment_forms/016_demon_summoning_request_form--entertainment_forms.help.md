# Demon Summoning Request Form - Help Guide
## Purpose
The Demon Summoning Request Form is a tool used by the Department of Magical Affairs to gather information for summoning requests from various departments. This form ensures that all necessary information is collected and submitted to the correct department for processing.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the scheduling preferences for your summoning request. You can choose multiple options, but please note that this field is optional.
2. Provide a brief description of your request in the Request Details field. Please choose one of the provided options.
3. If required, select a date for the summoning to take place. If not required, you can leave this field blank.
4. Specify your preferred time for the summoning. This field is optional and only required if the scheduling date is also selected.
5. In the Ritual Type field, provide a short description of the ritual you wish to perform.
6. Add any additional information you feel is necessary in the Additional Info field.

## Field-by-Field Explanation
### Scheduling Preferences
* **Scheduling Preferences (select_multiple)**: Choose the scheduling options that best fit your needs. This field is optional.
### Request Details
* **Request Details (select_one)**: Select the option that best describes your request. This field is optional.
### Scheduling Date
* **Scheduling Date (date)**: If you've selected scheduling options, you can choose a date for the summoning. This field is optional.
### Preferred Time
* **Preferred Time (time)**: Specify your preferred time for the summoning. This field is optional and only required if a scheduling date is selected.
### Ritual Type
* **Ritual Type (text)**: Provide a short description of the ritual you wish to perform.
### Additional Info
* **Additional Info (note)**: Add any additional information you feel is necessary for the summoning process. This field is optional.
