### Purpose
The new_years_eve_post_event_survey form is designed to gather feedback from attendees of New Year's Eve events. The form aims to collect information about their experiences, satisfaction, and suggestions for improvements.

Please confirm that:
- You were an attendee of our New Year's Eve event.
- You have not filled out this form already.

### new_years_eve_post_event_survey - Help Guide

## How To Complete This Form

1. Please provide honest and detailed feedback about your experience at the event. This will help us understand what we do well and what we can improve.
2. Choose your level of satisfaction with the event. Select one of the options that best describes your feelings.
3. Check the boxes for the event preferences you enjoyed the most. You can choose multiple options.
4. If you have any suggestions for improvement, please provide them in the text field. Be as specific as possible.
5. If you'd like to be contacted for further discussion, please provide your contact information.
6. If you'd like to be contacted, make sure to fill out the email field.
7. If you'd like to be contacted, make sure to fill out the phone field.
8. If you have any other details to share, please include them in the "Other Details" field.
9. If you'd like to be contacted again, please fill out the "Email (Repeat)" field.
10. If you'd like to be contacted again, please fill out the "Phone (Repeat)" field.

## Field-by-Field Explanation

* **Event Experience** (text, optional): This field is for you to describe your experience at the event. Please be as detailed as you can.
* **Overall Satisfaction** (select one, optional): Select one of the following options:
	+ Very Satisfied
	+ Somewhat Satisfied
	+ Somewhat Dissatisfied
	+ Very Dissatisfied
* **Event Preferences** (select multiple, optional): Check the boxes for the event preferences you enjoyed the most:
	+ Music
	+ Food and Drinks
	+ Decorations
	+ Other (please specify)
* **Suggestions for Improvement** (text, optional): If you have any suggestions for improvement, please provide them in this field. Be as specific as you can.
* **Contact Info** (text, optional): If you'd like to be contacted, please provide your contact information.
* **Email** (email, optional): If you'd like to be contacted, make sure to fill out this field.
* **Date** (date, optional): If you'd like to be contacted, please fill out this field.
* **Time** (time, optional): If you'd like to be contacted, please fill out this field.
* **Other Details** (note, optional): If you have any other details to share, please include them in this field.
* **Email (Repeat)** (email, optional): If you'd like to be contacted again, please fill out this field.
* **Phone (Repeat)** (text, optional): If you'd like to be contacted again, please fill out this field.

## Tips

* Please be honest and detailed in your feedback.
* You can choose multiple options for "Event Preferences".
* If you'd like to be contacted, please fill out the contact fields.
* Please make sure to fill out the "Email (Repeat)" and "Phone (Repeat)" fields if you'd like to be contacted again.
* If you have any other details to share, please include them in the "Other Details" field.
