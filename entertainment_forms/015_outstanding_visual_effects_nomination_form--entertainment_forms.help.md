# Outstanding Visual Effects Nomination Form - Help Guide
## Purpose

This form is used to collect nominations for outstanding visual effects projects. Please fill it out if you have a project you believe deserves recognition.

## How To Complete This Form

1. Review each section of the form carefully and fill out all required fields. The form is divided into several sections, each with its own set of fields. Please complete each section in order.
2. For each field, enter your response according to the instructions provided.
3. Ensure you complete all required fields (marked as required: true).

## Field-by-Field Explanation

* **Goals** (id: 1, type: select_multiple, required: false): 
  This field allows you to specify the goals of your project. Please select all goals that apply. 
  - 'Yes' for each goal you believe your project achieves.

* **Name** (id: 7, type: text, required: true): 
  Enter the name of the project you are nominating.

* **Email** (id: 3, type: email, required: false): 
  If you have an email address related to your project, you can enter it here.

* **Phone** (id: 4, type: text, required: false): 
  If you have a phone number related to your project, you can enter it here.

* **Project Type** (id: 6, type: select_one, required: false): 
  Choose the category your project belongs to. 
  - Option 1, Option 2, Option 3, or Option 4.

* **Project Name** (id: 7, type: text, required: true): 
  Enter the name of the project.

* **URL** (id: 8, type: text, required: true): 
  Provide the web URL associated with the project.

* **Description** (id: 8, type: text, required: true): 
  Write a brief description of your project.

* **Submitter** (id: 11, type: text, required: true): 
  Enter your name or the name of the person submitting the project. 

## Tips

* Ensure all required fields (marked as required: true) are completed before submitting the form.
* Be specific and accurate when filling out each field.
* Double-check your answers to ensure they are correct before submitting the form.
