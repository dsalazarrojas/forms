# Theater Property Inventory Request Form - Help Guide
## Purpose
The Theater Property Inventory Request Form is used to collect information about theater property inventory requests. It helps the inventory team to gather all the necessary details for processing and managing requests efficiently.

## How To Complete This Form

1. Select the "Request Type" field to indicate the purpose of the request (e.g., maintenance, renovation, etc.).
2. Enter the "Requestor Name", "Requestor Email", and "Requestor Phone" fields with the relevant information.
3. Fill in the "Request Details" field with a clear and concise description of the request.
4. Select a date and time for the "Request Date" field.
5. If applicable, select one or more "Related Properties" that are related to the request.
6. Choose the "Request Status" to indicate the current status of the request (e.g., pending, approved, rejected).
7. Enter any "Request Comments" regarding the request.
8. Fill in the "Submitter Name", "Submitter Title", "Submitter Email", and "Submitter Phone" fields with the relevant information.
9. Select one or more "Submitter Approvals" required for the request.
10. Enter any additional notes in the "Submitter Notes" fields if necessary.
11. Finally, click the submit button to complete the form.

## Field-by-Field Explanation

* **Request Details**: A clear and concise description of the request.
* **Requestor Name**: The name of the person submitting the request.
* **Requestor Email**: The email address of the person submitting the request.
* **Requestor Phone**: The phone number of the person submitting the request.
* **Request Date**: The date the request was submitted.
* **Request Time**: The time the request was submitted (optional).
* **Request Type**: A selection of the purpose of the request (e.g., maintenance, renovation, etc.).
* **Request Description**: A detailed description of the request.
* **Related Properties**: A list of properties related to the request (optional).
* **Request Status**: The current status of the request (e.g., pending, approved, rejected).
* **Request Comments**: Any additional comments regarding the request.
* **Submitter Name**: The name of the person submitting the form on behalf of the requestor.
* **Submitter Title**: The title of the person submitting the form.
* **Submitter Email**: The email address of the person submitting the form.
* **Submitter Phone**: The phone number of the person submitting the form.
* **Submitter Notes**: Any additional notes from the person submitting the form.
* **Submitter Department**: The department of the person submitting the form (optional).
* **Submitter Role**: The role of the person submitting the form (e.g., manager, admin).
* **Submitter Approvals**: A list of approvals required for the request.
* **Submitter Notes 2**, **Submitter Notes 3**, **Submitter Notes 4**, **Submitter Notes 5**: Additional notes from the person submitting the form (optional).

Note: The fields marked as "optional" can be skipped if not applicable.
