# Script Rights Usage Request Form - Help Guide
## Purpose
This form is used to request script rights usage for a specific script. To complete this form, please follow the instructions below.

## How To Complete This Form
1. Select "Yes" or "No" to indicate if you want to request script rights usage.
2. Provide the details of the script you are requesting usage rights for.
3. Confirm if you have a license for the script.
4. Specify the type of usage you want for the script.
5. Enter the duration of the usage.
6. Enter the start and end dates for the usage.
7. Select the territories where the script will be used.
8. Select the languages that the script will be used in.
9. Provide any additional territory or language details.
10. Enter your payment information (if applicable).
11. Enter your contact details.
12. Confirm that you are submitting this form as the authorized representative.
13. Confirm your submitter's department, position, and title.
14. Confirm your company affiliation.
15. Enter any additional notes or comments.

## Field-by-Field Explanation
* **Script Rights Request** (`1`, `title`, required):
    * Please select "Yes" to indicate that you want to request script rights usage.
* **Submitter** (`2`, `submitter`, required):
    * Please select "Yes" to confirm that you are submitting this form as the authorized representative.
* **Script Details** (`3`, `script_details`, optional):
    * Please enter a description of the script you are requesting rights for.
* **License** (`4`, `license`, required):
    * Please confirm if you have a license for the script.
* **Usage Type** (`5`, `usage_type`, required):
    * Please select the type of usage you want for the script (e.g., commercial, non-commercial).
* **Duration** (`6`, `duration`, required):
    * Please enter the duration of the usage.
* **Start Date** (`7`, `start_date`, required):
    * Please enter the start date of the usage.
* **End Date** (`8`, `end_date`, required):
    * Please enter the end date of the usage.
* **Territory** (`9`, `territory`, required):
    * Please select the territories where the script will be used.
* **Language** (`10`, `language`, required):
    * Please select the languages that the script will be used in.
* **Territory Details** (`11`, `territory_details`, optional):
    * Please provide any additional details about the territory.
* **Language Details** (`12`, `language_details`, optional):
    * Please provide any additional details about the language.
* **Payment** (`13`, `payment`, optional):
    * Please enter your payment information (if applicable).
* **Submitter Details** (`14`, `submitter_details`, optional):
    * Please enter your contact information.
* **Submitter Email** (`15`, `submitter_email`, optional):
    * Please enter your email.
* **Submitter Phone** (`16`, `submitter_phone`, optional):
    * Please enter your phone number.
* **Submitter Address** (`17`, `submitter_address`, required):
    * Please select if you have a company address.
* **Submitter Department** (`18`, `submitter_department`, required):
    * Please confirm your department.
* **Submitter Position** (`19`, `submitter_position`, required):
    * Please confirm your position.
* **Submitter Title** (`20`, `submitter_title`, required):
    * Please confirm your title.
* **Submitter Company** (`21`, `submitter_company`, required):
    * Please confirm your company affiliation.
* **Submitter Notes** (`22`, `submitter_notes`, optional):
    * Please enter any additional notes or comments.
* **Submitter Signature** (`23`, `submitter_signature`, optional):
    * Please enter your signature (if required by your company).
* **Submitter Date** (`24`, `submitter_date`, optional):
    * Please enter the date of submission.
