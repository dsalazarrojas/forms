# Stage Rehearsal Time Request Form - Help Guide
## Purpose
This form is used by production teams to request and schedule stage rehearsal times. It is essential to have accurate and timely information about the event to ensure a smooth production process.

## How To Complete This Form
To complete this form, follow these steps:
1. Select the event date and time.
2. Choose the preferred time slots for the rehearsal.
3. Provide details about the event duration.
4. Specify any technical needs for the rehearsal.
5. Select the location where the rehearsal will take place.
6. Enter any additional notes about the event.

## Field-by-Field Explanation
- **Event Date** (`event_date`, date, required/optional): Select the date of the event.
- **Event Time** (`event_time`, time, required/optional): Select the time of the event.
- **Event Duration** (`event_duration`, number, required/optional): Enter the duration of the event in minutes.
- **Technical Needs** (`technical_needs`, text, required/optional): Provide any technical requirements for the rehearsal, such as sound or lighting equipment.
- **Rehearsal Location** (`stage_rehearsal_location`, select_one, required/optional): Select the location where the rehearsal will take place, such as Theaters or Schools.
- **Preferred Rehearsal Time** (`preferred_rehearsal_time`, select_multiple, required/optional): Choose the preferred time slots for the rehearsal, such as Morning, Afternoon, or Evening.
- **Notes** (`notes`, note, required/optional): Enter any additional notes about the event, such as special instructions or requirements.
