# DJSAMMACK'S Wedding DJ Planning Forms - Help Guide
## Purpose
This form is designed to gather information about wedding events to ensure that DJSammy's Wedding DJ team has all the necessary details to deliver an exceptional experience for the event.

## How To Complete This Form
To complete this form, please provide the required information for each field. Fields with a * are required, so be sure to fill those out.

## Field-by-Field Explanation

* **Music Style** (`music_style`, select_one, required): Select the style of music you would like DJSammy's Wedding DJ to play during the event. Choose from Rock, Jazz, Classical, Hip-Hop, Pop, Country, RnB, Electronic, Reggae, Blues, Folk, or World.
* **Number of Guests** (`number_of_guests`, number, required): Enter the expected number of guests attending the wedding event.
* **Start Date** (`start_date`, date, required): Enter the start date of the event in YYYY-MM-DD format.
* **End Date** (`end_date`, date, required): Enter the end date of the event in YYYY-MM-DD format.
* **Contact Name** (`contact_name`, text, required): Enter the name of the contact person responsible for the event.
* **Contact Phone** (`contact_phone`, text, required): Enter the phone number of the contact person.
* **Contact Email** (`contact_email`, email, required): Enter the email address of the contact person.
* **Contact Note** (`contact_note`, text, required): Provide any additional contact information or notes about the event.
* **Event Type** (`event_type`, text, required): Select the type of event (wedding).
* **Event Description** (`event_description`, text, required): Enter a brief description of the event.
* **Event Location** (`event_location`, text, required): Enter the location where the event will take place.
* **Music List** (`music_list`, text, required): Enter a list of specific songs or music genres you would like to be played.
* **Equipment Needed** (`equipment_needed`, text, required): List any specific equipment needed for the event.
* **Parking Info** (`parking_info`, text, required): Enter any parking information or instructions for the event location.
* **Photo Release** (`photo_release`, text, required): Provide any photo release information or instructions.
* **Terms** (`terms`, text, required): Review and agree to the terms of service.
* **Budget** (`budget`, number, optional): Enter the budget for the event (if applicable).
* **Date** (`date`, date, optional): Enter the date of the event (if not the start date).
* **Time** (`time`, time, optional): Enter the time of the event (if not the start time).
* **Venue** (`venue`, text, optional): Enter the venue or location of the event (if not the event location).
* **Contact Address** (`contact_address`, text, optional): Enter the address of the contact person (if not using contact name).
* **Contact Website** (`contact_website`, text, optional): Enter the website of the contact person (if not using contact email).
* **Additional Notes** (`additional_notes`, text, optional): Enter any additional notes about the event.
