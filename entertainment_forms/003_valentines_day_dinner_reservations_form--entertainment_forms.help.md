# Valentines Day Dinner Reservations Form - Help Guide
## Purpose
This form is used to collect information for Valentines Day dinner reservations.

## How To Complete This Form
- To complete this form, enter the following information:
    - Fill out the name and email fields with the customer's name and email address.
    - Enter the phone number of the customer.
    - For the time and date fields, select the desired reservation time and date for one table.
    - Select the number of guests.
    - Enter any special requests for the reservation in the "Special Requests" field.
    - Repeat this process for the second table by entering the time and date for the second table.
    - In the "Payment Method" field, select the payment option desired (yes/no).
    - Select the card type, whether it is yes/no.
    - Enter the card holder's name in the "Card Holder Name" field.
    - Enter the card number and cvv for the first card.
    - Select whether the card expiration month, year, and cvv are yes/no, and enter the expiration month and year for the card.
    - Repeat the process for the second card by entering the card number and cvv and selecting whether the card expiration month, year, and cvv are yes/no.

## Field-by-Field Explanation

* **Reservation Details** (`1`, `text`, required: false): Enter a brief description of the reservation.
* **Name** (`2`, `text`, required: false): Enter the customer's name.
* **Email** (`3`, `email`, required: false): Enter the customer's email address.
* **Phone** (`4`, `text`, required: false): Enter the customer's phone number.
* **Time** (`5`, `time`, required: false): Select the desired reservation time for one table.
* **Reservation Date** (`6`, `text`, required: false): Select the desired reservation date for one table.
* **Guests Count** (`8`, `number`, required: false): Select the number of guests for one table.
* **Special Requests** (`9`, `text`, required: false): Enter any special requests for the reservation.
* **Reservation Time 2** (`10`, `time`, required: false): Select the desired reservation time for the second table.
* **Reservation Date 2** (`11`, `date`, required: false): Select the desired reservation date for the second table.
* **Payment Method** (`12`, `select_multiple`, required: false): Select the payment method desired (yes/no).
* **Card Type** (`13`, `select_one`, required: false): Select whether the card type is yes/no.
* **Card Holder Name** (`14`, `text`, required: false): Enter the card holder's name.
* **Card Number** (`15`, `text`, required: false): Enter the card number.
* **CVV** (`16`, `select_one`, required: false): Select whether the cvv is yes/no.
* **Expiration Date** (`17`, `date`, required: false): Select the card expiration date (month/year).
* **Expiration Month** (`18`, `select_one`, required: false): Select whether the card expiration month is yes/no.
* **Expiration Year** (`19`, `select_one`, required: false): Select whether the card expiration year is yes/no.
* **Cvv 2** (`20`, `select_one`, required: false): Select whether the cvv2 is yes/no.
* **Card Number 2** (`21`, `select_one`, required: false): Select whether the card number 2 is yes/no.
* **Security Code** (`22`, `select_one`, required: false): Select whether the security code is yes/no.
* **Card Type 2** (`23`, `select_one`, required: false): Select whether the card type 2 is yes/no.
* **Card Holder Name 2** (`24`, `select_one`, required: false): Select whether the card holder name 2 is yes/no.
* **Payment Method 2** (`25`, `select_one`, required: false): Select whether the payment method 2 is yes/no.
