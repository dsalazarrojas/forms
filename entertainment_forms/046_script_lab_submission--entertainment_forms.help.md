# Script Lab Submission - Help Guide
## Purpose
The Script Lab Submission form is used to submit a script for evaluation in a Script Lab environment. It collects information about the script, including category, description, assigned tool, and output files.

## How To Complete This Form
To complete this form, follow these steps:
1. Select the category of your submission from the provided options.
2. Write a brief description of your script.
3. Choose the tool used for your submission.
4. Enter a unique Form ID and a description of the output file.
5. Optionally, enter another unique Form ID and select another tool.

## Field-by-Field Explanation
* **Category** (`category`, required, select_one):
  This field allows you to select the category for your submission. Select one of the provided options, either "Entertainment" or "Other".
* **Description** (`description`, required, text):
  Provide a brief description of your script.
* **Assigned Tool** (`assigned_tool`, required, select_one):
  Choose the tool used for your submission. You can select either "chatjimmy" or "Other".
* **Form ID** (`form_id`, required, number):
  Enter a unique ID for your submission.
* **Output File** (`output_file`, required, text):
  Upload your output file for evaluation.
* **File Description** (`file_description`, required, text):
  Provide a description of the uploaded output file.
* **Duplicate Form ID** (`form_id_2`, optional, text):
  Enter another unique ID (optional).
* **Another Assigned Tool** (`assigned_tool_2`, optional, select_one):
  Select another tool (optional, default to "Other"). 

## Tips
- Make sure you have all the necessary information and files before submitting the form.
- Some fields are required, so ensure they are filled in for a valid submission.
- If you're unsure about any field, refer to the field-by-field explanation above.
