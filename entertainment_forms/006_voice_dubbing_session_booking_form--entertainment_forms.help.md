# Voice Dubbing Session Booking Form - Help Guide
## Purpose
The Voice Dubbing Session Booking Form is a tool used to book voice dubbing sessions for specific projects or events. This form ensures that clients can provide necessary information to complete the session booking process.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the type of dubbing required (e.g., voiceover, dubbing, etc.)
2. Choose a date for the session
3. Select the start and end times of the session
4. Enter your contact number in case the team needs to reach you
5. Provide any additional message or instructions (optional)

## Field-by-Field Explanation

* **Dubbing Type** (`dubbing_type`, select_one, required): Select the type of dubbing required for your project. This field determines the type of voice talent needed for the session.
* **Date** (`date`, required): Choose a date for the voice dubbing session. Please note that the session will be scheduled on the selected date.
* **Start Time** (`start_time`, required): Choose the start time for the voice dubbing session. The session will commence on the selected start time.
* **End Time** (`end_time`, required): Choose the end time for the voice dubbing session. The session will conclude on the selected end time.
* **Client** (`client`, text, optional): Enter the name or company name of the client for whom you are booking the session. If you don't select this field, your name or the name of the company you represent will be used.
* **Contact Number** (`contact_number`, required): Enter your contact number in case the team needs to reach you to confirm the session details.
* **Message** (`message`, note, optional): If you have any additional instructions or details about the session, you can provide them here. This information will be passed to the voice talent.
