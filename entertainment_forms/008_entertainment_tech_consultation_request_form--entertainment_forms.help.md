# entertainment_tech_consultation_request_form - Help Guide
## Purpose
The purpose of this form is to collect information about a specific project's technical requirements, such as project details, project manager's name, project start and end dates, project status, location, description, and technology requirements. This form will help the internal team to better understand the project and provide relevant technical consultation.

## How To Complete This Form
To complete this form, please follow the steps below:

1. Enter the project details, including the project manager's name and project start and end dates.
2. Select the project status as Active or Inactive.
3. Provide a description of the project and enter the project location.
4. Select the required technologies, such as Video Equipment, Photography, or Audio.
5. Enter the budget allocated for the project.
6. Enter any additional notes about the project.

## Field-by-Field Explanation

### Project Details
* **Project Details** (`project_details`, text, optional): Enter a brief description of the project.
* **Project Manager** (`project_manager`, text, optional): Enter the name of the project manager.
* **Project Start Date** (`project_start_date`, date, optional): Enter the start date of the project in MM/DD/YY format.
* **Project End Date** (`project_end_date`, date, optional): Enter the end date of the project in MM/DD/YY format.
* **Project Status** (`project_status`, select_one, optional): Select the status of the project as Active or Inactive.

### Project Information
* **Project Location** (`project_location`, text, optional): Enter the project location.
* **Project Description** (`project_description`, text, optional): Provide a description of the project.

### Technology Requirements
* **Technology Requirements** (`technology_requirements`, select_multiple, optional): Select the required technologies, such as Video Equipment, Photography, or Audio.

### Project Resources
* **Budget Allocated** (`budget_allocated`, number, optional): Enter the budget allocated for the project.
* **Notes** (`notes`, text, optional): Enter any additional notes about the project.

## Tips
* Please ensure that you have filled out all the required fields before submitting the form.
* If you are unsure about any field, please refer to the field's hint for clarification.
* If you need to make changes to an existing request, please contact the internal team for further assistance.
