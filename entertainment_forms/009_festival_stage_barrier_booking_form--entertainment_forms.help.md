# festival_stage_barrier_booking_form - Help Guide
## Purpose
This form is used to book barrier details for festival stage and manage overall barrier bookings for events.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the stage barrier details in the designated field.
2. Specify the quantities of each barrier that need to be booked.
3. Choose the delivery timing that suits your needs.
4. Provide your contact details so we can get in touch with you.
5. Check the barrier status to confirm whether the barrier is available or not.
6. (Optional) Add any additional notes for the delivery team.
7. (Optional) Add any additional details for the barrier.

## Field-by-Field Explanation
* **stage_barrier_details** (Stage Barrier Details, Text, Required): Enter a brief description of the stage barrier you need to book.
* **barrier_quantities** (Barrier Quantities, Text, Required): Specify the quantities of each barrier that need to be booked.
* **delivery_location** (Delivery Location, Text, Not Required): Enter the location where the barrier needs to be delivered.
* **delivery_timing** (Delivery Timing, Text, Required): Choose the timing for the barrier delivery that suits your needs.
* **delivery_notes** (Delivery Notes, Text, Not Required): Add any additional notes for the delivery team.
* **contact_details** (Contact Details, Text, Required): Provide your contact details so we can get in touch with you.
* **notes** (Notes, Text, Not Required): Add any additional notes for the barrier booking.
* **barrier_status** (Barrier Status, Select One, Required): Check the barrier status to confirm whether the barrier is available or not.
* **rental_details** (Rental Details, Text, Not Required): Add any additional details for the barrier.
* **delivery_details** (Delivery Details, Text, Not Required): Add any additional details for the barrier delivery.
* **contact_name** (Contact Name, Text, Not Required): Enter your name for contact purposes.
* **contact_email** (Contact Email, Email, Not Required): Enter your email address for contact purposes.
* **contact_phone** (Contact Phone, Text, Not Required): Enter your phone number for contact purposes.
* **venue_location** (Venue Location, Text, Not Required): Enter the location of the venue.
* **notes_1** (Notes 1, Text, Not Required): Add any additional notes for the barrier.
* **notes_2** (Notes 2, Text, Not Required): Add any additional notes for the barrier.
* **barrier_1_details** (Barrier 1 Details, Text, Not Required): Add any additional details for barrier 1.
