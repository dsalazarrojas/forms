# Character Sheet Template - Help Guide
## Purpose
The Character Sheet Template is used to create a comprehensive profile for each character, including their name, level, attributes, skills, equipment, backstory, and any temporary notes or changes. This template helps players and game masters quickly reference and update character information during gameplay.

## How To Complete This Form

To complete this form, follow these steps:

1. **Header Section**: This section is optional and serves as a title for the character sheet. You can leave it blank or add a brief description of the character.
2. **Character Name**: Enter the name of the character, which will be used in gameplay and reference purposes.
3. **Player Name**: Enter the name of the player controlling the character, which helps identify who is playing the character.
4. **Level**: Enter the character's current level, indicating their progress and development.
5. **Attributes**: List the character's core stats, such as strength, agility, intelligence, etc.
6. **Skills**: List the character's notable skills or proficiencies, such as languages, combat styles, or magical abilities.
7. **Equipment**: List the character's primary gear and possessions, including weapons, armor, and tools.
8. **Backstory**: Enter a brief history or origin story for the character, providing context and depth to their personality and motivations.
9. **Notes**: Add any session notes or temporary changes to the character, such as recent injuries or plot developments.
10. **Last Updated**: Enter the date of the last update to the character sheet, helping track changes and updates.
