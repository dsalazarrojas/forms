# Soundtrack Rights Usage Request Form - Help Guide
## Purpose
The Soundtrack Rights Usage Request Form is a tool used to request usage rights for a project's soundtrack. This form collects information from both the composer and the client to ensure that all necessary rights are acquired and terms are agreed upon.

## How To Complete This Form
To complete this form, follow the steps below:

1. Provide the project name.
2. Select the project type.
3. Choose the project status.
4. Enter the project date.
5. Enter the composer's name.
6. Enter the composer's email address.
7. Enter the composer's phone number.
8. Describe the usage terms.
9. Enter the composer's notes.
10. Enter the project URL.
11. Enter the client's name.
12. Enter the client's email address.
13. Enter the client's phone number.
14. Enter the project deadline.
15. Enter the client's notes.
16. Select the composer's agreement status.
17. Select the client's agreement status.
18. Describe the payment terms.
19. Describe any payment details.
20. Select the license type.
21. Enter the composer's license information.
22. Enter the composer's license URL.
23. Select the client's license status.
24. Enter the client's license URL.
25. Submit the form.

## Field-by-Field Explanation
* **Project Name** (`project_name`, Text, Optional): Enter the full name of the project.
* **Project Type** (`project_type`, Select One, Optional): Select the category of the project.
* **Project Status** (`project_status`, Select One, Optional): Choose the current status of the project.
* **Project Date** (`project_date`, Date, Optional): Enter the project's start date.
* **Composer Name** (`composer_name`, Text, Optional): Enter the full name of the composer.
* **Composer Email** (`composer_email`, Email, Optional): Enter the composer's email address.
* **Composer Phone** (`composer_phone`, Text, Optional): Enter the composer's phone number.
* **Usage Terms** (`usage_terms`, Text, Optional): Describe the usage terms for the project's soundtrack.
* **Composer Notes** (`composer_notes`, Note, Optional): Enter any additional notes from the composer.
* **Project URL** (`project_url`, Text, Optional): Enter the URL of the project.
* **Client Name** (`client_name`, Text, Optional): Enter the full name of the client.
* **Client Email** (`client_email`, Email, Optional): Enter the client's email address.
* **Client Phone** (`client_phone`, Text, Optional): Enter the client's phone number.
* **Project Deadline** (`project_deadline`, Date, Optional): Enter the project's deadline.
* **Client Notes** (`client_notes`, Note, Optional): Enter any additional notes from the client.
* **Composer Agreement** (`composer_agreement`, Select One, Optional): Select the composer's agreement status.
* **Client Agreement** (`client_agreement`, Select One, Optional): Select the client's agreement status.
* **Payment Terms** (`payment_terms`, Text, Optional): Describe the payment terms for the project.
* **Payment Details** (`payment_details`, Text, Optional): Describe any payment details.
* **License Type** (`license_type`, Select One, Optional): Select the type of license for the project.
* **Composer License** (`composer_license`, Text, Optional): Enter the composer's license information.
* **Composer License URL** (`composer_license_url`, Text, Optional): Enter the URL of the composer's license.
* **Client License** (`client_license`, Select One, Optional): Select the client's license status.
* **Client License URL** (`client_license_url`, Text, Optional): Enter the URL of the client's license.
* **Submit** (`submit`, Text, Optional): Click the submit button to submit the form.

Note that all fields are optional, so users can fill in only the information that is relevant to their project.
