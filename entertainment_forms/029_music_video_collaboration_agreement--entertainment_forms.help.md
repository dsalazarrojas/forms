# music_video_collaboration_agreement - Help Guide
## Purpose
The music_video_collaboration_agreement form is used to collect collaboration agreements for music and video projects. This form gathers information about project details, role allocation, start and end dates and times, location, and description to ensure that everyone is on the same page and aware of their responsibilities and commitments.

## How To Complete This Form
To complete this form, follow these steps:

1. **Select the project details**: Enter a brief description of the project in the `Project Details` field. This field is not required but helps keep track of the project's summary.
2. **Choose roles**: Select the collaborators' roles in the project from the list of available options (`Yes` or `No`). This is a required field, so make sure to select a role for each collaborator.
3. **Set project schedule**: Enter the start and end dates for the project. These fields are not required but help in scheduling and planning.
4. **Specify start and end times**: Enter the start and end times for the project. These fields are not required but help in time-sensitive projects.
5. **Enter location**: If the project location is important, enter it in the `Location` field. This field is not required but helps in project coordination.
6. **Description**: Enter a brief description of the project, which can be used for reference or future project updates. This field is not required but helps in keeping track of project notes.

## Field-by-Field Explanation
* **Project Details** (`project_details`, text, optional): Enter a brief description of the project.
* **Role** (`role`, select_multiple, required): Select the collaborator's role in the project from the options provided.
* **Start Date** (`start_date`, date, optional): Enter the start date of the project.
* **Start Time** (`start_time`, time, optional): Enter the start time of the project.
* **End Date** (`end_date`, date, optional): Enter the end date of the project.
* **End Time** (`end_time`, time, optional): Enter the end time of the project.
* **Location** (`location`, text, optional): Enter the project location.
* **Description** (`description`, text, optional): Enter a brief description of the project for reference or future project updates.

## Tips
* Make sure to select a role for each collaborator to avoid incomplete agreements.
* Use the project description field for reference or future project updates.
* If the project location is important, ensure to enter it to avoid confusion.
* Review and validate the data before sending it to collaborators to prevent duplication and errors.
