The Karaoke Request Form is used to request a specific song to be played during a karaoke session. To ensure accurate processing and efficient execution, please complete the form carefully and avoid duplicate requests. Duplicate requests may lead to delays or conflicts with other events. If you have already submitted a request for the same song, please do not resubmit it. If you need help or have any concerns, please contact the event organizers.

## Karaoke Request Form - Help Guide

## Purpose
The Karaoke Request Form is designed to help you request a song to be played during a karaoke session. Your input will help our team determine which songs to play and ensure a smooth and enjoyable experience for all attendees.

## How To Complete This Form
To complete the Karaoke Request Form, follow these steps:

* Click on the "Song Request" page.
* Enter the name of the song you would like to request.
* If you have a specific song in mind that is not listed in the options, select the closest match or choose "None" to indicate a custom request.
* Select a time slot for the song to be played. Make sure to choose a time slot that works for you and the event schedule.
* Select a date for the song to be played. Ensure it matches the event date.
* Add any additional notes or requests to the "Operator Note" field, if necessary.
* Click the "Submit" button to send your request.

## Field-by-Field Explanation

* **Song Request** (Song Request, text, required):
    Enter the name of the song you would like to request. Please be as specific as possible, e.g., "Hotel California" by Eagles.
* **Song Selection** (Song Selection, select_one, optional):
    Choose a song from the list provided or select "None" if you have a specific custom request. If no song matches your request, choose "None" to indicate a custom request.
* **Request Time** (Request Time, time, required):
    Select the time slot you would like the song to be played. Please ensure it matches the event schedule.
* **Request Date** (Request Date, date, required):
    Select the date you would like the song to be played. Ensure it matches the event date.
* **Operator Note** (Operator Note, note, optional):
    Add any additional notes or requests to the operator note field, if necessary. This will help the operator understand your request better.

## Tips
* Please be considerate of others and request songs that fit the event theme and atmosphere.
* If you are unsure about the song you are requesting, you can ask the event organizers for guidance.
* Remember to review and submit only one request per song to avoid duplicate requests.
