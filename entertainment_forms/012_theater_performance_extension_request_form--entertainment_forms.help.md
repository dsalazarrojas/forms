# Theater Performance Extension Request Form - Help Guide
## Purpose
The Theater Performance Extension Request Form is a form used to request an extension to a theater performance. It is used for production companies to request additional dates or approval for a specific type of extension.

## How To Complete This Form
Before starting, please review the form carefully to ensure that all required fields are filled out accurately.

## Field-by-Field Explanation
* **Production Company** (1, text, required): Enter the name of the production company.
* **Production Name** (2, text, required): Enter the name of the production.
* **Start Date** (3, date, required): Enter the start date of the performance.
* **End Date** (4, date, required): Enter the end date of the performance.
* **Extension Request Type** (5, select_one, required): Choose the type of extension requested (e.g., Additional Dates or Approval).
* **Approval Person** (6, text, optional): If an approval is requested, enter the name of the person approving the extension.
* **Notes** (7, note, optional): Enter any additional notes or comments.
* **Production Team** (8, select_multiple, required): Select the production team members.
* **Contact Person** (9, select_one, optional): Choose the person to contact for more information.
* **Email** (10, email, required): Enter the email address of the person filling out the form.
* **Phone** (11, text, required): Enter the phone number of the person filling out the form.
* **Venue** (12, text, required): Enter the venue where the performance will be held.
* **Performance Days** (13, number, optional): If applicable, enter the number of performance days.
* **Performance Time** (14, time, optional): If applicable, enter the performance time.
* **Additional Notes** (15, note, optional): Enter any additional notes or comments.
* **Production Location** (16, text, optional): Enter the location of the production.
* **Show Start Date** (17, date, optional): Enter the start date of the show.
* **Show End Date** (18, date, optional): Enter the end date of the show.
* **Production Duration** (19, number, optional): If applicable, enter the production duration.
* **Show Length** (20, text, optional): Enter the length of the show.
* **Show Type** (21, select_one, required): Choose the type of show (e.g., Matinee or Evening).
* **Show Days** (22, select_multiple, required): Select the days of the show.
* **Show Time** (23, time, required): Enter the show time.
* **Approval Status** (24, select_one, required): Choose the approval status of the request.

## Tips
* Please ensure that all required fields are filled out accurately.
* Review the form carefully to avoid duplication of requests.
* If you are unsure about any field, please contact the production team for clarification.
* If you are requesting an approval, please ensure that the approval person is entered correctly.
