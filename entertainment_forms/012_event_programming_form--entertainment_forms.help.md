# Event Programming Form - Help Guide
## Purpose
The Event Programming Form is used to collect information about events, such as events organized by an individual or team. This form helps event organizers provide details about their events to participants or other stakeholders.

## How To Complete This Form
To complete this form, follow these steps:

1. Start by providing the event title.
2. Select the date of the event.
3. Choose the time of the event.
4. Select the event location from the provided options.
5. Add any additional event details in the note section.
6. If necessary, add any notes about the event.
7. Choose the tool assigned to the event.
8. Enter a unique identifier for the event.
9. Select the version of the event programming form being used.

## Field-by-Field Explanation

* **Event Organizer Information** (`event_organizer_info`): This field is used to enter any information about the person or team organizing the event. (Required)
* **Event Date** (`event_date`): Select the date of the event.
* **Event Time** (`event_time`): Choose the time of the event.
* **Event Location** (`event_location`): Select the location where the event will take place.
* **Event Details** (`event_details`): Add any additional information about the event, such as the purpose, goals, or objectives.
* **Event Notes** (`event_notes`): Enter any notes about the event, such as important reminders or additional details.
* **Assigned Tool** (`assigned_tool`): Choose the tool assigned to the event, if applicable.
* **Event ID** (`event_programming_form_id`): Enter a unique identifier for the event, if required.
* **Event Version** (`event_programming_form_version`): Select the version of the event programming form being used.

## Tips
* Make sure to provide accurate and up-to-date information about the event.
* Double-check all fields before submitting the form.
* If you have any questions or need help with this form, contact the event organizer or support staff.
