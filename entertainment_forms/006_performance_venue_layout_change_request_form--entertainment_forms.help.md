# Performance Venue Layout Change Request Form - Help Guide

## Purpose
This form is used to request changes to the layout of a performance venue. This could include changes such as moving or rearranging seating, altering stage positions, or modifying any other aspect of the venue's layout.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the correct "Performance Venue" from the dropdown menu. This ensures that your request is submitted for the correct location.
2. Enter your name and role to help the venue management team understand your request.
3. Provide a detailed description of the changes you would like to make to the layout.
4. Enter the date you would like the changes to be made by.
5. Enter the date the changes were actually completed, if applicable.
6. You can add any additional comments or information about your request.
7. If necessary, provide any other relevant information.

## Field-by-Field Explanation
* **Performance Venue**: Select the correct venue where you are requesting the layout change. This helps the venue management team understand where the changes are to be made.
* **Name**: Enter your name as you would like to be listed on the request.
* **Role**: Enter your role in relation to the venue, such as performer, event coordinator, or manager.
* **Request Description**: A detailed description of the changes you would like to make to the layout, including any specific details about what, where, and why you are requesting these changes.
* **Date**: Enter the date you would like the changes to be made by. This will help the venue management team plan and schedule the changes.
* **Time**: Enter the time you would like the changes to be completed by, if applicable. If not applicable, leave this field blank.
* **Email**: Enter your email address so the venue management team can contact you about your request.
* **Phone**: Enter your phone number in case the venue management team needs to contact you by phone.
* **Change Request**: Enter any additional details about the changes you are requesting, such as why the changes are necessary or what specific actions you would like the venue management team to take.
* **Change Reason**: Enter the reason you are requesting these specific changes.
* **Layout Details**: Enter any additional details about the layout changes you are requesting, such as specific measurements or configurations.
* **Expected Completion Date**: Enter the date by which you expect the changes to be completed.
* **Actual Completion Date**: If the changes have already been completed, enter the date when they were actually completed.
* **Comments**: Add any additional comments or information about your request.
* **Additional Comments**: Add any other comments or information that is not covered in the main comments section.
* **Reference**: Add any relevant references, such as documents or images, that support your request.
* **Other**: Add any other information that is not covered in the above fields.
