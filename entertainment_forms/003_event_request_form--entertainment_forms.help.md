## event_request_form - Help Guide

## Purpose
The `event_request_form` is a form used to submit requests for events, allowing users to provide information about the event and contact details for the event requesters. This form is intended for internal use within the organization and is used to gather necessary information for processing event requests.

## How To Complete This Form

1.  Enter a title for the event in the **Event Description** field. This will be used to identify the event.
2.  Provide information about the event in the **Event Details** field.
3.  Choose the venue for the event from the available options in the **Venue** field.
4.  Select the **Event Status** of the event from the available options.
5.  Add any necessary **Event Tags** to categorize the event.
6.  Enter the contact information for the event requester in the **Contact Information** field.
7.  Fill in the **Event Dates** field with the requested dates for the event.
8.  Enter any additional information about the event in the **Event Organizer Notes** field.

## Field-by-Field Explanation

*   **Event Request Form**: (required) - The main title for this form.
*   **Event Description**: (required) - A brief description of the event.
*   **Event Details**: (required) - Detailed information about the event.
*   **Contact Information**: (required) - Information about the person or organization requesting the event.
*   **Event Dates**: (required) - The date(s) of the event.
*   **Event Status**: (required) - The status of the event.
*   **Event Tags**: (required) - Categories the event into (e.g. charity, conference, seminar).
*   **Event Organizer Information**: (required) - Information about the person or organization hosting the event.
*   **Event Organizer Notes**: (required) - Any additional notes about the event.
*   **Event Requester Agreement**: (required) - An agreement that the event request is accurate.
*   **Event Organizer Agreement**: (required) - An agreement that the event organizer is aware of the event details.
*   **Venue**: (optional) - The location where the event will take place.
*   **Event Organizer Email**: (optional) - The email address of the event organizer.
*   **Event Organizer Phone**: (optional) - The phone number of the event organizer.
*   **Event Organizer Title**: (optional) - The title of the event organizer.
*   **Event Requester Email**: (optional) - The email address of the event requester.
*   **Event Requester Phone**: (optional) - The phone number of the event requester.
*   **Event Requester Organization**: (optional) - The organization of the event requester.
*   **Event Requester Name**: (optional) - The name of the event requester.
*   **Event Requester Notes**: (optional) - Any additional notes about the event requester.
*   **Event Requester Agreement**: (optional) - An agreement that the event requester is aware of the event details.
*   **Event Requester Additional Info**: (optional) - Additional information about the event requester.
*   **Event Organizers Information**: (optional) - Any additional information about the event organizers.
*   **Event Organizers Notes**: (optional) - Any additional notes about the event organizers.

Note: This explanation assumes that all fields are required unless otherwise stated. If a field is optional, it is marked as such in the Field-by-Field Explanation section.
