# Virtual Basket Raffle Form - Help Guide

## Purpose
The Virtual Basket Raffle Form is used to create and manage virtual events or activities with a basket theme. This form collects information about the event details, participants, and schedule.

## How To Complete This Form
To fill out this form, follow these steps:

1. Select the correct page from the options provided. The available pages are:
	* Home: This is the main page where you can view the overall event information.
2. Fill out the form sections based on the page you are on. Each section has a specific purpose and corresponding fields.

## Field-by-Field Explanation

* **Home** (`Page 1`, required: false): This is the main page where you can view the overall event information.
* **Basket Details** (`Page 2`, required: false): Enter a brief description of the virtual basket event.
* **Participant Name** (`Page 3`, required: false): Select the participant who is participating in the event. The options are:
	+ John Doe
	+ Jane Doe
	+ Bob Smith
* **Contact Number** (`Page 4`, required: false): Enter the contact number for the participant (this field is optional).
* **Email** (`Page 5`, required: false): Enter the participant's email address (this field is optional).
* **Prize** (`Page 6`, required: false): Enter a brief description of the prize associated with the event.
* **Start Date** (`Page 7`, required: false): Select the start date of the event.
* **End Date** (`Page 8`, required: false): Select the end date of the event.
* **Start Time** (`Page 9`, required: false): Select the start time of the event.
* **End Time** (`Page 10`, required: false): Select the end time of the event.
* **Description** (`Page 11`, required: false): Enter a detailed description of the event.
* **Participants** (`Page 12`, required: false): Select the participants who are participating in the event. The options are:
	+ John Doe
	+ Jane Doe
	+ Bob Smith
* **Total Participants** (`Page 13`, required: false): Enter the total number of participants.

## Tips
* Make sure to fill out all the required fields if applicable.
* If a field is optional, you can skip it or leave it blank.
* Double-check your input for accuracy before submitting the form.
* If you are unsure about any field, refer back to the form sections and their explanations.
