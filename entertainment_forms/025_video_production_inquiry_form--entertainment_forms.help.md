# video_production_inquiry_form - Help Guide
## Purpose
This form is used to gather information for video production projects.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the project title and description.
2. Enter the URL of the project (if applicable).
3. Enter the name of the contact person.
4. Enter the contact email.
5. Enter the contact phone number.
6. Select the production type (e.g., 2D, 3D, 360).
7. Select the video format (e.g., 2D, 3D, 360).
8. Enter the budget for the project.
9. Enter the expected delivery date for the project.
10. Enter the current project status (if applicable).

## Field-by-Field Explanation
- **Project Title** (`project_title`, text, required): Enter the title of the project.
- **Project Description** (`project_description`, text, required): Enter a brief description of the project.
- **Project URL** (`project_url`, text, optional): Enter the URL of the project (if applicable).
- **Client Name** (`contact_name`, text, optional): Enter the name of the client.
- **Contact Email** (`contact_email`, email, optional): Enter the email address of the contact person.
- **Contact Phone** (`contact_phone`, text, optional): Enter the phone number of the contact person.
- **Production Type** (`production_type`, text, required): Select the type of production (e.g., 2D, 3D, 360).
- **Video Format** (`video_format`, select_multiple, required): Select the video format (e.g., 2D, 3D, 360).
- **Budget** (`budget`, text, optional): Enter the budget for the project.
- **Delivery Date** (`delivery_date`, date, required): Enter the expected delivery date for the project.
- **Project Status** (`project_status`, text, optional): Enter the current status of the project (if applicable).

## Tips
- Make sure to fill in all required fields.
- Double-check your information before submitting the form.
- If you're unsure about any field, contact the project manager for clarification.
