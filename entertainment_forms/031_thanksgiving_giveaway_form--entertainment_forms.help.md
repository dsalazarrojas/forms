# Thanksgiving Giveaway Form - Help Guide
## Purpose
This form is for gathering information from users about their Thanksgiving preferences and giveaway interests.

## How To Complete This Form
1. **Basic Info**: Provide your basic contact information (optional).
2. **What Are You Thankful For**: In the text area provided, share what you are thankful for during the upcoming Thanksgiving holiday.
3. **How Did You Hear About Us**: Select how you found out about this giveaway (e.g. Social Media, Online Ad, Referral, or Other).
4. **What Would You Like to Win**: Select one or more prize options you would like to receive in the giveaway (A, B, C, or D).
5. **Rules and Agreement**: Read and agree to the rules and terms of the giveaway (text area).

## Field-by-Field Explanation
* **Basic Info** (text): Your name and contact information.
* **What Are You Thankful For** (text): Share something you are thankful for during the upcoming Thanksgiving holiday.
* **How Did You Hear About Us** (select_one):
	+ **Social Media**: If you found out about this giveaway through social media.
	+ **Online Ad**: If you saw the ad online.
	+ **Referral**: If someone referred you to this giveaway.
	+ **Other**: If you found out about this giveaway through another means.
* **What Would You Like to Win** (select_multiple):
	+ **A**: Select this option if you want to win option A.
	+ **B**: Select this option if you want to win option B.
	+ **C**: Select this option if you want to win option C.
	+ **D**: Select this option if you want to win option D.
* **Rules and Agreement** (text): Read and agree to the rules and terms of the giveaway.

## Tips
* Make sure to fill out all required fields (How Did You Hear About Us and What Would You Like to Win).
* Be creative and sincere when sharing what you are thankful for.
* Select all applicable options for What Would You Like to Win.
* Review the rules carefully before agreeing.
