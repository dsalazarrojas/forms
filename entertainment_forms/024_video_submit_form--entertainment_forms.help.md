# video_submit_form - Help Guide
## Purpose
This form collects metadata about videos, including title, description, categories, tags, video URL, and thumbnail URL, for our platform.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the title of the video.
2. Provide a brief description of the video.
3. Select one or more categories for the video from the list of options (Action, Comedy, Drama).
4. Add any relevant tags for the video (funny, interesting, cool).
5. Enter the URL of the video.
6. (Optional) Enter the URL of the thumbnail image.

## Field-by-Field Explanation
### <label> Video Title (video_title) (Text, required: false)
The video title is a brief text that describes the video.

### <label> Video Description (description) (Text, required: false)
Enter a short description of the video.

### <label> Categories (category) (Select, required: false)
Select one or more categories that best fit the video (Action, Comedy, Drama).

### <label> Tags (tags) (Select, required: false)
Add any relevant tags for the video (funny, interesting, cool).

### <label> Video URL (video_url) (Text, required: false)
Enter the URL of the video.

### <label> Thumbnail URL (thumbnail_url) (Text, required: false)
( Optional) Enter the URL of the thumbnail image for the video.

## Tips
* Ensure the video title and description are concise and accurate.
* Choose categories and tags that best represent the video content.
* Enter the correct video and thumbnail URLs.
* If you have any issues or need further clarification, contact form@gic.mx.
