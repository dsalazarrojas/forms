# Corrective Training Acknowledgment Form - Help Guide

## Purpose

This form is used to document the completion of corrective training for employees. It is a critical process to ensure that employees who have received corrective actions or disciplinary actions have completed any required training or counseling sessions. This form is used to track the progress and completion of the training, as well as any follow-up reports or actions.

## How To Complete This Form

1. Start by filling in the Form Title and Employee Name fields, which are required fields.
2. Enter the Training Date, which is also a required field. This date should be the date the training or counseling session was completed.
3. Select the type of training that was completed using the dropdown menu.
4. If applicable, select the status of the training using the dropdown menu.
5. Enter any follow-up report date and status using the date picker and dropdown menu, if applicable.
6. Enter any follow-up report notes, if applicable.
7. Enter any manager notes, if applicable.
8. Sign and date the form with both your signature and the manager's signature.
9. Enter the date the form was completed.
10. Select any follow-up frequencies and last follow-up dates and times, if applicable.
11. Enter any follow-up notes, if applicable.
12. Finally, review and submit the form for completion.

## Field-by-Field Explanation

* **Form Title** (form_title, text, required): Enter a brief title to identify the purpose of the training or counseling session.
* **Employee Name** (employee_name, text, required): Enter the name of the employee who received the corrective action or disciplinary action.
* **Training Date** (training_date, date, required): Enter the date the training or counseling session was completed.
* **Training Type** (training_type, select_one, required): Select the type of training or counseling session completed.
* **Training Status** (training_status, select_multiple, optional): If applicable, select the status of the training using the dropdown menu.
* **Follow-up Report Date** (follow_report_date, date, required): If applicable, enter the date of the follow-up report.
* **Follow-up Report Status** (follow_report_status, select_multiple, optional): If applicable, select the status of the follow-up report using the dropdown menu.
* **Follow-up Report Notes** (followup_report_notes, note, optional): Enter any additional notes for the follow-up report, if applicable.
* **Manager Notes** (manager_notes, note, optional): Enter any notes from the manager, if applicable.
* **Employee Signature** (employee_signature, text, required): Sign and date the form with the employee's signature.
* **Manager Signature** (manager_signature, text, required): Sign and date the form with the manager's signature.
* **Form Complete Date** (form_complete_date, date, required): Enter the date the form was completed.
* **Follow-ups** (followups, select_multiple, optional): If applicable, select the follow-up frequencies using the dropdown menu.
* **Follow-up Notes** (followup_notes, note, optional): Enter any follow-up notes, if applicable.
* **Training Completed Date** (training_completed, date, required): Enter the date the training was completed.
* **Training Status Update** (training_status_update, select_multiple, optional): If applicable, select the status of the training using the dropdown menu.
* **Follow-up Report Frequency** (follow_report_frequency, number, optional): If applicable, enter the follow-up report frequency.
* **Last Follow-up** (follow_report_last_followup, time, optional): If applicable, enter the last follow-up date and time.
* **Last Follow-up Time** (follow_report_last_followup_time, time, optional): If applicable, enter the last follow-up date and time.
* **Follow Report** (follow_report, date, required): Enter the date of the follow-up report.
* **Training Date** (training_date, date, optional): If applicable, enter the date of the training.
* **Training Hours** (training_hours, number, optional): If applicable, enter the training hours.
* **Training Status** (training_status, select_one, optional): If applicable, select the status of the training using the dropdown menu.
* **Follow-up Status** (followup_status, select_multiple, optional): If applicable, select the status of the follow-up report using the dropdown menu.
* **Follow-up Notes** (followup_notes, note, optional): Enter any follow-up notes, if applicable.
