# Notice Of Disciplinary Action Form - Help Guide

## Purpose
This form is used to document and report incidents of disciplinary action taken by an organization towards an employee.

## How To Complete This Form
1. Select "Disciplinary Action" as the type of action taken.
2. Fill in the employee's name as recorded in the company's records.
3. Enter the reason for the disciplinary action.
4. Select the disciplinary action taken (e.g., Verbal Warning, Written Warning, Termination).
5. Describe any next steps or actions that will be taken following the disciplinary action.
6. Identify the manager and supervisor involved in the process.
7. If the disciplinary status is set to "Suspended", provide a reason and date for suspension.
8. If the disciplinary status is set to "Closed", provide a reason and date for closure.
9. Fill in any additional notes or comments about the disciplinary action.
10. Review and submit the form for approval.

## Field-by-Field Explanation

* **Employee Name**: Enter the full name of the employee involved in the disciplinary action.
* **Reason For Action**: Describe the reason for the disciplinary action taken.
* **Date of Action**: Enter the date on which the disciplinary action was taken.
* **Disciplinary Action Description**: Provide a detailed description of the disciplinary action.
* **Action Taken**: Select the type of disciplinary action taken (e.g., Verbal Warning, Written Warning, Termination).
* **Next Steps**: Describe any next steps or actions that will be taken following the disciplinary action.
* **Manager**: Identify the manager involved in the process.
* **Supervisor**: Identify the supervisor involved in the process.
* **Employee Date of Birth**: Enter the employee's date of birth (if applicable).
* **Date of Disciplinary Action**: Enter the date on which the disciplinary action was taken.
* **Date of Next Steps**: Enter the date on which the next steps will be taken (if applicable).
* **Taken By**: Identify the person who took the disciplinary action.
* **Employee ID**: Enter the employee's ID number.
* **Disciplinary Status**: Select the current status of the disciplinary action (e.g., Open, Suspended, Closed, Archived).
* **Reason for Suspension**: If the disciplinary status is set to "Suspended", provide a reason for the suspension.
* **Date of Suspension**: If the disciplinary status is set to "Suspended", enter the date on which the suspension was implemented.
* **Disciplinary Status Suspended By**: If the disciplinary status is suspended, indicate the person who suspended the status.
* **Reason for Closure**: If the disciplinary status is set to "Closed", provide a reason for the closure.
* **Date of Closure**: If the disciplinary status is set to "Closed", enter the date on which the closure was implemented.
* **Disciplinary Status Archived By**: If the disciplinary status is set to "Archived", indicate the person who archived the status.
* **Notes**: Enter any additional notes or comments about the disciplinary action.
