# Disciplinary Action Amendment Form - Help Guide
## Purpose
This form allows users to update or amend a previously issued disciplinary action. It is used to provide more information or clarification on the action taken against an employee.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the "amended-disciplinary-action-id" field to choose the original disciplinary action that needs to be amended.
2. Provide the reason for the amendment in the "reason-for-amendment" field.
3. Enter the date and time of the amended disciplinary action in the "amended-disciplinary-action-date" and "amended-disciplinary-action-time" fields, respectively.
4. Select the appropriate options for the "user-id", "user-name", "user-title", "manager-id", "manager-title", "employee-id", and "amended-disciplinary-action-details" fields as required.
5. Enter any additional notes or comments in the "notes" field.

## Field-by-Field Explanation
- **Amended Disciplinary Action ID** (`amended-disciplinary-action-id`, number): Select the original disciplinary action ID that needs to be amended.
- **Reason for Amendment** (`reason-for-amendment`, text): Enter the reason for the amendment, including any relevant details or explanations.
- **Amended Disciplinary Action Date** (`amended-disciplinary-action-date`, date): Enter the date of the amended disciplinary action.
- **Amended Disciplinary Action Time** (`amended-disciplinary-action-time`, time): Enter the time of the amended disciplinary action.
- **User ID** (`user-id`, select one): Select "Yes" if the user is the subject of the disciplinary action, "No" otherwise.
- **User Name** (`user-name`, select multiple): Select "Yes" if the user is the subject of the disciplinary action, "No" otherwise.
- **User Title** (`user-title`, select multiple): Select "Yes" if the user's title is affected by the disciplinary action, "No" otherwise.
- **Manager ID** (`manager-id`, select multiple): Select "Yes" if the manager is involved in the disciplinary action, "No" otherwise.
- **Manager Title** (`manager-title`, select multiple): Select "Yes" if the manager's title is affected by the disciplinary action, "No" otherwise.
- **Employee ID** (`employee-id`, select multiple): Select "Yes" if the employee is affected by the disciplinary action, "No" otherwise.
- **Amended Disciplinary Action Details** (`amended-disciplinary-action-details`, select multiple): Select "Yes" if the disciplinary action details need to be updated, "No" otherwise.
- **Notes** (`notes`, text): Enter any additional notes or comments on the amended disciplinary action.
