# Employee Disciplinary Action Follow Up Form - Help Guide
## Purpose
The Employee Disciplinary Action Follow Up Form is used to track and document the progress of disciplinary actions taken against employees. It helps HR and management teams to follow up on the effectiveness of the disciplinary actions and ensure that they are being implemented as planned.

## How To Complete This Form
To complete this form, follow these steps:

1. Ensure that you have the necessary information and approval to access the employee's disciplinary action history.
2. Complete the Form Follow Up Date field with the date that you are following up on the disciplinary action.
3. Provide an update on the progress of the disciplinary action in the Follow Up Comments field.
4. If applicable, select the Action Efficacy Date field to record the date when the disciplinary action was deemed effective.
5. Choose the Follow Up Frequency field to indicate how often you will be following up on the disciplinary action (e.g., Daily, Weekly, Monthly, etc.).
6. Select the Follow Up Method field to indicate the method of follow-up (e.g., Phone, Email, In Person, etc.).
7. Select the Follow Up By field to indicate who will be following up on the disciplinary action (e.g., HR, Manager, Employee, etc.).
8. Choose the Follow Up To field to indicate to whom the follow-up will be directed (e.g., HR, Manager, Other, etc.).
9. Enter any additional comments or notes about the follow-up in the Follow Up Comments field.
10. Finally, select the Follow Up Status field to indicate the current status of the follow-up (e.g., Not Started, In Progress, Completed, On Hold, etc.).

## Field-by-Field Explanation
* **Form Follow Up Date**: This field is used to record the date when you are following up on the disciplinary action.
	+ Type: Date
	+ Required: No
* **Follow Up Comments**: This field is used to provide an update on the progress of the disciplinary action.
	+ Type: Text
	+ Required: No
* **Action Efficacy Date**: This field is used to record the date when the disciplinary action was deemed effective.
	+ Type: Date
	+ Required: No
* **Follow Up Frequency**: This field is used to indicate how often you will be following up on the disciplinary action.
	+ Type: Select One
	+ Options: Daily, Weekly, Bi-Weekly, Monthly, Quarterly, Semi-Annually, Annually
	+ Required: No
* **Follow Up Method**: This field is used to indicate the method of follow-up (e.g., Phone, Email, In Person, etc.).
	+ Type: Select One
	+ Options: Phone, Email, In Person, Video Conference, Video Call
	+ Required: No
* **Follow Up By**: This field is used to indicate who will be following up on the disciplinary action.
	+ Type: Select One
	+ Options: HR, Manager, Employee, Other
	+ Required: No
* **Follow Up To**: This field is used to indicate to whom the follow-up will be directed.
	+ Type: Select One
	+ Options: HR, Manager, Other
	+ Required: No
* **Follow Up Comments**: This field is used to record any additional comments or notes about the follow-up.
	+ Type: Text
	+ Required: No
* **Follow Up Status**: This field is used to indicate the current status of the follow-up.
	+ Type: Select One
	+ Options: Not Started, In Progress, Completed, On Hold
	+ Required: No

## Tips
* Be sure to keep the follow-up comments concise and focused on the progress of the disciplinary action.
* Use the follow-up frequency and method fields to ensure that the follow-up is done consistently and effectively.
* Select the follow-up status field accurately to reflect the current status of the follow-up.
* If applicable, use the action efficacy date field to record when the disciplinary action was deemed effective.
