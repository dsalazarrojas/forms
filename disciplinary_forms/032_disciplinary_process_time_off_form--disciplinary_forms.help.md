# Disciplinary Process Time Off Form - Help Guide
## Purpose
The Disciplinary Process Time Off Form is used to manage employee time off and leave requests, tracking absences, and approval status.

## How To Complete This Form
1. Select "I am an employee" or "I am a manager/supervisor" to indicate your role.
2. Fill out the form accordingly, providing the requested information.
3. Review and submit the form.

## Field-by-Field Explanation

* **Employee ID (1)**: A unique identifier for the employee.
	+ This field is required for internal tracking and identification purposes.
* **Time Off Start Date (2)**: The date the employee is expected to begin their time off.
	+ This field is optional, but helps in scheduling and tracking absences.
* **Time Off End Date (3)**: The date the employee is expected to end their time off.
	+ This field is optional, but helps in scheduling and tracking absences.
* **Reason For Absence (4)**: A brief explanation of the reason for the employee's absence.
	+ This field helps managers/supervisors understand the nature of the absence.
* **Supervisor Approvals (5)**: Select the supervisor(s) who need to approve the time off request.
	+ This field is optional, but helps in assigning approvals to relevant personnel.
* **Approval Status (6)**: The current status of the approval process.
	+ This field is optional, but helps in tracking the progress of the approval process.
* **Comments (7)**: Additional comments or notes from the manager/supervisor.
	+ This field is optional, but can be used for further clarification or communication.
* **Employee Name (8)**: The name of the employee requesting time off.
	+ This field is optional, but helps in identifying the employee.
* **Employee Title (9)**: The title of the employee requesting time off.
	+ This field is optional, but helps in understanding the employee's role and position.
* **Reason For Leaving (10)**: A brief explanation of the reason for the employee's absence.
	+ This field is optional, but helps managers/supervisors understand the situation.
* **Disciplinary Action (11)**: Select the disciplinary action taken or planned to be taken during the absence.
	+ This field is optional, but helps in recording and tracking disciplinary actions.
* **Time Off Start Time (12)**: The time the employee is expected to start their time off.
	+ This field is optional, but helps in scheduling and tracking start times.
* **Time Off End Time (13)**: The time the employee is expected to end their time off.
	+ This field is optional, but helps in scheduling and tracking end times.
* **Time Off Hours (14)**: A note on the time off hours.
	+ This field is optional, but can be used for further explanation or clarification.
* **Time Off Date (15)**: A note on the time off date.
	+ This field is optional, but can be used for further explanation or clarification.
* **Time Off Duration (16)**: A note on the duration of the time off.
	+ This field is optional, but can be used for further explanation or clarification.
* **Time Off Hours End (17)**: A note on the time off hours end.
	+ This field is optional, but can be used for further explanation or clarification.
* **Supervisor Name (18)**: The name of the supervisor who approved or rejected the time off request.
	+ This field is optional, but helps in tracking approvals and decisions.
* **Time Off Start Time Off Day (19)**: A note on the start time of the time off day.
	+ This field is optional, but can be used for further explanation or clarification.
* **Time Off End Time Off Day (20)**: A note on the end time of the time off day.
	+ This field is optional, but can be used for further explanation or clarification.
* **Time Off Hours Off Day (21)**: A note on the hours off on the time off day.
	+ This field is optional, but can be used for further explanation or clarification.
* **Time Off Start Date Off (22)**: A note on the start date of the time off.
	+ This field is optional, but can be used for further explanation or clarification.
* **Time Off End Date Off (23)**: A note on the end date of the time off.
	+ This field is optional, but can be used for further explanation or clarification.
* **Manager Name (24)**: The name of the manager who reviewed or approved the time off request.
	+ This field is optional, but helps in tracking and documenting the approval process.
* **Time Off Start Time Off (25)**: A note on the start time of the time off.
	+ This field is optional, but can be used for further explanation or clarification.
