# learner_suspension_notification - Help Guide
## Purpose
The learner_suspension_notification form is a template for documenting learner suspension cases. It collects relevant information and follow-up details to ensure that all necessary data is gathered and stored for future reference and decision-making.

## How To Complete This Form
To complete this form, follow these steps:

1. **School Information (school_info)**:
	* This field is used to collect information about the school related to the learner suspension case.
	* Please enter the name of the school.
	* (Optional)
2. **Suspension Information (suspension_info)**:
	* This field is used to collect details about the suspension itself.
	* Please provide a brief description of the suspension.
	* (Optional)
3. **Parent Information (parent_info)**:
	* This field is used to collect contact information about the learner's parent or guardian.
	* Please enter the parent's name, email, and phone number.
	* (Optional)
4. **Follow-up Steps (follow_up_steps)**:
	* This field is used to record any follow-up actions or next steps taken regarding the learner suspension case.
	* Please describe any additional actions or meetings scheduled.
	* (Optional)
5. **Submission Date (submission_date)**:
	* This field is used to record the date the form was submitted.
	* Please select a date from the calendar.
	* (Required)
6. **Notes (notes)**:
	* This field is used to record any additional comments or notes related to the learner suspension case.
	* Please provide any relevant details or observations.
	* (Optional)
7. **Follow-up Details (follow_up_details)**:
	* This field is used to collect any additional details about the follow-up process.
	* Please describe any further actions or meetings scheduled.
	* (Optional)
8. **Additional Comments (additional_comments)**:
	* This field is used to record any other comments or remarks about the learner suspension case.
	* Please provide any additional context or information.
	* (Optional)

## Tips

* Please fill out all required fields accurately and completely.
* Ensure that all optional fields are completed if relevant and helpful to the case.
* Review and submit the form only once per learner suspension case.
* If you are unsure about any field, please reach out to the designated authority for guidance.
* This form is for informational purposes only and should not be used to collect sensitive or confidential data.
