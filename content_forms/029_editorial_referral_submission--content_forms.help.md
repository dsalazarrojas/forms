# Editorial Referral Submission - Help Guide
## Purpose
This form is for submitting editorial referrals to the editorial team for review and consideration. It captures essential information about the referral, including the contributor's details, submission date, and content.

## How To Complete This Form
To complete this form, follow these steps:

1.  Enter your **Contributor Name** in the field provided. This is the name of the person submitting the referral.
2.  Select the **Submission Date** in the calendar picker. This is the date when you are submitting the referral.
3.  Upload a file with the name and contact information of the **Contributor** if required.
4.  If necessary, upload a file with the pitch for the referral.
5.  Upload a file with the content for the referral.
6.  Choose the **Submission Type** from the options provided. This helps the editorial team understand the nature of the referral.
7.  Select the **Content Type** from the options provided. This helps the editorial team understand the type of content the referral is for.
8.  Enter the name of the **Assigned Editor** who will handle the referral. This can be left blank if not applicable.
9.  Fill in the **Submission Status** field with a brief description of the referral's status. This can be left blank if not applicable.

## Field-by-Field Explanation
*   **Contributor Name** (text, required): Enter the name of the person submitting this referral.
*   **Submission Date** (date, required): Select the date when you are submitting this referral.
*   **Contributor File** (text, optional): Upload a file with the name and contact information of the **Contributor** if required.
*   **Pitch File** (text, optional): If necessary, upload a file with the pitch for the referral.
*   **Content File** (text, optional): Upload a file with the content for the referral.
*   **Submission Type** (select_one, optional): Choose the submission type from the options provided.
*   **Content Type** (select_multiple, optional): Select the content type from the options provided.
*   **Assigned Editor** (text, optional): Enter the name of the **Assigned Editor** who will handle this referral.
*   **Submission Status** (text, optional): Fill in the **Submission Status** field with a brief description of the referral's status.
