# Documentary Footage License Request Form - Help Guide
## Purpose
This form is used to request a license for documentary footage from [Your Company/Institution]. The form gathers essential information about the intended use of the footage, including usage purpose, distribution channel, license duration, and other technical details. This form must be filled out completely and accurately to ensure that we can efficiently process your request and provide the required licenses.

## How To Complete This Form
Before filling out this form, please make sure you are an authorized representative of your company or institution. The form has several sections with different fields that need to be filled out. Please read each section carefully and fill out the information as instructed.

## Field-by-Field Explanation
### Usage Purpose
* **Usage Purpose** (`select_multiple`, required): Select the purpose of your intended use of the footage. This can be one or more of the following options:
  * Film
  * TV
  * Digital
  * Theatrical
  * Other

### Distribution Channel
* **Distribution Channel** (`select_one`, optional): Select the channel through which you plan to distribute the footage. This can be one of the following options:
  * Online
  * Theatrical
  * DVD/BluRay
  * Other

### License Duration
* **License Duration** (`select_one`, required): Select the duration of the license you are requesting. This can be one of the following options:
  * Day
  * Week
  * Month
  * Year
  * Indefinite

### Usage Location
* **Usage Location** (`text`, required): Please enter the location where the footage will be used.

### Intended Audience
* **Intended Audience** (`select_multiple`, optional): Select the audience you plan to use the footage for. This can be one or more of the following options:
  * General Public
  * Educational
  * Commercial

### Media Type
* **Media Type** (`select_one`, required): Select the type of media you plan to use the footage for. This can be one of the following options:
  * Film
  * TV
  * Documentary
  * Short

### Footage Format
* **Footage Format** (`select_multiple`, optional): Select the format of the footage you plan to use. This can be one or more of the following options:
  * SD
  * HD
  * 4K
  * 3D

### Resolution
* **Resolution** (`number`, optional): Please enter the resolution of the footage you plan to use.

### Aspect Ratio
* **Aspect Ratio** (`text`, optional): Please enter the aspect ratio of the footage you plan to use. (e.g. 4:3, 16:9, etc.)

### Frame Rate
* **Frame Rate** (`number`, optional): Please enter the frame rate of the footage you plan to use.

### Audio Codec
* **Audio Codec** (`select_multiple`, optional): Select the audio codec you plan to use. This can be one or more of the following options:
  * PCM
  * WAV
  * MP3
  * AAC

### Video Codec
* **Video Codec** (`select_multiple`, optional): Select the video codec you plan to use. This can be one or more of the following options:
  * H.264
  * H.265
  * VP9

### Color Mode
* **Color Mode** (`select_multiple`, optional): Select the color mode you plan to use. This can be one or more of the following options:
  * Monochrome
  * RGB
  * YUV

### File Format
* **File Format** (`select_multiple`, optional): Select the file format you plan to use. This can be one or more of the following options:
  * MP4
  * MOV
  * AVI
  * MKV

### Filename
* **Filename** (`text`, required): Please enter a unique and descriptive filename for the footage.

### Email
* **Email** (`email`, required): Please enter a valid email address for contact purposes.

### Phone
* **Phone** (`text`, optional): Please enter your phone number for contact purposes.

### Contact Name
* **Contact Name** (`text`, required): Please enter the name of the contact person.

### Production Company
* **Production Company** (`text`, optional): Please enter the name of the production company.

### Project Name
* **Project Name** (`text`, optional): Please enter the name of the project.

### Delivery Date
* **Delivery Date** (`date`, optional): Please enter the expected delivery date of the footage.

### Delivery Time
* **Delivery Time** (`time`, optional): Please enter the expected delivery time of the footage.

### Notes
* **Notes** (`note`, optional): Please enter any additional notes or comments about the request.

### License Terms
* **License Terms** (`text`, optional): Please enter any additional license terms or conditions.

### Submission Agreement
* **Submission Agreement** (`text`, required): Please read and agree to the submission agreement.

Please note that some fields are optional and can be left blank if not applicable. Make sure to fill out the form completely and accurately to ensure that we can process your request efficiently.
