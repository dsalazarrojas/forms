# remote_writers_hub_booking_form - Help Guide
## Purpose
The remote writers hub booking form is used to collect information about a project and a remote writer's requirements for that project. It is designed to be completed by the project lead or person booking the remote writer.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the project title in the "Project Title" field. This should be a unique title that is not duplicated.
2. In the "Project Description" field, enter a brief description of the project.
3. Select the deadline date for the project in the "Deadline" field.
4. In the "Remote Writer Details" field, enter the remote writer's details, such as their name and contact information.
5. Enter the remote writer's rate for the project in the "Remote Writer Rate" field.
6. If necessary, enter any additional notes in the "Notes" field.
7. Select the remote writer's availability for the project in the "Availability" field.
8. Enter a brief summary of the project in the "Project Brief" field.

## Field-by-Field Explanation
* **Project Title**: Enter the unique title of the project (required)
* **Project Description**: Enter a brief description of the project (required)
* **Deadline**: Select the deadline date for the project (required)
* **Remote Writer Details**: Enter the remote writer's details, such as their name and contact information (required)
* **Remote Writer Rate**: Enter the remote writer's rate for the project (required)
* **Notes**: Enter any additional notes for the project (optional)
* **Availability**: Select the remote writer's availability for the project (required)
* **Project Brief**: Enter a brief summary of the project (required)

## Tips
* Make sure to use a unique project title to avoid duplication.
* Enter accurate and clear information to ensure the remote writer can complete the project successfully.
* If you are unsure about any field, please contact the project lead or project management team for clarification.
