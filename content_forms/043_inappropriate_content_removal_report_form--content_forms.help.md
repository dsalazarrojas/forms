# Inappropriate Content Removal Report Form - Help Guide
## Purpose
The Inappropriate Content Removal Report Form is used to report inappopriate content on a platform, allowing moderators, administrators, and reviewers to identify and address such content.

## How To Complete This Form
1. Fill out the form with accurate and detailed information about the reported content.
2. Select the correct options for the reported content type and reason for reporting.
3. Provide additional comments if necessary.
4. Specify the action taken on the reported content.

## Field-by-Field Explanation
* **Report Form** (text, required): This field is used to provide a detailed description of the reported content.
* **Item Id** (number, optional): This field is used to enter the ID of the reported item.
* **Reported User Id** (number, optional): This field is used to enter the ID of the user who reported the content.
* **Reason** (text, optional): This field is used to provide a brief explanation for the reason of the report.
* **Reported Item Type** (text, optional): This field is used to select the type of reported item (e.g., image, video, etc.).
* **Reported Item Title** (text, optional): This field is used to enter the title of the reported item.
* **Content** (text, optional): This field is used to provide a description of the reported content.
* **Additional Comments** (text, optional): This field is used to provide additional comments or information about the report.
* **Remove Item** (select_one, optional): This field is used to select the action to be taken on the reported content (e.g., Remove Item, Resolve Item, etc.).
* **Reported Content** (select_multiple, required): This field is used to select the type of reported content (e.g., Image, Video, Audio, etc.).
* **Reported Content Type** (select_one, required): This field is used to select the type of reported content (e.g., Image, Video, Audio, etc.).
* **Action Taken** (select_one, required): This field is used to select the action taken on the reported content (e.g., Remove Item, Resolve Item, etc.).
* **Date Submitted** (date, optional): This field is used to enter the date the report was submitted.
* **Time Submitted** (time, optional): This field is used to enter the time the report was submitted.
* **Reviewer Id** (number, optional): This field is used to enter the ID of the reviewer who reviewed the report.
* **Reviewer Name** (text, optional): This field is used to enter the name of the reviewer who reviewed the report.
* **Reviewer Role** (text, optional): This field is used to enter the role of the reviewer who reviewed the report.
* **Reviewer Comment** (text, optional): This field is used to enter comments from the reviewer.
* **Moderator Id** (number, optional): This field is used to enter the ID of the moderator who reviewed the report.
* **Moderator Name** (text, optional): This field is used to enter the name of the moderator who reviewed the report.
* **Moderator Comment** (text, optional): This field is used to enter comments from the moderator.
* **Admin Id** (number, optional): This field is used to enter the ID of the administrator who reviewed the report.
* **Admin Name** (text, optional): This field is used to enter the name of the administrator who reviewed the report.
* **Admin Comment** (text, optional): This field is used to enter comments from the administrator.
* **Form Completed** (select_one, optional): This field is used to indicate whether the form was completed.

Note: The fields marked as "required" are necessary to fill out for the report to be considered complete and valid.
