# HTML Code Submission Form - Help Guide
## Purpose

The HTML Code Submission Form is designed to collect and review HTML code submissions from users. It serves as a platform for developers, testers, or content creators to share their code for feedback, improvement, or review purposes.

## How To Complete This Form

1. **Provide your User Name**: Enter your name to associate it with your submission and enable us to contact you for review or further feedback.
2. **Enter your Email**: Please provide a valid email address to allow us to contact you regarding your submission.
3. **Enter your Code**: Share your HTML code in the designated area. This is the code you want to be reviewed or used for feedback.
4. **Choose your Language**: Select the programming language used for the code you've submitted (e.g., HTML, CSS, JavaScript).
5. **Submission Details**: Provide the date and time you submitted the code.
6. **Review Details**: If the submission has been reviewed, provide the date and status of the review.
7. **Submission Status**: Select the status of your submission, from "New" to "Approved" or "Rejected".
8. **Specify your Reviewer**: Identify the person reviewing your code (if applicable).
9. **Provide Feedback**: If feedback is available, enter a detailed description of the changes or improvements.

## Field-by-Field Explanation

* **User Name** (`user_name`, text, **required**): Enter your name as you want to be associated with your submission.
* **Email** (`email`, email, **optional**): A valid email address to contact you regarding your submission.
* **Code** (`code`, note, **optional**): Share your HTML code in this text area.
* **Language** (`code_language`, select_one, **optional**): Select the programming language used for the code submission.
* **Submission Date** (`submit_date`, date, **optional**): The date you submitted the code.
* **Submission Time** (`submit_time`, time, **optional**): The time you submitted the code.
* **Review Date** (`review_date`, date, **optional**): If the submission has been reviewed, enter the review date.
* **Submission Status** (`submission_status`, select_one, **optional**): Select the current status of your submission (e.g., New, Pending, Approved, Rejected).
* **Reviewer** (`reviewer`, text, **optional**): If available, provide the name of the person reviewing your code.
* **Feedback** (`feedback`, note, **optional**): If feedback is available, enter a description of the changes or improvements suggested.
