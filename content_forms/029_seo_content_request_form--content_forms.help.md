# seo_content_request_form - Help Guide
## Purpose
The seo_content_request_form is used to request content from the content team for various purposes such as blog posts, articles, videos, and more.

## How To Complete This Form
1. Fill in the required fields marked as "required" in the form.
2. Make sure to select the correct "Form Type" and "Content Request Type" from the dropdown menus.
3. Provide a brief description of the content you are requesting.
4. If applicable, attach relevant files to support your request.

## Field-by-Field Explanation
* **Form ID** (`form_id`, number, optional): Enter a unique ID for your form, if desired.
* **Form Type** (`form_type`, select_one, required): Select the type of content you are requesting (e.g. Article, Blog, Video, etc.).
* **Target Audience** (`target_audience`, select_multiple, required): Select the target audience for your content request (e.g. B2B, B2C, C2C, etc.).
* **Keywords** (`keywords`, text, optional): Enter relevant keywords related to your content request.
* **Description** (`description`, text, optional): Briefly describe the content you are requesting.
* **Due Date** (`due_date`, date, optional): Enter the date by which you would like the content to be completed.
* **Content Length** (`content_length`, number, optional): Enter the length of the content you are requesting.
* **Word Count** (`word_count`, number, optional): Enter the word count for the content you are requesting.
* **Format** (`format`, select_one, required): Select the format of the content you are requesting (e.g. Article, Blog, Social Media Post, etc.).
* **Content Request Type** (`content_request_type`, select_one, required): Select the type of content request (e.g. Article, Blog, Social Media Post, etc.).
* **Content Request** (`content_request`, text, optional): Enter a brief description of the content request.
* **Contact** (`contact`, text, optional): Enter your contact information.
* **Email** (`email`, email, optional): Enter your email address.
* **Phone** (`phone`, text, optional): Enter your phone number.
* **File Attachment** (`file_attachment`, text, optional): Attach relevant files to support your request.
* **File Attachment Type** (`file_attachment_type`, select_one, optional): Select the type of file attachment (e.g. Image, Video, Document, etc.).
* **File URL** (`file_url`, text, optional): Enter the URL of the file attachment.
