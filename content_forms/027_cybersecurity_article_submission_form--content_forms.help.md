# Manuscript Form - Help Guide
## Purpose
The Manuscript Form is designed for submitting and managing manuscripts or articles in a publication or academic context. This form helps gather information about the manuscript, its status, and its submission process. Before completing this form, make sure to review the relevant instructions and guidelines for the submission process.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the required fields marked as "required" and ensure they are correctly formatted (e.g., date fields must be dates, email fields must be valid email addresses).
2. Select the correct options for fields marked as "select_one" or "select_multiple".
3. Upload any required file attachments.
4. Ensure all fields are accurately and completely filled out before submission.

## Field-by-Field Explanation

* **Manuscript** (`id: 1`, text, required): Enter the title of the manuscript.
* **Author Name** (`id: 2`, text, required): Enter the author's name as it appears on their manuscript.
* **Title** (`id: 3`, text, required): Enter the title of the manuscript.
* **Abstract** (`id: 4`, text, required): Enter a brief summary of the manuscript.
* **File Attachment** (`id: 5`, text, optional): Attach a file related to the manuscript, if applicable.
* **Keywords** (`id: 6`, select_one, optional): Select relevant keywords for the manuscript.
* **Submitter** (`id: 7`, text, required): Enter the name of the person submitting the manuscript.
* **Contact Email** (`id: 8`, email, optional): Enter the submitter's email address, if available.
* **Phone Number** (`id: 9`, text, optional): Enter the submitter's phone number, if available.
* **Manuscript Type** (`id: 10`, select_one, optional): Select the type of manuscript being submitted.
* **Submission Date** (`id: 11`, date, required): Enter the date of submission.
* **Publication Date** (`id: 12`, date, optional): Enter the expected publication date, if known.
* **Review Date** (`id: 13`, date, optional): Enter the expected review date, if known.
* **Manuscript Status** (`id: 14`, select_multiple, optional): Select the current status of the manuscript.
* **Submission Status** (`id: 15`, select_multiple, optional): Select the current submission status of the manuscript.
* **Submitter Organization** (`id: 16`, text, optional): Enter the submitter's organization, if applicable.
* **Submission Comments** (`id: 17`, text, optional): Enter any comments related to the submission.
* **Article Type** (`id: 18`, select_one, optional): Select the type of article, if applicable.
* **Manuscript ID** (`id: 19`, text, optional): Enter the manuscript ID, if available.
* **Article ID** (`id: 20`, text, optional): Enter the article ID, if available.
* **Submission ID** (`id: 21`, text, optional): Enter the submission ID, if available.
* **Reviewer Comments** (`id: 22`, text, optional): Enter any comments from the reviewer.
* **Reviewer Name** (`id: 23`, text, optional): Enter the reviewer's name, if available.
* **Editor Comments** (`id: 24`, text, optional): Enter any comments from the editor.
* **File Attachment 2** (`id: 25`, text, optional): Attach a second file related to the manuscript, if applicable.
