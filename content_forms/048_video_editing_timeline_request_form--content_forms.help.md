# Video Editing Timeline Request Form - Help Guide
## Purpose
This form is designed to gather essential information for the video editing process. It helps the video editing team to accurately capture project details, deadlines, editor information, and files that need to be edited.

## How To Complete This Form
To complete this form accurately, follow these steps:

1.  Enter project details in the first field.
2.  Specify the deadline for the project in the second field.
3.  Provide information about the editors working on the project in the third field.
4.  Select all the files that require editing in the fourth field.

## Field-by-Field Explanation
* **Project Details**: A text field where you can enter any relevant details about the project.
* **Deadline**: A date field where you can select the deadline for the project.
* **Editors Info**: A text field where you can provide information about the editors working on the project.
* **Project Files**: A multiple-select field where you can choose all the files that need to be edited.

## Tips
- Please fill out each field completely and accurately to avoid any confusion or delays in the editing process.
- Ensure that you only select files that are relevant to the project. 
- If you are unsure about any field, you can reach out to the video editing team for further clarification.
