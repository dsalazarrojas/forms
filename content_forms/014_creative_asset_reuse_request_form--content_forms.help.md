# Creative Asset Reuse Request Form - Help Guide
## Purpose
The Creative Asset Reuse Request Form is used to request access to pre-existing creative assets for use in new and existing content projects.

## How To Complete This Form
To complete this form, follow these steps:

1.  Enter the name of the project you are requesting the creative asset for.
2.  Enter the title and name of the creative asset you are requesting.
3.  Select the type of request you are making (e.g., 'reuse' or 'update').
4.  Enter the URL of the creative asset you are requesting, or if not applicable, select 'N/A'.
5.  Enter the date you are requesting the asset for.
6.  If applicable, select a specific time of day you are requesting the asset for.
7.  Enter your name and email address so that we can contact you.
8.  Enter your phone number (optional).
9.  Add any additional comments or requests for the asset.

## Field-by-Field Explanation

*   **Form Name**: The name of the project you are requesting the creative asset for.
    *   Type: Text
    *   Required: Optional
*   **Creative Asset**: The title and name of the creative asset you are requesting.
    *   Type: Text
    *   Required: Optional
*   **Asset Name**: The specific name of the asset being requested.
    *   Type: Text
    *   Required: Required
*   **Request Type**: The type of request you are making (e.g., 'reuse' or 'update').
    *   Type: Select One
    *   Required: Required
*   **Asset URL**: The URL of the creative asset you are requesting, or select 'N/A' if not applicable.
    *   Type: Text
    *   Required: Optional
*   **Request Date**: The date you are requesting the asset for.
    *   Type: Date
    *   Required: Required
*   **Request Time**: A specific time of day you are requesting the asset for, if applicable.
    *   Type: Time
    *   Required: Optional
*   **Requester Name**: Your name so that we can contact you.
    *   Type: Text
    *   Required: Required
*   **Requester Email**: Your email address so that we can contact you.
    *   Type: Email
    *   Required: Required
*   **Requester Phone**: Your phone number (optional).
    *   Type: Text
    *   Required: Optional
*   **Comments**: Additional comments or requests for the asset.
    *   Type: Text
    *   Required: Optional
