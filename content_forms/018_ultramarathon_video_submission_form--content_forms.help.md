# Ultramarathon Video Submission Form - Help Guide
## Purpose
This form is designed to collect information about ultramarathon events for submission to a platform. Please fill out the form accurately and completely to ensure a smooth review process.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the event details, including the event name, location, and date.
2. Provide a brief description of the event recap, including any notable moments or achievements.
3. Add a description of the footage you are submitting, including a brief explanation of what it shows.
4. Enter any relevant participant details, including their name, and any other relevant information.
5. Add any additional participant footage if applicable.
6. Enter the event start and end times.
7. Submit the form by clicking the "Submit" button.

## Field-by-Field Explanation
* **Event Details (Event Details)**: Enter the name of the ultramarathon event, including any relevant dates or categories (e.g., distance, terrain).
* **Participant Details (Participant Details)**: Enter a brief description of the participant, including their name and any other relevant information.
* **Footage Details (Footage Details)**: Enter a brief description of the footage you are submitting, including what it shows and why it's relevant to the event.
* **Event Recap (Event Recap)**: Enter a short description of the event, including any notable moments or achievements.
* **Event Recap Description (Event Recap Description)**: Enter a more detailed description of the event, including any notable moments or achievements.
* **Participant Footage (Participant Footage)**: Add any additional participant footage, such as photos or videos, that showcase their performance.
* **Participant Footage URL (Participant Footage URL)**: Enter the URL of the participant's footage, if it's hosted online.
* **Event Date (Event Date)**: Enter the date of the event.
* **Event Start Time (Event Start Time)**: Enter the start time of the event.
* **Event Location (Event Location)**: Enter the location of the event.
* **Tips**
* Make sure to review each field carefully before submitting the form.
* If you're unsure about any information, you can contact us at form@gic.mx for clarification.
