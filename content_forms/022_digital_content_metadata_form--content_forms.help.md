# Digital Content Metadata Form - Help Guide
## Purpose
This form is used to collect metadata about digital content, ensuring consistency and accuracy in the metadata collected.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter a valid **Project Title** that accurately represents the content.
2. Enter a valid **Creator Name** that is associated with the content.
3. Enter a valid **Publication Date** for the content.
4. Select the **Content Type** from the available options (Video, Audio, Image).
5. Select relevant **Keywords** from the provided options.
6. Select the **Language** of the content from the available options (en, fr, es).
7. Enter the **Author Name**.
8. If necessary, enter the **Contributor Name** and choose the **Contributor Role**.
9. Fill in the **Rights Holder** field to specify who holds the rights to the content.
10. Enter a valid **Publication Date Range**.
11. Fill in the **Copyright** information correctly, including the **Copyright Status**.
12. Provide a valid **URL** for the content.
13. If necessary, enter an **E-mail** address for further contact.
14. If necessary, enter a **Phone Number**.
15. Enter a description of the content in the **Description** field.
16. If necessary, select relevant **Keywords List** and **Categories**.
17. If necessary, select additional **Tags List**.

## Field-by-Field Explanation

* **Project Title** (text, required): Enter a valid project title that accurately represents the content.
* **Creator Name** (text, required): Enter a valid creator name that is associated with the content.
* **Publication Date** (date, required): Enter a valid publication date for the content.
* **Content Type** (select_one, required): Select the type of content from the available options (Video, Audio, Image).
* **Keywords** (select_multiple, required): Select relevant keywords from the provided options.
* **Language** (select_one, required): Select the language of the content from the available options (en, fr, es).
* **Author Name** (text, required): Enter the author's name.
* **Contributor Name** (text, optional): Enter the contributor's name if necessary.
* **Contributor Role** (text, required): Describe the contributor's role in the content creation.
* **Rights Holder** (text, required): Specify who holds the rights to the content.
* **Publication Date Range** (date, required): Enter a valid publication date range.
* **Copyright** (text, required): Fill in the copyright information correctly.
* **Copyright Status** (select_one, required): Select the copyright status from the available options (published, pending, withdrawn, expired).
* **URL** (text, required): Provide a valid URL for the content.
* **E-mail** (email, optional): Enter an E-mail address for further contact if necessary.
* **Phone** (text, optional): Enter a phone number if necessary.
* **Description** (note, optional): Enter a description of the content.
* **Keywords List** (select_multiple, optional): Select additional keywords if necessary.
* **Categories** (select_multiple, optional): Select additional categories if necessary.
* **Tags List** (select_multiple, optional): Select additional tags if necessary.
* **Related Links** (text, optional): Provide related links if necessary.
* **Another Tags List** (select_multiple, optional): Select additional tags if necessary.
