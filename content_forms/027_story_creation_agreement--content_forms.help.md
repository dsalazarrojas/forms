# Story Creation Agreement - Help Guide
## Purpose
The Story Creation Agreement form is a tool used to collect and manage project details for content creation projects. It helps to streamline the process of creating new projects and ensures that all necessary information is captured.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the **Project Details** section and provide a brief description of the project.
2. In the **Delivery Date** section, enter the date by which the project is expected to be completed.
3. In the **Compensation** section, enter the agreed-upon compensation for the project.
4. In the **Payment Terms** section, enter any additional payment terms that apply to the project.
5. In the **Project Start Date** and **Project End Date** sections, enter the start and end dates of the project.
6. In the **Project Status** section, select the current status of the project (Active or Inactive).
7. In the **Client Name** section, enter the name of the client.
8. In the **Payment Terms 2** and **Agency Terms** sections, enter any additional payment or agency terms that apply to the project.
9. In the **Project Notes** section, enter any additional notes about the project.
10. In the **Project Terms** section, enter any additional terms that apply to the project.
11. In the **Project Type** section, enter the type of project (although this field is not required, it can be useful for categorization purposes).

## Field-by-Field Explanation
* **Project Details**: Enter a brief description of the project, providing context and an overview of the work to be done.
* **Delivery Date**: Enter the expected completion date of the project, helping to set realistic deadlines and expectations.
* **Compensation**: Enter the agreed-upon compensation for the project, including any relevant financial details.
* **Payment Terms**: Enter any additional payment terms that apply to the project, such as payment schedules or conditions.
* **Project Start Date** and **Project End Date**: Enter the start and end dates of the project, helping to set a clear timeline.
* **Project Status**: Select the current status of the project (Active or Inactive), indicating its progress and availability.
* **Client Name**: Enter the name of the client, ensuring clear communication and accountability.
* **Payment Terms 2** and **Agency Terms**: Enter any additional payment or agency terms that apply to the project, providing clarity on expectations and responsibilities.
* **Project Notes**: Enter any additional notes or comments about the project, providing context and reference points for future use.
* **Project Terms**: Enter any additional terms that apply to the project, such as specific conditions or requirements.
* **Project Type**: Enter the type of project, providing categorization and filtering capabilities (optional but helpful for organization and reporting purposes).
