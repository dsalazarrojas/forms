# Film Restoration Project Application Form - Help Guide
## Purpose
The purpose of this form is to provide detailed information about a film restoration project. Fill out this form carefully to ensure accurate and comprehensive data submission.

## How To Complete This Form
- Start by filling out the required fields, which are indicated by the asterisk \* symbol. This form is divided into multiple pages.
- Review and fill out each field carefully, as they are critical to ensuring the project's submission is accurate and complete.
- Ensure you have all necessary information before submitting the form. If you are unsure about any field, please refer to the field-by-field explanation below.

## Field-by-Field Explanation
* **Project Title** (Project Title, text, required/optional: false): Enter a brief title of the project.
* **Project Lead** (Project Lead, text, required/optional: false): Enter the name of the person in charge of the project.
* **Project Description** (Project Description, text, required/optional: false): Provide a brief description of the project.
* **Film Title** (Film Title, text, required/optional: false): Enter the title of the film being restored.
* **Film Year** (Film Year, number, required/optional: false): Enter the year of the film.
* **Project Location** (Project Location, text, required/optional: false): Enter the location where the project was filmed or is being restored.
* **Team Name** (Team Name, text, required/optional: false): Enter the name of the team responsible for the project.
* **Project Status** (Project Status, select_one, required/optional: false): Select the current status of the project (Active, Inactive, Completed).
* **Project Start Date** (Project Start Date, date, required/optional: false): Enter the date the project started.
* **Project End Date** (Project End Date, date, required/optional: false): Enter the date the project finished.

## Tips
- Double-check all fields carefully before submitting the form.
- If you need more information about any field, please refer to the field-by-field explanation above.
- If you are unsure about any field, please contact the relevant authorities or project lead for further assistance.
