# video-metadata-update-form - Help Guide
## Purpose
This form is used to update video metadata.

## How To Complete This Form
- Fill out the form in the following steps:
    1. Click on the "Update" button to begin filling out the form.
    2. Enter the video title on page 1.
    3. Select the video category on page 1.
    4. Select multiple tags on page 1.
    5. Enter the video ID on page 1.
    6. Move on to page 2.
    7. Enter the upload date on page 2.
    8. Enter the update date on page 2.
    9. Select the status on page 2.
    10. Enter the description on page 2.
    11. Enter the user email on page 2.
    12. Enter the user phone on page 2.
    13. Enter the assigned tool on page 2.
    14. Enter notes on page 2.
    15. Enter category ID on page 2.
    15. Enter tags ID on page 2.
    15. Enter video ID on page 2.
    15. Enter thumbnail ID on page 2.
    15. Enter upload date ID on page 2.
    15. Enter update date ID on page 2.
    15. Enter status ID on page 2.
    15. Enter description ID on page 2.
    15. Enter user email ID on page 2.
    15. Enter user phone ID on page 2.
    15. Enter notes ID on page 2.
    15. Enter form ID on page 2.

## Field-by-Field Explanation
- **Video Title** (1, text, required): Enter the title of the video.
- **Video Category** (2, select_one, required): Select the category of the video.
- **Tags** (3, select_multiple, required): Select multiple tags for the video.
- **Video ID** (4, text, required): Enter the ID of the video.
- **Upload Date** (6, date, required): Enter the date the video was uploaded.
- **Update Date** (7, date, required): Enter the date the video was updated.
- **Status** (8, select_one, required): Select the status of the video.
- **Description** (9, text, required): Enter a description of the video.
- **User Email** (10, email, required): Enter the email of the user who uploaded the video.
- **User Phone** (11, text, required): Enter the phone number of the user who uploaded the video.
- **Assigned Tool** (12, text, required): Enter the tool assigned to the video.
- **Notes** (13, note, required): Enter any additional notes about the video.
- **Category ID** (14, text, required): Enter the ID of the category.
- **Tags ID** (15, text, required): Enter the ID of the tags.
- **Video ID** (16, text, required): Enter the ID of the video.
- **Thumbnail ID** (17, text, required): Enter the ID of the thumbnail.
- **Upload Date ID** (18, text, required): Enter the ID of the upload date.
- **Update Date ID** (19, text, required): Enter the ID of the update date.
- **Status ID** (20, text, required): Enter the ID of the status.
- **Description ID** (21, text, required): Enter the ID of the description.
- **User Email ID** (22, text, required): Enter the ID of the user email.
- **User Phone ID** (23, text, required): Enter the ID of the user phone.
- **Notes ID** (24, text, required): Enter the ID of the notes.
- **Form ID** (25, text, required): Enter the ID of the form.
