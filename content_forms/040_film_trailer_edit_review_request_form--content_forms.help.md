# film_trailer_edit_review_request_form - Help Guide
## Purpose
This form is designed to collect and track feedback, review status updates, and associated files for editing film trailers.

## How To Complete This Form
To complete this form, follow these steps:

1.  Fill out the "Edit Notes" field with any general notes or comments about the film trailer.
2.  Select the "Deadline Date" and "Deadline Time" fields to schedule the review deadline.
3.  Provide any associated "Links" to relevant files or resources.
4.  Attach "Reference Files" for further reference.
5.  Select the "Review Request Status" to track the status of the review request.
6.  Add "Review Request Notes" for any additional details about the review request.
7.  Enter "Edit Requester" name for the person requesting the edit.
8.  Enter "Reviewer Notes" for comments from the reviewer.

## Field-by-Field Explanation

### Edit Notes
*   Edit Notes (text): A field for any general notes or comments about the film trailer.

### Deadline Date
*   Deadline Date (date): Select the date when the deadline for the review should be met.

### Deadline Time
*   Deadline Time (time): Select the time when the deadline for the review should be met.

### Links
*   Links (text): For any associated links to relevant files or resources.

### Reference Files
*   Reference Files (text): Attach any additional reference files.

### Review Request Status
*   Review Request Status (select one): Select the status of the review request, such as awaiting approval or feedback.

### Review Request Notes
*   Review Request Notes (text): For any additional comments or details about the review request.

### Edit Requester
*   Edit Requester (text): Enter the name of the person requesting the edit.

### Reviewer Notes
*   Reviewer Notes (text): Enter comments from the reviewer.
