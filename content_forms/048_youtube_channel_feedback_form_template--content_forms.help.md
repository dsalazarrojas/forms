# youtube_channel_feedback_form_template - Help Guide
## Purpose
This form is designed to collect feedback from YouTube channel viewers about what they like and dislike about the channel, and their opinions on the content quality.

## How To Complete This Form
To complete this form, simply navigate through each page and fill out the fields as requested. Each page is labeled as "feedback_form" and contains the following fields:
- Fill out page 1 with any comments or feedback you have about the channel.
- On page 2, select what you like about the channel by typing in the text field "what_do_you_like".
- On page 3, select what you dislike about the channel by typing in the text field "what_do_you_dislike".
- On page 4, select your opinion on the content quality of the channel using the multi-select option "do_you_like_content_quality".
- On page 5, enter your email address in the "email" field to receive a copy of your submitted feedback.

## Field-by-Field Explanation
* **Feedback Form** (`feedback_form`, text, required: false): This is a text field where you can enter any comments or feedback you have about the channel. It's a good place to let us know what's on your mind.
* **What Do You Like?** (`question_1`, text, required: false): This is a text field where you can select what you like about the channel. Examples might include "interesting content", "good energy", or "entertaining videos".
* **What Do You Dislike?** (`question_2`, text, required: false): This is a text field where you can select what you dislike about the channel. Examples might include "poor video quality", "inaccurate information", or "not engaging".
* **Do You Like Content Quality?** (`question_3`, select_multiple, required: false): This is a multi-select option field where you can choose from "good", "better", "best", "worse", "worst", or "neutral" to describe your opinion on the content quality of the channel.
* **Email** (`email`, email, required: false): This is a field where you can enter your email address if you'd like to receive a copy of your submitted feedback.
