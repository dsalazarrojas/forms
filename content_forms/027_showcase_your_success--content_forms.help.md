# Showcase Your Success - Help Guide
## Purpose
The "Showcase Your Success" form is designed to collect information about a success story from a user. The information collected will be used to display on a public platform, allowing others to learn from and be inspired by the user's success.

## How To Complete This Form

1.  Go through the form section by section.
2.  Fill in all required fields.
3.  Fill in any additional fields you wish to complete your story.

## Field-by-Field Explanation

*   **Story Details** (text, optional): This section allows users to input their story details.
*   **Story File** (text, optional): This section allows users to upload a story file.
*   **Supporting Files** (text, optional): This section allows users to upload supporting files.
*   **Publish Details** (text, optional): This section allows users to input information about the story's publication.
*   **Publish Consent** (select_one, optional): This section allows users to choose how to share their story (Public, Private, Not Shared).
*   **Recognition Program** (select_multiple, optional): This section allows users to choose how to share their recognition (Public, Private, Not Shared).
*   **Story Tags** (text, optional): This section allows users to input story tags.
*   **File Tags** (text, optional): This section allows users to input file tags.
*   **Recognition Tags** (text, optional): This section allows users to input recognition tags.
*   **Recognition Program Tags** (text, optional): This section allows users to input recognition program tags.
*   **Story Description** (text, optional): This section allows users to input a description of their story.
*   **User Details** (text, optional): This section allows users to input their personal details.
*   **Contact Info** (text, optional): This section allows users to input their contact information.

Note: All fields are optional unless stated otherwise.
