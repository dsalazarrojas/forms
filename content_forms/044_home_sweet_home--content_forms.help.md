# Home Sweet Home - Help Guide
## Purpose
The "Home Sweet Home" form is designed to collect information about home-related programs or projects. It is intended for tracking or management purposes.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the Nomination Basket Program field with a brief description of the program or project.
2. Enter your Full Name in the text field provided.
3. Provide your Address in the Address field.
4. Enter the Start Date and End Date of the program or project in the respective date fields.
5. Write a brief description of the program or project in the Program Description field.
6. Specify the Program Duration and Program Duration 2 fields with numbers.
7. Choose the correct Program Type from the options provided.
8. Select multiple options for the Program Category field.
9. Select the current status of the program or project from the Program Status field.
10. Add any additional notes about the program or project in the Program Notes field.

## Field-by-Field Explanation

* **Nomination Basket Program** (`nomination_basket_program`, text, optional): A brief description of the program or project.
* **Full Name** (`name`, text, optional): Your full name.
* **Address** (`home_details`, text, optional): Your address.
* **Start Date** (`start_date`, date, optional): The start date of the program or project.
* **End Date** (`end_date`, date, optional): The end date of the program or project.
* **Program Description** (`description`, text, optional): A brief description of the program or project.
* **Program Duration** (`program_duration`, number, optional): The duration of the program or project.
* **Program Type** (`program_type`, select_one, optional): The type of program or project (Home Improvement, Home Renovation, Home Maintenance, Home Repair, or Other).
* **Program Category** (`program_category`, select_multiple, optional): Multiple categories for the program or project (Type A, Type B, Type C, Type D, Type E).
* **Program Status** (`program_status`, select_one, optional): The current status of the program or project (Active, Inactive, Pending, Cancelled).
* **Program Notes** (`program_notes`, text, optional): Any additional notes about the program or project.
* **Program Duration 2** (`program_duration_2`, number, optional): Another duration field for the program or project.

## Tips

* Make sure to fill in all required fields (if any) to ensure accurate data entry.
* Use the select_one and select_multiple fields to choose the correct options for each field.
* If you have any questions or need help, contact form@gic.mx.
