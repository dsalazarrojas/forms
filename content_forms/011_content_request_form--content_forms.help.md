# Content Request Form - Help Guide
## Purpose
The Content Request Form is a tool for users to request content creation from a content team. It helps content creators gather the necessary information to produce high-quality content that meets the user's requirements.

## How To Complete This Form
To complete this form, follow these steps:
- Start by providing a brief description of the content topic and title in the "Content Topic/Title" field.
- Select the target audience for the content in the "Target Audience" field.
- Specify the format of the content you are requesting (e.g., Blog Post, Case Study, Video Script, etc.) in the "Requested Format" field.
- Provide an approximate word count for the content in the "Desired Word Count" field.
- List specific subtopics or arguments to be covered in the "Key Points to Cover" field.
- If necessary, upload relevant visual assets (e.g., graphics, screenshots, charts) to support the content.
- Select the priority level of the request (Low, Medium, High) in the "Request Priority" field.
- Finally, add any additional comments or requirements in the "Additional Comments" field.

## Field-by-Field Explanation
- **Your Name** (`requester_name`, text, required): This field is for your name as the person requesting the content.
- **Department/Project** (`requester_department`, text, required): This field is for the department or project you are representing.
- **Content Topic/Title** (`content_topic`, text, required): Provide a brief description of the content topic and title.
- **Requested Format** (`content_format`, select_one, required): Choose the primary format for the content (e.g., Blog Post, Case Study, Video Script, etc.).
- **Target Audience** (`target_audience`, text, required): Select the target audience for the content.
- **Desired Word Count** (`desired_word_count`, number, optional): This is an approximate word count for the content.
- **Key Points to Cover** (`key_points_to_cover`, text, required): List specific subtopics or arguments to be covered.
- **-- Production Requirements --** (`production_details_header`, note, required): This section is for providing details on timing and references.
- **Deadline Date** (`deadline_date`, date, required): Specify the deadline for the final content version.
- **Reference Links or Documents** (`reference_links`, text, optional): Provide links to similar content or source data.
- **Are visual assets required?** (`visual_assets_needed`, select_one, required): Choose if visual assets (e.g., graphics, screenshots, charts) are needed.
- **Request Priority** (`priority_status`, select_one, required): Select the priority level of the request (Low, Medium, High).
- **Additional Comments** (`additional_comments`, text, optional): Add any additional comments or requirements for the content creation.
