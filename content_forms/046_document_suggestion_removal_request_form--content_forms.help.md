# Document Suggestion Removal Request Form - Help Guide

## Purpose
This form is used to request removal of a document from the system. Fill out this form to submit a request to remove a suggested document.

## How To Complete This Form
To complete this form, simply select the relevant options and fill out the required fields. If you have any issues with the form or need assistance, feel free to reach out to a system administrator.

## Field-by-Field Explanation
* **Document Suggestion Removal Request Form** (page 1): Select 'Yes' to indicate that you want to remove the suggested document.
* **Document Title**: Enter the title of the document you want to remove.
* **Reason**: Provide a brief explanation for the removal request.
* **Document URL**: Enter the URL of the document you want to remove.
* **Suggested By**: Enter the name of the user who suggested the document.
* **Suggestion Date**: Select the date when the document was suggested.
* **Submitted By**: Select 'Yes' if you submitted the original suggestion.
* **Submitted Date**: Select the date when you submitted the original suggestion.
* **Status**: Select the status of the document (Active or Inactive).
* **Comments**: Any additional comments or feedback about the document.
* **Notes**: Any additional notes or information about the document.
* **Form ID**: Enter the unique ID of the form (not applicable for users).
* **Form Title**: Enter the title of the original form (not applicable for users).
* **Form Category**: Enter the category of the original form (not applicable for users).
* **Assigned Tool**: Enter any tool related to the original form (not applicable for users).
