# Content Optimization Checklist - Help Guide
## Purpose
The purpose of this form is to help users evaluate and improve the quality of their content for search engines and user experience.

## How To Complete This Form
To complete this form, please follow these steps:

1. Choose the type of content you are optimizing (e.g., Blog Post, Landing Page, etc.).
2. Fill out the form with the relevant information for each question.
3. Answer each question carefully, taking into account the specific content you are optimizing.
4. Review your answers to identify areas of improvement.
5. Use the results to make data-driven decisions to enhance your content's visibility and engagement.

## Field-by-Field Explanation
### Page 1: Content Details
* **Content Title** (`content_title`, `text`, required/optional): Enter the title of the content being optimized.
* **Content URL** (`content_url`, `text`, required/optional): Enter the URL of the content being optimized.
* **Content Type** (`content_type`, `select_one`, required/optional): Choose the type of content (e.g., Blog Post, Landing Page, etc.).
* **Optimizer Name** (`optimizer_name`, `text`, required/optional): Enter the name of the person performing the optimization.
* **Optimization Date** (`optimization_date`, `date`, required/optional): Enter the date of the optimization.

### Page 2: SEO Optimizations
* **Primary Keyword** (`primary_keyword`, `text`, required/optional): Enter the main target keyword.
* **Secondary Keywords** (`secondary_keywords`, `text`, optional/optional): Enter additional target keywords (if any).
* **Title Tag Optimized** (`title_tag_optimized`, `select_one`, required/optional): Check if the title tag is optimized for SEO.
* **Title Tag Length** (`title_tag_length`, `select_one`, required/optional): Check if the title tag is under 60 characters.
* **Meta Description Optimized** (`meta_description_optimized`, `select_one`, required/optional): Check if the meta description is optimized.
* **Meta Description Length** (`meta_description_length`, `select_one`, required/optional): Check if the meta description is 150-160 characters.

### Page 3: Content Quality and Structure
* **Keyword in Title** (`keyword_in_title`, `select_one`, required/optional): Check if the primary keyword is in the title.
* **Keyword in First Paragraph** (`keyword_in_first_paragraph`, `select_one`, required/optional): Check if the primary keyword is in the first 100 words.
* **Keyword Density** (`keyword_density`, `select_one`, required/optional): Check if the keyword density is appropriate (1-2%).
* **Headers Optimized** (`headers_optimized`, `select_one`, required/optional): Check if H1, H2, H3 tags are properly used.

### Page 4: Images and Links
* **Image Alt Text** (`image_alt_text`, `select_one`, required/optional): Check if all images have alt text.
* **Internal Links** (`internal_links`, `select_one`, required/optional): Check if there are internal links to related content (3 or more).
* **External Links** (`external_links`, `select_one`, required/optional): Check if there are authoritative external links.
* **URL Structure** (`url_structure`, `select_one`, required/optional): Check if the URL is short and descriptive.

### Page 5: User Experience and Performance
* **Mobile Friendly** (`mobile_friendly`, `select_one`, required/optional): Check if the content is mobile-optimized.
* **Page Load Speed** (`page_load_speed`, `select_one`, required/optional): Check if the page loads in under 3 seconds.
* **Call to Action** (`call_to_action`, `select_one`, required/optional): Check if there is a clear call to action.
* **Readability Score** (`readability_score`, `select_one`, required/optional): Check if the content is easy to read.
* **Schema Markup** (`schema_markup`, `select_one`, required/optional): Check if structured data is implemented.
* **Social Sharing Enabled** (`social_sharing_enabled`, `select_one`, required/optional): Check if social share buttons are present.
* **Content Freshness** (`content_freshness`, `select_one`, required/optional): Check if the content is up to date.

### Additional Optimizations
* **Additional Optimizations** (`additional_optimizations`, `text`, optional/optional): Enter any other optimizations made.
