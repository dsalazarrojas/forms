# creative_competition_footage_usage_consent_form - Help Guide

## Purpose
This form is used to capture consent and necessary information for a creative competition.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill in your user input (page 1).
2. Provide a title for your submission (page 2).
3. Upload your submission file (page 3).
4. Specify the purpose of usage for your submission (page 4).
5. Enter your email address (page 5).
6. Enter your phone number (page 6).
7. Choose the usage rights for your submission (page 7).
8. Specify the duration of usage (page 8).
9. Enter any notes on usage rights and usage agreement (page 9 and 10).
10. Choose whether you accept or decline the usage agreement (page 11).
11. Confirm your submission details (page 12).

## Field-by-Field Explanation

* **User Input** (page 1, required: false): This field is for users to enter any additional information about their submission.
* **Submission Title** (page 2, required: false): Enter a title for your submission.
* **Submission File** (page 3, required: false): Upload your submission file.
* **Usage Purpose** (page 4, required: false, type: select multiple):
	+ **contests**: This is for submissions related to contests.
	+ **festivals**: This is for submissions related to festivals.
	+ **campaigns**: This is for submissions related to campaigns.
* **Email** (page 5, required: false): Enter your email address.
* **Phone Number** (page 6, required: false): Enter your phone number.
* **Usage Rights** (page 7, required: false, type: select one):
	+ **all**: This means the user has given consent for all types of usage.
	+ **exclusive**: This means the user has given consent for exclusive usage.
	+ **non exclusive**: This means the user has given consent for non-exclusive usage.
* **Usage Duration** (page 8, required: false, type: select multiple):
	+ **forever**: This means the submission can be used indefinitely.
	+ **until terminated**: This means the submission can be used until it is terminated.
	+ **until cancellation**: This means the submission can be used until it is cancelled.
* **Cancellation** (page 9, required: false, type: note): Enter any notes on cancellation.
* **Submission Agreement** (page 10, required: false, type: note): Enter any notes on submission agreement.
* **Creative Commons License** (page 11, required: false, type: select one):
	+ **any**: This means the user has given consent for any creative commons license.
	+ **some**: This means the user has given consent for some creative commons licenses.
	+ **none**: This means the user has not given consent for any creative commons licenses.
* **Usage Agreement** (page 12, required: false, type: note): Enter any notes on usage agreement.
* **Organizer Information** (page 13, required: false): Enter any information about the organizer.
* **Organizer Name** (page 14, required: false): Enter the name of the organizer.
* **Organizer Email** (page 15, required: false): Enter the organizer's email address.
* **Organizer Phone** (page 16, required: false): Enter the organizer's phone number.
* **Organizer Website** (page 17, required: false): Enter the organizer's website.
* **Submission Date** (page 18, required: false): Enter the date of submission.
* **Submission Time** (page 19, required: false): Enter the time of submission.
* **Submission Time Zone** (page 20, required: false): Select the time zone of submission.
* **Submission Location** (page 21, required: false): Enter the location of submission.
* **Submission File** (page 22, required: false): Upload a file related to submission.
* **Creative Commons License Notes** (page 23, required: false): Enter any notes on creative commons license.
* **Usage Agreement Notes** (page 24, required: false): Enter any notes on usage agreement.
* **Usage Agreement Acceptance** (page 25, required: false, type: select one):
	+ **accepted**: This means the user has accepted the usage agreement.
	+ **declined**: This means the user has declined the usage agreement.
* **User Confirmation** (page 26, required: false, type: select multiple):
	+ **confirmation 1**: This is the first confirmation.
	+ **confirmation 2**: This is the second confirmation.
	+ **confirmation 3**: This is the third confirmation.
	+ **confirmation 4**: This is the fourth confirmation.
