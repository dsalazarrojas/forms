# Category Management Form - Help Guide
## Purpose
The Category Management Form is a tool for managing categories within an e-commerce platform, CMS, or digital library. It allows users to create, update, or deactivate categories and set up relationships between them.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the type of management action you want to perform using the "Type of Management Action" field.
2. Specify the target system where the category will be created or updated.
3. Enter the category name exactly as it will be displayed.
4. If necessary, select a parent category for the new category.
5. Provide a description of the category (optional).
6. Choose the category's visibility status (public, members only, hidden, or archived).
7. For SEO and taxonomy purposes, you can add an SEO title tag and meta keywords (optional).
8. If applicable, select related categories for cross-linking.
9. Choose the category owner/manager.
10. Schedule a review frequency (monthly, quarterly, annually, or ad-hoc).
11. Set the effective date for the change.
12. Confirm that manager approval has been obtained.

## Field-by-Field Explanation

* **Type of Management Action** (`action_type`, select_one): Choose from "Create New Category", "Update Existing Category", "Deactivate/Archive Category", or "Merge Categories".
* **Target System** (`target_system`, text): Enter the name of the system where the category will be created or updated (e.g., E-commerce Platform, CMS, Digital Library).
* **Category Name** (`category_name`, text): Enter the exact name to be displayed for the category.
* **Parent Category** (`parent_category_name`, text): Write "Root" if it's a top-level category.
* **Category Description** (`category_description`, text): Provide a description of the category (internal or public-facing).
* **Category Visibility** (`visibility_status`, select_one): Choose from "Public - Visible to all", "Members Only", "Hidden - Internal use", or "Archived".
* **SEO Title Tag** (`seo_title_tag`, text): Add a title tag for SEO purposes (optional).
* **Meta Keywords** (`meta_keywords`, text): Enter keywords separated by commas (optional).
* **Related Categories for Cross-linking** (`related_categories_list`, text): List related categories (optional).
* **Category Owner/Manager** (`category_owner`, text): Choose the category owner/manager.
* **Scheduled Review Frequency** (`review_frequency`, select_one): Select from "Monthly", "Quarterly", "Annually", or "Ad-hoc".
* **Effective Date for Change** (`last_updated_date`, date): Set the date for when the change takes effect.
* **Manager Approval Obtained** (`approval_status`, select_one): Confirm that manager approval has been obtained (yes or pending).

## Tips
* Make sure to complete all required fields.
* Double-check the category name and description for accuracy.
* Ensure that the category owner/manager is aware of the changes.
* Review and update the category's visibility status as necessary.
* Schedule reviews and confirm manager approval for ongoing category management.
