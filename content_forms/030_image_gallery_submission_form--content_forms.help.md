# Image Gallery Submission Form - Help Guide
## Purpose
The Image Gallery Submission Form is designed for users to submit new images to the image gallery for internal use within the organization. This form captures necessary information to categorize and store the submitted images.

## How To Complete This Form
To complete this form, follow these steps:
1. Enter the title of the image in the "form-title" field.
2. Select the category of the image from the list of options in "form-category".
3. Provide a description of the image in the "form-description" field.
4. Upload the image file in the "form-file" field.
5. Enter the date and time of the image submission in the "form-date" and "form-time" fields.
6. Enter your email address in the "form-email" field.
7. Enter your phone number in the "form-phone" field.
8. Add any additional notes about the image in the "form-notes" field.
9. Select one option from the list in "form-select-one".
10. Select multiple options from the list in "form-select-multiple".
11. Enter a numeric value in the "form-integer" field.
12. Enter a decimal value in the "form-decimal" field.
13. Enter text in the "form-text" field.
14. Enter a password in the "form-password" field (not recommended for security reasons).

## Field-by-Field Explanation
- **form-title** (text, required/optional): Enter the title of the image.
- **form-category** (select one, required): Select the category of the image.
- **form-description** (text, required): Provide a description of the image.
- **form-file** (text, required): Upload the image file.
- **form-date** (date, required): Enter the date of the image submission.
- **form-time** (time, required): Enter the time of the image submission.
- **form-email** (email, required): Enter your email address.
- **form-phone** (text, required): Enter your phone number.
- **form-notes** (note, required): Add any additional notes about the image.
- **form-select-one** (select one, required): Select one option from the list.
- **form-select-multiple** (select multiple, required): Select multiple options from the list.
- **form-integer** (number, required): Enter a numeric value.
- **form-decimal** (number, required): Enter a decimal value.
- **form-text** (text, required): Enter text.
- **form-password** (text, optional): Enter a password (not recommended for security reasons).

## Tips
* Please make sure to fill out all required fields.
* Make sure to select the correct options for "form-select-one" and "form-select-multiple" fields.
* Enter valid email and phone number.
* Make sure to enter a valid password for "form-password" field (if filling it out). 
* Use a valid date and time format for "form-date" and "form-time" fields. 
* Use a valid image file for "form-file" field. 
* Use a valid image file format for "form-file" field.
