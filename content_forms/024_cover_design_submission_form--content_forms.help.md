# Cover Design Submission Form - Help Guide
## Purpose
This form is used for submitting new cover designs. Please fill out the form with your submission details and any relevant attachments.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the required fields: **first name**, **last name**, and **email**.
2. If you have a cover design image URL, provide it in the **cover design image URL** field.
3. If you have a file to submit, provide the **file URL** and other relevant details.
4. Choose the **submission type** from the options provided (cover design or other).
5. Choose the **submission status** from the options provided (submitted or not submitted).
6. If you have any comments, add them in the **comments** field.
7. If you have a file to upload, add the relevant details in the **file upload URL**, **file name**, **file size**, **file type**, and **file date uploadeed** fields.
8. If you have a cover design file, provide the **cover design file size** and other relevant details.
9. Choose the **is urgent** option if this is an urgent submission.
10. Choose the **team** and **user** fields as relevant.

## Field-by-Field Explanation

* **First name** (`first_name`, text, required): Enter your first name.
* **Last name** (`last_name`, text, required): Enter your last name.
* **Email** (`email`, email, required): Enter your email address.
* **Cover design image URL** (`cover_design_image_url`, text, optional): If you have a cover design image URL, provide it here.
* **Submission date** (`submission_date`, date, optional): Enter the date you are submitting this design.
* **Submission time** (`submission_time`, time, optional): Enter the time you are submitting this design.
* **Cover design description** (`cover_design_description`, text, optional): Add a description of your cover design.
* **Is urgent** (`is_urgent`, select_one, optional): Choose if this submission is urgent.
* **Submission type** (`submission_type`, select_multiple, optional): Choose the type of submission (cover design or other).
* **Submission status** (`submission_status`, select_one, optional): Choose the status of your submission (submitted or not submitted).
* **Comments** (`comments`, text, optional): Add any additional comments about your submission.
* **File upload URL** (`file_upload_url`, text, optional): Enter the URL where the file can be uploaded from.
* **File name** (`file_name`, text, optional): Enter the name of the file you are uploading.
* **File size** (`file_size`, number, optional): Enter the size of the file you are uploading.
* **File type** (`file_type`, text, optional): Enter the type of the file you are uploading.
* **File date uploadeed** (`file_date_uploadeed`, date, optional): Enter the date the file was uploaded.
* **File time uploaded** (`file_time_uploaded`, time, optional): Enter the time the file was uploaded.
* **File status** (`file_status`, select_one, optional): Choose the status of the file (uploaded or not uploaded).
* **File URL** (`file_URL`, text, optional): Enter the URL where the file can be downloaded from.
* **File description** (`file_description`, text, optional): Enter a description of the file.
* **Cover design file size** (`cover_design_file_size_bytes`, number, optional): Enter the size of the cover design file.
* **Submission date due** (`submission_date_due`, date, optional): Enter the date your submission is due.
* **Submission time due** (`submission_time_due`, time, optional): Enter the time your submission is due.
* **Team** (`team`, text, optional): Enter the team name.
* **User** (`user`, text, optional): Enter the user name.
* **Cover design submission form** (`cover_design_submission_form`, select_one, optional): Choose the type of cover design submission (e.g. logo, social media, etc.)
