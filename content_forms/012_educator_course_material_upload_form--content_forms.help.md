# Educator Course Material Upload Form - Help Guide
## Purpose
The Educator Course Material Upload Form is a tool designed for educators to upload various types of course materials, such as audio, video, and documents, for management and tracking within an educational institution.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in your First Name, Last Name, and Email.
2. Enter your Phone number.
3. Select the type of file you are uploading (Audio, Video, or Document).
4. Provide a brief Description of the material.
5. Choose the Category (Math, Science, or Art).
6. Select the File (by providing the File URL).
7. Enter the File Title and File Size.
8. Choose the File Type (e.g., MP3, MP4, PDF).
9. Choose the File Status (Pending Review, Approved, or Rejected).
10. Enter the File URL for download.
11. Enter the File Size for download.
12. Choose the File Status for download (Pending, Approved, or Rejected).
13. Enter the User ID and School ID (if applicable).
14. Enter the Course ID (if applicable).
15. Select the person who submitted the material (Submitted By).
