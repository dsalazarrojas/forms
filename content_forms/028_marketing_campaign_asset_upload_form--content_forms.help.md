# Marketing Campaign Asset Upload Form - Help Guide
## Purpose

This form is for uploading marketing campaign assets, such as images, videos, or documents. It's a critical component of our marketing campaign asset management system.

## How To Complete This Form

1. Fill out the **Marketing Campaign Name** field with the name of the marketing campaign that the asset is associated with.
2. Select the **Asset Type** from the available options to identify the type of asset being uploaded.
3. In the **Asset File** field, upload the actual file containing the marketing asset.
4. In the **Usage Context** field, describe the context in which the asset will be used (e.g., social media, email marketing, website).
5. In the **File Description** field, provide a brief description of the asset.
6. Select relevant **Tags** for the asset to aid in search and categorization.
7. In the **Comments** field, add any additional comments or notes about the asset.

## Field-by-Field Explanation

### Marketing Campaign Name
* **Marketing Campaign Name**: The name of the marketing campaign that the asset is associated with. This field is **required** and should be filled out accordingly.

### Asset Type
* **Asset Type**: The type of asset being uploaded (e.g., image, video, document). This field is **optional** but recommended for proper asset categorization.

### Asset File
* **Asset File**: The actual file containing the marketing asset. This field is **required** for uploading the asset.

### Usage Context
* **Usage Context**: The context in which the asset will be used (e.g., social media, email marketing, website). This field is **optional** but recommended for better asset management.

### File Description
* **File Description**: A brief description of the asset. This field is **optional** but recommended for better asset organization.

### Tags
* **Tags**: Relevant tags for the asset for easier search and categorization. This field is **optional** but recommended.

### Comments
* **Comments**: Additional comments about the asset. This field is **optional** but recommended for better asset tracking.

## Tips

* Be aware that asset tags are used for filtering and categorization, so please use relevant tags for better asset discoverability.
* Do not upload unnecessary or duplicate assets to avoid clutter and confusion.
* Only upload assets by authorized personnel to prevent unauthorized access or asset misuse.
