# Online Course Content Submission Form - Help Guide

## Purpose
This form is designed to collect information about online courses, including instructor details, course information, and file uploads. It is intended for instructors or administrators to submit course content for review and publication. Please ensure that the submitted information is accurate and relevant to the course.

## How To Complete This Form
1. Start by filling in the required fields, marked with an asterisk (*).
2. Select the correct options from the dropdown menus where indicated.
3. Upload any necessary files as required.

## Field-by-Field Explanation

* **Course Information** (`id: 2`, `required: true`): Please provide course details, including course name, code, description, start date, end date, and instructor's name.
* **Course Name** (`id: 3`, `required: false`): Enter the name of the course.
* **Course Code** (`id: 4`, `required: false`): Enter the alpha-numeric code of the course.
* **Course Description** (`id: 5`, `required: false`): Provide a brief description of the course.
* **Start Date** (`id: 6`, `required: true`): Enter the start date of the course in the format YYYY-MM-DD.
* **End Date** (`id: 7`, `required: true`): Enter the end date of the course in the format YYYY-MM-DD.
* **Instructor** (`id: 8`, `required: false`): Enter the name of the instructor.
* **Course Level** (`id: 9`, `required: true`): Select one of the following options:
	+ High
	+ Low
* **Other (Specify)** (`id: 10`, `required: false`): If the course level is not High or Low, describe it here.
* **Language** (`id: 12`, `required: true`): Select one of the following options:
	+ Yes
	+ No
* **Other (Specify)** (`id: 13`, `required: false`): If the language is not Yes or No, describe it here.
* **Upload file** (`id: 15`, `required: false`): Upload any supporting files for the course.
* **File type** (`id: 16`, `required: true`): Select Yes or No to indicate whether the file is a course file or not.
* **Size** (`id: 17`, `required: false`): Enter the file size in KB.
* **Content type** (`id: 18`, `required: true`): Select one or more of the following options:
	+ Yes
	+ No
* **Other (Specify)** (`id: 19`, `required: false`): If the content type is not Yes or No, describe it here.
* **Content file** (`id: 21`, `required: false`): Upload any content files.
* **Content file type** (`id: 22`, `required: true`): Select Yes or No to indicate whether the content file is a course file or not.
* **Content version** (`id: 23`, `required: false`): Enter the version of the content.
* **Review** (`id: 24`, `required: false`): Enter any additional comments or review.
* **Additional comments** (`id: 25`, `required: false`): Enter any additional comments.

Please fill in all the required fields and provide accurate information to ensure a successful submission. If you have any doubts or concerns, feel free to reach out to the support team.
