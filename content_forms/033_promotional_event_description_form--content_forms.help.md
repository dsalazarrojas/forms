# Promotional Event Description Form - Help Guide

## Purpose
The Promotional Event Description Form is used to gather information about promotional events. Please ensure that you are filling this form for a legitimate event that is not already included in our database. If you are unsure if an event is already listed, please search our event database before submitting this form. This form helps us collect detailed information about your event, which will be displayed on our promotional page.

## How To Complete This Form
To complete this form, follow these steps:

1. Provide a brief title for your event in the "Event Title" field.
2. Enter the date of your event in the "Event Date" field (YYYY-MM-DD format).
3. Choose the event duration in hours and minutes in the "Event Duration" field.
4. Select the type of event (Event, Conference, Seminar, Workshop) in the "Event Type" field.
5. Enter the location of your event in the "Event Location" field.
6. Optionally, add a detailed description of your event in the "Event Description" field.
7. Enter the name of the event organizer in the "Event Organizer" field.
8. If you want to, add the organizer's phone number in the "Event Contact Phone" field.
9. If you want to, add the organizer's email in the "Event Contact Email" field.
10. Select the status of your event (Active, Upcoming, Completed) in the "Event Status" field.
11. Optionally, add a link to your event in the "Event Link" field.
12. Optionally, add a photo of your event in the "Event Image" field.
13. If you want to, add more information about the organizer in the "Event Organizer Name", "Event Organizer Title", "Event Organizer Email", "Event Organizer Phone", "Event Organizer Address", "Event Organizer Website", "Event Organizer Facebook", "Event Organizer Instagram", "Event Organizer Twitter", "Event Organizer Other" fields.

## Field-by-Field Explanation

* **Event Title** (`event_title`, text, required): Enter a brief title for your event to help users identify it easily.
* **Event Date** (`event_date`, date, required): Enter the date of your event in YYYY-MM-DD format.
* **Event Time** (`event_time`, time, required): Enter the time of your event in 24-hour format.
* **Event Duration** (`event_duration`, number, required): Enter the duration of your event in hours and minutes.
* **Event Type** (`event_type`, select_one, required): Choose the type of event you are promoting (Event, Conference, Seminar, Workshop).
* **Event Location** (`event_location`, text, required): Enter the location of your event.
* **Event Description** (`event_description`, text, optional): Add a detailed description of your event if you want to.
* **Event Organizer** (`event_organizer`, text, optional): Enter the name of the event organizer.
* **Event Contact Phone** (`event_contact_phone`, text, optional): Enter the phone number of the event organizer.
* **Event Contact Email** (`event_contact_email`, email, optional): Enter the email of the event organizer.
* **Event Status** (`event_status`, select_one, required): Choose the status of your event (Active, Upcoming, Completed).
* **Event Link** (`event_link`, text, optional): Add a link to your event if you want to.
* **Event Image** (`event_image`, text, optional): Add a photo of your event if you want to.
* **Event Contact Email** (`event_contact_email`, email, optional): Enter the email of the event organizer.
* **Event Contact Phone** (`event_contact_phone`, text, optional): Enter the phone number of the event organizer.
* **Event Additional Info** (`event_additional_info`, text, optional): Add more information about your event if you want to.
* **Event Terms and Conditions** (`event_terms_and_conditions`, text, optional): Add any terms and conditions related to your event.
* **Event Organizer Name** (`event_organizer_name`, text, optional): Enter the name of the event organizer.
* **Event Organizer Title** (`event_organizer_title`, text, optional): Enter the title of the event organizer.
* **Event Organizer Email** (`event_organizer_email`, email, optional): Enter the email of the event organizer.
* **Event Organizer Phone** (`event_organizer_phone`, text, optional): Enter the phone number of the event organizer.
* **Event Organizer Address** (`event_organizer_address`, text, optional): Enter the address of the event organizer.
* **Event Organizer Website** (`event_organizer_website`, text, optional): Enter the website of the event organizer.
* **Event Organizer Facebook** (`event_organizer_facebook`, text, optional): Enter the Facebook profile of the event organizer.
* **Event Organizer Instagram** (`event_organizer_instagram`, text, optional): Enter the Instagram profile of the event organizer.
* **Event Organizer Twitter** (`event_organizer_twitter`, text, optional): Enter the Twitter profile of the event organizer.
* **Event Organizer Other** (`event_organizer_other`, text, optional): Enter other information about the event organizer if you want to.

Note: All fields marked as optional should be filled in only if necessary.
