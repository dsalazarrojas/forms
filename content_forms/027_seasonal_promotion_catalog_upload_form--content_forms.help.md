# Seasonal Promotion Catalog Upload Form - Help Guide
## Purpose
This form is used to upload seasonal promotions from vendors. It collects information about the promotion, including its title, description, image, price, and other relevant details.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the required fields with accurate and relevant information.
2. Ensure that all required fields are filled out before submitting the form.
3. Preview the form before submitting it to make sure everything looks correct.

## Field-by-Field Explanation
- **Vender Name** (`vendor_name`, text, required): Enter the name of the vendor who is uploading this promotion.
  * Ensure that this field is filled out with the correct vendor name.
  * Make sure to spell the name correctly.
- **Category** (`category`, select_one, optional): Choose whether this promotion is a yes or no category.
  * Select 'Yes' if this promotion fits into this category.
  * Select 'No' if it does not fit into this category.
- **Sub Category** (`subcategory`, select_one, optional): Choose whether this promotion is a yes or no subcategory.
  * Select 'Yes' if this promotion fits into this subcategory.
  * Select 'No' if it does not fit into this subcategory.
- **Product Name** (`product_name`, text, required): Enter the name of the product being promoted.
  * Ensure that this field is filled out with accurate and relevant information.
  * Make sure to spell the name correctly.
- **Product Description** (`product_description`, text, optional): Enter a brief description of the product.
  * This field is not required but it's recommended to provide a description for better understanding of the product.
  * Keep the description concise and relevant.
- **Product Image** (`product_image`, text, required): Enter the URL or image link of the product image.
  * Ensure that this field is filled out with the correct image URL.
  * Make sure the image is relevant to the product.
- **Product Video** (`product_video`, text, optional): Enter the URL or video link of the product video.
  * This field is not required but it's recommended to provide a video for better understanding of the product.
  * Keep the video concise and relevant.
- **Price** (`product_price`, number, required): Enter the price of the product.
  * Ensure that this field is filled out with accurate and relevant information.
  * Make sure to format the price correctly.
- **Tags** (`product_tags`, text, optional): Enter relevant tags for the product.
  * This field is not required but it's recommended to provide tags for better searchability.
  * Keep the tags concise and relevant.
- **Tags List** (`product_tags_list`, select_multiple, optional): Choose relevant tags for the product.
  * Select all the relevant tags that apply to the product.
  * Make sure to select only the correct tags.
- **Upload Date** (`upload_date`, date, required): Select the date you are uploading the promotion.
  * Ensure that this field is filled out with the correct date.
  * Make sure to format the date correctly.
- **Upload Time** (`upload_time`, time, optional): Select the time you are uploading the promotion.
  * This field is not required but it's recommended to provide a time for better tracking.
  * Keep the time concise and relevant.
- **Form Submission** (`form_submission`, note, optional): Enter any additional notes about the form submission.
  * This field is not required but it's recommended to provide any additional information.
  * Keep the notes concise and relevant.
- **E-Mail** (`email`, email, optional): Enter your email address.
  * This field is not required but it's recommended to provide an email address.
  * Make sure to format the email correctly.
- **Phone** (`phone`, text, optional): Enter your phone number.
  * This field is not required but it's recommended to provide a phone number.
  * Make sure to format the phone correctly.
- **Address** (`address`, text, optional): Enter your address.
  * This field is not required but it's recommended to provide an address.
  * Make sure to format the address correctly.
- **Country** (`country`, text, optional): Enter your country.
  * This field is not required but it's recommended to provide a country.
  * Make sure to format the country correctly.
- **City** (`city`, text, optional): Enter your city.
  * This field is not required but it's recommended to provide a city.
  * Make sure to format the city correctly.
- **Zip Code** (`zip_code`, text, optional): Enter your zip code.
  * This field is not required but it's recommended to provide a zip code.
  * Make sure to format the zip code correctly.
- **State** (`state`, text, optional): Enter your state.
  * This field is not required but it's recommended to provide a state.
  * Make sure to format the state correctly.

  * This field is not required but it's recommended to provide a region.

  * This field is not required but it's recommended to provide a latitude.

- **Notes** (`notes`, text, optional): Enter any additional notes.

  * Ensure that all required fields are filled out before submitting the form.
