# Image Upload For Visual Effects - Help Guide
## Purpose
The purpose of this form is to collect project briefs, reference images, deadlines, and other relevant information for visual effects projects.

## How To Complete This Form
To complete this form, follow these steps:
1. Review and understand the project brief on the first page.
2. Upload a reference image that is relevant to the project.
3. Set a deadline for the project if applicable.

## Field-by-Field Explanation

* **Project Brief** (`project_brief`, note, required: false): This is a brief description of the project. Please provide a concise summary of the project, including its objectives, goals, and any relevant details.
* **Reference Image** (`reference_image`, text, required: false): This is where you can upload a reference image that is relevant to the project. This image can help the visual effects team understand the project's visual requirements.
* **Deadline** (`deadline`, date, required: false): If applicable, please set a deadline for the project. This will help the visual effects team plan and prioritize their tasks accordingly.
* **Upload Button** (`upload_button`, text, required: false): This is the button to upload a reference image. Clicking on this button will prompt you to select a file from your device. Please ensure that the image you upload is relevant to the project.

## Tips
* Please make sure that the reference image is clear and relevant to the project.
* Avoid uploading unrelated images, as they may confuse the visual effects team.
* If you have any questions or concerns about the form, please contact form@gic.mx.
