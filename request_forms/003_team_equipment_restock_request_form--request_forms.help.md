# team_equipment_restock_request_form - Help Guide
## Purpose
The team equipment restock request form is used to submit a request for restocking of team equipment. This form helps the team to request the required equipment in a timely manner.

## How To Complete This Form
To complete this form, follow these steps:
1. Select the category for the request (Team, Equipment, or Restock).
2. Choose the item to be restocked (Apple, Banana, or Orange).
3. Provide a brief description of the item to be restocked.
4. Specify the quantity of the item needed.
5. Select a due date for the restocking request.
6. Choose the requester's name.
7. Provide a reason for the request.
8. If applicable, provide additional information about the request.
9. Select whether attachments are required for the request.
10. Select whether to upload attachments for the request.
11. Indicate whether contact information is needed for the request.
12. Select whether the team is involved in the request.
13. Select whether the current page is relevant to the team.
14. Select whether any other pages are relevant to the team.

## Field-by-Field Explanation

- **Team** (Team, select_multiple): Select the team that is requesting the equipment restock.
  * This field helps to identify the team that is requesting the equipment.

- **Equipment** (Equipment, select_one): Choose the type of equipment to be restocked (Apple, Banana, or Orange).
  * This field helps to specify the equipment type being requested.

- **Description** (Description, text): Briefly describe the item to be restocked.
  * This field provides a short description of the item to be restocked.

- **Quantity** (Quantity, number): Specify the quantity of the item needed.
  * This field indicates the amount of the equipment to be restocked.

- **Due Date** (Due Date, date): Select a due date for the restocking request.
  * This field helps to ensure the equipment is restocked on time.

- **Requester** (Requester, select_one): Choose the person requesting the equipment restock (Chat or Jimmy).
  * This field identifies the person submitting the request.

- **Reason** (Reason, text): Provide a reason for the request.
  * This field helps to understand the need for the equipment restock.

- **Additional Info** (Additional Info, note): Provide any additional information about the request.
  * This field allows for any additional details to be included.

- **Attachments** (Attachments, select_multiple): Select whether attachments are required for the request.
  * This field indicates whether supporting documents are needed for the request.

- **Uploads** (Uploads, select_multiple): Select whether to upload attachments for the request.
  * This field allows for uploading supporting documents.

- **Contact Info** (Contact Info, select_multiple): Indicate whether contact information is needed for the request.
  * This field helps to determine if the requester's contact information is required.

- **Team** (Team, select_multiple): Select whether the team is involved in the request.
  * This field indicates whether the team is part of the request.

- **Relevant Team** (Relevant Team, select_multiple): Select whether the current page is relevant to the team.
  * This field determines the relevance of the current page to the team.

- **Other Relevance** (Other Relevance, select_multiple): Select whether other pages are relevant to the team.
  * This field helps to determine which other pages are relevant to the team.

## Tips
- Please select the correct team and equipment type to ensure accurate restocking.
- Make sure to provide a brief and clear description of the item to be restocked.
- Specify the quantity needed and due date to facilitate timely restocking.
- Provide a valid reason for the request to help with processing.
- Upload any necessary attachments to support the request.
- Indicate whether contact information is required for the requester.
- Select whether the team is involved in the request.
