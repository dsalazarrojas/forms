# sap_sprinklr_general_request_form_2_0 - Help Guide
## Purpose
The sap_sprinklr_general_request_form_2_0 is a general request form designed for users to provide input on various aspects of their concerns.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the relevant department from the available options.
2. Choose the status of your issue.
3. Provide a date and time for reference.
4. Add any additional notes if necessary.
5. Enter your email address for contact purposes.
6. Enter your phone number for easy contact.
7. Choose a submit option.
8. Provide any comments if necessary.
9. Select the type of request you are making.
10. Choose the priority of your request.
11. Select the urgency of your request.
12. Enter any relevant tags.
13. Attach any comments if necessary.
14. Attach any files or documents if necessary.
15. Select the type of attachment.
