# Threshold Configuration Form - Help Guide
## Purpose
This form is used to configure thresholds for monitoring and alerting in your system. A threshold is a condition that triggers a notification when it is met. Thresholds can be configured for different types of conditions, such as absolute values or relative time periods. This form helps you set up custom thresholds and notification settings to suit your needs.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the **Threshold Conditions** page to define the conditions under which the threshold should be triggered.
2. Choose the **Notification Method** for the threshold from the options provided.
3. Select the **Threshold Action** to be taken when the threshold is triggered.
4. Enter the **Email Address** for notification via email.
5. Select the **Chat ID** for notification via chat.
6. Set the **Threshold Value**, **Threshold Unit**, and **Threshold Time** to define the condition.
7. Choose the **Threshold Type**, which can be **Absolute** or **Relative**.
8. Define the **Alert Level** for the threshold, which can be **Low**, **Medium**, or **High**.
9. Select the **Notification Method 2** and **Notification Method 3** for additional notification options.
10. Add any additional **Notes** for the threshold, such as a description or reminders.

## Field-by-Field Explanation
* **Threshold Conditions**: Select the conditions under which the threshold should be triggered.
* **Notification Method**: Choose how the notification should be sent, such as email or chat.
* **Threshold Action**: Select the action to take when the threshold is triggered.
* **Email Address**: Enter the email address to send notifications to.
* **Chat ID**: Enter the chat ID for chat notifications.
* **Threshold Value**: Enter a numerical value to define the threshold condition.
* **Threshold Unit**: Choose the unit of measurement for the threshold value (seconds, minutes, hours).
* **Threshold Time**: Set the time period for the threshold condition.
* **Threshold Type**: Choose whether the threshold is **Absolute** or **Relative**.
* **Alert Level**: Select the level of alertness (Low, Medium, High).
* **Notification Method 2**: Select an additional notification method.
* **Notification Method 3**: Select another additional notification method.
* **Threshold Period**: Choose the periodicity of the threshold condition (Daily, Weekly, Monthly).
* **Threshold Interval**: Choose the interval between threshold triggers (Daily, Weekly, Monthly).
* **Threshold Description**: Add a note describing the threshold condition.
* **Threshold Note**: Add a note for the threshold condition.
* **Note**: Add a general note for the threshold configuration.
* **Email Note**: Add a note for the email notification method.
* **Threshold Note 2**: Add a note for the second threshold condition.
* **Threshold Note 3**: Add a note for the third threshold condition.
* **Threshold Note 4**: Add a note for the fourth threshold condition.
* **Threshold Note 5**: Add a note for the fifth threshold condition.
