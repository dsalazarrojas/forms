# Press Table Allocation Request Form - Help Guide
## Purpose
The Press Table Allocation Request Form is designed to allow users to request the allocation of press tables for a specific event or purpose.

## How To Complete This Form
1. Select the press table allocation request form by clicking on the "Press Table Allocation Request Form" label.
2. Select the preferred table for your request by choosing from the available options on the "Press Table Request" field.
3. Select any additional table preferences by choosing from the available options on the "Press Table Preference" field.
4. Enter the name of the event or purpose for which the press table is required.
5. Select the media type for your request (e.g., video, photo, or audio).
6. Select the time of day for your request (e.g., M, T, or A).
7. Enter a valid email address that can be contacted for confirmation.
8. Enter a valid phone number that can be contacted for confirmation.
9. Add any additional comments or information about your request in the "Comment" fields.

## Field-by-Field Explanation
* **Press Table Allocation Request Form** (`page_1`, `text`, required/optional): The title of the form to be filled out.
* **Press Table Request** (`press_table_request_form_page_2`, `select_one`, required/optional): Select the press table you are requesting from the available options.
* **Press Table Preference** (`press_table_allocation_request_form_page_2`, `select_multiple`, required/optional): Select any additional tables you would like to be allocated in addition to your main request.
* **Press Name** (`press_table_allocation_request_form_page_2`, `text`, required/optional): Enter the name of the press or media personnel requesting the press table.
* **Event Name** (`press_table_allocation_request_form_page_2`, `text`, required/optional): Enter the name of the event or purpose for which the press table is required.
* **Media Type** (`press_table_allocation_request_form_page_2`, `select_one`, required/optional): Select the type of media requested (e.g., video, photo, or live stream).
* **Time** (`press_table_allocation_request_form_page_2`, `select_one`, required/optional): Select the time of day for your request (e.g., M, T, or A).
* **Email** (`press_table_allocation_request_form_page_2`, `email`, required/optional): Enter a valid email address that can be contacted for confirmation.
* **Phone Number** (`press_table_allocation_request_form_page_2`, `text`, required/optional): Enter a valid phone number that can be contacted for confirmation.
* **Comment** (`press_table_allocation_request_form_page_2`, `text`, required/optional): Add any additional comments or information about your request.

## Tips
- Make sure to fill out all required fields to ensure your request is processed correctly.
- Double-check your selections and entries for accuracy before submitting the form.
- If you have any questions or concerns, contact the event organizer or coordinator for assistance.
