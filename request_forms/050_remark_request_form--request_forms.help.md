# Remark Request Form - Help Guide
## Purpose
The Remark Request Form is used to submit a request for feedback or clarification on a remark made by an instructor on a student's work. This form is intended to ensure that students have a clear understanding of the feedback and can effectively address any issues raised by the instructor.

## How To Complete This Form

1. Fill out the form completely and accurately.
2. Enter your student name in the `student_name` field.
3. Select the type of remark that you are requesting feedback on from the `remark_type` dropdown list.
4. Enter the course section where the remark was made.
5. Enter the name(s) of the instructor(s) who made the remark.
6. Enter the name of the assignment that the remark was made on.
7. Enter the due date for the assignment, if applicable.
8. Enter the date the remark was received, if applicable.
9. Enter any comments or feedback you would like to include with your request.
10. If applicable, attach any supporting documents or files to your request.
11. Enter your email address for contact information.
12. Enter your phone number for additional contact.
13. Select the name(s) of the person responsible for resolving the remark.
14. Select the status of the remark request (optional).
15. Select the person(s) who created and modified this request (optional).

## Field-by-Field Explanation

* **Student Name** (`student_name`, text, required): Enter your name as a student.
* **Remark Type** (`remark_type`, select_one, required): Select the type of remark you are requesting feedback on.
* **Course Section** (`course_section`, text, required): Enter the course section where the remark was made.
* **Instructor Name** (`instructor_name`, select_multiple, required): Enter the name(s) of the instructor(s) who made the remark.
* **Assignment Name** (`assignment_name`, text, required): Enter the name of the assignment that the remark was made on.
* **Due Date** (`due_date`, date, optional): Enter the due date for the assignment, if applicable.
* **Received Date** (`received_date`, date, optional): Enter the date the remark was received, if applicable.
* **Status** (`status`, select_one, optional): Select the status of the remark request.
* **Remark Request Date** (`remark_request_date`, date, optional): Enter the date you are making this request, if applicable.
* **Comments** (`comments`, text, required): Enter any comments or feedback you would like to include with your request.
* **Attachment** (`attachment`, text, required): If applicable, attach any supporting documents or files to your request.
* **Email** (`email`, email, required): Enter your email address for contact information.
* **Phone** (`phone`, text, required): Enter your phone number for additional contact.
* **Remarker Name** (`remarker_name`, select_multiple, optional): Select the name(s) of the person responsible for resolving the remark.
* **Remarker Name 2** (`remarker_name2`, text, required): Enter the name of the person responsible for resolving the remark (if not already selected).
* **Remarker Name 3** (`remarker_name3`, text, required): Enter an additional name of the person responsible for resolving the remark (if not already selected).
* **Remarker Email** (`remarker_email`, email, required): Enter the email address of the person responsible for resolving the remark.
* **Remarker Phone** (`remarker_phone`, text, required): Enter the phone number of the person responsible for resolving the remark.
* **Remarker Status** (`remarker_status`, select_one, optional): Select the status of the person responsible for resolving the remark.
* **Created By** (`created_by`, select_multiple, optional): Select the person who created this request.
* **Modified By** (`modified_by`, select_multiple, optional): Select the person who modified this request.
* **Created** (`created_date`, date, optional): Enter the date this request was created.
* **Modified** (`modified_date`, date, optional): Enter the date this request was modified.
