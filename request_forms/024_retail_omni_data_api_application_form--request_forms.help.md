# retail_omni_data_api_application_form - Help Guide
## Purpose

The retail omni data API application form is for requesting access to the Retail Omni Data API. Fill out this form to submit a request for API access, which will be reviewed and approved by a designated team member.

## How To Complete This Form

To complete this form, please follow these steps:

1. Fill out the required fields, indicated by an asterisk (\*) on the form.
2. Enter your business email address for verification and communication purposes.
3. Describe your intended use case for the API.
4. Select your preferred API access type.
5. If necessary, provide additional details for review.
6. Review the form for accuracy before submission.

## Field-by-Field Explanation

* **Company Details**: Enter your company's name and other relevant details.
* **Business Email**: Enter your business email address for verification and communication purposes.
* **Intended Use Case**: Describe your company's intended use case for the API. This is a required field, as it helps us understand your company's needs.
* **API Access Type**: Select the type of API access you are requesting. This will help us determine the level of access you need.
* **Review Date**: Enter the date you would like to start reviewing the API (if applicable).
* **Review Time**: Enter the time of day you would like to start reviewing the API (if applicable).
* **Notes**: Enter any additional comments or details that would be helpful for our review.
* **API Access Request Details**: Enter any additional details you would like to provide about your API request. This is optional, but can be helpful in our review process.
* **API Access Type (Select One)**:
	+ This field is not applicable, as API Access Type is already defined as select_one in the schema.
* This selection determines the level of access you need to the Retail Omni Data API.
