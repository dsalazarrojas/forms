# Marketing Quest Form - Help Guide
## Purpose
The Marketing Quest Form is designed to collect information about the user's marketing-related needs and preferences. This form helps the marketing team understand the user's requirements for events, graphic design services, website updates, and grant requests.

## How To Complete This Form
To complete this form, follow these steps:

1. Review the form's pages and select the relevant options for each field.
2. Answer each field carefully, providing accurate and relevant information.
3. Ensure that you have read and understood the purpose of the form before submitting it.

## Field-by-Field Explanation

* **Event or Workshop (Event/Workshop)** (`select_one`, required: false): 
Select one or more options that describe the type of event or workshop you are interested in. You can choose from "Event", "Workshop", or "Other" if your option is not listed.

* **Graphic Design (Graphic, UI/UX, Web Design)** (`select_multiple`, required: false): 
Choose the graphic design services you are interested in. Select as many options as apply to you, such as "Graphic", "UI/UX", or "Web Design".

* **Website Update (Yes/No)** (`select_one`, required: false): 
Indicate whether you are interested in a website update. If yes, select "Yes". If not, select "No".

* **Grant (Grant)** (`text`, required: false): 
Use this field to describe your grant request. Provide a brief and clear explanation of the grant you are requesting, and be sure to include all relevant details.

## Tips
- Please provide accurate and relevant information for each field.
- Ensure that you have read the form's purpose and instructions before submitting it.
- If you are unsure about any field, please ask for clarification or assistance.
