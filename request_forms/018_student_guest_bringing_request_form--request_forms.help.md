# Student Guest Bringing Request Form - Help Guide

## Purpose
The Student Guest Bringing Request Form is used to request permission for a student to bring a guest to a specific event.

## How To Complete This Form

Before filling out the form, please make sure you have all the necessary information ready. The form is divided into several sections:

*   **Student Information**: This section is used to enter the student's name and ID number.
*   **Event Details**: Enter the event name, date, and time.
*   **Guest Information**: Enter the guest's name, type (e.g., student, teacher, staff, or other), and any other relevant information.
*   **Event Details (continued)**: Enter any additional event details, such as the event type and location.
*   **Request Information**: Enter any additional information, such as the request date and status.

## Field-by-Field Explanation

*   **Student Id** (`student_id`, number, required): Enter the student's ID number.
*   **name** (`name`, text, required): Enter the student's name.
*   **Date** (`date`, date, optional): Enter the event date (if applicable).
*   **Event Name** (`event_name`, text, required): Enter the name of the event.
*   **Guest Name** (`guest_name`, text, required): Enter the guest's name.
*   **Email** (`email`, email, optional): Enter the guest's email address (if applicable).
*   **Phone** (`phone`, text, required): Enter the guest's phone number.
*   **Event Type** (`event_type`, select_one, required): Select the type of event (e.g., school, college, seminar).
*   **Guest Type** (`guest_type`, select_one, required): Select the type of guest (e.g., student, teacher, staff, other).
*   **Event Details** (`event_details`, text, required): Enter any additional event details.
*   **Message** (`message`, text, optional): Enter any additional message or comments.
*   **Event Date** (`event_date`, date, optional): Enter the event date (if applicable).
*   **Event Time** (`event_time`, time, optional): Enter the event time (if applicable).
*   **School Name** (`school_name`, text, optional): Enter the school name (if applicable).
*   **School Location** (`school_location`, text, optional): Enter the school location (if applicable).
*   **Request For** (`request_for`, text, optional): Enter any additional request information.
*   **Request Date** (`request_date`, date, optional): Enter the request date.
*   **Status** (`status`, select_multiple, optional): Select the status of the request (e.g., pending, approved, rejected).
*   **Remarks** (`remarks`, text, optional): Enter any additional remarks or comments.
*   **Submit** (`submit`, text, optional): Click the submit button to complete the form.
