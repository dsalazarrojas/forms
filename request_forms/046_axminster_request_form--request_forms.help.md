# Axminster Request Form - Help Guide

## Purpose
This form is for requesting Axminster products or services for a specific project. It helps the Axminster team understand your project requirements and needs.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill out the Project Basics section with your project's basic details.
2. Provide your contact information, including your full name and email address.
3. Enter the project's name, a unique name for the project.
4. Specify the area or room where the Axminster product will be installed.
5. Provide measurements for the installation area.
6. Select the style, color, and underlay type for the Axminster product.
7. Enter a preferred installation date, if applicable.
8. Add any site access or installation notes.
9. Enter a budget estimate for the project.
10. Indicate whether you need to receive physical samples.
11. Make any additional comments or notes for the Axminster team.
12. Finally, indicate the approval status for your request.

## Field-by-Field Explanation

* **Requester Full Name** (Required: true, Type: text): Please enter your full name as the person requesting the Axminster product or service.
* **Email Address** (Required: true, Type: email): Enter your email address for communication purposes.
* **Project Name** (Required: true, Type: text): Enter a unique name for your project.
* **Room or Area for Installation** (Required: true, Type: text): Specify the specific area or room where the Axminster product will be installed.
* **Width (in Meters)** (Required: true, Type: number): Enter the width of the installation area in meters.
* **Length (in Meters)** (Required: true, Type: number): Enter the length of the installation area in meters.
* **Axminster Style/Pattern** (Required: true, Type: select_one): Select the primary style or pattern for the Axminster product.
* **Primary Color Palette** (Required: true, Type: text): Specify the primary color palette for the Axminster product (e.g. Royal Blue, Forest Green).
* **Underlay Type** (Required: true, Type: select_one): Select the underlay type based on expected foot traffic.
* **Preferred Installation Date** (Required: false, Type: date): Enter a preferred installation date, if applicable.
* **Site Access and Installation Notes** (Required: false, Type: text): Add any site access or installation notes.
* **Budget Estimate** (Required: false, Type: number): Enter a total project budget in local currency.
* **Samples Requested?** (Required: true, Type: select_one): Indicate whether you need physical samples to be sent.
* **Additional Comments** (Required: false, Type: text): Add any other information for the Axminster team.
* **Approval Status** (Required: false, Type: select_one): This field is for internal use only and should be completed by Suzanne.
