# Security Alarm Reconfiguration Request Form - Help Guide

## Purpose
This form is designed to facilitate the reconfiguration of security alarms within the organization. The purpose of this form is to gather necessary information from the requester and reviewer to facilitate a smooth and efficient reconfiguration process.

## How To Complete This Form
1. Click on the form title to begin filling out the form.
2. Fill out the form fields as instructed below.

## Field-by-Field Explanation

- **Request Form** (`request_form`): Please provide a clear and concise description of the security alarm reconfiguration request.
  - Type: Text
  - Required: Yes

- **Request Date** (`request_date`): Enter the date the request was made.
  - Type: Date
  - Required: Yes

- **Request Time** (`request_time`): Enter the time the request was made. Note: This field is optional.
  - Type: Time
  - Required: No

- **Alarm Description** (`alarm_description`): Provide a detailed description of the alarm to be reconfigured.
  - Type: Text
  - Required: Yes

- **Affected Zone** (`affected_zone`): Indicate if the alarm is affected.
  - Type: Select One
  - Required: Yes

- **Affected Zone Options** (`affected_zone_options`): Select any additional options related to the affected zone. Note: This field is optional.
  - Type: Select Multiple
  - Required: No

- **Alarm Settings** (`alarm_settings`): Enter any specific alarm settings.
  - Type: Text
  - Required: Yes

- **Alarm Type** (`alarm_type`): Choose the type of alarm.
  - Type: Select One
  - Required: Yes

- **Alarm Status** (`alarm_status`): Choose the status of the alarm.
  - Type: Select One
  - Required: Yes

- **Requester Name** (`requester_name`): Enter the name of the requester.
  - Type: Text
  - Required: Yes

- **Requester Email** (`requester_email`): Enter the email of the requester.
  - Type: Email
  - Required: Yes

- **Department** (`department`): Select the department involved in the request. Note: This field is optional.
  - Type: Select Multiple
  - Required: No

- **Team** (`team`): Select the team involved in the request. Note: This field is optional.
  - Type: Select Multiple
  - Required: No

- **Submitter Name** (`submitter_name`): Enter the name of the submitter.
  - Type: Text
  - Required: Yes

- **Submitter Email** (`submitter_email`): Enter the email of the submitter.
  - Type: Email
  - Required: Yes

- **Review Status** (`review_status`): Choose the review status.
  - Type: Select One
  - Required: Yes

- **Review Date** (`review_date`): Enter the review date. Note: This field is optional.
  - Type: Date
  - Required: No

- **Review Time** (`review_time`): Enter the review time. Note: This field is optional.
  - Type: Time
  - Required: No

- **Notes** (`notes`): Enter any additional notes. Note: This field is optional.
  - Type: Note
  - Required: No

- **Submitter Comments** (`submitter_comments`): Enter any additional comments from the submitter. Note: This field is optional.
  - Type: Text
  - Required: No

- **Reviewer Name** (`reviewer_name`): Enter the name of the reviewer.
  - Type: Text
  - Required: No

- **Reviewer Comments** (`reviewer_comments`): Enter any comments from the reviewer.
  - Type: Text
  - Required: No

- **Reviewer Name Submitter** (`submitter_name_reviewed`): Enter the name of the reviewer and submitter.
  - Type: Text
  - Required: No

- **Review Submitter Name** (`submitter_name_reviewer`): Enter the name of the submitter and reviewer.
  - Type: Text
  - Required: No

- **Review Submitter Comments** (`submitter_comments_reviewed`): Enter any comments from the reviewer and submitter.
  - Type: Text
  - Required: No
