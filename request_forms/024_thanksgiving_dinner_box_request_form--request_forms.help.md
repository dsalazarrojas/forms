# Thanksgiving Dinner Form - Help Guide
## Purpose
The form is designed to collect information about a Thanksgiving dinner event, including the date, reporter's status, contact information, and preferences for various dinner aspects.

## How To Complete This Form
To complete the form, please follow these steps:

1. **Thanksgiving Dinner Date**: Enter the date of the Thanksgiving dinner event.
2. **Reporter**: Check "Yes" if you are the reporter for this dinner event.
3. **Phone**: Enter the phone number where you can be reached.
4. **Email**: Enter your email address (optional).
5. **Name of Guests**: Enter the name of the guests attending the dinner.
6. **Special Instructions**: Provide any special instructions or requests for the dinner event (optional).
7. **Turkey**: Check "Yes" if a turkey will be served.
8. **Stuffing**: Check "Yes" if stuffing will be served.
9. **Cranberry Sauce**: Check "Yes" if cranberry sauce will be served.
10. **Pumpkin Pie**: Check "Yes" if pumpkin pie will be served.
11. **Pie Crust**: Check "Yes" if a homemade pie crust will be used.
12. **Pie Toppings**: Check "Yes" if there will be any pie toppings.
13. **Main Course**: Check "Yes" if a main course will be served.
14. **Sides**: Check "Yes" if sides will be served.
15. **Drinks**: Check "Yes" if drinks will be served.

* **Pumpkin Pie** (`pumpkin_pie`, select_multiple, optional): Check "Yes" if pumpkin pie will be served.
* **Pie Crust** (`pie_crust`, select_multiple, optional): Check "Yes" if a homemade pie crust will be used.
