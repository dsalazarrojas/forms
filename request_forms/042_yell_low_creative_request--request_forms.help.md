# Yell Low Creative Request - Help Guide
## Purpose
This form is a request form for a creative project. It is designed to collect information from clients about their project needs and requirements.

## How To Complete This Form
To complete this form, please follow these steps:

* Fill in the required fields with the requested information about your project.
* Ensure that you provide accurate and complete information to help us understand your project requirements.
* Review your submission carefully before submitting it to ensure that all required fields are filled in correctly.

## Field-by-Field Explanation
### Client Name
* **Client Name** (client_name, text, required: false): This field is for the name of the client.
* Please enter the name of the client submitting the project request.

### Project Type
* **Project Type** (project_type, select_one, required: false): This field allows you to select the type of project you are requesting.
* Please select the type of project you are requesting (e.g., Type 1, Type 2, or Type 3).

### Project Name
* **Project Name** (project_name, text, required: false): This field is for the name of the project.
* Please enter a brief name of the project.

### Project Description
* **Project Description** (project_description, text, required: false): This field is for a brief description of the project.
* Please provide a brief description of the project (e.g., the project's objective, scope, and expected outcomes).

### Contact Person
* **Contact Person** (contact_person, text, required: false): This field is for the contact person's name.
* Please enter the name of the contact person responsible for this project.

### Contact E-Mail
* **Contact E-Mail** (contact_email, email, required: false): This field is for the contact person's email address.
* Please enter the email address of the contact person.

### Contact Number
* **Contact Number** (contact_number, text, required: false): This field is for the contact person's phone number.
* Please enter the phone number of the contact person.

### Project Deadline
* **Project Deadline** (project_deadline, date, required: false): This field is for the project deadline.
* Please enter the deadline for the project (date format, e.g., YYYY-MM-DD).

### Project Location
* **Project Location** (project_location, text, required: false): This field is for the project location.
* Please enter the location where the project will take place or be executed.

### Project Notes
* **Project Notes** (project_notes, text, required: false): This field is for any additional notes about the project.
* Please enter any additional information about the project that will help us understand the project's requirements.

### Client Notes
* **Client Notes** (client_notes, text, required: false): This field is for any additional notes from the client.
* Please enter any additional information from the client that will help us understand the project's requirements.

### Creative Requirements
* **Creative Requirements** (creative_requirements, text, required: false): This field is for any creative requirements or specific needs.
* Please enter any specific creative requirements or needs for the project.

### Budget
* **Budget** (budget, text, required: false): This field is for the project budget.
* Please enter the budget for the project.

### Payment Terms
* **Payment Terms** (payment_terms, text, required: false): This field is for payment terms.
* Please enter the payment terms for the project.

### Submission Deadline
* **Submission Deadline** (submission_deadline, date, required: false): This field is for the submission deadline.
* Please enter the deadline for submitting the project proposal or final work.

## Tips
* Ensure that you provide accurate and complete information in all fields to help us understand your project requirements.
* Review your submission carefully before submitting it to ensure that all required fields are filled in correctly.
* If you have any questions or concerns, please contact us at your earliest convenience.
