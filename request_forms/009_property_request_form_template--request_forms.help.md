# Property Request Form Template - Help Guide
## Purpose
This form is designed to collect property-related information from property owners/managers or potential buyers/sellers to facilitate smooth property transactions.

## How To Complete This Form

1. Fill out the Property Request Form page (page 1).
2. Scroll down to the Additional Details page (page 2).

## Field-by-Field Explanation

* **Property Request Form** (`property_request_form_template`, Text, Required/Optional: N/A):
	+ Provide a brief description of the property you're interested in.
* **Additional Details** (`property_request_form_page_2`, Text, Required/Optional: N/A):
	+ Enter any additional information about the property that's not already mentioned in the form.
* **Additional Details 2** (`additional_details_2`, Text, Required/Optional: N/A):
	+ If there's more information to share, please type it here.

## Tips

* Be concise and clear in your responses to facilitate easy processing of your request.
* If you need help or have questions, contact the property owner/manager or seek guidance from a professional.
* Ensure you provide accurate information to avoid delays or misunderstandings.
* Double-check your details before submitting the form to avoid errors.
