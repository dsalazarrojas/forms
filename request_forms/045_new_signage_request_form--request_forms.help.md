# new_signage_request_form - Help Guide
## Purpose

The `new_signage_request_form` is used to submit requests for new signage.

## How To Complete This Form

To submit a new signage request, please fill out the following fields:

* Please make sure to provide accurate information in each field, as this will help us process your request efficiently.
* If any field is left blank, it may delay the process or lead to incorrect signage placement.

## Field-by-Field Explanation

* **request** (`request`, `text`, required/optional): Enter a brief description of your signage request, including the location, size, and type of signage.
* **signage_type** (`signage_type`, `select_multiple`, true): Select all applicable signage types (Yes/No) to indicate the type of signage you are requesting (e.g., directional, informational, etc.).
* **start_date** (`start_date`, `date`, true): Enter the date when you would like the signage to be placed or updated.
* **end_date** (`end_date`, `date`, true): Enter the date when you would like the signage to be removed or updated.
* **start_time** (`start_time`, `time`, optional): Enter the time when you would like the signage to be placed or activated.
* **end_time** (`end_time`, `time`, optional): Enter the time when you would like the signage to be removed or deactivated.
* **status** (`status`, `select_one`, true): Select the status of the signage request (Active/Inactive).
* **signage_request_details** (`signage_request_details`, `text`, optional): Enter any additional details or comments about your signage request.

## Tips

* Make sure to double-check your information for accuracy before submitting the form.
* If you have any questions or concerns about the form, please do not hesitate to contact us.
* We appreciate your cooperation in ensuring timely and accurate signage placement.
