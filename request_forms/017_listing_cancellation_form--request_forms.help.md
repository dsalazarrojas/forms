# Listing Cancellation Form - Help Guide

## Purpose
The Listing Cancellation Form is used to cancel a listing. This form helps the user to provide reasons for cancellation and other relevant details.

## How To Complete This Form
To complete the Listing Cancellation Form, follow these steps:
1. Click on the "Cancel Listing" option to open the form.
2. Provide the `listing_id` number of the listing you want to cancel.
3. Select the reason for cancellation from the `cancellation_reason` options.
4. Enter the specific `reason_for_removal` details.
5. Choose the `cancellation_date` for the cancellation.

## Field-by-Field Explanation
* **listing_cancellation**: This is the main field where you can input the listing cancellation request. It should be a short text description of the listing cancellation.
* **cancellation_reason**: Select one or more reasons for cancellation from the options. This will help us understand why the listing is being cancelled.
* **listing_id**: Enter the unique number of the listing you want to cancel.
* **reason_for_removal**: Provide a detailed explanation for the cancellation.
* **cancellation_date**: Enter the date when the listing will be cancelled.
