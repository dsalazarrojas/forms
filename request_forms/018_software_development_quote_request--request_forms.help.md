# Software Development Quote Request - Help Guide
## Purpose
This form is used to request a software development quote for a new project. It captures essential information about the project, which will be used by the development team to provide a accurate quote.

## How To Complete This Form
1. Fill out all the required fields (indicated by an asterisk \*).
2. For each field, provide as much information as possible.
3. Review and submit the form when finished.

## Field-by-Field Explanation

* **Company Name** (`company_name`, text, false): Enter your company name or the name of your organization.
* **Project Name** (`project_name`, text, false): Enter a brief title for your project.
* **Description** (`description`, text, false): Provide a short description of the project.
* **Team Name** (`team_name`, text, false): Enter the name of the team responsible for the project.
* **Start Date** (`start_date`, date, false): Enter the start date of the project.
* **End Date** (`end_date`, date, false): Enter the end date of the project.
* **Project Type** (`project_type`, select_multiple, false): Select all types of projects that apply to your project (e.g., web development, mobile app, etc.).
* **Project Status** (`project_status`, select_one, false): Select the current status of your project (e.g., Active, Inactive).
* **Team Lead** (`team_lead`, text, false): Enter the name of the team lead responsible for the project.
* **Project Manager** (`project_manager`, text, false): Enter the name of the project manager responsible for the project.
* **Project Owner** (`project_owner`, text, false): Enter the name of the project owner responsible for the project.
* **Email** (`email`, email, false): Enter your email address.
* **Phone** (`phone`, text, false): Enter your phone number.
* **Website** (`website`, text, false): Enter the website of your organization.
* **Budget** (`budget`, number, false): Enter the budget for the project.
* **Location** (`location`, text, false): Enter the location of the project (e.g., city, country).
* **Timezone** (`timezone`, select_one, false): Select the timezone of your project location.
* **Language** (`language`, select_one, false): Select the language of your project (e.g., English, Spanish, etc.).
* **Project Lead** (`project_lead`, text, false): Enter the name of the project lead.
* **Project Manager Name** (`project_manager_name`, text, false): Enter the name of the project manager.
* **Project Manager Email** (`project_manager_email`, email, false): Enter the email of the project manager.
* **Project Manager Phone** (`project_manager_phone`, text, false): Enter the phone number of the project manager.
* **Project Manager Website** (`project_manager_weblink`, text, false): Enter the website of the project manager.
* **Project Description** (`project_description`, text, false): Enter a detailed description of the project.
* **Project Requirements** (`project_requirements`, text, false): Enter the requirements of the project.

Note: Some fields are not required, but providing as much information as possible will help the development team to provide an accurate quote.
