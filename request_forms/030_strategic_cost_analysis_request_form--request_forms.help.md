# Strategic Cost Analysis Request Form - Help Guide
## Purpose
The Strategic Cost Analysis Request Form is a tool used to collect information about strategic projects from project teams. This form helps us understand project scope, status, and resource requirements, allowing us to focus on initiatives with the greatest impact.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter a brief description of your project in the **Project Description** field.
2. Select the current **Project Status** (Active or Inactive) to help us understand the project's current state.
3. Enter the start and end dates of your project in the **Project Start Date** and **Project End Date** fields, respectively.
4. Enter the name of your **Project Manager**, if applicable.
5. Optionally, add any additional notes or context about your project in the **Project Status Note** field.
6. Enter a brief description of your request or any additional comments in the **Form Request Note** field.

## Field-by-Field Explanation

* **Form Request** (`form_request`, text, optional): Enter a brief description of your request for submitting this form.
* **Project Name** (`project_name`, text, optional): Enter the name of your project.
* **Project Description** (`project_description`, text, optional): Enter a brief description of your project.
* **Budget** (`budget`, text, optional): If applicable, enter the budget associated with your project.
* **Project Status** (`project_status`, select_one, optional): Select the current status of your project (Active or Inactive).
* **Project Start Date** (`project_start_date`, date, optional): Enter the start date of your project.
* **Project End Date** (`project_end_date`, date, optional): Enter the end date of your project.
* **Project Manager** (`project_manager`, text, optional): Enter the name of your project manager, if applicable.
* **Project Status Note** (`project_status_note`, note, optional): Add any additional notes or context about your project status.
* **Form Request Note** (`form_request_note`, note, optional): Enter a brief description of your request or any additional comments.

## Tips
* Please ensure that you have not submitted a request for the same project recently.
* If you are unsure about any of the fields, contact your project manager or project team for clarification.
* Ensure that your project has a clear business case and is active before submitting this form.
* Be concise and clear in your submissions to help us better understand your project requirements.
