# Document Suggestion Removal Request Form - Help Guide
## Purpose
This form is used to request removal of a document that was previously suggested for inclusion in the collection. The form is intended for use by staff members who want to remove a document from the collection due to a specific reason.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter a brief description of the document in the **Form Description** field.
2. In the **What is the Document** field, enter the title of the document you want to remove.
3. In the **Who Suggested It** field, enter the name or username of the person who suggested the document.
4. In the **When Was It Suggested** field, select the date when the document was suggested.
5. In the **Reason for Removal** field, select the reason you want to provide for the removal.
6. In the **Type of Document** field, select all the types of documents that the removed document belongs to.
7. In the **Review Status** field, select the current status of the document.

## Field-by-Field Explanation
* **Form Description** (1, text, optional): Enter a brief description of the document to be removed.
* **What is the Document** (2, text, optional): Enter the title of the document you want to remove.
* **Who Suggested It** (3, text, optional): Enter the name or username of the person who suggested the document.
* **When Was It Suggested** (4, date, optional): Select the date when the document was suggested.
* **Reason for Removal** (5, select_one, optional): Select the reason for removal from the options provided.
* **Type of Document** (6, select_multiple, optional): Select all the types of documents that the removed document belongs to.
* **Review Status** (7, select_one, optional): Select the current status of the document.
