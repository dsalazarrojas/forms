# New Product Category Approval Request Form - Help Guide
## Purpose
The New Product Category Approval Request Form is a form used to request the approval of a new product category. This form is to be filled out by authorized personnel to propose a new category for approval. 

## How To Complete This Form
To fill out this form, follow these steps:

1. Enter the category name in the `Category Name` field.
2. Enter the product name in the `Product Name` field.
3. Write a brief description of the category in the `Category Description` field.
4. Enter the name of the person requesting the category in the `Requestor Name` field.
5. Enter the email of the person requesting the category in the `Requestor Email` field.
6. Enter the phone number of the person requesting the category in the `Requestor Phone` field.
7. Select the date the request was made in the `Date` field.

## Field-by-Field Explanation
### Category Name (Category Name)
* **Category Name**: This is the name of the new product category being requested.
*   Type: text
*   Required: No

### Product Name (Product Name)
* **Product Name**: This is the name of the product associated with the new category.
*   Type: text
*   Required: No

### Category Description (Category Description)
* **Category Description**: This is a brief description of the new category.
*   Type: text
*   Required: No

### Requestor Name (Requestor Name)
* **Requestor Name**: The name of the person making this request.
*   Type: text
*   Required: No

### Requestor Email (Requestor Email)
* **Requestor Email**: The email address of the person making this request.
*   Type: email
*   Required: No

### Requestor Phone (Requestor Phone)
* **Requestor Phone**: The phone number of the person making this request.
*   Type: text
*   Required: No

### Date (Date)
* **Date**: The date this request was made.
*   Type: date
*   Required: No
