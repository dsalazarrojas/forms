# Game Developer Asset Support Request Form - Help Guide
## Purpose
The Game Developer Asset Support Request Form is a tool for game developers to report issues with assets that are not functioning as expected. If you're experiencing problems with a specific asset, please fill out this form to get our support team's assistance.

## How To Complete This Form
To effectively complete this form, please make sure to:

*   Select the game developer whose asset you're experiencing the issue with
*   Choose the type of asset that's not functioning as expected
*   Describe the issue you're experiencing with the asset
*   Provide the location where the asset can be accessed or found
*   If relevant, mention the name of the game associated with the asset
*   Select the type of issue you're facing with the asset
*   If necessary, provide the URL of the asset

## Field-by-Field Explanation
*   **Game Developer** (`game_developer`, select_one, required): Choose the game developer whose asset you're experiencing the issue with.
*   **Asset Type** (`asset_type`, select_one, required): Select the type of asset that's not functioning as expected.
*   **Issue Description** (`issue_description`, text, required): Describe the issue you're experiencing with the asset in detail.
*   **Asset Location** (`asset_location`, text, required): Provide the location where the asset can be accessed or found.
*   **Game Name** (`game_name`, text, required): If applicable, please mention the name of the game associated with the asset.
*   **Issue Type** (`issue_type`, select_one, required): Select the type of issue you're facing with the asset.
*   **Asset URL** (`asset_url`, text, optional): If necessary, provide the URL of the asset.
