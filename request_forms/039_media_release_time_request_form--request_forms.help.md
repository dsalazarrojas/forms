# media-release-time-request-form - Help Guide
## Purpose
The Media Release Time Request Form is a form used to request media releases or permissions for various purposes such as filming, interviewing, or photography. It is used to gather information from users who want to request media releases for their time and media.

## How To Complete This Form
To complete this form, follow these steps:
1. Fill in the required fields:
	* Media Release Type (optional but recommended)
	* Request Date (format: dd/mm/yyyy)
	* Request Start Time (format: 24-hour clock, e.g., 14:00)
	* Request End Time (format: 24-hour clock, e.g., 16:00)
	* Request Duration (in hours and minutes, e.g., 2h 30m)
	* Media Release Locations (e.g., home, work, public place)
	* Contact Name (first and last name)
	* Contact Email (format: name@domain.com)
	* Contact Phone (format: E. 123-456-7890)
2. Select the assigned tool that will be used to manage the request (optional but recommended)
3. Add any additional details about the request in the Submission Description field

## Field-by-Field Explanation
* **Media Release Type**:
	+ (Photography, Filming, Interview)
	* Select the type of media release you are requesting.
* **Request Date**:
	+ Date (format: dd/mm/yyyy)
	* Enter the date you are requesting the media release for.
* **Request Start Time**:
	+ Time (format: 24-hour clock, e.g., 14:00)
	* Enter the start time of your request.
* **Request End Time**:
	+ Time (format: 24-hour clock, e.g., 16:00)
	* Enter the end time of your request.
* **Request Duration**:
	+ (Number, e.g., 2 hours 30 minutes)
	* Enter the duration of your request.
* **Media Release Locations**:
	+ (Text, e.g., home, work, public place)
	* Enter the location where the media release will take place.
* **Contact Name**:
	+ (First and last name)
	* Enter your name as the contact person.
* **Contact Email**:
	+ (Format: name@domain.com)
	* Enter your email address as the contact person.
* **Contact Phone**:
	+ (Format: E. 123-456-7890)
	* Enter your phone number as the contact person.
* **Assigned Tool**:
	+ (Select One, e.g., chatjimmy, another-tool, default-tool)
	* Select the tool that will be used to manage your request.
* **Submission Description**:
	+ (Text)
	* Add any additional details about your request.
