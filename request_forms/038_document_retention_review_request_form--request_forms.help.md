# Document Retention Review Request Form - Help Guide
## Purpose
The Document Retention Review Request Form is used to request a review of documents that are subject to retention policies. This form is typically used by individuals who need to review documents for their own use or for others in their organization.

## How To Complete This Form

To complete this form, please follow these steps:

1. Select the type of document you are requesting to be reviewed.
2. Enter the location of the document.
3. If necessary, provide a reason for requesting the review.
4. Enter the date you would like the document to be reviewed by.
5. Enter any additional comments or notes related to the document.
6. Enter the ID of the person submitting the request.
7. Enter the ID of the person reviewing the document.
8. Select the status of the review (Pending, Approved, or Denied).

## Field-by-Field Explanation

* **Document Type** (`document_type`, select_one, required): Select the type of document you are requesting to be reviewed. This field helps the reviewer understand what kind of document is being requested.
* **Document Location** (`document_location`, text, optional): Enter the location of the document, such as a file folder or database where it can be found.
* **Reason For Requesting Review** (`reason_for_requesting_review`, text, optional): If you are requesting a review for a specific reason, enter it here. This can be helpful for the reviewer to understand the context of the request.
* **Review Date** (`review_date`, date, required): Enter the date you would like the document to be reviewed by. This ensures that the review happens on the desired date.
* **Comments** (`comments`, text, optional): Provide any additional comments or notes related to the document you are requesting.
* **Submitter ID** (`submitter_id`, text, required): Enter the ID of the person submitting the request.
* **Reviewer ID** (`reviewer_id`, text, required): Enter the ID of the person reviewing the document.
* **Review Status** (`review_status`, select_one, required): Select the status of the review. Options include Pending, Approved, and Denied. 

## Tips

* Make sure to fill out the form accurately and completely.
* Ensure that you are requesting a review of a document that is subject to retention policies.
* If the document has already been reviewed or is in an ongoing review process, do not complete this form.
* If you need assistance with completing the form, contact your local support team.
