# pdf_to_word_conversion_request - Help Guide
## Purpose
This form is used for requesting the conversion of a PDF file to Word document format.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the form completely and accurately.
2. Click on the "Submit" button to send the form.

## Field-by-Field Explanation

* **Client Details** (`client_details`, text, optional): This field is used to collect information about the client who is requesting the conversion. Please provide a brief description of the client and their needs.
* **PDF to Upload** (`pdf_to_upload`, text, optional): In this field, please upload the PDF file that you would like to convert.
* **File Type** (`file_type`, select_one, required): Select the type of file you would like to convert. The options are:
	+ Text
	+ Image
	+ PDF
* **Conversion Preset** (`conversion_preset`, select_one, required): Choose a conversion preset that suits your needs:
	+ Standard
	+ Premium
	+ Express
* **Conversion Options** (`conversion_options`, text, optional): If you have any specific options or instructions for the conversion, please provide them here.
* **Turnaround Time** (`turnaround_time`, select_one, required): Select the turnaround time for the conversion:
	+ 1 hour
	+ 2 hours
	+ 4 hours
	+ 8 hours
	+ 12 hours
	+ 24 hours
* **Notes** (`notes`, note, optional): Add any special instructions or comments for the conversion.
* **Email** (`email`, email, optional): Provide the email address of the client.
* **Phone** (`phone`, text, optional): Provide the phone number of the client.
* **Upload PDF** (`upload_pdf`, text, optional): In this field, you can upload the PDF file again if you want.
* **Submit** (`submit`, text, optional): Click this button to submit the form and send the conversion request.

## Tips

* Please make sure to fill out all required fields correctly before submitting the form.
* Make sure to provide accurate and complete information to ensure that the conversion request is processed correctly.
* If you have any questions or concerns, please contact the support team.
