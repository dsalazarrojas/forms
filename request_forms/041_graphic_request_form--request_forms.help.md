# Graphic Request Form - Help Guide
## Purpose
This form is designed to help users request access to graphics for their projects. Please use this form to ensure that the requested graphics are relevant to your work.

## How To Complete This Form
1. Please select the **Category** for your graphic request.
   - If your request is related to a **Request Form**, choose this option.
   - Otherwise, choose **Other**.
2. Provide a **Description** of the graphic you are requesting.
   - Please be as specific as possible about what you need.
3. Check if a **Tool** is assigned to you for this graphic.
   - If yes, you will be notified when the graphic is ready.
4. Enter a **Form ID** for your request.
   - This will help us track your request.
5. Check if you want the graphic output in a **Chat**.
   - This will notify your team when the graphic is ready.
6. Choose if you want to receive a chat notification from **Jimmy**.
   - This will ensure Jimmy gets in touch with you.
7. Choose if you want to receive a chat notification from **John**.
   - This will ensure John gets in touch with you.

## Field-by-Field Explanation

* **Category**: Select the category that best describes your graphic request. This will help us route your request to the correct team.
* **Description**: Please provide a clear and concise description of the graphic you are asking for. This will ensure that we create the right graphic for you.
* **Tool**: If a tool is assigned to you for this graphic, we'll notify you when it's ready.
* **Form ID**: Enter a unique ID for your graphic request. This will help us track your request.
* **Output File**: This field is not currently used. Please ignore it.
* **Assigned**: If you're assigned to the graphic, we will let you know when it's ready.
* **Jimmy**: Choose if you want to receive a chat notification from Jimmy when the graphic is ready.
* **John**: Choose if you want to receive a chat notification from John when the graphic is ready.
* **Form ID**: Please enter a unique ID for your graphic request. This will help us track your request.
* **Assigned to**: If you're assigned to the graphic, we will let you know when it's ready.
