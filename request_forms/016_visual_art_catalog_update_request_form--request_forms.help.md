# visual_art_catalog_update_request_form - Help Guide
## Purpose
The visual art catalog update request form is used to add or modify metadata about artworks in the visual art catalog. Use this form to ensure that the artwork information is accurate and up-to-date.

## How To Complete This Form
1. Fill out the form with the necessary information about the artwork.
2. Select the update type from the "Update Type" field.
3. Enter the artwork's title, details, artist name, description, image, and video information as needed.
4. Select the assigned tool and creator(s) responsible for the artwork.
5. Enter the creation date and time.
6. Select the last update details.
7. Review your submission and click "Submit" to save your changes.

## Field-by-Field Explanation
* **Artwork Title**: The title of the artwork. Enter a brief and descriptive title.
* **Update Type**: Choose the type of update you are making (e.g., "Add new artwork", "Update existing artwork", etc.).
* **Artwork Details**: Provide additional details about the artwork, such as its medium, size, and location.
* **Artist Name**: The name of the artist who created the artwork.
* **Artwork Description**: A descriptive summary of the artwork.
* **Artwork Image**: The URL or reference of the artwork's image.
* **Artwork Video**: The URL or reference of the artwork's video.
* **Assigned Tool**: The tool or equipment used to create the artwork.
* **Created By**: Select the person(s) responsible for creating the artwork.
* **Created Date**: The date the artwork was created.
* **Created Time**: The time the artwork was created.
* **Updated By**: Select the person(s) responsible for updating the artwork.
* **Updated Date**: The date the artwork was last updated.
* **Updated Time**: The time the artwork was last updated.
* **Submit**: Click this button to save your changes and update the artwork's metadata.

## Tips
* Make sure to fill out all required fields to ensure accurate and up-to-date information.
* If you are adding a new artwork, make sure to check if an artwork with the same title already exists in the catalog.
* If you are updating an existing artwork, make sure to select the correct update type and update details accurately.
