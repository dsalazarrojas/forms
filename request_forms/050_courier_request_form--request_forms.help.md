# Courier Request Form - Help Guide
## Purpose
This form is used to collect information for a courier request, allowing you to submit a request for courier services.

## How To Complete This Form
To complete this form, follow the steps below:

1. Enter your business user information in the "Business User" field.
2. Select the delivery type by choosing "Yes" or "No".
3. Provide the delivery date in the format MM/DD/YYYY.
4. If applicable, provide the courier service information in the "Courier Service" field.

## Field-by-Field Explanation
* **Business User** (`Business User`, text, optional): Enter your business user information in this field.
* **Delivery Type** (`Delivery Type`, select_one, required): This field allows you to select whether a delivery is requested. Choose "Yes" if you need a courier to make a delivery, or "No" otherwise.
* **Delivery Date** (`Delivery Date`, date, required): Enter the date for the delivery in the format MM/DD/YYYY.
* **Courier Service** (`Courier Service`, text, optional): If you have a preferred courier service, you can provide its information in this field.

## Tips
- Make sure to fill out all required fields (Delivery Type and Delivery Date).
- If you're unsure about any of the fields, feel free to ask for clarification.
- The form will be reviewed and responded to promptly once submitted.
