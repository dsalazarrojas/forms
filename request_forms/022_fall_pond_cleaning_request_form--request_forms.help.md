# Fall Pond Cleaning Request Form - Help Guide
## Purpose
The Fall Pond Cleaning Request Form is used to request pond cleaning services for fall ponds.

## How To Complete This Form
To complete this form, follow these steps:
1. Please fill in your name and contact information in the corresponding fields.
2. Choose your contact method, either "Yes" or "No", depending on your preference.
3. Select all the services that apply to the pond cleaning you require.
4. Indicate the size of the pond you are requesting to be cleaned.
5. Specify the type of pond you are requesting to be cleaned.
6. Enter the location of the pond.
7. Choose a date for the cleaning to take place.
8. If desired, enter a specific time for the cleaning.
9. If you have any additional comments or requests, please enter them in the "Additional Comments" field.
10. Enter your email address so we can contact you about the cleaning schedule.

## Field-by-Field Explanation
* **Homeowner**: Enter your name so we can identify you for the cleaning request.
* **Contact Method**: Select "Yes" if you would like to be contacted by phone or email about the cleaning schedule, or "No" if you don't want to be contacted.
* **Services**: Select all the services that apply to the cleaning you require. Examples include:
	+ Cleaning the pond and surrounding area
	+ Pumping out waste
	+ Algae control
	+ Other (please specify in the "Additional Comments" field)
* **Pond Size**: Enter the size of the pond in square feet.
* **Pond Type**: Select "small" for small ponds or "large" for larger ponds.
* **Pond Location**: Enter the location of the pond, including the address or a description of the area.
* **Date Requested**: Choose a date for the cleaning to take place. Please note that we will do our best to accommodate your requested date, but availability may be limited.
* **Time Requested**: If desired, enter a specific time for the cleaning to take place.
* **Additional Comments**: If you have any additional requests or comments, please enter them here. This is also where you can specify any custom services not listed under "Services".
* **Email**: Enter your email address so we can contact you about the cleaning schedule.
* **Phone**: Enter your phone number so we can contact you about the cleaning schedule.
