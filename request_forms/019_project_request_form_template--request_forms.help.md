# Project Request Form Template - Help Guide
## Purpose
This form is designed to collect information about projects from users.

## How To Complete This Form
To complete this form, follow these steps:
1. Fill in the **Project Name** field with the name of the project.
2. Enter a brief description of the project in the **Project Description** field.
3. Select the **Request Date** when the project was requested.
4. Choose the current **Status** of the project from the dropdown list.
5. Select the **Project Status** of the project from the dropdown list.
6. Select the **Priority** of the project from the dropdown list.
7. Enter your **User Email** to be contacted for any follow-up questions.
8. Enter the **Project Requester** who submitted the project request.
9. Enter the **Project Manager** who is handling the project.
10. Choose the **Request Type** of the project from the dropdown list.
11. Enter any **User Input** related to the project.

## Field-by-Field Explanation
* **Project Name** (`project_name`, text, required/optional): Enter the name of the project.
* **Request Date** (`request_date`, date, required/optional): Enter the date when the project was requested.
* **Status** (`status`, select_multiple, required/optional): Choose the status of the project from the dropdown list (In Progress, Completed, Cancelled, Pending).
* **Project Status** (`project_status`, select_one, required/optional): Choose the current status of the project from the dropdown list (Open, Closed).
* **Priority** (`priority`, select_one, required/optional): Choose the priority of the project from the dropdown list (High, Medium, Low).
* **User Email** (`user_email`, email, required/optional): Enter your email to be contacted for follow-up questions.
* **Project Requester** (`project_requester`, text, required/optional): Enter the name of the person who submitted the project request.
* **Project Manager** (`project_manager`, text, required/optional): Enter the name of the person who is handling the project.
* **Request Type** (`request_type`, select_multiple, required/optional): Choose the type of project from the dropdown list (Type A, Type B, Type C).
* **Project Description** (`project_description`, text, required/optional): Enter a brief description of the project.
* **User Input** (`user_input`, text, required/optional): Enter any relevant information about the project.

## Tips
* Be accurate when entering project details to ensure that the project information is up-to-date and relevant.
* Review the form carefully before submitting to avoid mistakes.
