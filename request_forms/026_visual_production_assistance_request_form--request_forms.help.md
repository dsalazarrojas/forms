# Visual Production Assistance Request Form - Help Guide
## Purpose
This form is designed to gather information from users to facilitate production requests. Please use this guide to ensure you complete the form correctly and efficiently.

## How To Complete This Form
To complete this form, follow these steps:

1. Select "Yes" or "No" from the dropdown menu to indicate if you are requesting production support from the marketing team.
2. Enter the name of the agency or organization involved in the project, if applicable.
3. Provide a detailed description of the project, including any specific requirements or constraints.
4. Specify the production requirements for the project, including any specific deadlines or time-sensitive deliverables.
5. Enter the budget for the project, if applicable.
6. Enter your contact email address and phone number so we can reach out to you with updates or follow-ups.
7. If you have any additional comments or files related to the project, please include them here.
8. Please select "Yes" or "No" to indicate if you are requesting production assistant for this project.
9. Finally, enter your client's contact details, if applicable.

## Field-by-Field Explanation
### 1. Marketing Team
• **Marketing Team** (Select multiple options): 
  Select "Yes" if the production team will be involved in this project, and "No" otherwise.

### 2. Agency Name
• **Agency Name** (Text): Enter the name of the agency or organization involved in the project.

### 3. Project Details
• **Project Details** (Note): Provide a detailed description of the project, including any specific requirements or constraints.

### 4. Production Requirements
• **Production Requirements** (Text): Specify the production requirements for the project, including any specific deadlines or time-sensitive deliverables.

### 5. Deadline Date
• **Deadline Date** (Date): Enter the deadline date for the project.

### 6. Deadline Time
• **Deadline Time** (Time): Enter the deadline time for the project.

### 7. Budget
• **Budget** (Number): Enter the budget for the project.

### 8. Contact Details
• **Contact Details** (Text): Enter your email address and phone number so we can reach out to you with updates or follow-ups.

### 9. Additional Comments
• **Additional Comments** (Text): Include any additional comments or files related to the project.

### 10. Email
• **Email** (Email): Enter your contact email address.

### 11. Phone Number
• **Phone Number** (Text): Enter your contact phone number.

### 12. File Upload
• **File Upload** (Text): Please upload any relevant files related to the project.

### 13. Assistant
• **Assistant** (Select one): Select "Yes" if you are requesting production assistant, and "No" otherwise.

### 14. Client Details
• **Client Details** (Text): Enter your client's contact details, if applicable.

## Tips

* Be as detailed and descriptive as possible when filling out the form, especially when providing project details and production requirements.
* Ensure you are not duplicating efforts by checking if a similar project has already been requested.
* Use this form for new requests only.
* If you need more information or clarification on any of the fields, contact us directly.
