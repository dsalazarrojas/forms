# it_laptop_order_form - Help Guide
## Purpose
This form is designed to collect information about a laptop purchase request from a user.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill in the "User Input" field with your name and contact information.
2. Select the desired "Laptop Model" and "Laptop Color".
3. Enter the "Purchase Date" when you would like to purchase the laptop.
4. If applicable, enter the "Order Reason" and "Laptop Price" fields.
5. Enter the "Laptop Quantity" if you are requesting multiple laptops.
6. Enter your "Contact Email" and "Contact Phone" for communication purposes.
7. Select the current "Laptop Status" (Active or Inactive).
8. Select the "Order Type" (Yes or No).
9. Select the "Department" (Yes or No) if applicable.
10. Select the "Assigned Tool" (Yes or No) if applicable.
11. Select the "Submitted By" (Yes or No) if applicable.
12. Select the "Category" (Yes or No) if applicable.
13. Enter the "Description" of the laptop purchase.

## Field-by-Field Explanation

* **User Input** (user_input, text, required/optional): Enter your name and contact information.
* **Laptop Model** (laptop_model, select_one, required/optional): Select the type of laptop you wish to purchase.
* **Laptop Color** (laptop_color, select_multiple, required/optional): Select the desired color of the laptop.
* **Purchase Date** (purchase_date, date, required/optional): Enter the date you would like to purchase the laptop.
* **Order Reason** (order_reason, text, required/optional): Enter any additional information about your order.
* **Laptop Price** (laptop_price, number, required/optional): Enter the price of the laptop.
* **Laptop Quantity** (laptop_quantity, number, required/optional): Enter the number of laptops you are ordering.
* **Contact Email** (contact_email, email, required/optional): Enter your email address for communication purposes.
* **Contact Phone** (contact_phone, text, required/optional): Enter your phone number for communication purposes.
* **Laptop Status** (laptop_status, select_one, required/optional): Select the current status of the laptop (Active or Inactive).
* **Order Type** (order_type, select_multiple, required/optional): Select the type of order (Yes or No).
* **Department** (department, select_multiple, required/optional): Select the department (Yes or No) if applicable.
* **Assigned Tool** (assigned_tool, select_multiple, required/optional): Select the assigned tool (Yes or No) if applicable.
* **Submitted By** (submitted_by, select_one, required/optional): Select the submitted by (Yes or No) if applicable.
* **Submitted Date** (submitted_date, date, required/optional): Not applicable.
* **Submitted Time** (submitted_time, time, required/optional): Not applicable.
* **Form ID** (form_id, text, required/optional): Not applicable.
* **Assigned To** (assigned_to, select_one, required/optional): Select the assigned to (Yes or No).
* **Category** (category, select_multiple, required/optional): Select the category (Yes or No) if applicable.
* **Description** (description, text, required/optional): Enter a description of the laptop purchase.
