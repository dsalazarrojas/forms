# Hearing Request Submission - Help Guide
## Purpose
The Hearing Request Submission form is designed to collect information about a hearing request. This form is used to gather details about the requestor, the hearing date, and the start and end times.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill in the required information in the corresponding fields.
2. Ensure that you fill in all the required fields (marked as "required" in the form).
3. Review your submission before submitting it.

## Field-by-Field Explanation
* **Hearing Request Submission Form (Text Field)**: This is the main field for entering the hearing request details. Please type in the relevant information in this field.
* **Requestor (Text Field)**: Enter the name of the person or entity requesting the hearing.
* **Requestor Email (Email Field)**: Enter the email address of the requestor.
* **Hearing Date (Date Field)**: Select the date of the hearing from the calendar picker or enter it manually.
* **Start Time (Time Field)**: Select the start time of the hearing from the time picker or enter it manually.
* **End Time (Time Field)**: Select the end time of the hearing from the time picker or enter it manually.

## Tips
- Make sure to enter accurate and complete information in all the fields.
- Use the calendar and time pickers to enter dates and times accurately.
- Review your submission carefully before submitting it to ensure it is complete and accurate.
- If you have any doubts or questions, please contact form@gic.mx.
