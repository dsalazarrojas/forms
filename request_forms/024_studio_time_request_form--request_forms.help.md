# Studio Time Request Form - Help Guide
## Purpose
The Studio Time Request Form is a tool used to request a specific time slot in the studio. It is intended for users who need to book a time slot for a project or meeting and want to provide necessary information for the studio to process the request.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill out the form with the required information.
2. Make sure to provide accurate information in each field.
3. Review and submit the form once complete.

## Field-by-Field Explanation
* **Start Date** (`start_date`, date, required: false): This field is where you enter the date you want to start your studio time. Please enter the date in the correct format (YYYY-MM-DD).
* **Start Time** (`start_time`, time, required: false): This field is where you enter the time you want to start your studio time. Please enter the time in the 12-hour format (HH:MM AM/PM).
* **End Date** (`end_date`, date, required: false): This field is where you enter the date you want to end your studio time. Please enter the date in the correct format (YYYY-MM-DD).
* **End Time** (`end_time`, time, required: false): This field is where you enter the time you want to end your studio time. Please enter the time in the 12-hour format (HH:MM AM/PM).
* **User** (`user`, text, required: false): This field is where you enter your name or the name of the person requesting the studio time.
* **Studio** (`studio`, text, required: false): This field is where you can add any additional information about the studio or equipment required.
* **Notes** (`notes`, note, required: false): This field is where you can add any additional notes or comments about your request.

## Tips
* Make sure to provide accurate and complete information in each field to ensure your request is processed correctly.
* If you need to book multiple time slots, you can fill out the form multiple times, but be aware that your request may be rejected if it's not approved in a previous submission.
* If you have any issues or concerns, please contact form@gic.mx.
