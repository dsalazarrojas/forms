# Tool Movement Form - Help Guide
## Purpose
The Tool Movement Form is used to collect and track the movement of tools within a facility or system. 

## How To Complete This Form
- Carefully read the form instructions and ensure only one form is completed for each tool movement event.
- Answer all questions accurately and truthfully.
- Fill out the form in its entirety before submitting.

## Field-by-Field Explanation
- **Tool Moved From** (`tool_moved_from`, Select One, Not Required): 
  This field allows you to select whether the tool was moved from within the facility or from outside the facility.
  - 'Yes' indicates that the tool was moved from within the facility.
  - 'No' indicates that the tool was moved from outside the facility.

- **Moved To** (`moved_to`, Select One, Not Required): 
  This field is used to select whether the tool was moved to a different location within the facility or outside the facility.
  - 'Yes' indicates that the tool was moved to a different location within the facility.
  - 'No' indicates that the tool was not moved to a different location.

- **Moved By** (`moved_by`, Select One, Not Required): 
  This field is used to select whether a team member or a machine/machine was used to move the tool.
  - 'Yes' indicates that a team member was used to move the tool.
  - 'No' indicates that a machine/machine was used to move the tool.

- **Tool Name** (`tool_name`, Text, Not Required): 
  This field allows you to enter the name of the tool that was moved.

- **Moved Date** (`moved_date`, Date, Not Required): 
  This field is used to input the date on which the tool was moved.

- **Moved Time** (`moved_time`, Time, Not Required): 
  This field is used to input the time at which the tool was moved.

- **Moved To Location** (`moved_to_location`, Text, Not Required): 
  This field allows you to enter the location to which the tool was moved.

- **Assigned To** (`assigned_to`, Select One, Not Required): 
  This field is used to select whether the tool was assigned to a team member or not.
  - 'Yes' indicates that the tool was assigned to a team member.
  - 'No' indicates that the tool was not assigned to a team member.

- **Moved By Tool Type** (`moved_by_tool_type`, Select One, Not Required): 
  This field is used to select whether the tool was moved using a specific type of equipment/machine or not.
  - 'Yes' indicates that the tool was moved using a specific type of equipment/machine.
  - 'No' indicates that the tool was not moved using a specific type of equipment/machine.

- **Moved By User** (`moved_by_user`, Select One, Not Required): 
  This field is used to select whether a specific user was used to move the tool.
  - 'Yes' indicates that a specific user was used to move the tool.
  - 'No' indicates that no specific user was used to move the tool.

- **Reason For Movement** (`reason_for_movement`, Text, Not Required): 
  This field allows you to enter the reason for the tool movement, providing valuable context for the movement event.

Please note that fields marked 'Not Required' may be filled out on a voluntary basis, but are not mandatory fields for completing the form.
