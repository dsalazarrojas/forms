# Property Maintenance Request - Help Guide
## Purpose
This form is used to submit a property maintenance request to the facilities team for assistance with various property-related issues.

## How To Complete This Form
To complete this form, follow these steps:
1. Ensure you have not recently submitted a similar request for the same property.
2. Check the facilities team's work order system for any outstanding requests to avoid duplication.
3. Fill in the required fields as described in the next section.

## Field-by-Field Explanation
* **Maintenance Request** (<code>maintenance_request</code>, text, required/optional): A brief description of the issue you are experiencing with the property.
* **Property Details** (<code>property_details</code>, text, required/optional): Provide a detailed description of the property, including its address.
* **Priority** (<code>priority</code>, select_one, optional): Choose the priority level for the request:
	+ High: Urgent attention required
	+ Medium: Medium attention required, but not urgent
	+ Low: Low attention required, can wait
* **Description** (<code>description</code>, text, required/optional): A detailed description of the maintenance issue, including any relevant details.
* **Date** (<code>date</code>, date, required/optional): The date when the issue was first noticed.
* **Time** (<code>time</code>, time, required/optional): The time when the issue was first noticed.
* **Address** (<code>address</code>, text, required/optional): The property address where the issue is located.
* **Contact Number** (<code>contact_number</code>, text, required/optional): The phone number or contact information of the person reporting the issue.
* **Manager** (<code>manager</code>, text, required/optional): The name and title of the property manager or contact person.
