# Schedule Collection Request - Help Guide
## Purpose
The Schedule Collection Request form is used to request collection from a collection manager. It is designed to gather necessary information to schedule a collection.

## How To Complete This Form
To complete this form, follow these steps:
1. Select "Yes" or "No" for "Schedule Collection Request".
2. Provide customer details, if applicable.
3. Enter the address where collection is required.
4. Enter the phone number of the customer.
5. Select the pickup time for the collection.
6. Select the schedule type (e.g., 'Yes' for scheduled pick-up).
7. Select the schedule date and time for the collection.
8. Choose the collection method (e.g., 'Yes' for scheduled collection).
9. Select the collection time window (e.g., 'Yes' for within a specific time window).
10. Select the pickup time window (e.g., 'Yes' for within a specific time window).
11. Select the collection method window (e.g., 'Yes' for within a specific time window).
12. Select the pickup schedule (e.g., 'Yes' for scheduled pick-up).
13. Select the collection schedule (e.g., 'Yes' for scheduled collection).
14. Select the schedule window (e.g., 'Yes' for within a specific time window).
15. Select the collection time window (e.g., 'Yes' for within a specific time window).
