# Guarantor Recommendation Letter Request Form - Help Guide
## Purpose
This form is used to collect details about the applicant and the guarantor for a recommendation letter. The letter will be used to support the applicant's application for certain programs or opportunities.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill in the required fields with accurate and complete information about the applicant and the guarantor.
2. Provide a detailed description of the guarantor's relationship with the applicant.
3. If necessary, include any follow-up details that may be relevant to the application.
4. Submit your request by selecting "Submit Request".

## Field-by-Field Explanation
* **Guarantor Name**: The name of the individual writing the recommendation letter.
* **Guarantor Relationship**: A description of the guarantor's relationship with the applicant, such as "parent," "guardian," or " mentor."
* **Guarantor Contact Details**: A contact method or email address for the guarantor.
* **Guarantor Letter Details**: A brief description of the letter's purpose and content.
* **Follow-up Details**: Any additional information that may be relevant to the application.
* **Submit Request**: Select "Yes" to submit your request, or "No" if you need to make changes or corrections.
