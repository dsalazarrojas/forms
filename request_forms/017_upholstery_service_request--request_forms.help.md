# Upholstery Service Request - Help Guide
## Purpose
The "Upholstery Service Request" form is used by customers to submit their service requests for various upholstery-related services, such as reupholstery repair, sarging, cushion replacement, and re-trimming. The form is used to collect necessary information for the service request, including contact information, service details, and follow-up requirements.

## How To Complete This Form
1. Begin by selecting the "Start" option.
2. Fill in the required fields, including:
	* Contact Name
	* Customer Email
	* Customer Phone
	* Service Type
	* Assigned To
	* Status
	* Follow-up Status
3. Optionally, fill in the additional fields, including:
	* Service Scheduled
	* Service Completed
	* Follow-up Date
	* Follow-up Time
	* Next Follow-up Date
	* Next Follow-up Time
	* Customer Address
	* Customer Notes
	* Follow-up Message
4. Select the correct options for "Assigned To" and "Status" fields.
5. Enter the necessary information in the "Follow-up Message" field if follow-up is required.
6. Select the correct "Service Type" from the drop-down menu.
7. Select the correct "Follow-up Status" from the drop-down menu.
8. Enter the necessary information in the "Customer Address" field if required.
9. Enter the necessary information in the "Customer Notes" field if required.
10. Review the form for accuracy and completeness before submitting.

## Field-by-Field Explanation
* **Start** (id: 1, type: text, required: false): The beginning of the form. Select this option to initiate the form-filling process.
* **Contact Name** (id: 2, type: text, required: true): Enter the customer's name as they want to be addressed.
* **Contact Email** (id: 3, type: email, required: true): Enter the customer's email address.
* **Customer Phone** (id: 4, type: text, required: true): Enter the customer's phone number.
* **Service Request** (id: 5, type: text, required: true): Describe the specific service request, including any details or specifications.
* **Furniture Description** (id: 6, type: text, required: false): Provide a detailed description of the furniture item requiring service, including any specific requests for repair.
* **Service Type** (id: 7, type: select_one, required: true): Select the type of service required from the drop-down menu:
	+ Reupholstery Repair
	+ Serging/Re-stretching
	+ Cushion Replacement
	+ Re-Trimming
	+ Other
* **Follow-up Needed** (id: 8, type: select_multiple, required: false): Indicate if follow-up is required, and select the correct options:
	+ Yes
	+ No
* **Customer Name** (id: 9, type: text, required: true): Enter the customer's name as they want to be addressed.
* **Customer Email** (id: 10, type: email, required: true): Enter the customer's email address.
* **Customer Phone** (id: 11, type: text, required: true): Enter the customer's phone number.
* **Service Scheduled** (id: 12, type: date, required: false): Enter the date and time the service is scheduled to be completed.
* **Service Completed** (id: 13, type: date, required: false): Enter the date the service was completed.
* **Follow-up Date** (id: 14, type: date, required: false): Enter the follow-up date.
* **Follow-up Time** (id: 15, type: time, required: false): Enter the follow-up time.
* **Next Follow-up Date** (id: 16, type: date, required: false): Enter the next follow-up date.
* **Next Follow-up Time** (id: 17, type: time, required: false): Enter the next follow-up time.
* **Customer Address** (id: 18, type: text, required: false): Enter the customer's address.
* **Customer Notes** (id: 19, type: note, required: false): Enter any additional notes for the customer.
* **Assigned To** (id: 20, type: select_one, required: true): Select the person or team member assigned to handle the service request from the drop-down menu:
	+ chatjimmy
	+ Other
* **Status** (id: 21, type: select_one, required: true): Select the current status of the service request from the drop-down menu:
	+ Open
	+ In Progress
	+ Completed
* **Follow-up Status** (id: 22, type: select_one, required: false): Select the follow-up status from the drop-down menu:
	+ None
	+ Follow-up Sent
	+ Follow-up Completed
* **Follow-up Message** (id: 23, type: text, required: false): Enter the message to be sent to the customer as a follow-up.
* **Follow-up Date** (id: 24, type: date, required: false): Enter the follow-up date.
* **Follow-up Time** (id: 25, type: time, required: false): Enter the follow-up time.
* **Next Follow-up Date** (id: 26, type: date, required: false): Enter the next follow-up date.
* **Next Follow-up Time** (id: 27, type: time, required: false): Enter the next follow-up time.
* **Customer Address** (id: 28, type: text, required: false): Enter the customer's address.
* **Customer Notes** (id: 29, type: note, required: false): Enter any additional notes for the customer.
* **End** (id: 30, type: text, required: false): The end of the form.

## Tips
* Ensure all required fields are filled in accurately and thoroughly.
* Review the form for completeness before submitting.
* If unsure about any field, refer to this guide for clarification.
* If additional information is required, please provide it in the "Customer Notes" field.
* If you have any questions or concerns, contact the relevant team or team lead.
