# Graphic Configuration Estimate Request - Help Guide
## Purpose
The purpose of this form is to collect information from users about their graphic configuration estimate request for a graphic design project. This form will help the project administrator understand the user's requirements and provide a more accurate estimate for the project.

## How To Complete This Form
Please follow these steps to complete the form:

1. Enter your email address in the **User Email** field.
2. Provide the name of the project in the **Project Name** field.
3. Describe the project in the **Project Description** field.
4. Enter the estimated budget for the project in the **Project Budget** field.
5. Select the design type (yes or no) in the **Design Type** field.
6. Select the design format (yes or no) in the **Design Format** field. You can select multiple options.
7. Enter the project start date in the **Project Start Date** field.
8. Enter the project deadline in the **Project Deadline** field.
9. Add any additional information or comments about the project in the **Additional Info** and **Project Notes** fields.

## Field-by-Field Explanation
* **User Email**: Enter your email address so we can contact you about your project.
* **Project Name**: Provide the name of your project, which will help us understand the context.
* **Project Description**: Describe your project in a few sentences to give us a clear idea of what you need.
* **Project Budget**: Enter the estimated budget for your project.
* **Design Type**: Select yes if you need custom design or no if you don't need any design work.
* **Design Format**: Select the design format you need, such as yes or no for specific formats.
* **Project Start Date**: Enter the date when you plan to start the project.
* **Project Deadline**: Enter the date when you need the project completed.
* **Additional Info**: Add any additional information or comments about the project.
* **Project Notes**: Add any specific notes or requirements about the project.
* **User Comments**: Add any comments or feedback about the project or our services.
