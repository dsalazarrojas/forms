# residential_data_input_form - Help Guide
## Purpose
The "residential_data_input_form" is a form used to collect data about residential properties for real estate agents.

## How To Complete This Form
1. Fill out the form with the required information for the property you are entering.
2. Ensure all required fields are completed.
3. Enter accurate and complete information.

## Field-by-Field Explanation
* **Address Line 1** (`1`, `text`, required: `false`): Enter the first line of the property's address.
* **Address Line 2** (`2`, `text`, required: `false`): Enter the second line of the property's address.
* **City** (`3`, `text`, required: `true`): Enter the city where the property is located.
* **State** (`4`, `text`, required: `true`): Enter the state where the property is located.
* **Zip Code** (`5`, `number`, required: `true`): Enter the zip code of the property's location.
* **Number of Bedrooms** (`6`, `number`, required: `false`): Enter the number of bedrooms in the property.
* **Number of Bathrooms** (`7`, `number`, required: `false`): Enter the number of bathrooms in the property.
* **Square Footage** (`8`, `number`, required: `true`): Enter the square footage of the property.
* **List Price** (`10`, `select_one`, required: `true`): Select the list price of the property from the options provided.
* **Sale Status** (`11`, `select_multiple`, required: `true`): Select the current sale status of the property from the options provided.
* **Property Type** (`12`, `select_multiple`, required: `true`): Select the type of property from the options provided.
* **Year Built** (`13`, `select_one`, required: `false`): Select the year the property was built from the options provided.
* **Lot Size** (`14`, `text`, required: `true`): Enter the size of the lot.
* **Lot Orientation** (`15`, `text`, required: `false`): Enter the orientation of the lot.
* **Lot Frontage** (`16`, `text`, required: `false`): Enter the frontage of the lot.
* **Lot Depth** (`17`, `number`, required: `false`): Enter the depth of the lot.
* **Lot Width** (`18`, `number`, required: `false`): Enter the width of the lot.
* **Lot Frontage Type** (`19`, `text`, required: `false`): Enter the type of frontage of the lot.
* **Building Height** (`20`, `number`, required: `false`): Enter the height of the building.
* **Building Area** (`21`, `number`, required: `false`): Enter the area of the building.
* **Parking** (`22`, `select_multiple`, required: `false`): Select the type of parking available from the options provided.
* **Property Condition** (`23`, `text`, required: `false`): Enter the condition of the property.
* **Property Status** (`24`, `select_one`, required: `true`): Select the current status of the property from the options provided.
* **Agent Notes** (`25`, `text`, required: `false`): Enter any additional notes about the property.
