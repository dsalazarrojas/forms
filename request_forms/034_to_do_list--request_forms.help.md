# to_do_list - Help Guide
## Purpose
The purpose of this form is to create a To-Do list for tasks that need to be completed.

## How To Complete This Form
To complete this form, follow these steps:

1. Select one of the options for "to-do-item" to indicate whether the task is ready to be started.
2. Enter the due date of the task or select a date from the provided calendar.
3. Choose the priority level of the task, indicating its level of importance.
4. Check if the task has been completed.
5. Enter any additional notes or comments about the task.

## Field-by-Field Explanation
* **to-do-item** (select_one): Select whether the task is ready to be started or not.
* **due-date** (date): Enter the date when the task is due or select a date from the calendar.
* **priority** (select_one): Choose the priority level of the task, indicating its level of importance.
* **completed** (select_one): Check if the task has been completed.
* **notes** (text): Enter any additional comments or notes about the task.

## Tips
* Make sure to select a date that is in the future if the task is not completed yet.
* If a task has a high priority, make sure to give it more attention and time.
* Keep the "notes" field for any additional comments or reminders about the task.
