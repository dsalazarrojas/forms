# Translation Quote Request Form - Help Guide
## Purpose
This form is designed to collect information from clients requesting a translation quote for a specific project. The data collected will be used to provide a detailed quote for the project.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the Client Details section with the client's name, contact information, and project requirements.
2. In the Project Details section, provide a brief description of the project and any specific requirements or requests.
3. In the File Upload section, attach the file to be translated.
4. In the Service Details section, select the service type and any additional services required.
5. In the Quote Details section, provide any additional information needed to generate an accurate quote.
6. If you have any additional information or comments, use the Additional Info section.
7. If you would like to receive the quote via email, select Send Quote and enter your email address.
8. Finally, confirm your request and submit the form.

## Field-by-Field Explanation
* **Client Details** (Required): Please fill out the client's name, contact information, and project requirements. This information will help us to provide a personalized quote.
* **Project Details** (Required): Give a brief description of the project, including any specific requirements or requests.
* **File Upload** (Required): Attach the file to be translated.
* **Service Details** (Required): Select the type of service required (e.g. PDF to Spanish, PDF to French, etc.).
* **Quote Details** (Required): Provide any additional information needed to generate an accurate quote.
* **Additional Info** (Optional): If you have any additional information or comments, use this section to provide them.
* **Send Quote** (Optional): If you would like to receive the quote via email, select this option and enter your email address.
* **Confirmation** (Required): Confirm your request before submitting the form.
* **Comments** (Optional): If you have any comments or additional information, use this section to provide them.
* **File URL** (Optional): If you have a link to an online file storage (e.g. Google Drive), provide the URL instead of uploading the file.
* **File Description** (Optional): If you have a description of the file, use this section to provide it.
