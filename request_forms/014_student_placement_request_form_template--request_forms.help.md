# Student Placement Request Form Template - Help Guide
## Purpose
The Student Placement Request Form Template is used to collect information from students who require placement within the university. This form is not intended for general use, but rather for internal use by the university to track and manage student placement requests.

## How To Complete This Form
1. Enter a title for the request in the **Student Placement Request Form Template** field.
2. Select the category of your request from the **Category** dropdown menu (e.g., Request Forms, Other).
3. Provide a description of your needs in the **Description** field.
4. If applicable, select the tool you are assigned from the **Assigned Tool** dropdown menu.
5. If necessary, upload additional form data in the **Form Data** field.
6. Enter your email address in the **Submitted By** field to associate your request with your account.
7. Select a date and time for when the request was submitted in the **Submitted On** field.

## Field-by-Field Explanation
- **Student Placement Request Form Template** (`form_title`, text, required/optional): Enter a title that describes your request.
- **Category** (`category`, select_one, required/optional): Choose a category for your request (e.g., Request Forms, Other).
  Please note that this field is not required, so you can select "Other" if your request does not fit into one of the provided categories.
- **Description** (`description`, text, required/optional): Provide a brief description of your request.
- **Form ID** (`form_id`, number, required/optional): Enter a unique identifier for your request.
  This field is not typically used by students, so you can leave it blank.
- **Assigned Tool** (`assigned_tool`, select_one, required/optional): Select the tool you are assigned (e.g., chatjimmy, chatjimmy2).
  If no tool is assigned to you, you can leave this field blank.
- **Output File** (`output_file`, text, required/optional): Upload any additional files related to your request.
  This field is not typically used, so you can leave it blank.
- **Form Data** (`form_data`, note, required/optional): Enter any additional information about your request.
  This field is not typically used, so you can leave it blank.
- **Submitted By** (`submitted_by`, email, required/optional): Enter your email address associated with your account.
  This field is required to associate your request with your account.
- **Submitted On** (`submitted_on`, date, required/optional): Select the date and time when you submitted the request.
  This field is required to track when the request was submitted.
