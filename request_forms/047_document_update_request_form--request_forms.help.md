# Document Update Request Form - Help Guide
## Purpose
The Document Update Request Form is used to collect information from staff and clients to request updates to a document. Before submitting a request, please ensure that it is valid and not a duplicate of an existing request.

## How To Complete This Form
To complete this form, follow these steps:

* Fill in the required fields, which are marked as `required` in the form.
* For non-required fields, you can choose to leave them blank or fill them in if you have additional information to provide.
* Review the form carefully to ensure that all fields are filled in correctly.

## Field-by-Field Explanation
* **Document Request** (`document_request`, text, required/optional): 
This field is for the description of the document update request.
* **Prophets** (`document_details`, text, required/optional): 
This field is for any additional information about the document, such as changes or updates requested.
* **File Upload** (`file_upload`, text, required/optional): 
This field is for uploading any relevant file related to the document update request.
* **Staff Requesting** (`staff_requesting`, select_one, required/optional): 
This field is for the staff member or client requesting the document update.
* **Date Requested** (`date_requested`, date, required/optional): 
This field is for the date when the document update is requested.
* **Time Requested** (`time_requested`, time, required/optional): 
This field is for the time when the document update is requested.
* **Requested By** (`requested_by`, text, required/optional): 
This field is for the staff member or client making the request.
* **Document Status** (`document_status`, text, required/optional): 
This field is for the current status of the document.
* **Request Details** (`request_details`, text, required/optional): 
This field is for any additional information about the document update request.
* **Review Notes** (`review_notes`, text, required/optional): 
This field is for any comments or review notes about the document update request.

## Tips
* If you are unsure about what information to provide, please contact the document management team for assistance.
* Make sure to fill in the required fields accurately and thoroughly.
* Avoid submitting duplicate requests for the same document.
