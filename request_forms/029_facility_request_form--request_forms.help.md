# Facility Request Form - Help Guide
## Purpose
This form is used to collect information about a facility's status and requirements.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the form title.
2. Enter detailed information about the facility.
3. Select the correct priority level for the request.
4. Select the status of the facility.
5. Confirm if the facility is located within the specified area.
6. Enter the contact information for the facility.
7. Enter the email address for the facility.
8. Enter the phone number for the facility.
9. Select if the facility request is required or not.
10. Date and time of the request.
11. Enter any additional comments about the facility.
12. Confirm if attachments are required for the request.
13. Enter any additional notes.

## Field-by-Field Explanation
* **Facility Request Form**: This is the title of the form, which should be a brief and descriptive name for the request.
* **Facility Details**: This is a note field where you can provide a detailed description of the facility.
* **Priority**: Choose the priority level of the request from the dropdown menu.
* **Facility Status**: Select the current status of the facility from the dropdown menu.
* **Facility Located Within Specified Area**: Confirm if the facility is located within the specified area.
* **Facility Contact Information**: Enter the contact person's name or department.
* **Facility Email**: Enter the email address of the facility.
* **Facility Phone Number**: Enter the phone number of the facility.
* **Request Required**: Confirm if the facility request is required.
* **Request Date**: Enter the date of the request.
* **Request Time**: Enter the time of the request.
* **Facility Comments**: Enter any additional comments about the facility.
* **Attachments Required**: Confirm if attachments are required for the request.
* **Additional Notes**: Enter any additional notes about the facility.
