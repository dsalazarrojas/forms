# Corporate Cost Review Registration Form - Help Guide
## Purpose
This form is designed to collect and manage corporate cost review requests within an organization.

## How To Complete This Form
To complete this form, follow the steps below:

1. Enter your request details
2. Provide expense details
3. Attach any supporting documents
4. Select the finance manager and manager approvals
5. Update the review notes
6. Select the finance manager approval and review status

## Field-by-Field Explanation

* **Request Details** (request_details): Enter a brief description of the request.
* **Expense Details** (expense_details): Enter a detailed description of the expense.
* **Supporting Documents** (supporting_documents): Attach any relevant documents or files to support the request.
* **Approvals** (approvals): Enter any relevant approvals or signatures.
* **Requestor Information** (requestor_info): Enter your contact information.
* **Manager Approvals** (manager_approvals): Select manager approvals for the request.
* **Finance Team Approvals** (finance_team_approvals): Select finance team approvals for the request.
* **Review Notes** (review_notes): Add any notes or comments for the reviewer.
* **Finance Manager Approval** (finance_manager_approval): Select the finance manager's approval (Approve, Reject, Request More Information).
* **Review Status** (review_status): Select the current status of the review (Approved, Rejected, Under Review).
* **Request Status** (request_status): Select the status of the request (New, Pending, Completed).
* **Expense Type** (expense_type): Select the category of expense (Travel, Meals, Hotel, Other).
* **Request Category** (request_category): Select all applicable categories of expense (Travel, Food, Hotel, Other).

## Tips
* Please ensure all required information is entered before submitting the form.
* Please ensure all fields are completed before submitting the form.
* Review and update the form regularly to track changes and status updates.
* Ensure all supporting documents are attached and easily accessible.
* Use clear and concise language when entering descriptions and comments.
* Use the correct format for dates and times.
* Ensure all approvals and statuses are accurate and up-to-date.
