# Payroll Statement Copy Request Form - Help Guide
## Purpose
The Payroll Statement Copy Request Form is used for requesting a copy of a payroll statement. This form is designed to collect necessary information from the user to fulfill the request.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill out the first name field, which should be a basic identifier for the person making the request.
2. Enter the pay period for which the payroll statement is being requested. This is usually a month and year, or a specific range of dates.
3. Enter the employee's ID number.
4. Provide a brief reason for requesting the payroll statement.
5. If you're requesting a statement for a specific date range, enter the start and end dates.
6. Optionally, select the pay periods for which you'd like to receive a copy of the statement.

## Field-by-Field Explanation
- **First name**: Enter the name of the person making the request, as an identifier.
- **Pay Period**: Enter the month and year or a specific range of dates for which you're requesting the payroll statement.
- **Employee ID**: Enter the employee's ID number.
- **Reason for Request**: Provide a brief reason for why you're requesting the payroll statement.
- **Start Date**: If you're requesting a statement for a specific date range, enter the start date.
- **End Date**: If you're requesting a statement for a specific date range, enter the end date.
- **Pay Period**: This field is a repeat of the "Pay Period" field, but with a dropdown menu. Select the pay periods for which you'd like to receive a copy of the statement.
