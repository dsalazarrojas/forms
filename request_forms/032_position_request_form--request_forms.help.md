# Position Request Form - Help Guide
## Purpose
The Position Request Form is a form used to submit formal requests for position changes within an organization. This form is intended for employees and departments to submit requests for new job titles, job levels, or other position changes.

## How To Complete This Form
1. Select the relevant options for the form, which include fields for employee name, email, manager's email, department head's name, department, job title, job level, job category, job description, and job requirements.
2. Choose the required supporting documents to attach to the request.
3. Enter the date of the request and the expected date of promotion.
4. Provide details about your current position and the new position you are requesting.
5. Request manager approval for your position change.
6. Select who submitted the request and who approved or rejected it.
7. Enter any comments or notes about the request.

## Field-by-Field Explanation
* **Title (request_form)** (`text`, required/optional): The title of the form, which is the Position Request Form.
* **Employee Name (employee_name)** (`text`, required/optional): The employee submitting the request's name.
* **Employee Email (employee_email)** (`text`, required/optional): The employee's email address.
* **Manager's Email (manager_email)** (`text`, required/optional): The manager's email address.
* **Department Head (department_head)** (`select_one`, required/optional): Choose the department head who will review your request.
* **Department (department)** (`text`, required/optional): The department the position change belongs to.
* **Job Title (job_title)** (`text`, required/optional): The title of the new position.
* **Job Level (job_level)** (`select_one`, required/optional): Choose the new level of the position.
* **Job Category (job_category)** (`text`, required/optional): A description of the new position's category.
* **Job Description (job_description)** (`text`, required/optional): A detailed description of the new position.
* **Job Requirements (job_requirement)** (`text`, required/optional): A description of the requirements for the new position.
* **Supporting Documents (supporting_docs)** (`select_multiple`, required/optional): Attach relevant documents to support your request.
* **Date of Request (date_of_request)** (`date`, required/optional): The date the request was made.
* **Expected Promotion Date (expected_promotion_date)** (`date`, required/optional): The date the promotion is expected to take place.
* **Current Position (current_position)** (`text`, required/optional): The employee's current position.
* **New Position (new_position)** (`text`, required/optional): The new position the employee is requesting.
* **Manager Approval (manager_approval)** (`select_one`, required/optional): Select whether manager approval is required.
* **Comments (comments)** (`text`, required/optional): Add any comments or notes about the request.
* **Submitted by (submitted)** (`select_one`, required/optional): The person submitting the request.
* **Submitted Date (submitted_date)** (`date`, required/optional): The date the request was submitted.
* **Approved by (approved)** (`select_one`, required/optional): The person approving the request.
* **Approved Date (approved_date)** (`date`, required/optional): The date the request was approved.
* **Rejected by (rejected)** (`select_one`, required/optional): The person rejecting the request.
* **Rejected Date (rejected_date)** (`date`, required/optional): The date the request was rejected.
