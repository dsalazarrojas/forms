# Research Publication Support Request Form - Help Guide
## Purpose
The Research Publication Support Request Form is designed to collect information from researchers to help with manuscript publication support. Fill out this form accurately to ensure your request is processed efficiently.

## How To Complete This Form
- Start by selecting the correct research team member or associate from the drop-down list.
- Enter the manuscript title, including the title and subtitle if applicable.
- Select one or more authors for the manuscript.
- Choose the format of the manuscript (PDF, DOCX, DOC).
- Select the channel for publication (journal, conference, book chapter).
- Enter the estimated date needed for publication.
- If necessary, upload a manuscript file in the correct format.
- Provide any additional information about the manuscript.
- Select the expected month of publication.
- Choose the expected year of publication.
- Enter a short description of the manuscript.
- If applicable, enter the manuscript DOI, URL, or keywords.
- Select the manuscript status (submitted, in review, in production).
- Choose the manuscript type (research, review, other).
- Select the manuscript category (research, review, other).
- Enter keywords, authors, institutions, and address if necessary.
- Confirm that your request is genuine by checking the box at the bottom of the form.

## Field-by-Field Explanation
- **Request Form** (1): Enter a brief description of the issue you're facing with manuscript publication.
- **Research Team** (2): Select the member of the team who will assist with manuscript publication.
- **Manuscript Title** (3): Enter the title of the manuscript in question.
- **Author Names** (4): Select the authors of the manuscript.
- **Manuscript Format** (5): Choose the format of the manuscript (PDF, DOCX, or DOC).
- **Publication Channel** (6): Select where the manuscript is to be published (journal, conference, book chapter).
- **Date Needed** (7): Enter the estimated date needed for manuscript publication.
- **Manuscript Upload** (8): Upload a manuscript file in the correct format if necessary.
- **Other Information** (9): Add any additional details about the manuscript.
- **Expected Publication Month** (10): Select the expected month of publication.
- **Expected Publication Year** (11): Choose the expected year of publication.
- **Manuscript Description** (12): Enter a short description of the manuscript.
- **Manuscript DOI** (13): Enter the manuscript's DOI if available.
- **Manuscript URL** (14): Enter the manuscript URL if available.
- **Manuscript Keywords** (15): Enter relevant keywords for the manuscript.
- **Manuscript Tags** (16): Enter relevant tags for the manuscript.
- **Manuscript Status** (17): Select the current status of the manuscript.
- **Manuscript Type** (18): Choose the type of manuscript (research, review, other).
- **Manuscript Category** (19): Select the category of the manuscript.
- **Manuscript Keywords** (20): Enter relevant keywords for the manuscript.
- **Manuscript Authors** (21): Enter the authors of the manuscript.
- **Manuscript Authors Affiliations** (22): Enter the affiliations of the authors.
- **Manuscript Institutions** (23): Enter the institutions where the research was conducted.
- **Manuscript Institutions Address** (24): Enter the address of the institutions.
- **Manuscript Funding** (25): Enter funding information, if applicable.
