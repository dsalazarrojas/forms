# Prayer Request - Help Guide
## Purpose
The Prayer Request form is designed to allow users to create and submit prayer requests for others. This form is used to record and track prayer requests, including the name and email of the person requesting prayer, details about the prayer request, and whether the prayer has been answered.

## How To Complete This Form
To complete this form, follow these steps:
1. Select whether the prayer request is for you or someone else by choosing "Yes" or "No" from the first field.
2. If the request is not for you, enter the other person's name in the "Name" field.
3. Enter the other person's email address in the "Email" field.
4. Provide a brief description of the prayer request in the "Prayer Request Details" field.
5. Indicate whether the prayer has been answered by selecting "Prayer Answered" or "Not Prayer Answered" from the "Prayer Answered" field.
6. Enter your name and the date and time you submitted the request in the "Submitted By", "Date Submitted", and "Time Submitted" fields. (Note: These fields are for tracking and administrative purposes and are not required to be completed by the person making the request.)
## Field-by-Field Explanation
* **Prayer Request Form**: This field is a multiple select field where you can choose whether the prayer request is for you or someone else.
* **Name**: This field is for entering the name of the person requesting prayer.
* **Email**: This field is for entering the email address of the person requesting prayer.
* **Prayer Request Details**: This field is for providing a brief description of the prayer request.
* **Prayer Answered**: This field is for indicating whether the prayer has been answered.
* **Submitted By**: This field is for recording the name of the person submitting the request.
* **Date Submitted**: This field is for recording the date the request was submitted.
* **Time Submitted**: This field is for recording the time the request was submitted.

## Tips
* Please use this form for submitting genuine prayer requests.
* If you need to submit multiple requests for the same person, you can do so by creating separate forms with different details.
* If you're unsure about the purpose of the form or how to complete it, please contact the form administrators for assistance.
