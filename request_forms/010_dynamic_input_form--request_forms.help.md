# Dynamic Input Form - Help Guide

## Purpose
The Dynamic Input Form is designed to collect user input for requests or submissions. It consists of multiple fields, each with its own purpose and requirements.

## How To Complete This Form
1. Start by filling out the first field, "Request Form", which is used to enter a general request.
2. Next, enter a value in the "Entry" fields to provide further details. These fields are meant to support the request with additional information.
3. If required, provide a "Consent" by selecting "Yes" or "No".
4. Upload or enter a "Supporting File" if necessary to support the request.
5. Continue entering values in the remaining "Entry" fields to provide more details.
6. If needed, upload additional "Supporting Files" to support the request.
7. Once all fields are filled out, review the form for completeness and accuracy before submitting it.

## Field-by-Field Explanation
* **Request Form (Required/Optional)**: Enter a general request or description.
* **Entry (Optional)**: Provide additional details to support the request.
* **Consent (Optional)**: Select "Yes" if you agree with the request, and "No" if you do not.
* **Supporting File (Optional)**: Upload a file to support the request.
* **Entry 2-12 (Optional)**: Enter more details for the request.
* **Supporting File 2-11 (Optional)**: Upload more files to support the request.
* **Entry 13 (Optional)**: Enter further details for the request.
* **Supporting File 11 (Optional)**: Upload an additional file to support the request.
