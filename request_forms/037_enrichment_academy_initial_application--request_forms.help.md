# enrichment_academy_initial_application - Help Guide
## Purpose
This form is used to submit an initial application for the Enrichment Academy.

## How To Complete This Form
To complete this form, please follow the steps below:

1. Fill in the required information, marked with an asterisk (\*) symbol next to the field label.
2. Ensure that your application is accurate and truthful.

## Field-by-Field Explanation

* **User Input** (`user_input`, text, not required): This field is where you can provide any additional information about yourself that you feel is relevant to your application.
* **introduction** (`introduction`, text, not required): Please briefly introduce yourself and explain why you're interested in the Enrichment Academy.
* **schedule_tour** (`schedule_tour`, date, not required): Select a date for the tour or event you'd like to schedule.
* **select** (`select`, select_one, required): Choose the option that best represents your preference or interest in the Enrichment Academy.
* **select** (`select`, select_one, required): Choose the option that best represents your interest in the Enrichment Academy for the selected tour date. This selection will help us tailor the tour to your needs.
* **schedule_tour_time** (`schedule_tour_time`, time, not required): Select a time for the tour that suits you best, if applicable.
* **email** (`email`, email, required): Enter a valid email address that we can use to contact you.
* **phone** (`phone`, text, not required): Provide your phone number so that we can reach you for further communication, if needed.
