# Digital Production Dashboard Application Form - Help Guide
## Purpose
This form is designed to collect project information for the Digital Production Dashboard Application.

## How To Complete This Form
To complete this form, follow these steps:

1. **Project Details** (Project Details, text, optional)
	* This field is for you to enter a brief description of the project.
2. **Technical Requirements** (Technical Requirements, text, optional)
	* In this field, please provide any technical requirements or specifications for the project.
3. **Supporting Files** (Supporting Files, text, optional)
	* If there are any files or attachments that support your project, please upload them here.
4. **Team Leads** (Team Leads, select multiple, optional)
	* Select the team leads who will be working on the project. Choose from the list of available options.
5. **Technical Leads** (Technical Leads, select multiple, optional)
	* Select the technical leads who will be working on the project. Choose from the list of available options.
6. **Project Deadline** (Project Deadline, date, optional)
	* Enter the project deadline in the format mm/dd/yyyy.
7. **Project Start Date** (Project Start Date, date, optional)
	* Enter the project start date in the format mm/dd/yyyy.
8. **Notes** (Notes, note, optional)
	* Provide any additional comments or notes about the project.
9. **Email** (Email, email, optional)
	* Enter your email address associated with the project.
10. **Phone** (Phone, text, optional)
	* Enter your phone number associated with the project.

* **Project Details**: Enter a brief description of the project.
