# Table Saw Extension Request Form - Help Guide
## Purpose
This form is used to collect information for a Table Saw extension request. A Table Saw is a machine used in various workshops and departments, and extensions are necessary to allocate extra time for maintenance, training, or other reasons.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill out the "User Input" field with a detailed description of the reason for the extension request.
2. Choose the correct "Supervisor Approval" status from the options provided.
3. Enter the equipment ID of the Table Saw in the "Equipment Id" field.
4. Select the "Extension Start Date" and "Extension End Date" fields to specify the period of the extension.
5. Choose the correct "Equipment Status" from the options provided.
6. If necessary, enter additional comments in the "Supervisor Comment" field.
7. Enter the supervisor's name in the "Supervisor Name" field.
8. Select the correct "Department" from the options provided.
9. Enter the workshop name in the "Workshop Name" field.
10. Enter a brief reason for the extension request in the "Reason" field.
11. If necessary, enter the "Supervisor Comment" field.
12. Enter the equipment status in the "Equipment Status" field.
13. Enter the number of days for the extension in the "Extension Days" field.
14. Enter the number of hours for the extension in the "Extension Hours" field.
15. Enter any additional comments in the "Supervisor Comment" field.
16. Enter the name of the prophet in the "Prophets Name" field.
17. Enter any additional comments in the "User Comment" field.
18. Enter the equipment ID of the Table Saw in the "Equipment Id 2" field.
19. Enter the extension status in the "Extension Status" field.
20. Enter the name of the user who is assigned to the Table Saw in the "Assigned User" field.
21. Enter the form ID in the "Form Id" field.
22. Enter the form version in the "Form Version" field.
23. Enter the date when the form was last updated in the "Last Updated" field.
24. Enter the user's name in the "User Name" field.
25. Select the department name in the "Department Name" field.
26. Enter the workshop name in the "Workshop Name 2" field.
27. Choose the correct "Supervisor Approval2" status from the options provided.
28. Select the correct start time for the extension in the "Extension Start Time" field.
29. Select the correct end time for the extension in the "Extension End Time" field.
30. Enter the status of the form in the "Form Status" field.
31. Enter the tool name assigned to the user in the "Assigned Tool" field.
32. Enter any additional notes in the "Form Notes" field.

## Field-by-Field Explanation

* **User Input** (`User Input`, text, required): Enter a detailed description of the reason for the extension request, including any relevant dates and times.
* **Supervisor Approval** (`Supervisor Approval`, select_multiple, optional): Choose the status of the supervisor's approval from the options provided.
* **Equipment Id** (`Equipment Id`, number, optional): Enter the equipment ID of the Table Saw.
* **Extension Start Date** (`Extension Start Date`, date, optional): Select the start date of the extension.
* **Extension End Date** (`Extension End Date`, date, optional): Select the end date of the extension.
* **Supervisor Name** (`Supervisor Name`, text, optional): Enter the supervisor's name.
* **Department** (`Department`, text, optional): Select the department where the Table Saw is located.
* **Workshop Name** (`Workshop Name`, text, optional): Enter the workshop name where the Table Saw is located.
* **Reason** (`Reason`, text, optional): Enter a brief reason for the extension request.
* **Equipment Status** (`Equipment Status`, select_multiple, optional): Choose the status of the equipment from the options provided.
* **Extension Days** (`Extension Days`, number, optional): Enter the number of days for the extension.
* **Extension Hours** (`Extension Hours`, number, optional): Enter the number of hours for the extension.
* **Supervisor Comment** (`Supervisor Comment`, text, optional): Enter any additional comments from the supervisor.
* **Prophets Name** (`Prophets Name`, text, optional): Enter the name of the prophet.
* **User Comment** (`User Comment`, text, optional): Enter any additional comments from the user.
* **Equipment Id 2** (`Equipment Id 2`, text, optional): Enter the equipment ID of the Table Saw.
* **Extension Status** (`Extension Status`, text, optional): Enter the extension status.
* **Assigned User** (`Assigned User`, text, optional): Enter the name of the user assigned to the Table Saw.
* **Form Id** (`Form Id`, number, optional): Enter the form ID.
* **Form Version** (`Form Version`, number, optional): Enter the form version.
* **Last Updated** (`Last Updated`, date, optional): Enter the date when the form was last updated.
* **User Name** (`User Name`, text, optional): Enter the user's name.
* **Department Name** (`Department Name`, text, optional): Select the department name.
* **Workshop Name 2** (`Workshop Name 2`, text, optional): Enter the workshop name.
* **Supervisor Approval2** (`Supervisor Approval2`, select_one, optional): Choose the status of the supervisor's approval from the options provided.
* **Extension Start Time** (`Extension Start Time`, time, optional): Select the start time for the extension.
* **Extension End Time** (`Extension End Time`, time, optional): Select the end time for the extension.
* **Form Status** (`Form Status`, text, optional): Enter the status of the form.
* **Assigned Tool** (`Assigned Tool`, text, optional): Enter the tool name assigned to the user.
* **Form Notes** (`Form Notes`, text, optional): Enter any additional notes for the form.
