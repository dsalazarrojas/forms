# job_estimate_request_form - Help Guide

## Purpose
This form is designed to collect information from users to estimate the time required for a job or project. It helps to gather essential details such as client name, project title, start and end dates, estimated hours, and contact information, enabling efficient project management and communication.

## How To Complete This Form

1. Fill in the form with the requested information.
2. Enter your client's name in the "Client Name" field.
3. Provide the project title in the "Project Title" field.
4. Enter the start and end dates for the project in the "Start Date" and "End Date" fields.
5. Describe the project in the "Project Description" field.
6. Estimate the number of hours required for the project in the "Estimated Hours" field.
7. Enter your email address in the "Requestor" field.
8. Add any contact number for further communication in the "Contact Number" field.
9. Customize the submit button label and text as desired in the "Submit Button Label" and "Submit Button Text" fields.
10. Add any additional description for the form in the "Form Description" field.

## Field-by-Field Explanation
- **Client Name**: Enter the name of the client who is requesting the job or project.
- **Project Title**: Enter a brief title of the project that is being requested.
- **Start Date**: Enter the start date of the project in a standard date format (yyyy-mm-dd).
- **End Date**: Enter the end date of the project in a standard date format (yyyy-mm-dd).
- **Project Description**: Describe the project and its scope in detail.
- **Estimated Hours**: Enter an estimate of the number of hours required for the project.
- **Requestor**: Enter your email address so that the client can contact you for further queries.
- **Contact Number**: Enter any additional contact number for the client to reach you.
- **Submit Button Label**: Customize the text of the submit button as desired.
- **Submit Button Text**: Customize the text on the submit button as desired.
- **Form Description**: Add any additional description or instructions for the form.
