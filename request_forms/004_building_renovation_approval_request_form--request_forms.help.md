# Building Renovation Approval Request Form - Help Guide
## Purpose
The Building Renovation Approval Request Form is used to request approval for building renovations. This form helps to gather necessary information for the renovation and ensures that all required details are provided before the approval process begins.

## How To Complete This Form
To complete this form, follow these steps:

1.  Complete the Renovation Request Details page with a brief overview of the renovation project.
2.  On the following pages, fill in the required information:
    *   Requester's name, department, and building location.
    *   Preferred start date and estimated completion date for the project.
    *   The estimated cost of the project.
    *   A summary of the scope of work, including major changes.
    *   If necessary, provide a safety and access plan to minimize disruption.
3.  Select the primary funding source for the renovation.
4.  Finally, indicate the current status of the approval decision.

## Field-by-Field Explanation

*   **Requester Name** (text, required): Enter the name of the person submitting the request.
*   **Department or Unit** (text, required): Enter the department responsible for the space being renovated.
*   **Building and Room Number** (text, required): Provide the exact location of the proposed renovation.
*   **Preferred Start Date** (date, required): Enter the desired start date for the renovation work.
*   **Estimated Completion Date** (date, required): Provide the anticipated finish date for the renovation.
*   **Estimated Cost** (number, required): Provide the approximate total cost of the project in local currency.
*   **Scope of Work Summary** (text, required): Describe the planned activities and major changes for the renovation.
*   **Safety and Access Plan** (text, optional): If needed, outline measures to ensure safety and minimize disruption during the renovation.
*   **Funding Source** (select one, required): Select the primary source of funds for the renovation from the given options.
*   **Approver Decision** (select one, required): Indicate the current status of the approval decision.
    *   Pending: The decision is pending.
    *   Approved: The request is approved.
    *   Conditional approval: The request is approved with conditions.
    *   Denied: The request is denied.

## Tips
*   Make sure to provide accurate and complete information.
*   Ensure that all required fields are filled out completely.
*   Double-check that the funding source matches the actual source of funds for the renovation.
*   Keep the scope of work summary clear and concise.
*   If the safety and access plan is not required, you can leave it blank.
