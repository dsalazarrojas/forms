# Investment Fund Switch Request Form - Help Guide
## Purpose
The Investment Fund Switch Request Form is used to submit a request for transferring funds between different investment funds.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill out the form with the required information.
2. Select the correct options for the fund transfer.
3. Ensure all fields are filled out correctly before submitting the form.

## Field-by-Field Explanation
- **First Page (First Page)**: This is the first page of the form where you can start entering your fund switch request details.
  - **Fund Transfer Details (Fund Transfer Details)**: Please provide detailed information about the transfer.
  - **Select Investment Fund (Select Investment Fund)**: Select the investment fund to transfer from.
  - **Transfer Date (Transfer Date)**: Enter the date of the transfer.
  - **Transfer Time (Transfer Time)**: Enter the time of the transfer.
  - **Select Transfer Option (Select Transfer Option)**: Select all options that apply to the transfer.

# Tips
- Please ensure all fields are filled out correctly before submitting the form.
- If you need help or have questions, contact the relevant department for assistance.
- Please review your form submission carefully before submitting it.
