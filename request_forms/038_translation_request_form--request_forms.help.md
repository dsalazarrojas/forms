# Translation Request Form - Help Guide

## Purpose
This form is used to request translation of a document or file for internal or external use. Fill out this form to initiate the translation process.

## How To Complete This Form

To complete this form, please follow these steps:

1. Fill in the "Document Title" field with the title of the document or file you wish to have translated.
2. In the "Document Type" field, select whether the document is for internal or external use.
3. If you select "Yes" in the "Document Type" field, you will be asked to provide the document language you wish to have it translated into.
4. If you select "Yes" for "Document Language" field, provide the language code of the document in the field below.
5. In the "Document File" field, provide the URL or path to the document or file you wish to have translated.
6. Click the "Submit" button to submit your translation request.

## Field-by-Field Explanation

* **Document Title**: Enter the title of the document or file you wish to have translated. This will help us identify the document correctly.
* **Document Type**: Select whether the document is for internal or external use. This will help us determine the target audience and requirements of the translation.
* **Document Language**: If the document is already in a language other than the one we support, select "Yes" to provide the language code. This will help us identify the correct target language.
* **Document File**: Enter the URL or path to the document or file you wish to have translated. This can be a URL to a shared drive or a local file path.
* **Submit**: Click this button to submit your translation request and initiate the translation process.

## Tips

* Make sure to provide accurate and clear information in the fields above to ensure we can process your translation request correctly.
* If you have any further questions or need assistance with the form, feel free to reach out to us.
