# Request For Quote - Help Guide
## Purpose
The Request For Quote form is a tool for customers to provide information about their product or service needs. This information will be used to generate a quote for the customer.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the customer's information, including their name, address, and any other relevant details.
2. Specify the delivery address for the quote.
3. Choose a delivery date and time that suits your needs.
4. Select the method of delivery that you prefer (e.g., via email, mail).
5. Choose any additional options for delivery that apply to you.
6. Select a location for the delivery (if applicable).
7. Choose a delivery method 2 (if you have a second option).
8. Add any notes about the delivery that you would like to include.

## Field-by-Field Explanation
* **Customer Information (Customer Information)**: This field is for you to enter your name and any other relevant details.
* **Delivery Address (Delivery Address)**: Enter the address where you would like the quote to be delivered.
* **Delivery Date (Delivery Date)**: Choose a date for the delivery of the quote. This can be in the format of YYYY-MM-DD.
* **Delivery Time (Delivery Time)**: Choose a time for the delivery of the quote. This can be in the format of 12:00 PM or 13:00.
* **Delivery Method (Delivery Method)**: Select the method of delivery you prefer from the options provided.
* **Options (Options)**: Choose any additional options that apply to you for delivery. These options will be specific to the selected delivery method.
* **Location (Location)**: If you have a specific location for the delivery, enter it here.
* **Delivery Method 2 (Delivery Method 2)**: Select a second option for delivery (if you have one).
* **Delivery Notes (Delivery Notes)**: Add any additional notes about the delivery that you would like to include.
