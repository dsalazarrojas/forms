# Stock Transfer Coordination Request - Help Guide
## Purpose
The Stock Transfer Coordination Request form is used to submit a request for stock transfer coordination between different warehouses. This form helps to ensure that stock transfers are properly documented and that the necessary parties are informed and involved in the process.

## How To Complete This Form
To complete this form, follow these steps:

1. Select "Yes" or "No" to indicate if this is a stock item ID or name request.
2. Enter the stock item ID or name if "Yes" was selected.
3. Choose "Yes" or "No" to indicate if the transfer is from the warehouse where you are currently located.
4. Choose "Yes" or "No" to indicate if the transfer is to another warehouse.
5. Select a transfer date using the calendar tool.
6. Enter the quantity of stock being transferred.
7. Choose "Yes" or "No" to indicate if this is a manual transfer request.
8. Enter any additional notes or comments about the transfer.
9. Select "Yes" or "No" to indicate if someone is assigned to handle the transfer.
10. Enter the email of the person assigned to handle the transfer, if selected.
11. Enter the email address of the person requesting the transfer.

## Field-by-Field Explanation
* **Transfer Request**: Enter a brief description of the stock transfer request.
* **Stock Item ID**: If you have the stock item ID, enter it here. This is an optional field.
* **Stock Item Name**: If you don't have the stock item ID, enter the stock item name.
* **Transfer From Warehouse**: Choose "Yes" if the stock transfer is from the warehouse where you are currently located.
* **Transfer To Warehouse**: Choose "Yes" if the transfer is to another warehouse.
* **Transfer Date**: Select a date for the stock transfer using the calendar tool.
* **Quantity Transferring**: Enter the quantity of stock being transferred.
* **Transfer Method**: Choose "Yes" if this is a manual transfer request.
* **Notes**: Add any additional notes or comments about the transfer.
* **Assigned To**: Choose "Yes" if someone is assigned to handle the transfer.
* **Email**: Enter the email of the person assigned to handle the transfer, if selected.
* **Email**: Enter your email address for record keeping. 

Note: Please ensure all required fields are completed as per the form instructions.
