# Virtual Learning Analytics Access Request Form - Help Guide
## Purpose
The Virtual Learning Analytics Access Request Form is used to request access to virtual learning analytics data for educational purposes. This form helps to identify the level of analytics access needed and the scope of data requested.

## How To Complete This Form
To complete this form, follow these steps:

1.  Enter your name and email address to be contacted for any further information.
2.  Choose the analytics access level required (High or Low).
3.  Select the data scope needed for your work.
4.  Specify the date and time you'd like to access the data.
5.  Add any additional comments about your request.

## Field-by-Field Explanation
### User Name
*   **User Name** (`user_name`, `text`, Optional): Enter your name as you'd like to be addressed for any further communication about your request.

### Email
*   **Email** (`email`, `email`, Optional): Enter your email address so we can contact you for further information or clarification.

### Phone Number
*   **Phone** (`phone`, `text`, Optional): If you'd like to be contacted by phone, please enter your phone number.

### Analytics Access Level 1
*   **Analytics Access Level 1** (`analytics_access_level_1`, `select_one`, Optional): Choose "High" for high-level analytics access or "Low" for basic analytics access.

### Analytics Access Level 2
*   **Analytics Access Level 2** (`analytics_access_level_2`, `select_one`, Optional): Select "High" for high-level analytics access or "Low" for basic analytics access.

### Data Scope 1
*   **Data Scope 1** (`data_scope_1`, `select_multiple`, Optional): Select "Yes" to access course-level data or "No" to access program-level data.

### Data Scope 2
*   **Data Scope 2** (`data_scope_2`, `select_multiple`, Optional): Select "Yes" to access module-level data or "No" to access system-level data.

### Request Date
*   **Request Date** (`request_date`, `date`, Optional): Specify the date you'd like to access the data.

### Request Time
*   **Request Time** (`request_time`, `time`, Optional): Specify the time you'd like to access the data.

### Request Comments
*   **Request Comments** (`request_comments`, `text`, Optional): Add any additional comments about your request.

## Tips

*   Please ensure that you have a valid reason for requesting analytics access and that the request is in line with your job responsibilities.
*   Be aware that access requests are reviewed and approved by administrators, and it may take some time to process your request.
*   If you're unsure about any aspect of the form or the analytics access process, feel free to ask for clarification.
