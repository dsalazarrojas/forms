# Open Learning Resource Contribution Request Form - Help Guide
## Purpose
This form is used to collect information from contributors who want to share their learning resources with the platform.

## How To Complete This Form

1. Review the form carefully to ensure you understand what information is being requested.
2. Fill out the form with accurate and detailed information about the resource you want to contribute.
3. Submit the form to request that the resource be evaluated and potentially published on the platform.

## Field-by-Field Explanation

* **Form Submit**:
	+ Type: text
	+ Required: No
	+ Description: Enter a brief description of your resource submission.
* **Resource Category**:
	+ Type: select_multiple
	+ Required: No
	+ Description: Select all applicable categories that describe your resource. For example, if your resource is a video, select "Video" and "Educational Resource."
* **Resource Type**:
	+ Type: select_one
	+ Required: No
	+ Description: Select "Yes" if your resource is an educational resource, "No" otherwise.
* **Resource License**:
	+ Type: select_multiple
	+ Required: No
	+ Description: If you're licensing your resource under a specific license, select it. For example, if you're using a Creative Commons license, select "Creative Commons."
* **License Notes**:
	+ Type: text
	+ Required: No
	+ Description: Provide any additional information about the license you've selected.
* **Resource Language**:
	+ Type: select_one
	+ Required: No
	+ Description: Select the language of your resource. For example, if your resource is in English, select "English."
* **Resource Level**:
	+ Type: select_one
	+ Required: No
	+ Description: Select the level of difficulty of your resource. For example, if your resource is suitable for beginners, select "High."
* **Resource Tags**:
	+ Type: select_multiple
	+ Required: No
	+ Description: Select all applicable tags that describe your resource. For example, if your resource is for math students, select "Math."
* **Contributor Info**:
	+ Type: text
	+ Required: No
	+ Description: Provide your name and any other relevant information about yourself as a contributor.
* **Submission Date**:
	+ Type: date
	+ Required: No
	+ Description: Enter the date when you're ready for your resource to be reviewed.
* **Submission Time**:
	+ Type: time
	+ Required: No
	+ Description: Enter the time when you're ready for your resource to be reviewed.
* **Submitter Info**:
	+ Type: text
	+ Required: No
	+ Description: Provide your name and any other relevant information about yourself as the submitter.
* **Submitter Email**:
	+ Type: email
	+ Required: No
	+ Description: Enter your email address.
* **Submitter Phone**:
	+ Type: text
	+ Required: No
	+ Description: Enter your phone number.
* **Submitter Notes**:
	+ Type: text
	+ Required: No
	+ Description: Enter any additional information you want to provide about yourself as the submittter.
* **Submitter Comments**:
	+ Type: text
	+ Required: No
	+ Description: Enter any comments or suggestions you have about the submission process.
* **Submission Confirmation**:
	+ Type: text
	+ Required: No
	+ Description: Enter "yes" to confirm your submission.
* **Form Confirmation**:
	+ Type: text
	+ Required: No
	+ Description: Enter "yes" to confirm that you've reviewed and understood the form. 

This form is intended to help you, as a contributor, to share your learning resources with the platform. Fill it out carefully and accurately to increase the chances of your resource being evaluated and published on the platform.
