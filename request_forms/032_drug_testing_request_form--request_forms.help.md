# drug_testing_request_form - Help Guide
## Purpose

This form is used to document information about drug testing requests. It is intended for employees who are required to undergo a drug test.

## How To Complete This Form

1. Fill out the form completely and accurately, ensuring that all required fields are completed.
2. If you are unsure about any part of the form, please consult with your supervisor or human resources representative.

## Field-by-Field Explanation

* **Employee Name** (`Employee Name`, text, optional): Enter the name of the employee undergoing the test.
* **Employee ID** (`Employee ID`, number, optional): Enter the employee's ID number, if applicable.
* **Test Type** (`Test Type`, select, optional): Select the type of test being conducted. Options include:
	+ Random Oral Test
	+ Pre-employment Test
	+ Random Urine Test
	+ Post-accident Test
	+ Return-to-work Test
	+ Other (please specify)
* **Test Date** (`Test Date`, date, optional): Enter the date of the test.
* **Test Time** (`Test Time`, time, optional): Enter the time of the test.
* **Authorized By** (`Authorized By`, text, optional): Enter the name of the person authorizing the test.
* **Date Tested** (`Date Tested`, date, optional): Enter the date the test was administered.
* **Time Tested** (`Time Tested`, time, optional): Enter the time the test was administered.
* **Test Employer** (`Test Employer`, text, optional): Enter the name of the test employer, if applicable.
* **Test Result** (`Test Result`, text, optional): Enter the result of the test.
* **Other Test Type** (`Other Test Type`, text, optional): If "Other" is selected for Test Type, please enter a brief description of the test type.
* **Test Note** (`Test Note`, note, optional): Enter any additional notes about the test.
* **Email** (`Email`, email, optional): Enter the employee's email address.
* **Phone** (`Phone`, text, optional): Enter the employee's phone number.
* **Department** (`Department`, text, optional): Enter the employee's department or work location.
* **Job Title** (`Job Title`, text, optional): Enter the employee's job title.
