# Network Connection Request Form - Help Guide

## Purpose
This form is designed to gather information from users to process their network connection requests efficiently and correctly.

## How To Complete This Form
To complete this form, follow the steps below:

1. Fill in your first and last name in the **First and last name** field.
2. Enter your email address in the **Email** field.
3. Select your user type from the **User type** dropdown menu.
4. Choose the department you belong to from the **Department** dropdown menu.
5. Select the type of network access you need from the **Network type** dropdown menu.
6. Enter the time you would like to have access to the network from the **Access time** field.
7. Choose the date you would like to have access to the network from the **Access date** field.
8. Provide a brief description of your request in the **Description** field.
9. Enter the name of your manager in the **Manager name** field.
10. Enter your manager's email address in the **Manager email** field.

## Field-by-Field Explanation
* **First and last name** (`user_info`, text, optional): Enter your first and last name to help us identify you.
* **Email** (`email`, email, optional): Enter your email address so we can contact you about your request.
* **User type** (`user_type`, select_one, optional):
	+ **User**: Select this option if you are a regular user.
	+ **IT-User**: Select this option if you are an IT user.
	+ **Guest**: Select this option if you are a guest user.
* **Department** (`department`, select_multiple, optional): Choose the department you belong to from the list.
* **Network type** (`network_type`, select_one, optional):
	+ **Local**: Select this option if you need access to a local network.
	+ **Remote**: Select this option if you need access to a remote network.
	+ **VPN**: Select this option if you need access to a VPN connection.
* **Access time** (`access_time`, time, optional): Enter the time you would like to have access to the network in 24-hour format (HH:MM).
* **Access date** (`access_date`, date, optional): Choose the date you would like to have access to the network.
* **Description** (`description`, note, optional): Provide a brief description of your request.
* **Manager name** (`manager_name`, text, optional): Enter the name of your manager.
* **Manager email** (`manager_email`, email, optional): Enter your manager's email address.
