# Security Camera Review Request Form - Help Guide
## Purpose
This form is designed to collect information from users about a security camera review request. This information will be reviewed by the security team to determine the appropriate course of action.

## How To Complete This Form
- To start, please fill out all required fields (though most fields are optional).
- For each field, please provide as much detail as possible.
- Once you have completed the form, click the submit button to send it to the security team for review.

## Field-by-Field Explanation
- **Incident Details** (`incident_details`, text, optional): This field is for providing a brief description of the incident you are reporting. Try to be as clear and concise as possible.
- **Supporting Files** (`supporting_files`, text, optional): If you have any files (e.g., images, videos, or screenshots) that support your report, please attach them here.
- **Security Team** (`security_team`, select_multiple, optional): Select all relevant security teams that should be notified about this incident. Note that this is a multiple-choice field.
- **File Upload** (`file_upload`, text, optional): If you have any files that do not fit in the "Supporting Files" field, you can upload them here.
- **Date of Incident** (`date_of_incident`, date, optional): Enter the date of the incident, in the format MM/DD/YYYY.
- **Time of Incident** (`time_of_incident`, time, optional): Enter the time of the incident, in the format HH:MM:SS.
- **Security Camera Location** (`security_camera_location`, text, optional): Describe the exact location where the security camera is located.

## Tips
- Make sure to check for any existing reports related to the incident you are reporting.
- If the incident is still ongoing, try to provide as much information as possible about what is happening.
- If you have any concerns or questions, do not hesitate to contact the security team for assistance.
