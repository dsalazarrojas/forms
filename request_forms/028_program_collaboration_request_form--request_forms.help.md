# Program Collaboration Request Form - Help Guide

## Purpose
This form is used to request collaboration on a program. It captures essential information about the program, its objectives, timelines, and review status. The form is designed to facilitate smooth collaboration between stakeholders and project team members. 

## How To Complete This Form
To complete this form, please follow these steps:

1. Provide a title for the program.
2. Select the collaboration type (e.g., Collaboration Type 1, Collaboration Type 2, Collaboration Type 3).
3. Briefly describe the objectives of the program.
4. Enter the expected timelines for the program.
5. Select the current review status (e.g., Review Status 1, Review Status 2, Review Status 3).
6. Add any additional comments about the program.
7. Enter your email address.
8. Enter your phone number.

## Field-by-Field Explanation

* **General Info** (`general_info`, text, optional): Enter a brief title for the program.
* **Collaboration Type** (`collaboration_type`, select_one, optional): Select the type of collaboration required for the program (e.g., Collaboration Type 1, Collaboration Type 2, Collaboration Type 3).
* **Objectives** (`objectives`, text, optional): Describe the main goals and objectives of the program.
* **Timelines** (`timelines`, date, optional): Enter the expected start and end dates for the program.
* **Review Status** (`review_status`, select_one, optional): Select the current status of the program's review (e.g., Review Status 1, Review Status 2, Review Status 3).
* **Comments** (`comments`, note, optional): Add any additional information or comments about the program.
* **Email** (`email`, email, optional): Enter your email address for communication purposes.
* **Phone** (`phone`, text, optional): Enter your phone number for communication purposes.

## Tips
* Please make sure to provide a clear and concise title for the program.
* Select the most relevant collaboration type for the program.
* Enter a realistic timeline for the program.
* Select the current review status accurately.
* Add any additional comments or information that may be helpful for the project team.
* Ensure that your email and phone numbers are correct and up-to-date.
