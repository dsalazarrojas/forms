# Software Engineer Technical Interview Q&A Guide Request Form - Help Guide
## Purpose

This form is used to create new Request Forms, which are guides to help software engineers prepare for technical interviews. Fill out this form to request a new Request Form with a title, category, description, and other details.

## How To Complete This Form

1. Fill out the form title to briefly describe the guide you want to create.
2. Select a category for the guide (e.g., "Request Forms").
3. Provide a detailed description of the guide you want to create.
4. Enter a unique title for the guide (if different from the previous field).
5. Enter a second unique title for the guide (if needed).
6. Identify the tool assigned for the guide (if applicable).
7. Specify the output file for the guide.
8. (Optional) Date and time the request was made.
9. (Optional) Date and time the request was updated.
10. Unique form ID (not to be filled out by users).

## Field-by-Field Explanation

* **Form Title**: (`form_title`, text, required: false)
    Enter a brief title for the guide you want to create.
* **Category**: (`category`, select_one, required: false)
    Select a category for the guide (e.g., "Request Forms").
* **Description**: (`description`, text, required: false)
    Provide a detailed description of the guide you want to create.
* **Form Title 2**: (`form_title2`, text, required: false)
    Enter a second unique title for the guide (if needed).
* **Form Title 3**: (`form_title3`, text, required: false)
    Enter a third unique title for the guide (if needed).
* **Assigned Tool**: (`assigned_tool`, text, required: false)
    Identify the tool assigned for the guide (if applicable).
* **Form Output File**: (`form_output_file`, text, required: false)
    Specify the output file for the guide.
* **Created At**: (`created_at`, date, required: false)
    Date and time the request was made (optional).
* **Updated At**: (`updated_at`, date, required: false)
    Date and time the request was updated (optional).
* **Form ID**: (`form_id`, number, required: false)
    Unique ID for the guide (not to be filled out by users).
