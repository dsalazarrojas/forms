# Family Portal Access Request - Help Guide
## Purpose
The Family Portal Access Request form is used to request access to a secure family portal for your student. This form is used to gather information about the student and the family member making the request.

## How To Complete This Form
1. Fill out the form completely and accurately.
2. Make sure to provide the required fields (marked as required).
3. For optional fields, provide as much information as possible if relevant.
4. Review the form carefully before submission.

## Field-by-Field Explanation
- **Family Portal Access Request** (`family_portal_access_request_form`, text, required): This field is where you can type in your request for access to the family portal. Be as clear and concise as possible about why you need access.
- **Guardian First Name** (`guardian_first_name`, text, optional): Enter the first name of the guardian or parent making the request.
- **Guardian Last Name** (`guardian_last_name`, text, optional): Enter the last name of the guardian or parent making the request.
- **Guardian Email** (`guardian_email`, email, optional): Enter the email address of the guardian or parent making the request.
- **Student ID** (`student_id`, number, optional): Enter the student ID number (if applicable).
- **Student Name** (`student_name`, text, optional): Enter the name of the student associated with this request.
- **School Year** (`school_year`, select_one, optional): Select the school year the student is currently in (if applicable). This will help us determine which school resources are available to you.
- **Reason for Request** (`reason_for_request`, text, optional): Enter a brief description of why you are requesting access to the family portal.
- **School Name** (`school_name`, text, optional): Enter the name of the school the student attends (if applicable).
- **Teacher Name** (`teacher_name`, text, optional): Enter the name of the student's teacher (if applicable).
- **Department** (`department`, select_multiple, optional): Select which departments or resources you are requesting access to. This could be multiple departments.
- **Teacher Email** (`teacher_email`, email, optional): Enter the teacher's email address (if applicable).
- **Parent Email** (`parent_email`, email, optional): Enter the email address of the parent or guardian making the request.
- **Student Grade** (`student_grade`, select_one, optional): Select the student's grade level (if applicable).
- **Request Status** (`request_status`, select_one, optional): Select the status of the request (Active or Inactive).
- **Request Date** (`request_date`, date, optional): Enter the date the request was made (if applicable).

Note: Some fields may have specific options to choose from, select the ones that apply to your situation.
