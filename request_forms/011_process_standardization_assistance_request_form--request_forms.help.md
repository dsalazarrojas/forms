# Process Standardization Assistance Request Form - Help Guide
## Purpose
This form is used to request assistance with standardizing processes. You can fill it out to seek help from experts in process standardization, process improvement, or change management.
## How To Complete This Form
To complete this form, follow these steps:
1. Select the request type that best suits your needs: "Standardization", "Improvement", or "Change Management". This will help us understand the scope of your request.
2. Describe your goal in the "Goal" field. This is where you can provide a brief description of what you aim to achieve.
3. Optionally, indicate your urgency level by selecting or entering a number in the "Urgency" field.
4. If your request involves operational changes, select all relevant options from the "Operational Change" field. This field allows you to choose "Process Optimization", "Process Standardization", or "Change Management".
5. If your operational change doesn't fit any of the provided options, describe it in the "Operational Change Other" field. This is where you can provide additional information.
## Field-by-Field Explanation
* **Request Form (Page 1)**: A text box where you can describe your request.
* **Request Type (Page 2)**: Select the type of request you need help with:
	+ "Standardization": Standardize or establish consistent processes.
	+ "Improvement": Improve existing processes to make them more efficient.
	+ "Change Management": Manage changes to existing processes.
* **Goal (Page 2)**: A brief description of what you aim to achieve with your request.
* **Urgency (Page 3)**: Indicate how urgently you need assistance. You can select a number or leave this field empty for standard processing.
* **Operational Change (Page 4)**: If your request involves operational changes, select all relevant options:
	+ "Process Optimization": Optimize existing processes.
	+ "Process Standardization": Standardize or establish consistent processes.
	+ "Change Management": Manage changes to existing processes.
* **Operational Change Other (Page 5)**: If your operational change doesn't fit any of the provided options, describe it here.
## Tips
* Be as specific as possible when filling out the form to ensure we understand your request correctly.
* If you're unsure about any field, ask your supervisor or the process standardization team for guidance.
* Please note that this form is for requesting assistance, not for submitting changes directly. We'll review and respond to your request accordingly.
