# phone_call_request_form - Help Guide
## Purpose
The phone call request form is a tool for users to request a phone call from a support staff member. It is used to capture necessary information to facilitate the call and ensure that the support staff member has all the necessary details before the call.

## How To Complete This Form
To complete this form, simply fill in the required and optional fields as instructed:

1. Enter a title for your request in the "Phone Call Request Form" field.
2. Select the category of your request from the "Category" dropdown menu.
3. Provide a brief description of your request in the "Description" field.
4. If applicable, specify the tool or application that is related to your request in the "Assigned Tool" field.
5. If you would like to receive the call details in a specific file format, select the desired output file type from the "Output File" field.

## Field-by-Field Explanation
* **Phone Call Request Form** (`phone_call_request_form`, text, required): Enter a brief title for your phone call request.
* **Category** (`category`, select_one, required): Select the category of your request from the options provided. This will help us understand the nature of your inquiry.
* **Description** (`description`, text, required): Provide a clear and concise description of your request. This will ensure that the support staff member is well-prepared for the call.
* **Assigned Tool** (`form_assigned_tool`, text, optional): If your request is related to a specific tool or application, please specify it here. This will help the support staff member understand the context of your request.
* **Output File** (`output_file`, text, optional): If you would like to receive the call details in a specific file format, such as PDF or CSV, select it from the options provided. This will allow you to easily reference the call details later on.
