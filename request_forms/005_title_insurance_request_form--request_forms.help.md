# Title Insurance Request Form - Help Guide
## Purpose
The Title Insurance Request Form is used to collect information from users regarding title insurance requests. This form is essential to ensure that all relevant details are captured accurately, allowing for efficient processing and handling of the request.

## How To Complete This Form
1. Fill out the form with accurate and complete information.
2. Ensure that all required fields are filled out.

## Field-by-Field Explanation
* **User Name (text, required)**: Enter your full name as it appears on your identification.
* **Email (email, required)**: Enter your official email address for communication purposes.
* **Property Type (select multiple, optional)**: If applicable, select the types of properties associated with this request.
* **Transaction Type (select one, required)**: Select whether this is a new or existing transaction.
* **Document Shipment (select one, required)**: Select whether you need the documents to be shipped.
* **Property Address (text, optional)**: Enter the property address if applicable.
* **Loan Amount (number, required)**: Enter the loan amount for the property.
* **Loan Date (date, required)**: Enter the date of the loan.
* **Shipment Type (select one, required)**: Select the type of shipment required.
* **Notes (note, optional)**: Enter any additional comments or instructions related to your request.
* **Phone (text, required)**: Enter your contact phone number for communication purposes.
