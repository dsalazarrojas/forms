# Spi Waterpark Maintenance Request Form - Help Guide
## Purpose
The Spi Waterpark Maintenance Request Form is designed to gather information about maintenance requests from users. Please only submit a request if you have a legitimate maintenance issue that requires attention.

## How To Complete This Form
To complete the form, follow these steps:
1. Fill out all required fields (indicated by **required: true**).
2. Enter your name and contact information in the corresponding fields.
3. Select the date and time you would like the maintenance to take place.
4. Provide your phone number so we can contact you to confirm the request.
5. Specify the location where the maintenance is needed.
6. Briefly describe the maintenance issue in the description field.

## Field-by-Field Explanation
* **name** (text, required: true): Enter your name so we can contact you about your maintenance request.
* **date** (date, required: false): Select the date you would like the maintenance to take place.
* **time** (time, required: false): Select the time you would like the maintenance to take place.
* **phone** (text, required: false): Enter your phone number so we can contact you to confirm your request.
* **location** (text, required: false): Specify the location where the maintenance is needed.
* **description** (text, required: false): Briefly describe the maintenance issue.
