# Schedule Change Request Form - Help Guide
## Purpose
The "Schedule Change Request Form" is used to submit a schedule change request to the relevant department.

## How To Complete This Form
To complete this form, follow these steps:
1. Select the teacher responsible for the schedule change from the "Teacher" field.
2. Enter the relevant student's name in the "Student" field.
3. Provide a clear and concise description of the schedule change request in the "Schedule Change Request Details" field.
4. Review and submit the form.

## Field-by-Field Explanation
* **Teacher** (`teacher`, select_one, required/optional): Select the teacher who is responsible for the schedule change.
* **Student** (`student`, text, required/optional): Enter the name of the student affected by the schedule change.
* **Schedule Change Request** (`schedule_change_request`, text, required/optional): Provide a clear and concise description of the schedule change request.
* **Schedule Change Request Details** (`schedule_change_request_details`, text, required/optional): Provide a detailed description of the schedule change request.
