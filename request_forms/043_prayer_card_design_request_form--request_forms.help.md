# prayer_card_design_request_form - Help Guide
## Purpose
The "prayer_card_design_request_form" is a form used to collect details for creating a custom prayer card. This form helps us to understand the specific needs and requests of the individual or event.

## How To Complete This Form
To complete this form, please follow the instructions below:
1. Select the correct options for each field as needed.
2. Fill in all required fields (marked as **Required**).
3. You can upload files if necessary.
4. Once you have completed all fields, click the **Submit** button.

## Field-by-Field Explanation

* **Church Name** (`church_name`, `text`, **Required**): Enter the name of the church making the request.
* **First Name** (`first_name`, `text`, **Required**): Enter the first name of the person receiving the card.
* **Last Name** (`last_name`, `text`, **Required**): Enter the last name of the person receiving the card.
* **City** (`city`, `text`, **Required**): Enter the city where the card will be delivered.
* **Zip/Postal Code** (`zip`, `number`, **Required**): Enter the zip code where the card will be delivered.
* **Phone Number** (`phone`, `text`, **Required**): Enter the phone number to contact the family.
* **Email** (`email`, `email`, **Optional**): Enter the email to contact the family.
* **Special Requests** (`special_requests`, `text`, **Required**): Enter any special requests or instructions for the card.
* **Date of Need** (`date`, `date`, **Required**): Enter the date the cards are required by.
* **Time of Death** (`time_of_death`, `time`, **Required**): Enter the time of death (HH:MM).
* **Number of Prayer Cards Wanted** (`prayer_cards_wanted`, `number`, **Required**): Enter the number of cards required.
* **Message to be Included** (`message_for_the_family`, `select_one`, **Optional**): Choose a pre-defined message to be included in the card.
	+ **Funeral Information**
	+ **Service Information**
	+ **Biographical Information**
	+ **Photo**
	+ **Other**
* **Other (please specify)** (`other_message`, `text`, **Optional**): Enter any other message you would like to be included.
* **File Upload** (`upload_file`, `select_multiple`, **Optional**): You can upload a photo or video file for the card.
* **Upload File (Other)** (`upload_other`, `text`, **Optional**): Select the type of file to be uploaded (Photo or Video).
* **Type of File** (`upload_other_type`, `text`, **Optional**): Enter the description of the file to be uploaded.
* **Size of File** (`upload_other_size`, `text`, **Optional**): Enter the size of the file to be uploaded.
* **Upload File** (`upload_other_file`, `text`, **Optional**): Enter the file to be uploaded.
* **Submit** (`submit`, `text`, **Required**): Click the **Submit** button to complete the form.

Note: Some fields are marked as **Required**, please ensure they are filled out correctly for accurate processing.
