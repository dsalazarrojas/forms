# Independent Contractor Request Form - Help Guide

## Purpose
The Independent Contractor Request Form is a tool used to create and manage requests for independent contractors. This form will help gather necessary information about contractors and their projects. 

## How To Complete This Form
To complete this form, follow these steps:
- Fill out the form with the required and optional fields as instructed.
- Ensure that the Client Name, Project Name, and Start Date fields have accurate and up-to-date information.
- Review each field carefully before submitting the form.

## Field-by-Field Explanation
- **Client Name (text, required: false)**: Enter the name of the client for whom the project is being requested.
- **Project Name (text, required: false)**: Enter the name of the project.
- **Start Date (date, required: false)**: Enter the start date of the project.
- **End Date (date, required: false)**: Enter the end date of the project.
- **Location (text, required: false)**: Enter the location where the project will be conducted.
- **Job Type (select_one, required: false)**: Select whether the project is 'Yes' or 'No' depending on whether it is an independent contractor job.
- **Job Description (text, required: false)**: Enter a brief description of the job.
- **Client Email (email, required: false)**: Enter the client's email address.
- **Client Phone (text, required: false)**: Enter the client's phone number.
- **Contractor Name (text, required: false)**: Enter the name of the independent contractor.
- **Contractor Email (email, required: false)**: Enter the independent contractor's email address.
- **Contractor Phone (text, required: false)**: Enter the independent contractor's phone number.
- **Project Status (select_one, required: false)**: Select the status of the project as 'Active' or 'Inactive'.
- **Job Status (select_one, required: false)**: Select the status of the job as 'Active' or 'Inactive'.

Note: Some fields are required while others are optional, ensure you understand which ones are mandatory and which ones are not before submitting the form.
