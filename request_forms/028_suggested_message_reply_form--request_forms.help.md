# Suggested Message Reply Form - Help Guide
## Purpose
This form is designed to help customer service representatives create a suggested message reply to a customer based on their preferences. The form allows selecting the message reply type and personalization options.

## How To Complete This Form
1. Click on the "Suggested Message Reply Form" button to access the form.
2. Fill in the required fields as prompted.
3. Customize the message using the options available in the form.

## Field-by-Field Explanation

* **Suggested Message Form** (`suggested_message_reply_form`): Enter a brief message to be sent to the customer.
* **Customer Message** (`customer_message`): Enter a message to be included in the reply. This field is optional.
* **Customer Name** (`customer_name`): Enter the name of the customer to be included in the reply.
* **Message Preferences** (`message_preferences`): Select multiple options for personalizing the message. Options include "Option 1", "Option 2", and "Option 3".
* **Reply Subject** (`reply_subject`): Enter a brief subject for the reply.
* **Reply Body** (`reply_body`): Enter a detailed message to be sent to the customer. This field is optional.
* **Preferred Contact Method** (`preferred_contact_method`): Select how the reply should be sent to the customer, e.g. "Email", "Phone", or "Text".
* **Send Reply** (`send_reply`): Indicate whether to send the reply to the customer. Options include "True" and "False".
* **Preferred Language** (`preferred_language`): Select the language of the reply, e.g. "English", "Espanol", or "Francais". This field is optional, but if left blank, the language will default to "English".
* **Other Language** (`other_language`): Enter a language other than the options listed, if desired.
* **Flag for Duplicate** (not visible in the form): Set a flag to indicate whether a reply is already being processed or has been sent. 

This flag is used internally to prevent duplicate responses and should be set to "Yes" to indicate that the reply is already being processed or has been sent, and "No" otherwise.
