# Signage Direction Update Request Form - Help Guide

## Purpose
The purpose of this form is to request an update to a signage's direction at a specified location. This form is used to ensure that the signage is correctly aligned with the direction of the surrounding environment.

## How To Complete This Form
To complete this form, follow these steps:
1. Fill in the "Request Details" section with a brief description of the request.
2. Select the correct "Signage Location" from the provided options.
3. If you are uploading a photo of the signage, enter the number of the photo in the "Signage Photo" field.
4. Choose the correct direction for the signage from the "Direction" field (select multiple options if necessary).
5. Select the level of urgency for the update from the "Urgency" field.
6. Provide additional comments in the "Comments" field (optional).
7. Select the user assigned to the request from the "Assigned User" field.

## Field-by-Field Explanation

* **Request Details (1)**: A short description of the request. Please provide a brief explanation of the signage's direction update request.
* **Signage Location (2)**: The location of the signage to be updated. This is a required field and should be selected carefully.
* **Signage Photo (3)**: An optional photo of the signage to be updated. If you have a photo, enter the photo number. This field is not required.
* **Direction (4)**: The direction of the signage. Select the correct direction from the options: North, South, East, West.
* **Urgency (5)**: The level of urgency for the direction update. Select High, Medium, or Low depending on the situation.
* **Update Details (6)**: Additional information about the request. This field is optional and can be used to provide more context.
* **Comments (7)**: Any additional comments about the request. This field is optional and can be used to provide more information.
* **Assigned User (8)**: The user assigned to complete the signage direction update. This field is required and should be selected carefully.
