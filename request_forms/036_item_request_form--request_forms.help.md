# Item Request Form - Help Guide
## Purpose
This form is designed to collect information from storekeepers about items they need or are currently missing. The form is used to track and manage these requests, ensuring that they are processed and fulfilled in a timely manner.

## How To Complete This Form

1. Fill out the form completely and accurately to ensure that your request is processed correctly.
2. Enter a brief description of the item you are requesting.
3. Specify the item number if applicable.
4. Provide the storekeeper's name and email address for communication.
5. Enter the storekeeper's phone number for additional contact information.
6. Select the status of the item (available or unavailable).
7. Add any comments or notes regarding the item or the request.
8. Enter any comments from the procurement officer regarding the request.
9. Set the date and time of submission.
10. Select the tool assigned to the item (e.g., "chatjimmy" or "Other").

## Field-by-Field Explanation

* **Item Request**: This is the main field where you enter the name of the item you are requesting.
* **Item Description**: A brief description of the item you are requesting.
* **Item Number**: If the item has a specific number assigned to it, enter it here.
* **Storekeeper Name**: Enter the name of the storekeeper submitting the request.
* **Storekeeper Email**: Enter the storekeeper's email address for communication.
* **Storekeeper Phone**: Enter the storekeeper's phone number for additional contact information.
* **Item Status**: Select "Item Available" if the item is available, "Item Unavailable" if it is not.
* **Storekeeper Comments**: Add any comments or notes regarding the item or the request.
* **Procurement Officer Comments**: Add any comments or notes from the procurement officer regarding the request.
* **Submit Date**: Enter the date you are submitting the request.
* **Submit Time**: Enter the time you are submitting the request.
* **Assigned Tool**: Select the tool assigned to the item (e.g., "chatjimmy" or "Other").
