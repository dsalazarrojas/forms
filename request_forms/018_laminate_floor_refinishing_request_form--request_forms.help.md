# Laminate Floor Refinishing Request Form - Help Guide
## Purpose
The purpose of this form is to request laminate floor refinishing services for a property. It collects essential information from the property manager to schedule and perform the service efficiently.

## How To Complete This Form
- Read this guide carefully to understand each field's importance.
- Fill out the form accurately and honestly, providing all necessary information.
- Ensure you submit the form only once to avoid duplication.

## Field-by-Field Explanation

* **Form Information (1)**: This field is required to provide a brief description of the service requested.
* **Property Information (2)**: Please provide a clear and concise description of the property, including its location.
* **Laminate Floor (3)**: Specify the laminate floor type that needs refinishing.
* **Evaluation Visit (4)**: Select 'Yes' if the team needs to visit your property for evaluation before performing the service.
* **Schedule Visit (5)**: Select a date and time for the refinishing service visit.
* **Collection Date (6)**: Enter the date when the data collection will be done.
* **Data Collection (7)**: Select 'Yes' if you need data collection during the service.
* **Contractor Information (8)**: Provide the contractor's name and contact details if you have already engaged one.
* **Property Manager (9)**: Specify the property manager's name and contact information.
* **Contact Information (10)**: Enter your contact name and phone number for follow-up.
* **Notes (11)**: Add any additional comments or requests about the service.
* **Email (12)**: Enter a valid email address for communication purposes.
* **Confirm Visit (13)**: Select 'Yes' if you confirm the service visit on the scheduled date.
* **Confirm Date (14)**: Select 'Yes' if you confirm the collection date.
* **Confirm Collection (15)**: Select 'Yes' if you confirm data collection during the service.

Note: Please fill in all required fields to ensure accurate and efficient service scheduling and communication.
