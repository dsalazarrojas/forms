# Family Toy Request Form - Help Guide

## Purpose

This form is used to collect information from family members to request toys for a family event or activity.

## How To Complete This Form

1. Fill out the form with your name, address, and contact information.
2. Select the category for your toy request (e.g. "Toy", "Game", "Activity").
3. Provide any additional information about your request.
4. Choose a status for your request (e.g. "Pending", "Approved", "Denied").

## Field-by-Field Explanation

* **Family Toy Request Form Input**:
	+ A text field where you can enter any information about your toy request.
* **Family Toy Request Form Input**:
	+ Another text field where you can enter any additional information about your request.
* **Family Toy Request Form Submit**:
	+ A text field where you can confirm your submission of the form.
* **Additional Information**:
	+ A text field where you can provide any additional details about your request.
* **Date**:
	+ A date field where you can select the date you would like to request a toy for.
* **Time**:
	+ A time field where you can select the time you would like to request a toy for.
* **Category**:
	+ A dropdown menu where you can select the category for your toy request.
	+ Options: "Toy", "Game", "Activity".
* **Additional info**:
	+ A text field where you can provide any additional information about your request.
* **Requestor Email**:
	+ An email field where you can enter your email address.
* **Requestor Phone**:
	+ A text field where you can enter your phone number.
* **Requestor Address**:
	+ A text field where you can enter your address.
	+ (Required)
* **Requestor Name**:
	+ A text field where you can enter your name.
	+ (Required)
* **Request Date**:
	+ A date field where you can select the date you would like to request a toy for.
* **Request Time**:
	+ A time field where you can select the time you would like to request a toy for.
* **Status**:
	+ A dropdown menu where you can select the status of your request.
	+ Options: "Pending", "Approved", "Denied".
	+ (Required)

## Tips

* Please ensure that you are providing accurate and complete information to avoid any delays or issues with toy distribution.
* If you have already submitted a request for the same event, you will be notified and asked to review and update your previous request instead of submitting a new one.
