# Decision Support Referral And Authorization Request Form - Help Guide

## Purpose
This form is designed to collect information from the referral requester regarding a referral request, including their name, email, phone number, department, and authorization details. The form also requires the input of the authorized doctor's name, department, education, and status.

## How To Complete This Form
1. Select "I agree" if you consent to the terms and conditions.
2. Indicate if a referral request is being made.
3. Enter the patient's name.
4. Enter the patient's name again (for verification purposes).
5. Enter the referral requester's name.
6. Enter the referral requester's email address.
7. Enter the referral requester's phone number.
8. Select whether the referral requester is from a department.
9. Enter the referral requester's title.
10. Select whether the referral requester is authorized.
11. Select whether the referral requester's department is authorized.
12. Select whether the referral requester's department has any facilities.
13. Select whether the referral requester has any education qualifications.
14. Select whether the referral requester has any work experience.
15. Select whether the referral requester has any licensing qualifications.
16. Select whether the referral requester has any specialties.
17. Select which languages the referral requester can communicate in.
18. Enter the authorized doctor's name.
19. Select whether the authorized doctor's department is authorized.
20. Select whether the authorized doctor has any education qualifications.
21. Select the authorized doctor's location.
22. Enter the authorized doctor's status.
23. Select whether the referral requester is authorized.
24. Select whether the referral requester's department is authorized.
25. Enter the referral requester's authorized title.
26. Select which languages the referral requester can communicate in.
27. Select whether the authorized doctor has any licensing qualifications.
28. Select whether the authorized doctor's department has any education qualifications.
29. Enter the authorized doctor's location.
30. Enter the authorized status.
31. Select whether the referral requester is authorized in terms of education.
32. Select whether the referral requester's department is authorized.
33. Enter the referral requester's authorized title.
34. Select which languages the referral requester can communicate in.
35. Select whether the authorized doctor has any licensing qualifications.
36. Select whether the authorized doctor's department has any education qualifications.
