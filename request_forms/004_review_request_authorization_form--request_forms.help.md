# Review Request Authorization Form - Help Guide
## Purpose
The Review Request Authorization Form is designed to standardize and streamline the review request process within your organization. It collects necessary information from submitters, reviewers, and approvers to facilitate effective communication and decision-making.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill out the submitter's information (Request Form) with accurate details.
2. Enter the Reviewer's Name, Email, and Phone number.
3. Provide a Brief description of the request.
4. Specify the Request Deadline.
5. Enter the Approver's Name and Department.
6. Select the Review Request Status (Approved, Rejected, In Progress).
7. Add any additional Review Request Notes.

## Field-by-Field Explanation

* **Request Form (`request_form`)**: Enter the submitter's name, email, and phone number.
* **Reviewer Name (`reviewer_name`)**: Enter the name of the person reviewing the request.
* **Reviewer Email (`reviewer_email`)**: Enter the email address of the person reviewing the request.
* **Reviewer Phone (`reviewer_phone`)**: Enter the phone number of the person reviewing the request.
* **Reviewer Department (`reviewer_department`)**: Enter the department of the person reviewing the request.
* **Request Description (`request_description`)**: Provide a brief description of the request.
* **Request Deadline (`request_deadline`)**: Specify the deadline for the review request.
* **Approver Name (`approver_name`)**: Enter the name of the person approving the request.
* **Approver Department (`approver_department`)**: Enter the department of the person approving the request.
* **Review Request Date (`review_request_date`)**: Enter the date the review request was made.
* **Review Request Status (`review_request_status`)**: Select the status of the review request (Approved, Rejected, In Progress).
* **Review Request Notes (`review_request_notes`)**: Enter any additional comments or notes about the review request.
