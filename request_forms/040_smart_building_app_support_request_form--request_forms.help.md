# Smart Building App Support Request Form - Help Guide
## Purpose
The Smart Building App Support Request Form is designed to gather information from users about their experience with the app. The form is intended to collect data about any issues or problems users are experiencing with the app, so that the support team can assist them in resolving these issues.

## How To Complete This Form

To complete this form, follow these steps:

1. Enter your contact information, including your name, email address, and phone number.
2. Describe the problem you are experiencing with the app in the description field.
3. Indicate whether you are running the latest app version.
4. If necessary, upload a screenshot or other file that demonstrates the issue.
5. Specify the type of request you are making (e.g. "Yes" for a bug report).
6. Enter the date and time you encountered the issue.
7. If you have any additional information or context about the issue, you can enter it in the Error Message field.
8. Finally, submit the form to send your request to the support team.

## Field-by-Field Explanation

* **Contact Information** (1): Enter your name, email address, and phone number so that we can contact you to discuss your issue.
* **Description** (2): Describe the problem you are experiencing with the app in as much detail as possible.
* **Problem** (3): If the problem has a name, enter it here.
* **App Version** (4): Check the box to indicate if you are running the latest app version.
* **Screenshot** (5): If necessary, upload a screenshot or other file that demonstrates the issue.
* **File Upload** (6): This field is for uploading additional files related to your issue.
* **Error Message** (7): If you have any additional information or context about the issue, enter it here.
* **Request Type** (8): Specify the type of request you are making (e.g. "Yes" for a bug report).
* **Request Date** (9): Enter the date you encountered the issue.
* **Request Time** (10): Enter the time you encountered the issue.
* **Contact Email** (11): Re-enter your contact email address.
* **Contact Phone** (12): Re-enter your contact phone number.

## Tips

* Be as detailed as possible when describing your issue.
* Make sure to upload a screenshot or other file if it will help support staff understand your issue.
* Be specific when specifying the type of request you are making (e.g. "bug report" vs. "general feedback").
