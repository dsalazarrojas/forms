# Judgment Review Request Form - Help Guide
## Purpose
The Judgment Review Request Form is a tool used to collect information from parties requesting a review of a judgment or decision made by a court or administrative agency.

## How To Complete This Form
To complete this form, please follow these steps:

1. Select the type of request you are submitting (Request for Reconsideration, Request for Appeal, or Request for Review).
2. Enter the date of the decision you are requesting to be reviewed.
3. Enter the decision number associated with the decision you are requesting to be reviewed.
4. Identify the party making the request (Requesting Party).
5. Identify the opposing party (Opposing Party).
6. Provide a detailed description of the request and the reason for submitting it in the "Review Request Details" field.
7. Enter your contact phone number and email address so that we can contact you with any further questions or updates.
8. If applicable, select the tool that will be used to review your request.

## Field-by-Field Explanation
- **Request Type** (`request_type`, select_one, required): Select the type of request you are submitting (Request for Reconsideration, Request for Appeal, or Request for Review).
- **Decision Date** (`decision_date`, date, required): Enter the date of the decision you are requesting to be reviewed.
- **Decision Number** (`decision_number`, text, required): Enter the decision number associated with the decision you are requesting to be reviewed.
- **Requesting Party** (`requesting_party`, text, required): Identify the party making the request.
- **Opposing Party** (`opposing_party`, text, required): Identify the opposing party.
- **Review Request Details** (`review_request_details`, note, required): Provide a detailed description of the request and the reason for submitting it.
- **Contact Phone** (`contact_phone`, text, optional): Enter your contact phone number so that we can contact you with any further questions or updates.
- **Contact Email** (`contact_email`, email, optional): Enter your contact email address so that we can contact you with any further questions or updates.
- **Assigned Tool** (`assigned_tool`, text, optional): If applicable, select the tool that will be used to review your request.
- **Additional Comments** (`additional_comments`, text, optional): Provide any additional information or comments about your request.
