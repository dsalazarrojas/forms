# social_media_account_linking_support_request - Help Guide
## Purpose
This form is for users to request support for social media account linking issues. If you are experiencing difficulties linking a social media account, please fill out this form so our support team can assist you in resolving the issue.

## How To Complete This Form
1. **Social Media Account Linking Support Request** (Required): Enter a brief description of your request for social media account linking support.
2. **What Type Of Account** (Optional): Select the type of account you are experiencing issues with (Account, Page, Profile).
3. **What Is The Account ID** (Optional): Enter the ID of your social media account (e.g., Facebook ID, Instagram ID, etc.).
4. **Social Media Platform** (Optional): Select one or more social media platforms where you are experiencing issues (Facebook, Instagram, Twitter).
5. **Account Name** (Optional): Enter the name of your social media account (e.g., Facebook account name, Instagram profile name, etc.).
6. **Email Address** (Optional): Enter your email address associated with your social media account.
7. **Phone Number** (Optional): Enter your phone number (e.g., for verification purposes).
8. **Issue Description** (Optional): Describe the issue you are experiencing with your social media account linking.
9. **Issue Priority** (Optional): Select the priority level of your issue (High, Medium, Low).
10. **Issue Details** (Optional): Provide additional details about the issue you are experiencing.
