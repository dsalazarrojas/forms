# property_sustainability_grant_registration - Help Guide
## Purpose
This form is designed to collect information for property owners who are applying for a sustainability grant.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill out the required fields for each section, which are marked as "required" in the form.
2. Ensure that you provide accurate and up-to-date information for each field.
3. Review your submission carefully before submitting it to the grant administration team.

## Field-by-Field Explanation

* **First Name** (1, text, required): Please enter your first name.
* **Last Name** (2, text, required): Please enter your last name.
* **Email** (3, email, required): Please enter a valid email address that we can use to contact you.
* **Phone** (4, text, required): Please enter your phone number.
* **Property Name** (5, text, required): Please enter the name of the property you're registering for the grant.
* **Address** (6, text, required): Please enter the address of the property.
* **City** (7, text, required): Please enter the city of the property.
* **Zip** (8, text, required): Please enter the zip code of the property.
* **State** (9, text, required): Please enter the state of the property.
* **Region** (10, text, required): Please enter the region of the property.
* **Grant Program** (11, select_one, required): Please select the grant program you're applying for (e.g., Green Property Grants, Other).
* **Grant Issued By** (12, select_multiple, required): Please select the entity that issued the grant (e.g., Municipalities, Nonprofits).
* **Grant Amount** (13, number, required): Please enter the amount of the grant.
* **Grant Date** (14, date, required): Please enter the date the grant was issued.
* **Upgrade Type** (15, select_one, required): Please select the type of upgrade being implemented (e.g., Solar Panels, Green Roofs).
* **Upgrade Status** (16, select_one, required): Please select the status of the upgrade (e.g., Completed, Pending).
* **Cost** (17, number, required): Please enter the cost of the upgrade.

## Tips
* Ensure that you've filled out all required fields before submitting the form.
* Double-check your submission for accuracy and completeness before submitting it to the grant administration team.
* If you're unsure about any field, please don't hesitate to contact the grant administration team for clarification.
