# Snail Mailing List Request - Help Guide
## Purpose
The Snail Mailing List Request form is used to collect information from users who want to be included in the company's internal mailing list. This list is used for internal communication and updates.

## How To Complete This Form
To complete this form, follow these steps:

1. Review the form sections and fields.
2. Fill in the required fields (if any) with accurate information.
3. Answer the optional fields with the information you have, or leave them blank if you don't have the information.
4. Review your submission before sending it in.

## Field-by-Field Explanation

* **Snail Mailing List Request** (`title`, text, **optional**): This field is the main title of your request. You can give your request a clear and concise title that summarizes what you're asking for.
* **Category** (`category`, select_one, **optional**): Please select the category that best fits your request. The options are:
	+ Request Forms
	+ Another Category
	+ Third Category
* **Description** (`description`, text, **optional**): This field is a brief description of your request. If you have more information about your request, please provide it here.
* **Snail Mail Subject** (`snail_mail_subject`, text, **optional**): This field is used to provide a subject for your email.
* **Snail Mail Message** (`snail_mail_message`, text, **optional**): This is the content of your email message.
* **Want Snail Mail** (`want_snail_mail`, select_one, **optional**): Please choose whether you want to receive snail mail or not:
	+ True
	+ False
* **Mail List** (`mail_list`, select_one, **optional**): Please choose whether you want to be included in the mailing list or not:
	+ Yes
	+ No
