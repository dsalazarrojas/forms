## Proposal Copy Edit Request Form - Help Guide
## Purpose
The Proposal Copy Edit Request Form is used to request changes to a proposal. To complete this form, you will need to provide details about the proposal you are working with, the type of edit you need, and your contact information.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the proposal number associated with the edit request.
2. Select the type of edit you need (Copy Edit, Minor Edit, or Major Edit).
3. Enter the date and time you are requesting the edit.
4. Enter your name and email address.
5. Optionally, enter any additional information about the edit request.

## Field-by-Field Explanation
* **Form Information** (1): Enter a brief description of the proposal you are requesting edits for.
* **Form ID** (2): This field is not required, but if you have a specific form ID associated with the proposal, you can enter it here.
* **Request Type** (3): Select one of the following options:
	+ Copy Edit: A copy of the entire proposal is needed.
	+ Minor Edit: Minor changes are needed to the proposal.
	+ Major Edit: Significant changes are needed to the proposal.
* **Proposal Number** (4): Enter the proposal number associated with the edit request.
* **Date** (5): Enter the date you are requesting the edit.
* **Time** (6): Enter the time you are requesting the edit.
* **Name** (7): Enter your name.
* **Email** (8): Enter your email address.

## Tips
* Make sure to enter accurate and complete information to ensure that the edit request is processed correctly.
* If you are requesting a copy edit, please note that a new proposal will be created, and you will need to review and approve it.
* If you are requesting a minor or major edit, please specify the changes needed and any relevant documentation or references that support your request.
