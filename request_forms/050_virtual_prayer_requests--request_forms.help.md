# Virtual Prayer Requests - Help Guide
## Purpose
This form is designed to gather information for virtual prayer requests. It helps us understand the specific requests and needs of individuals, which allows us to provide more effective and personalized support.

## How To Complete This Form
To complete this form, follow these steps:

1. Please enter your First Name in the "First Name" field.
2. Enter your Last Name in the "Last Name" field.
3. Provide your Email address in the "Email" field, if applicable.
4. Write a message describing your virtual prayer request in the "Message" field.
5. If you have someone requesting a prayer for you, select "Yes" or "No" in the "Prayer Requester" field.
6. If you are requesting prayers for others, select the relevant prayer requester from the list "Prayer Requester" (select multiple options as needed).
7. Finally, select a date for the request in the "Date" field, if applicable.

## Field-by-Field Explanation
* **First Name** (`first_name`, `text`, required/optional: optional): Enter your first name to help us understand your identity.
* **Last Name** (`last_name`, `text`, required/optional: optional): Enter your last name to help us understand your complete identity.
* **Email** (`email`, `text`, required/optional: optional): If applicable, enter your email address so we can contact you if needed.
* **Message** (`message`, `text`, required/optional: optional): Describe your virtual prayer request in this field.
* **Prayer Requester** (`prayer_requester`, `select_one`, required/optional: optional): Select "Yes" if you have someone requesting a prayer for you, "No" otherwise.
* **Prayer Requester** (`prayer_requester`, `select_multiple`, required/optional: optional): Select the relevant prayer requesters for those you are requesting prayers for.
* **Date** (`date`, `date`, required/optional: optional): Select a date for the request, if applicable.

## Tips
- Please fill out the form accurately and completely.
- Use the "Prayer Requester" field to indicate if you are receiving a prayer request, and the "Prayer Requester" field to specify who the request is for.
- If you need help with filling out this form, don't hesitate to ask.
