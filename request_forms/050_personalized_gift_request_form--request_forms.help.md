# Personalized Gift Request Form - Help Guide
## Purpose
This form is designed to help you request personalized gifts for various occasions. Please fill out this form to provide accurate information about yourself and the gift recipient.

## How To Complete This Form
To complete this form, simply follow the steps below:

1. Fill out your First Name and Last Name fields with your personal details.
2. Provide your Email address for communication purposes.
3. Check the Gift Type box to indicate if you are requesting a gift or not.
4. Specify the Occasion for the gift request.
5. If you have a message for the gift recipient, type it in the Message field.
6. If the gift is for someone else, enter the Recipient Name.
7. If you would like to include a personalized message on the gift card, type it in the Gift Card Message field.
8. Choose the type of gift card you would like to receive, if applicable.

## Field-by-Field Explanation
* **First Name**: Enter your first name as it appears on your documents.
* **Last Name**: Enter your last name as it appears on your documents.
* **Email**: Enter your email address where you can be contacted for updates on your gift request.
* **Gift Type**: Check the box if you are requesting a gift, or leave it empty if you are not.
* **Occasion**: Specify the occasion for the gift request, such as birthday, anniversary, etc.
* **Message**: Type a personalized message for the gift recipient, if applicable.
* **Recipient Name**: Enter the name of the person you are requesting the gift for.
* **Gift Card Message**: Type a message to be printed on the gift card, if applicable.
* **Gift Card Type**: Choose the type of gift card you would like to receive, if applicable.
