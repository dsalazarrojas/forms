# public_relations_request_form - Help Guide
## Purpose
This form is used for public relations requests.

## How To Complete This Form
1. Fill out the form accurately and completely.
2. Enter the required information for each field.
3. Ensure that any date fields are in the correct format (e.g., YYYY-MM-DD).

## Field-by-Field Explanation

* **Organization (text)**: Enter the organization submitting the request.
* **Department (text)**: Enter the department submitting the request.
* **Contact Person (text)**: Enter the contact person for the request.
* **Email (email)**: Enter the email address of the contact person.
* **Phone (text)**: Enter the phone number of the contact person.
* **Request Description (text)**: Provide a detailed description of the request.
* **Request Type (select_one)**: Select the type of request (Option 1, Option 2, or Option 3).
* **Requested Date (date)**: Enter the date when the request is requested.
* **Submitted Date (date)**: Enter the date when the request is submitted.
* **Assigned Tool (select_multiple)**: Select the tools to be assigned for the request (chatjimmy, chat bobby, chat sally).
* **Comments (note)**: Enter any additional comments or notes for the request.
* **Submitted (select_one)**: Indicate if the form has been submitted (True or False).
* **Form ID 1-9 (text)**: Enter any relevant form ID numbers.
* **Form ID 1-23 (text)**: There are multiple form ID fields, but they are likely not required and can be skipped.
* **Category (text)**: Enter the category of the request.
* **Description (text)**: Enter a detailed description of the request.
* **Output File (text)**: Enter any output file related to the request.
* **Form ID 2-9 (text)**: These fields are not required and can be skipped.

Note: The fields marked as "Form ID" are likely not required and can be skipped. Only enter the relevant information required for the request.
