# Process Safety Document Access Request Form - Help Guide
## Purpose
The Process Safety Document Access Request Form is designed for employees or managers to request or approve access to safety-related documents. This form helps track and manage the document review process, ensuring that documents are reviewed and approved in a timely and efficient manner.

## How To Complete This Form
1. Fill out the form with your personal information (First Name, Last Name, Email, Job Title, etc.).
2. Provide your manager's information (Manager Name, Manager Email).
3. Specify the purpose of the access request (Purpose of Access).
4. Identify the document type and number (Document Type, Document Number).
5. Enter the date the document was issued (Date of Issue).
6. Choose the equipment type and condition (Equipment Type, Equipment Condition).
7. If applicable, select the safety risk and action taken (Safety Risk, Action Taken).
8. Track the review status (Review Status).
9. Select who completed the review (Completed By).
10. Select who reviewed the document (Reviewed By).
11. Enter the review date (Review Date).
12. Provide a reviewer note (Reviewer Note).
13. Track the document review status (Document Review Status).
14. Select the document status (Document Number Status).
15. Enter the due date for the document (Document Due Date).

## Field-by-Field Explanation
* **First Name**: Your first name.
	+ Required: False
	+ Type: text
* **Last Name**: Your last name.
	+ Required: False
	+ Type: text
* **Email**: Your email address.
	+ Required: False
	+ Type: email
* **Department**: Your department name.
	+ Required: False
	+ Type: text
* **Job Title**: Your job title.
	+ Required: False
	+ Type: text
* **Manager Name**: Your manager's name.
	+ Required: False
	+ Type: text
* **Manager Email**: Your manager's email address.
	+ Required: False
	+ Type: email
* **Purpose of Access**: The reason for requesting access to the document.
	+ Required: False
	+ Type: text
* **Document Type**: The type of document being requested (e.g., safety procedure, policy, or instruction).
	+ Required: False
	+ Type: text
* **Document Number**: The identifier for the document being requested.
	+ Required: False
	+ Type: text
* **Date of Issue**: The date the document was issued.
	+ Required: False
	+ Type: date
* **Date Completed**: The date the document was completed.
	+ Required: False
	+ Type: date
* **Location**: The location where the document is being used.
	+ Required: False
	+ Type: text
* **Equipment Type**: The type of equipment related to the document.
	+ Required: False
	+ Type: text
* **Equipment Condition**: The condition of the equipment related to the document.
	+ Required: False
	+ Type: text
* **Safety Risk**: The safety risk associated with the document.
	+ Required: False
	+ Type: text
* **Action Taken**: The action taken to mitigate the safety risk.
	+ Required: False
	+ Type: text
* **Review Status**: The current status of the document review.
	+ Required: False
	+ Type: select_one
	+ Options: Approved, Pending, Rejected
* **Completed By**: The person or team that completed the review.
	+ Required: False
	+ Type: select_multiple
	+ Options: Operations Manager, Compliance Officer, Safety Manager
* **Reviewed By**: The person or team that reviewed the document.
	+ Required: False
	+ Type: select_multiple
	+ Options: Operations Manager, Compliance Officer, Safety Manager
* **Review Date**: The date the document was reviewed.
	+ Required: False
	+ Type: date
* **Reviewer Note**: A note from the reviewer.
	+ Required: False
	+ Type: text
* **Document Review Status**: The current status of the document review.
	+ Required: False
	+ Type: select_one
	+ Options: In Progress, Complete, Pending
* **Document Number Status**: The status of the document number.
	+ Required: False
	+ Type: select_one
	+ Options: Active, In Progress, Pending
* **Document Due Date**: The due date for the document.
	+ Required: False
	+ Type: date

## Tips

* If you are unsure about any field, contact your manager or HR representative for guidance.
* Review the form carefully before submitting it to ensure you have provided all necessary information.
* If you need help with the form or have questions, contact our support team.
