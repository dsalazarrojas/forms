# Hearing Accessibility Request Form - Help Guide
## Purpose
The Hearing Accessibility Request Form is used to submit accessibility requests for events, sessions, or meetings. This form helps to ensure that event accessibility needs are met and accommodates participants with disabilities. Please complete this form accurately to ensure that your accessibility needs are considered.

## How To Complete This Form
To complete this form, follow these steps:

1.  Provide event details, such as the title, start and end times, and location.
2.  Select the type of event you are requesting accessibility for (event, session, or meeting).
3.  Submit the form.

## Field-by-Field Explanation

*   **Event Details** (`event_details`, text, required): This field allows you to provide a brief description of the event, session, or meeting for which you are requesting accessibility accommodations. This information will help us understand the context of your request.
*   **EventType** (`event_type`, select_one, optional): Choose from the options to indicate the type of event you are requesting accessibility for (Event, Session, or Meeting).
*   **Start Time** (`start_time`, time, optional): Enter the start time of the event in 24-hour format (HH:MM:SS or HH:MM). This field is not required.
*   **End Time** (`end_time`, time, optional): Enter the end time of the event in 24-hour format (HH:MM:SS or HH:MM). This field is not required.

## Tips

*   Be sure to provide accurate and clear event details, including start and end times.
*   If you are unsure of the event type, feel free to ask the accessibility team for assistance.
