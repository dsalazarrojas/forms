# MAG Troubleshooting Request - Help Guide
## Purpose
The MAG Troubleshooting Request form is designed to collect information for identifying and resolving issues related to the MAG system. Please fill out this form to help our technical team understand and fix the problem.

## How To Complete This Form
1. Fill in the required fields with as much detail as possible.
2. Choose the correct category for the issue (Hardware, Software, or Network).
3. Describe the issue in the "Describe the issue" field.
4. If necessary, attach files related to the issue in the "Attachments" field.
5. Select the urgency level of the issue (Low, Medium, or High).
6. Click "Submit" to send the form for review.

## Field-by-Field Explanation
* **Device Details**: Enter a brief description of the device or equipment you're experiencing the issue with.
* **Issue Category**: Select the category that best describes the issue (Hardware, Software, or Network).
* **Describe the issue**: Provide a detailed description of the problem you're experiencing, including any error messages or relevant information.
* **Urgency**: Choose the level of urgency for the issue (Low, Medium, or High). This will help us prioritize the problem accordingly.
* **Attachments**: If you have files related to the issue, upload them here (e.g., logs, screenshots).
* **File**: If you have other files not covered by the above field, you can upload them here.
* **Submit**: Once you've completed the form, click "Submit" to send the form for review by our technical team.

## Tips
- Be as detailed as possible when describing the issue to help us understand and fix the problem faster.
- Attach relevant files to help us analyze the issue more efficiently.
- If you're unsure about any field, you can always contact our support team for assistance.
