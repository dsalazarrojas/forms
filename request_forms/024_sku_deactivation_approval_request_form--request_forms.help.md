# SKU Deactivation Approval Request Form - Help Guide
## Purpose
This form is used to request deactivation of a SKU in the inventory management system.

## How To Complete This Form
To complete this form, follow these steps:

1. Review the fields carefully and ensure you have the necessary information.
2. Select "True" in the "Submit Request" field to indicate that the request is ready to be submitted.
3. Enter the reason for deactivation in the "Reason for Deactivation" field.
4. Select the deactivation date and time from the respective fields.
5. Enter the SKU ID of the item being deactivated.
6. If the reason for deactivation is not applicable, enter an alternative reason in the "Reason for Deactivation (if no)" field.
7. If the deactivation date and time are not applicable, select the new deactivation date and time from the respective fields.
8. Enter the ID of the SKU if the standard SKU ID is not applicable.
9. Enter any additional notes or comments in the "Additional Notes" field.
10. Enter the name of the sales representative who will be handling the deactivation.
11. Review the form carefully before submitting it to ensure all fields are filled out accurately and completely.
