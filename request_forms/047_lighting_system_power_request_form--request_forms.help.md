# Lightning System Power Request Form - Help Guide

## Purpose
The Lighting System Power Request Form is used by the facilities team to request power for specific projects or events. This form gathers essential information to accurately estimate the power requirements and allocate the necessary resources.

## How To Complete This Form
To fill out this form, follow these steps:

1. Provide a clear description of the project or event.
2. Specify the power needs for the project or event.
3. List all the locations involved in the project or event.
4. Enter the dates when the power will be used.
5. If applicable, provide additional event details such as event type, event time, and power consumption.
6. Select the event team's response to power distribution.
7. Enter any specific power distribution requirements.

## Field-by-Field Explanation

* **Project Details** (`project_details`, `text`, optional): Describe the project or event in a concise and clear manner.
* **Power Needs** (`power_needs`, `number`, optional): Enter the total power required for the project or event.
* **Locations** (`locations`, `text`, optional): List all the locations involved in the project or event.
* **Usage Dates** (`usage_dates`, `date`, optional): Enter the dates when the power will be used.
* **Event Details** (`event_details`, `text`, optional): Provide any additional information about the event.
* **Event Date** (`event_date`, `date`, optional): Enter the date of the event.
* **Event Type** (`event_type`, `select_one`, optional): Select the type of event (e.g., meeting, presentation, exhibition).
* **Event Time** (`event_time`, `time`, optional): Enter the time of the event.
* **Event Team** (`event_team`, `select_multiple`, optional): Select the event team's response to power distribution.
* **Power Consumption** (`power_consumption`, `number`, optional): Enter the power consumption required for the event.
* **Power Distribution** (`power_distribution`, `text`, optional): Enter any specific power distribution requirements.

## Tips
* Please ensure you provide accurate information to avoid errors in power allocation.
* If you're unsure about any field, feel free to ask for assistance.
* If you're filling out the form for an event or project that has recurring power requirements, please fill out the form for each instance.
