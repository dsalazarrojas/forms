# Vending Machine Inventory Form Template - Help Guide
## Purpose
The Vending Machine Inventory Form Template is used to collect and record information about the inventory levels and status of vending machines. This form is typically used for inventory management and tracking the availability of products in vending machines.

## How To Complete This Form
To fill out the form, follow these steps:
1. Enter the Machine ID in the text field labeled "Machine ID".
2. Enter the Product ID in the text field labeled "Product ID".
3. Enter the current stock level in the number field labeled "Stock Level".
4. Enter the stock value in the number field labeled "Stock Value".
5. Select the current stock status from the dropdown menu labeled "Stock Status" (e.g., In Stock, Low Stock, Out of Stock).
6. Select the sales status from the dropdown menu labeled "Sales Status" (e.g., Yes, No).
7. Enter any additional comments or notes about the machine in the text field labeled "Notes".
8. Enter the contact information for the machine in the text field labeled "Contact" (e.g., email address).
9. Enter the phone number for the machine in the text field labeled "Phone".
10. Enter the date and time of the last inventory update in the date-time field labeled "Date-Time".
11. Enter the date of the last update in the date field labeled "Date".
12. Enter the time of the last update in the time field labeled "Time".
13. Enter the location of the machine in the text field labeled "Location".
14. Enter the name of the user assigned to the machine in the text field labeled "Assigned User".
15. Enter the date and time the machine was last assigned in the date-time field labeled "Assigned Time".
16. Enter the location where the machine was last assigned in the text field labeled "Assigned Location".
17. Select the status of the machine's assigned task from the dropdown menu labeled "Assigned Status" (e.g., In Progress, Done, Not Done).
18. Enter the current status of the machine in the text field labeled "Machine Status".
19. Enter the serial number of the machine in the text field labeled "Serial Number".
20. Enter the model number of the machine in the text field labeled "Model Number".
21. Enter the firmware version of the machine in the text field labeled "Firmware Version".
22. Enter the hardware version of the machine in the text field labeled "Hardware Version".
23. Enter the software version of the machine in the text field labeled "Software Version".

## Field-by-Field Explanation

* **Machine ID**: Enter the unique identifier for the vending machine.
* **Product ID**: Enter the identifier for the product being tracked.
* **Stock Level**: Enter the current stock level of the product in the machine.
* **Stock Value**: Enter the value of the stock level.
* **Stock Status**: Select the current status of the stock (e.g., In Stock, Low Stock, Out of Stock).
* **Sales Status**: Select the current sales status of the machine (e.g., Yes, No).
* **Notes**: Enter any additional comments or notes about the machine.
* **Contact**: Enter the contact information for the machine (e.g., email address).
* **Phone**: Enter the phone number for the machine.
* **Date-Time**: Enter the date and time of the last inventory update.
* **Date**: Enter the date of the last update.
* **Time**: Enter the time of the last update.
* **Location**: Enter the location of the machine.
* **Assigned User**: Enter the name of the user assigned to the machine.
* **Assigned Date**: Enter the date the machine was last assigned.
* **Assigned Time**: Enter the time the machine was last assigned.
* **Assigned Location**: Enter the location where the machine was last assigned.
* **Assigned Status**: Select the status of the machine's assigned task (e.g., In Progress, Done, Not Done).
* **Machine Status**: Enter the current status of the machine.
* **Serial Number**: Enter the serial number of the machine.
* **Model Number**: Enter the model number of the machine.
* **Firmware Version**: Enter the firmware version of the machine.
* **Hardware Version**: Enter the hardware version of the machine.
* **Software Version**: Enter the software version of the machine.

## Tips
- Make sure to fill out the form completely and accurately.
- Double-check the information entered to ensure it is correct.
- If you are unsure about any field, refer to your supervisor or the machine's documentation for guidance.
