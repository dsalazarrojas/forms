# Late Retake Exam Form - Help Guide

## Purpose
The Late Retake Exam Form is used to request to retake an exam that was previously taken. This form is designed to collect necessary information to process your request.

## How To Complete This Form
To complete this form, follow these steps:

1. Select "Yes" or "No" to indicate if you would like to retake the exam.
2. Enter your class 1 ID number.
3. Enter your class 2 ID number.
4. Provide a reason for requesting to retake the exam.
5. Write any additional reasons for requesting to retake the exam.
6. Enter your exam date (if available).
7. Enter your exam time (if available).

## Field-by-Field Explanation

* **Submit Request (submit_request)**: Select "Yes" to submit your request to retake the exam.
* **Class 1 (class_1)**: Enter your Class 1 ID number.
* **Class 2 (class_2)**: Enter your Class 2 ID number.
* **Reason for Requesting (reason_for_requesting)**: Provide a reason for requesting to retake the exam. This can include any relevant details, such as illness or technical difficulties.
* **Write Your Reasons (write_your_reasons)**: If there are additional reasons why you want to retake the exam, please include them here.
* **Class 1 ID (class_1_id)**: Enter your Class 1 ID number (if not entered in the Class 1 field).
* **Class 2 ID (class_2_id)**: Enter your Class 2 ID number (if not entered in the Class 2 field).
* **Exam Date (exam_date)**: Enter your exam date (if known).
* **Exam Time (exam_time)**: Enter your exam time (if known).
