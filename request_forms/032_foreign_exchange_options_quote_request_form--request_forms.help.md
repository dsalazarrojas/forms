# Foreign Exchange Options Quote Request Form - Help Guide

## Purpose
This form is used to request a foreign exchange options quote. The purpose of this form is to gather information about the user's requirements for a foreign exchange options quote, including exchange rates, currency pair, notional amount, and expiration dates.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the foreign exchange options quote request form from the available options.
2. Fill in the required fields: notional amount, currency pair (trade_currency and counter_currency), and expiration dates (expiration_date and expiration_date2).
3. Choose the price type (market, market mtm, price, or price mtm) and strike type (at strike or forward) for the quote.
4. Select the spread (bid, offer, best deal, best price, no spread, or spread available) for the quote.
5. Enter the strike prices (strike_price and strike_price2) and expiration strike price (expiration_strike_price and expiration_strike_price2) if required.
6. Enter the notional sizes (notional_size and notional_size2) if required.
7. Review and submit the form once all fields are filled.
