# Documentary Narration Revision Request - Help Guide
## Purpose
This form is used to request revisions to a documentary. Please fill out the form completely and accurately to ensure your request is processed efficiently.

## How To Complete This Form
To complete this form, follow these steps:

1.  Select the revision request form.
2.  Fill in the start and end timecodes for the section you would like to revise.
3.  Choose the urgency level for your request.
4.  Check if you have any reference files.
5.  Attach any relevant files.
6.  Provide a description of the issue you would like to revise.
7.  Add any additional revision details.
8.  Enter your name as the submitter.
9.  Enter your email address.

## Field-by-Field Explanation
*   **Revision Request Form**: This is the main form used for submitting a revision request.
*   **Start Timecode**: Enter the start timecode of the section you would like to revise.
*   **End Timecode**: Enter the end timecode of the section you would like to revise.
*   **Urgency Level**: Choose the level of urgency for your revision request. This can be Low, Medium, or High.
*   **Reference Files**: Check if you have any reference files related to your revision request.
*   **File**: Attach any relevant files to support your revision request.
*   **Description**: Describe the issue you would like to revise in this section.
*   **Revision Details**: Add any additional details about the revision you would like to make.
*   **Submitter**: Enter your name as the person submitting the revision request.
*   **Email**: Enter your email address for contact purposes.
