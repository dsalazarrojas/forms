# Hotel Request For Proposal Submission Form - Help Guide
## Purpose
The Hotel Request For Proposal Submission Form is a tool used to collect information from users for hotel project proposals. This form ensures that all necessary details are provided to streamline the submission and review process.

## How To Complete This Form
To complete this form, follow these steps:

1.  Start by filling in the form title, which should briefly describe the proposal.
2.  Next, select the correct category for your proposal from the provided options, or enter a custom category if it's not listed.
3.  Provide a detailed description of your proposal, including any relevant information that will aid in its evaluation.
4.  Attach any additional files required for the proposal, such as supporting documents or images.
5.  Finally, select the date you are submitting the proposal.

## Field-by-Field Explanation

* **Form Title** (`form_title`, text, required/optional): Briefly describe your proposal in a few words.
* **Form Category** (`form_category`, select_one, required/optional): Select the category that best describes your proposal from the provided options or enter a custom category.
* **Form Description** (`form_description`, text, required/optional): Provide a detailed description of your proposal, including any relevant information that will aid in its evaluation.
* **Form File** (`form_file`, text, required/optional): Attach any additional files required for the proposal, such as supporting documents or images.
* **Form Date** (`form_date`, date, required/optional): Select the date you are submitting your proposal.
