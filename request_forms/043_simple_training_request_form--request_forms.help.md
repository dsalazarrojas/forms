# Simple Training Request Form - Help Guide

## Purpose

This form is used to request training sessions from employees. Please fill out the form to provide necessary details about the training you require.

## How To Complete This Form

1. Select the option 'Yes' or 'No' for each field accordingly, except for 'Date' and 'Requested Training Date' which require specific dates.
2. Enter your description of the training requested, including any necessary details.
3. Select the name of the Training Manager and the location of the training.
4. Provide any additional information about the assigned tool, if applicable.
5. Enter any manager notes if necessary.
6. Submit the form by filling out all required fields and providing a clear and concise description.

## Field-by-Field Explanation

* **Request**: Select 'Yes' if you are submitting a new request, otherwise select 'No'.
	+ Type: Select One
	+ Required: False
* **Date**: Enter the date on which you would like the training to take place.
	+ Type: Date
	+ Required: False
* **Time**: Enter the time on which you would like the training to take place.
	+ Type: Time
	+ Required: False
* **Description**: Enter a brief description of the training you are requesting.
	+ Type: Text
	+ Required: False
* **Training Manager**: Select the name of the training manager who will be handling your request.
	+ Type: Select One
	+ Required: False
* **Employee Requesting**: Select all employees who are requesting the training.
	+ Type: Select Multiple
	+ Required: False
* **Training Location**: Select the location where the training will take place.
	+ Type: Select One
	+ Required: False
* **Requested Training Date**: Enter the date on which you are requesting the training.
	+ Type: Date
	+ Required: False
* **Manager Note**: Enter any additional notes from the manager.
	+ Type: Note
	+ Required: False
* **Form Submission**: Enter any additional comments or information.
	+ Type: Text
	+ Required: False
* **Assigned Tool**: Enter any tools that will be used during the training.
	+ Type: Text
	+ Required: False
* **Form ID**: Enter the ID of the form submission.
	+ Type: Text
	+ Required: False

## Tips

* Ensure that you have all necessary information before submitting the form.
* Double-check your selections to ensure accuracy.
* If you are unsure about any field, please consult your supervisor or training manager.
