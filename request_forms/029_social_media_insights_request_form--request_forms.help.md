# Social Media Insights Request Form - Help Guide

## Purpose
This form is used to request social media insights for a company. Please fill out the form below to provide us with the necessary information to fulfill your request.

## How To Complete This Form
1. Fill out the "Company" field with the name of the company you want insights for.
2. Provide a brief description of what you are requesting insights for.
3. Select the social media platform you want insights for.
4. Select the analytics tool you are using for insights.
5. Choose the specific insights you need (engagement, sentiment, keyword, etc.).
6. Select the frequency of the insights (daily, weekly, etc.).
7. Fill out the contact information (name, email, phone, etc.) of the person making the request.

## Field-by-Field Explanation

* **Company** (text, optional): Enter the name of the company you want insights for.
* **Description** (note, optional): Provide a brief description of what you are requesting insights for.
* **Company URL** (text, optional): Enter the URL of the company's website.
* **Social Media Platform** (select_one, optional): Select the social media platform you want insights for (Facebook, Twitter, Instagram, etc.).
* **Analytics Tool** (select_multiple, optional): Select the analytics tool you are using for insights (Google, Facebook, Hootsuite, etc.).
* **Email** (email, optional): Enter the email address of the person making the request.
* **Phone** (text, optional): Enter the phone number of the person making the request.
* **Description of Insights** (select_one, optional): Select the specific type of insights you need (daily, weekly, etc.).
* **Start Date** (date, optional): Enter the start date for the insights (if required).
* **End Date** (date, optional): Enter the end date for the insights (if required).
* **Time Period** (select_one, optional): Select the time period for the insights (30 days, 60 days, etc.).
* **Frequency** (select_multiple, optional): Select the frequency of the insights (daily, weekly, etc.).
* **Data Points** (select_multiple, optional): Select the specific data points you need (engagement, sentiment, etc.).
* **Data Types** (select_multiple, optional): Select the type of data you need (engagement, sentiment, etc.).
* **Additional Insights** (note, optional): Provide any additional insights or specific requirements.
* **Request Reason** (select_one, optional): Select the reason for your request (internal, referral, marketing, etc.).
* **Contact Name** (text, optional): Enter the name of the person making the request.
* **Contact Email** (email, optional): Enter the email address of the person making the request.
* **Contact Phone** (text, optional): Enter the phone number of the person making the request.
* **Contact Department** (text, optional): Enter the department of the person making the request.
* **Contact Title** (text, optional): Enter the title of the person making the request.
* **Company Name** (text, optional): Enter the name of the company (if different from the company field).
* **Company Address** (text, optional): Enter the address of the company.
* **Company Email** (email, optional): Enter the email address of the company.
* **Company Phone** (text, optional): Enter the phone number of the company.

## Tips
* Please fill out all relevant fields to provide accurate and complete information.
* This form will only process one-time requests. If you need further insights or updates, please submit a new request.
* Please ensure that you have the necessary permissions and agreements in place before filling out this form.
