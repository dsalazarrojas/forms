# HTTP Request Workflow Documentation Request Form - Help Guide
## Purpose
The HTTP Request Workflow Documentation Request Form is designed to collect relevant details for HTTP request workflow documentation requests. It is used to ensure that requests are properly documented and tracked.

## How To Complete This Form
To complete this form, follow these steps:

1.  Select the category of the request from the dropdown menu. This will help us understand the type of request you are making.
2.  Provide a detailed description of the request in the "description" field. This should include any relevant information about the request.
3.  If applicable, select the assigned tool for the request from the dropdown menu.
4.  If you have a specific output file for the request, provide the path to the file in the "output_file" field.

## Field-by-Field Explanation
- **Request Forms** (`category`, select_one, Required/Optional): Choose the category of the request you are making. This will help us understand the type of request you are submitting.
  - Options: Request Forms, Information Request Forms
- **Description** (`description`, text, Optional): Provide a detailed description of the request you are making. This should include any relevant information about the request.
- **Assigned Tool** (`assigned_tool`, select_one, Optional): If the request is assigned to a specific tool, select it from the dropdown menu.
  - Options: chatjimmy, Other
- **Output File** (`output_file`, text, Optional): If you have a specific output file for the request, provide the path to the file in this field.
- **Request Forms** (`category`, select_multiple, Optional): This field is duplicate with the "Request Forms" field above, please make sure to use the first field instead.
- **Request Forms (Duplicate)** (`request_form_3`, text, Optional): This field is intended for additional information about the request.
- **Request Forms (Duplicate 2)** (`request_form_2`, text, Optional): This field is intended for additional information about the request.
- **Request Forms (Duplicate 3)** (`request_form_1`, text, Optional): This field is intended for additional information about the request.
- **Output File (Duplicate)** (`output_file`, text, Optional): This field is intended for the path to the output file.

## Tips
- Be as detailed as possible when describing the request.
- Make sure to select the correct category for the request.
- If you have a specific output file, provide the path to it.
- Double-check that the category is not a duplicate.
