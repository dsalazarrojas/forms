# Promotion Request Form - Help Guide
## Purpose
This form is used to submit a promotion request to your reporting manager. Please fill out the form with accurate information to facilitate the promotion review process.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill out the required fields with your information.
2. Review and verify the details before submitting the form.

## Field-by-Field Explanation

### 1. First Name
* **First Name**: A text field to input your first name.
* Type: Text
* Required: Yes

### 2. Last Name
* **Last Name**: A text field to input your last name.
* Type: Text
* Required: Yes

### 3. Job Title
* **Job Title**: A text field to input your current job title.
* Type: Text
* Required: Yes

### 4. Reporting Manager
* **Reporting Manager**: A text field to input your reporting manager's name.
* Type: Text
* Required: Yes

### 5. Department
* **Department**: A text field to input your department name.
* Type: Text
* Required: Yes

### 6. Manager Confirmation
* **Manager Confirmation**: A text field for your reporting manager to confirm the promotion request.
* Type: Text
* Required: No

### 7. Reason for Request
* **Reason for Request**: A text field to input the reason for the promotion request.
* Type: Text
* Required: Yes

### 8. Effective Date
* **Effective Date**: A date field to input the effective date of the promotion.
* Type: Date
* Required: Yes

### 9. End Date
* **End Date**: A date field to input the end date of the promotion.
* Type: Date
* Required: No

### 10. Promotion Status
* **Promotion Status**: A dropdown field to select the promotion status (Pending, Approved, Rejected).
* Type: Select One
* Required: Yes

### 11. Notes
* **Notes**: A text field for any additional comments or notes about the promotion request.
* Type: Note
* Required: No

### 12. Email

* Type: Email
* Required: Yes

### 13. Phone

### 16. Manager Extension
