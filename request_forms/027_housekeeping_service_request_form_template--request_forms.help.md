# Housekeeping Service Request Form Template - Help Guide
## Purpose

The purpose of this form is to gather information for a housekeeping service request. 

## How To Complete This Form

1. To start, please ensure you have all the necessary information about the property and its occupants before filling out the form.
2. Fill out your name, phone number, and email to identify yourself.
3. Provide the address of the property you are requesting service for.
4. Select the total square footage of the property.
5. Choose whether the property is a type of residence (e.g., house, apartment).
6. Indicate the number of storeys the property has.
7. Select the type of flooring used in the property.
8. Select the number of bedrooms and bathrooms in the property.
9. If there are any additional services you would like to request, please describe them in the "additional service" field.

## Field-by-Field Explanation

* **Client Name**: Please enter the name of the person submitting the request.
*   *Client Email*: Enter the email address of the person submitting the request.
*   *Client Phone*: Enter the phone number of the person submitting the request.
*   *Client Address*: Enter the address of the property you are requesting service for.
*   *Total Sq Footage*: Please enter the square footage of the property.
*   *Type of Residence*: Select whether the property is a house, apartment, etc.
*   *Number of Storey*: Indicate the number of storeys the property has.
*   *Type of Flooring*: Select the type of flooring used in the property.
*   *Number of Bedrooms*: Select the number of bedrooms in the property.
*   *Number of Bathrooms*: Select the number of bathrooms in the property.
*   *Additional Service*: If there's anything else you'd like to request, please let us know.

## Tips

* Please ensure that you have all the necessary information before filling out the form.
* If you're unsure about any of the fields, please don't hesitate to ask us.
* Please provide as much detail as possible to ensure we have the best understanding of your request.
* If there's anything else you'd like to know or would like to add to the form, don't be afraid to let us know.
