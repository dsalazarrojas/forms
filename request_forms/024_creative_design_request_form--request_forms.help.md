# Creative Design Request Form - Help Guide
## Purpose
This form is designed to collect information about a client's creative design request, allowing our designers to provide high-quality designs that meet their needs and expectations.

## How To Complete This Form
To complete this form, please follow these steps:

1. Enter a brief description of the client's request in the **Client Request** field.
2. Provide the client's email address in the **Client Email** field.
3. Select the type of design the client is requesting (e.g., "Yes", "No") in the **Design Type** field.
4. If applicable, upload any relevant design files or attach them to the form.
5. Provide a detailed description of the design requirements in the **Design Description** field.
6. Add any relevant notes or comments in the **Design Note** field.
7. Set the design deadline in the **Design Deadline** field.
8. Select the current status of the design (e.g., "In Progress", "Completed", "Rejected") in the **Design Status** field.
9. If the client has already been assigned a designer, enter their name in the **Design Client** field.

## Field-by-Field Explanation

* **Client Request** (<code>client_request</code>): A text field where you can enter a brief description of the client's request.
* **Client Email** (<code>client_email</code>): An email field where you can enter the client's email address.
* **Design Type** (<code>design_type</code>): A select field where you can choose the type of design the client is requesting (e.g., "Yes", "No").
* **Design Files** (<code>design_files</code>): A text field where you can upload or attach relevant design files.
* **Design Description** (<code>design_description</code>): A text field where you can provide a detailed description of the design requirements.
* **Design Note** (<code>design_note</code>): A note field where you can add any relevant notes or comments.
* **Design Deadline** (<code>design_deadline</code>): A date field where you can set the deadline for the design.
* **Design Status** (<code>design_status</code>): A select field where you can select the current status of the design (e.g., "In Progress", "Completed", "Rejected").
* **Design Client** (<code>design_client</code>): A text field where you can enter the name of the client who has been assigned the designer.

## Tips

* Please ensure that you have the necessary permissions and approvals to submit this form on behalf of the client.
* Use clear and concise language when filling out the form to avoid any misunderstandings.
* If you're unsure about any field, please consult with the client or the design team before proceeding.
* Please note that this form is not intended for internal use, and you should not use it to submit existing designs or updates.
