# Create New Conversation - Help Guide
## Purpose
This form is used to initiate a new conversation with a support team.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the type of conversation you would like to have.
2. Choose whether the conversation requires support from a team.
3. Select any applicable projects associated with the conversation.
4. Select any applicable vendors involved in the conversation.
5. Enter the subject of the conversation.
6. Add a description of the conversation.
7. Set the priority of the conversation.
8. Choose the escalation policy for the conversation.
9. Select the person assigned to the conversation.
10. Set the due date for the conversation.
11. Enter the person who created the conversation.
12. Set the date and time the conversation was created.
13. Enter the person who updated the conversation.
14. Set the date and time the conversation was last updated.
15. Enter the person who deleted the conversation.
16. Set the date and time the conversation was deleted.

## Field-by-Field Explanation
- **Conversation Type** (`conversation_type`, select_one): Select the type of conversation you would like to have.
  * Yes: Internal conversation
  * No: External conversation
- **Support Team** (`support_team`, select_multiple): Choose whether the conversation requires support from a team.
  * Yes: Select the team members involved.
  * No: Conversation will not require support from a team.
- **Projects** (`projects`, select_multiple): Select any applicable projects associated with the conversation.
  * Yes: Select the projects related to the conversation.
  * No: Conversation is not related to any projects.
- **Vendor** (`vendor`, select_multiple): Select any applicable vendors involved in the conversation.
  * Yes: Select the vendors involved in the conversation.
  * No: Conversation is not related to any vendors.
- **Subject** (`subject`, text): Enter a brief description of the conversation subject.
- **Description** (`description`, text): Add a detailed description of the conversation.
- **Priority** (`priority`, select_one): Set the priority of the conversation.
  * Yes: High priority
  * No: Low priority
- **Escalation Policy** (`escalation_policy`, select_multiple): Choose the escalation policy for the conversation.
  * Yes: Select the escalation policy.
  * No: Conversation will not have escalation policy.
- **Assigned To** (`assigned_to`, text): Enter the person assigned to the conversation.
- **Due Date** (`due_date`, date): Set the due date for the conversation.
- **Created By** (`created_by`, text): Enter the person who created the conversation.
- **Created At** (`created_at`, time): Set the date and time the conversation was created.
- **Updated By** (`updated_by`, text): Enter the person who updated the conversation.
- **Updated At** (`updated_at`, time): Set the date and time the conversation was last updated.
- **Deleted By** (`deleted_by`, text): Enter the person who deleted the conversation.
- **Deleted At** (`deleted_at`, time): Set the date and time the conversation was deleted.
- **Status** (`status`, select_one): Set the status of the conversation.
  * Active: Conversation is active.
  * Inactive: Conversation is inactive.
