# Documentary Team Access Request Form - Help Guide
## Purpose
This form is used to request access for documentary teams. Please ensure that you are requesting access for the correct purpose and that you are not duplicating an existing request.

## How To Complete This Form
To complete this form, follow the instructions below:

1. Fill in the project details and visit details sections.
2. Select whether or not you have access requests.
3. Choose whether or not you agree to the terms of access.
4. Provide your contact information.

## Field-by-Field Explanation

* **Project Details** (Project Details, Text, Required): Enter a brief description of the project you are requesting access for, including any relevant context or background information.
* **Visit Details** (Visit Details, Text, Required): Provide a description of the visit for which you are requesting access, including any dates or dates of visit.
* **Access Request** (Access Request, Select One, Required): Choose whether or not you need access to the project. Select "Yes" if you are requesting access, and "No" if you are not.
* **Agreement** (Agreement, Select Multiple, Required): Indicate whether or not you agree to the terms of access. Select "Yes" if you agree to all terms, and "No" if you do not agree to any terms.
* **Contact Information** (Contact, Text, Required): Enter your contact information, including a name and any other relevant details.

## Tips
Please ensure that you have permission from your team lead or project manager before requesting access. Additionally, double-check your responses to ensure accuracy before submitting the form.
