# Distribution Group Request Form - Help Guide
## Purpose
This form is used to submit requests for distribution group products or resources. Please fill out this form to request a specific product or resource for your team.

## How To Complete This Form
This form has multiple pages, each with its own group of fields. Please complete each page thoroughly to ensure your request is processed efficiently.

## Field-by-Field Explanation
### Request Details
* **Request Details** (`request_details`, text, optional): A brief description of the request, if desired. This field is optional, but can be used to provide additional context about the request.

### Product Information
* **Product Name** (`product_name`, text, optional): The name of the product or resource being requested.
* **Quantity** (`quantity`, text, optional): The quantity of the product or resource being requested.
* **Date Needed** (`date_needed`, date, optional): The date by which the product or resource is needed.

### Requester Information
* **Requested By** (`requested_by`, text, optional): The person submitting the request.
* **Team Name** (`team_name`, select_one, optional): Whether the request is for your team or not.
* **Department Name** (`department_name`, select_one, optional): Whether the request is for your department or not.

### Additional Information
* **Requestor Name** (`requestor_name`, text, optional): The person responsible for the request, if different from the person submitting the request.
* **Request Status** (`request_status`, select_one, optional): The current status of the request (Active or Inactive).
* **Assigned To** (`assigned_tool`, select_one, optional): Whether the request is assigned to someone or not.
* **Description** (`description`, text, optional): A description of the product or resource being requested.
* **Comments** (`comments`, text, optional): Any additional comments or notes about the request.
* **Contact Number** (`contact_number`, text, optional): A contact number for the person submitting the request.
