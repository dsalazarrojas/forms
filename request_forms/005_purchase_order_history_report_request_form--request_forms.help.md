# Purchase Order History Report Request Form - Help Guide

## Purpose
The Purchase Order History Report Request Form is used to collect and document the history of a customer's purchase orders. This includes details about the customer's name, email, phone number, purchase order date, and status, as well as the reason for requesting access to their purchase order history.

## How To Complete This Form
To complete this form, follow the steps below:

1.  Enter the customer's name in the "Customer Name" field.
2.  Enter the customer's email address in the "Customer Email" field.
3.  Enter the customer's phone number in the "Customer Phone" field.
4.  Enter the purchase order date in the "Purchase Order Date" field.
5.  Enter the purchase order number in the "Purchase Order Number" field.
6.  Enter the total amount for the purchase order in the "Purchase Order Total" field.
7.  Select the status of the purchase order from the options provided in the "Purchase Order Status" field.
8.  Select the reason for requesting access to the purchase order history from the options provided in the "Request Reason" field.
9.  Enter the name of the person submitting the request in the "Submitter" field.
10.  Enter the name of the person reviewing the request in the "Reviewer" field.
11.  Enter the name of the person approving the request in the "Approved By" field.
12.  Enter the date and time the purchase order status was updated in the "Purchase Order Status Updated" field.
13.  Enter the date of the request in the "Request Date" field.
14.  Enter the name of the person who submitted the form in the "Form Submitted By" field.
15.  Enter any additional comments in the "Comments" field.
16.  If applicable, enter the purchase order number for a second purchase order in the "Purchase Order Number 2" field.
17.  Enter the total amount for the second purchase order in the "Purchase Order Total 2" field.
18.  Select the status of the second purchase order from the options provided in the "Purchase Order Status 2" field.
19.  Select the reason for requesting access to the second purchase order history from the options provided in the "Request Reason 2" field.
20.  Enter the name of the person submitting the request for the second purchase order in the "Submitter 2" field.
21.  Enter the name of the person reviewing the request for the second purchase order in the "Reviewer 2" field.
22.  Enter the name of the person approving the request for the second purchase order in the "Approved By 2" field.
23.  Enter the date and time the second purchase order status was updated in the "Purchase Order Status Updated 2" field.
24.  Enter the date of the request for the second purchase order in the "Request Date 2" field.

## Field-by-Field Explanation

* **Customer Name** (`customer_name`, `text`, required/optional): Enter the customer's name.
* **Customer Email** (`customer_email`, `text`, required/optional): Enter the customer's email address.
* **Customer Phone** (`customer_phone`, `text`, required/optional): Enter the customer's phone number.
* **Purchase Order Date** (`purchase_order_date`, `date`, required/optional): Enter the date of the purchase order.
* **Purchase Order Number** (`purchase_order_number`, `text`, required/optional): Enter the purchase order number.
* **Purchase Order Total** (`purchase_order_total`, `number`, required/optional): Enter the total amount for the purchase order.
* **Purchase Order Status** (`purchase_order_status`, `select_one`, required/optional): Select the status of the purchase order.
* **Request Reason** (`request_reason`, `select_multiple`, required/optional): Select the reason for requesting access to the purchase order history.
* **Submitter** (`submitter`, `text`, required/optional): Enter the name of the person submitting the request.
* **Reviewer** (`reviewer`, `text`, required/optional): Enter the name of the person reviewing the request.
* **Approved By** (`approved_by`, `text`, required/optional): Enter the name of the person approving the request.
* **Purchase Order Status Updated** (`purchase_order_status_updated`, `time`, required/optional): Enter the date and time the purchase order status was updated.
* **Request Date** (`request_date`, `date`, required/optional): Enter the date of the request.
* **Form Submitted By** (`form_submitted_by`, `text`, required/optional): Enter the name of the person who submitted the form.
* **Comments** (`comments`, `note`, required/optional): Enter any additional comments about the request.
* **Purchase Order Number 2** (`purchase_order_number_2`, `text`, required/optional): If applicable, enter the purchase order number for a second purchase order.
* **Purchase Order Total 2** (`purchase_order_total_2`, `number`, required/optional): If applicable, enter the total amount for the second purchase order.
* **Purchase Order Status 2** (`purchase_order_status_2`, `select_one`, required/optional): If applicable, select the status of the second purchase order.
* **Request Reason 2** (`request_reason_2`, `select_multiple`, required/optional): If applicable, select the reason for requesting access to the second purchase order history.
* **Submitter 2** (`submitter_2`, `text`, required/optional): If applicable, enter the name of the person submitting the request for the second purchase order.
* **Reviewer 2** (`reviewer_2`, `text`, required/optional): If applicable, enter the name of the person reviewing the request for the second purchase order.
* **Approved By 2** (`approved_by_2`, `text`, required/optional): If applicable, enter the name of the person approving the request for the second purchase order.
* **Purchase Order Status Updated 2** (`purchase_order_status_updated_2`, `time`, required/optional): If applicable, enter the date and time the second purchase order status was updated.
* **Request Date 2** (`request_date_2`, `date`, required/optional): If applicable, enter the date of the request for the second purchase order.
* **Tips**
*   To ensure the accuracy and consistency of the data, please do not duplicate entries.
*   If you have previously submitted this form, do not resubmit.
*   If you are unsure about any field or option, please refer to the field-by-field explanation above.
