# Screen Printing Request Form - Help Guide
## Purpose

The Screen Printing Request Form is used to submit a request for screen printing services to create an order. This form helps to gather all the necessary information to process your order accurately and efficiently.

## How To Complete This Form

To complete this form, please follow these steps:

1. Fill in the title of the project.
2. Provide a clear description of the artwork.
3. Upload any relevant design files.
4. Specify the production deadline for the order.
5. Select the quantity needed.
6. Choose the color scheme and ink color.
7. Select the fabric type and finish type.
8. Add any additional order notes.
9. Enter your contact email and phone number.
10. Review your information and submit the form.

## Field-by-Field Explanation

* **Form Title** (form_title, text, optional): Please enter a brief title for your project.
* **Artwork Description** (artwork_description, text, optional): A clear description of your artwork helps us understand what you need to print.
* **Design File** (design_file, text, optional): Uploading artwork or design files will help us get it right. Accepted file types are [list accepted file types].
* **Production Deadline** (production_deadline, date, optional): When would you like your order to be produced? Please use the YYYY-MM-DD format.
* **Quantity** (quantity, number, optional): Please specify the number of prints needed.
* **Color Scheme** (color_scheme, select_one, optional): Select the color scheme for your order:
	+ Red
	+ Blue
	+ Black
* **Ink Color** (ink_color, text, optional): Please enter the ink color for your order.
* **Fabric Type** (fabric_type, select_multiple, optional): Select the fabric type for your order:
	+ Cotton
	+ Polyester
	+ Tri-blend
* **Finish Type** (finish_type, select_multiple, optional): Select the finish type for your order:
	+ 3D
	+ Embroidery
	+ Print
	+ Screen Print
	+ Embellishment
* **Order Notes** (order_notes, note, optional): Please add any additional notes about your order.
* **Contact Information** (email, email, optional): Please enter your email address for contact purposes.
* **Phone Number** (phone, text, optional): Please enter your phone number for contact purposes.
* **Submit** (submit, text, optional): Click this button to submit your order.
