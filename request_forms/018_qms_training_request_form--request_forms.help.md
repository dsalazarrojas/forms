# qms_training_request_form - Help Guide
## Purpose
The "qms_training_request_form" is a form used to submit requests for QMS training sessions. 

## How To Complete This Form
To complete this form, follow the steps below:
1. Fill out the form completely and accurately.
2. Select the correct team name and trainer name.
3. Enter a valid email address.
4. Select the correct training topic and type (e.g., Training Session, Workshop, Webinar, Conference, or Video Conference).
5. Choose the attendees for the training session.
6. Add any additional comments.
7. Review the form carefully before submitting.

## Field-by-Field Explanation

* **Team Name (2)**: Enter the name of the team that requires the training session. This field is required.
* **Trainer Name (3)**: Enter the name of the trainer who will be conducting the training session. This field is required.
* **Email (4)**: Enter a valid email address for the requestor. This field is required.
* **Phone (5)**: Enter the phone number of the requestor. This field is optional.
* **Date (6)**: Select the date of the training session. This field is required.
* **Time (7)**: Select the time of the training session. This field is required.
* **Department (8)**: Select the department of the team that requires the training session. Options include Quality, Assurance, Engineering, and Manufacturing. This field is required.
* **Training Topic (9)**: Enter a brief description of the training topic. This field is required.
* **Training Type (10)**: Select the type of training required (e.g., Training Session, Workshop, Webinar, Conference, or Video Conference). This field is required.
* **Attendees (11)**: Select the individuals who will be attending the training session. This field is required.
* **Comments (12)**: Add any additional comments about the training request. This field is optional.
* **Approved By (13)**: Select the individual who approved the training request. This field is optional.
* **Approved Date (14)**: Select the date the training request was approved. This field is optional.
* **Approved Time (15)**: Select the time the training request was approved. This field is optional.
* **Approved Comments (16)**: Add any comments made during the approval process. This field is optional.
* **Requestor (17)**: Enter the name of the individual requesting the training session. This field is required.
* **Requestor Email (18)**: Enter a valid email address for the requestor. This field is required.
* **Requestor Phone (19)**: Enter the phone number of the requestor. This field is optional.
* **Requestor Department (20)**: Select the department of the requestor. Options include Engineering, Quality Assurance. This field is required.
* **Submitted By (21)**: Select the individual who submitted the training request. Options include Engineering, Quality Assurance. This field is optional.
