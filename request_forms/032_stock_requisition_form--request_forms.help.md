# Stock Requisition Form - Help Guide
## Purpose
The Stock Requisition Form is used to manage stock requisitions, which are requests for stock or materials from storekeepers. This form is a critical component of the stock management process.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the unique identifier for the form.
2. Provide a description of the request.
3. Select the tool associated with the request.
4. Select the category for the request (e.g. Request Forms, Storekeeper Forms).
5. Enter the title of the form.
6. Enter the form ID 1 and form ID 2.
7. Enter the tool associated with the request.
8. Select the category for the request (e.g. Request Forms, Storekeeper Forms).
9. Enter the description of the request.
10. Enter the tool associated with the request.

## Field-by-Field Explanation

* **Form Unique ID (1)**: A unique identifier for the form. This is a required field.
* **Form Description (2)**: A description of the request. This is a required field.
* **Assigned Tool (3)**: The tool associated with the request. This is a required field.
* **Output File (4)**: The output file for the request. This is a required field.
* **Form Category (5)**: The category for the request (e.g. Request Forms, Storekeeper Forms). This is a required field.
* **Form Title (6)**: The title of the form. This is a required field.
* **Form ID 1 (7)**: A unique identifier for the form. This is a required field.
* **Form ID 2 (8)**: A unique identifier for the form. This is a required field.
* **Form Output File (9)**: The output file for the request. This is a required field.
* **Category (10)**: The category for the request (e.g. Request Forms, Storekeeper Forms). This is a required field.
* **Description (11)**: A description of the request. This is a required field.
* **Tool (12)**: The tool associated with the request. This is a required field.
