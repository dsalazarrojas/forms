# Server Transfer Request Form - Help Guide
## Purpose
The Server Transfer Request Form is used to document server transfers between different servers. This form is essential for keeping track of transfer requests, enabling smooth and efficient management of your server resources.

## How To Complete This Form
- Please fill out this form carefully to provide accurate information about the server transfer request.
- Make sure to complete all required fields.
- Double-check the form before submitting it.

## Field-by-Field Explanation

- **Request Source** (`request_source`): Enter the server name or location where the file is currently stored.
- **Destination Server** (`request_destination_server`): Enter the server name or location where the file will be moved to.
- **Move Type** (`request_move_type`): Select 'Internal move' for transfers within the same server or 'External move' for transfers between different servers.
- **Move Date** (`request_move_date`): Enter the date when the file transfer is scheduled to take place (format: YYYY-MM-DD).
- **Move Time** (`request_move_time`): Enter the time when the file transfer is scheduled to take place (format: HH:MM).
- **Reason for Move** (`request_reason`): Provide a brief explanation for the server transfer request.
- **Comments** (`request_comments`): Add any additional comments or notes related to the server transfer.
- **Assignee** (`request_assignee`): If applicable, select the team member responsible for completing the server transfer request.

## Tips

- If you're unsure about the move type, please refer to your company's server transfer policies.
- If you need help filling out this form, contact your supervisor or the support team for assistance.
