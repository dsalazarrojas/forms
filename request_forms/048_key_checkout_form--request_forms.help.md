# key_checkout_form - Help Guide
## Purpose
The key_checkout_form is used to check out key items, including recording first name, last name, address, email, phone number, date, time, note, assigned tool, form ID, category, and output file.

## How To Complete This Form
1. Ensure that all fields are completed accurately and completely, as this form is used to record critical information about checked-out items.
2. Enter the First Name and Last Name fields to identify the individual checking out the item.
3. Enter the Address field to record the item's location or the location where the item will be stored.
4. Enter the Email field to record the individual's contact information.
5. Enter the Phone field to record the individual's phone number.
6. Enter the Date and Time fields to record the item's checkout date and time.
7. Enter the Note field to record any additional comments or notes about the item.
8. Select "Yes" or "No" in the Assigned Tool field to indicate if a tool has been assigned to the item.
9. Enter the Form ID field to record the item's unique ID.
10. Select one or more categories from the Category field to record the item's category.
11. Enter the Output File field to record the file associated with the item.

## Field-by-Field Explanation
* **First Name** (`first_name`, text, required/optional): Enter the first name of the individual checking out the item.
* **Last Name** (`last_name`, text, required/optional): Enter the last name of the individual checking out the item.
* **Address** (`address`, text, required/optional): Enter the location or storage location of the item.
* **Email** (`email`, email, required/optional): Enter the contact email of the individual checking out the item.
* **Phone** (`phone`, text, required/optional): Enter the phone number of the individual checking out the item.
* **Date** (`date`, date, required/optional): Enter the date the item is being checked out.
* **Time** (`time`, time, required/optional): Enter the time the item is being checked out.
* **Note** (`note`, note, required/optional): Enter any additional comments or notes about the item.
* **Assigned Tool** (`assigned_tool`, select_one, required/optional): Select "Yes" or "No" to indicate if a tool has been assigned to the item.
* **Form ID** (`form_ids`, number, required/optional): Enter the unique ID of the item being checked out.
* **Category** (`category`, select_multiple, required/optional): Select one or more categories for the item from the dropdown list.
* **Output File** (`output_file`, text, required/optional): Enter the file associated with the item.
