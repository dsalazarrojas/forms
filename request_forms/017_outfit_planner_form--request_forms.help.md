# Outfit Planner Form - Help Guide
## Purpose
The Outfit Planner Form is designed to gather information about an event to plan and coordinate the outfit for the event.

## How To Complete This Form
To complete this form, follow the steps below:

1. Fill out the **Event Details** field with any relevant information about the event.
2. Select the **Styling Services** that you would like to have for the event from the options provided.
3. Choose the **Event Type** from the options provided.
4. Enter the **Date** of the event.
5. Enter the **Time** of the event.
6. Enter the **Location** of the event.
7. Enter a **Description** of the event.
8. Enter any **Client Information** that is relevant to the event.
9. Enter the **Number of Guests** attending the event.
10. Enter the **Budget** for the event.
11. Select the **Services Offered** from the options provided.
12. Enter any **Client Preferences** that are relevant to the event.

## Field-by-Field Explanation
* **Event Details**: This field is used to gather any additional information about the event that is not specified in the other fields. This could include any specific requirements or requests from the client.
* **Styling Services**: This field allows you to select from three options for styling services:
	+ **Event Styling**: This is typically used for events such as weddings or other formal events where a cohesive look for all guests is desired.
	+ **Seasonal Styling**: This is used for events during specific seasons or holidays where seasonal colors and themes are relevant.
	+ **Personal Styling**: This is used for events where the client wants a more personalized look, such as a birthday party or a special celebration.
* **Event Type**: This field allows you to select the type of event from the options provided.
* **Date**: This field is used to enter the date of the event.
* **Time**: This field is used to enter the time of the event.
* **Location**: This field is used to enter the location of the event.
* **Description**: This field is used to enter a brief description of the event.
* **Client Info**: This field is used to enter any relevant information about the client.
* **Event Guests**: This field is used to enter the number of guests attending the event.
* **Budget**: This field is used to enter the budget for the event.
* **Services Offered**: This field allows you to select multiple services from the options provided.
* **Client Preferences**: This field is used to enter any specific preferences or requests from the client.

## Tips
* Ensure that all required fields are filled out completely before submitting the form.
* Be as detailed as possible when filling out the form to ensure the best possible outcome.
* If you are unsure about any field, please reach out to the form administrators for clarification.
