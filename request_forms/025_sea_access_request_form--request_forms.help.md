# Sea Access Request Form - Help Guide
## Purpose
The Sea Access Request Form is used to request access to sea areas, which are likely sensitive or restricted areas. This form is only for users with legitimate access requests.

## How To Complete This Form
To complete this form, follow these steps:

1.  Enter your name in the **User Name** field.
2.  Enter your email address in the **Email Address** field.
3.  If you have a phone number, enter it in the **Phone Number** field.
4.  Select the type of request you are making in the **Request Type** field.
5.  Enter the start date and end date of your request in the **Start Date** and **End Date** fields.
6.  If you are requesting access to a vessel, select the type of vessel you are working with in the **Vessel Type** field.
7.  If your vessel has a trailer, select **Vessel with a trailer** as the **Vessel Type**.
8.  Enter the length of your vessel in the **Boat Length** field, if applicable.
9.  Add any additional details or comments about your request in the **Request Details** field.

## Field-by-Field Explanation
* **User Name (User Name, Text, Required)**: Enter your name to be associated with your request.
* **Email Address (User Email, Email, Required)**: Enter your email address so we can contact you about your request.
* **Phone Number (User Phone, Text, Optional)**: Enter your phone number to provide an additional contact method.
* **Request Type (Request Type, Select One, Required)**: Select the type of request you are making (e.g., New, Renewal, Cancellation).
* **Start Date (Start Date, Date, Required)**: Enter the start date of your request.
* **End Date (End Date, Date, Required)**: Enter the end date of your request.
* **Vessel Type (Vessel Type, Select Multiple, Optional)**: If you are requesting access to a vessel, select the type of vessel you are working with (e.g., Small Boat, Large Boat, JetSki).
* **Boat Length (Boat Length, Number, Optional)**: If you are requesting access to a vessel, enter the length of your vessel.
* **Request Details (Request Details, Note, Optional)**: Add any additional details or comments about your request.
