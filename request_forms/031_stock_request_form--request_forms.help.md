# Stock Request Form - Help Guide
## Purpose
The Stock Request Form is a structured template designed to collect information from users who want to request stock or inventory from the system. The form is intended to help internal users manage stock requests efficiently.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the form fields as instructed below.
2. Submit the form for review and approval.

## Field-by-Field Explanation
* **Form ID**: `form_id`
	+ A unique identifier for this stock request form.
* **Requester**: `requester`
	+ The person submitting the request.
* **Item Name**: `item_name`
	+ The name of the item being requested.
* **Item Type**: `item_type`
	+ The type of item being requested.
* **Quantity**: `quantity`
	+ The quantity of the item being requested.
* **Unit Price**: `unit_price`
	+ The unit price of the item being requested.
* **Total Price**: `total_price`
	+ The total price of the items being requested.
* **Request Date**: `request_date`
	+ The date the request was submitted.
* **Status**: `status`
	+ The current status of the stock request (Approved, Declined, or In Progress).
* **Comments**: `comments`
	+ Additional comments or details about the stock request.
* **Email**: `email`
	+ The contact email of the user submitting the request.
* **Phone**: `phone`
	+ The contact phone number of the user submitting the request.

## Tips
* Make sure to double-check your information before submitting the form to avoid errors.
* If you are unsure about any field, please contact the stock management team for clarification.
