# Course Module Request Form - Help Guide
## Purpose
The Course Module Request Form is used to request a new course module, including information on the department, course number, proposed start and end dates, and status.

## How To Complete This Form
To complete this form, follow these steps:
1. Fill out the form completely and accurately.
2. Make sure to select the correct department and course number.
3. Enter the proposed start and end dates for the course module.
4. Check the status of the request.

## Field-by-Field Explanation

* **Department** (`course_module_request_form_department`, select_one, required): Select the department that the course module request is for.
* **Departmental Committee** (`course_module_request_form_departmental_committee`, text, required): Enter the name of the departmental committee that will be reviewing the request.
* **Course Number** (`course_module_request_form_course_number`, number, required): Enter the number for the course module being requested.
* **Module Requested** (`course_module_request_form_module_number`, select_multiple, required): Select the modules being requested. This field is multiple-choice, allowing you to select multiple modules.
* **Proposed Start Date** (`course_module_request_form_proposed_start_date`, date, required): Enter the date when you would like the course module to start.
* **Proposed End Date** (`course_module_request_form_proposed_end_date`, date, required): Enter the date when you would like the course module to end.
* **Request Status** (`course_module_request_form_request_status`, select_one, required): Select the status of the request, whether Active or Inactive.
* **Additional Details** (`course_module_request_form_additional_details`, note, optional): Provide any additional information or comments about the request.
