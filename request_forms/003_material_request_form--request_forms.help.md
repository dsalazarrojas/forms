# Material Request Form - Help Guide
## Purpose
This form is used to request materials from the organization. Please fill out the form accurately to ensure your request is properly processed.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the "Project Details" page with information about the project.
2. On the "Material Requested" page, select the type of material you are requesting (Paint, Tools, or Supplies).
3. On the "Building Type" page, select the type of building you are requesting the material for (New Construction, Renovation, or Repairs).
4. Enter the quantity of the material you need.
5. Select who requested the material (Builders, Architects, Development Directors, or Property Managers).
6. On the "Building Material" page, select the type of material you are requesting (Paint, Tools, or Supplies).
7. Select the project manager responsible for the project (chatjimmy or Other).
8. If needed, add any additional comments or notes about the request.
9. On the "Assigned Tool" page, select who the material should be assigned to (chatjimmy or Other).
10. Check the "Email Notification" box if you would like to receive an email notification about the request.
11. Select the date and time you would like to submit the request.

## Field-by-Field Explanation
* **Project Details** (`Project Details`, text, optional): Briefly describe the project you are requesting materials for.
* **Material Requested** (`Material Requested`, select_one, optional): Select the type of material you are requesting (Paint, Tools, or Supplies).
* **Building Type** (`Building Type`, select_multiple, optional): Select the type of building you are requesting the material for (New Construction, Renovation, or Repairs).
* **Quantity** (`Quantity`, number, optional): Enter the amount of material you need.
* **Requested By** (`Requested By`, select_one, optional): Select who requested the material (Builders, Architects, Development Directors, or Property Managers).
* **Building Material** (`Building Material`, select_multiple, optional): Select the type of material you are requesting (Paint, Tools, or Supplies).
* **Project Manager** (`Project Manager`, select_one, optional): Select the project manager responsible for the project (chatjimmy or Other).
* **Notes** (`Notes`, note, optional): Add any additional comments or notes about the request.
* **Assigned Tool** (`Assigned Tool`, select_one, optional): Select who the material should be assigned to (chatjimmy or Other).
* **Email Notification** (`Email Notification`, text, optional): Check this box if you would like to receive an email notification about the request.
* **Date** (`Date`, date, optional): Select the date you would like to submit the request.
* **Time** (`Time`, time, optional): Select the time you would like to submit the request.
* **Comments** (`Comments`, text, optional): Add any additional comments about the request.

## Tips
* Be as specific as possible when requesting materials.
* Double-check your selections to ensure you have filled out the correct information.
* If you have any questions or concerns, contact the project manager or the development team.
