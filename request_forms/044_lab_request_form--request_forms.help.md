# Lab Request Form - Help Guide
## Purpose
The Lab Request Form is a digital tool used for requesting laboratory tests and results from patients. It allows laboratory personnel to submit requests for tests, track progress, and manage test results.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the type of test you are requesting (e.g., Blood, Urine, Tissue).
2. Enter the patient's ID number.
3. Enter the sample ID number.
4. Enter the name of the test being requested.
5. Enter a brief description of the test.
6. Select the date the test was performed.
7. Enter the status of the result (e.g., Complete, Incomplete, Not Started).
8. Select the outcome of the test (e.g., Positive, Negative, Inconclusive).
9. Enter the patient's age.
10. Enter the date the sample was received.
11. Select the priority of the test (e.g., Low, Medium, High).
12. Enter the due date for the test completion.
13. Enter any additional comments about the test result.
14. Enter any remarks or comments about the test.

## Field-by-Field Explanation

* **Sample Type** (`Sample Type`): Select the type of sample being tested (e.g., Blood, Urine, Tissue).
* **Patient ID** (`Patient ID`): Enter the unique ID number of the patient being tested.
* **Sample ID** (`Sample ID`): Enter the unique ID number of the sample being tested.
* **Test Name** (`Test Name`): Enter the name of the test being requested.
* **Test Description** (`Test Description`): Enter a brief description of the test.
* **Test Date** (`Test Date`): Enter the date the test was performed.
* **Sample Received Date** (`Sample Received Date`): Enter the date the sample was received.
* **Test Priority** (`Test Priority`): Select the priority of the test (e.g., Low, Medium, High).
* **Test Due Date** (`Test Due Date`): Enter the due date for the test completion.
* **Test Result** (`Test Result`): Select the outcome of the test (e.g., Positive, Negative, Inconclusive).
* **Age** (`Age`): Enter the age of the patient.
* **Patient Sex** (`Sex`): Select the sex of the patient (e.g., Male, Female, Other).
* **Result Status** (`Result Status`): Select the status of the result (e.g., Complete, Incomplete, Not Started).
* **Lab Technician** (`Lab Technician`): Select the laboratory technician who performed the test.
* **Test Result Comment** (`Test Result Comment`): Enter any additional comments about the test result.
* **Test Remarks** (`Test Remarks`): Enter any additional remarks or comments about the test.
* **Request Date** (`Request Date`): Enter the date the request was made.
* **Test Status** (`Test Status`): Select the status of the test (e.g., Complete, In Progress, Not Started).
* **Sample Weight** (`Sample Weight`): Enter the weight of the sample (if applicable).
* **Test Result Comment** (`Test Result Comment`): Enter any additional comments about the test result.
* **Patient Name** (`Patient Name`): Enter the name of the patient.
* **Result Date** (`Result Date`): Enter the date the test result was received.
