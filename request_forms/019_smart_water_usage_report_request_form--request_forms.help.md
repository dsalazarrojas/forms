## Smart Water Usage Report Request Form - Help Guide

## Purpose
The Smart Water Usage Report Request Form is designed to collect information about a specific property's water usage for a specified period. This form is intended for property owners or managers to request a detailed report on their property's water usage. The report will provide valuable insights into water consumption patterns and help identify areas for improvement in water efficiency and conservation.

## How To Complete This Form
To complete the form, follow these steps:

1. Enter your property's details in the **Property Details** field.
2. Select the **Reporting Period** for which you want to request the report from the drop-down menu. You can choose from the following options: January, February, March, April, May, June, July, August, September, October, November, December.
3. If you want to specify the exact start date of the reporting period, enter it in the **Reporting Start Date** field in the format YYYY-MM-DD.
4. If you want to specify the end date of the reporting period, enter it in the **Reporting End Date** field in the format YYYY-MM-DD.
5. Enter your contact email address in the **Contact Email** field, where we will send the report.
6. Enter your contact phone number in the **Contact Phone** field.

## Field-by-Field Explanation
### Property Details
* **Property Details** (Text) - Enter a brief description of your property, such as its name, address, and any additional details that might be helpful for our report.

### Reporting Period
* **Reporting Period** (Select Multiple) - Choose the month(s) for which you want to request the report. You can select multiple months by holding down the `Ctrl` key while clicking on each month.

### Reporting Start Date
* **Reporting Start Date** (Date) - Enter the start date of the reporting period, in the format YYYY-MM-DD. This field is optional, but if you select a start date, we will use it to generate the report.

### Reporting End Date
* **Reporting End Date** (Date) - Enter the end date of the reporting period, in the format YYYY-MM-DD. This field is optional, but if you select a start date, we will use it to generate the report.

### Contact Email
* **Contact Email** (Email) - Enter your email address where we will send the report. This field is optional, but it's helpful for us to get back to you with any questions or follow-up information.

### Contact Phone
* **Contact Phone** (Text) - Enter your phone number where we can contact you with any questions or follow-up information. This field is optional, but it's helpful for us to get back to you in case of any clarifications.
