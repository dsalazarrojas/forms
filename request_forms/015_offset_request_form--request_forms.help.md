# offset_request_form - Help Guide
## Purpose
The offset_request_form is used to record and track orders from buyers and providers for offset projects.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the required fields with accurate and up-to-date information.
2. Double-check your entries for accuracy to ensure clear communication between parties involved.

## Field-by-Field Explanation
* **Provider Name** (`provider_name`, text, optional): Enter the name of the provider, if applicable.
* **Email** (`email`, email, optional): Enter the email of the provider, if available.
* **Phone** (`phone`, text, optional): Enter the phone number of the provider, if available.
* **Request Date** (`request_date`, date, optional): Enter the date of the request.
* **Provider Note** (`provider_note`, note, optional): Enter any additional note from the provider.
* **Buyer Name** (`buyer_name`, text, optional): Enter the name of the buyer.
* **Buyer Email** (`buyer_email`, email, optional): Enter the email of the buyer.
* **Buyer Phone** (`buyer_phone`, text, optional): Enter the phone number of the buyer.
* **Buyer Note** (`buyer_note`, note, optional): Enter any additional note from the buyer.
* **Order Items** (`order_items`, select multiple, optional): Select the status of the order items (Yes/No).
