# Ministry Event Request Form - Help Guide

## Purpose
The purpose of this form is to gather information about events or activities related to the Ministry. It is used to request events, meetings, or other activities that require approval or coordination from the Ministry.

## How To Complete This Form
To complete this form, simply follow these steps:

1. Fill in the required fields (marked as "Required") with the requested information.
2. Provide as much detail as possible in the text fields.
3. Select the appropriate options for the select fields.
4. Make sure to review your submission carefully before submitting the form.

## Field-by-Field Explanation

### Event Details (1)
* **Event Details** (`event_details`, text, Required): This is the main body of the event description. Please provide a brief and clear description of the event.

### Event Date (2)
* **Event Date** (`event_date`, date, Required): This is the date on which the event will take place. Please enter the date in the correct format (YYYY-MM-DD).

### Event Time (3)
* **Event Time** (`event_time`, time, Required): This is the time at which the event will start. Please enter the time in the format 12:00 AM or 12:00 PM.

### Event Location (4)
* **Event Location** (`event_location`, text, Required): This is the location where the event will be held. Please provide the address or venue name.

### Attendees (6)
* **Attendees** (`attendees`, select_multiple, Required): Indicate whether the event is public or private.

### Event Type (7)
* **Event Type** (`event_type`, select_one, Required): Select the type of event from the provided options.

### Event Organizer (8)
* **Event Organizer** (`event_organizer`, text, Not Required): This is the contact information for the event organizer.

### Contact Info (9)
* **Contact Info** (`contact_info`, text, Not Required): This is the contact information for the event organizer.

### Event Requester (10)
* **Event Requester** (`event_requester`, text, Not Required): This is the name of the person requesting the event.

### Event Requester Email (11)
* **Event Requester Email** (`event_requester_email`, email, Not Required): This is the email address of the event requester.

### Event Requester Phone (12)
* **Event Requester Phone** (`event_requester_phone`, text, Not Required): This is the phone number of the event requester.

### Event Requester Notes (13)
* **Event Requester Notes** (`event_requester_notes`, text, Not Required): This is any additional information about the event requester.

### Form Submission (14)
* **Form Submission** (`form_submission`, select_one, Not Required): Please select the correct submission option.

### Ministry Confirmation (15)
* **Ministry Confirmation** (`ministry_confirmation`, select_one, Not Required): Please select the correct confirmation option.

### Follow Up (16)
* **Follow Up** (`follow_up`, select_one, Not Required): Indicate whether you would like to be followed up on.

### Additional Notes (17)
* **Additional Notes** (`additional_notes`, text, Not Required): This is any additional information about the event.

### Event Status (18)
* **Event Status** (`event_status`, select_one, Not Required): Select the status of the event from the provided options.

### Status Update Date (19)
* **Status Update Date** (`status_update_date`, date, Not Required): This is the date the status was updated.

### Status Update (20)
* **Status Update** (`status_update`, text, Not Required): This is any additional information about the status update.

### Event Status Update (21)
* **Event Status Update** (`event_status_update`, text, Not Required): This is any additional information about the event status update.

### Notes (22)
* **Notes** (`notes`, text, Not Required): This is any additional information about the event.

### Event Organizer Email (23)
* **Event Organizer Email** (`event_organizer_email`, email, Not Required): This is the email address of the event organizer.

### Event Organizer Phone (24)
* **Event Organizer Phone** (`event_organizer_phone`, text, Not Required): This is the phone number of the event organizer.

### Event Organizer Phone 2 (25)
* **Event Organizer Phone 2** (`event_organizer_phone2`, text, Not Required): This is the phone number of the event organizer.

Please review each field carefully and ensure that you are providing accurate and complete information. If you have any questions or need further clarification, please do not hesitate to contact the Ministry.
