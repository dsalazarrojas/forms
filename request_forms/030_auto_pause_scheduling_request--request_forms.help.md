# Auto Pause Scheduling Request - Help Guide
## Purpose
The **Auto Pause Scheduling Request** form is used to pause services for a specific period. This allows the customer's service to be put on hold while they are dealing with external circumstances that affect their account or subscription.

## How To Complete This Form
To fill out this form, please follow these steps:
1. Fill in the required fields:
	* **Customer Name**: The full name of the customer's account holder.
	* **Account or Subscription ID**: The unique member number associated with the account.
	* **Contact Email**: A valid email address for confirmation and communication.
	* **Contact Phone**: A primary phone number to contact.
	* **Pause Start Date**: The date services should begin being paused.
	* **Pause End Date**: The date services should end being paused.
	* **Reason for Pause**: A choice of why the pause is needed (e.g. Vacation, Financial Reasons, etc.).
	* **Services to be Paused**: Select all services that will be paused during this period.
	* **Confirmation of Terms**: Confirm that you understand billing will resume automatically after the pause end date.
	* **Notifications Preference**: Choose when you'd like to receive updates (pause start, pause end, or both).
2. If desired, add **Additional Scheduling Notes** for any specific requests or requirements.

* **Customer Name (Customer Name)**: Enter the full name of the customer's account holder.
