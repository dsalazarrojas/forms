# Maintenance Request Form - Help Guide
## Purpose
The Maintenance Request Form is used to submit maintenance requests for tools and equipment. Fill out this form to request assistance for any issues you're experiencing with your assigned tool.

## How To Complete This Form
To submit a maintenance request, follow these steps:

1. Fill out the "Request Details" section with any relevant information about the problem you're experiencing.
2. Provide your "Contact Number" and "Contact E-mail" so we can get in touch with you for further information.
3. Indicate whether you're requesting a "Service Request" (e.g., repair, calibration, etc.).
4. Specify the type of maintenance you require (e.g., "Yes" for yes, "No" for no).
5. Add a detailed "Description" of the issue you're experiencing.
6. Choose the "Assigned Tool" you're experiencing issues with (or select "Other" if it's not listed).
7. Finally, confirm that you're ready to submit your request ("Yes" or "No").

## Field-by-Field Explanation
### Request Details
* **Request Details** (`note`, optional): Briefly describe the problem you're experiencing with your tool.

### Contact Number
* **Contact Number** (`text`, optional): Enter your phone number so we can contact you for further information.

### Contact E-mail
* **Contact E-mail** (`email`, optional): Enter your email address so we can contact you for further information.

### Service Request
* **Service Request** (`select_one`, optional): Check "Yes" if you're requesting a service (e.g., repair, calibration, etc.).

### Maintenance Type
* **Maintenance Type** (`select_one`, optional): Check "Yes" if this is a maintenance request form.

### Description
* **Description** (`text`, optional): Provide a detailed description of the issue you're experiencing.

### Assigned Tool
* **Assigned Tool** (`select_one`, optional): Choose the tool you're experiencing issues with, or select "Other" if it's not listed.

### Submit
* **Submit** (`select_multiple`, optional): Confirm that you're ready to submit your request ("Yes" or "No").
