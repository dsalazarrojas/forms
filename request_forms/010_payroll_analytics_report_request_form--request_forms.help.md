# Payroll Analytics Report Request Form - Help Guide
## Purpose
This form is intended to provide a structured way to request a payroll analytics report from the system. It is designed to gather necessary information from the requester to generate a report tailored to their needs.

## How To Complete This Form
To complete this form, follow these steps:
1. Select a report type (e.g., Payroll Summary, Payroll Details, Payroll Report) to indicate the type of report you need.
2. Choose the pay cycle(s) for which you need the report.
3. Confirm if you are an active or inactive employee.
4. Provide your employee ID number.
5. Enter the start and end dates for the report period.
6. Enter your name, email, and department (if applicable).
7. Add any additional comments or remarks to support your request.
8. Upload any supporting files if necessary.
9. Confirm your manager's approval (if applicable).
10. Submit the form to initiate the report generation process.

*   **End Date** (`4`, `date`, required/optional): Enter the end date of the report period you need.

*   **Pay Cycle** (`6`, `select_multiple`, required/optional): Select the pay cycle(s) for which you need the report.
*   **Department** (`7`, `select_one`, required/optional): Confirm if you are an employee of the department or not.
*   **Manager ID** (`8`, `select_multiple`, required/optional): Confirm if your manager has approved this request.
*   **Submitter Name** (`9`, `text`, required/optional): Enter your name for the report submission.
*   **Submitter Email** (`10`, `email`, required/optional): Enter your email address for report notification and updates.
