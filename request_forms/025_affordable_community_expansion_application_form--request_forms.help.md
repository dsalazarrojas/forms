# Affordable Community Expansion Application Form - Help Guide
## Purpose
This form is designed to collect information from organizations applying for an affordable community expansion project. It will help us evaluate and approve your project.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill in your organization's information, including name, type, address, and contact details.
2. Provide a project overview, including project name, location, and description.
3. Enter project specifics, such as timeline, total units planned, unit types breakdown, affordable units count, and affordability levels.
4. Indicate the target population and funding sources committed or anticipated.
5. Enter project cost and financing details, including estimated total cost, requested funding amount, and financing structure.
6. List any supporting documents attached with the application.
7. Sign and confirm the application.

## Field-by-Field Explanation
* **Organization Name** (`Organization Name`, text, required): Enter the name of your organization applying for the expansion project.
* **Organization Type** (`Organization Type`, select_one, required): Select the type of organization applying (Non-profit Housing Organization, Community Development Corporation, Government Agency, Private Developer, Cooperative, Faith-based Organization, Other).
* **Organization Address** (`Organization Address`, text, required): Enter the complete address of the organization.
* **Primary Contact Name** (`Primary Contact Name`, text, required): Enter the name of the primary contact person for this application.
* **Primary Contact Title** (`Primary Contact Title`, text, required): Enter the job title of the primary contact person.
* **Primary Contact Email** (`Primary Contact Email`, email, required): Enter the email address of the primary contact person.
* **Primary Contact Phone** (`Primary Contact Phone`, text, required): Enter the phone number of the primary contact person.
* **Project Overview** (`Project Overview`, note, required): Briefly describe the proposed expansion project.
* **Project Name** (`Project Name`, text, required): Enter the name of the affordable community expansion project.
* **Project Location** (`Project Location`, text, required): Enter the complete address where the expansion will take place.
* **Project Description** (`Project Description`, text, required): Briefly describe the proposed expansion project.
* **Project Timeline** (`Project Timeline`, text, required): Enter the expected start and completion dates for the project.
* **Total Units Planned** (`Total Units Planned`, number, required): Enter the total number of housing units planned in the expansion.
* **Unit Types Breakdown** (`Unit Types Breakdown`, text, required): Break down the number of units by type (studios, 1BR, 2BR, etc.).
* **Affordable Units Count** (`Affordable Units Count`, number, required): Enter the number of units designated as affordable housing.
* **Affordability Levels** (`Affordability Levels`, text, required): Enter the income levels the units will serve (AMI percentages).
* **Target Population** (`Target Population`, select_multiple, required): Select the target population for these units (Low-income families, Elderly seniors, Disabled individuals, Veterans, Young adults, Students, Working families, Homeless individuals).
* **Total Project Cost** (`Total Project Cost`, number, required): Enter the estimated total cost of the expansion project.
* **Requested Funding Amount** (`Requested Funding Amount`, number, required): Enter the amount of funding being requested for this project.
* **Other Funding Sources** (`Other Funding Sources`, text, required): List other funding sources committed or anticipated.
* **Financing Structure** (`Financing Structure`, text, required): Describe how the project will be financed.
* **Jobs Created** (`Jobs Created`, text, required): Enter the number of construction and permanent jobs to be created.
* **Community Services** (`Community Services`, text, required): List any community services provided with the expansion.
* **Sustainability Features** (`Sustainability Features`, text, required): Describe any sustainable or green features included.
* **Community Engagement** (`Community Engagement`, text, required): Explain how the community has been involved in planning.
* **Zoning Compliance** (`Zoning Compliance`, select_one, required): Indicate if the project is compliant with local zoning regulations (True, False, Pending Approval).
* **Environmental Clearance** (`Environmental Clearance`, select_one, required): Indicate if environmental clearance has been obtained or applied for (True, False, In Progress).
* **Fair Housing Compliance** (`Fair Housing Compliance`, text, required): Describe how the project ensures fair housing compliance.
* **Supporting Documents Attached** (`Supporting Documents Attached`, text, required): List any supporting documents included with the application.
* **Authorization Signature** (`Authorization Signature`, text, required): Sign and confirm the application with your electronic signature.

Note: All fields marked as `required` must be filled in to complete the form.
