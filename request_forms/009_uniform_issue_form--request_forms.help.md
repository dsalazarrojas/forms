# Uniform Issue Form - Help Guide
## Purpose
The Uniform Issue Form is used to report issues related to uniforms, such as missing or damaged items. This form helps to gather information about the problem, its location, and other relevant details to facilitate swift resolution.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the form completely, including all required fields (indicated by a star \*).
2. Enter your input in the provided text fields, such as User Label and Equipment Description.
3. Select the correct option for "Issued By" from the provided list.
4. Enter the number of equipment affected in the Equipment Count field.
5. Add any additional remarks or comments in the Remarks field.
6. Enter your email address and phone number, which will be used for contact purposes.

## Field-by-Field Explanation

* **User Input Group** (`user_input_group`, text, required/optional): This field is where you can enter any relevant information about the issue.
* **Group Label** (`group_label`, text, required/optional): Enter a brief description of the issue.
* **User Label** (`user_label`, text, required/optional): Enter your name or label associated with the issue.
* **Date Issued** (`date_issued`, date, required/optional): Record the date the issue was reported or discovered.
* **Date Required** (`date_required`, date, required/optional): Enter the deadline for resolution or follow-up, if applicable.
* **Equipment Description** (`equipment_description`, text, required/optional): Provide a detailed description of the equipment involved.
* **Equipment Serial** (`equipment_serial`, text, required/optional): Enter the serial number of the equipment (if applicable).
* **Equipment Cost** (`equipment_cost`, number, required/optional): Record the estimated or actual cost of the equipment.
* **Issued By** (`issued_by`, select_one, required): Select the person responsible for issuing the uniform.
* **Equipment Count** (`equipment_count`, number, required/optional): Enter the number of equipment affected by the issue.
* **Remarks** (`remarks`, note, required/optional): Add any additional comments or explanations about the issue.
* **User Email** (`user_email`, email, required/optional): Enter your email address for contact purposes.
* **User Phone** (`user_phone`, text, required/optional): Enter your phone number for contact purposes.
* **Issued To** (`issued_to`, select_multiple, required/optional): Select the individuals or groups affected by the issue.
