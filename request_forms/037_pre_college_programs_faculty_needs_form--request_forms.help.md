# Pre College Programs Faculty Needs Form - Help Guide
## Purpose
The purpose of this form is to allow faculty members to request supplies, guest speakers, field trips, and other additional support for the Pre-College programs. Please use this form to submit your requests and help the program directors efficiently manage and track these requests.

## How To Complete This Form
To complete this form, follow these steps:

1. Review each section carefully to ensure you are submitting a request that is necessary and not already fulfilled.
2. Fill out the form completely, providing as much detail as possible for each request.
3. Double-check that you have selected all the relevant options for each field.

## Field-by-Field Explanation
### Summer Course Information
• **Summer Course Information** (`summer_course_info`, text, optional): This field is intended for faculty to provide information about any summer courses or programs they are leading or participating in. Please include the course title, dates, and any other relevant details.

### Guest Speaker Info
• **Guest Speaker Info** (`guest_speaker_info`, text, optional): This field is for faculty to request guest speakers for their courses or programs. Please include the speaker's name, topic, and any other relevant details.

### Requested Supplies
• **Requested Supplies** (`requested_supplies`, select_multiple, optional): In this field, please select which supplies you require for your course or program. Please note that some requests may not be available, and the program directors will review each request.

### Additional Request
• **Additional Request** (`additional_request`, text, optional): If there is any other request or information that is not covered in the other fields, please include it here.

### Field Trip Info
• **Field Trip Info** (`field_trip_info`, text, optional): This field is for faculty to request field trips or off-campus activities for their courses or programs. Please include the trip details, including dates and locations.

### Course Information
• **Course Information** (`course_info`, text, optional): This field is for faculty to provide information about their course or program, including any relevant dates and topics.

### Email
• **Email** (`email`, email, optional): Please enter your email address so that the program directors can contact you regarding your request.

### Phone
• **Phone** (`phone`, text, optional): Please enter your phone number so that the program directors can contact you regarding your request.

### Date
• **Date** (`date`, date, optional): This field is for faculty to specify the date for their course or program. Please use the standard date format.

### Tips
- Be sure to check the form carefully before submitting to ensure you have filled out all required fields.
- If you are unsure about what to enter in a field, please reach out to the program directors for clarification.
- The program directors will review each request and contact you regarding the status.
- Please allow sufficient time for the program directors to review and fulfill your request.
