# NHA New Server Request Form - Help Guide
## Purpose
The NHA New Server Request Form is a tool used to request new servers for various purposes. This form allows you to provide detailed information about the request, including the server details, user information, and request type.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the Request Details section with any relevant information about the request.
2. Provide your user details, including email and phone number.
3. Choose the request type (Yes or No).
4. Enter the server request date and time (in date and time format).
5. Add a description of the request.
6. Choose the status of the server (Active or Inactive).
7. Add any additional notes about the request.
8. Enter your email address and phone number for communication purposes.
9. Specify the location where the server is located.

## Field-by-Field Explanation
* **Request Details (Text)**: This field is where you can provide any additional information about the request, such as the reason for the request or any relevant details.
* **User Details (Text)**: This field is where you can enter your name and contact information, including email and phone number.
* **Server Details (Text)**: This field is not currently being used, but if you have any additional information about the server, please enter it here.
* **Request Type (Select One)**: Choose whether the request is for a new server or not.
* **Server Request Date (Date)**: Enter the date when you would like the server to be available.
* **Server Request Time (Time)**: Enter the time when you would like the server to be available.
* **Description (Text)**: Provide a brief description of the request.
* **Assigned Technician (Select Multiple)**: Choose whether you want a technician assigned to this request.
* **Status (Select One)**: Choose the status of the server (Active or Inactive).
* **Notes (Note)**: Add any additional notes or comments about the request.
* **Email (Email)**: Enter your email address for communication purposes.
* **Phone (Text)**: Enter your phone number for communication purposes.
* **Location (Text)**: Specify the location where the server is located.
