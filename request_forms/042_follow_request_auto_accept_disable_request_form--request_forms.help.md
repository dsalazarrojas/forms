# Follow Request Auto Accept Disable Request Form - Help Guide
## Purpose
This form is used to update the auto-accept settings for a specific request. It is used by system administrators to determine whether a request should be accepted or disabled automatically.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the option for whether to follow the request auto-accept setting (`follow_request_auto_accept_disable_request_form`).
2. Provide a reason for the update (if any).
3. Optionally, provide a description of the changes.
4. Select additional follow request auto-accept settings as needed (`account_administrator_name`, `account_setting`, `follow_request_auto_accept_disable_request_form_0`, etc.).

## Field-by-Field Explanation
* **Follow Request Auto-Accept** (`follow_request_auto_accept_disable_request_form`): Select whether to follow the request auto-accept setting. This option is required.
	+ Select one of the following options:
		- **Yes**: Follow the request auto-accept setting.
		- **No**: Do not follow the request auto-accept setting.
* **Reason** (`reason`): Provide a reason for the update. This field is required.
* **Description** (`description`): Optionally, provide a description of the changes.
* **Account Administrator** (`account_administrator_name`): Select the account administrator who made the update. This field is optional.
* **Account Setting** (`account_setting`): Select the account setting to update. This field is optional.
* **Follow Request Auto-Accept 0** (`follow_request_auto_accept_disable_request_form_0`): Select additional follow request auto-accept settings. This field is optional.
* **Follow Request Auto-Accept 1** (`follow_request_auto_accept_disable_request_form_1`): Select additional follow request auto-accept settings. This field is optional.
* **Follow Request Auto-Accept 2** (`follow_request_auto_accept_disable_request_form_2`): Select additional follow request auto-accept settings. This field is optional.
* ... (repeat this pattern for all fields)
* **Follow Request Auto-Accept 16** (`follow_request_auto_accept_disable_request_form_16`): Select additional follow request auto-accept settings. This field is optional.
* **Follow Request Auto-Accept 17** (`follow_request_auto_accept_disable_request_form_17`): Select additional follow request auto-accept settings. This field is optional.

## Tips
* Make sure to select the correct option for whether to follow the request auto-accept setting.
* If you are unsure about any of the options, ask your administrator or consult the documentation.
* Be sure to provide a clear reason for the update if you are making changes.
* You can select multiple options for additional follow request auto-accept settings if necessary.
