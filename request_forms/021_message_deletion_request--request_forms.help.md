# Message Deletion Request - Help Guide

## Purpose
The Message Deletion Request form is used to request the deletion of a message. This form is intended to be used when a message is no longer needed or is incorrect and you would like to remove it for administrative purposes. Please note that this form should not be used for messages that are part of a critical system or have been created by other users that are not the submitter of this form. 

## How To Complete This Form
To complete this form, please follow these steps:

1. Enter the Message ID for the message you would like to delete.
2. Provide a brief reason for deleting the message.
3. If the message is being rejected, please provide a reason for rejection.

## Field-by-Field Explanation

* **Message ID (1)** (number, required): Enter the ID of the message you would like to delete.
* **Reason for Deletion (2)** (text, required): Enter a brief description of why the message should be deleted.
* **Delete Message (3)** (select_one, optional): Select 'True' to confirm that you would like to delete the message, or 'False' to cancel.
* **Reason for Rejection (4)** (text, optional): If the message is being rejected, enter a reason for rejection.

## Tips

* Make sure to enter the correct Message ID for the message you want to delete.
* If the message is part of a critical system, please do not use this form.
* If you are unsure about the purpose of the form or the process, please contact the relevant team member for assistance.
