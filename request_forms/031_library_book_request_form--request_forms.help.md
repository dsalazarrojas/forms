# Library Book Request Form - Help Guide
## Purpose
The Library Book Request Form is a simple form for requesting a book from the library. You can use it to submit a request for a book not already available at the library.

## How To Complete This Form
To complete this form, simply fill in the required fields with the requested information.

## Field-by-Field Explanation
* **Book ISBN** (book_isbn, text, optional)
	+ Enter the International Standard Book Number (ISBN) of the book you are requesting. This will help the library identify the book in their catalog.
* **Book Title** (book_title, text, optional)
	+ Enter the title of the book you are requesting.
* **Book Author** (book_author, text, optional)
	+ Enter the author of the book you are requesting.
* **Book Publisher** (book_publisher, text, optional)
	+ Enter the publisher of the book you are requesting.
* **Book Year** (book_year, number, optional)
	+ Enter the year of publication of the book you are requesting.
* **Book Format** (book_format, select_one, optional)
	+ Select the format in which you would like to receive the book (Hardcover, Paperback, E-book).
* **Book Requestor Info** (book_requestor_info, text, optional)
	+ Enter any additional information about yourself or your request (e.g., your department affiliation).
* **Request Message** (request_message, text, optional)
	+ Enter a brief message explaining why you are requesting this book.

Note: All fields are optional, but providing more information about the book and your request will help the library serve you better.
