# rma_request_form - Help Guide
## Purpose
The RMA Request Form is a tool for customers to submit a return merchandise authorization request for an item(s) they would like to return.

## How To Complete This Form
To complete this form, please follow these steps:

1.  Enter your customer information in the **Customer Info** field.
2.  Provide a brief explanation for the reason you would like to return the item in the **reason_for_return** field.
3.  Describe the item details you would like to return, including the item's condition and any other relevant information, in the **Item Details** field.
4.  Enter your return address in the **Return Address** field.
5.  Enter your phone number in the **Phone** field.
6.  Enter your email address in the **Email** field.
7.  Provide any relevant details about the order you would like to return in the **Order Details** field.

## Field-by-Field Explanation
* **Customer Info**: Enter your name and any other relevant customer information.
* **reason_for_return**: Explain the reason you would like to return the item, such as it was damaged upon arrival or not what I expected.
* **Item Details**: Describe the item you would like to return, including the item's condition and any other relevant information.
* **Return Address**: Enter the address where you would like to receive the return merchandise authorization.
* **Phone**: Enter your phone number so we can contact you with any updates.
* **Email**: Enter your email address so we can contact you with any updates.
* **Order Details**: Provide any relevant details about the order you would like to return, such as the order number or date of purchase.
