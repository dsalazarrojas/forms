# Warehouse Cooling Maintenance Request Form - Help Guide
## Purpose
The Warehouse Cooling Maintenance Request Form is used to report issues or concerns with the cooling equipment in the warehouse, request maintenance or repairs, and schedule the necessary work. This form helps to ensure that the maintenance requests are properly documented and assigned to the correct contact person.

## How To Complete This Form
To complete this form, follow these steps:

1.  Click on the link to access the form.
2.  Fill in the form as described in the following pages.
3.  Each page has fields with labels that describe what information to enter.

## Field-by-Field Explanation

*   **Request Form 1** (`request_form_1`, text, optional): Enter a brief description of the issue or concern with the cooling equipment.
*   **Cooling Equipment Type** (`cooling_equipment_type`, select one, optional): Select the type of cooling equipment that requires maintenance or repair (e.g., chiller, air handler, etc.).
*   **Maintenance Request** (`maintenance_request`, text, optional): Describe the specific maintenance or repair needed for the equipment.
*   **Location** (`location`, select multiple, optional): Specify the location where the cooling equipment is installed (e.g., floor 1, wing A, etc.).
*   **Priority** (`priority`, select one, optional): Indicate the level of priority for the maintenance request (e.g., high, low, etc.).
*   **Schedule Service** (`schedule_service`, date, optional): Enter the date when the maintenance or repair is scheduled.
*   **Contact Person** (`contact_person`, text, optional): Provide the name and contact information of the person responsible for the task.
*   **Contact Phone** (`contact_phone`, text, optional): Enter the phone number of the contact person.

## Tips
*   Make sure to fill in all the required fields to ensure that the request is properly documented and assigned to the correct contact person.
*   Use the correct format for the date field (e.g., YYYY-MM-DD).
*   If you have any questions or concerns, don't hesitate to contact the facility management team.
