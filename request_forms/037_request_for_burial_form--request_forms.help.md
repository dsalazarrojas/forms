# Request For Burial Form - Help Guide

## Purpose
The "Request For Burial Form" is designed to collect essential information for the burial process to ensure a respectful and proper burial. This form guides the user through the necessary details required for the burial to proceed.

## How To Complete This Form
Before starting, ensure you have all the necessary information required for the burial process. Follow these steps:
1. Enter the location where the burial will take place in the "Location" field.
2. Provide the date for the burial in the "Date Of Burial" field.
3. Select the time for the burial in the "Time Of Burial" field.
4. In the "Burial Cause" field, enter a brief description of the reason for the burial.
5. Select the cemetery where the burial will take place from the options in the "Burial Cemetery" field.
6. Add any additional remarks or notes in the "Remarks" field.

## Field-by-Field Explanation
* **Burial Request Form** (`request_for_burial_form`, text, optional): Enter a brief description of the purpose of the burial request.
* **Location** (`burial_location`, select_one, required): Select the location where the burial will take place from the available options.
* **Date Of Burial** (`date_of_burial`, date, optional): Enter the date of the burial.
* **Time Of Burial** (`time_of_burial`, time, optional): Select the time of the burial from the available options.
* **Burial Cause** (`burial_cause`, text, optional): Enter a brief description of the reason for the burial.
* **Burial Cemetery** (`burial_cemetery`, select_one, optional): Select the cemetery where the burial will take place from the available options.
* **Remarks** (`remarks`, note, optional): Add any additional remarks or notes about the burial.
