# Employee Time Log Adjustment Request Form - Help Guide
## Purpose
The purpose of this form is to request a time log adjustment. Please fill out the form if you need to make a change to your time logs.

## How To Complete This Form
To complete this form, follow these steps:
1. Fill out each field as described in the "Field-by-Field Explanation" section below.
2. Make sure to submit the form once you have filled out all required and optional fields.

## Field-by-Field Explanation
- **Form ID** (`form_id`, text, required: false): This field is the unique identifier for the form. You do not need to fill this out unless you are an administrator.
- **Assigned Tool** (`assigned_tool`, select_one, required: false): Select the tool assigned to this form. You can choose "chatjimmy" or "other".
- **Category** (`category`, select_multiple, required: false): This field is not used in this form.
- **Description** (`description`, text, required: false): Describe the reason for your time log adjustment.
- **Title** (`form_title`, text, required: false): Enter a title for your time log adjustment.
- **Form Category** (`form_category`, select_one, required: false): Select the category for your time log adjustment. You can choose "Request Forms" or "Other".
- **Form Description** (`form_description`, text, required: false): Enter a description for your time log adjustment.
- **Output File** (`form_output_file`, text, required: false): Enter a file name that will be used to output the adjustment request.
- **Form Assigned Tool** (`form_assigned_tool`, select_one, required: false): Select the tool assigned to this form. You can choose "chatjimmy" or "other".
- **Version** (`form_version`, text, required: false): Enter the version of the adjustment.
- **Created By** (`created_by`, text, required: false): This field is not used in this form.
- **Updated By** (`updated_by`, text, required: false): This field is not used in this form.
- **Created At** (`created_at`, date, required: false): This field is not used in this form.
- **Updated At** (`updated_at`, date, required: false): This field is not used in this form.

## Tips
- Please make sure to submit the form once you have filled out all required and optional fields.
- If you need help with your time log adjustment, contact the support team.
