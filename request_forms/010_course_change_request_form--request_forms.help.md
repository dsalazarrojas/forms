# Course Change Request Form - Help Guide
## Purpose
This form is intended for instructors to submit changes to course schedules, including but not limited to: course title changes, instructor assignments, room assignments, and other modifications. If you're not an instructor, please do not complete this form. If you've already submitted a course change request, it will not be processed again.

## How To Complete This Form
To complete this form, follow these steps:
1. Select the original course from the list of options.
2. Provide a brief reason for the change.
3. Select the new course to be substituted in its place.
4. Enter the date of the change.
5. Choose the time of day for the change (if applicable).
6. Enter your name and title to be included as a reference for tracking purposes.

## Field-by-Field Explanation

* **Original Course** (`3`, `select_one`, required): Select the current course that you wish to modify.
* **Reason For Change** (`2`, `text`, optional): Provide a brief explanation for the change, including but not limited to: title changes, instructor changes, room changes, or other modifications.
* **New Course** (`4`, `select_one`, optional): Select the new course to replace the original course.
* **Date of Change** (`5`, `date`, optional): Enter the date when the change is to be implemented.
* **Time of Day** (`6`, `time`, optional): If the change is time-sensitive, enter the exact time of day for the change.
* **Submitted By** (`7`, `text`, optional): Enter your name as it appears on your official university ID or other identifying information.
* **Submitted To** (`8`, `text`, optional): Enter the name and title of the person receiving this form, typically a department administrator or academic advisor.
