# Earnest Money Release Request Form - Help Guide
## Purpose
The Earnest Money Release Request Form is used to request the release of earnest money for a transaction. This form ensures that the terms of the transaction have been met and the earnest money can be released to the buyer.

## How To Complete This Form
1. Ensure you have the necessary approval and authorization to submit this form.
2. Review the form carefully and fill in all required fields.
3. Complete each field according to the instructions provided.
4. Submit the form for review and processing.

## Field-by-Field Explanation

* **Earnest Money Release Request** (`earnest_money_release_request`):
	+ A brief description of the reason for requesting the release of earnest money.
	+ This field is required.
* **Earnest Request Date** (`earnest_money_request_date`):
	+ The date the earnest money was requested.
	+ This field is required and should be in the format `YYYY-MM-DD`.
* **Buyer's Signature** (`buyer_signature`):
	+ Select 'Yes' to confirm that the buyer has signed the agreement.
	+ This field is required.
* **Seller's Signature** (`seller_signature`):
	+ Select 'Yes' to confirm that the seller has signed the agreement.
	+ This field is required.
* **Escrow Team's Signature** (`escrow_team_signature`):
	+ Select 'Yes' to confirm that the escrow team has signed the agreement.
	+ This field is required.
* **Earnest Money Payment Method** (`earnest_money_payment_method`):
	+ Select the method of payment used for the earnest money.
	+ Options are Bank, Wire Transfer, or Check.
	+ This field is required.
* **Earnest Money Payment Details** (`earnest_money_payment_details`):
	+ A description of the payment method and details.
	+ This field is required.
* **Earnest Money Amount** (`earnest_money_amount`):
	+ The amount of earnest money being requested.
	+ This field is required and should be a numeric value.
* **Earnest Money Payment Status** (`earnest_money_payment_status`):
	+ Select the status of the payment.
	+ Options are Active or Inactive.
	+ This field is required.
* **Earnest Money Delivery Preferences** (`earnest_money_delivery_preferences`):
	+ Select 'Yes' for each preferred delivery method.
	+ Options are Yes or No.
	+ This field is required.
* **Earnest Money Signature** (`earnest_money_signature`):
	+ A text field for the buyer to sign and confirm their identity.
	+ This field is required.
* **Earnest Money Signature Type** (`earnest_money_signature_type`):
	+ Select the type of signature used.
	+ Options are Electronic or Ink.
	+ This field is required.
* **Earnest Money Signature Date** (`earnest_money_signature_date`):
	+ The date the signature was made.
	+ This field is required and should be in the format `YYYY-MM-DD`.
* **Earnest Money Signature** (`earnest_money_signature`):
	+ Select 'Yes' to confirm that the buyer has signed the agreement.
	+ This field is not required.
* **Earnest Money Payment Instructions** (`earnest_money_payment_instructions`):
	+ Additional instructions for the payment method.
	+ This field is not required.
* **Earnest Money Delivery Preferences** (`earnest_money_delivery_preferences`):
	+ Select 'Yes' for each preferred delivery method.
	+ This field is not required but recommended for future reference.
