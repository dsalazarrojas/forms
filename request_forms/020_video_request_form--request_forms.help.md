# Video Request Form - Help Guide
## Purpose
The Video Request Form is designed to allow users to submit requests for videos based on specific categories and descriptions. Users can request videos for various purposes, such as training, meetings, or other company events.

## How To Complete This Form
To complete this form, follow these steps:

1. Click on the "Submit" button to start filling out the form.
2. Fill out the "Category" field by selecting the type of video you are requesting (e.g., animation, web series, or short movie).
3. In the "Description" field, provide a detailed description of the video you need.
4. In the "Assigned Tool" field, enter the name of the tool assigned to you for the video request.

## Field-by-Field Explanation
* **Category (Required)**: Select the type of video you are requesting (e.g., animation, web series, or short movie).
* **Description (Required)**: Provide a detailed description of the video you need. Be as specific as possible so that the request can be accurately processed.
* **Assigned Tool (Required)**: Enter the name of the tool assigned to you for the video request.

## Tips
- Make sure to fill out all required fields (Category, Description, and Assigned Tool) to ensure your request is processed accurately.
- If you're unsure about the category, check the options provided and choose the one that best matches your request.
- Be as detailed as possible in the Description field to avoid confusion and ensure your request is fulfilled correctly.
