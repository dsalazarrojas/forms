# Film Scene Retake Request Form - Help Guide

## Purpose
This form is used to request a reshoot for a film scene when there's an issue that requires re-filming or re-processing of the scene. Fill out this form to notify the team of the problem and we'll get back to you with an update on when and how the reshoot will take place.

## How To Complete This Form
1. Review the form fields below to ensure you're submitting all necessary information.
2. Select "Yes" for scenes that need a reshoot.
3. Fill out the "Reason" field with a brief explanation of the issue.
4. Choose the "Priority Level" that best describes the urgency of the reshoot.
5. Select a "Preferred Date" for the reshoot.
6. Choose the "Urgency Level" that best describes the situation.
7. If necessary, attach "Supporting Files" to help the team understand the issue better.
8. Add any "Notes" about the issue or the reshoot.
9. If the issue is related to an assigned tool, indicate if it's "Yes" or "No".
10. Fill out the "Review Date" for when you expect the reshoot to be reviewed.

## Field-by-Field Explanation
* **Scene Reshoot Request**: Select "Yes" for scenes that need a reshoot.
* **Reason**: Briefly explain the issue that requires the reshoot.
* **Priority Level**: Choose the level of priority for the reshoot (High, Low).
* **Preferred Date**: Select a date for the reshoot.
* **Urgency Level**: Choose the level of urgency for the reshoot (High, Low).
* **Supporting Files**: Attach any files that will help the team understand the issue better.
* **Notes**: Add any additional information about the issue or the reshoot.
* **Assigned Tool**: Indicate if the issue is related to an assigned tool (Yes, No).
* **Review Date**: Fill out the date for when you expect the reshoot to be reviewed.
* **Scene Reshoot Request 2-5**: Select "Yes" for additional scenes that need a reshoot.
* **Category/Category 2**: Choose the category related to the issue (Yes, No).
* **Output File/Output File 2/Output File 3**: Attach any output files related to the issue.
* **Assigned Tool 2**: Indicate if the issue is related to an assigned tool (Yes, No).
* **Scene Reshoot Request 6**: Select "Yes" for additional scenes that need a reshoot.
* **Form ID/Form ID 2**: Leave this field blank for internal use only.
* **Category 2/Category 6**: Choose the category related to the issue (Yes, No).
