# youtube_video_fetch_request - Help Guide
## Purpose
This form is designed to collect information about YouTube video fetch requests. It's intended for internal use, such as tracking requests from clients or stakeholders.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the YouTube URL of the video you want to fetch.
2. Specify the purpose of the request, which can be for marketing, creative, or support tasks.
3. Set the deadline for the request, if applicable.
4. List any specific requirements for the fetch, if necessary.
5. Select the priority level of the request: high, medium, or low.
6. (Optional) Add any additional tags or categories to help with organization and filtering.

## Field-by-Field Explanation
### YouTube URL (youtube_url)
* Label: YouTube URL
* Type: text input field
* Required: false

This field asks for the YouTube URL of the video you want to fetch. Enter the URL of the specific video you're requesting.

### Usage Purpose (usage_purpose)
* Label: Usage Purpose
* Type: text input field
* Required: false

This field is for specifying the purpose of the request, such as marketing, creative, or support tasks.

### Deadline (deadline)
* Label: Deadline
* Type: date input field
* Required: false

This field is for setting a specific deadline for the request, if one exists.

### Requirements (requirements)
* Label: Requirements
* Type: text input field
* Required: false

This field is for listing any specific requirements or conditions for the fetch, such as specific video quality or format.

### Tags (tags)
* Label: Tags
* Type: multiple select option field
* Required: false

This field offers three options for selecting tags or categories to help with organization and filtering. Select one or multiple tags as needed.

### Priority (priority)
* Label: Priority
* Type: select one option field
* Required: false

This field asks you to select a priority level for the request, which can be high, medium, or low. This helps with organizing and prioritizing tasks.

### Additional Tips
* Be as specific as possible when entering the YouTube URL and requirements fields.
* If you're unsure about the purpose or priority of the request, it's okay to leave them blank or add them later.
* Use the tags field to help with organizing and filtering requests, if desired.
