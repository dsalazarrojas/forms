# Course AddDrop Request Form - Help Guide
## Purpose
This form is used to request adding or dropping courses in a program. It is designed to facilitate the process of updating course enrollment information.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter your user information in the **User Information** field.
2. Select the program for which you want to add or drop courses.
3. Choose the courses you want to **Add** or **Drop** by selecting the respective options in the **Add Course** and **Drop Course** fields.

## Field-by-Field Explanation
### 1. **User Information** (text)
* This field is used to collect your basic user information.

### 2. **Program** (select_one)
* This field is used to select the program for which you want to add or drop courses.
* Please choose 'Yes' if you want to add or drop courses in this program.

### 3. **Add Course** (select_multiple)
* This field is used to select courses you want to add.
* Choose 'Yes' for each course you want to add.

### 4. **Drop Course** (select_multiple)
* This field is used to select courses you want to drop.
* Choose 'Yes' for each course you want to drop.

### Tips
* Make sure to select only the courses you actually want to add or drop.
* If you are unsure about any of the fields, please contact your program director or support team for assistance.
