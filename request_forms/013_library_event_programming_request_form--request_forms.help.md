# library_event_programming_request_form - Help Guide
## Purpose
The `library_event_programming_request_form` is a tool for librarians to collect and manage requests from community partners for events and programming needs. It helps librarians gather information, track submissions, and make informed decisions about programming and events.

## How To Complete This Form
To complete this form, follow these steps:
1. Fill in the **Community Partner Request** field with a brief description of the community partner's event or program request.
2. Select a date for the **Event Date** using the calendar or date picker tool.
3. Choose a time slot for the **Event Time**, using the format HH:MM or AM/PM.
4. Enter the **Librarian Contact** information for follow-up communication.
5. In the **Request Details** field, elaborate on the request, including any supporting documentation or notes.
6. Select the submission status by choosing one of the two options, **Submit** or **Review**.
7. Finally, choose the type of request being made in the **Request Type** field, such as **Request for Event** or **Request for Program**.
8. Select one or more of the options in the **Event Type** field for the specific type of event or program being requested, such as **Event** or **Program**.

## Field-by-Field Explanation
* **Community Partner Request**: Enter a brief description of the community partner's event or program request.
* **Event Date**: Select a date for the event or program using the calendar or date picker tool.
* **Event Time**: Enter the time for the event or program using the HH:MM or AM/PM format.
* **Librarian Contact**: Enter the name and contact information of the librarian handling the request.
* **Request Details**: Provide an elaborate description of the request, including supporting documentation or notes.
* **Submit Request**: Choose to submit the request or send it for review and further consideration.
* **Request Type**: Select one of the two available options, **Request for Event** or **Request for Program**, indicating the type of request being made.
* **Event Type**: Select one or more of the options, **Event** or **Program**, specifying the type of event or program being requested.
Note: Each field is optional, allowing for tailored input based on the specific request and needs of the community partner.
