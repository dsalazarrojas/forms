# Capital Expenditure Request Form - Help Guide
## Purpose
This form is for requesting capital expenditures for the upcoming budget cycle. It gathers information about the project, funding sources, and timeline for review and approval.

## How To Complete This Form
1.  Fill out the form carefully and accurately, making sure to include all required fields.
2.  Ensure that you have all necessary supporting documents attached or linked, as required.
3.  Follow the guidelines and instructions provided in this form.

## Field-by-Field Explanation

*   **Agency or Department Name** (`Agency Name`, `text`, required): Enter the name of your agency or department.
*   **Submitter Name** (`Submitter Name`, `text`, required): Enter your name as the person submitting the request.
*   **Email Address** (`Email Address`, `email`, required): Enter your email address for contact purposes.
*   **Phone Number** (`Phone Number`, `text`, required): Enter your phone number for contact purposes.
*   **Submission Date** (`Submission Date`, `date`, required): Enter the date of submission.
*   **Fiscal Year for Budget** (`Fiscal Year for Budget`, `text`, required): Enter the fiscal year for which the budget applies.
*   **Project Name** (`Project Name`, `text`, required): Enter the official name of the project.
*   **Project Description** (`Project Description`, `text`, required): Enter a detailed description of the project.
*   **Type of Project** (`Type of Project`, `select_one`, required): Select the type of project (e.g., Infrastructure, Technology, etc.).
*   **Project Category** (`Project Category`, `select_one`, required): Select the category of project (e.g., New asset, Replacement, etc.).
*   **Business Case/Justification** (`Business Case/Justification`, `text`, required): Explain why this project is necessary.
*   **Strategic Alignment** (`Strategic Alignment`, `text`, required): Describe how this project aligns with the agency's goals.
*   **Public Benefit** (`Public Benefit`, `text`, required): Explain how this project benefits the public.
*   **Risk if Not Funded** (`Risk if Not Funded`, `text`, optional): Describe the consequences of not funding this project.
*   **Total Project Cost** (`Total Project Cost`, `number`, required): Enter the total cost of the project.
*   **Cost Estimate Basis** (`Cost Estimate Basis`, `text`, required): Explain how the cost was estimated.
*   **Cost Breakdown by Component** (`Cost Breakdown by Component`, `text`, required): Itemize the costs involved.
*   **Inflation Adjustment Included?** (`Inflation Adjustment Included?`, `select_one`, optional): Indicate if inflation adjustment is included.
*   **Contingency Amount** (`Contingency Amount`, `number`, optional): Enter a buffer for cost overruns.
*   **Proposed Funding Sources** (`Proposed Funding Sources`, `select_multiple`, required): Select all applicable funding sources.
*   **Matching Funds Required?** (`Matching Funds Required?`, `select_one`, optional): Indicate if matching funds are required.
*   **Planned Start Date** (`Planned Start Date`, `date`, required): Enter the planned start date of the project.
*   **Planned Completion Date** (`Planned Completion Date`, `date`, required): Enter the planned completion date of the project.
*   **Project Duration (months)** (`Project Duration (months)`, `number`, optional): Enter the estimated duration of the project.
*   **Project Phasing** (`Project Phasing`, `select_one`, optional): Select the phasing of the project (e.g., single phase, multiple phases, etc.).
*   **Alternatives Considered** (`Alternatives Considered`, `text`, required): Describe the alternatives considered.
*   **Why is Recommended Alternative Best?** (`Why is Recommended Alternative Best?`, `text`, required): Explain why the recommended alternative is the best option.
*   **Department Head Name (for approval)** (`Department Head Name (for approval)`, `text`, required): Enter the name of the department head for approval purposes.

## Tips

*   Please ensure that all required fields are filled out accurately and completely.
*   Attach or link to any necessary supporting documents.
*   Review the form carefully before submission to ensure accuracy and completeness.
