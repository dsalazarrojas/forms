# Document Scanner App Download Request - Help Guide

## Purpose
This form is designed to help you download the Document Scanner App. Please fill it out carefully to ensure that you receive the correct download package for your operating system.

## How To Complete This Form
To complete this form, simply fill out the required fields with the requested information. You do not need to submit any additional information beyond what is required. 

## Field-by-Field Explanation

* **Request Form** (`1`, `text`, required: false): This field is where you can enter your request for the Document Scanner App.
* **Name** (`2`, `text`, required: false): Please enter your name as it appears on your official identification documents.
* **Email** (`3`, `email`, required: false): Enter your email address to enable us to contact you regarding your download request.
* **Version** (`4`, `number`, required: false): If you have a specific version of the app in mind, please enter it here. If not, you can leave this field blank.
* **Operating System** (`5`, `select_one`, required: false): Choose your operating system from the options below:
	+ Mac
	+ Windows
	+ Linux
* **Request Date** (`6`, `date`, required: false): Please enter the date you would like to receive your download package.
* **Comments** (`7`, `note`, required: false): If you have any special requests or comments, please enter them here.
* **Confirm** (`8`, `select_multiple`, required: false): Check the boxes next to 'Yes' to confirm your request:
	+ Yes
* **Assigned To** (`9`, `select_one`, required: false): Choose who you would like to assign this request to:
	+ IT
	+ Support
	+ Software Provider

## Tips
Please ensure that you have not previously submitted a request for the same app version. If you are unsure about any of the fields, please contact your IT department for assistance.
