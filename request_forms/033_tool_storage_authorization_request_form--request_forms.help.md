# Tool Storage Authorization Request Form - Help Guide
## Purpose
This form is used for requesting storage space for tools and equipment.

## How To Complete This Form
To complete this form, please follow these steps:
1. Fill in the form with the required information.
2. Make sure to specify the access level you are requesting (Low, Medium, or High).
3. If you are requesting high-level access, provide more details about the tool and storage location.

## Field-by-Field Explanation
* **Form Details** (`form_details`): This field is a general description of the tool or equipment being requested.
* **User Details** (`user_details`): This field is for providing additional information about the user requesting storage.
* **Tool Details** (`tool_details`): This field is for providing more details about the tool or equipment being requested.
* **Access Level** (`access_level`): This field allows you to specify the level of access you are requesting (Low, Medium, or High).
* **Requestor Phone** (`requestor_phone`): This field is for entering the phone number of the user requesting storage.
* **Requestor Email** (`requestor_email`): This field is for entering the email address of the user requesting storage.
* **Manager Phone** (`manager_phone`): This field is for entering the phone number of the manager who will be approving the storage request.
* **Manager Email** (`manager_email`): This field is for entering the email address of the manager who will be approving the storage request.
* **Manager Approve** (`manager_approve`): This field allows the manager to approve or reject the storage request.
* **Requestor Name** (`requestor_name`): This field is for entering the name of the user requesting storage.
* **Tool Name** (`tool_name`): This field is for entering the name of the tool or equipment being requested.
* **Storage Location** (`storage_location`): This field is for specifying the storage location for the tool or equipment.
* **Storage Size** (`storage_size`): This field is for specifying the storage size for the tool or equipment.
* **Storage Duration** (`storage_duration`): This field is for specifying the duration of storage for the tool or equipment.

## Tips
* Make sure to fill in all required fields.
* If you are requesting high-level access, provide more details about the tool and storage location.
* If you are requesting low-level access, make sure to enter only the minimum required information.
* The manager will review and approve or reject the storage request based on the information provided.
