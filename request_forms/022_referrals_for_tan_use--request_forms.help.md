# Referrals (for TAN Use) - Help Guide
## Purpose
The Referrals (for TAN Use) form is used to collect information from individuals who have referred someone to the TAN use program. This form helps to ensure that the correct referral source is attributed and that the information provided is accurate and up-to-date.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the referral source(s) that referred you to the TAN use program.
2. Provide the name of the referral source.
3. Choose the relationship you have with the referral source.
4. Enter the referral phone number (if applicable).
5. Enter the referral email address (if applicable).
6. Add any additional notes about the referral.
7. Indicate if there are more referrals, and if so, provide the source(s) for those referrals.
8. Confirm the correct referral source for any additional referrals.

## Field-by-Field Explanation

* **Referral Source** (`Referral Source`, `select_multiple`, required/optional): Choose all the sources that referred you to the TAN use program.
* **Referral Name** (`Referral Name`, `text`, optional): Enter the name of the referral source.
* **Referral Relationship** (`Referral Relationship`, `select_one`, optional): Choose the relationship you have with the referral source (e.g., friend, family, colleague).
* **Referral Phone** (`Referral Phone`, `text`, optional): Enter the referral phone number.
* **Referral Email** (`Referral Email`, `email`, optional): Enter the referral email address.
* **Referral Note** (`Referral Note`, `note`, optional): Add any additional notes about the referral source.
* **Number of Referrals** (`Number of Referrals`, `number`, optional): Indicate if there are more referrals.
* **More Referrals** (`More Referrals`, `select_one`, optional): If there are more referrals, select 'Yes' and provide the correct referral source for each additional referral.
* **Referral Source 2** (`Referral Source 2`, `select_multiple`, optional): If there are additional referrals, choose the source(s) for each.

## Tips

* Ensure that you provide accurate and up-to-date information about the referral source(s).
* If you have multiple referrals, be sure to select 'Yes' for the 'More Referrals' field and provide the correct referral source for each.
* If you are unsure about any of the fields, please contact the relevant authorities for clarification.
