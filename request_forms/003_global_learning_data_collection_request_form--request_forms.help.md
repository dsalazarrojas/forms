# Global Learning Data Collection Request Form - Help Guide
## Purpose

This form collects data relevant to global learning for research or educational purposes. It ensures that all necessary details are captured in a structured manner.

## How To Complete This Form

To complete this form, follow these steps:

1. Fill in the required fields with the requested information.
2. Review the form before submission to ensure all fields are accurate.
3. Submit the form once complete.

## Field-by-Field Explanation

* **Form Name** (`form_name`, text, required):
This field is the title of your form.
* **Title** (`form_title`, text, required):
This field is a descriptive title for the form.
* **Description** (`form_desc`, text, optional):
Use this field to add more information about the form.
* **URL** (`form_url`, text, optional):
Enter the URL related to the form.
* **Image** (`form_image`, text, optional):
Add an image related to the form, if necessary.
* **Category** (`form_category`, select_multiple, optional):
Select one or more categories for the form.
* **Category 2** (`form_category_2`, select_one, required):
Choose a category for the form.
* **Tags** (`form_tags`, select_multiple, optional):
Select one or more tags for the form.
* **Tags 2** (`form_tags_2`, select_one, required):
Choose a tag for the form.
* **Date** (`form_date`, date, optional):
Enter the relevant date for the form.
* **Time** (`form_time`, time, optional):
Enter the relevant time for the form.
* **Email** (`form_email`, email, optional):
Enter the email address related to the form.
* **Phone** (`form_phone`, text, optional):
Enter the phone number related to the form.
* **Note** (`form_note`, note, optional):
Add any additional notes about the form.

Please submit the form once you have filled out all the required fields accurately.
