# Floor Plan Revision Request Form - Help Guide

## Purpose

The Floor Plan Revision Request Form is used to collect information for floor plan revisions, including the client's name, reason for the revision, and details of the revision. This form helps the assigned team members to efficiently process the request and provide accurate feedback.

## How To Complete This Form

1. Fill out the form with the required information.
2. Provide a clear and concise description of the revision reason.
3. Ensure the assigned_to field is selected correctly, as it will determine which team member will review and process the request.
4. Enter the correct project status and location.
5. If applicable, add additional comments or details about the revision.
6. Submit the form to proceed with the revision process.

## Field-by-Field Explanation

* **Form Title** (`form_title`, text, optional): Enter a brief title for the floor plan revision request.
* **Client Name** (`client_name`, text, optional): Enter the name of the client who requested the floor plan revision.
* **Floor Plan ID** (`floor_plan_id`, number, optional): Enter the ID of the floor plan being revised.
* **Revision Reason** (`revision_reason`, text, optional): Briefly describe the reason for the floor plan revision.
* **Revision Date** (`floor_plan_revision_date`, date, optional): Enter the date the floor plan revision is needed by.
* **Revision Time** (`floor_plan_revision_time`, time, optional): Enter the time the floor plan revision is needed by.
* **Revision Details** (`floor_plan_revision_details`, text, optional): Provide additional details about the revision, such as what needs to be changed or updated.
* **Contact Name** (`contact_name`, text, optional): Enter the name of the person submitting the request.
* **Contact Email** (`contact_email`, email, optional): Enter the email of the person submitting the request.
* **Contact Phone** (`contact_phone`, text, optional): Enter the phone number of the person submitting the request.
* **Assigned To** (`assigned_to`, select_one, required): Select the team member who should review and process this request.
	+ Options: Architect, Engineer, Construction Team.
* **Assigned By** (`assigned_by`, select_one, required): Select the person who will assign the task to the selected team member.
	+ Options: chatjimmy, Other.
* **Project Status** (`project_status`, select_multiple, optional): Select the current status of the project.
	+ Options: Not Started, Ongoing, Completed.
* **Project Location** (`project_location`, select_multiple, optional): Select the location of the project.
	+ Options: Location 1, Location 2, Location 3.
* **Floor Plan Revision Image** (`floor_plan_revision_image`, text, optional): Upload or enter the URL of an image related to the floor plan revision.
* **Project Manager** (`project_manager`, text, optional): Enter the name of the project manager.
* **Project Manager Contact** (`project_manager_contact`, text, optional): Enter the contact information of the project manager.
* **Project Manager Email** (`project_manager_email`, text, optional): Enter the email of the project manager.
* **Project Manager Phone** (`project_manager_phone`, text, optional): Enter the phone number of the project manager.
* **Additional Comments** (`additional_comments`, text, optional): Add any additional comments or details about the revision.
* **Submission Date** (`submission_date`, date, optional): Enter the date the request was submitted.
* **Submission Time** (`submission_time`, time, optional): Enter the time the request was submitted.
* **Submitted By** (`submitted_by`, text, optional): Enter the name of the person who submitted the request.
* **Submitted By Email** (`submitted_by_email`, text, optional): Enter the email of the person who submitted the request.
* **Submitted By Phone** (`submitted_by_phone`, text, optional): Enter the phone number of the person who submitted the request.
