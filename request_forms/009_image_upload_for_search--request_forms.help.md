# Image Upload For Search - Help Guide
## Purpose
This form is for uploading an image for search purposes.

## How To Complete This Form
To complete this form, follow these steps:

* Click on the "Search Context" field and enter a short description of the context in which you are searching.
* Click on the "Search Image" field and browse for the image you want to upload.
* If you have given your consent for the image to be used, select "Yes" in the "Consent" field.
* In the "Additional Info" field, you can add any additional information you think is relevant to your search.
* If your search is for a specific type of content, select the corresponding "Search Type" in the "Search Type" field.

## Field-by-Field Explanation
* **Search Context (search_context)** (`text`, optional): Enter a brief description of the context in which you are searching.
* **Search Image (search_image)** (`text`, optional): Browse for the image you want to upload.
* **Consent (consent)** (`select_one`, optional): Indicate whether you have given your consent for the image to be used. Select "Yes" if you have given your consent.
* **Additional Info (additional_info)** (`note`, optional): Add any additional information you think is relevant to your search.
* **Search Type (search_type)** (`select_multiple`, optional): Specify the type of search you are performing. Select one or multiple options as applicable.
