# Installation Quote Request Form - Help Guide
## Purpose
This form is designed to gather essential details from customers to provide them with an installation quote. By filling out this form, you will be able to provide your contact information, details about the job, and any additional comments.

## How To Complete This Form
To complete this form, follow these steps:

1. Review the form to ensure you have all the necessary information required.
2. Fill out the form with your information, making sure to complete all required fields.
3. Double-check your responses for accuracy and completeness.

## Field-by-Field Explanation
* **Customer Name** (`customer_name`, text, optional): Enter your name as you would like to be referenced.
* **Contact Number** (`contact_number`, text, optional): Provide your contact number for follow-up communication.
* **Email Address** (`email_address`, email, optional): Enter your email address so we can contact you about your quote.
* **Job Type** (`job_type`, select_one, optional):
	+ Select the type of job you are requesting a quote for (e.g., "Job Type 1", "Job Type 2", "Job Type 3").
* **Installation Date** (`installation_date`, date, optional): Choose the date of the installation.
* **Start Time** (`start_time`, time, optional): Select the start time of the installation.
* **End Time** (`end_time`, time, optional): Select the end time of the installation.
* **Quote Amount** (`quote_amount`, number, optional): Provide the amount you are requesting for the quote.
* **Customer Message** (`customer_message`, text, optional): Enter any additional comments or details about the job.
* **Service Technician** (`service_technician`, select_one, optional):
	+ Select the service technician assigned to your job (e.g., "Technician 1", "Technician 2", "Technician 3").



## Tips
- Make sure to complete all required fields before submitting the form.
- Double-check your responses for accuracy and completeness.
- If you have any questions or concerns, contact us for assistance.
