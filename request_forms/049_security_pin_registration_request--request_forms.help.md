# Security PIN Registration Request - Help Guide
## Purpose
The Security PIN Registration Request form is used to request access to a specific system or feature that requires authentication with a Security PIN. This form is typically filled out by users who need to access restricted areas or perform tasks that require a high level of security clearance.

## How To Complete This Form
To complete the form, please follow these steps:

1. **User Details**: Enter your user details, including your name and any other relevant information that the system requires.
2. **Access Reason**: Briefly describe why you need access to the Security PIN. This can include the specific task or system you need access to.
3. **Policy Acknowledgments**: Select the relevant policies that apply to your request. This ensures you understand and agree to the terms and conditions for access.
4. **Access Reason Details**: Provide additional details about your access reason, if required.
5. **Requester's Name**: Enter the name of the person requesting access.
6. **Department**: Select the department that will be accessing the system or feature.
7. **Email**: Enter your email address, which will be used for communication purposes.
8. **Phone**: Enter your phone number, if necessary.
9. **Date**: Enter the date you need access to start.
10. **Time**: Enter the time you need access to start.

## Field-by-Field Explanation

* **Department** (`Department`, `select_one`, required): Select the department that will be accessing the system or feature.
* **Email** (`Email`, `email`, optional): Enter your email address, which will be used for communication purposes.
* **Phone** (`Phone`, `text`, optional): Enter your phone number, if necessary.
* **Access Reason** (`Access Reason`, `text`, optional): Briefly describe why you need access to the Security PIN.
* **Access Reason Details** (`Access Reason Details`, `text`, optional): Provide additional details about your access reason, if required.
* **Policy Acknowledgments** (`Policy Acknowledgments`, `select_multiple`, optional): Select the relevant policies that apply to your request.
* **Requester's Name** (`Requester's Name`, `text`, optional): Enter the name of the person requesting access.
* **User Details** (`User Details`, `text`, optional): Enter your user details, including your name and any other relevant information.
* **Date** (`Date`, `date`, optional): Enter the date you need access to start.
* **Time** (`Time`, `time`, optional): Enter the time you need access to start.

Note: Please make sure to review and understand the policies before selecting them.
