# Script Rights Usage Request Form - Help Guide
## Purpose
The Script Rights Usage Request Form is used to collect information for script usage rights requests.

## How To Complete This Form
To complete this form, please follow these steps:
1. Select the request type from the options provided.
2. Enter the script name.
3. Enter the usage date (if required).
4. Select the usage duration (if required).
5. Enter the requester's information.
6. Enter the company name (if required).
7. Enter the requester's email address.
8. Select the script rights required.
9. Read and agree to the terms and conditions.
10. Review and submit the form.

## Field-by-Field Explanation
- **Script Rights Usage Request** (`script_rights_usage_request_form`, text, optional): Enter a brief description of the script rights usage request.
- **Request Type** (`request_type`, select_one, required): Select the type of request being made, such as "Option 1", "Option 2", or "Option 3".
- **Script Name** (`script_name`, text, required): Enter the name of the script being requested for usage.
- **Usage Date** (`usage_date`, date, optional): If applicable, enter the date of the script usage.
- **Usage Duration** (`usage_duration`, time, optional): If applicable, enter the duration of the script usage.
- **Requester Info** (`requester_info`, text, optional): Enter any relevant information about the person or entity making the request.
- **Company Name** (`company_name`, text, optional): Enter the name of the company requesting the script usage.
- **Requester Email** (`requester_email`, email, required): Enter the email address of the person or entity making the request.
- **Requester Phone** (`requester_phone`, text, optional): Enter the phone number of the person or entity making the request.
- **Script Version** (`script_version`, text, optional): Enter the version of the script being requested.
- **Script Rights** (`script_rights`, select_multiple, required): Select the rights required for the script usage, such as "Option 1", "Option 2", or "Option 3".
- **Additional Info** (`additional_info`, note, optional): Enter any additional information that may be relevant to the request.
- **Terms and Conditions** (`terms_and_conditions`, select_multiple, required): Select the terms and conditions of the request, such as "Option 1" or "Option 2" or "Option 3".
- **Submit** (`submit`, select_one, required): Select "Submit" to complete the form or select "Other" to provide a custom submission option.
