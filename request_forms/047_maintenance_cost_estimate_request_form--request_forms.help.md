# Maintenance Cost Estimate Request Form - Help Guide
## Purpose
This form is designed to collect information about maintenance requests from the requester. It helps the facility management team to assess the estimated cost of the requested maintenance work and schedule it accordingly.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter your name in the "requester name" field (page 2).
2. Provide a detailed description of the maintenance job in the "job description" field (page 3).
3. Specify the location where the maintenance job needs to be done in the "location" field (page 4).
4. If applicable, select the start and end dates for the maintenance job (pages 5-6).
5. Enter your estimated cost for the maintenance job in the "cost estimate" field (page 7).
6. Add any additional comments or information about the job in the "comments" field (page 8).
7. Provide the contact person's name and phone number in the "contact person" and "phone number" fields (pages 9-10).
8. Enter the person's email address (page 11).
9. Provide the address of the location where the maintenance job needs to be done (page 12).
10. Select the status, type, and priority of the job from the respective dropdown menus (pages 13-15).
11. Finally, select the category and frequency of the job from the dropdown menus (pages 16-17).

## Field-by-Field Explanation
* **requester name** (page 2, required): Enter your name as the person submitting the maintenance request.
* **job description** (page 3, required): Provide a detailed description of the maintenance job, including any necessary details about the work required.
* **location** (page 4, required): Specify the exact location where the maintenance job needs to be performed.
* **start date** (page 5, optional): If applicable, select the start date for the maintenance job.
* **end date** (page 6, optional): If applicable, select the end date for the maintenance job.
* **cost estimate** (page 7, required): Enter your estimated cost for the maintenance job.
* **comments** (page 8, optional): Add any additional comments or information about the job.
* **contact person** (page 9, required): Enter the name of the contact person responsible for the maintenance job.
* **phone number** (page 10, required): Enter the phone number of the contact person.
* **email address** (page 11, optional): Enter the contact person's email address.
* **address** (page 12, required): Enter the address where the maintenance job needs to be performed.
* **job status** (page 13, optional): Select the status of the job from the following options: Open, In Progress, Completed.
* **job type** (page 14, optional): Select the type of job from the following options: Maintenance, Repair, Installation.
* **job priority** (page 15, optional): Select the priority of the job from the following options: High, Medium, Low.
* **job category** (page 16, optional): Select the category of the job from the following options: Urgent, Emergency, Regular.
* **job frequency** (page 17, optional): Select the frequency of the job from the following options: One Time, Reoccuring, Regular.

**Tips**: Please ensure that you fill out all required fields and provide accurate information to help the facility management team to better understand and process your maintenance request. If you need assistance, please contact form@gic.mx
