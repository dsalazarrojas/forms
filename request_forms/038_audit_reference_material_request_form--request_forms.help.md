# Audit Reference Material Request Form - Help Guide
## Purpose
The Audit Reference Material Request Form is designed to collect essential information for users to request access to materials needed for audits and reference purposes.

## How To Complete This Form
To fill out this form, follow these steps:

1. Fill in your full name and contact email and phone number in the "Requester Full Name", "Email Address", and "Phone Number" fields.
2. Select your department from the "Department" dropdown menu.
3. Enter the date you need the materials for in the "Request Date" field.
4. Provide the audit reference or name in the "Audit Reference" field.
5. Choose the type of material needed from the "Material Type" dropdown menu.
6. Describe the material needed in the "Material Description" field.
7. Specify the time period the materials should cover in the "Material Period" field.
8. Indicate the level of urgency with which the materials are needed using the "Urgency Level" dropdown menu.
9. Enter the date by which you need the materials in the "Needed By Date" field.
10. Choose how the materials should be delivered using the "Delivery Method" dropdown menu.
11. Select your preferred format for the materials in the "Format Preference" dropdown menu.
12. Specify if there are any access restrictions in the "Access Restrictions" dropdown menu.
13. Choose the approximate quantity or volume of materials needed in the "Quantity Needed" dropdown menu.
14. Select the purpose of the request from the "Purpose of Request" dropdown menu.
15. Indicate if materials need to be returned in the "Return Required" dropdown menu.
16. If materials need to be returned, specify the return date in the "Return Date" field.
17. Enter any special instructions or notes in the "Special Instructions" field.
18. Check if your manager has approved this request using the "Manager Approval" dropdown menu.

## Field-by-Field Explanation
* **Requester Full Name** (`requester_full_name`, `text`, `required`): Enter your full name.
* **Email Address** (`requester_email`, `email`, `required`): Enter your contact email address.
* **Phone Number** (`requester_phone`, `text`, `required`): Enter your contact phone number.
* **Department** (`department`, `select_one`, `required`): Select your department from the dropdown menu.
* **Request Date** (`request_date`, `date`, `required`): Enter the date you need the materials for.
* **Audit Reference** (`audit_reference`, `text`, `required`): Enter the audit name or reference number.
* **Material Type** (`material_type`, `select_one`, `required`): Choose the type of material needed from the dropdown menu.
* **Material Description** (`material_description`, `text`, `required`): Provide a detailed description of the materials needed.
* **Material Period** (`material_period`, `text`, `required`): Specify the time period the materials should cover.
* **Urgency Level** (`urgency_level`, `select_one`, `required`): Indicate the level of urgency with which the materials are needed.
* **Needed By Date** (`needed_by_date`, `date`, `required`): Enter the date by which you need the materials.
* **Delivery Method** (`delivery_method`, `select_one`, `required`): Choose how the materials should be delivered from the dropdown menu.
* **Format Preference** (`format_preference`, `select_one`, `required`): Select your preferred format for the materials from the dropdown menu.
* **Access Restrictions** (`access_restrictions`, `select_one`, `required`): Specify if there are any access restrictions.
* **Quantity Needed** (`quantity_needed`, `select_one`, `required`): Choose the approximate quantity or volume of materials needed from the dropdown menu.
* **Purpose of Request** (`purpose_of_request`, `select_one`, `required`): Select the purpose of the request from the dropdown menu.
* **Return Required** (`return_required`, `select_one`, `required`): Indicate if materials need to be returned.
* **Return Date** (`return_date`, `date`, `required`: false): If materials need to be returned, enter the date by which they should be returned.
* **Special Instructions** (`special_instructions`, `text`, `required`: false): Enter any special instructions or notes.
* **Manager Approval** (`manager_approval`, `select_one`, `required`): Check if your manager has approved this request.

## Tips

* Be as detailed as possible when filling out the form to ensure that the right materials are provided to you efficiently and effectively.
* Review the form carefully before submitting to ensure all required fields are filled out.
* If you have any questions or concerns, please don't hesitate to reach out to the team.
