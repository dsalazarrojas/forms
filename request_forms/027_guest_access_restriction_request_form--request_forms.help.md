# Guest Access Restriction Request Form - Help Guide
## Purpose
This form is designed to facilitate the request for guest access restrictions. By completing this form, you can request restrictions on specific areas, dates, times, and other access parameters for guests visiting your facility.

## How To Complete This Form
To complete this form, follow the steps below:

1. Ensure you have the required permissions to access the form.
2. Select the relevant fields to fill out based on your requirements.
3. Enter the necessary information for each field.
4. Review your form submission before submitting it.

## Field-by-Field Explanation

* **Guest Name** (`guest_name`, `text`, **Required**): Enter the name of the guest who will be visiting.
* **Guest Email** (`guest_email`, `email`, **Required**): Enter the email address of the guest.
* **Guest Department** (`guest_department`, `select_one`, **Required**): Select the department of the guest's host or affiliation.
* **Access Restriction Date** (`access_restriction_date`, `date`, **Required**): Select a date when the access restriction will begin.
* **End Date** (`end_date`, `date`, **Optional**): Select a date when the access restriction will end (if applicable).
* **Restriction Status** (`restriction_status`, `select_one`, **Required**): Choose the status of the restriction (Approved, Rejected, or Pending).
* **Approved By** (`approved_by`, `select_one`, **Required**): Select the person who approved the access restriction.
* **Restriction End Date** (`restriction_end_date`, `date`, **Optional**): Select a date when the access restriction will end (if applicable).
* **Department Head Approvals** (`department_head_approvals`, `select_multiple`, **Required**): Select multiple department heads who have approved the access restriction.
* **Request Status** (`request_status`, `select_one`, **Required**): Choose the status of the request (New Request, Approved, or Rejected).
* **Access Level** (`access_level`, `select_multiple`, **Required**): Select the access level for the restricted areas (High, Medium, or Low).
* **Notes** (`notes`, `note`, **Optional**): Add any additional comments about the access restriction.
* **Restricted Areas** (`restricted_areas`, `select_multiple`, **Required**): Select the areas that will be restricted for the guest.
* **Access Restricted Areas** (`access_restricted_areas`, `select_multiple`, **Required**): Confirm if the access restriction is applicable to the selected areas.
* **Restricted Dates** (`restricted_dates`, `select_multiple`, **Required**): Select the dates when the access restriction will be in effect.
* **Restricted Times** (`restricted_times`, `select_multiple`, **Required**): Select the times of the day when the access restriction will be in effect.
* **Restricted Days** (`restricted_days`, `select_multiple`, **Required**): Select the days of the week when the access restriction will be in effect.
* **Access Restricted Days** (`access_restricted_days`, `select_multiple`, **Optional**): Select the days of the week when the access restriction will not be in effect (if applicable).
* **Restricted Timeslots** (`restricted_timeslots`, `select_multiple`, **Optional**): Select the timeslots when the access restriction will be in effect (if applicable).
* **Restricted Days of Week** (`restricted_days_of_week`, `select_multiple`, **Required**): Select the days of the week when the access restriction will be in effect.
* **Restricted Timeslot Start Time** (`restricted_timeslot_start_time`, `time`, **Required**): Select the start time of the timeslot when the access restriction will be in effect.
* **Restricted Timeslot End Time** (`restricted_timeslot_end_time`, `time`, **Required**): Select the end time of the timeslot when the access restriction will be in effect.
* **Comments** (`comments`, `note`, **Optional**): Add any additional comments about the access restriction.
