# Vanity Mode Application Form - Help Guide
## Purpose
The Vanity Mode Application Form is designed to gather user information and preferences for vanity mode access. Please ensure you only submit this form if you have a genuine interest in vanity mode.

## How To Complete This Form
1. Fill in your user details, including name and contact information.
2. Provide a brief motivation for requesting vanity mode access.
3. If applicable, select yes to upload supporting files.
4. Describe your user request in the text field.
5. Enter your email address and phone number.
6. Enter your date and time of birth (or leave blank if you don't have this information).
7. Enter your note (optional).
8. Select one option from the select one field.
9. Select multiple options from the select multiple field.
10. Enter integer or decimal values for the integer and decimal fields, respectively.
11. Enter date and time values for the date and time fields, respectively.
12. Select one option from the select one list field.
13. Select multiple options from the select multiple list field.
14. Enter integer or decimal values for the integer list and decimal list fields, respectively.
15. Enter date values for the date list field.
16. Enter time values for the time list field.
17. Enter text in the text field.
18. Enter text in the textarea field.
19. Upload a file to the file field (optional).

## Field-by-Field Explanation

* **User Details** (`user_details`, `text`, optional): Enter your name and any other relevant user details.
* **Contact Details** (`contact_details`, `text`, optional): Enter your contact details, including email and phone number.
* **Motivations** (`motivations`, `text`, optional): Describe why you want vanity mode access.
* **Supporting Files** (`supporting_files`, `select_one`, optional): If you have any supporting files, select "Yes".
* **User Request** (`user_request`, `note`, optional): Describe your request in detail.
* **Email** (`email`, `email`, optional): Enter your email address.
* **Phone Number** (`phone_number`, `text`, optional): Enter your phone number.
* **Date Of Birth** (`date_of_birth`, `date`, optional): Enter your date of birth (YYYY-MM-DD format).
* **Time Of Birth** (`time_of_birth`, `time`, optional): Enter your time of birth (HH:MM format).
* **Note** (`note`, `note`, optional): Enter a note or comment about your request.
* **Select One** (`select_one`, `select_one`, optional): Select one option.
* **Select Multiple** (`select_multiple`, `select_multiple`, optional): Select multiple options.
* **Integer Field** (`integer_field`, `number`, optional): Enter an integer value.
* **Decimal Field** (`decimal_field`, `number`, optional): Enter a decimal value.
* **Date Field** (`date_field`, `date`, optional): Enter a date value (YYYY-MM-DD format).
* **Time Field** (`time_field`, `time`, optional): Enter a time value (HH:MM format).
* **Select One List** (`select_one_list`, `select_one`, optional): Select one option from the list.
* **Select Multiple List** (`select_multiple_list`, `select_multiple`, optional): Select multiple options from the list.
* **Integer List** (`integer_list`, `number`, optional): Enter a list of integers.
* **Decimal List** (`decimal_list`, `number`, optional): Enter a list of decimals.
* **Date List** (`date_list`, `date`, optional): Enter a list of date values (YYYY-MM-DD format).
* **Time List** (`time_list`, `time`, optional): Enter a list of time values (HH:MM format).
* **Text Field** (`text_field`, `text`, optional): Enter text in the field.
* **Textarea Field** (`textarea_field`, `note`, optional): Enter text in the textarea field.
* **File Field** (`file_field`, `text`, optional): Upload a file to the field.
