# local_listings_request_form - Help Guide
## Purpose
This form is designed to collect information from users for local listings requests, including user details, listing information, contact details, location, and additional information.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the **User Info** section with your personal details, including your name and any other relevant information.
2. Provide the required **Listing Info** for the listing you are requesting.
3. Enter your **Contact Info** if you wish to be contacted about the request.
4. Specify the **Location** where the listing is requested.
5. (Optional) Upload any relevant **Files** related to the request.
6. Finally, provide any **Additional Info** about the request in the **Additional Info** field.

## Field-by-Field Explanation
- **User Info** (required): This section is for your personal details, including your name and any other relevant information.
  - **Listing Info** (required): This section is for the details of the listing you are requesting.
  - **Contact Info** (optional): This section is for you to provide your contact information if you wish to be contacted about the request.
  - **Location** (required): This is where the listing is requested.
  - **Upload Files** (optional): This is where you can upload any relevant files related to the request.
  - **Additional Info** (required): This is a text field for you to provide any additional information about the request.
