# Document Processing Authorization Letter Request Form - Help Guide

## Purpose
The Document Processing Authorization Letter Request Form is used to collect information and requests from users to request processing of documents. This form helps the representative to understand the requirements and urgency of the document processing request.

## How To Complete This Form

To fill out this form, please follow these steps:

1. Select the correct options for each field as per your requirements.
2. Fill out the representative details and request description fields if required.
3. Submit your request.

## Field-by-Field Explanation

* **Request Form**: Enter a brief description of your document processing request.
* **Representative Details**: Enter the name, email, and other relevant contact information of the representative.
* **Signature Capture**: Select 'Yes' if you want to capture a signature on the document.
* **Data Collection**: Select 'Yes' if you want to collect any data from the document.
* **Document Details**: Enter any additional details about the document you are requesting to be processed.
* **Additional Document Details**: Enter any other document details if necessary.
* **Request Signature**: Select 'Yes' if you want the representative to sign the document.
* **Document Capture**: Enter the method of document capture you want to use (e.g. email, fax, etc.).
* **Document Capture Method**: Select all applicable methods for document capture.
* **Additional Capture Method**: Select any additional methods for document capture.
* **Request Status**: Select the status of your request (Active or Inactive).
* **Document Status**: Select the status of the document (Active or Inactive).
* **Signature Status**: Select the status of the signature (Active or Inactive).
* **Request Type**: Select the type of request.
* **Request Priority**: Select the priority of your request.
* **Request Urgent**: Select 'Yes' if your request is urgent.
* **Document Category**: Select all applicable categories for the document.
* **Document Sub Category**: Select all applicable sub categories for the document.
* **Request Description**: Enter a description of your request.
* **Representative Signature**: Select 'Yes' if you want the representative to sign the form.
* **Document Capture Date**: Enter the date and time you want the document to be captured.
* **Document Capture Time**: Enter the time you want the document to be captured.
* **Email**: Enter the email address of the representative.
* **Submit Request**: Submit your request.
