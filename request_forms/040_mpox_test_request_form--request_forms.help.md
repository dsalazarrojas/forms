# Mpox Test Request Form - Help Guide
## Purpose
The Mpox Test Request Form is a tool used to collect information from patients or individuals requesting medical testing. This form helps the laboratory or healthcare provider understand the patient's symptoms, test requirements, and contact information.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill out the required fields with accurate information about yourself.
2. Provide as much detail as possible in the optional fields to help the laboratory or healthcare provider understand your situation.
3. Review your submission before submitting it to ensure accuracy.

## Field-by-Field Explanation

* **First Name** (`first_name`, text, required): Enter your first name for identification purposes.
* **Last Name** (`last_name`, text, required): Enter your last name for identification purposes.
* **Date of Birth** (`date_of_birth`, date, required): Enter your date of birth to verify your identity.
* **Address** (`address`, text, required): Enter your address where we can contact you.
* **Phone** (`phone`, text, required): Enter your phone number where we can contact you.
* **Contact Email** (`contact_email`, email, required): Enter your email address where we can contact you.
* **Symptoms** (`symptoms`, text, optional): Describe your symptoms to help the laboratory or healthcare provider understand your situation.
* **Doctor's Note** (`doctor_note`, text, optional): If you have a doctor's note, please enter it here.
* **Test Date** (`test_date`, date, required): Enter the date you wish to take the test.
* **Doctor's Name** (`doctor_name`, text, optional): If you have a doctor's note, enter their name here.
* **Lab Location** (`lab_location`, text, optional): If you have a preferred lab location, enter it here.
* **Doctor's Phone** (`doctor_phone`, text, optional): If you have a doctor's phone number, enter it here.
* **Test Type** (`test_type`, select_one, required): Select the type of test you wish to perform (e.g., PCR, antigen).
* **Lab Name** (`lab_name`, text, optional): If you have a preferred lab name, enter it here.
* **Test Result** (`test_result`, text, optional): If you have a test result, enter it here.
* **Doctor's Note 2** (`doctor_note_2`, text, optional): If you have additional doctor's notes, enter them here.
* **Lab Technician** (`lab_tech`, text, optional): If you have a lab technician's name, enter it here.
* **Test Status** (`test_status`, select_one, required): Select the status of your test (e.g., pending, completed).
* **Lab Note** (`lab_note`, text, optional): If you have additional lab notes, enter them here.
* **Second Test Result** (`test_result_2`, select_one, optional): If you have a second test result, select it here.
* **Test Requester** (`test_requester`, text, optional): If you are the test request, enter your name here.
* **Contact Phone** (`contact_phone`, text, optional): If you have a contact phone number, enter it here.
* **Test Requester Email** (`test_requester_email`, email, optional): If you have a test requester's email address, enter it here.
* **Lab Result Comment** (`lab_result_comment`, text, optional): If you have additional lab result comments, enter them here.
* **Follow-up Instructions** (`follow_up_instructions`, text, optional): If you have follow-up instructions, enter them here.
