# Open Access Repository Upload Request Form - Help Guide

## Purpose
The purpose of this form is to collect information from authors and contributors to upload their manuscripts to an Open Access Repository.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in your author details.
2. Select the manuscript files you would like to upload.
3. Choose the repository you would like to upload your manuscript to.
4. Select the access rights you would like to grant for your uploaded work.
5. Confirm that you have reviewed and agree to the submission agreement.
6. (Optional) Select the no-code form option if you do not have a code to submit.
7. Confirm that you are the author or contributor of the manuscript.

## Field-by-Field Explanation

* **Author Details** (`author_details`, text, required): This is where you will enter your name and contact information to be associated with the uploaded manuscript.
* **Manuscript Files** (`manuscript_files`, select_multiple, required): Please select all the manuscript files you would like to upload. You can select multiple files from the list of options provided.
* **Repository Selections** (`repository_selections`, select_one, required): Choose the repository where you would like to upload your manuscript. This will help us to guide the upload process.
* **Access Rights** (`access_rights`, select_one, required): Select the access rights you would like to grant for your uploaded manuscript. This will determine the permissions and usage of your work.
* **Submission Agreement** (`submission_agreement`, note, required): Please review and confirm that you have read and agreed to the submission guidelines and terms.
* **Author Confirmation** (`author_confirmation`, text, required): Confirm that you are the author or contributor of the manuscript.
* **No-Code Form** (`no_code_form`, select_one, required): Select this option if you do not have code to submit. This will help us to process your request accurately.
* **No-Code Form** (`no_code_form` is actually not required for the form, but I've included it for reference.
