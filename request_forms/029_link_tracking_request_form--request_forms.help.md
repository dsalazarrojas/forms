# Link Tracking Request Form - Help Guide
## Purpose
The Link Tracking Request Form is used to create a new link tracking request. This form allows users to specify the type of link, URL, date, time, and other relevant details to track links. It is essential to fill out this form correctly to ensure accurate link tracking.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the Link Type from the dropdown menu.
2. Enter the URL of the link you want to track.
3. Choose the Date for the link.
4. Select the Time of Day for the link.
5. Enter your email address to receive updates on the link's status.
6. Select the person or team assigned to track the link.
7. Choose the status of the link (optional).
8. Enter the tracking link (if known).
9. Select the Reporting Schedule for the link.
10. Choose the stakeholders who should have access to the link.
11. Select the Campaign Measurement for the link (optional).
12. Enter any additional Notes for the link.

## Field-by-Field Explanation

* **Link Type** (Link Type, Select One, Required): Choose the type of link you want to track, such as "Website" or "Social Media Post".
* **URL** (URL, Text, Required): Enter the URL of the link you want to track.
* **Date** (Date, Date, Not Required): Enter the date for the link.
* **Time of Day** (Time of Day, Time, Required): Select the time of day for the link.
* **Email** (Email, Email, Required): Enter your email address to receive updates on the link's status.
* **Assigned To** (Assigned To, Select Multiple, Required): Choose the person or team assigned to track the link.
* **Status** (Status, Select One, Optional): Choose the status of the link (optional).
* **Tracking Link** (Tracking Link, Text, Required): Enter the tracking link (if known).
* **Reporting Schedule** (Reporting Schedule, Select One, Optional): Choose the Reporting Schedule for the link.
* **Stakeholder Access** (Stakeholder Access, Select Multiple, Optional): Choose the stakeholders who should have access to the link.
* **Campaign Measurement** (Campaign Measurement, Select One, Optional): Choose the Campaign Measurement for the link (optional).
* **Notes** (Notes, Note, Optional): Enter any additional notes for the link.
* **Notes 2-13** (Notes 2, Note, Optional): Enter any additional notes for the link (if needed).

**Tips**

* Make sure to fill out all required fields.
* Double-check the form for any errors before submitting.
* If you need help, contact your administrator.
* Review the link's status regularly for updates.
* Use the link tracking system to track your links efficiently.
