# Merchant Terminal Information Request Form - Help Guide
## Purpose
The Merchant Terminal Information Request Form is designed to collect information about a merchant terminal. 

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the required fields with accurate and complete information.
2. Ensure that all fields are correctly filled before submitting the form.

## Field-by-Field Explanation
* **terminal_number**: Enter the number of the terminal (e.g., 123 Main St).
* **Terminal Address**: Enter the terminal's physical address (e.g., 123 Main St, Anytown USA).
* **terminal_city**: Enter the city of the terminal (e.g., Anytown).
* **terminal_state**: Enter the state or province of the terminal (e.g., USA).
* **terminal_country**: Enter the country of the terminal (e.g., USA).
* **terminal_postal_code**: Enter the postal code or zip code of the terminal (e.g., 12345).
* **merchant_name**: Enter the name of the merchant associated with the terminal (e.g., John Doe).
* **terminal_contact**: Enter the contact person's name and phone number at the terminal (e.g., Jane Smith, 555-1234).
* **merchant_terminal_contact**: Enter the contact person's name and phone number at the terminal (e.g., Jane Smith, 555-1234).
* **request_reason**: Enter a brief explanation for the request (e.g., To process a new payment method).
* **merchant_email**: Enter the email address of the merchant associated with the terminal (e.g., [jane.smith@terminal.com](mailto:jane.smith@terminal.com)).
* **merchant_phone**: Enter the phone number of the merchant associated with the terminal (e.g., 555-1234).
* **merchant_fax**: Enter the fax number of the merchant associated with the terminal (e.g., 555-5555).
* **merchant_note**: Enter any additional notes about the terminal or request (e.g., Special instructions for payment processing).
* **request_date**: Enter the date of the request (e.g., 2024-03-15).
* **request_time**: Enter the time of the request (e.g., 10:00 AM).

Note: The fields with a hint will help guide you in completing the form correctly.
