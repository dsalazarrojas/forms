# events-hospitality-consultation-form - Help Guide
## Purpose
This form is designed to collect information about upcoming events, such as whether they are hospitality-related, their date and time of occurrence, the duration of the event, the number of guests expected, how guests can contact the event host, and any additional instructions provided to the event host.

## How To Complete This Form
To complete this form, please follow these steps:

1. Choose the type of event you are hosting (Event Type).
2. Select the date of the event's occurrence.
3. Select the time of the event's occurrence.
4. Choose whether the event will have a duration (yes or no).
5. Enter the expected number of guests (only required for events with duration).
6. Select the method of contact for guests (yes or no).
7. Enter your email address for contact.
8. Enter your phone number for contact.
9. If necessary, provide any additional instructions for the event host.

## Field-by-Field Explanation
* **Event Type (event-type)**: Choose 'Yes' or 'No' to indicate whether this is a hospitality-related event.
* **Date of Occurrence (date-of-occurrence)**: Select the date on which the event will take place.
* **Time of Occurrence (time-of-occurrence)**: Select the time of day when the event will occur.
* **Event Duration (event-duration)**: Choose 'Yes' or 'No' to indicate whether the event will have a duration.
* **Guest Quantity (guest-quantity)**: Enter the expected number of guests for events with duration.
* **Contact Method (contact-method)**: Choose 'Yes' or 'No' to indicate how guests can contact the event host.
* **Email (email)**: Enter your email address for contact.
* **Phone (phone)**: Enter your phone number for contact.
* **Additional Instructions (additional-instructions)**: If necessary, provide additional information or instructions for the event host.

## Tips
* Please ensure that you only fill out this form when the event is not already scheduled or planned internally.
* Double-check your answers to ensure accuracy.
