# Student Staff Reference Request Form - Help Guide
## Purpose

This form is designed to collect information for student staff reference purposes.

## How To Complete This Form

1. Fill out the form completely and accurately.
2. Select the most suitable referee for the student based on their qualifications, experience, and availability.
3. Provide detailed comments about the student's strengths and weaknesses.

## Field-by-Field Explanation

* **Request Form** (1): A text field to input any additional information about the student.
* **Name** (2): The student's name.
* **Referee Name** (3): The name of the referee.
* **Referee Title** (4): The title or position of the referee.
* **Email** (5): The email address of the referee.
* **Phone** (6): The contact number of the referee.
* **Department** (7): The department of the referee.
* **Date of Reference** (8): The date of reference.
* **Relationship with Student** (9): A text field to describe the relationship between you and the student.
* **Length of Service** (10): A number field to input the length of service.
* **Referee Comments** (11): A free-text field for additional comments about the student.
* **Select Referee** (12): A dropdown menu to choose a referee from the list.
* **Referee 1 Name** (13): The name of the first selected referee.
* **Referee 2 Name** (14): The name of the second selected referee (if applicable).
* **Referee 3 Name** (15): The name of the third selected referee (if applicable).
* **Referee 4 Name** (16): The name of the fourth selected referee (if applicable).
* **Referee 5 Name** (17): The name of the fifth selected referee (if applicable).
* **Select Referee 2** (18): A dropdown menu to choose another referee from the list.
* **Referee 6 Name** (19): The name of the second selected referee.
* **Referee 7 Name** (20): The name of the seventh selected referee (if applicable).
* **Referee 8 Name** (21): The name of the eighth selected referee (if applicable).
* **Referee 9 Name** (22): The name of the ninth selected referee (if applicable).
* **Referee 10 Name** (23): The name of the tenth selected referee (if applicable).
* **Comments** (24): A free-text field for additional comments.
* **Submitted By** (25): The name of the person submitting the form.

Note: Some fields are optional, but it's recommended to fill out as much information as possible to ensure a comprehensive reference for the student.
