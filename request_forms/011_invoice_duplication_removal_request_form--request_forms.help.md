# Invoice Duplication Removal Request Form - Help Guide
## Purpose
This form is used to request the removal of an existing duplicate invoice. Please fill out the form carefully to ensure that your request is processed correctly.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the correct option for "Request for Review" from the dropdown menu.
2. Fill out the "Description" field with a clear explanation of the issue.
3. Attach any supporting documents that are relevant to the request.
4. Fill out all the required fields, including "Customer Name", "Vendor Name", "Customer Email", and "Submitter Email".

## Field-by-Field Explanation

* **Submit a Request** (`submit_form`): This field allows you to select the reason for requesting the removal of the duplicate invoice.
* **Attach Supporting Documents** (`attach_documents`): This field is for attaching any documents that are relevant to the request.
* **Description** (`description`): Please fill out this field with a clear explanation of the issue.
* **List Duplicate Invoices** (`duplicate_invoices`): List all the duplicate invoices that need to be removed.
* **Vendor Name** (`vendor_name`): This is the name of the vendor who is involved in the issue.
* **Customer Name** (`customer_name`): This is the name of the customer who is involved in the issue.
* **Request for Review** (`review_request`): This field allows you to select the reason for requesting a review.
* **Submit** (`submit_button`): Please fill out this field with a clear message to indicate that you are submitting the request.
* **Vendor Comments** (`vendor_comments`): This field is for any comments from the vendor.
* **Customer Comments** (`customer_comments`): This field is for any comments from the customer.
* **Review Requester** (`review_requester`): This field is for the person requesting the review.
* **Review Request Date** (`review_request_date`): This field is for the date of the review request.
* **Reviewed By** (`reviewed_by`): This field is for the person who reviewed the request.
* **Review Date** (`review_date`): This field is for the date of the review.
* **Duplicate Status** (`duplicate_status`): This field allows you to select the status of the duplicate invoice.
* **Duplicate Date** (`duplicate_date`): This field is for the date of the duplicate invoice.
* **Customer Email** (`customer_email`): This is the email of the customer who is involved in the issue.
* **Customer Phone** (`customer_phone`): This is the phone number of the customer.
* **Submitter Email** (`submitter_email`): This is the email of the person submitting the request.
* **Submitter Phone** (`submitter_phone`): This is the phone number of the person submitting the request.
* **Vendor Email** (`vendor_email`): This is the email of the vendor.
* **Vendor Phone** (`vendor_phone`): This is the phone number of the vendor.
* **Review Requester Email** (`review_requester_email`): This is the email of the person requesting the review.
* **Review Requester Phone** (`review_requester_phone`): This is the phone number of the person requesting the review.
* **Created At** (`created_at`): This field is for the date when the request was created.
