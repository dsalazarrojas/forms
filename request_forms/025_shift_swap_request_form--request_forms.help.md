# shift_swap_request_form - Help Guide
## Purpose
This form is used to request a shift swap with a team member. You can use it to swap shifts with a colleague for any reason.

## How To Complete This Form
1. Ensure that you have a valid reason for requesting the shift swap.
2. Select the start date, start time, end date, and end time for the shift you want to swap.
3. Provide the shift ID of the shift you want to swap with.
4. Select whether you are the team member requesting the swap (team_member) or not.
5. Enter the reason for the shift swap request in the shift_swap_request_reason field.
6. Choose the start time and end time for the swap.
7. Select the shift ID of the new shift you want to swap to.
8. Ensure that the swap shift is available by checking the options list.
9. Submit the form.

## Field-by-Field Explanation
* **start_date** (1, date, required/optional): Enter the date you want to start your shift.
* **start_time** (2, time, required/optional): Enter the start time of your shift.
* **end_date** (3, date, required/optional): Enter the date your shift ends.
* **end_time** (4, time, required/optional): Enter the end time of your shift.
* **shift_id** (5, number, required/optional): Enter the shift ID you want to swap with.
* **team_member** (6, select_multiple, required/optional): Check this field if you are the team member requesting the swap.
* **shift_swap_request_reason** (7, text, required/optional): Enter a valid reason for requesting the shift swap.
* **swap_start_time** (8, time, required/optional): Enter the start time of the shift you want to swap to.
* **swap_end_time** (9, time, required/optional): Enter the end time of the shift you want to swap to.
* **swap_shift_id** (10, select_one, required/optional): Select the shift ID of the new shift you want to swap to.
* **submit** (11, text, required/optional): Click to submit your shift swap request.
*   **Tips**: Please ensure that you have all necessary permissions to submit this form and that you have followed all required procedures to avoid any issues in the future.
