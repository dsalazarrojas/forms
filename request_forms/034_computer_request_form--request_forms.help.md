# Computer Request Form - Help Guide

## Purpose
The Computer Request Form is a crucial tool for submitting computer hardware requests. It ensures that your computer needs are met accurately and efficiently. By filling out this form, you will be able to:

* Clearly state the reason for the request
* Specify the type of device and its requirements
* Provide necessary details for procurement and approval processes

## How To Complete This Form
To fill out the Computer Request Form:

1. Select "Request Details" and provide a brief description of your request.
2. Enter your name as the "Requester name".
3. Specify the "Department" responsible for the request.
4. Choose the type of device you are requesting (Laptop, Tablet, Desktop, or Other).
5. State the "Purpose" of the request.
6. If necessary, specify the "Duration needed" for the device.
7. Optionally, provide "Preferred specifications" for the device.
8. Indicate if "Approval needed" from a manager or procurement team.
9. Add any "Additional notes" to provide context.

## Field-by-Field Explanation

* **Request Details --** (`section_request_details`, note, optional): A brief description of your computer request. This field is a free-form text section where you can provide a brief overview of your needs.
* **Requester name** (`requester_name`, text, required): Enter your full name as the person submitting the request.
* **Department** (`department`, text, required): Specify the department responsible for the request. This helps ensure that the request is directed to the correct team.
* **Device requested** (`device_requested`, select_one, required): Choose the type of device you are requesting (Laptop, Tablet, Desktop, or Other).
* **Purpose** (`purpose`, text, required): Clearly state the reason for your request. This helps the team understand your needs.
* **Duration needed** (`duration_needed`, text, optional): If you're requesting a temporary device, specify the duration needed (e.g., Permanent, Temporary with end date).
* **Preferred specifications** (`preferred_specifications`, text, optional): If you have specific requirements or preferences for the device, provide them here.
* **Approval needed** (`approval_needed`, select_one, required): Check if approval is required from a manager or procurement team.
* **Additional notes** (`additional_notes`, text, optional): Add any additional context or details that will help the team process your request efficiently.

## Tips
* Ensure that you provide accurate and clear information to avoid errors.
* Review your submission carefully before submitting to ensure all required fields are filled.
* If you're unsure about any field, please don't hesitate to reach out to your department contact for guidance.
