# Feral Cat TNR Request Form - Help Guide
## Purpose
This form is for requesting assistance with feral cat TNR services. Please provide detailed information about the feral cat, its location, and the person or organization requesting assistance.

## How To Complete This Form
To complete this form, follow the instructions below:

1. Fill out all the required fields.
2. Provide accurate and detailed information about the feral cat and its location.
3. Select the correct request status and category for the feral cat.
4. Confirm that you have read and understood the form submission confirmation.

## Field-by-Field Explanation
* **Feral Cat Name** (`feral_cat_name`, `text`, required): Enter the name of the feral cat.
* **Location Address** (`location_address`, `text`, required): Enter the street address where the feral cat is located.
* **Location City** (`location_city`, `text`, optional): Enter the city where the feral cat is located (e.g., city name, e.g., "Anytown").
* **Location State** (`location_state`, `select_one`, required): Select the state where the feral cat is located from the list.
* **Location Zip** (`location_zip`, `text`, required): Enter the zip code of the location.
* **Location Country** (`location_country`, `text`, optional): Enter the country where the feral cat is located (e.g., "United States").
* **Location Latitude** (`location_latitude`, `number`, optional): Enter the latitude of the location (e.g., 37.7749).
* **Location Longitude** (`location_longitude`, `number`, optional): Enter the longitude of the location (e.g., -122.4192).
* **Request Status** (`request_status`, `select_one`, required): Select the current status of the request (e.g., "Open", "Closed", "In Progress", "Scheduled", "Completed", "Pending").
* **Request Category** (`request_category`, `select_one`, required): Select the category of the request (e.g., "General", "Feral Cat Spay/Neuter", "Feral Cat Trap-Neuter-Release (TNR)", "Feral Cat Adoption", "Feral Cat Rescue", "Other").
* **Requested By** (`requested_by`, `text`, required): Enter the name of the person or organization requesting assistance.
* **Date Trapped** (`date_trapped`, `date`, optional): Enter the date the feral cat was trapped (e.g., 2022-01-01).
* **Last Seen** (`date_last_seen`, `date`, optional): Enter the last date the feral cat was seen (e.g., 2022-01-01).
* **Notes** (`notes`, `text`, optional): Enter any additional information about the feral cat or request.
* **Volunteer Name** (`volunteer_name`, `text`, optional): Enter the name of the volunteer assisting with the feral cat.
* **Volunteer Email** (`volunteer_email`, `email`, optional): Enter the email of the volunteer assisting with the feral cat.
* **Volunteer Phone** (`volunteer_phone`, `text`, optional): Enter the phone number of the volunteer assisting with the feral cat.
* **Volunteer Organization** (`volunteer_organization`, `text`, optional): Enter the name of the organization the volunteer is representing.
* **Volunteer License** (`volunteer_license`, `select_one`, optional): Select the license type of the volunteer (e.g., "License 1", "License 2").
* **Volunteer Experience** (`volunteer_experience`, `text`, optional): Enter any relevant experience or credentials of the volunteer.
* **Volunteer Vehicle Type** (`volunteer_vehicle_type`, `text`, optional): Enter the type of vehicle used by the volunteer (e.g., "car", "van", "boat").
* **Volunteer Vehicle License** (`volunteer_vehicle_license`, `select_one`, optional): Select the license type of the volunteer's vehicle (e.g., "License 1", "License 2").
* **Volunteer Vehicle Insurance** (`volunteer_vehicle_insurance`, `select_one`, optional): Select the insurance status of the volunteer's vehicle (e.g., "Insured", "Uninsured").
* **Volunteer Vehicle Year** (`volunteer_vehicle_year`, `number`, optional): Enter the year of the volunteer's vehicle (e.g., 2010).
* **Confirm Form Submission** (`confirm_form_submission`, `text`, required): Confirm that you have read and understood the form submission confirmation.

Note: Make sure to review the fields carefully and provide accurate and detailed information about the feral cat and its location.
