# Process Control Adjustment Request Form - Help Guide
## Purpose
The Process Control Adjustment Request Form is a tool used to document and track requests for adjustments to equipment, processes, or other system settings. This form helps ensure that necessary adjustments are made and communicated effectively.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the Equipment Id of the equipment or process you wish to adjust.
2. Enter the Process Id of the equipment or process you wish to adjust.
3. Describe the reason for the adjustment request in the Description field.
4. If applicable, choose the Request Status to update the request's status.
5. Enter any additional comments or notes in the Comments field.

## Field-by-Field Explanation
* **Process Control Adjustment Request** (`request_form`): A brief description of the adjustment request. This field is a text field where you can enter a short explanation of the adjustment request.
* **Equipment Id** (`equipment_id`): Enter the Equipment Id of the equipment or process you wish to adjust. This is a unique identifier for the equipment or process.
* **Process Id** (`process_id`): Enter the Process Id of the equipment or process you wish to adjust.
* **Description** (`description`): Enter a detailed description of the reason for the adjustment request.
* **Date Request** (`date_request`): Enter the date on which the adjustment request was made. This is a date field where you can select a date.
* **Time Request** (`time_request`): Enter the time on which the adjustment request was made. This is a time field where you can select a time.
* **Requested By** (`requested_by`): Enter the person or team making the adjustment request. This field is used for internal tracking and record-keeping.
* **Approved By** (`approved_by`): Enter the person or team that approved the adjustment request.
* **Reason for Change** (`reason_for_change`): Enter the reason for the adjustment request. This field is for internal tracking and record-keeping.
* **Request Status** (`request_status`): Select the status of the adjustment request from the options provided. This field is used to update the request's status.
* **Assigned To** (`assigned_to`): Enter the person or team that will be making the adjustment. This field is used for internal tracking and record-keeping.
* **Comments** (`comments`): Enter any additional comments or notes about the adjustment request. This field is for internal tracking and record-keeping.
