# Menu Addition Support Request - Help Guide
## Purpose
This form is used to submit a support request for adding a menu item to our platform. Please fill out the form below with the required information to help us assist you with your menu addition request.

## How To Complete This Form
1. Click on the "Submit" button to send your request.
2. Fill out the form with the requested information.

## Field-by-Field Explanation
* **Menu Item Name** (`menu_item_name`, text, Optional): Enter the name of the menu item you'd like to add.
* **Category** (`category`, select_multiple, Required): Select one or more categories for your menu item from the provided options.
* **Description** (`item_description`, text, Optional): Provide a brief description of the menu item.
* **Item Price** (`item_price`, number, Optional): Enter the price of the menu item.
* **Tags (comma-separated)** (`item_tags`, text, Optional): Enter a comma-separated list of tags for your menu item.
* **Image URL** (`image_url`, text, Optional): Enter the URL of the image for your menu item.
* **Urgency** (`urgency`, select_one, Optional): Select the level of urgency for your menu addition request.
* **Attachment URL** (`attachment_url`, text, Optional): Enter the URL of the attachment for your menu item.
* **Restaurant ID** (`restaurant_id`, number, Optional): Enter the ID of the restaurant where the menu item belongs to.
* **Status** (`item_status`, select_one, Optional): Select the status of your menu addition request.
* **Type** (`item_type`, select_one, Required): Select the type of menu item you are adding (Menu Item or Menu Update).
* **Group** (`menu_group`, select_one, Optional): Select the group of the menu item.
* **Category** (`item_category`, select_one, Required): Select the category of the menu item.
* **Submit** (submit, Required): Click on this button to send your request.

## Tips
* Make sure to fill out all required fields.
* Use a comma-separated list for tags.
* Select the correct urgency and type of menu item.
* If you have any attachments, make sure to provide the URL.
