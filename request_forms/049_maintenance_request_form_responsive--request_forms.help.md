# Maintenance Request Form Responsive - Help Guide
## Purpose

This form is a collection of questions that will help us understand your maintenance request. It will help us determine the type of service you need and ensure that we can provide the best possible maintenance solution for your issue.

## How To Complete This Form

To complete this form, follow these steps:

* Fill out all the required fields.
* Select one option for the service type (Internet, TV, Phone, House Cleaning, Computer, Leaks).
* Answer yes or no to the instant request field.
* Briefly describe your maintenance request in the description field.
* Enter your phone number and email if you want us to contact you about your request.

## Field-by-Field Explanation

* **Maintenance Request Form** (`maintenance_request_form_responsive_page_1`, note, required): This is the main form page. Please read and understand the purpose of this form before filling it out.
* **What type of service do you need?** (`maintenance_request_form_responsive_page_2`, select_one, required): Select one of the options to indicate the type of service you require. Options are:
	+ Internet
	+ TV
	+ Phone
	+ House Cleaning
	+ Computer
	+ Leaks
* **Instant request** (`maintenance_request_form_responsive_page_3`, select_multiple, required): Answer yes or no to whether you need the service immediately.
* **Description** (`maintenance_request_form_responsive_page_4`, text, required): Briefly describe your maintenance request here.
* **Phone** (`maintenance_request_form_responsive_page_5`, text, required): Enter your phone number so we can contact you.
* **Email** (`maintenance_request_form_responsive_page_6`, email, required): Enter your email address so we can contact you.
* **Date** (`maintenance_request_form_responsive_page_7`, date, required): Enter the date of your maintenance request.

## Tips

* Please be as detailed as possible in your description to help us understand your request better.
* Make sure to enter accurate contact information so we can reach out to you promptly.
* If you have any additional information or clarification, please include it in the description field.
