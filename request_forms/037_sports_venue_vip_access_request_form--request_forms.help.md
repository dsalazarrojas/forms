# Sports Venue VIP Access Request Form - Help Guide
## Purpose
This form is used to request access to a sports venue for specific events and time slots.

## How To Complete This Form

To complete this form, follow these steps:

1. Enter your name, email address and other necessary information in the "User Information" page.
2. Choose the "Media Requester" field to indicate the purpose of your request (e.g. Media, Photography).
3. Enter a valid email address in the "Email" field.
4. Select the "Request Type" that best suits your needs.
5. Choose the "VIP Access Level" that you need (if applicable).
6. Enter the date and start and end time of the event you need access for.
7. Choose the time slot you need access for from the provided options.
8. Provide any additional comments about your request in the "Comments" field.
9. Click the "Submit" button to send your request.

## Field-by-Field Explanation
* **User Information** (User Information, Text, Required): Enter your name and any other necessary information.
* **Media Requester** (Media Requester, Text, Optional): Choose the purpose of your request (e.g. Media, Photography).
* **Email** (Email, Email, Required): Enter a valid email address.
* **Request Type** (Request Type, Select One, Optional): Select the reason for your request.
* **VIP Access Level** (VIP Access Level, Select Multiple, Optional): Choose the level of VIP access you need.
* **Event Start Date** (Event Start Date, Date, Optional): Enter the date of the event you need access for.
* **Event End Date** (Event End Date, Date, Optional): Enter the end date of the event you need access for.
* **Time Slot** (Time Slot, Time, Optional): Select the time slot you need access for.
* **Comments** (Comments, Note, Optional): Provide any additional comments about your request.
* **Submit** (Submit, Text, Optional): Click to send your request.

## Tips

* Make sure to enter accurate and complete information in the required fields.
* Choose the correct options in the "Request Type" and "VIP Access Level" fields.
* If you have any additional information or questions, please provide them in the "Comments" field.
* If your request is not a valid reason, please do not fill out this form. We will respond with an explanation or request for more information.
