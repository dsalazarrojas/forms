# Headcount Forecasting Request Form - Help Guide
## Purpose
The Headcount Forecasting Request Form is a tool used to collect information for headcount forecasting. This form helps managers request a headcount for a specific role, type, or location to support various business processes such as resource allocation, project planning, and budgeting.

## How To Complete This Form
To complete this form, follow these steps:

1.  Enter the name and contact information of the submitting manager.
2.  Provide the manager's name and email address.
3.  Enter the manager's phone number (if available).
4.  Indicate whether the role is 'Yes' or 'No'.
5.  Select one or multiple role types (if applicable).
6.  Enter the expected headcount (number of staff required).
7.  Select the start and end dates for the headcount.
8.  Enter the timeline for the headcount (if available).
9.  Specify the location for the headcount (if applicable).

## Field-by-Field Explanation

*   **Submitting Manager**: Enter the name of the submitting manager.
    *   **Type: text**: This field is used to collect the name of the submitting manager.
*   **Manager Name**: Enter the name of the manager who will be responsible for the headcount.
    *   **Type: text**: This field is used to collect the name of the manager.
*   **Manager Email**: Enter the email address of the manager.
    *   **Type: email**: This field is used to collect the email address of the manager.
*   **Manager Phone**: Enter the phone number of the manager (if available).
    *   **Type: text**: This field is used to collect the phone number of the manager.
*   **Role**: Indicate whether the role is 'Yes' or 'No'.
    *   **Type: select_one**: This field is used to determine if the role is required or not.
*   **Role Type**: Select one or multiple role types (if applicable).
    *   **Type: select_multiple**: This field is used to select multiple role types.
*   **Headcount**: Enter the expected number of staff required for the headcount.
    *   **Type: number**: This field is used to collect the expected headcount.
*   **Start Date**: Select the start date for the headcount.
    *   **Type: date**: This field is used to select the start date for the headcount.
*   **End Date**: Select the end date for the headcount.
    *   **Type: date**: This field is used to select the end date for the headcount.
*   **Timeline**: Enter the timeline for the headcount (if available).
    *   **Type: time**: This field is used to collect the timeline for the headcount.
*   **Location**: Specify the location for the headcount (if applicable).
    *   **Type: text**: This field is used to collect the location for the headcount.

## Tips
- Be accurate when filling out the form to ensure that the headcount forecasting is accurate.
- Ensure that you submit a new request only if your previous request has not been processed or if there has been a significant change in your circumstances.
- If you are unsure about any field, refer to your manager or the headcount forecasting team for guidance.
