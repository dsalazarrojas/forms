# Tax Request Form - Help Guide
## Purpose
This form is used to collect information for tax-related requests.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out each field as requested.
2. Ensure that all required fields are completed before submitting the form.

## Field-by-Field Explanation

* **Request Information** (`tax_request_form`, text, required: false): Please provide a brief description of your tax-related request.
* **Tax Status** (`tax_status`, select_one, required: false): Please select 'True' if you are requesting tax status, 'False' otherwise.
* **Has Filing Requirement** (`tax_return_status`, select_one, required: false): Please select 'True' if you have a filing requirement, 'False' otherwise.
* **Filing Date** (`tax_return_filing_date`, date, required: false): Please enter the date you are requesting to file your tax return.
* **Filing Frequency** (`tax_return_filing_frequency`, select_one, required: false): Please select how often you file your tax return ('once', 'quarterly', 'annually').
* **Taxpayer Identification** (`taxpayer_identification`, text, required: false): Please enter your taxpayer identification number.
* **Email** (`taxpayer_email`, email, required: false): Please enter your email address.
* **Phone** (`taxpayer_phone`, text, required: false): Please enter your phone number.
* **Tax Return Address** (`tax_return_address`, text, required: false): Please enter the address where you would like to receive your tax return.
* **Line 1** (`tax_return_address_1`, text, required: false): Please enter the line 1 of the address where you would like to receive your tax return.
* **Line 2** (`tax_return_address_2`, text, required: false): Please enter the line 2 of the address where you would like to receive your tax return.
* **City** (`tax_return_city`, text, required: false): Please enter the city where you would like to receive your tax return.
* **State** (`tax_return_state`, text, required: false): Please enter the state where you would like to receive your tax return.
* **Zip** (`tax_return_zip`, text, required: false): Please enter the zip code where you would like to receive your tax return.
* **Signature** (`taxpayer_signature`, note, required: false): Please provide your signature for the tax return.
* **Taxpayer Signature** (`tax_return_signature`, note, required: false): Please provide your tax return signature.
* **Organization Name** (`organization_name`, text, required: false): Please enter the name of the organization requesting tax information.
* **Organization EIN** (`organization_ein`, text, required: false): Please enter the EIN number of the organization requesting tax information.
* **Organization Address** (`organization_address`, text, required: false): Please enter the address of the organization requesting tax information.
* **Organization Address 1** (`organization_address_1`, text, required: false): Please enter the line 1 of the address of the organization requesting tax information.
* **Organization Address 2** (`organization_address_2`, text, required: false): Please enter the line 2 of the address of the organization requesting tax information.
* **Organization City** (`organization_city`, text, required: false): Please enter the city of the organization requesting tax information.
* **Organization State** (`organization_state`, text, required: false): Please enter the state of the organization requesting tax information.
* **Organization Zip** (`organization_zip`, text, required: false): Please enter the zip code of the organization requesting tax information.

Note that all fields are optional, but please ensure that all required fields are completed before submitting the form.
