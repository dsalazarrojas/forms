# video_to_text_conversion_request - Help Guide
## Purpose
This form is used to request a video-to-text conversion service.

## How To Complete This Form
To complete this form, follow these steps:

1. **Upload Video**: Upload a video file to initiate the request. 
2. Choose **Language** and select the language you want the conversion to be done in.
3. Select **Audio Output** to choose the audio format for the converted text (mp3 or wav).
4. **Video File**: You can also provide the path to an existing video file for conversion. 
5. **File Format**: Choose the resolution and aspect ratio of the converted text (4K, 8K, 1080p, 1080i, 2K, 6K).
6. **Transcription Speed**: Choose the transcription speed (normal, fast, priority).
7. **Email To**: Enter the email address where you want to receive the converted text file.
8. **File Size**: You can optionally provide the size of the video file for more accurate conversion.
9. **Description**: Provide a brief description of the request (optional).

## Field-by-Field Explanation
* **Upload Video**: Upload a video file from your computer or provide a URL to a publicly accessible video file.
