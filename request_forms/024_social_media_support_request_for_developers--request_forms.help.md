# Social Media Support Request For Developers - Help Guide
## Purpose
The Social Media Support Request For Developers form is used by developers to report and track issues related to social media presence, which might be affecting the company's online image or operations.

## How To Complete This Form
To complete this form, follow these steps:

1.  Select the type of social media platform affected by the issue (e.g., Facebook, Twitter, Instagram).
2.  Describe the issue you are facing in the "Describe The Issue" field.
3.  Provide a screenshot URL (if applicable) in the "Screenshot URL" field.
4.  If you have any additional details about the issue, please provide them in the "Issue Details" field.
5.  Enter your email address in the "Email" field.
6.  Choose the priority of the issue (High, Medium, or Low) in the "Priority" field.
7.  Enter the date and time the issue occurred in the "Date" field.

## Field-by-Field Explanation

*   **User Input** (`User Input`, `text`, optional): Please enter any additional information you think is relevant to the issue.
*   **Type of Social Media** (`Type of Social Media`, `select_multiple`, required): Select one or more social media platforms where the issue occurred (e.g., Facebook, Twitter, Instagram).
*   **Describe The Issue** (`Describe The Issue`, `text`, required): Provide a detailed description of the issue you are experiencing.
*   **Screenshot URL** (`Screenshot URL`, `text`, optional): If you have a screenshot of the issue, please provide the URL where it can be found.
*   **Issue Details** (`Issue Details`, `text`, optional): If you have any additional details about the issue, please provide them here.
*   **Email** (`Email`, `email`, required): Enter your email address so we can contact you for further assistance.
*   **Phone** (`Phone`, `text`, optional): If you prefer to be contacted via phone, please enter your phone number.
*   **Priority** (`Priority`, `select_one`, required): Choose the priority of the issue (High, Medium, or Low).
*   **Detailed Description** (`Detailed Description`, `text`, optional): If you have any additional details about the issue, please provide them here.
*   **Status** (`Status`, `select_one`, optional): Choose the status of the issue (Open, Closed, or Resolved).
*   **Resolution** (`Resolution`, `text`, optional): If you have a resolution for the issue, please provide it here.
*   **Developer** (`Developer`, `text`, optional): If you want to specify a developer who can assist with the issue, please enter their name.
*   **Team Lead** (`Team Lead`, `email`, optional): If you want to assign a team lead to the issue, please enter their email address.
*   **Date** (`Date`, `date`, required): Enter the date the issue occurred.
*   **Time** (`Time`, `time`, optional): If you have the time the issue occurred, please enter it here.
*   **Priority Label** (`Priority Label`, `text`, optional): If you have a label for the priority of the issue, please enter it here.
*   **Resolution Label** (`Resolution Label`, `text`, optional): If you have a label for the resolution of the issue, please enter it here.
*   **Status Label** (`Status Label`, `text`, optional): If you have a label for the status of the issue, please enter it here.
*   **Notes** (`Notes`, `text`, optional): If you have any additional notes about the issue, please enter them here.
*   **Confirm E-mail** (`Confirm E-mail`, `email`, optional): Please enter your email address to confirm your identity.
*   **Team Lead Confirm** (`Team Lead Confirm`, `text`, optional): If you want to confirm the team lead's identity, please enter their name.
*   **Issue Date** (`Issue Date`, `text`, optional): If you have any additional details about the issue date, please enter them here.
*   **Team Lead Phone** (`Team Lead Phone`, `text`, optional): If you have any additional details about the team lead's phone number, please enter them here.
*   **Assigned Tool** (`Assigned Tool`, `text`, optional): If you have any additional details about the tool assigned to the issue, please enter them here.

## Tips

*   Before submitting the form, please make sure to fill out all required fields accurately and completely.
*   Review the form carefully to ensure it is complete and submitted correctly.
*   If you're unsure about any field, please refer to this guide or contact the support team for clarification.
*   This form is not intended for general inquiries or support requests. Please do not use this form for questions about company policies, procedures, or general concerns.
