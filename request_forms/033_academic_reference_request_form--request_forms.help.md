# Academic Reference Request Form - Help Guide

## Purpose
This form is designed to help faculty members or advisors provide academic references for their students. The information collected will be used to assist the student in their graduate school applications, undergraduate programs, scholarship applications, research positions, job applications, or internship applications.

## How To Complete This Form
To complete this form, please follow these steps:

1. Please enter the student's name, email address, and student ID in the corresponding fields.
2. Enter the reference provider's name and email address.
3. Select the student's relationship to the reference provider.
4. Choose the purpose of the reference (e.g., graduate school application, undergraduate program, etc.).
5. Enter the target institution or program the student is applying to.
6. Set the reference deadline.
7. If applicable, specify the qualities or skills to highlight and the relevant courses or projects.
8. Indicate if the student has provided their resume or CV to the reference provider.
9. Confirm if the reference provider has received samples of the student's academic work.
10. Specify if you may or may not contact the student for additional information.
11. Waive or reserve your right to view the reference letter.
12. Provide any additional information that may help the reference provider in writing the letter.

## Field-by-Field Explanation

* **Academic Reference Request** (`reference_request_intro`, note, optional): This is an introduction to the form.
* **Student Name** (`student_name`, text, required): Enter the full name of the student requesting the reference.
* **Student Email** (`student_email`, email, required): Enter the current email address of the student.
* **Student ID** (`student_id`, text, required): Enter the official student identification number.
* **Reference Provider Name** (`reference_provider_name`, text, required): Enter the full name of the faculty member or advisor being asked for a reference.
* **Reference Provider Email** (`reference_provider_email`, email, required): Enter the professional email address of the reference provider.
* **Relationship to Student** (`relationship_to_student`, text, required): Describe how you know the student (e.g., as a professor, advisor, mentor, etc.).
* **Purpose of Reference** (`reference_purpose`, select_one, required): Select the reason for the reference (e.g., graduate school application, undergraduate program, etc.).
* **Target Institution or Program** (`target_institution_program`, text, required): Enter the name of the institution or program the student is applying to.
* **Reference Deadline** (`reference_deadline`, date, required): Set the deadline for the reference.
* **Specific Qualities to Highlight** (`specific_qualities_requested`, text, optional): Specify the qualities or skills the reference provider should emphasize.
* **Relevant Courses or Projects** (`relevant_courses_projects`, text, optional): List the relevant courses or projects the reference provider should focus on.
* **Resume/CV Provided** (`resume_cv_provided`, select_one, required): Indicate if the student has provided their resume or CV to the reference provider.
* **Samples of Previous Work Provided** (`previous_work_samples`, select_one, required): Confirm if the student has provided samples of their academic work.
* **Follow-Up Permission** (`follow_up_permission`, select_one, required): Specify if the reference provider may contact the student if they need more information.
* **Waiver of Rights** (`waiver_rights`, select_one, required): Waive or reserve your right to view the reference letter.
* **Additional Information** (`additional_information`, text, optional): Provide any additional information that may help the reference provider.
