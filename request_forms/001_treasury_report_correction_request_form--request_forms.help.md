# Treasury Report Correction Request Form - Help Guide
## Purpose

The Treasury Report Correction Request Form is used to report errors or discrepancies in treasury reports. Fill out this form to request corrections and provide accurate information to support your request.

## How To Complete This Form

1. Review the report and identify the issue you would like to correct.
2. Fill out the form completely and accurately, including all required fields.
3. Attach any supporting documents to help support your request.
4. Submit the form for review and approval.

## Field-by-Field Explanation

* **What is the issue with the report?**:
	+ A text field to describe the problem you've found with the report.
* **Report ID**:
	+ A field to enter the original Report ID number.
* **Report Date**:
	+ A field to enter the original report date.
* **Report Time**:
	+ A field to enter the original report time.
* **Corrected Report Date**:
	+ A field to enter the corrected report date.
* **Corrected Report Time**:
	+ A field to enter the corrected report time.
* **Reason for the correction**:
	+ A text field to describe the reason for the correction.
* **Attachments**:
	+ A field to attach supporting documents.

## Tips

* Please make sure to attach all relevant supporting documents to your request.
* If you're unsure about any field, ask your supervisor or colleague for clarification.
* Make sure to review your form carefully before submitting it to ensure accuracy and completeness.
