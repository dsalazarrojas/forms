# Smart Sensor Network Upgrade Request Form - Help Guide
## Purpose
The Smart Sensor Network Upgrade Request Form is used to submit an upgrade request for the Smart Sensor Network. This form helps the upgrade team process your request efficiently.

## How To Complete This Form
To complete this form, follow these steps:

*   Fill out all required fields.
*   If a field is not required, but you want to provide additional information, feel free to do so.
*   Use the "Notes" field to include any additional comments or details about your request.

## Field-by-Field Explanation
### sensor_network_id (ID Number)
*   This field is optional and allows you to specify your sensor network ID (if applicable).

### network_upgrade_scope (Text Field)
*   In this text field, please explain the specific upgrade scope you require.

### justification
*   Please provide a brief justification for your upgrade request.

### preferred_upgrade_date (Date Field)
*   Enter the date you prefer to upgrade your sensor network.

### sensor_type_upgrade (Multiple Selection)
*   Select one or more sensor types you want to upgrade.

### sensor_network_location (Text Field)
*   Provide the location of your sensor network.

### engineering_team_review_status (Selection Field)
*   The possible options are:
    -   pending
    -   in progress
    -   approved

### upgrade_priority (Number Field)
*   Please enter a number to represent the priority of your upgrade request.

### upgrade_frequency (Text Field)
*   Specify the frequency of upgrades you require.

### notes (Note Field)
*   Use this field to add any additional comments or details about your request.
