# Security Request Form - Help Guide
## Purpose
The purpose of this form is to collect information for new security requests, allowing for efficient tracking and management of security incidents, issues, or concerns.

## How To Complete This Form
To complete this form, follow the steps below:

1. Fill out the form completely and accurately, ensuring that all required and optional fields are filled out.
2. Review the form before submitting to ensure that all information is correct and relevant to the request.
3. Submit the form, and a designated team member will review and process it accordingly.

## Field-by-Field Explanation
- **New Security Request** (`security_request_form`, text, required): This is the title of your security request, briefly describing the issue or concern you are submitting.
- **Date Time of Request** (`date_time_of_request`, date, required): The date and time you submitted this request.
- **Name** (`name`, text, required): Your name and contact information for follow-up communication.
- **Department** (`department`, select_one, optional): The department related to your security request (e.g., IT, HR, Finance).
- **Location** (`location`, text, optional): The location where the security request is relevant (e.g., office, building, server room).
- **Reason** (`reason`, text, optional): A brief explanation of the security request, including the reason for the request.
- **Security Level** (`security_level`, select_one, optional): The level of security involved in your request (Low, Medium, High).
- **Category** (`security_category`, select_multiple, optional): The category or categories related to your security request (e.g., Network, Email, Server).
- **Notes** (`notes`, note, optional): Additional information or comments about your security request.
- **Assigned To** (`assigned_to`, select_multiple, optional): The team members or individuals assigned to handle your security request.
- **Assigned Tool** (`assigned_tool`, select_one, optional): The tool or application used to manage your security request (e.g., chatjimmy).
- **Status** (`status`, select_one, optional): The current status of your security request (Open, In Progress, Resolved).
- **Due Date** (`due_date`, date, optional): The date by which your security request is due.
- **Due Time** (`due_time`, time, optional): The time by which your security request is due.
- **Priority** (`priority`, select_one, optional): The priority level of your security request (Low, Medium, High).
- **Tags** (`tags`, select_multiple, optional): Keywords or labels assigned to your security request for easier tracking and organization.
