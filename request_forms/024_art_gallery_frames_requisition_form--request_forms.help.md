# Art Gallery Frames Requisition Form - Help Guide
## Purpose
The Art Gallery Frames Requisition Form is used to request frames for exhibitions or projects within the art gallery. This form gathers necessary information to ensure that the frames are ordered correctly and on time.
## How To Complete This Form
- Fill out the form completely and accurately to ensure that your frame request is processed correctly.
- Ensure that all required fields are filled out.
- If you are unsure about any information, please contact the relevant department or personnel.
## Field-by-Field Explanation
* **Requisition Date** (id: 1, required): Date of the frame request.
* **Requester Name** (id: 2, required): Full name of the person or entity making the request.
* **Requester Email** (id: 3, required): Email address of the person or entity making the request.
* **Department** (id: 4, required): The department associated with the exhibition or project.
* **Exhibition Name** (id: 5, required): Name of the exhibition or project.
* **Exhibition Dates** (id: 6, required): Start and end dates of the exhibition or project.
* **Installation Date** (id: 7, required): Date when frames are needed.
* **Frame Type** (id: 8, required): Type of frame required.
* **Frame Material** (id: 9, required): Material of the frame.
* **Frame Finish** (id: 10, optional): Frame finish or color.
* **Frame Dimensions** (id: 11, required): Size of the frame (width x height x depth).
* **Quantity Needed** (id: 12, required): Number of frames required.
* **Matting Required** (id: 13, required): Whether matting is needed.
* **Matting Specifications** (id: 14, optional): Description of matting requirements.
* **Glazing Type** (id: 15, required): Type of glazing (glass or acrylic).
* **Back Type** (id: 16, required): Type of backing.
* **Hanging Method** (id: 17, required): Preferred hanging method.
* **Artwork Details** (id: 18, required): Description of the artwork to be framed.
* **Artwork Value** (id: 19, optional): Approximate value of artwork.
* **Conservation Requirements** (id: 20, required): Conservation requirements for the artwork.
* **Estimated Cost** (id: 21, optional): Estimated cost per frame.
* **Total Budget** (id: 22, optional): Total budget for all frames.
* **Vendor Preference** (id: 23, optional): Preferred vendor.
* **Rush Request** (id: 24, required): Whether this is a rush order.
* **Rush Justification** (id: 25, optional): Reason for rush if applicable.
* **Approval Needed** (id: 26, required): Whether approval is needed for this order.
* **Approving Authority** (id: 27, optional): Name of the approving authority.
* **Additional Notes** (id: 28, optional): Any other information related to the order.
Note that fields with 'optional' designation should be filled out only if necessary or if additional information is required.
