# Quest Requisition Form - Help Guide
## Purpose
This form is used to gather information and requirements for a project or request. It's designed to help project managers and team members track and submit project requests, ensuring that all necessary details are captured and communicated effectively.

## How To Complete This Form
1.  Select the **Request Date** (ID 1) by choosing a date using the date picker.
2.  Indicate if the project is assigned to any **Employees** (ID 2).
3.  Choose how the project is **Requested** (ID 3).
4.  Select the **Output Format** (ID 6) to choose the desired output format.
5.  Enter the **Project Title** (ID 7).
6.  Choose the **Project Status** (ID 8).
7.  Select the **Project Start Date** (ID 9) and **Project Deadline** (ID 10).
8.  Indicate if a **Project Manager** (ID 11) is assigned.
9.  Enter the **Project Location** (ID 12).
10. Choose if the project is assigned to any **Tool** (ID 13).
11. Select the **Output Frequency** (ID 14).
12. Enter the **Output Formats** (ID 15).
13. Indicate if the project is assigned to anyone **To** (ID 16).
14. Enter the **Output File** (ID 17).
15. Select the **Project Start Time** (ID 18).
16. Choose the **Project Deadline 2** (ID 19).
17. Select the **Project Status 2** (ID 20).
18. Choose the **Output Type** (ID 21).
19. Enter the **Project Manager 2** (ID 22).
20. Indicate if the project is assigned to anyone **To 2** (ID 23).
21. Choose the **Output Frequency 2** (ID 24).
22. Enter the **Output File 2** (ID 25).

## Field-by-Field Explanation

* **Request Date** (ID 1) (Date, Optional): Enter the date when the project request was made.
* **Assigned Employees** (ID 2) (Select Multiple, Optional): Check if the project is assigned to any employees.
* **Requested By** (ID 3) (Select One, Optional): Choose how the project is requested.
* **Requested For** (ID 4) (Select One, Optional): Choose who the project is requested for.
* **Description** (ID 5) (Note, Optional): Enter a brief description of the project.
* **Output Format** (ID 6) (Select One, Optional): Select the output format for the project.
* **Project Title** (ID 7) (Text, Optional): Enter the title of the project.
* **Project Status** (ID 8) (Select One, Optional): Choose the current project status.
* **Project Start Date** (ID 9) (Date, Optional): Enter the project start date.
* **Project Deadline** (ID 10) (Date, Optional): Enter the project deadline.
* **Project Manager** (ID 11) (Select Multiple, Optional): Check if a project manager is assigned.
* **Project Location** (ID 12) (Text, Optional): Enter the location of the project.
* **Assigned Tool** (ID 13) (Select One, Optional): Check if the project is assigned to any tool.
* **Output Frequency** (ID 14) (Select One, Optional): Choose the output frequency.
* **Output Formats** (ID 15) (Text, Optional): Enter the output formats.
* **Assigned To** (ID 16) (Select One, Optional): Check if the project is assigned to anyone.
* **Output File** (ID 17) (Text, Optional): Enter the output file.
* **Project Start Time** (ID 18) (Time, Optional): Enter the project start time.
* **Project Deadline 2** (ID 19) (Time, Optional): Enter the project deadline 2.
* **Project Status 2** (ID 20) (Select One, Optional): Choose the project status 2.
* **Output Type** (ID 21) (Select One, Optional): Select the output type.
* **Project Manager 2** (ID 22) (Text, Optional): Enter the project manager 2.
* **Assigned To 2** (ID 23) (Select One, Optional): Check if the project is assigned to anyone 2.
* **Output Frequency 2** (ID 24) (Select One, Optional): Choose the output frequency 2.
* **Output File 2** (ID 25) (Text, Optional): Enter the output file 2.

## Tips

* Please fill out each field accurately and truthfully.
* Ensure all required fields are completed before submitting the form.
* For fields marked "Optional", feel free to provide more information, but it's not mandatory.
* This form is for gathering project request information, so ensure the details provided are relevant to the project.
* If you have any questions or need help, contact your project manager or team lead.
