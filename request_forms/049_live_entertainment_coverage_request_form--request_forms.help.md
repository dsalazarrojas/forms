# Live Entertainment Coverage Request Form - Help Guide

## Purpose
The "Live Entertainment Coverage Request Form" is used to request media coverage for live events such as concerts, festivals, and live events. It allows users to provide essential information about the event, including the submitter's details and event specifics.

## How To Complete This Form

To complete this form, follow the steps below:

1. Fill out the required fields with accurate information about the submitter and the event.
2. Review each field carefully to ensure that you are submitting accurate and complete information.
3. If you are unsure about any field, please consult the field-by-field explanation below.

## Field-by-Field Explanation

* **Submitter Name**: The name of the person submitting the request. This field is required.
* **Contact Email**: The email address of the person submitting the request. This field is required.
* **Contact Phone**: The phone number of the person submitting the request. This field is required.
* **Event Name**: The name of the event, such as "Concert for Charity" or "Festival of the Arts". This field is required.
* **Event Dates**: The start and end dates of the event, in the format `YYYY-MM-DD` or `YYYY-MM-DD to YYYY-MM-DD`. This field is required.
* **Event Type**: The type of event, such as concert, festival, or live event. This field is required, and you can select one of the options provided.
* **Venue**: The location where the event will take place, such as a concert hall or outdoor festival grounds. This field is required.
* **Media Type**: The type of media coverage requested, such as print, digital, broadcast, social media, or press. This field is required, and you can select multiple options if applicable.
* **Coverage Area**: The area or region to be covered by the media, such as a city or state. This field is required.
* **Notes**: Any additional information or comments about the event, such as a specific request or requirement. This field is optional.
* **Submit Date**: The date the request is being submitted, in the format `YYYY-MM-DD`. This field is optional, but recommended for tracking purposes.

## Tips

* Ensure that you are submitting accurate and complete information to avoid delays or rejection of your request.
* If you are submitting multiple requests for the same event, please do not fill out this form multiple times. Instead, submit a single request and provide additional details in the "Notes" field.
* If you have any questions or concerns about the form or the submission process, please contact the media relations team for assistance.
