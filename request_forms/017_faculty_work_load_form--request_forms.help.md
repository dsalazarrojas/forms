# Faculty Work Load Form - Help Guide
## Purpose
The Faculty Work Load Form is a tool for faculty members and teachers to manage their workload and request additional resources.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the category of the form from the dropdown menu. This will help us understand the type of request you are making.
2. Enter a brief description of your workload and requirements in the "Description" field.
3. Select the resources you are requesting (e.g. computers, other resources).
4. If applicable, enter the assigned tool or equipment that you are currently using.
5. Enter the filename of the output file that you would like to generate.
6. If you have a specific form ID, enter it in the "Form IDs" field.
7. Select any additional categories that apply to your request (e.g. Request Forms, other forms).

## Field-by-Field Explanation
* **Category** (`category`, select_one, required: false): Select the category of the form from the dropdown menu. This helps us understand the type of request you are making.
* **Description** (`description`, text, required: false): Enter a brief description of your workload and requirements.
* **Requested Resources** (`requested_resources`, select_multiple, required: false): Select the resources you are requesting (e.g. computers, other resources).
* **Assigned Tool** (`assigned_tool`, text, required: false): If applicable, enter the assigned tool or equipment that you are currently using.
* **Output File** (`output_file`, text, required: false): Enter the filename of the output file that you would like to generate.
* **Form IDs** (`form_ids`, number, required: false): If you have a specific form ID, enter it in this field.
* **Category** (`category`, select_multiple, required: false): Select any additional categories that apply to your request (e.g. Request Forms, other forms).
