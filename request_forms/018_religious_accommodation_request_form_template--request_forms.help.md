# Religious Accommodation Request Form Template - Help Guide

## Purpose
This form is designed to gather information from employees or individuals to request religious accommodations. It's a template to collect data about the accommodations requested, the details of the request, and any relevant dates. This form is not affiliated with any specific form platform and is an original adaptation of a public survey topic.

## How To Complete This Form
To complete this form, follow these steps:
1. Fill in the **Request Form Data** page (Page 1) with any relevant information about your request.
2. Select the type of religious accommodation you are requesting from the **Religious Accommodations** dropdown menu (Page 1).
3. If you selected **Other Religious** in step 2, provide more details in the **Religious Accommodations Details** text box (Page 1).
4. Enter the **Date Request Made** (Page 1) if this request is a new request or if you need to update an existing one.
5. Enter the **Date Request Ended** (Page 2) if this request has already been resolved or if it's not yet resolved.
6. In the **Manager Response** text box (Page 2), type a brief response or update about the status of your request.

## Field-by-Field Explanation

* **Request Form Data (Page 1)**: Use this field to provide any relevant information about your request. This can include background details about your request, such as your role in the organization or department.
* **Religious Accommodations (Page 1)**: Select the type of accommodation you are requesting:
	+ **Sabbath**: A day of rest or day off for religious observance.
	+ **Prayer**: A quiet space or accommodations for prayer or worship.
	+ **Holy Day**: A day of observance or celebration for a particular religion or culture.
	+ **Other Religious**: If you're requesting something else, please select this option and provide more details in the **Religious Accommodations Details** field.
* **Religious Accommodations Details (Page 1)**: If you selected **Other Religious** in the **Religious Accommodations** field, provide more information about your request in this text box.
* **Date Request Made (Page 1)**: Enter the date you made this request, or if you're updating an existing request, enter the date of the update.
* **Date Request Ended (Page 2)**: If this request has already been resolved, enter the date it was resolved. If it's not yet resolved, you can leave this field blank.
* **Manager Response (Page 2)**: In this text box, type a brief update or status about your request. Your manager can respond to you here with updates or actions taken. 

## Tips
Please ensure that you have permission to submit a request for religious accommodations before filling out this form.
Be concise in your responses and provide necessary details so that the requested accommodations can be understood and resolved.
This form is for internal use only and should not be shared with external parties.
If you have any issues with the form or need further guidance, contact form@gic.mx.
