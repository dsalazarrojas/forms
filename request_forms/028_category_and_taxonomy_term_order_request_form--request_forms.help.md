# Category And Taxonomy Term Order Request Form - Help Guide
## Purpose
The Category And Taxonomy Term Order Request Form is a tool used by users to communicate changes they need to make to their website or application's category and taxonomy terms. This form will help the IT and web teams prioritize and implement the requested changes.

## How To Complete This Form

To complete this form, follow these steps:

1.  Fill in the required fields with accurate information about the requested changes.
2.  Provide a clear description of the current order and the requested order of the taxonomy terms.
3.  Specify the reason for the change, if applicable.
4.  Choose the priority level of the request, considering its impact on the site.
5.  Indicate if the change has any impact on search engine optimization (SEO) or internal linking.
6.  Select a completion date for the request.

## Field-by-Field Explanation

* **Your Full Name** (`requester_name`): Enter your full name as the person submitting the request.
* **Department/Team** (`department_name`): Specify the department or team responsible for the category and taxonomy terms on your website or application.
* **Website or Application Name** (`platform_name`): Enter the name of your website or application where the taxonomy changes should be applied.
* **Type of Taxonomy** (`taxonomy_type`): Select the type of taxonomy you are dealing with, which can be "Categories", "Tags", "Custom Taxonomy Terms", or "Menu Items".
* **Specific Taxonomy ID or Name** (`specific_taxonomy_id`): Enter the ID or name of the specific taxonomy term you are referencing.
* **Description of Current Order** (`current_order_description`): Describe how the taxonomy terms are currently sorted or ordered on your website or application.
* **Requested New Order** (`requested_new_order`): List the terms in the exact order you want them displayed.
* **Reason for Reordering** (`reason_for_change`): Explain the reason why you are requesting the change, e.g., a seasonal promotion, user testing results, or new products.
* **Request Priority** (`priority_level`): Choose the priority level of the request, which can be "Critical - Site Blocker", "High - Marketing Deadline", "Medium - Routine Update", or "Low - Aesthetic Change".
* **Impact on SEO or Internal Linking** (`impact_assessment`): Determine if the change has a significant impact on search engine optimization (SEO) or internal linking.
* **Requested Completion Date** (`requested_completion_date`): Enter the date by which you want the changes to be implemented.
* **Additional Instructions for IT/Web Team** (`further_comments`): Provide any additional information the IT and web teams may need to complete the request.
