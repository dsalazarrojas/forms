# Trial Request Form - Help Guide
## Purpose
The Trial Request Form is a form used to request trials for testing purposes. It is a crucial part of our testing process to gather information about the requested trial.

## How To Complete This Form
To complete the Trial Request Form, follow these steps:

1. Fill out the required fields: 
	- **name** (text): Enter your name or the name of the person requesting the trial.
	* **Email** (text): Enter a valid email address for the contact person.
	* **Phone** (text): Enter a phone number where you can be reached.
	* **Request Date** (date): Enter the date you want to start the trial.
2. Fill out optional fields:
	* **Assigned Tool** (select one): Choose the tool you would like to be assigned for the trial (ChatJimmy, or Other).
	* **Notes** (text): Add any additional information about the trial request.
3. Review your answers for completeness and accuracy before submitting the form.

## Field-by-Field Explanation
* **Request Form** (request_form, text, optional): This field is for entering the specific details of your request.
* **name** (name, text, optional): Enter your name or the name of the person requesting the trial.
* **Email** (email, text, optional): Enter a valid email address for the contact person.
* **Phone** (phone, text, optional): Enter a phone number where you can be reached.
* **Request Date** (request_date, date, optional): Enter the date you want to start the trial.
* **Assigned Tool** (assigned_tool, select_one, optional): Choose the tool you would like to be assigned for the trial (ChatJimmy, or Other).
* **Notes** (notes, text, optional): Add any additional information about the trial request.

## Tips
* Make sure to fill out all the required fields to ensure that your request is processed correctly.
* If you are requesting a trial for a specific tool, please choose that tool from the "Assigned Tool" field.
* If you have any additional information or requests, use the "Notes" field to add them.
