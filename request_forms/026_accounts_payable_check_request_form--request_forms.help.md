# Accounts Payable Check Request Form - Help Guide
## Purpose
This form is designed to gather necessary information for the accounting department to process payments and ensure accuracy in their accounting records.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill out the "Payee Name" field with the name of the person or vendor to receive payment.
2. Enter the "Vendor ID" field if you know the internal system code for the payee.
3. Enter the "Invoice Number" field with the corresponding invoice number.
4. Enter the "Invoice Date" field with the date the invoice was issued.
5. Enter the "Total Amount" field with the total amount of the invoice in USD.
6. Select the payment method (e.g., Physical Check, Direct Deposit, Wire) in the "Payment Method" field.
7. Choose the priority level (e.g., Routine, Urgent) in the "Priority" field.
8. Provide a brief description of the purpose of the expenditure in the "Expense Description" field.
9. Enter the "GL Account Code" field with the General Ledger code for tracking.
10. If necessary, add a note in the "Signature Header" field to provide additional context.
11. If authorized, sign the "Department Head Signature" field to approve the request.
12. If necessary, enter any additional comments in the "Finance Manager Approval" field.
13. Enter the "Request Date" field with the date the request was made.

## Field-by-Field Explanation
* **Payee Name**: Name of the person or vendor to receive payment
* **Vendor ID**: Internal system code if known (optional)
* **Invoice Number**: Enter the corresponding invoice number
* **Invoice Date**: Date the invoice was issued
* **Total Amount**: Currency amount in USD
* **Payment Method**: How the payment should be issued (e.g., Physical Check, Direct Deposit, Wire)
	+ Physical Check: Payment will be issued as a check
	+ Direct Deposit: Payment will be deposited directly into the payee's bank account
	+ Wire: Payment will be transferred via wire transfer
* **Priority**: Priority level for processing the payment (e.g., Routine, Urgent)
	+ Routine: Standard processing time
	+ Urgent: Expedited processing time
* **Expense Description**: Brief description of the purpose of the expenditure
* **GL Account Code**: General Ledger code for tracking
* **Signature Header**: Optional note for additional context
* **Department Head Signature**: Signature from the department head to approve the request (if authorized)
* **Finance Manager Approval**: Additional comments from the finance manager (if necessary)
* **Request Date**: Date the request was made
