# Dropbox File Request Form - Help Guide
## Purpose
The Dropbox File Request Form is a tool for team members to submit requests for files that are not currently available to them.

## How To Complete This Form
To complete the form, follow these steps:

1. **Enter Your Information**: Fill in the "User Input" field with your name and any relevant details about your request.
2. **Provide File Details**: In the "File Details" field, describe the file you are requesting and why you need it.
3. **Specify the Request**: Choose whether the file is a "Yes" or "No" request.
4. **Select Request Status**: Choose the status of your request as either "Active" or "Inactive".
5. **Upload File (Optional)**: If you have the file available, you can upload it using the "Upload File" field. However, if you don't have the file, please leave this field blank.

## Field-by-Field Explanation
* **User Input** (`user_input`, text, optional): Enter your name and any relevant details about your request.
* **File Details** (`file_details`, text, optional): Describe the file you are requesting and why you need it.
* **File Request** (`file_request`, select_one, optional):
	+ "Yes" means you are requesting a file.
	+ "No" means you are not requesting a file.
* **Request Status** (`request_status`, select_one, optional):
	+ "Active" means your request is currently being processed.
	+ "Inactive" means your request is not currently being processed.
* **Upload File** (`upload_file`, time, optional): Upload the file you are requesting, if available. 

## Tips
* Only submit a request for a file if you need it for work-related purposes.
* Repeatedly submitting requests for the same file will not speed up the process and might be considered spam.
* If you don't have the file, please leave the "Upload File" field blank.
* If you're unsure about any of the fields, please ask an administrator for clarification.
