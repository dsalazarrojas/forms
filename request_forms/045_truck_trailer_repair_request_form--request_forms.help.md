# truck_trailer_repair_request_form - Help Guide
## Purpose
The "truck_trailer_repair_request_form" is a form used to gather information about a trailer repair request. This form is intended to help maintenance staff quickly and accurately collect the necessary information to complete a repair.

## How To Complete This Form

1. Ensure you are in the correct location to complete this form.
2. Select the trailer type that best describes the trailer being repaired.
3. Please describe the repair request in the space provided.
4. Select the maintenance date for the repair.
5. Enter the expected repair cost.
6. Enter the trailer number associated with the repair.
7. Select the current repair status.
8. If desired, enter additional notes about the repair.
9. Select the staff member assigned to complete the repair.
10. If completed, enter the completed date of the repair.
11. Enter any additional notes about the repair.

## Field-by-Field Explanation

* **Trailer Type** (trailer_type): This field allows you to select the type of trailer that needs repair. Please choose the option that best describes the trailer.
* **Repair Request** (repair_request): This field is where you can describe in detail the repair needed for the trailer.
* **Maintenance Date** (maintenance_date): Enter the date when the trailer was last maintained. This date is used to track the maintenance history.
* **Repair Cost** (repair_cost): Enter the expected cost of the repair.
* **Trailer Number** (trailer_number): This field is used to identify the trailer that requires repair. Enter the number assigned to the trailer.
* **Repair Status** (repair_status): Select the current status of the repair, such as pending, in progress, or completed.
* **Notes** (notes): Enter any additional information about the repair, such as any challenges or issues encountered.
* **Assigned To** (assigned_to): Select the staff member responsible for completing the repair.
* **Completed Date** (completed_date): If applicable, enter the date the repair was completed.
* **Notes** (notes): Enter any additional information about the completed repair, such as any lessons learned or follow-up actions.
