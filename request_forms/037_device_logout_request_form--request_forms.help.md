# Device Logout Request Form - Help Guide
## Purpose
This form is used to request a device logout, which is a process that removes a user's access to a device. This form is typically used when a user no longer needs or is no longer authorized to access a device.

## How To Complete This Form
1. Fill out the form completely and accurately.
2. Select the relevant options for each field.
3. Review your submission before submitting it for review.

## Field-by-Field Explanation

* **Device Request Form** (`device_logout_request_form`, number, required): This field is used to select the device that needs to be logged out.
* **Account Request Form** (`account_request_form`, text, required): Enter the account information associated with the device.
* **Reason for Request Form** (`reason_for_request_form`, text, required): Provide a brief description for the reason of the logout request.
* **Device Type Form** (`device_type_request_form`, select_one, required): Select the type of device that needs to be logged out (e.g., laptop, smartphone, etc.).
* **Account Type Form** (`account_type_request_form`, select_multiple, required): Select the types of accounts associated with the device (e.g., work, personal, etc.).
* **Device Status Form** (`device_status_request_form`, select_one, required): Select the status of the device (e.g., active, inactive, etc.).
* **Request Date Form** (`request_date_request_form`, date, required): Enter the date of the logout request.
* **Request Time Form** (`request_time_request_form`, time, required): Enter the time of the logout request.
* **User Form** (`user_request_form`, select_one, required): Select the user who is requesting the logout.
* **Manager Form** (`manager_request_form`, select_one, required): Select the manager who needs to be notified of the logout request.
* **Device ID Form** (`device_id_request_form`, number): Enter the ID of the device to be logged out.
* **Account ID Form** (`account_id_request_form`, number): Enter the ID of the account associated with the device.
* **Reason For Request Request Form** (`reason_for_request_request_form`, text, required): Enter a brief description for the reason of the logout request.
* **Notes Form** (`notes_request_form`, note, required): Enter any additional notes or comments about the logout request.
* **Email Form** (`email_request_form`, email, required): Enter the email address of the user who is requesting the logout.
* **Phone Form** (`phone_request_form`, text, required): Enter the phone number of the user who is requesting the logout.
* **User Request Status Form** (`user_request_status_request_form`, select_multiple, required): Select the status of the user's request (e.g., pending, approved, etc.).
* **Manager Request Status Form** (`manager_request_status_request_form`, select_multiple, required): Select the status of the manager's request (e.g., pending, approved, etc.).
* **Device Request Status Form** (`device_request_status_request_form`, select_multiple, required): Select the status of the device's request (e.g., pending, approved, etc.).
* **Notes Request Form 2** (`notes_request_form_2`, note, required): Enter any additional notes or comments about the logout request.
* **Email Request Status Form** (`email_request_status_request_form`, select_multiple, required): Select the status of the email's request (e.g., pending, approved, etc.).
* **Phone Request Status Form** (`phone_request_status_request_form`, select_multiple, required): Select the status of the phone's request (e.g., pending, approved, etc.).
* **User Request Form 2** (`user_request_form_2`, select_one, required): Select the user who needs to be notified of the logout request.
* **Manager Request Form 2** (`manager_request_form_2`, select_one, required): Select the manager who needs to be notified of the logout request.
* **Submit Form** (`submit_request_form`, select_multiple, required): Select the submit option to complete the form and send it for review.

Note: This help guide assumes that the form fields are self-explanatory and does not require further clarification. If a field label is unclear or not self-explanatory, it is recommended to update the field label or description for better clarity and usability.
