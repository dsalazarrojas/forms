# helpdesk_request_form - Help Guide
## Purpose
The helpdesk request form is a tool for users to submit requests for assistance or support. Use this form to request a new feature, report a bug, or ask a question.

## How To Complete This Form
To complete this form, follow these steps:

1. Choose the type of request you are submitting by selecting the appropriate option from the "Request Type" dropdown menu.
2. Enter a brief description of the problem or issue you are experiencing.
3. Provide your contact information, including your email address, so that we can get back to you.
4. If necessary, attach any relevant files or documents to support your request.

## Field-by-Field Explanation
* **Submit Request**: This field is for entering a brief title for your request.
* **Request Type**: Select the type of request you are submitting by choosing one of the provided options:
	+ Request a new feature
	+ Report a bug
	+ Post a question
* **Description**: Briefly describe the problem or issue you are experiencing.
* **Contact Info**: Enter your email address so that we can get back to you.
* **Attachment**: If necessary, attach relevant files or documents to support your request.
* **Created By**: This field is automatically populated with the name of the user who submitted the request.
* **Created At**: This field is automatically populated with the date and time the request was submitted.
* **Email**: Enter your email address so that we can get back to you. This field is required for us to contact you.

## Tips
* Please only submit one request at a time to avoid duplication.
* Use the "Request Type" dropdown menu to choose the correct type of request.
* Be as brief and concise as possible when entering your description.
* If you need to attach files, use the "Attachment" field.
* Make sure to enter a valid email address so that we can get back to you.
