# Outage Maintenance Request Form - Help Guide
## Purpose
The Outage Maintenance Request Form is a tool to report and manage maintenance requests for facilities and equipment.

## How To Complete This Form
To complete the form, follow these steps:

1.  Fill in the required fields with the relevant information.
2.  Select all relevant categories for the outage.
3.  Briefly describe the issue or problem you are experiencing.
4.  Choose the priority level of the outage.
5.  If applicable, select the person responsible for addressing the issue.
6.  Add any additional comments about the request.
7.  Submit the form.

## Field-by-Field Explanation

* **Facility Name** (Facility Name, Text, Optional): Enter the name of the facility experiencing the outage.
* **Date of Outage** (Date, Optional): Enter the date the outage occurred or is expected to occur.
* **Start Time** (Time, Optional): Enter the start time of the outage, if known.
* **End Time** (Time, Optional): Enter the end time of the outage, if known.
* **Category** (Multiple Select, Optional): Select all categories that apply to the outage (e.g., Electrical, Network, Software, Hardware, Other).
* **Description** (Text, Optional): Briefly describe the issue or problem you are experiencing.
* **Priority** (Select One, Optional): Choose the priority level of the outage (High, Low, Medium).
* **Assignee** (Multiple Select, Optional): Select the person responsible for addressing the issue (e.g., chatjimmy, Other).
* **Comments** (Note, Optional): Add any additional comments or details about the request.
* **Submitter** (Email, Optional): Enter your email address to receive notifications about the progress of your request.
