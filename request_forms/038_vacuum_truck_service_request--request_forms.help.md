# Vacuum Truck Service Request - Help Guide
## Purpose
This form is used to request services related to vacuum trucks. Fill out this form to provide information about the job you want to be performed.

## How To Complete This Form

To complete this form, follow these steps:

1. Go to the first page, "Job Details".
2. Fill out the job details.
3. Move to the next page, "Service Requested".
4. Select the service you are interested in requesting.
5. Move to the next page, "Job Type".
6. Select the job type you are interested in.
7. Move to the next page, "Date of Service".
8. Enter the date on which you would like to have the service performed.
9. Move to the next page, "Time of Service".
10. Enter the time on which you would like to have the service performed.
11. Move to the next page, "Location of Service".
12. Select the location where you would like to have the service performed.
13. Move to the next page, "Special Instructions".
14. Enter any special instructions that you have.
15. Move to the next page, "Contact Number".
16. Enter your contact number.
17. Move to the next page, "Email Address".
18. Enter your email address.
19. Move to the next page, "Address".
20. This field is not required, so you can skip it.
21. Move to the next page, "Services".
22. Select any additional services you would like to have performed.

## Field-by-Field Explanation

* **Job Details** (`Job Details`, `text`, required: false): Please enter a brief description of the job you would like to have performed.
* **Service Requested** (`Service Requested`, `select_one`, required: false): Please select the service you are interested in requesting.
* **Job Type** (`Job Type`, `select_one`, required: false): Please select the job type you are interested in.
* **Date of Service** (`Date of Service`, `date`, required: false): Please enter the date on which you would like to have the service performed.
* **Time of Service** (`Time of Service`, `time`, required: false): Please enter the time on which you would like to have the service performed.
* **Location of Service** (`Location of Service`, `select_one`, required: false): Please select the location where you would like to have the service performed.
* **Special Instructions** (`Special Instructions`, `note`, required: false): Please enter any special instructions you have.
* **Contact Number** (`Contact Number`, `text`, required: false): Please enter your contact number.
* **Email Address** (`Email Address`, `email`, required: false): Please enter your email address.
* **Address** (`Address`, `note`, required: false): This field is not required, and you can skip it.
* **Services** (`Services`, `select_multiple`, required: false): Please select any additional services you would like to have performed.

## Tips

* Please make sure to fill out all the required fields.
* If any of the fields seem redundant or unnecessary, please ask for clarification.
* Please provide accurate and complete information in all fields.
* If you're unsure of what to fill in any of these fields, please consult with someone who has more experience.
