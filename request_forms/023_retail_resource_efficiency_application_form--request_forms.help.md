# Retail Resource Efficiency Application Form - Help Guide
## Purpose
This form is used by employees to request resources and improvements from their manager or regional manager. The form gathers relevant information to assess the efficiency and productivity of retail processes, allowing management to track and analyze requests. Ensure to submit only once for each request.

## How To Complete This Form
To complete this form, follow these steps:

*   Fill in the required fields with accurate and truthful information.
*   Select the correct project status and resource requester from the drop-down lists.
*   Make sure to enter a descriptive project description to help management understand the resource request.

## Field-by-Field Explanation
*   **User Input** (text, optional): Enter a brief description of the resource or improvement you are requesting.
*   **Date Submitted** (date, optional): Select the date you are submitting this request.
*   **Resource Efficiency Project Name** (text, optional): Enter the name of the project or resource improvement request.
*   **Manager Name** (text, optional): Enter your manager's name.
*   **Contact Name** (text, optional): Enter your name.
*   **Email** (email, optional): Enter your email address.
*   **Phone** (text, optional): Enter your phone number.
*   **Description** (text, optional): Enter a detailed description of the resource or improvement request.
*   **Manager Email** (email, optional): Enter your manager's email address.
*   **Manager Phone** (text, optional): Enter your manager's phone number.
*   **Resource Request** (text, optional): Enter the resource or improvement you are requesting.
*   **Project Details** (text, optional): Enter more detailed information about the project or resource improvement request.
*   **Location** (text, optional): Enter the location of the project or resource improvement request.
*   **Resource Allocation** (text, optional): Enter the resources you are requesting or allocating for the project.
*   **Resource Availability** (text, optional): Enter the availability of the resources you are requesting.
*   **Project Status** (select_one, optional): Select the current status of the project. Choose from:
    +   Active
    +   In Progress
    +   Completed
*   **Resource Requester** (select_multiple, optional): Select the person requesting the resource or improvement. Choose from:
    +   Store Manager
    +   District Manager
    +   Regional Manager
    +   Corporate

Note:
*   Ensure to submit only one request per project.
*   Be as detailed as possible when providing descriptions and descriptions.
*   If you need help, contact the support team.
