# Creative Request - Help Guide
## Purpose
This form is designed to help you submit a creative request for promotional materials to our team. Please fill out this form completely and accurately to ensure we can provide you with the best possible outcome.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the **Project Description** field with a clear and concise description of your project. This will help us understand the scope and requirements of your request.
2. Choose the **Requested Promotions** you would like to have created for your project. You can select multiple options.
3. If applicable, choose the **Promotion Type** you would like to have created (e.g. banner ad, landing page, email, or graphics for social media).
4. (Optional) You can attach a file to be uploaded using the **File Upload** field.
5. Enter the **First Round Due Date** and **Delivery Date** for your project. These dates are critical for our team's planning and execution.
6. Add any additional **Notes** you'd like to share about your project.

## Field-by-Field Explanation

* **Project Description (1)**: A brief description of your project. Please be clear and concise so we can understand your project's scope and requirements.
* **Requested Promotions (2)**: Check all the promotional materials you would like to have created for your project. This can include, but is not limited to, social media graphics, emails, landing pages, and more.
* **Promotion Type (3)**: If you have a specific type of promotion in mind, such as a banner ad or email, select the corresponding option.
* **File Upload (4)**: If you have a file you'd like to attach to your request, you can do so here.
* **First Round Due Date (5)**: Enter the date by which we should have a first round of drafts for your project.
* **Delivery Date (6)**: Enter the date by which you would like to have the final promotional materials delivered.
* **Notes (7)**: Add any additional comments or information about your project you'd like to share with our team.
