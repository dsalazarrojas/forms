# Shared Workspace Configuration Request - Help Guide

## Purpose
This form is used to collect information from users about their shared workspace configuration requests. This information will help us better understand the needs of our users and improve our services accordingly.

## How To Complete This Form
To complete this form, follow these steps:

1. Answer all the fields that are marked as "required" in the form.
2. For the "space_needs" field, select all the options that apply to the shared workspace you are requesting.
3. For the "space_needs_6", "space_needs_7", and "space_needs_8" fields, enter the dates if applicable.
4. Make sure to provide accurate and clear information in the form, as it will help us to better understand your needs.

## Field-by-Field Explanation
### workspace_needs (Text)
* workspace_needs: This field is for you to describe the general needs of your shared workspace. Please provide a brief description of what kind of workspace you are requesting.
### workspace_needs_2 (Text)
* workspace_needs_2: This field is another opportunity to describe any additional needs you have for your shared workspace.
### needs (Text)
* needs: Please use this field to describe any specific needs you have for your shared workspace.
### needs_2 (Text)
* needs_2: Similar to the previous field, this is another chance to provide any additional needs you have.
### amenities (Text)
* amenities: Use this field to describe any amenities you would like to have in your shared workspace.
### space_needs (Select Multiple)
* space_needs: Please select all the options that apply to the type of shared workspace you are requesting. For example, you can select "Office" and "Meeting Room" if you are requesting a shared workspace with both an office and a meeting room.
### space_needs_2 (Text)
* space_needs_2: This field is for additional information about the space needs of your shared workspace. Please provide any details that are not covered by the previous "space_needs" field.
### space_needs_3 (Text)
* space_needs_3: Similar to "space_needs_2", this field is another chance to provide any additional information about the space needs of your shared workspace.
### space_needs_4 (Text)
* space_needs_4: This field is for you to describe any further details about the space needs of your shared workspace.
### space_needs_5 (Text)
* space_needs_5: Another field for you to provide any additional information about the space needs of your shared workspace.
### space_needs_6 (Date)
* space_needs_6: Please enter the date by which you need the shared workspace to be available.
### space_needs_7 (Date)
* space_needs_7: Another date field for you to provide the expected completion date of your shared workspace.
### space_needs_8 (Date)
* space_needs_8: Enter the date by which you need the space needs of your shared workspace to be resolved.
### space_needs_9 (Date)
* space_needs_9: Similar to "space_needs_8", this field is for you to enter the date by which you need the space needs of your shared workspace to be resolved.
### space_needs_10 (Date)
* space_needs_10: Final date field for you to enter the date by which you need the space needs of your shared workspace to be resolved.
