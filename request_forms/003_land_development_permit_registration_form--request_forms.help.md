# Land Development Permit Registration Form - Help Guide
## Purpose
The purpose of this form is to gather necessary information about a land development project, including its status, type, address, and contact details. This information will be used to process the project's registration and ensure compliance with relevant regulations.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the Project Details page (page 1), which includes the project's name, address, and a brief description.
2. On the Contact Details page (page 2), enter the contact person's name and telephone number.
3. On the Project Status, Type, and Project Manager pages (pages 3, 4, and 5), select the relevant options from the provided lists.
4. Review and submit the form once you have completed all the required fields.

## Field-by-Field Explanation

* **Project Status** (Required, Select One):
	+ Choose the current status of your project: Active, Inactive, or On Hold.
* **Project Type** (Required, Select One):
	+ Select the type of project: Residential, Commercial, Industrial, or Agricultural.
* **Project Description** (Optional, Note):
	+ Provide a brief description of your project.
* **Project Manager** (Required, Select One):
	+ Select the project manager's name from the provided list: John Doe, Jane Doe, or Bob Smith.
* **Contact Telephone** (Optional, Text):
	+ Enter the contact person's telephone number.
* **Project Address** (Optional, Text):
	+ Enter the project's address.
* **Project Details** (Optional, Text):
	+ Enter a brief description of your project.
* **Contact Details** (Optional, Text):
	+ Enter the contact person's name and any additional information you want to provide.

## Tips

* Ensure that all required fields are completed accurately and truthfully.
* If you are unsure about any field, please contact the authorities for clarification.
* Please submit the form once you have completed all the required fields.
