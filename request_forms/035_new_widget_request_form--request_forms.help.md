# New Widget Request Form - Help Guide

## Purpose
The New Widget Request Form is intended to facilitate the submission of requests for new widgets within your company. Use this form to request a specific widget for a legitimate reason, such as a new project or business need.

## How To Complete This Form
- **New Widget Request** (Required): Enter a brief description of the new widget request.
- **Customer Name** (Optional): If you are requesting the widget for someone else, please provide their name.
- **Customer Company** (Optional): If you are requesting the widget for a specific company, please provide their name.
- **Customer Email** (Optional): Provide the email address of the customer (if applicable).
- **Customer Phone** (Optional): Provide the phone number of the customer (if applicable).
- **Widget Model** (Optional): Select the desired widget model from the provided options.
- **Widget Description** (Optional): Enter a brief description of the widget's purpose or features.
- **Widget Price** (Optional): If you are providing a price for the widget, please enter it here.
- **Requestor Name** (Optional): If you are requesting the widget for yourself, please provide your name.
- **Requestor Company** (Optional): If you are requesting the widget for your company, please provide your name.
- **Requestor Phone** (Optional): If you need to be contacted, provide your phone number.
- **Requestor Email** (Optional): If you need to be contacted, provide your email address.

## Field-by-Field Explanation
- **New Widget Request**: This field is a text input where you can enter a brief description of the new widget request.
- **Customer Name**: If you are requesting the widget for someone else, enter their name here.
  This field is used to identify the customer who requested the widget.
- **Customer Company**: If you are requesting the widget for a specific company, enter their name here.
  This field is used to identify the company the widget is being requested for.
- **Customer Email**: If applicable, enter the email address of the customer here.
  This field is used for contact purposes.
- **Customer Phone**: If applicable, enter the customer's phone number here.
  This field is used for contact purposes.
- **Widget Model**: Select the desired widget model from the provided options.
  This field is used to select the type of widget being requested.
- **Widget Description**: Enter a brief description of the widget's purpose or features.
  This field provides additional information about the widget's functionality.
- **Widget Price**: If you are providing a price for the widget, enter it here.
  This field is used to track the price of the widget.
- **Requestor Name**: If you are requesting the widget for yourself, enter your name here.
  This field is used to identify the requestor of the widget.
- **Requestor Company**: If you are requesting the widget for your company, enter your name here.
  This field is used to identify the company that requested the widget.
- **Requestor Phone**: If you need to be contacted, enter your phone number here.
  This field is used for contact purposes.
- **Requestor Email**: If you need to be contacted, enter your email address here.
  This field is used for contact purposes.
