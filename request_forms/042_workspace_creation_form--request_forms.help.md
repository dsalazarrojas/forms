# workspace_creation_form - Help Guide
## Purpose
This form is used to create a new workspace, collecting information for its settings, team, and management.

## How To Complete This Form
To complete this form, follow these steps:

* Fill out the required fields (none are marked as required in the form, so all fields are optional).
* Enter the workspace name, description, and other relevant details.
* Select options for team invites, access levels, and other settings as needed.
* Ensure you have entered accurate and complete information to avoid errors.

## Field-by-Field Explanation
* **User Preferences** (`user_preferences`, text, optional): Enter a brief description of the user's preferences and expectations for the workspace.
* **Access Preferences** (`access_preferences`, text, optional): Describe the access preferences for the workspace.
* **Team Invites** (`team_invites`, text, optional): Enter the team invites and invitations information.
* **Workspace Name** (`workspace_name`, text, optional): Enter the name of the workspace.
* **Description** (`description`, text, optional): Enter a brief description of the workspace.
* **Team Name** (`team_name`, text, optional): Enter the name of the team.
* **Start Date** (`start_date`, date, optional): Enter the start date of the workspace.
* **End Date** (`end_date`, date, optional): Enter the end date of the workspace.
* **Team Leads** (`team_leads`, select_multiple, optional): Select whether team leads are available for this workspace.
* **Team Members** (`team_members`, select_multiple, optional): Select whether team members are available for this workspace.
* **Access Level** (`access_level`, select_one, optional): Select the access level for the workspace.
* **Workspace Type** (`workspace_type`, select_one, optional): Select whether this is a workspace or not.
* **Workspace URL** (`workspace_url`, text, optional): Enter the workspace URL.
* **Workspace URL 2** (`workspace_url_2`, text, optional): Enter the second workspace URL.
* **Team Owners** (`team_owners`, text, optional): Enter the team owners' names.
* **Workspace Owners** (`workspace_owners`, text, optional): Enter the workspace owners' names.
* **Department** (`department`, text, optional): Enter the department name.
* **Workspace Status** (`workspace_status`, select_one, optional): Select the status of the workspace (Active or Inactive).
* **Notes** (`notes`, note, optional): Enter any additional notes about the workspace.
* **Email** (`email`, email, optional): Enter the email address.
* **Phone** (`phone`, text, optional): Enter the phone number.
* **User Email** (`user_email`, email, optional): Enter the user's email address.
* **User Phone** (`user_phone`, text, optional): Enter the user's phone number.
* **Workspace ID** (`workspace_id`, text, optional): Enter the workspace ID.
* **User ID** (`user_id`, text, optional): Enter the user ID.
* **Team Invites** (`team_invites`, text, optional): Enter the team invites information.

Note: The field-by-field explanations aim to provide a general understanding of the field's purpose. Some fields, like "access_level" and "workspace_status", have unclear labels. The field labels are used as a starting point for these explanations.
