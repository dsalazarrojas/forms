# Car Rental Form - Help Guide

## Purpose
The Car Rental Form is designed to collect information from customers who are planning to rent a car. This form gathers necessary details such as customer contact information, rental preferences, and driving information to facilitate a smooth and safe rental experience.

## How To Complete This Form
To complete this form, follow these steps:

* Fill out all the required fields marked as "Required" in the form.
* Provide accurate and honest information in all fields.
* Make sure to review and agree to the rental terms and conditions.

## Field-by-Field Explanation

* **First Name** (`first_name`, text, required): Enter your first name.
* **Last Name** (`last_name`, text, required): Enter your last name.
* **Email Address** (`email`, email, required): Enter your email address for reservation communications.
* **Phone Number** (`phone`, text, required): Enter your contact number.
* **Street Address** (`address`, text, optional): Enter your street address (if applicable).
* **City** (`city`, text, optional): Enter your city (if applicable).
* **State** (`state`, text, optional): Enter your state (if applicable).
* **ZIP Code** (`zip_code`, text, optional): Enter your ZIP code (if applicable).
* **Rental Details** (`rental_details`, note, optional): Enter any additional information about your rental preferences.
* **Pickup Location** (`pickup_location`, select_one, required): Select one of the following locations: Airport Location, Downtown Location, Suburban Location, Hotel Delivery, or Other.
* **Pickup Address** (`pickup_location_address`, text, optional): Enter the specific address for pickup (if not at the main pickup location).
* **Pickup Date** (`pickup_date`, date, required): Select the date for pickup.
* **Pickup Time** (`pickup_time`, time, required): Select the time for pickup.
* **Return Location** (`return_location`, select_one, required): Select one of the following locations: Same as pickup, Different location.
* **Return Address** (`return_location_address`, text, optional): Enter the specific address for return (if different from pickup location).
* **Return Date** (`return_date`, date, required): Select the date for return.
* **Return Time** (`return_time`, time, required): Select the time for return.
* **Car Type** (`car_type`, select_one, required): Select one of the following car types: Economy, Compact, Mid-size, Full-size, SUV, Minivan, Luxury, Sports car, Truck, No preference.
* **Specific Vehicle Request** (`specific_vehicle_request`, text, optional): Enter any specific vehicle preferences.
* **Transmission Type** (`transmission_type`, select_one, required): Select one of the following transmission types: Automatic, Manual, No preference.
* **Fuel Type** (`fuel_type`, select_one, required): Select one of the following fuel types: Gasoline, Diesel, Hybrid, Electric, No preference.
* **Passenger Capacity** (`passenger_capacity`, select_one, required): Select one of the following capacities: 1-2, 3-4, 5-6, 7-8, 9+.
* **Luggage Capacity** (`luggage_capacity`, select_one, required): Select one of the following capacities: 1-2 bags, 3-4 bags, 5-6 bags, 7+ bags.
* **Rental Purpose** (`rental_purpose`, select_one, required): Select one of the following purposes: Business, Leisure/Vacation, Personal vehicle repair, Special event, Test drive, Other.
* **Additional Requests** (`additional_requests`, select_multiple, optional): Select any additional requests from the following options: GPS Navigation, Child Safety Seat, Booster Seat, Additional Driver, Ski Rack, Bike Rack, Toll Pass, Mobile WiFi, Wheelchair accessible, None.
* **Additional Requests Details** (`additional_requests_details`, text, optional): Enter any additional information about your requests.
* **Insurance Preference** (`insurance_preference`, select_multiple, optional): Select one of the following coverage options: Collision Damage Waiver, Liability Insurance, Personal Accident Insurance, Personal Effects Coverage, Roadside Assistance, Decline all coverage, Undecided.
* **Estimated Mileage** (`estimated_mileage`, select_one, optional): Select one of the following mileage ranges: Under 100 miles, 100-300 miles, 300-500 miles, Over 500 miles.
* **Special Needs** (`special_needs`, text, optional): Enter any accessibility needs.
* **Driver Information** (`driver_information`, note, optional): Enter any information about your license details.
* **Driver's License Number** (`license_number`, text, required): Enter your driver's license number.
* **License State** (`license_state`, text, required): Enter the state that issued your license.
* **License Expiration** (`license_expiry`, date, required): Enter the date of your license expiration.
* **Date of Birth** (`date_of_birth`, date, required): Enter your date of birth.
* **Additional Drivers** (`additional_drivers`, select_one, required): Select one of the following options: True, False.
* **Additional Driver Names** (`additional_driver_names`, text, optional): Enter names of additional drivers.
* **Payment Preference** (`payment_preference`, select_one, required): Select one of the following payment options: Credit Card, Debit Card, Corporate Account, Cash Deposit, Undecided.
* **Loyalty Program** (`loyalty_program`, select_one, optional): Select one of the following options: Yes - member, No - want to join, False.
* **Loyalty Number** (`loyalty_number`, text, optional): Enter your loyalty number (if applicable).
* **Corporate Account** (`corporate_account`, select_one, optional): Select one of the following options: True, False.
* **Corporate Account Name** (`corporate_account_name`, text, optional): Enter the name of your corporate account.
* **How Did You Hear About Us** (`how_heard_about_us`, select_one, optional): Select one of the following sources: Website, Mobile app, Search engine, Social media, Friend/Family, Travel agent, Advertisement, Previous customer, Other.
* **Special Occasion** (`special_occasion`, select_one, optional): Select one of the following options: False, Wedding, Business trip, Vacation, Anniversary, Other.
* **Additional Comments** (`additional_comments`, text, optional): Enter any other information.
* **Terms Agreement** (`terms_agreement`, select_one, required): Select one of the following options: I agree to the rental terms and conditions, I do not agree.
* **Request Date** (`request_date`, date, required): Enter the current date.

Note: Please ensure that you fill out all the required fields before submitting the form. If you need help or have any questions, feel free to contact us.
