# Sponsor Booth Electricity Request Form - Help Guide
## Purpose
The Sponsor Booth Electricity Request Form is used to collect information from event organizers, event managers, or event staff to request electricity sponsorships for their booths or exhibits at an event.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter a brief description of your request in the "Sponsor request" field.
2. Specify your power requirements in the "Power Requirements" field.
3. Select a date for the installation of the electricity infrastructure, if applicable, in the "Installation Schedule" field.
4. Choose your approval status from the options in the "Approval Status" field.
5. Add any additional comments or notes in the "Notes" field.
6. If approved, enter the name of the person who approved your request in the "Approved by" field.

## Field-by-Field Explanation
* **Sponsor request** (`sponsor_booth_request`, text, required/optional): A brief description of your request.
* **Power Requirements** (`power_requirements`, text, required/optional): Specify your power requirements, e.g., number of outlets, power type, etc.
* **Installation Schedule** (`installation_schedule`, date, required/optional): Select a date for the installation of the electricity infrastructure, if applicable.
* **Approval Status** (`approval_status`, select_one, required/optional): Choose your approval status from the options: Approved, Denied, or Pending.
* **Notes** (`notes`, note, required/optional): Add any additional comments or notes related to your request.
* **Approved by** (`approved_by`, text, required/optional): If approved, enter the name of the person who approved your request.

## Tips
* Please ensure that all required fields are completed before submitting the form.
* If your request has already been approved or denied, please do not submit this form again.
* If your request requires changes, please update the existing request instead of creating a new one.
* If you have any questions or need assistance, contact form@gic.mx.
