# Pool Heating Adjustment Request Form - Help Guide
## Purpose
This form is used to submit requests for adjustments to the pool heating system. If you are a pool owner or maintenance staff, fill out this form to submit your request for adjustments.

## How To Complete This Form
To complete this form, follow these steps:
1. Fill in your personal information (User Information)
2. Select the desired pool temperature
3. Choose the duration of the adjustment
4. Provide a reason for the adjustment
5. Choose the pool size
6. Select the option for the form category
7. Add any additional comments or notes
8. Submit the form

## Field-by-Field Explanation
* **User Information** (`user_info`, text, optional): Enter your name, company, and any other relevant details to help us address your request.
* **Pool Temperature** (`pool_temperature`, select_one, optional): Choose the pool temperature you would like to adjust to. Options: 23°C, 24°C, 25°C
* **Adjustment Duration** (`adjustment_duration`, number, optional): Enter the duration of the adjustment in hours or days.
* **Reason for Adjustment** (`reason_for_adjustment`, text, optional): Enter a brief description of why you're making this adjustment request.
* **Pool Size** (`pool_size`, select_one, optional): Select the size of your pool. Options: Small, Medium, Large
* **Submitted By** (`submitted_by`, text, optional): Enter your name or initials, so we know who submitted the request.
* **Date** (`date`, date, optional): Select the date you would like the adjustment to be made.
* **Time** (`time`, time, optional): Select the time you would like the adjustment to be made.
* **Email** (`email`, email, optional): Enter your email address, so we can contact you about your request.
* **Notes** (`notes`, text, optional): Enter any additional comments or notes about your request.
* **Form Category** (`form_category`, select_one, optional): Select the category for your request. Options: Option A, Option B
* **Assigned Tool** (`assigned_tool`, text, optional): Enter the tool or equipment used to make the adjustment.
