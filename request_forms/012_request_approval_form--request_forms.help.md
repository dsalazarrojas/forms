# Request Approval Form - Help Guide
## Purpose
The Request Approval Form is a form used for requesting approval for employee and manager-related tasks. To use this form, please ensure that the request is not already approved or duplicated. Before submitting a new request, check that it is not already approved.

## How To Complete This Form

1. Fill in all required fields, denoted by an asterisk (\*).
2. Enter relevant information in the `request_details` field to provide a detailed description of the request.
3. Attach any necessary files to the `request_files` field.
4. If the request requires approval from multiple managers, select all the necessary approvers in the `request_files` field.

## Field-by-Field Explanation

* **Request**: This is the main content of the request. Please provide a detailed description of the task or task-related information. 
* **Approver**: This field allows you to select whether the request is approved, denied, or pending. Please select one of the provided options.
* **Request Date**: This field allows you to select the date of the request. Use the date format to input the date.
* **Request Time**: This field allows you to select the time of the request. Use 24-hour time format to input the time.
* **Request Status**: This field is used to track the current status of the request. Select one of the provided options.
* **Notes**: This is a text field for any additional information or comments related to the request.
* **Email Address**: This is an email address to contact the requestor or approver.
* **Phone Number**: This is a phone number to contact the requestor or approver.
* **Department**: This field is used to track the department associated with the request.
* **Manager Name**: This is the name of the manager who submitted the request.
* **Manager Email**: This is the email address of the manager who submitted the request.
* **Manager Phone**: This is the phone number of the manager who submitted the request.
* **Manager Notes**: This is a text field for any additional information or comments related to the manager's approval or denial.
* **Employee Name**: This is the name of the employee who submitted the request.
* **Employee Email**: This is the email address of the employee who submitted the request.
* **Employee Phone**: This is the phone number of the employee who submitted the request.
* **Employee Notes**: This is a text field for any additional information or comments related to the employee's request.
* **Approver Status**: This field is used to track the status of the request after approval or denial.
* **Approver Notes**: This is a text field for any additional information or comments related to the approver's decision.
* **Request Details**: This is a text field for any additional information or comments related to the request.
* **Request Files**: This field allows you to select the files related to the request.
* **Approver Signature**: This is a text field for the approver's signature.
* **Employee Signature**: This is a text field for the employee's signature.
* **Approver Date**: This is a date field for the approver's date.
* **Request Number**: This is a text field for the request number.

## Tips

* Make sure to review the form carefully before submitting it to ensure that all required fields are filled in.
* Use the correct format for date and time fields.
* Use the correct format for email and phone number fields.
* Use clear and concise language in all fields.
