# On Call Consultant Request Form - Help Guide
## Purpose
The On Call Consultant Request Form is used to submit a new request for on-call consultant services. This form helps you communicate your needs to the consultant team and ensures that your request is properly assigned and tracked.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the required fields, which are marked as "required" in the form.
2. Enter a brief description of your request in the "request_description" field.
3. Choose the priority level of your request (High, Medium, or Low) in the "priority_level" field.
4. Select the assigned tool for the request (ChatJimmy or Other) in the "assigned_tool" field.
5. Enter the date and time you need the request by in the "request_date" and "request_time" fields.
6. Select the team that will be using the request in the "team_name" field.
7. Choose the status of your request (Pending, In Progress, or Completed) in the "request_status" field.
8. Enter any additional comments about your request in the "on_call_consultant_request_form_comments" field.
9. Confirm if you want the request to be submitted (Yes or No) in the "on_call_consultant_request_form_submit_button_2" field.

## Field-by-Field Explanation

* **on_call_consultant_request** (Text): Enter a brief description of your on-call consultant request.
* **consultant_name** (Text): Enter the name of the consultant assigned to your request.
* **contact_number** (Text): Enter the contact number of the consultant assigned to your request.
* **request_description** (Text): Enter a brief description of your request.
* **priority_level** (Select One): Choose the priority level of your request (High, Medium, or Low).
* **assigned_tool** (Select One): Select the assigned tool for the request (ChatJimmy or Other).
* **request_date** (Date): Enter the date you need the request by.
* **request_time** (Time): Enter the time you need the request by.
* **team_name** (Text): Enter the team that will be using the request.
* **request_status** (Select One): Choose the status of your request (Pending, In Progress, or Completed).
* **on_call_consultant_request_form_comments** (Note): Enter any additional comments about your request.
* **on_call_consultant_request_form_submit_button_2** (Select One): Confirm if you want to submit the request (Yes or No).
* **request_form_id** (Number): Enter the ID of the request form.
* **output_file** (Text): Enter the output file for the request.
* **on_call_consultant_request_form_submit_button** (Note): This field is not visible to the user, it is a submit button.

Note: The fields with the "required" property are marked as required in the form.
