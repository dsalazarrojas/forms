# Key Request Form - Help Guide
## Purpose
The Key Request Form is used to collect key information from users, including user name, organization, key description, pickup date, and issue date.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the required fields with accurate and complete information.
2. Select the correct organization type from the dropdown list.
3. Enter a clear and concise key description.
4. Choose the correct pickup date for the key.
5. Optionally, enter the issue date if applicable.

## Field-by-Field Explanation
* **User Name** (`user_name`, text, optional): Enter your official user name.
* **Organization** (`organization`, select_one, required): Select the type of organization that issued the key. Choose from 'university', 'school', or 'business'.
* **Department** (`department`, text, optional): Enter your department name if relevant.
* **Key Description** (`key_description`, text, required): Enter a clear and concise description of the key.
* **Pickup Date** (`pickup_date`, date, required): Choose a date when you plan to pick up the key. The date format is YYYY-MM-DD.
* **Issue Date** (`issue_date`, date, optional): Enter the date when the key was issued if applicable. The date format is YYYY-MM-DD.
* **Notes** (`notes`, text, optional): Enter any additional notes or comments about the key.
