# Documentary Sound Mixing Request Form - Help Guide
## Purpose
This form is used to submit a new mix for review and processing.

## How To Complete This Form

1. Select the mixer assigned to work on the mix.
2. Enter the client's name and project number (if known).
3. Choose the project type (Video, TV Show, or Commercial).
4. Specify the mix type (Stereo, Mono, or Surround Sound).
5. Select the mix status (In Progress, Completed, or In Review).
6. Add any additional comments or notes.

## Field-by-Field Explanation

* **Mixer**: The person assigned to work on the mix.
	+ Please select the name of the mixer who will be working on this mix.
	+ This field is required.
* **Submission Date**: The date of the mix submission.
	+ Please enter the date the mix was submitted for review.
	+ This field is optional.
* **Client**: The name of the client associated with the project.
	+ Enter the client's name if available.
	+ This field is optional.
* **Project**: The project number and name (if known).
	+ Enter the project number if it's known.
	+ This field is optional.
* **Project Type**: The type of project the mix is for.
	+ Choose the type that best describes the project (Video, TV Show, or Commercial).
	+ This field is optional.
* **Mix Type**: The type of mix being submitted.
	+ Select the mix type that applies (Stereo, Mono, or Surround Sound).
	+ This field is optional.
* **Mix Version**: The version of the mix being submitted.
	+ Enter the version number (if applicable).
	+ This field is optional.
* **Mix Status**: The status of the mix.
	+ Choose the status that best describes the mix (In Progress, Completed, or In Review).
	+ This field is optional.
* **Mix Comments**: Any additional comments for the mix.
	+ Enter any comments or notes about the mix.
	+ This field is optional.
* **Mix Notes**: Additional notes about the mix.
	+ Enter any additional notes or comments about the mix.
	+ This field is optional.
