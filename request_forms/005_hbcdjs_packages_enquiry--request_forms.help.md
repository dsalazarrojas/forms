# hbcdjs_packages_enquiry - Help Guide
## Purpose
The purpose of this form is to gather information about a potential event or request for a package quote.

## How To Complete This Form
To complete this form, please follow these steps:

1. Select the event type that best describes the event you are planning.
2. Enter the name of the event.
3. Choose the package type(s) that you are interested in.
4. Enter the number of guests that will be attending the event.
5. Enter the date and time of the event.
6. Provide a brief description of the event.
7. Select whether or not you would like to request a quote.
8. Enter your contact name and contact information.
9. Choose whether or not you would like to request a quote in a specific format.
10. Provide any additional details about the quote you would like to request.
11. Select whether or not you would like to request the quote.
12. Enter the package number and any additional details about the package you are interested in.
13. Enter the current status of the package.
14. Provide any additional details about the package.

## Field-by-Field Explanation
* **Event Type** (`Event Type`, select_one, required): Select the type of event that best describes the event you are planning.
* **Event Name** (`event_name`, text, required): Enter the name of the event.
* **Package Type** (`Package Type`, select_multiple, required): Choose the package type(s) that you are interested in.
* **Number of Guests** (`Number of Guests`, number, required): Enter the number of guests that will be attending the event.
* **Date of Event** (`Date of Event`, date, required): Enter the date of the event.
* **Time of Event** (`Time of Event`, time, required): Enter the time of the event.
* **Event Description** (`Event Description`, text, required): Provide a brief description of the event.
* **Quote Request** (`Quote Request`, select_one, required): Select whether or not you would like to request a quote.
* **Contact Name** (`Contact Name`, text, required): Enter your contact name.
* **Contact Email** (`Contact Email`, email, required): Enter your contact email.
* **Contact Number** (`Contact Number`, text, required): Enter your contact number.
* **Event Location** (`Event Location`, text, required): Enter the location of the event.
* **Quote Delivery** (`Quote Delivery`, select_one, required): Select whether or not you would like to request a quote in a specific format.
* **Quote Format** (`Quote Format`, select_one, required): Choose the format in which you would like the quote to be delivered.
* **Quote Details** (`Quote Details`, text, required): Provide any additional details about the quote you would like to request.
* **Quote Requested** (`Quote Requested`, select_one, required): Select whether or not you would like to request the quote.
* **Package** (`Package`, text, required): Enter the package number.
* **Package Number** (`Package Number`, text, required): Enter the package number.
* **Package Status** (`Package Status`, text, required): Enter the package status.
* **Package Details** (`Package Details`, text, required): Provide any additional details about the package.

## Tips
- Make sure to enter accurate and complete information to help us provide the best possible service.
- If you have any questions or concerns, please do not hesitate to contact us.
- This form is for general information gathering purposes only and should not be used to make a payment or booking.
