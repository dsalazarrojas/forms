# Oxygen Machine Request Form - Help Guide
## Purpose

The Oxygen Machine Request Form is used to collect information from users regarding oxygen machine requests. This form is intended to help staff quickly and accurately obtain the necessary details for processing these requests.

## How To Complete This Form

To complete this form, please follow these steps:

1. **Enter your request**: In the "User Input" field, describe the reason for your oxygen machine request.
2. **Select the machine type**: Choose the type of oxygen machine you are requesting from the "Machine Type" dropdown options.
3. **Provide patient information**: Enter the patient's name and age in their respective fields.

## Field-by-Field Explanation

* **User Input** (`User Input`, `text`, optional): This field is for you to provide a brief description of your request. Please be as concise as possible, as this information will help our staff understand your needs.
* **Machine Type** (`Oxygen Concentrator`, `Other`, select multiple, optional): Select one or more of the provided machine types that you are requesting. If "Other" is selected, please provide more details in the "User Input" field.
* **Patient Name** (`Patient Name`, `text`, optional): Enter the patient's name as it appears on their medical record or as they prefer to be addressed.
* **Patient Age** (`Patient Age`, `number`, optional): Enter the patient's age to ensure accurate information is kept on file.
