# Device Enrollment Notification Disable Request Form - Help Guide
## Purpose
The Device Enrollment Notification Disable Request Form is used to request disabling device enrollment for a team or user. This form is typically completed by a team member or user who wants to remove a device from the enrollment program.

## How To Complete This Form
To complete this form, follow the steps below:

1. Select whether you are a team member or not.
2. Choose whether the team submitting the request is the submitting team or not.
3. Enter the reason for the request (optional).
4. Select the date of the request.
5. Select the time of the request.
6. Enter any additional description of the request (optional).
7. Enter the number of devices being requested to be disabled.
8. Select the devices to be disabled (list multiple devices if necessary).
9. Select whether the approver is available to be notified.
10. Select the status of the enrollment (Active or Inactive).
11. Enter any additional notes about the request.
12. Enter the email of the person submitting the request.
13. Enter the phone number of the person submitting the request.
14. Enter the form ID (for internal use).

## Field-by-Field Explanation
* **Submitting Team**: Select 'Yes' if the team submitting this form is the one being asked to disable device enrollment. Select 'No' if another team is submitting this form.
* **Requesting User**: Select 'Yes' if the user submitting this form is the one being asked to disable device enrollment. Select 'No' if another team member is submitting this form.
* **Reason**: Enter a brief description of the reason for disabling device enrollment.
* **Date**: Select the date for the request.
* **Time**: Select the time for the request.
* **Description**: Enter any additional information about the request.
* **Device Count**: Enter the number of devices being requested to be disabled.
* **Devices**: Select the devices to be disabled (list multiple devices if necessary).
* **Approver**: Select 'Yes' if the approver should be notified of the request. Select 'No' if not.
* **Status**: Select the current status of the enrollment (Active or Inactive).
* **Notes**: Enter any additional notes about the request.
* **Email**: Enter the email of the person submitting the request.
* **Phone**: Enter the phone number of the person submitting the request.
* **Form ID**: Enter the form ID for internal use.
* **Assigned To**: Select 'Yes' if the request is assigned to someone else.

## Tips
* Ensure you have the necessary permission to submit this form.
* Review the form fields carefully and provide accurate information.
* If you have already submitted this form for the same purpose and device(s) in the past 7 days, you may not need to submit this form again.
