# Software Development Request Form - Help Guide
## Purpose
This form is used to submit requests related to software development projects. It captures essential information about the project, such as its type, description, deadline, and priority level.

## How To Complete This Form

1. To complete this form, please fill in the required fields as accurately as possible. 
2. If a field is marked as required, please make sure to provide a value for it. 
3. For select_one fields, please choose one option from the provided list. 
4. For date fields, please use the YYYY-MM-DD format (e.g., 2022-07-25). 

## Field-by-Field Explanation

* **Project Type** (`project_type`, select_one): Choose the type of project you are requesting (Web Development, Mobile App Development, or Software Development).
* **Project Description** (`project_description`, note): Briefly describe your project requirements and goals.
* **Client Information** (`client_info`, text): Enter the client's name, email, and phone number.
* **Project Status** (`project_status`, select_one): Select the current status of your project (In Progress, On Hold, or Cancelled).
* **Deadline** (`deadline`, date): Enter the deadline for the project in the YYYY-MM-DD format (e.g., 2022-07-25).
* **Priority** (`priority`, select_one): Choose the priority level of your project (High, Low).
* **Estimated Hours** (`estimated_hours`, number): Estimate the number of hours required for the project.
* **Assigned Tool** (`assigned_tool`, select_one): Select the tool assigned to the project (chatjimmy, other).
* **Additional Comments** (`additional_comments`, note): Add any additional comments or details about your project.
