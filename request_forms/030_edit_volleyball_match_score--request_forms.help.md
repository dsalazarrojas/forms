# Edit Volleyball Match Score - Help Guide
## Purpose
The "Edit Volleyball Match Score" form is designed to allow you to edit the score of a specific volleyball match. This form is typically used by administrators or authorized personnel to correct errors, update scores, or make adjustments to match results.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the match you want to edit by providing its Match ID in the "Match ID" field.
2. Enter the date and time the match was played in the "Date" and "Time" fields.
3. Provide a reason for the changes you're making in the "Reason for changes" field. This is an optional field but helps track the motivation behind the score adjustments.
4. Enter the updated score changes in the "Score Changes" field. Use this field to describe any score adjustments or corrections you're making to the match.

## Field-by-Field Explanation
* **Match ID (Number)**: Enter the unique identifier of the match you want to edit.
* **Date (Date)**: Select the date the match was played. Format should follow YYYY-MM-DD.
* **Time (Time)**: Select the time of the match was played. Format should follow HH:MM AM/PM.
* **Reason for changes (Text)**: Provide a brief explanation for the changes you're making. This field is optional.
* **Score Changes (Text)**: Enter the updated score changes you want to make to the match. Be as detailed as possible to ensure accurate changes are recorded.

## Tips
* Be thorough and accurate when entering score changes to ensure correct match results.
* If you are unsure about any information, contact your supervisor or team lead for assistance.
* Double-check your work before submitting the form to avoid errors.
