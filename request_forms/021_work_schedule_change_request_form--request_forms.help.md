# Work Schedule Change Request Form - Help Guide
## Purpose

The Work Schedule Change Request Form is used to request a change to your regular work schedule.

## How To Complete This Form

1. To complete this form, please fill out the required fields and provide any additional information as requested.
2. Ensure that you have the necessary approvals and signatures before submitting the form.
3. Please review the form carefully and submit it to your supervisor or HR representative for review and approval.

## Field-by-Field Explanation

* **Work Schedule Change Request Form** (`request_form`, text, not required): This is the title of the form.
* **Employee ID** (`employee_id`, number, not required): Enter your employee ID number.
* **Start Date** (`start_date`, date, not required): Enter the start date of the schedule change.
* **End Date** (`end_date`, date, not required): Enter the end date of the schedule change.
* **Shift ID** (`shift_id`, number, not required): Enter the ID of the shift you are requesting to change.
* **Reason for Request** (`reason`, text, not required): Please provide a clear explanation of the request.
* **Manager Approval** (`manager_approval`, select multiple, not required): Check if your manager has approved this change.
* **Department** (`department`, select one, not required): Select the department you are affiliated with.
* **Employee Status** (`employee_status`, select one, not required): Select your current employee status.
* **Manager Signature** (`manager_signature`, note, not required): Enter your manager's signature.
* **Employee Signature** (`employee_signature`, note, not required): Enter your own signature.
* **Approved By** (`approved_by`, select one, not required): Check if the manager has approved this change.
* **Approved Date** (`approved_date`, date, not required): Enter the date of approval.
* **Rejected By** (`rejected_by`, select one, not required): Check if the request was rejected.
* **Rejected Date** (`rejected_date`, date, not required): Enter the date of rejection.
* **Comments** (`comments`, note, not required): Enter any additional comments.
* **Status** (`status`, select one, not required): Select the status of the request.

Note: All fields are optional, however, please ensure that you have filled out all necessary fields before submitting the form.
