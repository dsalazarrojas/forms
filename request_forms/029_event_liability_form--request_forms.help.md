# event-liability-form - Help Guide
## Purpose
The event-liability-form is a tool used to gather event-related information, including date and time, organizer name and email, and sponsor details.

## How to Complete This Form
To complete this form, follow these steps:
1. Select the date of the event from the provided date field.
2. Choose the time of the event from the provided time field.
3. Enter the name of the event organizer.
4. Enter the name of the sponsor, if applicable.
5. Enter the email address of the sponsor, if applicable.

## Field-by-Field Explanation
* **Event Date**: This field is used to input the date of the event, in the format of MM/DD/YYYY. 
* **Event Time**: This field is used to input the start time of the event. 
* **Organizer Name**: Enter the name of the person or organization hosting the event. 
* **Sponsor Name**: Enter the name of any sponsor involved in the event, if applicable.
* **Sponsor Email**: Enter the email address of any sponsor involved in the event, if applicable.
