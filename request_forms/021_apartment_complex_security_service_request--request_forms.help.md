# Apartment Complex Security Service Request - Help Guide
## Purpose
This form is designed for residents to report security incidents or concerns to the apartment complex management. It will help ensure that the management receives accurate and detailed information to effectively address and resolve the issue. Please fill out the form with as much detail as possible to help us assist you in the best possible way.

## How To Complete This Form
- Fill out the form completely and accurately.
- Provide as much detail as possible for each field to help us better understand the issue.
- Review each field explanation below for specific guidance.

## Field-by-Field Explanation

* **Request date** (`request_date`, date, required): Enter the date you are submitting this report.
* **Request time** (`request_time`, time, required): Enter the time you are submitting this report.
* **Request ID number** (`request_id`, text, optional): This will be auto-generated reference number.
* **Resident name** (`resident_name`, text, required): Enter your name as a resident of the apartment complex.
* **Apartment number** (`apartment_number`, text, required): Enter your apartment number (e.g., 101, 202, etc.).
* **Phone number** (`phone_number`, text, required): Enter your contact phone number.
* **Email address** (`email_address`, email, required): Enter your email address.
* **Type of security issue** (`issue_type`, select_one, required): Select the primary category of the incident or concern.
  - Unauthorized access
  - Theft or property damage
  - Suspicious activity
  - Trespassing
  - Harassment or safety threat
  - Equipment malfunction
  - Access control issue
  - Lost access card or key
  - Parking violation
  - Other
* **Location of incident** (`issue_location`, text, required): Enter the location of the incident or concern.
* **Detailed description of security issue** (`issue_description`, text, required): Describe the incident or concern in as much detail as possible.
* **Date incident occurred** (`incident_date`, date, required): Enter the date the incident occurred (if it's not today, select the specific date).
* **Time incident occurred** (`incident_time`, time, optional): Enter the time the incident occurred (if known).
* **Were there any witnesses?** (`witnesses_present`, select_one, required): Select if there were any witnesses.
  - 'True'
  - 'False'
  - Unsure
* **Witness names and contact information** (`witness_details`, text, optional): If there were witnesses, enter their names and contact information.
* **Description of suspect if applicable** (`suspect_description`, text, optional): Provide a physical description, vehicle details, etc. if applicable.
* **Any property damage?** (`property_damage`, select_one, required): Select if there was any property damage.
  - 'True'
  - 'False'
  - Unsure
* **Description of damage** (`damage_description`, text, optional): Describe the property damage.
* **Has a police report been filed?** (`police_report_filed`, select_one, required): Select if a police report has been filed.
  - Yes, report number included
  - 'False'
  - Not applicable
* **Police report number if applicable** (`police_report_number`, text, optional): Enter the police report number.
* **Urgency level** (`urgency_level`, select_one, required): Select the urgency level.
  - Urgent - immediate threat
  - High - significant concern
  - Medium - standard priority
  - Low - non-urgent
* **Requested action from security** (`requested_action`, select_multiple, required): Select all applicable actions from security.
  - Security patrol
  - Camera review
  - Access card review
  - Additional lighting
  - Increased monitoring
  - Investigation
  - Arrest assistance
  - Other
* **Preferred follow-up method** (`follow_up_preference`, select_one, required): Select your preferred method of follow-up.
  - Phone
  - Email
  - In-person
  - Text message
  - No preference
* **Additional information or context** (`additional_information`, text, optional): If you have any further information or context to provide, enter it here.

Note: Fields marked as "optional" can be filled out if you have additional information, but are not required for the form submission.
