# New Account Request Form - Help Guide

## Purpose
The New Account Request Form is used to submit a request for a new account. Before filling out this form, please ensure that you have not already submitted a request for this account. If you are unsure whether you have already submitted a request, you can check our account request history.

## How To Complete This Form

To complete this form, follow these steps:

1. Review the purpose of this form and ensure you have not already submitted a request for this account.
2. Fill out the form by entering your information in the corresponding fields:
	* Select "Page 1: Request Form" to choose whether you want to request a new account (Yes/No)
	* Select "Page 2: Contact Information" to enter your contact information (name, phone number)
	* Select "Page 3: Request Details" to provide additional information about your request (Yes/No)
	* Select "Page 4: Submit" to submit your request. This is a numerical field that requires a value between 1 and 5.
	* Select "Page 5: Requested By" to select whether you are requesting the account for yourself or someone else (Yes/No)
	* Select "Page 6: Requesting User" to enter your email address
	* Select "Page 7: Requested User" to enter the user requesting the account (if different from yourself)
	* Select "Page 8: Account Request Date" to enter the date you want the account to be created (in date format)
	* Select "Page 9: Requester Phone" to enter your phone number

## Field-by-Field Explanation

* **Requested a new account?** (Page 1, new_account_request_form_page_1): This is the first page of the form where you decide if you want to request a new account. Please select "Yes" if you want to request a new account.
* **Contact Information** (Page 2, new_account_request_form_page_2): This field is used to enter your contact information. Please enter your name and phone number in the corresponding fields.
* **Request Details** (Page 3, new_account_request_form_page_3): This field allows you to provide additional information about your request. Please select "Yes" if you have any additional information about your request.
* **Submit** (Page 4, new_account_request_form_page_4): This field is used to submit your request. Please enter a value between 1 and 5 to submit your request.
* **Requested By** (Page 5, new_account_request_form_page_5): This field is used to select whether you are requesting the account for yourself or someone else. Please select "Yes" if you are requesting the account for someone else.
* **Requesting User** (Page 6, new_account_request_form_page_6): This field is used to enter your email address.
* **Requested User** (Page 7, new_account_request_form_page_7): This field is used to enter the email address of the user requesting the account (if different from yourself).
* **Account Request Date** (Page 8, new_account_request_form_page_8): This field is used to enter the date you want the account to be created. Please enter the date in date format.
* **Requester Phone** (Page 9, new_account_request_form_page_9): This field is used to enter your phone number.

## Tips

* Please ensure that all required fields are filled out before submitting the form.
* If you are unsure about any field, please refer to the field-by-field explanation above.
* If you have any issues with submitting the form, please contact our support team.
