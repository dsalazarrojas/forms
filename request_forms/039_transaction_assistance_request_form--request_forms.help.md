# Transaction Assistance Request Form - Help Guide
## Purpose
The Transaction Assistance Request Form is used to submit a request for help with a transaction that requires special handling.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in your First Name and Last Name in the respective fields.
2. Enter the date of the transaction in the Transaction Date field.
3. Enter the amount involved in the Amount field.
4. Provide a brief description of the transaction in the Description field.
5. Select the tool that should be assigned to handle the transaction from the Assigned Tool dropdown.
6. Choose the type of transaction from the Transaction Type field (e.g. cash, check).
7. Select the status of the transaction from the Transaction Status field (e.g. pending, complete).

## Field-by-Field Explanation
* **First Name** (`first_name`, `text`, required/optional): Enter your first name.
* **Last Name** (`last_name`, `text`, required/optional): Enter your last name.
* **Transaction Date** (`transaction_date`, `date`, required/optional): Enter the date of the transaction.
* **Amount** (`amount`, `number`, required/optional): Enter the amount involved in the transaction.
* **Description** (`description`, `text`, required/optional): Provide a brief description of the transaction.
* **Assigned Tool** (`assigned_tool`, `select_one`, required/optional): Select the tool that should be assigned to handle the transaction.
* **Transaction Type** (`transaction_type`, `select_multiple`, required/optional): Choose the type of transaction (e.g. cash, check).
* **Transaction Status** (`transaction_status`, `select_one`, required/optional): Select the status of the transaction (e.g. pending, complete).
