# social_media_content_request_form - Help Guide
## Purpose
The social_media_content_request_form is designed to help content teams gather information for social media content creation. It collects details such as social media platform, type of content, content description, target audience, and content request date. This form streamlines the process for content teams and ensures they have all the necessary information to create valuable content.

## How To Complete This Form
- **Social media platform:** Select the social media platform where you want to post the content.
- **Type of content:** Choose the type of content you want to post (e.g., photo, video, or post).
- **Content description:** Provide a detailed description of the content you want to create.
- **Target audience:** Specify the target audience for the content (e.g., specific age group, interest, or location).
- **Content request date:** Select the date you require the content to be published.

## Field-by-Field Explanation
- **Social media platform (select_one):** Select the social media platform where you want to post the content (e.g., Facebook, Instagram, Twitter).
- **Type of content (select_multiple):** Choose the type of content you want to post (e.g., photo, video, or post).
  - If you select multiple types of content, please separate them with commas (e.g., photo, video, post).
- **Content description (text):** Provide a detailed description of what you want to post. This field is used as a reference for the content team to create the post.
- **Target audience (text):** Specify the target audience for the content (e.g., specific age group, interest, or location).
- **Content request date (date):** Select the date you want the content to be published.

## Tips
- Be as specific as possible when selecting the social media platform and type of content.
- If you have any additional information or details about the content, you can include them in the content description field.
- Please make sure to separate multiple types of content with commas in the Type of content field.
