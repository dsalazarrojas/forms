# Agent Linking Guide Form - Help Guide
## Purpose
This form is used to request linking access to systems and manage the linking process for agents in a business setting.
## How To Complete This Form
To complete this form, follow these steps:

1. Enter your name and email in the "Requester name" and "Requester email" fields to identify yourself as the person making the request.
2. Specify the name of the agent you want to link in the "Agent to link" field.
3. List the systems or accounts you want to link in the "Systems to link" field, selecting all applicable options.
4. Choose the desired "Requested access level" from the available options (Read only, Edit, Admin).
5. Provide a brief explanation for the request in the "Justification for linking" field.
6. If necessary, enter the target date for the linking in the "Requested by date" field.
7. Enter the name of the approver who will review your request in the "Approver name" field.

## Field-by-Field Explanation
* **-- Linking Request --** (Page 1): This is a header section that introduces the form's purpose.
* **Requester name** (Page 1, Required): Enter your name for identification.
* **Requester email** (Page 1, Required): Enter your email for communication about the request.
* **Agent to link** (Page 1, Required): Enter the name or ID of the agent you want to link.
* **Systems to link** (Page 2, Required): Select all systems or accounts you want to link using the available options (CRM, Billing, Email, Support portal, Analytics).
* **Requested access level** (Page 2, Required): Choose the desired access level from the available options (Read only, Edit, Admin).
* **Justification for linking** (Page 2, Required): Provide a brief explanation for the request.
* **Requested by date** (Page 2, Optional): If necessary, enter the target date for the linking.
* **Approver name** (Page 3, Required): Enter the name of the approver who will review your request.
* **Notes** (Page 3, Optional): Provide any additional technical details about the request.

# Tips
- Be specific when listing systems or accounts to link.
- Choose the appropriate access level for the requested systems or accounts.
- Keep the "Justification for linking" field brief and clear.
- If a target date is specified, ensure it is a realistic and achievable deadline.
