# Solar Power Quote Request Form - Help Guide
## Purpose
This form is designed to collect your details so we can provide you with a quote for a solar power installation on your property.

## How To Complete This Form
To complete this form, simply fill out the fields as follows:
- Please enter your First Name.
- Enter your Last Name.
- Enter your Email address.
- Enter the name of the street you would like the solar panels installed on.
- Enter your Apartment Number (if applicable).
- Enter your City.
- Enter your State.
- Enter your Zip Code.
- Check the box indicating if you have a preferred installer.
- Select your preferred solar panel size from the options provided.
- Select the type of solar panels you are interested in (Monocrystalline, Polysilicon, Thin Film).
- Enter the system voltage you would like to have installed.
- Enter the number of panels you would like to have installed.
- Enter the size of the panels you would like to have installed.
- Enter the type of roof you have (Flat, Gable, Hip, etc.).
- Enter the angle of your roof.
- Select the type of solar panel angle you prefer.
- Enter the number of panels you would like to have installed.
- Enter the size of your roof.
- Enter the number of panels you would like to have installed on your roof.

## Field-by-Field Explanation
* **First Name** (`First Name`, text, required): Please enter your first name as it appears on your identification.
* **Last Name** (`Last Name`, text, required): Please enter your last name as it appears on your identification.
* **Email** (`Email`, email, required): Please enter a valid email address that we can use to contact you.
* **Street** (`Street`, text, required): Please enter the name of the street where you would like the solar panels installed.
* **Apt Number** (`Apt Number`, text, optional): If you live in an apartment, please enter the number of your apartment.
* **City** (`City`, text, required): Please enter the city where you would like the solar panels installed.
* **State** (`State`, text, required): Please enter the state where you would like the solar panels installed.
* **Zip Code** (`Zip Code`, text, required): Please enter the zip code where you would like the solar panels installed.
* **Preferred Installer** (`Preferred Installer`, select_multiple, optional): If you have a preferred installer, please check the box.
* **Solar Panel Size** (`Solar Panel Size`, select_one, optional): Please select the size of the solar panels you would like to have installed (small, medium, large).
* **Solar Panel Type** (`Solar Panel Type`, select_one, optional): Please select the type of solar panels you would like to have installed (Monocrystalline, Polysilicon, Thin Film).
* **System Voltage** (`System Voltage`, number, optional): Please enter the system voltage you would like to have installed.
* **Panel Count** (`Panel Count`, number, optional): Please enter the number of panels you would like to have installed.
* **Panel Size 2** (`Panel Size 2`, number, optional): Please enter the size of the panels you would like to have installed.
* **Roof Type** (`Roof Type`, select_one, optional): Please select the type of roof you have (Flat, Gable, Hip, etc.).
* **Roof Angle** (`Roof Angle`, number, optional): Please enter the angle of your roof.
* **Angle** (`Angle`, select_one, optional): Please select the type of solar panel angle you prefer (0, 10, 20, etc.).
* **Roof Area** (`Roof Area`, number, optional): Please enter the size of your roof.
* **Panel Size 2** (`Panel Size 2`, number, optional): Please enter the size of your roof.
* **Panel Count 2** (`Panel Count 2`, number, optional): Please enter the number of panels you would like to have installed on your roof.
