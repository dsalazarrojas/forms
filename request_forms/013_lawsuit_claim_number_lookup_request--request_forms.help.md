# lawsuit_claim_number_lookup_request - Help Guide
## Purpose
The lawsuit claim number lookup request form is designed to provide users with the necessary information on the status of a lawsuit claim by looking up the claim number.

## How To Complete This Form
1. Enter the claim number of the lawsuit you are inquiring about in the "Claim Number" field.
2. Fill out the optional fields as needed, providing the claimant's name, firm name, contact person, claim type, case status, and any supporting documents.
3. Enter your email address and phone number so that you can be contacted with the results.
4. Enter the date of the request in the "Request Date" field.
5. Submit the form to initiate the lookup process.

## Field-by-Field Explanation
* **Claim Number** (`Claim Number`, text, required): Enter the claim number of the lawsuit you are inquiring about. This field is mandatory as it helps to identify the claim uniquely.
* **Claimant Name** (`Claimant Name`, text, optional): If you know the name of the claimant, you can enter it here to narrow down the search results.
* **Firm Name** (`Firm Name`, text, optional): If you know the name of the firm involved in the lawsuit, you can enter it here to narrow down the search results.
* **Contact Person** (`Contact Person`, text, optional): If you have a contact person responsible for the claim, you can enter their name and phone number here to ensure they are notified of any developments.
* **Claim Type** (`Claim Type`, select_one, optional): Select "Yes" if the claim is in progress or "No" if it's closed or archived.
* **Case Status** (`Case Status`, text, optional): This field is not used in this form, please do not fill it out.
* **Supporting Documents** (`Supporting Documents`, note, optional): If you have any supporting documents related to the claim, you can attach them here.
* **Email** (`Email`, email, optional): Enter your email address so that we can contact you with the results of the lookup.
* **Phone** (`Phone`, text, optional): Enter your phone number so that we can contact you with the results of the lookup.
* **Request Date** (`Request Date`, date, required): Enter the date of the request in the format of MM/DD/YYYY.
