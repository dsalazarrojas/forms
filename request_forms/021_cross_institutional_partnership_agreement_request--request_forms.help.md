# Cross Institutional Partnership Agreement Request - Help Guide
## Purpose
The Cross Institutional Partnership Agreement Request form is a tool used to request a cross-institutional partnership agreement between two or more institutions. The form is used to provide necessary information for the partnership agreement and to track the agreement's progress.

## How To Complete This Form
To fill out this form, follow these steps:
1. Fill out the partnership request form with the required information.
2. Make sure to select the correct answer for the proposed partners.
3. Input your proposed start date and end date for the partnership.
4. Attach any supporting documents required for your request.
5. Fill out the contact details of the person requesting the partnership.
6. Select the correct status of the agreement.
7. Fill out the review comments and approval comments sections.
8. Input the signature date and signed by fields.
9. Select the correct approval status.
10. Input the approval date and time.
10. Review and fill out the review comments and review date fields.

## Field-by-Field Explanation
* **Partnership Request** (`Partnership Request`, Text, Required): This is the main field where you can describe your partnership request in brief.
* **Partner Name** (`Partner Name`, Text, Required): Please input the name of your partner institution.
* **Contact Person** (`Contact Person`, Text, Required): Please input the name of the contact person responsible for your institution.
* **Proposed Partners** (`Proposed Partners`, Select Multiple, Required): Please select 'Yes' if your institution is willing to partner with the proposed partner.
* **Partnership Start Date** (`Partnership Start Date`, Date, Required): Please input the date you propose to start the partnership.
* **Proposed End Date** (`Proposed End Date`, Date, Required): Please input the proposed end date of the partnership.
* **Supporting Documents** (`Supporting Documents`, Text, Optional): Please attach any relevant documents that support your partnership request.
* **Comments** (`Comments`, Text, Optional): Please input any additional comments or information that would be helpful for the review process.
* **Contact Details** (`Contact Details`, Text, Optional): Please input any additional contact details of the person requesting the partnership.
* **Agreement Status** (`Agreement Status`, Select One, Required): Please select the status of the agreement, either Draft, Review, or Signed.
* **Review Comments** (`Review Comments`, Text, Optional): Please input any comments from the reviewer.
* **Signature Date** (`Signature Date`, Date, Required): Please input the date the agreement was signed.
* **Signed by** (`Signed by`, Text, Required): Please input the name of the person who signed the agreement.
* **Reviewers** (`Reviewers`, Select Multiple, Optional): Please select 'Yes' if the reviewer has reviewed the agreement.
* **Reviewers Comments** (`Reviewers Comments`, Text, Optional): Please input any comments from the reviewer.
* **Approval Status** (`Approval Status`, Select One, Required): Please select the status of the approval, either Approved, Rejected, or Pending.
* **Approval Date** (`Approval Date`, Date, Required): Please input the date the agreement was approved.
* **Approval Date & Time** (`Approval Date & Time`, Time, Optional): Please input the date and time of the approval.
* **Agreement Version** (`Agreement Version`, Text, Optional): Please input the version of the agreement.
* **Approval Note** (`Approval Note`, Text, Optional): Please input any notes from the approval process.
* **Reviewer Name** (`Review Name`, Text, Optional): Please input the name of the reviewer.
* **Agreement Number** (`Agreement Number`, Number, Optional): Please input the number of the agreement.
* **Review Date** (`Review Date`, Date, Optional): Please input the date of the review.
* **Review** (`Review`, Text, Optional): Please input any information from the review process.
