# Archaeologist Estimate Form - Help Guide
## Purpose
The Archaeologist Estimate Form is designed to gather information about a project's details. This form is intended for project managers, team leaders, and other stakeholders to provide a comprehensive overview of a project's scope, timeline, and budget requirements. Fill out this form to ensure that your project is well-planned and that all necessary information is gathered.

## How To Complete This Form
1. Start by filling out the project details section, which includes the project name, location, and type of archaeological work.
2. Provide a detailed description of the project, including the scope of work and any specific requirements.
3. Estimate the duration of the project in days.
4. Decide if any team members or specialized expertise is needed and list them accordingly.
5. Specify any equipment required for the project.
6. Determine the budget range for the project, if known.
7. Choose the desired project start and deadline dates.
8. Indicate if any travel or laboratory work is required.
9. Finally, submit the form once all fields are completed.

## Field-by-Field Explanation
* **Project Name** (`project_name`, `text`, required): Enter the title or description of the project.
* **Project Location** (`project_location`, `text`, required): Enter the geographic area or site name where the project will take place.
* **Type of Archaeological Work** (`project_type`, `select_one`, required): Choose the type of archaeological work that will be performed.
* **Project Description** (`project_description`, `text`, required): Provide a detailed description of the project, including the scope of work and any specific requirements.
* **Estimated Project Duration (days)** (`project_duration_days`, `number`, required): Enter the estimated number of days required to complete the project.
* **Project Lead Archaeologist Required** (`team_lead_required`, `select_one`, required): Check if a project lead archaeologist is needed.
* **Number of Additional Team Members** (`team_members_count`, `number`, required): Estimate the number of additional team members needed.
* **Specialized Expertise Needed** (`specialized_expertise`, `select_multiple`, optional): Check if any specialized expertise is required, such as ceramics analysis or historical research.
* **Major Equipment Needed** (`equipment_needed`, `select_multiple`, optional): Specify the equipment required for the project, such as excavation tools or photography equipment.
* **Travel Required** (`travel_required`, `select_one`, required): Choose the level of travel required for the project (Local, Regional, National, International).
* **Accommodation Days Needed** (`accommodation_days`, `number`, optional): Enter the number of nights away from base required.
* **Laboratory Work Required** (`lab_work_required`, `select_one`, optional): Check if laboratory work is required.
* **Client Budget Range** (`estimated_budget`, `number`, optional): Enter the estimated budget range for the project, if known.
* **Desired Project Start Date** (`project_start_date`, `date`, required): Enter the desired project start date.
* **Project Deadline** (`project_deadline`, `date`, optional): Enter the date by which the project must be completed.
