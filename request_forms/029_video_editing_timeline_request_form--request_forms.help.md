# Video Editing Timeline Request Form - Help Guide

## Purpose
This form is used to request a video editing timeline from our team. Please fill out this form to provide us with the necessary information we need to create a timeline for your video editing project. Before submitting, ensure that you have all the required information and that this is not a duplicate request.

## How To Complete This Form
To complete this form, follow these steps:

1. Click on the "Submit" button at the end of the form.
2. Fill out all the required fields with the requested information.
3. If you need to provide additional information or clarification, use the "Deadline Notes" field.
4. Review and submit your request.

## Field-by-Field Explanation

* **Project Details** (`project_details`, text, required: false): Please provide a brief description of your project, including the project's name, scope, and any relevant background information.
* **Project Deadline** (`project_deadline`, text, required: false): Please provide the deadline for your project. This will help us create a timeline that meets your needs.
* **Files** (`files`, text, required: false): You may upload any relevant files or documents related to your project. This can include scripts, storyboards, or other reference materials.
* **Editors** (`editors`, select_one, required: false):
	+ If you have a preferred editor, please select "Yes" from the options. If not, select "No".
* **Files Details** (`files_details`, text, required: false): If you have specific requirements for the file types or formats, please provide more information here.
* **File Type** (`file_type`, select_multiple, required: false):
	+ If you have specific requirements for file type (e.g. 4K, 4K UHD), please select "Yes" from the options.
* **Deadline Notes** (`deadline_notes`, note, required: false): If you have any specific requirements or requests for the deadline, please provide more information here.
* **Project Lead** (`project_lead`, text, required: false): If you're representing a team or organization, please provide the name and contact information of the project lead.

## Tips
Please ensure that you have all the necessary information before submitting this form. If you have any questions or concerns, feel free to contact us for assistance.
