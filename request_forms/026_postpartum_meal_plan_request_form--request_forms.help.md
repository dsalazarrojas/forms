# Postpartum Meal Plan Request Form - Help Guide

## Purpose
This form is designed to assist healthcare providers in requesting postpartum meal plans tailored to the individual needs of patients. By completing this form, healthcare providers can specify the type of meal plan required, any medical clearance or special instructions, and the delivery details for the patient.

## How To Complete This Form
Please follow these steps to complete this form:

1. Select "Postpartum Meal Plan Request Form" from the menu.
2. Enter the category, name, email, phone number, and delivery address.
3. Choose the type of meal plan required (Vegetarian, Non-Vegetarian, Kosher, Vegan, Gluten-Free, or Other).
4. If applicable, enter any food allergies or medical clearance requirements.
5. Select the delivery frequency (Once, Regularly, or As needed).
6. Set the delivery date and time.
7. Enter the support program type (if required).
8. Enter any follow-up contact information.
9. Confirm if medical clearance or medical certificate is required.
10. Enter any additional medical information (if required).

## Field-by-Field Explanation

* **Category** (Category, Text): Enter the category of the patient (e.g. postpartum, pediatric, etc.).
* **Name** (Name, Text): Enter the patient's name.
* **Email** (Email, Email, Required): Enter the patient's email address.
* **Phone** (Phone, Text): Enter the patient's phone number.
* **Delivery Details** (Delivery Details, Text): Enter the delivery details, including any special instructions or requirements.
* **Meal Plan** (Meal Plan, Select One, Required): Choose the type of meal plan required:
	+ Vegetarian
	+ Non-Vegetarian
	+ Kosher
	+ Vegan
	+ Gluten-Free
	+ Other
* **Food Allergies** (Food Allergies, Text, Optional): If the patient has any food allergies, enter them here.
* **Follow-up** (Follow-up, Select Multiple, Required): Indicate if follow-up is required:
	+ Yes
	+ No
* **Delivery Preferences** (Delivery Preferences, Text): Enter the patient's delivery preferences.
* **Delivery Address** (Delivery Address, Text, Required): Enter the patient's delivery address.
* **Delivery Date** (Delivery Date, Date, Required): Set the delivery date for the meal plan.
* **Delivery Time** (Delivery Time, Time, Required): Set the delivery time for the meal plan.
* **Delivery Frequency** (Delivery Frequency, Select One, Required): Choose the delivery frequency:
	+ Once
	+ Regularly
	+ As needed
* **Support Program** (Support Program, Text, Required): Enter the support program type (if required).
* **Follow-up Contact** (Follow-up Contact, Text, Required): Enter any follow-up contact information.
* **Medical Clearance** (Medical Clearance, Select Multiple, Required): Confirm if medical clearance is required:
	+ Yes
	+ No
* **Medical Certificate** (Medical Certificate, Select Multiple, Required): Confirm if a medical certificate is required:
	+ Yes
	+ No
* **Medical Information** (Medical Information, Text, Optional): Enter any additional medical information (if required).
* **Medical Information 2** (Medical Information 2, Text, Optional): Enter any additional medical information (if required).
* **Medical Information 3** (Medical Information 3, Text, Optional): Enter any additional medical information (if required).
* **Medical Information 4** (Medical Information 4, Text, Optional): Enter any additional medical information (if required).
* **Medical Information 5** (Medical Information 5, Text, Optional): Enter any additional medical information (if required).
* **Support Program 2** (Support Program 2, Text, Optional): Enter any additional support program information (if required).
