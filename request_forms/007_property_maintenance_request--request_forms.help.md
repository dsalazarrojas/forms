# property_maintenance_request - Help Guide
## Purpose
The Property Maintenance Request form is used to submit requests for routine maintenance, repairs, or upgrades on a specific property. This form helps property managers and staff gather essential information from property owners or tenants about the work that needs to be completed.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the property details in the first field. This is a text field where you can provide any relevant information about the property, such as its address, unit number, or any other identifying details.
2. In the second field, describe the maintenance request in as much detail as possible. This is where you can outline the specific work that needs to be done, including any repairs, upgrades, or routine maintenance tasks.
3. In the third field, select the type of maintenance required from the provided options: Repair, Upgrade, or Maintenance. This helps staff understand the nature of the work and can help them prioritize and schedule the task accordingly.
4. Finally, provide a detailed description of the work required in the fourth field. This is an opportunity to add any additional context or instructions that may be helpful for the staff to complete the task efficiently.

## Field-by-Field Explanation
### Property Details
* **Property Details** (`Property Details`, `text`, required): Enter a brief description of the property, including its address, unit number, or any other identifying details.

### Request
* **Request** (`Request`, `text`, required): Describe the maintenance request in as much detail as possible, including any repairs, upgrades, or routine maintenance tasks required.

### Type
* **Type** (`Type`, `select_one`, optional): Select one of the following options to indicate the type of maintenance required:
	+ Repair
	+ Upgrade
	+ Maintenance

### Description
* **Description** (`Description`, `text`, required): Provide a detailed description of the work required, including any additional context or instructions that may be helpful for the staff to complete the task efficiently.
