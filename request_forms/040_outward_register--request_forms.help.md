# Outward Register - Help Guide
## Purpose
The Outward Register form is used to register outward activities or events, such as submitting requests, customer interactions, or other notable occurrences. This form helps to track and document these events, providing valuable information for future reference and analysis.

## How To Complete This Form
To complete the Outward Register form, follow these steps:

1. Select the option "Yes" or "No" for "Submit Request" to indicate whether the activity is a request submission.
2. Enter the customer's email address in the "customer_email" field, if applicable.
3. Enter the customer's name in the "customer_name" field.
4. Enter the customer's phone number in the "customer_phone" field, if applicable.
5. Write a brief message or description in the "customer_message" field to provide context about the activity.
6. Provide any additional information in the "customer_note" field, if needed.
7. Select the date of the outward activity in the "Date Of Outward" field.
8. Select the time of the outward activity in the "time_of_outward" field.
9. Choose whether a tool is assigned to the activity by selecting "Yes" or "No" in the "Assigned Tool" field.
10. Choose whether a user is assigned to the activity by selecting "Yes" or "No" in the "Assigned User" field.
11. Select a category for the activity by choosing "Yes" or "No" from the provided options.

## Field-by-Field Explanation
* **Submit Request** (`Submit Request`, `select_one`, required): Indicates whether the outward activity is a request submission. Select "Yes" to indicate a submission, "No" otherwise.
* **customer_email** (`customer_email`, `email`, optional): Enter the customer's email address, if applicable.
* **customer_name** (`customer_name`, `text`, required): Enter the customer's name.
* **customer_phone** (`customer_phone`, `text`, optional): Enter the customer's phone number, if applicable.
* **customer_message** (`customer_message`, `note`, required): Write a brief message or description about the outward activity.
* **customer_note** (`customer_note`, `note`, required): Provide any additional information about the outward activity.
* **Date Of Outward** (`Date Of Outward`, `date`, required): Select the date of the outward activity.
* **time_of_outward** (`time_of_outward`, `time`, required): Select the time of the outward activity.
* **Assigned Tool** (`Assigned Tool`, `select_one`, optional): Choose whether a tool is assigned to the outward activity by selecting "Yes" or "No".
* **Assigned User** (`Assigned User`, `select_one`, optional): Choose whether a user is assigned to the outward activity by selecting "Yes" or "No".
* **Category** (`Category`, `select_one`, optional): Select a category for the outward activity by choosing "Yes" or "No" from the provided options.
