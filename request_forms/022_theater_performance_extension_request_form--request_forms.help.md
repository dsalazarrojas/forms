# Theater Performance Extension Request Form - Help Guide
## Purpose
This form is used to request an extension for a theater performance.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill in the production date.
2. Fill in the show start and show end times.
3. Enter the theater's name.
4. Provide a valid reason for the extension request (optional but recommended).

## Field-by-Field Explanation

* **Production Date** (<name>, <type: date>): Enter the production date of the performance.
* **Show Start Time** (<name>, <type: time>): Enter the start time of the show.
* **Show End Time** (<name>, <type: time>): Enter the end time of the show.
* **Theater Name** (<name>, <type: text>): Enter the name of the theater where the performance will take place.
* **Extension Reason** (<name>, <type: text>): Enter a valid reason for the extension request (optional but recommended).
* **Extension Status** (<name>, <type: select_one>): Choose the status of the extension request from the available options (Approved, Denied, or Pending).
* **Notes** (<name>, <type: note>): Add any additional comments or notes about the production.
* **Production Team External URL** (<name>, <type: text>): Enter the external URL of the production team's website (optional).
* **Production Contact** (<name>, <type: text>): Enter the contact information of the production team (optional).
* **Production Email** (<name>, <type: email>): Enter the email of the production team (optional).
* **Production Phone** (<name>, <type: text>): Enter the phone number of the production team (optional).
* **Production Fax** (<name>, <type: text>): Enter the fax number of the production team (optional).
* **Theater Performance External URL** (<name>, <type: text>): Enter the external URL of the theater's website (optional).

## Tips

* Make sure to fill in all required fields.
* Double-check the production date and times to ensure accuracy.
* If you need to add any additional information, use the notes field.
* Choose the correct extension status to ensure that the request is processed smoothly.
