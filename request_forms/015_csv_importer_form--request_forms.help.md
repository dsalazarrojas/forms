# CSV Importer Form - Help Guide
## Purpose
The CSV Importer Form is used to collect information from users who wish to import data into the system. This form is necessary for the import team to process and import data correctly.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the requester's name and email address for status updates.
2. Specify the target system where the data will be imported.
3. Describe the data to be imported, including columns and expected formats.
4. Provide a link to a sample CSV file for reference.
5. Estimate the number of rows in the data to be imported.
6. Specify the request priority, which affects scheduling.
7. Add any additional notes or comments for the import team.

## Field-by-Field Explanation
### Requester name
* **Requester name** (text, required): Enter the name of the person requesting the data import.
### Requester email
* **Requester email** (email, required): Enter the email address of the person requesting the data import, to receive status updates.
### Target system for import
* **Target system for import** (text, required): Enter the name of the system where the data will be imported (e.g., CRM database or reporting system).
### Description of data to import
* **Description of data to import** (text, required): Explain the columns and expected formats of the data to be imported.
### Sample file link
* **Sample file link** (text, optional): Provide a link to a sample CSV file for reference.
### Estimated number of rows
* **Estimated number of rows** (number, required): Provide an estimate of the number of rows in the data to be imported, to help plan import processing.
### Request priority
* **Request priority** (select one: Low, Medium, High, required): Indicate the business impact of the import request, to affect scheduling.
### Additional notes
* **Additional notes** (text, optional): Add any other information that the import team should know about the data import request.

### Tips

* Ensure that you are authorized to import data into the system.
* Use this form for data that does not exist in the system yet.
* If you are unsure about any field, contact the import team for guidance.
