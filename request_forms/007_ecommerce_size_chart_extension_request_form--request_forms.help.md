# ecommerce_size_chart_extension_request_form - Help Guide

## Purpose
This form is designed to gather information from users for ecommerce size chart extension requests. It is intended for employees or users to provide necessary details for reviewing and processing size chart extension requests.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the required fields, indicated by a red asterisk (\*) after the field label.
2. Select one option from the Category dropdown menu.
3. Type a brief description of the extension request in the Description field.
4. Optionally select one or more options from the Review Status dropdown menu and add any additional review notes.
5. Optionally add any Web Development comments.

## Field-by-Field Explanation
### Category (<name>, Category, required)
Select a category to associate with this size chart extension request from the dropdown menu.

### Description (<name>, Description, required)
Type a brief description of the extension request, explaining the reason for the request.

### Review Status (<name>, Review Status, required:false)
Select one or more of the following options for the review status of this extension request:
- Option 5
- Option 6
- Option 7
- Option 8

### Review Notes (<name>, Review Notes, required:false)
Add any additional notes for reviewing this extension request.

### Web Dev Comments (<name>, Web Dev Comments, required:false)
Add any comments for the web development team related to this extension request.

Note: The required fields are marked with a red asterisk (\*) after the field label. Ensure that all required fields are filled before submitting the form.
