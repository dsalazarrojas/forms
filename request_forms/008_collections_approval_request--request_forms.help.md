# Collections Approval Request - Help Guide

## Purpose
The Collections Approval Request form is used to submit a request for collection approval for a specific customer account. This form provides all necessary details for the collections team to efficiently evaluate and approve collections requests.

## How To Complete This Form
### To begin, select the correct options for your collection request. 
1. Select the request date for when the collection request was submitted.
2. Fill in the Request Number, a unique identifier for this request.
3. Enter the name of the person making the request.
4. Enter the department making the request.
5. Provide the customer's email address.
6. Select who will handle the collection.
7. Enter the customer's name and account number.
8. Enter the invoice number associated with the request.
9. Enter the outstanding amount due.
10. Select the original due date for the payment.
11. (Optional) Enter the number of days past due.
12. Describe any previous collection attempts made.
13. Select the current payment status for the customer.
14. Select the methods of contact available for the customer.
15. Select the recommended collection strategy.
16. Select the approval authority level required.
17. Indicate if supporting documents are attached.
18. Set a desired collection deadline if necessary.
19. Enter any special considerations or notes.
20. (Optional) Enter the approval status and name of the approver.
21. Enter any approval comments or justification.

## Field-by-Field Explanation
* **Request Date**: The date the collection request was submitted.
* **Request Number**: A unique identifier for this collection request.
* **Requested By**: The name of the person making the request.
* **Department**: The department making the request.
* **Email Address**: The customer's email address.
* **Collections Agent or Team**: Who will handle the collection.
* **Customer Name**: The name of the entity owing payment.
* **Customer Account Number**: The customer's account number.
* **Invoice Number**: The invoice number associated with the request.
* **Outstanding Amount**: The total amount due from the customer.
* **Original Due Date**: The date the payment was originally due.
* **Days Past Due**: (Optional) The number of days past due.
* **Previous Collection Attempts**: Describe any previous collection attempts made.
* **Current Payment Status**: Select the current payment status for the customer.
* **Available Customer Contact Methods**: Select all available methods of contact for the customer.
* **Recommended Collection Strategy**: Select the recommended approach for collections.
* **Approval Authority Level Needed**: Select the level of approval required.
* **Supporting Documents Attached**: Indicate if supporting documents are attached.
* **Desired Collection Deadline**: (Optional) Set a desired collection deadline.
* **Special Circumstances or Notes**: Enter any relevant context or special considerations.
* **Approval Status**: (Optional) Enter the approval status and name of the approver.
* **Approval Comments**: Enter any approval comments or justification.
* **Approver Name**: (Optional) Enter the name of the person approving the request.
* **Approve Comments**: Enter any comments made during approval.
* **Collection Deadline**: (Optional) Enter a desired collection deadline.
* **Special Considerations or Notes**: Enter any additional context.
