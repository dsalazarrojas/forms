# Free Project Proposal - Help Guide
## Purpose
The Free Project Proposal form is used to collect and store information about new project proposals. 

## How To Complete This Form
To complete this form, please follow these steps:
1. Fill in the project title and description in the `Project Proposal` and `Project Description` fields.
2. Select the project status from the `Project Status` dropdown menu.
3. Add the names of all stakeholders involved in the project to the `Stakeholder List` field.
4. (Optional) Select the project start and end dates, and enter the project budget if applicable.
5. Fill in the project lead's name and contact information.

## Field-by-Field Explanation
* **Project Proposal** (text, required): Enter a brief title for the project.
* **Project Status** (select one, optional): Select the current status of the project, which can be "In Progress", "On Hold", or "Completed".
* **Stakeholder List** (select multiple, required): Add the names of all stakeholders involved in the project. This can be multiple stakeholders.
* **Project Description** (text, optional): Describe the project in a few sentences, highlighting its goals, objectives, and expected outcomes.
* **Project Start Date** (date, optional): Select the start date of the project if it's already known.
* **Project End Date** (date, optional): Select the end date of the project if it's already known.
* **Project Budget** (number, optional): Enter the budget for the project if it's already allocated.
* **Project Lead** (text, optional): Fill in the name of the project lead, who will be responsible for the project's progress and success.

## Tips
* Be as specific as possible when filling out the form.
* Use the correct format for dates (YYYY-MM-DD).
* If you're unsure about any field, feel free to ask for clarification.
* The form can be filled out multiple times for different projects, but please ensure that each project has a unique title.
