# Retail Store Signage Requisition Form - Help Guide
## Purpose
The Retail Store Signage Requisition Form is used by store employees to request signage installations for various purposes within their respective retail stores.

## How To Complete This Form

1.  Fill out the form completely and accurately to ensure that your request is processed efficiently.
2.  Review each field carefully to avoid any misunderstandings.
3.  Submit the form to your supervisor or manager for approval.

## Field-by-Field Explanation

*   **Location Name** (`Location Name`, text, required): This field is where you enter the name of the location where the signage is to be installed. Please ensure that this name is accurate and matches the location where the signage is needed.
*   **Sign Type** (`Sign Type`, select_one, required): This field is where you select the type of signage you need, such as Acrylic Sign, Backlit Sign, etc. Please choose the most suitable option from the list provided.
*   **Sign Description** (`Sign Description`, text, optional): This field is for a brief description of the signage, such as the text or image it will display. If you have a specific description, please enter it here; otherwise, leave it blank.
*   **Sign Image** (`Sign Image`, date, required): This field is where you select the date and time when the signage is needed. Please choose a specific date and time for installation.
*   **Installation Location** (`Installation Location`, text, required): This field is where you specify the exact location within the store where the signage will be installed, such as near the entrance or a specific aisle.
*   **Urgency** (`Urgency`, number, required): This field is where you rate the urgency of the signage installation, with options ranging from Low to Very High. Please select the most suitable level of urgency.
*   **Priority** (`Priority`, select_one, required): This field is where you choose the priority level of the signage installation, such as Low, Medium, or High. Please select the most suitable option.
*   **Sign Size** (`Sign Size`, number, required): This field is where you specify the size of the signage in inches. Please ensure that the size matches the location and type of signage selected.
