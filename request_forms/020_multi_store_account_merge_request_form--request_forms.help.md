# Multi Store Account Merge Request Form - Help Guide
## Purpose
The purpose of this form is to facilitate the process of merging multiple store accounts into one, allowing users to request the consolidation of their store accounts into a single, unified account.

## How To Complete This Form
To complete this form, please follow the instructions below:

1. Ensure you have all necessary information and authorization to request a store account merge.
2. Select the stores you wish to merge from the options provided.
3. Fill in the date and time you would like the merge to occur.
4. Enter any relevant notes about the merge request.
5. Review and submit the form.
