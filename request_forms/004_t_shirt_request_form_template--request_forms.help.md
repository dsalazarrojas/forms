# T Shirt Request Form Template - Help Guide
## Purpose
The T Shirt Request Form is used to collect information for T-shirt requests from students. It helps event organizers keep track of student requests and preferences for event T-shirts.

## How To Complete This Form
1. Fill in your event name and title in the event_organizer field.
2. Enter the student's name in the student_name field.
3. Provide the student's ID number in the student_id field.
4. Select the desired T-shirt size in the t_shirt_size field.
5. Choose one or more T-shirt colors in the shirt_color field.
6. Enter the event date in the event_date field.
7. Select the event time in the event_time field.
8. If you have any additional notes, type them in the note field.
9. Enter your email address in the email field.
10. Enter your phone number in the phone field.
11. Finally, select the quantity of T-shirts you need in the t_shirt_quantity field.

## Field-by-Field Explanation

* **Event Organizer** (`event_organizer`, Text, Optional): Enter the name of the event you are requesting the T-shirt for.
* **Student Name** (`student_name`, Text, Optional): Enter the name of the student requesting the T-shirt.
* **Student ID** (`student_id`, Number, Optional): Enter the student's ID number to confirm their identity.
* **T Shirt Size** (`t_shirt_size`, Select One, Optional): Choose the size of T-shirt you prefer.
* **Shirt Color** (`shirt_color`, Select Multiple, Optional): Select one or more colors of T-shirt you like.
* **Event Date** (`event_date`, Date, Optional): Enter the date of the event.
* **Event Time** (`event_time`, Time, Optional): Enter the time of the event.
* **Note** (`note`, Text, Optional): If you have any specific notes or requests, type them here.
* **Email** (`email`, Email, Optional): Enter your email address for contact purposes.
* **Phone** (`phone`, Text, Optional): Enter your phone number for contact purposes.
* **T Shirt Quantity** (`t_shirt_quantity`, Number, Optional): Select the quantity of T-shirts you need.
