# Days Off Request Form - Help Guide
## Purpose
This form is used by employees to request days off for a specific period. It helps the HR or management team to track and process these requests in a timely manner.

## How To Complete This Form
1. Fill in the employee's name to identify the person making the request.
2. Choose the dates for which the employee is requesting time off.
3. Provide a valid reason for the time off request.
4. (Optional) Select the approval status of the request.
5. (Optional) Add any comments or notes for the manager to review.
6. (Optional) Add any assigned tools or resources for the request.

## Field-by-Field Explanation
* **Employee Name** (`employee_name`, text, required): Enter the full name of the employee making the request.
* **Days Off Request Date** (`days_off_request_date`, date, optional): Select the date for which the employee is requesting time off.
* **Start Date** (`start_date`, date, optional): Enter the start date of the time off period.
* **End Date** (`end_date`, date, optional): Enter the end date of the time off period.
* **Reason** (`reason`, text, required): Enter a valid reason for the time off request, such as vacation, sick leave, or family emergency.
* **Approval Status** (`approval_status`, select_one, optional): Select the current status of the request: Approved, Denied, or Pending.
* **Comments** (`comments`, text, optional): Add any comments or notes for the manager to review.
* **Assigned Tool** (`assigned_tool`, text, optional): Enter any assigned tools or resources related to the request.
* **Manager Comments** (`manager_comments`, text, optional): Enter any comments or feedback from the manager.
* **Request Form ID** (`days_off_request_form_id`, text, optional): This is a unique identifier for the request.
* **Tips**: Please note that all fields are optional unless otherwise stated. Please ensure that all required fields are filled in before submitting the form.
