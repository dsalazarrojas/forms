# Treasury Resource Allocation Registration Form - Help Guide

## Purpose
The Treasury Resource Allocation Registration Form is a tool used to request treasury-managed and non-treasury-managed resources. This form helps track and manage requests for resources within the organization.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the type of resource you are requesting (Treasury-Managed Funds or Non-Treasury-Managed Funds)
2. Enter the amount of resources you need.
3. Provide a brief description of your request (Request Details).
4. Choose the department responsible for your request (Department).
5. Select the priority level of your request (Low, Medium, High).
6. Select the review status of your request (Approved, Denied, In Progress).
7. List all resources assigned for this request (Assigned Resources).
8. Select the user submitting the request (Submitted By).

## Field-by-Field Explanation
### Form Header
* **Form Header** (`form_header`, text, not required)

This is the header section of the form that contains the title and other information about the form.

### Request Type
* **Request Type** (`request_type`, select_one, not required)
  * Select the type of resource you are requesting (Treasury-Managed Funds or Non-Treasury-Managed Funds).

### Request Amount
* **Request Amount** (`request_amount`, number, not required)
  * Enter the amount of resources you need.

### Request Details
* **Request Details** (`request_details`, text, not required)
  * Provide a brief description of your request.

### Department
* **Department** (`department`, select_multiple, not required)
  * Choose the department responsible for your request (Accounting, Human Resources, Marketing).

### Priority
* **Priority** (`priority`, select_one, not required)
  * Select the priority level of your request (Low, Medium, High).

### Review Status
* **Review Status** (`review_status`, select_one, not required)
  * Select the review status of your request (Approved, Denied, In Progress).

### Assigned Resources
* **Assigned Resources** (`assigned_resources`, text, not required)
  * List all resources assigned for this request.

### Submitted By
* **Submitted By** (`submitted_by`, select_one, not required)
  * Select the user submitting the request (User 1, User 2, User 3).

## Tips
* Make sure to fill out all required fields to ensure your request is processed correctly.
* If you are unsure about any of the fields, please ask your supervisor or department head for clarification.
* If you need to make changes to your request, please contact the relevant department directly.
