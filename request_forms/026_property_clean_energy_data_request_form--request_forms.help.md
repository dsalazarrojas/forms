# property_clean_energy_data_request_form - Help Guide
## Purpose
This form is designed to collect information about a property's energy consumption and infrastructure. It is intended to help assess the property's energy efficiency and identify areas for improvement.
## How To Complete This Form
1. Fill in the required fields as prompted. Most fields are optional, but please ensure to fill in any required fields.
2. For fields with multiple options, select the options that best describe your property.
3. Be accurate when filling in numerical fields (e.g., building Sq Ft).
## Field-by-Field Explanation

* **Property Owner**: Enter the name of the property owner.
* **Property Address**: Enter the address of the property.
* **Contact Email**: Enter the email address of the contact person.
* **Contact Phone**: Enter the phone number of the contact person.
* **Energy Consumption Type**: Select the type of energy consumption (electricity, gas, water, or other).
* **Energy Consumption Period**: Select the period for which you are reporting energy consumption (daily, monthly, or yearly).
* **Energy Consumption Level**: Select the level of energy consumption (low, high, or other).
* **Energy Source**: Select the primary energy source (solar, wind, geothermal, or other).
* **Energy Storage**: Select the primary energy storage method (battery, tank, or other).
* **Building Sq Ft**: Enter the square footage of the building.
* **Total Appliances**: Enter the total number of appliances in the building.
* **Appliances with Energy Efficiency Features**: Enter the number of appliances with energy efficiency features.
* **Energy Efficiency Features**: Select the energy efficiency features (solar, wind, geothermal, or other).
* **Building Age**: Select the age of the building (new, 1-5, 6-10, 11-15, etc.).
* **Roof Type**: Select the type of roof (asphalt, metal, tile, or other).
* **Wall Type**: Select the type of wall (brick, wood, steel, or other).
* **Window Type**: Select the type of window (double, triple, single, or other).
* **Door Type**: Select the type of door (automatic, manual, or other).
* **Foundation Type**: Select the type of foundation (basement, crawlspace, slab, or other).
* **Floor Type**: Select the type of floor (slab, crawl, or other).
* **Wall Insulation**: Select the wall insulation (insulated, uninsulated, or other).
* **Attic Insulation**: Select the attic insulation (insulated, uninsulated, or other).
* **Roof Insulation**: Select the roof insulation (insulated, uninsulated, or other).
* **Foundation Insulation**: Select the foundation insulation (insulated, uninsulated, or other).
* **Foundation Drains**: Select the foundation drains (insulated, uninsulated, or other).
* **Electrical Systems**: Select the electrical systems (panel, breaker, or other).
* **Plumbing Systems**: Select the plumbing systems (panel, breaker, or other).
* **HVAC Systems**: Select the HVAC systems (central, window, or other).
* **Fire Alarm Systems**: Select the fire alarm systems (installed, not installed, or other).
* **Sprinkler Systems**: Select the sprinkler systems (installed, not installed, or other).
* **Security Systems**: Select the security systems (monitored, unmonitored, or other).
* **Smart Home Devices**: Select the smart home devices (hub, switch, or other).
* **Smart Home Features**: Select the smart home features (enabled, disabled, or other).
* **Smart Home Systems**: Select the smart home systems (hub, switch, or other).
* **Electrical Metering**: Select the electrical metering (smart meter, analog meter, or other).
