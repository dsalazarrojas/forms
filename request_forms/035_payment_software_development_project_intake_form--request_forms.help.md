# Payment Software Development Project Intake Form - Help Guide
## Purpose
This form is designed to collect information for the payment software development project intake process.

## How To Complete This Form
To complete this form, please follow the steps below:

1. Fill in the required fields, marked as "Required" in the form.
2. Answer each question carefully, ensuring that the information provided is accurate and complete.
3. Use the provided dropdown menus to select the correct options.

## Field-by-Field Explanation

* **Payment Software Development Project Intake Name** (`payment_software_development_project_intake_name`, Text, Required): Please provide a brief description of the payment software development project.
* **Is this a high priority project?** (`payment_software_development_project_intake_category`, Select Multiple, Required): Please select "Yes" if the project has high priority, "No" otherwise.
* **Please provide a description of the project** (`payment_software_development_project_intake_description`, Text, Required): Please provide a detailed description of the project, including the objectives, deliverables, and any specific requirements.
* **What is the project deadline?** (`payment_software_development_project_intake_deadline`, Date, Required): Please enter the project deadline in a format that follows the international standard (YYYY-MM-DD).
* **When does the project start?** (`payment_software_development_project_intake_start_date`, Date, Required): Please enter the project start date in a format that follows the international standard (YYYY-MM-DD).
* **Which organisation is associated with this project?** (`payment_software_development_project_intake_organisation`, Text, Required): Please provide the name of the organisation associated with this project.

## Tips
* Ensure that you have filled in all required fields correctly.
* Be as detailed as possible when providing the project description, as this will help the project management process.
* If you are unsure about any of the fields or their requirements, please contact the project management team for guidance.
