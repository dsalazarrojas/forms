# Graphic Design Request Form - Help Guide
## Purpose

This form is designed to collect detailed information about your graphic design project requests, including project description, type, size, and deadline.

## How To Complete This Form

To complete this form, follow these steps:

1. Enter a brief description of your project in the `Project Description` field.
2. Select the appropriate project type from the dropdown menu in the `project_type` field.
3. Choose the size of your project from the dropdown menu in the `project_size` field.
4. Enter the deadline for your project in the `Deadline` field (date format).
5. Enter your expected completion time for the project in the `Expected Completion Time` field.
6. Provide your email address in the `Email Address` field.
7. Enter your phone number in the `Phone Number` field.
8. Upload any relevant project files in the `Project File Upload` field.
9. Upload any design files in the `Design File Upload` field.
10. Add any additional comments or notes for the project in the `Notes` field.
11. Select the category of your project in the `Category` field.
12. Add relevant tags for your project in the `Tags` field.
13. Enter your budget for the project in the `Budget` field (numeric format).
14. Select the user assigned to your project from the dropdown menu in the `Assigned User` field.
15. Select the status of your project from the dropdown menu in the `Status` field.
16. Add any comments about your project in the `Comments` field.
17. Enter the project status in the `Project Status` field.
18. Add any custom fields as needed.
