# Workforce Inclusion Strategy Request Form - Help Guide
## Purpose
The purpose of this form is to collect specific requests regarding workforce inclusion strategies. It is meant to gather information about the requests, context, challenges, and recommended strategies and next steps. Please ensure that you submit only relevant and specific requests.

## How To Complete This Form
To complete this form, follow these steps:

1. Please provide the **Request Details** in the text box on the first page.
2. If applicable, select the **Challenges** faced in the **Challenges** field. You may select multiple challenges.
3. In the **Support Needs** field, specify what kind of support is required for the request.
4. Describe your recommended **Strategy Guidance** and **Strategy Recommendations** in the text boxes provided.
5. In the **Next Steps** field, describe the next actions or steps you plan to take.
6. Select your preferred **Review Date** and **Review Time** for the request submission.
7. Fill in your **Submitter Name** and **Submitter Email** with your valid name and email address. A valid email address is required for contact purposes.
8. Enter your valid **Submitter Phone** number for easy contact.

## Field-by-Field Explanation

* **Submitter Name** (`Submitter Name`, text, required): Enter your name as the submitter of this request.
* **Submitter Email** (`Submitter Email`, email, required): Please provide a valid email address for communication purposes.
* **Submitter Phone** (`Submitter Phone`, text, required): Enter a valid phone number for easy contact.
* **Review Date** (`Review Date`, date, optional): Select the date you would like the review to take place.
* **Review Time** (`Review Time`, time, optional): Choose the time you would like the review to take place.
* **Request Details** (`Request Details`, text, optional): Provide a brief description of the request.
* **Workforce Inclusion Context** (`Workforce Inclusion Context`, text, optional): Describe the context surrounding the request.
* **Challenges** (`Challenges`, select_multiple, required): Select one or more challenges faced while making the request.
* **Support Needs** (`Support Needs`, text, optional): Specify what kind of support is needed for the request.
* **Strategy Guidance** (`Strategy Guidance`, text, optional): Offer guidance for the strategy.
* **Strategy Recommendations** (`Strategy Recommendations`, select_multiple, required): Select recommended strategies for the request.
* **Next Steps** (`Next Steps`, text, optional): Describe the next actions or steps.
* **Submitter Email** is used for email contact.

Note: Please ensure you complete the form accurately and follow the provided structure for a smooth submission process.
