# Acting School Material Request Form - Help Guide
## Purpose
The Acting School Material Request Form is used to collect information from individuals or groups within the acting school requesting materials such as scripts, props, or costumes for productions or classes. This form helps ensure that the request is properly recorded and that materials are delivered correctly.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the required fields:
	* **Requester name**: Enter the full name of the person making the request.
	* **Contact email**: Enter the email address where you can be reached for delivery and follow-up.
	* **Production or class**: Enter the name of the production or class for which you are requesting materials.
	* **Item requested**: Describe the specific item you are requesting (e.g., script, prop, costume).
	* **Quantity needed**: Enter the number of items you require.
	* **Required by date**: Enter the date by which you need the materials.
	* **Approval name**: Enter the name of the manager or director approving this request.
2. If applicable, select the **Delivery method** from the options provided.

## Field-by-Field Explanation
* **Requester information**: This field is a placeholder and not applicable.
* **Requester name**: Enter the full name of the person making the request.
* **Contact email**: Enter the email address where you can be reached for delivery and follow-up.
* **Production or class**: Enter the name of the production or class for which you are requesting materials.
* **Item requested**: Describe the specific item you are requesting (e.g., script, prop, costume).
* **Quantity needed**: Enter the number of items you require.
* **Required by date**: Enter the date by which you need the materials.
* **Delivery method**: Select how you would like to receive the items (Pickup, Campus delivery, Mail).
* **Special instructions**: If necessary, provide any additional notes about sizing, color, or setup for the items.
* **Budget code**: If you have a specific account or cost center, enter it here.
* **Approval name**: Enter the name of the manager or director approving this request.
* **Additional notes**: Enter any other relevant information.

## Tips
* Please ensure that the production or class name and required date match the existing production schedule and materials requests.
* If you have any questions or concerns, contact the form administrators.
* This form will help us deliver the materials correctly and efficiently, so please provide detailed information for each field.
