# Soundtrack Rights Usage Request Form - Help Guide
## Purpose
This form is designed to collect information from users who wish to request the usage rights of music tracks for their projects.

## How To Complete This Form
To complete this form, please follow the steps outlined above and fill out each field in the provided sequence.

## Field-by-Field Explanation
### Project Info (project_info, text, required/optional)
Please provide a brief description of your project.

### Music Details (music_details, text, required/optional)
Enter a brief description of the music track you are interested in using.

### Usage Terms (usage_terms, text, required/optional)
Please describe how you plan to use the music, including any intended platforms, events, or other relevant details.

### License Terms (license_terms, text, required/optional)
If there are any specific terms or conditions that need to be met for the music usage, please list them here.

### Project Dates (project_dates, text, required/optional)
Enter the start and end dates of your project.

### Project Team (project_team, text, required/optional)
If your project involves a team, please list their names and roles.

### Submitter Info (submitter_info, text, required/optional)
Please provide your name and contact information so we can get back to you.

### Contact Info (contact_info, text, required/optional)
Enter your name and email address where you can be reached.

### Submit (submit, text, required/optional)
Once all information is filled out, click "Submit" to complete your request.

### Submitter Info (submitter_info, text, required/optional)
Please provide your name and any other relevant details for our records.

## Tips
Please review each field carefully to ensure you have filled it out completely and accurately before submitting the form. If you have any questions or concerns, feel free to contact us.
