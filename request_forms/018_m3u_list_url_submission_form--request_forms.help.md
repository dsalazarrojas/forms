# M3U List URL Submission Form - Help Guide

## Purpose
This form is for submitting M3U list URLs, which are used to create playlists for media players. The form helps us gather essential information from you, the user, to ensure the accuracy and relevance of the submitted lists.

## How To Complete This Form

1. Fill in the required fields with the necessary information.
2. Make sure to enter a valid M3U list URL for the `M3U List URL` field.
3. Provide clear and accurate `Usage Details` if you're using the list for any specific purpose.
4. Select your consent by choosing one of the options for the `Consent` field.
5. Enter your email address in the `Email` field.
6. Optional fields like `Provider Name`, `Media App Developer`, and `Playlist Curator` are for additional context and can be filled in if relevant.

## Field-by-Field Explanation

* **M3U List URL** (`title`, text, required): Enter the URL of the M3U list you're submitting. This is the primary field for the form and must be filled in for your submission to be valid.
* **M3U Links** (`m3u_links`, text, required): Enter the links associated with the M3U list, if applicable. This field is used to provide additional context and help us verify the accuracy of your submission.
* **Usage Details** (`usage_details`, text, optional): Provide a brief description of how you plan to use the M3U list. This helps us understand the purpose of your submission and ensure it's used correctly.
* **Consent** (`consent`, select_one, required): Choose the reason for submitting this M3U list. Please select one of the options provided.
* **Provider Name** (`provider_name`, text, optional): If you're submitting on behalf of a provider, please enter their name here.
* **Email** (`email`, email, required): Enter your email address to get updates and notifications about your submission.
* **Media App Developer** (`media_app_developer`, text, optional): If you're the developer of the media player, please enter your name here.
* **Playlist Curator** (`playlist_curator`, text, optional): If you're curating the playlist, please enter your name here.

Note: All fields marked as required must be filled in for your submission to be valid.
