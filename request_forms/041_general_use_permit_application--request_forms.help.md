# General Use Permit Application - Help Guide
## Purpose
The General Use Permit Application form is used to collect information for a general use permit application. This form is typically used for new applications or updates to existing applications. Please ensure that you are using this form for its intended purpose and not duplicating efforts. If you have already submitted an application for the same facility, please do not submit another application.

## How To Complete This Form
To complete this form, follow these steps:

1. Ensure you have all the necessary information before starting the application process.
2. Fill in the required fields (indicated by a *) with accurate and complete information.
3. Review the form for any errors or missing information before submitting.

## Field-by-Field Explanation

* **Application**: This is a note field to provide any additional information about the application.
* **Facility Name**: Enter the name of the facility that is applying for a permit.
* **Facility Type**: Select the type of facility from the provided options (Yes/No).
* **Applicant**: Select who is applying for the permit (Yes/No).
* **Contact E-mail**: Enter the contact email for the applicant or facility.
* **Contact Phone**: Enter the contact phone number for the applicant or facility.
* **Facility Address**: Enter the physical address of the facility.
* **Facility City, State ZIP**: Enter the city, state, and ZIP code of the facility.
* **Permit Application Date**: Enter the date of the permit application.
* **Permit Application Time**: Enter the time of the permit application.
* **Permit Expiration Date**: Enter the expiration date of the permit.
* **Permit Expiration Time**: Enter the expiration time of the permit.
* **Permit Status**: Select the status of the permit from the provided options (Active/Inactive).
* **Facility Use**: Enter the use of the facility.
* **Facility Capacity**: Select whether the facility has capacity (Yes/No).
* **Permit Fees**: Enter any fees associated with the permit.
* **Permit Fees Total**: Enter the total fees for the permit.
* **Payment Method**: Select the method of payment for the permit (Yes/No).
* **Application Status**: Select the status of the application from the provided options (Active/Inactive).
* **Comments**: Enter any additional comments about the application.
* **Facility Use Additional**: Enter any additional information about the facility use.
* **Facility Name 2**: Enter the name of the facility (if applicable).
* **Facility Type 2**: Enter the type of facility (if applicable).
* **Facility Use 2**: Enter the use of the facility (if applicable).
* **Facility Capacity 2**: Enter the capacity of the facility (if applicable).

## Tips
* Ensure that you have all the necessary information before submitting the application.
* Double-check the form for any errors or missing information before submitting.
* If you have any questions or concerns, contact the relevant authorities for assistance.
