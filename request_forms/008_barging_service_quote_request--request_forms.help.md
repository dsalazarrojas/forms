# Barging Service Quote Request - Help Guide
## Purpose

The purpose of this form is to provide us with necessary information about your cargo and requirements for transport so we can generate an accurate quote.

## How To Complete This Form

*   Complete all required fields with accurate information
*   Be as detailed as possible when providing cargo descriptions and special requirements
*   Indicate any hazardous materials involved
*   Select "True" if you are transporting hazardous materials, otherwise select "False"
*   Specify any additional services needed
*   Select a preferred barge type if you have one
*   Indicate any special requirements or comments

## Field-by-Field Explanation

*   **Company Name** (`company_name`, text, required): Name of your company or organization
*   **Contact Person Name** (`contact_name`, text, required): Full name of primary contact
*   **Job Title** (`job_title`, text, required): Your position or title
*   **Email Address** (`email_address`, email, required): For quote delivery and communication
*   **Phone Number** (`phone_number`, text, required): Best contact number
*   **Company Address** (`company_address`, text, required): Complete street address
*   **Type of Cargo** (`cargo_type`, select_one, required): Choose from Bulk materials, Containers, Heavy equipment, Liquid cargo, General freight, Project cargo, or Other
*   **Cargo Description** (`cargo_description`, text, required): Detailed description of goods
*   **Estimated Weight in Tons** (`estimated_weight`, number, required): Approximate total weight
*   **Cargo Dimensions** (`cargo_dimensions`, text, optional): Length x width x height if applicable
*   **Origin Port or Location** (`origin_port`, text, required): Where will cargo be loaded
*   **Destination Port or Location** (`destination_port`, text, required): Where will cargo be unloaded
*   **Estimated Distance in Nautical Miles** (`estimated_distance`, number, optional): If known
*   **Preferred Loading Date** (`preferred_loading_date`, date, required): When do you need loading to begin
*   **Preferred Delivery Date** (`preferred_delivery_date`, date, required): When do you need delivery completed
*   **Timeline Flexibility** (`timeline_flexibility`, select_one, required): Choose from Very flexible, Somewhat flexible, Not flexible - fixed dates
*   **Special Requirements** (`special_requirements`, text, optional): Any special handling or equipment needs
*   **Hazardous Materials Involved** (`hazardous_materials`, select_one, required): Select 'True' if you are transporting hazardous materials, otherwise select 'False'
*   **Hazardous Materials Details** (`hazmat_details`, text, optional): Describe the hazardous materials if applicable
*   **Insurance Coverage Required** (`insurance_required`, select_one, required): Choose from Yes, full coverage, Yes, basic coverage, No, we have our own insurance
*   **Previous Barging Experience** (`previous_barging_experience`, select_one, required): Select Yes, frequently, Yes, occasionally, or No, first time
*   **Preferred Barge Type** (`preferred_barge_type`, select_one, required): Select from No preference, Deck barge, Hopper barge, Tank barge, Container barge
*   **Quote Validity Period** (`quote_validity`, select_one, required): Choose from 30 days, 60 days, 90 days, As long as possible
*   **Additional Services Needed** (`additional_services`, select_multiple, required): Select from Loading services, Unloading services, Storage, Customs clearance, Cargo insurance, Tracking services, None
*   **How Did You Hear About Us** (`how_did_you_hear`, select_one, optional): Select from Online search, Referral, Industry contact, Advertisement, Previous customer, Other
*   **Additional Comments or Questions** (`additional_comments`, text, optional): Any other information to share
