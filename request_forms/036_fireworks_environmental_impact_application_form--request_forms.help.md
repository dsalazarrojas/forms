# Fireworks Environmental Impact Application Form - Help Guide
## Purpose
This form is used to gather information for events involving fireworks, such as displays, shows, and festivals. Please fill out the form with accurate and detailed information to ensure a successful application.

## How To Complete This Form
- Ensure that the start and end dates and times are filled in correctly, including AM/PM for times and month/day/year format for dates.
- Select the correct event type from the provided options.
- List all the types of fireworks that will be used.
- Write any special requests or additional information for our follow-up questions.
- Fill in any relevant permits or documentation details.
- Provide accurate contact information, including phone number and email.

## Field-by-Field Explanation

* **Event Details**: This field is where you can provide a brief description of the event. This can include details such as event theme, purpose, or any other relevant information that will help us understand the scope of the event.
* **Event Type**: Select the type of event from the list provided (Fireworks Display, Fireworks Show, Fireworks Festival, or Other). This will help us determine which regulations and permits apply to your event.
* **Start Date**: Enter the date of the event in month/day/year format (e.g., June 1, 2023).
* **Start Time**: Enter the start time of the event in AM/PM format (e.g., 8:00 PM).
* **End Date**: Enter the date of the event in month/day/year format (e.g., June 1, 2023).
* **End Time**: Enter the end time of the event in AM/PM format (e.g., 10:00 PM).
* **Firework Types**: Select all the types of fireworks that will be used, separated by commas (e.g., Sparkler, Roman Candles).
* **Protection Measures**: This field is for any additional measures you are taking to minimize the environmental impact of the event. This can include any steps you are taking to prevent noise pollution, fire prevention, or other environmental concerns.
* **Contact Name**: Enter the name of the person we can contact for follow-up questions or concerns.
* **Contact Phone**: Enter the phone number of the contact person.
* **Contact E-mail**: Enter the email of the contact person.
* **Event Location**: Enter the location where the event will take place.
* **Permit Details**: If you have any permits or documentation related to your event, please attach them here.
* **Special Requests**: If you have any special requests or additional information that we need to know, please provide it here.
* **Event Notes**: This is an optional field for any additional notes or comments about your event.

Please fill out this form accurately and completely to ensure that your event is properly reviewed and approved. If you have any questions or concerns, please don't hesitate to reach out to us.
