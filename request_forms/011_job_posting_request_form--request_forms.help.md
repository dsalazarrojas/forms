# Job Posting Request Form - Help Guide
## Purpose
This form is used to submit a new job posting for a job board or website.

## How To Complete This Form

To submit a new job posting, follow these steps:

1.  Select the type of job posting you want to create using the "Submit New Job Posting" options.
2.  Fill in the required information:
	*   Contact information:
		+   Contact Name
	*   Contact Email
	*   Contact Phone
3.  Add job posting details:
	*   Job Title
	*   Job Location
	*   Job Type
	*   Job Category
	*   Job Level
	*   Job Status
4.  Add any additional job posting details:
	*   Job Description
	*   Job Requirements
	*   Job Requirements Description
	*   Job Category Description
	*   Job Posting Comments
5.  Add any additional job posting information:
	*   Company Name
	*   Department
	*   Job URL
	*   Job Posting Date
	*   Job Status Date
	*   Company URL
6.  Upload a job posting image (optional)

## Field-by-Field Explanation

*   **Submit New Job Posting**: Select the type of job posting you want to create. This field is optional.
*   **Location**: Select the location(s) where the job is based.
*   **Job Description**: A brief description of the job.
*   **Job Type**: Select the type of job (full-time, part-time, freelance, etc.).
*   **Job Category**: Select the category of the job (IT, Marketing, Sales, etc.).
*   **Job Level**: Select the level of the job (entry level, mid level, senior level, etc.).
*   **Job Status**: Select the status of the job (active, inactive, etc.).
*   **Contact Name**: The name of the contact person.
*   **Contact Email**: The email of the contact person.
*   **Contact Phone**: The phone number of the contact person.
*   **Company Name**: The name of the company.
*   **Department**: The department of the company.
*   **Job URL**: The URL of the job posting.
*   **Job Posting Date**: The date the job was posted.
*   **Job Status Date**: The date the job status was updated.
*   **Company URL**: The URL of the company.
*   **Job Posting Status**: Select the status of the job posting (active, inactive, etc.).
*   **Job Category Description**: A brief description of the job category.
*   **Job Requirements Description**: A brief description of the job requirements.
*   **Job Posting Comments**: Any additional comments about the job posting.
*   **Contact Address**: The address of the contact person.
*   **Job Posting Image**: An optional image for the job posting.
*   **Submit**: Submit the form to create the job posting.
