# looking_for_a_lawyer - Help Guide
## Purpose
The "looking_for_a_lawyer" form is designed to gather information from individuals looking for legal representation. This form helps us understand what kind of legal assistance you need and provides us with necessary details to connect you with the right lawyer.

## How To Complete This Form
To complete this form, follow these steps:

1.  Please fill out all required fields (marked with *) with your information.
2.  Make sure to enter accurate dates in the required date fields (e.g., `Date of Birth`, `Crime Date`, `Crime Date 2`).
3.  Select the correct options in the multiple-choice fields (e.g., `Case Status`, `Contact Method`, `Case Location`, `Crime Type`, `Contact Method`, `Crime Type 2`, `Case Court 2`).

## Field-by-Field Explanation

*   **First Name** (`first_name`, Text, Optional): Enter your first name as it is on your identification documents.
*   **Last Name** (`last_name`, Text, Required): Enter your last name as it is on your identification documents.
*   **Email** (`email`, Email, Required): Enter a valid email address where you can be contacted.
*   **Phone Number** (`phone_number`, Text, Optional): Enter your phone number where you can be contacted.
*   **Date of Birth** (`date_of_birth`, Date, Optional): Enter your date of birth in the format MM/DD/YYYY.
*   **Crime Charges** (`crime_charges`, Select One, Required): Select the type of crime you are looking for a lawyer for (e.g., Civil, Criminal, etc.).
*   **Attorney Details** (`attorney_details`, Text, Optional): If you have any previous experience with an attorney, please describe it briefly.
*   **Case Number** (`case_number`, Text, Required): Enter your case number (if you already have one).
*   **Case Status** (`case_status`, Select One, Required): Select the current status of your case (e.g., Open, Closed, Pending, etc.).
*   **Court** (`case_court`, Select One, Optional): If you have a specific court associated with your case, please select it here.
*   **Attorney Notes** (`attorney_notes`, Note, Optional): If you have any comments or notes about the attorney you are looking for, please enter them here.
*   **Case Details** (`case_details`, Text, Optional): If you have any additional details about your case, please describe them briefly.
*   **Crime Type** (`crime_type`, Select Multiple, Required): Select the type(s) of crime you are looking for a lawyer for (e.g., Theft, Assault, etc.).
*   **Contact Method** (`contact_method`, Select Multiple, Required): Select the method(s) you prefer to contact (e.g., Phone, Email, In-person, etc.).
*   **Attorney Fees** (`attorney_fees`, Number, Optional): If you are concerned about the attorney's fee, you may estimate it here.
*   **Crime Count** (`crime_count`, Number, Optional): If you have multiple crimes, please enter their count here.
*   **Case Location** (`case_location`, Select Multiple, Required): Select the location(s) where the crime occurred or is associated with your case.
*   **Crime Date** (`crime_date`, Date, Optional): Enter the date of the crime (if applicable).
*   **Case Number 2** (`case_number_2`, Text, Optional): If you have multiple case numbers, please enter them here.
*   **Crime Location** (`crime_location`, Text, Optional): Enter any additional details about the location of the crime (e.g., specific room, etc.).
*   **Attorney Fee** (`attorney_fee`, Number, Optional): If you are concerned about the attorney's fee, you may estimate it here.
*   **Crime Location 2** (`crime_location_2`, Text, Optional): Enter any additional details about the location of the second crime (e.g., specific room, etc.).
*   **Crime Type 2** (`crime_type_2`, Select One, Required): Select the type of the second crime you are looking for a lawyer for.
*   **Crime Date 2** (`crime_date_2`, Date, Optional): If you have multiple crimes with different dates, please enter the date of the second crime (if applicable).
*   **Court 2** (`case_court_2`, Select Multiple, Optional): If you have a specific court associated with your second case, please select it here.
