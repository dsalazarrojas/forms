# Issue Record Request Form - Help Guide
## Purpose
This form is used to capture and track information related to issue records.

## How To Complete This Form

1. **Requestor Information**: Enter the name and contact information of the person submitting the request.
2. **Request Date**: Select the date the issue was first reported or discovered.
3. **Issue Description**: Provide a brief description of the issue.
4. **Coverage Type**: Select the type of coverage related to the issue.
5. **Coverage Type 2**: Select an additional coverage type if applicable.
6. **Issue Date**: Select the date the issue began or was first noticed.
7. **Claim Number**: Enter the claim number related to the issue, if applicable.
8. **Claim Status**: Select the current status of the claim.
9. **Claim Status 2**: Select the status of the claim for the second coverage type.
10. **Claim Number 2**: Enter the claim number for the second coverage type, if applicable.
11. **Claimant Name**: Enter the name of the person filing the claim, if applicable.
12. **Issue Record**: Enter any additional information about the issue.
