# Mpox Supply Request Form - Help Guide
## Purpose
The Mpox Supply Request Form is designed to collect information for internal supply management purposes. This form helps employees request supplies and materials for their tasks and projects. It's essential to fill out the form accurately to ensure that the supply requests are processed correctly.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the required fields:
	* `Item Number`: Enter the unique identifier for the item being requested.
	* `Item Name`: Enter the name of the item being requested.
	* `Item Type`: Select the type of item from the given options.
	* `Request Date`: Enter the date when the supply is needed.
	* `Contact Name`: Enter the name of the contact person responsible for the request.
	* `Contact Phone`: Enter the phone number of the contact person.
	* `Contact Email`: Enter the email address of the contact person.
	* `Item Location`: Enter the location where the item will be used or stored.
	* `Item Status`: Select the status of the item from the given options.
	* `Assigned User`: Select the user responsible for the item.
	* `Notes`: Add any additional notes about the request.
	* `Submit`: Choose how to submit the form, either as `Submit` or `Save Draft`.
	* `Submit Date`: Enter the date of submission.
2. Select the `Item Type` from the provided options.
3. Fill in the `Quantity` field, if required.
4. Ensure that all fields are accurate and complete before submitting the form.

## Field-by-Field Explanation

* **Item Number** (`item_number`, Number, optional): Enter a unique identifier for the item being requested.
* **Item Name** (`item_name`, Text, optional): Enter the name of the item being requested.
* **Item Type** (`item_type`, Select Multiple, optional): Select the type of item from the given options. This will help in categorizing the items for easier management.
* **Description** (`description`, Text, optional): Enter a brief description of the item, if necessary.
* **Quantity** (`quantity`, Number, optional): Enter the quantity of the item needed, if required.
* **Request Date** (`request_date`, Date, optional): Enter the date when the supply is needed.
* **Contact Name** (`contact_name`, Text, optional): Enter the name of the contact person responsible for the request.
* **Contact Phone** (`contact_phone`, Text, optional): Enter the phone number of the contact person.
* **Contact Email** (`contact_email`, Email, optional): Enter the email address of the contact person.
* **Item Location** (`item_location`, Text, optional): Enter the location where the item will be used or stored.
* **Item Status** (`item_status`, Select One, optional): Select the status of the item from the given options.
* **Assigned User** (`assigned_user`, Select One, optional): Select the user responsible for the item.
* **Notes** (`notes`, Text, optional): Add any additional notes about the request.
* **Submit** (`submit`, Select Multiple, optional): Choose how to submit the form, either as `Submit` or `Save Draft`.
* **Submit Date** (`submit_date`, Date, optional): Enter the date of submission.

**Tips**

* Ensure that all fields are accurate and complete before submitting the form.
* If you select `Save Draft`, you can come back to the form later to make changes or complete it further.
* If you select `Submit`, the form will be processed immediately, and you will not be able to make changes later.
