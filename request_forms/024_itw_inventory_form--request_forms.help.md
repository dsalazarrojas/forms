# itw_inventory_form - Help Guide
## Purpose
The **itw_inventory_form** is a multi-page form designed to collect detailed information from users. It is used to create and manage an inventory, tracking items and their corresponding details.

## How To Complete This Form
To complete this form, follow these steps:

1. Start by filling in the required fields on the first page.
2. Proceed to the second page and select multiple items from the list. You must select at least one item.
3. On the third page, select one item from the list.
4. Move on to the fourth page, where you can input a time if necessary.
5. The fifth page is for inputting a date if required.
6. On the sixth page, enter your email address.
7. The seventh page is optional and can be skipped.
8. Enter a numerical value on the eighth page, if required.
9. Proceed to the ninth page, where you must enter text.
10. On the tenth page, input another numerical value.
11. The eleventh page is a notes field, where you can input any relevant information.
12. On the twelfth page, select one item from the list.
13. Fill in a text field on the thirteenth page.
14. Enter your email address on the last page.
15. Select one of the two options on the last page, 'Yes' or 'No'.

## Field-by-Field Explanation

* **first page (group_1)** (note, required): This is the introductory page where you will input your details to begin the inventory creation process.
* **Select multiple items (group_2)** (select_multiple, required): Choose at least one item from the list to proceed with the inventory creation process.
* **Select one item (group_3)** (select_one, required): On this page, select one item from the list to continue with the inventory creation process.
* **Time (group_4)** (time, required): If necessary, input the time on this page.
* **Date (group_5)** (date, required): If required, input the date on this page.
* **Email (group_6)** (text, required): Enter your email address.
* **Notes (group_11)** (note, required): Input any relevant information you'd like to include with your inventory.
* **Select one item (group_12)** (select_one, required): On this page, select one item from the list.
* **Text input (group_13)** (text, required): Fill in the text field with the required information.
* **Email (group_14)** (email, required): Enter your email address.
* **Select an option (group_15)** (select_multiple, required): Select either 'Yes' or 'No' from the list.
