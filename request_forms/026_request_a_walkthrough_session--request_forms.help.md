# Request A Walkthrough Session - Help Guide
## Purpose
The purpose of this form is to collect information about your request for a walkthrough session.

## How To Complete This Form

To complete this form, please follow the steps above and fill in the required fields.

## Field-by-Field Explanation

* **Session Details** (id: 1, type: text, required: false): Enter a brief description of the session you are requesting.
* **Session Time** (id: 2, type: time, required: false): Select the time you are available to have the session.
* **Session Date** (id: 3, type: date, required: false): Choose the date you are available to have the session.
* **Requestor Name** (id: 4, type: text, required: false): Enter your name as the person requesting the session.
* **Requestor Email** (id: 5, type: email, required: false): Enter your email address.
* **Session Priorities** (id: 6, type: select_multiple, required: false): Choose how important is this session for you.
* **Priority Level** (id: 7, type: select_one, required: false): Select the level of priority for this session.
* **Additional Comments** (id: 8, type: text, required: false): Provide any additional information that will help us better understand your request.
* **Product/Service Name** (id: 9, type: text, required: false): If applicable, enter the name of the product or service related to this request.
* **Request Type** (id: 10, type: select_one, required: false): Choose the type of request (Product or Service).
* **Customer Success Manager** (id: 11, type: select_one, required: false): Select the team that handles customer success.
* **Additional Information** (id: 12, type: text, required: false): Enter any extra details that might be helpful for the session.
* **Request Status** (id: 13, type: select_one, required: false): Select the status of your request (New, In Progress, Completed).
* **Assigned To** (id: 14, type: select_one, required: false): Choose the team or individual that will handle your request.
* **Assigned Tool** (id: 15, type: select_one, required: false): Select the tool that will be used for this request.
* **Created By** (id: 16, type: text, required: false): Enter the name of the person who created this request.
* **Created Date** (id: 17, type: date, required: false): The date this request was created.
* **Updated Date** (id: 18, type: date, required: false): The date this request was last updated.
* **Updated By** (id: 19, type: text, required: false): Enter the name of the person who last updated this request.
* **Comments** (id: 20, type: text, required: false): Enter any comments related to this request.
* **Attachments** (id: 21, type: text, required: false): Upload any relevant files or documents.
