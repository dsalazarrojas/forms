# Software Installation Request Form - Help Guide
## Purpose
The Software Installation Request Form is a tool used to collect information from users who want to install software on their computer or server. This form helps the IT team to track and manage software installation requests efficiently.

## How To Complete This Form
To complete this form, follow these steps:

* Select whether you want to install software or not.
* Provide a brief description of the software you want to install.
* Enter the name of your school (this will help the IT team to identify your school and contact you more easily).
* Enter the name of the software you want to install.
* Specify the contact person responsible for the installation.
* Enter the email address of the contact person.
* Enter the contact phone number of the contact person.
* If your school has a department for the software installation, select it from the list.
* Enter the school ID number (if applicable).

## Field-by-Field Explanation

* **Request Software**: Choose 'Yes' to indicate that you want to install software. If you do not have any software requests, select 'No'.
* **Description**: Provide a brief description of the software you want to install, so that the IT team can better understand your request.
* **School Name**: Enter the name of your school. This will help the IT team to contact you more easily and ensure that the software is installed correctly.
* **Software Name**: Enter the name of the software you want to install.
* **Contact Person**: Enter the name of the person responsible for the software installation.
* **Contact Email**: Enter the email address of the contact person.
* **Contact Phone**: Enter the phone number of the contact person.
* **Department**: If your school has a department for the software installation, select it from the list.
* **School ID**: Enter the school ID number (if applicable).
