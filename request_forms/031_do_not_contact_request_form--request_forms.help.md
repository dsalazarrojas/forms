# Do Not Contact Request Form - Help Guide
## Purpose
This form allows users to indicate their preference not to be contacted by the organization, providing a clear and concise way to communicate their wishes.

## How To Complete This Form

*   Start by filling out the "Organization" field with the name of the organization you are not wanting to contact you.
*   Select "Yes" or "No" for "Contact Method" if you want to be contacted or not.
*   If "Yes" is selected, you will be asked "Other" if you have a specific reason for this request.
*   In "Reason for Requesting", you can enter a brief explanation for your request.
*   Select "Yes" or "No" for "Request Type" if you want to be contacted about a specific type of request.
*   If "Yes" is selected, you will be asked for more information in the "Email" or "Phone" fields.
*   Select "Yes" or "No" for "Best Method of Contact" if you have a preference for how you want to be contacted.
*   If "Yes" is selected, you will be asked for more information in the "Email", "Phone", or "Other" fields.
*   Select "Yes" or "No" for "How to Contact" if you want to be contacted through specific methods.
*   If "Yes" is selected, you will be asked for more information in the "Email", "Phone", or "Other" fields.
*   For "Do Not Call Me", "Do Not Mail Me", "Do Not SMS Me", "Do Not Email Me", and "Do Not Contact Me Anyway", select "Yes" if you do not want to be contacted through these methods.
*   Finally, select "Yes" or "No" for "Contact Preferred Method" if you have a preferred method of contact.

## Field-by-Field Explanation

*   **Organization**: Enter the name of the organization you are not wanting to contact you.
*   **Contact Method**: Select "Yes" if you do not want to be contacted at all, or "No" if you are open to being contacted.
*   **Reason for Requesting**: Enter a brief explanation for your request if you selected "Yes" for "Contact Method".
*   **Request Type**: Select "Yes" if you want to be contacted about a specific type of request, or "No" if you are open to all requests.
*   **Email/Phone/Other fields**: If you selected "Yes" for "Request Type", you will be asked for more information in the corresponding field.
*   **Best Method of Contact**: Select "Yes" if you have a preference for how you want to be contacted, and enter the corresponding field.
*   **How to Contact**: Select "Yes" if you want to be contacted through specific methods, and enter the corresponding field.
*   **Do Not Call Me, Do Not Mail Me, Do Not SMS Me, Do Not Email Me, Do Not Contact Me Anyway**: Select "Yes" if you do not want to be contacted through these methods.
*   **Contact Preferred Method**: Select "Yes" if you have a preferred method of contact, and enter the corresponding field.

## Tips

*   Make sure to fill out this form only once, unless your circumstances have changed significantly.
