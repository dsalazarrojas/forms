# Character Reference Request Form - Help Guide
## Purpose
The Character Reference Request Form is used to request a character reference from a referee. This form allows you to submit a structured request for a reference, providing essential details to help the referee write a comprehensive and relevant character assessment.

## How To Complete This Form
To complete this form, follow these steps:

1. Start by filling out the required fields:
	* Requester's name
	* Requester's email
	* Referee's name
	* Referee's contact information (email or phone)
	* Relationship (e.g., Employer, Colleague, Teacher, Friend, or Other)
	* Reason for the request
2. If necessary, provide additional information, such as the deadline for the reference and any additional instructions for the referee.
3. Confirm that the subject has given their consent for the reference request.

## Field-by-Field Explanation
* **requester name** (`requester_name`, text, required): Enter the name of the person requesting the reference.
* **requester email** (`requester_email`, email, required): Enter the contact email for follow-up communication.
* **referee name** (`referee_name`, text, required): Enter the name of the person who will write the reference.
* **referee contact** (`referee_contact`, text, required): Enter the email or phone number for the referee.
* **relationship** (`relationship`, select_one, required): Select the relationship between the requester and the referee (e.g., Employer, Colleague, Teacher, Friend, or Other).
* **reason for request** (`reason_for_request`, text, required): Explain why the reference is needed.
* **deadline** (`deadline`, date, optional): If applicable, enter the date by which the reference is needed.
* **additional instructions** (`additional_instructions`, text, optional): Provide any specific guidance for the referee.
* **consent from subject** (`consent_from_subject`, select_one, required): Confirm that the subject has given their consent for the reference request.
