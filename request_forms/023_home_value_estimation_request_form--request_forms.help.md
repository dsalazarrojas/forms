# Home Value Estimation Request Form - Help Guide
## Purpose
This form is designed to gather information from clients or customers to estimate the value of their property. It is used to provide essential details about the property, date, and contact information to generate an output file with the estimated home value.

## How To Complete This Form

1. Start by filling in the form title and description at the top of the page.
2. Select the form category from the options provided (Request Forms, Real Estate Forms).
3. Enter the client's name and address in the respective fields.
4. Choose the state where the property is located from the provided options.
5. Enter the zip code of the property.
6. Provide the date of the request.
7. Enter the time of the request.
8. Add the client's phone number and email for contact purposes.
9. Add any additional note about the request (optional).
10. Optionally, specify which tool is assigned to work on this request.
11. Optionally, upload or enter the name of the output file.
12. Enter the ID(s) of the form(s) this form is related to (if applicable).
