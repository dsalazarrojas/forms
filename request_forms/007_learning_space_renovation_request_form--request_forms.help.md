# learning_space_renovation_request_form - Help Guide
## Purpose
The purpose of this form is to request renovations for learning spaces in schools. This guide will walk you through each field of the form and explain how to complete it accurately.

## How To Complete This Form
1. Select the school ID from the drop-down menu that corresponds to the school where the learning space is located.
2. If the space is not currently available for renovation, enter the date you would like to request the renovation.
3. Enter the room number or address of the learning space.
4. Describe the type of renovation needed for the space.
5. Select the priority level of the renovation, which can be Low, Medium, or High.
6. Choose the status of the space, which can be New, Under Repair, Under Renovation, or Active.
7. Select the type of space, such as Classrooms, Labs, Offices, or Meeting Spaces.
8. Evaluate the current condition of the space, which can be Good, Fair, or Poor.
9. Enter the capacity of the space, if applicable.
10. Enter the date of the renovation request, if applicable.
11. Enter your name and title, so that the form can be submitted to the correct person.
12. Enter the person or department to whom the form should be submitted.
13. Enter the location of the learning space.
14. Enter the floor or level of the space.
15. Enter a brief description of the learning space.
16. Add any additional notes about the renovation request.

## Field-by-Field Explanation
* **School Id** (School Id, select_one, required): Select the school ID from the drop-down menu that corresponds to the school where the learning space is located.
* **Form Date** (Form Date, date, required): Enter the date you would like to submit the renovation request, if the space is not currently available for renovation.
* **Room Number** (Room Number, text, required): Enter the room number or address of the learning space.
* **Renovation Need** (Renovation Need, text, required): Describe the type of renovation needed for the space.
* **Priority Level** (Priority Level, select_one, required): Select the priority level of the renovation, which can be Low, Medium, or High.
* **Status** (Status, select_one, required): Choose the status of the space, which can be New, Under Repair, Under Renovation, or Active.
* **Space Type** (Space Type, select_one, required): Select the type of space, such as Classrooms, Labs, Offices, or Meeting Spaces.
* **Room Condition** (Room Condition, select_one, required): Evaluate the current condition of the space, which can be Good, Fair, or Poor.
* **Space Capacity** (Space Capacity, number, required): Enter the capacity of the space, if applicable.
* **Renovation Request Date** (Renovation Request Date, date, required): Enter the date of the renovation request, if applicable.
* **Submitted By** (Submitted By, text, required): Enter your name and title, so that the form can be submitted to the correct person.
* **Submitted To** (Submitted To, text, required): Enter the person or department to whom the form should be submitted.
* **Space Location** (Space Location, text, required): Enter the location of the learning space.
* **Space Floor** (Space Floor, text, required): Enter the floor or level of the space.
* **Space Description** (Space Description, text, required): Enter a brief description of the learning space.
* **Notes** (Notes, text, required): Add any additional notes about the renovation request.
* **Submit** (Submit, select_one, required): Select the Submit option to complete the form.
