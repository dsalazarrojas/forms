# Church Graphic Design Request Form - Help Guide

## Purpose
The Church Graphic Design Request Form is used to collect information from requestors to help our design team create effective and efficient graphics for various church projects, events, and events. This form should only be filled out by someone who has been directly requested to provide a graphic design for a specific project.

## How To Complete This Form
To complete this form, please follow the instructions below:

1. Fill out the **Requestor Information** section with your name and contact email.
2. Choose the **Ministry/Department** related to the project.
3. Enter the **Name of Project/Event** and the **Desired Completion Date** for the project.
4. Select all applicable **Types of Design Needed** for the project.
5. Provide information about the **Target Audience** for the project.
6. Enter the **Content/Copy to be Included** for the project.
7. Optionally, provide **Dimensions/Size Requirements** and **Style Preferences or Tone** for the project.
8. Mention if there are any specific **Imagery or Photos to include** with the project.
9. If applicable, enter the **Printing Budget** for the project.
10. If the project is a **RUSH Request (under 7 days)**, select **Yes - Reason provided below** and enter the reason why it's a rush request.
11. Finally, provide any **Additional Notes** for the designer to consider.

## Field-by-Field Explanation

* **Name of Requestor**: Please enter your name as the person requesting the graphic design.
* **Contact Email**: Enter your email address so our team can contact you with any questions or updates.
* **Ministry/Department**: Choose the relevant ministry or department related to the project.
*   **Desired Completion Date**: Enter the date you would like the project to be completed by.
*   **Date of Event (If applicable)**: If the project is for an event, enter the date of the event.
*   **Type of Design Needed**: Select all the types of graphic design that you need for your project.
*   **Who is the target audience?**: Enter who the project is intended for (e.g., parents, church members, unchurched community).
*   **Content/Copy to be Included**: Enter the exact text, dates, times, and location for the project.
*   **Dimensions/Size Requirements**: Enter any specific dimensions or size requirements for the project.
*   **Style Preferences or Tone**: Enter your desired style or tone for the project.
*   **Specific Imagery or Photos to include**: Mention any specific imagery or photos that need to be included.
*   **Printing Budget (if applicable)**: Enter the budget for printing the project (if applicable).
*   **Is this a RUSH Request (under 7 days)**: If the project is a rush request, select **Yes - Reason provided below** and enter a brief explanation.
*   **Any other details for the designer?**: Provide any other relevant details or requests for the designer to consider.

Note: This form is intended to provide all necessary information for a successful project. Please make sure to fill out each field accurately and thoroughly to ensure the best possible outcome.
