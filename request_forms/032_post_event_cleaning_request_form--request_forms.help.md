# post_event_cleaning_request_form - Help Guide
## Purpose
This form is designed to collect information from event organizers or coordinators regarding their post-event cleaning needs and preferences.

## How To Complete This Form

To complete this form, follow these steps:

*   Fill out the form completely and accurately.
*   Choose your preferred day and time for the cleaning service.
*   Select the services you require after the event.
*   Provide a brief description of the services you need.
*   Add any additional notes or comments about the event.

## Field-by-Field Explanation

*   **Event Details** (`event_details`, text, optional): This field is for providing any additional details about the event, such as event name, location, or date.
*   **Preferred Cleaning Time** (`preferred_cleaning_time`, select_one, optional): This field allows you to select the preferred time for the cleaning service. The options are:
    - 8am-10am
    - 10am-12pm
    - 12pm-2pm
    - 2pm-4pm
    - 4pm-6pm
    - 6pm-8pm
    - 8pm-10pm
    - 10pm-12am
*   **Preferred Day** (`preferred_day`, select_one, required): This field is for selecting the preferred day for the cleaning service. The options are:
    - Monday
    - Tuesday
    - Wednesday
    - Thursday
    - Friday
    - Saturday
    - Sunday
*   **Contact Person** (`contact_person`, text, optional): This field is for providing contact information for the person responsible for coordinating the cleaning service.
*   **Contact Details** (`contact_details`, text, optional): This field is for providing additional contact information, such as phone number or email.
*   **Service Needs** (`service_needs`, select_multiple, required): This field allows you to select the services you require after the event. The options are:
    - Cleaning
    - Supplies
    - Equipment
    - Trash Removal
*   **Service Needs Description** (`service_needs_description`, text, required): This field is for providing a brief description of the services you require.
*   **Event Description** (`event_description`, note, optional): This field is for providing a brief description of the event.
*   **Event Notes** (`event_notes`, note, optional): This field is for adding any additional notes or comments about the event.
*   **Notes** (`notes`, note, optional): This field is for adding any additional notes or comments about the form completion process or any other related information.

## Tips

*   Please ensure that the form is filled out completely and accurately.
*   If you need to make changes to your request, please contact the event management team.
*   The cleaning service will be scheduled based on the information provided in this form.
