# Audio Cable Replacement Request Form - Help Guide
## Purpose
This form is designed to help you request a replacement for your audio cable. Please fill out this form with accurate and detailed information to help us process your request efficiently.

## How To Complete This Form
- Fill out all the required fields.
- If you need to describe your issue in more detail, use the "Additional Issue Details" field.

## Field-by-Field Explanation
### Customer and Order Information
* **-- Customer and Order Information --** (`customer_info_section`, `note`, not required) 
  - This section is a note field for you to provide any additional information about your order and yourself.

### Customer Name
* **Full Name** (`customer_name`, `text`, required) 
  - Please enter your full name as it appears on your identification.

### Original Order Number
* **Original Order Number** (`original_order_number`, `text`, required) 
  - Please enter the order number found on your receipt or confirmation email.

### Approximate Purchase Date
* **Approximate Purchase Date** (`purchase_date`, `date`, not required) 
  - If you can provide an approximate date when you purchased the cable, this will help us locate your order in our system.

### Cable Issue Details
* **-- Cable Issue Details --** (`cable_details_section`, `note`, not required) 
  - This section is a note field for you to provide any additional information about the issue with your cable.

### Cable Type
* **Cable Type** (`cable_type`, `select_one`, required) 
  - Please select the type of cable you are experiencing issues with:
    - XLR Microphone Cable
    - TRS Instrument Cable
    - HDMI Video Cable
    - Speaker Cable
    - USB Audio Cable
    - Other

### Cable Length
* **Cable Length** (`cable_length`, `text`, required) 
  - Please provide the length of the cable you are experiencing issues with (e.g., 3ft, 10ft, 25ft).

### Description of the Problem
* **Description of the Problem** (`issue_description`, `select_one`, required) 
  - Please select the description of the issue you are experiencing:
    - No signal/Silent
    - Intermittent signal
    - Physical damage (fraying/cut)
    - Connector broken/bent
    - Static or noise

### Additional Issue Details
* **Additional Issue Details** (`issue_details_text`, `text`, not required) 
  - If there is anything else you would like to tell us about the issue, please use this field to describe it.

### Equipment Used with
* **Equipment used with this cable** (`device_used_with`, `text`, not required) 
  - If you can provide the name of the equipment you were using the cable with, this will help us locate the issue.

### Shipping Address
* **Full Shipping Address** (`shipping_address`, `text`, required) 
  - Please enter your full shipping address (Street, City, State, ZIP).

### Email Address
* **Email Address** (`contact_email`, `email`, required) 
  - Please enter your email address for shipping updates.

### Photo Confirmation
* **I can provide photos of the damage if requested** (`photo_confirmation`, `select_one`, required) 
  - Please let us know if you can provide photos of the issue with the cable if requested. 

### Tips
- Please be as detailed as possible when describing the issue with your cable. 
- If you have any additional questions or concerns, please reach out to us.
