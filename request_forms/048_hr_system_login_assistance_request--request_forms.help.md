# HR System Login Assistance Request - Help Guide
## Purpose
The HR System Login Assistance Request form is designed to assist employees or HR representatives in reporting issues or requests related to the HR System. This form helps HR personnel identify and resolve these issues efficiently.

## How To Complete This Form
To complete this form, follow these steps:

1. Describe the issue or problem you are experiencing with the HR System.
2. Provide the employee's name, email address, and ID number (if applicable).
3. Specify the urgency of the issue (High, Medium, or Low).
4. Select the category of the issue (HR, IT, or Payroll).
5. Add any additional details about the issue.
6. If the issue has already been resolved, select 'Yes' or 'No'.

## Field-by-Field Explanation
* **Issue description**: A clear and concise description of the issue or problem you are experiencing with the HR System. 
* **Employee name**: The name of the employee who is experiencing the issue.
* **Employee email**: The email address associated with the employee's HR System account.
* **Employee ID**: The employee's ID number (if applicable).
* **Issue urgency**: Indicate how urgent the issue is for the employee. High indicates an immediate solution is needed, while Low indicates the issue is not time-sensitive.
* **Issue type**: Select the category of the issue (HR, IT, or Payroll).
* **Issue details**: Additional details or information about the issue, including any steps taken to resolve it.
* **Employee phone**: The employee's phone number (not required, but useful if further communication is needed).
* **Issue solved**: If the issue has already been resolved, select 'Yes'. Otherwise, select 'No' to indicate that the issue is still pending.
* **Issue comments**: Any additional comments or information about the issue that may be helpful for HR to resolve it efficiently.
