# NGO Data Sharing Request Form - Help Guide
## Purpose
The NGO Data Sharing Request Form is a form used to collect information from non-profit organizations (NGOs) that request to access data from our platform. This form helps to track and manage these requests in a centralized manner, ensuring that all requests are reviewed and processed efficiently.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out your Non-Profit Organization name and purpose in the "Non-Profit Organization" and "Purpose" fields, respectively.
2. Check the "Data Access Request" field to indicate whether you are requesting access to data or not.
3. In the "Policy Agreement" field, select "Yes" to confirm that you have read and agree to our data sharing policies.
4. Select "Yes" or "No" in the "Data Sharing Terms" field to indicate whether you agree to the data sharing terms.
5. Check the "Request Review" field to indicate whether you want the request to be reviewed by our team.
6. Select the status of your request as "Active" or "Inactive" in the "Request Status" field.
7. Enter the name of the user assigned to handle your request in the "Assigned User" field.
8. Enter the dates for "Request Creation Date" and "Last Updated Date" using the date picker.

## Field-by-Field Explanation
* **Non-Profit Organization** (`non_profit`): Enter the name of your non-profit organization.
* **Purpose** (`purpose`): Describe the purpose of your data request.
* **Data Access Request** (`data_access_request`): Check this field to indicate whether you are requesting access to data or not. If you select "Yes", we will review your request and process it accordingly.
* **Policy Agreement** (`policy_agreement`): Select "Yes" to confirm that you have read and agree to our data sharing policies.
* **Data Sharing Terms** (`data_sharing_terms`): Select "Yes" or "No" to indicate whether you agree to the data sharing terms.
* **Non-Profit Data Sharing Policies** (`non_profit_data_sharing_policies`): Enter any additional policies or agreements related to data sharing that apply to your organization.
* **Data Sharing Terms** (`data_sharing_terms`): Select "Yes" or "No" to indicate whether you agree to the data sharing terms.
* **Request Review** (`request_review`): Check this field to indicate whether you want the request to be reviewed by our team.
* **Request Status** (`request_status`): Select the status of your request as "Active" or "Inactive".
* **Assigned User** (`assigned_user`): Enter the name of the user assigned to handle your request.
* **Request Creation Date** (`request_creation_date`): Enter the date when your request was created using the date picker.
* **Last Updated Date** (`last_updated_date`): Enter the date when your request was last updated using the date picker.
* **Form ID** (`form_id`): This is a system-generated field that displays the unique ID of your request form.
