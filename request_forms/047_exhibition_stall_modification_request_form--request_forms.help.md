# Exhibition Stall Modification Request Form - Help Guide
## Purpose
The exhibition stall modification request form is used to request changes to allocated exhibition stalls.

## How To Complete This Form

To complete this form, follow these steps:

1. Fill in the exhibitor name.
2. Fill in the stall number.
3. Choose the request type (Modification, Cancellation, or Swap).
4. Enter the request date.
5. Upload any supporting files.
6. Enter the preferred start date.
7. Enter the preferred end date.
8. Choose the priority level.
9. Add any additional comments.
10. Enter the email address of the exhibitor.
11. Enter the phone number of the exhibitor.
12. Choose who the request should be assigned to.
13. Choose the current status of the request.

## Field-by-Field Explanation

* **Exhibitor Name** (`exhibitor_name`, text, required): Enter the name of the exhibitor making the request.
* **Stall Number** (`stall_number`, number, required): Enter the number of the stall being modified.
* **Request Type** (`request_type`, select_one, required): Choose the type of modification requested (Modification, Cancellation, or Swap).
* **Request Date** (`request_date`, date, required): Enter the date on which the modification is being requested.
* **File Upload** (`file_upload`, text, optional): Upload supporting documents or files related to the request.
* **Preferred Start Date** (`preferred_start_date`, date, optional): Enter the date on which the exhibitor would like their stall to be modified.
* **Preferred End Date** (`preferred_end_date`, date, optional): Enter the date on which the exhibitor would like their stall to be closed.
* **Priority** (`priority`, select_one, required): Choose the priority level of the modification request (High, Medium, or Low).
* **Notes** (`notes`, note, optional): Provide any additional comments or details regarding the modification request.
* **Email** (`email`, email, optional): Enter the email address of the exhibitor making the request.
* **Phone** (`phone`, text, optional): Enter the phone number of the exhibitor making the request.
* **Assigned To** (`assigned_to`, select_one, required): Choose who the request should be assigned to.
* **Status** (`status`, select_multiple, required): Choose the current status of the request (Requested, Pending, Approved, Rejected, Assigned, or Closed).
