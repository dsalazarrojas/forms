# HR Review Request Form - Help Guide
## Purpose
The HR Review Request Form is a tool used to request reviews for new or existing employee projects. It allows employees and managers to provide necessary information for the review process, ensuring timely and accurate reviews.

## How To Complete This Form
To complete this form, please follow these steps:

1. Select "Yes" or "No" to indicate whether you are requesting a review.
2. Enter the name of your manager.
3. Enter the name of the employee involved.
4. Select the department related to the review.
5. Provide details about the concern or issue that needs to be addressed.
6. Upload any relevant supporting documents.
7. Enter the routing information, including any relevant dates or details.
8. Select a date for when the review is due.
9. Select a date for when the review is completed.

## Field-by-Field Explanation

* **Review Request** (`review_request_form`): Indicate whether you are requesting a review (Yes or No).
* **Manager Name** (`manager_name`): Enter the name of your manager.
* **Employee Name** (`employee_name`): Enter the name of the employee involved.
* **Department** (`department`): Select the department related to the review.
* **Concern Details** (`concern_details`): Provide details about the concern or issue that needs to be addressed.
* **Supporting Documents** (`supporting_documents`): Upload any relevant supporting documents.
* **Routing Information** (`routing_info`): Enter any relevant dates or details for the review process.
* **Review Due Date** (`review_due_date`): Select a date for when the review is due.
* **Completed** (`review_completed`): Select a date for when the review is completed.
