# Junk Removal Request Form - Help Guide
## Purpose
The Junk Removal Request Form is used to submit a request for the removal of unwanted items, ensuring that the process is properly documented and assigned to the correct personnel for efficient processing and disposal.

## How To Complete This Form
To complete this form, follow these steps:

1. Provide your First Name, Last Name, and Contact Number.
2. Enter your Email address to facilitate communication.
3. Specify the type of junk you are requesting to be removed (e.g. trash, debris, etc.).
4. Provide a brief description of the junk you are requesting to be removed.
5. Select a preferred date and time for the removal.
6. Add any additional notes or comments regarding the removal (optional).
7. Assign the request to a specific personnel for action (e.g. maintenance staff, waste management team, etc.).

## Field-by-Field Explanation

* **First Name** (`first_name`, text, required): Enter your first name as it appears on your identification.
* **Last Name** (`last_name`, text, required): Enter your last name as it appears on your identification.
* **Address** (`address`, text, required): Enter the address of the location where the junk is to be removed from.
* **Contact Number** (`contact_number`, text, required): Enter a contact number where you can be reached for further inquiries.
* **Email** (`email`, email, required): Enter your email address for communication purposes.
* **What type of junk is being removed?** (`junk_type`, text, required): Specify the type of junk you are requesting to be removed (e.g. trash, debris, etc.).
* **Briefly describe the junk** (`junk_description`, text, required): Provide a clear and concise description of the junk you are requesting to be removed.
* **Preferred date and time for removal** (`preferred_date`, date, required): Select a specific date and time for the removal.
* **Additional notes** (`additional_notes`, text, optional): Add any additional comments or notes regarding the removal.
* **Assigned To** (`assigned_to`, text, required): Assign the request to a specific personnel for action (e.g. maintenance staff, waste management team, etc.).
