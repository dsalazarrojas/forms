# Treasury Role Delegation Request Form - Help Guide
## Purpose
This form is used to request delegation of a treasury role to another user. This includes tasks such as managing financial data, granting access to specific accounts, and other related responsibilities.

## How To Complete This Form
To complete this form, follow the steps below:

1. Review the form and ensure that you are requesting delegation for the correct role.
2. Fill out the fields below with the required information.

## Field-by-Field Explanation
* **Delegation Request** (`page_1`, text, required): This field is for the main body of your delegation request. Be clear and concise in your request, including details such as the role you are requesting to be delegated and the reasons for the delegation.
* **Delegated User** (`delegated_user`, select_one, required): Select 'Yes' to delegate the role to another user.
* **Delegated User Email** (`delegated_user_email`, email, optional): Enter the email of the user you are requesting to delegate the role to. This is not required but recommended.
* **Delegated User Phone** (`delegated_user_phone`, text, optional): Enter the phone number of the user you are requesting to delegate the role to. This is not required but recommended.
* **Delegated User Date** (`delegated_user_date`, date, optional): Enter the date when you want the role to be delegated to. This is not required but recommended.
* **Reason for Delegation** (`reason_for_delegation`, text, optional): Provide a clear explanation for why you are requesting delegation of this role.
* **Notes** (`notes`, note, optional): Add any additional comments or information you would like to include with your delegation request.
* **Submitter** (`submitter`, text, required): This is the name of the person submitting the request.
* **Submitter Email** (`submitter_email`, email, optional): Enter the email of the person submitting the request. This is not required but recommended.
* **Submitter Phone** (`submitter_phone`, text, optional): Enter the phone number of the person submitting the request. This is not required but recommended.
* **Submitter Date** (`submitter_date`, date, optional): Enter the date when the request was submitted. This is not required but recommended.
* **Form Completed By** (`form_completed_by`, select_one, optional): Select 'Yes' if this form was completed by the submitter.
* **Form Reviewed By** (`form_reviewed_by`, select_one, optional): Select 'Yes' if this form has been reviewed by someone else.
* **Form Approved By** (`form_approved_by`, select_one, optional): Select 'Yes' if this form was approved by someone else.
* **Form Declined By** (`form_declined_by`, select_one, optional): Select 'Yes' if this form was declined by someone else.
* **Form Comments** (`form_comments`, text, optional): Add any comments or feedback about the form submission and outcome.
