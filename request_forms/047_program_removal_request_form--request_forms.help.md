### Program Removal Request Form - Help Guide

#### Purpose

This form is designed to request the removal of a program. The purpose of this form is to gather information for the removal process, ensuring that all necessary details are collected to facilitate a smooth transition.

#### How To Complete This Form

1.  **Program Name**: Enter the name of the program you wish to remove.
2.  **Reason for Removal**: Provide a clear and concise reason for the removal request.
3.  **Alternative Program**: If an alternative program is available, enter its name.
4.  **Comments**: Add any additional comments or notes for the removal process.
5.  **Program ID**: Enter the ID of the program to be removed.
6.  **Submitter**: Enter your name.
7.  **Submitter Email**: Enter your email address.
8.  **Submitter Phone**: Enter your phone number (optional).
9.  **Department**: Check 'Yes' if the removal request is related to a departmental process, otherwise, check 'No'.
10. **Division**: Select all divisions related to the removal request.
11.  **Date Submitted**: Enter the date you submitted the request.
12.  **Date Removal**: Enter the desired date for the program to be removed.
13.  **Time Removal**: Enter the time for the program to be removed (if desired).
14.  **Removal Status**: Select 'Active' to indicate the removal process is ongoing, 'Inactive' if it's already completed.
15.  **Assigned User**: Select 'Yes' if a specific user is assigned to the removal process.
16.  **Comments**: Add any additional comments for the assigned user.
