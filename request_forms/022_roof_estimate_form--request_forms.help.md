# Roof Estimate Form - Help Guide
## Purpose
This form is used to collect and store estimates for roof projects. It captures essential details such as project name, client information, estimate date, estimate time, estimate total, and other relevant details to ensure accurate and thorough estimates.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the required fields as accurately as possible, including:
	* Project Name
	* Address
	* Estimate Date
	* Estimate Time
	* Estimate Total
	* Roof Type
	* Square Feet
	* Number of Roofs
	* Total Roofs
	* Roof Condition
	* Payment Terms
	* Roof Condition
	* Additional Notes
	* Contractor Name
	* Contact Number
2. Select relevant options for:
	* Project Type (Residential, Commercial, Industrial)
	* Project Status (Active, In Progress, Complete)
	* Review Status (Not Reviewed, Reviewed, Approved, Rejected)
	* Roof Type (Flat, Gable, Hip, Shed)
	* Roof Condition (New, Like New, Used, Fair, Poor)
3. If required fields are not filled, the form will not be submitted.
4. Click submit to send the form for review and update.

## Field-by-Field Explanation
* **Project Name** (`project_name`, text, required): Enter a brief name for the project.
* **Client Name** (`client_name`, text, optional): Enter the name of the client.
* **Address** (`address`, text, required): Enter the address where the project is located.
* **Project Type** (`project_type`, select_one, optional): Choose the type of project (Residential, Commercial, Industrial).
* **Estimate Date** (`estimate_date`, date, required): Enter the date of the estimate.
* **Estimate Time** (`estimate_time`, time, required): Enter the estimated time for the project.
* **Estimate Total** (`estimate_total`, number, required): Enter the total estimate for the project.
* **Project Status** (`project_status`, select_one, required): Choose the status of the project (Active, In Progress, Complete).
* **Contractor Name** (`contractor_name`, text, required): Enter the name of the contractor.
* **Contact Number** (`contact_number`, text, required): Enter the contact number of the contractor.
* **Email Address** (`email_address`, email, optional): Enter the email address of the contractor.
* **Project Notes** (`project_notes`, text, optional): Enter any additional project notes.
* **Payment Terms** (`payment_terms`, text, required): Enter the payment terms for the project.
* **Roof Type** (`roof_type`, select_one, required): Choose the type of roof (Flat, Gable, Hip, Shed).
* **Square Feet** (`square_feet`, number, required): Enter the square feet of the roof.
* **Number of Roofs** (`number_of_roofs`, number, required): Enter the number of roofs.
* **Total Roofs** (`total_roofs`, number, required): Enter the total number of roofs.
* **Roof Condition** (`roof_condition`, select_one, required): Choose the condition of the roof (New, Like New, Used, Fair, Poor).
* **Estimate Details** (`estimate_details`, text, optional): Enter any additional details about the estimate.
* **Additional Notes** (`additional_notes`, text, required): Enter any additional notes about the project.
* **Review Status** (`review_status`, select_one, optional): Choose the review status of the project (Not Reviewed, Reviewed, Approved, Rejected).
* **Last Updated** (`last_updated`, date, optional): The date the form was last updated.
* **Updated By** (`updated_by`, text, optional): The person who last updated the form.
* **Created By** (`created_by`, text, optional): The person who created the form.
* **Created On** (`created_on`, date, optional): The date the form was created.
* **Tips**: Please ensure that all required fields are filled before submitting the form.
