# Sound Design Enhancement Request Form - Help Guide
## Purpose
The Sound Design Enhancement Request Form is used to gather project-related information for sound design enhancements and improvements.
## How To Complete This Form
To fill out the form, follow the steps below:

- Click on the "Submit" button to begin.
- Review each field carefully and enter the required information.
- Ensure that you fill in all the required fields before submitting the form.

## Field-by-Field Explanation

* **Project Details** (`Project Details`, text, required): This field is used to describe the project in a few words.
* **Project References** (`Project References`, note, optional): Use this field to provide any relevant project references that are not already included in the project name.
* **Required References (optional)** (`Required References (optional)`, text, optional): This field is used to provide additional references that are not already included in the project name.
* **Required References URL** (`Required References URL`, text, optional): Provide the URL of the reference.
* **Required References Type** (`Required References Type`, select_one, optional): Select the type of the reference.
* **Project Priorities** (`Project Priorities`, select_multiple, optional): Select all the priorities of the project that apply.
* **Sound Design Requirements** (`Sound Design Requirements`, text, optional): Describe the sound design requirements for the project.
* **Sound Design Requirements Description** (`Sound Design Requirements Description`, text, optional): Provide a detailed description of the sound design requirements.
* **Sound Design Requirements URL** (`Sound Design Requirements URL`, text, optional): Provide the URL of the sound design requirements.
* **Audio File Requirements** (`Audio File Requirements`, text, optional): Describe the audio file requirements for the project.
* **Audio File Requirements URL** (`Audio File Requirements URL`, text, optional): Provide the URL of the audio file requirements.
* **Priority** (`Priority`, select_one, optional): Select the priority of the project.
* **Deadline** (`Deadline`, date, optional): Enter the deadline for the project.
* **Deadline Notes** (`Deadline Notes`, note, optional): Provide any notes about the deadline.
* **Project Status** (`Project Status`, select_one, optional): Select the status of the project.
* **Project Status Description** (`Project Status Description`, text, optional): Describe the status of the project.
* **Project Status URL** (`Project Status URL`, text, optional): Provide the URL of the project status.
* **Project Status Type** (`Project Status Type`, select_one, optional): Select the type of the project status.
* **Notes** (`Notes`, text, optional): Provide any additional notes about the project.
* **Notes URL** (`Notes URL`, text, optional): Provide the URL of the notes.
* **Notes Type** (`Notes Type`, select_one, optional): Select the type of the notes.
* **Project Manager** (`Project Manager`, text, optional): Enter the name of the project manager.
* **Project Manager URL** (`Project Manager URL`, text, optional): Provide the URL of the project manager.
* **Project Manager Type** (`Project Manager Type`, select_one, optional): Select the type of the project manager.
* **Submission Status** (`Submission Status`, select_one, optional): Select the status of the submission.

This help guide is intended to be used by end-users of the Sound Design Enhancement Request Form. It is essential to follow the instructions provided carefully to ensure that the form is filled out correctly and efficiently.
