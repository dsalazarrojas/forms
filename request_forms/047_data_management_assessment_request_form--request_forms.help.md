# Data Management Assessment Request Form - Help Guide
## Purpose
The Data Management Assessment Request Form is used to submit a request for data management services. It helps the data management team understand the organization's data goals, challenges, and requirements to provide the necessary support and resources.

## How To Complete This Form
To complete this form, follow these steps:

* Fill out the form with accurate and detailed information about your organization's data management needs.
* Make sure to fill out all required fields.
* Review your submission before submitting to ensure that all information is correct.

## Field-by-Field Explanation
* **Organization Name (Text, Optional)**: This field is where you enter the name of your organization.
* **Data Challengers (Select Multiple, Optional)**: Check the box if you have data challengers, or leave blank if not applicable.
* **Data Goal (Text, Optional)**: Describe the data goal or objective of your request.
* **Data Challenge Description (Text, Optional)**: Provide a detailed description of the data challenge you are facing.
* **Priority (Select One, Optional)**: Choose the priority level of your request (High, Medium, Low).
* **Deadline (Date, Optional)**: Enter the deadline for the completion of the request (in YYYY-MM-DD format).
* **Submitter (Text, Optional)**: Enter the name of the person submitting the request.

Note: This help guide is intended to provide a general overview of the form and its fields. The actual fields and their requirements may be subject to change. If you have any questions or need further clarification, please reach out to the data management team.
