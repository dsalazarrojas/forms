# Hotel RFP Form Template - Help Guide

## Purpose
The purpose of this form is to gather information about a Request for Proposal (RFP) from a hotel. The form is designed to collect contact and project details, status updates, and other relevant information related to the RFP.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the contact name and email address of the person or company submitting the RFP.
2. Provide the name of the company associated with the RFP.
3. Enter the due date and start/end date for the RFP, if applicable.
4. Select the type of RFP (e.g., Sales, Marketing, Operations).
5. Enter the status of the RFP (e.g., Draft, In Progress, Completed, Cancelled).
6. Enter any additional RFP details.
7. Select any attachments related to the RFP (e.g., images, documents, videos).
8. Add any comments or notes about the RFP.

## Field-by-Field Explanation

* **Form** (Text, **1**, Required: No): Enter a brief description of the RFP.
* **Contact** (Text, **2**, Required: No): Enter the name of the person or company submitting the RFP.
* **Company** (Text, **3**, Required: No): Enter the name of the company associated with the RFP.
* **Email** (Email, **4**, Required: No): Enter the email address of the contact person.
* **Phone** (Text, **5**, Required: No): Enter the phone number of the contact person.
* **RFP Details** (Text, **6**, Required: No): Enter any additional information about the RFP.
* **Status** (Select One, **7**, Required: No): Select the current status of the RFP (Draft, In Progress, Completed, Cancelled).
* **Type** (Select Multiple, **8**, Required: No): Select the type of RFP (e.g., Sales, Marketing, Operations, Other).
* **Due Date** (Date, **9**, Required: No): Enter the due date for the RFP, if applicable.
* **Start Date** (Date, **10**, Required: No): Enter the start date for the RFP, if applicable.
* **End Date** (Date, **11**, Required: No): Enter the end date for the RFP, if applicable.
* **Address** (Text, **12**, Required: No): Enter the address associated with the RFP.
* **City** (Text, **13**, Required: No): Enter the city associated with the RFP.
* **State** (Text, **14**, Required: No): Enter the state associated with the RFP.
* **Zip** (Text, **15**, Required: No): Enter the zip code associated with the RFP.
* **Notes** (Note, **16**, Required: No): Enter any additional comments or notes about the RFP.
* **Comments** (Text, **17**, Required: No): Enter any additional comments about the RFP.
* **Attachments** (Select Multiple, **18**, Required: No): Select any attachments related to the RFP (e.g., images, documents, videos).

**Tips:**

* Make sure to fill out all the required fields accurately and thoroughly.
* Attach relevant files to provide additional context to the RFP.
* Keep the form up-to-date and reflect any changes in the status or due dates of the RFP.
