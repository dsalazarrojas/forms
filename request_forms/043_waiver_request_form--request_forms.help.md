# Waiver Request Form - Help Guide
## Purpose
The Waiver Request Form is used to request a waiver for a specific construction project. It is required to provide detailed information about the project, waiver number, date, and approver information to ensure that the waiver is processed correctly.

## How To Complete This Form
To complete this form, follow these steps:

1. Provide the Construction Project Information (Page 1). This page requires you to enter the details about the project you are requesting a waiver for.
2. Enter the Waiver Information (Page 2). This page asks for the waiver number and date, which is necessary for processing the waiver request.
3. Choose the Approver Information (Page 3 and 4). Select the approver(s) who will sign the waiver.
4. Enter the Waiver Number, Waiver Date, Waiver Signed By, and (optionally) Waiver Signed Date and Time (Pages 5-8). These fields are required for finalizing the waiver request.
5. Add any comments if necessary (Page 9). This is an optional field for providing additional context about the waiver request.

## Field-by-Field Explanation
* **Construction Project Information** (Page 1):
	+ **Construction Project Name** (required): Enter the name of the construction project you are requesting a waiver for.
* **Waiver Information** (Page 2):
	+ **Waiver Number** (required): Enter the waiver number associated with the project.
	+ **Waiver Date** (required): Enter the date of the waiver.
* **Approver Information** (Page 3):
	+ **Approver 1** (required): Select the primary approver for the waiver.
* **Approver 2 Information** (Page 4):
	+ **Approver 2** (required): Select additional approver(s) for the waiver.
* **Waiver Number** (Page 5):
	+ **Waiver Number** (required): Re-enter the waiver number for verification.
* **Waiver Date** (Page 6):
	+ **Waiver Date** (required): Re-enter the waiver date for verification.
* **Waiver Signed By** (Page 7):
	+ **Waiver Signed By** (required): Enter the name of the person signing the waiver.
* **Waiver Signed Date** (Page 8):
	+ **Waiver Signed Date** (optional): Enter the date the waiver was signed (if applicable).
* **Waiver Signed Time** (Page 8):
	+ **Waiver Signed Time** (optional): Enter the time the waiver was signed (if applicable).
* **Comments** (Page 9):
	+ **Comments** (optional): Add any additional comments about the waiver request.
