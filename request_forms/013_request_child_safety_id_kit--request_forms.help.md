# Request Child Safety ID Kit - Help Guide

## Purpose
This form is designed to collect information and documentation required for the safety and well-being of a child.

## How To Complete This Form
To complete this form, follow these steps:

* Fill in the required fields, marked as "true" in the schema, accurately and thoroughly.
* For fields with options, select the most relevant and accurate choice.
* Ensure that all fields with the "Required" label are filled out.
* Double-check your submission for accuracy before submitting.

## Field-by-Field Explanation

* **Request Form**: This is the main section where you can provide any additional information about the situation or concern.
* **Name**: This field is used to identify the child's name. Please fill in the child's full name.
* **School Name**: This field is used to identify the school the child attends. Please enter the school's name.
* **Program Type**: This field is used to categorize the child's program or activity. Please select the most relevant option from the list.
* **Address**: This field is used to provide the child's current address. Please enter the accurate address.
* **Email**: This field is used to provide the child's email address. Please ensure it is a valid email address.
* **Phone**: This field is used to provide the child's contact phone number. Please enter the accurate phone number.
* **Consent**: This field is used to confirm that you have the authority to submit this form on behalf of the child. Please mark 'True' if you have the necessary permissions.
* **Submitter Signature**: This field is used to sign the form digitally. Please provide your signature in the format of a date.
* **Submitter Name**: This field is used to identify the person submitting the form. Please enter your full name.
* **Submitter Email**: This field is used to identify the submitter's email address. Please ensure it is a valid email address.
* **Submitter Phone**: This field is used to provide the submitter's phone number. Please enter the accurate phone number.
* **Form Submitted**: This field is used to record the timestamp of the form submission.
* **Submitter IP**: This field is used to track the submitter's IP address. Please note that this field is not used in the actual processing.
* **Form Submitted By**: This field is used to identify who submitted the form. Please select the most relevant option.
* **User Agent**: This field is used to describe the user's role or position. Please enter a brief description.
* **Request ID**: This field is used to identify the unique ID of the form submission. Please enter a unique ID.
* **Form Language**: This field is used to set the language of the form. Please select the most relevant option.
* **Request Date**: This field is used to record the date of the form submission. Please enter the accurate date.
* **Submitter Country**: This field is used to identify the submitter's country. Please select the most relevant option.
* **Submitter Timezone**: This field is used to set the submitter's time zone. Please select the most relevant option.
* **User Country**: This field is used to identify the user's country. Please select the most relevant option.
* **User Timezone**: This field is used to set the user's time zone. Please select the most relevant option.
* **IP Address**: This field is used to track the IP address of the user. Please enter the accurate IP address.
* **Form ID**: This field is used to identify the unique ID of the form submission. Please enter a unique ID.

Note: If you need more information or have specific questions, please refer to the relevant authorities or support team.
