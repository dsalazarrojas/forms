# Minimalist Request Form - Help Guide
## Purpose
The Minimalist Request Form is a simple form designed to collect basic information for a request. It is not intended for collecting sensitive or personal data.

## How To Complete This Form
To complete this form, simply fill out the fields with the required information and submit it. You can skip any fields that are not relevant to your request.

## Field-by-Field Explanation
- **First Name** (`First Name`, text, optional): This field is used to collect your name.
- **Email** (`Email`, email, optional): This field is used to collect your email address.
- **Phone** (`Phone`, text, optional): This field is used to collect your phone number.
- **Request Type** (`Request Type`, select_one, optional): Please select one of the options to indicate the type of request you are making.
  - Yes or No: Select Yes if you are making a general request, No if you are not.
- **Request Priority** (`Request Priority`, select_one, optional): Please select one of the options to indicate the priority of your request.
  - Low, Medium, High: Select the priority of your request.
- **Description** (`Description`, text, optional): This field is used to provide more details about your request.
- **Assigned To** (`Assigned To`, select_one, optional): Please select one of the options to indicate who the request should be assigned to.
  - Yes or No: Select Yes if you want the request to be assigned to someone, No if you don't.
- **Status** (`Status`, select_one, optional): Please select one of the options to indicate the status of your request.
  - Active or Inactive: Select Active if your request is active, Inactive if it's not.
- **Due Date** (`Due Date`, date, optional): This field is used to collect the due date for your request.
- **Due Time** (`Due Time`, time, optional): This field is used to collect the due time for your request.
- **Request Date** (`Request Date`, date, optional): This field is used to collect the date when your request was submitted.
- **Request Time** (`Request Time`, time, optional): This field is used to collect the time when your request was submitted.
- **Notes** (`Notes`, note, optional): This field is used to collect any additional information about your request.
- **Form ID** (`Form ID`, text, optional): This field is used to collect a unique identifier for your request.
- **Created By** (`Created By`, text, optional): This field is used to collect the name of the person who created your request.
- **Assigned To** (`Assigned To`, select_one, optional): Please select one of the options to indicate who the request should be assigned to.
  - Yes or No: Select Yes if you want the request to be assigned to someone, No if you don't.

  - Active or Inactive: Select Active if your request is active, Inactive if it's not.
