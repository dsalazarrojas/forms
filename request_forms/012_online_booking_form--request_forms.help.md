# Online Booking Form - Help Guide
## Purpose
This form collects information for online bookings, including pickup location, travel dates and times, contact information, and other relevant details.

## How To Complete This Form
To complete this form, follow the instructions below:

* Select the relevant fields to fill out, using the labels and hints as a guide.
* For fields with a label like "Document A", "Document B", and "Document C", select the appropriate option from the dropdown list.
* For fields with labels like "Pickup Date" and "Reservation Date", enter the date in the correct format (yyyy-mm-dd).
* For fields with labels like "Pickup Time" and "Reservation Time", enter the time in the format (hh:mm).
* For fields like "Contact Number" and "Travel Agency Phone", enter the phone number in the international format (e.g. +1-123-456-7890).
* For fields like "Email Address" and "Travel Agency Email", enter the email address in the standard format (e.g. john.doe@example.com).
* For fields like "Latitude" and "Longitude", enter the geographic coordinates in decimal format (e.g. 37.7749, -122.4192).
* For fields like "Notes" and "Reservation Notes", enter any additional information you'd like to add about your booking.

* **Pickup Location**: Enter the location where you would like to be picked up.
* **Pickup Date**: Enter the date you would like to be picked up.
* **Pickup Time**: Enter the time you would like to be picked up.
* **Suggestion Area**: Enter any suggestions or comments you have for your pickup location.

* **Pickup Details**: Enter any additional details about your pickup preferences.
* **Tour Details**: Enter any additional details about your tour preferences.
