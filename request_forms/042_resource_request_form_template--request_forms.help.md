# Resource Request Form Template - Help Guide
## Purpose
The Resource Request Form Template is a tool used to submit requests for resources, such as equipment, software, or personnel. This form helps employees to efficiently and effectively communicate their needs to the relevant teams or departments.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the required fields with the necessary information.
2. Provide as much detail as possible in the comments field if you need to elaborate on your request.
3. Review your information for accuracy before submitting the form.

## Field-by-Field Explanation

* **Resource Request Form Template** (text, required): This is the title of the form, which should be filled out with a brief description of the resource requested.
* **Employee Name** (text, optional): Please enter your name, or the name of the person submitting the request.
* **Project Name** (text, optional): If this request is related to a specific project, enter the project name.
* **Resource Name** (text, optional): Enter the name of the resource being requested.
* **Quantity** (number, optional): If applicable, enter the quantity of the resource needed.
* **Unit Price** (number, optional): Enter the unit price of the resource, if applicable.
* **Request Date** (date, optional): Enter the date when the request was made.
* **Start Date** (date, optional): If applicable, enter the start date of the resource usage.
* **End Date** (date, optional): If applicable, enter the end date of the resource usage.
* **Status** (select_one, optional): Choose from the following options: approved, denied, pending.
* **Comments** (note, optional): If you need to provide additional information or context, use this field to elaborate on your request.
* **Email** (email, optional): Enter your contact email, in case the request requires further communication.
* **Phone** (text, optional): Enter your contact phone number.
* **Department** (select_one, optional): Choose from the following departments: IT, Marketing, Sales.
* **Team** (select_multiple, optional): Select the team(s) that will be using the resource.
* **Assigned to** (text, optional): If applicable, enter the name of the person assigned to handle the request.
* **Assigned Tool** (text, optional): If applicable, enter the name of the tool assigned for the request.
