# String Replacement Request Form - Help Guide

## Purpose
This form is used to track and manage string replacement requests. It allows users to submit a new request for string replacement, which can be for a website, application, or documentation. The form captures essential details about the request, including the request type, description, priority, and due date. This information helps the team to efficiently process and address the requests.

## How To Complete This Form

1.  Select the type of request (Website, App, or Documentation) you are submitting.
2.  Provide a detailed description of the string you would like to be replaced.
3.  If necessary, add any clarification or additional information about the request.
4.  Specify the priority of the request (Low, Medium, or High) to help the team prioritize the work.
5.  Choose a due date for the request if you want it to be completed by a specific time.
6.  If the request is assigned to someone, select 'Yes' to indicate that it is assigned.
7.  Update the status of the request as it moves through the process (Pending, In Progress, Completed).
8.  Select the status of the request (Open, Closed, In Progress) to reflect its current state.

## Field-by-Field Explanation

- **Form Data** (`form_data`, `Text`, required): This field is where you provide detailed information about the string replacement request.
- **Request Type** (`request_type`, `Select One`, required): Choose the type of request (Website, App, or Documentation) that this form is for.
- **Website URL** (`website_url`, `Text`, optional): If this is a request for a website, provide the URL of the site.
- **Description** (`description`, `Text`, required): Write a detailed description of the string you would like to replace.
- **Clarification** (`clarification`, `Text`, optional): Add any additional information or clarification about the request, if needed.
- **Request Status** (`request_status`, `Select Multiple`, required): Select the current status of the request (Pending, In Progress, Completed).
- **Assigned To** (`assigned_to`, `Select One`, required): If this request is assigned to someone, select 'Yes' to indicate that.
- **Created At** (`created_at`, `Date`, optional): This field shows the date the request was created.
- **Updated At** (`updated_at`, `Date`, optional): This field shows the last time the request was updated.
- **Closed At** (`closed_at`, `Date`, optional): This field shows the date the request was closed.
- **Comments** (`comments`, `Text`, optional): Add any comments or notes about the request.
- **Priority** (`priority`, `Select One`, required): Specify the priority of the request (Low, Medium, or High).
- **Due Date** (`due_date`, `Date`, optional): If you want to set a due date for the request, select it here.
- **Requestor** (`requestor`, `Text`, optional): This field is for your information and is not required.
- **Status** (`status`, `Select One`, required): Select the current status of the request (Open, Closed, In Progress).

Please follow these tips to help us process your request efficiently:

* Make sure to provide all necessary information to ensure we understand your request correctly.
* Be as specific as possible when describing the string you would like to replace.
* Set a realistic due date, if applicable.
* Update the status of the request as it moves through the process.

This form is designed to help you submit and manage string replacement requests effectively. If you have any questions or need further clarification, please don't hesitate to ask.
