## Animation Dialogue Sync Request Form - Help Guide
## Purpose
This form is used to request synchronization of animation dialogue for a project, ensuring that the animation and audio are perfectly synchronized to create a seamless viewing experience. The form will be used to gather all the necessary information to start the synchronization process.

## How To Complete This Form
To complete this form, follow these steps:
1. Fill in the required fields, marked with an asterisk (*). 
2. Select the correct options for each field, based on your project's needs.
3. Double-check your entries for accuracy and completeness.
4. Submit the form once you have filled out all the necessary fields.

## Field-by-Field Explanation
* **Project Title** (`sync_project_title`, text, required): Enter the title of your project. This will help identify your project and ensure that our team can find the corresponding files.
* **Client or Studio Name** (`sync_studio_name`, text, required): Enter the name of your client or studio. This will help us track who the project belongs to.
* **Dialogue Language** (`dialogue_language_selection`, select_one, required): Select the language for which the animation is being created. Options: English, Spanish, Japanese, French, German, or Other.
* **Total Audio File Duration - Seconds** (`audio_duration_seconds`, number, required): Enter the total duration of the audio file in seconds.
* **Number of Characters Speaking** (`character_speaker_count`, number, required): Enter the number of characters speaking in the animation.
* **Sync Requirement Level** (`sync_requirement_level_type`, select_one, required): Select the level of synchronization required:
	+ Phonetic Lip-Sync - High detail
	+ Body Performance Sync Only
	+ Full Performance and Facial Capture
* **Is a Script Provided?** (`script_provided_status`, select_one, required): Select whether a script is provided:
	+ Yes - Uploaded
	+ No - Not provided
	+ Pending - Not yet finalized
* **Desired Animation Frame Rate** (`animation_fps_preference`, select_one, required): Select the desired frame rate for the animation. Options: 24 fps - Standard Film, 30 fps - TV/Video, 60 fps - High Smoothness.
* **File Delivery Format** (`file_delivery_format_choice`, select_one, required): Select the format in which you want to receive the files. Options: FBX - Filmbox, ABC - Alembic, MP4 Preview Only, Maya Project File.
* **Target Delivery Deadline** (`sync_target_deadline`, date, required): Enter the deadline for the final delivery of the files.
* **Special Animation or Sync Instructions** (`special_sync_instructions`, text, optional): Enter any additional information or specific character emotional cues or pacing instructions. (Optional)

## Tips
* Double-check your entries for accuracy and completeness before submitting the form.
* Ensure that all required fields are filled out correctly to avoid delays in the synchronization process.
* If you have any questions or concerns, please contact our animation team.
