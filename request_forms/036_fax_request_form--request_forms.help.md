# fax_request_form - Help Guide
## Purpose
This form is intended to collect user information for fax requests.

## How To Complete This Form
To complete this form, follow these steps:
* Fill in the required and optional fields as specified below.

## Field-by-Field Explanation
* **User (1)** (`User`, text, required: false): Enter your name and contact information.
* **Fax Number (2)** (`Fax Number`, text, required: false): Provide the number to which the fax should be sent.
* **Fax Type (3)** (`Fax`, select_one, required: false): Choose the type of fax you require (Fax, Voice, or Call).
* **Fax Date (4)** (`Fax Date`, date, required: false): Select the date for the fax transmission.
* **Fax Time (5)** (`Fax Time`, time, required: false): Choose the time for the fax transmission.

## Tips
* Be sure to fill in all required fields, but feel free to leave optional fields blank if not applicable.
* Double-check your entries before submitting the form to ensure accuracy.
* If you have any questions or concerns, please contact your administrator.
