# Municipal Tree Service Contact Request - Help Guide
## Purpose
This form is used to request municipal tree service for trees in the area.

## How To Complete This Form
To submit a tree service request, follow these steps:

1. Enter the address where the tree service is needed.
2. Describe the issue with the tree in the "Description" field.
3. Enter your contact name and email address so we can follow up with you about the request.
4. Enter your phone number in the "Contact Phone" field.
5. Select the type of service requested (e.g. Tree Trimming, Removal, etc.).
6. Add any additional details you think are relevant to the request.
7. Attach a photo or video of the tree issue, if available.
8. Submit the form to send in your request.

## Field-by-Field Explanation

* **Request for Tree Service (1)** (`Request for Tree Service`, Text, **Required**): Enter a brief description of why you are requesting tree service.
* **Address (2)** (`Address`, Text, **Required**): Enter the address where the tree service is needed.
* **Contact Name (4)** (`Contact Name`, Text, **Required**): Enter your name or the name of the person responsible for the property.
* **Contact Email (5)** (`Contact Email`, Email, **Required**): Enter your email address where we can follow up with you about the request.
* **Contact Phone (6)** (`Contact Phone`, Text, **Required**): Enter your phone number where we can contact you about the request.
* **Tree Problem (7)** (`Tree Problem`, Text, **Required**): Describe the issue with the tree.
* **Photo or Video (8)** (`Photo or Video`, Text, **Required**): Attach a photo or video of the tree issue, if available.
* **Request Date (9)** (`Request Date`, Date, **Required**): Enter the date of when the tree problem occurred or is expected to occur.
* **Service Requested (10)** (`Service Requested`, Select One, **Required**): Select the type of service needed (e.g. Tree Trimming, Removal, etc.).
* **Additional Details (11)** (`Additional Details`, Text, **Optional**): Add any additional information about the tree issue.
* **Submit (12)** (`Submit`, Text, **Optional**): Click the "Submit" button to send in your request.

Note: Please make sure to fill out all required fields to ensure your request is processed efficiently.
