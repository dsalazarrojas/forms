# marketing_and_design_request_form - Help Guide
## Purpose
The marketing and design request form is used to gather information for new marketing and design requests. This form helps the management team make informed decisions by providing essential details about the project.

## How To Complete This Form
To complete this form, please follow these steps:

* Fill out all required fields, indicated by a asterisk (\*).
* For non-required fields, provide as much detail as possible to help the management team understand your request.
* Make sure to select the correct options for fields with dropdown menus.

## Field-by-Field Explanation
* **Form Request* (1):** Briefly describe the marketing and design request, including the goal and objective.
* **Design Request (2):** Provide specific design requirements and expectations for the project.
* **Project Details (3):** Include any relevant project details, such as the project name, description, or any specific requirements.
* **Target Audience (4):** Specify the target audience for the project, including demographics and location.
* **Marketing Channels (5):** Indicate which marketing channels will be used for the project, such as social media, email, or print media.
* **Marketing Budget (6):** Provide an estimate of the marketing budget for the project.
* **Deadline Date (7):** Enter the date by which the project needs to be completed.
* **Deadline Time (8):** Enter the time by which the project needs to be completed.
* **Assigned Manager (9):** Select the management team member(s) you would like to be responsible for the project. Please note that this is not a guarantee of assignment. The management team will review and assign the project accordingly.

## Tips
* Make sure to proofread your submission for grammar and spelling errors before submitting.
* If you are unsure about any field or have further questions, please don't hesitate to reach out to the management team.
* This form is for new marketing and design requests only. If you have an existing project or ongoing task, please don't submit this form again.
