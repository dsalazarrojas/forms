# rise_tribe_rr_form - Help Guide
## Purpose
The rise_tribe_rr_form is designed to capture information about a request related to a "Rise Tribe" initiative. This form helps gather specific details about the request, such as category, title, description, and various selection fields for context and categorization.

## How To Complete This Form

1. Begin by filling out the required fields:
	* Request Form: Enter a brief description of your request.
	* Category: Select the relevant category for your request.
	* Title: Enter a title that summarizes your request.
	* Tags: Select any relevant tags to further categorize your request.
2. Proceed to fill out the optional fields:
	* Description: Provide a more detailed description of your request.
	* Phone Number: Select whether you want to include your phone number for follow-up.
	* Email: Enter your email address for follow-up communication.
	* Cami Choice: Select your Cami preference.
	* Demi Choice: Select your Demi preference.
	* Cami Type: Select your Cami type preference.
	* Demi Type: Select your Demi type preference.
	* Cami Size: Select your Cami size preference.
	* Demi Size: Select your Demi size preference.
	* Cami Color: Select your Cami color preference.
	* Demi Color: Select your Demi color preference.
	* Cami Style: Select your Cami style preference.
	* Demi Style: Select your Demi style preference.
	* Tags Input: Select any additional relevant tags.
	* Tags 2: Select any additional relevant tags.
	* Tags 3: Select any additional relevant tags.
3. Review your filled-out form before submitting to ensure you have completed all relevant fields.
