# Lareddeingenieria - Help Guide
## Purpose
The Lareddeingenieria form is designed to collect project request information for further processing and evaluation. 

## How To Complete This Form
To complete this form, follow these steps:
1. Select the "Request Form" page.
2. Fill in the requested information, providing as much detail as possible.

## Field-by-Field Explanation
- **Request Form** (`1`, `text`, optional): This is the main page of the form, where you can provide a brief description of your request.
- **Project Name** (`2`, `text`, optional): Enter the name of the project you are requesting.
- **Project Description** (`3`, `text`, optional): Add a detailed description of the project, including any relevant context or background information.
- **Contact Name** (`4`, `text`, optional): Enter your name or the name of the person responsible for the contact.
- **Contact Phone** (`5`, `text`, optional): Provide your contact phone number or the contact's phone number.
- **Contact Email** (`6`, `email`, optional): Enter your email address or the contact's email address.
- **Project Deadline** (`7`, `date`, optional): Enter the project deadline date.
- **Project Start Date** (`8`, `date`, optional): Enter the project start date.
- **Project Location** (`9`, `text`, optional): Enter the location associated with the project.
- **Contact Address** (`10`, `text`, optional): Enter the contact's or your address.
- **Project Status** (`11`, `select_one`, optional): Choose the status of the project (Active or Inactive).

## Tips
- Please be as detailed as possible when filling out the form.
- If a field is not required, you can leave it blank or fill it in if you have relevant information.
- Make sure to double-check the form before submission to ensure accuracy.
