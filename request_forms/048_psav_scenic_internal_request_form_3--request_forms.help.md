# Psav Scenic Internal Request Form 3 - Help Guide
## Purpose
This form is used for submitting internal requests for scenic installations to support events on site.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the type of event you are requesting scenic installation for (e.g. Event, Meeting, Wedding, or Other).
2. Enter the date of the event.
3. If applicable, enter the date for facility booking and installation.
4. Provide the location for the scenic installation.
5. Add any additional notes about the installation location.
6. Specify the contact person's details.
7. Enter the contact person's email address.
8. Enter the contact person's phone number.
9. Add any additional notes for the site manager.

## Field-by-Field Explanation

### Event Type (1)
* **Event Type**: Select the type of event you are requesting scenic installation for. Choose from: Event, Meeting, Wedding, or Other.

### Event Date (2)
* **Event Date**: Enter the date of the event. This should be a standard date in the format YYYY-MM-DD.

### Facility Booking Date (3)
* **Facility Booking Date**: If you are booking a facility for the event, enter the date when the facility will be booked. (Only if Event Date is different from Facility Booking Date)

### Facility Install Date (4)
* **Facility Install Date**: Enter the date when the scenic facility needs to be installed. (Only if Facility Booking Date is different from Facility Install Date)

### Install Site Location (5)
* **Install Site Location**: Provide the location for the scenic installation.

### Install Location Note (6)
* **Install Location Note**: Add any additional notes about the installation location.

### Install Location Note (7)
* **Install Location Note**: This field is redundant. Please do not complete it. It seems to be a duplicate field. 

### Contact Person (8)
* **Contact Person**: Specify the person who will be in charge of the installation.

### Contact Email (9)
* **Contact Email**: Enter the contact person's email address.

### Contact Phone (10)
* **Contact Phone**: Enter the contact person's phone number.

### Site Manager Note (12)
* **Site Manager Note**: Add any additional notes for the site manager.

Please note that **Install Location Note** and **Install Location Note** fields are duplicates and should not be filled.
