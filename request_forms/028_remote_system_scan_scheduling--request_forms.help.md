# Remote System Scan Scheduling - Help Guide
## Purpose
This form is used to schedule a remote system scan for a specific system. Please fill out the form accurately to ensure the scan is scheduled correctly.

## How To Complete This Form
1. Select the first page by scrolling down or clicking on the page number.
2. Fill out the form with the necessary information, paying attention to required fields.
3. Review the information before submitting the form.

## Field-by-Field Explanation
* **Scan Request Details** (id: 2, text, required: false)
	+ This field is used to enter any additional details about the scan request.
* **Scan Type** (id: 3, select_one, required: false)
	+ Select the type of scan you require.
* **Schedule Time** (id: 4, time, required: false)
	+ Enter the time you want the scan to take place.
* **Schedule Date** (id: 5, date, required: true)
	+ Enter the date you want the scan to take place.
* **End Date** (id: 6, date, required: true)
	+ Enter the end date of the scan.
* **End Time** (id: 7, time, required: false)
	+ Enter the end time of the scan.
* **Schedule Duration** (id: 8, number, required: false)
	+ Enter the duration of the scan in minutes.
* **Time Slot** (id: 9, select_multiple, required: false)
	+ Select the time slot for the scan.
* **Scan Location** (id: 10, text, required: false)
	+ Enter the location of the system to be scanned.
* **Scan Frequency** (id: 11, select_one, required: false)
	+ Select the frequency of the scan (e.g., daily, weekly, etc.).
* **Notes** (id: 12, note, required: false)
	+ Enter any additional notes or comments about the scan.
* **Email** (id: 13, email, required: false)
	+ Enter the email address of the team lead or manager.
* **Phone** (id: 14, text, required: false)
	+ Enter the phone number of the team lead or manager.
* **Team Members** (id: 15, text, required: false)
	+ List the team members involved in the scan.
* **Team Lead** (id: 16, text, required: false)
	+ Enter the name of the team lead.
* **Manager Name** (id: 17, text, required: false)
	+ Enter the name of the manager.
* **Manager Email** (id: 18, email, required: false)
	+ Enter the email address of the manager.
* **Manager Phone** (id: 19, text, required: false)

* **Manager Team** (id: 20, text, required: false)

* **Scan Requestor** (id: 21, text, required: true)

* **Scan Request Status** (id: 22, select_multiple, required: false)

* **Scan Type Status** (id: 23, select_one, required: false)

* **Time Zone Offset** (id: 25, text, required: false)
