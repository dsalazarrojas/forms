# Event Recording Form - Help Guide
## Purpose
The Event Recording Form is designed to capture information about events, making it easier to record and reference details such as event title, description, date, time, location, and start time.

## How To Complete This Form
To complete this form, simply follow these steps:

* Fill in the event title and description in the respective text fields.
* Select the event date in the date field. This will format the date in the mm/dd/yyyy format.
* Select the event start and end time in the time fields. These fields are formatted in the 12-hour clock format (e.g., 01:00 PM).
* Enter the event location in the text field.
* Optionally, if the event start time is different from the general event time, you can specify it separately in the start time field.

## Field-by-Field Explanation
* **Event Title** (`event_title`, text, required): Enter the title of the event, a brief and descriptive name that represents the event.
* **Description** (`description`, text, required): Provide a short description of the event, explaining what it's about and what attendees can expect.
* **Event Date** (`event_date`, date, required): Enter the date of the event in the mm/dd/yyyy format (e.g., 02/27/2024).
* **Event Time** (`event_time`, time, required): Choose the time of the event, formatted in the 12-hour clock format (e.g., 01:00 PM).
* **Event Location** (`event_location`, text, optional): Enter the location of the event, including address, venue, or venue's name if necessary.
* **Start Time** (`event_start_time`, time, optional): If the start time is different from the general event time, enter it separately in the format 12-hour clock (e.g., 10:00 AM). 

## Tips
* Ensure that all fields with an asterisk (\*) are marked as required to ensure your submission is complete and valid.
* If unsure about any field, refer to the form title or contact form@gic.mx for clarification.
* This form is intended for internal use, if you're planning to use it publicly, please adjust your submission accordingly.
