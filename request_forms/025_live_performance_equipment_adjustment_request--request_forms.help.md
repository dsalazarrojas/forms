# Live Performance Equipment Adjustment Request - Help Guide
## Purpose
This form is used to request adjustments or changes to live performance equipment, such as sound or lighting systems. Please fill out this form to submit your request for approval.

## How To Complete This Form
To fill out this form, follow these steps:

1. Enter the title of your request in the "Live Performance Equipment Adjustment Request" field.
2. Select the category of your request from the "Category" dropdown menu.
3. Provide a brief description of your request in the "Description" field.
4. Select the venue where the request is being made from the "Venue" dropdown menu.
5. Enter the date and time you are requesting the adjustment or change.
6. Select the person who requested the equipment from the "Requester" dropdown menu.
7. Enter any additional information or notes regarding your request in the "Equipment Request Note" field.
8. Select the status of your request from the "AV Request Status" dropdown menu.
9. Set the priority of your request from the "AV Request Priority" dropdown menu.
10. Enter the date you are requesting the change from the "AV Request Date" field.
11. Enter the time you are requesting the change from the "Equipment Request Time" field.
