# Telecommunications Router Requisition Form - Help Guide
## Purpose
The Telecommunications Router Requisition Form is used to request the purchase of a new telecommunications router from the IT Department. This form is intended for internal staff members to submit their requests for new routers, allowing the IT Department to review and process the requests in a structured manner. Please make sure to fill out this form accurately and completely to ensure a smooth and efficient processing of your request.

## How To Complete This Form
To complete this form, follow these steps:

* Start by selecting the type of router you need from the dropdown list.
* Enter the quantity of routers you require.
* Fill in the location where the router will be used.
* Provide the name and department of the contact person associated with this request.
* Add any additional comments or notes if necessary.
* Choose the department that will approve this request.
* Select the date you would like to submit this request.
* If applicable, select the date you would like to purchase the router.
* Finally, choose the status of the request (e.g., Pending, Approved, Rejected, Cancelled).

## Field-by-Field Explanation
* **Router Type** (`router_type`, select_one): Choose the type of router you need from the list (e.g., Cisco, Huawei, Other).
* **Quantity** (`quantity`, number): Enter the number of routers you require.
* **Location** (`location`, text): Fill in the location where the router will be used (e.g., office, department, server room).
* **Contact Person** (`contact_person`, text): Provide the name and department of the contact person associated with this request.
* **Department** (`department`, text): Enter the department of the contact person (e.g., IT, Marketing, Sales).
* **Comments** (`comments`, note): Add any additional comments or notes if necessary.
* **Router Model** (`router_model`, text): If you need a specific router model, fill it in here.
* **Approved By** (`approved_by`, select_one): Choose the department that will approve this request (e.g., IT Department, Operations).
* **Request Date** (`request_date`, date): Select the date you would like to submit this request.
* **Purchase Date** (`purchase_date`, date): If applicable, select the date you would like to purchase the router.
* **Router Status** (`router_status`, select_one): Choose the status of the request (e.g., Pending, Approved, Rejected, Cancelled).
