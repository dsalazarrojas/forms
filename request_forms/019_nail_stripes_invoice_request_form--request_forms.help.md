# nail_stripes_invoice_request_form - Help Guide
## Purpose
The nail_stripes_invoice_request_form is a comprehensive form used to collect information for an invoice for nail services. It helps to create a detailed report for the customer's order.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the **Order Number**, which is a unique identifier for the customer's order.
2. Enter the **Order Date**, which is the date the order was placed.
3. Enter the **Customer Name**, which is the name of the person who placed the order.
4. Enter the **Email**, which is the customer's email address.
5. Enter the **Phone**, which is the customer's phone number.
6. Select the **Stripe Color**, which is the color of the nail striping service.
7. Select the **Stripe Pattern**, which is the pattern of the nail striping service. Note: This field is optional.
8. Select the **Stripe Type**, which is the type of nail service being ordered.
9. Enter any **Order Comments**, which are any additional comments or notes about the order.
10. Enter any **Customer Comments**, which are any additional comments or notes from the customer.
11. Select whether the **Invoice Was Sent To** the customer, which is a confirmation of invoice delivery.
12. Enter the **Invoice Date**, which is the date the invoice was sent to the customer.
13. Select whether to **Invoice Address** the customer, which is a confirmation of invoice delivery address.
14. Select the **Payment Method**, which is the method of payment used for the order.
15. Select the **Payment Status**, which is the status of the payment for the order.
16. Enter the **Payment Date**, which is the date of the payment for the order.
17. Enter the **Total Price**, which is the total price of the order.
18. Enter the **Stripe Price**, which is an optional price for the stripe service. Note: This field is optional.
19. Enter the **Tax Amount**, which is an optional tax amount for the order. Note: This field is optional.
20. Enter the **Discount Price**, which is an optional discount price for the order. Note: This field is optional.
21. Enter the **Shipping Address**, which is the address where the order will be shipped to.
22. Select the **Shipping Method**, which is the method of shipping used for the order.
23. Enter the **Shipping Price**, which is the price of shipping for the order.
24. Enter any additional **Note**, which is an optional note for the customer.
