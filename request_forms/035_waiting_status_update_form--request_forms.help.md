# Waiting Status Update Form - Help Guide
## Purpose
The "Waiting Status Update Form" is used to update the status of waiting requests, providing essential information to assigned users and follow-up contacts.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the type of request you are updating (Request Type).
2. Choose the current status of the request (Request Status).
3. Select the user who will be responsible for following up on the request (Follow Up User).
4. Optionally, provide detailed follow-up information in the "Follow Up Details" field.
5. Enter the date and time of the update (Update Date and Time).
6. Provide the phone number or email of the person to contact for follow-up (Follow Up Contact).
7. Choose the user who is currently assigned to the request (Assigned User).
8. Enter any additional notes or comments (Notes).
9. (Optional) Enter the email address of the follow-up user (Follow Up User E-mail).
10. (Optional) Enter the name of the follow-up user (Follow Up User Name).

## Field-by-Field Explanation
* **Request Type** (required): Choose the type of request you are updating (Ticket, Order, or Application).
* **Request Status** (required): Select the current status of the request (Open, Closed, or Waiting).
* **Follow Up User** (required): Select the user who will be responsible for following up on the request (User A, User B, or User C).
* **Follow Up Details** (optional): Provide detailed follow-up information.
* **Update Date** (optional): Enter the date of the update.
* **Update Time** (optional): Enter the time of the update.
* **Follow Up Contact** (optional): Enter the phone number or email of the person to contact for follow-up.
* **Assigned User** (required): Choose the user who is currently assigned to the request (User A, User B, or User C).
* **Notes** (optional): Enter any additional notes or comments.
* **E-mail** (optional): Enter the email address of the follow-up user.
* **Follow Up User Name** (optional): Enter the name of the follow-up user.
* **Follow Up User E-mail** (optional): Enter the email address of the follow-up user.
* **Update Status** (optional): Enter the text description of the updated status.
