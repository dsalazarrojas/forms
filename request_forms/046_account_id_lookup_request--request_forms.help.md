# Account ID Lookup Request - Help Guide
## Purpose
This form is used to request an account ID, ensuring that the requester provides necessary information to facilitate a quick and accurate search. It helps to avoid duplicate searches and unnecessary efforts.

## How To Complete This Form
1. Fill in all required fields with accurate and complete information.
2. Be specific about the urgency level and reason for the request.
3. Clearly indicate what type of account you are searching for and any previous search results.
4. Specify the sensitivity level of the data involved and any compliance requirements.
5. Check if approval is needed for this request.

## Field-by-Field Explanation

* **Requester Name** (`requester_name`, required, text): Enter your full name to be identified as the requester.
* **Requester Email** (`requester_email`, required, email): Enter your email address to ensure we can contact you back.
* **Requester Department** (`requester_department`, required, text): Specify your department for reference and identification.
* **Requester Phone** (`requester_phone`, required, text): Provide your phone number to be reached for further questions or details.
* **Request Date** (`request_date`, required, date): Specify the date of the request to plan and prioritize our search efforts.
* **Urgency Level** (`urgency_level`, required, select_one): Choose the level of urgency (Low, Medium, High, Critical).
* **Lookup Reason** (`lookup_reason`, required, select_one): Select a reason for the lookup (Customer service, Technical issue, Billing inquiry, Account verification, Security review, Audit requirement, Other).
* **Customer Identifier** (`customer_identifier`, required, text): Enter information to identify the customer (choose one or more).
* **Customer Identifier Type** (`customer_identifier_type`, required, select_one): Specify the type of customer identifier (Name, Email, Phone number, Address, Order number, Transaction ID, Previous account number, Other).
* **Alternative Identifiers** (`alternative_identifiers`, optional, text): Provide any other information that might help with the search.
* **Account Type Searched** (`account_type_searched`, required, select_one): Specify the type of account being searched for (Customer account, Vendor account, Employee account, Partner account, Other).
* **System Searched** (`system_searched`, required, text): Indicate which system you have already searched.
* **Previous Search Results** (`previous_search_results`, required, text): Provide details on any previous search results.
* **Business Impact** (`business_impact`, required, text): Specify the business impact of not finding this account ID.
* **Requested Resolution Date** (`requested_resolution_date`, required, date): Enter the date when you need the information.
* **Additional Context** (`additional_context`, optional, text): Provide any additional context to help with the search.
* **Data Classification** (`data_classification`, required, select_one): Choose the sensitivity level of the data involved (Public, Internal, Confidential, Highly Confidential).
* **Compliance Requirements** (`compliance_requirements`, required, select_multiple): Select any compliance requirements (GDPR, HIPAA, SOX, PCI DSS, None, Other).
* **Approval Needed** (`approval_needed`, required, select_one): Check if this request requires additional approval (No, Manager approval, Security approval, Executive approval).
* **Additional Comments** (`additional_comments`, optional, text): Enter any other information about your request.

Note: This guide is designed to be concrete, concise, and practical, aiming to help requesters complete the form accurately and correctly. If you are unsure about any field or its purpose, please ask for clarification.
