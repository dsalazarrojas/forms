# Tool Request Form - Help Guide
## Purpose
The Tool Request Form is used to request a specific tool for a particular job or task. To complete this form, you need to provide accurate information about the job and the tool required.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the required fields marked with an * (asterisk). The fields that are required to be filled in are:
	* Job Number
	* Job Type
	* Assigned Tool
2. Select the relevant options for the job type and tool type.
3. If applicable, specify the quantity of tools required.
4. Provide a brief description of the tool needed.
5. If necessary, add any comments or additional information.
6. Indicate who is requesting the tool.

## Field-by-Field Explanation

* **Job Number**: Enter the unique number of the job for which you are requesting the tool. This helps the tool team track the tool's association with the job.
* **Job Type**: Choose the type of job for which you are requesting the tool. This is usually related to the type of work or task involved.
* **Tool Type**: Select all the types of tools required for the job. This helps the tool team understand what tools are needed.
* **Quantity**: If you need more than one tool, specify the quantity here.
* **Description**: Provide a brief description of the tool you are requesting. This helps the tool team understand what the tool is and what it is used for.
* **Assigned Tool**: Select the person or team member who will be using the tool. This ensures the correct person gets the tool.
* **Comments**: If you have any additional information or context about the tool request, add it here.
* **Requested By**: Indicate who is requesting the tool. This is usually the person submitting the request or the person on behalf of the requester.

## Tips
* Make sure to enter accurate and complete information to ensure the tool team can process your request efficiently.
* If you are unsure about any of the fields, ask the tool team for guidance or clarification.
* Review your request before submitting to ensure it is complete and accurate.
