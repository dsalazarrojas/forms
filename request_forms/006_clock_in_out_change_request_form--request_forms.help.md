# Clock In Out Change Request Form - Help Guide
## Purpose
The Clock In Out Change Request Form is used to request changes to employee clock-in or clock-out times. This form should be used to correct errors or discrepancies in time records.

## How To Complete This Form
1. Enter your employee name as listed in the payroll system.
2. Enter your employee ID.
3. Select your department or team.
4. Provide details about the change request, if necessary.
5. Specify the type of change request (e.g., correction to clock in time, missing clock out time, etc.).
6. Select the date of the shift for which the change request applies.
7. If necessary, enter the original and corrected clock-in and clock-out times.
8. If necessary, enter the time difference in minutes.
9. Explain the reason for the change request.
10. If necessary, provide a detailed explanation.
11. Specify your supervisor's name and email address.
12. Confirm whether your supervisor has pre-approved this change request.
13. Select the date of the request.
14. If necessary, provide any supporting documentation.
15. Confirm the accuracy and completeness of the information provided.

## Field-by-Field Explanation

* **Employee Name**: Your full name as listed in the payroll system. This is a required field.
* **Employee ID**: Your employee identification number. This is a required field.
* **Department**: Your department or team. This is a required field.
* **-- Change Request Details --**: If you need to provide additional information about the change request, enter it here.
* **Type of Change Request**: Select the type of change request you are making (e.g., correction to clock in time, missing clock out time, etc.). This is a required field.
* **Date of the Shift**: Select the date of the shift for which the change request applies. This is a required field.
* **-- Original and Corrected Times --**: If you need to provide original and corrected clock-in and clock-out times, enter them here.
* **Original Clock In Time**: If necessary, enter the original clock-in time that needs to be corrected.
* **Corrected Clock In Time**: If necessary, enter the corrected clock-in time.
* **Original Clock Out Time**: If necessary, enter the original clock-out time that needs to be corrected.
* **Corrected Clock Out Time**: If necessary, enter the corrected clock-out time.
* **Total Time Difference in Minutes**: If necessary, enter the total time difference in minutes.
* **-- Reason for Change --**: Explain the reason for the change request.
* **Reason for this Change Request**: Select the reason for the change request (e.g., system error, forgot to clock, equipment issue, etc.). This is a required field.
* **Detailed Explanation**: Provide a detailed explanation for the change request, if necessary.
* **-- Approval Information --**: If you need to provide additional information, enter it here.
* **Supervisor Name**: Enter your supervisor's name.
* **Supervisor Email**: Enter your supervisor's email address. This is required for verification and approval.
* **Has your supervisor pre-approved this change**: Confirm whether your supervisor has pre-approved this change request.
* **Request Date**: Enter the current date.
* **Any supporting documentation**: If you need to provide supporting documentation, enter it here.
* **I confirm this information is accurate and complete**: Confirm that the information provided is accurate and complete.
