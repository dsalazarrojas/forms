# Creative Project Request Form - Help Guide

## Purpose
This form is designed to collect information about your creative project needs and preferences. It will help us understand your project goals, requirements, and constraints, allowing us to better serve you and deliver exceptional results.

## How To Complete This Form
To complete this form, follow these steps:

1. Provide your point of contact name, email, and phone number.
2. Enter the project's title and a brief description.
3. Choose the type of project you are requesting.
4. Enter the project manager's name, phone number, email, and company.
5. Specify the project budget.
6. If applicable, provide project location, start and end dates, and deadline.
7. Optionally, add project graphics research and notes.
8. Select the contact method(s) for future communication.

## Field-by-Field Explanation

* **Point of Contact Name** (`point_of_contact_name`): Your name, which will be used as a reference point for communication and project management.
* **Point of Contact Email** (`point_of_contact_email`): Your email address, which will be used for sending updates, notifications, and other project-related communications.
* **Point of Contact Phone** (`point_of_contact_phone`): Your phone number, which will be used for phone calls, voicemails, or other direct contact methods.
* **Project Title** (`project_title`): A brief and descriptive title of your project.
* **Project Description** (`project_description`): A short description of your project, including its goals, objectives, and requirements.
* **Project Graphics Research** (`project_graphics_research`): Optional field for providing additional graphics research or reference materials for your project.
* **Type of Project** (`project_type`): Select the type of project you are requesting, which will help us better understand its scope and requirements.
* **Project Manager** (`project_manager`): Enter the name of the project manager responsible for managing and delivering your project.
* **Project Manager Phone** (`project_manager_phone`): Enter the project manager's phone number for direct communication.
* **Project Manager Email** (`project_manager_email`): Enter the project manager's email address for sending updates and notifications.
* **Project Manager Company** (`project_manager_company`): Enter the project manager's company name.
* **Project Budget** (`project_budget`): Enter the project budget, which will be used to understand the financial constraints and requirements.
* **Location** (`project_location`): Enter the project location, if applicable.
* **Project Start Date** (`project_start_date`): Enter the project's start date, if applicable.
* **Project End Date** (`project_end_date`): Enter the project's end date, if applicable.
* **Project Deadline** (`project_deadline`): Enter the project's deadline, if applicable.
* **Project Notes** (`project_notes`): Optional field for providing additional project notes or reference materials.
* **Project Manager Notes** (`project_manager_notes`): Optional field for the project manager to add notes or reference materials.
* **Contact Method** (`contact_method`): Select the contact method(s) you prefer for future communication.
* **Contact Method 2** (`contact_method_2`): Select the secondary contact method, if applicable.
