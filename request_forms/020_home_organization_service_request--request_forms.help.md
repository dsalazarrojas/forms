# Home Organization Service Request - Help Guide
## Purpose
The purpose of this form is to request home organization services. Fill out this form to submit a request for service organization services.

## How To Complete This Form
- Please complete the form in its entirety, ensuring all required fields are filled out.
- Select the correct options for each field, as described below.

## Field-by-Field Explanation
* **Organization Service Request** (`organization_service_request`, text, Optional): Describe your service request in the provided text field.
* **Contact Information** (`contact_information`, select_multiple, Optional):
	+ Select 'Yes' if you have a specific contact method (e.g., phone number or email address) to communicate with you.
	+ Select 'No' if you do not have a contact method.
* **Schedule Appointment** (`schedule_appointment`, date, Optional): Select the date of the service appointment. 
* **Service Type** (`service_type`, select_one, Optional):
	+ Select 'Yes' if you are requesting a service type.
	+ Select 'No' if you are not requesting a service type.
* **Service Date** (`service_date`, date, Optional): Select the date of the service. 
* **Service Time** (`service_time`, time, Optional): Select the time of the service.
* **Notes** (`notes`, note, Optional): Add any additional notes or comments for the service request.
* **Email** (`email`, email, Optional): Enter your email address if you prefer to be contacted via email.
* **Phone** (`phone`, text, Optional): Enter your phone number if you prefer to be contacted via phone.
* **Submit Request** (`submit_request`, text, Optional): Enter your submission or any final request information.
* **Lead Qualifier** (`lead_qualifier`, select_one, Optional):
	+ Select 'Yes' if you are a lead qualifier.
	+ Select 'No' if you are not a lead qualifier.
* **Lead Status** (`lead_status`, select_one, Optional):
	+ Select 'Active' if you are active.
	+ Select 'Inactive' if you are inactive.
* **Assigned Tool** (`assigned_tool`, select_one, Optional):
	+ Select 'Yes' if a tool is assigned to you.
	+ Select 'No' if no tool is assigned to you.
