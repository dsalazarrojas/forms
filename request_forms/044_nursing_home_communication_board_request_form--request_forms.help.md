# Nursing Home Communication Board Request Form - Help Guide

## Purpose
The Nursing Home Communication Board Request Form is used to document a resident's communication requests, concerns, and needs. This form is crucial in ensuring that nursing home staff and administrators are aware of and address these requests in a timely manner.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the required fields as accurately and completely as possible.
2. Select the correct options for the "Request Type", "Facility", and "Resident Relationship" fields.
3. Enter the resident's name and date of service.
4. Add any additional request details.
5. Review and submit the form.

## Field-by-Field Explanation
### Resident Name (`Resident Name`, text, required: false)
The resident's name is the key identifier for this request. Enter the resident's full name as it is known to the staff.

### Date of Service (date, required: false)
Enter the date when the request was made or the date of the event that triggered the request.

### Request Type (select_one, required: false)
Select the type of request being made:
* Option 1: General Concern
* Option 2: Urgent Concern
* Option 3: Special Request

### Phone (text, required: false)
Enter the resident's phone number for follow-up or communication.

### Facility (select_multiple, required: false)
Choose the facility where the resident resides:
* Option 1: Option 1
* Option 2
* Option 3

### Email (email, required: false)
Enter the resident's email address for electronic communication.

### Resident Relationship (select_multiple, required: false)
Select the relationship between the resident and the staff member making the request:
* Option 1: Staff Member
* Option 2: Family Member
* Option 3: Other

### Request Details (text, required: false)
Provide any additional details about the request, concern, or need.

## Tips
* Be as detailed and specific as possible when filling out this form.
* Make sure to check for similar requests on the communication board before submitting this form.
* Follow up on the resident's request as soon as possible.
* Keep the communication board up to date to ensure timely follow-up on resident requests.
