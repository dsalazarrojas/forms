# Process Reengineering Pilot Application Form - Help Guide
## Purpose
This form is designed to gather information for the Process Reengineering Pilot Application Form.

## How To Complete This Form
To complete this form, follow these steps:

1.  Start by reading the form carefully and ensuring that you have all necessary permissions and approvals.
2.  Fill out the Request Form with a brief description of the project.
3.  Enter the Team Lead Info, including the name of the team lead or contact person.
4.  Provide a brief description of the project in the Project Details field.
5.  Explain the business case for the project in the Business Case field.
6.  List the name, position, and role of all team members involved in the project in the Team Details field.
7.  Choose the current project stage (inception, planning, development, deployment, maintenance, or aborted) in the Project Stage field.
8.  Select the type of project (internal or external) in the Project Type field.
9.  Choose the category of the project (IT project, non-IT project, or pilot) in the Project Category field.
10. Enter the location of the project (if applicable) in the Project Location field.
11. Enter the email address of the team lead or contact person in the Team Lead Email field.
12. Enter the name of the contact person in the Contact Person field.
13. Enter the deadline for the project completion in the Project Deadline field.
14. Enter the phone number of the team lead or contact person in the Team Lead Phone field.
15. Enter the project manager's name in the Project Manager field.
16. Enter the project approver's name in the Project Approver field.
17. Choose the type of request (new project, project renewal, project update, or project closure) in the Request Type field.
18. Provide a brief update on the project status in the Project Status Update field.
19. Add any additional project notes in the Project Notes field.
20. Attach any supporting documents in the Project Attachment field.
21. Enter the review status of the project in the Review Status field.
22. Enter the review date in the Review Date field.
23. Enter the name of the reviewer in the Reviewer field.
24. Enter any review comments in the Review Comments field.
