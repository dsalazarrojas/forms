# Project Documentation Access Request Form - Help Guide
## Purpose
The Project Documentation Access Request Form is a tool used to collect information about project documentation access requests. This form is used to gather details about the project being requested, the user's information, and the project access type.

## How To Complete This Form
To complete this form, follow the instructions below:

1. Fill out the form in the order and pages as instructed.
2. Make sure to provide accurate and complete information for each field.
3. Review your answers before submitting the form to ensure that they are correct.

## Field-by-Field Explanation

* **Project Documentation Access Request** (Page 1):
	+ This is the first page of the form where you will enter a general description of the project you are requesting access to.
* **User Information** (Page 1):
	+ This field is for your contact information, including your name and email address.
* **Project Selection** (Page 1):
	+ Select the project you are requesting access to from the list of options.
* **Multiple Projects** (Page 1):
	+ If you are requesting access to multiple projects, select all the relevant projects from the list of options.
* **Date Request Received** (Page 2):
	+ Enter the date you received the request for access.
* **Time Request Received** (Page 2):
	+ Enter the time you received the request for access.
* **Note Request** (Page 2):
	+ Enter any additional notes or comments about your request.
* **Email Requester** (Page 2):
	+ Enter the email address of the person making the request.
* **Phone Requester** (Page 2):
	+ Enter the phone number of the person making the request.
* **Project Access Type** (Page 3):
	+ Select the type of access you are requesting (e.g., "read-only" or "read-write").
* **Multiple Access Types** (Page 3):
	+ If you are requesting multiple types of access, select all the relevant types from the list of options.
* **Date Access Granted** (Page 3):
	+ Enter the date access was granted to you.
* **Time Access Granted** (Page 3):
	+ Enter the time access was granted to you.
* **Note Access** (Page 3):
	+ Enter any additional notes or comments about your access.
* **Email Grantor** (Page 3):
	+ Enter the email address of the person granting access.
* **Phone Grantor** (Page 3):
	+ Enter the phone number of the person granting access.
* **Assignee Information** (Page 4):
	+ Enter any additional information about the person or team being granted access.
* **Select Assignees** (Page 4):
	+ Select the person or team being granted access from the list of options.
* **Multiple Assignees** (Page 4):
	+ If you are granting access to multiple people or teams, select all the relevant teams from the list of options.
* **Date Assigned** (Page 4):
	+ Enter the date the access was granted.
* **Time Assigned** (Page 4):
	+ Enter the time the access was granted.
* **Note Assigned** (Page 4):
	+ Enter any additional notes or comments about the access granted.
* **Email Assignee** (Page 4):
	+ Enter the email address of the person or team being granted access.
* **Phone Assignee** (Page 4):
	+ Enter the phone number of the person or team being granted access.
* **Submit** (Page 5):
	+ Click the "Submit" button to complete and submit the form.

## Tips

* Make sure to review your answers before submitting the form to ensure they are accurate and complete.
* If you have any questions or concerns, please reach out to the person responsible for project documentation.
* This form is designed to be user-friendly and easy to complete. If you have any issues or need assistance, please don't hesitate to contact us.
