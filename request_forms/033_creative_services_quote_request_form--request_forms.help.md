# Creative Services Quote Request Form - Help Guide

## Purpose
The creative services quote request form is designed to gather essential information about your project so that we can provide an accurate quote for the services you're looking for.

## How To Complete This Form
- Start by providing basic project details such as project lead and expected start and end dates.
- Select the services you require from the provided options.
- Enter the expected budget for your project.
- Provide the expected start and end dates for the project.
- Select the project status.
- Fill in the project services quote and any other relevant details.
- Finally, provide the services requester's name and any additional comments.

## Field-by-Field Explanation

* **Project Lead (2)**: Enter the name and contact information of the person responsible for the project.
* **Services Selected (3)**: Select all the services you require for your project. Please review the options carefully and choose the services that best fit your needs.
* **Expected Start Date (4)**: Enter the date when you'd like the project to start. This will help us provide a more accurate quote.
* **Expected End Date (5)**: Enter the date when you expect the project to finish.
* **Project Budget (6)**: Enter the budget allocated for this project. This will help us understand the scope of work required.
* **Services Quote (7)**: Provide any additional comments or requirements for the services you're requesting.
* **Project Status (8)**: Select the current status of your project from the given options.
* **Services Requester (9)**: Enter your name and contact information so we can get back to you with the quote.

By following these steps, you'll be able to submit a complete and accurate quote request for the creative services you need. If you're unsure about any field, please don't hesitate to reach out for clarification.
