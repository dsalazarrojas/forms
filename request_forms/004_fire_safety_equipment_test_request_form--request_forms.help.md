# Fire Safety Equipment Test Request Form - Help Guide
## Purpose
This form is used to request a fire safety equipment test for fire alarms, sprinkler systems, or fire extinguishers. Please fill out this form with accurate and relevant information to ensure that your test request is processed efficiently.

## How To Complete This Form
1. Select the type of fire safety equipment to be tested (e.g. Fire Alarms, Sprinkler System, or Fire Extinguisher).
2. Enter the date you would like the test to take place (mm/dd/yyyy).
3. Enter the time you would like the test to take place (HH:MM AM/PM).
4. Fill in the location where the test will be performed.
5. Provide your contact information so we can reach out to you for any additional questions.
6. Enter your email address so we can notify you about the test results.
7. Add any additional comments or notes about the test request.
8. Select the personnel who will submit and receive the test results (e.g. Jimmy, Sarah, or John).

## Field-by-Field Explanation
* **Alarm Type**: Select one of the following options:
	+ Fire Alarms
	+ Sprinkler System
	+ Fire Extinguisher
* **Test Request Date**: Enter the date you would like the test to take place in the format MM/DD/YYYY.
* **Test Request Time**: Enter the time you would like the test to take place in the format HH:MM AM/PM.
* **Location**: Enter the location where the test will be performed.
* **Contact Info**: Enter your contact information so we can reach out to you for any additional questions.
* **Email**: Enter your email address so we can notify you about the test results.
* **Comments**: Add any additional comments or notes about the test request.
* **Submitted By**: Select the personnel who will submit the test request.
* **Submitted To**: Select the personnel who will receive the test results.

## Tips
* Please make sure to fill out all required fields to ensure that your test request is processed efficiently.
* If you are unsure about any information, please don't hesitate to reach out to the fire safety department.
* This form is only intended for fire safety equipment tests, if you need to request other types of tests, please use the corresponding form.
* Please review your test request carefully before submitting it to ensure that all information is accurate and complete.
