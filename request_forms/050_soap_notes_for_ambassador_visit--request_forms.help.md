# soap_notes_for_ambassador_visit - Help Guide
## Purpose
The purpose of this form is to record information about a visit made by an ambassador to a location.

## How To Complete This Form
To complete this form, please follow these steps:

* Fill out the form in a clear and legible handwriting.
* Ensure that you are providing accurate information in each field.
* Complete all required fields (if any).
* Review the form carefully before submitting it.

## Field-by-Field Explanation
### Visit Date
* **Visit Date** (`visit_date`, `date`, not required): The date on which the ambassador visited the location.

### Visit Time
* **Visit Time** (`visit_time`, `time`, not required): The time at which the ambassador visited the location.

### Ambassador S.S.N
* **Ambassador S.S.N** (`amb_ssns`, `text`, not required): The social security number of the ambassador.

### Visit Duration
* **Visit Duration** (`visit_duration`, `number`, not required): The duration of the visit in minutes.

### Comments
* **Comments** (`comments`, `note`, not required): Any comments or observations about the visit.

### Ambassador Phone Number
* **Ambassador Phone Number** (`amb_phone_number`, `text`, not required): The phone number of the ambassador.

### Email Address
* **Email Address** (`email_address`, `email`, not required): The email address of the ambassador.

## Tips
* Please ensure that you are providing accurate information in each field.
* If you are unsure about any information, please ask the relevant staff member for clarification.
* This form is for recording information about ambassador visits only. If you have any other type of visit, please use a different form.
