# Focus Mode Allowlist Request - Help Guide
## Purpose
This form is used to request focus mode access on a specific site or app.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the frequency of your access request (Daily, Weekly, or Rarely).
2. Provide a brief reason for your request in the "Reason" field.
3. If required by your organization's policies, enter manager and/or IT approvals in the "Manager Approval" and "IT Approval" fields respectively.
4. Indicate whether you need access to a Site, App, or Both.
5. Enter any comments or notes from your manager in the "Manager Comments" field.

## Field-by-Field Explanation
* **Frequency (request_frequency)**: Choose how often you need access to this site or app. Select Daily if you require daily access, Weekly if you need access once a week, or Rarely if you only need access occasionally.
* **Reason (request_reason)**: Provide a brief explanation for your access request. Be as detailed as possible to help the request be processed efficiently.
* **Manager Approval (manager_approval)**: If required, enter your manager's approval code or notes for your access request.
* **IT Approval (it_approval)**: If required, enter your IT approval code or notes for your access request.
* **Site or App (request_site_or_app)**: Indicate whether you need access to a Site, App, or Both.
* **Manager Comments (manager_comment)**: Enter any comments or notes from your manager regarding your access request.
