# Land Survey Records Request Form - Help Guide
## Purpose
This form is designed to collect and document land survey requests from clients or customers.

## How To Complete This Form
To complete this form, follow these steps:

*   Fill in the required fields with accurate and up-to-date information about yourself and the land survey request.
*   If you need to request multiple land surveys, please provide each survey request on a new submission.
*   Once you have filled in all the required fields, click the "Submit Request" button to send the request.

## Field-by-Field Explanation

*   **User Information (1)**: Enter your name and contact information to allow us to contact you regarding your land survey request.
*   **Contact Info (2)**: Provide your contact person's name and phone number so we can reach you to discuss your request.
*   **Land Information (3)**: Enter a detailed description of the land survey request, including property boundaries, coordinates, or any other relevant information about the site.
*   **Request Details (4)**: Explain in detail what you are requesting, including any specific requirements or deadlines.
*   **Request Documents (5)**: If you have any relevant documents or files to attach to your request, upload them here.
*   **Submit Request (6)**: Click this button to send your request to us.
*   **Confirm (7)**: Verify that all the information provided is accurate and up-to-date before submitting the request.
*   **Assigned Tool (8)**: This field is not required and will be filled in by our team once the request is assigned.
*   **Assigned Form ID (9)**: This field is not required and will be filled in by our team once the request is assigned.
*   **Category (10)**: Select the correct category for your land survey request from the dropdown list.
*   **Form Description (11)**: A brief description of the form is not necessary for submission but can be used as reference or documentation.
*   **Output File (12)**: This field will contain the output file name after the request is generated.
*   **Form ID (13)**: This field is not required and will be filled in by our team once the request is assigned.
*   **Output File (14)**: This field will contain the output file name after the request is generated.
*   **Form Category (15)**: This field will contain the category of the land survey request.
*   **Form Title (16)**: This field will contain the title of the land survey request.

Note: This form is designed to be completed in a step-by-step process, and the "Confirm" field is not strictly necessary but is intended to ensure that users double-check their information before submitting.
