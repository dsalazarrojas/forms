# Employee Pay Stub Access Request Form - Help Guide
## Purpose
The Employee Pay Stub Access Request Form is used by employees to request access to their pay stubs for a specific period.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the period for which you are requesting pay stub access using the "Period Selection" field.
2. Indicate your preferred delivery method and address using the "Delivery Preference" and "Delivery Address" fields. If you want to receive your pay stubs via email, please ensure you have provided a valid email address.
3. Enter your preferred method of delivery using the "Delivery Method" field.
4. If necessary, provide any comments or additional information in the "Comments" field.
5. Select the person or team to whom your request should be assigned using the "Assigned to" field.

## Field-by-Field Explanation
* **Period Selection** (`period_selection`, select_one, required/optional): Select the period for which you want to request pay stub access. This field allows you to choose a specific month from the list of options provided.
* **Delivery Preference** (`delivery_preference`, select_multiple, optional): Indicate how often you want to receive pay stubs. Select all the options that apply to you.
* **Period Start Date** (`period_start_date`, date, optional): Enter the date from which you want to request pay stub access.
* **Period End Date** (`period_end_date`, date, optional): Enter the date to which you want to request pay stub access.
* **Delivery Method** (`delivery_method`, select_one, optional): Select how you want to receive your pay stub. Options include email, mail, or in-person pickup.
* **Delivery Address** (`delivery_address`, text, optional): Enter your address if you want to receive your pay stub via mail.
* **Comments** (`comments`, note, optional): Enter any additional comments or information related to your request.
* **Assigned to** (`assigned_to`, select_one, optional): Select which team or person should be assigned to handle your request. Options include Chat, HR, or Payroll Team.
* **Status** (`status`, select_one, optional): Select the status of your request. Options include Pending, In Progress, or Complete.
* **Comments Required** (`comments_required`, select_one, optional): Select if comments are required for your request. Options include True or False.
