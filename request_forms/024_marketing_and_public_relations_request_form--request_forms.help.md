# Marketing And Public Relations Request Form - Help Guide
## Purpose
This form is used to request marketing and public relations support from the company. It's essential to provide accurate and complete information to help us process your request efficiently.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill out the contact details section with your name, company name (if applicable), and email address.
2. Select the type of contact you are (e.g., 'Yes' for a marketing inquiry or 'No' for other types of requests).
3. Provide your company's name and address if you are representing a company.
4. Enter your contact phone number.
5. Indicate the public relation request you are making.
6. Specify the deadline for the request, if applicable.
7. Provide any additional time requests.
8. Briefly describe the event details, if applicable.

## Field-by-Field Explanation
* **Contact Details** (`contact_details`, text, required: false):
	+ Please enter your name, company name (if applicable), and email address.
* **Type Of Contact** (`contact_type`, select_one, required: false):
	+ Select 'Yes' if this is a marketing-related inquiry, otherwise select 'No'.
* **Company Name** (`company_name`, text, required: false):
	+ Enter your company's name if you are representing a company.
* **Company Address** (`company_address`, text, required: false):
	+ Enter your company's address if you are representing a company.
* **Contact E-mail** (`contact_email`, email, required: false):
	+ Enter your email address.
* **Contact Phone** (`contact_phone`, text, required: false):
	+ Enter your phone number.
* **Public Relation Request** (`public_relation_request`, number, required: false):
	+ Indicate the public relation request you are making (e.g., media inquiry, product launch).
* **Deadline** (`deadline`, date, required: false):
	+ If applicable, specify the deadline for the request.
* **Time Request** (`time_request`, time, required: false):
	+ If applicable, indicate the time requested for the event or activity.
* **Event Details** (`event_details`, text, required: false):
	+ Briefly describe the event details, if applicable.

## Tips
* Please ensure that you provide accurate and complete information to help us process your request efficiently.
* If you have any additional information or attachments that would support your request, please attach them to the form or send them to us separately.
* If you have any questions or concerns, do not hesitate to contact us.
