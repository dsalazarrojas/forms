# Performance Analytics Support Request Form - Help Guide
## Purpose
The Performance Analytics Support Request Form is for customers or users who need support with performance analytics-related issues, such as problems with their analytics dashboard or data report.

## How To Complete This Form
To submit a support request using this form, follow these steps:

* Fill out the form completely.
* Select your preferred response time for our support team to get back to you.
* Provide any additional information you think would be helpful for our support team to assist with your request.

## Field-by-Field Explanation

* **User ID** (`user_id`, `number`, required: false): This is your unique identifier for our internal system. Please provide the ID number associated with your user account.
* **Request Type** (`request_type`, `select_one`, required: false): Select one of the following options:
	+ Analytics and dashboard support: This option is for issues related to your analytics dashboard or data display.
	+ Data and reporting support: This option is for issues related to data or reporting, such as incorrect or missing data.
	+ Other: If your issue doesn't fit into the above categories, please select this option and provide a brief description.
* **Problem Description** (`problem_description`, `text`, required: false): Describe the issue you're experiencing with your performance analytics.
* **Urgency Level** (`urgency`, `select_multiple`, required: false): Select one or more of the following options:
	+ High: You need urgent assistance as soon as possible.
	+ Medium: You can wait a few hours for our response.
	+ Low: You can wait longer for our response.
* **Expected Response Time** (`expected_response_time`, `select_multiple`, required: false): Select one or more of the following options:
	+ 1 hour: You expect our response within 1 hour.
	+ 2 hours: You expect our response within 2 hours.
	+ 4 hours: You expect our response within 4 hours.
	+ 8 hours: You expect our response within 8 hours.
* **Additional Information** (`additional_information`, `text`, required: false): If there's anything else you'd like to add to help us better understand your issue, please enter it here.
* **Category** (`category`, `select_one`, required: false): Select one of the following options:
	+ Request Forms: This is the default category for this form.
	+ Report Forms: This category is not relevant to this form.
	+ Other: If you think this category is more suitable, please select this option.
* **Form Comments** (`form_comments`, `text`, required: false): If you have any comments or additional information about this request, please enter it here.
