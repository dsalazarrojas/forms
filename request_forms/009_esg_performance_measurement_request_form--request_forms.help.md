# ESG Performance Measurement Request Form - Help Guide
## Purpose
The ESG Performance Measurement Request Form is a tool to gather information about the environmental, social, and governance (ESG) performance of a company or organization. It is intended to help the organization measure its ESG performance in a specific location and category.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the **Category** of ESG performance you want to measure (ESG or Other).
2. Enter the **Location** where the ESG performance is being measured (e.g., office, factory, or field).
3. Choose the **Performance measures** you want to report (select all that apply).
4. Enter the numerical **Measure 1**, **Measure 2**, and **Measure 3** values for each selected performance measure.
5. Add any additional **comments** about the ESG performance (optional).

## Field-by-Field Explanation

* **Category**: Select the category of ESG performance you want to report (ESG or Other). This will help us understand the scope of your request.
* **Location**: Enter the location where the ESG performance is being measured. For example, if you are submitting a report for an office building, enter the address of that location.
* **Performance measures**: Choose the ESG performance measures you want to report. Select all that apply to provide a comprehensive view of your organization's ESG performance.
* **Measure 1**: Enter the value of the first selected performance measure. This should be a numerical value (e.g., 10, 20, 30).
* **Measure 2**: Enter the value of the second selected performance measure. This should be a numerical value (e.g., 10, 20, 30).
* **Measure 3**: Enter the value of the third selected performance measure. This should be a numerical value (e.g., 10, 20, 30).
* **Comments**: If you have any additional information about your ESG performance, please add it here. This is optional but can provide context to your report.
