# Educational Data Compliance Review Request Form - Help Guide

## Purpose

The Educational Data Compliance Review Request Form is used to request a review of educational data to ensure it meets the required standards and regulations. This form is used to gather necessary information for the review process.

## How To Complete This Form

To complete this form, follow these steps:

1. Enter a brief description of the project in the **Project Details** field.
2. Provide the name of the project in the **Project Name** field.
3. Enter a brief description of the project in the **Project Description** field.
4. Specify the type of data being used in the **Data Type** field.
5. Indicate how the data will be used in the **Data Use** field.
6. Select all reviewers who should be notified about the review in the **Reviewers** field. (Multiple selections are allowed.)
7. Enter the date of the review in the **Review Date** field.
8. Enter the time of the review in the **Review Time** field.
9. Add any additional comments or notes about the request in the **Comments** field.
10. Enter your email contact information in the **Email** field.
11. Enter your phone number in the **Phone** field.
12. Add any additional comments or notes about the review process in the **Additional Comments** field.
13. Select whether the request should be routed to a specific reviewer in the **Route to** field.
14. If routed to a specific reviewer, enter their email address in the **Route to Reviewer Email** field.
15. If routed to a specific reviewer, enter their phone number in the **Route to Reviewer Phone** field.
16. Add any notes or instructions for the reviewer in the **Route to Reviewer Notes** field.

## Field-by-Field Explanation

* **Project Details** (text, optional): A brief description of the project.
* **Project Name** (text, optional): The name of the project.
* **Project Description** (text, optional): A brief description of the project.
* **Data Type** (text, optional): The type of data being used.
* **Data Use** (text, optional): How the data will be used.
* **Reviewers** (select multiple, optional): Select all reviewers who should be notified about the review.
* **Review Date** (date, optional): The date of the review.
* **Review Time** (time, optional): The time of the review.
* **Comments** (note, optional): Additional comments or notes about the request.
* **Email** (email, optional): Your email contact information.
* **Phone** (text, optional): Your phone number.
* **Additional Comments** (note, optional): Any additional comments or notes about the review process.
* **Route to** (select one, optional): Whether the request should be routed to a specific reviewer.
* **Route to Reviewer** (text, optional): The name of the reviewer to be routed to.
* **Route to Reviewer Email** (email, optional): The email address of the reviewer to be routed to.
* **Route to Reviewer Phone** (text, optional): The phone number of the reviewer to be routed to.
* **Route to Reviewer Notes** (note, optional): Any notes or instructions for the reviewer.

Note: All fields are optional, but providing accurate and complete information will help ensure a smooth and efficient review process.
