# Speaking Engagement Request Form - Help Guide
## Purpose
The Speaking Engagement Request Form is used to collect information from event organizers or promoters to centralize and manage speaking engagement requests.

## How To Complete This Form
1. Fill out the form with all the required fields (marked as 'required' in the form) to ensure that your request is processed efficiently.
2. Make sure to provide accurate and up-to-date information about the event and the speaker requester.
3. If you're unsure about any field, consult the field-by-field explanation below for clarification.

## Field-by-Field Explanation
* **Event Name** (`event_name`, text, required): This is the name of the event where you're requesting a speaking engagement. Please provide the exact name of the event.
* **Speaker Requester Name** (`speaker_requester_name`, text, required): This is the name of the person or organization requesting the speaking engagement. Please provide your name or the name of your organization.
* **Event Description** (`event_description`, text, required): A brief description of the event, including its purpose, location, and any other relevant details.
* **Speaker Requester Email** (`speaker_requester_email`, email, required): This is the email address of the person or organization requesting the speaking engagement. Please ensure it's up-to-date and correct.
* **Speaker Requester Phone** (`speaker_requester_phone`, text, optional): If you have a phone number associated with your organization or event, please provide it for easier communication.
* **Speaker Requester Organization** (`speaker_requester_organization`, text, optional): If your organization has a name or affiliation, please provide it for context.
* **Speaker Requester Job Title** (`speaker_requester_job_title`, text, optional): If you have a job title or position within your organization, please provide it for context.
* **Event Date** (`event_date`, date, optional): If you're providing the date of the event, please ensure it's in the correct format (YYYY-MM-DD).
* **Event Time** (`event_time`, time, optional): If you're providing the time of the event, please ensure it's in the correct 12-hour format (HH:MM).
* **Event Duration** (`event_duration`, number, optional): If you're providing the duration of the event, please ensure it's a numerical value in hours.
Note: Some fields are not required, so fill them out only if you have the necessary information.
