# Photography And Videography Request Form - Help Guide
## Purpose
The purpose of this form is to request photography and videography services for events. This form will be used to gather necessary information about the event and assign a tool, user, and category for the service.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the form on each page, making sure to provide accurate and complete information.
2. On the second page, select the appropriate tool from the dropdown menu.
3. On the third page, provide a detailed description of the event.
4. On the fourth page, select the category for the event (if applicable).
5. On the fifth page, enter a unique form ID.
6. On the sixth page, select the user who will be responsible for the event.
7. On the seventh page, enter the date of the event.
8. On the eighth page, enter the start time of the event.

## Field-by-Field Explanation

* **Photography And Videography Request Form** (`photography_and_videography_request_form`, text, optional): This is the title of the form. You can leave this field blank if you don't want to provide a title.
* **Assigned Tool** (`assigned_tool`, select_one, required): This field is used to select the tool that will be used for the event. Please choose the most suitable tool from the dropdown menu.
* **Description** (`description`, text, required): This field is used to provide a detailed description of the event. Please be as clear and concise as possible.
* **Category** (`category`, select_multiple, optional): This field is used to select the category for the event (if applicable). You can select multiple categories if necessary.
* **Form ID** (`form_id`, number, required): This field is used to enter a unique ID for the form. Please enter a number that is not already in use.
* **Assigned User** (`assigned_user`, select_one, required): This field is used to select the user who will be responsible for the event. Please choose the most suitable user from the dropdown menu.
* **Date Of Event** (`date_of_event`, date, required): This field is used to enter the date of the event. Please use the format YYYY-MM-DD.
* **Event Start Time** (`event_start_time`, time, required): This field is used to enter the start time of the event. Please use the 24-hour format (HH:MM)
