# PC Audit Request Form - Help Guide
## Purpose
The PC audit request form is used to collect information for a PC audit request.
## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the `location` field with the relevant location where the PC is located.
2. Select the departments that are associated with the PC or the request ( `department` field).
3. Choose the type of PC from the options provided ( `pc_type` field).
4. Add a brief description of the request ( `description` field).
5. If necessary, select a scheduled check date and time for the audit ( `scheduled_date` and `scheduled_check` fields).
6. Set the priority of the request, if necessary, using the options High, Medium, or Low ( `priority` field).
7. Add any additional comments about the request ( `comments` field).

## Field-by-Field Explanation
* **Location** (Select One): Select the location where the PC is located.
* **Department** (Select Multiple): Select all departments associated with the PC or the request.
* **PC Type** (Select One): Choose the type of PC from the options provided.
* **Description** (Text): Add a brief description of the request.
* **Scheduled Check** (Date): If scheduled, select a date and time for the audit.
* **Scheduled Date** (Date): If scheduled, select the date for the audit.
* **Priority** (Select One): Set the priority of the request to High, Medium, or Low.
* **Comments** (Note): Add any additional comments about the request.

## Tips
* Make sure to select all relevant departments if multiple departments are associated with the PC or the request.
* If a scheduled check is required, ensure that the scheduled date and time are correct.
* Use the comments field to provide any additional information that may be helpful for the audit.
* Ensure that the priority is set correctly, if applicable.
