## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the fields on Page 1:
	* Enter your custom PC build request in the **Custom PC Build Request** field.
	* Choose the **Hardware Type** that best describes your system.
	* Select the **Motherboard Type** that you want to use (if desired).
	* Enter the name or model of the **Processor** you want to use (if desired).
	* Choose the **Memory Type** that you want to use.
2. Fill out the fields on Page 2:
	* Enter the **RAM Size** you want to use (if desired).
	* Choose the **Storage Type** that you want to use.
	* Select the **Power Supply** type (if desired).
	* Enter the **Power Supply Wattage** (if desired).
	* Choose the **Cooling Type** that you want to use (if desired).
	* Select the **Case Type** that you want to use (if desired).
	* Choose the **Case Material** that you want to use (if desired).
	* Enter the name or model of the **Graphics Card** you want to use (if desired).

	* Enter the **Display Size** (if desired).
	* Enter the **Display Resolution** (if desired).
	* Choose the **Operating System** that you want to use.
	* Enter the **Budget** for the build (if desired).
3. Review your submission and make any necessary adjustments.
4. Click the **Submit** button to submit your request.
