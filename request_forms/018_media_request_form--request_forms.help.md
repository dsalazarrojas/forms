# Media Request Form - Help Guide
## Purpose
The Media Request Form is used to submit a request for media assets to our team. This form collects essential information about the requested media, ensuring that we can efficiently process and fulfill your requests.

## How To Complete This Form
1. **First Name**: Enter your name as it appears on official documents (e.g., passport).
2. **Email**: Enter your email address, which we'll use to contact you about your request.
3. **Media Request Type**: Choose the type of media you require (Video, Image, Audio, or Other).
4. **Description**: Provide a brief description of the requested media asset.
5. **Media Type**: Select the type of media you're requesting (Image, Video, or Audio).
6. **Production Date**: Enter the date of the media's production (if available).
7. **Release Date**: Enter the date of the media's release (if available).
8. **File**: If you have a relevant file or link to share, add it here (optional).
9. **Notes**: Include any additional details or comments about your request (optional).

## Field-by-Field Explanation
* **First Name**: A text input field where you enter your first name as it appears on official documents.
* **Email**: A field to enter your email address for communication purposes.
* **Media Request Type**: A dropdown menu to choose the type of media you're requesting (Video, Image, Audio, or Other).
* **Description**: A text area where you provide a brief description of the requested media asset.
* **Media Type**: A dropdown menu to select the type of media you're requesting (Image, Video, or Audio).
* **Production Date**: A date input field where you enter the date of the media's production (if available).
* **Release Date**: A date input field where you enter the date of the media's release (if available).
* **File**: A text area where you can add a relevant file or link (optional).
* **Notes**: A text area for any additional comments or details about your request (optional).

## Tips
* Double-check your information before submitting the form to ensure accuracy.
* If you need to make multiple requests, please fill out the form with new details each time.
* Our team will contact you via your email address to discuss your request further.
* Keep your email address up to date to ensure you receive our communication.
