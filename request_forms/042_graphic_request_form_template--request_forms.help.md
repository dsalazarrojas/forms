# Graphic Request Form Template - Help Guide

## Purpose
This form is designed to collect relevant information for graphic requests, including the title of the campaign, the department involved, the design type, deadline, artist notes, campaign URL, resource links, and notes. It is intended to streamline the request process and ensure that all necessary details are provided.

## How To Complete This Form

To complete this form, follow these steps:

1. Enter the title of the campaign in the "Campaign Title" field.
2. Select the department involved in the project using the "department" field.
3. Choose the design type from the "design_type" field.
4. Set the deadline for the project using the "deadline" field.
5. Provide any relevant artist notes in the "artist_notes" field (optional).
6. Add the campaign URL in the "campaign_url" field (optional).
7. Include any additional resource links in the "resource_links" field (optional).
8. Add any other notes in the "notes" field (optional).

## Field-by-Field Explanation

* **Campaign Title** (`campaign_title`, text, required): Enter the title of the campaign.
* **Department** (`department`, text, required): Select the department involved in the project.
* **Design Type** (`design_type`, select_one, required): Choose the type of design required for the campaign.
	+ Options: Option 1, Option 2, Option 3
* **Deadline** (`deadline`, date, required): Set the deadline for the project.
* **Artist Notes** (`artist_notes`, text, optional): Provide any additional notes or information for the artist.
* **Campaign URL** (`campaign_url`, text, optional): Add the URL for the campaign.
* **Resource Links** (`resource_links`, text, optional): Include any additional resource links.
* **Notes** (`notes`, text, optional): Add any other notes about the campaign.

## Tips

* Please fill in all required fields to ensure that the request is properly processed.
* Use a specific and descriptive title for the campaign.
* Be as detailed as possible when providing artist notes.
* Ensure that the deadline is realistic and achievable.
* If providing resource links, make sure they are relevant to the campaign.
