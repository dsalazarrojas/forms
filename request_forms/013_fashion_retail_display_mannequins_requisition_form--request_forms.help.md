## Fashion Retail Display Mannequins Requisition Form - Help Guide

## Purpose
This form is used to request display mannequins for fashion retail stores. It is essential for stores to have accurate and timely information to process the request correctly.

## How To Complete This Form

To complete this form, follow these steps:

1. Enter the **Store Name** where the display mannequins are needed.
2. Select the **Department** where the display mannequins will be used (e.g., Men, Women).
3. Choose the **Category** of the display mannequins (e.g., Tops, Bottoms, Dresses).
4. Enter the **Request Date** when the display mannequins are needed.
5. Enter the **Delivery Date** when the display mannequins are expected to be delivered.
6. Enter the **Delivery Time** when the display mannequins are expected to be delivered.
7. Enter the **Quantity** of display mannequins needed.
8. Enter the **Contact Name** and **Phone Number** of the person responsible for the request.
9. Enter the **Email Address** of the person responsible for the request.
10. Select the **Store Number** where the display mannequins will be delivered.
11. Select the **Location** where the display mannequins will be delivered.
12. Select the **Approval Status** of the request (e.g., Pending, Approved, Rejected).
13. Select the person who **Approved** the request (e.g., John, Jane).
14. Select the **Delivery Confirmation** status (e.g., Confirmed, Not Confirmed).
15. Enter the **Delivery Notes** (optional).
16. Enter any **Remarks** regarding the request (optional).
17. Enter the **Approval Date** (optional).
18. Enter the **Delivery Confirmation Date** (optional).
19. Select the person who made the **Delivery Confirmation** (optional).
20. Select the **Delivery Confirmation Status** (optional).

## Field-by-Field Explanation

* **Store Name (Required):** Enter the name of the store where the display mannequins are needed.
* **Department (Required):** Select the department where the display mannequins will be used (e.g., Men, Women).
* **Category (Required):** Choose the category of the display mannequins (e.g., Tops, Bottoms, Dresses).
* **Request Date (Required):** Enter the date when the display mannequins are needed.
* **Delivery Date (Required):** Enter the date when the display mannequins are expected to be delivered.
* **Delivery Time (Required):** Enter the time when the display mannequins are expected to be delivered.
* **Quantity (Required):** Enter the number of display mannequins needed.
* **Contact Name (Required):** Enter the name of the person responsible for the request.
* **Phone Number (Required):** Enter the phone number of the person responsible for the request.
* **Email Address (Required):** Enter the email address of the person responsible for the request.
* **Store Number (Required):** Select the store number where the display mannequins will be delivered.
* **Location (Required):** Select the location where the display mannequins will be delivered.
* **Approval Status (Required):** Select the approval status of the request (e.g., Pending, Approved, Rejected).
* **Approval By (Required):** Select the person who approved the request (e.g., John, Jane).
* **Delivery Confirmation (Required):** Select the delivery confirmation status (e.g., Confirmed, Not Confirmed).
* **Delivery Notes (Optional):** Enter any additional information about the delivery.
* **Remarks (Optional):** Enter any additional remarks or comments about the request.
* **Approval Date (Optional):** Enter the date when the request was approved.
* **Delivery Confirmation Date (Optional):** Enter the date when the delivery was confirmed.
* **Delivery Confirmation By (Optional):** Select the person who confirmed the delivery (e.g., John, Jane).
* **Delivery Confirmation Status (Optional):** Select the status of the delivery confirmation (e.g., Confirmed, Not Confirmed).
