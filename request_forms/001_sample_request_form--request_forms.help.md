# Sample Request Form - Help Guide
## Purpose
The Sample Request Form is designed to collect information from users to request specific services or products, and to assign a tool to process these requests.

## How To Complete This Form
To complete this form, follow these steps:

* Please fill out each field carefully and accurately, using the information requested.
* Ensure that you provide enough information to allow the request to be properly processed.
* If you are unsure about any field, please ask for clarification.

## Field-by-Field Explanation
* **Request** (`form_request`): A brief description of the request you are making. 
* **Product/Service** (`product_service_name`): Specify the product or service you are requesting. 
* **Email** (`email`): Enter your email address where you can be reached for further communication. 
* **Phone** (`phone`): Your phone number where you can be reached. 
* **Request Details** (`request_details`): A detailed description of your request, including any supporting information. 
* **Submit Request** (`submit_request`): Choose to submit your request to be assigned to a tool. 
* **Assigned Tool** (`assigned_tool`): The tool that will process your request. 
* **Form ID** (`form_id`): A unique identifier for this specific request. This will be generated automatically. 
* **Category** (`category`): Select the category under which this request falls. 
* **Description** (`description`): A brief description of your request. 
* **Output File** (`output_file`): If applicable, specify the name and location of the output file related to this request.

## Tips
* Please double-check your information before submitting your request.
* If you need to make multiple requests, create a new instance of this form for each request.
* If you have any further questions, please contact the relevant department.
