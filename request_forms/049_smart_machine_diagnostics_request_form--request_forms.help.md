# Smart Machine Diagnostics Request Form - Help Guide
## Purpose
The Smart Machine Diagnostics Request Form is used to submit a request for machine diagnostics when a machine is not functioning properly. It will guide the maintenance team in identifying the issue and making a plan to resolve it.

## How To Complete This Form
To complete this form, follow these steps:
1. Enter the **Machine Id** of the machine that is not functioning properly.
2. Describe the **Description** of the issue in detail.
3. Provide the **Location** where the machine is located.
4. Enter a detailed **Issue Description** of what is happening with the machine.
5. Select a **Diagnostic Visit Date** for when you would like the diagnostic visit to take place.
6. Choose a time for the **Diagnostic Visit Time** that works for you.
7. Enter the expected duration of the **Diagnostic Visit Duration** in minutes.
8. If necessary, enter any **Supporting Details** that will help the maintenance team diagnose the issue.
9. Choose the **Maintenance Team** that will be responsible for diagnosing the machine.
10. Select the **Equipment Provider** that provided the machine.
11. Set the **Issue Priority** level (High, Medium, or Low) to help the maintenance team understand the urgency of the request.
12. Indicate if the **Diagnostic Visit is Scheduled** or not.
13. Enter any **Diagnostic Visit Comments** about the issue or the visit.

## Field-by-Field Explanation
* **Machine Id** (number, required): Enter the unique identifier of the machine that is not functioning properly.
* **Description** (text, required): Briefly describe the issue with the machine.
* **Location** (text, required): Enter the location where the machine is located.
* **Issue Description** (text, required): Provide a detailed description of what is happening with the machine.
* **Diagnostic Visit Date** (date, required): Select the date for when you would like the diagnostic visit to take place.
* **Diagnostic Visit Time** (time, required): Choose a time for the diagnostic visit that works for you.
* **Diagnostic Visit Duration** (number, required): Enter the expected duration of the diagnostic visit in minutes.
* **Supporting Details** (text, optional): If necessary, enter any additional details that will help the maintenance team diagnose the issue.
* **Files** (note, optional): You may attach any supporting files for the maintenance team to review.
* **Maintenance Team** (select_one, required): Choose the maintenance team that will be responsible for diagnosing the machine.
* **Equipment Provider** (select_one, required): Select the equipment provider that provided the machine.
* **Issue Priority** (select_one, required): Set the issue priority level (High, Medium, or Low) to help the maintenance team understand the urgency of the request.
* **Diagnostic Visit Scheduled** (select_one, required): Indicate if the diagnostic visit is scheduled or not.
* **Diagnostic Visit Comments** (text, optional): Enter any comments about the issue or the diagnostic visit.
