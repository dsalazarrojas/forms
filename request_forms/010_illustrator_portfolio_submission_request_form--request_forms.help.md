# Illustrator Portfolio Submission Request Form - Help Guide

## Purpose
The "Illustrator Portfolio Submission Request Form" is intended to collect information from illustrators who want to submit their portfolio for consideration. Please use this form to submit your portfolio if you are an illustrator with a portfolio that you would like to share with our team.

## How To Complete This Form
To complete this form, simply fill out the required and optional fields as instructed below.

## Field-by-Field Explanation

* **Submit Form** (ID 1, text, optional): This field is not actually a field to fill out. Please just click on the "Submit" button to send us your completed form.
* **Name** (ID 2, text, optional): Please enter your real name as you would like it to be displayed in our records.
* **Email** (ID 3, email, optional): Enter your email address so we can contact you about your submission.
* **Contact Number** (ID 4, text, optional): If you have a phone number that you would like to be contacted at, please enter it here.
* **Portfolio Link** (ID 5, text, optional): If you have a public portfolio link, please enter it here so we can review it easily.
* **Portfolio Type** (ID 6, select_one, optional): Please select the type of portfolio you are submitting (e.g. Portfolio 1, Portfolio 2, etc.).
* **Portfolio Images** (ID 7, text, optional): Please provide a brief description of your portfolio images, including any relevant details about your work.

## Tips
- Make sure to enter all required fields to ensure that your submission is processed correctly.
- If you have any issues or questions, please contact us at [insert contact information].
