## Merchandising Request And Order Form - Help Guide
## Purpose
The Merchandising Request And Order Form is designed to gather information from customers to facilitate merchandising requests and order processing. This form ensures that all necessary details are collected to create and fulfill orders with the right customers.

## How To Complete This Form
Before you start, please make sure you have all the required information at hand. This form is divided into several sections, each corresponding to a different part of the merchandising process.

1.  Select the "Request Form" page.
2.  Fill in the "Customer Email" field with the customer's email address.
3.  Choose "Yes" or "No" for "Vendor Order" depending on whether a vendor order is required.
4.  Enter the "Product Code" if applicable.
5.  Select "Yes" or "No" for "Sales Person" depending on whether a sales person is involved.
6.  Enter the customer's name in the "Customer Name" field.

## Field-by-Field Explanation

*   **Request Form** (`request_form`, text, optional): This field is where you can enter any additional information about the request.
*   **Customer Email** (`customer_email`, email, optional): Enter the customer's email address where they can be reached for communication.
*   **Vendor Order** (`vendor_order`, select_multiple, optional): Choose "Yes" if a vendor order is required for this request; choose "No" otherwise.
*   **Product Code** (`product_code`, text, optional): Enter a product code if applicable.
*   **Sales Person** (`sales_person`, select_one, optional): Choose "Yes" if a sales person is involved in the request; choose "No" otherwise.
*   **Customer Name** (`customer_name`, text, optional): Enter the customer's name for records and communication.

## Tips

*   Please enter all required information for the form to be processed correctly.
*   Double-check all details before submitting the form.
*   If you need help or more information, contact our support team.
