# public_restroom_deployment_application_form - Help Guide
## Purpose
The Public Restroom Deployment Application Form is used to submit a request for the deployment of a public restroom. This form is intended for use by facility owners, managers, or other relevant stakeholders to provide information about the location, features, and accessibility requirements of the restroom. Please ensure that you have the necessary authorization to complete this form and that you are not submitting duplicate requests.

## How To Complete This Form
To complete this form, please follow these steps:

1. Review the form carefully to ensure you have all the necessary information.
2. Enter the location where the public restroom is to be deployed, including the address or name of the building.
3. Provide justifications for the deployment, such as the expected usage or benefits.
4. Specify the number of toilets required.
5. Indicate the level of gender neutrality desired for the restroom.
6. Select the level of wheelchair accessibility for the restroom.
7. Enter the contact information for the person submitting the request.
8. Enter the phone number of the person submitting the request.

## Field-by-Field Explanation
* **Location** (`Location`, `text`, required: false): Enter the location where the public restroom is to be deployed, including the address or name of the building.
* **Justifications** (`Justifications`, `text`, required: false): Provide justifications for the deployment, such as the expected usage or benefits.
* **Number of Toilets** (`Number of Toilets`, `number`, required: false): Specify the number of toilets required for the restroom.
* **Gender Neutrality** (`Gender Neutrality`, `select_one`, required: false): Indicate the level of gender neutrality desired for the restroom. Options are: Men, Women, All.
* **Wheelchair Accessibility** (`Wheelchair Accessibility`, `select_multiple`, required: false): Select the level of wheelchair accessibility for the restroom. Options are: Wheelchair accessible, Not wheelchair accessible, Not applicable.
* **Contact** (`Contact`, `email`, required: false): Enter the contact information for the person submitting the request.
* **Phone** (`Phone`, `text`, required: false): Enter the phone number of the person submitting the request.
