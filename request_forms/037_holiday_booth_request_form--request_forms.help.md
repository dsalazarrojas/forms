# Holiday Booth Request Form - Help Guide
## Purpose
The Holiday Booth Request Form is a tool to gather information for requesting or reserving holiday-themed booths at events or locations.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the "Holiday Booth Request Form" field with a brief description of the holiday-themed booth or resource you're requesting.
2. In the "event_name" field, enter the name of the event or location where the holiday-themed booth or resource will be used.
3. Select the start date for when you'd like the holiday-themed booth or resource to be available.
4. Select the end date for when you'd like the holiday-themed booth or resource to be available.

## Field-by-Field Explanation
- **Holiday Booth Request Form** (Text, Optional): A brief description of the holiday-themed booth or resource you're requesting.
- **event_name** (Text, Optional): The name of the event or location where the holiday-themed booth or resource will be used.
- **start_date** (Date, Optional): The start date for when you'd like the holiday-themed booth or resource to be available.
- **end_date** (Date, Optional): The end date for when you'd like the holiday-themed booth or resource to be available.

## Tips
- Be sure to provide as much detail as possible in the "Holiday Booth Request Form" field to help the form administrators understand your request.
- If you have any supporting documents or images, consider attaching them to the form to support your request.
- If you have any questions or concerns, contact the form administrators at [form@gic.mx](mailto:form@gic.mx).
