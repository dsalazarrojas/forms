# Agency Request Form - Help Guide
## Purpose
The Agency Request Form is designed to collect essential information from agencies requesting services from your organization. This form helps to gather details such as company name, contact person, email, and project requirements, allowing for efficient processing of agency requests.

## How To Complete This Form

1. **Requester Details**: This section is not required, but it's a good opportunity to provide additional context for the agency.
2. **Company Name**: Enter the name of the organization requesting agency services.
3. **Contact Person**: Type the name of the primary contact person for the agency.
4. **Contact Email**: Enter the email address of the primary contact for the agency, where you can reach them for follow-up.
5. **Project Scope**: Briefly describe the services or tasks the agency is requesting.
6. **Desired Timeline**: Specify the expected start and end dates for the project.
7. **Budget Range**: Enter an estimated budget for the project, if applicable.
8. **Key Objectives**: State the main goals for the engagement.
9. **Attachments Description**: Describe any supporting documents attached to the request.
10. **Preferred Contact Time**: Select the best time to reach the requester.

## Field-by-Field Explanation

* **-- Requester Details --** (optional): A free-form text field for additional context or information about the requester.
* **Company name** (required): The name of the organization requesting agency services.
	+ Please enter the official name of the agency.
	+ Make sure to use the correct spelling and title case.
* **Contact person** (required): The name of the primary contact person for the agency.
	+ Use the full name of the person, including their first and last name.
* **Contact email** (required): The email address of the primary contact person.
	+ Ensure the address is formatted correctly and is a valid email address.
* **Project Scope** (required): A brief summary of the requested services.
	+ Keep this to a few sentences or paragraphs, depending on the requirement.
* **Desired Timeline** (optional): The expected start and end dates for the project.
	+ Use the format 'start date' - 'end date' (e.g., 2023-03-01 - 2024-02-28).
* **Budget Range** (optional): The estimated budget for the project.
	+ Enter a range using the format 'min' - 'max' (e.g., 10,000 - 50,000).
* **Key Objectives** (required): The main goals for the engagement.
	+ Keep this to a few sentences or paragraphs, depending on the requirement.
* **Attachments Description** (optional): A description of any supporting documents attached to the request.
	+ Briefly describe the purpose and content of the attachments.
* **Preferred Contact Time** (optional): The best time to reach the requester.
	+ Select a time of day that suits you best to contact the agency.

## Tips
Before submitting the form, please ensure that all fields marked as 'required' are completed accurately and thoroughly. If you're unsure about any field, please reach out to your internal contacts for guidance. Also, please attach any supporting documents as described in the 'Attachments Description' field.
