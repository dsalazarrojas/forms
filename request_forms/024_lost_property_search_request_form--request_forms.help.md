## Lost Property Search Request Form - Help Guide

## Purpose
This form is used to request a search for a lost property. Fill out the form with the necessary information about the lost property and your contact details so that our team can initiate the search.

## How To Complete This Form

	* Enter a brief description of the property that you are searching for.
2. **Item Description** (item_description, text, required):
	* Provide a detailed description of the lost property.
3. **Item Location** (item_location, text, required):
	* Enter the location where the lost property was last seen.
4. **Item Category** (item_category, select_one, required):
	* Select the category of the lost property (e.g. Bag, Electronics, Food, etc.).
5. **Found** (item_found, select_multiple, optional):
	* Check if the property has been found. If it has, please provide the details of the location where it was found.
6. **Follow Up** (follow_up, date, optional):
	* Enter the date you would like our team to follow up with you about the search status.
7. **Follow Up Details** (follow_up_details, text, optional):
	* Provide any additional details regarding the follow up.
8. **Contact Name** (contact_name, text, optional):
	* Enter your name.
9. **Contact Email** (contact_email, email, optional):
	* Enter your email address.
10. **Contact Phone** (contact_phone, text, optional):
	* Enter your phone number.
11. **Contact Message** (contact_message, text, optional):
	* Enter any additional comments or messages for our team to reach out to you.

- Please be as descriptive as possible when providing information about the lost property.
