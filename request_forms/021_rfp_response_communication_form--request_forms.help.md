# rfp_response_communication_form - Help Guide

## Purpose
This form is used to gather information and communication responses from project stakeholders, vendors, and project managers.

## How To Complete This Form

To complete this form, follow these steps:

1. Ensure you are filling out the correct project number.
2. Enter the date you submitted the RFP (request for proposal) to the vendor.
3. Fill in the vendor's name, email, and phone number.
4. Select the status of the project (Active, Inactive, or Completed).
5. Enter the project manager's name and their comment (if required).
6. Enter the stakeholder's name, email, and phone number.
7. Enter the stakeholder's response date and time.
8. Select the status of the stakeholder response (Active, Inactive, or Completed).
9. Enter the project lead's name and their comment (if required).
10. Enter the date you submitted this form.
11. Enter any additional notes from the stakeholder or project manager.

## Field-by-Field Explanation
### Project Number
* Project Number (`project_number`, number, required: false): Enter the project number associated with this response.

### RFP Submission Date
* RFP Submission Date (`rfp_submission_date`, date, required: false): Enter the date you submitted the RFP to the vendor.

### Vendor Name
* Vendor Name (`vendor_name`, text, required: false): Enter the name of the vendor who submitted the response.

### Vendor Email
* Vendor Email (`vendor_email`, email, required: false): Enter the email address of the vendor.

### Vendor Phone
* Vendor Phone (`vendor_phone`, text, required: false): Enter the phone number of the vendor.

### Assigned Tool
* Assigned Tool (`assigned_tool`, text, required: false): Select the tool assigned to this project.

### Project Status
* Project Status (`project_status`, select_one, required: false): Select the status of the project (Active, Inactive, or Completed).

### Project Manager
* Project Manager (`project_manager`, text, required: false): Enter the name of the project manager.

### Stakeholder Name
* Stakeholder Name (`stakeholder_name`, text, required: false): Enter the name of the stakeholder.

### Stakeholder Email
* Stakeholder Email (`stakeholder_email`, email, required: false): Enter the email address of the stakeholder.

### Stakeholder Phone
* Stakeholder Phone (`stakeholder_phone`, text, required: false): Enter the phone number of the stakeholder.

### Stakeholder Response Date
* Stakeholder Response Date (`stakeholder_response_date`, date, required: false): Enter the date of the stakeholder response.

### Stakeholder Response Time
* Stakeholder Response Time (`stakeholder_response_time`, time, required: false): Enter the time of the stakeholder response.

### Stakeholder Status
* Stakeholder Status (`stakeholder_response_status`, select_one, required: false): Select the status of the stakeholder response (Active, Inactive, or Completed).

### Project Lead
* Project Lead (`project_lead`, text, required: false): Enter the name of the project lead.

### Form Submission Date
* Form Submission Date (`form_submission_date`, date, required: false): Enter the date of form submission.

### Stakeholder Response Note
* Stakeholder Response Note (`stakeholder_response_note`, note, required: false): Enter any additional notes from the stakeholder.

### Form Submission Note
* Form Submission Note (`form_submission_note`, note, required: false): Enter any additional notes from the project manager.

### Vendor Response Status
* Vendor Response Status (`vendor_response_status`, select_multiple, required: false): Select the status of the vendor response (Active, Inactive, or Completed).

### Project Manager Comment
* Project Manager Comment (`project_manager_comment`, text, required: false): Enter any comment from the project manager.
