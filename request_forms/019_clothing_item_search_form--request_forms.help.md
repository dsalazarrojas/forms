# Clothing Item Search Form - Help Guide

## Purpose
The purpose of this form is to gather information from you about the clothing items you are searching for. By answering the questions in this form, we will be able to provide you with more accurate and relevant results for your specific needs.

## How To Complete This Form
To complete this form, simply select or fill in the relevant fields according to your preferences. Make sure to fill in all required fields (marked with an *).

## Field-by-Field Explanation

* **Your Name**: Please enter your full name for our records.
* **Email Address** (*): Enter your email address so we can contact you with relevant results and recommendations.
* **Phone Number**: This is an optional field where you can enter your phone number for follow-up contact.
* **Item Search Details**: Briefly describe what you are looking for (e.g., "dress for a wedding" or " casual pants for daily wear").
* **Type of Item** (*): Select what type of item you are searching for (e.g., "Specific garment", "Complete outfit", etc.).
* **Garment Category** (*): Choose the category of garment you are interested in (e.g., "Dress", "Pants or jeans", etc.).
* **Describe Your Ideal Item**: Provide a description of the item you are looking for (e.g., "lightweight, pastel pink dress").
* **Style Aesthetic** (*): Select the style aesthetic that suits your preferences (e.g., "Classic and timeless", "Modern and contemporary", etc.).
* **Color Preference**: Select the colors you prefer (e.g., "Black", "White", etc.). You can select multiple colors.
* **Your Size** (*): Choose your size from the available options (e.g., "XS", "S", etc.).
* **Fit Preference** (*): Select your fit preference (e.g., "Slim and fitted", "Classic fit", etc.).
* **Length Preference**: This field applies to applicable items. Select your length preference (e.g., "Cropped or short", "Regular length", etc.). This field is only visible if the selected item type allows for length adjustment.
* **Preferred Fabrics**: Select the fabrics you prefer (e.g., "Cotton", "Linen", etc.). You can select multiple fabrics.
* **Fabric Characteristics**: Select the fabric characteristics you prefer (e.g., "Lightweight", "Stretchy or comfortable", etc.). You can select multiple characteristics.
* **Brand Preference**: If you have a specific brand in mind, enter it here.
* **Price Range**: Select the price range you are willing to pay (e.g., "Under 25", "50-100", etc.).
* **Intended Use or Occasion** (*): Select the occasion or purpose of the item (e.g., "Everyday wear", "Work or professional", etc.).
* **Urgency**: Indicate how urgently you need the item (e.g., "Very urgent - within days", "Normal - within a month", etc.).
* **Additional Preferences or Requirements**: If you have any other specific needs or preferences, type them in here.
* **May we contact you with recommendations?** (*): Select whether you want us to contact you with recommendations or not.
