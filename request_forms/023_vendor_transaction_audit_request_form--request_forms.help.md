# Vendor Transaction Audit Request Form - Help Guide
## Purpose
This form is used to request an audit of a vendor transaction. It is essential to understand that a vendor transaction audit can only be requested if the transaction has been completed or is pending. If the transaction has not been completed or is not pending, a separate request form should be used.

## How To Complete This Form
To complete this form, please follow these steps:

1. Enter the vendor's name in the **Vendor Name** field.
2. Provide the vendor's contact information in the **Vendor Contact** field.
3. Enter the vendor's address in the **Vendor Address** field.
4. Select the date of the transaction in the **Transaction Date** field.
5. Enter the amount of the transaction in the **Transaction Amount** field.
6. Provide a brief description of the reason for the transaction in the **Reason for Transaction** field.
7. Select the type of transaction from the options provided in the **Transaction Type** field.
8. Attach any supporting files related to the transaction in the **Supporting Files** field. This field is a note field where you can add any additional information.
9. Enter any additional details about the transaction that may be relevant to the audit in the **Review Details** field.
10. Enter any additional comments or observations about the transaction in the **Additional Comments** field.

## Field-by-Field Explanation

* **Vendor Name** (`vendor_name`, text, required/optional): Enter the name of the vendor involved in the transaction.
* **Vendor Contact** (`vendor_contact`, text, required/optional): Provide the contact information for the vendor, including their email, phone number, or other relevant details.
* **Vendor Address** (`vendor_address`, text, required/optional): Enter the address of the vendor where the transaction took place.
* **Transaction Date** (`transaction_date`, date, required/optional): Select the date of the transaction from the calendar.
* **Transaction Amount** (`amount`, number, required/optional): Enter the total amount of the transaction.
* **Reason for Transaction** (`reason_for_transaction`, text, required/optional): Provide a brief description of the reason for the transaction.
* **Transaction Type** (`transaction_type`, select_one, required/optional): Select one of the options provided to describe the type of transaction (e.g. purchase, payment, etc.).
* **Supporting Files** (`supporting_files`, note, required/optional): Attach any supporting files related to the transaction, such as invoices, receipts, or other relevant documents.
* **Review Details** (`review_details`, text, required/optional): Enter any additional details about the transaction that may be relevant to the audit.
* **Additional Comments** (`additional_comments`, text, required/optional): Enter any additional comments or observations about the transaction.
