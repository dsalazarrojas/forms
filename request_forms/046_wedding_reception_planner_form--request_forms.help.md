# Wedding Reception Planner Form - Help Guide

## Purpose
This form is designed to collect essential details for a wedding reception planning process. Please provide accurate information to ensure a successful and enjoyable event for the couple and their guests.

## How To Complete This Form
1.  Select the type of event you are planning: Wedding Reception, Ceremony, or both.
2.  Enter the couple's information, including their names.
3.  Provide details about the ceremony, if applicable.
4.  Enter the reception information, including the number of guests and other essential details.
5.  Mention any other essential services or activities that you would like to include during the reception.
6.  If applicable, enter information about the food and beverages you would like to have at the reception.
7.  Lastly, provide any other necessary information about professional services you would like to hire for the reception.

## Field-by-Field Explanation

* **Wedding Reception Information** (`wedding_reception_planner_form_info`, `select_one`, required): Select the type of event you are planning (Wedding Reception, Ceremony, or both).
* **Couple Information** (`couple_info`, `text`, required): Enter the names of the couple.
* **Ceremony Information** (`ceremony_info`, `text`, required): Provide details about the ceremony, if applicable.
* **Reception Information** (`reception_info`, `text`, required): Enter the details about the reception, including the number of guests you expect.
* **Guests Information** (`guests_info`, `text`, required): Mention any other essential information about the guests, if applicable.
* **Food and Beverages** (`food_and_beverages`, `text`, required): Enter the details about the food and beverages you would like to have at the reception.
* **Entertainment** (`entertainment`, `text`, optional): If applicable, enter information about the entertainment activities you would like to include.
* **Other Professional Services** (`other_services`, `text`, optional): If applicable, mention any other professional services you would like to hire.
