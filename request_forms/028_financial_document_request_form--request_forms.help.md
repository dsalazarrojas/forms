# Financial Document Request Form - Help Guide
## Purpose
This form is designed to collect information about financial document requests, including details about the document type, file upload, and request status.

## How To Complete This Form
To complete this form, follow these steps:

1. Provide a brief description of your request in the Request Details field.
2. Select the type of document you are requesting using the Document Type field.
3. If necessary, upload the financial document using the File Uploader field.
4. Enter the Request Date and File Size fields if applicable.
5. Choose the File Type and Financial Institution fields as required.
6. Select the Branch and Account Number fields if necessary.
7. Enter the Employee, Department, and Uploaded By fields as needed.
8. Provide a brief description of the financial institution using the File Description fields.
9. Select the Request Status field to indicate the current status of your request.
10. Click the Submit button to submit your request.

## Field-by-Field Explanation

* **Request Details**: Enter a brief description of your financial document request.
* **Document Type**: Select the type of financial document you are requesting (e.g. vendor payment, expense reimbursement, etc.).
* **File Uploader**: If necessary, upload the relevant financial document.
* **Request Date**: Enter the date you are requesting the financial document.
* **File Type**: Select the type of file you are uploading (e.g. pdf, excel, etc.).
* **File Name**: Enter a name for the file you are uploading.
* **File Size**: Enter the size of the file you are uploading.
* **File Location**: Enter the location where the file is stored.
* **Uploaded By**: Enter the person who uploaded the file.
* **Request Status**: Select the current status of your request (e.g. pending, approved, etc.).
* **Financial Institution**: Select the financial institution related to the request.
* **Branch**: Enter the branch of the financial institution.
* **Account Number**: Enter the account number of the financial institution.
* **Employee**: Enter the employee responsible for the request.
* **Department**: Enter the department related to the request.
* **File Description**: Enter a brief description of the file.
* **File Description 2**, **File Description 3**, **File Description 4**, **File Description 5**, **File Description 6**, **File Description 7**, **File Description 8**: Enter a brief description of the file for each field.
* **Submit**: Click this button to submit your request.

Note: All fields are optional unless marked as required in the form.
