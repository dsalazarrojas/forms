# Location Scan Request Form - Help Guide

## Purpose
This form is used to submit a request for location scanning, including details such as user, scan type, location ID, and scan request details. It is essential to provide accurate and complete information to ensure efficient processing of your request.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the "User" field with your name or username.
2. In the "Scan Details" field, provide a brief description of the scan request.
3. Enter the "Location ID" number.
4. Enter the "Location Name" of the location to be scanned.
5. Select the "Scan Type" option (Yes/No) indicating the type of scan required.
6. If "Scan Type" is "Other", enter the "Other Scan Type" in the text field.
7. Select the "On-Site Visit" options (Yes/No) indicating if you would like to visit the location on-site.
8. Enter the "Date" and "Time" for the scan request.
9. Enter the "Authorization" details, such as who has authorized the scan.
10. In the "Notes" field, provide any additional comments or information about the scan request.
11. If required, enter your "Email" and "Phone" contact details.
12. Enter the "Address" of the location to be scanned.
13. Enter the "Facility ID", "Location ID", "User ID", and other IDs as required.
14. Select the "Scan Request Status" (Active/Inactive) of the request.
15. Enter the "Scan Request Date" and "Scan Request Time" for the scan request.
16. In the "Scan Request Authorization Details" field, provide the details of who authorized the scan.
17. You can add a "Scan Request Note" if required.
18. Enter the "Scan Request Phone" and "Scan Request Address" details.
19. Enter the "Scan Request Facility ID" and "Scan Request Location ID" details.
20. Enter the "Scan Request User ID" details.

## Field-by-Field Explanation
* **User** (1) (Text, Required): Enter your name or username.
* **Scan Details** (2) (Text, Required): Provide a brief description of the scan request.
* **Location Id** (3) (Number, Required): Enter the location's unique ID number.
* **Location Name** (4) (Text, Required): Enter the name of the location to be scanned.
* **Scan Type** (5) (Select One, Required): Select the type of scan required (Yes/No).
* **Other Scan Type** (6) (Text, Required): If "Scan Type" is "Other", enter the specific type of scan.
* **On-Site Visit** (7) (Select Multiple, Required): Select if you want to visit the location on-site (Yes/No).
* **Date** (8) (Date, Required): Enter the date of the scan request.
* **Time** (9) (Time, Required): Enter the time of the scan request.
* **Authorization** (10) (Text, Required): Enter the details of who authorized the scan.
* **Notes** (11) (Note, Required): Provide any additional comments or information about the scan request.
* **Email** (12) (Email, Optional): Enter your email contact details.
* **Phone** (13) (Text, Required): Enter your phone contact details.
* **Address** (14) (Text, Required): Enter the address of the location to be scanned.
* **Location Scan Request Id** (15) (Number, Required): Enter the scan request's unique ID number.
* **Facility Id** (16) (Number, Required): Enter the facility's ID number.
* **User Id** (17) (Number, Required): Enter the user's ID number.
* **Scan Request Status** (18) (Select One, Required): Select the status of the scan request (Active/Inactive).
* **Scan Request Date** (19) (Date, Required): Enter the date of the scan request.
* **Scan Request Time** (20) (Time, Required): Enter the time of the scan request.
* **Scan Request Authorization Details** (21) (Text, Required): Enter the details of who authorized the scan.
* **Scan Request Note** (22) (Note, Optional): Provide any additional comments or information about the scan request.
* **Scan Request Phone** (23) (Text, Required): Enter your phone contact details.
* **Scan Request Address** (24) (Text, Required): Enter the address of the location to be scanned.
* **Scan Request Facility Id** (25) (Number, Required): Enter the facility's ID number.
* **Scan Request Location Id** (26) (Number, Required): Enter the location's ID number.
* **Scan Request User Id** (27) (Number, Required): Enter the user's ID number.
