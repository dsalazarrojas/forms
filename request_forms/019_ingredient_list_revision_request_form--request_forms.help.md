# Ingredient List Revision Request Form - Help Guide
## Purpose
The Ingredient List Revision Request Form is used to request changes to the ingredient list, such as adding, removing, or updating ingredients.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the category under which the ingredient change falls.
2. Choose the type of request you are making (e.g., New Ingredient, Removed Ingredient, or List Update).
3. If applicable, enter the ID number of the ingredient you are requesting to be added or removed.
4. Provide a clear and concise explanation for your request (Justification).
5. Upload any supporting documents.
6. Set the priority level of your request (Low, Medium, or High).
7. Enter the date the justification was created.

## Field-by-Field Explanation

* **Category** (`category`, select_one, optional): Select the category that the ingredient change falls under, such as Food Brands or Manufacturers.
* **Request Type** (`request_type`, select_one, optional): Choose the type of request you are making (e.g., New Ingredient, Removed Ingredient, or List Update).
* **Ingredient ID** (`ingredient_id`, number, optional): Enter the ID number of the ingredient you are requesting to be added or removed.
* **Justification** (`justification`, text, optional): Provide a clear and concise explanation for your request.
* **Documents** (`documents`, note, optional): Upload any supporting documents to your request.
* **Priority** (`priority`, select_one, optional): Set the priority level of your request (Low, Medium, or High).
* **Justification Date** (`justification_date`, date, optional): Enter the date the justification was created.

## Tips
* Please ensure that you have a clear understanding of the category and request type before proceeding.
* Be as specific as possible when providing the Ingredient ID.
* Use clear and concise language when filling out the Justification field.
* Attach relevant documents to support your request, if applicable.
* Set the correct priority level for your request based on business need.
