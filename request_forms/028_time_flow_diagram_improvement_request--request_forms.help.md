# Time Flow Diagram Improvement Request - Help Guide

## Purpose
This form is designed to collect improvement requests for Time Flow Diagrams, a tool used to visualize and document workflows or processes. The purpose of this form is to help identify areas where improvements can be made to enhance process efficiency and effectiveness.

## How To Complete This Form

To complete this form, follow these steps:

1. Enter the title of the Time Flow Diagram in the "Time Flow Diagram Improvement Request" field.
2. Provide a brief description of the request in the "Description" field.
3. Select the category of improvement request (e.g., "Technical", "Quality", or "Request Forms").
4. Provide the URL of the Time Flow Diagram.
5. If necessary, elaborate on the request in the "Description" field.
6. Indicate the impact of the improvement request (e.g., "High", "Medium", or "Low").
7. Identify the improvement area (e.g., "Technical", "Process", or "Other").
8. Select the priority of the improvement request (e.g., "High", "Medium", or "Low").
9. Assign a user to follow up on the request, if applicable.
10. Set the submitted date and time.

## Field-by-Field Explanation

* **Time Flow Diagram Improvement Request** (`form_title`, `text`, required): Enter the title of the Time Flow Diagram.
* **Description** (`description`, `text`, required): Provide a brief description of the improvement request.
* **Category** (`category`, `select_one`, required): Select the category of improvement request (e.g., "Technical", "Quality", or "Request Forms").
* **Diagram URL** (`diagram_url`, `text`, required): Enter the URL of the Time Flow Diagram.
* **Description (long)** (`description_long`, `text`, optional): If necessary, provide a more detailed description of the improvement request.
* **Impact** (`impact`, `select_multiple`, optional): Indicate the impact of the improvement request (e.g., "High", "Medium", "Low").
* **Improvement Area** (`improvement_area`, `select_one`, optional): Identify the improvement area (e.g., "Technical", "Process", or "Other").
* **Priority** (`priority`, `select_one`, required): Select the priority of the improvement request (e.g., "High", "Medium", "Low").
* **Assigned User** (`assigned_user`, `select_one`, optional): Assign a user to follow up on the request, if applicable.
* **Created By** (`created_by`, `text`, optional): Enter the name of the user who created the improvement request.
* **Created** (`created`, `date`, required): Set the date and time the improvement request was submitted.
* **Submitted** (`submitted`, `date`, optional): Set the date and time the improvement request was submitted, if applicable.
* **Closed** (`closed`, `date`, optional): Set the date and time the improvement request was closed, if applicable.
* **Form ID** (`form_id`, `number`, optional): Enter a unique identifier for the improvement request.
* **Form Version** (`form_version`, `number`, optional): Enter the version of the improvement request form.
* **Updated** (`updated`, `date`, optional): Set the date and time the improvement request was updated.
* **Updated By** (`updated_by`, `text`, optional): Enter the name of the user who updated the improvement request.
* **Form Status** (`form_status`, `select_one`, optional): Select the status of the improvement request (e.g., "Approved", "Rejected", or "Draft").
* **Note** (`note`, `note`, optional): Add any additional notes or comments about the improvement request.
* **Note (long)** (`note_long`, `text`, optional): Enter any additional details or comments about the improvement request.
* **Phone** (`phone`, `text`, optional): Enter a phone number for follow-up, if applicable.
* **Email** (`email`, `email`, optional): Enter an email address for follow-up, if applicable.
* **Submitted Time** (`submitted_time`, `time`, optional): Set the time the improvement request was submitted.
* **Form Title Version** (`form_title_version`, `text`, optional): Enter the version of the improvement request form title.
* **Description Version** (`description_version`, `text`, optional): Enter the version of the improvement request description.

## Tips

* Make sure to fill out all required fields.
* If you need to add additional details, use the "Description" or "Note" fields.
* If you need to assign a user to follow up on the request, select a user from the "Assigned User" field.
* If you need to set a date or time, use the corresponding fields.
* If you need to add a note or comment, use the "Note" or "Note (long)" fields.
