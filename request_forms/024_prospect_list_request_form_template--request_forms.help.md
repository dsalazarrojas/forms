# Prospect List Request Form Template - Help Guide
## Purpose
This form is used to request a list of prospects from the database. It helps to gather necessary information for sales or business development activities.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill in the **List Request Form** field with a brief description of the prospect list request.
2. Enter the prospect's **First Name**, **Last Name** if known.
3. Provide the prospect's **Email** address.
4. Enter the prospect's **Phone** number.
5. Specify the **Lead Source** from which the prospect came (e.g., "Yes" for an in-person meeting).
6. For the **Sales Stage**, select the current stage the prospect is at in the sales process (e.g., "Yes" for a prospect that has reached the decision stage).
7. In the **Sales Stage** field, enter any additional details or notes about the sales stage.
8. In the **Sales Stage Values** field, provide any relevant values or data associated with the sales stage.
9. Enter the name of the person who created this request.
10. Optionally, select a **Date** for the prospect list request.

## Field-by-Field Explanation

* **List Request Form** (`prospect_list_request_form`): A brief description of the prospect list request.
* **First Name** (`first_name`): Enter the prospect's first name if known.
* **Last Name** (`last_name`): Enter the prospect's last name if known.
* **Email** (`email`): The prospect's email address.
* **Phone** (`phone`): The prospect's phone number.
* **Lead Source** (`lead_source`): Specify the source of the lead (e.g., "Yes" for an in-person meeting).
* **Sales Stage** (`sales_stage`): Select the current sales stage the prospect is at.
* **Sales Stage** (`sales_stage_options`): Enter any additional details or notes about the sales stage.
* **Sales Stage Values** (`sales_stage_values`): Provide any relevant values or data associated with the sales stage.
* **Created By** (`created_by`): The name of the person who created this request.
* **Date** (`date`): Optionally, select a date for the prospect list request.

## Tips
* Make sure to provide accurate and relevant information to help the sales or business development team understand the prospect's needs.
* If the prospect's data is not available, please mark it as "No" or leave it blank.
* This form will help to streamline the prospect list request process and prevent duplication of effort.
