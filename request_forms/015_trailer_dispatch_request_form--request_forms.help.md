# Trailer Dispatch Request Form - Help Guide
## Purpose
This form is designed to collect information necessary for trailer dispatch requests, ensuring efficient and accurate logistics coordination.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the Pickup Location field with the address or location where the trailer is currently situated.
2. Enter the Carrier Name of the person or company responsible for handling the trailer dispatch request.
3. Provide the Trailer Number for easy identification.
4. Select the Pickup Date and Delivery Date for the trailer dispatch request.
5. Enter the Delivery Location field with the address or location where the trailer needs to be delivered.
6. If you wish to include a Contact Number, please provide it for communication purposes.
7. Add any additional Notes about the request, if necessary.

## Field-by-Field Explanation
* **Pickup Location** (`pickup_location`, text, required): Enter the address or location where the trailer is currently situated.
* **Carrier Name** (`carrier_name`, text, required): Enter the name of the person or company responsible for handling the trailer dispatch request.
* **Trailer Number** (`trailer_number`, text, optional): Provide the trailer's identification number for easy reference.
* **Pickup Date** (`pickup_date`, date, required): Select the date when the trailer should be picked up.
* **Delivery Date** (`delivery_date`, date, required): Select the date when the trailer should be delivered.
* **Delivery Location** (`delivery_location`, text, required): Enter the address or location where the trailer needs to be delivered.
* **Contact Number** (`contact_number`, text, optional): Enter your contact number for communication purposes, if required.
* **Notes** (`notes`, note, optional): Add any additional information or comments about the request, if needed.
