# IT Equipment Upgrade Request Form - Help Guide
## Purpose

This guide provides step-by-step instructions on how to complete the IT Equipment Upgrade Request Form, which is used to request upgrades for IT equipment.

## How To Complete This Form

1. Click on the "Submit" button to begin the form.
2. Select the type of equipment you would like to upgrade from the drop-down menu.
3. Provide a brief reason for the upgrade in the "Reason For Upgrade" field.
4. Describe the specific upgrade or upgrade request in the "Description" field (if applicable).
5. Enter the budget allocated for the upgrade in the "Budget Allocated" field.
6. Choose the person or department that the upgrade is assigned to from the "Assigned To" drop-down menu.
7. Optionally, select the date you would like to have the upgrade completed by in the "Date Required" field.
8. Click on the "Submit" button to complete and submit the form.

## Field-by-Field Explanation

* **Equipment Type** (`Equipment Type`, `select_one`, required): Select the type of equipment you would like to upgrade from the drop-down menu.
* **Reason For Upgrade** (`Reason For Upgrade`, `text`, required): Provide a brief explanation for the upgrade, such as "Upgrade to latest version" or "New equipment required for new software".
* **Description** (`Description`, `text`, optional): Provide a detailed description of the upgrade or upgrade request, if necessary.
* **Budget Allocated** (`Budget Allocated`, `number`, required): Enter the budget allocated for the upgrade, in the format of a dollar amount (e.g., "1000.00").
* **Assigned To** (`Assigned To`, `select_multiple`, required): Select the person or department that the upgrade is assigned to, to ensure the upgrade is handled correctly.
* **Date Required** (`Date Required`, `date`, optional): If you would like to specify a particular date for the upgrade, enter it in the "Date Required" field. Please use the standard date format "MM/DD/YYYY".
* **Submit** (`Submit`, `text`, required): Click on the "Submit" button to complete and submit the form.
