# Payment Term Definition Request Form - Help Guide
## Purpose
This form is designed to collect details about payment term definition requests from customers, helping the sales team to process and follow up on these requests effectively.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the required fields as accurately as possible.
2. Ensure that the information provided is correct and up-to-date.
3. Review the form before submitting to avoid errors.

## Field-by-Field Explanation
### **request_details** (`request_details`, text, required)
* This field is used to describe the payment term definition request. Please provide a clear and concise explanation of the request.

### **request_date** (`request_date`, date, required)
* Enter the date when the payment term definition request was made.

### **request_time** (`request_time`, time, required)
* Enter the time when the payment term definition request was made.

### **customer_name** (`customer_name`, text, required)
* Enter the customer's name associated with this request.

### **customer_email** (`customer_email`, email, required)
* Enter the customer's email address associated with this request.

### **customer_phone** (`customer_phone`, text, required)
* Enter the customer's phone number associated with this request.

### **department** (`department`, select_one, required)
* Select the department that this request is related to from the provided options.

### **payment_term** (`payment_term`, select_multiple, required)
* Select all applicable payment terms that apply to this request.

### **comments** (`comments`, text, optional)
* Add any additional comments or notes related to this request.

### **assigned_tool** (`assigned_tool`, text, optional)
* If applicable, mention the tool being used for this form.

### **created_by** (`created_by`, text, optional)
* Identify who created this request, if known.

Note: Please review the form carefully before submitting to avoid errors and ensure accurate processing.
