# emergency_location_request_form - Help Guide
## Purpose
The emergency_location_request_form is used to request a location in case of an emergency. Please fill out this form to provide information about the emergency location you are requesting.

## How To Complete This Form
To complete this form, follow these steps:

1. Select whether or not you are requesting an emergency location.
2. Choose the type of emergency that requires the location (e.g., "Yes" or "No").
3. Enter the name of the location (e.g., building, room, or address).
4. Provide details about the location (e.g., address, room number).
5. Enter the name of the person to contact in case of an emergency.
6. Enter the phone number of the person to contact in case of an emergency.

## Field-by-Field Explanation

* **Emergency Location** (Yes/No, select_multiple): 
  Select "Yes" if you are requesting an emergency location, "No" otherwise.
* **Issue Type** (Yes/No, select_one): 
  Choose the type of emergency that requires the location (e.g., "Yes" or "No").
* **Location** (text, optional): 
  Enter the name of the location (e.g., building, room, or address).
* **Location Name** (text, optional): 
  Enter the full name of the location (e.g., building name or room number).
* **Location Details** (note, optional): 
  Provide any additional details about the location (e.g., address, room number).
* **Location Coordinates** (text, optional): 
  Enter the GPS coordinates of the location (e.g., latitude and longitude).
* **Emergency Contact Name** (text, optional): 
  Enter the name of the person to contact in case of an emergency.
* **Emergency Contact Phone** (text, optional): 
  Enter the phone number of the person to contact in case of an emergency.

This form is designed to help you quickly and easily provide the necessary information for a location request in case of an emergency. Please be sure to fill out all required fields and provide as much detail as possible to ensure a successful location request.
