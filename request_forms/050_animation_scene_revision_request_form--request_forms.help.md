# Animation Scene Revision Request Form - Help Guide
## Purpose
The Animation Scene Revision Request Form is used to request changes to a specific scene in an animation project. It is a crucial tool for ensuring that revisions are accurately and efficiently processed.

## How To Complete This Form
To complete this form, follow these steps:
1. Fill out your name and role in the project.
2. Enter the scene ID and shot number of the scene requiring revision.
3. Choose the category of revision (e.g., character animation, background and environment, etc.).
4. Select the priority level of the revision (e.g., low, medium, high, or blocked).
5. Provide a detailed description of the changes required.
6. If applicable, include a reference timestamp and attach a markup or reference image.
7. Estimate the time needed for the revision.
8. Set a deadline for the completed revision.

## Field-by-Field Explanation
* **Requester Name (1)**: Enter your full name as the person making the request.
* **Current Role (2)**: Choose your role in the project (Director, Lead Animator, Client Representative, etc.).
* **Scene ID (3)**: Enter the ID of the scene requiring revision (e.g., SC-05).
* **Shot Number (4)**: Enter the shot number of the scene requiring revision.
* **Revision Category (5)**: Select the type of revision needed (Character Animation - Movement, Background and Environment, etc.).
* **Revision Priority (6)**: Choose the priority level of the revision (Low - Minor tweak, Medium - Standard revision, High - Critical for scene, Blocked - Cannot proceed without fix).
* **Detailed Revision Description (7)**: Provide a detailed description of the changes required, being as specific as possible.
* **Reference Timestamp in Edit (8)**: If applicable, include a reference timestamp (e.g., 01 - 24 - 15).
* **Is a markup or reference image provided? (9)**: Indicate if a markup or reference image is attached or linked to the request.
* **Estimated Revision Time - Hours (10)**: Estimate the time needed for the revision (to be filled in by the lead animator).
* **Deadline for Completed Revision (11)**: Set a deadline for the completed revision.

## Tips
* Please be as specific as possible when describing the required changes.
* Ensure that you have all relevant information (scene ID, shot number, etc.) to facilitate processing the request.
* If you are attaching a markup or reference image, make sure it is clear and relevant to the request.
* Revision priority and deadlines are crucial in ensuring timely and efficient processing of the request.
* If you are unsure about any field, please contact your project lead or animation department for guidance.
