# Buyout Payment Request Form - Help Guide

## Purpose
The "Buyout Payment Request Form" is used by employees or managers to submit requests for buyout payments to HR or Finance. This form gathers essential information about the request, which is then reviewed and processed accordingly.

## How To Complete This Form

1. Review the form carefully to ensure you have all necessary information and permissions before submitting.
2. Enter the required details in the designated fields.
3. Select the urgency level of the request.
4. Attach supporting documents if applicable.
5. Submit the form to HR or Finance for processing.

## Field-by-Field Explanation

* **Requestor Information**:
	+ **Requestor Name** (*Full name of the person submitting the request*)
	+ A text field to enter the full name of the person submitting the request.
* **Requestor Name for Buyout**:
	+ *Employee name whose buyout is requested*
	+ A text field to enter the name of the employee whose buyout is being requested.
* **Department**:
	+ *Department requesting the buyout*
	+ A text field to enter the department requesting the buyout.
* **Employee ID**:
	+ *Internal identifier if available*
	+ A text field to enter the employee's internal identifier if it's available.
* **Reason for Buyout**:
	+ *Explain rationale and any contractual references*
	+ A text field to enter a clear and concise explanation of the reason for the buyout.
* **Amount Requested**:
	+ *Enter numeric value in local currency*
	+ A number field to enter the exact amount requested for the buyout.
* **Effective Date**:
	+ *Date when buyout should take effect*
	+ A date field to enter the date when the buyout should be effective.
* **Supporting Documents Provided**:
	+ *List document names or paths, or state Not Applicable*
	+ A text field to list any relevant supporting documents or indicate if none are provided.
* **Approval Required From**:
	+ *Name or role of approver needed*
	+ A text field to specify the name or role of the person who needs to approve the request.
* **Urgency Level**:
	+ *Select urgency level for processing*
	+ A select-one field to choose the urgency level for the request (Routine, High, or Critical).
* **Additional Notes**:
	+ *Any further context for finance and operations*
	+ A text field for any additional information that might be helpful for finance and operations teams.

Note: This guide is designed to assist in the completion of the form, but if you're unsure about any field or process, please contact HR or Finance for guidance.
