# Rehydration Request Form - Help Guide
 
## Purpose
This form is used to collect information for rehydration requests.
 
## How To Complete This Form
To complete this form, please follow these steps:
 
1. Select the "patient_info" field to enter the patient's information.
2. Choose the rehydration type (IV or blood transfusion).
3. Select a preferred date and time for the rehydration.
4. Choose a preferred location (Clinic, Wellness Center, or Mobile IV Service).
5. Select the urgency level (High, Medium, or Low).
6. Add any additional comments or remarks.
7. Enter the patient's phone number and email address.

## Field-by-Field Explanation
* **patient_info** (patient_info, text, required/optional): Enter the patient's basic information, including name, age, and medical condition.
* **rehydration_type** (rehydration_type, select_one, required/optional): Choose the type of rehydration requested, either IV or blood transfusion.
* **preferred_date** (preferred_date, date, required/optional): Select a date for the rehydration, in YYYY-MM-DD format.
* **preferred_time** (preferred_time, time, required/optional): Select a time for the rehydration, in 24-hour format.
* **preferred_location** (preferred_location, select_multiple, required/optional): Choose a location for the rehydration, from Clinic, Wellness Center, or Mobile IV Service.
* **urgency** (urgency, select_multiple, required/optional): Select the urgency level for the rehydration, from High, Medium, or Low.
* **comments** (comments, note, required/optional): Add any additional comments or remarks about the rehydration request.
* **phone** (phone, text, required/optional): Enter the patient's phone number.
* **email** (email, email, required/optional): Enter the patient's email address.
