# Fence Request Form - Help Guide
## Purpose
The Fence Request Form is used to create and track fence requests for new fence projects. Authorized personnel should use this form to provide accurate and complete information to ensure efficient and successful fence construction.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the form completely and accurately.
2. Ensure all required fields (indicated by *) are filled out.
3. Select the correct fence type from the options provided.
4. Double-check the information for accuracy before submitting.

## Field-by-Field Explanation

* **User** (1, text, optional): Provide your name or name of the person submitting the request.
* **Contact Person** (2, text, optional): Enter the name and title of the person to contact for this fence project.
* **Contact Email** (3, email, optional): Enter the email address of the person to contact for this fence project.
* **Contact Phone** (4, text, optional): Enter the phone number of the person to contact for this fence project.
* **Fence Type** (5, select_one, optional): Select the type of fence you need (e.g., chainlink, picket, vinyl, wood, wrought).
* **Fence Height** (6, number, optional): Enter the height of the fence in feet.
* **Width** (7, number, optional): Enter the width of the fence in feet.
* **Post Type** (8, select_one, optional): Select the type of post (e.g., chain, steel, vinyl, wood).
* **Location** (9, text, optional): Enter the location of the fence project (e.g., address, site name).
* **Notes** (10, note, optional): Enter any additional information or notes about the fence project.

## Tips
- If you're unsure about any field or the form's purpose, please reach out to the contact person listed below for assistance.
- If you have already submitted a request for the same fence project, please do not submit another request.
- Ensure that the form is filled out completely and accurately to avoid delays in fence construction.
