# Virtual Reality Equipment Request Form - Help Guide
## Purpose
The Virtual Reality Equipment Request Form is a request form used to submit requests for virtual reality equipment to the IT department.

## How To Complete This Form
1. Fill in your name and email in the provided fields.
2. Specify the equipment type and model you are requesting, if known.
3. Provide the reason for requesting the equipment.
4. Choose the assigned user from the dropdown list.
5. Select the date you requested the equipment.
6. Review the form for any errors.
7. Click submit to complete the form.

## Field-by-Field Explanation

* **Virtual Reality Equipment Request Form** (1): This is the title of the form, which is used to identify the request.
* **Name** (2): Enter your name to be associated with this request.
* **Email** (3): Enter your school email to enable communication.
* **Department** (4): Enter your department to help in the equipment allocation process.
* **Equipment Type** (5): Specify the type of virtual reality equipment you need.
* **Equipment Model** (6): If known, enter the model number of the equipment you need.
* **Reason** (7): Describe the reason for requesting the equipment to help in the approval process.
* **Instructor** (8): Enter the name of the instructor requesting the equipment.
* **Student** (9): Enter the name of the student requesting the equipment.
* **Assigned** (10): Choose the user assigned to handle the request.
* **Date Requested** (11): Select the date you requested the equipment.
* **Comments** (12): Add any additional comments about your request.
* **Submit** (13): Review the form and click to submit it.
* **Cancel** (14): Review the form and click to cancel it.
* **Confirm** (15): Review the form and click to confirm it.
* **Error** (16): Displays any error messages, if present.
* **Success** (17): Displays a success message, if the form is submitted correctly.
* **User Input Error** (18): Displays any errors in user input, if present.
* **Form Not Submitter** (19): Displays a message if the form is not submitted correctly.
* **User Submitter Form** (20): Displays the submitted form.
* **Equipment Location** (21): Enter the location where the equipment will be used.
* **Requestor** (22): Enter the name of the person requesting the equipment.
* **Requestee** (23): Enter the name of the person requesting the equipment on behalf of.
* **Submitter** (24): Enter the name of the person submitting the request.
* **Date** (25): Select the date of the request.
