# Artist Backline Equipment Request Form - Help Guide

## Purpose
The Artist Backline Equipment Request Form is used to gather information about the artist's technical requirements for a performance or event.

## How To Complete This Form
1. Fill out the form with the artist's or band's name, contact person's name, contact email, and contact phone number.
2. Provide the performance or event date and time.
3. Specify the venue name and its capacity or stage size.
4. Indicate if a drum kit is required and provide additional details if necessary.
5. Check if a bass amplifier is required and specify its wattage, type, and model if applicable.
6. Check if a guitar amplifier is required and specify its wattage, type, and model if applicable.
7. Check if a keyboard or piano is required.
8. List any other instruments or equipment needed.
9. Specify any special stage setup requirements.
10. Indicate if a technical rider is attached or available.
11. Provide any special power requirements.
12. Add any additional notes or requests.

## Field-by-Field Explanation

* **Artist or Band Name** (`artist_name`, text, required): The name of the artist or band.
* **Contact Person Name** (`contact_name`, text, required): The name of the person who will be responsible for communication and coordination.
* **Contact Email** (`contact_email`, email, required): The email address of the contact person.
* **Contact Phone Number** (`contact_phone`, text, required): The phone number of the contact person.
* **Performance or Event Date** (`performance_date`, date, required): The date of the performance or event.
* **Performance Time** (`performance_time`, time, required): The time of the performance or event.
* **Venue Name** (`venue_name`, text, required): The name of the venue where the performance or event will take place.
* **Venue Capacity or Stage Size** (`venue_capacity`, text, optional): The capacity or stage size of the venue.
* **Drum Kit Required** (`drums_requested`, select_one, optional): Check if a drum kit is required.
* **Drum Kit Specifications** (`drum_details`, text, optional): Provide additional details about the drum kit, such as its size and configuration.
* **Bass Amplifier Required** (`bass_amplifier`, select_one, optional): Check if a bass amplifier is required.
* **Bass Amp Specifications** (`bass_amp_details`, text, optional): Specify the wattage, type, and model of the bass amplifier if applicable.
* **Guitar Amplifier Required** (`guitar_amplifier`, select_one, optional): Check if a guitar amplifier is required.
* **Guitar Amp Specifications** (`guitar_amp_details`, text, optional): Specify the wattage, type, and model of the guitar amplifier if applicable.
* **Keyboard or Piano Required** (`keyboards_required`, select_one, optional): Check if a keyboard or piano is required.
* **Other Instruments Needed** (`other_instruments`, text, optional): List any other instruments or equipment needed.
* **Stage Setup Requirements** (`stage_setup`, text, optional): Specify any special stage setup requirements.
* **Technical Rider Attached or Available** (`technical_rider_attached`, select_one, required): Check if a technical rider is attached or available.
* **Special Power Requirements** (`power_requirements`, text, optional): Specify any special power requirements.
* **Additional Equipment Requests or Notes** (`additional_notes`, text, optional): Provide any additional requests or notes.

Note: The technical rider is a document that outlines the artist's technical requirements, and it is expected to be attached or available for review by the production team.
