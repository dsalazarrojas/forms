# Facility Tour Request Form - Help Guide
## Purpose
The Facility Tour Request Form is a tool used by staff members to request a guided tour of a facility. This form captures essential information for the tour, ensuring that all necessary details are gathered to make the tour a success.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the "Facility Tour Request" page.
2. Fill out the "Facility" field with the name of the facility you wish to visit.
3. Choose a "Date" for the tour using the date picker.
4. Select a "Time" for the tour using the time picker.
5. Enter your "Staff Name" and "Staff Title" to ensure accurate tour scheduling.
6. Provide a brief "Purpose" for the tour to help the tour guide understand the focus of the visit.
7. Specify the "Number of Guests" attending the tour.
8. Add any necessary "Facility Equipment" for the tour guide to be aware of.
9. Indicate the "Facility Accessibility" features that the tour guide should be aware of.
10. Enter the "Staff Email" and "Staff Phone" contact information in case of last-minute changes.
11. Add any additional "Staff Note" for the tour guide's reference.
12. Enter the "Facility Address" and any other relevant details.
13. Select the "Facility Hours" of operation.
14. Add a "Facility Map" for better navigation.
15. Upload a "Facility Image" or "Facility Video" to aid in visualization.
16. Provide a "Facility Audio" description for a more immersive experience.
17. Finally, submit the form to schedule the tour.
