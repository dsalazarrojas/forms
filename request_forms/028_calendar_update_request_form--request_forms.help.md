# Calendar Update Request Form - Help Guide
## Purpose
The Calendar Update Request Form is used to update existing events or add new ones to the calendar. This form allows users to specify the type of update, event details, and any necessary information for the update.

## How To Complete This Form
To complete this form, follow these steps:

1. **Fill in your information**: Enter your name and email address in the "Requester Information" section.
2. **Choose the type of update**: Select the type of update you want to make from the "Type of Calendar Update" field.
3. **Enter event details**: Fill in the "Event Name", "Event ID" (if modifying), and "Event Location" fields.
4. **Specify new event details**: Enter the new date and time for the event in the "New Event Date" and "New Event Time" fields.
5. **Optional**: If the location is changing, select "Yes" in the "Is the Location Changing?" field.
6. **Notify attendees**: Choose whether to notify all attendees of the change.
7. **Add a reason for the update**: Provide a reason for the update in the "Reason for Update" field.
8. **Choose the urgency level**: Select the urgency level of the update from the "Urgency Level" field.

## Field-by-Field Explanation

* **Your Name**: Enter your name to associate with the request.
* **Email Address**: Enter your email address to contact you about the update.
* **Department**: This field is optional and not currently used.
* **Type of Calendar Update**: Choose the type of update you want to make:
	+ **Add Event**: Add a new event to the calendar.
	+ **Modify Event**: Modify an existing event.
	+ **Cancel Event**: Cancel an event.
	+ **Reschedule Event**: Reschedule an event.
	+ **Add Multiple Events**: Add multiple events to the calendar.
	+ **Other**: Select this option if the update is not listed.
* **Event Name**: Enter the name of the event.
* **Event ID (if modifying)**: If you are modifying an event, enter its ID.
* **Current Event Date**: Enter the current date of the event (optional).
* **Current Event Time**: Enter the current time of the event (optional).
* **New Event Date**: Enter the new date for the event.
* **New Event Time**: Enter the new time for the event.
* **Is the Location Changing?**: If the location is changing, select "Yes".
* **Event Location**: Enter the location of the event.
* **Number of Attendees**: Enter the number of attendees (optional).
* **Notify All Attendees of Change?**: Choose whether to notify all attendees of the change.
* **Reason for Update**: Provide a reason for the update.
* **Urgency Level**: Choose the urgency level of the update:
	+ **Routine**: A routine update.
	+ **Important**: An important update.
	+ **Urgent**: An urgent update.
	+ **Critical**: A critical update.
* **Is the Location Changing?**: If the location is changing, select "Yes" (if applicable).
