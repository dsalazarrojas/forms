# Distribution Group Request Form - Help Guide

## Purpose
This form is used to request a new distribution group for creating or updating forms.

## How To Complete This Form
To use this form, follow these steps:

1. **Fill in the form title** (`form_title`): Enter a brief title for your new distribution group.
2. **Select the form category** (`category`): Choose the category for your distribution group, e.g., "Distribution/Group Request" or "Request Forms".
3. **Add a description** (`description`): Provide a short description of your request.
4. **Provide output file information** (`output_file`): Enter any necessary information for outputting the form, if required.
5. **Assign a tool** (`assigned_tool`): Select the tool to be assigned to your new distribution group, e.g., "chatjimmy" or "other".
6. **Enter form ID** (`form_id`): Enter a unique ID for your new distribution group (optional).
7. **Choose form category** (`form_category`): Select the category for your distribution group, e.g., "Request Forms" or "other".
8. **Upload form file 1** (`form_filename`): Upload any associated files for your form, if required.
9. **Enter form IDs** (`form_ids`): List the IDs of other forms that should be assigned to this distribution group (optional).
10. **Upload form file 2** (`form_file`): Upload any other associated files for your form, if required.
11. **Set output filename** (`output_filename`): Enter the filename for your output file (optional).

## Field-by-Field Explanation

* **Form Title (form_title)**: A brief title for your new distribution group.
* **Category (category)**: The category for your distribution group, e.g., "Distribution/Group Request" or "Request Forms".
* **Description (description)**: A short description of your request.
* **Output File Information (output_file)**: Information for outputting the form, if required.
* **Assigned Tool (assigned_tool)**: The tool to be assigned to your new distribution group, e.g., "chatjimmy" or "other".
* **Form ID (form_id)**: A unique ID for your new distribution group (optional).
* **Form Category (form_category)**: The category for your distribution group, e.g., "Request Forms" or "other".
* **Form File 1 (form_filename)**: Upload any associated files for your form, if required.
* **Form IDs (form_ids)**: List the IDs of other forms that should be assigned to this distribution group (optional).
* **Form File 2 (form_file)**: Upload any other associated files for your form, if required.
* **Output Filename (output_filename)**: Enter the filename for your output file (optional).

Note: All fields are optional unless marked as required.
