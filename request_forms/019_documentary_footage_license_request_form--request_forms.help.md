# Documentary Footage License Request Form - Help Guide
## Purpose
This form is used to request a license for documentary footage. Please complete the form with your personal information and details about the footage you want to license.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter your First Name in the First Name field.
2. Enter your Last Name in the Last Name field.
3. Enter your Email address in the Email field.
4. Enter your Phone number in the Phone field.
5. Select the License Type that best suits your needs from the options provided.
6. Describe the Usage Purpose for which you want to use the licensed footage in the Usage Purpose field.
7. Select the Distribution channels you plan to use the licensed footage in from the options provided.
8. Enter the License Duration in the License Duration field.
9. Enter the Date Of Capture in the Date Of Capture field.
10. Enter the Date Received in the Date Received field.
11. (Optional) If you want to return the licensed footage, enter the Date Returned in the Date Returned field.
12. (Optional) Add any additional notes about your request in the Note field.

## Field-by-Field Explanation

* **First Name** (`first_name`, text, required): Enter your first name for identification purposes.
* **Last Name** (`last_name`, text, required): Enter your last name for identification purposes.
* **Email** (`email`, email, required): Enter your email address where you can be reached for communication.
* **Phone** (`phone`, text, required): Enter your phone number for contact purposes.
* **License Type** (`license_type`, select_one, required): Select the license type that best suits your needs from the options provided.
* **Usage Purpose** (`usage_purpose`, text, required): Describe the purpose for which you want to use the licensed footage.
* **Distribution** (`distribution`, select_multiple, required): Select the distribution channels you plan to use the licensed footage in from the options provided.
* **License Duration** (`license_duration`, number, required): Enter the duration for which you need the license.
* **Date Of Capture** (`date_of_capture`, date, required): Enter the date when the footage was captured.
* **Date Received** (`date_received`, date, required): Enter the date when you received the footage.
* **Date Returned** (`date_returned`, date, optional): If you want to return the licensed footage, enter the date when you plan to return it.
* **Note** (`note`, note, optional): Add any additional notes about your request.
