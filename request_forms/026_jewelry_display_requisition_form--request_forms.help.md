# Jewelry Display Requisition Form - Help Guide

## Purpose
This form is used to request the display of jewelry in an event or showcase setting. Please ensure you have read and understood the guidelines and requirements before proceeding.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the "Event Information" section with the details of the event or showcase you are requesting the display for.
2. Select the "Event Type" to indicate if the event or showcase is for a specific purpose (e.g. wedding, exhibition, etc.).
3. Enter the date of the event or showcase.
4. Enter the start and end times of the event or showcase.
5. Provide the location where the event or showcase will take place.
6. Enter the customer's information, including their name and contact details.
7. Enter the product information, including the type and description of the jewelry to be displayed.
8. Enter the jewelry information, including the specific items to be displayed.
9. Provide any additional notes or comments about the display.

## Field-by-Field Explanation
- **Event Information** (Event Information, text, required): Enter a brief description of the event or showcase, including the purpose and any relevant details.
- **Event Type** (Event Type, select_one, optional): Select the type of event or showcase this is for (e.g. wedding, exhibition, etc.).
- **Event Date** (Event Date, date, required): Enter the date of the event or showcase.
- **Start Time** (Start Time, time, required): Enter the start time of the event or showcase.
- **End Time** (End Time, time, required): Enter the end time of the event or showcase.
- **Location** (Location, text, required): Enter the address or location where the event or showcase will take place.
- **Customer Information** (Customer Information, text, required): Enter the customer's name and contact details, including phone number and email.
- **Product Information** (Product Information, text, required): Enter the type and description of the jewelry to be displayed.
- **Jewelry Information** (Jewelry Information, text, required): Enter the specific items of jewelry to be displayed.
- **Notes** (Notes, text, optional): Enter any additional comments or notes about the display.

## Tips
- Please ensure you have provided accurate and complete information to avoid any issues with the display.
- If you have any questions or need assistance, please do not hesitate to contact us.
- Please review your submission carefully before submitting to ensure it is correct.
