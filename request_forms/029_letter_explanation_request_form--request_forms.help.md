# Letter Explanation Request Form - Help Guide
## Purpose
The Letter Explanation Request Form is designed for users to request explanations and justifications for letters, providing detailed information to facilitate understanding.

## How To Complete This Form
To fill out the Letter Explanation Request Form, follow these steps:
1. Fill out the "Request Type" field with the purpose of the explanation you need (e.g., Request, Letter Explanation, or Other).
2. Enter the date you are requesting the explanation for in the "Request Date" field.
3. Provide a detailed description of the explanation you need in the "Request Description" field.
4. If necessary, fill out your contact details in the "Contact Name", "Contact Email" and "Contact Phone" fields.
5. Add your school's address, city, state, and zip code in the "School Address", "School City", "School State", and "School Zip" fields.
6. If you have any further messages or follow-up information, enter it in the "Follow-up Message" field.
7. Optionally, fill out the "Follow-up Date" field with the date for any follow-up.

## Field-by-Field Explanation
### School Id
* **School Id** (`<name>`, `number`, required/optional): This field is used to identify the school that the explanation is related to. Please fill it out if you are completing this form as part of a specific school process.

### Request Type
* **Request Type** (`<name>`, `select_one`, required): Select the type of explanation you need (e.g., Request, Letter Explanation, or Other). This will help the recipient understand the context and purpose of the explanation.

### Request Date
* **Request Date** (`<name>`, `date`, required): Enter the date for which you are requesting the explanation.

### Request Description
* **Request Description** (`<name>`, `text`, required): Provide a detailed description of the explanation you need.

### Contact Name
* **Contact Name** (`<name>`, `text`, optional): Enter your name if you want to be contacted for further information.

### Contact Email
* **Contact Email** (`<name>`, `email`, optional): Enter your email address if you want to be contacted for further information.

### Contact Phone
* **Contact Phone** (`<name>`, `text`, optional): Enter your phone number if you want to be contacted for further information.

### School Address
* **School Address** (`<name>`, `text`, optional): Enter your school's address for reference.

### School City
* **School City** (`<name>`, `text`, optional): Enter your school's city for reference.

### School State
* **School State** (`<name>`, `text`, optional): Enter your school's state for reference.

### School Zip
* **School Zip** (`<name>`, `text`, optional): Enter your school's zip code for reference.

### Follow-up Message
* **Follow-up Message** (`<name>`, `text`, optional): Enter any additional information or follow-up messages you have.

### Follow-up Date
* **Follow-up Date** (`<name>`, `date`, optional): Enter the date for any follow-up action.

Note: This form is designed to be completed in a specific context, please adjust according to your specific needs.
