# Food Culinary Referral Form - Help Guide
## Purpose
The Food Culinary Referral Form is used to collect information about food-related referrals, including contact details for the provider and the follow-up status of any contacts made.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill in the required fields, marked as "required".
2. Enter the provider's contact information (email, phone, address).
3. Select the referral type (Program, Service, Event).
4. Choose the follow-up status (New, In Progress, Closed) for each follow-up contact.
5. Enter the follow-up contact dates and methods for each contact.

## Field-by-Field Explanation
* **1. Food Culinary Referral**: This is the title of the form. It is a required field.
* **Name**: Enter the name of the person or organization making the referral. This is a required field.
* **Contact Email**: Enter the email address of the contact person. This is a required field.
* **Contact Phone**: Enter the phone number of the contact person. This is a required field.
* **Organization**: Enter the name of the organization making the referral. This is a required field.
* **Contact Address**: Enter the address of the contact person. This is a required field.
* **Referral Date**: Enter the date of the referral. This is a required field.
* **Referral Type**: Select the type of referral (Program, Service, Event). This is a required field.
* **Notes**: Optional field for any additional information about the referral.
* **Follow-up Date**: Enter the date of the follow-up contact. This is an optional field.
* **Follow-up Contact**: Enter the name or description of the follow-up contact. This is an optional field.
* **Follow-up Method**: Enter the method of the follow-up contact (e.g., phone, email, in-person). This is an optional field.
* **Follow-up Notes**: Optional field for any additional information about the follow-up contact.
* **Follow-up Status**: Select the status of the follow-up contact (New, In Progress, Closed). This is a required field.
* **Follow-up Last Contact**: These fields are for the last follow-up contact information and are optional.
	+ **Follow-up Last Contact**: Enter the name or description of the last follow-up contact.
	+ **Follow-up Last Method**: Enter the method of the last follow-up contact.
	+ **Follow-up Last Notes**: Optional field for any additional information about the last follow-up contact.
	+ **Follow-up Last Status**: Select the status of the last follow-up contact (New, In Progress, Closed).
	+ **Follow-up Last Date**: Enter the date of the last follow-up contact.
	+ **Follow-up Last Contact Method**: Enter the method of the last follow-up contact.
	+ **Follow-up Last Contact Notes**: Optional field for any additional information about the last follow-up contact.
	+ **Follow-up Last Contact Status**: Select the status of the last follow-up contact (New, In Progress, Closed).
