# theme_park_quote_request_form - Help Guide
## Purpose
The theme park quote request form is used to gather information for quotes from the theme park. This form helps us understand your event details and provide accurate pricing and availability for your event.

## How To Complete This Form

1. Fill out the form with the required information, which are marked as "required" in the form.
2. Be as detailed as possible when filling out the form to ensure your request is processed correctly.

## Field-by-Field Explanation

* **Name (Name)** (<name>, <text>, required): Please enter the name of the person submitting the request or the company representative.
* **Event Date (event_date)** (<name>, <date>, optional): If you have a specific date in mind for your event, please enter it here. If not, you can leave it blank.
* **Event Time (event_time)** (<name>, <time>, optional): If you have a specific time in mind for your event, please enter it here. If not, you can leave it blank.
* **Group Size (group_size)** (<name>, <number>, optional): If you know the expected number of attendees for your event, please enter it here. If not, you can leave it blank.
* **Email (email)** (<name>, <email>, required): Please enter the email address associated with your request.
* **Phone (phone)** (<name>, <text>, optional): If you'd like to be contacted by phone, please enter your phone number here.
* **Event Type (event_type)** (<name>, <select_multiple>, required): Select all event types that apply to your request. For example, if you're requesting a quote for a birthday party and a team building event, select both "birthday" and "team building".
* **Message (message)** (<name>, <note>, optional): Please add any additional information about your event, such as special requests or any other details that might help us process your request accurately.
