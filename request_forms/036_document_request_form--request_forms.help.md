# Document Request Form - Help Guide
## Purpose
The Document Request Form is used to submit a document request to the school administration. This form is used to request documents such as transcripts, letters, and other certificates.

## How To Complete This Form
1. Fill out the "Document Type" field by selecting the type of document you are requesting (e.g. Certificate, Transcript, Letter).
2. Enter your "Student Id" number, if applicable.
3. Provide your "Parent Name" if you are a parent or guardian requesting a document.
4. Enter your "Email" address if you have one.
5. Fill out any other required fields as prompted.

## Field-by-Field Explanation
* **Document Type** (`Document Type`, select_one, required): Select the type of document you are requesting (e.g. Certificate, Transcript, Letter).
* **School Id** (`school_id`, number, optional): Enter your student or employee ID number if you have one.
* **Student Id** (`student_id`, number, optional): Enter your student ID number if you are a student or have access to a student ID.
* **Parent Name** (`parent_name`, text, optional): Enter your name if you are a parent or guardian requesting a document.
* **Email** (`email`, email, optional): Enter your email address if you have one.
* **Document Requested Id** (`document_requested_id`, number, optional): Enter your document ID number if you have one.

## Tips
- Please ensure you have the necessary permissions to complete this form.
- Double-check your selections and entries before submitting the form.
- If you are unsure about any field, please contact your school administrator for assistance.
