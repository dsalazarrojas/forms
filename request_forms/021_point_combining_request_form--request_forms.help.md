# point_combining_request_form - Help Guide
## Purpose
The point combining request form is designed to gather information for customers to transfer points between their accounts. This form is divided into multiple pages for easy navigation and to ensure accuracy.

## How To Complete This Form
1. Navigate through the pages by clicking on the "Next" button at the end of each page.
2. Complete all required fields (marked as "True") before proceeding.
3. Review each page for any additional information or special instructions.

## Field-by-Field Explanation

* **Customer Info** (Customer Info, text, required): Enter the customer's name and other relevant information.
* **Customer Email** (Customer Email, email, required): Enter the customer's email address.
* **Transfer Points** (Transfer Points, number, required): Enter the number of points to be transferred.
* **Merge Accounts** (Merge Accounts, select_one, required): Select the account to merge or transfer points from.
* **Request Details** (Request Details, text, required): Provide a clear and concise description of the request.
* **Review Request** (Review Request, date, required): Choose a date to review the request.
* **Submit Request** (Submit Request, select_multiple, required): Confirm that the request has been submitted and is ready for review.
* **Request Notes** (Request Notes, text, required): Add any additional notes or information about the request.
* **Customer Notes** (Customer Notes, text, optional): Provide any additional notes or information from the customer.
* **Request Details 2** (Request Details 2, text, optional): Add any additional details or information.
* **Customer Email 2** (Customer Email 2, email, optional): Enter a second email address for the customer.
* **Customer Info 2** (Customer Info 2, text, optional): Enter any additional customer information.

Note: Some fields are marked as "optional," meaning they do not require completion, but providing them can help clarify the request and provide additional context.
