# Animation Questionnaire - Help Guide
## Purpose
The Animation Questionnaire is a form used to gather essential information from clients about their animation projects. This form helps us understand their specific needs, goals, and preferences for a successful project outcome. Please ensure you fill out this form accurately to enable our team to create a high-quality animation that meets your expectations.

## How To Complete This Form
To complete the form, follow these steps:
1. Provide your name and the name of the organization or company you represent.
2. Select the type of animation project you need help with.
3. Enter the desired length of the video in seconds.
4. Specify the primary target audience for the animation.
5. Define the core message or call-to-action for the animation.
6. Choose the preferred brand visual style.
7. If requested, provide a reference link to an existing video that represents the desired style.
8. Decide if a professional voiceover is required.
9. Determine if custom background music is needed.
10. (Optional) Estimate the project budget range in USD.
11. Select the desired final delivery deadline.

## Field-by-Field Explanation
* **Client or Organization Name (Page 1, 1)**: Enter your name or the name of the organization you represent.
* **Animation Project Type (Page 1, 2)**: Select the type of animation project you need help with, such as an explainer video or a social media advertisement.
* **Desired Video Length - Seconds (Page 1, 3)**: Enter the approximate duration of the video in seconds. This will help us understand the project scope.
* **Primary Target Audience (Page 1, 4)**: Specify who the animation is intended for, such as children, adults, or a specific age group.
* **Core Message or Call to Action (Page 1, 5)**: Define what action or message you want viewers to take after watching the animation.
* **Brand Visual Style Preference (Page 1, 6)**: Choose the visual style you prefer for your brand, such as minimalist or traditional.
* **Reference Link for Visual Style (Page 1, 7)**: (Optional) Provide a link to an existing video that represents your desired visual style.
* **Is a Professional Voiceover Required? (Page 1, 8)**: Decide if a professional voiceover is needed or not.
* **Is Custom Background Music Required? (Page 1, 9)**: Determine if you need custom background music or not.
* **Estimated Budget Range - USD (Page 1, 10)**: (Optional) Provide an estimated budget range for the project to help us scope it effectively.
* **Final Delivery Deadline (Page 1, 11)**: Select the desired final delivery date for the project.

Please note that some fields are optional, and you can skip them if not applicable to your project.
