# Electric Service Load Change Request - Help Guide

## Purpose
The Electric Service Load Change Request form is designed to capture information for internal purposes only. It is essential to ensure that the form is used correctly to avoid duplicate submissions and maintain data accuracy.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the "Contact Information" field with your contact details.
2. Provide a brief description of the service details in the "Service Details" field.
3. Write a clear and concise "Service Load Change Request" description in the "Service Load Change Request Description" field.
4. Confirm your contact details in the "Contact Details" field.

## Field-by-Field Explanation

* **Contact Information (form_1)**: Enter your name, email, and phone number to enable us to contact you for further information.
* **Service Details (service_details)**: Describe the service that needs to be changed or updated.
* **Service Load Change Request (form_3)**: Enter the specific details of the service load change request.
* **Service Load Change Request (form_4)**: Enter additional details about the service load change request.
* **Service Load Change Request Description (service_load_change_request_description)**: Provide a clear and concise description of the service load change request.
* **Contact Details (contact_details)**: Double-check your contact information to ensure it is accurate and up-to-date.
* **Electric Service Load Change Request (form_7)**: Enter any additional comments or notes about the service load change request.
* **Electric Service Load Change Request (electric_service_load_change_request)**: Enter any last-minute information about the service load change request.

Tips:

* Make sure to fill out all required fields to ensure that your submission is complete and accurate.
* Double-check your contact information to avoid delays or miscommunication.
* Be clear and concise in your descriptions to avoid misunderstandings.
* Do not submit duplicate submissions with the same information.
* Only authorized users should submit this form.
* This form is for internal purposes only, so please do not submit if not legitimate.
* If you have any questions or concerns, please contact us at form@gic.mx.
