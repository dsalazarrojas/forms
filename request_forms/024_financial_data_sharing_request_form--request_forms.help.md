# Financial Data Sharing Request Form - Help Guide
## Purpose
This form is used to request access to financial data. If you need access to financial data for a specific purpose, please complete this form to initiate the review process.

## How To Complete This Form
To complete this form, follow these steps:

1. Choose the correct options for each field based on your needs.
2. Ensure that you have checked "Yes" for all fields where you require access.
3. Select the appropriate time period for your request.
4. Choose the type of financial data you need access to.
5. Specify the access level you require (read, write, or edit).
6. If necessary, provide a review date for your request.
7. Finally, submit the form.

## Field-by-Field Explanation
- **finance_teams** (select_multiple, required/optional): Select all finance teams that you need access to. This will help us route your request to the correct team.
- **accounting_firms** (select_multiple, required/optional): Choose all accounting firms that you need access to. This will help us ensure that the correct firms are notified.
- **businesses** (select_multiple, required/optional): Select all businesses that you need access to. This will help us ensure that the correct businesses are notified.
- **data_purpose** (text, required/optional): Briefly describe the purpose for which you require access to the financial data.
- **time_period** (select_one, required/optional): Select the time period for which you require access to the financial data.
  - Option 1: Month
  - Option 2: Quarter
  - Option 3: Semi-annual
  - Option 4: Year
- **data_type** (select_one, required/optional): Choose the type of financial data you need access to:
  - Financial statements
  - Financial accounts
  - Financial reports
- **access_level** (select_one, required): Select the access level you require:
  - Read
  - Write
  - Edit
- **request_date** (date, required/optional): Provide the date when the data was requested. If you're unsure, choose the current date.
- **review_status** (select_one, required/optional): This field displays the status of your review. Please do not select this field.
- **review_comments** (text, required/optional): If there are any comments about your request, they will be displayed here.
  Note: This field is read-only and only updates automatically.
