# Project Endorsement Request Form - Help Guide

## Purpose
This form is designed to gather information for a project endorsement request. It is meant to help project teams provide a clear and concise request for a project endorsement, ensuring all necessary details are included in the submission.

## How To Complete This Form

To complete this form, please follow the instructions below:

1. Fill in the project details, if applicable.
2. Specify the reasons for the project endorsement request.
3. Attach any supporting documents that are relevant to the project.
4. If applicable, provide the signature of the project manager and sponsor.
5. Review the form for completeness and accuracy before submission.

## Field-by-Field Explanation

* **Project Details** (`project_details`, text, required/optional): This field is for providing an overview of the project, including its title, objective, and scope.
* **Reasons for Request** (`reasons_for_request`, text, required/optional): This field is for explaining the reasons and motivations behind the project endorsement request.
* **Supporting Documents** (`supporting_documents`, text, required/optional): This field is for attaching any relevant documents that support the project, such as images, videos, or PDFs.
* **Manager Signature** (`manager_signature`, text, required/optional): If applicable, this field is for providing the signature of the project manager, indicating their endorsement or approval.
* **Sponsor Signature** (`sponsor_signature`, text, required/optional): If applicable, this field is for providing the signature of the project sponsor, indicating their endorsement or approval.
* **Board Review** (`board_review`, text, required/optional): This field is for providing an overview of the board review process, if applicable.

## Tips

- Make sure to fill out all required fields, including project details and reasons for request.
- Attach any relevant supporting documents to enhance the submission.
- If a field is not applicable, please leave it blank or indicate that it is not relevant.
- Review the form carefully before submission to ensure accuracy and completeness.
- If you have any questions or concerns, contact [form@gic.mx](mailto:form@gic.mx).
