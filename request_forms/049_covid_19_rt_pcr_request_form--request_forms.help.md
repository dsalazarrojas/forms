# COVID 19 RT PCR Request Form - Help Guide

## Purpose
The form is designed to gather relevant information to facilitate the testing process for COVID-19.

## How To Complete This Form
To complete this form, please follow the instructions below. Each section is designed to help us gather specific information necessary for testing.

## Field-by-Field Explanation

* **Full Name** (2): Please enter the full name of the patient as it appears on their government-issued ID or medical record.
* **Medical Record Number** (3): If available, provide the patient's medical record number to help us expedite the testing process.
* **Date of Birth** (4): Enter the patient's date of birth in the format MM/DD/YYYY.
* **Age** (5): Enter the patient's age in years.
* **Email Address** (6): Enter the patient's email address to receive test results and updates.
* **Phone Number** (7): Enter the patient's phone number to receive test results and updates.
* **Reason for RT-PCR Test** (9): Choose the reason for the test from the provided options. If none of the options apply, select "Other" and describe the reason in the "Reason for Test" text field.
* **Date Symptoms Started** (10): If the patient is symptomatic, enter the date their symptoms started.
* **Current Symptoms** (11): Select all current symptoms the patient is experiencing.
* **Preferred Test Date** (13): Choose a date for the test, taking into account the urgency of the test (as specified in the next field).
* **Urgent Testing Needed?** (14): If the patient requires urgent testing, select "Yes" to expedite the testing process.
* **Previous COVID-19 Test Result** (16): If the patient has had a previous COVID-19 test, select the result.
* **Date of Previous Test** (17): If the patient has had a previous test, enter the date of the test.
* **Previous COVID-19 Diagnosis** (18): If the patient has been previously diagnosed with COVID-19, select "True".
* **Vaccination Status** (19): Select the patient's current vaccination status.
* **Preferred Testing Location** (21): If desired, select the preferred testing location.
* **How Would You Prefer to Receive Results?** (22): Choose how you would like to receive test results.
* **Request Submission Date** (23): The date this request was submitted.
