# Refund Reasons For Social Contributions - Help Guide
## Purpose
This form is used to request a refund for social contributions. It is intended for employees who have made contributions and are seeking a refund due to specific reasons such as incorrect or incomplete information, changes in circumstances, or other valid reasons.

## How To Complete This Form
1. Review the form carefully and fill out the required fields.
2. Select the applicable contribution reason from the options provided.
3. Fill out the additional details field if necessary.
4. Choose the correct employee and department from the options provided.
5. Select the date of refund.
6. Indicate if you want an email notification for the refund.
7. Leave any comments or submission comments if necessary.

## Field-by-Field Explanation

* **General Information** (general_information, text, optional): This field is used to capture any additional information about your request.
* **Contribution Reasons** (contribution_reasons, select multiple, optional): Select one or more reasons for your contribution refund. Please choose from the provided options.
* **Additional Details** (additional_details, text, optional): Use this field to provide more details about your request.
* **Employee Name** (employee_name, select one, optional): Please select the name of the employee who made the contribution.
* **Department** (department, select one, optional): Choose the department the employee belongs to.
* **Date of Refund** (date_of_refund, date, optional): Select the date for the refund.
* **Reason for Refund** (reason_for_refund, text, optional): Use this field to provide an explanation for the refund request.
* **Total Amount** (total_amount, number, optional): Input the total amount to be refunded.
* **Email Notification** (email_notification, select one, optional): Check this box if you want to receive an email notification for the refund.
* **Comments** (comments, text, optional): Leave any additional comments or notes.
* **Submission Comments** (submission_comments, text, optional): Add any comments related to your submission.
* **Attachment** (attachment, text, optional): Upload any supporting files or documents.
