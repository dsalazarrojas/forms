An Engineering Drawing Extension Line Reference Form is a request for a drawing extension that requires additional details, comments, and attachments for review and approval. To ensure the form is properly filled out and submitted, please review the following steps and explanations.

## Purpose
The Engineering Drawing Extension Line Reference Form is a request used to gather information and supporting materials for drawing extensions.

## How To Complete This Form
To complete this form, please follow these steps:

1. Select the correct Requestor Information, such as Requestor, Engineer, Drafter, Manager, Other, or Not Specified.
2. Enter the Drawing Info, such as the drawing details and specifications.
3. Enter the Drawing Number, which is the unique identifier for the drawing.
4. Provide Change Info, describing the specific changes requested.
5. Upload any relevant Supporting Files, which can be attachments or links to external documents.
6. Select the status of the request, which can be Accept, Reject, or Conditional.
7. Choose the Assigned User, which can be chatjimmy, engineering, drafting, other, or not-assigned.
8. Select the Due Date for the request.
9. Enter the Created-By and Updated-By fields, which are automatically populated with the current user's information.
10. Enter the Created-At and Updated-At fields, which display the current date and time.
