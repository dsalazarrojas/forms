# New Hardware Request - Help Guide
## Purpose
This form is used to submit a request for new hardware. Please provide all necessary information to ensure that your request is processed correctly.

## How To Complete This Form
To complete this form, follow these steps:

1. Choose the type of request you are submitting (damaged, outdated, or new hardware).
2. Provide a clear description of the hardware you are requesting.
3. Enter the name of the hardware you are requesting.
4. Enter the part number of the hardware you are requesting.
5. Specify the quantity of hardware you require.
6. Enter your name.
7. Enter your organization's name (if applicable).
8. Enter your email address.

## Field-by-Field Explanation
* **Request Type** (`request_type`, select_one, required: false):
	+ Choose the type of request you are submitting (damaged, outdated, or new hardware).
* **Reason for Request** (`reason_for_request`, text, required: false):
	+ Provide a brief description of why you are requesting new hardware.
* **Hardware Description** (`hardware_description`, text, required: false):
	+ Enter a detailed description of the hardware you are requesting.
* **Hardware Name** (`hardware_name`, text, required: false):
	+ Enter the name of the hardware you are requesting.
* **Hardware Part Number** (`hardware_part_number`, text, required: false):
	+ Enter the part number of the hardware you are requesting.
* **Quantity Requested** (`quantity_requested`, number, required: false):
	+ Specify the quantity of hardware you require.
* **Requestor Name** (`requestor_name`, text, required: false):
	+ Enter your name.
* **Organization** (`organization`, text, required: false):
	+ Enter your organization's name (if applicable).
* **Requestor Email** (`requestor_email`, email, required: false):
	+ Enter your email address.

## Tips
* Please ensure that your request is for a specific, concrete hardware item.
* If you are requesting multiple quantities of hardware, provide separate requests for each quantity.
* If you are unsure about any of the fields, please consult with your supervisor or the IT department.
* This form is for new hardware requests only; for hardware maintenance, repair, or upgrade requests, please use the relevant maintenance, repair, or upgrade forms.
