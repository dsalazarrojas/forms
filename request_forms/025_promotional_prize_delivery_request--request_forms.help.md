# promotional_prize_delivery_request - Help Guide

## Purpose
This form is used to submit a request to deliver a promotional prize or gift to a winner. It captures details about the winner, the prize, and the shipping information.

## How To Complete This Form

1. Fill in the required fields (marked as required).
2. Enter any additional information as needed.

## Field-by-Field Explanation

* **Winner Details** (`Winner Details`, text, required/optional): Enter the winner's name.
* **Name** (`Name`, text, required/optional): Enter the winner's name.
* **Shipping** (`Shipping`, select_multiple, required/optional): Select the shipping option (Yes/No).
* **Address** (`Address`, note, required/optional): Enter the winner's address.
* **Phone Number** (`Phone Number`, text, required/optional): Enter the winner's phone number.
* **Email** (`Email`, email, required/optional): Enter the winner's email.
* **Postal Code** (`Postal Code`, text, required/optional): Enter the winner's postal code.
* **Prize Details** (`Prize Details`, text, required/optional): Enter the prize details.
* **Prize Name** (`Prize Name`, text, required/optional): Enter the prize name.
* **Prize Type** (`Prize Type`, text, required/optional): Enter the prize type.
* **Prize Image** (`Prize Image`, text, required/optional): Enter the prize image.
* **Message** (`Message`, text, required/optional): Enter any additional message.
* **Additional Notes** (`Additional Notes`, note, required/optional): Enter any additional notes.
* **Winner Status** (`Winner Status`, select_one, required/optional): Select the winner status (Active/Inactive/Pending).
* **Shipping Method** (`Shipping Method`, select_one, required/optional): Select the shipping method (Standard Shipping/Express Shipping/Courier Shipping).
* **Shipping Address** (`Shipping Address`, text, required/optional): Enter the shipping address.
* **Shipping City** (`Shipping City`, text, required/optional): Enter the shipping city.
* **Shipping Postal Code** (`Shipping Postal Code`, text, required/optional): Enter the shipping postal code.
* **Shipping Country** (`Shipping Country`, text, required/optional): Enter the shipping country.
* **Shipping Province** (`Shipping Province`, text, required/optional): Enter the shipping province.
* **Shipping Postal Code 2** (`Shipping Postal Code 2`, text, required/optional): Enter the shipping postal code 2.
* **Shipping City 2** (`Shipping City 2`, text, required/optional): Enter the shipping city 2.
* **Shipping State** (`Shipping State`, text, required/optional): Enter the shipping state.
* **Shipping Country 2** (`Shipping Country 2`, text, required/optional): Enter the shipping country 2.
* **Shipping Instructions** (`Shipping Instructions`, note, required/optional): Enter any shipping instructions.
