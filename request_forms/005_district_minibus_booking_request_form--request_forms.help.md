# District Minibus Booking Request Form - Help Guide
## Purpose
The District Minibus Booking Request Form is used to request a minibus for a specific date and time, with the option to specify a contact person, location, and other details. This form helps to streamline the process of booking and managing minibus services.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the pickup date and time of the minibus booking.
2. Enter the pickup location where the minibus will depart from.
3. Enter the dropoff location where the minibus will arrive.
4. Provide contact information for the person responsible for the booking.
5. Select the minibus capacity required for the booking (10-50 passengers).
6. Choose which tool is assigned to manage the minibus booking.
7. Select the category and description of the request (if applicable).
8. Choose the user or users who will be assigned to manage the minibus booking (if applicable).

## Field-by-Field Explanation

* **Request Details (id: 1)**: Enter a brief description of the minibus request.
* **Pickup Date (id: 2)**: Enter the date when the minibus is needed.
* **Pickup Time (id: 3)**: Enter the time when the minibus is needed to pick up.
* **Pickup Location (id: 4)**: Enter the location where the minibus will depart from.
* **Dropoff Location (id: 5)**: Enter the location where the minibus will arrive.
* **Contact Person (id: 6)**: Enter the name and contact information of the person responsible for the booking.
* **Contact Number (id: 7)**: Enter the contact number of the person responsible for the booking.
* **Minibus Capacity (id: 8)**: Select the number of passengers that the minibus can accommodate (10-50).
* **Additional Details (id: 9)**: Enter any additional information or notes about the minibus booking.
* **Assigned Tool (id: 10)**: Select the tool or system used to manage the minibus booking.
* **Category (id: 11)**: Enter the category of the minibus request (if applicable).
* **Description (id: 12)**: Enter a brief description of the minibus request (if applicable).
* **Assigned User (id: 13)**: Select the user or users who will be assigned to manage the minibus booking (if applicable).
* **Form ID (id: 14)**: Enter a unique ID for the minibus booking request (if applicable).
* **Category (id: 15)**: Select the category for the minibus request (if applicable).

## Tips

* Make sure to provide accurate and complete information to ensure that the minibus booking is properly managed.
* Double-check the pickup and dropoff locations to ensure that the minibus can navigate to these locations.
* Enter a brief description of the minibus request to help with tracking and reporting purposes.
* Select the correct tool or system used to manage the minibus booking.
* Ensure that the minibus capacity is selected according to the number of passengers expected.
