# Gaming Equipment Calibration Request Form - Help Guide
## Purpose
The purpose of this form is to request calibration for gaming equipment. Please use this form to submit a request for calibration, providing as much detail as possible about the issue with the equipment.

## How To Complete This Form

To complete this form, please follow these steps:

1. Enter the game ID, which is a unique identifier for the game where the equipment is currently located.
2. Enter your name, which will be used to identify who is submitting the request.
3. Select the type of equipment that requires calibration.
4. Enter the serial number of the equipment.
5. Choose a date and time for when the equipment was last used or is currently experiencing issues.
6. Describe the issue with the equipment in the "Issue Description" field.
7. Evaluate the current condition of the equipment.
8. Select whether the calibration is completed, in progress, or not started.
9. Add any additional notes about the equipment or calibration request.
10. Enter your email address and phone number so that we can contact you for further information.

## Field-by-Field Explanation

* **Game Id**: A unique identifier for the game where the equipment is currently located.
* **User Name**: Please enter your name so we can identify who is submitting the request.
* **Equipment Type**: Select the type of equipment that requires calibration.
	+ Equipment Type 1
	+ Equipment Type 2
	+ Equipment Type 3
* **Serial Number**: Enter the serial number of the equipment.
* **Date**: Enter the date when the equipment was last used or is currently experiencing issues.
* **Time**: Enter the time when the equipment was last used or is currently experiencing issues.
* **Issue Description**: Describe the issue with the equipment in this field.
* **Equipment Condition**: Evaluate the current condition of the equipment.
	+ Good
	+ Fair
	+ Poor
* **Calibration Status**: Select whether the calibration is completed, in progress, or not started.
	+ Completed
	+ In Progress
	+ Not Started
* **Notes**: Add any additional notes about the equipment or calibration request.
* **Email**: Enter your email address so we can contact you for further information.
* **Phone Number**: Enter your phone number so we can contact you for further information.

## Tips

* Please provide as much detail as possible about the issue with the equipment.
* If you are unsure about any field, please contact us for clarification.
* If you are submitting this form multiple times for the same game or equipment, please note that it may be considered spam and will be addressed accordingly.
