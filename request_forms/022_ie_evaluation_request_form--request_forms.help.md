# IE Evaluation Request Form - Help Guide
## Purpose
The IE Evaluation Request Form is used to request evaluations for students, teams, or schools. This form collects necessary information to facilitate the evaluation process.

## How To Complete This Form
1. Fill out the form completely and accurately.
2. Ensure all required fields are filled out.
3. Review the form for any errors before submitting.

## Field-by-Field Explanation

* **School ID** (`school_id`, number, required): Enter the unique identifier for the school.
* **Student Name** (`student_name`, text, required): Enter the name of the student being evaluated.
* **Team Name** (`team_name`, text, required): Enter the name of the team being evaluated.
* **Date Prophets** (`date_prophets`, date, required): Select the date of the evaluation.
* **Evaluation Date** (`evaluation_date`, date, required): Select the date of the evaluation.
* **Evaluation Method** (`evaluation_method`, select_one, required): Choose the method of evaluation (Parent-Teacher, Teacher, Counselor, or Other).
* **Evaluation Location** (`evaluation_location`, select_one, required): Choose the location of the evaluation (Classroom, Office, or Other).
* **Evaluation Result** (`evaluation_result`, select_multiple, required): Select the result of the evaluation (Pass, Fail, or Needs Improvement).
* **School ID 2** (`school_id2`, number, optional): Enter the second school ID (if applicable).
* **Team ID** (`team_id`, select_multiple, optional): Select the team ID (Yes or No).
* **Evaluation Comments** (`evaluation_comments`, note, required): Enter comments about the evaluation.
* **Evaluation Requester** (`evaluation_requester`, select_one, required): Choose who made the request (Parent, Teacher, or School).
* **Follow-up** (`follow_up`, time, required): Set a follow-up time.
* **Evaluation Requester 2** (`evaluation_requester2`, select_one, optional): Choose who made the request (Parent, Teacher, or School).
* **Follow-up 2** (`follow_up2`, time, optional): Set a follow-up time.
* **Evaluation Requester 3** (`evaluation_requester3`, select_one, optional): Choose who made the request (Yes or No).
* **Team ID 2** (`team_id2`, select_multiple, optional): Select the team ID (Yes or No).
* **School ID 3** (`school_id3`, number, optional): Enter the third school ID (if applicable).
* **Follow-up 3** (`follow_up3`, time, optional): Set a follow-up time.
* **Evaluation Requester 4** (`evaluation_requester4`, select_one, optional): Choose who made the request (Yes or No).
* **School ID 4** (`school_id4`, number, optional): Enter the fourth school ID (if applicable).
* **School ID 5** (`school_id5`, number, optional): Enter the fifth school ID (if applicable).
* **School ID 6** (`school_id6`, number, optional): Enter the sixth school ID (if applicable).
* **School ID 7** (`school_id7`, number, optional): Enter the seventh school ID (if applicable).
* **School ID 8** (`school_id8`, number, optional): Enter the eighth school ID (if applicable).

## Tips

* Make sure to review the form carefully before submitting to ensure all required fields are filled out.
* If you're unsure about any field, consult with the evaluation team or form administrator.
* Double-check the dates and locations to ensure accuracy.
* Keep the evaluation comments clear and concise for efficient evaluation.
