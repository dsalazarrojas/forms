# Pedagogical Storytelling Resource Request Form - Help Guide
## Purpose
The Pedagogical Storytelling Resource Request Form is designed to help educators discover and access pedagogical resources that match their needs. To use this form effectively, follow the steps below.

## How To Complete This Form
* Please fill out this form with the required information, ensuring that all fields are accurate and complete.
* You can choose from the resource types offered at the bottom of the form (e.g., Book, Video, Website, Podcast).
* If you have additional contact information, such as an email address or phone number, please provide it to facilitate communication.

## Field-by-Field Explanation
* **Request Form** (`request_form`, text, optional): A brief description of the pedagogical resource you are looking for. This could be a specific topic, subject area, or learning objective.
* **Educator Info** (`educator_info`, text, optional): Some information about the educator submitting this form, such as their name and department. This will help us tailor the resource recommendation to their specific needs.
* **Resource Type** (`resource_type`, select_one, optional): Select the type of resource you are looking for:
	+ Book
	+ Video
	+ Website
	+ Podcast
* **Resource Link** (`resource_link`, text, optional): If you know the URL of the resource, please provide it. This will help us find the exact resource you are looking for.
* **Email** (`email`, email, optional): Your email address or the email address of the person submitting this form. This will help us contact you with resource recommendations or updates.
* **Phone** (`phone`, text, optional): Your phone number or the phone number of the person submitting this form. This will help us contact you with resource recommendations or updates.
* **Request Message** (`request_message`, text, optional): Any additional information you would like to provide about your resource request. This could include specific learning objectives, age range, or other details that will help us find the best resource for you.
* **Submit** (`submit_button`, text, optional): Please submit your request to start the resource discovery process.

## Tips
* Be as specific as possible when describing the resource you are looking for.
* If you have any questions or need help with your resource request, please contact your pedagogical resource manager.
