# Film Equipment Setup Request Form - Help Guide
## Purpose
This form is used to request film equipment setup for a specific shoot date, location, and contact information.

## How To Complete This Form
To complete this form, you will need to fill out each field with the required information. Here's a field-by-field explanation of each section:

## Field-by-Field Explanation
* **Location**: Enter the location where the equipment will be used (e.g., studio, park, etc.).
* **Shoot Date**: Enter the date of the shoot (in YYYY-MM-DD format).
* **Start Time**: Enter the start time of the shoot (in 24-hour format, e.g., 09:00).
* **End Time**: Enter the end time of the shoot (in 24-hour format, e.g., 18:00).
* **Location Description**: Enter a brief description of the location (e.g., outdoor, indoor, etc.).
* **Equipment Needed**: Select all the equipment types required for the shoot (e.g., Camera, Lenses, Lighting, etc.).
* **Contact Name**: Enter the name of the contact person.
* **Contact Email**: Enter the email address of the contact person.
* **Contact Number**: Enter the phone number of the contact person.
* **Notes**: Enter any additional notes or comments about the request.
* **Submitted By**: Select who is submitting the request (e.g., User, Manager, Team, etc.).
* **Submitted To**: Select who the request is being submitted to (e.g., Production Team, Client, Manager, etc.).
* **Submitted At**: Enter the date and time the request was submitted (in YYYY-MM-DD format).
* **Equipment Type**: Select the type of equipment required (e.g., Film, Television, Commercial, etc.).
* **Equipment Model**: Enter the model of the equipment required (e.g., camera model, lens type, etc.).
* **Equipment Size**: Enter the size or quantity of the equipment required.
* **Submitted By Label**: This field is not required and is for internal use.
* **Submitted To Label**: This field is not required and is for internal use.
* **Submitted At Label**: This field is not required and is for internal use.
* **Submitted By Name**: This field is not required and is for internal use.
