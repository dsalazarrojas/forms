# Event Video Request Form - Help Guide
## Purpose
The Event Video Request Form is used to collect information from clients about their video requests for events. This form helps the company keep track of video requests and ensures that all necessary information is captured before proceeding with the request.

## How To Complete This Form
To complete the form, follow these steps:

* Enter the client's details in the "Client Details" field.
* Provide the event details in the "Event Details" field.
* Select the type of broadcast (Live or Pre-Recorded) from the "Broadcast Type" dropdown.
* Select the status of the request (New, In Progress, or Done) from the "Request Status" dropdown.
* (Optional) Provide any additional comments from the client in the "Client Comment" field.

## Field-by-Field Explanation
* **Client Details** (`title`, `text`, required): Enter the client's name, company, and any other relevant details.
* **Event Details** (`title`, `text`, required): Provide a brief description of the event, including the date and any other important details.
* **Broadcast Type** (`title`, `select_one`, required): Select either "Live" or "Pre-Recorded" to indicate the type of broadcast the client is requesting.
* **Request Status** (`title`, `select_multiple`, required): Select all that apply from the following options: "New", "In Progress", "Done".
* **Client Comment** (`title`, `text`, optional): Provide any additional comments from the client, such as specific requirements or preferences.

## Tips
* Ensure that you are not requesting a video for an event that has already been recorded or is no longer active.
* If the event is part of a recurring series, please provide the specific date of the event you are requesting a video for.
* If you have any questions or concerns, please contact [form@gic.mx](mailto:form@gic.mx).
