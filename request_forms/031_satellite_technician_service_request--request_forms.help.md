# Satellite Technician Service Request - Help Guide
## Purpose
The Satellite Technician Service Request form is used to collect information from customers to schedule and complete service requests for satellite technician visits.

## How To Complete This Form
1. Please fill out the form accurately and completely.
2. Ensure all required fields are completed.
3. Select the correct options for each field where applicable.
4. If you have any questions or concerns, do not hesitate to contact the satellite department.

## Field-by-Field Explanation
* **Customer Details** (`customer_details`, text, required/optional): This field is used to collect the customer's details, such as name and address. Please provide the customer's name and address as per their official records.
* **Appointment Date** (`appointment_date`, date, required/optional): This field is used to schedule the appointment date for the satellite technician visit. Please select the date and time that best suits the customer's schedule.
* **Technician Name** (`technician_name`, text, required/optional): This field is used to select the technician who will perform the service request. Please select the technician's name from the provided list.
* **Customer Name** (`customer_name`, text, required/optional): This field is used to confirm the customer's name. Please ensure that it matches the customer's official name.
* **Customer Address** (`customer_address`, text, required/optional): This field is used to confirm the customer's address. Please provide the customer's official address.
* **Service Request Details** (`service_request_details`, text, required/optional): This field is used to describe the service request. Please provide a clear and concise description of the issue.
* **Scheduled Date** (`scheduled_date`, date, required/optional): This field is used to schedule the appointment date for the satellite technician visit. Please select the date and time that best suits the customer's schedule.
* **Scheduled Time** (`scheduled_time`, time, required/optional): This field is used to schedule the appointment time for the satellite technician visit. Please select the time of day that best suits the customer's schedule.
* **Technician Confirmation** (`technician_confirmation`, select_one, required/optional): This field is used to confirm the technician's availability. Please select "Accept" if the technician can perform the service request, or "Decline" if they are not available.
* **Customer Confirmation** (`customer_confirmation`, select_one, required/optional): This field is used to confirm the customer's acceptance of the scheduled appointment. Please select "Accept" if the customer accepts the appointment, or "Decline" if they are not available.
* **Form Comments** (`form_comments`, note, required/optional): This field is used to leave any additional comments about the service request. Please provide any relevant information about the request.
* **Email** (`email`, email, required/optional): This field is used to capture the customer's email address. Please provide the customer's official email address.
* **Phone** (`phone`, text, required/optional): This field is used to capture the customer's phone number. Please provide the customer's official phone number.

Note: This form is designed to be completed by customers, not by satellite technicians or other staff members. If you are not a customer, please do not complete this form.
