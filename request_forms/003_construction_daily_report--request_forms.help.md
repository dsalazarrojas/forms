# Construction Daily Report - Help Guide
## Purpose
The Construction Daily Report is a crucial document that provides a snapshot of the construction site's daily activities and conditions. It ensures that all relevant stakeholders have access to up-to-date information, facilitating better project planning and management.
## How To Complete This Form
1. Ensure that you have access to the necessary information and data for each field before starting to fill out the form.
2. Read through each section carefully and provide accurate answers to each question.
3. Fill out all required fields as indicated by the "Required" label.
4. Use the available hints to guide you in filling out each field accurately.
5. Double-check your responses before submitting the form.

## Field-by-Field Explanation
* **Project Name** (`project_name`, text, Required): Enter the name of the project you are currently working on.
* **Date of Report** (`report_date`, date, Required): Enter the date of the report in the format `mm/dd/yyyy`.
* **Reported By** (`report_by`, text, Required): Enter your name as the person filing this report.
* **Morning Weather** (`weather_am`, select_one, Required): Choose the correct weather condition that best describes the morning conditions.
* **Afternoon Weather** (`weather_pm`, select_one, Required): Choose the correct weather condition that best describes the afternoon conditions.
* **Average Temperature (F)** (`site_temperature`, number, Optional): Enter the average temperature on site in degrees Fahrenheit.
* **Total Number of Workers on Site** (`total_workers`, number, Required): Enter the total number of workers on site, including subcontractors.
* **Total Man-Hours Spent Today** (`total_man_hours`, number, Required): Enter the total number of hours spent on site today.
* **Subcontractors Present** (`subcontractors_present`, text, Optional): List any subcontractors who were on site today.
* **Activities Completed Today** (`activities_completed`, text, Required): List the major milestones or tasks finished today.
* **Delays or Issues Encountered** (`delays_or_issues`, text, Optional): Describe any weather, material shortages, equipment failure, etc.
* **Safety Incidents or Concerns** (`safety_incidents`, text, Required): Describe any incidents or near-misses that occurred.
* **Inspection Results** (`inspection_results`, select_one, Required): Choose the correct outcome of any official inspections conducted today.
* **Plan for Tomorrow** (`tomorrow_plan`, text, Required): Key objectives for the next shift.
* **General Observations or Notes** (`additional_notes`, text, Optional): Enter any general observations or notes about the site.
