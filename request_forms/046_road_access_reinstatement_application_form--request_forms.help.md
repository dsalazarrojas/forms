# Road Access Reinstatement Application Form - Help Guide
## Purpose
The Road Access Reinstatement Application Form is used to gather details about a road access reinstatement project. Please submit this form to inform us about your project so we can assist you better.

## How To Complete This Form
To complete this form, simply answer each field according to your project's details. Please ensure you fill out all the required fields. We will review your submission to provide you with the necessary assistance.

## Field-by-Field Explanation

* **Project Details** (`project_details`, `text`, required: false): Describe your project in a few sentences, including the project's name, location, and relevant details.
* **Schedule** (`schedule`, `date`, required: false): Select the expected project start and end dates.
* **Permits** (`permits`, `select_one`, required: false): Indicate if any permits are required for your project (Yes or No).
* **Restoration Requests** (`restoration_requests`, `select_multiple`, required: false): Check off any restoration requests you have for the project (Yes or No).
* **Contractors Involved** (`contractors_involved`, `select_multiple`, required: false): Check off the contractors involved in your project (Yes or No).
 
## Tips
- Please ensure you complete this form only once for each project.
- Double-check your answers to ensure you have provided accurate information.
- If you are unsure about any field, please contact us and we will be happy to assist you.
