# nursing_home_room_change_form_template - Help Guide
## Purpose
The nursing home room change form is used to record and manage resident room changes. This form collects essential information about the move, ensuring a smooth transition for residents.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the resident's name in the "resident_name" field.
2. Indicate the current room the resident is moving from.
3. Specify the new room the resident is moving to.
4. Provide a brief reason for the move.
5. Enter the date and time of the move.

## Field-by-Field Explanation
* **move_request**: Enter a description of the move request.
* **resident_name**: Enter the name of the resident moving.
* **current_room**: Specify the room number or name of the current room the resident is occupying.
* **new_room**: Specify the room number or name of the new room the resident is moving to.
* **reason_for_move**: Provide a brief explanation for the move (e.g., medical, personal, etc.).
* **date_of_move**: Enter the date of the move in the format (e.g., MM/DD/YYYY).
* **time_of_move**: Enter the time of the move (e.g., 14:00).

## Tips
* Make sure to capture all necessary details to ensure accurate record-keeping.
* Double-check the form before submitting to avoid errors.
* Use this form for new room change requests only.
