# Image Annotation Request Form - Help Guide
## Purpose
The Image Annotation Request Form is used to collect information for image annotation projects, which involve annotating or labeling images to prepare them for use in artificial intelligence, machine learning, or other applications.

## How To Complete This Form
To complete this form, follow these steps:
1. Select the uploads option that best fits your project needs.
2. Specify the requirements for the project, if any (optional).
3. Enter the deadline for submitting the project (required).
4. Indicate whether team managers are involved in the project.
5. Identify the vendors involved in the project (if any).
6. Enter the submission form number (if required by the client).
7. Enter the deadline for submitting the submission form.
8. Enter your name and other information as prompted by the "Submitted by" field.

## Field-by-Field Explanation

* **Uploads** (uploads, select multiple, required/optional): This field allows you to choose whether your project requires any uploads. Please select "Yes" if you plan to upload images for annotation.
* **Requirements** (requirements, text, optional): If your project has any specific requirements, please provide a brief explanation of what they are. This field is optional and will help the client understand the scope of your project.
* **Deadlines** (deadlines, date, required): Enter the date by which you plan to submit the project. This is a required field.
* **Team Managers** (team_managers, select one, optional): If team managers are involved in your project, please select "Yes".
* **Vendors** (vendors, select multiple, optional): If your project involves any vendors, please select "Yes" for each one.
* **Submission form** (submission_form, number, optional): If your client requires a submission form, please enter the number.
* **Submission deadline** (submission_deadline, date, optional): If you need to submit a submission form, enter the deadline for it.
* **Submitted by** (submitted_by, text, required): This field is where you enter your name and any other information as required by the client.
