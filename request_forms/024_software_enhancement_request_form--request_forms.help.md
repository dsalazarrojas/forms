# Software Enhancement Request Form - Help Guide
## Purpose
The Software Enhancement Request Form is used to collect information about the software enhancements or improvements requested by customers. This form helps our team to better understand the customer's needs and prioritize the enhancements accordingly.

## How To Complete This Form
To complete this form, please follow these steps:

*   Fill in your name and email address in the "Customer Name" and "Customer Email" fields.
*   Select the type of project you are working on from the "Project Type" dropdown menu.
*   Choose the type of request you are making from the "Request Type" dropdown menu.
*   Provide a detailed description of your enhancement request in the "Description" field.
*   If you have any suggestions or comments, please include them in the "Suggestion" field.
*   You can add any additional comments in the "Comment" field.

## Field-by-Field Explanation

*   *Customer Name* (`customer_name`, text, not required): Enter your name in this field.
*   *Project Type* (`project_type`, select_one, not required): Select the type of project you are working on.
    -   Options: Software Development, Other
*   *Customer Email* (`customer_email`, email, not required): Enter your email address in this format: `customer@example.com`.
*   *Customer Phone* (`customer_phone`, text, not required): Enter your phone number in this format: `123-456-7890`.
*   *Request Type* (`request_type`, select_one, not required): Choose the type of request you are making.
    -   Options: Bug Fix, Feature Request, Product Feedback
*   *Description* (`description`, text, not required): Provide a detailed description of your enhancement request.
*   *Suggestion* (`suggestion`, text, not required): If you have any suggestions, please include them here.
*   *Comment* (`comment`, text, not required): You can add any additional comments or notes here.
*   *Customer Comment* (`customer_comment`, text, not required): You can add any additional comments or notes here.
*   *Assigned Tool* (`assigned_tool`, select_one, not required): Select the tool assigned to this request.
