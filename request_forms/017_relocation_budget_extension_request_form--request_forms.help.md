# Relocation Budget Extension Request Form - Help Guide

## Purpose
This form is designed to help employees who are requesting a budget extension for relocation purposes. The form is used to gather information about the requested budget extension and ensure that all relevant details are provided in a structured and organized manner.

## How To Complete This Form

To complete this form, please follow these steps:

1. Fill out the **Request Form** (Page 1) with the required information.
2. Provide detailed **Request Details** (Page 2) about the requested budget extension, including any relevant context and supporting documents.
3. Enter the **Manager Approval** (Page 3) information, which will be reviewed and approved by your manager.

## Field-by-Field Explanation

* **Request Form (Page 1)**: A brief description of the request.
	+ Label: Request Form
	+ Type: Text
	+ Required: False
* **Request Details (Page 2)**: A detailed explanation of the requested budget extension.
	+ Label: Request Details
	+ Type: Text
	+ Required: False
* **Manager Approval (Page 3)**: The manager's approval or rejection of the request.
	+ Label: Manager Approval
	+ Type: Text
	+ Required: False

## Tips

* Please provide as much detail as possible in the **Request Details** field to ensure that your manager has a clear understanding of your request.
* If you are unsure about any information or have questions, please reach out to your manager or HR department for clarification.
* Make sure to sign and date the form to confirm that you have read and understood the terms of the budget extension request.
