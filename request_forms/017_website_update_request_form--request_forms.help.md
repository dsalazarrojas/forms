# Website Update Request Form - Help Guide
## Purpose
The website update request form is designed to gather information from users for website updates. This form is used to collect details about the user, the type of update requested, and the agency involved.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out your user information (if desired) in the **User Information** section.
2. Provide details about the update you want to make in the **Update Details** section.
3. Select the **Request Type** that best describes the type of update you need.
4. Choose one or more **Agency** options that are applicable to your update request.

## Field-by-Field Explanation
- **User Information (User Information, text, optional)**: This section is for users to provide any additional details about themselves that may be helpful for the update process. This is an optional field.
- **Update Details (Update Details, text, optional)**: In this section, enter a clear and concise description of the update you require. This will help our team understand the changes needed for your website.
- **Request Type (Request Type, select_one, required)**: Choose the type of update you require from the options provided. This will help us determine the correct course of action for your request.
- **Agency (Agency, select_multiple, required)**: Select all agencies that are involved or affected by your update request. This will help us prioritize and target the correct teams within our organization.
 
## Tips
- Please ensure that all required fields are completed to ensure accurate processing of your request.
- If you are unsure about any field, refer to your project manager or support team for guidance.
