# Project Expense Reimbursement Form - Help Guide
## Purpose
This form is used to request reimbursement for project expenses. To use this form, please follow the steps below.

## How To Complete This Form
1. Fill in the project details, including the project amount.
2. Indicate whether expenses were incurred or not.
3. Provide a brief description of the expense.
4. Enter the expense date.
5. Enter your contact information, including email address and phone number.

## Field-by-Field Explanation

* **First Page: Project Details** (`first_page`, `text`, required/optional): Enter a brief description of the project.
* **Project Amount** (`project_amount`, `number`, required/optional): Enter the total project amount.
* **First Page Project Amount Label** (`first_page_project_amount_label`, `text`, required/optional): Enter a label for the project amount field.
* **First Page Project Amount Hint** (`first_page_project_amount_hint`, `note`, required/optional): Enter a hint for the project amount field.
* **Expense Details** (`second_page`, `text`, required/optional): Enter a brief description of the expense.
* **Expense Type** (`expense_type`, `select_one`, required/optional): Select "Yes" or "No" to indicate whether an expense was incurred.
* **Expense Description** (`expense_description`, `text`, required/optional): Enter a brief description of the expense.
* **Second Page Expense Type Label** (`second_page_expense_type_label`, `text`, required/optional): Enter a label for the expense type field.
* **Second Page Expense Description Label** (`second_page_expense_description_label`, `text`, required/optional): Enter a label for the expense description field.
* **Expense Reimbursement** (`third_page`, `text`, required/optional): Enter a brief description of the expense reimbursement.
* **Expense Date** (`expense_date`, `date`, required/optional): Enter the date of the expense.
* **Second Page Expense Date Label** (`second_page_expense_date_label`, `text`, required/optional): Enter a label for the expense date field.
* **Third Page Expense Date Label** (`third_page_expense_date_label`, `text`, required/optional): Enter a label for the expense date field.
* **Additional Documents** (`fourth_page`, `text`, required/optional): Enter any additional documents or information related to the expense.
* **Receipt** (`receipt`, `text`, required/optional): Enter a receipt or supporting documentation for the expense.
* **Second Page Receipt Label** (`second_page_receipt_label`, `text`, required/optional): Enter a label for the receipt field.
* **Third Page Receipt Label** (`third_page_receipt_label`, `text`, required/optional): Enter a label for the receipt field.
* **Fourth Page Receipt Label** (`fourth_page_receipt_label`, `text`, required/optional): Enter a label for the receipt field.
* **Email Address** (`email_address`, `email`, required/optional): Enter your email address.
* **Second Page Email Address Label** (`second_page_email_address_label`, `text`, required/optional): Enter a label for the email address field.
* **Third Page Email Address Label** (`third_page_email_address_label`, `text`, required/optional): Enter a label for the email address field.
* **Fourth Page Email Address Label** (`fourth_page_email_address_label`, `text`, required/optional): Enter a label for the email address field.
* **Phone Number** (`phone_number`, `text`, required/optional): Enter your phone number.
* **Second Page Phone Number Label** (`second_page_phone_number_label`, `text`, required/optional): Enter a label for the phone number field.
* **Third Page Phone Number Label** (`third_page_phone_number_label`, `text`, required/optional): Enter a label for the phone number field.
* **Fourth Page Phone Number Label** (`fourth_page_phone_number_label`, `text`, required/optional): Enter a label for the phone number field.
* **Project Manager** (`project_manager`, `text`, required/optional): Enter the project manager's name.
* **Second Page Project Manager Label** (`second_page_project_manager_label`, `text`, required/optional): Enter a label for the project manager field.
* **Third Page Project Manager Label** (`third_page_project_manager_label`, `text`, required/optional): Enter a label for the project manager field.
