## Vehicle Information Request Form - Help Guide

### Purpose
This form is designed to collect information about a vehicle from a requesting user. It will help us understand the user's vehicle preferences and requirements for any vehicle-related services or inquiries.

### How To Complete This Form
To complete this form, follow the steps below:

1. Select the year of the vehicle you are inquiring about.
2. Choose the make of the vehicle.
3. Select the model of the vehicle (if known).
4. Choose the color of the vehicle.
5. Select the engine year of the vehicle.
6. Choose the transmission type of the vehicle.
7. Select the engine type of the vehicle.
8. Choose the drive type of the vehicle.
9. Enter your name, phone number, and email (if applicable).
9. Enter any additional notes or comments about the vehicle (if applicable).

### Field-by-Field Explanation

* **Vehicle Request Form**: This field is not visible to the user, it is a title for the form.
* **Year**: Select the year of the vehicle you are inquiring about.
	+ Please select the year from the options provided: 2016, 2017, 2018, 2019, 2020, 2021, 2022.
* **Make**: Choose the make of the vehicle.
	+ Select from the options: Toyota, Honda, Ford.
* **Model**: Enter the model of the vehicle (if known).
	+ This field is optional and can be left blank if not known.
* **Color**: Select the color of the vehicle.
	+ Choose from the options: Black, White, Red, Blue, Green, Yellow, Gray.
* **Engine Year**: Select the engine year of the vehicle.
	+ Please select from the options: 2016, 2017, 2018, 2019, 2020, 2021, 2022.
* **Transmission**: Choose the transmission type of the vehicle.
	+ Select from the options: Manual, Automatic, Semi-Automatic.
* **Engine Type**: Select the engine type of the vehicle.
	+ Choose from the options: Gas, Diesel, Electric.
* **Drive Type**: Choose the drive type of the vehicle.
	+ Select from the options: 2WD, 4WD, AWD.
* **Requesting User Name**: Enter your name.
	+ This field is required if you are requesting vehicle information on behalf of someone else.
* **Requesting User Phone Number**: Enter your phone number.
	+ This field is optional and can be left blank if not applicable.
* **Requesting User Email**: Enter your email.
	+ This field is optional and can be left blank if not applicable.
* **Requesting User Notes**: Enter any additional comments or notes about the vehicle.
	+ This field is optional and can be left blank if not applicable.
* **Requesting User Vehicle Year**: Enter the year of the vehicle you are requesting information about.
	+ This field is optional and can be left blank if not applicable.

### Tips

* Please ensure that you select the correct options for each field to provide accurate information.
* If you are unsure about any of the options, feel free to ask for assistance.
* If you have any additional questions or concerns, please don't hesitate to contact us.
