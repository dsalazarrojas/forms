# Remote Learning Device Request - Help Guide
## Purpose
This form is used to request remote learning devices for schools. It allows schools to provide essential information to request the necessary devices to support remote learning.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the required fields:
	* **Remote Learning Device Request**: Enter a brief description of your device request.
	* **School Name**: Enter your school's name.
	* **School Email**: Enter your school's email address.
	* **Devices Requested**: Select the type(s) of device(s) you are requesting (e.g., Laptops, Tablets, Smartphones, Desktop).
	* **Quantity Requested**: Specify the number of devices you are requesting for each type.
2. Fill in the optional fields:
	* **Classroom Name**: Enter the name of the classroom that will be using the devices.
	* **Teacher Email**: Enter the email address of the teacher responsible for the devices.
	* **Teacher Name**: Enter the name of the teacher responsible for the devices.
	* **School Address**: Enter your school's address.
	* **School Phone**: Enter your school's phone number.
	* **School City**: Enter your school's city.
	* **School Province**: Enter your school's province.
	* **School Post Code**: Enter your school's post code.
