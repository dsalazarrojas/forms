# Renewable Fuel Usage Application Form - Help Guide
## Purpose
The purpose of this form is to collect information on the usage of various types of renewable fuels used in projects. This form is intended to ensure accurate and consistent reporting of renewable fuel usage across projects.

## How To Complete This Form
1. Fill out the project request field with a brief description of the project.
2. Select the type of fuel used from the dropdown menu (Natural Gas, Diesel, Ethanol, Propane).
3. Enter the quantity of fuel used.
4. Enter the project location.
5. Select the start and end dates of the fuel usage period.
6. Enter any additional fuel usage notes.
7. Select the documents to submit with the form.
8. Enter the project manager's contact information.

## Field-by-Field Explanation
* **Project Request**: A brief description of the project.
* **Fuel Type**: The type of fuel used (e.g., Natural Gas, Diesel, Ethanol, Propane).
* **Quantity Used**: The amount of fuel used.
* **Project Location**: The location of the project.
* **Start Date**: The start date of the fuel usage period.
* **End Date**: The end date of the fuel usage period.
* **Fuel Usage Notes**: Any additional information about the fuel usage.
* **Submit Documents**: A list of documents to be submitted with the form.
* **Project Manager Email**: The email address of the project manager.
* **Project Manager Phone**: The phone number of the project manager.
* **Project Manager Name**: The name of the project manager.
* **Project Manager Title**: The title of the project manager.

## Tips
* Please ensure that you have all the necessary documents required for submission before submitting the form.
* If you are unsure about any field, please contact the project manager for clarification.
* This form should be filled out by someone with access to the project's information, such as the project manager or team member.
