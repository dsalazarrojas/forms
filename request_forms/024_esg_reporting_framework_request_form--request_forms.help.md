# ESG Reporting Framework Request Form - Help Guide
## Purpose
The ESG Reporting Framework Request Form is designed to gather information from organizations regarding their ESG reporting needs and preferences. This form will help the organization in identifying the appropriate reporting framework for their specific requirements.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill out each page of the form thoroughly and accurately.
2. Review each field for its specific label and description.
3. If you are unsure about any field, please ask your internal team for guidance.

## Field-by-Field Explanation

### Organization
* **Organization** (text, required/optional): This field is used to enter your organization's name.

### Reporting Guidance
* **Reporting Guidance** (text, required/optional): This field is used to describe any specific reporting guidelines or regulations that apply to your organization.

### Preferred Standards
* **Preferred Standards** (select_multiple, required/optional): Please select the ESG standards that your organization prefers to follow.
	+ 'Yes': Select this option if your organization prefers this standard.
	+ 'No': Select this option if your organization does not prefer this standard.

### Reporting Framework
* **Reporting Framework** (select_one, required/optional): Please select the type of reporting framework your organization would prefer.
	+ 'Yes': Select this option if you prefer this framework.
	+ 'No': Select this option if you do not prefer this framework.

### Focus Areas
* **Focus Areas** (select_multiple, required/optional): Please select the ESG focus areas your organization would prefer.
	+ 'Yes': Select this option if you prefer this focus area.
	+ 'No': Select this option if you do not prefer this focus area.

### Reporting Frequency
* **Reporting Frequency** (select_one, required/optional): Please select the frequency of reporting your organization would prefer.
	+ 'Yes': Select this option if you prefer this frequency.
	+ 'No': Select this option if you do not prefer this frequency.

### Reporting Deadline
* **Reporting Deadline** (date, required/optional): Please enter the date by which your organization would like to receive the reporting framework.

### Reporting Timeframe
* **Reporting Timeframe** (time, required/optional): Please select the timeframe in which your organization would like to receive the reporting framework.

### Contact Name
* **Contact Name** (text, required/optional): This field is used to enter the name of the person responsible for ESG reporting.

### Contact E-mail
* **Contact E-mail** (email, required/optional): This field is used to enter the contact email of the person responsible for ESG reporting.

### Contact Phone
* **Contact Phone** (text, required/optional): This field is used to enter the contact phone number of the person responsible for ESG reporting.

### Organization Size
* **Organization Size** (text, required/optional): This field is used to describe the size of your organization.

### Sustainability Focus
* **Sustainability Focus** (text, required/optional): This field is used to describe your organization's sustainability focus.

### Reporting Scope
* **Reporting Scope** (text, required/optional): This field is used to describe the scope of the reporting framework your organization would like to receive.

## Tips

* Please fill out each page thoroughly and accurately to ensure the best possible outcome.
* If you are unsure about any field, please ask your internal team for guidance.
* This form is designed to be completed by authorized personnel within the organization.
* Please do not fill out this form multiple times with different information.
