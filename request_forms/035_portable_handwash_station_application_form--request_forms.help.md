# Portable Handwash Station Application Form - Help Guide
## Purpose
The Portable Handwash Station Application Form is used to request a portable handwash station for a specific event or purpose. This form gathers essential information about the event, the station details, and the contact person responsible for the event.

## How To Complete This Form
To complete this form, please follow these steps:

1. Review the guidelines for requesting a portable handwash station and ensure you have read and understood them.
2. Fill in the form with the required information for the event or purpose you are requesting the portable handwash station for.
3. Double-check that you have entered all necessary information and that it is accurate.

* **Station Details**: (`station_details`, text, required) Provide any additional details about the portable handwash station you are requesting, such as location and quantity needed.
* **Request Details**: (`request_details`, text, optional) If required, provide more information about the request, such as any specific requests or special instructions.
