# 340B Program Audit Services Request Form - Help Guide

## Purpose

The purpose of this form is to help healthcare organizations request audit services for the 340B Program. 

## How To Complete This Form

1. Complete this form accurately and thoroughly, providing all the necessary information about your 340B Program audit request.
2. Please do not duplicate this form if the audit services request has already been processed by your organization.
3. Ensure that you have permission to fill out this form on behalf of your organization.

## Field-by-Field Explanation

* **Organization name**: The full legal name of the healthcare organization requesting audit services.
	+ Required Field
	+ Type: Text
	+ Explanation: Enter the full legal name of your organization.
* **Primary Contact Person**: The name of the individual responsible for this audit request.
	+ Required Field
	+ Type: Text
	+ Explanation: Enter the name of the individual who will be the primary contact person for this audit request.
* **Contact Email**: Official email for audit correspondence.
	+ Required Field
	+ Type: Email
	+ Explanation: Enter the official email address for the primary contact person.
* **Contact Phone Number**: Include area code.
	+ Required Field
	+ Type: Phone
	+ Explanation: Enter the contact phone number with area code for the primary contact person.
* **Type of Covered Entity**: Select the classification of your organization.
	+ Required Field
	+ Type: Select One
	+ Explanation: Choose the type of covered entity your organization is classified as.
* **Purpose of Audit Request**: Select the specific aspect of 340B compliance that needs review.
	+ Required Field
	+ Type: Select One
	+ Explanation: Select the specific aspect of 340B compliance that requires an audit.
* **Previous 340B Audits Conducted**: Number of prior audits conducted by your organization.
	+ Optional Field
	+ Type: Integer
	+ Explanation: Enter the number of prior audits conducted by your organization.
* **Scope of Audit Requested**: Select all areas that need examination.
	+ Required Field
	+ Type: Select Multiple
	+ Explanation: Choose all areas that require examination for the audit.
* **Preferred Dates for Audit**: Indicate the preferred timeframe for the audit.
	+ Optional Field
	+ Type: Text
	+ Explanation: Enter the preferred timeframe for the audit.
* **Estimated Prescription Volume**: Approximate number of prescriptions processed monthly.
	+ Optional Field
	+ Type: Integer
	+ Explanation: Enter the approximate number of prescriptions processed monthly.
* **Number of Contract Pharmacies**: The number of external pharmacies participating in your program.
	+ Optional Field
	+ Type: Integer
	+ Explanation: Enter the number of external pharmacies participating in your program.
* **Special Requirements or Considerations**: Any unique aspects of your organization that auditors should know.
	+ Optional Field
	+ Type: Text
	+ Explanation: Enter any unique aspects of your organization that the auditors should be aware of.
* **Budget Range for Audit Services**: Expected budget allocated for this audit.
	+ Optional Field
	+ Type: Select One
	+ Explanation: Choose the expected budget range for this audit engagement.
* **Timeline Expectations**: Select the completion date for the audit.
	+ Required Field
	+ Type: Select One
	+ Explanation: Choose the completion date for the audit.
* **Reporting Preference**: How would you like audit findings delivered?
	+ Optional Field
	+ Type: Select One
	+ Explanation: Choose the format in which you would like audit findings to be delivered.
* **Additional Services Needed**: Check any supplementary services required.
	+ Optional Field
	+ Type: Select Multiple
	+ Explanation: Check any additional services your organization may need.
* **Emergency Contact Information**: 24-hour contact for urgent audit matters.
	+ Optional Field
	+ Type: Text
	+ Explanation: Enter the 24-hour contact information for urgent audit matters.
* **Reference Number (if Applicable)**: Internal tracking number for this request.
	+ Optional Field
	+ Type: Text
	+ Explanation: Enter the internal tracking number for this audit request.
* **Additional Comments or Special Instructions**: Any other information relevant to your audit request.
	+ Optional Field
	+ Type: Text
	+ Explanation: Enter any other information relevant to the audit request.
