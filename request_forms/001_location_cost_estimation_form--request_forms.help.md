# Location Cost Estimation Form - Help Guide
## Purpose
The Location Cost Estimation Form is designed to collect information from end-users for estimating costs associated with a specific location or event space. This form helps gather essential details to provide accurate estimates.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the venue's details in the "Venue Details" section.
2. Provide the estimated capacity of the venue.
3. Select the estimate type.
4. Enter the date and time when the estimate request is made.
5. Add any additional contact information for the requester.
6. Enter any relevant notes about the estimate request.
7. Click the "Submit" button to send the form.

## Field-by-Field Explanation
- **Venue Details** (required/optional, text): Enter the address or description of the location where the estimate is requested.
- **Venue Capacity** (required/optional, number): Enter the estimated capacity of the venue.
- **Estimate Type** (required/optional, select_one): Select the type of estimate that is being requested (Type A, Type B, Type C).
- **Estimate Request Date** (required/optional, date): Enter the date when the estimate is requested.
- **Estimate Request Time** (required/optional, time): Enter the time when the estimate is requested.
- **Estimate Requester** (required/optional, text): Enter a name or description to identify the person requesting the estimate.
- **Contact Email** (required/optional, email): Enter the email address of the person requesting the estimate.
- **Contact Phone** (required/optional, text): Enter the phone number of the person requesting the estimate.
- **Notes** (required/optional, note): Add any additional comments or information about the estimate request.
- **Submit** (required, text): Click the "Submit" button to send the form to the relevant personnel.

## Tips
* Please ensure that all fields are filled out accurately and correctly.
* Use clear and concise language in the "Estimate Requester" and "Notes" fields.
* If you have any questions or concerns about the estimate request, please contact the relevant personnel directly.
