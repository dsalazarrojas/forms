# System Access Code Request Form - Help Guide
## Purpose
The System Access Code Request Form is a tool for requesting access codes for legitimate business purposes. It is used by system administrators to review and approve or deny requests based on the provided information.

## How To Complete This Form
1. Please fill out all the required fields. 
2. Select multiple team members if necessary.
3. Choose the correct access code type.
4. Provide the correct start and end dates.

## Field-by-Field Explanation
* **System Access Code Request Form** (`title`, `text`, required): This is the title of the form that you are completing.
* **Access Code** (`system_access_code_request`, `text`, required): Enter the specific system access code you are requesting.
* **Team Members** (`team_members`, `select_multiple`, required): Select all team members that need access to the system. 
* **Reason** (`reason`, `text`, required): Enter a brief reason for your request.
* **Business Needs** (`business_needs`, `text`, required): Enter a brief description of your business needs.
* **Access Code Type** (`access_code_type`, `select_one`, required): Choose the correct type for your access code.
* **Start Date** (`start_date`, `date`, required): Enter the date you need to start using the system.
* **End Date** (`end_date`, `date`, required): Enter the date you plan to finish using the system.

## Tips
- Be specific when filling out the 'Reason' field to help us better understand your needs.
- Choose the correct access code type that suits your purpose.
- Make sure to check the "Team Members" field for accuracy.
- Enter accurate start and end dates to avoid any conflicts.
- Fill out all the fields correctly to help us process your request smoothly.
