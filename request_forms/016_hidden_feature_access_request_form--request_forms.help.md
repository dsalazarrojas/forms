# Hidden Feature Access Request Form - Help Guide
## Purpose
This form is for requesting access to features that are currently not visible to all users. Fill out this form to submit your request for access to a hidden feature, providing the necessary user information and reasons for your request.

## How To Complete This Form
To complete this form, please follow the steps below:

1. Fill in your user information, including your name and feature name in the respective fields.
2. Select the type of access you require for the feature (e.g. admin, editor, or user).
3. Provide a reason for your request in the text field.
4. Set the date and time you require access to the feature.

## Field-by-Field Explanation

* **Hidden Feature Access Request** (`feature_access_request`): Enter the description of the feature you are requesting access to in the text field. This will help us understand your request.
* **User Information** (`user_info`): Enter your name, role, and contact information so we can reach out to you regarding your request.
* **Feature Name** (`feature_name`): Select the name of the feature you are requesting access to from the dropdown menu. Please choose from `admin`, `editor`, or `user`.
* **User Name** (`user_name`): Enter your name as it appears on our system, this will help us identify you.
* **Reason** (`reason`): Provide a clear and concise reason for your request in this text field.
* **Date** (`date`): Select the date you require access to the feature in the date picker format (e.g., MM/DD/YYYY).
* **Time** (`time`): Select the time you require access to the feature in the 24-hour clock format (e.g., 14:30).

## Tips

* Make sure to fill out all required fields to ensure your request is complete.
* Be as clear and concise as possible when describing the feature you are requesting access to.
* If you have any questions or need clarification, don't hesitate to contact us at [form@gic.mx](mailto:form@gic.mx).
