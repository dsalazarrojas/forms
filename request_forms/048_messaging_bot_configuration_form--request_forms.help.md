# Messaging Bot Configuration Form - Help Guide
## Purpose
The Messaging Bot Configuration Form is used to configure the messaging bot to send automatic messages to customers.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the form with the required information. Note that some fields are not required and can be left blank if not applicable.
2. Make sure to select the correct options for each field based on your needs.
3. Review the form carefully before submitting it to ensure that all information is accurate.

## Field-by-Field Explanation

* **main_page** (`main_page`, text, optional): This field is the main page that will be displayed to the customer. You can enter any text you want to display in this field.
* **page_2** (`page_2`, text, optional): This field is another page that will be displayed to the customer. You can enter any text you want to display in this field.
* **routing** (`routing`, select multiple, optional): Choose whether the messaging bot should route messages to the team members who are:
	+ Yes: Messages will be sent to team members who have this option selected.
	+ No: Messages will not be sent to team members who have this option selected.
* **team** (`team`, select one, optional): Choose which team should receive the messages:
	+ Yes: The selected team will receive the messages.
	+ No: The selected team will not receive the messages.
* **settings** (`settings`, text, optional): This field is used to store any additional settings for the messaging bot. You can enter any text you want to store in this field.
* **support_team** (`support_team`, select multiple, optional): Choose which support team members should receive messages:
	+ Yes: Messages will be sent to support team members who have this option selected.
	+ No: Messages will not be sent to support team members who have this option selected.
* **product_team** (`product_team`, select multiple, optional): Choose which product team members should receive messages:
	+ Yes: Messages will be sent to product team members who have this option selected.
	+ No: Messages will not be sent to product team members who have this option selected.
* **operations_team** (`operations_team`, select multiple, optional): Choose which operations team members should receive messages:
	+ Yes: Messages will be sent to operations team members who have this option selected.
	+ No: Messages will not be sent to operations team members who have this option selected.

## Tips
- Make sure to select the correct teams and options based on your team's structure and needs.
- If you're unsure about any of the fields, contact your administrator for clarification.
- This form is designed to be used by authorized personnel only, so ensure you have the necessary permissions before proceeding.
