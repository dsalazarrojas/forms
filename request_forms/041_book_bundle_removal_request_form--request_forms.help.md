# Book Bundle Removal Request Form - Help Guide
## Purpose
The Book Bundle Removal Request Form is a form used to request the removal of a book bundle from the system. It is essential for staff or partners to fill out this form when they need to remove a book bundle from the system.

## How To Complete This Form
To complete this form, follow these steps:

* Fill in the "Requester name" field with the name of the staff or partner requesting the removal.
* Enter the "Book bundle identifier" field with the SKU or bundle code of the book bundle to be removed.
* Provide a clear explanation of the "Reason for removal" in the "Reason for removal" field.
* If the removal action requires approval from a manager, select "True" in the "Approval required" field.
* If approval is required, enter the name of the approving manager in the "Approver name" field.
* Add any additional information in the "Notes" field as needed.
* If the removal should take effect immediately, ensure the "Effective date" field is left blank.
* If the removal should take effect on a specific date, enter the date in the "Effective date" field.

## Field-by-Field Explanation

* **-- Removal Request --**: This is a note field to acknowledge that this is a request to remove a book bundle. Please fill in your name in the "Requester name" field to ensure this is associated with your request.
* **Requester name**: Enter your name here to ensure this removal request is associated with you. This field is required.
* **Book bundle identifier**: Enter the SKU or bundle code of the book bundle you want to remove.
* **Reason for removal**: Clearly explain why you want to remove the book bundle. This field is required.
* **Effective date**: If you want the removal to take effect immediately, leave this field blank. If you want to set a specific date for removal, enter it here. This field is optional.
* **Approval required**: If the removal action requires approval from a manager, select "True" here. This field is required.
* **Approver name**: If approval is required, enter the name of the approving manager here. This field is optional.
* **Notes**: Add any additional information you think is necessary for the removal process.
