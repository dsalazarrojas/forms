# sfdc_campaign_request_form - Help Guide

## Purpose
The sfdc_campaign_request_form is a request form for clients to submit their salesforce campaign requests. It is used to gather information about the campaign type, client name, campaign requirements, media used, target audience, expected outcome, and payment terms.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the type of campaign you are requesting from the "Campaign Type" dropdown menu.
2. Enter the name of the client for whom the campaign is being requested.
3. Provide a brief description of the campaign requirements in the "Campaign Requirements" text field.
4. Select the media channels you plan to use for the campaign from the "Media Used" dropdown menu (you can select multiple options).
5. Choose the target audience for your campaign from the "Target Audience" dropdown menu (you can select multiple options).
6. Describe the expected outcome of the campaign in the "Expected Outcome" text field.
7. Specify the payment terms for the campaign in the "Payment Terms" text field.

## Field-by-Field Explanation

* **Campaign Type (campaign_type)**: Select the type of campaign you are requesting, such as Facebook ads, Google AdWords, or Bing Ads.
* **Client Name (client_name)**: Enter the name of the client for whom the campaign is being requested.
* **Campaign Requirements (campaign_requirements)**: Provide a brief description of the campaign requirements.
* **Media Used (media_used)**: Select the media channels you plan to use for the campaign, such as Google AdWords, Facebook, or Bing Ads.
* **Target Audience (target_audience)**: Choose the target audience for your campaign, such as adults, children, or seniors.
* **Expected Outcome (expected_outcome)**: Describe the expected outcome of the campaign.
* **Payment Terms (payment_terms)**: Specify the payment terms for the campaign.
