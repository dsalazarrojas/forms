# Release Tag Creation Request Form - Help Guide
## Purpose
This form is used to collect information for the creation of a release tag. Please fill out the form carefully to ensure that all necessary details are captured.

## How To Complete This Form
To complete this form, follow these steps:
1. Select the version of the release tag you wish to create.
2. Choose the environment where the release will be deployed.
3. Enter the release date and time.
4. Provide a brief description of the release.
5. Enter the tag names for the release.
6. Enter the name of the person who is requesting the release.
7. Enter the name and email of the person who will approve the release.
8. Enter the phone number of the approver.
9. (Optional) Add any additional notes for the approver.

## Field-by-Field Explanation
* **Select Version**: Select the version of the release tag you wish to create from the dropdown menu.
* **Select Environment**: Choose the environment where the release will be deployed.
	+ Please select one or more of the following environments: Production, Staging, QA, UAT, and Dev.
* **Release Date**: Enter the date of the release in the format mm/dd/yyyy.
* **Release Time**: Enter the time of the release in the format 12:00 AM, 12:00 PM, or 12:00 PM.
* **Description**: Provide a brief description of the release.
* **Tag Names**: Enter the names of the tags you would like to create for the release.
* **Requester**: Enter the name of the person who is requesting the release.
* **Approver**: Enter the name of the person who will approve the release.
* **Approver Email**: Enter the email address of the person who will approve the release.
* **Approver Phone**: Enter the phone number of the person who will approve the release.
* **Notes**: (Optional) Add any additional notes for the approver.
* **Created By**: Enter the name of the person who is creating the release tag request.
* **Created Date**: The date and time when the release tag request was created.
* **Updated By**: (Optional) Enter the name of the person who updated the release tag request.
* **Updated Date**: The date and time when the release tag request was last updated.
