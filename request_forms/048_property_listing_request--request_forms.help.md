# Property Listing Request - Help Guide
## Purpose
This form is designed to gather information for property listing requests. It's intended to be used by real estate agents or brokers to collect details about properties for listing purposes.

## How To Complete This Form
- Start by selecting the relevant property type (e.g., Apartment, House, etc.)
- Choose the location (e.g., New York, Los Angeles, Chicago, etc.) and select all applicable locations for multi-location properties.
- Enter the number of bedrooms, bathrooms, square footage, lot size, and year built for the property.
- Specify the price range of the property.
- List any notable features (e.g., Garage, Pool, Yard, etc.) and select all that apply.
- Choose the property status (e.g., Active, Pending, Sold).
- Provide contact information and a property address if applicable.
- If necessary, add any additional agent information or property description.
- Enter the property's price.

## Field-by-Field Explanation
- **Property Type** (`property_type`, Select One, Optional): Select the type of property you are listing (e.g., Apartment, House, etc.).
- **Location** (`location`, Select Multiple, Optional): Choose the location(s) where the property is located. 
  - This field is used to indicate where the property is situated.
- **Number Of Bedrooms** (`number_of_bedrooms`, Number, Optional): Enter the number of bedrooms in the property.
- **Number Of Bathrooms** (`number_of_bathrooms`, Number, Optional): Enter the number of bathrooms in the property.
- **Square Footage** (`square_footage`, Number, Optional): Enter the total square footage of the property.
- **Lot Size** (`lot_size`, Number, Optional): Enter the size of the property's lot.
- **Year Built** (`year_built`, Number, Optional): Enter the year the property was built.
- **Price Range** (`price_range`, Number, Optional): Enter the price range of the property.
- **Features** (`features`, Select Multiple, Optional): Select any notable features of the property (e.g., Garage, Pool, etc.).
- **Property Status** (`property_status`, Select One, Optional): Choose the property status (e.g., Active, Pending, Sold).
- **Contact Information** (`contact_information`, Text, Optional): Provide any relevant contact information about the property or agent.
- **Property Address** (`property_address`, Text, Optional): If applicable, enter the property's address.
- **Agent Information** (`agent_information`, Text, Optional): Enter any additional agent information.
- **Other Details** (`other_details`, Text, Optional): Add any other relevant details about the property.
- **Property Description** (`property_description`, Text, Optional): Write a brief description of the property.
- **Property Price** (`property_price`, Number, Optional): Enter the price of the property.

## Tips
- Please provide accurate and up-to-date information about the property.
- Ensure that you are submitting a legitimate property listing request.
- Double-check your entries before submitting the form to avoid errors.
- If you need help or have questions, feel free to contact us.
