# Payment Card Reader Request Form - Help Guide

## Purpose
This form is used to request the addition of a payment card reader to the organization's payment system. It is intended to gather information about the payment card reader, including its category, location, and request type, to determine the best course of action for the request.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the category of the payment card reader from the options provided.
2. Choose the location where the payment card reader will be used.
3. Select the type of request you are making.
4. Provide any additional information about the payment card reader, such as its device model and purchase date.
5. Enter the serial number of the payment card reader.
6. If applicable, provide notes about the payment card reader.
7. Enter your email address and phone number.
8. If applicable, select the person or tool assigned to manage the payment card reader.
9. Add any comments about the request.
10. If applicable, select the status of the request.

## Field-by-Field Explanation

* **Category** (`category`, select_one, required: false): Select the category of the payment card reader.
* **Location** (`location`, select_multiple, required: false): Choose the location where the payment card reader will be used.
* **Request Type** (`request_type`, select_one, required: false): Select the type of request you are making.
* **Device Model** (`device_model`, text, required: false): Provide any additional information about the payment card reader, such as its device model.
* **Device Description** (`device_description`, text, required: false): Provide a description of the payment card reader.
* **Serial Number** (`serial_number`, text, required: false): Enter the serial number of the payment card reader.
* **Purchase Date** (`purchase_date`, date, required: false): Enter the purchase date of the payment card reader.
* **Purchase Price** (`purchase_price`, number, required: false): Enter the purchase price of the payment card reader.
* **Notes** (`notes`, note, required: false): Add any notes about the payment card reader.
* **Email** (`email`, email, required: false): Enter your email address.
* **Phone** (`phone`, text, required: false): Enter your phone number.
* **Assigned To** (`assigned_to`, select_one, required: false): Select the person or tool assigned to manage the payment card reader.
* **Assigned Tool** (`assigned_tool`, select_multiple, required: false): If applicable, select the tool assigned to manage the payment card reader.
* **Comments** (`comments`, text, required: false): Add any comments about the request.
* **Created At** (`created_at`, time, required: false): This field will display the date and time the request was created.
* **Updated At** (`updated_at`, time, required: false): This field will display the date and time the request was updated.
* **Submitted By** (`submitted_by`, select_one, required: false): Select the person who submitted the request.
* **Submitted At** (`submitted_at`, date, required: false): Enter the date the request was submitted.
* **Status** (`status`, select_one, required: false): Select the status of the request.
* **Status Reason** (`status_reason`, text, required: false): Enter any reason for the status of the request.
* **Request Type 1** (`request_type_1`, select_one, required: false): Select the type of request 1.
* **Request Type 2** (`request_type_2`, select_one, required: false): Select the type of request 2.
* **Request Type 3** (`request_type_3`, select_one, required: false): Select the type of request 3.
* **Request Type 4** (`request_type_4`, select_one, required: false): Select the type of request 4.
