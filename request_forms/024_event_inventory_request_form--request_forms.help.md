# Event Inventory Request Form - Help Guide

## Purpose
The Event Inventory Request Form is designed to collect essential details about an event requested by an employee or team. This form helps the organization's internal events team to understand the requirements and process the request effectively.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill in your email address to ensure that you receive notifications and updates about your event request.
2. Provide your name so that we know who submitted the request.
3. Enter the date and time of the event you are requesting.
4. Add a brief description of the event, including any necessary details.
5. Select the location of the event.
6. Choose the type of event you are requesting (e.g., meeting, conference, etc.).
7. Specify the status of the event (e.g., completed, pending, cancelled, etc.).
8. Designate the responsible person for the event.
9. (Optional) Select the priority level of the event.

## Field-by-Field Explanation

* **Event Requester Email** (`event_requester_email`): Your email address for us to contact you about this request.
* **Event Requester Name** (`event_requester_name`): Your name so we know who submitted the request.
* **Event Date** (`event_date`): The date of the event.
* **Event Time** (`event_time`): The time of the event.
* **Event Description** (`event_description`): A brief description of the event, including any important details.
* **Event Location** (`event_location`): The location of the event.
* **Event Type** (`event_type`): Choose the type of event you are requesting (e.g., meeting, conference, etc.).
* **Event Status** (`event_status`): Select the current status of the event (e.g., completed, pending, cancelled, etc.).
* **Event Responsible** (`event_responsible`): The person responsible for this event.
* **Event Priority** (`event_priority`): (Optional) Select the priority level of the event (e.g., low, medium, high, etc.).
