# sow_information_collection - Help Guide
## Purpose
This form is used to collect project information for a Software for Offshore Wind (SOW) project.

## How To Complete This Form
To complete this form, follow these steps:

1. Review each field carefully and ensure you have all necessary information before proceeding.
2. Fill in the required fields, indicated by a star (\*) in the field label.
3. If you are unsure about any field, ask your supervisor or the project team for guidance.

## Field-by-Field Explanation
* **Project Scope** (1, text, optional):
	+ This field is asking for a brief description of the project scope.
	+ Please provide a short paragraph or sentence summarizing the project's objectives and goals.
* **Project Deliverables** (2, text, optional):
	+ This field is asking for a list of items that the project team will deliver.
	+ Please include all relevant details about what the project team will deliver to the client or stakeholders.
* **Project Timeline** (3, text, optional):
	+ This field is asking for a description of the project timeline.
	+ Please provide a brief overview of the project's start and end dates, key milestones, and critical deadlines.
* **Stakeholders** (4, select one, optional):
	+ This field is asking about the stakeholders involved in the project.
	+ Please select "Yes" if you know of any stakeholders who will be impacted by the project, such as team members, clients, or sponsors.
	+ If you are unsure, select "No" and ask your supervisor or the project team for guidance.

## Tips
* Please double-check your information for accuracy before submitting the form.
* If you need help with any field or have questions, don't hesitate to reach out to your supervisor or the project team.
* Make sure to save your work regularly, as the form will be automatically saved after each submission.
