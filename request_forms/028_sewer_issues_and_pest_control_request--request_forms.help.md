# Sewer Issues And Pest Control Request - Help Guide

## Purpose
This form is used to report any problems or issues with the sewer system, including pests, and to request assistance from the relevant department.

## How To Complete This Form
1. To complete this form, simply fill out the required and optional fields as instructed below.
2. Be as detailed as possible when describing the issue.
3. If you are submitting a photo of the issue, please ensure it is clear and easily readable.
4. If you have any follow-up requests or questions, please make sure to include them in the "Follow-up" field.

## Field-by-Field Explanation

* **Resident Name**: This is your name, and it is used to identify you as the one submitting the request.
* **Address**: Enter the address where the issue is located.
* **Issue Description**: Please describe the issue you are experiencing with the sewer system. Be as detailed as possible, including any symptoms or problems you are experiencing.
* **Issue Photo**: If you have a photo of the issue, please upload it here. This will help us better understand the problem.
* **Priority**: Select the priority level of the issue: High, Medium, or Low. This will help us determine the urgency of the request.
* **Urgency**: Select when you expect the issue to be resolved. Today, Tomorrow, This Week, or This Month.
* **Follow-up**: If you have any follow-up requests or questions, please include them here.
* **Contact Number**: If you have a preferred contact method, please include your phone number here.
* **Email**: If you have a preferred email address, please include it here.
* **Assigned Tool**: Select the tool you would like to be assigned for resolving the issue.
* **Notes**: Any additional information or comments you would like to add to your request.

## Tips
- Please be patient as it may take some time to resolve the issue.
- We will contact you once a solution has been assigned and is being worked on.
- If you have any further questions or concerns, please reach out to us directly.
