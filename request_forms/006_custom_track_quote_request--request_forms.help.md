# Custom Track Quote Request - Help Guide

## Purpose
This form is designed to collect project details for a custom track quote request. It is intended to be used by customers to provide information about their project, and our team will use this information to provide an accurate quote for the custom track.

## How To Complete This Form

1.  Click on the "Custom Track Quote Request" form to begin.
2.  Fill out the form fields as described below.
3.  Review your submission before submitting the form.

## Field-by-Field Explanation

*   **Project Info**: This field is for the name of the project.
    *   Label: Project Info
    *   Type: text
    *   Required: false
*   **Project Location**: Enter the location of the project.
    *   Label: project_location
    *   Type: text
    *   Required: false
*   **Project Length**: Enter the length of the project.
    *   Label: project_length
    *   Type: number
    *   Required: false
*   **Track Type**: Select the type of track you need.
    *   Label: track_type
    *   Type: select_multiple
    *   Options: standard, custom
    *   Required: false
*   **Track Material**: Select the material type for the track.
    *   Label: track_material
    *   Type: select_multiple
    *   Options: wood, asphalt, cement
    *   Required: false
*   **Track Width**: Enter the width of the track.
    *   Label: track_width
    *   Type: number
    *   Required: false
*   **Track Length**: Enter the length of the track.
    *   Label: track_length
    *   Type: number
    *   Required: false
*   **Track Depth**: Enter the depth of the track.
    *   Label: track_depth
    *   Type: number
    *   Required: false
*   **Track Slope**: Select the slope type of the track.
    *   Label: track_slope
    *   Type: select_one
    *   Options: flat, gently sloping, moderately sloping, steeply sloping
    *   Required: false
*   **Track Direction**: Select the direction of the track.
    *   Label: track_direction
    *   Type: select_one
    *   Options: east-west, north-south, northeast-southwest
    *   Required: true
*   **Project Description**: Enter a brief description of the project.
    *   Label: project_description
    *   Type: text
    *   Required: false
*   **Contact Name**: Enter the name of the contact person.
    *   Label: Contact Name
    *   Type: text
    *   Required: false
*   **Email**: Enter the email of the contact person.
    *   Label: Email
    *   Type: email
    *   Required: false
*   **Phone**: Enter the phone number of the contact person.
    *   Label: Phone
    *   Type: text
    *   Required: false
*   **Comments**: Enter any additional comments about the project.
    *   Label: Comments
    *   Type: text
    *   Required: true
*   **File Uploads**: Choose whether you want to upload files with your submission.
    *   Label: File Uploads
    *   Type: select_multiple
    *   Options: Yes, No
    *   Required: true

## Tips

*   Review your submission before clicking "Submit" to ensure all required fields are filled out.
*   If you have previously submitted a request for the same project, do not submit another request unless there have been changes to the project details.
*   Be sure to select "Yes" for file uploads if you have files to include.
