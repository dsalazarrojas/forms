# Website Content Request Form - Help Guide
## Purpose
The Website Content Request Form is used to request content for the website, such as text, images, or videos. This form is used to submit requests for content creation, updates, or changes.

## How To Complete This Form

1. Fill out the form completely and accurately, ensuring all required fields are filled.
2. Review the fields below for a detailed explanation of each field.

## Field-by-Field Explanation

* **Request Information** (`website_content_request_form`, text, required: false): Please describe the request you are submitting. This is a free-text field for you to explain your request.
* **Website Name** (`website_name`, text, required: false): Enter the name of the website or mobile application you are requesting content for.
* **Website URL** (`website_url`, text, required: false): Enter the URL of the website or mobile application you are requesting content for.
* **Website Type** (`website_type`, select_one, required: false):
	+ Select "Website" for a traditional website.
	+ Select "Mobile App" for a mobile application.
	+ Select "E-commerce" for an e-commerce website.
* **Content Request Type** (`content_request_type`, select_multiple, required: false):
	+ Select "Text" for a text-based content request.
	+ Select "Image" for an image-based content request.
	+ Select "Video" for a video-based content request.
* **Description** (`description`, text, required: false): Provide a brief description of the content you are requesting.
* **Email** (`email`, email, required: false): Enter your email address so we can contact you about your request.
* **Phone** (`phone`, text, required: false): Enter your phone number so we can contact you about your request.
* **Date** (`date`, date, required: false): Enter the date you would like to see the content live on the website.
* **Time** (`time`, time, required: false): Enter the time you would like to see the content live on the website.
* **Note** (`note`, note, required: false): Enter any additional notes or comments about your request.
* **Manager Name** (`manager_name`, text, required: false): Enter the name of the manager or contact person for your request.
* **Manager Email** (`manager_email`, email, required: false): Enter the email address of the manager or contact person.
* **Manager Phone** (`manager_phone`, text, required: false): Enter the phone number of the manager or contact person.
* **Submit** (`submit`, select_one, required: false):
	+ Select "True" to submit the request.
	+ Select "False" to cancel or cancel the request.
* **Submit Reason** (`submit_reason`, text, required: false): If you choose to cancel or cancel the request, please explain why you are cancelling the request.

## Tips
- Be thorough and accurate when filling out the form.
- Ensure you have a valid reason for submitting the request.
- If you are requesting content, be clear about what type of content you need (e.g., text, image, video).
- If you are requesting changes to existing content, be clear about what changes you need and why.
- Review the form carefully before submitting to ensure you have completed it accurately and thoroughly.
