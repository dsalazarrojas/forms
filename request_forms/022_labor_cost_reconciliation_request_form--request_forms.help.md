# Labor Cost Reconciliation Request Form - Help Guide
## Purpose
This form is a tool for requesting labor cost reconciliation, allowing employees or managers to record and verify labor costs for a project or project-related work.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the **Project Id** (if known) to ensure accurate processing of your request.
2. Enter the **Employee Id** (if known) to ensure accurate assignment of labor costs.
3. Select the **Date** for which you are requesting labor cost reconciliation.
4. Enter a brief **Description** of the work performed.
5. If the request is submitted by a manager, select **Yes** or **No** to indicate whether the employee has been paid correctly.
6. Submit the form to initiate the labor cost reconciliation process.

## Field-by-Field Explanation
- **Project Id**: Enter the ID of the project for which you are requesting labor cost reconciliation. This field is not required but is helpful for accurate processing.
  * If you do not know the project ID, please ask your manager for assistance.
- **Employee Id**: Enter the ID of the employee whose labor costs are being requested for reconciliation. This field is not required but is helpful for accurate assignment of labor costs.
  * If you do not know the employee ID, please check with your HR department or team lead.
- **Date**: Select the date for which you are requesting labor cost reconciliation. This field is not required as the default is the current date.
- **Description**: Enter a brief description of the work performed by the employee. This field should be concise and include any necessary details for labor cost reconciliation.
- **Submitted By**: Select 'Yes' if you or your team member has been paid correctly for the work performed. Select 'No' if payment is pending or if there are discrepancies with the submitted labor costs. This field is not required but recommended for accurate tracking of labor cost reconciliation.
  * Please ensure to mark 'No' for any pending payments or discrepancies.
