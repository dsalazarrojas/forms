# Applicant Portal Login Assistance Request - Help Guide
## Purpose
The Applicant Portal Login Assistance Request form is designed to help applicants who are experiencing issues with logging into the applicant portal. This form is intended to gather information about the issue, allowing our support team to provide prompt and effective assistance.

## How To Complete This Form
To complete this form, simply follow the instructions below:

* Fill in your Full Name and Email Address Used for Registration.
* If you know your Applicant ID, please enter it. If not, you can leave this field blank.
* Select the Program or Department you applied to.
* Describe the Type of Login Issue you are experiencing.
* If applicable, enter the exact Error Message Displayed.
* Provide a Detailed Description of the Problem.
* Specify the Browser and Operating System Used.
* Choose the Device Type (e.g., Desktop Computer, Laptop, Smartphone, Tablet).
* If you have an upcoming application deadline, specify the Next Application Deadline Date.
* Choose your Urgency Level (e.g., Low, Medium, High, Critical).
* Select your Preferred Method of Contact for Resolution (e.g., Email, Phone Call).
* If phone call is preferred, enter your Contact Phone Number (optional).

## Field-by-Field Explanation
* **Full Name** (`full_name`, text, **Required**): Enter your full name as it appears on your application.
* **Email Address Used for Registration** (`registered_email`, email, **Required**): Enter the email address you used to register for the application process.
* **Applicant ID (If known)** (`applicant_id_number`, text, **Optional**): If you know your applicant ID, enter it here. If not, you can leave this field blank.
* **Program or Department Applied To** (`program_applied_to`, text, **Required**): Select the program or department you applied to.
* **Type of Login Issue** (`issue_category`, select_one, **Required**): Choose the type of login issue you are experiencing (e.g., Forgot Password, Forgot Username - Email, Account Locked, Error Code During Login, Verification Link Not Received, Other Technical Error).
* **Error Message Displayed** (`error_message_displayed`, text, **Optional**): If applicable, enter the exact error message you see.
* **Detailed Description of the Problem** (`issue_description`, text, **Required**): Provide a detailed description of the issue you are experiencing.
* **Browser and Operating System Used** (`browser_and_os`, text, **Required**): Specify the browser and operating system you are using (e.g., Chrome on Windows 11, Safari on macOS).
* **Device Type** (`device_type`, select_one, **Required**): Choose the type of device you are using (e.g., Desktop Computer, Laptop, Smartphone, Tablet).
* **Next Application Deadline Date** (`application_deadline`, date, **Optional**): If you have an upcoming application deadline, specify the date.
* **Urgency Level** (`urgency_level`, select_one, **Required**): Choose the urgency level of your issue (e.g., Low, Medium, High, Critical).
* **Preferred Method of Contact for Resolution** (`preferred_contact_method`, select_one, **Required**): Select how you would like to be contacted (e.g., Email, Phone Call).
* **Contact Phone Number** (`contact_phone`, text, **Optional**): If you prefer a phone call, enter your phone number (optional).
