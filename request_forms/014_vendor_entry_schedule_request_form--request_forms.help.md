# Vendor Entry Schedule Request Form - Help Guide
## Purpose
The Vendor Entry Schedule Request Form is designed to collect essential information from vendors about their schedule entry. This form helps the management team to coordinate and schedule the vendor's entry efficiently.

## How To Complete This Form
To complete this form, follow these steps:
1. Click on the 'Submit' button to start filling out the form.
2. Fill out the form with the required information.
3. Ensure that you are filling out the form for the correct purpose and not duplicating a request that has already been made.

## Field-by-Field Explanation
* **Vendor Details** (`vendor_details`, `text`, required/optional): Enter the name and any other relevant details about the vendor.
* **Entry Date** (`entry_date`, `date`, required/optional): Select the date of the entry.
* **Entry Time** (`entry_time`, `time`, required/optional): Select the time of the entry.
* **Duration** (`entry_time_duration`, `number`, required/optional): Enter the duration of the entry in hours.
* **Site Access** (`site_access`, `select_one`, required/optional): Select the level of site access required for the entry (e.g., 1, 2, or 3).
* **Request Notes** (`request_notes`, `note`, required/optional): Enter any additional notes about the request.
* **Contact Phone** (`contact_phone`, `text`, required/optional): Enter the contact phone number of the vendor.

## Tips
* Ensure that you are entering the correct information for the correct purpose.
* Check your form before submitting it to ensure that it is complete and accurate.
* If you are unsure about any field, refer to the above field explanation for more information.
