# Open Access Courseware Distribution Request Form - Help Guide
## Purpose
The Open Access Courseware Distribution Request Form is a tool for requesting open access courseware distribution. Use this form to submit a request for distributing courseware to a specific location. This form will guide you through the required information for your request.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the details of your request in the **Request Details** page (page 1).
2. Provide the details about the courseware you are requesting to be distributed on the **Courseware Details** page (page 2).
3. Enter your contact information on the **Contact Info** page (page 3).
4. Select the date and time of your request on the **Date and Time** page (page 4).
5. If you have specific time preferences, select them on the **Time Preferences** page (page 5).
6. On the **Distribution Request Status** page (page 6), select the status of your request.
7. On the **Assigned Tool** page (page 7), enter the tool assigned to you for this request.
8. Enter the name of the user who submitted this request on the **Submitted By** page (page 8).
9. Enter the form ID on the **Form ID** page (page 9).
10. Finally, submit the date and time you submitted this request on the **Submitted On** and **Submitted Time** pages (pages 10 and 11).
11. Enter the name of the user who submitted this request on the **Submitted User** page (page 12).

## Field-by-Field Explanation

* **Request Details (Page 1)**: This page is where you enter the details of your request. Please provide a clear description of what you need to be distributed, including the location and any other relevant information.
* **Courseware Details (Page 2)**: Here, you enter the details about the courseware you are requesting. Make sure to provide accurate and complete information about the courseware.
* **Contact Info (Page 3)**: Enter your contact information so that we can get in touch with you if needed.
* **Date and Time (Page 4)**: Select the date and time you need the courseware to be distributed. Make sure to choose a specific date and time to avoid confusion.
* **Time Preferences (Page 5)**: If you have specific time preferences for the distribution, select them here.
* **Time Preferences List (Page 6)**: Select from the list of time preferences you provided in the previous page.
* **Distribution Request Status (Page 7)**: Select the status of your request (Active or Inactive).
* **Assigned Tool (Page 8)**: Enter the tool assigned to you for this request.
* **Submitted By (Page 9)**: Enter the name of the user who submitted this request.
* **Form ID (Page 10)**: Enter the unique ID assigned to this form.
* **Submitted On (Page 11)**: Select the date on which you submitted this request.
* **Submitted Time (Page 12)**: Select the time you submitted this request.
* **Submitted User (Page 13)**: Enter the name of the user who submitted this request.

## Tips
* Make sure to double-check your information before submitting the form.
* Only submit one request per location.
* If you have any questions or need help, contact us through the contact information provided.
