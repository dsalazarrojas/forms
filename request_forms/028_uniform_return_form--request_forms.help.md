# Uniform Return Form - Help Guide

## Purpose
This form is designed to handle the return of uniform items that are no longer needed or defective. Please fill out this form to facilitate a smooth return process.

## How To Complete This Form
To complete this form, follow these steps:

1. Select a reason for return from the "Reason for Return" dropdown menu.
2. Provide a brief description of the item being returned in the "Item Description" field.
3. Enter the item number associated with the returned item.
4. Enter the serial number of the item being returned.

## Field-by-Field Explanation

* **Reason for Return** (uniform_return_form_1, select_one, optional):
	+ Select a reason why you are returning the uniform, such as "Defective" or "Not needed".
* **Item Description** (uniform_return_form_2, text, optional):
	+ A brief description of the item being returned, including any relevant details.
* **Item Number** (uniform_return_form_3, number, optional):
	+ The item number associated with the returned item. If you are unsure, please leave this field blank.
* **Serial Number** (uniform_return_form_4, text, optional):
	+ The serial number of the item being returned. If you are unsure, please leave this field blank.

## Tips
- Please fill out all fields that are marked as "required" to ensure a prompt and accurate return process.
- If you are unsure about any field, please contact the relevant department for assistance.
- Make sure to review your entries carefully before submitting the form to ensure accuracy.
