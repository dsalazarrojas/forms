# Release Order Form - Help Guide
## Purpose
The Release Order Form is used to collect essential details about a product or service release. This form helps the team gather necessary information for the release process.

## How To Complete This Form

1. Fill in the form with the required and optional fields. Each field is labeled and described below.
2. Answer each question accurately and thoroughly.
3. Review the form before submitting to ensure all necessary information is provided.

## Field-by-Field Explanation

* **Release Order Form** (`release_order_form`, text, optional)
	+ This field is a text box where you can provide a description or details about the release you're requesting.
	+ Enter a brief summary of the release, and include any relevant context or background information.
* **Recipient Details** (`recipient_details`, select multiple, optional)
	+ This field allows you to select who will receive the release (e.g., a person or a group).
	+ Choose the options that apply to the recipient.
* **Release Date** (`release_date`, date, optional)
	+ Enter the date of the release.
	+ Use the date format specified in your organization's guidelines.
* **Release Time** (`release_time`, time, optional)
	+ Enter the time of the release.
	+ Use the time format specified in your organization's guidelines.
* **Release Note** (`release_note`, note, optional)
	+ This field is a text box for any additional comments or notes about the release.
	+ Use this field to provide any extra context or details about the release.
* **Recipient Email** (`recipient_email`, email, optional)
	+ Enter the email address of the recipient.
	+ Ensure the email is valid and formatted correctly.
* **Recipient Phone** (`recipient_phone`, text, optional)
	+ Enter the phone number of the recipient.
	+ Use the correct format for international phone numbers.
* **Release Authorizer** (`release_authorizer`, select one, optional)
	+ Choose whether the release requires authorization (yes or no).
	+ Select 'Yes' if the release requires authorization, and 'No' otherwise.
