# Event Request Form - Help Guide
## Purpose
The Event Request Form is used to submit requests for events such as meetings, conferences, and other gatherings within the organization.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the date you would like to schedule the event.
2. Provide a title for the event.
3. Enter the venue where the event will take place.
4. Describe the event in detail.
5. Enter the start and end times of the event.
6. Enter the expected duration of the event.
7. Provide the expected capacity of the event.
8. Enter the number of guests attending the event.
9. Enter the contact information for the person submitting the request.
10. Choose the type of event (Yes/No).
11. Choose the event category (Yes/No).
12. Enter the location where the event will take place.
13. Enter a description of the event venue.
14. Enter the type of event request (e.g. meeting, conference, etc.).
15. Add any additional information about the event.
16. Enter any notes about the event.
17. Enter the name of the event speaker (if applicable).
18. Enter the name of the sponsor (if applicable).
19. Choose the status of the event (Active/Inactive).
20. Choose the priority of the event (Yes/No).

## Field-by-Field Explanation

* **Request Date** (`request_date`, Date, Optional): Enter the date you would like to schedule the event.
* **Event Title** (`event_title`, Text, Optional): Provide a title for the event.
* **Venue** (`venue`, Text, Optional): Enter the venue where the event will take place.
* **Description** (`description`, Text, Optional): Describe the event in detail.
* **Start Time** (`event_start_time`, Time, Optional): Enter the start time of the event.
* **End Time** (`event_end_time`, Time, Optional): Enter the end time of the event.
* **Event Duration** (`event_duration`, Number, Optional): Enter the expected duration of the event.
* **Event Capacity** (`event_capacity`, Text, Optional): Provide the expected capacity of the event.
* **Number of Guests** (`number_of_guests`, Text, Optional): Enter the number of guests attending the event.
* **Contact Name** (`contact_name`, Text, Optional): Enter the contact information for the person submitting the request.
* **Contact Email** (`contact_email`, Email, Optional): Enter the contact email for the person submitting the request.
* **Contact Phone** (`contact_phone`, Text, Optional): Enter the contact phone number for the person submitting the request.
* **Contact Phone 2** (`contact_phone2`, Text, Optional): Enter any additional contact phone numbers (if applicable).
* **Contact Organization** (`contact_organization`, Text, Optional): Enter the organization associated with the contact person.
* **Event Type** (`event_type`, Select One, Optional): Choose the type of event (Yes/No).
* **Event Category** (`event_category`, Select One, Optional): Choose the event category (Yes/No).
* **Event Location** (`event_location`, Text, Optional): Enter the location where the event will take place.
* **Event Venue Description** (`event_venue_description`, Text, Optional): Enter a description of the event venue.
* **Event Request Type** (`event_request_type`, Text, Optional): Enter the type of event request (e.g. meeting, conference, etc.).
* **Additional Info** (`event_additional_info`, Text, Optional): Add any additional information about the event.
* **Event Notes** (`event_notes`, Text, Optional): Enter any notes about the event.
* **Event Speaker** (`event_speaker`, Text, Optional): Enter the name of the event speaker (if applicable).
* **Event Sponsor** (`event_sponsor`, Text, Optional): Enter the name of the sponsor (if applicable).
* **Event Status** (`event_status`, Select One, Optional): Choose the status of the event (Active/Inactive).
* **Event Priority** (`event_priority`, Select One, Optional): Choose the priority of the event (Yes/No).
