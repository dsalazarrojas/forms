# Floor Plan Drawing Request Form - Help Guide
## Purpose
The Floor Plan Drawing Request Form is used to submit a request for a floor plan drawing. This form helps the building owner or their representative provide essential information about the building, its location, and its requirements for the drawing.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the building type (e.g., Residential, Commercial, etc.)
2. Choose the building style (e.g., Modern, Art Deco, etc.)
3. Enter the building's size in square feet
4. Enter the floor dimensions in feet
5. Specify the building's orientation (optional)
6. Choose the scale of the floor plan drawing (e.g., 1:1, 1:5, etc.)
7. Choose the units of measurement for the floor plan drawing (e.g., Square Feet, Square Meters, etc.)
8. Select a date for the drawing request
9. Enter the address of the building, including city, state, zip, and country
10. Enter the phone number of the building owner or contact person

## Field-by-Field Explanation

* **Building Type**: Select the type of building you are requesting a floor plan drawing for (e.g., Residential, Commercial, etc.).
* **Building Style**: Choose the style of the building you are requesting a floor plan drawing for (e.g., Modern, Art Deco, etc.).
* **Building Size**: Enter the size of the building in square feet.
* **Floor Dimensions**: Enter the dimensions of the floor in feet.
* **Building Orientation**: Specify the orientation of the building (optional).
* **Floor Plan Drawing Scale**: Choose the scale of the floor plan drawing (e.g., 1:1, 1:5, etc.).
* **Floor Plan Drawing Units**: Choose the units of measurement for the floor plan drawing (e.g., Square Feet, Square Meters, etc.).
* **Drawing Request Date**: Select a date for the floor plan drawing request.
* **Building Address**: Enter the address of the building, including city, state, zip, and country.
* **Building Phone**: Enter the phone number of the building owner or contact person.
* **Assigned Tool**: Select the tool to be assigned for the floor plan drawing (e.g., chatjimmy).
* **Assigned User**: Enter the name of the user assigned to complete the floor plan drawing.
* **Assigned User Email**: Enter the email of the user assigned to complete the floor plan drawing (optional).
* **Assigned User Phone**: Enter the phone number of the user assigned to complete the floor plan drawing.
* **Notes**: Add any additional comments or notes about the building or the request.
* **Floor Plan Drawing Request Comments**: Add any additional comments or information about the request.
* **Floor Plan Drawing Request Attachments**: Attach any relevant documents or images to the request.
* **Drawing Requester**: Enter the name of the person or entity requesting the floor plan drawing (optional).
* **Drawing Requester Email**: Enter the email of the person or entity requesting the floor plan drawing (optional).
* **Building Zip**: Enter the zip code of the building.
* **Building Country**: Enter the country of the building.

Tips:
* Make sure to provide accurate and complete information about the building to ensure the floor plan drawing meets your needs.
* If you are unsure about any of the fields, please contact the assigned user for clarification.
* If you have any additional comments or questions, please enter them in the "Notes" field.
