# New Hire Registration Form - Help Guide
## Purpose
The New Hire Registration Form is used to collect information from new employees for various departmental purposes, including next area of work, title of work, office, job order, and other necessary details.

## How To Complete This Form
1. Fill in the required fields with accurate and relevant information.
2. Select the correct options for next area of work, office, and other fields as per your work requirements.
3. Ensure that the manager and admin approvals are accurate and up-to-date.
4. Review and edit the form before submitting it.

## Field-by-Field Explanation

* **Next Area Of Work**: Select the department that this new hire will be working with.
	+ New IT Department: IT-related work
	+ New Sales Department: Sales-related work
	+ New Marketing Department: Marketing-related work
* **Title Of Work**: Enter the title of your work or position within the selected department.
* **Related Office**: Choose the office where the new hire will be based. 
	+ New IT Office: IT office location
	+ New Marketing Office: Marketing office location
	+ New Sales Office: Sales office location
* **Job Order**: Select the job order for the new hire (e.g., New IT Department, New Marketing Department, New Sales Department)
* **Tools Involved**: Check which tools you will be using for your work (e.g., 'Yes', 'No')
* **New Hire Progress Monitoring**: Select which department will be monitoring your progress.
	+ New IT Department: IT will be monitoring
	+ New Marketing Department: Marketing will be monitoring
	+ New Sales Department: Sales will be monitoring
* **Office Requesting Job Order**: Check if the office is requesting this job order (e.g., 'Yes', 'No')
* **Job Order Description**: Describe the job order in this field.
* **Contact Person**: Select the person to contact for this job order (e.g., John Doe, Jane Doe, Joe Doe)
* **Email**: Enter the email address of the contact person.
* **Phone**: Enter the phone number of the contact person.
* **New Hire Notes**: Add any additional information about the new hire.
* **Manager Approvals**: Check if the manager has approved this job order (e.g., 'Yes', 'No')
* **Manager Name**: Select the manager's name for this job order (e.g., Jane Doe, John Doe, Joe Doe)
* **Manager Email**: Enter the manager's email address.
* **Manager Phone**: Enter the manager's phone number.
* **Manager Comment**: Add any comments from the manager.
* **Admin Notes**: Add any additional information from the admin.
* **Admin Approvals**: Check if the admin has approved this job order (e.g., 'Yes', 'No')
* **Admin Name**: Select the admin's name (e.g., Jane Doe, John Doe, Joe Doe)
* **Admin Email**: Enter the admin's email address.
* **Admin Phone**: Enter the admin's phone number.
* **Admin Comment**: Add any comments from the admin.
* **New Hire Status**: Select the status of the new hire (e.g., New, Pending, Active)
* **Submit**: Click the submit button to finalize the form submission.
