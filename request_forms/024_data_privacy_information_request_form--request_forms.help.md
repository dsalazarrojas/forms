# Data Privacy Information Request Form - Help Guide
## Purpose
This form is used to request access to your personal data that is stored by the organization. Fill out this form to provide the necessary information for your request.

## How To Complete This Form
To complete this form, please fill out the following fields:

1. **Request Form** (`request_form`, text, optional)
	* This field is a text area where you can provide a brief description of your request. Please be as detailed as possible to help us understand your request.
2. **Request Description** (`request_description`, text, optional)
	* This field is another text area where you can provide any additional information about your request. Again, please provide as much detail as possible.
3. **Supporting Documents** (`supporting_documents`, select_multiple, optional)
	* If you have any supporting documents that are relevant to your request, please select them from the list below:
		+ Document 1
		+ Document 2
		+ Document 3
4. **Request Date** (`request_date`, date, optional)
	* If you have a specific date in mind for when you would like to access your data, please select it from the calendar.
5. **Request Time** (`request_time`, time, optional)
	* If you have a specific time in mind for when you would like to access your data, please select it from the time picker.
6. **Request Note** (`request_note`, note, optional)
	* This is an optional text area where you can provide any additional information or comments about your request.
7. **Request Email** (`request_email`, email, optional)
	* If you would like to receive updates or notifications about your request, please provide a valid email address.
8. **Request Phone** (`request_phone`, text, optional)
	* If you would like to be contacted by phone about your request, please provide a valid phone number.
## Tips
* Please ensure that the information provided is accurate and up-to-date.
* If you are unsure about any of the fields, please contact the organization for assistance.
* We will review your request and respond as soon as possible.
* Please note that we may request additional information or clarification from you before processing your request.
