# Military Conditional Release Request Form - Help Guide

## Purpose
The Military Conditional Release Request Form is used to document a request for a military unit's conditional release.

## How To Complete This Form
1. Fill in the required fields, which include:
	* Unit Name: The name of the unit requesting the release.
	* Soldier Name: The name of the soldier being released.
	* Request Date: The date the release was requested.
	* Request Status: The status of the request, which can be either Active or Inactive.
2. Fill in the optional fields, which include:
	* Unit Administrator: The name of the unit administrator who is submitting the request.
	* Request Time: The time the release was requested.
	* Reason for Release: A brief explanation of the reason for the release.
	* Release Date: The date the release is expected to take place.
	* Return Date: The date the soldier is expected to return.
	* Supervisor Signature: The supervisor's signature, which provides an official approval.
	* Unit Officer Signature: The unit officer's signature, which provides an official approval.
	* Reason for Release Why: A more detailed explanation of the reason for release.
	* Reason for Release What: A description of the specific circumstances or events leading to the release.
	* Reason for Release When: The timing of the release, including specific dates or deadlines.
	* Reason for Release Where: The location or context of the release.

## Field-by-Field Explanation
* **Unit Administrator** (`unit_administrator`): Enter the name of the unit administrator who is submitting this request.
* **Request Date** (`request_date`): Enter the date the release was requested.
* **Request Time** (`request_time`): Enter the time the release was requested.
* **Reason for Release** (`reason_for_release`): Enter a brief explanation of the reason for release.
* **Release Date** (`release_date`): Enter the date the release is expected to take place.
* **Return Date** (`return_date`): Enter the date the soldier is expected to return.
* **Supervisor Signature** (`supervisor_signature`): Sign and date the supervisor's approval.
* **Unit Officer Signature** (`unit_officer_signature`): Sign and date the unit officer's approval.
* **Request Status** (`request_status`): Select Active or Inactive to indicate the status of the request.
* **Unit Name** (`unit_name`): Enter the name of the unit requesting the release.
* **Soldier Name** (`soldier_name`): Enter the name of the soldier being released.
* **Reason for Release Why** (`reason_for_release_why`): Enter a detailed explanation of the reason for release.
* **Reason for Release What** (`reason_for_release_what`): Enter a description of the specific circumstances or events leading to the release.
* **Reason for Release When** (`reason_for_release_when`): Enter the timing of the release, including specific dates or deadlines.
* **Reason for Release Where** (`reason_for_release_where`): Enter the location or context of the release.
