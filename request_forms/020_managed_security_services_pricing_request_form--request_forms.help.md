# Managed Security Services Pricing Request Form - Help Guide
## Purpose
This form is used to request managed security services from the organization. Please provide detailed information about your security needs and concerns so that our team can tailor a pricing solution to meet your requirements.

## How To Complete This Form
1. Select the type of security services you are interested in, such as Compliance and Governance, Cloud Security, or Security Consulting.
2. Enter your customer name, contact information, company name, and any other relevant details.
3. Describe your security concerns or areas where you need help.
4. Submit the form to send your request to our team.

## Field-by-Field Explanation
* **Which security services do you need?**: This field allows you to select the type of security services you are interested in. Please choose one or more from the list:
	+ Compliance and Governance
	+ Cloud Security
	+ Cyber Security Awareness
	+ Identity and Access Management
	+ Incident Response
	+ Penetration Testing
	+ Security Consulting
	+ Security Auditing
	+ Security Policy Development
	+ Vulnerability Management
* **Customer Name**: Enter your name so that we can address you correctly.
* **Contact Information**: Provide your email address and any other relevant contact details. This will help us get in touch with you promptly.
* **Company Name**: If you are requesting security services for your company, enter your company name here.
* **Security Concerns**: Describe your security concerns or areas where you need help. Please provide detailed information to help us better understand your requirements.
* **Note**: Please use this field for any additional comments or information that might be helpful in understanding your request.

## Tips
- Make sure to provide accurate and detailed information in all fields to ensure that we can assist you effectively.
- If you have any questions or need further clarification on the form, please contact our team.
