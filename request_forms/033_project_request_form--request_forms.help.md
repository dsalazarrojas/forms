# Project Request Form - Help Guide

## Purpose

The project request form is used to collect information about project requests submitted by team members or external partners. It helps project managers to track and manage project requests, including their status, priority, and completion date.

## How To Complete This Form

To complete this form, follow these steps:

1. Fill in the **Project Title** field with a brief description of the project.
2. Provide a detailed **Project Description** of the project.
3. Clearly state the **Purpose** of the project.
4. Specify the **Objective** of the project.
5. Choose a **Completion Date** for the project.
6. Select whether **Weekly Report** is required or not.
7. Specify the **Content Materials** required for the project (if any).
8. Choose the **Request Type** of the project.
9. Select the **Priority** level of the project.
10. Choose the **Completion Status** of the project.
11. Select the **Project Priority** level.
12. Choose the **Project Status** of the project.
13. Provide any additional **Notes** about the project (if needed).
14. Enter the **Email** address of the project requester.
15. Enter the **Phone** number of the project requester.
16. Specify the **Contact Person** responsible for the project.
17. Specify the **Department** of the project.
18. Specify the **Project Requester** name.
19. Specify the **Project Approver** name.
20. Specify the **Project Owner** name.
21. Enter the **Project Start Date** (if applicable).
22. Enter the **Project End Date** (if applicable).
23. Enter the **Project Deadline** (if applicable).

## Field-by-Field Explanation

* **Project Title** (1, text, required): A brief description of the project.
* **Project Description** (2, text, required): A detailed description of the project.
* **Purpose** (3, text, required): A clear statement of the project's purpose.
* **Objective** (4, text, required): A clear statement of the project's objective.
* **Completion Date** (5, date, required): The date by which the project should be completed.
* **Weekly Report** (6, select_one, required): Whether weekly reports are required for the project.
* **Content Materials** (7, text, optional): Any additional content materials required for the project.
* **Request Type** (8, select_multiple, required): The type of project request.
* **Priority** (9, select_one, required): The priority level of the project (High, Medium, Low).
* **Completion Status** (12, select_multiple, required): The status of the project (In Progress, Completed, Pending).
* **Project Priority** (13, select_one, required): The project priority level (High, Medium, Low).
* **Project Status** (14, select_one, required): The status of the project (Active, Inactive).
* **Notes** (15, note, optional): Any additional notes about the project.
* **Email** (16, email, optional): The email address of the project requester.
* **Phone** (17, text, optional): The phone number of the project requester.
* **Contact Person** (18, text, optional): The contact person responsible for the project.
* **Department** (19, text, optional): The department responsible for the project.
* **Project Requester** (20, text, optional): The name of the project requester.
* **Project Approver** (21, text, optional): The name of the project approver.
* **Project Owner** (22, text, optional): The name of the project owner.
* **Project Start Date** (23, date, optional): The start date of the project.
* **Project End Date** (24, date, optional): The end date of the project.
* **Project Deadline** (25, date, optional): The deadline for the project.

Note: If you are unsure about any of the fields, please ask your project manager or support team for assistance.
