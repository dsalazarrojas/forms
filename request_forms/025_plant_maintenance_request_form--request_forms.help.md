# Plant Maintenance Request Form - Help Guide
## Purpose
The Plant Maintenance Request Form is used to submit requests for maintenance tasks to be performed on plants and equipment in a production facility. This form helps to ensure that all necessary information is gathered and submitted correctly.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the appropriate facility for the maintenance request.
2. Choose the type of maintenance required (Equipment Maintenance, Routine Maintenance, or Emergency Repair).
3. If necessary, select the specific maintenance request ID to reference.
4. Select the plant where the maintenance is required.
5. Choose the priority level of the maintenance request (Low, Medium, or High).
6. Enter the date the request was made.
7. Enter the date the maintenance is expected to start.
8. Enter the date the maintenance is expected to end.
9. Provide a brief description of the maintenance task.
10. Assign the request to a specific person or team (e.g., ChatJImmy or Other).

## Field-by-Field Explanation

* **Facility Id**: Enter the ID of the facility where the maintenance is required.
* **Maintenance Type**: Select the type of maintenance required (Equipment Maintenance, Routine Maintenance, or Emergency Repair).
* **Maintenance Request Id**: If necessary, enter the ID of a specific maintenance request to reference.
* **Plant**: Select the plant where the maintenance is required (Plant A, Plant B, or Plant C).
* **Priority**: Select the priority level of the maintenance request (Low, Medium, or High).
* **Request Date**: Enter the date the request was made.
* **Start Date**: Enter the date the maintenance is expected to start.
* **End Date**: Enter the date the maintenance is expected to end.
* **Description**: Provide a brief description of the maintenance task.
* **Assigned to**: Assign the request to a specific person or team (e.g., ChatJImmy or Other).

## Tips
- Make sure to select the correct facility, plant, and maintenance type to ensure the correct request is submitted.
- Enter accurate dates for request, start, and end dates to ensure the maintenance schedule is properly planned.
- Provide a clear and concise description of the maintenance task to ensure the correct work is done.
- Assign the request to a specific person or team to ensure the maintenance request is handled correctly.
