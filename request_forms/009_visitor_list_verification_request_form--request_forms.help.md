# Visitor List Verification Request Form - Help Guide
## Purpose
The Visitor List Verification Request Form is used to request verification of a visitor's list. This form is intended for authorized users to collect information from visitors, ensuring accurate and efficient processing of visitor lists.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter your First name.
2. Enter your Last name.
3. Enter your Email address (if you have one).
4. Enter your Phone number (if you have one).
5. Enter your Date of birth.
6. Enter the Time of visit.
7. If available, select the Visitor list type (if not sure, leave blank).
8. Provide any additional Comments (if necessary).
9. If assigned, select the Assigned Tool and Assigned User.

## Field-by-Field Explanation

* **First name**: Enter your first name (if it's not already provided). This field is required.
* **Last name**: Enter your last name (if it's not already provided). This field is required.
* **Email**: Enter your valid email address (if you have one). Leave blank if you don't have an email.
* **Phone number**: Enter your phone number (if you have one). Leave blank if you don't have a phone number.
* **Date of birth**: Enter your date of birth in the correct format (e.g., MM/DD/YYYY).
* **Time of visit**: Enter the time you plan to visit. This field is optional.
* **Visitor list ID**: Enter your Visitor list ID (if assigned). This field is optional.
* **Visitor list type**: If you know your Visitor list type, select from the available options (Option 1, Option 2, or Option 3). If unsure, leave blank.
* **Comments**: Provide any additional information you'd like to share with the assigned user.
* **Assigned Tool**: If assigned, select the Tool assigned to you.
* **Assigned User**: If assigned, select the User assigned to you.

**Note**: Some fields may be optional or have specific instructions for accurate completion. Please review each field carefully for specific guidance.
