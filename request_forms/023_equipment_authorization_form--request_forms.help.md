# Equipment Authorization Form - Help Guide
## Purpose
The Equipment Authorization Form is used to authorize the use of equipment within your organization. This form is used to track and manage the authorization process for equipment usage, ensuring that all necessary approvals are in place before equipment is used.

## How To Complete This Form
1. Start by selecting the start and end dates for the authorized equipment use period.
2. Enter the name of the organization that will be using the equipment.
3. Determine if the equipment is of type 'Yes' or 'No' (e.g., computer, vehicle, etc.).
4. Enter the name of the person authorizing the equipment use.
5. Specify the duration of the authorization period (e.g., hours, days, etc.).

## Field-by-Field Explanation
* **Start Date**: Enter the date the equipment was first authorized for use.
* **End Date**: Enter the date the equipment's authorized use period ends.
* **Organization Name**: Enter the name of the organization that will be using the equipment.
* **Equipment Type**: Select 'Yes' if the equipment is a type that requires authorization (e.g., high-risk equipment, etc.). Select 'No' if it's not.
* **Authorized By**: Enter the name of the person authorizing the equipment use.
* **Authorization Duration**: Enter the duration of the authorization period (e.g., number of hours, days, etc.).
