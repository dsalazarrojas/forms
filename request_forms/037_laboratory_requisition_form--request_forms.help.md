# Laboratory Requisition Form - Help Guide
## Purpose
This form is used to collect and track laboratory testing requests, including details about the test type, status, and results.

## How To Complete This Form
To fill out this form, follow these steps:

1. Fill in the required fields for each page.
2. Enter the requested information for the test type, status, and results.
3. Provide any additional information that may be required for the laboratory test request.

## Field-by-Field Explanation

* **Test Request** (`test_request`): Enter a brief description of the test or procedure being requested.
* **Test Type** (`test_type`): Select the type of test being requested (e.g. Blood Test, Urine Test, Other).
* **Test Status** (`test_status`): Select the current status of the test (e.g. Ordered, Received, Cancelled).
* **Medical Clinic** (`medical_clinic`): Enter the name of the medical clinic where the test is being requested.
* **Test Name** (`test_name`): Enter the name of the specific test being requested.
* **Lab Test Requester** (`laboratory_test_requester`): Enter any relevant information about the person or department requesting the test.
* **Laboratory Requisition Date** (`laboratory_requisition_date`): Enter the date the test was requested.
* **Patient Info** (`patient_info`): Enter any relevant information about the patient (e.g. name, ID number, etc.).
* **Test Ordering Date** (`test_ordering_date`): Enter the date the test was ordered.
* **Lab Test Requested by** (`lab_test_requested_by`): Enter the name or initials of the person or department that requested the test.
* **Laboratory Requisition Form ID** (`laboratory_requisition_form_id`): A unique identifier for this test request.
* **Assigned to** (`assigned_to`): Select the name of the person or department assigned to process the test request.
* **Test Result** (`test_result`): Select the result of the test (e.g. Positive, Negative, Pending).
* **Patient Name** (`patient_name`): Enter the name of the patient undergoing the test.
* **Laboratory Requisition Status** (`laboratory_requisition_status`): Select the status of the test request (e.g. Open, Closed, Completed).
* **Test Ordering Time** (`test_ordering_time`): Enter the time the test was ordered.
* **Laboratory Requester Info** (`laboratory_requester_info`): Enter any relevant information about the person or department requesting the test.
* **Test Ordered by** (`test_ordered_by`): Enter the name or initials of the person or department that ordered the test.
* **Lab Test Results** (`lab_test_results`): Enter the result of the test.
* **Laboratory Test Result Status** (`laboratory_test_result_status`): Select the status of the test result (e.g. In Progress, Complete, Cancelled).
* **Test Requested Time** (`test_requested_time`): Enter the time the test was requested.
* **Laboratory Requisition Form Category** (`laboratory_requisition_form_category`): Select the category for the test request (e.g. Request Forms, Laboratory Forms).
* **Laboratory Test Requested Time** (`laboratory_test_requested_time`): Enter the time the test was requested.
