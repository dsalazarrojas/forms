# Report Request Form - Help Guide
## Purpose

The Report Request Form is used to request reports on projects. This form collects information about the project and the person requesting the report.

## How To Complete This Form

To complete this form, follow these steps:

1. Enter the name of the project you are requesting a report on.
2. Choose the status of the project (pending, ongoing, or completed).
3. Select the start date of the project (if known).
4. Select the due date of the project (if known).
5. Describe the project in a few sentences.
6. Enter your name as the report requester.
7. Enter your email address (in the format of `username@example.com`).
8. Enter your phone number (optional).
9. Enter your address.

## Field-by-Field Explanation

* **Report Request Form**: The title of the form that you are filling out. This will be used for reference purposes.
* **project_name**: The name of the project you are requesting a report on. Please enter the project name as it appears in the project list.
* **project_status**: The current status of the project (pending, ongoing, or completed).
* **project_start_date**: The start date of the project (if known). Enter the date in the format `YYYY-MM-DD`.
* **project_due_date**: The due date of the project (if known). Enter the date in the format `YYYY-MM-DD`.
* **project_description**: Briefly describe the project in a few sentences.
* **report_requester**: Your name as the person requesting the report.
* **report_requester_email**: Your email address in the format `username@example.com`.
* **report_requester_phone**: Your phone number (optional).
* **report_requester_address**: Your physical address.

## Tips

* Make sure to fill out the form completely and accurately.
* Check your project status before submitting the form.
* Enter your contact information correctly to ensure we can contact you with updates about your report.
