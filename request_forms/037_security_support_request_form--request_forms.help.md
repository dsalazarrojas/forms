# Security Support Request Form - Help Guide

## Purpose
The purpose of this form is to submit requests for security support when an incident occurs. This form helps the support team to quickly assess and address incidents.

## How To Complete This Form
To complete this form, follow these steps:

1.  Select the relevant report type for your incident.
2.  Enter a brief description of the incident in the "Incident Description" field.
3.  Enter the date of the incident in the "Report Date" field.
4.  If applicable, indicate which areas of the system or application were affected.
5.  Indicate which teams were affected by the incident.
6.  Select the priority level of your request.
7.  Finally, select the type of incident that occurred.

## Field-by-Field Explanation
* **Report Type** (`report_type`, select_one, optional):
	+ This field allows you to select the type of report you are submitting. Please choose the most accurate option for your incident.
* **Incident Description** (`incident_description`, text, optional):
	+ Provide a brief description of what happened. This will help the support team to quickly understand the nature of the incident.
* **Report Date** (`report_date`, date, optional):
	+ Enter the date of the incident. This will help the support team to track the timeline of the incident.
* **Incident Severity** (`incident_severity`, select_one, optional):
	+ If the incident had any severity, please select "Yes" or "No" accordingly.
* **Affected Areas** (`incident_affected_areas`, select_multiple, optional):
	+ Check the areas affected by the incident, if any.
* **Affected Teams** (`incident_affected_teams`, select_multiple, optional):
	+ Indicate which teams were affected by the incident.
* **Request Priority** (`request_priority`, select_one, optional):
	+ Select the priority level of your request. This will help the support team to quickly understand the urgency of your request.
* **Incident Type** (`incident_type`, select_one, optional):
	+ Select the type of incident that occurred.
