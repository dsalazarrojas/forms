# Information Technology Master Data Request Form - Help Guide
## Purpose
The Information Technology Master Data Request Form is designed to collect information related to IT requests, including request type, priority, business impact, request date, due date, status, assignee, and attachments. This form helps the IT team understand the nature of the request, allocate resources effectively, and ensure timely resolution.

## How To Complete This Form
1. Start by selecting the correct Request Type from the options provided.
2. Enter the Description of the request in the provided field.
3. Choose the Priority of the request from Low to High.
4. Select the Business Impact of the request from Low to High.
5. Enter the Request Date and Due Date in the format YYYY-MM-DD.
6. Choose the Status of the request from New, In Progress, or Resolved.
7. Enter the Assignee Name and Assignee Email (if available).
8. Enter the Submitting User Name and Submitting User Email.
9. Optionally, you can provide additional information or comments using the Submitter Notes or Submitter Comments fields.
10. If you have attached files, enter the File Name and provide the File URL.

## Field-by-Field Explanation

* **Request Type** (Required)
	+ This field indicates whether the request is a new request or a follow-up to an existing request.
* **Description** (Required)
	+ Provide a clear and concise description of the request.
* **Priority** (Required)
	+ Choose the priority level of the request from Low, Medium, or High.
* **Business Impact** (Required)
	+ Select the business impact level of the request from Low, Medium, or High.
* **Request Date** (Required)
	+ Enter the date the request was made in YYYY-MM-DD format.
* **Due Date** (Required)
	+ Enter the date by which the request should be resolved in YYYY-MM-DD format.
* **Status** (Required)
	+ Choose the current status of the request from New, In Progress, or Resolved.
* **Assignee Name** (Required)
	+ Enter the name of the assignee responsible for handling the request.
* **Assignee Email** (Optional)
	+ Enter the email of the assignee (if available).
* **Submitting User Name** (Required)
	+ Enter the name of the submitting user.
* **Submitting User Email** (Required)
	+ Enter the email of the submitting user.
* **Submitter Info** (Optional)
	+ Enter any additional information you'd like to provide about yourself.
* **Submitter Notes** (Optional)
	+ Enter any additional comments or notes about the request.
* **Submitter Comments** (Optional)
	+ Enter any additional comments or feedback about the request.
* **Attachments** (Optional)
	+ If you've attached files, enter the file name and provide the file URL.
* **File Name** (Optional)
	+ Enter the name of the attached file.
* **File URL** (Optional)
	+ Enter the URL of the attached file.
* **File Size** (Optional)
	+ Enter the size of the attached file.
* **File Type** (Optional)
	+ Enter the type of the attached file.
* **File Description** (Optional)
	+ Enter a brief description of the attached file.
* **File Upload** (Optional)
	+ This field is not used, instead, attach your file and provide the File URL.
