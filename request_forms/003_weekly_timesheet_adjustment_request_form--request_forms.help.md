# Weekly Timesheet Adjustment Request Form - Help Guide
## Purpose
The "Weekly Timesheet Adjustment Request Form" is used by employees to request adjustments to their weekly timesheet entries. This form helps to ensure that employees' work hours and activities are accurately reflected in their timesheet records.

## How To Complete This Form
1. Ensure that you have filled out all required fields (indicated by an asterisk \*).
2. Select the type of adjustment you wish to make from the "Adjustment Type" dropdown menu.
3. Enter the start and end dates of the adjustment period.
4. Enter the number of hours you wish to adjust.
5. Provide a brief reason for the adjustment.

## Field-by-Field Explanation
* **Weekly Timesheet Adjustment Request Form**: This is the title of the form, which is displayed at the top.
* **Week Start Date**: Enter the start date of the week you are making adjustments for. This date should match the start date of your timesheet week.
* **Week End Date**: Enter the end date of the week you are making adjustments for. This date should match the end date of your timesheet week.
* **Adjustment Type**: Select the type of adjustment you are making. Options include:
	+ Adjustments (e.g., removing incorrect hours)
	+ Additions (e.g., adding missing hours)
	+ Overtime (e.g., working extra hours)
	+ Leave (e.g., taking time off)
	+ Other (e.g., explaining a special situation)
* **Adjustment Start Date**: Enter the start date of the adjustment period.
* **Adjustment End Date**: Enter the end date of the adjustment period.
* **Hours**: Enter the number of hours you wish to adjust. Please ensure that this number is accurate.
* **Reason**: Provide a brief explanation for the adjustment. This will help administrators understand the context of the request.

## Tips
* Double-check all fields before submitting the form.
* Ensure that your adjustment request is clear and accurate.
* If you have any questions or concerns about your timesheet adjustments, contact your supervisor or HR representative.
