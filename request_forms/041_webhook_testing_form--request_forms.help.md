# Webhook Testing Form - Help Guide
## Purpose
This form is designed to help you test your webhooks and ensure they're working as expected. Fill out the form with details about your webhook's category, description, output file, assigned tool, event type, attachments, and payload.

## How To Complete This Form
To complete this form, follow these steps:

1. Choose the category that best describes your webhook (Request Forms).
2. Provide a brief description of your webhook.
3. Specify the output file you'd like to receive.
4. Select the tool assigned to your webhook (ChatJIMmy).
5. Choose the type of event your webhook handles (Webhook).
6. Add any attachments related to your webhook.
7. Include any additional information in the Payload field.

## Field-by-Field Explanation
* **Webhook Testing Form** (1, text, required/optional): Enter a name for your webhook.
* **Category** (2, select_multiple, required/optional): Select the category for your webhook (e.g., Request Forms).
* **Description** (3, text, required/optional): Enter a brief description of your webhook.
* **Output File** (4, text, required/optional): Specify the output file you'd like to receive.
* **Assigned Tool** (5, select_one, required/optional): Select the tool assigned to your webhook (e.g., ChatJIMmy).
* **Webhook Event Type** (6, select_multiple, required/optional): Choose the type of event your webhook handles (e.g., Webhook).
* **Attachments** (7, text, required/optional): Add any attachments related to your webhook.
* **Payload** (8, text, required/optional): Include any additional information about your webhook.
