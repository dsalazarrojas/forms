# Agent Removal Request Form - Help Guide
## Purpose
The Agent Removal Request Form is a critical document that initiates the process of removing an agent from systems and roles. It is used to provide formal notice of termination, resignation, internal transfer, or leave of absence of an agent and revoke access to necessary systems.

## How To Complete This Form

- Start by filling in the requested information:
    + **Manager Name**: Enter the name of the manager who is requesting the removal.
    + **Office Location**: Enter the department or office location where the agent works.
    + **Date of Request**: Select the date of the request.
    + **Agent Name**: Enter the full name of the agent being removed.
    + **Agent ID**: Enter the employee ID of the agent being removed.
    + **Type of Removal**: Select the reason for removal (e.g., termination, resignation, internal transfer, leave of absence, or retirement).
    + **Effective Date of Removal**: Enter the last working day of the agent.
    + **Reason for Removal**: Provide a detailed explanation for the removal.
    + **Access to be Revoked**: Select all systems that the agent will no longer have access to (e.g., email, CRM, office keys, VPN).
    + **Exit Interview Scheduled?**: Confirm if an exit interview is scheduled.
    + **Name of Authorizing Executive**: Enter the name of the executive authorizing the removal.

## Field-by-Field Explanation

* **-- Agent Removal Request --**: This is a header section that explains the purpose of the form.
* **Requested by - Manager Name**: This field is for the manager who is making the request to remove the agent.
* **Department or Office Location**: This field is for the department or office where the agent works.
* **Date of Request**: This field is for the date the agent's removal is being requested.
* **-- Agent to be Removed --**: This is a header section that explains the reason for the removal.
* **Agent Full Name**: This field is for the full name of the agent being removed.
* **Agent Employee ID**: This field is for the employee ID of the agent being removed.
* **Type of Removal - Termination, Resignation, Internal Transfer, Leave of Absence**: This field is for selecting the reason for the agent's removal.
* **Effective Date of Removal**: This field is for the last working day of the agent.
* **Reason for removal - provide details**: This field is for providing a detailed explanation for the removal.
* **Access to be revoked - Email, CRM, Office Keys, VPN**: This field is for selecting all systems that the agent will no longer have access to.
* **Exit interview scheduled?**: This field is for confirming if an exit interview is scheduled.
* **Name of Authorizing Executive**: This field is for the name of the executive authorizing the removal.

## Tips

- Be accurate and truthful when filling out this form.
- Ensure that you are authorized to make this request.
- If you are unsure about any of the fields, consult with the relevant authority before completing the form.
- This form is a formal document, so ensure that all fields are filled out accurately and completely.
- Review the form carefully before submission.
