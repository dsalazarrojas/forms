# HR Research Data Access Request Form - Help Guide
## Purpose
The HR Research Data Access Request Form is used to gather information about an employee's data access request for HR research purposes.

## How To Complete This Form
To complete this form, follow these steps:

1. Ensure you are submitting a unique request by checking the "Review Status" field for any outstanding requests.
2. Select the correct "Employee Details" category from the options provided.
3. Fill in the required "Employee Details Type" field to specify the type of employee.
4. If applicable, enter the employee's ID number and date of birth.
5. Provide the department and job title of the employee.
6. Enter the name of the employee's manager.
7. Describe the purpose and expected outcome of the request.
8. Optionally, select the review status and provide review comments.
9. Choose the type of research (HR, Non-HR, or Non-Research).

## Field-by-Field Explanation

* **HR Research Data Access Request Form**: This is the title of the form, which you should leave unchanged.
* **employee_details**: Select the category that best describes the type of employee, such as Full-time Employee, Part-time Employee, or Freelance.
* **employee_details_type**: Select the type of employee within the chosen category, also select Full-time Employee, Part-time Employee, or Freelance.
* **employee_id**: If you have the employee's ID number, enter it here.
* **date_of_birth**: If you have the employee's date of birth, enter it here (format: YYYY-MM-DD).
* **department**: Enter the department where the employee works.
* **job_title**: Enter the employee's job title.
* **manager_name**: Enter the name of the employee's manager.
* **purpose_of_request**: Describe the purpose of the data access request.
* **expected_outcome**: Describe the expected outcome of the data access request.
* **review_status**: If your request has been reviewed, select the status (Approved, Denied, or Pending).
* **review_comments**: If your request has been reviewed, enter any comments or feedback from the reviewer.
* **research_type**: Select the type of research (HR, Non-HR, or Non-Research).

### Tips
* Be as detailed as possible when providing employee information to ensure accurate processing of your request.
* Ensure you have the necessary permissions or approvals to access the requested data.
* If you are unsure about any field, consult the relevant personnel or HR representative.
