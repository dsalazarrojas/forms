# Academic Innovation Toolkit Request Form - Help Guide

## Purpose
This form is designed to help users request access to the Academic Innovation Toolkit. Please fill out this form carefully and accurately to ensure that your request is processed promptly.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the required fields, marked with an asterisk (*), completely and accurately.
2. For each field, provide as much detail as possible to facilitate efficient processing.
3. Ensure that you have approval from the current approver before submitting multiple requests.

## Field-by-Field Explanation

* **Requester full name** (`requester_name`, text, required): This field is for your full name, which will be used for communication and record-keeping purposes.
* **Contact email** (`email`, email, required): Enter your institutional email address, which will be used for correspondence and confirmation.
* **Department or unit** (`department`, text, optional): If applicable, please specify the department or unit requesting the toolkit.
* **Toolkit type requested** (`toolkit_type`, select_one, required): Choose the most relevant category for your request:
	+ Teaching toolkit
	+ Research toolkit
	+ Data analysis toolkit
	+ Accessibility toolkit
	+ Other
* **Intended use of toolkit** (`intended_use`, text, required): Briefly describe the planned activities or use of the toolkit.
* **Number of copies or licenses** (`number_of_copies`, number, optional): If applicable, estimate the quantity of the toolkit you need.
* **Desired timeline for delivery** (`timeline`, text, optional): Provide dates or semester for desired delivery.
* **Budget or funding source** (`budget_source`, text, optional): If applicable, provide department code or grant reference.
* **Approver confirmation** (`approver_confirmation`, text, optional): If required, please provide the signature or approver name for processing.

Note: This form is designed to gather all necessary information for efficient processing. Please fill out the form carefully and accurately to avoid delays or misunderstandings.
