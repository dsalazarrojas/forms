# ESP Feature Configuration Request - Help Guide
## Purpose
The ESP Feature Configuration Request form is designed to collect information from users to help us understand their needs and preferences for our ESP product. This form will help us identify areas of improvement and implement features that make the product more user-friendly and efficient.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the feature you would like to request or change in the "Feature Request" field.
2. In the "Team Name" field, select the team that will be using the requested feature.
3. Provide a brief explanation for the feature request in the "Feature Change Reason" field.
4. Specify the current version of the ESP product you are currently using in the "Current Version" field.
5. Enter the new version of the feature you are requesting in the "New Version" field.
6. For the "Impact Analysis" field, provide a brief analysis of how the new feature will impact the team's workflow or productivity.
7. In the "Testing Result" field, describe the results of any testing or trials you have conducted on the new feature.
8. Optionally, add any additional comments or feedback in the "Comments" field.

## Field-by-Field Explanation

* **Feature Request** (`Feature Request`, text, required): Enter the feature you would like to request or change in the ESP product. Be specific and clear about what you are looking for.
* **Team Name** (`team_name`, text, optional): Select the team that will be using the requested feature. This will help us understand which teams are affected by the feature request.
* **Feature Change Reason** (`feature_change_reason`, text, required): Provide a brief explanation for the feature request, including why the change is necessary.
* **Current Version** (`current_version`, text, optional): Specify the current version of the ESP product you are currently using.
* **New Version** (`new_version`, text, required): Enter the new version of the feature you are requesting.
* **Impact Analysis** (`impact_analysis`, text, optional): For the new feature, provide a brief analysis of how it will impact the team's workflow or productivity. This will help us understand the benefits and challenges associated with the new feature.
* **Testing Result** (`testing_result`, text, optional): In this field, describe the results of any testing or trials you have conducted on the new feature.
* **Comments** (`comments`, text, optional): Optionally, add any additional comments or feedback about the feature request or the ESP product.
