# Water Bottle Donation Request Form - Help Guide
## Purpose
This form is designed to collect information from donors for water bottle donations to be delivered to events, conferences, or other activities.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the required fields marked as "required" with the relevant information.
2. Make sure to select the correct options for each field according to your needs.
3. Review your information carefully before submitting the form.

## Field-by-Field Explanation

* **Request Details**: This section is not used in this form, but it was probably a leftover from the form's design.
* **Quantity Needed**: Enter the number of water bottles you would like to request.
* **Delivery Timing**: Select "Yes" if you would like to receive the water bottles on a specific date or time. Select "No" if you are unsure or flexible with the delivery timing.
* **Delivery Details**: Enter the details of the delivery, such as the method of delivery (e.g., pickup, delivery by courier, etc.).
* **Contact Name**: Enter the name of the person responsible for contacting you for the delivery.
* **Contact Email**: Enter the email address of the person responsible for contacting you for the delivery.
* **Delivery Method**: Select "Yes" if you would like to receive the water bottles through a specific delivery method (e.g., courier, pickup, etc.).
* **Delivery Address**: Enter the address where the water bottles will be delivered.
* **Notes**: Enter any additional information or comments about the request.
* **Confirm Delivery**: Select "Yes" if you confirm that you will receive the water bottles.
* **Confirmation Method**: Select "Yes" if you would like to confirm the delivery with the donor or organization.
* **Delivery Person**: Enter the name of the person responsible for delivering the water bottles.
* **Water Bottle Size**: Select the size of the water bottle you would like to request (e.g., small, large, etc.).
* **Water Bottle Type**: Select the type of water bottle you would like to request (e.g., regular, flavored, etc.).
* **Organization**: Select "Yes" if you are requesting for an organization or event.
* **Location**: Enter the location of the event or activity.
* **Contact Phone**: Enter the phone number of the person responsible for contacting you for the delivery.
* **Date**: Enter the date when you would like to receive the water bottles.
* **Time**: Enter the time when you would like to receive the water bottles.
* **Event**: Select "Yes" if this is a special event or activity.
* **Quantity**: Enter the total number of water bottles you would like to request.
* **Water Bottle Donor**: Select "Yes" if you are a water bottle donor.
* **Donor Name**: Enter the name of the donor.
* **Donor Email**: Enter the email address of the donor.
* **Donor Phone**: Enter the phone number of the donor.
 
This guide provides a clear overview of each field in the form. Please make sure to review it carefully before submitting your request.
