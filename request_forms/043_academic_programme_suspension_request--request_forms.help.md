# Academic Programme Suspension Request - Help Guide
## Purpose
This form is used by students to submit a request for academic programme suspension. The form collects necessary information from the student, including their full name, student ID, programme name, reason for suspension, proposed suspension start date, and expected return date. It also asks for supporting documents and comments from academic advisors, if applicable.

## How To Complete This Form

1.  To begin, click on the "Start" button to begin filling out the form.
2.  Enter your full name as per the "Student full name" field.
3.  Enter your institutional ID in the "Student identification number" field.
4.  Type the name of the programme you are currently enrolled in.
5.  In the "Reason for suspension" field, select a valid option from the dropdown menu, i.e. Medical, Personal, Financial, Academic, or Other.
6.  Enter your proposed suspension start date in the "Suspension start date" field. Be sure to follow the correct date format (YYYY-MM-DD).
7.  If possible, indicate your expected return date in the "Expected return date" field.
8.  If relevant, attach or describe any supporting documents in the "Supporting documents" field.
9.  If your academic advisor has any comments, please enter them in the "Academic advisor comments" field.
10. Finally, sign your name in the "Student signature" field by typing your full name.

## Field-by-Field Explanation
*   **-- Programme Suspension Request --** (`suspension_header`, Note, Not required): This is a header note that provides a brief description of the form's purpose.
*   **Student full name** (`student_name`, Text, Required): Enter your full name as per your legal identity documents.
*   **Student identification number** (`student_id`, Text, Required): Provide your institutional ID number, as assigned by the educational institution.
*   **Programme name** (`programme_name`, Text, Required): Type the name of your enrolled programme, e.g., Bachelor's of Engineering.
*   **Reason for suspension** (`suspension_reason`, Select, Required): Choose a valid reason for your programme suspension from the dropdown menu:
    +   Medical
    +   Personal
    +   Financial
    +   Academic
    +   Other
*   **Suspension start date** (`suspension_start_date`, Date, Required): Enter your proposed suspension start date in YYYY-MM-DD format.
*   **Expected return date** (`expected_return_date`, Date, Optional): If you know your expected return date, provide it in YYYY-MM-DD format. If not, leave this field blank.
*   **Supporting documents** (`supporting_documents`, Text, Optional): Attach any relevant documents or describe them if they are not attached.
*   **Academic advisor comments** (`advisor_comments`, Text, Optional): Enter any comments from your academic advisor, if applicable.
*   **Student signature** (`student_signature`, Text, Required): Type your full name to confirm submission.
