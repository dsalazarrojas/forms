# Event Listing Support Request - Help Guide
## Purpose
The Event Listing Support Request form is a tool used to report issues or requests related to an event listing. This form is intended to provide detailed information about an event in order to troubleshoot or resolve the issue.

## How To Complete This Form
To complete this form, follow these steps:

1.  Fill in the event title, ensuring it accurately represents the event.
2.  Provide the date and time of the event.
3.  Enter the location of the event.
4.  Select the type of organizer or team involved.
5.  Enter any contact information for the organizer or team.
6.  Describe the issue or request in detail.
7.  Provide any additional information that may be helpful to the support team.

## Field-by-Field Explanation
*   **Event Info** (`event_info`, text, optional): This field allows you to provide a brief description or details about the event. This can include any specific information about the event that may be relevant to resolving the issue.
*   **Event Date** (`event_date`, date, optional): Enter the date of the event.
*   **Event Time** (`event_time`, time, optional): Enter the time of the event.
*   **Event Location** (`event_location`, text, optional): Enter the location of the event.
*   **Organizer** (`organizer_info`, select_one, optional): Select who is responsible for the event, either "Event Team" or "Organizer".
*   **Contact Number** (`contact_number`, text, optional): Enter any contact information for the event organizer.
*   **Contact Email** (`contact_email`, email, optional): Enter the email address for the event organizer.
*   **Support Request** (`support_request`, text, optional): Describe the specific issue or request related to the event.
*   **Issue Description** (`issue_description`, text, optional): Provide a detailed description of the issue or request.
