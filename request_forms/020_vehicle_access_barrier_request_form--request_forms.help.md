# Vehicle Access Barrier Request Form - Help Guide

## Purpose

The Vehicle Access Barrier Request Form is used to request access to a gate that is inoperative or not accessible for vehicle use.

## How To Complete This Form

1. Fill out the form completely, ensuring that all required fields are filled in.
2. Enter your gate request details in the "Gate Request Details" field.
3. Select the gate type in the "Gate Type" field. Choose 'Yes' if you have access restrictions or 'No' if you don't.
4. Select the gate status in the "Gate Status" field. Select one or multiple options as necessary, such as 'Active', 'Inactive', 'Maintenance'.
5. Enter the number of vehicles requesting access in the "Vehicles" field.
6. Enter the date you are requesting access for in the "Access Request Date" field.
7. Enter the time you are requesting access for in the "Access Request Time" field.
8. Enter the gate operable height and width in the "Gate Operable Height" and "Gate Operable Width" fields respectively.
9. Select the gate opening type in the "Gate Opening Type" field. Choose 'Yes' or 'No' as necessary.
10. Enter the gate opening width in the "Gate Opening Width" field.

## Field-by-Field Explanation

* **Gate Request Details**:
  * (Gate Request Details, text, required): A brief description of why you need access to a specific gate.
* **Gate Type**:
  * (Gate Type, select_one, required): Choose 'Yes' if you need access restrictions or 'No' if you don't.
* **Gate Status**:
  * (Gate Status, select multiple, required): Select one or multiple options as necessary (e.g., 'Active', 'Inactive', 'Maintenance').
* **Vehicles**:
  * (Vehicles, number, required): Number of vehicles requesting access.
* **Access Request Date**:
  * (Access Request Date, date, required): Date you are requesting access for.
* **Access Request Time**:
  * (Access Request Time, time, required): Time you are requesting access for.
* **Gate Operable Height**:
  * (Gate Operable Height, number, required): Height of the gate that vehicles can access.
* **Gate Operable Width**:
  * (Gate Operable Width, number, required): Width of the gate that vehicles can access.
* **Gate Opening Type**:
  * (Gate Opening Type, select_one, required): Choose 'Yes' or 'No' as necessary.
* **Gate Opening Width**:
  * (Gate Opening Width, number, required): Width of the gate opening for vehicles.
