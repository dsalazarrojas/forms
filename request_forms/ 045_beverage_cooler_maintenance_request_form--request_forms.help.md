# Beverage Cooler Maintenance Request Form - Help Guide

## Purpose
This form is used to request maintenance for beverage coolers. It's designed to collect information about the issue, provide a convenient way to schedule repairs, and track progress. Please use this form to submit requests for maintenance or repairs for beverage coolers in a clear and detailed manner.

## How To Complete This Form
- To submit a maintenance request, start by filling out the personal information section with your full name and email address. This ensures we can contact you for updates and scheduling.
- Select the relevant date for your maintenance request.
- Choose the primary reason for your request from the available options.
- Provide any additional details about the issue if necessary.
- Confirm your agreement to the selected options.
- If applicable, estimate the value of the issue.
- If you have a preferred time for the maintenance, enter it in the time format. 
- Finally, add any final comments or remarks about the issue.

## Field-by-Field Explanation

* **Full name** (`full_name`, `text`, required): Enter your legal full name for contact purposes.
* **Email address** (`email`, `email`, required): Enter a valid email address for us to contact you for updates.
* **Phone number** (`phone`, `text`, optional): Include your country code if you're outside our local region. 
* **Date** (`reference_date`, `date`, required): Select the date relevant to your maintenance request.
* **Primary selection** (`primary_selection`, `select_one`, required): Choose the option that best applies to your reason for the maintenance request.
* **Quantity or rating** (`quantity_or_rating`, `number`, optional): Provide a whole number if you're reporting quantity or rating issues.
* **Additional details** (`additional_details`, `text`, optional): Provide any additional relevant information about the issue.
* **Please confirm agreement** (`agreement`, `select_multiple`, required): Select all options that apply to your agreement.
* **Estimated value** (`estimated_value`, `number`, optional): Enter the estimated value in decimal format if applicable.
* **Preferred time** (`preferred_time`, `time`, optional): Enter a time if scheduling is required for the maintenance.
* **Final comments or notes** (`final_comments`, `text`, optional): Add any final comments or remarks about the issue.
