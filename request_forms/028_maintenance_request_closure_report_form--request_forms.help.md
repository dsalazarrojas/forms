# Maintenance Request Closure Report Form - Help Guide
## Purpose
The Maintenance Request Closure Report Form is used to record and track the closure of maintenance requests. It should only be used by authorized personnel after the work has been completed.

## How To Complete This Form
To complete this form, follow these steps:

1. Review the maintenance request and ensure that it has been fully completed and documented.
2. Fill out the form accurately and thoroughly with all required information.
3. Make sure to save a copy of the form for future reference.

## Field-by-Field Explanation
* **Maintenance Type** (maintenance_request_closure_report_form_2):
  * Select the type of maintenance that was completed from the list of options (Option 1, Option 2, Option 3).
  * If the maintenance type is not listed, select "Other" and provide a detailed explanation in the "Maintenance Type (Other)" field.
* **Maintenance Type (Other)** (maintenance_request_closure_report_form_3):
  * This field is for specifying non-standard maintenance types not listed in the main options.
  * Please provide a detailed explanation of the maintenance type that was completed.
* **Description of Work Done** (maintenance_request_closure_report_form_4):
  * Provide a detailed description of the work completed.
  * Include any relevant details, such as the scope of work, tools used, and any notable issues or concerns.
* **Date Work Done** (maintenance_request_closure_report_form_5):
  * Enter the date the maintenance work was completed.
* **Time Work Done** (maintenance_request_closure_report_form_6):
  * Enter the time the maintenance work was completed.
* **Work Order Number** (maintenance_request_closure_report_form_7):
  * Enter the work order number associated with the maintenance request.
* **Technician Name** (maintenance_request_closure_report_form_8):
  * Enter the name of the technician who completed the maintenance work.
* **Supervisor Review** (maintenance_request_closure_report_form_9):
  * Select "Yes" if the supervisor has reviewed and approved the maintenance work.
  * Select "No" if the supervisor has not yet reviewed the work.
* **Supervisor Comments** (maintenance_request_closure_report_form_10):
  * If the supervisor has reviewed the work, enter any comments or feedback they may have.
* **Client Name** (maintenance_request_closure_report_form_11):
  * Enter the name of the client associated with the maintenance request.
* **Client Phone** (maintenance_request_closure_report_form_12):
  * Enter the phone number of the client associated with the maintenance request.

## Tips
* Make sure to fill out the form accurately and thoroughly.
* Double-check your answers for accuracy before submitting the form.
* Keep a record of the completed form for future reference.
