# Personalized Search Request - Help Guide
## Purpose
This form is used to collect information for creating a customized search query to be executed by our team. It is a request for a tailored search result based on your specific needs.

## How To Complete This Form
To complete this form, follow these steps:
1. Fill out the required fields with accurate and up-to-date information.
2. Enter your first name and last name in the "First Name" and "Last Name" fields.
3. Enter your company name in the "Company" field.
4. If you have an email address that you'd like to be contacted at, enter it in the "Email" field.
5. If you have a phone number where you can be contacted, enter it in the "Phone" field.
6. In the "Description" field, describe in as much detail as possible what you are looking for in the search results.
7. Choose the priority level of your search from "Low", "Medium", or "High" in the "Priority" field.
8. Finally, select the tool that you would like us to use for the search from the "Assigned Tool" field.

## Field-by-Field Explanation
* **First Name**: Enter your first name in this field.
* **Last Name**: Enter your last name in this field.
* **Company**: Enter your company name in this field.
* **Email**: This field is optional, but if you have an email address that you'd like to be contacted at, you can enter it here.
* **Phone**: This field is also optional, but if you have a phone number where you can be contacted, enter it here.
* **Description**: In this field, describe in as much detail as possible what you are looking for in the search results.
* **Priority**: Choose the level of priority you want us to give to your search. "Low" is less urgent, "Medium" is standard, and "High" is more urgent.
* **Assigned Tool**: Select the tool that you would like us to use for the search from the available options.
