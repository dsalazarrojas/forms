# Petty Cash Form - Help Guide
## Purpose
The Petty Cash Form is used to track and record petty cash transactions. This form helps accountants and financial administrators gather necessary information about expenses and transactions that fall under a specific category.

## How To Complete This Form

To complete this form, follow these steps:

- Fill in the required fields, such as Expense Date, Amount, and Expense Type.
- Select "Yes" or "No" for each of the other fields as applicable.
- Ensure you provide a valid email and phone number if the "Email" and "Phone" fields are filled in.
- If you select "Yes" for "Account Manager" or "Account Manager Id", make sure to enter a corresponding value for the "Account Name" field.

## Field-by-Field Explanation

* **Expense Date** (`expense_date`, date, required): Enter the date of the expense.
* **Account Id** (`account_id`, select_one, optional): Select the account that the expense relates to. This field is optional but recommended for accurate expense tracking.
* **Amount** (`amount`, number, optional): Enter the amount of the expense.
* **Category** (`category`, select_multiple, optional): Select any applicable categories for the expense. This field is optional but helps with expense filtering and reporting.
* **Notes** (`notes`, note, optional): Provide any additional notes or comments about the expense.
* **Email** (`email`, email, optional): Enter a valid email address if the expense requires communication. This field is optional but recommended for follow-up purposes.
* **Phone** (`phone`, text, optional): Enter a valid phone number if the expense requires phone communication. This field is optional but recommended for follow-up purposes.
* **Expense Type** (`expense_type`, select_one, optional): Select the type of expense (e.g., travel, meals, etc.).
* **Account Manager** (`account_manager`, select_one, optional): Select "Yes" if the expense requires account manager approval. This field is optional but recommended for accurate expense tracking.
* **Account Manager Id** (`account_manager_id`, select_one, optional): If you selected "Yes" for "Account Manager", enter the corresponding account manager's ID. This field is optional but recommended for accurate expense tracking.
* **Expense Date Note** (`expense_date_note`, note, optional): Enter any additional notes about the expense date.
* **Account Name** (`account_name`, select_one, optional): If you selected "Yes" for "Account Manager" or "Account Manager Id", select the corresponding account name.

## Tips

- Please ensure all required fields are filled out before submitting the form.
- Double-check the accuracy of all entered information before submission.
- Use the "Category" field to filter and report expenses for easy reference and analysis.
