# invoice_request_form - Help Guide
## Purpose
The invoice_request_form is used to request a new invoice from the system. Please use this form to submit a new request for an invoice if you need to create a new one.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the required information:
	* User Information (required)
	* Request Type (required)
	* Date (required)
	* Total Cost (required)
	* Tax Rate (required)
	* Payment Method (required)
2. Provide additional details:
	* Description (optional)
	* File Attachment (optional)
	* Shipping Address (optional)
	* Shipping Cost (optional)

## Field-by-Field Explanation
* **User Info**: Enter your name and contact information to help us process your invoice request.
* **Request Type**: Select the type of invoice you need: Invoice, Quote, or Estimate.
* **Date**: Enter the date you need the invoice for.
* **Description**: Provide a brief description of the invoice request, if needed.
* **File Attachment**: Attach any relevant files to support your invoice request.
* **Total Cost**: Enter the total cost of the items being invoiced.
* **Tax Rate**: Enter the tax rate to be applied to the invoice.
* **Tax Amount**: The system will automatically calculate the tax amount based on the tax rate and total cost.
* **Shipping Cost**: Enter the shipping cost, if applicable.
* **Shipping Address**: Enter the shipping address for the invoice.
* **Payment Method**: Select the payment method to be used for the invoice: Credit Card, Wire Transfer, or Check.
* **Payment Method**: Select the payment method to be used for the invoice: Credit Card, Wire Transfer, or Check.

Note: All fields marked as "required" are mandatory and must be filled out for the form to be submitted successfully. Optional fields can be filled out if you need to provide additional information.
