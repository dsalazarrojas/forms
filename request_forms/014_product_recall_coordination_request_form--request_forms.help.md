# Product Recall Coordination Request Form - Help Guide
## Purpose
This form is used to coordinate and record information for product recalls. It is used to gather data about the product, reason for recall, and other relevant details. Please ensure you have the necessary authorization and approval before submitting a request, and that the request is not a duplicate of a previously submitted request.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the product name in the **product_name** field.
2. Enter the product code in the **product_code** field.
3. Select the product category from the options in the **product_category** field.
4. Choose the reason for the recall from the options in the **reason_for_recall** field.
5. Enter the batch number in the **batch_number** field, if applicable.
6. Enter the product code again in the **product_code2** field, for verification purposes.
7. Enter a brief description of the product in the **product_description** field.
8. Enter the recall date in the **recall_date** field.
9. Enter the start and end dates for the recall in the **recall_start_date** and **recall_end_date** fields.
10. Enter the customer's name in the **customer_name** field.

## Field-by-Field Explanation
- **Product Name**: Enter the name of the product involved in the recall.
- **Product Code**: Enter the unique code assigned to the product.
- **Product Category**: Select the category of the product (e.g., Option 1, Option 2, or Option 3).
- **Reason for Recall**: Choose the reason for the recall from the available options (e.g., Option 1, Option 2, or Option 3).
- **Batch Number**: Enter the batch number, if applicable. This is usually found on the product's packaging or label.
- **Product Code 2**: Enter the product code again for verification purposes.
- **Product Description**: Enter a brief description of the product.
- **Recall Date**: Enter the date the recall is scheduled to start.
- **Recall Start Date**: Enter the start date of the recall.
- **Recall End Date**: Enter the end date of the recall.
- **Customer Name**: Enter the name of the customer requesting the recall.

## Tips
* Please ensure you have the necessary authorization and approval before submitting a request.
* Double-check the entered information for accuracy before submitting the form.
* If you're unsure about any field, please contact the relevant authorities for clarification.
