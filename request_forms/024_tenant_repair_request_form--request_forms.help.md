# tenant_repair_request_form - Help Guide
## Purpose
The Tenant Repair Request Form is designed to collect information from tenants about any issues or concerns they have with their rented property. This form is used to gather details about the problem, the tenant's description of the issue, and the date they first noticed it.

## How To Complete This Form
To complete this form, follow these steps:

1.  Click on the "Submit" button to start the form.
2.  On the first page, you will be asked to select the type of issue you are experiencing with your rented property. However, in this form, there is no option for selecting the type of issue, so please proceed to the next section.
3.  On the second page, type in a brief description of the issue you are experiencing with your rented property.
4.  On the third page, select the date you first noticed the issue.
5.  Once you have filled in the required fields, click on the "Submit" button to send the form.

## Field-by-Field Explanation
### Tenant Repair Issue
*   **Tenant Repair Issue** (`tenant_repair_issue`, text, optional): Describe the issue you are experiencing with your rented property. For example, "Leaky faucet" or "Broken light fixture".

### Description
*   **Description** (`description`, text, optional): Provide a detailed description of the issue you are experiencing with your rented property. This could include information like the location of the problem, how it affects your daily life, or any previous attempts to fix it.

### Report Date
*   **Report Date** (`report_date`, date, optional): Enter the date you first noticed the issue with your rented property. This helps our team track the history of your report and provide you with more accurate information on when to expect a solution.
