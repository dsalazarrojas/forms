# Teacher Request Form - Help Guide
## Purpose
The Teacher Request Form is designed to collect information from teachers about their requests, such as their title, student(s), school, subject(s), and whether they need help with specific subjects.

## How To Complete This Form
1. Ensure that you have all the necessary information before submitting the form.
2. Fill out the form accurately and completely.
3. Review the form carefully before submitting it.

## Field-by-Field Explanation
### 1. **Teacher** (select_one)
* This field allows you to select your title (Mr, Ms, Dr, or Other).

### 2. **Student** (select_one)
* This field allows you to select one or more students you are teaching.

### 3. **School** (text)
* In this field, enter your school name or identifier.

### 4. **Subject** (select_multiple)
* Select all the subjects you teach, separated by commas (e.g., Math, Science, English, History).

### 5. **Subject** (select_multiple)
* Select all the subjects you need help with, separated by commas (e.g., Math, Science, English, History).
 
### 6. **Subject** (select_multiple)
* This field is used to confirm your need for help with specific subjects.
 
## Tips
* Ensure that you have selected the correct student(s) and subject(s) for your request.
* If you need help with multiple subjects, make sure to select them all in the appropriate fields.
* Review your selection carefully before submitting the form to avoid errors.
