# Workmanship Warranty Submission - Help Guide
## Purpose
The purpose of this form is to submit a workmanship warranty claim to document and track workmanship-related issues. The claimant is the individual or company responsible for the workmanship issue.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the warranty claimant's name and email address in the corresponding fields.
2. Select the status of the warranty claim (Active, Inactive, or Unknown).
3. Enter the work order number related to the claim.
4. Attach any relevant images or photos to support the claim.
5. Provide a brief description of the workmanship issue in the comments field.
6. Optionally, you may add comments or attachments to provide further context.

## Field-by-Field Explanation
* **Warranty Claimant** (`warranty_claimant`, text, required): Enter the name of the individual or company responsible for the workmanship issue.
* **Claimant Name** (`claimant_name`, text, required): Enter the name of the claimant.
* **Claimant Email** (`claimant_email`, email, required): Enter the email address of the claimant.
* **Claimant Phone** (`claimant_phone`, text, optional): Enter the phone number of the claimant.
* **Warranty Date** (`warranty_date`, date, required): Select the date on which the warranty issue occurred.
* **Warranty Period** (`warranty_period`, text, optional): Enter any additional information about the warranty period, such as a date range.
* **Warranty Status** (`warranty_status`, select_one, required): Select the current status of the warranty claim (Active, Inactive, or Unknown).
* **Work Order Number** (`work_order_number`, text, required): Enter the number of the work order related to the claim.
* **Workmanship Description** (`workmanship_description`, note, optional): Enter a brief description of the workmanship issue.
* **Workmanship Images** (`workmanship_images`, select_multiple, required): Select one or more photos or images to attach to support the claim.
* **Workmanship Comments** (`workmanship_comments`, text, optional): Enter any additional comments or information about the workmanship issue.
* **Workmanship Attachment** (`workmanship_attachment`, text, optional): Attach any relevant files or documents to support the claim.
