# Preschool Student Skills Assessment Form - Help Guide

## Purpose
The Preschool Student Skills Assessment Form is a tool for teachers and caregivers to assess and track a preschool student's skills and abilities in various areas of development. This form helps to provide a snapshot of the student's skills at the end of each assessment period.

## How To Complete This Form
To complete this form, follow these steps:

1. Answer each question honestly and to the best of your ability.
2. For questions with multiple options, select all that apply.
3. For questions with a time or date field, enter the relevant information in the format required.
4. For questions with a text field, enter a brief description of the student's skills or abilities.

## Field-by-Field Explanation

* **preschool_student_skills_assessment_form_1_label** (`select_one`, required: false)
	+ This question asks whether the student demonstrates a basic understanding of colors. Please select 'Yes' if the student can identify and describe basic colors, and 'No' if they do not.
* **preschool_student_skills_assessment_form_2_label** (`select_multiple`, required: true)
	+ This question asks about the student's language and communication skills. Please select all of the areas where the student demonstrates these skills, such as:
		+ Identifies and describes basic shapes and colors
		+ Counts up to 10
		+ Tells stories or narratives
		+ Demonstrates an understanding of basic days and nights
		+ Shows an awareness of their name, age, and family members
	+ Other (please specify)
* **preschool_student_skills_assessment_form_3_label** (note, required: false)
	+ This section is for additional comments or observations about the student's skills or development. Please use this space to provide any relevant information that doesn't fit into one of the other categories.
* **preschool_student_skills_assessment_form_4_label** (text, required: false)
	+ This question asks about the student's fine motor skills. Please describe the student's ability to manipulate small objects, such as:
		+ Holding a pencil or crayon
		+ Using scissors
		+ Building with blocks
		+ Other (please specify)
* **preschool_student_skills_assessment_form_5_label** (number, required: true)
	+ This question asks about the student's ability to count up to a certain number. Please enter the highest number the student can count to.
* **preschool_student_skills_assessment_form_6_label** (number, required: true)
	+ This question asks about the student's ability to identify and write their name. Please enter the number of letters the student can write in their name.
* **preschool_student_skills_assessment_form_7_label** (`select_one`, required: false)
	+ This question asks whether the student demonstrates basic self-awareness. Please select 'Yes' if the student:
		+ Identifies themselves in a picture or mirror
		+ Demonstrates an understanding of their own feelings
		+ Shows an awareness of their own body
	+ Other (please specify)
* **preschool_student_skills_assessment_form_8_label** (`select_multiple`, required: true)
	+ This question asks about the student's social skills. Please select all of the areas where the student demonstrates these skills, such as:
		+ Initiates interactions with others
		+ Plays nicely with others
		+ Demonstrates empathy toward others
		+ Takes turns
		+ Shows an awareness of basic personal boundaries
		+ Other (please specify)
* **preschool_student_skills_assessment_form_9_label** (time, required: false)
	+ This question asks about the student's time estimation skills. Please enter the time it takes the student to complete a simple task, such as:
		+ Telling time (hours and minutes)
		+ Counting to 60 seconds
		+ Other (please specify)
* **preschool_student_skills_assessment_form_10_label** (date, required: false)
	+ This question asks about the student's awareness of basic concepts, such as:
		+ Days of the week
		+ Months of the year
		+ Other (please specify)
* **preschool_student_skills_assessment_form_11_label** (text, required: false)
	+ This section is for additional comments or observations about the student's skills or development. Please use this space to provide any relevant information that doesn't fit into one of the other categories.
* **preschool_student_skills_assessment_form_12_label** (email, required: false)
	+ This question is not applicable to this form.
* **preschool_student_skills_assessment_form_13_label** (text, required: false)
	+ This question is for any additional comments or concerns you have about the student's skills or development.

## Tips

* Please answer each question honestly and to the best of your ability.
* For questions with multiple options, select all that apply.
* If you have any additional comments or concerns, please use the provided space for additional comments or observations.
* If you are unsure about any question, please ask for clarification or assistance from your supervisor or administrator.
