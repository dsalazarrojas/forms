# Materials Release Form - Help Guide
## Purpose
The Materials Release Form is used to document and track the release of materials. This form captures essential details that help manage materials release effectively.

## How To Complete This Form

To complete this form, follow these steps:

1. Select the type of request from the 'Request Type' field. This will determine the type of materials release information you are submitting.
2. Enter the name of the material you are requesting to be released.
3. Enter the quantity of the material to be released.
4. Provide the release date for the materials.
5. Enter any reason for the release in the 'Reason for Release' field.
6. Add any comments related to the release in the 'Comments' field.
7. Enter contact information, including email and phone number, in the 'Contact Info' field.
8. Select whether the release is assigned to someone in the 'Assign To' field.
9. Confirm if the release is approved in the 'Approved By' field.
10. Enter the date approved and the title of the person approving the release in the 'Date Approved' and 'Approved By Title' fields.
11. Enter the name of the person approving the release in the 'Approved By Name' field.
12. Enter any release notes in the 'Release Notes' field.
13. Set the release date and time in the 'Release Date' and 'Release Time' fields.
14. Confirm if the release was submitted in the 'Submitted By' field.
15. Enter the date the release was submitted in the 'Submitted Date' field.
16. Enter the title and name of the person submitting the release in the 'Submitted By Title' and 'Submitter Name' fields.

## Field-by-Field Explanation
- **Request Type** (Required/Optional): Select the type of request you are submitting.
- **Material Name** (Optional): Enter the name of the material being released.
- **Quantity** (Optional): Enter the quantity of the material to be released.
- **Release Date** (Optional): Enter the date for the materials release.
- **Reason for Release** (Optional): Enter any reason for the materials release.
- **Comments** (Optional): Add any comments related to the release.
- **Contact Info** (Optional): Enter contact information, including email and phone number.
- **Assign To** (Optional): Select whether the release is assigned to someone.
- **Approved By** (Optional): Confirm if the release is approved.
- **Date Approved** (Optional): Enter the date approved.
- **Approved By Title** (Optional): Enter the title of the person approving the release.
- **Approved By Name** (Optional): Enter the name of the person approving the release.
- **Release Notes** (Optional): Enter any release notes.
- **Release Date** (Optional): Set the release date.
- **Release Time** (Optional): Set the release time.
- **Submitted By** (Optional): Confirm if the release was submitted.
- **Submitted Date** (Optional): Enter the date the release was submitted.
- **Assigned By Title** (Optional): Enter the title of the person assigned to the release.
- **Assigned By Name** (Optional): Enter the name of the person assigned to the release.
- **Submitted By Title** (Optional): Enter the title of the person submitting the release.
- **Submitter** (Optional): Enter the name of the person submitting the release.
- **Submitter Title** (Optional): Enter the title of the person submitting the release.
