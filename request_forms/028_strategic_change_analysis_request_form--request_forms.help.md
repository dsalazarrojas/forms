# Strategic Change Analysis Request Form - Help Guide
## Purpose
This form is used for requesting changes that are considered strategic in nature and that have significant impact on the organization.

## How To Complete This Form
1. Ensure that the change you are requesting is not a duplicate of an already existing request.
2. Thoroughly research and understand the implications of the change.
3. Clearly and concisely describe the change and its implications.
4. Fill out the form carefully and thoroughly.

## Field-by-Field Explanation

* **First Page**: This page is an introduction page with the section "first_page_section". Please select the appropriate option to describe the nature of the change.
  * **first_page_section**: Please select the option that best describes the category of the change (e.g., "Major Change", "Minor Change", etc.).
* **Second Page**: This page is used to provide a date for the change. Please enter the start date of the change.
  * **second_page**: Please enter the start date of the change.
* **Third Page**: This page is used to provide a date for the end of the change if it is not ongoing.
  * **third_page**: Please enter the end date of the change, if applicable.
* **Fourth Page**: This page is used to select one option for the change type. Please select the type of change (e.g., "New Project", "Process Change", etc.).
  * **fourth_page_section**: Please select the option that best describes the type of change.
* **Fifth Page**: This page is used to select multiple options for the impact on the organization. Please select all the options that apply.
  * **fifth_page_section**: Please select all the options that describe the impact of the change on the organization.
* **Sixth Page**: This page is used to provide a text description of the change. Please clearly and concisely describe the change.
  * **sixth_page**: Please provide a text description of the change.
* **Seventh Page**: This page is used to provide a date for the change. Please enter the end date of the change, if applicable.
  * **seventh_page**: Please enter the end date of the change, if applicable.
* **Eighth Page**: This page is used to select one option for the change type. Please select the type of change.
  * **eighth_page_section**: Please select the option that best describes the type of change.
* **Ninth Page**: This page is used to select multiple options for the impact on the organization. Please select all the options that apply.
  * **ninth_page_section**: Please select all the options that describe the impact of the change on the organization.
* **Tenth Page**: This page is used to provide a date for the change. Please enter the start date of the change.
  * **tenth_page**: Please enter the start date of the change.
* **Eleventh Page**: This page is used to select one option for the change type. Please select the type of change.
  * **eleventh_page_section**: Please select the option that best describes the type of change.
* **Twelfth Page**: This page is used to select multiple options for the impact on the organization. Please select all the options that describe the impact of the change on the organization.
  * **twelfth_page_section**: Please select all the options that describe the impact of the change on the organization.
* **Thirteenth Page**: This page is used to provide a text description of the change. Please clearly and concisely describe the change.
  * **thirteenth_page**: Please provide a text description of the change.

Note: The form has 13 pages, each with its own specific field for the user to fill out. Please ensure to carefully review each page before submitting the form.
