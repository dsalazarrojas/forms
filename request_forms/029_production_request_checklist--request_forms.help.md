# Production Request Checklist - Help Guide

## Purpose
The Production Request Checklist is used to collect production details for new requests. It is essential to fill out this form accurately to ensure that production requests are properly assessed and processed.

## How To Complete This Form
1. **Start by filling out the Production Details** field, which is a text field where you can enter any relevant production details.
2. **Select the Job Type**: Choose the type of job from the provided options. This will help us understand the nature of the request.
3. **Choose the Production Location**: Select the location where the production will take place.
4. **Enter the Production Date**: Fill out the date when the production is planned to start.
5. **Enter the Production Time**: Enter the time when the production is planned to start.
6. **Select the Job Status**: Choose the current status of the job from the provided options.
7. **Select Additional Production Details** (if necessary): If you need to provide more information about the production, you can select multiple options from the list.
8. **Enter Production Notes** (if necessary): If you have any additional comments or notes about the production, enter them in this field.

## Field-by-Field Explanation
* **Production Details (Production Request Checklist Form 1)**: Enter any relevant production details here. This can include information about the production, such as the name of the project or the equipment being used.
* **Job Type (Production Request Checklist Form 2)**: This field helps us understand the type of job being requested. Choose 'Yes' if this is a new job request, and 'No' if you are updating an existing job status.
* **Production Location (Production Request Checklist Form 4)**: Select the location where the production will take place.
* **Production Date (Production Request Checklist Form 5)**: Enter the date when the production is planned to start. This is usually in the format of mm/dd/yyyy.
* **Production Time (Production Request Checklist Form 6)**: Enter the time when the production is planned to start.
* **Job Status (Production Request Checklist Form 8)**: This field shows the current status of the job. Choose 'New' for new requests, 'In Progress' for ongoing productions, and 'Completed' when the production is finished.
* **Additional Production Details (Production Request Checklist Form 9)**: This field allows you to select multiple options that apply to the production. You can choose as many options as necessary to provide a detailed description of the production.
* **Production Notes (Production Request Checklist Form 10)**: This field is for any additional comments or notes about the production.
