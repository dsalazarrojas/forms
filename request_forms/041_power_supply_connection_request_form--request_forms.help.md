# Power Supply Connection Request Form - Help Guide
## Purpose
This form is used to request connections for power supply systems. It is meant to gather information about the connection type, power consumption, start and end dates, and other relevant details for the connection.

## How To Complete This Form
To complete this form, please follow these steps:

* Select a connection type from the list.
* Provide a detailed connection request.
* Enter the power consumption in watts or other unit specified by the form.
* Enter the start date for the connection.
* Enter the end date for the connection (if applicable).
* Specify the voltage of the power supply system.
* Specify the current of the power supply system.
* Choose the power factor for the connection.
* Add any additional comments if needed.
* Select the person assigned to handle the connection request.
* Choose the status of the connection request.
* Select the tool assigned to handle the connection request.
* Choose the power unit for the connection.
* Enter the name of the person who created the connection request.
* Enter the date the connection request was created.
* Enter the name of the person who modified the connection request.
* Enter the date the connection request was modified.
* Enter a unique connection ID.
* Enter the ID of the power supply system.
* Select the name of the power supply system.
* Select the model of the power supply system.
* Select the size of the power supply system.
* Select the type of power supply system.
* Add any notes for the connection request.

## Field-by-Field Explanation

* **Connection Type**: This field allows you to select the type of connection you are requesting. Please choose from the options provided.
* **Connection Request**: This field is for a detailed description of the connection request. Please provide a clear and concise description of the connection you are requesting.
* **Power Consumption**: This field is for the power consumption of the connection. Please enter the consumption in watts or the specified unit.
* **Start Date**: This field is for the start date of the connection. Please enter the date in the format dd/mm/yy.
* **End Date**: This field is for the end date of the connection (if applicable). Please enter the date in the format dd/mm/yy.
* **Voltage**: This field is for the voltage of the power supply system. Please enter the voltage in volts.
* **Current**: This field is for the current of the power supply system. Please enter the current in amperes.
* **Power Factor**: This field is for the power factor of the connection. Please choose from the options provided.
* **Comments**: This field is for any additional comments you may have about the connection request.
* **Assigned To**: This field is for selecting the person assigned to handle the connection request. Please choose from the options provided.
* **Status**: This field is for selecting the status of the connection request. Please choose from the options provided.
* **Assigned Tool**: This field is for selecting the tool assigned to handle the connection request. Please choose from the options provided.
* **Power Unit**: This field is for selecting the power unit for the connection. Please choose from the options provided.
* **Created By**: This field is for the name of the person who created the connection request.
* **Created On**: This field is for the date the connection request was created.
* **Modified By**: This field is for the name of the person who modified the connection request.
* **Modified On**: This field is for the date the connection request was modified.
* **Connection ID**: This field is for a unique connection ID.
* **Power Supply ID**: This field is for the ID of the power supply system.
* **Power Supply Name**: This field is for the name of the power supply system. Please select from the options provided.
* **Power Supply Model**: This field is for the model of the power supply system. Please select from the options provided.
* **Power Supply Size**: This field is for the size of the power supply system. Please select from the options provided.
* **Power Supply Type**: This field is for the type of power supply system. Please select from the options provided.
* **Notes**: This field is for any additional notes about the connection request.

**Tips**

* Please make sure to provide accurate and clear information in each field to ensure the connection request is handled efficiently.
* If you are unsure about any field, please ask for help or clarification before submitting the form.
* Please review the form carefully before submitting it to ensure all required fields are filled in correctly.
