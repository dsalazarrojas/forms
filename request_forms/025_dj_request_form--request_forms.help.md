# DJ Request Form - Help Guide
## Purpose
The DJ Request Form is used to gather information about a specific event, including the type of dance, song, and other details to create a customized playlist.

## How To Complete This Form
To complete this form, follow these steps:

1. Choose the type of dance for which you want the DJ to create a playlist (e.g., Dance, Event, Party, or Wedding).
2. Select the type of songs you want to be played during the event (e.g., Pop, Rock, or Hip-Hop).
3. Enter the name of the song you want to be included in the playlist.
4. Enter the name and contact information (email and phone number) of the person requesting the playlist.
5. Choose a date and time for the event.
6. Enter a message or notes about the event.
7. Select the tool or equipment you want to be assigned to the DJ.
8. Choose a category for the event (optional).
9. Enter a description of the event (optional).
10. Enter the form ID to track duplicates (only if you've already filled out this form before).

## Field-by-Field Explanation

* **Dance Type** (`id: 1`): Select the type of dance for which you want the playlist to be created (e.g., Dance, Event, Party, or Wedding).
* **Song Type** (`id: 2`): Select the type of songs you want to be played during the event (e.g., Pop, Rock, or Hip-Hop).
* **Song Name** (`id: 3`): Enter the name of the song you want to be included in the playlist.
* **DJ Name** (`id: 4`): Enter the name of the DJ who will be creating the playlist.
* **Email** (`id: 5`): Enter the email address of the person requesting the playlist.
* **Phone** (`id: 6`): Enter the phone number of the person requesting the playlist.
* **Event Date** (`id: 7`): Choose a date for the event.
* **Event Time** (`id: 8`): Choose a time for the event.
* **Message** (`id: 9`): Enter any additional notes or messages about the event.
* **Assigned Tool** (`id: 10`): Select the tool or equipment you want to be assigned to the DJ.
* **Category** (`id: 11`): Choose a category for the event (optional).
* **Description** (`id: 12`): Enter a description of the event (optional).
* **Form ID** (`id: 13`): Enter the form ID to track duplicates (only if you've already filled out this form before).
* **Output File** (`id: 14`): This field is not relevant for end-users.
* **Assigned Tool ID** (`id: 15`): Select the ID of the tool assigned to the DJ (e.g., chatjimmy or other).
* **Output File ID** (`id: 16`): This field is not relevant for end-users.

## Tips

* Make sure to fill out all required fields to ensure the DJ has all necessary information to create a great playlist.
* Check the form ID if you've already filled out this form before to avoid creating duplicates.
* If you have any further questions or concerns, please contact the DJ or the support team.
