# Stolen Firearm Report Form - Help Guide
## Purpose
The Stolen Firearm Report Form is designed to provide a standardized and efficient way to report a stolen firearm. Please use this form to report any stolen firearm you are aware of.

## How To Complete This Form
1. Select the correct type of firearm from the "Firearm Type" field.
2. Provide a detailed description of the firearm in the "Description" field.
3. If you have any additional details about the firearm, such as its model, serial number, caliber, color, year, or condition, fill them in accordingly.

## Field-by-Field Explanation
* **Firearm Type** (`Firearm Type`, select_one): Choose the type of firearm that was stolen (Handgun, Rifle, Shotgun, or Other).
* **Description** (`firearm_description`, text): Provide a detailed description of the firearm, including any distinctive features or markings.
* **Firearm Model** (`firearm_model`, text): If you know the firearm's model, please enter it here.
* **Firearm Serial Number** (`firearm_serial_number`, text): If you know the firearm's serial number, please enter it here.
* **Firearm Caliber** (`firearm_caliber`, text): If you know the firearm's caliber, please enter it here.
* **Firearm Color** (`firearm_color`, text): If you know the firearm's color, please enter it here. If not known, leave this field blank.
* **Firearm Year** (`firearm_year`, text): If you know the firearm's year of manufacture, please enter it here. If not known, leave this field blank.
* **Firearm Condition** (`firearm_condition`, text): If you know the firearm's condition, please enter it here.

## Tips
* Please ensure that you have a good faith belief that the firearm has been stolen before submitting this form.
* Do not submit duplicate reports for the same firearm.
* If you have any questions or concerns, contact the relevant authorities directly.
