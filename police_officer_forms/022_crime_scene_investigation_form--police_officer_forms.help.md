# crime_scene_investigation_form - Help Guide
## Purpose
The "crime_scene_investigation_form" is designed for documenting and gathering crucial information about crime scenes. This form helps investigators in collecting and storing data about cases in an organized and structured way.

## How to Complete This Form
To fill out this form, please follow the steps below:
1. Enter the "Case Number" to identify the specific case being investigated.
2. Enter the "Case Date" and "Case Time" to document the incident date and time.
3. Provide the "Investigator Name" for the officer handling the case.
4. Enter the location where the incident occurred.
5. Choose the "Incident Type" from the provided options (Assault/Aggression, Disorder/Disturbance, Theft, Vandalism, or Other).
6. Enter a detailed description of the suspect, if available.
7. Select the "Suspect Gender" from the provided options (Male, Female, or Unknown).
8. Enter the "Suspect Age" if known.
9. Enter any "Suspect Distinguishing Features" if applicable.
10. Enter the "Victim Name" if a victim is involved.
11. Enter the "Victim Age" if known.
12. Select the "Victim Gender" from the provided options (Male, Female, or Unknown).
13. Document any "Victim Injuries" if applicable.
14. Enter the "Weapon Used" if known.
15. Enter the "Vehicle Make" and "Vehicle Model" if a vehicle is involved.
16. Select the "Vehicle Color" from the provided options if applicable.
17. Enter the "Witness Name" if a witness is available.
18. Enter the "Witness Age" if known.
19. Select the "Witness Gender" from the provided options (Male, Female, or Unknown).
20. Enter a detailed description of the witness.
21. Enter the "Officer Name" for the officer handling the case.
22. Enter the "Officer Position" for the officer handling the case.
23. Add any "Notes" about the case for future reference.

## Field-by-Field Explanation

* **Case Number** (`case_number`, number, required): Enter a unique number to identify the case being investigated.
* **Case Date** (`case_date`, date, required): Enter the date the incident occurred.
* **Case Time** (`case_time`, time, required): Enter the time the incident occurred.
* **Investigator Name** (`investigator_name`, text, required): Enter the name of the officer handling the case.
* **Location** (`location`, text, required): Enter the address or location where the incident occurred.
* **Incident Type** (`incident_type`, select_one, required): Choose from Assault/Aggression, Disorder/Disturbance, Theft, Vandalism, or Other.
* **Suspect Description** (`suspect_description`, text, optional): Enter a detailed description of the suspect.
* **Suspect Gender** (`suspect_gender`, select_one, optional): Choose from Male, Female, or Unknown.
* **Suspect Age** (`suspect_age`, number, optional): Enter the age of the suspect if known.
* **Suspect Distinguishing Features** (`suspect_distinguishing_features`, text, optional): Enter any distinguishing features of the suspect.
* **Victim Name** (`victim_name`, text, optional): Enter the name of the victim.
* **Victim Age** (`victim_age`, number, optional): Enter the age of the victim if known.
* **Victim Gender** (`victim_gender`, select_one, optional): Choose from Male, Female, or Unknown.
* **Victim Injuries** (`victim_injuries`, text, optional): Enter any injuries sustained by the victim.
* **Weapon Used** (`weapon`, text, optional): Enter the type of weapon used.
* **Vehicle Make** (`vehicle_make`, text, optional): Enter the make of the vehicle involved.
* **Vehicle Model** (`vehicle_model`, text, optional): Enter the model of the vehicle involved.
* **Vehicle Color** (`vehicle_color`, text, optional): Enter the color of the vehicle.
* **Witness Name** (`witness_name`, text, optional): Enter the name of the witness.
* **Witness Age** (`witness_age`, number, optional): Enter the age of the witness if known.
* **Witness Gender** (`witness_gender`, select_one, optional): Choose from Male, Female, or Unknown.
* **Witness Description** (`witness_description`, text, optional): Enter a description of the witness.
* **Officer Name** (`officer_name`, text, optional): Enter the name of the officer handling the case.
* **Officer Position** (`officer_position`, text, optional): Enter the position of the officer handling the case.
* **Notes** (`notes`, text, optional): Enter any additional notes about the case.
