# Case Closure Form - Help Guide
## Purpose
The Case Closure Form is used to document and close cases, ensuring that all relevant information is accurately captured for review and reference purposes.

## How To Complete This Form
1. Review the case details and confirm that all issues have been resolved.
2. Fill in all required fields with accurate and detailed information.
3. Ensure that you have the necessary permissions and clearance to access the case details.
4. Double-check your responses for accuracy and completeness.
5. Review the form carefully before submitting it for supervisor review.

## Field-by-Field Explanation
* **Case Closure Report** (`closure_header`): A note field for official documentation of the case closure.
* **Case Number** (`case_number`): Enter the official case identifier.
* **Closure Date** (`closure_date`): Enter the date of case closure.
* **Closure Time** (`closure_time`): Enter the time of case closure (if applicable).
* **Case Information** (`case_info`): Provide original case details.
* **Type of Case** (`case_type`): Select the case classification from the provided options.
* **Case Category** (`case_category`): Enter the specific category of the case.
* **Date Case Opened** (`date_opened`): Enter the original opening date of the case.
* **Case Duration** (`case_duration`): Select the total investigation time from the provided options.
* **Primary Investigating Officer** (`investigating_officer`): Enter the name of the lead officer.
* **Officer Badge Number** (`officer_badge`): Enter the badge or ID number of the officer.
* **Reason for Case Closure** (`closure_reason`): Select the reason for case closure from the provided options.
* **Detailed Closure Explanation** (`closure_details`): Provide a comprehensive explanation of the case closure.
* **Suspect Information** (`suspect_info`): If applicable, provide information about the suspect.
* **Was a Suspect Identified?** (`suspect_identified`): Select whether a suspect was identified.
* **Suspect Names** (`suspect_names`): If applicable, enter the names of the suspects.
* **Was an Arrest Made?** (`arrest_made`): Select the arrest status.
* **Charges Filed** (`charges_filed`): Select whether charges were filed (if applicable).
* **Evidence Status** (`evidence_status`): Enter the evidence handling status.
* **Was Evidence Collected?** (`evidence_collected`): Select whether evidence was collected.
* **Evidence Disposition** (`evidence_disposition`): Select what happened to the evidence.
* **Victim Information** (`victim_info`): Enter victim status.
* **Was Victim Notified of Closure?** (`victim_notified`): Select the victim communication status.
* **Victim Satisfaction with Resolution** (`victim_satisfaction`): Select the victim's satisfaction with the resolution (if contact made).
* **Case Outcome** (`case_outcome`): Select the final result.
* **Is Case Referred to Court?** (`court_referral`): Select the court status.
* **Court Date** (`court_date`): If applicable, enter the court date.
* **Are There Related Cases?** (`related_cases`): Select whether there are related cases.
* **Related Case Numbers** (`related_case_numbers`): If applicable, enter the related case numbers.
* **Supervisor Review** (`supervisor_review`): A note field for management approval.
* **Reviewing Supervisor Name** (`supervisor_name`): Enter the supervisor's name.
* **Supervisor Badge Number** (`supervisor_badge`): Enter the supervisor's badge number.
* **Review Status** (`review_status`): Select the approval status.
* **Supervisor Comments** (`supervisor_comments`): Enter the supervisor's review notes.
* **Officer Signature Date** (`officer_signature_date`): Enter the date signed by the officer.
