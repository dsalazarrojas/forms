# Crew Uniform Fitting Booking Form - Help Guide

## Purpose
The Crew Uniform Fitting Booking Form is designed to help crew members schedule and submit their uniform fitting details. It allows users to select a date and time for the fitting, enter their crew details, select a location, and submit their fitting preferences.

## How To Complete This Form
To complete this form, follow these steps:

1. Select a date and time for the fitting using the "Schedule Fitting" field.
2. Enter your crew details in the "Crew Details" field.
3. Enter your wardrobe number in the "Wardrobe" field.
4. Enter your sizing details in the "Sizing Details" field.
5. Select a fitting location using the "Fitting Location" field.
6. Select a time for the fitting using the "Schedule Time" field.
7. Submit your fitting preferences using the "Submit Fitting Details" fields.

## Field-by-Field Explanation
* **Schedule Fitting**: Select a date and time for the fitting.
* **Crew Details**: Enter your crew details.
* **Wardrobe**: Enter your crew's wardrobe number.
* **Sizing Details**: Enter your sizing details.
* **Fitting Location**: Select a location for the fitting.
* **Schedule Time**: Select a time for the fitting.
* **Submit Fitting Details 1-18**: Select one of the options for submitting your fitting preferences.

Note: The "Submit Fitting Details" fields are used to submit your preferences for different aspects of the fitting. You will be asked to select one option for each field.
