# Studio Access Reschedule Request Form - Help Guide
## Purpose
This form is used to request rescheduling of studio access. Please fill it out to inform us of your new preferred date and time for studio access.

## How To Complete This Form
To complete this form, follow these steps:
1. Select the studio from the dropdown list that you would like to have access to.
2. Choose a date for the new studio access time.
3. Choose a time for the new studio access time.
4. Provide the reason for the reschedule request.
5. If additional information is required, please provide it in the space below.
6. Enter your phone number for contact.
7. Enter your email address for contact.
8. Select the user(s) you would like to grant studio access to.

## Field-by-Field Explanation
* **Studio <studio_access_reschedule_request_form_1>** (Studio, select_one): Choose the studio you would like to reschedule access to.
* **Date <studio_access_reschedule_request_form_2>** (Date, required: false): Select the date for your new studio access time. Please choose a date within the next 7 days.
* **Time <studio_access_reschedule_request_form_3>** (Time, required: false): Select the time for your new studio access time. Please choose a time between 08:00 and 18:00.
* **Reason <studio_access_reschedule_request_form_4>** (Reason, required: false): Provide a brief explanation for your reschedule request.
* **Additional Information <studio_access_reschedule_request_form_5>** (Additional Information, required: false): If there's anything else you'd like to add to your reschedule request, please enter it here.
* **Phone <studio_access_reschedule_request_form_6>** (Phone, required: false): Enter your phone number for contact.
* **Email <studio_access_reschedule_request_form_7>** (Email, required: false): Enter your email address for contact.
* **User <studio_access_reschedule_request_form_8>** (User, select_multiple, required: false): Select the user(s) you would like to grant studio access to.
