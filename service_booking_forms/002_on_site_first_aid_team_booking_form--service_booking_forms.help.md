# On Site First Aid Team Booking Form - Help Guide
## Purpose
This form is used to book an on-site first aid team for a specific event. It collects necessary details such as event description, services required, scheduled date, scheduled time, scheduled location, and contact number. This form is designed to be filled out in advance of the event.

## How To Complete This Form
To complete this form, follow these steps:
1. Fill out the form completely and accurately. Make sure to include all necessary information.
2. Select all required services for the event from the "staffing_needs" options.
3. Choose the date and time of the event in the format `MM/DD/YY` for date and `HH:MM` for time.
4. Enter the scheduled location of the event.

## Field-by-Field Explanation
* **Event Details** (`event_details`, text, optional): This field collects a brief description of the event. 
* **Staffing Needs** (`staffing_needs`, select_multiple, optional): This field allows you to select the services required for the event, such as Medical Team, First Aid Kit, or Other (please specify).
* **Scheduled Date** (`schedule_date`, date, optional): This field requires the date of the event in the format `MM/DD/YY`.
* **Scheduled Time** (`schedule_time`, time, optional): This field requires the time of the event in the format `HH:MM`.
* **Scheduled Location** (`schedule_location`, text, optional): This field collects the location where the event will take place.
* **Contact Number** (`contact_number`, text, optional): This field collects the contact number of the event organizer.

## Tips
* Make sure to submit the form well in advance of the event to ensure on-site first aid team availability.
* If you have any questions or need help with the form, contact the on-site first aid team coordinator.
