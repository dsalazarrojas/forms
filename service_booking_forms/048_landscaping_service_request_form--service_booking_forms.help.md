# Landscaping Service Request Form - Help Guide
## Purpose
The purpose of the Landscaping Service Request Form is to collect information from customers for landscaping services they would like to book. This form helps us to understand their needs and preferences to provide the best possible service to them.

## How To Complete This Form
1. **First Name** (`service_request`, `text`, required): Please enter your first name as it is written on your identification documents.
2. **Email** (`email`, `email`, required): Enter your valid email address that we can use to contact you back.
3. **Phone** (`phone_number`, `text`, optional): If you have a preferred phone number to contact you, please enter it here.
4. **Service Type** (`service_type`, `select_one`, required): Please select the type of landscaping service you are interested in:
	* Yes (e.g. lawn mowing, tree trimming)
	* No (e.g. other services like gardening, irrigation)
5. **Location** (`location`, `text`, required): Enter the address of the location for which you are requesting the service.
6. **Date** (`date`, `date`, required): Please enter the date when you would like to book the service.
7. **Time** (`time`, `time`, optional): If you have a preferred time for the service, please enter it here.
8. **Notes** (`notes`, `note`, optional): If you have any special requests or comments, please enter them here.

## Tips
- Make sure to fill out all required fields to ensure we can process your request properly.
- Please enter a valid email address so we can contact you back.
- If you have any questions or need assistance, don't hesitate to contact us.
