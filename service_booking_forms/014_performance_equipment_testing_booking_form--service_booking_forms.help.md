# Performance Equipment Testing Booking Form - Help Guide

## Purpose
The Performance Equipment Testing Booking Form is designed for booking and scheduling performance equipment testing. This form allows users to provide details about the testing information, equipment type, equipment ID, testing date, testing time, and testing duration. The form is used to ensure that performance equipment is tested and maintained regularly, which helps to identify any potential issues and prevent equipment failure.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the testing information page.
2. On the testing information page, select the "Yes" or "No" option to indicate if the equipment is ready for testing.
3. If the equipment is ready for testing, enter the equipment ID.
4. Select a testing date and time for the equipment.
5. Enter the testing duration.

## Field-by-Field Explanation

* **Testing Information**: This page is where you will enter the initial information about the testing request.
* **Equipment Type**: Choose "Yes" if the equipment is ready for testing, and "No" otherwise. This field helps us determine if the equipment is in a good condition for testing.
* **Equipment ID**: If you selected "Yes" in the previous field, enter the ID of the equipment being tested. This field is optional and is used to identify the equipment being tested.
* **Testing Date**: Select a date for the testing session. The testing date cannot be in the past.
* **Testing Time**: Select a time for the testing session. The testing time cannot be earlier than the selected date.
* **Testing Duration**: Enter the duration of the testing session. The testing duration must be a positive number.

## Tips
* Make sure to select "Yes" if the equipment is in good condition and ready for testing.
* If you are unsure about the equipment's condition, consult with the equipment's owner or maintenance personnel.
* Enter the correct equipment ID to ensure accurate identification of the equipment being tested.
* Select a testing date and time that is convenient for both you and the maintenance personnel.
* Enter the correct testing duration to ensure the testing session is completed within the specified time frame.
