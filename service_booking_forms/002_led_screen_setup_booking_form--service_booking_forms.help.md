# Led Screen Setup Booking Form - Help Guide
## Purpose

The Led Screen Setup Booking Form is used to book a LED screen installation, capturing necessary details for the installation process.

## How To Complete This Form

1. Fill in the required information for the event name, date, installation date, start time, finish time, contact number, contact email, and submit the form.
2. Enter any additional details such as location, installer name, and notes (if needed).
3. Provide special instructions if any specific requirements need to be noted.
4. Submit the form after ensuring all required fields are filled in.

## Field-by-Field Explanation

* **Event Name** (`event_name`, text, required): Enter the name of the event you want to book the LED screen installation for.
* **Date** (`event_date`, date, required): Select the date of the event.
* **Time** (`event_time`, date, required): This field is not applicable as the event date already specifies the date. This field can be skipped.
* **Location** (`location`, text, required): Enter the location where the LED screen will be installed.
* **Installer Name** (`installer_name`, text, required): Enter the name of the installer or team member who will be performing the installation.
* **Contact Number** (`contact_number`, text, required): Enter a valid contact number for the event organizer or responsible person.
* **Contact Email** (`contact_email`, email, required): Enter a valid email address for the event organizer or responsible person.
* **Installation Date** (`installation_date`, date, required): Select the date for the LED screen installation.
* **Start Time** (`start_time`, time, required): Select the start time for the installation.
* **Finish Time** (`finish_time`, time, required): Select the finish time for the installation.
* **Installation Duration** (`installation_duration`, text, optional): Provide an estimate of the installation duration if required.
* **Notes** (`notes`, text, optional): Enter any additional notes or comments regarding the installation.
* **Special Instructions** (`special_instructions`, text, optional): Enter any special instructions for the installation team.
* **Submit** (`submit`, select_one, required): Click "Yes" to confirm the booking, and "No" to cancel the booking.
