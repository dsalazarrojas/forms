# Graphic Inquiry Form - Help Guide
## Purpose
This form is designed to collect information from users to better understand their needs and preferences for graphic services.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in your User Information, including your name and email address.
2. Select the services you are interested in, such as Graphic Design, Branding, or Web Design.
3. Add a message or description of your project, if necessary.
4. If you have a file to upload, do so by selecting the "Upload File" field.
5. Choose a project deadline, if applicable.
6. Select the project status (Ongoing, In Progress, or Completed).
7. Choose a project manager (if applicable).
8. Select the location of your project.
9. Select the type of project you have (Graphic Design, Branding, or Web Design).
10. Choose the service type(s) you require (Graphic Design, Branding, or Web Design).
11. Finally, provide a description of your project in the Project Description field.

## Field-by-Field Explanation

* **User Information (id: 1)** (`name`, `text`, optional): Enter your name and any other relevant user information.
* **Name (id: 2)** (`name`, `text`, optional): Enter your name.
* **Email (id: 3)** (`email`, `text`, required): Enter your email address.
* **Services (id: 4)** (`services`, `select_multiple`, required): Select all the services you are interested in, such as Graphic Design, Branding, or Web Design.
* **Message (id: 5)** (`message`, `text`, optional): Add any additional message or description about your project.
* **File (id: 6)** (`file_upload`, `text`, optional): If you have a file to upload, select this field.
* **Upload File (id: 7)** (`upload_file`, `text`, optional): If you have a file to upload, select this field.
* **Project Deadline (id: 8)** (`project_deadline`, `date`, optional): Choose a project deadline, if applicable.
* **Project Start (id: 9)** (`project_start_date`, `date`, optional): Choose a project start date, if applicable.
* **Budget (id: 10)** (`project_budget`, `text`, optional): Enter your project budget.
* **Status (id: 11)** (`project_status`, `select_one`, required): Select the status of your project (Ongoing, In Progress, or Completed).
* **Project Manager (id: 12)** (`project_manager`, `text`, optional): Enter the name of your project manager.
* **Location (id: 13)** (`project_location`, `text`, optional): Enter the location of your project.
* **Type (id: 14)** (`project_type`, `select_one`, required): Select the type of your project (Graphic Design, Branding, or Web Design).
* **Service Type (id: 15)** (`service_type`, `select_multiple`, required): Select all the service types you require, such as Graphic Design, Branding, or Web Design.
* **Project Description (id: 16)** (`project_description`, `text`, optional): Enter a description of your project.

## Tips

* Please fill in all required fields to ensure accurate information collection.
* If you have any questions or need help, feel free to contact [form@gic.mx](mailto:form@gic.mx).
* Make sure to upload any required files in the appropriate format (e.g., JPEG, PNG, etc.).
* If you have any issues with file uploads, try clearing your browser cache or checking your internet connection.
