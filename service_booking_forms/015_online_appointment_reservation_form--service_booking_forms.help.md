# Online Appointment Reservation Form - Help Guide
## Purpose
This form is designed to collect information from clients to schedule an appointment with our service team. It is best to complete the form in the following order: First Page > Client Information > Service Request and Additional Details.

## How To Complete This Form
To complete this form, follow these steps:

1. Review the First Page to ensure you understand the purpose and instructions.
2. On the Client Information page, fill out your name and email address.
3. Select the appropriate Service Request from the list.
4. Choose your Start Time and Start Date for the appointment.
5. Select an End Date for the appointment.
6. Enter your Duration for the appointment.
7. Review and complete any additional fields that apply to you.

## Field-by-Field Explanation

### **First Page (First Page)**
* **First Page (Label)**: This is the introduction page of the form. It explains the purpose and instructions for completing the form.

### **Client Information (Client Information)**
* **Client Name (First Name, text, Optional)**: Enter your first name.
* **Last Name (Last Name, text, Optional)**: Enter your last name.
* **Client Email (Client Email, email, Optional)**: Enter your email address.

### **Service Request (Service Request)**
* **Service Request (Service 1, Service 2, Service 3, Optional)**: Select the service you would like to book an appointment for.

### **Service Request 2 (Service Request 2)**
* **Service Request 2 (Option 1, Option 2, Option 3, Optional)**: Select the secondary service you would like to book an appointment for. This will be considered as an additional service to your primary service request.

### **Start Time (Start Time, time, Optional)**: Select the time you would like to start your appointment.
* Note: Time is in 24-hour format (HH:MM).

### **Start Date (Start Date, date, Optional)**: Select the date you would like to start your appointment.
* Note: Date format is YYYY-MM-DD.

### **End Date (End Date, date, Optional)**: Select the end date of your appointment.
* Note: Date format is YYYY-MM-DD.

### **Duration (Duration, number, Optional)**: Enter the duration of your appointment in minutes.
* Note: This field is used to calculate the end time of your appointment based on the start time and duration.

### **Additional Notes (Additional Notes, text, Optional)**: Enter any additional notes or comments about your appointment.

### **Confirm Request (Confirm Request, select multiple, Optional)**: Confirm that you would like to book this appointment.
* Yes: Confirm that you would like to book this appointment.
* No: Cancel the appointment.

### **Submit (Submit, select one, Optional)**: Select one of the following options to complete the form.
* **Submit**: Save your completed form.
* **Save as draft**: Save your form as a draft for later completion.
* **Cancel**: Cancel the form and exit the application.
