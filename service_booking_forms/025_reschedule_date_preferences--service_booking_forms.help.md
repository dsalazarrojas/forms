**Reschedule Date Preferences - Help Guide**

## Purpose
The Reschedule Date Preferences form is used to capture information regarding date preferences when rescheduling an appointment or service booking. This form is typically used to accommodate clients who need to adjust the date and time of their scheduled appointment or service booking.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the preferred date for the rescheduled appointment or service booking from the calendar input field.
2. Provide a brief reason for the change in the text input field "reasons_for_change".
3. If you have selected a preferred date, please ensure that you enter the selected date in the "selected_date" field.
4. If you have a specific reason for rescheduling, please enter it in the "reason_for_request" field.
5. Choose your preferred time for the rescheduled appointment or service booking by selecting it from the time input field.
6. If you have a specific reason for rescheduling, enter it in the "reschedule_reason" field.

## Field-by-Field Explanation

* **preferred_date**: A date input field where you can select a new date for the rescheduled appointment or service booking.
* **reasons_for_change**: A text input field where you can provide a brief reason for changing the date.
* **selected_date**: A date input field where you can enter the selected date if you have already chosen a new date.
* **reschedule_request**: A text input field where you can enter a brief explanation for rescheduling.
* **reason_for_request**: A text input field where you can enter a specific reason for rescheduling.
* **preferred_time**: A time input field where you can select a preferred time for the rescheduled appointment or service booking.
* **reschedule_reason**: A text input field where you can enter a specific reason for rescheduling.
* **preferred_duration**: Not currently used in this form, please do not enter any value. 

**Tips**

* Please ensure that you select a valid date for the rescheduled appointment or service booking.
* If you have a specific reason for rescheduling, please provide it in the "reason_for_request" and "reschedule_reason" fields.
* If you have a preferred time, please select it from the time input field.
