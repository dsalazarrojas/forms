# Tattoo Waitlist Form - Help Guide
## Purpose
The "Tattoo Waitlist Form" is used to add new clients to the waitlist. This form helps manage client information to ensure accurate and efficient appointment scheduling.

## How To Complete This Form
Please follow these steps to complete this form correctly:

*   Fill out the form with the new client information.
*   Ensure all required fields have valid input.
*   Review and confirm your entries before submitting the form.

## Field-by-Field Explanation

*   **New Waitlist** (id: 1, type: number, required): 
    Enter the number for the new waitlist position to be added. Please input a numerical value for accurate waitlist organization.
*   **Client** (id: 2, type: select_multiple, required):
    Select all applicable client options from the list to determine which client(s) the waitlist position is associated with. Choose multiple clients if necessary.
*   **Date** (id: 3, type: date, required):
    Enter the date when the client's appointment will take place.
*   **Time** (id: 4, type: time, required):
    Enter the time of the client's appointment. Ensure this is accurate to ensure correct scheduling.
*   **Client Count** (id: 5, type: number, required):
    Enter the number of clients associated with this waitlist position.
*   **Client Name** (id: 6, type: text, optional):
    Provide the name of the client(s) associated with this waitlist position.
*   **Client Type** (id: 7, type: select_one, required):
    Select the type of client from the provided options to categorize the client accurately. Choose only one type for this client.
