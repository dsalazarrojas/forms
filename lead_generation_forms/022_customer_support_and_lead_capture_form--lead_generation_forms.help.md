# Customer Support And Lead Capture Form - Help Guide
## Purpose
The Customer Support And Lead Capture Form is designed to gather information from customers to provide them with the best possible support and lead capture experience. This form is not intended for internal use and is meant for customer-facing interactions.

## How To Complete This Form
To complete this form, follow these steps:

1. Review each page and select the options that apply to your inquiry.
2. Fill out the required fields (marked as required).
3. Provide any additional information in the text fields.
4. Submit the form when you're finished.

## Field-by-Field Explanation

* **Customer Support** (select_multiple, required: false):
	+ Select "Yes" if you need customer support.
	+ Select "No" if you do not need customer support.
* **Lead Capture Form 1** (select_multiple, required: false):
	+ Select "Yes" if you need to capture leads for this form 1.
	+ Select "No" if you do not need to capture leads for this form 1.
* **Lead Capture Form 2** (select_multiple, required: false):
	+ Select "Yes" if you need to capture leads for this form 2.
	+ Select "No" if you do not need to capture leads for this form 2.
* **Customer Inquiries** (select_one, required: false):
	+ Select "Customer Support" if your inquiry is related to customer support.
	+ Select "Lead Generation" if your inquiry is related to lead generation.
	+ Select "Customer Service" if your inquiry is related to customer service.
* **Customer Name** (text, required: false):
	+ Enter your name if you're the customer representative.
* **Email** (email, required: false):
	+ Enter your email address to receive any follow-up communication.
* **Phone Number** (text, required: false):
	+ Enter your phone number for easy communication.
* **Customer Message** (note, required: false):
	+ Provide any additional details about your inquiry.
* **Lead Capture Form 1** (select_multiple, required: false):
	+ Select "Yes" if you need to capture leads for this form 1.
	+ Select "No" if you do not need to capture leads for this form 1.
* **Lead Capture Form 2** (select_multiple, required: false):
	+ Select "Yes" if you need to capture leads for this form 2.
	+ Select "No" if you do not need to capture leads for this form 2.
