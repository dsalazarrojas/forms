# AI Search Onboarding Form - Help Guide
## Purpose
This form is designed to be a comprehensive template for onboarding new clients. It will help us understand your search requirements, industry, and technical needs, ensuring that we can provide the best possible service for your specific use case.

## How To Complete This Form
Please take your time to fill out the form accurately and thoroughly. Each section has been designed to help us understand your specific needs.

## Field-by-Field Explanation
* **Company Name** (`company_name`, required): Enter your company's name as it appears on your business card or website.
* **Primary Contact Person** (`contact_person`, required): Enter the name and title of the primary contact person responsible for your organization.
* **Contact Email** (`contact_email`, required): Enter the email address of the primary contact person.
* **Industry** (`industry`, required): Select the industry your organization belongs to:
	+ Technology/Software
	+ E-commerce/Retail
	+ Financial Services
	+ Healthcare/Life Sciences
	+ Legal
	+ Education
	+ Government
* **Primary Use Cases** (`use_cases`, required): Select all use cases that apply to your project:
	+ Customer Support (Help Center/FAQ)
	+ Internal Knowledge Base (Employee Search)
	+ E-commerce Product Search
	+ Legal/Compliance Document Discovery
	+ Research & Data Analysis
* **Existing Data Sources** (`data_sources`, required): Select where the content is currently stored:
	+ SQL/NoSQL Databases
	+ PDF/Office Documents
	+ Public Website URLs
	+ Notion/Confluence/Slack
	+ Cloud Storage (Google Drive, S3, Dropbox)
	+ API-based Content
* **Estimated Monthly Search Volume** (`search_volume`, required): Select your estimated monthly search volume:
	+ Under 1,000 queries
	+ 1,000 - 10,000 queries
	+ 10,000 - 100,000 queries
	+ Over 100,000 queries
* **Primary User Language(s)** (`search_languages`, required): Select the primary language(s) your users will be searching in:
	+ English Only
	+ Multi-lingual (Specify in comments)
	+ Non-English Primary
* **Technical & Privacy** (`technical_privacy_section`, optional): Please provide any technical or privacy constraints that may be relevant to your project.
* **Preferred Deployment** (`preferred_deployment`, required): Select the preferred deployment method for your search solution:
	+ SaaS (Cloud Hosted)
	+ Private Cloud (VPC)
	+ On-premise / Self-hosted
* **Data Privacy Compliance Required** (`compliance_requirements`, required): Select the primary compliance requirement:
	+ GDPR
	+ HIPAA
	+ SOC2 Type II
	+ ISO 27001
	+ None / Not Applicable
* **Preferred Integration Method** (`integration_method`, required): Select the preferred integration method for your search solution:
	+ REST API
	+ Pre-built UI Widget/Plugin
	+ Javascript SDK
	+ Mobile SDK (iOS/Android)
* **Existing Search Solution (if any)** (`current_solution`, optional): If you are using an existing search solution, please specify which one:
* **Project Timeline** (`project_timeline_section`, optional): If applicable, provide any project timeline information that may be relevant to your project.
* **Desired Launch Date** (`desired_launch_date`, optional): If applicable, provide the desired launch date for your project.
* **Current Project Stage** (`current_stage`, required): Select the current stage of your project:
	+ Initial Researching
	+ Active Evaluation / POC
	+ Ready to Implement
* **Additional Project Requirements or Comments** (`additional_requirements`, optional): Please describe any specific technical constraints or feature needs that are not covered in the above fields.

## Tips
Please take your time to fill out this form accurately and thoroughly. If you have any questions or concerns, please don't hesitate to reach out to us directly.
