# Smart Home Budget Calculator - Help Guide
## Purpose
This form is designed to collect information about a smart home project, including its location, budget, duration, and features. It's meant to be completed by a project lead or someone responsible for the project.

## How To Complete This Form

To complete this form, follow these steps:

1. Fill in the **Project Details** section with a brief description of your project.
2. Choose the **Project Location** from the provided options.
3. Select the **Budget Preferences** that best fit your project.
4. Enter the **Project Budget** and **Project Duration**.
5. Choose the **Smart Home Equipment** and **Smart Home Device** that you want to include in your project.
6. Enter any additional notes for the **Smart Home Device Note** and **Smart Home System Note** fields.
7. Choose your preferred **Smart Home Budget Preference**.
8. Fill in the optional **Follow Up Email**, **Follow Up Phone**, and **Follow Up Message** fields if you'd like to receive follow-up communications.
9. Finally, click **Submit** to review and submit your form.

## Field-by-Field Explanation

* **Project Details**: A brief description of your smart home project.
	+ Type: Text
	+ Required: true
* **Project Location**: The location of your smart home project.
	+ Type: Select One
	+ Required: true
	+ Options: Option 1, Option 2, Option 3
* **Budget Preferences**: The budget preferences for your smart home project.
	+ Type: Select Multiple
	+ Required: true
	+ Options: Option 1, Option 2, Option 3, Option 4
* **Project Budget**: The total budget for your smart home project.
	+ Type: Number
	+ Required: true

	+ Type: Time
	+ Required: true
* **Smart Home Equipment**: The equipment you want to include in your smart home project.
	+ Type: Select Multiple
	+ Required: true
	+ Options: Option 1, Option 2, Option 3, Option 4
* **Smart Home Budget Preference**: The budget preference for your smart home project.
	+ Type: Select One

* **Smart Home Device**: The smart home device you want to include in your project.
	+ Type: Text

	+ Type: Note

	+ Type: Note

* **Smart Home Feature**: The smart home feature you want to include in your project.
