# Retail Sale Event Lead Generation Form - Help Guide
## Purpose
The Retail Sale Event Lead Generation Form is a tool designed for store managers and owners to input information about their store's events and sales. This form collects data from store location, event type, contact details, store hours, and other relevant details to help event organizers track and follow up on event leads.

## How To Complete This Form
To complete this form accurately, please follow these steps:

1. Select the type of event from the dropdown menu.
2. Enter the store location where the event will take place.
3. Provide your first and last name as the contact person for the event.
4. Add the store's phone number for easy contact.
5. Enter the event date and start and end times.
6. Give a brief description of the event.
7. Provide the store manager's name.
8. Add the store's email address for easy contact.
9. Enter the store manager's phone number.
10. Check the status of the event (Active or Inactive).
11. Choose a follow-up date and contact name.
12. Add the follow-up contact person's email address and phone number.
13. Any additional notes about the event can be added here.

## Field-by-Field Explanation
* **Event Type (In-Store Event, Pop-Up Event, Seasonal Sale)**: Select the type of event you are planning. This will help in organizing and categorizing events.
* **Store Location**: Enter the physical address of your store. This will help in locating the event and making contact with the store.
* **First Name**: Enter your first name as the contact person for the store. This will help in identifying and verifying contact details.
* **Last Name**: Enter your last name as the contact person for the store. This will help in identifying and verifying contact details.
* **Store Phone**: Enter the store's phone number for easy contact.
* **Date**: Enter the date of the event.
* **Start Time**: Enter the start time of the event.
* **End Time**: Enter the end time of the event.
* **Event Description**: Give a brief description of the event.
* **Store Manager Name**: Enter the name of the store manager.
* **Store Email**: Enter the store's email address for easy contact.
* **Store Manager Phone**: Enter the store manager's phone number.
* **Event Status**: Check the status of the event (Active or Inactive).
* **Follow-Up Date**: Choose a date for follow-up contact.
* **Follow-Up Contact Name**: Enter the name of the person who will be contacted for follow-up.
* **Follow-Up Contact Email**: Enter the email address of the follow-up contact person.
* **Follow-Up Contact Phone**: Enter the phone number of the follow-up contact person.
* **Notes**: Add any additional comments or notes about the event.
* **Store Type**: Enter the type of store (if not already specified in the store location field).
* **Event ID**: Enter a unique ID for the event (if necessary).
* **Promotion ID**: Enter an ID for the promotion (if necessary).
* **Follow-Up Follow-Up Time**: If desired, enter a follow-up time for the event.
* **Event Type ID**: Enter an ID for the event type (if necessary).
* **Store Hours**: Enter the store's operating hours (if not already specified in the store location field).
* **Event Status**: Enter the status of the event (if not already specified).

## Tips
* Make sure to fill out each field accurately and completely to ensure correct data tracking.
* Use this form for single events only, to avoid data duplication.
* You can use this form for multiple events and sales across different stores.
* If you need to update an event, simply edit the existing form entry.
* You can use the event status to prioritize follow-up contact and action.
