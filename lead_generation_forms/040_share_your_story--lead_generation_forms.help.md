# share_your_story - Help Guide
## Purpose
This form is used to collect information about a lead's story, allowing us to better understand their needs and preferences.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the category that best describes the lead's story.
2. Enter a brief description of the lead's story.
3. Enter the lead's email address.
4. Enter the lead's phone number (optional).
5. Add any additional notes about the lead's story.
6. Select the status of the lead (e.g., New Lead, Converted, Dropped).
7. Enter the date and time when the lead was generated.
8. Enter the date and time when the form was last updated.
9. Select the user assigned to handle the lead.
10. Select multiple categories that best describe the lead's story.
11. Select the source of the lead (e.g., Webform, API, CRM).
12. Select the priority of the lead (e.g., Low, Medium, High).

## Field-by-Field Explanation

* **Category**: Select the category that best describes the lead's story. (Select One)
	+ This field allows you to categorize the lead's story into one of the three options: Lead Generation Forms, Lead Qualification Forms, or Lead Nurturing Forms.
* **Description**: Enter a brief description of the lead's story. (Text)
	+ This field is where you can provide a detailed explanation of the lead's story, including their interests and preferences.
* **Lead Email**: Enter the lead's email address. (Email)
	+ This field is used to capture the lead's email address, which is essential for communication and follow-up.
* **Lead Phone**: Enter the lead's phone number (optional). (Text)
	+ This field is not required, but it can be useful to have the lead's phone number for further contact.
* **Lead Notes**: Add any additional notes about the lead's story. (Note)
	+ This field is for any additional information or comments about the lead.
* **Lead Status**: Select the status of the lead (e.g., New Lead, Converted, Dropped). (Select One)
	+ This field indicates the current state of the lead, which can help track progress and follow-up.
* **Created At**: Enter the date and time when the lead was generated. (Date)
	+ This field is automatically populated and cannot be edited.
* **Updated At**: Enter the date and time when the form was last updated. (Time)
	+ This field is automatically populated and cannot be edited.
* **Assigned To**: Select the user assigned to handle the lead. (Select One)
	+ This field designates the user responsible for handling the lead, ensuring proper follow-up and follow-through.
* **Category**: Select multiple categories that best describe the lead's story. (Select Multiple)
	+ This field allows you to select multiple categories that apply to the lead's story.
* **Source**: Select the source of the lead (e.g., Webform, API, CRM). (Select One)
	+ This field indicates the origin of the lead, which can help track where they came from.
* **Priority**: Select the priority of the lead (e.g., Low, Medium, High). (Select One)
	+ This field determines the level of importance and urgency of the lead.
