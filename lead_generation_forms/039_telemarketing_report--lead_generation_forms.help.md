# Telemarketing Report - Help Guide
## Purpose
This form is designed to collect and display information about leads generated through telecalling and email marketing campaigns. It helps track and manage lead data for further analysis and decision-making.

## How To Complete This Form

To complete this form, follow these steps:

* Select the lead source from the dropdown menu.
* Enter the lead name in the text field.
* Enter the lead number, if applicable.
* Select the lead status from the dropdown menu.
* Choose the campaign ID and name from the dropdown menus.
* Enter the lead time, if applicable.
* Enter the lead date, if applicable.
* Enter the lead agent's name, title, email, and phone number, if applicable.
* Select the lead source type from the dropdown menu.
* Enter the lead source value, if applicable.
* Select the campaign type from the dropdown menu.
* Select the campaign status from the dropdown menu.
* Enter the lead value and value type, if applicable.
* Enter the lead agent's note, if applicable.
* Enter the lead agent's comment, if applicable.

## Field-by-Field Explanation

* **Lead Source**: Select the source of the lead. Options: 
  * Lead Source
  * Source 1
  * Source 2
  * Source 3
* **Lead Name**: Enter the name of the lead.
* **Lead Number**: Enter the lead number, if applicable.
* **Lead Status**: Select the status of the lead. Options: 
  * Active
  * Inactive
  * Lost
* **Campaign ID**: Select the campaign ID.
* **Campaign Name**: Select the campaign name.
* **Lead Time**: Enter the lead time, if applicable.
* **Lead Date**: Enter the lead date, if applicable.
* **Lead Agent**: Enter the lead agent's name, title, email, and phone number, if applicable.
* **Lead Source Type**: Select the source type of the lead. Options: 
  * Email
  * Phone
  * Other
* **Lead Source Value**: Enter the lead source value, if applicable.
* **Campaign Type**: Select the type of campaign. Options: 
  * Lead
  * Non Lead
  * Telemarketing
* **Campaign Status**: Select the status of the campaign. Options: 
  * Active
  * Inactive
  * Lost
* **Lead Value**: Enter the lead value, if applicable.
* **Lead Value Type**: Select the type of lead value. Options: 
  * Amount
  * Qualified
  * Converted
* **Lead Agent Note**: Enter the lead agent's note, if applicable.
* **Lead Agent Comment**: Enter the lead agent's comment, if applicable.
* **Lead Agent Name**: Enter the lead agent's name, if applicable.
* **Lead Agent Title**: Enter the lead agent's title, if applicable.
* **Lead Agent Email**: Enter the lead agent's email, if applicable.
* **Lead Agent Phone**: Enter the lead agent's phone number, if applicable.
