# Retail Personalization API Registration Form - Help Guide

## Purpose
This form is used to register for the Retail Personalization API. It is a one-time process that requires accurate and complete information.

## How To Complete This Form
1. Fill out all the fields carefully.
2. Review the form before submitting to ensure that all required fields are filled out correctly.
3. Submit the form via the provided link.

## Field-by-Field Explanation

* **Retail Personalization API Registration Form** (`form_title`): This is the title of the form. You can fill out any information you like, but it is not required.
* **Company** (`company`): This field is used to enter your company's name.
* **Email** (`email`): This field is used to enter your email address.
* **Phone** (`phone`): This field is used to enter your company's phone number.
* **Use Cases** (`use_cases`): This field is used to describe the use cases for which you are registering for the API.
* **Contact Name** (`contact_name`): This field is used to enter the name of the contact person.
* **Contact Phone** (`contact_phone`): This field is used to enter the phone number of the contact person.
* **Company URL** (`company_url`): This field is used to enter your company's website URL.
* **Use Cases Description** (`use_cases_description`): This field is used to describe the use cases in more detail.
* **API Access Level** (`api_access_level`): This field is used to select the level of API access you require (level1, level2, level3).
* **Review Notes** (`review_notes`): This field is used to add any additional review notes.
* **Form Comments** (`form_comments`): This field is used to add any comments about the form.
* **API Key** (`api_key`): This field is used to enter an API key (if required).
* **API Access Request** (`api_access_request`): This field is used to select the options for API access (Option 1, Option 2, Option 3).
* **API Access Request Details** (`api_access_request_details`): This field is used to enter more information about the API access request.
* **API Access Request Date** (`api_access_request_date`): This field is used to select the date of the API access request.
* **API Access Request Time** (`api_access_request_time`): This field is used to select the time of the API access request.
* **API Access Request Frequency** (`api_access_request_frequency`): This field is used to select the frequency of the API access request (Option 1, Option 2, Option 3).
* **API Access Request Status** (`api_access_request_status`): This field is used to select the status of the API access request (Option 1, Option 2, Option 3).
* **Assigned Tool** (`assigned_tool`): This field is used to select the tool to which you are registering the API access.
* **Submitted By** (`submitted_by`): This field is used to enter the name of the person who submitted the form.
* **Submitted On** (`submitted_on`): This field is used to select the date the form was submitted.
* **Form ID** (`form_id`): This field is used to enter a form ID.
* **Form Name** (`form_name`): This field is used to enter the name of the form.
* **Form Version** (`form_version`): This field is used to enter the version of the form.

Note: This guide assumes that you have the necessary information ready before proceeding with the form. If you are unsure about any of the fields, please contact our support team for assistance.
