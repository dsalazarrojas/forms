# Kitchen Remodeling Lead Generation Form - Help Guide
## Purpose
This form is designed to generate leads for kitchen remodeling projects. It captures information from potential customers who are interested in remodeling their kitchen and are looking for a contractor to help them with the project.

## How To Complete This Form
To complete this form, simply fill out the fields with the required information. Please note that some fields are optional and can be skipped if not applicable. The form is divided into sections, each with clear and concise labels to help guide you through the process.

## Field-by-Field Explanation
* **Kitchen Remodeling Lead Generation Form** (`lead_generation_form`, text, optional): This is a hidden field that is not visible to the user. It is used for internal purposes only.
* **Customer** (`customer_name`, text, optional): Please enter your full name.
* **Email** (`email`, email, optional): Please enter your email address.
* **Phone** (`phone_number`, text, optional): Please enter your phone number.
* **Service Type** (`service_type`, select_one, optional): Select a service type from the options provided:
	+ Bathroom Remodeling
	+ Kitchen Remodeling
	+ Whole House Remodeling
* **Other Service Type** (`service_type_other`, text, optional): If the selected service type is not listed above, please provide more information about the type of service you are looking for.
* **Project Description** (`project_description`, text, optional): Please provide a brief description of your project.
* **Lead Location** (`lead_location`, select_one, optional): Select a location where the project is located:
	+ Home
	+ Office
	+ Other
	+ School
	+ Store
	+ Restaurant
* **Lead Location Other** (`lead_location_other`, text, optional): If the location is not listed above, please provide more information about the location.
* **Address** (`lead_location_address`, text, optional): Please provide the address where the project is located.
* **Budget** (`budget`, number, optional): Please enter your budget for the project.
* **Other Budget** (`budget_other`, text, optional): If the budget is not listed above, please provide more information about your budget.
* **Preferred Contact Method** (`preferred_contact_method`, select_one, optional): Select a preferred contact method:
	+ Phone
	+ Email
	+ Text
	+ Other
* **Other Preferred Contact Method** (`preferred_contact_method_other`, text, optional): If the preferred contact method is not listed above, please provide more information about your preferred contact method.
* **Lead Source** (`lead_source`, select_one, optional): Select a lead source:
	+ Referral
	+ Facebook
	+ Google
	+ Home Showroom
	+ Other
* **Other Lead Source** (`lead_source_other`, text, optional): If the lead source is not listed above, please provide more information about the lead source.
* **Contact** (`lead_source_contact`, text, optional): Please provide contact information about the lead source.
* **Lead Source Other 2** (`lead_source_other_2`, text, optional): If the lead source is not listed above, please provide more information about the lead source.
* **Date Available** (`date_available`, date, optional): Please select a date when you are available to start the project.
* **Time Available** (`time_available`, time, optional): Please select a time when you are available to start the project.
* **Note** (`note`, note, optional): Please provide any additional notes or comments about your project.
* **Email 2** (`email_2`, email, optional): Please enter your secondary email address.
* **Follow Up Method** (`follow_up_method`, select_one, optional): Select a follow up method:
	+ Phone
	+ Email
	+ Text
	+ In Person
* **Other Follow Up Method** (`follow_up_method_other`, text, optional): If the follow up method is not listed above, please provide more information about the follow up method.
* **Follow Up Note** (`follow_up_note`, note, optional): Please provide any additional follow up notes or comments.
