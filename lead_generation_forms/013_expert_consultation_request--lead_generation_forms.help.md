**Expert Consultation Request - Help Guide**

## Purpose
The Expert Consultation Request form is a tool for users to submit their consultation requests to our team. It helps us to better understand their needs, preferences, and requirements for the consultation process.

## How To Complete This Form

1. Fill out the form carefully, providing accurate information about your consultation needs and preferences.
2. Make sure to fill out all required fields, indicated by an asterisk (\*) in the label.
3. For date fields, please use the format `YYYY-MM-DD` for the Schedule Date and Preferred Date, and `HH:MM` for the Preferred Time.
4. For email and phone fields, please use a valid email address and phone number format.

## Field-by-Field Explanation

* **User Details** (`user_details`, text, optional): Please provide your name and any other relevant details about yourself.
* **Consultation Details** (`consultation_details`, text, optional): Describe your consultation needs and requirements.
* **Schedule Date** (`schedule_date`, date, optional): If you have a specific date in mind for the consultation, please enter it in the format `YYYY-MM-DD`.
* **Preferred Date** (`preferred_date`, date, optional): If you don't have a specific date in mind, enter a preferred date for the consultation.
* **Preferred Time** (`preferred_time`, time, optional): If you have a preferred time for the consultation, please enter it in the format `HH:MM`.
* **Consultation Location** (`consultation_location`, text, optional): If you have a specific location in mind for the consultation, please enter it here.
* **Consultation Length** (`consultation_length`, number, optional): If you have a preferred length for the consultation, please enter the number of minutes.
* **Consultant Name** (`consultant_name`, text, optional): If you have a preferred consultant, please enter their name here.
* **Consultant Email** (`consultant_email`, email, optional): If you have a preferred consultant's email address, please enter it here.
* **Consultant Phone** (`consultant_phone`, text, optional): If you have a preferred consultant's phone number, please enter it here.
* **Consultation Notes** (`consultation_notes`, note, optional): If you have any additional information or notes for the consultant, please enter it here.
* **User Confirmation** (`user_confirmation`, text, optional): Please confirm that you have submitted this form to request a consultation.

Note: This form is designed to be completed by users who are requesting expert consultations. If you are a consultant, please contact our team to learn more about how to respond to these requests.
