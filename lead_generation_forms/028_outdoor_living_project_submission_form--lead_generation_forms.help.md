# Outdoor Living Project Submission Form - Help Guide
## Purpose
The Outdoor Living Project Submission Form is used to gather information about generated leads for outdoor living projects. This form helps the sales team to track and follow up on these leads effectively.

## How To Complete This Form
1. Fill out the form with accurate and relevant information for each lead.
2. Ensure that all required fields are filled out with a value.
3. For non-numeric fields, enter a brief description or explanation.
4. Review your submission before clicking the submit button.

## Field-by-Field Explanation
* **Project Details**: A brief description of the project.
* **Project Location**: The location where the project is being undertaken.
* **Project Type**: Select one of the available options to indicate the type of project (e.g., Living Room Patio, Kitchen Outdoor Kitchen).
* **Project Size**: Enter the size of the project in square meters or feet. If you're unsure, leave this field blank.
* **Project Budget**: Enter the estimated budget for the project. If you're unsure, leave this field blank.
* **Lead Source**: Select the source of the lead (e.g., Social Media, Email Marketing).
* **Contact Details**: Indicate whether the contact is available to be contacted or not.
* **Project Deadline**: Enter the deadline for the project, if applicable.
* **Project Notes**: Enter any additional notes or comments about the project.
* **Email**: Enter the contact email of the lead.
* **Phone**: Enter the contact phone number of the lead.
