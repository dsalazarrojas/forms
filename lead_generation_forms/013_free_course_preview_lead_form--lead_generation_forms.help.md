# Free Course Preview Lead Form - Help Guide
## Purpose
The Free Course Preview Lead Form is a tool used to collect contact information and course interests from users who are interested in exploring a course before committing to it.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter your email address in the "User Email" field.
2. Enter your name in the "User Name" field.
3. Select the course that interests you from the "What course interests you?" dropdown menu.
4. Write any additional comments or questions you have about the course in the "User Message" field (optional).
5. Click the "Submit" button to submit your lead.

## Field-by-Field Explanation

### User Email (`user_email`)

* `User Email`: This is where you enter your email address. Please make sure to enter a valid email address that you use regularly, as this is how we will contact you with more information about the course.
* Required: No

### User Name (`user_name`)

* `User Name`: This is where you enter your name. We will use this to personalize our communication with you.
* Required: No

### What course interests you? (`course_interest`)

* `What course interests you?`: This is a dropdown menu where you select the course that you are interested in. Please choose one of the options from the list.
* Required: No

### User Message (`user_message`)

* `User Message`: This is an optional field where you can write any additional comments or questions you have about the course. You can use this field to ask for more information or clarify your interests.
* Required: No

## Tips

* Make sure to enter a valid email address and name.
* Select only one course from the dropdown menu.
* You can only submit this form once. If you've already filled it out, you won't be able to submit it again.
* Use this form to get more information about the course that interests you.
