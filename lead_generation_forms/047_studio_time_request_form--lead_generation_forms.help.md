# Studio Time Request Form - Help Guide
## Purpose
This form is designed for users to request studio time for various purposes. Please ensure that you have reviewed the studio's availability and that the requested time slot is not already booked before submitting a request.

## How To Complete This Form
To complete this form, simply fill in the required fields and click the "Submit" button. If you need to cancel a request, click the "Cancel" button.

## Field-by-Field Explanation

* **User Input** (`user_input`, Text, **required: false**): This field is used to collect any additional information from the user.
* **Start Time** (`start_time`, Time, **required: false**): Enter the start time for the requested studio time.
* **End Time** (`end_time`, Time, **required: false**): Enter the end time for the requested studio time.
* **Studio Id** (`studio_id`, Number, **required: false**): Enter the studio ID number.
* **Studio Name** (`studio_name`, Text, **required: false**): Enter the name of the studio.
* **Studio Address** (`studio_address`, Text, **required: false**): Enter the address of the studio.
* **Contact Person** (`contact_person`, Text, **required: false**): Enter the name of the contact person for the studio.
* **Studio Phone** (`studio_phone`, Text, **required: false**): Enter the phone number of the studio.
* **Studio Email** (`studio_email`, Email, **required: false**): Enter the email address of the studio.
* **Booking Time** (`booking_time`, Time, **required: false**): Enter the desired booking time for the studio.
* **Start Date/Time** (`start_date_time`, Date, **required: false**): Enter the desired start date and time for the studio time request.
* **End Date/Time** (`end_date_time`, Date, **required: false**): Enter the desired end date and time for the studio time request.
* **Notes** (`notes`, Note, **required: false**): Enter any additional notes or comments for the studio time request.
* **User Notes** (`user_notes`, Note, **required: false**): Enter any additional notes or comments from the user.
* **Assigned Tool** (`assigned_tool`, Select One, **required: true**): Select "Yes" if you have assigned a tool to the user for the studio time request.
* **Submit** (`submit`, Select Multiple, **required: false**): Select "Yes" to submit the studio time request, or "No" to cancel it.
* **Cancel** (`cancel`, Select Multiple, **required: false**): Select "Yes" to cancel the studio time request, or "No" to leave it as is.

**Tips:**

* Make sure to review the studio's availability before submitting a request.
* Ensure that the requested time slot is not already booked.
* Fill in all necessary fields before submitting the request.
