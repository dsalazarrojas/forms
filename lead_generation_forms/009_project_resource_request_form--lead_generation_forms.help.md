# Project Resource Request Form - Help Guide
## Purpose
The Project Resource Request Form is designed to facilitate the submission of project resource requests to the project management team. This form collects important information about the project, such as its name, status, location, and resource requirements.

## How To Complete This Form
1. **Select "Project Name" field**: Enter the name of the project for which you are requesting resources.
2. **Select "Contract Type" field**: Choose the type of contract or agreement that applies to the project.
3. **Select "Project Start Date" field**: Enter the expected start date of the project.
4. **Select "Project End Date" field**: Enter the expected end date of the project.
5. **Select "Project Status" field**: Choose the current status of the project.
6. **Select "Resource Allocation" field**: Select the type of resources required for the project.
7. **Enter "Priority Level" field**: Enter a number to indicate the priority level of the project.
8. **Enter "Resource Requester" field**: Enter the name of the person or team requesting resources.
9. **Enter "Project Description" field**: Provide a brief description of the project.
10. **Enter "Resource Assignment" field**: Enter the resources assigned to the project.
11. **Enter "Project Location" field**: Enter the location of the project.
12. **Enter "Project Contact" field**: Enter the contact person or team for the project.
13. **Select "Resource Availability" field**: Choose when the resources are available.
14. **Enter "Estimated Project Duration" field**: Enter the estimated duration of the project.
15. **Select "Resource Request Status" field**: Choose the current status of the resource request.
16. **Enter "Resource Requester Name" field**: Enter the name of the person or team requesting resources.
17. **Enter "Company Name" field**: Enter the name of the company associated with the project.
18. **Enter "Company Email" field**: Enter the email address of the company.
19. **Enter "Company Phone" field**: Enter the phone number of the company.
20. **Enter "Project Lead" field**: Enter the name of the project lead.
21. **Enter "Project Manager" field**: Enter the name of the project manager.
22. **Enter "Resource Requester Title" field**: Enter the title of the resource requester.
23. **Enter "Assigned Project Manager" field**: Enter the name of the project manager assigned to the project.
24. **Enter "Assigned Project Lead" field**: Enter the name of the project lead assigned to the project.
25. **Enter "Project Status Notes" field**: Enter any additional information about the project status.

## Field-by-Field Explanation
- **Project Name**: Enter the name of the project for which you are requesting resources.
  - This field is used to identify the project and differentiate it from other projects.
  - Ensure that the name is descriptive and easy to understand.
- **Contract Type**: Choose the type of contract or agreement that applies to the project.
  - This field helps project managers understand the project's terms and conditions.
- **Project Start Date**: Enter the expected start date of the project.
  - This field helps plan and schedule project timelines.
  - Use the "mm/dd/yyyy" format for date entry.
- **Project End Date**: Enter the expected end date of the project.
  - This field helps project managers plan and schedule project timelines.
  - Use the "mm/dd/yyyy" format for date entry.
- **Project Status**: Choose the current status of the project.
  - This field helps project managers understand the project's progress.
  - Select from options: active, inactive, completed, ongoing, pending, cancelled.
- **Resource Allocation**: Select the type of resources required for the project.
  - This field helps project managers allocate resources effectively.
  - Select from options: hardware, software, personnel, equipment.
- **Priority Level**: Enter a number to indicate the priority level of the project.
  - This field helps project managers prioritize projects based on resource availability.
  - Use numbers to indicate the priority level (e.g. 1, 2, 3).
- **Resource Requester**: Enter the name of the person or team requesting resources.
  - This field is used to identify the resource requester and contact person.
- **Project Description**: Enter a brief description of the project.
  - This field provides a summary of the project's objectives and goals.
- **Resource Assignment**: Enter the resources assigned to the project.
  - This field helps project managers track resource allocation.
- **Project Location**: Enter the location of the project.
  - This field helps project managers understand the project's location and logistics.
- **Project Contact**: Enter the contact person or team for the project.
  - This field provides a contact point for project stakeholders.
- **Resource Availability**: Choose when the resources are available.
  - This field helps project managers plan resource allocation based on availability.
  - Select from options: morning, afternoon, evening, weekend, weekdays.
- **Estimated Project Duration**: Enter the estimated duration of the project.
  - This field helps project managers plan project timelines.
  - Use numbers to indicate the duration (e.g. 1, 2, 3).
- **Resource Request Status**: Choose the current status of the resource request.
  - This field helps project managers track resource requests.
  - Select from options: active, inactive, completed, ongoing, pending, cancelled.
- **Resource Requester Name**: Enter the name of the person or team requesting resources.
  - This field is used to identify the resource requester and contact person.
- **Company Name**: Enter the name of the company associated with the project.
  - This field provides a point of contact for the company.
- **Company Email**: Enter the email address of the company.
  - This field provides a point of contact for the company.
- **Company Phone**: Enter the phone number of the company.
  - This field provides a point of contact for the company.
- **Project Lead**: Enter the name of the project lead.
  - This field is used to identify the project lead and point of contact.
- **Project Manager**: Enter the name of the project manager.
  - This field is used to identify the project manager and point of contact.
- **Resource Requester Title**: Enter the title of the resource requester.
  - This field is used to identify the resource requester's title.
- **Assigned Project Manager**: Enter the name of the project manager assigned to the project.
  - This field is used to identify the project manager assigned to the project.
- **Assigned Project Lead**: Enter the name of the project lead assigned to the project.
  - This field is used to identify the project lead assigned to the project.
- **Project Status Notes**: Enter any additional information about the project status.
  - This field provides additional context about the project status.

## Tips
- Ensure that all required fields are completed before submitting the form.
- Double-check the form for accuracy and completeness before submission.
- Use clear and descriptive entries for all fields.
- If you are unsure about any field, please contact the project management team for assistance.
