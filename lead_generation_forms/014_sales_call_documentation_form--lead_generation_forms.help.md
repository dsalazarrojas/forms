# Sales Call Documentation Form - Help Guide
## Purpose
This form is used to document the details of a sales call with a client, ensuring that all relevant information is captured and tracked accurately.

## How To Complete This Form
1. Fill in the **Client Name** field with the name of the client you met with during the call.
2. Enter the **Call Date Time** using the date and time format (e.g., MM/DD/YYYY HH:MM AM/PM).
3. Select the **Call Location** from the dropdown options (e.g., New York, Los Angeles, Chicago).
4. Choose the **Lead Source** from the dropdown options (e.g., Referral, Advertisement, Social Media).
5. Select the **Lead Status** from the dropdown options (e.g., Lead, No Lead, Unknown).
6. Choose the **Lead Result** from the dropdown options (e.g., Agreed to meet, Disqualified, Unknown).
7. Select the **Follow up Actions** from the dropdown options (e.g., Schedule follow-up call, Send follow-up email, Unknown).
8. Enter the **Follow up Next Call** date and time using the date format (e.g., MM/DD/YYYY).
9. Enter the **Follow up Next Call Phone** for any additional phone number (e.g., 555-1234).
10. Enter the **Follow up Next Call Email** for any follow-up emails sent to the client.
11. Select the **Lead Owner** from the dropdown options (e.g., John, Jane, Bob).
12. Choose the **Sales Process** from the dropdown options (e.g., Salesforce, Manual Process, Unknown).
13. Select the **Lead Status Update** from the dropdown options (e.g., Updated, Unchanged, Unknown).
14. Select the **Follow up Next Call Status** from the dropdown options (e.g., Completed, In Progress, Unknown).
15. Enter the **Created By** for the person who created the form (e.g., John).
16. Enter the **Created At** date and time using the date and time format (e.g., MM/DD/YYYY HH:MM AM/PM).
17. Enter the **Updated By** for the person who last updated the form (e.g., John).
18. Enter the **Updated At** date and time using the date and time format (e.g., MM/DD/YYYY HH:MM AM/PM).
19. Enter the **Created At Datetime** using the date and time format (e.g., MM/DD/YYYY HH:MM AM/PM).
20. Enter the **Updated At Datetime** using the date and time format (e.g., MM/DD/YYYY HH:MM AM/PM).

## Field-by-Field Explanation

* **Client Name** (`client_name`, text, required): Enter the name of the client you met with during the call.
* **Call Date Time** (`call_date_time`, date, required): Enter the date and time of the call in the MM/DD/YYYY HH:MM AM/PM format.
* **Call Location** (`call_location`, select_one, required): Select the location of the call from the dropdown options (e.g., New York, Los Angeles, Chicago).
* **Sales Professional** (`sales_professional`, select_multiple, required): Select the sales professional who handled the call from the dropdown options (e.g., John, Jane, Bob).
* **Lead Status** (`lead_status`, select_one, required): Select the current lead status from the dropdown options (e.g., Lead, No Lead, Unknown).
* **Lead Source** (`lead_source`, select_one, required): Select the source of the lead from the dropdown options (e.g., Referral, Advertisement, Social Media).
* **Call Result** (`call_result`, select_multiple, required): Select the result of the call from the dropdown options (e.g., Agreed to meet, Disqualified, Unknown).
* **Follow up Actions** (`follow_up_actions`, select_multiple, required): Select the follow-up actions taken from the dropdown options (e.g., Schedule follow-up call, Send follow-up email, Unknown).
* **Follow up Next Call** (`follow_up_next_call`, time, required): Enter the date and time of the next follow-up call.
* **Follow up Next Call Phone** (`follow_up_next_call_phone`, text, required): Enter any additional phone number for the next follow-up call.
* **Follow up Next Call Email** (`follow_up_next_call_email`, email, required): Enter the email sent for the next follow-up call.
* **Lead Owner** (`lead_owner`, select_one, required): Select the lead owner from the dropdown options (e.g., John, Jane, Bob).
* **Sales Process** (`sales_process`, select_one, required): Select the sales process used from the dropdown options (e.g., Salesforce, Manual Process, Unknown).
* **Lead Status Update** (`lead_status_update`, select_multiple, required): Select the status update from the dropdown options (e.g., Updated, Unchanged, Unknown).
* **Follow up Next Call Status** (`follow_up_next_call_status`, select_multiple, required): Select the status of the next follow-up call from the dropdown options (e.g., Completed, In Progress, Unknown).
* **Created By** (`created_by`, text, required): Enter the person who created the form (e.g., John).
* **Created At** (`created_at`, date, required): Enter the date and time of form creation using the date and time format (e.g., MM/DD/YYYY HH:MM AM/PM).
* **Updated By** (`updated_by`, text, required): Enter the person who last updated the form (e.g., John).
* **Updated At** (`updated_at`, date, required): Enter the date and time of the last update using the date and time format (e.g., MM/DD/YYYY HH:MM AM/PM).
* **Created At Datetime** (`created_at_datetime`, date, required): Enter the date and time of form creation using the date and time format (e.g., MM/DD/YYYY HH:MM AM/PM).
* **Updated At Datetime** (`updated_at_datetime`, date, required): Enter the date and time of the last update using the date and time format (e.g., MM/DD/YYYY HH:MM AM/PM).

## Tips

* Please ensure you fill in all required fields to ensure accurate tracking and follow-up.
* If unsure about any field, refer to the sales process guidelines or contact the sales team for guidance.
