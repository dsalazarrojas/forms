# Exhibition Booking Form - Help Guide

## Purpose
The Exhibition Booking Form is designed to collect information from vendors and event organizers about exhibition bookings. This form will help us understand the event details, vendor requirements, and contact information.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill in the vendor's name.
2. Select the date of the event.
3. Choose the time of the event.
4. Provide the stall number for the event.
5. Enter the contact email of the event organizer.
6. Enter the contact phone number of the event organizer.
7. Enter the vendor's address.
8. Enter the location of the event.
9. Write a brief description of the event.
10. Select whether the vendor is participating (Yes/No) for vendor_type (single select) field.
11. Select whether the vendor is participating (Yes/No) for vendor_type (multiple select) field.
12. Add any additional notes about the event.
13. Select whether the assigned user will be involved (Yes/No) for assigned_user (single select) field.
14. Select whether the assigned user will be involved (Yes/No) for assigned_user (multiple select) field.
15. Add any additional notes about the event.

## Field-by-Field Explanation

* **vendor_name** (text, required false): Please enter the name of the vendor.
* **event_date** (date, required false): Select the date of the event.
* **event_time** (time, required false): Choose the time of the event.
* **stall_number** (number, required false): Enter the stall number for the event.
* **contact_email** (email, required false): Enter the contact email of the event organizer.
* **contact_phone** (text, required false): Enter the contact phone number of the event organizer.
* **vendor_address** (text, required false): Enter the vendor's address.
* **event_location** (text, required false): Enter the location of the event.
* **vendor_description** (text, required false): Write a brief description of the event.
* **vendor_type** (select_one, required false): Select whether the vendor is participating (Yes/No).
* **vendor_type** (select_multiple, required false): Select whether the vendor is participating (Yes/No) for multiple options.
* **notes** (note, required false): Add any additional notes about the event.
* **assigned_user** (select_one, required false): Select whether the assigned user will be involved (Yes/No).
* **assigned_user** (select_multiple, required false): Select whether the assigned user will be involved (Yes/No) for multiple options.
* **notes** (note, required false): Add any additional notes about the event.

Note: Fields with required false are optional and can be left blank if not applicable.
