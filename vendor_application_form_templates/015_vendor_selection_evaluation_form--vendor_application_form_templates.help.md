# Vendor Selection Evaluation Form - Help Guide

## Purpose
The Vendor Selection Evaluation Form is used to evaluate and compare different vendors. This form helps you to collect and assess relevant data about a vendor, including their quality and rating.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the "main" page and enter your answers to the questions or information about the vendor in the text fields.
2. In the "quality" field, enter a number value that represents the vendor's quality.
3. In the "quality_rating" field, enter a number value that represents the vendor's quality rating (on a scale, e.g., 1-5).
4. In the "vendor_rating" field, enter a text description of the vendor's overall rating.

## Field-by-Field Explanation

* **title** (Vendor Selection Evaluation Form, text, required/optional: optional): This is the title of the form. You can enter any text you like.
* **quality** (Number, required/optional: required/optional): Enter a number value that represents the vendor's quality. For example, 5/5 for an excellent quality vendor.
* **quality_rating** (Number, required/optional: required/optional): Enter a number value that represents the vendor's quality rating. For example, 3/5 for a medium quality vendor.
* **vendor_rating** (Text, required/optional: required/optional): Enter a text description of the vendor's overall rating. For example, "Good" or "Excellent".
