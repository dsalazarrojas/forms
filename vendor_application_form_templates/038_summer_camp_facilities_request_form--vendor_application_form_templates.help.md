The summer_camp_facilities_request_form is used to collect information and requirements related to a summer camp event. This form helps event organizers and summer camp staff to plan and prepare for a successful and safe event.

1. Select the applicable event type(s) that pertain to your summer camp event.
2. Choose a facility from the provided options or select "No" if no facility is required.
3. Enter any additional notes about the facility you've chosen, if necessary.
4. Provide the start and end dates for the event.
5. Enter the start and end times for the event, if applicable.
6. Specify the event location.
7. Enter the expected number of attendees.
8. Add any additional event details or notes, if necessary.
9. Specify any specific requirements or requests for the event, such as equipment or personnel.
10. Enter any facility-specific requirements or requests.
11. Provide information about the event host, including their name and contact details.
12. Add any final notes or comments about the event.
