# Trade Show Vendor Information Collection Form - Help Guide
## Purpose
The Trade Show Vendor Information Collection Form is a form used to collect vendor information for display at the trade show. Each vendor should only be entered once into the system.

## How To Complete This Form
To complete this form, please follow these steps:

1. Select the correct vendor type from the options provided.
2. Enter the vendor's address in the text box.
3. Enter the vendor's contact email in the format of [email address](mailto:email address).
4. Enter the vendor's phone number in the format of XXX-XXX-XXXX.
5. Select the correct booth size from the options provided.
6. Enter the vendor's website in the format of http://www.example.com.
7. Enter any additional notes about the vendor.
8. Select the social media handles for the vendor.
9. Enter any additional information about the vendor.
10. Upload an image of the vendor.
11. Upload a video about the vendor.
12. Upload a document about the vendor.

## Field-by-Field Explanation
* **Trade Show Vendor Information** (`trade_show_vendor_information_collection_form`): This is a text field where you can enter any additional information about the vendor.
* **Vendor Info** (`vendor_application_form_info`): This is a dropdown menu to select the type of vendor (e.g. Vendor A, Vendor B, Vendor C).
* **Vendor Address** (`vendor_address`): This is a text field where you can enter the vendor's address.
* **Contact EMail** (`contact_email`): This is a text field where you can enter the vendor's email address in the format of [email address](mailto:email address).
* **Phone Number** (`phone_number`): This is a text field where you can enter the vendor's phone number in the format of XXX-XXX-XXXX.
* **Vendor Type** (`vendor_type`): This is a dropdown menu to select the type of vendor (e.g. Food, Beverage, Service).
* **Booth Size** (`booth_size`): This is a number field where you can select the size of the vendor's booth.
* **Vendor Website** (`vendor_website`): This is a text field where you can enter the vendor's website in the format of http://www.example.com.
* **Vendor Notes** (`vendor_notes`): This is a text field where you can enter any notes about the vendor.
* **Social Media** (`vendor_social_media`): This is a dropdown menu to select the social media handles for the vendor (e.g. Twitter, Facebook, Instagram).
* **Vendor Additional Info** (`vendor_additional_info`): This is a text field where you can enter any additional information about the vendor.
* **Vendor Image** (`vendor_image`): This is a text field where you can upload an image of the vendor.
* **Vendor Video** (`vendor_video`): This is a text field where you can upload a video about the vendor.
* **Vendor Document** (`vendor_document`): This is a text field where you can upload a document about the vendor.
