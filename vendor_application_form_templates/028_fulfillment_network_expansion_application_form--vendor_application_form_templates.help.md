# Fulfillment Network Expansion Application Form - Help Guide

## Purpose
This form is used to collect contact and shipping information from vendors to expand our fulfillment network.

## How To Complete This Form
1. Please fill out the form completely, including all required fields (if any).
2. Make sure to select the correct options for each field as requested.
3. Review the form carefully before submitting to ensure accuracy.

## Field-by-Field Explanation
* **Contact Information** (Page 1)
	+ **Contact Information** (`contact_form`, `note`, not required):
		- This field is used to collect additional contact information from vendors. Enter any relevant details that would be helpful in communication.
* **Shipping Details** (Page 1)
	+ **Shipping Details** (`shipping_details_form`, `select_one`, not required):
		- Select 'Yes' to indicate that we will handle shipping and 'No' to indicate otherwise.
* **Vendor Information** (Page 2)
	+ **Vendor Information** (`vendor_info_form`, `select_multiple`, not required):
		- Select all applicable options to provide more information about the vendor. Select 'Yes' for each option that applies.
* **Order Information** (Page 2)
	+ **Order Information** (`order_form`, `select_multiple`, not required):
		- Select all applicable options to provide more information about the order. Select 'Yes' for each option that applies.
* **Address Information** (Page 2)
	+ **Address Information** (`address_form`, `select_one`, not required):
		- Select 'Yes' to indicate that the shipping address is the same as the contact address and 'No' otherwise.
* **Fulfillment** (Page 3)
	+ **Fulfillment** (`fulfillment_form`, `select_multiple`, not required):
		- Select all applicable options to provide more information about our fulfillment services. Select 'Yes' for each option that applies.
* **Additional Information** (Page 3)
	+ **Additional Information** (`additional_form`, `select_one`, not required):
		- Select 'Yes' to indicate that there is any additional information to provide and 'No' otherwise.
* **Notes** (Page 3)
	+ **Notes** (`notes_form`, `select_one`, not required):
		- Select 'Yes' to indicate that you have any notes to provide and 'No' otherwise.
* **Contact Information 2** (Page 4)
	+ **Contact Information 2** (`contact_form_2`, `select_multiple`, not required):
		- Select all applicable options to provide more information about contact. Select 'Yes' for each option that applies.
* **Vendor Information 2** (Page 4)
	+ **Vendor Information 2** (`vendor_form`, `select_multiple`, not required):
		- Select all applicable options to provide more information about the vendor. Select 'Yes' for each option that applies.
* **Order Information 2** (Page 5)
	+ **Order Information 2** (`order_form_2`, `select_one`, not required):
		- Select 'Yes' to indicate that there is any order information to provide and 'No' otherwise.
* **Shipping Info** (Page 5)
	+ **Shipping Info** (`shipping_form`, `date`, not required):
		- Enter the date for shipping. Use the format 'YYYY-MM-DD'.
* **Contact Information 3** (Page 5)
	+ **Contact Information 3** (`contact_form_3`, `select_one`, not required):
		- Select 'Yes' to indicate that you have any contact information to provide and 'No' otherwise.
* **Fulfillment 2** (Page 6)
	+ **Fulfillment 2** (`fulfillment_form_2`, `select_multiple`, not required):
		- Select all applicable options to provide more information about our fulfillment services. Select 'Yes' for each option that applies.
* **Notes 2** (Page 6)
	+ **Notes 2** (`notes_form_2`, `select_one`, not required):
		- Select 'Yes' to indicate that you have any notes to provide and 'No' otherwise.
* **Address Information 2** (Page 7)
	+ **Address Information 2** (`address_form_2`, `select_one`, not required):
		- Select 'Yes' to indicate that the shipping address is the same as the contact address and 'No' otherwise.

## Tips
* Make sure to fill out the form completely and accurately.
