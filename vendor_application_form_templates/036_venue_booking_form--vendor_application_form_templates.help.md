# Venue Booking Form - Help Guide
## Purpose
The Venue Booking Form is a form used to book venues for various events such as concerts, weddings, conferences, and more. It collects information about the event, venue, and contact details to ensure a smooth booking process.

## How To Complete This Form
To complete the form, follow these steps:

1. Select the booking date for your event.
2. Choose the type of venue you're interested in booking (e.g., Hotels, Restaurants, Bars, Theaters).
3. Enter the name of the venue.
4. If applicable, specify the venue's capacity.
5. Enter the number of guests attending the event.
6. Provide the name of the event.
7. Describe the event briefly.
8. Specify the start and end times of the event.
9. Enter your contact phone number for communication.

## Field-by-Field Explanation

* **Booking Date** (`venue_booking_date`): Enter the date you want to book the venue for.
* **Venue Type** (`venue_type`): Select the type of venue you're interested in booking (e.g., Hotels, Restaurants, Bars, Theaters).
* **Venue Name** (`venue_name`): Enter the name of the venue you've selected.
* **Venue Capacity** (`venue_capacity`): If applicable, enter the maximum capacity of the venue.
* **Number of Guests** (`number_of_guests`): Enter the number of guests attending the event.
* **Event Name** (`event_name`): Enter a descriptive name for your event.
* **Event Description** (`event_description`): Briefly describe the event.
* **Event Start Time** (`event_start_time`): Enter the start time of the event.
* **Event End Time** (`event_end_time`): Enter the end time of the event.
* **Contact Phone** (`contact_phone`): Enter your contact phone number for communication.

## Tips

* Please make sure to fill out all required fields to ensure the booking process is successful.
* Use the correct formatting for date and time fields.
* Ensure you select the correct venue type to get accurate information for your event.
* If you're booking for an event with a large number of guests, please note this in the Venue Capacity field. 

This guide is designed to be user-friendly and help users complete the form accurately and efficiently.
