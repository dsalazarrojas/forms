# Vendor Maintenance Form - Help Guide
## Purpose
The Vendor Maintenance Form is used to collect and update vendor information, including contact details and financial data.

## How To Complete This Form
To complete this form, follow these steps:

1. Ensure that only necessary changes are made to the existing vendor record. If the vendor has been previously set up, do not create a new record.
2. Fill out the form with the required information for each field.
3. Review the form carefully before submitting it.

## Field-by-Field Explanation

* **Title** (`Vendor Maintenance Form`): This is the title of the form.
* **Vendor Information** (`main_page`): This section contains the main information for the vendor.
* **Vendor Name** (`Vendor Name`): This is the name of the vendor.
	+ The vendor name is a required field.
	+ Please enter the name of the vendor as it appears on their official documents or business cards.
* **Vendor Address** (`Vendor Address`): This is the physical address of the vendor.
	+ The vendor address is a required field.
	+ Please enter the address where the vendor can be contacted or receives mail.
* **Vendor Phone** (`Vendor Phone`): This is the phone number of the vendor.
	+ The vendor phone is a required field.
	+ Please enter the primary phone number where the vendor can be reached.
* **Vendor Email** (`Vendor Email`): This is the email address of the vendor.
	+ The vendor email is a required field.
	+ Please enter the primary email address where the vendor can be reached.
* **Vendor Expenses** (`Vendor Expenses`): This is the estimated expense for the vendor.
	+ The vendor expenses is a required field.
	+ Please enter a number value for the estimated expense.
* **Expense Description** (`Expense Description`): This is a brief description of the expense.
	+ The expense description is a required field.
	+ Please enter a brief description of the expense.
* **Vendor Reimbursement** (`Vendor Reimbursement`): This is the reimbursement amount for the vendor.
	+ The vendor reimbursement is a required field.
	+ Please enter the reimbursement amount for the vendor.
* **Vendor Status** (`Vendor Status`): This is the current status of the vendor.
	+ The vendor status is a required field.
	+ Please select one of the following options: Active, Inactive, or Pending.
* **Vendor Comments** (`Vendor Comments`): This is an optional field for additional comments or notes about the vendor.
* **Assigned Tool** (`Assigned Tool`): This is an optional field for selecting the tool assigned to the vendor.
	+ Please select one of the following options: chatjimmy, jimsbot, or otherbot.
