# individual_vendor_application_form - Help Guide
## Purpose

The individual vendor application form is designed to collect and evaluate essential information from potential vendors for approval.

## How To Complete This Form

1. Review and understand the purpose of each section and field.
2. Ensure that all required fields are completed accurately and completely.
3. Double-check for any errors or missing information before submission.

## Field-by-Field Explanation

* **Vendor Information** (Vendor Information, text, required): This section requests basic facts about the vendor, including their name, contact information, and address.
* **Contact Information** (Contact Information, text, required): This section gathers details about the vendor's contact information, including their email address and phone number.
* **Vendor Address** (Vendor Address, text, required): This field requests the vendor's address for contact and delivery purposes.
* **Business Information** (Business Information, text, required): This section gathers details about the vendor's experience, work status, and work experience.
* **Experience Level** (Experience Level, select one, required): This field requests the vendor's experience level, which can be Basic, Intermediate, or Advanced.
* **Work Status** (Work Status, select multiple, required): This field requests the vendor's current work status, which can be Full-time, Part-time, or Intern.
* **Work Experience** (Work Experience, text, required): This field requests information about the vendor's work experience.
* **Vendor Profile** (Vendor Profile, text, required): This section provides additional insights into the vendor's background and qualifications.
* **Agreement Terms** (Agreement Terms, note, required): This section requests the vendor to review and accept the terms and conditions of the agreement.
* **Vendor Status** (Vendor Status, select one, required): This field requests the vendor's current status, which can be Active, Inactive, or Pending.
* **Vendor Category** (Vendor Category, select one, required): This field requests the vendor's primary category.
* **Vendor Subcategory** (Vendor Subcategory, select one, required): This field requests the vendor's subcategory.
* **Vendor Notes** (Vendor Notes, note, optional): This field provides space for additional comments or information.
* **Email** (Email, email, required): This field requests the vendor's email address.
* **Phone** (Phone, text, optional): This field requests the vendor's phone number.
* **Website** (Website, select one, required): This field requests the vendor's website.
* **Social Media** (Social Media, select multiple, optional): This field requests the vendor's social media platforms.
* **Vendor License Number** (Vendor License Number, select one, required): This field requests whether the vendor has a license.
* **Vendor Certifications** (Vendor Certifications, text, optional): This field requests information about the vendor's certifications.
* **Services Offered** (Services Offered, text, optional): This field requests information about the services offered by the vendor.
* **Employment Type** (Employment Type, select one, required): This field requests the vendor's employment type.
* **Annual Salary** (Annual Salary, number, optional): This field requests the vendor's annual salary.
* **Hours Worked** (Hours Worked, select one, required): This field requests the number of hours the vendor worked.
* **Sick Leave** (Sick Leave, select one, required): This field requests whether the vendor has sick leave.
* **Health Insurance** (Health Insurance, select one, required): This field requests whether the vendor has health insurance.
* **Vendor Social Media** (Vendor Social Media, select multiple, optional): This field requests the vendor's social media platforms.
* **Vendor License Number** (Vendor License Number, select one, required): This field requests the vendor's license number.
