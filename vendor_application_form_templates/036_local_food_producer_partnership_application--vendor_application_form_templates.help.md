# local_food_producer_partnership_application - Help Guide
## Purpose
This form is used to gather information from local food producers about their business, products, and partnerships. It helps potential partners and stakeholders understand their operations and products.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the farm information page (id 1, farm_info).
2. Move on to the farm details page (id 2, farm_details) and provide more information about your farm.
3. Continue to the producer information page (id 3, producer_info) and provide details about your business.
4. Move on to the contact information page (id 4, contact_info) and provide your contact information.
5. On the farm products page (id 5, farm_products), list the products you offer.
6. The certifications page (id 6, certifications) is optional.
7. The farm partners page (id 7, farm_partners) and the co-op partners page (id 8, co_op_partners) ask about your partnerships. Please answer based on your current partnerships.
8. The market partners page (id 9, market_partners) and the program partners page (id 10, program_partners) are also optional.
9. The retailer partners page (id 11, retailer_partners) is optional as well.
10. The delivery information page (id 12, delivery_info) and the produce information page (id 13, produce_info) are optional.
11. On the farm location page (id 15, farm_location), select the correct option to indicate if you have multiple locations.
12. If you have multiple locations, enter the address for each location on the farm address page (id 16, farm_address).
13. On the contact preferences page (id 17, contact_preferences), provide your communication preferences.
14. The emergency contacts page (id 18, emergency_contacts and id 19, emergency_contacts_2) are optional.
15. Finally, on the farm location pages (id 20, farm_location_2, id 21, farm_location_3, id 22, farm_location_4, id 23, farm_location_5, id 24, farm_location_6), select the correct options to indicate your farm locations.

## Field-by-Field Explanation

* **Farm Info** (id 1, farm_info): Enter a brief description of your farm.
* **Farm Details** (id 2, farm_details): Provide more information about your farm.
* **Producer Info** (id 3, producer_info): Share details about your business.
* **Contact Info** (id 4, contact_info): Enter your contact information.
* **Farm Products** (id 5, farm_products): List the products you offer.
* **Certifications** (id 6, certifications): If you have any certifications, list them here.
* **Farm Partners** (id 7, farm_partners): Check 'Yes' if you have farm partners.
* **Co-op Partners** (id 8, co_op_partners): Check 'Yes' if you have co-op partners.
* **Market Partners** (id 9, market_partners): Check 'Yes' if you have market partners.
* **Program Partners** (id 10, program_partners): Check 'Yes' if you have program partners.
* **Retailer Partners** (id 11, retailer_partners): Check 'Yes' if you have retailer partners.
* **Delivery Info** (id 12, delivery_info): If you have delivery information, enter it here.
* **Produce Info** (id 13, produce_info): If you have produce information, enter it here.
* **Produce Types** (id 14, produce_types): If you have produce information, enter it here.
* **Farm Location** (id 15, farm_location): Select 'Yes' if you have multiple locations.
* **Farm Address** (id 16, farm_address): If you have multiple locations, enter the address for each location.
* **Contact Preferences** (id 17, contact_preferences): Enter your communication preferences.
* **Emergency Contacts** (id 18, emergency_contacts): If you need emergency contact information, enter it here.
* **Emergency Contacts 2** (id 19, emergency_contacts_2): If you need secondary emergency contact information, enter it here.
* **Farm Location 2** (id 20, farm_location_2): Select 'Yes' if this location is correct.
* **Farm Location 3** (id 21, farm_location_3): Select 'Yes' if this location is correct.
* **Farm Location 4** (id 22, farm_location_4): Select 'Yes' if this location is correct.
* **Farm Location 5** (id 23, farm_location_5): Select 'Yes' if this location is correct.
* **Farm Location 6** (id 24, farm_location_6): Select 'Yes' if this location is correct.
* **Payment Info** (id 25, payment_info): If you have payment information, enter it here.
