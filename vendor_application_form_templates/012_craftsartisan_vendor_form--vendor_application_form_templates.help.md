# CraftsArtisanVendorForm - Help Guide
## Purpose
This form is used to create and manage vendor information for the CraftsArtisan platform.

## How To Complete This Form
To fill out this form, start by providing the following information:

1. **User Name (1)**: Enter the name of the user creating this vendor account.
2. **Email (2)**: Enter the email address of the user creating this vendor account.
3. **Vendor Name (3)**: Enter the name of the vendor.
4. **Vendor Category (4)**: Enter the category or type of vendor (e.g., material supplier, service provider, etc.).
5. **Vendor Website (5)**: If the vendor has a website, enter the URL here.
6. **Vendor Phone (6)**: Enter the phone number of the vendor.
7. **Notes (7)**: Add any additional notes or comments about the vendor.
8. **Address (8)**: Enter the physical address of the vendor.

## Field-by-Field Explanation

* **User Name (1)**: A unique identifier for the user creating this vendor account.
* **Email (2)**: The contact email address of the user creating this vendor account.
* **Vendor Name (3)**: The name of the vendor being listed.
* **Vendor Category (4)**: A classification of the type of vendor (e.g., material supplier, service provider, etc.).
* **Vendor Website (5)**: The website of the vendor (if applicable).
* **Vendor Phone (6)**: The phone number of the vendor.
* **Vendor Notes (7)**: Any additional information or comments about the vendor.
* **Address (8)**: The physical address of the vendor location.
