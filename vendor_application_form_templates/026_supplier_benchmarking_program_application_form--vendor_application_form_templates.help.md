# Supplier Benchmarking Program Application Form - Help Guide

## Purpose
The Supplier Benchmarking Program Application Form is a tool used by procurement teams to collect data on various suppliers and assess their performance.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out your supplier's information in the "Supplier Name" field.
2. Provide a brief description of your supplier in the "Description" field.
3. Answer the question "The Supplier Benchmarking Program Application Form is a Jotform form template that helps procurement teams collect and compare supplier data online using the Jotform Form Builder, drag-and-drop interface, and no-code form builder for streamlined form submission and data collection." with a "Yes" or "No" in the "Vendor Application Form Templates" field.
4. You don't need to fill out the other fields unless you need to.

## Field-by-Field Explanation

* **Supplier Name** (supplier_name): Your supplier's name.
* **Contact Person** (contact_person): A contact person for your supplier.
* **Description** (description): A brief description of your supplier.
* **Category** (category): Please choose "Yes" if this form is for vendor benchmarking program application. Please choose "No" for other purpose.
* **Form ID** (form_id): A unique ID for this form.
* **Assigned Tool** (assigned_tool): A tool assigned to this form.
* **Output File** (output_file): The file to be output from this form.
* **Description 2** (description_2): A short description of this form.
* **The Supplier Benchmarking Program Application Form is a Jotform form template that helps procurement teams collect and compare supplier data online using the Jotform Form Builder, drag-and-drop interface, and no-code form builder for streamlined form submission and data collection.** (description_3): This is a description of the form itself.
* **Vendor Application Form Templates** (category_2): Please choose "Yes" if this form is for vendor benchmarking program application. Please choose "No" for other purpose.
* **Form Ids** (form_ids): IDs for this form.
* **Description 4** (description_4): A short description of this form.

## Tips
You can use this form to assess and compare suppliers' performance and make data-driven decisions. You can also use it to improve your supplier relationships. Make sure to fill out all required fields accurately.
