# Supplier Compliance Recognition Application Form - Help Guide
## Purpose

This form is used to collect necessary information from suppliers about their compliance recognition application. It is designed to gather details such as supplier name, address, contact information, and application date.

## How To Complete This Form

1. Fill out the form with accurate and complete information about the supplier.
2. Upload any required documents in a supported format.
3. Select the correct options for the application.
4. Double-check that all fields are filled out accurately before submitting the form.

## Field-by-Field Explanation

* **Supplier Name** (`supplierName`, text, required): Enter the name of the supplier company or entity.
* **Vendor Address** (`vendor_address`, text, required): Enter the address of the supplier.
* **Contact Information** (`contact_information`, note, optional): Enter any additional contact information for the supplier.
* **Email** (`email`, email, required): Enter the email address of the supplier.
* **Phone** (`phone`, text, required): Enter the phone number of the supplier.
* **Application Date** (`application_date`, date, required): Enter the date of the application.
* **Upload Documents** (`upload_documents`, text, required): Upload any required documents in a supported format (e.g., PDF, JPEG, PNG).
* **Select One** (`select_one`, select_one, required): Select one of the provided options.
* **Select Multiple** (`select_multiple`, select_multiple, required): Select multiple options.
* **Time** (`time`, time, required): Select the time of the application.
* **Integer** (`integer`, number, required): Enter an integer value.
* **Decimal** (`decimal`, number, required): Enter a decimal value.
* **Select Yes/No** (`select_yes_no`, select_one, required): Select one of the provided options.
* **Date** (`date`, date, required): Enter a date value.
* **Submit** (`submit`, text, required): Review and submit the form.

## Tips

* Ensure all fields are filled out accurately and completely before submitting the form.
* Use supported document formats for uploading documents.
* If you're unsure about any information, please reach out to the relevant contacts or administrators for assistance.
