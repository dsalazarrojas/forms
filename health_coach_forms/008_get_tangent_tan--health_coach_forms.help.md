# Get Tangent (tan) - Help Guide
## Purpose
The purpose of this form is to help the user calculate the tangent of a given angle. This form is intended for users who want to find the tangent of an angle in the unit circle.

## How To Complete This Form
To complete this form, follow the steps below:

1. Enter the angle in decimal degrees in the first field.
2. Click on the "Submit" button to calculate the tangent of the angle.

## Field-by-Field Explanation
* **Enter a number** (Enter a number, number, optional): Enter a decimal degree angle value (e.g., 30.5, 45, 90) to calculate the tangent of the angle.
* **Tangent** (Tangent, note, optional): This field displays the calculated tangent of the input angle.

## Tips
This form is intended for basic angle calculations and is not designed for complex mathematical operations or advanced trigonometric functions. If you need more advanced calculations, please use a specialized trigonometry calculator or a computer algebra system.
