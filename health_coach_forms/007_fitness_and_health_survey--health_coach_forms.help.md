# Fitness And Health Survey - Help Guide
## Purpose
This survey is designed to gather information about your health habits, medical history, and participation in various activities related to fitness and health. The goal is to gather insights into your overall health and wellness.

## How To Complete This Form
1. Please answer all questions honestly and accurately.
2. Select multiple answers for questions that allow multiple selections.
3. If you have any medical conditions, please provide a brief description.
4. If you have any questions or concerns, do not hesitate to contact us.

## Field-by-Field Explanation
* **Introduction** (`Introduction`, Text, Not required): Please take a moment to review the following questions and answer them honestly.
* **Health Habits** (`Health Habits`, Select Multiple, Not required): Choose all that apply:
	+ Daily Exercise
	+ Healthy Eating
	+ Sleep
	+ Stress Management
* **Medical History** (`Medical History`, Text, Not required): If you have any medical conditions, please describe them briefly.
* **Activity Participation** (`Activity Participation`, Select One, Not required): Choose the activity you regularly participate in:
	+ Running
	+ Swimming
	+ Cycling
	+ Hiking
	+ Team Sports
	+ Gym
	+ Other
* **Health Goals** (`Health Goals`, Select Multiple, Not required): Choose all that apply:
	+ Weight Loss
	+ Weight Gain
	+ Improved Physical Health
	+ Increased Energy
	+ Better Mental Health
* **Physical Education Participation** (`Physical Education Participation`, Select Multiple, Not required): Choose all that apply:
	+ Physical Education Class

	+ Fitness Class
	+ Recreational Dance Class
	+ Other
* **Health Education Participation** (`Health Education Participation`, Select Multiple, Not required): Choose all that apply:
	+ Health Class

	+ Stress Management Class
	+ Other
* **Medical Conditions** (`Medical Conditions`, Text, Not required): If you have any medical conditions, please describe them briefly.
* **Health Participation** (`Health Participation`, Select Multiple, Not required): Choose all that apply:
	+ Chiropractor

	+ Other
