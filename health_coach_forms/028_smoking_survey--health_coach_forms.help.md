# Smoking Survey - Help Guide

## Purpose
This form is designed to collect information about your smoking habits and behavior. It will ask you a series of questions about your demographics, smoking status, and quitting history. Please answer these questions honestly, as the information you provide will help you and your healthcare provider create a plan to help you quit smoking.

## How To Complete This Form

1. Please answer each question carefully and honestly.
2. If you are unsure about any question, please ask for clarification.
3. You can select multiple options for select_multiple fields.
4. You can only select one option for select_one fields.

## Field-by-Field Explanation

* **First Name** (`first_name`, text, required): Please enter your first name as it appears on your official documents.
* **Last Name** (`last_name`, text, required): Please enter your last name as it appears on your official documents.
* **Age** (`age`, number, required): Please enter your age.
* **Gender** (`gender`, select_multiple, required): Please select one or more of the following:
	+ male
	+ female
	+ other
* **Smoking Status** (`smoking_status`, select_one, required): Please select one of the following:
	+ never
	+ sometimes
	+ daily
* **Years Smoking** (`years_smoking`, number, required): Please enter the number of years you have been smoking.
* **Cigarettes Per Day** (`cigarettes_per_day`, number, required): Please enter the number of cigarettes you smoke per day.
* **Quit Date** (`quit_date`, date, optional): If you have quit smoking, please enter the date you last smoked.
* **Reason for Quitting** (`reason_quit`, select_multiple, required): Please select one or more of the following:
	+ health
	+ stress
	+ money
* **Smoking Level** (`smoking_level`, select_one, required): Please select one of the following:
	+ light
	+ moderate
	+ heavy

## Tips
* Please answer honestly and carefully.
* If you need help, please ask.
* This form is designed to be completed once, please do not submit multiple times.
