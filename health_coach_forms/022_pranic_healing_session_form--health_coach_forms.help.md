# pranic_healing_session_form - Help Guide
## Purpose
The pranic healing session form is a tool for scheduling and organizing pranic healing sessions. It collects information about the client, session details, and other relevant data to support the health coach's preparation and delivery of the session.

## How To Complete This Form
- To complete this form, please follow these steps:

  - Select the type of session you are interested in.
  - Enter the client's name as a text input.
  - Choose a date for the session using the date picker.
  - Select the session time using the time input.
  - Enter the client's phone number.
  - Input the session length, which is the duration of the session.
  - Add any additional session details in the note field.
  - Check if a health coach is assigned for the session and select the "Yes" or "No" option accordingly.
  - Repeat step 9 if you have another health coach assigned for a different session.

## Field-by-Field Explanation

* **Session Type** (session_type, required): Select the type of pranic healing session you are interested in.
* **Client Name** (client_name, optional): Enter the client's name as it should be displayed on the session records.
* **Session Date** (session_date, optional): Choose a date for the session using the date picker. Please note that the date picker will help you select a date that is not too far in the past or future.
* **Session Time** (session_time, optional): Select the time for the session using the time input.
* **Client Phone** (client_phone, optional): Enter the client's phone number for communication purposes.
* **Session Length** (session_length, optional): Input the session duration in minutes. Please note that this will affect the session schedule and records.
* **Session Details** (session_details, optional): Add any additional notes or details about the session.
* **Assigned Health Coach** (assigned_health_coach, optional): Check if a health coach is assigned for the session. Please note that having a health coach assigned will affect the session preparation and follow-up.
* **Assigned Health Coach** (assigned_health_coach, optional): This field appears to be a duplicate of the previous field. Please disregard this field for now. We will review this further.
