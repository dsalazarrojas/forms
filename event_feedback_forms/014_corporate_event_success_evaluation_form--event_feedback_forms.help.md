# Corporate Event Success Evaluation Form - Help Guide

## Purpose
The Corporate Event Success Evaluation Form is designed to gather feedback and information about corporate events. The form helps event planners and organizers evaluate the success of their events, identify areas for improvement, and make informed decisions for future events.

## How To Complete This Form

1. **Introduction**: Please provide a brief description of the event, including its type (e.g., meeting, training, conference), location, and date.
2. **Event Type**: Select the type of event that best describes the event you attended (e.g., Meeting, Training, Conference).
3. **Location**: Enter the location where the event took place.
4. **Date**: Enter the date of the event.
5. **Time**: Enter the time of the event.
6. **Attendees**: Provide a brief description of the attendees, including their numbers and demographics.
7. **Overall Satisfaction**: Rate your overall satisfaction with the event on a scale of 1-5.
8. **Improvement Areas**: Provide feedback on areas where the event could be improved.
9. **Follow-Up Action**: Describe any follow-up actions taken or planned for the event.
10. **Comments**: Add any additional comments or feedback about the event.
11. **Email**: Provide your email address (optional).
12. **Phone**: Provide your phone number (optional).
13. **Assigned To**: Select the person or team member assigned to follow up on this event.
14. **Follow-Up Date**: Set a date for the follow-up follow-up (if applicable).
15. **Follow-Up Time**: Set a time for the follow-up follow-up (if applicable).
16. **Follow-Up Status**: Select the status of the follow-up follow-up (e.g., Done, Not Done, Pending).
17. **Follow-Up Notes**: Add any notes about the follow-up follow-up (if applicable).
18. **Assigned Tool**: Select the tool used for follow-up (e.g., Chatjimmy, Other).
19. **Follow-Up Frequency**: Select the frequency of the follow-up follow-up (e.g., Daily, Weekly, Monthly).
20. **Follow-Up Method**: Select the method of the follow-up follow-up (e.g., Call, Email, In-app Message).
21. **Follow-Up Message**: Add any follow-up message to be used (if applicable).
22. **Follow-Up Frequency Other**: If other follow-up frequency is selected, please describe it in this field.
23. **Follow-Up Method Other**: If other follow-up method is selected, please describe it in this field.
24. **Follow-Up Message Other**: If other follow-up message is selected, please describe it in this field.
25. **Follow-Up Comments**: Add any additional follow-up comments.

## Tips
* Please be thorough and accurate when filling out this form.
* Use the correct event type and location to help us understand the event better.
* If you have any additional comments or feedback, please add them in the comments section.
* Please select the correct assigned person or team member for follow-up.
* Use the follow-up date and time to schedule a follow-up action.
* Select the correct follow-up method and frequency for the follow-up action.
* Be descriptive in the follow-up notes and message fields if applicable.
* If other follow-up frequency, method, or message is selected, please describe it in the corresponding fields.
