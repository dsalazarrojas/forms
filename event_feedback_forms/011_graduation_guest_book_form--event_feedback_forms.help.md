# Graduation Guest Book Form - Help Guide
## Purpose
The Graduation Guest Book Form is designed to collect feedback, messages, or comments from guests at a graduation event. Your responses will help us understand your thoughts, sentiments, and experiences from this special occasion.

## How To Complete This Form
To complete this form, proceed page by page, filling out each field as instructed. Start with the first page, "Graduation Message," which will guide you through the process.

## Field-by-Field Explanation

* **Graduation Message** (`graduation_guest_book_form_page_1`, note, required: false): This page is a space for you to write a message or comment about the graduation event. Please feel free to share your thoughts, memories, or words of wisdom.
* **Name** (`graduation_guest_book_form_page_2`, text, required: false): This field is for you to provide your name. If you'd like to remain anonymous, you can leave this field blank.
* **Class** (`graduation_guest_book_form_page_3`, text, required: false): This field is intended for you to specify which class or group you are representing, if any. You can leave this field blank if not applicable.
* **Year** (`graduation_guest_book_form_page_4`, number, required: false): This field is for you to indicate the year of the graduation event, if known. You can leave this blank if not applicable.
* **Graduation Message 3** (`graduation_guest_book_form_page_5`, note, required: false): This field is similar to the first, allowing you to express your thoughts or messages about the event.
* **Graduation Message 2** (`graduation_guest_book_form_page_6`, note, required: false): Another field for additional comments or messages about the event.
* **Graduation Message 1** (`graduation_guest_book_form_page_7`, note, required: false): A field for more thoughts or memories about the graduation event.
* **Graduation Message 2** (`graduation_guest_book_form_page_8`, note, required: false): More space to share your comments or messages about the graduation event.

* **Graduation Message 7** (`graduation_guest_book_form_page_13`, note, required: false): Additional room for comments or messages about the graduation event.
* **Graduation Message 8** (`graduation_guest_book_form_page_14`, note, required: false): The final field for last-minute thoughts or messages about the graduation event.

## Tips
* Please fill out each page carefully, ensuring you're providing accurate information for each field.
