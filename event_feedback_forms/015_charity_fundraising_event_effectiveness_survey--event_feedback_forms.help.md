# Charity Fundraising Event Effectiveness Survey - Help Guide
## Purpose
This survey aims to gather feedback from participants in charity fundraising events to evaluate their effectiveness in meeting goals, engaging attendees, and improving future events.

## How To Complete This Form
To complete the survey, please follow these steps:

1. Review the form and ensure you have all the required information.
2. Provide honest and accurate feedback in the fields below.

## Field-by-Field Explanation
* **Your Name** (`respondent_name`, text, Optional): Please enter your name. This information will only be used for follow-up purposes, if needed.
* **Email Address** (`respondent_email`, email, Optional): Enter your email address for contact purposes, if necessary.
* **Your Role at This Event** (`role_at_event`, select_one, Required): Select your role at the event. Choose from:
	+ Attendee
	+ Volunteer
	+ Organizer
	+ Vendor
	+ Sponsor
	+ Other
* **Event Name** (`event_name`, text, Required): Type the name of the event you attended.
* **Event Date** (`event_date`, date, Required): Enter the date of the event.
* **Compared to Expectations, Attendance Was** (`expected_vs_actual`, select_one, Required): Choose how the attendance met your expectations:
	+ Exceeded Expectations
	+ Met Expectations
	+ Below Expectations
* **Was the Audience What You Expected** (`audience_demographics`, select_one, Optional): Choose how the audience matched your expectations:
	+ Yes, As Expected
	+ Somewhat Different
	+ Very Different
* **How Effective Was the Event's Reach** (`reach_assessment`, select_one, Required): Select the effectiveness of the event's reach:
	+ Very Effective
	+ Effective
	+ Somewhat Effective
	+ Not Effective
* **Was the Fundraising Goal Met** (`fundraising_goal_met`, select_one, Required): Choose if the fundraising goal was met:
	+ Exceeded Goal
	+ Met Goal
	+ Nearly Met Goal
	+ Below Goal
* **Percentage of Goal Achieved** (`percent_of_goal`, number, Optional): Enter the percentage of the fundraising goal achieved, if known.
* **Assessment of Donor Conversion** (`donor_conversion_rate`, select_one, Optional): Select the effectiveness of donor conversion:
	+ Excellent
	+ Good
	+ Average
	+ Poor
* **Were There Repeat Donors Present** (`repeat_donor_interest`, select_one, Optional): Choose if previous donors attended again:
	+ Yes, Many
	+ Some
	+ Very Few
	+ None
* **Overall Engagement Level of Attendees** (`engagement_level`, select_one, Required): Select the overall engagement level:
	+ Very High
	+ High
	+ Moderate
	+ Low
* **Did Attendees Connect with the Mission** (`mission_connection`, select_one, Required): Choose if attendees understood the cause:
	+ Very Strong
	+ Strong
	+ Moderate
	+ Weak
* **Rate Overall Event Effectiveness** (`event_effectiveness`, select_one, Required): Select the overall effectiveness of the event:
	+ Excellent
	+ Very Good
	+ Good
	+ Average
	+ Poor
* **Assessment of Return on Investment** (`return_on_investment`, select_one, Required): Choose the return on investment:
	+ Excellent ROI
	+ Good ROI
	+ Adequate ROI
	+ Poor ROI
* **Should We Repeat This Event** (`repeat_event`, select_one, Required): Choose if you'd recommend repeating the event:
	+ Definitely Yes
	+ Probably Yes
	+ Maybe
	+ Probably No
	+ Definitely No
* **Suggestions for Improvement** (`improvements_suggestions`, text, Optional): Provide any suggestions for improving future events.

## Tips
* Please answer questions honestly and provide specific examples when possible.
* If you have concerns or issues with the form, feel free to provide feedback in the "Suggestions for Improvement" field.
