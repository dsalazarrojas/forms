# Event Date Preference Survey - Help Guide
## Purpose
The Event Date Preference Survey is a tool designed to collect information about participants' preferred dates and times for an event.

## How To Complete This Form
To complete this form, follow these steps:

1. Select your preferred dates for the event from the list provided.
2. Choose your preferred start and end times for the event.
3. Indicate any additional notes or comments you have regarding the event.
4. Select any additional participant preferences, such as dates or times.

## Field-by-Field Explanation

* **Event Date Preference Survey Page 1**: This is the introductory page of the form.
* **Participant Preferences**: Select all the dates and times you prefer for the event.
* **Event Dates**: Choose one of the available dates for the event.
* **Preferred Date**: Select a preferred date for the event.
* **Start Time**: Choose the start time for the event.
* **End Time**: Choose the end time for the event.
* **Notes**: Provide any additional comments or notes regarding the event.
* **Event Time**: Choose the time for the event.
* **Preferred Time**: Select a preferred time for the event.
* **Participant Preferences 2-10**: Select any additional participant preferences for the event.
