# Meeting Content Suggestions Survey - Help Guide
## Purpose
This form is meant to collect feedback and suggestions from users about meetings. It helps meeting organizers track and follow up on action items and meeting notes.

## How To Complete This Form

To fill out this form, please make sure to:

*   Fill out all required fields accurately and completely.
*   Use the correct field types (e.g., date for dates, email for email addresses).
*   Make sure to provide feedback or suggestions in the text fields.

## Field-by-Field Explanation

*   **First Name** (text) (required/optional: False): This field is for your name.
*   **Last Name** (text) (required/optional: False): This field is for your surname.
*   **Email** (email) (required/optional: False): This field is for your email address.
*   **Suggestion** (text) (required/optional: False): This field is for any feedback or suggestions about the meeting.
*   **Category** (select_one) (required/optional: False): This field is a selection of categories. Please select one category that best describes your feedback.
*   **Sub Category** (select_multiple) (required/optional: False): This field is a selection of sub categories. You can select multiple options that best describe your feedback.
*   **Date** (date) (required/optional: False): This field is for the date of the meeting.
*   **Time** (time) (required/optional: False): This field is for the time of the meeting.
*   **Meeting ID** (number) (required/optional: False): This field is for the meeting identifier.
*   **Meeting Date** (date) (required/optional: False): This field is for the meeting date.
*   **Meeting Time** (time) (required/optional: False): This field is for the meeting time.
*   **Attendees** (select_multiple) (required/optional: False): This field is a selection of attendees. You can select multiple attendees that were present.
*   **Rating** (number) (required/optional: False): This field is for a rating of the meeting.
*   **Comment** (text) (required/optional: False): This field is for any optional comment about the meeting.
*   **Note** (note) (required/optional: False): This field is for taking notes about the meeting.
*   **Follow up** (text) (required/optional: False): This field is for suggesting a follow up on the meeting.
*   **Follow up Date** (date) (required/optional: False): This field is for the date of the follow up.
*   **Follow up Time** (time) (required/optional: False): This field is for the time of the follow up.
*   **Email Follow up** (text) (required/optional: False): This field is for suggesting to follow up via email.
*   **Phone Number Follow up** (text) (required/optional: False): This field is for suggesting to follow up via phone number.
*   **Meeting Notes** (note) (required/optional: False): This field is for taking notes about the meeting.
*   **Action Items** (select_one) (required/optional: False): This field is a selection of action items. Please select one that best describes what you need to follow up on.
*   **Completed** (select_one) (required/optional: False): This field is a selection of whether the action item is completed.
*   **Completed Date** (date) (required/optional: False): This field is for the date the action item is completed.
*   **Comments** (text) (required/optional: False): This field is for any comments about the action item.

**Tips**

*   Please make sure to fill out all required fields accurately and completely.
*   Use the correct field types (e.g., date for dates, email for email addresses).
*   Be as specific as possible when providing feedback or suggestions.
*   If you're unsure about a field, please reach out to the meeting organizer for clarification.
