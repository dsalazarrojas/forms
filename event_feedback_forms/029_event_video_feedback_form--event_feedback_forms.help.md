# Event Video Feedback Form - Help Guide
## Purpose
This form is used to collect feedback from individuals who have attended an event. It is meant to be filled out by one person per submission. The feedback form is split into two parts: the first part is for general feedback and the second part is for rating and additional information.

## How To Complete This Form
- Fill out the form completely before submitting it.
- Make sure to select the "Send notification" options that you prefer to receive.
- If you wish to receive email or phone notifications, please select 'Yes' in the corresponding field.
- Make sure to proofread your feedback before submitting it.

## Field-by-Field Explanation
* **Event Title**: This is the title of the event that we are providing feedback for.
* **Name**: Provide your name, so we can address the feedback to you.
* **Email**: Enter your email address, so we can contact you if needed.
* **Feedback**: Enter your general feedback for the event.
* **Rating**: Rate the event from 1 to 5, with 1 being the lowest and 5 being the highest.
* **Comment**: Enter any additional comments you might have.
* **Email notification**: Select 'Yes' if you want to receive email notifications.
* **Phone notification**: Select 'Yes' if you want to receive phone notifications.
* **Send notification**: Select 'Yes' if you want to send notification to the event organizer.
* **Notification method**: Select how you prefer to receive notification, either by email, phone, or both.
* **Email subject**: This is the subject line of the email that will be sent to you with any notification.
* **Email body**: This is a text field for you to enter any additional information about the email that will be sent to you with any notification.
* **Name 2/Phone 2/...**: These fields are meant for second/third/... individual to fill out, if applicable.
* **Rating 2/...**: Rate the event from 1 to 5, with 1 being the lowest and 5 being the highest.
* **Comment 2/...**: Enter any additional comments you might have for the second/third/... individual.
* **Email notification 2/...**: Select 'Yes' if you want to receive email notifications for the second/third/... individual.
* **Phone notification 2/...**: Select 'Yes' if you want to receive phone notifications for the second/third/... individual.
* **Send notification 2/...**: Select 'Yes' if you want to send notification to the second/third/... individual.
* **Notification method 2/...**: Select how the second/third/... individual wants to receive notifications, either by email, phone, or both.
* **Email subject 2/...**: This is the subject line of the email that will be sent to the second/third/... individual with any notification.
* **Email body 2/...**: This is a text field for the second/third/... individual to enter any additional information about the email that will be sent to them with any notification.
* **Name 3/Phone 3/...**: These fields are meant for third/... individual to fill out, if applicable.
* **Rating 3/...**: Rate the event from 1 to 5, with 1 being the lowest and 5 being the highest.
* **Comment 3/...**: Enter any additional comments you might have for the third/... individual.
* **Email notification 3/...**: Select 'Yes' if you want to receive email notifications for the third/... individual.
* **Phone notification 3/...**: Select 'Yes' if you want to receive phone notifications for the third/... individual.
* **Send notification 3/...**: Select 'Yes' if you want to send notification to the third/... individual.
* **Notification method 3/...**: Select how the third/... individual wants to receive notifications, either by email, phone, or both.
* **Email subject 3/...**: This is the subject line of the email that will be sent to the third/... individual with any notification.
* **Email body 3/...**: This is a text field for the third/... individual to enter any additional information about the email that will be sent to them with any notification.
