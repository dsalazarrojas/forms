# Event Equipment Vendor Satisfaction Survey - Help Guide
## Purpose
This form aims to collect feedback from event vendors on the equipment provided for events, helping us to understand their satisfaction and identify areas for improvement.

## How To Complete This Form
1. Make sure you are the correct person to complete this form. If you are not the event vendor, please do not fill out this form.
2. Fill out the form with accurate and honest feedback.
3. Please ensure that all required fields are filled out.

## Field-by-Field Explanation
* **Name** (`name`, text, optional): Please enter your name as the event vendor.
* **Event ID** (`event_id`, number, optional): If you know the event ID, please enter it here. This is not required but helps us track the event more easily.
* **Equipment ID** (`equipment_id`, number, optional): If you know the equipment ID, please enter it here. This is not required but helps us track the equipment more easily.
* **Vendor Name** (`vendor_name`, text, optional): Please enter your company or vendor name.
* **Rating** (`rating`, number, optional): Please rate your overall satisfaction with the equipment on a scale of 1-5.
* **Comments** (`comments`, text, optional): Please provide any comments or suggestions you have about the equipment.
* **Vendor** (`vendor_rating`, select_one, optional): Please select how you rate your satisfaction with the vendor:
	+ Excellent
	+ Good
	+ Fair
	+ Poor
	+ Very Poor
* **Event Date** (`event_date`, date, optional): If you know the date of the event, please enter it here. This is not required but helps us track the event more easily.
* **Event Time** (`event_time`, time, optional): If you know the time of the event, please enter it here. This is not required but helps us track the event more easily.
* **Contact Name** (`contact_name`, text, optional): If you have a contact person's name, please enter it here.
* **Contact Email** (`contact_email`, email, optional): If you have a contact email, please enter it here.
* **Contact Phone** (`contact_phone`, text, optional): If you have a contact phone number, please enter it here.

## Tips
* Please be honest and provide accurate feedback to help us improve our services.
* If you have any questions or concerns, please contact us at [your contact email or phone number].
