# observer_feedback_sign_up - Help Guide
## Purpose
This guide will walk you through the process of completing the observer feedback sign-up form for events.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the title of the event you are providing feedback on.
2. Enter your first name and last name.
3. Enter your email address.
4. Enter your phone number (optional).
5. Add any comments or feedback about the event.
6. Choose a category that best describes the event (optional).
7. Select a date and time (if applicable).
8. Rate your overall experience (optional).
9. Indicate if you agree or disagree with certain statements (optional).
10. Confirm the event date and time (if applicable).
11. Choose a tool that was assigned for the event (if applicable).
12. Enter the location of the event (if applicable).
13. Enter additional event titles (if applicable).

## Field-by-Field Explanation

* **Event Title** (`event_title`, text, required): Enter the title of the event you are providing feedback on. This is a required field.
* **First name** (`first_name`, text, required): Enter your first name. This is a required field.
* **Last name** (`last_name`, text, required): Enter your last name. This is a required field.
* **Email** (`email`, email, optional): Enter your email address.
* **Phone number** (`phone_number`, text, optional): Enter your phone number (if provided).
* **Comments** (`comments`, note, optional): Add any comments or feedback about the event.
* **Category** (`category`, select_one, optional): Choose a category that best describes the event (if applicable).
* **Date** (`date`, date, optional): Select a date the event took place (if applicable).
* **Time** (`time`, time, optional): Select a time the event took place (if applicable).
* **Rating** (`rating`, number, optional): Rate your overall experience (if applicable).
* **Agree** (`agree`, select_multiple, optional): Indicate if you agree or disagree with certain statements (if applicable).
* **Comments Agree** (`comments_agree`, note, optional): Add comments about why you agree or disagree (if applicable).
* **Event Date** (`event_date`, date, optional): Select a date the event took place (if applicable).
* **Event Time** (`event_time`, time, optional): Select a time the event took place (if applicable).
* **Assigned Tool** (`assigned_tool`, select_one, optional): If a tool was assigned for the event, choose one (if applicable).
* **Event Location** (`event_location`, text, optional): Enter the location of the event (if applicable).
* **Event Title 2-10** (`event_title_2`, `event_title_3`, `event_title_4`, `event_title_5`, `event_title_6`, `event_title_7`, `event_title_8`, `event_title_9`, `event_title_10`, text, optional): Enter additional event titles (if applicable).
