# Program Survey - Help Guide
## Purpose

The Program Survey form is designed to collect feedback and ratings on programs and events within the organization. This form helps to evaluate the effectiveness and quality of the programs, providing valuable insights for improvement and planning.

## How To Complete This Form

To complete the Program Survey form, follow these steps:

1. Enter the title of the program or event.
2. Select the category for the program or event (Yes/No).
3. Provide a short description of the program or event.
4. Choose a rating for the program or event, with ratings ranging from 1 to 5.
5. Optionally, add any additional comments about the program or event.

## Field-by-Field Explanation

* **Program Survey Title** (`program_survey_form_title`, `text`, required: false): The title of the program or event. Enter a descriptive and concise name that accurately represents the program.
* **Event Category** (`program_survey_form_category`, `select_one`, required: false): Select whether the program or event is a "Yes" or "No", indicating whether it is applicable or not.
* **Program Description** (`program_survey_form_description`, `text`, required: false): A short description of the program or event. This field should provide a brief overview of the program's purpose and content.
* **Rating (1-5)** (`program_survey_form_rating`, `select_one`, required: false): Choose a rating for the program or event, with ratings from 1 to 5. This rating system is subjective and based on how well the program met your expectations.
* **Comment** (`program_survey_form_comment`, `text`, required: false): Optionally, add any additional comments or feedback about the program or event.
