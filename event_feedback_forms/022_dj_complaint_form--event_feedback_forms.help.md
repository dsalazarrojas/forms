# DJ Complaint Form - Help Guide
## Purpose
This form is used to provide feedback on the performance of a DJ at an event. It helps to identify areas of improvement and track complaints or issues that need to be addressed.

## How To Complete This Form
To complete this form, follow these steps:

* Select "Yes" or "No" for each of the "prophets" fields (1, 5, 7, 10).
* Enter the date of the event in the "event date" field (2).
* Provide a detailed description of the complaint in the "complaint" field (3).
* Enter your email address in the "email" field (4) if you wish to be contacted for further discussion.
* Select the "assigned to" field (8) to indicate whether the complaint is assigned to a specific person or not.
* Select the "category" field (9) to identify the category of the complaint.
* Select "Yes" or "No" for the "assigned tool" field (12) to indicate whether a tool is assigned to address the complaint.
* Optionally, enter your phone number and a comment in the fields "phone" (5) and "comment" (6) if you wish to provide additional information.

## Field-by-Field Explanation
* **Prophets** (1): Select "Yes" if you were able to enjoy the performance, "No" if not.
* **Event Date** (2): Enter the date of the event where you experienced the issue.
* **Complaint** (3): Describe the specific issue you experienced with the DJ's performance.
* **Email** (4): Optional: Enter your email address if you would like to be contacted for further discussion.
* **Phone** (5): Optional: Enter your phone number if you would like to be contacted directly.
* **Comment** (6): Optional: Provide any additional comments or information about the complaint.
* **Prophets** (7): Select "Yes" if you were able to enjoy the performance, "No" if not.
* **Assigned to** (8): Select "Yes" if you would like the complaint to be assigned to a specific person, "No" if not.
* **Category** (9): Select "Yes" if the complaint is related to a specific category, "No" if not.
* **Prophets** (10): Select "Yes" if you were able to enjoy the performance, "No" if not.
* **Assigned Tool** (12): Select "Yes" if a tool is assigned to address the complaint, "No" if not.
