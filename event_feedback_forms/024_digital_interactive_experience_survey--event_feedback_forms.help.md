# Digital Interactive Experience Survey - Help Guide
## Purpose
This survey is designed to collect feedback and ratings from participants of digital interactive events such as webinars, workshops, conferences, and training sessions. The survey helps us understand the overall experience of the event, gather feedback, and identify areas for improvement.

## How To Complete This Form
To complete this form, follow these steps:

1. Start by reviewing the questions and fields below.
2. Fill out each field according to the instructions provided.
3. Make sure to provide as much detail as possible in the "feedback" and "additional comments" fields.
4. For the "rating" and "rating scale" fields, select the corresponding rating or scale that best represents your experience.
5. If you have any suggestions or comments, please type them in the "suggestion" field.
6. Finally, click "submit" to submit your survey.

## Field-by-Field Explanation

* **Introduction**: This is a short text field where you can provide a brief introduction to your feedback or any comments you'd like to share about your experience. (Text, optional)
* **Overall Experience**: Please rate your overall experience from 1 to 5. (Number, required)
* **Event Name**: Please enter the name of the event you attended. (Text, required)
* **Organizer**: Please enter the name of the event's organizer. (Text, required)
* **Event Date**: Please enter the date of the event you attended. (Date, required)
* **Time Slot**: Please select the time slot you attended the event. (Time, required)
* **Event Location**: This is an optional field where you can enter the location of the event. (Text, optional)
* **Participant Name**: Please enter your name. (Text, required)
* **Participant Email**: Please enter your email address. (Email, required)
* **Feedback**: Please provide a detailed feedback about your experience. (Text, required)
* **Rating**: Please rate your experience from 1 to 5. (Select One, required)
* **Suggestion**: If you have any suggestions or comments, please type them here. (Text, optional)
* **Additional Comments**: This is an optional field for any additional comments or thoughts. (Note, optional)
* **Contact Us**: Please enter your email address if you'd like to be contacted back. (Email, required)
* **Social Media**: This is an optional field for social media information. (Text, optional)
* **Event Type**: Please select the type of event you attended. (Select One, required)
* **Follow Up**: Please select whether you'd like to be contacted for follow up. (Select Multiple, optional)
* **Follow Up Reasons**: If you selected "Follow Up", please enter why you'd like to be contacted. (Text, optional)
* **Follow Up Message**: This is an optional field for a follow up message. (Text, optional)
* **Comments**: Please provide any additional comments about your experience. (Text, required)
* **Rating Scale**: Please select your rating scale from 1-10. (Select Multiple, required)
* **Rating Scale Reasons**: If you selected a rating scale, please provide a reason for your selection. (Text, optional)
* **Rating Scale Comments**: This is an optional field for additional comments about your rating scale selection. (Text, optional)
* **Participant Organizer**: This is an optional field for any information about the participant's organizer. (Text, optional)
* **Submission**: This is a text field for any final comments or thoughts. (Text, required)

Note: This help guide is based on the provided YAML fields and has been formatted to be concrete, concise, and practical. If a field label is unclear or weak, an effort has been made to explain the best-effort intent without inventing unsupported business logic.
