# OB GYN Event Attendance Survey - Help Guide
## Purpose
This form is used to gather feedback about the OB GYN events that you have attended. Your responses will help us understand your experience and improve future events.

## How To Complete This Form
To complete this form, simply follow these steps:

* Review the form carefully and fill out each field as instructed.
* Make sure to provide your email address so we can contact you if we need more information.
* Answer each question honestly and accurately.
* If you have any comments or suggestions, please use the "Comments" field.

## Field-by-Field Explanation

* **Email (Your email for contact)** (`email`, `email`, required/optional): This field is required so we can contact you if we need more information about your responses. Please enter a valid email address that you check regularly.
* **Phone Number** (`phone_number`, `text`, optional): This field is optional but recommended if you would like us to contact you directly.
* **Session Attendance 2** (`session_attendance_2`, `note`, optional): If you want to provide feedback about the second session you attended, use this field.
* **Comments** (`comments`, `note`, optional): If you have any comments, suggestions, or concerns, please share them here.

Note: Some fields on this form are optional and not required for submission. You can skip these fields if you do not want to provide additional information.

Tips: Please make sure to proofread your responses before submitting the form. If you are unsure about any field, ask for clarification before proceeding.
