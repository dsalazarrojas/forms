# Student Transfer Fair Feedback - Help Guide
## Purpose

This form is designed to collect feedback from students who attended a transfer fair event. The feedback collected will help us improve future events and provide better experience for students. 

## How To Complete This Form

1. Fill in the Event Name of the fair you attended.
2. If you did not attend, please check the box to indicate that you did not attend.
3. Fill in the date and time of the event, if you attended.
4. Rate your overall experience at the event (if any).
5. Add any feedback you may have about the event.
6. If you did not attend, check the box to indicate that.
7. If you did not attend, fill in the reason why you did not attend.
8. If you attended, fill in your email address if you gave it to the event organizer.
9. If you attended, fill in the phone number if you gave it to the event organizer.
10. Add any additional comments about the event.
11. If you attended, fill in the email of the event organizer, if you know it.
12. If you attended, fill in the email of the speaker, if you know it.
13. Add any comments to the event organizer.
14. If you attended, fill in the email of the event speaker, if you know it.
15. Add any comments to the speaker.

## Field-by-Field Explanation

* **Event Name** (`event_name`, text, optional): Fill in the name of the fair you attended.
* **Attended** (`attended`, select_one, optional): Check if you attended the event.
* **Date** (`date`, date, optional): Fill in the date of the event, if you attended.
* **Time** (`time`, time, optional): Fill in the time of the event, if you attended.
* **Overall Experience** (`overall_experience`, number, optional): Rate your overall experience at the event.
* **Feedback** (`feedback`, note, optional): Add any feedback you may have about the event.
* **Attended Fair** (`attended_fair`, select_multiple, optional): If you did not attend, select all the reasons why you did not attend.
* **Rating** (`rating`, number, optional): Rate your overall experience at the event.
* **Recommend** (`recommend`, select_one, optional): Check if you would recommend the event to others.
* **Email** (`email`, email, optional): Fill in your email address if you gave it to the event organizer.
* **Phone** (`phone`, text, optional): Fill in your phone number if you gave it to the event organizer.
* **Comments** (`comments`, note, optional): Add any additional comments about the event.
* **Email College** (`email_college`, email, optional): Fill in your college's email address if you know it.
* **Email Event** (`email_event`, email, optional): Fill in the email address of the event, if you know it.
* **Event Name Other** (`event_name_other`, text, optional): Fill in any other name of the event, if you attended.
* **Event Location** (`event_location`, text, optional): Fill in the location of the event, if you attended.
* **Event Time** (`event_time`, time, optional): Fill in the time of the event, if you attended.
* **Event Date** (`event_date`, date, optional): Fill in the date of the event, if you attended.
* **Event Organizer** (`event_organizer`, text, optional): Fill in the name of the event organizer, if you know it.
* **Event Speaker** (`event_speaker`, text, optional): Fill in the name of the event speaker, if you know it.
* **Comments** (`comments`, note, optional): Add any comments to the event organizer.
* **Email Event Organizer** (`email_event_organizer`, email, optional): Fill in the email address of the event organizer, if you know it.
* **Email Speaker** (`email_speaker`, email, optional): Fill in the email address of the speaker, if you know it.
* **Comments Organizer** (`comments_organizer`, note, optional): Add any comments to the speaker.
