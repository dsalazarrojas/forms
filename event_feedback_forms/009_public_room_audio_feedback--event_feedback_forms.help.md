# public_room_audio_feedback - Help Guide
## Purpose
This form is designed to gather feedback from event attendees on the public room audio quality during the event. Your responses will help us improve the sound quality for future events.

## How To Complete This Form
1. Please fill out all the required fields.
2. Be as specific and detailed as possible in your feedback, especially when answering the sound quality questions.
3. Make sure to select the correct options for "Sound Quality" and "Submitted By".

## Field-by-Field Explanation

* **Event Name** (Event Name, text, required): Enter the name of the event you attended.
* **Room Name** (Room Name, text, required): Enter the name of the public room where the event was held.
* **Sound Quality** (Sound Quality, select_one, required): Rate the sound quality of the event as:
	+ Very Good
	+ Good
	+ Fair
	+ Bad
* **Feedback** (Feedback, text, optional): Provide any specific feedback you have about the sound quality, including what could be improved or what was done well.
* **Email** (Email, email, optional): Enter your email address if you'd like to receive a follow-up from us.
* **Phone** (Phone, text, optional): Enter your phone number if you'd like to receive a call from us.
* **Date** (Date, date, required): Enter the date of the event you attended.
* **Time** (Time, time, required): Enter the time of the event you attended.
* **Note** (Note, note, optional): If you have any additional comments or notes about the event, you can add them here.
* **Submitted By** (Submitted By, select_one, required): Select who you are (or should be) as the person submitting this feedback:
	+ Event Staff
	+ Audience
	+ Venue Team
