# Freedom Journey Feedback Form - Help Guide
## Purpose
The "Freedom Journey Feedback Form" is used to collect feedback from program participants, which will help improve the Freedom Journey program.

## How To Complete This Form
1. Fill out the form completely and accurately.
2. For each field, provide your honest and detailed answers.
3. Make sure to provide a specific example or explanation to support your answers where possible.
4. Review your answers carefully before submitting the form.

## Field-by-Field Explanation

* **Participant Satisfaction** (id: 1): This field asks about your satisfaction with the Freedom Journey program. Answer on a scale from 1 to 5.
* **Recommendations** (id: 2): This field is for any recommendations you have for the Freedom Journey program. Answer "Yes" if you have any recommendations, and "No" otherwise.
* **Participant Sentiment** (id: 3): This field asks about your sentiment towards the program. Answer "Yes" if you have a positive sentiment, and "No" otherwise.
* **Facilitator Support** (id: 4): This field asks about the support you received from the facilitators. Answer on a scale from 1 to 5.
* **Program Organizers** (id: 5): This field asks about the support you received from the program organizers. Answer "Yes" if you have any, and "No" otherwise.
* **Date** (id: 6): This field asks for the date you participated in the program. Use the format "MM/DD/YYYY".
* **Time** (id: 7): This field asks for the time you participated in the program. Use the format "HH:MM AM/PM".
* **Email** (id: 8): This field is for your email address. If you do not have an email address, answer "None".
* **Phone** (id: 9): This field is for your phone number. If you do not have a phone number, answer "None".
* **Satisfaction Level** (id: 10): This field asks about your satisfaction level with the Freedom Journey program. Answer "Satisfied" or "Dissatisfied".
* **Additional Comments** (id: 11): This field is for any additional comments or feedback about the program.
* **Participant Satisfaction 2** (id: 12): This is a second field asking about your satisfaction with the program (same as id: 1).
* **Participant Sentiment 2** (id: 13): This is a second field asking about your sentiment towards the program (same as id: 3).
* **Facilitator Support 2** (id: 14): This is a second field asking about the support you received from the facilitators (same as id: 4).
* **Program Organizers 2** (id: 15): This is a second field asking about the support you received from the program organizers (same as id: 5).
* **Date 2** (id: 16): This is a second field asking for the date you participated in the program (same as id: 6).
* **Time 2** (id: 17): This is a second field asking for the time you participated in the program (same as id: 7).
* **Email 2** (id: 18): This is a second field for your email address (same as id: 8).
* **Phone 2** (id: 19): This is a second field for your phone number (same as id: 9).
* **Satisfaction Level 2** (id: 20): This is a second field asking about your satisfaction level with the Freedom Journey program (same as id: 10).
* **Additional Comments 2** (id: 21): This is a second field for any additional comments or feedback about the program (same as id: 11).
* **Program ID** (id: 22): This field asks for the program ID of the Freedom Journey program you participated in.
* **Program Name** (id: 23): This field asks for the name of the Freedom Journey program you participated in.
* **User ID** (id: 24): This field asks for the ID of the user who participated in the program.
* **User Name** (id: 25): This field asks for the name of the user who participated in the program.
