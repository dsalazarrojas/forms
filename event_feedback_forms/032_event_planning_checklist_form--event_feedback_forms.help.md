# Event Planning Checklist Form - Help Guide

## Purpose
The Event Planning Checklist Form is a comprehensive tool designed to guide event planners through the planning process, ensuring that all essential tasks and details are covered to deliver successful events.

## How To Complete This Form
To fill out this form, follow these steps:

1. Fill in the **Event Planning Checklist Form Title** field with a brief description of the event.
2. Select the **Category** that best fits the event's nature (Event Feedback Forms or Event Planning Forms).
3. Add a detailed **Description** of the event, including its purpose, scope, and any specific requirements.
4. Choose the **Category** (Event Feedback Forms or Event Planning Forms) for the event again, as this will help with organization and filtering.
5. Specify the **Output File Name** where the event's details will be saved.
6. Select the **Assigned Tool** responsible for the event's execution (chatjimmy or chatjohn).
7. Enter your **Creator Name** (your name) to acknowledge your role in creating the event.
8. Add your **Creator Email** to ensure that you can be reached in case of any issues or follow-up questions.
9. Enter your **Creator Phone Number** to facilitate quick communication.

## Field-by-Field Explanation
- **Event Planning Checklist Form Title**: A brief description of the event.
- **Category**: Select the type of form this event belongs to for easier categorization and retrieval (Event Feedback Forms or Event Planning Forms).
  • **Event Feedback Forms**: For events that are feedback-focused.
  • **Event Planning Forms**: For events that require planning and execution.
- **Description**: A detailed explanation of the event, its objectives, and any specific requirements.
  • Provide details about the event, such as date, location, and expected participants.
- **Category** (second instance): Same as the first Category field for consistency and organization.
- **Output File Name**: Specify the file name where the event's details will be saved.
  • This will be used for file naming conventions.
- **Assigned Tool**: Choose the tool or resource responsible for executing the event (chatjimmy or chatjohn).
  • This will help in resource allocation and tracking.
- **Creator Name**: Enter your name to acknowledge your role in creating the event.
  • This is for internal record-keeping and accountability.
- **Creator Email**: Enter your email to ensure that you can be reached for any follow-up or issues.
  • This facilitates internal communication and coordination.
- **Creator Phone Number**: Enter your phone number for quick and easy contact.
  • This is for rapid communication and response in case of emergencies.
