# Storyteller Event Feedback - Help Guide
## Purpose
The Storyteller Event Feedback form is designed to gather feedback from event participants about their experiences. This information is used to improve future events and ensure attendees have a positive experience.

## How To Complete This Form
To complete this form, follow these steps:
1. Select an option for "Event Feedback" from the dropdown list.
2. Rate the event using the number scale provided.
3. If desired, add a comment about your event rating.
4. Choose attendees who liked or disliked the event (optional).

## Field-by-Field Explanation
* **Event Feedback** (`event_feedback_form`, select_one, required): Select one of the provided options to share your feedback about the event.
* **Event Rating** (`event_rating`, number, required): Rate the event using the number scale provided. Please choose a number between 1 and 5.
* **Event Rating Comment** (`rating_comment`, note, optional): Provide additional comments about your event rating (if desired).
* **Attendees Who Liked** (`event_likers`, select_multiple, optional): Select attendees who enjoyed the event (optional).
* **Attendees Who Disliked** (`event_dislikers`, select_multiple, optional): Select attendees who did not enjoy the event (optional).
