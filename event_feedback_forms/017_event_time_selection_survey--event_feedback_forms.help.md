# Event Time Selection Survey - Help Guide
## Purpose

The Event Time Selection Survey is a form designed to gather information about the timing of events from attendees. The feedback collected will help us improve the scheduling and timing of future events.

## How To Complete This Form

1. The form consists of multiple pages. Please navigate through the pages and fill out the fields as required.
2. Start by selecting the time of your event on the "Select Time" page.
3. Next, choose the start and end dates of your event on the "Select Start Date" and "Select End Date" pages.
4. Then, select the duration of your event on the "Select Event Duration" page.
5. On the "Select Event Location" page, choose one or multiple locations where your event took place.
6. If you have additional comments or information about your event, you can enter it on the "Select Event Comments" page. Note that there are multiple "Select Event Comments" pages, and you can fill out as many as you need.
7. Finally, review your answers and submit the form.

## Field-by-Field Explanation

* **Select Time** (Select Time): Choose the time of your event from the options provided.
* **Select Start Date** (Select Start Date): Select the start date of your event.
* **Select End Date** (Select End Date): Select the end date of your event.
* **Select Event Duration** (Select Event Duration): Choose the duration of your event.
* **Select Event Location** (Select Event Location): Choose one or multiple locations where your event took place.
* **Select Event Time Format** (Select Event Time Format): Choose the time format of your event (AM/PM or 24hr).
* **Additional Information** (Additional Information): Enter any additional information about your event.
* **Select Event Phone** (Select Event Phone): Enter your event phone number.
* **Select Event Email** (Select Event Email): Enter your event email.
* **Select Event Comments** (Select Event Comments): Enter your event comments.
* **Select Event Comments 2-12** (Select Event Comments 2-12): Enter any additional comments or information about your event.
