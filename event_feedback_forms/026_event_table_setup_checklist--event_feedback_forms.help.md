# Event Table Setup Checklist - Help Guide
## Purpose
This form helps event organizers ensure that all necessary information for the event table setup is collected and complete.

## How To Complete This Form
To complete this form, follow these steps:

1. Review the event's specific requirements and ensure you have access to all necessary information.
2. Answer the questions about event planners, event table details, event setup dates and times, setup locations, event table setup responsibilities and tasks, and event table setup notes.
3. Indicate if the event table setup checklist is complete or not.

## Field-by-Field Explanation

* **Event Planners** (`event_planners`, `select_multiple`, required: false): 
  This field asks about the presence of event planners. Choose all the options that apply to your event, such as 'Yes', 'No', or 'Other' (if not listed).

* **Event Table Details** (`event_table_details`, `select_one`, required: false): 
  Select the number of event table details that apply to your event, such as '1', '2', or '3'.

* **Event Setup Dates** (`event_setup_dates`, `date`, required: false): 
  Enter the dates for the event setup, in the standard date format (e.g., MM/DD/YYYY).

* **Event Setup Times** (`event_setup_times`, `time`, required: false): 
  Enter the times for the event setup, in the standard time format (e.g., HH:MM AM/PM).

* **Setup Locations** (`setup_locations`, `select_multiple`, required: false): 
  Choose all the locations where the event setup will take place, such as 'Yes' or 'No'.

* **Event Table Setup Responsibilities** (`event_table_setup_responsibilities`, `select_one`, required: false): 
  Select the number of responsibilities that apply to your event, such as '1', '2', or '3'.

* **Event Setup Tasks** (`event_setup_tasks`, `text`, required: false): 
  Provide a list of tasks that need to be completed for the event setup.

* **Event Table Setup Notes** (`event_table_setup_notes`, `note`, required: false): 
  Add any additional notes about the event table setup.

* **Event Table Setup Checklist Complete** (`event_table_setup_checklist_complete`, `select_one`, required: false): 
  Indicate if the event table setup checklist is complete or not, selecting 'True' or 'False'.
