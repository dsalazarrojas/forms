# cultural_event_scrapbook_submission - Help Guide
## Purpose
The cultural_event_scrapbook_submission form is designed to collect feedback and information about cultural events. It helps event organizers gather valuable insights to improve future events.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the form title field to describe the event you are submitting feedback for.
2. If applicable, provide the event date and time using the date and time fields. This will help event organizers track the event's schedule.
3. Enter the event location and provide a brief description of the location if necessary.
4. Share your story about the event in the "Story" field.
5. Upload photos of the event to help event organizers get a better sense of what happened.
6. Provide your reflections about the event in the "Reflections" field.
7. Fill out the "Submitted By" field with your name.
8. Finally, enter any additional comments you have about the event.

## Field-by-Field Explanation

* **Form Title** (`form_title`, text, required): Enter a brief title to describe the event you are submitting feedback for.
* **Event Date** (`event_date`, date, optional): If you have the event date, please enter it in the format yyyy-mm-dd.
* **Event Time** (`event_time`, time, optional): If you have the event time, please enter it in the format hh:mm AM/PM.
* **Event Location** (`event_location`, text, required): Enter the name of the event location.
* **Event Location Description** (`event_location_description`, text, optional): If necessary, provide a brief description of the event location.
* **Event Description** (`event_description`, text, optional): Enter a brief description of the event.
* **Story** (`story`, text, optional): Share your story about the event.
* **Photos** (`photos`, text, optional): Upload photos of the event to help event organizers get a better sense of what happened.
* **Reflections** (`reflections`, text, optional): Provide your reflections about the event.
* **Submitted By** (`submitted_by`, text, required): Enter your name to indicate who submitted the feedback.
* **Comments** (`comments`, text, required): Enter any additional comments you have about the event.

## Tips

* Be as detailed and honest as possible when filling out the form.
* Use clear and concise language to help event organizers understand your feedback.
* If you have any photos or stories, please upload them to make your feedback more engaging.
* Remember to fill out all required fields, marked as such in the form.
* If you have any additional comments, please enter them in the "Comments" field.
