# Industry Expo Best Project Voting Form - Help Guide
## Purpose
This form is used to collect ratings and feedback for projects showcased at the Industry Expo. The form is designed to be completed by attendees to rate and provide feedback on each project they visited.

## How To Complete This Form
1. Fill in the project_id field with the ID of the project you are rating.
2. Enter the name of the project in the project_name field.
3. Select a rating for each of the project attributes (1-5 or Good/Fair).
4. Click the "Submit" button to submit your ratings and feedback.
