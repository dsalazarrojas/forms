# facilitator_evaluation_form - Help Guide
## Purpose
The facilitator_evaluation_form is a tool to help evaluate the effectiveness of a facilitator in an event or meeting. The form is designed to gather feedback from participants on the facilitator's performance, communication, and overall experience.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the page number to navigate through the form's 20 pages.
2. For each page, you'll find text fields where you can provide your feedback.
3. Type your answers in the designated boxes.
4. Make sure to fill out all fields on each page.
5. Once you've completed all pages, submit the form.

## Field-by-Field Explanation

* **Second Page** (`facilitator_evaluation_form_second_page`): What were your overall expectations from the event or meeting?
* **Third Page** (`facilitator_evaluation_form_third_page`): How would you rate the facilitator's communication style? (Scale: 1-5)
* **Fourth Page** (`facilitator_evaluation_form_fourth_page`): Were there any moments where you felt lost or confused during the event or meeting?
* **Fifth Page** (`facilitator_evaluation_form_fifth_page`): How would you rate the facilitator's ability to manage time effectively? (Scale: 1-5)
* **Sixth Page** (`facilitator_evaluation_form_sixth_page`): Were there any issues with the event or meeting facilities?
