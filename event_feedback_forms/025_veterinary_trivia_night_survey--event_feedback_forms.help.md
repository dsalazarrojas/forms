# Veterinary Trivia Night Survey - Help Guide
## Purpose

This form is designed to gather feedback from attendees of the Veterinary Trivia Night Survey. Please take a few minutes to provide your honest feedback, and help us create an even better experience for future events.

## How To Complete This Form

1. Read the instructions carefully and answer each question honestly.
2. Fill out each field as accurately as possible.
3. Make sure to enter your email address correctly.
4. Use the 24-hour time format for times (e.g., 21:00 or 09:00).
5. Select all applicable options for each select multiple field.

## Field-by-Field Explanation

* **Trivia Question** (`trivia_question`, text, optional): This is where you can provide any comments or suggestions about the trivia questions. Please be as specific as possible with your feedback.
* **Question Type** (`question_type`, select_one, optional): Please select the type of question that best describes the trivia question you were asked. Choose from: trivia, riddle, or puzzle.
* **Event Rating** (`rating`, number, optional): If you attended the event, rate it from 1 to 5, where 1 is poor and 5 is excellent.
* **Improvement Insights** (`improvement_insights`, text, optional): If you have any suggestions or comments about how we can improve the event, please provide them here.
* **Email** (`email`, email, optional): Enter your email address so we can follow up with you if needed.
* **Phone** (`phone`, text, optional): Enter your phone number if you'd like to be contacted for any further discussion.
* **Date Attended** (`date_attended`, date, optional): If you attended the event, please enter the date in YYYY-MM-DD format (e.g., 2022-09-01).
* **Start Time** (`start_time`, time, optional): If you attended the event, please enter the start time in 24-hour format (e.g., 21:00 or 09:00).
* **Finish Time** (`finish_time`, time, optional): If you attended the event, please enter the finish time in 24-hour format (e.g., 23:00 or 11:00).
* **Trivia Category** (`trivia_category`, select_multiple, optional): Select all categories that relate to your experience at the event. Choose from: animal shelter, veterinary clinic, veterinary hospital, animal adopt, pet breeder, veterinary school.
* **Attended Event** (`attended_event`, select_multiple, optional): If you attended the event, select yes. If not, select no or unsure.
* **Event Length** (`event_length`, select_one, optional): Estimate how long the event lasted for you. Choose from: 30-60 minutes, 1-2 hours, 2-3 hours, all day.
* **Comments** (`comments`, text, optional): If you have any additional comments or suggestions, please provide them here.
* **Form Completed** (`form_completed`, select_one, optional): If you completed the form accurately, select yes. If not, select no or unsure.

Remember, please answer honestly and provide as much detail as possible. Your feedback is valuable to us!
