# Botanical Garden Tour Feedback Form - Help Guide
## Purpose

The purpose of this form is to gather feedback from visitors like you to help us improve our tours.

## How To Complete This Form

1. **Fill out the form completely**, providing all required information (denoted by *) as accurately and thoroughly as possible.
2. **Submit the form** once you have filled out all fields.
3. **Review and submit a separate form** for each unique visit date.

## Field-by-Field Explanation

* **Visitor Name (`visitor_name`)**: *Optional - your name for follow-up purposes.*
*   This field is for your name and is not required. However, providing your name will help us follow up with you for any further questions or updates.
*   If you do not provide your name, we will not be able to contact you for follow-up purposes.
*   Please enter your name as it appears on your identification.
*   Please use the format "First Name Last Name" for example, "John Smith".
*   This field is not required but recommended for follow-up purposes.
*   Maximum characters: 50 characters
*   Example: John Smith
*   Input type: Text
*   Required: No

* **Visitor Email (`visitor_email`)**: *Email address for follow-up communications.*
*   This field is for your email address and is optional. However, providing your email will help us contact you for any further questions or updates.
*   Please enter a valid email address.
*   Example: john.smith@example.com
*   Maximum characters: 100 characters
*   Input type: Email
*   Required: No

* **Tour Date (`tour_date`)**: *Date when you attended the tour.*
*   This field is required. Please select the date you attended the tour from the calendar.
*   Example: 2024-02-20
*   Input type: Date
*   Required: Yes

* **Tour Type (`tour_type`)**: *Which tour did you attend.*
*   This field is required. Please select the type of tour you attended.
*   Options: Guided Garden Walk, Self-Guided Tour, Specialty Plant Tour, Historical Garden Tour, Children's Educational Tour, Photography Tour, Seasonal Highlights Tour.
*   Example: Guided Garden Walk
*   Input type: Select One
*   Required: Yes

* **Tour Guide Name (`tour_guide_name`)**: *Name of your tour guide if applicable.*
*   This field is optional. If you attended a tour with a guide, please enter their name.
*   Please enter the name as it was given to you by your tour guide.
*   Maximum characters: 50 characters
*   Example: John Doe
*   Input type: Text
*   Required: No

* **Group Size (`group_size`)**: *Number of people in your party.*
*   This field is required. Please select the number of people in your party.
*   Example: 5
*   Input type: Number
*   Required: Yes

* **Overall Satisfaction (`overall_satisfaction`)**: *How would you rate your overall tour experience.*
*   This field is required. Please rate your overall satisfaction with the tour.
*   Options: Excellent, Very Good, Good, Fair, Poor.
*   Example: Excellent
*   Input type: Select One
*   Required: Yes

* **Guide Knowledge and Expertise (`guide_knowledge`)**: *Rate the tour guide's knowledge of plants and gardens.*
*   This field is required. Please rate the tour guide's knowledge.
*   Options: Excellent, Very Good, Good, Fair, Poor, Not Applicable.
*   Example: Excellent
*   Input type: Select One
*   Required: Yes

* **Tour Pace (`tour_pace`)**: *How was the pacing of the tour.*
*   This field is required. Please rate the pacing of the tour.
*   Options: Too Fast, Just Right, Too Slow.
*   Example: Just Right
*   Input type: Select One
*   Required: Yes

* **Tour Duration (`tour_duration`)**: *Was the tour length appropriate.*
*   This field is required. Please rate the tour length.
*   Options: Too Short, Just Right, Too Long.
*   Example: Just Right
*   Input type: Select One
*   Required: Yes

* **Highlights You Enjoyed Most (`highlights_enjoyed`)**: *Select all that apply.*
*   This field is optional. Please select all highlights you enjoyed the most.
*   Options: Plant identification information, Garden history and stories, Scenic viewpoints, Interactive demonstrations, Q&A opportunities, Printed materials provided, Garden maintenance insights.
*   Example: Plant identification information, Garden history and stories
*   Input type: Select Multiple
*   Required: No

* **Facility Cleanliness (`facility_cleanliness`)**: *Rate the cleanliness of the garden facilities.*
*   This field is required. Please rate the cleanliness of the garden facilities.
*   Options: Excellent, Very Good, Good, Fair, Poor.
*   Example: Excellent
*   Input type: Select One
*   Required: Yes

* **Signage Quality (`signage_quality`)**: *Rate the quality and clarity of garden signage.*
*   This field is required. Please rate the quality and clarity of garden signage.
*   Options: Excellent, Very Good, Good, Fair, Poor.
*   Example: Excellent
*   Input type: Select One
*   Required: Yes

* **Likelihood to Recommend (`likelihood_recommend`)**: *How likely are you to recommend this tour to others.*
*   This field is required. Please rate your likelihood to recommend the tour.
*   Options: Very Likely, Likely, Neutral, Unlikely, Very Unlikely.
*   Example: Very Likely
*   Input type: Select One
*   Required: Yes

* **Areas for Improvement (`areas_improvement`)**: *What could we improve for future tours.*
*   This field is optional. Please enter any suggestions or feedback you might have for us to improve.
*   Maximum characters: 250 characters
*   Example: More tour guides would be great
*   Input type: Text
*   Required: No

* **Additional Comments (`additional_comments`)**: *Any other feedback you would like to share.*
*   This field is optional. Please enter any other feedback or comments you might have.
*   Maximum characters: 250 characters
*   Example: Beautiful garden!
*   Input type: Text
*   Required: No

* **Planning a Return Visit (`return_visit`)**: *Do you plan to visit the garden again.*
*   This field is required. Please let us know if you plan to return to the garden.
*   Options: Yes, definitely, Probably, Maybe, Probably not, False.
*   Example: Yes, definitely
*   Input type: Select One
*   Required: Yes

* **Newsletter Signup (`newsletter_signup`)**: *Would you like to receive our garden newsletter.*
*   This field is optional. Please let us know if you would like to receive our newsletter.
*   Options: True, False.
*   Example: True
*   Input type: Select One
*   Required: No
