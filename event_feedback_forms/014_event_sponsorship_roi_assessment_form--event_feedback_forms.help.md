# event_sponsorship_roi_assessment_form - Help Guide
## Purpose

The event sponsorship ROI assessment form is used to evaluate the success of a sponsored event. It helps in determining whether the event was profitable for the sponsor and identifies areas for improvement.
 
## How To Complete This Form

To complete this form, follow these steps:

1.  Determine if the event was sponsored.
2.  Select the event as 'Yes' or 'No' to answer if the event was sponsored.
3.  Fill in the name of the sponsor.
4.  Briefly describe the event and its description.
5.  Enter the ROI metric to measure the event's success.
6.  Enter the investment amount made for the event.
7.  If you have any feedback or suggestions for the sponsor, enter them in the 'feedback_suggestions' field.
8.  Indicate if the event had positive or negative feedback.
9.  Enter any additional notes about the event.
10. Enter the sponsor's email address (if available).
11. Enter the sponsor's phone number (if available).

## Field-by-Field Explanation

* **event_sponsorship** (Required, Select One):
	+ This field asks whether the event was sponsored or not. Select 'Yes' if the event was sponsored and 'No' otherwise.
* **sponsor_name** (Required, Text):
	+ Enter the name of the sponsor.
* **event_description** (Required, Text):
	+ Provide a brief description of the event.
* **roi_metric** (Required, Number):
	+ Enter the ROI metric to measure the event's success.
* **investment_amount** (Required, Number):
	+ Enter the investment amount made for the event.
* **feedback_suggestions** (Optional, Text):
	+ If you have any feedback or suggestions for the sponsor, enter them here.
* **event_feedback** (Required, Select Multiple):
	+ Indicate if the event had positive 'Yes' or negative 'No' feedback.
* **notes** (Optional, Note):
	+ Enter any additional notes about the event.
* **sponsor_email** (Optional, Email):
	+ Enter the sponsor's email address (if available).
* **sponsor_phone** (Optional, Text):
	+ Enter the sponsor's phone number (if available).
