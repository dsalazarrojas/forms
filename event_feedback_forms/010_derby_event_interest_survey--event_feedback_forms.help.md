# derby_event_interest_survey - Help Guide
## Purpose
This form is designed to collect feedback and interest information from users about events. This information will help event organizers and administrators understand what attendees found interesting or useful about the event.

## How To Complete This Form
This form is divided into several sections, each with a specific purpose. Please read each section carefully and fill out the form accordingly.

## Field-by-Field Explanation

* **Name** (`name`, `text`, optional): Please fill out your name as you would like to be addressed. This field is not required but it helps us get a better understanding of who filled out the form.
* **Email** (`email`, `email`, optional): If you would like to be contacted for follow-up questions or to receive more information about future events, please provide your email address. This field is not required.
* **Date** (`date`, `date`, optional): Please fill out the date you attended the event or the date you became interested in the event. This field is not required.
* **Time** (`time`, `time`, optional): If you can provide the time you attended the event, that would be great. However, this is not necessary.
* **Event Date** (`event_date`, `date`, optional): This field is meant to capture the date of the event, if you know it. Please provide it if you can. If you are unsure, you can leave it blank.
* **Activity** (`activity`, `select_one`, required): Please choose the activity or program that you found the most interesting or useful about the event.
* **Attendees** (`attendees`, `select_multiple`, required): Please select all the attendees you are interested in or have attended the event with. Please choose as many or as few as you like.
* **Comments** (`comments`, `text`, optional): If you have any additional comments or suggestions about the event, please feel free to add them here. This field is not required.

## Tips

* Please fill out the form as accurately and truthfully as possible.
* If you are unsure about any of the fields, please don't hesitate to contact us for clarification.
* You can fill out this form multiple times if you have interest in different events.
