# Event Result Summary - Help Guide

## Purpose
The Event Result Summary form is used to collect feedback and information about a specific event that has occurred. It is used to gather details about the event's name, date, time, outcomes, and any relevant feedback or ratings. This form is essential for event organizers, coordinators, and team members to quickly and efficiently capture event-related information. By completing this form, you will be providing a concise and structured summary of the event's result, which will aid in the evaluation and planning of future events.

## How To Complete This Form
To complete this form, follow these steps:

* Fill in the Event Name to describe the event briefly. This is an optional field, but it helps event organizers and coordinators to quickly identify the event.
* Select the Event Date when the event occurred.
* Choose the Event Time for the event. This can be in 12-hour clock format (e.g., 10:00 am) or 24-hour clock format (e.g., 10:00).
* Provide Outcome Details, where you can describe the event's outcome or result in a few sentences.
* Choose the outcome from the list of options provided in the Outcome Outcomes field. Select 'Yes' if the event was successful, and 'No' if it was not.
* Enter any additional Feedback Text to provide more context about the event's outcome.
* Select a Feedback Rating from the list of options provided (Good or Fair).
* If necessary, upload relevant files for File 1 and File 2.

## Field-by-Field Explanation
* **Event Name** (`event_name`, Optional): Enter a brief description of the event.
* **Event Date** (`event_date`, Required): Enter the date when the event occurred in the format mm/dd/yyyy.
* **Event Time** (`event_time`, Optional): Enter the time when the event occurred in 12-hour or 24-hour clock format.
* **Outcome Details** (`outcome_details`, Optional): Enter a brief description of the event's outcome or result.
* **Outcome Outcomes** (`outcome_outcomes`, Optional): Select 'Yes' or 'No' from the provided options to indicate whether the event was successful or not.
* **Feedback Text** (`feedback_text`, Optional): Enter any additional context or information about the event's outcome.
* **Feedback Rating** (`feedback_rating`, Optional): Select from the list to rate the event's outcome (Good or Fair).
* **File 1** (`file1`, Optional): Upload a relevant file if required for further reference.
* **File 2** (`file2`, Optional): Upload another relevant file if required for further reference.
