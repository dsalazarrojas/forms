# PHEV Event Feedback Survey - Help Guide
## Purpose
The PHEV Event Feedback Survey is designed to collect feedback from attendees about events such as conferences, workshops, and meetings. This feedback will help event organizers to better understand what worked well and what did not, and to make improvements for future events.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the required fields: Event Date, Event Time, Event Location, Event Type, and Feedback.
2. Enter the date of the event you attended.
3. Enter the time of the event you attended.
4. Enter the location of the event you attended.
5. Select the type of event you attended from the list: Conference, Workshop, Meeting.
6. Provide your feedback about the event.

## Field-by-Field Explanation
### General Information (<general_info>)
* **General Information** (`text`, required): Please provide a brief description of the event you attended.

### Event Date (<event_date>)
* **Event Date** (`date`, required): Enter the date of the event you attended. Please use the format mm/dd/yyyy.

### Event Time (<event_time>)
* **Event Time** (`time`, required): Enter the time of the event you attended. Please use the format 12:00 PM.

### Event Location (<event_location>)
* **Event Location** (`text`, required): Enter the location of the event you attended.

### Event Type (<event_type>)
* **Event Type** (`select_one`, required): Select the type of event you attended from the list:
	+ Conference
	+ Workshop
	+ Meeting

### Feedback (<feedback>)
* **Feedback** (`text`, required): Provide your feedback about the event. This is your opportunity to let us know what we did well and what we could improve on. Be honest and specific, and help us make future events better for everyone.
