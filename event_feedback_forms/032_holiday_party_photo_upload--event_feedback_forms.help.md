# holiday_party_photo_upload - Help Guide
## Purpose
This form is designed to collect feedback and photos from attendees of a holiday party event. It is meant for staff members and attendees to provide their input and experiences about the event.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the **Holiday Party Photo** field with a description or a short message about your experience at the holiday party.
2. If you attended the party, enter your **Attendee Name** in this field.
3. If you want to be contacted for any follow-up questions or surveys, enter your **Email** address.
4. If you have a **Phone** number, enter it so we can reach out to you if needed.
5. Select the **Event Date** the party took place on, using the date picker calendar.
6. Choose the **Event Time** the party occurred, using the time picker calendar.

## Field-by-Field Explanation

* **Holiday Party Photo** (`holiday_party_photo`, `text`, optional): This field is where you can write a short description or a brief message about your experience at the holiday party. You can share a funny quote, a memorable moment, or a kind word about the event.
* **Attendee Name** (`attendee_name`, `text`, optional): If you attended the party, please enter your name so we can identify you and connect your feedback with the correct event.
* **Email** (`email`, `email`, optional): If you want to be contacted for any follow-up questions or surveys, please enter your email address here.
* **Phone** (`phone`, `text`, optional): If you have a phone number, enter it so we can reach out to you if needed.
* **Event Date** (`event_date`, `date`, optional): Choose the date the holiday party event occurred from the calendar.
* **Event Time** (`event_time`, `time`, optional): Select the time the holiday party event occurred from the calendar.
