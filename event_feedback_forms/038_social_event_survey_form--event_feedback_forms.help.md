# Social Event Survey Form - Help Guide
## Purpose
The Social Event Survey Form is designed to gather feedback on social events. It aims to collect information that can help improve future events.
## How To Complete This Form
To complete this form, please follow these steps:
1. Enter the date of the social event.
2. Specify the location of the event.
3. Estimate the number of attendees.
4. Select the type of event (e.g., Networking Event, Party, Conference, etc.).
5. Provide any additional comments or feedback on the event (this will be a free-text field).
6. List specific areas where the event could be improved (e.g., food, entertainment, etc.).
7. Estimate the impact of the event (this is a numerical field, e.g., number of connections made, etc.).

## Field-by-Field Explanation
* **Event Date** (`event_date`, date, required: false): This field asks for the date of the social event. Please enter the date in the format MM/DD/YY.
* **Event Location** (`event_location`, text, required: false): Enter the location where the event took place.
* **Attendees Number** (`attendees_number`, number, required: false): Estimate the number of people who attended the event.
* **Event Type** (`event_type`, select_one, required: false): Choose the type of event from the options provided (e.g., Networking Event, Party, Conference, etc.).
* **Event Success** (`event_success`, note, required: false): Share any additional comments or feedback on the event.
* **Improvement Areas** (`improvement_areas`, note, required: false): List specific areas where the event could be improved (e.g., food, entertainment, etc.).
* **Impact Measured** (`impact_measured`, number, required: false): Estimate the impact of the event (e.g., number of connections made, etc.).
