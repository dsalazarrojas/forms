# Jazz Brunch Experience Survey - Help Guide
## Purpose
This form is designed to gather feedback on the Jazz Brunch Experience event.
## How To Complete This Form
To complete this form, follow these steps:

1. Click on the title field and enter a brief title for your feedback.
2. Enter your category of feedback (e.g., "Food and Beverage", "Entertainment", etc.).
3. Provide a detailed description of your experience.
4. (Optional) If you have an ID for the form, enter it.
5. (Optional) If you have an output file, provide its path.

## Field-by-Field Explanation
### Title
* **Title** (`title`, text, required): A brief title for your feedback.
### Category
* **Category** (`category`, text, required): Choose a category that best describes your feedback (e.g., "Food and Beverage", "Entertainment", etc.).
### Description
* **Description** (`description`, text, required): A detailed description of your experience.
### Form ID
* **Form ID** (`form_id`, text, optional): If you have an ID for the form, enter it here.
### Output File
* **Output File** (`output_file`, text, optional): If you have an output file, provide its path.
### Assigned Tool
* **Assigned Tool** (`assigned_tool`, text, optional): Not applicable for this form.
## Tips
* Please be as detailed and honest as possible in your feedback.
* If you have any suggestions for improvement, feel free to share them.
* You can skip any optional fields if they don't apply to your situation.
