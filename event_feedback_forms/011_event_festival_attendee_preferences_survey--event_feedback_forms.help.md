# Event Festival Attendee Preferences Survey - Help Guide
## Purpose
This form is designed to gather feedback from attendees to help us understand their opinions on the event and its programming. Your responses will help us identify areas of improvement for future events.

## How To Complete This Form
To complete this form, follow these steps:

1. Answer each question carefully and honestly.
2. If a question is not required, feel free to skip it.
3. For questions that allow multiple selections, choose all that apply.

## Field-by-Field Explanation
### 1. What did you think of the event
* This question allows you to share your thoughts and opinions about the event. You can enter any relevant details about your experience.
* Please be as specific as possible, and provide any feedback you have.

### 2. What did you like about the programming
* This question asks about your experiences with the event programming. Select all that apply if you liked multiple aspects.
* Examples of things you might like include:
	+ Variety of speakers
	+ Quality of speakers
	+ Organization of schedule
	+ Catering

### 3. How would you rate your overall satisfaction with the event
* This question asks for your overall satisfaction with the event. Choose one of the options provided:
	+ Not Satisfied
	+ Satisfied
	+ Very Satisfied
* Please choose the option that best reflects your true feelings.

### 4. How would you rate your overall preferences for this event
* This question is currently optional, but we're working on making it a required field!
* If this question were required, we would ask for your rating on a scale of 1-5, with 1 being low and 5 being high.
* Please note that this question is currently optional, so feel free to skip it if you're not comfortable providing a rating.

### 5. What could we improve on for next year
* This question is a chance for you to suggest any improvements or changes we could make for future events.
* Please be as specific as possible, and provide any relevant details.

### 6. Would you like to receive email updates
* This question asks if you'd like to receive email updates from us.
* If you select "Yes", we'll keep you informed about future events and updates.
* If you select "No", we'll make sure to respect your boundaries.

### 7. Would you like to receive phone updates
* This question is currently optional, but we're not sure what it's for yet!
* If you're interested in receiving phone updates, please let us know, and we'll get in touch with you.
* If you select "No", we'll not contact you via phone.

### 8. Additional comments
* This is an open-ended question where you can share any additional thoughts or comments about the event.
* We welcome any feedback, suggestions, or ideas you have, no matter how big or small.
* Please be as specific as possible and provide any relevant details.
