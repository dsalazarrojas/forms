# Event Attendee Experience Assessment - Help Guide
## Purpose
This form is designed to gather feedback and experiences from attendees of events, allowing organizers to improve future events.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the required fields with accurate information.
2. Select the correct options for each field.
3. Provide as much detail as possible in the text fields.
4. Submit the form once you have completed all required fields.

## Field-by-Field Explanation
### 1. **Attendee Experience** (`event_attendee_experience_assessment_form`, text, optional)
This field is an open-ended text field where you can provide a brief description of your experience at the event.

### 2. **Feedback** (`event_feedback_form`, select_one, optional)
Choose whether you have attended an event in the past.

### 3. **Satisfaction** (`event_satisfaction_survey`, number, optional)
Rate your satisfaction with the event on a scale of 0-10.

### 4. **Improvement Ideas** (`event_improvement_ideas`, select_multiple, optional)
Choose any improvement ideas you have for future events.

### 5. **Manage Forms** (`event_manage_forms`, text, optional)
Please do not complete this field. This field is for internal use only.

### 6. **Attendee Email** (`event_attendee_email`, email, optional)
Enter your email address so that we can follow up with you.

### 7. **Attendee Phone** (`event_attendee_phone`, text, optional)
Enter your phone number so that we can follow up with you.

### 8. **Attendance Date** (`event_attendance_date`, date, optional)
Enter the date of the event you attended.

### 9. **Start Time** (`event_start_time`, time, optional)
Enter the start time of the event you attended.

### 10. **End Time** (`event_end_time`, time, optional)
Enter the end time of the event you attended.

### 11. **Note** (`note`, note, optional)
Enter any additional notes about your experience at the event.

### 12. **Form Submitter** (`form_submitter`, text, optional)
Please do not complete this field. This field is for internal use only.

### 13. **Event ID** (`event_id`, number, optional)
Enter the ID of the event you attended.

## Tips
- Please be as detailed and honest as possible when providing feedback.
- If you have attended multiple events, please fill out the form for each event separately.
- If you need help or have questions, please contact us.
