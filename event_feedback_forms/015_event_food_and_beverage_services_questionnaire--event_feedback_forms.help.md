# Event Food And Beverage Services Questionnaire - Help Guide
## Purpose
The Event Food And Beverage Services Questionnaire is designed to gather feedback on the services provided to attendees at an event. This will help us understand their overall satisfaction and identify areas for improvement.

## How To Complete This Form
1. Fill out the form carefully and thoroughly, providing as much detail as possible.
2. Please select one option for each rating question (e.g. Excellent, Good, Average, Poor, Very Poor).
3. If you have any comments or suggestions, please type them in the provided text box.
4. Make sure to fill in your contact information so we can follow up with you if needed.

## Field-by-Field Explanation
* **Event Date** (`event_date`): The date of the event you attended. Please use the format `YYYY-MM-DD`.
* **Event Time** (`event_time`): The time of the event you attended. Please use the format `HH:MM AM/PM`.
* **Venue Name** (`venue_name`): The name of the venue where the event was held.
* **Food Quality** (`food_quality`): How would you rate the quality of the food provided at the event? Please select one of the following options:
	+ Excellent
	+ Good
	+ Average
	+ Poor
	+ Very Poor
* **Beverage Quality** (`beverage_quality`): How would you rate the quality of the beverages provided at the event? Please select one of the following options:
	+ Excellent
	+ Good
	+ Average
	+ Poor
	+ Very Poor
* **Service Quality** (`service_quality`): How would you rate the quality of service provided by event staff? Please select all that apply:
	+ Excellent
	+ Good
	+ Average
	+ Poor
	+ Very Poor
* **Overall Satisfaction** (`overall_satisfaction`): How satisfied were you with the event food and beverage services overall? Please select one of the following options:
	+ Excellent
	+ Good
	+ Average
	+ Poor
	+ Very Poor
* **Suggest any improvements** (`suggestions`): If you have any suggestions for how we can improve our services, please type them in here.
* **Comments** (`comments`): Do you have any additional comments about your experience at the event?
* **Email** (`email`): Please enter your email address so we can follow up with you if needed.
* **Phone** (`phone`): Please enter your phone number so we can follow up with you if needed.
* **Contact Person** (`contact_person`): Please enter the name of the person you would like to contact.
* **Contact Number** (`contact_number`): Please enter the contact number for the person you would like to contact.
* **Department** (`department`): Please enter the department or team you would like to contact.
* **Company** (`company`): Please enter the name of your company.
* **Event Name** (`event_name`): The name of the event you attended.
* **Event Date 2** (`event_date_2`): If this is a recurring event, please enter the date of the next event.
* **Event Time 2** (`event_time_2`): If this is a recurring event, please enter the time of the next event.
* **Venue Address** (`venue_address`): The address of the venue where the event was held.
