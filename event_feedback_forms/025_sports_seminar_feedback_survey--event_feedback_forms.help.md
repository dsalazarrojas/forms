# Sports Seminar Feedback Survey - Help Guide
## Purpose
The purpose of this form is to gather feedback from participants after attending the Sports Seminar event. This feedback will help us evaluate the event's effectiveness and make improvements for future events.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out your name in the "What is your name?" field.
2. Enter the name of the event you attended in the "Event Name" field.
3. For the "Feedback Score" field, rate your overall satisfaction with the event (1-10).
4. Provide any additional comments or suggestions in the "Comment" field.
5. Select the best description of your experience with the event.
6. If you have any further feedback, add it to the "Note" field.

## Field-by-Field Explanation
- **What is your name? (page_1)**: Enter your name to ensure we have accurate information for future correspondences.
- **Event Name (event_name)**: Enter the name of the event you attended so we can track feedback for specific events.
- **Feedback Score (feedback_score)**: Rate your overall satisfaction with the event on a scale of 1-10.
- **Comment (comment)**: Share any thoughts or suggestions you have about the event.
- **Suggestions (suggestions)**: Provide any suggestions for future events or improvements.
- **Email (email)**: Enter your email address so we can follow up with you for more information.
- **Phone (phone)**: Enter your phone number in case we need to contact you for more details.
- **Date (date)**: Enter the date of the event you attended.
- **Time (time)**: Enter the time of the event you attended.
- **Select One (select_one)**: Select "Yes" if you found the event helpful, otherwise select "No".
- **Select Multiple (select_multiple)**: Select all the ways you found the event helpful (if any).
- **Is this event useful? (page_3)**: Select "Yes" if the event was useful, otherwise select "No".
- **Event Date (event_date)**: Enter the date of the event you attended.
- **Event Time (event_time)**: Enter the time of the event you attended.
- **Comments (page_4)**: Share any additional comments or thoughts you have about the event.
- **Page 4 (page_4)**: Select all the ways you found the event helpful (if any).

## Tips

* Please fill out the form accurately and thoroughly for your feedback to be most helpful.
* If you have any questions or concerns, please don't hesitate to contact us.
* We value your feedback and appreciate your participation in helping us improve future events.
