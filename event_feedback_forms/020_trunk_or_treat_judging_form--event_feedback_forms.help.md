### Purpose

The Trunk or Treat Judging Form is used to collect feedback from judges on various aspects of Trunk or Treat events.

### How To Complete This Form

1. Fill out the form with the required information:
	* **Event**: Enter the name of the event you attended.
	* **Location**: Enter the location where the event took place.
2. Select the correct options for each category:
	* **Theme**: Choose the theme that best describes the event.
	* **Decorations**: Select all the decorations that you thought were impressive.
	* **Food**: Choose the type of food that was provided.
	* **Trunk**: Select the type of trunk that was most impressive.
	* **Team Spirit**: Choose the level of team spirit you observed.
	* **Score**: Select 'Yes' or 'No' if you think the event met the necessary standards, or select 'Other' if you have additional comments.
	* **Attended**: Select 'True' if you attended the event, or 'False' if you did not.
3. Provide any additional comments or feedback about the event in the **Comment** field.

### Field-by-Field Explanation

* **Event**: This field asks for the name of the event you are evaluating.
* **Theme**: This field allows you to select the theme that best describes the event.
* **Decorations**: This field is a multiple-select field where you can choose all the decorations that caught your attention.
* **Food**: This field is a single-select field where you choose the type of food that was provided.
* **Trunk**: This field is a single-select field where you choose the type of trunk that was most impressive.
* **Team Spirit**: This field is a single-select field where you choose the level of team spirit you observed.
* **Score**: This field is a multiple-select field where you can select 'Yes' if the event met the necessary standards, or 'No' if it did not. You can also select 'Other' to provide additional comments.
* **Attended**: This field is a multiple-select field where you can select 'True' if you attended the event, or 'False' if you did not.
* **Event Date**: This field is a date field where you enter the date of the event.
* **Location**: This field is a text field where you enter the location where the event took place.
* **Comment**: This field is a note field where you can provide additional comments or feedback about the event.

### Tips

* Make sure to provide accurate and honest feedback so that we can improve future events.
* If you have any additional comments or suggestions, please use the **Comment** field.
* If you are unsure about any of the fields, please ask for clarification before submitting your feedback.
