# Flood Information Session Feedback - Help Guide
## Purpose
This form is used to collect feedback from attendees after a flood information session. Your responses will help us improve our services and provide better support in the future.

## How To Complete This Form
To complete this form, simply follow these steps:

1. Click on the "Submit" button to start.
2. Fill out the fields according to the descriptions below.
3. Click on "Submit" again to submit your feedback.

## Field-by-Field Explanation
* **Event Name**: This is the name of the event where you attended the flood information session. Please type the name of the event as it was labeled.
* **Attendee Name**: This is your name as an attendee of the event. Please type your full name as it is written on your registration or identification.
* **Rating**: Please rate your overall satisfaction with the event on a scale of 1 to 5, where 1 is Not satisfied and 5 is Very Satisfied.
* **Comments**: If you have any comments or feedback about the event, please type them here.
* **Topic Suggestions**: If you have any suggestions for topics or improvements for future events, please select all that apply.
* **Email**: If you have any contact information, please type your email address so we can get back to you.
* **Phone**: If you have any contact information, please type your phone number so we can get back to you.
* **Event Date** and **Event Time**: These fields are used to record the date and time of the event. Please note that these fields are not required, but they are helpful for our records.
* **Phone** and **Event Date**: These fields are optional but can help us to keep our records up to date.

## Tips
- Make sure to fill out the form as accurately as possible.
- If you have any questions or concerns, please contact us directly.
- If you're having trouble filling out the form, try asking your event organizer for help.
