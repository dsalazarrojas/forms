# post event feedback form - Help Guide
## Purpose
The post event feedback form is designed to collect feedback from attendees after an event, allowing event organizers to improve future events based on attendee comments.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill out each page of the form in sequence.
2. For each question, provide as much detail as you need to answer the question.
3. Once you have completed all pages, press the submit button to submit your feedback.

## Field-by-Field Explanation
### Event Feedback Form 1
* **event_feedback_form_1_label** (`event_feedback_form_1`, text, optional): Enter your thoughts about the event.
### Question 1: What did you think?
* **What did you think** (`question_1`, text, optional): Share your thoughts and opinions about the event.
### Question 2: Rating (1-5)
* **Rating (1-5)** (`question_2`, number, optional): Rate your overall experience at the event on a scale from 1 to 5, where 1 is the lowest and 5 is the highest.
### Question 3: Would you come back?
* **Would you come back?** (`question_3`, select_one, optional): Select 'Yes' if you would attend another event by this organizer, 'No' if you would not.
### Question 4: Would you recommend this event?
* **Would you recommend this event?** (`question_4`, select_multiple, optional): Select all that apply: 'Yes' if you would recommend this event to others, 'No' if you would not.
### Question 5: Date
* **Date** (`question_5`, date, optional): Enter the date of the event you attended.
### Question 6: Time
* **Time** (`question_6`, time, optional): Enter the time of the event you attended.
### Question 7: Additional comments
* **Additional comments** (`question_7`, note, optional): Share any additional comments or thoughts about the event.
### Question 8: Attendee email
* **Attendee email** (`question_8`, email, optional): Enter your email address.
### Question 9: Attendee name
* **Attendee name** (`question_9`, text, optional): Enter your name.

## Tips
* Make sure to enter your email address if you want to receive updates about future events. 
* Please be honest and thorough in your feedback to help us improve future events.
