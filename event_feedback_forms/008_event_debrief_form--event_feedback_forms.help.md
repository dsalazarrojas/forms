# Event Debrief Form - Help Guide
## Purpose
The Event Debrief Form is a tool for gathering feedback from attendees after an event. It helps event organizers and stakeholders understand the event's outcome, identify areas for improvement, and make data-driven decisions for future events.

## How To Complete This Form
To complete the form, follow these steps:
1. Enter the event name in the "eventName" field. This is the name of the event you are providing feedback on.
2. Select the type of event from the "eventType" field. This will help us understand the nature of the event.
3. If you attended the event, select your rating for the event from the "feedbackRating" field. This will help us understand your overall satisfaction.
4. Provide your rating for the event using the 3-point or 4-point scale as needed.
5. If you have any comments or feedback about the event, please provide them in the "feedbackComment" field.
6. Enter the name and contact information of the event organizer in the "eventOrganizerName", "eventOrganizerEmail", and "eventOrganizerPhone" fields if applicable.
7. Click submit to send in your feedback.

## Field-by-Field Explanation
* **Event Debrief** (text, required: false): Enter a brief description of the event.
* **Event Name** (text, required: false): Enter the name of the event you are providing feedback on.
* **Event Date** (date, required: false): Enter the date of the event.
* **Event Location** (text, required: false): Enter the location of the event.
* **Feedback Rating** (number, required: false): Select one of the following: Very Satisfied, Somewhat Satisfied, Not Satisfied, Neutral, Not Satisfied At All.
* **Event Type** (select_one, required: false): Select the type of event this was (e.g., Conference, Workshop, etc.).
* **Feedback Comment** (note, required: false): Provide any additional comments or feedback you have about the event.
* **Feedback Rating 3 Scale** (select_one, required: false): Select one of the following: Very Satisfied, Somewhat Satisfied, Not Satisfied, Neutral, Not Satisfied At All.
* **Feedback Rating 4 Scale** (select_multiple, required: false): Select one or more of the following: Very Good, Somewhat Good, Not Good, Bad, Very Bad.
* **Event Organizer Name** (text, required: false): Enter the name of the event organizer.
* **Event Organizer Email** (email, required: false): Enter the email of the event organizer.
* **Event Organizer Phone** (text, required: false): Enter the phone number of the event organizer.
* **Event Organizer Contact** (text, required: false): Enter any additional contact information for the event organizer.
