# event_vendor_support_feedback_survey - Help Guide

## Purpose
The "event_vendor_support_feedback_survey" form is used to collect feedback from event planners about the support provided by vendors. This form helps improve the quality of support services offered to event planners.

## How To Complete This Form
To complete this form, follow these steps:
1. Review each question carefully and answer truthfully.
2. Complete all the required fields.
3. If you have any suggestions or comments, type them in the "Suggestions to improve support" field.
4. If you have any support issues, select all that apply in the "Have you encountered any support issues" field.
5. Provide the date and time of the event you are giving feedback on.

## Field-by-Field Explanation

* **Event Planner Feedback**: This field is where you can type in any comments or feedback about your experience with the vendor's support.
* **Have you encountered any support issues**: If you have any issues with the vendor's support, select all that apply. This will help us identify areas where we can improve.
* **Suggestions to improve support**: If you have any suggestions on how we can improve our support services, type them in this field.
* **Date of the event**: This field is required to help us narrow down the specific event you are giving feedback on. Please enter the date of the event in YYYY-MM-DD format.
* **Time of the event**: This field is also required to help us narrow down the specific event you are giving feedback on. Please enter the time of the event in 12-hour format (e.g., 2:00 PM).
* **Vendor Name**: If you are giving feedback on a specific vendor, type in their name here.
* **Contact Number**: This field is used to get in touch with you for follow-up questions or to provide additional support. Please enter a valid contact number.
* **Email**: This field is used to get in touch with you for follow-up questions or to provide additional support. Please enter a valid email address.

## Tips
* Please be as specific as possible when giving feedback.
* If you have any questions or concerns, don't hesitate to contact us.
* We appreciate your feedback and will use it to improve our support services.
