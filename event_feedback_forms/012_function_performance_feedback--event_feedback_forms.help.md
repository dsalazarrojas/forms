# Function Performance Feedback - Help Guide
## Purpose
This form is intended for users to provide feedback on the performance of functions provided by our organization. It is used to collect feedback on how well we meet the needs and expectations of our customers. By filling out this form, users can help us identify areas for improvement and provide input on how we can better serve them.

## How To Complete This Form

### Step 1: Select the Event
You should have already been directed to this form after participating in an event. If you are unsure which event this form is related to, please contact us for assistance.

### Step 2: Fill Out the Form
Carefully read each field explanation below for guidance on how to complete each section.

## Field-by-Field Explanation
* **Event Feedback (page_1)** (`text`, **Required**): Describe the function that was performed or event that you attended. Be as specific as possible.
* **Satisfaction (Satisfaction)** (`select_one`, **Not Required**): Choose how satisfied you were with the function performed or event. Select one of the following options:
	+ Very Dissatisfied
	+ Somewhat Dissatisfied
	+ Neutral
	+ Somewhat Satisfied
	+ Very Satisfied
* **Comments (Comments)** (`note`, **Not Required**): Add any additional comments or thoughts you have about the function or event. This is an optional but helpful field for providing more detailed feedback.
* **Email (Email)** (`email`, **Required**): Enter your email address so that we can contact you if we need more information or to follow up on your feedback.
* **Phone (Phone)** (`text`, **Not Required**): Enter your phone number (if any) so that we can contact you if necessary. This is optional but can be helpful in case we need to discuss your feedback in more detail.

## Tips

* Please be honest and specific in your feedback. This will help us to better understand how we can improve.
* If you are unsure about any of the fields, please contact us for assistance.
* We value your feedback and appreciate the time you take to provide it.
