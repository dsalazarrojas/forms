# ice_festival_feedback_survey - Help Guide
## Purpose
This form is designed to gather feedback from ice festival attendees. It's intended to be completed by attendees to provide their thoughts on their experience with the event.

## How To Complete This Form

To complete this form, follow these steps:

1. Review each section carefully and answer the questions honestly.
2. For multiple-choice questions, select one of the provided options.
3. For text fields, provide as much detail as you can.

## Field-by-Field Explanation

* **Title (No Label)**: This is the title of the form, which should be self-explanatory.
* **ice_festival_event_experience**:
	+ Type: Select One (`ice_festival_event_experience`, `type`: `select_one`)
	+ Required: Yes
	+ Description: Answer "Yes" if you attended the ice festival, "No" otherwise.

## Tips

* Please answer all required fields.
* Be as specific and detailed as possible when answering questions.
* If you have any further questions or concerns, contact the event organizers directly.
