# fundraising_event_report_form - Help Guide
## Purpose
The "fundraising_event_report_form" is a form designed to collect data from event organizers and participants to improve future fundraising events. This guide will walk you through each field and its purpose.

## How To Complete This Form
To complete this form, follow these steps:

1. Start by filling out the required fields, which are marked as "required" in the form.
2. For optional fields, provide as much detail as possible to help with data analysis.
3. Be accurate and honest when filling out the form, as the data will be used to improve future events.

## Field-by-Field Explanation

* **Event Details (1)**:
	+ **Title**: Enter the title of the event as it was displayed to participants.
	+ **Type**: Enter the type of event (e.g., charity walk, auction, bake sale, etc.).
* **Event Date (2)**:
	+ **Event Date**: Enter the date of the event in the format mm/dd/yyyy.
* **Event Time (3)**:
	+ **Event Time**: Enter the start and end time of the event in the format 12:00 PM - 3:00 PM.
* **Event Location (4)**:
	+ **Event Location**: Enter the location where the event took place.
* **Event Type (5)**:
	+ **Event Type**: Select 'Yes' if the event was a fundraising event; 'No' otherwise.
* **Attendees Number (6)**:
	+ **Attendees Number**: Enter the number of attendees at the event.
* **Event Organizer (7)**:
	+ **Event Organizer**: Enter the name of the person or organization that organized the event.
* **Donation Total (8)**:
	+ **Donation Total**: Enter the total amount donated during the event.
* **Participant Feedback (9)**:
	+ **Participant Feedback**: Share any feedback or comments from participants about the event.
* **Comments (10)**:
	+ **Comments**: Add any additional comments or observations about the event.
* **Additional Comments (11)**:
	+ **Additional Comments**: Enter any other information that might be relevant to the event.
* **Email Address (12)**:
	+ **Email Address**: Enter the email address of the event organizer or participant.
