# Mediation Session Feedback Form - Help Guide
## Purpose
The purpose of this form is to collect feedback from users on a mediation session, allowing us to improve our services and provide better support.

## How To Complete This Form
To fill out this form, please follow these steps:

*   Start by filling in the session name, which is the title of the mediation session you are providing feedback on.
*   Next, rate your experience with the session by choosing a rating from 1 to 5.
*   Write a brief comment about what you learned from the session.
*   Enter your email address so we can follow up with you.
*   Provide the date and time of the session.
*   If applicable, enter the number of participants in the session.
*   Choose the facilitator who led the session.
*   Select the type of session it was (e.g., Type A, Type B, Type C).
*   Enter the session goals.
*   Describe the outcome of the session.
*   If there is a follow-up session, choose whether it is true or not.
*   Enter any follow-up comments, if applicable.
*   Enter your follow-up email address, if applicable.
*   Enter your follow-up phone number, if applicable.
*   Enter the date and time of the follow-up session, if applicable.
*   Select the type of follow-up session (e.g., Type A, Type B, Type C), if applicable.
*   Enter the follow-up session goals, if applicable.
*   Describe the outcome of the follow-up session, if applicable.
*   Enter any additional follow-up comments.

## Field-by-Field Explanation

*   **Session Name** (`session_name`, text, required): Enter the title of the mediation session you are providing feedback on.
*   **What did you learn from the session?** (`feedback`, text, required): Write a brief comment about what you learned from the session.
*   **How would you rate this session?** (`rating`, number, required): Choose a rating from 1 to 5.
*   **Comments** (`comments`, text, optional): Enter any additional comments about the session.
*   **Email** (`email`, email, required): Enter your email address so we can follow up with you.
*   **Phone** (`phone`, text, optional): Enter your phone number, if applicable.
*   **Session Date** (`session_date`, date, required): Enter the date of the session.
*   **Session Time** (`session_time`, time, optional): Enter the time of the session, if applicable.
*   **Number of Participants** (`participants`, number, required): Enter the number of participants in the session.
*   **Facilitator** (`facilitator`, select_one, required): Choose the facilitator who led the session.
*   **Session Type** (`session_type`, select_multiple, required): Select the type of session it was (e.g., Type A, Type B, Type C).
*   **Session Goals** (`session_goals`, text, required): Enter the session goals.
*   **Session Outcome** (`session_outcome`, text, optional): Describe the outcome of the session.
*   **Follow-up** (`follow_up`, select_one, required): Choose whether there is a follow-up session or not.
*   **Follow-up Comments** (`follow_up_comment`, text, optional): Enter any follow-up comments.
*   **Follow-up Email** (`follow_up_email`, email, optional): Enter your follow-up email address, if applicable.
*   **Follow-up Phone** (`follow_up_phone`, text, optional): Enter your follow-up phone number, if applicable.
*   **Follow-up Session Date** (`follow_up_session_date`, date, optional): Enter the date and time of the follow-up session, if applicable.
*   **Follow-up Session Time** (`follow_up_session_time`, time, optional): Enter the time of the follow-up session, if applicable.
*   **Follow-up Session Type** (`follow_up_session_type`, select_one, optional): Select the type of follow-up session (e.g., Type A, Type B, Type C), if applicable.
*   **Follow-up Session Goals** (`follow_up_session_goals`, text, optional): Enter the follow-up session goals, if applicable.
*   **Follow-up Session Outcome** (`follow_up_session_outcome`, text, optional): Describe the outcome of the follow-up session, if applicable.
*   **Follow-up Notes** (`follow_up_notes`, text, optional): Enter any additional follow-up comments.
*   **Additional Follow-up Comments** (`follow_up_additional_comments`, text, optional): Enter any additional follow-up comments.
*   **Assigned Form** (`assigned_form`, select_one, required): Choose the form that was assigned to you for the follow-up session.
