# Event Vendor Feedback Questionnaire - Help Guide
## Purpose
This form is designed to collect feedback about events and their associated vendors. Your input will help us better understand your experiences and improve our services.

## How To Complete This Form
To complete this form, simply fill out the required and optional fields as prompted. Please make sure to provide as much detail as possible in each field.

## Field-by-Field Explanation

* **Event Details**: Provide a brief description of the event, including any relevant details that might be useful for our understanding of the event.
* **Your Feedback**: Share your thoughts and experiences about the event and its associated vendor. Be as detailed as possible.
* **Rating**: This field is optional, but if provided, it will help us gauge your overall satisfaction with the event and vendor.
* **Vendor Name**: Enter the name of the vendor associated with the event.
* **Email**: Enter your email address (if you want to receive follow-up emails or notifications).
* **Phone**: Enter your phone number (if you want to be contacted directly).
* **Event Date**: Select the date of the event.
* **Event Time**: Select the time of the event.
* **Event Venue**: Provide the location of the event.
* **Event Description**: Describe the event in detail, including its purpose and any notable aspects.
* **Vendor Rating**: This field is optional and allows you to rate the vendor's performance (e.g., Excellent, Good, Fair, Poor).
* **Vendor Comments**: Share any comments or suggestions about the vendor.
* **Assigned To**: Enter the name of the person assigned to manage the event.
* **Event Status**: Select the status of the event (Active, Inactive, Pending).
* **Vendor Status**: Select the status of the vendor (Active, Inactive, Pending).
* **Event Type**: Select the type of event (Conference, Workshop, Meeting, Seminar, Symposium).
* **Event Priority**: Select the priority of the event (High, Medium, Low).
* **Feedback Frequency**: Select how frequently you would like to provide feedback (Frequently, Occasionally, Rarely).

Note: All fields are optional unless marked as required. Please fill out as much information as possible to help us better understand your experiences.
