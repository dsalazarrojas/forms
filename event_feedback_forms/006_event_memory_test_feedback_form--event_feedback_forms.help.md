The Event Memory Test Feedback Form is used to collect feedback from users on the difficulty level of an event and how it helped with memory. This form is intended for users to provide input on the effectiveness of events, but it may not be suitable for all events. Please ensure that you have received permission from the event organizer to submit feedback before filling out this form. Also, be cautious not to submit duplicate feedback as this may affect the overall statistics and analysis.

# Event Memory Test Feedback Form - Help Guide
## Purpose
This form is designed to collect feedback on the difficulty level of an event and how it helped with memory.
## How To Complete This Form
To fill out this form, follow these steps:

* Fill in the title of the event you are giving feedback on.
* Select the difficulty level of the event from the options provided.
* Provide your email address so that you can be contacted if needed for further information.
* Share any suggestions for improvement with the event.
* If you were assigned to a specific tool, select it from the options.
* Optionally, provide a specific category for the event if it doesn't fit within the provided options.
* Provide any additional comments on the event.
* If you were using a specific tool, select it from the options.
* Submit the form to save your feedback.

## Field-by-Field Explanation

* **How was the difficulty level of the event?**
  This question is used to gauge how difficult or easy the event was. The options provided are:
  + too high
  + not high enough
  + just right

  *Please select the one that best describes your experience*

* **How do you think the event helped with your memory?**
  This question is used to understand the effectiveness of the event on memory. Provide a detailed description of your thoughts on this.

* **Date of the Event**
  This is an optional field for you to enter the date of the event. This will help us to track the events over time.

* **Email**
  This is an optional field for you to enter your email address. This will allow us to contact you for further information if needed.

* **Suggestions for improvement**
  This is an optional field for you to provide any suggestions on how the event could be improved.

* **Assigned to**
  This is an optional field to select who you were assigned to. This will help us to track which team members are involved in the event.

* **Category**
  This is an optional field to select a category for the event. This will help us to group events by category.

* **Comments**
  This is an optional field for you to provide any additional comments on the event.

* **Assigned Tool**
  This is an optional field to select which tool was used for the event. This will help us to track which tools are being used.

## Tips

* Be honest and detailed in your answers.
* Use the provided options for fields like difficulty level and tool.
* Only fill out fields that are relevant to your experience.
* Ensure that you have permission from the event organizer before submitting feedback.
* Be aware that duplicate feedback may affect overall statistics and analysis.
* Submit your feedback after you have finished filling out the form.
