# Liturgy Registration Form - Help Guide
## Purpose
The Liturgy Registration Form is used to register events such as weddings, funerals, masses, and other religious ceremonies. This form collects essential details about the event, including the type, date, location, and participant information.

## How To Complete This Form
1. Fill out the form with the following information:
	* **Event**: This is the unique identifier of the event.
	* **First name**: The first name of the person related to the event.
	* **Last name**: The last name of the person related to the event.
	* **E-mail**: The contact email for the event.
	* **Phone**: The contact phone number for the event.
2. Choose the correct event type from the dropdown options (Wedding, Funeral, Mass, etc.)
3. Confirm if there will be attendees at the event.
4. Provide any additional remarks about the event.
5. Select who created the event entry (Jimmy, John, Mary).
6. Confirm if the event has been updated (not required).
7. Select who updated the event entry (Jimmy, John, Mary, not required).
8. Enter the event date.
9. Enter the event time.
10. Specify the event location.

## Field-by-Field Explanation
* **Event**: A unique identifier for the event. This is a required field.
* **First name**: A required field to identify the person related to the event.
* **Last name**: A required field to complete the person's name.
* **E-mail**: A required field for contact purposes.
* **Phone**: A required field for contact purposes.
* **Event type**: A dropdown selection to categorize the event type (Wedding, Funeral, Mass, etc.). This is a required field.
* **Attendees**: A select multiple field to confirm if there will be attendees. This is a required field.
* **Remarks**: Additional information about the event (not required).
* **Created by**: A select one field to confirm who created the event entry (Jimmy, John, Mary). This is a required field.
* **Updated at**: A date field to track the last update of the event. This is not required.
* **Updated by**: A select one field to confirm who updated the event entry (Jimmy, John, Mary, not required).
* **Event date**: A date field to schedule the event. This is a required field.
* **Event time**: A time field to schedule the event. This is a required field.
* **Event location**: The location of the event. This is a required field, but note that it is optional to enter if you know the location.

## Tips
* Make sure to complete all required fields.
* Select the correct event type from the provided options.
* Ensure that the event date and time match the event date and time fields.
* If the event has attendees, make sure to select 'Yes' for this field.
* If someone updated the event, enter the correct updated date and confirm who made the update.
