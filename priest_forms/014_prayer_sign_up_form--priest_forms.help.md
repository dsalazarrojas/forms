# Prayer Sign Up Form - Help Guide
## Purpose
The purpose of this form is to collect information from individuals who want to sign up for prayers or spiritual guidance.

## How To Complete This Form
To complete this form, follow these steps:

1. Click on the "Submit" button at the end of the form to proceed.
2. Fill out the required fields (none are required in this form, but you can fill out any of the fields you feel comfortable sharing).
3. Enter your name, email, and other relevant information in the corresponding fields.
4. Be as specific as possible when entering your prayer request.
5. You can choose to include a phone number for contact purposes.
6. You can add any additional notes if you have more information to share.
7. Review your entries and click "Submit" to submit the form.

## Field-by-Field Explanation
* **Sign Up Form**: This is the title of the form, which is not actually a field you need to fill out.
* **Name of the person signing up**: This is the name of the individual signing up for the prayer.
	+ **Type:** text
	+ **Hint:** None
	+ **Required:** No
* **Email**: This is the email address of the individual signing up for the prayer.
	+ **Type:** text
	+ **Hint:** None
	+ **Required:** No
* **Prayer Request**: This is the specific prayer request you have.
	+ **Type:** text
	+ **Hint:** Please be as specific as possible about the prayer request.
	+ **Required:** No
* **Phone Number**: This is the phone number of the individual signing up for the prayer.
	+ **Type:** text
	+ **Hint:** Phone number for contact purposes.
	+ **Required:** No
* **Location**: This is the location where the prayer request is being made.
	+ **Type:** text
	+ **Hint:** None
	+ **Required:** No
* **Assigned Tool**: This is the tool or resource assigned to handle the prayer request.
	+ **Type:** text
	+ **Hint:** None
	+ **Required:** No
* **Prayer Request Date**: This is the date when the prayer request was made.
	+ **Type:** date
	+ **Hint:** Date of the prayer request.
	+ **Required:** No
* **Prayer Request Time**: This is the time when the prayer request was made.
	+ **Type:** time
	+ **Hint:** None
	+ **Required:** No
* **Note**: This is a field for any additional notes or information you want to add.
	+ **Type:** note
	+ **Hint:** None
	+ **Required:** No

## Tips
* You can fill out as much or as little information as you feel comfortable sharing.
* Be as specific as possible when entering your prayer request.
* If you have any questions or concerns, contact us for assistance.
