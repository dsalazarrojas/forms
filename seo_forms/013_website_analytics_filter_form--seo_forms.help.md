# Website Analytics Filter Form - Help Guide
## Purpose
This form is used to filter website analytics data for a specific segment of the website. You can use this form to specify the type of filtering you want to perform on the website's analytics data.
## How To Complete This Form
To complete this form, follow these steps:

1. Select the type of segmentation you want to perform on the website's analytics data.
2. Choose the frequency at which you want to filter the data.
3. Specify the metrics you want to include in the filter.
4. Enter any additional information required for the filter, such as email and phone number.

* **Analytics Segmentation Filter** (`analytics_segmentation_filter`, `select_one`, optional): Select the type of segmentation you want to perform on the website's analytics data. Options are `Website`, `Pages`, and `Keywords`.
* **Filter Request Type** (`filter_request_type`, `select_one`, optional): Select the type of filter you want to perform. Options are `Segmentation` and `Filter`.
* **Filter Request Date** (`filter_request_date`, `date`, optional): Enter the date range for the filter.
