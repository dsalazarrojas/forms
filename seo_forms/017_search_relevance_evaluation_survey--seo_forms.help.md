# Search Relevance Evaluation Survey - Help Guide
## Purpose
This form is used to gather feedback on search results to improve their relevance and usefulness.

## How To Complete This Form
1. Complete each page of the form, answering each question thoroughly.
2. For each question, provide your honest opinion based on your recent search experience.
3. If you have any additional comments or observations, use the "Additional Comments" field.

## Field-by-Field Explanation
* **Search Relevance (Page 1)**: Rate the relevance of the search results to your query. Please select a number from 1 to 5, where 1 is "Not Relevant at All" and 5 is "Very Relevant".
* **Search Satisfaction (Page 2)**: How satisfied were you with the search results? Choose the option that best describes your experience:
	+ Very Satisfied
	+ Somewhat Satisfied
	+ Neutral
	+ Somewhat Unsatisfied
	+ Very Unsatisfied
* **Result Clarity (Page 3)**: How clear were the search results? Select all that apply:
	+ Clear
	+ Somewhat Clear
	+ Somewhat Unclear
	+ Unclear
* **Search Results (Page 4)**: If you performed the search on a specific date, please enter the date in the format MM/DD/YY.
* **Search Time (Page 5)**: How much time did you spend searching? Please use a 24-hour clock format (HH:MM).
* **Search Quality (Page 6)**: Please provide a brief description of the search quality experience.
* **Additional Comments (Page 7)**: If you have any additional comments or observations, please share them here.
