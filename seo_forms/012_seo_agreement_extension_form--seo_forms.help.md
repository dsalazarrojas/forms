# seo-agreement-extension-form - Help Guide
## Purpose
This form is used to manage and track agreements with clients, including extension requests, approvals, and other related information.

## How To Complete This Form
1. Fill in the required fields, such as Client Name, Client Agreement Date, Reviewer Approval Date, Agreement Duration, Agreement Date, and Agreement Extension Date.
2. Enter the relevant information for each field, following the instructions provided for each field.
3. Select the correct options for Status, Agreement Extension Status, and other select type fields as necessary.

## Field-by-Field Explanation
* **Client Name** (`seo_agreement_extension_form`): The client's name who the agreement is with.
	+ This is the name of the client that you are creating an agreement with.
	+ Please enter the client's full name, as it appears in your records.
* **Client Agreement Date** (`seo_agreement_extension_form_client_agreement_date`): The date the client agreement was created.
	+ This is the date you created the initial agreement with the client.
	+ Please enter the date in the correct format (mm/dd/yyyy).
* **Client Approval Date** (`seo_agreement_extension_form_client_approval_date`): The date the client approved the agreement.
	+ This is the date the client approved the terms of the agreement.
	+ Please enter the date in the correct format (mm/dd/yyyy).
* **Client Agreement Version** (`seo_agreement_extension_form_client_agreement_version`): The version of the client agreement.
	+ This indicates the current version of the agreement with the client.
	+ Please enter the version number as it appears in your records.
* **Client Contract URL** (`seo_agreement_extension_form_client_contract_url`): The URL of the client's contract.
	+ This is the URL where the client's contract can be accessed.
	+ Please enter the URL as it appears in your records.
* **Contract File** (`seo_agreement_extension_form_contract_file`): An optional file associated with the client's contract.
	+ This is an optional field for uploading a file related to the client's contract.
	+ Please upload any relevant file as necessary.
* **Reviewer Name** (`seo_agreement_extension_form_reviewer_name`): The name of the reviewer who approved the agreement.
	+ This is the name of the person who reviewed and approved the agreement.
	+ Please enter the reviewer's full name.
* **Reviewer Role** (`seo_agreement_extension_form_reviewer_role`): The role of the reviewer who approved the agreement.
	+ This indicates the role of the person who reviewed and approved the agreement.
	+ Please select the correct role as it appears in your records.
* **Reviewer Approval Date** (`seo_agreement_extension_form_reviewer_approval_date`): The date the reviewer approved the agreement.
	+ This is the date the reviewer approved the agreement.
	+ Please enter the date in the correct format (mm/dd/yyyy).
* **Reviewer Comments** (`seo_agreement_extension_form_reviewer_comments`): The comments provided by the reviewer.
	+ This is the feedback or comments provided by the reviewer.
	+ Please enter any relevant comments.
* **Status** (`seo_agreement_extension_form_status`): The status of the agreement.
	+ This indicates the current status of the agreement.
	+ Please select the correct status from the options provided.
* **Extension Status** (`seo_agreement_extension_form_status_2`): The status of the agreement extension.
	+ This indicates the current status of the agreement extension.
	+ Please select the correct status from the options provided.
* **Comments** (`seo_agreement_extension_form_comments`): Optional comments about the agreement.

* **Extensions** (`seo_agreement_extension_form_extensions`): The number of extensions applied to the agreement.

* **Agreement Duration** (`seo_agreement_extension_form_agreement_duration`): The duration of the agreement.

* **Agreement Date** (`seo_agreement_extension_form_agreement_date`): The date the agreement was created.
