# digital_seo_referral_form - Help Guide
## Purpose
The digital_seo_referral_form is used to collect information from partners and clients about SEO referrals.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the referral source from the provided options.
2. Enter the partner's name and email address if they are not provided separately.
3. Enter any relevant project details and description.
4. Provide any additional notes for follow-up purposes.
5. Indicate the status of the referral, if applicable.

## Field-by-Field Explanation
* **Referral Source** (Select One, Optional): This field is used to select the source of the referral (e.g., Agency, Consultant, Other).
* **Partner Name** (Text, Optional): Enter the name of the partner who referred the project.
* **Partner Email** (Email, Optional): Enter the email address of the partner who referred the project.
* **Client Name** (Text, Optional): Enter the name of the client associated with the referral.
* **Project Details** (Note, Optional): Enter any relevant details about the project, such as the project type or scope.
* **Project URL** (Text, Optional): Enter the URL of the project or a related webpage.
* **Project Description** (Text, Optional): Enter a brief description of the project.
* **Partner Phone** (Text, Optional): Enter the phone number of the partner who referred the project.
* **Follow-up Note** (Note, Optional): Enter any additional notes for follow-up purposes.
* **Referral Status** (Select Multiple, Optional): Select the current status of the referral (e.g., Active, Inactive, Lost).

## Tips
* Please ensure that the information you enter is accurate and up-to-date.
* Review the referral source to ensure it matches the actual source of the project.
* Use the project details field to provide as much information as possible about the project.
* Select the correct status for the referral.
* If any additional notes are required, use the follow-up note field to provide further context.
