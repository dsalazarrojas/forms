# Category and Taxonomy Term Order Request Form - Help Guide
## Purpose
This form is for users to request changes to their website's category and taxonomy structures. Fill out this form to submit a request for changes to your site's taxonomy terms.

## How To Complete This Form
1. Fill out the form with your information and details about the changes you're requesting.
2. Select the correct options for each field, and provide as much relevant information as possible.
3. Be sure to review your submission before submitting it.

## Field-by-Field Explanation
* **Requester Name** (`requester_name`, text, required): This field is for your full name. Please enter it so we can reach out to you for any follow-up questions.
* **Email Address** (`email`, email, required): Enter your email address so we can contact you about your request.
* **Department** (`department`, select_one, required): Select your department from the options provided.
* **Request Date** (`request_date`, date, required): Enter the date of your request.
* **Priority Level** (`priority`, select_one, required): Choose how urgent your request is.
* **Taxonomy Type** (`taxonomy_type`, select_one, required): Select the type of taxonomy that needs changes.
* **Affected Website Section** (`affected_section`, select_one, required): Choose which part of the site will be affected.
* **Current Order** (`current_order`, text, required): Enter the current order of the terms.
* **Requested Order** (`requested_order`, text, required): Enter the desired order of the terms.
* **Terms to Add** (`terms_to_add`, text, optional): If you're adding new terms, enter them here.
* **Terms to Remove** (`terms_to_remove`, text, optional): If you're removing terms, list them here.
* **Terms to Rename** (`terms_to_rename`, text, optional): If you're renaming terms, list them here.
* **Parent-Child Relationship Changes** (`parent_child_changes`, text, optional): Describe any changes to the hierarchy.
* **SEO Impact Assessment** (`seo_impact`, select_one, required): Consider the SEO implications and select the correct option.
* **URL Redirects Needed** (`redirect_needed`, select_one, required): Determine if old URLs need redirects.
* **Affected URLs** (`affected_urls`, text, optional): List the URLs that will change.
* **Stakeholder Approval** (`stakeholder_approval`, select_one, required): Ensure stakeholders have approved this change.
* **Approver Name** (`approver_name`, text, optional): If applicable, enter the approver's name.
* **Implementation Deadline** (`implementation_deadline`, date, optional): Enter a deadline for implementation.
* **Testing Required** (`testing_required`, select_one, required): Determine if testing is needed before launch.
* **Rollback Plan** (`rollback_plan`, select_one, optional): Consider if the change can be reverted if needed.
* **Additional Notes** (`additional_notes`, text, optional): Enter any other relevant information.
