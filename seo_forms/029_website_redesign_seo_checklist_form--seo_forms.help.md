# website_redesign_seo_checklist_form - Help Guide
## Purpose
This form is designed to collect information about a website redesign project, specifically for Search Engine Optimization (SEO) purposes. The goal is to gather relevant data to identify areas that need improvement and prioritize tasks for the redesign process.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the project name and URL in the corresponding fields.
2. Select the level of SEO issues you have identified (Minor, Major, or Critical).
3. Indicate the current workflow stage of the project (Planning, Design, Development, Launch, or Post-Launch).
4. Select the team members involved in the project (Agency, Client, or Internal).
5. (Optional) Provide additional comments if needed.
6. Enter the date and time you are submitting the form.

## Field-by-Field Explanation
### project_name (1)
* **project_name**: Enter the name of the website redesign project.

### project_url (2)
* **project_url**: Enter the URL of the website that needs redesign.

### SEO Issues (3)
* **SEOs Issues**: Select one of the following:
	+ **none**: No SEO issues have been identified.
	+ **minor**: Minor SEO issues are present, but do not significantly impact the website.
	+ **major**: Major SEO issues are present and need to be addressed.
	+ **critical**: Critical SEO issues are present and require immediate attention.

### Workflow Stage (4)
* **Workflow Stage**: Select one of the following:
	+ **planning**: The project is still in the planning stage.
	+ **design**: The design phase is currently underway.
	+ **development**: The development phase is currently active.
	+ **launch**: The website has been launched.
	+ **post-launch**: The website has been launched and maintenance is ongoing.

### Team (5)
* **Team**: Select team members involved in the project:
	+ **Agency**: Agency team members are working on the project.
	+ **Client**: Client team members are involved in the project.
	+ **Internal**: Internal team members are working on the project.

### Additional Comments (6)
* **Additional Comments**: (Optional) Enter any additional comments or concerns.

### Date (7)
* **Date**: Enter the date you are submitting this form.

### Time (8)
* **Time**: Enter the time you are submitting this form.

### Comments (9)
* **Comments**: (Optional) Enter any additional comments.

### Email (10)
* **Email**: (Optional) Enter your email address for further correspondence.
