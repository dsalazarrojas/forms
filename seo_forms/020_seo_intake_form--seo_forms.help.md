# SEO Intake Form - Help Guide
## Purpose
This form is used to gather information about new projects and clients for the purpose of onboarding, tracking, and communication. Please fill out this form thoroughly to ensure that all necessary details are captured.

## How To Complete This Form
1. Ensure you are filling out the form for the correct purpose (new project or new client).
2. Complete all required fields (marked with an asterisk \*).
3. Fill out the form as accurately and completely as possible.

## Field-by-Field Explanation
* **client** (`client`, text, \*): Enter the name of the client or project's title.
* **project** (`project`, text, ): Enter a brief description of the project (optional).
* **seo_service** (`seo_service`, select_one, \*): Select the type of SEO service required (e.g., "Service 1", "Service 2", "Service 3").
* **services** (`services`, select_multiple, ): List the services you require (e.g., "Yes", "No").
* **location** (`location`, text, \*): Enter the location related to the project (e.g., city, country, or region).
* **notes** (`notes`, note, \*): Add any additional notes about the project or client (required).
* **date_of_birth** (`date_of_birth`, date, ): Enter the expected completion date of the project (optional).
* **time_of_birth** (`time_of_birth`, time, ): Enter the expected completion time of the project (optional).
* **email** (`email`, email, \*): Enter the email address of the client or project manager.
* **phone** (`phone`, text, \*): Enter the phone number of the client or project manager.
* **address** (`address`, text, ): Enter the address of the client or project manager (optional).
* **website** (`website`, text, ): Enter the website related to the project (optional).
* **contact_person** (`contact_person`, text, ): Enter the contact person's name (optional).
* **company** (`company`, text, ): Enter the company name related to the project (optional).
* **project_status** (`project_status`, select_one, \*): Select the project status (e.g., "Active", "Completed", "In Progress").
* **project_description** (`project_description`, text, \*): Enter a detailed description of the project.
* **project_manager** (`project_manager`, text, ): Enter the project manager's name (optional).
* **project_deadline** (`project_deadline`, date, ): Enter the project deadline (optional).
* **project_deadline_time** (`project_deadline_time`, time, ): Enter the project deadline time (optional).
* **project_deadline_date** (`project_deadline_date`, date, ): Enter the project deadline date (optional).
* **services_offered** (`services_offered`, text, ): Enter the services offered (optional).
* **services_requested** (`services_requested`, text, ): Enter the services requested (optional).
* **services_cost** (`services_cost`, text, ): Enter the services cost (optional).
* **services_price** (`services_price`, text, ): Enter the services price (optional).
* **services_terms** (`services_terms`, text, ): Enter the services terms (optional).
