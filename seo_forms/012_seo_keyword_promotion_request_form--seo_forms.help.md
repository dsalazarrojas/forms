# seo_keyword_promotion_request_form - Help Guide
## Purpose
The purpose of this form is to submit a request for SEO keyword promotion. Please fill out the form completely and accurately to expedite the process.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in your **Name** in the text field.
2. Enter your **Email** address in the email field.
3. If available, provide your **Phone** number.
4. Enter the **Keyword** or phrase you want to promote.
5. Enter the **Target URL** related to the keyword.
6. Select up to multiple **Keywords** from the dropdown options (e.g., Keyword 1, Keyword 2, Keyword 3).
7. Choose the **Keyword Type** from the dropdown options (e.g., Type 1, Type 2).
8. Describe the **Reason** for promoting the keyword.
9. Choose the **Date** when the keyword promotion should be completed or reviewed.
10. Select the **Status** of the request (e.g., In Progress, Completed, Rejected).
11. Select the **Assigned User** who will handle the request.

## Field-by-Field Explanation

* **Name**: Please enter your name for reference purposes.
* **Email**: Enter your email address for contact and verification purposes.
* **Phone**: If you have a phone number, please enter it for further contact.
* **Keyword**: Enter the keyword or phrase you want to promote.
* **Target URL**: Enter the URL related to the keyword for further context.
* **Keywords**: Select up to multiple keywords from the dropdown options to promote.
* **Keyword Type**: Choose the type of keyword promotion (e.g., Type 1, Type 2).
* **Reason**: Describe the reason for promoting the keyword.
* **Date**: Choose the date when the keyword promotion should be completed or reviewed.
* **Status**: Select the status of the request (e.g., In Progress, Completed, Rejected).
* **Assigned User**: Select the user who will handle the request.

Note: Please ensure that you're completing the form accurately and not duplicating existing requests. If you have any questions or concerns, please contact the assigned user or your supervisor.
