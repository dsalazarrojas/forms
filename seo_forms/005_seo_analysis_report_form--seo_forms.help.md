# SEO Analysis Report Form - Help Guide
## Purpose

This form is designed to collect information about a website's search engine optimization (SEO) analysis. The information collected will help SEO analysts evaluate and improve a website's visibility and ranking on search engines.

## How To Complete This Form

1. To complete this form, follow the steps below.
2. Fill in each field as prompted, making sure to provide accurate information.
3. Review your submission carefully before submitting it for analysis.

## Field-by-Field Explanation

* **Form Name** (`form_name`, text, optional): Enter the name of the website being analyzed.
* **Website Performance** (`website_performance`, number, optional): Enter a numerical value representing the website's performance.
* **Meta Tags** (`meta_tags`, text, optional): Enter the meta tags used on the website.
* **Meta Description** (`meta_description`, text, optional): Enter a brief description of the website.
* **Header Tags** (`header_tags`, text, optional): Enter the header tags used on the website.
* **Content** (`content`, select_one, optional): Select the type of content the website provides.
	+ Options: Option 1, Option 2, Option 3
* **Keywords** (`keywords`, text, optional): Enter the keywords used on the website.
* **Description** (`description`, select_multiple, optional): Select multiple descriptions that apply to the website.
	+ Options: Option 1, Option 2, Option 3
* **Meta Keywords** (`meta_keywords`, text, optional): Enter any meta keywords used on the website.
* **Header Tags 2** (`header_tags_2`, text, optional): Enter any additional header tags used on the website.
* **Header Tags 3** (`header_tags_3`, text, optional): Enter any further header tags used on the website.
* **Footer Tags** (`footer_tags`, text, optional): Enter the footer tags used on the website.
* **Image Tags** (`image_tags`, text, optional): Enter any image tags used on the website.
* **Image Tags 2** (`image_tags_2`, text, optional): Enter any further image tags used on the website.
* **Alt Tags** (`alt_tags`, text, optional): Enter any alt tags used on the website.
* **Alt Tags 2** (`alt_tags_2`, text, optional): Enter any further alt tags used on the website.
* **Robots Tags** (`robots_tags`, text, optional): Enter any robots tags used on the website.
* **Internal Links** (`internal_links`, select_one, optional): Select the type of internal links used on the website.
	+ Options: Option 1, Option 2, Option 3

Note: The fields marked as `optional` are not required for submission, but they are included for completeness and potential use in the analysis.
