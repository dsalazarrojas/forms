# Startup Pitch Event Leave Form - Help Guide
## Purpose
The Startup Pitch Event Leave Form is designed to collect information about a specific event, ensuring that it's properly scheduled and organized.

## How To Complete This Form
1. Start by filling in the **Event Name** field with the exact name of the event, as designated by the organizing team.
2. Enter the **Start Date** and **End Date** of the event, including the year, month, and date in the format `YYYY-MM-DD`.
3. Select the correct **Event Type** from the given options (Pitch Event, Meetup Event, Conference Event) that best describes the event.
4. Enter the **Start Time** and **End Time** of the event in 24-hour format.
5. If applicable, enter the **Event Location** in text format.
6. Select the **Team Member** involved in the event from the given options (Development Team, Sales Team).
7. Choose the **Approver** who will be handling the request from the given options (Manager, Director).
8. Set the **Approval Status** of the event (Approved, Rejected, Pending) to indicate the current status.
9. If necessary, add **Notes** for further comments or clarification.

## Field-by-Field Explanation

* **Event Name** (`event_name`, required): A clear and concise name of the event.
* **Start Date** (`start_date`, required): Date the event begins, following `YYYY-MM-DD` format.
* **End Date** (`end_date`, required): Date the event ends, following `YYYY-MM-DD` format.
* **Reason** (`reason`, required): Briefly describe the purpose of the event or why it's being requested.
* **Start Time** (`start_time`, required): Event start time in 24-hour format.
* **End Time** (`end_time`, required): Event end time in 24-hour format.
* **Event Location** (`event_location`, optional): The physical or virtual location where the event takes place.
* **Event Type** (`event_type`, required): The type of event (Pitch Event, Meetup Event, Conference Event).
* **Event Details** (`event_details`, optional): Any additional comments or information about the event.
* **Team Member** (`team_member`, required): Team members participating in the event (Development Team, Sales Team).
* **Approver** (`approver`, required): The person responsible for handling the event request (Manager, Director).
* **Approval Status** (`approval_status`, optional): Current status of the event (Approved, Rejected, Pending).
* **Approved Date** (`approved_date`, optional): Date the event was approved or denied.
* **Notes** (`notes`, optional): Additional comments or clarification about the event.
