# Family Reunion Leave Of Absence Request - Help Guide
## Purpose
The Family Reunion Leave Of Absence Request form is a formal application for employees to request time off for family reunions. This form is used to request approval for leave of absence from work for a specified period.

## How To Complete This Form
- Click on the "Start" button to begin filling out the form.
- Enter your name and ID in the "Employee Name" field. This is the name of the employee requesting leave.
- Enter the name of the manager to review and approve this request.
- Enter the start date of your absence in the "Dates Off" field. This should be the date you plan to start your leave.
- Enter the end date of your absence in the "Dates Back" field. This should be the date you plan to return to work.
- Provide a brief description of the family reunion in the "Reunion Description" field. This should include details about the reunion, such as the location and the number of family members attending.
- Enter the start date of the family reunion in the "Dates Reunion" field.
- Enter the duration of the family reunion in the "Duration Reunion" field. This should be the number of days or weeks you plan to be off.
- Enter the total number of days off in the "Total Days Off" field. This should be calculated based on the duration of the reunion and your work schedule.
- Enter the number of family members attending the reunion in the "Family Members Off" field. This should be an estimate of how many family members will be joining you for the reunion.
- Select a duration for the "Manager Review" field, which is the time it takes for your manager to review your request. Please note that this is not required but recommended for a smooth process.

## Field-by-Field Explanation
- **Form Title** (`form_title`, `text`, optional): A brief title for your leave request.
  * This field is not required but can be used to distinguish between different requests.
- **Employee Name** (`employee_name`, `text`, optional): The name of the employee requesting leave.
  * This field is required for identification and approval purposes.
- **Manager Name** (`manager_name`, `text`, optional): The name of the manager reviewing and approving this request.
  * This field is required for manager review and approval purposes.
- **Dates Off** (`dates_off`, `date`, optional): The start date of your absence.
  * Please enter the date you plan to start your leave in the format YYYY-MM-DD.
- **Dates Back** (`dates_back`, `date`, optional): The end date of your absence.
  * Please enter the date you plan to return to work in the format YYYY-MM-DD.
- **Dates Reunion** (`dates_reunion`, `date`, optional): The start date of the family reunion.
  * This should be the date of the family reunion, which may not be the same as your start date of absence.
- **Duration Reunion** (`duration_reunion`, `number`, optional): The duration of the family reunion in days or weeks.
  * Please enter the number of days or weeks you plan to be off for the reunion.
- **Total Days Off** (`total_days_off`, `number`, optional): The total number of days off requested.
  * This should be calculated based on the duration of the reunion and your work schedule.
- **Reunion Description** (`reunion_description`, `text`, optional): A brief description of the family reunion.
  * This field should include details about the reunion, such as location and number of family members attending.
- **Family Members Off** (`family_members_off`, `text`, optional): The number of family members attending the reunion.
  * This field is used to estimate the number of family members that will be joining you for the reunion.
- **Manager Review** (`manager_review`, `time`, optional): The duration for the manager review.
  * Please note that this is not required but recommended for a smooth process.
