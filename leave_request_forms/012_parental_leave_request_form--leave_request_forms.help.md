# parental_leave_request_form - Help Guide
## Purpose
This form is for requesting parental leave, which includes maternity, patery, and other family-related leaves. It is used to collect information from employees about their leave request, including details, dates, and status updates.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the "Leave Reason" field with a brief description of your request.
2. Enter the start and end dates of your leave in the "Start Date" and "End Date" fields, respectively.
3. Specify the duration of your leave in the "Leave Duration" field.
4. Choose the type of leave you are requesting from the available options (Parental Leave, Adoption Leave).
5. Select the status of your request from the options (Open, In Progress, Approved, Disapproved).
6. Choose whether to approve or disapprove the request from the options (Approve, Disapprove).
7. Add any additional comments or notes in the "Manager Approval Note" and "Manager Comment" fields.

## Field-by-Field Explanation
* **Leave Reason** (Leave Reason, text, required): A brief description of your leave request.
* **Start Date** (Start Date, date, required): The date when your leave will start.
* **End Date** (End Date, date, required): The date when your leave will end.
* **Leave Duration** (Parental Leave Duration, number, required): The length of your leave, in days or weeks.
* **Leave Type** (Leave Type, select_one, required): Choose the type of leave you are requesting (Parental Leave, Adoption Leave).
* **Leave Type Details** (Leave Type Details, text, optional): Add any additional information about the type of leave you are requesting.
* **Leave Request Status** (Leave Request Status, select_one, required): Select the status of your request (Open, In Progress, Approved, Disapproved).
* **Manager Approval** (Manager Approval, select_one, required): Choose whether to approve or disapprove the request.
* **Request Date** (Request Date, date, optional): The date and time of the request.
* **Manager Comment** (Manager Comment, text, optional): Add any additional comments for the manager.
* **Employee Comment** (Employee Comment, text, optional): Add any additional comments for the employee.
* **Manager Approval Note** (Manager Approval Note, text, optional): Add any additional comments for the manager.
* **Approval Status** (Approval Status, select_one, required): Select the final status of the request (Approved, Disapproved).
* **Comments** (Comments, text, optional): Add any additional comments.
* **Attachment** (Attachment, text, optional): Attach a file for the manager to review.
* **Attachment Name** (Attachment Name, text, optional): Attach a file and add a name for it.
* **Attachment Comment** (Attachment Comment, text, optional): Add any comments for the attachment.
