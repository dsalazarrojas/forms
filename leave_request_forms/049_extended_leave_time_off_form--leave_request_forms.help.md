# Extended Leave Time-Off Form - Help Guide
## Purpose
The Extended Leave Time-Off Form is used to request leave for a period, allowing employees to submit their requests in a structured manner.

## How To Complete This Form
To complete this form, please follow these steps:

1. Select the type of leave you are requesting (e.g. Annual Leave, Sick Leave, etc.)
2. Enter the start and end dates of your leave period
3. Provide a brief reason for your leave request
4. If applicable, indicate if this is an extended leave and the duration of your leave
5. Choose whether you have leave frequency options (e.g. Yes, No)
6. Select your desired approval status (Active, Inactive)
7. Enter any comments from your manager regarding your leave request

## Field-by-Field Explanation
* **Leave Request Form**: This is the main form to enter your leave request details.
	+ `required`: False (Not required)
	+ Type: Text (`leave_request_form`)
* **Extended Leave Type**: Select the type of leave you are requesting.
	+ `required`: False
	+ Options: Annual, Sick Leave, Vacation, Emergency Leave
* **Start Date**: Enter the start date of your leave period.
	+ `required`: False
	+ Type: Date
* **End Date**: Enter the end date of your leave period.
	+ `required`: False
	+ Type: Date
* **Reason**: Enter a brief reason for your leave request.
	+ `required`: False
	+ Type: Text
* **Return Date**: Enter the date you plan to return from leave.
	+ `required`: False
	+ Type: Date
* **Leave Duration**: If this is an extended leave, enter the duration in days.
	+ `required`: False
	+ Type: Number
* **Leave Frequency**: Check if you have leave frequency options.
	+ `required`: False
	+ Options: Yes, No
* **Approval Status**: Select your desired approval status.
	+ `required`: False
	+ Options: Active, Inactive
* **Manager Comment**: Enter any comments from your manager regarding your leave request.
	+ `required`: False
	+ Type: Note
