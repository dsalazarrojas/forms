# Unpaid Leave Request Form - Help Guide
## Purpose

The Unpaid Leave Request Form is used by employees to request unpaid leave from their manager. This form is used to gather necessary information to process the request accurately and efficiently.

## How To Complete This Form

To complete this form, please follow these steps:

1.  Fill in the Request Details section with a brief explanation of your leave request.
2.  Enter the Start Date and End Date of your leave request.
3.  Provide a valid Reason for your leave request.
4.  Select the Manager Approval option that best suits your request.
5.  Choose the Approval Status option that reflects the current status of your request.
6.  Enter any Employee Comment or Manager Comment if necessary.
7.  Enter the Leave Start Date and Leave End Date if applicable.
8.  Specify the number of Days Off you wish to take.
9.  Select the Leave Type that best describes your reason for leave.
10.  Choose the Manager Request option that best suits your manager's requirements.
11.  Enter any Manager Request Details if necessary.
12.  Enter your Employee Request.
13.  Specify the Leave Duration if applicable.
14.  Choose the Manager Approval Date if the request has been approved.
15.  Enter the Manager Denial Reason if the request has been denied.

## Field-by-Field Explanation

*   **Request Details** (`Request Details`, `text`, required): This field is used to provide a brief explanation of your leave request. Please enter a clear and concise description of your reasons for requesting unpaid leave.
*   **Start Date** (`Start Date`, `date`, required): This field is used to enter the start date of your leave request. Please ensure that this date is accurate and in the correct format (MM/DD/YYYY).
*   **End Date** (`End Date`, `date`, required): This field is used to enter the end date of your leave request. Please ensure that this date is accurate and in the correct format (MM/DD/YYYY).
*   **Reason** (`Reason`, `text`, required): This field is used to provide a valid reason for your leave request. Please enter a clear and concise explanation.
*   **Manager Approval** (`Manager Approval`, `select_one`, required): This field is used to select the manager's approval status. Please choose the option that best suits your request.
*   **Approval Status** (`Approval Status`, `select_one`, required): This field is used to select the current status of your request. Please choose the option that best describes the current status.
*   **Employee Comment** (`Employee Comment`, `text`, required): This field is used to enter any comments or feedback from the employee. Please enter any additional information that may be helpful for the manager's reference.
*   **Manager Comment** (`Manager Comment`, `text`, required): This field is used to enter any comments or feedback from the manager. Please enter any additional information that may be helpful for the employee's reference.
*   **Leave Start Date** (`Leave Start Date`, `date`, required): This field is used to enter the start date of your leave in the format (MM/DD/YYYY). Please ensure that this date is accurate.
*   **Leave End Date** (`Leave End Date`, `date`, required): This field is used to enter the end date of your leave in the format (MM/DD/YYYY). Please ensure that this date is accurate.
*   **Days Off** (`Days Off`, `number`, required): This field is used to specify the number of days you wish to take for your leave. Please enter a whole number.
*   **Leave Type** (`Leave Type`, `select_one`, required): This field is used to select the type of leave you are requesting. Please choose the option that best describes your reason for leave.
*   **Manager Request** (`Manager Request`, `select_one`, required): This field is used to select the manager's request. Please choose the option that best suits your manager's requirements.
*   **Manager Request Details** (`Manager Request Details`, `text`, required): This field is used to enter any manager's request details. Please enter any additional information that may be helpful for the employee's reference.
*   **Employee Request** (`Employee Request`, `text`, required): This field is used to enter any employee's request. Please enter any additional information that may be helpful for the manager's reference.
*   **Leave Duration** (`Leave Duration`, `number`, required): This field is used to specify the duration of your leave in days. Please enter a whole number.
*   **Manager Approval Date** (`Manager Approval Date`, `date`, required): This field is used to enter the date the manager approved your request. Please ensure that this date is accurate and in the correct format (MM/DD/YYYY).
*   **Manager Denial Reason** (`Manager Denial Reason`, `text`, required): This field is used to enter the manager's reason for denying your request. Please enter a clear and concise explanation.
*   **Employee Signature** (`Employee Signature`, `text`, required): This field is used to enter your signature. Please ensure that your signature is accurate and in the correct format.
