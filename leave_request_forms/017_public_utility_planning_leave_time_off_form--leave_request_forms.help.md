# Public Utility Planning Leave Time Off Form - Help Guide
## Purpose
The Public Utility Planning Leave Time Off Form is used to request leave for public utility planning purposes. This form helps employees communicate their leave needs to the management and ensures that their requests are processed smoothly.

## How To Complete This Form
To complete this form, follow these steps:
1. Fill in the employee name and job title fields.
2. Select the start and end dates of your leave.
3. Provide a reason for your leave.
4. Choose the relevant options from the select_one and select_multiple fields.
5. Enter your email and phone number (if applicable).
6. Provide any additional notes or comments.
7. Review and submit the form to complete the process.

## Field-by-Field Explanation
* **form_title**: This is the title of the leave request.
	+ Type: text
	+ Required: No
* **employee**: This is the name of the employee submitting the leave request.
	+ Type: text
	+ Required: No
* **job_title**: This is the job title of the employee submitting the leave request.
	+ Type: text
	+ Required: No
* **leave_start_date**: This is the start date of the leave.
	+ Type: date
	+ Required: No
* **leave_end_date**: This is the end date of the leave.
	+ Type: date
	+ Required: No
* **reason**: This is the reason for the leave request.
	+ Type: text
	+ Required: No
* **select_one**: This field allows you to select one option from the available choices.
	+ Type: select_one
	+ Required: Yes
* **select_multiple**: This field allows you to select multiple options from the available choices.
	+ Type: select_multiple
	+ Required: Yes
* **email**: This is the email address of the employee.
	+ Type: email
	+ Required: No
* **phone**: This is the phone number of the employee.
	+ Type: text
	+ Required: No
* **note**: This is an optional note field for any additional comments.
	+ Type: note
	+ Required: No
