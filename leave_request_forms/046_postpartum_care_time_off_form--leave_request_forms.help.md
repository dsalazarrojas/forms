# Postpartum Care Time Off Form - Help Guide
## Purpose
This form is used to request postpartum care time off for employees.

## How To Complete This Form
To complete this form, follow these steps:

1. Select "Yes" or "No" to indicate whether you are requesting postpartum care time off.
2. If you are requesting postpartum care time off, select the start date for your postpartum care period.
3. If necessary, select the end date for your postpartum care period.
4. If you have a return to work date, select it.
5. Provide a brief reason for your request.
6. If your manager has any comments, type them in the "Manager Comments" field.
7. Select which manager(s) will be approving your request.
8. Select which department(s) will be approving your request.

## Field-by-Field Explanation
* **Request Postpartum Care Time Off** (1, select_one, required/optional): 
  This field asks if you are requesting postpartum care time off. Select "Yes" to indicate that you are requesting postpartum care time off.
* **Postpartum Care Start Date** (2, date, required/optional): 
  This field is used to select the start date of your postpartum care period.
* **Postpartum Care End Date** (3, date, required/optional): 
  This field is used to select the end date of your postpartum care period.
* **Return To Work Date** (4, date, required/optional): 
  This field is used to select the date you plan to return to work.
* **Reason For Request** (5, text, required/optional): 
  This field is used to provide a brief explanation for your request.
* **Manager Comments** (6, text, required/optional): 
  This field is used to provide any comments from your manager regarding your request.
* **Manager Approvals** (7, select_one, required/optional): 
  This field is used to select which manager(s) will be approving your request.
* **Department Approval** (8, select_multiple, required/optional): 
  This field is used to select which department(s) will be approving your request.

## Tips
- Ensure you are selecting the correct dates for your postpartum care period.
- Make sure to provide a clear and concise reason for your request.
- Select the correct manager(s) and department(s) to ensure proper approval.
- If your manager has any comments, be sure to address them in your response.
