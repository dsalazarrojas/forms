# Media Investigative Leave Of Absence Request - Help Guide
## Purpose
The Media Investigative Leave of Absence Request form is used to notify the organization of a media investigator's leave of absence. This form helps to keep track of the investigator's status and ensures that necessary approvals and communications are made with the right personnel.

## How To Complete This Form
1. Fill out the form accurately and completely.
2. Provide the necessary information for your leave of absence.
3. Select the correct options from the dropdown menus for your request.
4. Double-check your information before submitting the form.

## Field-by-Field Explanation
* **Media Investigative Leave Request Form** (`media_investigative_leave_request_form`): A form to request media investigative leave of absence.
* **Media Investigative Leave Date From** (`media_investigative_leave_date_from`): The date you wish to start your leave from.
* **Media Investigative Leave To Date** (`media_investigative_leave_to_date`): The date you wish to end your leave on.
* **Media Investigative Leaving Organisations** (`media_investigative_leaving_organisations`): A select multiple option for whether you are leaving or not. Please select 'Yes' if you are leaving.
* **Media Investigative Organisations** (`media_investigative_organisations`): A select one option for whether you are working on or off site. Please select 'Yes' if you are working on site.
* **Media Investigative Leave Reason** (`media_investigative_leave_reason`): A text field for the reason of your leave.
* **Media Investigative Leave Requesting Manager** (`media_investigative_leave_requesting_manager`): A select multiple option for who is requesting your leave. Please select 'Yes' if your manager is requesting your leave.
* **Media Investigative Leave Requesting Managers** (`media_investigative_leave_requesting_managers`): A select one option for who is requesting your leave. Please select 'Yes' if your manager is requesting your leave.
* **Media Investigative Leave Requesting Manager Organisation** (`media_investigative_leave_requesting_manager_organisation`): A select one option for who is requesting your leave. Please select 'Yes' if your manager's organisation is requesting your leave.
* **Media Investigative Leave Requesting Manager Organisation ID** (`media_investigative_leave_requesting_manager_organisation_id`): A numeric field for the ID of the requesting manager's organisation.
* **Media Investigative Leaving Manager ID** (`media_investigative_leaving_manager_id`): A select one option for who is leaving. Please select 'Yes' if you are leaving.
* **Media Investigative Leave Requesting Manager Email** (`media_investigative_leave_requesting_manager_email`): An email field for the email of the requesting manager.
* **Media Investigative Leaving Manager Mobile Number** (`media_investigative_leaving_manager_mobile_number`): A text field for the mobile number of the leaving manager.
* **Media Investigative Leaving Manager Work Number** (`media_investigative_leaving_manager_work_number`): A text field for the work number of the leaving manager.
* **Media Investigative Leaving Manager Work Extension** (`media_investigative_leaving_manager_work_extension`): A numeric field for the work extension of the leaving manager.
* **Media Investigative Leave Requesting Manager Start Time** (`media_investigative_leave_requesting_manager_start_time`): A time field for the start time of the requesting manager's availability.
* **Media Investigative Leave Requesting Manager End Time** (`media_investigative_leave_requesting_manager_end_time`): A time field for the end time of the requesting manager's availability.
* **Media Investigative Leave Requesting Manager Start Date** (`media_investigative_leave_requesting_manager_start_date`): A date field for the start date of the requesting manager's availability.
* **Media Investigative Leave Requesting Manager End Date** (`media_investigative_leave_requesting_manager_end_date`): A date field for the end date of the requesting manager's availability.
* **Media Investigative Leaving Manager Notes** (`media_investigative_leaving_manager_notes`): A note field for any additional notes from the leaving manager.
* **Media Investigative Leaving Manager Requesting** (`media_investigative_leaving_manager_requesting`): A select one option for whether the manager is requesting your leave. Please select 'Yes' if the manager is requesting your leave.
* **Media Investigative Leaving Manager Approvals** (`media_investigative_leaving_manager_approvals`): A select one option for whether the manager has approvals. Please select 'Yes' if the manager has approvals.
* **Media Investigative Leaving Manager Approvals Date** (`media_investigative_leaving_manager_approvals_date`): A date field for the date of the manager's approvals.
* **Media Investigative Leaving Manager Approvals Reason** (`media_investigative_leaving_manager_approvals_reason`): A text field for the reason of the manager's approvals.
* **Media Investigative Leaving Manager Approvals Notes** (`media_investigative_leaving_manager_approvals_notes`): A note field for any additional notes from the manager's approvals.
