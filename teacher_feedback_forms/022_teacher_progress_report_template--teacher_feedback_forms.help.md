# Teacher Progress Report Template - Help Guide
## Purpose
The purpose of this form is to provide a template for teachers to report on student progress. This template captures information on student progress, subject, comments, and teacher comments, allowing teachers to provide a comprehensive overview of a student's performance.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the relevant subject for the student's progress report.
2. Enter the student's progress report in the designated text area.
3. Add any comments or feedback you have for the student.

## Field-by-Field Explanation

* **Student Progress Report** (`student_progress`, text, optional):
	+ Use this field to enter a brief summary of the student's progress.
* **Subject** (`subject`, select_one, optional):
	+ Choose the subject area the student's progress report relates to.
* **Comments** (`comments`, text, optional):
	+ Enter any additional comments or feedback you have for the student.
* **Teacher Comments** (`teacher_comments`, text, optional):
	+ Use this field to provide your overall comments on the student's performance.
* **Teacher Comments** (`teacher_comments`, text, optional):
	+ Enter any further comments or feedback you have for the student.
