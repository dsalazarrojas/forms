# Classroom Walkthrough Template - Help Guide
## Purpose
The Classroom Walkthrough Template is a tool designed to help observers/administrators document and provide feedback on a teacher's instruction and classroom environment. This guide will walk you through each section of the form, explaining the purpose and how to complete each field.

## How To Complete This Form
1.  Ensure that all required fields are completed.
2.  For each field, follow the provided instructions and guidelines.
3.  Be specific and accurate in your responses.
4.  Use the provided options as a reference for answering multiple-choice questions.
5.  If a field does not apply, select "Not Applicable" or provide a brief explanation in the text field.

## Field-by-Field Explanation

* **Observer/Administrator Name (2)**: Enter your name to associate it with the observation. This field is required.
* **Teacher Observed (3)**: Enter the teacher's name being observed. This field is required.
* **Grade Level and Subject (4)**: Enter the grade level and subject being observed. This field is required.
* **Date (5)**: Enter the date of the observation. This field is required.
* **Time (6)**: Enter the time of the observation. This field is required.
* **Duration of Observation (7)**: Enter the length of the observation in minutes. This field is optional.
* **Is the learning objective clearly posted? (9)**: Select "True" if the learning objective is clearly posted, "False" otherwise.
* **Student Engagement Level (10)**: Select the level of student engagement, which can be High (80-100% engaged), Moderate (50-80% engaged), or Low (less than 50% engaged). This field is required.
* **Instructional Strategies Observed (11)**: Select all the instructional strategies that were observed, such as Direct Instruction, Small Group Work, etc. This field is optional.
* **Classroom Management and Behavior (13)**: Select the level of classroom management and behavior, which can be Excellent - Seamless transitions, Effective - Occasional redirects, Developing - Frequent interruptions, or Needs Improvement - Significant disruption. This field is required.
* **Evidence of student learning displayed (14)**: Select the level of evidence of student learning displayed, which can be Current work displayed, Some work displayed, or No current work displayed. This field is required.
* **Praise - What was working well? (15)**: Enter a brief description of what was working well in the classroom.
* **Polish - Area for growth or consideration (16)**: Enter an area that the observer/administrator believes the teacher needs improvement. This field is optional.
* **Would you like to email this summary to the teacher? (17)**: Select "True" to email the summary to the teacher, or "False" otherwise. This field is required.
* **Follow-up meeting requested? (18)**: Select "True" if a follow-up meeting is requested, or "False" otherwise. This field is required.

Note: The provided fields are designed to gather specific information about the teacher's instruction and classroom environment. Be thorough and accurate in your responses to provide valuable feedback for teacher growth and development.
