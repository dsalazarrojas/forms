# Personal Training Waiver - Help Guide
## Purpose
This form is designed to collect personal information related to medical clearance and waiver for training purposes. It is intended to be filled out by individuals who are participating in training activities and need to provide their medical clearance and waiver information.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the form in a clear and legible handwriting.
2. Please answer all the questions truthfully and accurately.
3. If a field is not applicable, please fill it in with "N/A" or "Not Applicable".

## Field-by-Field Explanation

* **User Input** (1): This field is for the user to input their personal details.
* **Emergency Contact** (2): This field is for the user to input their emergency contact information.
* **Medical Clearance** (3): This field is for the user to input their medical clearance information.
* **Medical Condition** (4): This field is for the user to input any medical conditions they may have.
* **Waiver** (5): This field is for the user to input their waiver information.
* **Medical Procedure** (6): This field is for the user to input any medical procedures they may need to undergo.
* **Medical Test** (7): This field is for the user to input any medical tests they may need to undergo.
* **Training Agreement** (8): This field is for the user to input their training agreement information.
* **Emergency Contact 2** (9): This field is for the user to input additional emergency contact information.
* **Medical Clearance 2** (10): This field is for the user to input their second medical clearance information.

## Tips
* Please fill out the form carefully and accurately.
* If you are unsure about any field, please ask for clarification.
* This form is for your personal and private information, so please keep it confidential.
