# Crane Rental Application Form - Help Guide

## Purpose
This Crane Rental Application Form is designed to collect information for crane rental and operation purposes. It is a comprehensive form that helps us understand your project requirements and provide you with the best crane rental options.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill in the crane type you are interested in renting.
2. Provide details about the operating hours and days of the crane.
3. Complete the operating hours per day, start and end dates, and operating location information.
4. Enter the contact information for the operating location, including phone number, fax number, and email.
5. Provide details about the crane operator, including name and any relevant notes.
6. Specify the insurance details, if applicable.
7. Check the equipment condition and insurance coverage status.
8. Add any operating instructions or notes.

## Field-by-Field Explanation
Below is a field-by-field explanation of each section of the form:

* **crane_rental_details**: Enter a brief description of your project or task that requires crane rental.
* **crane_type**: Choose the crane type that best suits your needs.
* **crane_hours_of_operation**: Enter the total number of hours the crane will be in operation.
* **crane_days_of_operation**: Enter the total number of days the crane will be in operation.
* **crane_operating_hours**: Enter the number of hours the crane will be operating per day.
* **crane_operating_hours_per_day**: Enter the number of hours the crane will be operating per day.
* **crane_start_date**: Enter the start date of the crane's operation period.
* **crane_end_date**: Enter the end date of the crane's operation period.
* **crane_operating_location**: Enter the address of the operating location.
* **crane_operating_location_notes**: Enter any notes about the operating location.
* **crane_operating_address**: Enter the address of the operating location.
* **crane_operating_address_notes**: Enter any notes about the operating address.
* **crane_operating_location_city**: Enter the city of the operating location.
* **crane_operating_location_province**: Enter the province of the operating location.
* **crane_operating_location_postal_code**: Enter the postal code of the operating location.
* **crane_operating_location_phone**: Enter the phone number of the operating location.
* **crane_operating_location_fax**: Enter the fax number of the operating location.
* **crane_operating_location_email**: Enter the email address of the operating location.
* **crane_operator_name**: Enter the name of the crane operator.
* **crane_operator_phone**: Enter the phone number of the crane operator.
* **crane_operator_notes**: Enter any notes about the crane operator.
* **crane_insurance_details**: Enter any insurance details, if applicable.
* **crane_equipment_condition**: Check the condition of the equipment.
* **crane_insurance_coverage**: Indicate if insurance coverage is required.
* **crane_operating_instructions**: Enter any operating instructions or notes.

## Tips
- Please fill in all required fields accurately and thoroughly.
- If you are unsure about any field, please contact the designated contact person for clarification.
- Ensure that you have all necessary documents and details ready before submitting the form.
