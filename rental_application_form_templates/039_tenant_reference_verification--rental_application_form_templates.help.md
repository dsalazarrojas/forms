# Tenant Reference Verification - Help Guide
## Purpose
The Tenant Reference Verification form is used to verify a landlord's reference for a rental application. This form helps to gather information from a reference who has a personal relationship with the tenant, such as a family member or friend.

## How To Complete This Form
To complete this form, follow these steps:

1. Answer the questions truthfully and to the best of your ability.
2. If you have known the tenant for more than 5 years, select "Option 1" for the question "How many years have you known the tenant?"
3. If you have not met the tenant before, answer "Option 1" for "Have you ever met the tenant before".
4. If you do not have enough information to answer a question, select "Option 2" or "Unknown" (if available).

## Field-by-Field Explanation

* **Have you ever met the tenant before**: This question is used to confirm whether you have a personal relationship with the tenant.
* **How many years have you known the tenant**: Please answer this question based on your actual relationship with the tenant.
* **What was your experience with the tenant like**: Please provide a brief description of your experience with the tenant.
* **Do you know the tenant's employment history**: This question is used to gather information about the tenant's work history, which can be useful for making a decision.
	+ Option 1: Yes, I know the tenant's employment history.
	+ Option 2: No, I do not know the tenant's employment history.
	+ Option 3: Unsure.
* **What was the length of the tenancy**: This question is used to gather information about the tenant's tenancy length, which can be useful for making a decision.
* **Would you recommend the tenant**: This question is used to get your honest opinion about the tenant's suitability for renting a property.
	+ Option 1: Yes, I would highly recommend the tenant.
	+ Option 2: No, I would not recommend the tenant.
	+ Option 3: Neutral, I have mixed feelings.
* **Has the tenant ever committed a crime**: This question is used to gather information about any past criminal activity by the tenant. If you are unsure, select "Option 1".
* **Would you like to provide an email address for the tenant**: This question is used to gather an email address for the tenant. Please note that this is optional and not required. 

## Tips

* Please answer the questions truthfully and to the best of your ability.
* If you are unsure about any question, select the option that best represents your uncertainty.
* If you have any questions or concerns, please contact the property manager or landlord.
