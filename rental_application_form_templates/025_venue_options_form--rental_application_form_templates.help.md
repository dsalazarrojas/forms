# Venue Options Form - Help Guide
## Purpose
This form is designed to collect essential details about a venue for event hosting or rentals. Please complete the form to provide information about the venue's location, amenities, pricing, and contact details.

## How To Complete This Form
1. Select the "Event Location" page to start filling out the form.
2. Enter the venue's address in the "Address" field.
3. Select the "Venue Type" to indicate the type of venue (e.g., meeting room, conference center, outdoor space).
4. Enter the city and state where the venue is located.
5. Enter the zip code of the venue.
6. Select the payment term for the venue usage (e.g., Option 1, Option 2).
7. Enter the capacity of the venue.
8. List the indoor and outdoor amenities available at the venue (e.g., Option 1, Option 2, Option 3).
9. Select the payment method for the venue (e.g., Option 1, Option 2).
10. Enter the price of the venue.
11. Enter the contact person's name.
12. Enter the contact person's phone number.
13. Enter the contact person's email.
14. Enter the contact person's website (if applicable).
15. Enter any additional contact information for the contact person.
16. Enter any notes about the venue.
17. (Optional) Enter any parking fees associated with the venue.
18. (Optional) Enter any parking details about the venue.
19. (Optional) Enter any venue type details.
20. (Optional) Enter any payment details about the venue.
21. (Optional) Enter the venue's address again for verification.

## Field-by-Field Explanation

* **Event Location** (`report_page`, text, required): This field is for entering the event location where the venue is situated.
* **Venue Type** (`venue_type`, select_one, required): This field allows you to select the type of venue (e.g., meeting room, conference center, outdoor space).
* **Address** (`address`, text, required): Enter the address of the venue.
* **City** (`city`, text, required): Enter the city where the venue is located.
* **State** (`state`, text, required): Enter the state where the venue is located.
* **Zip** (`zip`, number, required): Enter the zip code of the venue.
* **Capacity** (`capacity`, text, required): Enter the maximum number of people that can be accommodated at the venue.
* **Indoor Amenities** (`indoor_amenities`, select_multiple, required): List the indoor amenities available at the venue (e.g., Option 1, Option 2, Option 3).
* **Outdoor Amenities** (`outdoor_amenities`, select_multiple, required): List the outdoor amenities available at the venue (e.g., Option 1, Option 2, Option 3).
* **Payment Method** (`payment_method`, select_one, required): Select the payment method for the venue usage (e.g., Option 1, Option 2).
* **Price** (`price`, number, required): Enter the price of the venue.
* **Contact Information** (`contact_information`, text, required): Enter any additional contact information for the contact person.
* **Contact Phone** (`contact_phone`, text, required): Enter the contact person's phone number.
* **Contact Email** (`contact_email`, email, required): Enter the contact person's email.
* **Contact Website** (`contact_website`, text, required): Enter the contact person's website (if applicable).
* **Contact Person** (`contact_person`, text, required): Enter the name of the contact person.
* **Contact Phone 2** (`contact_phone2`, text, required): Enter an additional contact person's phone number.
* **Cost** (`cost`, number, required): Enter the cost of the venue.
* **Payment Term** (`payment_term`, select_one, required): Select the payment term for the venue usage (e.g., Option 1, Option 2).
* **Notes** (`notes`, text, required): Enter any additional notes about the venue.
* **Parking Fees** (`parking_fees`, number, optional): Enter any parking fees associated with the venue.
* **Parking Details** (`parking_details`, text, optional): Enter any parking details about the venue.
* **Venue Type Details** (`venue_type_details`, text, optional): Enter any additional venue type details.
* **Payment Details** (`payment_details`, text, optional): Enter any additional payment details.
* **Venue Address** (`venue_address`, text, optional): Enter the venue's address again for verification.

## Tips

* Make sure to fill out all required fields.
* Double-check the entered information for accuracy.
* If you are unsure about any field, please contact us for clarification.
