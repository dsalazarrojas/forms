# Rental Standards Assessment - Help Guide
## Purpose
The Rental Standards Assessment form is designed to evaluate the standards of a rental property. It is meant to be completed by landlords or property managers to provide an overview of various aspects related to the property, including property details, landlord information, tenant information, property address, property type, property status, compliance ratings, inspection comments, additional comments, tenant status, property manager information, property owner information, and rental agreement.

## How To Complete This Form
To complete this form, follow these steps:

1. Begin by filling out the **Property Details** section with the relevant information about the property, including its address, type, and any other relevant details.
2. Provide information about the **Landlord Information** and **Tenant Information**, including any relevant contact details and status updates.
3. Enter the **Property Address** of the property being assessed.
4. In the **Property Type** section, select one of the options to indicate the type of property you are assessing (e.g., 'Yes' for an active property).
5. In the **Property Status** section, select one of the options to indicate the status of the property (e.g., 'Active' for a property that is currently rented).
6. In the **Compliance Ratings** section, select one or more of the options to indicate the compliance ratings of the property (e.g., 'Good' for a property that meets all required standards).
7. In the **Inspection Comments** section, enter any comments about the property's condition or any issues found during inspection.
8. In the **Additional Comments** section, enter any additional information about the property that is not covered in other sections.
9. In the **Tenant Status** section, select one of the options to indicate the status of the tenant (e.g., 'Active' for a tenant with an active lease).
10. In the **Property Manager Info** and **Property Owner Info** sections, enter any relevant information about the property manager or owner, respectively.
11. Finally, in the **Rental Agreement** section, enter any relevant information about the rental agreement, if applicable.

## Field-by-Field Explanation

* **Property Details**: Enter the address and other relevant details of the property.
* **Landlord Information**: Enter any relevant contact information and status updates for the landlord.
* **Tenant Information**: Enter any relevant contact information and status updates for the tenant.
* **Property Address**: Enter the address of the property being assessed.
* **Property Type**: Select one of the options to indicate the type of property (e.g., 'Yes' for an active property).
* **Property Status**: Select one of the options to indicate the status of the property (e.g., 'Active' for a property that is currently rented).
* **Compliance Ratings**: Select one or more of the options to indicate the compliance ratings of the property (e.g., 'Good' for a property that meets all required standards).
* **Inspection Comments**: Enter any comments about the property's condition or any issues found during inspection.
* **Additional Comments**: Enter any additional information about the property that is not covered in other sections.
* **Tenant Status**: Select one of the options to indicate the status of the tenant (e.g., 'Active' for a tenant with an active lease).
* **Property Manager Info**: Enter any relevant information about the property manager.
* **Property Owner Info**: Enter any relevant information about the property owner.
* **Rental Agreement**: Enter any relevant information about the rental agreement, if applicable.
