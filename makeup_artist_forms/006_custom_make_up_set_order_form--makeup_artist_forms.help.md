# Custom Make Up Set Order Form - Help Guide
## Purpose
The Custom Make Up Set Order Form is a tool for customers to place custom orders for makeup sets.

## How To Complete This Form
To complete the form, follow the steps outlined in the explanation section above.

## Field-by-Field Explanation
* **Submission Date** (`form_submission_date`, `select_one`, required): Select the date on which you would like to receive your custom makeup set order.
* **Submission Day** (`form_submission_day`, `select_one`, optional): Choose a specific day of the week for your custom order submission.
* **Submission Time** (`form_submission_time`, `select_one`, required): Select the time of day when you would like to receive your order.
* **Category** (`category`, `select_multiple`, required): Select the type of makeup set you are interested in purchasing, such as eyeshadow or face products.
* **Foundation Color Family** (`foundation_color_family`, `select_one`, optional): Choose the color family of the foundation you would like to receive.
* **Eyeshadow Type** (`eyeshadow_type`, `select_one`, optional): If you are purchasing an eyeshadow, select the type you want: matte, metallic, or duo.
* **Lip Balm Flavor** (`lip_balm_flavor`, `select_one`, optional): If you are purchasing a lip balm, choose the flavor you would like to receive: vanilla, strawberry, or blueberry.
* **Free Samples** (`free_samples`, `select_one`, optional): Decide if you would like to include free samples with your order.
* **Special Requests** (`special_requests`, `text`, optional): Add any special requests or additional information you would like to provide about your order.
* **Submission Day** (`form_submission_day`, `select_one`, optional): This field is used to choose a day for your custom order submission, it is not used in the order processing.
* **Form Submission 2** (`form_submission_2`, `select_one`, optional): This field is not used in the order processing, it is for internal use only.
