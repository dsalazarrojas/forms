# Makeup Pre Event Survey - Help Guide
## Purpose
This form is designed to collect information about a client's preferences and event details to ensure a successful makeup experience. By filling out this form, you will be able to tailor your services to the client's specific needs and preferences.

## How To Complete This Form
To complete this form, simply follow these steps:

1.  Start by selecting the event details, including the event type and any relevant information about the event.
2.  Next, choose the client's preferences for their skin type, tone, hair type, hair color, and makeup style.
3.  Then, select the client's preferred option for the event details 2 section.
4.  Enter the date and time of the event.
5.  Provide your contact information, including your phone number and email address.
6.  Finally, enter any additional event notes or comments.

## Field-by-Field Explanation
### Event Details
*   **Event Details** (`event_details_page`, text, required): Enter the event details, including the event type and any relevant information about the event.

*   **Event Details 2** (`event_details_2`, text, required: false): Enter any additional event details.

### Client Preferences
*   **Skin Type** (`Client Preferences`, select_multiple, required): Select the client's skin type from the following options:
    +   Skin Type
*   **Skin Tone** (`Client Preferences`, select_multiple, required): Select the client's skin tone from the following options:
    +   Skin Tone
*   **Hair Type** (`Client Preferences`, select_multiple, required): Select the client's hair type from the following options:
    +   Hair Type
*   **Hair Color** (`Client Preferences`, select_multiple, required): Select the client's hair color from the following options:
    +   Hair Color
*   **Makeup Style** (`Client Preferences`, select_multiple, required): Select the client's makeup style from the following options:
    +   Makeup Style

*   **Option 1** (`Client Preferences 2`, select_one, required): Select the client's preferred option from the following:
    +   Option 1
    +   Option 2
    +   Option 3
    +   Option 4

### Date and Time
*   **Date and Time** (`date_and_time`, date, required): Enter the date and time of the event.

### Contact Information
*   **Phone** (`phone`, text, required): Enter your phone number.

*   **Email** (`email`, email, required): Enter your email address.

### Additional Notes
*   **Event Notes** (`event_notes`, text, required: false): Enter any additional event notes or comments.
*   **Event Notes 2** (`event_notes_2`, text, required: false): Enter any additional event notes or comments.

*   **Makeup Artist Notes** (`makeup_artist_notes`, text, required: false): Enter any additional notes for the makeup artist.
