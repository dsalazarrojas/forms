# permanent_makeup_consultation_form - Help Guide
## Purpose
The permanent makeup consultation form is designed to gather essential information about you, our potential client. This form will help us understand your needs and preferences before we schedule an appointment for you. Please take a few minutes to complete this form accurately and honestly to ensure a smooth and successful consultation process.

## How To Complete This Form
1. Fill out this form completely and accurately.
2. Review each field carefully to ensure you understand the information required.
3. If you have any questions or concerns, please don't hesitate to contact us.

## Field-by-Field Explanation

* **Name** (`1`, `name`, required/optional): Please enter your name as it appears on your identification documents.
* **Email** (`2`, `contact_email`, required/optional): Enter your email address where you can be contacted.
* **Phone** (`3`, `contact_phone`, required/optional): Enter your phone number where you can be contacted.
* **Date** (`4`, `appointment_date`, required/optional): Select the date you're interested in booking a permanent makeup appointment.
* **Start Time** (`5`, `start_time`, required/optional): Select the start time of your appointment.
* **End Time** (`6`, `end_time`, required/optional): Select the end time of your appointment.
* **Medical History** (`7`, `medical_history`, required/optional): Please describe any medical conditions or allergies that may affect your permanent makeup appointment.
* **Medical Conditions** (`8`, `medical_conditions`, required/optional): List any medical conditions or concerns that you have.
* **Permanent Machines** (`9`, `permanent_machines`, required/true): Choose the permanent makeup services you're interested in booking. Please select from the options provided:
	+ Permanent Eyeliner
	+ Permanent Lip Liner
	+ Permanent Lashes
	+ Permanent Brow
	+ Permanent Lash Lifting
* **Other (Please specify)** (`10`, `permanent_machines_other`, required/false): If you have other permanent makeup services in mind, please specify them here.
* **Number of Appointments** (`11`, `num_appointments`, required/optional): If you know how many appointments you'll need, enter the number here. Otherwise, please leave this field blank.
* **Other (Please specify)** (`12`, `num_appointments_other`, required/false): If you're unsure about the number of appointments, please specify here.
* **Follow Up Info** (`13`, `follow_up_info`, required/optional): If you have any follow-up information or questions, please provide it here.
* **Follow Up Sessions** (`14`, `num_follow_ups`, required/optional): If you know how many follow-up sessions you'll need, enter the number here. Otherwise, please leave this field blank.
* **Follow-up Surgery** (`15`, `follow_up_surgery`, required/false): If you'll require follow-up surgery, please select the option that best fits your situation:
	+ True
	+ False
	+ Not sure yet
* **Number of Follow-up Sessions** (`16`, `num_follow_up_surgery`, required/optional): If you know how many follow-up sessions you'll need, enter the number here. Otherwise, please leave this field blank.
* **Follow-up Surgery Type** (`17`, `follow_up_surgery_type`, required/optional): If you know the type of follow-up surgery you'll require, please specify here.
* **Number of Surgeries** (`18`, `num_surgeries`, required/optional): If you know how many surgeries you'll need, enter the number here. Otherwise, please leave this field blank.
* **Surgery Type** (`19`, `surgery_type`, required/optional): If you know the type of surgery you'll require, please specify here.
* **Surgery Details** (`20`, `surgery_details`, required/optional): Please provide any additional information about the surgery you'll be requiring.
* **Number of Procedures** (`21`, `num_procedures`, required/optional): If you know how many procedures you'll require, enter the number here. Otherwise, please leave this field blank.
* **Other (Please specify)** (`22`, `num_procedures_other`, required/false): If you're unsure about the number of procedures, please specify here.
