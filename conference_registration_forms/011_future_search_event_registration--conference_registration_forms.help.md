# Future Search Event Registration - Help Guide
## Purpose
The Future Search Event Registration form is designed to collect information from individuals interested in attending a future search event.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter your First Name in the required field.
2. Enter your Last Name in the required field.
3. Provide your Email address.
4. If necessary, enter your contact number.
5. Specify whether the event type is "Yes" or "No".
6. Select a date for the event (note: this is a date field, but the options are not specified, so please use the MM/DD/YYYY format).
7. Choose an event time (note: this is a time field, but the options are not specified, so please use the standard 24-hour clock format, e.g., 08:00 or 14:30).
8. Enter any attendee preferences in the provided text area.
9. Specify your consent to participate in the event by selecting "Yes" or "No" (note: multiple selections are allowed).
10. Provide any additional comments about the event in the text area.

## Field-by-Field Explanation

* **First Name** (`first_name`, `text`, required): Enter your first name as it appears on your official documents.
* **Last Name** (`last_name`, `text`, required): Enter your last name as it appears on your official documents.
* **Email** (`email`, `email`, required): Enter a valid email address where you can be contacted.
* **Contact Number** (`contact_number`, `text`, optional): Enter your contact number if you'd like to be reached via phone.
* **Event Type** (`event_type`, `select_one`, optional): Choose whether you will be attending the event ("Yes" or "No").
* **Event Date** (`event_date`, `date`, optional): Select a date for the event in the MM/DD/YYYY format.
* **Event Time** (`event_time`, `time`, optional): Choose an event time in the 24-hour clock format (e.g., 08:00 or 14:30).
* **Attendee Preferences** (`attendee_preferences`, `note`, optional): Enter any additional information about your preferences for the event.
* **Consent** (`consent`, `select_multiple`, optional): Specify your consent to participate in the event by selecting "Yes" or "No" (multiple selections allowed).
* **Comments** (`comments`, `text`, optional): Enter any additional comments about the event.

## Tips

* Please ensure that the format for the Event Date and Event Time fields is correctly entered, as this information will be used to plan the event.
* Be as detailed as possible in the Attendee Preferences field to help us better cater to your needs.
* Multiple consents are allowed, please select all that apply.
* If you have any further questions or concerns, please don't hesitate to contact us.
