# Regional Product Showcase Registration - Help Guide
## Purpose
This form is designed to gather information about an upcoming product showcase event, allowing event organizers to provide a comprehensive overview of the event.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the form fields as required and provide the necessary details about the event.
2. Ensure that all required fields are filled out before submitting the form.
3. Review the form carefully before submitting to ensure that the information provided is accurate and complete.

## Field-by-Field Explanation
* **Event Organizer** (text, required/optional): This field is used to provide the name or contact information of the event organizer. Please enter the name or email address of the event contact person.
* **Event Details** (text, required): This field is used to describe the event in a few words. Please enter a brief description of the event.
* **Product Information** (text, required): This field is used to describe the product(s) that will be showcased during the event. Please enter a brief description of the product(s).
* **Terms and Agreements** (text, required/optional): This field is used to provide any relevant terms and agreements related to the event. Please enter any necessary terms and agreements.
* **Product Images** (select multiple, optional): Please select whether or not product images will be used during the event.
* **Product Videos** (select multiple, optional): Please select whether or not product videos will be used during the event.
* **Product Description** (text, required): This field is used to describe the product(s) that will be showcased during the event in more detail. Please enter a detailed description of the product(s).
* **Event Start Date** (date, required): This field is used to select the start date of the event. Please select the start date of the event.
* **Event End Date** (date, required): This field is used to select the end date of the event. Please select the end date of the event.
* **Event Start Time** (time, required): This field is used to select the start time of the event. Please select the start time of the event.
* **Event End Time** (time, required): This field is used to select the end time of the event. Please select the end time of the event.
* **Event Location** (text, optional): This field is used to provide the location of the event. Please enter the location of the event if applicable.
* **Event Address** (text, optional): This field is used to provide the address of the event location. Please enter the address of the event location if applicable.
* **Event Notes** (text, optional): This field is used to provide any additional notes or information about the event. Please enter any relevant notes or information about the event.
* **Event Organizer Contact** (text, required): This field is used to provide contact information for the event organizer. Please enter the contact email address or phone number of the event contact person.
