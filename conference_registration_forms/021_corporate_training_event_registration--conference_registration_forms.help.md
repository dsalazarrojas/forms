# Corporate Training Event Registration - Help Guide

## Purpose
This form is designed for users to register for corporate training events. The purpose of this form is to collect information about the attendee's preferences and details in order to efficiently manage the event registration process.

## How To Complete This Form
To complete this form, follow these steps:

* Read through each field and its corresponding explanation below to understand what information is required.
* Answer each question truthfully and accurately.
* Make sure to submit the form once you have filled out all the necessary fields.

## Field-by-Field Explanation

* **Session Preferences** (`session_preferences`, `select_one`, required: false): Please indicate if you would like to attend the session.
	+ Select "Yes" if you would like to attend the session.
	+ Select "No" if you would not like to attend the session.
* **Attendee Details** (`attendee_details`, `text`, required: false): Provide a brief description of the attendee.
* **Special Requirements** (`special_requirements`, `select_multiple`, required: false): Check the box if you have any special requirements.
	+ Select "Yes" if you have any special requirements.
	+ Select "No" if you do not have any special requirements.
* **Session Preferences 2** (`session_preferences_2`, `select_one`, required: false): Please indicate if you would like to attend the session 2.
	+ Select "Yes" if you would like to attend the session 2.
	+ Select "No" if you would not like to attend the session 2.
* **Session Preferences 3** (`session_preferences_3`, `select_one`, required: false): Please indicate if you would like to attend the session 3.
	+ Select "Yes" if you would like to attend the session 3.
	+ Select "No" if you would not like to attend the session 3.
* **Session Preferences 4** (`session_preferences_4`, `select_multiple`, required: false): Check the box if you would like to attend the session 4.
	+ Select "Yes" if you would like to attend the session 4.
	+ Select "No" if you would not like to attend the session 4.
* **Session Preferences 5** (`session_preferences_5`, `select_one`, required: false): Please indicate if you would like to attend the session 5.
	+ Select "Yes" if you would like to attend the session 5.
	+ Select "No" if you would not like to attend the session 5.

## Tips
* Please make sure to submit the form only once per attendee.
* If you have any special requirements, please specify them in the "Attendee Details" field.
* If you are unsure about any of the fields, please contact the event organizer for clarification.
