# Wildlife Preservation Symposium Registration Form - Help Guide
## Purpose
The Wildlife Preservation Symposium Registration Form is designed to collect registration information from attendees interested in joining the symposium. This form is part of the event management system and is used to collect attendee details.

## How To Complete This Form
To complete this form, follow these steps:

* Fill in your First Name.
* Fill in your Last Name.
* Enter your Email.
* Enter your Phone number.
* If you are registered with a Company, enter the name of the company.
* If you have a Job Title, enter it (optional).
* If you would like to share a brief Bio, enter it (optional).
* If you are representing an Organization, enter its name (optional).
* If you have a specific Job Function, enter it (optional).
* If you are in a specific Job Department, enter it (optional).
* Select 'Yes' or 'No' for each of the event attendance questions.
* Select the sessions you are interested in attending (up to 10 sessions can be selected).
* Click 'Submit' to complete the form.

## Field-by-Field Explanation

* **First Name** (`first_name`, text, required): Enter your first name as it is written on your identification document.
* **Last Name** (`last_name`, text, required): Enter your last name as it is written on your identification document.
* **Email** (`email`, email, required): Enter a valid email address that can be used to contact you.
* **Phone** (`phone`, text, required): Enter a valid phone number that can be used to contact you.
* **Company** (`company`, text, required): If you are registered with a company, enter its name.
* **Job Title** (`job_title`, text, optional): If you have a job title, enter it.
* **Bio** (`bio`, note, optional): If you would like to share a brief bio with the attendees, enter it.
* **Organization** (`organization`, text, optional): If you are representing an organization, enter its name.
* **Job Function** (`job_function`, text, optional): If you have a specific job function, enter it.
* **Job Department** (`job_department`, text, optional): If you are in a specific job department, enter it.
* **Event Attended** (`event_attended`, select_one, optional): Select 'Yes' if you have attended a similar event previously, 'No' otherwise.
* **Events Attended** (`events_attended`, select_multiple, optional): Select all the events you have attended previously.
* **Event Interests** (`event_interests`, select_one, optional): Select your interests in the event.
* **Events Interested In** (`events_interests`, select_multiple, optional): Select all the events you are interested in attending.
* **Session 01** (`session_01`, select_one, optional): Select 'Yes' if you are interested in attending Session 01, 'No' otherwise.
* **Session 02** (`session_02`, select_one, optional): Select 'Yes' if you are interested in attending Session 02, 'No' otherwise.
* **Session 03** (`session_03`, select_one, optional): Select 'Yes' if you are interested in attending Session 03, 'No' otherwise.
* **Session 04** (`session_04`, select_one, optional): Select 'Yes' if you are interested in attending Session 04, 'No' otherwise.
* **Session 05** (`session_05`, select_one, optional): Select 'Yes' if you are interested in attending Session 05, 'No' otherwise.
* **Session 06** (`session_06`, select_one, optional): Select 'Yes' if you are interested in attending Session 06, 'No' otherwise.
* **Session 07** (`session_07`, select_one, optional): Select 'Yes' if you are interested in attending Session 07, 'No' otherwise.
* **Session 08** (`session_08`, select_one, optional): Select 'Yes' if you are interested in attending Session 08, 'No' otherwise.
* **Session 09** (`session_09`, select_one, optional): Select 'Yes' if you are interested in attending Session 09, 'No' otherwise.
* **Session 10** (`session_10`, select_one, optional): Select 'Yes' if you are interested in attending Session 10, 'No' otherwise.
* **Submit** (`submit`, text, optional): Click this button to complete the form.
