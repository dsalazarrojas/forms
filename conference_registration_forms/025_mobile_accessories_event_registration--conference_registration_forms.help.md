# Mobile Accessories Event Registration - Help Guide
## Purpose
This form is designed to collect registration information from attendees for a mobile accessories event. It will help event organizers gather essential details about the attendees, including their contact and address information, interests, and other relevant details.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the attendee's name in the "attendee name" field.
2. Provide the attendee's email address in the "attendee email" field.
3. Select the attendee's segment interests by choosing from the options provided in the "segment interests" field.
4. Choose the type of event the attendee will attend by selecting from the options in the "event type" field.
5. Add any additional comments or notes about the attendee's sign up in the "sign up" field.
6. If necessary, provide a secondary name for the attendee in the "attendee name 2" field.
7. Enter the attendee's number of attendees (if applicable) in the "attendee number" field.
8. Enter the attendee's address in the "address" field.
9. Provide the attendee's contact information in the "contact" field.

## Field-by-Field Explanation

* **attendee name** (text, required: no): Enter the name of the attendee.
* **attendee email** (email, required: no): Enter the email address of the attendee.
* **segment interests** (select multiple, required: no): Select the segment interests that apply to the attendee.
	+ Choose from: Yes, No
* **event type** (select one, required: no): Choose the type of event the attendee will attend.
	+ Choose from: Yes, No
* **sign up** (note, required: no): Add any additional comments or notes about the attendee's sign up.
* **attendee name 2** (text, required: no): If necessary, enter a secondary name for the attendee.
* **attendee number** (number, required: no): Enter the number of attendees (if applicable).
* **address** (text, required: no): Enter the attendee's address.
* **contact** (text, required: no): Provide the attendee's contact information.

## Tips

* Please ensure that you fill out all required fields accurately and thoroughly.
* If you are unsure about any of the fields, feel free to ask the event organizers for clarification.
* Make sure to double-check your information before submitting the form.
