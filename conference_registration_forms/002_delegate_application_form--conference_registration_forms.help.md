# Delegate Application Form - Help Guide

## Purpose
This form is designed to help us understand your interest in being a conference delegate. It is a multiple-choice form that will help us to quickly identify potential delegates and their needs.

## How To Complete This Form
To complete this form, follow these steps:

1. Select all that apply from the list of options for each question. You can choose multiple options for each question.
2. For the text fields, please provide a brief description of your answer in the box provided.
3. Make sure to complete all required fields, even if they are not marked as required by default.

## Field-by-Field Explanation

### Are you looking for delegates?
* **delegate_application_form_1** (`conference_registration_forms`, select_multiple, not required): This question is asking you to select all that apply from the list of options if you are looking for delegates. Please choose 'Yes' if you are looking for delegates.
* **signup_forms** (`signup_forms`, select_one, not required): This question is asking you to select one option if you are looking for delegates. Please choose 'Yes' if you are looking for delegates.
* **are_you_looking_for_delegates** (`looking_for_conference_delegates`, text, not required): This text field is asking you to provide a brief description of why you are looking for delegates.
* **delegate_candidates_can_easily_apply** (`delegate_application_form_6`, text, not required): This text field is asking you to provide a brief description of how delegate candidates can easily apply.

### Event Description
* **event_description** (`event_description`, text, not required): This text field is asking you to provide a brief description of the event you are interested in.
* **conference_delegates_form_description** (`conference_delegates_form_description`, text, not required): This text field is asking you to provide a description of the delegate application form you are interested in. 

### Conference Delegate Description
* **are_you_looking_for_delegates** (`are_you_looking_for_delegates`, text, not required): This text field is asking you to provide a brief description of why you are looking for delegates.
