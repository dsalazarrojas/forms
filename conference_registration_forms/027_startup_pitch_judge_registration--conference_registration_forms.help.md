# Startup Pitch Judge Registration - Help Guide
## Purpose
This form is for registering as a startup pitch judge for a specific event. Fill out the form to let us know about your expertise and availability to judge.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the form on one page at a time, using the instructions for each page.
2. Make sure to provide accurate and complete information in each field.
3. Use the available options for select fields to choose the best answer for your situation.

## Field-by-Field Explanation
### User Details
* **User Details** (text, optional): Enter your name and any other relevant personal details you'd like to share with us.

### User Expertise
* **User Expertise** (select multiple, optional):
	+ Accelerators: Select if you have experience working with accelerators.
	+ Incubators: Select if you have experience working with incubators.
	+ Venture Capitalists: Select if you have experience working with venture capitalists.
	+ Industry Experts: Select if you have expertise in a specific industry (e.g. finance, tech, etc.).

### Availability
* **Availability** (select one, optional):
	+ Yes, I am available to judge: Indicate if you are available to judge at the event.
	+ False: Indicate if you are not available to judge at the event.

### Contact
* **Contact** (text, optional): Enter any contact information you'd like to have us reach out to you with.

### Email
* **Email** (email, optional): Enter your email address so we can contact you about the event.

## Tips
* Make sure to be honest about your availability, as this will help us schedule the event properly.
* If you have any specific expertise, select all relevant options to help us match you with the right startups.
* If you have any questions or concerns, feel free to contact us!
