# Dream Event Registration - Help Guide

## Purpose
The Dream Event Registration form is used to collect information from event attendees and organizers. This form helps to streamline the event planning and management process by gathering essential details about the event.

## How To Complete This Form
To complete the form, follow these steps:

1. Fill in your first name and last name in the corresponding text fields.
2. Enter your email address in the email field, ensuring it matches the format of your email address (e.g., [yourname@example.com](mailto:yourname@example.com).
3. If applicable, enter your phone number in the phone field.
4. Select the type of event (e.g., conference, workshop, or seminar) from the dropdown menu.
5. Enter the date and time of the event in the date and time fields, respectively.
6. Enter the location of the event in the event location field.
7. Provide a brief description of the event in the event description field (if applicable).
8. If relevant to your participation, select the participation type from the dropdown menu.
9. Enter the number of attendees for your event in the attendee count field (if applicable).
10. Select the status of your event (active or inactive) from the dropdown menu.

## Field-by-Field Explanation
* **First Name** (`first_name`, text, required): Enter your first name.
* **Last Name** (`last_name`, text, required): Enter your last name.
* **Email** (`email`, email, required): Enter your email address in the format of [yourname@example.com](mailto:yourname@example.com).
* **Phone** (`phone`, text, optional): If you have a phone number, enter it.
* **Event Type** (`event_type`, select_one, optional): Select the type of event (e.g., conference, workshop, or seminar).
* **Event Date** (`event_date`, date, optional): Enter the date of the event.
* **Event Time** (`event_time`, time, optional): Enter the time of the event.
* **Event Location** (`event_location`, text, optional): Enter the location of the event.
* **Event Description** (`event_description`, text, optional): Provide a brief description of the event.
* **Participation Type** (`participation_type`, select_multiple, optional): Select the type of participation (e.g., Yes or No).
* **Attendee Count** (`attendee_count`, number, optional): Enter the number of attendees for your event.
* **Event Status** (`event_status`, select_one, optional): Select the status of your event (e.g., Active or Inactive).
