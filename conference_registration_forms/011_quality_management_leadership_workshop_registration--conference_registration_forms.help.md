# Quality Management Leadership Workshop Registration - Help Guide
## Purpose
This form is used to register for a Quality Management Leadership Workshop. It is designed to collect relevant information about the workshop and the attendees.

## How To Complete This Form
To complete this form, please follow these steps:

1. Review each section carefully and fill out the required fields.
2. Make sure to provide accurate and complete information.
3. Click "Submit" to complete your registration.

## Field-by-Field Explanation

* **Dates and Times (id: 2)**: Choose the dates and times you will attend the workshop.
	+ Select "Yes" if you will attend, "No" if you will not.
* **Dates (id: 3)**: Enter the dates of the workshop you are registering for. 
	+ Use the format MM/DD/YYYY to avoid any errors.
* **Time (id: 4)**: Enter the time of the workshop you are registering for. 
	+ Use the format HH:MM AM/PM to avoid any errors.
* **Attendees (id: 5)**: Indicate if you will be bringing any attendees to the workshop. 
	+ Select "Yes" if you will bring attendees, "No" if you will not.
* **Attendee Details (id: 6)**: If you are bringing attendees, select their names here.
	+ This field requires a list of names separated by commas.
* **Special Requirements (id: 7)**: If there are any special requirements for your registration, such as dietary restrictions, please list them here.
	+ This field requires a list of requirements separated by commas.
* **Payment Method (id: 8)**: Indicate how you will be paying for the workshop.
	+ Select "Yes" if you will pay, "No" if you will not.
* **Amount (id: 9)**: Enter the amount you will be paying.
	+ This field requires a numerical value.
* **Notes (id: 10)**: Add any additional notes about your registration.
	+ This field is optional and can be used to provide any additional information.
* **Payment Status (id: 11)**: This field will be filled out automatically after payment is processed.
	+ Do not fill out this field.
* **Additional Info (id: 12)**: Add any additional information about your registration.
	+ This field is optional and can be used to provide any additional details.
* **Contact Info (id: 13)**: Enter your contact information.
	+ This field is optional and should be used to provide your email address or phone number.
* **Workshop Location (id: 14)**: Enter the location of the workshop.
	+ This field is optional and can be used to provide any additional location details.
* **Workshop Description (id: 15)**: Enter a brief description of the workshop.
	+ This field is optional and can be used to provide any additional details about the workshop.
* **Organizer (id: 16)**: Enter the name of the workshop organizer.
	+ This field is optional and can be used to provide any additional details about the organizer.
* **Organizer Email (id: 17)**: Enter the email address of the workshop organizer.
	+ This field is optional and should be used to provide the email address of the person organizing the workshop.
* **Organizer Phone (id: 18)**: Enter the phone number of the workshop organizer.
	+ This field is optional and should be used to provide the phone number of the person organizing the workshop.
* **Organizer Phone 2 (id: 19)**: Enter the backup phone number of the workshop organizer.
	+ This field is optional and should be used to provide a backup phone number of the person organizing the workshop.
* **Organizer Mobile (id: 20)**: Enter the mobile phone number of the workshop organizer.
	+ This field is optional and should be used to provide the mobile phone number of the person organizing the workshop.
* **Organizer Address (id: 21)**: Enter the address of the workshop organizer.
	+ This field is optional and can be used to provide any additional details about the workshop location.
* **Organizer Website (id: 22)**: Enter the website of the workshop organizer.
	+ This field is optional and can be used to provide any additional details about the workshop organizer.
* **Organizer Social Media (id: 23)**: Enter the social media handle of the workshop organizer.
	+ This field is optional and can be used to provide any additional details about the workshop organizer.
* **Organizer Notes (id: 24)**: Add any additional notes about the workshop organizer.
	+ This field is optional and can be used to provide any additional information about the workshop organizer.
* **Additional Notes (id: 25)**: Add any additional notes about your registration.
	+ This field is optional and can be used to provide any additional details about your registration.

## Tips
- Make sure to proofread your form carefully before submitting.
- If you have any questions or concerns, please contact the workshop organizer.
- This form is for your information and will be used to prepare for the workshop. It will not be shared with anyone else. 

This guide will help you complete the form accurately and efficiently. If you have any further questions, please don't hesitate to contact the workshop organizer.
