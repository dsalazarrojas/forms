# Vendor Booth Layout Revision Request Form - Help Guide
## Purpose
This form is used to request revisions to a vendor's booth layout at a conference or event. It is intended for event organizers to collect information about the current state of the booth and to coordinate and schedule revisions with the vendor.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the type of event you are requesting the booth revision for (Conference, Registration, or Request Form).
2. Enter a brief description of the changes you would like to make to the booth layout.
3. If you have a diagram illustrating the desired changes, you can attach it to this form.
4. Specify who will be responsible for implementing the changes (assigned or unassigned).
5. Choose a date and time when you would like the changes to be implemented.
6. If applicable, indicate whether this is a one-time event or if it will be recurring.
7. Enter any additional comments or details about the event.
8. Enter your name as the person making the request.

## Field-by-Field Explanation

* **Event Type**: 
  * Choose the type of event (Conference, Registration, or Request Form).
  * This will help event organizers understand the context and priority of the booth revision.
* **Description**: 
  * Enter a brief description of the changes you would like to make to the booth layout.
  * This will help event organizers understand what changes are needed and why.
* **Diagram**: 
  * If you have a diagram illustrating the desired changes, attach it to this form.
  * This will help event organizers understand the scope and detail of the changes.
* **Implemented by**: 
  * Choose whether the changes will be implemented by you or not.
  * This will help event organizers know who to coordinate with for the changes.
* **Timeline**: 
  * Choose a date and time when you would like the changes to be implemented.
  * This will help event organizers schedule the changes accordingly.
* **Vendor**: 
  * Enter your name as the person making the request.
  * This will help event organizers know who to contact for further information.
* **Changes**: 
  * Enter any additional comments or details about the changes you would like to make.
  * This will help event organizers understand the scope and priority of the changes.
* **Comments**: 
  * Enter any additional comments or details about the event.
  * This will help event organizers understand any additional context.
* **Date**: 
  * Choose a date when you would like the changes to be implemented.
  * This will help event organizers schedule the changes accordingly.
* **Time**: 
  * Choose a time when you would like the changes to be implemented.
  * This will help event organizers schedule the changes accordingly.
* **Recurring Event**: 
  * Check if this is a one-time event or if it will be recurring.
  * This will help event organizers understand the frequency and priority of the changes.
* **Other Details**: 
  * Enter any additional comments or details about the event.
  * This will help event organizers understand any additional context.

## Tips
* Please make sure to enter accurate and up-to-date information.
* If you have already submitted a similar request, please do not resubmit.
* This form is intended for internal use and its data will not be shared with anyone outside the event organizers team.
