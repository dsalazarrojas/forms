# New Matter Form - Help Guide
## Purpose
This form is used to create new matters, providing essential details for tracking and managing cases, issues, or subjects that require attention or resolution.

## How To Complete This Form
To complete this form:

1. Fill in the required fields with accurate and relevant information.
2. Select the correct options for matter type, status, priority, category, subtype, and subcategory from the respective dropdown menus.
3. Enter a description of the matter, including any relevant details or context.
4. Save the form to create the new matter.

## Field-by-Field Explanation
* **new_matter_form_page_1**:
	+ **title**: This is the title of the new matter, which should be a brief and descriptive name.
	+ **business_name**: The name of the business or entity associated with this matter.
	+ **contact_name**: The name of the contact person or representative.
* **matter_number**: A unique identifier for the matter.
* **contact_email**: The email address of the contact person or representative.
* **contact_phone**: The phone number of the contact person or representative.
* **client_address**: The address of the client or business.
* **case_number**: The case number or reference number (if applicable).
* **matter_type**: Select the type of matter (e.g., dispute, inquiry, complaint).
* **matter_status**: Select the current status of the matter (e.g., open, pending, resolved).
* **assigned_user**: Select the user responsible for this matter.
* **created_by**: Select the user who created this matter.
* **updated_by**: Select the user who last updated this matter.
* **date_created**: The date this matter was created.
* **date_updated**: The date this matter was last updated.
* **matter_description**: A detailed description of the matter, including any relevant context or background.
* **matter_notes**: Additional notes or comments about the matter.
* **matter_status_description**: A description of the current status of the matter.
* **matter_priority**: Select the priority level of the matter (e.g., high, medium, low).
* **matter_category**: Select the category of the matter (e.g., financial, legal, technical).
* **matter_subtype**: Select the subtype of the matter (e.g., tax, contract, employment).
* **matter_subcategory**: Select the subcategory of the matter (e.g., tax return, contract review, employment dispute).
* **matter_type**: A short text description of the matter type.
* **matter_number**: A unique identifier for the matter (not to be confused with the matter type).

Please note that some fields may have specific requirements or formats depending on the context or business rules. If you are unsure about a particular field, please consult with your supervisor or contact person for clarification.
