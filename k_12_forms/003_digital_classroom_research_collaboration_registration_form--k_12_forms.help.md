# Digital Classroom Research Collaboration Registration Form - Help Guide
## Purpose
This form is used to register digital classroom research collaborations for K-12 forms or other categories.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the **Category** field with the appropriate category for your project (e.g., K-12 Forms).
2. Enter a brief **Description** of your research collaboration project.
3. Enter your **Email** address for communication purposes.
4. Enter your **Phone** number for contact.
5. Specify whether your project has been assigned a tool (Yes/No).
6. Decide whether an **Output File** is associated with this project (Yes/No).
7. Fill in the **Title** field with a concise title for your research collaboration.
8. Select relevant **Tags** to describe your project (Yes/No).
9. Specify the **Version** of your research collaboration (a number).
10. Enter an **Alias** for your project (optional).
11. Enter the **Author** of your research collaboration.
12. Set the **Created At** date for your project.
13. Set the **Updated At** date for your project.
14. Specify whether this project has a **Creator** (Yes/No).
15. Select the **Reviewers** for your project (Yes/No).
16. Set the **Publish Date** for your project.
17. Set the **Publish Status** of your project (Active/Inactive).
18. Set the **Publish Date** for your project.
19. Set the **Publish Time** for your project.
20. Specify whether your project has a **Publish User** (Yes/No).
21. Add a note for **Version History** (optional).

## Field-by-Field Explanation

* **Category**: Select the category for your project (e.g., K-12 Forms).
* **Description**: Briefly describe your research collaboration project.
* **Email**: Enter your email address for communication purposes.
* **Phone**: Enter your phone number for contact.
* **Form ID**: Specify the ID for your form.
* **Assigned Tool**: Decide whether a tool has been assigned to your project (Yes/No).
* **Output File**: Decide whether an output file is associated with your project (Yes/No).
* **Title**: Enter a concise title for your research collaboration project.
* **Tags**: Select relevant tags to describe your project (Yes/No).
* **Version**: Specify the version of your research collaboration (a number).
* **Alias**: Enter an alias for your project (optional).
* **Author**: Enter the author of your research collaboration.
* **Created At**: Set the date when your project was created.
* **Updated At**: Set the date when your project was last updated.
* **Creator**: Specify whether this project has a creator (Yes/No).
* **Reviewers**: Select the reviewers for your project (Yes/No).
* **Publish Date**: Set the date when your project was published.
* **Publish Status**: Set the publish status of your project (Active/Inactive).
* **Publish Date**: Set the date when your project was published.
* **Publish Time**: Set the time when your project was published.
* **Publish User**: Specify whether your project has a publish user (Yes/No).
* **Version History**: Add a note for version history (optional).
