# High School Sports Participation Survey - Help Guide
## Purpose
This form is designed to gather information about high school students' participation in sports and their interests. Please take a few minutes to complete this form carefully.

## How To Complete This Form
- Fill out the form completely and accurately.
- Choose the options that best fit your responses.
- Do not leave any fields blank unless you are absolutely sure they are not applicable.

## Field-by-Field Explanation

* **sports_involvement (Yes/No)**: This question asks if you are involved in any sports. Please select 'Yes' if you are involved in any sports, even if it's just playing for fun or in your free time.
* **sports_teams (select one)**: If you are involved in sports, please select the teams you are involved in.
* **sport_interest (select multiple)**: If you have an interest in participating in sports, please select the sports that interest you.
* **barriers_to_participation (Yes/No)**: This question asks if you have faced any barriers to participate in sports. Please select 'Yes' if you have faced any barriers, such as lack of time, equipment, or resources.
* **future_teams (Yes/No)**: If you plan to participate in sports in the future, please select 'Yes' for the sports you are interested in.
* **sport_preferences (Yes/No)**: This question asks if you prefer playing sports as an individual or as part of a team. Please select 'Yes' for individual sports and 'No' for team sports.
* **additional_comments** : Please use this field to provide any additional information about your sports participation or preferences.
* **email**: This is your email address for contact and future communications.
* **phone**: This is your contact phone number.
* **date_of_birth**: Please enter your date of birth in the correct format (MM/DD/YYYY).
* **sport_participated (Yes/No)**: This question asks if you have participated in any sports before. Please select 'Yes' if you have participated in any sports.
* **sport_participation (Yes/No)**: If you have participated in sports, please select 'Yes' for the sports you have participated in.
* **school_sport_participated (Yes/No)**: This question asks if you have participated in any school sports. Please select 'Yes' if you have participated in any school sports.
* **school_sport_participation (Yes/No)**: If you have participated in school sports, please select 'Yes' for the sports you have participated in.
* **parent_consent (True/False)**: Please ask a parent or guardian to confirm their consent for your participation in sports.
* **student_name**: Please enter your name as it appears on your identification documents.
* **student_id**: Please enter your student ID number.
* **school_year (select one)**: Please select the current school year you are in.
* **school_grade (select one)**: This question asks for your current grade level. Please select the correct grade level.
* **school_grade_level (select one)**: This question also asks for your current grade level. Please select the correct grade level.
* **school_class (select one)**: If you are in a specific school class, please select it.
* **school_subjects (select multiple)**: If you are interested in or participating in specific school subjects, please select them.
* **school_subjects_english (select multiple)**: This question asks if you are interested in or participating in English subjects. Please select 'Yes' for any English subjects.
* **school_subjects_math (select multiple)**: If you are interested in or participating in math subjects, please select 'Yes'.
* **school_subjects_science (select multiple)**: This question asks if you are interested in or participating in science subjects. Please select 'Yes' for any science subjects.
