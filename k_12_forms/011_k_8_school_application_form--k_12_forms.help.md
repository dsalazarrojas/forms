# reported_k8_school_application_form - Help Guide
## Purpose
This form is used to collect information for K-8 school enrollment applications.

## How To Complete This Form
To complete this form, follow the steps below:
1. Fill in all required fields marked with * (e.g., Student Name, Grade Level, Student Status).
2. If you are the parent, please fill in your name, address, and employment status.
3. If you are the student, please fill in your name, address, email, phone number, and birthdate.
4. Select the relevant school and its type from the options provided.
5. Provide any additional information in the Student Notes and Parent Notes fields if necessary.

## Field-by-Field Explanation
* **Student Name** (`student_name`, required): Enter the name of the student.
* **Parent Name** (`parent_name`, required): Enter the name of the parent.
* **Student Address** (`student_address`, optional): Enter the address of the student, if applicable.
* **Parent Address** (`parent_address`, optional): Enter the address of the parent, if applicable.
* **Birthdate** (`birthdate`, optional): Enter the birthdate of the student.
* **Student Schools** (`student_schools`, required, select_one): Select the school where the student is currently enrolled or applying to.
* **Parent Employed** (`parent_employed`, required, select_one): Select the employment status of the parent.
* **Student Email** (`student_email`, optional, email): Enter the email address of the student.
* **Student Phone** (`student_phone`, optional): Enter the phone number of the student.
* **Grade Level** (`grade_level`, required, select_one): Select the grade level of the student (e.g., 1st, 2nd, 3rd).
* **Student Notes** (`student_notes`, optional): Add any additional notes about the student.
* **Parent Notes** (`parent_notes`, optional): Add any additional notes about the parent.
* **Student Education** (`student_education`, optional): Enter any relevant educational background or qualifications.
* **Parent Education** (`parent_education`, optional): Enter any relevant educational background or qualifications of the parent.
* **School Name** (`school_name`, optional): Enter the name of the school.
* **School Email** (`school_email`, optional, email): Enter the email address of the school.
* **School Phone** (`school_phone`, optional): Enter the phone number of the school.
* **Grade Level 2** (`grade_level2`, optional, select_one): Select the grade level of the school (e.g., High, Low).
* **Student Status** (`student_status`, required, select_multiple): Select the status of the student (e.g., New Student, Existing Student, Transfer Student).
* **School Status** (`school_status`, optional, select_multiple): Select the status of the school (e.g., Active, Inactive).
* **School Type** (`school_type`, required, select_one): Select the type of school (e.g., Primary, Secondary).
* **School Level** (`school_level`, required, select_one): Select the level of the school (e.g., K-1, K-2, etc.).
* **School Start Date** (`school_start_date`, optional): Enter the date the student started at school.
* **School End Date** (`school_end_date`, optional): Enter the date the student ended at school.
* **School Status 2** (`school_status`, optional, select_multiple): Select the status of the school (e.g., Active, Inactive).
