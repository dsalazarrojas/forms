# pedagogical_storytelling_resource_request_form - Help Guide
## Purpose
This form is used to request pedagogical storytelling resources for a specific grade level and subject in K-12 education.
## How To Complete This Form
1.  **User Input** (`user_input`, text, optional): Enter your name or the name of the person requesting the resource.
2.  **Resource Name** (`resource_name`, text, optional): Provide the name of the resource you are requesting.
3.  **Grade Level** (`grade_level`, select_one, optional): Select the grade level of the resource you are requesting (1-8).
4.  **Subject** (`subject`, text, optional): Enter the subject of the resource you are requesting.
5.  **Resource URL** (`resource_url`, text, optional): If you have a URL for the resource, enter it here.
6.  **Resource Description** (`resource_description`, text, optional): Provide a brief description of the resource you are requesting.
7.  **Requested By** (`requested_by`, text, optional): Enter the name of the person requesting the resource.
8.  **Email** (`email`, email, optional): Enter the email of the person requesting the resource.
9.  **Phone** (`phone`, text, optional): Enter the phone number of the person requesting the resource.
10. **Comments** (`comments`, text, optional): Provide any additional comments about the resource request.
11.  **Resource Type** (`resource_type`, select_one, optional): Select the type of resource you are requesting (Book, Video, Image, Website, or Other).
12. **Other Resource Type** (`resource_type_other`, text, optional): If you selected "Other", enter the type of resource you are requesting.
13. **Resource Tag** (`resource_tag`, text, optional): Enter a tag for the resource.
14. **Category** (`category`, text, optional): Enter the category for the resource.
15. **Tags** (`tags`, text, optional): Enter any additional tags for the resource.
16. **Submit** (`submit`, text, optional): Click this button to submit your resource request.
