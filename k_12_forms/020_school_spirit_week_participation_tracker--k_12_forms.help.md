# School Spirit Week Participation Tracker - Help Guide
## Purpose
The School Spirit Week Participation Tracker form is designed to collect data on student participation in school spirit week events. This form helps administrators and staff keep track of engagement, monitor trends, and make informed decisions to improve future events.

## How To Complete This Form
To complete the form, follow these steps:

1. Select the Spirit Week page to begin.
2. Fill in the School Name field with the name of the school where the event took place.
3. Enter the Date of the event in the Date field.
4. Enter the name of the Activity Name of the event in the Activity Name field.
5. Enter the Student Name in the Student Name field.
6. Choose the Grade Level of the student participating in the event.
7. Add any Feedback about the event in the Feedback field.
8. Enter the Student's Email address, if available.
9. Enter the Student's Phone number, if available.

## Field-by-Field Explanation
* **Spirit Week** (`spirit_week`, note, not required): A brief description or note about the spirit week event.
* **School Name** (`school_name`, text, not required): Enter the name of the school where the event took place.
* **Date** (`date`, date, not required): Enter the date of the event in the format MM/DD/YYYY.
* **Activity Name** (`activity_name`, text, not required): Enter a brief description of the activity participated in.
* **Student Name** (`student_name`, text, not required): Enter the name of the student participating in the event.
* **Grade Level** (`grade_level`, select_one, not required): Select the grade level of the student participating in the event. Options: A, B, C, D.
* **Feedback** (`feedback`, note, not required): Add any comments or feedback about the event.
* **Email** (`email`, email, not required): Enter the student's email address, if available.
* **Phone** (`phone`, text, not required): Enter the student's phone number, if available.
