# Classroom Student Altercation Incident Report - Help Guide

## Purpose
This form is used to report and document any incidents that occur within a classroom setting involving students. The goal is to gather information about the incident, including the date and time it occurred, the location, and the details of what happened. This will help staff and administrators better understand the situation and take appropriate actions to prevent future incidents.

## How To Complete This Form
To complete this form, please follow these steps:

1.  Select the date and time of the incident from the calendar.
2.  Choose the location where the incident occurred from the provided options.
3.  If the incident occurred off-campus, provide a more detailed location description in the "Specific Location Details" field.
4.  Enter the name and ID number of the reporting teacher.
5.  Choose the grade level of the students involved.
6.  Enter the full names and ID numbers of the students involved in the altercation.
7.  If other students were present, enter their names.
8.  Choose the type of altercation that occurred.
9.  Enter a detailed description of what happened.
10.  Identify what factors led up to the altercation.
11.  Describe any injuries sustained by the students or staff, and provide details about treatment provided.
12.  Enter the actions taken immediately after the incident.
13.  Enter the staff members who intervened.
14.  Check if parents were notified about the incident.
15.  If disciplinary actions were taken, select them from the list.
16.  Check if follow-up action is required and schedule the date for it.
17.  Add any additional comments or information about the incident.
18.  Enter your name as the person submitting the report.
19.  Select the date you are submitting the report.

## Field-by-Field Explanation

*   **Incident Date**: The date when the altercation occurred.
    *   This field is required and should be filled in using the calendar.
*   **Incident Time**: The time when the altercation occurred.
    *   This field is required and should be filled in using the calendar.
*   **Incident Location**: The location where the altercation took place.
    *   Select from the provided options: Classroom, Hallway, Cafeteria, Playground, Gymnasium, Bathroom, School Bus, Other School Property, Off-Campus School Event.
*   **Specific Location Details**: A more detailed description of the location.
    *   This field is required if the incident occurred off-campus.
*   **Reporting Teacher Name**: The name of the staff member who is reporting the incident.
    *   This field is required and should be filled in with the teacher's name.
*   **Reporting Teacher ID**: The employee ID number of the staff member who is reporting the incident.
    *   This field is required and should be filled in with the teacher's ID number.
*   **Grade Level**: The grade level of the students involved.
    *   Select from the provided options: Kindergarten, Grade 1-2, Grade 3-5, Grade 6-8, Grade 9-12.
*   **Student 1 Name**: The full name of the first student involved.
    *   This field is required and should be filled in with the first student's name.
*   **Student 1 ID Number**: The student ID number of the first student involved.
    *   This field is required and should be filled in with the student's ID number.
*   **Student 2 Name**: The full name of the second student involved.
    *   This field is required and should be filled in with the second student's name.
*   **Student 2 ID Number**: The student ID number of the second student involved.
    *   This field is required and should be filled in with the student's ID number.
*   **Other Students Involved**: The names of any other students who were involved in the altercation.
    *   This field is optional and should be filled in with the names of any other students who were involved.
*   **Witnesses Present**: The names of students or staff who witnessed the incident.
    *   This field is optional and should be filled in with the names of any witnesses.
*   **Type of Altercation**: The primary type of altercation that occurred.
    *   Select from the provided options: Verbal Argument, Physical Fight, Threatening Behavior, Bullying or Harassment, Property Damage, Other.
*   **Detailed Description of Incident**: A detailed account of what happened.
    *   This field is required and should be filled in with a detailed description of the incident.
*   **Precipitating Factors**: What led up to the altercation.
    *   This field is required and should be filled in with a description of the factors that led up to the incident.
*   **Injuries Sustained**: Describe any injuries sustained by the students or staff.
    *   Select from the provided options: No Injuries, Minor Injuries - First aid administered, Moderate Injuries - Nurse visited, Serious Injuries - Medical attention required.
*   **Injury Details**: A description of the injuries and treatment provided.
    *   This field is optional and should be filled in with a description of the injuries and treatment provided.
*   **Immediate Actions Taken**: The actions taken immediately after the incident.
    *   This field is required and should be filled in with a description of the actions taken.
*   **Staff Intervention**: The staff members who intervened.
    *   This field is required and should be filled in with a description of the staff members who intervened.
*   **Parents Notified**: Whether parents were notified about the incident.
    *   Select from the provided options: Yes - Both sets of parents notified, Yes - Only one set of parents notified, No - Will notify later, No - Awaiting administrator guidance.
*   **Disciplinary Actions Taken**: Disciplinary measures taken.
    *   Select from the provided options: Verbal Warning, Written Warning, Detention, Suspension, Parent Conference, Behavior Contract, Referral to Counselor, Other.
*   **Follow-Up Required**: Whether follow-up action is required.
    *   Select from the provided options: Yes - Administrator meeting scheduled, Yes - Counselor involvement needed, Yes - Parent conference needed, No - Matter resolved.
*   **Follow-Up Date**: The scheduled date for follow-up.
    *   This field is optional and should be filled in with the scheduled date for follow-up.
*   **Additional Comments**: Any other relevant information.
    *   This field is optional and should be filled in with any other relevant information.
*   **Report Submitted By**: The name of the person submitting the report.
    *   This field is required and should be filled in with your name.
*   **Report Date**: The date this report is being submitted.
    *   This field is required and should be filled in with the date you are submitting the report.
