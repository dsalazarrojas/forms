# Student Faculty Roundtable Recording Consent Form - Help Guide
## Purpose
This form is used to obtain student and faculty consents for recording student meetings, discussions, or events.

## How To Complete This Form
To complete this form, please follow these steps:
1. Fill out the form completely, including selecting the relevant options for each field.
2. Review each field below for more information on what is required.

## Field-by-Field Explanation
* **Student Faculty Roundtable Recording Consent Form** (`title`, text, optional): This field is the title of the form, which is already pre-filled.
* **Recordings Permissions** (`recording_permissions`, select, optional): 
  + Select 'Yes' if the student and faculty consent to be recorded.
  + Select 'No' if you do not want to be recorded.
* **Recording Method** (`recording_method`, select, optional): 
  + Select 'Yes' if you have a preference for how you would like to be recorded (e.g., video, audio, or in-person).
  + Select 'No' if you have no preference or would like to discuss with the recorder.
* **Recording Purpose** (`recording_purpose`, select, optional): 
  + Select 'Yes' if you have a specific purpose for the recording (e.g., for training, review, or assessment).
  + Select 'No' if you do not have a specific purpose or would like to discuss with the recorder.
* **Recording Duration** (`recording_duration`, select, optional): 
  + Select 'Yes' if you are comfortable with being recorded for a specific duration (e.g., 1 hour, 2 hours).
  + Select 'No' if you have concerns about the duration of the recording.

## Tips
- Make sure to review each field carefully before filling out the form.
- If you have any concerns or questions, please discuss with the recorder before completing the form.
- This form requires student and faculty consents for recording purposes, please be sure to fill it out completely and accurately.
