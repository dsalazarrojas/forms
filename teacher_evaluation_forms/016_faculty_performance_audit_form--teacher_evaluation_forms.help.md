# Faculty Performance Audit Form - Help Guide

## Purpose
The Faculty Performance Audit Form is a tool used to collect and evaluate the performance of faculty members. It is a crucial tool for review and feedback, helping to ensure that faculty members are held to high standards.

## How To Complete This Form

To complete this form, follow these steps:

1. Fill in your department ID, which can be found in your personnel file or by contacting your department head.
2. Enter the employee ID of the faculty member being evaluated.
3. Select a review date to record the date when the review took place.
4. Choose a reviewer ID to identify who conducted the review.
5. Select a review committee ID, if applicable.
6. Enter the evaluation date, which is the date the evaluation was completed.
7. Choose an evaluation period to select the time frame for the evaluation.
8. Enter the department name and employee name of the faculty member being evaluated.
9. Select a performance rating based on the evaluation, with 1 being the lowest and 5 being the highest.
10. Provide a brief evaluation summary.
11. Add any additional notes or comments regarding the evaluation.
12. Enter the faculty member's email and phone number for contact information.
13. Select the department the faculty member belongs to.
14. Choose the evaluation frequency, which determines how often evaluations take place.
15. Select the review status, which indicates the current state of the review process.
16. Enter the last review date, if applicable.
17. Select the review frequency, which determines how often reviews take place.
18. Choose the review type, which determines the type of review being conducted.
19. Select the evaluation type, which determines the type of evaluation being conducted.
20. Enter the name of the review committee, if applicable.
21. Enter the last evaluation date, if applicable.
22. Select the evaluation frequency, which determines how often evaluations take place.
23. Enter the submission date, which indicates when the evaluation was submitted.

## Field-by-Field Explanation

* **Department Id**: Enter your department ID to identify your department. 
* **Employee Id**: Enter the ID of the faculty member being evaluated.
* **Review Date**: Select the date when the review took place.
* **Reviewer Id**: Choose the ID of the reviewer who conducted the evaluation.
* **Review Committee Id**: Select the ID of the review committee, if applicable.
* **Evaluation Date**: Enter the date when the evaluation was completed.
* **Evaluation Period**: Choose the time frame for the evaluation.
* **Department Name**: Enter the name of the department the faculty member belongs to.
* **Employee Name**: Enter the name of the faculty member being evaluated.
* **Performance Rating**: Select a performance rating from 1-5, with 1 being the lowest and 5 being the highest.
* **Evaluation Summary**: Provide a brief summary of the evaluation.
* **Notes**: Add any additional notes or comments regarding the evaluation.
* **Email**: Enter the faculty member's email for contact information.
* **Phone**: Enter the faculty member's phone number for contact information.
* **Department**: Select the department the faculty member belongs to.
* **Evaluation Frequency**: Select how often evaluations take place.
* **Review Status**: Select the current state of the review process.
* **Last Review Date**: Enter the date of the last review, if applicable.
* **Review Frequency**: Select how often reviews take place.
* **Review Type**: Select the type of review being conducted.
* **Evaluation Type**: Select the type of evaluation being conducted.
* **Review Committee**: Enter the name of the review committee, if applicable.
* **Last Evaluation Date**: Enter the date of the last evaluation, if applicable.
* **Evaluation Frequency**: Select how often evaluations take place.
* **Submission Date**: Enter the date when the evaluation was submitted.
