# Teacher Impact Assessment - Help Guide
## Purpose
The "Teacher Impact Assessment" form is designed to collect feedback on a teacher's effectiveness and impact on their students' learning experience.

## How To Complete This Form
To complete this form, follow these steps:

1. Select all the ways in which a teacher has impacted your learning experience on the "Assessment" page.
2. Provide a brief description of your evaluation of the teacher's effectiveness on the "Evaluation" page.
3. Enter the date of your evaluation on the "Effectiveness" page.
4. Describe the evaluation process used to assess the teacher's effectiveness on the "Evaluation Process" page.
5. Indicate whether the teacher's support system was sufficient on the "Support System" page.
6. Enter any additional feedback or comments on the "Feedback" page.
7. Provide any additional comments or observations on the "Additional Comments" page.

## Field-by-Field Explanation
* **Assessment** (`teacher_impact_assessment`, Select multiple, Not required): This page allows you to select all the ways in which a teacher has impacted your learning experience.
  * Options: Yes, No
* **Evaluation** (`teacher_evaluation_forms`, Text, Not required): This page is for providing a brief description of your evaluation of the teacher's effectiveness.
* **Effectiveness** (`teacher_effectiveness`, Date, Not required): This page is for entering the date of your evaluation.
* **Evaluation Process** (`teacher_evaluation_process`, Text, Not required): This page is for describing the evaluation process used to assess the teacher's effectiveness.
* **Support System** (`teacher_support_system`, Select one, Not required): This page is for indicating whether the teacher's support system was sufficient.
  * Options: Yes, No
* **Feedback** (`feedback`, Note, Not required): This page is for entering any additional feedback or comments.
* **Additional Comments** (`additional_comments`, Text, Not required): This page is for providing any additional comments or observations.
