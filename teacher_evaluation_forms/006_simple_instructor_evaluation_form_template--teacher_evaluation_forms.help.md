# simple_instructor_evaluation_form_template - Help Guide

## Purpose
This form is designed to gather feedback from students on the instructor's performance and course quality. The goal is to improve teaching methods and student satisfaction.

## How To Complete This Form
1. Select the "Instructor Name" field and enter the name of the instructor you want to evaluate.
2. For the "Course Name" field, enter the name of the course being evaluated.
3. Fill in the ratings/evaluations for each aspect of instruction (e.g., clarity, helpfulness, punctuality, willfulness, joyfulness, etc.).
4. For multiple-choice questions, select all that apply (e.g., "Clear", "Very Satisfactory", "Helpful", etc.).
5. Once you've completed all fields, submit the form.
