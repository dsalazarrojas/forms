# Homework Submission Form - Help Guide
## Purpose
The Homework Submission Form is designed for teachers to submit homework assignments for review and feedback. This form helps gather essential information about student submissions, making it easier to track and review assignments.

## How To Complete This Form

### To complete this form, follow these steps:
- Fill in the required information for each field.

## Field-by-Field Explanation

### **1. Homework Submission**
* (`homework_submission_form`, text, required: false): This is where you will submit the actual homework assignment. Please enter any relevant details about the assignment, such as the assignment name, description, or any specific questions or tasks included.
* **2. Student Name**
* (`student_name`, text, required: false): Enter the student's name as it appears on their ID or school records.
* **3. Assignment Name**
* (`assignment_name`, text, required: false): Enter the name of the homework assignment being submitted.
* **4. Submission Date**
* (`submission_date`, date, required: false): Enter the date the assignment was submitted in the format `YYYY-MM-DD` (e.g., 2022-01-01).
* **5. Submission Time**
* (`submission_time`, time, required: false): Enter the time the assignment was submitted in the format `HH:MM:SS` (e.g., 14:30:00).
* **6. Comments**
* (`comments`, text, required: false): Use this field to add any comments or feedback about the submission, if necessary.

## Tips
- Ensure that all required fields are filled in before submitting the form.
- Use clear and concise language in each field to avoid confusion.
- If you need help or have questions, contact [form@gic.mx](mailto:form@gic.mx).
