# Teacher Evaluation Checklist Form - Help Guide
## Purpose
This form is designed to collect feedback and suggestions from students, parents, or peers on a teacher's performance and areas for improvement.

## How To Complete This Form
To complete this form, follow these steps:

1. Review each evaluation criterion and select the most accurate option that describes the teacher's performance.
2. Provide a comment or suggestion for the teacher, if applicable.
3. Rate the teacher's overall performance and overall satisfaction rating.

## Field-by-Field Explanation

* **Assessment Criteria** (`teacher_evaluation_checklist_form`): Choose the evaluation criterion that best describes the teacher's performance. Options include:
	+ Option 1
	+ Option 2
	+ Option 3
* **Comment** (`teacher_comment`): Provide any comments or suggestions you have for the teacher. This is an optional field, but it's a great way to add more detail to your feedback.
* **Overall Performance Rating** (`overall_performance_rating`): Rate the teacher's overall performance using the options provided.
* **Teacher Feedback** (`teacher_feedback`): Provide any feedback you have for the teacher. This is an optional field, but it's a great way to add more detail to your feedback.
* **Student Feedback** (`student_feedback`): Provide any feedback you have for the teacher from a student's perspective. This is an optional field, but it's a great way to add more detail to your feedback.
* **Evaluation Criterion 1-16** (`evaluation_criterion_1` to `evaluation_criterion_16`): Choose the evaluation criterion that best describes the teacher's performance for each criterion.
* **Teacher Suggestion** (`teacher_suggestion`): Provide any suggestions you have for the teacher. This is an optional field, but it's a great way to help the teacher grow and improve.
* **Teacher Response** (`teacher_response`): Rate the teacher's response to your feedback using the options provided.
* **Student Response** (`student_response`): Provide any response you have from a student's perspective. This is an optional field, but it's a great way to add more detail to your feedback.
* **Evaluation Criterion 13-16** (`evaluation_criterion_13` to `evaluation_criterion_16`): Choose the evaluation criterion that best describes the teacher's performance for each criterion.
* **Overall Satisfaction Rating** (`overall_satisfaction_rating`): Rate the teacher's overall satisfaction rating using the options provided.
* **Overall Performance** (`overall_performance`): Rate the teacher's overall performance using the options provided.
