# Sewing Pattern Feedback Survey - Help Guide
## Purpose
This form is designed to gather feedback from users about their experience with a sewing pattern. It will help us understand how to improve our patterns in the future.

## How To Complete This Form
To complete this form, simply follow these steps:

1.  Select "Yes" or "No" for the first question, "User Information", to let us know if you found the pattern helpful.
2.  Choose one or multiple options for "Pattern Type" to describe the type of pattern you used.
3.  Select "Yes" or "No" for "What Fabric Do You Have?" to indicate which type of fabric you used.
4.  Choose one option for "Difficulty" to rate how difficult you found the pattern.
5.  Type in your comment or suggestion in the "Comments" field, if you have any.
6.  Select "Yes" or "No" for "Contact Information" to let us know if you would like to be contacted.
7.  Enter your email address in the "Email" field, if you would like to be contacted.
8.  Enter your phone number in the "Phone" field, if you have one.

## Field-by-Field Explanation
- **User Information** (`User Information`, `select_one`, required/optional): Select "Yes" if you found the pattern helpful, or "No" otherwise.
- **Pattern Type** (`Pattern Type`, `select_multiple`, required/optional): Choose one or multiple options to describe the type of pattern you used.
- **What Fabric Do You Have?** (`What Fabric Do You Have?`, `select_multiple`, required/optional): Select "Yes" if you used the fabric, or "No" otherwise.
- **Difficulty** (`Difficulty`, `select_one`, required/optional): Choose one option to rate how difficult you found the pattern.
- **Comments** (`Comments`, `note`, required/optional): Type in your comment or suggestion about the pattern.
- **Contact Information** (`Contact Information`, `select_multiple`, required/optional): Select "Yes" if you would like to be contacted.
- **Email** (`Email`, `email`, required/optional): Enter your email address if you would like to be contacted.
- **Phone** (`Phone`, `text`, required/optional): Enter your phone number if you have one.
