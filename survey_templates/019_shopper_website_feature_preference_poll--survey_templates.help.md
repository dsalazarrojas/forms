# Shopper Website Feature Preference Poll - Help Guide

## Purpose
This form is used to collect feedback and preferences from shoppers on the website features that are important to them. The purpose of this form is to understand what features are most valuable to shoppers and to gather comments and suggestions on how to improve the website.

## How To Complete This Form
To complete this form, follow these steps:

1. Answer the survey questions in the first page of the form. The questions will ask you to rate the importance of certain features on the website.
2. On the second page, select all the features that you think are important for improvement. You can select multiple features.
3. If there are any other features that you think are important but not listed, enter them in the "Specify other improvement features" field.
4. In the "Comments" field, provide any additional comments or suggestions you have for improving the website.
5. If you have a specific email address or phone number where you can be contacted, enter it in the "Email" and "Phone" fields.
6. If you have any other comments or suggestions, enter them in the "Other comments" field.

## Field-by-Field Explanation

* **Survey questions** (Page 1):
	+ This is a page of questions that ask you to rate the importance of certain features on the website.
	+ The questions will be multiple-choice, and you will be asked to rate each feature on a scale (though the specific scale is not specified in the YAML).
* **How important is improving the following feature?** (Page 2):
	+ This page asks you to select all the features that you think are important for improvement.
	+ You can select multiple features by checking the boxes next to each feature.
* **How satisfied are you with the following features?** (Page 2):
	+ This page is similar to the previous one, but asks about your level of satisfaction with the features.
	+ You will also select multiple features by checking the boxes next to each feature.
* **Priority improvement features** (Page 3):
	+ This page asks you to select only one feature that is most important for improvement.
	+ You can choose one feature from the list.
* **Specify other improvement features** (Page 3):
	+ This field is for you to enter any other features that you think are important but not listed.
	+ Enter any other features that you think are important.
* **Comments** (Page 3):
	+ This field is for you to provide any additional comments or suggestions.
* **Email** (Page 4):
	+ If you have a specific email address where you can be contacted, enter it here.
* **Phone** (Page 4):
	+ If you have a specific phone number where you can be contacted, enter it here.
* **Other comments** (Page 4):
	+ This field is for you to provide any other comments or suggestions.
* **Comments Other 2** (Page 4):
	+ This field is for you to provide any other comments or suggestions.
* **Email 2** (Page 5):
	+ If you have a specific email address where you can be contacted, enter it here.
* **Phone 2** (Page 5):
	+ If you have a specific phone number where you can be contacted, enter it here.
