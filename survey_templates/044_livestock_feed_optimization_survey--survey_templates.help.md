# livestock_feed_optimization_survey - Help Guide
## Purpose
The livestock feed optimization survey is designed to gather data on your current livestock feed production and cost metrics. This survey will help identify areas for improvement to optimize your feed production and cost savings.

## How To Complete This Form
To complete this form, please follow these steps:

1. Select all that apply for each question.
2. Provide numerical values for questions marked as "number".
3. Fill in all required fields (indicated by an asterisk \*).

## Field-by-Field Explanation
* **1. Livestock Production** (`minimalist_livestock_production`, text, required): Answer in a brief description of your current livestock production levels.
* **2. Feed Type** (`feed_type`, select_multiple, required): Select all types of feed your farm uses (e.g., grain, hay, concentrates).
* **3. Current Feed Formulations** (`current_feed_formulations`, select_multiple, required): List the different feed formulations you currently offer.
* **4. Feed Formulations** (`feed_formulations`, select_one, required): Choose the type of feed formulation you use (e.g., dry mix, liquid).
* **5. Feed Additives** (`feed_additives`, select_multiple, required): Select all additives used in feed production (e.g., vitamins, minerals).
* **6. Current Feed Formulation** (`current_feed_formulation`, select_multiple, required): Select all current feed formulations used.
* **7. Feed Formulation Description** (`feed_formulations_description`, note, required): Describe the composition of your current feed formulations.
* **8. Current Livestock Production** (`current_livestock_production`, number, required): Enter the current number of livestock units produced.
* **9. Target Livestock Production** (`target_livestock_production`, number, required): Enter your target livestock production levels.
* **10. Production Goal** (`production_goal`, number, required): Set your production goal (e.g., 10,000 units).
* **11. Average Feed Conversion** (`average_feed_conversion`, number, required): Calculate the average feed conversion rate (e.g., 0.5).
* **12. Average Feed Cost** (`average_feed_cost`, number, required): Enter the average feed cost per unit.
* **13. Current Reported Feed Cost** (`current_reported_feed_cost`, number, required): Report the current feed cost per unit.
* **14. Feed Conversion Goal** (`feed_conversion_goal`, number, required): Set your feed conversion goal (e.g., 0.5).
* **15. Current Reported Conversion** (`current_reported_conversion`, number, required): Report the current conversion rate.
* **16. Average Reported Feed Cost** (`average_reported_feed_cost`, number, required): Report the average feed cost per unit.
* **17. Current Reported Conversion** (`current_reported_conversion`, number, required): Report the current conversion rate.
* **18. Total Livestock Value** (`total_livestock_value`, number, required): Enter the total value of all livestock.
* **19. Total Livestock Value Goal** (`total_livestock_value_goal`, number, required): Set your total livestock value goal.
* **20. Total Livestock Value** (`total_livestock_value`, number, required): Enter the total value of all livestock.
* **21. Average Livestock Value** (`average_livestock_value`, number, required): Calculate the average livestock value.
* **22. Feed Cost Goal** (`feed_cost_goal`, number, required): Set your feed cost goal.
* **23. Current Reported Feed Cost per Livestock** (`current_reported_feed_cost_per_livestock`, number, required): Report the current feed cost per unit.
* **24. Feed Conversion Cost Goal** (`feed_conversion_cost_goal`, number, required): Set your feed conversion cost goal.
* **25. Feed Conversion Cost** (`feed_conversion_cost`, number, required): Calculate the feed conversion cost per unit.
