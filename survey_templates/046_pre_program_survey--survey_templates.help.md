# Pre Program Survey - Help Guide
## Purpose
The Pre Program Survey is a form used to collect information about a program's details, including its type, location, start date, and expected graduation date. This information is essential for planning and managing programs effectively.

## How To Complete This Form
To complete this form, simply follow these steps:
1. Provide your program's information as needed.
2. Choose the correct options from the dropdown menus.
3. Enter dates in the correct format (MM/DD/YYYY).

## Field-by-Field Explanation
* **Program Information**: This section is used to provide a brief description of the program. Please enter the program's details in the text field.
* **Program Type**: This field asks whether your program is currently running or not. If it is running, select "Yes". If not, select "No".
* **Program Location**: Select all locations where your program operates.
* **Program Interest**: Indicate your level of interest in the program by selecting either "Yes" or "No".
* **Program Language**: Choose the languages associated with your program by selecting "Yes" for each relevant language.
* **Program Start Date**: Enter the date when your program started, using the MM/DD/YYYY format.
* **Program Expected Graduation Date**: Enter the date when your program is expected to graduate, using the MM/DD/YYYY format.
* **Program Notes**: Use this text area to add any additional comments or details about your program.

## Tips
* Please make sure to fill out all required fields.
* Double-check your responses for accuracy.
* If you have any questions, feel free to ask.
