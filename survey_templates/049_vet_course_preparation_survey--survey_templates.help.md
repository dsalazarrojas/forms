# vet_course_preparation_survey - Help Guide
## Purpose

The **vet_course_preparation_survey** form is designed to collect essential details about course preparation and delivery for veterinary professionals. This form is used to record and track information about the course type, delivery frequency, date, time, location, method, program length, participant details, and any additional comments or insights.

## How To Complete This Form

To complete this form, follow these steps:

1. Ensure you have all necessary information about the course and program before starting.
2. Select the relevant options for the following fields:
   * **program_type**: Choose one option that best describes the type of program or course being prepared.
   * **delivery_preferences**: Select multiple options that describe the delivery preferences for the course or program.
   * **delivery_frequency**: Select the frequency of delivery for the course or program (e.g., once, twice, more than once).
   * **delivery_date**: Enter the date of delivery for the course or program.
   * **delivery_time**: Enter the time of delivery for the course or program.
   * **delivery_duration**: Enter the duration of the course or program in numerical form.
   * **delivery_location**: Select the location of delivery for the course or program.
   * **delivery_method**: Select multiple options that describe the delivery method for the course or program.
   * **program_length**: Select the length of the program or course.
   * **participant_details**: Select multiple options that describe the participant details.
   * **learner_insights**: This is a note field for any additional insights or notes about the learners participating in the course or program.
   * **program_comments**: Enter any additional comments or feedback about the program or course.
   * **participant_comments**: Enter any comments or feedback from the participants or learners.
