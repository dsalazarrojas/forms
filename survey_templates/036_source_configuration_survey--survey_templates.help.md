# Source Configuration Survey - Help Guide
## Purpose
This form is designed to collect information about the configuration of data sources, which is used to improve the overall data source configuration and ensure that data collection is being done effectively and efficiently.

## How To Complete This Form
1. Select the team that you are configuring data collection for from the list of available teams.
2. Choose the start date for data collection.
3. Choose the end date for data collection.
4. Select the frequency at which data collection will occur.
5. Choose the status of data collection.
6. Enter any issues with data quality in the "Data Quality Challenge 1" field.
7. Enter any other issues with data quality in the "Data Quality Challenge 2" field.
8. If you have any additional comments, enter them in the "Additional Comments" field.

## Field-by-Field Explanation

* **Team Configuration** (Team A, Team B, Team C, required):
	+ This field is used to select which team is being configured for data collection. Please choose the team that corresponds to the data collection you are configuring.
* **Data Collection Start Date** (date, required):
	+ This field is used to select the start date for data collection. Choose the date from the calendar that appears when you click on the field.
* **Data Collection End Date** (date, required):
	+ This field is used to select the end date for data collection. Choose the date from the calendar that appears when you click on the field.
* **Data Collection Frequency** (number, required):
	+ This field is used to select the frequency at which data collection will occur. Please enter the number of days between data collections.
* **Data Collection Status** (Active, Inactive, Unknown, required):
	+ This field is used to select the status of data collection. Choose the status that corresponds to the current state of data collection.
* **Data Quality Challenge 1** (text, required):
	+ This field is used to enter any issues with data quality. Please enter any problems you have encountered with data quality.
* **Data Quality Challenge 2** (text, required):
	+ This field is used to enter any other issues with data quality. Please enter any additional problems you have encountered with data quality.
* **Additional Comments** (text, optional):
	+ This field is used to enter any additional comments about the data collection configuration. Please use this field to provide any additional information that may be helpful in improving data collection.
