# Invitation Negative Answer Survey - Help Guide
## Purpose
The "Invitation Negative Answer Survey" form is used to collect information on why users declined an invitation to an event. Providing this information can help event planners understand the reasons behind the denials and make adjustments for future event invitations.

## How To Complete This Form
To complete this form, follow these steps:

1. Read the form carefully and fill out the relevant fields according to your response.
2. Select the relevant options for each field, such as "Person" or "System" for the "Invitation Source" field.
3. Enter any additional comments or information in the "Additional Information" fields as needed.

## Field-by-Field Explanation
### Reason for Invitation Denial
* **Reason for Invitation Denial** (`invitation_denial_reason`, `text`, optional)
    This field is for providing a brief explanation on why you declined the invitation. Please be as concise as possible.

### Invitation Source
* **Invitation Source** (`invitation_sender`, `select_one`, optional)
    This field asks you to indicate where the invitation came from. Select either "Person" or "System".

### First Denial
* **First Denial** (`first_denial`, `select_one`, optional)
    Check "True" if this is the first time you've been invited to the event, or "False" otherwise.

### Still Want to Attend
* **Still Want to Attend** (`still_want_to_attend`, `select_one`, optional)
    Check "True" if you still want to attend the event, or "False" otherwise.

### Event Interest
* **Event Interest** (`event_interest`, `select_one`, optional)
    Check "True" if you're still interested in attending the event, or "False" otherwise.

### Additional Information
* **Additional Information** (`more_info`, `text`, optional)
    If you have any additional comments or information related to your response, please enter them here.

### More Info2, More Info3, More Info4, More Info5, More Info6, More Info7, More Info8, More Info9, More Info10
* **More Info2** (`more_info2`, `text`, optional)
    * **More Info3** (`more_info3`, `text`, optional)
    * **More Info4** (`more_info4`, `text`, optional)
    * **More Info5** (`more_info5`, `text`, optional)
    * **More Info6** (`more_info6`, `text`, optional)
    * **More Info7** (`more_info7`, `text`, optional)
    * **More Info8** (`more_info8`, `text`, optional)
    * **More Info9** (`more_info9`, `text`, optional)
    * **More Info10** (`more_info10`, `text`, optional)
    These fields are for providing any additional information you'd like to share. Please use them as needed.

## Tips
* Please be as specific as possible when filling out the form.
* If you're unsure about any of the fields, don't hesitate to ask for clarification.
* Providing feedback is optional, but it can help event planners make improvements for the future.
