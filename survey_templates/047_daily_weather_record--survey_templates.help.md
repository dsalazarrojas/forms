# Daily Weather Record - Help Guide
## Purpose
This form is designed to collect data about the current weather conditions in a specific location on a given date. It is intended for use in data collection and analysis.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the location where you are recording the weather conditions.
2. Select the date of the recorded weather conditions.
3. Record the current temperature.
4. Choose the current weather conditions (e.g. Sunny, Cloudy, Rainy, Windy).
5. (Optional) Record the wind speed.
6. (Optional) Record the humidity levels.
7. Add any additional notes about the weather conditions.

## Field-by-Field Explanation
* **Location** (text): Enter the location where you are recording the weather conditions.
* **Date** (date): Select the date of the recorded weather conditions. This field is required to associate the weather data with the correct date.
* **Temperature** (number): Record the current temperature in the location.
* **Weather Conditions** (select_one): Choose the current weather conditions from the options provided (e.g. Sunny, Cloudy, Rainy, Windy). This field is required to accurately classify the weather.
* **Wind** (number): Record the wind speed. (Optional)
* **Humidity** (number): Record the humidity levels. (Optional)
* **Notes** (note): Add any additional notes about the weather conditions. This field is optional and can be used to capture any relevant information not covered by the other fields.

## Tips
* Ensure that you are using the correct date for each recorded entry.
* Be as accurate as possible when recording the temperature and weather conditions.
* If you are unsure about the wind or humidity levels, you can skip these fields or record them with a question mark.
