# Vacant Land Listing Survey - Help Guide
## Purpose
The vacant land listing survey is a form designed to collect information about a vacant land listing. It will help us understand the characteristics of the land, such as its address, city, state, zip code, country, acres owned, property type, zoning status, property use, land use, lot size, property condition, lot shape, frontage, back to front, and lot owners.

## How To Complete This Form
1. Fill out the form carefully and accurately.
2. Make sure to enter the correct information for each field.
3. If you are unsure about any field, refer to the field-by-field explanation below.

## Field-by-Field Explanation
- **Address**: Enter the address of the vacant land listing.
  * Type: Text
  * Required: False
  * Hint: Please enter the address of the land listing.
- **City**: Enter the city of the vacant land listing.
  * Type: Text
  * Required: True
  * Hint: Please enter the city of the land listing.
- **State**: Enter the state of the vacant land listing.
  * Type: Text
  * Required: True
  * Hint: Please enter the state of the land listing.
- **Zip Code**: Enter the zip code of the vacant land listing.
  * Type: Number
  * Required: True
  * Hint: Please enter the 5-digit zip code of the land listing.
- **Country**: Enter the country of the vacant land listing.
  * Type: Text
  * Required: False
  * Hint: Please enter the country of the land listing.
- **Acres Owned**: Enter the number of acres owned by the land listing.
  * Type: Number
  * Required: True
  * Hint: Please enter the number of acres owned.
- **Property Type**: Select the type of property, such as Residential, Commercial, Industrial, or Agricultural.
  * Type: Select One
  * Required: True
  * Hint: Please select the type of property.
- **Zoning Status**: Select the zoning status of the land listing, such as Zoned, Unzoned, or Mixed-Use.
  * Type: Select Multiple
  * Required: True
  * Hint: Please select the zoning status of the land listing.
- **Property Use**: Select the use of the property, such as Single Family, Multi-Family, or Mixed.
  * Type: Select One
  * Required: True
  * Hint: Please select the use of the property.
- **Land Use**: Select the use of the land, such as Single Family, Multi Family, or Commercial.
  * Type: Select One
  * Required: True
  * Hint: Please select the use of the land.
- **Lot Size**: Enter the size of the lot in acres.
  * Type: Number
  * Required: False
  * Hint: Please enter the size of the lot.
- **Property Condition**: Select the condition of the property, such as Excellent, Good, Fair, or Poor.
  * Type: Select One
  * Required: True
  * Hint: Please select the condition of the property.
- **Lot Shape**: Select the shape of the lot, such as Regular or Irregular.
  * Type: Select One
  * Required: True
  * Hint: Please select the shape of the lot.
- **Frontage**: Enter the frontage of the lot.
  * Type: Text
  * Required: False
  * Hint: Please enter the frontage of the lot.
- **Back to Front**: Enter the back to front measurement of the lot.
  * Type: Text
  * Required: False
  * Hint: Please enter the back to front measurement of the lot.
- **Lot Owners**: Enter the name(s) of the lot owner(s).
  * Type: Text
  * Required: False
  * Hint: Please enter the name(s) of the lot owner(s).
