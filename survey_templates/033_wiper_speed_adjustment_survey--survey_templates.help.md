# Wiper Speed Adjustment Survey - Help Guide
## Purpose
The Wiper Speed Adjustment Survey is designed to gather feedback from users on various aspects of the wiper system, including wiper controls, preferred wiper speed, and wiper sensitivity. This survey will help us improve the wiper system and provide a better user experience.

## How To Complete This Form
1. Please select all that apply from the wiper controls options.
2. Choose your preferred wiper speed from the options provided.
3. Select whether you have any issues with the wiper position.
4. Select whether you think the wiper is too sensitive or not.
5. If you have any comments or suggestions, please add them in the comments section.
6. Repeat the same process for the remaining questions.
