# Project Lessons Learned Form - Help Guide
## Purpose

This form is designed to gather information about the lessons learned from a project. It will help you reflect on the project's successes and challenges, and identify areas for improvement.

## How To Complete This Form

1. Enter the project title and dates (start and end dates) of the project.
2. Answer the questions about the team members involved in the project, selecting all that apply.
3. Rate the outcomes of the project using the provided scale (Good, Fair, etc.).
4. Provide any recommendations for future projects based on your experiences.
5. Add any additional comments about the project.

## Field-by-Field Explanation

* **Project Title** (`project_title`, text, required): Enter the name of the project.
* **Project Start Date** (`project_start_date`, date, required): Enter the start date of the project.
* **Project End Date** (`project_end_date`, date, required): Enter the end date of the project.
* **Team Members** (`team_members`, select_multiple, optional): List all the team members involved in the project. You can select multiple members if they were part of the team.
* **Rating Outcomes** (`rating_outcomes`, select_multiple, required): Rate the outcomes of the project using the provided scale (Good, Fair, etc.).
* **Recommendations** (`recommendations`, text, optional): Provide any recommendations for future projects based on your experiences.
* **Comments** (`comments`, text, optional): Add any additional comments about the project.
