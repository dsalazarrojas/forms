# virtual_family_event_attendance_form - Help Guide
## Purpose
This form is designed to collect attendance information and details about virtual family events. Use it for events where family members can attend remotely, and ensure you're not duplicating information from similar forms.

## How To Complete This Form
1. Fill out the form with the required information.
2. Select the correct options for each field as needed.
3. Double-check your answers to ensure accuracy before submitting.

## Field-by-Field Explanation

* **family_event_details**: This is the main event description field where you'll provide a brief summary of the virtual event.
* **event_date**: Enter the date of the virtual event, following the standard date format (MM/DD/YY).
* **event_time**: Provide the start and end time of the virtual event, in 24-hour format (HH:MM).
* **attendees**: Select all applicable attendees from the given options (1-10). This field allows multiple selections.
* **attendee_relationships**: Choose the relationship with the attendee (parent, sibling, or both). This field is for specifying the type of relationship with each selected attendee.
* **comments**: If you'd like to add any additional comments or notes about the event, type them in this field.
* **email**: Enter the contact email for the event organizer or relevant contact information.
* **phone_number**: Provide the phone number for the event or relevant contact information.
* **attendance_confirmed**: Confirm the attendance status for each attendee (True, False, or unsure).
* **attendance_comments**: Leave any additional comments about attendance, if necessary.

Note: Some fields are not required, but it's essential to fill out all relevant information for accurate event planning and tracking.
