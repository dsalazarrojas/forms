# Sustainability Initiatives Implementation Assessment - Help Guide
## Purpose
This form is designed to help organizations assess and improve their sustainability initiatives. It gathers information about the type, duration, budget, and impact of sustainability initiatives, as well as other relevant details.

## How To Complete This Form

1. Please fill out the form page by page, starting from page 1.
2. For each field, provide a clear and concise answer.
3. Be as specific as possible when providing information.
4. If a field is marked as optional, please provide information if applicable.
5. If a field is marked as required, please fill it out completely.

## Field-by-Field Explanation

* **What is the name of your organization?** (`organization_name`, text, required)
	+ Please enter the name of your organization.
* **Which type of sustainability initiative is this for?** (`initiative_type`, select_one, optional)
	+ Select one of the following options: Green Housekeeping, Green Purchasing, Green Transportation, Green Supply Chain.
* **How long has the project been going on?** (`project_duration`, select_multiple, optional)
	+ Select all applicable options: Less than 6 months, 6-12 months, 1-2 years, 2-5 years, More than 5 years.
* **Which areas does the initiative target?** (`target_area`, select_multiple, optional)
	+ Select all applicable options: Community, Environment, Employees, Customers.
* **What budget is associated with the initiative?** (`budget`, number, required)
	+ Please enter the budget amount.
* **What is the expected impact of the initiative?** (`expected_impact`, number, required)
	+ Please enter a number.
* **What is the actual impact of the initiative?** (`actual_impact`, number, required)
	+ Please enter a number.
* **Is the organization's sustainability committee involved?** (`sustainability_committee`, text, optional)
	+ Please answer with a yes or no.
* **Which type of greenhouse gas emissions are being addressed?** (`greenhouse_gas`, select_multiple, optional)
	+ Select all applicable options: Electricity, Heat, Water, Waste.
* **How much carbon offset is achieved through this initiative?** (`carbon_offset`, text, optional)
	+ Please enter a number.
* **What is the organization's water conservation rate?** (`water_conservation`, text, optional)
	+ Please enter a number.
* **What is the organization's recycling rate?** (`recycling_rate`, select_one, optional)
	+ Select one of the following options: 0-10%, 11-20%, 21-30%, 31-40%, 41-50%.
* **Which mode of transportation is used for this initiative?** (`transportation_mode`, select_multiple, optional)
	+ Select all applicable options: Bike, Bus/Rail, Car, Other.
* **How energy efficient is this initiative?** (`energy_efficiency`, select_multiple, optional)
	+ Select one of the following options: High, Medium, Low.
* **Which type of renewable energy is used?** (`renewable_energy`, select_multiple, optional)
	+ Select all applicable options: Solar, Wind, Hydro, Other.
* **Is the building certified as green?** (`green_building`, text, optional)
	+ Please answer with a yes or no.
* **Which green certification is obtained?** (`green_certification`, select_multiple, optional)
	+ Select all applicable options: GBI, LEED, Other.
* **Are there sustainable water sources used?** (`sustainable_water_sources`, text, optional)
	+ Please answer with a yes or no.
* **Is the organization's building certified as green?** (`green_building_certification`, text, optional)
	+ Please answer with a yes or no.
* **How is the organization's land use managed sustainably?** (`sustainable_land_use`, text, optional)
	+ Please enter a description.
* **Which mode of transportation is used?** (`transportation_mode_2`, select_multiple, optional)
	+ Select all applicable options: Bus, Walk/Bike, Drive, Other.
* **How much carbon offset is achieved?** (`carbon_offset_2`, text, optional)
	+ Please enter a number.
* **Green Building Certification 2** (`green_building_certification_2`, select_multiple, optional)
	+ Select all applicable options: GBI, LEED, Other.
* **How is the organization's housekeeping managed sustainably?** (`green_housekeeping`, text, optional)
	+ Please enter a description.
* **Transportation Mode 3** (`transportation_mode_3`, select_multiple, optional)
	+ Select all applicable options: Bus, Walk/Bike, Drive, Other.

## Tips

* Be as specific as possible when providing information about your initiative.
* If a field is marked as optional, please provide information if applicable.
* If a field is marked as required, please fill it out completely.
* If you have any questions or need help filling out the form, please don't hesitate to ask.
