## Purpose
This form is designed to create and manage streaming trivia quizzes. It allows you to customize a quiz with various questions, options, and settings, making it suitable for different categories and themes.

## How To Complete This Form
To complete this form, follow these steps:

1. Choose the category for your quiz from the provided options.
2. Select the number of questions for the quiz.
3. Enter the correct answers for each question.
4. Select the number of points for each question.
5. Choose the submission method (e.g., yes/no, select one, etc.).
6. Enter any additional information as needed (e.g., date, time, email).
