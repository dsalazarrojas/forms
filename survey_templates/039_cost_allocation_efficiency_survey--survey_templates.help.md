# Cost Allocation Efficiency Survey - Help Guide
## Purpose

This form is designed to help departments identify areas for improving cost allocation efficiency. It gathers information about the current cost allocation processes, challenges, and performance of cost centers.

## How To Complete This Form

1. Please answer each question to the best of your ability. If you are unsure or lack information, please provide your best estimate or guess.
2. You can select multiple options for questions that allow it (e.g., "What are the current cost processes used in your department?").

## Field-by-Field Explanation

* **Introduction**:
	+ Label: Introduction
	+ Type: Text
	+ Description: This is a brief section where you can introduce your department and provide context for the rest of the survey.
* **What are the current cost processes used in your department?**:
	+ Label: What are the current cost processes used in your department?
	+ Type: Select Multiple
	+ Description: Select all the current cost processes used in your department. This will help us understand the scope of your processes.
* **What are the main challenges faced in the current cost processes?**:
	+ Label: What are the main challenges faced in the current cost processes?
	+ Type: Select Multiple
	+ Description: Identify the main challenges you face in your current cost processes. This will help us understand the pain points you're experiencing.
* **Which cost center should be allocated the highest priority?**:
	+ Label: Which cost center should be allocated the highest priority?
	+ Type: Select One
	+ Description: Select the cost center that you believe should be allocated the highest priority.
* **What is the current cost allocation process used in your department?**:
	+ Label: What is the current cost allocation process used in your department?
	+ Type: Select Multiple
	+ Description: Select the current cost allocation process used in your department.
* **What is the current cost center performance?**:
	+ Label: What is the current cost center performance?
	+ Type: Text
	+ Description: Please describe the current cost center performance. If you're unsure, provide your best estimate or guess.
* **Do you have any additional comments or suggestions for improving cost allocation efficiency?**:
	+ Label: Do you have any additional comments or suggestions for improving cost allocation efficiency?
	+ Type: Text
	+ Description: Share any additional comments or suggestions you have for improving cost allocation efficiency.
* **Do you have any notes on the cost allocation process?**:
	+ Label: Do you have any notes on the cost allocation process?
	+ Type: Note
	+ Description: Add any relevant notes or details about the cost allocation process.
* **How transparent is the current cost allocation process?**:
	+ Label: How transparent is the current cost allocation process?
	+ Type: Select One
	+ Description: Select how transparent you believe the current cost allocation process is.

## Tips

* Please be honest and provide as much detail as possible.
* If you're unsure or lack information, please provide your best estimate or guess.
* This form is intended to be a helpful tool for improving cost allocation efficiency, and your input will help us understand your department's needs better.
