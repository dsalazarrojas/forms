# Student Quiz Feedback Survey - Help Guide

## Purpose
The "Student Quiz Feedback Survey" form is used to collect feedback from students about their recent quiz experience. This helps the instructors and administrators to understand what questions were difficult and to gather suggestions for improvement.

## How To Complete This Form
To complete this form, follow these steps:

1. Select your role in the class:
	* If you are a student, choose "Student".
	* If you are a teacher, choose "Teacher".
	* If you are both, choose "Both".
2. Answer which question was most difficult for you:
	* Choose one or more of the options that best describe your experience.
3. Add any comments about the quiz:
	* Use this field to provide any comments or suggestions about the quiz.
4. Provide your contact information:
	* Enter your email address so we can contact you if needed.
5. Enter your phone number:
	* If you have a phone number, enter it so we can contact you if needed.
6. Provide any other suggestions:
	* Use this field to provide any other suggestions or comments you may have.
7. Enter the date you attended the quiz:
	* Use the calendar to select the date you attended the quiz.
8. Select the time you started the quiz:
	* Use the dropdown menu to select the time you started the quiz.
9. Enter the name of the quiz:
	* Type in the name of the quiz you took.

## Field-by-Field Explanation
* **What is your role in the class?** (`Student`, `Teacher`, `Both`):
	+ This field is used to determine who is completing the form.
* **Which question was most difficult for you?** (`Too easy`, `Just right`, `Too hard`, `I don't know`):
	+ This field allows you to select which question was most difficult for you.
* **Do you have any comments about the quiz?** (`note`):
	+ This field is for providing any comments or suggestions about the quiz.
* **How can we contact you?** (`email`):
	+ Enter your email address so we can contact you if needed.
* **How can we contact you?** (`text`):
	+ Enter your phone number so we can contact you if needed.
* **Other suggestions** (`note`):
	+ This field is for providing any other suggestions or comments you may have.
* **When did you attend this quiz?** (`date`):
	+ Use the calendar to select the date you attended the quiz.
* **What time did you start the quiz?** (`time`):
	+ Select the time you started the quiz using the dropdown menu.
* **What is the name of the quiz?** (`text`):
	+ Type in the name of the quiz you took.

**Tips**

* Make sure to select the correct role and options for the question that was most difficult for you.
* If you have any comments or suggestions, please be as specific as possible.
* If you have any other suggestions or comments, please enter them in the "Other suggestions" field.
* Use the calendar to select the correct date and the dropdown menu to select the correct time.
