# Product Feature Priority Poll - Help Guide
## Purpose
The Product Feature Priority Poll is a form used to collect feedback and input from users regarding the priority of specific product features. This form helps developers and stakeholders make informed decisions about which features to develop and prioritize next.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter a title for the poll in the "form_title" field. This should be a brief description of the poll.
2. Select the category for the poll in the "category" field. This will help us group similar polls together.
3. Enter a description of the poll in the "description" field. This should be a brief explanation of the poll.
4. Enter the name of the feature you'd like to prioritize in the "feature_name" field.
5. Enter the value of the feature in the "value" field. This could be a number or text describing the value of the feature.
6. Select the priority level for the feature from the options in the "priority" field. This could be High, Medium, or Low.
7. Enter any additional insights or comments about the feature in the "customer_insights" field.
8. Enter your email address in the "email" field so we can contact you if needed.
9. Enter your phone number in the "phone" field.

## Field-by-Field Explanation
* **form_title** (Text, Optional): Enter a title for the poll.
* **category** (Select One, Optional): Select a category for the poll to help us group similar polls together.
* **description** (Text, Optional): Enter a description of the poll.
* **feature_name** (Text, Optional): Enter the name of the feature you'd like to prioritize.
* **value** (Text, Optional): Enter the value of the feature.
* **Feature Value 2** (Text, Optional): Enter any additional value-related information about the feature.
* **Feature Value 3** (Text, Optional): Enter any other value-related information about the feature.
* **priority** (Select One, Optional): Select the priority level for the feature (High, Medium, or Low).
* **customer_insights** (Text, Optional): Enter any additional insights or comments about the feature.
* **email** (Email, Optional): Enter your email address so we can contact you if needed.
* **phone** (Text, Optional): Enter your phone number.
