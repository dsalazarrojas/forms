# Universal Shopping List - Help Guide
## Purpose
The Universal Shopping List form is designed for users to create and manage shopping lists. It gathers information about items, including their name, value, quantity, category, and other relevant details.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the first item list (Item List 1).
2. Enter the item name in the Item Name field.
3. Enter the item value in the Item Value field.
4. Enter the quantity of the item you want to purchase.
5. Choose a category for the item from the Category dropdown menu.
6. Add any additional notes about the item in the Note field.
7. Enter your email address in the Email field (optional).
8. Enter your phone number in the Phone field (optional).
9. Set the Date Added and Time Added fields according to when you added the item to the list.
10. Select the Assigned User who will handle the item purchase.

## Field-by-Field Explanation
* **Item List 1**: Enter the first list of items to be purchased.
* **Item Name**: Enter the name of the item you want to add to the list.
* **Item Value**: Enter the value of the item (price or cost).
* **Quantity**: Enter the quantity of the item you want to purchase.
* **Category**: Select the category of the item from the dropdown menu.
* **Category Options**:
	+ Option 1
	+ Option 2
	+ Option 3
* **Note**: Enter any additional notes or comments about the item.
* **Email**: Enter your email address (optional, but recommended for tracking purposes).
* **Phone**: Enter your phone number (optional).
* **Date Added**: Set the date when you added the item to the list.
* **Time Added**: Set the time when you added the item to the list.
* **Assigned User**: Select the user who will handle the item purchase.

## Tips
* Ensure each field is filled out accurately to prevent duplicates and ensure correct data collection.
* Use the Category field to categorize items for easier management.
* Use the Note field to add any additional information about the item.
* Enter your email and phone number if you want to be notified about updates or changes to the list.
* Use the Date Added and Time Added fields to track when items were added to the list.
* Review the form carefully before submitting to ensure accuracy.
