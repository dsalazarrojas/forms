# international_awareness_pre_activity_survey - Help Guide
## Purpose

The purpose of this form is to collect information about the respondent's background, demographics, and international awareness.

## How To Complete This Form

To complete this form, follow these steps:

1. Review each page carefully and ensure you have all the necessary information to complete it accurately.
2. Answer each question truthfully and thoroughly, providing as much detail as possible.
3. Make sure to complete all required fields (indicated by a red asterisk \*).
4. If a field is optional, use your discretion and provide information only if you have relevant data.

## Field-by-Field Explanation

* **background_info** (`background_info`, `text`, required/optional): Enter a brief description of your background and relevant information about yourself.
* **demographic_info** (`demographic_info`, `select_one`, required): Indicate if you have a background in international relations or experience abroad (Yes/No).
* **learning_goals** (`learning_goals`, `select_multiple`, required): Select all the learning goals that apply to you (Yes/No, multiple selection allowed).
* **global_experience** (`global_experience`, `date`, optional): If relevant, provide the date of your global experience (leave blank if none).
* **international_travel** (`international_travel`, `text`, optional): If you have traveled internationally, provide a brief description of your experiences.
* **previous_experience** (`previous_experience`, `text`, optional): If you have previous experience in international relations, provide a brief description of your experiences.
* **international_awareness_pre_activity_survey_form_help** (`international_awareness_pre_activity_survey_form_help`, `note`, optional): If you have any questions or need help, please use this field to ask.
* **international_awareness_pre_activity_survey_form_additional_info** (`international_awareness_pre_activity_survey_form_additional_info`, `select_one`, optional): If you have additional information to provide, select "Yes" and add the information.
* **background_info_2**, **background_info_3**, ..., **background_info_18** (`background_info_2`, `text`, optional): Enter additional background information (please note that these fields are optional and may not be applicable to everyone).

Please note that the fields with background_info_2, background_info_3, etc. are optional and are meant to collect more information about your background if needed. If you're unsure about any field or have questions, please don't hesitate to reach out to the form's administrator.
