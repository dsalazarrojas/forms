# Incident Report Insights Survey - Help Guide
## Purpose
This survey is designed to gather information about incidents that occurred at a site. Please provide accurate and detailed responses to help us improve incident reporting and risk assessment processes.

## How To Complete This Form
1. Fill in your site name.
2. Enter the date of the incident.
3. Provide contact information for your site.
4. Specify the location where the incident occurred.
5. Report the number of employees, visitors, contractors, and supervisors present during the incident.
6. Select the types of incidents that occurred (injuries, fires, electrical issues, chemical exposure, falls, vehicular incidents, and weather-related incidents).
7. Provide a brief description of the incident.
8. Report any injuries or damage that occurred.
9. Add any comments about the incident.
10. Make recommendations for future improvement.
11. Indicate when the survey was sent.

## Field-by-Field Explanation

* **site_name** (`Text`, Optional): Enter the name of the site where the incident occurred.
* **incident_date** (`Date`, Optional): Enter the date of the incident in the format YYYY-MM-DD.
* **site_contact** (`Text`, Optional): Provide contact information for your site, including names and titles.
* **site_location** (`Text`, Optional): Specify the location where the incident occurred.
* **incident_type** (`Text`, Optional): Report the type of incident that occurred (e.g., injuries, fires, electrical issues, etc.).
* **incident_description** (`Text`, Optional): Provide a brief description of the incident.
* **site_employees** (`Number`, Optional): Report the number of employees present during the incident.
* **site_visitors** (`Number`, Optional): Report the number of visitors present during the incident.
* **site_contractors** (`Number`, Optional): Report the number of contractors present during the incident.
* **site_supervisors** (`Number`, Optional): Report the number of supervisors present during the incident.
* **site_responders** (`Number`, Optional): Report the number of responders present during the incident.
* **incident_injuries** (`Number`, Optional): Report the number of injuries that occurred.
* **incident_fires** (`Number`, Optional): Report the number of fires that occurred.
* **incident_chemical** (`Number`, Optional): Report the number of chemical exposure incidents.
* **incident_electrical** (`Number`, Optional): Report the number of electrical issues that occurred.
* **incident_falls** (`Number`, Optional): Report the number of falls that occurred.
* **incident_vehicular** (`Number`, Optional): Report the number of vehicular incidents.
* **incident_weather** (`Number`, Optional): Report the number of weather-related incidents.
* **incident_other** (`Select One`, Optional): Select the type of incident that occurred (e.g., Chemical, Electrical, Falls, etc.).
* **site_comments** (`Text`, Optional): Add any comments about the incident.
* **site_recommendations** (`Text`, Optional): Make recommendations for future improvement.
* **survey_sent** (`Date`, Optional): Indicate when the survey was sent.

Note: All fields are optional, but please provide accurate and detailed responses to help us improve incident reporting and risk assessment processes.
