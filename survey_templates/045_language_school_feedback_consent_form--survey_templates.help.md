# Language School Feedback & Consent Form - Help Guide

## Purpose
The purpose of this form is to gather feedback and consent from students and their parents regarding the language school program. This form is used to collect information about their experience and opinions on the program, as well as to record their consent to participate in the program.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill out the general feedback section (Field 1: General Feedback) with your comments and thoughts about the program.
2. Rate the overall quality of the program (Field 2: Overall Rating).
3. Add any additional comments or feedback about the program (Field 3: Comments).
4. If you are a student, enter your name (Field 4: Name) and email address (Field 5: Email), but these are not required fields.
5. Enter your phone number (Field 6: Phone), but this is not a required field.
6. Enter the name of the course you are enrolled in (Field 7: Course Name), which is required.
7. Enter the name of the instructor (Field 8: Instructor Name), which is not required.
8. Rate the quality of the course (Field 9: Course Rating) and the instructor (Field 10: Instructor Rating), which are not required.
9. Add any comments about the instructor (Field 11: Comments About Instructor) and the course (Field 12: Comments About Course), which are not required.
10. Check if you have given consent to participate in the program (Field 13: Has Given Consent), which is required.
11. If you have given consent, provide a reason for your consent (Field 14: Consent Reason), which is not required.
12. If you are a student, enter your student ID (Field 15: student_name), which is not required.
13. Enter the current date (Field 17: Date) and time (Field 18: Time), which are both required.
14. Add any additional comments or feedback (Field 19: Comments 2), which is not required.
15. Enter your email address (Field 20: Email 2), which is not required.
16. Enter the department name (Field 21: Department), which is not required.
17. Enter the course code (Field 22: Course Code), which is not required.
18. Select the type of consent you have given (Field 23: Type of Consent), which is required.
19. Add any comments about the consent process (Field 24: Comments Consent), which is not required.
20. Select the options that apply to you (Field 25: Submit), which are required.

## Field-by-Field Explanation
- **General Feedback** (`General Feedback`, text, required): This field is where you can enter any general comments or feedback about the program.
- **Overall Rating** (`Overall Rating`, number, required): This field is where you can rate the quality of the program on a scale of 1 to 5.
- **Comments** (`Comments`, text, required): This field is where you can enter any additional comments or feedback about the program.
- **Name** (`Name`, text, optional): This field is where you can enter your name if you are a student.
- **Email** (`Email`, email, optional): This field is where you can enter your email address if you are a student.
- **Phone** (`Phone`, text, optional): This field is where you can enter your phone number.
- **Course Name** (`Course Name`, text, required): This field is where you enter the name of the course you are enrolled in.
- **Instructor Name** (`Instructor Name`, text, optional): This field is where you can enter the name of the instructor.
- **Instructor Rating** (`Instructor Rating`, number, optional): This field is where you can rate the quality of the instructor on a scale of 1 to 5.
- **Comments About Instructor** (`Comments About Instructor`, text, optional): This field is where you can enter any comments about the instructor.
- **Comments About Course** (`Comments About Course`, text, optional): This field is where you can enter any comments about the course.
- **Has Given Consent** (`Has Given Consent`, select_one, required): This field is where you check if you have given consent to participate in the program.
- **Consent Reason** (`Consent Reason`, text, optional): This field is where you can enter a reason for your consent.
- **Student Name** (`Student Name`, text, optional): This field is where you can enter your student ID if you are a student.
- **Date** (`Date`, date, required): This field is where you can enter the current date.
- **Time** (`Time`, time, required): This field is where you can enter the current time.
- **Comments 2** (`Comments 2`, text, optional): This field is where you can enter any additional comments or feedback.
- **Email 2** (`Email 2`, email, optional): This field is where you can enter your email address.
- **Department** (`Department`, text, optional): This field is where you can enter the name of the department.
- **Course Code** (`Course Code`, text, optional): This field is where you can enter the course code.
- **Type of Consent** (`Type of Consent`, select_one, required): This field is where you select the type of consent you have given.
- **Comments Consent** (`Comments Consent`, text, optional): This field is where you can enter any comments about the consent process.
- **Submit** (`Submit`, select_multiple, required): This field is where you select the options that apply to you.

## Tips
- Please be honest and thorough in your answers.
- Make sure to check the correct type of consent you have given.
- If you have any questions or concerns, please contact the language school administration.
