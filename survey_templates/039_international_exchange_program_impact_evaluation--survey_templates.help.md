# International Exchange Program Impact Evaluation - Help Guide

## Purpose
This form is designed to collect data on the impact and outcomes of international exchange programs. It is essential to complete this form accurately to provide valuable insights for program improvement.

## How To Complete This Form
To complete this form, follow these steps:

1. Ensure you have all the necessary information and answers to the questions before starting.
2. Answer each question carefully, and if you're unsure about any question, feel free to ask for clarification.
3. Enter your information in the relevant fields, and use the provided hints for guidance.

## Field-by-Field Explanation

* **Program ID**: A unique identifier for the program being evaluated.
	+ Type: Number
	+ Required: Yes
* **Program Name**: The name of the program being evaluated.
	+ Type: Text
	+ Required: Yes
* **Student Name**: The name of the student participating in the program.
	+ Type: Text
	+ Required: Yes
* **Email**: The email address of the student or participant.
	+ Type: Email
	+ Required: Yes
* **Phone**: The phone number of the student or participant.
	+ Type: Text
	+ Required: Yes
* **Semester**: The semester the participant was part of the program (e.g., Fall, Spring, Summer).
	+ Type: Select One
	+ Required: Yes
* **Exchange Type**: The type of exchange program (Short-term, Long-term).
	+ Type: Select Multiple
	+ Required: Yes
* **Host University**: The name of the host university.
	+ Type: Text
	+ Required: Yes
* **Home University**: The name of the home university.
	+ Type: Text
	+ Required: Yes
* **Program Start Date**: The date the program started.
	+ Type: Date
	+ Required: Yes
* **Program End Date**: The date the program ended.
	+ Type: Date
	+ Required: Yes
* **Overall Satisfaction**: A rating of the overall satisfaction (1-5).
	+ Type: Select One
	+ Required: Yes
* **Feedback**: Any additional feedback or comments.
	+ Type: Note
	+ Required: Yes
* **Additional Comments**: Any additional information or comments about the program.
	+ Type: Note
	+ Required: No
* **Participant Survey Response**: A confirmation of participation in the survey.
	+ Type: Select One
	+ Required: Yes
* **Participant Survey Response Justification** (3 fields): Additional justifications for the survey response.
	+ Type: Text
	+ Required: No
* **Host Survey Response**: A confirmation of the host's response.
	+ Type: Select One
	+ Required: Yes
* **Host Survey Response Justification** (3 fields): Additional justifications for the host's response.
	+ Type: Text
	+ Required: No
* **Outcomes Measured** (2 fields): Additional outcomes measured in the program.
	+ Type: Text
	+ Required: Yes
* **Participant Survey Response 2**, **Host Survey Response 2** fields not included as per original form

Note: The original form had multiple fields with similar labels, and I have kept only one for each pair to avoid duplication.
