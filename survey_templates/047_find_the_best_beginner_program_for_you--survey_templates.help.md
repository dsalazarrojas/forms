# find_the_best_beginner_program_for_you - Help Guide
## Purpose

This form is designed to help you find a program that suits your needs as a beginner in the field of programming. It will ask for your goals, time commitment, level of experience, format, and preferred language to suggest a suitable program for you to learn and develop your skills.

## How To Complete This Form

1. Please answer the questions on this form to the best of your abilities.
2. Be honest and clear in your answers as they will help us to suggest the most suitable program for you.

## Field-by-Field Explanation
### What do you want to achieve? (Program Goals)
* **What do you want to achieve?** (`program_goals`, `text`, required): This is the primary purpose of your journey to learn programming. Please type down your goals, for example, "I want to learn web development" or "I want to learn mobile app development".

### How much time do you have for the program per week?
* **How much time do you have for the program per week?** (`time_commitment`, `number`, required): You should specify the amount of time you have available per week to dedicate to the program. Please type a number that reflects your available time.

### What is your level of experience?
* **What is your level of experience?** (`experience_level`, `select_one`, optional): This field allows you to select your level of experience in programming, which will help us to suggest a program suited for your skill level. Please select one of the options:
	+ Beginner
	+ Intermediate
	+ Advanced

### What format do you prefer?
* **What format do you prefer?** (`format_preference`, `select_multiple`, optional): This field allows you to select the format that you prefer for the program, which will help us to suggest the best program for you. Please select one or more of the options:
	+ Online
	+ Offline
	+ In-person
	+ Group

### What language do you prefer?
* **What language do you prefer?** (`preferred_language`, `select_one`, optional): This field allows you to select your preferred language to learn, which will help us to suggest a program that uses that language. Please select one of the options:
	+ English
	+ Spanish
	+ French

### Recommended Programs
* **Recommended Programs** (`recommended_programs`, `note`, optional): This field will provide you with a list of recommended programs based on your answers. You will not be required to input anything here, as it will be populated automatically.

### Select a program
* **Select a program** (`selected_program`, `select_one`, required): This field is a yes or no question that will ask you to confirm if you want to start a program based on our recommendations. Please select one of the options:
	+ Yes
	+ No

### Program Details
* **Program Details** (`program_details`, `select_multiple`, required): This field will allow you to select the features of the program you are interested in. Please select one or more of the options:
	+ Yes
	+ No

## Tips

* Please be honest in your answers as they will help us to suggest the best program for you.
* This form is a critical step in getting started with programming, so make sure to complete it carefully.
* If you need help or have questions, feel free to contact us.
