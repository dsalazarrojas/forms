# Indexing Knowledge Quiz - Help Guide
## Purpose

The Indexing Knowledge Quiz form is designed to gather information about knowledge quizzes, including the type of quiz, questions, and score.

## How To Complete This Form

To complete this form, follow the steps below:

1. Enter your **First Name** in the "First Name" field.
2. Enter your **Email** in the "Email" field. Please make sure to enter a valid email address.
3. Select the type of quiz you are indexing from the "Quiz Type" dropdown menu.
4. For each question, select all that apply from the "Option" dropdown menu.
5. Enter your score out of the total number of questions.
6. Add any additional comments about the quiz in the "Comments" field.

## Field-by-Field Explanation

* **First Name**: This field is used to collect your name.
	+ Type: text
	+ Required: No
* **Email**: This field is used to collect your email address.
	+ Type: email
	+ Required: No
* **Quiz Type**: This field is used to select the type of quiz you are indexing.
	+ Type: select_one
	+ Required: No
* **Question 1**: This field is used to select all applicable options for the first question.
	+ Type: select_multiple
	+ Required: No
* **Question 2**: This field is used to select all applicable options for the second question.
	+ Type: select_multiple
	+ Required: No
* **Question 3**: This field is used to select all applicable options for the third question.
	+ Type: select_multiple
	+ Required: No
* **Score**: This field is used to enter your score out of the total number of questions.
	+ Type: number
	+ Required: No
* **Comments**: This field is used to add any additional comments about the quiz.
	+ Type: text
	+ Required: No

## Tips

* Please ensure that you are completing this form for the intended purpose of indexing knowledge quizzes.
* If you have any issues with the form, contact the support team for assistance.
