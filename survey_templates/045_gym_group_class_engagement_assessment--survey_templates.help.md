# Gym Group Class Engagement Assessment - Help Guide
## Purpose
The Gym Group Class Engagement Assessment form is designed to gather information about the engagement level of a group class in a gym. The form is used to track and analyze the progress, feedback, and performance of each class.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter your First Name in the First Name field.
2. Enter your Email in the Email field.
3. Provide Feedback in the Feedback field.
4. Enter the Class Name in the Class Name field.
5. Select the Date of the class in the Date field.
6. Choose the Time of the class in the Time field.
7. Select the Level of difficulty for the class in the Level of difficulty field.
8. Indicate your Engagement level in the Engagement level field.
9. Add any Suggestions for improvement or comments in the Suggestions field (optional).
10. Enter the Assigned Tool used in the Assigned Tool field.
11. Enter the Category of the class in the Category field.
12. Enter a Description of the class in the Description field.
13. Enter any Tags for the class in the Tags field.
14. Enter any Comments about the class in the Comments field.
15. Enter a Score for the class in the Score field.
16. Select the Status of the class in the Status field.
17. (Optional) Enter the Completed Date of the class in the Completed Date field.
18. Enter the Created Date of the class in the Created Date field.
19. Enter the Last Update Date of the class in the Last Update field.
20. Enter the Comments Count for the class in the Comments Count field.
21. Enter the Score Count for the class in the Score Count field.
22. Enter the Created By of the class in the Created By field.
23. Enter the Assigned To of the class in the Assigned To field.
24. Enter the Updated By of the class in the Updated By field.
25. Enter the Updated At of the class in the Updated At field.

## Field-by-Field Explanation
* **First Name** (`first_name`, text, required): Enter your name as it appears on your official documentation.
* **Email** (`email`, email, required): Enter your gym email address.
* **Feedback** (`feedback`, text, required): Provide feedback about your experience with the class.
* **Class Name** (`class_name`, text, required): Enter the name of the class.
* **Date** (`date`, date, required): Select the date of the class.
* **Time** (`time`, time, required): Select the time of the class.
* **Level of difficulty** (`level`, select_one, required): Select the level of difficulty for the class.
* **Engagement level** (`engagement`, select_multiple, required): Indicate your level of engagement with the class.
* **Suggestions** (`suggestions`, note, optional): Add any suggestions for improvement or comments.
* **Assigned Tool** (`assigned_tool`, text, required): Enter the tool assigned to you for the class.
* **Category** (`category`, text, required): Enter the category of the class.
* **Description** (`description`, text, required): Enter a description of the class.
* **Tags** (`tags`, text, required): Enter any tags for the class.
* **Comments** (`comments`, text, required): Enter any comments about the class.
* **Score** (`score`, number, required): Enter a score for the class.
* **Status** (`status`, select_one, required): Select the status of the class.
* **Completed Date** (`completed_date`, date, optional): Enter the completed date of the class.
* **Created Date** (`created_date`, date, required): Enter the created date of the class.
* **Last Update** (`last_update`, date, required): Enter the last update date of the class.
* **Comments Count** (`comments_count`, number, required): Enter the comments count for the class.
* **Score Count** (`score_count`, number, required): Enter the score count for the class.
* **Created By** (`created_by`, text, required): Enter the name of the person who created the class.
* **Assigned To** (`assigned_to`, text, required): Enter the name of the person assigned to the class.
* **Updated By** (`updated_by`, text, required): Enter the name of the person who last updated the class.
* **Updated At** (`updated_at`, date, required): Enter the updated at date of the class.
