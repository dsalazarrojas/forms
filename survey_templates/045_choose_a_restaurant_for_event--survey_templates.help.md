# Choose A Restaurant For Event - Help Guide

## Purpose
This form is designed to collect information about your event details, such as event type, date, time, number of guests, and other relevant information. The form is intended to help you find the best-suited restaurant for your event.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the type of event you are planning.
2. Enter the event date.
3. Enter the event time.
4. Specify the number of guests.
5. Provide your contact information (name, email, and phone number).
6. Select your preferred cuisine types.
7. Choose the preferred atmosphere and noise level of the restaurant.
8. Indicate whether you need a private room and if you have any dietary restrictions.
9. Select your preferred method of payment and specify if you have any budget limits.
10. Indicate your preferences for alcohol service.
11. Provide any additional requests or comments.
12. Finally, review and submit the form.

## Field-by-Field Explanation

* **Event Name** (`event_name`, Text, Required): Enter the name of your event.
* **Event Type** (`event_type`, Select One, Required): Select the type of event you are planning (e.g., Business meeting, Team lunch, Team dinner, etc.).
* **Event Date** (`event_date`, Date, Required): Enter the date of the event.
* **Event Time** (`event_time`, Time, Required): Enter the time of the event.
* **Number of Guests** (`number_of_guests`, Number, Required): Enter the number of guests attending the event.
* **Your Name** (`organizer_name`, Text, Required): Enter your name as the event organizer.
* **Email Address** (`organizer_email`, Email, Required): Enter your email address.
* **Phone Number** (`organizer_phone`, Text, Required): Enter your phone number.
* **Preferred Cuisine Types** (`preferred_cuisines`, Select Multiple, Required): Select all the cuisine types you prefer (e.g., American, Italian, Vegetarian, etc.).
* **Cuisines to Avoid** (`cuisine_to_avoid`, Text, Optional): If you have any cuisine types you prefer not to be served, enter them here.
* **Price Range Per Person** (`price_range`, Select One, Required): Select the price range per person you are willing to pay.
* **Dietary Requirements** (`dietary_requirements`, Note, Optional): If you have any special dietary needs, specify them here.
* **Dietary Restrictions** (`dietary_restrictions`, Select Multiple, Required): Select any dietary restrictions you have (e.g., Vegetarian, Vegan, etc.).
* **Location Preferences** (`location_preferences`, Note, Optional): If you have any preferred location or neighborhood for the event, enter them here.
* **Preferred Area or Neighborhood** (`preferred_area`, Text, Optional): If you have any preferred location or neighborhood, enter them here.
* **Maximum Distance from Center** (`distance_radius`, Select One, Optional): Select the maximum distance from the center you are willing to travel.
* **Is Parking Important** (`parking_needed`, Select One, Required): Indicate whether parking is essential or not.
* **Is Wheelchair Accessibility Needed** (`accessibility_needed`, Select One, Required): Indicate whether the restaurant needs to be wheelchair accessible.
* **Preferred Atmosphere** (`preferred_atmosphere`, Select One, Required): Select the preferred atmosphere of the restaurant (e.g., Casual, Upscale, etc.).
* **Noise Level** (`noise_level`, Select One, Required): Select the preferred noise level of the restaurant.
* **Is a Private Room Needed** (`private_room`, Select One, Required): Indicate whether a private room is essential or not.
* **Restaurant Suggestions** (`restaurant_suggestions`, Note, Optional): If you have any restaurant suggestions, enter them here.
* **Do you have Restaurant Suggestions** (`have_suggestions`, Select One, Required): Indicate whether you have any restaurant suggestions.
* **List Suggested Restaurants** (`suggested_restaurants`, Text, Optional): If you have any suggested restaurants, enter them here.
* **Restaurants to Avoid** (`restaurants_to_avoid`, Text, Optional): If there are any restaurants you do not prefer, enter them here.
* **Budget Information** (`budget_information`, Note, Optional): If you have any budget information, enter them here.
* **Payment Method** (`payment_method`, Select One, Required): Select the method of payment (e.g., Company paid, Split evenly, etc.).
* **Total Budget Limit** (`budget_limit`, Number, Optional): Enter any budget limit you may have.
* **Alcohol Preferences** (`alcohol_preferences`, Note, Optional): If you have any alcohol preferences, enter them here.
* **Alcohol Service Preference** (`alcohol_service`, Select One, Required): Select the preferred method of alcohol service (e.g., Full bar, Beer and wine only, etc.).
* **Additional Requests** (`additional_requests`, Note, Optional): If you have any additional requests, enter them here.
* **Special Occasions to Acknowledge** (`special_occasions`, Text, Optional): If you have any special occasions to acknowledge, enter them here.
* **AV or Presentation Needs** (`av_needs`, Text, Optional): If you have any AV or presentation needs, enter them here.
* **Additional Comments** (`additional_comments`, Text, Optional): Enter any additional comments you may have.
* **Decision Timeline** (`decision_timeline`, Date, Optional): If you have any deadline for when you need to make a decision, enter them here.
* **Organizer Signature** (`organizer_signature`, Text, Required): Enter a digital signature to confirm you are the event organizer.
* **Date of Submission** (`submission_date`, Date, Required): Enter the date of submission of this form.
