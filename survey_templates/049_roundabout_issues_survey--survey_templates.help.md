# Roundabout Issues Survey - Help Guide
## Purpose
This form is designed to collect information about your experiences and concerns regarding roundabouts. We want to know about any issues you've encountered while interacting with roundabouts, which will help us improve the design and functionality of roundabouts in the area.

## How To Complete This Form
- Start by reading the introduction, which will provide context for the questions that follow.
- Answer the questions in the order they appear, starting with "roundabout_type" and moving through the remaining fields.
- For each question, provide as many details as you feel are relevant.
- You may leave the "comments" field blank if you have nothing to add.

## Field-by-Field Explanation

* **Introduction** (`title`, `note`, required: false): This section provides background information about the form and its purpose. Please read through to understand the context for the questions that follow.
* **Roundabout Type** (`roundabout_type`, `select_one`, required: false): Please select the type of roundabout you are interacting with from the options provided:
	+ roundabout: A traditional roundabout with no traffic lanes or signals.
	+ traffic circle: A traffic circle with one or more traffic lanes or signals.
	+ turn lane: A roundabout with a dedicated turn lane.
* **Do you have any safety concerns about the roundabout?** (`safety_concerns`, `select_multiple`, required: false): If you have any safety concerns, please select all that apply:
	+ too fast
	+ too slow
	+ not enough signage
	+ too narrow
	+ not enough space
	+ other (please specify in the comments)
* **Comments** (`comments`, `text`, required: false): If you have any additional thoughts or suggestions, please provide them here. This is an optional field, so feel free to skip it if you don't have anything to add.
