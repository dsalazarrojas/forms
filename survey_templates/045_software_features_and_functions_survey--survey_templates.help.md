# Software Features And Functions Survey - Help Guide
## Purpose
This form is designed to collect feedback on the software features and functions. It aims to gather opinions on what features are available, how well they perform, and how easy they are to use.

## How To Complete This Form
To complete this form, follow these steps:

1. Start on the **Intro Page**. This page provides an introduction to the survey and explains what you will be asked to do.
2. On the **Features** page, select all the features that you have used or are familiar with. This will help us understand which features you have experience with.
3. On the **Performance** page, select the level of performance you experienced with the features you selected. Choose from **High**, **Medium**, or **Low**.
4. On the **Usability** page, rate the features in terms of how easy they are to use. Select all the features that you think are easy to use, medium to use, or difficult to use.
5. Finally, you can add any additional **Comments** on the **Comments** page if you have any thoughts or feedback that you don't see covered in the previous pages.

## Field-by-Field Explanation
### **Intro Page**
*   **Intro Page** (Page 1, Note, Required: False): This is the first page of the survey where you will find an introduction to the survey and what it is about.

### **Features**
*   **Features** (Page 2, Select Multiple, Required: False): Select all the features that you have used or are familiar with. This will help us understand which features you have experience with.

### **Performance**
*   **Performance** (Page 3, Select One, Required: False): On this page, select the level of performance you experienced with the features you selected. Choose from **High**, **Medium**, or **Low**.

### **Usability**
*   **Usability** (Page 4, Select Multiple, Required: False): Rate the features in terms of how easy they are to use. Select all the features that you think are easy to use, medium to use, or difficult to use.

### **Comments**
*   **Comments** (Page 5, Note, Required: False): You can add any additional comments or feedback on this page if you have any thoughts or opinions that you don't see covered in the previous pages.

## Tips
*   Be honest and thorough in your feedback.
*   Take your time to answer all the questions carefully.
*   If you have any questions or concerns, don't hesitate to contact us.
