# Theme Park Attraction Satisfaction Survey - Help Guide
## Purpose
This survey aims to collect feedback from visitors to theme park attractions, allowing us to understand their experiences and satisfaction with different theme park attractions.

## How To Complete This Form
1. Please provide your honest answers to the following questions.
2. You can fill in as much or as little information as you like, depending on your preference.
3. If you have any comments or feedback, please use the text box provided.

## Field-by-Field Explanation
* **Theme Park Attraction Name** (`Theme Park Attraction Name`, `text`, required: false): Enter the name of the theme park attraction you visited.
* **Rating** (`Rating`, `number`, required: false): Rate your experience with this attraction from 1 to 5, where 1 is the lowest and 5 is the highest.
* **Visited Before** (`Visited Before`, `select_one`, required: false): Indicate if you have visited this attraction before.
	+ Park Name: If you have visited this attraction before, select this option.
	+ Theme Park: If you have visited this attraction as part of a theme park visit, select this option.
	+ True: If you have visited this attraction before, select this option.
	+ False: If you have not visited this attraction before, select this option.
* **Visited Last Visit** (`Visited Last Visit`, `select_multiple`, required: false): Choose when you last visited this attraction:
	+ Last 30 days: If you visited this attraction within the last 30 days, select this option.
	+ Between 1-30 days: If you visited this attraction between 1 and 30 days ago, select this option.
	+ More than 30 days: If you visited this attraction more than 30 days ago, select this option.
* **Attraction Type** (`Attraction Type`, `select_one`, required: false): Indicate the type of attraction:
	+ Roller Coaster: If you visited a roller coaster, select this option.
	+ Water Ride: If you visited a water ride, select this option.
	+ Live Show: If you visited a live show, select this option.
* **Time Spent** (`Time Spent`, `time`, required: false): Estimate how much time you spent at this attraction.
* **Comments** (`Comments`, `text`, required: false): Share any additional comments or feedback you have about this attraction.
* **Email** (`Email`, `email`, required: false): Enter your email address if you would like to be contacted about this survey.
* **Phone** (`Phone`, `text`, required: false): Enter your phone number if you would like to be contacted about this survey.
* **Feedback** (`Feedback`, `note`, required: false): Share any further feedback or suggestions you may have about this attraction.

Note: The email and phone fields are optional and only required if you want to be contacted about this survey.
