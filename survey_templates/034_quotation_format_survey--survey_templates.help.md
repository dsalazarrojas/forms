# quotation_format_survey - Help Guide
## Purpose
This form is designed to gather information on quotation format preferences from clients. It helps ensure that clients' expectations are met and provides them with a clear understanding of how their projects will be handled.

## How To Complete This Form
To complete this form, follow these steps:

1. Please read the introduction page.
2. Select "Yes" or "No" for client information and project requirements.
3. Choose "Yes" or "No" for budget expectations.
4. Select "Yes" or "No" for submission details.

## Field-by-Field Explanation

* **Client Info (client_info, text, optional)**: Please provide any relevant information about your client that will help us understand their quotation format preferences.
* **Project Requirements (project_requirements, select multiple, optional)**: Indicate whether your project has any specific requirements that need to be met in the quotation format.
* **Budget Expectations (budget_expectations, select multiple, optional)**: Choose how you expect to be informed about budget details in the quotation format.
* **Submission Details (submission_details, select one, optional)**: Select how you expect to receive submission details in the quotation format.
