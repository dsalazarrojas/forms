# Multi Stakeholder Feedback Survey - Help Guide
## Purpose
This form is used to collect feedback from multiple stakeholders on a project's performance.

## How To Complete This Form
To complete this form, follow these steps:

1. Select all the relevant stakeholders that are involved in the project.
2. Choose the project status from the provided options.
3. Enter the project name and description in the respective fields.
4. Enter the start and end dates of the project.
5. Rate the project using the rating scale provided (if applicable).
6. Provide any additional feedback on the project.
7. Enter your email address.

## Field-by-Field Explanation

* **Project Team**: Select all the team members involved in the project from the list of options.
	+ Project Manager
	+ Team Lead
	+ Team Member
	+ Other ( specify in the "Other" field)
* **Stakeholders**: Select all the stakeholders involved in the project from the list of options.
	+ Client
	+ Stakeholder Group
	+ Vendor
	+ Other (specify in the "Other" field)
* **Rating Scale**: This field is only applicable if the project status is "Active". Enter a rating between 1 and 5.
* **Feedback**: Provide any additional feedback on the project.
* **Email**: Enter your email address to receive any notifications related to the project.
* **Project Status**: Choose the current status of the project from the provided options.
	+ Active
	+ Inactive
* **Project Name**: Enter the name of the project.
* **Project Start Date**: Enter the start date of the project.
* **Project End Date**: Enter the end date of the project.
* **Project Description**: Enter a brief description of the project.
