# horror-movie-viewing-checklist - Help Guide
## Purpose
This form is designed to gather information about your horror movie viewing habits and preferences. Please complete the form to share your experiences and opinions about horror movies.

## How To Complete This Form
To complete this form, simply go through the fields below and select your answers as follows:
* Answer all fields with a "Yes" or "No" as applicable.
* If you have watched a movie, select "Yes" under "Watched".
* For fields like "Genre preference", you can select multiple options if you enjoy multiple genres.

## Field-by-Field Explanation
* **Movie title** (`movie_title`, text, optional): Enter the title of the horror movie you're thinking about.
* **Horror genre** (`genre`, select_one, optional): Check if the movie is of the horror genre.
* **Year released** (`year_released`, number, optional): Enter the year the movie was released.
* **Runtime** (`runtime`, select_one, optional): Check the runtime of the movie.
* **Plot** (`plot_summery`, select_multiple, optional): Select all plot elements you enjoy in a horror movie.
* **Director** (`director`, select_multiple, optional): Check if you enjoy movies directed by this director.
* **Stars** (`stars`, select_multiple, optional): Check if you enjoy movies with these stars.
* **Runtime (minutes)** (`runtime_minutes`, number, optional): Enter the runtime of the movie in minutes.
* **Budget** (`budget`, number, optional): Enter the budget of the movie.
* **Rating** (`rating`, select_one, optional): Rate the movie as "Good" or "Fair".
* **Watched** (`watched`, select_one, optional): Check if you've watched the movie.
* **Genre preference** (`genre_preference`, select_multiple, optional): Select all horror movie genres you enjoy.
* **Watched before** (`watched_before`, select_one, optional): Check if you've watched the movie before.
* **Watched with** (`watched_with`, select_multiple, optional): Select who you watched the movie with.
* **Watched alone** (`watched_alone`, select_one, optional): Check if you watched the movie alone.
* **Watched in the theatre** (`watched_in_theatre`, select_one, optional): Check if you watched the movie in the theatre.
* **Watched streaming** (`watched_streaming`, select_one, optional): Check if you watched the movie streaming.
* **Watched on DVD** (`watched_on_dvd`, select_one, optional): Check if you watched the movie on DVD.
* **Watched rented** (`watched_rented`, select_one, optional): Check if you watched the movie after renting it.
* **Watched bought** (`watched_bought`, select_one, optional): Check if you bought the movie.
* **Watched purchase option** (`watched_purchase_option`, select_multiple, optional): Select all purchase options you've used for the movie.
* **Purchase DVD** (`purchase_dvd`, select_one, optional): Check if you purchased the movie on DVD.
* **Purchase on digital** (`purchase_on_digital`, select_one, optional): Check if you purchased the movie digitally.
* **Purchase streaming** (`purchase_streaming`, select_one, optional): Check if you purchased the movie streaming.
* **Purchase CD** (`purchase_cd`, select_one, optional): Check if you purchased the movie on CD.
