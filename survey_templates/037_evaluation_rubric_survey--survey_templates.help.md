# Evaluation Rubric Survey - Help Guide

## Purpose

This form is a tool for evaluating a user's performance or achievement in a specific domain. It helps to assess whether a submission meets the required criteria and provides feedback and assessment from an evaluator.

## How To Complete This Form

To complete this form, follow these steps:

1. Enter a title for the evaluation in the **Survey Title** field.
2. Choose a **What is the rating scale?** rating from the options provided.
3. Enter any additional **Criteria** that were not included in the list.
4. Select which **Criterion** applies to the submission.
5. Enter your **Evaluation** of the submission (yes or no).
6. Select which **Rubric** applies to the submission (yes or no).
7. Enter any comments about the submission in the **Comments** field.
8. Enter the date and time of submission if relevant.
9. Enter your email and phone number if you want to be contacted for follow-up evaluation.
10. Enter a **Form ID** to reference the submission.
11. Enter a brief **Category** for the submission.
12. Enter a description of the submission if necessary.

## Field-by-Field Explanation

* **Survey Title** (`survey_title`, text, required: false): Enter a brief title for the evaluation.
* **What is the rating scale?** (`rating_scale`, select_one, required: false): Choose the rating scale that best describes the evaluation (e.g. Good, Fair).
* **Criteria** (`criteria`, text, required: false): Enter any additional criteria that were not included in the list.
* **Criterion** (`criterion`, text, required: false): Select which criterion applies to the submission.
* **Evaluation** (`evaluation`, select_one, required: false): Enter your evaluation of the submission (yes or no).
* **Rubric** (`rubric`, select_multiple, required: false): Select which rubric applies to the submission (yes or no).
* **Comments** (`comments`, note, required: false): Enter any comments about the submission.
* **Submission** (`submission`, date, required: false): Enter the date of submission if relevant.
* **Submission Time** (`submission_time`, time, required: false): Enter the time of submission if relevant.
* **Submission Date** (`submission_date`, date, required: false): Enter the date of submission if relevant.
* **E-mail** (`email`, email, required: false): Enter your email address if you want to be contacted for follow-up evaluation.
* **Phone** (`phone`, text, required: false): Enter your phone number if you want to be contacted for follow-up evaluation.
* **Form ID** (`form_id`, text, required: false): Enter a reference number for the submission.
* **Category** (`category`, text, required: false): Enter a brief category for the submission.
* **Description** (`description`, text, required: false): Enter a brief description of the submission if necessary.
