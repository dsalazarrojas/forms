# Historical Document Review Form - Help Guide
## Purpose
The purpose of this form is to collect information about historical documents for review purposes. The form is used by experts to evaluate and provide feedback on the accuracy and completeness of historical documents.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the type of document you are reviewing (e.g. Document, Manuscript, Artifact).
2. Enter the date of publication (if applicable).
3. Upload a file or provide a file URL (if applicable).
4. Enter a rating (out of 5) to indicate your overall assessment of the document.
5. Add any comments or feedback you'd like to provide.
6. Enter the URL of the file (if you uploaded it).
7. Describe the file in detail (if you uploaded it).
8. Enter the size of the file in MB (if you uploaded it).
9. Select the type of file you uploaded (e.g. Text, Image, Audio, Video).
10. Select the format of the file (e.g. PDF, JPEG, MP3, MP4).
11. Enter the date of your review.
12. Enter your name and title (e.g. Professor, Historian, Researcher).
13. Enter the name of the organization or institution associated with the document.

## Field-by-Field Explanation

* **Document Type** (`document_type`): Choose the type of document you are reviewing. For example, if you are evaluating a historical text, select "Document". If you are reviewing an image, select "Artifact".
* **Date of Publication** (`date_of_publication`): Enter the date the document was published, if applicable. This is useful for understanding the historical context of the document.
* **File Upload** (`file_upload`): If you have a file to upload, use this field to attach it to the review form. You can also enter a file URL if you don't want to upload a file.
* **Rating (out of 5)** (`rating`): Rate the document based on its accuracy and completeness. A rating of 5 indicates a perfect score, while a rating of 1 indicates a poor score.
* **Comments** (`comment`): Add any additional comments or feedback you'd like to provide about the document.
* **File URL** (`file_url`): Enter the URL of the file you uploaded, if you chose to upload a file.
* **File Description** (`file_description`): Describe the file in detail, if you uploaded it. For example, you might describe a text file as "a historical essay on the American Revolution".
* **File Size (MB)** (`file_size`): Enter the size of the file you uploaded, if you chose to upload it.
* **File Type** (`file_type`): Select the type of file you uploaded (e.g. Text, Image, Audio, Video).
* **File Format** (`file_format`): Select the format of the file you uploaded (e.g. PDF, JPEG, MP3, MP4).
* **Review Date** (`review_date`): Enter the date you completed this review.
* **Reviewer's Name** (`reviewer_name`): Enter your name as you'd like to be credited for this review.
* **Reviewer's Title** (`reviewer_title`): Enter your title or position (e.g. Professor, Historian, Researcher).
* **Organization** (`organization`): Enter the name of the organization or institution associated with the document.

## Tips

* Please review the document carefully and provide thorough feedback.
* Be sure to enter accurate information for each field.
* If you're unsure about any field, refer to the form's instructions or contact your supervisor or project lead.
