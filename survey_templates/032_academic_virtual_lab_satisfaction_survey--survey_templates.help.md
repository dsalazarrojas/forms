# Academic Virtual Lab Satisfaction Survey - Help Guide
## Purpose
This guide will walk you through the process of completing the Academic Virtual Lab Satisfaction Survey form. The feedback collected through this form will help us improve the quality and effectiveness of our virtual lab platform.

## How To Complete This Form
To complete this form, follow these steps:

1. Review each page carefully to ensure you understand the question and the options available for each question.
2. For select_one questions, choose the option that best describes your experience with the virtual lab.
3. For text questions, provide as much detail as possible in the space provided.

## Field-by-Field Explanation
- **-- Academic Virtual Lab Satisfaction Survey --** (Page 1)
	* This is the title of the survey, and it's not a question to answer. Simply read the page and start with the next question.
- **Your role** (`respondent_role`, required)
	* Please select the category that best describes your role in using the virtual lab:
		+ Student
		+ Faculty
		+ Teaching Assistant
		+ Lab Technician
		+ Staff
- **Department or course** (`department`, required)
	* Please enter the name of the department or course that you are using the virtual lab for.
- **Name of the virtual lab course or module** (`lab_course_name`, required)
	* Enter the name of the virtual lab course or module you used.
- **How often did you use the virtual lab** (`frequency_of_use`, required)
	* Select the frequency with which you used the virtual lab:
		+ Daily
		+ Several times a week
		+ Once a week
		+ A few times during the semester
		+ Only once
- **How easy was it to access the virtual lab platform** (`ease_of_access`, required)
	* Select the level of difficulty you experienced in accessing the virtual lab platform:
		+ Very difficult
		+ Difficult
		+ Neutral
		+ Easy
		+ Very easy
- **How would you rate the technical quality of the virtual lab (speed, reliability, graphics)?** (`technical_quality`, required)
	* Evaluate the technical quality of the virtual lab:
		+ Poor
		+ Fair
		+ Good
		+ Very good
		+ Excellent
- **How relevant was the virtual lab content to your course objectives** (`content_relevance`, required)
	* Assess the relevance of the virtual lab content to your course objectives:
		+ Not relevant
		+ Slightly relevant
		+ Moderately relevant
		+ Very relevant
		+ Extremely relevant
- **How effective was the virtual lab in helping you learn compared to a physical lab** (`learning_effectiveness`, required)
	* Compare the effectiveness of the virtual lab to a physical lab:
		+ Much less effective
		+ Somewhat less effective
		+ About the same
		+ Somewhat more effective
		+ Much more effective
- **How clear were the instructions provided for virtual lab activities** (`instructions_clarity`, required)
	* Evaluate the clarity of the instructions provided for virtual lab activities:
		+ Very unclear
		+ Somewhat unclear
		+ Neutral
		+ Somewhat clear
		+ Very clear
- **Did you experience any technical issues during virtual lab sessions?** (`technical_issues`, required)
	* Select the frequency with which you experienced technical issues:
		+ Never
		+ Rarely
		+ Sometimes
		+ Often
		+ Very often
- **If you needed technical support, how responsive was it?** (`technical_support_rating`, optional)
	* Evaluate the responsiveness of technical support if you needed it:
		+ Did not need support
		+ Very unresponsive
		+ Somewhat unresponsive
		+ Neutral
		+ Responsive
		+ Very responsive
- **Overall, how satisfied are you with the virtual lab experience?** (`overall_satisfaction`, required)
	* Rate your overall satisfaction with the virtual lab experience:
		+ Very dissatisfied
		+ Dissatisfied
		+ Neutral
		+ Satisfied
		+ Very satisfied
- **Would you recommend virtual labs to other students?** (`recommend_virtual_lab`, required)
	* Select whether you would recommend virtual labs to other students:
		+ Yes - definitely
		+ Yes - with some improvements
		+ Neutral
		+ False
- **What improvements would make the virtual lab experience better?** (`improvement_suggestions`, optional)
	* If you have any suggestions for improving the virtual lab, please enter them here.

## Tips
* Please answer honestly and accurately based on your experience with the virtual lab.
* If you have any suggestions or ideas for improvement, provide them in the "What improvements would make the virtual lab experience better?" question.
* If you have any questions or concerns, feel free to contact us.
