# Dance Recital Theme Voting Form - Help Guide
## Purpose
The dance recital theme voting form is designed to gather theme suggestions from users before the dance recital. The form will help determine the most popular themes among the users, which will influence the final theme selection for the dance recital.

## How To Complete This Form
1.  Select the theme(s) that you are interested in by clicking on the corresponding checkbox.
2.  Provide a brief description of your chosen theme(s) in the dedicated text field(s).
3.  Click the "Submit" button to submit your theme suggestion(s).

## Field-by-Field Explanation
* **Yes/No (`select_theme`, select_one, required: false):** Select "Yes" if you are interested in the theme, or "No" if you are not. This will help us determine the popularity of each theme.
* **Theme 1 (`theme_1`, text, required: true):** Enter a brief description of Theme 1.
* **Theme 2 (`theme_2`, text, required: true):** Enter a brief description of Theme 2.
* **Theme 3 (`theme_3`, text, required: true):** Enter a brief description of Theme 3.
* **Theme 4 (`theme_4`, text, required: true):** Enter a brief description of Theme 4.
* **Theme 5 (`theme_5`, text, optional):** Enter a brief description of Theme 5 (optional).
* **Theme 6 (`theme_6`, text, optional):** Enter a brief description of Theme 6 (optional).
* **Theme 7 (`theme_7`, text, optional):** Enter a brief description of Theme 7 (optional).
* **Theme 8 (`theme_8`, text, optional):** Enter a brief description of Theme 8 (optional).
* **Theme 9 (`theme_9`, text, optional):** Enter a brief description of Theme 9 (optional).
* **Theme 10 (`theme_10`, text, optional):** Enter a brief description of Theme 10 (optional).

## Tips
* Make sure to provide clear and concise descriptions for each theme to help us determine the most popular themes.
* Do not submit multiple theme submissions for the same theme.
* Do not provide excessive or off-topic information.
* If you have any questions or concerns, please contact the administrators.
