# general_purpose_worksheet - Help Guide
## Purpose
The general_purpose_worksheet form is a template used to gather basic information about a project or task.

## How To Complete This Form
1. Fill out each field with the corresponding information.
2. Ensure to provide accurate and detailed responses for each field.
3. Review your completed form for any errors or inconsistencies.

## Field-by-Field Explanation
* **Project Name** (`project_name`, text, optional): Enter the name of the project or task.
* **Project Details** (`project_details`, text, optional): Provide a brief description of the project or task.
* **Project Status** (`project_status`, select_one, optional): Select the status of the project or task from the available options: Active, Completed, or In Progress.
* **Project Type** (`project_type`, select_multiple, optional): Choose the type(s) of the project or task from the available options: Type 1, Type 2, or Type 3.
* **Start Date** (`start_date`, date, optional): Enter the start date of the project or task.
* **End Date** (`end_date`, date, optional): Enter the end date of the project or task.
* **Start Time** (`start_time`, time, optional): Enter the start time of the project or task.
* **End Time** (`end_time`, time, optional): Enter the end time of the project or task.
* **Note** (`note`, note, optional): Add any additional comments or notes about the project or task.
* **Contact Email** (`contact_email`, email, optional): Enter the contact email for the project or task.
* **Contact Phone** (`contact_phone`, text, optional): Enter the contact phone number for the project or task.
* **Other Details** (`other_details`, text, optional): Enter any other relevant details about the project or task.
