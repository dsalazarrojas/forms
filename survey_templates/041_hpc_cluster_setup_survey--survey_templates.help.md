# HPC Cluster Setup Survey - Help Guide

## Purpose
This survey is used to collect information about HPC cluster setup from users.

## How To Complete This Form
1. Fill out the form completely and accurately.
2. Select the appropriate options for each field.
3. Provide additional comments where necessary.

## Field-by-Field Explanation

* **Cluster Name** (`cluster_name`, text, optional): Enter the name of the HPC cluster.
* **Cluster Type** (`cluster_type`, select_one, required): Select the type of cluster (High-Performance Computing (HPC), Cloud, Hybrid, or Other (Please specify)).
* **IT Team** (`it_team`, select_multiple, optional): Select the IT team(s) involved in the cluster setup.
* **Research Team** (`research_team`, select_multiple, optional): Select the research team(s) involved in the cluster setup.
* **Cluster Purpose** (`cluster_purpose`, select_one, required): Select the purpose of the cluster (General purpose computing, HPC applications, Data analytics, or Other (Please specify)).
* **Cluster Location** (`cluster_location`, text, optional): Enter the location of the cluster.
* **Cluster Size** (`cluster_size`, number, required): Enter the size of the cluster.
* **Support Team** (`support_team`, select_one, required): Select the support team (Team A, Team B, or Team C).
* **Support Level** (`support_level`, select_one, required): Select the support level (High, Medium, or Low).
* **Timeline Start** (`timeline_start`, date, required): Enter the start date of the cluster setup.
* **Timeline End** (`timeline_end`, date, required): Enter the end date of the cluster setup.
* **Timeline Duration** (`timeline_duration`, number, required): Enter the duration of the cluster setup.
* **Budget** (`budget`, number, required): Enter the budget of the cluster setup.
* **Cluster Name Comments** (`cluster_name_comments`, text, optional): Add any comments regarding the cluster name.
* **Cluster Type Comments** (`cluster_type_comments`, text, optional): Add any comments regarding the cluster type.
* **Research Team Comments** (`research_team_comments`, text, optional): Add any comments regarding the research team.
* **IT Team Comments** (`it_team_comments`, text, optional): Add any comments regarding the IT team.
* **Cluster Purpose Comments** (`cluster_purpose_comments`, text, optional): Add any comments regarding the cluster purpose.
* **Support Level Comments** (`support_level_comments`, text, optional): Add any comments regarding the support level.
* **Timeline Start Comments** (`timeline_start_comments`, text, optional): Add any comments regarding the timeline start date.
* **Timeline End Comments** (`timeline_end_comments`, text, optional): Add any comments regarding the timeline end date.
* **Timeline Duration Comments** (`timeline_duration_comments`, text, optional): Add any comments regarding the timeline duration.
* **Budget Comments** (`budget_comments`, text, optional): Add any comments regarding the budget.
* **Submitted By** (`submitted_by`, email, required): Enter your email address for submission.
