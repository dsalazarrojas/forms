# Material Count Survey - Help Guide
## Purpose
The Material Count Survey is a form used to collect information about the quantity of materials available in a specific category, such as the number of metal, wood, or plastic materials. This form helps to gather data that can be used to track inventory levels and inform future procurement decisions.

## How To Complete This Form
To complete the Material Count Survey, follow these steps:

1. Select the correct material type from the drop-down list.
2. Enter the material's unique ID, if applicable.
3. Enter the count of the material.
4. Submit the form to save the information.

## Field-by-Field Explanation
- **Material Type** (`material_type`, select_one, required): Select the type of material you are counting, such as Metal, Wood, or Plastic.
- **Material ID** (`material_id`, number, optional): If you have a unique ID for the material, enter it here. This helps to identify the material more accurately.
- **Material Count** (`count`, number, optional): Enter the quantity of the material you are counting. This can be a whole number or a decimal value.

## Tips
- Make sure to select the correct material type to ensure accurate data collection.
- If you have any issues with submitting the form, please contact the system administrator for assistance.
- This form is meant for general information collection and is not intended for urgent procurement requests. If you need to request a material urgently, please contact your procurement team directly.
