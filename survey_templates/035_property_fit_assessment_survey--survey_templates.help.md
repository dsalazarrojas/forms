# Property Fit Assessment Survey - Help Guide
## Purpose
The Property Fit Assessment Survey is designed to gather essential information about a property and its features, enabling property owners and managers to identify potential matches with clients.

## How To Complete This Form
To complete this form, follow these steps:

1.  Complete each section thoroughly and accurately.
2.  Ensure that you have all the necessary information about the property and its features before proceeding.
3.  Select the most relevant options for each field based on the property's characteristics.

## Field-by-Field Explanation

*   **Property Address**: Enter the address of the property, including the street number, city, state, and zip code.
*   **Property Type**: Select the type of property (Residential, Commercial, or Industrial).
*   **Property Price**: Enter the price of the property. This will help potential clients understand the budget required to purchase or rent the property.
*   **Client Needs**: This field is not always required, but if you can select any additional needs or requirements the client has (e.g., Budget, Location, Lifestyle).
*   **Budget**: Enter the budget for the property. This should match the property price you entered earlier.
*   **Contact Name**: Enter the name of the contact person or representative responsible for the property.
*   **Email**: Enter a valid email address of the contact person or representative.
*   **Phone**: Enter a valid phone number of the contact person or representative.
*   **Property Details**: This field is a note field where you can add any additional information about the property.
*   **Additional Notes**: This field is another note field where you can add any additional information about the property.
*   **Property Status**: Select the status of the property (Active, Inactive, Sold, Renting, Under Contract, Coming Soon).
*   **Client Preferences**: This field is not always required, but if you can select any preferences the client has (e.g., Outdoor Space, Parking, Gym, Yard).
*   **Property Features**: This field is not always required, but if you can select any features the property has (e.g., Pool, Garden, View, Balcony, Elevator).
*   **Property Size**: Select the size of the property (Small, Medium, Large).
*   **Property Location**: Select the location of the property (City, Suburbs, Rural).

Note: This guide is intended to be used as a general reference. The specific requirements and options may vary based on your organization's policies and the specific use case. Always verify the information with your organization's guidelines before completing this form.
