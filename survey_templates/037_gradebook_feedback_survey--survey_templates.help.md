# Gradebook Feedback Survey - Help Guide
## Purpose

This form is intended to collect feedback from teachers and staff members on a student's performance in a gradebook system. The feedback will be used to support student development and growth.

## How To Complete This Form

1. Select one or more of the feedback options from the drop-down menu.
2. Fill in the text boxes with your feedback and recommendations.
3. Select your overall rating for the student's performance.
4. Provide any additional comments or recommendations.

## Field-by-Field Explanation

* **Feedback from Teacher (`gradebook_feedback_survey_page_1`)**:
  This field allows you to select one or more feedback categories, such as "Feedback", "Comments", or "Rating".
* **Feedback from Teacher (`teacher_feedback_1`)**:
  This field is a text box where you can write any feedback or comments you have for the student.
* **Feedback from Staff (`staff_feedback_1`)**:
  This field is a text box where you can write any feedback or comments you have for the student. (Note: This field is optional)
* **Date of Feedback (`date_of_feedback`)**:
  This field is a date field where you can select the date of your feedback submission.
* **Overall Rating (`rating_1`)**:
  This field is a drop-down menu where you can select the student's overall performance rating, such as "Excellent", "Good", "Average", or "Below Average".
* **Teacher Recommendations (`teacher_recommendations_1`)**:
  This field is a text box where you can provide any recommendations you have for the student.
* **Teacher Comments (`teacher_comments_1`)**:
  This field is a text box where you can provide any additional comments you have for the student. (Note: This field is optional)
* **Staff Recommendations (`staff_recommendations_1`)**:
  This field is a text box where you can provide any recommendations you have for the student. (Note: This field is optional)
* **Staff Comments (`staff_comments_1`)**:
  This field is a text box where you can provide any additional comments you have for the student. (Note: This field is optional)

## Tips

* Please provide detailed and specific feedback whenever possible.
* Use the overall rating field to rate the student's performance.
* Keep the comments fields concise and focused on providing actionable recommendations.
* Ensure that you are providing feedback on the student's strengths and weaknesses.
* This form is designed to be completed in a timely manner to ensure that feedback is provided in a timely fashion.
