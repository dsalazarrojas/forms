# First Time Attendee Survey - Help Guide
## Purpose
The First Time Attendee Survey is designed to gather valuable insights and feedback from new attendees of events, helping event organizers and sponsors tailor their events to better serve this audience.

## How To Complete This Form
To complete this form, simply select the relevant options for each question, enter your contact details, and submit your response. You can refer to the field-by-field explanations below for more details on each question.

## Field-by-Field Explanation
### Attending Event for First Time
* **Attending Event for First Time** (`attending_event_for_first_time`, select_one, optional): This question asks if you are attending the event for the first time. If you have attended the event before, please select 'Yes' or 'No' accordingly.
### Event Attendance Status
* **Event Attendance Status** (`event_attendance_status`, select_multiple, optional): This question asks about your attendance status at the event. You can select one or more of the options: 'True', 'False', or 'Maybe'.
### Feedback
* **Feedback** (`feedback`, note, optional): This is a text field where you can provide any feedback or comments about your experience as a first-time attendee.
### Event Type
* **Event Type** (`event_type`, select_one, optional): This question asks about the type of event you are attending. You can select: 'Conference', 'Workshop', or 'Seminar'.
### Event Date
* **Event Date** (`event_date`, date, optional): This question asks for the date of the event you are attending.
### Expected Duration
* **Expected Duration** (`expected_durations`, number, optional): If you know or estimate the duration of the event, please enter it here.
### Attended Event Before
* **Attended Event Before** (`attended_event_before`, select_one, optional): This question asks if you have attended this event before. If you have not, select 'True' or 'False'.
### Previous Attendee Status
* **Previous Attendee Status** (`previous_attendee_status`, select_one, optional): This question asks about your previous attendance status at similar events. You can select: 'First Time', or 'Return'.
### Attended Sponsored Event Before
* **Attended Sponsored Event Before** (`attended_sponsored_event_before`, select_one, optional): This question asks if you have attended a sponsored event before. If you have not, select 'True' or 'False'.
### Sponsored
* **Sponsored** (`sponsored`, select_one, optional): This question asks if this event is sponsored. If it is, select 'Yes' or 'No'.
### Sponsor
* **Sponsor** (`sponsor`, select_one, optional): This question asks about the sponsor of the event. You can select: 'Yes', or 'No'.
### Contact Name
* **Contact Name** (`contact_name`, text, optional): This is a field to enter your name.
### Contact Email
* **Contact Email** (`contact_email`, email, optional): This is a field to enter your email address.
### Contact Phone
* **Contact Phone** (`contact_phone`, text, optional): This is a field to enter your phone number.
### Contact Phone Extension
* **Contact Phone Extension** (`contact_phone_extension`, text, optional): This is a field to enter your phone extension (if applicable).
### Contact Cell
* **Contact Cell** (`contact_cell`, text, optional): This is a field to enter your cell phone number.
### Contact Address
* **Contact Address** (`contact_address`, text, optional): This is a field to enter your contact address.
### Contact City
* **Contact City** (`contact_city`, text, optional): This is a field to enter your city.
### Contact State
* **Contact State** (`contact_state`, text, optional): This is a field to enter your state.
### Contact Zip
* **Contact Zip** (`contact_zip`, text, optional): This is a field to enter your zip code.
### Contact Country
* **Contact Country** (`contact_country`, text, optional): This is a field to enter your country.
### Contact Work Phone
* **Contact Work Phone** (`contact_work_phone`, text, optional): This is a field to enter your work phone number.
### Contact Job Title
* **Contact Job Title** (`contact_job_title`, text, optional): This is a field to enter your job title.
### Event Attendance Date
* **Event Attendance Date** (`event_attendance_date`, date, optional): This question asks for the date you attended the event.
### Event Sponsor
* **Event Sponsor** (`event_sponsor`, select_one, optional): This question asks if the event is sponsored. If it is, select 'Yes' or 'No'.

Note: Please ensure that you have provided your contact details accurately, as we may need to contact you for further information or clarification.
