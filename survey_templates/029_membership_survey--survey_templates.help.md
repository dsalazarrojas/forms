# membership_survey - Help Guide

## Purpose
The "membership_survey" form is used to collect information about a user's category membership. This data is used to categorize users into different groups for organizational purposes.

## How To Complete This Form

To complete this form, follow these steps:

1. Review the available options in the "Category" field and select the appropriate response.
2. Enter a brief description of yourself in the "Description" field.
3. If you have been assigned a tool, enter the tool's name in the "Assigned Tool" field.

## Field-by-Field Explanation

* **Category** (`Yes/No`, required: false): Please select the correct category that you belong to.
* **Description** (`text`, required: false): Enter a brief description of yourself.
* **Assigned Tool** (`text`, required: false): If a tool has been assigned to you, enter the tool's name.
* **Category Id** (`Yes/No`, required: false): This field is not relevant to the user's category membership. 
* **Category Name** (`text`, required: false): Enter the name of the category you belong to.
* **Category Description** (`text`, required: false): Enter a brief description of the category you belong to. 
* **Category Id** ( duplicate field, not visible in the form): This field was likely a typo.
