# Municipal Waste Survey - Help Guide
## Purpose
The purpose of this form is to gather information from residents on their household waste habits, recycling practices, and other related topics. This data will be used by the municipality to inform policy decisions and improve waste management services.

## How To Complete This Form
To complete this form, follow these steps:

1. Answer each question carefully and accurately.
2. If a question is not applicable, please provide a brief explanation or note.
3. Do not provide any personal or sensitive information that you do not want to share.
4. Complete all required fields, but you can skip optional fields if they are not relevant to you.
5. Review your answers carefully before submitting the form.

## Field-by-Field Explanation
* **Household Waste Habits** (`household_waste_habits`, text, optional)
	+ This field is a text box where you can describe your household's waste habits. Please be as detailed as possible.
* **Recycling Practices** (`recycling_practices`, select_one, optional)
	+ Select one of the options:
		- Landfill
		- Recycling Center
		- Compost
	+ Please choose the option that best describes your household's recycling practices.
* **Waste Disposal Methods** (`waste_disposal_methods`, select_multiple, optional)
	+ Select all that apply:
		- Landfill
		- Recycling Center
		- Private Disposal
	+ Please choose the methods your household uses for waste disposal.
* **How Often Do You Recycle?** (`recycling_frequency`, number, optional)
	+ If you recycle at all, please select the frequency.
	+ If not applicable, please provide a brief explanation.
* **Survey Comments** (`survey_comments`, note, optional)
	+ Please provide any additional comments or feedback on the municipal waste survey.
	+ This is a free-text field for your suggestions or concerns.
* **Email** (`email`, email, optional)
	+ If you want to be contacted for any follow-up questions or concerns, please provide your email address.
	+ You can leave this field empty if you prefer not to be contacted.
* **Phone Number** (`phone_number`, text, optional)
	+ If you want to be contacted for any follow-up questions or concerns, please provide your phone number.
	+ You can leave this field empty if you prefer not to be contacted.
* **Household ID** (`household_id`, text, optional)
	+ Please provide your household ID (if applicable).
	+ If you are unsure what to enter here, please consult with the municipality for guidance.
