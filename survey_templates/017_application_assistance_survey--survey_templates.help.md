# Application Assistance Survey - Help Guide
## Purpose
The Application Assistance Survey is designed to gather feedback from users about their experience with a specific application process. This form will help administrators or support teams evaluate and refine the application process to make it easier and more user-friendly.

## How To Complete This Form
To complete this form, please answer each question as accurately as possible, and provide as much detail as you need to help us understand your experience. The form is divided into two main sections: "Application Context", "Assistance Received", "User Experience Evaluation", and "Suggestions for Improvement".

## Field-by-Field Explanation

* **-- Application Context --**: This section provides a brief context about the application process you completed.
* **Name (Optional)**: If you want to provide your name, you can do so here. This is an optional field.
* **What type of application did you complete?**: Select the type of application you completed from the list:
	+ Membership Application
	+ Funding - Grant Request
	+ Job Application
	+ Educational Enrollment
	+ Permit - License Request
	+ Other
* **-- Assistance Received --**: This is a heading for the next section.
* **Did you use any of the following assistance tools?**: Select all the tools that you used during the application process:
	+ Online Help Center / FAQ
	+ Live Chat Support
	+ Phone Support
	+ Email Support
	+ In-person Guidance
	+ None
* **How easy was it to find the help you needed?**: Rate how easy or difficult it was to find help during the application process:
	+ Very Easy
	+ Somewhat Easy
	+ Neutral
	+ Somewhat Difficult
	+ Very Difficult
* **-- User Experience Evaluation --**: This is a heading for the next section.
* **How clear were the questions on the application form?**: Rate how clear or confusing the questions on the form were:
	+ Extremely Clear
	+ Mostly Clear
	+ Somewhat Confusing
	+ Very Confusing
* **Did you encounter any technical issues while applying?**: Rate how many technical issues you encountered:
	+ No Issues
	+ Minor Technical Glitch
	+ Major Error (Prevented Completion)
* **If you encountered issues, please describe them**: If you encountered any technical issues, please describe them in detail.
* **Approximately how long did the application take to complete?**: Rate how long the application process took:
	+ Under 15 Minutes
	+ 15-30 Minutes
	+ 30-60 Minutes
	+ Over 1 Hour
* **-- Suggestions for Improvement --**: This is a heading for the next section.
* **Were the instructions provided at the beginning helpful?**: Rate how helpful the instructions were:
	+ Yes - Very Helpful
	+ Yes - Somewhat Helpful
	+ No - Not Helpful
	+ No Instructions Provided
* **What is one thing we could do to make the application process easier?**: Provide one specific suggestion to improve the application process.
* **Rate your overall satisfaction with the application process**: Rate your overall satisfaction with the application process:
	+ 1-5 stars
* **Any other comments you would like to share?**: If you have any additional comments or feedback, please feel free to share them.
* **Date of Survey Completion**: This is the date and time when the survey was completed.
