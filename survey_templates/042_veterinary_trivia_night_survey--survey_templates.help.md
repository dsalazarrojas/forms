# Veterinary Trivia Night Survey - Help Guide
## Purpose
This form is designed to collect feedback and data from users who have attended veterinary trivia nights.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out each field with the requested information. If a field is not relevant to your experience, you can leave it blank.
2. Make sure to answer each question truthfully and accurately.
3. Review your answers before submitting the form.

## Field-by-Field Explanation

* **Event Details** (`event_details`, text, optional): This field is where you can provide any additional information about the event you attended. If you have any comments or feedback about the event, you can put it here.
* **Event Name** (`event_name`, text, optional): This field is where you can enter the name of the event you attended.
* **Rating** (`rating`, number, optional): This field is where you can rate the event on a scale of 1-5. A higher rating indicates that you enjoyed the event more.
* **Attended Other Event** (`attended_other_event`, select_one, optional): This field is where you can select whether you attended another event or not. If you selected "Yes", you can enter the name of the other event in the **Name Of Other Event** field.
* **Attended Veterinary Event** (`attended_veterinary_event`, select_one, optional): This field is where you can select whether you attended a veterinary event or not.
* **Attended Another Veterinary Event** (`attended_another_veterinary_event`, select_one, optional): This field is where you can select whether you attended another veterinary event or not.
* **Name Of Other Event** (`name_of_other_event`, text, optional): This field is where you can enter the name of the other event you attended, if you selected "Yes" in the **Attended Other Event** field.
* **Other Event Details** (`other_event_details`, text, optional): This field is where you can enter any additional information about the other event you attended, if you selected "Yes" in the **Attended Other Event** field.
* **Improvement Suggestion** (`improvement_suggestion`, text, optional): This field is where you can suggest any improvements or changes you would like to see made to future events.
* **Rating Value** (`rating_value`, number, optional): This field is where you can enter the numerical value of your rating. For example, if you rated the event 4 out of 5, you can enter 4.
* **Rating Value Max** (`rating_value_max`, number, optional): This field is not currently used in the survey.
* **Rating Value Min** (`rating_value_min`, number, optional): This field is not currently used in the survey.
* **Rating Value Avg** (`rating_value_avg`, number, optional): This field is not currently used in the survey.
* **Rating Value Std** (`rating_value_std`, number, optional): This field is not currently used in the survey.
* **Rating Value Median** (`rating_value_median`, number, optional): This field is not currently used in the survey.
* **Rating Value Dev** (`rating_value_dev`, number, optional): This field is not currently used in the survey.
* **Rating Value Var** (`rating_value_var`, number, optional): This field is not currently used in the survey.
* **Rating Value Sum** (`rating_value_sum`, number, optional): This field is not currently used in the survey.
* **Total Participants** (`total_participants`, number, optional): This field is not currently used in the survey.
* **Average Score** (`average_score`, number, optional): This field is not currently used in the survey.
* **Max Score** (`max_score`, number, optional): This field is not currently used in the survey.
* **Min Score** (`min_score`, text, optional): This field is not currently used in the survey.
* **Participant Count** (`participant_count`, number, optional): This field is not currently used in the survey.
* **Survey Time** (`survey_time`, time, optional): This field is not currently used in the survey.
* **Survey Date** (`survey_date`, date, optional): This field is not currently used in the survey.

## Tips
* Make sure to answer each question accurately and truthfully.
* Review your answers before submitting the form.
* If you have any feedback or suggestions, please enter them in the **Improvement Suggestion** field.
