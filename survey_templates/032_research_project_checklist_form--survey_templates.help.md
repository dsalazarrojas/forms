# research_project_checklist_form - Help Guide
## Purpose
The purpose of this form is to collect information about research projects, including project details, lead contacts, and project status. This form helps streamline project management and communication by gathering all relevant information in one place.

## How To Complete This Form
To complete this form, follow these steps:

1. **Project Details**: Fill in the project title, project lead, project start date, and expected completion date. These fields are all required.
2. **Lead Contacts**: Enter the contact information for the project lead, including phone and email. These fields are optional.
3. **Project Status**: Select the current status of the project from the dropdown options: Active, Inactive, or On Hold. This field is required.
4. **Budget Allocation and Notes**: Enter the budget allocation amount and any notes about the budget. These fields are required.
5. **Submission Notes**: Add any additional notes for submission. This field is required.
6. **Optional Fields**: Fill in any additional information you have about the research project, such as research focus, objectives, expected outcome, research methodology, research tools, risk management, resource allocation, and project manager comments. These fields are optional.
