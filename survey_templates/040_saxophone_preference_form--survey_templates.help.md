# Saxophone Preference Form - Help Guide

## Purpose
This form is used to collect user preferences regarding saxophone types.

## How To Complete This Form
To complete this form, follow the instructions below:

1. Read through each page, and select your preferences for alto, tenor, and baritone saxophones.
2. For each page, select "Yes" if you prefer the corresponding saxophone type, or "No" if you do not.
3. Make sure to complete all pages, as they are not required.

## Field-by-Field Explanation

* **Alto Sax**: This section is asking about your preference for the Alto Saxophone. Please select "Yes" if you prefer the Alto Sax, or "No" if you do not.
* **Tenor Sax**: This section is asking about your preference for the Tenor Saxophone. Please select "Yes" if you prefer the Tenor Sax, or "No" if you do not.
* **Baritone Sax**: This section is asking about your preference for the Baritone Saxophone. Please select "Yes" if you prefer the Baritone Sax, or "No" if you do not.

## Tips
* Make sure to select one preference per section.
* If you are unsure about your preference, you can select "No" for now, and review your answer later.
* Remember, this form is not a commitment, and you can change your preference at any time.
