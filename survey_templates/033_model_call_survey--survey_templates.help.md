# Model Call Survey - Help Guide
## Purpose
This form is designed to help users submit a model call with relevant details for evaluation and processing. It is primarily used for users to provide information about the category, description, assigned tool, and output file related to the model call.

## How To Complete This Form
To complete this form, follow these steps:

1. Review the form carefully to ensure you have all the required information.
2. Enter the category of the model call, which will help with categorization and filtering.
3. Provide a clear and concise description of the model call, including any relevant details.
4. Specify the assigned tool used for the model call, if applicable.
5. Upload or provide the output file related to the model call, if applicable.
6. Review your entries before submitting the form.

## Field-by-Field Explanation
* **Category** (`Category`, select_one, required: false): Select the category of the model call to help with categorization and filtering.
* **Description** (`description`, text, required: false): Provide a clear and concise description of the model call, including any relevant details.
* **Assigned Tool** (`assigned_tool`, text, required: false): Specify the tool used for the model call, if applicable.
* **Output File** (`output_file`, text, required: false): Upload or provide the output file related to the model call, if applicable.

## Tips
* Make sure to review the form carefully before submitting it.
* If you are unsure about the category, you can ask for help or clarification.
* Use clear and concise descriptions to help with the evaluation and processing of the model call.
* Ensure that you have all the required information before submitting the form.
* If you have any further questions or need assistance, do not hesitate to contact us.
