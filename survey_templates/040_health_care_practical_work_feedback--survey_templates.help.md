# health_care_practical_work_feedback - Help Guide
## Purpose
This form is used to collect feedback and practical work data from students in the healthcare industry.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in your **Student Name** in the text field labeled "Student Name".
2. Enter your **Student ID** in the text field labeled "Student ID".
3. Indicate if you have had **Clinical Site Experience** in the select field labeled "Clinical Site".
4. Answer if you have had **Work Experience** in the select multiple field labeled "Work Experience".
5. Provide feedback on your **Supervisor Feedback** in the select multiple field labeled "Supervisor Feedback".
6. Write your **Feedback** on the text field labeled "Feedback".
7. Offer any **Suggestions** you may have in the text field labeled "Suggestions".
8. Rate the overall quality of your work with a number between 1-5 in the field labeled "Overall Rating".
9. Select the **Date** you completed this form in the date field labeled "Date".
10. Indicate the **Time** you completed this form in the time field labeled "Time".

## Field-by-Field Explanation
* **Student Name**: Enter your full name as per your student ID or identification.
	+ Type: text
	+ Required: true
* **Student ID**: Enter your student ID number as per your student ID or identification.
	+ Type: text
	+ Required: true
* **Clinical Site**: Select "Yes" if you have had clinical site experience, "No" otherwise.
	+ Type: select_one
	+ Required: true
* **Work Experience**: Select all that apply regarding your work experience.
	+ Type: select_multiple
	+ Required: true
* **Supervisor Feedback**: Select all that apply regarding your supervisor feedback.
	+ Type: select_multiple
	+ Required: true
* **Feedback**: Write your feedback on your practical work experience.
	+ Type: text
	+ Required: true
* **Suggestions**: Write any suggestions you may have for improvement.
	+ Type: text
	+ Required: true
* **Overall Rating**: Rate the overall quality of your work with a number between 1-5.
	+ Type: number
	+ Required: true
* **Date**: Select the date you completed this form.
	+ Type: date
	+ Required: true
* **Time**: Select the time you completed this form.
	+ Type: time
	+ Required: true
