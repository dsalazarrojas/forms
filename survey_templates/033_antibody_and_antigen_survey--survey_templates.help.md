# Antibody And Antigen Survey - Help Guide
## Purpose
This form is designed to collect information on an individual's testing and exposure history related to antibodies and antigens, which are essential in diagnosing and monitoring diseases caused by infections or pathogens.

## How To Complete This Form
To complete this form, follow these steps:

* Select the "Antigen Test Result" field (field 3) to indicate whether the individual has had an antigen test recently.
* If the individual has had an antigen test, select the corresponding result in the "Antigen Test Result" field (field 4).
* Select the "Antibody Test Result" field (field 5) to indicate whether the individual has had an antibody test.
* If the individual has had an antibody test, select the corresponding result in the "Antibody Test Result" field (field 6).
* In the "Vaccination Status" field (field 7), provide information on the individual's vaccination status for relevant diseases.
* In the "Recent Symptoms" field (field 8), select any symptoms the individual has experienced recently.
* In the "Exposure History" field (field 9), provide any information on known exposure to confirmed cases.

## Field-by-Field Explanation

* **Have you had an antigen test recently (2)**: This field is a yes/no question that asks if the individual has had an antigen test within the last 14 days.
	+ Select "True" if the individual has had an antigen test recently.
	+ Select "False" if the individual has not had an antigen test recently.
* **Antigen test result (3)**: This field is used to select the result of the antigen test.
	+ Select "Positive" if the test result is positive.
	+ Select "Negative" if the test result is negative.
	+ Select "Indeterminate" if the test result is indeterminate.
	+ Select "Not tested" if the individual has not had an antigen test.
* **Have you had an antibody test (4)**: This field is a yes/no question that asks if the individual has had an antibody test.
	+ Select "True" if the individual has had an antibody test.
	+ Select "False" if the individual has not had an antibody test.
* **Antibody test result (5)**: This field is used to select the result of the antibody test.
	+ Select "Positive" if the test result is positive.
	+ Select "Negative" if the test result is negative.
	+ Select "Unknown" if the test result is unknown.
* **Vaccination status for relevant disease (6)**: This field is used to provide information on the individual's vaccination status for relevant diseases.
	+ Enter the number of doses received and the date of the last dose.
* **Recent symptoms (7)**: This field is used to select any symptoms the individual has experienced recently.
	+ Select all applicable symptoms.
* **Known exposure to confirmed case (8)**: This field is used to provide information on known exposure to confirmed cases.
	+ Enter the approximate date of exposure.
* **Additional comments or clarifications (9)**: This field is used to provide any additional comments or clarifications about testing or symptoms.
	+ Enter any relevant information.

Note: The required fields are "Have you had an antigen test recently" (2), "Have you had an antibody test" (4), and "Additional comments or clarifications" (9) are optional but recommended for accurate completion.
