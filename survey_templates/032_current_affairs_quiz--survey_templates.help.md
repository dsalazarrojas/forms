# Current Affairs Quiz - Help Guide
## Purpose
This form is designed to collect user opinions and responses on current affairs. It is intended to gather information and feedback from users on various topics.

## How To Complete This Form
To complete this form, follow these steps:

1. Navigate through the pages using the provided navigation links.
2. Answer each question on the corresponding page.
3. Ensure that you have filled out all required fields.

## Field-by-Field Explanation

* **Intro Label** (intro_page, text, optional): This is the introduction page with a brief description of the form.
* **Question 1** (question_1_page, select_one, optional): This is a select one question with four options: option a, option b, option c, option d.
* **Question 2** (question_2_page, text, optional): This is a text question where you can provide your answer.
* **Question 3** (question_3_page, select_multiple, optional): This is a select multiple question with four options: option 1, option 2, option 3, option 4.
* **Question 4** (question_4_page, time, optional): This is a question that requires you to enter a time in 24-hour format.
* **Question 5** (question_5_page, number, optional): This is a question that requires you to enter a number.
* **Note** (note_page, note, optional): This is a free text field for any additional comments or notes.
* **Email** (email_page, email, optional): This is a field for entering your email address.

Note: The required fields are marked as optional in this form, meaning that you can choose to fill them out or not.
