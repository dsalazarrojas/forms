# FinOps Tool Evaluation Survey - Help Guide
## Purpose
This form is a survey designed to gather feedback and opinions from users on their experience with the FinOps tool.

## How To Complete This Form
1. To complete this form, navigate through each page using the buttons at the top or bottom of each page.
2. Read each question or instruction carefully before entering your answer.
3. Answer the questions truthfully and accurately to the best of your ability.
4. You can select multiple options for the questions that have the "select_multiple" type.
5. You can select only one option for the questions that have the "select_one" type.
6. If a question is marked as required, you must provide an answer before proceeding.
7. Use the "Submit" button to complete the form and submit your answers.

## Field-by-Field Explanation

### Page 1
* **Page 1:** This is the first page of the survey. This page is currently not displaying any questions, but it's here to set the stage for the rest of the form.

### Page 2
* **Page 2 (Select Multiple):** This page asks you to select all the options that apply to your experience with the FinOps tool. You can choose one or more of the options. (Yes, No)
* **Yes:** This option is selected when you have had a positive experience with the FinOps tool.
* **No:** This option is selected when you have not had a positive experience with the FinOps tool.

### Page 3
* **Page 3:** This page is not currently displaying any questions, but it's here to keep the form going.

### Page 4
* **Page 4 (Text):** This field is for any additional comments or feedback you may have about the FinOps tool. Please provide a brief description of your experience.

### Page 5
* **Page 5 (Select One):** This page asks you to select one option that best describes your experience with the FinOps tool. You can choose only one of the options. (Yes, No)
* **Yes:** This option is selected when you have had a positive experience with the FinOps tool.
* **No:** This option is selected when you have not had a positive experience with the FinOps tool.

### Page 6
* **Page 6 (Number):** This field is for any numerical rating you may have for the FinOps tool. You can enter a number between 1 and 5, with 1 being the lowest rating and 5 being the highest.

### Page 7
* **Page 7 (Time):** This field is for the amount of time you spent using the FinOps tool. Please enter a time in the format of HH:MM (hours:minutes). You can select any value within reason, as this field is for estimation purposes only.
