# New Class Feedback Report Form - Help Guide
## Purpose
The New Class Feedback Report Form is a survey used to collect feedback from new class instructors or teachers about their recent class experience. It is used to monitor the quality of new classes and help identify areas for improvement.

## How To Complete This Form
- Fill out the form for each new class that has just finished.
- Make sure to complete all required fields (see below).
- Answer each question thoroughly and honestly.
- Submit the form once you have completed it.

## Field-by-Field Explanation
- **New Class** (`new_class_feedback_report_form`, text, required/optional): This is the main title of the form, which should match the class being evaluated.
- **Class ID** (`class_id`, number, required/optional): The unique ID of the class being evaluated. Please use the ID number provided by the system.
- **Feedback Question** (`feedback_question`, text, required/optional): Answer this question in detail, providing as much information as possible about your recent class experience.
- **Feedback Answer** (`feedback_answer`, select_multiple, required/optional): Choose one or more of the provided options to answer the feedback question. Select all that apply.
  - Option 1
  - Option 2
  - Option 3
- **Date Completed** (`date_completed`, date, required/optional): The date the class was completed. Please use the date in the format MM/DD/YYYY.
- **Time Completed** (`time_completed`, time, required/optional): The time the class was completed. Please use the 24-hour clock format (HH:MM).
- **Comments** (`comments`, note, required/optional): Use this field to provide any additional comments or feedback not covered in the previous questions.
- **Email** (`email`, email, required/optional): Please enter your email address. This will be used to contact you if we need more information or clarification. 

## Tips
- Please be as thorough and honest as possible in your answers.
- Do not fill out this form for ongoing classes.
- If you have any issues or concerns, please contact us at [insert contact information].
