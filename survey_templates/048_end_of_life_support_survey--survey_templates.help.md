# end_of_life_support_survey - Help Guide
## Purpose
This form is used to gather information about end-of-life support services.

## How To Complete This Form

1. Please answer each question carefully and accurately.
2. Make sure to fill in all required fields.
3. Select only one option for questions with multiple options (e.g., select_one).
4. Select multiple options for questions that allow multiple selections (e.g., select_multiple).

## Field-by-Field Explanation

* **end_of_life_support_experience** (Number, Required): Please enter the number of days or weeks since the individual began receiving end-of-life support.
* **end_of_life_support_care_provider** (Select One, Required): Choose the care provider that has been supporting the individual, such as Option 1, Option 2, or Option 3.
* **end_of_life_care_team** (Select Multiple, Optional): Select multiple care providers that have been supporting the individual (e.g., Option 1, Option 2, Option 3).
* **end_of_life_support_location** (Date, Required): Enter the location where end-of-life support has been provided, using the date format (e.g., YYYY-MM-DD).
* **end_of_life_support_nurse** (Time, Optional): If applicable, enter the time of day when end-of-life support was provided.
* **end_of_life_support_physician** (Number, Required): Please enter the number of physicians who have been involved in the individual's care.
* **end_of_life_support_social_worker** (Select One, Required): Choose the social worker that has been supporting the individual, such as Option 1, Option 2, or Option 3.
* **end_of_life_support_chaplain** (Select Multiple, Required): Select multiple chaplains that have been supporting the individual (e.g., Option 1, Option 2, Option 3).
* **end_of_life_support_volunteer** (Text, Required): Please enter any additional comments or details about the volunteer's role or impact.
* **end_of_life_support_feedback** (Email, Required): Enter your email address for follow-up or to request more information.
* **end_of_life_support_phone_number** (Text, Required): Enter your phone number for follow-up or to request more information.
* **end_of_life_support_survey_comments** (Note, Optional): If you have any additional comments or suggestions about the form, please enter them here.

## Tips

* Be as accurate and honest as possible when answering each question.
* If you are unsure about any question, please ask for clarification.
* Your feedback and suggestions are valuable to us and will help us improve end-of-life support services.
