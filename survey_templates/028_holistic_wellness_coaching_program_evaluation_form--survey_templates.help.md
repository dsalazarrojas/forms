# Holistic Wellness Coaching Program Evaluation Form - Help Guide
## Purpose
This form is designed to collect feedback and evaluation from clients who have participated in the Holistic Wellness Coaching Program. Your input will help us understand how the program has met your needs and identify areas for improvement.

## How To Complete This Form
To complete this form, simply follow the instructions below for each section.

1.  Please read the form carefully and answer each question to the best of your ability.
2.  If you have not had a transformative experience with the program, you are not required to fill out this form, but we still encourage you to do so.
3.  If you have any suggestions or comments about the program, please include them in the "comments" section.
4.  If you would like to stay in touch with us, please fill in your contact information.

## Field-by-Field Explanation

* **Introduction** (Page 1, id: 1)
	+ **Label:** Introduction 
	+ **Type:** Note
	+ **Description:** This is a general introduction to the form and the purpose of the Holistic Wellness Coaching Program.
* **Coaching Programs** (Page 1, id: 2)
	+ **Label:** Coaching Programs 
	+ **Type:** Select Multiple 
	+ **Description:** Please select any coaching programs you have participated in as part of the Holistic Wellness Coaching Program.
* **Coaching Outcomes** (Page 1, id: 3)
	+ **Label:** Coaching Outcomes 
	+ **Type:** Number 
	+ **Description:** Please provide a numerical rating on your experience with the coaching program.
* **Client Experience** (Page 1, id: 4)
	+ **Label:** Client Experience 
	+ **Type:** Text 
	+ **Description:** Describe your experience with the Holistic Wellness Coaching Program.
* **Feedback** (Page 1, id: 5)
	+ **Label:** Feedback 
	+ **Type:** Select One 
	+ **Description:** Please select one of the options to provide your feedback on the program.
* **Suggestions** (Page 1, id: 6)
	+ **Label:** Suggestions 
	+ **Type:** Select Multiple 
	+ **Description:** Please select any suggestions you have for improving the program.
* **Overall Rating** (Page 1, id: 7)
	+ **Label:** Overall Rating 
	+ **Type:** Number 
	+ **Description:** Please provide a numerical rating for your overall experience with the program.
* **Email** (Page 1, id: 8)
	+ **Label:** Email 
	+ **Type:** Email 
	+ **Description:** If you would like to stay in touch with us, please provide your email address.
* **Phone** (Page 1, id: 9)
	+ **Label:** Phone 
	+ **Type:** Text 
	+ **Description:** If you would like to stay in touch with us, please provide your phone number.
* **Comments** (Page 1, id: 10)
	+ **Label:** Comments 
	+ **Type:** Text 
	+ **Description:** If you have any additional comments or suggestions for the program, please provide them here.
* **Submission Date** (Page 1, id: 11)
	+ **Label:** Submission Date 
	+ **Type:** Date 
	+ **Description:** The date and time you completed this form.

## Tips
- Please be honest and accurate with your feedback.
- If you are unable to answer a question, please provide an explanation or skip it if it's not required.
- If you have any questions or need assistance, please contact us.
