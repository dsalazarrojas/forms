# dns_assessment_survey - Help Guide
## Purpose
This form is used to assess the current state of DNS management practices within an organization.

## How To Complete This Form
To complete this form, follow these steps:

1. Answer each field according to your knowledge and expertise on DNS management.
2. Make sure to select the correct options for each field, if applicable.
3. Review your answers before submitting the form to ensure accuracy.

## Field-by-Field Explanation

* **dns_management_practices**: A brief description of DNS management practices currently in place within your organization. Please provide a concise answer in the text field.
* **dns_infrastructure_satisfaction**: Select all that apply to indicate the level of satisfaction with your DNS infrastructure. You can select multiple options.
	+ Satisfied
	+ Dissatisfied
* **security_readiness**: A text field for you to describe your organization's security posture related to DNS management. Please provide a brief, concise answer.
