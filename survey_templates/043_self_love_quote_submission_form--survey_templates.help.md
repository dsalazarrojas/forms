# self_love_quote_submission_form - Help Guide
## Purpose
The self-love quote submission form is a tool to collect inspiring and uplifting quotes that promote self-love and positivity.

## How To Complete This Form
To complete this form, please follow these steps:

1. Start by providing the quote that you want to share. This is a required field, so please ensure that you enter a valid text string.
2. Next, enter your name as it would be listed on your identification or contact information.
3. Enter a valid email address that you check frequently.
4. If you have a phone number, enter it so we can reach out to you in case of any further questions.
5. If the quote has a source, please specify the name of the source or enter a URL where the quote can be found.
6. If applicable, provide the date when the quote was discovered or shared.
7. Finally, click the "Submit" button to send the form.

## Field-by-Field Explanation
* **Quote** (`quote`, `text`, Required): Enter the quote that you would like to submit. Please enter a valid text string.
* **Name** (`name`, `text`, Required): Enter your name as it would be listed on your identification or contact information.
* **Email** (`email`, `email`, Required): Enter a valid email address that you check frequently. This will help us contact you if needed.
* **Phone** (`phone`, `text`, Required): If you have a phone number, enter it so we can reach out to you in case of any further questions.
* **Quote Source** (`quote_source`, `text`, Optional): If the quote has a source, please specify the name of the source or enter a URL where the quote can be found.
* **Quote Source URL** (`quote_source_url`, `text`, Optional): If you provided a URL for the quote source, enter it here.
* **Date** (`quote_date`, `date`, Required): If applicable, provide the date when the quote was discovered or shared.
* **Submit** (`submit`, `text`, Optional): Click the "Submit" button to send the form.
