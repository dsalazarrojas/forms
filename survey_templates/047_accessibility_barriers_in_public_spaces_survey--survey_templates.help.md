# Accessibility Barriers In Public Spaces Survey - Help Guide
## Purpose
This survey is designed to help us gather information on accessibility barriers in public spaces and facilities, which will aid in improving the overall accessibility of these areas.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the location where the barrier was observed.
2. Fill in the name and address of the space.
3. Choose the date of the visit.
4. Select any accessibility barriers you observed.
5. Rate the ease of navigation in the space.
6. Evaluate the clarity of signs for accessible routes.
7. Provide your perspective on the feedback (e.g., as a user with a physical disability).
8. Describe a specific barrier or incident in detail.
9. Suggest improvements to address the barriers.
10. Rate the overall accessibility of the space (1-10).
11. Let us know if you'd like to be contacted for more information.

## Field-by-Field Explanation

* **Name of the Public Space or Facility** (`space_name`, text, required): Enter the name of the public space or facility you visited.
* **Address or Location of the Space** (`space_address`, text, required): Provide enough detail for identifying the site.
* **Date of Visit** (`date_of_visit`, date, required): Enter the date you visited the space.
* **Select any accessibility barriers you observed** (`barriers_observed`, select_multiple, required): Check all that apply.
	+ **Uneven Sidewalks**: Select this option if the sidewalks or walkways had uneven surfaces.
	+ **Lack of Ramps**: Select this option if there were no ramps or access paths.
	+ **Heavy Doors**: Select this option if doors were difficult or impossible to open.
	+ **No Tactile Paving**: Select this option if there were no tactile paving markings.
	+ **Narrow Entrances**: Select this option if entrances were too narrow.
	+ **Inaccessible Restrooms**: Select this option if restrooms were not accessible.
	+ **Poor Lighting**: Select this option if lighting was inadequate.
* **How easy was it to navigate the space?** (`ease_of_navigation`, select_one, required): Rate the ease of navigation in the space (Very Easy, Average, Difficult, Impossible).
* **Were there clear signs for accessible routes?** (`signage_adequacy`, select_one, required): Evaluate the clarity of signs for accessible routes (Yes - Very Clear, Some Signs, No Signs Found).
* **Your perspective** (`user_perspective`, select_one, required): Choose your perspective on the feedback (User with Physical Disability, User with Visual Impairment, Parent with Stroller, Senior Citizen, Concerned Citizen).
* **Describe a specific barrier or incident in detail** (`specific_incident_description`, text, required): Provide a detailed description of a specific barrier or incident you faced.
* **What improvements would be most helpful?** (`suggested_improvements`, select_multiple, required): Choose key priorities for improvement.
	+ **Install Ramps**: Suggest installing ramps for better accessibility.
	+ **Add Automatic Doors**: Suggest adding automatic doors for easier access.
	+ **Improve Signage**: Suggest improving signage for better navigation.
	+ **Add Braille Labels**: Suggest adding Braille labels for better navigation.
	+ **Repair Pavement**: Suggest repairing uneven pavement.
	+ **Install Handrails**: Suggest installing handrails for better support.
* **Rate the overall accessibility of this space 1-10** (`overall_accessibility_rating`, number, required): Rate the overall accessibility of the space (1-10, where 10 is fully inclusive).
* **May the planning committee contact you for more information?** (`follow_up_permission`, select_one, required): Let us know if you'd like to be contacted for more information (Yes, No).
