# Vacation Bible School Interest Survey Form - Help Guide
## Purpose
The form is designed to gather information about your interest in attending or participating in the Vacation Bible School program.

## How To Complete This Form
To complete the form, follow these steps:

1.  Choose all the options that apply to you from the "What are you interested in learning about?" field.
2.  If you have a phone number, enter it in the "Phone Number" field.
3.  If you have an email address, enter it in the "Email Address" field.
4.  Add any additional comments in the "Comments" field if you have any other thoughts or questions.
5.  If you are interested in attending the program, select the corresponding date and time on the "Date" and "Time" fields.
6.  If you have a preferred tool for the program, you can enter it in the "Assigned Tool" field.
7.  If you have a preferred user to be assigned to you for the program, you can enter it in the "Assigned User" field.

## Field-by-Field Explanation
- **Survey Form** (select_multiple):
    *   This field allows you to select all the options that apply to you about what you are interested in learning about.
    -   Options: Yes, No, and any additional options that are not listed here.
- **What are you interested in learning about?** (select_one):
    *   This field allows you to select a single option that best describes what you are interested in learning about.
    -   Options: Option 1, Option 2, and Option 3
- **Age** (number):
    *   This field is for entering your age.
    -   Please enter a numerical value.
- **Phone Number** (text):
    *   If you have a phone number, enter it here.
    -   Please enter a valid phone number.
- **Email Address** (email):
    *   If you have an email address, enter it here.
    -   Please enter a valid email address.
- **Comments** (note):
    *   This field is for adding any additional comments or questions you have.
    -   Please use this field to provide any additional information.
- **Date** (date):
    *   If you are interested in attending the program, select the date you are interested in.
    -   Please select a valid date.
- **Time** (time):
    *   If you are interested in attending the program, select the time you are interested in.
    -   Please select a valid time.
- **Assigned Tool** (text):
    *   If you have a preferred tool for the program, enter it here.
    -   Please enter a valid tool name.
- **Assigned User** (text):
    *   If you have a preferred user to be assigned to you for the program, enter it here.
    -   Please enter a valid user name.
