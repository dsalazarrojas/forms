# Marine Diagenesis Survey - Help Guide
## Purpose

This form is a tool for researchers to collect and document information about marine sediment samples. It's designed to gather data on the samples' characteristics, methods used, and other relevant details.

## How To Complete This Form

To complete this form, follow these steps:

*   Fill out the form in a new tab/browser window to avoid losing your progress.
*   Review the form's instructions and questions carefully.
*   Fill in the provided fields with the required information.

## Field-by-Field Explanation

*   **Sediment Samples** (`sediment_samples`)
    *   A text field to input any information related to the sediment samples.
*   **Diagenetic Features** (`diagenetic_features`)
    *   Select all the diagenetic features that apply to the sample (yes/no).
*   **Methods Used** (`methods_used`)
    *   Select the methods used for collecting or processing the sample (yes/no).
*   **Sample Location** (`sample_location`)
    *   A text field to input the location of the sample.
*   **Supporting Files** (`supporting_files`)
    *   Select all the supporting files that accompany the sample (yes/no).
*   **Notes** (`notes`)
    *   A text field to input any additional comments or notes about the sample.
*   **Date Collected** (`date_collected`)
    *   A date field to input the date the sample was collected.
*   **Time Collected** (`time_collected`)
    *   A time field to input the time the sample was collected.
*   **Researcher Notes** (`researcher_notes`)
    *   A text field to input any notes from the researcher.
*   **Sample ID** (`sample_id`)
    *   A text field to input the ID of the sample.

## Tips

*   Please ensure you input accurate and complete information for each field.
*   Review your submission carefully before submitting to avoid errors.
*   If you have any issues or questions, contact the relevant team member or supervisor.
