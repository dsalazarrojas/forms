# Personal Values Worksheet - Help Guide

## Purpose
The Personal Values Worksheet is a tool to help you determine what matters most in your life. It is a survey that asks you to reflect on your core values and prioritize them.

## How To Complete This Form
To complete this form, please follow these steps:

1. Review each value option and answer "Yes" or "No" accordingly.
2. Select your top priority value from the options provided.
3. Enter the value of your top priority (if required).
4. Continue to review and answer each value option, selecting your top priority for each.
5. In the Core Values Summary section, select all values that matter most to you.
