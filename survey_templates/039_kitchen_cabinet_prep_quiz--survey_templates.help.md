# Kitchen Cabinet Prep Quiz - Help Guide
## Purpose
This form is designed to assess the preparation for a kitchen cabinet painting project.

## How To Complete This Form
To complete this form, please follow these steps:

1. Go through each page and fill out the fields that apply to your project.
2. Answer all questions carefully and accurately, and provide detailed information in text fields.
3. Make sure you have filled out all required and optional fields before proceeding.

## Field-by-Field Explanation

* **Client Readiness** (`Client Readiness`, `select_multiple`, required/optional): This field is used to gauge your understanding and preparedness for the project. Select all that apply to describe your client's situation.
	+ Client has all necessary tools
	+ Client has all necessary materials
	+ Client has a clear understanding of the project scope
* **Safety Awareness** (`Safety Awareness`, `select_one`, required/optional): This field is used to determine your level of awareness and adherence to safety procedures. Please select whether you have a true or false understanding of safety protocols.
* **Confidence** (`Confidence`, `number`, required/optional): This field is used to gauge your confidence level in completing the project. Please enter a number between 1 and 10 to indicate your level of confidence.
* **Project Scope** (`Project Scope`, `text`, required/optional): This field is used to describe the scope of the project. Please provide a detailed description of what needs to be done.
* **Materials Needed** (`Materials Needed`, `select_multiple`, required/optional): This field is used to list the materials and tools required for the project. Please select all that apply.
	+ All necessary paint and primer
	+ All necessary paintbrushes
	+ All necessary drop cloths
* **Project Location** (`Project Location`, `select_one`, required/optional): This field is used to specify the location of the project. Please select one of the options.
	+ Home
	+ Office
	+ Commercial
* **Painting Techniques** (`Painting Techniques`, `select_multiple`, required/optional): This field is used to describe the painting techniques to be used. Please select all that apply.
	+ Water based
	+ Latex based
	+ Oil based
* **Painting Safety** (`Painting Safety`, `select_multiple`, required/optional): This field is used to list the safety equipment and protocols to be followed. Please select all that apply.
	+ Safety glasses
	+ Paint respirator
	+ Mask
* **Cabinet Type** (`Cabinet Type`, `select_one`, required/optional): This field is used to specify the type of cabinet. Please select one of the options.
	+ Solid
	+ Hollow
	+ Semi-hollow
* **Paint Type** (`Paint Type`, `select_multiple`, required/optional): This field is used to specify the type of paint to be used. Please select all that apply.
	+ Latex
	+ Oil based
	+ Water based
* **Prep Process** (`Prep Process`, `select_one`, required/optional): This field is used to describe the preparation process to be followed. Please select one of the options.
	+ Sanding
	+ Stripping
	+ Scraping
* **Paint Color** (`Paint Color`, `select_one`, required/optional): This field is used to specify the paint color to be used. Please select one of the options.
	+ White
	+ Red
	+ Blue
* **Additional Comments** (`Additional Comments`, `text`, required/optional): This field is used to provide any additional comments or details about the project. Please enter any relevant information.
* **Has Painted Before** (`Has Painted Before`, `select_one`, required/optional): This field is used to determine whether you have painted before. Please select true or false.
* **Hire A Painter** (`Hire A Painter`, `select_one`, required/optional): This field is used to determine whether you plan to hire a painter. Please select true or false.
