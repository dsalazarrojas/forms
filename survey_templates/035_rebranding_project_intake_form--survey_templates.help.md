# Rebranding Project Intake Form - Help Guide
## Purpose
The Rebranding Project Intake Form is a tool used to collect information about new branding projects. This form helps ensure that all necessary details are captured and organized for efficient project management and execution.

## How To Complete This Form
Before starting, please ensure that you have all the necessary information about the project available. The form is divided into several sections, each covering a different aspect of the project. Please fill out each section carefully and accurately.

## Field-by-Field Explanation
* **Project Name** (1): Enter the name of the project as it will be known to the client and the team.
* **Client Name** (2): Enter the name of the client.
* **Contact Name** (3): Enter the name of the contact person for the project.
* **Email** (4): Enter a valid email address for the contact person. (Note: This field is optional, but it's recommended to be filled out for easy communication.)
* **Phone** (5): Enter the phone number of the contact person.
* **Project Type** (6): Select whether the project is 'Yes' or 'No' to indicate its type.
* **Project Description** (7): Provide a detailed description of the project in the text box.
* **Start Date** (8): Enter the start date of the project in the YYYY-MM-DD format.
* **End Date** (9): Enter the end date of the project in the YYYY-MM-DD format.
* **Project Budget** (10): Enter the budget allocated for the project.
* **Project Lead** (11): Enter the name of the project lead.
* **Project Status** (12): Select multiple options to indicate the project status.
* **Project Notes** (13): Enter any additional notes about the project.
* **Client Notes** (14): Enter notes specific to the client.
* **File Uploads** (15): Upload any relevant files for the project.
* **Files** (16): Upload files related to the project.
* **Project Tags** (17): Select multiple options to indicate whether the project has tags.
* **Tags** (18): Select multiple options to indicate tag status.
* **Tag Name** (19): Enter the name of a tag.
* **Tag Description** (20): Provide a description of the tag.
* **Tag Status** (21): Select multiple options to indicate the tag status.
* **Tag Status 2** (22): Select multiple options to indicate tag status.
* **Status** (23): Select multiple options to indicate tag status.
* **Status 2** (24): Select multiple options to indicate tag status.
* **Status 2 List** (25): Select multiple options to indicate tag status.

Please note that all fields marked as 'required' must be filled out for the form to be considered complete.
