# Audience Voting Form - Stand Up Contest - Help Guide
## Purpose
This guide will walk you through the Audience Voting Form for the Stand-up Contest, which aims to collect feedback from audience members on the performers' shows.

## How To Complete This Form
To complete this form, follow these steps:

1. Read the form carefully and understand its purpose.
2. Answer the required fields (indicated by a star).
3. Fill out the form in its entirety.

## Field-by-Field Explanation
* **Show Name**: <label> 
This field is a text input where you can enter the name of the performer's show.
* **Show Date**: 
This field is a date picker where you can select the date of the performer's show.
* **-- Your Ballot --**: <label> 
This section is a note field where you can add any additional comments or notes about the performer's show.
* **Who was the funniest comedian tonight?**: 
This field is a text input where you can enter the name of the comedian you found to be the most entertaining.
* **How would you score their set?**: 
This field is a number input where you can rate the performer's set on a scale of 1 to 10.
* **What was your favorite joke of the set?**: 
This field is a text input where you can enter your favorite joke of the performer's set.
* **How was their crowd work?**: 
This field is a select one input where you can choose how well the performer interacted with the audience.
	+ Excellent
	+ Good
	+ Average
	+ Poor
	+ N/A - No crowd work
* **Stage Presence and Confidence**: 
This field is a select one input where you can rate the performer's stage presence and confidence.
	+ Professional
	+ Comfortable
	+ Nervous but funny
	+ Needs work
* **Any other feedback for the performers?**: 
This field is a text input where you can add any additional feedback or comments about the performer's show.
* **Your Email (Optional)**: 
This field is an email input where you can enter your email address to join the comedy club mailing list (if you choose to do so).
