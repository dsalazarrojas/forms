# Practice Test Creation Survey - Help Guide
## Purpose

This form is designed to gather information about your experiences with creating practice tests. Your responses will help us better understand the challenges you face and the tools you use in the practice test creation process.

## How To Complete This Form

1. Please select your role as an educator, tutor, or training team member.
2. Enter the number of years you have been involved in education.
3. Choose the type of test you create (e.g., Practice Exam, Final Exam, Mock Exam).
4. Select the purposes for which you create practice tests (e.g., time management, assessing student preparation).
5. Choose how often you create practice tests (e.g., daily, weekly).
6. Indicate the difficulty level of the tests you create.
7. If applicable, select who you collaborated with to create the test.
8. Describe any additional comments or thoughts you'd like to share.

## Field-by-Field Explanation

* **what_is_your_role** (`what_is_your_role`, select_one, required):
  + This question is to determine your role in the education sector. Please select one of the provided options (Educator, Tutor, Training Team).
* **years_in_education** (`how_many_years_have_you_been_in_education`, number, required):
  + This question is to gather information about your years of experience in education. Enter the number of years you have been involved in education.
* **test_type** (`what_type_of_test_did_you_create`, select_multiple, required):
  + This question is to understand the type of test you usually create. Select all that apply (Practice Exam, Final Exam, Mock Exam).
* **test_uses** (`practice_test_creation_survey_uses`, select_multiple, required):
  + This question is to identify the reasons you create practice tests. Select all that apply (Time management and efficiency, To assess student preparation and engagement, To evaluate student learning progression).
* **why_do_you_create_practice_tests** (`why_do_you_create_practice_tests`, select_multiple, required):
  + This question is to gather insights into your motivation for creating practice tests. Select all that apply (Time management and efficiency, To assess student preparation and engagement, To evaluate student learning progression).
* **frequency_of_practice_test_creation** (`practice_test_creation_survey_frequency`, select_multiple, required):
  + This question is to understand how frequently you create practice tests. Select all that apply (Daily, Weekly, Monthly, Quarterly, As needed).
* **test_difficulty_level** (`test_difficulty_level`, select_multiple, required):
  + This question is to determine the difficulty level of the practice tests you create. Select all that apply (Easy, Medium, Hard).
* **who_did_you_create_the_test** (`who_did_you_create_the_test`, select_multiple, required):
  + If you created the test independently, select all that applies. Otherwise, choose the correct option from the dropdown list.
* **time_taken_to_create_test** (`time_taken_to_create_test`, select_multiple, required):
  + This question is to gather information about the amount of time you take to create a practice test. Select all that apply (Less than an hour, Between 1-2 hours, Between 2-5 hours, More than 5 hours).
* **what_tools_did_you_use_to_create_the_test** (`what_tools_did_you_use_to_create_the_test`, select_multiple, required):
  + If you used Jotform Survey Templates, select it as a tool. Otherwise, choose Other (please specify) and type the tools you used.
* **what_was_most_difficult_part_of_creating_the_test** (`what_was_most_difficult_part_of_creating_the_test`, select_multiple, required):
  + This question is to understand what was most challenging for you when creating the practice test. Select all that apply (Time Management, Finding the right questions, Other (please specify)).
* **any_other_comments** (`any_other_comments`, text, required):
  + Please type any additional comments or thoughts you'd like to share.
* **who_did_you_collaborate_with_to_create_the_test** (`who_did_you_collaborate_with_to_create_the_test`, select_multiple, required):
  + If you collaborated with someone, select all that apply. Otherwise, choose None or type Other (please specify) and type the names of those individuals.
