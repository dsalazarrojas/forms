# Pre Installation Survey - Help Guide
## Purpose
The Pre Installation Survey form is designed to collect information from users before the installation of a system or application. This information is crucial for a successful and smooth installation process.

## How To Complete This Form
To complete this form, please follow these steps:

1. Review each section carefully and answer all questions accurately.
2. Fill out the form with the requested information.
3. Ensure you've reviewed each field to avoid missing crucial information.
4. If a field is not applicable to you or your environment, please indicate this in the corresponding field.

## Field-by-Field Explanation
### Environment Info (Page 1)
* **Environment Info** (Environment Info, text, Optional): This field is used to collect general information about the environment where the installation will take place.

* **System Admin Info** (System Admin Info, text, Optional): This field is used to collect information about the system administrator's details.

* **User Info** (User Info, text, Optional): This field is used to collect user-related information.

* **Network Info** (Network Info, text, Optional): This field is used to collect network-related information.

* **Database Info** (Database Info, text, Optional): This field is used to collect database information.

* **Hardware Info** (Hardware Info, text, Optional): This field is used to collect hardware-related information.

* **Operating System Info** (Operating System Info, text, Optional): This field is used to collect operating system information.

### Application Info
* **Application Info** (Application Info, text, Optional): This field is used to collect application information.

### Server Info
* **Server Info** (Server Info, text, Optional): This field is used to collect server information.

### Contact Info
* **Contact Info** (Contact Info, text, Optional): This field is used to collect contact information.

### Goals
* **Goals** (Goals, select multiple, Optional): This field is used to select the goals for the installation process.

### Support Info
* **Support Info** (Support Info, text, Optional): This field is used to collect support information.

* **Notes** (Notes, text, Optional): This field is used to add any additional notes or comments.

* **Email** (Email, email, Optional): This field is used to collect email information.

* **Phone** (Phone, text, Optional): This field is used to collect phone information.

* **Assigned User** (Assigned User, text, Optional): This field is used to assign a user for the installation process.

* **Assigned Tool** (Assigned Tool, text, Optional): This field is used to assign a tool for the installation process.

* **Created By** (Created By, text, Optional): This field is used to collect information about the person who created the form.

* **Created Date** (Created Date, date, Optional): This field is used to collect the date when the form was created.

* **Updated By** (Updated By, text, Optional): This field is used to collect information about the person who updated the form.

* **Updated Date** (Updated Date, date, Optional): This field is used to collect the date when the form was updated.

* **Form ID** (Form ID, text, Optional): This field is used to collect a unique form ID.

* **Submitted By** (Submitted By, text, Optional): This field is used to collect information about the person who submitted the form.

* **Submitted Date** (Submitted Date, date, Optional): This field is used to collect the date when the form was submitted.

* **Server Info** (Server Info, text, Optional): This field is used to collect server information.

Please fill out the form carefully and ensure you've reviewed all fields to avoid missing crucial information.
