# Cultural Event Sponsorship Voting Form - Help Guide
## Purpose
The Cultural Event Sponsorship Voting Form is designed to collect votes from multiple users on potential sponsors for a cultural event. 

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the fields as required, which is specified by the required field label in brackets (**required**: true/false).
2. Provide accurate information for each field to ensure that your vote is counted.

## Field-by-Field Explanation
* **Form Header** (`form_header`, text, no): Enter a brief description of the form purpose or a note about the event. This is an optional field that does not affect the voting outcome.
* **Event Name** (`event_name`, text, no): Enter the name of the cultural event.
* **Event Start Date** (`event_start_date`, date, no): Enter the start date of the event.
* **Event End Date** (`event_end_date`, date, no): Enter the end date of the event.
* **Sponsor Name** (`sponsor_name`, text, no): Enter the name of the potential sponsor for the event.
* **Sponsor Title** (`sponsor_title`, text, no): Enter a brief title or description of the potential sponsor.
* **Sponsor Amount** (`sponsor_amount`, number, no): Enter a numerical value indicating how much you are willing to sponsor the event.
* **Sponsor Message** (`sponsor_message`, text, no): Enter any additional information you want to provide about your sponsorship vote.
* **Form Footer** (`form_footer`, text, no): Enter any additional comments or notes about the event or the sponsor. This is an optional field. 

## Tips
* Make sure to fill in all required fields accurately to ensure that your vote is counted.
* If you are unsure about any field, please contact the event organizer or the system administrator for clarification.
* The event and sponsor names should match with the actual event and sponsor information to ensure that the vote is correctly attributed.
* Please do not fill out the form multiple times with the same information, as this can lead to duplicate votes and incorrect results.
