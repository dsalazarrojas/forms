# Office Software Shortcuts Quiz - Help Guide
## Purpose
This form is designed to gather data about users' knowledge of office software shortcuts. The purpose of this form is to collect users' responses to a series of questions about their use of office software shortcuts and provide insights to improve user experience.

## How To Complete This Form
To complete this form, follow these steps:

1. Read each question carefully and fill in the corresponding field with your response.
2. Make sure to fill in all required fields (indicated by a red asterisk *).
3. If a field has options, select the correct answer from the list.
4. Double-check your responses before submitting the form.

## Field-by-Field Explanation
* **Shortcut Name** (`shortcut_name`, text, required/optional): Enter the name of the shortcut you are answering about. This could be a key combination, mouse gesture, or menu path.
* **Shortcut Description** (`shortcut_description`, text, required/optional): Describe the shortcut in a brief sentence or phrase.
* **Correct Answer 1** (`correct_answer`, select_multiple, required/optional): Select all correct answers for the first question. This question is asking about the effectiveness of the shortcut.
* **Correct Answer 2** (`correct_answer_2`, select_one, required/optional): Select the correct answer for the second question. This question is asking about the accuracy of the shortcut.
* **Correct Answer 3** (`correct_answer_3`, select_one, required/optional): Select the correct answer for the third question. This question is asking about the efficiency of the shortcut.
* **Shortcut 2** (`shortcut_2`, text, required/optional): Enter the name of the second shortcut you are answering about. This could be a key combination, mouse gesture, or menu path. 

## Tips
* Make sure to fill in all fields accurately and honestly.
* If you're unsure about an answer, try to best-guess or leave a comment.
* If you have any further questions or concerns, contact your supervisor or support team.
