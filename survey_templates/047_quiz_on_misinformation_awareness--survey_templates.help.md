# Quiz On Misinformation Awareness - Help Guide
## Purpose
The form is designed to create a new quiz template for assessing users' awareness of misinformation. The template will ask users questions related to the topic and provide answers and next steps for users to learn more.

## How To Complete This Form
To complete this form, follow the steps below:

1. Fill out the survey template title and description to briefly describe the quiz.
2. Select an image from the available options to represent the quiz.
3. Add survey questions related to the topic of misinformation.
4. Add answers to the survey questions.
5. Select the next steps for users to take after completing the quiz.
6. Select the category that the quiz belongs to.

## Field-by-Field Explanation

* **Survey Template Title** (`survey_template_title`, text, required: false): Enter a title for the quiz that will appear on the front-end. This will help users easily identify the quiz.
* **Survey Template Description** (`survey_template_description`, text, required: false): Enter a brief description of the quiz that will appear on the front-end. This will provide context for users about what the quiz is about.
* **Survey Template Image** (`survey_template_image`, select_multiple, required: false): Select an image that represents the quiz. This will be displayed on the front-end and help users understand the topic of the quiz.
* **Survey Template Questions** (`survey_template_questions`, text, required: false): Enter questions related to the topic of misinformation. These questions will be displayed to users and will help them assess their knowledge on the topic.
* **Survey Template Answers** (`survey_template_answers`, text, required: false): Enter answers to the survey questions. This will help users understand the correct answers to the questions.
* **Survey Template Results** (`survey_template_results`, select_one, required: false): Select a result for the user to receive after completing the quiz.
* **Survey Template Next Steps** (`survey_template_next_steps`, select_multiple, required: false): Select the next steps for users to take after completing the quiz.
* **Category Select** (`category_select`, select_one, required: true): Select the category that the quiz belongs to. This will help organize and categorize the quiz.
* **Description** (`description`, text, required: false): Enter a brief description of the quiz. This will provide context for users about what the quiz is about.
