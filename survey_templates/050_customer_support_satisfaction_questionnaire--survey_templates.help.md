# Customer Support Satisfaction Questionnaire - Help Guide
## Purpose
This form is a survey designed to collect feedback from customers on their experience with the support team.
## How To Complete This Form
To complete this form, simply follow the instructions below:
1. Select the reasons you were contacted for support.
2. Rate your overall satisfaction with the support team.
3. Provide any comments or feedback you have for the support team.
4. Identify areas where you would like to see improvements.
5. Provide your contact information so we can reach out to you.

## Field-by-Field Explanation
* **What were you contacted for? (Select all that apply)**
	+ Label: what_were_you_contacted_for
	+ Type: Select Multiple Options
	+ Explanation: Please select all the reasons you were contacted for support from the list provided.
* **Rating** (`rating`, required/true)
	+ Type: Number
	+ Explanation: Rate your overall satisfaction with the support team on a scale of 1-5.
* **Comments** (`comments`, required/true)
	+ Type: Text
	+ Explanation: Provide any comments or feedback you have for the support team.
* **Satisfied** (`satisfied`, required/true)
	+ Type: Number
	+ Explanation: Rate your level of satisfaction on a scale of 1-5.
* **Improve in areas** (`improve`, required/true)
	+ Type: Select One Option
	+ Explanation: Identify one area where you would like to see improvement from the support team.
* **Contact Method** (`contact`, required/true)
	+ Type: Select Multiple Options
	+ Explanation: Select the contact method you would like to use for follow-up communication.
* **Additional Comments** (`additional_comments`, required/false)
	+ Type: Text
	+ Explanation: Provide any additional comments or feedback you have for the support team.
* **Email** (`email`, required/true)
	+ Type: Email
	+ Explanation: Provide your email address so we can reach out to you.
* **Phone** (`phone`, required/false)
	+ Type: Text
	+ Explanation: Provide your phone number so we can reach out to you.
