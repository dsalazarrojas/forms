# Repair Request Survey - Help Guide

## Purpose
This form is designed to collect information about the customer's repair request, including their contact details, location, and issue description. The form is intended to help our team understand the nature of the issue and prioritize repairs efficiently.

## How To Complete This Form

1. To begin, please enter the customer's email address in the "Customer Email" field. This will help us verify their identity and ensure we can contact them with updates on their repair.
2. If the customer has provided an alternate email address, please enter that in the "Customer Email 2" field.
3. Enter the customer's name in the "Customer Name" field.
4. Enter the customer's name again in the "Customer Name 2" field.
5. Select the location of the issue from the dropdown menu in the "Location" field.
6. If the issue is related to the customer's second location, please select that location from the "Location 2" field.
7. Enter the date of the issue in the "Issue Date" field.
8. Enter the date of the repair in the "Repair Date" field.
9. Enter the repair date for the second issue in the "Repair Date 2" field.
10. Select the type of issue from the dropdown menu in the "Issue Type" field.
11. Select the type of issue for the second issue from the "Issue Type 2" field.
12. Select the severity of the issue from the dropdown menu in the "Issue Severity" field.
13. Select the severity of the issue for the second issue from the "Issue Severity 2" field.
14. Select the repair type from the dropdown menu in the "Repair Type" field.
15. Select the repair outcome from the dropdown menu in the "Repair Outcome" field.
16. Select the repair outcome for the second issue from the "Repair Outcome 2" field.

## Field-by-Field Explanation

* **Customer Email** (`customer_email`, email, required: false): Enter the customer's email address.
* **Customer Name** (`customer_name`, text, required: false): Enter the customer's name.
* **Location** (`location`, select_one, required: false): Select the location where the issue is located.
* **Repair Date** (`repair_date`, date, required: false): Enter the date of the repair.
* **Issue Description** (`issue_description`, text, required: false): Enter a description of the issue.
* **Issue Type** (`issue_type`, select_one, required: false): Select the type of issue.
* **Issue Severity** (`issue_severity`, select_one, required: false): Select the severity of the issue.
* **Repair Type** (`repair_type`, select_one, required: false): Select the type of repair.
* **Repair Outcome** (`repair_outcome`, select_one, required: false): Select the outcome of the repair.
* **Customer Feedback** (`customer_feedback`, text, required: false): Enter any feedback from the customer.
* **Prophets Comments** (`prophets_comments`, text, required: false): Enter any comments from the prophet.
* **Customer Phone** (`customer_phone`, text, required: false): Enter the customer's phone number.
* **Customer Email 2** (`customer_email2`, email, required: false): Enter the customer's alternate email address.
* **Customer Name 2** (`customer_name2`, text, required: false): Enter the customer's alternate name.
* **Location 2** (`location2`, select_one, required: false): Select the location of the second issue.
* **Repair Date 2** (`repair_date2`, date, required: false): Enter the date of the second repair.
* **Issue Description 2** (`issue_description2`, text, required: false): Enter a description of the second issue.
* **Issue Type 2** (`issue_type2`, select_one, required: false): Select the type of second issue.
* **Issue Severity 2** (`issue_severity2`, select_one, required: false): Select the severity of the second issue.
* **Customer Feedback 2** (`customer_feedback2`, text, required: false): Enter feedback from the customer for the second issue.
* **Comments 2** (`comments2`, text, required: false): Enter any comments for the second issue.
* **Repair Outcome 2** (`repair_outcome2`, select_one, required: false): Select the outcome of the second repair.
