# Inspiration Collection Form - Help Guide
## Purpose
The "Inspiration Collection Form" is designed to gather creative ideas, themes, or concepts for a project or project series.

## How To Complete This Form
To complete this form, follow the instructions below:

1. Review each page carefully and fill out the corresponding fields with the requested information.
2. Make sure to select at least one option for each required field.
3. If a field has multiple options, select all relevant options that apply.
4. Double-check your answers before submitting the form.

## Field-by-Field Explanation
### Page 4: Form Categories
* **Form Categories** (select_multiple): Select all categories that apply to the inspiration you are collecting.

### Page 5: Form Question 1
* **Form Question 1** (select_one): Select one option from the list that best describes the inspiration.

### Page 6: Form Question 2
* **Form Question 2** (select_one): Select one option from the list that best describes the inspiration.

### Page 7: Form Question 3
* **Form Question 3** (number): Enter a numerical value that represents the inspiration.

### Page 8: Form Question 4
* **Form Question 4** (time): Enter a time value that represents the inspiration.

### Page 9: Form Question 5
* **Form Question 5** (date): Enter a date value that represents the inspiration.

### Page 10: Form Question 6
* **Form Question 6** (email): Enter an email address that is relevant to the inspiration.

### Page 11: Form Question 7
* **Form Question 7** (text): Enter a text description of the inspiration.

### Page 12: Form Question 8
* **Form Question 8** (note): Enter a note or additional information about the inspiration.

### Page 13-20: Form Question 8-15
* **Form Question 8-15** (text): Enter text descriptions of the inspiration for each question.

## Tips
* Make sure to fill out all required fields (indicated by a star) to ensure that your answers are complete and accurate.
* If you need help or clarification on any field, refer to the field label or contact the form owner.
* This form is designed to be flexible and adaptable, so feel free to add or remove pages as needed.
