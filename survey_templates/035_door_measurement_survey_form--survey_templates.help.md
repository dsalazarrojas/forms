# Door Measurement Survey Form - Help Guide
## Purpose
The Door Measurement Survey Form is used to collect measurements and details of doors for a property or building. This information is used to inform property management and maintenance tasks.

## How To Complete This Form
To complete this form, simply follow the steps below:

1. Select the type of door you are measuring.
2. Enter the height, width, and thickness of the door, if applicable.
3. Choose the material and style of the door.
4. Select the condition of the door.
5. Add any additional notes about the door.

## Field-by-Field Explanation

* **Door Type** (`door_type`, select_one): This field asks you to select the type of door you are measuring. Please choose from the options: Panel Door, Sliding Glass Door, Steel Door, or Other.
* **Height** (`door_height`, number): This field is used to enter the height of the door. Enter a numerical value for the height of the door, in millimeters.
* **Width** (`door_width`, number): This field is used to enter the width of the door. Enter a numerical value for the width of the door, in millimeters.
* **Thickness** (`door_thickness`, number): This field is used to enter the thickness of the door. Enter a numerical value for the thickness of the door, in millimeters.
* **Material** (`door_material`, select_one): This field asks you to select the material of the door. Please choose from the options: Wood, Metal, Glass, or Other.
* **Style** (`door_style`, select_multiple): This field is used to select the style of the door. Choose from the options: Rounded, Arch, Raised Panel, Flat, or Other.
* **Color** (`door_color`, text): This field is used to enter the color of the door. Enter a brief description of the door's color.
* **Condition** (`door_condition`, select_one): This field asks you to select the condition of the door. Please choose from the options: Good, Fair, or Poor.
* **Notes** (`door_notes`, note): This field is for any additional notes about the door.
* **Installer Notes** (`installer_notes`, note): This field is for any notes from the installer or technician about the door.
* **Property Manager Notes** (`property_manager_notes`, note): This field is for any notes from the property manager about the door.

## Tips

* Please make sure to answer accurately and completely, as the information collected will be used to inform decisions and actions related to the property or building.
* If you are unsure about any field, please ask for clarification or contact the property manager.
* If you have any additional information that is not captured in this form, please add it in the notes field.
* If you need to complete the form for multiple doors, please fill out each field for each door individually.
