# Grazing Project Approval Survey - Help Guide
## Purpose
The Grazing Project Approval Survey is a form used to collect project information for grazing projects. It helps in tracking and monitoring project progress.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill in the project location.
2. Enter the project title.
3. Enter the start and end dates of the project.
4. Provide the project duration.
5. Add a brief description of the project.
6. Select the project area.
7. Enter the location of the project.
8. Select the project start and end times (if applicable).
9. Choose the project status (Active, Inactive, or Pending).
10. Select the project type (Grazing, Haymaking, or Harvesting).
11. Choose the grazing method (Strip Grazing or Mob Grazing).
12. Add any project leads and partners.
13. Enter any project notes.
14. Select environmental measures (if applicable).
14. Enter the agency's details: name, phone number, email, address, and number of employees.

## Field-by-Field Explanation
### Location (1)
* **Location** (text, required/optional): Enter the location of the project.
### Project Title (2)
* **Project Title** (text, required/true): Enter a brief title of the project.
### Project Start Date (3)
* **Project Start Date** (date, required/true): Enter the start date of the project.
### Project End Date (4)
* **Project End Date** (date, required/true): Enter the end date of the project.
### Project Duration (5)
* **Project Duration** (number, required/optional): Enter the duration of the project.
### Project Description (6)
* **Project Description** (text, required/optional): Enter a brief description of the project.
### Project Area (7)
* **Project Area** (text, required/optional): Enter the project area.
### Project Location (8)
* **Project Location** (text, required/true): Enter the exact location of the project.
### Project Start Time (9)
* **Project Start Time** (time, required/optional): Enter the start time of the project.
### Project End Time (10)
* **Project End Time** (time, required/optional): Enter the end time of the project.
### Project Status (11)
* **Project Status** (select_one, required/optional): Select the project status (Active, Inactive, or Pending).
### Project Type (12)
* **Project Type** (select_one, required/optional): Select the project type (Grazing, Haymaking, or Harvesting).
### Grazing Method (13)
* **Grazing Method** (select_multiple, required/optional): Choose the grazing method (Strip Grazing or Mob Grazing).
### Project Leads (14)
* **Project Leads** (text, required/optional): Enter any project leads.
### Project Partners (15)
* **Project Partners** (text, required/optional): Enter any project partners.
### Project Notes (16)
* **Project Notes** (text, required/optional): Enter any project notes.
### Environmental Measures (17)
* **Environmental Measures** (text, required/optional): Select any environmental measures (if applicable).
### Project Agency (18)
* **Project Agency** (text, required/true): Enter the name of the project agency.
### Project Agency Phone (19)
* **Project Agency Phone** (text, required/true): Enter the phone number of the project agency.
### Project Agency Email (20)
* **Project Agency Email** (email, required/optional): Enter the email of the project agency.
### Project Agency Fax (21)
* **Project Agency Fax** (text, required/optional): Enter the fax number of the project agency.
### Project Agency Website (22)
* **Project Agency Website** (text, required/optional): Enter the website of the project agency.
### Project Agency Address (23)
* **Project Agency Address** (text, required/true): Enter the address of the project agency.
### Project Agency Employees (24)
* **Project Agency Employees** (text, required/optional): Enter the number of employees in the project agency.
### Project Agency Notes (25)
* **Project Agency Notes** (text, required/optional): Enter any notes about the project agency.

## Tips
* Please ensure that all required fields are filled in before submitting the form.
* If you are unsure about any field, please refer to the field label for clarification.
* If you are filling out the form for someone else, please double-check that you have the correct information to avoid mistakes.
* If you have any questions or concerns, please contact your project lead or agency for assistance.
