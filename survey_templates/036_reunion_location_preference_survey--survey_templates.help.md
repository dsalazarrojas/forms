# Reunion Location Preference Survey - Help Guide

## Purpose
This survey is designed to collect information about the preferred location and details for a reunion. The purpose of this survey is to gather feedback and preferences from attendees to determine the best location and timing for the event.

## How To Complete This Form
To complete this form, simply follow these steps:

1. Select your preferred location for the reunion from the list of options provided.
2. Choose how likely you are to attend the reunion.
3. If you have any specific location in mind, please provide it in the "Recommended Location Preference" field.
4. Choose the start and end dates for the reunion.
5. Provide your contact email and phone number so we can keep you updated about the reunion.

## Field-by-Field Explanation

* **Location Preference** (`location_preference`, `select_multiple`, Required): Select one or more of the following locations as your preferred location for the reunion:
	+ Hawaii
	+ Florida
	+ Las Vegas
	+ California
	+ Texas
* **Attendance Likelihood** (`attendance_likelihood`, `select_one`, Required): Choose how likely you are to attend the reunion:
	+ Likely
	+ Unlikely
* **Recommended Location Preference** (`recommended_location`, `text`, Optional): If you have a specific location in mind for the reunion, please provide it here.
* **Start Date** (`start_date`, `date`, Optional): Select the start date for the reunion.
* **End Date** (`end_date`, `date`, Optional): Select the end date for the reunion.
* **Contact Email** (`contact_email`, `email`, Required): Provide your email address so we can keep you updated about the reunion.
* **Contact Phone** (`contact_phone`, `text`, Optional): Provide your phone number so we can keep you updated about the reunion.
* **Comments** (`comments`, `text`, Optional): Add any additional comments or suggestions you have about the reunion.

Note: The required fields are marked as `Required`.
