# sector_icons_feedback_survey - Help Guide
## Purpose
The sector icons feedback survey is designed to collect feedback on the usability and effectiveness of icons. Your input will help us improve the design and user experience.

## How To Complete This Form
To complete this form, follow these steps:

1. Answer the questions on each page in order.
2. For each question, provide a response based on your honest opinion.
3. If a question is not applicable, choose "Not Applicable" as the answer.
4. Provide any additional feedback you may have in the "Additional Feedback" field.

## Field-by-Field Explanation
* **What do you think about these icons?** (`user_feedback`, `text`, required)
	+ Provide a brief description or statement about your thoughts on the icons.
* **How would you describe this icon's design?** (`icon_design`, `select_multiple`, required)
	+ Select all that apply from the options to describe the design of the icons.
* **How effective do you think this icon is in its current state?** (`icon_effectiveness`, `select_one`, required)
	+ Choose how effective you think the icon is on a scale from very effective to not effective.
* **How useful do you think this icon will be?** (`icon_usefulness`, `number`, required)
	+ Please enter a numeric value from 1-10 to indicate how useful you think the icon will be.
* **How easy or hard do you think this icon is to use?** (`icon_usability`, `select_one`, required)
	+ Choose how easy or hard you think the icon is to use on a scale from very easy to very hard.
* **Additional Feedback** (`feedback`, `text`, optional)
	+ Provide any additional comments or suggestions about the icons.
* **Email Address** (`email_address`, `email`, optional)
	+ Enter your email address if you'd like to receive feedback on your response.
