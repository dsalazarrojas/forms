# Fill In The Blank Survey - Help Guide
## Purpose
The Fill In The Blank Survey form is designed to collect feedback and information from users in a simple and structured way. This form should be used when gathering opinions, preferences, or ratings from users, such as in market research, user engagement, or user experience surveys. **Please note that this form is not intended for collecting sensitive or personal data**.

## How To Complete This Form
To complete the form, follow these steps:

1. **Introduction**: Please provide a brief description of your thoughts on the topic. This field is optional.
2. **Quiz**: Select the answers to the questions presented. You can choose one answer for each question. For example, if the questions are:
	* 'question 1: answer 1'
	* 'question 1: answer 2'
	* 'question 1: answer 3'
	* 'question 2: answer 4'
	* 'question 2: answer 5'
3. **Results**: Choose all that apply for the questions presented.

## Field-by-Field Explanation
### **Introduction**
* **Introduction** (`text`, optional): A space to write your thoughts on the topic. 

### **Quiz**
* **question 1: answer 1** (`select_one`, required): Select the answer for the first question.
* **question 1: answer 2** (`select_one`, optional): Select the answer for the first question (if not answered in the first question).
* **question 1: answer 3** (`select_one`, optional): Select the answer for the first question (if not answered in the first question).
* **question 2: answer 4** (`select_one`, optional): Select the answer for the second question.
* **question 2: answer 5** (`select_one`, optional): Select the answer for the second question.

### **Results**
* **Results** (`select_multiple`, optional): Choose all that apply for the questions presented.

## Tips
* Please answer all questions that apply to you.
* If a question does not apply, leave it blank.
* You can use this form multiple times if needed.
* If you need help, ask your administrator for assistance.
