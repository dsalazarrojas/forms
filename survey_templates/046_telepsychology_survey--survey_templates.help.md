# Telepsychology Survey - Help Guide
## Purpose
The Telepsychology Survey form is used to collect information about a telepsychology survey. This form is designed to gather data on various aspects of telepsychology, including category and description fields.

## How To Complete This Form
To complete this form, follow these steps:

1. Review each page of the form carefully and answer the questions as accurately as possible.
2. Select the correct category from the dropdown menu.
3. Enter a brief description of the survey in the designated text field.

## Field-by-Field Explanation
* **survey_template** (Page 1, Text): A text field where you can enter a brief description of the survey template.
* **telepsychology_survey** (Page 2, Text): A text field where you can enter a description of the survey.
* **category** (Page 3, Select One): Select the category of the survey from the options provided: "category template" or "Other".
* **description** (Page 4, Text): A text field where you can enter a description of the survey.
* **assigned_tool** (Page 5, Select Multiple): Check one or more boxes to indicate if the survey has been assigned to a tool.
* **results** (Page 6, Note): A text field where you can enter any additional notes or results from the survey.

## Tips
* Make sure to answer all questions accurately and thoroughly to ensure the data collected is useful for analysis.
* If you are unsure about any of the questions, please contact the relevant personnel for clarification.
* This form is designed to be user-friendly and easy to complete, but if you encounter any issues, please don't hesitate to reach out for assistance.
