The purpose of this form is to collect data from veterinarians about their practices and habits when sharing data. This form aims to understand what veterinarians do and why they share data, and what challenges they face when sharing data. The data collected will be used to improve the sharing of data in the veterinary industry.

To complete this form, the user should follow these steps:

## Purpose

This form is designed to gather information about veterinary practices and habits related to data sharing. It is part of a research effort to better understand how veterinarians share data and what factors influence their willingness and ability to do so.

## How To Complete This Form

1. Answer the questions on the survey_start page.
2. On the Data Sharing Habits page, select one or more of the options that best describe your current habits when sharing data.
3. On the Tools Used page, select the data sharing tools you currently use from the list provided.
4. On the Barriers To Data Sharing page, select the primary reason you face when sharing data.
5. On the Willingness To Share Data page, select how strongly you feel about sharing data.
6. On the Reasons For Not Sharing page, select any reasons that apply to you.
7. Click the "Survey End" page to submit your answers.

## Field-by-Field Explanation

* **Survey Start**: This page is a placeholder to guide you through the survey.
* **Data Sharing Habits**: This question asks about your current habits when sharing data. Please select all that apply:
	+ Always share data
	+ Sometimes share data
	+ Rarely share data
	+ Never share data
* **Tools Used**: This question asks about the tools you use to share data. Please select one that applies:
	+ Google Drive
	+ Dropbox
	+ Email
	+ Other
	+ None
* **Barriers To Data Sharing**: This question asks about the primary reason you face when sharing data. Please select one that applies:
	+ Time constraints
	+ Resource limitations
	+ Security concerns
	+ Data quality issues
	+ Other
* **Willingness To Share Data**: This question asks about your willingness to share data. Please select one that applies:
	+ Strongly willing
	+ Somewhat willing
	+ Not very willing
	+ Not at all willing
* **Reasons For Not Sharing**: This question asks about any reasons you might not share data. Please select all that apply:
	+ Concerns about data misuse
	+ Concerns about data security
	+ Concerns about data quality
	+ Other
	+ None
* **Survey End**: This page is a confirmation that you have completed the survey.
