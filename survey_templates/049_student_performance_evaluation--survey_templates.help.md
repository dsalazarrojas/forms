# Student Performance Evaluation - Help Guide
## Purpose
The purpose of this form is to assess the overall performance of students, evaluating their progress and attendance.

## How To Complete This Form
To complete this form, please follow these steps:
1. Fill in the required fields with accurate and truthful information about the student.
2. Make sure to select the correct options for each field, if applicable.
3. Submit the form once you have completed all the required fields.

## Field-by-Field Explanation
### First Name (`student_performance_evaluation`)
* **First Name (student_performance_evaluation)**: Enter the student's first name.
### Last Name (`last_name`)
* **Last Name (last_name)**: Enter the student's last name.
### Email (`email`)
* **Email (email)**: Enter the student's email address.
### Date of Birth (`date_of_birth`)
* **Date of Birth (date_of_birth)**: Enter the student's date of birth in YYYY-MM-DD format.
### Performance Score (`student_performance`)
* **Performance Score (student_performance)**: Evaluate the student's overall performance, on a scale from 1 to 100.
### Course Name (`course_name`)
* **Course Name (course_name)**: Enter the name of the course the student is enrolled in.
### Grade Point Average (`grade_point_average`)
* **Grade Point Average (grade_point_average)**: Evaluate the student's GPA, on a scale from 0 to 100.
### Graduation Date (`graduation_date`)
* **Graduation Date (graduation_date)**: If applicable, enter the student's expected graduation date in YYYY-MM-DD format.
### Student Status (`student_status`)
* **Student Status (student_status)**: Select the student's current status, which can be active, inactive, or pending.
### Teacher Name (`teacher_name`)
* **Teacher Name (teacher_name)**: Enter the name of the teacher responsible for the student.
### Department (`department`)
* **Department (department)**: Enter the name of the department the student is enrolled in.
### Student ID (`student_id`)
* **Student ID (student_id)**: Enter the student's ID number.
### Student Comments (`student_comments`)
* **Student Comments (student_comments)**: Add any additional comments about the student's performance.
### Course Performance (`course_performance`)
* **Course Performance (course_performance)**: Evaluate the student's performance in the course, as excellent, satisfactory, or unsatisfactory.
### Student Attendance (`student_attendance`)
* **Student Attendance (student_attendance)**: Evaluate the student's attendance, on a scale from 0 to 100.
### Teacher Comments (`teacher_comments`)
* **Teacher Comments (teacher_comments)**: Add any additional comments from the teacher.
### Student Performance Attendance (`student_performance_attendance`)
* **Student Performance Attendance (student_performance_attendance)**: Evaluate the student's performance attendance, on a scale from 0 to 100.
### Course Attendance (`course_attendance`)
* **Course Attendance (course_attendance)**: Evaluate the student's course attendance, on a scale from 0 to 100.
### Student Progress (`student_progress`)
* **Student Progress (student_progress)**: Enter any additional comments about the student's progress.
### Teacher Progress (`teacher_progress`)
* **Teacher Progress (teacher_progress)**: Enter any additional comments from the teacher about the student's progress.
### Student Performance Graph (`student_performance_graph`)
* **Student Performance Graph (student_performance_graph)**: Enter a graph or chart of the student's performance over time.
### Teacher Performance Graph (`teacher_performance_graph`)
* **Teacher Performance Graph (teacher_performance_graph)**: Enter a graph or chart of the teacher's performance over time.
### Student Evaluation Form Status (`student_evaluation_form_status`)
* **Student Evaluation Form Status (student_evaluation_form_status)**: Select the status of the form, which can be completed, incomplete, or pending.
### Student Form Submission Time (`student_form_submission_time`)
* **Student Form Submission Time (student_form_submission_time)**: Enter the time the form was submitted.
### Student Form Submission Date (`student_form_submission_date`)
* **Student Form Submission Date (student_form_submission_date)**: Enter the date the form was submitted in YYYY-MM-DD format.
### Student Evaluation Form Submission Status (`student_evaluation_form_status`)
* **Student Evaluation Form Submission Status (student_evaluation_form_status)**: Select the status of the form submission, which can be completed, incomplete, or pending.
