# Roots Evaluation Survey - Help Guide

## Purpose
This form is designed to collect feedback and information about the "Roots" project's progress, focusing on participant feedback, root knowledge, health observations, management challenges, and root health observations. The form aims to gather insights into the project's strengths and weaknesses to help inform future development and decision-making.

## How To Complete This Form
1. Review the form carefully and ensure you understand each field's purpose and options.
2. Answer each question honestly and to the best of your ability.
3. Select the relevant options for each field based on your understanding and experience with the project.
4. Ensure all required fields (indicated by *) are filled in before submitting the form.

## Field-by-Field Explanation

* **participant_feedback** (Required/Optional): This field allows you to provide feedback about your experience with the project. Write a brief description of your thoughts and feelings about the project's progress and any challenges you've faced.
* **root_knowledge** (Optional): If you have a good understanding of the root system, select "Yes". If you are unsure or lack knowledge, select "No".
* **health_observations** (Optional): If you have observed any health-related concerns or issues with the root system, select "Yes". If you have not observed any concerns, select "No".
* **management_challenges** (Optional): If you have faced management-related challenges with the project, select "Yes". If you have not faced any challenges, select "No".
* **root_health_observations** (Optional): If you have observed any health-related concerns with the root system, select "Yes". If you have not observed any concerns, select "No".
* **root_management_challenges** (Optional): If you have faced management-related challenges with the root system, select "Yes". If you have not faced any challenges, select "No".
* **root_knowledge** (Optional): If you have a good understanding of the root system, select "Yes". If you are unsure or lack knowledge, select "No".
* **root_health_observations** (Optional): If you have observed any health-related concerns with the root system, select "Yes". If you have not observed any concerns, select "No".

## Tips
* Be honest and thorough in your answers to provide valuable insights.
* If you are unsure about any field, ask for clarification or guidance from your supervisor or project lead.
* Remember to review the form carefully before submitting to ensure all required fields are filled in correctly.
