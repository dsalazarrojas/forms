# Cultural Event Communication Form - Help Guide
## Purpose
This form is designed to gather information about cultural events, including event details, participant information, and communication preferences. It is intended for event organizers to effectively communicate with participants and ensure a smooth event experience.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the event name in the first field, `event_name`.
2. Provide participant information in the `participant_info` field.
3. If you want to be contacted regarding the event, please enter your email address in the `contact_email` field. (This field is optional and not required.)
4. Enter your phone number in the `contact_phone` field, if you want to be contacted by phone. (This field is optional and not required.)
5. Provide additional details about the event in the `event_details` field.
6. If you have any feedback about the event, please enter it in the `feedback` field. (This field is optional and not required.)
7. Select the date of the event from the `event_date` field. (This field is required.)
8. Choose the time of the event from the `event_time` field. (This field is required.)
9. Select the type of event from the `select_type` field. (This field is optional but recommended.)
10. Select the participants attending the event from the `select_participants` field. (This field is optional but recommended.)
11. Choose your preferred language from the `select_language` field. (This field is optional but recommended.)
12. If necessary, provide additional information about the event in the `additional_info` field. (This field is optional and not required.)
13. Finally, select a date for the event from the `select_date` field. (This field is optional but recommended.)
14. Select the time for the event from the `select_time` field. (This field is optional but recommended.)

## Field-by-Field Explanation
- **Event Name** (`event_name`, `text`, required): Enter the name of the event in this field.
- **Participant Information** (`participant_info`, `text`, required): Provide details about the participants, such as their names and roles.
- **Contact Email** (`contact_email`, `text`, optional): Enter your email address if you want to be contacted about the event. (If this field is left blank, we will not be able to contact you.)
- **Contact Phone** (`contact_phone`, `text`, optional): Enter your phone number if you want to be contacted about the event. (If this field is left blank, we will not be able to contact you.)
- **Event Details** (`event_details`, `text`, optional): Provide any additional information about the event that is not covered in the other fields.
- **Feedback** (`feedback`, `text`, optional): Enter any feedback you have about the event. (If this field is left blank, we will not be able to take your feedback into account.)
- **Event Date** (`event_date`, `date`, required): Select the date of the event from the calendar. 
- **Event Time** (`event_time`, `time`, required): Choose the time of the event from the time options.
- **Type of Event** (`select_type`, `select_one`, optional): Select the type of event from the available options (Event, Workshop, Conference).
- **Participants Attending** (`select_participants`, `select_multiple`, optional): Select which participants are attending the event from the options.
- **Preferred Language** (`select_language`, `select_one`, optional): Choose your preferred language for event communication from the options (English, Spanish, French).
- **Additional Information** (`note`, `text`, optional): If you have any additional information about the event, please enter it here.
- **Select Date** (`select_date`, `select_one`, optional): Select a date from the options (Today, Tomorrow, Next day).
- **Select Time** (`select_time`, `select_multiple`, optional): Choose the time from the options (Morning, Afternoon, Evening).
