# Gaming New Features Feedback Report Form - Help Guide
## Purpose

This form is designed for players to provide feedback on new features in a game. It helps game developers understand what players think about the new features and how they can be improved. The feedback collected through this form will be used to make data-driven decisions and improve the game experience.

## How To Complete This Form

1. **Start by selecting the game you are providing feedback on** (not shown in the YAML, but implied as a required field not defined in the YAML). Please select the game title that corresponds to the feedback you are providing.
2. **Enter the name of the new feature you are providing feedback on** in the "Feature Name" field. This is the specific feature you are commenting on.
3. **Provide a brief description of your feedback** in the "Feedback" field. Be as detailed as possible to help the developers understand your thoughts.
4. **Rate your satisfaction with the new feature** using the "Rating" field. This will help us understand how well the feature met your expectations.
5. **Choose a category that best describes the new feature** in the "Category" field. This will help us group similar feedback together. Choose from "New Features", "Gameplay", "Storyline", "Gameplay Mechanics", "Sound", or "Graphics".
6. **Add any additional comments or thoughts** about the feature in the "Comment" field. This is an optional field where you can provide more information or clarification.
7. **Enter your email address** in the "Email" field, so we can contact you if needed for further discussion.
8. **Add your phone number** in the "Phone" field, for any additional contact information.

## Field-by-Field Explanation

* **Game Title** (`game_title`, text, required/optional): This field is used to select the game you are providing feedback on. Please enter the exact title of the game.
* **Feature Name** (`feature_name`, text, required/optional): This field is where you provide the name of the new feature you are commenting on.
* **Feedback** (`feedback`, text, required/optional): This field is where you can provide a brief description of your thoughts on the new feature.
* **Rating** (`rating`, number, required/optional): This field allows you to rate your satisfaction with the new feature, from 1 to 10.
* **Category** (`category`, select_one, required/optional): This field is where you choose a category that best describes the new feature.
* **Comment** (`comment`, note, optional/optional): This field is for any additional comments or thoughts you have about the feature.
* **Email** (`email`, email, required/optional): This field is where you can enter your email address, so we can contact you if needed for further discussion.
* **Phone** (`phone`, text, required/optional): This field is for any additional contact information.

## Tips

* Please be as specific as possible when providing feedback, as this will help us understand your thoughts better.
* If you have any further questions or concerns, please don't hesitate to contact us.
