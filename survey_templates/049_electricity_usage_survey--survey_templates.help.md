# electricity_usage_survey - Help Guide
## Purpose
This form is designed to collect information about electricity usage patterns and consumption habits from users. It will help us better understand how electricity is being used and inform decisions on energy-saving initiatives.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the type of electricity usage you have (Meter, Kilowatt, or Watt).
2. Choose the location where the electricity usage occurs (Home, Building, or Office).
3. Enter the start and end dates of the electricity usage period.
4. Enter a brief description of the electricity usage (Electricity Usage).
5. Enter the unit of electricity consumption (Electricity Consumption Unit).
6. (Optional) Enter the frequency of electricity usage, and any additional notes or comments about the electricity usage (Electricity Usage Notes).

## Field-by-Field Explanation
* **Electricity Usage Survey 1**: This is the title of the form and is not a field that needs to be filled. It is used to identify the form and provide a reference point.
* **What type of electricity usage do you have?**: This is a required field that asks you to select the type of electricity usage you have. Please choose from the options provided: Meter, Kilowatt, or Watt.
* **Usage Location**: This is a required field that asks you to select the location where the electricity usage occurs. Please choose from the options provided: Home, Building, or Office.
* **Usage Start Date**: This is a required field that asks you to enter the start date of the electricity usage period. Please use the date picker to select a date.
* **Usage End Date**: This is a required field that asks you to enter the end date of the electricity usage period. Please use the date picker to select a date.
* **Electricity Usage**: This is a required field that asks you to enter a brief description of the electricity usage. Please provide a clear and concise answer.
* **Electricity Consumption Unit**: This is a required field that asks you to enter the unit of electricity consumption. Please enter the relevant unit (e.g., kWh, MW, or MWh).
* **Frequency of Usage**: This is an optional field that asks you to enter the frequency of electricity usage. Please provide a brief description of the frequency.
* **Frequency of Usage 2**: This is an optional field that is redundant with the previous field. Please do not fill this field unless you want to provide additional information.
* **Electricity Usage Notes**: This is an optional field that asks you to enter any additional notes or comments about the electricity usage. Please provide any relevant information that will help us understand the electricity usage better.
