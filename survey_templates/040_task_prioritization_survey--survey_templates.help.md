# Task Prioritization Survey - Help Guide
## Purpose
The purpose of this form is to gather information on tasks, their priority levels, and the order in which they should be performed.

## How To Complete This Form
This form is divided into several pages with different types of questions. Please follow the instructions for each page:
- Page 1: "What are the most important tasks" - Enter a brief description of the tasks that are most important to you.
- Page 2: "What tasks are least important" - Describe tasks that can be deprioritized.
- Page 3: Select "Yes" or "No" for the tasks that you want to prioritize first.
- Page 4: Select "Yes" or "No" for the tasks that you want to deprioritize first.
- Page 5 and 6: Select one of the three options (High, Medium, or Low) for Task 1 and Task 2.
- Page 7 and 8: These pages are currently empty and do not require any input.

## Field-by-Field Explanation
* **What are the most important tasks** (Page 1): This field is used to describe the tasks that are most critical to you. Be as brief and concise as possible.
* **What tasks are least important** (Page 2): This field is used to describe tasks that can be deprioritized. Think about tasks that can be delayed or done last.
* **Which tasks should be prioritized first** (Page 3): This field allows you to select tasks that should be done first. Select "Yes" for tasks that are high-priority.
* **Which tasks should be deprioritized first** (Page 4): This field is used to select tasks that can be done last. Select "Yes" for tasks that are low-priority.
* **Task 1** (Page 5): Select the priority level for Task 1. Choose "High" for tasks that are critical, "Medium" for tasks that are somewhat important, and "Low" for tasks that are least important.
* **Task 2** (Page 6): Select the priority level for Task 2. Choose "High" for tasks that are critical, "Medium" for tasks that are somewhat important, and "Low" for tasks that are least important.
* **Task date** (Page 7): This field is currently not being used in the form and does not require input.
* **Task time** (Page 8): This field is currently not being used in the form and does not require input.

## Tips
* Be as brief and concise as possible when filling out the form.
* Only enter information that is accurate and true to your current priorities.
* If a task has no priority level assigned, it is recommended to assign it a "Low" priority. 
* Please review your answers carefully before submitting the form to ensure accuracy.
