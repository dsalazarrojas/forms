# Option Selection Survey - Help Guide

## Purpose
This form is designed to gather information from users on various topics, including option selections, text inputs, and date/time selections.

## How To Complete This Form

1. Please select the options that apply to you from the available choices.
2. If you have any additional information or comments, please provide it in the text fields.
3. Select a date and time for when you would like to participate in a follow-up survey, if applicable.

## Field-by-Field Explanation

* **Select One Option** (`select_one_question`, Select One Option, required: false)
	+ This field allows you to select one option from the available choices.
* **Select Multiple Options** (`select_multiple_question`, Select Multiple Options, required: false)
	+ This field allows you to select multiple options from the available choices.
* **Select One Date** (`select_one_date_question`, Select One Date, required: false)
	+ This field allows you to select one date from the available choices.
* **Text Field** (`text_field`, Text Field, required: false)
	+ This field is for providing additional text information.
* **Text Area** (`text_area`, Text Area, required: false)
	+ This field is for providing more detailed text information.
* **Email** (`email_field`, Email, required: false)
	+ This field is for providing your email address.
* **Phone** (`phone_field`, Phone, required: false)
	+ This field is for providing your phone number.
* **Date** (`date_field`, Date, required: false)
	+ This field is for selecting a date.
* **Time** (`time_field`, Time, required: false)
	+ This field is for selecting a time.
* **Note** (`note_field`, Note, required: false)
	+ This field is for providing additional note information.
* **How did you hear about this survey?** (`follow_up_survey`, How did you hear about this survey?, required: false)
	+ This field is to determine how you heard about this survey.
* **When would you like to participate in a follow-up survey?** (`follow_up_survey_2`, When would you like to participate in a follow-up survey?, required: false)
	+ This field is for selecting a date and time for a follow-up survey.
