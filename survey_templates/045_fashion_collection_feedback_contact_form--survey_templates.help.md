# Fashion Collection Feedback Contact Form - Help Guide

## Purpose
The Fashion Collection Feedback Contact Form is designed to collect feedback and comments from fashion events, product collections, and other relevant information for analysis and improvement. This form is intended for customers, stakeholders, or staff to share their thoughts, concerns, and suggestions about existing or planned fashion collections.

## How To Complete This Form

To complete this form, follow these steps:

1. Select the relevant event details from the available options.
2. Provide detailed feedback about the event and product collection.
3. Enter your contact information (email, phone, and contact person).
4. Optionally, select the assigned user and tool for follow-up actions.
5. Add any additional comments or notes if needed.
6. Select the status and priority of the feedback.
7. Choose the category and assigned tool for the feedback.
8. Enter the created and updated timestamps for the feedback.

## Field-by-Field Explanation

* **Event Details**: This field is used to select the event details related to your feedback.
	+ Type: text
	+ Required: false
* **Feedback Details**: This field is used to provide detailed information about your feedback and comments.
	+ Type: text
	+ Required: false
* **Contact Details**: This field is used to enter your contact information (email, phone, and contact person).
	+ Type: text
	+ Required: false
* **Date**: This field is used to select the date of the event.
	+ Type: date
	+ Required: false
* **Product**: This field is used to select the product related to your feedback.
	+ Type: select_one
	+ Options: Product A, Product B, Product C, Product D
	+ Required: false
* **Contact Person**: This field is used to enter the contact person's name.
	+ Type: text
	+ Required: false
* **Phone**: This field is used to enter your phone number.
	+ Type: text
	+ Required: false
* **Email**: This field is used to enter your email address.
	+ Type: email
	+ Required: false
* **Feedback**: This field is used to add any additional feedback or comments.
	+ Type: text
	+ Required: false
* **Comments**: This field is used to add any additional comments or notes.
	+ Type: text
	+ Required: false
* **Follow-up**: This field is used to add any follow-up information.
	+ Type: note
	+ Required: false
* **Assigned To**: This field is used to select the assigned user for follow-up actions.
	+ Type: text
	+ Required: false
* **Assigned User**: This field is used to select the user assigned to the feedback.
	+ Type: select_one
	+ Options: User 1, User 2, User 3, User 4
	+ Required: false
* **Assigned Date**: This field is used to select the assigned date for the feedback.
	+ Type: date
	+ Required: false
* **Status**: This field is used to select the status of the feedback.
	+ Type: select_one
	+ Options: Open, In Progress, Done, Closed
	+ Required: false
* **Priority**: This field is used to select the priority of the feedback.
	+ Type: number
	+ Required: false
* **Category**: This field is used to select the category of the feedback.
	+ Type: select_multiple
	+ Options: A, B
	+ Required: false
* **Assigned Tool**: This field is used to select the assigned tool for the feedback.
	+ Type: text
	+ Required: false
* **Notes**: This field is used to add any additional notes or comments.
	+ Type: text
	+ Required: false
* **Created At**: This field is used to select the created timestamp for the feedback.
	+ Type: date
	+ Required: false
* **Updated At**: This field is used to select the updated timestamp for the feedback.
	+ Type: date
	+ Required: false
* **Deleted At**: This field is used to select the deleted timestamp for the feedback.
	+ Type: date
	+ Required: false
* **Deleted By**: This field is used to select the deleted user for the feedback.
	+ Type: text
	+ Required: false
* **Deleted Reason**: This field is used to select the deleted reason for the feedback.
	+ Type: text
	+ Required: false
