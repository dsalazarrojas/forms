# Drainage Survey - Help Guide

## Purpose
The Drainage Survey form is used to collect information about a drainage system, its status, material, size, orientation, and water quality.

## How To Complete This Form

To complete this form, follow these steps:

1. Review the form fields carefully and ensure you have access to the necessary information.
2. Answer each question to the best of your ability, and remember that some fields are optional.
3. Enter your answers in the format specified for each field.

## Field-by-Field Explanation

* **Drainage Survey Questionnaire**: This field is a free-form text area where you can enter a brief description of the drainage system, if necessary.
* **Drainage System Description**: Enter a brief description of the drainage system, including its location and purpose.
* **System Status**: Choose one or both of the following options:
	+ Active: The system is currently in use and functioning as expected.
	+ Inactive: The system is not currently in use or is not functioning as expected.
* **Flow Rate**: Enter the flow rate of the drainage system, if known. This can be a numerical value.
* **Pressure Head**: Enter the pressure head of the drainage system, if known. This can be a numerical value.
* **Pipe Material**: Choose one of the following options:
	+ Yes: The pipe material is suitable for the drainage system.
	+ No: The pipe material is not suitable for the drainage system.
* **Pipe Size**: Enter the size of the pipes used in the drainage system, if known. This can be a numerical value.
* **Pipe Orientation**: Choose one or both of the following options:
	+ Yes: The pipe orientation is suitable for the drainage system.
	+ No: The pipe orientation is not suitable for the drainage system.
* **Pipe Slope**: Enter the slope of the pipes used in the drainage system, if known. This can be a numerical value.
* **Pipe Grade**: Choose one or both of the following options:
	+ Yes: The pipe grade is suitable for the drainage system.
	+ No: The pipe grade is not suitable for the drainage system.
* **Flow Direction**: Choose one of the following options:
	+ Yes: The flow direction is suitable for the drainage system.
	+ No: The flow direction is not suitable for the drainage system.
* **Water Quality**: Choose one or more of the following options:
	+ Good: The water quality is acceptable for the drainage system.
	+ Poor: The water quality is not acceptable for the drainage system.

## Tips

* Be as accurate as possible when answering each question.
* Remember that some fields are optional, and you can leave them blank if you do not have the necessary information.
* If you are unsure about a particular field, try to make an educated guess or leave a note explaining your uncertainty.
* Save your completed form to reference later or share with others.
