# occasion_gift_bag_feedback - Help Guide
## Purpose
This form is designed to collect feedback on the occasion gift bag provided for an event.

## How To Complete This Form
1. Fill out the form completely, including all required fields.
2. Provide as much detail as possible in the text fields.
3. Select the correct options for the select multiple field (swag_item).
4. Submit the form to provide your feedback.

## Field-by-Field Explanation
* **Event Details** (`event_details`, text, required: false): This field is where you can provide any additional details about the event that you think is relevant to your feedback.
* **name** (`name`, text, required: true): Please enter your name, this will help us ensure that we can follow up with you if needed.
* **swag_item** (`swag_item`, select multiple, required: true): Select all the items that you liked, disliked, or have mixed feelings about from the occasion gift bag. For example, you can select 'Yes' for items you liked, 'No' for items you disliked, or both if you have mixed feelings.
* **Feedback** (`feedback`, text, required: true): Provide any additional feedback about the occasion gift bag, such as what you liked, disliked, or suggestions for improvement.
