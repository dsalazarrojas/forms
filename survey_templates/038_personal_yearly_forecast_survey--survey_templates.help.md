# Personal Yearly Forecast Survey - Help Guide
## Purpose
This form is designed to gather information about your past, current, and future goals, relationships, obstacles, habits, and other relevant aspects of your personal life. This data will be used to generate a personalized yearly forecast for you, providing you with insights and suggestions to achieve your goals and improve your overall well-being.

## How To Complete This Form
To complete this form, simply follow these steps:

1. Answer each question honestly and accurately.
2. Choose the correct options for each field.
3. Make sure to provide your email address so we can send you your forecast.

## Field-by-Field Explanation

* **Past Year** (`past_year`, text, required: false): 
  Please enter the year you are currently in.
* **Goals** (`goals`, select_multiple, required: false): 
  Please select whether you have achieved your goals in the past year. If yes, which ones?
* **Past Relationships** (`past_relationships`, select_one, required: false): 
  Please select whether you have relationships that have ended in the past year. If yes, which ones?
* **Current Relationships** (`current_relationships`, select_multiple, required: false): 
  Please select whether you have any relationships currently. If yes, which ones?
* **Past Goals** (`past_goals`, select_multiple, required: false): 
  Please select whether you have any goals that were achieved in the past year. If yes, which ones?
* **Past Obstacles** (`past_obstacles`, select_multiple, required: false): 
  Please select any obstacles you faced in the past year. If yes, which ones?
* **Next Year** (`next_year`, text, required: false): 
  Please enter the year you are looking forward to. This will be used as the base for your yearly forecast.
* **Next Goals** (`next_goals`, select_multiple, required: false): 
  Please select whether you have any goals for the next year. If yes, which ones?
* **Next Relationships** (`next_relationships`, select_multiple, required: false): 
  Please select whether you expect any relationships to start or end in the next year. If yes, which ones?
* **Next Obstacles** (`next_obstacles`, select_multiple, required: false): 
  Please select any obstacles you expect to face in the next year. If yes, which ones?
* **Self Care** (`self_care`, select_multiple, required: false): 
  Please select any self-care activities you have been doing recently. If yes, which ones?
* **Next Year Goals** (`next_year_goals`, select_multiple, required: false): 
  Please select any goals you have for the next year. If yes, which ones?
* **Current Obstacles** (`current_obstacles`, select_multiple, required: false): 
  Please select any current obstacles you are facing. If yes, which ones?
* **Next Year Obstacles** (`next_year_obstacles`, select_multiple, required: false): 
  Please select any obstacles you expect to face in the next year. If yes, which ones?
* **Past Habits** (`past_habits`, select_multiple, required: false): 
  Please select any habits you have had in the past year. If yes, which ones?
* **Next Habits** (`next_habits`, select_multiple, required: false): 
  Please select any habits you expect to form in the next year. If yes, which ones?
* **Next Year Habits** (`next_year_habits`, select_multiple, required: false): 
  Please select any habits you plan to have in the next year. If yes, which ones?
* **Past** (`past`, date, required: false): 
  Please enter the date your past year started.
* **Past** (`past_date`, date, required: false): 
  Please enter the date your past year ended.
* **Current Date** (`current_date`, date, required: false): 
  Please enter the date your current year started.
* **Next** (`next`, date, required: false): 
  Please enter the date your next year starts.
* **Next Date** (`next_date`, date, required: false): 
  Please enter the date your next year ends.
* **Time** (`time`, time, required: false): 
  Please enter your typical wake-up time.
* **Time** (`next_time`, time, required: false): 
  Please enter your typical wake-up time in the next year.
* **Email** (`email`, email, required: false): 
  Please enter your email address so we can send you your forecast.

Please note that all fields are optional, and you can select as many options as you feel are relevant to you.
