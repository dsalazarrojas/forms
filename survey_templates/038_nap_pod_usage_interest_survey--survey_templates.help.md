# Nap Pod Usage Interest Survey - Help Guide
## Purpose
This form is designed to collect information about your interest in using a Nap Pod. It will help us understand your preferences and needs for using the Nap Pod.

## How To Complete This Form

1. Fill out the form by selecting your answers to each question.
2. You can select multiple options for each question where possible.
3. If you have any other comments or feedback, please use the "Any Other Comments" field.
4. Make sure to provide your email and phone number so we can contact you back.

## Field-by-Field Explanation

* **Survey Template** (`survey_template`, note, not required): This is a note field where you can write any information you'd like to share with us.
* **usage_time_1** (`usage_time_1`, select_one, not required): Select the time of day you are interested in using a Nap Pod.
* **usage_time_2** (`usage_time_2`, select_one, not required): Select the time of day you are interested in using a Nap Pod.
* **usage_time_3** (`usage_time_3`, select_one, not required): Select the time of day you are interested in using a Nap Pod.
* **usage_time_4** (`usage_time_4`, select_one, not required): Select the time of day you are interested in using a Nap Pod.
* **Interested in Nap Pod** (`interested_in_nap_pod`, select_multiple, not required): Check the boxes for the reasons you are interested in using a Nap Pod.
* **Nap Pod Location** (`nap_pod_location`, select_multiple, not required): Check the boxes for the locations you would like to use a Nap Pod.
* **Preferred Time of Day for Nap Pod** (`preferred_time_of_day_for_nap_pod`, select_one, not required): Select the time of day you prefer to use a Nap Pod.
* **Why Do You Want to Use A Nap Pod?** (`why_do_you_want_to_use_a_nap_pod`, select_multiple, not required): Check the boxes for the reasons you want to use a Nap Pod.
* **How Often Do You Want to Use A Nap Pod?** (`how_often_do_you_want_to_use_a_nap_pod`, select_multiple, not required): Check the boxes for how often you want to use a Nap Pod.
* **Any Other Comments** (`any_other_comments`, note, not required): This is a note field where you can write any other comments or feedback you may have.
* **Feedback** (`feedback`, note, not required): This is a note field where you can write any other comments or feedback you may have.
* **Email** (`email`, email, not required): Enter your email address so we can contact you back.
* **Phone** (`phone`, text, not required): Enter your phone number so we can contact you back.
* **Email/Phone** (`email_phone_label`, text, not required): Enter your email and/or phone number so we can contact you back.
* **Other Email/Phone** (`other_email_phone`, text, not required): Enter any other email or phone number you would like us to use to contact you back.
* **How Many Nap Pod Sessions?** (`how_many_nap_pod_sessions`, number, not required): Enter the number of Nap Pod sessions you are interested in using.
* **How Long Do You Want to Use A Nap Pod?** (`how_long_do_you_want_to_use_a_nap_pod`, number, not required): Enter the length of time you want to use a Nap Pod for.
