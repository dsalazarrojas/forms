# Library Resources Feedback Request Form - Help Guide

## Purpose
The Library Resources Feedback Request Form is designed to collect feedback from users about library resources that they have used or plan to use. This form is used to understand the effectiveness of the resources and identify areas for improvement.

## How To Complete This Form
To complete this form, simply follow these steps:

1. Select the resource that you used (Online Resources, Books, Articles, Journals, or Databases).
2. Rate your satisfaction with the resource (Slightly Dissatisfied, Somewhat Satisfied, Somewhat Very Satisfied, Very Satisfied, or Neither Satisfied Nor Dissatisfied).
3. Provide any improvement opportunities or suggestions you have for the resource.
4. If you have any additional comments or feedback, you can type them in the "Comment" field.
5. Enter your email address so we can get in touch with you if needed.
6. If you have any other comments or feedback, you can type them in the "Comment" field.

## Field-by-Field Explanation
* **Feedback On Resources** (`feedback_on_resources`, `text`, optional): Please describe the resource you used or plan to use. For example, "I used the online library's database to find information on <subject>".
* **Resource Used** (`resource_used`, `select_one`, optional): Select the type of resource you used or plan to use (Online Resources, Books, Articles, Journals, or Databases).
* **Resource Satisfaction** (`resource_satisfaction`, `select_multiple`, optional): Rate your overall satisfaction with the resource using the following options: Slightly Dissatisfied, Somewhat Satisfied, Somewhat Very Satisfied, Very Satisfied, or Neither Satisfied Nor Dissatisfied.
* **Improvement Opportunities** (`improvement_opportunities`, `text`, optional): If you have any improvement suggestions, please type them here.
* **Improvement Suggestions** (`resource_improvement`, `text`, optional): Provide any other comments or suggestions you have for the resource.
* **Contact Information** (`contact_information`, `text`, optional): If you have any contact information that you'd like to share, such as your email or phone number.
* **Email Address** (`email_address`, `email`, optional): If you have an email address you'd like to provide, so we can get in touch with you, type it here.
* **Comment** (`comment`, `note`, optional): If you have any other comments or feedback, you can type them in this field.
 
Note: Fields marked as `optional` can be left blank if you do not have any information to provide.
