# pairwise_comparison_survey - Help Guide
## Purpose
This form is designed to collect ratings or preferences for pairs of items. It is intended to be used in a business or research context to gather opinions or ratings on various items, such as products, services, or features.

## How To Complete This Form
To complete this form, follow these steps:

1. Start by filling out the introduction page, which provides a brief overview of the survey.
2. On the item list pages, select the items you want to compare from the provided options.
3. On the item label list pages, select the labels or characteristics that you want to use for the comparison.
4. On the pairwise item list pages, select the pairs of items that you want to compare.
5. On the rating scale pages, provide your ratings or preferences for each pair of items.
6. Make sure to answer all the required fields.

## Field-by-Field Explanation

* **Introduction** (`1`, `text`, required: false): This page provides a brief overview of the survey.
* **Item list** (`2`, `number`, required: false): Select the items you want to compare from the provided options.
* **Item label list** (`4`, `select_multiple`, required: false): Select the labels or characteristics that you want to use for the comparison.
* **Item label list 2** (`5`, `select_one`, required: false): Select one label or characteristic from the options.
* **Rating scale** (`6`, `number`, required: false): Provide your rating or preference for each pair of items.
* **Pairwise item list** (`14`, `number`, required: false): Select the pairs of items that you want to compare.
* **Pairwise item label list** (`16`, `select_multiple`, required: false): Select the labels or characteristics that you want to use for the comparison.
* **Pairwise rating scale** (`18`, `number`, required: false): Provide your rating or preference for each pair of items.
