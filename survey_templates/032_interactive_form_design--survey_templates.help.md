# Interactive Form Design - Help Guide
## Purpose
The form is designed to gather information about an event. Please provide the necessary details to help you set up and track the event.

## How To Complete This Form
1. Click on the "Submit" button to start filling out the form.
2. Each section represents a page, fill out all fields on each page before proceeding to the next.
3. Fill out the required fields (marked as "yes" in the required column below) and provide your answers accordingly.

## Field-by-Field Explanation

* **First Page** (`first_page`, text, yes/optional):
  This is the main page where you'll start filling out the form. Please fill out all the fields on this page to proceed.
* **Event** (`event_details`, number, yes/optional):
  Enter the event's details, e.g., event ID or code.
* **Event Date** (`event_date`, date, yes/optional):
  Select the date of the event in the YYYY-MM-DD format.
* **Event Time** (`event_time`, time, yes/optional):
  Select the time of the event in the 12-hour format (HH:MM).
* **Event Location** (`event_location`, text, yes/optional):
  Enter the location of the event.
