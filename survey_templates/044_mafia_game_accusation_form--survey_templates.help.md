# Mafia Game Accusation Form - Help Guide
## Purpose
The Mafia Game Accusation Form is designed to collect information about accusations made during a game of Mafia.

## How To Complete This Form
To complete the form, follow these steps:

1. Select the Game Host Name from the dropdown menu to identify the host of the game.
2. Choose the Game Host Position from the provided options to indicate the host's role in the game.
3. In the Accused Player Name field, enter the name of the player you are accusing.
4. In the Accusation Details field, provide a clear and concise explanation of your reasons for the accusation.
5. If applicable, select a Game Date to indicate the date of the game session.

## Field-by-Field Explanation
* **Game Host Name (Text, optional)**: Enter the name of the game host.
* **Game Host Position (Select One, required)**: Choose from the provided options to indicate the host's role in the game (Mafia Player 1, Mafia Player 2, or Moderator).
* **Accused Player Name (Text, optional)**: Enter the name of the player you are accusing.
* **Accusation Details (Note, optional)**: Provide a clear and concise explanation of your reasons for the accusation.
* **Game Date (Date, optional)**: Enter the date of the game session if applicable.

## Tips
* Make sure to fill out the form accurately and truthfully.
* Only submit one accusation per player.
* If you have concerns about the game or its host, you can use this form to report them.
