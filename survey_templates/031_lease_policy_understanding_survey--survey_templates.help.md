# lease_policy_understanding_survey - Help Guide
## Purpose
This form is intended to collect information about a lease policy to ensure that both parties understand the terms of the lease agreement.
## How To Complete This Form
This form is divided into several sections, each with its own set of fields. Please complete each section thoroughly, and make sure to fill out all required fields (indicated by a *). You can select multiple options for fields with a "select_multiple" type.

## Field-by-Field Explanation
* **Tenant Name** (`tenant_name`, text, optional): Enter the name of the tenant. This is an optional field but can be useful for identification purposes.
* **Lease Start Date** (`lease_start_date`, date, optional): Enter the start date of the lease agreement. This field can be completed in conjunction with the other "Lease Start Date" field for clarity.
* **Tenants Contact Information** (`tenant_contact_info`, text, optional): Enter any relevant contact information for the tenant, such as phone number or email address.
* **Lease End Date** (`lease_end_date`, date, optional): Enter the end date of the lease agreement. Similar to the "Lease Start Date" field, this can be completed in conjunction with the other "Lease End Date" field.
* **Landlord Name** (`landlord_name`, text, optional): Enter the name of the landlord or property owner.
* **Lease Duration** (`lease_duration`, number, optional): Enter the duration of the lease, if applicable.
* **Rent Frequency** (`rent_frequency`, select_multiple, optional): Select the frequency of rent payments. Options include: Quarterly, Monthly, Bi-Weekly, and Weekly.
* **Notice Period** (`notice_period`, select_one, optional): Select the notice period for terminating the lease. Options include: 30, 60, and 90 days.
* **Notice Frequency** (`notice_frequency`, select_multiple, optional): Select the frequency of notice periods. Options include: 1, 2, and 3.
* **Notice Period 2** (`notice_period_2`, select_one, optional): Select an additional notice period. Options include: 30, 60, and 90 days.
* **Lease Start Date 2** (`lease_start_date_2`, date, optional): Enter a second start date for the lease, if applicable.
* **Lease End Date 2** (`lease_end_date_2`, date, optional): Enter a second end date for the lease, if applicable.

Tips:
- If you're unsure about any information, please contact your landlord or tenant representative for clarification.
- Make sure to review the form carefully before submitting it. 
- If you notice any errors or discrepancies, please correct them before submission.
