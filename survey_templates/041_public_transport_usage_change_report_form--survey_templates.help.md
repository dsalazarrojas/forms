# public_transport_usage_change_report_form - Help Guide
## Purpose
This form is used to collect feedback from public transport users about their usage habits and preferences. It helps administrators or managers to understand how often users take public transport and what improvements they would like to see.

## How To Complete This Form

To complete this form, follow these steps:

1. Choose the category that best describes your public transport usage:
	* Public: This category applies to public transport such as buses, trains, and subways.
	* Private: This category applies to private transport services such as taxis, ride-hailing, or carpooling.
2. Select the mode of travel you prefer:
	* Bus: Select this option if you often use buses.
	* Train: Select this option if you often use trains.
	* Bike: Select this option if you often use bicycles or walk.
3. Indicate how often you use public transport:
	* Often: Select this option if you use public transport frequently.
	* Occasionally: Select this option if you use public transport occasionally.
	* Rarely: Select this option if you rarely use public transport.
4. (Optional) Provide any comments or suggestions for improvement:
	* Enter any comments or suggestions you have about public transport services.
5. Rate your overall experience:
	* Agree: Select this option if you agree with your previous answers.
	* Disagree: Select this option if you disagree with your previous answers.
	* Neutral: Select this option if you have no strong feelings.
6. Provide any additional comments:
	* Enter any additional comments or thoughts you have about public transport services.
7. Enter your contact information:
	* Email: Enter your email address for future contact.
	* Phone Number: Enter your phone number for future contact.
