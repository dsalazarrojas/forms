# Christmas Event Planning Survey - Help Guide

## Purpose
The Christmas Event Planning Survey is a form designed to gather information about your preferences for a Christmas event. This will help us create a tailored and enjoyable celebration that suits your needs and interests.

## How To Complete This Form
To complete this form, simply fill out the required fields and select your preferences for the Christmas event. Make sure to answer the questions thoroughly, as this will help us plan an event that you'll enjoy.

## Field-by-Field Explanation

* **First Name** (`first_name`, text, required): Please enter your first name.
* **Last Name** (`last_name`, text, required): Please enter your last name.
* **Email Address** (`email`, email, required): Enter your email address so we can contact you about the event.
* **Phone Number** (`phone`, text, optional): If you'd like to be contacted, please provide your phone number.
* **What type of Christmas celebration are you interested in?** (`event_type`, select_one, required): Select one of the options:
	+ Corporate holiday party
	+ Family gathering
	+ Community event
	+ Charitable celebration
	+ Friend gathering
	+ Religious service and celebration
	+ Other
* **Ideal Number of Guests** (`ideal_guest_count`, number, required): Please select how many guests you would like to invite.
* **Estimated Budget Range** (`budget_range`, select_one, required): Select one of the options:
	+ Under $500
	+ $500 - $1,000
	+ $1,000 - $2,500
	+ $2,500 - $5,000
	+ Over $5,000
* **Venue Preference** (`venue_preference`, select_one, optional): Select where you'd like to hold the event:
	+ Indoors
	+ Outdoors
	+ Both options
	+ No preference
* **Activities of Interest** (`desired_activities`, select_multiple, required): Select all that apply:
	+ Dining and food
	+ Entertainment
	+ Games and competitions
	+ Gift exchange
	+ Caroling or music
	+ Charity or service
	+ Other
* **Entertainment Preferences** (`entertainment_preferences`, select_one, optional): Select one of the options:
	+ Live music
	+ DJ and dancing
	+ Holiday movies
	+ Comedy show
	+ None needed
	+ Other
* **Preferred Dining Style** (`preferred_dining_style`, select_one, optional): Select one of the options:
	+ Formal sit-down dinner
	+ Buffet
	+ Cocktail party
	+ Casual
	+ Picnic style
* **Dietary Considerations to Plan For** (`dietary_considerations`, select_multiple, optional): Select all that apply:
	+ Vegetarian options
	+ Vegan options
	+ Gluten-free
	+ Nut allergies
	+ Shellfish allergies
	+ Halal
	+ Kosher
* **Preferred Event Date** (`event_date_preference`, select_one, optional): Select one of the options:
	+ Before December 15
	+ December 15-20
	+ December 20-24
	+ December 25
	+ After December 25
	+ Flexible
* **Planning Timeline** (`planning_timeline`, select_one, required): Select one of the options:
	+ Less than 1 month
	+ 1-2 months
	+ 2-3 months
	+ 3+ months
	+ As soon as possible
* **Additional Comments or Special Requests** (`additional_comments`, text, optional): If you have any additional comments or requests, please enter them here.

## Tips
Please fill out the form accurately and completely to help us plan the best event for you. If you have any questions or concerns, feel free to reach out to us.
