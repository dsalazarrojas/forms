# Webinar Setup Checklist - Help Guide
## Purpose
This form is used to collect metadata for setting up webinars. It helps ensure that the webinar setup is completed correctly and accurately.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the URL of the webinar in the `Webinar URL` field.
2. Provide a brief description of the webinar in the `description` field.
3. Select the speaker information for the webinar from the `speaker_info` field.
4. Set the start date and time for the webinar using the `start_date` and `end_time` fields.
5. Select the target audience for the webinar from the `target_audience` field.
6. Provide more details about the target audience in the `target_audience_details` field.
7. Select the type of event for the webinar from the `event_type` field.
8. Select the language of the webinar from the `webinar_language` field.
9. Enter the link to the registration page in the `registration_link` field.
10. Set the dates when registration opens and closes in the `registration_open` and `registration_end` fields.
11. Enter the name of the speaker in the `speaker_name` field.
12. Enter the image of the speaker in the `speaker_image` field.

## Field-by-Field Explanation

* **Webinar URL** (1, text, required: false): Enter the URL of the webinar.
* **Description** (2, text, required: false): Provide a brief description of the webinar.
* **Speaker Info** (3, select multiple, required: false): Select the speaker information for the webinar.
* **Start Date** (4, date, required: false): Set the start date of the webinar.
* **End Time** (5, time, required: false): Set the end time of the webinar.
* **Duration** (6, number, required: false): Select the duration of the webinar.
* **Target Audience** (7, select multiple, required: false): Select the target audience for the webinar.
* **Target Audience Details** (8, text, required: false): Provide more details about the target audience.
* **Event Type** (9, select multiple, required: false): Select the type of event for the webinar.
* **Webinar Language** (10, select multiple, required: false): Select the language of the webinar.
* **Registration Link** (11, text, required: false): Enter the link to the registration page.
* **Registration Open** (12, text, required: false): Set the dates when registration opens.
* **Registration End** (13, date, required: false): Set the dates when registration closes.
* **Speaker Name** (14, text, required: false): Enter the name of the speaker.
* **Speaker Image** (15, text, required: false): Enter the image of the speaker.
