# Juvenile Rehabilitation Attitudes Survey - Help Guide
## Purpose
The Juvenile Rehabilitation Attitudes Survey is designed to gather information from stakeholders about their opinions and attitudes towards juvenile rehabilitation programs. The survey will help identify areas of improvement and inform policy decisions related to juvenile rehabilitation.

## How To Complete This Form
1. Review each page of the form, which includes:
	* Intro page: This page provides an introduction to the survey and its purpose.
	* Demographics page: Select the applicable demographic categories that apply to you.
	* Questions 3-12: Answer the questions regarding rehabilitation approach, services, attitudes, outcomes, environment, support, staff, community involvement, and comments.

## Field-by-Field Explanation

* **1. Intro Page**: An introduction to the survey and its purpose. No data collection will be collected from this page.
* **2. Youth Demographics**: 
	+ Select all that apply:
		- **Yes**
		- **No**: Please indicate which categories of young people you are working with.
* **3. Rehab Program Approach**: 
	+ Select the approach that best describes the rehabilitation program:
		- **Yes**
		- **No**: Please select the approach that best suits your understanding of the program.
* **4. Rehabilitation Services**:
	+ Select all that apply:
		- **Yes**
		- **No**: Please indicate which services your program offers.
* **5. Attitudes Towards Rehabilitation**: 
	+ Select all that apply:
		- **Yes**
		- **No**: Please indicate your attitude towards juvenile rehabilitation as a whole.
* **6. Outcomes of Rehab Program**:
	+ Select all that apply:
		- **Yes**
		- **No**: Please select which outcomes your program strives for.
* **7. Rehab Environment**:
	+ Select all that apply:
		- **Yes**
		- **No**: Please indicate how you perceive the environment of the rehab program.
* **8. Rehab Support**:
	+ Select all that apply:
		- **Yes**
		- **No**: Please indicate which support systems your program has.
* **9. Rehab Staff**:
	+ Select all that apply:
		- **Yes**
		- **No**: Please indicate the qualifications and expertise of your staff.
* **10. Community Involvement**:
	+ Select all that apply:
		- **Yes**
		- **No**: Please indicate how your program involves the community.
* **11. Comments**: Any other comments or suggestions for the program.
* **12. Contact Information**: Please provide any contact information for follow-up or further discussion.

## Tips
- Answer each question according to your personal understanding of the program.
- Be honest and accurate with your responses.
- Please select all that apply for multiple selections.
- If you have any additional comments or suggestions, please use the comments field.
