# Cost Efficiency Progress Survey - Help Guide
## Purpose
This form is designed to collect data on the progress of a project in terms of cost efficiency.

## How To Complete This Form
To complete this form, please follow these steps:
1. Review each page of the form carefully.
2. Fill out the required fields accurately and honestly.
3. For optional fields, use your discretion and fill out the information that you think is relevant.
4. Ensure that the data you enter is consistent with the project's status and actual data.

## Field-by-Field Explanation
### Page 1: Project Name
* **Project Name** (`Project Name`, `text`, required): Enter the name of the project.

### Page 2: Project Start Date
* **Project Start Date** (`Project Start Date`, `date`, required): Enter the start date of the project.

### Page 3: Project End Date
* **Project End Date** (`Project End Date`, `date`, required): Enter the end date of the project.

### Page 4: Project Duration
* **Project Duration** (`Project Duration`, `number`, required): Enter the duration of the project in days.

### Page 5: Project Type
* **Project Type** (`Project Type`, `select_one`, optional): Select 'True' if the project is a type of project that is relevant to this survey.

### Page 6: Project Status
* **Project Status** (`Project Status`, `select_one`, optional): Select 'Active' if the project is active, 'Inactive' otherwise.

### Page 7: Cost Efficiency Score
* **Cost Efficiency Score** (`Cost Efficiency Score`, `number`, required): Enter the cost efficiency score of the project.

### Page 8: Time Period
* **Time Period** (`Time Period`, `time`, required): Enter the time period for which the cost efficiency score is valid.

### Page 9: Cost Center
* **Cost Center** (`Cost Center`, `select_one`, optional): Select 'True' if the project has a cost center.

### Page 10: Cost
* **Cost** (`Cost`, `number`, required): Enter the cost of the project.

### Page 11: Efficiency
* **Efficiency** (`Efficiency`, `select_multiple`, optional): Select 'True' if the project has efficiency.

### Page 12: Additional Comments
* **Additional Comments** (`Additional Comments`, `note`, required): Enter any additional comments about the project.

### Page 13: Project Manager
* **Project Manager** (`Project Manager`, `select_one`, optional): Select 'True' if the project is managed by a project manager.

### Page 14: Project Team
* **Project Team** (`Project Team`, `select_multiple`, optional): Select 'True' if the project team is involved.

### Page 15: Project Location
* **Project Location** (`Project Location`, `select_one`, optional): Select 'True' if the project is located.

### Page 16: Page 16
* **Page 16** (`Page 16`, `number`, required): Enter the page number 16.

### Page 17: Time
* **Time** (`Time`, `time`, required): Enter the time of the project.

### Page 18: Project End
* **Project End** (`Project End`, `date`, required): Enter the end date of the project.

Tips:
* Ensure that you fill out the form accurately and honestly.
* If you have any doubts or concerns about the form, please refer to the project manager or the system administrator for guidance.
