# Event Planning Survey - Help Guide
## Purpose
The Event Planning Survey is designed to collect essential information about an event, including the event title, details, date, time, location, number of guests, budget, and any additional notes. This guide will walk you through each field of the survey and help you fill it out correctly.

## How To Complete This Form
To complete this form, simply fill out each field with the requested information. You can enter your text responses in the text fields (event_details, event_location, and event_note), select a date and time for the event in the event_date and event_time fields, and input the number of guests you expect to attend in the event_guests field. If a field is not required, you can leave it blank if you don't have the information or prefer not to provide it.

## Field-by-Field Explanation
* **event_details** (`event_details`, `text`, optional): This field is for any additional details about the event. Please enter a brief description of the event.
* **event_date** (`event_date`, `date`, optional): Select the date of the event.
* **event_time** (`event_time`, `time`, optional): Select the time of the event.
* **event_location** (`event_location`, `text`, optional): Enter the location of the event.
* **event_guests** (`event_guests`, `number`, optional): Input the expected number of guests.
* **event_budget** (`event_budget`, `text`, optional): Enter any additional information about the event budget.
* **event_note** (`event_note`, `note`, optional): Enter any additional notes or comments about the event.
