# quarterly_capa_trend_analysis_survey - Help Guide
## Purpose
The quarterly CAPA trend analysis survey is designed to gather information about the frequency, impact, and actions taken to address Corrective and Preventative Actions (CAPAs) within the organization. This data will help in identifying trends and patterns in the CAPA process and inform future improvements.

## How To Complete This Form
To complete this form, follow these steps:

1. Read each question carefully and answer accordingly.
2. Select the most accurate option for each question.
3. Provide detailed answers where necessary.
4. Submit the form once you have completed all the questions.

## Field-by-Field Explanation

* **Which department are you in**: This question is used to identify the department responding to the survey.
	+ Select 'Yes' if you are responding on behalf of your department.
	+ Select 'No' if you are not responding on behalf of your department.
* **CAPA Category**: This question is used to identify the type of CAPA you are familiar with.
	+ Select 'Yes' if you are familiar with the CAPA category.
	+ Select 'No' if you are not familiar with the CAPA category.
* **How often do you encounter CAPAs**: This question is used to gauge the frequency of CAPAs within your department.
	+ Select 'Yes' if you encounter CAPAs frequently.
	+ Select 'No' if you do not encounter CAPAs frequently.
* **Trend**: This question is used to determine if you perceive a trend in CAPAs within your department.
	+ Select 'Yes' if you see a trend in CAPAs.
	+ Select 'No' if you do not see a trend in CAPAs.
* **Impact**: This question is used to evaluate the impact of CAPAs on your department.
	+ Select 'Yes' if CAPAs have had an impact on your department.
	+ Select 'No' if CAPAs have not had an impact on your department.
* **Action Item**: This question is used to identify if you have taken any action items related to CAPAs.
	+ Select 'Yes' if you have taken action items.
	+ Select 'No' if you have not taken action items.
* **Action Item Status**: This question is used to determine the status of the action item.
	+ Select 'Active' if the action item is active.
	+ Select 'Inactive' if the action item is inactive.
* **Resolution**: This question is used to evaluate the resolution of the action item.
	+ Select 'Yes' if the action item has been resolved.
	+ Select 'No' if the action item has not been resolved.
* **Root Cause**: This question is used to identify the root cause of the CAPA.
	+ Select 'Yes' if you have identified the root cause.
	+ Select 'No' if you have not identified the root cause.
* **Preventive Action**: This question is used to identify if you have taken any preventive actions related to CAPAs.
	+ Select 'Yes' if you have taken preventive actions.
	+ Select 'No' if you have not taken preventive actions.
* **Follow-up**: This question is used to determine if you have followed up on the action item.
	+ Select 'Yes' if you have followed up on the action item.
	+ Select 'No' if you have not followed up on the action item.
* **Comments**: This question is used to provide any additional comments or feedback on the CAPA process.
* **Additional Comments**: This question is used to provide any additional comments or feedback on the CAPA process.
* **Submit**: This is the final step to submit the form. Please ensure you have answered all questions carefully before submitting.
* **Date Submitted**: This question is used to record the date and time the form was submitted.
* **Time Submitted**: This question is used to record the time the form was submitted.
* **Email**: This question is used to collect your email address for any further contact.
* **Phone**: This question is used to collect your phone number for any further contact.
* **Location**: This question is used to collect your location for any further contact.

Please note that the form fields are designed to be self-explanatory, but if you have any questions or concerns, please do not hesitate to contact us.
