# Resource Allocation Survey - Help Guide
## Purpose
The Resource Allocation Survey is used by project managers to report on resource allocation decisions made within their project. This information is used to track and analyze resource allocation trends across projects.

## How To Complete This Form
To complete this form, follow these steps:

1.  Click on the "Resource Allocation Survey" form.
2.  Select the "Project Manager" field and choose the correct project manager from the dropdown list.
3.  Select the "Resource Type" field and choose the type of resource being allocated.
4.  Select the "Allocation Method" field and choose the method used to allocate the resource.
5.  Enter the "Resource Quantity" field with the actual quantity of resources allocated.
6.  Add any additional notes in the "Notes" field.
7.  Enter the "Contact Email" and "Contact Phone" fields with the contact information for the project manager.
8.  Select the "Assigned To" field and choose the team member or department to whom the resource is allocated.

## Field-by-Field Explanation
*   **Resource Allocation** (id: 1):
    This field should be filled in with a brief description of the resource being allocated.
*   **Project Manager** (id: 2):
    Select the project manager who made the resource allocation decision.
*   **Resource Type** (id: 3):
    Choose the type of resource being allocated (e.g., personnel, equipment, etc.).
*   **Allocation Method** (id: 4):
    Select the method used to allocate the resource (e.g., manual, automated, etc.).
*   **Resource Quantity** (id: 5):
    Enter the actual quantity of resources allocated.
*   **Notes** (id: 6):
    Add any additional comments or notes about the resource allocation.
*   **Contact Email** (id: 7):
    Enter the email address of the project manager who made the resource allocation decision.
*   **Contact Phone** (id: 8):
    Enter the phone number of the project manager who made the resource allocation decision.
*   **Assigned To** (id: 9):
    Select the team member or department to whom the resource is allocated.
