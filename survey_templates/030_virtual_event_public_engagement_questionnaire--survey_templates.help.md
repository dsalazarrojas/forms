# Virtual Event Public Engagement Questionnaire - Help Guide

## Purpose
The Virtual Event Public Engagement Questionnaire is designed to collect feedback and evaluations from attendees of virtual events, aiming to improve the quality of the sessions and overall attendee experience.

## How To Complete This Form

1.  Please select the type of session you attended from the provided options (Online Session or In-Person Session).
2.  Enter the length of the session you attended.
3.  Choose the date of the session (if not already filled in).
4.  Select the time of the session (if not already filled in).
5.  Enter the topic of the session.
6.  Choose the number of attendees in your session.
7.  Select the type of feedback you want to provide (Technical Issues, Content Quality, Engagement, or Other).
8.  Enter any additional comments about the session.
9.  If applicable, provide session evaluations and likes/dislikes, with comments if desired.

## Field-by-Field Explanation

*   **Session Type**: This field is used to select the type of session you attended. Please choose either "Online Session" or "In-Person Session".
*   **Session Length**: Enter the length of the session you attended in minutes. This will help us understand how long the session lasted.
*   **Session Date**: Enter the date of the session you attended. This will help us track sessions over time.
*   **Session Time**: Enter the time of the session you attended. If you're unsure, don't worry about this field and move on to the next one.
*   **Session Topic**: Describe the topic of the session you attended. This will help us understand the subject matter covered.
*   **Session Attendees**: Choose the number of attendees in your session from the provided options (1-5, 6-10, 11-20, 21-50, 51 or more).
*   **Feedback Type**: Choose the type of feedback you want to provide. This could be Technical Issues, Content Quality, Engagement, or Other.
*   **Feedback Comments**: If you selected "Other" for Feedback Type, provide more details about your feedback in this field.
*   **Session Evaluations**: If applicable, enter a numerical value to rate the session from 1 to 10.
*   **Session Likes**: If applicable, enter a numerical value to rate how much you liked the session from 1 to 10.
*   **Session Dislikes**: If applicable, enter a numerical value to rate how much you disliked the session from 1 to 10.
*   **Session Likes Comments**: If you selected a high score for "Session Likes", provide more details about what made you like the session in this field.
*   **Session Dislikes Comments**: If you selected a low score for "Session Dislikes", provide more details about what made you dislike the session in this field.

## Tips

*   Please be as specific as possible when answering the questions.
*   If you have any issues with the session, provide as much detail as you can to help us improve.
*   If you have suggestions for improving future sessions, feel free to mention them in the "Feedback Comments" field.
