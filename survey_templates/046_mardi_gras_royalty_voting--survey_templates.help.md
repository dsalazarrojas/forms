# Mardi Gras Royalty Voting - Help Guide
## Purpose
This form is used to collect votes for the Mardi Gras Royalty positions: King, Queen, Duke, and Duchess. 

## How To Complete This Form
To complete this form, follow these steps:

1. Select the Krewes and event committees you are affiliated with (optional).
2. Choose the candidates for each position you would like to vote for (optional).
3. Cast your vote for each position by selecting the corresponding candidate (optional).

## Field-by-Field Explanation

* **Krewes and event committees** (`krewes_and_event_committees`, text, not required): Please enter the name of the krewes and event committees you are affiliated with.
* **Krewes** (`krewes`, select_multiple, not required): Select the Krewes you are associated with.
* **Event committees** (`event_committees`, select_multiple, not required): Select the event committees you are associated with.
* **Candidates for king** (`candidates_for_king`, select_multiple, not required): Select the candidate you would like to vote for as king.
* **Vote for king** (`vote_for_king`, select_multiple, not required): Select the candidate you would like to vote for as king.
* **Vote for queen** (`vote_for_queen`, select_multiple, not required): Select the candidate you would like to vote for as queen.
* **Vote for duke** (`vote_for_duke`, select_multiple, not required): Select the candidate you would like to vote for as duke.
* **Vote for duchess** (`vote_for_duchess`, select_multiple, not required): Select the candidate you would like to vote for as duchess.

## Tips
* Please ensure that you only select one candidate for each position.
* You can select more than one krewes and event committees, but you can only select one candidate for each position.
