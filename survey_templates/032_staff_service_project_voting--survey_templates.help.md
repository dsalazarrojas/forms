# staff-service-project-voting - Help Guide
## Purpose
This form is used to collect feedback and ratings from staff members on service project ideas.

## How To Complete This Form
1. Select the service project ideas that you have participated in or considered participating in.
2. Rate each project idea on a scale of 1-5.
3. Select up to 2 options for each project idea.
4. Enter any additional feedback or comments about each project idea.
5. Complete all fields for each page.

## Field-by-Field Explanation

* **Service Project Ideas (1)** (`service_project_ideas`, text, optional): Enter any service project ideas that you have participated in or considered participating in.
* **Ratings (2)** (`ratings`, number, optional): Rate each project idea on a scale of 1-5.
* **Rating Question (3)** (`rating_question`, text, optional): Enter your feedback question for each project.
* **Votes (4)** (`votes`, select_multiple, optional): Select up to 2 options for each project.
* **Ratings Choices (5)** (`ratings_choices`, select_one, optional): Select 1 option for each project.
