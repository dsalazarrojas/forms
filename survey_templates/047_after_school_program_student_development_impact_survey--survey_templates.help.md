# After School Program Student Development Impact Survey - Help Guide
## Purpose
The After School Program Student Development Impact Survey is a comprehensive tool designed to assess the impact of an after-school program on student development. It is intended to help parents or guardians provide feedback on their child's progress and experiences in the program.

## How To Complete This Form
To complete this form, please follow these steps:

1. Review each section and question carefully to understand what is being asked.
2. Answer each question honestly and to the best of your ability.
3. Be as specific as possible when providing feedback and examples.
4. Use the provided options to select the best answer for each question.

## Field-by-Field Explanation

* **Student Full Name** (`student_full_name`, text, required): Enter the student's complete legal name.
* **Current Grade Level** (`student_grade_level`, select_one, true): Select the student's current grade level from the options provided.
* **Student Age** (`student_age`, number, true): Enter the student's current age.
* **Program Participation Duration** (`program_participation_duration`, select_one, true): Select how long the student has been participating in the program.
* **Program Name** (`program_name`, text, true): Enter the name of the after-school program.
* **Parent/Guardian Name** (`parent_guardian_name`, text, true): Enter your name as the parent or guardian completing this survey.
* **Relationship to Student** (`parent_guardian_relationship`, select_one, true): Select your relationship to the student.
* **Homework Completion Improvement** (`homework_completion_improvement`, select_one, true): Select how the student's homework completion has improved since joining the program.
* **Academic Confidence Level** (`academic_confidence_level`, select_one, true): Select how the student's confidence in academic abilities has changed.
* **Subject Improvement Areas** (`subject_improvement_areas`, select_multiple, true): Select the subjects where the student has shown the most improvement.
* **Study Habit Development** (`study_habit_development`, select_one, true): Select if the student has developed better study habits since joining the program.
* **Peer Relationship Improvement** (`peer_relationship_improvement`, select_one, true): Select if the student's ability to interact with peers has improved.
* **Self-Confidence Level** (`self_confidence_level`, select_one, true): Select how the student's overall self-confidence has changed.
* **Conflict Resolution Skills** (`conflict_resolution_skills`, select_one, true): Select if the student's ability to resolve conflicts has improved.
* **Emotional Regulation Improvement** (`emotional_regulation_improvement`, select_one, true): Select if the student's ability to manage emotions has improved.
* **Classroom Behavior Improvement** (`classroom_behavior_improvement`, select_one, true): Select if the student's behavior in regular classes has improved.
* **Following Directions Ability** (`following_directions_ability`, select_one, true): Select if the student's ability to follow directions has improved.
* **Participation Level Increase** (`participation_level_increase`, select_one, true): Select if the student's participation in class activities has increased.
* **Overall Program Satisfaction** (`overall_program_satisfaction`, number, true): Rate your satisfaction with the after-school program overall.
* **Staff Quality Rating** (`staff_quality_rating`, number, true): Rate the quality of the program staff.
* **Program Safety Rating** (`program_safety_rating`, number, true): Rate the safety of the program environment.
* **Communication with Parents** (`communication_with_parents`, number, true): Rate your satisfaction with communication from program staff.
* **Leadership Skill Development** (`leadership_skill_development`, select_one, true): Select if the student has developed leadership skills through the program.
* **Creativity Development** (`creativity_development`, select_one, true): Select if the student's creativity has improved through the program.
* **Technology Skill Development** (`technology_skill_development`, select_one, true): Select if the student has developed technology skills through the program.
* **Additional Comments** (`additional_comments_section`, note, false): Provide any additional comments or feedback about the program.
* **Positive Changes Observed** (`positive_changes_observed`, text, false): Describe any positive changes you have observed in the student since joining the program.
* **Program Improvement Suggestions** (`program_improvement_suggestions`, text, false): Provide any suggestions for improving the program.
* **Continued Participation Likelihood** (`continued_participation_likelihood`, number, true): Rate how likely you are to continue participating in this program.

## Tips

* Be honest and specific when providing feedback.
* Use examples to support your answers.
* If you are unsure about any question, please select "No Change" or "No Development" accordingly.
* If you have any additional comments or suggestions, please use the "Additional Comments" section.
