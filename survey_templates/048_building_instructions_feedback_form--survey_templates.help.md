# Building Instructions Feedback Form - Help Guide

## Purpose
The Building Instructions Feedback Form is a survey designed to gather feedback from users on the clarity, completeness, accuracy, and overall effectiveness of building instructions. This form helps us understand the strengths and weaknesses of our instructions and identify areas for improvement. Your feedback will help us create better instructions that are easy to follow and understand.

## How To Complete This Form
To provide your feedback, simply fill out the form with the requested information. You can access the form through [insert link or portal URL].

## Field-by-Field Explanation
Please find explanations for each field below:

* **Your Name** (`respondent_name`, `text`, optional): Please provide your full name.
* **Department** (`department`, `text`, required): Please select the department or team you belong to.
* **Your Role** (`role`, `text`, required): Please select your job title or role.
* **Email Address** (`email`, `email`, required): Please provide your contact email address.
* **Feedback Date** (`feedback_date`, `date`, required): Please select the date of your feedback.
* **Project Name** (`project_name`, `text`, required): Please provide the name of the project.
* **Instruction Type** (`instruction_type`, `select_one`, required): Please select the type of instructions you are providing feedback on.
	+ Operating Instructions
	+ Assembly Instructions
	+ Safety Instructions
	+ Maintenance Instructions
	+ Installation Instructions
	+ User Manual
	+ Standard Operating Procedure
	+ Other
* **Instruction Title** (`instruction_title`, `text`, required): Please provide a title for the instructions.
* **Usage Frequency** (`usage_frequency`, `select_one`, required): Please select how often you use these instructions.
	+ Daily
	+ Weekly
	+ Monthly
	+ Occasionally
	+ First Time
* **Clarity Rating** (`clarity_rating`, `select_one`, required): Please rate how clear the instructions are.
	+ Very Clear
	+ Clear
	+ Somewhat Clear
	+ Unclear
	+ Very Unclear
* **Completeness Rating** (`completeness_rating`, `select_one`, required): Please rate how complete the instructions are.
	+ Very Complete
	+ Complete
	+ Somewhat Complete
	+ Incomplete
	+ Very Incomplete
* **Accuracy Rating** (`accuracy_rating`, `select_one`, required): Please rate how accurate the instructions are.
	+ Very Accurate
	+ Accurate
	+ Somewhat Accurate
	+ Inaccurate
	+ Very Inaccurate
* **Ease of Use** (`ease_of_use`, `select_one`, required): Please rate how easy to follow the instructions are.
	+ Very Easy
	+ Easy
	+ Moderate
	+ Difficult
	+ Very Difficult
* **Visual Aids Quality** (`visual_aids`, `select_one`, required): Please rate the quality of diagrams and images.
	+ Excellent
	+ Good
	+ Average
	+ Poor
	+ Very Poor
	+ Not Applicable
* **Formatting Rating** (`formatting_rating`, `select_one`, required): Please rate the layout and organization.
	+ Excellent
	+ Good
	+ Average
	+ Poor
	+ Very Poor
* **Terminology Clarity** (`terminology_clarity`, `select_one`, required): Please rate the appropriateness of language used.
	+ Very Appropriate
	+ Appropriate
	+ Somewhat Appropriate
	+ Inappropriate
	+ Very Inappropriate
* **Missing Information** (`missing_information`, `text`, optional): If you think any information is missing, please specify.
* **Confusing Sections** (`confusing_sections`, `text`, optional): If you find any sections unclear, please describe.
* **Errors Found** (`errors_found`, `select_one`, required): Please select the level of errors found in the instructions.
	+ No Errors
	+ Minor Typos
	+ Some Factual Errors
	+ Significant Errors
	+ Many Errors
* **Error Description** (`error_description`, `text`, optional): If you have found errors, please describe them.
* **Safety Warnings** (`safety_warnings`, `select_one`, required): Please rate the adequacy of safety notices.
	+ Very Adequate
	+ Adequate
	+ Somewhat Adequate
	+ Inadequate
	+ Very Inadequate
	+ Not Applicable
* **Would Recommend** (`would_recommend`, `select_one`, required): Would you recommend these instructions to others?
	+ Definitely Yes
	+ Probably Yes
	+ Maybe
	+ Probably No
	+ Definitely No
* **Suggestions for Improvement** (`improvement_suggestions`, `text`, optional): Please provide any suggestions you have for improvement.
* **Overall Rating** (`overall_rating`, `select_one`, required): Please rate your overall assessment.
	+ Excellent
	+ Good
	+ Average
	+ Poor
	+ Very Poor
* **Additional Comments** (`additional_comments`, `text`, optional): If you have any other feedback, please share.

## Tips
* Please answer all required fields.
* Provide specific examples or descriptions where possible.
* Take as much time as you need to complete the form.
* If you have any questions or concerns, please contact us at [form@gic.mx](mailto:form@gic.mx).
