# Web Application Features Survey - Help Guide
## Purpose
This form is designed to collect feedback on the features of our web application. Your input will help us understand which features are important to you and which ones need improvement.

## How To Complete This Form
1. Click on the "Submit" button to start.
2. Select the options for each question from the dropdown menu or type in your answer in the text field.
3. Make sure to answer all the questions before submitting the form.
4. If you'd like to provide additional feedback, feel free to share your thoughts in the "New Feature Improvement Ideas" field.

## Field-by-Field Explanation
### Feature Importance
* **Feature Importance**: Select how important you think each feature is to our web application.
	+ Select "Very Important" if you think the feature is essential to our web application.
	+ Select "Not Important" if you don't think the feature is necessary.
* **Very Important**
* **Not Important**

### New Ideas
* **New Ideas**: If you have any new ideas for features or improvements to existing features, share them here.

### Satisfaction
* **Satisfaction**: Select how satisfied you are with the current state of a feature.
	+ Select "Very Important" if you're extremely satisfied.
	+ Select "Important" if you're somewhat satisfied.
	+ Select "Neutral" if you're neutral about the feature.
	+ Select "Not Important" if you're somewhat dissatisfied.
	+ Select "Not At All Important" if you're extremely dissatisfied.

### New Feature Requests
* **New Feature Requests**: If you have ideas for new features, list them here.

### New Feature Improvement Ideas
* **New Feature Improvement Ideas**: If you have ideas for improving existing features, share them here.

### Feature Satisfaction
* **Feature Satisfaction**: Please type in a number between 1 and 5 to indicate how satisfied you are with the current state of a feature.
	+ 1 (Not At All Important)
	+ 2 (Not Important)
	+ 3 (Neutral)
	+ 4 (Important)
	+ 5 (Very Important)

## Tips
* Please answer all questions as honestly as possible.
* You can submit this form multiple times with different answers.
* If you're not sure about a feature, please don't hesitate to ask us for clarification.
* Your input will be kept confidential and will not be shared without your permission.
