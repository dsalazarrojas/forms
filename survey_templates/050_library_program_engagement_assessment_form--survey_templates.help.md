# Library Program Engagement Assessment Form - Help Guide

## Purpose
This form is designed to help library administrators assess the engagement level of library programs and events.

## How To Complete This Form
- This form consists of 10 sections, each representing a different aspect of library programs.
- Please answer each field as accurately and completely as possible.
- If you are unsure about the meaning of a field, consult the explanations below.

## Field-by-Field Explanation

### 1. **Event Participation** (`event_participation`, `number`, optional)
Event participation is a measure of how often you have attended library events in the past year.
Please answer with the number of times you have attended.

### 2. **Satisfaction Level** (`satisfaction_level`, `select_one`, optional)
Please rate the overall satisfaction level of library events. Choose one of the following options:
- **Excellent**
- **Good**
- **Fair**
- **Poor**

### 3. **Attendance Frequency** (`attendance_frequency`, `number`, optional)
Please indicate how often you attend library events per month.
 Answer with the number of times you visit the library in a month.

### 4. **Recommended to Others** (`recommendation_level`, `select_multiple`, optional)
Please mark if you have recommended library events to others.
Select all that apply:
- **True**
- **False**

### 5. **Event Length** (`event_length`, `time`, optional)
Please report the average length of library events in minutes.
(Note: This field will be used to calculate the average duration of events.)

### 6. **Event Date** (`event_date`, `date`, optional)
Please provide the date of the most recent library event you attended.
(Note: This field will be used to analyze the timing of events.)

### 7. **Staff Attention** (`staff_attention`, `select_one`, optional)
Please rate the quality of staff attention provided during library events.
Choose one of the following options:
- **Very Good**
- **Good**
- **Fair**
- **Poor**

### 8. **Event Location** (`event_location`, `select_one`, optional)
Please indicate if the library events take place at the library or elsewhere.
Select one of the following:
- **True**
- **False**

### 9. **Overall Satisfaction** (`overall_satisfaction`, `select_one`, optional)
Please rate your overall satisfaction with library services.
Choose one of the following options:
- **Excellent**
- **Good**
- **Fair**
- **Poor**

### 10. **Comments** (`comments`, `note`, optional)
Please use this section to provide any additional comments or suggestions for library program improvement.
(Note: This is an open-ended field for general comments.)

## Tips
- Answer honestly and accurately to provide valuable feedback.
- If you have any questions or concerns, contact library staff for assistance.
- Your input will help shape the future of library programs and services!
