# shipping_process_feedback_survey - Help Guide
## Purpose
The purpose of this form is to collect feedback about the shipping process from customers. The feedback will help us identify areas of improvement and make informed decisions about the shipping process.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the "shipping_process" option to indicate if the shipping process was satisfactory or not.
2. Enter the date of the shipment in the "shipping_date" field.
3. Enter the time of the shipment in the "shipping_time" field.
4. Select the "shipping_rate" option to indicate the rate of the shipment.
5. Provide any additional comments about the shipping process in the "comments" field.
6. Select the "shipping_company" option to indicate if the shipping company was used for the shipment.
7. Select the "shipping_service" option to indicate if the shipping service was satisfactory or not.
8. Enter the shipping address in the "shipping_address" field.
9. Enter the contact email in the "contact_email" field.
10. Enter the contact phone number in the "contact_phone" field.
11. Select the "assigned_agent" option to indicate if an agent was assigned to the shipment.
12. Provide any additional comments about the assigned agent in the "assigned_agent_comment" field.
13. Select the "shipping_status" option to indicate the current status of the shipment.

## Field-by-Field Explanation

* **shipping_process** (Select One): This field indicates if the shipping process was satisfactory or not. Select "Yes" if the process was satisfactory, and "No" if it was not.
* **shipping_date** (Date): Enter the date of the shipment.
* **shipping_time** (Time): Enter the time of the shipment.
* **shipping_rate** (Number): Select the rate of the shipment.
* **comments** (Note): Provide any additional comments about the shipping process.
* **shipping_company** (Select One): This field indicates if the shipping company was used for the shipment. Select "Yes" if the company was used, and "No" if it was not.
* **shipping_service** (Select One): This field indicates if the shipping service was satisfactory or not. Select "Yes" if it was satisfactory, and "No" if it was not.
* **shipping_address** (Text): Enter the shipping address.
* **contact_email** (Email): Enter the contact email.
* **contact_phone** (Text): Enter the contact phone number.
* **assigned_agent** (Select One): This field indicates if an agent was assigned to the shipment. Select "Yes" if an agent was assigned, and "No" if it was not.
* **assigned_agent_comment** (Note): Provide any additional comments about the assigned agent.
* **shipping_status** (Select One): This field indicates the current status of the shipment. Select "Active" if the shipment is active, and "Inactive" if it is not.
