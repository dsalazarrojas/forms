# language_practice_survey - Help Guide
## Purpose
This form is designed to collect information about language practice habits and preferences from individuals.

## How To Complete This Form

To complete this form, follow these steps:

1. Answer the questions on each page to provide as much detail as possible.
2. Make sure to fill out all required fields, indicated by an asterisk (*) in the label.
3. If a field is optional, feel free to answer it if it's relevant to your language learning process.

## Field-by-Field Explanation

* **Language Learning Habits** (`survey_questions`, text, required): Describe your typical language learning activities.
* **Progress Tracking Method** (`progress_tracking`, select_one, required): Choose the method you use to keep track of your progress:
	+ Calendar or planner
	+ Mobile app
	+ Paper notebook
	+ Other (please specify)
* **Helpful Language Programs or Resources** (`helpful_resources`, select_multiple, required): Select the resources you've found most helpful for language learning:
	+ Language exchange websites (e.g., language exchange websites)
	+ Language learning apps (e.g., Duolingo, Babbel)
	+ Language learning podcasts (e.g., 6 Minute Russian)
	+ Language learning YouTube channels (e.g., English Class 101)
	+ Other (please specify)
* **Received Support** (`received_support`, checkbox, required): Check if you've ever received support from a language teacher or tutor:
	+ Option A
	+ Option B
* **Note Taking Method** (`note_taking`, select_one, optional): Choose how you take notes during language learning sessions:
	+ Using a notebook or paper
	+ Using a digital note-taking app
	+ Recording audio or video
	+ Not taking notes at all
* **Practice Frequency** (`practice_frequency`, number, required): Indicate how often you practice writing or speaking a language:
* **Output File** (`output_file`, text, optional): Specify the name of an existing output file for this survey.
* **Category Name** (`category_name`, text, optional): Enter the category for this survey.
* **Description** (`description`, text, optional): Briefly describe the purpose of the survey.
* **Form IDs** (`form_ids`, text, optional): Enter form IDs for this survey.
* **Assigned Tool** (`assigned_tool`, text, optional): Specify the language learning tool assigned for this survey.
* **Category** (`category`, select_one, required): Select the category for this survey:
	+ Survey Templates
	+ Education Surveys
	+ Other

## Tips

* Be honest and accurate when answering the questions to ensure the form provides useful insights.
* If you're unsure about a particular field, try your best to provide a reasonable answer.
* If you have any questions or need assistance with this form, please contact your supervisor or survey administrator.
