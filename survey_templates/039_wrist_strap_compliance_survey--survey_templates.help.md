# Wrist Strap Compliance Survey - Help Guide

## Purpose
The Wrist Strap Compliance Survey is used to collect information from users about their wrist strap testing frequency, location, and other relevant details. The survey helps to understand how users are complying with ESD (ElectroStatic Discharge) and Non-ESD testing protocols.

## How To Complete This Form
To complete this form, follow the instructions below:

1. Select the Manufacturing Team involved in the testing process.
2. Enter the last date the ESD Wrist Strap was used or last date the Non-ESD Wrist Strap was used.
3. Choose the testing location (e.g., Location 1, Location 2, Location 3, or Other).
4. Enter the name of the supervisor who oversaw the testing process.
5. Enter any comments or notes about the testing process.

## Field-by-Field Explanation

* **Manufacturing Team** (id: 1): Select all the manufacturing teams involved in the testing process.
	+ Options: ESD Wrist Strap, Non-ESD Wrist Strap, Glove Box, Test Box, Other
	+ Required: No
* **ESD Wrist Strap Use** (id: 2): Enter the last date the ESD Wrist Strap was used.
	+ Type: Date
	+ Required: No
* **Testing Location** (id: 3): Choose the location where the testing took place.
	+ Options: Location 1, Location 2, Location 3, Other
	+ Required: No
* **Testing Supervisor** (id: 4): Enter the name of the supervisor who oversaw the testing process.
	+ Type: Text
	+ Required: No
* **Review Supervisor** (id: 5): Enter the name of the supervisor who reviewed the testing process.
	+ Type: Text
	+ Required: No
* **ESD Testing Frequency** (id: 6): Enter the frequency of ESD testing.
	+ Type: Number
	+ Required: No
* **Non-ESD Testing Frequency** (id: 7): Enter the frequency of Non-ESD testing.
	+ Type: Number
	+ Required: No
* **Safety Check** (id: 8): Indicate whether the testing process was safe.
	+ Options: True, False
	+ Required: No
* **ESD Wrist Strap Use Frequency** (id: 9): Enter the frequency of using ESD Wrist Strap.
	+ Type: Number
	+ Required: No
* **Non-ESD Wrist Strap Use Frequency** (id: 10): Enter the frequency of using Non-ESD Wrist Strap.
	+ Type: Number
	+ Required: No
* **Comments** (id: 11): Enter any comments about the testing process.
	+ Type: Text
	+ Required: No
* **Notes** (id: 12): Enter any additional notes about the testing process.
	+ Type: Text
	+ Required: No
* **ESD Testing Supervisor** (id: 13): Enter the name of the supervisor who conducted ESD testing.
	+ Type: Text
	+ Required: No
* **ESD Wrist Strap Testing Supervisor** (id: 14): Enter the name of the supervisor who tested ESD Wrist Strap.
	+ Type: Text
	+ Required: No
* **ESD Testing Review Supervisor** (id: 15): Enter the name of the supervisor who reviewed ESD testing.
	+ Type: Text
	+ Required: No
* **ESD Testing Frequency** (id: 16): Enter the frequency of ESD testing.
	+ Type: Number
	+ Required: No
* **ESD Testing Location** (id: 17): Choose the location where ESD testing took place.
	+ Options: Location 1, Location 2, Location 3, Other
	+ Required: No
* **Non-ESD Testing Location** (id: 18): Choose the location where Non-ESD testing took place.
	+ Options: Location 1, Location 2, Location 3, Other

* **Non-ESD Testing Review Supervisor** (id: 19): Enter the name of the supervisor who reviewed Non-ESD testing.
	+ Type: Text
	+ Required: No
* **ESD Wrist Strap Testing Supervisor** (id: 20): Enter the name of the supervisor who tested ESD Wrist Strap.
	+ Type: Text

* **ESD Testing Notes** (id: 21): Enter any notes about ESD testing.
	+ Type: Text

* **Non-ESD Testing Notes** (id: 22): Enter any notes about Non-ESD testing.
	+ Type: Text
	+ Required: No
* **ESD Wrist Strap Review Supervisor** (id: 23): Enter the name of the supervisor who reviewed ESD Wrist Strap testing.

	+ Required: No

## Tips
* Make sure to answer all required fields (if any).
* Enter accurate and detailed information to help with the testing process.
* If unsure about any field, please reach out to the supervisor for clarification.
