# Post Event Feedback Form - Help Guide
## Purpose
The Post Event Feedback Form is designed to collect information and feedback from attendees after an event. Your input helps us understand what worked well and what we can improve on for future events.

## How To Complete This Form
Please fill out this form carefully, providing as much detail as possible for each field.

## Field-by-Field Explanation

* **Event Details** (`event_details`, text, optional): This field is a free-text area where you can provide any additional information about the event you attended.
* **Attendees** (`attendees`, select_multiple, optional): Please select all that apply. This field helps us know if you were part of a team or attended with others.
* **Event Rating** (`event_rating`, select_one, optional): This field asks you to rate the event on a scale of 1-5, based on your experience. A 1-2 means the event was not satisfactory, 3 is neutral, 4-5 means it was very good. 
* **Comments** (`comments`, text, optional): Share your thoughts about the event in this field. This is a great place to provide any additional feedback you might have.
* **Suggestions** (`suggestions`, select_multiple, optional): We value your opinion, and would like to know if you think we did something well. Please select all that apply.
* **Rating** (`rating`, number, optional): This field is for numerical feedback, if you feel it's more helpful to provide a numeric rating. You can enter a number between 1 and 5.
* **Event Date** (`event_date`, date, optional): If you can remember the date of the event, please select it from the calendar.
* **Event Start Time** (`event_start_time`, time, optional): If you can recall the start time of the event, please select it.
* **Event Start Time Format:** The format for the Event Start Time field is 24-hour clock, e.g., 14:00 for 2:00 PM.
