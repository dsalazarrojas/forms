# Youth Employment Survey - Help Guide
## Purpose
The Youth Employment Survey is designed to collect data on the employment status and experiences of youth, providing valuable insights into their demographic information, employment status, education, skills, job type, and job satisfaction.

## How To Complete This Form
To complete this form, follow these steps:

* Review each page to ensure you have all the required information.
* Answer all questions truthfully and accurately.
* Use the drop-down menus to select your responses from the provided options.

## Field-by-Field Explanation

* **demographic_info (Page 1)**: This field collects demographic information about you.
	+ Required: False
	+ Type: Text
* **contact (Page 1)**: This field collects contact information about you.
	+ Required: False
	+ Type: Text
* **employment_status (Page 2)**: Select your current employment status.
	+ Required: False
	+ Type: Select One
	+ Options: Working, Not working, In school
* **job_type (Page 2)**: Select the type of job you have.
	+ Required: False
	+ Type: Select One
	+ Options: Full-time, Part-time
* **hours_worked_last_week (Page 3)**: Enter the number of hours you worked last week.
	+ Required: False
	+ Type: Number
* **weeks_worked_last_year (Page 3)**: Enter the number of weeks you worked last year.
	+ Required: False
	+ Type: Number
* **job_type_list (Page 4)**: Select all the types of jobs you have had.
	+ Required: False
	+ Type: Select Multiple
	+ Options: Sales, Marketing, Engineering
* **hours_worked_last_week_list (Page 4)**: Select all the days you worked last week.
	+ Required: False
	+ Type: Select Multiple
	+ Options: Monday, Tuesday, Wednesday
* **months_worked_last_year (Page 5)**: Enter the number of months you have worked last year.
	+ Required: False
	+ Type: Number
* **months_list (Page 5)**: Select all the months you have worked last year.
	+ Required: False
	+ Type: Select Multiple
	+ Options: January, February, March
* **weeks_worked_this_year (Page 6)**: Enter the number of weeks you have worked this year.
	+ Required: False
	+ Type: Number
* **weeks_list (Page 6)**: Select all the weeks you have worked this year.
	+ Required: False
	+ Type: Select Multiple
	+ Options: Week 1, Week 2
* **work_status_employer (Page 7)**: Select your current work status with your employer.
	+ Required: False
	+ Type: Select One
	+ Options: Employed, Unemployed, Self-employed
* **work_status_student (Page 7)**: Select your current status as a student.
	+ Required: False
	+ Type: Select One
	+ Options: Student, Not a student
* **education (Page 8)**: Select your level of education.
	+ Required: False
	+ Type: Select One
	+ Options: High school graduate, Some college, Bachelor’s, Post graduate, No formal education
* **skills (Page 8)**: Select all the skills you possess.
	+ Required: False
	+ Type: Select Multiple
	+ Options: Communication, Teamwork, Leadership, Problem-solving, Adaptability
* **work_experience (Page 9)**: Select all the years of work experience you have.
	+ Required: False
	+ Type: Select Multiple
	+ Options: 0-1 year, 1-2 years, 2-3 years
* **job_satisfaction (Page 9)**: Select your job satisfaction level.
	+ Required: False
	+ Type: Select One
	+ Options: Neutral, Satisfied, Very satisfied
* **job_satisfaction_list (Page 10)**: Select all the job satisfaction levels you experience.
	+ Required: False
	+ Type: Select Multiple
	+ Options: Satisfied, Very satisfied, Not satisfied
* **salary (Page 11)**: Enter your salary.
	+ Required: False
	+ Type: Number
* **hourly_wage (Page 11)**: Enter your hourly wage.
	+ Required: False
	+ Type: Number
* **months_salaried (Page 12)**: Enter the number of months you have been salaried.
	+ Required: False
	+ Type: Number
* **months_non_salaried (Page 12)**: Enter the number of months you have not been salaried.
	+ Required: False
	+ Type: Number
* **months_worked_non_salaried (Page 13)**: Enter the number of months you have worked non-salaried.
	+ Required: False
	+ Type: Number
* **comments (Page 14)**: Enter any additional comments you have about your employment experience.
	+ Required: False
	+ Type: Text
* **education_list (Page 15)**: Select all the levels of education you have attained.
	+ Required: False
	+ Type: Select Multiple
	+ Options: High school, Some college, Bachelor’s degree, Post graduate, No formal education
* **skills_list (Page 16)**: Select all the skills you possess.
	+ Required: False

## Tips
* Be truthful and accurate when answering all questions.
* Use the provided options to select your responses.
* If you have any additional comments, use the text fields to provide them.
* Review each page to ensure you have answered all questions.
