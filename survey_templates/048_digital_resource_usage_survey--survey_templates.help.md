# Digital Resource Usage Survey - Help Guide

## Purpose
This survey is designed to collect data on the usage frequency and characteristics of digital resources. Please answer the questions as accurately and completely as possible to help us better understand your digital resource usage habits.

## How To Complete This Form
1. Please fill in the required fields (denoted by the "required" field label) to the best of your ability.
2. For select_one and select_multiple fields, choose the options that apply to you.
3. If you have any comments or feedback, please provide it in the "Comments" field.
4. Rate the resources as instructed in the "Rating" fields.
5. Fill in the resource URLs in the corresponding fields.
6. Enter the most recent duration of resource use in the "Usage Duration" fields.
7. Review the form carefully before submitting it to ensure that all the required fields are filled in correctly.

## Field-by-Field Explanation

* **Introduction**: This field is an information note and does not require a specific answer.
* **Name**: Please enter your name.
* **Email**: This field is not required but is used for communication purposes if needed.
* **Resource Type**: Please select the type of resource you are using (e.g., website, app, game, etc.).
* **Resource URL**: Please enter the URL of the resource you are using.
* **How often do you use resources like this?**: Please select the frequency of your resource usage (e.g., daily, weekly, rarely, etc.).
* **What was the most recent duration of resource use?**: Please enter the duration of the most recent resource use.
* **Feedback**: Please provide any comments or feedback about the resource you are using.
* **Comments**: Please provide any additional comments about the resource.
* **Rating**: Please rate the resource as instructed (e.g., 1-3 stars).

* **Rating 2, **Rating 3, etc.: Repeat the same process as above for these fields.
* **Usage Duration 2, **Usage Duration 3, etc.: Repeat the same process as above for these fields.
