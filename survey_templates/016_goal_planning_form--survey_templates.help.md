# Goal Planning Form - Help Guide
## Purpose
The Goal Planning Form is used to record and track information about a goal, including its type, description, priority, and associated deadlines.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the form for each new goal you want to create or modify.
2. Select the goal type from the available options (e.g., Goal, Habit, Value).
3. Enter a brief description of the goal.
4. Set the goal priority (optional).
5. Set the goal start and end dates (optional).
6. Choose the goal frequency (e.g., Daily, Weekly, Monthly).
7. Select the goal status (e.g., Started, In Progress, Completed).
8. Choose the goal ownership (e.g., Me, Team, Organization).
9. Add any additional notes or comments about the goal.

## Field-by-Field Explanation

* **First Step**: Enter the first step or action item for the goal. This can be a brief description of the initial task or activity.
* **Goal Name**: Enter a short and descriptive title for the goal. This should be a concise label that summarizes the goal's purpose.
* **Goal Description**: Provide a brief description of the goal, including its objectives and outcomes.
* **Goal Type**: Select the type of goal from the available options (e.g., Goal, Habit, Value).
* **Goal Type - Habit**: Select the specific habit type related to the goal (e.g., Habit, Routine, System). This is only applicable if the goal type is set to "Habit".
* **Goal Type - Value**: Select the specific value type related to the goal (e.g., Happiness, Health, Wealth). This is only applicable if the goal type is set to "Value".
* **Goal Type - System**: Select the specific system type related to the goal (e.g., Personal, Professional, Spiritual). This is only applicable if the goal type is set to "System".
* **Goal Priority**: Set the goal priority level (optional). This can be used to indicate the importance or urgency of the goal.
* **Goal Achieved By**: Select the entity responsible for achieving the goal (e.g., Me, Team, Organization).
* **Goal Start Date**: Set the date when the goal is expected to start.
* **Goal End Date**: Set the date when the goal is expected to end.
* **Goal Frequency**: Select the frequency of the goal (e.g., Daily, Weekly, Monthly).
* **Goal Status**: Select the status of the goal (e.g., Started, In Progress, Completed).
* **Goal Ownership**: Select the ownership of the goal (e.g., Me, Team, Organization).
* **Notes**: Add any additional comments or notes about the goal.

## Tips

* Make sure to fill out each field accurately and completely.
* Be concise and clear in your descriptions and selections.
* Review and update the form regularly to track progress and status changes.
* Use the form to identify and address any obstacles or challenges that arise during goal achievement.
