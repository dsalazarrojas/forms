# Basketball Survey - Help Guide
## Purpose
This form is designed to collect feedback from players about their experience with the program, allowing us to identify areas of improvement and make informed decisions to enhance the program.

## How To Complete This Form
- Please answer all questions in English.
- If you've had a significant experience with the program, please provide feedback in the space provided.
- You can select multiple options for the "specific skills learned" question.
- Date format is YYYY-MM-DD, e.g., 2022-01-01.

## Field-by-Field Explanation

* **-- Player Experience Survey --** (`participant_intro`): This is a brief introduction to the player feedback survey. Please take a moment to read and understand the purpose of this survey.
* **Player Name (Optional)** (`player_name`): If you'd like to provide your name, please enter it here. If not, you can skip this question.
* **Which season are you providing feedback for?** (`season_played`): Select the season you're providing feedback for. This is a required question.
* **Rate the quality of coaching received** (`coaching_rating`): Rate the quality of coaching you received, using a scale from 1 (Poor) to 5 (Excellent).
* **How would you rate the team chemistry and cooperation?** (`teamwork_rating`): Select how you would rate the team chemistry and cooperation, using the options: Very Poor, Poor, Average, Good, Exceptional.
* **Do you feel your basketball skills improved this season?** (`skill_development`): Select how you feel about your skill development, using the options: Yes, significantly, Yes, somewhat, Stayed the same, False.
* **Which specific skills did you work on most?** (`specific_skills_learned`): Select all the skills you worked on most, using the options: Shooting, Ball Handling, Defense, Rebounding, Conditioning, Strategy.
* **Rate the quality of the practice and game facilities** (`facilities_rating`): Rate the quality of facilities, using a scale from 1 (Poor) to 5 (Excellent).
* **What was your favorite moment or highlight of the season?** (`favorite_moment`): Share your favorite moment or highlight of the season.
* **What is one thing we could do to improve the program?** (`program_improvements`): Provide a suggestion on how we can improve the program.
* **Do you plan to return next season?** (`return_next_season`): Select whether you plan to return next season, using the options: True, False, Undecided.
* **Would you recommend this program to a friend?** (`recommend_program`): Select whether you would recommend this program to a friend, using the options: True, False.
* **Survey Completion Date** (`completion_date`): Please enter the date you're completing this form.
