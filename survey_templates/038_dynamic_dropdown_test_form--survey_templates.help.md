# Dynamic Dropdown Test Form - Help Guide
## Purpose
The Dynamic Dropdown Test Form is designed to test the functionality of dynamic dropdown menus, allowing users to select from options and input various types of data.

## How To Complete This Form
To complete this form, follow these steps:
1. Select the options for each field according to the field type and requirements.
2. Enter the correct data type for each field, such as a date or time.
3. Fill out any optional fields as needed.

## Field-by-Field Explanation

### Page 1
* **Page 1** (`dynamic_dropdown_test_form_page_1`, text): This is the first page of the form, with no specific instructions for this page.
* **Select Dropdown Test** (`select_dropdown_test`, select_one, required): This field tests the functionality of selecting a single option from a dropdown menu. Please select one of the available options (Option 1, Option 2, Option 3).
* **Select Multiple Test** (`select_multiple_test`, select_multiple, required): This field tests the ability to select multiple options from a dropdown menu. Select all available options (Option A, Option B, Option C).
* **Date Test** (`date_test`, date, optional): This field tests the ability to input a date. Enter a date in the format MM/DD/YY (e.g., 02/15/22).
* **Time Test** (`time_test`, time, optional): This field tests the ability to input a time. Enter a time in the format HH:MM AM/PM (e.g., 12:30 PM).
* **Note Test** (`note_test`, note, optional): This field tests the ability to input a note. Enter a brief note or comment.
* **Email Test** (`email_test`, email, optional): This field tests the ability to input an email address. Enter a valid email address.
* **Phone Test** (`phone_test`, text, optional): This field tests the ability to input a phone number. Enter a valid phone number.
* **Text Test** (`text_test`, text, optional): This field tests the ability to input text. Enter any text or comment.
* **Integer Test** (`integer_test`, number, optional): This field tests the ability to input an integer value. Enter a whole number.

## Tips
* Make sure to select the correct type for each field according to the field type.
* Enter data in the correct format for each field type (e.g., date: MM/DD/YY, time: HH:MM AM/PM).
