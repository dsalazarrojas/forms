# Voice Agent Evaluation Survey - Help Guide
## Purpose
The Voice Agent Evaluation Survey is designed to collect feedback from customers and other users about their experience with the Voice Agent, which is a crucial aspect of customer service. The feedback collected will help the team improve their communication style, problem resolution, tone, and overall service delivery.

## How To Complete This Form
To complete this form, please follow these steps:

1. Answer all the required questions honestly and thoroughly.
2. For optional questions, only answer if you have relevant information to provide.
3. Please note that some questions have multiple options, select the one that best fits your experience.
4. If you are providing feedback on behalf of someone else, please enter their name, title, phone number, and email address in the respective fields.

## Field-by-Field Explanation
### First Call Experience
* **First Call Experience** (`first_call_experience`, `text`, required): Please describe your first call experience with the Voice Agent. Be as detailed as possible.

### Communication Style
* **Communication Style** (`communication_style`, `select_one`, required): Please select the best description of the Voice Agent's communication style from the options:
	+ Agent is very friendly and approachable
	+ Agent is very friendly and approachable but sometimes seems distant
	+ Agent is somewhat friendly and approachable
	+ Agent is not friendly and not approachable

### Problem Resolution
* **Problem Resolution** (`problem_resolution`, `select_multiple`, required): Please select all the ways the Voice Agent resolved the problem from the options:
	+ Very Effective
	+ Somewhat Effective
	+ Not Very Effective

### Tone
* **Tone** (`tone`, `select_one`, required): Please select the tone of the Voice Agent from the options:
	+ Very Good
	+ Somewhat Good
	+ Very Poor

### Overall Experience
* **Overall Experience** (`overall_experience`, `select_one`, required): Please select the overall experience with the Voice Agent from the options:
	+ Very Good
	+ Somewhat Good
	+ Very Poor

### Feedback
* **Feedback** (`feedback`, `text`, required): Please provide any additional comments or feedback about your experience with the Voice Agent.

### Email
* **Email** (`email`, `email`, optional): If you have a email address, please enter it here.

### Phone
* **Phone** (`phone`, `text`, optional): If you have a phone number, please enter it here.

### Submission Date
* **Submission Date** (`submission_date`, `date`, required): This field will be automatically populated with the current date and time.

### Submitted By
* **Submitted By** (`submitted_by`, `select_one`, optional): Please select who submitted the feedback from the options:
	+ QA Team
	+ Voice Agent
	+ Customer
	+ Other (please specify)

### Other User
* **Other User** (`other_user`, `text`, optional): If you are providing feedback on behalf of someone else, please enter their name here.

### Other User Title

### Other User Company

### Other User Phone

### Other User Email
* **Other User Email** (`other_user_email`, `text`, optional): If you are providing feedback on behalf of someone else, please enter their email address here.

### Other User Comments
* **Other User Comments** (`other_user_comments`, `note`, optional): If you are providing feedback on behalf of someone else, please enter any additional comments here.

### Customer Name
