# research_project_summary_form - Help Guide
## Purpose

The **research_project_summary_form** is a form used to gather essential details about a research project. This form helps project managers and researchers to document and track project information.

## How To Complete This Form

1. Review each field carefully and make sure you have all the necessary information before starting.
2. Fill out each field accurately and thoroughly.
3. Double-check your answers for completeness and consistency.

## Field-by-Field Explanation

* **Project Objectives** (`project_objectives`, text, optional): Provide a brief description of the project's goals and objectives.
* **Project Methodologies** (`project_methodologies`, select_multiple, optional): Indicate whether the project uses methodologies such as 'Yes' or 'No'.
* **Project Outcomes** (`project_outcomes`, text, optional): Describe the expected outcomes of the project.
* **Research Team Lead** (`research_team_lead`, text, optional): Enter the name of the person leading the research team.
* **Research Team Members** (`research_team_members`, select_multiple, optional): Indicate whether the project has a research team with 'Yes' or 'No'.
* **Project Sponsor** (`project_sponsor`, text, optional): Enter the name of the project sponsor.
* **Project Manager** (`project_manager`, text, optional): Enter the name of the project manager.
* **Research Project Start Date** (`research_project_start_date`, date, optional): Enter the project start date in a standard date format (e.g., MM/DD/YYYY).
* **Research Project End Date** (`research_project_end_date`, date, optional): Enter the project end date in a standard date format (e.g., MM/DD/YYYY).
* **Research Project Duration** (`research_project_duration`, text, optional): Describe the project duration.
* **Research Grant Award Number** (`research_grant_award_number`, text, optional): Enter the grant award number.
* **Research Grant Amount** (`research_grant_amount`, text, optional): Enter the grant amount.
* **Research Funding Sources** (`research_funding_sources`, select_multiple, optional): Indicate the funding sources with 'Yes' or 'No'.
* **Research Funding Agency** (`research_funding_agency`, text, optional): Enter the funding agency.

## Tips

* Make sure to fill out each field accurately and thoroughly.
* Use clear and concise language when filling in text fields.
* If you're unsure about any field, try to fill it in as best as you can with the information you have, or skip it for now and come back to it later if needed.
* Review each field carefully before submitting the form.
