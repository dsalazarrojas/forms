# pre_program_survey_template - Help Guide
## Purpose
The pre-program survey template is a form used to collect information about users' pre-program experience. It's designed to gather details about the user's ID, name, contact information, and program-related data.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter your User ID
2. Provide your First name
3. Enter your Last name
4. Enter a valid email address
5. Enter your phone number
6. Enter your date of birth
7. Enter the date of the program
8. Enter the program start date
9. Enter the program end date
10. Enter the program length in weeks
11. Select the type of program you're participating in (IPFLP or Other)
12. Select all relevant locations from the list (New York, Los Angeles, Chicago)

## Field-by-Field Explanation
* **User ID** (`user_id`, number, required): Enter your unique User ID.
* **First name** (`first_name`, text, required): Enter your first name.
* **Last name** (`last_name`, text, required): Enter your last name.
* **Email** (`email`, email, required): Enter a valid email address.
* **Phone** (`phone`, text, required): Enter your phone number.
* **Date of birth** (`date_of_birth`, date, required): Enter your date of birth in YYYY-MM-DD format.
* **Date of program** (`date_of_program`, date, required): Enter the date of the program in YYYY-MM-DD format.
* **Program start date** (`program_start_date`, date, required): Enter the start date of the program in YYYY-MM-DD format.
* **Program end date** (`program_end_date`, date, required): Enter the end date of the program in YYYY-MM-DD format.
* **Program length** (`program_length`, number, required): Enter the program length in weeks.
* **Program type** (`program_type`, select_one, required): Select the type of program you're participating in (IPFLP or Other).
* **Program location** (`program_location`, select_multiple, required): Select all relevant locations from the list (New York, Los Angeles, Chicago).
