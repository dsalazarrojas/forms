# Organic Farming Market Assessment Survey - Help Guide
## Purpose
This guide will walk you through each section of the Organic Farming Market Assessment Survey, explaining the purpose of each question and how to complete it correctly.

## How To Complete This Form
1. Read through each question carefully and answer honestly.
2. Ensure that you have the necessary information and permissions to answer each question accurately.
3. Fill out the form with your responses and submit.

## Field-by-Field Explanation

* **survey_start** (`survey_start`, `text`, optional): This section is an introduction to the form. Please type in your response to indicate your willingness to participate in the survey.
* **farm_name** (`farm_name`, `text`, optional): This field is where you should enter the name of your farm or production entity.
* **farm_location** (`farm_location`, `text`, optional): Enter the location of your farm or production entity.
* **farm_production_area** (`farm_production_area`, `number`, optional): This field asks for the production area of your farm or production entity. Please enter a numerical value.
* **years_inorganic_farming** (`years_inorganic_farming`, `number`, optional): This question asks for the number of years you have been practicing inorganic farming. Please enter a numerical value.
* **organic_certification_status** (`organic_certification_status`, `select_multiple`, optional): This field is asking for the status of your organic certification. Please select all the relevant options.
	+ Select "Active" if you are currently certified.
	+ Select "Inactive" if you are not currently certified.
* **organic_certification_type** (`organic_certification_type`, `select_multiple`, optional): This field asks about the type of organic certification you hold. Please select all relevant options.
	+ Select "Yes" if you hold the certification.
	+ Select "No" if you do not hold the certification.
* **farm_size** (`farm_size`, `number`, optional): This field asks for the size of your farm or production entity. Please enter a numerical value.
* **organic_certification** (`organic_certification`, `select_one`, optional): This question asks if you have organic certification. Please select the relevant option.
	+ Select "Yes" if you have the certification.
	+ Select "No" if you do not have the certification.
* **soil_type** (`soil_type`, `select_multiple`, optional): This field is asking about the type of soil you use. Please select all relevant options.
	+ Select "Yes" if you use the soil type.
	+ Select "No" if you do not use the soil type.
* **organic_practices_used** (`organic_practices_used`, `select_multiple`, optional): This field asks about the organic practices you use. Please select all relevant options.
	+ Select "Yes" if you use the practice.
	+ Select "No" if you do not use the practice.
* **production_costs** (`production_costs`, `number`, optional): This field asks for the production costs of your farm or production entity. Please enter a numerical value.
* **sales_channels** (`sales_channels`, `select_multiple`, optional): This field is asking about the sales channels you use. Please select all relevant options.
	+ Select "Yes" if you use the sales channel.
	+ Select "No" if you do not use the sales channel.
* **organic_products_sold** (`organic_products_sold`, `select_multiple`, optional): This field asks about the organic products you sell. Please select all relevant options.
	+ Select "Yes" if you sell the product.
	+ Select "No" if you do not sell the product.
* **organic_farm_products** (`organic_farm_products`, `select_multiple`, optional): This field asks about the products you produce on your farm or production entity. Please select all relevant options.
	+ Select "Yes" if you produce the product.
	+ Select "No" if you do not produce the product.
* **certification_body** (`certification_body`, `select_one`, optional): This question asks about the certification body you are certified by. Please select the relevant option.
	+ Select "Yes" if you are certified by the body.
	+ Select "No" if you are not certified by the body.
* **contact_person** (`contact_person`, `text`, optional): This field is for the name of the contact person for your farm or production entity.
* **contact_email** (`contact_email`, `email`, optional): This field is for the email of the contact person for your farm or production entity.
* **contact_phone** (`contact_phone`, `text`, optional): This field is for the phone number of the contact person for your farm or production entity.
* **survey_comments** (`survey_comments`, `text`, optional): This field is for any additional comments you would like to provide about your farm or production entity.
* **survey_comments_2** (`survey_comments_2`, `text`, optional): This field is for any additional comments you would like to provide about your farm or production entity.
* **survey_comments_3** (`survey_comments_3`, `text`, optional): This field is for any additional comments you would like to provide about your farm or production entity.
* **survey_comments_4** (`survey_comments_4`, `text`, optional): This field is for any additional comments you would like to provide about your farm or production entity.
* **survey_comments_5** (`survey_comments_5`, `text`, optional): This field is for any additional comments you would like to provide about your farm or production entity.
* **survey_comments_6** (`survey_comments_6`, `text`, optional): This field is for any additional comments you would like to provide about your farm or production entity.

**Tips:**

* Be honest and accurate when answering each question.
* If you are unsure about any question, please ask for clarification.
* Please complete the form with your farm or production entity's data only. Do not include personal data or sensitive information about other entities.
