# Survey On Space Planning - Help Guide
## Purpose
The purpose of this form is to collect feedback on space planning from end-users. 

## How To Complete This Form
To complete this form, follow these steps:

1. Answer each question honestly and thoroughly.
2. Select options that best describe your experience or thoughts.
3. For open-ended questions (space usage and additional comments), please type your response in the space provided.
4. Review each section carefully and ensure you are answering all required fields.

## Field-by-Field Explanation

* **Space Usage (`space_usage`, text, optional):** This is an open-ended question where you can describe your usage of available space.
* **Satisfaction Level (`satisfaction_level`, select_one, optional):** This question asks about your overall satisfaction with the current space planning. Please select one of the five options provided:
	+ Very Satisfied
	+ Somewhat Satisfied
	+ Neither Satisfied nor Dissatisfied
	+ Somewhat Dissatisfied
	+ Very Dissatisfied
* **Challenges (`challenges`, text, optional):** This is an open-ended question where you can describe any major challenges you have experienced with the space planning.
* **Space Planning Form (`space_planning_form`, select_multiple, optional):** This question asks about your experience with space planning. Select all options that apply:
	+ Option 1
	+ Option 2
	+ Option 3
	+ Option 4
	+ Other (please specify)
* **Additional Comments (`additional_comments`, text, optional):** This is an open-ended question where you can provide any additional comments or thoughts about the space planning. 

## Tips
* Be honest and thorough in your responses.
* If you are unsure about any question, please ask for clarification.
* If you have any suggestions or ideas for improvement, please provide them in the additional comments section.
