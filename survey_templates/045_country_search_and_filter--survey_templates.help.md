This is a help guide for the "Country Search And Filter" form. The form is used to search and filter countries based on various criteria. The purpose of the form is to allow users to quickly find specific countries or filter a list of countries based on their preferences.

The form is divided into two sections: searching and filtering. In the searching section, users can input a keyword in the "Search" field to find countries that match their search query. In the filtering section, users can choose to select one or multiple countries based on their preferences.

To complete the form, follow these steps:

1. In the "Search" field, type a keyword related to the country you are looking for. You can input any text, such as a country name, city, or region.
2. In the "Filter" field, select "Yes" to search for countries that match the criteria you have selected in the previous step.
3. In the "Select One" field, choose "Yes" to select a single country from the search results.
4. In the "Select Multiple" field, choose "Yes" to select multiple countries from the search results.

### Country Search And Filter - Help Guide

### Purpose
The Country Search And Filter form is used to search and filter countries based on various criteria.

### How To Complete This Form

#### To use this form, follow these steps:

1. Enter a keyword in the "Search" field to find countries that match your query.
2. Select "Yes" or "No" in the "Filter" field to search for countries that match or don't match your criteria.
3. In the "Select One" field, choose "Yes" to select a single country from the search results.
4. In the "Select Multiple" field, choose "Yes" to select multiple countries from the search results.

#### Search
* **Search** (`search_field`, text, optional): Type a keyword related to the country you are looking for in this field. You can input any text, such as a country name, city, or region.
#### Filter
* **Filter** (`search_filter_field`, select_multiple, optional): Select "Yes" to search for countries that match the criteria you have selected in the previous step.
#### Select One
* **Select One** (`select_one_field`, select_one, optional): Choose "Yes" to select a single country from the search results.
#### Select Multiple
* **Select Multiple** (`select_multiple_field`, select_multiple, optional): Choose "Yes" to select multiple countries from the search results.
