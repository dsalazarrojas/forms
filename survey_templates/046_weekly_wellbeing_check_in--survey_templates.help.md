# Weekly Wellbeing Check In - Help Guide
## Purpose
The purpose of this form is to help individuals regularly check in with their mental wellbeing and identify any areas of concern. It is a brief, informal assessment to help individuals maintain their mental health and wellbeing.

## How To Complete This Form
To complete this form, follow these steps:
1. Read each question carefully and answer accordingly.
2. Answer all questions to the best of your ability.
3. For questions with multiple options, select all that apply.

## Field-by-Field Explanation
- **This is a wellbeing check in**: This is an introductory note that explains the purpose of the form.
- **How Are You Feeling**: This question asks how you are feeling at the moment. Answer with either "Yes" or "No" to indicate if you are feeling good or bad.
- **Do You Have Any Mental Health Conditions**: This question asks if you have any mental health conditions. Answer with either "Yes" or "No" to indicate if you have a condition or not.
- **Have You Considered Mental Health Support**: This question asks if you have considered seeking mental health support. Answer with either "Yes" or "No" to indicate if you have considered it or not.
- **Wellbeing Score**: This is a text field for you to input your current wellbeing score (1-5).
- **Wellbeing Comment**: This is a text field for you to provide any additional comments about your wellbeing.
- **Action Items**: This question asks if you have any action items for your wellbeing. Answer with either "Yes" or "No" to indicate if you have an action item or not.
- **Wellbeing Score Comment**: This is a text field for you to provide additional comments about your wellbeing score.
- **Wellbeing Action Item**: This question asks if you have taken any action items for your wellbeing. Answer with either "Yes" or "No" to indicate if you have taken an action item or not.
- **Wellbeing Support Plan**: This question asks if you have a wellbeing support plan. Answer with either "Yes" or "No" to indicate if you have a plan or not.
- **Wellbeing Referral**: This question asks if you have a wellbeing referral. Answer with either "Yes" or "No" to indicate if you have a referral or not.
- **Wellbeing Note**: This is a text field for you to provide any additional comments about your wellbeing.
- **Wellbeing Score Averaged**: This is not applicable as it is an internal metric.
- **Wellbeing Score Average**: This field is duplicated. Please ignore.
- **Wellbeing Score Averaged**: This field is duplicated and should not be answered. 

Note: The duplicated fields at id 14 and 15 can be ignored, as they seem to be redundant and not applicable to the user.
