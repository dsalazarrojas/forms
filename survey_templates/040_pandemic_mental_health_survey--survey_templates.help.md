# Pandemic Mental Health Survey - Help Guide
## Purpose
The Pandemic Mental Health Survey is designed to gather information on the mental health and well-being of individuals during the pandemic. The survey aims to understand how people are coping with the challenges posed by the pandemic and identify areas where support and resources are needed.

## How To Complete This Form

To complete this form, follow these steps:

1. Read the form carefully and ensure you understand what each question is asking.
2. Answer each question honestly and to the best of your ability.
3. Select the options that apply to you.
4. Enter any additional information as needed.

## Field-by-Field Explanation

* **Introduction**: This is a brief introduction to the survey.
* **Demographic Information**: This section asks for some basic demographic information to help us understand your profile.
* **Mental Health**: Select one or more of the following options that apply to you:
	+ Anxiety
	+ Depression
	+ Stress
	+ Burnout
	+ Trauma
* **Emotional States**: Select all that apply to you:
	+ Calm
	+ Frustrated
	+ Sad
	+ Anxious
	+ Angry
* **Coping Strategies**: Select all that apply to you:
	+ Self-Care
	+ Social Support
	+ Mindfulness
	+ Exercise
	+ Support Groups
* **Support Resources**: Select all that apply to you:
	+ Family
	+ Friends
	+ Community
	+ Professional Help
* **Healthcare Access**: Select one of the following:
	+ True
	+ False
* **Healthcare Provider Contact**: Select one of the following:
	+ True
	+ False
* **Healthcare Provider Name**: If you have a healthcare provider, enter their name here.
* **Mental Health History**: Select one of the following:
	+ True
	+ False
	+ Unsure
* **Mental Health Services**: Select all that apply to you:
	+ Counseling
	+ Medication
	+ Therapy
	+ Support Groups
* **Mental Health Services Other**: If you have other mental health services, describe them here.
* **Healthcare Facility Visits**: Enter the number of times you visited a healthcare facility in the last month.
* **Healthcare Facility Visits Last Month**: Enter the number of times you visited a healthcare facility in the last month.
* **Medication Use**: Select one or both of the following:
	+ True
	+ False
* **Medication Name**: If you are taking medication, enter the name here.
* **Medication Dosage**: If you are taking medication, enter the dosage here.
* **Symptoms**: Describe any symptoms you are experiencing.
* **Symptoms Last Month**: Describe any symptoms you experienced in the last month.
* **Mental Health Survey**: Select one of the following:
	+ True
	+ False
* **Mental Health Survey Last Month**: Select one of the following:
	+ True
	+ False
* **Mental Health Survey Frequency**: Select one of the following:
	+ Daily
	+ Weekly
	+ Monthly
	+ Rarely
	+ Never
* **Survey Completion**: Select one or both of the following:
	+ True
	+ False
* **Survey Completion Last Month**: Select one or both of the following:
	+ True
	+ False

## Tips

* Be honest and accurate when answering the questions.
* Select all that apply to you.
* If you are unsure about any question, select the option that best represents your feelings or circumstances.
* If you have any concerns or questions, contact us for assistance.
