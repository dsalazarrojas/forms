# School Construction Update Survey - Help Guide
## Purpose
This guide is here to help you understand how to complete the School Construction Update Survey form. The form is designed to collect updates from school construction projects, providing essential information about the status and details of each project.

## How To Complete This Form
1. Fill in the "School Construction Update" field with the relevant information about your project's current status.
2. Select the "Contact Person" and enter their email address for contact purposes.
3. Add the "Building Name" to accurately identify the construction project.
4. Choose the correct "Project Status" from the options provided, or type in an "Other" status if not listed.
5. Select the relevant "Construction Updates" that apply to your project.
6. If necessary, provide any additional comments or notes about your project.

## Field-by-Field Explanation

### School Construction Update
* **School Construction Update**: Enter a brief description of your project's current construction status (e.g., "Ongoing", "Completed", "Delayed", etc.).

* **Contact Person**: Select the person responsible for your project's construction updates, and enter their email address for communication purposes.

* **Building Name**: Enter the exact name of the building or project you're updating (e.g., "Main Hall", "Library", etc.).

* **Project Status**: Select the current status of your project from the options provided:
	+ Active
	+ Inactive
* If your project's status is not listed, type in "Other" and provide a brief description in the "Project Status Other" field.

* **Construction Updates**: Select all the updates that apply to your project:
	+ Construction Update 1
	+ Construction Update 2
	+ Construction Update 3
* If none of the above updates apply, type in "Other" and provide a brief description in the "Construction Update Survey Other" field.

* **Submission Date**: Enter the date you're submitting the update (format: YYYY-MM-DD).

* **Submission Time**: Enter the time you're submitting the update (format: HH:MM:SS).

* **Submitted By**: Enter your name or the name of the person submitting the update.

* **Notes**: Add any additional comments or details about your project.

* **Project Status Other 2**: If your project's status is not listed, type in "Other" and provide a brief description.

* **Submission Date Other**: If the submission date is not listed, type in "Other" and enter the date in the format YYYY-MM-DD.

* **Submitted By Other**: If the submitter's name is not listed, type in "Other" and enter the name.

* **Comments**: Add any additional comments or details about your project.

* **School Construction Update Survey Other**: If none of the above fields apply, type in a brief description of your project's status.
