# European Monetary System Quiz - Help Guide
## Purpose
This form is designed to test your knowledge about the European Monetary System (EMS). The form will ask you questions about the EMS, its benefits, types, goals, and impact on your work or studies.

## How To Complete This Form
To complete this form, follow these steps:

1. Read each question carefully and answer to the best of your knowledge.
2. Select the correct options for each question.
3. For text fields, type your answer in the provided text box.
4. Make sure to answer all required questions (indicated by a red star).

## Field-by-Field Explanation

* **What do you know about the European Monetary System?** (`title`, `text`, required: false)
This is a introductory question to get you started. Please type in a brief answer about what you know about the EMS.
* **Which of the following is a key benefit of the EMS?** (`eurosystem`, `select_one`, required: true)
Select one of the provided options that best describes a key benefit of the EMS.
* **What type of EMS do you have experience with?** (`eurosystem_type`, `select_multiple`, required: false)
Select all the types of EMS that you have experience with. You can select multiple options.
* **What are the main goals of the EMS?** (`eurosystem_goals`, `select_multiple`, required: true)
Select all the main goals of the EMS that you are familiar with. You can select multiple options.
* **How has the EMS impacted your work or studies?** (`eurosystem_impact`, `text`, required: false)
Please type a brief answer about how the EMS has impacted your work or studies.
* **What type of participant do you work with?** (`eurosystem_participant`, `select_one`, required: true)
Select the type of participant that you work with.
* **With which participants have you worked on the EMS?** (`eurosystem_participants`, `select_multiple`, required: false)
Select all the participants that you have worked with on the EMS. You can select multiple options.
* **Do you have any comments about the EMS?** (`eurosystem_comments`, `text`, required: false)
Please type in any comments you have about the EMS.
* **What are some details about the participant?** (`eurosystem_participant_details`, `select_multiple`, required: false)
Select all the details about the participant that you are familiar with. You can select multiple options.
* **Are you willing to follow up with participants about the EMS?** (`eurosystem_followup`, `select_one`, required: false)
Select the option that best describes your willingness to follow up with participants about the EMS.
