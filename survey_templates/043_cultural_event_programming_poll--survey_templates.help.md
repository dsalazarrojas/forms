# Cultural Event Programming Poll - Help Guide
## Purpose
This form is used to gather information about a cultural event, including its name, date, time, location, and target audience.

## How To Complete This Form

### Step 1: Select the event you are submitting for the cultural event poll.
* Click on the "Main Page" tab, where you will find the form fields to fill out.

### Step 2: Fill out the form fields with the required information.
*   **Event Name (`event_name`)**: Enter the name of the event, e.g., "Cultural Festival"
*   **Event Location (`event_location`)**: Enter the location of the event, e.g., "City Hall"
*   **Event Date (`event_date`)**: Select the date of the event in the format MM/DD/YYYY
*   **Event Time (`event_time`)**: Select the start and end time of the event in 24-hour format, e.g., 12:00 and 17:00
*   **Event Duration (`event_duration`)**: Enter the duration of the event in minutes, e.g., 360
*   **Event Venue (`event_venue`)**: Enter the venue of the event, e.g., "Theaters"
*   **Event Description (`event_description`)**: Enter a brief description of the event, e.g., "A celebration of cultural heritage"
*   **Target Audience (`event_target_audience`)**: Select the primary audience for the event, e.g., "Adults"
*   **Other Audience (`event_target_audience_other`)**: If the target audience is not listed, select "Other" and enter the specific audience details in the next field
*   **Other Other Audience (`event_target_audience_other_other`)**: Enter the details of the other audience, e.g., "Children under 12"
*   **Other Other Other Audience (`event_target_audience_other_other`)**: Enter any additional details about the other audience

## Field-by-Field Explanation

*   **Main Page (`main_page`)**: This is the initial page where you will find all the form fields.
*   **Event Name (`event_name`)**: Enter a brief and descriptive name for the event.
*   **Event Location (`event_location`)**: Enter the physical location where the event will take place.
*   **Event Date (`event_date`)**: Select the date of the event in the MM/DD/YYYY format.
*   **Event Time (`event_time`)**: Enter the start and end time of the event in 24-hour format (HH:MM).
*   **Event Duration (`event_duration`)**: Enter the duration of the event in minutes.
*   **Event Venue (`event_venue`)**: Enter the name and description of the event venue.
*   **Event Description (`event_description`)**: Enter a brief description of the event.
*   **Target Audience (`event_target_audience`)**: Select the primary target audience for the event.
*   **Other Audience (`event_target_audience_other`)**: Select "Other" if the target audience does not match any of the provided options.
*   **Other Other Audience (`event_target_audience_other_other`)**: Enter the details of the other target audience.

## Tips

*   Make sure to fill out all required fields accurately and completely.
*   Review your answers carefully before submitting the form.
*   If you're unsure about any field, refer to the event planning guidelines provided by your supervisor or the event planning team. 

Note: The form fields are designed to be completed by staff members or administrators.
