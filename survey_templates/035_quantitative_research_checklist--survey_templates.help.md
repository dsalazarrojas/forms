# Quantitative Research Checklist - Help Guide
## Purpose
This form is used to assess the readiness and quality of quantitative research projects. It is designed to ensure that research projects meet certain standards and guidelines, and to gather information on various aspects of the project.

## How To Complete This Form
To complete this form, please answer each question carefully and accurately. You can select from the provided options or type in your response if required. Make sure to enter all the required information.

## Field-by-Field Explanation

* **research_project_readiness** (`research_project_readiness`, select_multiple, required: false): This field asks whether the research project is ready for review. Please select all the reasons why the project is ready or not.
* **study_steps** (`study_steps`, select_one, required: false): This field asks whether the study steps are complete. Please select the option that best describes the current status of the study steps.
* **data_collection_methods** (`data_collection_methods`, select_multiple, required: false): This field asks about the data collection methods used in the study. Please select all the methods that apply.
* **data_review_workflows** (`data_review_workflows`, select_one, required: false): This field asks whether the data review workflows are complete. Please select the option that best describes the current status of the data review workflows.
* **data_collection_frequency** (`data_collection_frequency`, number, required: false): This field asks for the frequency of data collection. Please enter the frequency of data collection.
* **study_start_date** (`study_start_date`, date, required: false): This field asks for the start date of the study. Please enter the date in the correct format.
* **study_end_date** (`study_end_date`, date, required: false): This field asks for the end date of the study. Please enter the date in the correct format.
* **researcher_name** (`researcher_name`, text, required: false): This field asks for the researcher's name. Please enter the researcher's name.
* **researcher_email** (`researcher_email`, email, required: false): This field asks for the researcher's email. Please enter the email address.
* **researcher_k_phone** (`researcher_k_phone`, text, required: false): This field asks for the researcher's contact phone number. Please enter the phone number.
* **study_location** (`study_location`, select_one, required: false): This field asks whether the study was conducted at a specific location. Please select the correct option.
* **data_quality_checks** (`data_quality_checks`, select_multiple, required: false): This field asks about the quality of data collected. Please select all that apply.
* **project_manager_contact** (`project_manager_contact`, select_one, required: false): This field asks whether the project manager is available for contact. Please select the correct option.
* **project_manager_name** (`project_manager_name`, text, required: false): This field asks for the project manager's name. Please enter the project manager's name.
* **project_manager_email** (`project_manager_email`, email, required: false): This field asks for the project manager's email. Please enter the email address.
* **project_manager_phone** (`project_manager_phone`, text, required: false): This field asks for the project manager's contact phone number. Please enter the phone number.
* **project_manager_notes** (`project_manager_notes`, note, required: false): This field asks for any additional comments or notes from the project manager. Please enter any comments.
* **reviewer_comments** (`reviewer_comments`, text, required: false): This field asks for any comments from the reviewer. Please enter any comments.
* **reviewer_name** (`reviewer_name`, text, required: false): This field asks for the reviewer's name. Please enter the reviewer's name.
* **reviewer_notes** (`reviewer_notes`, note, required: false): This field asks for any additional comments or notes from the reviewer. Please enter any comments.
* **reviewer_phone** (`reviewer_phone`, text, required: false): This field asks for the reviewer's contact phone number. Please enter the phone number.
* **reviewer_email** (`reviewer_email`, email, required: false): This field asks for the reviewer's email. Please enter the email address.
* **reviewer_email_2** (`reviewer_email_2`, email, required: false): This field asks for the reviewer's secondary email. Please enter the email address.
* **reviewer_notes_2** (`reviewer_notes_2`, note, required: false): This field asks for any additional comments or notes from the reviewer. Please enter any comments.
* **researcher_additional_comments** (`researcher_additional_comments`, text, required: false): This field asks for any additional comments from the researcher. Please enter any comments.
