# Event Result Summary - Help Guide
## Purpose
This form is used to collect details and outcomes of events, allowing you to document and track the progress of various events. The Event Result Summary form is a key tool for providing a comprehensive overview of event results, enabling you to make informed decisions and take action accordingly.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the basic event details such as event date, location, and contact information.
2. Provide a brief description of the event, including the outcomes and feedback.
3. Select the supporting files and team information relevant to the event.
4. Add any relevant notes or observations about the event.

## Field-by-Field Explanation

* **Event Details**: (`event_details`, `text`, required: false) This field is used to input the basic details about the event, such as a brief description or notes.
* **Event Outcomes**: (`event_outcomes`, `select_multiple`, required: false) Select all applicable outcomes that occurred during the event.
* **Event Feedback**: (`event_feedback`, `text`, required: false) Provide any feedback or comments about the event.
* **Supporting Files**: (`supporting_files`, `select_multiple`, required: false) Select any files that support the event, such as photos or videos.
* **School Info**: (`school_info`, `select_one`, required: false) Select whether the event took place at a school or not.
* **Event Date**: (`event_date`, `date`, required: false) Input the date of the event.
* **Event Time**: (`event_time`, `time`, required: false) Input the time of the event.
* **Event Location**: (`event_location`, `text`, required: false) Input the location of the event.
* **Event Contact**: (`event_contact`, `text`, required: false) Input the contact information for the event.
* **Event Notes**: (`event_notes`, `note`, required: false) Add any notes or observations about the event.
* **Event Email**: (`event_email`, `email`, required: false) Input the email of the event.
* **Event Phone**: (`event_phone`, `text`, required: false) Input the phone number of the event.
* **Event Image**: (`event_image`, `text`, required: false) Input the image of the event.
* **Event Video**: (`event_video`, `text`, required: false) Input the video of the event.

## Tips
* Make sure to fill in all relevant fields to ensure a complete event summary.
* Use the correct format for date and time fields.
* Be as detailed as possible when inputting event outcomes and feedback.
* Use the supporting files section to upload relevant files that support the event.
* If you're unsure about any field, ask your supervisor for guidance.
