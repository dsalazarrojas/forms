# post_game_fan_feedback_poll - Help Guide
## Purpose
This form is designed to collect feedback from attendees after a game has been played, allowing us to gather valuable insights and improve future events.

## How To Complete This Form
1.  Select the event you attended from the dropdown menu.
2.  Choose how satisfied you were with your game day experience.
3.  Rate your experience with event staff.
4.  Choose how good the food service was.
5.  Indicate whether or not you purchased merchandise.
6.  Add any additional suggestions for improvement (optional).
7.  If you have any additional comments, feel free to add them here (optional).
8.  Finally, provide your name and email address so we can get back to you.

## Field-by-Field Explanation
* **Which Event Did You Attend** (`event_attended`):
    * This field allows you to select the event you attended. Choose the correct option from the dropdown menu.
* **How Satisfied With Your Game Day Experience** (`overall_satisfaction`):
    * This field asks you to rate your overall satisfaction with your game day experience. Select one of the three options: Very Satisfied, Neutral, or Somewhat Dissatisfied.
* **Venue Rating** (`venue_experience`):
    * This field asks you to rate your experience with the venue. Note: This field is currently not visible in the form, but it will appear as an option in the future.
* **Event Staff Interaction** (`event_staff`):
    * This field asks you to rate how well you think event staff interacted with you. Select one of the three options: Excellent, Average, or Poor.
* **Merchandise Purchase** (`merchandise`):
    * This field asks you if you purchased merchandise. Select True if you bought something, or False if you didn't.
* **Suggestions For Improvement** (`suggestions`):
    * This field is an open-ended text field where you can add any suggestions you have for how we can improve future events.
* **Comments** (`comments`):
    * This field is another open-ended text field where you can add any additional comments about your experience.
* **Name** (`name`):
    * Please enter your name so we can address you personally.
* **Email** (`email`):
    * Enter your email address so we can get back to you with any questions or follow-ups.
* **Phone** (`phone`):
    * This field is currently not used, but you can add it if you'd like to provide a phone number.
* **Venue** (`venue`):
    * This field is currently not used, but you can add it if you'd like to provide the venue name or address.
* **Event** (`event`):
    * This field is currently not used, but you can add it if you'd like to provide the event name or description.

## Tips
* Please be honest and provide as much detail as possible to help us improve future events.
* If you have any questions or concerns, don't hesitate to contact us.
