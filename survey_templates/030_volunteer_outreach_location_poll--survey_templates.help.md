# Volunteer Outreach Location Poll - Help Guide
## Purpose
The Volunteer Outreach Location Poll is a form used to gather information from potential volunteers about their outreach preferences. This form helps us understand volunteers' attitudes towards different types of outreach and the location where they would like to be contacted.

## How To Complete This Form
To complete this form, follow these steps:

1. Select all the locations where you are interested in being contacted (Volunteer Locations).
2. Enter your email address (Email).
3. Enter the name of the location where you would like to be contacted (Location Name).
4. Enter the address of the location where you would like to be contacted (Address).
5. Enter the phone number of the location where you would like to be contacted (Phone).
6. Check your preferred location for outreach (Preferred Location).
7. Select all the types of comments you would like to make about the survey (Survey Comments, Other Comments, More Comments).
8. Select all the types of volunteers you are interested in (Type of Volunteer).

## Field-by-Field Explanation

* **Volunteer Locations** (`Volunteer Locations`, select_multiple): This field allows you to select all the locations where you are interested in being contacted. Please select all the locations that apply to you.
* **Email** (`Email`, email): Enter your email address here. This is the email address where we will contact you for outreach.
* **Location Name** (`Location Name`, text): Enter the name of the location where you would like to be contacted.
* **Address** (`Address`, text): Enter the address of the location where you would like to be contacted.
* **Phone** (`Phone`, text): Enter the phone number of the location where you would like to be contacted.
* **Email** (`Email`, email): This is the email address where we will contact you for outreach.
* **Preferred Location** (`Preferred Location`, select_one): This field allows you to choose your preferred location for outreach.
* **Comments** (`Comments`, note): Please note any additional comments you would like to make about your experience.
* **Survey Comments** (`Survey Comments`, select_multiple): Select all the types of comments you would like to make about the survey.
* **Other Comments** (`Other Comments`, select_multiple): Select all the types of comments you would like to make about the survey.
* **More Comments** (`More Comments`, select_multiple): Select all the types of comments you would like to make about the survey.
* **Type of Volunteer** (`Type of Volunteer`, select_multiple): This field allows you to select all the types of volunteers you are interested in.
