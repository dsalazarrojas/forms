# Women Attorneys Survey - Help Guide
## Purpose
The Women Attorneys Survey is designed to collect information about the demographics, work experience, and other details of women attorneys. This data will be used for research and analysis to better understand the profession and industry.

## How To Complete This Form
To complete this form, follow these steps:

1.  Start by reviewing the form's pages, which are:
    *   intro_page: This page will provide context and instructions for the survey.
    *   demographics_page: This page is for collecting demographic information about the respondent.
    *   work_experience_page: This page is for selecting the types of experiences and practices the respondent has.
    *   firm_size_page: This page is for selecting the firm size of the respondent.
    *   practice_areas_page: This page is for selecting multiple practice areas.
    *   work_type_page: This page is for selecting a single work type.
    *   work_type_other_page: This page is for selecting a custom work type that is not listed.
    *   work_type_other_other_page: This page is for adding additional custom work types.
    *   firm_size_other_page: This page is for selecting a custom firm size.
    *   firm_size_other_other_page: This page is for adding additional custom firm sizes.
    *   firm_size_other_other_other_page: This page is for selecting more custom firm sizes.

2.  Complete each page by selecting the relevant answers or adding your comments as required.

## Field-by-Field Explanation
### intro_page

*   **title** (`title`, `text`, required/optional): Enter a brief title for your response.

*   **hint** (`hint`, `text`, required/optional): Enter a brief note or description to help explain your response, if needed.

### demographics_page

*   **demographic information** (`demographic_information`, `note`, required/optional): Enter your demographic information as required.

### work_experience_page

*   **work experience** (`work_experience`, `select_multiple`, required/optional): Select all the types of experiences and practices you have had.

### work_experience_questions_page

*   **work experience questions** (`work_experience_questions`, `select_one`, required/optional): Select the most relevant work experience question that applies to you.

### firm_size_page

*   **firm size** (`firm_size`, `select_one`, required/optional): Select the size of your firm.

### practice_areas_page

*   **practice areas** (`practice_areas`, `select_multiple`, required/optional): Select all the practice areas you have experience in.

### work_type_page

*   **work type** (`work_type`, `select_one`, required/optional): Select the type of work you do.

### work_type_other_page

*   **other work type** (`work_type_other`, `text`, required/optional): Enter an alternate work type that is not listed.

### work_type_other_other_page

*   **other other work type** (`work_type_other_other`, `text`, required/optional): Enter another alternate work type that is not listed.

### firm_size_other_page

*   **other firm size** (`firm_size_other`, `select_one`, required/optional): Select if you have an alternate firm size.

### firm_size_other_other_page

*   **other other firm size** (`firm_size_other_other`, `text`, required/optional): Enter an alternate firm size that is not listed.

### firm_size_other_other_other_page

*   **other other other firm size** (`firm_size_other_other_other`, `text`, required/optional): Enter another alternate firm size that is not listed.

### firm_size_other_other_other_page

*   **other other other other firm size** (`firm_size_other_other_other_other`, `text`, required/optional): Enter a further alternate firm size that is not listed.

## Tips
*   Please answer each question to the best of your abilities and honestly.
*   If you are unsure about any question or field, please seek assistance from a knowledgeable person.
*   Double-check your answers before submitting the form to ensure accuracy.
