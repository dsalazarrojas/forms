# Number Rounding Calculator - Help Guide
## Purpose
The "Number Rounding Calculator" is a form that helps users round numbers to the nearest specified unit.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the number you want to round in the "Number to round" field.
2. Select the rounding method from the "Rounding method" dropdown menu. Options include "half up," "half down," "nearest hundred," "nearest ten," "nearest one," "nearest ten up," "nearest ten down," "nearest hundred up," and "nearest hundred down."
3. Select the rounded value in the "Rounded value" field.
4. If you want to display a label with the result, enter it in the "Result label" field.
5. Optionally, you can view the result in the "Result" field.
6. If an error occurs, a message will be displayed in the "Error message" field.
7. You can also view any error code in the "Error" field.
8. For additional information on the rounding method, view the "Rounding method description" field.
9. Finally, view a description of the result in the "Result description" field.

## Field-by-Field Explanation

* **Number to round** (`Number to round`, `number`, required): Enter the number you want to round. This field is required and must be a numerical value.
* **Rounding method** (`Rounding method`, `select_one`, required): Select the method to use for rounding. Options include:
	+ Half up: Rounds to the nearest higher value
	+ Half down: Rounds to the nearest lower value
	+ Nearest hundred: Rounds to the nearest hundred
	+ Nearest ten: Rounds to the nearest ten
	+ Nearest one: Rounds to the nearest single digit
	+ Nearest ten up: Rounds to the nearest ten up
	+ Nearest ten down: Rounds to the nearest ten down
	+ Nearest hundred up: Rounds to the nearest hundred up
	+ Nearest hundred down: Rounds to the nearest hundred down
* **Rounded value** (`Rounded value`, `number`, required): Enter the rounded value of the number.
* **Result label** (`Result label`, `text`, optional): Enter a label to display with the result, if desired.
* **Result** (`Result`, `text`, optional): View the result of the rounding operation.
* **Error message** (`Error message`, `text`, optional): Display a message if an error occurs.
* **Error** (`Error`, `number`, optional): View any error code that may occur.
* **Rounding method description** (`Rounding method description`, `text`, optional): View a description of the rounding method used.
* **Result description** (`Result description`, `text`, optional): View a description of the result.
