> # Tag Input Form - Help Guide
## Purpose
This form is used to collect tags and other essential details for a specific event. Please note that it's essential to review existing forms for this event to avoid duplication.

## How To Complete This Form
1. Select the relevant tags for the event from the provided options.
2. Fill out the event type, date, and time as required.
3. Enter the location of the event.
4. Add a note (optional).
5. Provide your email address (if required).
6. Add any additional information in the phone field (if necessary).

## Field-by-Field Explanation
- **Tag Input 1** (`tag_input_1`, select_one, optional):
	* Select the primary tag or category for this event.
- **Tag Input 2** (`tag_input_2`, select_multiple, optional):
	* Choose multiple tags or subcategories for this event.
- **Event Type** (`event_type`, text, optional):
	* Enter the type of event (e.g., meeting, conference, seminar).
- **Date of Event** (`date_of_event`, date, optional):
	* Select the date of the event using the date input field.
- **Time of Event** (`time_of_event`, time, optional):
	* Choose the time of the event using the time input field.
- **Location** (`location`, text, optional):
	* Enter the venue or location of the event.
- **Note** (`note`, note, optional):
	* Add any additional information or notes about the event.
- **Email** (`email`, email, optional):
	* Enter your email address for correspondence about this event.
- **Phone** (`phone`, text, optional):
	* Provide any phone number for contact or follow-up about this event.
- **Tag Input 3** (`tag_input_3`, select_one, optional):
	* Select an additional tag or category for this event.
