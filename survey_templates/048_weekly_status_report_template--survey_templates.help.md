# weekly_status_report_template - Help Guide
## Purpose
The "weekly_status_report_template" form is a template used to report the status of various departments on a weekly basis. It collects information on weekly activities, issues, and submitted data.

## How To Complete This Form
1. Select the status of each department from the provided options (Active or Inactive).
2. Select the department that this status report is for (Yes or No).
3. Enter any comments or issues that need to be addressed in the "Comments" field.
4. Select whether the status report was submitted by the current user (Yes or No).
5. Enter any additional form data in the "Form data" field.
6. Select the status of each department again from the provided options (Active or Inactive).
7. Select the department that this status report is for again (Yes or No).

## Field-by-Field Explanation
* **Weekly status** (`weekly_status`, select_multiple, required: false): Select the status of each department from the options (Active or Inactive).
* **Department** (`department`, select_one, required: false): Select the department that this status report is for (Yes or No).
* **Employee** (`employee`, text, required: false): Enter the name of the employee responsible for this status report.
* **Week start** (`week_start`, date, required: false): Enter the start date of the week for which this status report is being submitted.
* **Week end** (`week_end`, date, required: false): Enter the end date of the week for which this status report is being submitted.
* **Comments** (`comments`, note, required: false): Enter any comments or issues that need to be addressed.
* **Submitted by** (`submitted_by`, select_one, required: false): Select whether the status report was submitted by the current user (Yes or No).
* **Form data** (`form_data`, text, required: false): Enter any additional form data.
* **Weekly status** (`weekly_status`, select_multiple, required: false): Select the status of each department from the options (Active or Inactive). 
* **Department** (`department`, select_one, required: false): Select the department that this status report is for (Yes or No).
