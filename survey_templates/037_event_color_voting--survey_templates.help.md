# Event Color Voting - Help Guide
## Purpose
The purpose of this form is to collect feedback on color preferences from respondents.

## How To Complete This Form
1. Click on the "Submit" button to begin filling out the form.
2. Select your favorite color(s) from the "Color Options" field.
3. In "Color Choice", select your top choice color.
4. In "Color Preferences", select all the colors that you prefer.
5. If you have additional colors that you like, select them in "Additional Colors".
6. Optionally, enter any additional comments in "Color Comments".
7. Enter any notes in "Event Color Voting Form Notes" if you'd like.
8. Enter your email address in "Event Color Voting Form Email" if you'd like to be contacted.

## Field-by-Field Explanation
* **Event Color Voting Form** (`event_color_voting_form`, text, optional): This is the form title. You can ignore this field.
* **Color Options** (`color_options`, select_multiple, **true**): Select your top 3 favorite colors from the list. You can select multiple colors.
* **Color Choice** (`color_choice`, select_one, **true**): Select your top favorite color from the list.
* **Color Preferences** (`color_preferences`, select_multiple, **true**): Select all the colors that you prefer.
* **Additional Colors** (`additional_colors`, select_multiple, **false**): Select any additional colors that you like. You can select multiple colors.
* **Color Comments** (`color_comments`, text, **false**): Enter any additional comments about your color preferences.
* **Event Color Voting Form Notes** (`event_color_voting_form_notes`, note, **false**): Enter any additional notes or comments about the form.
* **Event Color Voting Form Email** (`event_color_voting_form_email`, email, **false**): Enter your email address if you'd like to be contacted.
