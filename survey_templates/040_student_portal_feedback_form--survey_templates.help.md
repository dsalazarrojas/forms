# Student Portal Feedback Form - Help Guide
## Purpose
This form is designed to collect feedback from students on their experience with the student portal.

## How To Complete This Form
To complete this form, follow these steps:

1. Review each page and question carefully.
2. Select the relevant option that best answers each question.
3. You can select multiple options for questions that allow it (e.g., "Which features do you frequently use on the portal?").
4. Enter any free-text feedback or comments in the "Any feedback or comments?" field.
5. If you wish to provide your contact information, enter your email and phone number in the respective fields.

## Field-by-Field Explanation
* **How satisfied are you with the portal overall?**
	+ Select one option from the scale:
		- Option 1: Not Satisfied
		- Option 2: Neutral
		- Option 3: Satisfied
* **Which features do you frequently use on the portal?**
	+ Select all applicable features from the list:
		- Option 1: Feature 1
		- Option 2: Feature 2
		- Option 3: Feature 3
		- Option 4: Feature 4
* **Have you experienced any technical issues with the portal?**
	+ Select one option from the scale:
		- Option 1: Yes
		- Option 2: No
* **How often do you use the portal?**
	+ Select one option from the scale:
		- Option 1: Frequently
		- Option 2: Occasionally
		- Option 3: Rarely
* **Any feedback or comments?**
	+ Enter any additional feedback or comments about your experience with the portal.
* **Email**
	+ Enter your email address if you wish to be contacted for further feedback.
* **Phone**
	+ Enter your phone number if you wish to be contacted for further feedback.
* **Note**
	+ Enter any additional notes or information you would like to share.
