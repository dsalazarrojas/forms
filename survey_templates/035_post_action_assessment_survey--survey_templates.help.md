# post_action_assessment_survey - Help Guide
## Purpose
This form is used to collect information on the post-action progress and next steps of an action plan after an event or session has taken place.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the relevant Event Type from the drop-down list.
2. Enter the Session ID (if available).
3. Answer the questions related to the event (Question 1, Question 2, Score 1, Score 2, Score 3).
4. Enter your Rating for the event (Rating 1).
5. Rate the Follow-up option (Follow up).
6. Enter any additional comments or notes.
7. Enter your Name, Email, Phone number (if applicable).
8. Enter the Session ID 2 (if applicable).
9. Select the Event Date and Event Start Time (if applicable).
10. Select the Session Duration (if applicable).
11. Enter the Action Plan and Next Action Steps (if applicable).
12. Select the next Follow-up option (Follow up).

## Field-by-Field Explanation
* **Event Type**: Choose the type of event or session this form is related to. This will help in categorizing the data for further analysis.
* **Session ID**: Enter the unique identifier for the session, if available.
* **Question 1**: Answer the first question related to the event.
* **Question 2**: Answer the second question related to the event.
* **Score 1**: Enter the score for the first question.
* **Score 2**: Enter the score for the second question.
* **Score 3**: Enter the score for the third question.
* **Rating 1**: Rate the event or session, using the provided options.
* **Follow up**: Select the next follow-up option, which will help in scheduling the next session or action.
* **Comment**: Enter any additional comments or notes related to the event or session.
* **Name**: Enter your name, which will be used for contact purposes.
* **Email**: Enter your email address, which will be used for contact purposes.
* **Phone**: Enter your phone number, which will be used for contact purposes.
* **Session ID 2**: Enter the unique identifier for the second session, if applicable.
* **Event Date**: Select the date of the event or session.
* **Event Start Time**: Select the start time of the event or session.
* **Event End Time**: Select the end time of the event or session.
* **Session Duration**: Select the duration of the session.
* **Session Time**: Select the duration of the session in a different format.
* **Session Duration**: Select the duration of the session in a different format.
* **Action Plan**: Enter the action plan for the next steps.
* **Next Action Steps**: Enter the next steps for the action plan.
* **Follow up**: Select the next follow-up option, which will help in scheduling the next session or action.
* **Session ID 2**: Enter the unique identifier for the second session, if applicable.
