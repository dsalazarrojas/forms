# urban_redevelopment_impact_survey - Help Guide

## Purpose
The urban_redevelopment_impact_survey form is designed to collect feedback and information about urban redevelopment projects. It's essential to provide accurate and complete information to help project managers and stakeholders make informed decisions.

## How To Complete This Form
1. Review each section carefully and provide the required information for each field.
2. For each field, ensure that you're providing accurate and relevant information.
3. If a field is marked as required, please make sure to fill it in accordingly.

## Field-by-Field Explanation

* **Awareness** (`1`, `text`, required: false): This field is used to gauge the user's awareness of the urban redevelopment project. Please provide a brief description of your understanding of the project.
* **Impacts** (`2`, `select_multiple`, required: false): Select all the impacts that you think the urban redevelopment project has on the following areas:
	+ Impacts affecting business
	+ Impacts affecting environment
	+ Impacts affecting livability
	+ Impacts affecting safety
	+ Impacts affecting sustainability
	+ Impacts affecting quality of life
	+ Impacts affecting health
* **Satisfaction** (`3`, `number`, required: true): Rate your satisfaction level with the project, using the following scale: 1 (very dissatisfied) to 10 (very satisfied).
* **Overall Satisfaction** (`4`, `select_one`, required: true): Choose the best description of your overall satisfaction with the project:
	+ Very satisfied
	+ Satisfied
	+ Somewhat satisfied
	+ Neutral
	+ Somewhat dissatisfied
	+ Very dissatisfied
* **Project Description** (`5`, `text`, required: true): Provide a brief description of the project and its goals.
* **Redeveloped Area Description** (`6`, `text`, required: false): Describe the area where the project will take place.
* **Contact Information** (`7`, `text`, required: true): Provide your contact information, including your name and any other relevant details.
* **Email Address** (`8`, `email`, required: false): Enter your email address (if you'd like to be contacted about the project).
* **Contact Phone** (`9`, `text`, required: false): Enter your phone number (if you'd like to be contacted about the project).
* **Project Completion Date** (`10`, `date`, required: true): Enter the projected completion date of the project.
* **Redeveloped Area Map** (`11`, `note`, required: false): Please use this field to provide any additional information or comments about the project.
* **Comments** (`12`, `text`, required: false): Provide any additional comments or feedback about the project.
* **Redeveloped Area Address** (`13`, `text`, required: false): Enter the address of the redeveloped area.
* **Redeveloped Area City** (`14`, `text`, required: false): Enter the city of the redeveloped area.
* **Redeveloped Area State** (`15`, `text`, required: false): Enter the state of the redeveloped area.
* **Redeveloped Area Zip** (`16`, `text`, required: false): Enter the zip code of the redeveloped area.
* **Project Manager** (`17`, `text`, required: false): Enter the name of the project manager.
* **Contact Name** (`18`, `text`, required: false): Enter your name.
* **Contact E-mail** (`19`, `email`, required: false): Enter your email address (if you'd like to be contacted about the project).
* **Contact Phone** (`20`, `text`, required: false): Enter your phone number (if you'd like to be contacted about the project).
* **Project Manager E-mail** (`21`, `email`, required: false): Enter the project manager's email address (if you'd like to be contacted about the project).
* **Project Manager Phone** (`22`, `text`, required: false): Enter the project manager's phone number (if you'd like to be contacted about the project).
* **Project Manager Title** (`23`, `text`, required: false): Enter the project manager's title.
* **Project Manager Contact** (`24`, `text`, required: false): Enter additional contact information for the project manager.
* **Additional Comments** (`25`, `text`, required: false): Provide any additional comments or feedback about the project.

## Tips
* Please answer each question truthfully and accurately.
* If you're unsure about any aspect of the form, please don't hesitate to ask for clarification.
