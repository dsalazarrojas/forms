# Diabetes Survey - Help Guide
## Purpose
The Diabetes Survey form is a tool for healthcare professionals to assess a patient's risk factors and treatment response for diabetes. It is designed to gather relevant information to provide a comprehensive understanding of the patient's medical history and current condition.

## How To Complete This Form
To complete this form, follow these steps:

1. Review the patient's medical history and current condition before proceeding.
2. Select all applicable answers to the questions on each page.
3. Enter any additional comments or notes in the "notes" field.
4. Review your answers for accuracy before submitting the form.

## Field-by-Field Explanation
### Introduction (Page 1)
* **Introduction**: This page serves as a brief introduction to the form and provides an overview of the purpose and scope of the Diabetes Survey.
* **Hint**: null

### Risk Factors (Page 2)
* **risk_factors** (`Select Multiple`): This question asks if the patient has any risk factors for diabetes. Select all that apply:
	+ **Yes**: The patient has one or more risk factors for diabetes.
	+ **No**: The patient has no risk factors for diabetes.

### Blood Workup (Page 3)
* **Blood workup** (`Select One`): This question asks about the patient's blood workup results. Select one of the following:
	+ **Option 1**
	+ **Option 2**
	+ **Option 3**

### Medications (Page 4)
* **medications** (`Select Multiple`): This question asks about the patient's current medications. Select all that apply:
	+ **Yes**: The patient is taking the selected medication.
	+ **No**: The patient is not taking the selected medication.

### Symptoms (Page 5)
* **symptoms** (`Select Multiple`): This question asks about the patient's symptoms related to diabetes. Select all that apply:
	+ **Yes**: The patient is experiencing the selected symptom.
	+ **No**: The patient is not experiencing the selected symptom.

### Treatment Response (Page 6)
* **treatment_response** (`Select One`): This question asks about the patient's response to treatment. Select one of the following:
	+ **Option 1**
	+ **Option 2**
	+ **Option 3**

### Complications (Page 7)
* **complications** (`Text`): This question allows you to enter any complications related to the patient's diabetes. Enter any relevant information.

### Notes (Page 8)
* **notes** (`Text`): This question allows you to enter any additional comments or notes about the patient's condition.

### Risk Factors Description (Page 9)
* **risk_factors_description** (`Text`): This question allows you to enter a brief description of the patient's risk factors.

### Blood Workup Description (Page 10)
* **blood_workup_description** (`Text`): This question allows you to enter a brief description of the patient's blood workup results.
