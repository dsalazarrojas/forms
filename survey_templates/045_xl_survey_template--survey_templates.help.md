# XL Survey Template - Help Guide
## Purpose
The XL Survey Template form is used to create or edit survey templates with multiple pages, each with its own set of questions.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the template you want to create or edit from the available options.
2. Enter the required information for the selected template, including:
	* Category
	* Description
	* Assigned tools
	* Email
	* Phone number
	* Date
	* Time
3. For each page, fill in the corresponding fields. Some pages have optional fields, which you can leave blank if not necessary.
4. Review your input before submitting the form.

## Field-by-Field Explanation
* **Category** (`category`, select_one, required): Select the category for this survey template.
* **Description** (`description`, text, required): Enter a brief description of the survey template.
* **Assigned Tools** (`assigned_tool`, select_multiple, required): Select the tools assigned to this template.
* **Email** (`email`, email, required): Enter a valid email address for the template.
* **Phone** (`phone`, text, required): Enter a phone number for the template.
* **Date** (`date`, date, required): Enter the date for the template.
* **Time** (`time`, time, required): Enter the time for the template.
* **Note** (`note`, note, optional): Add any additional notes about this template.
* **Survey Template 2** (`survey_template_10`, text, optional): Enter any additional information about the second survey template.
