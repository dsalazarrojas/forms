# Extension Usage Survey - Help Guide
## Purpose
The Extension Usage Survey form is used to gather information on the usage of extensions within the organization. This will help the management team to understand which extensions are being used, by whom, and in which category, aiding in making informed decisions on resource allocation and extension development.

## How To Complete This Form
1. Fill out the form completely, providing accurate and honest information on your usage of extensions.
2. Select the category for which you are using the extension.
3. Describe how you are using the extension (description).
4. Select all the tools you are using the extension with (assigned_tool).
5. Provide any feedback on your usage experience (feedback).
6. Input the date you started using the extension (date).
7. Input the time of day you use the extension (time).
8. Input your email address (email).
9. Input your phone number (phone).

## Field-by-Field Explanation

* **Extension Title (survey_title)**: Provide a brief title for the extension.
* **Category (category)**: Select the category for which the extension is being used. 
* **Description (description)**: Describe how you are using the extension.
* **Assigned Tools (assigned_tool)**: Select all the tools you are using the extension with.
* **Feedback (feedback)**: Provide any feedback on your usage experience.
* **Start Date (date)**: Input the date you started using the extension.
* **Time (time)**: Input the time of day you use the extension.
* **Email (email)**: Input your email address.
* **Phone (phone)**: Input your phone number.

## Tips

* Be honest and accurate when filling out this form.
* Only fill out this form if you are an authorized user of the extension.
* If you have any questions or need clarification on a field, feel free to contact the administration team.
