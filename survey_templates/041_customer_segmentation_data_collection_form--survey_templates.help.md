# Customer Segmentation Data Collection Form - Help Guide
## Purpose
This form is designed to collect data for customer segmentation purposes. It is used to gather information about customer segments, including segment name, audience size, target segment, and collection method. The form is meant to be filled out by customers or their representatives to provide accurate and up-to-date information about their segmentation data.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the relevant pages for your customer segmentation data collection.
2. Fill out the required fields for each page, indicated by a red asterisk (*).
3. Ensure that all fields are accurate and up-to-date.
4. Click the submit button to save your changes.

## Field-by-Field Explanation

* **Customer Segmentation**:
	+ This is the first page of the form.
	+ Enter a short description of the customer segmentation data you are collecting.
* **Segment Name**:
	+ Enter the name of the segment you are collecting data for.
* **Audience Size**:
	+ Enter the number of people in the audience for this segment.
* **Target Segment**:
	+ Select the primary target segment for this data collection.
* **Target Segment 2**:
	+ Select any additional target segment for this data collection (if applicable).
* **Data Collection Frequency**:
	+ Enter the frequency of data collection for this segment.
* **Collection Method**:
	+ Select the method used to collect this data (online or offline).
* **Consent Frequency**:
	+ Enter the frequency of consent for this segment.
* **Form Submission**:
	+ Enter the date and time the form was submitted.
* **Submission Status**:
	+ Select the status of this submission.
* **Customer Segmentation Data Collection Form Notes**:
	+ Enter any additional comments about this segment.
* **Email**:
	+ Enter a valid email address (if applicable).
* **Phone Number**:
	+ Enter a valid phone number (if applicable).
* **Customer Segmentation Data Collection Form Comments**:
	+ Enter any additional comments about this segment.
* **Customer Segmentation Data Collection Form Consent**:
	+ Select whether consent was given for this segment.
* **Customer Segmentation Data Collection Form Consent Date**:
	+ Enter the date of consent for this segment.
* **Customer Segmentation Data Collection Form Consent Time**:
	+ Enter the time of consent for this segment.
* **Customer Segmentation Data Collection Form Consent Notes**:
	+ Enter any additional notes about consent.
* **Customer Segmentation Data Collection Form Consent Status**:
	+ Select the status of consent for this segment.
* **Customer Segmentation Data Collection Form Segmentation Notes**:
	+ Enter any additional comments about this segment.
* **Customer Segmentation Data Collection Form Consent Expiration Date**:
	+ Enter the expiration date of consent for this segment.
* **Customer Segmentation Data Collection Form Consent Expiration Time**:
	+ Enter the expiration time of consent for this segment.
* **Customer Segmentation Data Collection Form Consent Expiration Notes**:
	+ Enter any additional notes about expiration.
* **Customer Segmentation Data Collection Form Consent Expiration Status**:
	+ Select the status of expiration for this segment.
* **Submission Tracking ID**:
	+ Enter a tracking ID for this submission.

Note: Fields with a red asterisk (*) are required. Make sure to complete them before submitting the form.
