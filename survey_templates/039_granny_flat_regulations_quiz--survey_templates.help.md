# Granny Flat Regulations Quiz - Help Guide
## Purpose
The Granny Flat Regulations Quiz is a form designed to collect information about Granny Flats, a type of building or development that has specific regulations and guidelines. 

## How To Complete This Form
To complete the form, follow these steps:

1. Fill out the form with accurate and relevant information about the Granny Flat.
2. Be sure to complete all applicable fields, especially those marked as "required".
3. Use the provided options for select fields, such as "Building Type" and "Building Location".
4. Enter dates in the format "dd/mm/yyyy" for date fields.
5. If unsure about any field, refer to the relevant regulations and guidelines for clarification.

## Field-by-Field Explanation

### First Name
* First Name (`first_name`, text, optional): Enter your name for identification purposes.

### Email
* Email (`email`, email, optional): Enter your email address for contact purposes.

### Contact Number
* Contact Number (`contact_number`, text, optional): Enter your contact number for communication purposes.

### Building Type
* Building Type (`building_type`, select_one, optional): Select the type of building, either "One", "Two", or "Three".

### Address
* Address (`address`, text, optional): Enter the address of the building.

### Building Age
* Building Age (`building_age`, number, optional): Enter the age of the building.

### Building Condition
* Building Condition (`building_condition`, select_one, optional): Select the condition of the building, either "Good", "Average", or "Poor".

### Building Status
* Building Status (`building_status`, select_multiple, optional): Select the status of the building, either "Occupied", "Vacant", or "Under Construction".

### Building Height
* Building Height (`building_height`, number, optional): Enter the height of the building.

### Building Use
* Building Use (`building_use`, select_one, optional): Select the use of the building, either "Residential", "Commercial", or "Industrial".

### Building Location
* Building Location (`building_location`, select_one, optional): Select the location of the building, either "Urban", "Rural", or "Suburban".

### Building Size
* Building Size (`building_size`, select_multiple, optional): Select the size of the building, either "Large", "Medium", or "Small".

### Building Year Built
* Building Year Built (`building_year_built`, date, optional): Enter the year the building was built.

### Building Year Relocated
* Building Year Relocated (`building_year_relocated`, date, optional): Enter the year the building was relocated.

**Tips**: If you're unsure about any field, refer to the relevant regulations and guidelines for clarification.
