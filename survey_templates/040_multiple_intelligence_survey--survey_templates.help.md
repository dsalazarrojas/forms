# multiple_intelligence_survey - Help Guide
## Purpose
This form is designed to collect information about your self-perceived intelligence, personality traits, and values.

## How To Complete This Form

1. Review each question carefully and select the option that best describes you.
2. You can choose one option for questions 1-9 and multiple options for questions 10-23.
3. Ensure you answer all questions, as they are all optional, but it's helpful to complete the entire form for an accurate assessment.

## Field-by-Field Explanation

* **Introduction** (`introduction`, `note`, required: false): This section serves as an introduction to the survey and provides background information about what the survey is about.
* **Survey Questions** (`survey_questions`, `select_multiple`, required: false): This question allows you to choose multiple options that best describe you. You can select one or more of the following:
	+ **Student**
	+ **Client**
	+ **Patient**
* **Which one of the following best describes you?** (`multiple_intelligence_survey_questions_1`, `select_one`, required: false): This question asks for your self-perceived level of intelligence:
	+ **Very Intelligent**
	+ **Moderately Intelligent**
	+ **Not Very Intelligent**
* **Which of the following best describes your personality?** (`multiple_intelligence_survey_questions_4`, `select_one`, required: false): Choose one option that best fits you:
	+ **Adventurous**
	+ **Cautious**
	+ **Determined**
* **What do you value most in life?** (`multiple_intelligence_survey_questions_5`, `select_one`, required: false): Select one option that you value most:
	+ **Happiness**
	+ **Wealth**
	+ **Success**
* **Which of the following best describes you?** (`multiple_intelligence_survey_questions_10`, `select_multiple`, required: false): Choose one or more of the following:
	+ **Creative**
	+ **Logical**
	+ **Social**
* **Which of the following best describes you?** (`multiple_intelligence_survey_questions_20`, `select_multiple`, required: false): Select one or more of the following:
	+ **Spontaneous**
	+ **Determined**
	+ **Flexible**
* **Which of the following best describes you?** (`multiple_intelligence_survey_questions_22`, `select_multiple`, required: false): Choose one or more of the following:
	+ **Spontaneous**
	+ **Determinant**
	+ **Flexible**
* **Which of the following best describes you?** (`multiple_intelligence_survey_questions_23`, `select_multiple`, required: false): Select one or more of the following:
	+ **Imaginative**
	+ **Logical**
	+ **Spontaneous**

## Tips

* Answer honestly and accurately to ensure the results reflect your true self-perception.
* You can select multiple options for questions that allow multiple selections.
* Take your time to review each question carefully and select the option that best fits you.
