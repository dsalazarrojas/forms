# it_service_desk_feedback_questionnaire - Help Guide
## Purpose
This form is designed to capture feedback from customers or users about their experience with an IT service desk.

## How To Complete This Form
To complete this form, simply follow the instructions below:

1. Review the form carefully and fill out each field as prompted.
2. If a field is not required, you can leave it blank or enter a default value if specified.
3. Be as detailed as possible when answering each question.

## Field-by-Field Explanation
### Introduction (Page 1)
* **Introduction** (`introduction`, `note`, no): This is just a brief welcome message to help you understand the purpose of the form.

### Feedback Type (Page 2)
* **Feedback Type** (`feedback_type`, `select_one`, no): Please select one of the following options:
	+ IT: related to IT services
	+ Non-IT: not related to IT services

### Feedback Date (Page 3)
* **Feedback Date** (`feedback_date`, `date`, no): Please enter the date of the issue.

### Contact Number (Page 4)
* **Contact Number** (`contact_number`, `text`, no): If you have a contact number, please enter it here.

### Feedback Details (Page 5)
* **Feedback Details** (`feedback_details`, `text`, no): Please provide a brief description of the issue you experienced.

### Issue Description (Page 6)
* **Issue Description** (`issue_description`, `text`, no): Provide a detailed description of the issue you experienced.

### Support Type (Page 7)
* **Support Type** (`support_type`, `select_one`, no): Please select one of the following options:
	+ Phone: phone call or voice support
	+ Email: email support
	+ Chat: live chat support

### Resolution Status (Page 8)
* **Resolution Status** (`resolution_status`, `select_one`, no): Please select one of the following options:
	+ Not Solved: issue not yet resolved
	+ Solved: issue resolved
	+ Pending: issue still pending resolution

### Resolution Time (Page 9)
* **Resolution Time** (`resolution_time`, `number`, no): If applicable, enter the time taken to resolve the issue.

### Satisfaction Level (Page 10)
* **Satisfaction Level** (`satisfaction_level`, `select_one`, no): Please select one of the following options:
	+ Very Dissatisfied
	+ Neutral
	+ Satisfied
	+ Very Satisfied

### Comments (Page 11)
* **Comments** (`comments`, `text`, no): Do you have any additional comments or feedback?

### Contact Email (Page 12)
* **Contact Email** (`contact_email`, `email`, no): If you have a contact email, please enter it here.

### Contact Phone (Page 13)
* **Contact Phone** (`contact_phone`, `text`, no): If you have a contact phone number, please enter it here.

### Support Agent (Page 14)
* **Support Agent** (`support_agent`, `text`, no): If you had a support agent, please enter their name or initials.

### Issue Category (Page 15)
* **Issue Category** (`issue_category`, `select_one`, no): Please select one of the following options:
	+ Hardware: hardware-related issues
	+ Software: software-related issues
	+ Network: network-related issues
	+ Security: security-related issues
	+ Other: other issues

### Resolution Method (Page 16)
* **Resolution Method** (`resolution_method`, `select_one`, no): Please select one of the following options:
	+ In-person: in-person support
	+ Phone Call: phone call support
	+ Chat: live chat support
	+ Email: email support
	+ Other: other methods

### Resolution Details (Page 17)
* **Resolution Details** (`resolution_details`, `text`, no): Provide any additional details about the resolution.

### Follow Up Status (Page 18)
* **Follow Up Status** (`follow_up_status`, `select_one`, no): Please select one of the following options:
	+ True: follow up required
	+ False: no follow up required

### Follow Up Date (Page 19)
* **Follow Up Date** (`follow_up_date`, `date`, no): If follow up is required, enter the date.

### Next Follow Up Date (Page 20)
* **Next Follow Up Date** (`next_follow_up_date`, `date`, no): If follow up is required, enter the next follow up date.

### Follow Up Notes (Page 21)
* **Follow Up Notes** (`follow_up_notes`, `text`, no): If follow up is required, please enter any follow up notes.

### Follow Up Contact Number (Page 22)
* **Follow Up Contact Number** (`follow_up_contact_number`, `text`, no): If follow up is required, enter the contact number.

### Follow Up Contact Email (Page 23)
* **Follow Up Contact Email** (`follow_up_contact_email`, `email`, no): If follow up is required, enter the contact email.

### Follow Up Contact Name (Page 24)
* **Follow Up Contact Name** (`follow_up_contact_name`, `text`, no): If follow up is required, enter the contact name.

### Follow Up Resolution Status (Page 25)
* **Follow Up Resolution Status** (`follow_up_resolution_status`, `select_one`, no): If follow up is required, please select one of the following options:
	+ Solved
	+ Not Solved
	+ Pending

### Follow Up Resolution Method (Page 26)
* **Follow Up Resolution Method** (`follow_up_resolution_method`, `select_one`, no): If follow up is required, please select one of the following options:
	+ In-person
	+ Phone Call
	+ Chat
	+ Email
	+ Other

### Follow Up Resolution Details (Page 27)
* **Follow Up Resolution Details** (`follow_up_resolution_details`, `text`, no): If follow up is required, provide any additional details about the resolution.

## Tips
