# Five Key Insights Survey - Help Guide
## Purpose
The "Five Key Insights Survey" is designed to gather five brief descriptions of the takeaways or lessons learned from a project. This form is suitable for users who want to provide a quick snapshot of their experience with a project.

## How To Complete This Form
To complete the "Five Key Insights Survey", follow these steps:

1. Enter the title of the project in the "Project Title" field.
2. Provide a brief description of the project in the "Project Description" field.
3. Enter a brief description for each of the five "Takeaway" fields.
4. Add any additional comments about your experience with the project in the "Comments" field.

## Field-by-Field Explanation
* **Project Title** (`survey_title`, text, optional): Enter a brief title for the project.
* **Project Description** (`survey_project_description`, text, optional): Provide a brief description of the project.
* **Takeaway 1** (`survey_takeaway_1`, text, optional): Enter a brief description of what you learned or took away from this project.
* **Takeaway 2** (`survey_takeaway_2`, text, optional): Enter a brief description of what you learned or took away from this project.
* **Takeaway 3** (`survey_takeaway_3`, text, optional): Enter a brief description of what you learned or took away from this project.
* **Takeaway 4** (`survey_takeaway_4`, text, optional): Enter a brief description of what you learned or took away from this project.
* **Comments** (`survey_comments`, text, optional): Add any additional comments about your experience with the project.

## Tips
* Please keep each "Takeaway" field brief and to the point.
* Do not provide detailed project reports.
* The form should take less than 5 minutes to complete.
* If you are unsure about any field, please contact form@gic.mx.
