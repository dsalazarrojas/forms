# Technical Mapping Survey - Help Guide
## Purpose

This guide will help you complete the Technical Mapping Survey form, which is designed to gather data on project types, tools, and challenges faced by project teams. The form consists of multiple sections, each covering a different aspect of project management.

## How To Complete This Form

1. Select the project type from the drop-down menu in the "Project Types" section.
2. In the "Tools Used" section, type the tools used in your project, separated by commas.
3. In the "Challenges Faced" section, select all the challenges you faced during your project from the drop-down menu.
4. In the "Project Challenges" sections, select the challenges you faced during your project.
5. In the "Project Tools" sections, select the tools you used for your project.

## Field-by-Field Explanation

* **Project Types** (Select One, Required): This section asks you to select the type of project you are working on. The options include "Project types" and "Other."
* **Tools Used** (Text, Optional): This section allows you to type the tools used in your project, separated by commas.
* **Challenges Faced** (Select Multiple, Required): This section asks you to select all the challenges you faced during your project.
* **Project Challenges 2-13** (Select One, Required): These sections ask you to select the challenges you faced during your project.
* **Project Tools 2-10** (Select One, Required): These sections ask you to select the tools you used for your project.

## Tips

* Make sure to select all the challenges and tools that apply to your project.
* Be as specific as possible when typing the tools used in your project.
* If you are unsure about any of the challenges or tools, select "Other" or "Unknown" and provide a brief explanation in the "Tools Used" section.
* This form is meant for high-level reporting and comparison purposes, so try to keep your answers concise but accurate.
