# Monument Sign Installation Survey Form - Help Guide
## Purpose
The Monument Sign Installation Survey Form is designed to gather information about monument sign installations. This form helps users understand the current state of these installations, enabling informed decision-making for future planning and execution.

## How To Complete This Form
To complete this form, follow the steps below:

1. Fill in the project details in the "Project Details" field.
2. Indicate the project's location by selecting "Yes" or "No" from the "Project Location" dropdown menu.
3. Provide contact details for the project in the "Contact Details" field.
4. Enter any site survey information in the "Site Survey" field.
5. Enter the installation schedule in the "Installation Schedule" field.
6. Select the current project status as "Active" or "Inactive" from the "Project Status" dropdown menu.
7. Enter any notes or comments about the project in the "Notes" field.
8. Identify the contact person responsible for the project in the "Contact Person" field.
9. Enter the email address of the contact person in the "Email" field.
10. Enter the phone number of the contact person in the "Phone" field.
11. Indicate the installation status as "Active" or "Inactive" from the "Installation Status" dropdown menu.

## Field-by-Field Explanation

* **Project Details** (text): Enter a brief description of the project, including the project name and ID.
* **Project Location** (select multiple): Indicate whether the project location is active or not. This will help us understand if the project is currently being worked on.
* **Contact Details** (text): Enter the name and contact information of the person responsible for the project.
* **Site Survey** (text): Enter any site survey information, including any observations or recommendations.
* **Installation Schedule** (text): Enter the schedule for the installation, including start and end dates.
* **Project Status** (select one): Select the current status of the project as either "Active" or "Inactive".
* **Notes** (text): Enter any additional comments or notes about the project.
* **Contact Person** (text): Enter the name of the contact person responsible for the project.
* **Email** (email): Enter the email address of the contact person.
* **Phone** (text): Enter the phone number of the contact person.
* **Installation Status** (select multiple): Indicate the status of the installation as "Active" or "Inactive".

## Tips

* Ensure that all fields are completed accurately and thoroughly to avoid any confusion or misinterpretation of the collected data.
* If a field is not applicable, select "None" from the dropdown menu or leave it blank.
* If you're unsure about any field, please consult the relevant team member or project manager for guidance.
