# Decision Follow Up Survey - Help Guide

## Purpose
This form is designed to gather information about the progress and satisfaction of a project or issue that has undergone a decision-making process. The survey is intended to be completed by stakeholders after the decision has been made to ensure that all parties are on the same page and that the decision aligns with the needs and expectations of all stakeholders.

## How To Complete This Form

1. Select the survey sections that apply to your situation by answering the questions in each section.

## Field-by-Field Explanation

* **Survey Leader** (`survey_leader`, select_one, required): Please select who was primarily responsible for making the decision.
	+ Answer 'Yes' if you were the decision leader.
	+ Answer 'No' otherwise.
* **Survey HR** (`survey_hr`, select_one, required): Please select if HR was involved in the decision-making process.
	+ Answer 'Yes' if HR was involved.
	+ Answer 'No' otherwise.
* **Project Team** (`project_team`, select_multiple, optional): Select all the team members that were involved in the decision-making process.
	+ Select 'Yes' for each team member that contributed to the decision.
* **Decision Date** (`decision_date`, date, required): Please enter the date when the decision was made.
* **Decision Leader** (`decision_leader`, select_one, required): Please select who made the decision.
	+ Answer 'Yes' if the person is the decision leader.
	+ Answer 'No' otherwise.
* **Follow Up Date** (`follow_up_date`, date, required): Please enter the date when follow-up actions were taken.
* **Follow Up Frequency** (`follow_up_frequency`, select_multiple, optional): Select all the frequencies at which follow-up actions were taken.
	+ Select 'Yes' for each frequency.
* **Follow Up Method** (`follow_up_method`, select_multiple, optional): Select all the methods used for follow-up actions.
	+ Select 'Yes' for each method.
* **Follow Up Leader** (`follow_up_leader`, select_one, required): Please select who led the follow-up actions.
	+ Answer 'Yes' if the person is the follow-up leader.
	+ Answer 'No' otherwise.
* **Follow Up Satisfaction** (`follow_up_satisfaction`, select_one, required): Please select the level of satisfaction with the follow-up actions.
	+ Select 'Satisfied' if you're satisfied with the follow-up actions.
	+ Select 'Dissatisfied' otherwise.
* **Follow Up Impact** (`follow_up_impact`, select_one, required): Please select if the follow-up actions had an impact.
	+ Answer 'Yes' if the actions had an impact.
	+ Answer 'No' otherwise.
* **Follow Up Suggestions** (`follow_up_suggestions`, text, optional): Please provide any suggestions for improvement or areas for follow-up.
	+ Enter your suggestions here.

## Tips
* Make sure to answer all the required fields, marked with a *.
* For select multiple fields, select all the options that apply.
* If you're unsure about any of the fields, please ask your team lead or contact your project manager for clarification.
