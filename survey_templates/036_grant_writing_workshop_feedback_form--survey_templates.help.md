# Grant Writing Workshop Feedback Form - Help Guide

## Purpose
The Grant Writing Workshop Feedback Form is used by workshop participants to provide feedback on their experience at the grant writing workshop. This form helps the workshop organizers to understand what participants thought of the workshop, what they gained from it, and how it can be improved for future workshops.

## How To Complete This Form
To complete the form, please follow the following steps:

* Start by answering the questions regarding your experience and opinions on the workshop.
* Be as specific as possible when answering the open-ended questions, such as "What did you think of the grant writing workshop?".
* Select the options that best fit your answer to the multiple-choice questions.
* If you wish to provide additional feedback or comments, use the dedicated text fields.
* Finally, indicate your agreement or disagreement with the questions regarding contact and communication preferences.

## Field-by-Field Explanation

* **What did you think of the grant writing workshop?** (Grant Writing Workshop Feedback)
	+ This question is an open-ended question that allows you to provide a brief summary of your thoughts and feelings about the workshop.
* **What did you gain from the workshop?** (Grant Writing Workshop Feedback)
	+ This question is also open-ended, allowing you to share what you found useful or beneficial from the workshop.
* **What is your experience level with grant writing?** (Grant Writing Experience)
	+ This question is a multiple-choice question that helps us understand your level of expertise with grant writing.
	+ Select from: Grant Writing Beginner, Grant Writing Intermediate, Grant Writing Advanced
* **What topics would you like to see covered in future grant writing workshops?** (Grant Writing Workshop Topics)
	+ This question is a multiple-choice question that allows you to suggest topics that you would like to see covered in future workshops.
	+ Select all that apply: Grant Writing Basics, Grant Research and Development, Grant Writing for Non-Profits, Grant Writing for Government Agencies
* **How would you rate the grant writing workshop format?** (Grant Writing Workshop Format)
	+ This question is a multiple-choice question that asks you to rate the workshop format.
	+ Select from: Excellent, Good, Fair, Poor
* **How satisfied were you with the grant writing workshop?** (Grant Writing Workshop Satisfaction)
	+ This question is a multiple-choice question that asks you to rate your satisfaction with the workshop.
	+ Select from: Very Satisfied, Somewhat Satisfied, Neutral, Somewhat Dissatisfied, Very Dissatisfied
* **What suggestions do you have for improving the grant writing workshop?** (Grant Writing Workshop Improvement)
	+ This question is an open-ended question that allows you to provide specific suggestions for improving the workshop.
* **How satisfied are you with the overall satisfaction of the workshop attendees?** (Grant Writing Workshop Attendee Satisfaction)
	+ This question is a multiple-choice question that asks you to rate the overall satisfaction of the attendees.
	+ Select from: Very Satisfied, Somewhat Satisfied, Neutral, Somewhat Dissatisfied, Very Dissatisfied
* **How would you rate the satisfaction of participants in the workshop?** (Grant Writing Workshop Participant Satisfaction)
	+ This question is a multiple-choice question that asks you to rate the satisfaction of the participants.
	+ Select from: Excellent, Good, Fair, Poor
* **Would you like to be contacted for further inquiries?** (Grant Writing Workshop Further Inquiries)
	+ This question is a multiple-choice question that asks if you wish to be contacted for further inquiries.
	+ Select from: True, False
* **Additional comments** (Grant Writing Workshop Additional Comments)
	+ This question is an open-ended text field that allows you to provide any additional comments or feedback.
* **Email Address** (Grant Writing Workshop Email)
	+ This question is an open-ended text field that asks for your email address if you wish to be contacted via email.
* **Phone Number** (Grant Writing Workshop Phone)
	+ This question is an open-ended text field that asks for your phone number if you wish to be contacted via phone.
* **Grant Writing Workshop Comments** (Grant Writing Workshop Comments 2)
	+ This question is an open-ended text field that allows you to provide any additional comments or feedback.
* **Would you like to agree to participate in future grant writing workshops?** (Grant Writing Workshop Agreement)
	+ This question is a multiple-choice question that asks if you agree to participate in future workshops.
	+ Select from: True, False
* **Grant Writing Workshop Comments 2** (Grant Writing Workshop Comments 3)
	+ This question is an open-ended text field that allows you to provide any additional comments or feedback.
* **Would you like to agree to allow workshop organizers to contact you?** (Grant Writing Workshop Agreed 2)
	+ This question is a multiple-choice question that asks if you agree to allow workshop organizers to contact you.
	+ Select from: True, False
* **Grant Writing Workshop Email Agreed** (Grant Writing Workshop Email Agreed)
	+ This question is a multiple-choice question that asks if you agree to allow workshop organizers to contact you via email.
	+ Select from: True, False
* **Grant Writing Workshop Phone Agreed** (Grant Writing Workshop Phone Agreed)
	+ This question is a multiple-choice question that asks if you agree to allow workshop organizers to contact you via phone.
	+ Select from: True, False
