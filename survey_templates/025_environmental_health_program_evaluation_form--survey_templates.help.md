# Environmental Health Program Evaluation Form - Help Guide
## Purpose
This form is designed to gather information on the effectiveness and accessibility of an Environmental Health Program. It includes questions on program frequency, satisfaction, and accessibility, which are necessary to understand the program's impact and areas for improvement.

## How To Complete This Form

To complete this form, please follow these steps:

1. Review the form to ensure you understand each question and its relevance to the Environmental Health Program being evaluated.
2. Answer each question honestly and accurately, considering the options provided.
3. Make sure to provide clear and concise comments where applicable.

## Field-by-Field Explanation

* **Program Information** (`program_info`, text, required: false): Provide a brief description of the Environmental Health Program being evaluated.
* **Program Evaluation Frequency** (`program_frequency`, select_one, required: false): Indicate how often the program is evaluated, using the options: Never, Less than 1 time per year, 1 time per year, 2 or more times per year, More than 2 times per week.
* **Program Satisfaction** (`program_satisfaction`, select_multiple, required: false): Rate your satisfaction with the program, using the options: Very satisfied, Somewhat satisfied, Neither satisfied nor dissatisfied, Somewhat dissatisfied, Very dissatisfied.
* **Program Likes** (`program_likes`, text, required: false): Describe what you like about the program.
* **Program Use** (`program_use`, select_one, required: false): Indicate how often you use the program, using the options: Never, Less than 1 time per week, 1 time per week, 2 or more times per week, More than 2 times per week.
* **Program Access** (`program_access`, select_one, required: false): Indicate if you have access to the program, using the options: Yes, No, Unknown.
* **Program Access Method** (`program_access_method`, select_multiple, required: false): Describe the methods you use to access the program, using the options: Online, In-person, Over phone, Through email, Through other means.
* **Program Access Frequency** (`program_access_frequency`, select_one, required: false): Indicate how often you access the program, using the options: Never, Less than 1 time per week, 1 time per week, 2 or more times per week, More than 2 times per week.
* **24/7 Availability** (`program_24_7`, select_one, required: false): Indicate if the program is available 24/7, using the options: Yes, No, Unknown.
* **Program Languages** (`program_languages`, select_one, required: false): Indicate if the program is offered in multiple languages, using the options: Yes, No, Unknown.
* **Program Interest** (`program_interest`, select_one, required: false): Rate your interest in the program, using the options: High, Medium, Low, None.
* **Program Unavailability** (`program_unavailability`, text, required: false): Describe any unavailability issues you experience with the program.
* **Comments** (`program_comments`, text, required: false): Provide any additional comments or feedback about the program.

Note: This help guide is intended to be a general guidance, please refer to the actual form for specific questions and options.
