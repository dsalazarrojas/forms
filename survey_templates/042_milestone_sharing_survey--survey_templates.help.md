# Milestone Sharing Survey - Help Guide
## Purpose
This survey is designed to collect information about a specific project milestone.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the relevant information for each field based on your knowledge about the project.
2. Fill in the required fields, denoted by an asterisk (\*), for accurate and complete information.
3. Use the "Share With" field to determine who should receive updates about the milestone.
4. Enter any comments or additional information in the "Comment" fields.
5. Once you have filled in all the required fields, review your information for accuracy and completeness.
6. Submit the form to share the milestone information.

## Field-by-Field Explanation

* **Team Member** (text): Enter the name of the team member responsible for the project.
* **Project ID** (number): Enter the project ID number.
* **Project Name** (text): Enter the name of the project.
* **Project Manager** (text): Enter the name of the project manager.
* **Date Completed** (date): Enter the date the project was completed.
* **Time Completed** (time): Enter the time the project was completed.
* **Description** (text): Enter a brief description of the project.
* **Type of Project** (select_one): Select the type of project (Project, Program, Department).
* **Department** (select_one): Select the department involved in the project.
* **Team Lead** (text): Enter the name of the team lead.
* **Status** (select_multiple): Select the status of the milestone (Active, Completed, Pending, Cancelled).
* **Team Lead Comment** (text): Enter any comments from the team lead.
* **Manager Comment** (text): Enter any comments from the project manager.
* **Milestone Value** (number): Enter the value of the milestone.
* **Share With** (select_multiple): Select who should receive updates about the milestone (Project, Team, Department, Manager).
* **Milestone Value Comment** (text): Enter any additional comments about the milestone value.
* **Date** (date): Enter the date of the milestone.
* **Time** (time): Enter the time of the milestone.
* **Date Range** (date): Enter the date range for the milestone.
* **Time Range** (time): Enter the time range for the milestone.
* **Value Range** (number): Enter the value range for the milestone.
* **Share With Range** (select_multiple): Select who should receive updates about the milestone range (Project, Team, Department, Manager).
* **Manager Comment Range** (text): Enter any comments from the project manager for the milestone range.
* **Status Range** (select_multiple): Select the status of the milestone range (Active, Completed, Pending, Cancelled).
* **Milestone Comment** (text): Enter any additional comments about the milestone.
