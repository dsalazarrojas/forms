# Distance Learning Program Evaluation - Help Guide
## Purpose
This form is designed to gather feedback and evaluations from participants about their experience with the distance learning program.

## How To Complete This Form
To complete this form, follow these steps:

1. Review the form carefully and ensure you have the necessary information to complete each section.
2. Answer each question truthfully and to the best of your ability.
3. Use the available options to select your responses, or type in your own text if necessary.
4. Submit your completed form when you are finished.

## Field-by-Field Explanation

* **Course Title** (`course_title`, **required**, text): Enter the title of the course you are evaluating.
* **Course Description** (`course_description`, **required**, text): Enter a brief description of the course.
* **Course Format** (`course_format`, **required, select_one): Select the format of the course (Online video course, In-person course, Hybrid course, Other).
* **Course Outcomes** (`course_outcomes`, **required, text): Describe the outcomes or learning objectives of the course.
* **List of Course Outcomes** (`course_outcomes_list`, **optional, note): Note: This is a free-form field for additional information.
* **Course Outcomes List Items** (`course_outcomes_list_items`, **optional, select_multiple): Select all applicable outcomes.
* **Goals** (`goals`, **required, text): Describe your goals for taking the course.
* **Goals List** (`goals_list`, **optional, note): Note: This is a free-form field for additional information.
* **Goals List Items** (`goals_list_items`, **optional, select_multiple): Select all applicable goals.
* **Course Content** (`course_content`, **required, text): Describe the course content.
* **Course Content List** (`course_content_list`, **optional, note): Note: This is a free-form field for additional information.
* **Course Content List Items** (`course_content_list_items`, **optional, select_multiple): Select all applicable course content.
* **Overall Satisfaction** (`overall_satisfaction`, **required, number): Rate your overall satisfaction with the course on a scale of 1-10.
* **Overall Satisfaction List** (`overall_satisfaction_list`, **optional, note): Note: This is a free-form field for additional information.
* **Overall Satisfaction List Items** (`overall_satisfaction_list_items`, **optional, select_one): Select all applicable overall satisfaction.
* **Recommend** (`recommend`, **required, select_one): Indicate if you would recommend the course.
* **Feedback** (`feedback`, **optional, text): Provide any additional feedback about the course.
* **Feedback List** (`feedback_list`, **optional, note): Note: This is a free-form field for additional information.
* **Course Satisfaction** (`course_satisfaction`, **required, number): Rate your satisfaction with the course on a scale of 1-5.
* **Course Satisfaction List** (`course_satisfaction_list`, **optional, note): Note: This is a free-form field for additional information.
* **Course Satisfaction List Items** (`course_satisfaction_list_items`, **optional, select_one): Select all applicable course satisfaction.
* **Additional Comments** (`additional_comments`, **optional, text): Provide any additional comments about the course.
* **Additional Comments List** (`additional_comments_list`, **optional, note): Note: This is a free-form field for additional information.
* **Additional Comments List Items** (`additional_comments_list_items`, **optional, text): Note: This is a free-form field for additional information.
