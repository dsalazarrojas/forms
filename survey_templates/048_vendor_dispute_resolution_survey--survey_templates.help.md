# Vendor Dispute Resolution Survey - Help Guide
## Purpose
This form is used to collect information about a vendor dispute from the user's perspective. It is meant to be a tool for resolving the dispute in a structured and organized manner.

## How To Complete This Form
To complete this form, simply fill out each page as instructed, and be as detailed and accurate as possible in your responses. Each page has its own set of instructions and fields to fill out. If you are unsure about any of the fields, please refer to the Field-by-Field Explanation section below.

## Field-by-Field Explanation

* **First Page (1)**: This is the introduction page, which explains the purpose and instructions for the form. Please read and agree to the terms before proceeding.
* **Vendor Dispute Report (2)**: This field is where you can describe the dispute in detail. Please be as thorough as possible and provide any relevant information about the incident.
* **Supporting Documents (3)**: Indicate if you have any supporting documents that may help resolve the dispute. This can include emails, photos, or any other relevant evidence.
* **Satisfaction Feedback (4)**: This field is meant to gather feedback on your satisfaction with the current situation. Please select the option that best describes your feelings.
* **Second Page (5)**: This page is used to provide the date of the dispute, which is a required field. Please enter the date in the format MM/DD/YYYY.
* **Phone Number (6)**: This is a required field where you can enter your phone number, which will be used for further contact and communication.
* **Email (7)**: This field is optional, but please enter your email address if you have one, as it will be used for further communication and updates.
* **Vendor (8)**: Indicate if you are currently working with a vendor or not. This will help us understand the context of the dispute.
* **Operations Manager (9)**: Indicate if the operations manager is involved or not. This will help us understand the scope of the dispute.
* **Procurement Manager (10)**: Indicate if the procurement manager is involved or not. This will help us understand the scope of the dispute.
* **Supporting Document 1-14 (11-25)**: Each of these fields is used to indicate if you have any supporting documents related to the dispute. Please select "Yes" if you have any documents, and "No" if you do not.

Note: This form is designed to be filled out in the order of the pages, from page 1 to page 5, and then back to page 6 to 25. Please follow the instructions and complete the form as instructed.
