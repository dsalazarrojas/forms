# Extension Pre Consultation Survey - Help Guide
## Purpose
The Extension Pre Consultation Survey is designed to gather project-related information from users to facilitate a productive pre-consultation process with architects. It helps architects understand project goals, budget, scheduling preferences, and other key aspects, enabling them to provide more informed guidance.

## How To Complete This Form
To complete this form, please follow these steps:

1. Answer each question thoroughly and accurately to the best of your abilities.
2. Review each field to ensure you have provided the necessary information.
3. Click submit once you have completed all fields.

## Field-by-Field Explanation
### 1. **Project Goals** (text, optional)
Project Goals: A brief description of the project's objectives and requirements.

### 2. **Project Budget** (number, optional)
Project Budget: The estimated budget for the project.

### 3. **Scheduling Preferences** (select_multiple, optional)
Select all the scheduling preferences that apply: 
* Option 1
* Option 2
* Option 3

### 4. **Project Location** (text, optional)
Project Location: A brief description of the project's location.

### 5. **Project Type** (select_one, optional)
Select the type of project:
* Option A
* Option B
* Option C

### 6. **Contact Details** (email, optional)
Contact Details: A valid email address for contact purposes.

### 7. **Phone Number** (text, optional)
Phone Number: A valid phone number for contact purposes.

### 8. **Project Start Date** (date, optional)
Project Start Date: The date when the project is expected to start.

### 9. **Project Finish Date** (date, optional)
Project Finish Date: The date when the project is expected to finish.

### 10. **Architect Comments** (text, optional)
Architect Comments: Any additional comments or information for the architect's reference.

## Tips
* Please ensure that all fields are filled with accurate and relevant information.
* Review each field to guarantee that the architect has a comprehensive understanding of your project.
* If you have any questions or concerns, feel free to contact us for assistance.
