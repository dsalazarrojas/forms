# Social Media Data Collection Form - Help Guide
## Purpose
This form is designed to collect data from social media platforms to understand their usage and data collection practices.

## How To Complete This Form
To complete this form, please follow the instructions below:

1. Select whether you use social media platforms for data collection.
2. Provide your handle (username) if you use social media platforms.
3. If you use social media platforms, please provide your follower count.
4. Select whether your account purpose is data collection or another reason.
5. (Optional) If you wish, you can provide additional comments or explanations about the drag and drop interface and no-code form builder.

## Field-by-Field Explanation

* **Social Media Data Collection** (`social_media_data_collection_form_page_1`): 
  This field is a select multiple field that asks whether you use social media platforms for data collection. Please select one or more options that apply to you.
* **Handle** (`handle`): 
  This field is a text field that asks for your social media handle (username). Please enter your handle as it appears on the social media platform.
* **Follower Count** (`follower_count`): 
  This field is a number field that asks for your follower count on social media platforms. Please enter a whole number that represents your follower count.
* **Account Purpose** (`account_purpose`): 
  This field is a select one field that asks whether your account purpose is data collection or another reason. Please select the option that best describes your account purpose.
* **Drag and Drop Interface** (`drag_and_drop_interface`): 
  This field is a note field where you can provide any comments or explanations about the drag and drop interface. If you do not have any comments or explanations, you can leave this field blank.
* **No-code Form Builder** (`no_code_form_builder`): 
  This field is a note field where you can provide any comments or explanations about the no-code form builder. If you do not have any comments or explanations, you can leave this field blank.
* **Organized Data Collection** (`organized_data_collection`): 
  This field is a note field where you can provide any comments or explanations about the organized data collection. If you do not have any comments or explanations, you can leave this field blank.
* **Account Purpose** (`account_purpose_select`): 
  This field is a select multiple field that asks whether your account purpose is data collection or another reason. Please select one or more options that apply to you.

## Tips
Please note that you can skip any fields that do not apply to your situation. If you have any further questions or concerns, please do not hesitate to contact us.
