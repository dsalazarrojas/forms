# Learning Experience Survey - Help Guide
## Purpose
The purpose of this form is to gather feedback from users about their recent learning experience. Your input will help us identify areas of improvement and make informed decisions to enhance your learning experience.

## How To Complete This Form

1. Please fill out the form in a single sitting, as it is not designed to be completed over multiple sessions.
2. Answer each question to the best of your ability.
3. Do not repeat answers to questions that have already been completed.
4. If you are not sure about any question, please provide a brief explanation.

## Field-by-Field Explanation

* **What did you learn?** (`page_1`, `text`, required): This is the first page of the form where you will be asked about the learning experience. Please provide a brief description of what you learned during the activity.
* **How do you feel about the experience** (`page_2`, `note`, optional): This section is for you to provide any comments or thoughts about the learning experience. You can write as much or as little as you like.
* **How did you get to know this?** (`page_3`, `select_one`, required): This question is about how you discovered this learning activity. Please select one of the provided options:
	+ Yes
	+ No
* **How do you think you could improve the experience?** (`page_4`, `select_multiple`, optional): This section is for you to suggest ways the learning experience could be improved. You can select multiple options:

	+ Yes
	+ No
