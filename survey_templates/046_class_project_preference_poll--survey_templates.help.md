# Class Project Preference Poll - Help Guide
## Purpose
This form is designed to collect student preferences for a class project. It helps the class instructor understand individual students' interests, needs, and expectations for the project, ensuring that each student can work on a project that suits them best.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill out your name and email address in the first two fields.
2. Choose your class and select the type of project you prefer.
3. Select your top interest area and choose a specific topic if you have one.
4. Choose your preferred group size and whether you have any partner preferences.
5. Select your preferred project duration and presentation format.
6. Check any resources you'll need for the project.
7. Choose when you'd prefer to work on the project.
8. Select any skills you'd like to showcase.
9. Describe any learning goals you hope to achieve.
10. If you have any concerns, write them down.
11. Finally, rate your excitement level for the project and provide any additional comments or ideas.

## Field-by-Field Explanation

* **Your Name** (1): Please enter your first and last name.
* **Email Address** (2): Enter your school email address so we can reach you.
* **Class Name** (3): Choose the name of your class (e.g., "Class A", "Class B", etc.).
* **What Type of Project Do You Prefer** (4): Select one from the list:
	+ Research paper
	+ Group presentation
	+ Creative project
	+ Case study analysis
	+ Build or prototype
	+ Community service project
	+ Multimedia project
	+ Debate or discussion
* **Which Topic Interests You Most** (5): Select one from the list:
	+ Current events and society
	+ Science and technology
	+ History and culture
	+ Arts and literature
	+ Business and economics
	+ Health and wellness
	+ Environment and sustainability
	+ Open to any topic
* **Do You Have a Specific Topic in Mind** (6): If you have a topic in mind, describe it briefly.
* **What Group Size Do You Prefer** (7): Select one from the list:
	+ Individual project
	+ Pair (2 students)
	+ Small group (3-4 students)
	+ Medium group (5-6 students)
	+ Large group (7+ students)
* **Do You Have Partner Preferences** (8): If you'd like to work with specific classmates, describe them here.
* **What Project Duration Do You Prefer** (9): Select one from the list:
	+ 1 week
	+ 2 weeks
	+ 3-4 weeks
	+ Full semester
	+ No preference
* **How Would You Prefer to Present** (10): Select one from the list:
	+ In-person presentation
	+ Video presentation
	+ Written report only
	+ Poster or display
	+ Digital portfolio
	+ Live demonstration
* **What Resources Will You Need** (11): Check all resources you'll need for the project.
	+ Library research access
	+ Computer lab access
	+ Art supplies
	+ Recording equipment
	+ Software access
	+ Meeting space
	+ Budget for materials
	+ No special resources
* **When Would You Prefer to Work** (12): Select all times when you'd prefer to work on the project.
	+ During class time
	+ After school
	+ Evenings
	+ Weekends
	+ Flexible schedule
* **What Skills Would You Like to Showcase** (13): Select all skills you'd like to use for the project.
	+ Writing
	+ Public speaking
	+ Research
	+ Design
	+ Technology
	+ Leadership
	+ Creativity
	+ Analysis
* **What Do You Hope to Learn** (14): Describe what you hope to learn from this project.
* **Do You Have Any Concerns** (15): If you have any concerns, write them down.
* **How Excited Are You About This Project** (16): Select one from the list:
	+ Very excited
	+ Excited
	+ Neutral
	+ Not very excited
	+ Not excited at all
* **Additional Comments or Ideas** (17): Share any additional comments or ideas you have about the project.

## Tips
* Be honest and open in your responses to ensure the class instructor can tailor the project to your needs.
* If you're unsure about any field, feel free to ask the instructor for guidance.
* Remember to check the required fields as they are crucial for the project setup.
