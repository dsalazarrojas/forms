This help guide is for the "Memory Book Submission Form". The form is used to collect memories and experiences from users, which will be compiled into a digital "memory book" for a specified purpose or project. This form is not intended for general public use, so please ensure you are authorized to access and submit this form.

## Memory Book Submission Form - Help Guide
## Purpose
This form is used to collect personal memories and experiences that will be compiled into a digital "memory book" for a specified purpose or project. This helps the project's creators to gather unique and personal stories that will contribute to the overall story of the project.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter your name in the "What is your name" field. This is a required field.
2. Select a year from the "Year" field. This is an optional field.
3. In the "What is your story" field, type a short description of your memory or experience. This is a required field.
4. If you have a photo related to your memory, you can upload it in the "Photo" field. This is a required field.
5. For each "Other notes" field, type any additional details or information that you want to share about your memory or experience. These fields are optional.

## Field-by-Field Explanation
* **What is your name** (`memory_book_submission_form`, text, required): Enter your name as it should be displayed in the memory book.
* **Year** (`memory_book_year`, number, optional): Select the year when your memory or experience happened.
* **What is your story** (`memory_book_story`, text, required): Type a short description of your memory or experience.
* **Photo** (`memory_book_photo`, text, required): If you have a photo related to your memory, upload it here.
* **Location** (`memory_book_location`, text, optional): If you want to share the location where your memory or experience happened, type it here.
* **Relationship to me** (`memory_book_relation`, select_one, required): Choose how you are related to the person or project associated with this memory book. Options are: 'Yes', 'No'.
* **Relationship to me options** (`memory_book_relation_options`, select_multiple, optional): If you are related to the person or project, select which options apply to you. Options are: 'Yes', 'No'.
* **Credit for photo** (`memory_book_photo_credit`, text, optional): If you want to give credit for the photo, type it here.
* **Other notes** (`memory_book_other_notes`, note, optional): Type any additional details or information that you want to share about your memory or experience.
* **Other notes 1-16** (`memory_book_other_notes_1`, `memory_book_other_notes_10`, note, optional): These are additional fields for any other notes or information you want to share about your memory or experience.

Note: This form is for collecting memories and experiences. Please be honest and respectful when submitting your content.
