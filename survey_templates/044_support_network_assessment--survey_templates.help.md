# Support Network Assessment - Help Guide
## Purpose
The Support Network Assessment is a form used to gather information on an individual's relationships and sources of support. This information is crucial in understanding the strength and depth of their support network.

## How To Complete This Form
To complete this form, follow these steps:

1. Review each page carefully and ensure you understand the questions being asked.
2. Answer each question honestly and thoroughly, providing as much detail as possible.
3. If you are unsure about any question, use the provided options or add any additional information in the "Other" fields.

## Field-by-Field Explanation

* **Introduction (Page 1)**: This page is a brief introduction to the form and its purpose. Please read it carefully before proceeding.
* **support_system (Page 2)**: This field asks about your support system, which refers to the people or services you rely on for emotional, financial, or practical support. Please provide any relevant information you have.
* **network_size (Page 3)**: This field asks about the size of your support network, which refers to the number of people you rely on for support. Please provide a number that best represents your network size.
* **network_type (Page 4)**: This field asks about the type of network you have, which can be Primary, Secondary, or Tertiary. Please select the option that best describes your network.
* **relationship_type (Page 5)**: This field asks about the types of relationships you have within your support network, which can be Family, Friend, or Other. Please select all that apply.
* **relationship_depth (Page 6)**: This field asks about the depth of your relationships, which can be Shallow, Medium, or Deep. Please select the option that best describes your relationships.
* **primary_contact (Page 7)**: This field asks about your primary contact within your support network, which can be a family member or friend. Please select one option.
* **secondary_contact (Page 8)**: This field asks about your secondary contact within your support network, which can be a family member or friend. Please select one option.
* **support_level (Page 9)**: This field asks about the level of support you receive from your network, which can be Emotional, Financial, or Practical. Please select all that apply.
* **support_source (Page 10)**: This field asks about the source of your support, which can be Family, Friend, Community, or Other. Please select one option.
* **support_level_other (Page 11)**: This field is for any additional support level not listed in the previous field.
* **frequency (Page 12)**: This field asks about how often you receive support from your network, which can be Rare, Occasional, Often, or Frequently. Please select all that apply.
* **support_type (Page 13)**: This field asks about the type of support you receive, which can be Emotional, Financial, or Practical. Please select one option.
* **support_type_other (Page 14)**: This field is for any additional support type not listed in the previous field.
* **need_level (Page 15)**: This field asks about your level of need within your support network, which can be Low, Medium, or High. Please select one option.
* **support_system_other (Page 16)**: This field is for any additional information about your support system not listed in the previous fields.
* **network_size_other (Page 17)**: This field is for any additional information about the size of your support network not listed in the previous fields.
* **support_source_other (Page 18)**: This field is for any additional information about the source of your support not listed in the previous fields.

Note: Please provide as much detail as possible for each field, and if you are unsure about any question, please use the "Other" fields to provide additional information.
