# Event Reflection Survey - Help Guide
## Purpose
This survey is designed to gather information and feedback from attendees after an event or activity has taken place. The goal is to improve future events and activities based on attendee experiences.

## How To Complete This Form
- Please provide feedback on your overall experience with the event.
- Respond to the questions and select the relevant answers for each section.
- If you have suggestions or comments, please use the text fields or select the option "Other" for suggestions.
- If you would like to rate the event, select one of the provided options for the "Rating" field.
- Ensure you enter a valid email address and phone number if you would like to be contacted for future events.

## Field-by-Field Explanation

* **Event Feedback** (`Event Feedback`, text, optional): This field is for providing a brief description of your experience with the event. Please be as detailed as possible.
* **Event Attendance** (`Event Attendance`, select multiple, optional): Indicate whether you attended the event. You can select multiple options if applicable.
* **Event Participation** (`Event Participation`, number, optional): Please enter a numerical value to indicate your level of participation in the event.
* **Reflection** (`Reflection`, text, optional): This field is for sharing your thoughts and reflections on the event. Please provide any insights or observations that might be helpful for improvement.
* **Suggestions** (`Suggestions`, text, optional): If you have any suggestions for future events, please enter them here. You can also select "Other" if you want to provide more specific feedback.
* **Rating** (`Rating`, select one, optional): Select one of the provided options to rate your overall satisfaction with the event.
* **Comments** (`Comments`, note, optional): This field is for providing additional comments or explanations for your rating.
* **Attended** (`Attended`, select one, optional): Indicate whether you attended the event. Please note that this field is not necessarily linked to the "Event Attendance" field.
* **Email** (`Email`, email, optional): Please enter a valid email address if you would like to be contacted for future events.
* **Phone** (`Phone`, text, optional): Enter your phone number if you want to be contacted for future events.
* **Assigned Tool** (`Assigned Tool`, select one, optional): Select the tool that was assigned to you for the event. If unsure, select "Other".
