# Image Upload For Recognition - Help Guide
## Purpose
This form is designed for uploading images and their descriptions for recognition purposes.

## How To Complete This Form
To complete this form, follow these steps:

1. Upload an image using the "Upload Image" field.
2. Provide a description of the image in the "Image Description" field.
3. If required, upload additional image metadata in the "Upload File" field.

## Field-by-Field Explanation

* **Upload Image**: 
Upload a single image from your computer or device. This field is used to collect the image for recognition purposes.

* **Image Description**: 
Provide a brief description of the image. This description will help with image recognition and categorization.

* **Upload File**: 
Upload a text file containing additional image metadata. This field is optional and is used to provide more detailed information about the image.

## Tips
- Make sure to upload only one image at a time.
- Be concise with the image description to ensure accurate recognition.
- If you need to upload additional image metadata, use the "Upload File" field.
- If you have any questions or need further clarification, contact form@gic.mx.
