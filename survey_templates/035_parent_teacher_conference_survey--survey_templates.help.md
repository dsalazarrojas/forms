# parent-teacher-conference-survey - Help Guide

## Purpose
This form is designed to collect information about the parent-teacher conference survey. It is an essential tool for schools to gather feedback and insights from parents and teachers. The purpose of this form is to facilitate open communication and understanding between parents and educators.

## How To Complete This Form
To complete this form, please follow these steps:

1. Select the category that best suits the purpose of the survey.
2. Provide a brief description of the survey.
3. Choose the tool assigned to the survey (e.g., ChatJimmy).
4. Select the output file type for the results.
5. (Optional) Select any additional categories and descriptions relevant to the survey.

## Field-by-Field Explanation

* **Category** (`category`, select_one, Required: False): Select the category that best suits the purpose of the survey.
* **Description** (`description`, text, Required: False): A brief description of the survey, helping others understand its context and relevance.
* **Assigned Tool** (`assigned_tool`, select_one, Required: False): Choose the tool assigned to the survey, such as ChatJimmy.
* **Output File** (`output_file`, text, Required: False): Select the type of output file for the results, such as CSV or PDF.
* **Category 2** (`category_2`, select_multiple, Required: False): (Optional) Select any additional categories relevant to the survey.
* **Description 2** (`description_2`, text, Required: False): (Optional) Provide a brief description of the additional categories.
* **Form Id 2** (`form_id_2`, number, Required: False): (Optional) Enter a unique form ID for the survey.

Note: The form ID field is not explicitly used in this form, so you may ignore it.
